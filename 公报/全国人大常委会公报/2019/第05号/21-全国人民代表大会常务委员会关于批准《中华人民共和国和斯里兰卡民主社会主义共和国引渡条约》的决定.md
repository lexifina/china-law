# 全国人民代表大会常务委员会关于批准《中华人民共和国和斯里兰卡民主社会主义共和国引渡条约》的决定

全国人民代表大会常务委员会关于

批准《中华人民共和国和斯里兰卡民主社会主义

共和国引渡条约》的决定

（2019年8月26日第十三届全国人民代表大会常务委员会第十二次会议通过）

第十三届全国人民代表大会常务委员会第十二次会议决定：批准2016年4月7日由中华人民共和国代表在北京签署的《中华人民共和国和斯里兰卡民主社会主义共和国引渡条约》。
