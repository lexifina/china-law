# 崇明区人民代表大会关于设立专门委员会的决定

(2017年1月10日崇明区第一届人民代表大会第一次会议主席团第二次会议通过)崇明区第一届人民代表大会第一次会议决定：

崇明区人民代表大会设立法制委员会与内务司法委员会（合署）、财政经济委员会与农业与农村委员会（合署）。各专门委员会受崇明区人民代表大会领导，在大会闭会期间，受崇明区人民代表大会常务委员会领导。
