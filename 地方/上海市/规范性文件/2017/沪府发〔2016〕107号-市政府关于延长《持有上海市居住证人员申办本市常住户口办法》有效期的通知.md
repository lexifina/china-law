# 市政府关于延长《持有上海市居住证人员申办本市常住户口办法》有效期的通知

大

中

小

沪府发〔2016〕107号

上海市人民政府关于延长《持有上海市居住证人员申办本市常住户口办法》有效期的通知

各区、县人民政府，市政府各委、办、局：

经评估，市政府2012年制定实施的《持有上海市居住证人员申办本市常住户口办法》（沪府发〔2012〕12号）需继续实施，其有效期延长至2019年12月31日。

特此通知。

上海市人民政府

2016年12月27日
