# 关于对本市危害食品药品安全刑事案件调整管辖的规定

》的通知各中级人民法院、各区人民法院、上海铁路运输法院、市高级人民法院有关部门；各检察分院、各区人民检察院、上海铁路运输检察院、市人民检察院有关部门；各公安分局、市公安局有关单位，各公安处（局）；各区司法局、市司法局有关部门：

现将市高级人民法院、市人民检察院、市公安局、市司法局联合制定的《关于对本市危害食品药品安全刑事案件调整管辖的规定》印发给你们，请遵照执行。

2017 年12 月15 日印发（共印发300 份）关于对本市危害食品药品安全刑事案件调整管辖的规定为进一步加强跨行政区划刑事司法工作规范有序推进，根据《刑事诉讼法》及本市2016 年8 月公检法司联合制发的《关于上海铁路运输法院、上海铁路运输检察院有关刑事案件调整管辖的工作意见》等规定，现对本市危害食品药品安全刑事案件管辖有关事项明确如下：

一、自2018 年1 月1 日起，各公安分局，上海市公安局文化保卫分局、上海市公安局水上公安局、上海市公安局城市轨道和公交分局、上海市公安局上海化工公安局、上海市公安局国际机场分局、上海市公安局农场分局、上海市公安局自由贸易试验区分局、上海港公安局、长江航运公安局上海分局、上海海事公安局立案侦查的危害食品药品安全刑事案件，由上海铁路运输检察院审查批捕、起诉，由上海铁路运输法院依法审判；依法由中级人民法院一审的案件，由上海铁路运输检察院报送上海市人民检察院第三分院审查起诉，由上海市第三中级人民法院依法审判。

上海市公安局立案侦查或提办的危害食品药品安全刑事案件，向上海市人民检察院第三分院移送审查起诉、依法应当由基层法院一审的案件，2018 年1 月1 日起，由上海市人民检察院第三分院交由上海铁路运输检察院审查起诉。

二、2018 年1 月1 日前立案的案件，按照原管辖及程序办理，不再变更。2018 年1 月1 日前已批准逮捕的案件，继续由作出逮捕决定的检察院审查起诉。

三、对相关案件的法律援助工作，分别由立案侦查机关、上海铁路运输检察院所在区的法律援助机构组织实施；依法由上海市人民检察院第三分院移送审查起诉的案件、上海市第三中级人民法院、上海铁路运输法院依法审判的案件的法律援助工作，由上海市法律援助中心组织实施。

四、市高级人民法院、市人民检察院、市公安局、市司法局关于本市刑事案件管辖的规定，与本规定不一致的，按照本规定执行。
