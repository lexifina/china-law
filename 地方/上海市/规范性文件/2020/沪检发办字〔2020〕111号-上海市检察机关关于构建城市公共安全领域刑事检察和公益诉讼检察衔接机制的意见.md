# 上海市检察机关关于构建城市公共安全领域刑事检察和公益诉讼检察衔接机制的意见

》的通知各分院、区院、铁检基层院，市院各部门、派出院：

《上海市检察机关关于构建城市公共安全领域刑事检察和公益诉讼检察衔接机制的意见》已经市院检委会2020 年第13 次会议审议通过，现予印发，请认真贯彻执行。执行中遇到的问题，及时上报市院第二、第八检察部。

上海市人民检察院

2020 年9 月15 日上海市检察机关关于构建城市公共安全领域刑事检察和公益诉讼检察衔接机制的意见（2020 年9 月8 日上海市人民检察院检察委员会2020 年第13 次·总第657 次会议通过）为贯彻“两高一部”《关于办理涉窨井盖相关刑事案件的指导意见》以及《上海市人民代表大会常务委员会关于加强检察公益诉讼工作的决定》，落实最高检“四号检察建议”精神，通过发挥检察机关职能作用，自觉践行“人民城市人民建，人民城市为人民”重要理念，维护上海城市公共安全，保护人民群众合法权益，现就构建城市公共安全领域刑事检察和公益诉讼检察衔接机制，提出如下意见：

一、充分发挥刑事检察和公益诉讼检察双轮驱动作用依法惩治涉窨井盖等危害城市公共安全犯罪，积极稳妥拓展城市公共安全领域检察公益诉讼，为维护城市公共安全和保护群众“身边安全”，提供坚强的检察力量和法治保障。履行检察机关在刑事诉讼中的主导责任，对涉窨井盖等危害城市公共安全犯罪案件依法加强刑事立案监督，及时批捕、起诉，准确适用相关罪名，确保罪责刑相适应。立足上海城市特点和群众需求，积极稳妥拓展城市公共安全领域检察公益诉讼，慎重办理具体案件，严格案件办理程序，做足做实调查核实、研究论证等工作。落实有关行刑衔接等工作机制，织密织牢维护城市公共安全的法网。

二、建立健全城市公共安全线索互移机制

（一）线索移送

建立健全城市公共安全线索互移机制。刑事检察部门在办理刑事案件中发现涉窨井盖等城市公共安全公益诉讼线索的，应当及时将线索移送公益诉讼检察部门。公益诉讼检察部门在办理公益诉讼案件中发现涉窨井盖刑事犯罪或者其他危害城市公共安全犯罪线索的，应当根据案由，及时将线索移送相应的刑事检察部门。涉及未成年人的相关线索，根据职能分工，统一由未成年人检察部门（办案组）办理。

（二）具体情形

刑事检察部门和公益诉讼检察部门在办案中发现有下列情形之一的，应当认真审查有关案件材料，在了解把握行为性质和行为影响的情况下，向对方移送有关线索：

1.公共道路、公共场所的窨井盖缺失、损坏或者不符合安全管理规定，存在公共安全隐患的；

2.高铁及其他轨道、桥梁、隧道、道路、机场、航道、灯塔、标志缺失、损坏或者不符合安全管理规定，或者在前述交通设施限定区域堆放、倾倒、遗撒物品，存在公共安全隐患的；

3.公共道路、公共场所的地下、地上管线设施缺失、损坏或者不符合安全管理规定，存在公共安全隐患的；

4.公共场所不符合防火、防爆等安全管理规定，存在公共安全隐患的；

5.建筑物、构筑物或者其他设施及其搁置物、悬挂物发生脱落、坠落，或者从建筑物上抛掷、坠落物品，存在公共安全隐患的；

6.易燃、易爆、剧毒、高放射性、强腐蚀性、高致病性等高度危险物的生产、储存、运输、使用违反安全管理规定，存在公共安全隐患的；

7.饲养烈性犬等禁止饲养的危险动物，违反安全管理规定，存在公共安全隐患的；

8.其他违反安全管理规定，存在严重或者普遍公共安全隐患的。

三、理顺接收线索办理机制

（一）刑事检察部门接收线索的办理机制

1.审查研判线索。刑事检察部门接收涉窨井盖刑事犯罪或者其他危害城市公共安全犯罪线索后，应当及时进行审查，收集必要的证据材料。公益诉讼检察部门应积极支持配合。

2.开展立案监督。刑事检察部门发现线索有刑事立案可能而侦查机关尚未受案或者尚处于侦查机关立案审查期限内的，应当将线索移送侦查机关处理；发现侦查机关超过立案审查期限未作出是否立案决定的，应当要求侦查机关说明逾期不作立案决定理由；发现有犯罪事实需要追究刑事责任，而侦查机关作出不予立案决定、行政处罚决定或者撤销案件决定的，应当要求侦查机关说明不立案理由。

3.引导侦查取证。线索获刑事立案后，刑事检察部门应当根据案件具体需要，积极依托专职检察官联络、提前介入等工作机制，引导侦查取证，提高办案质效。

4.加强沟通协助。案件办理中需要获取有关证据材料或者事件背景资料的，刑事检察部门可以请求公益诉讼检察部门予以必要的协助。公益诉讼检察部门应积极支持配合。

（二）公益诉讼检察部门接收线索的办理机制

1.提前介入调查。公益诉讼检察部门接收城市公共安全领域民事、行政公益诉讼线索后，应当按照公益诉讼案件办理程序及时开展调查取证，具体工作可以与侦查机关侦查、刑事检察环节补充侦查等同步开展。刑事检察部门应积极支持配合。

2.及时履行公告程序。对需要提起刑事附带民事公益诉讼的案件，公益诉讼检察部门和刑事检察部门要密切沟通协作，在基本查明案件事实的基础上，一体考量刑事起诉时间以及公益诉讼公告、起诉时间，及时履行公告程序，争取刑事起诉和民事公益诉讼起诉同步进行。

3.加强沟通协助。在公益诉讼案件中，公益诉讼检察部门遇有需要同法院刑事审判庭等案件办理相关单位沟通协调的事项，可以请求刑事检察部门予以必要的协助。刑事检察部门应积极支持配合。

4.确保文书质量。加强规范公益诉讼文书。文书的事实和理由部分，应当写明案件线索来源、检察机关审查认定的被告违法（犯罪）行为、社会公共利益受到损害的事实和有关证据、诉前程序履行及回复情况，以及被告应承担法律责任的理由和法律依据、检察机关提起公益诉讼的法律依据等。文书的诉讼请求部分必须明确具体，于法有据。

四、合力推动城市公共安全治理学习贯彻上海市委《关于深入贯彻落实“人民城市人民建，人民城市为人民”重要理念，谱写新时代人民城市新篇章的意见》要求，坚持以防为主、以控为要，推动完善城市安全预防体系，助力城市公共安全治理体系和治理能力现代化。刑事检察部门和公益诉讼检察部门在城市公共安全领域案件办理中，发现行政机关存在监督管理漏洞或者涉案单位存在普遍性、倾向性风险防范问题的，可以单独或联合向行政机关、涉案单位制发检察建议，督促建议对象履职尽责，做到“办理一案，治理一片”。加强同公安、应急管理、住房和城乡建设、交通等部门沟通协调，协同解决存在的城市公共安全治理问题，推动“人民城市人民建，人民城市为人民”重要理念和“四号检察建议”精神落地落实。对于社会关注度高的城市公共安全领域热点、难点、堵点问题，需要制发检察建议的，除最高检刑事检察部门部署或者涉行刑衔接的以外，原则上由公益诉讼检察部门牵头承办，移送线索部门协助。

五、助力城市治理共建共治共享主动加强同各级人大代表、政协委员沟通联络，积极听取特邀监督员、特约检察员、人民监督员等外部监督人士意见建议，适时开展城市公共安全领域重点案件听庭评议和庭审直播活动。

加强有关典型案事例的研究和推广，围绕维护城市公共安全、保护群众“身边安全”、服务大局主题，注重提炼总结、沟通报送和宣传发布。认真落实“谁执法谁普法”普法责任制，结合社会关注的城市公共安全治理和法律问题，充分发挥以案释法的宣传教育作用。优化法治宣传方式，提升宣传的贴近性、吸引度和感染力。助推打造特色检察宣传品牌，扩大检察品牌影响和宣传工作成效。

六、完善评价激励机制

积极发挥检察官业绩考核和基层院建设考核的激励作用，带动工作质效切实提升。对于在办案中发现城市公共安全领域公益诉讼和刑事犯罪案件线索、相关案件办理质效较好、推动社会治理成效较大的检察官和办案部门，予以必要的正面评价。充分调动城市公共安全领域案件办理的积极性、主动性，推动刑事检察和公益诉讼检察衔接机制落地落实。
