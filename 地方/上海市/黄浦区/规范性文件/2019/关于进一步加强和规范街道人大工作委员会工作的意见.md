# 关于进一步加强和规范街道人大工作委员会工作的意见

关于进一步加强和规范

街道人大工作委员会工作的意见（2019 年6 月28 日上海市黄浦区第二届人民代表大会常务委员会第二十八次会议通过）为全面贯彻习近平新时代中国特色社会主义思想和党的十九大精神，深入学习习近平总书记关于坚持和完善人民代表大会制度的重要思想，进一步加强和规范区人民代表大会常务委员会街道工作委员会（以下简称街道人大工委）工作，推进基层民主政治建设，服务保障人大代表依法履职，充分发挥人大代表的主体作用，助推我区经济和社会发展，根据《上海市实施〈中华人民共和国全国人民代表大会和地方各级人民代表大会代表法〉办法》《上海市人民代表大会常务委员会关于区县和乡镇人民代表大会工作的若干规定》等有关规定，结合本区实际，制定如下意见。

一、提高站位，坚持街道人大工作正确的政治方向党的领导是坚持和发展中国特色社会主义事业的根本保证，也是坚持和完善人民代表大会制度的根本保证。人大工作具有很强的政治属性，做好人大工作、推动人大事业发展，必须始终坚持和依靠党的领导。街道人大工委要牢固树立“四个意识”，坚定“四个自信”，坚决做到“两个维护”，始终在思想上政治上行动上与以习近平同志为核心的党中央保持高度一致。要自觉地把党的领导贯穿于街道人大工作全过程，落实到依法履职各方面，始终保持街道人大工作的正确政治方向，自觉服从服务于全区发展大局，主动服务于区人大常委会履行法定职权，积极对接街道工作实际，谋划和推进街道人大工作。

二、依法履职，充分发挥街道人大工委的职能作用街道人大工委是区人大工作的重要基础、延伸和拓展，主要履行以下四方面工作职能：

（一）服务代表履职。街道人大工委根据区人大常委会工作要求，围绕区委、区人大常委会和街道党工委的中心任务，围绕人民群众关心的热点、难点和重点问题，制订年度工作计划和代表组年度活动安排，并具体实施和开展好街道人大工作和代表组活动。组织代表围绕经济社会发展、关系人民群众切身利益以及社会普遍关注的重大问题，开展视察、调研等活动，将调研成果及时转化为代表议案或代表建议、批评和意见。认真督办区人大常委会交办的代表建议，及时向有关方面反映代表的意见和要求。组织代表围绕街道中心工作、民生实事开展献计献策活动，对街道工作提出意见建议。充分挖掘和整合代表资源，为社区经济社会发展服务。

（二）凝聚代表队伍。街道人大工委要密切联系本街道人大代表组的区人大代表、与街道人大代表组对口联系的市人大代表，每位街道人大工委委员相对固定联系本代表组的5 至7 名区人大代表，每名市人大代表固定联系3 至5 名区人大代表。街道人大工委要加强与代表所在单位的联系，关心代表的工作和生活，帮助代表解决履职中的困难和问题，及时了解代表信息变动情况。要加强对街道人大工作和代表履职事迹的宣传报道，尊重代表主体地位，增强代表履职责任感、使命感。

（三）提升代表能力。街道人大工委要把组织代表学习培训作为一项经常性工作抓好做实，通过多种方式帮助代表掌握党和国家的大政方针，掌握人民代表大会制度和人大业务知识，掌握《宪法》《代表法》《监督法》等法律知识，优化知识结构，提高综合素质和专业化水平。要及时向代表通报区情区政和区人大及其常委会开展重要工作和活动的情况，向代表提供有关资料和信息等，为代表知情知政提供服务保障。

（四）完善代表监督。街道人大工委要组织好区人大代表向原选区选民报告履职情况，接受原选区选民或选举单位和人民群众的监督。要建立代表履职档案，对代表履职情况进行登记和汇总，每季度进行通报。要密切人大代表同人民群众的联系，认真做好市、区人大代表与选民的联系工作，组织好代表联系社区（选区）活动，拓宽代表联系群众的方式和渠道，畅通社情民意表达和反映渠道，建立健全代表反映群众意见和要求的分级处理反馈机制。街道人大工委要严格按照法律规定和上级要求，做好人大代表换届选举、代表补选、代表资格变动等相关工作。

三、完善机制，强化街道人大工委工作的保障措施

（一）强化组织领导。街道人大工委是区人大常委会在街道设立的工作机构，受区人大常委会领导，向区人大常委会负责并报告工作。同时，街道人大工委要自觉接受街道党工委的领导，重大问题和重大事项应及时向街道党工委请示汇报，使党工委能够及时了解人大工作，切实把街道人大工作列入重要议事日程，研究解决街道人大工委在行使职权和自身建设中的重要问题，支持街道人大工委履行好职责。

（二）加强平台建设。街道人大工委要拓宽代表联系人民群众的渠道，进一步加强和完善代表活动室建设，使代表活动室成为代表学习培训的重要基地、代表履行职责的重要场所、展示代表活动成果的重要窗口、扩大人大社会影响力的重要阵地，努力把代表活动室打造成服务代表履职的有效平台，让代表具有归属感的“代表之家”，为促进闭会期间代表活动经常化、制度化、规范化提供平台和载体。积极拓展代表联系群众的阵地建设，打造“代表联络站”和“代表联系点”等形式多样的联系阵地。

（三）完善制度建设。街道人大工委要加强建章立制，制定具可操作性的学习制度、会议制度、代表活动制度、代表联系选民制度及向选民报告履职情况制度，并向区人大常委会主任会议报备，也可以根据各自实际情况自行制订其他工作制度，并严格落实各项制度，以此推动街道人大工作的制度化和规范化。

（四）强化工作支持。区人大各专委会、常委会各工委会应当加强与街道人大工委的联动监督机制建设，增强常委会各项监督工作的针对性、有效性。区人大常委会办事机构应当加强与街道人大工委的联系，为代表和街道人大工委开展工作提供多方面的服务和指导。区相关工作部门要为街道人大工委和人大代表开展监督、视察、调研、走访等工作提供便利和支持。
