# 何元乡人民政府关于成立何元乡社会救助专项整治工作领导小组的通知

各村(社区)委会，乡直有关单位：

按照《施甸县民政局关于进一步强化社会救助专项治理工作的通知》精神，我乡领导高度重视，将清理调整工作和社会救助专项整治工作纳入党委政府重要议事日程进行同部署、同安排、同落实，做到主要领导要亲自抓，分管民政工作的领导要具体抓，驻村分管领导是第一责任人，驻村工作组是责任主体，按程序要求，认真抓好落实工作，确保程序合法，对象准确。经乡政府研究，决定成立何元乡社会救助专项整治理工作领导小组。现将组成人员通知如下：
