# 万兴乡人民政府关于成立万兴乡东安村易地扶贫搬迁安置点项目工程建设指挥部的通知

各村（社区）委会、乡直相关单位：

根据中共施甸县委办公室、施甸县人民政府办公室关于印发《施甸县易地扶贫搬迁实施细则（暂行）的通知》施办电〔2016〕7号、《施甸县发展和改革局关于万兴乡东安村易地扶贫搬迁安置点项目建议书请示的批复》（施发改地区〔2017〕χ号）文件精神，乡人民政府已完成了项目前期工作，开工条件准备就绪，为了切实加强领导，确保该工程按质、按量、按时完成，达到工程预期效益。经乡党委政府研究决定，成立万兴乡东安村易地扶贫搬迁安置点项目工程建设指挥部，现将成员名单通知如下：

指 挥 长：董必磊 乡党委副书记

副指挥长：杨 军 乡武装部长

常世能 东安村支书

成 员：李银春 乡财政所所长

苏光泽 乡水利工作站站长

段 雄 乡水利工作站技术员

寸得山 会计

梅贵荣 出纳

段兆林 乡项目办人员

杨浩流 东安村主任

指挥部下设办公室和征地拆迁组，由段雄同志兼任办公室主任，负责处理工程建设实施的日常事务。征地拆迁组名单如下：

组 长：杨 军 乡武装部长
