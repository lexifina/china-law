# 万兴乡人民政府关于认真贯彻落实县指挥部通知要求切实抓好春节期间及下一步森林防火工作的紧急通知

各村（社区）委会、乡直各单位：

经乡人民政府研究同意，现将《施甸县人民政府森林防火指挥部关于认真贯彻

落实省委省政府领导批示精神和省指挥部通知要求切实抓好春节期间及下一步森林

防火工作的紧急通知》转发给你们，请认真遵照执行。

万兴乡人民政府

2017年2月11日

施甸县人民政府森林防火指挥部关于认真贯彻落实省委省政府领导批

示精神和省指挥部通知要求切实抓好春节期间及下一步

森林防火工作的紧急通知

各乡、镇人民政府森林防火指挥所，各林场森林防火指挥所：

为深入贯彻落实丽江市玉龙县“1.20”森林火灾省委、省政府领导批示精神，现就抓好春节期间及下一步森林防火工作有关事项通知如下：

一、提前安排部署

根据县气象局预测，预计2017年春节期间，我县降水较历年偏少、气温偏高，森林火险等级逐渐升高。各乡镇、林场要清醒认识春节前后森林防火面临的严峻形势，提早分析研究春节期间及今后一段时间面临的森林火险形势，超前制定防控方案，周密安排部署，明确领导责任、部门责任、管护责任、监护责任、应急值守责任，将防扑火力量布防到一线、措施落实到一线、检查开展在一线，全面做好森林火灾的预防和应急处置工作，特别是善洲林场、城镇面山要采取超常规措施，确保无森林火情发生。

二、加强野外火源管控

各乡镇、林场要迅速行动，组织野外违规用火巡查行动组，深入农村山神供奉点、林区边缘农地、林下产业区域、林区旅游景点进行一次全方位排查，发现问题及时发放森林火险隐患整改通知书，及时整改。善洲林场黄泥沟森林防火检查站要加强入山人员检查，对春节期间入山旅游人员进行宣传和100%实名登记、收缴火种。督促专业扑火队、各类护林员加大巡护力度，重点区域要死看死守，严查林区和林区边缘用火，对在林区及林区边缘的违规用火行为，必须严厉查处。各乡镇要协助村（居）委会把违规用火处罚办法纳入村规民约，利用村规民约制约村民违规用火行为。

三、加强森林防火宣传

以农村宣传为主，突出宣传重点，以“严禁火种入山、严禁烧草烧地、林区边缘严禁燃放鞭炮等一切野外用火”为主要内容，利用广播、基层综合服务平台、微信平台、手机短信等方式，深入开展宣传，营造春节期间严防森林火灾的浓厚氛围。要在入山路口、林区公路悬挂森林火险五彩旗，设置警示标牌、书写森林防火标语。深入群众大力宣传森林火灾典型案例，引导民众“火种不入山、林区不用火”的责任意识和自觉行为。

四、加强应急值守机制

春节期间，各乡镇、林场分管领导无特殊原因不得离开辖区，森林防火办主任必须坚守岗位，全力以赴抓好森林防火工作，严格执行24小时值、带班制度和工作日报制度。所有扑火力量必须坚守岗位、保持战备状态，所有扑火机具装备、通信设备、交通工具必须保持完好。综合运用瞭望台、地面巡逻、护林员定位管理系统等手段，对森林火情进行全覆盖、全天候的监控，切实做到早发现、早响应、早扑灭。严格执行森林火灾归口管理、统一上报制度，坚决避免因报告不及时、多头报告贻误和影响扑火救灾工作。对虚报瞒报森林火灾造成重要影响的，要严肃处理。对值、带班不到位，甚至脱岗、缺岗的，以及卫星热点和火情处置不符合要求的，要坚决进行整改，造成严重后果的，坚决追究相关人员责任。

五、加强扑火安全

要牢固树立“以人为本、安全第一”的思想，把保障各类扑火队员和人民群众的生命安全摆在首位，层层落实安全责任制，完善安全保障措施。一旦发生森林火情（灾），及时弄清火情，迅速启动《森林火灾应急处置办法》，领导靠前指挥，科学、安全、高效处置。严禁动员老人、妇女、儿童、残疾人和未参加过安全培训的人员参加扑救森林火灾。

六、加强督促检查

春节前夕，要加大森林防火工作督促检查力度，及时组织工作组深入村、组及重点部位、敏感地区等进行全面检查，现场整改工作中的不足和问题，确保森林防火各项措施落实到位。
