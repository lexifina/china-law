# 仁和镇人民政府关于成立2017年云南省彩票公益金项目工程领导小组的通知

各村（社区）、镇直各相关单位：

为确保我镇2017年云南省彩票公益金项目工程建设顺利实施，确保工程质量合格，全面完成云南省彩票公益金项目工程，顺利通过上级验收，通过云南省彩票公益金建设项目充分发挥效益，经镇党委、政府研究，决定成立仁和镇云南省彩票公益金项目工程领导小组，成员名单如下：

组 长：王 继 镇人民政府镇长

副组长：蒋必松 镇人民政府副镇长

李 季 镇纪委书记

成 员：李学凤 镇党政办公室负责人

杨 莹 镇财政所负责人

杨晓翔 村镇规划服务中心主任

杨 栓 镇国土所所长

李月光 镇项目办工程师

李光兴 镇项目办工作人员

郭金进 热水塘社区党总支书记

李华昌 勒平社区党总支书记

项目领导小组下设办公室在镇项目办，由李光兴同志担任办公室主任，负责处理项目日常工作。领导小组、项目村相关成员负责监督项目工程质量，做好项目实施协调相关工作。

仁和镇人民政府

2017年2月8日
