# 何元乡人民政府关于成立何元乡抗震救灾应急领导小组的通知

何政发〔2017〕26号

各村（社区）委员会，乡直有关单位：

因人事变动,现将我乡抗震救灾指挥部成员进行调整，调整后领导小组成员如下：

副指挥长：张忠孝 乡武装部部长

杨庆艳 乡人民政府副乡长

赵鑫义 乡水管站站长

李 亮 何元供电所负责人

何玉龙 何元电信所负责人

各村（社区）委会主任

抗震救灾指挥部下设办公室在乡党政办，乡党政办公室负责人兼任办公室主任，乡民政办负责人兼任办公室副主任，指挥部各成员单位指定1名联络员为办公室成员。在应急处置工作中，乡抗震救灾指挥部可根据工作实际，对组织机构和职能职责进行调整。
