# 关于印发《仁和镇计划生育技术服务实施方案》的通知

各村（社区）、镇直有关单位：

经镇人民政府研究同意，现将《仁和镇计划生育技术服务实施方案》印发给你们，请认真贯彻执行。

仁和镇人民政府

2017年2月9日

仁和镇计划生育技术服务实施方案

为适应新时期人口和计划生育工作的需要，创新计划生育管理与服务模式，大力推行科学管理、民主管理和依法管理，充分调动群众参与管理、服务和监督的热情，推动仁和镇人口和计划生育基层群众自治和诚信计生工作的开展，全面提高我镇育龄人群生殖健康保健意识；以保障生殖健康，提高出生人口素质为重点，降低孕产妇、婴幼儿死亡率及新生儿出生缺陷为重点，以妇女儿童健康服务为宗旨，认真贯彻卫生工作方针，依法规范妇幼保健各项管理与服务，提高妇女儿童整体健康水平。结合实际，制定本方案。

一、指导思想

以稳定低生育水平、建立广大群众自觉参与和实行计划生育的基层群众自治长效机制为重点，进一步深化计划生育居民自治的进程，创建诚信型计划生育基础，引导群众自我教育、自我管理、自我服务、自我监督，构建镇与村（居）委、村（居）委与居民，居民和居民之间的和谐氛围。开展计划生育优质服务试点工作，以促进计划生育技术服务工作思路和方法的根本转变，实现计划生育技术服务重心下移，形成多数人做少数人工作，群众自我主动接受计划生育技术免费服务、自我服务和自我监督的计划生育工作格局。

二、工作目标

仁和镇现有育龄妇女10500人，按照上级部门的管理要求，仁和镇应完成育龄妇女“三查”体检管理1504人、“优生促进”320对。2017年将在全镇全面推行计划生育“三下乡”工作，在全镇20个村（社区）开展计划生育技术服务、生殖健康咨询服务。通过开展“三下乡”工作，不断总结经验，培育和树立一批诚信计生示范村(社区)，全面推进人口和计划生育基层群众自治工作，在全镇实现人口和计划生育基层群众自治、主动接受计划生育技术服务的新格局。

三、领导机构

成立仁和镇开展计划生育“三下乡”工作领导小组，负责组织、协调、指导全镇诚计划生育技术技术服务、生殖保健、避孕节育工作的开展，领导小组成员名单如下：

四、工作职责

（一）镇计生办：负责全镇育龄妇女的组织、协调和后勤保障工作，确保体检工作顺利进行。

（二）仁和中心卫生院：负责全镇育龄妇女的体检技术服务工作（妇科疾病检查、化验检查、B超检查），严格把握体检质量关，做到人性化管理服务。

（三）各村（社区）：负责做好各村育龄妇女的摸底数据上报、育龄妇女宣传动员和组织体检工作，确保各项指标任务有效完成。

五、工作要求

各村（社区）、镇直有关部门要积极配合、加强沟通协调，认真履行好部门职能职责，圆满完成此次育龄妇女的计划生育服务工作，为服务对象提供优质服务；要结合实际认真组织好服务对象，将计划生育技术服务工作与“阳光计生”、计划生育“两无一提高”、创建计划生育村民自治合格村（先进村）、争创国家人口计生基层群众自治示范村（居）活动有机结合起来，采取有力措施，精心组织，确保计划生育“三下乡”工作取得成效。
