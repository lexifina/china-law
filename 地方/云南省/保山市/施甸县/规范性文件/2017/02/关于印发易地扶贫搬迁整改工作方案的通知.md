# 关于印发易地扶贫搬迁整改工作方案的通知

各党总支（支部）、各村委会、乡直有关单位：

根据国家发展改革委《关于抓紧核查整改易地扶贫搬迁工作中苗头性倾向性问题的通知》 《关于抓紧开展易地扶贫搬迁整改工作的通知》和云南省易地扶贫搬迁工作推进协调小组办公室关于《坚决做好我省易地扶贫搬迁整改工作的紧急通知》（云易地协调办〔2017〕1号）等要求，经乡党委、政府研究，特制定本方案。

一、整改目标

聚焦建档立卡贫困搬迁人口，严谨、准确把握政策，通过整改，易地扶贫搬迁工作中的苗头性倾向性问题得到制止，未严格执行政策的突出问题得到纠正，全乡易地扶贫搬迁工作有序推进。

二、整改原则

（一）向上看齐，对下补齐。整改工作的全过程务必与国家有关易地扶贫搬迁的路线方针政策保持高度一致，整改措施的落实不折不扣与国家政策看齐，各村具体操作当中严格对照查补和整改，确保政策不走样、措施不脱节。

（二）坚守底线，严守红线。以脱贫为导向，将列入国家规划的65万贫困人口、建档立卡率作为搬迁任务底线；严守建房面积标准、不增加群众搬迁负担、严格各渠道资金管理、建新拆旧和退地复垦等作为工作红线，确保政策执行到位。

（三）强化责任，稳妥整改。各村要按照整改工作的责任分工和时限要求，细化整改措施，落实整改责任，确保各项整改任务落实到位。各村、乡联席办、乡直有关单位要积极落实主体责任，做到深入研究和精细化工作，确保整改工作稳妥推进。

三、整改主体

整改主体为各村村委会，乡联席办、乡直相关部门配合。

四、整改时限

2017年2月2日前整改完毕

五、整改任务

（一）严肃住房建设政策要求

1.存在问题：部分安置点住房人均建设面积超标，有的正在设计和建设的建档立卡搬迁户住房面积严重超标；有的在修建新房后未拆除旧房、宅基地也未复垦，甚至出现在同一地方“占有两处宅基地”的情况；有的采取购房安置的搬迁户存在负担过重问题。

2.政策要求：严格按照“保障基本、安全适用”的要求，做好建档立卡搬迁人口安置住房的规划和建设，建档立卡搬迁人口住房建设面积严格执行不超过25平方米/人的标准，严禁“垒大户”、“造盆景”，防止因建房面积过大而增加搬迁群众负担，使建档立卡搬迁人口因搬迁而负债，防止购房安置的搬迁户负担过重；宅基地用地面积按照《云南省土地管理条例》规定或州（市）人民政府制定的标准执行；按照《土地管理法》“一户一宅”的规定，建新房拆旧房，具备复垦条件的宅基地进行复垦；合理确定同步搬迁户建房面积，防止出现悬殊过大、相互攀比，甚至返贫的现象。

3.整改措施：各村对住房建筑面积、宅基地用地及建新房拆旧房情况进行全面梳理和检查。全乡所有易地扶贫搬迁安置点都必须设计有人均25平方米/人的户型供搬迁群众选择；要通过宣传引导群众量力而行，充分发挥联建委员会作用，采取“打二建一”、“打三建一”的方式，有效控制面积、降低搬迁群众建房成本；对已超面积的住房要研究通过调整出享受易地扶贫搬迁政策范围，并依托危改、美丽乡村等政策稳妥消化，或将超标安置房销售给同步搬迁户或有住房改善需求的群众等方式加以整改；对正在设计和规划建设新的搬迁住房，要严格按照国家标准执行，合理设计多种户型，满足不同人口家庭的住房要求，绝不能变相扩大住房建设面积，让搬迁群众因为建房而大量举债；通过科学合理制定资金拨付政策、制定奖励激励政策等做好旧房拆除、宅基地复垦等工作。

（二）严格资金管理

1.存在问题：取得的政策性贷款无法发放，大量贷款闲置在县级平台公司的同时又支付大额利息,出现已取得的政策性贷款无法发放，部分贷款闲置在账户的同时又支付大额利息的情况。

2.政策要求：对建档立卡搬迁人口和同步搬迁人口的资金安排、使用严格实行分类管理。中央预算内投资、地方政府债券资金、专项建设基金和低成本长期贷款要封闭运行，仅用于建档立卡搬迁人口，不得挪作他用。农村危房改造、财政专项扶贫资金、农业发展银行贷款等资金，按照源渠道管理规定执行。

3.整改措施：各村、乡直有关单位要立即开展自查，针对资金滞留滞拨问题，要精准、快速锁定搬迁对象，加快项目前期工作，加快资金拨付进度，切实提高资金效益。

六、工作要求

（一）加强组织领导，确保整改工作稳步推进。各村和有关部门务必高度重视，统一思想，敢于直面问题和不足，主动担当，不折不扣抓好整改工作落实。要精心组织、细化责任，逐户、逐人、逐项全面梳理易地扶贫搬迁政策执行中存在的问题，在整改时限内完成整改工作。

（二）细化整改措施，确保整改工作取得实效。各村要加强政策研究，围绕整改目标，按照整改原则，对照整改任务扎实开展整改工作。要注重工作实际与政策原则相结合，科学合理、灵活的把握政策依据，注重工作方法和细节，将整改工作切实落到实处。请各村及各乡直各“挂包帮”有关部门于2月3日上午11：30前将整改落实情况上报乡联席办，联系人：杨静，联系电话：8863566，邮箱：mlylxb@126.com。

（三）强化政策执行，确保政策执行不走偏。各村及各乡直有关部门要认真落实国家有关政策，坚决整改2016年易地扶贫搬迁工作存在问题，做到问题有落实，整改见成效。今后，搬迁对象未精准锁定、建房组织方式未确定、建房面积设计不合理、未完成项目相关前期报批手续的项目一律不得提前实施。
