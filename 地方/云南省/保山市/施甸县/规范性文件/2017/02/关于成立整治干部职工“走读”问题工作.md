# 关于成立整治干部职工“走读”问题工作

为认真贯彻落实好中共保山市委员会提出的工作要求，以及中共保山市纪律检查委员会和中共保山市委组织部联合发出《关于整治保山市领导干部“走读”问题的通知》（保组通[2017]17号）文件，明确要求严禁干部“走读”,经镇党委政府班子会研究决定，成立整治干部职工“走读”问题工作领导小组。
