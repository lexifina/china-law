# 关于抓好2017年兵役登记工作的通知

各村（社区），相关单位：

全国征兵网于1月10日正式开通，1月13日，国防部征兵办公室下发了《2017年征兵准备工作的通知》，要求各地要高标准做好兵役登记和征兵宣传工作。为认真落实上级要求，现就抓好年度兵役登记工作有关事项明确如下：

一要高度重视早做筹划。各村要高度重视兵役登记工作，提前搞好筹划，集中时间、人力抓好兵役登记工作。要加大与相关部门、单位的协调力度，集中骨干力量，集中时间节点，集中领导精力，扎实开展兵役登记工作，确保提前完成登记任务。

二要抓住重点宣传到位。各村要积极创新宣传手段方法，深入村寨、街道做宣传、搞动员，要善于到青年家中做一人一事的工作，把《国防法》第三十条“国家实行兵役登记制度。每年十二月三十一日以前年满十八周岁的男性公民，都应在当年六月三十日以前，按照县、自治县、市、市辖区的兵役机关的安排，进行兵役登记。”作为宣传重点，真正做到家喻户晓，发动应登记青年自觉进行网上登记。

三要做好筛查不漏一人。各村要积极与派出所密切配合、联合调查，准确掌握本村适龄青年底数，搞清楚每一名具体对象在哪里、做什么、登记了没有、怎么完成登记。一个组一个组地过，一人一人地登记，切实做到一人不漏，在5月份以前、坚决在6月30日以前，100%完成兵役登记任务。

旧城乡人民政府征兵办公室

2017年2月17日
