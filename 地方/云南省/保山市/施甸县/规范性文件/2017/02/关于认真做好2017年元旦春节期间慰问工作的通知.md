# 关于认真做好2017年元旦春节期间慰问工作的通知

各村委会、乡直各单位：

为确保我乡低保对象、特困人员、百岁老人、农村特困老人、受灾困难群体和优抚对象等度过一个欢乐祥和的节日，切实体现党和政府对他们的关怀，感受社会主义大家庭的温暖，经2017年1月16日会议研究，决定在节日期间对他们开展走访慰问活动，现将做好2017年元旦春节期间慰问工作有关事项通知如下：

一、提高认识，切实增强做好慰问工作的责任感和使命感

各村委会务必高度重视，加强领导，精心组织，一定要从保障和改善民生、促进社会和谐的高度，开展好此次慰问工作，以科学的举措、高效的方法，认真履行为民职责，有效保障困难群众基本生活，把党和政府的关怀送到困难群众手中。

二、强化措施，妥善安排好困难群众生活

（一）认真核准慰问对象，精心制定实施方案。各村要把困难群众冬春生活安排作为当前工作的首要任务抓紧抓实，切实摸清底数，制定方案。同时，根据困难群众情况，结合安排的慰问资金和慰问品，形成切实可行的实施方案，明确工作任务和责任，做到不重、不漏，分类别、保重点，进一步提高资金物资使用效益。

（二）大力开展社会互助，营造良好社会氛围。各村要广开渠道、多措并举，全力帮助困难群众解决实际困难，确保元旦春节期间社会政治稳定。与此同时，动员工、青、妇等群团组织，广泛发动群众参与，营造良好的社会氛围，主要领导要亲自带队组成慰问团（组）逐户对特困人员户、低保户、因灾造成生活困难的困难户、重点优抚对象等进行走访慰问，安排好他们的节日生活，切实保障受灾困难群众得到有效救助。

（三）加强值守，继续做好应对工作。各村要发扬连续作战的作风，积极做好应对准备，加强应急值守，坚持24小时值班制度，加强信息报告工作，保证灾情一发生，迅速核实，及时上报，确保各项应对措施落实到位。

三、严格程序，切实管好用好慰问款物

慰问款物的管理使用政治性强、敏感度高，管好用好慰问款物是工作的重要环节之一，关系到工作的成效，因此，各村要进一步规范工作程序，明确纪律要求，建立责任制度，切实保证慰问款物合理合法使用，向人民群众交一本明白账、放心账。在慰问款物的使用上，要坚持“专款（物）专用，重点使用，分类救助”的原则；在救助对象的确认上，严格执行“户报、村评、乡审”的申报程序；在款物的发放上，严格实行“民主评议、登记造册、张榜公布、公开发放”的工作程序，切实做到手续完备、专账管理、专人负责、账款相符、账目清楚，确保慰问款物及时、足额发放到困难群众手中。

四、加强督促检查，确保各项工作落实到位

2017年元旦春节期间，经请示县人民政府同意，县民政局将会同相关部门组成检查组，赴13个乡（镇）、部分村、组进行检查，其主要内容是：①救灾方面，主要是检查灾区群众的吃、穿、住等生活方面的安排情况，救灾救济款物发放使用的方式及效果；②救助方面，检查特困人员户、城乡低保户等城乡困难群众生活情况，是否领到慰问款物和开展救助工作的情况；③优抚方面，主要是检查优抚对象是否足额领到抚恤补助优待金和落实“三难”工作的情况。

请各村务必于2017年1月19日17：30前将花名册电子版发至民政办邮箱（1158235521@qq.com），物资与慰问金发放时间乡民政办统一安排，提前联系各村。
