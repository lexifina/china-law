# 何元乡人民政府关于印发何元乡中学生青春健康教育活动实施方案的通知

何政发〔2017〕41号

各村委会，乡直各部门：

《何元乡中学生青春健康教育活动实施方案》经乡人民政府同意，现印发给你们，请结合实际，认真贯彻实施。

何元乡人民政府

2017年3月22日

何元乡中学生青春健康教育活动实施方案

为进一步提高人口素质、促进人口长期均衡发展，切实提高何元乡青少年性与生殖健康水平和身心健康素质，决定在全乡青少年中开展青春健康教育和服务工作，结合何元实际，制定本方案。

一、指导思想

以党的十八大、十八届三中、四中、五中、六中全会和全国卫生与健康大会精神为指导，认真贯彻落实《中共中央 国务院关于实施全面两孩政策改革完善计划生育服务管理的决定》、《“健康中国2030”规划纲要》和国家11个部委《关于“十三五”期间深入推进婚育新风进万家活动的意见》(国卫宣传发〔2016〕42号)、《教育部关于印发〈中小学健康教育指导纲要〉的通知》(教体艺〔2008〕12号)、八部门联发文件《关于在全省青少年中开展青春健康教育和服务工作的意见》精神，把健康放在优先发展的战略地位，努力全方位全周期保障人民健康，坚持国家计划生育政策，大力培育和践行社会主义核心价值观，创新宣传方式方法，发挥先行先导作用，建设适应新时期人口形势、促进人的健康和全面发展、体现中华传统美德和时代精神的新型婚育文化。

二、活动目标

将青春健康教育纳入中学阶段（含初中、高中、职中）素质教育的重要内容，将健康教育纳入体育与健康教师岗前教育和在岗培训内容，培养健康教育师资为全乡所有中学生提供乐于接受的性与生殖健康讲座和咨询服务，减少非意愿妊娠，减少早婚早育，提高人口素质。从2017年起，全乡所有中学均要定期开展中学生青春健康教育活动，为全面建成小康社会，实现“中国梦”创造良好的人口环境。

三、活动原则

（一）以各中小学为责任主体，全乡各级中小学，要结合自身实际，细化方案，围绕目标，合理安排活动。

（二）以学生需求为导向，以人的全面发展为目标，不断满足学生青春期性与生殖健康服务的新期待，努力创新教育思维、教育内容和教育手段。

（三）发挥各相关部门的职能作用，加强对活动的指导协调，形成工作合力。

四、活动内容

（一）培养青春健康教育师资。开展青春健康教育师资培训，逐步将全乡所有中学体育与健康教师培养成为青春健康教育的师资力量，为学生提供青春健康知识讲座、心理咨询疏导服务。

（二）营造宣传氛围。在校园内发放“青春健康教育”读本，利用广播、黑板报或在学生寝室内制作标语与宣传板宣传卫生知识，让学生随时注意、随时学习，培养良好的健康行为习惯，营造健康的校风。

（三）开展青春健康专题知识讲座。各中学每年要举办青春健康专题知识讲座，由体育与健康教师为学生讲授青春健康知识，让学生系统全面了解生理卫生知识，了解国家计划生育相关政策。

（四）提供心理疏导。对相关老师进行心理知识技能培训，使其了解学生特定时期心理特点，能够针对学生的心理状态进行简单的判断和疏导;在学校内设置专门的心理咨询处，或提供24小时开通的手机求助热线，在保护学生隐私的情况下，为学生提供心理辅导，帮助学生解答心理疑惑，克服心理问题。

（五）引导家庭教育。中学组织家长会，印发“致家长的一封信”，向家长普及家庭教育知识，强调良好、和睦的家庭氛围对子女心理健康的重要性；与家长建立相关联系，了解学生各方面的成长状况与问题，预防学生产生不良心理状况，寻求共同帮助学生健康成长的办法。

（六）举办健康知识竞赛。中学每年要结合“五·四”青年节知识竞赛、文艺晚会等活动，以问答、竞答等形式考察学生对青春期健康知识的了解程度，并设置不同级别的奖励，动员每一个学生积极参与到活动中来。

五、工作职责

各相关部门要进一步明确工作职责，各司其职，发挥各自优势，形成合力，共同促进青春健康教育和服务工作在全乡的顺利开展。

文化站：将此项工作纳入加强和改进青少年思想道德建设和社会主义核心价值观教育的内容，纳入全乡宣传思想工作的议事日程，抓好协调，落实相关宣传教育工作。各级各类媒体要加大健康科学知识宣传力度，积极建设和规范电视健康栏目，利用新媒体拓展青春健康教育。

宣传办公室：把青春健康教育工作与精神文明建设相结合，发展健康文化，移风易俗，培育良好的生活习惯。

各中小学：以中学为重点，建立学校青春健康教育推进机制。将青春健康教育纳入国民教育体系，普及健康科学知识，把青春健康教育作为初中教育阶段素质教育的重要内容。在校园内发放“青春健康教育”读本，利用广播、黑板报或在学生寝室内制作标语与宣传板宣传卫生知识，让学生随时注意、随时学习，培养良好的健康行为习惯，营造健康的校风。各中学组织家长会，印发“致家长的一封信”，向家长普及家庭教育知识，与家长建立相关联系，了解学生各方面的成长状况与问题，寻求共同帮助学生健康成长的办法。何元中学每年要举办青春健康专题知识讲座，由体育与健康教师为学生讲授青春健康知识。结合“五·四”青年节、文艺晚会等活动，每年要举办一次以上的青春健康知识竞赛或文艺活动。在学校内设置专门的心理咨询处，提供24小时开通的手机求助热线，在保护学生隐私的情况下，为学生提供心理辅导，帮助学生解答心理疑惑，克服心理问题。

司法所：将青少年青春健康教育与普法教育有机结合起来，积极开展预防和减少青少年性犯罪工作。同时，在服刑和劳教的青少年中有重点地开展青春健康教育培训活动，并为青少年提供相关法律援助。

卫生院：推进全民健康生活方式行动，建立健全健康促进与教育体系，提高健康教育服务能力，从小抓起，普及健康科学知识。为青少年提供适宜的、优质的生理、心理卫生咨询和相关生殖健康医疗保健服务，并协助做好有关青少年性与生殖健康的宣传教育等工作，积极倡导婚育新风进万家。

共青团：将青少年性与生殖健康、心理健康科学知识纳入团组织的宣传培训工作内容，在中学、各村做好性与生殖健康知识培训工作。依托青少年维权服务中心、青年中心、维权服务热线等阵地，切实为青少年提供生理、心理咨询服务，进一步加强青春健康教育和服务志愿者队伍建设，积极推动志愿服务项目化运作。

妇联：充分发挥妇联在家长学校、家庭教育方面的作用，把青春健康教育纳入讲师团宣讲内容，不断提高家庭教育水平。

计生办：要将青春健康教育和服务工作纳入协会常规工作及计划生育目标责任考核任务，统一部署、管理和考核。充分利用协会的网络队伍优势、人力资源优势，重点开展校外青少年的青春健康宣传教育培训和服务工作。利用群众团体组织的优势，广泛开展国内交流与合作，并利用先进的、科学的项目运作和管理的经验优势，为相关部门提供师资培训等技术支持。企业、村社区等基层计生协会要在外来务工人员、社会闲散人员和各类餐饮、娱乐等服务行业青少年中开展青春健康教育活动。

六、活动保障

（一）高度重视，加强领导。成立何元乡中学生青春健康教育活动领导小组，由乡长为组长，分管卫计、教育副乡长为副组长，乡党政办、宣传办、中心学校、文化广电站、卫生院、司法所、妇联、团委为成员，负责组织协调、检查评估青春健康教育活动；领导小组下设办公室在乡计生办，负责日常工作。各中小学、各部门要高度重视青少年性与生殖健康教育工作，成立青春健康教育工作领导小组，细化工作方案，加大经费投入，把青春健康纳入教学计划，统筹部署实施。

（二）部门协调，形成合力。全乡积极联动教育、卫生、共青团、妇联、计生办等单位组织成为推动活动的重要力量，共同推进青春健康教育工作，每年要举办一次以上的青春健康知识竞赛、文艺活动。

（三）加强督导，促进发展。何元乡青春健康教育活动领导小组要加大对各中小学青春健康教育工作的检查督促力度，并将青春健康教育工作情况，纳入乡人民政府对各单位工作责任目标考核管理，形成长效机制，确保全乡青春健康教育工作顺利推进。
