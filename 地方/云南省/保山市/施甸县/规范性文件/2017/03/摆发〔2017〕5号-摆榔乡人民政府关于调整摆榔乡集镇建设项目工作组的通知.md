# 摆榔乡人民政府关于调整摆榔乡集镇建设项目工作组的通知

摆发〔2017〕5号

中共摆榔乡委员会 摆榔乡人民政府

关于调整摆榔乡集镇建设项目工作组的通知

各支部（党总支）、村委会（社区）、乡直各二级站所：

摆榔乡集镇是摆榔乡经济、社会、文化的核心，摆榔集镇建设发展对摆榔乡各族群众能否如期脱贫，与全国全省同步实现小康具有十分重要的意义。要紧紧抓住省委办公厅、市纪委、市委办挂钩帮扶，把握云南中烟工业公司对特少民族乡镇实施整乡推进布朗族整族帮扶的历史机遇，实现摆榔经济社会跨越发展。摆榔集镇建设尤为重要，为有效整合易地扶贫搬迁、教育、卫生、社会事业、配套公共基础设施（路网、电网、给排水网）及村庄整治等项目资源，加强对摆榔集镇建设的领导，明确职责，建立统筹协调的工作机制，因人事变动，经乡党委、政府研究，决定调整摆榔集镇建设项目工作组，现将组成人员名单及工作职责通知如下：
