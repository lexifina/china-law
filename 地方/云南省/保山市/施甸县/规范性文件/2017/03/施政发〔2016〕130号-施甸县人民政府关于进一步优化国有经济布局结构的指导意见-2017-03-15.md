# 施甸县人民政府关于进一步优化国有经济布局结构的指导意见

各乡镇人民政府，县直各单位：

为深入贯彻落实《中共中央 国务院关于深化国有企业改革的指导意见》（中发〔2015〕22号）、《中共云南省委 云南省人民政府关于全面深化国有企业改革的意见》（云发〔2014〕10号）、《云南省人民政府关于进一步优化国有经济布局结构的指导意见》（云政发〔2016〕7号）和《保山市人民政府关于进一步优化国有经济布局结构的指导意见》（保政发〔2016〕11号）的总体部署和要求，结合实际，现就优化国有经济布局结构提出如下指导意见：

一、总体要求

（一）指导思想。以党的十八大和十八届三中、四中、五中全会精神为指导，主动适应经济发展新常态，主动服务和融入国家发展战略，牢固树立创新、协调、绿色、开放、共享的发展理念，坚定走开放型、创新型和高端化、信息化、绿色化的产业发展新路子，坚持以市场为导向、以企业为主体，做强做优做大国有企业，把调整国有经济布局结构与全面深化改革、推进转型升级、实施走出去战略结合起来，进一步加快国有企业改革、改组、改造和自主创新步伐，着力优化国有资本产业布局和企业布局，构建配置合理、结构优化、发挥功能、体现优势的国有经济新格局，充分发挥国有经济在推动全县跨越发展中的引领带动作用。

（二）基本原则

——坚持市场导向。遵循市场经济规律，尊重企业市场主体地位，充分发挥市场在资源配置中的决定性作用，加强政府引导及服务，提高国有资本配置和运营效率，优化国有经济布局，放大国有资本功能。

——坚持发挥优势。落实国家产业政策和重点产业布局调整总体要求，推动国有资本向符合国有企业功能定位的优势产业和企业集中，发挥全县资源、区位和产业优势，使国有资本在关系全县经济社会发展的战略性、基础性和民生服务等重要行业和领域发挥骨干引领作用。

——坚持有进有退。发挥国有资本投资、运营公司的作用，加快推动国有资本合理流动，促进国有资本逐步从不能发挥优势的行业和领域有序退出，新增国有资本更多投向提供公共服务、发展战略性新兴产业、保护生态环境、支持科技进步等重要领域和关键环节。

——坚持统筹规划。既要立足当前，又要着眼未来，使国有经济布局结构优化调整与全县经济社会发展有机衔接，统筹研究制定全县国有经济在产业及企业的总体布局规划，以规划统领国有经济布局结构调整，增强国有经济整体功能和效率。

——坚持动态调整。国有经济布局和结构调整坚持中长期规划指导、规范推进。积极应对国有经济发展面临的新形势和新课题，在实践中把握规律，做到在动态中调整、在创新中推进。

（三）主要目标

到2020年，全县国有资本基本实现向支撑带动地方经济发展的重点和优势产业集中，在战略性新兴产业培育、高新技术产业发展、现代服务业壮大、传统产业改造提升等方面取得重大突破，基本完成国有经济和国有企业战略性重组，形成比较合理的国有经济布局结构。

国有经济带动作用不断增强。混合所有制改革稳妥有序推进，国有资本引领带动作用充分发挥，国有经济对地方经济发展支撑作用不断增强。

产业结构明显优化。战略性新兴产业增加值比重逐年提高，现代服务业快速发展，新业态、新商业模式不断涌现，传统产业向高端化、信息化、绿色化方向转变取得重大进展。

国有经济运行质量整体提高。国有资本运作能力和效率明显提高，国有资产总量持续增长，“十三五”期间，全县年均国有资本均达到保值增值的目标。

企业竞争力全面提升。国有企业创新能力明显增强、运行质量和效益进一步提高，经济发展方式转变取得明显成效。在电力、投融资和交通安全技术服务等领域培育一批具有比较优势和市场竞争力的企业，力争年营业总收入达10亿元以上的企业1—2户。

二、着力优化国有资本的产业布局

（四）发挥国有资本在改造提升传统产业中的支撑作用。坚持在做优存量中提升实力，合理引导国有资本在传统产业中的布局，对具有特色优势，已经形成较大存量资产的投融资、交通安全技术服务等传统产业，按照“改造提升传统产业，发展壮大优势产业”的原则，推动传统产业向信息化、绿色化、集团化方向发展，促进全县产业结构调整升级和可持续发展。

（五）发挥国有资本在城市建设和发展领域中的引领作用。紧紧抓住云南加快发展以大理、隆阳、腾冲、芒市、瑞丽等为重点的滇西次级城市群机遇，围绕全县深入推进实施新型城镇化建设、交通优先发展等重大战略部署，以加快“五网”建设为重点，发挥国有资本在基础设施建设中的主导作用，以国有资本带动更多社会资本参与基础设施建设，特别是城市片区综合开发和配套建设，服务支撑地方经济发展。鼓励国有资本积极参与城市综合交通、供水等提供公共产品和服务的领域，成为保障和改善民生的主力军。

（六）发挥国有资本在发展壮大现代服务业中的带动作用。依托国有资本在全县旅游、文化、金融保险、现代物流等现代服务业领域已经形成的产业基础和发展优势，围绕打造东方国际慢城，推进温泉契丹古镇、千亩温泉、中业农业观光旅游项目建设。全面实施“互联网+”行动，积极培育服务业新业态、新模式，引导国有资本重点进入具有高附加值、高成长性的生产型服务业和生活型服务业，推动服务业规模化、品牌化、网络化。推动国有资本向传统服务业中的优势骨干企业集聚，整合资源，创新发展，形成结构优化、功能完善、附加值高、竞争力强的现代服务业发展格局。

三、积极调整国有经济的企业布局

（七）优化企业发展环境，完善制度建设。开展降低实体经济企业成本行动，优化运营模式，增强盈利能力。限制政府对企业经营决策的干预，减少行政审批事项。清理和规范涉企行政事业性收费，减轻企业负担，完善公平竞争和促进企业健康发展的政策、制度。培育企业家精神，依法保护企业家财产权和创新收益。大力推进现代企业制度建设。按照《中华人民共和国公司法》和现代企业制度的要求，完善公司法人治理结构。加强董事会建设，优化董事会成员结构，健全董事会工作机构，完善董事会工作规则，提高董事会治理绩效。完善监事会制度，整合监督资源，发挥监督作用。规范公司董事会、监事会和经营管理者的权责，形成各负其责、协调运转、有效制衡的公司法人治理结构。

（八）发展壮大一批大企业大集团。加大国有企业和企业化管理的事业单位的改制力度，按照以建立现代产权制度为核心，以发展混合所有制经济为目标，以股份制为主要实现形式，打破资产部门化、凝固化的利益格局，按照国有优质资产和资源向关键领域及优势企业集聚的改革思路，积极推动产权多元化。对于目前仍由各主管部门管理的国有企业和企业化管理的事业单位，根据“一企一策、重点突破、产权多元、优势整合、劣势退出”的原则，围绕突出主业，积极推进企业非主业资产重组。继续深入实施大企业大集团战略，充分发挥国有资本投资、运营公司作为市场化运作的专业平台作用，以产权为纽带，按照集团化管理和专业化经营的模式，以资本运作、产业整合和项目建设为重要手段，通过业务流程再造、创新管理模式和商业模式，尽快形成主业突出，具有较强自主创新能力、资源配置能力、风险管控能力、市场竞争能力的大企业大集团。

（九）大力支持央企、省属企业在施发展。支持央企、省属企业充分利用全县丰富的资源优势、开放的区位优势和产业发展的市场空间入施兴业，布局发展。深化与中央企业、省属企业的合作，充分发挥央企、省属企业在资金、技术、品牌和市场上的优势，加大支持其与市内企业战略合作力度，形成优势互补、共同发展的新格局，为施甸新型工业化、信息化、城镇化、农业现代化发展注入新动力。

（十）加快国有资本国际化布局。紧紧抓住国家“一带一路”和把云南建设成为我国面向南亚东南亚辐射中心的重大战略机遇，着力发挥我县在国家战略中新的区位优势，充分利用国际国内两个市场和两种资源，以开拓市场、利用资源、提升技术和打造品牌为重点，加快国际化战略布局，加快实施走出去战略。支持有实力的企业开展省外境外资源开发合作，建立多元化资源保障体系。

四、促进国有资本合理流动

（十一）推进国有股权市场化重组。以促进国有企业转换经营机制、放大国有资本功能、提高国有资本配置和运行效率为目标，全面推进国有企业股权多元化改革。积极引进战略投资者、财务投资人和各类基金参与国有企业改组改制，促进产权和投资主体多元化。把发展混合所有制经济与国有经济布局结构调整有机结合起来，全方位、多层次、宽领域地推进国有资本、集体资本、非公有资本的开放性和市场化联合重组，引进各类资本参与国有经济布局结构调整，使发展混合所有制经济成为国有经济布局结构调整的重要途径。

（十二）发挥国有资本投资运营平台作用。充分发挥国有资本投资、运营公司作为市场化运作的专业平台作用，通过平台进行投资融资、产业培育、资本整合，推动产业集聚和转型升级，使国有资本更多投向对地方经济发展有支撑力和带动力的重要行业、战略性新兴产业以及重点提供公益性产品和服务的领域，实现国有资本布局结构优化；通过股权运作、价值管理、有序进退，促进国有资本合理流动，推动国有资本和社会资本更好融合，改善国有资本结构，提高运营效率，实现国有资本保值增值。

（十三）推动国有企业整合重组。加快推动国有资本向重要行业、关键领域、重点基础设施集中，向前瞻性战略性产业集中，向产业链关键环节和价值链高端领域集中，向具有核心竞争力的优势企业集中。积极推动国有企业通过参股、控股、并购、联合等多种形式开展横向和纵向兼并重组，实现集约化发展、集团化经营，进一步提高综合竞争力。可通过与中央企业、省属企业市属企业间的股权并购、置换、相互参股等方式进行重组，努力推动县本级的国有经济做大做强。以提高发展质量效益为目标，采取市场并购、交叉持股、资产整合等方式，消除企业间同质化无序竞争，集中资源聚焦发展主业，加快从非主业领域退出，严控产能过剩行业投资，促进国有资本更多地向关系国家安全、国民经济命脉的重点行业和关键领域集中，引导企业整合内部资源，优化业务结构，完善产业链条，提高产业集中度，提高资源配置效率。

五、保障措施

（十四）加强组织领导。国有经济布局和结构调整涉及面广、情况复杂，事关职工切身利益和社会稳定。各部门要把国有经济结构优化布局调整作为一项长期任务，高度重视，加强领导，认真研究，把握重点，细化措施；要加强对重点工作的督促检查和指导，及时研究解决工作中遇到的困难和问题，把每一项工作落到实处，抓出成效。县国资委要高度重视推进国有资本调整和国有企业重组工作，搞好调查研究和可行性分析，充分听取各方面的意见，从实际出发，统筹规划，周密部署，积极稳妥推进。

（十五）坚持规划引领。有关部门要按照全县“十三五”规划的总体要求，把进一步优化国有经济布局结构目标任务纳入本部门的“十三五”规划，以规划为引领，坚持有所为有所不为、有进有退、有的放矢，扎扎实实优化国有资本产业布局，调整国有经济的企业布局，完善施甸特色的区域布局，持续推动全县国有经济布局结构的调整优化。

（十六）加大政策支持。有关部门要积极支持国有经济布局结构调整，加强协调沟通，强化协作互动，形成工作合力。有关部门要研究制定并落实好在投融资、产业发展、技术创新、税费减免、考核奖惩等方面的政策措施，加强服务指导，支持、引导和推动国有企业在国有经济布局结构调整优化中的积极作为。

（十七）营造良好氛围。要多形式、多方位、多层次做好舆论宣传，营造理解、关心、支持国有经济调整优化的良好氛围，做到思想统一、行动一致，形成政府推动、市场拉动、部门联动和企业主动的工作格局。
