# 关于印发旧城乡中学生青春健康教育活动实施方案的通知

各村（社区），乡直各相关单位：

《旧城乡中学生青春健康教育活动实施方案》已经乡人民政府同意，现印发给你们，请结合实际，认真贯彻实施。

旧城乡人民政府

2017年4月8日

旧城乡中学生青春健康教育活动实施方案

为进一步提高青少年思想道德素质，培养青少年健康的心理和良好的道德责任意识，促进青少年身心全面和谐发展，旧城乡结合实际，决定在全乡青少年中开展青春健康教育活动，现制定本实施方案。

一、 指导思想

以党的十八大、十八届三中、四中、五中、六中全会和全国卫生与健康大会精神为指导，认真贯彻落实省、市县相关文件精神，把健康放在优先发展的战略地位，努力全方位全周期保障人民健康，坚持国家计划生育政策，大力培育和践行社会主义核心价值观，创新宣传方式方法，发挥先行先导作用，建设适应新时期人口形势、促进人的健康和全面发展、体现中华传统美德和时代精神的新型婚育文化。

二、 活动目标

通过开展“青春期健康教育进校园”活动，对中学生进行生殖健康知识和珍爱生命教育，使广大青少年懂得生理健康知识，懂得如何保护自我，珍爱自我，珍爱生命。在校园活动中建立和完善科学、规范的服务制度，增强青少年的生殖健康意识和自我防护能力。提高生殖健康水平，促进人口和计划生育事业良好发展。

三、活动内容

1、积极开展健康教育宣传活动，多渠道、多形式进行健康促进活动的宣传和教育，力争使学生健康知识的知晓率不低于80%，健康知识问卷合格率不低于80%，健康行为合格率不低于90%。

2、按要求开设健康教育课程，同时开设课时，培养学生卫生习惯，自觉遵守和维护公共卫生、校园卫生，掌握卫生知识。

3、认真贯彻实施《学校卫生工作条例》，落实好教学楼、学生宿舍、学校食堂卫生制度，优化和美化校园环境，努力创建优美、整洁、高雅的育人环境。

4、每学期对学校健康教育进行综合评价，使各项健康教育工作达到标准。

四、工作措施

1、加强领导，健全组织。成立青春健康教育工作领导小组，确定具体负责此项工作的领导及工作人员。同时负责制定工作方案、计划和检查落实情况。做到目标落实，任务落实，责任落实，人员落实，措施落实，效果落实，确保此项工作积极扎实地开展。

2、全员培训，提高认识。对全体教师、学生进行培训，以便统一思想，提高认识，明确工作目标。科学合理地安排课程，按照要求开设青春健康教育课程，坚持每周至少上1课时，要求上课教师制定教学计划，按课时备好课，并定时进行课程检测考试。

3、发挥优势，建立载体。学校要依托计划生育办公室建立青春健康服务中心，服务中心要具备讲授知识、提高技能、开展咨询、提供法律支持和导医服务等五项功能，确保为目标人群提供知识服务和技术服务。

4、开展活动，培育健康环境。通过丰富多彩的校园文化生活，改善学生的习惯，陶冶学生的情操，愉悦学生的心灵。

5、加强督导，促进发展。加大对有关部门青春健康教育工作的检查督促力度，以确保全乡青春健康教育工作全面、健康发展。

旧城乡人民政府办公室 2017年4月8日印
