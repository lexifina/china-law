# 关于成立大学生村官班领导小组的通知

根据云南省委办公厅《关于进一步做好大学生村官工作的意见》（云办通〔2016〕66号）和保山市委组织部《关于印发<保山市大学生村官“管理办法”试行>的通知》文件要求，为进一步提高大学生村官自我组织、自我管理、自我服务、自我发展的能力，增强大学生村官队伍的凝聚力、执行力和团队意识，形成大学生村官群体的认同感、归属感和荣誉感，激发大学生村官干事创业激情，努力打造一支“听党话、跟党走”的大学生村官队伍，决定成立旧城乡大学生村官班领导小组，现将组成人员名单通知如下：

指导员：郑云波 旧城乡党委委员、组织委员

班 长：李国东 旧城乡大田坝村党总支书记助理

士 兵：姜桂芳 旧城乡旧城社区党总支书记助理

李 彬 旧城乡新街村主任助理

董建华 旧城乡芭蕉林村主任助理

段雨楠 旧城乡李来村主任助理
