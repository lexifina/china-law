# 摆榔乡人民政府关于成立摆榔乡整治领导干部“走读”问题领导小组的通知

摆发〔2017〕7号

中共摆榔乡委员会 摆榔乡人民政府

关于成立摆榔乡整治领导干部“走读”问题领导小组的通知

根据中共保山市纪律检查委员会 中共保山市委组织部印发的《关于整治县乡领导干部“走读”问题的通知》（保组通〔2017〕17号）和中共施甸县纪律检查委员会 中共施甸县委组织部《关于印发〈施甸县整治县乡领导干部“走读”问题暂行办法〉的通知》（施组通〔2017〕14号）精神，为扎实开展好相关工作，经乡党委政府研究，决定成立摆榔乡整治领导干部“走读”问题领导小组。现将领导小组人员名单通知如下：
