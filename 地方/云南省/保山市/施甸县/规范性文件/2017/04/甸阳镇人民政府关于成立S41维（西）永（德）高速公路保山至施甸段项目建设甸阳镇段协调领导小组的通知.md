# 甸阳镇人民政府关于成立S41维（西）永（德）高速公路保山至施甸段项目建设甸阳镇段协调领导小组的通知

根据《中共施甸县委办公室施甸县人民政府办公室关于成立 S41 维（西）永（德）高速公路保山至施甸段项目建设协调领导小组的通知》（施办发〔2016〕64 号），为确保涉及甸阳段协调工作顺利推进，经镇党委、政府研究，决定成立 S41 维（西）永（德）高速公路保山至施甸段项目建设甸阳镇段协调领导小组，现将小组成员名单通知如下：

组 长:杨治平 镇 长

副组长:李绍福 副镇长

段如贤 宣传委员

王施赢 组织委员

苏金荣 综治办负责人

陈建冬 财政所所长

董志伟 项目办主任

杨凤清 司法所所长

王延山 农业技术推广站站长、农村公路管理所常务副所长
