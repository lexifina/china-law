# 甸阳镇人民政府关于成立甸阳镇2017年防汛应急工作领导小组的通知

为做好甸阳镇2017年防汛工作，保护人民群众生命财产安全，维护社会稳定，及时有效地开展防汛工作，经镇人民政府研究决定，成立甸阳镇防汛应急工作领导小组，现将领导小组成员名单通知如下：

组 长：杨治平 甸阳镇镇长

副组长：苏 彬 甸阳镇副镇长、甸阳派出所所长

段如贤 甸阳镇宣传委员

成 员：杨发军 甸阳镇武装部部长、民政办主任

杨恒毅 甸阳镇党镇办负责人

赵 刚 甸阳镇水管站站长

蒋 荣 甸阳卫生院院长

杨凤清 甸阳司法所所长

张运海 甸阳镇林业服务中心主任

徐兴国 甸阳国土资源所所长

陈建冬 甸阳镇财政所所长

赵金林 甸阳镇中心学校校长

王延山 甸阳镇农科站站长

14个村（居）委会主任

领导小组下设办公室在甸阳镇水管站，由赵刚同志兼任办公室主任，负责处理办公室相关业务。

甸阳镇人民政府

2017年4月5日
