# 关于实施抓党建促脱贫巩固提升行动的具体方案

何发〔2017〕45号

为认真贯彻落实《中共保山市委办公室印发<关于全面推进”基层党建巩固提升”的实施意见>的通知》(保办发 【2017】10号)精神,结合本乡实际，现就实施抓党建促脱贫巩固提升行动提出以下方案。

一、目标和任务

深入实施基层党建和脱贫攻坚“双推进”，积极开展“党旗一线飘扬、党徽一线闪光、干部一线识别、群众一线给力”（“四个一线”）主体实践活动，坚持把基层组织建到项目点，把优秀干部派往最前沿、把党员作用发挥到一线、把基础保障落实到支部，筑牢脱贫攻坚堡垒，建强脱贫攻坚队伍，培育脱贫攻坚人才，锻造脱贫攻坚先锋，凝聚脱贫攻坚合力，增强脱贫攻坚保障，让党建触角延伸到脱贫攻坚的每个领域各个环节，强化基层组织整体功能，充分发挥贫困地区基层党组织和党员在脱贫攻坚中的引领作用。

二、工作措施

（一）筑牢脱贫攻坚堡垒。坚持在生产一线、重大项目一线、矛盾焦点一线、脱贫攻坚一线科学设置党组织，加大在龙头企业、农民专业合作社、农业产业链等重点领域和易地扶贫搬迁、产业园区等重点项目中建立党组织力度，扩大党在脱贫攻坚工作中的组织覆盖和工作覆盖。坚持领导联系、“一村一策”、派驻工作组等有效措施，持续整顿贫困村软弱涣散党组织，帮助解决突出问题，建强贫困村“两委”班子，对贫困村党组织书记进行集中“体检”，对不胜任脱贫攻坚任务的及时调整，确保全面提档升级。坚持“四议两公开”工作法，不断完善乡村组治理机制，加强村党组织领导下的村民自治组织建设，强化村务监督委员会职能。

（二）建强脱贫攻坚队伍。加强乡村干部队伍建设，把最优秀、最合适的乡干部选派到脱贫攻坚一线，坚持在一线考察识别干部，注重从乡事业编制人员、优秀村干部、大学生村官中选拔乡领导班子成员，鼓励乡机关人员到村工作。加强贫困村党组织带头人队伍建设，注重从农村致富带头人、外出务工经商人员、退伍军人、大学生村官、乡村医生中选拔村党组织负责人。加强村级后备力量建设，实施脱贫攻坚“好书记”选育计划，重点培养35岁以下优秀村民小组长、党建信息（平台）助理员、致富带头人、回乡大中专毕业生、外出务工返乡人员、退伍军人等，建立村级后备力量信息库。加强驻村扶贫工作队伍建设，确保每个贫困村驻村扶贫工作队有5—10人，并保持队伍稳定。每个村选派一名第一书记。加强乡村干部培训力度，充分发挥乡党校、村活动室和远程教育站点，开展贫困村党组织书记培训、“百名党员大轮训”等，提升乡村干部能力素质。

（三）培养脱贫攻坚人才。在一线挖掘人才，培养人才，使用人才。推动人才队伍的引进、培养和使用，实施乡土人才回引计划，探索建立与贫困地区发展相适应的人才工作体制机制。每年争取招考一批优秀大学毕业生、统筹选派一批专业技术人才、资助培育一批产业骨干人才到脱贫攻坚一线。推动农村实用人才队伍建设，围绕培训“七个一批”农村人才，大力组织实施“农村人才培训行动”。邀请技术部门、外聘专家学者到乡、村开展农村实用技术、职业技能和创业培训，培养造就一批能够带头致富并带领群众脱贫致富的生产能手、经营能手、能工巧匠等农村实用人才。

（四）锻造脱贫攻坚先锋。在一线发挥党员的先锋模范作用，示范引领。要在脱贫攻坚一项发现、培养、考察入党积极分子，做到每个村民小组都有党员，积极运用党员干部现代远程教育、基层综合服务平台等手段，经常性开展农村党员教育培训。培育一批党员创业致富示范基地，做到每个有劳动力的党员都有脱贫致富项目，每个贫困村都有党员致富带头人，通过“1+N”“N+1”结对帮扶等形式，在信息技术、资金等方面提供帮扶。要用好用活大力推广“基层党员带领群众创业致富贷款”，加大农村党员创业资金扶持力度，帮助解决党员发展资金短缺难题，让党员成员贫困地区带头致富、带领致富的先锋。

（五）凝聚脱贫攻坚合力。建立领导挂点促建、部门包村共建、星级党组织创建的“三建一创”机制，深入推进“双联系-共建双推进”活动，努力构建脱贫攻坚联动机制。建立驻村扶贫工作队严管机制，严格执行驻村工作队召回办法，充分运用保山市远程视频调研督查系统实行视频随机点名，综合服务平台工作日志等方式，加大管理力度，防止挂名走读，严肃工作队员工作纪律。驻村扶贫工作队成立临时党支部或党小组，第一书记（工作队长）兼任书记或小组长，纳入乡党委和村级党组织管理，第一书记向乡党委和派出单位双重述职。建立对口帮扶和社会力量参与扶贫机制，鼓励支持民营企业、社会组织、个人参与扶贫开发，实现社会帮扶资源和精准扶贫有效对接。

（六）增强脱贫攻坚保障。保障村级组织运转经费和干部报酬待遇，建立正常增长机制，探索村干部养老、医疗保险补助和正常离任村干部生活补贴制度，不断提高村干部保障水平。保障资金、项目、技术、人才向贫困地区倾斜，推动村民活动小组场所全覆盖、农村电商服务站全覆盖、集体经济万元以上村全覆盖，促进基层组织基础保障能力大幅提升。

三、组织实施

（一）压实领导责任。各党总支（支部）要把抓党建促脱贫攻坚工作作为一项重要政治任务，严格执行“一把手”负责制，坚持一线指挥部署，一线督促落实。

（二）强化督促考核。乡党委将把抓党建促脱贫攻坚工作纳入重点工作督查范围，成立督查组开展随机督查、专项检查、列表督查，适时通报，把抓党建促脱贫攻坚工作作为班子和干部年度考核的重点内容，党总支（支部）书记抓党建述职评议的重要内容。

（三）注重舆论宣传。各党总支（支部）要结合“两学一做”学习教育，注重总结出抓党建促脱贫攻坚工作的做法、成效和经验，加大宣传力度，营造良好氛围。注重在一线挖掘和宣传贫困村党员干部带领群众脱贫攻坚的典型，用身边典型感召人、激励人，引导广大群众从思想上“拔穷根”，凝聚打赢脱贫攻坚战、决胜全面小康的信心和力量。
