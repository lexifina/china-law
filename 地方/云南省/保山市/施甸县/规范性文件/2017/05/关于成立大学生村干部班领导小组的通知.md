# 关于成立大学生村干部班领导小组的通知

根据《云南省委办公厅 关于进一步做好大学生村干部工作的意见》（云办通〔2016〕66号）和《保山市委组织部 关于印发<保山市大学生村干部“管理办法”试行>的通知》文件要求，为进一步提高大学生村干部自我组织、自我管理、自我服务、自我发展的能力，增强大学生村干部队伍的凝聚力、执行力和团队意识，形成大学生村干部群体的认同感、归属感和荣誉感，激发大学生村干部干事创业激情，努力打造一支“听党话、跟党走”的大学生村干部队伍，经镇党委研究决定成立甸阳镇大学生村干部班领导小组，现将组成人员名单通知如下：
