# 关于成立甸阳镇村民小组活动场所建设领导小组的通知

为了切实解决我镇一些村办公活动场所简陋特别是少数村无办公活动场所问题，改善村级基层组织办公活动条件，促进农村各项工作有效开展，结合市委的有关要求和县委组织部《关于全面推进村民小组活动场所建设工作的通知》（施组通〔2016〕42号）文件精神，根据我镇实际，经镇党委政府研究，决定成立甸阳镇村民小组活动场所建设领导小组，现将领导小组成员名单通知如下：
