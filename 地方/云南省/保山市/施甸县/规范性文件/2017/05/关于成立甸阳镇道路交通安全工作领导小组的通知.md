# 关于成立甸阳镇道路交通安全工作领导小组的通知

为了切实加强甸阳镇道路交通安全工作，经镇党委、政府同意，决定成立甸阳镇道路交通安全工作领导小组，小组组成成员如下：

道路交通安全工作领导小组下设办公室在镇安监站，由何建菊同志负责处理日常事务工作。

二、部门和单位职责

道路交通安全工作小组职责:（一）负责承担甸阳镇道路交通安全委员会办公室的日常事务工作，拟定镇交通安全事故应急预案，并组织实施。（二）负责宣传国家安全生产法律法规及相关方针政策。（三）了解、掌握甸阳镇辖区内各道路交通安全管理单位的状况，车辆底数等，做到底子清情况明。（四）依法对甸阳镇辖区内组织开展道路交通安全隐患排查。（五）配合上级和其他有关部门进行道路交通安全事故的调查处理。（六）完成好县级和本镇交办的其他工作任务。

党政办职责：协助甸阳镇道路交通安全委员会办公室做好日常工作。

纪委办职责：对安全生产工作落实情况进行跟踪问责，并且对既不行动、拒不整改的干部进行诫勉谈话，对出现重大安全生产问题的相关责任人，启动“一案三查”，进行责任倒追。

财政所职责：（一）根据全镇道路交通安全工作的需要，确保全镇安全监督管理和行政执法所需的经费，以及全镇安全会议、专项整治、宣传教育、事故处理、安全奖励以及举报奖励等所需的经费。（二）每年安排专项资金，用于支持安全生产支撑体系建设、安全技术改造项目、应急救援体系建设以及重点监控涉及公共安全的重大事故隐患整治，并对资金的使用情况进行监督检查。（三）负责全镇财政系统直属单位的安全管理和事故防范工作。

甸阳派出所职责：（一）全面掌握辖区道路基础信息，重点排查临崖临水、事故多发易发、危险路段安全隐患，对排查出的隐患要建立登记台账，属于公安机关治理范围的要落实措施加强治理，属其他相关部门的要督促其尽快治理，坚决预防因隐患排查治理不到位导致重特大道路交通事故发生。（二）负责组织开展交通安全宣传教育和培训工作；维护道路交通秩序，查处各类道路交通违法行为。（三）落实上级部署的道路交通安全宣传工作。（四）定期组织开展辖区道路交通事故隐患点段的排查；处理简易程序以下的道路交通事故。（五）协助办理车驾管理的相关业务工作；完成好有关道路交通安全管理的相关业务信息、数据和报表的收集上报工作。（六）做好上级交办的其它工作。

综治办公室职责:（一）负责审查全镇道路交通安全监督管理的规范性文件草案，并监督检查其执行情况。（二）协同有关部门开展道路交通安全执法检查。

武装部、民政办职责：负责发生道路交通安全事故或重大灾害事故时，根据镇人民政府要求，按有关规定组织民兵预备参加应急救援和事故抢险。

甸阳司法所职责：（一）将道路交通安全法律法规列入全镇法制宣传的重要内容，会同有关部门广泛宣传普及道路交通安全法律法规知识。（二）监督、指导基层法律工作人员（包括律师）通过各种形式为道路交通安全部门提供法律服务，对经济困难的法人和社会团体依法提供道路交通安全法律援助。

宣传办职责：（一）将道路交通安全生产宣传作为全镇实施社会宣传教育的重要内容，纳入社会宣传和长远规划和年度计划，并组织实施。（二）组织、指导建立全镇道路交通安全公益宣传通道，开辟道路交通安全专栏，报道安全生产先进典型及重大道路交通安全活动。（三）协同有关部门开展各种形式的道路交通安全宣传教育活动。（四）正确把握舆论导向，引导新闻媒体正确宣传道路交通安全事故及其他安全突发事件，维护党和政府的形象和社会的稳定。

农村公路管理所职责：要充分发挥乡镇对农村道路交通安全的监管职责，加强业务指导力度，延伸交通管理触角，全面消除农村道路交通管理盲区、死角，坚决预防重特大道路交通事故发生，并采取多种形式广泛宣传农村道路交通安全管理工作，提高群众交通安全意识。同时，要广泛发动广大群众参与其中，动员群众积极举报严重交通违法行为。

文化广播电视服务中心职责：（一）履行全镇文化系统企事业单位的行业安全管理职责；（二）配合甸阳派出所做好道路交通安全监管工作，做好对各类旅游企业的日常监督检查和各种专项检查，道路交通安全检查。

中心学校职责：（一）履行全镇教育系统的安全监督管理职责，根据全镇各级、各类学校学生上下学接送安全状况，制定防范安全事故的措施和对策，建立师生道路交通安全事故防范机制。（二）加强对各类学校、单位组织学生开展校外社会实践活动的道路交通安全监督管理。指导、督促各类学校制定活动的应急预案和事故防范措施，严防各类事故的发生。（三）将道路交通安全教育列入义务教育的重要内容，组织师生员工开展事故警示教育活动，向师生员工普及事故防范知识，增强学生的自我保护能力。（四）参与全镇教育系统道路交通安全事故的应急救援和调查处理。

村（居）委会职责：（一）制定本村（居）委会道路交通安全管理规划并组织实施。（二）组织开展道路交通安全宣传教育，提高农村道路交通安全宣传教育覆盖面和普及率。（三）与辖区内企业、学校等单位签订道路交通安全责任书，定期督促检查工作落实情况。（四）每季度召开一次道路交通安全例会，分析本村（居）委会内道路交通安全状况，安排部署下季度工作。（五）建立健全本村（居）委会内机动车及驾驶人员信息纸质和电子台账，实现对车辆、驾驶员户籍化管理。（六）组织开展本村（居）委会内农村道路安全隐患排查，上报相关部门及时治理。（七）收集交通违法证据，及时向公安交警部门报告。（八）协助公安交警部门办理机动车、驾驶证车管业务。（九）协助公安交警部门做好交通事故现场维护、善后调解处理工作。（十）完成道路交通安全管理其他工作任务。

中共甸阳镇委员会 甸阳镇人民政府
