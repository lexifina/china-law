# 施甸县水务局关于成立施甸县水务局安全生产标准化建设领导小组的通知

局属各二级单位、各乡镇水利工作站：

为进一步加强水利行业安全生产标准化建设管理工作，促进生产经营单位安全生产主体责任的全面落实，切实加强我县水利行业安全生产标准化建设管理工作的领导，确保人民生命及财产安全，杜绝安全生产事故的发生。经局领导班子会议研究，决定成立施甸县水务局水利行业安全生产标准化建设领导小组，现将小组组成人员名单通知如下：
