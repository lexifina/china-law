# 关于印发木老元乡整乡推进布朗族整族帮扶项目2016—2017年度项目责任分工的通知

各村委会、乡直各单位：

为切实推进木老元乡布朗族整乡推进整族帮扶项目实施顺利开展，按时按质按量完成扶贫开发规划建设内容，实现布朗人民脱贫致富，与全国各族人民一同步入小康社会。经乡党委政府研究，决定将项目工程细化到人，明确项目指挥长、驻场人员、技术人员，确保各项工作落实到位。让我们全乡干部群众同心同德，齐心协力，自强不息，在省、市、县各级党委、政府的正确领导下，以更加饱满的工作热情、更加务实的工作作风、更加顽强的拼搏精神，励精图治、锐意进取，全力推进木老元整乡推进整族帮扶项目的开展，通过三年的攻坚，两年的提升，切实促使布朗人民脱贫致富，有效实现木老元现跨越发展。现将《木老元乡整乡推进布朗族整族帮扶项目2016—2017年度项目责任分工的通知》印发给你们，请各村委会、乡直各单位认真遵照执行。
