# 万兴乡人民政府关于加强汛期地质灾害防治工作的紧急通知

各村（社区）委会、乡直各单位：

今年雨季来临较往年偏早，近段时间来我乡降雨持续时间长，降雨量增多，极易引发地质灾害，为切实加强雨季地质灾害防治工作，防范灾害事故的发生，现将有关事项通知如下。

一、提高认识，切实加强组织领导

各村（社区）委会、乡直各单位要充分认识当前地质灾害防治的严峻形势，克服麻痹松懈思想，充分认识地质灾害防治工作面临的严峻形势，根据《施甸县2017年度地质灾害防灾减灾方案》（施政办发〔2017〕35号）文件要求，进一步细化、实化、深化各项防治措施，切实把地质灾害防治工作落到实处。单位主要负责人要亲自安排部署和检查督导地质灾害防治工作，加强对地质灾害防治工作的组织领导。

二、突出重点，全面开展地质灾害巡查排查

由于近段时间连续降雨，土层含水量处于饱和、半饱和状态，易发生泥石流、滑坡、塌方等地质灾害。各村（社区）委会、乡直各单位要加大对地质灾害监测点、电站、水库坝基、重要交通路段、公路沿线、重要居民点、学校、矿山企业、旅游景区、在建工程区的巡查排查力度，做到巡查排查到位，不留死角，对辖区内的地质灾害隐患做到心中有数，并根据各隐患点的变化情况采取相应措施，明确责任，制定具体防范措施，能整改的则立即整改，暂不能整改的要设立警示标识标志。

三、加强监测预警，提高应急处置能力

各村（社区）委会、乡直各单位要严格落实值班值守、主要领导带班制度，根据辖区或管理责任区内存在隐患的具体情况，详细制定并严格贯彻执行地质灾害防治“四项制度”、“三条措施”。密切关注天气形势和汛情发展，对重大雨情、水情、险情、灾情等有关情况，要全面掌握。险情或灾情发生后，领导干部要切实履职，果断组织受威胁群众撤离，第一时间启动应急预案，组织应急抢险救灾队伍赶赴现场，开展应急抢险、伤员救治和群众安置等工作，最大限度地减少群众生命财产损失。同时，各种数据要统一汇总、逐级及时上报，做到不重报，不漏报。

四、加大宣传力度，切实提升群众防灾自救能力

各村（社区）委会、乡直各单位要积极开展防灾减灾工作，充分利用公开栏、宣传栏，采用电视公告、发放宣传单等形式，加强对地质灾害防治工作的宣传，做到宣传力度大、广度深、效果显；各村（社区）委会、国土所对全乡所有地质灾害隐患点设立的警示牌和宣传栏进行检查，警示牌和宣传栏损坏的及时完善补充；及时向受威胁群众发放防灾、避险明白卡，明确险情发生后撤离转移的路线和避让地点；通过加大宣传教育和开展地质灾害应急避险演练工作，提升群众的识灾避灾和抗灾自救能力，全面提高突发地质灾害应急响应和处置工作水平。

万兴乡人民政府
