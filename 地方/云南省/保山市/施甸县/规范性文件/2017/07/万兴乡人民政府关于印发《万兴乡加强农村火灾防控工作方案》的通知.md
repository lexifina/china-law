# 万兴乡人民政府关于印发《万兴乡加强农村火灾防控工作方案》的通知

各村（社区）、各相关单位：

为认真吸取“3.2”红河弥勒亡7人农村较大火灾事故教训，充分发挥镇消防安全委员作用，切实加强对广大农村地区火灾防控工作，确保人民群众生命财产安全，根据省、市、县三级政府《关于加强和改进农村消防工作的意见》要求，经乡人民政府研究，决定开展“加强农村火灾防控”工作，特制定该方案，请认真遵照执行。

一、工作目标

在乡政府的统一领导下，分析研判我乡农村地区消防安全形势，进一步加大农村消防投入，夯实农村火灾防控基础，增强农村抗御火灾能力，全力抓好农村火灾防控工作，明显提升群众消防安全满意度，坚决确保我乡尤其是农村地区火灾形势平稳，为党的十九大胜利召开创造良好的消防安全环境。

二、组织领导

为确保该项工作组织推进到位、工作措施落实到位、工作职责履行到位，建立“一委一办三员”的工作格局：依托乡消防安全委员会，下设消防工作办公室，在消防工作办公室配备2名兼职消防安全管理员，专门负责日常工作。

办公室主任：杨学元 副乡长、派出所所长

消防安全管理员：杨 军 武装部长

杨 好 综治办负责人

杨 好 安监站负责人

行政村设立消防安全工作小组，村委会主任担任组长，为本村消防工作第一责任（消防安全管理员），成员为驻村干部、治保员、护林员和计生宣传员等。主要职责是在乡政府的领导下，加强本行政村微型消防站日常管理，组织人员扑救辖区内初期火灾，并按照上级要求，参与邻近村的火灾扑救工作，人员具体名单见附件1。

村民小组设立志愿消防队，村民小组长任队长（消防协管员），队员由村民组成。主要负责日常火灾隐患的检查，消防知识宣传，初期火灾扑救，人员具体名单见附件1。

三、工作措施

（一）加强农村消防基础设施建设。按照《农村防火规范》（GB50039-2010）、《村庄整治技术规范》(GB50445-2008)和省公安厅、住房城乡建设厅等6部门《关于加强城镇公共消防设施和基层消防组织建设的实施意见》(云公消〔2015〕224号)要求，将消防安全布局、消防车通道、消防水源、消防装备、消防组织等纳入乡总体规划和村庄建设规划，与村庄整治、脱贫攻坚、易地扶贫搬迁和美丽宜居乡村建设等同步规划建设。结合农村道路建设、人畜饮水工程，建设村庄消防车通道、消防供水设施。设有自来水管网的集镇、村庄，要建设室外消火栓；使用天然水源的村庄，要修建消防水池；农村散居住户及缺水地区，要因地制宜修建消防水池、水窖等储水设施；发动农户进行户内电气线路改造。采取政府购买服务方式，在传统村落、古建筑、福利机构等场所推广安装独立式感烟探测器，提高农村单位场所消防预警水平。

（二）加强农村消防组织力量建设。按照《云南省专职消防队伍管理办法》（省人民政府令第184号）和《乡镇消防队标准》（GAT 998-2012）要求，组建政府专职消防队，配齐专职消防队员，负责灭火救援、辖区单位场所和农村居民住宅的防火巡查与消防宣传工作。加强派出所消防警组建设，按照《云南省公安派出所消防警组建设标准》，对列管单位进行监督检查，开展消防宣传教育。加强微型消防站建设，行政村、30户以上的自然村依托志愿消防队建立微型消防站（微型消防站建设标准见附件2），队员由村干部、党员骨干、民兵等组成，主要负责所在地火灾扑救、防火巡查和走访宣传工作，年内完成40%行政村微型消防站建设任务。村委会、村民小组两级组织力量主要负责组织开展初起火灾扑救、消防安全自检自查和消防宣传教育。

（三）加强农村消防安全环境整治。乡消防安全委员会每季度召开一次联席会议，分析研判辖区消防安全形势，定期联合公安派出所、民政所、工商所等职能部门，开展针对性的消防安全检查，特别是在火灾高发季节、农业收割季节、重大节假日和乡村宗教祭祀、庙会等民俗活动期间加强防火巡查检查。村委会消防安全工作小组每月召开会议分析研判辖区消防安全形势，通报存在问题，定期组织发动专兼职消防队员、消防安全管理员、消防协管员重点排查纠治村民违规用火用电、乱堆乱放柴草杂物等易引发火灾的突出问题。建立消防安全联防机制，实行邻里互助协防模式，落实“十户联防”措施，在村民中指定消防联防人员，以十户为单位定期轮值开展消防安全自检自查。派出所要加强对行业、单位、基层组织的消防业务指导，培训行业、单位、村消防安全明白人，督促落实消防安全主体责任。

（四）加强农村消防宣传教育。文化、科技、卫生计生部门要结合“三下乡”活动广泛开展消防宣传教育，普及消防安全常识。学校要将消防知识纳入中小学校教学内容，加强中小学生消防宣传教育，确保每个学校“有课时、有教材、有师资”，充分发挥“小手拉大手”作用，带动提升家庭成员消防安全意识。农业有关部门要将消防知识纳入农业生产技术培训和农民务工技能培训内容，不断提高农民工消防安全素养。乡消防安全委员会要充分发挥“云岭先锋信息平台”作用，适时编辑发送针对性的消防宣传提示短信，提醒广大群众注意消防安全。乡、村专兼职消防协管员要适时进村入户开展消防宣传教育，特别要对孤寡老人、病弱残障人士、留守儿童等重点人群进行“一对一”帮扶、“面对面”宣传。村委会要依托农村广播站、文化站设立消防宣传站，利用喇叭、广播等坚持每日播放消防安全常识和火灾事故警示案例，以专栏、橱窗、板报、标语等形式提醒群众注意用火用电安全，切实提高群众消防安全意识。

四、工作要求

各行政村相关负责人必须认真抓好以上工作任务的落实，领导小组办公室务必尽职尽责，及时向乡消防安全委员会主要领导汇报相关工作进展，对思想重视不够，责任落实不力，任务完成不好，甚至敷衍塞责的单位和个人，将及时进行通报，对因主观原因导致的火灾隐患长期存在、火灾扑救不力而造成的具有一定负面影响火灾事故的单位和个人，由乡消防安全委员会的名义提请乡政府，实施问责处理。对发生较大以上火灾或同一区域在一季度内连续发生2起以上（含本数）一般火灾的，按照规定实行消防责任“一票否决”。
