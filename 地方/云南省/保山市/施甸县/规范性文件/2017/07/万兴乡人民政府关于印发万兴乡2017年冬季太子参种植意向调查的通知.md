# 万兴乡人民政府关于印发万兴乡2017年冬季太子参种植意向调查的通知

万兴、长浪坝、写寨、中山村（社区）：

根据万兴乡高原特色农业产业发展规划，调优产业结构，为提高当地居民种植收入，经乡产业办研究，决定在我乡海拔1200米以上，土壤砂壤、半砂壤，排灌便利地块大力发展材太子参种植产业。请各村（社区）加大对太子参种植产业宣传力度，发动适宜种植地块农户种植，对有种植意向的农户进行摸底统计造册，务必于7月15日前将意向种植花名册报乡产业办，进行统一汇总。

太子参为石竹科植物孩儿参。干燥块根。主要产于福建、江苏、山东、安徽等地。其中以福建柘荣县产的太子参最为出名。一九八五年正式列收载到《中国药典》。太子参具有益气健脾，生津润肺之功效，临床常用脾虚体倦、食欲不振、病后体虚、气阴不足、自汗口渴、肺燥干咳等症状，近年来随着太子参功能性保健品的开发问世，民间太子参药饮、药膳的普遍使用，太子参作为功能食品市场需求在逐年增加。

2017年初我乡在长浪坝村大龙洞山处试验种植1.5亩，目前处于成熟期，整个种植过程植株长势良好，病害较少（仅有部分植株因未进行种子消毒患有中度花叶病），初步估产，亩产约100kg（干重），近期太子参统货市场流通价格为80元/kg，亩产值达8000元，除去每亩种植成本1800元（种子1500元，化肥200元，农药100元，不含劳动成本），每亩净利润6200元，比传统烤烟产业亩增收3200元，该产业在我乡发展具有较高可行性。
