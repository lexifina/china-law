# 关于印发《何元乡乡级电子商务服务点项目建设实施方案》的通知

各村（社区）委会，乡直各单位：

《何元乡乡级电子商务服务点项目建设实施方案》经乡人民政府同意，现印发给你们，请结合实际，认真贯彻实施。

何元乡人民政府

2017年7月15日

何元乡乡级电子商务服务点项目建设实施方案

按照《云南省商务厅关于做好电子商务兴边富民三年行动计划2016年项目申报的通知》（云商市〔2016〕77号）要求，根据《中共施甸县委 施甸县人民政府关于加快电子商务发展的实施意见》（施发〔2016〕3号）文件精神，为加快农村电子商务公共服务平台建设，加强电子商务在全乡范围内的推广应用，结合我乡实际，特制定本实施方案。

一、何元乡农村电子商务发展概况

（一）创建乡电子商务服务所。为加快何元电子商务发展，在乡财政比较困难的情况下，积极筹措资金，挂牌成立了电子商务服务所，为企业及创业青年提供一个电商创业孵化平台。提供电商培训、开店指南、电商信息等电子商务孵化服务。

（二）组建团队，开展电商培训。由乡电子商务办公室牵头，以大学生村官和党建助理员为主要成员，成立电子商务技术服务推广队。负责定期组织对电子商务由兴趣或已经从事网络经营的群体，进行有针对性的电商技术培训一对一帮助，并邀请现在从事电商的人员开展电商心得交流，以实例促动电商推广。

（三）培育典型，带动电子商务发展。引导农产品经营者、农村合作社等积极开展农产品网上销售等业务，重点突出辣椒、黑皮花生、绿壳鸡蛋等特色产品。鼓励农村青年依托电子商务进行创业。加强电子商务知识培训和政策引导，以返乡创业青年、农村青年致富带头人和部分个体经营户伟重点，积极培育一批农村电子商务创业带头人，切实发挥其在农村电子商务发展中的引领示范作用。

（四）紧抓机遇，建设电子商务示范村。通过实地调查，到2020年，建设全乡的电子商务示范村2个，组军门村成立了兴农农特产品种植专业合作社，合作社与邮政合作，何元黑皮花生进入邮政游乐网平台销售；与县旅投公司合作，何元辣椒、黑皮花生进入电商平台销售；利用微信销售蜜本南瓜。

二、何元乡电子商务发展条件情况

（一）何元乡基本情况。

1.自然条件。何元乡地处怒江东岸，山势东高西低，山脉多呈南北走向，南北最大纵长16公里，东西最宽12公里，国土面积140.5平方公里，森林覆盖率为28.1%。全乡有耕地面积18945亩，其中：水田8360亩，旱地10585亩，人均耕地1.15亩。由于受地形特征及怒江热气流影响，气候属立体型气候。李为地、大仆寨一带为亚热带，大寨门一带属冷带，其余为温带，转换界线比较明显。年平均气温15℃，最高气温30℃，最低气温仅为3℃。年平均降水量为1040毫米。

2.地理环境。何元乡位于施甸县城西部山区17公里处。地处东经99。20'49"—99。23'18"，北纬24。25'26"—24。38'55"。东与甸阳镇接壤，西和太平镇交界并隔怒江与龙陵县相望，南跟万兴乡和甸阳镇菖蒲塘办事处为邻，北与由旺镇大秧田和仁和镇相邻。

3.人口状况。何元乡辖何元社区村民委员会、莽王村民委员会、石头寨村民委员会、王家庄村民委员会、李为地村民委员会、大仆寨村民委员会、组军门村民委员会、大坡脚村民委员会、大寨门村民委员会9个行政村（社区），54个自然村，民族以汉族为主，少数民族为彝、佤、傈僳、独龙、景颇、布朗、纳西、白族。总户数4091户，总人口16343人，其中农业人口15509人（建档立卡贫困人口5294人），少数民族人口3017人，劳动力10580人，乡村从业人员9595人。

4.资源优势。何元乡境内资源丰富，有许多得天独厚的优势，极具发展潜力：一是由于受怒江低热河谷的影响，具有典型的立体型气候，冬无严寒、夏无酷暑。二是土地资源丰富，肥沃的土壤，丰沛的雨量，亚热带与温带共存的高原立体气候孕育了丰富的物产，农副产品质量上乘，故有“西山晒烟、辣椒之乡”的美誉。三是矿产资源丰富，目前已探明的有汞矿、铁矿，莽王红大理石、五彩石、石灰石等。四是蕴藏丰富的海林檎资源，大寨门村、石头寨村、何元村蕴藏丰富的古生物化石群，吸引中外考古专家多次前往考察，是全国有名的海林檎之乡。五是地热资源丰富，境内娲女神泉谷中有丰富的地热自涌泉眼，具有不同的水质、不同的颜色、不同的医疗价值，胃病、风湿病、皮肤病、黄水疮等疾病的治愈让它闻名遐迩吸引着远方的客人；六是多彩的民族文化、古朴的民族风俗、新奇的怒江风光和滇西抗战遗址等构成了何元乡丰富的旅游资源。

（二）何元乡交通设施及物流建设情况。

何元，距县城17公里，有县乡级交通主干道一条，水泥预制小块铺筑路面，全长34公里，由县城直达娲女温泉，定名施平公路，日均发送客车4班往返，日均客运量232人次，年货运吞吐量3.47万吨，乡村级公路87公里，其中弹石路面37公里，乡村便民小客车5辆，年载客量5.9万人次。距南伞口岸272公里，距瑞丽姐告口岸310公里。全乡有县乡道路5条96公里，其中:水泥硬化道路43公里，未硬化53公里；村组村内道路282条，共387公里，目前已硬化29条，80.8公里。

目前，有物流快递企业6户，全乡快递服务已全覆盖。除中国邮政外，国内知名的中通、申通、韵达、天天等公司均已入驻何元。

（三）施甸县网络基础设施建设情况。

目前，全乡固定电话用户600多户，移动通讯网络3G、4G已经覆盖，3G网络已趋于稳定，4G正在努力建设完善中，据统计，当前共有手机用户2100多户, 4G网络和宽带网络已覆盖9个行政村及40%以上的自然村，宽带接入用户达170户。抓住省五大基础设施网络建设五年大会战的机遇，全乡积极推进互联网相关建设项目。下一步将积极做好何元35千伏变电站及输电线路升级改造工程项目，服务光伏发电项目的实施，建设施甸河四级水电站，估算投资400万元；电网改造架设路线70公里，入户2000户，估算投资3000万元。落实信息化工业化深度融合专项行动计划，建设全光纤网络和到村4G网络，提升带宽和质量，无限扩大群众“互联网生活”空间。

三、项目实施计划

（一）项目选址:项目拟选地址在何元乡何元街临街铺面。

（二）项目建设内容：为积极有效的开展此项工作，将在临街铺面筹建电子商务服务站。建设内容及投资规模如下：

1.通过政府采购完善服务所办公硬件设施配置建设。通过政府采购完善配置办公电脑、办公桌椅、档案柜、打印机、照相机、摄影机、饮水机等一批办公用品，预计投资85500元。

2.乡电子商务服务所房屋装修、装潢建设。按照全市电子商务服务中心（站）统一外围装饰，在铺面外围装饰电子商务服务所统一门头，，包括点灯、窗帘及电线安装预计投资24040元；预计电子商务培训300人次，含电子商务咨询服务，一乡一品策划方案等，预计投资45000元。

3.产品仓储。在乡电子商务服务所成立产品销售点，对何元有名的辣椒、黑皮花生、绿壳鸡蛋、蜜本南瓜等农特产品展示和销售。

以上三项合计，项目总投资154540元。

（三）推进时间表。

1.项目准备阶段。

2017年7月1日至2017年7月24日完成电商工作领导小组的建立、电商发展工作任务的分解方案和专项资金的申报及计划下达工作。

2.项目实施阶段。

2017年7月25日至8月25日组织项目实施。7月30完成设备采购报批手续和设备的采购工作，确保9月初项目投入使用。

3.项目验收阶段。

2017年9月1日组织项目验收，具体任务分解：9月5日至9月10日镇级组织初验，9月10日至9月15日前县级主管部门组织验收，9月15日后由市级主管部门对建设项目检查验收。

四、保障措施

(一)组织保障。何元乡电子商务服务所建设由乡人民政府为责任单位，乡宣传办为主要负责部门，抽调相关工作人员进行项目实施工作；项目实施过程中明确组织领导，明确责任，确保项目的顺利推进；建立电子商务工作制度，研究制定具体扶持政策和发展意见，加强对电子商务发展的促进引导和宏观指导。

(二)经费保障。积极争乡政府每年安排电商产业发展资金1万元，专项用于镇村级电子商务服务站设备购置、宣传、培训和电子商务示范企业创建工作等。积极争取小微企业“两个10万元”项目、“贷免扶补”及创业贷款项目，重点培育电子商务示范企业项目发展和个体点商户发展。

（三）监督保障。严格专款专用，建立规范的资金使用台帐，对项目资金申报、审核、批复、拨付资金和效果实行事前、事中、事后全程监督。对项目实施过程中，严格按项目资金要求报账，强化监管责任，切实提高资金的使用效益。
