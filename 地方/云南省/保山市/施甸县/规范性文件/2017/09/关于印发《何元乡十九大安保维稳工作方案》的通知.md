# 关于印发《何元乡十九大安保维稳工作方案》的通知

各村（社区）党（总）支部，村（社区）委员会,乡直各单位：

经乡党委政府研究，现将《何元乡十九大安保维稳工作方案》印发给你们，请认真贯彻执行。

中共何元乡委员会 何元乡人民政府

2017年9月20日 2017年9月20日

何元乡十九大安保维稳工作方案

为从严从实从细抓好保稳定、护安全、促和谐各项工作的落实，紧紧围绕“五个严防发生、三个绝不发生”的工作目标，进一步突出十九大安保维稳期间矛盾风险排查化解管控工作重点，坚决贯彻落实上级各级党委对关键时期的高标准和严要求，确保全乡社会政治稳定、治安秩序良好，结合何元辖区实际，特制定本方案。

一、工作目标

全面贯彻落实好各级党委政府和各级公安机关关于十九大安保维稳的各项部署要求和工作措施，始终牢牢把握“对党忠诚、服务人民、执法公正、纪律严明”的总要求，紧紧围绕为党的十九大胜利召开创造安全稳定的社会环境为主题，充分认识做好矛盾风险排查化解管控工作的重要意义，牢固树立风险意识、突出工作重点、找准问题难点、坚持研判机制，严格按照“抓早、抓小、抓苗头”和“属地管理”、“谁主管、谁负责”的原则，将各项矛盾纠纷和治安涉稳化解处置在初期，最大限度把问题解决在当地和萌芽状态，确保绝不发生严重影响政治稳定的重大事件、绝不发生大规模群体性事件和集体进京访，绝不发生由矛盾纠纷引发的影响恶劣的刑事犯罪案件和个人极端暴力案件，绝不发生群死群伤的重特大火灾、道路交通事故及其他治安灾害事故，坚决打赢十九大安保维稳这场硬仗。

二、组织领导

何元乡成立十九大安保维稳工作领导小组，负责此次安保工作的组织领导。

组 长：赵 伟 乡党委书记

副组长：段会伟 乡党委副书记、乡长

杨 军 副乡长、派出所所长

成 员：各二级站所、党总支、村（社区）委会负责人

领导小组下设办公室在派出所，由副乡长、派出所所长杨军兼任办公室主任，派出所安排专人负责每月社会矛盾纠纷化解和治安涉稳信息监测的收集、研判和整理上报等工作。各二级站所以及各村委会也要增强忧患意识、责任意识、防控风险、服务发展，破解难题、补齐短板，将各项工作措施细化到个人。

三、工作措施

（一）突出专项工作重点。十九大安保期间，各成员单位要突出社会矛盾纠纷排查的三个重点：一是突出重点部位。对矛盾纠纷多发、频发、易发的场所、村组、行业等部位进行拉网式排查，梳理出突出的社会矛盾问题。二是突出重点对象。突出抓好越级上访、重复上访、群体上访、“泛亚”和“e租宝”两个投资群体等重点对象的摸排工作，有针对性地采取措施。三是突出重点领域。重点排查化解涉军群体、涉众型经济案件、涉法涉诉、环境污染、医患关系、移民搬迁、食品药品安全等领域可能引发治安刑事案件、信访案件、群体性事件的矛盾纠纷，以及可能引发群体性事件的生产经营性、产权性纠纷、社区公共管理纠纷等社会矛盾的排查掌握。

（二）完善风险排查方式。要健全社会矛盾纠纷滚动排查，分级管控制度，针对不安定因素相对集中的领域、行业和群体，重点排查可能影响稳定的苗头性、倾向性问题，做到底数清、情况明。各村委会要充分发挥人熟、地熟、事熟的优势，把工作的触角延伸到村组及居民和农户家中，最大限度地获取社会信息，及时发现纠纷苗头；派出所、坚持日常排查、专项排查、敏感时点排查相结合，将工作的着力点放在影响社会稳定的各种热点纠纷及可能引发群体性事件的矛盾纠纷和苗头隐患上，注意发现群众反应热烈、可能造成上访等重大矛盾纠纷问题，及时发现苗头隐患，收集掌握社会舆情。

（三）强化矛盾纠纷化解。对排查出来的社会矛盾，各成员单位要及时进行化解；对于复杂的矛盾纠纷，各成员单位要采取“一个问题、一名领导、一套班子、一个方案、一抓到底”的办法，努力将可能影响社会稳定的苗头性问题化解在基层、解决在当地、消除在萌芽状态。化解不了的，及时向领导小组办公室汇报，对可能引发越级上访和大规模上访事件的，应当说明情况，并提出源头治理工作的建议。

（四）加强重点人员管控工作。要采取有效措施，把各类重点人员、可能铤而走险的危险分子、尚未改造好的刑满释放和解除劳教人员、多次进京上访滋事人员、肇事肇祸的精神病人等纳入管理视线，落实“包保”责任，对上访重点人员严格落实“一对一”、“人盯人”等的稳控。由村治保会主任、专职副主任跟踪掌握其思想动态及行踪，实行日报告制度。若有反常举动或离开辖区，及时上报乡领导小组办公室。做到领导到位、组织到位、稳控到位，情况明、行踪清，严密防范、加强教育、管理和控制。

（五）肇事肇祸精神病管控。对肇事肇祸精神病人，符合强制治疗条件的，一律送指定医院强制治疗；对于有肇事肇祸既往史、有可能造成危害的，督促其监护人、近亲属或单位、社区、村委会将其送医院治疗，对于送医院治疗有现实困难的，协商民政等部门提供帮助，确保入院治疗；对生活无着、流浪街头的精神病人，引导护送到民政部门救助站妥善处理，对未住院的精神病人，派出所与其监护人或近亲属签订责任书，责令其严加看管；没有监护人或近亲属的督促其所在单位、社区、村委会履行监管职责。

（六）加强道路交通安全管理工作。打好四场交通安全整治攻坚战：一是隐患歼灭战。通过开展交通安全整治隐患歼灭战，强力推进运输企业和重点车辆、驾驶人隐患“清零”，力争实现“六类”重点车（“营转非”大客车、大型公路客车、大型旅游客车、危险货物运输车、校车、重型货车）检验率、报废率、违法处理率达100%；重点驾驶人（A证、B证）审验率、换证率达100%；“两客一危”动态监控在线率、使用率，安全带齐全率、佩戴率进一步提高；货车违法超限超载行为整治进一步强化。二是路面防控战。把路面作为主战场，以“四车”（“两客一危”和重型货车）为发力点，充分发挥“四站”（交警执法站、公路超限检测站、乡镇交安办、农村劝导站）作用，集中查处四类交通违法行为（超速、超员、超载、疲劳驾驶），通过持续不断地开展严管统一集中行动，加大并保持对重点车辆严重交通违法行为的管控力度，实现路面通行秩序明显好转、严重交通违法行为明显下降。三是宣传攻势战。充分发挥宣传教育在事故预防工作中的基础性作用，组织好“四大宣传行动”，加强宣传教育和警示曝光，确保完成各项指标任务，坚决打赢交通安全宣传攻势战，为党的十九大胜利召开创造和谐有序、安全畅通的道路交通环境。四是共治合成战。严格按照于“四场攻坚战”的具体要求，深入扎实推进“三个不发生”创建活动的深入开展，坚持以问题为导向，整合部门的力量、行业的力量、信用的力量协同共治，补齐工作短板，努力形成齐抓共管共治合力，打好共治合成攻坚战，做到“三个集中”，集中通报运输安全状况的“完成率”达到100%；符合公开公示条件的严重交通违法行为公示率达到100%；向交通运输部门通报公路安全隐患情况的“完成率”达到100%。

四、工作要求

（一）落实重点人员管控。对排查出来的可能上访滋事、铤而走险和扬言行凶报复的重点人员，逐一查明情况、掌握动态，及时采集信息、入库上网，并在分析研判、评估风险的基础上，依靠单位、社区和基层组织，采取在党委政府统一领导下成立稳控小组、落实包保责任、重大节庆活动期间盯牢死守等措施，分级分类进行管控，有效解决突出问题，逐渐减少到省进京非访人次，缓解社会治安压力，维护正常工作秩序和社会稳定。

（二）健全研判预警机制。对排查监测出来的社会矛盾和治安维稳信息要逐一登记造册，按照诱因、时间、地点、性质、规模大小、人员构成、事态发展等要素逐一登记建档，。对排查监测发现的可能影响社会稳定、可能引发重大群体性事件的重大矛盾纠纷和治安维稳信息，要迅速向上级相关报告预警；及时部署开展相关稳控化解工作。

（三）加强应急处突准备。切实加强应急处突准备，不断细化应急处置预案，规范应急处置程序，建立健全跨区域协作机制，加强专门力量建设、通信装备保障和实战磨合演练，确保在重大紧急情况发生时能够做到快速响应、妥善应对、高效处置。

（四）严格实行责任倒查。各成员单位要结合单地实际，以更加坚定的决心和态度、采取超常规的措施和手段，一级抓一级，层层抓落实。十九大安保期间，对未实现“确保绝不发生严重影响政治稳定的重大事件、绝不发生大规模群体性事件和集体进京访，绝不发生由矛盾纠纷引发的影响恶劣的刑事犯罪案件和个人极端暴力案件”工作目标的，将严肃开展倒查追责工作，对因责任不落实、工作不到位和失职渎职导致发生重大案事件的，乡党委政府以及上级部门将严格责任追究、依纪依法严肃处理。
