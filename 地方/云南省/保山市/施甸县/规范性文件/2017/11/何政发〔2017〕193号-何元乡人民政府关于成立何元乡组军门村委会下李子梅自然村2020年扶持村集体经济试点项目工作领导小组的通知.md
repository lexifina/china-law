# 何元乡人民政府关于成立何元乡组军门村委会下李子梅自然村2020年扶持村集体经济试点项目工作领导小组的通知

何政发[2017]193号

各村（社区）委会,乡各单位：

为确保我乡组军门村委会下李子梅自然村2020年扶持村集体经济试点项目的顺利实施，确保工程质量合格，全面完成何元乡组军门村委会下李子梅自然村2020年扶持村集体经济试点项目的顺利通过验收，为项目区经济社会发展长期发挥效益，经乡人民政府研究，决定成立何元乡组军门村委会下李子梅自然村2020年扶持村集体经济试点项目领导小组。现将组成人员通知如下：

组 长：段会伟 乡人民政府乡长

副组长：徐晓强 武装部部长

成 员: 蒋必儒 纪委书记

张品能 农经站站长

施 勇 财政所所长

杨钟英 项目办主任

高关云 国土和村镇规划建设服务中心主任

段学强 国土所所长

段达柳 组军门村党总支书记

领导小组下设办公室在乡项目办，由徐晓强部长兼任办公室主任，负责处理日常工作。领导小组和涉及村组相关成员负责监督项目工程质量，并做好协调服务工作，确保项目顺利完工。

何元乡人民政府

2017年11月25日
