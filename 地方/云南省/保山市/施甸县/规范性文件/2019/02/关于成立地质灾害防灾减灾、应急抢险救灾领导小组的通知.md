# 关于成立地质灾害防灾减灾、应急抢险救灾领导小组的通知

各村委会、乡直各单位：

为切实搞好我乡2019年度地质灾害的防控监测工作，最大限度地维护和保障人民群众生命和财产安全，根据县地质灾害防灾减工作的要求，经乡人民政府研究决定成立木老元布朗族彝族乡地质灾害防治领导小组，现将组成人员通知如下：

组 长：蒋军礼 乡人民政府乡长

副组长：王剑涛 乡人民政府副乡长

姜云港 木老元国土资源所所长

成员：李金强 木老元派出所所长兼副乡长

杨有志 乡民政办负责人

杨佳丽 乡宣传干事

刘 义 乡安监站负责人

杨鑫媛 木老元财政所负责人

杨银华 木老元卫生院院长

杨忠团 乡文化广电站负责人

李有贵 木老元村委会主任

阿福友 哈寨村委会支部书记

何玉银 龙潭村委会支部书记、主任

张文权 大地村委会支部书记、主任

领导小组下设办公室在木老元国土资源所，办公室主任由姜云港担任，负责处理日常事务。
