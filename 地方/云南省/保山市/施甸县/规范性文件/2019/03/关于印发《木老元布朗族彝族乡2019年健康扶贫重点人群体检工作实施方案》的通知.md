# 关于印发《木老元布朗族彝族乡2019年健康扶贫重点人群体检工作实施方案》的通知

各村委会、乡卫生院、乡社保中心、乡派出所、乡综治办、乡民政办：

为全面抓好木老元乡2019年健康扶贫重点人群体检工作，按照政策要求，将相关事项通知如下：

一、组织领导

为开展好2019年健康扶贫重点人群体检工作，成立木老元乡2019年健康扶贫重点人群体检工作领导小组，组成人员名单如下：

组 长：李光辉 人大副主席

副组长：杨银华 卫生院院长

成 员：朱有力 龙潭村主任

李有贵 木老元社区支书、主任

阿福友 哈寨村支书、主任

饶建华 大地村主任

尹 旭 卫生院副院长

李永昌 卫生院公卫办主任

杨孝悦 卫生院办公室主任

领导小组下设办公室在卫生院，由李永昌兼任办公室主任，具体负责日常工作。

二、体检对象

（一）建档立卡户家庭0-6岁儿童除外的其他所有人群（注：0-6岁儿童已经开展着常规体检）。

（二）65岁以上老年人、糖尿病患者、严重精神障碍患者以及计划生育三查服务对象。

三、体检率

（一）建档立卡户家庭0-6岁儿童除外的其他所有人群，是施甸县卫生和计划生育局对木老元及摆榔的特殊要求，应做尽做，没有明确规定体检率。

（二）65岁以上老年人、糖尿病患者、严重精神障碍患者为健康扶贫及国家基本公共卫生服务均等化项目要求，65岁以上老年人体检率要求在70%以上，糖尿病患者体检率要求100%，精神病患者体检率要求在75%以上。

四、体检通知相关事项

（一）建档立卡户家庭0-6岁儿童除外的其他所有人群，由村组干部具体负责通知到组到户。

（二）65岁以上老年人、糖尿病患者、严重精神障碍患者由各村乡村医生点对点通知到服务对象；

以上所有体检对象携带户口簿及家庭医生签约服务手册接受体检，目的是便于如实登记个人信息及做好2019年的家庭医生签约续签及服务（注：服务手册已放于农户家中的脱贫攻坚的户档案袋里）。

五、体检时限及具体体检时间、地点

2019年3月11日至2019年6月30日，具体体检时间及地点由卫生室与村委会汇报协商后确定，根据实际情况灵活通知。

六、体检具体业务

（一）由卫生院成立专业体检组到指定地点开展，卫生室配合、村组干部协助宣传。

（二）为了便于体检结果信息的系统录入及反馈，逐户排序登记造册、体检。

（三）体检结果由专业人员做好评估结论形成反馈表及清单后，反馈到各村，由乡村医生录入国家基本公共卫生服务系统后，反馈到体检对象手中，与家庭医生签约服务手册一起装入脱贫攻坚家庭档案袋内。

以上工作由体检组工作人员、村组干部及乡村医生按照职责分工认真抓好落实，体检组伙食由专人与各村干部联系后，灵活安排，工作结束后按20元/人/顿的标准补助给村上，其它未尽事宜共同协商解决。

木老元布朗族彝族乡人民政府
