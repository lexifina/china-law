# 施甸县产业扶贫指挥部办公室关于下达2019年第一批产业扶贫项目和投资计划的通知

太平镇、甸阳镇、万兴乡人民政府：

根据《施甸县统筹整合使用财政涉农资金工作领导小组办公室关于下达2019年产业发展及人居环境项目资金的通知》（施财整合〔2019〕21号），县产业扶贫指挥部办公室对太平镇、甸阳镇、万兴乡人民政府编报的项目实施方案进行了审查，原则同意实施方案，现将第一批产业扶贫项目和投资计划下达给你单位（具体项目和投资计划情况详见附件），请严格按项目和投资计划抓紧组织实施。

附件：2019年第一批产业扶贫项目和投资计划表

施甸县产业扶贫指挥部办公室

（施甸县农业农村局代章）
