# 施甸县产业扶贫指挥部办公室关于下达2019年第三批壮大村集体经济项目和投资计划的通知

施甸县产业扶贫指挥部办公室关于下达

2019年第三批壮大村集体经济项目

和投资计划的通知

酒房乡、万兴乡、太平镇、何元乡、甸阳镇人民政府：

根据《施甸县统筹整合使用财政涉农资金工作领导小组办公室关于下达2019年第三批壮大村集体经济项目资金的通知》（施财整合〔2019〕56号），县产业扶贫指挥部办公室对酒房乡、万兴乡、太平镇、何元乡、、甸阳镇人民政府编报的项目实施方案进行了审查，原则同意实施方案，现将第三批壮大村集体经济项目和投资计划下达给你单位（具体项目和投资计划情况详见附件），请严格按项目和投资计划抓紧组织实施。

附件：2019年第三批产业扶贫壮大村集体经济项目和投资计划表

施甸县产业扶贫指挥部办公室
