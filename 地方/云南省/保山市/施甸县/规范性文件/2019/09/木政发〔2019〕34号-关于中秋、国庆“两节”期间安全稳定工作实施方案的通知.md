# 关于中秋、国庆“两节”期间安全稳定工作实施方案的通知

根据施甸县委、县政府有关会议精神，为保证“两节”期间的安全稳定，结合木老元乡实际情况，特制定本方案。

一、指导思想

本着责任重于泰山，百姓利益高于一切的思想，贯彻落实党的十九大精神和习近平总书记系列重要讲话精神，切实维护群众利益，积极打造和谐稳定的社会环境。

二、工作目标

为确保“两节”期间的安全稳定工作，以创建“平安木老元”为目标，进一步加大安全监管、森林防火、社会治安、信访调处、社区矫正和相关重点人群工作力度，有效遏制重特大安全和各类事故多发生，实现信访秩序明显好转，确保社会秩序。

三、工作措施

(一)提高认识，加强领导

成立领导小组由乡长蒋军礼任组长，派出所、司法所、民政办、综治办、卫生防疫、中小学校负责人和各村党总支部书记为组员，全力做好“两节”期间安全稳定工作，克服与己无关思想，全民参与求实效，预防各种不安定因素，稳定社会秩序。

（二）建立严密的治安防控体系

“两节”期间，全乡以村为单位，宣传、司法、派出所、综治、民政等部门选派得力人员和各村治保组成联合防控小组，在抓好村民法制宣传教育踪监督；通过大走访摸清问题实质，了解上访人心态对症下药；开展大调处缓解矛盾杜绝越级上访；采取有力措施解决问题化解矛盾，对应该解决的要尽快解决，暂时解决不了的要做出计划逐步解决以化解矛盾为目的；依法规范，对影响公共安全和正常秩序的要依法处理。

（三）做好扶贫济困献爱心

保证最低生活保障及时发放；发动全体干部和社会各界捐款、捐物送到最需要群众手中，让困难群众感受到党和政府的关怀，坚决杜绝饿伤、冻伤事件发生；积极开展扶贫活动，重点扶贫对象是老党员、军烈属、困难户、五保户，通过党员“一帮一”、干部“联系户”的方式深入基层、深入农户对困难户给予特殊救济，帮助群众解决一些实际问题。

（四）全面落实值班制度

各单位、各部门认真落实好24小时值班制度和领导带班制度。

四、具体要求

1.从讲政治维护稳定高度认识到安全稳定的重要性，切实加强领导落实“一把手”制度。

2.认真排查不稳定因素掌握第一手材料。

3.及时化解消除隐患。

4.严密监控依法规范。

5.落实责任。把“两节”期间维护社会稳定工作落实到具体领导还工作人员，把每项具体工作责任履行到位，一旦出现问题责任追究到人。

木老元布朗族彝族乡人民政府
