# 关于2019年第三批涉农统筹整合资金村内道路、未达到“遮风避雨”、改水改厕垃圾处理项目实施方案的批复

各乡（镇）人民政府：

你们上报的《2019年第三批涉农统筹整合资金村内道路、未达到“遮风避雨”、改水改厕垃圾处理项目实施方案》，县农村人居环境提升指挥部组织相关部门的领导和专业技术人员组成的项目审查组，对2019年第三批涉农统筹整合资金村内道路、未达到“避风遮雨”、改水改厕垃圾处理项目实施方案进行审查，审查组原则同意实施方案通过审查。请你们加快项目的组织实施，按时按质按量完成建设任务，并通过验收。
