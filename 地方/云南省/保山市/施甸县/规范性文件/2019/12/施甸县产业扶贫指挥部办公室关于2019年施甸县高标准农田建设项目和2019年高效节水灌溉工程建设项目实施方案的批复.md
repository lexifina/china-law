# 施甸县产业扶贫指挥部办公室关于2019年施甸县高标准农田建设项目和2019年高效节水灌溉工程建设项目实施方案的批复

施甸县农业农村局：

根据《保山市农业农村局关于下达2019年农田建设任务的通知》保农通〔2019〕65号精神，施甸县产业扶贫指挥部办公室对你们上报的《施甸县2019年高标准农田建设项目实施方案》和《施甸县2019年高效节水灌溉工程建设项目实施方案》进行了专家评审，现批复如下：

一、原则同意你们上报的实施方案

二、绩效目标：通过项目实施，有效改善项目区农田基础设施条件，提升耕地质量，提高农业综合生产能力。亩均增加产能

5％左右;田间道路通达率90％;耕地质量等级平均提升0.5个等次。

三、建设内容及投资概算(详见附件)。

四、项目主管和组织实施单位:项目建设工作实行目标、任务、资金、责任四到县农业农村局，县农业农村局对工程总负责，县农业农村局和实施项目乡镇人民政府为项目配合单位，按照实施方案确定的分工组织实施。

五、建设年限2019-2020年。

六、接文后，请严格按批复的实施方案，抓紧工程开工建设。 严格遵守项目建设程序，不得随意变更和调整项目建设性质、建

设内容、建设标准和建设地点，如确需进行调整，必须按程序报

批。工程建设过程中，请督促建设单位认真执行国家基本建设“四

制”，加强项目建设和资金管理，严格控制工程质量、工期，确保工程按时按质按量完成，发挥效益。工程实施结東，请及时整编资料上报市级组织验收。

附件：1、施甸县2019年高标准农田建设项目实施方案批复表

2、施甸县2019年高效节水灌溉工程建设项目实施方方案批复表
