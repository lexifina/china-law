# 施甸县产业扶贫指挥部办公室关于下达2019年度新型农业经营主体奖补项目和投资计划的通知

施甸县产业扶贫指挥部办公室关于下达

2019年度新型农业经营主体奖补

项目和投资计划的通知

县农业农村局、县供销合作社联合社：

根据《施甸县统筹整合使用财政涉农资金工作领导小组办公室关于下达 2019 年度新型农业经营主体项目补助资金的通知》（施财整合〔2019〕79号），县产业扶贫指挥部办公室对县农业农村局、县供销合作社联合社编报的项目实施方案进行了审查，原则同意实施方案，现将2019年度新型农业经营主体奖补项目和投资计划下达给你单位（具体项目和投资计划情况详见附件），请严格按项目和投资计划抓紧组织实施。

附件：2019年度新型农业经营主体奖补项目和投资计划表

施甸县产业扶贫指挥部办公室
