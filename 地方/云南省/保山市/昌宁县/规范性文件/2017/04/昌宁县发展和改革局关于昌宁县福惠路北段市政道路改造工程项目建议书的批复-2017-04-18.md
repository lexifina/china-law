# 昌宁县发展和改革局关于昌宁县福惠路北段市政道路改造工程项目建议书的批复

昌宁县住房和城乡建设局：

你单位《关于上报昌宁县福惠路北段市政道路改造工程项目建议书的请示》（昌住建发〔2017〕46号）收悉。经研究，同意昌宁县福惠路北段市政道路改造工程建设。现将有关事项批复如下：

一、项目名称：昌宁县福惠路北段市政道路改造工程

二、项目法人：昌宁县住房和城乡建设局；法人代表：夏润南

三、建设性质：改扩建

四、项目建设地点：昌宁县田园镇

五、建设年限：2017年3月—2017年5月

六、建设规模及内容：改扩建福惠路北段道路人行道长499米，宽7米；配套完善相关排水、弱电、消防等附属设施。

七、项目总投资及资金来源：项目估算总投资198.8万元，资金来源为自筹。

接文后，请抓紧做好规划设计、预算、资金筹措等前期准备工作。待具备开工条件后，再申请列入年度基建计划实施，未经批准，不得擅自开工建设。

昌宁县发展和改革局

2017年3月8日
