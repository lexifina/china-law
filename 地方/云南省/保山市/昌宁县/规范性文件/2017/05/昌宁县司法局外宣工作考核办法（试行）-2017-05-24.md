# 昌宁县司法局外宣工作考核办法（试行）

为充分调动全局广大干部职工参与新闻报道、信息报送和理论调研工作的积极性，鼓励多写稿、写好稿、多投稿，进一步加强外宣工作，弘扬主旋律，唱响正能量，全方位推介我县司法行政工作开展情况及所取得的成绩、经验等，提高全县司法行政工作的知名度和影响力，特制定本办法。

一、指导思想

以马列主义、毛泽东思想、邓小平理论、“三个代表”重要思想，党的十八大和十八届三中、四中、五中、六中全会精神和习近平总书记系列重要讲话精神为指导，深入学习实践科学发展观，全面贯彻落实中央和省、市、县各级工作会议精神，围绕县委、县政府中心工作，立足广大人民群众法治需求，深入推进开展法治宣传教育、社会矛盾排查化解、社会管理创新和公正廉洁执法等重点工作，切实加大信息、简报、新闻稿件及理论调研文章的采报力度，及时、客观、准确、全面地反映全县司法行政工作的新思路、新举措、新成绩、新经验，为实施依法治县营造良好的舆论氛围。

二、基本原则

（一）坚持实事求是原则。按照采写新闻真实性的要求，对外发表的司法行政工作新闻报道必须坚持实事求是，力求报道准确无误，避免失实和差错。

（二）坚持正面宣传原则。牢牢把握正确的宣传舆论导向，弘扬社会主旋律，发表的新闻报道必须做到正面宣传、扬名鼓劲，坚决杜绝造成负面影响。

（三）坚持服务大局原则。对外宣传报道必须紧紧围绕强化司法行政工作、实施依法治县、维护和谐稳定和推进县域经济跨越发展的大局。

（四）坚持审稿报送原则。一般信息，各股室、处所、中心的信息员或工作人员采写的稿件，由对应负责人初审签字，报局政治处审核通过后发表（报送）；凡事关全县改革发展稳定的重点工作、重大事项的外宣稿件，需上报到县级以上新闻媒体时，由对应负责人初审签字，报分管领导审核把关，经主要领导审核通过后方可向外报送。所有审稿要复印进行规范存档。

（五）坚持文责自负的原则。凡是未经审核由个人私自向外报送的稿件，一旦出现失实、差错等问题或造成负面影响的，将严肃追究相关领导和个人责任。

三、奖励对象

局机关各股室、处所、中心和各基层司法所广大干部职工或工作人员。县直单位和13乡镇积极帮助宣传司法行政工作，踊跃写稿投稿的干部职工，本人能够提供真实依据，经查属实的，参照本办法进行奖励。

四、奖励范围

凡在中央、国家级和省、市、县级公开发行的主流党报党刊、广播电视台和信息、网站以及司法行政部门主办的报刊杂志、网站上发（播）的正面宣传昌宁司法行政工作、开展情况及所取得的成绩、经验等新闻作品（含新闻图片），均予以奖励。新闻作品指反映我县司法行政工作开展情况及所取得成绩、经验的人或事的消息、通讯、特写、调查报告等。

（二）奖励规定

1.结合昌宁司法行政系统内宣、外宣工作需要，对相关单位、群体及个人，按《昌宁县司法局2017年基层两所绩效管理考核办法》实行目标管理，完成任务，按上述标准兑现奖励；完不成任务，不予奖励。被不同级别媒体采编的同一条（篇）稿件只统计完成任务数1次，不重复计算。

2.同一条新闻作品分别在各级各类报刊、杂志、电视台、广播电台、网站媒体上发表或被采编（播）的稿件不重复统计，只以最高奖励标准的1条进行奖励。

3.署名2人及以上的新闻、信息稿件，任务数和奖励资金只按1条（篇）计，由署名人协商认定与分配。

4.同一条新闻作品是指分别在各级各类报刊、杂志、电视台、广播电台、网站等媒体上发表的，即使是标题不同，只要内容相同均视为1条（篇）。

5.对失实或造成不良影响的新闻报道不计任务数，不予奖励。

六、工作要求

（一）加强领导，强化责任。考核工作由局政治处负责组织实施。各股室、处所、中心和基层所要高度重视，切实把新闻报道、信息报送作为日常工作中的重要内容，加强领导，不折不扣地完成工作任务，确保新闻报道、信息报送任务圆满完成。

（二）明确专人，及时报送。各股室、处所、中心和基层所要根据自身的职能职责，按信息考核的任务数，明确相关人员负责收集、撰写、上报。除保密信息外，稿件请报送到昌宁司法宣传QQ群123127694。保密信息请按保密规定报送，联系人：朱婕，电话：7130117。

（三）强化监督，严格奖惩。严格按照本考核办法的奖惩规定进行奖惩，对各股室、处所、中心和基层所工作主动性强，新闻报道、信息报送及时、质高且完成任务的给予奖励；对认识不到位，工作不力，新闻报道、信息报送不及时，完不成任务的，县局将给予通报批评。
