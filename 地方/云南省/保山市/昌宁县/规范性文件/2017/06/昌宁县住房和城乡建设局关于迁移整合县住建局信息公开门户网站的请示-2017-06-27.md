# 昌宁县住房和城乡建设局关于迁移整合县住建局信息公开门户网站的请示

县政府办：

昌宁县住房和城乡建设局门户网站于2012年开通，网站共设部门信息公开、机构概况、政策法规等专栏。自网站开通以来，在政策法规查阅、部门工作宣传、住建信息公开等方面发挥了一定作用。但也存在着资源整合不足、部门资源条块化、信息更新较慢等问题。根据《国务院办公厅关于印发政府网站发展指引的通知》（国办发〔2017〕47号）和《保山市人民政府办公室关于加强政府网站管理工作的通知》（保政办函〔2017〕73号）文件和县级专题会议要求，为进一步推进政务信息资源共建共享，积极深化政务公开、网上办事和政民互动工作，全面提升昌宁县住房和城乡建设局网站管理水平，恳请县人民政府网管中心将县住建局门户网站迁移整合管理。

当否，请批示。

昌宁县住房和城乡建设局
