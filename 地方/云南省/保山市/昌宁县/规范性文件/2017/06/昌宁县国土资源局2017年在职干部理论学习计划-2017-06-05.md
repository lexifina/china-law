# 昌宁县国土资源局2017年在职干部理论学习计划

根据县委和市国土资源局党组要求，结合我局实际，现就2017年在职干部理论学习计划安排如下：

一、总体要求

全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，认真学习马克思列宁主义、毛泽东思想和中国特色社会主义理论体系，深入学习贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，认真学习党章党规、党史国史、国情省情市情，坚持读原著、学原文、悟原理，坚持系统学、深入学、跟进学，坚持学而信、学而思、学而行，着力提高全县国土资源系统在职干部马克思主义思想觉悟和理论水平，掌握和运用马克思主义立场、观点、方法，增强中国特色社会主义道路自信、理论自信、制度自信、文化自信，牢固树立“四个意识”特别是核心意识、看齐意识，更好地用党的理论创新成果武装头脑、指导实践、推动工作。

二、主要内容

今年在职干部理论学习主要安排九个专题，各分局，机关各股（室）、中心要结合实际丰富学习内容，确保理论学习的针对性和实效性。

第一专题：深入学习贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略

习近平总书记系列重要讲话，以一系列富有创见的新思想新观点新要求，丰富和发展了党的科学理论，是21世纪马克思主义、当代中国马克思主义最现实的体现。要把学习贯彻习近平总书记系列重要讲话作为首要政治任务，以《习近平谈治国理政》《习近平总书记系列重要讲话读本》（修订本）《学习讲话精神系列问答》为基本教材，系统掌握蕴含其中的治国理政新理念新思想新战略，深入领会贯穿其中的坚定信仰追求、历史担当精神、真挚为民情怀、务实思想作风，深入领会蕴藏其中的思想理论脉络和历史文化源流，掌握立场观点方法，不断增强对讲话精神的政治认同、思想认同、理论认同。要把系列重要讲话作为理论学习的重中之重，坚持反复学，及时跟进学，真正学深悟透，知其然更知其所以然，并具体落实到思想政治水平的提高上，落实到优良作风的铸就上，落实到工作能力的增强上，自觉在思想上政治上行动上同以习近平同志为核心的党中央保持高度一致。

第二专题：深入学习党的十八届六中全会精神

党的十八届六中全会专题研究部署全面从严治党，开启了党的建设新征程。要以《关于新形势下党内政治生活的若干准则》和《中国共产党党内监督条例》为基本教材，重点学习《准则》关于加强和规范党内政治生活的方向目标、原则立场、任务举措，着力营造风清气正的政治生态；学习领会《条例》关于加强党内监督的指导思想、基本原则、内容范畴、方法途径等重要问题。学习贯彻十八届六中全会精神必须同学习贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略结合起来，深刻领会加强思想教育是严肃党内政治生活、净化党内政治生态的首要任务；深刻领会严明政治纪律和政治规矩是严肃党内政治生活、净化党内政治生态的关键；深刻领会坚持正确选人用人导向是严肃党内政治生活、净化党内政治生态的组织保证；深刻领会党的组织生活、开展批评和自我批评是严肃党内政治生活、净化党内政治生态的重要载体和手段；深刻领会加强制度建设是严肃党内政治生活、净化党内政治生态的根本保障，增强积极开展监督、主动接受监督的自觉性，推动党的十八届六中全会精神落到实处。

第三专题：深入学习中国共产党云南省第十次代表大会精神

云南省第十次党代会，是在全省上下认真学习贯彻党的十八届六中全会精神重要时刻、决战脱贫攻坚决胜全面小康关键阶段召开的一次十分重要的会议。学习贯彻省第十次党代会精神，要认认真真、原原本本学习陈豪同志所作的报告，深刻认识党代会主题充分体现了党的十八届六中全会精神，体现了坚决服从以习近平同志为核心的党中央领导，向以习近平同志为核心的党中央看齐、向党的理论和路线方针政策看齐、向党中央决策部署看齐的根本政治要求，回应了全省各族人民对全面建成小康社会的强烈期待；准确把握过去五年取得的新成就；准确把握今后五年全面脱贫全面小康目标顺利实现、民族团结进步示范区建设扎实推进、生态文明排头兵建设成效显著、面向南亚东南亚辐射中心建设步伐加快、全面从严治党落到实处五大奋斗目标；深刻认识“九个必须”既是过去五年发展的经验总结，也是今后全省经济社会发展的总体要求、指导原则；准确把握今后五年全省经济建设、政治建设、文化建设、社会建设、生态文明建设的重大部署；准确把握全面从严治党各项任务。要紧密结合实际，学以致用，推动党代会确定的各项任务落到实处。

第四专题：深入学习市第四次党代会和县第十三次党代会精神

中国共产党保山市第四次代表大会是在我市决战全面建成小康社会，决胜脱贫攻坚，全面实施“十三五”规划，开启保山跨越奋进新征程的关键时期召开的一次十分重要的会议。学习贯彻市第四次党代会精神，重点要学习赵德光同志代表三届市委所作的工作报告。深刻认识大会确定的坚持开创性、强化操作性，为实现保山跨越发展宏伟目标而努力奋斗的主题，是市委准确把握新常态下保山阶段性特征和独特优势，把上级精神和保山实际紧密结合作出的重大抉择；准确把握市第三次党代会以来所取得的显著成绩；深刻认识“四个始终坚持”的经验总结是我市攻坚克难、赶超跨越的重要法宝，在今后的发展中必须坚持不懈、一以贯之；准确把握未来五年工作的指导思想、奋斗目标和必须坚持的原则；准确把握未来五年发展的主要任务和重大举措。要把学习贯彻党代会精神与学习《论实际》《论方法》《论创新》《论跨越》《谈比较》结合起来，与推进“三个万亩”生态廊道、“园中园”、“十个万亩”规模农业、“轻纺、信息产业园”等重大项目建设结合起来，以更加有力的措施、更为务实的作风，落实好党代会各项决策部署。

中国共产党昌宁县第十三次代表大会是在我县经济社会跨越发展关键时期，决战脱贫攻坚，全面建成小康社会决胜阶段召开的一次十分重要的会议。学习贯彻县第十三次党代会精神，重点要学习苏格非同志代表十二届县委所做的工作报告。深刻认识大会确定的同心协力，共筑辉煌，为全面建成小康社会而努力奋斗的主题，是县委紧密联系国情、省情、市情，根据昌宁经济社会跨越发展的实际所做出的重大安排部署；准确把握县第十三次党代会以来所取得的显著成绩；准确把握未来五年工作的指导思想、奋斗目标和必须坚持的原则；准确把握未来五年发展的主要任务和重大举措，特别是准确把握建设“云南生物资源产业中心、最宜人居山水田园城市”的目标，要把学习贯彻党代会精神与持续夯实“四大基础”、加快推进“四化建设”、着力建设“五个昌宁”结合起来，与深入实施“八大工程”结合起来，主动作为、敢于担当，将党代会确定的各项任务扎扎实实落到实处。

第五专题：深入学习中央和省、市、县重要会议精神

认真学习中央经济工作会议、农村工作会议、全国两会精神，认真学习省委十届二次全会、省市两会精神，认真学习县委十三届二次全会、县两会等重要会议精神，明确中央、省、市、县各级党委政府对今年经济工作、农村工作的指导思想、总体要求、大政方针和主要任务。深刻认识环境保护对昌宁未来发展的重要意义，树立绿水青山就是金山银山的强烈意识，把环境保护和生态文明建设摆在理论学习中更加突出的位置，切实让绿色发展理念植根于广大干部的头脑中。深刻理解经济发展新常态的科学内涵、趋势变化和重要特征，深入学习以新发展理念为指导、以供给侧结构性改革为主线，贯彻稳中求进的工作总基调。深刻理解“三去一降一补”、振兴实体经济、创新驱动发展、生态文明建设、精准扶贫脱贫、保障和改善民生等方面政策措施。自觉坚持以经济建设为中心，自觉坚持发展是硬道理的战略思想，切实把中央、省市县各级党委的决策部署学习好、落实好。

第六专题：深入学习稳中求进工作总基调

习近平总书记在中央经济工作会议上对稳中求进作出深刻阐释，强调稳中求进工作总基调是治国理政的重要原则，也是做好经济工作的方法论。强调迎接党的十九大召开，必须保持经济社会大局稳定，稳是主基调、稳是大局，在稳的前提下在关键领域有所进取，在把握好度的前提下奋发有为。学习稳中求进，要把握好“稳”与“进”的辩证关系，深刻理解“稳”字当头，贵在有“进”。要深刻认识贯彻稳中求进工作总基调的特殊重要意义，深刻认识稳中求进不仅是经济工作的重要原则，也是对全局工作、对各个领域工作的重大要求。要深入学习稳中求进工作总基调的科学内涵和实践要求，深刻认识以新发展理念引领经济发展新常态，深刻认识我国经济所处的方位和发生的积极变化，深刻认识推进供给侧结构性改革的主攻方向和根本途径。

第七专题：深入学习协调推进“四个全面”战略布局和创新、协调、绿色、开放、共享五大发展理念

党的十八大以来，以习近平同志为核心的党中央从坚持和发展中国特色社会主义战略全局出发，提出并形成了协调推进全面建成小康社会、全面深化改革、全面依法治国、全面从严治党的战略布局，特别是在十八届五中全会确立了创新、协调、绿色、开放、共享的发展理念，是“十三五”乃至更长时期我国发展思路、发展方向、发展着力点的集中体现。学习协调推进“四个全面”战略布局和五大发展理念，要以党的十八大和十八届三中、四中、五中、六中全会精神为基本遵循，深入领会协调推进“四个全面”战略布局是实现“两个一百年”奋斗目标、实现中华民族伟大复兴中国梦的理论指导和实践指南；深入领会“四个全面”战略布局是事关坚持和发展中国特色社会主义大局的一个总战略、总布局，在党的一系列治国理政决策、部署中，发挥统揽的作用、引领的作用、主导的作用，是一个完整、系统、全面的战略体系和行动纲领；深入领会创新发展就是把创新摆在国家发展全局的核心位置，创新发展对协调发展、绿色发展、开放发展、共享发展具有很强的推动作用，着力解决发展动力问题；深入领会协调发展就是实现辩证发展、系统发展、整体发展，协调发展对推进绿色发展和共享发展具有显著作用，着力解决发展不平衡问题；深入领会绿色发展就是在中国发起一次生态革命，绿色发展对提高人民生活质量，为共享发展提供质量保证，着重解决人与自然和谐问题；深入领会开放就是深度融入世界经济，积极参与全球治理，开放发展使发展更加注重创新，更加重视生态文明的影响，有利于实现共享发展，着力解决发展内外联动问题；深入领会共享就是增进人民福祉，增强人民获得感，共享发展对其他四种发展提供出发点和落脚点，着力解决社会公平正义问题。学习协调推进“四个全面”战略布局和五大发展理念要相互贯通、相互促进，将两者之间的内在联系学深悟透。

第八专题：深入学习“四个自信”，切实推进昌宁“五个文化发展”

在推进治国理政进程中，习近平总书记鲜明提出文化自信，并与道路自信、理论自信、制度自信一起，并列为中国特色社会主义的“四个自信”，强调文化自信是更基础、更广泛、更深厚的自信，是更基本、更深层、更持久的力量，事关国运兴衰、事关文化安全、事关民族精神独立性的大问题。要加强“四个自信”特别是文化自信的学习，深刻理解文化自信是对中华优秀传统文化、革命文化、社会主义先进文化的自信。深刻领会文化自信是一个民族、一个国家、一个政党对自身文化价值的充分肯定和积极践行，并对其文化的生命力持有的坚定信心。深刻领会坚持中国特色社会主义道路自信、理论自信、制度自信，说到底是要坚持文化自信，也是协调推进“四个全面”战略布局的精神保证。深刻领会文化在综合国力竞争中的地位和作用，文化自信是实现中华民族伟大复兴中国梦的内源动力。进一步挖掘自身文化资源，丰富昌宁“五个文化”的内涵，保持对自身文化理想、文化价值的高度信心，对自身文化生命力、创造力的高度信心，高扬文化旗帜，坚定文化立场，努力推动昌宁文化繁荣发展。

第九专题：全面学习党的十九大精神

召开党的十九大，是全党全国人民政治生活中的一件大事，也是今年最具标志性、全局性的一件大事，对我们党高举中国特色社会主义伟大旗帜，团结带领全国各族人民实现“两个一百年”奋斗目标、开创中国特色社会主义事业新局面，具有重大而深远的意义。迎接、宣传、学习贯彻党的十九大是贯穿今年党和国家全局工作的主线，各班子成员、各股室、中心、分局，要按照中各级党委和局党组的要求，提前制定学习方案，采取各种有力措施，在党的十九大闭幕后迅速掀起学习贯彻热潮，用党的十九大精神统一思想、凝聚力量。

三、具体要求

（一）在深化学习上着力。加强在职干部理论学习，要紧的是用习近平总书记系列重要讲话精神和治国理政新理念新思想新战略统一思想、凝聚共识。充分发挥党组中心组学习的龙头带动作用，以贯彻落实《中国共产党党委（党组）理论学习中心组学习规则》为契机，深刻把握中心组学习的性质定位原则、内容形式要求、组织管理考核等各方面规定，结合“两学一做”学习教育，结合贯彻落实中央、省、市、县委重大决策部署，以中心组规范化、制度化、科学化的学习带动干部深化理论学习，形成理论学习以上率下、领导示范新格局，切实做到内化于心、外化于行。

（二）注重创新方式方法。要创新学习形式，把集中学习与个人学习结合起来，把面上学习同专题学习结合起来，把理论学习与解决实际问题结合起来，坚持“走出去”和“请进来”相结合，增强理论学习的吸引力。要丰富学习内容，创新学习方式，充分利用互联网等新兴媒体，搭建干部理论学习的新平台。要建立有效的激励机制，采取述学、评学等多种形式，调动干部理论学习的积极性。

（三）精心组织狠抓落实。局党组制定了本在职干部理论学习安排意见，局党组和办公室、人事教育股要精心组织，周密安排，确保学习专题、内容、要求落实，要加强对在职干部理论学习情况的督查、检查、指导。局各股室、中心、分局要确保时间、人员、效果落实，各股室、中心、分局要将在职干部开展理论学情况报送局办公室。
