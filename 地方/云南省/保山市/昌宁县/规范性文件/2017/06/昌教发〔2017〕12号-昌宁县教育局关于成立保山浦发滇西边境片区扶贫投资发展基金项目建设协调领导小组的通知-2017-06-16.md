# 昌宁县教育局关于成立保山浦发滇西边境片区扶贫投资发展基金项目建设协调领导小组的通知

各中小学、幼儿园，局机关各股室：

为加强对保山浦发滇西边境片区扶贫投资发展基金（以下简称“基金”）的承接、使用、管理以及基金项目建设协调推进工作，确保教育系统浦发基金有效、高效、安全使用，经研究，决定成立昌宁县教育局保山浦发滇西边境片区扶贫投资发展基金项目建设协调领导小组。现将有关事项通知如下：

一、领导小组组成人员

组 长：鲁开发 县教育局局长

副组长：路 爽 县教育局党委书记

于永军 县教育局党委副书记、纪委书记

洪云敏 县教育局副局长

张加志 县人民政府教育督导室主任

成 员：机关各股室负责人

各项目学校校长

领导小组下设办公室在县教育局项目办，由洪云敏同志兼任办公室主任，徐光伟、濮永权任副主任，负责统一协调处理日常事务。办公室人员为校建办及项目办全体工作人员。

二、领导小组及成员工作职责

（一）协调领导小组：负责研究工作中的重大事项；协调有关部门工作；检查督办项目工作；负责指导协调基金项目推进工作，用好管好基金，确保项目顺利实施及基金安全。

（二）领导小组办公室：负责处理日常事务，执行领导小组的工作安排，联系省、市、县相关部门；负责拟定工作目标、编制工作规划、完善工程资料、完成项目前期工作，切实解决项目谋划深度不足、前期工作滞后、项目开工率低的问题；负责全县项目建设推进情况收集整理、数据汇总、上报等工作。

（三）监察室：负责对项目进行监督管理。

（四）安全股：负责对项目施工安全工作进行监督管理。

（五）项目办：负责对接联系市县基础设施建设投资公司、扶贫办以及云南设计院集团业务；负责基金承接、使用、建设、管理、运营、监督等具体融资业务工作，负责项目勘察、规划设计、可研、施工等实施方案的编制、咨询、评估等。

（六）校建办：负责对项目施工进度及工程质量进行监管；对项目建设资金使用、成本等进行监控管理；负责协调工程款拨付、项目工程监督管理等。

（七）其他股室：负责对所挂钩项目进行常规管理，督促施工进度、施工进度和施工安全，协调解决项目建设中的问题。

（八）各项目学校校长：负责对接项目建设用地调整、矛盾纠纷调处及群众宣传发动工作；负责本学校项目规划审核、施工监督、过程协调工作。

三、有关要求

（一）领导小组成员要按照基金项目推进需要，积极做好各项工作，不得互相推诿，延误基金项目建设进度。

（二）各项目学校要高度重视，精心谋划，确保项目顺利落地实施。

（三）机关各股室要统筹安排好工作，监督管理好所挂钩的项目，确保基金项目顺利实施。
