# 昌宁县人民政府办公室关于印发昌宁县微型企业培育工程2017年工作实施方案的通知

各乡、镇人民政府，县直各办、局：

《昌宁县微型企业培育工程2017年工作实施方案》已经县人民政府同意，现印发给你们，请认真组织实施，抓好贯彻落实。

昌宁县人民政府办公室

2017年7月17日

昌宁县微型企业培育工程2017年工作实施方案

为贯彻落实《云南省人民政府办公厅关于印发云南省微型企业培育工程2017年工作实施方案的通知》（云政办发〔2017〕28号）、《保山市人民政府关于印发保山市微型企业培育工程2017年工作实施方案的通知》（保政办函〔2017〕52号）和《昌宁县人民政府关于进一步促进全县经济持续平稳发展20条措施的意见》（昌政发〔2017〕77号）精神,进一步强化政策支持，完善扶持措施，促进全县微型企业持续健康发展，制定本方案。

一、总体思路

认真贯彻落实中央、省、市关于支持小微企业发展的决策部署，围绕全县农特产品加工、新材料、信息、旅游文化、现代物流等重点产业,结合精准扶贫、精准脱贫攻坚行动，引导符合条件的微型企业向产业园区、“园中园”集聚发展，以创业带动就业促进产业发展。从2017年起继续实施微型企业培育工程，按照“三转变”和“四叠加”的思路，从直接扶持企业创办向间接助推企业成长转变，从增加企业数量向提高企业质量转变，从全面覆盖向突出重点转变；对微型企业贷款在现有担保基金的基础上实行贷款贴息、风险补偿和代偿损失统一担保兑付“四叠加”政策。

二、目标任务

2017年全县直接扶持170户，具体目标任务分解如下：县人力资源社会保障局20户；县市场监管局85户；县工商联30户；团县委20户；县妇联15户。其余采取贷款贴息和后续服务方式支持微型企业发展，为全县稳增长、调结构、增后劲、促就业奠定基础。

三、扶持范围

（一）实施范围。昌宁县属2017年全省76个扶贫开发重点县之一，省、市财政对170户微型企业实行直接补助，每户直接补助3万元，补助资金由省、市两级财政按照7：3的比例承担。每户微型企业（含微型企业主）在县内只能享受1次财政资金直接补助，2014—2016年已享受过的不再纳入直接补助范围。在全县范围内，继续采取扩大贷款额度、实行贷款贴息、提升后续服务等措施，加大间接扶持力度。

（二）重点扶持对象。优先扶持在昌宁生物资源加工工业园区、“昌宁园中园”落户的农特产品加工、新材料、信息、旅游文化、现代物流等重点产业领域内的微型企业。重点扶持高校毕业生、返乡农民工、失业人员、军队复员人员等创办的加工制造、科技创新、创意设计、软件开发、电子商务、生物医药、商贸流通、技术咨询、服务贸易、旅游文化、民族手工艺品和特色农产品加工等领域的微型企业。适当兼顾带动就业在3个月以上、经营周期长的种植业、养殖业，种养业扶持名额原则上不超过当年总指标的30%。

四、扶持条件

凡2014年4月1日后注册的微型企业，可按照要求申请直接补助或贷款贴息支持。组织形式和投资规模参照《云南省微型企业创业扶持实施办法》规定标准；注册标准参照《云南省人民政府办公厅关于下达2015年小额担保贷款扶持创业和“两个10万元”微型企业培育工程目标任务的通知》（云政办函〔2015〕29号）和《云南省工商行政管理局关于印发微型企业创业扶持财政补助资金申请受理初审暂行标准的通知》（云工商企注字〔2014〕10号）规定标准。微型企业须连续正常经营3个月及以上（申报时须提供近3个月税收缴纳证明或减免税证明）方可申请直接补助。

五、直接补助申报程序

符合扶持条件的微型企业，通过“云南省微型企业培育扶持工作平台”提交创业补助申请。县级承办部门在5个工作日内对申请材料进行审查,10个工作日内进行实地查验,审查材料每月向县民营办集中移送1次,由县民营办牵头组织会审、公示，公示期不少于3个工作日。县民营办每月汇总通过会审符合扶持条件的微型企业,向县财政局申请拨付补助资金。县财政局按照国库管理支付有关规定办理,在10个工作日内将补助资金划入微型企业开设的银行基本账户。有关部门严格按照要求时限加快工作进度。

六、对微型企业贷款实行政策叠加

（一）实行微型企业贷款贴息。2014年4月1日后注册的符合扶持行业要求的微型企业，可向农村商业银行、富滇银行、邮政储蓄银行3家承贷银行申请10万元—300万元创业扶持贷款。由“云南省微型企业培育扶持工作信息平台”向承贷银行直接推送企业名单，或由承贷银行根据扶持条件自主挑选企业，按照审贷程序发放贷款。10万元额度内的贷款，可按照规定享受“贷免扶补”、小额担保贷款等财政贴息政策。10万元—50万元额度的创业扶持贷款,符合条件可按照有关规定免担保；50万元—300万元额度的创业扶持贷款，可采取保证、抵押、质押、担保公司担保等多种方式办理。10万元—50万元创业扶持贷款应作为承贷银行重点发放对象单独进行考核。创业扶持贷款利率在人民银行公布的同期贷款基准利率基础上上浮不得超过14%,由省财政给予申贷微型企业不超过1年的基准利率贴息补助,基准利率上浮部分利息则由微型企业自行承担。

（二）实行全省统一担保兑付。根据《中共云南省委办公厅云南省人民政府办公厅关于进一步抓好政策落实支持民营经济发展的通知》（云办通〔2016〕46号）规定,对微型企业培育贷款担保方式进行适当调整，由省级2.9亿元担保基金进行全省统一担保。存量贷款和以借新还旧、展期等方式续贷的微型企业培育贷款可统一纳入担保基金担保范围。调整微型企业贷款代偿损失兑付方式，经核准的贷款损失应由省、州市、县三级财政承担的，调整为暂时从省级担保基金中兑付，年末由省民营办对州市、县两级财政承担的贷款损失进行汇总后报省财政厅，省财政厅通过年终结算统一扣回后回补省级担保基金。

（三）对新增贷款实行风险补偿。鼓励银行在担保基金放大倍率的基础上，增加对微型企业贷款，对承贷银行当年新增贷款以风险补偿形式给予支持，补偿额度与年度新增贷款规模挂钩。

（四）规范资金管理使用。微型企业贷款贴息资金按照比例存入承贷银行，实行专户管理、封闭运行、专款专用，并接受审计部门监督审计和配合财政资金绩效评价工作。县级承贷银行于每月5日前将上月贷款情况上报县民营办、承办部门和市级承贷银行。承贷银行每季度提出1次贴息申请，省民营办委托中介机构进行审核清算，符合条件的予以拨付。贷款风险补偿资金于次年1季度内进行审核清算，达到规定新增贷款目标的，按照规定拨付风险补偿资金。

七、强化部门责任加强督促检查

各承办部门要组织开展创业辅导培训，并积极向承贷银行推荐有贷款需求的符合条件企业，推荐和培训情况纳入工作考核。县民营办、承办部门和财政、审计等部门要加强协作，强化内部监管，规范工作程序，建立部门联动机制。按照“谁承办、谁监管、谁负责”的原则，各承办部门要采取抽查、暗访、回访、实地调研、交叉检查等方式，加大专项资金监管力度。微型企业获得扶持后2年内申请注销的，注销前应向承办部门书面报告创业扶持财政补助资金使用情况及注销理由，经承办部门审查出据注销意见后报县民营办同意方可给予注销。对骗取、套取资金的，采取措施予以追回，企业3年内不得申请专项资金扶持；构成犯罪的，及时移送公安、司法机关，依法追究刑事责任。

八、有关要求

（一）加大政策宣传力度。县民营办、各承办部门、各乡（镇）要认真开展政策宣传及培训，采取政策宣传专栏、门户网站、手机短信、公众微信等多种方式，扩大政策宣传面，让企业主、创业者全面、详细地了解申报流程、优惠政策，营造全社会创业、创新的良好氛围。

（二）规范操作流程。县民营办、各承办单位要严格按照有关政策文件要求及《昌宁县微型企业创业扶持初审和查验标准暂行意见》规范操作。确保2017年12月上旬前按质按量完成财政直补目标任务。

（三）运用好信息工作平台。充分运用“云南省微型企业培育工程网络申报和查询系统”，满足企业申报等需要。民营办、各承办部门、各承贷银行通过平台实时掌握企业注册、申请补助、申请贷款等情况，实现互联互通、信息共享。

（四）积极争取省级后续服务资金。各部门要根据省、市工作部署认真做好有关工作，积极争取省级竞争性分配后续服务资金，主动为小微企业提供研发服务、设计服务、检测检验、知识产权、法律服务、融资服务、财税代理、信用评价、会展服务、创业培训、人才培训、市场开拓、管理咨询、信息化及电子商务等后续服务。

（五）严守纪律确保公平公正。各承办部门要严格按照《昌宁县微型企业创业扶持初审和查验标准暂行意见》的规定对企业进行初审和查验，重点对投资证明与实物和带动就业人员的真实性进行实地查验，严把“实地查验”关，杜绝靠人情、关系申报扶持，对不符合扶持条件的，坚决不予扶持，防止骗取套取资金现象的发生，一经发现严格按照相关规定追究当事人责任。
