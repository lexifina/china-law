# 昌宁县教育局关于做好当前防汛工作的紧急通知

各中小学，幼儿园：

近期，全国各地强降雨频繁，南方地区连续遭受强降雨袭击，6月24日，四川省茂县发生山体垮塌重大地质灾害后，习近平总书记、李克强总理等中央领导和省委陈豪书记、阮成发省长分别对当前防汛工作作出重要批示。

当前全县已全面进入主汛期，单点性、区域性大雨大暴雨逐渐增多，极易诱发洪涝、泥石流、山体滑坡等衍生灾害。为贯彻落实各级领导重要批示精神，切实做好当前防汛工作，现就有关事项通知如下：

一、强化责任落实

进一步强化以校长（园长）负责制为核心的各项防汛责任，切实增强责任意识和担当意识，做到守土有责、守土尽责。各学校要在前期工作的基础上，再检查、再部署、再落实。将防汛责任落实到监测预警、巡查值守、抢险救灾、组织转移等各个环节。要严肃防汛纪律，加大督查力度，对责任不落实、工作不到位造成重大险情和人员伤亡的，追究当事人责任。

二、强化隐患排查

建立汛期地质灾害普查、险情巡查制度，将本校或辖区内学校的防洪设施和地质灾害隐患点纳入巡查范围并开展全面检查，不走形式、不留死角、不留隐患。对隐患区域要设置危险标识、画出警戒线，对危险性较大的高陡边坡，要积极主动采取防治措施，对排查出来的安全隐患，必须强化措施限期整改，确保安全度汛。

三、强化预警监测

要主动与当地国土、水务、气象部门沟通联系，提高预报精度，延长预见期。充分利用电话、微信、短信、广播等信息平台，提前将预警信息发送给师生员工。特别是15所地质灾害点学校（更戛乡米河完小、西桂完小，珠街乡珠街完小，大田坝镇中心幼儿园、文沧完小、华严完小，柯街镇玉地里完小，翁堵镇立桂完小，耈街乡阿水完小，漭水镇翠华完小、明德完小，温泉镇下六甲完小，鸡飞初级中学，大田坝初级中学，柯街中学），要修订完善应急处置预案，并按要求扎实开展应急疏散演练，尤其要强化夜晚的应急演练，让师生清楚撤离信号，知晓撤离要领，熟悉撤离路线。

认真执行每天定时监测记录制度，出现极端天气或连续降雨时，加强雨中、雨后监测，若隐患点监测结果出现强烈变化，要及时分析研判险情并如实上报，及时启动应急预案，果断撤离人员，必要时采取强制措施避让，确保师生生命财产安全。

四、强化值守和信息报送

要严格落实汛期领导带班和教师值班制度，确保人员在岗值守，确保24小时值班电话畅通，确保信息报送及时准确。各学校校长和安全办主任为信息上报责任人，若发生险情和灾情，按照规定程序第一时间上报，严禁瞒报、漏报、虚报行为发生。
