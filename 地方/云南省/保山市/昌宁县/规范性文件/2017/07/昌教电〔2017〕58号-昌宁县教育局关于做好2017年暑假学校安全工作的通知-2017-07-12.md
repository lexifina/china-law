# 昌宁县教育局关于做好2017年暑假学校安全工作的通知

各中小学，幼儿园：

为切实抓好2017年暑假中小学、幼儿园（以下简称学校）安全工作，根据《保山市教育局关于做好暑期学校安全工作的通知》（保教发电〔2017〕105号）要求，杜绝各类安全事故发生，确保师生生命财产安全，现将有关事项通知如下：

一、深入开展安全教育

各学校要结合本地本校实际、暑假生活特点和学校安全工作规律，在放假前集中对全体师生进行防溺水、防火、防邪教、防自然灾害及交通安全、食品安全等方面的宣传教育，通过主题班会、家长会、告家长书或寄送《致家长一封信》、《学生暑期安全提示》和发送短信、微信等形式，进一步提高师生的安全防范意识，对学生及家长广泛开展安全宣传教育，使学生及家长熟知安全提示内容，远离危险场所和物品，规避安全风险。同时，督促家长或监护人依法履行监护责任，明确家长所应承担的安全监护、教育责任，严防季节性安全事故的发生。学生放假离校时，要通知家长或监护人到校接孩子回家，班主任实行签字放行制度，并妥善保管好痕迹档案。

二、加强溺水防范工作

7－9月，仍是学生溺水死亡事件的高发期，各学校要充分利用学生离校日，教育、提醒学生不私自下水游泳，不擅自与他人结伴游泳，不在无家长或监护人带领的情况下游泳，不到不熟悉的水域游泳，不到无安全设施、无救护人员的水域游泳，不擅自下水施救。

三、开展隐患排查整治

放假前，各学校要组织人员对学校的重点部位、重要设施进行全面彻底的安全检查，坚决消除各种安全隐患。要要充分利用暑期对学校食堂、锅炉房、仓库、教室、实验室、电脑房、阅览室、报告厅、体育活动场地和器材，尤其要对校园内的危旧建筑、电网路线、违章用电、危险物品等进行排查，发现问题，立即整改。对有毒物品、放射性物品、易燃易爆物品要重点检查，严加管理，锁好门关好窗，杜绝发生火灾、失盗等重大案件。

四、加强外出活动管理

暑假期间，各学校原则上不组织师生外出活动，若确实需要开展活动的，须事先按规定报批，未经教育主管部门批准，任何学校不得擅自组织师生员工外出。组织活动前，学校要成立活动领导小组，制定方案，明确分工，落实职责，选择安全的活动路线和场所，必须乘坐有营运资质的车辆，驾驶员符合法定要求，并制定安保措施和应急预案，确保外出活动安全。

五、切实做好值守工作

各学校要组织专门力量，加强暑假期间校园安全巡逻，严格落实领导带班、值班人员值守制度，确保通讯工具24小时畅通。严格执行门卫值班制度和外来人员、车辆出入校门盘查登记制度，值班人员必须坚守岗位，尽职尽责，不得脱岗。特别是发生雷雨大风、冰雹、局部强降雨等强对流天气，值班人员要加大排查力度，做好汛期安全防范。认真执行请示报告制度，畅通信息报送渠道，发生突发事件或紧急灾情，立即向当地党委政府和上级教育主管部门报告，同时要迅速反映，稳妥处置，不得迟报、漏报或隐瞒不报。

教育局将对各学校暑假值班值守工作情况进行督查，对工作不到位的学校进行问责通报，对不遵守工作纪律，甚至玩忽职守而造成事故的责任人，将依照有关规定严肃处理，依法追究责任。

昌宁县教育局
