# 昌宁县人民政府办公室关于印发昌宁县生态环境监测网络建设工作方案的通知

各乡、镇人民政府，县直各办、局：

《昌宁县生态环境监测网络建设工作方案》已经县人民政府研究同意，现印发给你们，请认真遵照执行。

昌宁县人民政府办公室

2017年8月28日

昌宁县生态环境监测网络建设工作方案

为全面落实《云南省人民政府办公厅关于印发云南省生态环境监测网络建设工作方案的通知》（云政办发〔2017〕12号）》《保山市人民政府办公厅关于印发保山市生态环境监测网络建设工作方案的通知》（保政办发〔2017〕81号）要求，结合昌宁县实际，制定本方案。

一、总体要求

（一）基本原则

优化完善，全面设点。建成覆盖全县国土空间，全面涵盖环境质量、重点污染源和生态环境状况各要素、布局合理、功能完善的生态环境监测网络。

全县联网，统一发布。构建全县生态环境监测大数据平台，实现生态环境监测数据互联共享，完善生态环境监测信息统一发布机制。

创新驱动，综合集成。依靠科技创新与技术进步，开展大数据关联分析，提高生态环境监测立体化、自动化、智能化水平。

明晰事权，落实责任。依法明确各部门生态环境监测事权，厘清政府、企业、社会的责任，推进部门分工合作，构建上下畅通、横向到边的生态环境监测机制。

测管联动，依法追责。建立生态环境监测与监管有效联动机制，强化监测数据运用，加强环境监管，严厉打击环境违法违规行为，依法追究相关机构和人员责任。

开放市场，形成合力。开放服务性监测市场，发挥社会监测力量作用，形成行政主管部门所属生态环境监测机构和社会环境监测力量共同服务于生态文明建设的新格局。

（二）工作目标

到2018年，初步建成覆盖全县国土空间，全面涵盖环境质量、重点污染源和生态环境状况各要素的生态环境监测网络，构建生态环境监测数据网络和质量管理体系，实现各级各类监测数据互联共享，统一发布生态环境监测信息，监测监管有效协同联动。

到2020年，基本建成全县生态环境监测网络和生态环境监测大数据平台，生态环境监测立体化、自动化、智能化水平明显提升，生态环境监测数据得到充分运用，加快生态环境预报预警能力建设，各部门监测事权明晰，监测市场体系健全，各项保障机制与生态环境监测网络职责、功能和作用相适应，全面建成各环境要素统筹、信息共享、统一发布、上下协同的全县生态环境监测网络。

二、主要任务及分工

（一）全面构建生态环境监测网络

1.优化完善环境质量监测网络。建设涵盖大气、水、土壤、噪声、辐射等环境要素，统一规划、布局合理、功能完善的全县环境质量监测网络。

建设覆盖政府所在地的环境空气质量自动监测网络；建设覆盖重点水域、县级以上集中式饮用水水源地、跨界水体的水质自动监测网络；建设覆盖污染行业企业（含工业园区）及周边、社会关注热点重点区域的土壤环境质量监测网络；建设覆盖政府所在区域、道路交通及功能区的声环境监测网络，重点提升噪声敏感区环境噪声自动监测能力；完善全县辐射环境监测网络体系。建立完善水资源质量、地下水环境质量、农业环境质量等监测网络。（县环境保护局牵头负责全县大气、地表水、土壤、噪声、辐射环境质量监测网络建设，县水务局牵头负责水资源质量监测网络建设，县国土资源局牵头负责地下水环境质量监测网络建设，县农业局牵头负责农业环境质量监测网络建设；县发展改革局、县财政局、住房城乡建设局、交通运输局、卫生计生局、市场监督管理局、气象局等单位配合）

2.建立完善生态环境状况监测网络。配合省级以卫星遥感、无人机遥感监测和地面生态监测等为主要技术手段，建设完善自然保护区、森林生态区、石漠化区、生物多样性保护优先区等重点保护区域的生态环境状况监测网络。加强森林、湿地、草地、干热河谷等生态系统的定位观测和野外监测站点建设。建设覆盖全县重要江河湖泊水功能区、水土流失防治区的水土流失监测网络。（县林业局牵头重点保护区域的生态环境状况监测网络、定位观测和野外监测站点建设，县水务局牵头负责水土流失监测网络建设；县发展改革局、财政局、国土资源局、环境保护局、农业局等单位配合）

3.健全完善污染源监测网络。国家、省级重点监控排污单位必须安装建设稳定运行的污染物排放在线监测系统，市级、县级重点监控排污单位要积极安装建设稳定运行的污染物排放在线监测系统。工业园区要建设特征污染物在线监测系统，密切关注特征污染物的变化情况。污染物排放在线监测系统要实现全县联网。（县环境保护局牵头；县发展改革局、县工业商务科技信息化局、住房城乡建设局等单位配合）

（二）建立生态环境监测信息互联共享和统一发布机制

4.建立生态环境监测数据互联共享机制。优化完善生态环境监测数据采集、传输及共享等机制，建设全县生态环境监测数据传输网络和大数据平台，实现各类环境监测数据的有效集成、互联共享。加强生态环境监测数据资源开发与应用，开展大数据关联分析，为生态环境保护决策、管理和执法提供数据支撑。（县环境保护局牵头；县发展改革局、工业商务科技信息化局、公安局、财政局、国土资源局、住房城乡建设局、交通运输局、农业局、林业局、水务局、卫生计生局、统计局、气象局等单位配合）

5.完善生态环境监测信息统一发布机制。规范生态环境监测信息发布内容、流程、权限和渠道。环保局要按时发布环境质量、重点污染源等监测信息。各有关部门按照相关规定要求，依职责向公众发布监测信息，确保发布的权威性，保障公众知情权。（县环境保护局牵头；县发展改革局、工业商务科技信息化局、科技局、公安局、国土资源局、住房城乡建设局、交通运输局、农业局、林业局、水务局、卫生计生局、统计局、气象局等单位配合）

（三）加强环境管理与风险防范

6.加快环境质量监测预报预警能力建设。加快全县空气质量预报和污染预警能力建设，形成完善的环境空气质量预报预警体系。开展重点流域、重要湖库、水源涵养区等水环境质量预警研究，积极推进水质监测预报预警体系建设。提升土壤环境风险评估能力，掌握土壤重点污染区、风险区特征污染物动态变化情况。（县环境保护局牵头；县发展改革局、县工业商务科技信息化局、科技局、公安局、国土资源局、住房城乡建设局、农业局、水务局、卫生计生局、统计局、气象局等单位配合）

7.推进生态环境风险评估和预警体系建设。定期开展全县生态环境状况调查和评估，积极推进生态保护红线监管平台建设，开展生态保护红线等动态监控和综合评估，建立生态环境承载力评估机制，提升生态环境风险防控和预警能力。（县林业局牵头生态环境状况调查和评估等，县环境保护局牵头负责生态保护红线动态监控和综合评估，县发展改革局牵头负责生态环境承载力评估；县住房城乡建设局、国土资源局、农业局、水务局、卫生计生局、安监局、统计局等单位配合）

8.建立重点监控污染源监测自动预警体系。建立重点监控污染源自动监测与异常报警机制，提高污染物超标排放、在线监测设备运行异常等信息追踪、捕获与报警能力，以及企业排污状况自动化智能化监控水平。（县环境保护局牵头；县发展改革局、工业商务科技信息化局、住房城乡建设局、农业局、水务局等单位配合）

9.健全环境应急监测体系。开展环境应急监测能力建设，重点完善县级环境应急监测能力建设，提升环境应急监测快速反应装备水平，完善环境风险源数据库，储备应急监测物资，切实提高突发环境事件的应急监测能力。（县环境保护局牵头；县发展改革局、财政局、国土资源局、林业局、水务局、安监局、气象局等单位配合）

（四）构建生态环境监测与监管联动机制

10.推进生态环境监测数据运用。加强对各级各类生态环境监测结果运用管理，充分发挥生态环境监测数据在生态环境评价和考核中的作用，依据监测数据密切监控各区域生态环境质量状况及变化趋势，为落实生态环境保护责任考核、环境督察巡察、环境保护目标考核、领导干部离任审计、生态补偿、生态环境损害赔偿等提供技术支撑。（县环境保护局牵头；县监察局、工业商务科技信息化局、财政局、国土资源局、住房城乡建设局、农业局、林业局、水务局、统计局、审计局、扶贫办等单位配合）

11.生态环境监测与执法联动。建立生态环境监测与监管联合执法机制，强化执法监测，严格依法查处违法行为。建立监测监管联动快速响应机制，加大对生态环境监测数据异常区域的监测与执法，根据异常监测数据和自动报警信息，开展现场同步监测与执法。（县环境保护局牵头；县国土资源局、农业局、林业局、水务局、卫生计生局等单位配合）

12.加强生态环境监测质量管理。生态环境监测机构要严格执行国家相关法律法规、环境监测标准、技术规范和相关要求，健全并落实监测数据质量控制与管理制度。生态环境监测机构、环境监控设备运行维护机构及其负责人对监测数据的真实性、准确性、有效性、合法性负责。对生态环境监测活动中的违法违规行为，相关部门按照各自职责依法依规严肃查处。党政领导干部、国家机关工作人员篡改、伪造或指使篡改、伪造监测数据的，依法予以处理。（县环境保护局、市场监督管理局牵头；县监察局、公安局、国土资源局、住房城乡建设局、农业局、林业局、水务局、卫生计生局、气象局等单位配合）

（五）健全生态环境监测管理制度与保障体系

13.认真贯彻执行国家和省级环境监测体制改革部署。划分政府、企业、社会的监测事权，建立与生态环境网络功能、作用相适应的监测机构、人员编制、运行经费保障机制，确保全市生态环境监测网络的有效运行。（县委编办、县环境保护局牵头；县发展改革局、财政局、人力资源社会保障局等单位配合）

14.积极培育生态环境监测市场。稳步推进环境监测市场化，引入社会环境监测力量参与排污单位污染源自行监测、环境影响评价现状监测、建设项目施工期环境监测以及环境监控设备运行维护等环境监测活动。建立政府对社会环境监测机构监管和向社会购买环境监测服务的长效机制。（县环境保护局、市场监督管理局牵头；县发展改革局、工业商务科技信息化局、财政局等单位配合）

15.强化监测科技创新。积极推广先进、适用的环境监测新技术、新方法及新工艺的应用。积极开展生态环境监测合作。（县环境保护局牵头；县科技局、教育局、发展改革局、工业商务科技信息化局、财政局、国土资源局、住房城乡建设局、交通运输局、农业局、林业局、水务局等单位配合）

16.加强生态环境监测能力建设。加强各级各类生态环境监测机构基础设施（业务用房、仪器设备、监测车辆等）建设，重点加强环境质量与污染源监测、生态环境状况监测、环境应急监测、核与辐射监测、预报预警和监测数据平台等能力建设。加强生态环境监测技术队伍建设和人才培养。（县财政局、人力资源社会保障局、发展改革局、环境保护局按各自职责分别牵头；县工业商务科技信息化局、国土资源局、农业局、林业局、水务局、统计局、卫生计生局、气象局等单位配合）

17.建立生态环境监测投融资和预算保障机制。按照政府主导、社会参与的原则，积极筹措资金，拓宽融资渠道，采取预算保障、政府购买社会服务、政府与社会资本合作、委托运营等方式，建立与生态环境监测网络建设和运行任务相适应的投融资机制。根据生态环境监测事权的划分和生态环境监测体制改革，将生态环境监测机构所需人员和运行经费等纳入财政预算重点给予保障，建立与生态环境监测网络运行相适应的运行经费保障机制。（县财政局、发展改革局、环境保护局按各自职责分别牵头；县委编办、工业商务科技信息化局、国土资源局、住房城乡建设局、农业局、林业局、水务局、卫生计生局、气象局等单位配合）

三、工作要求

（一）加强组织领导

各乡（镇）人民政府、园区管委会、相关部门要高度重视，切实把生态环境监测网络建设作为生态文明建设的重要支撑，列入重要议事日程，加强组织领导，保障工作条件，确保工作方案各项任务的全面落实。

（二）强化工作落实

各牵头部门要会同配合部门，按照国家相关规范和省级工作方案、本工作方案及相关要求，对照任务分工，尽快组织开展本系统生态环境监测网络现状调查，梳理现有监测点位、指标、技术标准规范。按照本方案工作目标和时限要求，全面完成方案确定的各项工作任务。
