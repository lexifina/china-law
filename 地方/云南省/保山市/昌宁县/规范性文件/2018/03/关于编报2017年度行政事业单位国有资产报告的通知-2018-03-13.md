# 关于编报2017年度行政事业单位国有资产报告的通知

各乡（镇）人民政府，县直各部、委、办、局：

为做好2017年度行政事业单位国有资产报告编报工作，进一步加强行政事业单位国有资产的制度化、规范化、动态化和常态化管理工作，及时准确完整反映行政事业单位国有资产管理工作成果，现将《保山市财政局转发云南省财政厅关于编报2017年度行政事业单位国有资产报告文件的通知》（保财资〔2018〕18号）转发给你们，并结合我县实际情况，提出以下要求，请一并遵照执行。

一、编报范围

截止2017年12月31日止行政事业单位的全部国有资产情况。

二、编报内容

《行政事业单位国有资产报告》内容主要包括：行政事业单位资产报表、填报说明、分析报告三部分（使用财政部统一格式）。除在行政事业单位资产管理信息系统上报相关数据材料外，还应将纸质的汇总表、填报说明、分析报告按要求加盖单位公章、单位负责人签字（盖章）后报送至昌宁县财政局对口业务股室，各股室收集完成后，统一交国资办存档。

三、编报要求

请各单位高度重视，精心组织，认真编报。应在保证账账相符、账实相符的基础上，结合部门决算报表编报工作，将资产报表和决算报表相同口径机构、人员及资产指标进行核对，确保同口径资产报告数据与部门决算数据一致。并在编报资产报告的同时，按《行政事业单位资产报表分析报告内容提要》撰写分析报告，反映本部门资产管理及资产数据情况，并对资产报表与决算报表同口径数据不一致的情况进行分析说明。

四、编报时间

各乡（镇）人民政府，县直各部、委、办、局请于2018年3月10日前报送至财政局对口业务股室。各对口业务股室与部门决算数据审核无误后于2018年3月15日前报国资办。国资办汇总审核并撰写全县的填报说明和分析报告后于2018年3月20日前上报市财政局。

五、编报网址

行政事业单位国有资产报表通过行政事业单位资产管理信息系统报送，报表编制操作流程手册可在系统首页下载专区下载。
