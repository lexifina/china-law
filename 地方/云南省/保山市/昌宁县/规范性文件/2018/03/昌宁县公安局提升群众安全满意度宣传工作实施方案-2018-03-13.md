# 昌宁县公安局提升群众安全满意度宣传工作实施方案

为进一步推进平安昌宁、法制昌宁建设，不断提升群众安全感满意度，确保我县2017年下半年群众安全感满意度工作实现提升进位。根据县委、县政府统一安排部署，结合县局实际，制定本方案。

一、指导思想

以党的十八届四中、五中、六中、七中全会精神和习近平总书记系列重要讲话精神为指导，认真贯彻落实2017年10月13日全市“平安保山暨提升群众安全感满意度现场推进会”精神，以平安创建活动为抓手，通过广泛宣传，凝聚全县各级各部门和社会各界力量，有效提升群众安全感满意度，营造全县平安和谐稳定的社会环境。

二、目标任务

坚持问题导向，改革创新，进一步深化平安昌宁、法制昌宁和过硬政法队伍建设，创新政法综治宣传工作，宣传身边警、弘扬身边事，以政法综治维稳工作的全面推进赢得群众安全感满意度“双提升”，努力使全县群众安全感满意度综合指数达到95%以上，力争排名进入全省前十位，全县社会和谐稳定，群众安居乐业。

三、工作措施

各部门要扎实开展综治平安建设集中宣传活动，做好部门民警、辅警、职工及其家属的宣传发动和政策解释工作，最大限度提高广大干部群众对维护社会平安和谐、促进经济发展的知晓率和参与率，最大限度地发动广大干部群众奏响“幸福在昌宁，满意在昌宁”的主旋律。

（一）层层召开动员会，周密部署群众安全感满意度提升进位攻坚专项活动。各部门要及时召开专题会议，全面贯彻全县“深化平安建设暨提升群众安全感满意度工作推进会”精神，成立工作领导机构，制定工作方案，把责任细化到人。做好部门民警、职工、辅警及管理服务对象的教育引导，做好内部宣传、正面引导，确保本部门民警、职工、辅警的家庭和亲属、单位管理服务对象在接受民调测评时客观公正的评价。（责任部门：全局各部门、13乡镇派出所；完成时间：持续开展，至活动结束）

（二）由政治处新闻中心制作《平安美丽昌宁，我们携手共建——致全县人民的一封公开信》传单，各部门、派出所于11月10日前到新闻中心领取，按照每人10份的标准发放到部门民警、辅警手中，并由民警、辅警带回家中向亲友宣传。（责任部门：全局各部门、13乡镇派出所；完成时间：2017年11月10日前）

（三）县公安局、交警大队、交警城区中队、巡特警大队、田园派出所在滚动大屏上播放“坚决打击整治突出违法犯罪活动，建设平安昌宁”标语。（责任部门：政治处新闻中心、交警大队、巡特警大队、田园派出所；完成时间：2017年11月9日前）

（四）县公安局、交警大队、交警城区中队、巡特警大队、禁毒大队自行制作“坚决打击整治突出违法犯罪活动，建设平安昌宁”红布标语、13个乡镇派出所自行制作“坚决打击整治突出违法犯罪活动，建设平安（乡镇名）” 红布标语悬挂在部门外墙显眼处。其中，巡特警大队要利用巡逻车，在车体上悬挂或粘贴宣传标语，边巡逻边宣传。（责任部门：政治处新闻中心、交警大队、禁毒大队、巡特警大队、田园派出所；完成时间：2017年11月9日前）

（五）县局官方微信平台持续转发县委政法委、县公安局“12340”宣传信息。（责任部门：政治处新闻中心；完成时间：持续开展，直至活动结束）

（六）刑侦大队、交警大队、治安大队、禁毒大队、巡特警大队及13乡镇派出所结合部门实际，围绕“打击整治违法犯罪活动、建设平安昌宁”活动主题，撰写本部门工作措施及成效总结信息，附照片发送至县局政治处新闻中心，新闻中心将信息刊载于“平安昌宁建设、公安在行动”专栏。（责任部门：政治处新闻中心、刑侦大队、交警大队、治安大队、禁毒大队、巡特警大队及13个乡镇派出所）（附报送时间表）

（七）各派出所自主制作警民联系卡，并于11月10日以前发放到辖区群众手中。

（八）制作印有《群众的安全和满意，就是我们工作的目标》的宣传台卡，发放给部门座机用户，严格将其摆放在座机旁。（责任部门：全局各二级部门；完成时间：11月10日前）

四、工作要求

（一）统一思想，提高认识。扎实开展提升群众安全感满意度宣传工作，是进一步提升群众安全感满意度，为全县经济社会健康发展提供良好环境的重要举措，是进一步提高政法部门满意率，扩大政法综治工作影响力的有效手段。各部门要从讲政治、讲大局、讲稳定的高度，进一步提高对此项工作重要性的认识，坚决摒弃厌烦、敷衍思想，确保该项工作有效推进。

（二）迅速落实，抓出实效。各部门要按照方案要求迅速落实，细化工作措施，发动民警、职工、辅警做好宣传工作，认真倾听群众心声，向群众解释宣传内容，尽力解决发现问题，着重向“座机用户+手机用户”及其家庭成员宣讲全县政法综治维稳工作近年来取得的成效和全县创建平安昌宁的各项成果，解读群众安全感满意度测评相关问题。

（三）加强督查，严格奖惩。为确保各项工作措施落实，县局将组织专项督查，对落实工作措施不到位的部门和个人，将进行通报，并将督查结果纳入县局2017年度综合考核。
