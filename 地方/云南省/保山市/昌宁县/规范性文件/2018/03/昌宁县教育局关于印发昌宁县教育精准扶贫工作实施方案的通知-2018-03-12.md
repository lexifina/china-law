# 昌宁县教育局关于印发昌宁县教育精准扶贫工作实施方案的通知

为进一步落实好教育部等六部门关于印发《教育脱贫攻坚“十三五”规划》的通知（教发〔2016〕18号）《中共云南省委 云南省人民政府关于深入贯彻落实党中央、国务院脱贫攻坚重大战略部署的决定》（云发〔2015〕38号）《保山市教育局关于印发教育精准扶贫2017年工作要点的通知》（保政教发〔2017〕77号）等相关文件要求，切实抓好“教育脱贫一批”相关工作，结合教育系统实际，特制定本实施方案。

一、总体目标

把提高全县偏远地区教育水平放在突出位置，做到预算单位精准、资助对象精准、资助力度精准、资金发放精准、信息管理精准、技术手段精准、政策宣传精准、资助育人精准、资助评价精准、政策执行精准共“十个精准”。按照定点定向的原则，努力构建到村、到户、到人的教育精准扶贫体系，支持全县农村贫困家庭学生就学、升学、就业、创业，提升综合素质和技能水平，建立上下联动、各股室合力推进，各学校鼎力配合的教育扶贫机制，通过教育提升贫困乡镇和贫困家庭的自我发展能力，做到全县学生不因贫辍学，家庭不因学致贫，从根本上消除贫困。

二、细化任务，明确责任

（一）加快全县乡村学前教育发展

1.重点发展边远、贫困、民族地区学前教育，使乡村学前三年毛入园率有大幅增长，达到75%及以上。（牵头股室：学前教育股配合单位：项目办、校建办、全县幼儿园）

2.健全学前教育资助制度，帮助乡村贫困家庭幼儿接受学前教育。将每年300元的学前教育困难学生补助向建档立卡户、城市低保户家庭倾斜。（牵头股室：财务股配合单位：学前教育股、全县幼儿园）

3.加快推进全县“一村一幼、一乡一公办、一县一示范”目标建设。资金和项目向未建成乡村倾斜，根据未建成乡镇的自然环境、适龄人口分布等情况，优先支持各村利用闲置校舍改建、新建幼儿园，支持乡镇小学建设普惠性、低收费幼儿园，努力增加乡村学前教育资源总量。（牵头股室：项目办配合单位：校建办、基教股、学前教育股、全县幼儿园）

4.加强全县乡村幼儿园教师队伍建设和培训工作，增加幼儿教师数量，努力提高幼儿教师保教能力和水平。（牵头股室：师训办、人事股配合单位：学前教育股、全县幼儿园）

（二）巩固提升全县义务教育均衡发展

1.认真执行制定的义务教育均衡发展规划，努力实现脱贫摘帽与基本普及学前一年教育、义务教育均衡基本发展、普及高中阶段教育同步规划，同步实现。（牵头股室：督导室、基教股配合股室：学前教育股、财务股、电教站、全县中小学）

2.优化配置教育资源，全面改善农村义务教育薄弱学校基本办学条件，加强义务教育学校标准化建设。（牵头股室：项目办配合股室：校建办、基教股、电教站、全县中小学）

3.建档立卡贫困户小学和初中家庭经济困难寄宿学生享受“两免一补”和“营养改善计划”。办好必要的村完小和教学点，对不足100人的村完小和教学点，按100人核定公用经费，寄宿制学校公用经费在执行普通学校标准的基础上，再按照200元/生/年的标准核定；建立健全农村义务教育学校校舍维修改造补助长效机制。（牵头股室：财务股配合单位：基教股、校建办、全县中小学）

4.切实落实《昌宁县关于加强中小学控辍保学工作实施方案》。（牵头股室：基教股配合单位：全县中小学）

5.督促各学校认真做好“控辍保学”工作，进一步完善县乡村三级“控辍保学”工作制度，认真落实“双线”“六长”制，严格控制学生辍学率，进一步提高九年义务教育巩固率。（牵头股室：基教股配合单位：督导室、招生办、全县中小学）

6.建立健全留守儿童领导小组联席会议制度，健全留守儿童关爱体系。完善留守儿童登记、社会救助、医疗保健和安全保障等工作制度，开展形式多样的关爱活动。建设“乡村学校少年宫”、“留守儿童之家”等关爱基地，实施代理家长、寄宿之家、亲属代管等教育管理方式。加强留守儿童安全教育、心理健康教育，构建社会关爱服务机制。开展假期农村留守儿童关爱活动，帮助农村留守儿童健康成长。（牵头股室：基教股配合单位：安全股、全县中小学）

7.实施义务教育质量提升计划，切实提高农村义务教育水平和质量。启动实施义务教育阶段中小学校“1+1”城乡结对帮扶共建工程，继续推行“基地+教研+师训”的模式，进一步加强对薄弱学校、薄弱学科的教师培养培训，辐射带动教研工作向纵深推进。带动乡村学校发展，提高学校管理水平和教育教学质量，缩小城乡教育差距。（牵头股室：教研室配合单位：基教科、全县中小学）

8.对建档立卡贫困户残疾学生家庭要切实落实好特殊教育“一人一案”政策。确保每一个特教学生接受义务教育。到2020年，残疾儿童少年义务教育阶段入学率达到95%以上，重视在特殊教育中渗透职业教育，尽可能让特教学生掌握一定技能。（牵头股室：基教股配合单位：师训办、全县中小学）

（三）推进全县农村普及普通高中阶段教育

1.进一步提高全县普通高中教育，努力改善普通高中办学条件，扩大普通高中办学规模。（牵头股室：基教股配合单位：项目办、校建办、全县中小学）

2.实施建档立卡户、城乡低保家庭等子女就读高中免除学杂费政策，普通高中国家助学金向建档立卡贫困户、城乡低保家庭子女倾斜。建立普通高中生均公用经费财政拨款制度，完善普通高中学校经费保障机制。（牵头股室：财务股配合单位：监管中心、全县中小学）

3.在学生意愿，家长同意的基础上，对升学无望的九年级、高中学生实行分流到中职学校就读。（牵头股室：职成教育股配合单位：招考办、全县中学）

（四）大力发展职业教育

1.充分发挥职业教育在农村地区群众脱贫致富中的“金钥匙”作用，努力争取“现代职业教育质量提升计划”中央资金、“省级中等职业教育专项资金”等支持。（牵头股室：项目办、基教股配合单位：财务股、职业技术学校）

2.根据人才市场需求、企业用人需要和国家颁布的职业岗位，按照“长短结合、宽窄并存，按需开办、灵活设置，提前培养、同步使用”的原则，重点办好一批社会有需求、办学有质量、就业有保障的特色优势专业。（牵头股室：基教股配合单位：项目办、职业技术学校）

3.积极搭建中等、高等职业教育相互衔接贯通，产教融合、校企合作的职业教育体系。支持高等职业院校与有条件的中等职业学校共同开展五年一贯制“3+2”分段培养，扩大乡村学生接受高等教育的机会。发挥职业院校的优势资源，配合人力资源和社会保障部门、农业部门等对有就业需求和培训意愿的农村建档立卡贫困户实施职业技能培训。（牵头股室：职成教育股配合单位：职业技术学校）

（五）支持全县技能人才培养与培训

按照普职比大体相当的基本要求，继续扩大中等职业教育办学规模。增加中职和普通高中招生计划，并压实责任严格进行考核。继续抓好职业教育精准扶贫和对口支援，让建档立卡贫困村未能升学的初、高中毕业生都能到中职学校或职业院校就读，为我县培养出得去、留得住、用得上的应用技术技能型人才，全面推进国家级农村职业教育和成人教育示范县创建工作。组织参加每年全市中等职业学校技能大赛，组织开展好“职业教育活动周”。制定职业教育精准扶贫实施方案，重点解决“两后生”接受职业教育和建档立卡贫困人口因缺技能、缺知识而“因学致贫”的问题。（牵头股室：职成教育股配合单位：职业技术学校）

（六）加强全县乡村学校师资队伍建设

1.全面贯彻落实《昌宁县乡村教师支持计划（2015—2020）》和《昌宁县义务教育学校校长教师交流轮岗工作实施方案》,鼓励支持优秀校长教师到乡村中小学任教，城镇中小学教师在评聘高级职务（职称）和评先评优时同等条件下有在乡村学校任教经历的优先。开展好优质学校对口帮扶乡村学校工作，通过优秀教师到乡村学校支教、走教，乡村教师到优质学校跟岗学习等途径，结成相对稳定的对口帮扶关系，提高农村学校办学水平。(牵头股室：人事股 配合单位：全县中小学)

2.进一步加强全县教师师德建设，充分发挥乡镇学校党组织和党员教师的模范带头作用。(牵头股室：办公室 配合单位：人事股、师训办、全县中小学)

3.加大乡村教师补充力度，对新招和调入教师的分配向乡村学校倾斜。组织实施好中央特岗计划，为乡村学校补充紧缺学科教师。鼓励服务期满特岗教师留在当地任教。(牵头股室：人事股 配合单位：全县乡镇学校)

4.全面落实乡村教师生活补助差别化政策，重点向条件艰苦的山区、村完小及教学点倾斜。在现行制度架构内，做好贫困乡村教师重大疾病救助工作。各学校要每年为教师提供一次免费常规体检。优先安排贫困乡村学校教师周转房建设项目，改善乡村教师生活条件。(牵头股室：人事股 配合单位：教育工会、项目办、校建办、监管中心、全县中小学)

5. “国培计划”、“省培”等教师培训项目重点向乡村学校倾斜，针对农村教师队伍实际，探索适合的教师培训模式。到2020年，实现农村教师、校长培训全覆盖。教育系统评优评先对乡村学校和教师予以倾斜。(牵头股室：师训股 配合单位：人事股、全县中小学)

（七）提升全县乡村学校信息技术装备条件

统筹做好各乡村中小学教育信息化项目实施，加大对各乡村“三通工程”建设投入，夯实乡村教育信息化基础设施。推进“宽带网络校校通”，实现乡村所有学校宽带网络接入。加快“优质资源班班通”，力争各乡村多媒体教室比例达到60%以上。推进“网络学习空间人人通”，实现有条件上网的所有教师开通网络学习空间。继续推进教学点数字教学资源全覆盖项目的应用，促进教学点开齐课程，不断用好资源，提高教学水平。(牵头股室：电教站 配合单位：教研室、全县中小学)

（八）改善全县乡村学校基本办学条件

对照云南省贫困县“20条底线”要求，对未达标学校进行督促改善，优先安排实施第二期学前教育三年行动计划、全面改善农村义务教育薄弱学校基本办学条件、义务教育学校标准化建设、农村中小学校舍维修改造等项目，全面改善乡村学校基本办学条件。有序推进13个乡镇中心学校、初级中学和116个村完小办学条件的改善工作，使乡村中小学办学条件明显改善，基本实现校舍建设标准化。同时，优先加强对乡村学校管理和校园文化建设的工作指导，确保乡村学校全面实现硬件、软件同步提升。(牵头股室：项目办 配合单位：校建办、采购办、安全办、营养办、基教股、全县中小学)

（九）建立和完善精准化贫困生资助体系

加大对贫困家庭学生的资助力度，建立和完善各级各类教育贫困学生资助体系，进一步完善资助政策，扩大资助范围，提高资助标准。完善学前教育资助制度，资助家庭经济困难儿童、孤儿和残疾儿童接受学前教育。建立完善高中阶段家庭经济困难学生资助体系。逐步分类推进中等职业教育免除学杂费。采取多种形式实施农村中小学营养改善计划。逐步完善特殊教育的资助政策。积极引导机关企事业单位、社会组织、基金会、民间爱心人士对乡村学生开展资助，促进贫困学生健康、全面发展。(牵头股室：财务股 配合单位：营养办、基教股、全县中小学)

（十）开展各级教育结对帮扶工作

1.学前教育结对帮扶。统筹安排城区公办幼儿园、优质民办幼儿园对口帮扶乡镇中心幼儿园，乡镇中心幼儿园对口帮扶所在乡镇村级幼儿园，在县域内建立“县—乡”和“乡—村”两层结对帮扶关系。(牵头股室：学前教育 股配合单位：全县幼儿园)

2.义务教育结对帮扶。统筹安排城区义务教育学校对口帮扶农村薄弱义务教育学校，组织乡镇中心校对口帮扶所在乡镇村小学、教学点，在县域内建立“市—县”“县—乡”和“乡—村”三层结对帮扶关系。(牵头股室：基教股 配合单位：全县中小学)3.普通高中结对帮扶。积极争取市级高中学校帮扶支持，在县域内建立“市—县”的“一对一”结对帮扶关系。（牵头股室：基教股配合单位：昌宁一中、昌宁二中）

4.职业教育结对帮扶。积极争取东部地区职教集团，市级中职学校，国家中职改革发展示范校“一对一”对口帮扶各县职学校并建立起长期结对帮扶关系。（牵头股室：职成教育股配合单位：职业技术学校）

5.继续教育结对帮扶。面向乡村开展公益性继续教育，打造教育部“一村一名大学生计划”国家开放大学升级版，为各乡镇每一个行政村培养若干后备干部、创业青年和致富带头人。（牵头股室：基教股配合单位：全县中小学）

6.贫困家庭学生结对帮扶。动员大学生志愿者、社会志愿者与乡村贫困学生建立“一对一”长期结对帮扶关系，鼓励开展多种形式的社会公益活动。统筹、建立校长、教师“一对一”对口帮扶农村留守儿童的工作机制。支持社会团体、非政府组织、企业开展关爱农村留守儿童的结对帮扶活动。（牵头科室：基教股配合单位：全县中小学）

（十一）落实学校立德树人根本任务

坚持教育为社会主义现代化建设服务、为人民服务，把立德树人作为教育的根本任务，培养德智体美全面发展的社会主义建设者和接班人。坚持以促进人的全面发展的理念指导扶贫开发，深入落实教育规划纲要，以立德树人为根本任务，以弘扬和践行社会主义核心价值观为主线，以改革创新为动力，着力提高贫困学生服务国家、服务人民的社会责任感、勇于探索的创新精神和善于解决问题的实践能力，提升贫困群众教育、文化水平和综合素质。全力推进文明学校建设，培育践行社会主义核心价值观，从小抓起、从学校抓起，从贫困家庭抓起、从贫困村落抓起，切实加强贫困乡村校风、教风、学风建设，形成全员全过程全方位育人的强大合力。（牵头股室：基教股配合单位：全县中小学）

三、保障措施

（一）加强组织领导把教育精准扶贫工作摆上重要议事日程，精心组织、狠抓落实。坚持教育精准扶贫工作的科学统筹和指导，各相关单位全力支持配合、密切合作，确保目标、任务和各项措施切实得到贯彻落实。会同县级有关部门和13乡镇，共同研究、指导、协调、落实教育系统精准扶贫工作任务，推进教育帮扶目标完成。落实农村教育扶贫项目和资金督导检查制度。（牵头股室：办公室配合单位：项目办、校建办、监管中心、全县中小学）

（二）加强工作考核

对各学校教育扶贫工作实施进展、质量、成效纳入校长目标考核。层层压实责任，将各学校教育投入、人均受教育年限、学前三年毛入园率、义务教育均衡发展目标完成情况、九年义务教育巩固率、“控辍保学”工作成效、高中阶段教育毛入学率等作为对各学校教育考核的重点内容。（牵头股室：基教股配合单位：教研室、全县中小学）

（三）加强监督检查

建立信息公开制度，接受社会和群众监督。将贫困退出中教育指标完成情况纳入对县（市、区）教育部门专项督导的重要内容，制定年度贫困退出教育指标推进工作督导方案，进一步压实各级教育部门、学校贫困退出责任。严格落实责任制，强化责任追究制度，加大扶贫工作的指导和考核评价力度，建立健全各项管理制度，采取定期和不定期检查，适时抽查和跟踪检查相结合的方式，督促工作落实，切实加强惠民政策资金使用的监督，确保脱贫攻坚工作取得实效。（牵头股室：监察室配合单位：办公室、基教股、财务股、全县中小学）

（四）加强舆论宣传

各学校要充分发挥新媒体在舆论宣传中的优势作用，大力宣传中央、省市、县委县政府关于精准扶贫的战略部署，大力宣传教育精准扶贫的政策措施和教育精准扶贫中的先进典型和工作经验。进一步凝聚力量、激发热情、增强信心，形成社会支持教育精准扶贫、人人配合教育精准扶贫的良好氛围。（牵头股室：宣传中心配合单位：全县中小学）
