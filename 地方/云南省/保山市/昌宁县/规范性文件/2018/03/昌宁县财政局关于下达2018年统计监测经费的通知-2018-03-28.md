# 昌宁县财政局关于下达2018年统计监测经费的通知

国家统计局昌宁调查队：

根据《保山市财政局保山市人民政府关于提前下达2018年中央及省级财政专项扶贫资金的通知》（保财农<2017>230号）文件要求，现将2018年统计监测经费2万元下达你队，请列入2018年“2130599—其他扶贫支出”预算支出功能分类科目。

请加快预算执行进度，严格按照资金使用计划组织实施，专项用于扶贫统计监测。资金要实行专账核算，专款专用。严禁挤占、滞留、挪用财政专项资金，提高资金使用效益，确保目标任务顺利完成。

昌宁县财政局

2018年3月23日
