# 昌宁县财政局关于下达2018年度易地搬迁建房贷款省级贴息资金的通知

昌宁县财政局：

根据《保山市财政局关于下达2018年度易地搬迁建房贷款省级贴息资金的通知》（保财农〔2018〕99号）文件要求，现将2018年度易地搬迁建房贷款省级贴息资金103.16万元下达你局扶贫资金专户，请列入2018年“2130507—扶贫贷款奖补和贴息”预算支出功能分类科目。

请加快预算执行进度，严格按照资金使用计划组织实施，专款专用。严禁挤占、滞留、挪用财政专项资金，提高资金使用效益，确保目标任务顺利完成。

昌宁县财政局

2018年5月20日
