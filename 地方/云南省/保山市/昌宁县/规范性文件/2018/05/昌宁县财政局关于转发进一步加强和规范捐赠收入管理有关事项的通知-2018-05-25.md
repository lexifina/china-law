# 昌宁县财政局关于转发进一步加强和规范捐赠收入管理有关事项的通知

昌宁县林业和草原局、各乡镇财政所：

根据《保山市财政局 保山市林业和草原局关于下达2021年中央财政林业草原生态保护恢复资金的通知》（保财资环〔2021〕25号），现将2021年中央财政林业草原生态保护恢复资金2094.84万元下达给你们。具体金额和科目详见附件。

附件：2021年中央财政林业草原生态保护恢复资金安排表
