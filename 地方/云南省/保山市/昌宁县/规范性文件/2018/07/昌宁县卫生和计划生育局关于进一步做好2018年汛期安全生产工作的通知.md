# 昌宁县卫生和计划生育局关于进一步做好2018年汛期安全生产工作的通知

各医疗卫生计生单位：

自进入主汛期以来，影响安全生产的不利因素增多，引发生产安全事故的风险加大，汛期安全生产形势严峻。为贯彻落实好全县汛期安全生产会议精神和《昌宁县安全生产委员会关于进一步做好2018年汛期安全生产工作的通知》（昌安电〔2018〕5号）要求，切实做好汛期安全生产工作，有效防范和处置自然灾害引发的生产安全事故，促进卫生计生系统安全生产形势持续稳定好转，现就有关事项通知如下：

一、加强组织领导，强化汛期安全责任落实

各医疗卫生计生单位要始终牢记红线意识，坚守底线思维，要认真贯彻各级领导关于安全生产的重要指示批示精神和各级安全生产工作会议精神，高度重视强降雨、洪水、洪涝、泥石流、山体滑坡、雷电等自然灾害给安全生产工作带来的不利影响，将汛期安全生产工作摆到突出位置，按照“工作部署到位、制度完善到位、责任细化到位、物资储备到位、隐患排查到位、应急响应到位”的要求，严格落实安全生产责任，坚持主要领导亲自抓、分管领导具体抓，建立健全工作机制，对汛期安全生产工作进行再部署、再要求、再检查，全力防范应对各类自然灾害引发安全生产事故。对汛期期间措施不力、监管不到位，有失职渎职、玩忽职守等行为的，要依法依纪追究责任，导致生产安全事故发生的，一律从严追究责任。

二、加强安全监管，强化隐患排查治理

汛期历来是暴雨、洪水、泥石流、地质灾害、建筑施工等事故的易发时期，各医疗卫生计生单位要牢固树立“安全第一、预防为主、综合治理”的方针，要结合汛期特点，主要领导带队，组织人员分片包干，立即对本单位和本辖区村卫生室进行一次彻底的汛期安全隐患排查，强化安全生产检查和隐患排查治理，对检查出的隐患和问题，建立好安全隐患台账，立即整改，切实整治和排除各类事故隐患。

（一）地质灾害安全检查。各医疗卫生计生单位要进一步加强水害和地质灾害隐患的排查治理，对暴雨、洪水、泥石流、地质灾害等威胁各医疗卫生计生单位和村卫生室重点开展检查，要构筑防范排洪设施，并将防范措施落实到位。凡是构成安全威胁的房屋，要采取果断措施封闭停用，设置醒目的安全警示标志、标语，并进行跟踪管理，以防发生危房倒塌造成安全伤亡事故，对存在安全隐患的房屋，要及时进行维修和加固。

（二）药品存储安全检查。各医疗卫生计生单位要严格执行各项药品存储安全技术规程，加强存储设施温度等参数的监控，有针对性地对遇湿或高温容易分解的药品采取防水、防潮、降温等存储措施。

（三）电气设备安全检查。各医疗卫生计生单位要加强防雷电设施、电梯等特种设备和供气设备的安全检查，做好本单位供水、供电设施路线检查和维护，保证医疗设备安全有效运转和医疗服务持续提供。

（四）建筑工地安全检查。各医疗卫生计生单位要对在建工程施工工地存在滑坡、崩塌、洪水、泥石流等自然灾害危险的隐患进行认真排查，特别是对宿营地、工棚、仓库等重点位置要科学选址，在确保安全的前提下进行作业和居住。对易受雷电、暴雨等极端恶劣天气影响的场所、宿舍、工棚、仓库以及塔吊行车等设备，要提前采取防护措施，在确保安全的前提下进行生产、作业、居住和使用。强化施工现场各关键部位、关键环节检查，尤其要全面掌握深基坑、管沟（槽）和地下作业的排水、放坡和支护情况，塔吊、物料提升机、落地式脚手架等垂直运输支撑设施的基础稳固和拉结及防风装置情况。要密切关注天气变化，根据天气合理安排施工进度和计划，遇大风、连续暴雨等恶劣天气情况下，要停止施工，并根据情况安排工人撤离施工现场或危险区域。

（五）饮用水质安全检查。综合监督执法所和县疾控中心要加强对全县饮用水的检查督查，认真搞好水质监测，确保全县饮用水安全。

（六）道路交通安全检查。各医疗卫生计生单位要大力开展干部职工交通安全知识教育培训，增强安全意识和防护意识。要对单位公务车辆安全状况进行检查，防止车辆受高温发生自燃、爆燃事故和交通安全事故的发生。严禁干部职工超载、超限及酒后驾驶、疲劳驾驶、无证驾驶等违法行为。

三、加强应急值守，强化应急响应与处置工作

各医疗卫生计生单位要加强应急值守，严格执行领导干部到岗带班和关键岗位24小时值班制度，值班人员要坚守岗位、尽职尽责，确保应急通信畅通，信息报告及时准确，灾害事故要及时上报，严禁迟报、漏报和不报。要进一步完善防范自然灾害引发生产安全事故的专项应急预案，组织开展应对自然灾害的应急演练，储备应急所需物资、装备。各医疗卫生计生单位应急医疗卫生救援队伍要进入战备状态，要强化应急响应，一旦发生灾害或事故，能够迅速投入医疗卫生救援工作。要加强汛期防灾救灾减灾知识宣传，普及应急知识，提高单位干部职工防灾意识和避险、自救、互救能力。
