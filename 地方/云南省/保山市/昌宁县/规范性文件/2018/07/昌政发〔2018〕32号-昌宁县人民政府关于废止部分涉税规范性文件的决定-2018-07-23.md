# 昌宁县人民政府关于废止部分涉税规范性文件的决定

各乡、镇人民政府，县直各办、局：

为深入贯彻落实党中央、国务院关于国税地税征管体制改革精神，昌宁县人民政府对税收规范性文件进行了全面清理，经研究决定：

《昌宁县人民政府关于加强建筑安装工程和货物运输税收扣缴管理工作的通知》（昌政发〔2011〕108号）、《昌宁县人民政府办公室关于开展个人自有房产涉税情况清理检查的通知》（昌政办发〔2011〕162号）、《昌宁县人民政府办公室关于进一步加强建设领域税收管理工作的通知》（昌政办发〔2014〕43

号）、《昌宁县人民政府办公室关于印发昌宁县私人建房涉税清理检查工作方案的通知》（昌政办发〔2014〕109号）4个涉税文件予以废止，自本决定公布之日起不再施行。

昌宁县人民政府

2018年7月20日
