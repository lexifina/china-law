# 昌宁县人民政府办公室关于切实抓好2019年森林草原防灭火工作的通知

各乡、镇人民政府，县直各办、局：

为深入贯彻落实全国、全省、全市森林草原防灭火工作电视电话会议精神，切实抓好2019年全县森林草原防灭火工作，经县人民政府同意，现将有关事项通知如下：

一、提高政治站位，统一思想认识。决胜脱贫攻坚希望在山，潜力在林。我县97%的国土面积是山区，76.02%的面积是林地，绝大部分贫困群众生活在山区、林区。当前，全县已进入坚决打赢脱贫攻坚战、决胜全面建成小康社会的关键阶段，抓紧抓牢森林草原防灭火工作尤为重要。各乡镇、各单位要切实把思想认识统一到国家、省、市森林草原防灭火工作要求上来，深刻认识2019年森林草原防灭火工作的重要性、复杂性和严峻性，特殊年份采取超常规手段，充分估计困难，制定有效措施，杜绝侥幸心理，克服厌战情绪，消除麻痹思想，以更强的责任感、紧迫感、使命感，全力以赴抓好2019年森林草原防灭火工作。特别是在机构改革中，要提高政治站位，服从大局安排，按照原定职责做好各项工作，确保机构平稳过渡、工作有序衔接。

二、加强组织领导，严格责任追究。各乡镇、各单位要严格落实森林草原防灭火行政首长负责制和部门分工责任制，将防灭火责任落实到单位、落实到个人，层层传导压力，层层抓好落实。尤其要抓好重点单位、重点火险区、敏感林区的责任落实，确保防火责任有人担、防范工作有人抓、火情处置有人管、火案查处有人办。深化落实重点森林草原防灭火单位及其责任人公示制度，探索推行重点林区、重点部位“山长制”。加强行政督查和火险隐患限期整改制，继续推行森林草原防灭火工作约谈制度。按照“党政同责、一岗双责、失职追责”要求，明确责任主体，细化责任分工，突出抓好机构编制、责任制落实、人员和经费到位、队伍建设、火源管理、防灭火效果等重点工作，全面落实行政问责机制。实行“较大火灾”惩戒机制，凡发生24小时未能扑灭的森林草原火灾的，市、县森林防火指挥部将组织召开现场会，发生一把开一把，同时对相关责任人严肃追责，对火灾肇事者严惩不贷。

三、加强宣传教育，提高防范意识。各乡镇、各单位要充分利用广播、电视、微信等媒体，文艺汇演、乡村舞台、群众集会等群众活动，村广播、户主会等传统方式，把脱贫攻坚与森林草原防灭火结合起来，以警示教育为主要手段，以灾前防范、灾情处置、火源管理和村规民约为主要内容，增强广大群众森林草原防灭火的安全意识、责任意识和防范意识，营造“全民防火”的舆论氛围。紧紧围绕开展“十二月宣传月”“三月中小学校宣传周”“清明节宣传周”等活动，盯紧基层管理群体、“五种人”监护人和林农、林企、林区施工单位、户外运动爱好者等进山重点人群，突出宣传重点，增强宣传效果。分级分类开展森林草原防灭火专兼职人员培训，层层把好人员素质关、扑火安全关、能力提升关，全面打牢安全用火、扑火、避火基础，各类培训务必在进入高火险期之前完成。

四、加强火源管控，从严依法治火。各乡镇要全面落实“五个百分之百”野外火源管理制度，严把入山路口、严查进山人员、管死野外火源。全面督促护林人员上岗就位、巡山护林，对进入林区人员进行防火安全检查和教育。切实加强县级重点火险区的防火工作，对重点林区增人、增卡、增巡护、增督查，进行封山管理。继续推行限时上坟、集中烧纸钱等制度，做到重点时段重点盯守、重要林区重点投入。动员组织森林消防、森林公安、管护局、专业扑火队、护林员等力量开展武装巡查巡护，形成声势，造成震慑。加强科学防火，继续推行“两改一提前”安全用火模式，在适宜林区采取森林抚育、计划烧除和割除或提前开设防火隔离带等措施，有效降低火灾隐患。从严依法治火，继续强力推进违规用火专项治理行动，全面实行见烟必查、有火必处、违规必罚。建立健全野外用火管理制度，完善村规民约，规范野外用火行为。加强火灾案件查处，大力提高火灾案件破案率，严厉打击火灾肇事者。建立有奖举报、案件查处以奖代补机制，提高全社会参与森林草原防灭火的积极性。加大交界区域火灾防控力度，积极与交界区域的县区（乡镇）对接，共同制定联防措施，切实减小外来火威胁，依法、稳妥、安全、有序、有效处置交界区域火情火灾。

五、加强资金整合，实现管护全覆盖。各乡镇要按照有林地的每个村民小组至少配备1名护林人员的标准，增加巡山护林力量，对所有林地实施网格化管理，全面建成覆盖全县森林草原的巡山护林体系，实现“组组有人管、山山有人防”。2019年2月1日前，要全面梳理所辖村民小组、管护林地面积、管护力量分布、管护盲区等有关情况。要按照“适合、实用”原则，科学合理设置常年护林员或季节性护林员，实现重点时段护林员对村民小组全覆盖（重点时段为2019年2月1日—5月31日）。积极整合森林生态效益补偿、生态护林员、停止天然商品林采伐管护等政策及项目和植被恢复、集体林权流转、集体林权收益、集体经济等资金，动员涉林企业、合作社、专业大户等积极加大投入，多渠道筹措管护经费，解决护林员报酬。要加强护林员队伍管理，建立考核奖惩机制。对防控不到位、火灾发现不及时、火案未查处，且发生过火面积100亩以上森林火灾的，要对护林员进行辞退处理，并追究相关责任。

六、加大经费投入，提高保障水平。把森林草原防灭火基础设施建设纳入县级国民经济和社会发展规划，把预防和扑救森林草原火灾的经费（包括：“三·三”制专项经费、专业扑火队伍经费、高火险期新增护林员经费、政策性森林火灾保险配套经费和物资、设备购置经费等）纳入财政预算。要坚持“生态优先、林业收入用于林业”的原则，优先使用植被恢复费等涉林收入，确保投入按时足额到位。各乡镇要编列必要的森林草原防火专项经费，其中，田园镇、卡斯镇、更戛乡、耈街乡等重点林区乡镇不少于8万元，其他一般乡镇和林场不少于5万元。严格按照县级50万元以上、乡级5万元以上和林场2万元以上的标准落实森林草原防灭火储备物资。

七、强化队伍建设，提高应急能力。要严格按相关要求组建季节性专业扑火队和应急扑火队，加强扑火演练，做到“收得拢、拉得出、能扑灭”，一旦发生火情，迅速启动森林火灾处置预案（处置办法），动员和组织扑火力量，迅速出动、安全高效处置。

八、加强应急处置，确保扑火安全。去冬今春，全省发生了3起扑火伤亡事故，造成2人死亡、8人受伤。各乡镇、林场要深刻汲取扑火人员伤亡事故的惨痛教训，强化扑火安全红线意识，把扑火安全放到森林防火工作的首要位置并贯穿始终，将扑火安全责任和防范措施层层落实到各级指挥员、扑火队长、扑火队员以及扑火一线，落实到火灾扑救工作的全过程。要经常性组织开展扑火安全隐患排查，重点检查各级指挥员、扑火人员是否了解掌握安全常识、是否配齐了防护装备，车辆、机具装备和相关设施是否存在安全隐患等，对排查发现的问题要及时进行整改，做到防患于未然。要进一步加强宣传教育培训，严格落实各项管控措施，坚决做到扑火安全零伤亡。

九、落实行业责任，形成工作合力。各级森林防火指挥部（所）成员单位要各司其职，通力协作，切实负起森林草原防灭火工作的有关责任。县级和乡镇森林防火指挥部（所）要进一步明确各成员单位的责任，完善责任清单，形成工作合力，全面抓好落实。森林公安要主动作为，加大森林火灾案件的侦破和查处力度，充分发挥好“四两拨千斤”的作用。各管护局、林场、乡、村、组是森林草原防灭火工作的前哨和主战场，要全民动员、群防群治，把森林草原防灭火责任落实到村、组，落实到农户，落实到干部职工和护林员身上。防火期内，县级和乡镇森林防火指挥部（所）各成员单位要对挂钩乡镇、林场和村委会开展不少于3次督促检查，每次督促检查结束后要向同级森林防火指挥部（所）报送专题报告。

十、降低火灾风险，抓实保险工作。森林火灾保险事关广大林农切身利益，要按照政府引导、市场运作、自主自愿、协同推进的工作原则，确保公益林应保尽保、商品林愿保尽保。各乡镇、林场要严格按照县人民政府的统一部署，按照时间节点，配合承保公司完成保费收缴、投保清单收集、查勘定损和案件理赔工作。

昌宁县人民政府办公室

2019年1月17日
