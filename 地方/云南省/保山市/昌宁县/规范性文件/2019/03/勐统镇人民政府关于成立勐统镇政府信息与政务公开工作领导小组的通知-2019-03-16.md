# 勐统镇人民政府关于成立勐统镇政府信息与政务公开工作领导小组的通知

各村（社区），有关单位：

根据中央和省、市、县关于加强政府信息与政务公开工作的有关要求，经镇人民政府研究，决定成立勐统镇政府信息工作领导小组。现将组成人员通知如下：

组长：成洪艳 镇人民政府镇长

副组长：于 聪 镇党委副书记

成员：鲁 永 镇农业综合服务中心主任

杨忠鹏 镇林业服务中心主任

谢 芳 镇财政所所长

罗文忠镇文广中心主任

董 萍 社保中心负责人

张媛芳 镇党政办负责人

领导小组下设办公室在党政办，由张媛芳同志兼任办公室主任，董萍为办公室工作人员，负责政府网站信息公开栏目的维护、管理及处理日常事务。

（此件公开发布）

昌宁县勐统镇人民政府

2019年3月10日
