# 大田坝镇人民政府关于印发大田坝镇2019年地质灾害防灾减灾工作方案的通知

各村（社区），镇直单位：

现将《大田坝镇2019年地质灾害防灾减灾工作方案》印发给你们，请结合实际，认真贯彻执行。

大田坝镇人民政府

2019年2月14日

（此件公开发布）

大田坝镇2019年地质灾害防灾减灾工作方案

根据《地质灾害防治条例》《保山市人为地质灾害管理办法》及《保山市地质灾害防治规划》等规定，为切实做好大田坝镇地质灾害防灾减灾工作，保护全镇人民群众生命、财产安全，结合我镇实际，制定本方案。

一、2019年地质灾害趋势预测

（一）预测依据

1. 地质环境背景条件。大田坝镇位于昌宁县西北部，地理坐标为东经99°27′—99°39′，北纬20°53′—25°08′，地处保山、大理两地州交界地，山峦起伏，地形、地貌、地质复杂多样，全镇总人口22251人，总土地面积312平方公里，山区面积占98%，由于人多地少，山高坡陡，水土流失严重，地质环境比较复杂，易发生滑坡、崩塌、泥人石流等地质灾害。

2. 降雨情况预测分析。根据市、县气象台气候趋势及主要气象灾害预测，2019年我镇气候呈立体分布，年平均气温17℃，平均降雨量1100毫米，但时空分布不均，旱涝灾害明显。其中1—4月份全镇降雨量为正常至偏少，雨季开始期为正常至偏晚，一般在5月中旬至下旬开始，6—8月为主汛期。

3. 工程建设活动。2017—2018年期间大田坝镇浦发、国开项目较多涉及道路建设有80多公里，尤其新寨村和文沧村道路建设过程中路边高边坡开挖，道路建设产生的废弃土石存在严重坍塌滑坡隐患。

4.地质灾害综合防治。各级历来高度重视地质灾害防治工作，特别是2013年全省启动地质灾害综合防治体系建设以来，全镇地质灾害调查评价、监测预警、综合防治与应急体系建设取得明显进展，提升了应对突发地质灾害的能力。

（二）预测结果

1.地质灾害活动水平：2019年汛期全镇地质灾害频度及危害程度总体上属正常年份。

2.地质灾害高易发时期：6—10月。工程建设和矿山生产诱发人为地质灾害的时间具有不确定性。

3.地质灾害高发区域：在建工程、道路交通（包括乡村道路）、矿山以及中小学校等。

二、地质灾害重点防范区

（一）重点防范的地理区域

1.大田坝社区

该社区有新寨、下木瓜寨1、下木瓜寨2、石桥、新河、下杨、河边、寨子头、上木瓜寨、兰家寨、林家洼及中心完小11个地质灾害点。重点区域在寨子头、下木瓜寨1、下木瓜寨2、上木瓜寨。

2. 华严村

该村有大平地、大窝子地、上坡处、仓门前、伙头寨5个地质灾害点。重点区域在上坡处。

3. 文沧村

该村有对门寨、陈家寨、大寨3个地质灾害点。重点区域在陈家寨、大寨。

4. 清河村

该村有外寨（李家寨）、下寨、里寨（易家寨）、上寨4个地质灾害点。重点区域在里寨（易家寨）、外寨（李家寨）。

5. 新寨村

该村有大寨、浪坝寨、三沟水旧寨、三沟水大浪坝、王家洼、芭蕉河、小寨7个地质灾害点，均属于不稳定性滑坡点，重要灾害点是：大寨、王家洼。

6. 湾岗村

该村有上寨、外寨、大湾岗、外松坡、下梅树、茶叶树、大桥河、立巴兰8个地质灾害点，均属于不稳定性滑坡点。重要灾害点是：上寨、大桥河。

（二）重点防范的矿山地质灾害

矿山地质灾害主要由矿山开发引起，根据《地质灾害防治条例》，采取矿山企业自我监测、自我预防、自我治理的原则。政府相关部门结合矿山安全生产监管进行矿山地质灾害防治的监督检查。

1. 地下开采的矿山。我镇地下开采的矿山主要是文沧铜矿厂、昌宁锡矿厂，地下开采主要易引起地面塌陷地质灾害和铜厂河、蒿坝地河泥石流灾害。

2. 露天开采的重点矿山。主要是位于天堂山硅矿开采区的：贞元硅矿采选厂、盛吉硅矿采选厂、元盛硅矿采选厂、大田坝硅矿采选厂，开采主要会引发锅厂河之大田坝河、芭蕉河、李子树河、小米河泥石流灾害。

（三）重点防范的公路地质灾害

我镇主要防范的公路地质灾害地段为大田坝社区至新寨村三沟水段，因2018年公路建设存在大量路基高边坡开挖，存在塌方隐患；同时文沧村、新寨村纳入国开行贫困村基础设施建设的80多公里乡村道路也应该纳入重点防范。

（四）重点防范的学校地质灾害

1.大田坝社区：中心完小。

2.华严村：华严完小。

（五）重点防范村（社区）

初步预测2019年全镇受灾害威胁较大的为湾岗村、大田坝社区。

（六）重点防范期

全镇地质灾害的发生受降雨影响十分明显，汛期当降雨时间较长并伴随多次单点暴雨时，各类地质灾害尤其是崩塌、滑坡和泥石流等将明显增多，并具有明显的突发性、滞后性。因此，全镇地质灾害防治以主汛期（6—10月）作为重点防范期。各村（社区）、镇直各部门要提前做好各方面准备工作，及早进入重点防范工作状态，认真执行汛期地质灾害防治各项制度，利用气象信息科学防御地质灾害，确保安全度汛，最大限度地减少地质灾害造成的损失。

近年来，全镇因不合理工程建设活动所诱发的人为地质灾害日趋增多。同时，人为地质灾害不完全由降雨诱发，具有不确定性，无雨期也可能发生地质灾害，且以危岩土体崩塌等工程活动诱发的地质灾害最为典型。因此，工程建设单位要严格履行基本建设程序，施工前必须开展地质灾害危险性评估，施工过程中要规范施工行为，严防因违反施工操作程序而引发地质灾害发生。

三、地质灾害防治措施

（一）指导思想，工作原则

1. 指导思想

以党的十九大精神及习近平新时代中国特色社会主义思想为指导，突出以人为本，以群测群防为主要手段，以突发性地质灾害防御工作为重点，以科学调查监测评价为依据，以维护人民生命财产安全为根本出发点，紧紧围绕受威胁的人口集中区和居民点以及重要设施进行放置部署，保障社会稳定，为建设经济富裕、社会和谐新大田坝作贡献。

2. 工作原则

（1）坚持从实际出发，因地制宜，讲究实效的原则。

（2）坚持全面规划，统筹安排，把握重点，兼顾一般，量力而行，分步实施的原则。

（3）落实地质灾害“以预防滑坡泥石流为主、以监测预报为主、以灾前避让为主”的“三为主”方针和“防治结合、群专结合、单项治理与综合治理相结合、重点建设规划与地质灾害防治规划相结合”的“四结合”原则。

（二）防治相关措施和对策

1. 健全机构、明确职责、全面监控。地质灾害防治事关人民群众生命财产安全，事关全镇经济发展和社会稳定。为加强全镇地质灾害防治的组织领导，我镇成立了地质灾害防灾减灾工作领导小组，负责组织和协调全镇的地质灾害防治工作。组成人员如下：

领导小组下设办公室在镇地质灾害防灾减灾工作领导小组办公室，由郭斌担任办公室主任，国土分局鲁跃兴担任办公室工作人员，处理日常事务。各村（社区）要进一步完善群测群防网络，落实辖区责任领导、各灾害点检测负责人和具体监测员，结合各灾害点实际和汛期降雨情况加强监测。一旦发现险情，及时向镇领导小组通报并采取措施，尽最大努力避免和减少人员伤亡。对出现险情、灾情后隐瞒不报的要严肃处理。

2. 统一认识、统筹安排、加强制度建设。各村（社区）和各镇直单位要多渠道、多形式的深入开展地质灾害防治法规和科普知识宣传培训工作，提高全民防灾减灾意识。要加强地质灾害的执法监督力度，督促负责人主体采取防治措施，特别要加强对人为因素诱发地质灾害的执法监督，坚决防止人为诱发地质灾害。与此同时，要建立健全并严格落实相应的制度。

3. 突出重点，做好汛期地质灾害防治工作。汛期是地质灾害的高发期，是全年防御工作的重中之重。一是要严格执行险情巡查、灾情速报、汛期值班等制度。二是各村（社区）要做好地质灾害隐患点及时排查和汛期检查，对新发生的地质灾害隐患点及时安排监测人员和责任人，并迅速报镇地质灾害领导小组。三是对目前掌握的易造成人员伤亡和重大经济损失的地质灾害隐患点，要有计划地组织治理，并做好危险区居民的搬迁工作，确保人民生命财产安全。四是要加大执法工作力度，重大建设项目和采矿权审批必须请有资质的地质部门进行地质灾害危险性评估，尽量避免人为诱发的地质灾害。

4. 汛期严格落实“三项措施”、“四项制度”。落实“汛期值班制度”，保证汛期24小时信息传输渠道畅通；落实“汛期巡查制度”，加强对全镇所有地质灾害隐患点的巡查与监测；落实“汛期灾情速报制度”，确保地质灾害信息准确及时地上报；落实“汛期层层负责制度”确保分工明确，责任到位。执行“汛期简易观测措施”，及时掌握汛期地质灾害发展动态；执行“汛期灾前报警措施”，及时组织疏散和避让；执行“汛期紧急避让措施”，尽量减少伤员，降低损失。

（三）加强地质灾害群测群防网络机构

1. 各村（社区）要成立机构并根据个村的实际情况制定出相应的地质灾害防灾减灾方案，负责辖区内地质灾害点监测与检查，组织实施辖区内地质灾害巡查。

2. 地质灾害领导小组组长、副组长为全镇地质灾害防治责任人，各村党总支书记为村辖区内地质灾害的直接责任人，各矿山企业负责人为矿山地质灾害防治的直接责任人。各个地质灾害隐患点的监测员从受灾害威胁的群众中选取2人担任，必须身体健康、责任心强，以确保群测群防网络高效运转。
