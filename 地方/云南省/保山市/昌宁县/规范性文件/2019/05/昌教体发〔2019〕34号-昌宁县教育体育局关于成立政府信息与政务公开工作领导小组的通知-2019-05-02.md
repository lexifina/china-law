# 昌宁县教育体育局关于成立政府信息与政务公开工作领导小组的通知

局机关各股室，各中小学、幼儿园：

为顺利推进我县教育体育系统政府信息与政务公开工作，创建公正便民、勤政廉政效能的机关，经县教育体育局班子会议研究，决定成立昌宁县教育体育局政府信息与政务公开工作领导小组。具体组成人员如下：

组 长：鲁开发 县委教育体育工委书记、县教育体育局党组书记、局长

成 员：左彭军 县委教育体育工委委员、县教育体育局党组成员、县教育体育局副局长

李 岚 县委教育体育工委委员、县教育体育局党组成员、县教育体育局副局长

洪云敏 县教育体育局副局长

张加志 县人民政府教育体育督导委员会办公室主任

胡永海 县教育体育局办公室负责人

李春攀 县委教育体育工委办公室负责人

杨学奎 县教育体育局基础教育体育股负责人

夏润平 县教育体育局人事股负责人

徐光伟 县教育体育局校建办负责人

濮永权 县教育体育局项目办负责人

余 彪 县教育体育局宣传中心暨政策法规股负责人

杨学忠 县教育体育局学校经费监管中心负责人

李光丽 县教育体育局财务股负责人

35所法人学校校（园）长

领导小组下设办公室在行政办公室，由左彭军副局长分管此项工作，胡永海兼任办公室主任，负责处理政府信息与政务公开工作的各项日常事务。
