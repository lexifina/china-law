# 昌宁县教育局关于对田园镇达仁村幼儿园等级评估认定结果的通知

为进一步贯彻落实《幼儿园工作规程》《3—6岁儿童学习与发展指南》，全面提升办园水平和保教质量，促进我县学前教育健康发展，根据《云南省幼儿园办园水平综合评价方案》通知精神，2019年1月17日，县教育局成立领导小组，组成专家组对照条件保障、园务管理、办园效益三个方面44项C级指标，采取定性与定量相结合的方法，对符合申报条件的田园镇达仁村幼儿园进行办园水平综合评估。通过综合专家评估意见，并经县教育局局务会议研究，同意认定田园镇达仁村幼儿园为二级一等幼儿园。

希望田园镇达仁村幼儿园以评估工作为契机，在巩固已有成绩的基础上，根据评估专家组提出的意见和建议，认真落实整改，进一步强化园务管理，全面提高保教质量。
