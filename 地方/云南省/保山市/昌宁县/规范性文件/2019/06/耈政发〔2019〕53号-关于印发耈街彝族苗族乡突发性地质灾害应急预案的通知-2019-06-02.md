# 关于印发耈街彝族苗族乡突发性地质灾害应急预案的通知

耈政发〔2019〕53号

耈街彝族苗族乡人民政府关于印发耈街乡突发性

地质灾害应急预案的通知

各村（社区）、乡直及驻耈各单位：

现将《耈街乡突发性地质灾害应急预案》印发给你们，请结合实际，抓好贯彻落实。

耈街彝族苗族乡人民政府

2019年5月28日

耈街乡突发性地质灾害应急预案

一、总则

“十三五”期间，为贯彻落实以人为本的基本理念，高效、有序地做好地质灾害防治和抢险工作,避免或最大限度减少灾害造成的损失，维护人民群众生命、财产安全和社会稳定。根据《地质灾害防治条例》（国务院令第394号）、《国家突发地质灾害应急预案》、《云南省地质环境管理条例》和《云南省突发性地质灾害应急预案》，结合我乡实际，制定本预案。

（一）本预案所称突发性地质灾害是指因自然因素或者人为活动引发的危害人民生命和财产安全的山体坍塌、滑坡、泥石流、地面塌陷等与地质作用有关的地质灾害。

（二）地质灾害应急是一旦发生地质灾害前兆或出现地质灾害临灾险情时，为了避免或最大限度减轻地质灾害造成的人员伤亡和财产损失，而采取的不同于正常工作程序的紧急防灾和抢险救灾行动。

（三）地质灾害应急分为临灾应急和灾害应急两类。

临灾应急：出现地质灾害临灾险情后，即进入临灾应急期，所采取的紧急防灾避险行动称为临灾应急。

灾害应急：发生地质灾害后，即进入灾害应急期，所采取的紧急抢险救灾和防止灾情进一步扩大的行动称为灾害应急。

（四）地质灾害按照人员伤亡、经济损失大小，分为四个等级：

1．特大型：因灾死亡30人以上或因灾造成直接经济损失1000万元以上的；

2.大型：因灾死亡10人以上、30人以下，或因灾造成直接经济损失500万元以上、1000万元以下的；

3.中型: 因灾死亡3人以上、10人以下，或因灾造成直接经济损失100万元以上、500万元以下的;

4.小型:因灾死亡3人以下，或因灾造成直接经济损失100万元以下的。

（五）地质灾害临灾险情按照受威胁的人数或者可能造成的经济损失，分为四个等级：

1.特大级：受威胁人数在1000人以上或潜在可能造成的经济损失1亿元以上的；

2.重大级：受威胁人数在500人以上、1000人以下，或潜在经济损失5000万元以上、1亿元以下的；

3．较大级：受灾害威胁，需搬迁转移人数在100人以上、500人以下，或潜在经济损失500万元以上、5000万元以下的；

4.一般级：受威胁人数在100人以下，或潜在经济损失500万元以下的。

（六）地质灾害应急工作遵循以人为本、快速反应、统一领导、分级负责、依靠科学、部门协作和因地制宜的原则。

（七）本预案适用于耈街乡区域内发生中型和小型地质灾害以及出现较大级和一般级地质灾害险情后的紧急防灾和抢险救灾工作。区域内发生特大型和大型地质灾害以及出现特大级和重大级临灾险情后启动和执行《昌宁县突发性地质灾害应急预案》。

二、组织机构和部门职责

（一）耈街乡人民政府地质灾害抢险救灾指挥机构为乡地质灾害抢险救灾指挥部，由乡人民政府乡长任总指挥、分管领导任副总指挥，必要时由乡党委书记直接任总指挥。

指挥部主要职责：在根据地质灾害险情或灾情，决定是否启动本预案；统一指挥和组织地质灾害抢险救灾工作；执行省、市、县地质灾害抢险救灾指挥部下达的其它关于地质灾害防灾任务；发生特大型和大型的地质灾害后，应立即向省、市、县有关部门报告，并配合省、市、县应急工作组工作。

（二）指挥部办公室设在乡党政办，办公室主任由乡党政办公室主任担任，各相关单位派联络员参加办公室工作。

办公室主要职责：督促、检查、落实各单位地质灾害应急准备工作；组织地质灾害灾情、险情调查和评估，提出启动地质灾害应急预案的建议；根据指挥部的各项指示、命令、负责实施、协调并督促、检查、落实各项应急工作；有关信息、联络、接待等各项指挥部的日常工作。

（三）指挥部下设七个应急工作组，各工作组组成及主要职责：

1.紧急抢险组：乡武装部牵头，派出所、水利站、安监站等部门组成。

主要职责：调集必要的设备，指导抢险救灾队伍（民兵应急分队），抢救被压埋人员；对已经发生或可能引发的水灾、火灾、爆炸及剧毒和强腐蚀性物质大量泄漏等“次生灾害”进行抢险，消除隐患；根据实际情况，及时组织受到地质灾害威胁的人员财产转移到安全地带，情况紧急时，强行组织避灾疏散。

2.调查监测组：耈街国土分局牵头，乡规划员、民政助理等组成。

主要职责：调查、核实险情或灾情，组织险情或灾情监测和评估，预测灾害发展趋势和潜在威胁，提出应急防范对策、措施。

3.医疗卫生组：乡卫生院牵头，村卫生室等部门组成。

主要职责：组织急救队伍，抢救伤员，向灾区提供所需药品和医疗器械；检查、监测灾区的饮用水源、食品等，采取有效措施，防止和控制传染病的暴发流行。

4.治安保卫组：乡派出所牵头，武装部、交警等部门组成。

主要职责：维护灾区社会治安和道路交通秩序，负责救灾物资和灾区人员、财产、政府机关及重要部门、单位安全，保证抢险救灾工作顺利进行。

5.基本生活保障组：乡民政办牵头，乡财政所、机关后勤等部门组成。

主要职责：指导灾区村委会做好灾民的基本生活保障工作，

包括急需物资的供应、调配和管理，灾民的转移、临时安置及死难者的善后、保险理赔等工作。

6.设施修复和生产自救组：供电、通信、水利、教育、农业、林业等部门组成。

主要职责：指导灾区组织力量抢修受损的通信、电力、供水、水利、交通、校舍等设施，指导灾区修复损毁的农田、林地，保证抢险救灾工作顺利进行，尽快恢复灾区的生产和教育秩序。

7.应急资金保障组：乡财政所牵头，农商行、民政办等部门组成。

主要职责：负责应急救灾资金的筹集和落实，做好应急款物的分配及使用指导、监督和管理工作。

三、应急准备

（一）各村（社区）、各单位，应根据本预案和本单位职责制定具体的抢险救灾应急行动方案，并报乡人民政府和地质灾害防治领导小组办公室备案。

（二）11个村（社区）各地质灾害隐患点应根据本预案的要求制定出各隐患点的具体救灾抢险行动方案，内容包括监测、预防责任人、预警信号、人员财产撤离路线、临时避险安置点的安排等，并报乡人民政府和乡地质灾害防治领导小组办公室备案。

（三）指挥部各成员单位，应当根据应急预案和行动方案的要求，保证应急设施、设备、救灾物品、机器等物资储备。

（四）各村（社区）、各单位，应当抓好应急队伍建设和人员落实，定期对相关机构和人员进行应急处理相关知识、技能的培训及应急处理演练，推广最新知识和先进技术，提高应对各类突发地质灾害的能力。

（五）各村（社区)、各单位，应当对公众开展地质灾害防治及应急知识的宣传教育，增强全社会对地质灾害的防范意识和应对能力。

（六）乡人民政府要把地质灾害应急工作纳入国民经济和社会发展计划，落实应急资金。

四、临灾应急

（一）接到一般级、较大级地质灾害临灾险情报告后，指挥部办公室应迅速组织应急调查组赶赴现场，调查、核实险情，提出应急抢险措施建议，并向指挥部提出是否启动临灾应急预案的建议。

（二）指挥部接到启动临灾应急预案建议后，应立即召开紧急会议，进行险情会商，研究部署抢险避灾各项工作，并视情况宣布启动本预案。

（三）一旦启动本预案，乡指挥部根据需要设立若干工作组，指导、协助各村（社区）有序地组织抢险避灾工作。

1．调查险情，组织专业技术人员会商，提出应急抢险避灾措施建议，确定抢险避灾方案。

2．根据灾害成因、类型、规模、影响范围和发展趋势，划定地质灾害危险区，设置危险区警示标志；确定预警信号和撤离路线；组织危险区内人员和重要财产撤离，情况危急时，强制组织避灾疏散。地质灾害隐患点人员财产撤离方向、预警信号。

3.对灾害隐患进行动态监测，分析、预测其发展趋势，根据险情变化及时提出应急对策，并做好灾害突发的预报工作。

4.组织专业施工队伍实施必要的应急避险工程，减缓和排除灾害险情的发展。

5.气象、电力、通讯部门和民政、派出、卫生、交通、水利等部门根据险情状况做好相关应急工作。

（四）及时向乡人民政府和自然资源部门报告险情和抢险避灾情况，迅速取得指导和支援。

（五）灾害险情得到有效控制，应到根据调查组的建议，宣布结束临灾应急期，确定撤销或者继续保留危险区事宜，提出下一步防灾、搬迁避让或工程治理方案措施，及时组织实施。

（六）接到重大级和特大级临灾险情报告后，应立即向县、市有关部门报告，并迅速组织应急调查组赶赴现场，配合省、市、县应急调查组调查及抢险救灾工作。

五、灾害应急

（一）发生小型、中型地质灾害后，指挥部办公室应立即派出应急调查组或工作组，赶赴灾区调查、核实灾情，提供乡人民政府采取有效应急措施，防止灾情扩大，并向指挥部提交启动灾害应急预案的建议。

（二）指挥部接到启动预案的建议后，立即召开紧急会议，进行灾情会商，研究部署抢险救灾各项工作，宣布启动应急预案。

（三）指挥部各应急工作组根据总指挥的指令和职责分工，指导、协助各村（社区）高效有序地组织抢险救灾工作。主要任务：

1．调查监测组：查明灾害类型，规模、潜在的威胁和影响范围及成因和诱发因素，组织灾情监测和评估，分析、预测灾害发展趋势，提出应急对策措施。

2.紧急抢险组：组织紧急抢险队伍，抢救被压埋人员；对已经发生或可能引发的各种“次生灾害”进行抢险，消除隐患；组织受灾害威胁的人员和重要财产转移到安全地带，情况紧急时，强行组织避灾疏散。

3.医疗卫生组：组织急救队伍，可设置急救站，抢救伤员，向灾区提供所需药品和医疗器械；检查、监测灾区的饮用水源、食品等，采取有效措施，防止和控制传染病的爆发流行。

4.治安保卫组：维护灾区社会治安和道路交通秩序；根据调查组的建议，及时划定地质灾害危险区和抢险救灾特别管制区，设置明显警示标志，安排巡逻值勤人员；禁止与抢险救灾行动无关的人员、车辆进入危险区和特别管制区。

5.基本生活保障组：负责妥善安排灾民生活，协同做好死难者的善后和保险理赔等工作。

6.设备修复和生产自救组：指导灾区组织力量抢修受损的通信、电力、供水、水利、交通、校舍等设施，指导灾区修复损毁农田、林地、保证抢险救灾工作顺利进行，尽快恢复灾区的生产和教学秩序。

7.应急资金保障组：负责应急救灾资金的筹集和落实，做好应急款物的分配及使用的指导、监督和管理等工作。

8．防灾指挥部办公室及时向县自然资源部门报告灾情和抢险救灾情况，取得指导和支援；协调并督促、检查、落实各项应急工作；做好新闻报道、受灾群众的慰问、接待等工作。

（四）发生地质灾害后，有关村（社区）、村民小组、寨邻寨户应当先行组织自救、互救工作，并采取紧急避让和抢险救灾措施。

（五）灾情、险情已经消除或者得到有效控制，应当根据调查组的建议，宣布结束灾害应急期、撤销抢险救灾特别管制区，确定撤销或者继续保留危险区事宜，提出下一步防灾、搬迁避让或工程治理方案，及时组织实施。

（六）乡人民政府、各村（社区）应当根据地质灾害灾情和地质灾害防治需要，统筹规划、安排受灾地区的重建工作。

（七）发生大型、特大型地质灾害后，应立即向县、市有关部门报告，并迅速派应急工作组赶赴现场，配合县、市应急工作组进行抢险救灾工作。

六、附则

（一）地震引发的地质灾害的应急工作，按《云南省地震应急预案》的有关规定执行。

对洪水等自然灾害引发的崩塌、滑坡、泥石流的应急工作，防洪等法律、行政法规有规定或有预案的，从其规定或按其预案执行，本预案可与其配合实施。

（二）各村（社区）应拟定本行政区域的突发地质灾害应急预案，报乡人民政府和防灾指挥部办公室备案。

（三）本预案在实施中如无重大变化不作调整，如有调整另行通知。

（四）本预案解释权归乡防灾指挥部办公室。

（五）本预案自发文之日起实施。

耈街彝族苗族乡党政办公室
