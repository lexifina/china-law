# 昌民政发〔2019〕33号昌宁县民政局关于提高2019年困难群众基本生活保障标准的通知

各乡镇人民政府办公室、财政所：

为更好地保障城乡困难群众基本生活，根据《保山市财政局 保山市民政局关于下达2019年第三批城乡困难群众基本生活救助补助资金的通知》（保财社〔2019〕132号）、《保山市民政局关于提高2019年困难群众基本生活保障标准的通知》（保民政发〔2019〕34号）文件要求，决定提高我县困难群众基本生活保障标准，现将有关事项通知如下：

一、提标安排

城乡居民最低生活保障标准、特困人员救助供养标准、孤儿生活补助标准从2019年7月1日起执行。

（一）城市最低生活保障标准

城市最低生活保障标准从565元/人.月提高到620元/人.月，城市低保月人均补助水平人均提高30元。

（二）农村最低生活保障标准

农村最低生活保障标准从3800元/人.年提高到4500元/人.年，A类保障标准从300元/人.月提高到360元/人.月；B类保障标准从230元/人.月提高到270元/人.月；C类保障标准从175元/人.月提高到200元/人.月。

（三）特困人员救助供养标准

1.集中供养特困人员执行1000元/人.月（其中保障标准为732元/人.月）。

2.分散供养特困人员：特困人员从670元/人.月提到732元/人.月。

3.集中供养特困人员照料护理补贴标准为：一档（完全丧失生活自理能力或一级重度残疾的特困人员）835元/人.月，二档（部分丧失生活自理能力或二级重度残疾的特困人员）418元/人.月，三档（其他特困人员）251元/人.月；分散供养特困人员照料护理补贴标准为：一档151元/人.月，二档88元/人.月，三档不予补助。

（四）孤儿生活补助标准

集中供养儿童补助标准达到1974元/人.月，分散供养儿童补助标准达到1274元/人.月。

二、工作要求

（一）加强沟通协调。

各乡镇要切实做好农村最低生活保障制度与扶贫开发政策的有效衔接，充分发挥低保兜底保障作用，切实把提高困难群众基本生活保障标准工作做实做细。

（二）认真组织开展好特困救助供养人员生活处理能力评估工作。

各乡镇人民政府协调乡镇卫生院，在村（居）委员会协助下，对特困人员生活自理能力进行评估，并根据评估结果，确定特困人员应当享受的照料护理标准档次。

昌宁县民政局
