# 关于印发大田坝镇2019年森林和湿地资源监测工作实施方案的通知

各村（社区）：

现将《大田坝镇2019年森林和湿地资源监测工作实施方案》印发给你们，请结合实际，认真贯彻落实。

大田坝镇人民政府

2019年11月7日

（此件公开发布）

大田坝镇2019年森林和湿地资源监测工作

实施方案

根据《生态文明建设目标评价考核实施办法》（云厅字[2017]28号）《云南省绿色发展指标体系》、《云南省生态文明建设考核目标体系》（云发改资环[2017]1265号）、《云南省自然资源资产报告制度》（云自然资[2019]131号）等文件要求和建设内容的安排，结合我镇实际，特制订方案。

一、指导思想

以习近平新时代中国特色社会主义思想和党的十九大精神为指导，认真贯彻习近平总书记关于着力开展森林城市建设的重要指示，牢固树立“创新、协调、绿色、开放、共享”的发展理念，以全省2016年森林资源二类调查，2018年森林资源监测数据库为基础，运用“3S”档案更新、人工现地核实及林木生长等手段，抓实森林湿地保护，着力森林和湿地资源的保护管理水平，为生态文明建设提供科学依据。

二、组织机构

为切实加强对森林和湿地资源监测工作的领导，确保森林和湿地资源监测工作稳步推进，决定成立大田坝镇森林和湿地资源监测工作领导小组，组成人员如下：

领导小组下设办公室在林业服务中心，由周要全兼任办公室主任，具体负责森林和湿地资源监测的日常工作，督促检查并协调有关部门工作。各村各部门要根据全镇的统一部署，研究制订工作计划，协调各方力量，推动森林和湿地资源监测长效机制的健全和完善。

三、职责分工

为加强我镇森林和湿地资源监测工作的落实，各相关部门要密切协调配合，形成森林和湿地资源监测保护的强大合力。

（一）镇林业服务中心。负责林业相关法律法规的宣传教育；负责森林和湿地资源监测保护的组织协调工作；负责全镇森林和湿地资源监测和林地湿地管理、科技推广；负责林业行政案件的查处工作，在镇党委、政府的领导下，对各村（社区）森林和湿地资源监测情况进行检查。

（二）镇自然资源所。负责监督林地、土地使用，未经林业部门审核同意，不得批准建设项目使用林地湿地；做好国土规划与林地湿地保护的衔接；协助林业部门查处非法开垦和非法使用林地湿地案件。

（四）镇农业综合服务中心。配合抓好草原湿地资源保护工作，确保森林、草原资源和人民群众生命财产的安全。

（五）镇水务站。结合“河长制“工作，落实做好水源地湿地生态保护和修复工作。

（六）天堂林区派出所。组织保护发展森林湿地资源相关法律法规宣传，自觉维护全镇林区治安稳定，负责侦破破坏森林湿地资源案件。

（七）各村（社区）。负责辖区内群众的普法教育，负责辖区内森林湿地的保护工作。

四、相关要求

（一）统一思想，狠抓落实。森林和湿地资源监测工作时间紧，任务重，各村各部门要充分认识森林和湿地资源监测工作的重要性，确保各项工作任务的落实。

（二）广泛宣传，全员参与。要把森林和湿地资源监测保护的意义采取镇、村干部大会，社员大会等多种宣传形式，加大宣传力度。宣传森林和湿地资源监测保护的重要意义，宣传森林和湿地资源监测保护是每个群众应尽的义务和责任，真正做到家喻户晓。
