# 昌宁县卫生健康局应对新型冠状病毒感染的肺炎流行医疗救治工作方案

为有效应对可能发生的新型冠状病毒感染的肺炎流行 ， 科学 、规范 、有效地开展医疗救治工作， 最大限度地减少对公众健康和生命安全造成的危害， 根据《保山市卫生健康委 员会转发关于印发云南省应对新型冠状病毒感染的肺炎流 行医疗救治工作方案的通知》要求， 结合实际，制定本方案。

工作职责： 全面统筹 、安排、指挥我县新型冠状病毒感 染的肺炎医疗救治工作； 整合医疗资源， 统一组织、协调各 方力量， 全面落实各项医疗救治措施， 及时组织救治病人； 协调好药品 、 医疗设备、应急车辆、 防护用品等物资储备。 领导小组下设办公室在县卫生健康局， 由赵东宁兼任办公室 主任， 成员： 赵勇 、吴洪美、鲁光明， 负责 日 常工作。

二、定点医院

县级定点医院： 指定县人民医院为我县新型冠状病毒感 染的肺炎定点收治医院， 负责收治昌宁县辖区需住院治疗的 新型冠状病毒感染的肺炎病例。做好床位 、药品 、医疗设备、 应急车辆、 防护用品等物资储备。

县人民医院要制定工作方案， 成立本医院工作领导小组 和由感染性疾病、呼吸 、重症医学、儿科、护理 、 医院感染 控制 、临床检验 、 医学影像、 中医、药学等专业专家组成的 专家组， 负责重症病例的医疗救治工作 。要切实担负起疫情

防控和医疗救治责任， 全天候做好值班安排和应急值守， 春 节假日期间务必安排好人员值班， 确保 一旦出现疫情能够迅 速有效处置 。主要同志要靠前指挥， 统筹协调， 加强组织部 署和信息报告， 一旦发现确诊病例要全力以赴做好医疗救治 工作。

三、成立县级新型冠状病毒感染的肺炎医疗救治专家组

县级成立由感染性疾病、呼吸、重症医学 、儿科 、 医院 感染管理、检验、 医学影像 、 中医等学科的专家组成的新型 冠状病毒感染的肺炎医疗救治专家组， 专家名单见( 附件) ， 根据工作需要临时抽调的医务人员应服从安排积极参加救 治工作。主要职责是负责当地新型冠状病毒感染的肺炎医疗 救治技术培训、会诊 、指导， 对集中收治重症病例的定点医 院提供技术支持， 对辖区救治工作提出建议等。县卫生健康 局将根据需求及时调度专家力量支援诊治能力薄弱的下级 医院。

专家组实行组长负责制， 专家组成员24 小时保持通信 通畅， 参与工作的人员必须严格遵守保密规定， 未经卫生健 康行政部门允许， 不得在任何场合发布、传播和评论工作内 容。

四、病人转运

由县人民医院 ( 急救站) 负责辖区内病人转运工作， 各 医疗机构转运需住院治疗的新型冠状病毒感染的肺炎病例 时， 要及时与县急救中心联系转运至定点医院。县人民医院 要按照国家及省、市级要求做好转运工作。各医疗机构和急

救中心要做好病例转运交接记录， 转运疑似病例要由转出医 院专家组组长签字确认并做好交接， 及时做好疫情报告工作。

五、医疗救治

各级各类医疗机构要国家及省、市 、县有关要求做好新新型冠状病毒感染的肺炎诊断和治疗工作， 加强重症病例的救 治、会诊及转诊， 严格落实医院感染控制各项要求。

六、工作要求

( 一 )各医疗机构要高度重视，成立领导小组和专家组， 切实加强新型冠状病毒感染的肺炎医疗救治工作的组织领 导和技术保障， 严格按照《全国各省 ( 区、市) 首例新型冠 状病毒感染的肺炎病例确认程序》进行病例确认及公布。

( 二 ) 各单位要做好医疗救助物资储备工作， 加强人员 培训和演练， 提高诊疗水平， 按照《新型冠状病毒感染的肺 炎诊疗方案 (试行第二版) 》做好病例的发现、报告、治疗、 隔离 、转运 、 医院感染控制等各项工作 。做到早发现 、早隔 离、早诊断、早治疗， 降低新型冠状病毒感染的肺炎发生率 和病死率。必要时可请县级、市级 、省级专家组指导帮助救

治。

( 三 )各单位要高度重视新型冠状病毒感染的肺炎防治工 作， 切实担负起疫情防控和医疗救治责任， 全天候做好值班安 排和应急值守， 春节假期间务必安排好值班人员， 确保责任到 人， 措施到位。对疫情瞒报、谎报、迟报等玩忽职守的人员要 严肃处理。

( 四 )县卫生健康局将对开展防控措施落实情况的督导检 查，确保各项措施的落实。重点督查应急预案制定、业务培训、 技术演练 、疫情报告 、传染病预检分诊及疫情现场控制等措施 落实情况， 发现问题、及时解决。

( 五 ) 各单位要按照《保山市卫生健康委员会转发关于做 好新型冠状病毒感染肺炎有关工作的通知》(保卫健发〔 2020〕 17 号 ) 要求， 做好信息报送工作 。 自 2020 年 1 月 22 日开始 ， 于每天上午 09:00 前将《发热、疑似及确诊患者统计汇总表》 ( 附件 2 ) 及《新型冠状病毒感染的肺炎个案登记表》 ( 附 件 3 ) 报县疾病预防控制中心， 并按照省、市、县级要求进 行“零报告”及统 一文档格式。我局将对不按时上报的单位 进行通报批评， 造成严重后果的将依法依规追究责任。
