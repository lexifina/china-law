# 昌宁县财政局转发《保山市财政局保山市卫生健康委员会关于转发做好新型冠状病毒感染的肺炎疫情防控防治补助资金管理指导意见的通知》的通知

各乡、镇人民政府，县公安局、县卫生健康局：

现将《保山市财政局 保山市卫生健康委员会关于转发做好新型冠状病毒感染的肺炎疫情防控防治补助资金管理指导意见的通知》（保财社〔2020〕45号）转发给你们，请按相关要求切实做好疫情防控防治资金的管理，全力支持好疫情防控工作。

附件：1.保山市财政局 保山市卫生健康委员会关于转发做好新型冠状病毒感染的肺炎疫情防控防治补助资金管理指导意见的通知

2.云南省财政厅 云南省卫生健康委员会关于做好新型冠状病毒感染的肺炎疫情防控防治补助资金管理的指导意见
