# 昌宁县2020年消除疟疾行动项目工作计划

根据《云南省消除疟疾行动计划实施方案( 2010-2020年)》和《保山市消除疟疾工作方案(2016-2020年)》要求，为明确部门职责，落实各项工作任务措施，巩固全县消除疟疾行动项目成果，特制定本计划。

一、指导思想

坚持预防为主、科学防治、 因地制宜、分类指导原则，在政府领导、部门合作、全社会参与的工作机制下实施消除疟疾行动项目，充分利用资源，不断提高疟疾防治技术水平，巩固消除疟疾行动项目成果。

二、工作目标

稳定疟疾防治队伍，加强业务技能培训，加大学校及社区疟疾防治知识宣传力度，努力提高疟疾防治知识知晓率，持续巩固消除疟疾行动项目成果。

三、主要工作任务指标

( 一 )技能培训

年内完成1期县级疟原虫镜检技能培训，提高各监测点的镜检技能水平。

( 二 ) 发热病人疟原虫血检

县级综合医院、县疾控中心和乡镇卫生院认真开展疟原虫血检工作。以乡镇为单位“三热”病人(临床诊断疟疾、疑似疟疾和不明原因发热病人)疟原虫年血检总数不低于辖区人口数的1‰，县人民医院血检率占门诊发热病人5%以上，柯街镇中心卫生院、卡斯镇中心卫生院、湾甸乡卫生院、勐统镇中心卫生院、鸡飞镇卫生院、耇街乡中心卫生院血检率占门诊发热病人10%以上；每年1月、2月、5-10月疟疾传播季节各单位 血检人数不低于年血检总数的80%；疟疾病例实验室检测率达100%，实验室确诊病例达100%；出入境流动人口发热病人疟疾筛查比例达100%。2020年完成“三热”病人血检750人份(见附件) ，开展阴性血片复检90张。

( 三 )病例报告、治疗和个案调查

各级各类医疗卫生机构诊断疟疾后24小时内报告率达100%，疟疾病例规范治疗率达100%，流行病学个案调查率达100%。

( 四 )疫点处置

内源性疟疾疫点和输入性疟疾疫点处置率达 100%。

四、防治策略和措施

( 一 )传染源控制及管理

1.及时发现病人。各级各类医疗卫生机构通过“三热”病人疟原虫血片镜检或快速诊断试剂条(RDT) 辅助检测及早发现疟疾病人。当RDT检测阳性时，应保留试纸，然后采集血清，保留血片备查，并送县疾控中心镜检确诊。

2.加强疟疾疫情报告。县级医疗机构和乡镇卫生院对发现的疟疾病人按照《中华人民共和国传染病防治法》和《传染病 信息报告管理规范》要求报告疫情。

3.病例核实。县疾控中心对网络直报的所有疟疾病例立即进行疟原虫血片镜检核实， 并在3个工作日内完成流行病学个案调查。

4.规范治疗病人。县级医疗机构、乡镇卫生院对发现的疟疾病人按照《抗疟药使用原则和用药方案》进行治疗，并对疟疾病人服药进行全程管理。

5.休止期根治。在疟疾传播休止期，对前2年的间日疟病人和混合感染者进行抗复发治疗，根治工作在医护人员的监护下进行。

6.疫点处置。出现疟疾病例并具有传播条件的自然村或居民点，7个工作日内由县疾控中心负责组织开展病例搜索，对近2周内有发热史者采集血样进行疟原虫血片镜检或RDT检测，同时对疫点采取相应的媒介防制措施，发放疟疾防治宣传材料，提供疟疾咨询服务信息。

( 二 )健康教育

1.大众宣传教育。一是各单位利用报纸、广播、电视、互联网等新闻媒体结合“全国疟疾 日”活动，广泛宣传疟疾防治知识和国际消除疟疾政策，提高居民自我防护意识。二是县疾控中心定期提供宣传内容，各医院候诊大厅、乡镇卫生院、村 卫生室设立消除疟疾健康宣传栏，并及时更新。

2.中小学生健康教育。制作适宜中小学生学习的宣传笔、课件、宣传手册、折页等材料，组织开展健康教育工作，并通过“小手牵大手”方式向家庭传播疟疾防治相关知识。

( 三 )特殊人群的疟疾防治

加强流动人口和特殊人群(如：缅甸、越南新娘)的管理，召开乡级协调会，建立协调机制，确保各项工作顺利开展。

( 四 )疾病监测

1.加强信息系统管理， 提高病例报告及监测数据质量。

2.为进一步巩固消除疟疾成果，2020年在疟疾流行季节开 展4次疟疾主动病例侦查工作。

五、项目管理

( 一 )开展项目管理培训，加强项目管理、数据收集和沟通协调。

( 二 )根据工作任务和指标，召开一次县级疟疾年会，签订消除疟疾项目工作协议书。

( 三 )配备必要的试剂及耗材，保证“三热”病人血检及疟疾监测开展。

( 四 )开展1次督导评估，并进行交流和通报。

六、资料整理

按照档案管理要求汇编成册进行装订，做到分年度、有目录，入资料盒、资料柜专人保管。
