# 鸡飞镇人民政府关于成立鸡飞镇易地扶贫搬迁复垦复绿验收工作领导小组的通知

各村（社区），镇直各单位：

为进一步加强和完善我镇易地扶贫搬迁复垦复绿工作，保证复垦复绿按时、按质、按量完成，经镇党委、政府研究，决定成立鸡飞镇易地扶贫搬迁复垦复绿工作领导小组，现将有关情况通知如下：
