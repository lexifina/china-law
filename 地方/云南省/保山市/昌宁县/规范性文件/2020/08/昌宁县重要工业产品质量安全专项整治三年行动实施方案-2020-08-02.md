# 昌宁县重要工业产品质量安全专项整治三年行动实施方案

为贯彻落实《云南省重要工业产品质量安全专项整治三年行 动实施方案》 (云市监办发〔 2020〕41 号 ) 和《保山市市场监督 管理局关于印发保山市重要工业产品质量安全专项整治三年行动 实施方案的通知》 的工作要求， 守住重要工业产品安全底线， 维 护好我县重要工业品质量安全稳定的良好态势， 不断推动我县高 质量发展， 开展重要工业产品质量安全专项整治。制定本方案。一、总体要求坚持习近平新时代中国特色社会主义思想为指引， 以维护质量 安全和提升质量水平为主线， 通过三年专项整治， 全县重要工业 产品质量水平有明显提高； 生产企业质量安全主体责任进一步夯 实； 重要工业产品质量安全事中事后监管工作体系进一步完善 ， 全县重要工业产品质量安全水平明显提升。

领导小组下设办公室在质量发展与监督管理股， 负责专项整 治行动的统筹协调、组织有关专题会议及各项工作推进情况有关 材料的收集上报等工作。

三、主要任务分解

( 一 ) 督促生产许可证获证企业履行质量安全承诺

对通过告知承诺、简化审批程序取证的企业， 在规定时间内 开展全覆盖例行检查和后置现场审查， 检查企业条件是否符合质 量安全承诺。对报送材料不符合要求， 生产检验设备不符合产品 实施细则要求的企业， 通报发证机构依法撤销其证书； 对故意提 供虚假材料， 完全不具备生产条件骗取生产许可证的， 通报发证 机构按照《中华人民共和国行政许可法》规定撤销其生产许可证， 并在三年内不 再受理其生产许可证申请。 (责任科室： 行政许可股、质量发展 与监管股)

( 二 ) 督促获证企业完善管理机制， 依法合规生产

按“双随机， 一公开”方式加强对获证企业的监督管理。重 点对获证企业是否建立产品质量验收、 出厂检验和售后服务等确 保产品符合标准要求的制度并实施。

对不能保持生产许可证、强制性产品认证要求条件的企业 ， 责令限期改正； 预期未改正的， 由发证机关和认证机构撤销其资 质证书。对不再从事重要工业产品生产的企业， 及时通报发证机 构依法注销其生产许可证书、强制性产品认证证书。

结合实际情况， 努力探索建立质量追溯体系， 畅通举报渠道， 鼓励举报质量违法行为。对偷工减料、生产假冒伪劣商品以及造 成质量安全事故的， 依法严惩。 (责任科室： 信用体系监管股、 质量发展与监督管理股、标准化和计量认证监管股、信用体系监 管股、法规股)

( 三 ) 落实销售经营者主体责任

督促各重要工业产品经营者严格履行《中华人民共和国产品质量法》《中华人民共和国消费者权益保护法》《中华人民共和国食品安全法》规定的责任和义务， 建立和完善 进货验收等经营管理制度， 严格执行进货验收， 销售登记管理要 求， 承担进销产品质量安全责任， 采取有效措施， 坚决遏制无生 产许可证， 无强制性认证产品和不合格、假冒产品进入市场。(责 任科室： 质量发展与监督管理股、标准化和计量认证监管股、投 诉举报中心)

( 四 ) 实施防范化解重要工业产品质量安全重大风险治理行 动

1.突出危险化学品产品质量风险隐患排查整治， 督促企业落 实质量安全主体责任，针对辖区重点产品，重点企业、重点区 域、 重点指标开展质量安全风险排查， 组织企业开展自查， 重点 排 查原材料进货检验、过程控制、 出厂检验、生产设备、检验设施 (备) 等是否符合要求， 针对自查情况， 督促企业制定质量安全 风险隐患排查治理清单， 逐一 明确和细化隐患， 督促销售企业建 立并执行进货检查验收制度， 验明产品合格证明和其他标识， 杜 绝采购、销售实施生产许可证管理的未获证危险化学品。

组织开展获证企业现场检查， 重点针对证照信息、关键设备、 过程控制、标识标注、强制性标准的执行情况进行检查。对报送 材料不符合要求、生产检验设备不符合产品实施细则的， 通报发 证机构依法撤销其生产许可证书； 对提供虚假材料、完全不具备 生产条件骗取生产许可证的， 通报发证机构依法撤销生产许可证， 且 3 年内不再受理其生产许可证申请； 对不再从事生产许可发证 的企业， 及时通报发证机构依法注销其生产许可证书。 (责任科 室： 行政许可股、质量发展与监督管理股)

2.对烟花爆竹产品开展产品质量监督抽查。配合好市质量检 测中心重点针对烟花爆竹批发零售经营企业销售的烟花爆竹产品 质量进行监督抽查， 突出不合格企业后处理， 依法监督生产经营 企业采取下架、整改销毁和召回等措施管控质量。 (责任科室： 质量发展与监督管理股、法规股)

3.对常压罐体罐车质量检验工作进行检查。督促承担危险化

学品车载罐体定期检验的检验机构进行自查， 自查内容包括资质 条件是否具备， 质量管理体系和相关管理制度是否有效运转， 关 键检验设备是否按要求配置齐全且状态良好， 检验设备是否按要 求进行检定或校准， 检验报告的真实性、检验内容的完整性、检 验结论的准确性， 以及检验报告与原始记录等相关信息的一致性。

组织开展检验机构现场检查， 重点对资质条件、质保体系和 检验质量控制进行检查， 抽查其最近的检验报告， 根据检验报告 的信息， 到检验现场抽查罐体实物质量， 检查实物与检验报告在 产品质量与相关信息等方面是否相符。 (责任科室： 标准化计量 认证监管股)

4.加强电动自行车产品销售企业的监管。认真落实《云南省 安全生产委员会办公室关于加强电动自行车火灾事故防范工作的 通知》 (云安办〔 2019〕34 号 ) ， 督促企业落实质量安全主体责 任， 主动落实进货查验、质量承诺等自律制度， 诚信守法经营； 查处违法生产、销售不符合 GB17761—2018《电动自行车安全技术 规范》 的电动自行车； 严厉打击生产、销售假冒伪劣电动自行车 及配件的违法行为； 严厉打击销售违规改装拼装电动自行车等违 法行为。 (责任科室： 标准化计量认证监管股、商标广告股、法 规股)

5． 深入开展钢铁行业淘汰落后产能， 防范“地条钢”死灰复 燃专项工作。充分发挥生产许可证在落实国家产业政策中的约束 作用， 严格生产许可证受理， 严肃查处无证生产违法行动； 畅通

举报渠道， 强化社会监督， 充分发挥“12315”投诉举报热线作用， 引导公众广泛参与监督， 营造社会共推落后产能退出的良好环境。

(责任科室： 行政许可股、质量发展与监督管理科、投诉举报中 心、法规股)

(五) 强化产品质量监督抽查和风险预警监测

配合国家省市三级组织开展工业产品质量监督抽查， 突出重 点产品、重点企业、重点区域、重点指标， 生产领域以涉及国计 民生的重要工业产品生产企业为主， 销售流通领域以量大面广、 消费者投诉多、质量安全问题较为突出的消费品为主。进一步强 化监督抽查结果处理， 特别是针对国家级、省级、市级监督抽查 发现的产品质量安全问题， 依法监督生产经营者采取下架、整改 销毁和召回等措施管控质量， 并依法追究法律责任， 及时将处理 情况上报任务下达部门。

强化风险监测预警作用， 组织开展重点产品质量安全风险预 警监测， 结合生产许可、监督抽查情况， 多渠道搜集质量安全风 险信息， 调查了解质量安全状况。存在严重问题的逐级上报县市场监管局。 (责任科室： 质量发展与监督管理股)

(六) 严厉打击质量安全违法行为

正确处理好严格执法与“放管服”改革的关系， 加大行政执法力

度， 严厉查处制售假冒伪劣商品的违法行为， 并纳入企业信用信 息公示系统“黑名单”， 不得以“放管服”改革和减少督查检查 为由限制执法、放松执法。

在产品质量安全风险隐患排查中发现的问题， 依法责令停产、 限期整改。对实行生产许可证管理的产品， 整改后复查仍不合格 的， 通报发证机构依法办理撤销生产许可证手续。依法严厉查处 无证生产、偷工减料、使用不合格原材料、制售假冒伪劣商品等 违法行为， 涉嫌犯罪的依法移送司法机关处理。

严格按照《企业信息公示暂行条例》等法律法规要求， 通过 国家企业信用信息公示系统依法公示相关行政处罚信息。认真落 实《关于加强严重质量失信企业管理的指导意见》， 依法将具有 主观故意、严重违反质量相关法律法规、社会影响恶劣的违法企 业纳入严重质量失信企业管理。按照《关于对严重质量违法失信 行为当事人实施联合惩戒的合作备忘录》要求， 及时推送相关数 据， 会同相关部门依法依规对严重质量违法失信企业及其法定代 表人进行联合惩戒， 使其“ 一处违法、处处受限”。 (责任科室： 质量发展与监督管理股、标准化计量认证监管股、商标广告股、 法规股、信用体系监管股)

四、进度安排

从 2020 年 7 月至 2022 年 12 月， 分四个阶段进行。

( 一 ) 制定方案 ( 2020 年 7 月 )

在市局印发工作方案的基础上， 我局结合我县实际制定实施 方案， 作出具体部署。

( 二 ) 排查整治 ( 2020 年 7 月至 12 月 )

县局各相关业务科室、各市场监督管理所， 结合我县实际，

对重点领域、重点企业、关键环节安全风险隐患进行全面深入排 查， 建立问题隐患和制度措施“两个清单”， 坚持边查边改、立 行立改， 整治工作取得初步成效。

( 三 ) 集中攻坚 ( 2021年)

动态更新“两个清单”， 采取建立台账、 限期整改、严肃查 处、严厉问责等措施， 加大专项整治攻坚力度， 落实和完善治理 措施， 推动建立健全重要工业产品质量安全隐患排查和安全预防 控制体系， 整治工作取得明显成效。

( 四 ) 巩固提升 ( 2022年)

深入分析重要工业产品质量安全方面共性问题和突出隐患 ， 深挖深层次矛盾和原因， 从法规标准、政策措施层面建立完善具 体制度， 健全长效机制， 形成一套较为完善的安全监管制度体系。

五、工作要求

( 一 ) 加强组织领导。各股室， 各所要将重要工业产品质量 安全专项整治三年行动作为全面发现问题、及时补齐短板、加强 质量监管、打牢安全基础的重要抓手， 明确职责分工， 细化工作 措施， 推动工作落实。

( 二 ) 完善工作机制。领导小组组长要定期听取三年行动工 作推进情况汇报， 协调解决重大问题。各股室在工作中要主动打 开部门界限， 发挥市场监管综合效能。要通过督查督办、情况通 报、警示约谈等形式， 推动工作落实。

( 三 ) 加强监管服务。将“打治结合”贯穿专项整治三年行

动全过程， 严格执法措施。坚持执法寓服务之中， 组织专家、技 术人员开展精准指导服务， 实行远程咨询、“会诊”与专家、技 术人员指导、上门服务相结合， 帮助解决产品质量安全生产难题， 加强跟踪指导服务。大力推广可复制经验， 曝光负面典型， 鼓励 和引导广大群众特别是企业职工举报重大隐患和违法违规行为 ， 形成全社会参与支持、群防群治的良好局面。

( 四 ) 严格跟踪问效。综合运用通报、约谈、警示、曝光、 督办、考核、线索移交、提出问责建议等措施， 对整治工作不负 责、分工责任不落实、措施不得力、重大问题隐患不整改、逾期 没有完成目标任务的， 坚决问责。对因整治工作失职渎职， 造成 事故发生的， 移交司法部门依法严肃追究法律责任。
