# 腾冲市城区义务教育初中阶段公办学校2020年招生通告

根据《腾冲市人民政府办公室关于印发腾冲市城区义务教育阶段公办学校招生工作方案（试行）的通知》（腾政办发〔2018〕45号），现将我市城区义务教育初中阶段公办学校2020年招生工作通告如下：

一、招生方式、对象和证明材料

（一）招生方式

实行网上报名，网上录取，网上公布结果。

（二）招生对象及报名资格

1. 招生对象

户籍在城区公办学校服务范围内的适龄少年和外来务工人员适龄随迁子女（腾冲市民族中学初中部招收部分农村户口的少数民族学生）。

2. 报名资格

（1）在城区中学片区内完成小学六年义务教育（即：小学六年级毕业）的适龄少年，获得初中一年级报名资格。

（2）在城区中学招生片区外完成小学六年义务教育的，需要到城区就读初中的，办理方法见“七、其它事项（一）（二）（三）”。

（3）完成小学六年义务教育的腾冲市农村户口少数民族学生，有腾冲市民族中学初中一年级报名资格。

（三）报名及录取验证时应提供的证明材料

家长根据报名志愿，提供对应的证明材料，用于网上报名及资格复审。具体要求如下：

1. 凡报名者必须提供户口簿，包括适龄少年本人、户主（报名少年所在户口本的首页，即写有详细地址的页面）及父（或母）的，共3个页面。

2. 户口在城区学校招生片区内的，以户口为报名依据。按照第1个要求提供材料，要求适龄少年必须与父（或母）在一个户口本上。户口挂靠亲朋的适龄少年（下文统称“挂靠户”）放在第二批录取。

3. 户口在城区学校招生片区外的，可根据情况，用城区内的房产证、营业执照或居住证等条件报名。

（1）以房产证为依据报名的。房产证必须是适龄少年父或母（或其他法定监护人）的；已购房但房产证正在办理的，提供购房合同；房产证用于抵押贷款的，提供房产证复印件和贷款合同；

（2）以营业执照为依据报名的。营业执照必须是适龄少年父或母（或其他法定监护人）的；营业执照必须在检审有效期内。

（3）腾冲市外随迁子女，以父（母）和其子女的居住证和居住证发放回执为依据报名。其中，报名时间必须在居住证签注的有效期内；

（4）腾冲市内进城务工人员随迁子女以腾越派出所出具的证明为依据报名；

以上四项，如果适龄少年与父或母（或其他法定监护人）不在一个户口本上的，提供出生证或其他相关证明。

4. 符合优待照顾政策的，提供对应证明材料。

5. 报腾冲市民族中学的农村户口少数民族学生，提供户口本，注册后可直接报名。

6. 上传佐证材料原件高清照片。网上报名注册有困难的，可申请就读小学帮助家长完成。

（ 二）根据志愿先后，按照以下批次顺序进行预录取

1. 第一批 按照户籍地址与公办学校招生范围一致的原则预录取孩子与父（或母）户口在一起的城区户籍适龄少年和符合优待政策的适龄少年。

2. 第二批 按照以下2个小批次顺序预录取城区外腾冲市户籍适龄少年和户口挂靠户。

（1）房产证载明的地址与公办学校招生范围一致的适龄少年和户口挂靠户（注：2019年6月22日后办理的挂靠户口不作为报名依据）；

（2）营业执照载明的地址与公办学校招生范围一致的适龄少年；

3. 第三批 按照以下3个小批次顺序预录取外来务工人员（市外）随迁子女。

（1）房产证载明的地址与公办学校招生范围一致的适龄少年；

（2）营业执照载明的地址与公办学校招生范围一致的适龄少年；

（3）居住证载明的地址与公办学校招生范围一致的适龄少年；

4. 第四批 按照腾越派出所开具的居住证明载明的地址与公办学校招生范围一致的原则，预录取进城务工人员（市内）适龄随迁子女。

5. 第五批 预录取腾冲市民族中学民族生。根据城区初中报名人数和学位数确定腾冲市民族中学招收民族生的人数。待城区初中各学校录取结束后，根据腾冲市民族中学学位空额情况，录取该校初中民族生。当报名人数小于或等于空额学位数时，直接录取报名对象；当报名人数大于空额学位数时，按照以下三个批次顺序进行录取：（1）录取小学毕业生人数超过招生规模数的乡镇的腾冲籍民族生，录取人数为超规模数，以保证该乡镇新招生不出现大班额；（2）录取腾冲籍六种世居少数民族（傈僳族、傣族、回族、白族、佤族和阿昌族）；（3）录取腾冲籍其他少数民族。

（三）预录取办法

系统根据志愿先后，按照批次顺序自动进行预录取。

1. 在预录取第一志愿时，当上一批预录取后有剩余招生指标的，则启动下一批预录取；当预录取到某一批次出现报名人数超过该校招生指标时，系统自动进行随机抽取，被抽到的，则预录入所报名学校，此时该学校额满；未抽到的，则依据第二志愿来预录取；

2. 同理操作预录取第二志愿，如果第二志愿所报学校已经满额，则依据第三志愿来预录取；

3. 同理操作预录取第三志愿，如果第三志愿所报学校已经满额时，对于在“是否服从调配”栏选择了“是”的，系统通过随机抽取的办法自动调配到有空额的学校入学；如果学校不再有空额，抽取剩下的人员，属腾冲市户口的，回户口所在地学校就学，属腾冲市外户口的，到腾冲市城市社区以外的学校联系就学。

4. 预录取第二、三志愿时，有报名依据的优先录取。

5. 根据教育部“教育资源不够均衡的地方，稳妥实施多校划片，采取随机派位方式入学”的要求，对设定学位数少于报名数的学校通过多校划片随机派位方式安排入学。

（四）验证和注册报到

1. 被预录取的，系统上会显示预录取结果，同时会收到预录取短信，按照短信提示的时间和要求，到预录取学校进行验证和注册报到。

2. 在报名条件中属于“有证件”被预录取的，验证时，提供被录取的依据材料，确认上传证件与原件信息一致的，通过验证；

3. 在报名条件中属于“无证件”被预录取的，验证时，提供填报第一志愿时上传的证件原件，确认上传证件与原件信息一致的，通过验证；

4. 通过民族中学民族生报名通道录取到腾冲市民族中学的，提供户口簿，确认户口簿上登记的民族与报名依据的民族一致的，通过验证；

5. 验证时，对报名信息与证件原件信息不一致的，经确认为弄虚作假者，取消预录取资格；

6. 通过验证的，在网上进行公示，公示无异议者，发“义务教育入学通知书”短信。

五、优待照顾政策

（一）烈士子女、符合条件的现役军人子女、公安英模和因公牺牲伤残警察子女、2020年新冠肺炎疫情我市援助湖北医疗队员子女、见义勇为人员或其子女、孤儿及其他各类符合条件的优待对象，经相关部门认定并提供书面证明材料的，可根据实际居住地选择就读学校（提供对应部门证明材料和本人相关证明到教育体育局基础教育股盖章确认并登记）。

（二）在职在编的教职工子女可在父（母）现任职学校就读（提供对应学校证明并到教育体育局基础教育股核准盖章确认）。

（三）位于腾冲市境内的招商引资企业，非腾冲市户籍的法定代表人、副董及以上管理人员根据《腾冲市关于招商引资企业相关人员子女就读腾冲市义务教育阶段公办学校优待办法（试行）》，经腾冲市投资促进局审核盖章，交教育体育局基础教育股核准盖章的，可根据实际居住地选择就读学校。

六、工作纪律要求

（一）工作要求

1. 所有城区内的义务教育学校不得招收未在本招生报名系统注册及报名注册未被录取的适龄少年。

2. 学生学籍按实际录取名单由教育体育局统一导入学籍系统，以后不再办理转学。

（二）纪律要求

1. 严肃工作纪律，杜绝营私舞弊，违者追究相关人员责任。

2. 严禁容留借读、寄读、旁听生和空挂学籍。

七、其它事项

（一）户口在城区中学招生片区内，但不在城区中学招生片区内完成小学教育的，请于2020年8月1日前带户口本到腾冲市教育体育局基础教育股审核并录入本年度城区初中招生数据库。

（二）户口在城区中学招生片区外但具有城区中学报名条件的，办理条件如下：请于2020年8月1日前办理小升初异地入学手续（省内小学毕业生请使用附件4“小升初异地入学申请表”，省外小学毕业生请使用附件5“中小学学生跨省升学申请表”）。手续完善的，录入本年度城区初中招生数据库，获得初中一年级报名资格。

（三）所提供户口簿、房产证（购房合同）、营业执照办理时间截止于当年招生通告发布之日前有效。

（四）提供腾越派出所居住证明的，居住时间必须在通告发布之日前。

（五）根据《腾冲市城区义务教育阶段公办学校2019年招生通告》第七项之第5项，2019年6月22日之后办理的挂靠户口不得作为报名依据。

（六）不在有效报名时间内报名者，视为自动放弃报名资格。报名成功后，关注短信提示或网络提示，按提示要求进行处理。
