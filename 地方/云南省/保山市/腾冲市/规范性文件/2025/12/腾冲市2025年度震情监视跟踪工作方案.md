# 腾冲市2025年度震情监视跟踪工作方案

根据2025年全国地震趋势会商会意见，为切实做好年度重点危险区震情跟踪工作，全面提升地震灾害风险防范和应对处置能力，有效减轻地震灾害损失，按照《云南省地震局关于印发2025年云南省震情监视跟踪和应急准备实施方案的通知》，结合腾冲实际，修订完善我市震情监视跟踪工作方案。

一、工作目标

深入学习贯彻习近平总书记防灾减灾救灾重要论述和防灾减灾重要指示批示精神，认真贯彻落实国家、省、市地震局和腾冲市委市政府的决策部署，坚持“人民至上、生命至”上，牢固树立“震情第一”观念，提高政治站位，加强组织领导，强化责任落实，围绕防大震、抗大灾跟踪监视工作重点，聚焦辖区震情监视跟踪研判，切实提升地震监测预报、灾害风险防治和应对处置能力。

二、组织领导

（一）成立腾冲市震情监视跟踪工作领导小组

组 长：杨朝甦、孙自刚

副组长：黄治波、李丹、刘克骧

成 员：马学智、张综甫、李枝安、谷正湘、何从昌、白会珍、黄智及腾冲地震监测中心站全体干部职工。

主要职责：贯彻落实全国、全省和全市强化监视跟踪和应急准备工作部署；负责腾冲市震情监视跟踪组织领导；组织开展腾冲市震情跟踪准备工作；研究和协调解决工作中的重大问题；审议批准震情跟踪工作方案；决策、落实、协调、检查、调整震情跟踪准备工作内容。

领导小组成员主要由腾冲市防震减灾局在职工作人员、腾冲地震监测中心站工作人员组成，如遇岗位调整由接任者自动顶替。领导小组的日常工作由市防震减灾局监测预报中心及腾冲地震监测中心台站业务室配合完成。

三、工作措施

（一）加强地震监测工作

1. 持续优化台网布局。全力推进腾冲“十五五”防震减灾规划项目实施，配合实施好2024年全国地震系统“巨灾防范工程”科学谋划好腾冲市内“防震减灾+”重点工程，配合中国地震科学实验场建设云南项目设计腾冲的4个化学站点的建设工作。（责任单位：腾冲地震监测中心站、局观测预报中心）

2. 加强地震监测台网运维管理。认真贯彻落实《保山市地震监测预报质量提升行动方案》，切实加强仪器设备的巡检、标定和维护工作，严密监控各类地震观测仪器的运行状态，及时排除故障与干扰，保障台网系统正常运行，观测资料连续可靠。

（责任人：马学智、段胜朝、何从昌、番绍辉、张山元）

3. 进一步完善地震监测质量管理体系。建设高效的监测运维技术保障系统，规范和保障地震监测站网运维工作，保障数据链路稳定，确保各类观测传输系统的正常运行级观测数据的及时汇集、处理、传输与共享。节点设备故障做到24小时内修复，通讯类故障按照与供应商约定的修复时间执行。确保无线通讯系统的正常运行。（责任人：马学智、何从昌、张综甫、段胜朝、张山元）

4. 加强地震监测设施和地震观测环境保护。强化地震观测台站日常监管，建立健全巡查制度，密切关注破坏、影响地震监测设施和观测环境行为，第一时间介入并依法予以制止。适时开展新建台站监测设施和观测环境保护范围备案工作，加强对台站观测环境的保护，确保观测数据连续稳定可靠。（责任人：黄治波、郑洋、马学智、何从昌）

5. 加强与腾冲地震监测中心站的密切合作。充分发挥腾冲地震监测中心站专业技术力量，在监测站点改造提升、监测设备标定和检查、监测站点巡检和异常核实等方面，加强与腾冲地震监测中心站的协作配合，保障全市监测网点观测仪器的正常运行，确保观测数据连续可靠，为监视跟踪全市乃至全省震情提供有力支撑。

6. 强化队伍建设。围绕地震监测预报业务能力提升，强化地震监测预报人才队伍建设，积极参与省市地震监测预报业务培训，建立与腾冲地震监测中心站之间监测预报人员交流机制，不断培养复合型业务人才。（责任人：杨朝甦、黄治波、李丹、马学智、何从昌）

（二）提升地震预报预警能力和服务水平

1. 丰富地震预报服务产品。以服务市委市政府决策为出发点，完善地震长中短临预报服务产品清单。进一步完善地震安全保障服务机制，持续做好重大活动和特殊时段地震安全保障工作，及时为重大活动或特殊时段提供震情专项服务，主动为经济社会发展提供地震安全保障。（责任人：黄治波、、李丹、谷正湘、张综甫、李枝安、黄志）

2. 不断提高地震预报服务政府社会能力。强化地震趋势研判和震情监测跟踪，严格执行重大震情通报制度，及时研究提出应对防范措施建议，全力协助推动政府及应急管理部门做好地震应急准备与风险防范工作，积极推动将地震预报意见转化为实际减灾行动。（责任人：谷正湘、马学智、张综甫、何从昌）

3. 强化舆情监视和引导。健全完善地震谣言应对处置机制，强化地震舆情监视，主动引导舆情，切实维护社会和谐稳定。（责任人：李丹、谷正湘、张综甫、李枝安、白会珍、黄志）

4. 强化预警站网运行保障能力。健全地震预警系统联合运行维护保障工作机制，优化预警技术系统全链条业务流程，完善风险防控机制。强化技术支持和技能培训，提高专业人员科研创新能力，确保地震预警服务及时性和可靠性，让预警工程更好服务高质量发展。（责任人：黄治波、谷正湘、何从昌）

（三）强化异常调查核实

1. 不断健全完善工作机制。进一步修订完善震情短临跟踪协同工作机制，落实好宏观异常报告、现场核实和震情会商制度，完善异常分级、分类现场调查核实工作机制，建立健全异常核实技术规范，确保宏微观异常现场调查核实属地责任落到实处。〔责任人：黄治波、马学智、段胜朝、何从昌、〕

2. 严格执行宏微观异常零报告制度。严格执行《宏微观异常零报告制度》，按照分级负责的原则，每天对辖区内正常观测的各项资料进行处理分析，动态监视跟踪各项观测资料，发现异常及时核实并立即上报。〔责任人：马学智、何从昌〕

3. 及时开展异常调查核实。严格执行《云南省地震前兆观测资料异常核实工作实施细则》，按照第一时间发现、第一时间调查处理、第一时间分析研判的工作要求，及时组织开展好辖区内异常的现场调查核实工作，确保发现的宏微观异常做到发现一起核实一起，重大异常核实上报不超过24小时。及时提交调查核实表，并上报市局分析预报科和云南省地震台相关业务部门。对特别重大异常，申请市局业务人员到现场对异常进行核实和分析研究，必要时可请求省地震局专家对异常进行现场调查核实。通过组织开展异常现场核实工作，把牢异常调查核实研判关，为开展地震预报工作打牢基础。〔责任人：马学智、段胜朝、何从昌）〕

（四）加强震情跟踪研判

1. 严格执行会商制度。健全完善震情监视跟踪工作方案并组织实施；规范开展月、年度等日常会商和加密会商、特殊节点会商；参加保山市地震局组织召开的会商；当辖区内发生3级以上、邻区发生5级以上地震和出现突出宏微观异常、作出重大地震预测意见时，要及时组织召开紧急、加密会商会，形成会商意见，必要时须提请腾冲地震监测中心站召开专题会商会，从技术层面为落实震情会商制度和“异常零报告”制度提供保障。每月3日前须将《月震情分析》以电子版形式报保山市局分析预报科，每年 5月、9月上旬在组织召开年中和年度地震趋势会商会的基础上，须将年中和年度地震趋势研究报告报市局分析预报科。若保山市内发生5级以上地震，组织开展为期7天的加密会商，并于每天下午16:00前将加密会商意见上报市局分析预报科。（责任人：马学智、何从昌）

2. 扎实做好观测数据分析处理工作。实时跟踪分析本地区正常观测的各项观测数据资料，充分利用现代化信息技术手段，加强对监测数据的研究，多途径探索，多方法应用，全面提升观测资料异常识别和分析研判能力，不断健全完善地震形势预测、危险区确定和短临预报指标体系，促使基于预测指标的地震综合概率预测业务能力得到提升。〔责任人：马学智、何从昌）〕

3. 抓实区域内震情监视跟踪工作。认真履行成员单位工作职责，开展好震情监视跟踪有关工作。同时，加强与市地震局、腾冲中心站之间的沟通协调，促进合作与交流，推进信息互联互通、资源共享共用，较快较好实现区域地震预测预报探索工作。〕

4. 创新推进群测群防工作。健全完善新时代群测群防工作机制，深入推进群测群防工作队伍建设，加强宏观测报点的建设与管理，切实做好地震宏观现象的观测和信息上报、联络等工作，充分发挥好群测群防在地震短临预报中的积极作用。每年至少要组织开展1次群测群防工作业务培训。〔责任人：杨朝甦、黄治波、李丹、郑洋、谷正湘、张综甫、马学智、白会珍）

（五）做好信息服务工作

1. 强化信息报送。做好本辖区地震预测意见的管理及时报告保山市地震局。每月按要求向市委、市政府报送《月震情分析意见》。年度和年中地震趋势会商后，若出现显著地震活动、重大地震预测意见、显著宏微观异常等，主动向市委、市政府报告地震预测意见，提出有效对策建议，为政府决策提供震情信息服务。严格落实领导带班和震情值班制度，若发生震情，按要求及时向市委市政府及市抗震救灾指挥部成员有关单位报告震情。（责任人：办公室人员、观测预报中心人员）

2. 强化新闻宣传。创新宣传内容和方式，发挥好网站和新媒体平台的优势，持续做好日常和重点时段的新闻宣传。突发地震事件发生后，及时组织人员深入震区开展地震科普知识宣传，并视情况参与政府震后新闻发布会，主动发声，积极稳妥回应社会关切，切实维护社会和谐稳定。（责任人：李丹、张综甫、谷正湘、白会珍、黄志）

3. 强化科普宣传。持续推进防震减灾知识“六进”活动和“地震科普携手同行”主题活动，打通防震减灾服务基层“最后一公里”。全力推进“互联网+防震减灾科普”行动计划，充分发挥微博、微信、手机客户端等新媒体和广播、电视、报刊、图书等传统媒体在防震减灾科普宣传中的作用，不断提升社会公众防震减灾意识和自救互救能力。（责任人：李丹、谷正湘、张综甫、白会珍、李枝安）

4. 强化舆情处置。加强与宣传、公安、应急等有关部门和新闻媒体的沟通协调，协助并配合省地震局做好地震谣传应对处置工作。发现地震谣传和舆情事件时，及时向市委、市政府和保山市地震局报告。及时收集涉震舆情信息，根据舆论声量、扩散范围和影响规模，将舆情事件分类，对应启动相应级别响应，并开展涉震舆情处置工作。认真总结涉震舆情处置工作经验和教训，分析存在问题和不足，不断提升涉震舆情处置能力。对重大舆情事件的处置要形成专报，及时报市委、市政府和保山市地震局。（责任人：李丹、谷正湘、张综甫、白会珍、李枝安）

四、保障措施

（一）统一思想认识。各单位、各科室要充分认识所面临的严峻复杂的震情形势，切实把震情监视跟踪工作作为重要政治任

务，扛在肩上、抓在手上，以高度的思想自觉和行动自觉，全力

做好震情监视跟踪各项工作，为全市经济社会高质量跨越式发展

提供强有力的地震安全保障。

（二）强化组织领导。加强对震情监视跟踪工作的组织领导，不断健全完善组织体系和责任体系，进一步明确人员职责和任务，不断提高震情监视跟踪实效。主要负责人作为年度震情监视跟踪工作第一责任人，对本单位年度震情监视跟踪工作负总责，要做到亲自研究部署，亲自安排推动，亲自督促落实。

（三）强化责任落实。各科室要加强协调配合，按照责任分工，落实好工作责任，形成抓落实的合力，推动震情监视跟踪工作有力有序有效开展，确保做到“守土有责、守土负责、守土尽责”。

（四）加强督促检查。加强对全市震情监视跟踪工作检查督促，并及时通报督查情况。对工作推进不力或工作完成质量不高的科室和个人，将按照有关规定进行通报批评或追究工作责任。
