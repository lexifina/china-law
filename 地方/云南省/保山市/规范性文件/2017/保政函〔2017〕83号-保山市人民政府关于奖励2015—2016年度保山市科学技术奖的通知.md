# 保山市人民政府关于奖励2015—2016年度保山市科学技术奖的通知

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

根据《中共保山市委办公室 保山市人民政府办公室关于印发保山市科学技术奖励办法（试行）的通知》（保办发﹝2006﹞161号）规定，2015—2016年度保山市科学技术奖共评选出突出贡献奖项1人，技术发明类和科技进步类奖项50项。经市人民政府同意，决定授予濮永华同志为保山市科学技术奖突出贡献奖，授予“HWZY—4水能鱼苗孵化器”成果为保山市科学技术奖技术发明类三等奖，授予大麦抗旱减灾技术集成及示范推广等4项为保山市科学技术奖科技进步类一等奖、隆阳区整县制一季中稻平均亩产700千克技术集成与应用等8项为保山市科学技术奖科技进步类二等奖、多抗粳稻品种岫粳20号选育应用等37项为保山市科学技术奖科技进步类三等奖（具体名单见附件）。

希望获奖者再接再厉，勇攀高峰，再创辉煌。全市广大科技工作者要向获奖者学习，继续发扬与时俱进、团结协作、顽强拼搏、开拓创新的精神，大力推进科技创新，加速科技成果向现实生产力转化，努力创造更多支撑和引领经济社会跨越发展的科技成果，为建设创新型保山作出新的更大贡献。

附件：2015—2016年度保山市科学技术奖奖励人选、项目及等级

保山市人民政府
