# 保山市人民政府办公室关于印发政府门户网站重点领域信息公开专栏建设规范的通知

各县（市、区）人民政府，市直各委、办、局：

为进一步加强和规范重点领域信息公开，充分发挥政府门户网站在政府信息与政务公开中的第一平台作用，根据《云南省人民政府办公厅关于印发政府门户网站重点领域信息公开专栏建设规范的通知》（云政办函〔2017〕95号），市人民政府组织编制了《政府门户网站重点领域信息公开专栏建设规范》（以下简称《建设规范》），现印发给你们。请各县（市、区）人民政府结合实际，于2017年11月底前完成政府门户网站重点领域信息公开专栏建设；请市直有关单位依据《建设规范》要求，在网站后台引用重点领域信息公开专栏，于2017年8月底前完成建设，并及时发布内容。

保山市人民政府办公室

2017年7月6日

（此件公开发布）
