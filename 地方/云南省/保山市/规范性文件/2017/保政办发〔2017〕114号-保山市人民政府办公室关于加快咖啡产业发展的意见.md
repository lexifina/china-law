# 保山市人民政府办公室关于加快咖啡产业发展的意见

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

为深入贯彻落实市委、市人民政府着力推进重点产业发展的有关部署，促进全市咖啡产业健康发展，加快推进咖啡产业做大做强，经市人民政府同意，现提出如下意见：

一、总体要求

（一）指导思想

全面贯彻落实党的十八大和十八届三中、四中、五中、六中全会精神，深入学习贯彻习近平总书记系列重要讲话精神和考察云南重要讲话精神，牢固树立和贯彻新发展理念，主动服务和融入国家发展战略，立足区位、资源等优势，稳步扩大精品咖啡原料基地面积，加快改造提升咖啡加工业，强力推进咖啡品牌打造，把我市建设成为世界优质咖啡豆原料基地、全省重要的咖啡精深加工生产基地，积极招商引资建成保山咖啡豆交割仓和贸易中心，构建一二三产业融合发展的现代咖啡产业体系，实现从咖啡原料大市向咖啡加工、咖啡旅游、咖啡贸易和咖啡文化强市转变。

（二）基本原则

市场主导，政府推动。充分发挥市场在资源配置中的决定性作用，强化企业的市场主体地位，以市场需求确定咖啡产业发展方向，推进产业结构调整和生产要素整合。强化政府在加快咖啡产业发展中的组织领导、顶层设计、政策制定、公平竞争市场秩序维护等宏观指导作用。

创新驱动，协同发展。引导企业把创新摆在产业发展的核心位置，强化科技创新引领作用，推动产业转型升级，实现产业可持续发展。支持企业在高校创建咖啡产业创新创业实践基地，推动大众创业、万众创新。

龙头带动，品牌引领。坚持扶优扶强，重点支持市场带动力强、发展规模大、发展前景好、效益突出的龙头企业，积极引进先进科技和管理经营人才，着力培育规模优势明显、工艺技术领先、品牌竞争力强的行业“小巨人”和企业集群。大力实施品牌战略，全面提升“保山小粒咖啡”品牌知名度、影响力和带动力。

智能制造，“两化”融合。以绿色生态、质量安全和循环经济为导向，推进“互联网+”与咖啡产业深度融合，用智能化改造提升咖啡原料种植、产品设计、生产制造、管理服务和金融贸易水平。利用“互联网+”推进咖啡产业供给侧结构性改革，推动生产方式与消费方式创新，促进一二三产业协同发展。

（三）发展目标

1.总量目标。到2020年，全市优质咖啡园保持在30万亩左右，总产量达6万吨以上，产值比“十二五”末翻一番，达到20亿元（其中农业产值10亿元）；出口创汇翻一番，达到5000万美元；电商销售收入增6倍，达到3亿元。

2.基地发展目标。以巩固提升隆阳区、龙陵县、高黎贡山旅游度假区的最佳适宜区现有面积为重点，按照逐步淘汰次适宜区、适度发展最佳适宜区的原则，走精品化、规模化、特色化发展路子，全市每年新植精品咖啡园0.5万亩，改造中低产咖啡园1万亩。在保持现有咖啡种植面积的基础上，加强原料基地建设，重点支持种植面积达到0.3万亩、产量300吨以上的生产大村。

3.企业发展目标。支持咖啡产业龙头企业做大做强，推进本土企业与国际咖啡巨头战略合作，到2020年，争取培育1—2户咖啡上市企业，力争注册登记的咖啡电商企业发展到50户、从业人员3000人、交易额3亿元以上；重点培育电商年销售收入3000万元以上的企业2户、2000万元以上的5户、1000万元以上的10户。

4.技术创新目标。到2020年，规模以上咖啡加工企业研发经费支出占主营业务收入比重达1.5%左右，推动建设咖啡行业省级技术中心和一批市级企业技术中心，成立保山咖啡工程研究中心。

5.品牌培育目标。到2020年，新增云南省著名商标1个、保山市著名商标5个。

二、重点任务

（一）发展咖啡现代农业

进一步优化咖啡农业区域布局，按照“绿色、有机、生态”的消费趋势，运用现代工业经营管理理念，大力推进“龙头企业+基地+合作社+农户”模式，建立咖啡农场（家庭）、咖啡小镇、咖啡生态旅游园等集约化经营组织，推动咖啡种植业从传统小规模经营向现代农业规模化经营转变，加快形成新的产业发展方式。以“互联网+”为核心，在咖啡种植、采收、初加工、存储、运输、交易和管理等环节，引导鼓励龙头企业推广电子商务、线上线下融合、智能制造等应用，促进土地、人力、资金、技术、设备资源共享，有效解决咖啡豆良种培育、种植技术推广、咖啡园管护、庄园建设、标准化种植、初加工技术标准化和农业市场信息不对称等问题，实现农业生产要素优化配置，促进我市咖啡品质逐年稳定提高，全面提升咖啡种植业价值链效益。（市农业局牵头负责；市工业信息化委、科技局、商务局，隆阳区人民政府、龙陵县人民政府、高黎贡山旅游度假区管委会配合）

（二）提升咖啡工业信息化水平

深化物联网、云计算、大数据等与咖啡产业研发、生产、服务和管理等融合发展，重点推动信息化在咖啡产品工业设计、生产流程、物流配送等关键环节深度应用和综合集成，大幅提升我市咖啡产品智能化水平。实施传统咖啡制造工艺智能制造应用示范，实现传统产业转型升级。通过异地协同设计、个性化定制、网络众包、云制造等研发、生产新模式，引导咖啡制造企业满足消费者个性化、多样化、定制化消费需求，开发符合市场定位的咖啡产品及衍生品，催生咖啡产品消费新业态，实现咖啡产业“增品种、提品质、创品牌”。通过打造先进生产体系，推动咖啡产业向信息化、智能化、服务化、集群化发展，促进一二三产业融合发展。（市工业信息化委牵头负责；市科技局、农业局、商务局，隆阳区人民政府、龙陵县人民政府、高黎贡山旅游度假区管委会配合）

（三）推动龙头企业集聚发展

依托龙头企业，充分发挥保山交通、区位、人才、资本、仓储、气候等优势，打造一二三产业融合发展的保山咖啡产业园区。强化产业链招商，引入国内外具有创新能力和创新优势的企业，通过先进技术改造提升传统产业，提高附加值、延伸产业链条，向产业链终端和价值链高端发展。以项目带动、技术创新、品牌建设为转型升级的重要抓手，按照“扶优、扶大、扶强”的原则，推动资金、项目、技术、土地等政策和资源向优势区域集中，鼓励1—2户产业基础好、带动能力强的企业在潞江、芒宽、杨柳、腊勐、木城等咖啡主产区布局建设咖啡精深加工生产线，对现有品牌进行深度开发，扩大产品市场份额，发展成为规模优势明显、工艺技术领先、品牌竞争力强的标杆龙头企业，打造精品咖啡核心基地，促进全市咖啡产业实现集团化、集群化发展。（市工业信息化委牵头；市质监局、招商合作局，隆阳区人民政府、龙陵县人民政府、高黎贡山旅游度假区管委会配合）

（四）构建咖啡产业发展平台

依托纽约期货交易所和云南国际咖啡交易中心，进一步推动我市咖啡制造业与原料基地协同发展、与服务业融合发展，着力将保山建设成为国内连接东南亚地区重要的咖啡豆集散地，扩大现货交割交易量，为我市咖啡产业链参与主体提供优质便捷的信息、交易、结算、仓储物流、融资增信等服务。建立咖啡豆收储机制，稳定市内咖啡市场价格，促进咖啡制造业规范化、高附加值化和可持续化发展，持续推动我市咖啡产业发展壮大。（市商务局牵头负责；市工业信息化委、农业局、金融办，腾冲海关、腾冲出入境检验检疫局，隆阳区人民政府、高黎贡山旅游度假区管委会配合）

（五）建立健全咖啡标准体系

组建市级咖啡标准化体系建设专家委员会，适时推动其升级为省级咖啡标准化体系建设专家委员会。借鉴国际咖啡生产技术标准，依托我市有关咖啡地方标准，加强与省级有关部门衔接，积极参与咖啡省级标准制定工作，推动具有我市特色的咖啡地方标准上升为省级标准。（市质监局、科技局、农业局按照职责分工分别牵头负责；市发展改革委、工业信息化委配合）

（六）强化品牌宣传

充分利用电视、报纸、广播、新闻媒体等，多形式、多维度宣传保山小粒咖啡地域品牌和产品品牌，充分利用各类会展、保山端阳花市等活动，将咖啡工业制造、旅游观光、文化传播和品牌宣传相结合，提升我市咖啡的国内国际影响力。支持市咖啡商会牵头成立保山咖啡行业协会，加强与国际咖啡组织和品牌的对接联系。（市政府新闻办、民政局、商务局按照职责分工分别牵头负责；市工业信息化委、农业局、文化广播电视新闻出版局、旅游发展委，隆阳区人民政府、龙陵县人民政府、高黎贡山旅游度假区管委会配合）

（七）加大市场开拓力度

积极争取有关保税政策，优化我市咖啡进出口贸易环境。鼓励咖啡企业进行转口贸易、加工贸易，积极参与世界咖啡贸易。支持企业拓宽终端销售渠道，积极为企业创造市内外展销条件，帮助企业开拓国内国际市场。依托高校校企创业孵化平台资源，激发高校师生将咖啡和创新创业紧密联结，培养新消费群体对我市咖啡的品饮习惯。发挥旅游资源丰富的优势，开发适应旅游消费习惯的产品，协助咖啡企业对接旅游景区安放咖啡产品自动售卖机等方式，助推更多消费者了解和消费我市咖啡产品。（市商务局牵头负责；市工业信息化委、文化广播电视新闻出版局、农业局、旅游发展委，隆阳区人民政府、龙陵县人民政府、高黎贡山旅游度假区管委会配合）

三、保障措施

（一）加强组织领导

市人民政府统筹推动全市咖啡产业发展，进一步加大部门间的沟通协调力度，强化对涉及产业发展重大问题的协调解决，及时研究产业发展中出现的新情况新问题，结合我市实际，有针对性地出台政策措施。充分发挥隆阳区人民政府、龙陵县人民政府、高黎贡山旅游度假区管委会对咖啡产业发展的主导作用，形成上下联动、协调推进的发展局面。（市农业局牵头；隆阳区人民政府、龙陵县人民政府、高黎贡山旅游度假区管委会及市直有关部门配合）

（二）优化发展支撑环境

进一步完善财税、金融等扶持政策，整合项目、资金、技术、人才等，加大对咖啡产业发展的支持力度，夯实产业发展基础。突出重点，加大对一二三产业融合发展标杆企业的财政扶持力度，提高龙头企业带动产业发展能力。（市财政局、工业信息化委，市国税局、地税局按照职责分工分别牵头负责；隆阳区人民政府、龙陵县人民政府、高黎贡山旅游度假区管委会配合）

（三）强化产业基金引导

依托“51+49”股权模式、产业发展基金等，充分发挥基金对咖啡产业发展的引领带动作用，扶持咖啡产业做大做强。积极推动金融机构加大对我市咖啡产业的支持力度，引导社会资本、大型国企等积极参与咖啡产业发展，从股权投入方面探索咖啡产业发展模式。（市财政局牵头负责；市发展改革委、市工业信息化委、市农业局、市金融办，隆阳区人民政府、龙陵县人民政府、高黎贡山旅游度假区管委会配合）

（四）强化科技创新引领

积极支持咖啡企业与高等院校、科研院所建立合作平台，建设一批特色鲜明、重点突出、机制完善的咖啡产业技术创新平台。加强咖啡行业重大关键技术研发，积极组织相关企业申报国家和省科技计划项目，加快具有知识产权的科技成果转化。（市科技局牵头负责；市工业信息化委、农业局、商务局，隆阳区人民政府、龙陵县人民政府、高黎贡山旅游度假区管委会配合）

（五）强化人才智力支撑

以高层次和高技能人才队伍建设为重点，着力引进、培育一批在关键核心技术产业化、产品开发、创新经营管理模式、市场开拓等方面具有突出贡献的领军人才和紧缺人才。加大对企业核心技术开发有突出贡献、起关键作用人才的激励力度，鼓励企业实施高薪、期权期股、技术入股等政策，提升重点企业研发岗位吸引人才、稳住人才的竞争力。支持咖啡制造企业与市内外高等院校、技工院校、科研院所合作，培养市内咖啡产业急需的科研人员、技术技能人才和复合型人才。（市人力资源社会保障局、工业信息化委按照职责分工分别牵头负责；隆阳区人民政府、龙陵县人民政府、高黎贡山旅游度假区管委会配合）
