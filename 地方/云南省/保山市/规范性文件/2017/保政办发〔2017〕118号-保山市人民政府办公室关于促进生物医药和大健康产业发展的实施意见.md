# 保山市人民政府办公室关于促进生物医药和大健康产业发展的实施意见

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

为深入贯彻落实《云南省人民政府办公厅关于促进医药产业健康发展的实施意见》（云政办发〔2017〕15号），结合全市重点产业发展思路，经市人民政府同意，现提出以下意见：

一、总体要求

（一）基本思路

全面贯彻党的十九大以及习近平总书记系列重要讲话精神，以“五大发展理念”为引领，认真落实市委、市人民政府关于重点产业发展的决策部署，以市场需求为导向，做大做强中医药，着力推动生物技术药、化学药产业发展，推进医药产业向大健康产业转型，满足人民群众多层次、多样化的健康需求，加快构建特色鲜明、布局合理、结构优化、创新力强的医药产业体系。

（二）发展原则

——科技支撑，创新发展。建设产业公共服务平台，推动创新资源集聚，强化企业创新主体地位，加快创新转化，完善医药协同创新体系，积极开发具有自主知识产权的产品，改造提升传统产品。

——资源整合，规模发展。内培外引，推进医药企业联合、重组，优化资源配置，发展医药产业集群。支持医药领域重大项目建设，培育一批龙头骨干企业。

——突出优势，特色发展。依托丰富的生物资源和中药产业基础，加强关键技术的研发和传统优势品种的深度开发，积极发展现代生物制品，形成一批拥有自主知识产权的创新药物，提高产业竞争力。

——提升质量，绿色发展。引导中药企业规范种植（养殖），推行企业绿色化生产、园区集聚化发展，健全医药流通信息网络和产品质量追溯体系，促进医药产业改造升级和安全发展。

——招商引智，借力发展。围绕优势资源和产业导向，开展专业招商、引进龙头企业、高端人才和重大项目，做大产业增量。

（三）发展目标

到2020年，全市生物医药和大健康产业规模进一步壮大，资源开发利用率大幅提高，核心竞争力明显提升；体制机制逐步完善，产业发展环境显著改善；生物医药和大健康产业主营业务收入达到95亿元，年均增长20%左右。

二、主要任务

（一）积极发展生物医药产业

以保山动植物、微生物药用资源为基础，运用现代生物技术，发展生物技术药物和现代中药。鼓励市内医药骨干企业推进生物医药开发，重点支持发展腾药心脉隆注射液、美洲大蠊系列产品、东方红制药肠胃宁片、品斛堂龙陵紫皮石斛、施甸海瑞迪水蛭冻干粉、保山泽元藻业雨生红球藻、龙陵河头蜂毒提取、保山山田红豆杉开发、中牧股份动物疫苗等高新技术产品，增强企业技术创新能力，提高大宗常用药品的市场占有率。开发和应用现代中药提取纯化技术和符合中药特点的制剂技术，推广质量控制、自动化和在线检测等技术在中药生产中的应用。创新医药研发模式，鼓励开展研发外包服务；鼓励企业与科研机构深度合作，建立完善产学研用协同创新体系，加大新药研发、仿制药一致性评价以及中药二次开发支持力度。加强保健食品、中药饮片、化妆品等健康类产品开发与生产。（牵头单位：市科技局；配合单位：市发展改革委、工业信息化委、商务局、招商合作局、人力资源社会保障局、食品药品监管局、卫生计生委、财政局、林业局）

（二）健全发展医疗服务体系

构建多元化的医疗服务格局，提升医疗机构服务能力。进一步抓好人才引进和培养，全力推进卫生基础设施建设，加快推进信息化建设，加强重点学科、院士专家工作站和医院创等达标等工作。继续深化县级公立医院综合改革，全面推开城市公立医院改革，落实政府办医的领导、保障、管理和监督4项责任，加快建立现代公立医院管理制度，进一步调动医务人员的积极性、创造性，严格控制公立医院医疗费用不合理增长。以家庭医生签约服务为抓手，以人才下沉和资源利益共享为导向，引导二级以上医院向下转诊诊断明确、病情稳定的慢性病患者，加快推进分级诊疗。抓好重大疾病防控，实施好基本公共卫生服务项目，提高人民健康素养。健全基层医疗卫生服务运行机制，进一步提升基层服务能力。以争创全国基层中医药工作先进市为抓手，实施好基层中医药服务能力提升工程，进一步提高基层中医药服务能力。加大中药（民族药）的开发力度，支持各级中医医院挖掘开发名中医及民间祖方、验方，加快推出一批作用机理明确、技术含量高、疗效可靠的医院制剂和药物。积极发展中医“治未病”养生保健服务，不断规范中医养生保健服务管理。（牵头单位：市卫生计生委；配合单位：市发展改革委、财政局、工业信息化委、人力资源社会保障局）

（三）加快推进旅游养生产业发展

以全域旅游10项重点工作、旅游品牌化8项重点任务为抓手，推进生物医药和大健康产业与旅游融合发展，统筹利用全市温泉、气候、森林、医疗、中医药、红色旅游等优势资源，规划建设集养生、养老、医疗、康复与休闲度假于一体的医药健康旅游基地。（牵头单位：市旅游发展委；配合单位：市发展改革委、卫生计生委、国土资源局、民政局）

（四）加快养老产业发展

抓好城市公办养老机构和农村敬老院建设，积极推进居家养老服务中心和村（社区）养老服务中心建设，鼓励社会资本兴办养老机构，探索发展区域性养老服务中心建设。（责任单位：市民政局）

（五）加快体育产业发展

推动体育与医疗、文化等融合发展，发展户外运动、运动康复、健身培训等体育服务业。加强培养体育旅游项目，完善配套基础设施建设，形成特色体育旅游产品和线路。（责任单位：市体育局）

（六）加快中药材产业发展

着力推进中药材种植（养殖）基地规范化发展，搭建中药材资源信息沟通桥梁，抓好4个万亩中药材标准化基地建设，建设中药材初加工厂，加强中药材、中药生产、流通及使用追溯体系建设。加强药食同源产品等健康类产品开发与生产。加强中药资源保护利用，通过中药资源普查工作，筛选区域优势中药品种，做好种子种苗基地建设，结合精准扶贫工作，扶持和指导山区乡镇组建中药材种植合作社，推动中药材科学种植和规模种植。（牵头单位：市农业局；配合单位：市食品药品监管局、林业局、卫生计生委）

（七）强化药品质量管理、供应保障和标准体系建设

全面实施并严格执行药品生产质量管理规范（GMP）、药品经营质量管理规范（GSP），实行全员、全过程、全方位质量管理，健全药品安全追溯体系。强化企业是药品质量安全第一责任意识，督促药品生产企业全面提升质量管理水平。推动企业建设遍及城乡的药品流通配送网络，提高基层和边远地区药品供应保障能力。按照国家药品标准体系，完善、提升药品等生产技术规范和质量控制标准。（牵头单位：市食品药品监管局；配合单位：市商务局、质监局）

三、政策保障和组织实施

（一）强化组织领导

成立市生物医药和大健康产业领导小组（名单见附件），负责统筹协调各项工作，及时制定配套措施，抓好政策落实，形成政策叠加效应和强大合力。领导小组下设办公室在市科技局，负责组织协调日常事务。设立市生物医药和大健康产业发展专家咨询委员会，为产业发展提供决策参考和智力支持。（牵头单位：市科技局；责任单位：市生物医药和大健康产业领导小组成员单位）

（二）加大扶持力度

制定出台促进生物医药和大健康产业发展专项扶持政策，加大投入力度。用好支农惠农和退耕还林等政策，支持规范化和标准化种植（养殖）基地建设。支持全市生产的医药品种进入全省基本药物目录和医保目录。（牵头单位：市科技局；配合单位：市财政局、发展改革委、工业信息化委、人力资源社会保障局、国土资源局、农业局、林业局、商务局、卫生计生委、食品药品监管局、招商合作局，市国税局、地税局）

（三）加大招商引资力度

将生物医药和大健康产业项目列入全市招商引资重点领域，大力引进省内外知名企业入保发展，做特做强全市现代生物技术药、化学药和大健康产业。（牵头单位：市招商合作局；配合单位：各县（市、区）人民政府，市直有关部门）

（四）健全医药产品采购机制

按照公开透明、公平竞争的原则，完善药品、高值医用耗材等医药产品招标采购机制，确保药品采购各环节在阳光下运行。（牵头单位：市卫生计生委；配合单位：市食品药品监管局）

（五）促进人才引进及培养

大力实施人才引进培养计划，鼓励设立企业技术创新中心、院士专家工作站等人才培养平台，加强协同创新；积极支持保山中医药高等专科学校中医学、中药学等学科建设成为全省同类院校一流学科，加强医药教育的教学质量和师资队伍建设，积极培养和引进医药产业复合型人才。建立健全知识产权保护及风险防控机制，推进知识产权强企，引导和支持企业、高校、科研机构对重要关键技术获取发明专利。（牵头单位：市科技局；配合单位：市教育局、卫生计生委、人力资源社会保障局、食品药品监管局，保山中医药高等专科学校）

（六）加强产业协同监管

加大对违法市场主体行政处罚和信用约束力度，依法实施吊销营业执照、吊销注销撤销许可证、列入经营异常名录和“黑名单”等惩戒措施。建立健全经营异常名录管理和严重违法失信企业名单管理制度。对被列入经营异常名录、严重违法失信企业名单、重大税收违法案件当事人名单等失信主体依法予以限制或禁入，形成“一处违法，处处受限”的联合惩戒机制。（牵头单位：市工商局；配合单位：市食品药品监管局、卫生计生委，市国税局、地税局）

（七）强化统计监测

认真贯彻落实《云南省生物医药和大健康产业统计监测暂行办法》，确保统计数据真实、完整和准确。其中，天然药物和健康产品原料主要统计监测指标数据由市农业局负责牵头提供；生物医药和大健康产品生产主要统计监测指标数据由市工业信息化委负责牵头提供；生物医药和大健康商贸流通主要统计监测指标数据由市商务局负责牵头提供；与健康产业密切相关的研发服务机构主要统计监测指标数据由市科技局负责牵头提供；医疗养生服务主要统计监测指标数据由市卫生计生委负责牵头提供。（牵头单位：市统计局；配合单位：市农业局、工业信息化委、商务局、科技局、卫生计生委、人力资源社会保障局）

各县（市、区）、有关部门要充分认识生物医药和大健康产业发展的重要意义，认真贯彻落实市委、市人民政府的决策部署，加强组织领导，健全工作机制，形成工作合力。各责任单位要明确目标任务，按照职责分工抓好工作落实，定期向市生物医药和大健康产业领导小组报告工作进展情况。
