# 保山市人民政府办公室关于印发保山市2017年政务公开工作要点分工方案的通知

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

为贯彻落实《国务院办公厅关于印发2017年政务公开工作要点的通知》（国办发〔2017〕24号）、《云南省人民政府办公厅关于印发云南省贯彻落实国务院办公厅2017年政务公开工作要点分工方案的通知》（云政办发〔2017〕41号）要求，切实明确责任分工，增强公开实效，经市人民政府同意，现将《保山市2017年政务公开工作要点分工方案》（以下简称分工方案）印发给你们，并提出如下要求，请认真贯彻落实。

一、强化组织领导，确保扎实推进

各级各部门要加强对新形势下全面推进政务公开工作重要性的认识，落实国家、省、市全面推进政务公开工作的决策部署，将政务公开列入重要议事日程，确保主要负责人年内至少听取1次政务公开工作汇报，研究部署推进工作。要明确1位负责人分管政务公开工作，列入工作分工并对外公布。要健全政务公开领导机制和工作机制，调整完善政务公开领导小组。要全面加强政务公开工作力量配置建设，使之与政务公开工作相适应，做到主要领导亲自推进部署、责任部门落实具体措施、经办人员积极主动开展工作。要进一步加大政务公开工作调研培训力度，增强公开意识和理念，提高公开工作能力。

二、明确职责任务，确保有序开展

各级各部门要按照分工方案要求，围绕稳增长、促改革、调结构、惠民生和防风险工作，坚持创新发展理念，全面推进“五公开”工作，加强协作配合，形成工作合力；要认真对标对表分工方案，逐项抓好工作落实。牵头单位要按照“谁牵头负责、谁组织落实”的原则，加强组织统筹，抓好任务分解，积极推进开展各项工作，按时汇总进展情况，建立季度通报制度，定期提示进展情况。责任单位要根据各自职能，细化方案，落实责任，积极支持配合牵头单位抓好落实，及时向牵头单位反馈进展情况。各县（市、区）人民政府和市直有关部门要围绕近年政府信息与政务公开重点工作，在单位门户网站开设重点领域信息公开工作专题专栏，统一集中发布信息。各县（市、区）人民政府、市直有关部门要将重点领域信息公开专栏网址分别于2017年6月底和8月底前报市人民政府办公室备案。

三、加强督促检查，确保落实落细

各级各部门要切实承担起本级本部门政务公开工作的组织推动、指导监督、督促检查主体责任，强化统筹领导，履行工作职责，将涉及本级本部门的工作任务进一步分解细化，详细制定切合实际的实施方案或工作措施。市直各部门要积极对接省直相应部门，对本系统公开工作提出的具体要求要认真抓好落实。责任单位要认真履行职责，加强对本系统本行业政务公开工作的指导、督促和检查，强化与有关部门的联系，明确具体要求，不断强化对上沟通、横向协调和对下指导，及时掌握汇总有关情况。各级各部门要加大政府网站的整合力度，尤其对县级以下无人维护、信息内容无力保障的政府网站要坚决予以关停。请各级各部门将年度政务公开工作要点落实情况于2017年12月1日前通过电子公文系统报市人民政府办公室，同时在本单位门户网站公开发布。市人民政府办公室将采取年初定计划、年中抓进度、年末严考核的方式，适时开展专项督查，全面推进政务公开工作的落实。各级各部门的落实情况将在市人民政府门户网站开设专题网页集中展示，并纳入全市年度综合考评政务公开重要指标内容。联系人：徐敏继，电话：2160031。

保山市人民政府办公室
