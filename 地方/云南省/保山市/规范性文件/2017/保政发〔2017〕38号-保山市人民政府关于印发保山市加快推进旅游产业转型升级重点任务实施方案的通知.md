# 保山市人民政府关于印发保山市加快推进旅游产业转型升级重点任务实施方案的通知

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

现将《保山市加快推进旅游产业转型升级重点任务实施方案》印发给你们，请认真贯彻实施。

保山市人民政府

2017年7月28日

（此件公开发布）

保山市加快推进旅游

产业转型升级重点任务实施方案

为贯彻落实《云南省人民政府关于印发云南省加快推进旅游产业转型升级重点任务的通知》（云政发〔2017〕39号）要求，全面落实全域旅游、旅游品牌化发展战略，加快实施旅游产业“十三五”发展规划，推动旅游产业转型升级，结合保山实际，制定本方案。

一、推进旅游目的地转型升级

（一）创建一批全域旅游示范区。推动腾冲市创建国家级全域旅游示范区，推动隆阳区、龙陵县、昌宁县、高黎贡山旅游度假区管委会创建省级全域旅游示范区。到2020年，力争以上5个县（市、区）、园区创建成国家级、省级全域旅游示范区。（有关县市区人民政府，高黎贡山旅游度假区管委会牵头负责；市旅游发展委配合）

（二）建设一批生态旅游区。创建以青华海为主的“三个万亩”生态廊道国家生态旅游示范区，创建国家湿地公园、中国农业公园、国家森林公园，建设高黎贡山、天堂山、小黑山、界头、摩苍寺等生态旅游区，加强生态保护，合理有效利用资源，努力把保山打造成高品质生态旅游目的地。（有关县市区人民政府，高黎贡山旅游度假区管委会牵头负责；市国土资源局、环境保护局、住房城乡建设局、林业局、旅游发展委，高黎贡山自然保护区保山管理局等配合）

（三）建设一批旅游度假区。腾冲市以创建国家级旅游度假区为抓手，加快推进从景点旅游模式向全域旅游模式转变，建设世界知名、国内一流的康体养生休闲度假目的地。建设龙陵邦腊掌、高黎贡山旅游度假区、昌宁田园城市、施甸怒江大峡谷4个省级旅游度假区。到2020年，力争国家级旅游度假区达到1个、省级旅游度假区达到4个。（有关县市区人民政府，高黎贡山旅游度假区管委会牵头负责；市国土资源局、旅游发展委等配合）

（四）创建一批国家高A级景区。提升改造一批传统景区，深度挖掘、整合生态、文化资源新建一批A级景区。到2020年，力争将和顺古镇建成5A级景区；青华海、北海湿地、云峰山、滇西抗战纪念馆及国殇墓园、松山、善洲林场、龙江特大桥建成4A级景区；潞江坝大型服务区、汉营走马古镇、银杏村、樱花谷、天堂山、省农科院热带亚热带经济作物研究所等建成10个以上3A级景区。（各县市区人民政府，有关园区管委会牵头负责；市旅游发展委配合）

（五）建设一批旅游城市综合体。推动旅游产业与城市建设融合发展，建设完善保山青华海生态旅游城市综合体、腾冲旅游型城市综合体、昌宁田园城市综合体、龙陵生态颐养型城市综合体、施甸康体养生型城市综合体，打响“滇西最美生态城市”品牌。（各县市区人民政府牵头负责；市发展改革委、国土资源局、住房城乡建设局、规划局、旅游发展委等配合）

（六）推出一批特色旅游小镇。推动16个特色小镇创建，注重旅游功能和配套设施建设，积极创建云南旅游名镇。到2020年，力争旅游名镇达到3个以上。（各县市区人民政府，有关园区管委会牵头负责；市发展改革委、住房城乡建设局、国土资源局、规划局、旅游发展委等配合）

（七）建设一批旅游农庄和旅游特色村。深入推进旅游与农业、农村全面融合，建设10个特色鲜明、设施配套、管理科学、效益显著的旅游农庄，形成100个宜居、宜业、宜游的旅游特色村和美丽乡村，打造“中国最美乡村民宿——和顺民宿”“中国最美乡村——银杏村”“国际观鸟胜地——百花岭”“中国最美休闲乡村——坡脚村”4个乡村旅游品牌。（各县市区人民政府，高黎贡山旅游度假区管委会牵头负责；市委农办，市民宗局、国土资源局、住房城乡建设局、规划局、农业局、林业局、水务局、交通运输局、金融办、扶贫办、旅游发展委等配合）

二、推进旅游产品转型升级

（八）丰富温泉养生度假产品。申报世界温泉公园，建设“一市百泉”工程，打造热海温泉谷、悦椿温泉村、柏联温泉、荷花温泉、石头纪温泉、邦腊掌温泉、蒲缥温泉、鸡飞温泉等一批高星级温泉度假区；依托玛御谷温泉小镇、高黎贡国际旅游城、曲石原乡、怒江大峡谷旅游综合体、镇安温泉、小桥温泉、温泉契丹古镇、汉营走马古镇等项目，推出一批养生养老旅游示范产品，将保山建成云南温泉养生度假示范基地。（市旅游发展委牵头；各县市区人民政府，有关园区管委会负责；市民政局、发展改革委、国土资源局、住房城乡建设局、商务局、卫生计生委等配合）

（九）发展健康医疗旅游产品。推动传统中医中药、温泉康体疗养与旅游开发结合，培育健康管理、医疗旅游产品业态。到2020年，力争推出板桥健康疗养型城镇、东山中医药健康旅居小镇、高黎贡山中医药健康旅游示范项目、云天湖畔千亩高原有机生态中药材种植示范基地等4个以上中医药健康旅游示范项目，将保山建成云南健康旅游示范基地。（有关县市区人民政府牵头负责；市卫生计生委、发展改革委、科技局、国土资源局、旅游发展委、食品药品监管局、招商合作局等配合）

（十）发展体育旅游产品。申报中国围棋名城和中国围棋之乡，建设中国永子围棋国家文化旅游体育产业示范基地、腾冲市全域旅游国际户外运动文化中心PPP项目、火山激速户外运动公园，打造“永子国际围棋大赛”“腾冲马拉松”“高黎贡山超级越野赛”3个国际赛事品牌。重点发展徒步、骑行、垂钓、越野跑、定向运动等体育旅游新产品，适度发展直升机、运动机、滑翔伞、热气球、三角翼等航空运动旅游特色项目。（市体育局，各县市区人民政府，高黎贡山旅游度假区管委会牵头负责；市公安局、国土资源局、交通运输局、文化广播电视新闻出版局、水务局、工业信息化委、旅游发展委等配合）

（十一）发展自驾露营旅游产品。打造“滇西最美自驾线路”和“滇西红色旅游环线”2个全国知名线路品牌，培育“腾冲—密支那出境自驾旅游线路”，完善全市精品自驾旅游线路沿途的信息管理、服务网点、应急救援、旅游标识等公共服务设施，支持发展落地自驾、异地租还车、分时租赁车等新业态。到2020年，完成7个自驾车房车露营地建设，把保山打造成“滇西落地自驾大本营”。（市旅游发展委、交通运输局按照职责分工牵头；各县市区人民政府，高黎贡山旅游度假区管委会负责；市体育局、公安局、国土资源局、公安边防支队，腾冲海关、腾冲出入境检验检疫局等配合）

（十二）发展边境跨境旅游产品。利用保山独特区位及缅甸旅游资源和产品，开发提升“腾冲—密支那”“腾冲—缅甸—瑞丽”边境跨境旅游线路，推进腾冲机场口岸建设。到2020年，初步建成腾冲边境旅游试验区，中缅跨境旅游合作区建设取得实质性进展，建设面向南亚东南亚的区域性国际旅游集散枢纽。（市旅游发展委牵头；腾冲市人民政府负责；市公安局、商务局、公安边防支队，腾冲海关、腾冲出入境检验检疫局等配合）

（十三）发展节庆、演艺、会展旅游产品。规划建设保山市文化艺术中心，重点提升打造10个特色旅游文化节庆产品，打造1个精品演艺品牌，面向周边国家发展会展旅游产品。（市文化广播电视新闻出版局，各县市区人民政府，高黎贡山旅游度假区管委会牵头负责；市文产办、民宗局、商务局、旅游发展委等配合）

三、推进旅游公共基础设施转型升级

（十四）推进旅游交通便捷化。提升保山机场、腾冲机场通航能力，开辟航线，加密航班，完善“空巴通”空地联运机制。加快东绕城、昌保、保施、腾猴高速公路，密支那至班哨二级公路，大瑞铁路保山段、保山至猴桥铁路建设，推进干线公路与主要旅游度假区、旅游景区、旅游小镇、旅游特色村的连接道路，推动旅游专线公交向郊区景点、乡村旅游点延伸。（市交通运输局，各县市区人民政府，高黎贡山旅游度假区管委会牵头负责；市发展改革委、财政局、国土资源局、旅游发展委等配合）

（十五）推进旅游厕所品质化。深入推进“厕所革命”，提升改造和新建一批旅游厕所，引进推广新型生态旅游厕所，鼓励社会资本参与旅游厕所建设，提升旅游厕所建管养水平。到2020年，完成新建、改建旅游厕所280座，主要旅游交通沿线、旅游城镇、旅游景区和旅游特色村实现旅游厕所全覆盖、全达标。（各县市区人民政府，高黎贡山旅游度假区管委会牵头负责；市住房城乡建设局、交通运输局、商务局、旅游发展委等配合）

（十六）推进公共服务全域化。完善全市区域内高速路、国省道以及具有历史文化、旅游观光价值的所有道路的旅游标识牌建设，在出入境口岸、机场、车站、码头、游客服务中心、游客休息站点、旅游景区、旅游度假区、旅游城镇、乡村旅游点、市政道路、城市休闲街区等场所，科学规范设置多语种旅游公共标识系统，在机场、车站、干线公路及旅游公路重要节点规划建设一批游客服务（集散）中心、游客休息服务站点。（市旅游发展委牵头；各县市区人民政府，高黎贡山旅游度假区管委会负责；市发展改革委、国土资源局、住房城乡建设局、交通运输局、规划局、商务局、质监局，保山机场、腾冲机场等配合）

（十七）推进休闲空间多元化。增加城市公共休闲空间，加快建设提升保山中心城区“三个万亩”生态廊道工程、腾冲城市四项工程、界头花海慢城、施甸青牛白马广场、龙陵龙山湖公园、昌宁湿地公园，规划建设大西山游步道、怒江木棉风情走廊、野鸭湖慢游圈、天堂山生态慢游系统，鼓励支持全市各地免费开放城市公园、博物馆、文化馆、图书馆、科技馆、体育场馆、红色旅游景区和爱国主义教育基地。到2020年，全市建成免费风景骑（步、登）游休闲慢生活廊道100公里，新增城市休闲公园、绿地100公顷。（各县市区人民政府，高黎贡山旅游度假区管委会牵头负责；市发展改革委、国土资源局、住房城乡建设局、规划局、文化广播电视新闻出版局、体育局、科技局、旅游发展委等配合）

四、推进旅游管理服务转型升级

（十八）提升旅游服务质量。加快旅游人才引进，加大旅游教育培训力度，提升旅游从业人员队伍整体素质。推广腾冲旅游标准化试点工作成果，以创建国家级、省级旅游标准化试点单位为抓手，大力推进国家标准和相关行业标准在旅游住宿业、餐饮业、旅行社、景区、特色街区等领域应用，进一步突出地方特色和文化品味，促进旅游经营管理、服务设施和服务技能与国际标准接轨，积极培育旅游行业具有典型性、示范性的龙头企业。（市旅游发展委牵头负责；各县市区人民政府，高黎贡山旅游度假区管委会，市质监局、人力资源社会保障局等配合）

（十九）强化旅游行业自律。充分发挥行业协会、商会、旅游企业、研究机构在旅游标准制定、推广和实施中的主体地位作用，建立健全旅游市场主体、从业人员信用等级评定制度，引入第三方评估，加强舆论监督，逐步构建包括旅游诚信服务记录、评价、激励、惩戒的信用体系和标准化管理手段，推动形成约束性的行业自律机制，不断提升旅游服务质量和水平。（市旅游发展委牵头负责；各县市区人民政府，高黎贡山旅游度假区管委会，市民政局、工商局、质监局，各旅游行业协会等配合）

五、推进旅游数字化转型升级

（二十）提供游客综合服务平台。借助云南旅游大数据中心及各类旅游电子商务平台，加快智慧旅游建设，为游客提供游前资讯和预定购买，游中导览导游导航和安全应急疏导，游后分享评价投诉等信息服务。做好保山旅游微信、微博和官方网站的管理运营，强化信息发布和推送。利用互联网积极开展旅游品牌形象推广和产品营销，鼓励支持各级、有关部门通过电信运营商为游客发送旅游欢迎短信和提示短信。（市旅游发展委牵头负责；各县市区人民政府，高黎贡山旅游度假区管委会，市工业信息化委，中国电信保山分公司、中国联通保山公司、中国移动保山分公司等配合）

（二十一）建设旅游综合管理平台。依托国家、省相关旅游管理平台，加强产业运行分析、旅游数据统计、旅游安全监管、旅游应急指挥、旅游服务质量、旅游信用监管、旅游投诉管理、导游执业管理、旅游景区客流监测和分流、旅游车辆运行监管等工作。建立健全旅游市场监管综合调度指挥平台、旅游警察大队、旅游市场监管执法大队、旅游联合执法巡逻队，设立旅游巡回法庭，开通投诉举报专线，成立相关行业协会，完善“1+3+N”旅游市场综合管理模式。（市旅游发展委牵头；各县市区人民政府，高黎贡山旅游度假区管委会负责；市工业信息化委、公安局、工商局、统计局等配合）

（二十二）夯实旅游数字化发展基础。推动旅游区域互联网基础设施和物联网设施建设，推进机场、车站、宾馆饭店、景区（点）、主要乡村旅游点等旅游区域无线网络、4G信号等基础设施的覆盖，加大触控屏幕、平板等旅游信息互动终端的布放，全面提升旅游公共信息服务硬件能力。到2020年，力争重点景区、重点区域实现免费WIFI全覆盖，4A级以上景区实现智能导游、在线预订、信息推送等功能全覆盖。（市工业信息化委、旅游发展委按照职责分工牵头；各县市区人民政府，高黎贡山旅游度假区管委会负责）

六、保障措施

（二十三）明确责任，细化安排。各县（市、区）人民政府、高黎贡山旅游度假区管委会要按照属地责任制的要求，党政主要领导是统筹推进旅游产业转型升级的第一责任人，要切实抓好本地旅游产业转型升级推进工作，细化工作措施，明确工作时间，制定工作方案。市旅游产业发展领导小组办公室依据各地工作时间表，制定考核办法，进行进度考核。对完成工作情况好的部门和地区给予表彰，对推进不力的部门和地区进行通报。旅游产业转型升级考核结果纳入全市年度综合考核内容。（市旅游产业发展领导小组办公室牵头；各县市区人民政府，高黎贡山旅游度假区管委会负责）

（二十四）改革创新，优化环境。按照“放管服”改革要求，及时清理、修订不适应旅游产业转型升级的规范性文件。将旅游项目建设用地纳入土地利用总体规划和年度计划合理安排，优先确保旅游产业转型升级重大项目的用地供给，探索建立旅游用地分类供给方式，采取点状供地、零星供地、单独选址、弹性年期出让和长期租赁、先租后让、租让结合的灵活政策；对立项2年仍未开发，以及投入强度明显低于协议约定的项目，依法依规收回资源使用权。创新财政资金使用方式，重点支持旅游项目前期工作、旅游公共服务设施建设和旅游宣传推介，综合运用投资补助、以奖代补、贷款贴息、基金注资、购买服务等多种方式，促进旅游产业转型升级。要发挥好市级产业发展基金的作用，积极采取政府和社会资本合作（PPP）模式，在撬动社会资本投向转型升级重点项目的同时，优先投向旅游公共服务和旅游公共设施项目。对符合国家产业政策的重点招商引资旅游项目，实行企业投资项目承诺制和审批服务代办制。要鼓励社会资本进入旅游业，着力培育大型龙头旅游企业，打造品牌旅游企业，推动支持旅游企业上市。（市政府督查室，市发展改革委、财政局、国土资源局、旅游发展委、国资委及有关部门按照职责分工牵头；各县市区人民政府，高黎贡山旅游度假区管委会负责）

（二十五）统筹推进，加强协调。市人民政府常务会议每半年听取1次旅游产业转型升级重点任务推进情况汇报。市旅游产业发展领导小组根据需要适时召开重点工作调度会议，及时协调解决旅游产业转型升级中的有关问题；及时召开现场办公会议和专题工作会议，协调解决旅游重大项目、重点工作和旅游企业遇到的困难和问题。（市旅游产业发展领导小组办公室牵头负责）
