# 保山市人民政府关于确认万晓军等30名同志为第八批有突出贡献优秀专业技术人才的决定

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

根据《中共保山市委 保山市人民政府关于创新体制机制加强人才工作的实施意见》（保发〔2015〕1号）精神，经逐级推荐申报、资格审核、专家评审委员会评审和公示等程序，市人民政府决定确认万晓军等30名同志为保山市第八批有突出贡献的优秀专业技术人才，其中：一等奖5名、二等奖10名、三等奖15名。

有突出贡献的优秀专业技术人才是全市专业技术人员中的优秀代表，在工业、农业、教育、文化、卫生等领域作出了突出贡献。有关单位要高度重视，积极创造条件，进一步发挥优秀专业技术人才在科技创新、产业发展、学科建设等方面的领军带头作用，让各类人才的创造活力竞相迸发、聪明才智充分涌流，努力营造人人渴望成才、人人努力成才、人人皆可成才、人人尽展其才的良好局面。

第八批有突出贡献的优秀专业技术人才要进一步增强责任感、使命感，珍惜荣誉，再接再厉，在各自岗位上再创佳绩；全市广大专业技术人员要以受表彰的同志为榜样，奋发图强，扎实工作，共同为推动保山跨越发展、全面建成小康社会作出新的更大贡献。
