# 保山市人民政府关于授予第三届保山市政府质量管理奖的决定

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

为引导和激励各类组织加强质量管理，追求卓越绩效，推动保山发展转型升级和提质增效，根据《保山市人民政府质量管理奖管理办法》，经市政府质量管理奖评审委员会审议，市人民政府决定授予云南腾冲火山热海投资开发有限公司、云南永昌硅业股份有限公司第三届保山市政府质量管理奖。

希望获奖企业珍惜荣誉、再接再厉，积极发挥示范带动作用，努力在新的起点上争创更大成绩。全市各级各部门要进一步树立以质取胜的质量发展理念，坚持走质量效益型发展道路，不断增强质量优势和品牌优势，为建设质量强市作出新贡献。

保山市人民政府

2018年3月8日
