# 保山市人民政府办公室关于成立保山市云计算大数据产业发展领导小组的通知

领导小组下设办公室在市工业信息化委，刘志胡兼任办公室主任，许伟、王明超、郭绍坤任办公室副主任。

办公室主要职责：承担领导小组日常工作，协调领导小组各成员单位的工作，负责做好需提交领导小组审议批准事项的准备工作；研究起草推动保山市云计算大数据产业发展相关文件和政策措施；督促落实领导小组决定事项，推进完成各项工作任务；梳理云计算大数据产业发展过程中的困难及问题，及时研究提出解决方案，并向领导小组报告；完成领导小组交办的其他工作。

领导小组成员如遇工作变动，由相应职务人员自行接替，报领导小组办公室备案，不再另行发文。
