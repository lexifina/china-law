# 保山市人民政府办公室关于命名2018年度“四好农村路”示范乡镇及示范村的通知

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

2018年以来，全市各级各部门认真贯彻落实习近平总书记关于“四好农村路”建设的重要指示精神，按照市委、市政府工作部署，从打赢脱贫攻坚战和实施乡村振兴战略的高度出发，高质量推进“四好农村路”建设，涌现出了一批“四好农村路”建设先进典型。经县级申请、对标遴选、市级核查、实地考评等程序，市人民政府决定命名隆阳区板桥镇等7个乡（镇）为2018年度“四好农村路”示范乡镇，命名隆阳区板桥镇北汉庄社区等11个建制村为2018年度“四好农村路”示范村。

希望被命名为2018年度“四好农村路”示范乡镇和示范村的乡（镇）、建制村珍惜荣誉，再接再厉，充分发挥示范引领作用，推动农村公路高质量跨越发展。

各县（市、区）要认真总结推广和学习先进经验，全面深入推进“四好农村路”建设各项工作，强化农村公路建设的主体责任，进一步把农村公路建好、管好、护好、运营好，开拓创新，攻坚克难，补齐发展短板，为全面建成小康社会、实施乡村振兴战略提供坚实的保障。

市加快推进“四好农村路”建设工作领导小组办公室要在开展2019年度示范乡镇、示范村考评的同时，对2018年度命名的示范乡镇、示范村开展好复评工作。2019年底，对已命名的2018年度示范乡镇、示范村，经复评合格的给予授牌，复评不合格的将撤销其示范称号。
