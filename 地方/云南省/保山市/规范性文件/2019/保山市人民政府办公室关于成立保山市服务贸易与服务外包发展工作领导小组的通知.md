# 保山市人民政府办公室关于成立保山市服务贸易与服务外包发展工作领导小组的通知

领导小组设办公室在市商务局，由王云任办公室主任，负责协调各成员单位和领导小组日常工作。

二、领导小组及办公室主要职责

（一）领导小组主要职责：加强对服务贸易和服务外包工作的指导，统筹协调推进全市服务贸易和服务外包发展工作；研究加快服务贸易和服务外包发展的工作措施和举措；推广服务贸易创新发展试点经验工作，负责组织服务外包示范城市的申报和建设，协调解决工作推进中遇到的重大问题；落实全市服务贸易和服务外包发展的重大事项，安排部署各阶段工作。

（二）领导小组办公室主要职责：贯彻落实领导小组关于服务贸易和服务外包工作的决策部署；协调、督促、检查成员单位履行工作职责和落实领导小组决定事项；负责领导小组日常工作，具体承办申报服务外包示范城市等工作，完成领导小组安排的其他工作。

领导小组成员如有变动，由成员单位相应岗位职责人员自行递补，并报领导小组办公室备案，不再另行发文。
