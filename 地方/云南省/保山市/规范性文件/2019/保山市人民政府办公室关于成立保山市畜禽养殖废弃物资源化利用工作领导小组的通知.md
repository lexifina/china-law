# 保山市人民政府办公室关于成立保山市畜禽养殖废弃物资源化利用工作领导小组的通知

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

为加强组织领导和统筹协调，市人民政府决定成立保山市畜禽养殖废弃物资源化利用工作领导小组。现通知如下:

领导小组下设办公室在市农业农村局，办公室主任由何树林兼任，副主任由张有华兼任，成员由市农业农村局畜牧科科长王国良、市生态环境局污控科科长朱秀梅担任。

二、领导小组及办公室主要职能

（一）领导小组

统筹协调全市畜禽养殖废弃物资源化利用工作，研究制定有关政策措施，指导督促各县（市、区）、园区和市直有关单位落实各项工作任务，研究解决工作中的重大问题，完成省级和市委、市人民政府交办的其他事项。

（二）领导小组办公室

承担领导小组日常工作，贯彻落实领导小组决定事项，细化有关工作方案并抓好督促落实，收集、通报全市工作开展情况，分析研究工作中存在的突出问题，提出解决的意见和建议，完成领导小组交办的其他事项。领导小组人员如有变动，由接替相应职务人员自行递补，并报领导小组办公室备案，不再另行发文。
