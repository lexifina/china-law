# 保山市人民政府办公室关于调整保山市打击传销工作领导小组的通知

领导小组下设办公室在市市场监管局，负责日常工作，办公室主任由许旻担任，副主任由市公安局经侦支队副支队长邱德祥、市市场监管局价格监督检查和反不正当竞争科科长胡杰、市委政法委综治督导科科长施云担任，领导小组办公室联络员由各成员单位指定1名工作人员。今后领导小组成员如有变动，由该成员单位相应负责人替补，报领导小组办公室备案，不再另行发文。

二、领导小组及其工作职责

领导小组工作职责：负责全市打击传销、无传销创建的组织领导工作。按照《禁止传销条例》规定的工作职责及国家有关打击传销、无传销创建工作的部署和要求，加强对查处传销工作的组织领导、督促协调；研究制定保山市打击传销、无传销创建工作的政策措施，督促市场监管、公安、金融监管、商务、教育、通信管理等有关部门依法履行监督管理职责，组织各成员单位根据工作职责开展打击传销、无传销创建工作，形成各司其职、相互配合、权责一致的打击防范传销工作格局；及时研究解决打击传销、无传销创建工作中的重大事项和问题。

领导小组办公室工作职责：负责全市打击传销、无传销创建的日常工作；组织查处涉及区域广、参与人员多、社会影响恶劣、在全市范围内有重大影响的传销大案和要案，努力抓好全市范围内传销案件查处、打击传销规范直销有关工作的督查督办和指导协调工作；协调成员单位之间工作，促进协作与配合；及时向领导小组及成员单位通报查处重大传销案件的基本情况以及无传销创建工作急需解决的有关问题；根据各成员单位意见和建议提出领导小组全体会议议题，经领导小组组长、副组长批准，组织召开会议，做好会务工作；督办落实领导小组全体会议作出的各项决定，及时通报打击传销、无传销创建有关工作情况；沟通工作信息，交流工作经验，开展调查研究，收集、分析、处理有关传销数据资料，及时掌握全市传销活动动态；完成领导小组交办的其他任务。

三、成员单位工作职责

市场监管部门：承担打击传销工作领导小组办公室职责，做好牵头协调和日常事务工作；按要求认真抓好“无传销网络平台”创建和督促指导好“无传销社区（村）”创建工作；认真受理、核查、答复打击传销各类信访咨询和举报投诉；加强刑行衔接、积极配合公安机关依法查处传销违法犯罪案件，积极做好查处传销参与人员的教育引导和劝返遣散工作；认真履行职责，充分发挥职能作用，加大对传销活动特别是网络传销的预警监控力度，有效遏制传销蔓延扩散或回流反弹；以防为主、打防结合、高压防范，认真落实打击传销属地管辖责任制，狠抓宣传教育，积极营造良好氛围，努力抓好源头治理工作；规范运用打击传销信息系统，完善传销案件和参与传销人员信息数据库，汇总和通报打击传销工作情况。

公安部门：加强对户籍、流动人口、重点人员、特种行业、房屋租赁和网络监控的规范管理，健全制度，在当地政府领导下认真抓好防控工作；认真受理、核查、答复打击传销各类信访咨询和举报投诉；认真收集、整理、汇总并及时向市打击传销工作领导小组办公室通报有关工作情况，及时曝光典型案例；充分发挥侦查办案职能作用，整合内部资源协调联动，加强对传销特别是网络传销的舆情研判和监控预警，坚持“露头就打、打早打小”原则，依法快侦快破大案要案，严惩传销组织者和骨干分子，严厉查处拒绝、阻碍执法部门依法执行公务以及聚众暴力抗法等违法犯罪行为；加强与市场监管等部门的协调配合和联查联动，整合资源，提前介入重大传销案件和扰乱社会治安秩序传销案件的查处工作，形成打击传销合力；积极参与“无传销社区（村）”和“无传销网络平台”创建活动，依职责认真组织开展打击传销预警防范和宣传教育工作。

市委政法委：将打击传销、无传销创建工作内容纳入年度综治维稳（平安建设）工作目标管理责任制考核、先进平安县（市、区）和深化行业系统平安建设考核评价范围，认真落实各级党委、政府打击传销、无传销创建第一责任人责任。

法院、检察院：与市场监督管理、公安部门密切配合，及时沟通解决传销案件查处过程中遇到的各种困难和问题，共同研究传销违法犯罪法律适用问题，对市场监管、公安部门打击传销和查处案件给予司法支持，从快批捕、起诉、审判传销案件。

宣传、广电部门：积极配合市场监管、公安机关，组织、协调新闻出版以及相关新闻媒体，适时刊播打击传销有关法律法规、知识和典型案例；积极协调各新闻媒体认真做好“防范传销、拒绝传销、打击传销、远离传销”的宣传报道工作，增强人民群众识别、防范和抵制传销的自觉性和主动性，努力营造良好舆论氛围。

司法行政部门：将打击传销有关法律、法规及知识的普及宣传工作纳入普法宣传内容开展普法宣传，积极参与无传销社区（村）创建活动，引导广大人民群众认识了解传销违法犯罪严重危害性及欺诈本质，努力提高预防防范传销的意识和能力。

人力资源社会保障部门：切实加强对人才市场、劳动力市场和人才（职业）中介服务机构管理，加强对招聘企业的资格审查，加强对人才（职业）中介服务机构以招聘为名收取介绍或报名费行为的管理；积极协助市场监管、公安部门认真做好防止传销向待业、就业、求职和外出务工人员渗透的宣传教育工作；通过提供就业指导、拓宽就业渠道等方式，积极帮助下岗职工、大（中）专和职业院（校）毕业生、农民工等特殊群体实现就业、再就业，有效预防防范传销组织诱骗求职就业和外出务工人员加入传销组织。

教育体育部门：加强对各级各类学校特别是各类大（中）专和职业院（校）教职员工和学生的规范管理，严防传销组织引诱诱骗广大师生陷入传销陷阱；积极组织开展防止传销进校园各种宣传教育活动，正确引导广大师生提高预警防范意识，促使广大师生认识传销、抵制传销、拒绝传销、远离传销，严防传销进校园；积极配合市场监管、公安部门加强对校园周边环境整治和学校教职员工出租房屋管理，有效预防防范传销的滋生渗透。

财政部门：认真落实打击传销工作专项经费，将打击传销、无传销创建专项工作经费纳入财政预算范围予以统筹考虑安排。

金融监管部门：积极协调各有关银行业金融机构，特别是第三方支付发现的疑似传销异常账户，依法协助执法部门开展对涉嫌传销资金、账户的查询、查封、冻结工作。

网信办：依法监督各类互联网平台加强自律，主动净化网络环境，及时清理网络传销信息，压实反传销责任。组织协调各类网站加大网络传销违法犯罪的预警提示和宣传教育力度，积极配合开展打击网络传销工作。

文明办：将打击传销、无传销创建工作纳入文明城市、文明县（市、区）创建范围实施考核评价管理。

通信管理部门：加强互联网涉传相关信息的检测和甄别，及时发现网络传销违法犯罪线索，按要求及时删除屏蔽涉传网站及相关信息；认真贯彻落实《互联网信息服务管理办法》，加大对利用互联网传销和为传销提供互联网信息服务行为的查处和管理力度，对公安、市场监管部门认定的传销网站依法予以关停并纳入黑名单管理，依法严厉打击利用互联网从事传销和为传销提供互联网信息服务的行为。

民政部门：指导基层社区居民委员会和农村村民委员积极协助执法部门配合做好打击传销、无传销创建的有关基层基础工作，筑牢夯实防范传销防线；积极配合市场监管、公安机关做好被骗参与传销、生活无着落、符合救济条件人员的救助以及遣返工作。

商务部门：加强对直销企业和申请直销企业的审查审核和申报行为管理，把好审核审查关口；充分发挥职能作用，认真履行工作职责，严格依照《直销管理条例》规定要求，积极协助市场监管等有关部门依法规范监管直销企业、申请直销企业及其分支机构、经营服务网点（店铺）的经营活动，严防直销企业及其分支机构、经营服务网点（店铺）以直销名义从事违规直销或传销违法犯罪活动。
