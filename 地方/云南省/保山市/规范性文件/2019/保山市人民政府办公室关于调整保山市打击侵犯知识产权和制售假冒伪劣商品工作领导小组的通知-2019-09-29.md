# 保山市人民政府办公室关于调整保山市打击侵犯知识产权和制售假冒伪劣商品工作领导小组的通知

领导小组下设办公室在市市场监管局，承担领导小组日常工作，办公室主任由市市场监管局副局长、市知识产权局局长许旻兼任。

打击侵犯知识产权和制售假冒伪劣商品工作已纳入全市综合考评，请各县（市、区）和园区参照成立“双打”领导小组，并按要求贯彻落实好相关工作要求。领导小组成员如发生变动，由该成员单位相应负责人替补，报领导小组办公室备案，不再另行发文。
