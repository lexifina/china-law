# 保山市人民政府办公室关于调整充实保山市移民搬迁安置工作领导小组的通知

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

二、领导小组及办公室主要职责

领导小组主要职责：贯彻落实党中央、国务院和省委、省政府关于移民搬迁安置工作的决策部署，研究制定全市搬迁安置工作政策措施，研究解决全市移民搬迁安置的重大问题和主要事项，统筹协调处理移民搬迁安置工作中遇到的问题，督促指导各县（市、区）、园区和市直有关单位做好移民搬迁安置、后期扶持等工作。

领导小组下设办公室在市搬迁安置办公室，办公室主任由杨存金兼任，负责承担领导小组日常工作，处理日常事务，贯彻落实领导小组决定事项。

领导小组成员如有变动，由成员单位相应岗位职责人员自行递补并报领导小组办公室备案，不再另行发文。
