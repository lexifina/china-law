# 保山市人民政府办公室关于进一步加强“安全生产月”活动有关工作的通知

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

我市“安全生产月”和“防范风险化工行”活动与全国、全省同步，于2019年6月1日—30日在全市范围内开展。为进一步扩大“安全生产月”活动影响力和覆盖面，充分调动社会公众参与的积极性，确保活动取得实效，经市人民政府同意，现将有关事项通知如下：

一、进一步提高站位

各级各有关部门要进一步提高思想认识，深入贯彻落实习近平总书记关于安全生产工作的重要论述，落实国家、省、市关于安全生产工作的重大决策部署，以防范化解重大风险、消除安全隐患、遏制生产安全事故为目标，通过集中开展“安全生产月”活动，增强全民安全生产意识，提升公众安全素质，为新中国成立70周年营造安全稳定的社会环境。

二、进一步突出工作重点

各级各有关部门要对照《保山市人民政府安全生产委员会办公室关于开展2019年“安全生产月”活动的通知》（保安办发〔2019〕12号）要求，认真组织开展“安全生产月”活动启动仪式、安全宣传咨询日、主题宣讲、安全发展论坛、警示教育和科普宣传、应急预案演练和“防范风险化工行”等活动。安全生产月期间，结合国家、省有关要求，市安委会将印发1个开展安全生产月活动的通知、撰写1封致全市人民的公开信、召开1次专题会、开展1次专项督查。各县（市、区）人民政府、园区管委会要聚焦安全发展主题，结合实际积极开展安全生产月活动，做到“规定动作不走样，自选动作有新意”。

三、深入开展“查找身边的隐患”活动

各级各有关部门要围绕“防风险、除隐患、遏事故——从身边做起”主题，推动安全宣传教育进企事业单位、进学校、进机关、进社区、进农村、进家庭、进公共场所，教育引导社会公众严守法律法规、遵守操作规程、杜绝不安全行为，做自身安全的主人。要聚焦国务院安全生产和消防工作第七考核巡查组、危险化学品安全生产专项巡查组开展安全生产大检查时发现的问题，做好问题隐患“回头看”，确保问题整改到位。要广泛发动群众、企业职工和家属，全面查找身边的安全隐患，通过人民网安全生产举报平台、12350举报投诉热线和96119消防举报电话，积极举报风险隐患，勇于同不安全行为作斗争，在保护自身安全的同时维护公众安全，筑牢防范化解安全风险的第一道防线。

四、进一步拓宽社会宣传面

各级各有关部门要紧密结合实际，加大活动宣传力度，进一步拓宽宣传面，推动全社会关心安全生产、参与安全发展。要在机场、车站、影剧院、商场、宾馆、商业街区、城市社区、广场、公园、风景名胜区等公共场所和高速路口、街道宣传栏等醒目位置，广泛张贴、悬挂安全标语横幅、安全提示、安全警示挂图和公益宣传画。要充分发挥公交车、长途客车、飞机等交通工具电子显示屏的公益传播介质作用，持续滚动播放安全公益广告、警示教育片和科普短视频，并面向社会公众定期推送一批通俗易懂、知识性强的安全生产公益信息，让安全生产知识触手可及。

五、加强调研和督导

各级各有关部门要把开展“安全生产月”活动作为深入学习习近平总书记关于安全生产重要论述的集中宣讲月，作为严格安全管理、压实安全责任、推动问题整改的工作落实月，作为传播安全知识、提升应急能力的安全科普月，扎实推进各项工作。市应急局、交通运输局、工业和信息化局、住房城乡建设局等安全生产“1+7”专项整治行动牵头单位要继续深入推进煤矿、非煤矿山、危险化学品、交通运输、房屋建筑和市政工程等重点领域安全生产专项整治；市文化和旅游局要牵头开展旅游景区、景点安全生产专项整治，强化问题隐患整改，确保工作取得实效。各县（市、区）、园区、有关单位要深入基层调研督导，及时评估成效，推动“安全生产月”和“防范风险化工行”活动走深、走细、走实。市安委办要深入地质灾害隐患点、建筑施工单位、重点隐患企业开展专项督促，并对各单位开展活动情况进行评估督导，督导情况向市人民政府报告，同时推广有关经验和做法。

保山市人民政府办公室
