# 保山市人民政府办公室关于通报表扬打击走私综合治理成绩突出单位的通知

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

2018年以来，全市各级各部门坚决贯彻落实习近平总书记重要指示批示精神，坚持“打防结合、突出重点、综合治理、坚持不懈”的工作方针，紧紧围绕中央关注、社会关切、群众关心的突出走私问题，全力开展高压严打、强化监管防控、推进综合治理，走私猖獗势头得到遏制，打击走私综合治理工作取得了明显成效，为维护全市经济社会发展稳定作出了积极贡献。为激励先进，市人民政府决定对措施有力、成绩突出的市委政法委等7个单位、施甸县人民政府等3个县（市）予以通报表扬。现通知如下：

一、成绩突出单位（7个）

市委政法委

市公安局

市市场监管局

市商务局

市森林公安局

腾冲海关

市烟草专卖局

二、成绩突出县市（3个）

施甸县人民政府

腾冲市人民政府

龙陵县人民政府

希望受表扬的单位和县（市）珍惜荣誉，再接再厉，为推动全市打击走私综合治理工作作出新贡献、创造新业绩。各级各部门要以先进为榜样，进一步提高政治站位，准确把握形势，找准工作重点，优化工作布局，全面提升打击走私综合治理工作的能力和水平，努力开创新时代打私工作新局面，为维护全市经济社会稳定贡献新力量。

保山市人民政府办公室

2019年9月10日
