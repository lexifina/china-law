# 保山市人民政府办公室关于切实做好“一部手机办事通”APP应用与推广工作的通知

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

为认真贯彻落实《云南省人民政府办公厅关于做好“一部手机办事通”上线运行工作的通知》（云政办函〔2019〕4号）要求，切实做好全市“一部手机办事通”（以下简称“办事通”）上线运行各项工作，经市人民政府同意，现将有关事项通知如下：

一、强化认识，高度重视“办事通”上线运行工作

建设“一部手机办事通”是省委、省人民政府贯彻落实党中央、国务院加快推进“互联网+政务服务”工作、推广移动政务服务决策部署的重大举措，是践行以人民为中心的发展思想、方便企业和群众办事创业的重要载体，是省人民政府2019年10件惠民实事之一。企业和群众通过下载安装“办事通”，获取查询、预约、办理、缴费等办事服务和行业应用、咨询投诉等应用服务，实现上线服务事项“掌上办、指尖办”。各级各部门要认真贯彻落实省、市决策部署，从思想上高度重视，行动上坚决落实，全力以赴推进“办事通”上线运行工作，强化推广应用，切实增强企业和群众办事创业的便捷性。

二、细化措施，切实做好“办事通”上线运行各项工作

（一）提高业务水平。针对首批上线的12个办事主题和150个服务事项，财政、公安、民政、人力资源社会保障、市场监管、税务、司法、卫生计生、医保9个涉项部门要及时与省级业务管理部门请求给予业务支持和指导，及时组织各级服务窗口工作人员、业务审批人员、系统技术人员等进行集中培训，尽快熟练业务办理流程，掌握网上办理方法，为企业和群众提供优质高效的便民服务。

（二）引导推广应用。各县（市、区）、各部门要结合“办事通”上线运行工作，进一步调整优化本行政区域内政务服务中心涉及的上线服务事项业务办理流程、办事指南、物流配送等工作，在显著位置张贴“办事通”宣传材料，摆放、张贴宣传展板和宣传海报，安排专人指导办事群众下载安装“办事通”并注册登录，积极引导使用手机办事，有序推进“办事通”办理有关业务，最大程度利企便民。按照“我知、我用、我推广”工作要求，各级党政机关、人民团体、事业单位及国有企业要带头应用、带头推广，积极引导干部职工下载安装使用“办事通”，按照注册用户全覆盖的要求，确保实现所有职工全员覆盖，并切实加大向各类市场主体及人民群众的推广力度，提高群众知晓率和使用率，全力做好我市“办事通”的推广应用。

（三）及时反馈意见。“办事通”运行过程中要充分发挥用户评价功能，广泛收集各方意见，发现问题、及时汇总上报。

三、优化服务，不断完善应用服务功能

（一）持续上线服务事项。各级各部门要积极主动组织梳理规范本系统行政职权、公共服务事项清单以及业务手册和办事指南，按照适宜手机办理和统一规范要求，进一步优化网上申请、受理、审查、决定、送达等业务办理流程，缩短办理时限，分批推出上线服务事项并接入“办事通”，确保做到“应上尽上”，推动更多政务服务事项实现“掌上办、指尖办”。

（二）提升在线办事比例。各级各部门要通过流程优化、系统整合、数据共享、业务协同，推动企业和群众办事从“线下跑”向“网上办”、从“分头办”向“协同办”转变，降低办事成本，不断提高应用“办事通”办理上线服务事项比例。

（三）实现数据共享互通。各级各部门要按照“一数一源”的要求，梳理编制统一完整的政务服务数据共享目录清单。按照“谁主管、谁提供、谁负责”的原则，保证提供的数据采集规范、真实准确，及时更新维护，提高数据质量。推进数据共享平台建设工作，满足企业和群众办事需求。

四、落实责任，加强上线运行监督管理

（一）完善管理机制。随着“办事通”上线运行和办事群众的不断增加，各级各部门要认真梳理规范业务申报、预审、受理、办理、办结、取件、送达等工作任务，建立业务办理协同机制，确保各岗位人员就位、设备就位、系统就位，做到预约准确有效、查询响应迅速、办理实时反馈。对手机申报的各类办事服务事项，要有序衔接网上受理和实际办理环节，及时规范处理企业和群众的申请办件，确保件件有落实；对咨询投诉类服务事项，要及时回复反馈意见，确保事事有回音。

（二）建立联动机制。“办事通”上线运行后，对出现的各种问题，要认真收集分析过滤，建立问题处置联动机制，各级各有关部门要主动加强与上级部门的沟通联系，确保出现问题及时解决。

五、工作要求

（一）强化协作推进。各级各部门要充分认识“办事通”工作的重要性，切实统一思想、加强领导、团结协作，层层压实工作责任，抓好各项工作落实。

（二）强化宣传推广。各县（市、区）、各部门要充分利用宣传手册、宣传栏、LED电子显示屏、广播电视等媒介及政府门户网站、网上政务服务大厅、微信公众号、微博公众号等新媒体进行宣传推广，积极引导企业和群众应用办事通办理有关业务，扩大社会知晓面，营造良好氛围。各级建行要积极配合各相关部门开展好宣传推广工作。

（三）强化监督考核。各级各部门要将“办事通”应用推广纳入年度综合考评内容和督查事项，建立相应的督办工作机制，强化监督管理，对工作推进不力的，要限期整改落实；情节严重、影响工作推进的，按照有关规定严肃问责。
