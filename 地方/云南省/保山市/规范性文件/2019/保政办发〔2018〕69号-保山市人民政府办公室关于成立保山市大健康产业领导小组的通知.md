# 保山市人民政府办公室关于成立保山市大健康产业领导小组的通知

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

领导小组下设办公室在市卫生计生委，兼任办公室主任，朱光亮、赵明宽、夏红军、市农业局局长兼任办公室副主任，负责组织协调大健康产业发展工作日常事务。领导小组成员如有变动，由成员单位相应岗位职责人员自行递补，报领导小组备案，不再另行发文。

二、专项组组成和发展领域

（一）健康医疗产业发展专项组

牵头单位：市卫生计生委

责任单位：市发展改革委、市财政局、市工业信息化委、市人力资源社会保障局、市政府新闻办、市招商合作局、市科技局、市安全监管局、市食品药品监管局

发展领域：医疗、中医保健、健康管理等

（二）健康养生产业发展专项组

牵头单位：市旅游发展委

责任单位：市发展改革委、市财政局、市民政局、市国土资源局、市政府新闻办、市招商合作局、市住房城乡建设局、市林业局、市工商局、市环境保护局、市安全监管局、市质监局、市税务局

发展领域：健康养生服务业（生态文化体验、避暑度假养生、休闲观光度假、温泉水疗养生等）

（三）健康养老产业发展专项组

牵头单位：市民政局

责任单位：市发展改革委、市财政局、市卫生计生委、市政府新闻办、市招商合作局、市住房城乡建设局、市安全监管局

发展领域：养老产业等

（四）健康运动产业发展专项组

牵头单位：市体育局

责任单位：市文化广播电视新闻出版局、市财政局、市政府新闻办、市招商合作局、市教育局、市环境保护局、市安全监管局、市质监局

发展领域：户外运动、运动健身等

（五）健康食药材产业发展专项组

牵头单位：市农业局

责任单位：市财政局、市食品药品监管局、市政府新闻办、市招商合作局、市国土资源局、市质监局、市科技局、市林业局、市工商局、市环境保护局、市安全监管局、市税务局

发展领域：中药材种植、中药材流通、无公害农产品种植等

三、主要工作职责

（一）贯彻执行国家和省有关大健康产业的法律法规、政策措施，研究拟订实施办法并推进实施。

（二）建立联席会议制度，领导小组组长、第一副组长是总召集人，各专项组牵头单位主要领导为专项组联席会议召集人。总召集人每年至少组织召开2次部门联席会议，根据情况适时组织召开全体会议；各专项组每年定期召开1—2次联席会议。

四、其他要求

请领导小组各成员单位明确1名工作联系人，将联系人名单（姓名、单位、职务、手机号码）于2018年12月30日前报市卫生计生委医政医管科。联系人：黄云天；电话：2220842；邮箱：bsyzygk@163.com。
