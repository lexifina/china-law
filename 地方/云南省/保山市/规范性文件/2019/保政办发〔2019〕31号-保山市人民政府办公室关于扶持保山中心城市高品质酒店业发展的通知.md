# 保山市人民政府办公室关于扶持保山中心城市高品质酒店业发展的通知

隆阳区人民政府，市工贸园区管委会，市直及驻保有关单位：

为全面贯彻落实国家和省级关于减税降费、优化营商环境的系列政策措施，加快保山中心城市高品质酒店业发展，完善城市服务功能，助推现代化大城市建设，经市人民政府研究，现将扶持保山中心城市高品质酒店业发展有关事项通知如下：

一、扶持对象范围

酒店注册地、建设地、纳税地在保山中心城市规划区范围内（即：《云南省人民政府关于保山市城市总体规划（2017-2035年）的批复》（云政复﹝2018﹞29号）划定的160平方公里范围内），2019年1月1日后正式营业运营，按时足额纳税，且符合以下条件之一的经营性酒店：

（一）获得全国星级酒店评审委员会颁发的中国五星级及以上饭店证书。

（二）酒店建设投资额（不含土地成本）达3亿元人民币以上的新建或改建酒店（投资额需经具备合法资质的第三方专业造价认定或审计机构认定，并出具评估或审计报告）。

（三）引进符合《云南省引进国内外知名酒店品牌指导目录》确认的国际国内知名酒店品牌管理公司管理运营，并签订3年及以上的委托管理合同，且正式以引进方酒店管理品牌冠名。

二、扶持政策

对符合奖励扶持条件的酒店从正式营业之日起算，每满12个月为1个营业年度，前3个营业年度所交纳的增值税、企业所得税、房产税、土地使用税、城市维护建设税、教育费附加等税收，分营业年度将市、区（园区）级留成部分的50%奖励给纳税酒店，用于扶持酒店经营发展。

三、扶持政策的申报和审批

符合税收收入市、区（园区）级留成部分奖励扶持的酒店，在每个经营年度终了后，持酒店法人登记证、经营许可证、经税务部门确认的纳税票据和完税证明、税收奖励扶持申请向市财政局申报奖励扶持资金，市财政局会同相关行业主管部门审核认定后，列入下一年度市、区（园区）级财政预算并拨付到应得酒店。

四、其他事项

（一）引进或建设时另有其他优惠或奖补扶持政策约定的酒店，引进或建设时约定的优惠或奖补幅度大于本通知规定的奖励扶持政策的，按引进或建设时约定政策执行，不得重复享受本通知规定的奖励扶持政策；引进或建设时约定的优惠或奖补幅度小于本通知规定的奖励扶持政策的，由酒店业主选择按本通知规定的奖励扶持政策或按引进（或建设）时约定的政策执行，但不得重复享受。

（二）属房地产开发项目的配套酒店，且已享受其他优惠、奖补扶持政策的，不再享受本通知规定的奖励扶持政策。

（三）本通知规定的奖励扶持政策执行时间为2019年1月1日—2025年12月31日，即2025年12月31日后投入运营的酒店不再享受本通知规定的奖励扶持政策，原已享受本通知规定的奖励扶持政策但不满3年的，继续享受奖励扶持政策到3年期满。

（四）本扶持政策由市财政局负责解释。
