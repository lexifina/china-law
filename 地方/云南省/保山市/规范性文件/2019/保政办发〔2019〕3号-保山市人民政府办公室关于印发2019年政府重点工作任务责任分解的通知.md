# 保山市人民政府办公室关于印发2019年政府重点工作任务责任分解的通知

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

经市人民政府同意，现将《保山市2019年政府重点工作任务责任分解》（支撑性指标、保障性工作）印发给你们，并就有关事项通知如下，请认真抓好贯彻落实：

一、政府重点工作任务实行牵头主办部门负责制。各牵头主办部门要按照“谁牵头、谁落实，谁负责、谁落实”的原则，主动协调，牵头研究，逐项对照工作任务，于2019年1月31日前制定实施方案报市人民政府领导审阅，同时抄送市政府督查室；实施方案要细化各配合单位工作职责，逐项倒排工作时间表，明确时间节点和具体责任人；要加强向责任领导请示报告，确保圆满完成有关工作任务。各主要配合单位对涉及职能范围内的工作事项要主动担当，加强组织实施和协调服务，积极配合牵头主办部门完成所承担的工作。其他未详列的有关单位，要根据具体工作要求，按照牵头主办部门的统筹要求，对所需承担的工作任务务必认真履职尽责。各县（市、区）、园区要对照工作任务，认真完成所承担的工作任务，确保各项重点工作任务全面落实落地。

二、各牵头主办部门要指定1名责任心强、熟悉业务的人员专门负责有关工作任务推进情况的汇总上报工作，分别于2019年4月15日、7月15日、10月15日和2020年1月15日前将1季度、上半年、前3季度和全年的支撑性指标和保障性工作任务完成情况按照样表格式（见附件），经单位负责人审核签字并加盖公章后报送市政府督查室（联系电话：2121551，邮箱：2121551@163.com）。上报内容要全面、文字要简练、数据要统一，坚决杜绝迟报、漏报、瞒报、虚报现象发生。

三、政府重点工作任务责任贯彻落实情况以及工作推进情况材料上报工作纳入年度综合考评指标体系，市人民政府办公室、市政府督查室要根据各项工作进展情况适时组织开展督查调研，定期梳理汇总贯彻落实情况。对完不成任务目标的，上报材料不及时不准确的，由市政府督查室协同牵头主办部门厘清责任主体，依据《中共保山市委办公室保山市人民政府办公室关于印发<保山市督查工作考核办法>的通知》（保办字〔2018〕46号），在年终综合考评指标中对有关责任单位给予扣分处理。
