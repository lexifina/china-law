# 保山市人民政府办公室关于成立保山市决战县域高速公路“能通全通”工程领导小组的通知

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

领导小组下设办公室在市交通运输局，办公室主任由成德君同志兼任，办公室副主任由市发展改革委副主任赵继会、市财政局副局长侯琰、市自然资源和规划局副局长赵品银、市交通运输局副局长杨立凯、市国资委副主任邵平担任，办公室人员从领导小组成员单位抽调。

二、领导小组及办公室工作职责

领导小组主要职责：落实省决战县域高速公路“能通全通”工程领导小组的决定；全面组织、指导市直有关部门、有关单位和县（市、区）人民政府决战全市县域高速公路“能通全通”工程；统筹研究全市县域高速公路“互联互通”工程的建设规划和重大决策，组织推进“互联互通”工程建设；研究全市高速公路投融资建设模式，协调金融机构对高速公路建设提供融资支持，指导解决建设资金问题；协调解决建设中的重大问题。

办公室主要职责：承担领导小组日常工作；协调领导小组各成员单位推进决战全市县域高速公路“能通全通”工程，督促落实领导小组决定事项；提出县域高速公路“互联互通”工程的建设规划；按照“一项目一方案”方式制定高速公路项目推进方案，明确时间表、路线图和责任清单，挂图作战推进各项工作任务，及时研究解决推进过程中的困难和问题；加强高速公路项目储备；建立工作通报机制，每月通报、排名工作进展情况；完成领导小组交办的其他工作。

三、有关要求

（一）领导小组定期召开会议，听取各项工作推进情况汇报，调度研究有关工作，安排部署下一阶段工作；领导小组办公室每月至少研究1次工作，遇有特殊情况，要及时研究解决。

（二）各县（市、区）人民政府是本地决战县域高速公路“能通全通”工程的责任主体，主要负责人是第一责任人，要加强组织领导，建立相应工作机制，统筹推进本地决战县域高速公路“能通全通”工程各项工作。

（三）市直有关部门、有关单位要切实履行工作职责，明确专门机构，组织专门力量，实行专人负责，畅通工作联络渠道，形成合力，全力推动决战县域高速公路“能通全通”工程各项任务如期完成。

领导小组成员如有变动，由成员单位相应岗位职责人员自行递补，并报领导小组办公室备案，不再另行发文。
