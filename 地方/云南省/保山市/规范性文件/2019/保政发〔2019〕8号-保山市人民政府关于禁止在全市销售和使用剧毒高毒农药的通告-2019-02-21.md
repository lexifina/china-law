# 保山市人民政府关于禁止在全市销售和使用剧毒高毒农药的通告

各县（市、区）人民政府，各园区管委会，市直各委、办、局：

为贯彻落实“创新、协调、绿色、开放、共享”发展理念和乡村振兴战略，发展绿色生态农业，保障农产品质量安全、生态环境安全和人民生命安全，根据中华人民共和国农业部第199号、第2445号、第2552号等公告规定，现通告如下：

一、禁止销售和使用的农药

六六六、滴滴涕、毒杀芬、二溴氯丙烷、杀虫脒、二溴乙烷、除草醚、艾氏剂、狄氏剂、汞制剂、砷类、铅类、敌枯双、氟乙酰胺、甘氟、毒鼠强、氟乙酸钠、毒鼠硅、甲胺磷、对硫磷、甲基对硫磷、久效磷、磷胺、苯线磷、地虫硫磷、甲基硫环磷、磷化钙、磷化镁、磷化锌、硫线磷、蝇毒磷、治螟磷、特丁硫磷、硫丹、氯磺隆、福美胂、福美甲胂、甲磺隆、百草枯水剂、磷化铝、有效成分含量30%以下草甘膦混配水剂、胺苯磺隆、八氯二丙醚。

二、禁止在烟草、蔬菜、果树、茶叶、中草药材上使用的农药

甲拌磷、甲基异柳磷、内吸磷、克百威、涕灭威、灭线磷、硫环磷、氯唑磷、毒死蜱、三唑磷、氧乐果、灭多威、三氯杀螨醇、氰戊菊酯、丁酰肼、水胺硫磷、杀扑磷、氟虫腈、溴甲烷、氯化苦、乙酰甲胺磷、乐果、丁硫克百威、氟苯虫酰胺、2,4-滴丁酯、百草枯（胶剂）不得用于烟草、蔬菜、果树、茶叶、中草药材上。任何农药产品都不得超出农药登记批准的使用范围使用。

三、在烟草上禁止使用和推荐使用的农药

禁止使用的农药：多菌灵、氟氯氰菊酯、高效氯氟氰菊酯、三氯苯酚代乙酸、甲草胺、乙基谷硫磷、谷硫磷、克菌丹、氯丹、克死螨、毒虫畏、杀螨酯、甲基内吸磷、敌敌畏、乙拌磷、异狄氏剂、杀虫丹、克线磷、六六粉、七氯、林丹、利谷隆、灭虫威、速灭磷、灭蚁灵、杀线威、五氯苯甲醚、五氯苯酚、残杀威、七氟菊酯、特丁磷。

推荐使用的农药：吡虫啉、阿维·吡虫啉、吡蚜酮、甲氨基阿维菌素苯甲酸盐、腈菌唑、甲霜·锰锌、甲霜·霜霉威、溴氰菊酯。

请各农药经营单位和广大用户严格遵守，互相监督。各级农业执法部门要加大对高剧毒农药销售和使用的监管力度，一旦发现违规经营和使用者，将按《农药管理条例》及相关法规予以处罚。

保山市人民政府

2019年2月20日
