# 保山市人民政府办公室关于做好2019年度个人所得税综合所得汇算清缴工作的通知

各县（区、市）人民政府，各园区管委会，市直各委、办、局：

根据个人所得税法及其实施条例、《国家税务总局关于办理2019年度个人所得税综合所得汇算清缴事项的公告》（国家税务总局公告2019年第44号）、《保山市人民政府办公室关于加强税收征管保障工作的通知》（保政办函〔2019〕36号）有关规定和精神，自2020年3月1日起，首次个人所得税综合所得汇算清缴工作（以下简称汇缴工作）实施。为确保全市汇缴工作平稳有序开展，经市人民政府同意，现将有关工作通知如下：

一、成立领导小组，加强组织领导

为稳妥推进全市汇缴工作，切实加强组织领导，推动形成上下联动、协同高效、社会共治的工作格局，市人民政府决定成立保山市个人所得税综合所得汇算清缴工作领导小组（见附件），负责全市汇算清缴工作的组织、协调、指导和考核。领导小组组长由分管税务工作的副市长担任，市财政局局长、人民银行保山市中心支行行长、市税务局局长任副组长，成员由市政府督查室、财政局、发展改革委、教育体育局、公安局、民政局、人力资源社会保障局、医保局、住房公积金管理中心，市税务局、人民银行保山市中心支行组成。

二、提高政治站位，增强责任意识

新的个人所得税改革是党中央、国务院着眼于优化税收制度、推动经济发展、惠及百姓民生作出的一项重大决策，新的个人所得税制实现了从分类税制向综合与分类相结合税制的重大转变，征收方式由过去以扣缴义务人代扣代缴为主转为扣缴义务人代扣代缴和纳税人自行申报相结合。

首次汇缴工作具有体量大、业务新、链条长、风险多的特点，将面对流动分散且数量庞大的纳税人，涉及海量涉税信息的采集应用和风险比对，对税收征管、纳税服务和信息化建设带来前所未有的挑战。各级各有关单位要充分认识汇缴任务的艰巨性、复杂性、重要性，切实增强使命感、责任感和紧迫感，确保将汇缴工作落到实处。

三、区别汇缴群体，分类分策汇算

根据个人所得税法规定，2020年3月1日—6月30日，居民个人（以下称纳税人）需要汇总2019年1月1日—12月31日取得的工资薪金、劳务报酬、稿酬、特许权使用费等4项所得（以下简称综合所得）的收入额，适用修改后的个人所得税法及有关规定计算年度最终应纳税额，再减去2019年度已预缴税额，得出本年度应退或应补税额，向税务机关申报并办理退税或补税。纳税人需要办理2019年度汇算的情形：一是2019年度已预缴税额大于年度应纳税额且申请退税的。包括2019年度综合所得收入额不超过6万元但已预缴个人所得税；年度中间劳务报酬、稿酬、特许权使用费适用的预扣率高于综合所得年适用税率；预缴税款时，未申报扣除或未足额扣除减除费用、专项扣除、专项附加扣除、依法确定的其他扣除或捐赠，以及未申报享受或未足额享受综合所得税收优惠等情形。二是2019年度综合所得收入超过12万元且需要补税金额超过400元的。包括取得2处及以上综合所得，合并后适用税率提高导致已预缴税额小于年度应纳税额等情形。

全市各级税务机关要有效划分“重点汇算人群”、“一般汇算人群”、“豁免汇算人群”，做到分类施策、精准辅导。进一步加强年度汇算的政策解读和操作辅导力度，分类编制办税指引，通俗解释政策口径、专业术语和操作流程，多渠道、多形式开展提示提醒服务，并通过手机个人所得税APP、网页端、12366纳税服务热线等渠道提供涉税咨询，帮助纳税人解决办理年度汇算中的疑难问题，积极回应纳税人诉求。各有关单位要按照本地疫情防控形势和要求，在汇缴期内妥善灵活调整有关安排和细化落实网格化管理责任，暂缓对医院等参与防控防疫的单位和人员开展年度汇算工作。

四、压实工作责任，加强分工协作

汇缴工作需要部门之间密切配合、协同推进，有关部门既要各司其职，又要密切协作，形成工作合力，协同完成各项工作任务。根据个人所得税法第十五条“公安、人民银行、金融监督管理等相关部门应当协助税务机关确认纳税人的身份、金融账户信息。教育、卫生、医疗保障、民政、人力资源社会保障、住房城乡建设、公安、人民银行、金融监督管理等相关部门应当向税务机关提供纳税人子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人等专项附加扣除信息”的要求，有关部门要配合税务部门做好专项附加扣除数据共享、信息核验和后续管理工作。

各级各部门要压实工作责任，督促本地、本单位人员完成APP下载注册、实名认证、专项附加扣除信息采集修改、收入明细查询、银行卡信息采集等基础工作。各单位要配合税务部门深入做好疫情防控期间办理汇算清缴的服务引导工作，按照“尽可能网上办”的原则，分批、分期、分策积极引导本单位人员，优先通过个人所得税手机APP、网页端等自然人电子税务局渠道完成自行申报。对于收入来源单一、愿意委托单位办理的纳税人，要完善并畅通扣缴义务人代为办理渠道。

各级税务、财政、人民银行要及时沟通退税办理情况，确保退税资金充足、退税流程快捷。税务部门与发展改革部门要落实纳税信用管理机制，及时对不遵从纳税人实施信用联合惩戒。有关单位要加强政策宣传，营造良好汇缴氛围，规范政策口径，督促员工如实填报有关涉税信息，提高纳税遵从度，按照当地税务部门通知，按期完成汇缴申报。

五、严明工作纪律，确保数据安全

个人所得税数据具有高度敏感性，各级各部门在工作开展中要严明工作纪律，防止数据外泄，确保数据安全。要严格做好舆论风险防控工作，进一步加强舆情监测，做好宣传解释，发现舆情要及时上报并做好处置工作。

六、加强督导考核，保证工作质量

为确保各级各部门切实履行工作职责，市人民政府建立汇缴工作责任机制，将汇算清缴完成率、准确率纳入市政府税收征管保障督查事项。市级将建立工作通报制度，定期通报工作完成进度，对落实不力的单位将追究相关人员责任。
