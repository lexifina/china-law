# 龙陵县人民政府办公室关于印发龙陵县深化出租汽车行业改革实施细则的通知

各乡、镇人民政府，县政府各工作部门，县直有关单位：

《龙陵县深化出租汽车行业改革实施细则》已经县人民政府同意，现印发给你们，请认真遵照执行。

2017年2月28日

龙陵县深化出租汽车行业改革实施细则

为贯彻落实党中央、国务院、省及市委、市政府深化改革的决策部署，慎稳推进出租汽车行业改革，鼓励创新，促进转型，进一步满足人民群众出行需求，根据《国务院关于进一步深化改革推进出租汽车行业健康发展的指导意见》（国办发〔2016〕58号）、《云南省人民政府关于深化改革推进出租汽车健康发展的实施意见》（云政办发〔2016〕112号）和《保山市人民政府关于深化改革推进出租汽车行业健康发展的实施意见》（保政办发〔2016〕197号）精神要求，确保全县出租汽车行业改革积极稳妥有序推进，结合龙陵县实际，制定如下实施细则。

一、改革指导思想、原则和目标

（一）指导思想

全面贯彻落实国家、省和市关于深化出租汽车改革决策部署，牢固树立创新、协调、绿色、开放、共享的发展理念。坚持优先发展公共交通、适度发展出租汽车的基本思路，正确处理出租汽车行业改革、发展和稳定的关系，以改革促发展，优化出租汽车行业结构，构建包括巡游出租汽车（以下简称巡游车）和网络预约出租汽车（以下简称网约车）在内的多样化服务体系，以增量带动存量促进传统出租汽车转型升级，满足人民群众的差异化出行需求，促进出租汽车行业稳定、规范、健康发展。

（二）基本原则

1．坚持公交优先，乘客为本。建立城市“公交为主、出租为辅”的交通发展理念，突出公交公益属性，以改善城市公共交通条件、保障乘客安全出行和维护人民群众合法权益作为改革的出发点和落脚点，为社会公众提供安全、便捷、舒适、经济的个性化出行服务。

2．坚持问题导向，稳改结合。出租汽车行业改革是一项重大民生工程，应当尊重历史形成和行业发展过程中形成的客观现实，兼顾各方合法利益，处理好改革、发展、稳定之间的关系，坚持“控总量、稳运价、调结构、上水平”发展政策，稳改结合，积极稳慎推进出租汽车行业改革发展。

3．坚持依法规范，鼓励创新。正确处理政府和市场的关系，强化法治思维，完善出租汽车行业法规体系，依法推进行业改革，维护公平竞争的市场秩序，结合行业现实矛盾，抓住实施“互联网+”行动的有利时机，拓宽思路，勇于创新，解决问题，促进发展。

4．坚持统筹兼顾，融合发展。统筹发展巡游车与网约车实行错位发展和差异化经营，统筹创新发展与安全稳定，统筹新老业态发展，为社会公众提供品质化、多样化的运输服务，推进新老业态融合发展。

5．坚持部门联动，分工负责。深化出租汽车改革实行县人民政府为主体，各职能部门为责任主体，坚持政府主导，部门联动，各部门要充分发挥自主权和创造性，积极探索符合全县出租汽车行业发展实际的管理模式。

（三）改革目标

坚持公交优先的发展战略，确立公共交通在城市交通体系中的主导地位，充分发挥市场机制和政府引导作用，加快供给侧结构性改革，促进出租汽车与互联网融合创新，统筹巡游车和网约车错位发展，实行差异化经营，着力规范出租汽车行业管理体制和运营模式，切实提升服务水平和监管能力，使出租汽车服务质量显著提高、出租汽车行业形象明显提升，实现出租汽车市场化资源配置，有效解决部分群众“打车难”的问题，逐步构建符合社会公众出行需求的城市公共交通运输服务体系。

二、科学定位适度发展

（一）科学定位出租汽车服务。出租汽车是城市综合交通运输体系的组成部分，是城市公共交通的补充，为社会公众提供个性化运输服务，切实确立“公交为主、出租为辅”的城市公共交通发展理念。

（二）确定出租汽车服务形式。出租汽车服务主要包括巡游车和网约车。巡游车喷涂、安装明显的巡游车专用标识，主要在道路上巡游揽客、站点候车，也可通过电信、互联网等方式提供运营服务；网约车要有明显的运营标识，是以互联网技术为依托构建服务平台，通过线上线下提供服务，不得提供在道路上巡游揽客、站点候客等运营服务。县人民政府根据全县公共交通营运情况和市场需求，统筹发展巡游车和网约车，培育多元化服务体系，实行错位发展和差异化经营，为人民群众提供高品质、多样化的出行服务。

（三）建立总量动态调控机制。根据当前全县出租汽车管理和经营特点、社会公众多样化出行需求及出租车发展定位，综合考虑人口数量、经济发展水平、城市道路承载能力、出租车里程利用率、环境保护等因素，合理确定出租汽车运力规模和在城市综合交通运输体系中的分担比例，建立动态监测和调控机制，逐步实现市场调节。同时坚持优先发展城市公共交通，巡游车和网约车要有合理的运力规模和结构，实行动态控制，使其与本地公交发展水平相协调，与城市经济社会发展相适应。新增和更新出租汽车，鼓励、支持使用新能源或清洁能源车辆。

三、改革行业管理体制

（一）理顺管理体制。按照国家大部制机构改革要求，将管理职责划转到县级道路运输管理机构，在县级人民政府领导下，负责具体实施出租汽车行业管理。县人民政府根据实际情况核定具体承担出租汽车管理职责的道路运输管理机构的人员编制数，并将工作经费纳入本级财政预算。

（二）厘清部门职责。县级交通运输主管部门在本级人民政府领导下，负责指导监督本行政区域内出租汽车行业管理。县级道路运输管理机构在本级人民政府和交通运输主管部门领导下，具体负责实施本行政区域内出租汽车行业管理。

政法、宣传、维稳、应急、发改、工信、公安、财政、人社、住建、人行、税务、市场监管、法制、金融、网信、信访、工会等部门依据法定职责，对出租汽车实施相关监督管理。

（三）加强制度建设。加快完善出租汽车管理和经营服务的标准规范，明确管理职责和主体责任，规范资质条件和经营许可，形成较为完善的出租汽车管理规范体系，实现出租汽车行业管理、经营服务和市场监督有法可依、有章可循。

四、深化巡游车改革

（一）实施巡游出租汽车运力动态调整。将综合城市人口、经济水平、出行需求、出租汽车里程利用率等因素，结合本地出租汽车在综合交通运输体系中的分担比例等因素，行业管理部门制定巡游车运力投放指标体系，建立巡游车运力动态监测调整机制，每年调整公布运力规模，科学动态调整运力，逐步实行市场化配置。

（二）完善经营权管理制度。出租汽车经营权实行政府许可和期限制，经营期限为8年，一律实行无偿使用，经营期限内不得擅自变更经营主体，确需变更经营主体的，依照法律法规规定的条件和程序办理。经营期满后经营者拟继续经营的，可按照规定向道路运输管理机构提出申请，道路运输管理机构以其服务质量信誉考核结果为主要依据，考核合格的予以重新许可；考核不合格或未按照规定提出申请的，不再予以许可,依法无偿收回经营权；对服务质量信誉好的经营者，经营到期后重新配置时可以得到优先配置，保持经营服务及市场稳定。

（三）建立经营权退出机制。行业管理部门要建立和完善以服务质量信誉为导向的经营权配置和管理制度，对经营期限届满或经营过程中出现重大服务质量问题、重大安全生产责任事故、严重违法经营行为、服务质量信誉考核不合格等情形，按有关规定依法收回经营权。

（四）清理经营权归属。全面清理规范经营关系，经营者取得经营权的，应当实行《机动车行驶证》《道路运输证》《从业资格证》三证合一管理，不得向驾驶员转嫁经营风险。出租汽车经营权不得变更经营主体，凡私下炒卖和擅自转让的，依法收回其经营权。

（五）健全利益分配制度。规范企业收费行为，抓紧清理、废止违反国家政策的不合理收费项目。出租汽车企业要依法与驾驶员签订劳动合同或经营合同。行业管理部门要保护驾驶员合法权益，构建和谐劳动关系。要利用互联网技术更好的构建企业和驾驶员运营风险共担、利益合理分配的经营模式。鼓励、支持和引导出租汽车企业、行业协会与出租汽车驾驶员、工会组织平等协商，根据经营成本、运价变化等因素，合理确定、动态调整出租汽车管理费。严禁出租汽车企业向驾驶员收取高额抵押金。

（六）完善营运价格形成机制。进一步发挥市场在资源配置中的决定性作用，对巡游车运价实行政府定价。对巡游车电召、网约服务等其他增值服务实行市场调节价，充分发挥运价调节出租汽车运输市场供求关系的杠杆作用；要建立合理的巡游车运价形成机制和动态调整机制，健全作价规则，完善运价与燃油价格联动办法，综合考虑巡游出租汽车运营成本、居民和驾驶员收入水平、交通状况、服务质量及消费价格指数等因素，定期对巡游车运价进行评估，科学制订、及时调整巡游车运价；要加强价格监督检查、畅通投诉举报渠道，及时处理、反馈驾驶员及乘客有关价格和收费的合理诉求，对涉及出租汽车行业的价格违法行为要严肃查处，切实保障出租汽车驾驶员和乘客合法权益。

（七）推动行业转型升级。加快推进出租汽车行业“互联网+”发展，鼓励巡游车经营者、网约车经营者通过兼并、重组、吸收入股等方式，按照现代企业制度实行公司化经营，实现新老业态融合发展，鼓励巡游车通过电信、互联网等电召服务方式提供运营服务，推广使用符合金融标准的非现金支付方式，拓展服务功能，减少车辆空驶，降低驾驶员劳动强度，方便公众乘车。巡游车在巡游揽客和电召时，均使用巡游车专用的出租汽车计程计价装置，并据此收费和出具出租汽车专用发票。

（八）加强从业人员规范管理。出租汽车企业要落实主体责任，完善内部管理制度，关心关爱驾驶员，逐步提高本地驾驶员从业比例。加强驾驶员的教育培训和管理，构建和谐劳动关系。强化出租汽车驾驶员动态管理，规范从业行为，落实出租汽车服务质量信誉考核制度和驾驶员从业资格管理制度，加强驾驶员从业资格准入、注册、继续教育等工作，提高文明服务水平；将出租汽车从业人员非法集聚、集体罢运、集体上访等严重扰乱社会秩序事件纳入县级应急处置管理体系，采取有效措施，及时进行管控。

五、规范发展网约车

（一）规范经营者管理。网约车经营者（以下简称网约车平台公司）作为运输服务提供者，应具备线上线下服务能力，承担承运人责任和相应的社会责任，具备企业法人资格、取得出租车经营许可。申请从事网约车经营的平台企业，应在属地依法办理工商注册和税务登记，并在经营所在地设置服务机构、办公场所，具备相应的服务能力，获得省级交通运输主管部门联合工业和信息化、公安、网信等相关部门出具的线上服务能力认定后，向属地道路运输管理机构提出申请办理《网络预约出租汽车经营许可证》，经营期限为8年，到期经审核合格后可延续许可。网约车平台公司相关服务器应设在中国内地，网络服务平台数据库应接入服务所在地道路运输管理机构的信息化监管平台，自觉接受检查和管理。

（二）规范车辆管理。从事网约车经营的车辆应当为本市车辆号牌的7座及以下乘用车，车辆初次注册登记时间未满4年，安装具有行驶记录功能的卫星定位装置和应急报警装置，车辆按规定开展相应的维护和检测，技术性能符合运营相关标准，按照高品质服务、差异化发展的原则，车型档次应高于本地巡游车标准，优先使用新能源汽车，使用性质应登记为预约出租客运，并取得服务所在地道路运输管理机构核发的《网络预约出租汽车运输证》。网约车运营标识由道路运输管理部门确定，车辆经营权不得擅自转让，车辆经营权期限自车辆注册登记之日起最长不超过8年，行驶里程达到60万千米时强制报废；行驶里程未达到60万千米但使用年限已达到8年时，必须退出网约车经营。车辆报废、转出、所有权擅自转让的，注销车辆经营权；平台公司与车辆接入关系终止或者平台公司经营期终止的，车辆在未办理接入新平台期间，不得从事网约车运营活动。

（三）规范驾驶员管理。从事网约车经营的驾驶员为服务所在地户籍或居住满1年以上，应取得相应准驾车型的机动车驾驶证并具有3年以上驾驶经历，初中以上文化程度，男性年龄在60周岁、女性年龄在55周岁以下，无交通肇事犯罪，危险驾驶犯罪记录，无吸毒、饮酒后驾驶记录，最近3个记分周期没有被扣满分记录，无暴力犯罪记录，身体健康等。经服务所在地设区的市级道路运输管理机构审查和考核后，核发《网约出租汽车驾驶员证》。取得《网约出租汽车驾驶员证》的驾驶员，由所属网约平台公司向县道路运输管理机构申请注册。网约车平台公司应当依法与驾驶员签订多种形式的劳动合同或协议，明确双方的权利和义务；网约车平台企业应当维护和保障驾驶员的合法权益，开展有关法律法规、安全运营、服务规范、职业道德等方面的岗前培训和日常教育。

（四）建立价格形成机制。网约车运价实行市场调节价，必要时实行政府指导价，网约车运价原则上应不低于巡游车运价。网约车平台公司要提前公示作价规则、计程计价方式和价格标准，按规定明码标价，计程计价方式要符合国家和本县有关规定。网约车平台公司不得有为排挤竞争对手或者独占市场以低于成本的价格运营、不得滥用市场支配地位以不公平的高价运营等扰乱正常市场秩序、损害公众利益或者其他经营合法权益的价格违法行为。网约车要提供本县出租汽车专用发票，不得侵害乘客合法权益和社会公共利益。

（五）规范经营行为。网约车平台公司应当依法纳税，必须承担安全生产、承运人、信息安全、网络安全和相应社会责任，承担车辆、驾驶员的安全管理职责和驾驶员队伍稳定责任，购买履行承运人责任的相关保险。对服务过程中发生的安全事故、责任事故等，承担先行赔付责任，不得以任何形式向乘客及驾驶员转移运输服务风险。

网约车平台公司要按有关法律法规规定，负责组织运营车辆、确定服务价格、制定服务标准、驾驶员管理和服务监督等网约车经营活动管理。线上要加强对网约车经营全过程的动态监控，确保驾驶员按照国家相关规定和标准提供运营服务，制定相应管理措施，实行非现金支付结算；线下要加强对提供服务的车辆和驾驶员的管理，确保车辆技术状况良好、安全性能可靠，具有劳动车辆相关保险，线上提供服务的车辆和驾驶员与线下实际提供服务的车辆和驾驶员一致。网约车通过网络预约方式提供运营服务，不得巡游揽客，不得以私人小客车合乘名义提供网约车经营服务。网约车应当在许可的经营区域内从事经营活动，超出经营区域的，起讫一端应当在许可的经营区域内。

网约车平台公司在服务所在地必须有完备的监控体系，不得泄漏事关国家安全的敏感信息，采集的相关个人信息和生成的相关业务数据仅限于在中国大陆境内存储和使用。

（六）规范私人小客车合乘。私人小客车合乘，也称为拼车、顺风车，是由合乘服务提供者事先发布出行信息，出行线路相同的人选择乘坐合乘服务提供者的小客车、分摊部分出行成本或免费互助的共享出行方式，县相关职能部门要予以支持，其具体管理规定另行制定。

私人小客车合乘不属于道路运输经营行为，是合乘各方自愿的民事行为，相关权利、义务及安全责任事故等由合乘方依法、依约自行承担。公安、道路运输管理、工信等部门，要坚决打击以私人小客车合乘名义从事非法运营的行为。

六、营造良好市场环境

（一）依法严厉打击违法违规行为。按照“政府管理、联合执法”的原则，坚持日常打击与集中整治相结合，完善“政府牵头、部门参与、条块联动”的打击非法营运长效工作机制。各有关部门按照部门职责，对违法违规行为依法从严查处，加大惩处力度。

（二）推进服务网点建设，完善配套服务设施。县职能部门要加快出租汽车综合服务区、专用候客泊位（停靠点）、加气站、充（换）电站等配套服务设施的布局和建设。机场、火车站、一级汽车客运站、码头等大型交通枢纽必须设置出租汽车专用停车候客区，商场、医院、学校等公共场所和居民住宅区应当划定出租汽车临时停车位，为出租汽车运营提供便利。要规划建设出租汽车驾驶员服务站，切实解决出租汽车驾驶员在停车、就餐、如厕等方面的实际困难。要在公交专用道沿线适当地点设置出租汽车临时停靠点，允许出租汽车在载客时使用公交专用道并在限行的路段和路口享有与公交同等的路权。

（三）加强行业信用体系建设。落实服务质量信誉考核制度和驾驶员从业资格管理制度，制定出租汽车企业、服务标准和从业人员信用管理制度，明确依法经营、诚信服务的基本要求。积极运用互联网、大数据、云计算等技术，建立出租汽车企业和驾驶员评价系统，加强对违法违规及失信行为、投诉举报、乘客服务评价等信息的记录，作为出租汽车企业和从业人员准入退出的重要依据，并纳入信用信息共享平台和企业信用信息公示系统，把社会各界对出租汽车经营者和驾驶员的评价结果，运用到行业准入和退出过程中，真正实现优胜劣汰。

（四）弘扬行业新风。完善优秀驾驶员表彰奖励制度，开展星级驾驶员、星级服务标兵车和优秀企业评选活动，对文明服务、见义勇为、拾金不昧、助人为乐的驾驶员和管理规范、服务优质的经营企业给予表彰；发挥弘扬雷锋车队、共产党员红旗示范车队等示范作用，积极推进行业精神文明建设，提升出租汽车行业新形象。倡导驾驶员与乘客相互理解、相互尊重的风气，形成全社会关心关爱驾驶员的良好氛围。

（五）提升市场监管水平。强化事前、事中和事后全过程监管，实现管理的闭环，建立完善政府监管平台，积极运用科技信息化手段，提高监管能力，将对出租汽车行业的监督检查情况向社会公布，提高监管透明度。结合出租汽车服务新业态，完善出租汽车服务管理信息管理体系，提高运行和管理效率；建设驾驶员供求信息平台，为企业和驾驶员提供便利。

发展和改革（价格）、通信、公安、人力资源社会保障、工信、住建、人民银行、税务、市场管理监督、网络等部门按照各自职责，对出租汽车经营行为实施相关监督检查，并对违法行为依法处理。

七、保障措施

（一）加强组织领导。成立以县人民政府主要领导为组长，政法、宣传、维稳、应急、发改、工信、公安、财政、人社、交通、住建、人行、税务、市场监管、法制、金融、网信、信访、工会等部门主要领导为成员的龙陵县深化出租汽车行业改革领导小组，统一指导，分组负责，同时加强与工会的沟通协作，努力提升治理能力，履职尽责，形成合力，共同推进出租汽车行业改革工作。

（二）做好舆论宣传和引导。县直有关部门要明确分工、紧密协作、深入分析、准确研判、周密准备，注意舆论宣传和引导工作，对改革的指导思想、基本原则和主要改革内容等社会高度关注的问题，全面细致地做好政策宣传和解疑释惑，让社会更加理性面对、了解和支持出租汽车改革，为行业改革营造良好舆论氛围。

（三）维护行业稳定。各相关部门要高度重视出租汽车行业稳定工作，全面落实维稳主体责任，做到守土有责、守土尽责。要按照规定的时间出台针对性强、可操作性强的改革实施方案、细则和配套政策措施。在制定过程中，要加强调研、实事求是、公开透明、广开言路，对经营权改革、网约车规范管理落地政策的推出及过渡方案等重大决策，要广泛征求意见，并完成专家论证、开展社会稳定风险评估等重大事项决策程序，完善应急预案，化解各类矛盾，切实维护行业和社会稳定。
