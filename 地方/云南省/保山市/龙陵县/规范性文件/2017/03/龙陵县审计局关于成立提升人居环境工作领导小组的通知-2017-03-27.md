# 龙陵县审计局关于成立提升人居环境工作领导小组的通知

各股（室）、中心：

根据《中共龙陵县委办公室龙陵县人民政府办公室关于印发〈龙陵县进一步提升城乡人居环境五年行动计划（2016-2020年）〉的通知》（龙办发﹝2017﹞13号）文件要求，局党组认真抓好贯彻落实，并经局党组会议研究决定，成立龙陵县审计局提升人居环境工作领导小组如下：

组 长：杨太能 党组成员、局 长

副组长：段祖庆 党组书记、副局长

赧光荣 党组成员、副局长

杨永辉 党组成员、副局长

成 员：各股（室）、中心负责人。

领导小组下设办公室在局办公室，由杨永辉副局长任办公室主任，杨泽从、赵旭任办公室副主任，负责处理日常事务，其他工作人员视工作推进情况从各股（室）、中心抽调。
