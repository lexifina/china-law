# 龙陵县招商局关于调整领导班子成员分工的通知

因人事变动，经县招商局领导班子会议研究，决定将领导班子成员工作分工调整如下：

张睿玲（党支部书记、局长）：主持县招商局党支部及招商局全面工作。具体负责对接新材料及先进装备制造业项目。联系人：杨树昌。

杨树昌（党支部副书记、副局长）：协助支部书记、局长工作，分管办公室、党建、党风廉政建设、档案、保密、扶贫（“挂包帮”“转走访”）、信访、干部人事、工会、意识形态、政府信息公开和外宣工作。负责县内相关部门的对接联系、各种重要材料的撰写和审核把关，相关会议、活动的组织筹备等工作；负责莅龙考察企业（客商）接洽、接待及已落户企业的走访和协调服务工作；负责做好党建、党风廉政建设、保密、扶贫（“挂包帮”“转走访”）、信访、工会、意识形态工作。具体负责高原特色现代农业和生物资源产业项目工作。联系人：杨有帅。

马 娜（副局长）：协助局长工作，分管招商股、财务、统计、物资采购、道路交通安全、综治维稳、防处邪教、依法治县、殡葬改革、禁毒、共青团和妇联工作。负责制订年度招商活动计划和招商引资项目储备、开发、包装、对外宣传推介和督查上报工作，负责县委、县政府外出招商小分队协调服务和组织开展对外招商活动；负责外出招商服务分局的联络、服务和管理工作；负责做好综治维稳、防处邪教、依法治县、殡葬改革和禁毒工作。具体负责对接文化旅游开发和大健康项目工作。联系人：夏志茂、卢焕艳。

段春久（副局长）：协助局长工作，全面负责昆明招商服务分局工作，含分局公务用车、财务等。联系人：杨丽萍。

龙陵县招商局领导班子成员工作既有明确分工，又有协作配合。分工协作关系如下：张睿玲—杨树昌，杨树昌—马娜，马娜—段春久。

龙陵县招商局
