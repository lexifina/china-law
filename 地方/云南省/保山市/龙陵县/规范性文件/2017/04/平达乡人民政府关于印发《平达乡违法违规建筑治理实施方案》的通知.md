# 平达乡人民政府关于印发《平达乡违法违规建筑治理实施方案》的通知

各(社区)村民委员会、乡直各单位：

经乡人民政府研究决定，现将《平达乡违法违规建筑治理实施方案》印发给你们，请认真贯彻执行。

平达乡人民政府

2017年4月10日

平达乡违法违规建筑治理实施方案

为进一步提升平达乡人居环境质量，加强乡村规划建设管理，全面创新管理手段，持续开展违法违规建筑治理工作，建立健全长效管理机制，有效控制和整治违法建设行为，按照《龙陵县城乡违法违规建筑治理工作实施方案》（龙办发〔2017〕19号）、《龙陵县进一步提升城乡人居环境五年行动计划（2016—2020年）》（龙办法〔2017〕13号）文件要求以及县委、县人民政府关于违法违规建筑整治工作的一系列文件、会议精神要求，结合平达乡实际，制定本行动方案。

一、总体目标

按照“杜绝增量、消化存量、建立机制、确保长效”的总体目标，坚持突出重点、疏堵结合，拆改结合、以拆为主,依法治理、属地为主、综合整治。完善防控违法违规建筑的制度体系，健全整治违法违规建筑的长效机制，全面开展平达乡违法违规建筑集中治理行动，重点查处违法占用土地，影响规划实施、影响集镇面貌、占用公共资源、影响居民生活、群众反映强烈的违法违规建筑行为，严控违法违规建筑增量，着力改善乡村人居环境和农村发展面貌，努力把平达乡建设管理水平提升到一个新高度。

二、具体工作目标任务

按照“问题导向、突出重点、杜绝增量、消化存量、建立机制、确保长效”的总体目标，通过宣传教育、调查摸底、集中整治、依法处理、检查验收、图斑对比、常态巡查等多种手段，分时、分区、分类、分期对平达乡违法违规建筑进行治理，建立健全农村建房规划许可制度，全面推进平达乡违法违规建筑治理工作。2017年，全力突破，并逐步处理违法违规建筑存量，消化违法违规建筑总量的70%，年底农村建房规划许可覆盖率达到40%以上；2018年，治理收尾，消化违法违规建筑总量的30%，农村建房规划许可覆盖率达到50%以上。2019年巩固治理成果，使违法违规建筑增量得到坚决遏制、存量基本整治、长效工作机制形成。

三、治理原则

（一）坚持依法整治，长效管理。坚持依法查处，整合执法力量，强力开展“两违”治理行动，切实加大现场巡查力度，采取行政、经济和法律等手段，及时有效打击新出现的“两违”行为，做到发现一起、查处一起、教育一片、惩戒一方。同时，构建长效管理机制，坚决杜绝新增“两违”行为，有序推进我乡辖区内建设和管理的规范化、制度化、法制化。

（二）坚持属地管理，分级负责。各村（社区）要分别成立“两违”整治工作领导小组，建立健全乡、村（社区）、组三级组织网络体系。落实属地管理主体责任，切实抓好“两违”问题的综合整治工作。明确乡直单位职责，积极配合各村（社区）开展治违工作。

（三）坚持群众参与，社会监督。强化宣传，广泛动员单位、企业和群众，自觉担负起建设、管护乡村义务，积极劝阻、制止和举报“两违”行为，动员“两违”主体自行消除违法违规行为。

（四）坚持自行整改和强制整治相结合。充分发挥党员干部带头作用及村（社区）宣传发动作用和依法强制整改的教育震慑作用，专项整治工作以“两违”主体自行整改为主、执法部门依法整治为辅。

四、治理重点

（一）治理范围

2017年，对集镇建成区（新街、老街）、主要交通道路沿线（省道231平达范围段、段家坝—木城公路平达范围段、河尾村—苏帕河段、乡政府—平达社区、河尾社区、平安社区、小河村、小田坝村主道路）、平达河（平安—河尾段）周边区域违法违规建筑进行治理。

2018年，对主要交通道路沿线（乡政府—章赛村、橄榄寨村、安庆村、黄连河村、安乐村）、重点江（怒江）河（苏帕河）流域、水库（岔河水库、小河水库、段家坝水库）周边区域违法违规建筑进行治理。

（二）治理内容

1．未取得建设用地手续进行建设的行为；

2．占道经营、乱摆乱停等影响集镇市容市貌和道路交通安全的行为；

3．不符合规划和改变用途的设施农用地上的建筑物、构筑物；

4．违法违规取沙采矿点；

5．不符合规划的广告牌、标示牌、通信基塔等实施；

6．占用公共空间进行建设的行为；

7．其他违法违规建筑物、构筑物。

（三）治理方式

采用拆除和整改相结合的方式，具体按以下进行治理。

1．拆除

（1）拆除对象。一是未取得建设用地手续进行建设的；二是违法违规取砂采矿点；三是占用公共空间的坡道、台阶等构筑物；四是存在安全隐患的；五是群众反映强烈的；六是正在进行违法建设的；七是已下达限期拆除违法建设决定书还未拆除的；八是未按整改要求进行建设的；九是其他应拆除的情形。

（2）拆除方式。由单位或个人在规定时限内自行拆除，拆除

费用自行负责；如未按规定进行拆除的，属干部职工的由所在单

位包保拆除，其他由所属村（社区）包保拆除，确实无法拆除的，必须书面向指挥部说明情况，如因不作为、推诿扯皮、弄虚作假等原因导致不能拆除的，乡党委政府将追究单位负责人和有关责任人的责任并承担依法拆除的费用；确实无法拆除的由平达乡人民政府依法进行拆除，拆除后不得重新建设。

2．整改

（1）整改对象。通过整改能符合规定的建筑物、构筑物。

（2）审批方式。纳入整改范围的需按有关程序办理建设手续，具体审批、监管、验收由国土和规划中心、国土所按现行有关审批程序办理。

（3）整改方式。整改由单位或个人自行整改，整改费用自行负责；未按规定时限进行整改或整改不达标的，属干部职工的由所在单位包保整改，其他由所属村（社区）包保整改，确实无法整改的，必须书面向指挥部说明情况，如因不作为、推诿扯皮、弄虚作假等原因导致不进行整改或整改不到位的，由乡党委政府追究单位负责人和有关责任人的责任并承担依法拆除的费用；确实不进行整改或整改不达标的由平达乡人民政府依法进行拆除，拆除后不得重新建设。

（四）治理步骤

1．宣传发动及摸底调查阶段（2016年11月—2017年4月）。2017年4月底前各村（社区）、各单位必须完成动员部署会议，进一步统一思想，对违法违规建筑治理工作进行全面安排部署，确定工作重点及职责分工，广泛宣传，完成治理范围内的各种违法违规建筑的调查摸底，进行分类统计和登记造册。4月7日前完成规划区范围内单位和干部职工（含离退休干部职工）违法违规建筑申报工作。

2．集中整治阶段（2017年5月1日—2018年12月31日）。2017年5月1日起按照分时、分区、分类、分期对违法违规建筑进行治理。6月30日以前完成示范点治理工作；9月底机关、企事业单位、村级集体经济组织和干部职工的违法违规建筑全部治理达标；11月底以前完成2017年治理内容；其他纳入整改范围的于2018年6月底全部整改达标，2018年底全部完成治理工作。各村（社区）、各单位根据职责分工，按步骤、分阶段逐步推进违法违规建筑综合治理工作。

3．巩固提高阶段（2019年1月—12月）。各村（社区）、各职能部门要加大日常监管力度，建立健全长效管理机制，防止违法违规建设行为反弹。大力宣传有关法律法规，提高市民素质，

切实巩固违法违规建筑整治成果。

4．检查验收阶段。2020年5月底完成自检自查，做好迎接上级考核验收准备。

六、工作要求

（一）统一思想，提高认识。当前，平达乡违法违规建筑问题严重，违法违规建筑治理工作既是民生工程，又是政治工程，全乡各级各部门必须高度重视，切实把思想和行动统一到乡党委政府的工作要求上来，以高度的政治责任感和紧迫感，把握工作重点，注重方式方法，迅速、全面、深入、持续开展整治工作，确保整治工作取得实效。

（二）加强领导，落实责任。各村（社区）要进一步加强组织领导，成立领导机构，严格按照属地原则，认真履行工作职责。主要领导要切实把控违、防违、治违摆上重要议事日程，亲自研究、亲自部署、亲自协调解决具体问题。迅速组织辖区开展违法违规建筑自检自查工作，对在建、新建的违法违规建筑要依法采取行政强制措施及时制止，对已建成的，要第一时间制定方案，倒排时限，分步拆除。指挥部要充分发挥组织协调作用，加强督促协调，层层落实责任，及时组织开展违法建设月通报工作，摸清辖区内违法建设情况，制定整治拆除计划，按时限要求完成拆除工作。

（三）明确任务，有序推进。各村（社区）要在前期违法建筑普查工作的基础上对辖区内的违法违规建筑的行为进一步查缺补漏。指挥部将对各村（社区）违法违规建筑明细表列入目标考核进行监督管理，组织人员现场进行督查、检查，重点对瞒报、漏报、弄虚作假情况进行通报，提出限时整改要求，对逾期不整改的，乡纪委将严肃处理。

（四）依法处置，应拆尽拆。各村（社区）、各部门在整治工作中要坚持依法行政，对违法违规建筑的治理要严格执法程序，注重执法细节，做到执法主体合法、执法程序完善、执法行为规范，还要明确政策导向，在农村危房改造、易地扶贫搬迁项目的拆迁中，属于违法违规建筑的，一律不能给予补偿。对新建、在建违法违规建筑要做到早发现、早制止，发现一起、拆除一起，确保整治工作在规定时限内全面完成，严格保证平达乡违法违规建筑“零增长”。

（五）统筹联动，签订目标责任状。按照全乡统筹，属地化管理，辖区具体组织实施的原则，各村（社区）及相关部门与乡人民政府签订目标责任状，明确各村（社区）、各部门的具体责任人和具体工作目标，确保责任落实到位。

（六）定位准确，创新工作方法。各村（社区）、各单位要找准各村（社区）违法违规建筑形成的主要原因，坚持因地制宜、重点突破、循序渐进，善于做群众工作，以改革的思路和创新的精神抓实工作。坚持融合推进，把违法违规建筑治理与新型城镇化和新农村建设、生态文明建设、改善农村居民居住条件、优化国土资源开发利用紧密结合，推动平达乡人居环境整体提升。

（七）加大宣传，教育引导。各村（社区）、各部门要加大有关法律法规的宣传力度，开展多层次、多渠道、多形式的法制宣传教育活动，加强典型违法案件的宣传报道，对有重大社会影响的违法违规建筑及其当事人进行公开曝光。积极引导广大群众学习和掌握相关法律、法规、政策、规定，理解并支持治理工作，自觉遏制违建行为，动员群众自觉拆除违法违规建筑。

（八）严格监督，强化问责。各村（社区）、各部门要高度重视违法违规建筑治理工作，乡党委政府对各辖区的整治工作情况进行考核，并将整治工作成效与年度考核挂钩。乡纪委依据考核结果对工作不力、措施不实导致违法建设反弹的村（社区）和部门，取消当年所有评先评优资格；对未按时限要求完成年度整治工作任务、新增违法违规建筑突出的村（社区）和部门依据有关规定进行严厉问责。
