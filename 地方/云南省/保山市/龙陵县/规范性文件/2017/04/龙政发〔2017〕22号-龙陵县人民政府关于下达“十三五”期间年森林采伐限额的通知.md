# 龙陵县人民政府关于下达“十三五”期间年森林采伐限额的通知

各乡、镇人民政府，县政府各工作部门，县直有关单位：

根据《国家林业局关于切实加强“十三五”期间年森林采伐限额管理的通知》（林资发〔2016〕24号）、《云南省人民政府关于下达“十三五”期间年森林采伐限额的通知》（云政发〔2016〕65号）和《保山市人民政府关于切实加强“十三五”期间年森林采伐限额管理的通知》（保政发〔2017〕3号）精神，结合我县实际，现将“十三五”期间年森林采伐限额下达给你们，并就加强采伐限额管理提出相关要求，请一并贯彻执行。

一、严格执行采伐限额管理制度

根据《云南省人民政府关于下达“十三五”期间年森林采伐限额的通知》（云政发〔2016〕65号）文件，省人民政府下达龙陵县“十三五”期间年森林采伐限额为38.12万立方米，其中，按照采伐类型分，主伐采伐22.36万立方米、抚育采伐10.85万立方米、更新采伐1.08万立方米、其他采伐0.86万立方米、低产林改造采伐2.97万立方米；按照森林类别分，公益林采伐1.56万立方米、商品林采伐36.56万立方米；按照森林起源分，天然林采伐10.62万立方米、人工林采伐27.5万立方米；按照权属分，国有林采伐1.93万立方米、集体林采伐36.19万立方米。

结合全县编限资源数据和森林资源情况，经征求各乡镇、林场意见，现将“十三五”期间年森林采伐限额分解下达到各乡镇、林场，其中2016年森林采伐限额已执行。所下达的采伐限额是各乡镇、林场“十三五”期间每年采伐林地上胸径5厘米以上林木蓄积的最大限量，各乡镇、林场必须严格执行，不得突破，按权属、起源、森林类别、采伐类型的各分项限额不得串换使用。公路、铁路、农垦等部门经营的森林，统一纳入当地采伐限额管理。采伐非林地上的林木和经依法批准建设项目使用林地上的林木，不纳入采伐限额管理。县人民政府下达各乡镇、林场的年度森林采伐限额，在年度内原则上不得调整，确因重大项目建设需要或实施林业工程项目不能满足的，由各乡镇、林场向县林业局提出申请，县林业局可根据情况在全县范围内进行调整使用。因自然灾害毁损的林木，必须申请办理林木采伐许可证，并按照林木采伐许可证的规定进行采伐，林木采伐指标可以按程序逐级上报省林业厅申请灾害木专项指标。各乡镇、林场应及时安排采伐指标，开展采伐申请审核、审批办证工作，严格坚持采伐公示制度，加强技术指导，提高服务水平，为林农做好服务，在安排森林采伐指标时要做到公平、公正、公开，并按规定做好公示。严禁截留、倒卖采伐指标和将采伐指标分配给没有森林资源的单位和个人，严禁利用分配、安排采伐指标谋取非法利益。（各乡镇、林场年森林采伐限额详见附件1、附件2）。

二、强化保护发展森林资源目标责任制

“十三五”时期是我县落实国家和省、市关于生态文明建设决策部署，实现跨越发展宏伟目标，全力实施“生态立县”战略，建设生态城市和美丽宜居乡村，扎实推进森林龙陵、生态龙陵、美丽龙陵建设，争当全省生态文明建设排头兵的重要阶段。各级各有关部门要深入贯彻落实绿色发展要求，牢固树立“绿水青山就是金山银山”理念，严格落实各级人民政府主要领导是森林资源保护管理的第一责任人、分管领导是主要责任人、林业部门主要领导是直接责任人的森林资源保护责任制。要按照森林资源“双增”目标，落实“十三五”期间各级政府保护发展森林资源目标责任制，确保实现森林覆盖率、森林蓄积量、林地保有量、森林资源消耗和天然林保护目标要求，确保全县森林资源数量和质量“双提高”。

三、严格执行采伐管理政策规定

要按照国家和省、市要求，切实加强天然林保护，严禁移植天然大树进城，严禁对天然林实施皆伐改造，严禁天然林商品性采伐。严格执行国家和省、市关于公益林管理的相关规定，公益林只能进行抚育和更新性质的采伐。要切实加强我县重点区域林木采伐管理，自然保护区、国家公园、风景名胜区、森林公园、革命纪念地、湿地、水库周边、江河两岸，重点饮用水源区及周边，铁路、高速公路、国道、省道等重要交通干线、风景旅游区公路两侧以及城镇面山可视范围内，旅游景区、旅游度假区、旅游发展规划区、“美丽乡村”建设规划区等重点区域的人工商品林，只能进行抚育采伐和择伐，不得实施皆伐作业；上述重点区域以外林地内的人工商品林，严格执行《森林采伐作业规程》，科学编制采伐规划，合理确定采伐方式、强度，需要实施皆伐作业的，严格按照采伐作业规程的规定按坡度控制采伐作业面积，并在伐区周围保留相当于采伐面积的保留林带。各乡镇也可根据生态建设需要组织区划界定重点生态保护区域。退耕还林地可以实施抚育采伐，但必须严格按照国家和省、市相关要求，切实加强指导和管理。按照《退耕还林条例》规定，退耕还林政策补助期满后，在不影响整体生态功能的前提下，报经有关主管部门批准，退耕还林权利人可以对其所有的林木申请采伐，但必须严格执行采伐管理相关规定，且采伐后必须及时更新造林，确保林地性质不变。采伐非林地上的林木，由经营者自主决定采伐年龄和方式，但必须凭证采伐和凭证运输。严格执行《云南省木材运输管理规定》（云南省人民政府第208号令），各乡镇、各部门要切实加强对《云南省木材运输管理规定》和《云南省凭证运输木材名录》的学习和宣传，强化对木材运输的监督和管理，依法查处违法运输木材案件。

四、着力创新森林经营管理机制

各乡镇及林业主管部门要积极引导和鼓励森林经营者科学编制森林经营方案，并将其作为科学开展森林经营活动和采伐管理的重要依据，不断完善采伐限额管理办法和机制。国有林的森林经营方案由所属林业主管部门组织编制并监督实施。鼓励、支持森林经营者科学开展森林抚育等改善林分结构、提高森林质量的活动，加快实现森林可持续经营。

五、认真履行管理工作职责

各乡镇及林业主管部门要严格执行凭证采伐制度，切实提高农村烧材、自用材的办证率。要依法依规审核发放林木采伐许可证，进一步简化优化林木采伐许可证办理程序，并坚持采伐公示制度。对权属不清、有争议的，不得核发林木采伐许可证。要全面推行集体林采伐简易设计，企事业单位和集体经济组织（包括行政村、村民小组、集体林场、相关林业合作组织等）申请采伐，应依据相关技术标准进行伐区调查设计。林农个人申请采伐，可由林农自行或委托他人根据申办林木采伐许可证的基本要求进行简易伐区调查设计，一次采伐蓄积5立方米以下的可免于设计。国有林采伐严格按照有关技术规程编制采伐作业设计。林木采伐作业以经营者自主管理、自我约束为主，林业主管部门按规定不再实行伐前拨交、伐中检查和伐后验收等现场监管方式，工作重点转移到为森林经营者提供优质服务和技术指导，积极引导林农依法依规采伐利用森林资源，严肃查处违法采伐和运输案件，依法保护森林资源持续发展等方面。

六、进一步强化监督管理和加强队伍建设

各乡镇要进一步强化对森林采伐限额执行情况的监督管理，依法开展经常性检查与年度专项检查。采伐限额年度执行结果与专项检查情况须报同级人民政府和上级林业行政主管部门。对森林限额采伐管理政策规定执行不到位、超限额采伐，以及因人为因素引发大的破坏森林资源案件并造成严重后果和影响的，依法依纪严肃追究有关人员的责任。要层层做好政策宣传与学习解读，及时回应社会关切，努力在全社会形成关心、保护和科学利用森林资源的良好氛围。要进一步重视、关心和支持森林资源保护管理机构和林业执法队伍建设与管理，保持林业机构和林业执法队伍稳定，不断强化教育培训，加强廉政建设，认真履行职责，充分发挥职能作用，进一步改善工作条件，以适应形势发展和工作任务的需要。
