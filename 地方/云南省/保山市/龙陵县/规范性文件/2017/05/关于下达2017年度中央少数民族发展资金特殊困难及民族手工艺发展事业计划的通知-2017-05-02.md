# 关于下达2017年度中央少数民族发展资金特殊困难及民族手工艺发展事业计划的通知

碧寨、象达、木城乡（镇）政府：

根据保财农〔2016〕255号文件要求，下达我县特殊困难及民族手工艺发展资金30万元。现按照文件要求及项目实施单位编撰的申报材料审定，金泉组、大坪子、桦桃林、懒板凳等4个自然村实施项目并给予项目建设资金的补助。现将相关要求及资金事业计划下达如下：

一、请在《龙陵民族项目工作系统》（186935331QQ群文件）中下载及上传所关联的文件及其它信息材料。

二、在项目建设中，不得擅自改变项目建设计划和资金用途。严格按照《少数民族发展资金管理办法》等相关规定做好项目的监督、检查、实施、审计、验收、档案及公示等工作，确保资金运行安全，促进少数民族和民族地区经济社会发展。

三、请乡镇接此通知后，套乡（镇）政府红头文件，将《XXX项目开工报告》（下载），于2017年5月20日以前，电子政务平台或186935331QQ群共享文档中上传。

四、报账工作要求。请项目实施单位务必于2017年10月30日以前，将报账纸质材料一式三份报送到县民宗局。

五、项目实施和资金使用情况书面总结材料及数码图片，电子文本于2017年11月25日前，报县民宗局经济发展股和县财政局农业股。

龙陵县民族宗教事务局

2017年5月2日
