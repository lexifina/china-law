# 勐糯镇人民政府关于2017年安全生产工作的指导性意见

2017年的安全生产工作以科学发展观为指导，认真贯彻落实党中央、国务院有关安全生产工作的一系列方针、政策、法律、法规，以坚持“预防为主、加强监管”原则和落实“党政同责、一岗双责、失职追责”为重点，按照“管行业必须管安全、管生产必须管安全、管业务必须管安全”的要求，深入开展各类安全检查和督查，进一步落实企业安全生产主体责任和政府的监管责任，有效遏制重特大事故发生，实现安全生产形势持续稳定发展，努力为全镇经济社会发展创造良好环境。

二、工作目标

年度不发生重特大安全事故，年度事故死亡人数为零。

三、工作重点

（一）继续强化安全生产专项整治工作。坚持把非煤矿山、交通运输、危险化学品、烟花爆竹、爆炸物品、消防、防汛、建筑施工、食品、天然气管线等行业和领域的安全生产作为专项整治的重点，以整治和规范生产秩序，遏制重特大事故发生，建立安全生产长效机制为目的，推动安全生产专项整治工作不断深入，确保重点行业和领域的安全生产形势的平稳发展。

（二）切实加大安全生产隐患排查力度。以镇人民政府下发隐患整改通知的重大隐患为重点，落实安全生产隐患整治分级管理制度，使安全生产隐患做到整改责任、人员、措施、时间四落实。各村（社区）、驻勐及镇直各有关单位要督促责任单位按时完成隐患整改任务。

（三）深入开展企业安全质量标准工作。夯实企业安全基础，行业主管部门和企业要根据本行业安全质量标准，制定相关制度和工作程序，全面提高企业安全管理水平，同时进一步加强对非公有制企业和中、小企业的安全监管，着力解决非公有制企业和中、小企业存在安全工作“无人管、不会管、管不好”的突出问题，要通过安全培训、加强指导和技术支持等措施提高企业安全管理水平，对安全隐患严重的，要加大监管执法力度，责令限期整改，对不符合安全生产条件的，依法实施关、停、并、转。

（四）建立健全安全生产应急救援体系。按照上级突发公共事件总体应急预案内容，建立和完善我镇安全生产应急预案体系，完成安全生产各领域的专项应急预案和重点单位、重点部位事故应急预案，依托县应急指挥信息平台，构建起我镇安全生产应急救援网络和数据库、整合安全生产事故类应急救援信息资源，为快速有效应对突发事件提供决策依据和救援保证，形成“指挥统一，功能齐全，反应灵敏，运转高效”的应急机制。

四、工作任务

（一）抓好矿山、冶金等工矿行业安全监管工作。矿山、冶金等工矿商贸行业重点检查矿山安全。监测监控系统是否健全、汛期安全防范措施和值班值守制度是否落实，安全生产标准化、地下矿山安全避险“四大系统”、尾矿库监测系统建设任务是否完成，隐患排查治理情况是否落实。

（二）抓好危险化学品、烟花爆竹、油气管道、民爆器材安全监管工作。剧毒、易燃易爆化学品生产、储存、运输、使用、废弃等环节的安全隐患是否得到有效治理，危险化学品生产、储存设施的安全防护距离、安全设施、消防设施、应急预案和应急器材是否符合规范要求。烟花爆竹批发企业仓库、作业过程是否符合要求，爆竹经营单位、民爆器材是否落实库房及各种安全措施。

（三）抓好市政工程安全监管工作。主要是施工现场安全管理和隐患排查整改。

（四）抓好特种设备安全监管工作。特种设备生产、使用单位是否依法履行质量安全管理主体责任，车站、商场、医院、办公区域、居住小镇、宾馆酒店等人员密集场所使用的锅炉、压力容器、电梯、起重机械等特种设备是否合格，特种设备生产使用单位的安全管理机构、人员、制度、特种设备使用登记证、作业人员上岗证、定期检验和应急预案等制度是否建立落实。

（五）抓好道路运输行业安全监管工作。监督管理全镇道路交通运输安全，道路运输经营是否按要求执行，客运车辆和危险货物运输是否合法合规。

（六）抓好公路、水路行业安全生产和应急管理工作。桥梁、隧洞、危险路段、交通事故多发路段安全隐患和政府挂牌督办的重大道路交通安全隐患治理是否到位，临水临崖、长下坡、急弯等部位安全防护措施是否进一步完善，水上交通驾乘人员是否按规定穿着救生衣，驾驶人员是否持证上岗，船舶是否定期检验，是否符合运输要求。

（七）抓好工业企业、通信企业安全监管工作。相关工业企业的制度是否完善，相关设施是否具备，应急救援物资储备是否到位等。

（八）抓好地质灾害预防和工程建设项目。是否开展汛期隐患排查和隐患点除险加固，汛期各项安全防范措施是否落到实处，预防自然灾害引发事故工作机制和各种预案是否健全完善，应急救援演练是否开展到位，各地质灾害点主要存在问题是哪些，是否建立通讯联络机制，联络责任人是否落实等详细情况。工程建设项目主要是除水利和市政项目以外的项目施工安全。

（九）抓好校园安全监管工作。校园周边治安、道路交通和经营场所是否存在安全隐患，中小学、幼儿园是否租用拼装车、报废车和个人机动车接送学生、幼儿，学校购买或租用专门用于接送学生、幼儿的机动车辆是否经交管部门检验合格并按照有关规定喷涂标识和挂牌，是否定期维护和检测，机动车驾驶员资质是否符合有关规定，是否存在超载现象，各级各类学校消防设施、应急照明、指示标志、疏散通道、安全出口是否符合国家有关标准。

（十）抓好农机安全监管工作。各类农业机械是否按要求进行登记、检验，是否按要求进行驾驶证的申领、换发、审验，农机驾驶操作人员是否存在违法载客、超速超载、无证驾驶、酒后驾驶等违法行为。

（十一）抓好卫生系统安全管理工作。组织或指导协调医疗事故、医疗卫生救援，加强医院内部防护工作。

（十二）抓好放射性废物的监督管理和事故现场的环境监测工作。

（十三）抓好安全生产领域无照经营监管工作。负责查处安全生产领域的无照经营行为。

（十四）抓好水利行业安全监管工作。组织、指导水库、水电站大坝的安全监督管理，监督管理水利项目建设安全生产工作。大坝枢纽、溢洪道、泄洪洞、输水沟渠是否按要求落实运行、管理安全措施，高陡边坡是否存在安全隐患，排水沟渠是否畅通，是否制定防洪度汛应急预案，防洪度汛等储备物资是否到位等。电网企业运行情况，各项安全措施、制度是否健全，安全人员是否到位。

（十五）抓好公共文化场所、活动室的安全管理工作。依法对旅游景区景点、度假区、酒店、旅行社、旅游车船、旅游项目等旅游经营者实施旅游安全综合监督管理。

（十六）抓好食品药品生产、经营、使用和医疗器械等安全生产的监管工作。负责放射性药品、麻醉药品、毒性药品、精神药品、药品类易制毒化学品等特殊药品和中药材专业市场、药品零售企业的安全生产监督管理。

（十七）抓好消防安全。人员密集场所的消防设施设备、责任人、操作规程、预案演练、巡查检查、员工安全教育培训、值班值守等是否到位，室内装修材料、建筑保温材料是否符合消防技术标准，防火间距、防火防烟分区、疏散楼梯、疏散通道、安全出口设置是否符合消防安全要求，高层、地下建筑，易燃易爆危险品生产、经营、储存单位是否按照火灾高危单位管理要求，采取严格的消防措施，有关单位消防行政许可、安全责任制、安全管理制度和措施是否落实，消防安全责任人是否明确、是否经过消防安全培训。

（十八）抓好道路交通安全。运输企业是否落实各项安全措施，是否严把市场准入关、营运车辆技术状态关、营运驾驶从业人员资格关。严处道路旅客运输车辆违法、违规行为及农村面包车非法营运，加强对客运企业卫星定位装置安装和使用的督查，落实好客运企业的监控主体职责，加大对各类危险路段的排查和治理力度。交警部门要加大路面管控力度，加大上路巡查力度，突出赶集日、周末学生乘车期间的交通监管，严厉打击“三超一疲劳”，货车野蛮驾驶、无证驾驶、酒后驾驶，货车、拖拉机违法载人，摩托车、电动自行车违法超载等交通违法行为，在重点时段、重点区域、重点路段开展执法检查，加大道路隐患排查整改力度。

五、工作要求

（一）抓好责任落实。各村（社区）、各部门要进一步加强领导，调整充实安全生产工作领导小组，完善体制机制，“一把手”是安全生产第一责任人，要认真研究解决涉及安全生产的相关问题，层层签订安全生产目标责任书，实行安全生产目标管理和安全生产“一票否决”制度。在镇政府的统一领导和镇纪委的监督下，切实承担起安全生产监管和监督职责。

（二）抓实监督检查。各村（社区）、各部门、各企事业单位要认真落实属地责任和行业主管责任，研究本单位、本系统存在的不安全因素，在重要环节、具体细节上抓落实，在容易出问题的环节上抓落实，决不能满足于一般的部署，一定要做到细致、周到、周密。文件中明确的18项安全生产工作任务，必须建立长效机制，镇党委、政府班子成员是分管工作领域和所挂钩村（社区）的责任领导，各责任领导必须每季度组织有关责任单位对分管领域和所挂钩的村（社区）进行1次以上安全检查，召开1次以上安全生产专题会议。镇安全生产工作领导小组必须每季度组织1次以上全镇性的安全生产大检查，召开1次以上安全生产工作联席会。各有关企业必须按照有关规定每季度组织1次以上安全大检查，召开1次以上安全生产工作联席会。各项安全工作检查必须要有记录、有汇报、有整改、有反馈。对存在问题自查、整改不彻底、不到位的单位，交由相关主管部门依法予以处理。

（三）抓牢领导带头。安全责任落实贵在领导带头，各村（社区）、各部门、各企事业单位领导要在行动上带头抓好抓实。杜绝以会议贯彻会议、以文件落实文件，必须切实转变作风、以身作则、亲力亲为带头深入一线抓落实。要在全镇营造“人人抓安全、时时想安全、事事重安全、处处查安全、会会讲安全”的浓厚氛围。

（四）抓严追责问责。凡今后发生安全事故，造成财产损失和人员伤亡的，要严格按照“事故原因不查清不放过、事故责任不承担不放过、干部群众不受教育不放过、防范措施不落实不放过”和“当事人一律处理、单位一律通报、单位领导一律问责、企业一律整顿、损失一律追偿”的“四不放过”、“五个一律”原则从快从严处理，绝不姑息迁就。
