# 龙陵县2017年农村危急孕产妇住院分娩资金补助实施方案

为进一步加强省级农村孕产妇住院分娩补助配套资金的使用和管理，使有限的救助资金能发挥对贫困危急孕产妇的最大救助，有效降低孕产妇死亡率，经县卫计局研究，对原执行的《龙陵县卫生局关于印发龙陵县农村危急孕产妇住院分娩资金补助实施方案的通知》（龙卫发〔2014〕27号）进行调整，并制定实施方案。

一、资金来源

每年省财政按上一年活产数人均43元下拨农村危急孕产妇救助金（每年约13万元）。

二、资金管理

危急孕产妇救助金由县卫计局设专人专账管理，专款专用，不得挪做他用。

三、补助对象

农村危急孕产妇及产科并发症（如产后大出血需输血治疗、重度妊娠期高血压疾病、妊娠合并心脏病心功能二级以上、羊水栓塞、其它危及生命的产科并发症等）救治费用。

四、补助标准

（一）参加新农合的危急孕产妇所产生的救治费用，先由农村孕产妇住院分娩补助资金补助400元，剩余部分由新农合按疾病住院报销政策给予报销（包括大病二次补偿），最后余下部分由省级农村孕产妇住院分娩补助配套资金按比例补助，其余不足部分由孕产妇个人支付，补助标准如下：

1.自付部分在2000元以内（含2000元），不给予补助，产妇本人持低保证或残疾证的农村孕产妇给予全额补助；

2.自付部分在2000元以上、5000元以内，按50%比例补助，产妇本人持低保证或残疾证的农村孕产妇按80%比例补助；

3.自付部分在5000元以上、10000元以内，按60%比例补助，产妇本人持低保证或残疾证的农村孕产妇按90%比例补助；

4.自付部分在10000元以上的报龙陵县农村孕产妇住院分娩补助办公室研究决定特别补助金额。

（二）未入新农合的危急孕产妇所产生的救治费用，先由农村孕产妇住院分娩补助资金补助400元，剩余资金由省级农村孕产妇住院分娩补助配套资金按比例补助，其余不足部分由孕产妇个人支付，补助标准如下：

1.自付部分在2000元以内（含2000元），不给予补助；产妇本人持低保证或残疾证的农村孕产妇按50%给予补助。

2.自付部分在2000元以上、5000元以内，按50%比例补助；产妇本人持低保证或残疾证的农村孕产妇按60%给予补助。

3.自付部分在5000元以上、10000元以内，按60%比例补助；产妇本人持低保证或残疾证的农村孕产妇按70%给予补助。

4.自付部分在10000元以上的报龙陵县农村孕产妇住院分娩补助办公室研究决定特别补助金额。

五、相关工作要求

（一）农村孕产妇住院分娩严重产科并发症的救治助产机构必须提供《孕产妇危急抢救表》及《危急孕产妇救助登记表》。

（二）以上四项补助经费由各医疗卫生机构垫支，凭“云南省农村孕产妇住院分娩补助卡和补助经费四联单”定期到龙陵县农村孕产妇住院分娩补助项目办公室审核报销。

（三）该方案自下发之日执行，原《龙陵县卫生局关于印发龙陵县农村危急孕产妇住院分娩资金补助实施方案的通知》（龙卫发〔2014〕27号）同时废止。
