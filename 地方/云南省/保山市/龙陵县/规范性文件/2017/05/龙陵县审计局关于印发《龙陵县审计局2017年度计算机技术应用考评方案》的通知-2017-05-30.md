# 龙陵县审计局关于印发《龙陵县审计局2017年度计算机技术应用考评方案》的通知

各股室、中心：

为加快适应数字化审计新要求，切实深化计算机技术在审计业务和项目管理中的应用，积极推进“金审工程”三期建设，不断提升计算机技术应用能力，尤其是大数据审计分析能力、计算机技术的创新应用能力等，根据《保山市审计机关2017年度计算机技术应用考评方案》（保审发〔2017〕15号）的要求，结合实际研究制定了《龙陵县审计局2017年度计算机技术应用考评方案》，经局党组会议研究同意，现印发给你们。

希望各股室务必高度重视，围绕考评内容认真做好计算机技术应用推广及提升工作，并在实际工作中自查自纠，不断提升计算机技术应用水平。届时，县审计局将严格按照方案要求组织考评。

为持续提高我局审计信息化建设的应用成果，推进“金审工程”三期建设，转变审计管理模式，积极探索大数据审计分析，不断提升数字化审计的能力和水平，不断提高审计质量和效率，制订本考评方案。

一、考评对象

各股室（含中心）。

二、考评机构

成立龙陵县审计局计算机审计技术推广应用领导小组，负责考评工作，领导小组组长由局长担任，副组长由其他班子成员担任，成员由各股室负责人、余自刚组成。领导小组办公室设在综合办公室，由尹玮薇担任办公室主任，负责处理日常工作。

三、考评内容

结合我局计算机技术推广应用情况，对各股室进行计算机技术基础应用及创新应用考评。基础应用主要考评计算机技术在审计工作中的应用情况，包括审计管理系统（OA）应用、审计管理系统（OA）与现场审计实施系统（AO）的交互应用、计算机技术应用成果、计算机技术应用宣传、信息化人才培养、网络应用与安全、数据报送以及信息化建设等基本内容；计算机技术创新应用主要考评计算机审计应用案例、信息系统审计案例、审计应用软件开发、信息化人才培养、审计数据分析、计算机技术应用课题研究、计算机技术应用宣传以及计算机技术应用著作等，具体的考评得分标准详见附件。

四、考评程序

（一）各股室按照考评标准组织自评，并将自评结果于2017年11月15日前报至计算机审计技术推广应用领导小组办公室（综合办公室）。

（二）领导小组办公室组织相关人员组成考评小组进行初评，并将初评结果于2017年12月25日前向各股室反馈。

（三）各股室在收到初评结果5个工作日内提出反馈意见，逾期视为无异议。领导小组办公室对各股室的反馈意见进行研究，决定是否采纳其反馈意见，并作出说明。

（四）领导小组办公室将考评结果报领导小组，领导小组对考评结果进行审核后报局党组会研究决定最终考评结果。

五、考评结果及应用

（一）考评得分计算方法

计算机应用考评基础分为100分，未完成考核目标的，按扣分标准进行扣分，扣完为止；达到加分条件的，按加分标准进行加分；基础分得分和加分得分合计构成总得分。

（二）考评结果应用

1. 各股室的考评结果向全局进行通报，计算机审计应用案例和计算机技术应用宣传任务的完成情况还将作为相关股室人员年终评优的重要依据。

2. 经局党组研究决定，从上级审计机关和县委县政府对我局的考核经费中安排2万元，用于在计算机应用考评方面取得成效的股室和个人（具体分配标准见附件3）。更好地发挥综合考评的导向、激励、助推作用，着力提升审计队伍计算机技术应用整体水平，不断增强审计人员在信息化环境下的审计监督能力，为维护全县经济社会的健康运行做好审计服务。

六、检查落实措施

（一）分解任务，落实责任。县审计局根据与市审计局签订的计算机应用考评责任状，结合实际将考评任务分解到各股室。

（二）领导督查，技术支持。进一步加强对全局信息化工作的管理、指导、督查、通报，领导班子成员负责对所分管股室的计算机应用情况进行指导和督查，督查结果将在全局通报。

（三）分层培训，丰富方式。逐步建立层次清楚、方式多样的信息化培训机制，针对不同对象，采取多种方式进行信息化审计培训，提升信息化审计水平和质量。具体是：组织开展初级应用培训和实战培训；积极参加审计署、审计厅、市审计局组织的相关培训。

（四）强化应用，严格奖惩。县审计局每年根据考评结果，严格按规定进行奖励和惩罚，并与其他考核进行衔接，严格落实考核结果应用。各股室计算机审计应用案例和计算机技术应用宣传任务未完成的，本股室人员在年终考核时股室负责人在最后得分上扣减1分，其他人员扣减0.5分，股室负责人的优秀票扣减2票，其他人员优秀票扣减1票（优秀票以扣完为止，如无优秀票则不扣减）。
