# 龙陵县人民政府关于2017年烤烟生产工作意见

各乡、镇人民政府，县政府各工作部门，县直有关单位：

为加快烟叶生产发展方式转变，全力推进烤烟产业转型升级，主动应对市场变化，提质增效促烟农增收，积极推动烟叶发展再上新水平，不断开创烤烟生产发展新局面，促进龙陵经济社会持续健康发展，现就全县2017年烤烟生产提出如下意见：

一、总体要求

以党的十八大、十八届六中全会和中央经济工作会议精神为指导，贯彻落实五大发展理念、省第十次党代会和省、市烟叶工作会议精神，紧紧围绕“供给侧改革、转变发展方式、促进烟农增收”的任务要求，坚持“控制总量、优化结构、降本增效、完善体系”的工作方针，以市场、质量、绿色、生态、安全为主线，控制总量、提升质量，创新驱动、精益管理，着力推进烤烟产业转型升级，推动烤烟生产再上新台阶，更好发挥烟草产业支柱作用，为全县经济社会跨越发展作出新贡献。

二、目标任务

（一）生产收购计划及工作目标

完成市下达我县烤烟指令性收购计划12.92万担（比2016年指令性计划减少0.28万担），其中，红花大金元品种1.5万担（比2016年减少2万担）；力争实现烤烟产值1.8亿元以上、烟叶税0.4亿元以上。各乡（镇）指令性收购计划（含出口备货）安排为：龙山镇1.5万担；龙江乡2万担，其中，红大品种1.5万担；镇安镇0.93万担；腊勐乡3.16万担；碧寨乡1.08万担；平达乡2.12万担；木城乡0.88万担；象达乡0.85万担；龙新乡0.4万担。

（二）烟叶质量目标

按照国家收购等级标准，收购等级综合合格率80%以上、综合等级纯度90%以上，上等烟比例达到67%左右（分乡镇指标另行分解下达），烟叶内在品质化学成分评分达60分以上，农药残留不超标。

三、政策措施及考核办法

（一）政策措施

1．坚持稳控规模，增强调控能力。各乡（镇）、各有关单位要认清当前形势，把握发展机遇，切实将思想认识统一到县委、县政府和上级烟草部门烟叶宏观调控的决策部署上来，主动把工作重心转移到稳控规模、提质增效和可持续发展上来，紧紧围绕“稳得住，控得住”的工作目标，坚持以合同制为主线，严格计划分解，强化过程控制，层层落实责任，统筹处理好“稳”与“控”的关系，努力赢得发展主动权；要把稳控总量作为烤烟工作的首要任务，严明纪律要求，切实维护计划与合同的严肃性；坚持市场导向，实行下一年度生产计划与烟叶质量结构、产能情况、市场需求等进行挂钩的工作机制，对完成生产收购计划、质量结构达到目标要求及工业需求的乡（镇），在下一年度生产收购计划分解上给予倾斜，对完不成生产收购计划或质量结构达不到目标要求及工业需求不足的乡（镇），加大下一年度生产计划调减幅度。

2．稳定支持政策，促进持续发展。各乡（镇）人民政府要继续稳定投入政策，将烟叶税地方实际所得10%以上用于烤烟产业投入，其中3%专户存储、专项用于基础设施建后日常管护及维修。县烟草分公司要充分用足行业补贴政策，坚持和完善对烟农种烟的扶持机制，对化肥、农药等烟用物资以及育苗、自然灾害风险防范、散叶收购专业化分级服务等进行补贴，调动和促进烟农种烟积极性，落实烟草行业补贴资金，用于烟水、密集烤房、机耕路、育苗基地等综合配套建设。

3．落实价格政策，保证烟农利益。严格执行中国烟草总公司关于2017年烟叶收购价格的有关政策，坚持收购价款以电子结算方式一次性兑现给烟农。

4．加强烘烤培训，提升烘烤水平。切实利用好专业化烘烤补贴政策，采取多种模式推进专业化烘烤服务，力争密集烤房专业化烘烤比例达80%以上，商品化烘烤提高到60%以上，烘烤损失率控制在8%以内。

5．规范专业分级，完善散叶收购。充分利用烟草行业专业化分级散叶收购50元/担的补贴政策，抓实站点一体化专业化分级，除出口备货外，100%推行专分散收模式。

6．完善防范机制，维护烟农利益。继续按照“政府引导、烟农投保、烟草补贴、全面覆盖”的商业保险模式，健全保险与救助相结合的自然灾害风险管理机制，进一步提高风险防范能力，最大限度降低灾害造成的损失，完善灾害查勘定损操作流程和理赔兑现办法，较好体现保险的托底保障作用，有效缓解烟农种烟后顾之忧。另外，经县产业发展领导小组研究决定，全县烟叶生产自然灾害风险防范保险资金中的烟农承担部分，用县级提取的烤烟发展资金补助，烟农不再自行承担（具体实施方案另行发文）。

7．加大产业扶贫，促进烟农脱贫。脱贫攻坚工作是我县全面建成小康社会的重点难点，产业是精准扶贫、精准脱贫“五个一批”中的一项重要抓手。要围绕“十三五”时期脱贫攻坚工作的目标要求，做好产业扶贫文章，发挥产业的优势，在烟农脱贫攻坚上发挥带动和促进作用。我县大部分地区为山区，种植烤烟仍然是当地农民主要的增收门路。要切实做好烟草产业精准扶贫工作，按照扶贫对象精准、项目安排精准、资金使用精准、措施到户精准、因村派人精准、脱贫成效精准的六个精准工作要求，认真调查，掌握贫困烟农数量和致贫原因，着眼于提高贫困烟农产业化发展能力，从统筹规划、政策扶持和产业投入等方面，创造烤烟产业加快扶贫的必要条件。在合同计划安排、扶持政策、专业化服务、现代烟草农业建设等方面，对贫困村和建档立卡贫困户烟农实行差别化的政策倾斜，促进烟区贫困户脱贫致富。

8．完善激励机制，强化考核管理。县财政按合同收购量每担烟安排50元专项用于烤烟生产扶持发展，其余烟叶税全部返还种烟乡镇。在提取的生产扶持费中，每担烟安排乡镇10元，主要是对乡、村干部的考核奖励（完成合同收购任务的奖励乡镇2元、村级3元；完成县下达上等烟叶收购指标的，奖励乡镇2元、村级3元）。每担烟安排5元，专项用于自然灾害风险防范；每担烟安排5元，用于烤烟辅导员主管的工资及年终考核奖励。乡镇要继续加大对村级支持力度，在考核、考评、奖励上给予一定的倾斜和扶持，建立和健全激励机制，重点支持贫困种烟村和广大贫困烟农不断提高烤烟种植水平，加快全县种烟贫困村脱贫摘帽步伐。

9．加强统筹整合，促进协调发展。抓住现代烟草农业建设转型升级的机遇，加大统筹协调力度，建立健全工作联动机制，充分整合发展改革、财政、国土资源、交通运输、农业、水利、扶贫等相关部门涉农项目，以现代烟草农业建设的转型升级推动全县农村经济社会全面协调发展。

（二）考核办法

对严格按照下达计划组织生产收购、组织管理工作落实到位、经县烟草分公司验收烟叶质量达到考核指标要求、现代烟草农业建设成效明显的乡（镇）及相关单位，给予兑现相应考核奖励。

1．目标责任考核与2016年标准相同。

2．生产收购计划考核。对完不成生产收购计划总量的乡（镇），实行一票否决制；2018年全县下达各乡（镇）生产收购任务视2017年各乡（镇）收购总量、上等烟比例完成情况和经济增长贡献率作相应调整。

3．乡镇质量考核。组织管理工作落实到位、完成各项分解下达计划和《保山烤烟综合标准》贯彻落实到位，烟叶质量指标经烟叶质量监督检测站验收合格的乡镇，市人民政府给予红花大金元品种每担2元、一般品种每担1元的质量考核。

四、工作重点及措施

紧紧围绕“坚持烟叶生产基础地位不动摇、控制烟叶规模收购红线不动摇、引导烟农增收工作举措不动摇、稳定烟叶政策基本导向不动摇”的“四个不动摇”任务要求，认真贯彻“控制总量、优化结构、降本增效、完善体系”的工作方针，以市场、质量、绿色、生态、安全为主线，控制总量、提升质量，创新驱动、精益管理，转变方式、助力增收，确保控得住、稳得住、提得高、卖得好，努力开拓龙陵烤烟产业发展新天地。

（一）严格落实严控规模工作

各乡（镇）、各有关单位要认清当前烟叶市场形势变化，认真贯彻省委省政府和省烟草专卖局决策部署，切实增强红线意识，把好计划分解“总开关”，牵住种植面积“牛鼻子”，遵循农业生产规律，结合实际生产水平，科学约定单产，既不允许“宁多勿少”简单扩量保计划，埋下超产超收隐患，引发社会矛盾，又要避免“宁少勿多”消极应付控面积，导致歉产歉收，完不成计划浪费合同指标；要严格按照合同签订程序，以及分解落实的种植面积、烟叶收购数量，与烟农面对面正式签订种植收购合同，做到“一户一签”，100%推行电子合同和电子结算；要强化过程控制，严把“十大”关口，统一供应种子，按合同约定面积和标准配套供应烟苗和烟用物资，按合同组织烟叶收购，切实加强计划及合同执行过程管理，压实扛牢工作责任，强化检查监督，严格考核奖惩，坚决守住计划红线。

（二）优化调整烤烟生产布局

按照“看土地、看生态、看劳力、看技能、看水平”的原则，充分尊重市场规律，优化生产要素资源配置，推进适度规模种植，以稳定核心烟区为基础，选择生态优越、集中连片、品质优良的区域，集中建设以千亩村、万担乡为主的骨干烟区，着力提高连片种植规模，力争户均种烟规模达到10亩以上；加快土地流转步伐，以土地三权分置为契机，引导农民自发流转承包土地，依托乡镇、村和烟农专业合作社等机构，构建土地流转平台，促进烟地规范有序、长期稳定流转，引导烟田向职业烟农集中，力争烟田集中流转比例达到20%；扎实抓好特色品种种植，结合红花大金元品种对自然气候和栽培条件要求较高的特点，科学规划，合理布局，强化技术措施落实，彰显清香型风格特色，增强优质原料有效供给能力；逐步调整烟叶香气风格不突出、工业需求意愿不强的云烟99、云烟105等品种的种植规模，全面提升烟叶品质和种植效益，促进不同种植区域烟叶生产均衡发展，着力提升烟叶生产整体发展水平。

（三）强化实用技术推广应用

把提质增效放到更加重要位置，坚定不移地走依靠质量提升效益的路子。突破四大核心技术，加强特色品种筛选、机械化作业、营养调控、烘烤提质四大核心技术攻关，推动科研成果转化落地，促进烟叶生产水平提升。落实十项关键技术，系统集成“9+1”技术（合理密植、膜下小苗深栽、适时集中移栽、节水灌溉、精准施肥、统防统治、4—6片上部叶一次性采收、专业化烘烤、专业化分级，加精益管理），同一片区3天内完成移栽、5月10日前完成移栽，推动水、肥、土、技的全要素耦合，逐步扩大节水灌溉、水肥一体化、膜下小苗深栽推广面积，力争统防统治推广比例达到100%，大田生育期达到130天左右，确保田间烟株整齐一致、分层落黄明显。强化精益生产，以全面实施GAP为抓手,重点在精准施肥、精准灌溉、精准用药、精准烘烤上下功夫，实现技术精良化；以集群设施和连片烟田为基础，以专业化服务为重点，以精准管理为手段，着力推动生产集中、资源积聚、要素集约；按片区配备专业队，按网格配备技术队员，实行片区服务、网格作业，提高烟叶生产精益管理水平。

（四）持续推进绿色优质生产

紧紧围绕市场需求，充分发挥龙陵得天独厚的生态环境优势，实施土壤保育行动，严格落实以烟为主的耕作制度，突出抓好轮作，优化施肥技术，全面施用有机肥，推进减量增效施肥，落实好土壤改良技术，确保烟田用养结合；开展绿色防控专项研究，严禁使用除草剂，科学合理用药，控制好烟叶农残，提高烟叶安全性；加大烟区生态环境保护，推广生态循环农业技术，实行清洁生产，示范应用生物质燃料烘烤，有效落实田间废旧农膜、农药瓶袋、烟株残体等非烟物质清除处理，推动烟叶生产与生态环境和谐发展。突出特色优质烟叶开发，围绕工业企业高端品牌原料需求，持续抓好特色特需烟叶生产，巩固提升特色优质烟叶单元建设水平，不断提升全县特色优质烟叶开发水平。

（五）持续提高烟叶质量水平

以完善提升生产体系为重点，以基地单元为载体，加强与工业企业合作，落实“一基一案”，完善品牌导向型烟叶生产技术体系；开展关键技术精益化、采烤分一体化、化肥农药减量化研究与应用，构建精益生产技术体系，确保技术精准到位；健全优质烟叶标准化生产体系，持续加强《保山烤烟综合标准》的宣传和贯彻落实，强化对标生产、对标检查、对标管理，提升标准化生产水平，切实提升工业满意度。全面加强收购管理，突出抓好第三方专业人员分级，提高专分散收的专业化和组织化程度，着力解决“三混”问题；坚持工商共同制作收购样品，实行对样收购、平稳收购、均衡收购，加强分级、定级、成包等关键环节的质量监管，重点把控收购质量，严格质量考核，强化考核结果运用；坚持平稳收购、均衡收购，围绕8月25日—10月20日收购的目标任务，努力将全县日收购进度保持在2—3%的合理水平，杜绝“前紧、中松、后不管”乱象，始终保持较高的收购等级纯度和质量水平。

（六）扎实推进现代烟草农业

紧密结合我县烤烟生产实际，强化集约经营，着力转变烟叶生产方式，着力构建以职业烟农为主体、合作社为纽带、专业化服务为支撑的生产组织方式，加快职业烟农培育，重点培育“以烟为主、有一定技能水平、经营管理能力和生产规模”的职业烟农，建立完善职业烟农教育培训、差异化扶持、评定管理和动态管理办法；做精做强专业化服务，重点提升合作社科学化组织、专业化服务、市场化运作、规范化管理等能力，加强育苗、机耕、烘烤、分级合作社队伍建设，做精、做强、做优专业化服务，力争专业化育苗、专业化分级达到100%，专业化翻犁达到60%以上，烟叶生产用工努力控制在25个/亩左右。持续推进烟叶生产基础设施建设，烟草部门要充分用足行业政策，重在查漏补缺和提升完善，重点布局在主产烟区、特色烟区、优势烟区及扶贫任务较重烟区，重点推进烟水工程、适用农机及损毁项目修复。

（七）加大水源工程建设力度

充分抓住烟草行业大力支持水源工程建设的机遇，扎实推进水源工程建设。按照“注重效益、从严管理，实事求是、以新促老”的要求，严格执行新项目申报与在建项目建设管理情况挂钩，坚决杜绝“重项目申请、轻项目建设”等现象发生。认真做好淘金河水库工程项目储备、申报等前期工作，充分发挥组织实施的主体作用，建立健全高效的项目建设和协调机制，确保水源工程发挥最大效益。乡（镇）人民政府、县直有关单位要紧密配合，严格经费管理，精心组织施工，做好工程监管，保证建设质量。

（八）切实加强烟叶流通管理

围绕烤烟生产收购工作中心任务，严格计划合同管理，严厉打击各种利用签订大合同、虚假合同倒买倒卖烟叶违法行为，坚决杜绝虚假合同和买卖合同、侵吞烟农合同等违法违规行为；认真落实非法烟叶来源地追溯制度，对烟叶非法流动较多的地区，要减少下一年烟叶收购计划，严肃责任追究。烟草、公安、交通、市场监管等部门要通力协作，坚持烟草专卖政策，建立市场监管长效机制，疏堵并举，打防结合，综合治理，保持对涉烟违法犯罪活动的高压态势，维护良好的烟叶收购流通秩序和市场环境。各乡（镇）要组织协调相关部门力量，重点加强对不适用烟叶处置工作的监管，严厉打击不适用烟叶的收购、囤积、加工、贩运等行为，坚决杜绝不适用烟叶流入市场。烟草部门要切实按照省局《专卖内管工作流程规范》和《烟叶种植收购合同管理办法》要求，规范烟叶种植、收购、移库等内部规范管理工作。

（九）提升助农增收服务水平

充分认识促农增收工作的重要意义，始终坚持把烟农利益放在心上，切实做到领导到位、责任到位、措施到位、服务到位，不断增强服务意识，综合施策，千方百计促进亩均效益、户均效益同步提高，增加烟农种烟收入；注重提高合作社的经营素质、生产组织能力和市场竞争能力，构建合作社与烟农的利益联结机制，吸引烟农参与合作社专业化服务，增加烟农服务性收入；发挥烟草行业设施和地方党委政府组织优势，密切产学研商合作，从种植作物种类、技术支持、资金扶持、销售渠道等方面进行探索，积极延伸产业链，拓展设施综合利用，既要坚定不移地稳定提高烟农户均种烟收入，又要增强烟农服务性收入、多元化收益，全面提升烟农增收工作水平。

（十）政企合力推进产业发展

烤烟产业发展事关全县经济稳增长大局，事关全县全面建成小康社会工作大局，各乡（镇）、各有关单位要按照县委、县政府统一部署，以“两学一做”学习教育为抓手，进一步认清形势、统一思想，充分认识烤烟产业转型升级在我县经济社会发展中重要作用，增强责任意识，牢记责任使命，认真履行组织领导责任，坚持主要领导亲自抓、分管领导具体抓和“政府调控、公司主抓、烟农主体、部门配合”的工作格局，大力弘扬伟大的长征精神，坚定发展信心、保持发展定力，落实分级负责制，加强工作统筹，整合力量、整合资源、整合资金，形成各方面齐心协力抓烤烟生产的正能量，用发展的眼光、改革的办法、创新的手段，奋力推动我县烤烟产业转型升级，努力保持全县烤烟产业持续稳定发展。
