# 龙陵县人民政府关于2017年石斛产业发展指导性意见

为充分发挥我县地域特色优势、石斛资源优势，加快推进石斛产业向生态化生产、产业化经营方向发展，培育壮大我县石斛产业，促进农民增收，结合我县实际，现就2017年石斛产业发展提出如下意见。

一、指导思想

以党的十八大和十八届三中、四中、五中、六中全会精神为指导，认真贯彻落实习近平总书记系列重要讲话和考察云南重要讲话精神，坚持“绿色、生态、环保、健康、安全”的石斛产业

发展理念。按照“打牢基础、巩固提升，打造品牌、开拓市场，龙头带动、做强做大”的发展思路。构建“政府主导、农民主体、协会推动、部门联动、共同推进”的发展模式。以质量为生命、市场为导向、龙头为引擎、科技为支撑、品牌为核心、政策为保障，突出生物资源开发，推进“公司+协会（合作社）+基地+农户”的有机结合。实行生产、加工、销售一体化，加快发展石斛产业，使之成为我县县域经济的特色支柱产业，促进龙陵经济又好又快发展。

二、目标任务及工作重点

（一）目标任务

全县计划完成石斛新栽培面积70万平方米，栽培总面积达730万平方米，全年实现石斛鲜条产量3200吨、农业产值4.5亿元，从业人员达5.5万人；规划建设连片面积不低于50亩的石斛野生种植县级示范园1个；完成培训500人次；规范象达、河头石斛交易市场；设立2个专门销售龙陵紫皮石斛的省外店铺；培育以销售紫皮石斛产品为主的电子商务示范企业2户以上；建设5个石斛枫斗标准化加工点；组织1次全县枫斗加工技能比赛；积极申报紫皮石斛健字号产品批文；打造碧寨乡天宁村野生石斛种植示范村。

（二）工作重点

1．摸清种植情况，巩固协会会员。各乡镇要认真履职，明确部门和人员，调查清楚本乡镇内石斛种植情况，建立全面、准确的种植户台账，并报县石斛产业领导小组办公室备案，准确掌握辖区内的种植户数、种植模式、种植品种、产量、质量检测等情况，对种植户数量、种植品种、产量、面积的消长情况等进行统计更新。同时，认真做好种植户加入协会工作，积极吸纳石斛种植户加入协会，2017年各乡镇石斛种植户入会率要达到30%以上。

2．强化检测工作，确保石斛质量安全。严格按照“绿色、生态、环保、健康、安全”的石斛产业发展理念，采取强有力的措施对种植、加工、销售等环节进行有效监管，确保石斛产品质量的安全可控；严格执行种植申请备案、产品质量检测检验等6项制度；探索推行石斛种植资格证制度；深入开展龙陵紫皮石斛地理标志产品保护，鼓励企业积极使用地理标志证明商标；加大联合检查、执法力度，查处不合格产品，杜绝存在安全问题的产品流入市场，实现石斛鲜条、枫斗产品全面检测、统一包装，各乡镇石斛鲜条质量安全检测率达100%，合格率达98%以上。提高石斛种植、经营管理水平，推进石斛种植技术、病虫害防治、枫斗加工等方面的培训工作，确保石斛产品质量安全。

3．完成紫皮石斛“身份”认证工作。力争完成龙陵紫皮石斛新食品原料申报工作和龙陵紫皮石斛全国知名品牌创建示范区验收工作。

4．加大科技研发力度。以李凡专家基层工作站为纽带，围绕龙陵紫皮石斛基础研究和产品开发研究，继续做好与中国农业科学院农产品加工研究所、上海中医药大学中药研究所、云南省中医药产业发展研究院等合作研究项目的对接工作，加强项目管理，确保项目研究持续推进；加大云南品斛堂生物科技有限公司、龙陵云河石斛开发有限公司等石斛系列产品的研发、生产、销售力度，积极支持以龙陵紫皮石斛为原料或主要原料的产品“健字号”申报、审批工作；加快龙陵紫皮石斛理化分析研究，有效成分分析、毒理药效及临床运用的研究。

5．挖掘龙陵石斛特色文化，加大品牌、产品宣传推广力度。以养生文化、民族民间文化等丰富“龙陵石斛”品牌文化，提升“龙陵石斛”文化内涵；启动“龙陵石斛”微电影、“舌尖上的石斛”系列宣传片的拍摄制作；出版《龙陵石斛》期刊3期；组织1次龙陵紫皮石斛产品推介活动，组织参加1次以上国际性、全国性产品展销会；组织1次对全国部分中药材市场、石斛产品加工、销售企业的对接、调研活动；组织1次省内紫皮石斛种植情况调研活动，全面掌握全国紫皮石斛种植情况；积极构建有形的营销市场网络与虚拟的电子商务平台营销网络经营模式。

6．探索金融支持石斛产业新业务。充分发挥县石斛研究所、龙斛生物科技有限公司作用，盘活存量资产，逐步拓展经营范围，为搭建融资平台创造条件；积极探索石斛产品存货质押贷款、种植保险、石斛产业基金等金融措施，提高石斛企业融资能力和石斛产业的抗风险能力。

7．科技支撑，培植龙头。林业、工信、市场监管、石斛研究所等部门要进一步加强与各级科研院（所）的合作（协作），走产、学、研相结合的路子，积极探索能够有效解决石斛种苗、野生栽培、病虫害防治、质量安全控制、保鲜及精深加工等方面的技术性难题；在云南省《紫皮石斛》地方标准的基础上，不断进行技术创新，不断增加对石斛产业的科技投入，强化科技成果转化，提高科技对石斛产业的贡献率，为产业健康发展提供科技支撑、技术保障和智力支持；开展紫皮石斛良种选育、规范集约化种植、野生种植技术；实施石斛种质资源圃建设，做好石斛种质资源收集保护工作；加大培植龙头企业力度，做好企业项目建设服务工作，积极争取项目资金扶持龙头企业，鼓励企业开发石斛系列产品，延伸产业链，提高产品附加值；加大对石斛专业合作社的支持，提升合作社产业带动作用。

8．加强宣传，开拓市场。加强石斛质量安全管理的宣传，树立“质量是石斛产业生命线”的意识，坚定信心，推进石斛产业稳步发展；围绕打造“生态、环保、绿色、健康、安全”的“龙陵紫皮石斛”品牌，通过平面广告、电视、网络等媒体加大龙陵紫皮石斛宣传力度；组织对石斛产品销售市场、营销渠道进行调研，加强与石斛产品消费地区的联系，形成政府、企业之间的合作关系，支持石斛加工企业、石斛经纪人“走出去”找市场，到石斛产品消费市场建立产品直销点，拓宽石斛产品销售渠道，利用“互联网+”发展电子商务线上销售，拓宽销售渠道、增加销售收入。县石斛协会要做好产品加工和市场营销，扩展石斛产品销售渠道和市场，发挥产品价格调控作用。

三、扶持政策

（一）新植扶持。对当年新增野生（天然林种植、移活树种植）种植石斛连片面积达到5亩以上且每亩种植8000株以上的，经检查验收合格每亩补助1000元，同时在贴息贷款、小额担保贷款上给予重点扶持；对当年有机种植石斛净面积在400平方米以上且每平方米种植60株以上，并严格执行规范化管理制度的种植户，由县林业局按照规定优先给予贴息贷款扶持，同时提供相应的技术资料、技术培训、产品质量检测及信息服务。

（二）野生种植县级示范园扶持。对确定的县级示范园，经检查验收达到标准的给予10万元资金补助，重点支持示范园用于水、电、路、管护用房建设及生态种植技术试验示范，示范园扶持与野生新植扶持不得重复补助。对县级确定的生态石斛示范村，经验收合格，给予一次性补助15万元，用于石斛基地的基础设施建设、文化氛围营造等。

（三）企业发展扶持。积极支持企业申报以紫皮石斛为主要原料的普通食品、保健食品、药品生产许可证，对申报企业相关职能部门全力配合，鼎力支持；对县内经营电子商务销售石斛产品且销售额达100万元—300万元的企业给予2万元的资金鼓励，销售额达300万元—500万元的给予4万元的资金鼓励，销售额在500万元以上的给予5万元的资金鼓励；对合法经营、守法经营、诚信经营的企业给予免费使用“龙陵紫皮石斛地理标志证明商标”“农产品地理标志”和“国家地理标志保护产品标志”。

（四）石斛专业合作社的扶持。积极帮助经营管理较好的石斛专业合作社申报示范性农民专业合作社，获得国家级、省级、市级示范性农民专业合作社称号的按照上级的补助政策兑现；对具有固定枫斗加工场所、有相对固定加工人员，并且示范带动作用较好的专业合作社，可以申报枫斗标准化加工点项目扶持；对县内经营电子商务销售石斛产品且销售额达100万元—300万元的专业合作社给予2万元的资金鼓励，销售额达300万元—500万元的给予4万元的资金鼓励，销售额在500万元以上的给予5万元的资金鼓励；对合法经营、守法经营、诚信经营的合作社给予免费使用“龙陵紫皮石斛地理标志证明商标”“农产品地理标志”和“国家地理标志保护产品标志”。

（五）市场拓展的扶持。鼓励县内企业、合作社、协会副会长单位、种植户到省外开设专门销售龙陵紫皮石斛产品的店铺，对年销售鲜条数量在50吨或干品10吨以上的，凭县林业局调运手续及销售记录给予铺面租金补助5万元；对年销售鲜条数量在100吨或干品20吨以上的，凭县林业局调运手续及销售记录给予铺面租金补助10万元；对合法经营、守法经营、诚信经营的企业、合作社、个人给予免费使用“龙陵紫皮石斛地理标志证明商标”“农产品地理标志”和“国家地理标志保护产品标志”。

（六）扶持政策要求。对在城镇规划区范围内的种植户、没有取得种植资格的新增种植户、没有加入石斛协会的种植户、石斛产品没有经过质量检测合格的种植户一律不予贴息贷款、小额担保贷款等一切政策扶持。

四、工作措施

（一）强化领导，明确职责。成立龙陵县石斛产业工作领导小组，负责组织、指挥、协调全县石斛产业发展工作，研究发展中的重大事项，建立石斛产业联席会议制度，定期研究石斛产业发展工作；各乡镇要统一思想、提高认识，及时调整充实石斛产业领导机构、工作机构，定期或不定期的研究部署石斛产业工作，及时解决发展中遇到的重大问题，要进一步明确石斛产业工作领导小组的职能、职责，建立相应的规章制度，对种植农户、石斛辅导员、石斛协会会员进行有效的管理；整合石斛研究所、林业产业工作站、龙斛生物科技有限公司人员，进一步明确职责，做到统筹协调、全面推进；县发改、财政、金融、宣传、农业、市场监督管理等部门要积极争取上级项目资金支持，积极筹措资金，加大对石斛产业发展各个环节的投入；在新农村建设、整村推进项目实施过程中找准与石斛产业发展的结合点，整合项目、整合资金；支持生产加工企业做好以龙陵紫皮石斛为原料或主要原料研发的保健食品研发及向上级主管部门申报保健食品注册批文工作；推进石斛深加工、交易市场建设等项目招商引资工作；加强天气预测预报工作，及时发布预警信息，各乡镇要认真抓好监督，做好灾害应急处置，及时反馈相关灾害信息；县石斛研究所要做好基础设施建设和科研设备的配备，做好有关科研项目工作；县石斛协会要充分发挥行业管理和自律的作用，做好行业标准规范工作。

（二）确保质量，树立品牌。各乡镇、各部门要从石斛种植、加工、销售、流通各环节严格把关石斛质量安全，切实加强对石斛的生态种植、规范管理、全面检测工作，健全石斛产品质量安全管理体系，要把石斛质量安全工作作为石斛产业发展的重要工作来抓。进一步强化部门联动机制，各乡镇、各部门在做好石斛质量安全监管工作的同时紧紧围绕“龙陵紫皮石斛”品牌加大宣传力度，做好商标注册、品牌打造。

（三）加大投入，加快发展。一是积极主动开展招商引资工作，吸引外商来龙陵投资石斛精深加工、交易市场建设等项目。二是加大产业发展资金支持力度，县级财政安排150万元石斛产业发展资金专项用于推动石斛产业发展，各乡镇要筹措一定数额的资金专项用于石斛产业发展。三是积极向上对接争取项目支持，集中财力培植石斛产业化龙头企业。

（四）强化管理，搞好服务。县石斛协会要加大对各乡镇分会的管理工作力度，进一步明确责任。各乡镇石斛分会在县石斛协会的领导下，在乡镇石斛产业领导小组的指导下，认真开展工作，充分发挥行业管理和自律的作用，加强对种植户的管理和指导，组织种植技术、生产管理、产品销售等服务培训，做好行业标准规范工作；积极为会员提供林业贴息、小额担保贷款等扶持政策的宣传、业务办理服务；提高石斛协会会员入会率，提升对副会长单位和会员的服务能力，加强行业自律管理。

（五）强化督查，严格考核。县委督查室、县政府督查室将定期或不定期组织对石斛产业发展中的有关情况进行督促检查，确保工作质量和进度。2017年全县石斛产业发展完成情况统一纳入全县经济社会发展指标一并考核，占一定分值。

（此件公开发布）
