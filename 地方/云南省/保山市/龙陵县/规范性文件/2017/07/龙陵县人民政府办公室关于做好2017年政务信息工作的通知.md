# 龙陵县人民政府办公室关于做好2017年政务信息工作的通知

各乡、镇人民政府，县政府各工作部门，县直有关单位：

为进一步适应新形势、新任务的要求，规范全县政府系统政务信息工作的管理，提高政务信息质量和效率，为领导了解情况、科学决策、推进工作提供及时高效的信息服务，实现政务信息在全市争先进位的目标，推动全县政务信息工作再上新台阶，现就有关事项通知如下：

一、统一思想，充分认识加强政务信息工作的重要性

政务信息是政府工作的重要组成部分，是各级政府了解情况、协调工作、科学决策的重要保障。及时、准确、全面地反映经济社会发展中的重要情况，对于保证政府系统政令畅通、促进政府机关科学决策，具有十分重要的意义。各乡镇、各部门要把政务信息作为问政于民、问需于民、问计于民的重要渠道，作为反映新思路、新举措和新经验的重要平台，作为政府科学决策、制定政策、指导工作的重要依据，不断加强和改进政务信息报送工作，及时反映经济社会发展中出现的新情况、新问题，使政府作出的决策、采取的举措更符合客观实际和规律，更符合广大人民群众的意愿和利益。

二、围绕中心，明确政务信息的报送重点

认真遵循“把握大局、围绕中心、突出重点、服务决策”的原则，紧紧围绕党的十八大精神贯彻落实，按照县委十三届

二次全体（扩大）会议、县“两会”确定的目标，及时反映本乡镇、本部门工作开展情况。主要包括：当前中心工作的进展情况和问题；上级部署的重要工作开展情况；重要会议精神贯彻落实情况；各乡镇、各部门的新经验、新举措、新思路；国民经济和社会发展方面的重要动态情况；重大突发事件及其处理情况；文件、政策、指令在执行过程中出现的矛盾问题和解决建议；经济指标完成情况；重点项目的进展情况；责任目标落实情况等。

三、创新方法，提高政务信息的质量和水平

各乡镇、各部门要积极探索加强政务信息工作的新思路、新方法，努力在提高质量上下功夫，进一步提高信息服务水平。

（一）要做到及时、准确、全面。要以高度负责的态度，及时做好信息报送工作，确保信息的时效性，为县人民政府及时了解情况、掌握动态提供服务。要坚持以客观事实为依据，认真做好信息的采编、核实工作，确保上报的信息内容客观、数据准确、情况清楚，切忌以偏概全、主观臆断。

（二）要坚持喜忧兼报原则。坚持实事求是，有喜报喜，有忧报忧，喜忧兼报。既要报送在推进工作过程中取得的成效、经验，也要报送经济社会发展中出现的困难和问题，尤其是涉及到民生、土地房屋征迁、节能减排、安全生产、社会治安等影响社会和谐稳定的热点难点问题。在问题类信息的报送上既要注意反映宏观性、全局性的重大问题，努力争取上级政府的支持与帮助，也要反映基层的真实情况和呼声，切实为领导把握大局、作出决策提供依据。

（三）要提高信息采编的深度。要紧紧围绕县委、县政府的中心工作，进一步转变工作作风，深入基层，深入实际，切实加强信息调研工作。要突出重点，认真总结工作经验，并针对存在问题提出对策建议，形成有深度的专报信息。要加强对一般性或动态性信息的提炼和深度开发，积极挖掘特色和亮点，做到可预见的信息提前写、突发信息立即写、常规信息定时写，加强工作经验的总结提炼，努力形成高质量的政务信息。

四、强化领导，提升政务信息工作的保障

各乡镇、各部门要切实把政务信息报送工作列入重要议事日程，纳入年度目标考核，强化工作措施，抓紧抓实。一是要落实责任。单位主要负责人要亲自过问，分管负责人要具体部署，信息工作人员要专职抓实。二是要加强保障。要提供必要的经费保障，为信息工作人员参与领导活动、参加各种重要会议和重要调研活动提供有利条件，并通过参加培训、学习交流等方式不断提高信息工作人员的政治素质和业务技能。三是要强化网络建设。要进一步优化政务信息工作网络，拓宽信息采集和报送渠道，扩大信息来源，不断提高工作质量和水平，更好地为全县经济社会发展服务。

五、严把程序，规范政务信息的报送

（一）严格执行信息报送审签制度。上报县人民政府办公室的信息必须经本单位分管领导审核、签发，所报送的信息必须注明审签人、报送人姓名及联系电话，未注明审签人和报送人的信息不予采用。

（二）严格规范信息报送渠道。非涉密一般性政务信息可直接发送在县政府办信息股邮箱（llxzfbxxk@126.com）。紧急突发信息要按照全面、及时、准确的要求，务必在第一时间上报。如一时无法掌握详细情况或形成文字材料的，必须将初步情况以电话形式报县人民政府办公室值班室，随后及时将信息以纸质材料和电子文档上报，否则视为迟报或漏报。

六、提高认识，强化政务信息的任务落实

（一）任务分解。县人民政府办公室对2017年政务信息工作任务进行了分解（见附件1），请各单位参照分解情况抓好落实。县人民政府办公室将按季度对信息采编情况进行通报。

（二）评分标准。被《龙陵政务信息》和《龙陵政情专报》采用的信息每条计10分，简讯每条计5分，凡县委、县政府领导作出批示的每条加计5分；凡被市人民政府办公室采用的在县级计分的基础上加计10分，被市委、市政府领导批示的每条再加计10分，累计加计20分；凡被省政府办公厅采用的每条加计20分，被省委、省政府领导批示的每条再加计20分，累计加计40分；凡被国务院办公厅采用的每条加计30分，被党中央、国务院领导批示的每条再加计30分，累计加计60分。由两个或两个以上单位合报的信息，所得分值由合报单位平均分配，不重复计分和加分。报送信息失实，造成严重后果的，扣50—100分；紧急信息迟报、漏报被省、市级通报的扣50分，被县级通报的扣30分。

（三）稿费计发。采用稿费参照保山市人民政府办公室政务信息稿费计发相关标准执行。
