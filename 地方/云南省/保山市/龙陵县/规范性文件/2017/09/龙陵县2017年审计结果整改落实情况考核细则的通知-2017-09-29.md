# 龙陵县2017年审计结果整改落实情况考核细则的通知

各乡镇人民政府、县直各相关单位：

《龙陵县2017年审计结果整改落实情况考核细则》已经县人民政府分管领导同意，现印发给你们，请各涉及单位做好考核相关工作。

根据《中华人民共和国审计法》和中共龙陵县委办公室、龙陵县人民政府办公室关于印发《龙陵县2017年度综合考评方案》的通知（龙办发〔2017〕39号）精神，制定本细则。

一、考核范围

《龙陵县2017年度综合考评方案》所列考评对象中2017年接受县审计局审计的项目及以前年度未整改到位的项目。

二、考核时间

2018年初。

三、考核内容

本细则所称审计结果整改落实情况，具体包括：对《审计报告》、《审计决定》提出问题（以下统称审计查出问题）的整改落实情况及审计建议采纳情况，按要求报送《审计整改落实情况报告》或《审计决定执行、审计建议采纳情况反馈表》，自行公告整改结果等。

四、评分办法

根据《龙陵县2017年度综合考评方案》，该项目为“动态管理指标扣分项”之一，扣分上限3分。

1.对审计查出问题认真进行研究，制定整改措施，对照考核内容按期完成整改的，该项不扣分；未研究制定整改措施也未落实整改的，该项扣3分。

2.对审计查出问题已制定整改措施但未实际落实整改的扣2分， 部分整改、部分不整改的扣1分。

3.对审计查出问题已整改，但针对存在问题未采纳审计意见建议建立和完善相关内控制度、未按要求报送《审计整改落实情况报告》或《审计决定执行、审计建议采纳情况反馈表》、未将整改结果自行公告的，每项扣0.5分。

4.未按要求提供审计整改资料或对审计监督及整改设置障碍的，每次扣1分。
