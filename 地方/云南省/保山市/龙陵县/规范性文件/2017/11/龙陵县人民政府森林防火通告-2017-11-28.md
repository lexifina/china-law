# 龙陵县人民政府森林防火通告

根据国务院《森林防火条例》和《云南省森林防火条例》规定，经县人民政府同意，2017年12月1日至2018年6月15日为全县森林防火期，2018年3月1日至4月30日为森林高火险期。森林防火期间，各乡（镇）人民政府、森林防火指挥机构和村委会（社区）以及森林、林木、林地经营单位和个人，要根据森林火险预报，采取相应的预防和应急准备措施，加大监督检查力度和密度。禁止在林区林缘吸烟、烧纸、烧香、烧蜂、烧山狩猎、烤火、野炊、使用火把照明、燃放烟花爆竹和孔明灯、焚烧垃圾等，禁止携带火种和易燃易爆物品进入林区。进入林区的车辆和人员必须自觉接受森林防火检查站的检查和登记。严格控制农事用火，确需在林区、林缘用火的，一定要逐级申报批准，严格按照批准的时间、地点、范围用火，并服从森林防火指挥机构、林业部门的监督管理。森林高火险期间，林区及周边100米内禁止一切野外用火。要加强对无民事行为能力人和限制民事行为能力人的监护，严防被监护人进入林区用火、玩火。林区电力、通讯线路和石油天然气管道等产权单位，旅游服务单位和个人，中小学校要加强森林防火宣传教育，定期检查防火安全。任何单位和个人发现森林火灾，应当立即报告，及时拨打森林火警电话12119。违反用火管理规定，一律给予经济处罚，公职人员一律严厉问责，引发森林火灾并造成重大损失的，将依法追究刑事责任。
