# 龙陵县民宗局关于“两违”整治工作的实施方案

为认真贯彻落实中央和省、市城市工作会议精神，根据《云南省违法建筑处置规定》等规定，按照《中共龙陵县委办公室龙陵县人民政府办公室关于印发〈龙陵县进一步提升城乡人居环境五年行动计划（2016—2020 年）〉的通知》（龙办发〔2017〕13号）要求，结合工作实际，制定本方案。

一、总体目标

坚持“突出重点、疏堵结合、以拆为主、改造为辅、依法治理、属地管理、综合治理”的原则，完善防控违法违规建筑的制度体系，健全整治违法违规建筑的长效机制，全面开展城乡违法违规建筑集中治理行动，重点查处违法占用土地、影响规划实施、影响城乡面貌、占用公共资源、影响居民生活、群众反映强烈的违法违规建设行为，从根本上遏制违法违规建设行为，全面提升城乡人居环境。

二、工作任务

按照“杜绝增量、消化存量、建立机制、确保长效”的总体目标，通过宣传教育、调查摸底、集中整治、依法处理、检查验收等多种手段，严厉打击违法建设行为，提高广大群众依法建设意识，使违法违规建设蔓延势头得到有效遏制，城乡建设环境进一步优化，努力构建和谐社会。

三、工作原则

（一）明确职责分工。根据县委、县人民政府统一领导依法治理违法违规建筑工作，按职责分工，抓好落实。

（二）严格依法行政。必须严格按照《中华人民共和国城乡规划法》《中华人民共和国土地管理法》《中华人民共和国行政强制法》等法律法规规定，完善有关实施方案，加强执法队伍建设，建立健全管理制度，依法依规拆除违法违规建筑。

（三）完善规划管理。完善规划编制体系，科学编制规划，增强规划的科学性、严肃性和连续性，严格执行《城乡规划违法违纪行为处分办法》（监察部、人力资源和社会保障部、住房和城乡建设部令第29 号）和《云南省城乡规划督察办法》，建立健全违反规划行为追究机制，严肃追究违反规划行为的责任。

四、工作步骤

（一）宣传发动及摸底调查阶段。召开动员会议，进一步统一思想，对违法违规建筑综合治理工作全面安排部署，确定工作重点及职责分工，广泛宣传。对治理范围内的各种违法违规建筑进行全面、细致的调查摸底。

（二）集中整治阶段。按照分时、分区、分类、分期对违法违规建筑进行治理。按照职责分工，按步骤、分阶段逐步推进违法违规建筑综合治理工作。

（三）巩固提高阶段。加大日常监管力度，建立健全长效管理机制，防止违法违规建设行为反弹。大力宣传有关法律法规，提高群众素质，切实巩固违法违规建筑综合治理成果。

（四）检查验收阶段。完成治理成果的自检自查和档案归档工作。

五、工作要求

（一）提高认识，落实工作责任。切实增强责任感、使命感和紧迫感，严格按照方案要求，明确职责分工、分解工作任务、细化工作措施，并结合工作实际，创新工作方法，着力解决群众反映强烈的突出问题。强化违法违规建筑治理的责任主体，要充分认识依法治理违法违规建筑工作的重要性和艰巨性，要建立主要领导负总责、分管领导直接抓、工作人员具体抓的工作责任体系，尽快成立工作机构，制定工作方案和措施，层层分解任务、层层落实责任，确保任务落实和各项措施取得成效。必须将违法违规建筑纳入党员、干部个人事项报告范围，自行申报。充分发挥“一把手”第一责任人的作用，在规定的时间内督促干部职工带头治理，党员、干部要率先垂范、带头治理，并确保做好亲属工作。

（二）抓好宣传，提高群众意识。加大有关法律法规的宣传力度，使学法、懂法、守法成为群众的自觉行为，引导群众认识违法违规建设的危害性，从根本上抵制违法违规行为。

（三）严格要求，注重工作效果。一是对存在违法违规建筑的要自觉报告。不主动停止违法建设行为或不报告，一经查实，将予以严厉问责。二是主动配合执法部门开展查处工作，自觉整改和拆除违法建筑物、构筑物。

（四）细化分工，强力推进治理。要通力配合，加强协作，建立查处机制，确保违法违规建筑治理工作全面有序推进。

（五）强化督查，加快工作推进。对调查摸底情况、党员干部申报情况、自行治理情况和依法拆除情况进行督促检查。在治理工作中，对不作为、不配合、推诿扯皮、弄虚作假的单位和个人，要加大执纪问责力度。由本人自行组织治理，不主动治理或干扰阻碍拆除治理工作的，将按有关规定严肃处理。
