# 龙陵县人民政府办公室关于印发2018年政府工作报告重点任务责任分解方案的通知

各乡、镇人民政府，县政府各工作部门，县直有关单位：

《2018年政府工作报告重点任务责任分解方案》已经县人民政府同意，现印发给你们，并就方案实施的有关事项通知如下，请认真抓好贯彻落实。

一、认清形势，提高思想认识

2018年是全面贯彻落实党的十九大精神的开局之年，是改革开放40周年，也是龙陵决战脱贫攻坚、实现跨越发展、决胜全面建成小康社会的关键一年。为全面有效推进政府各项工作落细落实，县人民政府确定了63项重点工作，事关全县的发展大局，各项重点工作能否顺利完成，不仅直接影响到全县经济社会

发展目标的实现，而且对进一步筑牢龙陵今后的发展基础，加快经济结构调整和发展方式转变都具有十分重要的意义。因此，各乡镇、各部门要高度重视，坚持市委、市人民政府和县委的正确领导，全面贯彻落实党的十九大精神，以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，全面推进“五位一体”总体布局和“四个全面”战略布局，深入贯彻落实习近平总书记考察云南重要讲话精神，发扬“跨越发展、争创一流；比学赶超、奋勇争先”精神，集中力量推进脱贫攻坚优质化、工业聚集化、农业规模化、旅游品牌化、全域生态化、“五网”建设高效化、改革创新常态化、社会治理精细化，加快全面建成小康社会步伐。

二、明确责任，层层抓好各项工作任务

《2018年政府工作报告重点任务责任分解方案》明确了有关工作的主办单位、协办单位、责任领导和督办人，并实行县人民政府领导分管督办制和部门责任制，每项工作均由1—2名县人民政府领导分管，由1—2名县人民政府办公室对口负责人具体督办，主办单位的行政负责人为第一责任人。各主办单位、协办单位要按照通知要求认真履行职责，主办单位要率先负起责任，做好统筹协调，确保各项工作都有领导分管、有专人负责、有落实方案，按时按质完成工作任务；协办单位要主动落实承办的具体工作，密切配合，协同做好工作。任务分解中未提及的部门也要认真对照《2018年政府工作报告重点任务责任分解方案》中的任务和要求，明确目标任务，扎实做好各项工作，确保工作推进有力。

三、严格督查，确保工作顺利推进

县人民政府对63项重点工作实行年度督查制和督查工作逐级负责制，并根据工作进展情况，适时组织督查组进行专项督查，及时发现和解决工作推进中存在的困难、问题；各乡镇、各部门要结合各自工作实际，对各自负责的工作任务开展有效地督促检查，对工作中的重大情况和问题，要及时向县人民政府分管领导汇报，同时要定期、不定期上报工作进展情况。对因认识不到位、工作措施不力等原因造成工作进展缓慢的，给予通报批评、限期整改；对不作为、乱作为的，给予有关责任人问责，确保全年各项目标任务圆满完成。

四、认真落实，按时上报工作推进情况

各主办单位要围绕所负责的具体工作，按照“定目标、定责任、定时限、定标准、定措施”的原则，认真制定详细的工作落实方案，并由单位主要领导审签、加盖公章后于3月31日前报县人民政府督查室。并分别于6月30日和12月15日前将上半年工作推进情况、全年工作完成情况上报县人民政府督查室（报送格式见附件2）。联系人及电话：周竟 0875-6121736，电子邮箱：bslldcs@126.com。
