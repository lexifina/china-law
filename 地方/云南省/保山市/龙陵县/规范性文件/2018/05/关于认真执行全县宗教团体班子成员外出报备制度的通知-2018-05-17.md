# 关于认真执行全县宗教团体班子成员外出报备制度的通知

县宗教团体、各宗教活动场所：

为进一步加强宗教事务管理，保障各项工作有序衔接、正常运转。根据《国家宗教事务条例》及相关规定精神，经局领导班子研究，现就全县宗教团体班子成员外出报备有关事项通知如下：

一、报备对象

县佛教协会、县基督教“两会”会长（主席）、副会长（副主席）、秘书长（总干事）；各宗教活动场所主持（负责人）；全县备案宗教教职人员。

二、报备事由

离开龙陵县出差（开会、学习培训、交流研讨等），出国境探亲、旅游等。

三、报备时间

离开县内的，须提前3天书面向县民宗局报备；出国（境）的，应提前1周书面向县民宗局报备；因紧急事项临时外出的，先口头、电话向县民宗局分管领导报告，事后补填《外出报备情况表》。

四、报备方式

县佛教协会、县基督教“两会”会长（主席）、副会长（副主席）、秘书长（总干事）、各宗教活动场所主持（负责人），经书面向县民宗局报告并填写《外出报备情况表》，《外出报备情况表》报送县民宗局宗教股备案。在外期间行程、时间有变化的，要及时向县民宗局说明行程变化情况。全县备案宗教教职人员离开辖区须报所在活动场所主要负责人同意，并填写《外出报备情况表》存入活动场所档案。

五、有关要求

（一）报备对象外出期间应保持通讯畅通。

（二）报备对象外出期间，因故须逾期返回的，必须及时向县民宗局报告，并向宗教股报备。

（三）各全县宗教团体要严格按照本通知要求，切实抓好外出报备工作。对没有报备外出，或者与报备不一致的，将视情况予以约谈、通报批评。

龙陵县民族宗教事务局

2018年5月17日
