# 龙陵县0-14岁儿童脊柱畸形·先天性心脏病筛查实施方案

2018年，在市红十字会的关心指导下，在广大爱心人士的支持下，县红十字会与嘉里·首彩基金合作，在龙陵县实施脊柱畸形·先心病筛查，为切实抓好筛查工作，特制定如下实施方案：

一、筛查背景和目的

龙陵县属于高原地区，因农村医疗条件受限，部分妇女孕期未能得到全面的检查，先心病患病率高于平原和低海拔地区，主要以农村和山区为主。截至目前我县共有0-14岁儿童53605人。由于经济水平相对落后，大部分先心病患儿未及早发现或因贫困得不到及时治疗而夭折。为尽早发现患病儿童并及时开展手术救治，同时提高基层医生的诊断水平，县红十字会与嘉里·首彩基金会合作，在龙陵县开展先心病术前筛查。

二、组织保障

（一）健全组织，完善机构。

为确保如期完成筛查任务，经研究，成立龙陵县脊柱畸形·先天性心脏病筛查工作领导小组及工作督导组，人员名单及部门职责如下：

工作领导小组的组成：

组长：王德华县委常委、县人民政府常务副县长

常务副组长：闫双芹县政协副主席、县红十字会监事长

副组长：董军县红十字会常务副会长

闫义智县卫计局局长

余自明县教育局局长

成员：张必鹏县民政局局长

杨忠县人社局局长

马从晓团县委书记

赵燕梓县妇联主席

杨世海县残联理事长

毕红安县扶贫办主任

十个乡（镇）分管领导

领导小组下设办公室在县红十字会，由董军同志兼任办公室主任，负责处理日常工作。

各成员单位工作职责：

红十字会：负责筛查整体工作，做好部门间的协调联系，负责县级的筛查汇总，对筛查出的先心病患儿，及时联系转诊治疗。

各乡镇：组织开好筛查培训会，做好宣传动员，让群众知晓儿童先心病筛查的意义，积极主动带适龄儿童参加筛查。组织好本乡镇的卫生院筛查工作，按时完成筛查任务。

卫计局：负责从各医疗机构抽调业务精、技术好的医生按要求完成筛查工作，并从卫计局抽调4名工作人员、从县人民医院抽调6名志愿者配合开展培训工作，工作人员及志愿者于5月6日8:30到工作领导小组办公室报到（县红十字会办公室）。

教育局：组织各学校、幼儿园配合好筛查工作，提前安排、部署好5月7日下午到龙一中初中部和龙山小学初筛的相关工作。

民政局：对有先心病的儿童的困难家庭，按规定给予临时生活救助、大病医疗救助。

人社局：负责按医保政策落实接受手术治疗儿童的医疗费用报销及政策宣传。

团委、妇联、残联：做好先心病筛查工作的宣传，营造一个人人关心儿童、关心健康的良好氛围，按规定对困难家庭给予救助。

工作督导组：由红十字会、卫计局、教育局和县级医院相关人员组成，负责检查督导各乡镇筛查工作开展情况。

（二）经费保障

所需的筛查经费由嘉里·首彩基金会支持，县级给予相应工作经费配套，按筛查任务及工作量兑现到各医疗机构。

四、筛查方法和步骤

（一）筛查前培训

1.县级培训。县红十字会组织参与县级培训的人员进行初筛业务培训，对相关政策和先心病筛查技术进行辅导学习。

2.乡镇培训。各乡镇按照筛查工作要求，组织村医、村干部培训，全面安排布置筛查工作，宣传政策和培训先心病筛查相关知识。

（二）筛查对象和任务分配

1.筛查对象。龙陵县辖区内0—14儿童(含流动儿童)。

2.任务分配。各乡镇卫生院完成辖区内儿童初筛检查，县人民医院完成龙陵一中初中部、龙山小学、凯龙城幼儿园、特殊教育学校儿童的初筛检查，县妇幼保健和计划生育服务中心完成矫鹰幼儿园、县幼儿园(含锦绣分园及中心园)儿童的初筛检查，县中医医院（含河头卫生院）完成龙山镇辖区内除县医院和妇计中心负责以外的儿童初筛检查。

（三）筛查方法

1.村级筛查。先由村医和村干部对学龄前儿童进行入户宣传登记和初筛，通知疑似心脏有问题的儿童家长带着儿童在规定的时间到乡镇卫生院接受乡镇医生筛查。

2.各医疗卫生单位筛查。按照任务分配对辖区内适龄儿童进行宣传登记和初筛，将疑似儿童登记、汇总，上报县红十字会，通知疑似儿童在规定时间内到县人民医院参加复诊。

3.县级诊断。疑似先天性心脏病儿童家长在规定时间带儿童到县人民医院，由县人民医院与中国人民解放军总医院专家配合，进行B超确诊登记汇总。

五、工作要求及职责

（一）统一思想，提高认识

儿童先心病筛查是一项惠及千家万户的民生工程，各乡镇和部门要加强领导，把筛查工作与当前的精准扶贫工作紧密结合起来，安排专人负责此项工作，认真组织医院、学校、村干部和乡村医生抓好落实。

（二）明确责任，分工协作

各部门要加强工作的协同配合，既要明确工作分工，又要加强沟通协商，确保按时完成筛查任务，做到所有适龄儿童都得到项目筛查，确保所有确诊患儿得到及时诊治。
