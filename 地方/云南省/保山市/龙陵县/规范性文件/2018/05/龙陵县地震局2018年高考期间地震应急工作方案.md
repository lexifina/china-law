# 龙陵县地震局2018年高考期间地震应急工作方案

根据《龙陵县2018年全国普通高考工作方案》要求，为切实做好高考期间我县地震应急准备工作，特制定本方案。本方案适用于高考期间地震应急工作，特殊时段规定为2018年6月7日至8日。

一、组织机构

为确保高考期间震情判定的及时性，成立高考期间震情判定工作领导小组：

组 长：范必松

副组长：石晓玫

成 员：杨永平、周官强、苏尹旺、杨荣留

二、震情会商方案

（一）震情会商时间安排与要求

1.会商时间规定

按照龙陵县地震局震情会商制度要求，高考特殊时段会商安排在2018年6月1日和6月4日召开两次会商会。

2.会商工作重点

跟踪分析地震活动性和宏微观前兆资料动态变化特征，在分析趋势异常的基础上，重点突出短临异常的提取和判定，跟踪月会商提出的震情判定意见，给出未来一周或稍长一段时期，即高考期间的震情趋势判定意见。

（二）应急会商的规定与要求

1.启动条件

当发生具有广泛社会影响地震事件（龙陵县发生Ms≥3.0级地震)、出现重大异常、出现有明确三要素地震谣传和传言或接到领导指示后，县地震局必须立即组织召开加密（临时）会商会，并将会商意见逐级上报。

2.应急会商重点

突发地震事件：对显著地震事件后地震活动趋势给出震情趋势判断意见。

出现重大异常：判定异常的信度和性质；历史上出现的状况；与当前震情的关系。

出现谣传和传言：面对迅速传播的谣传，弄清其基本事实，并判断谣传出现地区近期的地震形势。

领导指示：针对领导指示的内容做出明确复。

三、异常及时报告

（一）异常及时报告

对发现突出的宏微观异常变化第一时间向市地震局预报科报告，实行突出异常变化报告不过夜。

（二）异常处置要求

1.一般异常核实

发现异常1小时内通过电话方式进行核实。视情况12小时之内组织现场核实。

2.重大异常核实

对重大异常，可由市、县地震部门派出的专家组进行联合调查。联合现场调查应在2天之内完成并得出初步结论。

3.调查核实结论

在24小时之内报告市地震局。

四、工作措施

（一）加强组组领导。县地震局要高度重视高考期间震情跟踪监视工作，保持思想上的高度警觉和行动上的全面准备，进一步健全组织领导体系，认真履行《工作方案》中各项职责。

（二）加强震情会商。县地震局要加强前兆资料的分析处理，认真做好周、月和加密（临时）会商。

（二）加强震情值班和监测仪器管理维护工作。县地震局要落实好24小时震情值班带班制度，特殊时段内，全县地震部门工作人员不得私自离开县城，保证能在二十分钟内赶到各自工作岗位；要加强对各类地震监测仪器设备的管理和维护，确保监测仪器工作正常，数据连续可靠，信息传输畅通。

（四）加强异常核实上报。地震局要加强与乡镇地震宏观联络员的联系，对重点宏观点要主动落实有无异常，对辖区发现的宏微观异常应按照异常处置要求及时组织进行现场核实和上报。

（五）加强配合保障。地震局要与相关部门加强联系，配合相关部门做好高考期间地震应急工作方案的修改完善和各项应急准备工作。高考期间龙陵县若发生有感地震，县地震局要及时向市地震局和县政府报告震情，并通报相关部门。

龙陵县地震局 2018年5月30日
