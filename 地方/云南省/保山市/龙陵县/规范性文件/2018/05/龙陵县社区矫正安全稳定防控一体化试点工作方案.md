# 龙陵县社区矫正安全稳定防控一体化试点工作方案

为进一步抓好社区矫正安全稳定工作源头治理，全面深化司法所主导、村（社区）委员会联动的一体化防控体系，切实构建起预防和减少社区服刑人员脱管、漏管和重新犯罪的“第一道防线”。根据省司法厅、省综治办、省教育厅、省民政厅、省人社厅《关于组织社会力量参与社区矫正工作的实施意见》和《保山市社区矫正安全稳定防控一体化试点工作的实施意见》要求，经县司法局党组研究，制定本方案。

一、指导思想

全面贯彻党的十九大精神和依法治国方略，以全国、全省政法工作会议精神为指导，紧紧围绕县委、县政府的决策部署，以维护社会安全稳定为宗旨，坚持规范化、标准化、精细化的工作理念，开拓创新，在国家现行法律框架内，不断探索、完善具有新时代中国特色社会主义的非监禁刑罚执行制度，充分整合利用社会各方力量和资源，不断加大对社区服刑人员的监督管理、教育矫正、帮困扶助力度，有效预防和减少重新犯罪，为龙陵经济社会跨越发展营造安全稳定的社会环境。

二、总体目标

紧紧围绕社区矫正安全稳定工作大局，强化忧患意识和风险意识，以管理横向到边、防范纵向到底为抓手，主动预防工作中存在的安全稳定隐患，切实增强社区服刑人员管控工作的预见性和实效性。通过建立司法所主导、村（社区）委员会联动的一体化防控体系，全面规范司法所社区矫正执法行为，充分发挥村（社区）委员会贴近社区服刑人员日常工作和生活的优势，有效预防和减少社区服刑人员脱管、重新犯罪，提高全县社区矫正监管教育水平，加强社区矫正突发事件应对能力，全力实现我县社区矫正工作深入开展与安全稳定的双推进。

三、时间要求

2018年5月20日前完成试点建设工作。

四、工作内容和步骤

（一）研究制定工作方案

1.2018年3月底前，县司法局研究制定《县社区矫正安全稳定防控一体化试点工作方案》，下发试点司法所。

2.2018年4月底前，试点司法所结合工作实际研究制定《乡镇、村社区矫正安全稳定防控一体化试点工作方案》。

（二）工作步骤

1.选定社区矫正安全稳定防控一体化试点。经县司法局党组研究，我县社区矫正安全稳定防控一体化试点工作，决定在前期选定矛盾纠纷联动调处试点的镇安镇镇安社区村民委员会、芒告村民委员会和龙江乡赧等社区村民委员会、勐柳社区村民委员会开展。

2.强化社区矫正安全稳定防控一体化组织领导。以社区矫正工作领导小组为依托，不断调整和充实领导小组成员，将具备一定工作基础或工作责任心强的村（社区）委员会干部充实到领导小组中，确保建立起一个务实、高效的组织领导机构。

3.建立社区矫正安全稳定防控一体化制度机制。牢牢抓住村（社区）委员会充分贴近社区服刑人员日常工作、生活这个实际和优势，从调查评估、矫正小组建立、日常监管、请假外出、考核奖惩、帮困扶助等工作中寻找切入点，如：一是在调查评估、考核奖惩、请假外出的审查、审批中增加村（社区）委员会出具书面意见的程序；二是建立社区矫正安全稳定防控联络员模式，按社区服刑人员所在村（社区）的行政区域进行划分，明确一名村（社区）委员会干部作为社区矫正安全稳定防控联络员（联络员人选原则上选用社区矫正工作领导小组成员），负责协助司法所开展区域内的防控工作；三是充分运用微信、口袋助理等信息化手段，将乡镇、村（社区）委员会、村民小组等社会力量凝聚起来，搭建起“一防一”“多防一”的防控一体化网络平台，从而对社区服刑人员的思想、行为动态和脱管、重新犯罪苗头做到第一时间掌握、第一时间发现、第一时间处置。积极探索建立将司法所抓管理与村（社区）委员会抓防范有效结合的制度。

五、工作要求

（一）开展试点乡镇司法所要结合上述试点的工作情况和工作特点，认真按照工作要求制定实施方案，强化指导、监督、协调力度，力争在5月20日前完成试点建设工作。未列入开展试点的乡镇司法所，也要按照试点方案要求抓好社区矫正稳定安全工作。

（二）试点乡镇司法所于每月15日前要将试点建设进展情况书面上报县司法局社区矫正大队，社区矫正大队将根据情况适时开展督查，对于工作拖沓、敷衍塞责等情况，将按照《保山市社区矫正工作问题通报制度》的规定进行通报处理。
