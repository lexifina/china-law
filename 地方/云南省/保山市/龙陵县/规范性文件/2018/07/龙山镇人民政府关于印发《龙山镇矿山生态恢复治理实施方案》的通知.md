# 龙山镇人民政府关于印发《龙山镇矿山生态恢复治理实施方案》的通知

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大精神，按照“五位一体”总体布局和“四个全面”战略布局，牢固树立并切实贯彻创新、协调、绿色、开放、共享发展理念，科学规划、整体推进、突出重点、注重成效，着力构建政府、企业、社会共同参与的恢复和综合治理新机制，尽快形成在建、生产矿山和历史遗留等“新老问题”统筹解决的恢复和综合治理新局面，全面提高我镇矿山恢复治理水平，为加快“森林龙山”“美丽龙山”建设作出新的贡献。

二、基本原则

（一）坚持“四个统一”。针对矿山恢复治理任务重、时间长、要求高、参建部门多的现状，必须坚持统一领导、统一规划、统一目标、统一标准。

（二）坚持政府主导、部门联动。进一步明确责任主体，一次规划、分步实施，各负其责。

（三）坚持矿山恢复治理与全民义务植树活动相结合。把全镇全民义务植树活动与矿山恢复治理工作有机结合，广泛动员镇干部、村干部、村民、参与到龙山镇矿山恢复治理工作中来，提高全民参与的自觉性。

（四）坚持因地制宜、适地适树。结合矿山的立地条件，选择以乡土树种为主、速生快长的树种开展造林恢复。

三、目标责任及时间要求

（一）目标责任

龙山镇矿山恢复治理总目标为612.9亩（有责任主体193亩，无责任主体419.9亩）。有责任主体的矿山恢复治理由国土所、林业站督促其责任人限期恢复治理；无责任主体的矿山恢复治理，由各村（社区）组织人员恢复治理，复绿造林，恢复治理造林树种选用旱冬瓜（桤木）。

（二）时间要求

各村（社区）目标任务于2018年7月31日前完成。

四、造林技术

（一）树种选择

按照适地适树、乡土树种为主的原则，恢复治理造林树种选用旱冬瓜（桤木）。

（二）造林技术

1．整地方式

整地方式采用穴状整地方式。整地时必须最大限度的减少对现有植被的破坏，同时要保证整地的土层厚度。对于没有土层、土层极薄或土壤污染严重的地块，必须采取培土的造林技术措施。

2．种植技术

种植株行距按2m×3m，每亩种植111株，打塘标准为：40cm×40cm×40cm。要根据当地气候条件，选用树种的生物学特性和土壤墒情确定种植时间，时间一般选择7月为宜。种植方法：第一步先将植树穴周边的表层土捣细后，回填到植树穴内，抚平穴底，厚度约20cm；第二步将苗木慢慢放在植树穴中央，扶正苗木，用细土从苗木树篼侧边垫正苗木，直到放手后苗木不偏斜；第三步再次向植树穴内沿树篼周围均匀回填细土捶紧，直到覆盖土高于树篼原根径3-5cm厚为宜，再用工具轻轻迫压土表即可；第四步沿树干周围垒一圈土埂，浇足定根水。

3．抚育管理

栽植后应及时设置护围栏和撑杆，防止苗木倒斜和人畜进入破坏，要视当地气候和土壤墒情而定，必要时组织浇水，中耕除草。

针对矿山恢复治理任务重、地势复杂的状况，各村（社区）要强化安全生产理念，牢固树立安全生产观，时刻绷紧安全生产这根弦，确保施工时间内不发生安全事故。

（二）资金保障

龙山镇恢复治理矿山无责任主体共419.9亩。各村根据面积统计苗木、制定具体造林时间后与林业站沟通，及时依法采购种苗待各村（社区）矿山生态恢复治理完成后，由林业站、国土所负责验收，由财政所按照每亩补助50元的标准统筹所需资金。

六、后续管理

1.今后各村（社区）一旦出现私挖乱采现象，必须及时制止，制止不了要及时上报有关部门。

2.对已恢复治理的矿山要加强管理，确保种植的林木成活。
