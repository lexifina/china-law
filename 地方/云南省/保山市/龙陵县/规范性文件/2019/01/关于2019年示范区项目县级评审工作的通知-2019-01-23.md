# 关于2019年示范区项目县级评审工作的通知

龙山镇、平达乡、木城乡人民政府：

根据《关于云南省示范区建设十百千万工程第二批项目申报工作的通知》的要求，现将2019 年示范区项目县级评审工作有关事项通知如下：

一、请各乡镇分别安排1名分管领导和项目编撰人员参加评审。

二、评审日期：2019年1月25 日9:00 在县政协二楼会议室召开评审会（请各乡镇参加人员8:30 以前到县民宗局报到，并自行携汇报材料,一个乡镇一个综合汇报材料）。

三、评审顺序如下：

1.龙山镇芒麦村蛮旦民族特色村建设项目

2.平达乡民族团结进步示范村（产业）建设项目

3.木城乡民族团结进步示范村（抵边小集镇、民族特色村、产业）建设项目。

龙陵县民族宗教事务局

2019年1月23日
