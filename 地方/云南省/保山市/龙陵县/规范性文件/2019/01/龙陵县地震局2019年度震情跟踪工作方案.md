# 龙陵县地震局2019年度震情跟踪工作方案

为全面贯彻落实2019年度保山市地震趋势会商会精神，全力做好2019年度龙陵县震情监视跟踪与短临预测预报工作，根据保山市地震局《关于印发保山市2019年度震情监视跟踪工作方案的通知》（保震发〔2019〕1号）要求，结合云南省当前面临的强震大震形势和龙陵县实际，特制定本方案。

一、总体思路

全面贯彻落实2019年度全国、全省地震趋势会商精神，牢固树立“震情第一”的观念，以最大限度减轻地震灾害损失为根本宗旨，按照“重基础、重措施、重短临、防大震”的工作思路，加强组织领导，完善工作机制，落实工作责任，加强地震监测，强化数据处理分析与异常核实，及时会商研判，加强信息服务，切实做好2019年保山市震情监视跟踪与短临预测预报工作。

二、组织机制

为加强我县震情跟踪工作的组织领导，我局成立了震情跟踪工作领导小组，组成人员和工作职责如下。

组长：范必松（龙陵县地震局局长）

副组长：卢升玉（龙陵县地震局副局长）

石晓玫（龙陵县地震局副局长）

成 员：杨永平、苏尹旺、杨荣留。

主要职责：

1.组织实施震情跟踪监视工作，制定震情跟踪预测预报技术方案；加强24小时震情值班；加强地震活动和前兆资料的动态跟踪分析研究。及时组织震情会商，拟定上报震情预测意见，及时向市局和县政府上报各种灾情资料。充分应用邦腊掌地震观测站观测资料，全市五县区观测资料和短临前兆宏观异常指标的动态分析和研究，对各种震兆和前兆异常信息进行全面、深入、细致的分析研究，把握震情发展趋势。

2. 当确认进入短临阶段后，及时增加短临跟踪观测手段，加密观测，捕捉临震突变信息。及时维护观测仪器，确保观测仪器正常工作，确保地震观测数据、资料能及时传送上报。

3．强化重大异常落实、分析研究工作。对出现的重大宏、微观异常现象，及时进行现场落实和分析研究工作，尽可能进行定量测试并能有效识别，必要时进行定点连续观测，在确认异常可靠的基础上捕捉短临震兆信息。

4．与周边县市地震部门互通情报，形成微、观宏观监视网。县域内，充分发挥乡村地震宏观联络员能动作用，及时捕捉可出现的各种宏观异常现象。

三、工作措施

（一）邦腊掌观测站水化测项跟踪

1.制定本单位震情跟踪方案，制定措施、分解责任，并认真组织实施。

2. 坚持按观测规范，做好水氡、水温、流量、恒量汞、氢浓度等数据的观测。按时、按质提供连续可靠的观测数据。确保仪器设备正常工作，观测数据连续可靠和及时上报。准确记录周边相关范围内可能影响观测资料的环境变化，确保观测数据准确有效。

3. 加强观测仪器的检修和维护，全面检查仪器运行状况，发现仪器故障、问题及时报告市局监测预报科。

4.观测中一旦发现观测资料突出异常，要及时查明原因并上报结果。每天对一号泉采样的同时，注意流沙和汽泡的观察。对仙人澡堂水色的观察，并做好文字记录，及时上报县局。每月1、15日，对一号泉、二号泉、仙人澡塘、间歇泉、大沸泉流量进行观察，水温测量和间歇时间记录。

（二）地震分析预报跟踪

1.每天对观测数据进行处理分析，发现异常立即组织核实。每周一组织全局人员进行震情会商，并填报《宏微观零异常报告登记表》，上报市局监测预报科。每月底组织全局人员召开震情会商会，对下一月地震形势开展分析，把分析结果上报市局监测预报科。

2.加强与周边县区的震情跟踪交流，每周、每月定期交流震情趋势意见，努力提高震情分析研判的科学性。

3.加强震情会商，县内出现3级以上地震，周边县区发生5级以上地震，立即启动本局应急预案，进行紧急和加密会商，研究震情发展趋势，并把会商意见上报市地震局。每年5月、9月上旬上交年中、年度地震趋势研究报告。

4. 县内出现3级以上地震，周边县区发生5级以上地震，立即组织全局人员开展震情会商，并把地震三要素上报县委县政府，并提出对策建议，积极做好重要时段的震情保障工作，有效应对各种突发性地震事件，维护好社会稳定。

（三）信息传递与处理

1.保障计算机网络、信息传输畅通，数据传输准确、及时。

2.确保每天按时报数、传数，做到不缺数。

3.做好行业网络和网站的维护、管理，出现问题及时报告、及时维修。

四、保障措施

1.加强组织领导，局主要领导为第一责任人，分管领导为第二责任人，股室领导为直接责任人，认真履行震情跟踪工作责任。主要领导要及时向上级业务管理部门和县政府汇报震情跟踪监视情况。

2.加强震情值班，本局的值班制度中，安排了值班人员和带班领导，实行全天24小时值班、带班。一旦我县及周边县区发生3.0级以上有感地震，立即启动本局应急预案，全局人员立即进入临震应急状态，开展震情跟踪及会商，判断地震发展趋势。

五、震情跟踪技术方案

1.震情跟踪区域

中国地震局和云南省地震局2019年度会商结论，滇西北东条带的德宏-保山-大理-丽江-迪庆列为5.0级地震重点监视区，龙陵县在危险区范围。因此，龙陵县地震局重点跟踪好本县范围的各种宏微观异常，立足邦腊掌基础数据，及三十多年来地方震前兆异常数学形态，做好短临跟踪。
