# 龙陵县财政局龙陵县民宗局关于下达2019年扶贫资金少数民族发展资金项目事业计划的通知

龙山、平达、木城乡(镇)人民政府

根据《保山市财政局关于下达2019年第一批央财政专项扶贫资全的通知》(保财整合(﹝2018﹞11号)《龙陵县财政局关于下达2019年统筹整合财政涉农资金(第期)的通知》(龙财涉农合(﹝2019﹞1号)和《龙陵县扶贫办龙陵县财政局关于下达2019年时牌农资金整合项目计划(第二期)的道知》(龙开办(﹝2019﹞)11号)文件要求,现将中央少数民族发展资全1500万元项目事业计划下达给你们(详见附表),并就相关事宜道知如下:

一、严格资金管理和项目建设

在项目建设中,不得撞自改变项目建设计划和资金用途,格按照国务院办公厅印发《关于支持贫困县开展统筹整合使用财政涉农资金试点的意见》(国办发[2016]22号)、省委办公厅印发的《贫困县开展统筹整合使用财政涉农资金试点的意见方案》(云厅字﹝2016﹞20号)、《中央财政专项扶贫项目资金管理办法》(农财﹝2016﹞22号)、《少数民族发展资金管理办法》等相关规定做好项目的实施、监督、检查、审计、验收、档案及招投标、公示公告等项目实施工作,确保资金安全运行。

二、确保项目建设任务顺利完成

（一）在项目信息管理中，此次安排的项目资全是中央财政专项扶貧资全(少数民族发展资金)项目。龙山镇，平达乡、木域乡人民政府是该项目的实施单位，要不断创新项目建设机制，严格执行项目招投标、资金公告公示、目工竣工等验收制度,确保资全专款专用，不得滞留、截留和挪用。

(二)请龙山、木成、平达乡人民政府接此通知后，及时开展项目建设。一是2019年2月20日前完成项目招投标、资金公示公告等项目实施工作。项目招投标结束后，以乡政府红头文件的形式（xx项目开工报告）（“项目群”文件中下载），以及招投标相关合同文件、公示公告材料，于2019年2月28日以前，盖章并扫描电子版上报“项目群”。二是2月28日前必须确保开工建设。项目建设过程中,项目实施乡镇要切实加大项目建设的督促检查力度,确保项目建设进度和质量。三是6月30日前确保项目建设全部完工，并严格按照示范区建设示范点创建考核办法及(尤陵县财政专项扶贫资金乡级财政报账制管理实施细则试行))(龙政办发(2017)67号)文件,做好乡级项目验收工作,并将验收材料报县民宗局,县财政局农财科备案。

（三）根据项目建设进度,及时做好项目实施和资全使用情况书面材料及数码图片电子版上传至“项目群”,纸质版签字盖章报县民宗局和财政局农业股，同时按照项目验收要求，做好乡级报账及项目验收等痕迹工作。

龙陵县民族宗教事务局

2019年1月28日
