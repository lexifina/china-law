# 龙陵县人民政府办公室关于县政府门户网站2018年四季度运行情况的通报

各乡、镇人民政府，县直有关单位：

根据县人民政府主要领导指示，结合三季度网站运行情况通报的整改落实情况，县人民政府办公室组织开展了四季度全县政府网站运行维护管理工作情况检查，现将检查情况通报如下：

一、总体情况

2018年四季度县政府门户网站共发布信息1335条，其中，动态类信息751条，公开类信息584条（发布情况见附件）；“来信留言”栏目收件36件，已按时办复36件，办复率100%，内容主要涉及教育、民政、道路交通建设、医疗保障、住房保障、社保工作等方面；网站总访问量32万余次，除省内用户外，大部分访客来自北京、上海、天津、广东、辽宁等地，主要浏览终端（操作系统）Windows、Android和iOS分别占76.23%、15.96%和4.63%，其他类型终端占3.18%。

二、存在的主要问题

（一）部分网站运营管理不到位。监测发现县工业和科技信息化局、县国土资源局、县司法局、县住房和城乡建设局、县水务局、县安全生产监督管理局、县环境保护局、县地震局、县招商局、县硅工业园区管理办公室、镇安镇人民政府等多个部门和乡镇网站栏目更新不及时。乡镇部门对“错别字检测系统”运用不充分，发布的信息中错别字现象仍然存在，县地震局10月25日发布的“龙陵县2018年防震减灾工作总结”中将“党的十九大精神”表述错误，县石斛研究所10月29日发布的“国家基本药物目录（2018年版）解读”将“中华人民共和国”表述错误，根据网站普查指标，属“单项否决”。

（二）网民留言办理不规范。存在办理留言“等通知才办”、“敷衍了事”、“能公开的留言不公开”等情况。

三、下一步工作要求

（一）进一步加强网站建设与管理。各乡镇、各部门要按照《政府网站发展指引》有关工作要求，强化责任意识，切实加强网站维护管理工作。

（二）规范政府网站域名管理。按照《云南省人民政府办公厅关于印发全省政府网站域名清理工作方案的通知》（云政办函〔2018〕193号）要求，严格执行注册审批制度，做好域名变更、备案、注销等工作。

（三）高度重视网民留言办理工作。要明确专人负责，每日登录政府门户网站后台管理系统，及时处理，同时加强对答复内容的审核，能公开答复的留言应公开答复。

（四）强化政务公开工作。要对照《龙陵县2018年政务公开工作要点分工方案》《龙陵县政务公开工作存在问题整改方案》及《保山市推进公共资源配置领域政府信息公开实施方案》《保山市推进社会公益事业建设领域政府信息公开实施方案》等政务公开工作的要求，在政府门户网站持续推进政务公开工作。特别是公共资源配置领域及社会公益事业建设领域政府信息公开工作，牵头部门要积极与市主管部门对接，推进相关工作。

对此次通报指出的问题，有关乡镇、部门（单位）要高度重视，认真整改，于2019年2月20日前将整改情况（主要负责同志签字纸质版1份和电子文档）通过协同办公平台报县网管中心。
