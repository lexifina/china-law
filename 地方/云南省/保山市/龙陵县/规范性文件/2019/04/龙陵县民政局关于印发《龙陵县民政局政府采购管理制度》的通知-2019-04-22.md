# 龙陵县民政局关于印发《龙陵县民政局政府采购管理制度》的通知

局属各股室、二级单位：

现将《龙陵县民政局政府采购管理制度》印发给你们，请认真贯彻执行。

龙陵县民政局

2019年4月12日

龙陵县民政局政府采购管理制度

为进一步规范我局项目采购行为，提高采购资金使用效益，有效地控制单位支出，节约财政资金，强化廉政建设，实现采购公开、公正、公平。根据《中华人民共和国政府采购法》《中华人民共和国招标投标法》、《云南省2019年政府采购集中目录及标准的通知》等要求，结合我局项目采购、内控制度、财务管理工作实际，特制定《龙陵县民政局政府采购管理制度》。

第一条 组织领导。成立项目采购工作领导小组，由分管项目工作的副局长担任组长，成员由负责项目、财务的工作人员以及股室负责人、二级单位负责人组成。项目采购管理工作领导小组下设办公室在项目办，办公室主任由负责项目的工作人员担任，副主任由负责财务的工作人员担任，负责民政局日常采购管理工作。完成政府采购项目申报审批表的填制、申报、参与招标和自行组织采购的招标函制作、招标函公示、招标主持、发中标通知书、中标公示、档案管理等工作。

第二条 采购适用。民政系统内各单位使用财政资金和其他资金进行货物类采购、服务类、与工程建设有关的服务等。

货物类，是指各种形态和种类的物品，包括原材料、燃料、设备、产品等。

服务类，是货物和工程以外其他与民政服务有关的政府采购对象。

工程建设服务类，是指民政建设工程，具体包括敬老养老服务中心、殡仪馆、公墓建设、儿童福利院、救助站、特困人员供养机构设施等工程地堪、设计、造价、监理等服务。

第三条政府采购预算编制。年初各科室根据科室实际情况上报所需购买的办公设备、劳务服务或工程服务，提出采购申请，编制采购预算和计划，报分管领导审核后报单位主要领导签批，签批后报采购领导小组统一办理。

预算的编制和审核既要满足业务需要，同时也要和资产存量情况相适应，既要避免出现重复购置、浪费资金，又要避免应购未购影响业务工作。

第四条 项目审核。单位政府采购实行领导审核签批制度，单位采购价值在1万元以上的采购项目由单位领导班子集体研究决定。采购环节中的采购需求与审批，采购实施与监督、验收，采购付款审批与付款执行等不相容岗位相分离。各部门将所需采购项目提出书面申请经财务审核资金来源后，报请分管领导同意，再由采购领导小组办公室按程序进行采购。

第五条政府集中采购项目目录和标准及审批程序。严格执行《云南省2019年政府采购集中目录及标准》规定要求，政府集中采购目录之内具体审批程序为：

民政局各股室及二级单位招标采购，由采购股室根据批准的采购方案或根据局批复的事项填写《龙陵县政府采购项目申报审批表》，报规财股核实资金来源，经局分管领导、财务分管领导审核同意后，按程序由项目办经办人员通过政府采购系统在网上按程序办理。

第六条 分散采购限额标准。政府集中采购目录之外，单项或批量金额在50万元以上（含50万元）的项目按政府集中采购程序办理。

政府集中采购目录之外，单项或批量金额在50万元以下（不含50万元）项目的采购程序：

民政局各股室及二级单位招标采购，由采购股室根据批准的采购方案或局批复的事项填写《龙陵县政府采购项目申报审批表》，经局规财股核实资金来源、签批审核意见，采购部门分管领导审核，报项目采购工作领导小组办公室签批拟采购方式，采购方式包含：竞争性谈判、询价、竞争性磋商、单一来源（单一来源采购必须经民政局局长办公会决定），报请局采购工作领导小组组长或副组长对采购项目进行审核签批。

单项或批量采购限额，如果政府年度集中采购目录和标准有变化，按变化限额执行，未变化之前严格按照规定执行，不得以化整为零方式规避政府采购。

第七条目录外项目招标采购。

民政局各股室及二级单位需进行目录外招标采购的，由民政局项目采购工作领导小组办公室负责招标采购。采购预算在10-50万元项目根据批准的采购方式采购，在10万元以下项目采用简易程序按单一来源采购方式进行。

第八条招标采购公示。采购公告在民政局门户网站及龙陵县民政局一楼宣传栏。

第九条开标。开标时，由民政局项目采购工作领导小组办公室负责检查投标文件密封情况，经确认无误后，方可拆封，宣布投标人名称、投标价格和招标文件规定的需要宣布的其他内容，投标人不足3家不准开标。

第十条评标。项目评审按《中华人民共和国政府采购法》第三十八条、第三十九条、第四十条规定程序办理。组建局项目内部评标专家库，成员由申请采购股站室及民政局项目领导小组办公室人员组成。项目评审时，由专家库中随机抽2人，组成3人的内部评审组进行评审。

第十一条项目评审程序及办法。项目评审程序及办法按《中华人民共和国政府采购法》第三十八条、第三十九条、第四十条规定及财政部令第74号《政府采购非招标采购方式管理办法》、财政部令第87号《政府采购货物和服务招标投标管理办法》办理。

第十二条中标及公示。成交结果在龙陵县民政局一楼院场宣传栏及民政局门户网站上进行公示。

第十三条合同。采购单位根据确定的中标人，中标人15日内应与采购单位签订合同，所签合同不能对招标确定事项和中标人投标文件作实质性修改，合同应包括采购人与中标人名称、住所、标的、数量、质量、价款或报酬、履行期限及地点和方式、验收要求、违约责任、解决争议方法等相关内容。工程类和服务类视情况签订安全生产合同，采购合同、安全合同报项目采购工作领导小组办公室备案。单位合同必须经法人签字。

第十四条项目实施及管理。按《龙陵县民政局项目管理实施细则》（试行）管理。

第十五条项目验收。中标人完成采购单位的货物、服务后，采购单位和项目采购工作领导小组办公室组织相关人员要按照采购合同，对采购的每一项工程、产品、技术、服务等进行验收，并出具验收意见，验收意见由验收人签名，必要时邀请第三方参与验收。

第十六条资金管理。按项目资金管理相关规定执行，报账时规财股严格把关，凡进行政府采购和招标的项目，报账时必须提供政府采购及招标的相关材料。

第十七条采购的监督和纪律。凡使用财政资金和其他资金进行货物类、服务类采购的，一律办理采购手续，未经同意自行采购的，财务不得列支，局规划财务股、项目采购工作领导小组加强对项目采购行为的指导、监督和检查。任何单位和个人有权监督和举报采购活动中的违纪违法行为。

第十八条，解释及执行。本规定由龙陵县民政局负责解释，自发文之日起施行。
