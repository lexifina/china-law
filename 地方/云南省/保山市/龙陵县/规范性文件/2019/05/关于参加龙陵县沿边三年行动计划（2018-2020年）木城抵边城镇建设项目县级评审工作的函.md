# 关于参加龙陵县沿边三年行动计划（2018-2020年）木城抵边城镇建设项目县级评审工作的函

县发改局、财政局、住建局、国土局：

根据《云南省深入实施兴边富民工程改善沿边群众生产生活条件三年行动计划（2018—2020 年）》（云政办发〔2018〕76 号）和《保山市深入实施兴边富民工程改善沿边群众生产生活条件三年行动计划（2018—2020 年）》（保政办发〔2018〕55 号）文件要求，龙陵县人民政府于2018 年12 月印发了《龙陵县深入实施兴边富民工程改善沿边群众生产生活条件三年行动计划（2018—2020 年），根据上述文件精神，木城乡人民政府负责组织《龙陵县木城抵边城镇建设规划设计方案》编制工作。现项目建设规划设计方案已编制完成，初定于2019 年5 月24 日下午15:00 在政协二楼会议室组织县级评审，特请贵单位一名领导参加评审为谢！请贵单位把参加评审人员名单（姓名、性别、职务、联系方式）于2019 年5 月22 日下午16:30 前报龙陵县民宗局（联系电话0875-6121109、传真6121109）。

此函。

龙陵县民族宗教事务局
