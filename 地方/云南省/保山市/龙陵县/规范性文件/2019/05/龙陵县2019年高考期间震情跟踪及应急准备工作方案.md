# 龙陵县2019年高考期间震情跟踪及应急准备工作方案

为切实做好龙陵县2019年高考期间的震情监视跟踪及应急准备工作，特制定本方案。

一、组织机制

为确保龙陵县2019年高考期间震情判定的及时性和协调性，成立高考期间震情跟踪领导小组、震情判定工作组及地震应急工作组：

（一）震情跟踪领导小组

组 长：李正双

副组长：卢升玉

成 员：杨永平、杨荣留

工作职责：负责龙陵县2019年高考期间震情跟踪监视工作的组织领导；组织开展龙陵县2019年高考期间震情跟踪监视与短临预报工作；研究和协调解决震情跟踪工作中的重大问题；协调和指导相关单位进行地震应急工作。

（二）震情判定工作组

组 长：卢升玉

副组长：杨永平

成 员：周官强、杨荣留

工作职责：组织开展龙陵县2019年高考期间的震情监视跟踪工作；深入分析地震活动性，跟踪各类宏微观异常的发展，分析地震趋势；根据有关要求报送龙陵县2019年高考期间地震趋势判定意见；根据实际情况提出稳定社会的工作措施。

（三）地震应急工作组

组长：李正双

副组长：石晓玫

成员：周官强、罗明祝、王钇涵

工作职责：组织开展龙陵县2019年高考期间地震应急准备工作，地震局震害防御股具体承担应急处置及联络工作。

二、震情会商

（一） 震情会商时间安排与要求

1.会商时间规定：6月3—8日每天进行加密会商，研判高考期间龙陵县震情趋势。

2.会商工作重点要求：跟踪分析地震活动性和宏微观前兆资料动态变化特征，在跟踪分析趋势异常的基础上，重点突出短临异常的提取和判定，跟踪研究月会商提出的震情判定意见，给出未来一周或稍长一段时期，尤其高考期间的震情趋势判定意见。

（二） 应急会商的规定与要求

1.启动条件

当发生具有广泛社会影响的显著地震事件（龙陵县发生Ms≥3.0级或有感地震）、出现重大异常、出现有明确三要素地震谣传和传言或接到领导指示后，立即组织召开加密（紧急）会商会，并将会商意见逐级上报。

2.应急会商重点

突发地震事件：对显著地震事件后地震活动趋势给出震情趋势判断意见。

出现重大异常：判定异常的信度和性质，分析历史上相关震例和当前震情的关系。

出现谣传和传言：弄清谣传来源，判断谣传出现地区近期的地震形势，迅速辟谣，稳定社会和民心。

领导指示：针对领导指示的内容作出明确答复。

三、异常跟踪

（一）异常及时报告

对发现突出的宏微观异常变化第一时间向县委县政府及市局监测预报科报告，实行突出异常变化报告不过夜。

（二）异常处置要求

1.一般异常核实

发现异常后1小时内通过电话方式进行核实。视情况在12小时之内组织现场核实。

2.重大异常核实

对于重大异常，报请省、市地震局，并协助省、市派出的专家组进行联合调查核实。联合现场调查核实应在2天之内完成并得出初步结论。

3.调查核实结论

异常出现后，经调查核实的结论，应在24小时之内报告市局监测预报科。

四、工作措施

（一）加强组织领导。要高度重视高考期间震情跟踪监视及应急准备工作，保持思想上的高度警觉和行动上的全面准备，进一步健全组织领导体系，认真履行《龙陵县2019年度震情跟踪工作方案》中各项工作职责。

（二）加强震情会商。要强化前兆资料的分析处理，认真做好周、月和加密（紧急）会商。并及时将会商意见上报县委县政府及市局监测预报科。

（三）加强震情值班和监测仪器的管理维护工作。要落实好24小时震情值带班制度，高考期间特殊时段内，地震局工作人员不得私自离开所在城区，保证能在二十分钟内赶到各自工作岗位；要加强对各类地震监测仪器设备的管理和维护，确保监测仪器工作正常，数据连续可靠，信息传输畅通。

（四）加强异常核实上报。要加强与乡镇地震宏观联络员的联系，对重点宏观点要主动落实有无异常，对辖区发现的宏微观异常应按照异常处置要求及时组织进行现场核实和上报。

（五）加强配合保障。要与相关部门加强联系，配合相关部门做好高考期间地震应急预案的修改完善和各项应急准备工作。高考期间若发生有感地震，要及时向县委县政府报告震情，通报相关部门，并按相关应急预案处置。
