# 龙陵县关于“少数民族特色村寨”申报国家命名的通知

各相关乡镇：

根据国家省市民委（民宗）“少数民族特色村镇”申报国家命名工作的通知。请各相关乡（镇）按照“指导意见”，结合辖区实际认真贯彻落实，遵循时间节点，以少数民族自然村为载体申报国家命名：电子版一村（镇）一套、纸质材料一村（镇）两套，满足资料齐全、内容完整的申报材料。通知“龙陵政务交换平台”，业务对接“龙陵民族项目工作群（群号：186935331）”。

一、规范管理工作涉及龙新乡黄草坝小米地、勐冒村陆家寨，勐糯镇大寨村大寨认真对照《国家民委关于进一步加强和规范新时期少数民族特色村镇保护与发展工作的指导意见》（民委发〔2018〕135号以下简称《指导意见》，见附件5）开展规范管理工作，进行认真对照检查，对村寨的发展现状进行认真分析，对不符合《指导意见》要求的及时进行规范整改，并于7 月6 日前将规范管理工作开展情况、存在的问题、整改方案及是否保留挂牌等相关情况报县民宗局。

二、认真做好申报推荐“中国少数民族特色村镇”国家命名的申报材料的工作拟申报的国家命名的“中国少数民族特色村镇（寨）”，按照国家民委及省市相关要求，认真准备国家命名的申报材料，做好少数民族特色村镇的推荐工作。申报材料于8月10日前，报县民宗局。

龙陵县民族宗教事务局

2019年5月28日
