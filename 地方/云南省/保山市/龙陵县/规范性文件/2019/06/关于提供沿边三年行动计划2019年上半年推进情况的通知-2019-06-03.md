# 关于提供沿边三年行动计划2019年上半年推进情况的通知

各成员单位：

按照《云南省深入实施兴边富民工程改善沿边群众生产生活条件三年行动计划领导小组办公室关于提供沿边三年行动计划2019 年上半年推进情况的函》通知要求，根据《龙陵县深入实施兴边富民工程改善沿边群众生产生活条件三年行动计划（2018—2020 年）》（以下简称沿边三年行动计划）督查考核的相关要求，请做好以下工作：

一、完成相关统计报表。统计范围为木城乡，请按照统计范围内上半年实际落实的资金和项目情况进行填报，共需填报3 张表格，表1《第二轮沿边三年行动计划部门资金投入情况统计表》；表2《第二轮沿边三年行动计划项目资金投入情况统计表》；表3《第二轮沿边三年行动计划县级单位项目落实情况表》；请按表中的计量单位要求填写，为统计需要，请一季度、二季度分别进行填写。（一季度上报情况请在请在沿边三年微信群上查看）

二、提供第二季度工作推进情况。按照沿边三年行动计划工作任务要求，对2019 年第二季度工作情况进行总结，主要包括工作推进情况、资金项目安排情况、目标任务完成情况、主要做法、存在困难和问题、下一步工作打算。请各成员单位高度重视，及时安排部署，安排专人开展统计并进行工作总，主要领导审核盖章后，于6月20日前将工作推进情况和统计表格（纸质版和电子版）反馈至县沿边三年行动计划领导小组办公室（县民宗局）。联系电话：0875-6121109。

龙陵县民族宗教事务局
