# 勐糯镇人民政府关于印发勐糯镇2019年肉牛产业发展方案的通知

为实现勐糯镇肉牛产业发展目标，根据《龙陵县肉牛产业发展指挥部关于落实县级肉牛产业发展工作推进会议精神加快肉牛产业发展工作进度的通知》（龙牛指发〔2019〕3号）精神，结合本镇实际，特制定本方案。

一、目标任务

2019年，勐糯镇计划新建存栏肉牛标准化育肥场20个。其中：存栏肉牛50头标准化育肥场5个，存栏肉牛30头标准化育肥场5个，存栏肉牛20头标准化育肥场10个；扶持发展200户建档立卡贫困户，每户养殖能繁母牛2头以上，扶持新增能繁母牛400头；购买能繁母牛商业保险2018至2019年累计完成1555头；完成基础母牛建档1555头；新建肉牛养殖示范村1个；巩固提升勐糯镇动物防疫社会化服务合作社1个；巩固提升冻改点1个；实施粮改饲项目6000吨；开展肉牛养殖技术培训700人次。

二、政策扶持

（一）肉牛养殖扶持政策

1.存栏肉牛50头标准化育肥场财政资金每个补助10万元；存栏30头标准化育肥场财政资金每个补助6万元；存栏20头标准化育肥场财政资金每个补助4万元。

2.出栏肉牛奖励政策。为调动广大农户养殖积极性，规范合作社运作，增加村级集体经济收入，对通过肉牛养殖专业合作联合社交售给东方皓月公司的育肥牛每头给予100元奖励，分配方式：养殖户70元，合作联合社30元（其中：合作联合社5元，分社25元）。架子牛每头给予合作联合社20元奖励。

（二）能繁母牛养殖扶持政策。新增良种能繁母牛445头。新增能繁母牛必须由勐糯合作联合社按照采购程序到县外购买的西门塔尔、安格斯和云岭牛及其杂交后代品种，符合县肉牛产业指挥部确定的能繁母牛标准和《种牛引种审批程序》，养殖户加入合作联社，接受合作联合社的统一管理和服务，才能享受能繁母牛补助、能繁母牛保险和新增犊牛奖励政策。

1.一般养殖户良种母牛补助政策。加入肉牛养殖专业合作联合社的一般养殖户，每户养殖2头以上良种能繁母牛，每头给予1000元补助。

2.贫困户养殖良种能繁母牛政策。加入肉牛养殖专业合作联合社的贫困养殖户，每户养殖2头以上良种能繁母牛，每头给予补助3000元，超过2头的，超过部分按照一般养户的补助标准补助。

（三）能繁母牛扩群增量行动新增犊牛奖励政策。全镇存栏2头以上能繁母牛、并加入合作联合社的养殖户，在2018年6月1日-2019年12月31日期间，每产1头犊牛给予奖励资金1000元。其中养殖户800元，合作联社200元（其中：合作联社50元，分社150元）。

（四）投保扶持政策。对全镇存栏能繁母牛购买能繁母牛保险。建档立卡贫困户参保率达100%，其他农户按自愿的原则应保尽保。每头牛的保费按6000元的2.7%计算，每头162元，其中：财政资金补助100元，占保费的61.73%，农户自筹62元，占保费的38.27%。

（五）信贷扶持政策

1.落实扶贫贴息贷款和贷免扶补贴息贷款，扶持勐糯肉牛产业发展。

2.协调勐糯农行和勐糯信用社给予养殖户贷款扶持。

（六）粮改饲政策补助。2019年动员搬迁户积极流转土地种植全株玉米，统一销售给龙陵飞扬农业开发有限公司进行收贮，收购价格460元/吨，所流转土地种植玉米政府每亩补助200元。

三、项目实施要求

（一）巩固提升合作联合社。所有项目发展对象必须加入勐糯合作联合社，由合作联合社统一运作及组织销售，方可享受政策扶持。

（二）建设要求。标准化规模养殖场必须由县级畜牧主管部门登记备案，具有较高的饲养管理技术，完善的管理措施。建设相关设施配套建设指标要求：牛舍按每头牛6平方米计算，青贮池按每头牛2.5立方米计算，储草棚按每头牛0.4平方米或每户20平方米计算，粪污处理池1000头以上的按每头牛0.03立方米、存栏500头以下的按每头0.06立方米或每户10立方米计算，无害化处理池按0.03立方米计算或每户5立方米计算，堆粪场按每头牛0.1平方米或每户20平方米计算。同时配套建设消毒池、消毒室、上牛台、保定架、隔离间、供水、供电、道路围墙及铡草机、饲料混合机等其它设施设备，做到雨污分流、净道污道分开。每个肉牛标准化规模育肥场按要求完成规划建设任务、养殖肉牛存栏达到设计规模的60%以上，并通过县级考核验收方可兑现补助资金。

（三）时间要求

1.第一阶段：2019年4月30日前完成方案编制。

2.第二阶段：2019年5月20日前确定标准化规模养殖场、能繁母牛养殖户、贫困养户、一般养户等扶持发展对象。

3.第三阶段：2019年6月30日前完成养殖场选址及规划。

4.第四阶段：2019年11月30日前完成建设内容、培训及基础种牛群组建。

5.第五阶段：2019年12月份迎接县级验收组验收。

（四）示范村建设要求。勐糯镇建设丛岗村或沟心寨村肉牛养殖示范村1个。示范村建设要求：建设1个以上标准化育肥示范场（户），养殖能繁母牛2头以上的一般户占本村一般户的三分之一，村内建档立卡贫困户养殖良种能繁母牛全覆盖，按“公司+合作社+养殖场（户）+建档立卡贫困户”的模式运作，实现村级集体经济年收入5万元以上、村内建档立卡贫困户稳定脱贫的目标。

四、工作要求

（一）强化领导，明确职责。各村社区及相关单位要切实提高思想认识，进一步调整充实领导小组，明确主要领导是第一责任人，对责任事项负总责，细化、量化工作目标、责任分工，层层抓好落实。协助单位要主动配合，积极参与，共同推进工作落实。

（二）精心组织，细化方案。各村社区及有关单位要对照分解的主要目标任务，细化责任目标，制订工作方案，明确工作计划，确定工作进度和保障措施，随时掌握进展情况，及时解决问题。

（三）明确时限，及时完成。各村社区及有关单位要于2019年4月30日前完成实施方案的编制；5月20日前确定标准化规模养殖场、能繁母牛繁育场（户）、贫困养户、一般养户等扶持发展对象；11月底前完成建设内容和培训、完成基础种牛群组建；12月份县级组织验收。各村社区及有关单位从4月份开始，每月20日将工作进度及有关材料上报镇肉牛产业办公室，由肉牛产业办汇总上报县肉牛产业指挥部办公室。

（四）坚持标准，严把质量。各村社区及有关单位和勐糯镇畜牧兽医工作站技术人员在工作开展过程中一定要做好宣传引导和指导，严格标准和质量。建设规模、建设内容、建设标准、存栏数量等在考核验收时必须完成或超额完成方予兑现补助，完不成其中一项内容的当年不予兑现补助，超额完成的不增加补助。

（五）强化督查，狠抓落实。将肉牛产业发展的目标任务完成情况及工作推进情况纳入镇级年度经济社会指标进行考核。勐糯镇肉牛产业办公室要紧盯关键环节，定期、不定期对重点工作实施情况进行督促检查，随时掌握进度，及时协调解决工作中出现的问题和困难，定期通报工作开展情况，对工作不力、推诿扯皮、进度缓慢、虚报套取的责任单位和个人，将严肃追究相关责任。
