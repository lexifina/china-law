# 龙陵县住房和城乡建设局关于印发2019年“安全生产月”活动方案的通知

驻龙各建筑施工、监理、房地产开发企业：

今年6月是全国第18个“安全生产月”，为贯彻落实《龙陵县人民政府安全生产委员会办公室关于开展2019年“安全生产月”活动的通知》（龙安办发〔2019〕21号）精神，龙陵县住房和城乡建设局将以“防风险、除隐患、遏事故”为主题，开展“安全生产月”活动。现就有关事项通知如下：

一、总体思路

习近平新时代中国特色社会主义思想为指导，深入宣传贯彻党的十九大和十九届二中、三中全会精神，深入学习宣传习近平总书记关于安全生产的重要论述精神，贯彻落实国家和省、市关于安全生产的重大决策部署，以防范化解重大风险、及时消除安全隐患、有效遏制生产安全事故为目标，增强全民安全生产意识，提升公众安全素质，推动基层和企业严格安全管理，为新中国成立70周年营造良好的安全生产环境。

二、“安全生产月”活动主要内容

我局“安全生产月”活动与全国同步于6月1日至30日在全县范围内统一开展，各相关企业要采取多种形式开展“安全生产月”活动。

（一）组织开展“安全生产月”启动活动。各相关企业要进行“安全生产月”活动动员，拉开“安全生产月”活动序幕；采取悬挂横幅、张贴标语等发布“安全生产月”活动信息。

（二）组织开展“6·16”安全生产宣传咨询日活动。一是开展安全生产相关知识宣讲。我局将面向社会公众和从业人员集中宣传安全生产方针、政策、法律法规以及安全知识和自救互救方法等，回答群众关心的安全生产问题，继续开展安全生产大讲堂活动，普及安全生产常识。二是积配合和参与媒体宣传咨询与互动宣传，进一步推动全社会关心、支持、参与安全生产工作。三是为切实引导和推动全县建筑施工企业广泛深入开展“安全生产月”活动，确保安全生产月活动开好局，龙陵县住建局将积极参与龙陵县安委办举行的“安全宣传咨询日”活动。努力营造良好的社会舆论氛围，不断提高社会公众的知晓度和参与度。

（三）开展主题宣讲活动。各相关企业要组织开展“安全生产大讲堂”，企业主要负责人要面向全体职工讲一堂“安全生产公开课”，大力宣传党中央、国务院关于安全生产的决策部署、安全生产法律法规、规章制度和知识技能，深入一线班组面对面交流安全生产心得体会。邀请专家学者开展专题讲座和安全诊断，精准指导企业管控风险、排除隐患，不断提高企业本质安全水平。

（四）积极参与安全发展论坛。县住建局及各相关企业要积极参与县安委会组织的各类安全发展论坛及交流活动，讨论、交流安全管理、安全风险管控和隐患排查治理的经验做法，探讨提升安全管理水平的思路举措，汇智聚力助推安全发展。

（五）开展先进典型宣传。各相关企业要树立和宣传好本企业内先进个人典型，重点宣传先进个人爱岗敬业、担当作为、乐于奉献的典型事迹和取得的优异成绩，做到事迹感人，学有榜样，充分发挥好先进典型的集体效应和辐射作用。

（六）开展安全警示教育和科普宣传活动。各相关企业要开展安全生产标准规范宣传普及和知识技能竞赛活动，督促标准规范制度上墙上网，推动企业职工熟悉标准、掌握技能、维护权益。广泛开展体验式安全教育活动，不断提高全体员工的应急意识和安全素养。

（七）开展应急预案演练活动。各相关企业要根据行业领域潜在的各类风险隐患，进一步修订完善应急预案。认真排查梳理自身重大安全风险，广泛开展现场处置方案和重点岗位应急处置演练活动，特别是车间班组一线员工操作式、实战化的初期应急处置演练，强化标准规范意识，提高应急处置能力。

（八）开展监管执法专项行动。县住房和城乡建设局将实时组织开展监管执法行动，督促落实企业主体责任。通过监督检查，倒查企业主要负责人履职尽责、安全投入、安全管理等方面的合法性，对违法违规行为严查重处，在全社会形成执法威慑，激发企业内生动力，倒逼企业落实主体责任，强化安全基础管理，提升本质安全水平。

三、有关要求

（一）加强领导，明确责任。为认真、高效开展“安全生产月”活动，切实加强领导，健全工作机制，确保工作保障到位、责任落实到人。龙陵县住建局结合各自实际认真研究制定龙陵县住房和城乡建设局2019年“安全生产月”活动方案，按照方案组织开展形式多样、内容丰富、具有行业特色、的宣教活动，确保“安全生产月”活动更加贴近基层、贴近企业一线、贴近职工群众，做到上下联动、氛围浓厚、成效显著。

（二）加强宣传，务求实效。充分发挥新闻媒体作用，紧紧围绕活动主题和重点内容，抓住正反两方面典型，予以宣传和公开曝光，推动各企业切实履行责任。进一步增强活动期间宣传报道的针对性和实效性，不断扩大“安全生产月”活动的覆盖面和影响力。

（三）加强督导，做好总结。各有关企业要认真策划活动方案，及时报送相关信息。

龙陵县住房和城乡建设局

2019年6月6日
