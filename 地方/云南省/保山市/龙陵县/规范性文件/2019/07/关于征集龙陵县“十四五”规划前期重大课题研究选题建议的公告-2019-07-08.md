# 关于征集龙陵县“十四五”规划前期重大课题研究选题建议的公告

国民经济和社会发展第十四个五年规划（以下简称“十四五”规划）是在习近平新时代中国特色社会主义思想指引下，开启全面建成社会主义现代化强国建设新征程的第一个五年规划。科学编制和实施“十四五”规划，对抢抓发展机遇、适应形势新变化、应对发展新挑战，实现龙陵高质量跨越发展具有重大意义。做好“十四五”前期重大课题研究，是编制实施好“十四五”规划的基础。为进一步提高规划质量，提升规划编制的透明度和社会参与度，广泛凝聚全社会智慧和共识，龙陵县发展和改革局现面向社会各界公开征集龙陵县“十四五”规划前期重大课题选题建议，并将有关事项公告如下：

一、选题要求

课题选题要以习近平新时代中国特色社会主义思想为指导，立足新形势、新理念、新要求，贯彻落实党的十九大精神，习近平总书记视察云南重要指示精神，市委、市政府的各项工作部署，重点围绕“十四五”时期关系龙陵经济社会发展的前瞻性、全局性、战略性问题提出课题选题建议，重点包括但不限于经济（产业）发展、城乡融合、新型城镇化、乡村振兴、基础设施、资源环境、深化改革、开放创新、社会保障、教育医疗、公共安全等事关全县经济发展和人民关注的重点热点问题，提出具有科学性、可操作性的“十四五”规划前期重大课题选题建议。

二、提交方式

参与征集的部门和个人请按要求填写《龙陵县“十四五”规划前期重大课题研究选题建议表》（详见附件），并于2019年7月20日前通过电子邮件、传真或邮寄方式发至龙陵县发展和改革局国民经济综合股。

三、课题评定

龙陵县发展和改革局将对选题建议进行研究，择优确定选题建议并开展下一步工作。
