# 龙陵县林业和草原局关于印发《龙陵县林业和草原局2019年脱贫攻坚工作实施方案》的通知

各股室、各二级单位：

经龙陵县林业和草原局领导班子同意，现将《龙陵县林业和草原局2019 年脱贫攻坚工作实施方案》印发给你们，请认真抓好贯彻执行。

龙陵县林业和草原局

2019年7月1日

（此件公开发布）

龙陵县林业和草原局2019年脱贫攻坚工作实施方案

为全面抓好脱贫攻坚工作，着力解决“两不愁三保障”突出问题，围绕脱贫攻坚“夏季攻势”，以“短板清零”“任务清仓”为目标，扎实做好全县2019年脱贫攻坚工作，确保2020年如期全面高质量完成脱贫攻坚任务，根据《龙陵县打赢脱贫攻坚战三年行动实施方案》，制定本实施方案。

一、总体要求

坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻习近平总书记关于扶贫工作的重要论述和党中央脱贫攻坚方针政策，进一步树牢“四个意识”、坚定“四个自信”，坚决做到“两个维护”，坚持精准扶贫精准脱贫基本方略，坚持脱贫标准，坚持问题导向，结合各级巡视巡察、督查检查、考核评估发现问题抓好整改，着力补齐脱贫短板，着力开展脱贫人口“回头看”，着力夯实贫困人口稳定脱贫基础，着力构建稳定脱贫长效机制，着力加强扶贫领域腐败和作风问题治理，确保2019年脱贫目标全面实现，为实施乡村振兴战略打好基础。

二、目标任务

以巩固提升脱贫质量和全面完成2019年脱贫攻坚任务为目标，对照脱贫退出标准，着力解决当前脱贫攻坚工作中存在的特别是“两不愁三保障”方面的突出问题，实现“短板清零”、“任务清仓”，继续巩固好脱贫成果，加大林业产业扶贫、生态扶贫及相关涉林扶贫力度，全面抓好各级巡视、巡察、考核、督查发现问题的整改落实，全力补齐脱贫攻坚短板，做好各项脱贫巩固工作，推进脱贫攻坚与乡村振兴的有效衔接。

三、工作重点

（一）从严从实抓好各级脱贫攻坚专项巡视发现问题的整改工作。提高政治站位，切实把整改作为打赢脱贫攻坚战的重要保障，紧盯问题抓整改，确保发现问题全面彻底整改到位，纠正全县各级干部思想上、工作上的偏差，确保党中央关于脱贫攻坚方针政策和决策部署不折不扣的贯彻落实到位，坚决杜绝脱贫攻坚工作中的形式主义、官僚主义，坚决防止“虚假式”脱贫、“算账式”脱贫、“游走式”脱贫、“指标式”脱贫现象。

（二）实施林业产业扶贫巩固提升工程，抓实林业产业扶贫，全面巩固提升脱贫质量。围绕所有建档立卡贫困户人口人均纯收入达到4000元、收入略高于贫困线的农户收入持续稳定增长的目标，进一步优化扶贫产业项目，完善重点产业扶持政策，将符合条件发展林业产业扶贫的贫困户林业产业帮扶项目全覆盖，新型林业经营主体高覆盖，切实提升核桃、草果、澳洲坚果、糯橄榄等传统林业产业，2019年巩固提升51.3万亩核桃、4.58万亩澳洲坚果、2.54万亩糯橄榄、草果5.4万亩，确保核桃、草果、澳洲坚果、糯橄榄产量稳中有升，力促建档立卡贫困种植户从中受益，扩大建档立卡贫困户以林业产业增收致富的路径，大力发展石斛、胡蜂等特色林业产业，提质优化农民专业合作社等林业新型经营主体，深入推进沪滇扶贫协作项目，2019年新增石斛种植面积90万平方米，种植总面积达900万平方米，预计石斛产量3800吨，产值5.1亿元，带动石斛从业农户达12000多户，巩固现有石斛企业及石斛专业合作社，加大沪滇扶贫协作10个石斛枫斗加工厂建设项目，有序引导建档立卡贫困户从事石斛种植、枫斗加工及销售；以蜂种繁育、胡蜂产业骨干技术培训、养殖管理技术培训等方式为主继续巩固推进现有胡蜂产业发展。

（三）全面加强森林生态效益补偿工作，完成2019年纳入森林生态效益补偿面积37.98万亩及资金兑付工作；完成2019年停止天然林商业性采伐面积173.9963万亩及资金兑付工作；完成省、市下达我县退耕还林还草任务3.5万亩；完成聘用公益林、天然林护林员456人，聘用建档立卡贫困人口生态护林员674人，并按规定兑付公益林、天然林护林员及生态护林员管护劳务费用。

（四）深化涉林扶贫工作

深化扶贫保障服务工作，强化林地助力扶贫工作，完成公益性项目使用林地的报批工作，助力推进交通基础设施建设、推进水利基础设施建设、饮水保障提升建设等贫困地区基础设施建设；深化“挂包帮、转走访”工作，结合“自强、诚信、感恩”教育作好贫困户群众工作，协助挂包村实施易地扶贫搬迁、农村危房改造、农村人居环境整治等工作，以支部结对帮扶创建为契机，坚持挂包村党建扶贫双推进；深化林业科技扶贫工作，组织实施开展林业科技培训助力脱贫攻坚工作，大力开展林业产业技术培训。

四、保障措施

（一）压实脱贫攻坚责任。按期开展脱贫攻坚专题研究，完成遍访贫困村和贫困户工作。全面落实“县级领导挂乡包村、乡科级领导干部分片包组、县乡干部职工包贫困户和联系非贫困户”责任制，形成上下统一、高效协调、步调一致、责任明确的指挥协调和责任落实体系。各股室、各二级单位要认真落实脱贫攻坚“一把手”责任制，完成好脱贫攻坚工作任务。

（二）加强扶贫资金投入和管理。积极向上争取财政专项扶贫资金，资金要围绕林业扶贫项目库规划精准使用，严格规范扶贫资金管理，按照管理规定、规范程序和项目进度及时拨付扶贫资金，加强扶贫项目资金绩效管理，推动扶贫资金项目公告公示制度在乡村两级落实落地，堵住扶贫资金监管漏洞，确保扶贫资金使用规范、监管安全。

（三）加强社会帮扶工作。做好沪滇扶贫协作项目工作，实施好沪滇协作项目石斛枫斗加工厂项目，积极引导贫困群众脱贫致富，积极对接吸引林业企业支持全县脱贫攻坚。聚集社会各方面资源助推脱贫攻坚。

（四）坚持党建扶贫“双推进”。做好支部结对帮扶工作，以挂包贫困村为重点，不断提高挂包基层党组织的组织力，深入开展“自强、诚信、感恩”教育活动，促进群众工作提档升级，激发群众内生动力，加强农村精神文明建设，教育引导贫困群众弘扬传统美德、树立文明新风、培育文明乡风。深入推进文化扶贫，提升贫困群众的公共文化服务获得感。

（六）加强驻村扶贫工作队员的选派管理。严格做好驻村工作队员选派工作，确保工作队员选派“尽锐出战”，加强驻村扶贫工作队员的工作指导和日常管理，落实好“总队长（副总队长）—第一书记（工作队长）—工作队员”的内部管理机制，确保驻村工作队员如期发挥应有作用。

（七）从严从实开展督导。按照中央和省、市改进督查检查工作的有关要求，整合督查力量，转变督查方式，围绕干部工作作风、工作状态和责任落实情况开展调研督导，确保全县脱贫攻坚政策落实、责任落实、工作落实和整改落实，脱贫过程和脱贫成效经得起检验。
