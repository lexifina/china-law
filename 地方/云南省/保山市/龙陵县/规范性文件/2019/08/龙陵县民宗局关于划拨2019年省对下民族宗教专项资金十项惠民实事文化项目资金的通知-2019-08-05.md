# 龙陵县民宗局关于划拨2019年省对下民族宗教专项资金十项惠民实事文化项目资金的通知

勐糯镇人民政府：

根据《保山市人民政府办公室关于认真完成2019年10件惠民实事目标任务的通知》（保政办发〔2019〕11号） 精神，为切实抓好2019年10件惠民实事的落实，高质高效 完成我县少数民族传统文化保护传承工程建设项目，现将7万元文化项目资金划拨给各单位，（至此，《保山市财政局关 于下达2019年度第一批省级统筹整合涉农资金的通知（保财农﹝2018﹞16 号）》文件中下达的龙陵县2019年文化项目资金7万元已调补划拨完成）。现就相关工作要求通知如下：

一、目标任务

实施少数民族传统文化抢救保护项目1个，即：龙陵县勐糯镇傣族剪纸技艺培训项目。

二、工作要求

（一）资金管理。做到专款专用、专账核算、监控有效、 档案规范完整，确保资金使用管理的规范、安全和高效。

（二）项目实施（2019年8月3日—2019年1月20日）。按项目申报表（附件1）内容，结合实际有序推进项目建设，坚持将“惠民”作为根本方向，以加强各民族交往交流交融、铸牢中华民族共同体意识为出发点，以繁荣发展民 族文化、建设各民族共有精神家园为落脚点，以文化扶贫、 文旅融合、乡村振兴等方针战略为结合点，切实提升工程惠 民的质量和范围，切实加快项目实施、资金执行等各项工作，对项目制定科学规范、切实可行的绩效目标和实施计划，确保所有项目在2019年11月2日前完成。

（三）检查验收。项目实施单位要建立健全工程项目实施台账，配合做好省、市民族宗教部门实地抽查等相关检查工作。县民宗局将于11月30日前对项目进行竣工验收，项目乡镇于11月20日前完成所有项目的竣工验收。

（四）进度报送。根据市级要求，项目实施进展情况实行月报制度，请勐糯镇人民政府自8月起，于每月15日之前，逐月报送项目进展情况（附件2）报县民宗局。

龙陵县民族宗教事务局

2019年8月3日
