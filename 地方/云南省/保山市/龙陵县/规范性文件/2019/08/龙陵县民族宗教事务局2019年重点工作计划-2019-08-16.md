# 龙陵县民族宗教事务局2019年重点工作计划

根据《龙陵县人民政府办公室关于印发2019年政府工作报告重点任务分解方案的通知》（龙政办发〔2019〕15号）文件要求，结合民宗局实际，制定以下重点工作计划。

2019年，我局将以习近平新时代中国特色社会主义思想和党的十九大精神为指导，严格按照县委县政府及省、市民宗部门的整体工作部署，认真贯彻落实各项会议精神，以民族宗教团结稳定和全县经济社会发展为工作重点，强化措施，加大力度，积极开展好民族宗教工作，为全县全面建成小康社会作出更大的贡献。

一、强化引导，加大宣传培训力度

（一）以“民族团结宣传月”和“宗教政策法规宣传月”为载体。建立起长期有效的民族宗教政策法规宣传机制，大力宣传民族宗教政策和国家相关法规，大力开展教育培训工作，不断提高宗教人士的政策法治观念。重点开展《宗教事务条例》等政策法规宣传，重点对基层干部、宗教活动场所负责人进行培训，切实做到党的民族宗教政策法规深入人心， 家喻户晓。2019年组织培训1期民族宗教界人士及民族宗教干部《宗教事务条例》培训。

（二）努力营造全社会共同重视民族宗教工作的思想氛围。进一步健全完善联系民族宗教人士制度，加大与民族宗教界上层人士的沟通联系，积极发挥其作用；通过各种形式，加大对民族宗教政策法规的宣传力度，使各级党员干部群众 充分认识“民族宗教无小事”的重要性，站在讲政治的高度 来重视民宗工作，做好民宗工作。

（三）进一步提升创建活动。2019年继续深入开展示范 区创建“六进”（进机关、进学校、进村、进社区、进企业、 进宗教活动场所）活动及实施好民族团结进步提升改造示范 村建设，助推脱贫攻坚。

二、强化措施，扎实做好宗教管理工作

（一）深入开展以学习为主题的“宗教和谐寺观教堂”创建活动。以和谐寺观教堂创建活动为契机，加强宗教教职人员的管理，抓好教职人员教育培训工作，营造研习教义、遵守教规、注重修行、提高素质的良好宗教活动环境，自觉抵制一切不良风气的侵袭，树立宗教界良好形象。

（二）强化对宗教活动的依法管理。严格执行宗教法规政策，依法依规进行宗教活动场所合法审批、举办大型宗教活动和开办经学班提前审批、宗教教职人员备案登记和宗教教职人员外出报备制度，确保宗教活动场所依法依规开展活动。

（三）定期对宗教违法现象清理整顿。加大宗教综合执法力度，不断规范宗教活动。与统战、公安、610办等部门形成长效联合检查机制，对各宗教活动场所形成常态管理，定期互通信息，及时发现和制止非法宗教活动行为，严厉打击邪教组织，净化宗教环境，切实维护宗教界的合法权益，确保宗教界的稳定。

（四）建立健全多部门联防境外渗透机制。建立健全由统战部、民宗局、国家安全等多部门联动的抵御渗透工作机制，对宗教领域各种渗透进行快速响应和依法处置，认真贯彻落实好《龙陵县反教邪强基防渗固边工程实施细则》，以“墙基工程、墙网工程和墙堡工程三个全覆盖”为依托，监牢边境“一面墙”，以“基层工作常态化、社会防控工作网格化、邪教人员管控工作智能化和警示教育工作立体化”四化建设为抓手，织密境内防渗透一张网，抓实抵御渗透工作。

三、强化政策落实，促进少数民族地区稳定发展

（一）健全和完善民族事务纠纷调解机制。定期开展民族之间的各种联谊活动，增进民族感情，积极引导四个世居民族过好传统民族节日，不断促进全县民族团结和谐稳定。

（二）扎实抓好示范区项目建设。进一步健全完善《少数民族项目帮扶项目库》，积极争取上级项目资金支持，加大对少数民族地区基础设施投入，推动少数民族经济更好更快发展。2019年计划争取10个示范村项目建设，每个项目争取上级补助100万元。进一步加大示范区项目建设的指导和督查力度，确保示范项目建设按期建设竣工。

（三）加强沟通协调，认真抓好沿边三年行动计划(第二轮)规划及实施工作。组织协调沿边乡镇及相关部门规划编制《第二轮兴边富民工程改善沿边群众生产生活条件三年行动方案》，并启动实施。

（四）加强调研，全面了解民族地区经济社会发展情况。 深入开展少数民族贫困地区，少数民族聚居区调研工作，加快少数民族地区经济社会发展步伐。通过调研提供给上级党委政府决策依据，帮助解决少数民族生产生活中的困难和问 题。

（五）扎实做好民族地区矛盾纠纷调处工作。按照“属地管理、分级负责”和“谁主管、谁负责”的原则，集中时间、集中力量，对本辖区民族宗教领域当前存在的突出矛盾和问题隐患，开展地毯式排查，通过排查分析，有针对性地提出具体意见和办法，做到早发现问题、早解决问题、早化解矛盾，将可能引发的矛盾和问题消除在萌芽状态，有效维护民族宗教领域团结和谐稳定。
