# 关于切实做好2019年度中央少数民族发展资金项目竣工验收工作的通知

各乡（镇）人民政府：

为确实做好民族专项资金项目建设，促进民族地区经济社会发展步伐，增进民族团结、社会和谐稳定,充分发挥少数民族发展资金在脱贫攻坚战中的积极作用，根据省、市相关要求，现将2019 年度少数民族发展资金项目竣工验收有关工作通知如下，请各项目乡镇按要求抓好落实。

一、加快项目建设

请项目乡镇加快项目建设进度，所有项目在11 月30 日前竣工，并完成项目乡级初验工作。

二、做好项目系统管理。

按项目进度完善脱贫攻坚系统项目录入和动态管理工作（按脱贫攻坚领导小组办公室统一要求执行）。

三、按时报送项目材料

请各项目乡镇于2019年11月30日前，将项目验收竣工材料（包括项目申、事业计划文件、报招投标、项目建设、竣工总结、验收材料、资金使用、项目审计等）装订成册上报民宗局。

龙陵县民族宗教事务局

2019年11月7日
