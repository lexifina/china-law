# 关于印发《龙山镇2019年农村户厕新建、改造工作实施方案》的通知

镇直各相关单位、各村（社区）：

根据《云南省人居环境整治工作领导小组办公室关于印发

＜云南省农村厕所改造建设验收办法（试行）＞的通知》《龙陵县2019年农村户厕新建、改造实施方案》，结合我镇工作实际，特制定《龙山镇2019年农村户厕新建、改造工作实施方案》，请镇直各单位、各村（社区）按照文件要求认真抓好贯彻落实。

龙山镇2019年农村户厕新建、改造工作

实施方案

一、指导思想

全面贯彻党的十九大精神，深入贯彻落实习近平总书记关于“坚持不懈推进厕所革命，努力补齐影响群众生活品质的短板”的重要指示精神，加快推进乡村振兴战略，切实解决农村无害化卫生户厕普及率低等问题，倡导健康文明生活方式，不断满足人民群众对美好生活的需求。

二、工作目标

采取县、乡、村、组、户五级联动，财政资金撬动、党员干部带动、群众投工投劳的方式，动员各方力量，强化各项措施，全力补齐农村户厕短板，从根本上提升农村户厕质量，解决农村无户厕问题，逐步消灭农村旱厕，2019 年完成农村户厕新建、改造2000座以上，到2020年全面消除辖区内非卫生厕所。

三、项目实施

（一）实施范围

按照“人畜分离、厨卫入户”的要求，加快建设农村无害化卫生户厕新建、改建，坚持农户自主、政府帮扶的原则，2019年重点对辖区内农业户籍无厕户和非卫生厕所户进行新建、改造。但以下三种类型户厕新建、改造不得享受各级补助政策:

1. 有家庭成员或户主的父母、配偶、子女为国家公职人员的；

2. 有家庭成员任“村两委”和“村监委”干部的；

3.已享受过易地扶贫搬迁政策扶持或计划纳入易地搬迁的。

（二）实施标准

农村户厕新建、改造的标准，按照2019年6月保山市农业农村局印发的《云南省农村厕所改造建设技术指南（试行）》执行。各村（社区）实施农村户厕新建、改造必须以自然村为单元进行项目建设。农村户厕新建、改造必须上有顶（可采用灰色彩钢瓦、树脂瓦、磁瓦、烧制土瓦），四周有围合（有墙），内有冲水箱、蹲便器，侧有门，下有三格一体式化粪池（可采用小砖支砌式化粪池、塑料装配式化粪池、玻璃钢装配式化粪池），建设或改造后达到无害化卫生户厕的要求。

（三）实施步骤

第一阶段（2019年10月底前），各村（社区）认真做好宣传发动，制定2019年户厕新建、改造年度计划；第二阶段（2019年11月底前），全面完成无厕户厕所建设，完成各村（社区）户厕新建、改造计划的70%；第三阶段（2019年12月底前）完成全镇2019年户厕新建、改建剩余的全部任务。

（四）项目申报

各村（社区）要认真完成辖区内农村户厕基础数据核实。并经村（社区）主要负责人签字后以自然村为单位进行申报，并形成农村户厕新建，改造申请报告，申报情况上报至龙山镇农业综合服务中心（联系人: 李红杏，联系电话[电话略]）。

（五）以奖代补标准

农村户厕新建、改造实行先建后补。在验收合格后给予每座补助1000元（其中省级补助400元、市级补助100元、县级财政整合边境地区转移支付等资金补助500元）；废弃沼气项目的户厕改造，经验收合格后，县级财政整合边境地区转移支付等资金给予每座补助300元。

（六）验收范围及验收方式

1.验收依据

按照《云南省人居环境整治工作领导小组办公室关于印发＜云南省农村厕所改造建设验收办法（试行）＞的通知》及《云南省农村厕所改造建设技术指南（试行）》要求进行验收。

2.验收范围

龙山镇辖区符合项目实施范围的2019年1月1日至2019年12月31日新建、改建的农村无害化卫生户厕。

3. 验收方式

（1）村级初验。按照新建、改建全覆盖验收并建档的要求进行初验（要注意收集农户建设前、建设中、建设完成后的图片资料。特别是地下工程部分，购买使用装配式三格化粪池的还需收集批次产品检验报告），并填写《云南省农村户厕验收评分表》。验收结束后，上报验收情况汇总表并在村委会及村民小组（自然村）进行公示。

（2）镇级验收。镇级验收的主要内容为农村户厕新建、改建完成数量、建设质量、台账档案管理、实地核查四个部分。待镇级验收结束后申请县级验收。验收完成后对验收合格的村（社区）农户兑付奖励，验收不合格的村（社区）需按要求进行整改，整改完成后再次验收，验收合格后兑付奖励。

四、有关要求

（一）强化领导，落实责任。镇级将成立党委书记、镇长为双组长，分管领导为副组长，相关部门负责人、各村（社区）党总支书记、监委会主任为成员的厕所革命领导小组。各村（社区）是项目实施的责任主体，要指定专人负责，认真做好宣传发动、组织实施等各项工作，研究制定本辖区农村户厕新建、改造工作计划，镇直各挂包部门要督促帮扶干部落实包保责任，做好挂钩户的思想动员、组织动员等工作，形成“纵到底、横到边、全覆盖、无缝隙”的责任体系，确保农村户厕新建、改造按时按质完工。

（二）广泛宣传，发挥群众主体作用。各村（社区）要通过召开党员会议、村民代表会议、户主会议，利用手机短信、宣传栏等方式广泛开展点对点、一对一的宣传动员工作。

（三）层层压实，严把项目质量关。各村（社区）要严格项目建设管理，做到规划计划到位，组织实施到位，杜绝出现半拉子项目工程。做好项目计划公开公示、补助资金公开透明到位，确保资金拨付使用安全。

（四）强化服务，形成合力。镇直各单位、各村（社区）要主动服务、积极配合，项目建设涉及的土地、排水、排污、防护等由领导小组负责协调。涉及到贫困户的，帮扶干部要全程参与，主动为挂包户出谋划策，做通帮扶对象思想工作。

（五）加强监督，强化纪律检查。镇纪委要实时进行跟踪督查，层层压实工作责任，对工作不力，引发集体矛盾纠纷、发生安全生产事故、出现施工质量问题，推诿扯皮，进度缓慢，达不到镇党委、政府目标要求的要严肃追究责任。特别是对在项目建设过程中出现以权谋私、损公肥私、贪污挪用项目资金的，要严查快查、通报曝光。

（此件公开）
