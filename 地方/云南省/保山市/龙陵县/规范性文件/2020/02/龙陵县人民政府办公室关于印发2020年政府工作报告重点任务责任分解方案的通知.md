# 龙陵县人民政府办公室关于印发2020年政府工作报告重点任务责任分解方案的通知

各乡、镇人民政府，县政府各工作部门，县直有关单位：

《2020年政府工作报告重点任务责任分解方案》已经县人民政府同意，现印发给你们，并就有关事项通知如下，请认真抓好贯彻落实。

一、提高站位，统一思想认识

2020年是全面建成小康社会和“十三五”规划收官之年，也是实现“第一个百年目标”的决胜之年。为全面有效推进政府各项工作落细落实，县人民政府确定了15项支撑性指标、73项重点工作，各乡镇、各部门要以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中三中四中全会、中央经济工作会议精神，深入落实习近平总书记对云南工作的重要指示批示精神，统筹推进“五位一体”总体布局，协调推进“四个全面”战略布局，紧扣各项支撑性指标、重点工作，提高认识，细化方案，压实责任，全力抓好工作落实，确保“十三五”规划圆满收官、全面建成小康社会，为“十四五”发展打下坚实基础。

二、明确责任，层层抓好落实

《2020年政府工作报告重点任务责任分解方案》明确了各项工作任务的主办单位、协办单位、责任领导和督办人，并实行县人民政府领导分管督办制和部门责任制，每项工作均由县人民政府领导分管，由县人民政府办公室对口负责人具体督办，主办单位的行政负责人为第一责任人。各主办单位、协办单位要按照通知要求认真履行职责，主办单位要率先负起责任，做好统筹协调，确保各项工作都有领导分管、有专人负责、有落实方案，按时按质完成工作任务；协办单位要主动落实承办的具体工作，密切配合，协同做好工作。任务分解中未提及的部门也要认真对照《2020年政府工作报告重点任务责任分解方案》中的任务和要求，明确目标任务，扎实做好各项工作，确保工作推进有力。

三、严格督查，强化跟踪问效

县人民政府对73项重点工作实行年度督查制和督查工作逐级负责制，并根据工作进展情况，适时组织督查组进行专项督查，及时发现和解决工作推进中存在的困难、问题；各乡镇、各部门要结合工作实际，对各自负责的工作任务开展有效的督促检查，对工作中的重大情况和问题，要及时向县人民政府分管领导汇报，同时要定期、不定期上报工作进展情况，确保全年各项目标任务圆满完成。对因认识不到位、工作措施不力等原因造成工作进展缓慢的，将给予通报批评，并限期整改；对不作为、乱作为的，将追究有关责任人的责任。

四、积极主动，按时反馈进展

各主办单位要围绕所负责的具体工作，按照“定目标、定责任、定时限、定标准、定措施”的原则，认真制定详细的工作落实方案，经单位主要领导审签、加盖公章后于3月31日前报县人民政府督查室，并分别于2020年7月10日和2021年1月8日前将上半年工作推进情况、全年工作完成情况上报县人民政府督查室（报送格式见附件3）。联系人及电话：王林，0875-6121943；电子邮箱：bslldcs@126.com。
