# 龙陵县审计局关于成立政府信息与政务公开领导小组的通知

各股（室）、中心：

根据《中华人民共和国政府信息公开条例》、龙陵县人民政府办公室关于印发《龙陵县2020 年政务公开工作要点》的通知》(龙政办发〔2020〕40 号)文件要求，我局始终把做好政府信息与政务公开工作列入单位工作议事日程，进一步规范政府信息公开内容，对政府信息与政务公开的范围、内容、形式、制度等作了进一步的明确。经研究决定，成立龙陵县审计局政府信息与政务公开工作领导小组如下：

组 长：杨太能 党组成员、局 长

副组长：段祖庆 党组书记、副局长

赧光荣 党组成员、副局长

段东宇 党组成员、副局长

成 员：各股（室）、中心负责人。

领导小组下设办公室在局办公室，由段东宇副局长任办公室主任，张敏生任办公室副主任，负责处理日常事务，设联络员1名。具体承担推进、指导、协调、监督信息公开工作；办理信息公开相关工作；负责编制信息公开指南、信息公开目录、定期公开和更新信息、依时公布全局信息公开工作年度报告等信息公开相关的日常工作。

龙陵县审计局

2020年2月27日
