# 龙陵县搬迁安置办公室关于龙江乡新寨村沙坝田沟渠和桥头田沟渠修复建设项目实施方案请示的批复

龙江乡人民政府：

你乡报来的《关于龙陵县龙江乡新寨村沙坝田沟渠和桥头田沟渠修复建设项目实施方案请示》（龙江政发〔2020〕8号）已收悉，经研究现批复如下：

一、实施项目名称：龙陵县龙龙江乡新寨村沙坝田沟渠和桥头田沟渠修复建设项目。

二、项目建设单位：龙陵县龙江乡人民政府

三、项目主管单位：龙陵县搬迁安置办公室

四、资金监管单位：龙陵县财政局

五、同意“请示”中的建设规模和内容，即: 新建取水坝2座，长15米，支砌72立方米；浇筑沟渠长1000米，支砌350立方米（沟段面0.4*0.4）；支砌挡墙3垛，长37米，支砌60.5立方米；土方开挖3687.6立方米。

六、资金来源及项目总投资：大中型水库后期扶持资38.5万元。

七、原则同意《龙陵县龙江乡新寨村沙坝田沟渠和桥头田沟渠修复建设项目实施方案请示》的工程实施计划，要求龙江乡按照批复意见，认真做好项目的组织实施，严格控制项目投资预算，确保建设资金足额到位，按质按量完成项目建设计划。

此复
