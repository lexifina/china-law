# 龙陵县发展和改革局关于龙陵县水利工程农业供水定价成本监审结果公开的公告

根据《龙陵县水务局关于制定水利工程农业供水价格的请示》（龙水发〔2020〕30号），按照《政府制定价格成本监审办法》（国家发展改革委令第8号）及《云南省物价局关于印发<政府制定价格成本信息公开管理办法>和<政府制定价格成本信息公开目录（第一批）>的通知》（云价成本〔2018〕99号）等有关规定，我局遵循公平、科学、规范、效率的原则，依法对岔河水库、小河水库、八0八水库2017年至2019年农业供水定价成本费用进行了监审，现将监审结果予以公开。

一、公开时间：2020年5月9日至2020年5月23日
