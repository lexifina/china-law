# 象达镇人民政府关于汛期交通出行及安全防范的通告

全镇广大父老乡亲们：

当前我镇已全面进入主汛期，受持续强降雨影响，山体含水趋于饱和，岩土松动加剧，滑坡、塌方等地质灾害风险持续走高。为切实保障全镇人民群众生命财产安全，现将汛期安全防范有关事项通告如下：

一、注意出行安全，警惕道路塌方

近期降雨导致我镇境内多处道路边坡土体松动，塌方、落石风险显著增高，新国道G219象达段及镇内乡村公路，道路两侧多为高边坡，雨季期间常发生坍塌。广大村民出行务必注意以下几点：

1. 暴雨大雨天气尽量少出行，确需出行的，务必提前确认路况，避开积水、落石、滑坡、塌方路段。

2. 驾车出行务必减速慢行，途经临崖、高边坡路段时仔细观察上方山体情况，确认安全后再快速通过，切勿在危险路段逗留。

3. 严禁强行通过塌方或安全隐患路段。如遇道路临时管制，务必坚决服从现场工作人员指挥，不得冲卡或冒险通行。

4. 行人避开涵洞、陡坡、临河临崖路段，路面出现漩涡、漂浮电线立即远离并报警求助。

5. 如发现道路塌方、路基损毁等险情，请第一时间联系所在村委会干部。

二、关注天气预警，增强防范意识

请广大父老乡亲通过手机、微信、村组广播、电视等正规渠道，密切关注天气预报和防汛预警信息。汛情预警由低到高依次分为蓝、黄、橙、红四色等级：蓝色预警时减少外出；黄色预警时非必要不外出，远离河道、水库、山箐、山洪隐患点；橙色预警时立即停止户外活动，危险区域人员做好转移准备；红色预警时严禁一切外出，坚决服从镇村统一调度紧急撤离。所有汛情、险情信息以官方发布为准，做到不造谣、不信谣、不传谣。

三、发现险情及时上报，共同守护家园安全

请广大父老乡亲以主人翁身份积极配合镇村开展防汛巡查、隐患排查工作。如发现山洪暴涨、山体垮塌、泥石流、道路损毁、房屋坍塌、人员被困等紧急险情，请第一时间拨打象达镇人民政府防汛值班电话：0875-6850002或联系所在村委会干部。

请全镇父老乡亲相互转告、邻里守望、共保平安！

象达镇人民政府
