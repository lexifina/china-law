# 玉溪市人民政府关于对玉溪市公安消防支队记功的决定

玉溪市人民政府关于

对玉溪市公安消防支队记功的决定

玉政发〔2018〕34号

各县区人民政府，市直各委、办、局，各人民团体和企事业单位，中央、省驻玉单位，驻玉军（警）部队：

2013年以来，玉溪市公安消防支队在市委市政府的坚强领导下，全市消防部队共处警6000余次，抢救、疏散和帮助人民群众1.2万余人，挽回经济损失1.1亿元；出动社会救助2436次，为群众生产生活送水1852车辆次，走访慰问困难群众74户，为贫困地区群众送温暖、献爱心活动120余次，累计捐款捐物达18万余元；共检查单位和场所10万余个，发现和消除火灾隐患17万处，对151家重大火灾隐患单位整改销案；圆满完成了南博会、聂耳音乐周及中国·东盟外长会、党的十九大、历届玉溪“哇家灯会”等重大活动消防安保任务，力保全市连续23年未发生重特大火灾事故，为守护全市人民群众平安和服务经济社会发展作出了重大贡献，在省内外树立了“玉溪消防卫士”的良好形象，得到了公安部、省公安厅和各级领导的充分肯定和认可。

为鼓励先进，弘扬正气，激励斗志，市人民政府决定对玉溪市公安消防支队记集体二等功1次。希望玉溪市公安消防支队珍惜荣誉、发扬成绩，在今后的工作中再接再厉、再立新功。继续保持和发扬为人民服务的宗旨意识，继续为全市公共消防安全和各类灾害事故的应急救援工作作出新的贡献。全市各级各部门和广大干部职工要以先进为榜样，锐意进取、开拓创新、扎实工作，不断取得新的成绩，为玉溪实现跨越发展和全面建成小康社会做出新的更大贡献。

玉溪市人民政府

2018年12月17日
