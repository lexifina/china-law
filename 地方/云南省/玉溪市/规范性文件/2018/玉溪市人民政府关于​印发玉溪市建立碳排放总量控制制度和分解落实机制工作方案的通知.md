# 玉溪市人民政府关于​印发玉溪市建立碳排放总量控制制度和分解落实机制工作方案的通知

玉溪市人民政府关于印发玉溪市建立碳排放总量控制

制度和分解落实机制工作方案的通知

各县区人民政府，市直各委、办、局：

现将《玉溪市建立碳排放总量控制制度和分解落实机制工作方案》印发你们，请认真贯彻执行。

玉溪市人民政府

2017年12月14日

玉溪市建立碳排放总量控制制度和

分解落实机制工作方案

根据《国家发改委关于逐步建立全国碳排放总量控制制度和分解落实机制的通知》（发改气候〔2014〕3011 号）和《云南省人民政府关于印发云南省建立碳排放总量控制制度和分解落实机制工作方案及云南省落实全国碳排放权交易市场建设实施方案的通知》（云政发〔2016〕95号）要求，结合我市生态文明建设和体制改革总体要求，为加强应对气候变化，有效控制碳排放，制定玉溪市建立碳排放总量控制制度和分解落实机制。

一、总体要求和目标

全面贯彻落实党的十九大精神，牢固树立创新、协调、绿色、开放、共享的发展理念，把低碳发展作为我市经济社会发展的重大战略和生态文明建设的重要途径，采取积极措施，有效控制温室气体排放。按照国家和省碳排放总量控制工作要求，建立玉溪市碳排放总量控制制度和分解落实机制，促进经济结构、能源结构调整，提高能源利用效率、增加森林碳汇，确保实现省政府下达的碳排放总量控制目标。研究确定全市碳排放总量和强度控制目标，并提出各县、区碳排放总量和强度控制目标。制定和落实控制碳排放的各项政策措施，实施碳排放权交易，对重点碳排放企业及其他重点碳排放单位实施碳排放量管控，逐步建立碳排放总量控制制度和分解落实长效机制，争取早日达到碳排放峰值，实现低碳发展，努力成为全省生态文明建设排头兵。

二、工作重点

（一）建立碳排放总量控制制度

1．研究确定玉溪市碳排放峰值

在保持全市经济稳定增长的前提下，统筹考虑经济结构、能源结构、能源消费等变化趋势，研究确定玉溪市碳排放达到峰值的时间和数量，制定相应的减排路线图，形成低碳发展倒逼机制，争取成为全省率先达到碳排放峰值的典型地区。（牵头单位：市发展改革委，配合单位：市工业和信息化委、市住房城乡建设局、市林业局，市农业局，市交通运输局、市统计局、市能源局）

2．制定并落实多种控制碳排放政策措施

按《国务院关于印发“十三五”控制温室气体排放工作方案的通知》（国发〔2016〕61号）要求，围绕控制碳排放的重点领域，制定《玉溪市“十三五”控制温室气体排放工作方案》，落实控制碳排放政策措施，通过调整优化能源结构、合理控制能源消费，加快产业结构调整，强化节能和提高能效，控制工业生产过程、农业和废弃物处理领域温室气体排放，增加生态系统碳汇，加强高排放产品节约与替代等多种手段，有效控制碳排放。（牵头单位：市发展改革委，配合单位：市工业和信息化委、市林业局、市农业局、市环境保护局、市能源局）

3．深化玉溪市国家低碳城市试点建设

加快推进能源体系、产业体系、消费领域低碳转型，开展低碳产业园区、低碳城镇、低碳社区、低碳交通、低碳建筑、低碳旅游区、低碳学校、低碳商业等示范项目建设。落实《玉溪市低碳城市试点方案》，建立重点企业排放数据报送监督与分析预警机制，制定园区、社区排放的统计分析工作规范，探索开展战略新兴产业与低碳发展的示范性融合，探索抚仙湖区域近零碳排放试点示范。评估试点示范效果和总结经验，形成具有玉溪特色的可推广复制的示范低碳发展模式。推进我市优势工业产品和高原特色农产品低碳标准、标识认证工作。（低碳发展试点推进工作领导小组各成员单位）

（二）建立碳排放总量目标分解落实机制

1．完善碳排放基础数据统计、核算、报告和核查体系

将温室气体排放基础统计指标纳入政府统计指标体系，建立健全涵盖能源活动、工业生产过程、农业、土地利用变化与林业、废弃物处理等领域、适应温室气体排放核算要求的基础统计制度。结合省政府对地方的低碳考核要求，定期编制市级温室气体排放清单，并组织各部门专职人员及专家对数据进行核对。根据碳排放统计需要，完善能源统计体系。实行重点企事业单位碳排放报告制度，推动重点排放单位健全能源消费和碳排放台账记录，建立市级温室气体清单子系统，常态化开展温室气体排放数据的收集、统计、报告和分析工作。建立碳排放控制目标预测预警机制，推动落实碳排放控制工作任务。（牵头单位：市发展改革委，配合单位：市工业和信息化委、市林业局、市农业局、市住房城乡建设局、市统计局、市质监局、市能源局）

2．实行碳总量控制目标区域分解

根据省级下达的我市碳排放总量目标和强度“双控”目标，综合考虑各县区经济水平、产业结构、能源消费总量、能源结构、重点行业技术水平、重大项目建设等因素为基础，将省政府下达的碳排放总量和强度“双控”目标分解下达到各县区。各县区必须按照下达任务完成“双控”目标任务。（牵头单位：市发展改革委，配合单位：市统计局）

3．实行目标责任考核

将碳排放总量控制目标纳入经济社会发展综合评价和绩效考核体系，强化指标约束。结合省对市的考核要求，制定市县碳排放总量控制目标责任评价考核办法，定期对各县区碳排放总量控制目标完成情况和措施落实情况进行监督与考核。考核结果向社会公开，接受舆论监督。（牵头单位：市考评办）

（三）落实碳排放权交易制度和配额分配制度

贯彻落实国家《碳排放权交易管理暂行办法》，按照国家和省部署同步实现区域内重点企业开展碳交易工作。确定全国碳排放交易主体，对重点企事业单位开展年度碳排放监测、报告和第三方核查。配合省级开展区域碳排放配额分配，及时就配额分配方案、总量、分配方式等关键问题进行分析汇报，确保我市配额合理适度。分析全国、全省碳市场配额流通对我市碳排放总量控制的影响，制定相关的初步应对方案。（牵头单位：市发展改革委，配合单位：市财政局，市工业和信息化委、市统计局、市环境保护局、市林业局、市农业局、市商务局、市质监局）

三、责任分工

（一）县区人民政府职责

各县区人民政府要提高对控制温室气体排放重要性、紧迫性、艰巨性的认识，统一思想。县区人民政府按照下达的区域碳排放总量控制和强度指标，切实做好区域的部署安排及分解落实相关工作，确保完成目标任务。县级人民政府对本地区控制温室气体排放工作负总责。

（二）市直各部门职责

按照市政府成立的玉溪市低碳发展试点推进工作领导小组、玉溪市节能减排及应对气候变化工作领导工作小组、玉溪市低碳基础数据统计试点工作领导小组，市发改委统筹管理，建立跨部门协作机制，会同相关部门开展碳排放总量控制和分解落实工作。市统计局负责指导、协调全市低碳基础数据统计试点工作，其他部门根据职责分工，按照总体要求和专项工作方案，切实抓好落实。

四、强化低碳基础能力建设

（一）开展温室气体控制培训

面向各县区政府和相关部门的决策层、管理层、执行层，开展有针对性的教育培训工作，解读国家和省相关政策，明确总量控制和分解落实工作原则和要求，提升政府和相关部门在本项工作中的管理效率和执行能力。（牵头单位：市发展改革委，配合单位：玉溪市节能减排及应对气候变化领导小组成员单位，各县区人民政府）

（二）加强专业化技术服务能力

加快建立政产学研用有效结合机制，发展技术支撑机构，培养稳定的、高素质的专家队伍，加强碳排放预测、总量分解等的研究，提升在政策解读、数据分析、方案编制等方面的能力和实力，为碳排放总量控制和分解落实相关工作提供科学决策支撑。（牵头单位：市科技局，配合单位：市教育局、市发展改革委）

（三）积极开展交流合作

积极推进碳排放总量控制和分解落实机制等低碳发展对外交流合作，在科学研究、技术研发和能力建设等方面开展务实合作。加强与碳排放交易领先地区开展合作共建，学习借鉴总量控制和分解落实工作先进经验，增强低碳发展能力。（牵头单位：市发展改革委，配合单位：市科技局）

五、完善财政激励政策和投融资政策

（一）各县、各部门要积极争取国家支持，统筹融合各类降低碳排放资金，切实加大碳排放总量和强度“双控”资金投入力度，支持低碳试点建设、碳排放控制、碳排放交易、能力建设等。创新财政资金使用方式。（牵头单位：市财政局，配合单位：市发展改革委、市工业和信息化委、市林业局、市农业局）

（二）积极引导多元投资、经营主体和各类社会资金进入到低碳试点建设和碳排放权交易等有助于完成碳排放总量控制目标的领域。鼓励银行业金融机构加大对减排降碳项目的支持力度。探索政府和社会资本合作（PPP）等创新投融资模式在低碳领域项目建设运营中的应用。支持外资投入低碳产业发展及低碳技术研发应用。（牵头部门：市财政局，配合单位：市发展改革委、市工业和信息化委、市林业局、市农业局）
