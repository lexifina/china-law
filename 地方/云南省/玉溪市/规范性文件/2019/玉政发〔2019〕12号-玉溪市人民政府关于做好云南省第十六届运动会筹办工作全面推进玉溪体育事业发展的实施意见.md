# 玉溪市人民政府关于做好云南省第十六届运动会筹办工作全面推进玉溪体育事业发展的实施意见

玉溪市人民政府关于做好

云南省第十六届运动会筹办工作

全面推进玉溪体育事业发展的实施意见

玉政发〔2019〕12号

2022年云南省第十六届运动会（以下简称“省十六运会”）将在玉溪举办。为做好省十六运会筹办工作，全面推进我市体育事业发展，根据《中共玉溪市委 玉溪市人民政府关于进一步加强体育工作的意见》（玉发〔2016〕41号）精神，结合我市实际，制定如下实施意见。

一、总体要求

（一）指导思想。以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，坚持以人民为中心的发展思想，牢固树立新发展理念，紧扣“六个走在全省前列”、打造“三张牌”要求，围绕经济社会发展“5577”总体思路，创新体制机制，明确筹办任务，落实条件保障，以筹办省十六运会为契机，助推全市竞技体育、群众体育和体育产业全面协调发展，努力实现玉溪体育事业高质量跨越式发展。

（二）重要意义。2022年适逢党的二十大、北京冬奥会、杭州亚运会、世界杯足球赛等，是一个汇聚诸多大事的年度。云南省运动会是全省规模最大、规格最高、竞技水平最强的综合性体育盛会。圆满筹办2022年省十六运会，既是全市政治、经济、文化生活中的一件大事，也是实现我市经济社会高质量跨越式发展的重大机遇，对于促进我市创新型城市建设、提升全民健康素质、拉动消费、促进经济增长、增强人民群众幸福感获得感具有重要意义。

（三）主要目标

——群众体育工作再上新台阶。完善亲民、便民、利民的全民健身公共服务体系，进一步增强体育服务基层群众的能力，全民健身与全民健康深度融合，人民群众的健康素质明显提升。

——竞技体育工作再创新辉煌。青少年体育竞技水平和省运会参赛成绩显著提高。培育和输送一批优秀体育后备苗子，玉溪运动员入选国家、省级运动队人数增加，涌现更多的“奥星、亚星、国星”人才。

——体育产业发展实现新突破。逐步建立和完善以体育服务、竞赛表演、健身休闲等业态为主的体育产业架构，体育产业发展速度和体育消费明显增强。

——体育设施建设提升新层次。市县区基本建成与经济社会发展水平相适应的体育公共基础设施，城市社区、乡镇、行政村建有健身活动场所，人均体育场地面积明显增加。

——全市经济发展增添新动能。以举办省十六运会为动力，推进旅游、金融、商贸、通讯、餐饮等服务业的发展，城市服务功能进一步完善，社会事业和经济发展更加繁荣，社会文明程度明显提升。

（四）基本原则

——坚持党的领导。坚持党对体育工作的领导，充分发挥党总揽全局、协调各方的领导核心作用，牢牢把握正确的发展方向，把坚持党的领导贯穿筹办工作全过程。

——坚持改革创新。加大筹办工作改革探索力度，创新服务方式，树立绿色、康养、智慧的办赛理念，彰显玉溪特色。

——坚持问题导向。找准突出问题，补强薄弱环节，明确目标要求，改进工作方法，集中力量攻关，逐个逐项突破，有效破解制约我市体育发展的瓶颈难题。

——坚持统筹协调。注重当前、兼顾长远，做好顶层设计，整合资源力量，建立起运转高效、协同配合的工作运行机制，全面推进各项工作。

——坚持廉洁节俭。坚持廉洁办赛、节俭办赛，控制成本、讲求绩效，杜绝违纪违法和铺张浪费行为，努力把省十六运会办成公正、廉洁、节俭、高效的运动会。

二、重点工作

（五）精心筹办省运盛会。秉承东道主办赛要出彩、参赛更要出彩的理念，以办出玉溪特色、玉溪水平的省运盛会为目标，围绕重点工作和关键环节，紧扣时间节点，做好各环节的有序衔接，提高省十六运会筹备工作组织化程度。做好赛事组织和服务，确保各项竞赛有序进行，为参赛运动员展示才能、发挥水平、创造佳绩提供良好条件。做好各项会议、活动的组织以及省运会嘉宾、媒体等接待工作，努力为各代表团和来宾提供热情周到的服务。做好舆论宣传工作，充分调动全民参与的积极性，为赛事成功举办营造浓厚氛围，展现玉溪城市新形象和玉溪人民新面貌。

（六）加大公共体育设施建设力度。按照满足赛事需要、可持续利用的原则统筹做好比赛训练场馆规划建设。严格工程质量标准和公共体育设施建设标准，提高场馆设施科技含量。注重完善功能，以利赛后开放、服务社会，为人民群众提供更多的健身场地设施。将全市体育场馆、设施等公共体育设施建设纳入市县区城市总体规划，坚持以县区为主、市级补助、积极争取的原则，各县区逐步建成包括标准田径场、体育馆、游泳池、2块标准社会足球场在内的公共体育设施，实现到2022年所有县区体育设施能达到承办省级综合性运动会、国内单项高水平比赛的条件水平。

（七）稳步提高竞技体育综合实力

优化竞技体育项目布局。重点扶持田径、游泳、皮划艇、击剑、体操、网球等优势项目；突破提高自行车、射箭、拳击、排球等潜优势项目；适当增设足球、帆船等短板项目。优化项目布局，促进全市竞技体育各门类均衡发展。

加大各级体校建设。按照国家体育总局、中华人民共和国教育部发布的《少年儿童体育学校管理办法》、《中等体育运动学校管理办法》和有关要求，推进市县区体校、少体校建设，进一步发挥其功能作用，为社会提供更为广泛的青少年体育服务，推动青少年体育工作的发展。加大教练员培训力度，增强教练员敬业精神，提高教练员业务素质和执教能力。制定完善教练员任期目标、职称评定、竞争择优、考核奖惩及相关待遇等具体实施办法。

提高科学训练水平。坚持“培养兴趣，选好苗子，打好基础，科学训练，积极提高”的原则，学习运用先进训练理念和方法，科学制定训练计划，组织开展系统扎实训练，不断提高青少年训练的科学化水平，争创省十六运会团体总分、金牌总数全省第二，培养输送更多奥运会、亚运会、全运会优秀后备人才。

（八）贯彻落实全民健身国家战略

认真实施“六个身边”工程。以促进人民健康为中心，落实中共中央、国务院发布的《“健康中国2030”规划纲要》和《全民健身条例》，实施“六个身边”工程，即健全群众身边的健身组织、提供群众身边的健身设施、服务群众身边的健身活动、支持群众身边的健身赛事、组织群众身边的健身指导和讲述群众身边的健身故事。结合乡村振兴战略，加大公共体育服务供给侧结构性改革力度，建设更高水平、内容完备、惠及全民的基本公共体育服务体系，逐步推动公共体育服务在地区、城乡、行业和人群间的均等化。

加强健身场地设施建设与管理。构建县区、街道（乡镇）、社区（村）三级群众健身场地设施网络，推进建设城市社区15分钟健身圈，到2022年全市人均体育场地面积达1.9平方米。广泛开展丰富多样的全民健身活动，拓展全民健身活动的广度和深度，打造具有玉溪特色的全民健身精品赛事活动。保障各类社会群体基本体育权利，实现到2022年全市经常参加体育锻炼人数比率不低于39%。健全全民健身组织，大力培育和发展体育总会、单项运动协会、体育俱乐部等体育社会组织，完善“覆盖城乡、规范有序、富有活力”的全民健身组织网络。

加强国民体质监测。制定科学合理的国民体质监测实施方案，加大宣传动员力度，周密有序地开展国民体质监测工作，对各类人群进行体质测试，实现各类人群体质监测常态化。建立国民体质数据库，统计分析监测数据，公布监测结果，为各级党委、政府工作决策和研究提供依据。

（九）积极培育体育产业

做好国家体育产业联系点城市工作。认真贯彻国务院《关于加快发展体育产业促进体育消费的若干意见》（国发〔2014〕46号）和国家发展改革委、国家体育总局联合印发的《进一步促进体育消费的行动计划（2019—2020年）》（体经字〔2019〕13号），抓住我市作为国家体育产业联系点城市发展机遇，转变工作职能，提高服务水平，清除体育产业发展中的政策性障碍，落实体育产业发展规划，研究建立体育产业指标体系和统计制度，切实做好我市体育产业各项工作，贡献更多“玉溪智慧”和“玉溪经验”。

建立健全多业并举的体育产业架构。以体育健身为重点，大力发展健身服务业，着力培育体育竞赛表演业、健身休闲业，推动体育与互联网、金融、旅游等产业的融合发展。加强体育场馆资源开发利用，不断提高场馆综合效益。以市场为导向，加强体育资源商业开发，推动体育消费便利化。鼓励社会力量参与体育产业市场开发，对重点体育产业项目和企业给予扶持，培育具有影响力的玉溪本土体育品牌。

（十）完善后备人才培养体系

夯实学校体育基础。按照国家教育委员会、国家体委联合发布的《学校体育工作条例》和《国务院办公厅关于强化学校体育促进学生身心健康全面发展的意见》（国办发〔2016〕27号）的有关要求，充分发挥体育的育人功能，以培养学生体育意识和体育兴趣为重点，以增进学生体育技能和体质达标为抓手，加强体育课和课外体育锻炼，促进青少年健康成长。加强学校体育教师队伍建设，增加体育教师和体育教研人员配备。鼓励优秀教练员、退役运动员、社会体育指导员、有体育特长的志愿人员参与青少年体育工作。

强化青少年体育组织网络建设。强化以市级训练单位为龙头，县区少体校为重点，体育传统项目学校、体育特色项目学校、青少年体育俱乐部等为依托的青少年体育组织网络建设，促进规范化建设，积极扩大初级训练规模，开发青少年运动天赋和专项特长，提高输送率和成材率。

创新发展青少年体育竞赛体系。进一步完善青少年体育竞赛体系，切实发挥竞赛在竞技体育后备人才培养中的杠杆作用。建立健全符合青少年生长发育规律、运动员成才规律、运动技能形成规律及符合玉溪特点的青少年体育竞赛体制，逐步建立形式多样、覆盖面广、满足不同青少年群体需求的多元化青少年体育竞赛体系，不断增强青少年体质健康水平。

积极构建体育科研格局。通过引进和联合开发等措施，结合科教创新城建设，进一步建立市县区体育科研工作网络，加强体育训练创新技术服务平台建设，建立健全具有科学选材、科学训练等研究和应用能力的体育科研格局。积极开展运动项目规律研究和科学健身指导研究，不断提高体育科研开发和推广应用能力，促进玉溪体育科技进步。

三、保障措施

（十一）加大经费投入。探索建立政府主导、市场参与、社会支持的经费投入机制。增加市县区后备人才所需经费纳入同级财政预算的比重，及时足额拨付，每年从市级体育彩票公益金中安排资金支持市县区竞技体育后备人才培养。牢牢把握举办省十六运会的机遇，积极挖掘省十六运会的资源和价值，加大市场开发和资金筹措力度。

（十二）完善激励保障机制。贯彻落实好《国务院办公厅转发体育总局等部门关于进一步加强运动员文化教育和运动员保障工作指导意见的通知》（国办发〔2010〕23号）及《云南省人民政府办公厅关于转发省体育局等部门关于进一步加强运动员文化教育和运动员保障工作指导意见的通知》（云政办发〔2011〕183号）等有关文件精神，大力支持体育事业的健康发展。制定玉溪市筹办省十六运会总体方案和各项管理措施，落实好运动员文化教育与运动员保障工作，对代表玉溪参赛省十六运会取得优异成绩的运动员在训练、升学、就业、创业等方面给予倾斜性政策保障。

（十三）组建筹办工作专家咨询团队。结合《关于实施玉溪市“百千万人才计划”的若干意见》（玉室字〔2018〕17号）的贯彻实施及我市办赛参赛目标，通过引进、聘用等多种途径，在省十六运会场馆建设运营、备战训练、赛事组织、媒体融合、招商引资、市场开发等方面引入专业团队、专业人才，发挥优秀团队、人才的智慧和力量，为玉溪体育事业发展提供强有力的人才支撑和智力支持。

（十四）严格执行赛风赛纪和反兴奋剂规定。强化政治担当，以最大决心，用最严措施，做好赛风赛纪的教育、监督和管理，落实赛风赛纪和反兴奋剂工作责任制，杜绝任何违反赛风赛纪和兴奋剂违规事件的发生，确保玉溪体育代表团干干净净参赛。

（十五）强化服务保障。精心做好安全保卫、服务接待、新闻宣传、信息通讯、医疗卫生、交通、电力、气象和志愿服务等各项服务保障工作。加快推进城市基础设施建设和环境综合整治，促进城市功能服务不断提升。加大科技服务创新意识，提高办赛科技含量。加强服务行业建设，开展志愿者专项服务培训，切实提高行业文明和志愿服务水平。

四、组织实施

（十六）加强组织领导。切实加强对筹办工作的组织领导，建立指挥保障体系。市级成立省十六运会筹办工作委员会，组建若干工作部门，选派素质全面、能力过硬的干部加入到工作中来，明确目标、分解任务、落实责任，分阶段推进各项工作。

（十七）注重工作联动。各县区及市直有关部门要把筹办省十六运会作为推进玉溪经济社会实现高质量跨越式发展的重要任务，结合各自职能作用，强化力量整合，及时沟通情况，密切协作配合，主动融入筹办工作体系，形成工作合力，为圆满筹办和参赛省十六运会创造有利条件。

（十八）严肃纪律作风。各县区及市直有关部门要提高政治站位，从全局和战略的高度出发，强化责任担当，工作不推诿、不扯皮，杜绝形式主义、官僚主义，全力以赴支持并参与做好各项筹办工作，以高效工作、务实作风、严明纪律充分展示东道主的良好形象。对在省十六运会筹办工作中失职渎职并造成不良影响的部门、单位和个人，将严肃追究责任。
