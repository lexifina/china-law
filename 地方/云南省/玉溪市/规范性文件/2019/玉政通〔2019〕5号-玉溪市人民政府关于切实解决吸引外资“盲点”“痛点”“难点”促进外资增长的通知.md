# 玉溪市人民政府关于切实解决吸引外资“盲点”“痛点”“难点”促进外资增长的通知

玉溪市人民政府关于切实解决吸引外资

“盲点”“痛点”“难点” 促进外资增长的通知

玉政通〔2019〕5号

各县区人民政府，市直各委、办、局，中央、省驻玉单位：

为认真贯彻落实《云南省人民政府关于切实解决吸引外资“盲点”“痛点”“难点”促进外资增长的意见》（云政发〔2019〕20号）精神，着力解决我市吸引外资“盲点”、“痛点”、“难点”问题，持续改善营商环境，全面提高我市吸引外资的水平和质量，现将有关事项通知如下：

一、进一步扩大开放，落实政策，消除“盲点”

（一）拓宽吸引外资渠道

依托国际商会（协会）、驻外机构、外资企业和自然人等，拓宽引资渠道，创新引资方式，实施精准招商。对吸引外资有重大贡献的机构、团体、自然人按贡献大小给予奖励。强力推进“一把手”招商，对招商引资重点团组，在因公临时出国（境）计划、任务审批、出访经费等方面优先保障。各县区、玉溪高新区每年组织赴国（境）外精准招商不少于2次，吸引外资签约项目1个以上。（玉溪高新区管委会、各县区人民政府牵头；市直有关部门配合）

（二）扩大外商投资领域

鼓励外资积极参与我市打造“三张牌”及以新经济为龙头的战略性新兴产业建设。支持外资以独资、合资方式进入高端制造、智能制造、绿色制造等领域，单晶硅、大硅片研发生产；高原特色现代农业、生物医药及大健康、旅游、现代物流等项目建设及经营；新能源汽车及专用车制造、新能源汽车关键零部件制造、有色金属精深加工；食品加工、开发和生产，特色食用资源开发及应用；新型电子元器件制造，触控系统制造，5G设备组件、半导体材料、集成电路研发制造，物联网技术开发与应用等领域；天然香料香精生产技术开发及制造，智能家具研发制造。支持外资在我市设立合资证券公司、证券投资基金管理公司、期货公司、寿险公司，外资股比不超过51%；支持外资以合资、合作方式进入民用机场建设和经营；支持高校、中职学校（高中）和学前教育机构引进国（境）外优质教育资源，在玉溪开设相应层次和类型中外合作办学机构。支持外资在我市与中方医疗机构合资、合作。探索建立国外或港澳台产业园。（市发展改革委、市商务局、市投资促进局牵头；市直有关部门，玉溪高新区管委会，各县区人民政府配合）

（三）加大财政支持力度

1．扩大利用外资规模支持政策。除严格执行省级政策外，对在我市新设投资项目且实际到位资金100万美元以上（含100万美元）的国（境）外企业，每100万美元补助10万元人民币，最高补助不超过300万元人民币。补助资金市、县区（玉溪高新区）按4∶6比例一次性补助。（市投资促进局、市商务局牵头；市财政局，玉溪高新区管委会，各县区人民政府配合）

2．强化外资招大引强支持政策。落实好省级政策，配合做好土地利用计划指标安排工作。对投资符合《玉溪市重点产业招商引资若干优惠政策规定》标准以上的企业，自投产之日起，3年内由各县区、高新区按企业缴纳增值税和所得税形成地方财力留成部分的40%给予奖励；对以兼并、收购或其他方式盘活我市重点产业领域破产、停产或长期亏损国有或集体企业，安置原企业职工30%以上并签订3年以上劳动合同，实际注入资金大中企业600万美元以上、小型企业200万美元以上的，自投产之日起，3年内由各县区、高新区按企业缴纳增值税和所得税形成地方财力留成部分的40%给予奖励。对外资跨国公司总部或地区总部项目，按“一事一议”重点支持。（玉溪高新区管委会，各县区人民政府牵头；市直有关部门配合）

3．突出金融业利用外资支持政策。对新设立的外商独资法人金融机构，或境外金融分支机构（分行、分公司），市财政给予一次性奖励50万元人民币；对新设立的合资法人金融机构，市财政给予一次性奖励30万元人民币；对新设立的合资金融机构分支机构（分行、分公司），市财政给予一次性奖励10万元人民币。（市财政局牵头；市政府金融办、人民银行玉溪中心支行、玉溪银保监分局，玉溪高新区管委会，各县区人民政府配合）

4．优化外资研发创新合作支持政策。对经认定的新设外资研发中心，市财政按有关规定给予补助支持。世界500强企业、全球行业龙头企业在我市新设具有独立法人资格的外资研发机构，可按“一事一议”方式给予重点支持。支持外商投资企业参与承担国家和省、市科技计划项目。（市科技局牵头；市财政局、市商务局，玉溪高新区管委会，各县区人民政府配合）

5．落实外商投资企业税收优惠政策。落实国家利用外资系列税收优惠政策。符合条件并经认定的高新技术企业，减按15%征收企业所得税。（市税务局牵头；市商务局，玉溪高新区管委会，各县区人民政府配合）

（四）强化外商投资要素保障

1．用地支持政策。对经认定的省、市级重大外商投资项目，在符合经济社会发展规划、土地利用规划、城乡规划的前提下，优先保障建设用地需求，做到应保尽保。（市自然资源规划局牵头；市直相关部门、各县区人民政府配合）

2．用工支持政策。市、县人力资源社会保障部门支持外商投资企业有组织地开展职业技能培训。对参加就业技能培训和创业培训的毕业年度高校毕业生，按规定给予一定标准的职业培训补贴。被认定为见习基地的外商投资企业，招录离校2年内未就业高校毕业生和中职毕业生、16—24周岁失业青年参加见习的，按规定给予一定标准的就业见习补贴。（市人力资源社会保障局牵头；市财政局，各县区人民政府配合）

3．用电支持政策。支持外商投资企业直接参与电力市场化交易，或委托售电公司、供电部门代理购电，直接交易的电量和容量不再纳入发用电计划。（市发展改革委、市能源局、玉溪供电局按照职责分工负责）

二、进一步优化环境，强化措施，缓解“痛点”

（五）加大外商投资企业贷款支持

认真贯彻落实省级政策措施，积极发展政府性融资担保机构，探索建立金融机构风险补偿制度、重大外商投资项目信贷审批绿色通道机制，创新授信和审贷模式，服务外商投资企业发展。对市场前景好、有核心竞争力，投资额达到500万美元以上的项目，在自有资金投资达到项目总投资的50%以上，符合相关条件和要求的，由玉溪市融资担保有限公司担保向银行贷款其余项目建设资金，担保费率不超过贷款额的2%。（市政府金融办牵头；市发展改革委、人民银行玉溪中心支行、玉溪银保监分局配合）

（六）降低企业用地、物流和经营成本

1．降低项目用地成本。严格执行省级归类工业产业类项目用地政策。纳入市级重点项目的，市内园区土地出让底价可按照不低于所在地《工业用地最低价标准》的70%执行。所形成的项目协议（合同）价与土地成本价价差由市、县区（高新区）按4∶6比例承担。鼓励企业采取长期租赁、先租后让、租让结合方式使用土地，年租金按照出让地价评估后折算到1年期价格确定。推行工业用地出让弹性年期制，出让价格按照相应出让年限评估确定。（市自然资源规划局牵头；市直相关部门，玉溪高新区管委会，各县区人民政府配合）

2．降低企业物流成本。落实好省级降低企业物流成本政策。对首次认定的市级重点物流企业给予一次性100万元人民币奖励；对固定资产投资2000万美元以上的物流在建项目，每个项目一次性给予50万—100万元人民币的补贴。（市商务局牵头；市直相关部门，各县区人民政府配合）

3．降低企业经营成本。支持外资制造业企业依法依程序进行厂房加层、厂区改造、内部用地整理及扩建生产、仓储场所，提升集约化用地水平，不再增收地价款。（玉溪高新区管委会，各县区人民政府牵头；市直相关单位配合）

（七）营造宽松的人才环境

认真组织实施玉溪市“百千万人才计划”，支持外商投资企业引进海内外高端人才。落实好省、市有关人才引进经费支持、服务保障等政策，与市级用人单位正式签订5年以上引进协议的，经评审认定，一次性给予50万—1000万元人民币的项目经费资助，一次性给予30万—200万元人民币的购房补助。同时，刚性引进上述人才的部门和单位可获一次性10万元人民币或5万元人民币工作经费补助。（市人才办牵头；市直相关部门，玉溪高新区管委会，各县区人民政府配合）

（八）加大知识产权保护力度

严厉打击侵权假冒行为，不强制转让知识产权。落实针对外商投资企业新技术、新材料的快速审查、确权、维权服务措施，积极支持外商投资企业，参与各类科技成果评审。（市市场监管局牵头；市直相关部门配合）

三、进一步优化服务，完善机制，攻克“难点”

（九）着力提高通关便利化

加快玉溪海关建设步伐，进一步简化单证、优化流程、提升信息化、降低收费，提高通关效率。对接开通玉溪面向南亚东南亚口岸农副产品快速通关“绿色通道”，加快与民航、港口、铁路等行业机构合作对接，为市场主体提供全程“一站式”通关物流信息服务。对接全国版跨境电商线上综合服务平台，强化“通关+物流”功能。（市商务局牵头；玉溪海关、市交通运输局、市农业农村局配合）

（十）深入推进外商投资管理体制改革

深入推进外资企业设立、变更备案管理改革，简化外商投资项目管理程序和外资企业设立、变更程序。积极推行负面清单以外领域，外商投资企业商务备案与工商登记“单一窗口、单一表格”受理改革，在各级政务服务中心设立综合受理窗口，对“多证合一”登记业务全面实行一套材料、一表登记、一窗受理、一次采集、一档管理“五个一”工作模式。探索将外商投资企业设立、变更的审批、备案和登记事项下放至有条件的县、区商务主管部门和市场监管部门。除法律法规另有规定外，有关部门要按照内外资企业统一标准、统一时限的原则，审核外商投资企业业务牌照和资质申请。严格兑现依法向投资者作出的政策承诺，对未兑现承诺或未履行承诺而造成严重不良影响的有关责任单位、责任人，要严肃追责、问责。（市政务服务局、市市场监管局、市商务局牵头；市直有关部门，各县区人民政府配合）

（十一）着力打造一流外商投资环境

全面贯彻落实省、市营商环境提升年各项工作任务，巩固提升“123456”改革成果，深入开展负面清单之外“零门槛”、收费清单之外“零收费”、对企业服务“零距离”、对侵权行为“零容忍”等“四个零”行动，努力实现“只进一扇门、只到一个窗、最多跑一次”，着力营造审批最少、流程最简、时限最短、成本最低、服务最优的办事创业和营商环境。（市政务服务局、市市场监管局牵头；市直有关单位，各县区人民政府配合）

（十二）建立吸引外资协调及考核评价机制

在市招商引资工作委员会的领导下，建立全市吸引外资协调工作机制，组建工作专班，强化对外资企业服务。建立完善吸引外资考核评价机制，加大吸引外资工作在招商引资考核中的权重。强化政策兑现审定和服务，各县区（高新区）每年11月10日前将符合兑现政策的相关佐证材料报市招商委办公室，由市招商委办公室组织市财政局、市商务局、市税务局等部门进行初审，依程序提交市招商引资工作委员会审核通过后兑现。本《通知》涉及市级专项资金纳入各产业次年专项资金预算列支，并于次年5月底前兑现。省政府扶持政策及奖励、补助（贴）等各类资金，由市招商委办公室按要求收集整理所需材料，会同有关部门审核，经市政府审定后上报落实。（市招商引资绩效考核办、市投资促进局牵头；市直相关部门，玉溪高新区管委会，各县区人民政府配合）

本通知执行期限为2019—2022年，通知中优惠奖励政策与国家、省、市其他政策重叠的，按照“就高不重复”原则执行。市直有关部门、各县区人民政府要高度重视，主动作为，积极推动省、市政策措施落到实处，市人民政府视情况开展督查，对工作成效较好的给予通报表扬，对工作不力的县区、部门及有关责任人进行问责。

2019年9月19日
