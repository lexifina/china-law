# 关于安排个旧市2019年专业技术职称评审计划的通知

市属各有关单位：

按照《云南省人力资源和社会保障厅关于印发2019年高级专业技术职称评审计划的通知》（云人社通〔2019〕47号）、《红河州人力资源和社会保障局关于印发2019年专业技术职称评审计划的通知》（红人社发〔2019〕69号）要求，我市各中、初级评委会承办部门须严格按照评审计划安排的时间开展评审工作，不得提前或延期。各单位需按承办部门的工作安排和要求，完成本单位的职称推荐上报工作。现将相关通知及附件公布。
