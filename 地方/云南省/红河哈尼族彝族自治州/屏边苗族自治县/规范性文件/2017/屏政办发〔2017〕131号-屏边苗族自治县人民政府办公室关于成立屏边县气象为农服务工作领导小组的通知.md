# 屏边苗族自治县人民政府办公室关于成立屏边县气象为农服务工作领导小组的通知

各乡镇人民政府，县属有关部门：

为建立健全我县农业气象服务和农村气象灾害防御体系，切实做好气象灾害的防御工作，保障人民群众的生命财产安全。经研究，决定成立屏边县气象为农服务工作领导小组。现将有关事项通知如下：

领导小组下设办公室在县气象局，由郭填绥同志兼任办公室主任，负责处理日常事务。各成员单位要认真按照职责职能配合抓好各项工作的落实。

二、工作职责

（一）负责县级“三农”气象服务专项建设工作的组织领导，研究解决项目工作中的重要事项和重点问题。

（二）组织编制、实施精细化农业气候区划和农业气象灾害风险区划，制定县级农业气象服务标准和规范，完善农业气象服务体系。

（三）建立广泛覆盖的预警信息发布网络，推进国家突发事件预警信息发布系统建设并向乡镇延伸。

（四）推进农村气象灾害防御组织体系建设，完善“政府主导、部门联动、社会参与”的气象灾害防御机制。

（五）完成县委、县人民政府交办的气象为农服务和灾害防御等各项工作。
