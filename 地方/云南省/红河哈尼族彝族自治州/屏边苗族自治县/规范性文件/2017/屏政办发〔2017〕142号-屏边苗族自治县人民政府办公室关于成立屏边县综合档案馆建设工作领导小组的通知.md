# 屏边苗族自治县人民政府办公室关于成立屏边县综合档案馆建设工作领导小组的通知

各乡镇人民政府，县属有关部门：

为加快推进县综合档案馆建设步伐，促进全县档案事业发展，经研究，决定成立屏边县综合档案馆建设工作领导小组，其组成人员名单如下：

组 长：李秀英（县人民政府副县长）

副组长：吴自红（县档案局局长）

成 员：尚高奎（县人防办主任）

汤开伟（县发展和改革局副局长）

邓明富（县国土资源局副局长）

熊保良（县林业局副局长）

王 磊（县审计局副局长）

张建林（县环境保护局副局长）

熊树斌（县档案局副局长）

覃 勤（玉屏镇人民政府副镇长）

领导小组下设办公室在县档案局，由吴自红同志兼任办公室主任，熊树斌同志兼任办公室副主任。负责统筹新馆建设工作。领导小组各成员如有变动，由成员单位相应职务人员自行替补并报领导小组办公室备案。

屏边苗族自治县人民政府办公室

2017年11月3日
