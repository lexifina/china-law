# 屏边苗族自治县人民政府办公室关于调整县人民政府办公室领导分工的通知

屏政办发〔2017〕34号

各乡镇人民政府，县属各部门：

因人事变动，为更好地开展好办公室各项工作，经研究，决定对县人民政府办公室领导分工进行调整。现将调整后的分工通知如下：

主任刘朝恒：主持县人民政府办公室全面工作，联系挂钩扶贫、招商引资、信访工作。

副主任邢林生：负责招商引资工作。

副主任杨海：负责信访工作。

副主任黄自水：负责文秘工作，分管秘书一科、秘书二科、综合科，联系县人民政府研究室、县人民政府法制办公室（县行政复议办公室）。

副主任甘娟：负责后勤接待、机关事务管理、办公室工、青、妇和离退休干部服务工作，分管县机关事务管理局、行政科（车编办、保卫科）、财务室。

副主任王庆永：负责安全生产、综治维稳、党风廉政、纪检监察、支部党建和档案工作，分管督查室、应急管理办公室（政府总值班室）。

副主任杨永春：负责脱贫攻坚、信息、普法教育、政务公开和电子政务工作，分管信息科、网络管理中心。

请各乡镇、各部门按此分工范围联系工作。

屏边苗族自治县人民政府办公室

2017年3月14日

抄送：县委各部门，县人大常委会办公室，县政协办公室，县法院，县检察院，县人武部，各人民团体，省州驻屏单位。

屏边县人民政府办公室 2017年3月14日印发
