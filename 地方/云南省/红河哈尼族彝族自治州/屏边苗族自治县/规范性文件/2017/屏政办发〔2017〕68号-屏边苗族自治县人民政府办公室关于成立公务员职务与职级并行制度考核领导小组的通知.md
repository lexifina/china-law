# 屏边苗族自治县人民政府办公室关于成立公务员职务与职级并行制度考核领导小组的通知

屏政办发〔2017〕68号

各科室：

根据《关于印发〈屏边县县乡机关建立公务员职务与职级并行制度实施方案〉的通知》（屏办发〔2015〕75号）精神，为确保县政府办公室机关公务员职务与职级并行制度工作顺利进行，经研究决定，成立县政府办公室机关公务员职务与职级并行制度考核领导小组。其组成人员如下：

组 长：刘朝恒 县政府办公室主任

副组长：黄自水 县政府办公室副主任

甘 娟 县政府办公室副主任

王庆永 县政府办公室副主任

杨永春 县政府办公室副主任

成 员：李雪曼 县政府督查室主任

朱学云 县政府应急办主任

李 娟 县网络管理中心主任

安红刚 县政府办公室秘书一科科长

韩治国 县政府办公室秘书二科科长

祝应红 县政府办公室综合科科长

陶 涛 县政府办公室信息科科长

李天艳 县政府办公室行政科科长

领导小组下设办公室在综合科，由王庆永同志兼任办公室主任，负责处理相关事务工作。

屏边苗族自治县人民政府办公室
