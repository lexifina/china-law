# 屏边苗族自治县人民政府办公室关于成立屏边猕猴桃地理标志产品保护申报管理委员会的通知

屏政办发〔2017〕91号

各乡镇人民政府，县属有关部门：

为做好我县猕猴桃地理标志产品保护申报各项工作，进一步提升屏边猕猴桃的知名度和文化品位。经研究，决定成立屏边县猕猴桃地理标志产品保护申报管理委员会。其组成人员如下：

主 任：李雄文（县人民政府县长）

副主任：万执政（县人民政府副县长、县财政局局长）

成 员：陈德伟（县农业和科学技术局局长）

朱 勇（县林业局局长）

万玉东（县市场监督管理局局长）

李星桩（县环境保护局局长）

管理委员会下设办公室在县农业和科学技术局，由陈德伟同志兼任办公室主任，负责做好猕猴桃地理标志申报工作的材料收集、制定工作计划、材料申报、答辩等各项工作和处理日常事务。各成员单位要密切配合，加强协调，按照各自的职责，做好地理标志产品申报工作。

屏边苗族自治县人民政府办公室

2017年6月22日

抄送：县委办公室，县人大常委会办公室，县政协办公室，县法院，县检察院。
