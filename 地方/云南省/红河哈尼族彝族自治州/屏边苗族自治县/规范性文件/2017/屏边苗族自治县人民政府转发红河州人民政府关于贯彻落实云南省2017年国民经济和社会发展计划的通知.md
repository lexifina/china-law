# 屏边苗族自治县人民政府转发红河州人民政府关于贯彻落实云南省2017年国民经济和社会发展计划的通知

各乡镇人民政府，县属各部门：

现将《红河州人民政府关于贯彻落实云南省2017年国民经济和社会发展计划的通知》（红政发〔2017〕49号）转发你们，并提出以下意见，请一并抓好贯彻落实。

一、请各乡镇、各部门认真按照省州工作要求和《屏边苗族自治县人民政府关于印发屏边县2017年经济工作重点任务责任分解方案的通知》（屏政发〔2017〕29号）要求，认真抓好全县国民经济和社会发展计划各项经济指标落实。

二、请各乡镇、各部门高度重视，切实加强组织领导，按照年初目标任务，采取有力措施，狠抓工作落实，确保目标如期实现，为全县全年经济持续平稳较快发展打牢基础。

屏边苗族自治县人民政府

2017年7月24日
