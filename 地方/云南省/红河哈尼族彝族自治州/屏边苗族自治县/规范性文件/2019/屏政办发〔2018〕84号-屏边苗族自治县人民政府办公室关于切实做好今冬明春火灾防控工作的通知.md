# 屏边苗族自治县人民政府办公室关于切实做好今冬明春火灾防控工作的通知

各乡镇人民政府，县属各部门：

为切实做好今冬明春火灾防控工作，严防发生重特大尤其是群死群伤恶性火灾事故，保障我县经济发展和社会稳定，按照《国务院安委会办公室关于开展2018年今冬明春火灾防控工作的通知》（安委办〔2018〕25号）、《云南省人民政府办公厅关于切实做好今冬明春火灾防控工作的通知》（云政办发〔2018〕101号）和《红河州人民政府办公室关于切实做好今冬明春火灾防控工作的通知》（红政办发〔2018〕74号）要求，现就切实做好全县今冬明春火灾防控工作通知如下：

一、切实增强做好今冬明春火灾防控工作的责任感和紧迫感

冬春季节，风干物燥，人流物流量大，各类活动增多，火、电、油、气用量增加。从历年火灾数据分析，冬春季节火灾亡人数占全年火灾亡人总数的2/3左右，因烤火取暖等原因引发的小火亡人现象较为突出。近年来，我省多起影响重大的火灾事故，多数发生在冬春季节。2014年1月11日，香格里拉独克宗古城发生火灾；2017年3月2日，弥勒市弥阳镇新村村委会新村353号发生火灾，造成7人死亡；2018年9月1日，昆明市西山区福海街道办事处杨家地社区王家地新村37号发生火灾，火灾造成6人死亡；2018年12月2日，昆明市西山区福海街道办事处船房社区新农村居民小组84号发生火灾，火灾直接造成5人死亡，在自救逃生过程中，另有3人坠楼身亡。做好冬春火灾防控工作，对维护人民生命财产安全、确保全年火灾形势平稳具有重要意义。当前，根据中央深化机构改革决策部署，地方机构改革任务将在2019年3月底前基本完成。今冬明春正是我县地方机构改革调整的关键时期，一些基层监管部门、行业部门正面临着改制重组、职能调整、人员转隶，消防安全管理容易出现断档甚至空档。各乡镇、各部门必须坚持以习近平新时代中国特色社会主义思想为指导，坚决贯彻落实国务院安委会办公室、省人民政府、州人民政府关于冬春火灾防控工作的决策部署，切实提高政治站位，进一步增强责任感和紧迫感，扎实抓好本乡镇、本系统今冬明春火灾防控工作，确保火灾形势持续平稳。

二、严格落实消防工作责任

各乡镇要按照“党政同责、一岗双责、失职追责”要求，充分发挥主导作用，把消防工作纳入重要议事日程，组织召开专题会议，研究本乡镇消防安全形势。工信、教育、公安、民政、住建、交通、文体旅广、旅发委、卫计、安监、市场监管等主管部门，要按照“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，细化和完善本系统工作方案，督促相关行业单位落实消防安全主体责任，做好火灾防控工作。各社会单位要严格落实消防安全责任制和岗位责任制，做到安全自查、隐患自除、责任自负。各乡镇要建立健全消防安全组织机构，明确专人负责消防工作，督促村（居）民委员会落实消防工作责任，及时排查、整治和消除火灾隐患，落实源头管控措施。要深入开展大约谈工作，重点约谈工作不力、火灾多发的属地政府和行业主管部门、国有重点企业，各行业部门要集中约谈问题突出的行业系统单位，消防部门要分类约谈大型连锁企业集团、火灾高风险单位，督促落实冬春火灾防控责任和措施。对履职不到位或工作不力，导致发生重特大火灾事故，造成重大人员伤亡和经济损失的，要严肃追究有关人员的责任。

三、深入开展火灾隐患排查整治工作

各乡镇、各部门要认真研判本地区、本行业系统火灾形势，查找火灾防控的薄弱环节和主要问题，结合今冬明春火灾防控实际，制定工作方案，周密安排部署，全面开展火灾隐患排查整治工作。要针对辖区实际，统筹兼顾，突出重点，切实加强城中村、“多合一”、小单位小场所和博物馆、文物建筑消防安全管理，有针对性开展重点专项治理工作。要把握重大节日、“两会”等关键节点，组织工信、教育、公安、民政、住建、交通、文体旅游广、旅发委、卫计、安监、市场监管等有关部门，开展以高层建筑、大型城市综合体、易燃易爆单位、在建工地、文物古建、商场市场、学校、医院、养老福利机构、公共娱乐场所为重点的火灾隐患排查工作。要强化农村火灾防控，认真落实《屏边县人民政府办公室关于进一步加强和改进农村消防安全工作的实施意见》（屏政办发〔2017〕93号），充分发挥公安派出所、乡镇和农村“一委一办三员”、乡镇政府专职消防队作用，排查火灾隐患，提升农村抵御火灾风险的能力；各乡镇要认真学习弥勒市在农村消防工作方面的做法和经验，推广安装独立式联网火灾探测报警器。消防部门要按照“双随机、一公开”要求开展监督抽查，对检查发现的火灾隐患实行“零容忍”，严格规范执法，坚决督促整改，严格落实重大火灾隐患立案销案、专家论证、挂牌督办和公示曝光制度，已挂牌督办的，要加快整改进程，确保按期销案；对新发现的重大火灾隐患，要及时按要求挂牌督办，明确责任，综合整治；对一时难以整改的，要督促单位强化严管严控措施，防止遗患成灾。

四、广泛开展消防安全宣传教育

各乡镇、各部门要认真谋划，扎实开展冬春消防安全宣传工作，在主流媒体和政府门户网站开办专题专栏，刊播消防公益广告，广泛宣传消防安全知识。要针对火灾易发高发的重点时间、重点人群、重点场所和部位，充分运用报刊、广播、电视、互联网、微信、微博等媒体，积极宣传普及安全用火、用电、用油、用气和逃生自救等消防安全常识，切实提高全民消防意识。要继续曝光重大火灾隐患和消防安全不良行为，剖析典型火灾案例，警示社会单位和群众，切实提高全社会消防认知水平。要加强消防安全培训，组织各级党政机关、国有企业、社会单位及乡镇、村（居）委会消防安全责任人、管理人开展消防安全培训，切实培养一批消防安全“明白人”。

五、切实提高应急救援能力

各乡镇、各部门要组织对行政区域内的消防水源、消火栓、消防车通道等公共消防基础设施开展1次全面普查，对存在的问题要及时整改。各行业系统要修订灭火救援应急预案，完善灭火救援区域联防机制，提高区域应急联动能力。消防部门和政府、企业专职消防队要开展冬季业务大练兵，对重要场所、重点区域制定有针对性的灭火作战预案，组织开展实地、实战演练，提高复杂恶劣环境下的实战能力。要坚持“救人第一、科学施救”，力争打早、打小，减少火灾造成的损失。各乡镇、各有关部门要重视消防技术装备建设，提供必要的经费保障，添置防火灭火和个人防护器材，提高防火灭火能力和抢险救援水平。

各乡镇、县属各部门工作开展情况，请于每月20日前报县公安消防大队。联系人及电话：范冬梅，3226605，邮箱：2535883838@qq.com。
