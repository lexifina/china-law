# 屏边县人民政府办公室关于印发屏边县2019年“十百千”工程产业发展方案的通知

各乡镇人民政府，县属有关部门：

为切实加快屏边县“十百千”产业工程进度，做好屏边荔枝、猕猴桃、枇杷等特色产业发展工作，促进屏边高原特色现代农业健康发展，实现群众增收致富，制定本方案。

一、工作目标

年内发展屏边荔枝、猕猴桃、枇杷产业各1万亩，总计3万亩（县农业农村和科学技术局负责牵头完成屏边荔枝、猕猴桃各1万亩，县林业和草原局负责牵头完成枇杷1万亩），各乡镇具体种植任务见附件。

二、扶持政策

（一）补助方式：补助资金以整合的方式切块到各乡镇，各乡镇根据实际在切块资金中筛选项目，同时可自行制定补助方式和补助标准组织实施，并报县级主管部门备案。

（二）信贷支持：以财政和金融部门制定下发的方案执行。

三、建设时限

2019年3月—2020年2月。

四、有关要求

（一）各乡镇、县属有关部门要进一步加强组织领导，明确责任领导、责任科室和联络员，细化、量化工作任务，拟定各季度各项指标完成情况，精心组织，层层抓好落实。

（二）各乡镇、县属有关部门要充分利用广播、电视、报刊等媒体做好产业发展宣传发动工作，广泛动员农户大力发展产业，加快“十百千”工程建设步伐。

（三）县农业农村和科学技术局、县林业和草原局要加大科技培训力度，大力推广普及种植技术，增强农户科技意识。同时，负责与乡镇一同把好屏边荔枝、猕猴桃、枇杷的苗木质量关，做好产业苗木补足筹备应急工作。

（四）各乡镇要切实做好产业的地块落实、基础设施建设、组织种植等相关工作；县供销社、县科协要积极组织农民专业合作社建设的申报工作。

（五）各乡镇、各有关部门要精心组织，协作配合，认真组织实施，切实加强对各项目的指导、协调、检查和落实工作，及时解决工作中遇到的困难和问题，确保“十百千”工程的稳步推进并取得实效。

（六）各乡镇要加强对产业发展技术培训，指导产业健康发展，严禁各种不利套种行为。
