# 屏边县人民政府办公室关于印发《屏边县2019-2020年农村户厕改建资金补助实施方案》的通知

各乡镇人民政府，县属各部门：

《屏边县2019-2020年农村户厕改建资金补助实施方案》已经县人民政府同意，现印发给你们，请认真贯彻执行。

2019年11月12日

（此件公开发布）

屏边县2019—2020年农村户厕改建资金补助实施方案

为加快推进我县农村户厕改造建设工作，根据《云南省“厕所革命”三年行动计划》（云政发〔2018〕33号）、《云南省人民政府办公厅关于印发云南省抓实推进厕所革命工作实施方案的通知》（云政发〔2019〕76号）、《红河州“厕所革命”三年行动实施方案（2018—2020年）》（红政发〔2019〕1号）、《屏边县农村人居环境整治三年行动实施方案（2018—2020年）》（屏办发〔2018〕71号）和《屏边县农村“厕所革命”实施方案2019-2020年》（屏农联发〔2019〕4号）等要求，为确保按时按质完成上级下达目标任务，经研究制定本方案。

一、目标任务

根据《红河州农村人居环境整治三年行动实施方案（2018—2020年）》（红办发〔2019〕1号）和《屏边县农村人居环境整治三年行动实施方案（2018—2020年）》（屏办发〔2018〕71号）等文件，到2020年实现农村无害化卫生户厕普及率达到50%以上，农村卫生户厕普及率达到85%以上的目标，全县需要通过改造建设一批农村户厕，完成农村无害化卫生户厕改造建设11322座，改造建设农村卫生户厕8460座。

（一）2019年农村户厕改建目标任务数

1.2019年农村无害化卫生户厕改建任务数。全县需要完成无害化卫生户厕改建5890座（含2018年未完成458座），其中：玉屏镇717座、新现镇1343座、新华乡676座、和平镇1076座、白云乡449座、湾塘乡695座、白河镇934座。

2.2019年农村卫生户厕改建任务数。全县需要完成卫生户厕改建4230座，其中：玉屏镇822座、新现镇664座、新华乡714座、和平镇441座、白云乡297座、湾塘乡349座、白河镇943座。

（二）2020年农村户厕改建目标任务数

1.2020年农村无害化卫生户厕改建任务数。全县需要完成无害化卫生户厕改建5432座，其中：玉屏镇717座、新现镇1108座、新华乡495座、和平镇1076座、白云乡407座、湾塘乡695座、白河镇934座。

2.2020年农村卫生户厕改建任务数。全县需要完成卫生户厕改建4230座，其中：玉屏镇822座、新现镇664座、新华乡714座、和平镇441座、白云乡297座、湾塘乡349座、白河镇943座。

二、资金补助标准和方式

（一）补助标准。按照农村无害化卫生户厕改建1500元/座（省级补助400元/座、县级补助1100元/座），农村卫生户厕改建县级补助800元/座。

（二）资金测算

1.2019年农村无害化卫生户厕改建任务数5890座（含2018年未完成任务数458座）。2018年未完成任务数458座，县级补助1500元/座，合计68.7万元；2019年任务数5432座，县级补助1100元/座，合计597.52万元。共需要补助资金666.22万元；卫生户厕4230座，县级补助800元/座，需要补助资金338.4万元。共计需补助资金1004.62万元。

2.2020年农村无害化卫生户厕改建任务数5432座，县级补助1100元/座，需要补助资金597.52万元；卫生户厕4230座，县级补助800元/座，需要补助资金338.4万元。共计需补助资金935.92万元。

（三）项目实施安排。农村户厕改造建设项目由各乡镇根据县级下达目标任务数，按照补助标准编制项目，上报研究审批后组织实施。

（四）补助方式。项目资金由各项目实施乡镇按照“先建后补”方式进行补助。每年12月底，各乡镇项目实施完成后，由乡镇向县农村“厕所革命”工作领导小组提出验收申请，领导小组组织县财政局、县农科局、县卫生健康局、县扶贫办、县爱卫办等部门按照《云南省农村厕所改建验收办法》等相关标准要求组织验收，经验收合格的农村户厕由项目实施的乡镇按照补助标准进行补助。

三、强化资金监管和绩效管理

项目资金主要用于2019年至2020年农村无害化卫生户厕和卫生户厕新建或改造补助。2019年以前实施的农村户厕已纳入财政奖补或已获得财政资金补助的农村厕所，不得重复补助。

各乡镇要切实加强项目资金的监管，按照资金管理办法组织项目实施，每个项目按年度认真组织绩效申请、绩效执行监控及绩效自评，并将评价结果上报县农村“厕所革命”工作领导小组开展绩效评价后，上报省、州财政部门备案。
