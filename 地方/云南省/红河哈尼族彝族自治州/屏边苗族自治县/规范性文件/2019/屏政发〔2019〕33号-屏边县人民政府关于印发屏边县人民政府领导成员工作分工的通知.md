# 屏边县人民政府关于印发屏边县人民政府领导成员工作分工的通知

各乡镇人民政府，县属各部门：

因机构改革和工作需要，并报上级党委备案同意，现将《屏边县人民政府领导成员工作分工》印发你们，请按此分工范围联系工作。

2019年5月31日

（此件公开发布）

屏边县人民政府领导成员工作分工方案

根据《中华人民共和国宪法》、《中华人民共和国地方各级人民代表大会和地方各级人民政府组织法》、《屏边苗族自治县人民政府工作规则》规定，县人民政府实行县长负责制，县人民政府其他领导成员协助县长工作，并按照分工负责处理分管工作。

县长李雄文同志：领导并主持县人民政府全面工作。负责审计工作，分管县人民政府办公室。

常务副县长吴显贵同志：负责县人民政府常务工作。负责发展和改革、人事社保、自然资源、市政建设、生态环境、应急管理、人民防空、提升城乡人居环境行动、通信保障等工作。

分管县发展和改革局（含县粮食和物资储备局）、县人力资源和社会保障局、县自然资源局、州生态环境局屏边分局、县住房和城乡建设局（含县人民防空办公室）、县应急管理局、县地震局、县搬迁安置办公室、县人大代表建议办理工作。联系县人大常委会、县委老干部局、县消防大队、云南电网有限责任公司红河屏边供电局、中国电信屏边分公司、中国移动屏边分公司、中国联通屏边分公司、中国邮政集团公司屏边分公司、云南广电网络屏边支公司。

副县长许春平同志：负责公安、社会稳定、退役军人事务、双拥、信访、道路交通安全、打击走私等工作。

分管县公安局、县司法局、县退役军人事务局、县信访局、县打私办、县道路交通安全委员会。

联系县法院、县检察院、县人武部、驻屏人民解放军和武警部队、屏边火车站派出所。

副县长陈镇同志：负责农业农村、重大动物疫病防控、科技、两烟、自然资源公安、大围山管理等工作。

分管县农业农村和科学技术局、县水务局、县林业和草原局、县自然资源公安局、大围山屏边管理分局、县政协提案办理工作，协助县长分管县审计局。

联系县政协、县科协、县气象局、县烟草公司。

副县长汪晋云同志：负责扶贫开发、民政、统计、政务服务等工作。

分管县政府扶贫开发办公室、县民政局、县统计局、县政务服务管理局（含县行政审批局、县公共资源交易管理局）。

副县长李秀英同志：负责教育体育、民族宗教、卫生健康、医疗保障、残疾人等工作。

分管县教育体育局、县民族宗教事务局、县卫生健康局（含县中医药管理局、县防治艾滋病局）、县医疗保障局、县残联、县爱卫办、县红十字会、县行政学校、县妇儿工委。

联系县总工会、团县委、县妇联、县中华职教社、老年体协。

副县长万执政同志：负责工商经济、财税金融、交通运输、文化旅游、市场流通及监督、供销、投资促进、机关事务、苗文化研究等工作。

分管县工业商务和信息化局、县财政局（含县政府金融管理办公室）、县交通运输局、县文化和旅游局、县市场监督管理局、县供销社、县投资促进局、县机关事务局、县苗文化研究中心。

联系县文联、县税务局、县人行、县农行、县联社、县工商联、屏边公路路政管理大队、红河公路管理局屏边分局、屏边县道路运输管理局、屏边火车站、县财产保险公司、县人寿保险公司、红河州住房公积金管理中心屏边管理部、县石油分公司、县石化分公司、宏达汽车运输公司。

副县长李洪新同志（挂职）：协助分管脱贫攻坚工作，负责中信集团公司对口帮扶工作，协助分管县政府扶贫开发办公室。

副县长秦晓光同志（挂职）：负责森林城市创建工作，协助分管县林业和草原局、县自然资源公安局、大围山屏边管理分局。

副县长萧兆铭同志（挂职）：协助分管脱贫攻坚工作，负责东西部扶贫协作上海市徐汇区援助工作，协助分管县政府扶贫开发办公室、县文化和旅游局、县投资促进局。

副县长林浩同志（挂职）：负责政务督查、政务公开、外事等工作。

分管县人民政府外事办公室、督查工作，协助分管县发展和改革局、县司法局、县政务服务管理局（含县行政审批局、县公共资源交易管理局）、县信访局，协助联系县法院、县检察院。

副县长杨洪涛同志（挂职）：协助分管脱贫攻坚工作，协助分管县政府扶贫开发办公室、县人力资源和社会保障局、县医疗保障局。

副县长林增伟同志（挂职）：协助分管脱贫攻坚工作，协助分管县政府扶贫开发办公室、县农业农村和科学技术局。
