# 屏边县人民政府关于县人民政府领导班子成员分工调整的通知

各乡镇人民政府，县属各部门：

《屏边县人民政府领导班子成员工作分工》已经2019年县政府党组第12次会议研究，并报上级党委备案同意，现印发给你们，请按此联系工作。

2019年12月3日

（此件公开发布）

屏边县人民政府领导班子成员工作分工

根据《中华人民共和国宪法》《中华人民共和国地方各级人民代表大会和地方各级人民政府组织法》《屏边苗族自治县人民政府工作规则》规定，县人民政府实行县长负责制，县人民政府其他领导成员协助县长工作，并按照分工负责处理分管工作。

县长李雄文同志：领导并主持县人民政府全面工作。负责审计工作，分管县人民政府办公室。

常务副县长吴显贵同志：负责县人民政府常务工作。负责发展和改革、人事社保、自然资源、市政建设、生态环境、应急管理、政务服务、人民防空、提升城乡人居环境行动、通信保障等工作。

分管县发展和改革局（含县粮食和物资储备局）、县人力资源和社会保障局、县自然资源局、州生态环境局屏边分局、县住房和城乡建设局（含县人民防空办公室）、县应急管理局、县政务服务管理局（含县行政审批局、县公共资源交易管理局）、县地震局、县搬迁安置办公室、县人大代表建议办理工作。

联系县人大常委会、县委老干部局、县消防救援大队、云南电网有限责任公司红河屏边供电局、中国电信屏边分公司、中国移动屏边分公司、中国联通屏边分公司、中国邮政集团公司屏边分公司、云南广电网络屏边支公司。

副县长许春平同志：负责公安、社会稳定、信访、道路交通安全、打击走私等工作。

分管县公安局、县司法局、县信访局、县打私办、县道路交通安全委员会。

联系县法院、县检察院、屏边火车站派出所。

副县长陈镇同志：负责水务、林业和草原、供销、大围山管理、自然资源公安等工作。

分管县水务局、县林业和草原局、县供销社、大围山屏边管理分局、县自然资源公安局、县政协提案办理工作，协助县长分管县审计局。

联系县政协、县气象局。

副县长汪晋云同志：负责扶贫开发、民政、退役军人事务、双拥、统计等工作。

分管县政府扶贫开发办公室、县民政局、县退役军人事务局、县统计局。

联系县人武部、驻屏人民解放军和武警部队。

副县长李秀英同志：负责教育体育、民族宗教、卫生健康、医疗保障、残疾人等工作。

分管县教育体育局、县民族宗教事务局、县卫生健康局（含县中医药管理局、县防治艾滋病局）、县医疗保障局、县残联、县爱卫办、县红十字会、县行政学校、县妇儿工委。

联系县党史研究和地方志编撰办公室、县总工会、团县委、县妇联、县中华职教社、老年体协。

副县长万执政同志：负责工商经济、财税金融、交通运输、农业农村、文化旅游、市场流通及监督、投资促进、机关事务、重大动物疫病防控、科技、两烟、苗文化研究等工作。

分管县工业商务和信息化局、县财政局（含县政府金融管理办公室）、县交通运输局、县农业农村和科学技术局、县文化和旅游局、县市场监督管理局、县投资促进局、县机关事务局、县苗文化研究中心。

联系县工商联、县文联、县科协、县税务局、县人行、县农行、县联社、县烟草公司、屏边公路路政管理大队、红河公路管理局屏边分局、屏边县道路运输管理局、屏边火车站、县财产保险公司、县人寿保险公司、红河州住房公积金管理中心屏边管理部、县石油分公司、县石化分公司、宏达汽车运输公司。

副县长王立同志（挂职）：协助分管脱贫攻坚工作，负责中信集团公司对口帮扶、政务督查、政务公开、外事工作。

分管县政府政务督查、政务公开、外事办公室，协助分管县政府扶贫开发办公室、县投融资工作。

副县长周浩波同志（挂职）：协助分管脱贫攻坚工作，负责东西部扶贫协作上海市徐汇区援助工作，协助分管县政府扶贫开发办公室、县文化和旅游局、县投资促进局。
