# 中央财政资金补助的建水县体育馆2018年开放工作方案

根据《体育总局办公厅关于做好2018年大型体育场馆免费或低收费开放工作有关事宜的通知》（体群字【2018】49号）要求，现将建水县体育馆2018年免费或低收费开放工作方案公布如下：

一、建水县体育馆简介

建水县体育运动中心体育馆位于红河州建水县城区清远路与翠屏路交叉口，隶属建水县文化体育和广播电视局。它是一个集体育竞技、文艺演出、健身娱乐展示为一体的大型综合性体育馆。该馆于2012年8月竣工，总投资达2696万元,占地面积3463平方米，建筑面积6028平方米，有座位3000个及运动员、裁判员休息室、更衣室等配套服务功能设施。体育馆内设灯光、音响、显示屏等，可举行篮球、排球、乒乓球、羽毛球等体育赛事，同时可承办中型文艺演出、商业会展等。体育馆建成后，承接过州政协系统、州人大系统、电力系统、农业系统等职工运动会及县级各类体育比赛及文艺演出。

建水县体育馆周边外围体育场地于2012年8月同时建成，总面积2000平方米。

二、免费或低收费开放项目、开放时间及收费标准

（一）开放项目和场地

建水县体育馆平时开放项目有：篮球、羽毛球、健身房。

开放场地：体育馆内篮球场、羽毛球场地及馆内各功能室。

建水县体育馆周边外围体育场地开放项目有：篮球、羽毛球、乒乓球、健身、太极拳、网球、广场舞、健身路径等。

（二）开放时间

建水县体育运动中心体育馆设施全年免费或低收费开放，开放天数达360天以上，开放时段为：羽毛球：低收费时段7:00—10:00（15元/时/场）；14:00—17:00（15元/时/场）；19:00—23:00（20元/时/场）。免费开放时段：免费开放时段为10：00—14:00；17:00—19:00。（全民健身日和举办各项比赛、活动免费开放）篮球：低收费时段8:00—23:00（400元/场）临时约定安排。健身房：低收费时段8:00—23:00（10元/时/人）。

建水县体育馆每周开放时间达112小时，除免费低收费开放外，积极承办各级各类赛事、群众性体育活动、各类演出、讲座和展览等活动,较好地发挥了场馆的社会效益。

四、群众参加体育赛事和体育活动、接收体育培训、进行日常健身服务情况

（一）室内体育场地

体育馆计划全年接待不低于5万人次，月均接待不低于4100人次，日均接待不低于140人次，全年室内体育馆场地每万平米均接待不低于55万人次。

（二）室外体育场地

体育馆外围场地核心区计划全年接待不低于15万人次，月均接待不低于12500人次，日均接待不低于400人次，全年室内体育馆场地每万平米均接待不低于75万人次。

五、为群众身边的体育组织服务情况

截至2018年底，体育馆将为 8 个运动项目俱乐部（群众体育组织）提供活动场所，会员总人数达到 60000人。

2018年体育馆开放成本支出预计最低 89万元，其中人工、水电气热能耗、小型维修维护等支出最低为28万元。
