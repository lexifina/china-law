# 建水县2018年秋季至2019年春季学期雨露计划项目资助对象公告（2019年第二批次）

按照建水县扶贫开发领导小组办公室《关于进一步做好雨露计划补助情况核实工作的通知》（建开组办便签〔2019〕21号）文件要求，各乡镇对辖区范围内符合条件的建档立卡贫困家庭学生再次深入排查，积极动员学生申报。按照“户申请、村推荐、乡审核、县复核”程序，经逐级审核、公示，我县建档立卡贫困家庭中共有156名中、高职在校学生符合项目资助条件。根据《建水县扶贫开发领导小组办公室关于划拨建水县2018年度“雨露计划”项目第二批次补助资金的通知》（建开组办便笺〔2019〕51号）要求，各乡镇及时将补助资金兑付到建档立卡贫困家庭。现将建水县2018年秋季至2019年春季学期雨露计划项目资金分配表及资助学生花名册进行公告。

公告起止时间：2019年5月23 日—2019年6月1日。
