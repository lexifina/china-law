# 建水县人民政府办公室关于2019年第四季度网站与政务新媒体检查情况通报

各乡镇人民政府，县属各办、局：

根据国务院办公厅、省政府办公厅关于政府网站与政务新媒体检查的有关精神，对照《云南省人民政府办公厅关于印发云南省政府网站与政务新媒体监管工作年度考核指标的通知》要求，县政府办公室组织开展了2019年四季度县政府网站与全县政务新媒体运行情况检查。现将检查情况通报如下：

一、总体情况

（一）政府网站自查情况。2019年四季度，建水县人民政府门户网站已按考核指标要求做好运维工作，在国务院办公厅的抽查和省政府办公厅开展的季度普查中未出现单项否决相关情形，并严格按要求实时更新网站专栏信息。

（二）政务新媒体检查情况。2019年四季度，共检查乡镇、部门继续留用的政务新媒体20个，其中乡镇6个，部门14个。临安镇“魅力临安”、曲江镇“田园曲江山水氡泉”、南庄镇“葡萄名镇毓秀南庄”、西庄镇“爱善西庄”、官厅镇“活力官厅”、县综合执法局“建水城市管理”微信公众号和县司法局“云南建水司法行政”新浪微博未严格按照每两周发布一次原创信息的要求进行更新。

（三）网民留言办理情况。截至2019年12月12日，“我为政府网站找错”平台、政民互动平台收到的信件未出现超时办理情况。

二、工作要求

（一）重视网站及政务新媒体维护工作。各乡镇、各部门要以认真负责的态度，踏实严谨的作风配合做好政府网站运行维护工作，做好政务新媒体运行维护工作，认真对照政府网站、政务新媒体检查指标，逐项排查存在问题，确保政府网站、政务新媒体健康有序发展。

（二）加强内容维护工作。增加稿件发布量及频率，更新频率低的网站栏目建议合并优化，避免空白栏目出现。对存在更新慢、不更新、回复敷衍、言论不当等问题的政务新媒体要及时规范整改，确属无力运行维护的要坚决予以关停。

（三）狠抓信息发布审核工作。各乡镇、各部门务必高度重视政府门户网站、政务新媒体信息发布的重要性和严肃性，强化信息发布前审查和信息发布后检查工作，通过优化人工审核流程、及时跟踪网民留言方式，多措并举层层把关，杜绝错别字、漏字情况。

各乡镇、各部门务必高度重视工作中出现的问题，严格落实主体责任，开展自查自纠，制定有效措施逐项整改。请存在问题的部门于2019年12月20日前完成整改工作，并将整改情况报县政府办公室。
