# 开远市人民政府办公室关于成立热电汽循环利用产业园大唐片区一组团成员的通知

有关单位：

为进一步推进热电汽循环利用产业园大唐片区建设，加强组织领导，整合工作力量，推动园区项目落地，经市人民政府研究，决定成立热电汽循环利用产业园大唐片区“一组团”成员，现通知如下：

一、“一组团”成员及联系方式

团 长：吴世雄 市人民政府市长

常务副团长：苏宏先 市委常委、常务副市长

副 团 长：范国平 开远经开区管委会主任

团 员：张爱林 市政府办副主任

杨铭寿 市发展改革局副局长

程克炜 市工业商务信息化局副局长

初 涛 市林业局副局长

鲍永亮 市安全生产监督管理局副局长

刘 磊 大唐公司常务副总经理

“一组团”下设办公室在开远经开区管委会，办公室主任由普绍文同志兼任。办公室负责贯彻落实市委、市政府关于热电汽循环利用产业园的决策部署，管理日常事务，定期或不定期向团长汇报工作进展情况；组织、协调推进热电汽循环利用产业园工作，并对各项工作实施情况进行监督检查，统筹解决工作开展过程中遇到的问题和困难，并做好资料档案管理工作。

今后凡涉及热电汽循环利用产业园项目的工作，均由调整后的“一组团”负责统筹推进，如领导小组成员发生变动，由接任其职务的人员自行递补，不再另行发文。

二、“一组团”部门工作职责

市政府办职责：1．负责对园区建设及项目推进情况进行督查；2．负责对“一组团”团长交办事项进行落实及反馈。

开远经开区管委会职责：做好项目建设协调服务工作，确保项目尽快落地，顺利推进。

市发展改革局职责：1．负责对园区项目业主办理备案手续进行具体指导和服务。对符合国家产业政策在市级权限备案的项目，申办材料齐全，2个工作日内办理备案手续；2．需上级部门审批的项目，负责积极协调省州对口业务部门，加快项目审批进度；3．负责争取符合国家投资导向项目列入国家资金支持盘子。

市工业商务信息化局职责：1．负责协调省州对口业务部门，加快项目业主申报相关政策的审批进度；2．在项目建设和推进中，履行好本部门能源协调和服务职能。

市国土资源局职责：做好辖区内土地调规、用地报批及供地工作。

市环境保护局职责：1．根据《中华人民共和国环境影响评价法》《云南省建设项目环境保护分级管理规定》，对园区项目指导开展环境评价和审批；2．对园区业主申报的涉环保许可的相关资料进行具体的指导和服务；3．在本部门受理审批的权限内，最短时间完成项目业主申报审批环保许可手续的办理；4．对上级审批的项目，负责协调省州对口业务部门，加快项目环保审批进度；5．在园区建设和项目推进中，履行好环境监察和环保“三同时”落实期间的跟踪监管和服务。

市住房城乡建设局职责：1．负责园区自来水供给工作；2．负责园区项目工程质量监督管理工作。

市交通运输局职责：根据园区建设及发展需要，逐渐加强对园区周边交通规划。

市林业局职责：1．对园区项目业主申报建设项目使用林地审核审批手续进行指导和服务；2．在本部门受理审批权限内，最短时限完成项目业主申报审批使用林地手续的办理；3．负责协调省、州对口业务部门，加快项目业主已申报的建设项目使用林地审核审批进度；4．在园区建设和项目推进中，履行好本部门森林资源管理和服务职能。

市水务局职责：1．负责对园区项目业主中标水土保持方案的编制，评审进行具体指导和服务。2．在本部门受审批权限内，最短时限完成水保方案的评审和审批手续的办理。

市市场监督管理局职责：1．负责受理审批园区项目业主办理营业执照的申请，对食品生产许可申请材料进行初审和厂房布局、设备安装、工艺流程、质量控制等具体指导；2．在本部门受理审批权限内，最短时限完成项目业主申报审批相关手续的办理；3．负责协调省州对口业务部门，加快项目业主已申报的行政审批进度；4．在园区建设和项目推进中，履行好本部门食品安全、产品质量、计量器具、特种设备等日常监管职能。

市安全生产监督管理局职责：1．负责对园区项目业主申报建设项目安全设施及职业卫生“三同时”审批手续进行具体指导和服务；2．在本部门受理审批权限内，最短时限完成项目业主申报审批建设项目安全设施及职业卫生“三同时”手续的办理；3．负责协调省州安全生产监督管理局，加快项目业主已申报的建设项目安全设施及职业卫生“三同时”审批进度；4．在园区建设和项目推进中，履行好市安监局安全生产管理和服务职能。

灵泉街道办事处职责：1．积极配合市级职能部门和大唐公司做好相关工作；2．按照项目推进进展情况及时提供土地。

大唐公司职责：1．负责对园区内招商引资项目进行供汽、供水、供电等合作参数的协商；2．负责与上级公司协调，完成改造项目的审批手续办理；3．负责对供汽、供水、供电机组进行技术改造并修建热网站至园区范围；4．在园区建设和项目推进中，履行好公司服务职能，积极配合并协助项目推进。
