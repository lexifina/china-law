# 开远市人民政府关于对2015年度科技进步奖进行奖励的决定

各乡镇人民政府（街道办事处），各办、局：

为认真贯彻落实党的十八大和十八届三中、四中、五中、六中全会、全国科技创新大会精神，深入实施创新驱动发展战略，加快建设创新型开远，根据《开远市科学技术进步奖励办法》（开政发〔2002〕40号）规定，经市科技进步奖评审委员会严格评审，并按有关规定进行公示，授予“合成塔电炉电极杆密封技术研究及应用”1项科技成果为2015年度开远市科技进步一等奖；授予“基于行业标准的中职汽修专业理实一体化教学研究 ”等2项科技成果为2015年度开远市科技进步二等奖；授予“髂内动脉预置球囊防止凶险型前置胎盘剖宫产术中大出血的临床应用”等7项科技成果为2015年度开远市科技进步三等奖。

希望获奖单位和个人在今后的工作中戒骄戒躁、再接再厉，勇于探索创新，争取获得更大的成果。全市各部门及广大科技工作者要虚心向获奖者学习，继续发扬求真务实、勇于创新的精神，进一步解放思想、更新观念，增强科技创新积极性、主动性，充分发挥科技在经济社会发展中的引导和推动作用，逐步提升全市自主创新能力和核心竞争力，努力为推进开远科学发展、和谐发展、跨越发展作出新贡献。
