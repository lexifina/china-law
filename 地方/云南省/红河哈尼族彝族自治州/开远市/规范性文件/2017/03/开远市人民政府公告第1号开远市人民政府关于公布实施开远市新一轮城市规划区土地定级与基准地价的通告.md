# 开远市人民政府公告第1号开远市人民政府关于公布实施开远市新一轮城市规划区土地定级与基准地价的通告

现公布《开远市人民政府关于公布实施开远市新一轮城市规划区土地定级与基准地价的通告》，本通告自2017年3月9日起施行，有效期至2022年3月8日。

2017年2月9日

开远市人民政府关于

公布实施开远市新一轮城市规划区

土地定级与基准地价的通告

为认真执行国有土地有偿使用制度和城市基准地价定期更新制度，加强土地市场管理，充分发挥土地价格在市场经济中的宏观调控作用，根据《城镇土地分等定级规程》和《城镇土地估价规程》，结合我市实际，开远市人民政府组织相关部门开展完成了全市第六轮城市规划区49.73平方公里的土地定级与基准地价测算更新工作，工作成果已通过云南省国土资源厅组织的省级验收。经市人民政府批准，市人民政府法制办公室登记（登记编号：开府规登7号），现公布更新后的开远市城市规划区土地定级与基准地价，更新后的城市规划区土地定级与基准地价自2017年3月9日起施行，有效期至2022年3月8日。开远市人民政府于2016年5月5日发布的《开远市人民政府关于公布实施更新后的开远市城市规划区土地级别和基准地价的通告》同时废止。
