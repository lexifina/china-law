# 开远市人民政府办公室关于印发开远市贯彻落实红河州人民政府办公室2018年政务公开工作要点分工方案的通知

各乡镇人民政府（街道办事处），各办、局：

根据《云南省人民政府办公厅关于印发云南省贯彻落实国务院办公厅2018年政务公开工作要点分工方案的通知》（云政办发〔2018〕36号）、《红河州人民政府办公室关于印发红河州贯彻落实省政府办公厅2018年政务公开工作要点分工方案》（红政办函〔2018〕31号）的要求，结合开远政务公开工作实际，开远市人民政府办公室提出的《开远市贯彻落实红河州人民政府办公室2018年政务公开工作要点分工方案》（以下简称方案）已经市人民政府同意，现印发给你们，请结合以下工作要求，认真贯彻执行，执行中若发现问题，及时反馈。

一、加强组织领导，推动政务公开工作落实

推进政务公开是全面贯彻党的十九大和十九届二中、三中全会精神，促进法治政府、创新政府、廉洁政府和服务型政府建设的重要举措和必然要求，是各级政府及其工作部门义不容辞的法定责任。各部门要以习近平新时代中国特色社会主义思想为指引，深入贯彻落实党中央、国务院和省委、省政府、州委、州政府重要决策部署，切实将全面推进政务公开工作列入重要议事日程，真正把政务公开工作与本部门的中心工作同研究、同部署、同考核、同推进，着力加强公开解读回应工作，着力提升政务服务工作实效，着力强化公开平台建设管理，着力推进政务公开制度化规范化，确保《方案》明确的各项工作任务落实到位。各部门主要负责同志每年至少听取1次政务公开工作情况汇报，研究部置相关推进工作；确定1位负责同志分管政务公开工作，列入工作分工并对外发布；各部门要进一步明确政务公开工作承担机构，配齐配强专（兼）职工作人员，分管负责人及其直接责任人员应履行职责到位，扎实工作，真正发挥作用。对未明确工作承担机构和工作负责人员的部门，将在政务公开年度综合考评中实行“一票否决”。

二、细化工作任务，切实把《方案》做实做细做到位

各部门要认真组织学习研究《方案》，做到学深学透、学有所思、学有所获、学有所用，尽快熟悉掌握方案重点工作内容、工作进度、完成时限等具体要求，并学会和提高在研究学习中推进落实工作的本领和水平；有关责任部门要严格对照《方案》进一步细化分解任务，将各项任务和责任落实到具体科室和具体责任人，防止出现工作遗漏；有关牵头部门要按照“谁牵头负责、谁组织落实”的原则，强化工作组织落实意识，加强统筹协调，主动与相关协助部门沟通交流协商，形成工作合力，齐心协力的共同推进各项工作；各责任部门要紧扣《方案》明确的工作任务要求，分管负责同志要及时掌握工作进度，及时协调解决遇到的困难和问题，严格按时限推进落实，确保《方案》确定的各项目标任务顺利完成。

三、压实工作责任，强化督促检查考评

各责任部门要切实担当起政务公开工作组织推动落实、统筹协调、督促检查主体责任。加强对政务公开工作的领导、督促、检查和落实工作，始终坚持事前谋划、事中督导检查、事后总结考核总体工作流程，扎扎实实地将本部门政务公开各项工作落到实处。

按照积极适应新时代、新担当、新作为的要求，市政府将把政府信息公开、重要政策解读、依申请公开、回应公众关切、扩大公众参与、平台渠道建设管理等公开业务工作开展情况，作为年度目标管理绩效考评和政务督查重要核心工作内容，进一步强化督查督导，跟踪问效，压实主体责任，全面从严考评，加强定期或不定期检查和专项动态督办，并适时进行工作落实情况通报，务求《方案》落地见效，力争做到事事有着落、项项有结果；各责任部门要坚持问题导向，认真对照2013年以来中央、省、州相关政府信息与政务公开工作要点，组织开展“回头看”，查找本部门在行政执法、财政资金、公共资源配置、公共服务、公共监管等重点领域和关键环节信息公开存在的问题，对查找出的问题进行分析研究，拿出过硬有效的整改措施和办法，补齐政务公开工作方面的短板；各相关部门要牢固树立以“人民为中心”的发展思想和“公开是常态，不公开是例外”的意识和理念，结合部门开展的各项工作，严格按照“决策公开、执行公开、管理公开、服务公开、结果公开”（简称“五公开”）的要求，及时、全面、准确的在所负责的市政府门户网站重点领域政府信息公开专栏和相应栏目主动公开政府信息，真正让人民群众在政务公开工作中享受到更多的获得感，保障群众知情权。

各乡镇（街道办事处）请根据今年工作要点，结合各自乡镇实际情况，对照制定乡镇2018年政务公开工作要点分工方案，并认真组织实施。各部门、乡镇（街道办事处）的年度政务公开工作要点落实情况，请于2018年11月28日前报市政府办公室。市政府办公室将适时开展专项督查，全面推进政务公开工作的落实。
