# 河口县人民政府关于印发河口县登革热应急处置预案的通知

各乡镇人民政府，县委和县级国家机关各部委办局，各人民团体，各农场，驻河口的中央、省、州属有关单位：

登革热为《中华人民共和国传染病防治法》规定的乙类传染病，是由登革病毒感染引起的急性传染病，与我县接壤的越南是登革热疫情高发区。为指导我县早发现、早诊断、正确处置疫情，有效控制登革热疫情的发生和蔓延。现将《河口县登革热应急处置预案》印发你们，请认真贯彻执行。

河口瑶族自治县人民政府

2017年8月21日

河口县登革热应急处置预案

登革热是由登革病毒引起、经伊蚊传播的急性传染病。由于登革热传播迅猛，发病率高，登革出血热和登革休克综合征的病死率较高，不仅严重影响人民的健康而且严重影响当地经济开发和旅游贸易事业的发展，为有效预防和控制登革热的发生和流行，保护人民群众的生命与健康保障人民群众健康，促进经济社会的稳定发展。根据《中华人民共和国传染病防治法》、《突发公共卫生事件应急条例》、《突发公共卫生事件与传染病疫情监测信息报告管理办法》等法律法规及《云南省登革热监测与防控方案》，结合我县实际，特制定本预案。

一、目的

确保一旦发生登革热重大突发疫情、及时采取有效措施，迅速控制和扑灭疫情。

二、预警与分级

依据登革热病例发生数、疫情扩散速度、流行范围和趋势，将疫情划分为四个预警等级。

（一）Ⅳ级预警：周边县（市）或境外相邻地区发生登革热疫情。

（二）Ⅲ级预警：以县为单位，有输入性登革热病例1例。

（三）Ⅱ级预警：在人口相对集中的地点（例如一个社区、学校、村庄）15日内发生登革热病例3例以上；同一州（市）2个以上县发生病例；因输入性病例导致局部地区流行；特殊情况需要定为Ⅱ级的。

（四）Ⅰ级预警：短期内发生较大范围的流行；15日内2个以上州（市）发生登革热流行；特殊情况需要定为Ⅰ级的。

三、应急反应

（一）Ⅳ级反应

县疾病预防控制中心启动Ⅳ级反应，组织人员进行个案调查及疫区处理；医院组织救治病人；县疾控中心向县卫生和计划生育局和省寄生虫病防治所报告疫情和处理情况。

（二）Ⅲ级反应

县卫计局成立领导小组，组织疫情控制工作并报告县人民政府批准启动Ⅲ级反应；县疾病预防控制中心组织专业技术组进行个案调查及疫区处理，控制疫情的扩散；医院组织力量救治病人；县卫计局立即向县人民政府及州卫生计生委、省寄生虫病防治所报告疫情和疫情处理情况。

（三）Ⅱ级反应

县卫计局立即向县人民政府及州卫生计生委上报疫情；州卫生计生委立即向州人民政府报告批准启动Ⅱ级反应，并组织成立领导小组、专业技术小组，组织实施疫情控制工作；州、县疾病预防控制中心组织专业技术组进行个案调查和疫区处理，控制疫情的蔓延；医院组织力量救治病人；省卫生计生委接到疫情报告后，立即组织专业技术组，赶赴疫区进行技术指导，并向上一级卫生计生委、人民政府报告疫情和疫情处理情况。

（四）Ⅰ级反应

县卫计局立即向县人民政府及州卫生计生委报告疫情；省卫生计生委接到Ⅰ级疫情后立即向省人民政府报告批准启动Ⅰ级反应，并成立领导指挥小组、专业技术指导小组，组织指挥疫情控制工作。疫情控制工作在二级反应的基础上做好以下工作：

1.县人民政府立即成立领导小组，组织实施本县的疫情控制工作。

2.县疾病预防控制中心成立专业技术组进行个案调查和疫区处理，控制疫情蔓延；

3.医院根据医疗救治的需要，组织力量救治病人，动员本地所有医疗机构做好收治病人的准备；

4.县卫计局和政府部门做好物资、资金等给予疫情发生地紧急支持；

5.省、州卫生计生委接到疫情报告后，立即组织专业技术指导组，赶赴疫区进行防治指导及疫情控制处理；

6.省级卫生计生委及时向国家卫生计生委、人民政府报告疫情和疫情控制情况。

四、部门工作职责

（一）县卫计局

做好各辖区常规防控和疫情处置技术指导，开展技术培训；组织开展伊蚊媒介和病例监测，病例救治，流行病学调查，定期开展风险评估、预测和预警工作；参与政府组织的督导督查。指导开展样本采集、运送和病原检测工作。

（二）县爱卫办

主要负责组织协调爱卫会成员单位开展以防蚊灭蚊为重点的爱国卫生运动；积极发动各级各部门和广大群众开展以清除蚊虫孳生地为主要内容的环境综合整治活动，对各单位部门、乡镇、农场和社区防蚊灭蚊工作落实情况进行督促检查。

（三）县委宣传部

主要结合秋冬爱国卫生运动，深入开展健康教育，充分利用大众媒体，多形式、多层次、多渠道普及登革热防治知识，宣传卫生防病常识，倡导文明健康生活方式，增强群众防蚊灭蚊、预防疾病的意识和应对能力。定期开展预防控制登革热宣传，组织电视台等新闻媒体，加强全县“清洁家园，灭蚊防病”的公益宣传，做到家喻户晓，人人皆知，使群众自觉参与防治登革热行动。

（四）河口出入境检验检疫局

负责对出入境人员的检疫，发现病人或疑似病人及时转诊到定点医疗机构防蚊治疗，并及时向县疾控中心通报。根据境外登革热疫情情况对出境人员（旅游、劳务、商务等）进行预防知识的宣传教育。

（五）县住建局

加强城区绿化带、公园、市政工程和房屋建筑工地的环境卫生管理，组织开展环境卫生治理工作，及时清理各类积水、垃圾以及卫生死角，彻底清除蚊虫孳生地；加强对风景名胜区、公园、市政工程和房屋建筑工地有关人员的宣传教育，做到有病及时就医，及时报告；加强对物业管理企业人员的宣传和培训，督促小区物管部门聘请专业消杀队伍有效开展灭蚊行动，协助社区、村委会做好蚊虫孳生地清理工作；清疏城镇河道、城镇下水道和沙井，确保水流畅通，有效控制蚊虫孳生。

（六）县教育局

负责督促各类学校和幼儿机构搞好环境卫生，开展爱国卫生运动，全面灭蚊并清除蚊虫孳生地。组织学校做好疫区来华留学生登革热监测工作；做好在校学生、教职工的宣传教育和自我防护工作；组织中小学、幼儿园开展“小手拉大手”活动；动员学生家长配合做好清积水、灭蚊虫工作。

（七）县水务局

做好农村改水、河道卫生治理，组织疏通沟渠，清除河道淤积。结合水利工程和农村饮水安全工程建设，配合有关部门做好预防控制登革热的传播。

（八）县市场监督管理局

负责公共场所、城乡结合部及综合市场的监督管理，配合相关部门做好爱国卫生运动、灭蚊喷洒及疫情处置工作；负责登革热疫情应急处理药品、医疗设备和器械的监督和管理。并对个体工商户、废旧轮胎收理场、各类集贸市场和小旅社的防病知识宣传，对各类集贸市场、宾馆酒店、小旅社业主灭蚊和消除蚊媒孳生地工作落实情况进行督促指导。

（九）县林业局

负责对全县木材加工企业的防病知识宣传，对各加工企业开展灭蚊和消除蚊媒孳生地工作落实情况进行督促检查，确保其经营范围内的布雷图指数控制在5以下。督促业主加强对境外从事木材加工务工人员的管理，并提供必要的防蚊设施。

（十）县公安局

依法、及时、妥善地处置与疫情有关的突发事件，查处打击违法犯罪活动，维护社会稳定。必要时协助卫生计生行政部门落实强制措施，负责辖区出租房业主和住户的防病知识宣传，确保其经营范围内的布雷图指数控制在5以下；协助相关部门开展入户宣传工作。

（十一）县外事侨务办

负责对外联络，加强中越双边的联防联控协调工作，建立跨境联防联控工作机制，做到防控关口外移，及时、定期互通疫情信息。做好涉外企业、内贸企业和外出务工人员的宣传工作，出境务工要做好防蚊措施，入境后要及时到当地医疗卫生机构进行排查，并密切观察，如有发热及时到正规医疗机构就诊。

（十二）县旅发委

负责出境旅游人员防病知识的宣传并督促其采取必要的防蚊措施。督促指导各旅游宾馆、文化娱乐场所、景区认真落实好灭蚊和消除蚊媒孳生地各项措施，确保其经营范围内的布雷图指数控制在5以下。

（十三）县国土局

负责城区未开工建设已售空地的监管，督促业主对空地采取必要的防蚊、灭蚊措施，确保布雷图指数控制在5以下。

（十四）县财政局

负责登革热防控工作经费保障的监测、预测、疫情处置、培训、科研、演练和事件处置所需的设备、器材、药品等经费；储备登革热疫情应急处置经费；做好经费使用情况监督检查工作。

（十五）县监察局

负责对各级各部门落实登革热防控措施情况进行督促检查。对在登革热防控工作中玩忽职守、失职、渎职的单位和个人，给予严惩；对造成登革热传播流行后果严重的，严肃追究相关人员责任。

（十六）各乡镇、农场

各乡（镇）政府、农场是辖区登革热防控工作的基层主要组织管理和执行机构，负责组织发动和督促本辖区开展爱国卫生运动，定期清理卫生死角，清除积水，做好防蚊灭蚊工作，消除室内外蚊媒孳生地等网格化管理工作措施的具体落实，确保达到蚊媒控制指标；防控工作要覆盖本辖区各居（村）委会、机关团体、单位、住宅小区、公共地带、工地等，并与周边辖区通力协作，确保每一项工作措施落实到位，不留空白、不留死角。

（十七）社区、村委会

负责动员群众积极配合和参与灭蚊行动，适时开展入户清查及宣传工作，发动群众翻盆倒罐，清除室内外伊蚊孳生地。根据县卫计局和专业机构的防控意见，确定蚊媒重点防控地区和场所，开展疫点周边和疫区的灭蚊工作。组织专业队伍、药械，开展疫点、疫区的灭蚊、环境清理、消除孳生地工作。

（十八）县交通运输局

按照废旧轮胎规范储存和管理的要求，加强对机动车维修、轮胎经营维修企业或个人开展监督执法检查，监督和指导企业或个人认真落实废旧轮胎规范储存和管理。

（十九）驻军、驻警

按照属地政府的统一安排部署，落实好单位内部清除积水、成蚊灭杀等工作；加强单位的登革热预防知识的宣传，动员官兵家属共同开展防蚊灭蚊行动；加大边境管控力度，配合有关部门开展疫情处置工作。

（二十）其他部门和单位

严格按照政府有关要求和部门、单位职责，建立工作责任制，制定单位内部登革热的防控方案，做好单位内外环境、外来户及单位职工的管理，定期开展以清除蚊虫孳生地为主的灭蚊消杀工作，落实各项防蚊灭蚊措施。

五、反应终止

根据疫情控制情况和监测结果，末例登革热病例确诊后，25天内无新发病例出现，由专家组提出结束反应，经县卫计局报告县政府和应急领导指挥小组决定，本次应急反应结束。
