# 河口县人民政府办公室关于调整政务公开领导小组的通知

各乡镇人民政府，县直各部门，各农场管委会：

为进一步做好单位政务信息工作，根据《河口县政务公开工作实施方案》要求，经研究决定,对河口县政务公开工作领导小组成员进行调整。现将调整后的成员名单通知如下:

组 长：龙 艳 河口县人民政府副县长

副组长：庞汉元 河口县人民政府办公室主任

成 员: 何 芳 河口县人民政府办公室副主任

杨 燕 河口县人民政府办公室政务公开科科长

邓遵慧 河口县人民政府办公室政务公开科工作人员

领导小组下设办公室在县政府办政务公开科。杨燕同志兼任办公室主任，政务公开科负责统一安排部署协调河口县政务信息公开工作。
