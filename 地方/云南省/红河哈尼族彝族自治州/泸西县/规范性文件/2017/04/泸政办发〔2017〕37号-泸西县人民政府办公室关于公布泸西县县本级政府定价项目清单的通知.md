# 泸西县人民政府办公室关于公布泸西县县本级政府定价项目清单的通知

各乡、镇人民政府，县属各办、局：

为加快完善主要由市场决定价格机制，推动价格改革向纵深发展，根据《中共云南省委　云南省人民政府关于推进价格机制改革的实施意见》（云发〔2016〕34号）和《云南省发展和改革委员会关于印发云南省定价目录的通知》（云发改物价〔2015〕1746号）精神，结合我县实际，对省级定价目录和省级有关文件授权县一级人民政府定价项目清单进行梳理后制定了《泸西县县本级政府定价项目清单》，现予公布，请抓好落实。
