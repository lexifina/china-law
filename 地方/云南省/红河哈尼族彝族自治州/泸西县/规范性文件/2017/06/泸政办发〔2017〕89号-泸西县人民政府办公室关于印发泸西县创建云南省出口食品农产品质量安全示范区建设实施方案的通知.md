# 泸西县人民政府办公室关于印发泸西县创建云南省出口食品农产品质量安全示范区建设实施方案的通知

各乡、镇人民政府，县属有关办、局：

《泸西县创建云南省出口食品农产品质量安全示范区建设实施方案》已经县人民政府研究同意，现印发给你们，请认真贯彻执行。

（此件公开发布）

泸西县人民政府办公室

2017年5月31日

泸西县创建云南省出口食品农产品质量

安全示范区建设实施方案

为提升我县食品农产品质量安全水平，扩大食品农产品出口贸易规模，做好我县创建云南省出口食品农产品质量安全示范区建设工作，制定本实施方案。

一、指导思想

坚持以科学发展观为指导，全面贯彻落实党的十八大以及十八届三中、四中、五中、六中全会精神，围绕提高出口食品农产品质量安全和扩大食品农产品出口规模的总体目标，按照“效益优先、注重生态、强化服务、重在示范”原则，加快建立健全出口食品农产品质量安全公共管理体系，大力推行现代农业生产管理模式，推动我县农产品生产基地实现“科学化、集约化、规模化、标准化”，增强我县食品农产品核心竞争力，努力将泸西打造成面向东南亚的食品农产品出口基地。

二、工作思路和目标

（一）工作思路

依托食品农产品加工出口龙头企业，在重点地域、主要品种、关键环节上实施良好的农业操作规范，推行出口食品农产品标准化种养、生产加工和出口管理，严格区域内农业化学投入品管理，建立健全规范的农业化学投入品“产、供、销、用”全程链式管理机制，在全县范围内建立较为完善的出口食品农产品质量安全公共管理体系，形成具有一定规模、符合出口食品农产品质量安全的种植示范区域。

（二）工作目标

结合我县实际，示范区建设区域布局为：在中枢镇、午街铺镇、金马镇、白水镇四镇建设高原梨、油桃、生菜、油麦菜等食品农产品质量安全示范区18.1万亩。示范区涵盖全县大部分传统大宗出口食品农产品，出口食品农产品企业全部通过检验检疫和质量控制体系认证，全县食品农产品质量安全整体水平明显提升，出口产品合格率达到100%、目标市场要求达到100%、出口蔬菜水果追溯查询达到100%。

三、领导机构和工作职责

（一）领导机构

成立泸西县创建云南省出口食品农产品质量安全示范区建设工作领导小组（以下简称领导小组），领导小组下设办公室在县农业和科学技术局。

（二）工作职责

1. 领导小组工作职责：负责领导出口食品农产品质量安全示范区建设工作；研究制定支持出口食品农产品质量安全示范区建设相关政策措施；负责加大出口食品农产品质量安全示范区对外宣传力度，提高我县农产品在国际国内市场的形象和信誉度；协调解决出口食品农产品质量安全示范区建设推进过程中出现的重大问题。

2. 领导小组办公室职责：制定示范区建设规划和配套规章制度；具体负责做好日常工作；安排部署阶段性工作；对县属有关部门履行示范区建设职责的情况进行监督检查。

（三）相关部门工作职责

县农业和科学技术局：负责制定出口食品农产品质量安全示范区建设推进计划；会同县市场监督管理局、县供销社等部门对农业化学投入品生产企业、经营专营店进行监管；选派技术人员培训指导农产品加工企业、农业合作经济组织和农民，建立规范统一的食品农产品生产田间管理档案和农业化学投入品详细使用档案；负责基地食品农产品病虫害预测预报和绿色防控技术指导；负责加强农业标准化生产技术培训，有计划、有步骤、有重点、分层次地对示范区内农业技术人员、企业基地管理人员和农民进行农业标准化生产技术培训。

县工业商务和信息化局：负责外经贸知识培训，加大对出口企业有关外经贸知识培训力度；负责向出口企业提供出口政策导向、国家优惠政策、国际市场动向等相关信息；负责组织出口产品、出口企业对外招商和推介工作，培育一批出口名牌产品；培育食品农产品出口市场主体，鼓励县内生产加工企业与国内外转港贸易企业合作，并引导其在省内登记注册自营出口，提高对原料生产基地的辐射带动能力。

县财政局：负责示范区建设专项资金安排与监督管理。

县市场监督管理局：负责食品农产品质量安全监管的综合协调、安全事故查处和信息发布；负责农业投入品市场监管；负责食品农产品流通环节的监管；制定出口食品农产品生产地方标准，依法查处农业投入品和食品非法添加等违法行为。

县环境保护局：负责出口示范区种植环境的土壤、水质监测及示范区内生产加工企业建设项目的环境监管。

县公安局：负责农业违法案件查处。

县供销社：做好示范区内化肥、农膜、农药等农业生产投入品的配送、销售工作，带动更多农业生产投入品经销单位高标准服务示范区建设。

乡镇人民政府：积极配合县属有关部门开展工作并按照属地管理原则，负责组织落实本辖区食品农产品质量安全示范区各项工作任务。

四、工作任务

在示范区建立“1种形式+4个体系”的出口食品农产品质量安全区域化综合管理模式，即：推行“以加工企业为龙头、以农民专业合作组织为载体、以种植基地为基础、以标准为核心”的现代农业生产加工组织形式，建立健全“政府质量安全公共管理体系、企业质量安全控制体系、风险预警与快速反应体系、技术服务支撑体系”。

（一）推行现代化农业生产加工组织形式

充分发挥龙头企业作用，鼓励加工企业、基地开展农业合作，实行以“公司+基地+标准化”为主体的生产组织形式，指导示范区基地建立统一管理制度、统一推荐肥料使用、统一病虫害防治、统一农残检测，促进食品农产品生产企业向规模化、集约化、标准化方向发展。（由县农业和科学技术局牵头，县工业商务和信息化局、县供销社等部门配合）

（二）完善政府质量安全公共管理体系

1. 完善农业投入品使用准入监管制度。依照国家有关法律法规，针对示范区产品特点，建立农业投入品公告制度。定期公布并明示示范区允许使用、禁用或限用的农业投入品目录。建立示范区农业投入品市场准入制，制订《示范区准用农业投入品销售专营企业登记备案管理办法》，对农业化学投入品专营店实行登记管理。对示范区农业投入品使用情况进行监督检查，依法对农业投入品进行质量安全检查，杜绝使用禁用农药行为。对私自销售和使用禁用农药化学投入品的单位和个人予以依法惩处。（由县农业和科学技术局牵头，县市场监督管理局、县供销社等部门配合）

2. 完善疫情疫病防控制度。实行科学防治，调查示范区内发生有害生物种类、发生情况，并制定监测计划及综合防治措施等。开展种植基地疫情疫病检测，落实防疫制度。（由县农业和科学技术局牵头，县环境保护局配合）

3. 完善环境检测和治理制度。定期对示范区土壤、大气、水源进行检测评估，制定实施种植环境土壤、水质及大气检测计划。（由县环境保护局牵头，县农业和科学技术局配合）

（三）完善加工企业和初级农产品生产者质量控制体系

1. 完善原料环节控制。制定实施种植基地良好农业规范（GAP）推行计划及种苗管理规范。鼓励基地应用新品种、新技术、新肥料、新农药、新机具，提高生产管理技术和病虫害防治水平，鼓励申请注册地理标志证明商标、集体商标，实施地理标志保护和农产品地理标志登记保护。（由县农业和科学技术局牵头，县市场监督管理局、县供销社配合）

2. 完善加工环节控制。指导加工企业应用危害分析与关键控制点（HACCP）原理，对生产全过程进行无缝隙的安全控制；鼓励加工企业通过国内外知名认证机构的管理体系认证和产品认证，提高市场认可度。（由县市场监督管理局牵头，县环境保护局配合）

3. 完善质量追溯管理。指导种植基地及出口加工企业建立从田间到产品的质量追溯制度，追溯链节环环相扣。（由县农业和科学技术局牵头，县市场监督管理局配合）

（四）完善风险预警与快速反应体系

1. 建立风险信息举报、收集、研判、预警制度及质量安全信息互通制度。及时掌握食品农产品质量安全隐患，各监管部门要互通监控结果和质量安全信息，定期发布预警通报。（由县市场监督管理局、县农业和科学技术局、县环境保护局等部门根据职责分工负责）

2. 建立质量重大突发事件应急处置机制。对于发生严重问题的区域或企业，根据预警信息，县属有关部门通过联席会议制度，立即启动追溯程序，联合研究应对措施，有效控制突发事件的发生、发展。（由县市场监督管理局、县农业和科学技术局、县公安局等部门根据职责分工负责）

3. 建立诚信管理机制。对企业开展遵纪守法和讲诚信培训教育；建立企业诚信档案，实行企业失信举报奖励和失信通报制度，发挥社会监督作用；每年对企业进行诚信考核评级，建立企业诚信扶持导向机制，对守诚信的企业予以扶持，对不守诚信的企业按照要求进行整改和处罚。（由县市场监督管理局牵头，县财政局、县工业商务和信息化局等部门根据职责分工负责）

（五）完善技术服务支撑体系

1. 加大农产品质量安全监管检测体系建设。引进高端设备，加快检测人才培养，不断扩大检测项目、提高检测准确度、缩短检测周期；推行生产企业自检制，加强培训，提高检测水平，提升产品质量。（由县农业和科学技术局、县市场监督管理局等部门根据职责分工负责）

2. 加大法律法规宣传力度。掌握国内外食品农产品法规、标准最新动态，并及时告知生产加工企业，确保出口食品农产品符合国内外出口产品技术标准。（由县市场监督管理局、县工业商务和信息化局、县农业和科学技术局、县环境保护局等部门根据职责分工负责）

3. 强化科技培训支撑。通过举办专家讲座、现场培训等形式，指导示范区生产基地开展病虫害绿色防控、生产投入品科学使用和加工企业质量安全控制等相关技术培训咨询服务。（由县农业和科学技术局、县工业商务和信息化局、县市场监督管理局等部门根据职责分工负责）

五、工作要求

（一）加强组织领导。全面落实属地管理原则，各乡镇要建立相应组织领导机构，加强对创建工作的组织领导。

（二）健全工作制度。为保障示范区建设有效运行，各乡镇要制定配套的工作制度、工作计划、工作规范和监督制度等，确保示范区建设工作按进度推进。

（三）加大宣传培训。领导小组要加大出口食品农产品质量安全示范区建设的对外宣传力度，提高泸西农产品知名度。加强对基地、企业管理人员的培训，组织专家实施现场技术指导，提高食品农产品从业人员质量安全意识。

（四）严格资金管理。示范区建设专项资金，主要用于建设示范区、奖励成效突出的单位。领导小组要做好示范区建设专项资金监督管理，确保专项资金用到实处。

（五）做好沟通协调。领导小组办公室要建立例会、联络员等制度，加强与领导小组各成员单位的沟通协调，及时收集汇总工作情况及工作中存在的困难和问题，并分年度对示范区建设工作进行总结。
