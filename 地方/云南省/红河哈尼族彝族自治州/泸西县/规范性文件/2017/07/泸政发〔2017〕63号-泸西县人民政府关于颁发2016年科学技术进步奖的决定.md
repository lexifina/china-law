# 泸西县人民政府关于颁发2016年科学技术进步奖的决定

各乡、镇人民政府，县属有关办、局：

为深入贯彻落实党的十八大和十八届三中、四中、五中、六中全会精神，深化科技体制改革，大力实施创新驱动发展战略，不断提升自主创新能力，充分发挥科技在经济社会发展中的支撑引领作用，经研究，决定对2016年在全县科学技术进步和创新中作出突出贡献的科学技术人员及组织给予奖励：授予“急诊PCI治疗急性ST段抬高型心肌梗死的推广应用”1项成果泸西县科学技术进步一等奖；授予“颅外颈动脉及椎动脉狭窄支架置入术”等6项成果泸西县科学技术进步二等奖；授予“优化流程重组在批量白内障手术期护理中的应用”等15项成果泸西县科学技术进步三等奖（详见附件）。

希望全县广大科技工作者向获奖者学习，继续发扬求真务实、勇于创新、团结协作、勇攀高峰的科学精神，深入实施创新驱动发展战略，争创更多优秀科学技术成果，并促进科学技术成果向现实生产力转化，为把我县建设成为独具特色的宜居型高原花园城市、滇中城市经济圈重要交通物流枢纽、云南省高原特色现代农业示范区和全国康体休闲养生旅游目的地，实现与全国全省全州同步全面建成小康社会做出更大贡献。

附件：2016年泸西县科学技术进步奖获奖项目
