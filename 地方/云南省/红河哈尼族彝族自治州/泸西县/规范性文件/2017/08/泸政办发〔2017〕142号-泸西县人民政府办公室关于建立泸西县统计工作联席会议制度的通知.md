# 泸西县人民政府办公室关于建立泸西县统计工作联席会议制度的通知

各乡、镇人民政府，县属有关办、局：

为进一步完善县级部门统计管理制度，切实加强对全县统计工作的组织领导，增进部门间的协调配合，建立健全部门统计数据信息共享机制，为县委、县政府提供真实、科学的决策依据，经县人民政府研究，决定建立泸西县统计工作联席会议制度（以下简称联席会议）。现将有关事项通知如下：

一、主要职能

联席会议在县委、县政府领导下进行，负责组织协调、督促指导各部门的统计工作，增强统计工作的服务功能；及时准确研判经济形势，分析研究经济运行中出现的新情况、新问题，及时向县委、县政府提出建议；对全县重点产业建设开展统计监测，探索“三新”经济（新产业、新业态、新模式）的统计调查办法，推进统计管理体制改革，研究和改进统计工作方式方法，不断增强统计工作的科学性和准确性；研究讨论工业、建筑业、房地产业、商贸业等行业的企业培育、纳规升规、入库退库等工作；加强部门间统计信息的沟通和交流，实现资源共享，建立统计工作长效机制；协调落实县委、县政府交办的其他事项。

二、成员单位

联席会议成员单位由县发展和改革局、县工业商务和信息化局、县教育局、县农业和科学技术局、县公安局、县民政局、县财政局、县人力资源和社会保障局、县环境保护局、县住房和城乡建设局、县交通运输局、县林业局、县水务局、县文化体育和广播电视局、县卫生和计划生育局、县统计局、县旅游发展委员会、泸西工业园区管委会、县招商局、县地税局、县国税局、县市场监督管理局、中国邮政泸西分公司、中国电信泸西分公司、中国移动泸西分公司、中国联通泸西分公司、中国人民银行泸西支行等部门和单位构成，成员单位的主要负责人为联席会议成员。

联席会议下设办公室在县统计局，由县统计局局长兼任办公室主任。联席会议办公室主要职责为：负责联席会议的组织、协调和联络工作；收集、研究和提出联席会议议题；督促成员单位落实联席会议议定事项；承办联席会议交办的其他事项。

联席会议办公室下设六个专项组：综合组、工业组、投资组、建筑（房地产）组、商贸组和第三产业组。

（一）综合组。由县统计局牵头，县发展和改革局、县工业商务和信息化局、县财政局、县农业和科学技术局、泸西工业园区管委会、县市场监督管理局、县国税局、县地税局配合，主要负责组织召开年度和临时会议，联系成员单位，收集归纳成员单位统计数据，形成经济形势分析材料。

（二）工业组。由县工业商务和信息化局牵头，县发展和改革局、县财政局、县统计局、县地税局、县国税局、县市场监督管理局、泸西工业园区管理委员会配合，主要负责工业经济运行情况的分析、研判，收集达到标准的工业企业入库所需的所有资料。

（三）投资组。由县发展和改革局牵头，县工业商务和信息化局、县教育局、县住房和城乡建设局、县农业和科学技术局、县水务局、县统计局、县旅游发展委员会、县招商局、县交通运输局、县市场监督管理局配合，主要负责重大项目建设，督促项目建设单位加快办理开工手续，及时提供项目建设开工、竣工情况和入库所需材料，研究解决重大项目建设过程中出现的问题和矛盾。

（四）建筑（房地产）组。由县住房和城乡建设局牵头，县统计局、县地税局、县市场监督管理局配合，主要负责提供资质内建筑企业、房地产开发企业的增减变动情况，新增、注销、消亡企业入（退）库所需的各种材料，督促企业及时到所在地统计部门办理入（退）库手续；及时提供建设项目中标建筑企业名单及信息；督促建筑企业向所在地统计部门报送各项统计数据。

（五）商贸组。由县工业商务和信息化局牵头，泸西工业园区管委会、县统计局、县地税局、县国税局、县市场监督管理局配合，主要负责批发零售、住宿餐饮企业的入库工作，引导、督促外地企业和连锁企业在当地注册；定期跟踪监测有望达到限额以上的批发零售、住宿餐饮企业，并收集达到限额以上标准入库所需的所有资料，及时报送所在地统计部门。

（六）第三产业组。由县发展和改革局牵头，县公安局、县财政局、县住房和城乡建设局、县交通运输局、县工业商务和信息化局、县文化体育和广播电视局、县统计局、县旅游发展委员会、泸西工业园区管委会、县招商局、县市场监督管理局、县教育局、中国邮政泸西分公司、中国电信泸西分公司、中国移动泸西分公司、中国联通泸西分公司、中国人民银行泸西支行配合，主要负责第三产业情况的分析、研判。相关部门按月收集，提供测算第三产业增加值所需指标数据及分析资料。

三、组织形式

联席会议总召集人为县人民政府分管领导，县人民政府办公室联系工作的副主任、县统计局主要负责人为召集人，同时由县统计局确定1名联席会议联络员，负责联席会议的日常事务。联席会议建立月度、季度、年度会议制度。

（一）月度会议

会议时间：每月中旬。

召 集 人：县人民政府办公室联系工作的副主任、县统计局主要负责人

会议内容：通报上月规模以上工业增加值、固定资产投资、限上批发零售业商品销售额、限上住宿餐饮业营业额、财政收支、金融等主要经济指标完成情况，分析研判月度经济运行情况以及存在的问题，研究制定工作措施。

参加单位：县发展和改革局、县财政局、县住房和城乡建设局、县交通运输局、县水务局、县工业商务和信息化局、县统计局、泸西工业园区管委会、县市场监督管理局、县招商局、县农业和科学技术局、县旅发委等。

（二）季度会议

会议时间：1月、4月、7月、10月中下旬。

召 集 人：县人民政府分管领导

会议内容：通报上季度生产总值、三次产业增加值、规模以上工业增加值、固定资产投资、社会消费品零售总额、财政收支、城镇居民人均可支配收入、农村居民人均可支配收入、建筑业、房地产、劳动工资、金融等主要经济指标完成情况，分析上季度经济运行情况，对照目标任务，分析考核指标完成情况，提出对策建议；对各项重要监测、考核、评估的指标数据进行分析评估论证，保障重要统计数据“数出一门”、真实可信；通报各成员单位统计工作开展情况，交流统计工作经验，协调解决部门统计工作中的重要问题。

参加单位：县发展和改革局、县工业商务和信息化局、县财政局、县人力资源和社会保障局、县住房和城乡建设局、县交通运输局、县农业和科学技术局、县统计局、县地税局、县国税局、县市场监督管理局、县水务局、县旅发委、中国邮政泸西分公司、中国电信泸西分公司、中国移动泸西分公司、中国联通泸西分公司、中国人民银行泸西支行。

（三）年度会议

会议时间：12月下旬

召 集 人：县人民政府分管领导

会议内容：研判全年经济运行情况，分析考核指标数据，评估数据质量，促进部门统计数据的协调性与匹配性，确保全年经济目标任务的完成；对次年经济社会发展预期目标进行研判。

参加单位：联席会议全体成员单位及邀请参会单位。

四、工作规则

（一）除月度、季度和年度会议外，联席会议可根据工作需要召开，研究协调重大事项，全体成员单位参加；研究单项工作，根据议题确定参加会议的成员单位。

（二）联席会议由总召集人或召集人确定议题，联席会议办公室负责下发会议通知，并根据会议内容通知有关成员单位按要求准备相关材料，准时参加。

（三）成员单位需要提交联席会议研究的议题，应在联席会议召开前将相关资料送交联席会议办公室，统一提交会议研究讨论。

（四）联席会议做出的决定，以会议纪要的形式印发各成员单位。各成员单位要按照部门职责，分工负责，抓好落实。

五、工作要求

各成员单位要积极参加联席会议，按照职责分工认真贯彻执行联席会议决定，及时报告本单位落实联席会议决定事项的情况。切实履行统计职能，主动向联席会议提出加强改进统计工作的意见和建议，互通信息，相互配合，相互支持，形成合力，充分发挥联席会议作用，为加强和改进统计工作，推进全县跨越发展做出新的更大贡献。
