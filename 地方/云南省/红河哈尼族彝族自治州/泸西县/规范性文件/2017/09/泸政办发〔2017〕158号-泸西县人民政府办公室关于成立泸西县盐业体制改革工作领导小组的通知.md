# 泸西县人民政府办公室关于成立泸西县盐业体制改革工作领导小组的通知

各乡、镇人民政府，县属有关办、局：

为加强对全县盐业体制改革工作的组织领导，县人民政府决定成立泸西县盐业体制改革工作领导小组（以下简称领导小组）。现将有关事项通知如下：

一、组成人员

组 长：唐卫平 县委常委、县人民政府常务副县长

副组长：夏云旺 县人民政府办公室副主任

高洪春 县工业商务和信息化局局长

张景泽 县发展和改革局局长

成 员：李 伟 县编办副主任

赵兴强 县发展和改革局副局长

冯林祥 县工业商务和信息化局副局长

张汝发 县公安局副局长

高 翔 县民政局副局长

唐明荣 县财政局副局长

张汝印 县农业和科学技术局副局长

袁明东 县卫生和计划生育局副局长

刘文斌 县市场监督管理局副局长

二、工作机构

领导小组下设办公室在县工业商务和信息化局，承担领导小组日常工作，由冯林祥同志兼任办公室主任。

三、主要职责

贯彻落实国务院和省州政府盐业体制改革有关工作部署，统筹协调全县盐业体制改革工作，指导和督促各乡镇、各有关部门和企业开展工作，协调解决跨地区、跨部门重要事项，督促检查盐业体制改革重要工作落实情况。

（此件公开发布）
