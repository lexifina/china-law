# 泸西县人民政府办公室关于近期强降水条件下进一步加强地质灾害防范工作的紧急通知

各乡、镇人民政府，县属有关办、局：

近期，我县部分地区持续降雨，土壤含水率极高，发生滑坡、泥石流等地质灾害的可能性极大。为进一步做好地灾防范工作，现结合我县地灾防范工作实际提出以下要求，请认真抓好落实。

一、进一步提高减灾防灾的思想警惕性

一是要以对人民群众生命财产安全高度负责的态度，充分认识当前汛期地质灾害防范工作面临的严峻形势，克服麻痹大意疲劳情绪，进一步加强组织领导，迅速行动起来，完善工作措施，落实防灾责任，加强监督检查，狠抓工作落实。主要领导要切实履行第一责任人责任，分管领导要切实履行具体领导责任，加强统筹协调和督促落实。各乡镇要将责任压实到村民小组一级，层层抓落实。二是要加强宣传，及时通过电视、网络、短信等方式向社会发布气象信息、地灾预警信息、防灾减灾常识，全民动员，全民防灾。三是充分发挥群测群防员作用，要随机抽查群测群防员在岗在位履职情况，做到技防人防相结合，提前预警预报，及时转移避让。

二、进一步加强紧急避让和应急值守工作

在近期特殊气候条件下，要严格执行24小时值班值守和领导带班、信息报送等制度，确保不出现脱岗现象、确保通信联络畅通、确保应急人员和车辆到位，按事权与应急预案，第一时间妥善处置突发地质灾害，把灾害损失降到最低。值班室不但要发挥“上情下达，下情上传”的作用，而且还要充分发挥“指挥部”、“总调度”的作用。发现灾险情时，要及时科学研判，果断应急处置，及时组织群众紧急转移避让，必要时可协调相关部门采取强制措施，做到“宁愿受到群众骂，不要看到群众哭”。危险地段、避让后的区域要封死、控好，有值守人员，有醒目的警示标志和禁入警戒线，做到只出不进。

三、进一步加强巡排查工作

沟口、河谷、陡坡下方、人口密集区、施工工棚区域为重点排查对象，要将专业巡排查、行政巡排查，群测群防员巡排查、群众自查有机结合起来，确保不留死角。对新增隐患点要及时明确群测群防员，宣传防灾减灾知识，开展演练，让群众明白危险、主动观测、知道逃生。各乡镇、各有关部门要依托专业队伍开展地灾全面排查，科学研判，对发现隐患点要提出切实有效的处置措施。

各乡镇、各有关部门要切实履行防灾减灾工作职责。对责任不落实、措施不到位、失职渎职等造成重大人员伤亡和财产损失的单位和人员，将严格按照有关规定，严肃追究有关单位和人员责任。
