# 泸西县人民政府办公室关于加快培育和发展住房租赁市场的实施意见

各乡、镇人民政府，县属有关办、局：

为贯彻落实《云南省人民政府办公厅关于加快培育和发展住房租赁市场的实施意见》（云政办发〔2017〕10号）、《红河州人民政府办公室关于加快培育和发展住房租赁市场的实施意见》（红政办发〔2017〕122号）精神，深化住房制度改革，加快培育和发展我县住房租赁市场，经县人民政府同意，现提出以下实施意见：

一、总体目标

紧紧围绕城镇居民住有所居目标，建立租购并举的住房制度，构建以市场配置为主、政府提供基本保障的住房租赁体系。支持住房租赁消费，促进全县房地产市场平衡健康发展。到2020年，全县基本形成供应主体多元、经营服务规范、租赁关系稳定的住房租赁市场体系，基本形成保基本、促公平、可持续的住房租赁保障体系，基本形成市场规则明晰、政府监管有力、权益保障充分的住房租赁法规制度体系。

二、主要任务

（一）培育市场供应主体

1. 发展住房租赁企业。积极引导和支持成立市场化、专业化运作的住房租赁企业。调动企业积极性，采取租赁、购买等方式多渠道筹集房源，提高住房租赁企业规模化、集约化、专业化水平，形成大、中、小住房租赁企业协同发展的格局，满足不断增长的住房租赁需求。探索组建住房租赁有限公司，按照市场化、专业化、规模化的要求搭建租赁平台，收购或租赁库存商品房、车库等开展租赁业务，按有关政策规定出租给有需求人群，带动、促进各类中、小专业化住房租赁企业协同发展。将住房租赁作为主营业务的住房租赁企业，按照有关规定享受生活性服务业有关支持政策。（县住房和城乡建设局牵头，县发展和改革局、县财政局、县市场监督管理局、县地税局、县国税局、中国人民银行泸西县支行、各乡镇人民政府配合）

2. 鼓励和支持房地产开发企业开展住房租赁业务。支持房地产开发企业拓展业务范围，通过租售并举，利用已建成住房或新建住房开展租赁业务；鼓励房地产开发企业出租库存商品住房；引导房地产开发企业与住房租赁企业合作，发展租赁地产。（县住房和城乡建设局牵头，县国土资源局、县财政局、中国人民银行泸西县支行、各乡镇人民政府配合）

3. 加强信贷支持。房地产开发企业对租赁住房进行装修的费用，可享受房地产项目有关贷款政策，金融机构要给予信贷支持。（县财政局牵头，中国人民银行泸西县支行、县住房和城乡建设局、各乡镇人民政府配合）

4. 规范住房租赁中介机构。加强中介行业的自律管理，县住房和城乡建设局、县市场监督管理局要指导当地中介行业建立行业内部诚信档案，健全行业自评机制，不断完善中介从业人员培训制度，强化中介机构人员培训，提升从业人员素质，规范中介行业居间服务工作流程、督促中介机构严格执行收费标准，促进中介机构依法经营、诚实守信、公平交易。（县住房和城乡建设局牵头，县市场监督管理局、县财政局、县发展和改革局、各乡镇人民政府配合）

5. 支持和规范个人出租住房。进一步规范住房租赁合同登记备案制度，免收个人登记费用。落实鼓励个人出租住房的优惠政策，鼓励个人依法出租自有住房，支持个人委托住房租赁企业和中介机构出租住房，并建立长期稳定的合作关系。（县住房和城乡建设局牵头，县市场监督管理局、县地税局、县国税局、各乡镇人民政府配合）

6. 整顿和规范物业服务行业。全面提升物业企业服务水平，明确物业服务各方主体的责、权、利，制定质价相符的物业服务标准，接受社会监督。同时，鼓励物业服务企业拓展业务，兼营住房租赁业务。（县住房和城乡建设局牵头，县市场监督管理局、县发展和改革局、各乡镇人民政府配合）

（二）完善支持政策

1. 落实税收优惠。对依法登记备案的住房租赁企业、机构和个人，给予税收优惠政策支持。落实营改增关于住房租赁的有关政策，对个人出租住房的，由按照5%的征收率减按1.5%计算应纳税额；小规模纳税人出租住房月销售额不超过3万元（按季纳税9万元）的，可享受小微企业暂免征收增值税优惠政策；其他个人（自然人）采取预收款形式出租不动产，取得的预收租金收入，可在预收款对应的租赁期内平均分摊，分摊后的月租金收入不超过3万元的，可享受免征增值税优惠政策。对房地产中介机构提供住房租赁经纪代理服务，一般纳税人适用6%的增值税税率，小规模纳税人增值税按3%征收率征收；对一般纳税人出租在2016年4月30日前取得的不动产，可以选择适用简易计税办法，按照5%的征收率计算缴纳增值税；对个人出租住房所得，减半征收个人所得税（即按10%征收个人所得税）。若税收政策变化按新的税收政策执行。（县国税局牵头，县地税局、县住房和城乡建设局、各乡镇人民政府配合）

2. 提供金融支持。鼓励金融机构按照依法合规、风险可控、商业可持续的原则，针对住房租赁企业的融资需求，加快创新信贷产品和服务，优化信贷办理流程，加大对住房租赁企业的金融支持力度。（县财政局牵头，中国人民银行泸西县支行、县住房和城乡建设局、各乡镇人民政府配合）

3. 完善供地方式。积极盘活城区存量土地，深入推进城镇低效用地再开发，采用多种方式增加租赁住房用地有效供应。新建租赁住房项目用地以招标、拍卖、挂牌方式出让的，出让方案和合同中应明确规定持有出租的年限。（县国土资源局牵头，县住房和城乡建设局、各乡镇人民政府配合）

4. 引导新建租赁住房。根据实际情况，结合住房供需状况等因素，将新建租赁住房纳入住房发展规划，合理确定租赁住房建设规模，并在年度住房建设计划和住房用地供应计划中予以安排，引导土地、资金等资源合理配置，有序开展租赁住房建设。（县住房和城乡建设局牵头，县国土资源局、各乡镇人民政府配合）

5. 允许改建房屋用于租赁。允许将商业用房等按照规定改建为租赁住房，土地使用年限和容积率不变，土地用途调整为居住用地，调整后用水、用电、用气价格按照居民标准执行。允许将现有住房按照住宅设计规范改造后出租，改造中不得改变原有防火分区、安全疏散和防火分隔设施，必须确保消防设施完好有效。健全县国土资源局、县住房和城乡建设局等部门的高效联动工作机制，建立改建项目绿色审批通道。（县住房和城乡建设局牵头，县国土资源局、县发展和改革局、县公安消防大队、各乡镇人民政府配合）

6. 推进公共租赁住房货币化。转变单一的公共租赁住房保障方式，实现实物保障与租赁补贴并举。实物配租房源不足的，可采取购买或长期租赁商品住房作为公共租赁住房房源。支持公共租赁住房保障对象通过市场租房，政府对符合条件的家庭给予租赁补贴。完善租赁补贴制度，结合市场租金水平和保障对象实际情况，合理确定租赁补贴标准。（县住房和城乡建设局牵头，县财政局、县人力资源和社会保障局、各乡镇人民政府配合）

7. 进一步提高保障能力。鼓励采取政府购买服务或政府和社会资本合作（PPP）模式，将现有政府投资和管理的公共租赁住房交由专业化、社会化企业运营管理，不断提高管理和服务水平。在城镇稳定就业的外来务工人员，凡符合当地城镇居民公共租赁住房准入条件的，应全部纳入保障范围。公共租赁住房可作为各类受灾群众、棚户区改造、移民搬迁、重点项目房屋被征收对象的临时安置过渡用房。落实提取住房公积金支付房租政策并简化办理手续，缴纳住房公积金满3个月，本人及配偶在缴存城市无住房或住房困难而租住住房的，可提取夫妻双方住房公积金支付房租。非本地户籍承租人可按照《居住证暂行条例》等有关规定申领居住证，享受义务教育、医疗等国家规定的基本公共服务。县教育局等相关部门要结合实际，研究出台符合条件承租人子女就近入学等基本公共服务政策措施。（县住房和城乡建设局牵头，县发展和改革局、县财政局、县扶贫办、县人力资源和社会保障局、县公安局、州住房公积金管理中心泸西管理部、县教育局、县卫生和计划生育局、各乡镇人民政府配合）

（三）加强住房租赁监管

1. 健全法规制度。完善住房租赁法规和配套政策，规范市场行为，稳定租赁关系。配合建立州、县统一的住房租赁信息系统，推行住房租赁合同网上签约、网上登记备案制度，房地产开发企业、房地产中介、单位、个人出租的房屋要实行网签网备。住房租赁信息系统建设、运行和维护经费列入财政预算予以保证。住房租赁合同登记备案要作为享受住房租赁优惠政策的必要条件。（县住房和城乡建设局牵头，县财政局、县市场监督管理局、各乡镇人民政府配合）

2. 加强行业管理。县住房和城乡建设局负责住房租赁市场管理和有关协调工作，要会同县市场监督管理局等有关部门加强住房租赁市场监管，完善住房租赁企业、中介机构和从业人员信用管理制度，全面建立有关市场主体信用记录，纳入全国信用信息共享平台，对严重失信主体实施联合惩戒。（县住房和城乡建设局牵头，县市场监督管理局、县公安局、各乡镇人民政府配合）

3. 加强治安管理。县公安局要加强出租住房治安管理和住房租赁当事人居住登记，督促指导社区、村民委员会、物业服务企业以及其他管理单位排查安全隐患。有关部门要按照职责分工，依法查处利用出租住房从事违法经营的活动。（县公安局牵头，县市场监督管理局、县住房和城乡建设局、各乡镇人民政府配合）

4. 督促权利义务的履行。住房租赁当事人要使用统一规范的住房租赁合同示范文本，明确各方权利义务。出租人应按照有关法律法规和合同约定履行义务，保证住房和室内设施符合要求。住房租赁合同期限内，出租人无正当理由不得解除合同，不得单方面提高租金，不得随意克扣押金；承租人应按照合同约定使用住房和室内设施，并按时缴纳租金。中介机构应提供质价相符的居间服务。在结束出租、承租关系后，出租方应及时将已解除租赁关系的信息材料提供到物业、社区、村委会、县住房和城乡建设局及县公安局办理登记。（县住房和城乡建设局牵头，县市场监督管理局、县公安局、各乡镇人民政府配合）

三、工作要求

（一）加强组织领导，健全工作机制。各乡镇人民政府、各有关部门要充分认识加快培育和发展住房租赁市场的重要意义，加强组织领导，健全工作机制，做好宣传引导，营造良好的工作环境。各乡镇人民政府对本行政区域内的住房租赁市场管理负总责，要建立联合监管体制，明确职责分工，充分发挥社区、村委会等基层组织作用，推行住房租赁网格化管理。要加快建设住房租赁信息服务与监管平台，推进部门间信息共享。

（二）细化任务分工，落实工作责任。各有关部门要进一步细化任务分工，落实工作责任，确保各项工作有序推进。加快培育和发展住房租赁市场，大力盘活闲置房源，培育专业化、规模化的住房租赁经营企业，支持开发企业租售并举，鼓励物业服务企业兼营住房租赁业务，把发展住房租赁与商品房去库存工作有机结合，促进房地产市场与住房租赁市场共同健康发展。

（此件公开发布）
