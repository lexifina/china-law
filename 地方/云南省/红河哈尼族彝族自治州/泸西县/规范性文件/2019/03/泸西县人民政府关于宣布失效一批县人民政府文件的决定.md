# 泸西县人民政府关于宣布失效一批县人民政府文件的决定

各乡、镇人民政府，县属各办、局：

根据国务院和省、州人民政府对政府文件清理工作部署，为进一步推动简政放权、放管结合、优化服务改革，促进大众创业、万众创新，激发市场活力和社会创造力，加快建设法治政府，维护县人民政府文件的权威性、严肃性，决定对县人民政府文件进行全面清理。

经清理，对与现行法律法规不一致、已被新规定涵盖或替代、调整对象已消失、工作任务已完成或者适用期已过2000—2015年期间印发的1047件县人民政府文件宣布失效。凡宣布失效的县人民政府文件，自本决定印发之日起一律停止执行，不再作为行政管理的依据。

各乡镇、各部门要充分认识文件清理工作的重要意义，做好政策衔接，完善事中事后监管，防止出现“空档”。要加大工作力度，抓紧清理本乡镇、本部门印发的文件，废止不符合现行法律法规或没有法律依据，不利于稳增长、促改革、调结构、惠民生、防风险的文件，坚决破除对企业和群众干事创业的各种束缚，把简政放权、放管结合、优化服务改革推向纵深，加快转变政府职能，为创业创新创造良好环境，促进全县经济社会持续健康发展。
