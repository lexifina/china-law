# 泸西县扶贫开发工作领导小组关于对财政涉农整合资金收回的通知

县财政局：

泸西县财政局《关于请求收回2017年度农业综合开发土地治理项目结余资金的请示》（泸财〔2019〕33号）文件已收悉，根据云南省扶贫开发领导小组办公室关于印发《云南省财政专项扶贫资金县级结余结转综合治理办法（试行）的通知》（云开组办〔2018〕2号）文件“对结余结转资金由县级财政部门收回并调整用于其他扶贫项目”的要求。现批复如下：

一、收回2017年农业综合开发项目资金129807.7元，由县财政局调整安排用于其他扶贫项目。

二、资金收回截止时间为2019年3月1日（星期五）上午10:00前返回扶贫资金专户。
