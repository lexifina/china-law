# 泸西县扶贫开发工作领导小组关于收回向阳乡贫困户入户道路硬化项目结余资金的通知

向阳乡党委、政府，县财政局：

中共向阳乡委员会 向阳乡人民政府《关于请求收回贫困户入户道路硬化款结余资金的请示》（向发〔2019〕95号）收悉，经县扶贫开发工作领导小组2019年8月30日会议研究。现通知如下：

一、同意收回向阳乡贫困户入户道路硬化款结余资金97.683136万元。

二、收回资金由县财政局调整安排用于其他扶贫项目。

三、资金收回截止时间为2019年9月3日（星期二）上午10:00前返回扶贫资金专户。

户名：泸西县财政局（扶贫资金专户）

开户行：中国建设银行泸西支行
