# 泸西县扶贫开发工作领导小组关于收回县农业农村局集体经济全覆盖部分项目资金的通知

县农业农村局，县财政局：

泸西县农业和科学技术局关于《请求收回泸西县永宁乡永宁村集体经济全覆盖200亩人参果种植基地建设项目40万项目资金的请示》（泸农科发〔2019〕147号）收悉。现通知如下：

一、同意收回县农业农村局安排在永宁乡永宁村的集体经济全覆盖200亩人参果种植基地建设项目资金40万元。

二、收回资金由县财政局调整安排用于其他扶贫项目。

三、资金收回截止时间为2019年9月13日（星期五）上午11:00前返回扶贫资金专户。
