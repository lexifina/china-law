# 泸西县财政局泸西县扶贫办关于下达州级2019年55个贫困村第一书记工作队长）工作经费的通知

各乡镇党委、政府：

根据《红河州财政局 红河州扶贫办关于下达2019年州级798个贫困村第一书记（工作队长）工作经费的通知》（红财农发〔2019〕35号）文件要求，现将州级财政下达全县55个贫困村第一书记（工作队长）工作经费进行分配（详见附件1）。请于7月21日前安排专人到县财政局农业农村科划拨。

请各乡镇、贫困村严格按照《云南省财政专项扶贫资金管理办法》（云财农发〔2017〕213号）和《关于加强贫困村驻村工作队选派管理工作的实施意见》（云厅字〔2018〕15号）及《泸西县人民政府关于印发泸西县财政扶贫资金乡（镇）级财政报账制暂行管理办法（试行）的通知》（泸政发〔2018〕40号）等文件要求，切实加强资金管理，充分发挥资金使用效益。

举报电话：泸西县扶贫办：0873-6621797，泸西县财政局0873-6621886
