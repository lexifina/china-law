# 泸西县扶贫开发工作领导小组关于收回县农业农村局2018年度农业综合开发项目结余资金的通知

县农业农村局，县财政局：

泸西县农业农村局关于《请求收回泸西县2018年度农业综合开发财政涉农资金统筹整合项目结余资金的请示》（泸农科发〔2019〕151号）收悉。现通知如下：

一、同意收回泸西县永宁村果蔬规模化种植基地基础设施建设项目结余资金0.02元；同意收回泸西县益谷、雨龙片区通村道路建设项目结余资金0.26元；同意收回向阳乡阿盈里村蔬菜规模化种植基地基础设施建设项目结余资金109939.67元。合计收回109939.95元。

二、收回资金由县财政局调整安排用于其他扶贫项目。

三、资金收回截止时间为2019年9月26日（星期五）上午11:00前返回扶贫资金专户。
