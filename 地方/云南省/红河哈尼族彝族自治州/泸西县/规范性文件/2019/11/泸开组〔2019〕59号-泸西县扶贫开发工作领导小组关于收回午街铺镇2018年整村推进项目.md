# 泸西县扶贫开发工作领导小组关于收回午街铺镇2018年整村推进项目

午街铺镇人民政府：

你单位《泸西县午街铺镇人民政府关于请求收回2018年整村推进项目结余资金的请示》（午政发〔2019〕72号）已收悉。经研究，现批复如下：

一、同意收回2018年水塘村委会阿古块老寨、小河边整村推进项目结余资金42029.97元；2018年山林村委会坝上村整村推进项目结余资金1294.91元，共计43324.88元。

二、收回资金由县财政局调整安排用于其他扶贫项目。

三、资金收回截止时间为2019年9月30日（星期一）上午10:00前返回扶贫资金专户。
