# 泸西县扶贫开发工作领导小组关于收回泸西县交通运输局超范围使用

县交通运输局、县财政局：

泸西县交通运输局《泸西县交通运输局关于请求收回超范围使用涉农整合资金的请示》（泸交发〔2019〕39号）已收悉。经研究，现批复如下：

一、同意收回《泸西县扶贫开发工作领导小组关于2018年泸西县财政涉农整合资金项目安排的通知》（泸开组〔2018〕89号）文件安排的“2018年白水镇农村公路配套设施建设项目”资金60万元、“2018年永宁乡农村公路配套设施建设项目”资金60万元，共计120万元。

二、收回资金由县财政局调整安排用于其他扶贫项目。

三、资金收回截止时间为2019年10月10日（星期四）上午10:00前返回扶贫资金专户。
