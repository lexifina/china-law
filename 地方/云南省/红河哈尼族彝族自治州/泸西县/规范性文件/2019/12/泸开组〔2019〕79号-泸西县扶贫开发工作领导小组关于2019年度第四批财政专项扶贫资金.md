# 泸西县扶贫开发工作领导小组关于2019年度第四批财政专项扶贫资金

根据《中华人民共和国政府信息公开条例》《财政部关于全面加强脱贫攻坚期内扶贫资金管理的意见》（财办〔2018〕24号）《关于完善扶贫资金项目公告公示制度的指导意见》（国开办发〔2018〕11号）《云南省人民政府扶贫开发办公室 云南省财政厅关于印发云南省全面实施扶贫资金项目公告公示制度的实施意见的通知》（云开办〔2018〕109号）等相关文件要求，为加强我县财政专项扶贫资金管理信息公开，提高财政专项扶贫资金使用效益和透明度，实现阳光化运行、常态化公开，保障贫困群众知情权、参与权和监督权，现将2019年财政专项扶贫资金安排情况（第四批）予以公开（详见附件），下达资金为275万元，其中专项资金为239.319569万元，整合资金为35.680431万元。公开文件相关情况如下：

文件名1：泸西县扶贫开发工作领导小组关于2019年度第四批财政专项扶贫资金

文号：泸开组〔2019〕79号

文件类型：资金下达文件

文件金额：275万元

文件涉及的专项资金名称：关于提前下达2019年第一批中央财政专项扶贫资金的通知、关于下达2019年第二批中央财政专项扶贫资金的通知、关于提前下达2019年第八批中央统筹整合涉农资金的通知

资金预算年度：2019年

公开部门监督举报电话：0873-6621797
