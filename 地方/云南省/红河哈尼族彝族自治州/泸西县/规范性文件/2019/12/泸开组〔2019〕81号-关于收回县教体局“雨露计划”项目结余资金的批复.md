# 关于收回县教体局“雨露计划”项目结余资金的批复

县教体局，县财政局：

泸西县教育体育局《关于请求收回“雨露计划”项目结余资金的请示》（泸教体发〔2019〕114号）收悉。经研究，现通知如下。

一、同意收回《泸西县扶贫开发工作领导小组关于2019年度第二批财政专项扶贫资金扶贫项目安排的通知》（泸开组〔2019〕62号）文件安排的：泸西县教育体育局实施的“雨露计划”项目结余资金88.2万元。

二、收回资金由县财政局调整安排用于其他扶贫项目。

三、资金收回截止时间为2019年11月29日（星期五）上午10:00前返回扶贫资金专户。
