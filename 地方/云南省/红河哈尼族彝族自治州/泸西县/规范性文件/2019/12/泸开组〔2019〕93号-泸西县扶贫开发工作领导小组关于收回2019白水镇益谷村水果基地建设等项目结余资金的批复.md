# 泸西县扶贫开发工作领导小组关于收回2019白水镇益谷村水果基地建设等项目结余资金的批复

白水镇人民政府：

泸西白水镇人民政府报送的《白水镇人民政府关于请求收回2019年白水镇益谷村水果基地建设项目资金的请示》（白政发〔2019〕54号）、《白水镇人民政府关于请求收回2019年白水镇综合养殖产业扶贫项目和2019年白水镇综合种植产业扶贫项目结余资金的请示》（白政发〔2019〕55号）已收悉。经研究，现批复如下：

一、同意收回《泸西县扶贫开发工作领导小组关于2019年度第十二统筹整合财政涉农资金建设项目资金安排的通知》（泸开组〔2019〕79号）文件安排的2019年白水镇益谷村水果基地建设项目结余资金200万元；《泸西县扶贫开发工作领导小组关于2019年度养殖业产业扶贫项目资金安排的通知》（泸开组〔2019〕24号）文件安排的2019年白水镇综合养殖产业扶贫项目结余资金5.05万元、《泸西县扶贫开发工作领导小组关于2019年度种植业产业扶贫项目资金安排的通知》（泸开组〔2019〕25号）2019年白水镇综合种植产业扶贫项目结余资金3.92125万元。

二、收回资金共计208.97125万元，由县财政局调整安排用于其他扶贫项目。

三、资金收回截止时间为2019年12月4日（星期三）下午16:00前返回扶贫资金专户。
