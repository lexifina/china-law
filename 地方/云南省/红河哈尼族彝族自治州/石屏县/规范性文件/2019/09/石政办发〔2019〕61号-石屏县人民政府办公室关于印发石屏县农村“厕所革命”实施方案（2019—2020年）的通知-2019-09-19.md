# 石屏县人民政府办公室关于印发石屏县农村“厕所革命”实施方案（2019—2020年）的通知

各乡镇人民政府，县属有关部门：

《石屏县农村“厕所革命”实施方案（2019—2020年）》已经县人民政府同意，现印发给你们，请认真贯彻落实。

2019年6月30日

石屏县农村“厕所革命”实施方案

（2019—2020年）

为加快推进我县农村无害化卫生厕所建设改造工作，根据《云南省“厕所革命”三年行动计划》（云政发〔2018〕33 号）《红河州“厕所革命”三年行动实施方案（2018—2020年）》（红政发〔2019〕1 号）和《石屏县农村人居环境整治三年行动实施细则（2018—2020年）》（石办发〔2018〕57号）等相关要求，结合实际，制定本方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实习近平总书记关于“厕所革命”重要指示批示，把农村“厕所革命”作为实施乡村振兴战略的具体举措，作为重要的民生工程、生态工程、文明工程来抓，按照“有序推进、整体提升、建管并重、长效运行”的基本思路，先试点示范、后面上推广、再整体提升，因地制宜推进农村户用厕所无害化建设改造和行政村村委会所在地水冲式公共卫生厕所全覆盖，全面提升农村厕所改建品质和管理质量，引导农民群众养成良好如厕和卫生习惯，切实增强农民群众的获得感和幸福感。

二、主要目标

（一） 总体目标

通过新建一批、改造一批、提升一批，2019—2020年全县改造建设农村无害化卫生户厕12552座以上，无害化卫生厕所普及率达到50%以上，有较好基础、基本具备条件的行政村、自然村(组)卫生厕所普及率达到85%左右；地处偏远、尚不具备基本条件改造卫生厕所的行政村、自然村(组)卫生厕普及率逐步提高，达到如厕环境干净整洁的基本要求，从而有效解决农村户厕中旱厕数量较多、无害化卫生户厕普及率低及少数地方无户厕等问题。改造提升行政村村委会所在地公厕43座，达到行政村村委会1座以上无害化卫生公厕全覆盖，基本实现“数量充足、布局合理、管理规范、文明如厕”的目标。

（二）年度目标（任务见附件1）

2019年，改造建设农村无害化卫生户厕6276座，完成行政村村委会所在地公厕提升改造25座。

2020年，改造建设农村无害化卫生户厕6276座，完成行政村村委会所在地公厕提升改造18座。

各乡镇2018年未完成的行政村村委会所在地公厕提升改造任务以及农村无害化卫生户厕改建任务在2019年要继续推进完成。

三、重点任务

（一）全面摸清底数。各乡镇要以行政村为单位摸清农村户用厕所、公共厕所的数量、布点、模式等信息，全面梳理农村厕所建设改造、管理维护、使用满意度等情况及时查找问题，并跟踪农民群众对厕所建设改造的新认识、新需求。根据改建标准组织开展农村厕所现状大摸底，对照目标任务扎实开展行政村村委会所在地公厕和农村无害化卫生户厕建设工作。

（二） 科学编制工作方案。各乡镇要综合考虑地理环境、水源条件、经济水平、建设管理能力、农民生产生活习惯等因素，按照中央农办等8部委《关于推进农村“厕所革命”专项行动的指导意见》《云南省“厕所革命”三年行动计划》《红河州“厕所革命”三年行动实施方案（2018—2020年）》《石屏县农村人居环境整治三年行动实施细则（2018—2020年）》，结合乡村振兴、脱贫攻坚、改善农村人居环境等规划，按照村庄类型，突出乡村优势特色，体现农村风土人情，因地制宜编制本乡镇农村“厕所革命”工作方案，进一步细化年度目标任务、工作措施、保障措施等，确保农村“厕所革命”任务落细落实。

（三） 合理选择改厕标准和模式

农村户厕：拆除重建的农村房屋、易地移民生态搬迁以及农户新建的住房，要按照“人畜分离、厨卫入户”的要求，配套建设无害化卫生户厕。其余农户住房要按照《云南省农村厕所改造建设技术指南（试行）》，因地制宜选择无害化卫生厕所建设改造标准和模式，推广简单实用、成本适中、农民群众能够接受的无害化卫生改厕技术和产品，原则上以“水冲厕+装配式三格化粪池+资源化利用”方式为主，不具备建设水冲厕所的供水困难地区可结合实际，按照《农村户厕卫生规范》GB19379-2012、《免水冲卫生厕所》GB/T18092-2000等规定的要求，改造建设粪尿分集式、双坑交替式或双瓮漏斗式等模式的无害化卫生户厕。有条件的农户无害化卫生户厕要入户进院，并结合实际，提倡入室；化粪池所选位置应避免粪液直接排入水体。有条件的村庄应采取生态处理等方式对化粪池的出水进行自然消纳处理；引导农户对粪渣资源化利用，集肥还田；提倡将农村厕所粪污、畜禽养殖废弃物一并处理并进行资源化利用。鼓励农户自备砖、砂石、水泥等建筑材料参与建设。已实施异地搬迁的老屋、拟规划搬迁及近三年无常住人口的农户不在改造范围。

农村公厕：按照“清洁卫生、经济适用、维护方便、不污染公共水体”的原则，改造提升行政村村委会所在地公厕，改造后的农村公厕要有墙、有顶、有冲水及粪污无害化处理设施，厕内粪便不裸露，清洁无蝇蛆，基本无臭味。农村公厕应与各类生产生活服务设施紧密结合，可配建经营性用房，便于管理维护，纳入村庄保洁管理主要内容，避免区域内形成孤立公厕无人管护或加大养护成本。

（四）严格把质量关。施工建设砖混结构贮粪池时把不渗不漏作为基本要求，釆用一体化厕所产品时注重材料强度和密闭性，避免出现二次污染。各乡镇要严格执行改建厕所流程、加强施工技术指导、提升工程质量管理。要加强对改建户厕农户信息、施工过程、产品质量、检查验收等环节全程监督，推动“厕所革命”取得实效。

（五）开展示范建设改造。各乡镇要学习借鉴浙江“千村示范、万村整治”工作经验，结合打造“最美乡村”开展工作，总结推广一批适宜不同村庄类型、不同资源条件、不同经济水平的农村改厕典型范例。鼓励和支持整村推进农村“厕所革命”示范建设，整村推进坚持“分类示范、自愿申报、有序推进、先建后验、以奖代补”的原则，树立一批农村无害化卫生厕所建设示范村，以点带面、积累经验、形成引领效应。

（六）多渠道统筹项目建设。各乡镇人民政府要结合农户房屋改造和重建、易地移民生态搬迁及环境整治项目，统筹推进农村无害化卫生户厕改造建设，鼓励有条件的地区根据乡村旅游、产业发展、水源保护等高标准开展无害化卫生户厕改建。按照“因地制宜、查缺补漏”的原则，加快推进行政村村委会所在地公共厕所改造提升，着力完善农村公共卫生环境，积极探索引导农家乐、农业庄园等农村经营主体对外开放厕所，弥补区域厕所数量不足。

（七）协同推进厕所粪污与生活污水治理。统筹推进农村厕所粪污治理与农村生活污水治理，因地制宜推进厕所粪污分散处理、集中处理或接入污水管网统一处理，“分户改造、集中处理”与单户分散处理相结合，鼓励联户、联村、村镇一体治理。积极推动农村厕所粪污资源化利用，鼓励各地探索粪污肥料化、污水达标排放等经济实用技术模式，推行污水无动力处理、沼气发酵、堆肥和有机肥生产等处理方式，严禁随意排放和倾倒粪污，解决好粪污排放和利用问题。

（八）完善建设管护运行机制。要坚持建管并重，充分发挥村级组织和农民主体作用，建立政府引导与市场运作相结合的后续管护机制，引导当地农民组建社会化、专业化、职业化服务队伍。要明确厕所管护标准，做到有制度管护、有资金维护、有人员看护，已改厕农户统一编码管理，形成规范化的运行维护机制。鼓励以乡镇为单元，采取政府购买服务方式，由专业管护公司（队伍）对农村厕所进行维护、无害化处理及资源化利用等后续管护工作。将农村公厕保洁、设备设施管理维护纳入村庄保洁责任范围。

（九）有序开展技术培训。采用请进来和走出去的方式，对农村无害化卫生厕所建设和改造开展培训与技术指导。结合实际，围绕《云南省农村厕所改造建设技术指南（试行）》， 实时组织相关人员开展农村厕所建设和维护培训，提升工作能力。

四、保障措施

（一）加强组织领导。县农业农村和科学技术局、县卫生健康局、县住建局联合成立县农村“厕所革命”技术指导办公室，负责全县农村无害化卫生厕所建设和改造工作的宣传动员、组织 协调和技术指导。按照“县级统筹协调、乡镇负总责、各级抓落实”的原则，县级建立推进农村“厕所革命”工作会商和调度机制，各乡镇人民政府是推进农村“厕所革命”的实施责任主体，要把农村改厕工作列入重要议事日程，主要领导亲自抓，分管领导具体抓，明确责任分工，及时研究解决农村厕所建设改造中的问题。

（二） 加强政策支持。涉及农村厕所规划、用地、立项、审批、用水、用电等方面事宜应依法依规给予倾斜支持，简化农村厕所建设和改造项目审批和招投标程序，降低建设成本，因地制宜选择卫生户厕类型，确保工程质量。行政村公厕可以使用集体用地进行建设，公厕水电价格按照相应类别价格水平执行。

（三） 强化资金筹措。各乡镇通过统筹项目资金、深化农村产权制度改革、壮大利用村集体经济、探索宅基地使用权有偿退出和出让、引导农户投工投劳等多种方式筹集建设资金。发挥好财政资金撬动作用，依法合规吸引社会资本参与投入，推动建立市场化管护长效机制。根据各乡镇工作推进情况，我县农村“厕所革命”上级奖补资金实行“先建后补”、“以奖代补”，乡镇统筹使用。按以下标准补助：

1.任务数内的行政村公厕，验收合格后按蹲坑（男、女）总数在4至6个的，新建水冲式4万元/座、改造提升3万元/座；7个（含7个蹲位以上），按新建每增加1个蹲位补助4000元、改造每增加1个蹲位补助3000元。异龙湖沿湖行政村公厕实行差别化补助政策，最高封顶10万元/座补助。各乡镇财政结合实际安排专项资金，积极保障厕所建设管养经费。

2.任务数内的农村户厕，对达到验收标准的无害化卫生户厕改建，按水冲厕平均1200元/座、旱厕平均800元/座的标准给予补助。

（四）强化上下联动。建立完善农村无害化卫生厕所建设改造进展情况“月通报、半年评比、年度考核”的工作推动机制。各乡镇要按时上报工作方案、工作进展情况和总结。从2019 年6月份起，各乡镇于每月20日前（遇节假日请提前报送）向县农科局科教与环境资源科报送本月农村无害化卫生厕所改建进度。农村卫生厕所建设和改造工作将在为年度综合考核、各类创建评选的重要条件，实行“一票否决”。

（五）注重宣传引导。各乡镇要结合实际，组织开展农村“厕所革命”宣传活动，加大科普宣传力度，结合“三美”（美丽县城、美丽湖泊、美丽乡村）建设、文明村创建、农村人居环境整治、村庄清洁行动等，多层次、多方位宣传农村卫生改厕对于改善人居环境、促进乡风文明、革除陋习的重要意义，加强文明如厕、卫生防疫等知识宣传教育。充分发挥基层党员干部作用，广泛发动群众，激发农民群众改善自身生活条件的主动性和积极性。
