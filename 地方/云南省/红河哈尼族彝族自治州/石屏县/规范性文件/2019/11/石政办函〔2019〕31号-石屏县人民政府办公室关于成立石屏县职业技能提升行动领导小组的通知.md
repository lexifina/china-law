# 石屏县人民政府办公室关于成立石屏县职业技能提升行动领导小组的通知

各乡镇人民政府，县属各部门：

为深入贯彻《红河州人民政府办公室关于印发推行终身职业技能培训 推进职业技能提升行动计划实施方案( 2019—2021年)的通知》(红政办发〔2019〕41号)，经县人民政府研究，决定成立石屏县职业技能提升行动领导小组，现将有关事项通知如下：

一、主要职责

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，落实州政府职业技能提升行动的有关要求，推动开展职业技能提升行动，加强技能人才队伍建设，协调各乡镇、各部门开展工作。加强政策供给，完善工作机制，解决重点问题，加强工作督导和服务，加大宣传力度，指导各单位开展工作。

二、组成人员

（一）领导小组

组建石屏县职业技能提升行动领导小组，领导小组统筹研究职业技能提升行动重大政策和相关工作，指导专项行动工作开展落实。成员如下：

（二）办公室

石屏县职业技能提升行动领导小组下设办公室，承担领导小组日常工作。办公室主任由陶刚同志兼任，副主任由王丽同志担任。办公室负责承担综合协调，组织开展政策研究制定及协调，进行工作任务分解、信息报送、统计和政策宣传宣讲、督查指导等工作，指导开展补贴培训信息实名制管理等。办公室下设3个小组。

综合协调组：负责办公室综合协调工作，组织开展政策研究制定及协调工作，进行工作任务分解。

宣传统计组：负责信息报送、统计和政策宣传宣讲工作。

督查指导组：负责督查指导等工作，指导开展补贴培训信息实名制管理工作。

三、工作内容

（一）落实职业技能提升行动方案。研究相关政策，分解下达工作任务，完善实名制信息管理制度，部署和指导各乡镇、各部门开展职业技能提升行动工作。

（二）召开会议研究工作。传达贯彻省、州关于职业技能提升行动工作的重要指示精神，研究重点工作举措，协调解决难点问题，统筹推进工作，并定期向县委、县政府报告职业技能提升行动工作进展情况。

（三）组织开展调研督导。领导小组适时组织对各乡镇、各部门进行调研督导，领导小组各成员单位要结合自身职能加强对乡镇指导并及时解决工作中的问题。

（四）加强宣传统计工作。督促落实相关信息日常报送和季报、年报制度，加强统计工作，汇总分析各乡镇、各部门工作进展情况，组织开展宣传宣讲和政策解读工作。

领导小组成员如有变动，由相应职务的人员自行接替，不再另行发文。
