# 石屏县人民政府关于下达2019年退役士兵安置计划的通知

有关乡镇人民政府，县属有关部门：

为确保我县退役士兵安置任务按时完成，经过摸底调查，经县人民政府同意，提出了我县2019年退役士兵接收安置计划，现将有关事项通知如下:

一、拟定安置岗位

县人民武装部民兵武器仓库1名、县交通运输局公路路政管理大队1名、坝心镇林业和草原服务中心1名、牛街镇水务服务中心1名、牛街镇社会保障服务中心1名、龙朋镇农业综合服务中心1名、龙武镇农业综合服务中心1名、龙武镇国土和村镇规划建设服务中心1名、大桥乡社会保障服务中心1名、新城乡文化广播电视服务中心1名，共计10名。

二、相关要求

（一）县退役军人事务局要与用人单位认真对接，按有关政策做好选岗工作，确保完成符合条件退役士兵的安置任务。

（二）县委编办、县财政局、县人社局、县退役军人事务局要认真落实好各项政策，确保2019年11月15日前圆满完成选岗任务。

2019年11月4日
