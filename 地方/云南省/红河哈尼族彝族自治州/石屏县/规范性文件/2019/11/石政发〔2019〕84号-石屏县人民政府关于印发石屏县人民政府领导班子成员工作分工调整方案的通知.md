# 石屏县人民政府关于印发石屏县人民政府领导班子成员工作分工调整方案的通知

各乡镇人民政府，县属各部门：

根据石屏县人民政府领导班子成员调整情况和工作需要，《石屏县人民政府领导班子成员工作分工调整方案》已经石屏县人民政府党组会议、石屏县第十六届人民政府第37次常务会议研究，并报上级党委备案同意，现印发给你们，请按此联系工作。

2019年11月11日

（此件公开发布）

石屏县人民政府领导班子成员工作分工调整方案

根据《中华人民共和国宪法》《中华人民共和国地方各级人民代表大会和地方各级人民政府组织法》《石屏县人民政府工作规则》规定，县人民政府实行县长负责制，县人民政府其他领导成员协助县长工作，并按照分工负责处理分管工作。

张鹏程同志：领导并主持县人民政府全面工作。负责党风廉政建设和反腐倡廉及审计工作。直管县审计局。

李 宏同志：负责县人民政府常务工作。统筹协调县人民政府重大事项、重要工作。负责财政、人力资源和社会保障、自然资源、住建、应急管理、古城保护与开发服务、搬迁安置等工作。协助县长抓好党风廉政建设和反腐倡廉及审计工作。

分管县人民政府办公室（县人民政府外事办公室）、县财政局（县人民政府国有资产监督管理局、县人民政府金融工作办公室）、县人力资源和社会保障局、县自然资源局、县住房和城乡建设局（县人民防空办公室、县城市管理综合行政执法局）、县应急管理局、县古城保护与开发服务中心、县搬迁安置办公室。协管县审计局。

联系县人大常委会、县纪委、县监察委、县委编办、县人武部、驻屏部队、县消防救援大队（县综合应急救援大队）、县税务局、州住房公积金中心石屏管理部、人民银行石屏支行、工商银行石屏支行、农业银行石屏支行、建设银行石屏支行、县农村信用合作联社、邮政储蓄银行石屏支行、财产保险公司石屏支公司、人寿保险公司石屏支公司、人寿财产保险公司石屏支公司。

胡连平同志：协助县长工作。负责卫生健康、市场监督管理、医疗保障、残联、妇女儿童等工作。

分管县卫生健康局（县中医药管理局、县防治艾滋病局）、县市场监督管理局（县人民政府食品安全委员会办公室）、县医疗保障局、县残联、县红十字会、县妇儿工委。

联系县政协、县妇联、县关工委。

许 浩同志：协助县长工作。负责发展和改革、工业经济、生态环境、水务、统计、异龙湖管理、招商等工作。

分管县发展和改革局（县粮食和物资储备局、县能源局）、县工业商务和信息化局（县无线电管理办公室、县中小企业局）、州生态环境局石屏分局、县水务局、县统计局、异龙湖管理局（石屏县异龙湖国家湿地公园管理局）、石屏工业园区管理委员会（石屏豆制品特色产业园区管理委员会）、县投资促进局。

联系县工商联、石屏供电局、邮政石屏分公司、电信石屏分公司、移动石屏分公司、联通石屏分公司。

彭继伟同志：协助县长工作。负责民族宗教、综合交通、农业农村、林业和草原、精准扶贫、供销合作、两烟等工作。

分管县民族宗教事务局、县交通运输局、县农业农村和科学技术局（县畜牧兽医局、县糖办）、县林业和草原局、县扶贫办、县森林公安局（县公安局森林警察大队）、县供销社、县烟办。

联系县科协、县气象局、石红高速公路建设指挥部、州烟草公司石屏分公司（县烟草专卖局）。

王国永同志：协助县长工作。负责教育体育、文化旅游、退役军人事务、地震等工作。

分管县教育体育局、县文化和旅游局（县文物局）、县退役军人事务局、县地震局。

联系县总工会、团县委、县委县直机关工委、县文联、云南广播电视网络公司石屏支公司。

唐 虎同志：协助县长工作。负责公安、司法、信访、政务服务管理、政务公开、社会稳定、突发公共事件应急管理、打击走私等工作。

分管县公安局、县司法局、县信访局、县政务服务管理局（县行政审批局、县公共资源交易管理局）。

联系县法院、县检察院。

胡 弢同志（挂职）：协助县长工作。协管县扶贫办、县投资促进局。

唐 萍同志（挂职）：协助县长工作。负责民政工作。

分管县民政局（县勘界办）。

吴春华同志（挂职）：协助县长工作。协管县教育体育局、县卫生健康局（县中医药管理局、县防治艾滋病局）。

刘 永同志：负责县人民政府办公室日常事务、机关事务等工作。

分管县机关事务局。

石屏县人民政府领导的工作既有明确分工，又有协作配合。分工协作关系为：

李宏—许浩—胡弢，胡连平—王国永—吴春华，彭继伟—唐虎—唐萍。
