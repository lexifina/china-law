# 绿春政办关于印发绿春县2017年农田水利改革实施方案的通知

各乡镇人民政府，县直有关单位：

《绿春县2017年农田水利改革实施方案》已经县人民政府同意，现印发给你们，请认真抓好贯彻落实。

绿春县人民政府办公室

2017年9月14日

绿春县2017年农田水利改革实施方案

为贯彻落实《云南省人民政府办公厅关于推广农田水利改革试点经验的意见》（云政办发〔2015〕98号）、《红河州人民政府办公室关于推广农田水利改革试点经验的实施意见》（红政办发〔2016〕122号）和《云南省水利厅关于印发2017年农田水利改革行动计划的函》（云水函〔2017〕235号）精神，进一步深化农田水利改革，加快推广、提升农田水利改革试点经验，结合绿春县2017年农田水利工作实际，制定本实施方案。

一、目标任务

围绕加快高原特色现代农业发展和脱贫攻坚工作，按照“先建机制、后建工程”的原则，实施一批农田水利改革项目，因地制宜建立初始水权分配、合理的农业水价形成、社会资本参与、节水奖励和精准补贴、群众全程参与、工程管护、产权制度改革、节水减排合同管理等机制，不断完善与高原特色现代农业和农村经济跨越发展相适应的农田水利投入、建设、运营、管理的体制机制。积极争取多方投入中央资金390万元，发展高效节水灌溉面积0.48万亩以上，其中：水利部门0.48万亩。

二、改革范围

2017年中央和省级安排补助立项建设的小型农田水利重点县、高效节水灌溉、山区“小水网”等农田水利项目，均纳入全面深化农田水利改革范围。

三、改革内容

（一）总体要求。以高效节水灌溉建设为主，依托小型农田水利重点县建设，推进农田水利设施配套完善，因地制宜建立初始水权分配、合理的农业水价形成、社会资本参与、节水奖励和精准补贴、群众全程参与、工程管护6项机制，加快解决农田水利“最后一公里”问题，促进高原特色现代农业持续健康发展。

（二）县级重点督促的改革区域。2017年，县级以大黑山罗布巩片区肉桂种植高效节水灌溉项目为重点区域，通过“先建机制、后建工程”，大力吸引社会资本参与，发展高效节水灌溉面积0.38万亩以上，为全县发展高效节水灌溉、促进高原特色现代农业发展、改善农村生态环境提供示范和引领。

四、实施计划及时间步骤

（一）实施计划。2017年，以绿春县大黑山罗布巩片区肉桂种植高效节水灌溉项目、绿春县大兴镇马宗村委会山区“小水网”建设项目为重点，示范带动推进农田水利改革工作。

（二）制定方案。由水务部门梳理提出2017年度农田水利改革项目清单，牵头组织制定年度农田水利改革实施方案，细化目标任务，明确工作措施，确保2017年农田水利改革工作顺利推进。各乡镇和县级相关部门要将改革清单和实施方案于2017年9月20日前报县水务局备案。县水务局要根据上报的农田水利改革项目清单，及时与各乡镇签订2017年度农田水利改革目标责任书。

（三）组织实施。2017年10月30日前，完成项目机制方案和工程方案评审批复、招投标工作并开工建设；11月30日前，工程建设全面完工；12月底前，完成年度农田水利改革工作检查考核和总结工作。

五、保障措施

（一）建立工作机制。县农田水利建设领导小组要进一步建立完善农田水利改革协调机制，定期研究推进农田水利改革有关事项，协调解决改革推进过程中的困难和问题。各乡镇要认真贯彻落实《农田水利条例》，尽快建立由政府牵头，相关部门参加的农田水利规划委员会，强化政府在农田水利项目建设中的主体作用，完善相应工作机制，加快编制并批复包括发改、财政、国土、农业、扶贫、烟草、水务等涉及农田水利建设项目的县级农田水利建设“十三五”规划，提出规划项目清单，将责任细化到乡镇、部门，确立县级农田水利规划在农田水利建设中的指导地位，整合项目，集中治理，扎实推进农田水利设施建设。

（二）落实责任分工。各有关部门要根据《绿春县人民政府办公室关于推广农田水利改革试点经验的实施方案》（绿政办发〔2017〕111号）要求，明确部门工作职责，全面落实农田水利改革主体责任，加强协调配合，做好督促指导，组织实施好2017年农田水利改革工作，确保农田水利改革目标任务顺利完成。

（三）抓好项目前期。在农田水利项目前期方案编制工作中，要坚持与发展高原特色现代农业和脱贫攻坚工作紧密结合，按照“先建机制、后建工程”的原则，切实把好改革机制设计关，项目机制方案审定后，方可进行工程方案审批，确保工程建设方案与改革机制方案同时设计、同时审批、同时施工、同时投入运行。

（四）强化检查考核。把全面深化农田水利改革工作纳入年度综合考评范围，加强督促指导和考核结果应用，考评情况将作为下一年度农田水利改革项目资金安排的重要参考依据。下半年，将由县水务局牵头，会同县级有关职能部门分片对各乡镇推进农田水利改革工作情况进行督导检查。

（五）加强宣传培训。县直有关部门要切实加强农田水利改革的政策解读、经验总结、舆论引导，及时传达中央和省、州、县深化农田水利改革的政策，及时回应社会关注的热点问题，宣传改革取得的突出成效，营造全社会关心、关注和参与农田水利改革的良好氛围。要切实加强农田水利改革培训，提高培训的针对性和时效性，不断提升推广农田水利改革经验的工作能力和业务素质。
