# 绿春县人民政府关于印发2018年度整合财政涉农资金补充调整方案的通知

各乡镇人民政府，县级各有关部门：

《绿春县2018年度整合财政涉农资金补充调整方案》已经县人民政府研究同意，现予印发，请遵照执行。

绿春县人民政府

2019年1月7日

绿春县2018年度整合财政涉农资金

补充调整方案

为全面贯彻落实中央、省、州脱贫攻坚战略部署，优化财政涉农资金供给机制，全力推动统筹整合使用各类性质相近的涉农资金，精确瞄准贫困地区和建档立卡贫困对象，集中财力打赢脱贫攻坚战。结合我县实际，于2018年3月编制了《绿春县2018年统筹整合使用财政涉农资金调整实施方案》，方案编制计划整合财政涉农资金49,224万元。根据《云南省财政厅 云南省扶贫办关于做好2018年贫困县涉农资金整合试点工作的通知》云财农〔2018〕61号文件要求，于8月31日对年初整合方案进行了调整，调整形成了《绿春县2018年统筹整合使用财政涉农资金调整实施方案》，将计划整合资金49224万元调整为60856.85万元（中央资金48035.03万元、省级资金10776.82万元、州级资金2045万元）。根据财政部财政扶贫“问与答”第三期要求，绿春县于2018年12月31日再次对2018年8月31日的《绿春县2018年统筹整合使用财政涉农资金调整实施方案》进行了补充调整，补充调整资金1432.21万元（第七批中央统筹整合涉农资金20万元、县级财政专项资金20万元、2017年盘活存量资金1392.21万元）。

附件：绿春县2018年统筹整合使用财政涉农资金补充调整表
