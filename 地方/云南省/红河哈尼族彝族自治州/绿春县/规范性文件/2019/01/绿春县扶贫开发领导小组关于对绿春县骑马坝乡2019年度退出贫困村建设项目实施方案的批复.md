# 绿春县扶贫开发领导小组关于对绿春县骑马坝乡2019年度退出贫困村建设项目实施方案的批复

骑马坝乡人民政府：

《骑马坝乡人民政府关于上报骑马坝乡坝嘎村委会2019年度退出贫困村建设项目实施方案的请示》（骑政发〔2018〕115号）《骑马坝乡人民政府关于上报骑马坝乡玛玉村委会2019年度退出贫困村建设项目实施方案的请示》（骑政发〔2018〕116号）《骑马坝乡人民政府关于上报骑马坝乡托河村委会2019年度退出贫困村建设项目实施方案的请示》（骑政发〔2018〕117号）《骑马坝乡人民政府关于上报骑马坝乡东龙村委会2019年度退出贫困村建设项目实施方案的请示》（骑政发〔2018〕118号）收悉。经研究，现批复如下：

一、原则同意《骑马坝乡坝嘎村委会2019年度退出贫困村建设项目实施方案》《骑马坝乡玛玉村委会2019年度退出贫困村建设项目实施方案》《骑马坝乡托河村委会2019年度退出贫困村建设项目实施方案》《骑马坝乡东龙村委会2019年度退出贫困村建设项目实施方案》。

二、请严格按照《中央财政专项扶贫资金管理办法》（财农〔2017〕8号）《云南省财政专项扶贫资金管理办法》（云财农〔2017〕213号）《关于进一步加强财政专项扶贫资金管理的意见》（红财农发〔2017〕42号）《绿春县统筹整合使用财政涉农资金管理办法（试行）》（绿政发〔2018〕34号）《绿春县统筹整合使用财政涉农资金项目管理暂行办法》（绿政发〔2018〕72号）等文件规定管理使用项目资金，并按照项目建设实施方案，认真组织实施，及时上报项目实施进度。要加强项目和资金管理，不得随意变更项目，严格执行扶贫项目“三项制度”，认真开展廉政文化进项目活动，加强资金监管，杜绝拉用、挪用现象发生，确保资金足额投入。要加强督促检查力度，强化工作措施，提高扶贫资金使用效益，确保按质、按量、按时完成各项建设任务。
