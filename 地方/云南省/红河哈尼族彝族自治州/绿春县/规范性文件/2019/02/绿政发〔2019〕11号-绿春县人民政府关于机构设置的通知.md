# 绿春县人民政府关于机构设置的通知

各乡镇人民政府，县直各委、办、局：

根据中共红河州委、红河州人民政府批准的《绿春县机构改革方案》（红办发﹝2019﹞17号）文件，以及县人民政府依法报请县人大常委会备案的绿春县人民政府机构设置情况，现将绿春县人民政府机构设置通知如下：

绿春县交通运输局

绿春县水务局

绿春县政务服务管理局

二、绿春县人民政府工作部门加挂牌子机构

绿春县发展和改革局加挂绿春县粮食和物资储备局、绿春县能源局牌子。绿春县工业商务和信息化局加挂绿春县无线电管理办公室、绿春县中小企业局牌子。绿春县财政局加挂绿春县人民政府国有资产监督管理局、绿春县人民政府金融工作办公室牌子。绿春县住房和城乡建设局加挂绿春县人民防空办公室、绿春县城市管理综合行政执法局牌子。绿春县农业农村和科学技术局加挂绿春县畜牧兽医局牌子。绿春县文化和旅游局加挂绿春县文物局、绿春县哈尼梯田管理局牌子。绿春县卫生健康局加挂绿春县中医药管理局、绿春县防治艾滋病局牌子。绿春县市场监督管理局加挂绿春县人民政府食品安全委员会办公室牌子。绿春县政务服务管理局加挂绿春县行政审批局、绿春县公共资源交易管理局牌子。

三、绿春县人民政府直属事业单位

绿春县机关事务局

绿春县投资促进局

绿春县地震局

绿春县搬迁安置办公室

绿春县数据发展中心

四、绿春县人民政府工作部门管理的正科级行政机构

绿春县自然资源公安局（绿春县公安局自然资源大队）由绿春县林业和草原局、绿春县公安局实行双重管理。

五、上级部门的派出机构

红河州生态环境局绿春分局作为红河州生态环境局的派出机构。
