# 绿春县人民政府办公室关于调整绿春县人民政府食品安全委员会组成人员的通知

各乡镇分管食品安全工作领导

县人民政府食品安全委员会下设办公室在县市场监督管理局，具体承担县人民政府食品安全委员会的日常工作，办公室主任由毕云峰同志兼任，办公室副主任由施七文、罗哈山、李刚努同志兼任。各乡镇要建立食品安全委员会相应组成人员及办公室，健全组织，明确职责。

今后县人民政府食品安全委员会成员若有变动，由相应职务人员接替，不再另行发文。
