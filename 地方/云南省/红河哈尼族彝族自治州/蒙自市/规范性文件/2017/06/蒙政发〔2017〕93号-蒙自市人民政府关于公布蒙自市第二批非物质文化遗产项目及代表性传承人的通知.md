# 蒙自市人民政府关于公布蒙自市第二批非物质文化遗产项目及代表性传承人的通知

各乡镇人民政府，各委、办、局：

根据《中华人民共和国非物质文化遗产法》、《云南省非物质文化遗产保护条例》及州非物质文化遗产保护方面的相关文件要求，我市组织开展了第二批蒙自市非物质文化遗产名录项目申报工作，通过筛选和评审，经三届市人民政府第二次常务会研究同意，并按照有关规定进行了公示，现将老寨苗族山歌等5个项目公布为蒙自市第二批非物质文化遗产项目、纪枚等99人为蒙自市第二批非物质文化遗产项目传承人。

市文体旅广局要完善非物质文化遗产项目传承人动态管理考核机制，加强对传承人监管。各乡镇、各部门要认真贯彻执行有关法律法规，按照“保护为主、抢救第一、合理利用、传承发展”的工作方针，坚持科学的保护理念，扎实做好非物质文化遗产名录项目的保护和管理工作，进一步传承和弘扬我市优秀民族民间传统文化，努力推动全市非物质文化遗产保护工作迈上新台阶。
