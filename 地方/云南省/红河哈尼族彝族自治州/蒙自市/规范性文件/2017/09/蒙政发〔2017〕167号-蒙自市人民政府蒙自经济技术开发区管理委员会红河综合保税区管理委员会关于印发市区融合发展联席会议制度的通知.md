# 蒙自市人民政府蒙自经济技术开发区管理委员会红河综合保税区管理委员会关于印发市区融合发展联席会议制度的通知

各有关部门：

为加强市、区融合发展工作的组织领导和统筹协调，特制定《市区融合发展联席会议制度》，现印发你们，请结合实际认真贯彻执行。

蒙自市人民政府

蒙自经济技术开发区管理委员会

红河综合保税区管理委员会

2017年8月16日

市区融合发展联席会议制度

为加强市、区融合发展工作的组织领导和统筹协调，明确职责分工，形成分工明确、运转有序的工作机制，有效推动市、区融合发展，建立市、区融合发展联席会议制度（以下简称“联席会议”）。

一、主要职能

联席会议在州委、州政府的领导下，研究解决涉及市、区融合的具体问题，互通市、区信息，共商融合发展事宜；研究建立市、区融合发展规划监督管理机制，实行多规合一，涉及市、区融合发展的经济社会发展规划、城市总体规划、土地利用规划及其他专项规划实行统一备案，确保功能上高度契合，布局上无缝对接；协商创新推进教育、医疗、交通、生活等基础设施互通共享机制，推动市区硬件和软件上的深度融合；研究整合市区招商资源，共抓招商工作；研究推动就业融合，建立招工、就业、创业的良性用工机制，不断增强滇南中心城市的核心竞争力。

二、机构组成

联席会议由红河综合保税区管委会、蒙自经济技术开发区管委会，蒙自市主要领导担任总召集人，分管领导担任召集人，三方各相关部门主要负责人为成员。三方各自设立联席会议办公室，蒙自市联席会议办公室设在市政府办，由蒙自工业园区管委会主任张瑞华担任办公室主任，市政府办主任汪永安担任办公室副主任，成员根据工作需要从成员单位抽调，承担联席会议日常工作，承办联席会议交办事项，落实联席会议议定事项。联席会议设联络员，由三方联席会议办公室主任或副主任担任，若联系人有变更需及时报送其他联席会议办公室备案。

三、工作机制

（一）建立联席会议制度。建立蒙自市和经开区、综保区良性互动机制，实行市、区双月联席会制度，采取轮值主持方式，分别由蒙自市、经开区、综保区轮值召集联席会，每次联席会由轮值主持方负责筹备并收集提交会议议题，组织召开。若有需要联合解决的紧急事项或重大事项，可由提出方联席会议办公室拟订方案，提交其他两方联席会议办公室共同组织召开。

（二）建立联合调研制度。为提高议事效率，三方联席会议办公室根据工作需要，不定期组织开展专题联合调研，对发展状况和问题进行实地调研、交流探讨和分析研究，制订切实可行的解决方案，加快推动市区深度融合。

（三）完善信息共享机制。建立信息快速有效的互通、共享工作机制。三方联席会议办公室定期收集市区融合工作计划、政策文件等在联席会统一印发；定期收集市区融合发展工作的重要事项、典型经验、突出问题等，形成书面材料报送另外两方联席会议办公室，呈送各领导机构成员单位。

四、工作要求

（一）加强组织领导。蒙自市、综保区、经开区要高度重视市、区融合发展工作，根据《关于推进市区融合发展的实施意见》（蒙政发〔2017〕98号）精神，联合制订联席会议组织机构，确保联席会议不走形式，高效召开。

（二）注重跟踪督办。为确保联席会议取得实效，会上列出的工作事项，要做到定时限、有检查、有督办、有总结。轮值主席方联席会议办公室要认真做好会议记录，行成会议纪要及任务清单，督促相关部门狠抓落实，并及时将办理结果进行反馈。每次联席会议要通报上一次联席会议列出工作事项的办理情况，确保联席会议研究事项都能得到高效解决。

（三）形成工作合力。市、区融合发展是州委、州政府的一项重要的决策部署，是推动滇南中心城市二次跨越发展的重要举措。蒙自市、综保区、经开区要高度重视，把市区融合发展列入全年工作的一项大事，相互配合，抓好抓实。三方联席会议办公室要加强沟通，紧密配合，形成工作合力，切实解决工作中遇到的困难和问题，确保各项工作任务落到实处。
