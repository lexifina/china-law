# 蒙自市人民政府办公室关于成立蒙自市驻蒙中央和省属国有企业“三供一业”分离移交工作领导小组的通知

各乡镇人民政府，市直各单位：

为加强我市对驻蒙中央和省属国有企业“三供一业”分离移交工作的领导和指导，经市人民政府研究，决定成立蒙自市驻蒙中央和省属国有企业“三供一业”分离移交工作领导小组。现将组成人员通知如下：

组 长：赵渐强 市委常委、常务副市长

副组长：彭高启 市财政局局长、市国资局局长

成 员：徐 涛 市政府办副主任

刘 梅 市财政局副局长、市国资局副局长

杨 垚 市发改局局长助理

师向忠 市工信局副局长

付成刚 市人力资源社会保障局副局长

赵 伟 市国土资源局副局长

陈进良 市住建局副局长

王兴科 市水务局副局长

周 磊 云南电网公司红河供电局蒙自分局局长

顾勋虎 市消防大队助理工程师

领导小组下设办公室在市财政局，由市财政局副局长刘梅兼任办公室主任，成员由相关单位抽人组成。负责统筹协调具体事务，完成领导小组交办的工作任务。

以上人员如遇人事变动，由相应职务人员接替工作，不再另行发文调整。

蒙自市人民政府办公室

2018年5月14日
