# 蒙自市人民政府办公室关于成立蒙自石榴种植系统申报中国重要农业文化遗产领导小组的通知

各乡镇人民政府、各有关部门：

为了保护和挖掘蒙自石榴种植系统和文化底蕴，积极将蒙自石榴种植系统申报中国重要农业文化遗产。经研究，决定成立蒙自石榴种植系统申报中国重要农业文化遗产领导小组，现将领导小组组成人员名单通知如下：

组 长：姜 伟 市长

副组长：杨云鸿 副市长

黄明生 副市长（挂职）

成 员：汪永安 市政府办主任

杨雪萌 市政府办副主任

宋 京 市民宗局副局长、市政府办副主任（挂职）

张国飞 市农科局局长

杜志明 市文体育旅广电局局长

彭 岗 雨过铺镇镇长

陆俊宇 草坝镇镇长

冯光荣 市果蔬站站长

张 莹 市果蔬站副站长（推广研究员）

工作领导小组下设办公室在市农科局，办公室主任由张国飞同志兼任，成员由相关单位抽调组成。具体负责收集报送有关申报材料和日常工作。

今后如有人事变动，由领导小组成员单位新任相应职务人员接替工作，不再另行文。
