# 红河州市场监督管理局关于印发《红河州市场监督管理局随机抽查事项清单（第一版）》的通知

各县市市场监督管理局，州局有关科室：

根据《国务院关于在市场监管领域全面推行部门联合“双随机、一公开”监管的意见》（国发〔2019〕5号）和《市场监管总局关于全面推进“双随机、一公开”监管工作的通知》（国市监信发〔2019〕38号）、云南省市场监管局关于印发《云南省市场监督管理局随机抽查事项清单（第一版）》（共计25大项，72小项）的通知要求，现制定《红河州市场监督管理局随机抽查事项清单（第一版）》。各地可结合实际制定本部门随机抽查清单。

红河州市场监督管理局

2019年8月6日
