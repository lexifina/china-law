# 金平县人民政府关于中央环境保护督察反馈意见问题整改情况的报告

州环境保护督察工作领导小组办公室：

按照《中共红河州委办公室 红河州人民政府办公室关于印发红河州贯彻落实中央环境保护督察反馈意见问题整改总体方案的通知》（红办发〔2017〕28号）和《红河州环境保护督察工作领导小组办公室关于进一步明确中央环境保护督察反馈意见问题及报送要求的通知》（督字〔2017〕第8号）要求，金平县对照方案，将涉及我县的问题逐一进行分解、落实，确保整改工作按期完成。现将整改情况报告如下：

一、对生态环境保护认识不深、要求不严、落实不力

（一）2005年底前注册营运的黄标车淘汰工作进度较慢，与国家要求差距较大

开展车主、车辆、驾驶人参加的三见面活动，组织学习黄标车淘汰相关政策，督促及时办理车辆淘汰报废注销手续。严格执行《机动车强制报废标准规定》，对达到国家强制报废规定的，一律强制报废。对达到国家强制报废标准逾期不办理注销登记的机动车，公告机动车登记证书、号牌、行驶证作废。严格执行排放标准规定的机动车登记。按照相关规定国四以下排放标准车辆，一律不予办理注册登记和外地转入登记。公安、环保、交通等部门进行认真调研，制定黄标车限行和禁行规定，加强对黄标车的通行管控。经排查摸底，我县涉及黄标车及老旧车辆345辆，近期交警大队加大路面查处力度和宣传教育力度，报废老旧机动车3辆。

（二）在新环境保护法实施以来的环境案件数量和行政处罚总额与上级的要求差距较大

积极贯彻新《环保法》，深化环境综合执法体制改革，实施三级“网格化”监管模式，建立了县、乡、村三级环境监管网格，深入排查环境风险隐患，依法严厉打击环境违法行为。由于近年来工业经济不景气，我县大部门企业处于停产状态，近期橡胶生产企业季节性复厂，已对2户橡胶生产企业进行了监察，企业对环保设施进行了维修检查，生产时确保了环保设施的正常运行，生产产生的废水、废气经环保设施进行处理，未发现环境违法行为。

（三）1.已建成的城镇污水处理厂中，有相当一部分存在管网不配套、截污不彻底等问题，建制镇生活污水处理设施、生活垃圾处理设施建设不到位

2017年度州住建局下达金平县污水管网建设任务11公里，近期新建0.15公里污水管网，累计完成2.4公里，完成22%。乡镇已开工建设金水河镇、勐拉镇、勐桥乡生活垃圾处理设施建设及勐桥乡、马鞍底乡生活污水处理设施建设，完成投资378万元，累计完成工程进度30%。

2.建制村环境综合整治不到位

我县已完成金平县勐桥乡骂卡村委会石洞村农村环境综合整治项目、金平县大寨乡大寨村农村环境综合整治工程、金平县大寨乡大都马村、金平县金河镇马鹿塘、白马河村委会农村环境连片整治工程、金平县马鞍底乡标水岩哈尼民俗文化村、勐拉镇田头村6个农村环境综合整治项目实施方案编制并通过评审，其中金平县金河镇永平、白马河村委会农村环境连片整治工程于2016年6月获得项目资金120万元，项目由金河镇人民政府组织实施，目前已基本完工。

（四）监测站、监察大队编制偏少，未达到国家建设标准。在公车改革中，环境保护执法执勤用车没有得到有效保障

按照《中共云南省委机构编制办公室 云南省环境保护厅关于进一步加强州县两级环境监测监察机构建设的通知》（云编办〔2017〕72号）要求，拟同意县环境监测站增加1名事业编制、县环境监察大队增加7名事业编制，共计增加8名事业编制。待编委会通过，将于近期行文。

二、一些工作推进不严不实，个别企业环境问题群众反映强烈

（一）全州城乡规划总体落后，建设管理水平较低，环境“脏、乱、差”现象比较普遍

为进一步提升人居环境，加快推进城市环境“脏、乱、差”现象整治工作，5月3日，我县组织城区第二轮“拆违”行动，县人民政府从相关部门抽调人员成立了专项联合整治小组，并由县级领导带队，集中人力物力对乱搭乱建、占道经营、占道堆放建筑材料、乱丢乱扔、乱排乱倒等行为，以及广场公园、公共厕所、建筑工地、棚户区等重点区域及渣土车泼洒、街道楼房乱贴小广告等突出问题开展整治；加强动静态城市交通秩序管理，着力加强乱停乱放整治，规范对电动摩托车、普通两轮摩托车、农用三轮摩托车、老年人代步车等无证车辆管理，保障交通安全畅通；控制扬尘污染，整治黑臭水体，减少生活垃圾污染，严控建筑施工、交通、商业及社会活动噪声；加强对宾馆、酒店、饮食摊点、集贸市场、餐饮等服务业的环境卫生治理，重点整治服务设施落后、服务水平不高、环境卫生差等问题；整治金平河城区段垃圾；加强城乡接合部、背街小巷、社区卫生整治。本轮“拆违”行动将持续三个月左右，直至拆完为止。县委、县政府将继续加大打击力度，做到“发现一起，查处一起，新建一处，拆除一处”，进一步规范县城区内用地及建设行为和城区乱搭乱建行为，坚决维护社会公共利益，还老百姓一个和谐共享的宜居环境，为我县经济社会持续健康发展、人民安居乐业提供强有力的保障。
