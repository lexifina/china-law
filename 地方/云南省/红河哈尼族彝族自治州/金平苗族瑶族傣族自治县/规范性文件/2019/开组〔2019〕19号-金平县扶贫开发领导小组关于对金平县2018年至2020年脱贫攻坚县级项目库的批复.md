# 金平县扶贫开发领导小组关于对金平县2018年至2020年脱贫攻坚县级项目库的批复

各乡镇人民政府：

金平县2018年至2020年脱贫攻坚县级项目库动态调整，经县扶贫开发领导小组会议审定，现批复如下：

一、原则同意13个乡镇93个行政村申报的9类31项69个项目、资金投入规模25.25亿元（2018年度6.66亿元、2019年度14.73亿元、2020年度3.86亿元），其中：易地扶贫搬迁资金2.8亿元、产业扶贫4.7亿元（种植业0.87亿元、养殖业1.2亿元、创新产业发展模式1.46亿元、农业灌溉设施建设0.79亿元、就业扶贫0.38亿元）、农村危房改造4.82亿元、教育扶贫0.1亿元、健康扶贫0.23亿元、生态扶贫享受政策无资金投入、就业扶贫0.38亿元、贫困村振兴13.34亿元、兜底保障享受政策无资金投入，共计9类31项5315个项目予以入库。

二、脱贫攻坚项目库，申请入库项目规模适度，报送项目合规、可行，申报入库项目符合现行政策要求和金平县脱贫攻坚规划要求，且项目布局合理，项目储备及资金投入规模与全县脱贫攻坚任务相适应，同意纳入脱贫攻坚县级项目库管理使用。

三、按《关于进一步加强项目库建设及项目管理的实施意见》要求，在县脱贫攻坚指挥部组的统一安排部署下，项目实行动态管理，有进有出，适时更新，成熟一批入库一批，入库项目将作为今后我县脱贫攻坚项目立项实施的主要依据。

四、项目库使用。根据年度脱贫目标制定项目计划或实施方案，列入计划或实施方案的项目，从项目库中选择。

附件：金平县2018年至2020年脱贫攻坚县级项目库汇总表。

金平县扶贫开发领导小组
