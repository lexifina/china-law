# 金平县2019年国民经济和社会发展计划

今年是新中国成立70周年，也是金平脱贫摘帽的决战决胜之年。今年政府工作的总体思路是：以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会及中央经济工作会议精神，深入落实州委“13611”工作思路，按照省委十届六次全会、州委八届五次全会和县委十二届四次全会决策部署，落实州委“两个聚焦三个着力”要求，以脱贫攻坚统揽经济社会发展全局，坚持稳中求进工作总基调，坚持新发展理念，坚持高质量跨越式发展，统筹推进稳增长、促改革、调结构、惠民生、防风险各项工作，增强人民群众获得感、幸福感、安全感，保持经济持续健康发展和社会大局稳定，为决战脱贫攻坚、决胜全面建成小康社会打下决定性基础，以优异成绩庆祝中华人民共和国成立70周年。

全县经济社会发展主要目标建议为：实现地区生产总值增长9%以上，规模以上固定资产投资增长15%左右，地方一般公共财政预算收入增长2%左右，社会消费品零售总额增长11%左右，边境贸易总额增长20%以上，城镇和农村常住居民人均可支配收入分别增长8%、10%以上，单位GDP能耗完成上级下达目标任务。

围绕上述目标任务，今年重点抓好以下八个方面工作。

（一）着力抓好“四个聚焦”，奋力夺取脱贫攻坚全面胜利

2019年，全县要达到脱贫摘帽条件，必须实现8个贫困乡镇退出，58个贫困村出列，3.73万贫困人口脱贫，贫困发生率控制在1.5%以内。能否顺利达到脱贫摘帽条件事关全省、全州脱贫步伐和发展大局。我们要将全局工作聚焦脱贫攻坚，目标聚焦“两不愁三保障”，方法聚焦“户户清”，保障聚焦干部作风转变，集中一切资源、想尽一切办法、动员一切力量，与时间赛跑、同任务角力，全力考好脱贫攻坚“毕业考”，打好攻坚大会战，确保兑现如期脱贫的军令状。

打好打赢产业脱贫攻坚战。按照“横向划片区、纵向划高低”的思路，优化产业布局，培育打造一批贫困人口参与度高、能带动贫困户长期稳定增收的特色优势产业，在立足“6个10万亩”主导产业的基础上，大力发展特色养殖业，抓住“金平诺玛飞鸡”品牌打造已见成效机遇，以“龙头企业+养殖大户+合作社+贫困户”模式，发展本地鸡集中养殖；与温氏集团、文智农业公司合作，发展壮大生猪养殖业。积极发展梯田红米、百香果、稻鱼鸭等订单种养殖，拓宽群众生产性收入渠道。实行推广新的甘蔗补助政策和种植方式，提高甘蔗产业种植单产和比较效益，发展甘蔗3万亩，实现保有面积11.6万亩，实现全县有产业发展意愿的建档立卡贫困户全覆盖。实施贫困村“一村一品”产业推进计划，不断培育壮大集体经济，实现全县93个村委会村集体收入分别达到3万元以上。大力培育新型农村合作经济组织，培育州级龙头企业2家、专业合作社8个、种植大户13家、养殖大户13家。研究出台奖补政策措施，建立健全新型经营主体带动建档立卡贫困户激励机制及与建档立卡贫困户利益联结机制，实现新型经营主体带动建档立卡贫困户全覆盖，拓宽贫困群众增收渠道。研究解决收入水平略高于建档立卡贫困户的群体缺乏政策支持等新问题。

打好打赢就业脱贫攻坚战。以促进农村贫困劳动力有序组织转移就业增收为目标，以扶持人力资源服务企业为抓手，以政策、资金扶持为保障，继续采取“321”模式有组织地开展贫困劳动力转移就业工作，依托人力资源服务中介机构建立金平县13个基层农村劳务输出服务站，搭建“基层党组织+劳务合作社+人力资源公司+贫困务工群众”的效益共享劳务输出平台，推行就业扶贫政企农劳务合作“一金四保”模式，组建村级农村劳务专业合作社，建立劳务输出数据库，更加全面精准收集农村贫困劳动力就业意向信息，有针对性开展定单、定向、定岗培训，提高就业培训实效。完成农村贫困劳动力培训1.1万人，新增农村贫困劳动力外出务工0.5万人以上，全县建档立卡劳动力稳定外出务工保持在3.78万人以上，争取有就业意愿和能力的贫困户户均有1人实现外出务工。针对难以外出务工的建档立卡户，积极开发卫生清洁、村道维护、综治协管等乡村公共服务岗位，实现就地就近就业。

打好打赢易地扶贫搬迁攻坚战。加快推进易地扶贫搬迁项目，加强拆旧复垦力度，确保2016年、2017年度易地扶贫搬迁任务全面完成，2018年13个安置点按时搬迁入住，结合搬迁群众就业创业需求和意愿，做实产业就业规划和培训工作，将产业发展规划和脱贫就业计划落到实处，确保群众搬得出、稳得住、能发展、可致富。最大限度用好城乡建设用地增减挂钩节余指标交易政策，重点完成已实施5个增减挂钩项目拆旧复垦安置方案，拆旧规模2950.63亩，建新规模1263.96亩，产生节余指标1686.67亩。

打好打赢生态脱贫攻坚战。围绕扩大收益面抓实生态扶贫，把生态保护政策集中向贫困户倾斜，推进合作社造林模式，把补助资金最大化用在贫困户头上，提高退耕还林、造林补贴、生态补偿等政策收益面，实施新一轮退耕还林7.5万亩，实施城镇面山通道绿化1700亩，在建档立卡户自愿的前提下实现项目全覆盖；继续选（续）聘建档立卡贫困人口生态护林员1802人，通过参与林业管护、技术培训、获得劳务报酬实现脱贫。发挥我县50余万亩商品林资源优势，加快引进木材加工企业，延伸木材产业链，实现脱贫攻坚与生态文明双赢。

打好打赢农村危房改造攻坚战。将农村危房改造、易地扶贫搬迁作为打赢脱贫攻坚战的着力点和突破口，切实解决农村困难群众的住房安全问题。保质保量推进农村危房改造工作，积极争取中央和省级补助资金解决4类重点对象改造资金，县级统筹整合解决非4类重点对象改造资金，确保资金足额到位。压实农村危房改造包保责任，加强和优化施工队伍力量，加快工作进度，确保2019年1月底前锁定的4类重点对象15903户、非4类重点对象6677户危房存量在2019年6月底前全面“清零”，2019年6月底前锁定的4类重点对象危房存量在2019年9月底前全面“清零”，彻底消除农村危房。

打好打赢教育脱贫攻坚战。紧紧围绕办好人民满意教育这个目标，聚焦义务教育均衡发展督导评估这个脱贫摘帽前置堡垒，以“20条底线”和“十项指标”为标准，采取切实有效措施，积极筹措资金，全力推进义务教育均衡发展各项工程建设，确保按时竣工投入使用；清醒认识“控辍保学”的严峻形势，建立入学联控联保机制，落实教师、乡村干部、挂联干部等责任人的责任，开展控辍保学“清零行动”，以强大攻势、过硬措施、暖心帮助实现返校就学，做到不漏一户一人，确保顺利通过义务教育均衡发展督导评估。

打好打赢健康脱贫攻坚战。着力实施健康金平和健康扶贫行动计划，抓好村级卫生室达标建设，确保建档立卡贫困户家庭成员100%参加城乡居民基本医疗保险和大病保险，在建档立卡贫困户实行“基本医疗、大病保险、医疗救助、兜底保障”四重保障的基础上，继续实施综合保险、“顶梁柱”公益保险，防止因病致贫返贫；持续推进家庭医生签约服务，努力做到“签约一人、履约一人、服务一人”。

打好打赢革除陋习攻坚战。全面推进移风易俗革除陋习，大力倡导丧事简办、喜事新办，杜绝大操大办、大吃大喝。规范修订村规民约，强化村规民约约束和执行落实，依法打击别有用心人员利用村规民约进行道德绑架、挑拨民族关系、胁迫或煽动群众参与群体性治安事件的行为。全面推广“以表现换积分、以积分换物品”的“爱心公益超市”自助式帮扶做法，在每个行政村建设一个“爱心公益超市”，建立“以奖代补”正向激励机制，激发群众内生动力。探索设立“红黑榜”，加大对攀比跟风、环境脏乱差、无原则争当贫困户等不良行为的曝光力度，引导贫困群众知法守法。

打好打赢八大攻坚战，我们要加大县级财政投入，用好专项扶贫资金，整合涉农资金、金融贷款以及社会帮扶资金，确保资金投入只增不减。要强化一把手总负责制，选优配强乡村扶贫队伍，压紧压实帮扶干部责任，实行常态化督查巡查。要深化与外交部定点扶贫和上海东西部扶贫协作联系，加强与省、州帮扶单位联系对接，开展好“万企帮万村”行动，争取更多社会帮扶力量。要注重“志智”双扶，激发贫困群众脱贫的主观能动性和荣誉感。要加大脱贫攻坚政策落实、工作推进、帮扶成效、资金管理督查力度，大力整治责任落实不到位、工作措施不精准、工作作风不扎实等问题，以更有力的行动、更扎实的工作，确保群众满意、考评通过、顺利摘帽。

（二）持续打好防范化解重大风险攻坚战和污染防治攻坚战，全力营造安全稳定环境，守护滇南生态安全屏障

以更高的政治站位深化认识，始终把防范化解重大风险政治责任扛在肩上、抓在手上，持续深入整改中央巡视组交办的问题。仔细梳理各领域存在的重大风险隐患，切实做到底数清、情况明。通过盘活国有资产、压缩“三公”经费等一般性支出、积极培植新税源、规范开展政府与社会资本合作等措施，逐年偿还现有政府债务。对政府性投资项目，要进行充分论证，科学确定建设规模及标准，认真落实建设资金来源，切实管控政府性债务风险。深入推进社会信用体系建设，开展互联网金融风险和非法集资专项整治，严厉打击非法集资、民间高利借贷等违法违规金融活动，保持经济持续健康发展和社会大局稳定。发挥金平县政通投资开发有限公司和金平县城市投资开发有限责任公司平台作用，不断提升“造血”功能。

深入学习贯彻习近平生态文明思想，牢固树立“绿水青山就是金山银山”的生态理念，抓好分水岭国家级自然保护区、中国•红河蝴蝶谷和哈尼梯田生态环境保护。继续做好中央环境保护督察“回头看”及省级环境保护督察反馈意见问题整改落实工作。加强环境监管，严把新上项目环保关，严控高污染、高能耗、高排放和产能过剩产业项目建设。实施好“河（湖）长制”，强化域内河流排查管控和综合治理，改善河流水域环境。扎实开展工业废气、机动车尾气等专项治理，继续巩固现有空气质量成果。推动金平县电动汽车推广应用及产业发展，加快充电设施规划与建设，逐步形成布局合理、便捷高效、覆盖全县的充电设施服务网络。淘汰落后产能，强化土壤污染管控与修复。加强农村面源污染综合防治，持续加强畜禽养殖污染治理。启动省级生态文明县创建工作，推进美丽乡村农村环境综合连片整治工作。

（三）抓紧抓实四大项目建设，有力夯实脱贫摘帽坚实基础

把项目建设作为经济发展的主抓手，把全年目标任务落实到具体项目上，通过抓项目带投入促发展。要围绕脱贫攻坚、资源优势、区位优势、边贸发展等抓紧谋划、储备一批项目，并有序推进，打好发展基础，增强发展后劲，形成“大抓项目、抓大项目、抓好项目”的良好局面，为全县脱贫摘帽提供有力支撑。

抓好交通项目：加快推进元蔓高速公路（金平段）、蔓金高速公路建设，力争启动金平县城至金水河口岸高速公路项目。进一步牢牢把握农村公路建设主攻方向不动摇，建设“四好农村路”，计划总投资4.27亿元，力争启动实施2019年“直过民族”地区自然村通硬化路项目38个、50户以上不搬迁自然村通硬化路项目85个；启动铜厂至老勐至老集寨、104至营盘公路路面修复，者米向阳村至老集寨坪寨公路提升改造工程；启动建设马堵山库区小河口大桥。实施26个建制村公路生命防护工程，保障广大群众出行安全。

抓好水利项目：计划完成水利投资4.13亿元，继续推进铜厂水库、那兰水电站水资源综合利用和河堤治理等在建重点水利工程；启动建设麻子河大寨段、金水河曼棚段、茨通坝河茨通坝段等中小河流治理工程，力争实施金勐灌区节水配套改造等一批水利项目。按照贫困退出考核标准，实施饮水保障项目。

抓好能源通信项目：围绕打造“绿色能源牌”，加快推进金水河三级、荞菜坪三级、三家河三级、三家河一级水电站项目建设，力争投产发电。全面推进光伏扶贫工程，在13个乡镇82个贫困村建设光伏扶贫电站78座，装机规模8200千瓦，促进1640户6090名建档立卡贫困人口增收脱贫。抓好勐桥乡龙脖河至马鞍底乡地西北、金河镇热水塘至金水河镇隔界、勐拉镇老乌寨至者米乡木吾寨等边境沿线村寨的通信基础设施建设，让广大边境群众及时听到党和政府的声音。

抓好城市基础设施项目。完成金河镇公共人员防空及避难场所、城市污水处理厂管网完善等重点市政工程；新建城市公厕3座、改造3座；启动金平县垃圾收转运、城市污水处理厂提标改造工程。加快汇金半岛、滨江尚城、中景•濠廷房地产项目建设，完成房地产开发投资1亿元。

（四）调优调精产业发展结构，致力提升县域经济发展质量

着力推进农业产业提质增效。围绕打造“绿色食品牌”，突出“一县一业、一乡一特、一村一品”，重点提升橡胶、香蕉、甘蔗、油茶、人工商品林、生物药材6个10万亩以上长效主导产业。推广橡胶林下套种阳春砂仁、魔芋，发展橡胶林下经济；加强香蕉病虫害防治，引导农户轮作或改种，实现良种良法配套实施；创新油茶产业发展模式，逐步实现规模化发展、示范化种植、科学化管理，加强与国内知名油茶企业联系对接，实施油茶提质增效项目。抓好生物药材产业培育，以“公司+合作社+农户”模式，推广迷迭香种植与精深加工，建设构树试验示范种植基地1000亩。积极推进“南板蓝根”“金平砂仁”“金平人参”“金平诺玛飞鸡”“马鞍底古树茶”地理标志证明商标注册申报工作，引导、鼓励涉农企业走品牌发展道路，有效保护优质特色产品，促进产业品牌快速发展。实施以奖代补推动农业产业向高质量发展，夯实全县农业产业发展基础。
