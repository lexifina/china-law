# 金平县扶贫开发领导小组办公室关于2019年度第三批统筹整合使用财政涉农资金项目实施方案的批复

各乡镇人民政府、金平农场，县农科局、县林草局、县水务局、县交通局、县住建局、县发改局、县人社局、县教体局、县扶贫办，分水岭管护局：

根据你们上报的2019年度第三批统筹整合使用财政涉农资金项目实施方案，并经2019年7月7日县扶贫开发领导小组第三十四次会议研究同意，现将2019年度第三批统筹整合使用财政涉农资金项目实施方案批复如下：

一、整合资金来源

根据红河州财政局 红河州农业农村局《关于下达2019年州级农业生产发展专项资金和绩效目标的通知》（红财农发〔2019〕19号）、红河州财政局《关于下达2019年第五批中央统筹整合涉农资金的通知》（红财整合〔2019〕9号）、红河州财政局《关于下达2019年第八批中央统筹整合涉农资金的通知》（红财整合〔2019〕10号）、红河州财政局《关于下达2019年第七批中央统筹整合涉农资金的通知》（红财整合〔2019〕11号）、红河州财政局《关于调整安排2019年第一批中央财政专项扶贫资金的通知》（红财农发〔2019〕36号）、红河州财政局《关于下达贫困县2019年度第二批中央财政专项扶贫资金的通知》（红财整合〔2019〕12号）、红河州财政局《关于下达2019年第十批中央统筹整合涉农资金的通知》（红财整合〔2019〕14号）、红河州财政局《关于下达2019年第三批省级统筹整合涉农资金的通知》（红财整合〔2019〕13号）、红河州财政局 红河州扶贫办《关于下达2019年州级财政专项扶贫资金的通知》（红财农发〔2019〕34号）、红河州财政局 红河州扶贫办《关于下达2019年州级南部山区综合扶贫开发专项扶持资金的通知》（红财农发〔2019〕24号）等文件要求，将以上文件指标资金纳入2019年度第三批统筹整合，合计资金45812.35万元。

二、项目资金用途

严格按照《金平县统筹整合使用财政涉农资金管理办法（试行）》（金政发〔2019〕29号）和县扶贫开发领导小组第三十四次会议研究批复方案执行，不得随意改变资金用途。

三、加快项目推进

请各乡镇和县级项目责任部门在接到批复文件后，必须在30日内启动项目实施，超过规定时间未启动实施的，按规定收回项目及资金。

四、做好公示公告

全面实行项目公示公告制度，资金项目要事前公示、事后公告，按照“谁分配、谁公开，谁使用、谁公开，分配到哪里、公开到哪里”的原则，分级进行公示公告。财政专项扶贫资金、涉农整合资金、参照财政专项扶贫资金管理的资金及项目，全部纳入公告公示范围；各项目实施单位要在项目实施前进行公示，竣工验收后进行公告，引导贫困群众参与扶贫项目决策、管理和监督，接受群众和社会监督。请各项目单位在接到文件后10个工作日内，将项目实施方案报县脱贫攻坚指挥部项目管理组备案。

五、做好台账资料

项目启动后及时建立台账资料，按照金平县扶贫开发领导小组办公室《关于加快财政专项扶贫资金项目竣工验收的通知及附件》（金贫开办发〔2017〕52号）以及《金平县统筹整合使用财政涉农资金管理办法（试行）》（金政发〔2019〕29号），有关规定，做好项目检查验收和台账管理。
