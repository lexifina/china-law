# 金平县人民政府关于同意关闭金平华盈矿业有限公司水源铜镍矿等4座矿山的批复

县自然资源局：

你局《关于关闭金平华盈矿业有限公司水源铜镍矿等4座矿山的请示》（金自然资发〔2019〕41号）收悉，经金平第十三届县人民政府第26次常务会议研究，现批复如下：

一、同意关闭金平华盈矿业有限公司水源铜镍矿、金平县勐拉乡红岩采石场石灰岩矿、金平县金河镇黄家寨深沟石灰石矿、金平县金河镇火绳冲建筑石料用灰岩矿等4座矿山。

二、请县自然资源局依法依规办理有关手续，并做好矿山监管有关工作。

2019年8月9日
