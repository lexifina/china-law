# 关于“巴事快办”项目筹备建设情况汇报

（2019年5月17日）

市政务服务局

各位领导、同志们：

按照会议安排，我就启动建设“巴事快办”项目有关情况及下一步重点工作安排做一汇报。

一、“巴事快办”项目基本情况

（一）项目建设的背景

为深化全市“放管服”改革，进一步优化地区营商环境，市政务服务局主动学习借鉴上海“一网通办”、北京“街乡吹哨、部门报到”、江苏“不见面审批”、浙江“最多跑一次”、山东“直通快办”等地区的先进做法，在2018年实施“互联网+政务服务”工程的基础上，启动实施了 “巴事快办”项目，项目主要内容为：面向企业、群众和政府部门，打造集政务、公共和社会服务于一体的“12345”政务服务热线平台，线上线下“一窗受理”政务服务综合平台，重大项目直通快办平台，效能监察平台。通过启动实施“巴事快办”项目，积极构建群众诉求一号响应机制，打造含盖审批服务、公共服务、便民服务，线上线下业务受理、监督管理、绩效考核、数据分析等多功能于一体的政务服务平台，实现群众有诉求，政府有反应，件件有回音，事事有落实，全力打造巴彦淖尔政务服务升级版。

（二）项目建设具体内容

一是建设市民热线服务平台。按照“属地管理、分级负责”的原则，开通巴彦淖尔市“12345”市民热线服务平台，统一部署推进整合全市各类政务服务热线电话，形成一号受理、分类处理、限时办理、超时问责、结果反馈政务服务工作机制。将群众通过网络、手机、电话、书信等渠道反映的诉求，汇集到12345市民热线服务平台，解决政务热线“打不通、无人接、态度冷、说不清”和群众投诉无门，部门不作为、慢作为等问题，努力做到政务服务“一号对外”、“一号响应”、“一站式服务”。同时，开发政务数据分析平台，形成统计分析成果，辅助政府科学决策。

二是建设线上线下“一窗受理”政务服务综合平台。线下实体大厅将部门分设的办事窗口整合为综合受理窗口，凡属承诺件、联办件均纳入“一窗受理”范围，实行“前台综合受理、后台分类审批、综合窗口出件”，办事群众与审批部门不见面，由原来群众跑窗口变为综合受理窗口人员代跑、代办。线上办事大厅整合各部门网上办事入口，推动部门业务信息系统接入巴彦淖尔网上办事大厅，使各类政务服务事项纳入网厅“一窗办理”，让群众少跑腿，数据多跑路。

三是开发建设重大项目直通快办平台。实行重大项目全程在线实时督查、督办工作机制，将发改、工信部门确定的重大项目纳入平台管理，实行直通快办模式，全程实时反映重大项目在相关部门的审批流程、审批进度及存在的问题，为负责项目推进的相关部门和领导实时督查、督办项目落地提供实时状态查询，提升项目建设效率，保障项目快速落地。

四是建设政务服务效能监察平台。通过12345市民热线服务平台、线上线下综合窗口受理平台、重大项目直通快办平台汇集的办件数据，通过与各级纪委监委建立联动响应机制，对不作为、慢作为、乱作为精准问责，倒逼部门改进作风，提高行政效率，提升群众满意度。

（三）项目投资概算及进度

该项目软硬件总投资为1256万元（项目软件费用550万元，硬件费用614万元，室内改造装修101万元），项目每年运维费用约200万元。4月22日，市局组织召开专家论证会，计划于近期开始招投标（项目软硬件通过单一来源招标，室内改造及日常运维拟通过面向社会公开招投标）。计划在8月底前，完成四大平台的开发、部署、设备安装调试及培训工作。

二、存在的问题和建议

（一）“巴事快办”项目运行工作机制问题。“12345”政务服务热线实行一个平台、三级（市、旗县区、苏木乡镇街道）调度运行机制。目前，急需各旗县区建立指挥调度机构，抓紧组建旗县、苏木乡镇街道两级指挥调度中心。建议各旗县区政府将此项工作列入“一把手”工程，统筹落实场地建设、机构和人员配置，建立工作机制、运行机制和督查考核制度机制。会后，明确一个牵头部门负责推进项目建设和运行，按照项目建设方案相关要求,尽快制定本地、本部门配合实施“巴事快办”项目的具体工作措施,明确责任书、路线图和时间表,由专人具体负责,建立强有力的工作推进机制，确保如期完成建设，高效运转。

（二）权责清单梳理的问题。此轮机构改革完成后，一些新设立或涉改部门的权责清单还未确定，建议各地各部门按照法律法规的立、改、废情况和各部门“三定”方案，尽快重新调整梳理，并公布部门权责清单。依照权责清单，重新梳理事项要素，实现全部事项标准化、颗粒化，为群众诉求精准派单，以及实现“一表申请”“一套材料”“一窗受理”提供基础保障。目前，市直部门已经基本完成了清单梳理工作，请各旗县区加快进度，确保5月底前完成权责清单梳公布工作。

（三）部分热线整合的问题。目前，我们正在对全市所有热线情况进行梳理摸底，热线整合方案还不成熟，哪些需要整合，如何整合，哪些不能整合，与12345平台如何对接正在调研，下一步将组织工作人员外出调研考察，借鉴先进地区的先进经验和成功做法，尽快制定可操作性的热线整合方案，启动“12345”政务服务热线。建议市直各部门积极参与对接，认真配合完成调研摸底工作，并提出建设性意见建议。

（四）重大项目库建设的问题。目前，我市重大项目库尚未建立，建议由市发改委、市工信局、住建局依照职责分别牵头确定全市重点项目建设库清单，纳入“巴事快办”平台管理，实行直通快办模式，为负责项目推进的相关部门和领导在线督查、督办项目情况提供实时状态查询，提升项目建设效率，保障项目快速落地。

（五）平台整合市场服务资源的问题。按照“资源整合、功能优化”建设原则，“巴事快办”平台要将政府提供的服务和市场提供的服务融合汇聚，实现平台功能最大化，让平台为老百姓提供更加全面、更加专业的服务。鉴于目前我们对市场提供的服务事项，包含市场主体类别、数量、服务供给内容、场所、联系方式等要素情况还不掌握，底数不清，资源整合方案还未成熟。下一步，请市各部门协助配合此项调研工作，尽快形成“12345”市民服务热线平台资源整合方案，完善平台服务内容，让平台发挥更大功能。
