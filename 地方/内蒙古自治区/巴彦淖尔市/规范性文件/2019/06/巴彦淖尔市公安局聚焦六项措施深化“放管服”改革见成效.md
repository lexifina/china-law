# 巴彦淖尔市公安局聚焦六项措施深化“放管服”改革见成效

今年以来，巴彦淖尔市公安局按照“六个一”“五个为”“三集中三到位”的要求，结合解决群众办事办证难度堵点问题，不断出台便民利民惠民举措，有序下放审批权限，拓展和延伸便民服务的渠道和内涵，全力优化营商发展环境，助推全市经济社会高质量发展。

一是梳理“网上办”行政审批及服务事项。在2018年实现46个行政审批及服务事项“网上办”“一体办”的基础上，今年又梳理确定包括性别变更、出生日期变更、出入境公民回国恢复户口、宣告死亡恢复户口、因私出入境记录查询、公安监管场所远程视频预约会见、公安监管场所被监管人员家属会见(探访)安排、公安监管场所律师会见电话(网上)预约8个行政审批及服务事项可实现“一体办”。下半年可纳入“网上办事大厅”办理。

二是推进落实“警邮合作”项目，最大限度方便群众。充分利用邮政营业网点分布广泛和物流速递服务便利快捷的优势，依托邮政网点代办8类车驾管业务，方便群众就近办理业务。目前，已在7个乡镇的邮政所建立了“警邮便民服务站”。

三是在全区率先实现身份证业务电子支付。临河区公安局积极与自治区财政厅及中国农业银行沟通联系，于2019年2月1日，户政服务大厅及局属23个派出所在全区率先开通身份证工本费微信支付服务，缴纳费用将直接存入公安厅身份证专款账户。截至目前，乌拉特前旗公安局和乌拉特后旗公安局户籍办证大厅及所属派出所户籍室也已开通了电子支付缴费，6月份前全市户籍办证大厅及所有派出所将全部开通。

四是办理出入境证件全面启用电子快捷支付。市公安局联合工商银行巴彦淖尔分行升级了出入境证照办理缴费系统，拓展现有支付方式，群众办理出入境证件可选择现金、刷卡、微信、支付宝、银联二维码等多种方式进行支付，进一步缩短了办证时间。目前，市、旗县区所有出入境接待窗口均、已开通运行。

五是研发使用外国人临时住宿登记移动警务APP。市公安局结合“互联网+公安出入境服务”的思路，委托系统开发公司研发了外国人临时住宿登记移动警务APP，留宿人员只需要扫描外国人护照资料页即可自动识别申请人的基本信息。APP的使用减轻了民警的工作量，提高了工作效率，进一步加强散居社会面外国人管理，提高了信息录入采集的及时率、准确率、合格率。

六是及时启动实施小型汽车驾驶证全国“一证通考”等10项改革措施落地工作。2019年6月1日起，将在全国范围内推行10项车驾管改革利民措施，市公安局交管支队赴重庆、四川考察后，结合工作实际找准难点，提前安排部署，出台工作方案和任务分解表，陆续实施包括选定4S店、培训工作人员、购买设备、做好分科目收费等前期准备工作。
