# 关于做好2014年全市企业经济效益月度快报工作的通知

通辽市财政局关于做好2014年

全市企业经济效益月度快报工作的通知

各旗县（市、区）财政局:

为进一步做好2014年全市企业经济效益月度快报（以下简称“月报”）工作，提高企业财务信息的时效性、全面性和准确性，根据《内蒙古自治区财政厅转发财政部关于做好2014年企业经济效益月度快报工作的通知》（内财工[2013]2333号），并结合我市实际，就有关事项做如下要求，请遵照执行。

一、做好扩大月报编报范围工作

（一）各旗县（市、区）财政局应加大扩大月报编报范围的工作力度，将符合规定标准的国有企业、已纳入财政资金扶持范围和需要申请财政资金扶持政策的非国有企业，全部纳入月报编报范围。

2014年度自治区财政厅工业交通处将把企业报送月报作为申报财政

资金支持政策的考核内容，对未列入编报范围的企业，各级财政部门原则上不予支持。

（二）已纳入月报编报范围的企业，除因关闭、重组、破产等特殊原因外，不得擅自停报。未经批准停报企业，不得申报任何财政资金支持项目。如有确实无法继续报送月报的企业，需及时经当地财政局向市财政局工业交通科报备，并说明停报原因。

二、报送要求

各旗县（市、区）财政局要高度重视月报工作，指定专人负责，做好报送督促工作。各报送单位每月9日前上报纳入编报范围企业的分户数据。各旗县（市、区）财政局负责此项工作人员要及时登录工业交通信息管理系统（http://202.99.230.234/netrep），了解本地区企业上报情况，并进行督促（登录用户名：150500）。

2014年月报仍采用网上数据报送的形式，各报送单位登陆工业交通管理信息系统（http://202.99.230.234/netrep）进行数据的报送及审核。

月报工作联系电话：0475-8836642。

三、考核奖励制度

年终市财政局根据各旗县（市、区）企业上报数据的完整性、及时性、准确性及编报范围扩大情况等进行考核，根据各项考核情况确定年度先进单位，并予以通报表彰。

2014年1月23日
