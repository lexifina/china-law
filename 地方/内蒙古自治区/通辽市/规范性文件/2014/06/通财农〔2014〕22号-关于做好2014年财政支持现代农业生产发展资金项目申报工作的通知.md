# 关于做好2014年财政支持现代农业生产发展资金项目申报工作的通知

通财农〔2014〕22号

通辽市财政局关于做好2014年财政

支持现代农业生产发展资金项目申报工作的通知

旗县市区财政局、通辽经济技术开发区财政局：

根据自治区财政厅《关于做好2014年财政支持现代农业生产发展工作的通知》（内财农〔2014〕596号）及通辽市“8837”发展思路关于建设绿色农畜产品输出基地的战略部署，为做好2014年财政支持现代农业生产发展资金项目申报工作，现将有关事宜通知如下：

一、基本原则

（一）自治区宏观指导，地方自主选项。根据中央1号文件、自治区7号文件及“8337”发展思路提出的建设我区绿色农畜产品输出基地要求，各旗县市区根据当地资源条件、产业状况、发展潜力等，科学确定发展目标、重点项目和政策措施，分类申报。2014年，现代农业生产发展资金主要支持肉羊、肉牛、中心城市蔬菜等优势特色产业。

（二）突出重点，确保效果。财政支持现代农业生产发展资金按照“扶优扶强、多方投入、集中连片、打造精品”的总体要求，突出产业选择、支持环节、区域布局三个方面的重点，即突出支持主要优势农畜产品生产、突出解决制约主导产业发展的关键环节、突出支持优势产业带建设。项目区选择体现“三个优先”：一是优先支持发展优质、安全、高效、生态、品牌农牧业，促进农牧业生产、生态保护和农牧民增收，各盟市要围绕农畜产品生产环境安全、农产品质量安全、资源节约型和生态友好型农业科技等，因地制宜促进优势特色主导产业可持续发展。二是以主导产业为承接，加大对产业内各类新型主体的支持力度，推动农业生产经营体系创新。项目实施主体优先向农牧民合作组织、家庭农牧场倾斜，同等条件下优先扶持。三是同等条件下，旗县（区）整合各类资金支持项目建设较多的优先支持，项目实施主体自筹资金较多的优先支持。

（三）整合资金，多方投入。按照“渠道不乱、用途不变、统筹安排、集中投入、各负其责、各计其功、形成合力”的原则，各级财政部门要加大资金投入，并积极整合各级各部门的相关资金、技术等资源，加强协作配合，形成齐抓共管、共同推进的良好局面。同时，充分发挥财政资金的引导作用，引导社会各方面增加对农牧业产业发展投入，把现代农业生产发展资金项目打造成资金整合的新平台，引领社会资本投资的新领域。

（四）竞争立项、差额淘汰。项目申报经市级财政实地考察，遴选汇总后上报自治区，将依据“公开、公正、公平”的原则，由自治区财政厅组织专家，采取实地考察、专家评审、现场答辩、综合评分等方式，对各类申报的项目进行评分排名，实行差额淘汰。最终立项结果将通过内蒙古自治区财政厅门户网站统一对外公示，接受社会监督。因资金、名额所限暂不能安排的项目，如本身项目质量较高，可纳入储备项目库，在下一年度优先考虑。

二、财政资金扶持环节及方式

（一）扶持环节。按照财政部要求，财政支持现代农业生产发展资金支持环节原则上不超过2个，并体现“看得见、可操作、能量化、能考核”的要求。结合我区实际，支持的具体环节：肉羊、肉牛产业重点支持良种繁育、育肥和家庭牧场标准化棚圈建设；蔬菜产业重点支持蔬菜生产基地建设（以日光温室、大棚建设为主）。

（二）扶持方式。采取先建后补、以奖代补等方式。

三、项目申报

（一）申报程序。项目申报由盟市财政部门牵头，会同有关部门按照“公开、筛选、上报”的程序，组织符合条件的旗县（区）政府自愿申报。确定申报项目后，由旗县（区）政府制定项目总体实施方案。旗县（区）政府对项目的真实性、合规性、准确性负责。

（二）报送内容。旗县（区）政府关于旗县（区）发展优势特色产业的申请文件申报文件、及旗县（区）项目实施方案。方案内容主要包括：主导产业发展状况、实施区域选择、项目建设内容、资金投入概算（总投入、旗县（区）投入、申请盟市以上财政投入情况及自筹情况等）、资金整合方案（整合资金名称、规模、使用重点）、预期效益和组织保障措施等。

（三）报送时间。盟(市)财政部门将所属旗县（区）实施方案汇总后，于2014年6月25日前上报市财政局，逾期不予受理。今年初个别已经申报到自治区财政厅的相关项目也应纳入此次范围统一重新申报，并参与竞争立项。今年已经列入并已下达资金的项目旗县（区）不再申报。

四、有关要求

（一）高度重视，精心组织申报。财政支持现代农业项目实施主体是旗县（区）政府。旗县（区）政府应高度重视，精心组织，充分调动和发挥部门的积极性，认真编制项目实施方案，落实项目建设资金。市级财政部门将对旗县（区）项目的选择进行指导工作，项目建设必须充分尊重和体现项目实施主体的意愿。

（二）实事求是，合理确定投资规模。旗县（区）政府要根据产业发展需求，实事求是地确定项目投资规模，不得盲目夸大投资规模。市级财政部门与旗县（区）政府签订项目实施协议，督促旗县（区）足额落实配套、整合及自筹资金。

（三）加强配合，建立协调沟通机制。各级财政、农业、水利等部门要建立完善定期通报、定期联席会议等协调沟通机制，明确职责分工，理顺工作程序，密切协作配合，共同抓好财政支持现代农业生产发展项目申报和后续管理工作。财政部门负责做好牵头协调、资金管理和绩效评价等工作，加强对项目建设单位财务的监督检查，及时落实财政整合配套资金，督促项目单位足额落实自筹资金，根据项目建设进度拨付财政资金，加快预算执行。各级农业等部门负责抓好项目管理，牵头组织开展项目督导督促、技术指导服务等工作。
