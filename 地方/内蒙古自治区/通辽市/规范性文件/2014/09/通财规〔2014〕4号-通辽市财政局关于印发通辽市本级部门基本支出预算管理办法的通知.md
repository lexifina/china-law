# 通辽市财政局关于印发通辽市本级部门基本支出预算管理办法的通知

市委各部委，市人大常委会办公厅，市政府各委、办、局，市政协办公厅，市中级人民法院、人民检察院，通辽市各人民团体，市直属事业单位：

现将《通辽市本级部门基本支出预算管理办法》印发给你们，请结合实际，认真贯彻执行。

2014年9月9日

通辽市本级部门基本支出预算管理办法

第一章总则

第一条为规范和加强市本级行政事业单位基本支出预算管理，提高资金使用效益，保证行政事业单位正常运转，根据《中华人民共和国预算法》、《中华人民共和国预算法实施条例》及自治区部门预算管理有关要求，结合我市实际，制定本办法。

第二条本办法适用于所有纳入市本级部门预算编制范围的市直属行政、事业单位和群团组织（以下统称“预算单位”）的基本支出预算管理。

第三条基本支出预算是部门预算的组成部分，是行政事业单位为保障其机构正常运转、完成日常工作任务而编制的年度基本支出计划。

第四条基本支出预算编制原则：

一、综合预算原则。基本支出预算的编制，统筹考虑预算内外资金，合理安排人员支出和公用支出。

二、优先保障原则。优先保障单位基本支出的合理需要，保证机构正常运转。

三、定额管理原则。基本支出预算实行定员定额管理，结合单位资产占有状况，建立单项定额标准、综合定额标准、行业定额标准，实现资产管理与定额管理相结合。

四、厉行节约原则。日常公用支出要精打细算，严禁铺张浪费，严格控制“三公经费”等一般性支出。

第二章基本支出的范围

第五条根据政府收支分类科目，基本支出分为人员支出和公用支出。

第六条人员支出包括支出经济分类科目“工资福利支出”和“对个人和家庭的补助”。

（一）工资福利支出包括基本工资、津贴补贴、奖金、社会保障缴费、绩效工资、伙食补助费、其他工资福利支出等。

（二）对个人和家庭的补助支出包括离退休费、退职（役）费、抚恤金、生活补助、救济费、医疗费、助学金、奖励金、住房公积金、购房补贴、其他对个人和家庭的补助等。

第七条公用支出包括支出经济分类科目“商品和服务支出”和“其他资本性支出”中属于基本支出范围的支出。包括：办公费、印刷费、水费、电费、邮电费、物业管理费、差旅费、因公出国（境）费用、维修（护）费、会议费、培训费、公务接待费、工会经费、福利费、公务用车及其他交通工具运行维护费、离退休人员管理费、办公设备购置、其他商品和服务支出等。

第八条基本支出范围随财政部颁布的政府收支分类科目进行适时调整。

第三章基本支出预算定额管理

第九条本办法所称的定员，是指机构编制主管部门根据部门的性质、职能、业务范围和工作任务所下达的人员配置标准；定额，是指财政部门根据各单位机构正常运转和日常工作任务的基本需要，结合财力实际，统筹考虑预算内外资金，对基本支出的各项内容所确定的预算额度。

第十条基本支出预算定额包括人员支出预算定额和公用支出预算定额。

第十一条人员支出预算定额根据预算单位性质、人员配置标准内的实有人数，以及组织、人事、老干部局等部门确定的人员支出的各类定额标准核定。

第十二条公用支出预算定额根据预算单位所承担的职能、工作量、占用的资源和编制内实有人数等实际情况，予以分类分档设定。

第十三条行政单位（包括政法单位）公用支出，实行单项定额和综合定额相结合的预算管理。公用支出中，可以量化到物的支出，按单项定额标准和符合国家、自治区及市政府规定的实物配置数核定预算；不能量化到物的支出，按量化到人的综合定额标准和机构编制主管部门核定的编制内实有人数核定预算。

第十四条事业单位公用支出，结合单位各自职能和业务特点实行差别化预算管理。行政执法类事业单位，参照行政单位的公用支出预算管理方式；部分行业特点明显的事业单位采用行业定额标准管理方式；其他事业单位采用单项定额和综合定额相结合的管理方式。

第十五条定额标准的执行期限与预算年度一致，定额标准一经下达，在年度预算执行过程中不作调整。定额标准的调整在预算年度开始前进行，在确定下一年度定额标准时，财政部门综合考虑各项影响因素，提出调整预算定额标准意见，报市政府审定后，于编制下一年度部门预算前公布。

第四章基本支出预算的编制和审批

第十六条基本支出预算从基层预算单位编起，逐级上报，经主管部门审核汇总后报财政部门审核。具体编制和批复程序按财政部门编制年度部门预算的要求执行。

第十七条人员支出预算根据国家、自治区和市政府制定的人员经费开支标准和预算单位报送的基础数据及相关资料进行编制。

第十八条公用支出预算根据财政部门编制年度预算公布的定员定额，结合预算单位行业特点分类编制。

第十九条基本支出基础信息库是核定基本支出预算的重要依据，各预算单位应保证填报数据的真实性、准确性和及时性。

第二十条基本支出预算中按照规定属于政府采购的项目，预算单位必须单独分列集中采购或分散采购项目，并逐项列明项目名称、数量及金额。

第二十一条财政部门对预算单位报送的基础数据和相关资料进行审核，核定基本支出，列入部门预算。

第二十二条财政部门按照规定程序将预算（草案）提请市政府常务会议审议、市委常委会审定，提交市人民代表大会审议通过。

第五章基本支出预算的执行和监督

第二十三条预算年度开始后，当年部门预算在市人民代表大会审议通过前，财政部门参照上年同期支出数和当年预算控制数先行拨付预算单位的基本支出，保证行政事业单位的正常运转。部门预算经市人民代表大会审议通过后，财政部门及时批复部门预算，并按批准的预算执行。

第二十四条各预算单位要严格按照有关政策规定、开支比例、范围和标准执行基本支出预算。预算执行过程中，人员支出与公用支出之间不得调剂使用，公用支出单项定额之间、单项定额与综合定额之间原则上不能调剂使用，实行综合定额的各项支出内容之间可调剂使用。公用支出预算实行总额控制管理，超支不补。

第二十五条基本支出预算一经下达，原则上不予调整。在预算执行中影响基本支出的有关因素，一般在确定下一年度基本支出预算时统一考虑。预算年度执行中，如遇国家、自治区和市政府出台的有关政策对预算执行影响较大，确需调整基本支出预算的，按预算管理有关程序，经批准后进行调整。

第二十六条各部门及所属单位预算执行中发生的非财政补助收入超收部分，原则上不得安排当年的基本支出，应向财政部门提出申请，安排项目支出或结转下年使用；出现短收的，应及时向财政部门提出申请，调减当年预算。

第二十七条各预算单位应加强对基本支出的管理，精打细算，厉行节约，大力压缩“三公经费”等一般性支出。年终财政补助收入形成的基本支出结余资金一律收回总预算，按照结余资金管理相关规定进行统筹管理。

第二十八条各预算单位在基本支出执行过程中，要严格按照批准的预算控制各项支出，并对资金使用效益和财务活动情况进行分析和评价。

第二十九条财政部门对预算单位基本支出预算的编制、执行情况进行监督检查，对违反国家有关法律、法规和财务规章制度的，依法进行处理。

第六章附则

第三十条本办法由市财政局负责解释。

第三十一条本办法自公布之日起30日后执行。
