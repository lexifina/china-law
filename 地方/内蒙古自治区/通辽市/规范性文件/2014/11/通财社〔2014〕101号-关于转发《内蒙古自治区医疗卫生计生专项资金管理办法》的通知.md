# 关于转发《内蒙古自治区医疗卫生计生专项资金管理办法》的通知

通财社〔2014〕101号

关于转发《内蒙古自治区财政厅、卫生计生委

关于印发〈内蒙古自治区医疗卫生计生

专项资金管理办法〉的通知》的通知

各旗县市区财政局、卫生局:

为规范和加强通辽市医疗卫生计生项目专项资金管理，确保资金安全使用，明确各方责任，增强资金分配、使用的科学性、公正性、公平性，现将《内蒙古自治区财政厅、卫生计生委关于印发〈内蒙古自治区医疗卫生计生专项资金管理办法〉的通知》(内财社〔2014〕1572号)转发给你们，请结合本地区实际，认真贯彻执行。

附件：内蒙古自治区财政厅、卫生计生委关于印发《内蒙古自治区医疗卫生计生专项资金管理办法》的通知
