# 关于印发2016年帮扶包联工作进展情况及2017年工作安排的通知

市直林业各单位、局机关有关科室：

2017年1月9日市林业局党组召开会议，专题研究、安排了对奈曼旗土城子乡的帮扶包联工作，对前一阶段帮扶包联工作进行了总结，对下一步工作进行了研究部署，现将《2016年帮扶包联工作进展情况及2017年工作安排》印发给你们。脱贫攻坚工作是当前一项重大政治任务,是第一民生工程。请各单位、有关科室务必高度重视，结合各自工作实际认真抓好落实，在项目和资金上对帮扶包联工作给予配合、支持。同时，在春节即将到来之际，要切实做好包联贫困村特困户的慰问工作，为他们送去关怀与温暖。

附件：通辽市林业局扶贫包联清单

2017年1月11日

2016年帮扶包联工作进展情况及2017年

工作安排

按照市委、市政府统一部署，通辽市林业局包联奈曼旗土城子乡土城子村、后头沟村及杏树园子村（该村部分精准扶贫户）。为确保完成帮扶包联任务，市林业局组成2个下基层扶贫工作队，进村入户开展帮扶包联工作，积极落实“三到村三到户”、“金融扶贫”、“十个全覆盖”工程等，同时协助基层开展党建工作。帮扶包联工作顺利推进，并取得阶段性成效。

一、帮扶包联工作任务落实情况

帮扶包联工作开展以来，市林业局积极协调乡党委、政府的关系，两个工作队与所包联村两委班子，按照帮扶包联工作方案要求，结合“532”工作法，深入各村民小组了解情况，通过公开、公正、透明的原则，筛选精准扶贫对象，在充分征求贫困户意见的基础上，召开村民代表大会，制定扶贫实施方案，对精准扶贫户建档立卡，制定合理的脱贫计划及落实脱贫项目，明确脱贫目标与时间，真正做到“一村一规划、一户一方案”。确定到2017年包联两个村整体脱贫（后头沟村2016年底整体脱贫），共脱贫180户536人，（其中：后头沟村60户171人；土城子120户365人）；杏树园子村13个精准扶贫户脱贫。

针对奈曼南部山区缺水的自然环境，产业发展重点以养殖业为主，到目前，已落实养羊户48户441只羊；养驴户42户42头；养猪户25户100头，养鹅（鸡）户5户460只；养牛户1户1头；特色种植户2户；已批社会救助户9户，发放财政扶贫资金90万元。

二、包联工作进展情况

（一）精准帮扶。市、旗、乡确定市林业局精准扶贫户为73户，其中：土城子村40户、后头沟村20户、杏树园子村13户。2016年，经工作队走访调研，并经村“两委”班子和村民代表会讨论通过，3个村遴选出30个特困户，作为市直林业系统各党支委、支部结对帮扶的重点对象，对特困户进行精准扶贫。把此项任务作为2016年各总支、支部的党建重要活动载体来抓，定下目标到2016年底，特困户的生活有明显的改善。市林业局筹措扶贫资金20万元，购买基础母羊280只，发放到30个特困户，平均每户8只。

（二）生态扶贫。市林业局高度重视土城子乡的林业生态建设，近几年不断加大资金投入和项目扶持，特别是2016年结合“十个全覆盖”工程村屯绿化，市林业局扶贫工作队、旗林业局组织专业技术人员深入村屯规划指导村屯绿化并提供苗木，投入资金达30余万元。加强林业基础建设，投入40万元以造代育培育油松大苗1000亩，发展特色林业产业方面投入植被恢复资金50万元帮助建立800亩大扁杏经济林基地和100亩苗圃。同时加强对基层林业工作站的建设，把土城子乡林工站建设纳入到全市重点标准站建设范畴，投资金额25万元。还配备森林防火车、计算机、GPS等10余万元仪器设备；积极支持小城镇建设，投入10多万元对乡政府大院和街路进行了绿化。

三、2017年帮扶工作安排

按照市党工委及旗、乡精准扶贫工作方案要求，继续把扶贫工作作为2017年市直林业系统各支委、支部党建重要活动载体，加大资金投入力度，提高扶贫质量。

（一）精准扶贫。筹措30万元资金，完成43户精准扶贫任务（土城子村30户、杏树园子村13户）。

（二）生态扶贫。为全乡的生态建设多争取荒地造林、封山育林、低效林改造、退耕还林、村屯绿化等林业生态建设工程项目，改善当地生态环境。发展果树、大扁杏等特色林业产业，提高农民收入。

（三）扶持村集体经济发展。根据土城子位居南部山区的区位特点，选择适合于地区的村集体发展项目，填补村集体经济空白。计划投资45万元，为三个村各建一处100亩村办苗圃。

（四）协助抓好基层组织建设与党建工作。继续加强村级班子和干部队伍建设及村制度建设，推进村级民主管理，促进干群关系和谐。重点开展党的群众路线教育、两学一做、嘎查村“532”工作法、上党课等多形式多内容的各类学习，提高“两委”班子成员及所有党员的素质，加强组织教育与管理。
