# 关于规范通辽市直林业系统干部职工因私出国（境）管理工作的通知

市直林业系统各单位、局机关各科室：

根据《内蒙古自治区领导干部因私出国（境）审批管理暂行办法》、《通辽市领导干部因私出国（境）审批管理实施细则》和《关于加强国家工作人员因私出国（境）管理暂行规定》等有关规定，为了加强对市直林业系统全体干部职工因私出国（境）管理，现特要求如下 ：

1、因私出国（境）的干部职工个人应提出申请，申请内容包括：姓名、性别、出生日期、身份证号码、户口所在地、工作单位、现任职务、出入境地点及境外停留时间等信息。

2、个人申请必须由职工所在单位主要负责人签字同意后方可报局人教科。局人教科报局主要领导及分管领导签字同意后方可履行备案等相关手续。

3、因私出国（境）的干部职工个人，根据规定应与通辽市林业局签订《保密协议书》后方可出国（境）。

4、申领过出国（境）证件的干部职工，应在出国（境）归国后15日内将证件交由局人教科统一集中管理。

请各单位认真贯彻执行，切实加强对干部职工因私出国（境）的管理工作，因工作相互推诿，管理不力，出现漏洞的，要视情节追究相关人员的责任。

2017年2月7日
