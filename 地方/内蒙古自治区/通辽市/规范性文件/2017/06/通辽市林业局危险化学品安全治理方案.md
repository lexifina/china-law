# 通辽市林业局危险化学品安全治理方案

根据《通辽市安全生产委员会转发内蒙古自治区安全生产委员会关于开展危险化学品全行业安全风险排查工作的通知》通安委会字【2017】18号文件要求，我局对通辽市林业行业涉及的危险化学品进行了排查。整个行业涉及危险化学品的部门只有一个--通辽市森林病虫害防治检疫站，现制定我局危险化学品安全综合治理方案。

一、主要化学药品：氯氰菊酯、灭幼脲、苦参碱、噻虫啉、吡虫啉等农药。全部是国家允许使用药剂。

二、化学药品的用途：主要用于重特大森林虫害的灭杀。

三、储存农药地点：通辽市森林公园内的半地下碉堡。碉堡坚固安全，有厚重的铁门，从内部上锁，只有手腕伸进的开锁孔。

四、安全看护:森林公园有24小时值班人员。

五、农药储备、：由市森林病虫害防治检疫站根据虫情预测，提出药品采购计划，经政府采购购置药剂后，登记药剂品名、数量并储存于半地下碉堡的药库内。

六、调拨：如有各旗县市区森防机构急用农药时，经主管领导签字同意后，按数量、品名登记，领药人、药剂管理者、单位负责人签字审批后出库；林农及个人防治林业有害生物时领药人、药剂管理者、单位负责人签字审批后按品名、数量领取。药品有入库单、出库单，领药者、管理者、负责人签字备案。

七、药剂的使用:施药人员配备防毒面具，施药区域由当地政府发布公告、宣传单送至居民户。同时配备一定的数量的急救解毒药品，确保施药区人畜安全。
