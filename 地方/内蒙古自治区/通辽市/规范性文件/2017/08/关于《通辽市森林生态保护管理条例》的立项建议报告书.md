# 关于《通辽市森林生态保护管理条例》的立项建议报告书

市人大常委法制工作委员会：

一、立法目的

为进一步加强通辽市森林生态的保护和管理，科学合理开发利用森林资源，提高森林覆盖率，改善生态环境,促进生态文明建设，根据《中华人民共和国森林法》、《中华人民共和国森林法实施条例》等有关法律、法规，结合我市林业生态工作实际，制定本条例。

二、主要解决的问题

该条例主要解决上位法以作出原则性规定，但未有详细具体规定的有关林业生态保护的问题以及近年来全市林业生态工作中遇到需立法层面作出相关规定的问题：

1、林地保护红线的划定；

2、林地种植农作物等非林业生产活动擅自改变林地用途造成林地严重流失；

3、完善森林生态补偿的具体办法；

4、规范采伐迹地的更新造林；

5、杜绝滥放牧毁坏林木；

6、明确非林业用地上林木采伐管理；

7、集体林地限期造林绿化；

8、造林苗木种源管理；

9、部分法律责任操作性不强，需进一步量化、细化。

三、相关上位法的立法动态

目前，为适应林业改革发展的需要，国家林业局已经开展了《森林法》的修改工作，并形成了《中华人民共和国森林法（2016年修改征求意见稿）》，现公开向社会征求意见。

四、拟列入2018年调研项目。
