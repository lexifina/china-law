# 关于公布一批规范性文件清理结果的通知

各旗县市区民政局、局机关各科室、局属各单位：

按照市政府办公厅《关于开展规范性文件清理工作的通知》（通政办字〔2017〕155号）和市政府法制办《关于切实做好规范性文件清理工作的通知》（通政法办发〔2017〕20号）要求，办公室对2015-2016年以通辽市民政局名义制发的规范性文件进行全面清理。经征求各起草科室（部门）意见，同时分管领导审议后，将《通辽市民政局关于规范和简化惠民殡葬办理程序的通知》（通民社字〔2015〕16号）等16个规范性文件宣布继续有效。
