# 通辽市人民政府关于调整通辽市城镇职工基本医疗保险有关政策的通知

各旗县市区人民政府、开发区管委会，市政府各委办局：

为贯彻实施《内蒙古自治区城镇基本医疗保险条例》，进一步完善城镇职工基本医疗保险政策，提高待遇水平，保障参保人员基本医疗需求，推动我市基本医疗保险健康可持续发展，结合我市实际，决定对《通辽市城镇职工医疗保险管理办法》（通政发〔2014〕142号）相关政策调整如下：

一、调整职工基本医疗保险统筹基金支付比例

城镇职工基本医疗保险统筹基金支付比例提高5个百分点。调整后，《通辽市城镇职工医疗保险管理办法》（通政发〔2014〕142号）第十七条（三）款如下：

二、灵活就业人员自愿选择参加职工基本医疗保险建立个人账户

自2017年1月1日起，新参保的灵活就业人员，可以参加职工基本医疗保险（含用人单位转入灵活就业人员），自愿选择按照通辽市上年度在岗职工平均工资的10%缴纳基本医疗保险费，建立个人账户，个人账户计入比例按照《通辽市城镇职工医疗保险管理办法》（通政发〔2014〕142号）第九条规定执行。未达到法定退休年龄的灵活就业已参保人员，可自愿选择按照上述比例和当年缴费基数进行补缴，补缴后建立个人账户。

三、本通知自2017年1月1日起执行。
