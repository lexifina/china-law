# 关于印发《通辽市住房和城乡建设委员会贯彻落实实施方案》的通知

各旗县(市)区住建局、开发区建设发展局，各建设、设计、监理、施工单位，施工图审查中心：

根据《国务院关于优化建设工程防雷许可的决定》(国发〔2016〕39号)、《中国气象局等11部委关于贯彻落实<国务院关于优化建设工程防雷许可的决定>的通知》(气发〔2016〕79号)、《内蒙古自治区人民政府关于贯彻落实国务院优化建设工程防雷许可决定的通知》(内政发〔2016〕114号)、自治区住建厅转发《关于贯彻落实国务院优化建设工程防雷许可决定的通知》(内建设〔2016〕463号)精神和市政府要求，将我市范围内原由气象部门承担的房屋建筑和市政基础设施工程防雷装置设计审核、竣工验收等项工作均交由住房城乡建设部门负责监督管理，为认真贯彻落实以上文件精神，进一步明确和落实相关责任，加强房屋建筑和市政基础设施工程防雷安全监管，保障人民群众生命财产安全，制定《通辽市住房和城乡建设委员会贯彻落实<国务院关于优化建设工程防雷许可的决定>实施方案》,现印发给你们，请认真贯彻执行。

《通辽市住房和城乡建设委员会贯彻落实<国务院关于优化建设工程防雷许可的决定>实施方案》(通住建发〔2017〕274号)同时废止。

附件：《通辽市住房和城乡建设委员会贯彻落实<国务院关于优化建设工程防雷许可的决定>实施方案》

2018年5月30日

通辽市住房和城乡建设委员会贯彻落实<国务院关于优化建设工程防雷许可的决定>实施方案

为认真贯彻落实《国务院关于优化建设工程防雷许可的决定》等上级文件精神和市政府要求，根据《中华人民共和国气象法》、《气象灾害防御条例》、《雷电防护装置检测资质管理办法》等法律法规，结合我市住房和城乡建设工作实际，制定如下实施方案。

一、指导思想

优化建设工程防雷许可是国务院深化行政审批制度改革，推进简政放权、放管结合、优化服务，解决建设工程防雷管理领域存在的部门职责交叉、重复许可等问题而采取的又一重要改革举措，对于减少建设工程防雷重复许可、重复监管，明确和落实相关部门责任，加强事中事后监管，保障建设工程防雷安全具有重要意义。

二、职责范围

(一) 各地住房城乡建设主管部门按照属地管理和“谁审批、谁负责、谁监管"原则、负责监督管理我市范围内原由气象部门承担的房屋建筑和市政基础设施工程防雷装置设计审核、竣工验收等工作。

1.房屋建筑和市政基础设施工程防雷装置设计审核，整合纳入建筑工程施工图审查。

2.房屋建筑和市政基础设施工程防雷装置竣工验收许可，整合纳入建筑工程竣工验收备案。

3.房屋建筑和市政基础设施工程防雷及接地工程的质量和施工安全监管由各地住房城乡建设主管部门或委托质量监督部门负责。

(二)全市油库、气库、弹药库、化学品仓库、烟花爆竹、石化等易燃易爆建设工程和场所，雷电易发区内的矿区、旅游景点或者投入使用的建(构)筑物、设施等需要单独安装防雷电防护装置的场所，以及雷电风险高且没有防雷标准规范、需要进行特殊论证的大型项目，仍由气象部门负责防雷装置设计审核和竣工验收许可。

三、工作要求

(一)防雷检测单位资质和从业人员资格方面。

1.从事通辽市行政区域内房屋建筑与市政基础设施工程防雷检测业务的检测单位，须提供防雷检测资质证书和检测从业人员资格证明文件，接受项目所在地住房和城乡建设主管部门或委托的质量监督部门检查。

2.防雷检测单位及其从业人员必须具备省级气象主管部门认定的防雷检查资质和资格证明文件，并应在中国气象局政府门户网站中可查询。

3.防雷检测单位按照资质等级承担相应的防雷装置检测工作，严禁无资质、超资质、租借资质、挂靠资质从事防雷装置检测工作。

(二)防雷及接地工程过程监管方面。

1.各地住房城乡建设主管部门要督促设计单位严格按照国家和自治区相关工程设计规范标准进行房屋建筑和市政基础设施工程防雷装置设计，督促施工图审查中心按照有关法律法规、对施工图涉及公共利益、公众安全和工程建设强制性标准的内容进行审查。

2.各建设、设计、监理、施工和检测单位要切实承担起房屋建筑和市政基础设施工程防雷装置质量安全主体责任，确保防雷装置与主体工程同时设计、同时施工和同时投入使用，所安装的防雷装置应当符合法律法规、规范标准规定的使用要求。投入使用后的防雷装置应当按照法律法规和规范标准的要求定期进行防雷装置检测，确保防雷装置安全运行。

3.各地住房城乡建设主管部门或委托的质量监督部门要加强房屋建筑和市政基础设施工程的防雷及接地工程的事中事后监管，重点加强以下部位和环节监管：(1)地基基础施工过程中的接地装置安装；(2)主体结构施工过程中引下线、等电位、防侧雷击均压环、防侧雷击、设备基础、屋面外露金属物等接地预埋件安装；(3)装饰装修过程中接闪器和防雷检测点箱(盒)安装；(4)成套设备安装过程中浪涌保护器的安装。

4.为及时组织工程竣工验收和实施质量安全监管，建设单位在工程开工时，应委托具备相应检测资质的防雷检测单位开展防雷装置跟踪(竣工)检测。

5.各地住房城乡建设主管部门或委托的质量监督部门要切实履行房屋建筑和市政基础设施工程防雷监管职责，将防雷安全工作纳入安全生产综合督查、专项检查、执法检查和考核范畴，明确和落实建设、设计、施工、监理和检测单位等在防雷工程质量安全方面的主体责任，加大对不按照图纸施工、使用不合格材料等违法违规行为的抽查、巡查力度，加大对失信行为的曝光和惩戒力度，提高市场主体守法诚信意识。

(三)防雷检测过程和检测报告方面。

1.为保证防雷检测结果的真实性，由持有合法资质的防雷检测单位进行防雷检测时，建设单位要根据有关法律法规和技术标准等要求，组织设计、监理、施工、检测等有关单位对防雷工程质量进行现场联合验收，各地住房城乡建设主管部门或委托的质量监督部门要加强对验收过程的监管。

2.防雷检测单位要将防雷检测资质证明文件、从业人员资格证书及防雷检测过程和结果一并形成防雷检测报告，作为建筑电气工程的子分部工程质量验收合格证明材料，分别在工程竣工验收前和工程竣工验收备案时由建设单位提交给各地住房城乡建设主管部门或委托的质量监督部门和备案机关。

(四)与气象部门密切配合方面。

1.各地住房城乡建设主管部门或委托的质量监督部门发现防雷检测单位存在违法违规行为的，应及时移交相关部门做出相应处理，并纳入建筑市场不良行为记录。

2.各地住房城乡建设主管部门或委托的质量监督部门要与气象部门密切配合、加强协调，建立相应部门合作机制，研究解决防雷减灾管理中的重大问题，确保将房屋建筑和市政基础设施工程防雷监管各项任务落到实处。
