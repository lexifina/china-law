# 关于印发《通辽市“优质粮食工程”专项资金管理办法》的通知

各旗县市区财政局、商务和粮食局，科左后旗经信局：

为了规范和加强我市“优质粮食工程”专项资金管理，提高资金使用效益，根据《内蒙古自治区粮食局财政厅关于印发“优质粮食工程”实施方案的通知》（内粮发[2017]91号）、《关于印发“优质粮食工程”实施方案的通知》(通粮字〔2018〕8号)和《预算法》等有关规定，我们制定了《通辽市“优质粮食工程专项资金管理办法》，现印发给你们，请遵照执行。

附件：通辽市“优质粮食工程”专项资金管理办法

通辽市财政局

通辽市粮食局

2018年6月12日

通辽市“优质粮食工程”专项资金管理办法

第一章总则

第一条为了规范和加强我市“优质粮食工程”专项资金管理，提高资金使用效益，根据《内蒙古自治区粮食局财政厅关于印发“优质粮食工程”实施方案的通知》（内粮发[2017]91号）、《关于印发“优质粮食工程”实施方案的通知》(通粮字〔2018〕8号)和《预算法》等有关规定，结合我市实际，制定本办法。

第二条本办法所称“优质粮食工程”专项资金（以下简称“专项资金”），是指中央及自治区财政安排用于支持实施粮食产后服务体系建设、粮食质量安全检验监测体系建设、“中国好粮油”行动建设的专项资金。

第三条专项资金的管理和使用应当遵循“突出重点、公平公正、注重绩效”的原则。

第四条专项资金由财政部门和粮食行政主管部门共同管理，其职责分工如下：（一）财政局负责专项资金预算管理和资金拨付，会同市粮食局研究制定资金管理制度、专项资金支持重点、方向和方式，监督检查资金使用情况和绩效管理。（二）市粮食局负责专项资金项目管理，会同市财政局提出年度专项资金预算建议;制定实施方案并组织项目申报，审核确定专项资金支持具体项目，提出项目资金分配方案，下达项目计划并对项目实施情况进行跟踪管理和绩效评价。（三）旗县（市）区财政、粮食主管部门各司其职，各负其责，财政部门负责专项资金拨付和监督管理，粮食部门负责项目申报、实施、验收及绩效评价等工作。

第二章支持对象和内容

第五条专项资金的支持对象为实施“粮食优质工程”的地区、单位、粮食企业、合作社、种粮大户等新型粮食经营主体。

第六条专项资金主要用于支持以下事项：（一）粮食产后服务中心建设。主要以整合盘活现有仓储设施等资源，重点支持改造、提升粮食处理新技术、新设备，一般不得新建仓容，基建部分以维修改造为主。（二）粮食质量安全检验监测体系建设。统筹用于配置检化验仪器设备、配套基础设施建设等，提升收购环节的粮食质量安全调查和品质测报水平；入库、出库环节的质量把关检验；加强军供粮、救灾粮“放心粮油”等成品粮油的检测水平。（三）“中国好粮油”行动。主要用于开展“中国好粮油”和“内蒙古好粮油”产品的参评遴选；鼓励全市粮油加工企业加大研发产品、拓展营销渠道；支持优质粮油产粮大的旗县和具有示范带动效应的粮油加工企业，开展示范县和示范企业建设。

第三章项目申报和审核

第七条市粮食局组织旗县（市）区粮食主管部门申报。各旗县（市）区申报的项目统一上报市粮食主管部门并汇总报备自治区粮食局。

第八条各级粮食主管部门建立健全项目申报审核制度，落实项目申报、审核的主体责任，对项目的合规性、真实性、可行性负全责。

第四章资金拨付管理

第九条市财政局收到上级下达的专项资金指标后，根据项目实施方案和资金分配意见，按照国库管理相关规定下达旗县（市）区专项资金指标，旗县（市）区财政部门收到专项资金后，按照同级粮食主管部门提供的项目验收报告等相关程序拨付项目单位。

第十条资金拨付方式。根据“优质粮食工程”三个子项目建设情况，采取先建后补、以奖代补等形式拨付补贴资金。

第十一条专项资金安排使用中属于政府采购和招投标管理范畴的，应严格按照国家有关规定执行。

第五章监督管理和绩效评价

第十二条各级粮食行政管理部门督促项目单位严格遵守粮食工程建设标准和技术规范，确保工程质量和资金使用安全，不得擅自变更资金支持方向和使用内容，确需调整的，应将调整情况及调整原因报市粮食局、财政局备案后执行。

第十三条项目单位应按照粮食企业会计准则及有关会计制度进行会计核算，做到专账管理，严格按规定用途使用资金，并自觉接受财政、粮食、审计等部门的监督检查。

第十四条各级粮食主管部门要加强项目跟踪监督，对项目实施进展情况实行动态管理，及时发现和协调解决项目执行中遇到的问题，确保项目在规定时限内完成。

第十五条各级财政、粮食主管部门对项目执行情况和专项资金使用情况进行监督检查，对截留、挤占、挪用、骗取专项资金的违法行为，一经查实，严格按照《预算法》、《公务员法》、《行政监察法》、《财政违法行为处罚处分条例》等国家有关规定追究相应责任;涉嫌犯罪的，移送司法机关处理。

第十六条市粮食局、市财政局及时组织开展专项资金绩效自评工作，包括项目决策、项目管理、项目产出、项目效果等，并将专项资金绩效评价自评报告上报自治区粮食局、财政厅。

第六章附则

第十七条本办法由通辽市财政局、粮食局负责解释。

第十八条本办法自印发之日起30日后执行，有效期5年。
