# 关于做好2019年国有贫困林场扶贫资金项目工作的通知

科左中旗、科左后旗、奈曼旗、库伦旗林业局：

为帮助国有贫困林场改善生产生活条件，促进国有林场 尽快脱贫致富，自治区财政厅按照财政部的要求，提前下达 我市2019年中央财政国有贫困林场专项扶贫资金500万元。市财政局于2018年12月10日印发《关于提前下达2019年中央财政 专项扶贫资金预算的通知》（通财农〔2018〕1234号），已将扶贫资金“切块下达”到左中、后旗、奈曼、库伦4个国贫旗，资金项目审批权限完全下放到旗县，不得提出与脱贫攻坚无关的任务要求。

一、项目建设范围

按照中央6号文件和国家财政部、国家林业和草原局相关 规定，贫困林场脱贫工作要与国有林场改革安置富余职工相结合，2019年项目扶持重点，用于国有林场改革后富余职工就业安置的种苗、花卉、经济林、森林旅游等经营项目。

二、编制项目可研报告文本

各项目建设单位要组成项目可研报告编制小组，严格按照《中央财政专项扶贫资金管理办法》（财农〔2017〕78号）和《内蒙古自治区人民政府关于进一步加强扶贫资金使用管理的意见》（内政发〔2018〕21号）等文件要求，结合本场实际，科学合理确定项目建设内容，详细编制项目可研文本，细化 文本内容。

三、严格审核项目可研报告

各地林业主管部门要成立林业专家评审组（不少于5人），对林场编制完成的扶贫资金项目文本进行可行性评审，提出 评审意见并签字，形成评审报告，3月30日前,连同修改完善后的项目文本报市林业局（各一式四份）和当地财政局。

四、编制实施方案

各项目建设单位根据林业专家评审组评定后的项目文本，编制科学合理、切实可行的《项目建设实施方案》，由林业 主管部门连同《项目评审报告》报当地财政局进行财政价格 评审并报审计局备案。同时，《项目建设实施方案》一式四份上报市林业局。

五、严格项目实施和资金使用管理及工程验收

一是各项目建设单位完成的《项目建设实施方案》经财政评审后，严格按照政府招投标程序和政府采购中心批复的采购方式组织实施；二是项目资金由旗县财政统一管理，在履行 财政价格评审、政府招投标、采购中心批准采购方式等程序后，在项目建设过程中，林场提出支付申请，由财政支付中心向第三方或林场支付资金，并独立建账管理；三是按照项目 建设期限，各地林业主管部门要组织专家组，及时并严格进行项目工程的前期审查、中期评估和监督、竣工验收，并形成 验收报告，一式四份报市林业局。

六、保障措施

（一）加强组织领导。各地林业主管部门要成立贫困林场扶贫工作领导小组，具体负责扶贫项目的实施和建设，并加强监督和管理。各项目建设单位，在林业和财政部门的具体指导和支持下，精心组织，认真实施，确保项目工程保质保量按时完成。

（二）强化质量管理。加强项目建设的质量管理，严格 执行相关技术标准和要求，在项目实施过程中，始终把工程 质量放在首位，严格把好施工的每一个环节质量，确保扶贫 项目建设的质量和效益。

（三）严格资金管理。严格执行财政部、国家林业局制定的《国有贫困林场扶贫资金管理办法》，严格按照自治区财政厅、林业和草原局的相关要求，严格履行政府招投标程序和 政府采购中心批复的采购方式实施建设，做到专款专用，确保扶贫资金的规范使用。
