# 关于加强安全生产监督管理工作的紧急通知

各旗县区林业局，霍林郭勒市农牧林业局，开发区农牧林水局：

近日，锡林郭勒盟西乌旗银漫矿业公司发生重特大安全生产事故，导致多人遇难和受伤。这次事故再一次给我们敲响了警钟，安全生产必须警钟长鸣、常抓不懈，丝毫不能放松。为做好我市涉林企业安全生产监督管理工作，特提出如下要求：

一、切实增强做好安全生产工作的紧迫感和责任感

安全生产事关人民群众的生命安全，一旦出现事故，将给一个家庭造成灾难性后。旗县市区林业主管部门务必高度 重视，增强紧迫感和责任感，把安全生产监督管理工作做实 做细。认真指导督促涉林企业，切实抓好安全生产责任和措施落实，坚决防范遏制重特大生产安全事故发生。

二、狠抓涉林企业安全生产隐患排查与治理

旗县市区林业主管部门要督促涉林企业落实安全生产主体责任，对涉林企业强化隐患排查治理，着力查大风险、除大 隐患、防大事故。木材加工企业要对原料、下脚料及成品存储是否存在火险隐患进行排查，对生产车间电路及设备是否存在安全隐患进行排查；森林生态旅游企业要对旅游设施是否安全进行排查，对存在风险隐患的游客自主活动项目及时给予警示告知；其他涉林企业也要在生产经营的每个环节，注重安全 生产责任的落实。对排查出来的隐患要立即整改，要明确整改的事项、时间、目标，最大限度的降低涉林企业的安全生产 风险。

三、加强安全宣传教育，提升从业安全防范意识和能力

旗县市区林业主管部门要督促涉林企业开展安全生产 培训，进一步提升从业人员的安全防范意识和能力。各类生产经营单位要突出重点岗位作业人员，加强全员安全培训，使 从业人员了解掌握相关知识和技能，及时消除隐患，有效应对初起险情的应急处置能力。
