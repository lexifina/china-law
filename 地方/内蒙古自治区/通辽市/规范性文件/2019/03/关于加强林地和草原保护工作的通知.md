# 关于加强林地和草原保护工作的通知

各旗县市区林业和草原主管部门：

为深入贯彻落实习近平总书记在十三届全国人大二次会议内蒙古代表团审议时提出的“保护草原、森林是内蒙古生态系统保护的首要任务”的重要指示和要求，切实保护好我市林地和草原资源，不断巩固、扩大生态建设成果，现将有关事宜通知如下：

一、严格禁止乱开滥垦林地草原种植农作物。严格执行《中华人民共和国森林法》《中华人民共和国草原法》《中华人民共和国森林法实施条例》《内蒙古自治区草原管理条例》和《中共通辽市委办公厅 通辽市人民政府办公厅关于印发<通辽市开展乱开滥垦和非法开荒清理整顿工作实施方案>的通知》（通党办字〔2017〕40号）等相关法律法规政策，坚决禁止一切滥开荒破坏森林草原的违法行为。对乱开滥垦林地草原行为，依法严肃查处。

二、持续开展森林和草原资源清理整顿工作。深入开展无立木林地清理整顿恢复造林工作，严格按照无立木林地恢复造林三年规划完成2019年年度任务，对2018年无立木林地恢复造林不合格地块及时进行补植补造，确保合格。对2018年森林督查移交图斑开展“回头看”，并举一反三，对违法使用林地和改变林地用途行为坚决整改到位。深入推进违法占用草原整改工作，按照《通辽市贯彻落实中央环保督察“回头看”及草原整改问题专项督察反馈意见整改方案》要求，对未履行审核审批手续征占草原和草原滥开荒情况进行深入拉网式排查，对存在的问题全面进行整改，彻底解决未履行审核审批手续征占草原问题。征占用林地草原新建设项目，要严格按照有关法律法规办理林地草原征占用审核手续。

三、严格执行禁牧制度。严格执行《内蒙古自治区禁牧和草畜平衡监督管理办法》，全面落实禁牧和草畜平衡制度，依法查处禁牧区、禁牧期放牧和违反草畜平衡区超载放牧行为。重点生态建设工程项目区、公益林区、中幼林区、经济林地和沙化严重区域实施全年禁牧，围封育林育草，努力恢复林草植被，切实保护好生态建设成果。各地要按照相关法律法规规定，划定常年禁牧区，并设立禁牧标志。

四、严厉打击破坏森林草原违法行为。要组织森林公安、草原监理等部门成立专项行动小组，实行联合执法，加大对林地、草原巡护、监管力度，始终保持打击破坏森林草原违法行为的高压态势，坚决制止并严肃查处乱开滥垦林地草原，滥采麻黄草、甘草、苦参等野生植物及盗挖油松、五角枫等珍稀树种行为；严厉打击乱占林地草原和在自然保护区、林地、草牧场进行挖沙、采石、取土等破坏生态环境的违法行为。对发现的破坏森林草原违法行为，从严、从快侦办，并向社会发布处理情况。

五、进一步加大宣传力度。要通过报纸、广播电视、网络、发放宣传单等形式广泛宣传关于生态保护的法律法规，努力做到家喻户晓。设立监督举报电话，发动群众监督的力量。及时通报各类典型案例，发挥震慑和警示作用。

各旗县市区林业和草原主管部门要积极主动作为，立即向当地党委、政府汇报关于加强林地和草原保护工作的有关要求，切实加强林地和草原保护工作的组织领导和宣传发动工作，严格履行保护林地和草原工作职责，确保全市森林和草原得到有效保护。
