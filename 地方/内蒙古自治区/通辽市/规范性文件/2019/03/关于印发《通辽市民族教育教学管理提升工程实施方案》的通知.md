# 关于印发《通辽市民族教育教学管理提升工程实施方案》的通知

各旗县市区教育（教体）局、市直学校（幼儿园）：

为了优先重点发展民族教育，提高民族学校教育教学管理质量，将立德树人融入教育全过程，引导民族地区师生积极培育和践行社会主义核心价值观，牢固树立维护民族团结和国家统一的思想意识，通辽市教育局决定制定《通辽市民族教育教学管理提升工程》实施方案。现印发给你们。请认真贯彻落实。

2019年3月29日

通辽市民族教育教学管理提升工程实施方案

为深入推进民族教育综合改革，加强学校管理，全面提高教育教学质量，增强广大教师在岗位上有幸福感、事业上有成就感、社会上有荣誉感，加快教育现代化，建设教育强国，办好人民满意教育。根据全市民族教育发展的实际，制定通辽市民族教育教学管理提升工程实施方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的教育方针、《内蒙古自治区民族教育发展水平提升工程实施方案(2011-2015)》(内政办发〔2012〕19号)、《内蒙古自治区民族教育条例》和《通辽市中小学教育质量提升工程实施方案》（通教发〔2014〕68号）、《通辽市民族中小学校管理办法》（通教发〔2017〕41号），坚持以人为本，发展素质教育，在坚定理想信念、厚植爱国主义情怀、加强品德修养、增长知识见识、培养奋斗精神、增强综合素质上下功夫，促进学生健康成长，增强教师责任感和使命感。

二、目标任务

（一）总体目标。高举改革开放旗帜，坚持思想再解放、改革再深入、工作再抓实，在更高起点、更高层次、更高目标上推进全面深化改革。要落实立德树人根本任务，遵循教育规律，强化教师队伍基础作用，围绕凝聚人心、完善人格、开发人力、培育人才、造福人民。

（二）具体任务。

各旗县市区教育（教体）局民族教育综合指标，学前三年毛入园率达到95%、小学适龄儿童入学率100%、初中毕业生升学率90%、九年义务教育巩固率95 %、高中阶段毛入学率95%。幼儿园专任教师学历合格率90%、小学专任教师学历合格率100%、初中专任教师合格率100%、高中专任教师学历合格率98%、职业高中教师学历合格率90%。优先安排残疾儿童少年就近或者到指定的具备条件的普通学校接受义务教育，对于学习和生活上需要特别支持的残疾学生，要提供专业服务做到送教上门，不让一个孩子掉队。

加强蒙古语授课教学管理，继续提升教学质量。小学阶段，巩固“读标准音写规范字”活动成果，继续抓好“读书”活动，稳步提升学生语文素质，为全面提升教学质量打好基础，彻底消除小学生学业不及格现象；中学阶段，逐步提高蒙古语授课初高中毕业生中高考成绩，缩小与汉语授课考生分数的差距，以中考数学学科为例，将生均分数差距，由2018年8.9分缩小至5分以下；以高考数学学科为例，将生均分差距，理科数学由2018年17.49分缩小至12分以下，文科数学由2018年15.67分缩小至10分以下；稳步提升高考高分率，将蒙授高分段（600分以上）学生占全市比率，由2018年2.9%提升至6%以上；文科一本上线率，由2018年37.37%提升至40% 以上，理科一本上线率由2018年49.19%提升至51%以上；完成每年全区蒙古语授课文理科状元“保一争二”的任务。

要高度重视现代教育技术手段普及和应用水平，加大对民族中小学和幼儿园课程资源、网络资源的开发力度，提高教育资源共享水平。

要建立健全民族教育短缺学科教师补充机制和教师更新制度，及时开展短缺学科教师招聘和补充教师工作，确保优秀民族师资及时得到补充。

要加强民族学校校长（园长）的选聘工作，真正推选出懂教学、会管理和责任心、事业心强的优秀管理人才。全面加强教师思想政治建设和师德师风建设，全面提升教师队伍专业素养和教育教学能力。

要加强市、旗教研室(进修学校)教研队伍建设，配齐蒙古语授课教研员。教研部门和教研员要围绕课程规划、课程实施、教学改革、考试评价等专业问题，组织开展调查研究，为市、旗两级教育行政部门决策提供专业意见和建议。真正发挥专业智库的作用，研究形成幼儿园到高中教育有效衔接的教育教学模式。

各学校要坚定不移地抓课改，向课改要质量。校长要开放思维组织教师认真地学习、研究新课程标准，把握好方向，提升教师专业素养，提高课堂效率，重视蒙古语授课学校理科教学。

三、工作重点

（一）坚持立德树人，加强社会主义核心价值观教育。中小学生践行社会主义核心价值观，指引青年学生健康成长，全面推进教育改革发展。要在勤学、修德、明辨、笃实上下功夫。从落细、落小、落实入手，形成课堂教学、校园文化和社会实践多位一体的育人平台，切实推动社会主义核心价值观进教材、进课堂、进学生头脑，促进青少年学生学会劳动、学会勤俭，学会感恩、学会助人，学会谦让、学会宽容，学会自省、学会自律。要在课程建设和教材修订中强化优秀传统文化内容，组织编写普及读物，分学段有序推进中华优秀传统文化教育。

（二）教育教学要探索要创新。要充分发挥课堂教学主渠道作用，全面深化课程改革，不断完善大中小学有机衔接、循序渐进的课程体系和教材体系。在教育教学研究院“四大工程”“九个项目”的基础上，深入研究民族学校“四项课题”理念，因地制宜，理念和做法要活学活用，避免在各学段、各学科课程标准研究、课堂教学、教辅资料编写、考试评价中，生搬硬套“先进做法”。校本教材编制要按照《关于实施中华优秀传统文化传承发展工程的意见》，结合本地实际发扬和传承，要有教材、有教师、进课堂。每年要组织开展“教育研究年会”、“义务教育阶段学校学生正字大赛”、“民族学校联盟”和“蒙汉学校联盟”，在互动交流中达到共同提升的目的。

（三）科研工作从小处着手。发挥各旗县市区教研室、名师工作坊作用，教研员和名师既要潜心投入课堂，辅导各校教师课堂教学还要进行课题研究。课题选择要大处着眼，小处着手，不能盲目选择宽泛的题目，找出突破口，进行精准施策，解决制约教育发展的瓶颈问题。各地教育行政部门要给予教研室充分的物质和精神支持。

（四）美育教育注重内涵发展。美育可以陶冶人的情操、培养人的品格修养、提高人的思想道德水准，改进人类生存环境，服务人类精神需要，是一种综合素养的提升，是全人教育。各地各校严格按生师比配备音体美体育教师。美育教育要培养四个能力为目的：一是培养和提高学生感受美的能力，二是培养和提高学生鉴赏美的能力，三是培养和提高学生表现美、创造美的能力；四是培养和提高学生追求人生趣味和理想境界的能力。各地教育行政部门要把美育工作纳入教育现代化评估指标体系、考试制度改革、督导评价内容。民族学校美育教育工作要与传承民族文化项目结合实施，在传承弘扬民族文化的同时陶冶情操、增强体质、健全人格、锤炼意志品质。

（五）师德师风规范队伍。依据《中共通辽市委通辽市人民政府关于全面深化新时代教师队伍建设改革的实施意见》和《第二轮通辽市“立师德•正师风•树形象”师德师风建设三年行动计划（2019—2021）》，进一步完善师德师风建设的长效机制，开展争当“四有好老师”活动，引导广大教师增强政治意识、大局意识、核心意识、看齐意识，自觉爱党护党为党，敬业修德，奉献社会，争做“四有”好教师的示范标杆。每年要开展师德专项治理工作，对从事有偿家教、有偿补课，违规开设“小饭桌”等行为进行监管，建立问责制度。

（六）家校合作共育未来。

通过家校互动、亲子共读、家长学校、家校合作委员会等形式，强化家校共育机制，建立新型的家校合作方式，让父母更多地参与学校生活，引领父母与孩子共同成长，使家庭教育与学校教育协同互补、互相促进，最终实现家庭、学校教育的协调发展。

（七）平安校园人人有责。

安全教育指自然灾害、意外伤害、社会安全、健康卫生、网络安全、心理健康等方面。要多在学校明显位置悬挂或放置安全宣传展板、组织主题系列活动进行安全教育、与专业部门联合开展自然灾害、意外伤害、健康卫生知识教育，把安全知识全面的宣传到每个人的心里。社会安全是导致校园伤害发生的最大隐患。

（八）校园管理精细化，营造良好教书育人环境。建设花园式学校，学校要做到有院墙、有操场、有树木、有花草，教室要清洁宁静，宿舍要方便舒适，食堂要安全卫生，厕所要干净美观。校园有文化、学习有氛围，积极向上，拼搏进取。使学校真正成为播种知识的田园，传播文化的阵地，培养人才的摇篮。开展校园安全及校园周边环境治理专项整治活动，保障学校正常教学秩序。

四、实施步骤

民族教育教学管理提升工程分为三个阶段进行：

第一阶段：启动阶段（2019年4月－12月）。将2019年确定为民族教育教学管理提升工程启动年，主要任务是提出实施方案，对工作进行安排部署。各地各校以座谈交流、问卷调查、资料分析等形式，从校长业务管理能力、学校目标管理、教师队伍建设、学生培优方案，教师课堂管理、质量管理、绩效管理，毕业班管理，教师激励等方面，剖析制约民族教育质量提升的瓶颈，研究制定各地各校的具体工作实施方案。要层层分解工作责任，保证各项工作责任到人。

第二阶段：实施阶段（2020年1月—2021年12月）。将2020年、2021年确定为民族教育教学管理提升工程全面实施年，主要任务是按照实施方案进行责任分解，实施各项工作任务。各地各校要按照实施方案开展工作，以学期、学年度为时间单位，切实做到目标明确、重点突出、措施得力、考核细致、奖惩分明，确保工作进展到位。

第三阶段：总结验收阶段（2022年9月—12月）。将2022年确定为民族教育教学管理提升工程总结验收年。各地各校要认真总结，对取得的成绩、存在的问题进行客观地分析，并做好相关资料文件的统计、归档工作。将阶段性总结和年度验收相结合，逐步完善提高教育质量的长效机制，进一步推进教育质量提升工程的制度化、规范化、程序化和常态化。

五、保障措施

(一)提高认识，加强领导。要站在科学发展的高度，充分认识实施教育质量提升工程的深远历史意义和现实意义，切实增强提高教育质量的紧迫感和责任感。为切实加强民族中小学教育质量提升工程的领导，市教育局成立了民族教育教学管理提升工程领导小组。领导小组主要负责民族教育教学管理提升工程的组织领导、具体工作方案的制定、对各有关学校的教育质量进行评估、督导检查、阶段验收和评比表彰等工作。

各旗（县市区）、各中小学校也要相应成立以局长、校长为组长的教育教学管理提升工程领导小组，加强对本旗（县市区）、本学校教育质量提升工程工作的领导。要结合本地、本校实际，制定具体实施方案，落实责任，确保各项工作落到实处。

（二）建立机制，齐抓共管。各旗县市区教育行政部门要以教育教学管理提升工程为突破口，推进教育改革和教育质量的提高。教研部门要经常组织教研员深入学校，帮助学校制定工作方案，通过调研视导、学科教研、教学质量监测等途径，对学校的成功经验和有效做法进行总结和推广,对发现的问题和不足提出改进的意见。校长要强化教学工作第一责任人意识，把主要精力放在教学上，建立学校领导，特别是学校一把手深入教学一线，和教师一起在实践中研究的制度，将课堂教学、校本教研、校本培训等工作有机地整合起来，统筹兼顾。

（三）统筹协调，重点突破。提高教育质量是一项系统工程，各地各校要加强统筹协调，多措并举，整体推进。要把教育质量提升工程与学校标准化建设、教师队伍建设、学生全面发展有机结合，要从课程改革、素质教育、招生评价等方面进行全方位推进，尤其要研究本地区本学校在提升教育质量方面存在的薄弱环节，抓住关键，重点突破。

（四）严格督查考核。市、旗（县市区）两级教育督导室要充分履行职责，组织人员深入学校、深入课堂，通过定期与不定期相结合，抽查与专项检查相结合的方式，强化对教育质量提升工程的督促检查。各地各校要明确质量目标和工作责任，要强化考核，将目标任务完成情况纳入对学校和个人考核。

（五）保障经费投入。市、旗两级教育行政部门要加强部门间的协调，做好工作统筹。把经费投入的重点向优化资源配置、强化教学环节、提高教育质量方面倾斜。安排专项经费时，要突出教育质量提升工程的推进、改革试验的扶持、优质学校的创建、贡献突出单位的表彰奖励等。
