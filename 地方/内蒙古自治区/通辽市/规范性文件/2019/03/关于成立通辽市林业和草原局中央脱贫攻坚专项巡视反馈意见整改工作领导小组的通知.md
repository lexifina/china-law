# 关于成立通辽市林业和草原局中央脱贫攻坚专项巡视反馈意见整改工作领导小组的通知

各旗县区林业局、霍市农牧林业局、开发区农牧林水局，局机关各科室、市直林业和草原各单位：

为扎实推进林业领域脱贫攻坚巡视整改工作，按照《中央脱贫攻坚专项巡视反馈意见整改调度会议纪要》要求，切实把责任落实落细，现成立通辽市林业和草原局中央脱贫攻坚专项巡视反馈意见整改工作领导小组：

组 长：吕国华 市林业和草原局党组书记 局长

领导小组办公室设在局办公室，办公室主任吴玉国（兼），副主任李文峰，成员：张喜学、杨丽枫、李想。

工作职责：

领导小组统一负责中央脱贫攻坚专项巡视反馈问题整改工作，统筹研究解决林业扶贫巡视整改工作中的重大问题。领导小组办公室具体负责推动落实林业扶贫巡视整改各项工作任务，对全市林业扶贫巡视整改工作进行调度、指导、检查。同时负责领导小组日常工作协调、联络沟通和领导小组交办的其他工作。
