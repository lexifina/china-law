# 关于印发《通辽市林业和草原生态扶贫2019年实施方案》的通知

各旗县市区林业和草原主管部门：

现将《通辽市林业和草原生态扶贫2019年实施方案》印发给你们，请各地结合实际，认真贯彻执行，并于5月15前将本地林业和草原生态扶贫2019年实施方案报市林业和草原局。

联系人：李想（707室）

电 话：8251929

邮 箱：jck6395020@163.com

2019年4月29日

通辽市林业和草原生态扶贫2019年实施方案

为切实做好2019年林业和草原生态扶贫工作，根据中央、自治区、市级相关扶贫政策，按照《内蒙古自治区林业和草原生态扶贫2019年实施方案》要求，结合我市实际，制定本方案。

一、总体要求

（一）指导思想

以习近平新时代中国特色社会主义思想为指导，牢固树立和践行“绿水青山就是金山银山”的科学理念，全面贯彻党的十九大精神和习近平总书记参加十三届全国人大一、二次会议内蒙古代表团审议时重要讲话精神，以扶贫规划为引领，以脱贫成效为导向，以林草项目为平台，通过实施重大林草生态工程建设、加大生态补偿力度、大力发展生态产业、创新生态扶贫方式、着力加强作风建设，助力脱贫攻坚工作。

（二）年度目标

2019年完成贫困地区林业生态建设任务60万亩。将全市林业重点工程任务80%落实到贫困地区。实施生态护林员精准脱贫，抓好1500名生态护林员落实任务。做好中央第八巡视组脱贫攻坚专项巡视反馈意见整改方案中涉及林业部门的整改工作，落实好“一林果”（庭院经济林）产业建设工作，按时限完成整改。树立一批对贫困户增收带动作用明显的生态扶贫典型，开展示范推广。按市委、政府要求，全力做好林业系统扶贫驻村包联工作。

（三）主要途径

大力实施国家生态护林员政策，带动贫困人口就业得到稳定的工资性收入；大力实施林草重点工程建设吸纳贫困人口参与，增加贫困人口劳务性收入；大力发展林业富民产业、培育林草龙头企业、发展林业（种草）产业合作社，增加贫困人口经营性收入和财产性收入。

（四）实施范围

按照中央关于稳定脱贫攻坚政策的要求（摘帽不摘责任、摘帽不摘政策、摘帽不摘帮扶、摘帽不摘监管），全市林业和草原生态扶贫工作实施范围为科左中旗、科左后旗、奈曼旗、库伦旗、开鲁县、扎鲁特旗6个旗县。

二、具体工作

（一）抓好扶贫巡视整改工作

严格按照通辽市委印发的《中央第八巡视组脱贫攻坚专项巡视反馈意见整改方案》分工要求，切实做好有关林业生态扶贫整改任务。

1.对履行脱贫攻坚主体责任不够到位问题，扶贫开发领导小组统筹协调不完善问题整改措施：一是成立市林业和草原局巡视反馈意见整改工作领导小组，领导小组办公室定期报告巡视整改情况。二是将习近平总书记关于扶贫工作的重要论述和中央精准扶贫政策列入林业和草原局党组中心组学习内容。完成时限：立行立改，长期坚持，3月底前取得阶段性成效。（责任人：吴玉国 责任单位：规划财务科）

2.对统筹指导发展产业扶贫乏力。产业扶贫层次不高，基础薄弱，户企利益联结不够紧密，存在返贫风险问题整改措施：一是配合牵头部门（市扶贫办）做好产业精准扶贫工作（涉及林业部分为“一林果”），利用各类林业生态扶贫资金在贫困地区建设果树经济林，辐射带动周边贫困户发展果树经济林，壮大“一林果”庭院经济，并定期召开会议研究生态产业扶贫工作。二是扶持有条件的贫困户发展锦绣海棠、黄太平、沙棘等特色林果业等，鼓励有条件的地区建立扶贫造林（种草）合作社，发展生态旅游产业，优先吸纳贫困人口参与造林和管护，增加贫困人口收入。整改时限：立行立改，长期坚持，5月底前取得阶段性成效。（责任人：吴玉国 责任单位：规划财务科）

（二）抓好林草重点生态工程扶贫工作

加大对贫困地区生态保护与修复力度，坚持生态建设与扶贫攻坚相结合。保持各类重大林业生态工程任务和资金安排继续向贫困地区倾斜，安排贫困地区三北防护林、退化林分修复、退耕还林等重点工程建设任务占总任务的80%以上。加大沙化土地封禁保护力度，开展草原修复工程建设，年内对300万亩草原进行修复，破解草原生态保护与修复瓶颈，严控因生态环境恶劣致贫、返贫问题。

1.将“三北”防护林工程优先安排给林草扶贫实施范围内的6个旗县，加快推进造林绿化实施力度，合理引导贫困人口参与林业重点工程施工，让更多贫困人口获得劳务性收入。（责任人：包宝君 责任科室：治沙造林科）

2.组织各级草原监理部门对草原“四禁”（禁止放牧、禁止打井、禁止开垦、禁止一切违法生产经营活动）进行拉网式排查。按照因地制宜、分类指导、精准施策的原则，采取封育、禁牧、免耕补播等不同的保护措施和治理模式，依托退牧还草工程等项目，改良退化草原50万亩以上。通过项目建设，促进项目区植被恢复，推进天然草原生态环境持续改善。（责任人：吕国华 责任单位：草原监督管理科）

3.继续将新一轮退耕还林工程优先向符合要求的贫困户倾斜，满足贫困户退耕需求，指导贫困户利用退耕还林还草政策，营造优质高效特色经济林，使贫困户得到长期稳定收入。（责任人：贺希格 责任单位：治沙造林科）

（三）抓好生态补偿政策落实

以森林资源管护为重点，落实好国贫旗生态护林员生态保护公益性岗位。2019年实聘建档立卡贫困人口生态护林员1500人，并积极向上级主管部门争取增加生态护林员专项资金支持。落实好贫困地区森林生态效益补偿政策，支持贫困地区利用森林生态效益补偿开展公益林和草原管护，吸纳更多的贫困人口参与林草管护工作。

1.严格执行《生态扶贫2019年脱贫攻坚“清零达标”专项行动工作方案》，及时跟踪调度建档立卡贫困人口生态护林员选聘、管理情况，指导、推进护林员选聘工作落实，核实护林员资格和补助发放情况，确保生态护林员精准到户，实现政策精准到户清零达标。探讨护林员工资月结制或季结制。（责任人：贺希格 责任单位：市林业工作站）

2.积极争取扩大森林生态效益补偿范围，优先保障贫困地区。（责任人：吴玉国 责任单位：市天然林资源保护管理局）

3.切实开展林业实用技能培训，指导发展林业产业，力争使稳定脱贫后的每个生态护林员都能够拥有一项林业产业或者掌握一项林业实用技能。（责任人：包宝君 责任单位：市林业科学研究院）

（四）抓好林业（种草）产业发展

在确保生态安全的前提下，积极使用整合资金发展林业（种草）产业助推脱贫攻坚，进一步现固和提高贫困人口林业（种草）产业发展受益能力和水平。

1.全力抓好22个深度贫困地区林业生态扶贫工作，深入 22个深度贫困地区监督指导林业生态建设资金规划使用情况（2018年每个村安排20万元），鼓励支持发展“一林果” （庭院经济林）、果树经济林、林木种苗等为主的林业产业，让实实在在绿水青山变为真真切切金山银山。（责任人： 吴玉国 责任科室：规划财务科）

2.2019年自治区林业和草原局安排专项资金支持我市经济林示范基地建设，建设过程中，计划通过贫困户参与基地建设用工、林地入股、果品收益等方式，建立基地+贫困户的利益连接机制。（责任人：包宝君 责任单位：治沙造林科）

3.利用2019年林业产业化发展补助资金，通过聘用产业 工人、季节性用工、原料收购、技术帮扶等多种利益联结模式助力贫困地区贫困户实现脱贫。（责任人：吴玉国 责任单位：改革发展和产业科）

4.指导贫困地区林下经济示范基地建设，发展林下种养 产业，带动贫困人口增收脱贫。按照上级要求，借鉴“山西 模式”，探索组建林业生态扶贫造林（种草）专业合作社 试点，吸纳贫困人口参与重大生态工程建设，提高贫困人口 受益程度。（责任人：徐振喜 吴玉国 责任单位：改革发展和产业科）

（五）抓好贫困地区培训力度和项目储备工作

在补偿、吸纳、引导、助力贫困户脱贫的同时，积极做好林草专业技术培训工作和林草扶贫项目库储备工作。

1.组织林业专业技术人员深入贫困地区、贫困户家庭， 通过集中授课、现场培训、入户跟踪、微信视频、电话咨询等方式，重点以经济林栽植和种苗繁育等林业实用技术为培训 内容，力争培训贫困人员7000人次。（责任人：包宝君 责任单位：市林业科学研究院）

2.组建市旗两级草原修复技术支撑团队，对贫困地区建设进行技术指导、技术培训等全程服务，重点推广应用免耕 补播、封育、飞播等技术。按照自治区《关于认真做好2019年牧鸡治蝗生态扶贫工作通知》精神，市草原站2019年结合草原蝗虫发生情况，向牧区贫困户投放牧鸡5000只。（责任人： 吕国华 责任单位：市草原工作站）

3.将全市林草重点工程项目建设与脱贫攻坚有机结合，建立项目库。在抓好扶贫项目储备的同时，突出精准要求，实行动态管理，确保扶贫项目落实后资金投入真正用到贫困地区、贫困人口解决脱贫问题上。（责任人：包宝君 责任科室：规划财务科）

（六）抓好林业系统驻村包联扶贫工作

按照要求，待市里明确具体包联嘎查村后，根据当地致贫原因，精准施策，助力脱贫。（责任人：吴玉国 责任 科室：规划财务科）

三、保障措施

（一）加强组织领导。要充分认识林草生态扶贫重要性、艰巨性、紧迫性，责任领导和责任科室要按照职责分工，加强业务指导和支持，对各自工作进行责任细化分解，明确时间进度。积极争取林草扶贫项目资金和技术跟踪指导服务，在做好各自职责的同时，大力发掘在各地生态扶贫工作中示范引领突出的典型范例和特色项目，积极争取全区生态扶贫现场会议在我市召开。

（二）强化监督管理。完善林草生态扶贫督导检查机制，统筹做好林草生态扶贫督导检查和调査研究工作。全力抓好《中央第八巡视组脱贫攻坚专项巡视反馈意见通辽市林业和草原局生态扶贫整改方案》中产业精准扶贫工作“一林果”部分，建立台帐，狠抓整改，对落实不力、进度滞后的进行通报批评，对真抓实干、成效明显的表扬激励，确保生态扶贫工作顺利进行。

（三）狠抓作风建设。市本级、各地区要全面加强林草生态扶贫领域干部职工思想宣传教育工作，要增强“四个意识”、坚定“四个自信”、做到“两个维护”，强化责任担当，力戒形式主义，杜绝“数字扶贫”，用严的态度、实的作风推进林草生态扶贫各项工作落实。

（四）密切信息交流。各地林草部门要积极上报林业和草原生态扶贫政策和机制创新的典型案例（主要包括生态护林员脱贫、生态管护扶贫机制创新、森林旅游扶贫利益联结机制创新等），局扶贫办根据内容协调市级媒体进行宣传报道。 同时，各地要结合实际制定切实可行的2019年林业和草原生态扶贫实施方案，并于5月15日前将本地年度实施方案报送至市林草局（联系人：李想，电话：8251929）。
