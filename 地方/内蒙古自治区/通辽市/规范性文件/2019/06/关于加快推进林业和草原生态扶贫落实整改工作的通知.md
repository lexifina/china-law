# 关于加快推进林业和草原生态扶贫落实整改工作的通知

各旗县市区林业和草原主管部门，局机关各科室、系统各单位：

为进一步贯彻通辽市扶贫开发领导小组《关于印发<通辽市对照认领2018年国家对内蒙古自治区脱贫攻坚成效考核指出问题整改方案>的通知》（通扶组发〔2019〕28号）要求，加快推进林业和草原生态扶贫整改工作，现将有关事宜通知如下：

一、对迁出点按时恢复植被。根据通辽市扶贫开发领导小组制定的整改方案，对于拆旧户的707.17亩林草地进行复绿，其中扎鲁特旗507.17亩，库伦旗200亩。请涉及到的两个旗林草部门尽快与当地扶贫部门沟通，认领整改任务，到实地进行勘察设计，按照“宜草则草，宜林则林”原则，科学选择种草或种树恢复植被，抓住雨季宜种时机，9月底前完成复绿任务。（责任科室：造林治沙科、草原科）

二、加快资金拨付和资金整合进度。从4月份调查看， 2015-2018年林业专项资金未拨付到位额度达15亿。各旗县林业资金到位率过低，严重影响了林业工程进度和旗县涉农资金统筹整合进度。市直林业和草原局已向各地政府印发了尽快将林业资金拨付到位的函，各地林业和草原主管部门要积极与属地政府和财政部门沟通，尽快将林业资金拨付到位。同时，及时将林业资金支出情况向社会公示，对公示公告制度落实不到位问题进行全面整改。（责任科室：规划财务科）

三、抓好林草部门扶贫投入项目。2018年，印发了《关于下达2018年自治区财政林业专项补助资金的通知》通财农〔2018〕574号，对于全市22个深度贫困村（嘎查）每村下达20万元， 共计440万元。请各地林业和草原主管部门与属地财政和扶贫部门沟通，将此项资金用于林业重点扶贫项目，整合使用于林业产业扶贫上，突出扶贫用途针对性，确保取得良好成效。各地要将此项资金的使用情况，及时上报市林业和草原局。（责任科室：规划财务科）

四、抓好“一林果”庭院经济建设工作。要抓好“六个一”扶贫工作中的“一林果”建设，鼓励更多有条件的贫困户利用房前屋后空闲地栽植林果，并加强对贫困户的技术培训与技术 指导，使农民掌握好果树管理维护技术，促进农民庭院经济提质增效。（责任科室、单位：造林治沙科、市林业工作站、市林业科学研究院）

五、加强林业生态扶贫工作。做好建档立卡贫困户生态 护林员聘用、考核工作，保持队伍相对稳定，保障森林资源 安全，同时保证生态护林员工资及时足额发放。（责任部门： 市林业工作站）

2019年6月15日

抄送：市扶贫开发领导小组办公室，扶贫办
