# 关于成立“未履行审核审批手续征占用草原整改项目”现场查验互查组的通知

各旗县市区林业和草原主管部门：

为深入贯彻落实中央环境保护督察“回头看”及草原生态环境问题专项督察反馈意见，持续推进生态文明建设，进一步筑牢我国北方重要生态屏障。根据《内蒙古自治区林业和草原局关于落实中央环境保护督察“回头看”及草原生态环境问题专项督察反馈意见整改工作的通知》（内林办发〔2019〕99号），关于严格按照《自治区政府办公厅转发自治区农牧业厅关于未履行审核审批手续征占用草原项目整改意见的通知》办理征用使用草原审核手续工作的要求，经研究决定成立现场查验互查组。

现场查验互查组的人员构成：市林业和草原局副局长吴玉国任组长，市草原监理所所长（高级畜牧师）赵毅博、副所长（高级畜牧师）王永忠任副组长，在市草原监理所及各旗县市区草原监理所（局）中选1-2名监理员任组员。

现场查验互查组职责：对“未履行审核审批手续征占用草原整改项目”进行现场查验工作。

现场查验互查组工作方式方法：由市林业和草原局根据未履行审核审批手续征占用草原项目整改工作的进展情况，统一协调组织市、旗县现场查验互查组成员组成互查组，采取旗县之间互查的方式对“未履行审核审批手续征占用草原整改项目”进行现场互查工作。

现场查验互查组应填写《草原征用使用现场查验表》、《草原征占用申请表》中“现场查验意见”一栏，形成《现场查验报告》等相关材料的具体工作。
