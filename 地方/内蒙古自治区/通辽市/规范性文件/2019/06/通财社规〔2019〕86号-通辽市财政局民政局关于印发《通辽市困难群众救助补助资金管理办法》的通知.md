# 通辽市财政局民政局关于印发《通辽市困难群众救助补助资金管理办法》的通知

各旗(县、市、区)财政局、民政局,开发区财政局、民政局:

为进一步加强困难群众救助补助资金管理,根据《内蒙古自治区财政厅民政厅关于印发〈困难群众救助补助资金管理办法〉的通知》(内财社规〔2018〕7号)等有关规定,结合我市实际,我们制定了《通辽市困难群众救助补助资金管理办法》,现印发给你们,请遵照执行。

通辽市财政局

通辽市民政局

2019年5月15日

通辽市困难群众救助补助资金管理办法

第一条为规范和加强困难群众救助补助资金(以下简称“补助资金”)管理,提高资金使用效益,支持做好困难群众救助工作,根据相关法律法规和《自治区财政厅民政厅关于印发<困难群众救助补助资金管理办法>的通知》(内财社规〔2018〕7号)专项补助资金管理有关规定,制定本办法。

第二条本办法所称补助资金是指中央财政、自治区财政和通辽市财政安排用于补助各旗县(市、区)开展城乡低保、特困人员救助供养、临时救助、流浪乞讨人员救助、孤儿和艾滋病病毒感染儿童基本生活保障工作的资金,以及通辽市财政安排的用于支持各旗县(市、区)开展政府购买社会救助服务工作的资金。

第三条补助资金使用和管理要坚持公开、公平、公正的原则。

第四条通辽市财政局负责会同通辽市民政局对补助资金实施全程预算绩效管理。按照预算管理规定,各旗县(市、区)民政部门商同级财政部门设定补助资金区域绩效目标,明确资金与工作预期达到的效果,报通辽市民政局审核。市民政局在完成绩效目标审核后及时提出补助资金的分配建议及当年全市整体绩效目标和分区域绩效目标,商报市财政局确认后下达补助资金,同步下达分区域绩效目标。各旗县(市、区)要确保优质高效完成既定目标任务。年度执行中,市民政局会同市财政局指导各旗县(市、区)民政部门、财政部门对绩效目标实现情况进行监控,确保绩效目标如期实现。

第五条补助资金按因素法分配,主要参考困难群众救助任务量、保障标准及补助水平、地方财政困难程度、地方财政努力程度、绩效评价结果、资金结余等因素。每年分配资金选择的因素和权重,可根据年度重点工作情况适当调整。补助资金重点向贫困深度、保障任务重、工作绩效好的地区倾斜。

第六条各旗县(市、区)财政部门收到上级补助资金后,应将其本级财政安排的资金统筹使用,商同级民政部门制定本地区资金分配方案。同时,将资金分配结果报市财政局、民政局备案。

第七条通辽市财政按照预算管理规定,在市人大批复预算后,将按分担比例承担的补助资金下达旗县(市、区)。

第八条各旗县(市、区)财政部门要会同民政部门优化资金支出结构,科学合理编制预算,加强补助资金统筹使用,积极盘活财政存量资金,加大结余结转资金消化力度,发挥补助资金合力,提升资金的使用效益。

通辽市在下达补助资金时,将城乡低保、特困人员救助供养、临时救助、流浪乞讨人员救助、孤儿和艾滋病病毒感染儿童基本生活保障等资金统筹下拨。各旗县(市、区)可结合困难群众救助工作实际,统筹使用并下拨相关资金。

第九条各旗县(市、区)要综合考虑本地区职工工资、物价水平等情况,按照服务对象数量、服务半径等因素进行测算,将政府购买社会救助服务资金纳入财政预算。安排预算时,政府购买社会救助服务资金可以从当地自行安排的社会救助工作经费或社会救助专项资金之中按比例划出一部分,总额度原则上不得超过上年度自治区和通辽市下拨的困难群众救助补助资金总和的2%(例如:编制2018年预算时,以2017年度自治区和通辽市财政下达的困难群众救助资金总额为参照)。如划出部分不能满足相关工作需求,可由本级财政预算予以补足。

第十条市财政局、民政局每年组织开展补助资金的绩效评价,主要内容包括资金投入与使用、预算执行、资金管理、保障措施、资金使用效益等。评价结果公开发布,并将作为调整政策、督促指导旗县(市、区)改进工作、分配补助资金的重要依据。

第十一条补助资金支付按照国库集中支付制度有关规定执行。低保金、散居特困人员救助供养金、临时救助金原则上应支付到救助对象个人账户,集中供养特困人员救助供养金应统一支付到供养服务机构集体账户。分散供养的孤儿和艾滋病病毒感染儿童的基本生活费应支付到本人或监护的个人账户,集中养育的孤儿和艾滋病病毒感染儿童基本生活费用应统一支付到福利机构集体账户。

旗县(市、区)财政、民政部门应当为救助家庭或个人在代

理金融机构办理接受补助资金的账户,也可依托社会保障卡、财政补贴资金“一卡通”等渠道发放补助资金,代理金融机构不得以任何形式向救助家庭或个人收取账户管理费用。

第十二条补助资金要专款专用,用于为低保对象发放低保金,为特困人员提供基本生活条件、对生活不能自理的给予照料、提供疾病治疗、办理丧葬事宜,为临时救助对象发放临时救助金或实物,为孤儿和艾滋病病毒感染儿童发放基本生活费,为生活无着的流浪乞讨人员实施主动救助、生活救助、医疗救治、教育矫治、返乡救助、临时安置并实施未成年人社会保护。用于支持政府购买社会救助服务工作的资金,可按照法定程序购买社会救助事务性和服务性等两类服务项目。补助资金使用后按支出方向单独记账,分别核算。

各旗县(市、区)财政部门、民政部门和经办机构应严格按规定使用相关资金,不得擅自扩大支出范围,不得以任何形式挤占、挪用、截留和滞留,不得向救助对象收取任何管理费用。补助资金不得用于工作经费,不得用于机构运转、大型设备购置和基础设施维修改造等支出。

第十三条各旗县(市、区)财政、民政部门要建立健全资金监管机制,定期或不定期地对补助资金的使用管理情况进行检查,及时发现和纠正有关问题,并对资金发放情况进行公示,接收社会监督。

第十四条各旗县(市、区)财政、民政部门应自觉接受审计、监察等部门和社会的监督。

第十五条各旗县(市、区)财政、民政部门及其工作人员在补助资金的分配审核、使用管理等工作中,存在违反本办法规定的行为,以及其他滥用职权、玩忽职守、徇私舞弊等违法违纪行为的,按照有关规定追究相应责任。涉嫌犯罪的,依法移送司法机关严肃处理。

第十六条各旗县(市、区)财政、民政部门可参照本办法,结合当地实际,制定困难群众救助补助资金管理具体办法。

第十七条本办法由通辽市财政局会同通辽市民政局负责解释。

第十八条本办法自2019年6月1日起施行,有效期为5年。《通辽市财政局民政局关于印发<通辽市困难群众基本生活救助补助资金管理办法>的通知》(通财规〔2015〕195号)同时废止。
