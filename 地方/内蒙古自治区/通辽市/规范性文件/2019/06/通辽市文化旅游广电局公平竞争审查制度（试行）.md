# 通辽市文化旅游广电局公平竞争审查制度（试行）

第一条为贯彻落实《通辽市关于在市场主体中建立公平竞争审查制度的实施方案》（通政办字〔2017〕323号）精神，推进公平竞争审查制度的有效落实，维护公平竞争秩序，从我局实际出发，制定本制度。

第二条凡涉及市场准入、产业发展、招商引资、招标投标、政府采购、资质标准、经营者行为规范等涉及市场主体经济活动的规范性文件和其他政策措施，均应在起草过程中进行公平竞争审查，具体包括：自行出台的规范性文件和政策措施；牵头联合行文出台的规范性文件和政策性措施；代市政府起草或代拟的规章、规范性文件及其他政策措施。

第三条审查方式按照“谁起草、谁审查”的原则，各科室牵头起草以通辽市文化旅游广电局名义出台的相关政策措施时，应严格对照明确的审查标准和审查要求进行自我审查，并形成书面审查结论，随相关文件材料一并报局办公室、局领导签批。与部门联合发文的政策措施，属我局牵头实施的，由承办科室负责公平竞争审查；属其他部门牵头实施的，由牵头部门负责公平竞争审查。我局代市政府拟定，以市政府名义出台的政策措施，由承办科室负责公平竞争审查。相关政策措施若需提交局政策法规科进行合法性审查的，应一并提交公平竞争自我审查结论。局政策法规科在合法性审查中，同时对各科室是否已履行公平竞争审查程序以及是否符合公平竞争审查规定进行审查。

第四条不得制定减损市场主体合法权益或者增加其义务的政策措施；不得违反《中华人民共和国反垄断法》制定含有排除、限制竞争内容的政策措施。

第五条各业务科室在有关政策制定过程中必须实行公平竞争审查，未经公平竞争审查的，一律不得出台。

第六条各业务科室要按照确立竞争政策基础性地位的要求，有针对性的制定政策措施，不断完善文化旅游市场竞争规则，加快形成统一、开放、竞争有序的市场体系。

第七条公平竞争审查应公开接受市场主体和社会各界监督，通过通辽市文化旅游广电局网站对外公开公示。对涉嫌违反公平竞争审查标准的政策措施，要及时清理。

第八条本制度自公布之日起实施。

2019年6月10日
