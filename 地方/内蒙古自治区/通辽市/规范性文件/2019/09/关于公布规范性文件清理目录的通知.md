# 关于公布规范性文件清理目录的通知

TLSGYHXXHJ-2023-005

各科室、局属各单位：

按照《内蒙古自治区规范性文件制定和备案监督管理办法》（自治区人民政府令第191号）《通辽市人民政府办公室关于做好2019年度行政规范性文件全面清理工作的通知》（通政办字〔2019〕44号），对我局截至2018年12月31日制发的规范性文件进行了清理。现将清理目录予以公布，自公布之日起，列为废止和失效的文件不再执行。

附件： 1.继续有效的规范性文件目录(1件)

2.废止和失效的规范性文件目录(2件)

2019年9月26日
