# 关于印发《通辽市本级行政事业单位通用资产配置标准的规定》的通知

通辽市人大常务委员会、市委办公厅、市政府办公厅、市政协办公厅，市直各行政事业单位：

为加强通辽市本级行政事业单位通用办公设备、家具配置管理，推进资产管理科学化规范化，结合改革要求和市本级实际，我们制订了《通辽市本级行政事业单位通用资产配置标准的规定》，在征求各方无意见后印发给你们，请遵照执行。执行中有何问题，请及时反馈。

2019年11月14日

通辽市本级行政事业单位通用资产

配置标准的规定

为贯彻落实预算法和深化财税体制改革要求，推进党政机关厉行节约反对浪费，建设节约型机关，强化资产管理与预算管理相结合，进一步规范和加强通辽市本级行政事业单位国有资产配置管理，根据《中华人民共和国预算法》、《行政单位国有资产管理暂行办法》（财政部令第35号）、《事业单位国有资产管理暂行办法》（财政部令第100号）和《党政机关厉行节约反对浪费条例》等文件精神，参照《内蒙古自治区财政厅关于印发〈内蒙古自治区本级行政事业单位通用资产配置标准的规定〉的通知》（内财资规〔2017〕17号）文件，结合我市实际，现将有关事项规定如下。

第一条本规定适用于通辽市本级党的机关、人大机关、政协机关、行政机关、各民主党派机关和事业单位（以下简称“行政事业单位”，以独立法人为核算单位）通用资产配置行为。有关人民团体和政府投资类临（时）设机构参照执行。

第二条本规定所称通用资产，是指适用于通辽市本级各行政事业单位，满足办公基本需要的设备、家具,不含专用类设备及家具。主要包括《通辽市本级行政事业单位通用资产配置标准》（详见附表）所列资产类别。未列入本标准资产类别内的其他通用设备、家具，应当按照与单位履行职能需要相适应的原则，从严控制。因保密、救灾、维稳等工作另有规定的，从其规定。

第三条本规定是资产配置标准体系的重要组成部分，是编制和审核资产配置预算，实施政府采购、国库支付和资产处置管理等工作的基本依据。

第四条本规定包括资产类别、配置数量上限、价格上限、最低使用年限和性能要求等内容。

（一）资产类别是根据办公设备、家具普遍适用程度确定。

（二）配置数量上限根据单位机构设置、职能、编制内实有人数等确定，是不得超出的数量标准。

（三）价格上限的标准依据市场行情确定，是不得超出的价格上限。

（四）最低使用年限根据资产的使用频率和耐用程度等确定，是资产使用的底线标准。未达到最低使用年限的，除确因损毁且无修复价值的，原则上不得更新，达到使用年限仍可以使用的应继续使用。

（五）性能要求是对通用办公设备、家具功能等方面的要求和限定，应以简单高效实用为主。

第五条通辽市本级行政事业单位配置办公设备应当按照《中华人民共和国政府采购法》规定，配置具有较强安全性、稳定性、兼容性，且能耗低、维修便利的设备;其中购置涉密或非涉密信息类产品，采购事项及采购程序要符合相关规定。

第六条通辽市财政局可根据经济发展水平、公共服务保障要求、财力状况、政府采购价格变化等因素，适时调整和更新通用资产配置标准。

第七条通辽市本级行政事业单位应当按照本规定，结合内设机构职能和业务需要编制年度部门预算，并根据预算安排情况，以不超出本规定配置标准的总量为前提，统筹安排本单位内设机构各项资产配置。

第八条对现有标准不能满足工作需要特殊单位的职能和业务且确需超标准采购的，由单位提出依据并提供相关资料，经主管部门审核后，在其主管部门所辖单位之间调配超标准配置资产。仍不满足需求的，按照《通辽市行政事业单位国有资产管理办法》（通政发〔2012〕8号）及通辽市本级资产配置管理相关规定和程序履行审批。

第九条本规定所制定的配置标准是通辽市本级通用资产配置的上限，目的是为了保障机关单位的正常运转，而非必须达到的配置标准，原则上能省则省、可不购置则不购置；现有资产超过本配置标准的单位，一律不得新购置资产。

第十条本规定施行后，市本级行政事业单位违反本规定要求超标准配置资产，财政部门将根据有关规定通过调剂和拍卖等方式进行处置；对涉及违法行为的单位和个人，按照中华人民共和国国务院令《财政违法行为处罚处分条例》（第427号）等规定进行处理。

第十一条本规定由通辽市财政局负责解释，此前发布市财政局相关规定与本规定不一致的，以本规定为准。

第十二条旗县市区财政局可结合各地实际，参照本规定制定本地区的配置标准。

第十三条本规定自发布之日起施行。
