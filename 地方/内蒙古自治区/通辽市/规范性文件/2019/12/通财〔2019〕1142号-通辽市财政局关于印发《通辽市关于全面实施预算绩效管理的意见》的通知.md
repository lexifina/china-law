# 通辽市财政局关于印发《通辽市关于全面实施预算绩效管理的意见》的通知

各旗县市区委、人民政府，开发区党工委、管委会，市委各部委办，市政府各委办局，各人民团体及事业单位：

为贯彻落实党中央、国务院和自治区关于全面实施预算绩效管理的决策部署，加快建成我市全方位、全过程、全覆盖的预算绩效管理体系，经市委、市政府同意，现将《通辽市关于全面实施预算绩效管理的意见》印发给你们，请遵照执行。

附件：《通辽市关于全面实施预算绩效管理的意见》
