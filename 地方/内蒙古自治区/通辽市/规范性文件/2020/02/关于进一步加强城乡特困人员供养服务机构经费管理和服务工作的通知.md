# 关于进一步加强城乡特困人员供养服务机构经费管理和服务工作的通知

各旗县市区民政局，通辽市社会福利院：

为切实保障城乡特困人员基本生活，进一步提高城乡特 困人员供养服务机构的服务质量，根据内蒙古自治区人民政府《关于进一步健全特困人员救助供养制度的实施意见》(内政发〔2016〕106号)和内蒙古自治区民政厅《关于进一步加强城乡特困人员供养服务机构经费管理及服务工作的通知》(内民政发〔2019〕38号)等文件精神，结合我市实际，现就进一步加强城乡特困人员供养服务机构经费管理和服务工作通知如下。

一 、进一步明确供养内容

特困人员供养机构须为特困人员提供以下救助供养服务。

(一)提供基本生活条件。包括供给粮油、副食品、生活用燃料、服装、被褥等日常生活用品和零用钱。可以通过

实物或者现金的方式予以保障。

(二)提供教育服务。切实保障特困人员受教育的权利。 特困人员就学的，要为其提供好就学服务，并全面纳入各教育阶段的救助范围。(该项主要针对儿童福利机构)

(三)对生活不能自理的给予照料。包括日常生活、住院期间的必要照料等基本服务。

(四)提供疾病治疗。全额资助参加城乡居民基本医疗保险的个人缴费部分。医疗费用按照基本医疗保险、大病保险和医疗救助等医疗保障制度规定支付后仍有不足的，由救助供养经费予以支持。

(五)办理丧葬事宜。集中供养的特困人员死亡后的丧葬事宜，按照基本从简的原则，由供养服务机构办理。丧葬

费用从救助供养经费中支出。

二、 进一步明确供养标准

特困人员救助供养标准包括基本生活标准和照料护理标准。

(一)基本生活标准。应当满足特困人员基本生活所需，按照不低于通辽市城乡居民最低生活保障标准的1.3倍执行。目前我市的供养标准是：农村牧区特困人员每人每年11000元；城市特困人员每人每月1600元。特困人员基本生活费由供养机构按比例进行分块支配，主要用于保障和提高供养人员的生活质量，包括伙食、医疗、被服、床品、易耗品、零用钱等费用支出。根据特困人员基本生活费标准，按百分比进行分配使用。其中：45%用于伙食费(粮油、副食品、燃料)支出；25%用于医疗费用支出；10%用于服装和床品费 用支出；20%用于供养机构统筹费(3%用于零用钱发放、2%用于易耗品费用支出，15%用于其它费用支出)支出。

(二)照料护理标准。依据特困人员生活自理能力和服务需求实行差异化服务，按当地上年度最低工资标准的一定 比例分档制定。照料护理服务标准分为具备生活自理能力标准、部分丧失生活自理能力标准，完全丧失生活自理能力标准三档：具备生活自理能力标准由旗县市区政府根据当地经济社会发展水平、财力状况和特困人员实际形成的照料护理需求进行确定；部分丧失生活自理能力标准按照内蒙古自治区上年度最低工资标准的25%执行；完全丧失生活自理能力标准按照内蒙古自治区上年度最低工资标准的65%执行。目前我市的照料护理标准是：部分丧失生活自理能力人员每人每年5000元；完全丧失生活自理能力人员每人每年13000元。

(三)特困人员生活自理能力评估。参照民政部《特困人 员认定办法》,对特困人员生活自理能力进行评估，根据评估结果，确定其应当享受的照料护理标准档次。特困人员生活自理能力，依据以下6项指标综合评估

1. 自主吃饭；

2. 自主穿衣；

3.自主上下床；

4. 自主如厕；

5.室内自主行走；

6. 自主洗澡。

6项指标全部达到的，可以视为具备生活自理能力；有1至3项(含3项)指标不能达到的，可以视为部分丧失生活自理能力；有4项以上(含4项)指标不能达到的，可以视为完全丧失生活自理能力。

三、 进一步加强供养机构管理

各旗县市区要统筹规划本地区城乡特困人员供养服务机构建设。对以政府投入为主、利用国有资产举办的供养服务机构，要按照《事业单位登记管理暂行条例》有关规定，进行事业单位法人登记管理。要加强特困人员供养服务机构的运营管理，建立健全服务管理体系，包括安全管理制度、服务规范、岗位工作规范等。特困人员供养服务机构在满足特困人员集中供养服务需求的前提下，要积极拓展服务范围为农村牧区其他低收入、高龄、独居和失能人员提供照料服务。

有条件的城乡特困人员供养服务机构，经卫生健康行政 部门批准或备案，要设立医务室或护理站。鼓励通过设置护理专区、提供护理床位等方式，完善护理服务功能。到2022年，要实现护理型床位占供养服务机构床位总数60%的目标。

四、 进一步保障供养资金

按相关规定，城乡特困人员供养服务机构运转经费全部由当地财政列支，特困人员救助供养资金由自治区和市财政给予适当补助。各旗县市区民政部门要积极协调同级财政部门将城乡特困人员供养服务机构运转经费、特困人员救助供养资金列入财政预算，确保机构正常运转。同时，要坚决杜绝将特困人员救助供养资金用于机构运转经费的情况发生。

五、 进一步提高服务水平

城乡特困人员供养服务机构(不包括儿童福利机构)管理服务要按照《养老机构服务质量基本规范》的要求，重点

在以下方面提高服务水平。

(一)室内环境

1.室内环境应符合GB/T 50340中的要求。室内空气质量应符合CB/T18883 的要求。室内灯光照度应柔和，灯光照度应符合GB50034的要求。冬季供暖温度应不低于18℃、降温不高于28℃。

2.机构活动场所应布置合理，清洁整齐。

3.机构应设有垃圾专门存放区域，并分类管理。医疗垃圾应使用专用容器或包装袋，并设有标识。

(二)设施设备要求

1.公共设施与服务功能相匹配，并配置无障碍设施。

2.机构应设置播报系统、监控系统、消防系统、微型消防站、报警装置等设施。对未能设置消防系统的养老机构，应加强物防、技防措施，配备应急照明和灭火器材等。

3.公共区域和活动场所应配置座椅、健身设备、照明设施。

(三)膳食服务

1.膳食服务的内容包括食谱的制定、营养配餐、食品加工与制作、为失能、半失能人员送餐等。

2.提供膳食服务的人员应具备相关技能，并持有健康合格证。

3.食谱的制定应结合供养人员生理特点，身体状况、民族和宗教习惯，低盐，低脂、低糖、粗细搭配，确保一日三餐(保证每位供养人员每天一颗鸡蛋、 一杯牛奶，并保证肉食和水果供应)。

4.营养配餐应多种多样，蛋白质、脂肪，碳水化合物、维生素和矿物质比例合理，达到营养均衡。

(四)食品加工与制作

1.操作间宜采用开放式厨房或视频方式，食品加工与制作全程可视。

2.食品加工使用的原料应选用新鲜，无变质、无毒、无害食品。

3.加工用的工具、容器、设备应清洗、消毒，分类存放。

4.加工后的储存应做到成品与半成品分开、生熟分开、食物与药物分开、食物与天然冰分开。

5.应对餐具进行一洗、二刷、三冲、四消毒，并放置在指定位置。

6.每周应对食谱内容进行调整，向供养人员公布并存档。临时调整时，需提前告知。

7.每餐要进行食品留样，每种样品不少于100克，并在专用盒上标注品名、时间、餐别、采样人，并将留样盒放置 于0℃ 4℃冰箱内，储存时间不少于48小时，并做好留样记录。

(五)生活照料服务

1.做好生活照料服务，包括：穿衣、修饰、饮食起居、如厕、口腔清洁、皮肤清洁、体位转移、便溺照料、睡前照

料、皮肤护理等。

2.要定期对皮肤、口腔、头发，手足、指(趾)甲及细部清洁。

3.老年人居室应做到室内清洁、物品整齐，空气新鲜、无异味。

4.应保留提供服务的相关资料和记录。记录应及时、准确、真实、完整，责任人要签字确认。

(六)协助医疗护理服务

1.要协助做好医疗护理服务，内容包括：观察供养人员日常生活情况变化；协助供养人员前往定点医疗机构取常规 口服药；为生活不能自理的供养人员安置肢体功能位；协助或指导供养人员使用辅助器具；为供养人员完成化验标本的收集送检；协助医生和护士为供养人员预防并发症；协助医生、护士做好院内感染的预防工作。

2.供养机构应有必要的服务设备，包括压疮预防辅助器具、生活自理及防护辅助器具、个人移动辅助器具等。

3. 要协助供养人员服药时应注意药品名称正确、药品在有效期内、剂量准确、给药时间准确、给药途径正确。

4.应保留提供服务的相关资料和记录，记录应及时、准确、真实、完整，责任人应签字确认，并对供养人员相关信

息保密。

(七)医疗服务

1.应为供养人员建立健康档案。

2.应为供养人员开展健康体检，每年至少1次。

3.应做好供养人员疾病防控工作，开展卫生知识宣教每月至少1次。

(八)环境卫生服务

1.要搞好环境卫生服务，内容包括：公共活动区域的清洁、老年人居室内的清洁。

2.机构应制定清洁工作流程，做好公共活动区域及供养人员居室日常环境、设施设备的清洁工作。

3.应每日定期清扫供养人员房间，整理供养人员个人物 品及生活用品。定期更换床上用品及窗帘、清洗消毒卫浴设备等。

4.应定期对走廊、活动区域及设施设备进行清洁和消毒。

5.应配备专用清洁设施设备及用具，并对不同区域设施设备及用具用不同标识进行区分。

6.清洁过程中，应摆放明显标识，对供养人员进行提示。

7.环境卫生清洁应做到地面干燥、无异味，无积存垃圾、无卫生死角、无纸屑、无灰尘、物品摆放整齐。

8.环境卫生清洁产生的垃圾应进行分类处理，清洁完毕后做好记录。

(九)洗涤服务

1.要做好洗涤服务，内容包括：为供养人员收集和清洗衣物、被褥、尿布等织物。

2.机构宜配备专门的洗涤服务人员，负责收集、分类、清点、清洗、消毒和返还供养人员。

3.每次清洗衣物，管理人员应对洗涤效果和衣物进行检查，确保供养人员衣物清洗干净、衣物完好无损。

六 、进一步落实相关责任

各旗县市区要进一步加强对特困人员供养机构工作的领导，进一步明确和落实相关责任，理顺体制制度、资金投入、工作保障和监督管理责任，逐步统筹城乡特困人员供养机构的政策、标准、场所、服务等内容，建立监督管理长效机制。要进一步完善特困人员供养机构责任追究制度，定期组织开展专项检查，加大行政问责力度，对责任不落实、互相推诿、处置不及时等造成严重后果的，要依法依规追究单位和个人责任。

机构改革后，市民政局参照自治区民政厅的机构设置，已将城乡特困人员供养机构管理工作统一归口社会福利科，各旗县市区也要统筹建立与市民政局的对应管理机制。
