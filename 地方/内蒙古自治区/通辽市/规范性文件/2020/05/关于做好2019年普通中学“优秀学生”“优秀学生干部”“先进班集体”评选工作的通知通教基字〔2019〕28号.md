# 关于做好2019年普通中学“优秀学生”“优秀学生干部”“先进班集体”评选工作的通知通教基字〔2019〕28号

各旗县市区教体局、团委、开发区教体卫计局，市直普通中学：

为进一步做好2019年普通中学“优秀学生”、“优秀学生干部”和“先进班集体”评选工作，现将有关事宜通知如下：

一、2019年的评选工作按照《通辽市普通中学“优秀学生”“优秀学生干部”“先进班集体”评选办法》（见附件1）要求进行评选。

二、“优秀学生”、“优秀学生干部”和“先进班集体”名额，依据2018年教育统计综合报表，按规定比例进行分配（见附件2），各地各校上报时均不得突破分配名额。

三、“优秀学生”、“优秀学生干部”登记表，学生成绩栏内一律填写学业水平考试成绩（优、良、中、差），并加盖组织考试单位公章。

四、各地各校务于4月15日前完成推荐工作，并将各类获奖证明材料复印件一并上报市教育局基础教育科。

五、为了弘扬先进、树立榜样，要广泛宣传“优秀学生”、“优秀学生干部”和“先进班集体”的先进事迹。各地各校要将他们的先进材料认真进行审查，整理后与花名册、登记表等一并上报。

六、各旗县市区教育行政部门在推荐评选工作中，要向边远农村牧区及民族学校倾斜，认真执行有关文件精神，严格掌握政策，按规定程序评审。各旗县市区教育行政部门及市直学校要将推荐名单在校内进行公示，不得弄虚作假，切实把评选工作引导到培养“有理想、有道德、有文化、有纪律”的德、智、体、美、劳全面发展的社会主义事业建设者和接班人的轨道上来，通过开展学习先进活动，使评选工作真正起到鼓励广大学生奋发向上，健康成长的作用。

通辽市普通中学“优秀学生”“优秀学生干部”“先进班集体”评选办法

一、评选条件

（一） 市级“优秀学生”

1.热爱祖国，拥护中国共产党的领导；树立正确的理想信念，自觉践行社会主义核心价值观，思想道德高尚。模范遵守法律、法规和校规校纪；遵守《中小学生守则》和《中学生日常行为规范》，具有良好的社会公德和公民素养。

2.学习态度端正，学习目的明确，勤奋刻苦，有较强的分析问题和解决问题的能力。学习成绩优秀，学年成绩每科不低于85分，(以分数呈现的成绩为85分，以等第呈现的成绩为优)

3.积极参加公益劳动和各项集体活动。尊敬师长，孝敬父母，团结同学，关心集体，热爱劳动，言行举止文明礼貌，未受过任何纪律处分。

4.积极锻炼身体，参加文娱活动，《国家学生体质健康标准》测试达到优良等级。有良好的卫生习惯和健康的心理素质。残疾学生能努力参加力所能及的体育锻炼。

5.具有健康向上的审美意识及鉴赏美、表现美、创造美的能力，有一两项艺术特长和爱好。

（二）市级“优秀学生干部”

1.具备“优秀学生”评选的基本条件，且参评学年学生干部工作情况考核优秀。

2.担任班级、团支部和校级学生干部一年以上。

3.个人严于律己，模范带头作用强；任学生干部期间尽职尽责，积极协助老师工作；认真组织开展各项活动，热心为同学服务，有较强的工作能力和较为突出的工作成绩，在同学中威信较高。

（三）市级“先进班集体”

1.团支部和班委会政治立场坚定、团结协作、以身作则、联系同学，有较强的团队精神；

2.有积极上进、团结互助、遵规守纪、崇尚科学、热爱集体、热爱劳动、朝气蓬勃、文明健康的良好班风；

3.有严谨求实、刻苦钻研、奋发向上、争先创优的优良学风；

4.积极参与校风校貌建设活动，始终保持整洁的教室（宿舍）卫生环境；

5.全班同学都达到《国家体育锻炼标准》要求；

6.参评学年获得校级（含校级）以上“先进班集体”荣誉。

7.所在班级班主任无违反师德行为。班级管理和校内外教育活动严格执行通辽市中小学规范办学行为有关规定。本条规定，实行“一票否决”。

二、评选比例

初中毕业年级“优秀学生”评选不超过初中毕业年级在校生总数的3‰，普通高中“优秀学生”评选不超过普通高中在校生总数的2‰，“优秀学生干部”评选不超过普通中学班数的2%；“先进班集体”评选不超过普通中学班数的1%；“优秀学生”、“优秀学生干部”中少数民族学生比例不低于当地少数民族学生总数的25%。

三、评选程序及要求

（一）市教育局依据当年教育事业统计报表中学生在校生数和评选比例，确定推荐评选名额。

（二）旗县教育局会同当地团委按市教育局下达的评选推荐名额组织初评和推荐工作。

（三）教育行政部门要高度重视市级“优秀学生”、“优秀学生干部” 和“先进班集体”评选工作，加强组织领导，严格按评选条件组织推荐和评选，确保评选质量，严禁在评选过程中徇私舞弊，弄虚作假。

（四）学校推荐市级“优秀学生”、“优秀学生干部” 和“先进班集体”要坚持公开、公平、公正的原则。要实行公示制度，公示期不少于5个工作日。

本办法适用于全市普通初中、高中（含特殊教育学校初、高中学生）。
