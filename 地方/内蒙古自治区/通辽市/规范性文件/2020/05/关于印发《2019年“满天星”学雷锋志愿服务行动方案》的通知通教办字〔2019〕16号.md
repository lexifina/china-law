# 关于印发《2019年“满天星”学雷锋志愿服务行动方案》的通知通教办字〔2019〕16号

各旗县市区教体局，开发区教体卫计局，市直各校：

现将《2019年“满天星”学雷锋志愿服务行动方案》印发给你们，请结合实际认真贯彻落实。

2019年2月28日

2019年“满天星”学雷锋志愿服务行动方案

为大力弘扬“奉献、友爱、互助、进步”的志愿服务精神，通过在全市广泛开展形式多样、丰富多彩的学雷锋主题实践活动，激励和引导广大党员干部、青少年发挥示范引领作用，推动学雷锋活动常态化，通辽市教育局决定在全市各中小学校开展“满天星”学雷锋志愿服务行动。现制定行动方案如下：

一、指导思想

以习近平新时代中国特色社会主义思想为指导，以深化文明城市创建，助力新时代文明实践中心建设为主线，大力弘扬社会主义核心价值观和志愿服务理念，积极引导全市教育系统广大师生投身于学雷锋志愿服务活动中，让志愿服务遍地开花，形成人人为我，我为人人的良好社会风尚。

二、参加人员

各旗县市区教体局，开发区教体卫计局，市直各校领导、全体教职工，广大中小学生。

三、活动安排

（一）满天星志愿服务行动标准。按照“有标识、有场地、有队伍、有制度、有项目、有台账”的标准，每个志愿者都必须是在“全国志愿服务信息系统”实名注册登记的志愿者。每个单位都要建设“满天星”学雷锋志愿服务站，开展活动要有“某单位志愿者”字样的服装（绶带）或打着“某单位志愿者”字样的队旗，开展活动做到群众需求在哪里，文明志愿服务就到哪里。

（二）三月份志愿服务行动内容。

1.3月5日，举办“学雷锋活动月启动仪式”，开展“岗位学雷锋、行业树新风”活动、雷锋精神在校园活动。在月内相关会议上，表彰2018年学雷锋志愿服务先进集体和个人。

（三）四月份志愿服务行动内容。

2.4月5日清明节期间，开展网上祭英烈、文明祭扫、平安清明活动。

3.4月23日，于世界读书日开展赠书、送书、经典诵读、读书宣传周活动，着力打造书香校园。

（四）五月份志愿服务行动内容。

4.5月4日，以通辽实验中学“暖情行动”为模板，倡导全市各校学生开展关爱社区空巢老人活动。

（五）六月份志愿服务行动内容。

5.6月1日儿童节期间，开展关爱留守儿童、关爱残疾儿童、捐资助学活动。

（六）九月份志愿服务行动内容。

6.9月10日教师节期间，开展感恩教师、服务我恩师、慰问老教师，“走基层 弘师德”志愿服务活动。

7.9月20日，于公民道德宣传日开展自觉排队、文明让座、文明礼仪进校园，做一个“有道德的人”主题教育活动。

（七）十月份志愿服务行动内容。

8.国庆节前后，开展爱国主义教育宣传，在“十一”黄金周开展“文明出游从我做起”文明旅游志愿服务活动。

四、注册志愿者要求

1.注册网址：通辽文明网（http://nmgtl.wenming.cn/），全国志愿服务信息系统。

2.2019年全年注册志愿者人数目标分解。见附件。

各地各校要把志愿服务纳入日常工作，研究制定志愿服务管理办法，鼓励人人参加力所能及的志愿服务。要根据志愿服务活动的需要，为志愿者购买必要保险、提供基本保障。

五、活动要求

1.加强领导、精心组织。开展志愿服务活动对于发挥党员干部模范带头作用，展示中小学生风采，树立校园文明形象，服务深化文明城市创建，倡导乡风文明具有重要的推动作用。各地各校要切实加强领导，充分认识志愿服务活动的重要意义和“满天星”学雷锋志愿服务活动的深刻内涵，积极引导和鼓励广大干部群众参与到志愿服务活动当中。

2.精心设计、务求实效。各地各校要创新工作思路，把“满天星”学雷锋志愿服务活动作为新时代文明实践中心建设的载体活动，多运用师生喜闻乐见的方式，多搭建师生便于参与的平台，多开辟师生乐于接受的渠道，吸引广大师生自觉参与到志愿服务活动中，推动向上向善、诚信互助良好社会风尚的形成。

3.严格督查、厉行节俭。市委宣传部每月会对各地各责任部门活动开展情况进行督促检查，推动活动落细落实。各地各校要及时总结推广好经验好做法，要坚持艰苦奋斗、倡导厉行节约，杜绝形式主义、反对铺张浪费。

4.扩大影响、营造氛围。各地各校要切实加大活动的宣传力度，充分利用各自宣传方式并借助各种宣传媒介，大力宣传各地各校深入开展“满天星”学雷锋志愿服务活动的典型经验，努力扩大活动的影响力和覆盖面，为活动开展营造良好舆论氛围。

5.认真总结，全面上报。各旗县市区教体局，开发区教体卫计局，市直各校要制定活动方案并指派专人负责。对活动不力的单位将通报批评。在年底将对活动开展丰富的集体和个人进行表彰。请各地各校将志愿者人数分解表、组织活动开展情况、活动总结和有关图片的电子版报送至电子邮箱:1043106204@qq.com，联系人：韩艳春，联系电话：[电话略]。
