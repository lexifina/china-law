# 关于印发《通辽市住房和城乡建设局2020年度法治政府建设工作实施方案》的通知

各科室、局属各执法单位：

现将《通辽市住房和城乡建设局2020年度法治政府建设工作实施方案》印发给你们，请认真抓好贯彻落实。

2020年4月30日

通辽市住房和城乡建设局2020年度法治

政府建设工作实施方案

按照中共中央、国务院《法治政府建设实施纲要2015-2020年）》、通辽市人民政府办公室关于印发《通辽市2020年度法治政府建设工作实施方案》的通知（通政办字[2020]22号）要求，为完成法治政府建设过程中的各项工作，制定如下方案：

一、指导思想和目标

以习近平新时代中国特色社会主义思想为指导，深入贯彻习近平总书记关于全面依法治国、法治政府建设重要论述和党的十九届四中全会精神，进一步学习领会中央全面依法治国委员会第三次会议精神。根据通辽市政府有关要求，围绕《法治政府建设实施纲要（2015—2020年）》，坚持依法治国、依法执政、依法行政共同推进，坚持法治国家、法治政府、法治社会一体建设，全面完成法治政府建设各项任务，2020年基本建成职能科学、权责法定、执法严明、公开公正、廉洁高效、守法诚信的法治政府。

二、重点工作任务

（一）进一步提高政治站位，夯实法治政府建设第一责任人职责。

一是落实领导责任。按照中办国办《党政主要负责人履行推进法治建设第一责任人职责》和《法治政府建设与责任落实督察工作规定》精神，领导班子要自觉运用法治思维法治方式深化改革、推动发展、化解矛盾、维护稳定，对法治建设重要工作亲自部署、重大问题亲自过问、重点环节亲自协调、重要任务亲自督办，把本单位各项工作纳入法治化轨道。领导班子每年要专题听取本地区、本单位法治政府建设情况汇报1次，专题研究法治建设工作不少于2次。

二是落实领导干部带头学法制度。按照《纲要》要求,党组（党委）领导班子中心组学法不少于4次，举办1期领导干部、行政执法人员法治专题培训班,进行1次全体人员通用法律知识考试。

三是落实工作实绩考核评价体系。单位党政主要负责人

履行推进法治建设第一责任人职责情况列入年终述职内容，

将法治政府建设纳入本地区经济社会发展总体规划和年度计划，与经济社会发展同部署、同推进。

（二）进一步深化“放管服”改革。持续深化简政放权、

放管结合、优化服务改革工作。

一是着力做好简政放权重点工作。公布行政权力事项清单和公共服务事项清单；按照国务院要求，对直接面向群众、量大面广、由基层实施更方便有效的行政审批事项，按要求下放基层管理；全面清理于法无据的资质、资格准入行政许可；一律取消没有法律依据的证明事项，对保留的证明事项实行清单管理，做到“清单之外无证明”。

二是大力推行“互联网+政务服务”。落实推进“一窗通办”、“一网通办”、“最多跑一次”改革和政务服务标准化工作，政务服务重点领域和高频事项办理基本实现“一网、一门、一次”。

三是深入推进优化营商环境工作。贯彻落实国务院《优化营商环境条例》，精简涉企经营许可事项，持续放宽市场准入，政府基金、涉企行政事业性收费、涉企保证金等实行目录清单管理，加强社会信用体系建设。

四是提高政务服务水平。按照国务院办公厅《关于建立政务服务“好差评”制度提高政务服务水平的意见》，夯实政务服务责任，厘清政务服务事项，规范政务服务要求；深入推进党建引领“一号通办、街镇（苏木）统办”群众工作机制，切实打通服务群众“最后一公里”。

五是加强政府购买服务监管。建立健全政府购买服务制度，加强政府购买公共服务质量监管，对服务数量、质量和效果开展第三方评估。

（三）进一步加强行政执法“三项制度”落实。认真学习贯彻《内蒙古自治区行政执法公示执法全过程记录重大执法决定法制审核办法》，进一步规范行政执法程序，加强行政执法监督。及时归集汇总各类执法信息并予以公示；对行政执法的启动、调查取证、审核决定、送达执行等过程通过文字、音像等记录方式进行记录；在作出重大行政执法决定前，进行法制审核。加强事中、事后监管，开展“双随机、一公开”监督检查；要加大监管执法工作力度。

（四）进一步落实重大行政决策程序。严格贯彻落实《重

大行政决策程序暂行条例》，全面履行公众参与、专家论证、

风险评估、合法性审查和集体讨论决定重大行政决策程序。制定重大行政决策应当听取法律顾问意见，发挥法律顾问咨询论证、审核把关作用。对涉及经济社会发展和人民群众切身利益的重大决策、重大项目，要进行社会稳定、公共安全等方面的风险评估。制定重大行政决策专家论证、风险评估制度、终身责任追究制度和责任倒查机制。

（五）进一步推进综合行政执法改革。推进政执法改革，理顺市本级与科区、开发区的执法职责，整合执法力量，避免出现职责交叉、重复执法等问题。

（六）进一步推进行政复议、行政应诉等工作。运用法治政府建设智能一体化平台审理录入行政复议案件，全程网上留痕，利用大数据汇集、分析，发挥行政复议化解行政争议的主渠道作用；加强和改进行政应诉工作，行政机关负责人出庭应诉率要不低于50%，涉及重大公共利益和社会高度关注等案件，被诉行政机关负责人出庭率应达到100%；要继续严格落实规范性文件制定、清理、审核和备案程序。

（七）进一步做好“七五”普法验收等工作。严格落实“谁执法谁普法”普法责任制，对照全市“七五”普法规划，全面做好普法自查，查弱项，补短板，有效完成“七五”普法验收各项任务；加强网络在线学法和普法考试工作力度；继续加强法治教育培训力度，组织开展行政执法人员法律法规专题培训，加强领导干部任职前法律知识考查和依法行政能力测试，考核干部工作把法治观念强不强、法治素养好不好作为衡量干部德才的重要标准。

（八）进一步创新社会治理方式。一是提高公共突发事

件防范处置和防灾救灾减灾能力。在处置重大突发事件中推

进法治政府建设，提高依法执政、依法行政水平。二是完善生态环境保护制度。加强节能降耗和生态环境保护

三、具体方法步骤

（一）自查整改推进阶段（2020年4月30日-7月31日）

围绕所承担的法治政府建设具体任务认真开展“回头看”，深入进行自查，找差距、补短板，对已经完成的工作，要形成台账资料，对未完成的工作，要找准症结，尽快完成。按照自查中存在的问题建立工作台账，明确时间表和路线图，实行销号管理，逐项落、逐条抓，全面完成各项任务，并将任务完成情况于8月5日之前报送市委全面依法治市委员会办公室（市司法局），除有明确完成时间节点的工作外，《法治政府建设任务清单》中的其他任务要在7月底之前完成，确保《纲要》任务圆满收官。

（二）组织验收阶段（2020年8月1日-10月31日）

接受市委全面依法治市委员会办公室对法治政府建设任务完成情况进行核查验收，查缺补漏、及时发现典型做法，为迎接自治区验收作好准备。

（三）全面总结阶段（2020年11月1日-12月5日）

对《纲要》五年工作任务完成情况进行全面总结，于12月8日之前报送市委全面依法治市委员会办公室（市司法局）。

四、强化保障措施

（一）坚持党的领导，把党的领导贯彻到法治政府建设各方面。党的领导是全面推进依法治国、加快建设法治政府最根本的保证，必须坚持党总揽全局、协调各方的领导核心作用。自觉接受党的领导，切实增强建设法治政府的使命感、紧迫感和责任感，强化工作责任，一级抓一级，层层抓落实。

（二)健全组织机构，为法治政府建设提供保障。充分发挥领导小组的统筹协调作用，按照《纲要》既定任务，压实责任，推进法治政府建设任务如期完成。

（三）及时调度，促进法治政府建设任务落地见效。

按照市政府实行的“周调度、月通报”工作机制及市政府对法治政府建设任务推进落实情况开展专项督察的要求，切实履行法治建设第一责任人职责，狠抓责任落实。

（四）明确专人负责，及时完成法治政府建设智能化一

体平台录入。法制宣传和执法监督科负责统筹推进法治政府建设智能化一体平台录入工作，各相关科室、单位在各自职责范围内录入相关信息。

（五）形成监督合力，强化对行政权力的制约。自觉接受党内监督、人大监督、民主监督和司法监督，有效制约行政权力，促进行政机关依法依规行政；加强行政监督和审计监督；要持续推进政务公开，实行政务公开清单管理制度，并动态更新。
