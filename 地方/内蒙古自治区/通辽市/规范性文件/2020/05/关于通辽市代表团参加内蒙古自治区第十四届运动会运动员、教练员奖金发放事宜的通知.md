# 关于通辽市代表团参加内蒙古自治区第十四届运动会运动员、教练员奖金发放事宜的通知

各旗县市区教体（教科体）局，各相关单位：

内蒙古自治区第十四届运动会于2018年8月在乌兰察布市闭幕，通辽市代表团团结协作、顽强拼搏在内蒙古自治区第十四届运动会上取得较好成绩，共获得90枚金牌、78枚银牌、104枚铜牌，总分5786分，其中竞技组获得85枚金牌、72枚银牌、100枚铜牌，总分5469分；群众组获得5枚金牌、6枚银牌、4枚铜牌，总分317分。

为表彰我市运动员、教练员在自治区“十四运”取得的优异成绩，激励广大运动员、教练员刻苦训练，再创佳绩，实现我市参加自治区“十五运”新的突破，决定对代表我市参加自治区“十四运”取得优异成绩的运动员、教练员予以奖励，现将相关事宜通知如下：

一、奖励范围

代表通辽市参加内蒙古自治区第十四届运动会取得名次的运动员、教练员（以《内蒙古自治区第十四届运动会秩序册》和《内蒙古自治区第十四届运动会总成绩册》为准）。

二、奖励标准

（一）竞技组

1.运动员奖励标准

（1）在自治区第十四届运动会比赛中，取得个人项目前三名的运动员，分别给予4万元、1.5万元、0.8万元的奖励（不再按分计奖），第四名至第八名按所得分数计奖，每分奖励200元。

（2）在自治区第十四届运动会比赛上，奖牌双记的个人项目，按实际计入我市代表团的奖牌数给予奖励；破（超）纪录的项目、按实际计入我市代表团的奖牌加破（超）记录分数给予奖励，在同一赛事中多次破（超）纪录，只奖励一次。

2.教练员的奖励标准

根据本办法获得奖励的运动员，其对应的教练员也给予奖励，奖励标准与获奖运动员奖励标准相同。无论涉及几名教练员，只按一名教练员的奖金标准给予奖励。

3.集体项目奖励标准

集体类项目按照记入我市代表团的奖牌和分数给予奖励，第1-3名每计入一枚金牌奖励8万元，第4-12名每计入一分奖励400元，运动队、教练员（团队）各占总奖金的50%。

（二）群众组

群众组只对运动员进行奖励，奖励标准为在自治区第十四届运动会比赛中，取得项目前三名的运动员，分别给予4万元、1.5万元、0.8万元的奖励（不再按分计奖），第四名至第八名按所得分数计奖，每分奖励200元。

三、分配办法

（一）本通知所称奖金均为税前金额，运动员、教练员实际所得奖金为税后奖金（按照《中华人民共和国个人所得税法》，征收20%个人所得税，由市体育局整体代缴）。

（二）单项团体类项目按照上场运动员人数平均分配

奖金，教练员与所属运动员同奖。

（三）集体类项目，出队单位根据运动员、教练员贡献大小自行确定奖金分配数额。

四、相关要求

（一）奖金分配关乎教练员、运动员的切身利益，涉及人数多、社会关注程度高，各地各部门要高度注视，层层落实责任，领导分级把关，务必做到人数、人员、金额清晰，不出任何纰漏，决不允许出现多报、瞒报、漏报等情况，一旦出现类似问题将严肃追究相关人员的责任。

（二）凡出现人数不清、金额数量存疑情况，由各地各单位协商解决，市体育局不接受存疑报表。

（三）各地各单位认真填报相关表格（附件1、附件2），经相关人员签字，加盖单位和主管部门公章后上报市体育局各相关科室。任何项目不全、数据不符合要求，市体育局将不发放奖金，直到达到要求为止。

（四）涉及多名教练员的获奖项目或因特殊情况运动员、教练员不在秩序册名单中人员的奖金分配，需单位出具正式文件说明。

（五）市体育局将依据各单位报送表格（附1、附2）信息，将奖金直接拨付至获奖个人银行账户，要求各上报单位核准个人姓名、身份证号码、银行账户及卡号均与获奖本人信息一致。
