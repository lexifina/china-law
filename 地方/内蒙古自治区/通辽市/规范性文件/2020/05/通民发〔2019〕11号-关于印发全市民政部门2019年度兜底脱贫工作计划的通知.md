# 关于印发全市民政部门2019年度兜底脱贫工作计划的通知

通民发〔2019〕11号

&nbsp;

各旗县市区民政局，局机关相关科室：

按照《中共通辽市委员会 通辽市人民政府关于打赢脱贫攻坚战三年行动的实施意见》（通党字〔2018〕69号）、《通辽市人民政府办公厅关于进一步加强农村牧区最低生活保障制度与扶贫开发政策有效衔接的工作方案》（通政办字〔2018〕42号）、《通辽市在脱贫攻坚三年行动中切实做好社会救助兜底保障工作的实施方案》（通民发〔2018〕94号）、《通辽市民政局打赢脱贫攻坚战三年行动计划实施计划》（通民发〔2018〕97号）要求，市民政局制定了全市民政部

&nbsp;

门2019年兜底脱贫工作计划，现将工作计划印发给你们，请认真抓好落实。

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;

2019年3月22日

&nbsp;

&nbsp;

全市民政部门2019年度兜底脱贫

工作计划

&nbsp;

一、工作任务

（一）按照市委市政府要求，坚决做好中央脱贫攻坚专项巡视反馈意见的整改工作，确保问题整改到位。（各旗县市区民政局，社会救助科、社会科负责）

（二）开展无劳动能力建档立卡贫困人口未落实兜底政策“清零达标”专项行动，将完全和部分丧失劳动能力且符合条件的建档立卡贫困人口纳入低保和特困供养范围，确保建档立卡贫困人口纳入低保兜底保障和特困人员救助供养未落实到位清零。（各旗县市区民政局，社会救助科负责）

（三）落实低保兜底保障脱贫工作联席会议制度，共享因病、因残等完全丧失劳动能力和部分丧失劳动能力建档立卡贫困人口数据，确保应保尽保。（各旗县市区民政局，社会救助科负责）

（四）加大临时救助力度，将符合临时救助条件的建档立卡贫困人口特别是返贫人口纳入临时救助范围。（各旗县市区民政局，社会救助科负责）

（五）加强与扶贫部门信息核对工作，市旗两级民政、扶贫部门每季度至少核对一次农村低保对象和建档立卡贫困人口数据，做到动态调整、及时比对。（各旗县市区民政局，社会救助科负责）

（六）做好建档立卡贫困人口与低保对象信息共享，定期交换部门相关数据。（各旗县市区民政局，社会救助科负责）

（七）继续健全完善农村牧区建档立卡贫困留守老年人信息台账录入和定期探访制度。（各旗县市区民政局，社会科负责）

（八）落实农村牧区建档立卡贫困留守儿童监护责任。（各旗县市区民政局，社会科负责）

（九）做好农村牧区建档立卡贫困残疾人基本生活补贴和重度残疾人照料护理补贴发放工作。（各旗县市区民政局，社会科负责）

（十）配合做好自治区民政厅社会工作服务京蒙“牵手计划”有关工作，实施社会组织帮扶项目。（各旗县市区民政局，社会组织管理局负责）

二、工作要求

（一）提高思想认识，高度重视兜底脱贫工作。各地民政部门要切实提高政治站位，加强组织领导，切实把思想和行动统一到市委市政府关于做好脱贫攻坚工作的部署要求上来，严格按照年度工作计划，落实好各项脱贫攻坚工作任务。

（二）明确职责分工，深入推进兜底脱贫工作。各旗县市区、局机关相关科室要把2019年度民政部门脱贫攻坚工作责任落实到人，明确工作时限，建立工作台账。各地民政局主要负责人要定期听取本地区兜底脱贫工作进展情况，研究解决工作推进中存在的困难和问题，确保民政部门兜底脱贫工作有效落实。

（三）强化督导检查，确保各项工作取得实效。市民政局要成立督导组，对全市各地民政部门落实脱贫攻坚工作责任和工作推进情况进行实地督导检查，及时发现存在的问题和不足，及时指导纠正。对工作推进迟缓、弄虚作假的，要严肃问责并通报全市。
