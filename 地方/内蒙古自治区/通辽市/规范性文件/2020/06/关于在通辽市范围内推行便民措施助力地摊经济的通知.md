# 关于在通辽市范围内推行便民措施助力地摊经济的通知

各旗县市区住房和城乡建设局、开发区住建和交通运输局、各旗县市区城市管理执法部门：

为深入贯彻落实党中央、国务院“六稳”、“六保”方针，纾困中小微企业和个体工商户，在保障安全、保障通畅、保障防疫情况下，在通辽市范围内推行“四允许”便民措施助力地摊经济有序健康发展，现将有关工作通知如下：

一、允许临街店铺临时越门经营

在不占用盲道和消防通道、不侵害他人利益、保证环境卫生前提下，允许临街商家临时越门摆放商品。

临街餐饮店铺在规定的时段内(18：00-23：00)允许占道经营，店外摆放的餐桌下要有垃圾桶，地面要铺设防油垫，并配备专职保洁员。一律不得店外吹碳，不得店外烧烤，不得往雨水篦子里倒污物。

二、允许流动商贩有序经营

在不占用黑色路面、不占用盲道和消防通道、不侵害他人利益的前提下，允许流动商贩在规定的街路小巷和居住集中区域沿街贩卖经营，经营过程中产生的垃圾要随产随清，撤摊后地面要保持整洁。

三、允许大型商超占道促销

大型商超在商场红线范围内开展占道促销活动，做到不动火、不动气、不冒烟，确保没有安全隐患，产生的垃圾及时清理，撤摊后要保持地面卫生整洁。

四、在布局合理的前提下允许早夜市占道经营

早夜市要在规定的时间段内经营（早市撤市时间7:30，夜市上市时间18:00，撤市时间23:00）,摊位要整齐有序、自备垃圾容器，车辆停放不得堵塞交通。食品加工制作摊位场地上要铺设防油垫，地面油污要及时处理，不得往雨水篦子里倒污物。

2020年6月9日
