# 市人大常委会法工委举办全市人大立法、备案审查工作培训班

5月10日至11日，全市人大立法、备案审查工作培训班在市少数民族文化交流服务中心举办。市人大常委会副主任马嘎尔迪、刘英杰，部分市人大法制委员会组成人员出席开班仪式。刘英杰作动员讲话，市人大常委会法工委主任靳锐主持开班仪式。

刘英杰在动员讲话中强调，一要统一思想，充分认识立法培训的重要性。在加强和改进地方立法工作、提高地方立法质量的新形势下，对立法人员进行知识更新培训尤为必要。二要认真学习，确保立法培训取得实效。通过学习掌握地方立法工作涉及的专业知识，并将所学知识运用到今后的立法和备案审查工作的具体实践中，学以致用。

培训班上，自治区人大常委会法工委备审处处长苏秀泉讲授了《地方立法和备案审查具体工作中应重点把握的几个主要问题》。福州市人大常委会副调研员吴光华讲授了《福州市园林绿化管理条例》立法规范与技术，福州市人大常委会城环工委生态环保处处长朱益刚以《福州市园林绿化管理条例》为视角，讲授了园林绿化立法工作实践与思考。

此次培训，使我市立法和备案审查工作人员充实了理论知识，开阔了视野，加强了业务能力建设。

市人大常委会办公厅、各委员会负责备案审查的工作人员，各旗区人大常委会、康巴什新区人大工委分管备案审查工作的副主任和工作人员，市人大常委会各基层立法联系点负责人以及有关人员，市法制办有关工作人员，市建委、园林局等部门负责《城市绿化管理条例》立法的相关人员共50多人参加了培训。（张英辉、乌日娜）
