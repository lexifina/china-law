# 鄂尔多斯市环境保护局关于印发《鄂尔多斯市汛期环境安全生产大检查百日行动实施方案》的通知

各旗区、开发区环保局：

按照《内蒙古自治区环境保护厅西部环境保护督查中心关于开展汛期安全生产大检查百日行动的通知》（内环西督函〔2014〕171号）和鄂尔多斯市安委办《鄂尔多斯市汛期安全生产大检查百日行动实施方案》（鄂安办发〔2014〕28号）要求，我局制订了《鄂尔多斯市2014年汛期环境安全大检查百日行动实施方案》，现印发给你们。请结合自身实际，认真组织开展汛期环境安全大检查百日行动，并严格按照实施方案要求按时报送相关工作信息和总结报告。

2014年7月16日

鄂尔多斯市2014年汛期环境安全大检查百日行动实施方案

为深入贯彻落实国务院安委会办公室、国家安全生产监督管理总局《关于做好汛期安全生产工作的通知》（安委办〔2014〕9号）、《内蒙古自治区环境保护厅西部环境保护督查中心关于开展汛期安全生产大检查百日行动的通知》（内环西督函〔2014〕171号）和鄂尔多斯市安委办《鄂尔多斯市汛期安全生产大检查百日行动实施方案》（鄂安办发〔2014〕28号）文件精神和要求，结合我市当前汛期环境安全工作形势，我局决定在全市范围内开展汛期环境安全大检查百日行动，特制订本方案。

一、指导思想

以国务院安委办〔2014〕9号文件、内环西督函〔2014〕171号、鄂安办发〔2014〕28号文件为指导，充分认识汛期环境安全大检查百日行动的重要性和紧迫性，健全工作机构、强化组织领导，层层落实责任，早部署、早安排、早发动、早准备，确保汛期环境安全。

二、活动时间

2014年6月下旬至2014年9月下旬。

三、检查内容

百日行动期间，各旗区、开发区环保局要组织开展汛期环境安全大检查工作，切实落实汛期环境安全要求和应急防范措施，全面深入排查治理环境安全隐患，严防各类环境安全事故发生。重点突出以下六个方面：

（一）存在环境风险隐患的企业，必须重点检查，要求有问题的企业立即整改，不得遗漏任何死角。

（二）全面排查饮用水水源保护区、准保护区及上游地区，对存在隐患、可能造成水体污染的风险源，积极采取有效措施，及时清理和整改，防患于未然。

（三）对灰坝、垃圾填埋场、排土场、矸石场等全面排查，严格规范处置，严防因垮塌，滑坡等造成的人员伤亡和环境污染。

（四）对污水暂存池、泥浆池、应急池、蒸发池等可能因大雨引发环境污染的设施和环节进行专项检查，避免因雨水量大造成事故排污。

（五）对存在排土堵塞河道、影响行洪的矿区，应尽快采取有效的整改措施，联合有关部门进行河道清理，保证行洪畅通。

（六）对其他因洪水可能产生次生环境灾害的隐患点进行排查，严防突发环境事件的发生。

四、工作要求

（一）加强领导，认真组织。

各旗区、开发区环保局要牢固树立红线意识，充分认识抓好环境安全工作的极端重要性和当前安全生产形势的严峻性，深刻吸取近年来突发环境事件的沉痛教训，坚决克服麻痹思想和侥幸心理，切实增强做好汛期环境安全工作的责任感和紧迫感。要在全面分析汛期环境安全形势和薄弱环节的基础上，结合实际周密制定环境风险隐患排查治理工作方案。要按照“党政同责、一岗双责、齐抓共管”的要求，加强组织领导，健全机构，明确责任，完善一级抓一级、层层抓落实的责任体系。主要领导要亲自研究部署，加强督促检查；分管领导要切实履行职责，深入一线开展督查，确保汛期安全大检查百日行动有序开展，有力推进，扎实有效。

（二）全面排查，狠抓落实。各旗区、开发区环保局要加大环境风险隐患整治力度，不打折扣、不留死角、不走过场，做到“全覆盖、零容忍、严执法、重实效”。对排查出的隐患和问题，要求企业落实整改责任、措施、资金、期限和预案，能整改的立即整改，一时难以整改的要加强防控，并及时报告旗区政府、开发区管委会和我局。对存在重大隐患的企业实行分级挂牌督办制度和限期治理销号制度，进行跟踪督办，逐项整改销号。对重点领域、重点行业、重点企业、重点部位和重点隐患，要盯死看紧，保持高压态势，一抓到底。

（三）加强应急管理，提高应急处置能力。各旗区、开发区环保局要进一步完善应急管理工作机制，严格执行领导干部带班值班制度和关键岗位24小时值班制度，切实加强领导、落实责任，全面做好环境突发事件的信息报送工作，保持信息渠道畅通。环境应急队伍要做好应急准备，确保救援队伍、设备、物资等应急资源落实到位。

（四）总结经验，畅通信息。各旗区、开发区环保局务必于9月10日前报送汛期环境安全生产大检查百日行动总结。同时，要加强信息反馈工作，及时将汛期环境安全大检查相关信息报送至市环保局。

百日行动期间，市安委办将组织对全市汛期安全工作部署和落实情况进行全面检查。对存在隐患严重、不及时整改的相关责任人追究相应责任。
