# 丰台区2012年“周末百姓大舞台”活动方案

为深入贯彻落实党的十七届六中全会精神和丰台区第十一次党代会精神，充分发挥文化的社会引领、文明促进、品牌塑造和人心凝聚作用，为建设繁荣、文明、幸福新丰台建设目标营造良好的文化氛围，我委将于2012年继续组织开展“周末百姓大舞台”活动，以露天剧场、文化广场为平台，通过内容丰富、形式多样的文艺节目，丰富群众文化生活，为党的十八大召开营造浓厚的文化氛围。具体方案如下：

一、活动时间

2012年5月——10月

二、活动地点

2007年以来，由政府投资新建、改扩建的19个文化广场。

三、场次安排

每个广场安排6场演出，总计场次114场。

四、活动形式

在各街乡（镇）原有文化活动的基础之上，根据当地群众需求，每月选择双休日时间在广场组织一场高质量的文艺演出，节目形式、内容要贴近实际、贴近生活、贴近群众。

为确保演出质量，区文化馆将对参加演出单位进行资格评审，凡获得评审通过的演出单位方可参加本年度“周末百姓大舞台”演出（具体演出安排详见附件1）。

五、经费补助标准

（一）演出团队补助

群众业余文艺团队每场演出补助4000元；

（二）场地单位补助

各场地单位每场演出补助1000元；

（三）辖区管理单位补助

各辖区管理单位每场演出补助1000元。

六、组织机构

成立活动领导小组。

七、工作职责

（一）区文委

1.负责制定2012年“周末百姓大舞台”演出工作方案；

2.负责做好活动的统筹、协调工作；

3.负责参加演出团队的考核；

4.负责与财政局共同制定专项资金拨付方案，并对资金使用情况实施监督。

（二）场地提供单位

1.负责按照演出要求做好演出场地、背板或横幅、音响保障；

2.负责做好演出团队后勤保障工作，为演职人员提供用水等必要条件；

3.树立“安全第一”的观念，制定切实可行的安保方案和应急预案，确保广大群众与演员的人身安全。

（三）辖区管理单位

1.负责与演出团队、场地提供单位进行沟通、协调，制定演出活动具体方案，提前将演出时间、场次报送办公室备案；

2.负责演出节目的审查、监督、检查工作；

3.负责做好现场观众的组织工作；

4.每场演出结束，填写《“周末百姓大舞台”演出评价表》（见附件2），并附演出节目单及2张反映现场演出情况的照片报送活动办公室。

（四）演出单位

1.以“繁荣、文明、幸福”为主题，精心编排一台内容健康，形式多样的文艺节目；

2.每场演出时间控制在90—120分钟之间；

3.所有演员必须着演出服并化妆登台演出；

4.提前将节目单、演员阵容、演出需求报辖区管理单位，演出当日应提前一小时到达演出场地，确保高水平、高质量完成演出任务。

八、工作要求

（一）高度重视，精心组织。各单位要充分认识此项活动在活跃群众文化生活，构建和谐社会中的重要作用，认真落实分工职责，制定切实可行工作方案，做到定岗、定人、定责，确保活动既有规模、声势，又扎实、有效。

（二）整合资源，突出特色。整合区域文化资源，深入挖掘本地区文化特色，通过活动内容、形式、手段的推陈出新，不断丰富活动内容，吸引力更多的群众积极参与，满足广大群众多层次、多样化的文化需求。

（三）加强沟通，密切配合。此项活动涉及单位多、覆盖面广、时间跨度长，各单位要积极配合，密切沟通，通力协作，做好场地安排、后勤保障、节目演出等各环节工作，确保整体活动顺利进行。

（四）加大宣传，营造氛围。充分利用各种宣传手段和渠道，借助现代化的传播工具，加大宣传力度，扩大活动影响力。

（五）安全第一，万无一失。各单位要坚持安全为先的原则，结合本单位职责分工制定相应的安保方案、应急预案，坚决杜绝各类安全事故的发生，保证活动顺利进行。
