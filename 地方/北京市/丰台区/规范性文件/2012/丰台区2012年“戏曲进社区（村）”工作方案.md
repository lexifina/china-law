# 丰台区2012年“戏曲进社区（村）”工作方案

为贯彻落实十七届六中全会精神，按照《中共丰台区委区委关于把丰台建设成为充满活力的首都文化强区的实施意见》的总体要求，丰台区文化委员会与中国戏曲学院将于2012年继续开展“戏曲进社区（村）”活动。通过开展丰富多彩的戏曲活动，传承中华传统文化，活跃社区居民文化生活，为丰台区打造戏曲文化中心建设目标奠定基础。为保证活动的顺利开展，特制定工作方案如下：

一、目的意义

为配合丰台区戏曲文化中心建设，进一步扩大受众范围，在以往戏曲进社区活动的基础上创新方式，以公开辅导，开门授课为核心，以授课送至家门，贴近百姓，服务百姓为宗旨，利用丰台区新建的文化广场，使“戏曲进社区活动”切实走进百姓生活中。同时，组织学生志愿者服务社区，艺术实践进社区，在实际工作中成才干做贡献。通过活动，充分发挥丰台区的戏曲及文化资源优势，丰富居民的文化生活，搭建社区与校园的艺术沟通桥梁，促进优势互补，共同构建和谐社会。

二、活动时间

2012年5月——11月

三、活动地点

区文化馆、区图书馆、和义文化广场、万芳亭公园文化广场、宛平文化广场、北京十二中、北京十八中、北京十中、丰台二中、赵登禹中学、航天中学。

四、参与方式

在区图书馆安排系列讲座，包括戏曲音乐基础、演唱基础、唱腔演唱指导；在区文化馆将安排分行当教学，包括老生、老旦和青衣唱腔、身段表演。全区戏曲爱好者可按照课程表自行前往听课。

在三个文化广场安排戏曲健身操培训，主要由广场所在地街道办事处组织当地戏曲爱好者作为基本成员参加，其他地区的戏曲爱好者可根据授课内容就近选择地点参加活动。

在六所学校和我区机关安排戏曲知识启蒙课程10讲，同时邀请我区机关工作人员和各行业领域的戏曲爱好者参加。

在有票房的街道乡镇，有针对性的开展票房辅导。

五、活动形式与内容

（一）授课形式

采取公开辅导，开门授课的方式，根据课程内容形成分层次、分类别、分行当的系列教学模式，由中国戏曲学院派出专业教师、研究生及高年级学生分赴指定地点进行授课和辅导。主要开设戏曲知识系列讲座，戏曲健身操系列教学，唱腔、身段表演教学等课程，重在简而精，递进式增大难度和深度。

（二）具体内容

——戏曲知识讲座

以专题讲座的形式重点讲解戏曲演唱基础、戏曲音乐基础、唱腔音乐与演唱指导分析、戏曲发音技巧、演唱技巧、唱段演唱指导分析。

——分行当表演课

采取分组教学方式，按照青衣、老生、老旦三个行当分别进行唱段与身段指导。

——戏曲健身操系列

采取广场教学的方式重点教授戏曲健身操中的三套，即《云手操》、《折扇操》、《水袖操》。

六、经费预算

戏曲知识系列讲座费用19800元；分行当教学32400元；戏曲健身操教学费用32400元；票房辅导费用9000元，总费用合计101600元。

七、任务分工

（一）丰台区文化委员会：

1.负责制定活动总体方案并部署；

2.负责印发戏曲进社区授课地点、课程安排；

3.与中国戏曲学院签署合作协议书并做好经费拨付；

4.负责整体活动的监督落实。

（二）中国戏曲学院：

1.制定详细课程计划并组织实施，确保授课质量；

2.监督授课情况，对现场参加人员进行统计；

3.收集群众意见并反馈，对教学工作进行及时调整；

4.对活动全过程影响资料留存，活动结束后形成书面总结。

（三）和义街道办事处、西罗园街道办事处、宛平地区办事处：

1.负责场地环境布置及音响保障；

2.负责组织辖区内戏曲爱好者参加活动，并视情况摆放座椅；

3.配合中国戏曲学院做好教学保障工作；

4.确保活动现场秩序井然。

（四）区文化馆、图书馆

1.负责场地环境布置及音响保障；

2.配合中国戏曲学院做好教学保障工作。
