# 丰台区关于创建基本公共文化服务全覆盖试点和城市“六型社区”示范单位的工作方案

为深入贯彻落实党的十七届六中全会精神，建立和完善覆盖城乡、结构合理、功能健全、实用高效的公共文化服务体系，北京市文化局将于2012年在全市范围内开展创建基本公共文化服务全覆盖试点社区和城市“六型社区”示范单位工作，为确保我区创建工作顺利实施，现结合我区实际，制定方案如下：

一、指导思想

以邓小平理论和“三个代表”重要思想为指导，以科学发展观为统领，以提高广大群众的思想道德和科学文化素质为目标，大力加强社区文化阵地、文化队伍、文化活动和文化工作机制建设，形成社区文化设施完备、文化活动活跃、队伍健康发展、机制健全有效的良性运作格局，为建设经济繁荣、社会文明、人民幸福的新丰台提供强有力的精神支撑和思想道德保障。

二、工作目标

按照北京市总体部署，在我区完成103个基本公共文化服务全覆盖试点社区、59个城市“六型社区”示范单位创建工作（具体名单见附件1）。以创建促发展，以创建促提升，建立完善社区公共文化服务设施，提高公共文化服务能力与水平，丰富广大群众文化生活，吸引更多的社区居民参与，满足群众日益增长的精神文化需求，增强居民对社区的认同感、归属感，激发居民参与社区建设的积极性、主动性，营造文明祥和、健康向上的社区文化氛围。

三、创建内容

（一）建立基本公共文化服务全覆盖试点社区

全区将在16个街道对103个社区开展试点工作。根据北京市文化局《北京市基层公共文化设施服务规范（试行）》（附件2）的内容和要求，推进实施。试点社区要达到：文化设施能够提供演出排练、电影放映、图书阅览、展览展示、文化信息共享、文艺创作、文化技能培训、校外活动、学生自习和娱乐健身等基本公共文化服务和文化产品，能够满足老年人、未成年人、残疾人等各类群体的基本文化需求。

（二）建立城市“六型社区”示范单位

全区将在16个街道对59个社区开展创建工作。根据北京市文化局《北京市文化社区指导标准细则（试行）》（附件3）的内容和要求，推进实施。通过创建做到群众性文明创建活动蓬勃开展，居民文明素质不断提升；社区教育普及深入，学习型社区建设成效显著；社区文化生活丰富多彩，社区的凝聚力、创造力不断增强。

四、时间安排

创建完成时间为2012年11月中旬，分为以下三个阶段进行：

第一阶段：工作部署阶段（4月—5月）

根据北京市文化局关于创建基本公共文化服务全覆盖试点和城市“六型社区”示范单位的要求，制定创建工作方案。

第二阶段：全面实施阶段（6月—9月）

各单位根据创建工作方案对创建社区进行对照检查，逐项抓好落实，确保创建工作扎实有效开展。

第三阶段：总结验收阶段（10月—11月）

各单位在做好创建档案资料、相关数据收集整理工作基础上，对创建工作进行全面总结，挖掘先进典型，进行经验推广，巩固创建成果。

五、工作要求

（一）提高认识，加强领导。创建工作是加强社会主义文化建设的一项重要内容，关系社会稳定与发展大局，各单位领导要高度重视，充分认识做好创建工作的重要性、紧迫性，切实把创建工作作为重要工作摆上议事日程，要成立创建工作领导小组，主管领导负总责，主管科室领导亲自抓。

（二）明确责任，精心组织。各单位要根据创建工作方案，结合本地区实际，制定具体的创建工作计划和实施方案，细化分工，明确职责，按照要求狠抓落实。在创建工作中要树立创新意识、服务意识，密切联系群众，听取群众的意见建议，确保创建工作取得显著成效。

（三）做好宣传，营造氛围。各单位要利用多种形式，向社会公布创建社区，接受公众监督和社区居民评议。要把为社区居民服务，满足广大群众多样化、多层次的文化需求作为创建工作的出发点和落脚点，确保社区居民充分享受到文化发展的成果，使他们切实感受到党和政府的关怀和温暖。
