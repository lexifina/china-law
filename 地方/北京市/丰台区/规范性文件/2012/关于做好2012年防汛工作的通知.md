# 关于做好2012年防汛工作的通知

教委所属各单位：

2012年是党的十八大召开之年，也是实施“十二五”规划承上启下的重要一年，为切实做好2012年全系统防汛工作，确保我系统师生生命安全和正常的教学秩序，根据区防汛指挥部《关于做好二〇一二年度防汛各项准备工作的通知》（京丰汛办〔2012〕3号）要求，针对极端天气逐年增多，我区普教系统人员相对集中、单位分散，且女同志多、未成年人多的特点，为切实做好2012年迎汛、度汛工作，确保我系统师生人身和财产安全，现将有关安排通知如下：

一、防汛安全工作的指导思想和工作目标

指导思想：以“三个代表”重要思想和科学发展观为指导，关注民生，时刻牢记群众利益无小事，以构建预防为主的长效管理与应急处理机制为根本，最大限度地保障全系统广大师生的生命和财产安全，努力将损失降至最低点，确保教育系统内部安全与稳定。

工作目标：思想重视、认真准备；落实责任、消除隐患；减少损失、确保安全。

三、任务分解

1.教委防汛办公室负责对防汛指示的上传与下达，及时处理一切与防汛有关的日常工作，对各基层单位的防汛工作负有宣传、教育、指导、监督、检查的责任。对各单位上报的安全隐患及时组织力量进行复查，尽快排除隐患，确保师生人身及财产安全。

2.教委基建科主要负责我系统新建工程的防汛防雨工作，确保在施新建工程的安全度汛。

3.教育发展服务中心主要负责基层校办企业用房的安全与管理，负起监督检查的责任。在生产工作中，坚持安全第一，对存在安全隐患的房屋要果断处理，坚决停用。

4.教委装备处主要负责督促各单位做好汛期教育教学装备、化学药品等物品的保管工作。

5.教委车队负责做好汛期特殊情况下，人员运输、物资调运等交通保障工作的准备。

6.教委房管所作为我系统防汛的主要职责部门，除做好防汛办公室的工作外，还要做好汛期的值班、抢险队伍和物资的准备工作，在遇有汛情时要果断处置，并及时派出抢险队伍抢修。

7.学校成立以校长为组长的防汛领导小组，负责学校师生和财产安全，遇有紧急情况及时处理和上报。

四、工作要求

1.加强领导，强化责任。各单位要建立健全防汛组织机构，切实加强领导、精心组织，继续坚持法人代表是第一责任人和“谁主管、谁主责”的原则。单位领导要与责任人签订责任书，明确保障重点、安全标准、责任范围、保障措施等内容，把责任制落实到岗、落实到人，实现“无缝隙、无死角”的安全责任体系，切实保证我系统安全度汛。

2.及时排查，消除隐患。各单位接此通知后要在前期隐患排查的基础上再次组织力量对本单位的校舍（包括出租房屋）、电路、围墙、排水、燃气系统、避雷设施、地下人防等进行一次全面细致的检查与维护，特别是要对平房校舍进行重点检查，清除楼顶上的杂物。各单位在排查过程中，必须做到“一个亲自”“三个不放过”，即重点部位防汛责任人要亲自带队到现场检查，防汛责任人不落实的不能放过，存在防汛安全问题和隐患没查清的不放过，防汛安全措施、应急设施没落实的不放过，做到100%到位。对检查出的问题，学校要采取措施，抓紧整改，明确负责人，并且及时反馈到教委防汛办公室。

教委防汛办公室在遇中雨以上雨情或连阴雨时，要安排成员在教委房管所值班待命；遇有大到暴雨时，教委防汛办公室50%成员要在教委房管所值班，抢险队到达指定地点待命；遇有特大暴雨时，教委防汛办公室全部成员要在教委房管所值班，抢险队到达指定地点待命。

汛期，教委防汛办公室将会同保卫科组织人员对汛期值班情况进行检查。
