# 花乡2012年领取社会保险（障）待遇人员资格认证工作实施方案

为进一步规范领取社会保险（障）人员的管理，维护社保基金和财政专项基金安全，根据市区有关文件精神和工作部署，制定花乡2012年领取社会保险（障）待遇人员资格认证工作实施方案。

一、 工作要求

各单位要严格按照《关于做好2012年度领取社会保险（障）待遇资格认证信息准备等业务工作问题的通知》（京社保发【2012】18号）、《关于开展2012年度领取社会保险（障）待遇资格认证工作有关问题的通知》（丰人社发【2012】69号）的文件要求，充分认识此次生存认证工作的重要性，落实管理责任，采取多种形式广泛宣传，加强信息沟通和反馈，在规定时限内确保认证工作顺利进行，避免死亡人员通过认证情况的发生。

二、 认证时间、范围、地点

时间：自2012年4月1日至2012年7月15日止。

范围：凡2011年12月31 日前领取社会保险（障）待遇的下列人员均须参加2012年度待遇领取资格认证：

（一）按月领取基本养老金的离退休人员；

（二）按月领取伤残津贴、护理费的工伤职工；

（三）按月领取供养亲属抚恤金的工亡职工的供养亲属；

（四）按月领取城乡居民养老金的人员；

（五）按月领取城乡无社会保障老年居民养老保障待遇（福利养老金）的人员。

地点：基层单位劳动服务站、专业公司及直属单位办理待遇领取资格认证手续。

三、实施步骤和方法

认证实施阶段：2012年4月1日至7月15日

1、补认证工作。

自2012年3月20日起，停止办理2010-2011年度待遇领取资格补认证工作。凡未办理补认证的领取待遇人员自2012年4月1日起参加2012年度的待遇领取资格认证。

2、2012年认证工作和流程。

（1）居住在本市的领取待遇人员

本人认证：在规定时间内，须携带《社会保障卡》，因故暂时没有领到《社会保障卡》的，需携带《居民身份证》，到村委会、专业公司及直属单位进行待遇领取资格认证。

代理认证：因生病长期住院（含居家治疗）或行动不便的，可由其亲属代为办理待遇领取资格认证，届时应提供委托人的《社会保障卡》或《居民身份证》和代理人的《居民身份证》，同时填写《北京市领取社会保险（障）待遇人员资格认证代理表》。

（2）异地居住领取待遇人员

由所在单位在2012年4月30日前将《北京市领取社会保险（障）待遇人员异地居住资格认证表》（简称《异地认证表》）邮寄给个人，领取待遇人员也可通过北京市人力资源和社会保障局网站（http：//bjld.gov.cn）下载打印《异地认证表》。于2012年7月5日前将《异地认证表》寄回所在单位，所在单位通过企业版软件进行录入汇总后，于2012年7月10日前将认证的电子信息导出连同打印的《异地认证汇总表》和《异地认证表》一并报送社保中心支付办。

（3）出境定居或国外生活的领取待遇人员

出境定居或国外生活的领取待遇人员于2012年10月31日前，向所在单位提供加盖我国使馆印章的《健在确认书》或领事认证。所在单位于2012年11月20日前，将《健在确认书》或领事认证送交区人保局社保中心支付部。

3、未认证人员的处理办法

（1）对未按期进行待遇领取资格认证的本市居住和未按期邮寄回《异地认证表》的外阜居住领取待遇人员，自2012年8月起暂停支付相关社会保险（障）待遇。

（2）对未按期提供《健在确认书》或领事认证的出境定居或在国外生活的领取待遇人员，自2012年12月起暂停支付相关社会保险（障）待遇。

（3）凡未办理2010-2011年度补认证的领取待遇人员，在进行了2012年度待遇领取资格认证且符合继续领取待遇条件的，自2012年8月起恢复并补发中断期间的相关社会保险（障）待遇。

（4）自2012年8月起，凡未在规定期限内进行认证的领取待遇人员，可到居住地附近的区县社保经办机构或街道（乡镇）社保所办理领取资格补认证手续。凡进行补认证且符合继续领取待遇条件的，原则上于补认证的次月起恢复并补发中断期间的相关社会保险（障）待遇。

四、组织领导

为配合此次领取社会保险待遇人员资格认证工作的开展，同时也为建立长效的生存认证工作机制，成立花乡领取社会保险待遇人员资格认证工作领导小组。办公室设在花乡社保所。
