# 2014年“戏曲进社区（村）”活动方案

2014年我委继续与中国戏曲学院合作，开展“戏曲进社区（村）”活动。通过戏曲知识普及，活跃群众文化生活，传承中华传统文化，巩固我区戏曲文化品牌。为使此项活动能够更好的满足群众需求，提高实效性，我委根据各街乡镇对活动的建议，结合不同需求定制课程并安排有针对性的票房指导，以积极推动文化惠民项目与群众文化需求有效对接。

一、组织机构

成立活动领导小组。区文委主任担任组长，区文委主管副主任及各街乡镇主管领导担任副组长，成员由文委文化科科长、各街道文教科科长及各乡镇文化站站长组成。

下设活动办公室。办公室设在区文委文化科，联系人：寇京亚，联系电话：83811363（已失效），邮箱：ftwwwhk@163.com。中国戏曲学院联系人：徐璟，[电话略]（已失效）；刘振芳，[电话略]。

二、活动时间

2014年3月--10月

三、活动安排

活动内容按照层次、类别、形式、人群的不同，设置戏曲知识讲座、票房剧目指导、戏曲身段培训、成果集中展示四大部分。

（一）戏曲知识讲座

1.时间：3月--10月，每周二--周五安排教师讲座；

2.地点：各街乡镇指定的地点；

3.课时：根据各街乡镇选课情况，本次讲座在21个街乡镇共安排88次，每次讲座时长120分钟；

4.课程：《戏曲艺术的传统与时尚》、《戏曲表演美学》、《戏曲艺术常识》、《戏曲演奏》、《戏曲锣鼓经》、《戏曲流派艺术》、《戏曲服饰艺术》、《戏曲化妆造型艺术》、《戏曲身段与程式动作》、《戏曲名段赏析》等多门课程。

（二）票房指导

1.时间：3月--8月，根据各票房的活动时间，安排授课时间；

2.地点：各票房活动地点；

3.课时：根据各街乡镇统计情况，对我区现有43个票房进行指导。每个票房平均指导3次，全区共129次，每次120分钟；

4.内容：根据各票房的实际需求，有针对性地进行唱腔及表演等专业辅导。

（三）戏曲身段培训

1.时间：4月--10月；

2.地点：中国戏曲学院；

3.课时：每次120分钟，共24次；

4.内容：在全区范围内征集戏曲身段培训学员，教授戏曲健身操中的两套，即《戏曲折扇组合》、《戏曲水袖组合》。

（四）成果集中展示

计划以联谊会的形式举办中秋戏曲票友联谊会或者迎国庆的戏曲票友联谊会，将各票房的优秀节目组合，组成一台戏曲文艺演出。计划于9月或10月进行。

预计节目由6至8个票房组成，选定票房将另行给予2次专业指导。

四、工作职责

（一）区文委

1.负责制定活动总体方案并统筹协调；

2.负责与中国戏曲学院洽谈合作协议，并签订协议书；

3.负责与区财政局沟通，申请专项经费，确保活动开展；

4.负责监督中国戏曲学院对整体活动的执行情况。

（二）中国戏曲学院

1.制定详细活动计划并组织实施，确保任务质量；

2.管理并监督各项任务落实情况，填报《活动登记表》；

3.做好与各街乡镇和各票房的工作对接，确保活动按计划完成；

4.收集、留存活动全过程的影像资料，全年活动结束后形成书面总结。

（三）各街乡镇

1.按照本方案的具体安排组织落实各项任务，对接好需求，安排好场地，组织好人员；

2.加强对活动的管理，确保活动的实效与安全；

3.及时对活动情况进行反馈。
