# 丰台区区域内临时占地费指导标准实施细则

各相关单位：

鉴于我区临时占地费标准沿用多年且相对偏低，根据《中华人民共和国土地管理法》第五十七条的规定及周边区域调研结果，结合本区实际，制定本细则。

一、指导标准  丰台区临时占地费指导标准为 9万元 / 亩 / 年，临时使用土地期限一般不超过二年。

二、适用范围

丰台区区域范围内，因建设施工项目或地质勘查等工作需要临时使用土地的，项目主体与原土地方依据《中华人民共和国土地管理法》的规定，并参照本细则确定的指导标准协商订立临时土地使用合同。

三、指导标准实施时点

实施时点为本文印发之日起。
