# 丰台区卫生和计划生育委员会档案安全管理措施和应急预案

为迅速、有效地处置安全突发事件，并尽早予以防范，确保卫生系统档案资料安全，特别是在易发生大范围洪涝灾害的天气条件下，如何保证档案安全的渡过汛期，根据《国家档案局办公室关于加强汛期档案安全保管的紧急通知》（档电〔2012〕6号文件）文件精神，结合我区卫生计生系统档案管理实际，区卫生计生委制定本预案。

一、适用范围

本预案适用于全区直属各医疗卫生机构，在正常情况下适用安全管理措施，预防为主保障档案安全；遇到汛情启动应急预案。

二、档案防汛应急领导小组

为加强对防汛工作的领导，保证全区卫生系统档案安全度过汛期，区卫计委成立档案防汛工作领导小组，档案的安全度汛由档案防汛工作领导小组领导。领导小组下设办公室，办公室设在委办公室。由办公室及时收集天气预报、防汛信息，并通知全区各医疗卫生机构。

丰台区卫生计生系统档案防汛领导小组办公室：

主任：刘婉莹区卫生计生委副书记、副主任、调研员

副主任：丁欣刚区卫生计生委办公室主任

组员：薛峰区卫生计生委办公室科员

三、档案防汛安全管理要求

各医疗卫生单位要牢固树立档案安全意识，坚持以人为本、预防为主原则，克服麻痹思想，采取切实可行的汛期档案安全预防措施。

一是对档案库房进行一次全面细致的安全检查，发现不安全因素立即进行整改，及时采取措施，坚决消除事故隐患，确保档案安全度汛。

二是为更好的防范雨水倒灌进库，对档案室处于低洼地势的单位，必须在库房门内侧加固一个高40公分左右的防水台，作为防汛应急隔离台。

三是对现存档案进行一次全面清查，确定档案的存放位置和数量，做到底数清，存放位置明，以便应对紧急情况下准确、有序的转运。

四是建立汛期档案安全预警制度，成立档案汛期应急工作领导小组，安排专人24小时巡查，并与本单位值班室保持24小时通讯畅通，在汛期如有雨水倒灌，危及档案安全的情况，由本单位值班人员及时通知本行政负责人，迅速应急处理。

四、汛期应急抢险

当汛情发生时，立即起动应急预案。本单位档案应急工作领导小组及工作人员迅速到达档案存放地，迅速开展抢险工作，并将汛情及时报告区卫生计生委办公室。

五、汛期应急保障

一是确定一个临时档案库。为确保汛期应急情况下档案能及时转运，且有较安全的临时存放地。

二是加强汛期档案安全应急队伍建设，开展应急演练工作。要结合本单位实际建立和及时调整汛期档案安全应急队伍，按照本预案要求定期组织实战演练，增强应急意识，提高应对能力，确保应急时期本单位档案安全。
