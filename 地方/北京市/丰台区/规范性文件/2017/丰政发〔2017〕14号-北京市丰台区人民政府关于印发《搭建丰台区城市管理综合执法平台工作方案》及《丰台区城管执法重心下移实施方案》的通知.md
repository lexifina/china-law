# 北京市丰台区人民政府关于印发《搭建丰台区城市管理综合执法平台工作方案》及《丰台区城管执法重心下移实施方案》的通知

各街道办事处、乡镇政府，区政府各委、办、局，各区属机构：

经第18次区政府常务会审议通过，现将《搭建丰台区城市管理综合执法平台工作方案》及《丰台区城管执法重心下移实施方案》印发给你们，请认真贯彻执行。

北京市丰台区人民政府

2017年11月23日
