# 北京市丰台区人民政府关于发布公共服务事项目录和办事指南的通告

各街道办事处、乡镇政府，区政府各委、办、局，各区属机构：

为贯彻落实国务院“放管服”改革措施，进一步加强政务服务标准化、规范化建设，加快推进政府职能转变，根据《北京市人民政府关于加强政务服务体系建设的意见》（京政发〔2016〕62号）、市政府审改办《关于全面推进公共服务事项梳理的通知》（京审改办函〔2016〕13号）、《关于继续做好区、乡镇（街道）和村（社区）公共服务事项梳理工作的通知》（京政服发〔2017〕7号）精神，全区各相关单位坚持依法依规、便民利民、统一规范的原则对公共服务事项进行梳理，形成区、乡镇（街道）、村（社区）三级公共服务事项目录和办事指南，现通过北京市丰台区人民政府网站予以公开。

特此通告。

北京市丰台区人民政府

2017年12月20日
