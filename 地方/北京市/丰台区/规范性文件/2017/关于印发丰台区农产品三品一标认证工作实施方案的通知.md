# 关于印发丰台区农产品三品一标认证工作实施方案的通知

为落实市、区农村工作会议精神，健全农产品质量安全监管体系和检验检测体系，推进农产品生产标准化，做好我区无公害农产品、绿色食品、有机食品、农产品地理标志（以下简称“ 三品一标”）认证及监管工作，结合我区实际，制定本实施方案。

一、指导思想

坚持政府引导和鼓励相结合的原则，推动“三品一标”认证工作。以打造北京“安全农业” 品牌为导向，贯彻创新、协调、绿色、开放、共享发展理念，全面推进农业标准化、品牌化和产业化经营，确保安全优质农产品供给，提高农产品市场竞争力，促进标准化生产、标识化流通、规范化管理、健康化消费，着力提升全区农产品质量安全水平。

二、认证资格

（一）无公害农产品

1.农产品的产地环境应符合相应无公害农产品产地环境要求，达到规定的用水、土壤、空气的质量指标，符合相应的产地环境国家标准。

2.制定并执行农产品的生产技术规程和农产品质量安全控制措施。

3.农产品的安全质量应符合相应的国家标准要求，达到规定的农产品的重金属及有害物质限量和农药最大残留限量。

（二）绿色食品

1.必须出自优良生态环境，即产地经监测，其土壤、大气、水质符合《绿色食品产地环境技术条件》要求。

2.生产过程必须严格执行绿色食品生产技术标准。

3.产品必须经绿色食品定点监测机构检验，其感官、理化(重金属、农药残留、兽药残留等)和微生物学指标符合绿色食品产品标准。

4.绿色产品认证由北京市绿色产品认证机构负责，生产主体取得认证的，在乡镇主管部门登记备案，并上报区农委备案。

（三）有机食品

1.在生产和加工过程中必须严格遵循有机食品生产、采集、加工、包装、贮藏、运输标准，禁止使用化学合成的农药、化肥、激素、抗生素、食品添加剂等，禁止使用基因工程技术及该技术的产物及其衍生物。

2.生产和加工过程中必须建立严格的质量管理体系、生产过程控制体系和追踪体系。

3.必须通过具备合格资质认证机构认证，生产主体取得认证的，在乡镇主管部门登记备案，并上报区农委备案。

（四）农产品地理标志

地理标志农产品由区级主管部门初步审核，按照认证程序要求，报送上级主管部门开展认证工作。认证产品必须符合相关具体规范要求。

三、奖励范围、标准及程序

（一）奖励范围

在本区注册登记，从事农产品生产、加工、经营、管理的企事业单位、农村经济合作组织。

（二）奖励标准

1.对首次获得无公害农产品认证主体，给予一次性奖励资金3万元，首次认证三个品种以上的（含三个品种），给予一次奖励资金5万元。每增加一个产品，认证产量3000公斤以上的奖励1万元，认证产量3000公斤以下的奖励5000元。

2.对首次获得绿色食品认证主体，给予一次性奖励资金5万元。每增加一个产品，奖励1万元。

3.对首次获得有机食品认证主体，给予一次性奖励资金6万元。每增加一个产品，奖励2万元。

4.对首次获得地理标志农产品认证主体，给予一次性奖励8万元。

5.对连续保持国家“无公害农产品、绿色食品、有机农产品”复查换证的认证主体，当年给予生产企业奖励资金3万元。

6.对于同一生产企业，一年内获得两种以上的认证主体，按照其中认证最高的奖励标准对一个认证进行奖励。

7.有下列情况之一的，不被列入奖励范围。监管部门日常检查、抽检出现产品不合格并未及时整改的；不接受日常检查、抽检的；在相关认证过程中未达到规范要求的；日常管理未达到相关生产要求的；没有稳固的生产基地的；当年发生过农产品质量安全问题的。

（三）奖励程序

取得“ 三品一标”认证，符合奖励条件的，由认证主体于每年5月底前向乡镇政府主管部门提出申请。乡镇政府农业主管部门于 15个工作日内组织实地考察并提出审核意见，经本级政府同意后报送区农委审核，奖励资金按照区财政相关要求统一发放。

四、工作要求

（一）加强领导，落实措施

各乡镇政府“三品一标”认证工作部门要从提高农业综合生产能力和增加农民收入的大局出发，以科学发展观统领“三品一标”认证发展，将其纳入到镇域农业和农村经济工作的重要议事日程，确保各项措施落到实处，认真将工作抓紧、抓实、抓出成效。

（二）强化责任，建立激励机制

对乡镇域内的企业进行认真细致的摸底，有一定规模的农产品基地都要纳入申报范围。已经取得产品认证的基地，鼓励企业增加认证品种，提高认证产量，力争实现认证主体生产的主要产品100%开展认证。

（三）加强沟通，积极申报

各乡镇主管部门要及时与区农委沟通，及时将摸排的情况上报，并将符合条件需要申报无公害农产品、绿色食品、有机食品的企业名单及联系方式报区农委。
