# 关于印发丰台区卫生计生委安全生产大检查实施方案的通知

区域内各医疗卫生机构：

为做好丰台区卫生计生系统安全生产工作，根据《丰台区安全生产委员会关于开展安全生产大检查的通知》（丰安发〔2017〕5号）要求，结合我系统实际制定了《丰台区卫生计生委安全生产大检查实施方案》，现印发给你们。请各单位严格落实《方案》要求，切实做好本单位安全生产各项工作，保障卫生计生系统安全稳定，确保党的十九大胜利召开。

丰台区卫生计生委

2017年8月3日
