# 关于转发《北京市安全生产监督管理局北京煤矿安全监察局关于对从事安全生产工作二十年以上人员颁发荣誉证书的意见》的通知

关于转发《北京市安全生产监督管理局北京煤

矿安全监察局关于对从事安全生产工作二十年

以上人员颁发荣誉证书的意见》的通知

区域内各卫生计生单位：

现将《北京市安全生产监督管理局北京煤矿安全监察局关于对从事安全生产工作二十年以上人员颁发荣誉证书的意见》（京安监发〔2017〕14号）转发给你们，请各单位对符合条件的人员进行推荐，于5月18日下午16:00前，先将人员名单报至区安监局办公室外网邮箱ftajj@163.com；5月23日前，将《从事安全生产工作二十年以上人员登记表》，由本人签字，加盖单位公章，一式两份送至区安监局207室。

丰台区卫生计生委

2017年5月17日
