# 关于转发北京市丰台区人民政府办公室丰台区加强高风险电梯综合整治工作的通知

区域内各卫生计生单位：

为消除电梯安全隐患，保障电梯运行安全，现将《北京市丰台区人民政府办公室丰台区加强高风险电梯综合整治工作的通知》（丰政办发〔2017〕22号）转发给你们，请各单位重视此项工作，汇报本单位领导。整改台账中需整改的单位请尽快落实改造工作，不在台账中的单位开展电梯自查工作。每月24日前，台账中需整改的单位将高风险电梯治理完成情况统计表（22号文附件2）发送至wsjxzkaq@163.com。

丰台区卫生计生委

2017年5月12日
