# 关于转发北京市丰台区人民政府办公室加强“一带一路”国际合作高峰论坛消防安全管控措施的通知

区域内各卫生计生单位：

5月14、15日，“一带一路”国际合作高峰论坛将在北京举行，为做好峰会期间消防安全工作，现将《北京市丰台区人民政府办公室关于加强“一带一路”国际合作高峰论坛消防安全管控措施的通知》（丰政办发〔2017〕24号）转发给你们，各单位严格落实文件精神，切实加强高峰论坛消防安全管控工作。

附件：北京市丰台区防火安全委员会办公室关于进一步做好“一带一路”国际合作高峰论坛消防安全管控措施工作的通知

丰台区卫生计生委

2017年5月12日
