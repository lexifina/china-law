# 关于转发北京市丰台区人民政府防汛指挥部办公室2017年防汛预警响应机制的通知

区域内各卫生计生单位：

2017年汛期即将来临，为确保丰台区卫生计生系统安全度汛，现将《北京市丰台区人民政府指挥部办公室关于印发丰台区2017年防汛预警响应机制的通知》（京丰汛办〔2017〕12号）和《北京市丰台区人民政府防汛指挥办公室关于2017年6月1日全区上汛的通知》（京丰汛办〔2017〕13号）转发给你们，请各单位结合当前市区工作要求，做好以下工作：

一、各单位及时制定完善本单位防汛计划和应急预案，加强应急演练。

二、各单位做好各项防汛物资的储备工作。

三、做好本单位区域内房屋自查及直属家属院房屋自查，有易积水低洼院落，全面做好排水，确保房屋安全。

四、做好日常防汛巡视，有普通地下室的单位加强日常巡查检查，防止雨水倒灌。

五、各单位加强应急值班，加强领导带班，汛情预警期间确保通讯畅通，做好重点部位抢险各项准备。

丰台区卫生计生委

2017年6月5日
