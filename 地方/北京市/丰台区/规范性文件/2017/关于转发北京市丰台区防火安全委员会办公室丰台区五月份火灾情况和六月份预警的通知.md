# 关于转发北京市丰台区防火安全委员会办公室丰台区五月份火灾情况和六月份预警的通知

区域内各卫生计生单位：

现将北京市丰台区防火安全委员会办公室《关于丰台区五月份火灾情况和六月份预警的通知》（丰防安办字〔2017〕26号）转发给你们，请紧密结合单位实际，严肃认真做好六月份及夏季火灾防控工作。

要牢固树立预防为主的思想，认真排查整治各种火灾隐患；要加强对各种可燃、易燃物的清理，始终把电气火灾防控摆在突出位置；要加强火灾防控业务培训，全面提高应急处置能力；要加强消防安全基础设施建设，确保中控室、灭火器等消防设施设备的完好率、可操作率，确保消防疏散、应急通道畅通；要加强同当地公安消防机关的沟通协作，不断建立完善消防安全网络。切实有效地加强消防安全工作。

丰台区卫生计生委

2017年6月12日
