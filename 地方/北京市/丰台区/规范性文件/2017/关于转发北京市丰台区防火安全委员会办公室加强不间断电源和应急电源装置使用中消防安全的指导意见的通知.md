# 关于转发北京市丰台区防火安全委员会办公室加强不间断电源和应急电源装置使用中消防安全的指导意见的通知

区域内各卫生计生单位：

为保障“一带一路”国际合作高峰论坛的顺利举行，现将北京市丰台区防火安全委员会办公室《关于加强不间断电源和应急电源装置使用中消防安全的指导意见的通知》（丰防安办字〔2017〕16号）转发给你们，请各单位加强不间断电源管理，严格按照通知要求对本单位的不间断电源和应急电源隐患进行排查摸底，建立台账，并及时解决存在的安全隐患。

丰台区卫生计生委

2017年5月3日
