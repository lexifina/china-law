# 关于转发北京市丰台区防火安全委员会办公室市防火委办公室党的十九大安保期间加强城市地下空间等六类场所消防安全严防严控工作的通知

关于转发北京市丰台区防火安全委员会办公室

市防火委办公室党的十九大安保期间

加强城市地下空间等六类场所

消防安全严防严控工作的通知

区域内各卫生计生单位：

中国共产党第十九次全国代表大会18日上午隆重开幕。为做好会议期间丰台区卫生计生系统消防安全工作，现将北京市丰台区防火安全委员会办公室转发市防火委办公室《关于党的十九大安全保期间加强城市地下空间等六类场所消防安全严防严控工作的通知》（丰防安办字〔2017〕61号）转发给你们，请各单位高度重视，结合我委之前下发的党的十九大消防工作文件精神，认真落实。确保党的十九大期间丰台区卫生计生系统安全稳定。

附件1：北京市丰台区防火安全委员会办公室转发市防火委办公室关于党的十九大安保期间加强社会福利机构消防安全严防严控工作的通知

附件2：北京市丰台区防火安全委员会办公室关于启动党的十九大消防安保社会面网格化火灾防控实体化运行工作模式的通知
