# 关于转发北京市丰台区防火安全委员会深入推进区属部门单位内部彩钢板房建筑清理拆除工作的通知

关于转发北京市丰台区防火安全委员会

深入推进区属部门单位内部彩钢板房建筑

清理拆除工作的通知

各直属单位：

为进一步推进丰台区卫生计生系统单位内部彩钢板建筑拆除工作，现将北京市丰台区防火安全委员会《关于深入推进区属部门单位内部彩钢板建筑清理拆除工作的通知》转发给你们，请各单位重视此项工作，按照前期会议部署时限抓紧拆除，如实填写区属部门单位内部彩钢板建筑明细台账（附件1），如拆除工作有困难务必写出书面报告，于8月31日16:00前上报至wsjxzkaq@163.com。

注：表格只填写全彩钢板建筑拆除情况，不涉及仅屋顶为彩钢板的建筑。

丰台区卫生计生委

2017年8月31日
