# 关于转发北京市迎接党的十九大消防安保动员部署电视电话会议领导讲话的通知

区域内各卫生计生单位：

现将《北京市丰台区防火安全委员会办公室关于转发北京市迎接党的十九大消防安保动员部署电视电话会议领导讲话的通知》（丰防安办字〔2017〕47号）转发给你们，请各单位高度重视，认真组织学习领导讲话，结合我委9月19日会议和培训会议相关内容落实安全生产各项工作，为党的十九大胜利召开创造良好的消防安全环境。

丰台区卫生计生委
