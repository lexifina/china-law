# 关于转发北京市防火安全委员会《消防安全网格化管理工作指导手册（试行）》的通知

区域内各卫生计生单位：

现将北京市防火安全委员会关于印发《消防安全网格化管理工作指导手册（试行）的通知》（丰防安字〔2017〕18号）转发给你们，请紧密结合各单位实际情况，全面落实消防安全主体责任。要认真制定消防安全制度、消防安全操作规程、灭火和应急疏散预案并定期组织开展训练、演练，要高度重视消防设施，器材、消防安全标志配备工作并保证完好有效。要确保疏散通道、安全出口、消防车通道畅通，要定期组织防火检查和消防安全培训教育，按照消防安全标准化管理的要求，稳步开展“四个能力”达标建设。要特别注重人员密集场所，易燃易爆场所和高层、地下公共建筑、电气设施、电梯等火灾高危点位管控，要强化主体责任，坚决避免火灾事故发生。

丰台区卫生计生委

2017年5月3日
