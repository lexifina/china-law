# 关于转发北京市防火安全委员会办公室深刻吸取近期火灾事故教训进一步加强火灾防控工作的通知

关于转发北京市防火安全委员会办公室

深刻吸取近期火灾事故教训进一步

加强火灾防控工作的通知

区域内各卫生计生单位：

现将北京市防火安全委员会办公室《关于深刻吸取近期火灾事故教训进一步加强火灾防控工作动的通知》（防安办字〔2017〕32号）转发给你们，请各单位严格落实通知要求，做好以下工作：

1.认真学习市防火委《通知》，紧密结合自身实际，梳理危险源、防火点，立即开展有针对性排查整治。

2.强化责任意识，坚持以上率下，层层落实消防工作责任

3.加强日常消防安全管理，规范用火用电用气行为，要紧盯重点部位、重点环节，加强对火灾的防控。

4.加强消防安全应急训练演练，提高处置能力。

丰台区卫生计生委

2017年7月7日
