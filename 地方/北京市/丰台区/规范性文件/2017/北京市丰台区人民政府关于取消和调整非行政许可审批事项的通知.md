# 北京市丰台区人民政府关于取消和调整非行政许可审批事项的通知

各街道办事处、乡镇政府，区政府各委、办、局，各区属机构：

为贯彻落实市政府《关于取消调整一批行政审批事项的通知》（京政发〔2015〕63号）、《关于取消和调整一批非行政许可审批事项的通知》（京政发〔2017〕5号）和市政府审改办《关于区级实施非行政许可审批事项有关事项的通知》（京审改办函〔2015〕75号）精神，决定取消和调整我区71项非行政许可行政审批事项，现将有关事项通知如下：

一、取消和调整71项非行政许可审批事项。其中7项非行政许可审批事项予以取消或划转；9项非行政许可审批事项调整为政府内部审批事项；27项非行政许可审批事项并入区政府部门权力清单原有事项；28项非行政许可审批事项调整为25项区政府部门权力清单事项。今后不再保留“非行政许可审批事项”这一审批类别。

二、各相关部门要做好非行政许可审批事项取消和调整的落实与衔接工作，对取消的非行政许可审批事项，不得以任何形式搞变相审批，同时要加强事中事后监管，防止出现管理真空。对调整为政府内部审批的事项，审批部门不得面向公民、法人和其他社会组织实施审批，同时要明确审批的权限、范围、条件、程序、时限等，规范审批行为，严格限制自由裁量权。对调整为行政许可、行政确认、其他职权的事项，要纳入区政府部门权力清单，切实加强规范管理，并及时在区政府网站和各相关部门网站上予以相应调整。
