# 北京市丰台区卫生计生委关于印发《北京市丰台区卫生和计划生育委员会政府购买服务指导性目录》的通知

各直属单位，委机关各科室：

根据区财政局关于做好政府购买服务指导性目录编制管理工作的通知要求，为进一步规范我委政府购买服务工作，我委编制了《北京市丰台区卫生和计划生育委员会政府购买服务指导性目录》,已经区财政局确认，现予印发，请遵照执行。

附件：北京市丰台区卫生和计划生育会员会政府购买服务指导性目录

丰台区卫生计生委
