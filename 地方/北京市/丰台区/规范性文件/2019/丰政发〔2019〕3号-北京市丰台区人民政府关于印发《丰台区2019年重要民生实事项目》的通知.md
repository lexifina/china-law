# 北京市丰台区人民政府关于印发《丰台区2019年重要民生实事项目》的通知

各街道办事处、乡镇政府，区政府各委、办、局，各区属机构：

《丰台区2019年重要民生实事项目》已经区政府常务会、区委常委会、区人大常委会审议通过，现印发给你们。各街道乡镇、各有关部门和单位要高度重视，严格按照责任分工，制定详实的工作落实预案，早安排、早部署，确保优质高效完成各项任务，切实将实事做实、办好，不断增强人民群众获得感、幸福感、安全感。

北京市丰台区人民政府

2019年3月28日
