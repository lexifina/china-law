# 关于印发《中共丰台区委社会工委、丰台区民政局政府购买服务指导性目录》的通知

委局各科室、所属事业单位：

为加快推进政府购买服务改革，保证政府购买服务工作与机构改革的有效衔接，进一步规范委局政府购买服务工作，根据《丰台区区级政府购买服务指导性目录编制工作方案》的要求，结合工作实际，编制了《中共北京市丰台区社会工作委员会政府购买服务指导性目录》，现印发给你们，请遵照执行。

附件：中共丰台区委社会工委、丰台区民政局政府购买服务指导性目录
