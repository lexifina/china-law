# 关于印发《丰台区联合惩戒案例归集和信息共享工作实施办法》的通知

各街乡镇，区政府各委、办、局，各区属机构：

为贯彻落实《国务院关于建立完善守信联合激励和失信联合惩戒制度加快推进社会诚信建设的指导意见》（国发〔2016〕33号）、《国家发展改革委办公厅关于做好联合惩戒案例归集和信息共享工作的通知》（发改办财金〔2018〕475号）、《北京市人民政府关于建立完善信用联合奖惩制度加快推进诚信建设的实施意见》（京政发〔2017〕15号）等文件要求，促进丰台区联合惩戒案例归集、公示和共享，全面反映区联合奖惩措施的实施成效，特制定本办法，现印发给你们，请认真贯彻落实。附件：《丰台区联合惩戒案例归集和信息共享工作实施办法》

丰台区社会信用体系建设联席会议办公室（代章）
