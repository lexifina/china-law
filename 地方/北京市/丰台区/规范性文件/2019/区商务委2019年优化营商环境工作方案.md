# 区商务委2019年优化营商环境工作方案

为贯彻落实国务院和市区优化营商环境工作部署，根据丰台区工作方案，立足我委工作任务，特制定本方案。

一、工作目标

以9+N政策2.0版落实为主线，加快优化商务领域营商环境，不断提高商务领域企业的满意度，打造稳定、公平、透明、可预期的营商环境。

二、工作机构

成立委优化营商环境工作领导小组，主要领导任组长，班子其他成员为副组长，各科室负责人为成员，负责组织领导我委优化营商环境工作。下设办公室在外经贸科，由分管领导牵头，负责对外联络及日常工作。

三、工作安排

（一）开展培训宣讲

一是配合市商务局做好中介机构和企业有关跨境贸易便利化政策培训工作，了解我区参加培训情况。（责任科室：外经贸科）

二是做好联系服务企业工作，深入重点企业走访调研，开展内外贸政策宣讲，为企业送上“服务包”。（责任科室：各相关科室）

三是组织窗口工作人员开展提升京津跨境贸易便利化21项政策措施学习，做到熟练掌握，准确解读。（责任科室：外经贸科、政府服务科）

（二）做好宣传报道

一是配合区委宣传部做好我委优化营商环境宣传，利用我委微信公众号及新媒体平台，进行广泛宣传。（责任科室：综合科）

二是启动营商环境信息日报制度，每日将我委政策培训、宣传、落实、自查、问题整改等工作信息报送至区发展改革委。（责任科室：综合科）

（三）开展自查整改

一是开展自查，对发现的问题要立行立改。（责任科室：各相关科室）

二是开展9+N政策2.0版落实情况自查。（责任科室：外经贸科）

四、工作要求

1.高度重视，严格落实。各分管领导及科室负责人要亲自抓优化营商环境工作，加强工作统筹，确保各项工作落实到位。

2.加强督查，强化问责。实行问责制，将优化营商环境工作纳入年底个人考核，对成绩突出的予以表扬，对工作落实不力、推诿扯皮、问题整改不到位的，将严肃追究责任。
