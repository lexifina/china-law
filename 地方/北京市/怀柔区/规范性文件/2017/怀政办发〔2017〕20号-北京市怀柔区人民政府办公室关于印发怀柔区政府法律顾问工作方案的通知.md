# 北京市怀柔区人民政府办公室关于印发怀柔区政府法律顾问工作方案的通知

怀政办发〔2017〕20号

各镇乡人民政府、街道办事处，区政府各委办局，各区属机构：

《怀柔区政府法律顾问工作方案》已经区政府第5次常务会议审议通过，现印发给你们，请认真贯彻执行。

北京市怀柔区人民政府办公室

2017年2月24日

怀柔区政府法律顾问工作方案

为全面贯彻落实市政府《关于加强政府法律顾问工作的意见》（京政发〔2016〕30号），进一步推进政府法律顾问工作，结合本区实际，制定本工作方案。

一、工作目标

镇乡人民政府、街道办事处、区政府各委办局应建立健全以本单位法律人才为主体、吸收专家和律师参与的政府法律顾问队伍，形成区、镇乡街道、委办局组成的政府法律顾问工作联动体系。

二、工作原则

（一）全面覆盖。镇乡人民政府、街道办事处、区政府各委办局应当按照政府法律顾问工作总体目标要求，结合本部门实际，建立健全政府法律顾问机构和队伍，全面加强政府法律顾问工作。

（二）注重实效。镇乡人民政府、街道办事处、区政府各委办局应当按照政府法律顾问工作总体目标要求，建立健全相关工作机制，完善工作规则和配套措施，为政府法律顾问履职提供有力保障。

三、实施范围和经费保障

（一）实施范围

各镇乡人民政府，街道办事处，区政府各委办局。

（二）经费保障

各单位推行政府法律顾问工作所需经费纳入同级财政预算予以保障，聘请的法律顾问可以按照提供法律服务的工作情况给予适当报酬，具体报酬标准及支付方式由双方在合同中约定。

四、重点任务和时间安排

（一）2017年3月底前，区政府法制办完成《怀柔区政府法律顾问工作规则》、《怀柔区政府法律顾问工作方案》的制定及区政府法律顾问聘用工作。

（二）2017年6月底前，各镇乡人民政府、街道办事处、区政府各委办局完成法律顾问制度的建立和本部门法律顾问聘用工作。

五、聘用方式

（一）各镇乡人民政府应当单独聘请法律顾问。

（二）龙山街道、泉河街道可以联合聘请法律顾问。

（三）区国家保密局、区地震局、区民防局、区气象局、区农机中心、区种植中心与区政府联合聘请法律顾问，除上述单位外，其他部门应当单独聘请法律顾问。

六、工作要求

（一）提高认识，加强组织领导

各单位主要负责人作为推进依法行政的第一责任人，要采取有效措施，加强法律顾问机构和队伍建设，配足配强、选好用好法律顾问，使法律顾问机构和队伍建设与其承担的法律顾问职责和任务相适应，切实发挥好法律顾问的作用。

（二）明确职责，落实责任分工

法律顾问工作纳入区依法行政考核。各单位要明确职责，责任到人。区依法行政办负责全区法律顾问工作的统筹协调、监督指导和区政府外聘专家、律师的日常管理工作。各单位每年7月初和12月初将本单位半年和全年法律顾问工作情况报送区依法行政办。

（三）加大力度，保障资金到位

各单位要采取有力措施，切实加强法律顾问队伍建设，有效保障资金到位，将法律顾问工作所需经费列入本单位财政预算，规范经费使用和管理，确保法律顾问工作顺利开展。
