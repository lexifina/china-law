# 北京市怀柔区人民政府办公室关于印发加强中国（怀柔）影视产业示范区投资服务环境建设工作方案的通知

怀政办发〔2017〕21号

各镇乡人民政府、街道办事处，区政府各委办局，各区属机构：

《关于加强中国（怀柔）影视产业示范区投资服务环境建设的工作方案》已经区政府第5次常务会议审议通过，现印发给你们，请认真贯彻执行。

北京市怀柔区人民政府办公室

2017年2月24日

关于加强中国（怀柔）影视产业示范区投资服务环境建设的工作方案

为落实国家新闻出版广电总局设立中国（怀柔）影视产业示范区的批复要求和北京市建设“全国文化中心”的战略定位，怀柔区正全力推进中国（怀柔）影视产业示范区建设发展，将通过搭建O2O创新创业服务平台（以下简称“双创”平台）和影创空间孵化平台（以下简称影创空间）等产业服务平台，发挥工商、税务等行政管理部门服务经济发展的职能作用，进一步加强示范区投资服务环境建设，不断提升“中国影都”的品牌影响力、竞争力和吸引力。现就做好相关工作提出以下方案：

一、总体目标

围绕建设国家级影视产业示范区的总体目标，深入贯彻落实国家新闻出版广电总局批复要求和市委、市政府关于加快构建首都“高精尖”经济结构的指示精神,进一步加强中国（怀柔）影视产业示范区投资服务环境建设，工商、税务等行政审批部门深入落实“简政放权、放管结合、优化服务”的改革要求，优化审批流程，创新服务方式，提供精准优质服务；区文促中心（影管办）和影都文投公司要发挥政府机构和市场平台的合力，建好公共服务、创客和种子企业的孵化等载体，为影视文化企业、项目和剧组提供更便捷高效的投资和拍摄服务；全力建设北京市和国家影视产业示范区的投资服务、宣传交流窗口，推动影视产业示范区集聚优势，蓬勃发展。

二、具体措施

（一）设立O2O创新创业服务平台

中国（怀柔）影视产业示范区O2O创新创业服务平台，定位于影视产业公共服务平台，突出一站审批、宣传展示和管理服务三大功能，线上集聚影视产业要素搭建网络服务系统，线下统筹整合工商分局、区国税局、区地税局、区文促中心（影管办）等职能机构和影都文投公司，建立从企业注册、建设、运营到影视拍摄、制作、发行的全产业链服务体系。

“双创”平台设在中国（怀柔）影视产业示范区内，由区文促中心（影管办）负责日常运营管理。平台实行开放办公，设置综合服务、行政审批、创业指导、项目协调、剧组服务和宣传推广6个窗口，建立窗口受理、专人负责、一条龙服务的运行机制。其中：行政审批窗口由工商分局、区国税局、区地税局选派工作人员；创业指导窗口由区文促中心（影管办）和影都文投公司共同选派工作人员；其余窗口均由区文促中心（影管办）选派工作人员。

（二）设立工商登记服务分中心

按照市工商局《关于优化准入服务支持服务业扩大开放综合试点的意见》，工商分局在“双创”平台设立影视产业登记分中心，重点服务注册在示范区的影视文化类企业，同时为杨宋、北房两镇的市场主体提供工商政策咨询和登记注册等服务，实现企业登记注册一体化、一条龙服务。

为最大化提供便捷、专业、高效的登记注册服务，工商分局积极协调扩大登记管辖范围，向市工商局申请工商登记授权；放宽示范区内影视及文化创意产业企业的经营范围登记，经营范围除记载主营项目、前置审批项目、“先照后证”项目外，可不登记其他具体经营项目；示范区内从事广播、电视、电影等文化创意产业为主营的企业，经申请住所可使用“中国（怀柔）影视产业示范区”字样，具体表述为“中国（怀柔）影视产业示范区XX路XX号”，主体住所迁出示范区及时变更住所。

（三）设立影视文化产业专业税务所

针对国家税务征管改革和示范区建设发展需求，区地税局研究设立影视文化产业专业税务所，按照行业分类将影视及相关文化创意产业企业划归到该所管理，具体业务包括征收管理、日常检查、纳税服务和风险防控，为影视文化企业提供针对性、专业化、一条龙的税务服务。区国税局要加大影视文化专业税务服务研究，设置自助办税设备和网上办税体验区，加大“互联网+”税务服务，实现影视文化企业网上办理税务登记、发票核定、网上备案、网上领票、签订三方协议、网上申报等涉税服务，形成国地税的税务服务和征管合力。

（四）设立影视企业专业孵化平台

由怀柔区和市文投集团共同出资成立的影都文投公司，定位于示范区建设的市场运营主体和重要的平台运营公司，以市场化、企业化、专业化的方式加快示范区建设发展。影创空间是由影都文投公司投资运营的影视企业专业孵化平台，通过“吸引创客、助推创业、推进创投”，发挥孵化器、加速器、助推器的作用。参照《北京市文化创意产业发展指导目录（2016年版）》，影创空间优先引入影视产业链两端附加值高的影视企业入驻。影都文投公司为入驻企业提供专业化配套服务，搭建企业服务平台、金融服务平台、政策服务平台和物业服务平台。

影创空间作为示范区影视产业专业孵化平台建设运营，按照支持“孵化器”放宽登记条件，允许入驻企业将备案工位登记为企业住所；制定《影创空间入驻企业管理办法》，建立科学合理的准入、管理、退出机制，明确入驻企业的资金、项目、技术、人才等入驻要求，严格监管、适时淘汰。

（五）建立影视剧组服务体系

学习借鉴其他省市影视剧组服务经验，统筹整合区级职能部门服务资源，逐步建立来怀影视剧组的拍摄制作服务体系。“双创”平台的剧组服务窗口作为服务开端，通过剧组服务手册和怀柔影视外景拍摄资源查询系统等媒介，为影视剧组提供外景地、服装化妆道具、拍摄器材、演员经纪等专业资源信息服务，以后逐步拓展提供影视剧组在怀拍摄制作时涉及的各类事项的全流程协调服务。

（六）加快搭建金融、人才、技术服务平台

学习区内外先进经验典型，不断推出更加优越的投资服务措施。下一步要研究搭建影视金融服务平台，建立影视文化企业与银行、担保、基金等金融机构融资的对接渠道，积极培育、创新影视金融产品，依托金融服务平台和影视领军企业，形成示范区影视全产业链金融联合体，加速金融助推产业发展。充分认识北京电影学院怀柔新校区落户和建设的重大意义，围绕示范区“抢占影视技术和影视人才制高点”定位，深入研究，主动对接，强化人才引进、培养和服务，集聚影视专业人才。同时，以市场为导向，引导企业搭建具有公共服务职能的技术服务平台，助力影视产业示范区建设。

三、工作要求

（一）转变理念，创新服务

围绕国家级影视产业示范区建设，创新管理体制机制，转变政府服务理念，深化行政审批“放管服”改革，营造公平便利的市场环境，发挥政府投资引导作用，为影视产业提供一体化、一条龙、一站式的专业服务。鼓励改革创新在示范区的先行先试，积极争取国家、市级政策支持，增强制度和政策创新供给，激发市场活力和社会创造力，推动大众创业、万众创新。加大招商引资力度，以搭建“双创”平台和影创空间为契机，创新投资服务方式，优化产业服务环境，打造怀柔影视产业投资服务品牌。

（二）明确责任，抓好落实

作为影视产业示范区的产业主管部门，区文促中心（影管办）要做好“双创”平台管理和运营工作，认真带头落实好影视剧组服务等各项窗口职责，依托工商、税务、统计等部门基础数据，做好产业和示范区建设数据统计，为领导科学决策提供有力支撑。工商分局要加大对示范区工商政策指导，建好登记服务分中心，优化审批流程，稳步落实工作方案各项具体措施。区地税局要加快设立影视产业专业税务所，区国税局要进一步梳理下放审批管理权限，提供专业化的影视税务征管服务。影创空间运营单位要加大招商引资力度，按照管理办法筛选入驻企业，搭建影视金融投资平台，提供专业高效的配套服务。

（三）加强领导，强化协作

建立高效联动协调机制，完善区级文化创意产业领导小组，积极对接市相关委办局，推动市、区两级产业扶持政策出台，研究用好市区级影视产业促进政策。各行政审批部门、行业管理部门和市场主体，要依托“双创”平台建立相互协作、资源共享、互动配合的工作机制，促进影视产业示范区投资与服务的无缝对接。在本工作方案实施过程中，各职能部门要加强动态管理、法规管理和数据管理，完善调整投资服务内容，不断完善企业监管方式，做好风险防控。
