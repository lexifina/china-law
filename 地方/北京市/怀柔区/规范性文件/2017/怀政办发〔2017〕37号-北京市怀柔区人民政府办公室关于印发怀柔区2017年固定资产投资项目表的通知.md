# 北京市怀柔区人民政府办公室关于印发怀柔区2017年固定资产投资项目表的通知

怀政办发〔2017〕37号

各镇乡人民政府、街道办事处，区政府各委办局，各区属机构：

经区政府同意，现将《怀柔区2017年固定资产投资项目表》印发给你们，请各单位结合自身职责和工作实际，狠抓落实，确保各项工程任务按时保质完成。

北京市怀柔区人民政府办公室

2017年3月16日
