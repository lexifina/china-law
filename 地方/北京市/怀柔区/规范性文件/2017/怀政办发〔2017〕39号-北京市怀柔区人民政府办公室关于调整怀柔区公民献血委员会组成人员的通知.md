# 北京市怀柔区人民政府办公室关于调整怀柔区公民献血委员会组成人员的通知

怀政办发〔2017〕39号

各镇乡人民政府、街道办事处，区政府各委办局，各区属机构：

鉴于怀柔区公民献血委员会（以下简称委员会）部分组成人员工作发生变动，为加强公民献血管理工作，保证医疗临床用血需要和安全。区政府决定对委员会组成人员进行调整。调整后的成员名单如下：

主 任: 焦宝军 副区长
