# 北京市怀柔区人民政府办公室关于调整北京电影学院怀柔新校区建设协调领导小组的通知

怀政办发〔2017〕8号

各镇乡人民政府、街道办事处，区政府各委办局，各区属机构：

主要职责：贯彻落实市区两级关于北京电影学院怀柔新校区建设的各项决策部署；围绕北京电影学院怀柔新校区建设，统筹推动各项工作任务，确保该项目按时、保质完成；研究协调解决北京电影学院怀柔新校区推动过程中的重大问题；完成市区两级关于北京电影学院落户怀柔交办的其他相关工作。

领导小组下设办公室、征地拆迁工作部、建设审批工作部、市政和公共配套工作部。

主要职责：负责领导小组会议组织及相关协调服务工作；负责与市委、市政府相关工作部门和市教委的联络、协调与对接；督查督办领导小组决策的工作事项；及时收集汇总北京电影学院怀柔新校区推动过程中所涉及信息材料，编发、报送信息简报，通报工作进展情况；负责结合北京电影学院落户怀柔带来的产业带动优势，研究中国（怀柔）影视产业示范区未来产业发展方向、定位及宣传工作；完成领导小组交办的其他工作。

三、工作要求

（一）严格执行责任制度。领导小组各部室主责单位主要负责人对本部室承担的各项工作任务负总责，对各项工作要亲自研究、亲自部署、亲自检查、亲自协调、亲自落实。各工作部室要统筹制定本部室的工作方案，进一步细化工作任务、工作职责及落实的具体措施，确保责任落实到单位、岗位及专人。各成员单位要严格按照工作范围和职责分工，建立台账，明确可量化的完成标准和具体的完成时限，务必做到责任到人、任务包干。确需抽调人员和经费保障的，上报领导小组统筹协调解决。

（二）严格执行协调会议机制。制定领导小组联席会议制度，原则上每两周召开一次领导小组联席会议，听取情况、研究问题、部署工作，遇重大问题随时召开领导小组会议研究解决。要严格执行重大问题调度会议制度，对本部室不能解决的问题，第一时间向领导小组报告，申请协调解决。同时，各部室建立相应的例会、协调机制，原则每周召开一次工作例会，梳理、通报工作进展及存在问题，切实形成工作合力，共同确保北京电影学院怀柔新校区建设工作高效推进。

（三）严格落实信息报送制度。领导小组各部室要确定专人负责本部室信息报送工作，认真落实周报、月报和重要事项专报机制，及时将本部室工作进展、主要举措、存在问题及其他重要工作信息报送领导小组办公室。办公室要跟踪收集各部室工作推进情况，及时编发工作动态简报和问题专报，报送领导小组和上级有关部门。各部室要严格执行重大问题专项通报制度，对工作中的重大、突发情况，第一时间核实情况并上报领导小组。
