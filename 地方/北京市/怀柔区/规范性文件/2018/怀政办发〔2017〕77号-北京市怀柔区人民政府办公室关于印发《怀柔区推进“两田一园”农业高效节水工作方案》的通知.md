# 北京市怀柔区人民政府办公室关于印发《怀柔区推进“两田一园”农业高效节水工作方案》的通知

怀政办发〔2017〕77号

各镇乡人民政府、街道办事处，区政府各委办局，各区属机构：

《怀柔区推进“两田一园”农业高效节水工作方案》已经区政府同意，现印发给你们，请认真贯彻执行。

北京市怀柔区人民政府办公室

2017年12月29日

怀柔区推进“两田一园”农业高效节水工作方案

为深入贯彻落实《中共中央国务院关于深入推进农业供给侧结构性改革加快培育农业农村发展新动能的若干意见》（2017年中央一号文件）、《中共北京市委北京市人民政府关于调结构转方式发展高效节水农业的意见》（京发〔2014〕16号）以及《北京市推进“两田一园”高效节水工作方案》（京政办发〔2017〕32号），推进本区粮田、菜田、鲜果果园（以下简称“两田一园”）高效节水工作，制定本方案。

一、指导思想

深入贯彻落实习近平总书记视察北京重要讲话精神和市委、市政府关于发展高效节水农业工作要求，严格遵循“节水优先、空间均衡、系统治理、两手发力”的新时期治水方针，深入推进农业供给侧结构性改革，把农业节水作为方向性、战略性大事来抓，大力实施区域化、规模化高效节水工程，按照“细定地、严管井、上设施、增农艺、统收费、节有奖”的建管模式，以健全农业水价形成机制为核心，以完善高效节水灌溉工程体系为基础，以创新体制机制为保障，以科技为支撑，不断完善农业用水总量和强度双控管理制度，促进都市现代农业可持续发展。

二、基本原则

（一）坚持以水定地、量水发展。继续推进农业种植结构调整，在地下水严重超采区和水源保护区逐步退出高耗水作物种植，推动支持农业规模化、集约化发展。实施农业用水总量控制与限额管理，降低农业用水总量，提高农业用水效率。

（二）坚持建管一体、机制先行。“两田一园”内农业高效节水工程推行标准化建设、一体化运营管理。建立完善用水收费、节水考核奖励、灌溉机井管理、基层水务管理等机制，优化工程建设审批流程，明确设施管护主体。

（三）坚持科技引领、示范推广。坚持专家领衔，科学规划，系统设计，充分利用新技术、新设备，实现工程建设现代化、管理手段现代化。抓好基础条件好的高效节水示范区建设，以典型推动、高标准引导，充分发挥示范带动作用。

三、工作目标

到2020年底，在“两田一园”范围内建立完善的高效节水灌溉工程建设、管理、运营体系。“两田一园”范围内雨养农业、生态景观农业之外的灌溉农田实现高效节水灌溉设施全部覆盖、良性运行，农业灌溉用水全面实施限额管理、计量收费，灌溉用新水总量下降到0.22亿立方米左右，农田灌溉水有效利用系数提高到0.75以上。

四、主要任务

（一）机制创新

1.健全政府购买服务机制

通过公开招投标确定专业化公司，实行农业节水设施建设运行统筹管理，明确区水务局、镇（乡）政府、村委会和专业化公司的职责分工。在工程规划、建设过程中，区水务局负责制定分年度实施计划、监督考核和验收评估，各镇（乡）政府负责建设及运维的协调与监管；专业化公司严格执行市级农业高效节水灌溉工程相关技术指引文件要求，开展高效节水灌溉工程标准化建设，严格执行高效节水灌溉设施维护标准，确保农业高效节水灌溉工程长效运行。

区水务局建立对专业化公司的监管考核和依效付费机制，成立督查考核小组，科学设置绩效考核指标进行考核，同时委托第三方服务机构开展“两田一园”高效节灌设施运行和用水户满意度调查评价，考评结果作为绩效服务费支付依据。

2.健全农业水价形成机制

建立健全反映供水成本、水资源稀缺程度的农业水价形成机制，完善怀柔区农业节水管理办法。高效节水灌溉工程农业水价原则上实行政府指导价并适时调整，综合考虑用水户承受能力合理分步实施。近期实行运行成本水价，包括日常维修费、人员费、动力费三部分。远期逐步实行全成本水价，包括运行成本、折旧费、材料费等。

实行农业灌溉用水限额管理，设施作物每年用水量不超过500立方米/亩，粮田、露地菜每年用水量不超过200立方米/亩，鲜果果园每年用水量不超过100立方米/亩。超限额部分执行加价收费并征收水资源费，水资源费按照本市有关规定标准执行。

水费征收以村委会为收费主体，区财政局和各镇（乡）政府指导监督。收取的水费主要用于缴纳动力费、设备维护费用等，确保设施良性运行。超限额加征的农业用水水资源费由区政府统筹用于农业节水相关工作。

3.建立节水考核奖励机制

在完善水价形成机制的基础上，建立与节水成效、工程运行和财力状况相匹配的节水考核奖励机制，统筹考虑当年农业用水节水量、逐级考核用水情况以及智能化计量系统记录的用水情况，按照“不用水不奖、多节水多奖”的原则对用水户进行奖励，奖励标准依据限额内节水量和市、区有关政策规定确定。

按照“区考核镇（乡），镇（乡）考核村，村考核用水户”的流程逐级考核。奖励资金由市级考核奖励资金中解决，以区水务局统计核实的数据为依据，并报请区政府批准后按相关规定拨付。

4.完善农用机井管理机制

按照《北京市推进“两田一园”高效节水工作方案》（京政办发〔2017〕32号）要求，制定出台怀柔区农用机井管理办法。明确农用机井管理主体。严控用途管控，农业灌溉机井取水只能用于农业灌溉，不能用于其他用途。严控机井数量，通过论证确需更新农业灌溉机井的，要保证封填一眼，更新一眼。严格水量管理，根据所灌溉地块的种植结构、面积和用水限额标准核定农业灌溉机井取水限额。严格计量管理，农业灌溉机井全部安装水量计量设施和电表，落实一井两表。委托专业化公司负责农用机井的运行维护。

5.创新优化项目审批流程

“两田一园”高效节水灌溉设施建设按照“提出需求、落实地块、核准任务、立项审批”的流程推进。

地块选择：各镇（乡）将粮田、菜田地块基本情况、灌溉设施现状及节水灌溉工程建设需求上报区农委，将果园地块基本情况、灌溉设施现状及节水灌溉工程建设需求上报区园林绿化局。地块应在“两田一园”生产空间内，选择粮田规模经营或集中连片50亩以上、露地菜田和鲜果果园规模经营或集中连片30亩以上的地块及全部设施作物地块优先发展农业高效节水灌溉工程。

项目立项：区农委和区园林绿化局核定各镇（乡）上报的“两田一园”高效节水灌溉工程地块是否在两田一园图斑范围内，拟定年度配套节水灌溉设施实施计划。区水务局根据审核结果和年度实施计划编制实施方案，包装项目。

项目审批：区发展改革委负责对整体项目进行统一审批立项。区水务局负责核定田间节水设施建设的投入资金（含市级补助、区级自筹）和高效节水灌溉设施运行维护资金，并报区政府批准后，列入年度财政预算。

项目实施：通过公开招标的方式分别确定建设、管护实施主体，负责高效节水灌溉工程的建设、管护。专业化公司根据年度管护任务向区水务局申报管护资金，区水务局核准后报送区财政局，待区政府批准后支付。

验收审计：项目验收工作由区水务局牵头，参照《水利水电建设工程验收规程》（SL 223—2008）和市水务局印发的《“两田一园”高效节水灌溉设施运行维护标准》（京水务郊〔2017〕83号）执行。农业高效节水灌溉工程项目按照区发展改革委和区财政局要求，开展审计工作，保障资金使用安全。

6.深化基层管水员队伍改革

贯彻落实《北京市怀柔区人民政府办公室关于印发北京市怀柔区农村管水员改革工作方案的通知》（怀政办发〔2017〕6号），进一步优化管水员队伍，提高管水员补贴，明确管水员职责。

建立镇（乡）、村级管水员监督考核机制。区水务局负责制定镇（乡）级考核办法，根据考核情况核定各镇（乡）应拨付资金。各镇（乡）出台村级管水员管理考核办法，通过实地检查、民意测评、村级自评等方式考核，考核结果作为村级管水员业绩评定的重要依据。

（二）工程建设

1.建设要求

“两田一园”内因地制宜建设喷灌、微灌等高效节水灌溉工程。工程建设与高标准农田建设、农业提质增效、规模化经营、家庭农场经营等现代农业建设相结合，与集蓄雨洪、农艺措施相结合。规模经营或集中连片的粮田、菜田和鲜果果园优先建设高效节水灌溉工程。

2.建设任务

（1）高效节水灌溉工程建设

目前，全区现有高效节水灌溉面积2.54万亩，规划调结构发展雨养农业、生态田园8.09万亩，仍需更新改善高效节水灌溉面积4.17万亩。根据地块设施现状，更新机井、建设井房、配套水泵、安装施肥过滤设备、修建输水管道、更新田间设施，到2020年底，全区“两田一园”范围内共需更新改善高效节水灌溉工程4.17万亩，其中露地菜微灌0.17万亩，果树微灌4万亩。

（2）高效节水核心示范区建设

建设高效节水核心示范区2处。集中展示果树微灌工程新材料、新技术，水肥一体化技术、节水信息化控制、灌溉水有效利用系数监测、灌溉制度试验示范、运行管护和培训宣传等，形成北京地区可推广、可复制的成套化、标准化高效农业节水核心示范区。

（3）推广农艺节水措施

因地制宜推广农艺节水技术。在设施农业中推广地膜覆盖、防草布敷设、水肥一体化等农艺技术；在鲜果果园中推广果园生草、园艺地布敷设、枝条粉碎还园、雨水集蓄、化控节水、蓄水保墒等农艺技术；在大田中推广抗旱品种种植、秸秆还田、免耕播种等农艺技术，发展雨养农业、生态田园8.09万亩。

（三）运行维护

农业高效节水灌溉工程运行维护包括2.54万亩现有农业高效节水灌溉工程和4.17万亩更新改善农业高效节水灌溉工程，主要任务为机井、水泵、井房、配电、施肥装置、过滤装置、计量设施、输水管道等骨干基础设施和田间首部设施、田间灌溉设施等田间节水设施的日常巡视检查、设备维护更新等。

六、投资估算

（一）投资政策

1.骨干基础设施投资政策

骨干基础设施主要包括机井、水泵、变频配电、计量设施、施肥装置、过滤装置、井房、输水管道等，骨干基础设施达到使用年限后方可更新改造。按照市级相关要求和生态涵养区补助标准争取市级资金支持。

2.田间节水设施投资政策

田间节水设施包括田间首部设施和田间灌溉设施，按照“先建后补”的原则，由区水务局会同区财政局根据建设内容和年度建设任务核定工程建设资金，报请区政府批准后拨付。市级通过转移支付的方式予以支持，市、区两级承担比例为1:1。

3.运行维护政策

区水务局联合区财政局制定农业高效节水设施运行维护的考核机制，按照每亩每年50元的标准建立运行维护资金，其中市级按照每亩每年最高25元的标准给予补助，其余由区财政局筹措。

（二）投资估算

根据国家及市级相关政策要求，怀柔区可采取政府购买服务的方式发展农业高效节水。

七、保障措施

（一）加强组织领导，强化责任落实

成立由主管副区长任组长，区发展改革委、区财政局、规划分局、国土分局、区农委、区农业局、区园林绿化局、区水务局、区质监局、区种植中心、区农机中心和各镇（乡）政府为成员单位的怀柔区农业高效节水工作领导小组，负责全区农业高效节水灌溉工程建设和运行维护领导工作。领导小组下设办公室，办公室设在区水务局，负责计划安排、组织管理、检查指导等工作。建立部门联动工作机制，实现政策、资金、技术的集成，推动全区农业高效节水工作顺利实施。

（二）强化监管考核，严格督查制度

建立农业高效节水监管考核制度，区水行政主管部门组织相关单位采取不定期检查、抽查或委托第三方检查等方式，对农业高效节水灌溉工程建设、运行维护实施主体的执行落实情况和成效进行监督考核。将农业节水纳入区政府对镇（乡）政府的绩效考核，加强对年度工作任务落实情况的督查考核，并作为年度绩效考核的重要指标，将督查考核情况及时反馈各镇（乡）政府。

（三）打好建设基础，强化技术支撑

严格用水限额管理，将用水指标落实到镇（乡）、村，按限额标准逐井核算用水量，将计量收费等基础工作落实到位；对现有灌溉机井进行核查，把“两田一园”中已有、更新改善高效节水灌溉工程的地块节水设施全面建档上图，实行动态管理；加强管水员队伍能力建设，确保服务、巡查全覆盖。结合示范区建设推进产、学、研一体化建设，完善科技支撑，服务到田间地头。

（四）加强业务培训，广泛动员宣传
