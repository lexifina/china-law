# 北京市怀柔区食品药品安全委员会关于印发《怀柔区食品生产加工作坊准许产品目录及生产加工要求》的通知

京怀食药委〔2019〕2号

区食品药品安全委员会各相关成员单位，各镇乡政府、街道办事处食品药品安全委员会：

为贯彻落实《北京市小规模食品生产经营管理规定》，根据市食品药品安全委员会办公室《关于贯彻落实〈北京市小规模食品生产经营管理规定〉有关工作的通知》（京食药安办〔2019〕2号）文件精神及区领导批示，我区制定《怀柔区食品生产加工作坊准许产品目录及生产加工要求》，已经区政府同意，现印发给你们，请认真贯彻执行。

附件：《怀柔区食品生产加工作坊准许产品目录及生产加工要求》

北京市怀柔区食品药品安全委员会

2019年6月5日
