# 北京市怀柔区人民政府办公室关于2018年度人大代表建议政协委员提案优秀承办件评选结果的通报

怀政办发〔2019〕1号

2018年，区政府系统各承办单位深入贯彻市、区关于进一步加强人大和政协工作的决定，认真落实人大代表建议、政协委员提案办理工作各项制度和措施，立足工作实际，积极开展办理工作，97件代表建议和129件委员提案全部办复。人大代表建议和政协委员提案的落实，有效推动了政府工作的开展。为鼓励先进，进一步推进代表建议、委员提案办理工作，根据《人大代表建议政协委员提案办理工作表彰奖励办法》（怀政办发〔2002〕2号）有关规定，2018年共评出人大代表建议、政协委员提案优秀承办件26件，现给予通报表彰。

一、第2号，关于加强电力设施保护工作的建议（承办单位：区城管委）

二、第13号,关于增加“煤改气”农户补贴的建议（承办单位：区农委）

三、第22号，关于肇事肇祸精神病人救治的建议（承办单位：区卫生计生委）

四、第32号，关于增加沙峪村银行服务窗口的建议（承办单位：区发展改革委）

五、第37号，关于加快推进各村养老服务驿站建设的建议（承办单位：区民政局）

六、第50号，关于在京密引水渠两岸适宜地段开辟休闲健身场所的建议（承办单位：区城管委）

七、第54号，关于加大北部山区森林防火技防设施投入力度的建议（承办单位：区园林绿化局）

八、第60号，关于改善怀柔镇中心小学交通情况的建议（承办单位：公安分局）

九、第74号，关于为方便山区群众乘车便利，增设招呼站的建议（承办单位：区交通局）

十、第89号，关于给予山区养鸡大棚后期腾退拆除工作资金政策支持的建议（承办单位：区农业局）

十一、第94号，关于在111国道沿线村庄与国道交叉路口增设安全措施的建议（承办单位：公安分局）

十二、第2号，关于我区棚户区改造建设的提案（承办单位：区住房城乡建设委）

十三、第11号，关于深入实施细化垃圾分类的提案（承办单位：区城管委）

十五、第30号，关于加大对高新技术企业政策支持力度的提案（承办单位：区人力社保局、区投资促进局）

十六、第47号，关于养殖业腾退的提案（承办单位：区农业局）

二十二、第92号，关于加快怀柔科学城配套设施—优质基础教育学校建设的提案（承办单位：区教委）

二十三、第105号，关于挖掘怀柔历史文化，服务美丽乡村建设的提案（承办单位：区文化委）
