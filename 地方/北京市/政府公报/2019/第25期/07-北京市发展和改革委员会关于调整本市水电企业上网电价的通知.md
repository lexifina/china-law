# 北京市发展和改革委员会关于调整本市水电企业上网电价的通知

京发改〔2019〕759号

国网北京市电力公司、北京华电水电有限公司、北京京西发电有限责任公司：

根据国家发展改革委《关于降低一般工商业电价的通知》(发改价格〔2019〕842号)要求，调整增值税税率降至13%的水电企业上网电价，调后标准见附件。

本通知自2019年7月1日起执行，北京市发展和改革委员会《关于调整北京电厂上网电价的通知》(京发改〔2011〕2203号)同时废止。

特此通知。

附件：北京市水电企业上网电价表
