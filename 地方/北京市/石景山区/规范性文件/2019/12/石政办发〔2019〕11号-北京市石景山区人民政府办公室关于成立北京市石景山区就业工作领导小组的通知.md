# 北京市石景山区人民政府办公室关于成立北京市石景山区就业工作领导小组的通知

石政办发〔2019〕11号

各街道办事处，区政府各委、办、局、处，各区属机构：

为进一步加强对我区就业工作的组织领导和统筹协调，凝聚就业工作合力，更好实施就业优先政策，按照党中央、国务院和北京市委、市政府工作要求，成立北京市石景山区就业工作领导小组（以下简称“领导小组”），作为我区议事协调机构，北京市石景山区社会保障和就业工作领导小组同时撤销。

领导小组负责对石景山区就业工作进行统筹协调、指导推进和督促落实，严格贯彻党中央、国务院和北京市委、市政府关于就业工作的决策部署；落实区委、区政府关于就业工作的指示要求；统筹协调全区就业工作，研究解决就业工作重大问题；研究审议拟出台的就业工作宏观规划和重大政策，部署实施就业工作改革创新重大事项；督促检查就业工作有关法律法规和政策措施的落实情况，交流推广经验，表彰先进典型；完成区委、区政府交办的其他事项。

领导小组组长由区委常委、常务副区长柯永果同志担任，副组长由区人力资源和社会保障局局长齐兵、区人民政府办公室副主任靳晶等同志担任，成员单位包括区人力资源社会保障局、区发展改革委、区财政局等23个单位。

领导小组办公室设在区人力资源社会保障局，承担领导小组日常工作。办公室主任由区人力资源社会保障局副局长周翠英同志担任，办公室成员由各成员单位一名有关科室负责同志组成。
