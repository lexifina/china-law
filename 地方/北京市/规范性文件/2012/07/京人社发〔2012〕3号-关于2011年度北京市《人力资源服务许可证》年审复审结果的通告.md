# 关于2011年度北京市《人力资源服务许可证》年审复审结果的通告

京人社发〔2012〕3号

根据《北京市人才市场管理条例》和《北京市劳动力市场管理条例》等人力资源市场相关法规规定，我局于2012年5月28日发出通告（京人社发〔2012〕1号），对暂缓通过2011年度年审的52家人力资源服务机构进行复审。

经复审，下列17家人力资源服务机构通过2011年度年审，可依法按照核准业务范围开展人力资源服务活动：
