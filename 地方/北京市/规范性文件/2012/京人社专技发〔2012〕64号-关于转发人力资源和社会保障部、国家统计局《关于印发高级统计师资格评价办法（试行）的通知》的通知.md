# 关于转发人力资源和社会保障部、国家统计局《关于印发高级统计师资格评价办法（试行）的通知》的通知

京人社专技发〔2012〕64号

各区县人力社保局、统计局，市属各委、办、局、总公司、高等院校人事（干部）处，各人民团体人力资源（干部）部门，各有关单位：
