# 关于印发第四批北京市职业技能公共实训基地专业设置标准的通知

京人社能发〔2012〕307号

各区县人力资源和社会保障局，各技工院校、职业技术学校，各有关单位：

为加强北京市职业技能公共实训基地建设工作，加快高技能人才培养，根据《北京市关于进一步加强职业培训工作的实施意见》（京政发[2011]33号），我局组织制定了第4批 6个专业的职业技能公共实训基地专业设置标准（目录及标准另发），现予公布。

请各单位认真组织学习，按照颁布的职业技能公共实训基地专业设置标准，建设好公共实训基地。

附件：第四批北京市职业技能公共实训基地专业设置标准目录
