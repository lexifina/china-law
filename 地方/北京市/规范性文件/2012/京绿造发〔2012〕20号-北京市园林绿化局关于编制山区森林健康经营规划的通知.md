# 北京市园林绿化局关于编制山区森林健康经营规划的通知

各有关区、县园林绿化局：

为积极推进本市森林可持续经营工作，全面提高森林健康经营管理水平，按照《北京市人民政府关于建立山区生态公益生态效益促进发展机制的通知》和2012年北京市山区造林营林和森林经营工作会议要求，现就开展山区森林健康经营规划编制工作 有关事项通知如下：

一、要充分认识规划编制工作的重要意义

森林经营规划是各区县开展年度森林健康经营工作的重要依据，是园林绿化发展规划的重要内容，也是建设“绿色北京”和中国特色世界城市的重要基础工作。编制好森林经营规划，对于落实国家和本市森林经营方针政策，统筹国家、市级和区县级营造林工程中森林经营项目，科学合理安排本区县森林经营规模面积、年度任务、主要措施等都具有重要意义和作用。各区县要高度重视森林健康经营规划编制工作，认真组织技术力量，结合本区县实际，明确责任，落实任务，按期完成规划编制任务。

二、要严格落实规划编制的各项要求

森林经营规划的编制必须以科学发展为指导，以森林可持续经营理论为依据，以培育健康、稳定、高效的森林生态系统为目标，按照《北京市人民政府关于建立山区生态公益生态效益促进发展机制的通知》、《北京市山区生态公益林生态效益促进发展机制森林健康经营项目管理暂行办法》和《北京市山区生态公益林生态效益促进发展资金管理暂行办法》的要求，坚持“科学规划，突出重点，措施得当，务求实效”的原则，明确规划期限、规划面积、年度任务、主要措施、实施方式、目标成效等内容，体现规划的深度和可操作性。

各区县要以“十一五”末全市二类资源调查数据为基础数据，并结合近两年营造林工程实施情况，按照林木抚育5-8年一轮的森林经理要求，编制森林健康经营规划，规划期限原则上为2012年—2020年。规划编制中，要认真分析不同区域功能定位、不同森林类型、不同经营需求，以及制约森林健康经营的主要因素，制定有针对性的森林健康经营措施。森林健康经营措施要以林木抚育为主，主要包括松土扩埯、修枝割灌、间株定株、补植补造、抚育间伐等技术措施，同时要把林区作业道、生态林用排水设施、重点地段游憩保障设施等林业基础建设纳入一并规划，统筹规划好资源保护、经营发展与后续开发利用。森林健康经营林木抚育规划要打破乡镇和村的界线，在全区县统筹考虑林分抚育需求，按轻重缓急程度依次成片推进，避免年度任务星星点点分布，确保经营成效。

三、要认真抓好规划编制的具体工作

森林经营规划编制工作量大、技术要求高。一是要加强领导，明确专人负责，落实具体责任；二是要在现有资源数据的基础上，进行现地调查，夯实基础，做到底数清楚、情况明了、数据准确、依据可靠。三是各区县原则按《区县森林经营规划编制提纲》（附后）的格式和内容编制本区县规划，可针对实际情况增加相应内容。四是各区县要在9月30日前完成本区县森林健康经营规划编制工作，以正式文件形式报市园林绿化局审批。五是各区县于2012年8月8日17点前将规划编制主管领导、责任部门、具体联系人员名单报市园林绿化局。
