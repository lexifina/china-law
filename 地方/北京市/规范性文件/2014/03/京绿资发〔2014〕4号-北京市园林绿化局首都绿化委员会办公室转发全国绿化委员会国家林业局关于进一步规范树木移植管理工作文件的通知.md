# 北京市园林绿化局首都绿化委员会办公室转发全国绿化委员会国家林业局关于进一步规范树木移植管理工作文件的通知

各区县园林绿化局、绿化委员会办公室，市级有关部门，局属国有林场苗圃：

现将全国绿化委员会、国家林业局《关于进一步规范树木移植管理的通知》（全绿字〔2014〕2号，见附件）转发给你们，并结合我市实际，提出如下工作要求，请一并认真贯彻落实。

一、提高认识，认清大树古树移植的危害性

大树已生长多年，甚至几十年，古树生长上百年，完全适应了当地土质、气候条件等生长环境。移植大树古树不仅破坏树木原生环境，而且移植后养护费用相当高，2-3年内易产生假活现象，不易成活，特别是古树成活率更低，很难充分发挥生态功能。如树木死亡则还需重新绿化，不仅景观受到影响，而且造成的经济损失更大。因此，各区县园林绿化主管部门和各有关部门、单位要充分认识大树古树移植的危害性，认清大树古树移植是违背树木自然生长规律的做法和行为，是对绿化资源的一种严重破坏，大量移植大树古树用于城乡绿化不符合科学发展观要求；要组织开展好学习贯彻通知精神，宣传到基层单位并带头执行，从自身做起，从本部门、本单位做起，要加大对大树古树移植危害性的宣传力度，摒弃立地成景、见效快的思维模式，杜绝“形象工程”、“面子工程”，厉行节约，在全社会形成科学绿化的发展理念，不断加强和规范树木移植用于城乡绿化管理工作，推动我市园林绿化事业更加快速健康发展。

二、依法审批，进一步加强源头管理

依据我市园林绿化法规，我市移植林木（含树木，以下简称林木）必须办理林木移植许可手续，生产苗木的苗圃、农村居民移植自留地和房前屋后个人所有的零星树木、苗木除外。要加强本地区（单位）林木资源源头管理，进一步加大对林木的保护力度，认真执行有关法规、政策规定、技术规程，严控以营利为目的的商业性移植。因工程建设、森林经营保护等情况确需移植林木的，应制定移植方案和原地林木保护方案，其中森林经营性保护性移植，应聘请专家论证，符合相关要求实施。

三、科学统筹本市城乡绿化造林用苗，严格规范大树使用

各区县园林绿化主管部门和市有关部门、单位要加强对绿化苗木的检查。对用于本市绿化的苗木，除需提供《植物检疫合格证》之外，还要有苗木标签、林木种子生产许可证和经营许可证。对证件不齐全的苗木，按相关规定处理。城乡绿化所用大规格苗木应按照本市有关规定，在本地区培育发展。

积极鼓励因工程建设中符合移植的林木用于城乡绿化建设，坚持以乡土树种、优质苗木绿化为主，以大苗栽植代替大树移植。除特殊景观需要外，严格控制使用大规格林木、禁止古树用于造林绿化工程。

四、加强监督检查，严厉打击非法移植林木行为

各区县园林绿化主管部门要严格履行法律职责，对违反规定、程序批准移植林木的人员，要依法追究责任；对未经审批擅自移植、运输林木的，要依法制止和查处，特别是擅自移植运输大树古树的行为；各级森林公安机关等执法部门要对违法违规移植大树、古树案件依法查办，从严打击，切实保护好首都森林资源。

各有关部门、单位要积极配合各级园林绿化主管部门开展林木保护管理工作，对森林资源保护不力的单位和直接责任人员，依照相关规定处理。
