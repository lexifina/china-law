# 北京市水务局关于清理规范涉水行政审批中介服务事项的公告

为进一步深化简政放权、放管结合、优化服务改革，市政府决定清理规范150项政府部门行政审批中介服务事项。

根据《北京市人民政府关于清理规范一批政府部门行政审批中介服务事项的通知》（京政发[2016]65号），现将涉及水务部门的17项行政审批中介服务事项予以公布。

特此公告。
