# 北京市园林绿化局关于印发《城镇园林绿化养护管理年度考评工作细则》的通知

各区园林绿化局：

为进一步规范城镇园林绿化养护管理年度考评工作，维护公平竞争、公正考评的严肃性，切实强化争优创先意识，不断提高精细化养护管理工作质量和水平，市园林绿化局研究制定了《城镇园林绿化养护管理年度考评工作细则》。现印发你们，请认真抓好贯彻落实。

北京市园林绿化局

2017年3月14日

城镇园林绿化养护管理年度考评工作细则

为进一步规范城镇园林绿化养护管理年度考评工作，维护公平竞争、公正考评的严肃性，强化争优创先的意识，有效促进城镇园林绿化养护管理工作落实，不断提升精细化养护管理水平，切实发挥城市园林绿化的生态效益、景观效益和社会效益，特制定城镇园林绿化养护管理年度考评工作细则。

第一条 考评原则

依据《北京市绿化条例》、《城镇绿地养护管理规范》和《北京市城镇绿地分级分类办法》，注重日常检查和过程管理，做到公平、公正、公开，真实反映城镇园林绿化养护管理工作质量和水平。

第二条 考评内容

考评内容包括公共绿地、社会绿地(单位附属绿地、居住区绿地)养护管理和日常问题整改情况。其中：公共绿地、社会绿地养护管理，重点考评绿地植物养护、植物保护、绿地保洁、附属设施管理、安全作业等园艺性措施，以及绿地看管、巡查、围护、保洁、宣传等园务性工作落实情况；日常问题整改，主要借助城镇园林绿化动态管理系统平台考评暗查、信访、媒体反映问题整改情况。

第三条 考评标准

区分日常检查、季度检查、专项检查，细化量化具体考评标

准。日常检查、季度检查考评标准(详见附件)，专项检查根据内容另行制定考评标准。

第四条 考评办法

通过日常检查、季度检查、专项检查，考评年度工作情况。

年度考评成绩由日常检查、季度检查、专项检查的分值确定，具体按照日常检查占10%、季度检查占80%、专项检查占10%的比例计算，即：年度考评成绩=日常检查成绩×10%+季度检查成绩×80%+专项检查成绩×10%。

第五条 考评结果

日常检查、季度检查、专项检查的情况，通报区园林绿化局，抄送区政府，以工作信息形式报送市主管领导，并将年度考评成绩作为对各区园林绿化管理工作绩效考评的依据。

第六条 本细则下发之日起执行，市园林绿化局负责解释。
