# 北京市水务局关于水务工程建设项目招投标进入公共资源交易平台有关事项的通知

各区水务局、局属各相关单位：

根据市政府《关于印发〈北京市整合建立统一规范的公共资源交易平台实施方案〉的通知》（京政办发〔2016〕9号）、市发展改革委《关于印发北京市整合建立统一规范的公共资源交易平台任务分工方案的通知》（京发改〔2016〕745号）等文件要求，全市政府投资和使用国有资金依法必须招标的水务工程建设项目招投标，须全面进入区级以上人民政府建立的公共资源交易平台。现将有关事项通知如下：

一、按照市发展改革委工作进度要求，自2017年7月1日起，以谁立项谁监管的原则，结合“放管服”要求，市水务局负责全市水务工程建设项目招投标活动的行政监督和管理工作，并负责局属单位水务工程建设项目招投标的监管，各区水务局负责辖区内的水务工程建设项目招投标的监管工作。

二、各区水务局要积极配合区发展改革委，做好进入区级公共资源交易平台开展招投标的各项工作，按时完成进度计划。在平台未运行前，各区水务局应作好本辖区内水务工程建设项目线下招投标的监督管理工作。

三、各区水务局于每季度末前，以书面报告形式向市水务局报送本季度水务工程招投标情况（详见附件）。

特此通知。
