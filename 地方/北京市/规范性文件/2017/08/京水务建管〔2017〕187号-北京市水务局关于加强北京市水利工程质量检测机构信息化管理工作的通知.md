# 北京市水务局关于加强北京市水利工程质量检测机构信息化管理工作的通知

各市管水利工程质量检测机构：

根据国务院印发的《质量发展纲要（2011-2020年）》及水利部印发的《贯彻质量发展纲要提升水利工程质量的实施意见》（水建管〔2012〕581号）中的要求，北京市水利工程质量管理系统正式开发完成。系统投入使用后，将全面规范我市水务工程建设市场的质量及安全管理工作，强化检测机构及行业管理，实现检测数据自动采集和实时上传功能，为更好的发挥系统作用，现就质量检测有关要求通知如下：

一、总体要求

市属水利工程质量检测机构的检测报告应全部上传。严禁检测报告弄虚作假行为。市水利质量与安全监督中心站具有查询不合格检测报告权限。

检测报告格式及具体参数内容应全部统一，符合SL734的规定。

各市管水利工程质量检测机构应于2017年8月31前，将《自动采集设备安装情况统计表》（附件1）报送至北京市水利工程质量与安全监督中心站。各机构应建立和完善检测数据自动采集的管理制度，并于2017年10月底前全部实现要求的试验参数自动采集功能，具体目录见《检测数据自动采集的检测项目及参数目录》（附件2）。

二、 报告上传时限

打印正式检测报告后，应确保该检测报告已上传到系统。

三、检测管理软件故障处理

出现异常情况导致自动采集仪不能正常工作的，应及时报告市水利质量与安全监督中心站。在此期间出具的检测报告，应单独建立台账，保存好原始记录，并于故障排除后填写“自动采集数据未上传检测报告统计表”（附件3），存档备案。通过非系统方式完成收样、样品自编号等操作，可向委托方出具书面检测结果通知，不得出具检测报告。故障排除后，应先将自编号样品按收样顺序录入系统（收样日期、检测日期及报告日期以实际时间为准），完成报告上传等工作，在自编号样品未全部录入系统前，不得新收样品。在这期间出具的检测报告应在故障排除后2日内按检测分类代码分类、报告编号顺序填写 “非系统方式临时收样统计表（附件4）”，存档备查。

四、基本信息情况更新要求

各检测单位应于2017年8月18日前，登录系统，填报相关机构信息，如信息发生变更，应于3个工作日内更新完成，确保机构基本信息准确。
