# 北京市园林绿化局关于下放“对从事林木良种推广使用工作的专业技术人员的认定”等公共服务事项的通知

各区园林绿化局：

为适应改革形势的需要，提高为民办事效率，经市编办批准，我局决定将“对从事林木良种推广使用工作的专业技术人员的认定”(行政确认)、“对使用先进适用的采种机械给予补贴”(行政给付)两项公共服务事项下放给各区办理。

各区园林绿化局要做好两项公共服务事项下放后的承接工作，研究制定办理的标准和流程，并及时对外公布，切实加强事中事后监管。
