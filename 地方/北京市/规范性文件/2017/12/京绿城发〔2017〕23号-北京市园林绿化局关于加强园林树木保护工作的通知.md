# 北京市园林绿化局关于加强园林树木保护工作的通知

各区园林绿化局：

为进一步做好园林树木保护工作，切实巩固和提高园林绿化的生态效益、景观效益、社会效益，现就加强园林树木保护工作通知如下：

一、搞好宣传引导。各级园林绿化部门要借助宣传橱窗、网络媒体、微信平台等载体，广泛宣传加强园林树木保护的意义，以及损害绿化行为的法律后果，引导市民自觉爱绿、护绿，共同保护来之不易的园林绿化成果，切实为改善和保护生态环境做出积极贡献。

二、加强监督检查。各级园林绿化局要严格落实属地管理负责制，采取日检查、周通报、月讲评的形式，会同属地街道、社区加强对辖区绿地的监督检查，尤其要加大附属绿地监督检查力度，有效杜绝损害绿化行为的发生，不断提升辖区园林绿化整体管理质量和水平。

三、主动对接服务。各区园林绿化局要主动对接辖区街道、社区，定期组织小区物业、社会单位等绿地管理人员参加的园林绿化养护管理业务培训，讲解养护及修剪技能，讲清树木修剪与抹头、摘冠、截杆的危害，主动为小区物业、社会单位抓好绿化工作提供服务。

四、从严界定底线。各级园林绿化局要依据《北京市绿化条例》第四章第五十条第六款之规定，澄清树木修剪与抹头、摘冠、截杆的本质区别，明确树木抹头、摘冠、截杆等同于砍树，损害了树木基本的生态效益、景观效益，属于损害绿化成果的行为。

五、加大查处力度。各级园林绿化部门要加强与属地城管部门的沟通合作，积极拓宽执法巡查、监督举报等渠道，采取“零容忍”的态度，依法追究损害园林绿化行为人的民事责任或刑事责任，严厉打击损害绿化的行为，齐心协力保护园林绿化成果，为首都园林绿化工作做出应有的努力和贡献。

北京市园林绿化局
