# 北京市人民政府办公厅关于清理杨柳絮防止发生火灾的紧急通知

京政办发〔2017〕22号

各区人民政府，市政府各委、办、局，各市属机构：

近期，本市天干物燥，又值杨柳飞絮高发期，违规违法用火极易引发火灾。特别是5月1日在朝阳区孙河乡前苇沟村一停车场发生火灾，造成90台车辆不同程度过火，经初步调查，就是明火引燃堆积的杨柳絮波及所致。为进一步加强杨柳飞絮治理，切实防止违规违法用火引发火灾，现就有关事项紧急通知如下：

一、高度重视，增强紧迫感、责任感。各区政府、各部门、各单位要高度重视，深刻汲取朝阳区孙河乡火灾教训，举一反三，从严从紧落实各项防范措施，严防类似问题再次发生。

二、落实责任，全面开展杨柳絮清理工作。市城市管理委、市园林绿化局、市交通委等部门和各区政府要立即行动起来，组织动员社会力量，落实防火责任制，围绕居民社区、学校、加油加气站、易燃易爆厂房仓库、公交场站、文物古建、公园、施工工地、林地林区等重点场所和部位，及时洒水清扫，严禁焚烧处理。

三、严管火源，杜绝违法用火行为。切实加强用火、用电安全管理，严格执行相关操作规程。强化野外火源控制和安全用火管理，严禁野外烧荒、林地林区吸烟等违法用火行为。同时，广泛发动群众对违法违规用火行为进行举报。

四、强化监管，加大检查和执法力度。要层层落实责任，加强巡查、监控和盯守，深入彻底排查各类火灾隐患及存在的突出问题。对重大隐患要挂牌督办整改，对违反规定的行为，依法依规严肃处理。

五、强化应急管理，快速有效应对。各区政府、各部门、各单位要立足于抓早抓小，细化完善应急措施，做好应急准备，确保快速反应、高效应对、迅速管控，避免小火酿成大灾。

六、加强宣传引导，提高防范意识。要利用广播、电视、报纸、网络等媒体，普及杨柳絮清理措施，防止处理不当引发火灾。

北京市人民政府办公厅

2017年5月2日
