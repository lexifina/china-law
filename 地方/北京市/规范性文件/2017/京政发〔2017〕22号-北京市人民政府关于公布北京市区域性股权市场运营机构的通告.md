# 北京市人民政府关于公布北京市区域性股权市场运营机构的通告

京政发[2017]22号

北京股权交易中心有限公司是经北京市人民政府批准的全市唯一一家区域性股权市场运营机构。2013年成立以来，北京股权交易中心有限公司立足融资、交易、孵化、改制、宣传、创新等六大功能，以融资服务为核心，积极支持实体经济特别是中小微企业发展，是为北京市行政区域内中小微企业证券非公开发行、转让及相关活动提供设施与服务的唯一合法场所。

特此通告。
