# 北京市园林绿化局关于在本市林果产业生产和生态建设中禁止实施“大水漫灌”的通知

各区园林绿化局(果品办)、海淀区农委：

为进一步贯彻落实《中共北京市委　北京市人民政府关于调结构转方式发展高效节水农业的意见》(京发〔2014〕16号)、《北京市人民政府关于实行最严格水资源管理制度的意见》(京政发〔2012〕25号)等有关文件精神，加强园林绿化行业春季用水管理和林果产业生产指导相关工作，通知如下：

一、高度重视园林绿化全行业春季用水管理和生产指导工作，在平原造林、城镇绿化、公园风景区绿化中，不得实施“大水漫灌”等影响首都城市形象的行为；

二、各区园林绿化局按照《中共北京市委　北京市人民政府关于调结构转方式发展高效节水农业的意见》，本着“量水发展、生态优先、提质增效、农民增收”的工作原则，切实做好本地区春季果树、花卉、种苗等生产用水管理，采取有力措施，杜绝春灌中出现“大水漫灌”。

三、各区园林绿化主管部门要加强节水宣传工作，通过多种形式推广节水灌溉和农艺节水技术，宣传节水意义，提升园林绿化从业者、广大林农果农生产生活中的节水意识。同时，要加强检查巡查工作，一旦发现“大水漫灌”，立即制止、坚决纠正。

四、市园林绿化局将适时组织对重点区域、路段周边进行巡查，出现“大水漫灌”现象将予以通报。

北京市园林绿化局
