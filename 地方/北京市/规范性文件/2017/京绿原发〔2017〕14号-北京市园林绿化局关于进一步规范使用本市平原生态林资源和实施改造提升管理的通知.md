# 北京市园林绿化局关于进一步规范使用本市平原生态林资源和实施改造提升管理的通知

各区园林绿化局：

平原地区生态林资源是我市平原生态系统的主体，为保护好本市平原生态林资源，规范平原生态林经营和使用林地管理，更好服务国家和市级重点公共服务类基础设施建设项目占用平原生态林管理，依据《北京市人民政府关于对完善基础设施建设项目占用园林绿化用地管理意见的批复》(京政字〔2017〕2号)有关要求，提出以下意见。

一、平原生态林范围

本通知所指平原生态林是指本市在平原地区由政府投资并享受生态林补助营造和保护的生态公益林，包括平原地区百万亩造林、一道绿隔和二道绿隔生态林、“五河十路”等重点绿色通道两侧永久性绿化带生态林、平原地区重点区域绿化建设工程营造的生态林等。

二、严格重点工程项目占用平原生态林管理

(一)因重点工程项目建设确需永久占用平原生态林，区园林绿化主管部门要协调占地单位明确占用平原生态林范围和林木情况，并汇总相关材料报市园林绿化局。报送材料包括占用平原生态林依据(项目批准文件)、占地范围图、现状树木调查结果及保护平原生态林承诺等(承诺按要求补造，承担补造资金)。临时占用平原生态林由各区园林绿化主管部门负责监管，相关材料和要求可参考永久占地。

(二)占用地块上的林木要本着“优先保护利用、能移不伐”的原则，按照相关程序办理林木采伐、移植等有关手续，林木采伐、移植结果报送区平原生态林养护监管部门。

(三)本着“依法保护、严格控制，区域统筹、占补平衡”的原则，补造地块实行区域平衡，由各区园林绿化主管部门优先列入下年度造林绿化计划(不计入年度造林绿化指标)，对于辖区内确实无法实现占补平衡的，经市政府批准后，由市园林绿化局在全市范围内安排平衡。补造工作由区园林绿化主管部门统筹安排，建设标准不低于所占地块原有林木质量水平，并确保与周边景观协调一致，建设资金由占地单位承担。临时占用林地，占地单位在工程竣工一个年度内负责恢复绿化，恢复绿化前方案需报区园林绿化主管部门。区园林绿化主管部门要加强对补造和恢复绿化工程的管理和技术指导，竣工验收后报市园林绿化局申请核查。

(四)因占用生态林地而产生的市级土地流转补助和林木养护结余资金纳入下一年度全区土地流转、林木养护资金。土地流转费原则上按照半年结算，超过半年按照整年拨付，林木养护费从占地与养护交接完成后下月起核减。补造或恢复竣工验收后重新核定所需土地流转和养护资金。

三、加强平原生态林提升改造规范管理

(一)平原生态林提升改造要坚持生态林属性不变、功能效益提高的原则，要有相关行业专家论证意见或部门的立项批复。

(二)提升改造项目严禁皆伐和大面积移植树木，要充分保护和利用现有林木，本着留优去劣、整体提升的原则，编制提升改造施工设计方案，其中伐除200株(含)以上或移植500(含)株以上的提升改造项目施工设计方案由区园林绿化局初审后报市园林绿化局审定，伐除200株以下或移植500株以下的提升改造项目施工设计方案由区园林绿化局审定，相关材料报市园林绿化局。相关部门按照审定的施工设计方案，办理树木采伐和移植手续。

(三)提升改造项目单位要按照审核后的施工设计方案开展工程建设，区园林绿化局要加强项目建设的管理和技术指导，竣工验收后报市园林绿化局申请核查。

(四)对在提升改造项目内继续使用的移植林木，工程建设中只负责移植费用；对不能在本项目利用的林木，要优先用于政府投资的生态公益类项目；对确无利用价值、生长不良的低劣林木可进行伐除。改造提升项目实施期间，原有林木养护费用由区园林绿化局根据实际统筹管理使用。

四、严格生态林资源保护和强化监督

(一)各区园林绿化主管部门要高度重视生态林资源保护工作，严格履行规定程序，确保平原生态林资源不减少。依据本通知要求，各区结合本区实际可制定相应实施细则。

(二)各区园林绿化主管部门要加强补造和提升改造项目的技术指导和监督检查，切实提高平原生态林质量，提升功能效益。竣工验收后，按照工程管理规定加快养护移交工作，并做好建设与养护的衔接。

(三)加强档案规范管理，对占用林地、林木调整和补造完成情况要及时归档，全面准确反映造林地、林木变动情况。

(四)严格资金管理，各区园林绿化部门要加强对补造经费、林木养护和土地流转结余资金使用管理，确保专款专用，规范合理，提高资金使用效益。
