# 北京园林绿化局关于进一步做好郊野公园养护管理工作的通知

各有关区园林绿化局：

2007年，我市启动了以郊野公园建设为主要内容的绿化隔离地区“公园环”建设工程，截至目前，绿隔地区“公园环”已完成新建公园60个，使该区域公园总量达到81个，总面积7.68万亩。郊野公园建成以来，在满足市民日益增长的健身休闲等方面发挥了重要作用，但随着这一地区城市化进程的加快，游人数量逐年递增，需求日益多样化，给保持良好的生态景观和游园环境等管理工作带来很大压力。为进一步增强市民绿化获得感和游园满意度，现就进一步做好郊野公园养护管理工作通知如下：

一、严格责任落实，加强环境综合整治

各区园林绿化局是郊野公园养护管理工作的责任主体，要切实履行监管职责，建立健全管理制度，严格责任落实，加强统筹协调，动员各方力量，全面开展环境综合整治工作。一是进一步完善郊野公园运行管理机构，明确职责任务，切实组织郊野公园的日常运行维护工作，包括园区林木绿地养护、设施设备维护、环境卫生保洁、安全应急管理和游客服务等。二是突出问题导向，加大力度，采取措施，全面开展环境治理，解决垃圾乱扔乱堆、设施维护、车辆乱停、过度踩踏、杂草清理等最基本的管理问题。三是实施分区域管理。在确保全园整洁安全的前提下，结合公园游客游览分布情况，将公园进行区划，实行分区科学管理，对主要景区要按照《公园管理工作规范》实行精细化管理。

二、突出工作重点，加强养护精细管理

各区要以提升公园绿地景观质量水平和园容园貌为重点，督促指导各公园制定年度管理工作计划，编制园区绿地养护工作实施方案，明确养护内容和技术标准，把任务细化分解到地块，根据不同季节特点和不同时间节点要求，着力抓好植物养护、卫生保洁、安全管理等工作，确保林木生长旺盛、绿地干净整洁、园内环境良好。

(一)植物养护。各公园要结合树势对乔灌木整形修剪，清理枯枝病枝、内膛枝、徒长枝和树干部多余萌条，生长季节要及时抹芽，要求修剪后枝条疏密适当、主侧枝分布均匀、树冠通风透光；要结合土壤墒情、季节差异及时浇水灌溉，雨季要做好绿地积水排除防涝；要及时清除树穴和草坪内的杂草，其他区域适当修剪，严控草荒和拉拉秧上树；要对清除后的枯死树及时补植，保持树木合理密度和植物整体景观；要严禁随意移植园区树木。

(二)园容卫生。要加强园路、广场、垃圾箱、厕所、桌椅等设施设备卫生清扫，确保地面整洁、厕所卫生、垃圾箱清理到位；要及时捡拾和清除绿地内垃圾、杂物和绿化废弃物，严禁就地焚烧，鼓励枯枝落叶粉碎后掩埋到绿地改良土壤；要保持绿地属性不变，严禁园区绿地乱搭乱建、乱堆乱倒、乱垦乱种、乱牧乱养。

(三)安全管理。要加强园内桌椅、指示牌、健身器材等设施设备维护，确保休憩体育等设施和运动场地正常使用；要加强安全管理，做好监控系统、广播系统维修保护，加强车辆管理，防止社会车辆入园，影响游园安全；要做好重大活动期间、重点节假日、组织文体活动、极端天气及突发事件的安全应急管理。

三、加强监督检查，确保养护质量成效

要建立郊野公园检查巡查机制，采取区级自查、市级考核相结合的方式，确保养护质量成效。各区园林绿化局要结合所管公园现状，根据年度养护计划，通过不定期巡查和季度集中检查的方式，对各公园植物养护、卫生保洁、园容园貌、设施管理等重点内容组织监督检查，发现不合格的要以书面方式责令整改，同时要对日常养护检查详细记录、建立管理台账。要研究建立养护管理质量成效与养护费用拨付使用挂钩机制。市园林绿化局第三季度将在各区自查的基础上，组织有关专家通过查阅养护记录、政策制度档案和现场抽查的方式，采取集中量化打分考核，结合日常检查、社会调查对各区开展综合考评，并在全市通报。

四、要进一步抓好基础管理工作

各区园林绿化局要加强郊野公园的养护经费使用监督、审计，任何单位和个人不得截留、挪用，确保专款专用，提高资金使用效益；同时要围绕提升郊野公园景观和更好发挥功能作用，积极主动争取区发改、财政、旅游等相关部门的政策资金支持。

各区要加快推进公园竣工决算工作。认真梳理影响竣工决算进度的问题，加大沟通协调和解决问题的力度，完善相关资料，推进决算及早完成。要对具备登记注册条件的公园，抓紧履行相关手续，争取尽早纳入公园行业管理，提升规范化管理水平。

各区有郊野公园改造提升计划的，要报市园林绿化局审查规划设计方案。要加强舆情监督，对媒体报道的问题及时调查整改，减少社会影响。

请各区于8月31日前将郊野公园养护管理工作情况总结，报市园林绿化局平原绿化处。

北京市园林绿化局
