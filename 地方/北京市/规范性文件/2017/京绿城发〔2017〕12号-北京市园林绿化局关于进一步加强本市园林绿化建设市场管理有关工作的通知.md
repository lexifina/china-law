# 北京市园林绿化局关于进一步加强本市园林绿化建设市场管理有关工作的通知

园林绿化建设各相关单位：

根据《国务院关于修改和废止部分行政法规的决定》(国务院令第676号)、《住房城乡建设部办公厅关于做好取消城市园林绿化企业资质核准行政许可事项相关工作的通知》(建办城〔2017〕27号)精神，为维护本市园林绿化建设市场公平竞争秩序，促进园林绿化行业稳定发展，确保资质取消后相关工作的有序衔接，现就有关事项通知如下：

一、建立园林绿化信用信息管理机制。市园林绿化局负责建立以企业基本信息、技术和管理人员信息、企业业绩和诚信信息为主要内容的园林绿化建设市场信用信息系统(系统未上线前，暂以北京市园林绿化企业管理服务平台登记公布的信息为准)。园林绿化建设各相关单位共同参与本市园林绿化建设市场信用信息建设。企业信用信息作为园林绿化建设活动激励、惩戒的重要依据。

二、根据北京市人民政府办公厅印发的《北京市整合建立统一规范的公共资源交易平台实施方案》(京政办发〔2016〕9号)，政府投资和政府融资园林绿化建设项目、全部使用国有资金投资或国有资金投资控股或占主导地位的园林绿化建设项目以及重点园林绿化建设项目的施工、监理、重要设备材料采购招投标交易活动必须全部纳入北京工程建设公共资源交易平台园林子平台。

三、园林绿化建设工程的发包须严格遵守国家及本市相关的法律法规。发包人应根据发包工程的规模、类型和技术难度等，综合考评承包人的人员、业绩、信用等履约能力。施工技术复杂的重大工程项目可以设置与工程相适应的企业类似业绩要求。类似业绩通过造价、工程内容等指标体现的，一般不超过招标工程相应指标的70%。

四、园林绿化建设工程招投标不得设置城市园林绿化企业资质或市政公用工程施工总承包等任何资质的要求。政府投资的园林绿化项目，招标人编制资格预审文件和招标文件，应使用本市园林绿化工程招标的相关示范文本。在资格审查和评标时，应以北京市园林绿化建设市场信用信息系统的相关信息为准。

五、从事园林绿化工程建设的施工企业应具备承担相应园林绿化工程的能力。担任园林绿化工程的项目负责人应为北京市园林绿化建设市场信用信息系统在库人员，且不得同时承担两个或以上在建项目。

六、市园林绿化局应加强对招标投标活动、工程质量等监督管理，检查结果纳入本市园林绿化建设市场信用信息系统。

七、本通知所指园林绿化建设工程包括绿化种植工程、园林景观构筑物及其它造景工程、园林铺地工程、园林给排水工程、园林用电工程等。

八、本通知自2017年7月1日起施行。
