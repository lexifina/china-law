# 北京市园林绿化局关于印发《北京市城六区背街小巷绿化美化工作实施意见》的通知

东城区、西城区、朝阳区、海淀区、丰台区、石景山区园林绿化局：

为认真贯彻落实市政府关于抓好背街小巷整治提升的工作部署及相关文件精神，按照全市统一要求，市园林绿化局结合城六区工作实际，研究制定了《北京市城六区背街小巷绿化美化工作实施意见》。现印发给你们，请按要求抓好落实。

北京市园林绿化局

2017年8月16日

北京市城六区背街小巷绿化美化工作实施意见

为贯彻落实市政府关于抓好背街小巷整治提升的工作部署，实施《北京市城六区2017年背街小巷环境整治提升工作方案》及《首都核心区背街小巷环境整治提升三年(2017-2019年)行动方案》关于园林绿化建设和管理的各项任务，指导各区规范开展好背街小巷绿化美化建设和管理工作，提升背街小巷绿化美化水平，特提出如下意见：

一、充分认识做好背街小巷绿化美化工作的意义

背街小巷是北京历史文化名城、国际性大都市的重要组成部分，代表着城市的形象和文明程度，也传承城市的文化，彰显着城市的精神。背街小巷环境整治提升工作中，绿化美化工作作为其中的重要内容，不仅有益于协调好胡同街巷的整体环境，传承古都历史风貌、留住老北京乡愁乡情，而且能有效改善邻里生活、生态、交往环境。进一步推进背街小巷绿化美化工作，对治理背街小巷存在的脏乱差等问题，体现北京城市精细化管理水平，展现首都新形象、新面貌作用显著。

二、总体要求

(一) 指导思想。以习近平总书记视察北京重要讲话精神为指导，牢牢把握“四个中心”首都城市战略定位，坚持以改善群众生活环境和服务水平为遵循，以“治顽疾、促提升、惠民生”为目标，全面加强背街小巷绿化美化规划建设和精细化管理工作，显著提升背街小巷绿地景观、生态、文化、服务水平，为建设国际一流的和谐宜居之都提供有力支撑。

(二)遵循原则。坚持文脉传承、风貌统一的原则；坚持以人为本、建管并进的原则；坚持因地制宜、注重实效的原则；坚持部门联动、分步实施的原则；坚持多方参与、共建共享的原则。

(三)工作目标。

1.总体目标：城六区背街小巷在环境综合整治的基础上，通过实施多元增绿，增添花卉，不断拓展绿色空间，美化街巷环境；建立一套标准统一，责任明晰的专群协作绿地管护机制，动员群众参与和自主管理，实现社会共治，共建共享。

2.具体目标：

首都核心区：东城区2017-2019年，实施“百街千巷”环境整治绿化美化提升建设1228条(胡同1050条，大街178条)。2017年完成胡同绿化511条，大街绿化134条；西城区三年内完成背街小巷绿化美化建设1331条(街巷1171条，道路160条)。2017年完成街巷绿化912条，道路绿化86条。

城四区：2017年完成背街小巷绿化美化提升建设74条(朝阳区20条、海淀区20条、丰台区22条、石景山区12条)。

三、任务分工

(一)规划设计与管护规则。市园林绿化局负责制定背街小巷绿化美化规划建设技术指导书及绿地养护管理指导意见，用以指导城六区背街小巷绿化美化建设和管护工作。

(二)建设实施与绿地管护。背街小巷建设与管护工作按属地采取专群结合的方式落实责任。即：属区园林绿化局管理的，由区园林绿化局负责绿化美化任务组织实施及建成后的养护管理工作；属区街道管理的，原则由各街道负责，区园林绿化局负责做好绿化美化方案的审查，绿化建设及绿地养护管理的指导监督、验收工作。

四、工作要求

(一)高度重视。抓好背街小巷环境整治，实施绿化美化景观提升工作，是落实习近平总书记视察北京时强调的“既要管好主干道、大街区、又治理好每个社区、每条小街小巷小胡同”要求的具体体现。各区、各部门要认真贯彻习近平总书记视察北京重要讲话精神，从讲政治和履行好“四个服务”职责的高度，围绕建设国际一流的和谐宜居之都目标，深入开展背街小巷绿化美化景观提升工作，常抓不懈，久久为功，坚决治理“城市病”痼疾顽症，全面提升城市绿化美化精细化管理水平。

(二)落实责任。市园林绿化局牵头协调市级有关部门，研究制定背街小巷绿化美化工作规划、建设、管护技术标准及相关政策；指导、调度背街小巷绿化美化建设实施，推动工作开展。城六区政府为实施绿化美化工作的责任主体，负责制定建设及养护管理方案，创新机制，分级落实责任。首都核心区要按照《背街小巷环境整治提升三年(2017-2019年)行动方案》确定的建设计划，落实好各项任务。城四区要在2017年工作任务的基础上，抓紧制定明后两年的工作任务台帐，确保背街小巷绿化美化水平得到整体提升。

(三)监督管理。强化督促检查，市园林绿化局将会同市有关部门、各区政府，开展背街小巷绿化美化建设管理工作督导检查，确保背街小巷建设任务按计划落实，各项建设内容按方案准确实施。

(四)宣传发动。利用宣传橱窗、报刊、电台、电视台等各类宣传媒介，多种方式广泛宣传背街小巷绿化美化工作的重要意义，发动社区居民参与到背街小巷绿化美化景观提升改造工作中来，全民参与，共建共享，提高广大居民爱绿、护绿、植绿意识，积极营造良好的社会氛围，有效推动背街小巷绿化美化工作开展。
