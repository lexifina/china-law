# 北京市园林绿化局关于进一步加强园林绿化工程质量监督分站建设的通知

各区园林绿化局：

为落实市委第一巡视组专项巡视反馈“抓紧解决园林绿化工程实施过程中跟踪问效少、质量追责难等问题”的相关要求，进一步加强园林绿化工程质量管理，规范园林绿化建设行为，依据《北京市建设工程质量条例》、《北京市绿化工程质量监督实施办法》相关规定，现就全面加强全市园林绿化工程质量监督分站建设，稳步提升园林绿化市场管理水平，努力构建企业自控、行业自律、社会监督、政府监管的工程质量治理机制，将有关要求通知如下：

一、充分认识园林绿化工程质量监督工作的必要性和重要性

(一)加强园林绿化工程质量监督是法律法规赋予的神圣职责

2015年9月25日，市十届人大第二十一次会议审议通过了《北京市建设工程质量条例》(以下简称《条例》)，并于2016年1月1日起正式施行。该《条例》在法规层面规定了园林绿化工程要实行质量监督，明确了由园林绿化行政主管部门负责园林绿化专业工程质量监督工作。因此，加强园林绿化工程的监督管理是各级园林绿化行业行政主管部门不可推卸的责任。

(二)加强园林绿化工程质量监督是园林绿化建设发展的必然要求

十八大以来，随着“五位一体”总体布局的确立以及五大发展理念的提出，各级政府对于城市生态环境的重视程度和建设力度都在稳步提升。自百万亩平原造林工程之后，我市相继启动城市副中心建设、新机场建设、2019年世园会、2022年冬奥会以及2017年国际合作高峰论坛等重大活动筹备工作，其中涉及园林绿化建设项目数量多、资金投入大、工期紧、任务繁重。在当前发展形势下，进一步做好建设工程特别是重大工程的质量监督工作，意义重大，影响深远。

(三)加强园林绿化工程质量监督是园林绿化行业健康发展的基础保障

在园林绿化工程建设中推行质量监督管理，充分发挥质量监督机构人员以及专业优势，规范绿化建设行为，保证工程建设质量，提高建设资金使用效率，是有效发挥园林绿化经济效益、生态效益和社会效益的重要基础，是促进园林绿化行业科学、规范、可持续发展的根本保障。

二、进一步加强园林绿化工程质量监督机构建设

(一)质量监督机构的法定职责

工程质量监督机构是代表行业行政主管部门对辖区建设工程质量进行监督的职能部门，工作职责是严格按照国家的有关法律法规、标准规范、规章制度，对参建各方的质量责任行为以及工程实体质量进行监督，对竣工验收进行监督，并出具工程质量监督报告。

(二)本市园林绿化行业质量监督机构建设情况

“十二五”期间，在市、区两级园林绿化主管部门的积极推动下，在市园林绿化工程质量监督站的具体指导下，全市相继有朝阳、海淀、大兴等八个区建立了园林绿化工程质量监督分站。“十三五”起步之年，通州区园林绿化局成立了全市首个具有正式编制的区级园林绿化工程质量监督机构，为全市园林绿化工程质量监督分站建设作出了表率。

我市园林绿化工程质量监督体系在近十年的发展过程中，实现了监督制度从无到有、队伍建设日益加强、监管能力稳步提升，并在工作实践中逐步探索出一套制度化、规范化的工作模式，成功指导完成了2008年奥运工程、万亩滨河森林公园、APEC绿化景观提升等重大建设工程质量监督任务。在取得成绩的同时，当前园林绿化工程质量监督工作仍然存在诸多不足：一是市区两级质量监督体系并不健全，仍有七个区尚未建立质量监督分站；二是在已建立质量监督分站的区中，多数工作人员仍以兼职为主，除朝阳、海淀、大兴已经开展工程质量监督工作外，其余各区尚不能正常开展质量监督工作；三是监督人员规范开展质量监督工作的能力以及对宏观政策的把握能力需要尽快提升。

(三)加快建立区级园林绿化工程质量监督机构

工程质量监督是集政策性、专业性和技术性于一体的工作。着眼于当前园林绿化建设面临的新形势、新任务以及今后大量繁重的园林绿化养护管理任务，全市应加快健全市、区两级质量监督体系，共同推动园林绿化质量管理工作。对于尚未建立质量监督机构的区，要加快质量监督分站建设，充分履行作为政府职能局对建设工程进行质量监督的职能；对于已经成立质量监督分站的区，要明确职责，完善机制，努力培养一支遵纪守法、素质能力强、专业技术过硬的专职质量监督队伍，对辖区内园林绿化工程，特别是使用国有资金投资或者国家融资的绿化项目全面开展质量监督工作，发现问题及时整改，确保园林绿化优质的工程质量。

三、积极发挥质量监督机构的作用，全面推进园林绿化工程质量监督工作迈上新台阶

随着我市生态环境建设的深入推进，园林绿化工程质量监督工作面临着难得的发展机遇和前所未有的工作挑战。园林绿化建设规模的快速增长，广大市民对于首都生态环境改善的殷切期待，建设国际一流和谐宜居之都目标的实现，都对新时期园林绿化工作提出了更高的标准和要求。各区要进一步提高质量意识，充分强化质量责任，切实发挥质量监督机构作用，适应新形势，寻求新突破，依法监督，严肃履职，扎实推进园林绿化工程质量监督工作，促进本市园林绿化事业蓬勃发展。

(一)强化市区两级联动的五统一运行机制

建立和遵循工程质量监督程序，做到程序化、制度化、规范化，加强法律法规和业务培训，提高业务水平和执法水平，在市园林绿化工程质量监督站的指导下开展实质性的工作，形成市区两级质量监督统一政策指导、统一监督受理、统一监督流程、统一检查标准、统一业务培训的运行机制，深入开展园林绿化工程的质量监督工作，履行政府监管的职责，抓好工程质量管理，确保工程建设质量。

(二)创新完善双随机抽查监督模式

建立规范高效的工程质量巡查、抽查制度，把工程质量检查与各方责任主体质量行为结合起来，把施工前预控、施工中检查与竣工验收有机结合起来，加大不定时、不定点、不定人、不定内容、不提前告知的日常质量监督巡回抽查力度，真正对责任主体起到震慑作用。监督抽查要做到专项治理与日常监督相结合、告知性检查与突击性检查相结合、综合执法检查与专项检查相结合、行为监督与实体监督相结合。通过对关键环节、重点部位的控制，有效减少质量问题的发生。

(三)落实质量监管与市场监管联动机制

强化“市场”与“现场”联动，建立“两场”监管机制，切实解决重企业资质、个人资格审批，轻审批后的动态监管；重市场准入及招投标管理，少市场清出管理；监督检查多，检查结果利用少等问题。从招投标、资质资格管理等环节着手，充分发挥市场机制的约束作用，将工程质量监管与招标投标、资质资格等紧密结合起来，建立完善企业质量诚信与市场准入相关联的管理制度。实现“现场”与“市场”的联动动态监管，形成一种守信激励、失信惩诫的诚信机制，促进园林行业提高质量责任意识和自律意识。

(四)大力推行差别化监管

大力实行差别化管理，不断提升监管效率。一是监管对象差别化。根据不同企业业绩、信誉、质量保证能力等情况，结合信用评价机制，实施不同程度的监管，起到扬优治劣的作用。二是工程类型差别化。重点加强对大型公用工程、政府重大项目等工程的监督。三是投资主体差别化。对政府投资与非政府投资项目实施不同监督控制模式。四是监督过程差别化。突出对工程质量重要因素、关键环节以及新材料、新工艺、新技术运用较多部位的监管。
