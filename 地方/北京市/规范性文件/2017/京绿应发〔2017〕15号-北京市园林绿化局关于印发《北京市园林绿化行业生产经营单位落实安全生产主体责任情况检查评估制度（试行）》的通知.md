# 北京市园林绿化局关于印发《北京市园林绿化行业生产经营单位落实安全生产主体责任情况检查评估制度(试行)》的通知

各区园林绿化局：

为进一步强化生产经营单位安全生产主体责任落实，按照市安委会办公室《关于市政府有关部门建立本行业生产经营单位落实安全生产主体责任情况检查评估制度的指导意见(试行)》要求，市园林绿化局制定了《北京市园林绿化行业生产经营单位落实安全生产主体责任情况检查评估制度(试行)》，现印发给你们，请结合各区实际情况，建立本区园林绿化行业生产经营单位落实安全生产主体责任情况检查评估制度。其中，园林绿化施工企业评估对象参照《北京市园林绿化施工企业台账》，公园、野生动物园评估对象参照各区现有台账。此项工作从2018年开始实施，请各区抓好落实工作，夯实本区园林绿化行业安全生产基础。
