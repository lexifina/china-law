# 北京市园林绿化局北京市发展和改革委员会关于门头沟区绿道系统规划的审查意见

门头沟区园林绿化局：

你局《关于<门头沟区绿道系统规划>报审的请示》(门绿文〔2017〕19号)收悉。经研究论证，《门头沟区绿道系统规划》(以下简称《规划》)已按照专家评审会意见进行了修改完善，原则同意该规划，并提出如下意见：

一、该规划作为指导你区绿道建设和实施管理的主要依据，基本符合上位规划及你区实际，对强化门头沟区生态涵养功能，促进绿色转型发展、完善绿色基础设施以及门头沟区园林绿化事业发展具有重要意义。

二、抓紧编制各条绿道具体建设方案，进一步提出详实、可行的引导性和限制性要求。要优化绿道线路走向和空间布局，按照因地制宜、人车分行的原则设计通行系统，对借道部分的必要性要充分论证，慢行道路混合铺设的绿道应提出物理隔离等措施，保证游人通行安全。要创新绿道建设和管理运维模式，探索多种方式吸引社会力量参与。

三、绿道建设要与“疏解整治促提升”等全市重点工作相结合，做好留白增绿、拆违还绿配套工作，要与永定河流域综合治理等重大项目相结合，要从群众的感受和体验角度提升相关配套服务设施，充分拓展绿道生态服务功能、挖掘绿道文化内涵、引导市民绿色出行。

四、依据《北京市级绿道系统规划》和《关于北京市级绿道建设的指导意见》要求，门头沟区绿道建设应在2020年底前，完成总建设量约238.05公里的市级、区级、社区级绿道(其中市级绿道约95.3公里)。

五、你局要加快推进市级绿道的建设进度，初步构建门头沟区绿道体系的结构骨架。同时加强对《规划》实施情况的跟踪分析，定期会同有关部门做好绿道建设的评估考核和宣传工作。

北京市园林绿化局 北京市发展和改革委员会

2017年6月28日
