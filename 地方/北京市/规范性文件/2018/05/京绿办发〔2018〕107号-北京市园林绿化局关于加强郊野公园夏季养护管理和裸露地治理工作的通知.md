# 北京市园林绿化局关于加强郊野公园夏季养护管理和裸露地治理工作的通知

各有关区园林绿化局：

当前已进入林木绿地夏季养护期，为加强第一道绿化隔离地区郊野公园林木绿地养护管理和推进裸露土地治理，营造良好游园环境，现就有关工作通知如下。

一、以提升景观为目标着力抓好树木修剪等日常养护

夏季是树木生长的重要时期，公园养护管理要充分考虑园内树木种类、生长习性、景观效果，结合树木长势科学采取养护措施，不断促进树木生长和提升生态景观。重点要对落叶乔木影响树形的萌生枝、徒长枝加强修剪工作，做到分布均匀、树形美观；要围绕减少安全隐患及时清除枯枝死杈和死树；要对景观树木、花灌木根据树形、树龄、生长势等进行修剪整形，确保单株分布的树形美观，丛植花灌木或绿篱类外形轮廓整齐；要结合雨季雨水丰沛的有利条件，对景观效果不理想区域开展补植补造，同时做好浇水保水灌溉保活，确保新植树木生长。

二、优先保护利用现有野草地被推进公园裸露地治理

坚持优先保护利用园内现有地被和野草野花植物，禁止随意拔除和采挖，特别是天然长出的原生草本植物，要通过修剪、浇水、施肥等措施促进生长但不能出现草荒，有条件的可采取移栽扩大野生地被面积。对于园内裸露地要根据景观需求、区位现状，因园而异制定地被景观营造保护方案。一般对于因园路不足游人踩踏而形成的裸露地，可采取碎石、石板或透水材料铺装建设园路；对于重要节点、广场周边、一级园路沿线宜从满足游人赏花观景、健身休闲等需求，通过人工种植低矮、耐修剪、自播能力强、易管护的花卉提升景观；对于其他林下空间裸露地，根据景观需求和季节变化，选择乡土一二年生与多年生草本花卉播种，丰富林下景观规模。

各区要对辖区公园地表现状开展调查，摸清底数，统筹制定裸露地治理方案和工作计划，明确地被种植区位、种植面积、植物种类、实施时间和阶段目标，力争通过2-3年公园裸露地得到有效治理。同时将裸露地治理方案于6月20日前报市园林绿化局平原绿化处。

三、加强绿地保洁和园容园貌环境、设施设备维护

要按照公园管理规范要求，突出督查督导，着力加强公园绿地保洁和园容园貌环境、设施设备维护，防止园内出现乱堆杂物、乱倒垃圾、私搭乱建、乱垦乱种等影响绿地卫生、园容园貌现象，一旦发现垃圾要及时清除，确保绿地卫生整洁。要加强厕所卫生保洁和园椅等基础设施设备检查维护维修，确保正常使用。要做好公园雨季积水排涝，原则上要实现雨水园内蓄存不外排，同时加强自然灾害安全防范，确保游园秩序和安全游园环境。

请各区园林绿化局对郊野公园养护管理主要措施、裸露地治理典型经验成效等提升郊野公园养护管理水平工作加强宣传，对阶段性养护管理工作总结及时报市园林绿化局平原绿化处。我们将围绕郊野公园树木修剪、裸露地治理、绿地保洁、园容园貌等内容组织检查，共同营造良好游园环境，不断提高市民获得感。
