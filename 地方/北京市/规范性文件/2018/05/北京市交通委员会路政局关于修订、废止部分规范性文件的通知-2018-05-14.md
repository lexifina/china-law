# 北京市交通委员会路政局关于修订、废止部分规范性文件的通知

各公路分局、直属单位，局机关各处室：

为不断完善规范体系，提高文件制定质量，按照《关于进一步加强规范性文件管理工作的实施意见》，我局组织对现行有效的规范性文件进行清理。经局长办公会审议通过，决定对《北京市公路桥梁桥下空间使用管理暂行办法》等11个规范性文件作出修订，废止《关于加强公路养护工程设计管理的通知》等6个规范性文件。现将文件目录及修订内容印发给你们，请各单位遵照执行。
