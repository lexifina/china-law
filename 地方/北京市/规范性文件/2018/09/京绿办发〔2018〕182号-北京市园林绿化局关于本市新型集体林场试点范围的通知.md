# 北京市园林绿化局关于本市新型集体林场试点范围的通知

各有关区园林绿化局：

为贯彻落实市政府办公厅《关于完善集体林权制度促进首都林业发展的实施意见》(京政办发〔2018〕17号)中关于“重点探索在平原地区、浅山地区发展集体林场”的部署，各区园林绿化局在认真开展调查研究的基础上，提出了本区探索建立新型集体林场的试点乡镇、试点范围和基本思路。经市园林绿化局研究，确定门头沟区军庄镇、房山区大石窝镇等23个乡镇为全市新型集体林场试点范围，乡镇名单如下：

门头沟区：军庄镇

房山区：大石窝镇

通州区：马驹桥镇、西集镇、潞城镇

顺义区：大孙各庄镇

大兴区：采育镇、长子营镇

昌平区：流村镇

平谷区：马坊镇

怀柔区：桥梓镇、琉璃庙镇

密云区：西田各庄镇

延庆区：延庆镇、张山营镇、永宁镇、旧县镇、八达岭镇、井庄镇、康庄镇、大榆树镇、沈家营镇、香营乡

各试点单位要按照《北京市新型集体林场试点方案》要求，结合本地区实际，积极探索、大胆创新，推进试点工作不断深入。市、区园林绿化部门将组成专门工作组加强对试点工作的指导，认真研究解决试点工作中出现的新情况和新问题，及时总结阶段性成效，保障全市试点工作目标顺利实现。

北京市园林绿化局
