# 北京市园林绿化局关于转发住建部《关于进一步加强城市公园安全管理工作的通知》的通知

各区园林绿化局，各公园管理机构：

近日，住房和城乡建设部印发《关于进一步加强城市公园安全管理工作的通知》(下简称《通知》)，现转发给你们，请结合各区、各公园实际认真贯彻执行。郊野公园、森林公园、湿地公园等其他类型公园参照执行。为了进一步贯彻落实好《通知》要求，做好本市公园安全管理工作，现将有关事项通知如下。

一、高度重视公园安全工作。随着我市人民生活水平的提高，公园已经成为广大市民不可或缺的重要产品、游憩健身的重要场所。同时，我们也要清醒地认识到，公园是人口密集的场所，有效防范公园安全事故的发生，是各区园林绿化部门、各公园管理机构的重要职责。公园安全重于泰山，要全面落实安全管理责任，加大安全管理力度，加强安全隐患排查，杜绝或减少各类安全事故的发生。

二、严格依法行政，落实安全规范。《北京市公园条例》、《北京市公园管理工作规范》和《北京市公园风景名胜区安全管理规范》是本市公园安全管理的规范性文件，各区园林绿化部门、各公园管理机构都要认真学习、加强培训，严格落实、遵照执行。要科学制定安全应急预案，努力做好防火安全、防汛安全、活动安全、人身安全，为人民群众营造一个安全有序的游园环境。

三、加强监督检查，全面排查整治安全隐患。要根据今年初公园安全隐患排查行动的部署安排，建立定期检查制度，对公园内的文物古建、游艺设施(特别是大型游乐设施)、山石水面、栏杆棚架、动物兽舍、食品卫生、车辆机械、水电设施、消防设施等进行拉网式检查，针对安全隐患，逐个梳理解决。要特别加强动物园中大型动物安全管理，防止动物伤人事件的发生；特别加强公园内节假日(或大型活动期间)游人密集区的安全管理，避免踩踏事故的发生。要将公园安全检查排查的任务落实到人，落实到地块，落实到具体环节。
