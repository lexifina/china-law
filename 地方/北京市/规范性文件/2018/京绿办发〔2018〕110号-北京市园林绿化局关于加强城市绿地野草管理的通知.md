# 北京市园林绿化局关于加强城市绿地野草管理的通知

各区园林绿化局：

城市绿地野草管理需要科学的态度和方法，应因地制宜、管控结合，不能任其自由蔓延，也不能一拔了之，否则野草的生态功能和景观效益就会大打折扣，甚至会影响居民的生活和城市的环境。为加强城市绿地野草的管理，更好发挥野草的功能和效益，现就城市绿地野草管理工作通知如下：

一、抓好教育培训

各单位要以各级领导关于生态环境方面的讲话，市园林绿化局下发的《北京市绿地林地地被植物选择与养护技术指导书(试行)》为主要内容，采取专家授课、以会代训、现场示范、参观见学等多种形式，有针对性地抓好一线养护作业人员的教育培训，重点学习理解生态环境建设的新理念、新思路、新要求，了解认识野草的生态功能和景观效益，以及城市绿地裸露治理的重要性和必要性，掌握城市绿地养护的技术规范和行业要求，尤其是分区域、分类别管理城市绿地的方法，不断强化一线养护作业人员的生态理念，切实为加强和推进城市生态环境建设奠定良好的基础。

二、实施分类管理

城市绿地野草的管理，要因地制宜，分区管理，分类施策。具体是：

1.乔灌木树堰内的野草。应采取修剪的方法，合理控制野草高度，在丰富植物多样性的同时，最大限度保证绿地美观度和地表覆盖率。

2.绿篱色块及宿根花卉区域的野草。绿篱色块及宿根花卉内的野草，应及时清除，保证绿篱色块及宿根花卉的美观度和整齐度；绿篱色块及宿根花卉外侧边缘的野草，应采取修剪、中耕的方法，合理控制高度和密度，保证区域内的地表覆盖率。

3.草坪中的野草。公园绿地主要游览区，城市主干道及单位、居住区等主要景观区的草坪，应采取修剪与拔除相结合的方法，合理控制野草比率，其中：低矮、耐修剪，能与草坪草共生的野草，应按照目标草实施管理；高大、不耐修剪、不融合的野草，应及时清除，优先保证草坪的景观效果；其他非主要游览、景观区的草坪，应采取修剪的方法，控制好野草高度，最大限度保护、利用好野草的功能效益。

4.外来入侵的野草。城市绿地中外来入侵的恶性野草、与区域景观差异性大的野草，应及时发现、清除，最大限度保护乡土地被植物和区域内绿地景观效果。

三、加强宣传引导

各级园林绿化部门要在抓好内部教育培训的基础上，充分借助文化橱窗、网络媒体、微信平台等宣传载体，广泛宣传城市绿地野草的生态功能和景观效益，以及城市绿地野草管理的科学态度和方法，引导企业单位、社会团体、广大市民正确认识城市绿地野草在丰富植物多样性、改善生态环境方面的地位和作用，大力营造爱生态、保生态的浓厚氛围，减少和杜绝人为破坏城市绿地、生态环境的问题，共同为改善城市生态环境做出积极的努力和贡献。
