# 北京市规划和自然资源委员会关于发布《关于推进北京市核心区责任规划师工作的指导意见》的通知

各有关单位：

为贯彻落实《北京城市总体规划（2016年-2035年）》提出要建立责任规划师制度、开展直接有效的公众参与的要求，以建立责任规划师制度为抓手，完善专家咨询和公众参与长效机制，提升核心区规划设计水平和精细化管理水平，我委组织编制了《关于推进北京市核心区责任规划师工作的指导意见》。该文件已经市委、市政府研究通过，现予发布执行。

特此通知。
