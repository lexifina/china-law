# 北京市园林绿化局关于进一步加强林业生态建设促进农民就业增收工作的通知

各区园林绿化局、各有关单位：

为贯彻落实北京市委、市政府关于促进农民就业增收及低收入农户帮扶、低收入发展工作的相关政策文件精神，结合《北京市园林绿化局关于加强低收入农户精准帮扶工作的实施意见》，现将进一步加强林业生态建设，促进农民就业增收工作通知如下。

一、充分认识和发挥林业生态建设对促进农民就业增收的重要作用

随着本市生态建设的推进，特别是实施平原造林以来，林业生态建设已成为农村劳动力就业的重要途径。通过严格落实平原生态林、山区森林经营等管护就业政策，有力保障了农民绿岗就业增收。但也要看到，部分政策还未完全到位，实施林业生态富民的潜力还很大。各区园林绿化局、各有关单位要进一步提高政治站位，牢固树立"四个意识"，增强责任感和使命感，把进一步加强林业生态建设，促进农民就业增收作为一项重要的政治任务来抓。要加强组织领导，明确任务目标，严格台账档案管理，强化监督考核，促进林业生态建设和农民就业增收同步发展，实现生态美百姓富的有机统一。

二、严格落实各项林业生态惠民政策措施

各区各单位要严格执行以下三方面林业生态惠民政策。一是严格落实山区生态公益林生态效益促进发展机制和山区生态林补偿机制，确保11月底之前将生态补偿资金发放到户，确保在各区或乡镇规定时限之前将山区生态林管护员岗位补贴发放到人。二是严格执行生态林管护农民就业政策，确保平原生态林养护招用本地农民不低于60%、规模化苗圃招用不低于50%、山区森林健康经营招用不低于80%，并优先吸纳低收入劳动力。三是积极研究及创新绿色产业扶持政策，确保政策落实到项目、到地块、到人头；同时统筹利用好各类培训政策，加强规划引领，通过系统培训，培养一批新型职业农民和集体林业工人。

三、积极拓宽农民绿岗就业增收渠道

（一）引导农民积极参与绿化建设。各区可根据新一轮百万亩造林绿化等工程项目情况及本区实际，明确要求本地农民的用工比例，将此作为承接工程项目的前置条件并纳入合同管理。

（二）创新农民养护就业机制。以新一轮百万亩造林为契机，对浅山区台地、平缓地造林绿化工程后期养护，可依托乡镇林业站力量，试点组建全部使用本地农民的林木养护队伍。乡镇林业站同时负责监管，确保生态受保护，农民得实惠。

（三）强化绿色产业带动农民就业。在现有五大林业产业的基础上，充分利用我市良好的生态基础，大力发展围绕现代化规模化果园、花卉基地的休闲旅游、科普体验、观光采摘及森林旅游、森林康养等本地农民更能充分就业、收益更高的高端绿色产业，进一步促进农民绿岗就业增收。

四、建立健全档案台账管理及信息报送宣传制度

（一）加强组织管理。依托市局低收入农户精准帮扶工作领导小组，分别由生态保护修复处、产业发展处及科技处牵头，从生态建设和管护、绿色产业发展、技能培训和科技服务三个方面建立健全农民就业档案及管理台账。各区也要建立相应机制，加大工作力度，加强组织调度。各区、各单位要于3月29日前填报市区联系表（附件1、2），形成横向连通、上下联动的沟通机制。

（二）规范档案管理。以规范生态建设和管护项目促进农民就业档案为突破口，建立健全农民就业档案，明确管理制度，专人负责。档案应包括且不限于人员花名册、就业合同或协议、身份证复印件、考勤表、工资表等。区园林绿化局应会同区档案局对档案管理工作加强监督指导。

（三）建立就业台账。填报本年度促进农民就业情况，动态管理，每季度底15天内更新台账并上报至市园林绿化局（一季度台账推迟至4月15日前报送市局汇总）。具体流程如下：每季度底，由建设或管护单位填报年初至本季度底的就业登记表（附件3）；由各区园林绿化局汇总形成就业统计表（附件4）并分类型报市园林绿化局各相关单位；市局各单位汇总形成全市就业汇总表（附件5）。附件3-4纸质版由具体单位或区园林绿化局留存备查，电子版均需报市园林绿化局。

（四）及时报送相关信息。各区各部门要加强信息报送工作，每半年梳理汇总一次促进农民就业增收工作报告。对于创新发展、统筹政策或取得突出进展的典型案例，要及时形成动态信息，推动各区及基层发挥主观能动性，促进经验交流，实现全面发展。

五、加强督导检查及考核管理

加强林业生态建设和促进农民就业增收，要两手抓、两手都要硬。各区要切实加强监管，积极开展自查自纠，确保农民就业档案及台账规范管理；在明确具体项目单位主体责任的基础上，建立严格的奖惩机制。市局组建生态建设和管护、绿色产业、技能培训和科技服务三个联合督查小组，开展定期或不定期的督导检查，并建立通报制度，确保农民绿岗就业增收实效。对于工作中发现的不严不实、搞形式主义，甚至弄虚作假的单位和个人，要严肃追究责任。针对本通知部署的生态建设和管护项目促进农民就业的档案及台账管理情况，市园林绿化局将于6-7月集中开展一次全市范围的大检查，请各相关单位予以高度重视。
