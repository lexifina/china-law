# 关于转发《住房和城乡建设部关于修改部分部门规章的决定》的通知

各区水务局，局属各相关单位，局机关各相关处室：

2019年3月13日，住房和城乡建设部公布了《住房和城乡建设部关于修改部分部门规章的决定》（建设部令第47号），现转发给你们，并就有关事宜通知如下：

一、各区水务局、局属各相关单位、局机关各相关处室要严格按照新修改后的《房屋建筑和市政基础设施工程施工分包管理办法》《房屋建筑和市政基础设施工程施工招标投标管理办法》《危险性较大的分部分项工程安全管理规定》《城市建设档案管理规定》《城市地下管线工程档案管理办法》等相关行政法规依法履职。

二、各区水务局、局属各相关单位、局机关各相关处室要做好水行政权力清单相应要素内容的调整工作；涉及水行政职权调整的，相关单位应当按照规定程序予以修改。

特此通知。

北京市水务局法制处
