# 北京市园林绿化局关于印发《新建简易低风险附属小型市政工程涉及占用绿化资源管理的暂行办法（试行）》的通知

各区园林绿化局、市自来水集团、市城市排水集团、国网北京市电力公司：

为进一步优化营商环境，提升审批服务能力，切实落实《市政府办公厅印发<关于优化新建社会投资简易低风险工程建设项目审批服务的若干规定>的通知》（京政办发〔2019〕10号）精神，现将我局研究制定的《新建简易低风险附属小型市政工程涉及占用绿化资源管理的暂行办法（试行）》印发给你们，请结合实际组织贯彻落实。

特此通知。
