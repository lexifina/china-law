# 北京市园林绿化局关于进一步加强林业有害生物防治检疫有关工作的通知

各区园林绿化局：

为进一步贯彻执行"谁经营、谁防治"的林业有害生物防治责任制度，提高林地绿地养护水平，保护造林绿化成果，对有关防治检疫工作部署通知如下：

一、大力加强产地检疫和调运复检工作

各区园林绿化局要进一步增强政治站位，强化责任担当，落实属地管理。各防治检疫机构要大力加强产地检疫、调入苗木跟踪复检、栽植检查巡查等各阶段、各环节工作，落实对栽植苗木事前、事中、事后监管职责，严格防止带疫苗木入坑穴，弱苗变病苗；要进一步加强检疫追溯平台应用，确保苗木来源清晰可查可追溯；要做好工程监理人员培训，履行监理职责中，严格检查"两证一签"，可以识别常见的检疫性、危险性林业有害生物及其危害状，发现检疫性有害生物及时上报。探索委托社会化专业化防治组织开展造林地栽植苗木的质量巡查；区防治检疫机构要加大行政执法力度，及时准确打击违法行为。

二、提高监测预报工作水平，做好防治技术培训与指导

各单位要根据辖区林业有害生物发生种类，在发生期做好林业有害生物的监测，及时发布监测信息，通过多种媒介，扩大监测预报信息的受众和覆盖面；各社会化专业化防治组织要实现第一时间发现第一时间除治；要强化技能培训，增强技术指导，不断提高监测、防治等专业水平。依法发送《限期除治通知书》，有效做好"谁经营，谁防治"的责任制度落实。

三、贯彻落实好新《农药管理条例》的实施，认真做好违规农药的自查自纠工作

各单位要认真组织开展"林用农药安全、合理使用技术指导"的服务工作，规范养护单位、有林单位和社会化专业化防治组织等的用药行为，严禁使用国家已经明令禁止生产、销售和使用的农药品种，不得使用国家"限制使用"的农药品种（国家禁止和限制使用农药名单见农业部公告），谨慎使用有可能对空气、水体、土壤、人畜、天敌昆虫、野生动物以及群众生活等造成严重影响的农药种类，轮换使用高效低毒的化学药剂和植物源类药剂，大力推广使用营林措施、生物防治、物理防治等绿色防控措施，减少化学药剂的使用量，推动土壤污染防治工作进程；要组织督促各养护单位开展对国家已经明令禁止生产、销售和使用的农药品种的自查自纠工作，对自查自纠过程中发现有库存、正在使用等要及时整改，并委托有危险化学品处理资质的公司进行专业化处理；要探索违规用药黑名单制度，组织开展对各单位使用农药、防治措施等情况检查，对违规使用农药的单位列入黑名单，对防治措施不到位的责令限期改正。我局近期将对违规使用农药进行专项检查。

四、加强安全教育宣传，做好应急防控队伍演练和物资储备，提高应急处置能力

要做好飞机防治、地面防治、药剂药械管理等方面的培训和安全教育，落实相关资金，开展应急防控队伍的日常演练，做好防治药剂、药械、防护用品等物资储备；开展林业有害生物应急防控预案和飞机防治应急事件预案的桌面推演和实战演练，车辆、防治器械、药剂管理，特别是飞机防治的各个环节要责任到人；做好世园会、外事活动、中华人民共和国成立70周年庆祝活动和节假日期间的应急备战等工作。

北京市园林绿化局
