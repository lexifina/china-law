# 北京市水务局关于全面落实供排水接入营商环境改革工作的函

各区人民政府：

按照市政府要求，为进一步做好2019年度优化营商环境工作，全面落实《关于进一步优化水、电、气、热、通讯接入服务措施的通知》（京管函〔2018〕618号）及《北京市水务局关于进一步做好供排水优化营商环境工作的通知》（京水务供〔2019〕4号）文件要求，现就世行评价指标、国家试评价指标（详见附件）及相关政策要求函告如下：

由于世界银行评价专家已经开展发放调查表、收集案例等工作，国家营商环境评价专家也将同时展开调查评价。为确保今年北京评价结果相比去年有所提升，恳请贵区责成区水务管理部门、市政管理部门、有关乡镇等部门（单位），根据上述文件要求做好辖区内供排水接入改革措施落地组织工作。

为更好地提升营商环境改善效果，在京管函〔2018〕618号文件基础上，市自来水集团和市排水集团正在推进对小型用户项目统一实施、免费接入措施，力保小型用户接水总时间（含管线施工）控制在20个工作日以内。请各区参照该措施，以20个工作日完成小型用户供排水接入为工作目标，并尽可能在5月以前形成足够多的项目案例。

特此致函。
