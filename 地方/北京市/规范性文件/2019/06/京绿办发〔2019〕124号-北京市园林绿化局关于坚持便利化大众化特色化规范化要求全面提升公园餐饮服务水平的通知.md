# 北京市园林绿化局关于坚持便利化大众化特色化规范化要求全面提升公园餐饮服务水平的通知

各区园林绿化局,各公园主管部门:

为了进一步提升公园的餐饮服务水平，增强人民群众的获得感、幸福感，按照市委、市政府领导批示精神，现就坚持便利化、大众化、特色化、规范化要求，全面提升公园餐饮服务水平相关工作通知如下：

一、编制餐饮服务规划

根据公园总体规划，在做好游客需求调研的基础上，研究编制公园餐饮服务规划，明确餐饮服务定位,科学、合理布局公园商业网点和经营服务内容，规范公园服务。

二、启动公园餐饮提升行动

制定公园餐饮近、中、远期工作时间表。将公园餐饮服务提升内容，纳入公园经营服务的大盘子统筹考虑，合理安排。坚持便利化、大众化、特色化、规范化原则，统一公园餐饮服务形象，推动品牌、产品、渠道及运营一体化，严格规范经营管理。加强餐饮服务空间设计，改造提升基础设施。

三、丰富餐饮等服务内容

注重"固定+流动"相结合原则。公园餐饮平时基本满足游客需求，但在重大节假日、公园淡旺季等特殊时段，不能满足游客需求时，可以根据不同时段分别制定不同方案，全方位、立体式满足游客日益提高的需求。

四、积极优化调整"老三样"食品

启动"老三样（香肠、面包、方便面）"食品提档升级工作。全面丰富预包装面包等食品的种类，提高食品品质。优化公园餐饮结构，丰富食品种类，各公园增加中式、西式快餐种类，提高丰富度和选择性。

五、各类餐饮点实施分类管理

按照正餐、简餐、小食品售卖三类进行监管。具备营商条件（电力充足、给排水功能完善）的餐饮点，可选择优质餐饮品牌企业合作，提供简餐服务；不具备条件的公园可探索引进公园周边餐饮的配送机制，提高餐饮服务水平。对于小而全的经营模式要加强整合，规范经营、一店一品，做到专而精。

各区园林绿化局要遵照市领导批示精神,结合辖区内公园实际,研究制定本区《提升公园餐饮服务工作方案》,加大检查督办力度，推进规划编制和实施，加快餐饮服务调整转型，促进公园文化餐饮发展，在一年内实现较大改观，让游客在公园里也能够体验到丰富多样的公园美味餐饮服务，并于12月31日前，将"方案"和公园餐饮服务工作提升情况报市园林绿化局公园管理处（邮箱:gyfjqc@yllhj.beijing.gov.cn）。
