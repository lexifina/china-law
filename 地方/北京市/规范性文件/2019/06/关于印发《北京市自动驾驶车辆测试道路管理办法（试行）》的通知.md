# 关于印发《北京市自动驾驶车辆测试道路管理办法（试行）》的通知

各有关单位:

为推动科技创新和自动驾驶产业发展，本市相继出台了《北京市关于加快推进自动驾驶车辆道路测试有关工作的指导意见（试行）》和《北京市自动驾驶车辆道路测试管理实施细则（试行）》等系列管理规定和技术要求，为了进一步加速技术迭代和产业升级，满足区域经济发展和企业科技创新需要，在确保安全的前提下为自动驾驶企业提供更为丰富的实际道路测试场景，本市制定了《北京市自动驾驶车辆测试道路管理办法（试行）》，经市政府同意，现印发给你们，请遵照执行。
