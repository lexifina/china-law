# 北京市水务局关于落实《北京市人民政府关于划定禁止使用高排放非道路移动机械区域的通告》的通知

各区水务局，局属各有关单位:

市政府于7月 25 日印发了《北京市人民政府关于划定禁止使用高排放非道路移动机械区域的通告》(京政发〔2019]10号，以下简称《通告》)，请各单位认真贯彻执行，现就进一步做好本市水务系统禁止使用高排放非道路移动机械工作提出如下要求:一、各单位要切实提高重视程度，认真做好《通告》的贯彻落实工作，将《通告》发至所属每个工程的建设单位、项目部、施工总承包、监理企业、分包企业、机械分包企业等单位，不漏单位不留死角。

二、各单位要按照《通告》要求严格做好监督管理，继续做好非道路移动机械台账登统计工作，工程日常检查中注重做好非道路移动机械管控工作，严禁在禁止使用高排放非道路移动机械区域的水利工地中使用高排放非道路移动机械，发现问题机械要立整立改，再次发现的要按照有关规定进行处理，问题严重的要移交有关部门予以处罚。对被有关部门处罚的施工企业、责任单位(个人)等，要予以约谈、曝光、停工整改、合同处罚等方式予以从重处罚，切实提高违法成本。

三、各施工单位是施工机械使用的主体责任人，要不折不扣的执行《通告》，要对每台进场施工的机械进行认真检查，不得在禁止区域内租(使)用超标机械，

各工程监理单位要严格履行监督职能，将工地使用机械情况

列入日常监理内容，发现问题机械要督促施工单位立即整改四、各工程建设单位(项目业主)在编制工程招投标文件中，必须对禁止使用高排放非道路移动机械予以限定并列入评标因素。

各区水务局要加强招投标文件备案核验工作，确保在每个工程施工招投标文件中，都将禁止使用高排放非道路移动机械予以限定并列入评标因素。

特此通知。
