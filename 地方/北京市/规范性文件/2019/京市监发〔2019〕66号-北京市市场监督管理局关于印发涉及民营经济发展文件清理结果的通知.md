# 北京市市场监督管理局关于印发涉及民营经济发展文件清理结果的通知

京市监发〔2019〕66号

各区局、分局，市局机关各处室，各稽查总队，各事业单位，各协会、学会：

根据《关于开展涉及民营经济发展的规章、规范性文件集中清理工作的通知》（京司法〔2018〕85号）要求，市局对截至2018年10月31日有效的文件进行了清理，决定废止5件涉及民营经济发展的规范性文件。现将废止目录予以印发，请认真贯彻执行。

附件：北京市市场监督管理局废止文件目录

北京市市场监督管理局

2019年5月14日
