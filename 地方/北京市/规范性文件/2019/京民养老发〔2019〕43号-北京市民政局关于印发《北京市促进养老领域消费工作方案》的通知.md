# 北京市民政局关于印发《北京市促进养老领域消费工作方案》的通知

京民养老发〔2019〕43号

各区民政局，市社会福利事务管理中心：

现将《北京市促进养老领域消费工作方案》印发给你们，请结合实际，按要求认真落实。

北京市民政局

2019年3月5日

(联系人：孙常虎，李树丛；联系电话：65395677)

北京市促进养老领域消费工作方案

为贯彻落实中共中央、国务院和民政部有关通知要求，根据《北京市人民政府关于培育扩大服务消费优化升级商品消费的实施意见》(京政发〔2017〕20号)，着力提高社会资本进入养老服务业的积极性，全面提升老年人消费能力，有效促进养老领域消费，制定以下工作方案。

一、总体目标

深入贯彻落实党的十九大精神和习近平总书记对加强养老服务的批示精神，通过加强养老设施建设，提升养老服务供给水平，补足养老消费短板，促进养老消费结构优化，提高老年人消费能力。通过消费升级进一步引领养老服务市场供给，实现更高水平的供需平衡，有力带动全市总消费增长。

二、主要措施

(一)增收减支，有效提高支付能力

1.提升老年人消费支出能力。通过完善社会福利制度体系，整合老年人福利保障政策，加强老年人分类保障力度，提升老年人消费支出能力。一是出台《北京市老年人能力综合评估实施办法》，对老年人能力综合情况和照料需求进行专业评估，并据此发放政府补贴、实施政府购买服务项目、落实相关补贴政策。二是出台我市老年人综合津贴补贴政策，建立困难老年人生活补贴、失能老年人护理补贴、高龄津贴等制度。

2.加强老年用品政策研究。致力于满足失能老年人对各类老年用品的需求，促进老年用品产业发展，研究制定老年人康复辅助器具示范推广和配置服务管理办法，研究失能老年人租赁购买使用康复辅助器具补贴、失能老年人康复服务等政策，减轻失能老年人家庭经济压力，促进老年产品用品市场发展。

(二)扩大养老供给，引导消费意愿

3.落实养老服务机构运营补贴扶持政策。利用信息化手段，发挥好市级社会福利管理平台作用，落实《北京市养老机构运营补贴管理办法》《北京市社区养老服务驿站运营扶持办法》。对营利性、非营利性养老机构实行同等运营支持政策，综合考虑机构接收服务对象身体状况、服务质量星级评定、诚信评价和医疗能力等因素实行差异化补贴，每床位每月最高补贴1050元。对社区养老服务驿站，从服务流量补贴、托养流量补贴、连锁运营补贴、运维支持等方面加大养老服务驿站运营扶持力度，促进驿站可持续发展。支持本市养老驿站连锁化品牌化运营，连锁运营一家养老驿站，可获得不低于5万元补贴。

4.继续加大养老服务机构建设支持力度。支持鼓励社会资本投资建设养老服务机构，会同市发展改革委、市财政局等部门出台社会力量一次性建设经费支持和集中式居家养老服务社区扩大试点的长效政策，破解投入大、成本高、运营困难、规划调整难、审批周期长等难题。依据《北京市基层公办养老机构建设资助工作实施办法》，围绕权属不清、养老性质不符等难点问题，利用政府固定资产投资和财政预算资金，推进基层公办养老机构改扩建，改善街乡镇公办养老机构软硬件条件。

5.抓好市政府2019年为民办实事项目。利用社会资本参与养老设施建设的投资热情，发挥政府资金的杠杆和撬动作用，通过政府提供场地或资源、给予资助形式，重点推动社会化方式建设社区居家养老设施，实现全年新开业运营150家社区养老服务驿站和20家养老照料中心的目标。一是开展社区养老服务驿站建设，由政府无偿提供设施并给予30万元一次性建设资金等方面的扶助支持，广泛动员社会各界力量积极参与；二是按照每个街道(乡镇)建设1所养老照料中心的总体安排，着力推动应建未建的空白区域养老照料中心建设，给予最高450万元建设资助，充分调动市场和社会力量参与建设，补齐设施供给短板，方便老年人就近养老。

6.加强养老服务人才队伍建设。会同相关部门出台《北京市养老服务人才培养培训实施办法》，以提升养老服务质量和养老服务行业持续健康发展为出发点，加强制度设计，改善服务供给，健全培训管理体系，进一步提升我市养老服务人才队伍素质。

(三)优化养老领域消费环境，保护老年人权益

7.加强养老服务行业“保健”市场监管，严厉打击各类违法行为，营造安全放心的养老服务市场消费环境和公平高效的营商环境，配合市场监管部门开展整治养老行业“保健”市场乱象行动，并探索建立长效机制，确实保障老年人权益。

8.细化落实《北京市养老服务机构监管办法(试行)》，制定养老机构会员制和押金管理使用办法，依据机构改革后的各部门职能，明确各部门职责和联席会议协商机制，建立养老服务机构综合监管制度。

9.加快推进养老服务业诚信体系建设。对套取骗取政府财政资金、违法违规开展金融活动、发生欺老虐老等11种情形，直接纳入信用黑名单，实行运营商禁入、联合惩戒等制度。对于特别严重失信的养老机构，在依法追究法律责任的同时，其法定代表人和主要负责人进入信用黑名单，实施信用惩戒，不得担任其他单位的法定代表人、负责人或者高级管理人员，亦不得在企业法人担任监事职务。推进养老行业诚信自律建设，指导北京养老行业协会进行换届并出台养老服务行业诚信自律公约。

三、工作要求

(一)加强组织领导。各区民政局要高度重视养老领域促进消费工作，在区政府的领导下，根据重点工作的部署，加强部门间协调机制，整体推进养老服务市场供给，加大对养老服务机构扶持力度，切实增强老年人消费能力，增加老年人获得感、幸福感。

(二)鼓励创新支持。支持区民政局创新激励养老领域促进消费工作措施，通过政府购买服务等方式，壮大养老消费市场活力，鼓励老年人就近养老。

(三)规范市场秩序。加强养老服务机构服务质量监管，严厉查处欺老虐老等行为，完善老年人投诉举报渠道，维护老年人合法权益。
