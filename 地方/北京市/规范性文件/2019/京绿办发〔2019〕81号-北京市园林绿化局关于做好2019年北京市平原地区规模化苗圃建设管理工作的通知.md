# 北京市园林绿化局关于做好2019年北京市平原地区规模化苗圃建设管理工作的通知

各区园林绿化局、各有关单位：

根据《关于加快平原地区规模化苗圃发展的意见》（京绿造发〔2014〕2号）有关要求，为加强规模化苗圃精细化管理，为加强规模化苗圃精细化管理，做大做强做优种苗产业，促进规模化苗圃带动农民就业增收，确保2019年北京市平原地区规模化苗圃建设管理工作顺利实施，现将有关事项通知如下：

一、2019年新建（新增）规模化苗圃申报

请各区园林绿化局按照《关于加快平原地区规模化苗圃发展的意见》（京绿造发〔2014〕2号）（以下简称《意见》）、《北京市园林绿化局关于印发北京市平原地区规模化苗圃建设管理办法、建设规范和经营管理合同范本的通知》（京绿造发〔2014〕13号）等相关文件要求，明确拟建规模化苗圃用地性质为非永久基本农田，开展实地勘察，组织编制和完成《规模化苗圃建设实施方案》初审，并于4月30日前报送市园林绿化局。

二、加强规模化苗圃经营期管理

针对规模化苗圃在经营期内，出现经营主体变更、退出及因征占用地面积减少等情况，根据《意见》和《北京市财政局 北京市园林绿化局关于印发<北京市平原地区规模化苗圃土地流转补助资金管理办法>的通知》（京财农〔2014〕2500号）（以下简称《资金管理办法》）要求实施管理。

（一）允许规模化苗圃变更经营主体

因经营管理需要变更经营主体的规模化苗圃，由变更双方经所在村集体、乡镇政府同意后，向区园林绿化局提出申请；区园林绿化局提交《规模化苗圃经营主体变更审核表》（附件1）等相关材料，报市园林绿化局批复后，与受让方、乡镇政府重新签订《北京市平原地区规模化苗圃经营管理合同》，同时终止原合同。

（二）允许规模化苗圃申请退出经营

经营期不满10年、拟申请退出经营的规模化苗圃，须经所在乡镇政府同意后，向区园林绿化局提出申请；区园林绿化局提交《规模化苗圃退出经营审核表》（附件2）等相关材料，报市园林绿化局批复后，方可退出。拟申请退出经营的规模化苗圃须符合下列条件：1. 永久基本农田范围内的规模化苗圃，应原路径退回已获得的土地流转补助资金；2. 非永久基本农田范围内的苗圃，可原路径退回已获得的土地流转补助资金或按《意见》及《资金管理办法》等文件规定，提前三年向所在区园林绿化局上报《苗木保留方案》。

（三）因政府征占用地导致面积减少的规模化苗圃，须提交相关材料，经区园林绿化局审核并报市园林绿化局备案。审核确认后的面积继续享受土地流转补助政策。

三、开展2018年度规模化苗圃市级抽查验收

根据《意见》及《北京市平原地区规模化苗圃建设检查验收细则（试行）》（京绿造发〔2014〕16号）要求，2018年度规模化苗圃的市级抽查验收工作，在各区全面检查验收基础上，实行量化考核打分。

（一）抽查验收对象比例

抽查对象：经各区检查验收合格的规模化苗圃。

抽查比例：市级抽查验收数量、面积均不低于总数的50%。

（二）抽查验收人员

市级验收小组由生态保护修复处、计财处、种苗站、林勘院等单位相关人员组成。

（三）抽查验收进度

4月上旬-5月下旬，具体时间另行通知。

（四）量化考核评分

2018年度市级抽查验收，重点考核苗圃面积、苗木栽植、用工情况、土壤污染防治及安全生产等内容，同时鼓励企业发挥社会效益、加强种质资源收集保存、新品种新技术应用等，制定《规模化苗圃市级抽查验收指标评分表》（附件3）。采取量化考核评分，引导规模化苗圃规范化经营，促进规模化苗圃精细化管理。

四、其他要求

（一）严格落实规模化苗圃生态惠民政策。根据《北京市园林绿化局关于进一步加强林业生态建设促进农民就业增收工作的通知》（京绿办发〔2019〕52号）要求，确保规模化苗圃招用本地农民工人数不低于总用工数量的50%，优先吸纳低收入劳动力，并按时足额支付农民工工资；规范档案管理，建立健全农民就业档案，明确管理制度，专人负责；建立就业台帐，填报本年度促进农民就业情况《规模化苗圃促进农民就业情况登记表》、《规模化苗圃促进农民就业情况统计表》，实行动态管理，每季度底15天内更新并上报至市园林绿化局。

（二）强化土地流转补助资金绩效管理。根据《资金管理办法》和《北京市财政局 北京市园林绿化局关于印发<北京市林业改革发展资金管理办法>的通知》（京财农〔2018〕2850号）要求，切实加快规模化苗圃实施进度和土地流转补助资金拨付进度，提高财政资金使用效益；加强补助资金分配、使用、管理情况的监督检查，发现问题及时纠正，并于6月30日前，组织对上一年度规模化苗圃土地流转补助资金使用情况开展自评工作，形成绩效自评报告。

（三）加强规模化苗圃安全生产工作。根据《北京市园林绿化局关于印发2019年公共安全工作要点的通知》（京绿办发〔2019〕4号）要求，高度重视安全生产管理工作，牢固树立安全发展理念；明确安全生产管理职责分工，全面落实“管行业必须管安全、管业务必须管安全、管生产经营单位必须管安全、谁主管谁负责”的要求，明确主抓苗圃安全生产管理责任人；加强苗圃企业安全生产监管，落实安全生产责任制，健全安全生产组织机构，加强在圃苗木养护、土壤及设施设备管理，严防各类事故发生。
