# 北京市规划和自然资源委员会关于印发《北京市规划和自然资源行政执法操作规程(试行)》的通知

各分局、机关各处室、委属各单位：

《北京市规划和自然资源行政执法操作规程(试行)》已经2019年10月22日第14次委主任办公会审议通过，现印发给你们，请遵照执行并做好各项相关工作。

特此通知。
