# 北京市市场监督管理局办公室关于推进瓶装液化石油气气瓶充装质量追溯信息系统建设工作的通知

京市监办发〔2020〕47号

各区市场监管局、北京经济技术开发区商务金融局、房山区燕山市场监管分局，市特检中心,各有关单位：

按照《国务院办公厅关于加快重要产品追溯体系建设的意见》（国办发〔2015〕95号）、《市场监管总局办公厅关于加快推进全国气瓶质量安全追溯体系建设的通知》（市监特设〔2019〕69号）、《北京市人民政府办公厅关于印发建立危险化学品集中管理体系若干意见的通知》（京政办发〔2013〕53号）、《北京市液化石油气发展建设专项规划》（京管发〔2020〕6号）等文件的要求，进一步提高充装单位安全管理水平，规范充装行为，预防安全事故，现就推进瓶装液化石油气气瓶充装质量追溯信息系统建设工作通知如下：

一、总体要求

以落实瓶装液化石油气充装安全主体责任为基础，以提升液化石油气充装质量安全为目标，对气瓶充装质量实施信息追溯管理，实现液化石油气气瓶充装“来源可循、去向可溯、安全可控、责任可查”，统一追溯标准，信息互通共享，提高监管效能，落实液化石油气充装质量追溯信息系统的建设要求，提升本市液化石油气充装安全管理工作水平，防范气瓶安全事故发生。

二、工作范围

本市区域范围内的液化石油气充装单位和承担本市范围气瓶检验的检验单位,按要求建立液化石油气气瓶充装质量追溯信息系统和与之配套的检验数据信息系统。

三、主要工作

（一）统一瓶装液化石油气气瓶充装质量追溯信息系统建设技术导则

各单位在开展瓶装液化石油气气瓶充装质量追溯信息系统建设过程中，应当按照《瓶装液化石油气气瓶充装质量追溯信息系统技术导则》（以下简称《技术导则》，见附件），落实充装追溯信息系统的要求，包括基本要求、标识要求、编码要求、信息采集要求、信息安全等相关技术导则。

（二）建设全市瓶装液化石油气充装质量信息追溯监管平台

根据国家及本市相关法律法规，结合本市实际情况及监管需求，建设北京市瓶装液化石油气充装质量信息追溯监管平台（以下简称“监管平台”），汇总气瓶充装、检验环节安全信息。同时监管平台预留气瓶流向信息等数据接口，为城市管理、交通运输、城管执法等部门开展相应环节信息化系统建设提供技术支撑。

（三）充装单位建设和完善本单位的瓶装液化石油气气瓶充装质量追溯信息系统

1.充装单位按照《技术导则》的要求，建立和完善本单位的瓶装液化石油气气瓶充装质量追溯信息系统以下简称“企业管理系统”），对本单位气瓶档案、充装质量、特种设备作业人员和气瓶流转等信息进行信息化管理。企业管理信息系统应具备可追溯、可交换、可查询和防篡改的要求，及时向监管平台报送数据信息。企业管理系统建设过程中，应为经营、运输等气瓶流转环节留有数据接口，为实现瓶装液化石油气全流程信息化管理做好准备。

2.充装单位负责对本单位建档的气瓶加装信息化标识，配备信息化标识手持识别终端设备。通过信息化手段，逐瓶记录充装前后检查、气瓶流向等信息，按要求生成充装过程相关信息，便于查询使用。落实气体气质检测的有关要求，并将气质检测报告上传监管平台。

3.充装单位应配备具有联锁控制功能的智能充装设备，例如智能充装电子称、智能充装角阀等。智能充装设备应与企业管理系统实现信息互联互通，通过扫描气瓶信息化标识完成对气瓶质量安全确认后，充装设备方可启动充装作业，避免人为因素导致不合格气瓶的充装。

（四）气瓶检验单位开展气瓶检验信息管理系统建设

气瓶检验单位要按照《技术导则》的要求，建设气瓶检验信息管理系统，系统应与监管平台实现互联互通，实现气瓶检验的信息动态更新。

四、工作分工

（一）市市场监管部门：指导全市瓶装液化石油气气瓶充装质量追溯信息系统建设工作，将有关要求纳入气瓶充装许可条件。

（二）区（地区）监管部门：对充装单位开展监督检查，督促气瓶充装、检验单位加快瓶装液化石油气气瓶充装质量追溯信息系统建设工作，将系统的建设使用情况纳入检查重点，严厉查处相关违法违规行为。

（三）充装单位：按照本通知要求完成系统建设工作，及时上传气瓶充装安全质量信息，确保数据真实、准确、完整。

（四）气瓶检验单位：按照本通知的要求，完成气瓶检验信息管理系统建设工作。定期检验报告完成后，及时向监管平台上传气瓶检验信息。

（五）液化石油气气瓶充装质量追溯信息系统项目建设的技术支持单位：北京石油交易所股份有限公司、北京市液化石油气公司、北京市特检中心作为项目建设的技术支持单位，应为瓶装液化石油气气瓶充装质量追溯信息系统建设提供技术支持和服务保障。同时负责监管平台的建设和运维，定期统计汇总相关数据，为监管工作提供技术支撑和保障。

五、进度要求

按照《北京市液化石油气发展建设专项规划》相关要求，加快推进气瓶充装质量追溯信息系统建设，实现气瓶充装安全可追溯管理。自通知发布之日起，液化石油气充装单位申请气瓶充装许可的新增和延续，应当具备符合要求的充装质量追溯信息系统。2020年7月15日前，北京石油交易所股份有限公司牵头完成监管平台的建设工作；液化石油气充装单位完成瓶装液化石油气气瓶充装质量追溯信息系统建设工作；气瓶检验单位完成检验信息化系统建设工作。充装质量追溯信息系统建成后，充装单位不得充装未纳入充装质量追溯信息系统的液化石油气气瓶；气瓶检验单位不得检验未纳入充装质量追溯信息系统的液化石油气气瓶。

六、工作要求

（一）高度重视，强化组织

瓶装液化石油气气瓶充装质量追溯信息系统建设工作，是我市液化石油气改革工作的一项重要举措，也是全市危险化学品集中管理体系建设的重要内容。各区级市场监督管理部门务必要高度重视，指定专人负责，确保相关工作要求落实到位。

（二）严格落实，强化监管

各区（地区）监管部门要加大对瓶装液化石油气充装单位的监督检查力度，督促各相关单位，按照本通知的要求，结合自身实际，制定工作方案，做好资金保障，加快完成系统建设工作。

（三）积极引导，强化宣传

在系统建设过程中要充分利用各种媒体，加大政策宣传力度，加强正面引导，为系统建设工作的顺利推进，营造良好的安全氛围。要抓好正反典型的宣传，对于工作推进力度大、工作成效好的单位，给予正面宣传报道；对于工作推进不力的，通过媒体进行曝光。
