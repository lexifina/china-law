# 通化市人民政府办公室关于印发改革完善医疗卫生行业综合监管制度实施方案的通知

通化市人民政府办公室关于印发改革完善

医疗卫生行业综合监管制度实施方案的通知

通市政办发〔2019〕12号

各县（市、区）人民政府，通化医药高新区管委会，吉林通化国际内陆港务区管委会，市政府各委办局、各直属单位：

《通化市人民政府办公室关于改革完善医疗卫生行业综合监管制度实施方案》已经市政府同意，现印发给你们，请认真组织实施。

通化市人民政府办公室

2019年8月6日

（此件公开发布）

通化市改革完善医疗卫生行业

综合监管制度实施方案

为建立严格规范的医疗卫生行业综合监管制度，根据《吉林省人民政府办公厅关于改革完善医疗卫生行业综合监管制度的实施意见》（吉政办发〔2019〕15号）精神，结合全市实际，制定本实施方案。

一、工作目标

到2020年，建立职责明确、分工协作、科学有效的综合监管制度，健全机构自治、行业自律、政府监管、社会监督相结合的多元化综合监管体系，建成专业高效、统一规范、文明公正的卫生健康执法监督队伍，实现医疗卫生行业综合监管法治化、规范化、常态化。

二、重点任务

（一）构建综合监管体系，明确监管主体和责任。

1.加强党的领导。公立医院实行党委领导下的院长负责制，充分发挥党委把方向、管大局、作决策、促改革、保落实的领导作用。加强公立医院领导班子及成员履行政治责任、行使职权、党风廉政建设和作风建设，提高履职尽责能力，加强社会办医党组织建设。（市卫生健康委、市中医药管理局负责）

2.强化政府主导责任。深入推进“放管服”改革，充分发挥政府在法治建设、行业规划、标准制定、行业准入、行政执法等方面的主导作用。建立由市卫生健康委牵头，相关部门为成员单位的通化市医疗卫生行业综合监管联席会议制度，负责统筹综合监管的协调、指导和医疗卫生服务重大案件查处等工作。（市卫生健康委牵头，相关部门参与）

3.落实医疗卫生机构自我管理主体责任。医疗卫生机构对本机构依法执业、规范服务、医疗质量、安全生产、行风建设等承担主体责任，其主要负责人是第一责任人。（市卫生健康委牵头，市中医药管理局、市公安局、市民政局、市财政局、市司法局、通化海关、通化军分区保障处参与）

4.发挥行业组织自律作用。积极培育医疗卫生行业组织，引导和支持其提升专业化水平和公信力。（市卫生健康委牵头，相关部门参与）

5.加强社会监督。支持社会各界参与监督，引入第三方监督机制，积极开展第三方患者满意度调查。发挥专业机构和中介组织的技术支撑和社会监督作用。（市卫生健康委牵头，相关部门参与）

（二）完善综合监管措施，加强全过程监管。

6.加强卫生健康行政秩序监管。各级卫生健康行政部门依据现行卫生健康法律法规，加强对医疗机构审批、校验、重点专科、等级评审、项目资金和大型设备购置等重要岗位的监管以及安全生产、社会综合治理、重大安全事件处置等重点事项的监管。（市卫生健康委、市中医药管理局牵头，相关部门参与）

7.优化医疗卫生服务要素准入。加快推进医药卫生领域行政审批制度改革，相关部门按职责建立行政审批事项清单并向社会公示。优化医疗卫生机构、从业人员以及医疗技术、药品、医疗器械等准入和行政许可流程，简化医疗机构审批申请手续。（市卫生健康委、市中医药局、市发展改革委、市民政局、市市场监管局、通化军分区保障处分别负责，市医保局、市商务局参与）

8.加强医疗服务质量和安全监管。完善全市医疗质量管理与控制制度建设和组织体系。发挥各专业医疗质量控制中心作用，实现医疗质量闭环管理。以医疗机构自我质量管理为基础，严格落实医疗质量和安全管理核心制度。（市卫生健康委、市中医药管理局负责）

严格执行药品和医用耗材招标采购政策、实行网上公开交易，严厉打击非法渠道购销药品、价格欺诈、价格垄断以及伪造、虚开发票等违法违规行为，严肃查处公立医疗机构不执行“两票制”和企业“过票洗钱”行为。（市卫生健康委、市市场监管局、市医保局、市税务局、市中医药管理局负责）

9.加强医疗卫生机构运行监管。重点监管公立医疗卫生机构破除以药养医机制，落实药品、耗材采购制度和医疗服务价格政策，建立科学合理的内部薪酬分配机制，控制医疗费用不合理增长。加大对公立医院人员支出、基本建设等监管力度。审计机关依法对医疗卫生机构开展审计监督。（市卫生健康委、市财政局、市审计局、市中医药管理局分别负责，市发展改革委、市人力资源社会保障局、市医保局、通化军分区保障处参与）

加强对非营利性医疗机构资金结余使用等方面的监督管理，其所得收入除符合规定的合理支出外，只能用于医疗机构的继续发展。加强对营利性医疗机构盈利率的管控，依法公开服务价格等信息。（市卫生健康委、市发展改革委、市民政局、市财政局、市税务局、市市场监管局、市医保局、市中医药管理局分别负责）

强化医疗保险的监督和控费作用。积极发挥各类医疗保险对医疗行为的引导与监督制约作用。严厉打击欺诈骗保行为，保障医保基金安全。（市医保局、通化银保监分局分别负责，市发展改革委、市财政局、市卫生健康委、市中医药管理局参与）

10.加强公共卫生服务监管。依法加强对环境保护、食品安全、饮用水卫生等公共卫生服务的监管。加强对国家基本公共卫生服务和重大公共卫生服务项目实施情况的绩效考核和监管。（市卫生健康委、市发展改革委、市财政局、市教育局、市中医药管理局、市生态环境局、市住房城乡建设局、市城市管理执法局、市自然资源局、市水利局、通化海关、市市场监管局、通化军分区保障处分别负责）

11.加强医疗卫生从业人员监管。加大医疗卫生行业行风建设力度，落实医务人员医德考评制度。继续加强“九不准”等相关制度执行。严肃查处违法违规和违反医德医风的执业行为，将对违法违规行为的处罚纳入医疗卫生行业信用体系。（市卫生健康委、市中医药管理局、通化军分区保障处分别负责）

12.加强医疗卫生服务行业秩序监管。建立医疗卫生服务行业行政处罚和刑事司法衔接联席会议、失信人员联合惩戒等联防联控机制。严厉打击医药购销领域商业贿赂、涉医违法犯罪和骗取、套取公共卫生资金行为。（市卫生健康委、市委宣传部、市网信办、市市场监管局、市公安局、市商务局、市司法局、市中医药管理局、通化海关、市城市管理执法局、市医保局、通化军分区保障处分别负责，市法院、市检察院参与）

13.加强健康产业监管。落实《通化市人民政府办公室关于印发通化市大健康产业五年行动计划（2016—2020年）的通知》（通市政办发〔2016〕35号），建立健全覆盖医疗健康产业全链条、全流程的包容、审慎、有效监管机制，明确监管责任，提高监测能力。（市卫生健康委、市中医药管理局、市网信办、市发展改革委、市科技局、市民政局、市财政局、市工业和信息化局、市商务局、市文化广电和旅游局、市税务局、市市场监管局、市自然资源局、市城市管理执法局、市水利局、市教育局、市医保局、通化银保监分局分别负责）

（三）创新综合监管机制，提升监管水平和效能。

14.完善规范行政执法机制。各级监管部门按照法律法规要求，规范重大执法决定法制审核、执法检查形式、执法流程、执法文书制作、执法结果公示等内容。落实执法责任制和责任追究制，建立容错纠错和免责机制。（市卫生健康委、市司法局、市城市管理执法局、市中医药管理局分别负责）

15.全面推行“双随机、一公开”抽查机制。完善抽查清单，健全检查对象库、检查人员名录库。科学制定年度抽查计划和目录，公开抽检情况及查处结果，推进医疗卫生行业跨部门综合执法、联合监管。（市卫生健康委、市工业和信息化局、市税务局、市市场监管局、市医保局、市中医药管理局分别负责）

16.建立健全医疗卫生行业信用机制。将医疗卫生行业行政许可、行政处罚等信用信息纳入全国信用信息共享平台。对进入“黑名单”的机构，纳入重点监管名单。建立健全依法联合惩戒体系。（市卫生健康委、市公安局、市人力资源社会保障局、市工业和信息化局、市商务局、市中医药管理局、人民银行通化市中心支行、通化海关、市政务服务和数字化局、市税务局、市市场监管局、市医保局、通化军分区保障处、市法院、市检察院分别负责）

（四）加强综合监管保障，确保监管长效有力。

17.建立综合监管督查机制。建立由市卫生健康委牵头，相关部门参与的医疗卫生行业综合监管督查机制，每年对各县（市、区）贯彻落实医疗卫生行业综合监管相关政策、突出问题及处理、综合监管责任落实、政府分管负责人的责任落实等情况进行督查。对存在突出问题的地方和负有监管职责的有关部门，可不定期开展专项督查。（市卫生健康委负责，相关部门参与）

18.建立综合监管结果协同运用机制。进一步强化综合监管结果统筹运用，将综合监管结果与医疗卫生机构校验、等级评审、医保定点协议管理、重点专科评选、财政投入等挂钩，从业人员医疗卫生服务监管结果与职称评聘、职务晋升、评先评优、绩效分配等挂钩。（市卫生健康委、市财政局、市人力资源社会保障局、通化海关、市市场监管局、市医保局、市中医药管理局、通化军分区保障处分别负责）

三、工作步骤

（一）制度建设阶段（2019年6月至2019年12月）。各有关部门按照职责制定各项监管制度，落实综合监管各项措施，建立健全综合监管协调、督查、信用等机制。

（二）全面实施阶段（2020年1月至2020年9月）。各有关部门按照职责，加强医疗卫生行业综合监管，积极开展联合检查、联合执法、联合惩戒、联合督查，大力推进综合监管队伍、能力、信息化等建设。

（三）巩固提升阶段（2020年10月至2020年12月）。针对综合监管制度运行中存在的问题和不足，结合新形势、新情况、新要求，进一步完善监管措施，健全监管机制，提升全市医疗卫生行业综合监管水平。

四、组织实施

（一）加强组织领导。各地区、各部门要加强组织领导，结合部门和辖区实际，细化工作方案，明确责任，强化措施，确保各项工作落实到位。

（二）强化责任落实。卫生健康、发展改革、教育、公安、民政、司法、财政、人力资源社会保障、医保、生态环境、住房城乡建设、自然资源、商务、人民银行通化市中心支行、审计、海关、税务、市场监管、通化银保监、部队卫生等部门依法承担相应监管职责，确保工作责任到位、措施到位。

（三）严肃追责问责。严肃查处监管工作中的失职渎职行为，对国家公职人员依法依规依纪追究责任；涉嫌犯罪的，依法移交司法机关追究刑事责任。对发现问题多、社会反映强烈、监管效果不明显的单位和人员，要严肃追责问责，并通报典型案例，形成有力震慑。
