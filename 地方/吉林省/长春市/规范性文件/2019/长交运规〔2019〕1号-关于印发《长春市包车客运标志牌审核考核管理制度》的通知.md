# 关于印发《长春市包车客运标志牌审核考核管理制度》的通知

长春市交通运输局文件

长交运规〔2019〕1 号长春市交通运输局关于印发长春市包车客运标志牌审核考核管理制度的通知（2019 年11 月6 日长交运规〔2019〕1 号文发布，根据2021 年9 月27 日《长春市交通运输局关于公布行政规范性文件清理结果的决定》修正）各县（市、区）交通运输局、客运、旅游企业：

现将《长春市包车客运标志牌审核考核管理制度》，印发给你们，请遵照执行。

长春市交通运输局

2019 年11 月6 日长春市包车客运标志牌审核考核管理制度

第一章总则

第一条依据交通运输部《包车客运管理信息系统建设及管理规范》及吉林省互联网+道路运政服务系统中包车客运管理信息子系统的有关规定，为进一步规范我市包车客运标志牌备案审核管理工作，更好的为道路旅客运输企业提供方便、便捷的服务，提高全行业工作效率，及时审核包车客运标志牌，制定本办法。

第二条全市包车客运标志牌备案审核应使用吉林省互联网+道路运政服务系统中包车客运管理信息子系统实施备案审核，按审核方式分为自动审核和人工审核。

自动审核指系统通过比对数据库内道路旅客运输企业的有关信息，达到系统设定的有关要求的，自动通过审核；

达不到的，自动判断为审核不通过。

人工审核指市及县（市、区）级交通运输主管部门或者相关机构包车标志牌管理人员，通过登录吉林省互联网+道路运政服务系统中包车客运管理信息子系统后查看备案申请，人工确认是否通过审核。

第三条包车客运标志牌的审核适用于长春市车籍所在地为长春本级及县（市、区）班线客运和旅游包车客运企业所属车辆从事包车客运经营活动的包车客运标志牌的备案审核。自动审核权限全天24 小时开放，人工审核时间为工作日时间（上午8:00 至下午16:30，如工作时间调整按市政府确定时间为准）。

第二章包车标志牌使用管理

第四条市级交通运输综合行政执法机构负责对全市道路旅客运输企业提交的省际、市际、县际包车客运标志牌申请实施审核。

县（市、区）交通运输主管部门或者相关机构负责对辖区道路旅客运输企业提交的县内包车客运标志牌申请实施审核。

第五条市级交通运输综合行政执法机构负责向各县（市、区）交通运输主管部门或者相关机构发放吉林省互联网+道路运政服务系统包车客运标志牌审核账号；负责向客运、旅游包车企业发放吉林省互联网+道路运政服务系统包车客运标志牌自动审核账号。

第六条市级交通运输综合行政执法机构根据全市包车客运标志牌使用情况，制定包车客运标志牌印制计划。安排专人负责包车客运标志牌的申领、发放、管理工作，建立入库和发放包车客运标志牌台账，并将包车客运标志牌号录入吉林省互联网+道路运政服务系统。对县（市、区）交通运输主管部门或者相关机构及市区道路旅客运输企业发放包车客运标志牌，实行包车客运标志牌交旧领新制度。

县（市、区）交通运输主管部门或者相关机构设立专人负责对申领的包车客运标志牌号录入吉林省互联网+道路运政服务系统。对辖区道路旅客运输企业发放包车客运标志牌，实行包车客运标志牌交旧领新制度。建立入库和发放包车客运标志牌台账，做好包车标志牌的使用监管工作。

第七条道路旅客运输企业要建立包车客运标志牌使用登记制度，安排专人管理标志牌的领用签发工作，领用人要签字确认，交旧领新，严禁发放空白旅游包车客运标志牌。

包车标志牌必须使用与系统相连打印机打印，手工填写无效。

包车标志牌打印后，加盖企业和签发人印章。执行完旅游包车任务后，企业应及时收回标志牌并在系统中予以核销；对未核销的车辆和人员，不得派发其他旅游包车任务；严禁“一车多牌”和重复打印旅游包车客运标志牌。对已使用、作废的包车标志牌要及时收回、上交至交通运输主管部门或者相关机构。

第三章包车标志牌备案审核

第八条道路旅客运输企业登录系统进行旅游包车客运备案申请，填写备案信息，要确保备案信息的内容真实、准确，不得弄虚作假。旅游包车客运任务有效期一般不超过15天；起始地、终到地必须有一端在车籍地。每一运次的旅游包车客运任务完成之前，相关车辆和驾驶员在系统中应处于锁定状态，无法再用同一车辆或驾驶员申请下一运次的标志牌。

第九条为促进道路旅客运输企业落实好安全主体责任，提升管理和执行能力，推进全市道路旅客运输企业包车标志牌自动审核的准入和退出机制，对卫星定位动态监控使用情况、行业日常安全检查整改情况、行管部门交办日常工作完成情况等方面实行考核管理。市级交通运输综合行政执法机构次日对道路旅客运输企业自动审核包车客运标志牌进行抽查，确保道路旅客运输企业包车标志牌自动审核规范、有序开展。

有下列情形之一的，将直接收回道路旅客运输企业自动审核权限，改为人工审核。

（一）行管部门抽查包车标志牌备案信息不规范的；

（二）卫星定位动态监控人员查岗率月低于95%、车辆入网率月低于95%、营运车辆在线率月低于95% 、轨迹完整率月低于80%的；

（三）动态监控中心通报企业所属营运车辆存在违规行为的；

（四）上一自然月违法抄告车辆两次以上的；

（五）行管部门日常安全检查发现问题或安全隐患的；

（六）对从事道路旅客运输企业经营一年以上未通过三级以上安全生产标准化评定的或已通过三级以上安全生产标准化有效期超期的；

（七）其他不宜实施自动审核的。

第十条遇有国家重大会议、活动期间及特殊时期，包车标志牌由自动审核改为人工审核，并按照国家、省市有关要求实施审核。

第十一条本制度自印发之日起执行，由市交通运输局负责解释。
