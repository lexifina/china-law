# 第三十四条

（违法使用的处罚）物业服务企业或其他管理人违反本办法第三十一条第一款的规定，虚列维修工程项目或虚增维修工程量，由市或区（市）县房产行政管理部门责令限期改正；逾期不改正的，处虚列或虚增金额2倍以下罚款，但最高罚款金额不得超过10万元。业主委员会或相关业主有前款行为，由市或区（市）县房产行政管理部门责令限期改正；逾期不改正的，对业主委员会成员或相关业主给予警告。物业服务企业或其他管理人、业主委员会或相关业主未将已拨付的专项维修资金专项用于使用方案所列维修项目的，由市或区（市）县房产行政管理部门责令限期改正；逾期不改正的，对物业服务企业或其他管理人、业主委员会成员或相关业主予以警告，并责令退回资金。
