# 攀枝花市人民政府办公室关于分解落实2014年食品安全工作责任的通知

市级有关部门：

根据省政府与市政府签订的《四川省2014年食品安全责任书》，现结合我市实际，现将省政府下达的食品安全工作责任分解到市级有关部门（《2014年市级部门食品安全工作责任分解表》附后），请认真组织贯彻落实。

附件：《2014年市级部门食品安全工作责任分解表》

攀枝花市人民政府办公室

2014年10月16日
