# 攀枝花市人民政府办公室关于下达全市“十三五”规划前期重大课题研究任务的通知

钒钛高新技术园区管委会，市级有关部门：

即将进入的“十三五”时期，是我市全面建设小康社会的关键时期。根据全市“十三五”规划编制工作安排，今年重点是开展“十三五”规划前期工作，完成各项重大课题研究，在此基础上形成“十三五”规划的基本思路。全市“十三五”规划前期重大课题已经市政府同意，现下达给你们，并将有关事项通知要求如下：

一、加强组织领导。各重大课题牵头部门、单位（详见附件单位）要及时成立研究起草小组，确定负责人、参与人和执笔人，做到工作明确，、任务落实，、责任到人，。并于2014年10月27日前将课题组联络员名单报全市“十三五”规划工作领导小组办公室，联系人：市发展改革委综合处付建平，联系电话：3324235。

二、突出调查研究。各重大课题牵头部门（单位）要加强调查研究，多借鉴国内外、省内先进城市的经验，多吸收国内、省内有关专家的意见，充分把握正确的研究角度和方向，提出的工作思路要具有较强的前瞻性、可行性。

三、完成课题研究的时间安排。各重大课题牵头部门（单位详见附件）于11月30日前提交中期成果报告并做好评审准备工作，2014年12月20日前将最终研究报告提交市“十三五”规划工作领导小组办公室。

请各课题牵头部门（单位）按照上述要求认真组织开展工作，按期完成各项任务。市发展改革委负责“十三五”规划前期重大课题研究的综合协调工作。
