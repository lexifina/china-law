# 攀枝花市人民政府办公室关于印发《2017年攀枝花市政府网站绩效评估指标体系》的通知

各县（区）人民政府，市级各部门：

现将《2017 年攀枝花市政府网站绩效评估指标体系》印发你们，请认真对照指标，结合《2017 年政务公开考核办法》（攀办函〔2017〕19 号）和《攀枝花市 2017 年政务公开工作分工方案》（攀办发〔2017〕84 号）文件要求，切实加强政府网站信息内容建设，不断深化政务公开，提高在线办事能力，增强政民互动，确保国家、省、市政府网站普查工作取得实效。

攀枝花市人民政府办公室

2017 年 7 月 13 日
