# 攀枝花市人民政府办公室关于进一步加强信访维稳工作的通知

攀枝花市人民政府办公室

关于进一步加强信访维稳工作的通知

各县（区）人民政府，市级各部门，各企事业单位：

为迎接党的十九大胜利召开，在非常之时，必须用非常之举、行非常之策解决涉稳信访矛盾问题，切实做好近期信访维稳工作，全力实现我市信访维稳“ 四个确保不发生” 。现就有关事项通知如下。

一、统一思想，提高认识

迎接党的十九大隆重召开是党和国家政治生活中的一件大事，做好党的十九大期间信访维稳工作责任重大、任务艰巨、使命光荣。各级各部门要坚定不移地把思想、行动统一到中央、省、市关于信访维稳工作的决策部署上来，站在讲政治、讲大局的高度，以破釜沉舟的决心、超常规的措施和严明过硬的纪律，全力以赴做好党的十九大期间信访维稳工作。

二、加强领导，明确重点

各级各部门务必高度重视，充分认识信访维稳工作的严峻性、复杂性、艰巨性和特殊性。深刻理解依法、及时、就地解决群众合理诉求，促进社会和谐稳定的重要性。加强组织领导，切实做好当前信访维稳各项工作。一是克服麻痹松懈思想，坚持常抓不懈、严抓不松、持续用力。进一步明确主攻方向和工作重点，找准工作着力点和切入点，集中精力做好源头治理、矛盾排查、化解稳控、信息灵通、依法处置等工作，聚焦聚力抓好落实。二是进一步强化源头治理，做好基层基础工作。坚持科学民主决策，落实重大决策社会稳定风险评估制度，加强社情民意收集研判，将群众路线贯彻到信访维稳工作全过程。三是进一步强化矛盾排查。严格落实三级矛盾纠纷排查化解工作制度和每天排查、研判、报告制度。重点聚焦城乡建设、环境保护和脱贫攻坚等事关群众切身利益的问题，做到全覆盖、无疏漏排查。四是加大化解稳控力度。按照“ 属地管理、分级负责，谁主管、谁负责” 原则，严格落实“ 一岗双责” 责任，进一步压紧压实各级领导干部和基层责任，分类化解涉稳信访问题，全力做好疏导和稳控工作。五是进一步强化信息灵通，及时收集各类情报信息。加强对苗头性、倾向性、预警性情报信息的收集和研判，做到心中有数、超前预防，牢牢把握工作主动权。六是进一步强化依法处置，坚持原则性和灵活性相统一，充分运用法治思维和法治方式依法治访。提前谋划布局，坚守法治底线，重点对非法聚集、打、砸、抢或者围攻市、县党委政府的要依法处置。高压严打非访、闹访、缠访等信访维稳领域违法犯罪活动。

三、强化责任，扎实推进

按照全省统一部署，从 8 月开始，集中 3 个月时间，全面开展信访维稳问题排查化解“ 百日攻坚战” ，专项开展大排查、大接访、大包案、大化解、大督导“ 五大行动” 。各级各部门要进一步增强政治敏锐性，强化责任担当，集中力量打赢“ 百日攻坚战” ，确保不发生恶性社会治安事件和群体性事件，确保不发生大规模进京赴省非访集访事件，并扎实抓好以下几项行动。

（一）大排查行动。要对本系统、本地区范围内矛盾纠纷加强排查，特别是对部分军队退役人员、涉众型经济案件利益受损人员、“ 三供一业” 改造涉及人员、失独家庭涉及人员等重点群体，房地产、劳动保障、水电移民等问题集中领域，以及近年来多次进京赴省非正常上访、集访、缠访、闹访的人员进行全面排查，密切关注舆情信息，实行动态跟踪监管，确保人员吸附在当地，矛盾化解在初始。

（二）大接访行动。从现在开始，县、乡两级每天务必要有 1 名党政负责同志接待群众来访，主动回应群众诉求，对所接待涉稳信访问题要全程负责、一盯到底。各级各部门要逐人逐项做深做细工作，做到思想见面一人不漏、困难帮扶一个不漏、管理措施一条不漏。同时强化领导干部走访下访工作，促进重点信访维稳问题及时、就地解决。

（三）大包案行动。对省上交办的 27 件涉稳信访问题，市级排查梳理的 302 件涉稳信访突出问题、12 件重点环境信访举报案件和 273 个不稳定群体，按照“ 清单制+责任制” 要求，明确市领导包案。各责任单位要按照“ 谁负责、谁化解、谁稳控” 要求，最大限度促进矛盾有效化解，问题有序解决。

（四）大化解行动。要深入研究和梳理政策，找准问题成因，制定包案化解工作方案，明确时间表、任务书，挂图作战、逐案攻坚、精准施策，按照“ 有政策就高不就低、无政策依法依规办” 的原则，综合运用法律、政策、经济、行政等手段，因时、因情、因地落实对策措施，强力推动涉稳信访问题有效解决。

（五）大督导行动。涉稳信访问题实行销号制管理，包案领导带案下访，强化督导检查，督促各级各部门及时有效化解。严格实行责任追究制和倒查制，对因领导重视不够、责任措施不落实、工作不到位等导致发生重大群体性事件，造成恶劣社会影响或严重后果的单位和有关人员，将严肃追究责任。

四、强化督查，严明纪律从 8 月开始，市政府将启动信访维稳工作通报、约谈、问责机制，根据市信联办每月通报的信访维稳工作完成情况，约谈相关县（区）和市级部门的责任领导。在当月通报中排名最后一名的，由分管信访维稳工作的副市长对县（区）政府和市级部门主要领导进行约谈；连续两次通报排名最后一名的，由常务副市长、分管联系副市长和分管信访维稳工作的副市长对县（区）政府和市级部门主要领导进行约谈；连续三次通报排名最后一名的，由市政府主要领导、分管联系副市长和分管信访维稳工作的副市长对县（区）政府和市级部门主要领导进行约谈，并将严肃问责追责。被约谈单位要坚持问题导向，明确工作要求，细化整改措施，注重整改实效。市信访、维稳部门要加强工作指导督查力度，及时收集反馈信息，为党委政府决策提供意见建议。

从 8 月至党的十九大结束，市政府将每月听取涉稳信访问题包案化解工作推进情况。各级各部门要集中资源和力量，持续化解涉稳信访案件，按要求定期上报案件办理情况，切实推动涉稳信访问题妥善解决。
