# 九寨沟县人民政府办公室关于认真做好“五·一”小长假旅游安全与旅游应急保障工作的通知

各乡（镇）人民政府，各涉旅部门：

为切实做好我县旅游安全与旅游应急保障工作，确保2017年“五·一”小长假（2017年4月29日至5月1日）全县旅游市场持续稳定，现将有关事宜通知如下：

一、强化责任意识，维护安全形势稳定。各乡（镇）、各涉旅部门要充分认识到做好旅游安全与旅游应急保障工作的重要意义，强化责任意识和担当意识，加强组织领导，周密研究部署，狠抓责任和防范措施落实，坚决防止和遏制重特大涉旅事故发生。

二、开展安全检查，及时消除安全隐患。各涉旅部门、相关乡（镇）要进一步加强安全防范，督促企业认真落实主体责任，加强安全管理。县旅游发展局及相关涉旅部门要在节前组织开展拉网式旅游市场综合执法大检查，及时消除安全隐患。

三、加强值班值守，做好旅游应急处置。各涉旅部门、相关乡（镇）要切实保障九寨沟县涉旅投诉举报平台24小时运转和0837—7712980投诉举报电话24小时畅通，要加强值班值守，严格执行领导干部到岗带班和24小时值班制度，及时处置涉旅投诉平台交办的事件。加大与九管局、大九旅集团协调力度，进一步完善县、局、司、镇旅游高峰应急响应机制，为有效应对“五·一”小长假奠定坚实基础。

四、加强督促检查，严肃旅游工作纪律。县目标督查办和县监察局要对值班工作进行检查，重点检查值班制度是否健全，值班人员是否到位，领导带班制度是否落实，突发事件信息报告和处理是否及时，值班通信工具是否完备畅通等，针对检查发现的问题要立即进行整改，对整改不力的乡（镇）、部门要在全县范围内通报批评，造成严重影响的将追究主要领导和相关人员责任。

请各乡（镇）、各涉旅部门于4月27日（星期四）前将“五·一”小长假值班安排表报政府办（联系人：刘进；联系电话：7731577；电子邮箱：jzgzfb@163.com）。
