# 九寨沟县人民政府办公室关于同意办理永乐镇清平三村村民李林强国有土地使用权设定登记手续的批复

县国土资源局：

你局《关于永乐镇清平三村村民李林强缴纳土地出让金的请示》（九国土资源〔2017〕80号）收悉，经县人民政府研究，原则同意在李林强缴清土地出让金后由不动产登记中心为其办理出让国有土地使用权设定登记手续。该宗地位于永乐镇好吃街，使用权类型为出让，用途为商业，使用期限为40年，使用权面积为183.68平方米。请你局严格按照有关法律和程序办理。

此  复。
