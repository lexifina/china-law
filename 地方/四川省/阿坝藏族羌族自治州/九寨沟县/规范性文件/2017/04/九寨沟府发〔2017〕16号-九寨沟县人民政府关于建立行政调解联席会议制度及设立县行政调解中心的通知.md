# 九寨沟县人民政府关于建立行政调解联席会议制度及设立县行政调解中心的通知

各乡（镇）人民政府，县级各部门：

为充分发挥行政调解在化解社会矛盾中的重要作用，维护社会稳定，促进我县经济发展和社会和谐，根据阿坝州法制办《关于做好2017年全州行政调解工作的通知》精神，经县人民政府研究，决定建立九寨沟县行政调解工作联席会议制度并设立九寨沟县行政调解中心。现将有关事项通知如下：

一、联席会议

（一）联席会议召集

总召集人：刘今朝    县委常委、县政府常务副县长

召 集 人：何富民    县政府法制办主任

成员单位：县发改局、县经信局、县教育局、县科技局、县民宗局、县公安局、县监察局、县民政局、县司县法局、县财政局、县人社局、县国土局、县环林局、县住建局、交通局、县农水局、县工质食药监局、县文广新局、县卫计局、县审计局、县安监局、县统计局、县城管局、县旅发局、县扶贫移民局、县政府法制办公室。

联席会议可邀请县人大代表、县政协委员及县内宗教界人士、基层社区或人民调解组织人员参加。

联席会议根据工作需要，由总召集人或召集人适时召集，全体或部分成员单位参加，各成员单位主要负责人为本单位行政调解工作第一责任人参加政府行政调解联席会议，各成员单位法制工作人员为联席会议联络员，负责本部门行政调解的具体工作。

（二）联席会议职责

1.定期研究解决我县在开展行政调解工作中涉及的问题，指导、协调重大复杂争议纠纷的调处工作；

2.完善行政调解工作规程。根据有关法律、法规规定，结合实际，进一步完善具体工作细则或规程，全面规范行政调解工作程序，确保行政调解工作合法、规范、有序；

3.具体解决行政案件审理过程中存在的较为复杂的问题；

4.其他行政调解工作需要解决的问题。

二、行政调解中心

（一）行政调解中心设立

行政调解中心设在县政府法制办公室，由县政府法制办公室负责具体工作，行政调解中心主任由县政府法制办副主任担任。政府法律顾问及政府法制办工作人员为行政调解员。

（二）行政调解中心职责

1.根据县政府行政调解工作有关要求制定和完善相应的工作制度和办法；

2.开展行政调解宣传活动；

3.负责与各行政机关行政调解室的工作联系，指导协调其他行政调解机构的行政调解工作，定期汇总、分析行政调解工作开展情况，并向联席会议报告；

4.按照有关制度规定负责具体行政案件的调解和处理，承担本级政府行政调解活动；

5.承担县行政调解联席会议具体工作任务。

九寨沟县人民政府
