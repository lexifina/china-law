# 九寨沟县人民政府关于印发《九寨沟县2017年电力扶贫工作实施方案》的通知

有关乡（镇）人民政府，县级相关部门：

《九寨沟县2017年电力扶贫工作实施方案》已经2017年5月5日县十四届人民政府第9次常务会议审议通过，现印发你们，请认真贯彻执行。

九寨沟县人民政府

2017年5月19日

九寨沟县2017年电力扶贫工作实施方案

为助力脱贫攻坚工作，改善基层生产生活条件，根据《四川省发展和改革委员会关于九寨沟县无电村通电工程可行性研究报告的批复》要求，结合县情实际，特制定本方案。

一、年度目标

通过开展电力扶贫工作，实施无电地区电力建设项目，逐步扩大九寨沟县电网覆盖面，在2017年彻底解决全县无电地区农民照明、生活用电问题，促进无电地区农民生活条件得到较大改善，建立健全无电地区有关电力建设和运行管理的法规和制度，保障无电地区电力建设顺利进行和工程安全运行，通过解决无电村社的用电问题，减少森林砍伐量，提高森林覆盖率，巩固天保和退耕还林工程的成果，保护全县生态环境，改善农村生活、生产环境，使8个乡的文化教育科技卫生事业有较大发展，人民物质文化生活水平明显提高。

二、重点工作

2017年九寨沟县无电地区电力建设项目涉及安乐、白河、草地、永和、大录、郭元、马家、玉瓦等8个乡，项目建设内容为电网延伸（涉及6个乡34个村2621户、10942人）与利用当地小水电站联网就近供电（涉及2个乡10个村1302户、5329人），同时兼顾优化配置35kV网架结构与变电容量布点、提高电网整体供电能力与供电可靠性、增设10kV及以下配电设施。

1.安乐乡：共有无电户数252户，该乡无电地区电力建设内容，一是10kV：新建10kV线路9.3公里，新增10kV配电变台6个540kVA；二是0.4kV及户表：新建0.4kV配电线路42.05公里，新增户表252户。

2.白河乡：共有无电户数378户，该乡无电地区电力建设内容，一是10kV：新建10kV线路16km，新增10kV配电变台10个780kVA；二是0.4kV及户表：新建0.4kV配电线路69.6km，新增户表378户。

3.草地乡：共有无电户数278户，该乡无电地区电力建设内容，一是10kV：架设10kV输电线路17.2km，新增10kV配电变台9台0.66MVA；二是0.4kV及户表：新建0.4kV配电线路61.8km，新增户表278户。

4.永和乡：共有无电户数1024户，该乡无电地区电力建设内容，一是10kV：架设10kV输电线路52.1km，新增10kV配电变台29台2.21MVA。二是0.4kV及户表：新建0.4KV配电线路173.4km，新增户表1024户。

5.大录乡：共有无电户数566户，该乡无电地区电力建设内容，一是10kV：新建10kV线路27.9km，新增10kV配电变台17台1.4MVA；二是0.4kV及户表：新增0.4kV配电线路103km，新增户表566户。

6.郭元乡：共有无电户数597户，该乡无电地区电力建设内容，一是10kV：新建10kV线路31.98km，新增10kV配电变台19台1.49MVA；二是0.4kV及户表：新建0.4kV配电线路125km，新建户表597户。

7.马家乡：共有无电户数349户，该乡无电地区电力建设内容，一是10kV：新建10kV线路16.8km，新增10kV配电变台11台0.96MVA；二是0.4kV及户表：新建0.4kV配电线路58km，新增户表349户。

8.玉瓦乡：共有无电户数479户，该乡无电地区电力建设内容，一是10kV：新建10kV线路22.4km，新增10kV配电变台14个1070kVA；二是0.4kV及户表：新建0.4kV配电线路95.75km，新增户表479户。

三、资金筹集

2017年九寨沟县无电地区电力建设项目，总投资10369.12万元，其中：省级财政资金5184.56万元、黄浦电力公司自筹资金5184.56万元。

四、保障措施

一是落实加快藏区跨越式发展有关精神，积极协调金融机构支持扩大藏区能源项目和无电地区电力建设信贷规模，提供优惠贷款，降低无电地区电力建设财务成本。二是研究无电地区电力建设运营可持续发展，制定农牧民用得起，供电企业供得起的电价，特别偏远地方考虑建立农牧民电费财政补贴机制。三是协调降低地方供电企业售出电价差，适当提高地方供电企业收入用以维系地方电网的正常运营，使之不断提高运行管理水平，逐步迈入良性循环的轨道。
