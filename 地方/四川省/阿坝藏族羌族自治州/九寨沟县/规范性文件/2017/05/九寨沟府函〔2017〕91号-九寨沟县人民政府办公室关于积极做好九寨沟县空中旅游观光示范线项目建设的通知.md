# 九寨沟县人民政府办公室关于积极做好九寨沟县空中旅游观光示范线项目建设的通知

各乡（镇）人民政府、县级各部门：

九寨沟县空中旅游观光示范线项目是我县大力推进“四个全域、四个九寨”战略规划，助推旅游转型升级、提质增效的重要支撑项目。目前，该项目已进入全面开工准备阶段，前期各项准备工作正有序推进。为进一步加快推进九寨沟县空中旅游观光示范线项目建设，现将有关事项通知如下：

一、高度重视，加强组织领导。九寨沟县空中旅游观光示范线项目是我县2017年重点项目之一，该项目秉承了我县“全域发展、绿色崛起”总体战略、“拓景扩容、多点多极”发展理念和全域旅游发展需要，项目的建成将打破漳扎镇片区交通瓶颈，缓解交通压力，全面提升我县全域旅游通达率。为加快推进项目落地，我县成立了九寨沟县空中旅游观光示范线项目推进工作领导小组，全力推进项目建设。有关乡（镇）、各部门要充分认识九寨沟县空中旅游观光示范线项目建设的重要性和紧迫感，进一步加强组织领导，强化职能职责，周密安排部署，认真积极配合业主单位开展各项工作，确保项目顺利推进。

二、落实责任，积极协调配合。一是沿线涉及乡（镇）及部门要主动配合、协助业主单位在既定期限内完成项目线路选址、地质勘查、农田水利设施界定等相关工作。二是沿线涉及乡（镇）要及时排查项目建设过程中可能出现的矛盾和隐患，做到早发现早处理，使矛盾隐患得到有效控制并消灭在萌芽状态，对问题纠纷严重的要及时向县政府相关部门及负责领导汇报，确保问题得到有效解决。三是沿线涉及乡（镇）及相关部门要及时成立专项工作组，安排专门工作人员定岗定责，全力做好项目实施过程中的对接、协调工作。四是沿线涉及乡（镇）和相关部门要配合业主单位做好项目现场取证、资料收集等工作，确保项目实施过程中矛盾纠纷处理有据可依、有证可查。五是相关部门要切实加强与业主单位的沟通联系，主动协调解决项目实施过程中用工、用地、用电、用水等要素保障，为业主单位提供良好的施工环境。六是沿线涉及乡镇、有关部门要认真贯彻落实县委、县政府决策部署，自觉支持、配合、服务项目前期及项目过程中的各项工作，依法依规协助业主单位做好土地征用、拆迁等工作，同时要向群众做好宣传、教育、说服工作，确保项目顺利推进。七是县国土资源局要联合涉及乡（镇）积极配合业主单位依法依规做好征地实地勘测、用地规划、征地协商洽谈、征地补偿方案编制等工作，积极协调处理企业与群众在征地过程中的矛盾纠纷。同时，认真做好征地补偿费征收，并对征地补偿费落实情况进行监督。八是县发展和改革局要积极配合业主单位抓紧项目立项，确保在6月底完成项目立项，确保项目建设前土地、环评、能评、规划等手续齐全并能如期开工建设。九是沿线涉及宾馆酒店、餐饮等企业要全力配合执法部门及相关单位和业主单位进行征地、拆迁等工作。十是电信公司、移动公司、联通公司、黄浦电力公司、天然气公司、自来水厂、水电开发公司等企业要及时为业主单位提供管网图纸、长线距等相关资料，积极配合业主单位进行管网改迁等工作。

三、强化监管，依法严厉打击。在项目建设过程中，对在房地产权、土地面积、建筑面积、房屋评估等方面弄虚作假，夸大数量，办理假证照、出具假证明等骗取补偿的；或支持煽动群众突击搭建违法违章建筑、抢种树木、抢植农作物的；曲解政策，散布各类妨碍项目建设言论或信息的；鼓动或组织群众提出非法及不合理要求，甚至煽动集体上访、聚众闹事和抵制项目建设的等行为要进行严厉打击，全力为项目建设创造良好的社会环境。

四、认真总结，及时上报信息。各涉及乡（镇）、各部门要进一步加强信息沟通，随时通报工作开展情况，发现问题并及时研究解决。对工作开展中的特色亮点、做法要及时提炼总结并以简报形式及时报送至县政府办（联系人：杨进宝，邮箱：jzgzfb@163.com；电话：[电话略]）。
