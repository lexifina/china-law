# 九寨沟县人民政府办公室关于成立九寨沟县旧城区改造项目推进工作领导小组的通知

永乐镇人民政府、县级相关部门：

为加快推进九寨沟县旧城区改造，完善我县城市功能，进一步提升城市形象，不断提升公共服务能力，经县人民政府研究，决定成立九寨沟县旧城区改造项目推进工作领导小组，其成员如下：

组    长：陶     钢   县委副书记、县长

副组长：刘今朝   县委常委、常务副县长

刘明清   县政府副县长

白建安   永乐镇镇长

领导小组办公室设在县城乡规划建设和住房保障局，由杜宇同志兼任办公室主任，负责处理日常事务。

（一）领导小组工作职责：负责对九寨沟县旧城区改造项目推进工作实行统一领导，研究制定保障项目顺利实施的政策措施，协调县级相关部门及乡（镇）人民政府解决项目推进过程中的征地拆迁、资金保障、手续办理等问题，确保项目推进平稳有序。

（二）领导小组办公室工作职责：在领导小组的领导下，具体负责九寨沟县旧城区改造项目推进日常工作，传达、通报上级各部门有关精神及领导小组决定，制定具体工作实施意见，督促检查县级相关部门及乡（镇）工作推进情况，及时向领导小组反馈工作情况，确保按时顺利完成各阶段工作及总体目标任务。
