# 九寨沟县人民政府办公室关于同意建设九寨沟县全域旅游“三态、三微”郭元乡柴门关（青龙村）旅游基础设施建设项目的批复

郭元乡人民政府：

你乡《关于建设九寨沟县全域旅游“三态、三微”郭元乡柴门关（青龙村）旅游基础设施建设项目的请示》（郭元府〔2017〕80号）收悉，经县人民政府研究，原则同意建设九寨沟县全域旅游“三态、三微”郭元乡柴门关（青龙村）旅游基础设施建设项目，该项目总投资175万元（其中，邛崃对口援建资金120万元，邛崃商会援建资金10万元，县农水局集体经济建设资金45万元），请你乡严格按照相关法律和基本建设程序办理。

此复。

九寨沟县人民政府办公室

2017年5月25日
