# 九寨沟县人民政府办公室关于印发《九寨沟县旅游市场综合监管实施方案》的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县旅游市场综合监管实施方案》已经县人民政府同意，现印发你们，请认真贯彻执行。

九寨沟县人民政府办公室

2017年5月17日

九寨沟县旅游市场综合监管实施方案

为深入贯彻落实《国务院办公厅关于加强旅游市场综合监管的通知》（国办发〔2016〕5号）、《四川省人民政府办公厅关于进一步加强全省旅游市场综合监管的实施意见》(川办发〔2016〕97号）和《阿坝州人民政府关于印发〈阿坝州旅游市场综合监管实施意见〉的通知》（阿府发〔2017〕5号）精神，进一步规范旅游市场秩序，优化旅游市场环境，保障旅游者合法权益，促进全县旅游业健康、有序、持续发展，特制定本实施方案。

一、规范涉旅企业和从业人员行为

（一）加强购物市场管理

1.取消旅游定点购物。倡导旅游产品开发本土化，积极鼓励销售本地名特产品。严禁新建旅游购物店（点），现有旅游购物商店纳入社会商品零售企业进行统一监管，严禁超范围经营。在旅游沿线合理设置休息点（服务区），加强休息点（服务区）旅游公共服务设施建设，设立专区销售“净土阿坝”名特产品和九寨沟县名优特产品。

责任单位：县工质食药监局、县旅发局、漳扎镇、县公安局、县住建局、县交通局、县经信局

完成时限：5月31日前完成取消旅游定点购物工作，12月31日前完成旅游沿线休息点（服务区）设置工作。其他工作长期坚持。

2.严厉打击不正当竞争行为。严禁购物商店与旅行社或驾导人员以任何方式在旅游购物活动中进行商业贿赂；严禁在景区景点、演艺、住宿、藏（农）家乐、餐饮等游客集中活动场所诱导、强迫或变相诱导、变相强迫游客进入购物商店消费。

责任单位：县工质食药监局、漳扎镇、县物价局、县公安局、县旅游执法局、县旅发局

完成时限：长期坚持。

3.严厉打击购物商店的各种欺诈行为。加大商品质量检测抽检力度，加强计量器具周期检定，规范商品标识标签，标注商品真实信息。严厉打击以次充好、以假充真、磨粉增量、缺斤少两、“药托”“医托”、使用不合格计量器具、不明码标价、标注误导信息等违法违规行为。严厉查处以宗教活动为名，欺诈游客钱财，侵害游客合法权益的行为。强化导购人员实名制，不得借用“扎西”“卓玛”等名字或以当地群众的身份，变相欺骗游客；严禁导购人员利用包厢、藏家等进行虚假宣传、诱导消费。

责任单位：县工质食药监局、漳扎镇、县物价局、九管局、县民宗局

完成时限：长期坚持。

4.加强购物商店涉税事项管理。在旅游景区、旅游线路的大型购物商店，推行使用增值税发票升级版系统。强化纳税申报及核查，严厉打击不按规定开具发票和偷税等违法行为。

责任单位：县国税局、县地税局

完成时限：长期坚持。

5.规范购物商店变更登记。同一年度内被投诉3次（包括3次）以上且经查证属实的或被列入旅游经营服务不良信息名录的购物市场经营主体，如其法人代表、经营范围和经营地址均不变的情况下，提出名称变更登记申请的，登记机关对其实行失信惩戒，原则上对其名称变更登记申请不予受理，并不得实行“一址多照”“一照多址”登记。

责任单位：县工质食药监局

完成时限：长期坚持。

（二）加强旅游团队运行管理

1.坚决打击“不合理低价游”。旅行社不得以不合理低价组织旅游活动，诱骗旅游者，并通过安排购物或者另行付费旅游项目获取回扣等不正当利益。以公布的我州旅游线路产品诚信参考价为标准，禁止旅行社发布、销售“不合理低价游”产品和组织接待“不合理低价游”团队，对违反规定的依法从严处理，并将被吊销经营许可证的旅行社法定代表人列入“黑名单”，实施行业禁入。

责任单位：县旅游执法局、漳扎镇、县运管所、县工质食药监局、县公安局

完成时限：长期坚持。

2.加强旅游团队检查。加大车辆区间测速力度。加大旅游客运车辆检查力度，严厉打击旅游客运非法营运行为。依法从严查处签订虚假合同、阴阳合同、不签订或不使用合同示范文本（2014版）、未使用或不规范使用电子行程单，未经游客同意转团或拼团、擅自变更行程和强制购物等违法违规行为。

责任单位：县旅游执法局、漳扎镇、县运管所、县工质食药监局、县公安局、县旅发局

完成时限：长期坚持。

3.规范导游人员管理。强化导游行业管理，加强导游培训，落实导游薪酬、保险制度，配合完成电子导游证核发工作，加强导游执业抽查检查，严厉打击虚假宣传、诱导消费、擅自变更行程、不按服务质量规范提供服务等违法违规行为。

责任单位：县旅游执法局、漳扎镇

完成时限：6月30日前完成电子导游证核发工作，其他工作长期坚持。

（三）加强景区规范管理

重点整治景区及景区周边拉客揽客、尾随兜售行为。规范景区及景区周边停车场建设和管理，对擅自圈占停车位收费的行为进行严厉查处。维护景区及景区周边良好的交通秩序、社会治安、环境卫生。

责任单位：九管局、森管局、漳扎镇

完成时限：长期坚持。

（四）加强餐饮住宿规范管理

1.规范餐饮经营行为。针对团餐接待单位制定完善食品安全经营的相关规定，建立准入和退出机制，加大旅游团餐接待单位食品安全监管力度，严禁超能力接待。对于发生食品安全重大责任事故、因违反《食品安全法》受到食品药品监管部门2次以上行政处罚或因食品安全与服务质量等问题受到投诉举报并造成恶劣影响的，坚决予以退出，并纳入黑名单。

责任单位：县工质食药监局、县旅游执法局、漳扎镇

完成时限：长期坚持。

2.加强住宿业规范管理。加大暗访力度，对存在质量严重下滑、设施严重老化等问题的三星级及以下的酒店，予以摘牌或降级处理；四星级及以上的酒店报上级旅游主管部门处理。对不符合接待条件、存在重大安全隐患、服务质量较差造成恶劣影响的非星酒店、非标客栈（民宿）、乡村酒店（客栈、藏家乐），依法予以取缔。

责任单位：县旅游执法局、县工质食药监局、漳扎镇、县公安局、县消防大队、景区消防大队、县旅发局

完成时限：6月15日前完成，并长期坚持。

二、优化旅游产品供应

（五）持续推广旅游线路产品。加大宣传营销力度，积极推广高端定制游、中端自助自驾游、跟团游（标准团、品质团、精品团）系列旅游线路产品，不断完善旅游配套服务设施建设，强化旅游线路产品有效供给，持续推进细化细分旅游线路产品工作。

责任单位：县委宣传部、九管局、县旅发局、森管局、县全域旅游办公室

完成时限：长期坚持。

（六）实行景区门票全网预约。启动景区门票全网预约（预售）机制。九寨沟景区实行景区门票实名制，其他景区要逐步实行实名制。建立完善的旅游大数据库，加强对游客流量实时监测和游客消费行为统计分析，实行涉旅企业“红”“黑”榜公示，并设置专题页面，推介“净土阿坝”和全县名特产品；开设社交栏目，加大社会舆论监督。

责任单位：九管局、县旅发局、森管局、县委宣传部

完成时限：长期坚持。

（七）加强旅游市场诚信体系建设。积极参与主动配合打造“一网”（阿坝州市场主体信用信息公示系统）“一码”（二维码）“一中心”（阿坝州市场主体信用信息交换中心）“一平台”（消费维权平台）信用监管体系，继续完善县旅游资讯频道曝光台栏目。建立涉旅企业诚信经营自主承诺和严重违法企业“黑名单”制度，推行县涉旅企业诚信经营保证金制度。完善涉旅企业和从业人员诚信记录。督促行业协会严格执行30天内无理由退货机制。

责任单位：县旅游市场综合治理领导小组成员单位

完成时限：12月31日前完成并长期坚持。

三、强化旅游市场综合监管工作保障

（八）全面落实旅游市场综合监管责任。全面落实旅游市场综合监管属地管理、行业监管责任，大力开展联合巡查督查，严厉打击各类违法违规行为。

责任单位：县旅游市场综合治理领导小组成员单位

完成时限：长期坚持。

（九）推广“1 3 N”旅游综合监管模式。加强旅游综合监管队伍建设，结合实际完成“1 3 N”监管机构建设工作。

责任单位：县法院、县公安局、县工质食药监局、县旅发局、县编办

完成时限：5月31日前初步完成；12月31日前全面完成。

（十）完善区域联动机制。积极配合州旅发委建立兰阿、渝阿、成阿等区域联合执法机制；构建九环线、环红线、南环线等全域覆盖、反应快速、处理高效的旅游综合监管联动机制；完善县、局、司、镇联合联动机制；严格落实旅游市场综合监管联席会议制度。

责任单位：县旅发局、县旅游执法局、九管局、大九旅集团、

漳扎镇

完成时限：6月30日前完成并长期坚持。

（十一）建立投诉分析处理机制。建立旅游投诉纠纷统一受理机制，统一对外公布九寨沟县旅游投诉电话（0837-7712980），快速处理各类旅游投诉，形成信访、旅游、工商、公安等部门所涉及的旅游投诉处理信息共享机制。落实快速理赔制度。整合信访、网络、电话等旅游投诉数据，建立旅游投诉分析机制。

责任单位：县旅游市场综合治理领导小组成员单位、九管局、大九旅集团

完成时限：长期坚持。

（十二）建立考核督查与问责机制。将旅游市场综合监管工作纳入县级目标绩效考核管理，对市场监管不力，发生恶性旅游事件，造成恶劣社会影响的相关单位和责任人进行严肃问责。

责任单位：县目标督查办、县监察局

完成时限：长期坚持。
