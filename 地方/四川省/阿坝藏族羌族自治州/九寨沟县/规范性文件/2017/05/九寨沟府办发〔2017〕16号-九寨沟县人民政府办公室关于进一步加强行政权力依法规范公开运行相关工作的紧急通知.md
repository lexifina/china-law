# 九寨沟县人民政府办公室关于进一步加强行政权力依法规范公开运行相关工作的紧急通知

县级各相关行权部门：

为进一步加强全县行政权力依法规范公开运行平台建设和使用管理，全面推进依法行政，现就有关事宜通知如下：

一、统一思想，提高认识。推行行政权力依法规范公开运行是深入推进依法行政、建设服务型政府的内在要求，是进一步推进政务公开、加快构建惩防体系的迫切需要，也是创新政府管理手段和服务方式的重要举措。各有关单位要充分认识推行行政权力依法规范公开运行工作的重要性、必要性和紧迫性，进一步统一思想、提高认识，增强做好此项工作的责任感，抓好各项工作落实，确保我县行政权力依法规范公开运行工作规范有序开展。

二、查找原因，整改提高。一是各相关单位要根据自身行政权力实际情况，实事求是，认真梳理2017年1月至5月行政权力运行情况相关数据。二是各相关部门要及时对4月网上录入办件量为零的情况作出具体说明，查找原因、及时整改。三是各相关部门要根据业务流程需要，安排一名分管领导和一名专职人员专门负责此项工作，及时报备分管领导和专职人员名单及联系方式，压实责任、强力推进。

以上材料请各相关单位务必于5月27日18:00前报县政府办综合科301室（联系方式：7732007）。

三、及时录入，严格督查。请各相关单位务必于2017年6月1日前完成1月至5月行政权力运行平台网上办件量录入工作。县纪检监察机关将重点围绕“推动主体责任落实、推动网上行权、推动日常监督、推动系统优化、强化执纪问责”五个方面开展工作，对行权平台工作认识不到位、重视不够、推动不力、监督不好的部门将给予通报批评、书面函询，对通报、函询后整改不力的，将对单位一把手及分管领导进行约谈。

九寨沟县人民政府办公室
