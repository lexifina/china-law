# 九寨沟县人民政府办公室关于印发《九寨沟县2017年耕地地力保护补贴实施方案》的通知

各乡（镇）人民政府，县级相关部门:

《九寨沟县2017年耕地地力保护补贴实施方案》已经县人民政府研究同意，现印发你们，请认真贯彻执行。

九寨沟县人民政府办公室

2017年6月3日

九寨沟县2017年耕地地力保护

补贴实施方案

根据《四川省农业厅四川省调整完善农业三项补贴政策实施方案》（川农业〔2015〕50号）、《四川省财政厅四川省农业厅关于下达2017年中央财政相关农业专项资金的通知》（川财农〔2017〕4号）、《四川省农业厅四川省财政厅关于做好2017年耕地地力保护补贴工作的通知>的通知》（川农业函〔2017〕414号）、《阿坝州财政局阿坝州农牧局关于下达2017年农业生产发展资金的通知>的通知（阿州财农〔2017〕54号）要求，按照我县2016年调整完善“农业三项补贴”政策实施情况，结合农业生产实际，特制定本实施方案。

一、实施范围和内容

在保持政策的稳定性和连续性基础上，坚持兼顾“生产与生态、公平与效率、指向性与操作性”的原则，增强农业补贴政策精准性、指向性和实效性，及时分配拨付，提高农业补贴政策效能。

（一）资金来源：将原农资综合补贴的80%、种粮农民直接补贴和清算后的农作物良种补贴，用于耕地地力保护补贴。

（二）补贴对象：拥有耕地承包权的种地农民，享受补贴的农民要做到耕地不撂荒，地力不降低。

（三）补贴方式：“耕地地力保护补贴”与耕地面积挂钩。耕地面积的核定，以第二轮土地承包面积为基础，对已作为畜牧养殖场使用的耕地、林地、成片粮田转为设施农业用地、非农业征（占）用耕地等已改变用途的耕地，以及长年抛荒地、占补平衡中“补”的面积和质量达不到耕种条件的耕地等不给予补贴。

（四）补贴标准：最终以县、乡（镇）核实确认耕地面积作为补贴面积，并请示县人民政府批准同意后确定补贴标准。

（五）兑付时间。经严格核实相关面积后，通过“一折（卡）通”直接发放到土地承包户手中。

二、资金分配原则

根据《阿坝州财政局阿坝州农牧局关于下达2017年农业生产发展资金的通知>的通知（阿州财农〔2017〕54号），用于耕地地力保护补贴资金336.03万元(其中耕地地力保护补贴资金331.33万元，工作经费4.7万元），对加强耕地生产能力建设，实施“耕地地力保护补贴”类资金，依据各乡（镇）人民政府耕地面积据实测算，经农村信用联社通过“一折（卡）通”直接发放到土地承包户手中。鼓励农民采取秸秆还田、科学施肥用药、推进病虫害绿色防控和统防统治等综合措施，切实加强农业生态资源保护，自觉提升耕地地力。

三、主要工作及程序

（一）加强宣传。县委宣传部、县农业畜牧和水务局、县财政局、各乡（镇）人民政府等部门要及时通过各种媒体向广大农民、基层干部以及社会公布，宣传“农业三项补贴”政策及耕地地力保护补贴，各乡（镇）人民政府要将国家“农业三项补贴”政策及耕地地力保护补贴宣传到村组、到农户，让基层干部和农民充分了解中央改革政策精神实质和主要内容，在实施过程中要做好执行新政策与老政策的口径解释等问题。同时，要加强直接参与政策宣传和操作落实有关人员的培训，明确政策在补贴对象、面积认定、操作方式等方面的调整变化，确保调整完善后的“农业三项补贴”政策及耕地地力保护补贴落到实处。充分调动农民生产积极性，营造良好社会氛围，推动补贴工作的顺利开展。

（二）核实补贴面积。县农业畜牧和水务局负责实际耕地面积的终审确认。各乡（镇）人民政府负责组织所在行政区域耕地面积核实工作。严格执行补贴公示制度，由乡（镇）人民政府负责两次公示，第一次每个农户的补贴面积公示，第二次每个农户的补贴标准、补贴金额公示，接受群众监督，确保公示内容与实际发放补贴一致（公示时间不少于7天）。公示期间，应当听取农民群众的意见，接受群众监督，发现问题及时纠正。

（三）补贴资金发放。县财政局负责组织补贴资金发放。对耕地地力保护补贴类资金：乡（镇）人民政府在负责审核、确认实际耕地面积基础上，要建立分村、社的耕地补贴清册。县财政局根据县级农业部门提供的经过终审确认的实际种植面积，以及乡（镇）人民政府提供的补贴清册，依据各乡（镇）人民政府耕地面积据实测算，经农村信用联社通过“一折（卡）通”直接发放到土地承包户手中。

四、保障措施

（一）加强组织领导。耕地地力补贴关系到广大农民切身利益和农业农村发展大局。县人民政府作为责任主体，要加强组织领导，成立相应领导小组。我县成立以分管农业副县长为组长的县“耕地地力保护补贴”领导小组（见附件），成员单位涉及县农业畜牧和水务局、县财政、县委宣传部、县审计局、县农村信用社等部门，领导小组办公室设在县农业畜牧和水务局，由县农技站具体负责补贴相关工作。各乡（镇）人民政府应成立以乡（镇）人民政府主要领导任组长的乡（镇）级“耕地地力保护补贴”领导小组，并报县农业畜牧和水务局农技站备案，负责核实补贴面积、宣传解说、监督检查及信访等工作。

（二）强化部门协调。各乡（镇）、县级相关部门要高度重视“耕地地力保护补贴”工作，切实把该项工作作为稳定种植面积、提高单产、增加农民收入的重要举措来抓，明确分工、落实责任、密切配合、形成合力，推动补贴工作顺利实施。县财政局负责落实补贴资金预算、拨付工作；县农业畜牧和水务局负责项目组织实施、制定方案、面积核实、技术服务等工作；县级相关部门要各司其职、各负其责，为补贴工作搞好服务。

（三）强化工作要求。县级相关部门要紧密结合我县实际，充分听取各方面意见，明确政策实施的具体要求和组织保障措施，保证补贴工作的顺利实施。县农业畜牧和水务局将补贴标准报请县委、县政府审批同意后，各乡（镇）再按补贴标准对补贴金额进行公示，公示后报县农技站，县农技站汇总后报州农业畜牧局、州财政局备案。各乡（镇）人民政府要于2017年6月底前完成本辖区内“耕地地力保护补贴”系统的录入、两次公示和公示后纸质版和电子版材料报农业畜牧和水务局农技站。

（四）强化监督检查。各乡（镇）、县级相关部门要严格执行政策，强化补贴工作项目管理。补贴资金要专款专用，切实按照国家规定严格使用。任何地方、单位和个人都不得以任何形式和理由套取、挤占、挪用补贴资金。凡违规操作和套取、挤占、挪用补贴资金的，一经查实将按照有关规定严肃处理，并视其情节追究有关单位、领导和当事人的责任。县、乡要加强监督检查，对不认真履行职责、政策执行不力的要及时发现，督促整改。

（五）强化档案管理。通过现有统计渠道，建立农业补贴信息管理档案，对列入补贴的农户逐户登记，立档管理，做到将补贴对象与耕地面积一一对应。各乡（镇）人民政府负责组织所在行政区域补贴面积具体核实工作，县农业畜牧和水务局负责补贴面积最终审核确认和汇总上报。补贴资金发放实行乡、村两级公示制,公示内容包括补贴面积、补贴标准、补贴资金数额等，两级公示责任主体均为乡政府。公示期间，应当充分听取农民群众的意见，接受群众监督，发现问题及时纠正。
