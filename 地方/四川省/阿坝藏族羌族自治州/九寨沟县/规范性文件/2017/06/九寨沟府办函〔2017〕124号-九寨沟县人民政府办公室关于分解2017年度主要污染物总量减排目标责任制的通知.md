# 九寨沟县人民政府办公室关于分解2017年度主要污染物总量减排目标责任制的通知

各相关单位：

为扎实推进我县主要污染物总量减排工作，按照州人民政府办公室《关于下达2017年主要污染物总量减排目标任务的通知》（阿府办函〔2017〕50）要求，我县将漳扎污水处理厂、甘海子污水处理厂、县城污水处理厂、高原食品有限公司确定为2017年重点减排项目，各责任单位要严格管理，有效推进减排工作，确保完成2017年减排目标任务。

一、减排目标

2017年，州人民政府下达我县的主要污染物总量减排目标为：化学需氧量516吨，氨氮67吨，二氧化硫5吨，氮氧化物2吨。

二、工作要求

（一）高度重视，落实责任。各相关部门要高度重视总量减排工作，加强组织领导，落实项目资金，严格监督管理，确保减排目标任务的完成。

（二）增添措施，扎实推进。各相关部门要全面落实总量减排政策措施，主动作为，有力、有序推进减排工作。

（三）突出重点，确保实效。一要加强污水处理厂运行保障和监督管理。加强对污水处理厂的督促指导，强化监测、监管，确保已建成的污水处理设施全部投入运行，实现达标排放。二要加强工业污染治理，积极淘汰落后产能。对新建项目严格执行环境影响评价和“三同时”制度，强化节能环保准入；要加大工业结构调整，严格按照国家产业政策，依法坚决淘汰落后产能。

三、减排责任落实

（一）县经济商务和信息化局：负责研究制定有利于污染减排的产业政策；负责严格执行国家产业政策，组织推广应用新技术、新工艺、新产品，指导督促企业技术改造和污染减排，推进清洁生产和循环经济；负责组织实施我县产业结构调整，淘汰落后产能，提请县政府关闭、淘汰落后工艺（如砖瓦窑），确保完成国家、省、州下达的淘汰落后产能目标任务。

（二）县城市管理局：负责漳扎污水处理厂、县城污水处理厂的正常运行。推进城镇管网配套和雨污分流工程，完善污水收集系统，提高污水收集率和处理率；对我县漳扎、县城污水处理设施运行进行监管，漳扎污水处理厂已完成提标技改，并于5月1日开始运行，应尽快与州环保局联系完成环保验收；负责我县城镇污水处理厂污泥规范化处理处置。

（三）九寨天堂国际会议度假中心有限公司：负责甘海子污水处理厂的正常运行，积极做好减排相关工作。

（四）九寨沟高原食品有限公司：加快燃煤锅炉的淘汰，积极做好减排相关工作。

（五）县环境保护和林业局：负责牵头统筹推进全县减排工作，指导、协调、督促有关部门采取有效措施，落实重点减排项目和行业减排任务，确保实现全县减排目标；负责污水处理厂运行情况的监督管理；负责加强减排统计、考核体系建设，积极协调上级监测部门进行监测；负责组织加强日常环保执法监督检查，提升对重点污染源的监管质量和效率；负责牵头落实县减排工作联席会议制度，加强有关部门之间的沟通配合、协调联动；负责牵头定期对减排情况进行核查核算，并将核算结果报县人民政府审定后予以通报；牵头负责配合环保部、省环保厅、州环保局做好对全县减排情况、重点减排项目的核查核算。
