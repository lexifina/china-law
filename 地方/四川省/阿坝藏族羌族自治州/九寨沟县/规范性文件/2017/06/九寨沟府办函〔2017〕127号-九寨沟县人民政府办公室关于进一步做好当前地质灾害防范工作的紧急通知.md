# 九寨沟县人民政府办公室关于进一步做好当前地质灾害防范工作的紧急通知

各乡（镇）人民政府，县级各部门:

2017年6月24日6时左右，茂县叠溪镇新磨村突发山体高位垮塌，造成河道堵塞2公里，100余人被埋。州委副书记、州长杨克宁第一时间作出重要批示，要求各县（市）对地质灾害隐患点作全面排查，加强日常监测和防范，一旦出现险情、灾情，及时组织受威胁群众转移避让。为贯彻落实克宁州长指示精神，确保我县经济社会持续健康发展和人民生命财产安全，现将有关事宜通知如下：

一、逐级压实地质灾害防范责任

各乡镇、部门、企业务必要高度重视，充分认识到今年我县地质灾害防范工作面临的严峻形势，进一步强化地质灾害防范工作责任制，逐级分解任务，建立切实有效的防灾责任监督机制，全面抓好地质灾害隐患点的行政、监测、技术、避险等具体责任人的落实。

二、积极构建完善防灾工作体系

各乡镇、部门、企业要在防灾减灾责任落实方面重点强化工作重心下移；在隐患发现方面重点强化多方位动态普查；在实际操作层面重点强化专职监测体系建设；在主动预防避让方面重点强化“三避让”原则；在找准薄弱环节方面重点强化人口密集区及在建工程防灾措施落实；在关键区域及关键地段重点强化突出防范；在督促指导方面重点强化全域立体督导，全力做好汛期地质灾害防范工作，最大限度的降低因灾损失，切实保护人民群众生命财产安全。

三、全力做好汛期地灾防范工作

各乡镇、部门、企业要围绕重点时段、重点区域，全面细化落实地质灾害防范各项措施，对地质灾害防范工作进行再落实、再部署。一是全面开展辖区内地质灾害隐患点和易地扶贫搬迁点排查，坚持雨前排查、雨中巡查、雨后复查，动态监控威胁人员财产安全隐患点变化情况，对排查出的隐患要及时进行处置，对一时无法处置的，必须建立预案、安排专职监测人员、制定并发放受威胁群众的“两卡一表”、明确预警信号、制定紧急撤离路线。二是对地质灾害高易发区，要进一步完善防灾预案，强化责任落实，健全群测群防体系，加强应急演练，提高防大灾的能力。三是全面开展督促检查，推动相关管理部门的防范主体落实防灾责任和防范措施，督促建设、开发主体严防不合理工程活动引发的灾害及导致人员的伤亡，确保施工人员安全。四是县级联系门要深入联系村协助开展地灾隐患点和易地扶贫搬迁点隐患排查工作，做到早发现、早防范。

四、积极深化主动预防避让工作

各乡镇、部门、企业要深刻把握“主动避让、提前避让、预防避让”的工作原则，在发出地质灾害预警后，相关责任人要按照预案快速组织群众安全转移，必要时可采取强制措施，坚决避免因灾死亡事件发生。遇连续降雨、强降雨等极端天气时，必须提前将地质灾害高发易发区人员转移至安全地带，并在危险区域设置警戒标识，防止群众进入。

五、严格执行应急值班值守制度

各乡镇、部门、企业要把汛期地质灾害防范工作摆在更加重要的位置来抓，要加强对监测人员的管理，督促和检查监测人员信息通畅，确保预警信息能第一时间传达到位。持续强化汛期24小时值班和领导带班制度，要定时或不定时抽查监测人员在岗在位情况，要做好抽查记录与信息传递记录，督促监测人员做好监测记录。同时，在遭遇连续降雨、强降雨天气时，单位负责同志必须到值班现场值守，并认真督促各地质灾害责任人和监测人员切实履职尽责，时刻保持防灾工作的高压态势。

六、必须严格遵守防灾工作纪律

各乡镇、部门、企业必须严格执行汛期地质灾害防范工作各项制度，确保各项防灾工作部署落实到位。县目标办和纪检监察部门要加大对汛期工作纪律、责任、命令执行情况的监督督查力度，对预警信息传递不及时造成人员伤亡的，各类水库、水电站、尾矿坝看护巡查不到位、预案不落实、抢险不及时造成重大险情的，在建涉水工程应急度汛措施不到位造成重大责任事故和损失的，以及学校、医院、集镇、景区、居民聚集点等重点地区防范不力、转移不及时造成人员伤亡的，必须严肃追究相关人员责任。

各乡镇、县级各部门必须于6月25日（星期日）17:00前将主要领导签字同意的工作开展情况报县应急办和县国土资源局（县应急办：7725005/7732007；县国土资源局：7733376/7732022）。
