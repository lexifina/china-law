# 九寨沟县人民政府办公室关于进一步加强公务车辆安全管理的通知

各乡（镇）人民政府，县级各部门：

2017年5月22日，阿坝州城乡建设住房局一辆丰田牌小型普通客车因公前往若尔盖出差，9时20分左右在G317线303KM 150M（马尔康前往成都方向梭磨路段）处被山体飞石砸中，造成1人重伤、4人轻伤的意外道路交通事故。州委副书记、州长杨克宁作出重要批示要求全州上下都要做好车辆运行安全。为深入贯彻落实克宁州长指示精神，进一步加强公务车辆安全管理，根据县政府工作安排，现将有关事宜通知如下：

一、严格落实车辆安全责任。各乡镇、各部门要进一步建立健全公务用车管理制度，对车辆实行统一管理、统一调度，不得擅自将车辆交于他人驾驶，不得擅自出车，严禁公车私用，坚决杜绝因管理不到位发生的行车安全事故。

二、切实加强日常检查维护。各乡镇、各部门要加大对公务车辆进行安全检查，及时发现排除安全隐患。驾驶员要爱惜车辆，注重车辆保养，做到经常检查主要机件，确保行车安全。

三、加强驾驶员安全教育。各乡镇、各部门要加大对驾驶员教育力度，确保其牢固树立“安全第一、文明驾车”的观念，严厉禁止酒后驾车、带病驾车、疲劳驾驶等危险驾车行为。

四、不断提升驾驶技能。各乡镇、各部门要结合实际开展多种形式的教育培训工作，全面加强驾驶从业人员对《道路交通安全法》等法律法规学习力度，切实提高突发事件的应急处置能力。
