# 九寨沟县人民政府办公室关于立即搬离黄木山土桥沟左侧滑坡危险区群众的紧急通知

永和乡人民政府：

6月以来，受持续强降雨天气影响，州内多县（市）爆发洪涝和山洪泥石流灾害。6月24日6:00左右，茂县叠溪镇新磨村突发山体高位垮塌，造成40余户农房、100余人被掩埋，岷江支流松坪沟河道堵塞2公里。永和乡是地质灾害多发区和易发区，汶川特大地震和芦山强烈地震后，山体稳定性降低，不良地质活动加剧，尤其是黄木山土桥沟左侧滑坡体自2015年9月以来加速变形。经排查发现，黄木山土桥沟左侧滑坡危险区仍有群众未及时搬离，存在巨大安全隐患。为千方百计保障人民生命财产安全，现将有关事宜通知如下：

一、永和乡必须立即启动仍住在黄木山土桥沟左侧滑坡危险区群众的搬迁工作，搬迁新房达到入住条件的要立即搬入新居，未达到入住条件的要立即采取“投亲靠友”或由永和乡统一安排住宿等形式立即搬离，在前期工作基础上，加强巡查、排查，确保无一人居住在黄木山土桥沟左侧滑坡危险区。

二、永和乡必须落实专人对黄木山土桥沟左侧滑坡体进行24小时不间断监测，一旦发现险情要立即报告并及时整治，不得出现“有情况不报告、有险情不处置”等问题出现。

三、永和乡必须严格按照“提前避让、主动避让、预防避让”原则，进一步完善应急预案，一旦出现短期内难以整治完成的险情，要及时组织群众转移，不得耽误。

四、永和乡要进一步加强防灾减灾教育培训力度，组织开展突发地质灾害应急演练，切实提升广大干部群众预防和处置突发地质灾害的能力。

五、永和乡要严格执行汛期防汛减灾工作零报告制度，于每日上午10:00前和下午16:00前将相关信息报送至县应急办、县防汛办、县国土资源局。

特此通知。

九寨沟县人民政府办公室

2017年6月26日
