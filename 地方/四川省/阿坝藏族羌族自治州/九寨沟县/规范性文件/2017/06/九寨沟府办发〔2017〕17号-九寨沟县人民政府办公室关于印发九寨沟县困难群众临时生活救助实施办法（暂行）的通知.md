# 九寨沟县人民政府办公室关于印发九寨沟县困难群众临时生活救助实施办法（暂行）的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县困难群众临时生活救助实施办法（暂行）》已经县人民政府同意，现印发你们，请抓好贯彻落实。

九寨沟县人民政府办公室

2017年5月31日

九寨沟县困难群众临时生活救助

实施办法（暂行）

根据《阿坝藏族羌族自治州城乡困难群众临时生活救助实施办法》（阿府办发〔2011〕23号）要求，结合我县经济发展水平和财政状况，对符合条件的困难家庭申请临时生活救助的，按照申请对象困难程度实行“分级、分类”救助，并随着县域经济发展和人民生活水平提高，适时进行合理调整确定救助标准。结合我县发展实际，特制定本办法。

一、临时救助对象

（一）临时救助对象。包括精准扶贫建档立卡贫困户、城乡居民最低生活保障对象和其他专项社会救助覆盖对象由于特殊原因仍导致基本生活出现暂时困难的家庭；在最低生活保障和其他专项社会救助制度覆盖范围之外，由于教育、医疗、因灾等特殊原因造成基本生活出现暂时困难的低收入家庭；重点是低保边缘家庭；县人民政府认定的其他特殊困难人员；家庭成员患危重疾病医治，在扣除城乡医疗保险等医疗救助报销部分和其他社会帮困救助资金后，因个人负担的医疗费数额较大，直接导致家庭基本生活短期内难以维持的城乡低收入家庭；遇到突发事件，导致基本生活暂时困难的家庭；因子女教育支出造成基本生活暂时困难的贫困家庭；其他特殊原因造成基本生活暂时困难的家庭。

（二）不予实施临时生活救助对象。危害国家公共秩序和社会公共安全的，因打架斗殴、赌博、吸毒等原因导致家庭基本生活困难的；参与政府明令禁止的非法组织活动的；拒绝管理机关调查、隐瞒或不提供家庭真实收入、出具虚假证明的；县人民政府认定的其他不予救助的人员。安全责任事故（含交通事故）肇事方原则上不给予救助。

二、临时救助标准

（一）因患危重病或重度残疾，造成生活暂时出现较大困难的家庭，根据病情给予500—30000元的救助；

1.一般病种或轻微摔伤等无法劳动造成临时生活困难的给予500—1000元救助；

2.轻度（早期）癌症、心脏病等给予1000—3000元救助；

3.重度癌症、心脏病及血液病等给予3000—5000元救助；

4.特别重大疾病造成家庭赤贫的或费用在扣除各类医疗报销（含其他救助）后仍超过3万元以上的，给予5000—30000元救助。

（二）因火灾等突发性意外事件，造成临时生活困难的，按1000—5000元标准执行；

1.火灾户未参加农房保险的给予救助1000元及临时过渡食宿物资；

2.火灾户已参加农房保险的给予救助2000元及临时过渡食宿物资；

3.因火灾造成家庭成员伤亡的受灾户给予3000—5000元救助和临时过渡食宿物资。

（三）家庭成员中有人遭遇车祸、溺水等人身意外伤害，发生临时生活困难的，给予1000—5000元的救助；

1.交通事故造成一般性身体伤害的给予1000元救助；

2.交通事故、溺水造成重大身体伤害的给予2000—3000元救助；

3.交通事故、溺水造成家庭成员死亡的给予3000—5000元救助。

（四）贫困家庭有子女在高中、大学阶段就学，经其他救助帮扶后，仍然无力支付教育费用的，给予每名学生1000—5000元救助。教育、红十字会、慈善总会等对贫困学生已给予专项救助金的，不再救助；

（五）其他特殊原因造成家庭生活特别困难的城乡困难家庭，除已享受的基本生活保障外，可再给予相当于1—2个月家庭最低基本生活费用的救助。

三、申报程序

临时救助坚持“救急救难”和“公开、公平、公正”的原则，按照“村（居）民自愿申请、村（居）委会民主评议、乡（镇）政府审核（乡镇需指派专人负责，应到村入户进行审核，并单列出具审核意见，张榜公示）、县民政部门审批”的操作程序办理。管理审批机关自接到临时救助书面申请之日起，应当在20个工作日内（不含公示期）办结审批手续，并发放临时生活救助金，实行社会化发放。对因突发事件提请的紧急临时生活救助申请，应当适当简化审批程序，及时审批，增强救助实效性。

四、审批权限

1000元（含1000元）以下的由县民政局分管副局长签字审定；1000至3000（含3000元）的由县民政局局长签字审定；3000至10000（含10000元）的由县民政局班子会集体研究审定；10000至30000（含30000元）的由县民政局班子会集体研究后报县政府分管副县长签字审定。

五、救助限额

临时生活救助金原则上一年只能享受一次，一次性救助金最高限额为30000元。因多种原因导致基本生活困难的家庭重复申请临时生活救助的，每年不得超过两次，全年累计不能超过30000元。对符合条件的救助对象以相同事由申请临时生活救助时，享受的救助金额范围应相同。

六、本办法由县民政局负责解释。

七、本办法自印发之日起施行，有效期为二年。在本办法施行期间，如遇县级及以上人民政府出台新规定，本办法自行废止。
