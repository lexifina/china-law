# 九寨沟县人民政府办公室关于印发《九寨沟县2017年脱贫攻坚保险项目实施方案（试行）》的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县2017年脱贫攻坚保险项目实施方案（试行）》已经县委、县人民政府研究通过，现印发你们，请认真组织实施。

九寨沟县人民政府办公室

2017年6月19日

九寨沟县2017年脱贫攻坚

保险项目实施方案（试行）

为有效推动九寨沟县经济快速发展，切实增强农业、农村、农民抵御自然灾害和应对重特大意外事故的能力，促进我县脱贫攻坚工作有序推进。根据中国人民银行成都分行等七部门《四川省金融助推脱贫攻坚行动方案（2016-2020年）》的通知（成银发〔2016〕67号）、四川省财政厅关于印发《四川省农业保险保险费补贴管理办法的通知》（川财金〔2017〕12号）等文件精神，结合我县实际，制定本方案（试行）。

一、基本原则

在开展种养殖业、涉旅企业、农房保险推广过程中，务必遵循着眼长远，全程贯穿便民惠民的理念，坚持“政府组织推动、实体（农户）自愿参保、保险公司市场运作”的原则，采取地方政府通过财政保险费补贴等手段引导和鼓励实体（农户）自愿参保并承担部分保险费的方式开展保险购买工作，同时充分尊重实体（农户）自愿参保的自主选择权。

二、实施措施

按照“适度竞争、平稳有序”的原则，根据我县实际，综合考虑各方因素，在中国人民财产保险公司九寨沟县支公司和中华联合财产保险公司九寨沟县支公司协商同意的前提下，确定由中国人民财产保险公司九寨沟县支公司经办种植业保险；中华联合财产保险公司九寨沟县支公司经办养殖业保险。请两个保险机构负责印制简易宣传资料，组织人员成立专项工作组，拟定推动工作计划和实施方案，定期向政府报送工作开展进度。

三、工作步骤

（一）宣传启动阶段（6月10日—6月15日）

各乡镇人民政府、村两委积极配合保险公司发放宣传资料、并通过社区和村委会宣传栏、村务信息公开栏等方式做好宣传工作，重点宣传国家强农惠农、金融扶贫及财政保险费补贴政策，公司保险产品和服务方案要点（包括但不限于险种名称、保险责任、保险金额、财政补贴比例、被保险人自交保费、免赔规定、赔偿标准、出险报案、理赔渠道等）。

（二）整体推进阶段（6月15日—6月30日）

各乡镇负责配合保险公司收集专合组织、种养殖户、集体经济等单位的投保需求调查表，保险公司根据需求情况及时上门收集资料、审核承保，出具保险凭证，各乡镇、村要积极动员参保、做到应保尽保、保全保足，保险公司要做好风险管理，对散种散养等不符合投保条件的要做解释沟通工作。

（三）查漏补缺阶段（7月1日—7月31日）

保险公司根据承保情况和乡镇、农水、扶贫移民局等部门进行数据核对，查找应保未保名单，再次上门宣传动员，提高承保面、覆盖率。各乡镇、县农水局、县扶贫移民局等部门要及时将新投产的种养殖项目信息和保险公司对接，作到投产一项、投保一项，避免产业漏保。

（四）防灾防损阶段（6月15日以后）

保险公司要会同气象、农水等部门做好日常防灾防损工作，提前制定预案，树立防重于救、救胜于赔的宗旨，最大限度降低风险损失，实现保险企业、产业主体共赢局面。

本方案试行期为1年。
