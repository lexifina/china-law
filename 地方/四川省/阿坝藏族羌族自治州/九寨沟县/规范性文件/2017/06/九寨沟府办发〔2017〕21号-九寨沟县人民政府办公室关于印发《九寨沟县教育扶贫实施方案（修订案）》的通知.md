# 九寨沟县人民政府办公室关于印发《九寨沟县教育扶贫实施方案（修订案）》的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县教育扶贫实施方案（修订案）》已经县委、县人民政府研究通过，现印发你们，请认真组织实施。

九寨沟县人民政府办公室

2017年6月19日

九寨沟县教育扶贫实施方案（修订案）

为深入贯彻落实中央、省、州关于教育扶贫一系列安排部署和省委王东明书记关于义务教育保障的指示精神，加强建档立卡贫困家庭学生资助，确保全县建档立卡贫困家庭学生无一例因贫困而失学。按照“两不愁，三保障，四个好”的脱贫攻坚目标和《四川省脱贫攻坚义务教育保障2016年实施方案》要求，特制定本实施方案：

一、指导思想

高举中国特色社会主义伟大旗帜，以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入学习贯彻习近平总书记系列重要讲话精神，落实国家扶贫攻坚总体部署，把教育扶贫作为扶贫攻坚的优先任务，调动社会各界力量，广泛筹措资金，资助建档立卡贫困学生完成学业，使学生不因家庭经济困难而失学，为建设“全域奔康、幸福九寨”作出贡献。

二、加大贫困家庭学生上学保障力度

（一）全面落实十五年免费教育政策

认真落实《阿坝州十五年义务教育经费保障机制实施意见》，按照“明确各级责任、加大财政投入、提高保障水平”的基本原则，从2013年秋季学期开始，逐步将学前教育、九年义务教育、普通高中教育全面纳入公共财政保障范围，建立“州级补助、以县为主”的十五年免费教育经费保障机制。全面实施学前教育“一免一补”、义务教育“三免两补”、高中教育“两免一助”政策，确保我县适龄儿童、青少年学生全面入学。

1.政策范围。全县所有在校就读的适龄儿童及青少年学生。

2.政策标准。一是学前教育实施“一免一补”政策。在园注册就读幼儿，减免保教费75元/生.月（一年按10个月计算，共750元）；享受幼儿午餐补助3元/生.天（全年按200天计发，全年600元）。二是义务教育实施“三免两补”政策。义务教育阶段学生均享受免杂费、免书费、免费提供作业本和享受寄宿制学生生活补助和膳食补助。即免学杂费（小学生600元/生.年、初中生800元/生.年）、免书费(小学90元/生.年、初中180元/生.年)、免费提供作业本（小学30元/生.年、初中40元/生.年）；寄宿制学生生活费补助1700/生.年（170元/生.月，全年按10个月计算)，膳食补助800元/生.年(4元/生.天，全年按200天计发)。三是高中教育实施“两免一助”政策。高中注册在校学生均享受免学杂费、教材费政策；50%的学生享受普通高中国家助学金（覆盖所有建档立卡贫困家庭学生）。标准：学杂费920元/生.年（基准学费620元，生均公用经费300元），教材费600元/生.年；普通高中国家助学金2000元/生.年。

3.资金保障。按照《阿坝州人民政府关于进一步完善十五年免费教育经费保障机制的实施意见》（阿府发〔2016〕18号）及《九寨沟县人民政府办公室关于印发<九寨沟县进一步完善十五年免费教育经费保障机制实施方案>的通知》（九寨沟府办函〔2016〕135号）精神，由省州县分项目、按比例分担，予以保障。

（二）协助落实“9+3”免费中职教育资助政策

在“9+3”学校、州内中职学校就读的学生享受免学费、提供生活费补助和交通、住宿、书籍等杂费补助政策。

1.受助范围。“9+3”学校在读学生及州内中职学校在读学生。

2.政策标准。州外就读学生享受免补学杂费、生活费等共18300元，（其中免学费2000元/生.年，三年计6000元；生活费补助第一、二学年3000元/生.年，第三学年每生1500元，三年共计7500元；杂费补助1500元/生.年，三年共计4500元。同时享受“城镇居民医疗保险”，个人应缴的保险费由国家承担。新生入学当年，每人有300元冬装补助费）。

州内中职校就读免补学杂费、生活费等共10000元，（其中免学费2000元/生.年，三年共计6000元；生活费补助，前两年1500元/生.年，第三年每生1000元，三年共计4000元）。

3.资金保障。国家财政保障，学校统一发放。

（三）协助落实高校（含中职、技工）贫困学生生活补助政策

1.受助范围。普通本科高校和高等职业学校全日制本专科在校家庭经济困难学生，中等职业学校所有全日制在校农村学生及城市家庭经济困难学生。

2.政策标准。一是落实国家励志奖学金制度。对普通本科高校和高等职业学校全日制本专科在校生中品学兼优的家庭经济困难学生，给予5000元/生.年的资助。二是落实国家助学金制度。普通本科高校和高等职业学校家庭贫困学生，平均给予2000元/生.年的资助（各地根据实际情况在1000—3000元/生.年范围内确定2-3档，其中建档立卡贫困家庭学生享受国家助学金3000元/生.年）；所有全日制中等职业学校在校农村学生和城市家庭经济困难的学生，给予1500元/生.年的资助，国家资助两年，第三年实行学生工学结合、顶岗实习。

在享受上述政策的基础上，从2016年秋季学期起，对全县建档立卡贫困家庭全日制学历教育正式学籍中职（含技工）学生再给予每生每学期500元的生活补助；2016年及以后被全国普通高等学校录取就读全日制本专科（含高职）的建档立卡贫困家庭学生，给予每生每年4000元标准的资助（其中学费资助2000元、生活补助2000元）。

3.资金保障。中央部门所属高校国家励志奖学金及国家助学金所需资金由中央负担。地方所属高校国家励志奖学金及国家助学金所需资金根据各地财力及生源状况由中央与地方按比例分担。其中，西部地区，不分生源，中央与地方分担比例为8∶2；中部地区，生源为西部地区的，中央与地方分担比例为8∶2，生源为其他地区的，中央与地方分担比例为6∶4；东部地区，生源为西部地区和中部地区的，中央与地方分担比例分别为8∶2和6∶4，生源为东部地区的，中央与地方分担比例根据财力及生源状况等因素分省确定。

4.申报程序。学生进入省学生资助网，注册登录“四川省建档立卡贫困家庭学生资助管理系统”进行在线申请，县级教育、人社、扶贫部门审核公示，公示无异议后，提交生成当年建档立卡贫困家庭学生资助发放名单。并由生源地教育或人社部门负责打卡发放资助资金。具体按照《四川省教育厅 四川省财政厅 四川省人力资源和社会保障厅 四川省扶贫和移民工作局〈关于实施建档立卡贫困家庭学生资助政策有关具体事项的通知〉》（川教函〔2016〕277号）文件规定程序申报。

（四）落实生源地信用助学贷款

按照“方便群众、防范风险、愿贷尽贷”的原则，对户籍在本县的家庭经济困难在校就读大学生，给予生源地信用助学贷款资助。

1.受助范围。具有中华人民共和国国籍，诚实守信，遵纪守法，并且已被根据国家有关规定批准设立、实施高等学历教育的全日制普通本科高校、高等职业学校和高等专科学校（含民办高校和独立学院，学校名单以教育部公布的为准）正式录取，取得真实、合法、有效的录取通知书的新生或高校在读的本专科学生、研究生和第二学士学生的家庭经济困难的学生。

2.贷款标准。借款人每年申请的贷款原则上最高不超过8000元，全日制研究生（含硕士研究生、博士研究生）申请贷款额度上限为12000元，主要用于解决学生在校期间的学费和住宿费问题。高校在读学生当年在高校获得了国家助学贷款的，不得同时申请生源地信用助学贷款，其他资助帮扶政策与生源地助学贷款可同时享受。

3.资金保障。国家开发银行各分行及有关金融机构的分支机构按照有关精神和国家助学贷款管理的有关规定、制度保障实施。

4.申报程序。实行网上申报，学生注册登录后，按网络申报程序进行本人申请——乡村认定——县资助中心审查、签订合同——高校回执确认——发放贷款。具体程序按照国家开发银行生源地助学贷款基本要求和操作流程进行申报。

（五）建立县级教育扶贫救助基金

九寨沟县建立基数为500万元的县级教育扶贫救助专项基金，对户籍在本县区域内的建档立卡贫困家庭学生，在享受现有教育保障制度和助学帮扶政策（含免学杂费、助学金、生活补助、扶贫资助、助学贷款等）基础上，仍存在与子女就学直接相关的特殊困难给予资助。

1.救助范围。户籍在本县区域内的建档立卡贫困家庭学生。

2.救助时间。脱贫攻坚期间。

3.救助内容。学前教育阶段：可对幼儿伙食费等进行救助。

义务教育阶段：可对学生购置校服、文具、辅导资料、校内伙食等进行救助。高中教育阶段：可对学生教辅资料、住宿费、生活费等进行救助。高等教育阶段：可对学生交通费、学费、住宿费、生活费等进行救助。

4.资助标准。原则上每户救助标准为500-5000元/年，即学前教育建档立卡贫困家庭学生救助1000元/生.年，小学阶段建档立卡贫困家庭学生救助1000元/生.年，初中建档立卡贫困家庭学生救助2000元/生.年，高中阶段建档立卡贫困家庭学生救助3000元/生.年，全日制大专院校录取的建档立卡贫困家庭学生救助4000元/生.年；当一户建档立卡贫困家庭有两个以上学生，且救助标准合计超过5000元时，建档立卡贫困家庭应向县人民政府提出申请，由县人民政府审议确定救助金额。

5.资金保障。通过省级财政补助、州县财政预算、社会捐助、对口支援、基金收益和其他合规资金注入等方式筹措资金。

6.申报程序。申领程序遵循“个人申请→村级初审公示→乡镇复审公示→县级部门审定公示→拨付发放”的基本管理程序。

（1）凡符合教育扶贫救助基金救助条件的建档立卡贫困家庭在校学生在县内就读的由学生或其家长向就读学校提出申请（申请内容包括家庭人口数、经济来源、经济收入、困难状况等资助理由），领取申请表；县外就读的学生（如大学生等）由学生或其家长向当地乡（镇）人民政府提出申请，并领取申请表。

（2）学校和乡镇按照教育扶贫救助基金救助条件对申请对象进行初审，符合条件的发放“九寨沟县教育扶贫救助基金救助申请表”。

（3）村两委会按照教育扶贫救助基金救助条件对申请对象进行审查，符合条件的在村内进行公示（公示时间不少于5天）、公示无异议后签署意见、出具证明（公示证明和贫困证明）、拟定救助对象，并报乡（镇）人民政府。

（4）乡（镇）人民政府按照教育扶贫救助基金救助条件对上报的资助对象进行审核，符合条件的予以公示（公示时间不少于5天）、公示无异议后签署意见、出具证明（公示证明和贫困证明），核实资助对象。县内就读的交学校汇总、县外就读的填报《九寨沟县教育扶贫救助基金救助学生信息表》及收集相关证明材料交九寨沟县学生资助管理中心汇总。

（5）学校对拟定的救助对象在校内予以公示（公示时间不少于5天），符合条件的填报《九寨沟县教育扶贫救助基金救助学生信息表》、并收集相关证明材料交九寨沟县学生资助管理中心汇总。

（6）学生资助管理中心将汇总后的名单交九寨沟县扶贫移民局审核。

（7）九寨沟县扶贫移民局审核后符合条件的由九寨沟县教育局审定救助对象。

（8）县教育局将建档立卡贫困家庭学生救助金采用直接“打卡”的方式发放，个别不具备直接“打卡”条件的地方，允许采取开具现金支票的方式发放。采取现金支票发放方式的需按国家《现金管理暂行条例》规定执行。

（9）村委会和学校将救助金发放情况予以公示（公示时间不少于5天）。

（六）治理教育乱象，防止增加贫困家庭经济负担

加大教育乱收费、滥订教辅资料和有偿补课、违规补课等教育乱象整治力度，建立教育乱象整治工作组随时对教育乱象进行督查整治，防止增加贫困家庭经济负担。对师德败坏有损教师形象的、违规收受礼品礼金的、乱订教辅资料的、体罚学生或变相体罚学生等教育乱象发现一起查处一起，对典型案例要指名道姓公开通报曝光，情节严重的，依法依规给予开除处分或解除劳动合同，并撤销其教师资格；涉嫌犯罪的，将移送司法机关处理。确保家庭经济困难学生能上学、上好学。

三、工作要求

（一）强化组织领导，明确工作责任。各有关部门要高度重视，按照《四川省教育厅 四川省财政厅 四川省人力资源和社会保障厅 四川省扶贫和移民工作局关于实施建档立卡贫困家庭学生资助政策有关具体事项的通知》（川教函〔2016〕277号）、《九寨沟县人民政府办公室关于印发〈九寨沟县进一步完善十五年免费教育经费保障机制实施方案〉的通知》（九寨沟府办函〔2016〕135号）等文件要求，加强协调配合，明确职责分工，落实专门人员，形成多部门协作、共同推进教育扶贫的工作机制。并结合我县实际，制定切实可行的教育扶贫专项基金管理使用办法，足额落实配套资金，确保政策全面落实到位。各学校要落实专门人员负责此项工作，积极配合有关部门，认真审核并及时提供学生真实、准确的就读信息。

（二）加强宣传引导，确保应助尽助。各乡镇、扶贫移民局、教育局及各学校要通过主流媒体报道、宣传手册、手机短信、网络媒体等多种渠道，全方位准确宣传建档立卡贫困家庭学生资助政策和资助申请办法，让所有符合条件的学生和家长知晓政策内容，明确申请方式，清楚申请时间和具体流程。要加强与学生、家长的沟通联系，对不符合资助政策的申请人，要耐心做好学生本人及其家长的解释工作。

（三）加强资金监管，确保资金安全。教育局要对教育扶贫专项基金实行专账核算，严格资金拨付、发放过程管理，严把受助学生资格审核关，切实加强资助名单审核公示和数据统计上报工作，确保做到不冒领、无遗漏。财政局和审计局要加强审计监督，将教育扶贫专项基金纳入审计内容定期审计。要建立健全责任追究制度，对因审核把关不严、资金发放不及时不到位等情况，严格追究相关人员责任。
