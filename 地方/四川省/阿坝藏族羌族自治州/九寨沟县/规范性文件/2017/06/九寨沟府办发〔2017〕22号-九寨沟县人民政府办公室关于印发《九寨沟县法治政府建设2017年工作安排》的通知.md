# 九寨沟县人民政府办公室关于印发《九寨沟县法治政府建设2017年工作安排》的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县法治政府建设2017年工作安排》已经县政府研究同意，现印发你们，请认真遵照执行。

九寨沟县人民政府办公室

2017年6月19日

九寨沟县法治政府建设2017年工作安排

2017年，全县法治政府建设要紧紧围绕《法治政府建设实施纲要（2015—2020年）》、《阿坝州法治政府建设工作方案（2017-2020年）》和《九寨沟县法治政府建设工作方案（2017-2020年）》的安排部署，进一步解放思想，创新举措，求真务实，扎实推进年度阶段工作落地落实，在法治政府制度建设、执法队伍培训、重点领域执法、规范性文件审查等方面下功夫，为我县“全域发展，绿色崛起”战略提供有力的法治保障。

一、全面推进法治政府建设

（一）认真贯彻落实法治政府建设相关政策文件。切实加大中共中央、国务院印发的《法治政府建设实施纲要（2015—2020年）》、《阿坝州法治政府建设工作方案（2017-2020年）》、《九寨沟县法治政府建设工作实施方案(2017-2020年)》的学习宣传和贯彻执行力度，落实工作责任，明确推进进度，确保法治政府建设各项任务扎实有效推进。

责任单位：县法制办、县级各部门、各乡（镇）人民政府

（二）建立法治政府建设第一责任人职责清单。根据《党政主要负责人履行推进法治建设第一责任人职责规定》，细化法治政府建设第一责任人责任，建立职责清单，采取有效措施推进落实。上级政府应当对下级政府主要负责人履行推进法治政府建设第一责任人职责情况开展定期检查、专项督查。对不认真履行第一责任人职责的，年度内发生多起重大违法行政案件造成严重后果的，依法追究主要负责人责任。

责任单位：县法制办、县级各部门、各乡（镇）人民政府

（三）强化组织领导。一是签订《2017年法治政府建设责任书》。充分发挥法治政府建设工作领导小组协调督促指导作用，与县级行政执法部门、各乡（镇）人民政府签订《2017年法治政府建设责任书》，一级抓一级，层层压紧压实 2017年法治政府建设各项工作。二是建立健全年度法治政府建设工作报告机制。每年第一季度县人民政府主动向县委及人大常委会报告上一年度法治政府建设情况。县政府每年第一季度要听取乡（镇）人民政府、县政府工作部门上一年度法治政府建设工作报告。县政府常务会议每年至少听取2次推进依法行政、建设法治政府工作汇报，研究解决有关问题，部署推进依法行政工作的具体任务和措施。

责任单位：县法治政府建设工作领导小组成员单位、县政府办公室、县依法治县办、各乡（镇）党委、政府按相应职责分别负责

（四）完善工作机制。一是根据阿坝州法治政府建设绩效评估考核细则规定，提高法治政府建设考评指标在政府绩效考核体系中的比重，扩大考评对象范围，改革和完善考评方式，强化考评结果应用力度。二是建立健全领导干部任前法律知识考试和依法行政能力测试机制。将法律知识考试和依法行政能力测试结果作为领导干部任职的重要参考。

责任单位：县委组织部、县纪委、县政府办公室、县委县政府目标督查办、县法制办、县司法局

（五）提升履职能力。一是进一步提高政府法制部门工作人员履职能力，加强政府法制部门履行合法性审查、行政复议、执法监督、依法行政业务指导能力，配齐配强专（兼）职人员。二是加强行政执法、行政复议和政府法律顾问队伍建设，创新政府法治人才选拔、培养机制。

责任单位：县委编办、县委组织部、县人社局、县司法局、县法制办、乡（镇）人民政府按相应职责分别负责

二、依法全面履行政府职能

（六）深化行政审批制度改革。全面清理行政审批事项，取消非行政许可审批事项，承接落实国务院、省政府、州政府取消下放的行政审批事项；积极开展好相对集中行政许可改革试点工作；对保留的行政审批事项，实行目录化、编码化管理。2017年，实现行政审批服务部门进驻中心100%，行政审批服务事项进驻服务窗口100%。

责任单位：县委编办、县发改局、县政务服务中心、阿坝州公共资源交易中心九寨沟分中心、县法制办

（七）明晰政府权责。一是建立县本级行政权力清单动态调整机制，完善县本级行政权力清单，实行全县统一的行政权力清单目录化、编码化管理，向社会公布县行政权力清单和责任清单。二是根据国务院、省政府有关规定，做好行政事业性收费和政府性基金清理工作。实行行政事业性收费和政府性基金目录清单制度，按照上级财政部门相关规定调整、公布行政事业性收费和政府性基金清单。三是推进机构、职能、权限、程序、责任法定化，优化机构设置，理顺职责关系，根据职能调整核定“三定”方案，优化工作流程，界定部门责任。四是2017年12月，行政机关建立健全各项工作制度，重点将权力事项、办事程序、执法流程以及部门工作所依据的主要法律、法规、规章等汇编成册、公开发布，推进制度规范全覆盖。五是全面实施工商营业执照、组织机构代码证、税务登记证等“五证合一”、“一照一码”。 按照国家、省、州的统一部署，推行电子营业执照和全程电子化登记，实行“一址多照”和“一照多址”。

责任单位：县委编办、县发改局、县财政局、县工质食药监局、县国税局、县地税局、县政务服务中心、县法制办

（八）推进“诚信九寨”建设。一是坚持问题导向，积极探索九寨沟特色的信用体系建设路径，大力推进政务诚信、个人诚信、电子商务领域诚信和司法公信建设，不断提高全社会诚信意识和诚信水平、改善经济社会运行环境，在全县广泛形成“守信奖励、失信惩戒”的良好氛围。二是严格执行行政决定事项，撤销或变更已经生效的行政决定须有法定事由并经过法定程序。严格履行合同和协议，依法履行判决、裁定、行政复议、仲裁决定等生效法律文书。三是建立公务员诚信档案，将公务员个人重大事项报告、廉政记录、违法违纪违约行为等信用信息纳入档案，将公务员诚信记录作为考核、任用和奖惩的重要依据。

责任单位：县委组织部、县委编办、县发改局、县财政局、县人社局、县工商质量技术和食药监局、县国税局、县地税局、人行九寨沟县支行

（九）完善社会管理。一是编制社会组织提供的公共服务目录，明确解决事项的范围。二是建立网络社团管理机制，规范和引导网络社团健康发展，提高网络信息安全风险防控。三是健全落实领导责任制，完善立体化社会治安防控体系，推进社会治安综合治理网格化建设，有效防范管控社会安全风险，建立健全公共突发事件防范处置应对机制。四是全面落实“党政同责、一岗双责、齐抓共管、失职追责”的安全生产责任体系。五是落实政府购买公共服务制度，制定并公开政府购买公共服务目录，加强监管，引入竞争机制，推进公共服务提供主体和提供方式多元化。六是贯彻执行阿坝州生态环境保护条例、湿地保护条例、野生动物植物保护条例、实施草原法的变通规定等民族自治法规。完善并严格实行环境信息公开、环境影响评价和污染物排放总量控制制度。七是严格执行排污权有偿使用出让标准，深化电力、天然气、供水等资源型产品价格和税费改革，推进能源价格市场化改革。八是严格生态环境损害责任追究，认真落实生态环境损害赔偿制度。实行自然资源资产离任审计制度，在水资源、土地资源、矿山生态环境、大气污染防治等领域，实行对领导干部的离任审计。

责任单位：县公安局、县民政局、县发改局、县安监局、县财政局、县环林局、县农水局、县审计局、县综治办、各乡(镇)人民政府按相应职责分别负责

三、完善依法行政制度体系

（十）加强规范性文件监督管理。一是落实规范性文件合法性审查制度，未经合法性审查或审查不合法的，不予审议印发。落实规范性文件统一登记、统一编号、统一公布制度，严格执行《阿坝州行政规范性文件“三统一”制度》。二是完善规范性文件备案审查制度，依法及时报备。加强备案审查能力建设，把所有规范性文件纳入备案审查范围，加大备案审查力度，做到有件必备、有备必审、有错必纠。三是健全公民、法人和其他组织对规范性文件的建议审查制度。对公民、法人和其他组织提出的规范性文件异议审查申请，依法及时处理并反馈处理结果。四是实行规范性文件动态管理制度，每2年开展一次行政规范性文件定期清理工作。2017年年底，完成2015年5月1日至2017年4月30制发的规范性文件清理工作，清理结果向社会公布。五是按照国家、省、州的统一部署，对县人民政府成立以来的政府文件对照清理标准、工作要求进行全面清理，向州人民政府报告清理结果。

责任单位：县政府办公室、县政府法制办、县级相关部门及各乡镇人民政府

四、推进行政决策科学化、民主化、法治化

（十一）健全行政决策机制。一是建立重大行政决策事项目录，落实重大行政决策公众参与制度。做出重大行政决策前，将该决策的内容、事项、依据等公开，组织相关部门和群众代表参加座谈会、听证会，广泛听取群众特别是利害关系人的意见建议。二是建设重大行政决策公众参与平台。三是制定《九寨沟县重大行政决策专家论证办法》，建立健全行政决策咨询论证专家库。四是贯彻执行《四川省社会稳定风险评估办法》，全面落实重大决策社会稳定风险评估机制。五是严格落实《九寨沟县人民政府行政决策合法性审查规定》。完善行政机关内部重大决策合法性审查机制，未经合法性审查或经审查不合法的，不得提交讨论。2017年底，实现合法性审查制度全覆盖。六是充分发挥党委、政府法律顾问作用。

责任单位：县政府办公室、县维稳办、县法制办、县级各部门，乡（镇）人民政府按相应职责分别负责

（十二）落实行政决策责任。贯彻执行《四川省重大行政决策责任追究暂行办法》、《关于对州委州政府重大决策部署执行不力实行问责的办法（试行）》。严格实施重大决策终身责任追究制度及责任倒查机制。对决策严重失误或依法应该及时作出决策但久拖不决造成重大损失、恶劣影响的，追究相关责任人员的党纪政纪和法律责任。

责任单位：县监察局、县级各部门、乡（镇）人民政府按相应职责分别负责

五、坚持严格规范公正文明执法

（十三）改革行政执法体制。根据省、州统一安排结合本县实际积极推进旅游、林业及城市管理等领域的综合行政执法改革工作。探索推进综合执法体制改革，整合部门内部执法机构和职能，调整部门内部相关机构职能职责，建立完善制度机制，强化工作监管，提高执法水平，确保依法行政。

责任单位：县旅发局、县委编办、县县工质食药监局、县法制办和县级各行政执法部门、乡(镇)人民政府按相应职责分别负责

（十四）加强重点领域行政执法。加强市场监管、环境保护、安全生产、道路交通、公共卫生、民族宗教、旅游领域、扶贫等领域执法。完善食品、药品、农畜产品等重要商品安全和违反公平竞争秩序的失信惩戒制度，按照省、州统一要求,加大执法力度，严厉打击违法行为。构建信用监管、信息监管、法制监管等多位一体的新型监管模式。完善特种设备安全监管体系。

责任单位：县农水局、县工质食药监局、县环林局、县安监局、县交通局、县公安局、县卫计局、县民宗局、县综治办、县维稳办、县旅发局、县扶贫移民局、县法制办、县级各行政执法部门、乡(镇)人民政府按相应职责分别负责

（十五）全面落实行政执法责任制。严格确定执法责任。建立健全常态化责任追究机制。各行政执法部门应将本部门的法定职权分解落实到执法机构和执法岗位,明确执法机构、执法岗位和执法人员的责任,并向社会公开。贯彻执行《阿坝州行政执法人员管理办法（试行）》。依法界定行政执法部门的主体资格、执法依据、职责权限并向社会公示。

责任单位：县委编办、县法制办、有行政执法职责的县级部门、乡（镇）人民政府按相应职责分别负责。

（十六）加大培训力度。一是稳步推进“互联网+”培训模式，认真开展全县行政执法人员通用法律知识培训工作。二是按照《阿坝州行政执法人员管理办法（试行）》的规定，组织开展行政执法人员通用法律知识培考试工作；县级各部门要加大系统内执法专业人员的专业法律培训和考试，切实提高行政执法人员业务知识水平和能力。未经资格考试的人员不得申领行政执法证，不得参与行政执法工作，严把执法队伍的“入口关”。

责任单位：县法制办、县级各行政执法部门、各乡(镇)人民政府

（十七）加强行政执法监督工作。一是积极开展执法案卷评审工作。组织全县执法案卷的评审工作，评选优秀案卷，加大执法指导力度。二是县级主要行政执法部门制定案例指导制度，每年在县政府门户网站上公布2件以上典型案例。贯彻执行《四川省行政执法全过程记录制度》。杜绝随意执法、执法程序违法、执法证据不全等现象发生。三是贯彻执行《四川省行政执法监督条例》，加大重点领域的行政执法监督检查力度，落实行政执法权限争议协调机制，及时解决行政执法机关之间的权限争议。

责任单位：县法制办、县级各行政执法部门

（十八）推进行政执法和刑事司法衔接机制。完善案件移送标准和程序，建立健全法制机关、行政执法机关、公安机关、检察机关、审判机关信息共享、案情通报、案件移送制度。坚决杜绝有案不移、有案难移和以罚代刑等现象。定期召开“两法衔接”全体成员联席会议，通报工作开展情况。

责任单位：县检察院、县法制办、县法院、县监察局、县公安局、县级各行政执法部门按相应职责分别负责

（十九）加强重点领域和重要环节监督。组织开展对财政资金分配使用、国有资产监管、政府投资、公共资源转让、公共工程建设等权力集中的部门和岗位、项目进行监督检查。

责任单位：县发改局、县财政局、县国资公司、县国土局、县环林局、县交通运输局、县审计局、县法制办、乡（镇）人民政府按相应职责分别负责

（二十）加强行政复议工作。一是贯彻执行《阿坝州行政机关应诉办法》，落实行政复议委员会制度。提高行政复议办案质量，纠正违法或者不当的行政行为，发挥行政复议工作的纠错、监督功能。二是重大疑难复杂案件交由行政复议委员会审理，由案审会集体审议决定，增强行政复议的专业性、透明度。三是加强行政复议能力建设。贯彻执行《中华人民共和国行政复议法》及其实施条例对行政复议办案人员不少于2名的规定。四是提升行政复议规范化建设水平。各行政执法部门要及时回应司法建议和行政复议建议，办理情况抄送县政府法制机构。

责任单位：县法制办、县委编办、县财政局、县机关事务管理局、乡（镇）党委、政府按相应职责分别负责

（二十一）依法有效化解社会矛盾纠纷。建立健全社会矛盾预警机制，完善依法应对群体性及突发性事件预案。加强应急机制建设，强化依法处置群体性及突发性事件的能力。完善救济救助机制。通过社会救助方式的多元化，形成救助工作合力，实现社会救助工作组织体系与救助工作的专业化。健全行政调解制度，规范行政调解程序，加强行政调解队伍建设。依法开展行政调解，及时化解矛盾纠纷。认真落实《阿坝州行政行政机关行政应诉办法》，按照“谁主管谁应诉”、“谁主办谁出庭”的原则强化各级行政机关及其工作人员行政应诉的法定职责。

责任单位：县综治办、县维稳办、县信访局、县应急办、县公安局、县民政局、县法制办、乡（镇）人民政府按相应职责分别负责

（二十二）推进信访工作。完善信访工作机制。贯彻执行《信访条例》和四川省信访信息化建设“十三五”规划。依托四川省网上信访信息系统，实现信访业务网上流转；依托党委政府门户网站,畅通信访渠道。强化属地和部门责任，健全及时就地解决群众合理诉求机制。完成信访工作手机移动应用平台开发，完善视频接访系统。严格执行“诉访分离”规定。实行涉法涉诉信访与普通信访相分离，建立受理、甄别和分类处理机制，完善审查办理机制，健全刚性终结及移交机制，加大依法惩处违法信访行为的力度，适时公开审理一批典型案件，加强宣传引导，把涉法涉诉信访处理工作纳入法治轨道。

责任单位：县信访局，县法制办、乡（镇）党委、政府按相应职责分别负责

六、强化对行政权力的制约和监督

（二十三）自觉接受党内监督、人大监督、民主监督、司法监督。一是建立健全党风廉政建设检查考核制度机制，明确检查考核的内容、方法、程序。贯彻落实《中共中央、国务院关于实行党风廉政建设责任制的规定》。在党委的领导下，各级政府及其部门党组（党委）要切实履行党风廉政建设和反腐败工作的主体责任，对本级政府本部门党风廉政建设负总责。二是认真执行向本级人大及其常委会报告工作制度，接受询问和质询。三是健全知情明政机制。政府有关部门向政协定期通报有关情况，为政协委员履职提供便利、创造条件。及时研究办理政协委员提案。四是贯彻执行《阿坝州行政机关行政应诉办法（试行）》。落实行政机关负责人依法出庭应诉制度。支持审判机关依法受理行政案件，尊重并执行审判机关生效裁判，积极配合检察机关对行政违法行为依法进行监督。2017年，规范使用四川省统一行政应诉法律文书。

责任单位：县监察局、县政府办公室、县法制办等县级有关单位、乡（镇）党委、政府按相应职责分别负责

（二十四）加强行政监督和审计监督。一是建立健全常态化、长效化监督制度。改进上级行政机关对下级行政机关的监督，加强政府法制监督。二是加强对政府内部权力的制约。对财政资金分配使用、国有资产、监管、政府投资、政府采购、公共资源转让、公共工程建设等权力集中的部门和岗位实行分事行权、分岗设权、分级授权，定期轮岗，强化内部流程控制，防止权力滥用。三是建立健全监察监督工作机制，切实履行监督责任，确保廉政建设各项任务落实。

责任单位：县级各部门、乡（镇）人民政府。

（二十五）完善社会监督和舆论监督机制。是建立健全网络舆情监测、收集、研判，完善部门间舆情联动处置工作机制，推动网络监督规范化、法治化。

责任单位：县监察局、县委宣传部、县网信办、乡（镇） 人民政府按相应职责分别负责

七、全面推进政务公开

（二十六）加大政务公开力度。按规定编制、修订并公布政府信息公开指南和政府信息公开目录，并及时更新。完善政府信息主动公开、发布协调、工作考核、社会评议、年度报告、责任追究等配套制度，明确政府信息公开范围、内容、方式和程序。依法受理并在法定期限内及时答复公民、法人和其他组织提出的政府信息公开申请。完善政府新闻发言人、突发事件信息发布等制度，做好对热点敏感问题的舆论引导，及时回应人民群众关切。创新政务公开方式，加强互联网政务信息数据服务平台和便民服务平台建设，提高政务公开信息化、集中化水平。

责任单位：县政府办公室、县信息公开办、县委宣传部、县法制办、乡（镇）党委、政府按相应职责分别负责

八、加强政府工作人员法治思维和依法行政能力建设

（二十七）全面落实领导干部学法制度。严格落实政府常务会议和部门办公会议学法制度。制订领导干部年度学法计划并组织实施。开展4次法治政府建设大讲堂活动。县、乡（镇）政府每年至少举办1期领导干部法治专题培训班和2期以上法治专题讲座。

责任单位：县政府办公室、县法制办等县级有关部门，乡（镇）人民政府

（二十八）强化考核评价。一是建立法治政府建设责任人约谈制度。对法治政府建设考核结果较差的乡（镇）和部门，约谈主要领导或分管负责人，情节严重的予以行政问责。二是邀请“两代表一委员”，组织企事业单位、新闻媒体和社会公众，或委托专门的评估机构，采取座谈、走访、发放评估卡、意见书等方式，每年至少开展一次法治政府建设工作评估。

责任单位：县委组织部、县监察局、县政协办公室、县法制办、各乡（镇）党委、政府按相应职责分别负责
