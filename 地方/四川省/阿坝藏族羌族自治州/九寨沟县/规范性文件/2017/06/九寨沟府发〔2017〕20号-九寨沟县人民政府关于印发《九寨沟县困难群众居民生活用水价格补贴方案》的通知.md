# 九寨沟县人民政府关于印发《九寨沟县困难群众居民生活用水价格补贴方案》的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县困难群众居民生活用水价格补贴方案》已经中共九寨沟县四届县委第17次常委会议和县十四届人民政府第8次常务会议审议通过，现印发你们，请遵照执行。

九寨沟县人民政府

2017年6月6日

九寨沟县困难群众居民生活

用水价格补贴方案

为切实减轻困难群众生活负担，助推全县脱贫攻坚事业，结合我县实际，特制定本方案。

一、补贴对象

1.供区内享受城镇最低生活保障和农村最低生活保障对象中无固定工作和无固定经济收入、因病因灾因学造成家庭生活特别困难的人员；

2.供区内建档立卡精准扶贫户家庭成员；

3.供区内无固定经济收入、生活困难的残疾人员；

4.供区内分散供养的三无人员、五保户；

5.供区内因病因灾因学致贫困难户的家庭成员。

具有多重身份的受补贴对象只享受一次补贴，不得重复享受。

二、申请和审批程序

1.建立动态价格补贴机制，符合以上条件人员在次年3月底前就上年度居民生活用水价格补贴提出书面申请，填写《困难群众自来水价格补贴申请表》，并提供本人户口簿、身份证等相关证件；

2.村（居民）委会、所在乡镇逐级进行评议和审核，建档立卡精准扶贫户同时须扶贫移民局进行审核；

3.自来水厂对补贴对象上年度用水量按月进行审核；

4.民政部门进行汇总、审批、公示和资金兑现等工作。

三、补贴标准

按照3m3/人·月的用水量对补贴对象进行定额补贴。

四、补贴方式

困难群众居民生活用水价格补贴资金，由县人民政府在财政预算中安排，由县财政局按照社会救助资金划拨县民政局，县民政局按城乡社会救助资金管理办法进行发放，并注明困难群众居民生活用水价格补贴，确保专款专用。

五、该方案从2017年9月1日起与调整后的居民生活用水价格同步执行。
