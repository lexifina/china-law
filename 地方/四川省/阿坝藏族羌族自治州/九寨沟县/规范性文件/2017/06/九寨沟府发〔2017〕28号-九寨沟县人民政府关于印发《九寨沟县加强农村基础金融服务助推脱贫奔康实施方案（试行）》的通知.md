# 九寨沟县人民政府关于印发《九寨沟县加强农村基础金融服务助推脱贫奔康实施方案（试行）》的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县加强农村基础金融服务助推脱贫奔康实施方案（试行）》已经县十四届人民政府第10次常务会议审议通过，现印发你们，请抓好贯彻落实。

九寨沟县人民政府

2017年6月7日

九寨沟县加强农村基础金融服务

助推脱贫奔康实施方案（试行）

为贯彻落实县委、县政府《九寨沟县金融助推脱贫攻坚实施意见（2016—2020）》（九寨沟府办发〔2016〕44 号），持续改善农村基础金融服务环境，切实降低贫困地区金融服务成本，鼓励农村基础金融服务长效、高效发展，助推全县贫困村和贫困人口脱贫奔康，特制定本方案（试行）。

一、主要工作任务

一是通过在全县各无银行网点乡镇，及以贫困村为主的具备电力、通信等基础条件的行政村建设助农取款服务点（以下简称服务点），就近为贫困户、农村群众提供各类补贴、补助资金到账查询、取现、转账、汇款等基础金融服务，节省贫困户、农村群众支取补贴、补助款项的时间和资金成本。

二是加强对服务点的维护管理，建立健全激励机制，促进农村基础金融服务的可持续发展；在此基础上，选择部分具备条件的服务点逐步为贫困户、农村群众提供零钞兑换、旧币换新、假币鉴别、小额贷款、银行卡申请、金融投诉咨询、金融知识宣传等更多更好的金融服务，试点建设农村金融综合服务平台和农村金融综合服务站（以下简称服务平台、站）。探索整合金融、邮政、电信等功能，试点建设村级综合便民服务点。

二、工作原则

（一）普惠原则：让广大人民群众都能享受到便捷、低成本的基础金融服务。

（二）可持续原则：通过激励政策的实施，最大限度调动农村基础金融服务提供者的积极性，提升助农取款服务点利用率，促进其可持续发展。

三、激励政策

（一）县政府设立“农村基础金融服务奖补资金”

暂按“10万元/年”的奖补总金额纳入县财政年度预算，用于支持和鼓励金融机构消除全县金融服务空白乡镇村，各服务点（平台、站）持续、优质的为农村群及贫困户众提供服务，以及促进服务点的规范和递进发展。

（二）具体内容

1.规范化建设补贴

激励对象：严格按照农村金融服务“五个统一”标准（即统一标识、统一要求、统一制度、统一门槛、统一账册），店招和标识、标牌等外观风貌规范统一，内部机具、设备布置整洁美观的服务点。

激励方式：一次性补贴。

激励标准：经人民银行验收，达到“五个统一”标准的服务点，对其为按照统一规范制作店招、标识、标牌等费用支出，暂按2000元/个服务点的标准给予一次性补贴。

2.手续费补贴

激励对象：办理助农取款服务（小额现金支取）的服务点代理商户。

激励方式：按年补贴。

激励标准：对成功为农村地区的群众提供助农取款服务（小额现金支取）的，暂按1元/笔的标准，按年汇总统计后给予办理手续费补贴。

3.服务点持续服务奖励

激励对象：持续提供农村基础金融服务的服务点代理商户。

激励方式：分级评选、按年奖励。

激励标准：对全县持续提供服务的助农取款服务点，每年按标准（另行制定）评选出一等奖10名，给予1500元（暂定）的当年服务奖励；评出二等奖20名，给予1000元（暂定）的当年服务奖励；评出二等奖30名，给予500元（暂定）的当年服务奖励。

4.服务点优质服务奖励

激励对象：成功创建四川省助农取款服务示范点、农村金融服务示范站的助农取款服务点代理商户。

激励方式：一次性奖励。

激励标准：

（1）对成功创建为四川省助农取款服务示范点的，暂按1500元/个的标准给予一次性奖励；

（2）对成功创建为四川省农村金融服务示范站的，暂按3500元/个的标准给予一次性奖励。

四、管理措施

为进一步规范我县“农村基础金融服务奖补资金”的管理使用，确保其发挥助推脱贫奔康应有效果，人行九寨沟县支行将会同县财政局、县扶贫移民局制定相应的资金申报、拨付、管理等相关制度办法，另行印发。

五、其他要求

（一）本方案试行2年，“农村基础金融服务奖补”按年开展，次年完成对上一年度的奖补工作。

（二）各项奖补激励政策，由各服务点的主办金融机构依照规定程序和要求按年度申报，经人行九寨沟县支行、县财政局、县扶贫移民局共同审核拨付。

（三）本方案中的具体政策内容、激励对象和标准等，可在暂定总额范围内根据实际情况进行调整和调剂使用；“农村基础金融服务奖补资金”如超出暂定总额且确有增加需要的，可根据实际情况按规定程序申请追加。
