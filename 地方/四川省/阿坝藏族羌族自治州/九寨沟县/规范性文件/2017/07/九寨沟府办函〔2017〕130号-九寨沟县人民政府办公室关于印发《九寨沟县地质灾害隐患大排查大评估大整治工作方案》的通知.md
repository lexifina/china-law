# 九寨沟县人民政府办公室关于印发《九寨沟县地质灾害隐患大排查大评估大整治工作方案》的通知

各乡（镇）人民政府，县级各部门:

《九寨沟县地质灾害隐患大排查大评估大整治工作方案》已经县人民政府同意，现印发你们，请认真贯彻执行。

九寨沟县人民政府办公室

2017年7月1日

九寨沟县地质灾害隐患

大排查大评估大整治工作方案

为进一步做好九寨沟县地质灾害隐患大排查大评估大整治工作，根据《关于做好地质灾害和防汛安全隐患排查防治工作的紧急通知》（川办函〔2017〕135号）要求，结合我县实际，特制定本工作方案。

一、工作目标

采用群众普查与专业技术单位调查相结合、重点调查与一般核查相结合方法，建立以乡镇为主体、群众广泛参与、专业技术力量为支撑的全面工作格局，从7月1日起，用1个月左右时间对全县所有区域地质灾害隐患进行大排查，用3个月左右时间对全县重点区域进行大排查，对前期排查成果进行大评估，并依据大评估进行大整治，确保大排查工作覆盖全县每一个区域每一个角落，大评估、大整治工作覆盖每一个地质灾害隐患点，实现减少灾害损失向减轻灾害风险转变。

二、工作内容

根据《地质灾害排查规范》（DZ/T0284-2015）和《滑坡崩塌泥石流灾害调查规范（1:50000）四川实施细则》等规程规范，坚持“全域覆盖、突出重点”“群专结合、以专为主”“坡要到顶、沟要到头”的工作原则，在中央、省、州相关部门大力支持下，依托四川省国土资源、地矿等行业所属专业调查机构，通过资料收集、群众普查、专业调查，辅以无人机航拍、三维激光扫描、干涉雷达等新技术、新方法、新手段，扩大调查范围、提高调查工作可靠度，及早发现高位、具有隐蔽性的地质灾害隐患点，研判地质灾害发育分布现状及稳定性趋势，进一步摸清家底，前移防治关口。

（一）地灾隐患大排查。在充分收集已有成果的基础上，严格执行相关技术要求，对全县所有区域进行大排查，及时发现地质灾害隐患点，确保不留盲区、不留死角。在全县所有区域大排查的基础上，通过加强对已有隐患点核查、已建地质灾害治理工程复查复核、新增隐患点调查及人口聚居区地质环境调查、易发区工程项目地质灾害危险性评估防范措施落实情况检查，特别是要加强对居住区、学校、医院、公路沿线、旅游景区、工矿企业、建设工程施工地和营房进行重点排查并开展准确评估。

（二）地灾隐患防灾措施。对前期各阶段（排查、详查、评估等）工作发现的地质灾害隐患点，重点评价其发展变化情况、防灾措施落实情况等，并明确提出存在的问题和整改措施；对新发现的地质灾害隐患点，全面评价其类型、规模、成因及发展趋势，完善和落实各项防治措施；对已实施的地质灾害治理工程项目进行重点调查其防灾减灾效果，总结经验教训，提出完善治理工程的措施建议。对地质灾害危险区内在建工程项目，要对照危险性评估报告提出的防灾措施，并结合现场实际，检查其防灾措施落实情况，对措施不落实或落实不到位的，要及时提出整改意见和建议。

（三）地灾防灾避险培训。坚持“谁排查、谁宣讲”，同步推行地质灾害隐患点公告和防治知识宣传培训工作，结合发放宣传单、海报、宣传册、举办知识讲座、现场讲解、多媒体演示等多种手段，逐点实现地质灾害受威胁人员宣传培训全覆盖，让受威胁群众熟知地质灾害隐患点全面情况，明白各自在地质灾害隐患点辐射危险区内所处位置，清楚各自撤离路线和安全避险场所，切实增强群众防灾意识和能力，调动基层广大干部群众识灾防灾避灾报灾的主动性和积极性。

三、工作要求

（一）创新工作方式，消除盲区死角。各片区工作组要充分调动基层广大干部群众识灾避灾报灾的积极性，采取群专结合、人技结合、点面结合等方式，对全县所有区域进行大排查大评估大整治。各乡镇要对各地质灾害隐患点进行逐一登记造册，并根据专业地勘单位提出的防灾措施建议，逐点逐户落实到位，建立全民参与的地灾防范工作体系。

（二）及时公开信息，确保调查时效。对新发现的灾害隐患点或有变形的已有灾害隐患点，要在第一时间通过广播、电视、微信、短信、发放“两卡一表”、函件等方式告知受威胁群众，同时制定、细化和完善防灾预案，逐一落实监测责任人和监测员，建立警示标识标牌，对变形明显或有临灾征兆的灾害隐患点，各乡镇人民政府第一时间组织受威胁群众转移避让。

（三）边排查边整治，分类推进实施。县国土资源局要督促专业地勘单位对地灾隐患点进行评估，并逐一落实防范措施，逐一明确责任，逐一建立责任清单。各乡镇要逐点对标措施建议，坚持边查边整，特别是险情紧迫、危害大或短时间难以完成整治的隐患点，要采取主动预防避让措施，全力确保受威胁群众安全。

（四）强化保障措施，有序开展工作。各片区工作组和专业地勘队伍要认真贯彻“安全第一”安全生产方针，增强野外作业所有人员的自防意识，杜绝安全事故的发生。此外，鉴于此次大排查大评估大整治工作时间紧、任务重、范围广、要求高等特点，通过直接委托的方式开展工作。工作经费严格按照省、州要求执行，经费来源为财政资金。
