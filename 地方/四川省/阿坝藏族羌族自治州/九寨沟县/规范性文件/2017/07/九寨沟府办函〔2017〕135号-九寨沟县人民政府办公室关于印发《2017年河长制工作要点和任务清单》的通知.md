# 九寨沟县人民政府办公室关于印发《2017年河长制工作要点和任务清单》的通知

各乡（镇）人民政府，县级各部门，企事业单位:

《2017年河长制工作要点和任务清单》已经县政府同意，现印发你们，请认真贯彻执行。

九寨沟县人民政府办公室

2017年7月7日

2017年河长制工作要点和任务清单

按照《中共中央办公厅、国务院办公厅印关于全面推行河长制的意见》《中共四川省委办公厅、四川省人民政府办公厅关于印发〈四川省全面落实河长制工作方案〉的通知》《中共阿坝州委、阿坝州人民政府关于印发〈阿坝州贯彻落实全面推行河长制意见的实施方案〉的通知》和《中共九寨沟县委办公室、九寨沟县人民政府办公室关于印发〈九寨沟县“河长制”工作实施方案〉的通知》要求，为扎实有序推进我县河长制相关工作，特制定2017年河长制工作要点和任务清单。

一、总体要求

全面贯彻落实党的十八大和十八届系列全会精神，深入学习习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，紧紧围绕统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，牢固树立“治水抓生态就是讲政治、治水抓生态就是促转型、治水抓生态就是惠民生”的理念，坚持建设长江上游生态屏障和建设川西北生态经济示范区的目标不动摇，坚持生态优先，走绿色发展之路。深刻认识我县全面推行河长制在坚定促进转型发展、坚决守护绿水青山、全面落实主体功能区规划约束和严守资源环境生态红线等方面的重要性和紧迫性，扎实抓好河长制相关工作，做到相关制度和政策措施到位、组织体系和责任落实到位、工作方案到位、监督检查和考核评估到位。

二、主要思路

紧扣水资源保护、水域岸线管理、水污染防治、水环境治理、水生态修复和涉河湖执法监管六大任务，着力构建党政主导、部门联动、责任明确、协调有序的河湖管理保护组织领导体系。通过科学制定工作制度，形成高效有序常态化的工作机制。制定各级工作方案，编制一河一策管理保护方案，明确具体年度工作目标清单、问题清单、任务清单、责任清单，实行“1＋4”河湖管理保护工作模式，坚持河湖保护工作重心下移、工作下沉，全面开展清河、护岸、净水、保水行动。广泛开展宣传工作，增强公众对河湖管理保护的责任意识和参与意识，营造全社会关注河湖、保护河湖的良好氛围，确保2017年底全面建立河长制。

三、重点工作

（一）建立全面落实河长制组织体系。2017年3月10日前，成立九寨沟县全面落实河长制工作领导小组，设立总河长、县级河长、总河长办公室和县河长制办公室。5月底前，设立完成乡（镇）级河长制办公室。

（二）建立完善工作机制。2017年7月15日前，出台九寨沟县全面落实河长制工作领导小组运行规则、九寨沟县河长制会议制度、7条重要河流县级河长工作推进机制、县级河长联络员单位工作制度、2017年河长制工作要点和任务清单、7条重要河流管理保护投诉举报受理办法，制定九寨沟县河长制工作相关职责及分工。7月底前，建立九寨沟县河长制督导检查、验收、考核、问责等制度。2017年8月底前，县、乡级建立相关制度，明确河长制工作相关职责及分工，建立上下联动、部门协调、责任落实、同步推进的工作机制；建立县级河长制验收、考核、问责等制度，为年底前全省逐级开展河长制验收、考核工作建章立制。

（三）上报河湖名录、设立各级河长，公告河长信息。2017年6月10日前，上报全县河湖名录，设立各级河长；7月底前分级分批公告县、乡河长信息。2017年8月底前，在河湖岸边显著位置竖立河（段）长公示牌，注明河（段）长职责、河湖概况、管护目标、监督电话等内容。

（四）出台各级工作方案。2017年6月10日前，印发县级河长制工作方案；6月20日前出台县、乡级工作方案，细化落实各级工作目标、职责和任务分工。

（五）制定一河一策管理保护方案。2017年6月底前，省10大主要河流涉及我县相关乡（镇）提出4张2017年度工作清单，由县河长制办公室汇总上报；8月30日前，编制完我县一河一策管理保护方案，并上报州河长办；8月底前，县级联络员单位根据责任分工，按照河湖管理保护年度工作要求，编制完成县级31条河流4张2017年度工作清单，并报州河长制办公室； 11月底前，编制完成31条县级河流一河一策管理保护方案，并报州级河长批准后执行；形成“1＋4”河湖管理保护工作模式。

（六）建立县、乡河长常态化工作机制。2017年11月底前，研究制定县、乡级河段长巡河制度等；完善河湖突出问题的处置、解决机制，督促县、乡级河段长全面开展日常巡河、问题督办、情况通报、责任落实等工作；启动基层河段长清河、护岸、净水、保水四项行动，把河湖管理保护责任落实在基层、问题解决在基层。

（七）开展河长制宣传。利用各种媒体和传播手段，加强宣传引导，及时报道我县河长制工作动态和成效，增强公众河湖保护的责任意识和参与意识；鼓励、引导民间环保组织有序参与河湖管理保护，聘请相关专家学者、生态文明志愿者、政风行风监督员等对河湖管理保护工作进行监督和评价，适时开展河湖管理保护第三方评估，营造良好舆论环境。

（八）组织河长制工作考核验收。按照河长制工作考核验收制度，逐级实行差异化绩效考核评价，考核结果作为党政领导班子和有关成员综合考核评价的重要依据，作为领导干部自然资源资产离任审计和生态环境损害责任追究的重要内容。2017年12月底前，完成各级全面推行河长制工作验收，为在全州全面建立落实河长制打下坚实基础。

四、任务清单

（一）建立县级河长制组织领导体系

工作任务：成立九寨沟县全面落实河长制工作领导小组，设立第一总河长、总河长、县级河长、总河长办公室、县河长制办公室。

完成时间：3月上旬

责任单位：县委办公室、县政府办公室（列首位的为牵头单位，下同）

（二）印发《九寨沟县“河长制”工作实施方案》，全面启动河长制工作

完成时间：5月底前

责任单位：县委办公室、县政府办公室、县农业畜牧和水务局

（三）召开总河长办公室第一次主任会议

工作任务：研究县级河长制推进重点工作，细化职责任务和分工。

完成时间：4月底前

责任单位：县河长制办公室

（四）召开九寨沟县推进河长制工作电视电话会议

工作任务：对全县推进河长制有关工作进行再动员、再部署，明确相关职责分工和任务。

完成时间：4月底前

责任单位：县总河长办公室、县政府办公室、县河长制办公室

（五）制发《九寨沟县全面落实河长制工作方案》

工作任务：细化全县河长制工作目标、主要任务和职责分工。

完成时限：6月10日前；县、乡（镇）6月20日前

责任单位：县河长制办公室

（六）建立完善相关工作机制

工作任务：建立九寨沟县全面落实河长制工作领导小组运行规则、九寨沟县河长制会议制度、7条重要河流县级河长工作推进机制、县级河长联络员单位工作制度、2017年河长制工作要点和任务清单、7条重要河流管理保护投诉举报受理办法等，制定九寨沟县河长制工作相关职责及分工；指导乡（镇）建立相关制度，制定河长制工作相关职责及分工，建立上下联动、部门协调、责任落实、同步推进的工作机制。

完成时间：7月底前

责任单位：县河长制办公室

（七）召开县全面落实河长制工作领导小组第一次会议

工作任务：听取河长制工作情况汇报，审议《九寨沟县全面落实河长制工作领导小组运行规则》《九寨沟县河长制会议制度》《7条重要河流州级河长工作推进机制》《县级河长联络员单位工作制度》和《2017年河长制工作要点和任务清单》。

完成时间：7月底前

责任单位：县委办公室、县政府办公室、县总河长办公室

（八）上报河湖名录，设立各级河长，公告河长信息

工作任务：2017年6月10日前，上报全县河湖名录，设立各级河长；分级分批公告县、乡（镇）河长信息。2017年8月底前，在河湖岸边显著位置竖立河（段）长公示牌。

完成时间：8月底前

责任单位：县河长制办公室

（九）落实河长制办公室工作机构、职能职责、人员编制、工作经费

工作任务：落实县河长制办公室工作机构、职能职责、人员编制、工作经费；指导乡（镇）同步落实河长制办公室工作机构、职能职责、人员编制、工作经费。

完成时间：7月底前

责任单位：县委编办、县财政局、县农业畜牧和水务局

（十）开展一河一策管理保护方案编制工作，明确年度工作目标、问题、任务、责任四张清单

工作任务：按要求报送县级31大主要河流4张2017年度工作清单及一河一策管理保护方案相关内容；委托设计单位编制《县级一河一策管理保护方案》，县级联络员单位根据任务分工，按照一河一策管理保护方案大纲要求，提出解决河湖管理保护突出问题的方案，落实到体制、机制、政策措施、工程措施和保障措施，提出分年实施计划和任务分解方案，报县级河长批准后执行；并按照一河一策管理保护方案和河湖管理保护年度工作要求，提出4张年度工作清单，经县级河长批准后执行，并报县河长制办公室备案；形成“1＋4”河湖管理保护工作模式。

完成时间：8月30日上报省级嘉陵江一河一策管理保护方案；12月底前完成县级31条主要河流一河一策管理保护方案

责任人和责任单位：县级河长及联络员单位、县河长制办公室

（十一）开展两次全面推行河长制工作督查

工作任务：按照《四川省全面推行河长制工作督导检查制度（暂行）》要求，制定我县推行河长制工作督导检查方案，由县级河长牵头，在全县范围内开展推行河长制工作督导检查。

完成时间：8月底前制定我县推行河长制工作督导检查方案；11月底前完成全县范围内推行河长制工作督导检查。

责任人和责任单位：县级河长及联络员单位、县河长制办公室

（十二）建立县（市）、乡河长常态化工作机制

工作任务：研究制定县、乡级河段长巡河制度等，完善河湖突出问题的处置、解决机制，督促县、乡级河段长全面开展日常巡河、问题督办、情况通报、责任落实等工作，启动基层河段长清河、护岸、净水、保水四项行动。

完成时间：11月底前

责任单位：县河长制办公室

（十三）开展全面推行河长制工作学习

工作任务：组织到河长制工作先进地区学习河长制相关工作。

完成时间：12月底前

责任单位：县河长制办公室

（十四）全面推行河长制宣传工作

工作任务：拟制宣传工作方案、计划，加强宣传力度。

完成时间：12月底前

责任单位：县委宣传部、县河长制办公室

（十五）组织开展全面推行河长制工作考核验收

工作任务：县级河长组织对相应河（湖）开展督查考核；县总河长办公室自上而下逐级督查考核验收，并对县级职能部门开展督查考核。

完成时间：12月底前

责任人和责任单位：县总河长办公室、县级河长及联络员单位
