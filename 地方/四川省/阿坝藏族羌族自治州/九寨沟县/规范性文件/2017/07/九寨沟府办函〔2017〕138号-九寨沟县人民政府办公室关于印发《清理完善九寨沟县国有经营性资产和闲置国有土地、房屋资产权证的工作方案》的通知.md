# 九寨沟县人民政府办公室关于印发《清理完善九寨沟县国有经营性资产和闲置国有土地、房屋资产权证的工作方案》的通知

县级各部门：

《清理完善九寨沟县国有经营性资产和闲置国有土地、房屋资产权证的工作方案》已经县十四届人民政府第11次常务会审议通过，现印发你们，请认真贯彻执行。

九寨沟县人民政府办公室

2017年7月4日

清理完善九寨沟县国有经营性资产

和闲置国有土地 房屋资产权证的工作方案

为进一步加强对全县国有经营性和闲置国有资产的管理，提高国有资产使用效率，实现国有资产保值增值，根据《中华人民共和国企业国有资产法》（主席令第五号）《行政单位国有资产管理暂行办法》（财政部第35号令）《事业单位国有资产管理暂行办法》（财政部第36号令）等相关法律法规，结合我县实际，特制定本实施方案。

一、工作目的及原则

（一）工作目的。通过对县内各类国有经营性和闲置国有资产进行全面清查，摸清全县党政机关及各类国有企事业等单位国有经营性和闲置国有资产现状，分析解决国有资产在运行管理中的问题，进一步提升国有资产监管工作水平，切实提高国有资产使用效率，完善国有资产管理信息系统，确保国有资产保值增值。

（二）清理原则。坚持“统一领导，分级管理；产权明晰，无权属纠纷；盘活闲置，保值增值；各负其责，责任到人”。

二、工作步骤

全县国有企业、行政事业单位国有经营性资产和闲置土地房屋产权清理工作坚持统一管理、先易后难、逐步变更、科学管理的原则，统一部署，同步开展，自2017年7月开始全面实施。

（一）自清自查，权证移交。各单位对截止到2017年5月31日占有使用的闲置性国有房屋土地资产及国有经营性资产情况进行清理自查。自查重点是房屋所有权证、土地使用证是否齐全，有无房产纠纷，房屋、土地的界限是否清楚，面积是否准确，资产的实物、原值是否与账务一致，是否与土地使用证和房屋所有权证记载一致，是否有对外担保、抵押、出租出借情况，是否有外借丢失情况，是否有违规处置和违规建设的房地产等，并整理资产形成规程制度相关文档资料。对截止日至实际清查日资产变动情况予以说明。

各部门在完成自查清理工作后，要将清查结果形成自查报告，并经主要负责人签字盖章后，连同两证原件及相关资料上报县国有经营性和闲置资产清理工作领导小组办公室（县国资公司）；未办理两证在两证办理齐全后报县国有经营性和闲置资产清理工作领导小组办公室（县国资公司）。

（二）集中核查，变更登记。在各部门自查上报的基础上，由县国有经营性和闲置资产清理工作领导小组组织国土、住建等部门，分小组集中核查。采取循序渐进、由点及面、以册点物的方法，组织相关人员对照原账面记录与实务逐一进行核对。

核查工作结束后，对于有两证且无纠纷的单位，由各部门向县人民政府提交划转变更至县国资公司的请示，待县人民政府批复后，由县国资公司向县国土资源局和县规划建设局提出申请，并按城镇规划调整用地性质，将其房地产权属变更登记至县国资公司名下；未办理两证，且有纠纷的单位，待产权界定明晰后办理产权登记后划转至县国资公司名下。

县国资公司建立国有经营性资产和闲置土地、房屋产权管理档案资料库，登记统计台账，定期复核权属、资产质量状况及使用情况。

（三）总结完善，建章立制。在产权集中的基础上，根据各部门实际情况，县国资公司制定集中管理、绩效考核等相关制度，提出资产整合、运营意见，对资产调拨、使用情况进行跟踪监督，不断探索符合我县实际的资本运作体系，并根据清理情况划转部分资产至县国投公司，提高融资效率。

三、组织领导

为确保本次资产集中清理整治工作顺利进行，特成立全县国有经营性和闲置国有资产集中清理整治工作领导小组（以下简称领导小组），对资产清理过程中的重大事项和问题进行研究，作出决策。各部门要成立相应组织，安排专人负责做好本系统经营性和闲置国有资产清理工作，积极落实领导小组各项部署和决策。领导小组成员名单如下：

四、工作分工

（一）各部门要认真清理本部门资产，如实提供相关资料、证件和有关情况，切实处理好应移交资产存在的遗留问题，做到不少报、不漏报；

（二）县国资公司负责组织协调清理登记工作，收集有关资料并整理归档，进一步充实完善国有经营性资产管理信息系统；

（三）县住建、国土等部门负责提供相关建筑物、土地等资料，协助处理资产移交、产权界定、房地产权证明等工作；

（四）县监察部门负责对资产移交全程监督；

（五）县纪检监察部门负责对资产清理整治工作中发现的侵占国有资产、违规处置国有资产和其他违规违纪行为进行处理。县目标督查办负责对工作不力，致使本次清查内容不全、数据不真实或不能按时完成登记上报的部门进行通报批评。
