# 九寨沟县人民政府办公室关于成立九寨沟县2017年第九次森林资源清查工作领导小组的通知

各乡（镇）人民政府、县级各部门：

按照全州第九次森林资源清查工作会议和《四川省林业厅关于开展第九次森林资源清查工作的通知》（川林发〔2017〕12号）要求，经县人民政府研究，决定成立九寨沟县2017年第九次森林资源清查工作领导小组，组成人员如下：

组  长：龚学文   县政府副县长

副组长：黄泽明   南坪林业局副局长

刘春龙   九寨沟管理局副局长

徐荣鸿   县环境保护和林业局局长

成  员：党国庆   九寨沟国家森林公园管理局局长

格让珠   县环境保护和林业局副局长

莫劲雁   贡杠岭保护区主任

冷志成   白河保护区主任

胡学煜   勿角保护区主任

黄小兵   县环境保护和林业局资源站站长

各乡（镇）长

领导小组下设办公室在县环境保护和林业局资源站，由格让珠同志兼任办公室主任，负责处理日常事务。各成员单位要做好辖区内的组织协调和支持配合工作，重点在人力、物力、交通、生活等方面予以大力支持，在向导和安全方面予以全力保障。

九寨沟县人民政府办公室

2017年7月7日
