# 九寨沟县人民政府办公室关于成立扶持村集体经济发展试点项目工作领导小组的通知

各乡（镇）人民政府、县级各部门：

根据《四川省财政厅关于开展扶持村级集体经济发展试点有关事项的通知》（川财农〔2017〕12号）和《四川省财政厅中共四川省委农村工作委员会关于印发扶持村集体经济发展试点的指导意见的通知》（川财农〔2017〕16号）要求，为统筹推进我县扶持村集体经济发展试点项目工作，特成立九寨沟县扶持村集体经济发展试点项目工作领导小组，其成员如下：

组     长:  龚学文   县政府副县长

副组长:   李    勇   县农业畜牧和水务局局长

王玉梅   县财政局局长

成     员:  叶   林   县委办公室主任

郭友林   县政府办副主任、扶贫和移民工作局局长

白建安   永乐镇镇长

王志华   漳扎镇镇长

南    波   永丰乡乡长

黄    伟   保华乡乡长

郭    莉   大录乡乡长

切    保   玉瓦乡乡长

祁    宇   黑河乡乡长

秦远康   陵江乡乡长

张宗祥   郭元乡乡长

薛彦辉   永和乡乡长

领导小组下设办公室在县农业畜牧和水务局，由李勇同志兼任办公室主任，牵头负责扶持村集体经济发展试点项目工作。
