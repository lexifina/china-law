# 九寨沟县人民政府办公室关于印发《九寨沟县“十三五”水资源消耗总量和强度双控行动方案》的通知

各乡（镇）人民政府，县级相关部门:

《九寨沟县“十三五”水资源消耗总量和强度双控行动方案》已经县人民政府同意，现印发你们，请认真贯彻执行。

九寨沟县人民政府办公室

2017年7月26日

九寨沟县“十三五”水资源消耗总量和强度

双控行动方案

为进一步加强全县水资源消耗总量控制，提高水资源使用效率，确保水资源可持续利用，根据《水利部国家发展改革委关于印发〈“十三五”水资源消耗总量和强度双控行动方案〉的通知》（水资源〔2016〕379号）、《四川省人民政府办公厅转发 〈四川省“十三五”水资源消耗总量和强度双控行动实施方案〉 通知》（川办函〔2017〕46号)和《阿坝州人民政府办公室转发〈阿坝州“十三五”水资源消耗总量和强度双控行动方案〉的通知》要求，结合我县实际，制定本方案。

一、主要目标

到2020年，基本完善水资源总量和强度双控管理制度，双控措施有效落实，双控目标全面完成，初步实现城镇发展规模，人口规模，产业结构和布局等经济社会发展要素与水资源协调发展。全县用水量得到有效控制，地下水开发利用得到有效管控，万元地区生产用水量比2015年降低19％，万元工业增加值用水量比2015年降低18％，农田灌溉水有效利用系数提高到0.46。

二、重点任务

（一）健全指标体系

按照《阿坝州人民政府办公室关于印发〈阿坝州实行最严格水资源管理制度考核办法〉的通知》（阿府办发〔2014〕23号）精神，严格用水量指标管理。2018年底前完成县水资源综合规划编制工作，有序推进主要江河流域水量分配工作，逐步将用水总量控制指标落实到流域和水源。（牵头单位：县农水局；责任单位：县发改局、县经信局、县住建局）

全县按照州分解下达的用水强度控制目标和年度水资源管理控制指标，落实年度用水计划和审批取水许可，严格用水定额管理，超计划和超定额取水的，对超计划或超定额部分累进收取水资源费。参照《四川省用水定额》，适时建立地方用水定额体系和节水标准体系。（牵头单位：县农水局；责任单位：县机关事务管理局、县发改局、县经信局、县教育局、县国土局、县住建局、县环林局、县文体广新局、县卫计局、县统计局、县工商食药监局）

( 二）强化目标考核和责任追究

建立用水总量和强度控制目标责任制。按照《阿坝州人民政府关于实行最严格水资源管理制度的实施意见》（阿府发〔2014〕11号）和阿府办发〔2014〕23号文件要求，对县政府实施年度考核，将用水总量和强度纳入最严格水资源管理制度考核和生态文明建设目标评价考核内容，完善考核评价体系，突出用水量和强度双控要求。（牵头单位：县农水局；责任单位：县发改局、县经信局、县住建局、县统计局）

建立用水总量和强度双控责任追究制。严格责任追究，对落实不力的采取约谈，通报等措施施予以督促并要求限期整改;对因盲目决策和渎职，失职造成水资源浪费，水环境破坏等不良后果的相关责任人，依法依纪追究责任。严格落实国家水资源督察制度，加强对区域用水总量和强度控制目标完成情况的督察，确保相关政策措施落实到位。进一步强化考核结果运用，将考核结果作为对全县政府领导班子和相关领导干部年度绩效目标和综合评价的重要依据（牵头单位：县委组织部；责任单位：县检察院、县发改局、县经信局、县住建局、县农水局、县统计局）

（三）强化水资源承载能力刚性约束

建立水资源承载能力监测预警机制。根据全县水资源承载能力评价成果，2018年12月底以全县为单位建立预警体系，发布预警信息，强化水资源承载能力对经济社会发展的刚性约束。（责任单位：县农水局）

建立健全规划水资源论证制度。进一步强化规划水资源论证管理，重点推进城市总体规划，重大产业布局，各类开发区、工业园区、工业集中发展区规划的水资源论证，加快出台我县实施规划水资源论证评价的重要依据，保障规划发展与区域、流域水资源承载能力相适应。（牵头单位：县农水局；责任单位：县发改局、县国土局，县住建局）

建立健全建设项目水资源论证制度，严格建设项目水资源论证和取水许可管理，合理配置项目水源，从严核定许可水量，对取水总量达到或超过控制指标的地区暂停审批新增取水。（责任单位：县农水局）

（四）全面推进各行业节水

全面推进节水型社会建设。推进县编制完成节水型社会建设“十三五”规划，贯彻节水优先方针，强化节水宣传，营造全社会节水氛围，确保各行业，各领域节水目标的如期实现。加强节水型社会县，节水型城市建设，促进节水型社会建设的整体推进。（牵头单位：县农水局；责任单位：县发改局、县经信局、县财政局、县住建局）

强化农业节水。加快重大农业节水工程建设，力争到2020年完成1至2个中型灌区续建配套和节水改造任务。依托中央.省级及州级水利发展项目资金，加大农业综合开发、国土整治、现代农业示范等各类涉水涉农项目整合力度，统筹支持高效节水灌溉发展。（责任单位：县农水局）

加快实施高标准农田建设和农村水利节水灌溉设施工程建设。结合我县特色农业、畜牧业发展、大力推广喷灌和水肥一体化等高效节水灌溉技术，推广节水技术设备应用，充分利用粮油绿色高产创建和园艺作物标准园创建平台，建设一批高效节水示范区工程。（牵头单位：县农水局；责任单位：县发改局、县财政局、县国土局）

强化工业节水。严格落实主体功能区规划，优化高耗水行业布局，并向工业园区集中。按照《国家鼓励和淘汰的用水技术、工艺、产品和设备目录》，重点指导冶金、化工、印染、造纸、食品等高耗水工业行业进行节水技术改造，支持一批重大节水改造项目。开展“十三五”重点企业节水行动，大力推广工业水循环利用，提高工业用水效率，将年取水量10万立方米以上的企业纳入节水管理制度完善、用水效率达到行业先进水平的节水型示范企业，开展节水型工业园区建设工作。到2020年，高耗水行业力争达到定额标准。（牵头单位：县经信局；责任单位：县发改局、县农水局）

强化城镇节水大力发展城镇集中供水，加快推进城镇供水管网漏损控制工作，鼓励开展供水管网独立分区计量管理，加快进行城镇公共供水管网改造，加强节水器具和节水产品推广及普及工作，积极开展节水型居民小区和公共建筑节水达标创建活动。到2020年全县按照《节水型社区评价导则》，加快节水型居民小区建设，确保建成率不低于10％。（牵头单位：县住建局；责任单位：县发改局、县农水局）

按照《四川省公共机构节约能源资源“十三五”规划》要求，做好公共机构节水工作，到2020年，人均水耗比2015年下降15％,50％以上的县直机关达到四川省公共机构节水型单位建设标准，建成节水型单位，重点推进学校、医院、体育馆、等单位创建节水载体。县直有关部门负责对其下属单位节水型创建，并按行业节水规程和规范要求积极组织申报、考核工作，每年底前将行业内创建成功的节水型单位命名文件报送州水务局州机关事务管理。（牵头单位：县农水局；责任单位：县机关事务管理局、县教育局、县住建局、县卫计局等）

强化对节水产品实施质量监督抽查，严厉打击生产不合格用水产品的违法行为。（责任单位：县工商食药监局）

贯彻落实国家发展改革委等单位《关于印发〈全民节水行动计划〉的通知》（发改环资）〔2016〕2259号），到2020年，在农业、工业、服务业、公共机构等领域，城镇、乡村、社区、家庭等各层面，生产、生活、消费等各环节，全面推进节水型社会建设。县每年至少减少建成三个不同种类的节水载体。(牵头单位：县发改局；责任单位：县农水局、县机关事务管理局、县经信局、县教育局、县科技局、县住建局、县工商食药监局）

大力推行合同节水管理。落实国家发展改革委等单位《关于推行合同节水管理促进节水服务产业发展的意见》（川发改环资〔2016〕455号），到2020年，大力培育节水型服务企业，在全县范围内实施两个以上合同节水管理项目。（牵头单位：县发改局；责任单位：县农水局、县机关事务管理局、县经信局、县国税局、县地税局）

开展水效领跑引领行动。落实国家发展改革委等单位《关于印发〈水效领跑者引领行动实施方案〉的通知》（发改环资〔2016〕876号）和省发展改革委等单位《关于转发〈水效领跑者引领行动实施方案〉的通知》（川发改环资〔2016〕485号）文件，各有关部门（单位），各有关部门要加强统筹协调。

（五）加强地下水管理

实施地下水取用水总量和水位控制，根据全省2017年底前完成地下水禁采区、限采区范围划定情况，适时推动开展全县相关工作。依法规范机井建设管理，限期关闭未经批准的公共供水管网覆盖范围内的自备水井。加快地下水监测工程，完善地下水监测网络，实现对地下水动态有效监测。（牵头单位：县农水局；责任单位：县国土局、县住建局）

（六）统筹配置和有序利用水资源

合理有序使用地下水、控制使用地下水、积极利用非常规水。做好流域和区域水资源统筹调配，减少水资源消耗，逐步降低过度开发流域和重点区域水资源配置，强化水资源统一调度，统筹协调生活、生产、生态用水。积极推进中水、雨水等非常规水源利用，将非常规水源纳入水资源统一配置。（牵头单位：县农水局；责任单位：县发改局、县住建局）

（七）稳步推进水权制度建设

加快明晰区域和取用水户初始水权，稳步推进确权登记，逐步建立水权初始分配制度。（责任单位：县农水局）

（八）加快理顺价格税费

贯彻落实《国务院办公厅关于推进农业水价综合改革的意见》（国办发〔2016〕2号）和《四川省推进农业水价综合改革实施方案》，推进建立农业水价形成机制，建立进准补贴和节水奖励机制，大力提升农业用水效率。农田水利设施相对完善的中型灌区要率先实现改革目标。合理制定、调整城镇供水结构，全面推行居民阶梯水价和非居民用水超定额超计划累进加价制度。加强水资源费征收管理，确保应收尽收。积极推进水资源税费改革。（牵头单位：县发改局；责任单位：县经信局、县财政局、县住建局、县农水局、县地税局）

（九）提升水资源计量监控能力

加快推进全县水资源监控能力建设，实现信息共享、互联互通和业务协同。全面做好国家水资源监控能力建设（2016-2018年）项目，不断提升县水资源监控能力。结合中型灌区建设与节水配套改造、小型农田水利设施建设，完善灌溉用水计量设施，提高农业灌溉用水定额管理和科学计量水平。（牵头单位：县农水局；责任单位：县财政局）

（十）加强重点用水单位监督管理

建立健全县两级重点监控用水单位名录，强化取水计量监控，完善取用水统计和核查体系。对重点用水单位的主要用水设备、工艺和水消耗情况及用水效率等进行监控管理。严格按照水利部《用水总量统计方案》开展取水量统计工作，建立健全用水统计台账。引导重点用水单位建立健全节水管理制度，实施节水技术改造，提高其内部节水管理水平。(牵头单位：县农水局；责任单位：县经信局、县住建局)

（十一）加快推进技术与机制创新成果的应用

积极推广综合节水、非常规水源开发利用、水资源信息监测、水资源计量器具在线校准等先进技术，加快推进水资源高效利用创新成果的应用。(责任单位：县科技局、县农水局、县工商食药监局)

三、保障措施

（十二）加强组织领导。各级政府对水资源消耗总量和强度双控工作负总责，将“双控”工作纳入经济社会发展重要议事日程，制定落实方案，明确具体措施和任务分工，确保“双控行动”目标完成。现有关部门要按照职责分工，加强指导，抓好落实，将水资源消耗总量和强度双控工作纳入最严格水资源管理制度考核内容。

（十三）加大财税金融支持。各级政府要加大财政资金投入，落实相关税收优惠政策，支持重大节水工程建设、节水型社会建设、水资源监控能力建设，等“双控”任务的落实。积极探索合同节水管理等新模式，利用政府和社会资本合作（PPP）模式等，鼓励社会资本进入节水等领域。

（十四）夯实管理基础。健全完善水资源管理制度，加强水资源管理能力建设，大力推进水资源管理法制化进程，切实提高水资源管理与社会服务能力。

（十五）强化公众参与。广泛深入开展基本水情和节约用水宣传教育，强化社会舆论监督，增强全社会的水忧患意识、水资源节约保护意识，大力推进水资源管理科学决策和民主决策，完善公众参与机制。各级政府应依法公开水资源信息，及时发布水资源管理决策，提高决策透明度，健全听证等公众参与制度，对涉及群众用水利益的发展规划和建设项目，采取多种方式充分听取公众意见。
