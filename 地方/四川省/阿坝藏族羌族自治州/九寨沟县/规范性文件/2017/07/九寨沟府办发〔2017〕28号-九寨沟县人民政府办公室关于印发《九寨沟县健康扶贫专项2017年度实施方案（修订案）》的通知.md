# 九寨沟县人民政府办公室关于印发《九寨沟县健康扶贫专项2017年度实施方案（修订案）》的通知

各乡（镇）人民政府，县级各部门:

《九寨沟县健康扶贫专项2017年度实施方案（修订案）》已经县人民政府研究同意，现印发你们，同时终止执行九寨沟县22个扶贫专项实施方案中《九寨沟县健康扶贫专项2017年度实施方案》，请认真贯彻执行。

九寨沟县人民政府办公室

2017年7月7日

九寨沟县健康扶贫专项2017年度实施方案

（修订案）

一、年度目标

确保2017年县级综合医院达到二级甲等，其他县级医疗卫生机构达到二级水平，每个建制乡镇均有达标卫生院，36个计划退出村均有达标村卫生室和合格村医。2017年12月底前，县摘帽、村退出和脱贫人口健康扶贫考核指标达到目标要求。确保贫困患者县域内住院和慢性病门诊维持治疗医疗费用个人支付占比控制在10%以内。确保贫困人口100%参加城乡居民基本医疗保险。

二、重点工作

（一）大力实施贫困人群医疗救助扶持行动

牵头单位：县卫生和计划生育计局；

责任单位：县人力资源和社会保障局、县财政局、县民政局、县扶贫和移民工作局、县红十字会、县残联。

1.完善贫困患者精准识别和“十免四补助”政策医疗扶持。加强医疗机构信息化建设，依托四川省贫困人口就医信息管理系统，对贫困患者逐户分类建档，实现贫困人口就医信息精准管理。进一步落实“先诊疗后结算”和“一站式”报销服务制度，优先落实贫困人口“十免四补助”政策，即贫困人口就诊免收一般诊疗费、免收院内会诊费、免费开展白内障复明手术项目、免费艾滋病抗病毒药物治疗和抗结核一线药物治疗、免费提供基本公共卫生服务、免费提供妇幼健康服务、免费开展义诊巡诊服务、免费药物治疗包虫病患者、免费提供基本医保个人缴费、免费实施贫困孕产妇住院分娩，对手术治疗包虫病患者按2.5万元/人给予补助，对0-6岁贫困残疾儿童进行手术、康复训练和辅具适配按3万元/人给予补助，对符合治疗救助条件的晚期血吸虫病人按5000元/人给予补助，对重症大骨节病贫困患者按700元/人给予对症治疗补助。

贫困人口参加城乡居民基本医保的个人缴费部分，由财政部门按最低档次缴费标准给予全额代缴，确保贫困人口参加城乡居民基本医保参保率达100%。贫困孕产妇县域内住院分娩，危急重症孕产妇确需转诊救治的除外，统筹使用城乡居民基本医保、农村孕产妇住院分娩补助、大病保险、民政医疗救助、医药爱心扶贫基金等专项经费，实现贫困孕产妇住院分娩全免，超出限价控费标准的部分，由县级卫生扶贫救助基金统筹兜底解决。

组建家庭医生服务团队，开展家庭医生签约服务，6537名贫困人口家庭医生服务签约率达到100%。通过“1+1+1”（1个卫生院团队+1名村医+1户贫困家庭）家庭医生签约服务，与居民建立稳定的契约服务关系，按照“无病防病、有病管理”的原则，为居民提供综合、便捷的健康管理服务，增强居民的信任感、获得感，引导形成以家庭医生首诊为基础的分级诊疗就医格局。

2.巩固“两保、三救助、三基金”医保持续成效。对6537名建档立卡贫困人口全面落实医保扶持政策，贫困人口医疗费用按照基本医疗保险、大病保险、大病补充商业保险、县域内政策范围内住院费用全报销、民政医疗救助、城乡居民医保重大疾病专项补助基金、城乡居民医保重特大疾病特殊补偿政策的顺序予以保障，统筹使用医药爱心基金、卫生扶贫救助基金和重大疾病慈善救助基金，确保贫困患者县域内住院和慢性病门诊维持治疗医疗费用个人支付占比控制在10%以内。按照州级大病保险贫困人口差别化支付政策，大病保险支付比例应达到50%以上。将贫困人口重特大疾病需要长期门诊治疗，导致自付费用较高的，给予门诊救助。继续落实大病补充商业保险财政补助，专项用于建卡贫困人口购买大病补充商业保险。不断强化“医药爱心基金、卫生扶贫救助基金和重大疾病慈善救助基金”县域外治疗重大疾病的减负作用。

3.完善分级诊疗制度和医疗费用控制政策。进一步完善分级诊疗制度，落实首诊责任，规范双向转诊，贫困患者县域内就诊率达到95%以上。县级以下医疗机构要严格执行医疗控费政策，严格掌握出入院指征，坚决防止住院标准过宽，门诊患者串换升格住院治疗、压床治疗、挂床住院等不合理医疗和违规行为，产生的所有不合规医疗费用全部由医疗机构自行承担。严格执行执行贫困人口医疗费用公示制度，广泛接受患者和社会各界监督，公示覆盖率达到100%。

（二）大力实施贫困人群公共卫生保障行动

牵头单位：县卫生和计划生育计局；

责任单位：县财政局、县发展和改革局、县扶贫和移民工作局。

1.精准实施贫困人口免费健康体检及基本公共卫生服务。按照6537名建档立卡贫困人口脱贫攻坚期内每人免费体检1次的目标，2017年为全县建档立卡贫困人口开展免费体检，力争建卡贫困人口健康体检覆盖率达100%。对重点人群实施精准健康教育、健康管理，对0至6岁儿童、65岁以上老年人、35岁以上原发性高血压患者、2型糖尿病患者、孕产妇、结核病患者、严重精神障碍患者7类重点人群的健康管理水平力争达到全省平均水平，深入推进类风湿关节炎、慢性阻塞性肺疾病、高原心脏病患者健康管理工作。全面推广基层医疗卫生机构管理信息系统，提升居民健康档案规范建档率和动态更新率。

2.降低贫困地区传染病发病率。强化全县预防接种工作，认真落实儿童入托、入学时检查接种证制度，适龄儿童免疫规划疫苗报告接种率达到95%以上。加强全县传染病的检测，做到年部署、季评估、月分析、日监测。加强对艾滋病、结核病、包虫病等重大疾病防治，缩小与全省差距。加强卫生监测工作，饮用水卫生监测乡镇全覆盖。

3.加强慢性病综合防控。2017年培训20名健康管理员。开展针对性防治知识宣传，指导基层医疗卫生机构做好重点慢性病患者健康管理工作。对上消化道癌开展早诊早治工作，早诊率达60%。加强儿童口腔卫生工作，提高小学生口腔卫生知识的知晓率达到70%。职业病报告率达60%。

4.强化贫困地区健康生活方式养成。对标“四好村”创建。以“健康九寨•幸福家园”为主题，广泛开展健康教育“五进五讲”活动（即进村庄、进学校、进家庭、进夜校、进电视广播；讲卫生习惯、讲疾病预防、讲看病就医、讲减免政策、讲自我保健）和“三减三健”行动（即减盐、减油、减糖、健康口腔、健康体重、健康骨骼），普及卫生科学知识，倡导文明、健康、科学的生活方式，健康教育宣传品进村入户率达100%，健康教育活动开展率达100%，力争实现户户有一个健康明白人，村村有健康教育阵地和健康管理员。引导贫困人群养成好习惯、形成好风气。

（三）大力实施贫困地区医疗能力提升行动

牵头单位：县卫生和计划生育计局；

责任单位：县发展和改革局、县财政局、县人力资源和社会保障局。

1.强化17个乡镇卫生院和36个脱贫村村卫生室建设。通过基础设施建设（新建村卫生室4个，维修改造9个）、设备购置和人员配备，确保17个乡镇卫生院和36个脱贫村村卫生室全部达标，所有村卫生室有合格村医。

2.强化县级医院能力提升。继续加强以人才、技术、重点专科为核心的能力建设，重点加强县域内发病率排名前十位、近3年县外转诊率排名前五位疾病病种对应科室的临床专科建设，确保县级医院对200种常见病、多发病的诊断治疗率达95%。

3.强化精准卫生对口支援。一是成都大学附属医院安排精通管理、乐于奉献的管理团队到九寨沟县人民医院挂职院长，主持医院全面工作，提升县人民医院管理水平、服务质量。二是成都大学附属医院和邛崃市选派医疗专家人员19名驻点帮扶我县县级和基层医疗卫生机构，践行一线工作法，适时开展新适宜技术，拓展医院服务多样性。认真开展三级医师查房、巡诊义诊、专题知识培训讲座等活动，提高我县医疗卫生机构诊疗技术和服务水平。

4.强化对乡镇、贫困村的巡回医疗和义诊。县、乡两级医疗机构定期组织巡回医疗队，到乡镇、贫困村开展巡诊、义诊，慢病随访，政策宣传等活动。县级医疗机构到乡镇开展巡诊、义诊全覆盖，乡镇卫生院到村巡回医疗活动全覆盖。

5.强化基层卫生医疗机构“三大行动”。开展全县基层医疗机构技术大练兵行动、设备使用率提升行动和健康管理全覆盖行动。

（四）大力实施贫困地区卫生人才培植行动

牵头单位：县卫生和计划生育计局；

责任单位：县人力资源和社会保障局、县编办、县财政局。

1.推进人才增量提质。组织开展“3+3”定向学生培养、乡村医生中专学历教育、农村订单定向医学本科生免费培养、定向医学专科生引进、“三支一扶”等项目，促进卫生人才增量提质。

2.加大基层医疗单位空岗补员力度。根据基层卫生事业单位核准岗位总量和相应专业技术岗位空缺情况，制定招聘计划和实施方案，着力引进实用人才。

3.开展大培训带动大提高。按照分级分类、各级负责的原则，开展医务人员大轮训，通过5年时间，实现县、乡、村全覆盖，完成率分别达95%、90%、85%。开展2017年规范化业务培训，以临床医学为主，选派县级医疗机构业务骨干到省、州及以上医疗机构进修学习6个月，不少于10人次；选派乡镇卫生院临床医生到邛崃市中心医院进修学习6个月，不少于5人次；乡镇卫生院选派临床医生到县级医疗机构跟岗轮训3个月，三期25人次；组织乡村医生集中培训3次，乡村医生到辖区卫生院跟岗进修学习不少于20天。

4.推进乡村一体化管理。以家庭医生签约服务为基础，积极推进乡镇卫生院和村卫生室的人员队伍一体化管理，着力解决村医人数不足，能力不高问题。鼓励乡镇卫生院核编内岗位空缺公开招聘符合条件的乡村医生，鼓励乡镇卫生院具备资格在编岗位卫计人员选派到村卫生室开展医疗服务。

5.健全卫生人才激励机制。持续落实基层医疗卫生机构四项基金提取办法，健全名医、学科带头人、终身从医、一次性考取执业（执业助理）医师、边远乡镇工作5年、10年一次性补助等人才奖励机制。

（五）大力实施贫困地区生育秩序整治行动

牵头单位：县卫生和计划生育计局；

责任单位：县财政局。

1.强化计划生育目标管理。进一步加强生育程序整治重点计划生育目标管理责任制，与各乡镇及企事业单位签订计划生育目标管理责任书，加强督查考核，严格落实“一票否决”制度。 2017年生育秩序整治重点政策外多孩率降低至10%以内。

2.落实包村包户责任制和“一对一”联系制度。实行乡村干部计划生育包村包户责任制，组织发放计划生育入户宣传品和免费发放避孕药具，每月到所包村了解群众婚、孕、育信息和计划生育工作情况，，每季度组织所包村已婚育龄妇女参加计划生育“三查”服务，及时动员已达到政策规定生育数量上限的群众落实长效节育措施、不符合政策怀孕对象落实补救措施。包村包户责任制落实率达100%。对已达到政策生育数量上限、未落实长效节育措施的已婚育龄妇女提供一对一指导服务。指导育龄妇女落实安全、有效、适宜的避孕节育措施。包村包户干部和一对一联系专业技术人员要记录工作日志，上级主管部门定期检查。

3.加强计划生育基层基础。注重进村入户、面对面宣传，加大计划生育执法力度。加强计划生育队伍建设，加强妇幼保健计划生育机构建设，配齐配强工作人员。全面落实村级计划生育干部报酬待遇，确保不低于村主要负责人的80%。

三、资金筹措

2017年计划筹措资金362.8万元，其中中央省级资金199.8万元，州级资金31万元，县级资金76万元，邛崃市对口支援56万元。

（一）疾病防控省级资金13万元。

（二）重大传染病和地方病防治省级资金39.8万元。

（三）县级医院临床重点专科建设省级资金10万元。

（四）全科医生特岗省级安排5万元。

（五）贫困人口免费健康体检40万元，其中：省级资金20万元，县级资金20万元。

（六）贫困人口参加城乡居民基本医保补助60万元，其中：省级资金42万元，州级资金9万元，县级资金9万元。

（七）贫困人口城乡居民医保倾斜性支付补助中央、省补助70万元。

（八）贫困人口商业附加保险补助49万元。其中：州级补助22万元，县级补助47万元。

（九）邛崃市对口支援56万元。其中：卫生扶贫救助资金50万元，人员培训资金6万元。

四、保障措施

（一）明确工作职责。坚持中央统筹、省负总责、县抓落实的工作机制。县卫计局负责牵头方案实施，其他各相关部门在各自职责范围内负责相应工作。结合实际制定切实可行的措施，明确目标、责任、任务和进度，统筹实施健康扶贫。各医疗卫生机构具体承担健康扶贫各项任务，明确牵头人和责任人，逐项抓好工作落实。扎实推进健康扶贫工作。

（二）强化政策落实。各乡镇、各部门要严格贯彻落实省、州健康扶贫相关政策，继续深化落实“五大行动”。结合县摘帽、村退出和脱贫人口健康扶贫考核验收指标，因地制宜、补齐短板，确保县、乡、村三级医疗卫生机构建设达标，贫困人口顺利脱贫。

（三）严格考核奖惩。加强健康扶贫工作督查，对督查中发现的问题要及时整改，对重视不够、工作不实、推进不力造成严重后果或不良影响的，要严格问责。严格落实考评措施，采取定期和不定期督导及明察暗访等方式，督促各医疗卫生机构主动作为，全力做好2017年健康扶贫工作。
