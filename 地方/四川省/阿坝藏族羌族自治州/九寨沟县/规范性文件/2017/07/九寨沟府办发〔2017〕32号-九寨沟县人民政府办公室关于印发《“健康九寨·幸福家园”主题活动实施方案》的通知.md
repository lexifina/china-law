# 九寨沟县人民政府办公室关于印发《“健康九寨·幸福家园”主题活动实施方案》的通知

各乡（镇）人民政府，县级各部门：

《“健康九寨·幸福家园”主题活动实施方案》已经县人民政府研究同意，现印发你们，请认真贯彻执行。

九寨沟县人民政府办公室

2017年7月20日

“健康九寨·幸福家园”主题活动实施方案

为深入贯彻落实“健康中国2030”规划纲要精神，按照四川省脱贫攻坚领导小组办公室关于印发《四川省脱贫攻坚医疗卫生保障实施方案的通知》（川脱贫办发〔2016〕61号）和《阿坝州人民政府办公室关于开展全民健康生活方式行动的通知》（阿府办函〔2015〕124号）要求，为倡导文明、健康、科学的生活方式，不断提高人民群众的卫生知识水平和自我保健能力，如期实现“全域奔康·幸福九寨”目标，结合“四好”工作和我县实际，决定在全县范围内开展“健康九寨·幸福家园”主题活动，为确保此次活动取得实效，特制定本实施方案。

一、指导思想

以普及健康生活、优化健康服务、完善健康保障、建设健康环境、发展健康产业为重点，紧紧围绕“全域发展、绿色崛起”总体战略和“在全州率先全面建成小康社会”目标，把健康融入所有政策，全方位、全周期保障人民健康。深入贯彻“预防为主”的卫生计生工作方针，坚持政治思想性、科学性、群众性、艺术性的健康教育基本原则，协调和联合社会各部门，以“健康九寨·幸福家园”为主题，通过“五进五讲”等多种宣传方式，开展“三减三健”、“养成好习惯，形成好风气”等教育活动，普及卫生科学知识，不断提高人民群众的卫生知识水平和自我保健能力，为建设世界休闲度假旅游目的地提供坚实的医疗卫生保障。

二、活动目标

创建一镇一村，以点带面，全面推进“健康九寨·幸福家园”主题活动在全县范围的开展；利用现有资源，积极开展全民健康生活方式支持性环境建设工作；以村为单位，至少培养3-5名健康生活方式指导员，在周围人群中开展健康生活方式宣传教育，指导开展健康生活方式活动，提高居民健康行为能力。

三、活动安排

为确保“健康九寨·幸福家园”主题活动的顺利实施，健康主题活动将集中在三个月时间分段重点开展，并形成长效机制。

（一）组织成立阶段（2017年5月20日—5月31日）成立领导小组，落实部门职责，形成长效工作机制：

1.切实加强对“健康九寨·幸福家园”健康主题活动（以下简称：健康主题活动）的领导，成立九寨沟县“健康九寨·幸福家园”主题活动领导小组，负责本次健康主题活动的组织、领导和协调。领导小组办公室设于县卫生和计划生育局，负责开展日常工作。

2.各相关单位也要分别完善“健康九寨·幸福家园”主题活动领导小组，积极组织落实本单位健康主题活动的开展，并确定1名专（兼）职人员负责日常工作。

（二）动员启动阶段（2017年6月1日—6月20日）通过全面动员、深入贯彻，把思想和行动统一到“健康九寨·幸福家园”主题活动要求上来。各相关部门、各乡（镇）要开展以“健康九寨·幸福家园”为主题的健康宣传教育和健康行为养成活动。

组织相关单位和乡（镇）召开启动会和工作联络会，广泛宣传开展“健康九寨·幸福家园”主题活动的初衷背景、目的意义、方法步骤和基本要求，组织广大干部群众积极参与到活动中来。

（三）组织实施阶段（2017年6月21日—10月31日）各牵头单位和责任单位要按照普及健康生活、优化健康服务、完善健康保障、建设健康环境、发展健康产业来推进方案的进行，建立活动长期协调机制和工作机制，为创建“健康九寨·幸福家园”这一目标提供保障。

1.建立固定的健康教育阵地。各相关单位要结合实际，利用本单位有利的特性和在单位醒目位置建立健康教育专栏。利用固定的全民健康阵地，面向广大人民群众，定期开展健康教育活动。医疗单位利用自身资源，面向广大群众开设健康咨询窗口或建设健康小屋，积极向广大群众提供免费健康咨询和体重测量、血压测量等工作。

责任单位：各成员单位

2.加强健康支持性环境建设。按照《全民健康生活方式行动健康支持性环境建设指导方案》要求，积极开展健康学校、健康步道等健康支持性环境建设工作，并加强对已建设的健康支持环境的维护和动态管理；卫计系统负责开发制作健康生活方式宣传资料，并对全县健康支持环境的营造提供技术指导。

责任单位：县卫计局、县教育局、县城市管理局、县文体广新局

3.创建健康村镇示范点。以行政镇村为单位，选择一镇一村作为建设健康村镇示范点，示范村镇公开承诺并倡导全体居民参与健康村镇建设，将健康村镇建设纳入本辖区发展规划，形成制度，写入村规民约中。通过健康村镇的建设，居民健康素养大大提高，参与体育锻炼的主动性比以往有所提高。

责任单位：漳扎镇、郭元乡沟里村

4.深入开展全民健康卫生知识教育。积极组织“健康卫生知识进万家”活动，在全县掀起健康卫生知识学习的高潮。重点针对机关企事业单位工作人员和中小学、托幼机构青少年儿童，采取黑板报、宣传栏、电视台专栏节目、印发健康卫生知识宣传单或小册子等多种形式，集中开展全民健康卫生科学知识和自我保健知识宣传教育，不断提高全县人民群众的卫生知识知晓率和健康行为形成率。

责任单位：县委宣传部、县卫计局、县文广新局、县广播电视台

5.举办形式多样的健康教育讲座。根据不同人群需求，选择临床经验相对丰富、表达能力较强的医生或外邀健康专家作为主讲人，针对老年人、女性朋友、机关企事业单位人员等开展有针对性的健康讲座。精心筹备、合理规划、认真组织、分步实施，在讲座后接受咨询、发放相关健康教育材料，尽可能扩大健康知识教育普及面，惠及更多人群。

责任单位：县卫计局、县总工会、县妇联、县团委、县老龄办

6.因材施教开展学校健康主题活动。充分利用学校优势，针对不同学龄学生，在全县各中、小学校、托幼机构开展多种形式的健康主题活动，培养儿童、青少年的健康意识和良好的生活行为习惯，同时通过“小手牵大手”活动，让儿童青少年用所学健康知识和行为去影响和引导家长。学校要将健康教育列入学期年度教学工作计划，各学校健康教育开课率达到100%。

责任单位：县教育局

7.积极开展控烟健康教育活动。广泛开展创建“无烟单位”活动，在公共场所、工作场所及各单位禁烟区内要设置醒目的禁止吸烟标志，提倡单位工作人员带头禁烟，以开展“送烟=送危害”宣传活动为载体，积极组织开展大规模的禁烟宣传活动，从组织领导、制度制定落实、禁烟标识设置、控烟宣传和戒烟咨询等方面在全县各机关事业单位形成浓厚的禁烟氛围。

责任单位：县直机关工委、县卫计局、县总工会

8.积极推广工作场所工间操健身活动。全县机关企事业单位开展“天天工间操、远离慢性病”活动，大力推广工作场所工间操制度，每人每天不少于10分钟。

责任单位：县总工会、县直机关工委

9.推广专项技术指导方案、技术指南和技术支持工具。各单位依托工作平台，通过设立咨询台、摆放展板、发放宣传资料、在微信或微博上发送信息等多种形式，在管辖范围和职工中积极推广《中国居民膳食指南（2016）》和《中国公民健康素养：基本知识与技能及释义（2015年版）》等健康生活方式知识与技能，适时推广至少1种技术支持工具，如：限酒杯、控油壶、限盐勺、BMI盘、计步器、腰围尺等。

责任单位：各成员单位

（四）总结表扬阶段（2017年11月1日—11月20日）通过督查考核、总结表彰，建立健全促进工作创新的长效机制，确保“健康九寨·幸福家园”活动取得实效。

1.考核验收。结合活动实施方案进行考核，对活动开展情况进行检查验收，结果作为评比考核的重要依据。

责任单位：目标督查办、县卫计局

2.总结提炼。对活动开展情况进行总结，提炼活动中的经验和办法，促进活动成果制度化、长效化，使这次活动真正成为全县健康社会发展的重要推动力，同时将整个活动过程和总结的经验、亮点进行规范整理并形成专卷。

责任单位：各相关单位、史志办、档案局

3.评先选优。围绕开展本次健康主题活动，开展评先选优活动，评选和推介各级各部门工作中的创新做法，奖励在健康主题活动中表现突出的先进单位和个人。

责任单位：目标督查办、各成员单位

四、工作要求

（一）强化组织、务求实效

各相关单位及各乡（镇）党委政府结合本部门、本单位性质和特点，认真履行部门职责，同时制定适合本部门单位实际的活动方案，采取切实可行措施，建立有效的沟通联系机制，加强单位间的协调，形成上下联动，良性互动的推进机制。

（二）广泛宣传、全民参与

各部门、各单位要把本次健康主题活动作为建设文明、和谐、全面小康社会进程中的一项重要民生工程，切实抓紧抓好。通过举办各种健康教育活动，充分利用广播电视、手机短信平台、宣传栏、电子显示屏以及开设健康讲座等多种形式，共同推进活动深入开展，广泛发动群众积极参与各项宣传教育活动。

（三）加强督导、确保落实

各相关单位及乡（镇）党委政府务必高度重视此项活动，将本次健康主题活动列入重要议事日程，根据目标任务，充分结合本单位的实际，制定切实可行的实施计划和具体措施，狠抓落实。活动期间，县目标督查办将对各相关单位及乡（镇）党委政府进行督促检查。
