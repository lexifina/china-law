# 九寨沟县人民政府办公室关于印发《九寨沟县安全隐患排查和整改清单建设实施方案》的通知

各乡（镇）人民政府，县级各部门：

经县委、县政府同意，现将《九寨沟县安全隐患排查和整改清单建设实施方案》印发给你们，结合工作实际，认真抓好落实。

九寨沟县人民政府办公室

2017年7月11日

九寨沟县安全隐患排查和整改清单

建设实施方案

为深入贯彻落实国家、省、州关于安全生产工作的决策部署、进一步强化安全生产红线意识，创新推进我县安全生产管理体制改革工作，按照中共阿坝州委办公室、阿坝州人民政府办公室关于印发《阿坝州建立安全隐患排查和整改清单的实施方案》的通知（阿委办〔2017〕83号）文件精神，结合我县实际，特制定本方案。

一、指导思想

以邓小平理论、“三个代表”重要思想、科学发展观为指导，全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，深入贯彻习近平总书记、李克强总理关于安全生产重要系列讲话、指示批示精神，认真落实《中共中央国务院关于推进安全生产领域改革发展的意见》，坚持改革创新、依法监管、源头防范、系统治理，着力完善体制机制，着力健全责任体系，确保安全隐患排查、整改落实到实处，有效防范遏制重特大事故发生，切实提升全县安全生产监管效率。

二、工作目标

坚持“安全第一、预防为主、综合治理”的方针，坚持“党政领导、安办协调、行业监管、企业主责”的原则，以遏制安全事故发生为目标，以实施生产经营单位分级分类管理为基础，以安全隐患排查标准为依据，以开展生产经营单位自查自改自报、政府部门监督为核心，突出“两个清单”管理，构建安全隐患排查、治理、防控常态化机制，推动安全隐患排查治理全过程闭环管理和差异化管理，促进全县安全生产形势持续稳定向好。

三、工作任务

（一）生产经营单位

生产经营单位是安全隐患排查和整改的责任主体，生产经营单位按照安全生产责任体系“五落实五到位”规定，制定完善安全隐患排查治理制度，明确隐患排查治理责任、排查内容、排查时间和频次，以及隐患整改责任、措施、资金、时限、应急预案等要求。

1.开展隐患排查。开展经常性的安全生产检查，及时发现工艺系统、基础设施、技术装备、防（监）控设施等方面存在的危险状态以及落实安全生产责任、执行劳动纪律、实施现场管理等方面存在的缺陷。

主要负责人和分管负责人定期组织安全生产管理人员、专业技术人员和其他相关人员进行全面的安全隐患排查。

2.对排查出的安全隐患，按照隐患的等级进行登记管理，并建立安全隐患信息档案。隐患排查登记内容包括：隐患排查参加人员、时间、排查发现的安全隐患的部位、发现安全隐患的内容、交办确认等。

3.组织实施安全隐患自查自改自报工作，实现隐患排查、登记、评估、报告、监控、治理、销账闭环管理。

对重大隐患，组织专业技术人员、专家或者具有相应资质的专业机构进行风险评估，根据风险评估结果制定治理方案，治理方案应明确治理目标和任务、治理方法和措施、经费和物资保障、责任部门和人员、治理时限和要求、安全措施和应急预案等内容，并组织落实治理方案，消除安全隐患。

（二）各行业主管部门

各行业主管部门依法对其职责范围内的安全隐患排查治理实施监督管理，有计划、有重点、多频次、多形式的组织开展隐患排查，并建立相应的监督检查信息台账并存档。

1.按照“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”（以下简称“三必须”）的要求，根据需要进行现场核查，督促生产经营单位按照治理方案整治安全隐患，防止事故发生。必要时，可对生产经营单位采取停产停业、设置安全警示标志等应急措施。

2.依照《四川省安全隐患排查治理信息系统》中已发布的行业企业《安全隐患排查上报通用标准》并参照国家安全监管总局制定的《工贸行业事故隐患排查上报通用标准》，排查或督促排查行业（领域）管理范围内的隐患，整改或督促整改行业（领域）管理范围内的隐患，建立并督促隐患单位建立“两个清单”和隐患排查、整改汇总台账档案。

3.每月进行一次隐患排查整改及“两个清单”、汇总台账档案建立和管理工作情况检查，协调排查整改过程中遇到的突出问题。

4. 各行业主管部门要组织专业技术人员、专家对重大隐患整改效果进行现场核查，未达到整改要求的，不能复工复产（使用）。

（三）县安办

县安办要发挥好综合协调功能，联动行业部门开展隐患排查，对辖区隐患登记进行统一管理。

1.加强综合协调、督促行业主管部门开展隐患排查整改及“两个清单”、汇总台账档案建立和管理工作。

2.每季度协调组织开展一次隐患排查整改及“两个清单”、汇总台账档案建立和管理工作综合督查。

3.收集辖区隐患排查整改情况并进行统计分析，为安全生产工作决策提供科学依据。

4.将隐患分级（色标预警）、分类管理，定期进行动态公示。

（四）县委、县人民政府、各乡镇党委政府

各乡党委、政府要按照“党政同责、一岗双责，齐抓共管”的要求，对本行政区域内安全隐患排查治理工作统一领导，组织有关部门排查安全隐患，建立本辖区重大隐患档案。根据安全生产工作特点，结合本地实际情况，在重点时段深入开展重点行业、重点领域的专项整治。

1.及时调整充实隐患排查治理工作领导小组，进一步明确领导责任。

2.研究制定隐患排查治理绩效考评办法。

3.梳理本辖区内重大隐患，政府主要负责人和分管负责人要督促整改。

4.加大隐患整改责任人问责力度，对整改进度缓慢的要进行通报，对不整改或不按时完成整改的要按照相关规定严格追责。

5.落实专项工作经费，用于人员培训、设备配置、专业评估等。

四、工作要求

（一）理清隐患标准，强化安全意识。

安全隐患分为“一般隐患”和“重大隐患”。一般隐患，是指危害和整改难度较小，发现后能够立即整改排除的隐患。重大隐患，是指危害和整改难度较大，应当全部或者局部停产停业，并经过一定时间整改治理方能排除的隐患，或者因外部因素影响致使生产经营单位自身难以排除的隐患。一般隐患原则上立即整改，限期整改的最长整改时间不超过1个月；重大隐患最长整改时间不超过6个月。

（二）制定计划，稳步推进。

2017年4-5月，各乡党委政府、各部门、各行业、各单位要结合实际制定具体工作方案，明确目标、任务、措施，在非煤矿山、危险化学品、客运企业等重点生产经营单位和道路交通、地质灾害、城市建设、重点工程、旅游、教育、卫生等重点行业（领域）开展隐患排查、整改工作和建立“两个清单”、汇总台账档案等试点工作。6-9月，在重点生产经营单位和重点行业（领域）试点的基础上，全面开展隐患排查、整改工作和建立“两个清单”、汇总台账档案等工作。10-12月，各乡党委政府、各部门、各行业、县安办要开展工作情况检查督查，总结经验，完善制度，将隐患排查、整改工作和建立“两个清单”、汇总台账档案工作纳入常态化轨道，建立长效机制。

（三）安全隐患上报要求。

1.各生产经营单位于每月25日前，将本单位隐患排查和整改情况报辖区乡镇安办和行业主管部门；发现的重大隐患应立即以书面和电子邮件形式上报，并持续报送隐患整改进度。

2.各村（社区）于每月25日前将本辖区隐患排查和整改的情况报送辖区乡镇安办。

3.各乡镇安办于每月27日前将本辖区隐患排查和整改情况报送县安办和行业主管部门，发现的重大隐患应立即以书面或电子邮件形式上报，并持续报送隐患整改进度。

4.各行业主管部门每月28日前将隐患排查和整改情况报送县安办和上级行业主管部门；对一时难以整改的重大隐患应及时以书面和电子邮件形式上报，并持续报送隐患整改进度。（联系人：徐书平，邮箱：224139515@qq.com，联系电话：7725109  手机：[电话略]）

5.县安办于每月3日前将上月重大隐患排查、整改情况汇总报州安办。

（四）严格管理，保证效果。

各乡党委政府、各部门、各行业、各单位要将“两个清单”、汇总台账管理贯穿于隐患排查治理体系建设工作全过程。严格按照“两个清单”、汇总台账管理要求，建立完善隐患排查、整改、分析、上报、建档等制度，落实领导负责、层层督办责任，确保隐患排查整改到位。要发挥安全生产专家作用，组织专家参加安全隐患排查整改活动。对于生产工艺、系统复杂的高危单位和存在较大事故风险的单位，可以采取购买服务的方式委托有资质的中介服务机构或专家团队进行“会诊”排查，针对性制定整改方案，提升隐患排查整改工作质量。今年，通过隐患排查整改工作的推进和“两个清单”、汇总台账的建立，要实现“真查出一批隐患，真整改一批隐患，真上报一批隐患”，确保不发生重特大事故。

（五）加强宣传，强化执法。

各乡党委政府、各部门、各行业、各单位要充分利用广播、电视、报纸、互联网、微信公众号等媒体，宣传好经验、好做法，营造良好舆论氛围。要充分动员群众，发挥舆论监督作用，举报、曝光重大安全隐患，起到警示和威慑作用。各乡党委政府、各部门、各行业、各单位要加强协调联动，开展联合执法。对存在安全隐患又不认真自查自改自报的，要依法进行查处；对拒不整改的，要列入“黑名单”向社会公布；对存在重大隐患且不能保证生产经营安全的，要依法停产停业（使用）整顿，涉嫌犯罪的，要及时移交司法机关。
