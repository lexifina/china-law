# 九寨沟县人民政府办公室关于调整九寨沟县两项资金工作领导小组成员的通知

各乡（镇）人民政府，县级各部门，企事业单位:

因人事变动，经县人民政府研究，决定调整九寨沟县两项资金工作领导小组，其成员如下：

组    长：陶    钢    县委副书记、县长

副组长：陈志敏    县政府副县长

出吾扎西   县民族宗教局局长

王玉梅    县财政局局长

成    员：叶    林    县委办公室主任

郭友林    县政府办公室副主任、县扶贫和移民工作局局长

彭旭东    县纪委副书记

泽     军    县发展和改革局局长

李     勇    县农业畜牧和水务局局长

李贵先    县审计局局长

程     龙    县财政局副局长

张     敏    县民族宗教局副局长

各乡（镇）长

领导小组办公室设在县民族宗教局，由出吾扎西兼任办公室主任，程龙、张敏兼任办公室副主任，张敏负责处理日常事务。

职责分工：

县委农工办：主要负责项目检查调度、综合协调等工作；

县监察局：主要负责项目建设监督检查和违纪违规案件的查处等工作；

县发展和改革局：主要负责项目招投标政策指导、程序把关和协调等工作；

县民族宗教局：主要负责项目监管、推进协调，组织项目验收及资料归档等工作；

县财政局：主要负责招标项目的财政评审和结算、项目资金的管理、资金使用的监督检查等工作；

县扶贫和移民工作局：主要负责扶贫专项项目和资金的监督检查等工作；

县农业畜牧和水务局：主要负责项目实施方案编制、审查、项目实施过程技术指导等工作；

县审计局：主要负责项目审计等工作；

各乡（镇）人民政府：主要负责项目实施、推进、监督和协调等工作。
