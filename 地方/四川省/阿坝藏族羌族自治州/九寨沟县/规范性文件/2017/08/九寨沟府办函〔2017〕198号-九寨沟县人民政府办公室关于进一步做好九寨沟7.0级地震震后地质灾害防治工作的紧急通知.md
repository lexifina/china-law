# 九寨沟县人民政府办公室关于进一步做好九寨沟7.0级地震震后地质灾害防治工作的紧急通知

各乡（镇），县级相关部门：

按照九寨沟县地质灾害应急防治指挥部工作安排，县国土资源局、县监察局、县安全生产监督管理局、县农业畜牧水务局组成两个联合督导组，对全县17个乡（镇）、九寨沟风景名胜区管理局、县交通运输局、九寨国家森林公园管理局等地质灾害防范主体单位进行了督导检查，发现部分地质灾害隐患点排查制度不完善、部分监测员在岗履职不到位、值班抽查力度不够等突出问题（详见附件），请你们坚持问题导向，立即对承担防范主体责任的地灾灾害隐患点防灾措施落实情况进行整改落实，切实解决地灾灾害隐患点防治工作中的安全隐患问题，并于2017年9月1日前以正式文件将整改落实工作开展情况报送至县委县政府目标督查办公室（联系电话：7729436）和县国土资源局（联系电话：7732022），一旦发现未整改或整改不到位等情况，将立即对防范主体单位启动问责程序。

特此通知。
