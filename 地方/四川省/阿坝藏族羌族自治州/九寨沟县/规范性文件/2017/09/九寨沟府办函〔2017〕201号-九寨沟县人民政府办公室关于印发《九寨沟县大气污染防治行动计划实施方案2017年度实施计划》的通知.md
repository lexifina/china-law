# 九寨沟县人民政府办公室关于印发《九寨沟县大气污染防治行动计划实施方案2017年度实施计划》的通知

各乡（镇）人民政府，县级相关部门:

《九寨沟县大气污染防治行动计划实施方案2017年度实施计划》已经县十四届人民政府第17次常务会议审议通过，现印发你们，请认真贯彻执行。

九寨沟县人民政府办公室

2017年9月1日

九寨沟县大气污染防治行动计划

实施方案2017年度实施计划

为扎实推进我县大气污染综合防治,改善环境空气质量，有力保障人民群众身体健康，大力提升环境保护和生态文明建设水平，按照州政府《关于印发阿坝州“十三五”环境空气质量和主要大气污染物总量减排指标目标任务分解计划的通知》（阿府办函〔2017〕72号）和州“三大战役”领导小组办公室《关于印发〈阿坝州大气污染防治行动计划实施方案2016年度实施计划〉的通知》（阿州污防“三大战役”办〔2017〕13号）要求，结合我县实际，制定本实施方案。

一、年度目标

（一）环境空气质量目标。九寨沟县可吸入颗粒物（PM10）年均浓度控制≤45(微克／立方米),细颗粒物（PM2.5）年均浓度控制≤31(微克／立方米)。

（二）主要大气污染物排放控制目标。九寨沟县二氧化硫和氮氧化物减排年度目标：二氧化硫5吨、氮氧化物2吨。

二、重点工作

（一）加大工业污染治理力度。

1.强力整治挥发性有机物污染。到2017年底，全面完成加油站、储油库、油罐车的油气回收治理工作。（牵头单位：县环林局，配合单位：县经信局）

2.积极推进燃煤、小锅炉淘汰。

按照统一规划、以热定电、适度规模的原则，科学推进“煤改气”、“煤改电”工程建设。对暂不具备实施清洁能源替代的,必须实施高效除尘改造;新装锅炉原则上应使用清洁能源,城市建成区和工业园区禁止新装额定蒸发量小于20T/h的燃煤锅炉，九寨沟自然保护区范围内禁止新装燃煤锅炉；产业聚集区集中建设热电联产机组或大型集中供热设施。

根据安全、节能、环保的要求，所有在用锅炉（含新装）及其系统应按规定进行热效率测试，对于低于工业锅炉热效率指标的锅炉，使用单位必须加装锅炉节能系统。（牵头单位：县工商质量食药监局，配合单位：县环林局、县经信局、县发改局、县安监局）

3.持续推进企业清洁生产和提高科技创新

一是加快天然气、液化石油气、煤制天然气、太阳能、绿色能源、沼气、地热能等清洁能源的供应和推广，逐步提高城市清洁能源使用比重。二是严格落实节能评估审查制度，新建高耗能项目单位产品（产值）能耗要达到国内先进水平，用能设备达到一级能效标准。三是推行工业领域清洁生产，对重点行业企业全力推进清洁生产审核，推进实施清洁生产技术改造。四是大力推进可再生能源与建筑一体化应用。五是持续推进马脑壳金矿、草地金矿清洁生产技术改造。大力发展工业循环经济。建设生态工业园区，促进能源梯级利用、废物交换利用、土地节约集约利用，促进企业循环式生产、产业循环式组合。（牵头单位：县发改局，配合单位：县环林局、县经信局、县农水局）

4.加快发展节能环保产业

大力发展节能环保产业，加大节能环保新技术、新产品、新工艺科技成果转化、推广应用力度；积极推进环境服务业发展，有效推动节能环保、新能源等战略性新兴产业发展。（牵头单位：县发改局，配合单位：县经信局、县科技局、县环林局）

（二）积极推动产业转型升级，提高落后产能淘汰水平。

1.加快淘汰落后产能。

结合产业发展实际和环境空气质量状况，制定范围更宽、标准更高的淘汰政策。继续加大淘汰落后产能力度，将经整改整顿仍不达标的企业列入年度淘汰计划。（牵头单位：县经信局，配合单位：县发改局、县环林局）

2.严控“两高”行业新增产能。城市建成区、工业园区禁止新建每小时20蒸吨以下的高污染燃料锅炉，其他地区禁止新建每小时10蒸吨以下的高污染燃料锅炉，漳扎镇禁止新建、使用燃煤锅炉。（牵头单位：县发改局，配合单位：县经信局、县环林局、漳扎镇）

（三）加快优化区域经济布局，严格节能环保准入。

1.强化节能环保指标约束。

提高节能环保准入门槛，进一步完善重点行业准入条件。严格落实污染物排放总量控制制度，把二氧化硫、氮氧化物、工业烟粉尘、挥发性有机物等主要污染物排放总量指标作为建设项目环境影响评价审批的依据之一，其中二氧化硫、氮氧化物排放总量控制按照环境保护部印发的《建设项目主要污染物排放总量指标审核及管理暂行办法》（环发〔2014〕197号）有关规定执行；严格落实节能评估审查制度，固定资产投资项目单位产品（工序）能耗要达到国家强制性能耗限额标准。（牵头单位：县环林局，配合单位：县发改局）

2.优化区域空间布局。

深化落实主体功能区规划要求，城市总体规划应当包括生态环境保护与建设目标、污染控制与治理措施等强制性内容，合理确定产业发展布局、结构和规模；加强产业政策在产业转移过程中的引导和约束作用，严格控制、限制在生态脆弱或环境敏感地区建设“两高”行业项目；加强各类产业发展规划环境影响评价工作。经依法批准的城乡规划应当严格执行，任何单位和个人未经法定程序不得擅自修改。积极调整产业结构，优化工业布局，加强区域合作联动，形成有利于大气污染物扩散的城市和区域空间格局。（牵头单位：县住建局，配合单位：县国土资源局、县环林局、县经信局、县发改局）

（四）重点整治面源污染，加强城市综合管理。

1.加强建设施工工地和道路扬尘污染整治。

严格落实建设施工工地扬尘整治管理制度。积极推行绿色施工，建设工程施工现场必须全面推行标准化文明工地管理模式，做到“六必须”（必须围档作业、必须硬化道路、必须设置冲洗设施、必须及时洒水作业、必须落实保洁人员、必须定时清扫施工现场，道路建设仅要求高速公路必须围挡作业）、“六不准”（不准车辆带泥出门、不准运渣车辆冒顶装载、不准高空抛撒建筑垃圾、不准现场搅拌混凝土、不准场地积水、不准现场焚烧废弃物）。加强建设工地监督检查，督促责任单位落实降尘、压尘和抑尘措施。

认真整治城市道路扬尘污染。强力实施绿化带“提档降土”改造工程和裸土覆盖工程，减少城市道路两侧裸土面积；加强建筑垃圾管理，严格审批发放建筑垃圾运输许可证，全面实行建筑垃圾密闭运输。加强城市道路路政养护管理，控制城市道路占用挖掘审批，减少路面破损和路面施工；加大城市管理行政执法力度，严格查处抛洒滴漏、带泥行驶、道路乱开乱挖以及擅自清运工程渣土等行为。

推进堆场扬尘综合治理。强化料堆监督管理；大型料堆场应建立密闭料仓与传送装置，生产企业中小型堆场和废渣堆场应搭建顶篷并修筑防风墙；临时露天堆放的应加以覆盖或建设自动喷淋装置。对长期堆放的废弃物，应采取覆绿、铺装、硬化、定期喷洒抑尘剂或稳定剂等措施。加强各类废弃地治理，实施生态修复，抑制扬尘产生。

加强城市绿化建设。依托城市自然山水景观资源，大力推进城市生态公园绿地建设。强化绿地系统规划编制和绿线管理，保护好城市绿道绿廊、山体公园等城市生态空间。（责任单位：县住建局、县交通局）

2.强力推进秸秆焚烧和综合利用。

落实秸秆焚烧责任体系，加大巡查力度，及时发现、制止和查处秸秆焚烧行为。积极推广秸秆综合利用先进技术和秸秆焚烧管理经验，推动秸秆综合利用项目建设，持续提高秸秆综合利用率。落实属地管理责任，加强城市建成区露天焚烧落叶、垃圾等行为管控，倡导春节、中元节、清明节文明祭祀，加大居民小区、背街小巷等区域巡查力度。（责任单位：县农水局，配合单位：县发改局、县住建局、各乡（镇））

3.有力防治餐饮油烟污染。

加强城区餐饮油烟排放的监管，对问题集中区域实行专项治理。严格饮食服务经营场所环境保护审批。依法推行餐饮业排污许可证制度。大中型餐饮企业和单位食堂要安装高效油烟净化装置，并确保油烟净化设施稳定运行。（牵头单位：县住建局，配合单位：县国土局、县环林局、县经信局、县发改局）

4.全面落实高污染燃料禁燃区划定工作。

认真落实相关规定，科学划定高污染燃料禁燃区，加大执法检查力度，禁燃区内禁止燃烧各类高污染燃料。（牵头单位：县发改局，配合单位：县经信局、县环林局）

（五）实施“车油路管”，综合治理，加强机动车污染整治。

1.加强城市交通管理。

实施公交优先战略，完善公共交通网络，提高公共交通出行比例，促进机动车使用强度降低。（责任单位：县交通局）

2.严格监管燃油品质。

全面供应符合国家第五阶段标准的车用汽、柴油，加强油品质量监督检查和监督抽查，保障油品质量，督促加油站不得销售不符合标准的车用汽油、柴油。（牵头单位：县工商食药监局，配合单位：县经信局）

3.加强机动车环保管理。

加强机动车环保检验工作。加强机动车环保监控体系管理，全面开展机动车环保定期检验，实现机动车环保标志核发全覆盖。（牵头单位：县公安局，配合单位：县发改局、县经信局、县环林局、县交通局、县工商食药监局）

4.开展非道路移动机械污染防治。

启动非道路移动机械调查工作，推进非道路移动机械污染整治。按照《关于实施国家第三阶段非道路移动机械用柴油机排气污染物排放标准的公告》（环境保护部2016年第5号）要求，严控不达标机械进入施工、作业现场。（牵头单位：县住建局，配合单位：交通局、县农水局）

（六）推进能源清洁利用，持续降低煤炭消费总量。

1.提高天然气消费比重和有调节能力的水电站占水电装机容量的比重，控制煤炭消费总量

2.大力发展清洁能源。大力发展太阳能、生物质能。

3.提高煤炭清洁利用效率。严厉禁止销售高灰份、高硫份的劣质煤炭。（牵头单位：县发改局，配合单位：县经信局）

（七）健全监测预警和应急体系，强化基础能力。

1.进一步完善空气自动监测网络建设。

做好县城及漳扎镇空气自动监测站的管理维护，进一步加强监测数据质量管理和监测数据的部门共享，客观反映空气质量状况，继续加强重点污染源在线监控建设。（责任单位：县环林局，配合单位：漳扎镇）

2.完善监测预警体系。

继续推进重污染天气预警监测体系建设，加强环保、气象等部门间合作，完善重污染天气联合会商和预警发布机制。（牵头单位：县环林局，配合单位：县应急办、县气象局、县文体广新局、县经信局、县住建局）

3.强化重污染天气应急、注重常态化管控。

加强空气质量监测网络建设，实行监测资料共享，提高监测和预报预警能力水平。（责任单位：县环林局）

4.加强重污染企业监管。

加强监督检查，确保稳定达标排放，推进人工影响天气改善环境质量。（牵头单位：县环林局，配合单位：县经信局、县气象局）

三、保障措施

（一）强化责任落实。县人民政府是大气污染防治工作的责任主体，对本行政区域内大气环境质量负责。编制和实施大气污染防治计划，确保目标、责任、任务、项目、资金“五落实”，并向社会公开实施进展情况，确保各项任务全面完成。

（二）强化目标管理。严格按照省委绿色发展决定的部署、《四川省环境污染防治“三大战役”实施方案》、《阿坝州大气污染防治行动计划实施方案》确定目标任务、细化落实举措、积极推进，全面管控，确保目标任务全面完成。

（三）强化联动机制。实行环境规划、标准、监测、环评、执法、信息公开“六统一”，定期召开大气、水、土壤污染防治工作联席会议，研究工作推进措施完善长效工作机制。

（三）强化执法监管。认真落实《中华人民共和国环境保护法》、《中华人民共和国大气污染防治法》和《国务院办公厅关于加强环境监管执法的通知》（国办发〔2014〕56号）、《四川省人民政府办公厅关于加强环境监管执法工作的通知》（川办发〔2015〕47号），不断强化多部门执法检查，加大现场检查、随机抽查力度，全面排查整改各类大气污染隐患和问题，严厉打击各类大气污染环境违法行为，对涉嫌环境污染犯罪的依法追究刑事责任。

（四）严格责任落实。对各乡（镇）、部门大气污染防治工作实施情况进行严格考核。考核结果将作为各乡（镇）、各部门领导班子和领导干部综合考核评价的重要依据，对大气污染防治工作不力、空气质量状况恶化的地方，实施区域限批和问责制。

（五）加强信息公开。县环林局继续加强大气环境质量信息发布，规范发布模式，融合信息资源，提升信息公开的实效性、权威性。县环林局、县气象局要加强重污染天气预报预警信息发布和传播，提高社会公众防范意识和能力。
