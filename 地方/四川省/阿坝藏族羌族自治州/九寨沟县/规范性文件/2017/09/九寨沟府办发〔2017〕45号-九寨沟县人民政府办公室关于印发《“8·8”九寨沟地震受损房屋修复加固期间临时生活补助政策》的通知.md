# 九寨沟县人民政府办公室关于印发《“8·8”九寨沟地震受损房屋修复加固期间临时生活补助政策》的通知

各乡（镇）人民政府、县级有关部门：

《“8·8”九寨沟地震受损房屋修复加固期间临时生活补助政策》已经2017年9月4日县十四届人民政府第18次常务会议审议通过，请结合实际，抓好贯彻执行。

九寨沟县人民政府办公室

2017年9月5日

“8·8”九寨沟地震受损房屋修复加固期间临时

生活补助政策

按照《阿坝州人民政府关于九寨沟7.0级地震受损房屋修复加固和重建补助标准的批复》（阿府函〔2017〕133号）精神，为确保因灾房屋受损群众在实施房屋维修加固期间基本生活有保障。按照省、州、县抗震救灾指挥部的统一安排部署，根据第三方评估机构出具的居住房屋安全鉴定（判别）报告结论，本着安全第一和方便群众生活的原则，结合我县实际，特制定本补助政策。

一、临时生活补助发放对象、时间、标准及人员确定

（一）临时生活补助对象

对城乡居民住房安全鉴定（判别）结果为“轻微损坏”、“中等破坏”、“严重破坏”，房屋通过维修加固后，即可返家入住的；

（二）临时生活补助发放的时间

对城乡居民住房安全鉴定（判别）结果为“轻微损坏”、“中等破坏”、“严重破坏”的家庭成员的临时生活补助时间分别为15天（2017年8月24日起至9月7日止）、25天（2017年8月24日起至9月17日止）、38天（2017年8月24日起至9月30日止）。

（三）生活补助发放的标准

以损坏的城乡居民住房所有权人户籍登记人数为准，按每人每天20元和1斤粮（折价3元/斤）的标准进行现金补助。

（四）户籍人口确定

1.以2017年8月9日零时以前户籍登记人口数为准，以户为单位发放临时生活补助。

2.户籍不在该户，但与该户户籍成员有婚姻关系的，凭婚姻证明和原户籍地未领取临时生活救助证明（外县人员除外）在该户登记，原户籍地不再登记。

户籍中的家庭成员不在县内，但系外出务工、求学的予以登记。

3.国有企事业单位工作人员、国家公务人员（含离退休人员）及空挂户均不予登记。

4.在执行临时生活救助政策前已死亡但未销户的人员不予登记。在执行临时生活救助政策过程中死亡（死亡当日截止）或出生（出生当日开始计算）的人口以实际天数计算。

三、临时生活补助申领程序

（一）兑现程序

1.公布。由乡（镇）人民政府依据本实施方案，将补助对象、补助标准和补助申领时间向群众公布和宣传。

2.申请。由符合条件的受灾群众以户为单位向所在地村（社区）进行申请，村（社区）负责对申请对象条件进行初审，并协助填写《“8·8”九寨沟地震受损房屋修复加固期间临时生活补助审批表》一式两份。

3.公示。村（居）民代表会议或村民（社区）议事会组织对申请对象进行评议，经评议通过的对象予以公示，公示期不少于3天。评议公示情况和村（社区）意见填入《“8·8”九寨沟地震受损房屋修复加固期间临时生活补助审批表》，公示资料照像保存。

4.审核。经公示无异议的对象，经村（社区）负责人签字盖章后报乡（镇）人民政府审核。乡（镇）意见填入在《“8·8”九寨沟地震受损房屋修复加固期间临时生活补助审批表》。同时按补助申请对象具体情况报县住建或国土部门审核确认。

5.审批。对乡（镇）人民政府、县住建、国土部门审核通过的合格的补助对象，由县民政局最终审批确定。

（二）资料要求

符合条件的受损家庭户向房屋所在地村（社区）提出临生活补助申请时，应提供下列材料：

房屋所有权证或其他产权证明（验原件，提交复印件）；鉴定报告（房屋安全鉴定评估结论。验原件，提交复印件）；户口簿、户主身份证、银行卡或存折（验原件，提交复印件）

四、工作职责

（一）各乡（镇）人民政府：负责辖区内受灾群众生活补助申报工作、安抚受灾群众、引导群众按规定时间安全返家尽快恢复生产生活，落实政策和日常管理等工作。

（二）县民政局：统筹协调群众维修加固房屋期间临时生活补助发放工作，协助乡（镇）人民政府做好登记造册工作，落实资金补助的发放；负责对本方案的解释。

（三）县财政局：负责筹措补助资金，加强资金管理和监督。

县城乡规划建设和住房保障局：负责出具受损房屋安全鉴定评估结论、审核乡（镇）上报申报材料等工作。

（四）县纪委、监察局：负责对政策执行过程中干部徇私舞弊、违规、违纪、优亲厚友行为进行查处。

五、工作要求

（一）各乡（镇）、县级各部门要坚决服从灾后重建工作领导小组的统一安排部署；乡（镇）党委、政府，村（社区）要高度重视此项工作，配备专门人员，狠抓落实。

（二）各乡（镇）、县级各部门要统一思想，提高对群众生活补助工作的认识，认真履行工作责任，切实完成此项工作。

（三）各乡（镇）、县级各部门要把握正确的舆论导向，做好政策的宣传解释工作。对政策宣传要细化，做到家喻户晓，营造受灾群众积极开展生产自救，自力更生，重建美好家园的浓厚氛围。
