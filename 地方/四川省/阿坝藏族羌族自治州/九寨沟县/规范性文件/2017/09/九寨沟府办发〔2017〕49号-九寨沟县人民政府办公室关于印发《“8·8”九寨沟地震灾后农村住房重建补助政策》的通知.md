# 九寨沟县人民政府办公室关于印发《“8·8”九寨沟地震灾后农村住房重建补助政策》的通知

各乡（镇）人民政府、县级有关部门：

《“8·8”九寨沟地震灾后农村住房重建补助政策》已经2017年9月4日县十四届人民政府第18次常务会议审议通过，请结合实际，抓好贯彻执行。

九寨沟县人民政府办公室

2017年9月5日

“8·8”九寨沟地震灾后农村住房重建补助政策

为做好“8·8”九寨沟地震灾后农村住房重建工作，根据《阿坝州人民政府关于“8·8”九寨沟地震受损房屋修复加固和重建补助标准的批复》（阿府函〔2017〕133号）文件要求，结合我县实际，制定农村住房重建补助政策,，具体如下。

一、补助对象

1.因地震导致农村住房倒塌或严重破坏且无加固价值须拆除的农户；

2.住房因地震造成的地质灾害隐患威胁，经地灾评估必须避让搬迁的农户。

二、补助方式

1.补助资金按照“一户一宅”的原则，以户为单位发放；

2.补助资金实行“专款专用、直补到户”。补助资金原则上通过银行卡、存折方式直接发放到房屋所有权人，支付凭证装入农房重建档案。

三、补助标准

根据补助对象家庭人口数实行分档补助，具体补助标准如下：

四、补助发放程序

1.申请。根据公布的房屋安全鉴定（判别）结论或地灾评估报告属于重建户的家庭，在重建方式批准后，填写《“8·8”九寨沟地震受损住房拆除认定表》并拆除旧房，再由重建户填报《“8·8”九寨沟地震灾后农房重建补助申请审批表》向房屋所在地的村委会（社区居委会）提出农房重建补助申请，同时应提供户主身份证、家庭成员户口簿、房屋安全鉴定（判别）报告等相关材料的复印件。

2.评议。村委会（社区居委会）接到申请后，组织进行评议，对评议通过的重建补助申请户进行公示，公示期不少于3天。经公示无异议或异议不成立的，上报乡（镇）人民政府初审。

3.审核。乡（镇）人民政府对重建补助申请户进行审核；审核通过的，由乡（镇）人民政府张榜公示，公示期不少于3天；经公示无异议或异议不成立的，公示结果和申请材料报县民政局审批。

4.审批。农房重建补助申请户经县民政局会同县住建局审批同意后，确定为农房重建补助对象。

5.资金发放。县财政局筹集拨付补助资金，加强资金监管;县民政局按照重建工程进度分阶段发放重建补助资金：

原址重建和异址重建：以该户核定的重建补助金额为基数，一是已按程序拆除旧房且开工建设并完成基础部分的，拨付50%；二是房屋主体建设完工后，再拨付40%；三是竣工验收合格、资料齐备报乡（镇）人民政府存档，如系异址重建住房的对原宅基地进行复垦后，拨付剩余10%补助资金。

自主购房：选择自主购房方式重建的受灾户，原住房必须自行拆除完毕，并对原宅基地进行复垦，在提供了“购房合同”等拥有永久居住房屋的证明后，一次性兑付补助资金。

6.建卡归档。县民政局、各乡（镇）应分门别类，登记造册，对重建补助对象逐户建卡归档，形成一套重建补助从申请到发放的完整资料。县民政局和重建所在乡（镇）各存一份。

五、工作职责

各乡（镇）人民政府、村（社区）：负责受理补助申请，评议、审核补助金额，公示补助金额等工作。

县住建局：负责农村住房重建补助审批相关工作。

县财政局：负责补助资金的组织安排和使用监管，及时审核拨付资金。

县民政局：负责农村住房重建补助审批相关工作并组织兑现农村住房重建补助。

县公安局（派出所）：负责对受灾家庭户籍状况和家庭人口数的审核认定等工作。

县国土资源局：负责土地权属的认定、变更、申报办理，提供经第三方评估的地质灾害需要搬迁的范围。

六、其他

本补助政策自发布之日起执行，仅适用于“8·8”九寨沟地震灾后农村住房重建。

农村住房重建应符合城乡规划、村庄规划要求；本补助政策由县城乡规划建设和住房保障局负责解释。

附件1

“8·8”九寨沟地震农房重建户界定和补助对象

相关政策解释

一、重建户界定

（一）重建户界定标准

重建户以2017年8月9日零时之前户籍登记为准，按“一户一宅”基本原则进行界定。

（二）有下列情况之一的，界定为一户重建户

1.夫妻双方不在同一户籍的，界定为一户；

2.对“一户多宅”的，界定为一户；

3.对于“一宅多户”未分户办理土地和房屋权属证的，界定为一户；

4.2017年8月9日零时之前，虽然已经依法解除婚姻关系，但仍然共同生活未分家析产的，界定为一户。

二、补助对象及人数认定

（一）重建补助对象特殊情况处理

1.关于“一户多宅”。在九寨沟县境内农村有多处住房因地震灾害全部倒塌或严重破坏无加固价值须拆除的，只计为一次补助对象；住房既有倒塌或严重破坏且无加固价值须拆除，又有需要修复加固的，以修复加固且建成时间较近、实际居住的住房作为补助对象；

2.对因灾造成的“三孤”人员（孤儿、孤老、孤残）和需重建的散居五保对象不单独重建住房，通过纳入福利院、敬老院重建规划统筹解决，不享受重建补助；

3.农房的主房和附属房（厕所、厨房、圈舍等）损坏程度鉴定（判别）不一致的，以主房损坏程度鉴定（判别）对应的补助标准，享受补助政策。

（二）农房重建补助对象家庭人口数的认定

1.以2017年8月9日零时之前的户籍人口为准；

2.家庭成员中有大中专院校在校学生、现役军人（含国家政策不予安置的士官）和服刑人员的均计入该户家庭人口数；夫妻双方户籍不在同一户口簿的，凭结婚证明计入该户家庭人口数；

3.在2017年8月9日零时之前出生但未上户的，认定为家庭人口数；

4.“一宅多户”且分户但未办理土地和房屋权属证的，按一户享受补助政策，人口数按共同生活居住的人口合计计算。

有下列情况的，不计入家庭人口：

1.家庭成员中已经参加工作（机关、事业单位、国有企业正式职工）但户籍未迁出的，不能认定为家庭人口；

2.2017年8月9日零时之前死亡但未销户口的，不计入家庭人口数；

3.空挂户口的，不计入家庭人口数。

（三）以下情况不纳入补助范围

1.建新房后未拆除的旧房，包括已集中搬迁的高半山村寨未拆除的旧房；

2.未经批准，违反相关规定建设的房屋；

3.受损住房经第三方机构鉴定（判别）为只需通过修复加固即可居住，但农户执意拆除重建的。
