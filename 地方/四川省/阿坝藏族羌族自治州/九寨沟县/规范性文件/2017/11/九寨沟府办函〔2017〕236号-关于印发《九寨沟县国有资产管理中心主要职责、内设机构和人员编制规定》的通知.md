# 关于印发《九寨沟县国有资产管理中心主要职责、内设机构和人员编制规定》的通知

各乡（镇）人民政府，县级各部门，企事业单位:

《九寨沟县国有资产管理中心主要职责、内设机构和人员编制规定》已经县人民政府同意，现印发给你们，请认真遵照执行。

九寨沟县人民政府办公室

2017年11月7日

九寨沟县国有资产管理中心

主要职责、内设机构和人员编制规定

按照《中共阿坝州委机构编制委员会办公室关于设立九寨沟县国有资产管理中心的批复》（阿编办〔2017〕122号）要求，结合九寨沟县实际，设立九寨沟县国有资产管理中心，作为九寨沟县人民政府直属财政全额拨款公益一类正科级事业单位。

一、主要职责

（一）根据县人民政府授权，依照《中华人民共和国企业国有资产法》《企业国有资产监督管理暂行条例》《中华人民共和国公司法》和《阿坝州企业国有资产监督管理暂行办法》等法律法规，履行出资人职责，加强县属国有及控股（参股）企业的国有资产监管。

（二）代表县人民政府向所监管的国有及控股（参股）企业派出监事会，并负责监事会的日常管理工作。

（三）指导国有及控股（参股）企业完成改革和重组，建立健全现代企业制度，完善公司法人治理结构，推动国有经济布局和结构的战略性调整。

（四）按照法定程序对所监管的国有及控股（参股）企业负责人进行考核、任免，并根据其经营业绩进行奖惩，建立符合社会主义市场经济体制和现代企业制度要求的选人、用人机制，完善经营者激励和约束机制。

（五）负责国有企业资产保值增值监督管理，建立完善县级国有资产保值增值指标体系，制定考核标准;通过统计、稽核等方式对所监管企业国有资产运行情况进行监管，确保国有资产保值增值；负责所监管国有及控股（参股）企业工资分配管理，制定所监管企业负责人收入分配政策，并组织实施。

（六）参与制定国有资本经营预算有关管理制度；提出所监管企业年度国有资本经营预算计划；组织和监督所监管企业国有资本经营预算执行情况;审查所监管县级国有独资、控股（参股）企业的年度国有资本经营决算报告;负责组织所监管企业上缴国有资本金收益。

（七）根据县人民政府授权，负责县属国有及控股（参股）企业负责人的任免和管理。

（八）制定县级国有资产管理办法和制度，并对县级国有资产管理进行指导和监督。

（九）承办县委、县人民政府交办的其他事项。

二、内设机构

根据上述职责，县国有资产管理中心下设3个内设机构。

（一）综合办公室

处理中心运转的日常工作；负责中心综合协调、文电、会议、机要、保密、档案、财务、安全生产和信息化等工作;承担重要文件和主任办公会议决定事项的督办工作;指导所监管企业开展信访维稳工作;负责中心干部、人事及机构编制管理和所监管企业的人事、档案管理等工作。

（二）产权管理股

依照《中华人民共和国企业国有资产法》《企业国有资产监督管理暂行条例》《中华人民共和国公司法》《阿坝州企业国有资产监督管理暂行办法》等法律法规，研究提出县域内国有资产产权管理的建议，拟定国有资产产权界定、登记、划转、处置及产权纠纷等方面的规章制度和管理办法，并组织实施；承担国有资产评估项目的核准和备案工作；审核所监管企业资本金变动、股权转让及发债方案；监督、规范国有产权交易，参与重大投资决策，履行出资人职责；拟定国有企业清产核资的政策及制度、方法，组织所监管企业完成清产核资工作；按照国家有关规定，负责所监管企业资产损失和债权损失核销工作；负责组织所监管企业上缴国有资本收益。

（三）统计与绩效考核股

负责所监管企业国有资产和财务等统计工作；负责编报国有资本经营预算建议草案；负责所监管企业国有资本收益收缴工作；负责审核报批国有独资企业年度预（决）算草案；负责所监管企业收支决算的审核汇总工作；指导、规范所监管企业财务制度、会计核算制度建设；负责所监管企业清产核资和资产损失核销工作；负责拟订和完善所监管企业经营业绩考核制度及薪酬制度，经报批后组织实施；牵头组织实施所监管企业的年度目标考核工作；负责企业财务的监督检查工作；负责组织实施国有企业年度审计和专项审计工作。

三、人员编制和领导职数

九寨沟县国有资产管理中心事业编制8名，其中：主任1名（正科级）、副主任2名（副科级），股级领导职数3名（正股级）。

四、附则

本规定由中共九寨沟县委机构编制委员会办公室负责解释，其调整由中共九寨沟县委机构编制委员会办公室按规定程序办理。
