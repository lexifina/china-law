# 九寨沟县人民政府办公室关于印发《九寨沟县村邮站建设工作实施方案》的通知

各乡（镇）人民政府，县发展和改革局，县经济商务和信息化局，县交通运输局，县供销社，县邮政公司:

《九寨沟县村邮站建设工作实施方案》已经县人民政府同意，现印发给你们，请认真贯彻执行。

九寨沟县人民政府办公室

2018年3月14日

九寨沟县村邮站建设工作实施方案

根据《阿坝州人民政府办公室关于推进村邮站挂牌工作的通知》（阿府办函〔2017〕70号）要求，受“8·8”九寨沟地震影响，我县拟在2018年一季度底加快推进全县邮政公共服务能力水平，解决邮件“最后一公里”投递难题，助推全县“互联网 ”战略，推进全县农村脱贫攻坚步伐，特制定如下实施方案。

一、重要意义

普遍服务是国家保障的基本公共服务，村邮站是在农村实现普遍服务的重要公共基础设施，是保障和支撑农村邮政普遍服务、快递服务的重要终端。在全县村级建设村邮站，是服务边远山村群众，便民利民的一个重大民生项目，是解决农村快递服务和电子商务发展最后一公里问题的有效途径，是农村地区发展“互联网 ”实现农村脱贫致富的有效途径。村邮站的建成，既能有效解决我县边远乡村党报党刊投递不及时，信件、包裹、汇兑等农村基本邮政普遍服务不到位等问题，同时，也能有效解决我县农村电子商务发展中农村物流快递短板的问题，有效助推全县农村电子商务的发展。

二、目标要求

2018年一季度底全面完成120个行政村村邮站建设，每个村邮站配备一名兼职村邮员。

三、设置方式

（一）设置模式。以县政府为主，县邮政公司负责统筹推进村邮站建设和建立服务标准等相关工作。乡（镇）政府具体负责协助县邮政公司进行村邮站设置和日常管理工作。村邮站以村委会办公楼为场所，以村委会人员兼职为主的方式，确定村邮站的收件、投件人员，发挥好村邮站党报、邮件的接转功能。

（二）建设标准。村邮站建设应做到“二定三有四统”即：定人员、定职责；有村邮站工作用房（场地），有办理业务所需用品用具，有标识牌；统一标牌、统一标准、统一设施、统一管理。村委会为村邮站设置的实施主体，以现有的村委会办公楼为平台，村邮站面积原则上不小于15平方米，各乡（镇）政府负责统筹协调落实村邮站办公场地和兼职村邮员，县邮政公司负责业务培训和日常工作安排。

（三）服务功能。村邮站必须承担中央、省和市级主要党报党刊投递，收寄印刷品、包裹，收订报刊以及各类邮件的接转和投递到户的基本功能。同时，村邮站在承担好基本功能服务的前提下，可扩展服务功能，开展农村“互联网 ”，积极探索推进“农产品进城、工业品进村”业务，做好本地“农产品进城”的上线工作，展示和销售本地特色农产品，全面加快全县农产品走出去步伐。也可作为电费、水费、通信费等费用收缴和飞机票、汽车票、火车票预订等代理代办的便民利民综合服务平台。

（四）建设规划。因距离一季度底仅余不到1个月，全县村邮站建设全面完成已迫在眉睫。计划分以下时间节点进行。

1.3月10日前成立由分管领导任组长，各乡（镇）政府、县发展和改革局、县经济商务和信息化局、交通运输局、县供销社、邮政公司主要领导为成员的村邮站建设工作领导小组。领导小组下设办公室，办公室设在县邮政公司，具体负责村邮站的组织、协调和推进工作。

2.各乡（镇）政府和村委会确定村邮站收发邮件的兼职村邮员和各乡（镇）联系人，以村委会干部兼职为主，优先选聘懂电脑，有农村电子商务发展意识人员。于3月16日前报送县村邮站建设办公室（联系人：张健，联系电话：[电话略]），办公室审核汇总后，上报县人民政府，并抄送县邮政公司备案。

3.至3月20日起，由县邮政公司组织专业培训人员前往各乡（镇）召开业务培训会。同日，统一发放各村邮站标牌及相关办公用品，签订邮件转投协议。各乡（镇）政府积极组织协调村邮员参加培训会。

4.2018年4月1日，各村邮站正式运行。

四、保障措施

全县相关单位要积极创造条件，努力营造良好的设置环境，共同有序推进村邮站设置工作。

（一）县人民政府。负责村邮站设置的具体组织实施工作，加强检查督促力度，协调处理好设置和运营过程中的有关问题。

（二）县级相关部门职责。县交通运输局负责做乡村邮件搭载农村客运车辆协调服务工作，县发展和改革局、县经济商务和信息化局、县供销社等给予村邮站建设积极政策项目支持。

（三）各乡（镇）人民政府。负责统筹协调各村委会落实村邮站办公场地及村邮站兼职工作人员。

（四）邮政企业。邮政企业具体承担邮政普遍服务义务，县邮政公司按照村邮站建设标准购置村邮站标识牌和必要的设施设备；负责对村邮站的运行情况进行检查指导，及时协调解决运行中出现的问题；负责村邮站的业务指导和人员的日常培训，要做好乡邮政所与村邮站工作人员交收邮件的时间和频次的对接工作，保障农村寄递渠道的畅通。
