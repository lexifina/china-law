# 关于印发《九寨沟县2018年涉环保项目“邻避”问题防范化解工作实施方案》的通知

各乡（镇）人民政府，县级各部门:

《九寨沟县2018年涉环保项目“邻避”问题防范化解工作实施方案》已经县人民政府同意，现印发给你们，请认真贯彻执行。

九寨沟县人民政府办公室

2018年5月23日

九寨沟县2018年涉环保项目“邻避”问题

防范化解工作实施方案

为贯彻落实省州关于切实做好2018年涉环保项目防范与化解“邻避”问题，加强涉环保项目矛盾纠纷治理工作的决策部署，根据《阿坝州2018年涉环保项目“邻避”问题防范化解工作的实施方案》要求，结合我县实际,制定本方案。

一、总体要求

（一）指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大精神和习近平总书记来川视察重要讲话精神，深入贯彻落实省第十一次党代会、省委十一届二次全会、州委十一届四次全会、县委四届四次全会精神，牢固树立和践行“绿水青山就是金山银山”理念，坚持“全域发展、绿色崛起”总体战略，按照“防控风险、服务发展、破解难题、补齐短板”的要求，统筹推动和督促全县各乡（镇）、部门和企事业单位扎实履行涉环保项目“邻避”问题防范与化解主体责任，通过创新体制机制、完善制度和提高能力，建立健全防范与化解“邻避”问题长效机制，变“邻避效应”为“邻利效应”，切实维护广大人民群众利益，确保社会和谐稳定。

（二）基本原则

1.坚持属地为主，齐抓共管的原则。各乡（镇）、部门要按照属地管理原则，切实担负起防范与化解“邻避”问题的主体责任，明确部门职责，科学合理界定企业、公众权利义务。

2.坚持系统谋划，协调联动的原则。各乡（镇）、部门要系统谋划，充分沟通交流信息，推进政府、企业、公众的良性互动，形成政府统筹、部门合作、涉事企事业单位协同配合的工作局面。

3.坚持预防为主，防控结合的原则。各乡（镇）、部门要将防范与化解“邻避”问题融入经济社会发展大局和全过程监管机制化建设中考虑，切实做到科学民主决策，从源头上防范风险。在“邻避”问题出现后，要及时研判形势，主动采取有效措施，预防重大舆情和群体性事件。

4.坚持依法推进，综合施策原则。各乡（镇）、部门要根据本地区、本部门管理职责范围内存在的突出问题和实际情况，多措并举，加强机制建设和法律制度规范，从信息公开、公众参与、惠益分享、防控措施、宣传和舆情应对等对各环节综合施策，科学高效地防范与化解“邻避”问题，推动重大建设项目平稳落地。

（三）工作重点

全县生活垃圾处理、生活污水处理、医疗废物集中处置，涉危、涉重通讯基站等涉及公众环境权益的项目的“邻避”问题防范与化解。

（四）职责分工

1.统筹协调责任。各乡（镇）、部门要系统谋划，充分沟通交流信息，使政府、企业、公众能良性互动。

2.属地管理责任。各乡（镇）按照属地管理原则，明确责任、权限以及各级管理范围，切实担负起防范与化解“邻避”问题的主体责任。

3.行业主管责任。各部门要深入分析了解本行业领域存在的问题隐患，明确责任。

（五）工作目标

到2018年底前，全面推进涉环保项目“邻避”问题防范与化解工作，建立健全长效机制，形成综合对策体系，制定针对性强的具体实施方案，积累可推广的案例与经验，顺利推进涉环保“邻避”项目平稳落地，有效遏制涉环保项目“邻避”问题引发的群体性事件。

二、工作任务

（一）扎实推进涉环保项目“邻避”问题防范与化解工作。围绕涉环保项目“邻避”问题，制定建设项目“邻避”问题防范与化解工作具体实施方案，开展并实施社会稳定风险评估，依法推进建设项目立项、规划、选址、用地、环评、稳评等前期工作，加强宣传引导，扎实做好公众沟通工作，妥善处理群众诉求，强化建设项目全过程监管，严格落实隐患排查和整治，切实解决影响群众身体健康的突出环境问题，保障公众权益，逐步实现从管理到治理、从行政许可到公众认可的转变。

（二）建立健全工作专责小组机制。一是成立涉环保项目“邻避”问题防范化解工作领导小组，由政府分管领导为组长，环林局、信访办、维稳办主要领导为副组长，宣传部、信访局、维稳办、发改局、文体广新局、经信局、民政局、国土局、住建局、交通局、卫计局、安监局、法制办等为成员，进一步明确工作任务和职责分工。二是建立责任体系。各乡（镇）、部门要研究建立“党政同责、一岗双责、权责一致、终身追责”的责任体系，明确责任分工，制定责任追究办法。三是建立技术支持机制。针对“邻避”问题涉及的行业及各类风险环节，建立“邻避”问题专家库，广泛吸纳相关领域专业咨询机构及重点企事业单位专家意见，发挥相关专家在公众释疑、科学引导、矛盾纠纷化解、应急处置等方面的技术支持作用。各乡（镇）分管领导和相关负责人组成涉环保项目推进小组，共同推进涉环保项目建设。

三、实施步骤

（一）制定方案，动员部署。全面启动2018年涉环保“邻避”问题防范与化解工作，制定实施方案。各乡（镇）、部门根据本方案对应制定具体实施方案，明确分管领导和具体负责人。

（二）全面推进，完善台账。各乡（镇）、部门要在前期排查梳理“邻避”项目清单和台账的基础上，全面排查各领域在建和待建项目存在“邻避”问题风险情况，每月动态更新台账，系统分析清单内相关项目决策论证、规划选址、环境影响评价、社会稳定风险评估、日常运营监管等环节存在的矛盾纠纷和风险隐患，分门别类研究制定相关防范与化解对策，并汇总形成风险总台账。

（三）巩固提升。各乡（镇）、部门要及时进行分析总结，查找存在问题，明确整改方向。县环林局负责组织对专项治理工作进展情况进行定期督查，确保各项工作落到实处。并将会同各乡（镇）及相关部门将体制机制、对策体系、具体实施方案和能力建设等内容和具体做法集成为可借鉴和推广的经验，同时形成可以示范的典型案例。

四、保障措施

（一）加强信息报送。各乡（镇）、部门每月收集拟建和在建的“邻避”项目情况，包括项目进展情况、存在的矛盾纠纷、潜在的社会稳定风险、已落实的预防应对措施和需要上级部门支持指导的事项等。对于重大敏感的“邻避”项目要全天候滚动排查，实时报送情况。

（二）加强工作研判。涉环保领域信访维稳工作专责小组定期组织召开形势分析研判会，对各乡（镇）、部门报送并建立台账的项目进行集体“会诊”，分析评估各地“邻避”项目的决策论证、规划选址、技术标准、公众参与、环评、稳评、舆情风险评估等关键环节是否依法依规，各项工作是否扎实到位。各部门落实主管责任，按照职能对各地实施分类指导、综合施策。

（三）加强督查督办。对经过综合评估和系统审核后仍存在突出社会稳定风险的涉环保“邻避”项目，尤其是发生过不稳事件且经相关部门督促指导后仍无法化解的项目，根据项目存在的突出问题，由县人民政府进行约谈督办，或派出联合工作组赴现场督办，检查维稳措施和预案落实情况，压实各乡（镇）、部门在相关项目的主体责任，积极稳妥推进项目建设。

（四）加强预警预测。各乡（镇）、部门要进一步加强预警预测、信息通报、应急处置及调查评估等工作，妥善处理涉环保“邻避”问题。对出现不稳定事件苗头的，由掌握信息的部门实施预警预测，将相关情况通报相关企业和部门单位，及早预防、及早应对、及时化解。对因“邻避”问题引发的不稳定事件，各乡（镇）要及时、果断、科学处置事件，引导群众依法理性维权，防止引发不良示范效应。

（五）加强舆论引导。各乡（镇）、部门要充分发挥新闻媒体的作用，以本地计划建设的涉环保“邻避”项目为载体，以群众喜闻乐见的形式做好涉“邻避”科普宣传，提高群众认知水平和接受度，营造项目建设的良好氛围。要建立舆情监测、研判、预警机制，针对“邻避”项目推进建设的不同阶段，周密制定舆情处置预案，切实提高舆情危机应对能力，维护社会稳定。
