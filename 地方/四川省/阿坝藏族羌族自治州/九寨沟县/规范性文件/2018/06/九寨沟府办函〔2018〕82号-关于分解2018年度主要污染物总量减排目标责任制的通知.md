# 关于分解2018年度主要污染物总量减排目标责任制的通知

各相关单位：

为扎实推进我县主要污染物总量减排工作，按照州“三大战役”领导小组办公室《关于下达2018年主要污染物总量减排约束性指标目标任务的通知》（阿州污防“三大战役”办〔2018〕13号）文件精神，2018年我县将县城污水处理厂、乡镇及农村污水处理设施、禁养区内关停的养殖场、白河乡内关停的砖瓦窑确定为2018年重点减排项目，各责任单位要严格管理，有效推进减排工作，确保完成2018年减排目标任务。

一、减排目标

2018年，州人民政府下达我县的主要污染物总量减排目标

为：化学需氧量100吨，氨氮11吨，二氧化硫2吨，氮氧化物2吨。

二、工作要求

（一）高度重视，落实责任。总量减排工作纳入了政府工作计划，是刚性目标任务。考核结果纳入政务目标并占据较重分值，同时也用于生态转移资金考核、生态县创建、卫生城市创建、撤县建市等各项重点考核。各相关部门要高度重视总量减排工作，加强组织领导，落实项目资金，严格监督管理，确保减排目标任务的完成。

（二）强化沟通，深挖潜力。各相关部门要加强沟通和信息通报，摸清正在实施或即将实施城市、乡镇生活污水处理设施建设或升级改造、配套管网、农村生活污水和垃圾处置、工业污染防治设施升级改造、淘汰落后产能、砖瓦窑关停、禁养区内养殖场的拆除、燃煤锅炉淘汰和清洁能源替代等对总量减排有贡献的项目情况。

（三）增添措施，扎实推进。各相关部门要全面落实总量减排政策措施，主动作为，有力有序推进减排工作。

（四）提前收集，实施核查。各相关部门要按《2017年主要污染物总量减排核算有关要求》（详见附件2）文件的要求，提前收集整理减排项目支撑材料，做好资料准备工作，实施总量减排半年和年终核查核算。

三、落实减排责任

（一）县经济商务和信息化局负责研究制定有利于污染减排的产业政策；负责严格执行国家产业政策，组织推广应用新技术、新工艺、新产品，指导督促企业技术改造和污染减排，推进清洁生产和循环经济；负责组织实施我县产业结构调整，淘汰落后产能，提请县政府关闭、淘汰落后工艺（如砖瓦窑），确保完成国家、省、州下达的淘汰落后产能目标任务；负责收集整理白河乡内关停的8家砖瓦窑的减排支撑资料及核算工作。

（二）县城市管理局负责县城污水处理厂的正常运行，对县城污水处理设施运行进行监管，督促收集整理减排项目支撑材料，并负责我县城镇污水处理厂污泥规范化处理处置。

（三）县农业畜牧和水务局要负责指导督促畜禽养殖业污染减排工作，做好畜禽养殖业减排项目核查核算，完善禁养区内关停、拆除的养殖场减排项目的支撑材料；组织并监督实施畜禽养殖污染整治，指导督促实施规模化畜禽养殖场、养殖小区、养殖专业户的养殖废物、废水综合治理或者改进养殖方式减排污染，确保实现全县畜禽养殖业污染减排目标。

（四）县城乡规划建设和住房保障局负责本单位实施的乡镇及农村污水处理设施减排支撑材料的收集和核算。

（五）县环境保护和林业局负责牵头统筹推进全县减排工作，指导、协调、督促有关部门采取有效措施，落实重点减排项目和行业减排任务，确保实现全县减排目标；负责污水处理厂运行情况的监督管理；负责本单位实施的乡镇及农村污水处理设施减排支撑材料的收集和核算；负责加强减排统计、考核体系建设，积极协调上级监测部门进行监测；负责组织加强日常环保执法监督检查，提升对重点污染源的监管质量和效率；负责牵头落实县减排工作联席会议制度，加强有关部门之间的沟通配合、协调联动；负责牵头定期对减排情况进行核查核算，并将核算结果报县人民政府审定后予以通报；牵头负责配合环保部、省环保厅、州环保局做好对全县减排情况、重点减排项目的核查核算。
