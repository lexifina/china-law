# 关于印发《九寨沟县2018年砂石加工厂集中整治方案》的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县2018年砂石加工厂集中整治方案》已经县人民政府同意，现印发给你们，请认真贯彻执行。

九寨沟县人民政府办公室

2018年6月11日

九寨沟县2018年砂石加工厂集中整治方案

为深入贯彻国家、省、州环保问题整改的决策部署，规范全县砂石管理，遏制河道及非河道砂石乱采滥挖现象，保障河道行洪安全、水生态环境保护植被，切实解决砂石合法供应的问题，按照《阿坝州落实中央环境保护督查反馈意见整改工作领导小组办公室关于加大力度开展河道采砂问题整改的通知》（阿环整改办发﹝2018﹞10号）要求，根据相关法律法规，制定本方案。

一、整治对象

根据前期摸排结果，全县目前安装有成套砂石加工设备的砂石加工厂24处，其中，砂石原料来源于河道的有12处，来源于非河道有12处，主要集中在白河、黑河、白水江、汤珠河流域（详见附件）。各砂石加工厂除营盘河坝打砂场办有采砂许可证外，其余均无采砂许可证或者已到期，但均无环保、行洪论证、国土用地审批等手续，均属关停对象。其他如小型沉砂凼、村民自用砂砂坑等不在此次整治范围内。

二、具体工作计划

（一）参加单位

县农业畜牧和水务局、县国土资源局、县环境保护和林业局、县公安局、相关乡（镇）。

（二）整治时间

6月10日――7月10日

（三）整治范围及内容

根据《中华人民共和国环境保护税法》《中华人民共和国水法》《中华人民共和国防洪法》《中华人民共和国矿产资源法》《中华人民共和国土地管理法》《中华人民共和国河道管理条例》《四川省河道采砂管理条例》等法律法规以及省、州、县关于砂石管理相关规定，对白河、黑河、白水江、汤珠河流域进行全面清理整顿，严厉打击各类砂石违法行为，依法关停上述24处砂石加工厂，并按照法律法规进行处罚。营盘河坝打砂场暂停加工，依法完成整改后才能继续生产。对拒不执行处罚决定的，由主管部门依法申请县人民法院强制执行，对在专项清理整治活动中顶风作案造成国家砂石资源损失和暴力抗法的，依法追究相关责任人的刑事责任。

三、工作职责

（一）各涉及河流河长

严格按照河长制工作职责，县、乡（镇）、村三级河（段）长认真履行责任。负责组织领导相应河段的管理和保护工作，牵头组织对辖区内非法砂石加工厂依法进行清理整治，并协调解决矛盾纠纷问题。

（二）县环境保护和林业局

按照《四川省落实中央第五环保督察反馈意见整改方案》整改任务和《阿坝州落实中央第五环保督察反馈意见整改方案》整改任务清单及《阿坝州环境保护大检查大整改工作领导小组办公室关于转发<四川省环境保护厅关于全面排查处理自然保护地违法违规开发活动的函>的函》的要求，加快采砂问题整改，结合“绿盾2018”专项行动，进一步加强对各类自然保护区破坏生态问题的整治力度，全面清理，彻底整改。

依照相关法律法规，认真清查各采砂场、打砂场对生态环境的影响和破坏问题，责令限期整改，涉及违法的依法处理。

（三）县农业畜牧和水务局

全面清理、整顿、规范采砂作业和加工作业。严格按照相关法律法规和州水务局、州环境保护局关于河道采砂问题整改的相关文件要求，认真落实整改。对白河、黑河、白水江、汤珠河流域河道采砂和砂石加工厂进行全面清查，责令限期关停非法砂石加工厂、拆除打砂设备、清运机具、平整场地、恢复生态。对涉及河道非法采砂的，依据相关法律进行处罚。

妥善处置存量砂石，制定关停砂石加工厂的存量砂石处置方案，按照稳定供应建设项目用砂的原则，加快存量砂石消化，防止砂场整治导致砂石供应短缺或价格大幅波动，影响工程建设项目顺利推进。

在开展河道非法砂场整治的同时，同步推进河道采砂规划和河道采砂年度实施方案的编制工作，按规定程序报审和批准后，按照公开、公平、公正的原则，通过“招、拍、挂”的方式，依法出让河道采砂权，确保上下规划期河道采砂的顺利衔接，稳定河道砂石的市场供应。

（四）县国土资源局

严格按照相关法律法规，对非河道采砂点和砂石加工厂进行集中清理与整治，未办理相关手续的责令限期关停，拆除打砂设备、清运机具、平整场地、恢复生态，涉嫌违法的依法处理。已办理采砂许可证但未办理环保、行洪论证、国土用地审批等手续的，责令限期整改。

制定关停砂石加工厂的存量砂石处置方案，按照稳定供应建设项目用砂的原则妥善处置存量砂石，防止砂场整治导致砂石供应短缺或价格大幅波动，影响工程建设项目顺利推进。

加强对拍卖砂场的管理，督促完善相关手续。开展岩体砂石场采砂规划的编制和实施，依法出让采砂权，稳定砂石供应市场。

（五）县公安局

严格按照《九寨沟县公安局关于河道总警长及警长制工作方案》的要求，全面落实河道警长工作，加强执法检查，全力支持辖区内的整治行动，协助相关部门加强现场处置工作，负责整治现场的警戒工作，防止阻挠整治工作的群众滋事，并负责处置整治现场的突发事件和对违法闹事人员的依法处理。

四、工作要求

（一）统一领导，分级负责。按“谁主管，谁负责”的原则，明确工作责任，负责出现问题的及时、妥善处理。

（二）预防为主，防范未然。坚持预防为主、实事求是的工作方针，从源头上防止损害群众合法利益的事件发生，建立健全稳定预警工作机制，做到早发现、早解决。

（三）依法处置，防止激化。注重工作方法和策略，综合运用法律、行政等手段，加强宣传、协商、调解等处置方法。引导群众以合理、合法方式表达利益的诉求，解决矛盾。严格执法，将违法行为一查到底，决不姑息。对包庇、纵容、掩盖违法行为，对整治工作形成阻碍的，从严查处。

（四）快速反应，相互配合。在阻碍整治工作现象发生后，严格按照应急处置责任制，相互配合、协作和支持，形成最大工作合力。同时在信息收集、情况报告与现场处置等各环节紧密衔接，在最短时间内控制事态发展。对发生暴力行为、严重破坏社会治安、危害公共安全的恶性事件，及时、果断采取措施，坚决制止违法行为，尽快平息事态。

（五）加强教育，正确引导。严格按照实施方案和相关法律规定，制定通告、通知，要将法治宣传教育、疏导工作，贯穿工作的整个过程，教育群众遵守法律法规，依法维护自身合法权益，通过正当渠道和方式反映问题。

六、纪律要求

（一）所有参加人员必须听从组长的统一指挥，不得各行其是，不得推诿扯皮。

（二）所有参加人员必须统一行动，不得擅自离开整治现场，并严格按照各自职能职责搞好整治工作。

（三）所有参加人员必须注意安全、做好自我保护和互相保护工作。

（四）各执法人员做到文明执法、文明用语，不得以任何理由和借口激发矛盾。
