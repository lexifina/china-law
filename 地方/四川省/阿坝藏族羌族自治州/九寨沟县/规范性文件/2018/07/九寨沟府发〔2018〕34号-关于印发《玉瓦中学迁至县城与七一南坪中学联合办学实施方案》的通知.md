# 关于印发《玉瓦中学迁至县城与七一南坪中学联合办学实施方案》的通知

各乡（镇）人民政府，县级各部门：

《玉瓦中学迁至县城与七一南坪中学联合办学实施方案》已经县十四届人民政府第38次常务会议审议通过，现印发给你们，请严格遵照执行。

九寨沟县人民政府

2018年7月30日

玉瓦中学迁至县城与七一南坪中学

联合办学实施方案

为保障玉瓦中学灾后迁建项目顺利实施，优化县域初中校点布局，提升教育质量，经县人民政府研究论证，决定将玉瓦中学迁至县城与七一南坪中学联合办学。迁建项目涉及师生员工安排、课程设置、资产处置、征地新建教学及辅助用房等工作，为科学、平稳、安全完成迁建工作，特制定本实施方案。

一、指导思想

深入贯彻落实党的十九大精神，坚持以习近平新时代中国特色社会主义思想为指引，紧扣“全域发展、绿色崛起”总体战略，突出重点、通力协作，确保玉瓦中学迁至县城与七一南坪中学联合办学工作有力有序推进。

二、工作目标

按照《教育部关于进一步推进义务教育均衡发展的若干意见》（教基〔2005〕9号）要求，进一步解放思想，优化布局，整合玉瓦中学可利用教育资源，将联合中学建设成为“理念先进、目标明确、行为规范、质量领先”优质学校，促进我县教育事业均衡发展。

三、工作措施

保留玉瓦中学组织机构，采取“资源重组、统一管理”办法进行联合办学，具体措施如下：

（一）学生方面

1.玉瓦中学在读学生转迁工作。原玉瓦中学初一、初二年级41名在读学生，于2018年秋季开学之际，统一转迁至七一南坪中学平行班就读。两校须提前做好对接，细化学生转迁方案；接收年级班主任提前主动联系转迁学生，让转迁学生尽快找到归属感。开学之际，七一南坪中学要将教室分布图、宿舍分配情况等信息张贴在学校公告栏，安排专人引导转迁学生顺利报名就读。

2.玉瓦片区初一新生招录工作。2018年秋季，玉瓦中学不再进行单独招生，玉瓦片区小学（大录小学、玉瓦小学、黑河小学、陵江小学）小升初学生原则由联合中学招录。

3.转迁学生后勤保障工作。因玉瓦片区地处偏远，两校联合办学后，转迁学生统一安排住校，学校后勤部门提前做好转迁学生住宿保障工作。

（二）师资方面

1.专任教师调整工作。根据七一南坪中学和县中学学科设置、岗位设置等实际需求，按照人岗相符原则，优先配置初中紧缺学科教师，对玉瓦中学教师进行按需调整。经研究，决定将玉瓦中学26名教师进行如下调整：12人留任联合中学，6人调整至县中学任教，5人调整至县第三小学任教，2人调整至县第一小学任教，1人调整至县第四小学任教。调整至小学任教的原玉瓦中学专任教师，在联合中学、县中学需补充任课教师时，须优先选调。

2.调整后教师职称待遇。按需调整后的教师保留原玉瓦中学职称待遇，2018年继续按玉瓦中学岗位设置进行评职晋级。2019年起，所有调整教师同等参与所在学校评职晋级。

3.教辅人员调整工作。8名编外后勤人员进行如下调整：联合中学留任3人（住管2人、厨师1人），县第三小学分流3人（厨师），留守玉瓦中学2人（原保安）。

（三）资产方面

1.动产。两校联合后原玉瓦中学动产（教育教学设施设备等）按需并入七一南坪中学，剩余部分由县教育局统一调配至所需小学。

2.不动产。不动资产（房屋、土地等）由县教育局依法依规移交县国有资产管理中心进行监管。

（四）课程编排方面

两校联合办学后，课程由七一南坪中学教导处统一编排，继续保留开设藏文课程，配足藏语任课教师，行课时间由学校统一安排，集中上课（每周藏文课程不少于4课时）。

四、组织领导

为确保玉瓦中学迁至县城与七一南坪中学联合办学工作顺利开展，特成立九寨沟县联合办学推进工作领导小组，其成员如下：

五、工作要求

（一）高度重视，统一思想。局、校、老师务必高度重视，统一思想，加大宣传两校联合办学重要意义，切实做好玉瓦片区群众引导工作，防止群众集体上访。

（二）压实责任，齐心协力。严格落实“一把手负总责”要求，务必按照迁建工作总体部署，细化工作环节，层层压实责任，形成工作合力，保证两校联合办学工作平稳有序推进。

（三）规范管理，加强监督。七一南坪中学、玉瓦中学两校联合办学后，由县教育局按需调整学校领导班子，加强学校工作指导；学校应进一步建立健全管理机制，加强学生思想教育，引导学生团结互助、遵守校规校纪，确保联合办学工作步入正轨。
