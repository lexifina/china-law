# 关于印发《九寨沟县加强社会信用体系建设工作实施方案（2018-2020年）》的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县加强社会信用体系建设工作实施方案（2018-2020年）》已经县委、县政府研究同意。现印发给你们，请认真贯彻执行。

九寨沟县人民政府

2018年9月28日

九寨沟县加强社会信用体系建设工作

实施方案（2018-2020年）

为进一步加强“诚信九寨”建设，营造良好社会信用生态环境，支持“8·8”九寨沟地震灾后恢复重建和脱贫奔康工作，助推我县世界休闲度假旅游目的地建设，全面促进县域经济社会持续、健康、快速发展，按照《国务院关于印发社会信用体系建设规划纲要（2014-2020年）的通知》（国发〔2014〕21号）、《国务院关于建立完善守信联合激励和失信联合惩戒加快推进社会诚信建设的指导意见》（国发〔2016〕33号）、《四川省人民政府办公厅关于印发四川省社会信用体系建设工作实施方案的通知》（川办发〔2016〕61号）和《四川省人民政府办公厅关于印发加强个人诚信体系建设实施方案的通知》（川办发〔2018〕10号）等要求，特制定本方案。

一、总体目标

坚持社会主义市场经济的改革方向，围绕灾后恢复重建和脱贫攻坚中心工作，加强县域社会成员信用信息库（网）建设，建立覆盖全县的信用信息平台，加大失信惩戒和守信奖励的力度，强化诚信宣传教育，切实维护县域良好社会信用环境。到2019年6月前，基本建立经济社会主要领域守信联合激励和失信联合惩戒机制；到2020年底，基本建立跨行业、跨部门、跨领域的守信联合激励和失信联合惩戒工作机制，初步建成与我县经济社会发展水平相适应的社会信用体系框架，基本形成政府部门协同联动、行业组织自律管理、信用服务机构积极参加、社会舆论广泛参与的共同治理工作格局，以信用为核心的新型市场监管机制作用得到有效发挥，全社会信用意识普遍增强，“诚信九寨”建设取得积极效果。

二、工作原则

（一）统筹规划、分步实施。立足当前，着眼长远，统筹规划，明确思路和目标。抓住重点领域和关键环节，有序推进、逐步完善社会信用体系基本框架。

（二）健全机制、协同推进。按照“政府主导、双向牵头、共同参与”的工作机制，充分发挥政府在规划引导、资源整合、示范带动等方面的主导作用，发改、人行九寨沟县支行在建设信用信息系统的推动作用，相关部门和金融机构在行业信用建设、信用产品开发使用以及信用服务中的重要作用，推动全社会共同参与、宣传和监督我县社会信用体系建设的良好格局。

（三）积极探索、注重实效。推进社会信用体系建设体制机制创新，积极探索灾后信用体系建设的有效路径。强化社会信用体系建设与灾后恢复重建、脱贫奔康、市场监管体系建设等工作的有效对接，促进信用信息的广泛应用，建立健全守信激励和失信惩戒机制。

（四）依法依规，保护权益。严格依照法律法规和政策规定，科学界定守信和失信行为，开展守信联合激励和失信联合惩戒。建立健全信用修复、异议申诉等机制，保护当事人合法权益。

三、主要工作

（一）夯实诚信建设基础

依据国家、行业主管部门和省相关法律法规，建立健全我县信用信息数据管理、应用制度体系和标准化平台，加快推动信用信息在行业和部门间的互通共享，依法有序地向社会公众和信用服务机构公开信用信息。

1.完善信用信息数据管理体系。结合我县灾后恢复重建、脱贫奔康等工作实际，依法收集、整理、汇总各部门、单位在履职过程中形成的自然人、法人和其他组织的基础信息和信用信息；各部门要按照本行业法规和规划，加强自身信用信息系统的建设和运用，全面落实统一社会信用代码制度，完善重点领域个人实名登记，依法依规、及时准确、完整规范的收集、整理和保存信用主体的信用信息。

牵头单位：县发改局、人行九寨沟县支行

责任部门：各成员单位

2.完善信用信息共享应用机制。按照国家、省的规划、方案和各行业主管部门信息共享合作备忘录要求，健全我县信用信息报送、归集、整合的相关制度，建立县域信用信息共享应用平台，促进各部门信用信息的互动融合，推动公共信用信息与金融信用信息的逐步共享；将县域信用信息共享应用平台的查询、使用嵌入各部门行政审批、业务监管等日常流程，做到应查、能查、必查。

牵头单位：县发改局、人行九寨沟县支行

责任部门：各成员单位

3.完善信用信息公开发布机制。按照《国家发展改革委办公厅关于做好〈关于加强和规范守信联合激励和失信联合惩戒对象名单管理工作的指导意见〉贯彻落实工作的通知》（发改办财金〔2018〕87号）精神，出台我县信用信息公开发布相关制度，依托县域信用信息共享应用平台数据，开通“九寨信用网”、建立“诚信九寨”微信公众号，按规定向社会发布公共信用信息，宣传征信知识、工作动态和诚信典型，曝光严重失信案例，为社会公众、信用服务机构、金融机构、行业协会商会等查询和使用公共信用信息，了解社会信用体系建设情况提供便利。

牵头单位：县委宣传部、人行九寨沟县支行

责任部门：各成员单位

4.完善信用体系建设标准制度。按照《关于加强和规范守信联合激励和失信联合惩戒对象名单管理工作的指导意见》（发改财金规〔2017〕1798号）相关规定，加快完善信用体系建设相关认定标准的制度建设，健全诚信典型“红名单”和严重失信主体“黑名单”认定标准，动态维护红黑名单信息，并依法依规规范信用红黑名单发布行为；明确守信联合激励、失信联合惩戒对象认定标准，按照强化信用约束和协同监管要求，认真贯彻落实国家和省有关要求，制定信用评价、信用分类管理等制度措施，推进联合奖惩步入标准化、制度化和法制化轨道。

牵头单位：县发改局、人行九寨沟县支行

责任部门：各成员单位

（二）营造浓厚宣传氛围

积极开展“诚信九寨”倡树行动、挖掘诚信主体、讲好诚信故事，多渠道向社会宣传、推介、树立诚信典型；深入开展诚信主题宣传活动，扎实做好校园诚信文化教育工作，在全县营造浓厚诚信氛围。

1.多渠道选树诚信典型。开展诚信创建活动，各成员单位依据记录的信用信息，建立诚信典型常态化报送工作机制，依法依规将信用状况良好的行政相对人、信用乡（镇）、信用村、信用户、“诚信示范单位”、“守合同重信用”企业、“诚信经营示范点”、诚信道德模范、优秀青年志愿者、行业协会商会推荐的诚信会员、新闻媒体挖掘的诚信主体等树立为诚实守信典型，推荐主管部门、行业协会商会予以表彰；通过“九寨信用网”、“诚信九寨”微信公众号、电视、报刊等渠道进行宣传、报道，并在会展、银企对接等活动中重点推介诚信典型。

牵头单位：县委宣传部、人行九寨沟县支行

责任部门：各成员单位

2.大力弘扬诚实守信文化。以培育和践行社会主义核心价值观为根本，将诚信文化建设贯穿县域精神文明建设全过程。推动创作诚信文化与时代价值观相融合的文艺作品、公益广告，丰富宣传载体，增加宣传频次，提升宣传水平；组织各类网站开设诚信九寨专题，推出一批高质量的网络诚信主题文化作品，开展网络失信案例警示教育；打造信用建设示范基地（走廊），发挥先进典型的示范带动作用。

牵头单位：县委宣传部、人行九寨沟县支行

责任部门：各成员单位

3.全面深入开展诚信教育。深化“一人一校一队”校园诚信教育，在县域中小学建设“诚信教育示范基地”，将诚信教育作为思想品德教育的重要内容，开设相关课程，引导广大学生加强道德修养；开展公务员诚信、守法和道德教育，将诚信建设纳入公务员培训和领导干部进修课程；推动建立完善企业法定代表人及相关负责人和各类专业技术人群的职业道德教育；鼓励各类社会组织和企业开展入职信用知识培训。

牵头单位：县教育局、人行九寨沟县支行

责任部门：县委宣传部、县委组织部、县人社局、县团委

4.深入开展诚信主题活动。在各行业领域，以“诚信九寨”为总体品牌，持续组织开展“6·14”信用记录关爱日、质量月、安全生产月、诚信兴商宣传月、征信知识宣传周、“3·15”国际消费者权益日等特色诚信主题宣传、教育实践活动。

牵头单位：县委宣传部、人行九寨沟县支行

责任部门：县工质食药监局、县经信局、县旅发局（旅游执法局）、县环林局、县住建局、县交通局、县税务局、县司法局

（三）优化守信联合激励

按照国家和各行业主管部门联合奖惩备忘录等文件精神，通过探索实行行政审批便利、优先提供公共服务便利、降低市场交易成本等措施，进一步加大对我县灾后恢复重建、脱贫攻坚等领域诚信行为的褒扬和激励力度。

1.探索建立行政审批“绿色通道”。按照分类管理和便民服务的原则，探索在行政许可过程中，对县级及以上树立的灾后恢复重建、脱贫攻坚等领域诚信典型和五年无不良信用记录的行政相对人，可根据实际情况实施“绿色通道”和“容缺受理”等便利服务措施。对符合条件的行政相对人，除法律法规要求提供的材料外，部分申报材料不齐备的，如其书面承诺在规定期限内补充，可先行受理，加快办理进度。

牵头单位：县政务服务中心

责任单位：县工质食药监局、县经信局、县环林局、县住建局、县交通局、县税务局、县教育局、县人社局

2.探索优先提供公共服务便利。各部门要研究制定在公共服务中查询和使用企业信用记录的制度，在日常对企服务中关注企业信用状况。重点探索在灾后恢复重建、脱贫攻坚等领域的政府采购、招标投标、财政性资金使用中推进信用报告制度，拓展企业信用报告的应用领域，依法依规对信用评级较高的诚信市场主体采取信用加分等措施，限制信用评级低的企业市场准入，提升市场主体信用意识。

牵头单位：县发改局、县财政局

责任单位：县公共资源交易中心、县工质食药监局、县经信局、县旅发局（旅游执法局）、县环林局、县住建局、县交通局、县税务局、县教育局、县人社局

3.优化诚信企业行政监管安排。市场监管部门应根据监管对象的信用记录和信用评价分类，注重运用大数据手段，完善事中事后监管措施，为市场主体提供便利化服务。对县级及以上树立的灾后恢复重建、脱贫攻坚等领域诚信典型和五年无不良信用记录的企业、个人等符合一定条件的诚信主体，可在日常检查、专项检查中适当减少检查频次。

牵头单位：县发改局、县工质食药监局

责任单位：县经信局、县旅游执法局、县环林局、县住建局、县交通局、县税务局、县教育局、县人社局

4.切实降低市场交易成本。推动各部门信用信息在金融服务中的应用，对县级及以上树立的灾后恢复重建、脱贫攻坚等领域诚信典型和五年无不良信用记录的企业、个人等达到一定条件的诚信市场主体提供条件更优、成本更低的银行信贷、保险等金融产品；积极探索中小企业信用体系建设，依托“应收账款融资服务平台”和“小微企业融资服务平台”降低中小企业融资成本，在公共资源交易领域为中标中小微企业提供融资信息服务；进一步深化农村信用体系建设试点，引导涉农金融机构为评定的信用乡（镇）、信用村、信用农户和守信经营主体提供“信用—信贷”联动新产品；拓展银税合作新方式，为纳税信用级别高的纳税人提供更便利、多样的金融服务；县财政应积极探索在政策性金融产品补贴中，对评定的信用主体给予差别化支持的措施。

牵头单位：人行九寨沟县支行

责任单位：县金融办、县财政局、县税务局、县扶贫移民局、县域各金融机构

（四）完善失信联合惩戒

按照国家和各行业主管部门联合奖惩备忘录等文件精神，通过探索加大重点领域和严重失信行为联合惩戒力度、强化行政性约束和惩戒、加强市场性约束和惩戒等措施，进一步加大对失信行为的约束和惩戒力度。

1.加强行政性约束和惩戒。各部门依法依规将经认定、发布的严重失信主体列为重点监管对象，从严审核行政许可审批项目，从严控制各类许可证发放，限制发起设立或参股金融及准金融等机构；限制申请财政性资金项目，限制参与灾后恢复重建、脱贫攻坚等领域项目的公共资源交易活动，限制参与基础设施和公用事业特许经营；对经认定、发布的公职人员严重失信行为，纳入其晋职晋级、评先评优等考核、考察事项；对经认定、发布的严重失信企业及其法定代表人、主要负责人，以及对失信行为负有直接责任的注册执业人员等依法依规实施市场和行业禁入措施，并及时撤销其荣誉称号，取消其参加评先评优资格。

牵头单位：县发改局、县公共资源交易中心

责任单位：县委组织部、县财政局、人行九寨沟县支行、县金融办、县经信局、县旅发局（旅游执法局）、县环林局、县住建局、县交通局、县税务局、县教育局、县人社局、县扶贫移民局、县政务服务中心

2.加强市场性约束和惩戒。对依法依规确定的严重失信主体，各部门应及时通过“九寨信用网”、“诚信九寨”微信公众号、电视、报刊等渠道公开披露相关信息，防范信用风险；对有履行能力但拒不履行的严重失信行为人实施限制非生活和工作必需的消费行为措施；引导金融机构按照风险定价原则，对经认定、发布的严重失信主体审慎提供各类金融服务。

牵头单位：县法院、人行九寨沟县支行

责任单位：县委宣传部、县各金融机构

3.加强行业性约束和惩戒。各部门要加强对工商企业、旅游和电商等行业协会、商会的指导，推动行业信用建设，建立行业内部信用信息采集、共享、运用机制，将经认定、发布的严重失信行为记入会员信用档案；鼓励开展会员单位信用等级评价，支持行业协会商会按照行业标准、行规、行约等，视情节轻重对失信会员实行警告、行业内通报批评、公开谴责、不予接纳、劝退等惩戒措施。

牵头单位：县发改局、县工质食药监局

责任单位：县旅发局（旅游执法局）、县经信局、县工商联

（五）构建联合奖惩协同机制

通过建立联合奖惩触发反馈机制、完善信用修复机制、健全信用主体权益保护机制等措施，进一步完善信用救济体系，多渠道、多方式强化信用主体的诚信意识和自觉守信的主动性。

1.健全信用红黑名单制度。根据国家和行业主管部门有关规定，完善诚信典型“红名单”制度和严重失信主体“黑名单”制度，依法依规规范各领域红黑名单产生和发布行为，建立完善退出机制。在保证独立、公平、客观前提下，鼓励有关群众团体、金融机构、征信机构、评级机构、行业协会商会等将产生的“红名单”和“黑名单”信息，提供县域信用信息共享应用平台参考使用。

牵头单位：人行九寨沟县支行、县发改局

责任单位：各成员单位

2.建立联合奖惩发起响应机制。在县社会信用体系建设领导小组的领导下，建立、健全守信联合激励和失信联合惩戒的发起和响应机制。各成员单位作为联合奖惩的发起部门，负责确定（撤销）激励和奖惩主体，依法依规在县域信用信息共享应用平台中发布联合奖惩名单，并推送至联合奖惩配合单位；配合单位在行政管理、公共服务等职权范围内，对名单中的行政相对人依法依规实施奖惩，并定期将实施奖惩情况及时反馈发起部门。

牵头单位：人行九寨沟县支行、县发改局、县工质食药监局

责任单位：各成员单位

3.健全信用主体权益保护机制。建立、健全信用信息异议处理制度，按照“谁决定、谁负责”的原则，由发起部门及时审查。惩戒对象对失信行为联合惩戒认定有异议的，应当向联合惩戒发起部门提出书面异议申请，理由成立的应予纠正，理由不成立的按规定程序予以驳回。公民、法人或其他组织对驳回决定不服的，可向有权机关提起行政复议或行政诉讼。发起部门应同时在联合奖惩信用信息系统将处理结果推送至其他配合单位。异议处理阶段联合惩戒措施不停止执行。

牵头单位：人行九寨沟县支行、县发改局

责任单位：各成员单位

4.建立健全信用修复机制。建立失信主体自我纠错的信用修复机制，联合惩戒发起部门应依据相关法规、规章和规范性文件，明确各类失信行为的联合惩戒期限，到期后推送配合部门移出联合惩戒名单；在规定期限内纠正失信行为、消除不良影响的，可向发起部门提出信用修复申请并提供相关证据，发起部门收到申请后进行核查，认为其已经整改到位、符合管理要求的，不再作为联合惩戒对象，应推送配合部门及时移出联合惩戒名单。

牵头单位：人行九寨沟县支行、县发改局

责任单位：各成员单位

四、保障措施

（一）加强组织领导。建立健全“政府主导、人行九寨沟县支行和发改局双牵头、相关部门和金融机构共同参与”的工作机制，突出目标导向，强化资源整合、信息共享。在县委、县政府的统一领导下，成立“九寨沟县社会信用体系建设工作领导小组”，负责全面推进“8·8”九寨沟地震后县域社会信用体系建设，明确各成员单位职责任务；领导小组下设办公室，负责办理日常事务，加强成员单位间的议事协调。

（二）加强协调配合。各成员单位要将“8·8”九寨沟地震后社会信用体系建设与履行本部门职责结合，相互促进、相互提高；领导小组办公室要建立、完善成员单位定期联席会议和联络员制度，加强信息沟通、推动协调配合、形成工作合力；各项任务牵头单位要加强与责任单位的指导、协调，确保落实进度；县政府每年召开一次社会信用体系建设工作会议，总结经验、部署任务、推进工作。

（三）加强宣传引导。各部门应在领导小组办公室和牵头单位的组织下，充分利用广播电视、报刊、网络、公益广告和主题活动等渠道资源，加大对社会信用体系建设推进工作的宣传报道，并及时向领导小组办公室反馈相关情况，共同营造全社会关心、支持、参与社会信用体系建设工作的良好氛围。

（四）加强经费保障。县财政要根据“8·8”九寨沟地震后社会信用体系建设工作实际，对相关经费给予支持和保障，重点加强对信用基础设施建设、信用联合奖惩、信用产品应用、信用信息社会化应用、诚信建设创新示范、诚信宣传教育与信用人才培养等方面的资金支持力度。

（五）加强督查考核。领导小组办公室和县目督办，要健全社会信用体系建设工作督查和考核制度，将社会信用体系建设列入各成员单位年度工作重点，进行监督考核；县政府将依据考核结果，对工作成效明显的部门、个人给予表彰奖励，对因工作不力造成不良影响的单位、个人，给予通报批评或惩戒，确保社会信用体系建设取得应有成效。
