# 关于继续执行《九寨沟县2017年脱贫攻坚保险项目实施方案》的通知

各乡（镇）人民政府，县级有关部门：

为切实增强农业、农村、农民抵御自然灾害和应对重特大意外事故的能力，充分发挥金融助推脱贫攻坚、乡村振兴作用，经县人民政府研究，原则同意继续执行《九寨沟县2017年脱贫攻坚保险项目实施方案》，有效期限至2020年12月31日。农业保险保费补贴按照《四川省财政厅关于印发〈四川省农业保险保费补贴管理办法〉的通知》（川财金〔2017〕12号）执行。如遇中央、省、州相关政策调整，按调整后政策执行。

特此通知。

九寨沟县人民政府办公室

2019年3月1日
