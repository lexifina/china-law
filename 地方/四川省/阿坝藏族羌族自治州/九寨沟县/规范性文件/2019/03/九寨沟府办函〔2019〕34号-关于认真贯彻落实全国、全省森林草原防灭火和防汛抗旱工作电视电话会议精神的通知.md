# 关于认真贯彻落实全国、全省森林草原防灭火和防汛抗旱工作电视电话会议精神的通知

县安全生产委员会办公室，县级相关部门：

2019年3月28日，应急管理部副部长黄明主持召开“全国森林草原防灭火和防汛抗旱工作电视电话会议”。国务委员、国家森林草原防灭火指挥部总指挥、国家防汛抗旱总指挥部总指挥王勇出席会议并讲话。国务院副秘书长孟扬传达学习了中共中央政治局常委、国务院总理李克强重要批示精神。应急管理部副部长黄明通报去年以来工作情况并提出下步工作建议。水利部、国家林业和草原局、中国气象局、内蒙古自治区、黑龙江省、安徽省、广东省分别作了发言。会后，四川省召开全省部署动员会议，省政府副省长尧斯丹就下一步工作提出要求：

李克强总理批示指出，做好森林草原防灭火和防汛抗旱工作，事关安全，事关大局。要坚持以习近平新时代中国特色社会主义思想为指导，认真贯彻党中央、国务院决策部署，坚持底线思维，主动担当作为，切实加大防范化解风险力度，着力消除重大隐患。要坚持以防为主、防灭结合，严格落实森林草原防灭火各环节责任，全面提升火灾综合防控和救援能力，坚决防范重特大火灾事故发生。要立足防大汛、抗大旱，扎实做好防范应对准备，加快补齐水利基础设施短板，保障防洪和供水安全。要加强组织协调，完善法规制度和预案，健全监测预警、应急指挥和快速救援等工作机制，注重联防联控，不断提高防灾抗灾减灾能力，有力维护人民群众生命和财产安全。

国务委员王勇要求，一是肯定成绩，认清形势，切实增强防灭火和防汛抗旱的使命感责任感。二是突出重点，强化措施，全力以赴，做好今年防灭火和防汛抗旱工作。三是压实责任，推动工作落实落地。

尧斯丹副省长要求，一是务必坚持问题导向，坚持底线思维。二是务必落实防火措施，严防重大火灾发生。三是抓好防汛抗旱，守住灾害防御的底线。四是务必抓好地灾防范，切实减轻灾害损失。五是务必压紧压实责任，确保工作落地落实。

经县政府研究，决定由县安全生产委员会办公室牵头把学习贯彻落实全国、全省森林草原防灭火和防汛抗旱工作电视电话会议精神作为当前和今后一个时期的重要任务。请县安全生产委员会办公室及时将贯彻落实情况报告县政府。

特此通知。

九寨沟县人民政府办公室
