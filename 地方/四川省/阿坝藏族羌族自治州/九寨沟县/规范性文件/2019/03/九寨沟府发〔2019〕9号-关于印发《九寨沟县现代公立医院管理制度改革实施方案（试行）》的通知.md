# 关于印发《九寨沟县现代公立医院管理制度改革实施方案（试行）》的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县现代公立医院管理制度改革实施方案（试行）》已经县人民政府研究同意，现印发给你们，请认真贯彻执行。

九寨沟县人民政府

2019年3月26日

九寨沟县现代公立医院管理制度改革

实施方案（试行）

为全面推进我县公立医院综合改革，加快建立现代公立医院管理制度，努力实现全县公立医院治理体系现代化，提升管理和服务效能，逐步满足群众看病就医需求，根据《四川省人民政府办公厅关于建立健全现代医院管理制度的实施意见》（川办发〔2018〕39号）和阿坝州人民政府办公室关于印发《建立健全现代医院管理制度实施意见》（阿府办办发〔2018〕28号）文件精神，结合我县实际，特制定本实施方案。

一、指导思想

认真贯彻落实习近平新时代中国特色社会主义思想和党的十九大精神，坚持以“人民为中心”发展思想，全面践行“健康中国”战略，牢固树立“大健康大卫生大服务大共享”改革理念，按照国家和省州决策部署，以维护和增进群众健康为出发点和落脚点，逐步优化公立医院治理体系、增强管理能力、提升医疗服务效能、提高医疗服务质量，推动公立医院社会效益与运行效率有机统一，探索具有九寨特色的医院治理体系和现代化管理能力。

二、主要目标

到2020年底，基本形成维护公益性、调动积极性、保障可持续性的现代公立医院运行新机制和管理制度。通过现代医院管理制度建设，推动公立医院管理法治化、规范化、精细化、科学化，全面提升医疗服务能力，提高人民群众满意度、幸福感和获得感，为建成“两地一典范、美丽新九寨”提供坚实有力的医疗健康服务保障。

三、实施措施

（一）明确政府举办职能，进一步健全管理制度

1.明确医院的公立性质。政府行使公立医院举办权、发展权、重大事项决策权、资产收益权等，审议公立医院章程、发展规划、重大项目实施、收支预算等。强化医疗卫生服务体系规划和医疗机构设置规划执行。(牵头部门：县卫计局，责任部门：县委组织部、县委编办、县人社局负责)

2、制定落实医院章程。结合公立医院等级、规模等实际情况,科学制定医院章程，明确医院性质、办医宗旨、功能定位、办医方向、管理体制、经费来源、组织结构、决策机制、管理制度、监督机制、文化建设、党的建设、群团建设等内容。制定公立医院章程时，要明确党支部在医院内部治理结构中的地位和作用。(牵头部门：县卫计局，责任部门：县委组织部、县委编办、县人社局负责)

3、试行院长竞聘制。逐步取消公立医院行政级别，卫生健康行政部门负责人一律不得兼任公立医院领导职务，探索试行院长竞聘年薪制度。定期组织公立医院综合绩效考核以及院长年度和任期目标责任考核，考核结果与院长薪酬、任免、奖惩等挂钩。（牵头部门：县卫计局，责任单位：县发改局、县财政局、县人社局、县委编办负责）

4、强化管理自主权。深化医疗领域“放管服”改革，探索实行公立医院所有权与经营权分离。公立医院要依法依规进行经营管理和提供医疗服务，行使内部人事管理、机构设置、中层干部聘任、人员招聘和人才引进、内部绩效考核与薪酬分配、年度预算执行等经营管理自主权。（牵头部门：县卫计局，责任部门：县委编办、县财政局、县人社局）

5、健全医院决策机制。坚持民主集中制，实行集体领导、个人分工和层级管理相结合的管理机制。在决策程序上，公立医院发展规划、“三重一大”等重大事项，以及涉及医务人员切身利益的重要问题，要经医院党支部会议研究决定，保证党组织意图在决策中得到充分体现。充分发挥专家作用，组建医疗质量安全管理、药事管理等专业委员会，对专业性、技术性强的决策事项提供技术咨询和可行性论证。（牵头部门：县卫计局）

6、健全民主管理制度。健全以职工代表大会为基本形式的民主管理制度。工会依法组织职工参与医院的民主决策、民主管理和民主监督。医院研究经营管理和发展的重大问题应当充分听取职工意见，召开讨论涉及职工切身利益的会议，必须有工会代表参加。推进院务公开，落实职工群众知情权、参与权、表达权、监督权。（牵头部门：县卫计局）

（二）实行员额备案管理，进一步健全人事制度

7、健全人力资源管理制度。公立医院实行人员总量管理，人员总量由事业编制和员额构成，员额实行备案管理。建立人员动态调整机制,将员额纳入县级公立医院岗位设置总量,合理调控，探索试行取消职称比例,在岗位聘用、收入分配、职称评定、管理使用等方面,对编制内外人员统筹考虑。（牵头单位:县委编办，责任单位:县委组织部、县人社局、县财政局、县卫计局）

8、健全绩效考核制度。围绕岗位职责、工作质量、工作项目，建立符合行业特点、体现医务人员技术劳务价值的绩效制度。对不同岗位、不同职级医务人员实行分类考核，突出岗位职责履行、工作量、服务质量、行为规范、医疗质量安全、医疗费用控制、医德医风和患者满意度等重点指标。继续巩固破除以药养医成果，严禁给医务人员设定创收指标。将考核结果与医务人员岗位聘用、职称晋升、个人薪酬挂钩。（牵头部门：县卫计局，责任部门：县人社局、县财政局）

9、健全培养培训制度。落实住院医师规范化培训、专科医师规范化培训和继续医学教育制度，做好订单定向等医学生培养工作。加强县级公立医院临床重点专科、学科建设，提升医院核心竞争力。县级公立医院积极为基层、县域内医共体下级单位培养人才。（牵头部门：县卫计局，责任部门：县委编办、县人社局、县教育局负责）

（三）加强财务资产管理，进一步健全薪酬制度

10.健全财务资产管理制度。公立医院财务收支、预算决算、会计核算、成本管理、价格管理、资产管理等必须纳入医院财务部门统一管理。建立健全全面预算管理、成本管理、财务报告、第三方审计和信息公开机制，确保经济活动合法合规，提高资金资产使用效益。结合医保支付方式改革，初步形成按项目、按病种、按疾病诊断分类实行定额标准。切实加强国有资产配置、使用、处置事项管理，维护国有资产安全完整，提高资产使用效率。（牵头部门：县卫计局，责任部门：县人社局、县财政局）

11、健全薪酬分配制度。根据医疗卫生行业特点,按照“两个允许”要求,优化薪酬结构、合理确定薪酬水平、实行总量控制自主分配,做到多劳多得、优劳优酬,重点向临床和公共卫生一线、业务骨干、关键岗位和有突出贡献的人员倾料。（牵头单位:县人社局，责任单位:县委组织部、县财政局、县委编办、县卫计局）

（四）加强行业自律自省，进一步健全监管机制

12、完善医院综合监管体系。

各相关部门强化政策法规、发展规划、标准规范的监督指导。进一步建全综合监管制度，加强对公立医院医疗质量安全、医疗费用以及大处方、欺诈骗保、药品回扣等行为的监管。加强药械配送管理和采购全过程的监管。建立医保医师制度，健全不良执业行为记分管理和退出“黑名单”制度。对造成重大社会影响的乱收费、不良执业行为，造成重大安全事故的行为，严重违法违纪案件，要严格追究责任。（牵头单位：县卫计局，责任单位：县人社局、发改局、物价局、审计局、工质食药监局）

13、加强行业自律和社会监督。完善和落实医院信息公开制度，拓展公众参与监管的渠道。以质量安全、医疗价格、服务费用、财务状况、绩效考核等为重点，加强医院信息主动公开，县人民医院、县中藏医院相关信息每年向社会公布不少于1次。进一步加强行业自律，引导医院依法经营、公平有序竞争。改革完善医疗质量、技术、安全和服务评估认证制度。探索建立第三方评价机制。（牵头部门：县卫计局）

（五）加强医院党的建设，进一步健全保障机制

14、充分发挥党支部的领导核心作用。公立医院党支部要抓好对医院干部职工的政治、思想和组织领导，自觉在思想上政治上行动上同以习近平同志为核心的党中央保持高度一致，全面贯彻党的理论路线方针政策，把方向、管大局、促落实。坚持把党组织活动与业务工作有机融合，积极推进活动创新、思想政治工作内容和载体创新。严格发展党员和党员教育管理工作，充分发挥党支部的凝聚作用和党员先锋模范带头作用。（牵头部门：县卫计局，责任部门：县委组织部）

15、加强医院先进文化建设。树立正确的办院理念，弘扬“敬佑生命、救死扶伤、甘于奉献、大爱无疆”的职业精神。恪守服务宗旨，增强服务意识，提高服务质量，全心全意为人民健康服务。推进医院精神文明建设，开展社会主义核心价值观教育，促进形成良好医德医风。关心爱护医务人员身心健康，尊重医务人员劳动成果和辛勤付出，增强医务人员职业荣誉感。建设医术精湛、医德高尚、医风严谨的医务人员队伍，塑造行业清风正气。（牵头部门：县卫计局，责任部门：县委宣传部）

16、健全医疗质量安全管理制度。建立全员参与、覆盖临床诊疗服务全过程的医疗质量管理与控制工作制度，严格落实首诊负责、三级查房、分级护理、手术分级管理、抗菌药物分级管理、临床用血安全等医疗质量安全核心制度。加强重点科室、重点区域、重点环节、重点技术的质量安全管理，推进合理检查、用药和治疗。建立不良事件预警机制，推进医疗质量（安全）不良事件信息报告制度。建立健全警医联动、警院协同机制，依法处置涉医违法犯罪活动。推动院内调解、人民调解、司法调解、医疗风险分担机制有机结合的“三调解一保险”机制建设，依法妥善化解医疗纠纷，构建和谐医患关系。（牵头部门：县卫计局、责任部门：县法院、县公安局、县司法局、县信访局）

17、健全基本建设和后勤管理制度。强化医院发展建设规划编制和项目前期论证，落实基本建设项目法人责任制、招标投标制、合同管理制、工程监理制、质量责任终身制等。合理配置适宜医学装备，建立采购、使用、维护、保养、处置全生命周期管理制度。积极探索医院“后勤一站式”服务模式，推进医院后勤服务社会化。（牵头部门：县卫计局，责任单位：县发改局、县住建局）

18、健全信息管理应用制度。公立医院开展就医引导、检查检验结果互认、异地就医结算、护工、志愿者等便民措施，进一步优化就医流程，改善医疗服务。探索公立医院信息系统标准化和规范化建设，与医保、预算管理、药品电子监管等系统有效对接，加快开展“互联网 医疗”服务，逐步实现九寨智慧医疗。（牵头部门：县卫计局，责任部门：县人社局）

19、健全重点专科建设制度。建立健全专业技术人才引进及留用激励机制，促进人才队伍建设。建立健全对外合作发展机制，逐渐从对口帮扶转为合作共赢发展。健全重点科室建设提升机制，坚持“一年一科室”“一年一重点”，逐项逐科提升打造。

逐渐实现县人民医院创建“三级乙等”综合医院，建成区域医疗卫生中心，打造川甘青结合部医疗高地；县中藏医院建成治未病分中心，探索建设九寨特色健康养生服务中心；县第二人民医院打造成国际旅游医疗应急保障中心、建设高原病过渡康养中心。（牵头部门：县卫计局，责任部门：县委组织部、县人社局、县委编办、县财政局分别负责）

三、进度安排

（一）启动实施（2019年1月-3月）

制定《九寨沟县现代公立医院管理制度改革实施方案》，明确目标任务、责任主体和工作要求。

（二）组织实施（2019年4月-2020年10月）

县医改领导小组各成员单位根据《九寨沟县现代公立医院管理制度改革实施方案》制定具体实施细则和政策措施，明确工作任务、时间节点和工作要求，及时发现工作推进中存在的问题和困难，及时查找原因，积极整改，高质量推进相关工作落地、落实。

（三）总结完善（2020年11月-12月）

对县级公立医院现代管理制度工作进行总结归纳，巩固改革成果，完善改革措施，建立健全长效机制，形成可借鉴、可复制、可推广的九寨沟现代公立医院管理制度改革经验。

五、工作要求

（一）加强组织领导。县医改领导小组成员单位要高度重视。在县委、县政府统一领导下，着力加强“三医”联动、区域联动、部门协调和政策统筹。县委编办、发改、人社、卫计、财政、医保等相关部门落实1名分管领导具体负责，根据各自单位职责统筹推进制度建设、实施等工作。

（二）强化督促指导。县医改领导小组定期对各单位开展工作情况进行督导，每季度召开1次联席会，及时分析研判和解决现代医院管理制度建设推进过程中遇到的新情况、新问题。认真总结特色做法和成熟经验，不断巩固扩大工作成效。

（三）强化宣传引导和信息报送。各成员单位加强密切沟通联系，做好正面宣传和舆论引导，落实专人负责工作进展等信息报送。
