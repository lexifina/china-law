# 关于切实做好2019年耕地保护工作的通知

各乡（镇）人民政府，县级有关部门：

党的十九大以来，以习近平同志为核心的党中央高度重视耕地保护工作。习近平总书记提出，耕地是粮食生产的命根子，要牢牢抓住耕地保护红线，强化地方人民政府主体责任。根据《中共中央 国务院关于加强耕地保护和改进占补平衡的意见》（中发〔2017〕4号）、《国务院办公厅关于印发〈省级政府耕地保护责任目标考核办法〉的通知》（国办发〔2018〕2号）、《四川省人民政府关于贯彻落实粮食安全省长责任制的意见》（川府发〔2015〕34号）、《阿坝州国土资源局关于转发〈四川省国土资源厅关于严格落实耕地保护责任严防死守耕地红线的通知〉的通知》（阿州国土资发〔2014〕62号）精神，现就做好2019年耕地保护工作有关事宜通知如下。

一、严防死守耕地红线，切实保护基本农田

（一）认真落实耕地保护目标责任。各乡（镇）人民政府要进一步提高认识、统一思想、加强领导、落实责任，认真贯彻落实“十分珍惜、合理利用土地，切实保护耕地”的基本国策，严格执行土地管理法律法规，正确处理“保护耕地、保障发展”的关系，确保全县耕地和基本农田数量不减少、质量有提高，着力加强耕地数量、质量、生态“三位一体”保护；对本行政区域耕地保有量、基本农田保护面积、建设占用耕地占补平衡负总责，政府主要负责人为第一责任人，分管负责人为直接责任人。严格执行耕地保护目标责任制，层层分解落实耕地保有量和基本农田保护任务。落实最严格的耕地保护制度，确保现有耕地面积基本稳定。加强耕地质量建设，采取综合措施提高耕地基础地力，提升产出能力。规范耕地占补平衡，严格实行耕地“占一补一”“先补后占”和“占优补优”。对占用耕地特别是基本农田的，有条件的地区要开展剥离耕作层土壤再利用试点，开展补充耕地质量评定和土壤改良培肥。严格执行政府领导干部耕地和基本农田保护离任审计制度。

（二）切实加强基本农田保护。按照新一轮土地利用总体规划确定的基本农田面积和中央、省、州要求，已完成永久基本农田划定工作，建好永久基本农田数据库，数据库成果经省国土资源厅验收合格。严格落实保护责任，完善保护标识，强化有效监测，实行永久保护，永久基本农田一经划定，任何单位和个人不得擅自占用或改变用途。

（三）严禁未经批准占用耕地，特别是将基本农田用于非农建设，严禁“以租代征”非法使用农民集体所有土地用于非农建设。从严控制非农建设占用耕地，加大耕地保护执法监察力度，努力构建耕地保护长效机制，不断巩固耕地保护成果。

二、加快推进灾后恢复重建土地整理项目，提高耕地质量等级

（一）切实抓好2019年度九寨沟县双河镇草坪村、各条村、松柏村、黄阳村、中和村、团结村、张家梁村，保华乡土门村、灵华村、灵保村灾后恢复重建土地整理项目的实施工作。

（二）切实做好占补平衡项目工作。按照《中共中央 国务院关于加强耕地保护和改进占补平衡的意见》（中发〔2017〕4号）精神，高度重视、加强领导、落实人员，在新立项土地整理项目上提前谋划、科学编制项目实施计划和新增耕地结构，保证新增耕地质量，坚决防止耕地占补平衡中补充耕地数量不到位、质量不到位等问题，坚决防止占多补少、占优补劣、占水田补旱地等现象。

三、严防集体土地流转“非农化”

坚决贯彻落实习近平总书记重要指示精神和李克强总理等中央领导同志批示要求，按照省委省政府、州委州政府安排部署和州委常委、县委书记罗智波在县委2019年度综合工作会议上的讲话精神，紧紧围绕“全域发展、绿色崛起”总体战略、“四个全域、四个九寨”战略规划，充分认识到保护耕地红线的重要性、必要性和紧迫性，在全县生产建设中坚决遏制农地非农化乱象，对法律法规明令禁止、与农业生产无关的违规违法行为坚决依法依规严厉打击。

不得借农地流转之名违规搞非农业建设，严禁在流转土地上建设旅游度假村、高尔夫球场、别墅、农家乐、私人会所等。引导农业结构调整不改变耕地用途，严禁占用基本农田挖塘造湖、种植林果、建绿色通道及其他毁坏基本农田种植条件的行为。设施农业项目要严格执行《阿坝州国土资源局 阿坝州农业畜牧局关于转发〈国土资源部 农业部关于进一步支持设施农业健康发展的通知〉的通知》（阿州国土资发〔2015〕22号）相关规定，尽可能利用农村存量建设用地和非耕地，不得占用基本农田。

严格落实属地管理原则，各乡（镇）人民政府要按照守土有责、守土负责、守土尽责的要求，把耕地保护工作落到实处，坚决遏制农地非农化乱象，对不作为、慢作为、失职渎职的进行严肃问责追责。

四、强化耕地保护执法监察

以当前“大棚房”清理整治专项行动及挤占生态空间问题清理整治为契机，各乡（镇）人民政府要加强对违反规划计划扩大建设用地规模、农村土地流转和农业结构调整中损坏基本农田等违法违规行为的执法检查。加大动态巡查力度，认真落实违法行为报告制度，坚持重大典型违法违规案件挂牌督办制度，对占用耕地重大典型案件及时进行公开查处、公开曝光。

五、强化用地预审关

强化建设项目用地预审，严格项目选址把关。凡不符合土地利用总体规划、耕地占补平衡要求、征地补偿安置政策、用地标准、产业和供地政策的项目，一律不得通过用地预审。要进一步深化耕地占补平衡审查，确保落实占一补一、占优补优。在预审环节，预先安排补充耕地，实现质量等级不降低，不符合要求的，不得通过预审。

六、落实耕地保护目标考核

为进一步加强全县耕地保护工作，切实落实耕地保护责任制，制定九寨沟县2019年耕地保护目标责任考核办法，并于年底对各乡（镇）开展耕地保护目标责任考核。耕地保护目标责任考核结果列为乡（镇）人民政府第一责任人工作业绩考核的重要内容。对考核确定为不合格的乡（镇），由县纪委、县监委、县自然资源局对其建设用地情况进行全面检查，发现涉嫌违法违纪的，依法依规查处相关责任人；涉嫌犯罪的，依法追究刑事责任。
