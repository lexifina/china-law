# 关于印发《九寨沟县救助野生大熊猫放归工作实施方案》的通知

勿角乡人民政府，县级相关部门：

《九寨沟县救助野生大熊猫放归工作实施方案》已经县人民政府研究同意，现印发你们，请认真贯彻执行。

特此通知。

九寨沟县人民政府办公室

2019年5月31日

九寨沟县救助野生大熊猫放归

工作实施方案

2019年4月5日，九寨沟郭元乡金字村发现一只病饿野生大熊猫，九寨沟县赓即组织相关部门对其进行全力救护，并于4月7日将该大熊猫送往成都大熊猫繁育研究基地救助治疗。目前，该大熊猫已恢复健康。经大熊猫专家对该大熊猫恢复情况及身体健康状况的检查评估，该大熊猫已具备野外放归条件。经省林业和草原局研究，同意将该大熊猫在原栖息地（九寨沟县）进行放归，为确保大熊猫顺利安全放归，特制订本工作方案。

一、放归时间：2019年6月12日

二、放归地点：四川勿角自然保护区白马沟

三、组织机构
