# 关于印发《九寨沟县2019年卫生健康重点工作抓落实方案》的通知

各乡（镇）人民政府、县级有关部门，各医疗卫生机构：

经县委、县政府领导同意，现将《九寨沟县2019年卫生健康重点工作抓落实方案》印发你们，请认真组织实施。

九寨沟县人民政府办公室

2019年5月24日

九寨沟县2019年卫生健康

重点工作抓落实方案

为认真贯彻九寨沟县委四届六次全会精神、县第十四届人民代表大会第三次会议和县十四届人民政府第一次会议精神，落实县委、县政府对2019年卫生健康工作的相关要求，推动卫生健康工作全面发展，现提出如下卫生健康重点工作抓落实方案。

一、抓好重点工作

1.编制全县卫生健康行业三年发展规划。县卫健局牵头，6月底前，开展广泛调研，结合省、州工作要求和县情实际，发动医疗卫生机构干部职工共同编订全县卫生健康行业三年发展规划，报审后印发。

2.制定2019年工作计划。县卫健局牵头，5月底前，印发2019年全县卫生健康工作要点和项目实施计划。

3.有序实施灾后恢复重建项目。县卫健局牵头，按县统一要求时间进度，完成工程项目竣工验收、审计，完成设备采购、安装调试、验收，完成资金支付和项目财务决算。

4.召开全县卫生健康大会。县委办公室、县卫健局、县医保局牵头，7月底前，组织召开全县卫生健康和医疗保障工作大会。

5.召开县卫生健康合作座谈会。县卫健局牵头，有序推进对外交流合作工作，推动省三甲医院与县签订战略合作协议，6月底前，在成都市组织召开全县卫生健康合作座谈会。

6.推进全县医疗卫生事业单位人事制度改革。县卫健局、县人社局牵头，6月中旬前，拟定《全县医疗卫生事业单位人事制度改革方案》《全员竞聘工作方案》后按程序报审、实施。

7.大力开展人才引进工作。县人社局、县卫健局牵头，6月中旬前，拟定《人才引进工作方案》后按程序报审，并适时开展柔性引才和公开招聘工作。

8.启动实施九寨名医评选工作。县卫健局、县人社局牵头，5月底前，拟定《九寨名医评选工作方案》后按程序报审，完成九寨名医评选工作。

9.推进区域中心卫生院建设工作。县卫健局牵头，6月中旬前，拟定《区域中心卫生院建设工作方案》后按程序报审。

10.大力开展远程诊疗服务工作。县卫健局牵头，8月底前，县本级公立医院建立起与华西医院、四川省妇幼保健院、成都大学附属医院等医院的远程医疗会诊系统，开展远程医疗会诊服务。

11.开展重大传染病防治、检测工作。县卫健局牵头，全年对高危场所人群所进行综合干预、监测；动态开展包虫病调查，实施犬只药物驱虫治疗和犬粪检测，做好重大传染病病人的治疗、随访工作。

12.重点整治全县医疗卫生机构突出问题。县卫健局牵头，5月中旬前，拟定《以项目方式深入推进卫生健康系统突出问题重点整治的实施方案》后按程序报审，并从6月起开展为期半年的专项整治行动。

13.积极对上、对外争取政策、资金和项目。县发改局、县卫健局牵头，全年主动对接省、州相关部门，积极争取倾斜政策、资金和项目。

二、加强组织领导

1.分管县领导强化督促指导，开展专题研究和调研协调。建立联席会议制度，每月召开一次工作例会，听取卫生健康领域重点工作推进情况，对工作推进中存在的问题进行专题研究和调研协调。

2.牵头部门和牵头领导认真落实重点工作抓落实方案，加强调查研究和沟通协调，梳理任务清单，谋划具体措施，推进工作落实。

3.各相关部门积极担当作为，坚持“清单制 责任制”，抓实抓细，努力推动各项工作开展。

4.县委督查室加大督查力度，对落实不力的进行通报批评，并督促限期整改。
