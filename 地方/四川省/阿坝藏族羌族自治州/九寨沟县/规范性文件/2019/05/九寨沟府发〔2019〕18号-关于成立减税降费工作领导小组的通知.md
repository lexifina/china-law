# 关于成立减税降费工作领导小组的通知

各乡（镇）人民政府，县级各部门：

为深入贯彻党中央、国务院关于实施更大规模减税降费的重大决策部署，确保各项减税降费政策措施不折不扣落实到位，促进我县经济高质量发展，经县人民政府研究，决定成立减税降费工作领导小组（以下简称“领导小组”），其成员如下：

组  长：张  威  县委常委、副县长

副组长：彭旭东  县纪委副书记、监察委副主任

任  军  县委宣传部常务副部长

吴雪峰  国家税务总局九寨沟县税务局局长

成  员：吴玉平  县经济和信息化局局长

王玉梅  县财政局局长

龙凤莲  县人力资源和社会保障局局长

杜  宇  县住房和城乡建设局局长

李贵先  县审计局局长

董慧英  县医疗保障局副局长（主持工作）

肖  勇  县国有资产管理中心副主任（主持工作）

陈晓川  中国人民银行九寨沟县支行行长

领导小组的主要任务是贯彻落实党中央、国务院关于减税降费工作各项决策部署，按照国家税务总局、省局、州局安排，负责九寨沟县税务系统实施减税降费工作统筹协调、整体推进；负责制定减税降费政策实施方案、工作制度。领导小组办公室设在县税务局税政股，由吴雪峰同志兼任办公室主任，负责日常工作。

九寨沟县人民政府
