# 关于转发《九寨沟县2019年度审计项目计划》的通知

各乡（镇）人民政府，县级有关部门:

《九寨沟县2019年度审计项目计划》已经2019年县委审计委员会第一次会议、县十四届人民政府第52次常务会审议通过，现印发给你们，请认真组织实施。各部门和单位要自觉接受审计监督，积极配合审计部门开展工作。

九寨沟县人民政府办公室

2019年6月5日

（抄送：县委办，县人大办，县政协办，县纪委，县委组织部）

九寨沟县2019年度审计项目计划

一、总体思路

以习近平新时代中国特色社会主义思想为指导，深入学习贯彻习近平总书记关于“要高质量推进九寨沟地震灾后恢复重建和发展提升，努力建成民族地区绿色发展脱贫奔康典范，让灾区群众早日过上幸福安康生活”的重要指示精神，全面落实中央、省审计委员会第一次会议和各级审计工作会议精神，紧紧围绕“六个稳”要求和县委四届五次、六次全会决策部署，按照县委“全域发展、绿色崛起”总体战略和“四个全域·四个九寨”战略规划，找准审计监督与九寨经济社会发展和生态环境保护建设结合点，聚集打好“三大攻坚战”，推动优化营商环境、激发微观主体活力，推动做好稳增长、促改革、调结构、惠民生、防风险各项工作，更好发挥审计促进经济高质量绿色发展、促进全面深化改革、促进权力规范运行、促进反腐倡廉的职能作用，为加快构建“一主两核三带”绿色发展新布局，贡献审计力量。

二、重点任务

紧紧围绕县委、县政府和县委审计委员会的决策部署，加强审计工作统筹，充分发挥审计机关整体效能，科学组织实施好各项审计，依法全面履行审计监督职责，重点抓好以下几个方面：

（一）促进经济高质量绿色发展。围绕县委“全域发展、绿色崛起”总体战略和“四个全域·四个九寨”战略规划，聚焦“两地一典范，美丽新九寨”发展目标，持续打好“三大攻坚战”，加强脱贫攻坚、污染防治、政府性债务、地方金融风险等相关事项审计。

（二）促进全面深化改革。围绕财税、金融等重点领域改革推进，加强对行政审批制度改革、减轻企业负担、支持民营经济健康发展等政策措施落实情况的审计；聚焦人大监督重点拓展，推动全面实施预算绩效管理，加强对积极财政政策落实、税收和非税收入征管等情况审计，深入分析问题背后的体制机制障碍，提出有效的对策建议。

（三）促进权力规范运行。坚持党政同责、同责同审，深化领导干部经济责任审计和自然资源资产离任审计。围绕凝聚高质量绿色发展合力，聚焦权力运行和责任落实，关注重大改革事项推进、重大经济决策落实、领导干部遵守党风廉政建设有关规定情况等，促进领导干部守法守纪守规尽责，廉洁用权、干净干事。

（四）促进反腐倡廉。加大对中央八项规定精神等执行情况的审计监督力度，推动持续正风肃纪。加强对公共资金分配、公共资源交易等重点领域的审计监督，坚决查处徇私舞弊、中饱私囊、失职渎职等重大违纪违法行为，聚焦群众身边的“微腐败”，严肃查处脱贫攻坚、社会保障等领域的严重违纪违法行为，推动全面从严管党治吏。

三、审计项目

（一）重大政策措施落实情况跟踪审计（署定）。

【审计目标和重点】围绕“四个年”建设目标，聚焦“绿色发展、乡村振兴、民族团结、从严治党”四个主攻方向和加快构建“一主两核三带”绿色发展新布局，以推动重大政策措施贯彻落实、促进经济高质量绿色发展为目标，牢牢抓住“八条路径”，重点关注深化供给侧结构性改革、优化营商环境、防范化解重大风险隐患、脱贫攻坚、污染防治、区域协调发展、保障改善民生等方面的重大政策措施落实情况，持续反映打好“三大攻坚战”相关政策措施落实情况，持续反映减税降费、清理拖欠民营企业中小企业账款、惠农补贴“一卡通”管理使用等情况，着力反映影响国家经济安全的重大问题和风险隐患，严肃揭示弄虚作假、隐瞒实情以及不作为、慢作为、假作为等懒政怠政庸政问题。各季度阶段性跟踪主要内容：

一季度：结合扶贫审计，跟踪审计精准扶贫精准脱贫等重大政策措施落实情况。

二季度：结合预算执行、扶贫审计、民生项目等专项审计（调查），跟踪审计深化供给侧结构性改革、积极财政政策、乡村振兴战略、防范化解金融风险、社会领域公共服务补短板等政策措施落实情况。

三季度：结合扶贫审计、领导经济责任审计等，跟踪审计“放管服”改革推进、清理拖欠民营企业中小企业账款、脱贫攻坚等政策措施落实情况。

四季度：结合部门主要领导经济责任审计、乡镇领导干部自然资源资产任中（离任）审计等，跟踪审计地方财政安全运行及隐性债务风险、脱贫攻坚、污染防治、区域协调发展等政策措施落实情况。

年中，在完成上述各季度内容的基础上，县审计局将根据县委、县政府重大决策部署，确定跟踪审计重点内容，另行安排和调整审计计划，推动本县重大政策措施贯彻落实。

【组织实施方式及执行单位】县局政策跟踪审计股具体实施。

【审计时间】以季度综合报告需求为导向，严格按照《四川省审计厅2019年重大政策措施落实情况跟踪审计实施意见》及州局政策跟踪审计办所安排的内容和时间节点开展审计。在每个季度末月的10日前，各业务股在所负责项目审计现场结束时提交专题材料。县局政策跟踪审计股汇总情况，并向州局政策跟踪审计办报送跟踪审计综合报告、问题清单和整改台帐，同时抄送县人民政府。

1.减税降费重大政策措施落实情况跟踪审计。

【审计目标和重点】围绕县委、县政府关于减税降费工作部署，关注县级各部门在推进减税降费过程中职责履行情况，已出台政策措施的落地情况以及执行过程中出现的新情况新问题。减轻企业税收负担方面，关注深化增值税改革、支持小微企业发展税收优惠政策、鼓励研发创新等政策落实和效果；清理规范涉企收费方面，持续关注涉企收费目录清单执行、规范行政审批中介服务收费、依托行政权力及影响力收费等情况。

【组织实施方式及执行单位】结合税收和非税收入征管审计等相关审计项目实施，县局政策跟踪审计股负责实施。

【审计时间】全年全过程跟踪审计，负责项目审计现场的业务股分季度向县局政策跟踪审计股提交审计结果。

2.清理拖欠民营企业中小企业账款跟踪审计。

【审计目标和重点】聚焦民营经济健康发展支持政策落地生效，持续关注政府部门和县属国有企业欠款台账建立、欠款“限时清零”等情况，揭示政府部门和县属国有企业利用优势地位拖欠民营企业款项的行为，督促尽快制订清欠计划，严防新增欠款，支持民营企业健康发展。

【组织实施方式及执行单位】结合部门预算执行等相关审计项目实施，县局政策跟踪审计股负责实施。

【审计时间】全年全过程跟踪审计，负责项目审计现场的业务股分季度向县局政策跟踪审计股提交审计结果。

（二）县级预算管理审计。

1.财政预算执行及决算（草案）编制审计（省定）。

【审计目标和重点】以推动积极财政政策落实、深化预算管理制度改革、促进全面实施预算绩效管理、防控政府债务和隐性债务风险为目标，关注预算法和县委、县政府系列规定及重大决策部署的贯彻落实和保障情况。围绕预算分配管理，关注预算安排与存量资金统筹衔接、部分资金预算分配标准及执行、预算安排的细化和下达、国有资本经营预算全覆盖及收益解缴和支出安排等；围绕转移支付管理，关注专项转移支付设立依据、资金管理办法制定、退出机制的完善、转移支付结构、清理整合等；围绕预算绩效管理，关注绩效目标设置、项目绩效跟踪、绩效评价和结果应用，以及交通运输、基本建设、产业发展、就业等专项资金和财政实拨资金使用绩效等；围绕生态环境保护、财政金融互动、就业创业补助、省级产业发展投资引导基金等专项资金的分配、拨付和绩效等内容，关注财政资金促进落实相关政策情况；围绕政府债务限额分配、地方政府债券分配和使用、隐性债务清理核实等反映政府债务和隐性债务风险防控情况；围绕收支核算、重大事项披露等，对财政总决算草案的真实性、完整性以及编制的规范性进行审计。

【组织实施方式及执行单位】县局财政与农业农村审计股负责对县财政局等开展预算管理审计和财政决算草案审计。对财政金融互动、就业资金、减税降费政策落实进行专题审计，按照省厅的统一安排，采取“集中分析、分散核查、统一指挥、统筹整合”的组织实施方式，审计内容纳入县财政预算执行审计报告，并向州审计局报送审计结果。

【审计时间】4月至5月开展预算执行审计和专题审计。5月10日前出具审计报告，并分别向州审计局和县人民政府报送专题审计结果。

2.县级部门预算执行审计（州定）。

【审计目标和重点】以促进部门规范预算和资产管理、提高预算执行效率和财政资金使用绩效、推进全面实施预算绩效管理、保障各级党委政府重大决算部署贯彻落实为目标，对县民政局进行审计。围绕政策措施落实情况，关注降费政策、清理拖欠民营企业中小企业账款、涉企保证金清理、节能减排目标任务完成、行政机关与行业协会脱钩、津补贴政策执行等；围绕部门预算绩效管理情况，关注预决算编制、绩效目标设置及执行、绩效评价和中期评估、财政存量资金清理盘活、部门预算执行进度、专项转移支付下达等；围绕部门综合管理情况，关注编外人员管理、“三公”经费等重点支出管理、国有资产管理、项目库建立和更新、银行账户管理、政府采购和购买服务等。

【组织实施方式及执行单位】结合经济责任审计，由县局经济责任与自然资源审计股对县民政局2018年度部门预算执行情况实施审计。

【审计时间】4月至5月展开审计，5月10日前出具审计报告，并分别向州审计局和县人民政府报送专题审计结果。

（三）农业农村审计。

东西部扶贫协作受援县专项审计调查（州定）。

【审计目标和重点】围绕东西部扶贫协作和对口支援资金项目、社会帮扶资金项目建设管理情况，关注发改、财政等职能部门履职尽责情况，东部地区产业帮扶措施是否精准有效，帮扶规划与当地脱贫攻坚规划是否充分衔接，有无将帮扶资金用于与脱贫攻坚无关领域等问题。揭示落实产业合作、劳务协作、人才支援、动员社会参与、资金项目支持等政策措施中存在的体制机制等问题，提出完善政策制度、推动政策落实的审计建议，促进我县受援工作进一步强化责任落实、聚焦脱贫攻坚，提升扶贫协作成效。

【组织实施方式及执行单位】县局财政与农业农村审计股对2017年、2018年实施情况进行审计，并将2018年省委巡视组扶贫领域反馈问题的整改落实情况纳入审计内容。

【审计时间】7月开始，10月20日前出具审计报告。

（四）资源环境审计。

乡镇党政领导干部自然资源资产离任（任中）审计（省定）。

【审计目标和重点】围绕“两地一典范，美丽新九寨”发展目标，以稳步推进全县资源环境审计监督覆盖面和领导干部自然资源资产任中（离任）审计，巩固和深化乡镇领导干部自然资源资产任中审计成果为目标，开展九寨沟县勿角乡镇党政领导干部自然资源资产任中审计。重点关注乡镇领导干部履行自然资源资产管理和生态环境保护责任的具体措施及取得成效，揭示县乡两级相关管理职能边界不清、责任不明以及权责不统一的问题，通过厘清责任、落实网格化管理促进乡镇领导干部知责尽责。

【组织实施方式及执行单位】县局经济责任与自然资源审计股负责，开展勿角乡党政领导干部自然资源资产任中审计。

【审计时间】7月上旬开始，11月20日前，分别向州审计局和县人民政府报送审计结果。

（五）“8·8”九寨沟地震灾后恢复重建跟踪审计（省定）。

【审计目标和重点】以促进阳光重建、廉洁重建为目标，借鉴运用芦山地震灾后恢复重建跟踪审计经验，对灾后重建规划实施、重建支持政策措施落实、灾后恢复重建资金和重点项目及审计整改情况实施全过程跟踪审计，及时揭示灾后重建过程中存在的突出问题，严肃查处违纪违规、损失浪费、失职渎职等问题，提出整改和加强管理的建议，保障九寨沟“8·8”灾后恢复重建顺利推进和总体目标按期实现。

【组织方式】按照省厅统一安排，通过购买社会中介服务方式整合审计力量，实施跟踪审计。

【审计时间】省厅统一组织，统一实施。省、州、受灾县审计机关上下联动，今年上半年、下半年各实施一次跟踪审计，省厅定期公告全县跟踪审计结果。6月中旬完成上半年跟踪审计任务，2020年1月中旬完成下半年跟踪审计任务。

（六）重点专项审计。

1.农村信用社防风险审计调查（省定）。

【审计目标和重点】围绕深化金融供给侧结构性改革，防范化解地方金融风险，增强金融服务实体经济能力为目标，关注农村信用社依法合规经营、服务实体经济等情况，揭示薄弱环节和风险隐患，坚决打击违法违规金融活动，提出强化经营管理，加强服务实体经济的建议意见。

【组织实施方式及执行单位】以政策跟踪审计方式组织实施，采取“总体分析、发现疑点、分散核查、系统研究”的实施模式，按照省厅金融审计处组织实施要求，县局政策跟踪审计股负责对分析发现的疑点进行核查。

【审计时间】3至5月核查疑点问题，按要求5月10日前，分别向州审计局和县人民政府报送审计结果。

2.重点项目专项审计调查（州定）。

【审计目标和重点】通过审计调查，发现问题，分析原因，提出建议，促进重大（重点）项目科学决策、有效推进，提高资金使用绩效。对九寨沟县生活垃圾处理设施、广播电视干线网络传输工程2个灾后重建项目进行专项审计调查，结合“一州两区三家园”和县“全域发展、绿色崛起”战略目标，重点关注发改、财政等职能部门履职尽责情况，计划投资进度完成情况，项目建设资金落实情况。及时揭示是否存在拖欠民营企业工程款和农民工工资、资金筹集管理不合规、形成地方隐形债务，盲目决策、重复建设、项目未开工或推进缓慢等问题。确保项目建设规范有序、廉洁高效、公开透明，促进相关单位和人员履职尽责，保障重点项目建设的顺利推进。

【组织方式】县局固定资产投资审计股按照州局固定资产投资审计科统一制定专项审计调查工作方案组织实施。

（八）固定资产投资审计。

【审计目标和重点】以促进灾后重建政策措施贯彻执行和规范重建项目建设管理为目标，重点关注灾后重建规划、灾后重建相关政策落实情况，检查项目建设资金筹集使用、概算执行、履行建设程序、决算编制等情况的真实性、合法性。揭示重建项目实施过程违反基本建设程序、不依法招标投标、违规施工建设、工程结算不实、弄虚作假等各种违法违规问题，以及相关主管部门、业主单位履职尽责不到位，相关参建主体履约尽责不到位等问题，促进相关单位依法行政。揭示项目项目建设中存在的重大损失浪费和工程质量风险隐患等问题，促进相关单位提高项目建设管理水平。

【组织实施方式及执行单位】县局固定资产投资审计股负责对九寨沟县民族体育馆、县自然资源局2019年6月30日前已完成竣工决算的24个地灾治理项目进行审计。通过购买社会中介服务方式，整合审计力量具体实施。

【审计时间】根据被审计单位资料准备情况进场实施。

（十）县委、县政府和县审计委员会交办的其他事项。

四、工作要求

（一）提高政治站位锐意进取。审计机关要始终坚持党对审计工作的集中统一领导，牢固树立“四个意识”，坚定“四个自信”，坚决做到“两个维护”，认真落实县委、县政府和省审计厅、州审计局对审计工作的部署要求，勇于担当、奋发有为，以高度的政治责任感、历史使命感和职业荣誉感，圆满完成各项审计任务，努力开创新时代审计工作新局面。

（二）坚持依法文明审计。坚持在法定职权范围内开展审计，严格规范审计取证，资料获取，银行账户查询，延伸调查等行为。按照“三个区分开来”的要求，历史全面客观看待问题，客观审慎作出评价。在坚持客观求实、坚持问题导向、及时发现问题的基础上，积极推动问题的及时解决，找准审计发挥服务作用的着力点，注重引导、预防和参谋作用的发挥，服务部门科学管理、服务领导科学决策、服务大局科学发展。严格遵守各项纪律要求，加强廉政、保密和安全教育管理，切实维护审计机关良好形象。

（三）严格审计项目计划执行。年度审计项目计划一经下达，必须严格执行。各组织实施单位应按照国家审计准则的要求，细化审计目标、范围、内容和重点以及任务分工，按照计划安排时间节点完成审计任务。未经批准不得擅自变更或调整审计范围、参审单位、实施时间等，确需调整必须履行报批程序。

（四）切实提高审计质量和效率。积极探索创新与审计全覆盖相适应的审计组织方式。为适应新的工作要求，更有效地整合审计资源、优化业务流程，探索将部分专项审计（调查）项目以政策跟踪审计方式进行组织部署。全面落实分层级质量控制责任，加强现场管理。强化大数据审计思维，扎实开展大数据审计，加强数字化审计方式的应用，提高运用大数据核查问题、评价判断，宏观分析的能力，不断提高审计质量与效率。
