# 关于公布第六批县级非物质文化遗产名录的通知

各乡（镇）人民政府，县级各部门：

为进一步充实我县县级非物质文化遗产名录库，加强对非物质文化遗产的保护和利用，经县人民政府研究，同意将良美都钦等10个项目列入第六批县级非物质文化遗产名录，并予以公布：

1.良美都钦（类别：民俗）；

2.嘛智助钦（类别：民俗）；

3.顾朵（类别：民俗）；

4.蜜蜜子的制作技艺（类别：传统手工艺）；

5.椅窝子的制作技艺（类别：传统手工艺）；

6.白马纱尕帽的制作技艺（类别：传统手工艺）；

7.核桃馍的制作技艺（类别：传统手工艺）；

8.手工剪纸（类别：传统手工艺）；

9.手工木雕（类别：传统手工艺）；

10.白马刺绣（类别：传统手工艺）。

九寨沟县人民政府办公室
