# 关于印发《〈九寨沟县加强生态保护助推脱贫攻坚实施方案（2018-2020年）〉2019年调整方案》的通知

各乡（镇）人民政府，县级各部门：

《〈九寨沟县加强生态保护助推脱贫攻坚实施方案（2018-2020年）〉2019年调整方案》已经县十四届人民政府第55次常务会议审议通过，现印发你们，请认真贯彻执行。

九寨沟县人民政府

2019年6月10日

《九寨沟县加强生态保护助推脱贫攻坚实施

方案（2018-2020年）》2019年调整方案

根据《中共阿坝州委 阿坝州人民政府关于开展生态扶贫的实施意见》（阿委发〔2017〕13号）文件精神，我县于2018年制定了《九寨沟县加强生态保护助推脱贫攻坚实施方案（2018-2020年）》并组织实施。同年，省委第一巡视组对九寨沟县开展扶贫领域专项巡视工作，发现“落实公益岗位政策不精准”问题。为全面贯彻落实中央、省、州关于脱贫攻坚的重大决策部署，认真完成巡视反馈意见整改工作，特制定本方案。

一、调整依据

（一）省委第一巡视组关于对九寨沟县开展扶贫领域专项巡视的反馈意见；

（二）县委、县政府贯彻落实省委第一巡视组扶贫领域专项巡视反馈意见整改工作安排部署。

二、调整原则

（一）对不符合年龄条件生态管护员进行清退。

（二）对2018年无劳动能力的生态管护员姓名等信息更换为有劳动能力且自愿从事生态管护工作的家庭成员。

（三）对因与子女分户、病残和“五保”等无劳动能力的生态管护员进行清退。

（四）对清退的贫困人口实施养老兜底，保障长期稳定的生活补贴。

三、调整情况

2018年全县共有生态管护员1598人，死亡和退出8人，2019年初实有生态管护员1590人。经对全县贫困户生态管护员信息和家庭情况进行清查核查，对352人无劳动能力委托管护人员进行清理。其中贫困户家庭有劳动能力169人，将原无劳动能力的户主更换为有劳动能力且自愿从事生态管护工作的家庭成员；因与子女分户、病残和“五保”等无劳动能力的生态管护员183人进行清退。在第二次全面清查核实中清退病残疾、超龄、长期外出务工的生态管护员10人。全县共清退无劳动能力生态管护员193人。清退后实有生态管护员1397人（生态护林员1293人、河道管护员104人）。

四、资金测算

按照《中共阿坝州委 阿坝州人民政府关于开展生态扶贫的实施意见》（阿委发〔2017〕13号）和《九寨沟县人民政府关于印发〈九寨沟县加强生态保护助推脱贫攻坚实施方案（2018-2020年）〉的通知》（九寨沟府发〔2018〕2号）文件内容，2019年生态管护员补助标准8150元/年·人，生态管护员意外伤害保险费120元/年·人，生态管护员统一标识着装（背心）20元/年·人，全县共需资金1158.113万元。目前已下达国家生态管护员资金263万元，县级财政配套生态管护员意外伤害保险费、生态管护员统一标识着装（背心）费19.558万元，州级配套缺口资金875.555万元。

五、保障措施

县林业和草原局、县水务局分别负责生态护林员和河道管护员监督、指导工作，各乡镇具体负责管理选聘和培训工作。管护岗位补助兑现由乡、村两级考核，将考核兑现表分别上报县林业和草原局、县水务局汇总，由项目单位财务人员交县财政局审核通过后，根据考核结果，由财务人员将管护岗位补助转信用社，打入“一卡通”兑现，并对资金到户情况进行检查。
