# 关于印发《九寨沟县2019年度城乡居家养老服务工作实施方案》的通知

各乡（镇）人民政府：

《九寨沟县2019年度城乡居家养老服务工作实施方案》已经县十四届人民政府第55次常务会议审议通过，现印发给你们，请认真遵照执行。

九寨沟县人民政府

2019年6月14日

九寨沟县2019年度城乡居家养老服务

工作实施方案

为深入推进我县居家养老服务工作的开展，全面提升我县养老服务社会化工作水平，逐步形成机构养老和居家养老相结合的社会养老服务体系，更好地为居家的老年人提供生活照料、家政服务、康复护理和精神慰藉等方面服务，根据四川省老龄工作委员会办公室《关于〈全面推进居家养老服务工作的意见〉的通知》及阿坝州人民政府办公室《关于推进居家养老服务工作实施意见》，结合我县实际，特制定如下工作方案。

一、指导思想

以注重我县居家老年人的社会养老，改善居家困难老年人生活条件为目的，以专业化服务为主要服务形式，以满足老年人群日益增长的养老服务需求为出发点，以服务特困、高龄、病残、空巢、孤寡老人为重点，遵循“真诚、关爱、沟通、服务”的基本理念，广泛动员社会力量，充分利用社会资源为居住在家的老年人提供以解决其日常生活困难为主要内容的社会化服务。积极探索新形势下社区居家养老服务的新机制、新途径、新方法，向居家老年人开展生活照料、家政服务、安全看护、精神慰藉、文化娱乐为主要内容的社会化服务，使老人更幸福，社会更和谐。

二、居家养老服务原则

坚持“政府倡导、社会参与、市场运作、全民关怀”的工作思路，建立社区社会化养老服务体系，使老年人获得生活上的照料和便利，精神上的关爱和慰藉，各种居家养老服务需求能得到最大限度的满足。

1.坚持政府主导与扶持，社会参与、市场化运作相结合的原则；

2.坚持家庭养老为主，社会养老为辅的原则；

3.坚持先面向特殊群体后逐步扩大的原则；

4.坚持专业化居家养老服务与社区义务服务、邻里互助相结合的原则；

5.坚持根据不同需求，提供相应养老服务项目的原则；

6.坚持实行低偿、有偿服务、公益服务相结合的原则。

三、居家养老服务事项

（一）居家养老服务对象。为全县3000名困难家庭的失能老人和80周岁以上高龄老人提供居家养老服务，开展居家老年人生活照料、家政服务、安全看护、医疗保健、精神慰藉、文化娱乐等为主要内容的社会化服务，不断提高我县居家养老服务水平，满足老年人不断增长的多样化需求。

（二）居家养老服务时间

2019年6月至2020年6月为期1年

（三）居家养老服务内容。以老人的生活需求为重点，提供生活照料、家政服务、医疗护理等服务，同时兼顾老年人文化娱乐、学习教育、体育健身、精神慰藉和政策解读、宣讲、法律咨询等服务，服务内容可逐步拓展。

安全保障服务：主要通过相应的联系制度，充分发挥助老服务员、社区工作者、邻里和志愿者的作用，对老人特别是对高龄、生活不能自理的老人住所定期进行安全排查，排除和预防安全隐患，保障老人安全。安排资金可在同一乡（镇）范围内，适度整合集中使用于部分老年人。

生活照料服务：主要包括上门照料服务，提供护理、洗衣、打扫卫生、家电维修等一般家政服务。

医疗保健服务：主要通过医疗服务机构，为老人提供免费健康体检、健康咨询、健康教育、疾病防治、康复治疗、健康讲座等服务。对高龄、生活不能自理的老人提供家庭医生上门服务。

文化娱乐、法律政策宣传服务：主要包括文体娱乐、精神慰藉、法律咨询、心理疏导等；以维护老年人权益为重点，认真宣传相关法律法规、老年优待政策，及时了解老年人政策落实过程中的问题，让老年人得到实实在在的实惠。

四、运营规划

根据四川省老龄工作委员会办公室《关于<全面推进居家养老服务工作的意见>的通知》、阿坝州人民政府办公室《关于推进居家养老服务工作实施意见》中“居家养老服务项目可以由社会单位、社会组织承担，也可以由企业承担”规定，今年为营造良好的竞争机制，增加服务工作的对比性，特将居家养老项目分为两个片区（具体分配附后），按照竞争性谈判的方式，选出两家机构承接居家养老项目。

五、资金来源和服务费拨款办法

居家养老服务采取政府购买服务方式，为3000名困难家庭失能老人和80周岁以上高龄老人提供居家养老服务，平均每人每年提供300元的服务费，共计90万元。资金由省、州、县三级财政筹集解决，其中省级财政按50%共计45万元补助；剩余部分州县财政配套，比例为州县3：7，州级补助资金共计13.5万元；县级补助资金共计31.5万元。

项目经费支付，由县民政局按照实际服务人次和开展工作情况，每季度按不高于合同总额的20%拨付，项目结束后根据对老年人满意度测评结果拨付最后20%。（具体测评办法另行制定）
