# 关于印发《九寨沟县2019年经济工作安排暨争创县域经济发展先进县实施方案》的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县2019年经济工作安排暨争创县域经济发展先进县实施方案》已经县委、县政府同意，现印发给你们，请结合工作实际，认真组织实施。

九寨沟县人民政府

2019年6月17日

九寨沟县2019年经济工作安排

暨争创县域经济发展先进县实施方案

为深入贯彻习近平总书记关于高质量推进九寨沟地震灾区恢复重建和发展提升的重要指示，全面落实省委清华书记“建成典范、发展提升”的总体要求，按照中央经济工作会议七项重点任务、省委经济工作会议七项重点任务及州委十一届五次、六次全会和县委四届五次、六次全会要求，坚持稳中求进工作总基调，抓好稳增长、促改革、调结构、惠民生、防风险各项工作，着力推动县域经济平稳、健康、可持续发展，实现“两地一典范、美丽新九寨”目标，推动县域经济不断发展壮大，结合全省县域经济发展考核办法和我县作为重点生态功能区经济发展实际，制定如下实施方案。

一、重点工作

（一）围绕“一个中心”。紧紧围绕“两地一典范、美丽新九寨”这一个中心，坚持“全域发展、绿色崛起”总体战略和“四个全域、四个九寨”战略规划，充分利用资源、区位优势发展特色产业，着力加强生态建设，构建“一主两核三带”绿色发展新布局，不断夯实县域经济基础，助推县域经济转型升级、跨越发展。

（二）完成“两大任务”。争创“县域经济先进县”和“天府旅游名县”。对标《四川省县域经济发展考核办法》和《天府旅游名县考核验收评分细则（试行）》中的考核指标，结合我县实际，深入分析各项指标，聚焦重点难点，找准问题差距、明确工作任务。精准施策、精准发力，突出生态保护优先，侧重生态空间规模质量和生态产品供给能力提升。注重文旅融合发展，进一步提升文化和旅游的供给力、吸引力、影响力。以点带面、以创促优，成功创建全省“县域经济发展先进县”和“天府旅游名县”。

（三）力求“三个突破”。一是投资实现“质”的突破。牢固树立“抓发展必须抓投资，抓投资必须抓项目”的理念，把稳投资摆到突出位置，进一步扩大有效投资，全年全社会固定资产投资增长32.3％。按照“四个一批”要求，突出抓好重点项目建设，依托重建项目推进的系列创新，形成具有九寨特色的项目工作长效机制，推动在建项目完成更多实物工作量，确保新开工项目加快建设。二是消费实现“量”的突破。加快项目建设，确保九寨沟、甲勿池等景区景点早日开园，拉动服务业和社消零高位增长。积极响应国家降费减税相关政策，落实个人所得税专项附加扣除政策，释放消费潜能，促进消费增长。积极培育旅游消费惠民新增长点。三是出口实现“新”的突破。积极搭建专业外贸公司与农产品生产企业对接合作平台，鼓励我县九珍党参产业有限公司、鑫海农业开发有限公司等农产品经营主体积极与专业外贸公司对接。抓好农产品的集约化种植，科学化管理和农产品出口相关认证，努力培育农产品出口基地，推进我县农产品出口有新的突破。

（四）突出“四项重点”。一是重点抓好乡村振兴，为县域经济发展夯实基础。注重规划引领。加快编制《乡村振兴战略“1+1+6+N”规划》，分类推进乡村产业、生态、人才、文化、组织“五大”振兴，积极创建省级乡村振兴示范县。打造一批示范乡村，加快推进产业提档升级。加快改善农村人居环境，90%以上的行政村生活垃圾得到有效治理、卫生厕所普及率达到70%以上。加快推进农业农村改革，完善承包地“三权”分置制度。二是重点发展民营经济，为县域经济发展提供保障。强化民营经济在县域经济中的主体作用，鼓励和引导民间资本投向县域特色产业和基础产业。着力破除民营经济发展的体制机制和政策障碍，“拆三门破三山”，营造亲清新型政商环境。保障民营经济依法平等使用生产要素、公平参与市场竞争，促进民营经济不断发展壮大。三是重点加强开放合作，为县域经济发展提供依托。抢抓“一带一路”建设、长江经济带等战略机遇和“一干多支、五区协同”发展机遇，主动融入“丝绸之路经济带”和“成都平原经济区”，积极构建“8+3”区域发展协作区，借力东西部协作和省内对口帮扶机制，加大与东部发达地区与环成都经济圈的交流合作，推动经济社会一体化发展，全面提升整体竞争力和综合实力，努力将我县打造成为川西北生态示范区开放合作新高地。四是重点强化飞地园区建设，为县域经济发展提供动能。强力发展“飞地经济”，积极探索主体结构、开发建设、运营管理、利益分配等方面的新模式，有条件地创新政策供给，加快“飞地”园区建设，建立健全“飞地”园区市场化利益分享机制，力争九绵生态文化旅游产业园企业入驻率达50%，嘉善—庆元—九寨沟产业园年底前基本达到开园条件，九寨沟—平湖产业园年内实现收益。

（五）把握“五个着力”。一是着力推进结构调整，加快产业转型升级。构建“一主两核三带”绿色发展新布局，以生态经济发展推动产业升级。着眼生态有机农业，大力推进农业专业化、规模化、集约化经营，加大农产品生产基地建设，发展农产品加工业。突出发展绿色工业，坚持转型升级和绿色发展“双向用力”，重点引进高质环保企业发展旅游产品加工业，逐步实现产品加工本土化、规模化。培育新型服务业，促进一二三产融合发展，大力发展康养产业，依托对口帮扶资源，引进一批医疗、保健、康养机构，开发健康文化、高端养生等特色服务业。二是着力推进城乡融合发展，打造宜居宜业功能布局。牢固树立“规划+”理念，不断优化城镇布局，改善人居环境，加快形成“核心驱动，多点发力”的城乡发展格局。围绕“漳扎国际生态旅游魅力小镇”和“南坪旅游服务中心”，坚持统一规划、分步实施，加强农村“水、电、路、信”建设，打造一批传统村落和特色村寨，培育一批辐射周边的特色集镇，促进城乡协调发展。改造提升一批城市公园、休闲广场、公共绿地和生态停车场，破解城乡二元结构，按照“全域旅游”要求，推进城乡统筹，完善旅游功能，提升城乡形象。三是着力保障和改善民生，不断增进百姓福祉。坚持以人民为中心的发展理念，加快补齐教育、医疗、社会保障等民生短板，全力推进撤县设市；全面提升教育基础设施，高质量推进九寨沟县七一南坪中学、九寨沟第一小学等教育类项目建设；完成国际旅游医疗应急救援中心、九寨沟县人民医院恢复重建等项目，不断完善县、乡、村三级医疗服务体系；抓好就业促进，开发、用好公益性岗位，不断提升社会保障兜底能力。四是着力保护生态环境，建设美丽新九寨。建立体现生态文明要求的目标体系、考核办法、奖惩机制，把资源消耗、环境损害、生态效益纳入经济社会发展评价体系。强化生态空间规划管控，认真落实国家和四川省主体功能区规划，优化国土空间开发格局，加快研究编制《九寨沟县空间规划》，全面促进资源节约，切实提高资源利用效率和效益。加快震后生态修复保护，打好大气、水、土壤污染防治攻坚战，抓好中央和省环境保护督察反馈问题整改，严厉打击乱砍滥伐、非法采挖等违法行为，大力推行“以电代柴”，促进能源结构进一步优化。五是着力防范化解风险，遏制隐性债务增量。积极贯彻落实预算法，推动加快建立规范的政府举债融资机制，强化限额管理和预算管理，开展债务风险评估和预警，建立债务风险应急处置机制，构建债务风险常态化监督机制，依法查处问责违法违规融资担保行为。

三、组织保障

（一）加强组织领导。加强对县域经济发展推进工作的组织领导，建立组织有力、运转高效的领导运行机制和严格的责任追究机制，实行党政“一把手”负总责、分管领导具体负责的工作推进责任制。建立相关部门、单位参加的会商及联席会议制度，及时协调解决工作实施中的有关问题。各乡（镇）、各相关部门、单位要主动担责，按照责任分工，加强工作协调，强化指导服务，做好衔接配合。各部门、单位主要负责人要亲自上手、亲自部署、亲自督促、亲自检查，确保各项重点任务落实组织有力、推动有序、效果明显。

（二）加强调度分析。建立全县经济运行调度机制、全县经济发展半年分析会商机制、重大问题协调解决机制，县政府每季度、县发改局每月进行一次调度。加强调度分析结果运用，对各部门、单位开出“点穴”式问题清单并抄送部门单位主要负责同志，对主要运行指标降幅较大的主管部门、单位进行约谈。县发改局、县统计局每月对经济相关匹配指标、关联指标进行大数据分析，与竞争县（市）进行对比分析，相关部门和单位负责提供相关数据，加强数据资源共享，形成专题分析报告，精准掌握全县经济运行情况。

（三）加强考核督办。县委、县政府制定工作推进考核评价办法，量化确定县域经济发展目标任务，重点考核各乡（镇）、各部门、单位推进特色优势产业培育、重点项目建设、主要经济指标完成等情况，强化对责任落实情况的督促检查，对责任落实、措施有力、成效明显、完成任务较好，综合考评排名靠前、位次提升幅度较大、县域经济先进县和天府旅游名县创建成效显著的部门、单位进行表彰，对责任不到位、工作不力、项目推进情况较差的部门、单位进行通报批评，并把考核结果作为领导干部进退留转的重要依据，充分发挥政绩考核的激励和导向作用。
