# 关于严格土地用途管制和规范建筑容积率管理的通知

各乡（镇）人民政府，县级各部门：

为加强土地利用全程管理，依法依规解决遗留问题，按照《四川省城乡规划条例》《关于印发〈建设用地容积率管理办法的通知〉》（建规〔2012〕22号）、《四川省人民政府贯彻落实〈国务院关于深化改革严格土地管理的决定〉的实施意见》（川府发〔2005〕15号）、《四川省人民政府印发关于进一步加强土地出让管理规定的通知》（川府发〔2014〕58号）等要求，并充分借鉴成都地区相关细化政策文件，结合我县实际，现就县域范围内严格土地用途管制，规范建筑容积率管理等有关事项通知如下：

一、严格土地用途管制和规划管控

各类建设用地不得擅自改变土地用途，任何单位和个人无权擅自更改规划条件。以招标、拍卖、挂牌出让方式取得的国有经营性建设用地，确需改变的，由县人民政府收回后重新安排招标、拍卖、挂牌出让。

因非企业原因确需调整的，必须依据《城乡规划法》规定的程序进行。

二、规范建筑容积率管理

（一）自然资源局应严格按照《国有建设用地使用权出让合同》确定的规划条件审查并办理相关手续。经批准调整容积率的，自然资源局按程序重新出具规划条件，与原土地使用权人重新签订《国有建设用地使用权出让合同》。

（二）因下列情况增加容积率的，土地使用权人应补缴土地价款：

1.土地使用权人以非招标、拍卖、挂牌方式取得的国有建设用地，原有土地已进行了规划项目建设，因我县漳扎国际生态旅游魅力小镇建设和宜居县城建设需要提升改造，需按现行规划指标进行提档升级打造的。

2.土地使用权人以非招标、拍卖、挂牌方式取得的国有建设用地，原有土地已进行了规划项目建设，因“8·8”九寨沟地震灾后重建，需按现行规划指标进行拆除重建的。

3.在我县原新区规划建设征地过程中，因特殊历史原因县政府赠予了被征地村集体组织一定比例的国有建设用地作为村集体发展用地，该类土地需按现行规划指标进行规划建设的。

三、土地使用条件的认定

（一）原土地使用条件的认定

1.原已签订《国有建设用地使用权出让合同》的，根据原批准的规划条件认定原土地使用条件；

2.原已签订《国有建设用地使用权出让合同》但未附规划条件的，根据原批准的规划建设项目总平面图或地块现状建筑面积实测报告认定原土地容积率。

（二）新土地使用条件的认定

根据县自然资源局按程序出具的新规划条件认定。

四、自印发之日起执行，有效期两年。有效期间，国家、省、州对此类情况有相关新规定的，按新规定执行。

九寨沟县人民政府
