# 关于印发《九寨沟县医疗保障扶贫工作实施方案》的通知

各乡（镇）人民政府，县级各部门:

为做好农村贫困人口医疗保障工作，完善医疗保障扶贫制度，进一步明确细化扶贫政策，推动医保扶贫工作有效落实，根据《四川省医疗保障局 四川省民政厅 四川省财政厅 四川省扶贫开发局关于印发〈四川省医疗保障扶贫三年行动实施方案（2018-2020年）〉的通知》（川医保发〔2018〕5号）要求，结合我县实际，制定本方案。请各单位结合自身职能职责，按照分工做好对接、抓好落实。

九寨沟县人民政府办公室

2019年7月2日

九寨沟县医疗保障扶贫工作实施方案

一、总体要求

（一）指导思想。全面贯彻党的十九大和十九届二中、三中全会精神，以习近平新时代中国特色社会主义思想为指导，认真贯彻落实习近平总书记关于脱贫攻坚的重要指示精神，将打赢脱贫攻坚战作为当前的首要任务，重点聚焦因病致贫返贫等特殊贫困人口，实现参保缴费有资助、待遇支付有倾斜、基本保障有边界、管理服务更高效、就医结算更便捷。充分发挥基本医保、大病保险、医疗救助各项制度作用，切实提高农村贫困人口医疗保障受益水平，为实现2020年国家现行标准下全县农村贫困人口脱贫提供坚强保障。

（二）任务目标。医疗保障扶贫对象为建档立卡贫困人口、农村特困供养人员、农村低保对象等农村人口，到2020年，以上人员全部纳入基本医保、大病保险、医疗救助范围，医疗保障受益水平明显提高，基本医疗保障更加有力。

1.医疗保障扶贫对象基本医疗保险参保率达100%；

2.大病保险起付线降低50%、支付比例提高5-10个百分点；

3.年度救助限额内农村贫困人口政策范围内个人自付住院医疗费用按规定给予救助，救助比例不低于70%；

4.促进定点医疗机构严格控制医疗服务成本，减轻农村贫困人口目录外个人费用负担；

5.医疗保障经办管理服务不断优化，医疗费用结算更加便捷。

二、实施措施

（一）贯彻落实可持续筹资政策，实现贫困人口应保尽保。

1.精准识别扶贫对象。加强贫困人口精细化管理，做到底数清、情况明，为精准实施医疗扶贫夯实基础。

牵头部门：县扶贫开发局、县民政局

责任单位：各乡镇人民政府

2.基本医疗保险全覆盖。建立贫困人口参保考核办法和农村贫困人信息沟通和动态调整机制，并在医保信息系统中做好标识；按照规定足额安排补助资金；对年度内新增加的农村贫困人口，按规定资助参保，实现农村贫困人员参加基本医疗保险率达100%。

牵头部门：县医疗保障局

责任单位：县民政局、县扶贫开发局、县财政局、各乡镇人民政府

（二）实施综合保障措施，提高贫困人口待遇水平。

1.稳步提高城乡居民基本医保待遇。完善城乡居民基本医疗保险制度，稳定住院保障水平。进一步完善城乡居民医保门诊统筹政策，逐步提高门诊保障水平，扩大门诊保障范围，减轻患者门诊医疗费用负担。

牵头部门：县医疗保障局

责任单位：县卫生健康局

2.加大大病保险倾斜支付力度。将农村贫困人口大病保险起伏线降低50%、报销比例提高5-10个百分点。

牵头部门：县医疗保障局

责任单位：县卫生健康局

3.加大医疗救助托底保障力度。对农村贫困人口要分类分档细化农村贫困人口救助方案，确保年度救助限额内农村贫困人口政策范围内个人自付住院医疗费用按规定给予救助，救助比例不低于70%。

牵头部门：县医疗保障局

责任单位：县卫生健康局

4.落实建档立卡贫困人口医保扶持政策。按照基本医保、大病保险、县域内政策范围内住院费用倾斜性支付等政策，确保建档立卡贫困患者县域内住院政策范围内医疗费用个人支付占比控制在10%以内；对建档立卡贫困患者在县域外发生的政策范围内住院医疗费用，经基本医保、大病保险及各类补充医疗保险、商业保险报销后的个人负担费用，在年度救助限额内按不低于70%的比例给予救助。

牵头部门：县医疗保障局

责任单位：县卫生健康局

（三）使用适宜技术，促进就医公平可及。

1.落实基本医疗保障范围规定。全面执行全州统一的基本医保药品目录，及时将国家医保目标谈叛准入药品纳入医保支付范围。落实国家对诊疗项目目录和医疗康复项目的管理要求。

牵头部门：县医疗保障局

责任单位：县卫生健康局

2.落实分级诊疗制度。引导参保人员优先到基层首诊；省域内就医结算执行州内同等支付政策。探索将符合条件的互联网诊疗服务项目纳入医保支付范围。

牵头部门：县医疗保障局

责任单位：县卫生健康局

（四）优化基层公共服务，全面推进费用直接结算。

1.提升服务能力。推进城乡居民基本医保、大病保险、医疗救助信息共享和服务衔接，实现农村贫困人口医疗费用“一站式服务、一窗口办理、一单制结算”，减少农村贫困人口跑腿垫资；制定专人负责政策宣传并帮助贫困人口兑现政策，解决群众政策不知情、就医报销难等问题。

牵头部门：县医疗保障局

责任单位：县卫生健康局、各乡镇人民政府

2.做实跨地区就医结算服务。对异地安置和异地转诊的农村贫困人口，要优先做好异地就医登记备案和就医结算等服务，切实做好贫困地区外出就业创业人员异地就医备案工作。

牵头部门：县医疗保障局

责任单位：县就业局

（五）加强医疗服务管理，控制医疗费用不合理增长。

1.推行医保支付方式改革。探索建立区域内医疗卫生资源总量、医疗费用总量与经济发展水平、医保基金支付能力相适应的调控机制。重点推行按病种付费改革，逐步将日间手术和符合条件的中西医病种门诊治疗纳入按病种收付费范围。完善按人头、按床日等多种付费方式，积极开展按病种分值付费试点和按疾病诊断相关分组（DRG）付费试点。注重医疗费用成本控制，提供使用适宜的基本医疗服务，切实降低农村贫困人口医疗费用总体负担。

牵头部门：县卫生健康局

责任单位：县医疗保障局

2.完善定点医药机构服务协议管理。健全定点服务考核评价体系，将考核结果与医保基金支出挂钩。全面开展医保职能监控，不断完善医保信息系统，提高医保基金使用效率。

牵头单位：县医疗保障局

责任单位：县卫生健康局、市场监督管理局

三、保障措施

（一）加强组织领导。各部门要把打赢脱贫攻坚战作为重大政治任务，强化一把手负总责的领导责任制，明确责任、尽锐出战、狠抓实效。要把医疗保障扶贫工作纳入年度重点任务推进，医保、民政、财政、扶贫等部门要加强通力协作，建立医疗保障扶贫工作沟通联系机制，确保各项扶贫政策落实落地。

（二）坚持现行制度基本标准，狠抓落实。各部门要充分认识医疗保障扶贫任务的重要性、艰巨性和长期性,将思想和认识统一到中央、省、州、县的决策部署上来,既要狠抓落实确保扶贫任务全面完成,也要高度重视防范出现不切实际过高承诺、过度保障、不可持续的问题。坚持基本医疗保障标准,充分发挥现有医疗保障制度功能;贯彻落实精准方略,健全医疗保障扶贫机制;坚持严格管理,确保基金长期平稳可持续。对出现的苗头性、倾向性问题,要采取有效措施,及时规范整改,并做好衔接和平稳过渡。

（三）建立专项工作调度机制。医疗保障部门要统筹基本医保、大病保险、医疗救助三项制度,建立医疗保障扶贫专项工作调度机制,加强对医疗保障扶贫工作督导检查。要会同相关部门在医保信息系统中做好农村贫困人口身份标识,建立贫困人口专项管理台账;加强农村贫困人口参保缴费、患病就医、待遇保障、费用结算等情况监测,定期汇总报送数据。

(四)深入开展医疗保障扶贫作风专项治理。要不断改进工作作风,将加强作风建设贯穿医疗保障扶贫全过程,重点解决贯彻中央、省、州、县脱贫攻坚决策部署不坚决、扶贫责任落实不到位、政策措施不精准、资金管理使用不规范、工作作风不扎实、考核评估不严格等问题。防止形式主义、官僚主义，加强工作实效。

(五)加强典型宣传和风险防范。深入宣传习近平总书记关于扶贫工作的重要论述和党中央、省、州关于精准扶贫精准脱贫的重大决策部署,宣传医疗保障扶贫成就和典型事迹,营造良好的舆论氛围。加强医疗保障扶贫政策风险评估,建立重大事件应急处置机制,加强对脱贫攻坚的舆情监测,合理引导社会舆论。
