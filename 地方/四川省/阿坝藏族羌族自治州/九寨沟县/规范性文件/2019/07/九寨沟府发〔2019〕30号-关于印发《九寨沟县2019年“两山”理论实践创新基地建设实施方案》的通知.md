# 关于印发《九寨沟县2019年“两山”理论实践创新基地建设实施方案》的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县2019年“两山”理论实践创新基地建设实施方案》已经县十四届人民政府第57次常务会议审议通过，现印发给你们，请认真遵照执行。

九寨沟县人民政府

2019年7月9日

九寨沟县2019年“两山”理论

实践创新基地建设实施方案

“绿水青山就是金山银山”绿色发展理念，是习近平生态文明思想的核心理念。践行“绿水青山就是金山银山”，是九寨沟县推进生态文明建设、筑牢绿色之基、引领绿色发展的重要路径。为加快推进“绿水青山就是金山银山”实践创新基地（以下简称“两山”理论基地）建设，探索形成“点绿成金”的九寨模式，打造四川生态文明建设的金名片，特制本实施方案。

一、总体要求

（一）指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大精神和习近平总书记来川视察重要讲话精神及习近平生态文明思想，牢固树立和践行“绿水青山就是金山银山”理念，坚持“全域发展、绿色崛起”总体战略，按照“四个全域、四个九寨”战略规划布局，依托九寨沟县生态优势和国家重点生态功能区良好工作基础，全面推进“两山”理论基地建设，促进大生态、大旅游、大扶贫、大数据融合发展，开辟国家重点生态功能区生态修复保护、绿色富民、绿色惠民新路径，探索“绿水青山”转化为“金山银山”可复制、可推广的九寨“两山”经验实践模式，将九寨沟县打造成为全国少数民族地区“两山”理论实践创新基地建设示范区。

（二）基本原则

1.坚持生态优先，保值增值。

2.坚持绿色发展，点绿成金。

3.坚持共建共享，惠民富民。

4.坚持改革创新，长效保障。

（三）建设目标

以“宜居宜游、绿色低碳、文明和谐、美丽富裕”为核心。

1.生态环境质量保持全州一流水平

到2019年底，生态环境质量持续改善，生态功能有效巩固提升，森林覆盖率达到58.65%，河流断面水质达标率100%，城乡饮用水源水质达标率100%，县城清洁燃料普及率达97%；严格控制化学需氧量、氨氮、二氧化硫、氮氧化物等主要污染物排放总量，全年大气优良天数比例保持在99%以上。

2.绿色产业发展水平显著提升

2019年底全县地区生产总值达到26亿元，经济绿色化程度大幅提高，服务业增加值占地区生产总值比重达到59.7%以上，生态旅游竞争优势保持领先，游客接待和旅游总收入逐步恢复。

3.居民生活水平稳步提升

2019年实现人均地区生产总值31902元，城镇居民人均可支配收入超过35354元，农村居民人均可支配收入超过14127元，全面消除绝对贫困。城镇生活污水集中处理率达到85%以上，农村生活污水集中处理率达到80%以上，城镇生活垃圾无害化处置率达到95%以上，农村生活垃圾收集率达到90%以上，农村公共厕所基本达到等级标准。

4.体制机制基本完善

完善生态补偿机制，生态环保大数据平台和管理系统基本形成，“两山”评估考核机制基本建立，完成九寨沟县生态文明建设评价指标体系建设，完成九寨沟县“两山”理论实践创新基地建设规划编制和“三线一单”编制工作。

5.经验成果基本形成

重点以九寨沟风景名胜区、勿角民族生态旅游试验区、神仙池生态旅游区、甘海子生态文化旅游区、九寨·鲁能胜地旅游度假区等为载体，形成“两山”实践经验。

在成功举办州运会、元宵晚会、涂墨节、马拉松赛等大型活动的基础上，实现“全域发展”与“金山银山”互促共进。实现人与人、人与自然、人与社会和谐共生。

二、主要任务

（一）摸清生态本底，强化资源管理利用。开展“多规合一”，研究编制九寨沟县国土空间规划，设定并严守资源消耗上限、环境质量底线、生态保护红线，将各类开发活动限制在资源环境承载能力内。控制开发强度，规范开发秩序，整体谋划国土空间开发，全县国土空间开发强度控制在0.7%以内。一是摸清生态资本。开展自然资源统一确权登记，在不动产登记的基础上，建立统一的自然资源登记体系，摸清全县水流、森林、山岭、草原、荒地和探明储量的矿产资源等自然资源权属、位置、面积等信息，形成生态资源总价值。二是强化国土空间治理，以第三次国土调查成果为基础，在国土空间规划编制中划定生态保护红线、永久基本农田、城镇开发边界等控制线，完成节约资源和保护环境的生产、生活、生态空间布局构建。三是优化国土空间开发布局。按照《中共中央国务院关于建立国土空间规划体系并监督实施的若干意见》，以第三次全国国土调查数据作为规划现状底数和底图基础，全面开展对原有空间规划实施的评估、对国土空间开发保护现状和未来风险点的评估，以及自然资源承载能力和国土空间开发适宜性评价，在评估评价的基础上按照规定时间完成编制。

责任单位：县自然资源局、县发展和改革局、县林业和草原局、县交通运输局、县科学技术和农业畜牧局、九寨沟生态环境局

（二）加强生态修复保护，重塑绿水青山。落实《“8·8”九寨沟地震灾后恢复重建总体规划》，统筹推进山水林田湖草系统治理，实行自然修复与人工治理相结合、生物措施与工程措施相结合，最大程度恢复提升自然生态功能。一是加快修复自然生态系统，加强九寨沟县保护区外震损林地植被恢复封禁管护工作，加快核实调整植苗造林部分和工程造林部分地块及完成相关涉及调整手续；加快九寨沟地震灾区珍稀动物受损栖息地林草植被快速恢复模式研究与示范，形成相关成果。二是加强生物多样性保护，基本完成自然保护区珍稀动物栖息地修复项目；加快黄土梁大熊猫基因交流走廊带项目建设，完成设备安装调试。三是扎实推进造林增绿护湿护草，采取以封禁为主的自然恢复措施，以人工修复为辅，年内完成造林3.542万亩。四是加强放牧管理，禁止散养山羊或圈养代替散养。

责任单位：县林业和草原局、县科学技术和农业畜牧局

（三）加强污染防治，打好“三大战役”。坚决摒弃以牺牲环境为代价换取经济增长的做法，以保障人民健康为目的，打好大气、水、土壤污染防治攻坚战。

1.实施大气污染治理行动。深入推进蓝天保卫战，持续开展国省干线路域环境综合整治工作，强化九绵高速、川九路及漳扎镇国际生态旅游魅力小镇建设等项目施工监管，加强安全文明施工监管，完善项目施工防尘、降尘设施，规范车辆运输，加强扬尘治理，严防运输车辆“抛、洒、滴、漏”，全面改善公路及沿线路域环境，全力构建快捷、舒适、绿色、安全的通行环境。严把准入关，落实工业企业节能监管，严控新建高耗能、高污染项目，重点发展绿色环保、低能耗、高技术产业。积极推进汽车能源改造，启用清洁能源公交车、观光车；加大排放不达标大型载客汽车、重型载货汽车淘汰力度，引导公交、环卫、出租车等行业及政府机关使用新型能源汽车。

责任单位：县交通运输局、县公安局、县住房和城乡建设局、县经济和信息化局、县商务和经济合作局、县运管所、九寨沟生态环境局、州公路局九寨沟分局

2.实施水污染治理行动。深入推进碧水保卫战，严格执行“河湖长制”“河湖警长制”，加强水资源管理。完成九寨沟县灾后重建黑河小流域治理工程第二期建设任务，治理水土流失面积6平方公里；完成国家水土保持重点治理九寨沟县永和乡城沟小流城治理项目，治理水土流失面积6.2平方公里。实施城镇管网等基础设施提升工程，完成南坪镇村（社区）雨污分流建设及道路恢复建设9267米，在景区开园前完成九寨沟县城市生活污水处理厂（二期）项目建设，完成漳扎镇污水处理厂管网及提标技改项目建设；加强污水处理厂运行管理，确保稳定达标排放。持续推进水染污企业整治，督促企业稳定达标排放。完成集中式饮用水源基础信息调查、评估和隐患排查整改工作。

责任单位：县水务局、县公安局、县住房和城乡建设局、九寨沟生态环境局、永乐镇

3.实施土壤污染防治行动。深入推进净土保卫战，减少农业生产活动中农药化肥的施用量，大力推广清洁绿色配方；加强地膜回收利用，加强秸秆综合利用管理，提高综合利用率。加强生活垃圾渗滤夜处置和管理，大力探索建立城乡生活垃圾市场化运行和管理机制，推进城乡生活垃圾分类投放、收集、运输、处理系统全覆盖和“厕所革命”，新建乡村公共厕所9座、改建7座，筹建九环沿线8个农村垃圾分类示范村、2座垃圾中转站，基本实现农村生活垃圾分类处理，力争农户参与率达到95%。加强医疗废物、危险化学品、放射性废物集中收集和专业化处置，严禁含重金属的废水、废渣污染土壤，防控重大环境风险。加强危险废弃物的申报登记和管理，完成土壤重点企业用地信息调查，按照《阿坝州六个涉重金属行业限期整治工作方案》要求，制定紫金矿整治方案。

责任单位：县住房和城乡建设局、县科学技术和农业畜牧局、县文化体育和旅游局、县应急管理局、九寨沟生态环境局

（四）优化产业体系，增强发展动能。围绕绿色、循环、低碳、创品牌，构建基于现代服务业的旅游产业体系，融合推进产业发展。

1.加快转变农业发展方式。积极发展现代农业示范区，调整优化农业产业结构、品种结构、品质结构和产品层次，提高农业发展质量。发展特色效益农业，大力扶持“九寨刀党、九寨中蜂、九寨藏香猪、九寨水果、九寨花椒、九寨核桃”等特色种养基地建设，全面完成白河乡岩米家、保华乡土门村、双河镇上甘座村、大录乡沙勿村、安乐乡上安乐村等10乡23个村的特色种养殖生产基地建设项目。大力推行无公害农产品、绿色食品、有机食品认证和国家地理标志产品保护，培育特色农产品品牌，完成5个无公害农产品的申报，完成农产品质量安全检验检测中心双认证工作。建设农业现代化融合园区，加快农田艺术景观、农事节庆活动等创意农业试点，10月底完成罗依乡、白河乡、永丰乡、马家乡、黑河乡5个现代农业生产融合示范园项目建设。

责任单位：县科学技术和农业畜牧局、各乡（镇）

2.积极培育发展绿色循环工业。着力推动绿色农畜产品深加工企业高原食品、兴茂畜牧、九寨庄园葡萄酒业等成长型企业发展。加快培育工业发展“第二梯队”，引进资金、技术和管理经验，进一步加大投入，千方百计促进农畜产品加工企业快速成长。围绕绿色主导产业，整合现有资源，加快产品更新换代步伐，不断提高配套能力，努力打造影响力大、带动性强、优势突出的绿色农畜产品加工业。力争生态文化旅游产业园企业入驻率达40%，嘉善-庆元-九寨沟产业园年底前主体结构全部封顶，部分厂房具备交付使用条件，九寨沟-平湖产业园力争年内实现落地。

责任单位：县经济和信息化局、县商务和经济合作局

3.提高服务业绿色低碳发展水平。完善功能性服务体系，积极推行绿色旅游产品和企业认证工作，积极申报绿色饭店3个、绿色景区3个，落实企业环保意识和文明公约签订，为旅游发展营造良好市场氛围。强化餐饮、酒店、藏（农）家乐等涉旅企业和个体工商户监管，严把准入关，严防高污染、高排放企业运营，培育1家绿色旅游餐饮龙头企业，打造2条绿色美食街，认定30家绿色旅游餐饮示范点，举办1次美食节，推动九环沿线酒店餐饮业振兴发展。

责任单位：县文化体育和旅游局、县市场监督管理局

4.加快旅游业转型升级。全力做好九寨沟景区开园准备工作，加快推进九寨沟风景名胜区、神仙池生态旅游区、甘海子生态文化旅游区、勿角民族生态旅游试验区、九寨光谷国际旅游度假区、漳扎镇国际生态旅游魅力小镇等旅游类重建项目建设，加快推进中查沟九寨鲁能胜地旅游度假区建设，形成多景区互为支撑、多点多极发展的旅游业态。大力开发特色民居、主题小镇等乡村旅游，提升打造一批精品旅游民宿，建设2处自驾营地，开辟九寨全域旅游线路，逐步辐射勿角、白河、罗依等区域生态文化景点。积极引导支持休闲酒店、特色民宿建设和宾馆饭店提档升级，在全省率先完成藏（农）家乐星级评定和非星级旅游酒店评等定级工作。设立漳扎、县城、双河等重要旅游集散地游客咨询服务中心3个；建成县域旅游综合指挥调度系统，完成九寨沟区域智慧旅游公共应急平台一期建设，积极争创天府旅游名县，加快建设国家全域旅游示范区先行地。

责任单位：县文化体育和旅游局

（五）突出生态扶贫，促进价值转化。一是坚持扶贫开发与生态保护深度融合，通过实施生态工程建设，创新生态扶贫方式等，使贫困人口从生态保护与修复中得到更多实惠，实现脱贫攻坚与生态文明建设“双赢”。推广“合作社+管护+贫困户”模式，落实生态管护员1397人，兑现管护员工资8150元/年/人。加快甲勿海大熊猫保护研究园项目和白河自然保护区金丝猴科普基地项目建设，推进生态旅游发展助推生态扶贫项目。二是大力发展生态产业，充分利用丰富的生态资源，大力开发重楼、黑木耳、香菇等林下种植和林下养殖生态产品，发展林下经济，完成花椒嫁接改造3500株，嫁接核桃11100株。利用良好的山水资源发展生态旅游、农家乐旅游，积极地探索让生态效益转化为经济效益、让生态优势转化为发展优势的绿色发展道路。

责任单位：县林业和草原局、县科学技术和农业畜牧局、各乡（镇）

（六）统筹城乡建设，构建美丽家园。坚持走以人为本、绿色低碳的新型城镇化道路，全面提高城乡规划建设管理水平，让人民群众生活在更加宜居的环境中。
