# 关于印发《九寨沟县促进民营经济健康发展若干政策措施责任分工方案》的通知

各乡（镇）人民政府，县级各部门：

按照《九寨沟县促进民营经济健康发展若干政策措施》（九寨沟委发〔2019〕12号）要求，特制定《九寨沟县促进民营经济健康发展若干政策措施责任分工方案》，并经县人民政府研究同意，现印发给你们，请认真遵照执行，并做好以下三点工作：

一、强化落实，解决最后一公里问题。各牵头单位要将《九寨沟县促进民营健康发展若干政策措施责任分工方案》纳入重要议事日程，按照《九寨沟县促进民营健康发展若干政策措施》，进一步细化工作举措，落实工作责任，制定工作方案，切实解决最后一公里问题，促进全县民营经济健康发展。

二、强化协作，狠抓工作推进。各牵头单位要主动作为，充分发挥综合协调、牵头抓总的作用，加强与协同单位的对接沟通，准确掌握工作进展情况。各牵头单位要分别于4月5日、6月24日、9月24日、12月24日将工作推进落实情况经单位主要负责人签字盖章同电子档一并报县民营经济工作领导小组办公室（联系人：申欢，联系电话：0837-7725093），内容主要包括工作开展情况、推进进度、采取的举措、取得的成效、存在的问题、下一步打算等，内容简明扼要，实事求是，数据详实，对于材料质量不过关的将一律退文处理。

三、强化考核，压实工作责任。县目督办要将分工任务情况纳入目标绩效管理，加强对各项分工任务落实情况的督查检查，对推进落实情况及时进行通报，全程跟踪督办，确保各项工作高效完成。对于工作推进不力、推诿扯皮、敷衍了事，将予以严肃追责，请务必引起高度重视。

九寨沟县人民政府

2019年7月11日

九寨沟县促进民营经济健康发展

若干政策措施分工方案

为贯彻落实《中共九寨沟县委 九寨沟县人民政府关于印发〈九寨沟县促进民营经济健康发展若干政策措施〉的通知》（九寨沟委发〔2019〕12号）提出的系列政策措施，根据有关部门和单位职责，现提出如下分工方案。

一、进一步激发市场活力

1.降低准入门槛，按照“非禁即入”原则，保障民间资本平等进入市场准入负面清单外所有行业和领域，不得对民间资本单独设置附加条件、歧视性条款和准入门槛。

责任单位：县发展和改革局、县经济和信息化局、县商务和经济合作局（排名第一的单位为牵头单位，下同）

2.全面清理规范县级行政许可事项，取消无法律法规依据的前置审批事项。

责任单位：县行政审批局、县级有关部门

3.拓宽民营资本投资领域，充分发挥我县区位、生态、品牌等特色优势，用好用足中央支持藏区发展、深度贫困地区脱贫攻坚、灾后恢复重建等政策，制定完善招商引资优惠政策，以相对优势吸引更多的知名企业到我县投资兴业。我县民营企业新增投资同等享受招商引资政策。

责任单位：县商务和经济合作局、县发展和改革局、县经济和信息化局、县财政局

4.发挥县财政资金支撑引导作用，通过投资补助、贷款贴息、设立产业发展专项资金等方式，鼓励民营企业向漳扎镇国际生态旅游魅力小镇、南坪旅游服务中心、弓杠岭至双河全域旅游发展示范带、双河至郭元和勿角休闲度假旅游发展带、陵江至大录生态文化旅游培育带投资布局。

责任单位：县财政局、县经济和信息化局、县商务和经济合作局、县发展和改革局、县自然资源局、县文化体育和旅游局

5.鼓励民营企业向九寨沟-绵竹文化旅游产业园、九寨沟-嘉善产业园和九寨沟-平湖科创产业园等“飞地”园区投资布局。

责任单位：县商务和经济合作局、县经济和信息化局

6.鼓励民营企业向清洁能源、民族文化、智慧旅游等产业投资布局。支持民营企业参与乡村振兴、污染防治、脱贫攻坚、灾后恢复重建、防灾减灾等事业。

责任单位：县发展和改革局、县商务和经济合作局、县经济和信息化局、县科学技术和农业畜牧局、县扶贫开发局、县自然资源局

7.大力发展特色农牧业，鼓励传统小农经济向精品化、集约化、现代化生态农业转变，在特色农业品牌建设、产业用地政策、农村金融创新政策、生态循环农业技术等方面给予大力支持，吸纳民营企业、返乡创业企业投资发展现代农业产业园，建立“公司+合作社+基地+农户”“合作社+基地+农户”等现代农业发展新模式。

责任单位：县科学技术和农业畜牧局、县发展和改革局、县自然资源局、县扶贫开发局、县人力资源和社会保障局、县金融办

8.通过政府和社会资本合作（PPP）、政府购买服务等方式，引导民营企业参与医疗机构、养老服务机构、教育机构、文化设施、体育设施、新能源设施建设运营。

责任单位：县财政局、县发展和改革局、县级有关部门

9.对重点民营企业、重大民营资本投资项目，采取“一企一策”“一事一议”“特事特办”的方式，优先保障配置关键资源和要素。建立健全县级领导牵头、职能部门负责的项目常态化服务机制，动态更新项目推进情况总台账和年度台账，实施“一企一档”管理制度，为项目跟踪对接、签约落地、开工建设、竣工投产、生产经营、销售推广、转型升级等环节提供“一对一”全程服务。

责任单位：县发展和改革局、县市场监督管理局、县经济和信息化局、县商务和经济合作局、县自然资源局、县行政审批局、县住房和城乡建设局、县级有关部门

10.经县级相关部门推荐、民营经济工作领导小组审核认定，每年筛选5至10家经济发展贡献大、社会效益明显、市场前景好、发展潜力大的重点成长型企业，纳入重点扶持培育范围，实行动态管理，强化项目服务、要素保障和措施落实。

责任单位：县市场监督管理局、县发展和改革局、县经济和信息化局、县商务和经济合作局、县行政审批局、县民营办、民营经济工作领导小组成员单位

11.支持“个转企”“小升规”，个体工商户转型升级为企业的，允许保留原字号和行业特点。对乡村旅游酒店（客栈）、藏（农）家乐等个体工商户转为企业法人的，给予一次性0.5万元奖励。对分公司转独立法人的企业，给予一次性1万元奖励。

责任单位：县行政审批局、县经济和信息化局、县商务和经济合作局、县市场监督管理局、县文化体育和旅游局、县财政局

12.对首次纳入国家统计网报企业库的规模以上工业、有资质的建筑业和房地产开发经营业的民营企业，给予一次性5万元奖励。对首次纳入国家统计网报企业库的限额以上批发零售业和住宿餐饮业、规模以上服务业的民营企业，给予一次性1万元奖励。对首次创办小微企业或从事个体经营，且所创办企业或个体工商户自工商登记注册之日起，正常运营1年以上的贫困劳动力和农民工等返乡创业人员，除州级财政补贴外，县级财政再给予一次性0.5万元创业补贴。

责任单位：县财政局、县统计局、县经济和信息化局、县商务和经济合作局、县住房和城乡建设局、县人力资源和社会保障局

13.对县内、合作园区规模以上工业企业年主要营业收入首次突破1亿元的民营企业，给予最高5万元的奖励，年主要营业收入每上一个1亿元台阶给予企业最高5万元奖励。对县内、合作园区限额以上批发零售业和住宿餐饮业、规模以上服务业企业年主要营业收入首次突破1亿元的民营企业，给予最高5万元的奖励，年主要营业收入每上一个1亿元台阶给予企业最高5万元奖励。在县注册具有独立法人资格企业的施工总承包资质每提高一个等级，除州级财政补助外，县级财政再给予企业2万元奖励。

责任单位：县财政局、县经济和信息化局、县商务和经济合作局、县住房和城乡建设局、县文化体育和旅游局、县统计局

14.大力发展总部经济，对将公司总部落户注册在我县或在我县注册子公司的世界500强、中国500强、行业500强企业，分别给予一次性20万元、10万元、5万元奖励。吸引和争取大型骨干企业、鼓励本土在外企业，将公司总部落户我县注册，根据其经济贡献，给予一次性2万元奖励。

责任单位：县商务和经济合作局、县经济和信息化局、县财政局、县行政审批局

二、进一步降低民营企业经营成本

15.全面落实税收优惠政策。在国家规定的税额幅度内，民营企业纳税人按上限享受增值税起征点、重点群体创业就业税收优惠、蔬菜及部分鲜活肉蛋产品流通环节免征增值税等政策。全面落实国家有关促进小微企业发展的增值税、企业所得税政策，促进西部大开发所得税优惠政策，以及支持企业改制重组的契税、土地增值税减免等税收优惠政策。落实国家关于符合条件的高新技术企业减按15%的税率征收企业所得税、符合条件的技术转让所得减免企业所得税、研发费用加计扣除等税收政策。因有特殊困难不能按期缴纳税款的企业，可以依法申请延期缴纳税款。

责任单位：县税务局、县财政局、县科学技术和农业畜牧局

16.严格清理规范涉企收费。全面落实国家、省、州加快推进涉企行政事业性收费零收费各项政策。

责任单位：县财政局、县发展和改革局、县经济和信息化局、县级有关部门

17.对行政事业性收费项目、政府性基金实行清单管理制度，收费标准按最优惠规定执行，对小微企业、科技型初创企业可实施普惠性税收政策。

责任单位：县发展和改革局、县税务局、县级有关部门

18.全面清理规范行政审批中介服务，将各涉企收费单位纳入政务服务中心，分别开设独立或综合窗口进行统一管理，实行“单位开票、银行收款、财政统管”的规范管理模式。

责任单位：县财政局、县发展和改革局、县行政审批局

19.民营企业工会会费的工作经费由原来的12％降至5％。

责任单位：县总工会、县税务局

20.规范中介机构、行业协会的收费标准，一律禁止强制企业付费参加考核、评比、表彰、参展等活动。

责任单位：县发展和改革局、县民政局、县人力资源和社会保障局、县工商联、县级有关部门

21.强化重点项目用地保障，全面落实供地优惠政策，保障民营企业土地使用。将农产品冷链烘干设施、农产品初加工设施、农产品储藏流通设施、休闲采摘设施纳入农业附属设施范围，对直接用于或者服务于农业、林业生产的生产设施用地、附属设施用地以及配套设施用地按农用地管理，不办理农用地转用审批手续。发展乡村旅游、休闲、养老、健康等特色产业确需使用建设用地的，可点状供地。对民营企业投资非营利性教育、科研、体育、公共文化、医疗卫生、养老、社会福利、公用设施等设施用地，符合《划拨用地目录》的，可按划拨方式供应。

责任单位：县自然资源局、县科学技术和农业畜牧局、县经济和信息化局、县发展和改革局、县文化体育和旅游局

22.主动了解民营企业生产经营状况，坚持开源节流，科学调度，对产业园区、优势民营企业，优先保障生产要素供给。支持符合全县发展功能定位、符合国家鼓励发展产业使用留存电量等电力政策。科学合理利用好水资源，依法保障民营企业合法用水权。

责任单位：县经济和信息化局、县发展和改革局、县住房和城乡建设局、县水务局

23.科学合理制定水、电、气价格，实现一般商业用水、用电、用气同价的价格政策。

责任单位：县发展和改革局、县市场监督管理局

24.按照国家、省统一部署，全面落实降低社保缴费名义费率政策，确保企业社保缴费实际负担有实质性下降。对依法参保缴费并采取有效措施稳定职工队伍的民营企业，在失业保险基金中给予企业稳岗补贴，按照企业及其职工上年度实际缴纳失业保险费总额的60%给予补贴。

责任单位：县人力资源和社会保障局、县财政局

25.将就业见习补贴范围由离校未就业高校毕业生扩展至16至24岁失业青年；组织失业青年参加3至12个月的就业见习，按规定给予就业见习补贴。鼓励民营企业吸纳我县建档立卡贫困劳动力就业，对签订1年以上劳动合同并参加社会保险的，给予企业1000元/人奖补；对吸纳10人以上建档立卡贫困劳动力就业的民营企业，一次性给予不低于5万元奖补。鼓励农民专业合作社、种养大户、家庭农场、农村电商等各类经营主体吸纳我县建档立卡贫困户劳动力就业，对稳定就业半年以上的，按1000元/人标准，给予生产经营主体一次性奖补；吸纳10人以上的，再一次性给予1万元奖补。

责任单位：县人力资源和社会保障局、县财政局、县扶贫开发局、县科学技术和农业畜牧局、县林业和草原局、县商务和经济合作局

三、进一步加强民营企业融资服务

26.县财政每年统筹200万元作为民营企业贷款贴息资金，对符合条件的民营企业贷款给予贴息补助。

责任单位：县财政局

27.力争实现三个不低于，即金融机构对民营企业贷款增速不低于上年增速，金融机构对民营企业贷款增量不低于上年增量，当年金融机构新拓展的民营企业客户数不低于上年增加的户数。壮大县域金融服务主体，积极引进和建设融资担保公司、小额贷款公司、村镇银行。

责任单位：县金融办、人行九寨沟县支行、九寨沟县各银行金融机构

28.建立农业信贷担保体系和乡村振兴农业产业发展贷款风险补偿金制度，积极转变财政支持方式，充分发挥财政资金引导作用，撬动金融和社会资本投入农业产业发展领域。对投保特色种养殖保险的民营企业，由县级财政给予保费补贴。

责任单位：县财政局、人行九寨沟县支行、县科学技术和农业畜牧局

29.开展诚信全域旅游示范区建设，按照《九寨沟县加强社会信用体系建设工作实施方案（2018－2020年）》，动态调整红黑名单信息，实施守信联合激励和失信联合惩戒，评定并表彰一批诚实守信典型民营主体，鼓励金融机构向诚实守信典型民营主体提供条件更优、成本更低的金融信贷产品，并由县级财政进行奖补。

66.积极推荐思想政治坚定、行业代表性强、参政议政能力优、社会信誉好的民营企业家兼职参与到党政部门工作中，兼职参与到人大、政协调研视察、参政议政工作中。发挥民营经济工作领导小组作用，每年召开全县民营经济工作会议。完善县级民营经济工作目标绩效考核机制，健全民营经济统计监测体系和定期发布制度。

责任单位：县民营办、县统计局、县民营经济工作领导小组成员单位

67.加强对民营经济主体扶持资金跟踪考核，对业绩突出效果明显的，继续加大扶持力度；对在困难环境中拼搏坚守的，给予关心帮助；对因经营主体自身主观原因导致经营不善的，给予停止、取消相关扶持并追回国家资金等处置。

责任单位：县财政局、县民营办、县级有关部门

68.设立政府服务民营企业工作作风专项举报热线，对漠视企业正当诉求、无视企业困难问题的，不正确履行职责、工作落实不力、监督管理缺失的，由纪检监察机关和组织部门，对相关单位和责任人严肃追责问责。

责任单位：县纪委监委、县组织部、县民营办

69.县级有关部门要根据本政策措施，结合部门实际，制定相应工作细则，确保各项措施落到实处，取得实效。

责任单位：县民营经济工作领导小组成员单位
