# 关于印发《九寨沟县“两不愁、三保障”回头看大排查农村危房改造方案》的通知

各乡（镇）人民政府，县级各部门：

《九寨沟县“两不愁三保障”回头看大排查农村危房改造方案》已经县十四届人民政府第61次常务会议审议通过，现印发给你们，请认真贯彻执行。

九寨沟县人民政府

2019年9月23日

九寨沟县“两不愁、三保障”回头看大排查

农村危房改造方案

为深入贯彻落实习近平总书记在解决“两不愁三保障”突出问题座谈会上的重要讲话精神，按照省、州关于开展“两不愁三保障”回头看大排查工作的安排部署，根据农村居民住房大排查情况，特制定本方案。

一、指导思想

以解决农村困难群众基本居住安全问题为目标，开展农村危房改造工作，确保农村困难群众都住上安全、适用的房屋，进一步改善农村困难群众生活条件。

二、工作原则

（一）坚持政府引导、农户自愿的原则。通过宣传引导，充分调动农民群众自愿改造危破房的积极性，发挥农民群众建设美好家园的主体作用。县政府充分发挥组织、协调作用，为农村危房改造创造条件。

（二）坚持公开、公平、公正的原则。公开资助政策、公开申请审批程序、公布审批结果，规范操作程序，接受群众监督，确保客观公正，让群众满意。

（三）坚持因地制宜、经济实用的原则。按照新农村建设的要求，从当地实际出发，充分尊重当地自然和建筑形式，使用地方建筑材料，确保改造的住房既安全、经济、适用、节地，又美观大方。

三、工作任务

2019年度任务为“两不愁三保障”回头看大排查工作中发现的，经第三方鉴定为C级危房的16处农房和1处D级危房。

四、资金来源和补助标准

农村危房改造资金来源为农户自筹和政府补助。

此次农村危房改造补助资金标准：C级危房按1.3万元/户的标准补助到户；D级危房参照我县2019年度藏区新居建设标准，即按3万元/户的标准补助到户。

五、工作程序

（一）申请。由户主自愿向所在村委会提出书面申请，填写《农村危房改造申请审批表》，并提供户籍、危房照片等证明材料。

（二）评议。村委会接到申请后，召开会议进行评议，议定是否符合条件，签署评议意见，加盖村委会公章，并予以公示；经评议认为符合建设（改造）条件，且公示无异议的，上报乡（镇）政府。对不符合建设（改造）条件或公示有异议的，应及时退回申请材料并向申请人说明理由。

（三）审核。乡（镇）政府接到村委会的申报材料后，应上门逐户进行核查。经审核符合条件的，公示后报县住建局进行审批。对不符合条件的，将材料退回所在的村委会并说明原因。

（四）审批。县住建局接到乡（镇）上报的材料后，在进行复核抽查的基础上，完成审批工作。

（五）验收。项目完工后，由乡（镇）政府进行初验。初验合格后向县住建局提交验收申请，由县住建局牵头，扶贫、发改、财政、民政等相关部门参与，对项目进行抽查、验收，并填写验收合格报告表。

（六）拨付。竣工验收合格后，乡（镇）政府要在10日内完成并向县住建局提供报账资料，县住建局在接到乡（镇）政府报送的报账材料之日起20日内将补助资金足额兑付到户。

（七）挂牌。项目完成后要在房屋的显著位置悬挂“农村危房改造”标识牌，挂牌所需费用由县级财政承担。

六、重点工作

（一）确保房屋质量安全。农村危房改造要严格落实《农村危房改造抗震安全基本要求（试行）》（建村〔2011〕1115号）、《农村危房改造最低建设要求（试行）（建村〔2013〕90号）和《四川省农村居住建筑C级危房加固维修技术导则（试行）》（川建村镇发〔2013〕1124号）有关要求，必须达到主要部件合格、结构安全，具备卫生厕所，满足人畜分离等基本居住卫生条件。

（二）加强档案信息管理。农村危房改造实行一户一档的农户档案管理制度，批准一户、建档一户。纸质档案必须包括农户申请、公示、《农村危房改造申请审批表》、会议纪要、评估表、前后对比照片、竣工验收表等材料。

七、工作要求

（一）提高认识，加强组织领导。农村危房改造工作涉及面广、政策性强、工作量大，各乡（镇）、县级相关部门一定要高度重视，确保按时完成农村危房改造工作目标任务。

（二）明确职责，做好政策衔接。农村危房改造工作实行地方政府负责制，按属地进行管理，各乡（镇）政府是责任主体、工作主体和实施主体。县级关部门要各司其职，密切配合，搞好政策衔接。

（三）规范操作，强化社会监督。一是要完善上门调查核实制度。必须上户调查核实，具体了解实际情况和征求村民的意见，不得瞒报、虚报、漏报，一经发现将追究主要负责人和相关责任人员的责任。二是要建立健全公示制度。村委会评议情况、乡（镇）审核情况都必须在乡（镇）及村委会进行张榜公布，设立举报箱和咨询投诉电话，广泛接受群众的咨询和投诉。

（四）严格要求，确保顺利实施。实施农村危房改造是政府对农村住房困难家庭建房给予的适当资金补助，而不是大包大揽。要强化县、乡（镇）、村三级的组织协调、指导帮助、督促检查等责任，要采取分片包干、责任到人的办法，层层签定责任书，及时进行督促检查，随时跟踪项目工程进展情况。对工作推诿拖拉，严重影响工程进度和质量的，要公开曝光，并追究主要负责人和相关责任人员的责任；对以权谋私、涉嫌犯罪的，移交司法机关依法处理。

八、其他

此次对农房实施的改造加固属于建筑结构改造加固，不能消除地质灾害隐患影响，由县住建局会同村、乡（镇）两级尽快完成危房改造。经第三方房屋评估资料显示，山体运动、地下水变化等地质原因是导致此次危房的主要因素，请县自然资源局及时拿出切实可行的地质处理方案和农房安置建议方案，防止资金使用效果不明显，危房根治不彻底，反复性过大等现象发生。
