# 关于印发《州政府工作报告》重点工作任务分工方案的通知

各乡（镇）人民政府，县级各部门：

为进一步推动全县经济社会高质量发展，按照州政府办《关于印发2020年〈政府工作报告〉重点工作任务分工方案的通知》（阿府办函〔2020〕12号）要求，我县及时对2020年重点工作进行了分解，制定了《〈州政府工作报告〉重点工作任务分工方案》，现印发你们，请认真抓好贯彻落实。

一、加强组织领导，提早谋划实施。各乡（镇）、部门要切实将思想和认识统一起来，认真研究、深入分析，由主要负责同志牵头抓、负总责，抓紧组织制定具体工作方案，拿出实实在在的行动和举措，逐项细化目标任务、明确措施时限，确保工作有人抓、任务能落实，保质保量如期完成各项工作任务。

二、加强沟通协作，强推工作落实。县级各部门（单位）要切实履职尽责，“勤耕责任田，狠抓实干风”，不断推动工作落地落实。各牵头单位要充分发挥综合协调、牵头抓总的作用，加强对各乡（镇）的联系指导，对涉及跨区域、跨部门、跨行业的工作任务，加强与协同单位的对接沟通，准确把握工作进度、及时梳理汇总，定期向县政府报告。各协同单位要切实强化大局意识，全力配合实施，强力推动工作落实。各牵头单位（牵头单位为两个以上的县直部门的，由排名第一的部门负责汇总报送）分别于2020年3月25日、2020年6月25日、2020年9月25日和2020年12月25日前将年度一、二、三季度和全年工作落实情况（内容包括重点工作开展情况、工作进度、采取的措施、取得的成效、存在的问题、下步打算等，尽量用数据表现，篇幅力求精简）以纸质文档（需经单位主要负责人签字）和电子文档报县政府办318室（联系人：金学刚；联系电话0837-7731577），对于材料质量不过关的将一律退文处理，同时抄送目标办。

三、加强督促检查，压实工作责任。县政府办要将各乡（镇）、部门（单位）工作落实情况纳入目标绩效管理和重点督查督办事项，定期开展督促检查，及时发现问题，全程跟踪督办，确保各项工作顺利完成。对工作推动不力、严重滞后、问题突出的，予以通报处理。
