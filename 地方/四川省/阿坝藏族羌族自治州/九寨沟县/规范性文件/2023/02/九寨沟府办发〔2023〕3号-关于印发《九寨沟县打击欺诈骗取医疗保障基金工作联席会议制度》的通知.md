# 关于印发《九寨沟县打击欺诈骗取医疗保障基金工作联席会议制度》的通知

关于《九寨沟县打击欺诈骗取医疗保障基金工作联席会议制度》的解读

各乡（镇）人民政府，县级各部门：

《九寨沟县打击欺诈骗取医疗保障基金工作联席会议制度》已经县人民政府同意，现印发给你们，请认真贯彻执行。

九寨沟县人民政府办公室

2023年2月6日

九寨沟县打击欺诈骗取医疗保障基金

工作联席会议制度

为深入贯彻落实党中央省州关于加强医保基金监管、打击欺诈骗保工作重大决策部署，密切相关部门工作联系，加强医保基金监管统筹协调，形成医保基金监管合力，进一步排查欺诈骗取医保基金的风险点，规范定点医疗机构医疗服务行为和参保人员的就医行为，保障医保基金运行安全，维护广大参保群众的合法权益，共同维护医保基金安全。经县政府同意，决定建立健全九寨沟县打击欺诈骗取医疗保障基金工作联席会议制度（以下简称“联席会议”），统筹推进打击欺诈骗保工作。

一、总体目标

构建“党委领导、政府监管、社会监督、行业自律、个人守信”的全领域、全流程基金安全防控联动机制，整合执法资源，全面推进医保基金法治建设，密切相关部门工作联系，加强信息共享，建立健全医疗保障基金综合监管、协同执法、行刑衔接机制，做到一案多查、一案多处，齐抓共管、联合惩戒，严厉打击定点医药机构、参保人员及医保经办机构欺诈骗取医疗保障基金行为，确保医保基金安全有效运行，共同守护好人民群众的“看病钱”“救命钱”。

二、主要职责

（一）全面贯彻落实国家、省、州相关医疗保障法律法规及政策规定，统筹协调推进医疗保障基金监管工作，严厉打击和防范欺诈骗取医疗保障基金行为。

（二）研究提出全县打击和防范医疗保障领域欺诈骗保行为总体部署和要求，安排协作配合的重大事项和重要工作，审议相关制度文件。

（三）综合分析研判全县打击和防范医疗保障领域欺诈骗保形势和任务，制定预防和查处的政策措施。

（四）研究全县重大欺诈骗保违规违法案件，开展多部门联合检查、联合执法、联合惩戒，共同打击欺诈骗保违法违规行为。

（五）听取各成员单位打击欺诈骗保工作开展情况汇报，指导、督促、检查有关政策措施落实，通报打击欺诈骗保违法违规案件查处情况，实施行政执法与刑事司法有效衔接。

（六）研究解决工作中存在的重大问题，促进部门协作配合，实现信息互通、数据共享，全面推进医疗保障基金监管体系规范化建设。

三、组成部门及人员

联席会议由县人民政府分管副县长担任召集人，县委政法委副书记、县政府办副主任、县医疗保障局局长担任副召集人，县医疗保障局、县委政法委、县人民法院、县人民检察院、县发展和改革局、县公安局、县司法局、县财政局、县卫生和健康局、县审计局、县市场监督管理局、县税务局、县人民银行等13个部门负责担任为联席会议成员。

联席会议下设办公室于县医疗保障局，由县医疗保障局主要负责同志担任联席会议办公室主任。县公安局、县卫生和健康局、县医疗保障局分管负责同志担任联席会议办公室副主任，负责联席会议筹办及日常联络、调研、咨询和信息沟通等工作，督促落实联席会议议定事项，定期报告和通报有关情况，协调解决工作中的具体问题。

联席会议联络员，由各成员单位有关科室负责同志担任，负责及时传达联席会议办公室工作要求，反馈本单位工作开展情况等。

四、职责分工

（一）县医疗保障局：负责管理全县医保基金；负责牵头研究制定打击和防范欺诈骗取医疗保障基金工作相关政策，健全完善联席会议制度，起草年度工作方案，广泛开展打击欺诈骗保工作政策宣讲，牵头开展打击欺诈骗取医疗保障基金专项行动；监督检查医保经办机构、定点医药机构医保服务行为和参保人员就医购药行为，依法依规对单位和个人违法违规的行为开展协议处理、行政执法；做好行刑衔接，依法依规向公安机关移送涉嫌医保欺诈犯罪案件；依法依规向纪检监察机关移送国家机关工作人员涉嫌违纪、犯罪线索；对于当事人逾期并经催告后仍不执行行政处理处罚决定的，依法向人民法院申请强制执行；建立健全医保违法违规信息共享机制，及时为联席会议各成员单位调查涉嫌医保欺诈案件提供业务咨询和人员力量支持；依法受理诈骗医疗保障基金举报、投诉线索，对查实举报案件落实举报奖励；推动医保行政执法与医疗“三监管”联动处罚，按规定向卫健部门通报医疗保障行政执法信息；按规定向发展改革、市场监管部门提供医疗保障领域相关违规违法信息，推动医疗保障诚信体系建设；参与重大医疗保障欺诈类犯罪案件会商处理；做好联系会议办公室日产工作。

（二）县委政法委：负责将打击欺诈骗取医疗保障基金工作纳入平安九寨建设年度目标考核内容，强化工作指导和督导；统筹协调医保网格化服务管理工作，组织网格员协助开展打击欺诈骗保政策宣讲、案件调查和就医行为真实性核查等工作；积极构建行刑衔接机制，推动形成打击合力；参与重大医疗保障欺诈类犯罪案件会商处理。

（三）县人民检察院：负责依法指导、办理涉医疗保障欺诈骗保类刑事案件，做好重大医疗保障欺诈类犯罪案件的提前介入引导侦查、审查逮捕、审查起诉、出庭公诉工作；依法监督行政执法机关将涉嫌犯罪案件移送刑事处理，做好侦查监督、审判监督工作；协助开展打击欺诈骗保法律法规政策宣传；参与重大医疗保障欺诈类犯罪案件会商处理。

（四）县人民法院：负责依法受理、审判检察机关提起公诉的涉医疗保障欺诈骗保类刑事案件；依法审判涉欺诈骗保的其他案件；协助开展打击欺诈骗保法律法规政策宣传；参与重大医疗保障欺诈类犯罪案件会商处理。

（五）县发展和改革局：负责全县社会信用体系建设的指导、协调和综合管理工作，按程序上报“双公示”数据；负责指导并协助医保部门建立健全医疗保障基金监管信用体系，将其纳入社会信用体系范畴，协调各成员单位信用信息互通互相；参与重大医疗保障欺诈类犯罪案件会商处理。

（六）县公安局：负责依法查处打击各类医疗保障欺诈骗保等违法犯罪活动；组织专业力量调查移送的涉欺诈骗保类案件线索，符合立案条件的，及时立案侦查；加强与医保部门的协作配合、信息共享，对医保部门核查涉欺诈骗保类案件给予专业力量支持；充分利用信息化手段，加大对医保欺诈犯罪的研判力度，及早研判发现犯罪线索；协助开展打击欺诈骗保法律法规政策宣传；参与重大医疗保障欺诈类犯罪案件会商处理。

（七）县司法局：负责对有关医疗保障基金使用监督管理的制度文件开展合法性审查；协助开展打击欺诈骗保法律法规政策宣传；参与联席会议对重大案件调查处理的会商。

（八）县财政局：负责监管全县医保基金，支持医保部门加强基金检查、审计、稽核等工作，防范医保基金风险向财政传导；参与联席会议对重大案件调查处理的会商。负责监督管理全县医保基金，支持医保部门加强基金检查、审计、稽核等工作，防范医保基金运行风险向财政传导；参与联席会议对重大案件调查处理的会商。

（九）县卫生健康局：负责加强全县医疗机构和医疗服务行业监管，规范医疗机构及其医务人员医疗服务行为；加强“三医”监管，协助医保部门开展打击欺诈骗取医疗保障基金专项行动，协助做好医疗机构涉嫌欺诈骗取医疗保障基金违规违法案件调查；及时对套保骗保的医疗机构及医务人员在职权范围内进行严肃处理，按规定通报行政处理、处罚信息；收集、整理群众举报线索并依职责转交相关部门查办；及时将违法违规案件情况纳入到医疗机构及相关责任人员医院评审、医师定期考核等业务应用范围；参与联席会议对重大案件调查处理的会商。

（十）县审计局：负责加强医疗保障基金使用审计，对审计发现的欺诈骗保案件问题线索移送相关部门处理；参与联席会议对重大案件调查处理的会商。

（十一）县税务局：负责依法对参保单位、参保人员缴纳医疗保险费用情况进行监督检查稽核；负责医保基金征收征缴信息比对核查，加强与医保部门对单位、个人参保缴费信息比对核查，及时对接征缴信息，实现数据共享、信息互通；参与联席会议对重大案件调查处理的会商。

（十二）县市场监督管理局：负责依法查处医疗卫生行业各类价格违法行为；查处使用未依法注册或者备案的医疗器械开展服务违法违规行为，加强药械经营、使用质量和药师执业监管，组织整顿和规范药品零售及使用环节市场秩序，检查药品进货渠道，打击违法购进药品行为；协助医保部门加强各级医保定点零售药店监督管理，及时将违法违规案件情况纳入到零售药店的监管和行政处罚中；协助查处药品生产、经营企业、医疗机构、医务人员套取骗取医保基金案件；参与联席会议对重大案件调查处理的会商。

（十三）县人民银行：负责加强有关保险公司监督管理；参与联席会议对重大案件调查处理的会商。

五、工作要求

（一）原则上每年至少召开1次打击欺诈骗保工作联席会议，由召集人主持。重大问题由召集人召集成员单位和人员会商研究解决，一般性问题由联席会议办公室协调成员单位研究解决。根据工作需要或紧急情况可由召集人临时召开全体会议或部分成员会议，也可邀请其他部门和单位参加会议，研究相关工作。

（二）联席会议由联席会议办公室提出需要解决的问题和事项，报召集人审定会议议题，确定会议时间及会议形式，通知成员单位按要求准备有关材料。以会议纪要形势明确会议议定事项，由召集人签署后印发各成员单位实施。

（三）联席会议各成员单位要聚焦职能职责，认真抓好联席会议决定贯彻落实，及时报告本单位落实联席会议决定事项情况。主动向联席会议提出加强改进本辖区、本部门打击欺诈骗取医疗保障基金工作的意见和建议。联席会议办公室定期通报全县打击欺诈骗保专项整治工作情况。
