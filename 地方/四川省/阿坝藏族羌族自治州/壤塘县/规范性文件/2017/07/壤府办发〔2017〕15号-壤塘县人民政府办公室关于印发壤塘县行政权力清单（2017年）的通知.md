# 壤塘县人民政府办公室关于印发壤塘县行政权力清单（2017年）的通知

壤府办发〔2017〕15号

各乡镇、县政府各部门、各直属部门：

为深化简政放权、放管结合、优化服务改革，促进法治政府、廉洁政府、创新政府、和服务政府建设，全面推进行政权力依法规范公开运行，按照四川省人民政府办公厅《关于印发四川省权力清单（2016本）的通知》（川办发〔2016〕108号）要求，对我县的9项权力事项进行了动态调整。调整后权力事项5338项，分别为：行政处罚4525项、行政征收48项、行政强制198项、行政确认36项、行政裁决6项、行政给付10项、行政检查239项、行政奖励118项、其他行政权力158项。经县政府研究决定，现将《壤塘县行政权力清单（2017年）》印发你们，并通过“中国壤塘”政府门户网站予以公布。

权力清单公布后，各行权部门要加强行政权力依法规范公开运行，凡发生的行政权力事项均应纳入行政权力依法规范公开运行平台上网运行，并按照要求将运行情况向社会公开，接受社会监督。未列入清单的行政权力事项，各行权部门不得行使。

壤塘县人民政府办公室

2017年6月29日
