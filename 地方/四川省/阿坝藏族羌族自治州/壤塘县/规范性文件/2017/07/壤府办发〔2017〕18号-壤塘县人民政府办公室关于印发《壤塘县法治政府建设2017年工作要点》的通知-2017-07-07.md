# 壤塘县人民政府办公室关于印发《壤塘县法治政府建设2017年工作要点》的通知

壤府办发〔2017〕18号

各乡（镇）党委和人民政府，县级各部门：

《壤塘县法治政府建设2017年工作要点》已经县委、县政府研究同意，现印发你们，请结合实际，认真贯彻执行。

壤塘县人民政府办公室

2017年7月7日

壤塘县法治政府建设2017年工作要点

2017年，全县法治政府建设要牢固树立五大发展理念，紧紧围绕中央、国务院印发的《法治政府建设实施纲要（2015—2020 年）》《四川省法治政府建设实施方案（2016-2020 年）》《阿坝州法治政府建设工作方案（2017-2020 年）》和《壤塘县法治政府建设工作方案（2017-2020 年）》的各项安排部署，进一步解放思想，创新举措，求真务实，扎实推进年度阶段工作落地落实，切实抓好法治政府制度建设、执法队伍培训、重点领域执法、规范性文件审查等工作，实现法治政府建设制度基本健全，全县各级政府及各部门依法行政能力和水平显著提升的目标任务，为我县经济和社会发展提供有力的法治保障。

一、全面推进法治政府建设

（一）认真贯彻《壤塘县法治政府建设工作方案（2017-2020年）》精神。加强《实施纲要》《实施方案》的学习，按照《壤塘县法治政府建设工作方案（2017-2020年）》要求，加强领导、细化措施、落实责任、明确重点，确保各项任务扎实有效推进。

责任单位：县政府法制办、县直各部门、各乡（镇）人民政府

（二）建立法治政府建设第一责任人职责清单。根据《党政主要负责人履行推进法治建设第一责任人职责规定》，细化法治政府建设第一责任人责任，建立职责清单。上级政府应当对下级政府主要负责人履行推进法治建设第一责任人职责情况进行定期检查、专项督查。对不认真履行第一责任人职责的，年度内发生多起重大违法行政案件造成严重后果的，依法追究政府主要负责人责任。

责任单位：县政府办、县政府法制办、县直各部门、各乡（镇）人民政府

（三）强化组织领导。一是调整充实壤塘县法治政府建设工作领导小组，充分发挥法治政府建设工作领导小组协调督促指导作用。二是县人民政府与州人民政府签订《2017年法治政府建设责任书》，确保顺利完成《壤塘县法治政府建设工作方案（2017-2020 年）》年度任务。三是建立健全党委、人大、政府听取年度法治政府建设工作报告机制。每年第一季度县人民政府要主动向县委、县人大常委会及州政府报告上一年度法治政府建设情况。县政府常务会议每年至少听取2次推进依法行政、建设法治政府工作汇报，研究解决有关问题，部署推进依法行政工作的具体任务和措施。报告要通过政府门户网站向社会公开。

责任单位：县法治政府建设工作领导小组成员单位、县委办、县政府办、县依法治县办，各乡（镇）党委、政府按相应职责分别负责

（四）提升履职能力。一是提高县级政府法制部门工作人员履职能力，加强县政府法制部门履行合法性审查、行政复议、执法监督、依法行政业务能力，配齐配强专（兼）职人员。二是加强行政执法、行政复议和政府法律顾问队伍建设，创新政府法治人才选拔、培养机制。三是加强行政执法部门专（兼）职法制人员的配备。

责任单位：县委编办、县委组织部、县人社局、县司法局、县政府法制办

（五）深化行政审批制度改革。一是全面清理行政审批事项，取消非行政许可审批事项，承接落实国务院、省政府取消下放的行政审批事项。二是对保留的行政审批事项，实行目录化、编码化管理。2017年，实现行政审批服务部门进驻政务中心100%，行政审批服务事项进驻服务窗口100%。三是加快推进投资项目在线审批监管平台建设，实施在线监测。

责任单位：县政务服务中心、县发改经信局、县委编办、县公共资源交易中心、各乡（镇）人民政府按相应职责分别负责

（六）明晰政府权责。一是实行权责清单动态调整管理，公布县级行政权力责任清单，并上网运行。二是实行行政事业性收费和政府性基金目录清单制度，按照上级财政部门相关规定调整、公布行政事业性收费和政府性基金清单。三是推进机构、职能、权限、程序、责任法定化，优化机构设置，理顺职责关系，根据职能调整核定“三定”方案，优化工作流程，界定部门责任。四是2017年底前，各级行政机关建立健全各项工作制度，重点将权力事项、办事程序、执法流程以及部门工作所依据的主要法律、法规、规章等汇编成册、公开发布，推进制度规范全覆盖。五是全面实施工商营业执照、组织机构代码证、税务登记证等“五证合一”、“一照一码”。 按照国家、省、州的统一部署，推行电子营业执照和全程电子化登记，实行“一址多照”和“一照多址”。

责任单位：县发改经信局、县委编办、县财政局、县工质食药监局、县国税局、县地税局、县政务服务中心、县政府法制办，有收费基金项目的、其他有行政权力事项的县直部门，各乡（镇）人民政府按相应职责分别负责

（七）推进“诚信阿坝”建设。一是严格执行行政决定事项，撤销或变更已生效的行政决定须有法定事由并经法定程序。严格履行合同和协议，依法履行判决、裁定、行政复议、仲裁决定等生效法律文书。二是建立公务员诚信档案，将公务员个人重大事项报告、廉政记录、违法违纪违约行为等信用信息纳入档案，将公务员诚信记录作为考核、任用和奖惩的重要依据。三是实行公务员晋升依法行政考核制度。

责任单位：县级各部门、各乡（镇）人民政府按相应职责分别负责

（八）完善社会管理。编制社会组织提供的公共服务目录，建立网络社团管理机制，完善立体化社会治安防控体系，全面落实“党政同责、一岗双责、齐抓共管、失职追责”的安全生产责任体系，落实政府购买公共服务制度，贯彻执行阿坝州生态环境保护条例、湿地保护条例、野生动物植物保护条例、实施草原法的变通规定等民族自治法规，制定排污权有偿使用出让标准，完善生态环境损害责任追究配套制度等，完善社会管理制度。实行对领导干部的离任审计。

责任单位：县发改经信局、县公安局、县民政局、县安全监管局、县环林局、县财政局、县农牧水局、县国土资源局、县监察局、县审计局、县综治办、各乡（镇）人民政府按相应职责分别负责

二、完善依法行政制度体系

（九）加强规范性文件监督管理。一是落实规范性文件合法性审查制度，未经合法性审查或审查不合法的，不予审议印发。落实规范性文件统一登记、统一编号、统一公布制度。二是完善规范性文件备案审查制度，依法及时报备。加强备案审查能力建设，把所有规范性文件纳入备案审查范围，加大备案审查力度，做到有件必备、有备必审、有错必纠。三是健全公民、法人和其他组织对规范性文件的建议审查制度。对公民、法人和其他组织提出的规范性文件异议审查申请，依法及时处理并反馈处理结果。四是实行规范性文件动态管理制度，每2年开展一次行政规范性文件清理工作。2017年底，完成2015年5月1日至2017年4月30制发的规范性文件清理工作，清理结果向社会公布。五是按照国家、省、州的统一部署，对县人民政府成立以来的政府文件对照清理标准、工作要求进行全面清理，向上级人民政府报告清理结果。

责任单位：县政府办、县政府法制办、县直各部门、各乡（镇）人民政府按相应职责分别负责

三、推进行政决策科学化、民主化、法治化

（十）健全行政决策机制。一是贯彻执行重大行政决策公众参与、专家论证、风险评估、合法性审查、集体讨论决定制度。广泛听取群众特别是利害关系人的意见建议，全面落实专家论证、社会稳定风险评估机制，完善行政机关内部重大决策合法性审查机制，未经合法性审查或经审查不合法的，不得提交讨论。2017年底，实现合法性审查制度全覆盖。二是落实《阿坝州党委法律顾问工作制度》《阿坝州人民政府法律顾问团管理办法》，充分发挥法律顾问作用。

责任单位：县政府办、县政府法制办、县直各部门、各乡（镇）人民政府按相应职责分别负责

（十一）落实行政决策责任。贯彻执行《四川省重大行政决策责任追究暂行办法》《关于对州委州政府重大决策部署执行不力实行问责的办法（试行）》。建立健全并严格实施重大决策终身责任追究制度及责任倒查机制。对决策严重失误或依法应该及时作出决策但久拖不决造成重大损失、恶劣影响的，追究相关责任人员的党纪政纪和法律责任。

责任单位：县监察局、县政府法制办、县直各部门、各乡（镇）人民政府按相应职责分别负责

四、坚持严格规范公正文明执法

（十二）加强重点领域行政执法。加强市场监管、环境保护、安全生产、道路交通、公共卫生、民族宗教、旅游、扶贫等领域执法力度。完善食品、药品、农畜产品等重要商品安全和违反公平竞争秩序的失信惩戒制度，加大执法力度，严厉打击违法行为。

责任单位：县政府法制办、县直行政执法部门、各乡（镇）人民政府按相应职责分别负责

（十三）全面落实行政执法责任制。建立健全常态化责任追究机制。各级行政执法部门应将本部门的法定职权分解落实到执法机构和执法岗位,明确执法机构、执法岗位和执法人员的责任,并向社会公开。贯彻执行《阿坝州行政执法人员管理办法（试行）》。依法界定行政执法部门的主体资格、执法依据、职责权限并向社会公示。

责任单位：县委编办、县政府法制办、县直行政执法部门、各乡（镇）人民政府按相应职责分别负责。

（十四）加大培训力度。一是稳步推进“互联网+”培训模式，认真开展全县各级行政执法人员通用法律知识培训和考试工作。二是县级各部门要加大系统内执法专业人员的专业法律培训和考试，切实提高全县行政执法人员业务知识水平和能力。未通过资格考试的人员不得申领行政执法证，不得参与行政执法工作，严把执法队伍的“入口关”。

责任单位：县政府法制办、县直行政执法部门

（十五）加强行政执法监督工作。一是贯彻执行《阿坝州行政执法案件评查办法（试行）》《阿坝州行政处罚案卷评查标准（试行）》，开展执法案卷评审工作。二是县直行政执法部门制定案例指导制度，每年在县政府门户网站上公布2件以上典型案例。贯彻执行《四川省行政执法全过程记录制度》。杜绝随意执法、执法程序违法、执法证据不全等现象发生。三是贯彻执行《四川省行政执法监督条例》，加大重点领域的行政执法监督检查力度，落实行政执法权限争议协调机制，及时解决行政执法机关之间的权限争议。

责任单位：县政府法制办、县直行政执法部门

（十六）推进行政执法和刑事司法衔接机制。完善案件移送标准和程序，建立健全法制机关、行政执法机关、公安机关、检察机关、审判机关信息共享、案情通报、案件移送制度。坚决杜绝有案不移、有案难移和以罚代刑等现象。定期召开“两法衔接”全体成员联席会议，通报工作开展情况。

责任单位：县检察院、县法院、县监察局、县公安局、县国安局、县政府法制办，其他有行政执法职责的县直部门按相应职责分别负责

（十七）加强行政复议工作。落实行政复议委员会制度，发挥行政复议工作的纠错、监督功能。及时回应司法建议和行政复议建议，办理情况抄送本级政府法制机构。

责任单位：县政府法制办、县直各部门，各乡（镇）党委、人民政府按相应职责分别负责

（十八）依法有效化解社会矛盾纠纷。建立健全社会矛盾预警机制，完善依法应对群体性及突发性事件预案。完善救济救助机制。健全行政调解制度，规范调解程序。完善信访工作机制，实行涉法涉诉信访与普通信访相分离。认真落实《阿坝州行政机关行政应诉办法》，按照“谁主管谁应诉”、“谁主办谁出庭”的原则强化各级行政机关及其工作人员行政应诉的法定职责。2017年开始，规范使用四川省统一行政应诉法律文书。

责任单位：县直各部门、各乡（镇）人民政府按相应职责分别负责

五、强化对行政权力的制约和监督

（十九）自觉接受党内监督、人大监督、民主监督、司法监督。一是建立健全党风廉政建设检查考核制度机制，明确检查考核的内容、方法、程序。二是认真执行向本级人大及其常委会报告工作制度，接受询问和质询。三是健全知情明政机制。政府有关部门向政协定期通报有关情况，为政协委员履职提供便利、创造条件。四是积极配合检察机关对行政违法行为依法进行监督。

责任单位：县纪委、县政府办、县政府法制办等县直有关部门，各乡（镇）党委、人民政府按相应职责分别负责

（二十）加强行政监督和审计监督。一是加强政府法制监督。二是加强对政府内部权力的制约，防止权力滥用。三是建立健全监察监督工作机制，确保廉政建设各项任务落实。

责任单位：县直各部门、各乡（镇）人民政府。

六、全面推进政务公开

（二十一）加大政务公开力度。按规定编制、修订、公布政府信息公开指南和政府信息公开目录，并及时更新。完善政府信息主动公开、发布协调、工作考核、社会评议、年度报告、责任追究等配套制度，明确政府信息公开范围、内容、方式和程序。依法受理并在法定期限内及时答复公民、法人和其他组织提出的政府信息公开申请。完善政府新闻发言人、突发事件信息发布等制度，做好对热点敏感问题的舆论引导，及时回应人民群众关切。创新政务公开方式，加强互联网政务信息数据服务平台和便民服务平台建设，提高政务公开信息化、集中化水平。

责任单位：县政府办、县政府信息公开办、县委宣传部，各乡（镇）党委、政府按相应职责分别负责

七、加强政府工作人员法治思维和依法行政能力建设

（二十二）全面落实领导干部学法制度。严格落实政府常务会议和部门办公会议学法制度。贯彻执行《壤塘县人民政府常务会议学法制度》。县政府每年至少举办1期领导干部法治专题培训班和2期以上法治专题讲座。

责任单位：县政府办、县政府法制办等县直有关部门，各乡（镇）党委、人民政府按相应职责分别负责

（二十三）强化考核评价。一是建立法治政府建设责任人约谈制度。对法治政府建设考核结果较差的乡（镇）和部门，约谈主要领导或分管负责人，情节严重的予以行政问责。二是邀请“两代表一委员”，组织企事业单位、新闻媒体和社会公众，或委托专门的评估机构，采取座谈、走访、发放评估卡、意见书等方式，每年至少开展一次法治政府建设工作评估。

责任单位：县委组织部、县监察局、县人大办、县政协办、县政府法制办，各乡（镇）党委、人民政府按相应职责分别负责。
