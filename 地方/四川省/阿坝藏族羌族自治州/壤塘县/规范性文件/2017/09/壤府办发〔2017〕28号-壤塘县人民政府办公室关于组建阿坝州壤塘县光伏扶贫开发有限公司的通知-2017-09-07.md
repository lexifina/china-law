# 壤塘县人民政府办公室关于组建阿坝州壤塘县光伏扶贫开发有限公司的通知

壤府办发〔2017〕28号

各乡（镇）人民政府，县级各部门，各企事业单位 :

为贯彻落实《国家发展改革委等五部门关于实施光伏发电扶贫工作的意见》（国能新能〔2016〕621号）及光伏扶贫相关政策文件精神，加快推进壤塘县光伏扶贫工作，经县人民政府研究决定，由壤塘县扶贫产业开发有限责任公司作为县人民政府光伏扶贫投融资平台公司，代表县域内建档立卡贫困户参与光伏扶贫电站投资，与国家电投集团四川电力有限公司共同组建阿坝州壤塘县光伏扶贫有限公司，作为壤塘县光伏扶贫电站（壤塘县嘎咔4万千瓦集中式光伏电站）实施主体和承贷主体。

壤塘县人民政府办公室

2017年9月7日
