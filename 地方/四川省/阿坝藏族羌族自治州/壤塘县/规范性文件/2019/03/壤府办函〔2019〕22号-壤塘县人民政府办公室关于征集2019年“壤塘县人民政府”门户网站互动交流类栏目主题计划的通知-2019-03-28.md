# 壤塘县人民政府办公室关于征集2019年“壤塘县人民政府”门户网站互动交流类栏目主题计划的通知

壤府办函〔2019〕22号

各乡（镇）人民政府，县级各部门：

为进一步强化“壤塘县人民政府”门户网站政民互动功能，做好2019年网站互动交流类栏目内容保障工作，现向各乡（镇）人民政府、县级各部门征集互动交流类栏目主题计划。请对照“壤塘县人民政府”门户网站互动交流类栏目简介（详见附件1），围绕县委、县政府中心工作和群众关心的热点、焦点问题，结合工作实际，认真策划，提出本单位参与互动交流类栏目的主题计划，并将其列入本单位政务公开和信息公开的重要内容，明确专人负责，主动加强与县政府信息公开办的联系沟通。各乡（镇）人民政府、县政府各部门至少选择1个栏目模块确定1项主题计划。同时，欢迎县委各部门主动参与互动交流工作。

各乡（镇）人民政府、县级各部门确定主题计划后，认真填写《“壤塘县人民政府”门户网站2019年互动交流类栏目主题计划征集表》，并于2019年4月15日前，报县政府信息公开办（各单位填报的征集表须经单位分管领导审核把关并加盖单位印章，同时报送电子文档）。各乡（镇）人民政府、县政府各部门互动交流类栏目主题计划上报及落实情况，纳入2019年度政府信息公开绩效考核内容。

附件1

“壤塘县人民政府”门户网站互动交流类

栏目简介

“壤塘县人民政府”门户网站互动交流类栏目，是加强政府与社会公众互动交流，深化政务公开，切实保障公众的知情权、参与权、表达权、监督权的重要载体和创新渠道，主要包括在线访谈、新闻发布、意见征集、网上调查4个功能模块。

一、在线访谈

栏目通过在线访谈的形式（全程视频录制），邀请各乡（镇）人民政府、县政府各部门负责人解读重点、热点工作的政策规定和推进情况，在线回答公众关心的问题和咨询。每期在线访谈时间控制在20分钟之内。节目制作后，在网站播出，并辅以图片、文字发布。

二、新闻发布

栏目通过召开新闻发布会的形式（全程视频录制），由单位新闻发言人对重点工作部署及其推进情况、经济形势、政策法规解读等方面的工作向社会进行发布和权威解读。新闻发布会全程摄录，视频、文字和图片在网站发布。新闻发布主题计划需同时报县政府信息公开办备案审批。

三、意见征集

根据县委、县政府工作规则和重大决策规则的相关规定，各乡（镇）人民政府、县政府各部门在作出重大决策、推进重点工作过程中，应当将公众参与作为必经程序和重要环节。意见征集栏目主要功能，即在作出重大决策、推进重点工作的过程中，特别是贯彻地方法规和规范性文件制定过程中，为面向社会各界征求意见和建议搭建的工作平台。

四、网上调查

栏目功能与意见征集基本一致，与意见征集为完全开放式平台，不设置任何参考答案。不同之处在于，网上调查根据调查的问题，结合实际设置多项参考答案供参与调查的公众选择，成为收集舆情民意、为领导决策提供参考依据的统计分析工具。

各栏目具体情况，请点击“壤塘县人民政府”门户网站参阅。
