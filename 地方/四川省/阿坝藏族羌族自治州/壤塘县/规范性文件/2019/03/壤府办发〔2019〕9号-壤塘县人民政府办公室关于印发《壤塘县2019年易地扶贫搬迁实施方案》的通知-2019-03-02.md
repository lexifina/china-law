# 壤塘县人民政府办公室关于印发《壤塘县2019年易地扶贫搬迁实施方案》的通知

壤府办发〔2019〕9号

各乡（镇）人民政府，县级各部门：

《壤塘县2019年易地扶贫搬迁实施方案》经十四届县人民政府第28次常务会议研究通过，现印发你们，请遵照执行。

壤塘县人民政府办公室

2019年3月2日

壤塘县2019年易地扶贫搬迁实施方案

易地扶贫搬迁是针对贫困地区、贫困农村人口实施精准扶贫、精准脱贫的重要举措，是实现脱贫奔康的有力抓手，在总结工作经验的基础上，根据全县2019年脱贫攻坚决战决胜工作要求，结合《壤塘县“十三五”易地扶贫搬迁实施方案（2016—2019）》和壤塘县易地扶贫搬迁工作专题会会议精神，特制定本实施方案。

一、基本情况

“十三五”时期我县计划实施易地扶贫搬迁2992人，2016年至2018年已完成730户2992人的搬迁任务。2019年，将全面完成各项扫尾工程建设任务，巩固脱贫攻坚成果。

二、建设目标

认真贯彻落实国家、省、州易地扶贫搬迁政策要求和县委十三届四次全会精神，结合全县脱贫攻坚基础设施建设工程，以高效务实的作风、常抓不懈的精神、严谨细致的举措，统筹完善易地扶贫搬迁户的安全饮水、安全用电、入户路、寨内路、健身广场、活动室等配套基础设施和公共服务设施建设。强化跟踪调查，关注搬迁群众的后续脱贫发展，产业支持及搬迁成效，实现搬迁群众搬得出、稳得住、能致富目标。坚持问题导向，对照省、州、县成效考核、专项督导及稽察发现的问题，找准找实易地扶贫搬迁工作推进中存在的薄弱环节和问题隐患，切实加强整改，全面提升搬迁工作成效。

三、工作内容

（一）推进配套基础设施建设项目

加强要素保障，扎实推进20个配套基础设施续建项目和壤塘村、康垄村2个新开工项目的实施，10月30日前全部竣工。

责任单位：各乡镇、县发改经信局

完成时限：2019年10月31日前

（二）加大资金拨付

2018年基础设施建设项目多，完工基建项目未完成结算，大部分支付了70%的进度款，资金拨付成为一大难题，2019年，督促竣工配套基础设施建设项目完成结算，完成包括前期、监理、设计等所有费用支付。

责任单位：各乡镇、县发改经信局、县财政局、县审计局

完成时限：2019年12月10日前

（三）抓好问题整改

坚持问题导向，结合省、州巡察督查反馈的问题，主动自查我县易地扶贫搬迁存在的问题，不遮丑不回避，积极抓好问题整改。

1.对象识别方面。重点检查是否按照规定程序进行评议、审核和公示，精准确定搬迁对象；搬迁对象是否为建档立卡贫困户；是否对居住在深山、荒漠化、地方病多发等生存环境差、不具备基本发展条件，以及生态环境脆弱、限制或禁止开发地区等“一方水土养不活（好）一方人”地方的建档立卡贫困人口实施易地搬迁，优先安排位于地震活跃带及受泥石流、滑坡等地质灾害威胁的建档立卡贫困人口；是否建规将危旧房、无房纳入易地扶贫搬迁；是否重复享受政策；搬迁人口与全国扶贫开发信息系统标记是否一致。

责任单位：各乡镇、县发改经信局、县扶贫移民局

完成时限：2019年3月31日前

2.住房建设方面。重点检查是否严格执行人均住房面积不超过25平方米，最大住房面积不超过150平方米要求；对超面积住房是否完成整改；是否注重功能用房区分，卧室、客厅、厨房等功能必须隔离；住房面积严重不达标是否整改；装修是否合理，新建房屋外观风貌融合村容村貌，按照当地民俗特色装饰装修，地面平整，房屋吊顶，铺设地板、地毯或地板胶，墙面贴墙纸、刮涂料或板材装饰；是否按居家环境改善要求配置生活用品：坐床、茶几、碗柜、火炉、锅碗瓢盆等；是否具备合法用地手续；是否拆除旧房；是否对易地扶贫搬迁原址复垦复绿。

责任单位：各乡镇、县发改经信局、县住建局、县国土局

完成时限：2019年6月30日前

3.科学选址方面。重点检查是否原址重建；安置地资源条件和承载能力是否满足搬迁人口需要；安置点是否靠近乡（镇）政府、村委会、学校、卫生院，交通是否便利；是否开展地质灾害、洪涝灾害危险性评估；是否严格审核住房选址条件；配套基础设施、公共服务设施是否完善。

责任单位：各乡镇、县发改经信局、县扶贫移民局、县国土局

完成时限：2019年6月30日前

4.搬迁成效方面。重点检查是否对住房安全开展评估；是否有住房安全验收合格材料；是否有产业支撑；搬迁后是否有增收渠道（收入来源）；能否达到稳定脱贫状态；是否真正入住；强化住房管护，对漏雨墙裂等现象进行修复整改。

责任单位：各乡镇、县发改经信局、县住建局、县扶贫移民局、县农业畜牧和水务局

完成时限：2019年6月30日前

5.宣传培训方面。重点检查县政府是否每年至少组织召开2次易地扶贫搬迁工作推进会；县发改经信局、扶贫移民局等是否每年至少组织4次易地扶贫搬迁政策培训；各乡镇每年是否至少组织6次易地扶贫搬迁政策宣传培训；开展易地扶贫搬迁的每一名干部是否做到人人熟悉政策。

责任单位：各乡镇、县政府办、县发改经信局、县扶贫移民局

完成时限：2019年12月31日前

6.资金落实方面。重点检查建房补助是否发放到搬迁户手中；搬迁户（包括进城购房的）户均自筹建（购）房资金不超过1万元；搬迁户是否因建房而举债，因举债而难脱贫；搬迁户是否知晓补助标准；搬迁户是否清楚建房费用支出构成；是否建立户明白卡或一本明细账；乡镇发放补助是否有佐证材料用；是否存在资金挤占、挪用、沉淀等问题；申请材料是否缺失、造假；各乡镇是否建立易地扶贫搬迁资金拨付备查账；是否规范按照会计制度开展会计核算。

责任单位：各乡镇、县发改经信局、县财政局、县国资公司

完成时限：2019年5月31日前

7.配套基础设施建设方面。重点检查新开工项目是否开工；项目是否完工、审结；资金拨付是否完成；是否落实项目法人制、招投标制、工程监理制和合同管理制“四制”；年度计划项目开工率及工程建设进展情况；跨年度项目建设情况；是否落实安置区的规划设计及工程质量监管；工程质量监理和竣工验收是否符合相关规定和要求；项目档案是否按照一项目一档案管理，进行分类、编号、造册。

责任单位：各乡镇、县发改经信局、县住建局、县审计局、县扶贫移民局

完成时限：2019年12月31日前

8.档案管理方面。重点检查是否确定专人负责易地扶贫搬迁档案收集工作；是否建立健全相关制度；是否分“乡（镇）、村、户”做好易地扶贫搬迁档案管理工作；是否在国家扶贫开发信息子系统和省“六有”大数据平台及时完善易地扶贫搬迁工作对象动态管理、项目实施、资金使用、脱贫举措等信息。

责任单位：各乡镇、县发改经信局、县扶贫移民局

完成时限：2019年10月31日前

五、保障措施

（一）加强组织领导。成立以县长为组长，分管扶贫的副县长为副组长，县发改经信局、县监察委等部门和乡（镇）相关负责人为成员的壤塘县易地扶贫搬迁后续工作领导小组，下设办公室于县发改经信局。县级有关部门在壤塘县易地扶贫搬迁后续工作领导小组的领导下，密切配合、形成合力，全面落实搬迁目标、任务、资金、权责“四到位”制度。乡镇是易地扶贫搬迁的工作主体、责任主体、实施主体，要确保措施有力、落实到位。

（二）健全工作机制。各乡镇要建立健全领导机构，明确2019年易地扶贫搬迁任务，主要领导要亲自抓，分管领导要具体抓，落实骨干力量专人负责报表信息、统计数据和档案管理工作。相关部门要明确具体负责的易地扶贫搬迁工作任务，做好乡村业务服务和指导工作。

（三）规范资金管理。加强易地扶贫搬迁资金监管，严格执行国家易地扶贫搬迁资金有关管理办法，规范资金使用。易地扶贫搬迁资金要封闭运行、专款专用，严禁挪作他用。县监察委、发改经信、扶贫移民、财政、审计等部门要加强对资金使用管理的监督检查和指导。

（四）严格检查问责。县级层面组织力量分阶段开展监督检查，将易地扶贫搬迁实施情况纳入扶贫绩效考核范围，定期或不定期通报易地扶贫搬迁项目进展情况，对建设进度滞后的实行“一对一”督促检查。对工作不主动，工作不到位、效果不明显等问题要向县纪委监察委移送线索，确保易地扶贫搬迁工作有力、有序顺利推进。

附件：壤塘县易地扶贫搬迁后续工作领导小组
