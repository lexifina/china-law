# 壤塘县人民政府办公室关于印发《壤塘县加快一体化政务服务进程,进一步深化“互联网+政务服务”推进审批服务便民化，优化营商环境，建设服务型政府实施方案》的通知

壤府办发〔2019〕18号

各乡（镇）人民政府、县级相关部门：

因机构改革，对原政府第27次常务会议通过的《壤塘县进一步深化“互联网+政务服务”推进审批服务便民化，优化营商环境，建设服务型政府实施方案》进行了修改完善，现予以印发，请遵照执行。

壤塘县人民政府办公室

2019年4月30日

壤塘县加快一体化政务服务进程，进一步深化“互联网+政务服务”推进审批服务便民化，

优化营商环境，建设服务型政府实施方案

为深入贯彻习近平新时代中国特色社会主义思想和党的十九大精神，认真落实《国务院关于加快推进全国一体化在线政务服务平台建设的指导意见》（国发〔2018〕27号）《国务院办公厅关于印发进一步深化“互联网+政务服务”推进政务服务“一网、一门、一次”改革实施方案的通知》（国办发〔2018〕45号）和《四川省人民政府关于印发加快推进四川省一体化政务服务平台建设进一步深化“互联网+政务服务”工作实施方案的通知》（川府发〔2018〕42 号）要求，加快推进一体化政务服务平台建设工作，全面实现政务服务“一网通办”和企业群众办事“只进一扇门”“最多跑一次”目标，不断推进审批服务便民化，优化营商环境，建设服务型政府。现结合壤塘实际，制订本实施方案。

一、指导思想

坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大精神，加大转变政府职能和简政放权力度，以更快更好方便企业和群众办事创业为导向，坚持以人民为中心、依法依规、放管并重、放管结合、体制创新和机制创新相结合的原则，围绕直接面向企业和群众、依申请办理的行政审批和公共服务事项，推动审批服务理念、制度、作风全方位深层次改革，最大限度提高企业和群众办事便捷性，不断优化办事创业和营商环境，努力建设人民满意的服务型政府，为加快建设“美丽壤巴拉家园”提供坚强保障。

二、目标和任务

根据省、州统一要求，到2019年6月底，除法律法规另有规定或涉及国家秘密等外，实现审批服务事项“最多跑一次”比例达90%以上，网上可办率不低于50%，基本实现所有事项“马上办、网上办、就近办、一次办”全覆盖。到2020年年底前，互联网与政务服务深度融合，大数据服务能力显著增强，政务服务质量与实效大幅提升，热点高频事项实现“掌上办”“减证便民”行动成效明显，中介服务规范有序，基本建成审批服务标准化体系和审管衔接、监管到位的事中事后监管体系，实现“宽进、快办、严管、便民、公开”的审批服务模式，为持续推进“放管服”改革、推动政府治理现代化提供强有力支撑。

三、重点工作及责任分解

（一）高质量完成一体化政务平台对接任务。

1.全方位对接。按照《四川省人民政府关于印发加快推进四川省一体化政务服务平台建设进一步深化“互联网+政务服务”工作实施方案的通知》（川府发〔2018〕42 号）要求，一是涉及审批服务事项的部门要确定1名分管领导，1名行政审批股室负责人和2名业务人员分别作为负责政务服务工作的首席代表和窗口、后台工作人员进驻政务中心。二是负责制定单位实施方案，从办事服务入口整合、统一身份认证、政务服务办理系统对接、电子证照对接、电子印章对接、公共物流配套系统对接、公共支付系统对接、网络对接、数据返还接口对接、安全保障体系对接等方面进行全面对接；三是按照统一的时间表和路线图完成本部门清单梳理和授权等工作任务。

2.统一服务平台。依托全省一体化政务服务平台，实现线上线下“一套服务标准、一个办理平台”。一是统一线上线下办事编码；二是与企业和群众相关的电子证照、申请材料、办理事项等政务服务信息要形成相应目录清单；三是与省一体化政务服务平台深度对接融合，实现省一体化平台系统与各部门业务系统平台互联互通、数据共享、业务协同，持续提高办事材料线上线下共享复用水平，实现办理流程和评价标准统一，形成形式统一规范、内容深度融合的政务服务公共入口；四是有项目审批权限的相关部门还要负责四川省投资项目在线审批平台办理；五是实现事项集中发布、服务集中提供，为企业群众办事“一网通办、全国漫游”提供支撑保障。

3.对接四川政务服务网。各部门现有网上办事大厅已全部关停并转，通过四川政务服务网地方和部门站点配置和展示，统一网上政务服务进出口，推动政务服务事项清单、办事指南、办理状态等相关信息在政务服务平台、移动终端、实体大厅、政府网站和第三方互联网入口等政务服务渠道同源发布。

牵头部门：县行政审批局

责任单位：县级各部门、各乡镇人民政府

完成时限：2019年3月30日前完成

（二）全面推行审批服务标准化。

4.建立政务服务事项动态管理机制。实施并完善清单管理，动态调整、公布“最多跑一次”“全程网办”“就近办”“马上办”审批服务事项清单，其中“最多跑一次”的事项占比应当达到90%以上。

5.规范政务服务事项标准。按照全省政务服务事项标准统一的要求，同一事项在统一名称、编码、依据、类型等基本要素的基础上，完善政务服务事项受理条件、申请材料、中介服务、办理流程等信息要素，以依申请办理的行政权力事项和公共服务事项为重点，推动实现办事指南中主项名称、子项名称、设定依据、法定时限、申请材料、申请表单“六统一”，原则上各部门不得自行修改、增减标准和另设要求。

6.进一步优化政务服务流程。将涉及跨层级多部门的事项归并整合、优化改造，建立一体化的办事规范和办理流程，打通层级间、部门间办事环节，形成跨层级、跨部门协同联办机制，推动更多政务服务事项的申请、受理、审查、决定、制证、公开、收费、咨询等环节全流程在线办理，实现“一件事”全流程“最多跑一次”，逐步实现所有政务服务事项在全省一体化政务服务平台统一流转。

7.全面推行审批服务“马上办、网上办、就近办、一次办”。推动合法合规事项“马上办”，一般事项“网上办”，面向个人事项“就近办”，复杂事项“一次办”，其中“最多跑一次”的事项占比应当达到90%以上。

8.全面推进“一网通办”。凡是能在四川政务服务网办理的事项，不得要求企业和群众必须到现场办理。

牵头部门：县行政审批局

责任单位：县级各部门、各乡镇人民政府

完成时限：2019年6月30日前

（三）持续开展“减证便民”行动。

9.各部门要对照事项进行清理，精简办事材料、缩短办理时限。凡是没有法律法规依据的办事材料一律取消；凡是企业和群众提交过且能够复用的办事材料不得要求重复提交；凡是全省一体化政务服务平台和各部门政务信息资源共享交换平台能够核验的信息不得要求企业和群众重复提交。要做好办事材料目录化、标准化、电子化，开展在线填报、在线提交、在线预审和在线审核，推动证照、办事材料、数据资源共享互认，减少不必要的重复举证。

牵头部门：县行政审批局

责任单位：县级各部门、各乡镇人民政府

完成时限：2019年底前，企业和群众到政府办事所提供的材料减少60%以上

（四）推行审批服务集中办理。

10.推进“一门”服务。部门进驻大厅办理比例不低于80%。

11.全力推进“一窗受理、分类审批、统一出件”工作模式。将政务服务中心原来分设在各个部门的服务窗口整合为综合受理窗口，优化一体化政务服务平台一窗受理和智能表单功能，集成多证合一、多图联审、多规合一、告知承诺、容缺受理、并联审批、多级联办等服务功能，推动实现更多事项一窗进出、一次告知、一表申请、一次办成。2019年6月底前，投资项目审批、工程建设项目审批、商事登记、不动产交易登记、医保社保、公安服务等领域政务服务事项完成50%以上政务服务事项“一窗受理”，2019年年底前，达到80%以上，2020年年底前，所有政务服务事项实现“一窗受理”。

12.大力推行“网上办理”。50%以上审批服务事项实现网上办理。

牵头部门：县行政审批局

责任单位：县级各部门、各乡镇人民政府

完成时限：2019年底前

（五）着力提升“互联网+政务服务”水平。

13.加快实现信息联通互享。加快建设州、县（市）两级政务信息资源共享交换平台，持续优化完善政务信息资源目录，推动部门自有政务信息系统接入全省统一的数据共享交换体系，实现人口、法人、社会信用、空间地理等基础信息资源及公共资源交易、投资、交通、旅游等重点领域信息共享。有序推进电子证照、电子公文、电子印章等应用。建立统一的政务数据服务平台。

14.推进线上线下深入融合。运用大数据，以审批智能化、服务自助化、办事移动化为重点，整合实体大厅、网上平台、移动客户端、自助终端、12345服务热线等，依托省、州、县、乡、村五级线下政务服务体系，优先推动教育、医疗、民政、社保、医保、养老、生育、公安、住房、纳税、信用等方面民生事项“一证通办”，实现企业群众“只凭一张证，办成所有事”。

牵头部门：县行政审批局

责任单位：县级各部门、各乡镇人民政府、县政府信息办

完成时限：与州同步，2019年底前完成

（六）创新便民利企审批服务方式。

15.推动更多政务服务事项“掌上办”。以自然资源、税务、公安、人力资源和社会保障、教育、卫生健康、民政、住房和城乡建设、交通运输等领域为重点，积极推进覆盖范围广、应用频率高的政务服务事项的咨询、申请、支付、查询、评价等环节在移动端办理，推动更多政务服务事项“掌上办”。2019年年底前，30个高频事项实现“最多跑一次”，2020年年底前，100个高频事项实现“最多跑一次”。

牵头部门：县行政审批局

责任单位：县自然资源局、县人力资源和社会保障局、县教育局、县卫生健康局、县民政局、县住房和城乡建设局、县交通运输局、县税务局、县公安局及县级相关部门、各乡镇人民政府。

完成时限：与州同步

16.推进重点领域改革。按照国家、省部署开展“证照分离”改革，推进“照后减证”，进一步压缩企业开办时间。实行企业投资项目“多评合一”、并联审批，推行线上全程电子化登记，规范实施“多证合一”。对无前置审批、企业名称核准与设立登记为同一机关的，企业设立登记办理时限压缩至3个工作日。在建设工程领域全面推行联合勘验、联合审图、联合测绘、联合验收。对国家鼓励类企业投资项目探索不再审批。对不新增用地“零土地”技改项目推行承诺备案制。在实行“多规合一”基础上，探索“规划同评”。

牵头部门：县行政审批局

责任单位：县行政审批局、县发展和改革局、县经济商务和信息化局、县住房和城乡建设局、县自然资源局、生态环境局、县市场监督管理局、县林业和草原局、县委编办

完成时限：2019年12月底前有突破性进展

17.积极创新便民服务举措。加快推进办理居民身份证、驾驶证、出入境证件、医保、社保、住房公积金等便民服务事项互联互通、在线可查、异地可办。推广容缺后补、告知承诺、快递送达等便利化措施和预约办理、异地代办、跨层联办等服务方式，对量大面广的个人事项，鼓励利用银行、邮政等网点实现服务端口前移。在农村地区推行代缴代办代理等便民服务。

牵头部门：县行政审批局

责任单位：县公安局、县卫生健康局、县人力资源和社会保障局、县市场监督管理局、阿坝州住房公积金管理中心壤塘县管理部

完成时限：2019年12月底前

（七）深化行政审批中介服务改革

18.清理公布中介服务事项清单。清理公布保留的审批中介

服务事项清单，明确办理时限、工作流程、申报条件、收费标准。依托政务服务网，建设中介服务网上交易平台，中介服务机构“零门槛、零限制”入驻，实现网上展示、网上竞标、网上中标、网上评价。

牵头部门：县行政审批局

责任单位：县发展和改革局、县经济商务和信息化局、县司法局

完成时限：2019年6月底前

四、保障措施

（一）建立完善工作体系。

1.加强组织领导。成立由县人民政府县长为组长，常务副县长为执行副组长，副县长为副组长，县政府办、县政府信息公开办、县委编办、县行政审批局和县级各部门、电力、通信、银行、邮政等为成员的政务服务推进领导小组，建立健全县域“互联网+政务服务”管理协调机制，整合运营资源，加强技术支撑和运营管理队伍建设，加强对一体化政务服务平台和实体大厅运行管理的组织协调和评估考核。

2.强化工作机构。以国家机构改革为契机，以县行政审批局牵头，负责统筹协调全县审批服务便民化工作的推进。乡镇要建立健全便民服务中心机构，落实主任和窗口工作人员和职责。

3.强化工作职能。各行权部门作为主体责任部门，要落实政务服务分管领导、审批股室负责人和工作人员及其责任，要在进驻政务大厅业务人员的配置和业务能力等方面给予充分保障，窗口人员至少1-2名，后台人员至少1名，按要求逐步将审批服务事项划转行政审批局开展本部门审批服务工作。要完善办事指南、办事流程。

（二）强化“三集中、三到位”，实现“真入驻”。

1.人员要进驻。除涉密和场地限制外的所有行权部门，按照进驻大厅比例不低于80%的要求，第一批安排县发展和改革局、县经济商务和信息化局、县教育局、县民宗局、县公安局、县民政局、县司法局、县财政局、县人力资源和社会保障局、县自然资源局、生态环境局、县林业和草原局、县住房和城乡建设局、县交通运输局、县科学技术和农业畜牧局、县市场监督管理局、县文化体育和旅游局、县卫生健康局、县城市管理局、县残联、阿坝州住房公积金管理中心壤塘县管理部等21个部门进驻政务大厅，安排并授权单位审批服务股室人员2 人入驻政务服务中心。县税务局按县政府统一安排，设分中心，由部门成立相应机构统一由县中心管理并按四川省一体化政务服务平台2.0进行受理办理，部门履行监管职能。

2.事项要授权。所有部门事项进驻大厅，交由窗口人员和后台人员统一受理和办理，由单位首席代表负责审批权限的把控。

3.实行“一站式”服务。进驻中心后实行“前台综合受理、后台分类审批、综合窗口出件”，杜绝“人员入驻、事项权限不入驻”和办事群众和企业“两头跑、反复跑”的现象。

（三）切实加强事中事后监管。

1.强化落实监管责任。健全责任清单制度，按照权责对等、权责一致的原则，厘清审批和监管权责边界，明确监管责任，健全工作会商、联合核验、业务协同和信息互通的审管衔接机制。

2.积极推进综合监管。推行“双随机、一公开”监管制度，在一定范围实施“一支队伍管执法”，推动执法力量和工作重心下沉，切实提高执法效能，推进规范执法、阳光执法。

3.建立长效监管机制。进一步强化工作协同，实现全流程监管。加快“一枚印章管审批”改革，进一步方便企业和群众办事创业。

（四）进一步提升政务服务功能。

1.加强乡镇便民服务中心、村（社区）服务站点建设。按照“利企便民”的原则，各部门依法按程序将政务服务事项下沉到乡镇便民服务中心、村（社区）服务站点。

2.进一步提升政务服务大厅功能标准化建设。一是完善管理职能。进驻政务大厅的单位人员应统一服从中心管理、考核。加大自有系统向四川省政务一体化服务平台对接和办事力度。二是改善服务环境。按照“应进必进”要求，增加政务大厅、服务场所面积，投入资金对现有大厅按照功能布局要求进行适当整改，重点在群众等候区、便民服务区、窗口受理区、后台分类审批区、培训及会议区等进行调整和改造。三是提升大厅服务功能和能力。对县、乡两级服务大厅窗口、后台设施、设备进行补充完善，配齐电脑、打印、高拍仪、身份识别仪等硬件，升级电子政务外网，提升网络运转速度。

3.拓展政务服务渠道。通过与浙江温州和绵阳对口联系以购买服务方式，在县政务大厅和有条件的乡镇，利用政务服务一体机、银行、电力、邮政等自助服务终端信息化设备提高基层响应群众诉求和为民服务能力，实现企业群众办事“就近办”。充分发挥“两微一端”等新媒体和社会第三方平台拓展政务服务渠道，对已建政务服务移动端应尽快与全省一体化政务服务平台对接。

（五）加强队伍建设。

1.配齐配强政务服务业务骨干和工作人员。采取招聘、志愿者、公益性岗位等购买服务方式，解决政务中心没有工作人员和专业人才的问题。

2.加大业务培训力度。邀请省、州政务中心业务骨干到壤现场培训和指导，注重前台受理和后台分类审批人员的技能和业务提升。加大自有专业技术人员的培养力度，提升政务大厅管理和服务水平。

3.加强对窗口人员管理，健全考核激励机制。按照川委发〔2008〕11号和川府发〔2008〕38号文件精神，将对各部门窗口工作考核作为对该部门年度目标绩效综合考评的重要内容。一是各部门安排的窗口人员和后台人员，应相对固定，原则上应工作2年后方可调整。二是将窗口人员考勤、请销假、事项办理数量及质量等纳入政务中心对窗口个人业绩考评的主要内容，由政务中心统一管理，统一考核；三是部门事项进入率、窗口授权率、现场办结率、按时办结率、评议满意率、投诉率以及“三集中、三到位”情况、并联审批情况、窗口工作情况等行政效能指标与部门考核直接挂钩，纳入政府目标管理；四是对照《壤塘县目标绩效管理考核办法》，制定《壤塘县部门窗口及工作人员考核实施细则》。

4.统一县行政审批工作人员着装，树立整齐的窗口服务形象。

5.加强关心和指导。各部门领导要加强对窗口人员的关心关爱力度，分管领导要定期到窗口现场办公。

（六）加大宣传力度，提升“互联网+政务服务”利用率。

通过网络、电视、手机、报刊、广告等多种宣传形式，加大宣传力度，提高群众对“最多跑一次”改革的知晓率，提升“网办”率。

（七）加大政务服务工作的督查力度。

为进一步引起各部门对该项工作的重视，县委、县政府将政务服务工作推进情况，列入重点督查事项，行政效能监察机关要对各单位人员和事项进驻政务中心情况和有无“两头受理”现象进行督查，适时组织开展督查督办、明察暗访和评估检查。建立健全企业和群众满意度评价机制，定期开展满意度调查。对敷衍塞责、工作不力的要严肃问责，有力的推动“互联网+政务服务”工作、推进审批服务便民化，不断优化营商环境，建设人民满意的服务型政府。
