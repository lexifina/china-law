# 壤塘县人民政府办公室关于下达2019年县政府门户网站信息报送和目录管理系统填报发布目标任务的通知

壤府办函〔2019〕58号

各乡（镇）人民政府，县级各部门：

为响应阿坝州人民政府办公室关于报送政务信息的要求，进一步做好“壤塘县人民政府”门户网站内容保障工作，充分发挥政府网站政务公开第一平台的作用，县政府办公室对2019年“壤塘县人民政府”门户网站信息报送、目录管理系统填报发布目标任务进行了调整。现将《县政府门户网站信息报送和目录管理系统填报发布目标任务的通知》印发你们，请认真抓好落实。

各乡（镇）人民政府、县级各部门要高度重视内容保障工作，进一步拓展政务公开范围，加大政务信息发布力度，确保应当让社会公众广泛知晓或参与的事项及时在政府网站公开，努力提升政府网站的建管水平、运行效率和服务质量。目标任务完成情况纳入年终目标绩效考评，县政府办公室将继续采用“月度提醒、季度通报、半年督查、年度考评”的方式，强化督查，加大责任追究力度，对不履行主动公开义务的，予以通报。

各乡（镇）人民政府、县级各部门要切实提高信息报送质量，重大事件或有领导参与的活动、会议必须报送相关图片，图片要求清晰、质量高（背景环境整洁，领导无小动作等）。县级及以上领导参与的活动、会议简报需单位主要负责人签字后上报。本县重特大事件信息简报未及时上报的，追究相关部门责任，并在年度目标绩效考核评估指标中扣减1-3分。

附件3

2019年壤塘县政务信息公开工作目标任务考核办法

为进一步提升政务信息决策服务能力，依法加强政府信息公开工作，结合本县实际，制定本办法。

一、考核对象

纳入年底目标绩效考核的12个乡（镇）和45个县级部门，包含：消防队、交警队、社保局、就业局、新农保、疾控中心、卫生执法监督所和运管所等二级部门和省州直属部门。

二、考核办法

（一）政务信息目标绩效计分1分，满分100分，政府信息目标任务按比例和工作开展情况合理分解到每个季度，采用情况按季度进行通报，年终统一进行考核。

（二）对一次未完成季度目标任务的乡（镇）和县级部门，要求书面查找原因，并提出整改意见；对两次及以上未完成季度目标任务的乡（镇）和县级部门进行通报批评，视为未完成年度目标任务，由单位负责人向县政府写出书面检查，取消该乡（镇）、部门政务信息公开先进单位年度评选资格，并在年度目标绩效考核评估指标中扣减0.5-1分。

（三）对县政府办公室专题约稿信息、县政府领导批示要求反馈的信息不报、迟报以及报送信息失实造成不良后果的，在年度目标绩效考核评估指标中扣减1-3分。

三、记分办法

2019年政务信息考核采用计分制，信息被采用才能计分。

（一）“壤塘县人民政府”门户网站（www.rangtang.gov.cn）采用政务动态类信息计1分/条。

（二）“阿坝州人民政府”门户网站采用政务动态类文字信息计2分/条。

（三）省政府网站采用政务动态类文字信息计5分/条。

（四）获县委、县政府领导批示计3分/条。

（五）门户网站互动交流类栏目主题采用计2分/条。

四、报送要求

各乡镇及部门要高度重视信息上报工作，明确分管领导主抓政务信息工作，并落实专人负责信息的收集、整理、编写及上报等工作。及时将所报信息电子文档传送至壤塘县政府办邮箱（rt-zfb@abazhou.gov.cn，联系人：马倩、张宗雪；联系电话：2379296），以确保信息的时效性。凡涉密信息不得通过邮箱上报。报送范围及要求：

1.重点反映贯彻落实国家、省、州、县重大决策部署、重要决定指示的相关情况；各项民生工作的进展情况、取得的新成绩、提出的新思路、出现的新情况、遇到的新问题、具有推广价值和借鉴意义的新经验；干部群众的重要思想动态、重要社情民意等。

2.国家、省、州、县领导深入基层视察、调研、指导、督促工作的相关信息，并附图片资料。

3.反映经济发展、社会进步、社情民意等的重要信息、动态，加强综合分析。此类信息要选题准确、观点鲜明、文字精练、数据准确，基本情况、主要成效、主要做法及体会、下一步打算等，结构层次要分明。

4.信息在综合编写过程中，要注意基本要素不可缺少：动态性信息要有时间、地点、人物或单位、事件事由等要素；经验性信息要有时间、地点、单位、具体做法、效果等要素；问题性信息要有时间、地点、问题、原因及解决办法等要素。

信息编写要通顺、准确、简明，中心突出、条理分明；文句符合语法、逻辑，简洁易懂；时间、数字、人名、地名准确；主题正确、鲜明、突出，符合党的方针政策，与当前中心工作相吻合，要实事求是、不夸大和缩小事实；选好角度、突出特点，观点新颖、内容实在，言简意赅、朴实无华，不拘形式、生动活泼，要素齐全、内容完整。

对于信息报送未达到以上要求的，造成所报信息未被采用不能计分而影响年终目标考核的，后果自负；对因误报、延报、漏报等情况，造成不良舆论影响的，将进行全县通报，并扣减该单位政务信息目标绩效得分。
