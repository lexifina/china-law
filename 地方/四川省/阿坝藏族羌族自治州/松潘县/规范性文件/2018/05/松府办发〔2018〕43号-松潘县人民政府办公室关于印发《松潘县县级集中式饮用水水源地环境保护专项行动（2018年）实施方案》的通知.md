# 松潘县人民政府办公室关于印发《松潘县县级集中式饮用水水源地环境保护专项行动（2018年）实施方案》的通知

松府办发〔2018〕43号

松潘县人民政府办公室

关于印发《松潘县县级集中式饮用水水源地

环境保护专项行动（2018年）实施方案》

的通知

各相关单位，川主寺镇、山巴乡人民政府：

为贯彻党的十九大关于坚决打好污染防治攻坚战的决策部署，加快解决饮用水水源地突出环境问题，经县政府同意，现将《松潘县县级集中式饮用水水源地环境保护专项行动（2018年）实施方案》印发给你们，请抓紧落实。

特此通知。

松潘县人民政府办公室

2018年5月17日

松潘县县级集中式饮用水水源地环境保护

专项行动（2018年）实施方案

为贯彻落实党的十九大关于坚决打好污染防治攻坚战的决策部署，按照《全国集中式饮用水水源地环境保护专项行动方案》和长江经济带生态环境保护相关要求，切实解决好我县县级地表水型集中式饮用水水源地突出环境问题，根据县情实际，特制定本实施方案。

一、指导思想

以习近平总书记生态文明建设重要战略思想为指导，坚持生态优先、绿色发展，突出问题导向，加大环境保护执法力度，集中力量解决损害群众健康和影响绿色发展的突出环境问题，提升我县生态环境保护水平，保障饮用水安全，努力建设上中下游相协调、人与自然相和谐的绿色生态廊道。

二、工作目标和主要任务

工作目标：到2018年11月30日前，完成县级以上城市集中式饮用水水源地排查整治任务，全面清理饮用水水源保护区的环境问题，进一步提高饮用水水源地水质安全保障水平。

主要任务：严格执行环境保护法律法规，督促划定饮用水水源保护区并设立地理界标和警示标志，安装饮用水源地监控设备，排查整治饮用水水源保护区内的排污口和违法建设项目等环境问题。

三、工作内容

按照《环境保护法》《水污染防治法》《四川省饮用水水源保护管理条例》《饮用水水源保护区划分技术规范》《集中式饮用水水源地规范化建设环境保护技术要求》等法律法规和技术标准要求，主要开展以下三个方面的工作。

（一）建立健全饮用水水源保护区制度。根据饮用水划定方案，完善“一源一策”建档和管理制度。

（二）依法在饮用水水源保护区的边界设立明确的地理界标和明显的警示标识。

（三）清理饮用水水源保护区内环境违法问题。重点检查饮用水水源一级保护区内是否设有排污口、建有与供水设施和保护水源无关的建设项目、从事网箱养殖等违法行为，二级保护区内是否设有排污口、建有排放污染物的建设项目，是否存在违法从事网箱养殖等违法行为。

四、进度安排

（一）山巴乡第二自来水厂集中式饮用水水源地保护区。

一是完成山巴乡第二自来水厂集中式饮用水水源地保护区划定工作，并梳理、完善矢量边界信息制作，完善水源地基础信息档案。二是加强山巴乡第二自来水厂集中式饮用水源地水质监测。三是县财政局加强资金保障。四是由县环林局、山巴乡人民政府加强应急物资筹备以及保护区内的防护工程设施建设。

牵头单位：县环林局

责任单位：县农牧水局、县国土资源局、县财政局、山巴乡人民政府

完成时限：2018年11月30日前

（二）川主寺镇漳金四村县城集中式饮用水水源地保护区。

一是待山巴乡第二自来水厂集中式饮用水水源地保护区划定完成后，对川主寺镇漳金四村县城集中式饮用水水源地保护区调整进行论证，如需调整取消，必须依照《饮用水水源保护区划分技术方案》（HJ338—2018），按法定程序予以调整取消。二是严格整治饮用水水源地保护区环境违法行为，并制定水源地应急预案。三是加大环境监测人员培训以及监测设备建设，提升预防和应对供水生产突发事件的能力。四是每半年公开集中式饮用水源地水质检测情况，积极探索、实行一体化饮用水管理机制，明确部门责任。

牵头单位：县环林局

责任单位：县给排水厂、川主寺镇人民政府

完成时限：2018年11月30日前

五、组织方式

各相关部门，川主寺镇、山巴乡人民政府要高度重视此项工作，安排专人负责、统一部署，深入开展排查整治工作。在全面、深入、细致排查的基础上，对查出的问题要依法处理、分类处置。能整改的要责令立即整改；问题严重或单一部门难以解决的，县环林局要及时协调相关部门研究解决，重大问题按程序报县人民政府及相关部门研究解决。

各部门要采取联合执法、区域执法、交叉执法等方式，加强对川主寺镇漳金四村、山巴乡第二自来水厂两个县城饮用水水源地环境问题排查整治工作的督查，重要情况及时向县政府报告。

六、工作措施

（一）加强组织领导。各相关部门，川主寺镇、山巴乡人民政府要充分认识到保障群众饮水安全的重要意义，切实增强排查整治工作的责任感和紧迫感。由盛碧慧副县长牵头，统筹协调组织县环林局等相关部门共同推进整改，确保排查整治工作顺利推进。

（二）强化资金投入。饮用水环境问题整治涉及面广、问题复杂，资金需求大。财政部门要优先安排饮用水水源地整治资金，按照“构建政府为主导、企业为主体、社会组织和公众共同参与的环境治理体系”总体要求，综合运用政策、经济、行政等手段，充分发挥政府财政资金杠杆作用，加强社会资本合作，鼓励各类投资主体以多种模式参与饮用水水源地专项整治。

（三）整改落实到位。各相关部门，川主寺镇、山巴乡人民政府要落实水源地环境保护主体责任，根据排查情况制定专门整改工作方案。各相关部门，川主寺镇、山巴乡人民政府作为饮用水水源地环境问题整治工作的实施主体，要党政主要领导亲自挂帅，针对问题清单和各地自查、督查及排查中发现的问题，建立健全“问题清单”“责任清单”“整改清单”制度，按照“一个饮用水水源地、一套整改方案、一抓到底”原则，认真组织编制切实可行的整改工作方案，明确整改标准、时间结点、牵头部门和配合部门职责，整合各方资源，倒排工期，挂图作战，确保按时完成任务。要建立饮用水水源地管理档案（应包括饮用水水源保护区划定情况、地理界标和警示标志设立情况、水源地边界信息SHP矢量格式文件、饮用水水源污染隐患动态数据库、环境监管情况、存在的主要问题和整改方案、整改进展等）。

（四）严格责任追究。各部门应结合实际，建立健全饮用水水源地日常监管制度，加强部门之间沟通协作，严格依法审批涉饮用水水源地建设项目，严防污染问题反弹。对不顾生态环境盲目决策导致饮用水水源地水质恶化、造成严重后果的，依法依纪追究责任。

（五）全面公开信息。松潘县门户网站每季度按规定向社会公开饮用水水源地水质、问题清单和整治进展情况，主动接受社会监督。宣传部门要制定宣传工作方案，通过电视、广播、报纸以及微博、微信等方式，集中宣传饮用水水源地保护工作，组织电视台和群众参加执法检查，公开曝光违法案件，努力营造共抓大保护的良好氛围。

信息公开选项：主动公开
