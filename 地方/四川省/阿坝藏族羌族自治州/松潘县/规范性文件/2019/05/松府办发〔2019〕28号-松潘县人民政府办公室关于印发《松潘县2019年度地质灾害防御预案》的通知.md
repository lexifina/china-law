# 松潘县人民政府办公室关于印发《松潘县2019年度地质灾害防御预案》的通知

松府办发〔2019〕28号

各乡（镇）人民政府，县府各部门：

《松潘县2019年度地质灾害防御预案》已经县人民政府研究同意，现予印发，请认真贯彻执行。

松潘县人民政府办公室

2019年5月24日

松潘县2019年度地质灾害防御预案

为提高对地质灾害应急反应能力和防御水平，避免或尽可能减轻地质灾害造成的损失，确保人民生命财产安全，维护社会稳定，根据《地质灾害防治条例》、《四川省地质环境管理条例》和相关政策规定，结合我县地质灾害分布规律、形成特点、主要诱因、危险程度和2019年汛前地质灾害隐患排查情况，制定本预案。

一、全县地质灾害现状

我县地处西部高山峡谷区，境内山高坡陡，峡谷深切、地势险峻、地层复杂，属地质灾害易发区、高发区。在“8·8”九寨沟地震后，山体稳定性降低，不良地质活动加剧。泥石流、滑坡、崩塌等地质灾害发生频繁。经对县域内地质灾害隐患点全面排查，全县共有地质灾害隐患点469处（其中泥石流灾害166处、不稳定斜坡70处、滑坡166处、崩塌65处、危岩2处），对着全县25个乡（镇）3931户19393名群众的生命财产安全构成了严重的潜在威胁。

二、诱发地质灾害因素

我县山高坡陡，地层岩石破碎，不稳定斜坡、松散堆积层、高危高位危岩体、地震形成的碎屑物等是引发各类地质灾害发生的主要自然因素。加之，近年来全球气温变化，降雨的空间分布、时间分布不均等因素也是诱发地质灾害的重要自然因素。采矿、工程建设、爆破、加载等人为因素也是造成地质灾害的原因之一。

三、地质灾害发展趋势预测

境内总体地形是西北高东南低，境内地势随山脉走向由西北向东南倾斜，境内有岷江、涪江、白草河等支流，涉及沟谷较多，按地面特征大致可分为西北高山高原和东南高山峡谷两部分。

地质灾害高易发区：小河乡、施家堡乡、白羊乡以及十里乡—小姓乡、镇坪乡境内，灾害点类型为滑坡、泥石流、崩塌等。

地质灾害中易发区：黄龙乡—大姓乡境内，灾害点主要类型为泥石流、滑坡等。

地质灾害低易发区：川主寺镇—燕云乡、毛儿盖镇境内，灾害点主要类型为滑坡等。

根据水文、气象等因素综合分析，今年6—9月有暴雨，部分地区易发生山洪、泥石流、滑坡等地质灾害，雨季结束期在10月中旬。

四、地质灾害防灾重点及措施

我县位于川西北高原东北部（青藏高原东南缘），具有特殊的地质地貌景观。受“8·8”九寨沟地震影响以及受地质岩性、地质结构、地形地貌，水文地质及人类工程活动增加等诸多因素的影响，全县地质灾害防灾形式十分严峻，地质灾害频繁，严重重威胁人民群众生命和财产安全及国民经济基础设施安全。今年我县地质灾害防灾重点情况如下：

风景区：黄龙风景名胜区、牟尼沟风景区、龙滴水自然保护区、毛儿盖红色文化旅游区等县域辖区内观光旅游区域。由于旅游旺季都集中在雨季，而雨季诱发地质灾害的概率相对高发，应作为地质灾害重点防治区和防治重点。

九环线公路沿线：随着“8·8”九寨沟地震后旅游逐步复苏，为切实保障人民群众生命财产安全，对全县人民和过往人员、车辆安全负责，为游客提供舒适安全的旅游环境，切实为松潘旅游业服务，汛期对县域辖区内的九环线公路沿线泥石流、山体崩塌、滑坡等地质灾害的防御工作迫在眉睫。

沿江河区域：沿江河区域，属地质灾害高易发区，具体范围包括岷江沿岸的川主寺镇、水晶乡、山巴乡、进安镇、进安乡、青云镇、安宏乡、岷江乡、镇江关乡、镇坪乡；涪江沿岸的黄龙乡、施家堡乡、小河乡、白羊乡；热务曲、毛儿盖河沿岸的小姓乡、红土乡、红扎乡、燕云乡、草原乡、毛儿盖镇、下八寨乡；以及地处谷坡、山麓坡脚地带的大姓乡、大寨乡、牟尼乡。

五、防御措施

地质灾害防御工作是事关人民群众生命财产安全的大事，各乡（镇）人民政府、各部门要充分掌握“8·8”九寨沟地震后地质灾害防御工作的新情况，认真履行职责，完善防灾减灾措施，力争将灾害损失降到最低程度。

（一）加强组织领导，强化责任意识。

各乡（镇）、各部门要充分认识地质灾害防治工作中重要性，进一步增强防御工作的责任感和紧迫感。要成立地质灾害防治工作领导小组，明确责任、细化程序，推行“一把手”负总责、分管领导直接负责、经办人员具体负责的工作机制，切实加强对地质灾害防御工作的领导和组织协调工作。

（二）加强监测力度，开展全方位排查。

各乡（镇）要加强汛前地质灾害隐患点监控力度，对地质灾害隐患进行排查，研判其危险性和发展趋势；重点对易发生地质灾害的沟口、堆积扇、靠山靠崖、以及人员密集的旅游景点（购物点）、安置点、学校、医院、工矿企业、在建工程、临时工棚、重要交通干线沿线、城镇和人口密集区进行监控。对新生隐患点，要逐一建立突发性地质灾害应急预案，落实防灾责任人、监测责任人和各项制度。

（三）完善防灾预案，落实预防措施。

结合本地实际，建立防灾工作明白卡和防灾避险明白卡，认真编制今年的防御预案。在汛期，要坚持领导带班制度，坚持24小时值班制度，做好上传下达工作。对可能发生灾害的地段，已有险情征兆的山地灾害点，必须落实专人观测，做好预报工作，并根据实际情况制定切实可行的避险措施；对避灾地点、疏散路线、报警信号等提前进行周密的安排部署。

（四）强化宣传教育，提升群测群防能力。

大力宣传和贯彻落实国务院《地质灾害防治条例》和《四川省地质环境管理条例》，采取传统媒体宣传与新媒体相结合，应急演练配套开展的方式，普及地质灾害识别、监测、预报和避让知识。增强群众防灾、减灾、救灾意识和全社会防御地质灾害的主动性、自觉性。建立健全县、乡、村、三级群测群防体系，提高防灾避险的能力。

（五）完善值守制度，增强应急反应力。

进一步完善汛期值班值守、险情巡视和灾情速报等制度，各乡（镇）及各部门要严格实行带班值班制度，向社会公布地质灾害报警电话，接受社会监督，组织力量对重点地质灾害危险区进行巡回排查，对灾害发展趋势做到心中有数，落实好各隐患点的预防措施，做好抗灾应急准备工作。灾情发生后，在县委、县政府的统一领导下，确保以乡（镇）、村领导及民兵为骨干的群众性抗灾队伍能及时投入抢险工作，尽快恢复电力、通讯、交通等基础设施，保障受灾群众正常生产生活，当地质灾害来临时，变被动为主动。

（六）加强环境治理，防止人为致灾。

严禁在地质灾害易发区开荒、砍伐树木、开山炸石、开矿以及在河道内建设永久性建筑物、构筑物。严禁未经批准非法采矿，坚决制止乱采滥挖矿产资源的行为，杜绝矿山安全生产事故的发生。对已进行治理的地段要采取排导、拦挡、护岸和排水等工程进行疏导。并采取封山育林、人造水土保持林等措施，减少水土流失，改善流域内生态环境，减少地质灾害发生，降低危害程度。

（七）加强部门联动，形成防灾合力。

自然资源、应急管理、气象、交通、水务等部门要加强横向联系，在县委、县政府的统一领导下，密切配合，通力合作，确保信息畅通，以便适时掌握雨情、水情、灾情，为制定辖区内地质灾害预案和防治措施提供准确依据。

（八）坚持依法行政，严格责任追究。

认真贯彻执行《四川省地质环境管理条例》、《地质灾害防治管理办法》及《建设用地地质灾害危险性评估技术要求》等相关法律及政策规定，加强建设用地地质灾害危险性评估工作。对违规建设、采矿等活动诱发的地质灾害，或已经发现的自然作用形成的山地灾害，没有采取有效措施避让，或没有进行建设用地地质灾害危险性评估、未考虑建设用地条件而批准使用土地和建设，或者没有履行矿山安全生产监管职责以及山地灾害防治工作职责，有灾不报、虚报、瞒报，影响抢险救灾工作，造成重大人员伤亡和财产损失的，按照《国务院关于特大安全事故行政责任追究的规定》等法律、法规的规定，严肃追究相关人员的责任。

县应急管理局：负责牵头组织编制全县地质灾害应急防灾减灾预案，承担应急预案衔接工作；组织开展应急演练，并落实、组织指导地质灾害应急救援、救灾，组织协调地质灾害救援工作，并按权限作出决定，承担全县应急抢险指挥、处置工作，依法统一发布灾情。

县自然资源局：负责落实综合防灾减灾规划，组织编制并实施地质灾害防治规划，组织、指导、协调和监督地质灾害调查评价及隐患的普查、详查、排查；组织指导开展群测群防、专业监测和预警等工作；组织、开展地质灾害工程防治工作，承担地质灾害应急救援的技术保障工作。

县财政局：负责地质灾害防治经费的预算安排、组织资金分配和资金拨付，对防灾资金的使用进行监督、检查，保证资金及时到位。

县经济商务和信息化局：负责协调电信、电力、移动通信等企业及周边地质灾害隐患排查和防治工作。确保通讯电力设施不受破坏，确保人员安全。保证通信、电力畅通。

县教育局：负责学校及周边地质灾害隐患排查、防治、宣传、培训和演练工作。

县公安局：负责维护隐患点范围内的社会治安，打击不法分子的谣传。

县民政局：负责组织核查报告灾情；组织转移、安置灾民；负责困难灾民吃、穿、住、医等生活救助；申请、管理、分配救灾款物，组织指导救灾捐赠；组织调拨救灾物资。

县住房和城乡建设局：负责组织协调工业与民用建筑的抢险救灾工作；对地质灾害治理工程的设计、施工、质量、安全的监督管理工作。

县科学技术和农业畜牧局：负责组织指导灾区动物疫病的预防、控制和扑灭工作，加强动物疫情的监测，切实采取有效措施防止和控制动物疫病暴发流行，负责指导和帮助灾后农业生产自救对受灾农业生产提供救助指导并采取必要的救灾措施。

县水务局：负责河道、水利设施、水电等建设项目生产生活场所及周边地质灾害隐患排查和防治工作，因洪水引发地质灾害的预防工作；组织、协调水利工程建设过程中突发性地质灾害和既有水利工程范围内自然或人为因素突发性地质灾害的抢险救灾工作；负责县境内河道突发性地质灾害防治并组织水利设施修复工作。
