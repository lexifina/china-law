# 松潘县人民政府办公室关于严格落实“三集中三到位”确保政务服务高效便捷的通知

松府办发〔2019〕72号

松潘县人民政府办公室

关于严格落实“三集中三到位”确保政务服务

高效便捷的通知

各相关部门：

为推动我县行政审批制度改革工作不断向纵深开展，严格落实中央、省州“放管服”改革和行政审批“三集中三到位”，切实落实整改措施，推动标准化服务与信息化相结合，构建程序规范、服务优良、群众满意、监测到位的办事环境，全面清理入驻事项，确保项目“应进必进”。现将我县开展行政审批“三集中、三到位”工作有关事宜通知如下：

一、工作目标

全面推进“放管服”改革工作，加快推进“最多跑一次”改革，通过行政审批事项集中报件受理，优化审批流程，提升办理实效，实现便企利民目标。

二、工作内容

（一）强化事项进驻大厅。按照“应进必进”的原则，所有行政审批事项及公共服务事项必须进驻政务服务大厅，确保大厅外无审批。

（二）相对稳定部门入驻人员。进驻政务服务大厅各行政审批和公共服务职能部门要选定素质高、业务精、服务意识强、有较高的计算机水平、能承担审批和服务职能的骨干人员（优先派驻会藏汉双语）专门从事派驻工作，保持人员队伍相对稳定，并确定一名进驻大厅首席代表。

（三）确保审批授权到位。进驻大厅部门对首席代表要充分授权，使其能独立完成行政审批工作。对不需要现场勘查、集体讨论、专家论证听证的一般性许可审批事项，在窗口受理后可直接办结。对确需集体研究和主要责任人、分管负责人审核的重大项目，在履行相关程序、一次性收集相关材料后，在服务承诺时限内在窗口办结，实现“最多跑一次”。

（四）全面梳理进驻大厅功能需求。各进驻政务大厅的部门需要根据工作需求，以正式文件形式向县行政审批局提交进驻人数及办公设备、特殊办公用房、审批专项及自助终端设置等方面需求。

三、工作要求

(一)提高思想认识。“三集中、三到位”工作是全县进一步深化行政审批制度改革的一项重要举措，是推动“最多跑一次”改革，提高审批效率、提升政务服务水平的有力抓手，各相关部门要牢固树立大局意识，以强有力的措施确保各项工作任务顺利推进。

（二）加强组织领导。“三集中、三到位”工作既涉及相关部门领导分工调整，同时也涉及具体工作人员职责调整，因此，各相关部门“一把手”务必站在全县发展高度亲手抓落实，安排和处理好进驻政务服务大厅审批工作和部门其他工作。

（三）统筹协调推进。按照相关要求，入驻政务服务大厅窗口人员应当是行政机关公务员，或依法授权承担政务服务事项的事业单位正式工作人员，窗口工作人员在进驻政务服务大厅期间，不再承担本部门行政审批及公共服务以外的其他工作，同时清退不符合要求的窗口工作人员。请各相关部门按要求对已经进驻大厅的工作人员进行调整，对不符合要求的及时进行更换，未进驻单位加快安排合理人员进驻。对有特殊要求的事项，要及时将需求上报县行政审批局，根据需求进行办公场地设施设备调整。
