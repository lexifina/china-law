# 若尔盖县人民政府办公室关于印发若尔盖县生育秩序整治行动实施方案的通知

若府办发〔2017〕42号

各乡（镇）、场，县级机关各部门，各企事业单位：

《若尔盖县生育秩序整治行动实施方案》已经县人民政府同意，现印发你们，请认真抓好落实。

若尔盖县人民政府办公室

2017年6月13日

若尔盖县生育秩序整治行动实施方案

为深入贯彻《四川省健康扶贫专项2017年实施方案》（川委厅〔2017〕15号）、《阿坝州国家卫生健康委员会关于开展深化生育秩序整治行动的通知》（阿州卫计发〔2017〕61号）精神，进一步深入开展生育秩序整治行动，助力脱贫攻坚工作。结合我县实际，特制定本实施方案。

一、目标任务

坚持计划生育基本国策不动摇，改革完善计划生育服务管理，严格控制政策外生育，逐步减少政策外多孩生育现象，保障正常的生育秩序。

二、工作措施

（一）加强督导考核

根据州委、州政府《关于实施全面两孩政策改革完善计划生育服务管理的意见》、《阿坝州2017年计划生育工作目标任务管理考评细则》要求，结合我县计划生育工作实际情况，合理确定考核内容和考核指标，签订计划生育目标管理责任书。细化计划生育“一票否决”办法，将计划生育主体责任严重不落实、政策外多孩生育严重、违法行政造成严重后果、工作后长期不能改变面貌等情况纳入“一票否决”，严格考核，兑现奖惩。将各乡（镇）、场计划生育执行落实情况纳入目标考核，年度计划生育工作落实情况由县卫生和计划生育局负责考核。

（二)加强组织领导

1.建立县级各部门对各乡（镇）场联系指导制度。切实加强计划生育服务管理。联系单位要认真分析乡、村计划生育工作情况，定期到联系乡、村了解情况，发现问题，研究对策，帮助联系乡村加强和改进计划生育服务管理。各部门联系指导点以县委组织部下发的文件为准（名单附后），工作开展情况按季度报卫生计生局基层指导股汇总。

2.县卫生计生局领导班子和各股室负责人联系育龄群众制度。定点联系两户以上达到法律法规规定生育数量上限的育龄妇女。联系干部要开展经常性的联系走访,及时了解联系对象的情况，做好计划生育政策法规和生殖保健知识的宣传，督促联系对象落实长效节育措施，确保联系对象不出现违法生育行为。联系人要记录联系工作日志，做到有档可查、有迹可循。对履职不到位，联系对象出现违法生育行为的，责令联系干部作出书面检查，给予通报批评，联系干部当年不得参与评先评优。

3.实行乡、村干部计划生育“包村包户”责任制。将计划生育管理和服务落实到乡村干部并严格考核。“包村包户”责任制的主要任务是：组织开展经常性计划生育宣传教育，组织发放计划生育入户宣传品，确保每户至少有一份计划生育图文宣传品；“包村包户”责任人每月到所包村了解群众婚、孕、育信息和计划生育工作情况并向乡镇党委、政府专题汇报；及时组织向育龄群众免费发放避孕药具；每季度组织所包村已婚育龄妇女参加计划生育“三查”服务；及时动员已达到政策规定生育数量上限的群众落实长效避孕措施，及时动员不符合政策怀孕对象落实补救措施；协助有关部门做好违法生育对象社会抚养费征收工作；协调有关部门落实好各项计划生育奖励优待政策，开展计划生育贫困家庭帮扶工作。2017年底前“包村包户”责任制落实率达到100%。

4.在实行“包村包户”责任制的同时同步建立实行专业技术服务人员“一对一”联系制度。县妇幼保健和计划生育技术服务中心要指导和督促乡镇卫生院开展专业技术人员“一对一”联系工作。坚持面向基层、深入乡村、方便群众、服务上门，充分发挥乡镇卫生院、妇幼保健计划生育技术服务机构作用，组织有关专业技术人员为已婚育龄妇女特别是已生育2—3个孩子的已婚育龄妇女提供计划生育技术指导，使每名已婚育龄妇女有一名固定的专业技术人员为其提供一对一指导服务；经常向联系对象宣传计划生育、优生优育和生殖保健知识；了解联系对象的婚育情况，对符合政策的拟生育对象，宣传动员参加孕前优生健康检查；对已孕妇女，协同做好孕产期保健服务；做好科学育儿宣传；向联系对象宣传避孕节育知识，既要坚持避孕方法知情选择，更要指导对象落实安全、有效、适宜的避孕节育措施；了解联系对象的避孕情况，发现不符合生育政策怀孕的，及时报告，并协助动员落实补救措施。2017年底前“一对一”联系制度落实率达到90%。

5.实行长效节育措施奖励制度。对全县45周岁及以下、达到法律法规规定生育数量上限、自愿采取宫内节育器或皮下埋植等长效避孕节育措施的已婚育龄妇女，每例奖励300元，此项奖励经费由省、州、县级财政共同负担，省级负担50%，州和县负担50%（州、县分担比例由州人民政府确定），州、县级财政负担经费要纳入年初预算并及时足额到位。今年，奖励资金县卫生和计划生育局将在计生事业费中列支经费，奖励自愿采取长效避孕节育措施的育龄妇女,女扎每例400元, 孕49天内药物流产每例100元。

所有需采取长效避孕节育措施的育龄妇女，由户籍所在地的乡（镇）场人民政府出具《若尔盖县计划生育技术服务介绍信》到我县定点医院（县人民医院）试行，并凭介绍信和发票到县妇幼保健计划生育技术服务中心登记核实后兑现奖励资金（在县外施行手术的需提供医疗机构或保健机构发票和乡政府证明），所有奖励经费通过财政补贴农民“一卡通”渠道直接发放到人，不得发放现金和代领代发。县、乡、村要通过多种形式开展政策宣传，动员符合条件的育龄妇女自愿接受长效避孕节育措施。

三、加强计划生育宣传教育

大力宣传计划生育政策法律法规，提高群众计划生育、优生优育、生殖健康知识知晓率，树立科学、文明、进步的婚育观念，将计划生育纳入我县经济社会发展总体规划，推动群众树立中华人民共和国人口与计划生育法制理念。今年，县卫生和计划生育局将在计生事业费中列支1万元作为各乡（镇）、场的计生工作经费，要求各乡（镇）、场在人口聚居地制作一幅永久性宣传标语，及时更换宣传专栏内容，确保村发药员手中有二至三样宣传资料，各乡（镇）场结合传统节日等开展计划生育宣传活动，及时向县卫生和计划生育局上报宣传活动信息。县卫生和计划生育局在县城交通要道制作两幅固定标语，建立宣传文化长廊，切实提高宣传的可及性和可接受性，增强宣传效果，推动群众婚育观念转变。

四、坚持依法行政

坚持用法治思维、法治方式推进计划生育工作，加大计划生育执法力度，严格控制政策外多孩生育。清理近年计划生育工作情况，摸清政策外生育底数；对违法生育对象依法调查取证、作出处理决定，违法生育立案处理率达到90%以上；对尚未缴清社会抚养费的，及时进行催缴；有履行能力但拒不缴纳的，申请人民法院强制执行；清理党员、干部违法生育问题，除依法征收社会抚养费外，依纪依规予以纪律和组织处理。

采取长效避孕节育措施坚持群众自愿原则，必须在取得计划生育技术服务资质的机构施行。未取得计划生育技术服务资质的机构或个人擅自施行计划生育手术特别是违规取出宫内节育器、皮下埋植剂的，依照相关法律法规从严惩处，涉嫌犯罪的，移送司法机关依法处理。

五、加强贫困地区计划生育队伍建设

各乡（镇）、场要明确负责计划生育工作的负责人及工作人员，村级明确计划生育干部，以女性为主。全面落实村级计划生育干部报酬待遇不低于村级主要领导的80%的要求；明确乡镇、村级计划生育干部工作职责，严格考核；县卫生和计划生育局每年组织开展2次以上乡（镇）场计划生育干部培训，乡镇每年开展1次以上村（居）计划生育干部培训，提升服务水平。加强县妇幼保健计划生育服务机构计划生育专业人才队伍建设，通过增加编制、引进人才等方式，确保有人干事。加强县乡级计划生育协会的组织和能力建设。

六、工作步骤及要求

第一、二季度：县卫生和计划生育局要完善目标管理责任制和“一票否决”办法，与各乡（镇）、场进行签订，各乡（镇）、场要按要求制定实施方案，细化工作台账，明确工作职责；梳理本地工作的突出问题和矛盾焦点，制定妥善可行的工作措施；及时开展工作动员，做好前期调研，摸清实际工作情况，清理人口底数，整合相关行政资源和技术资源，做好生育秩序整治各项基础工作；全面建立 “包村包户”责任制和专业技术人员“一对一”联系制度。

第三季度：县卫生和计划生育局要统筹做好全县生育秩序整治工作开展情况的督促、指导。各乡（镇）、场要按照方案要求，开展乡村干部培训，形式多样的宣传活动，落实并强化“包村包户”责任制和专业技术人员“一对一”联系制度，逐级压实工作任务，确保工作落实。

第四季度：县卫生和计划生育局统筹做好全县生育秩序整治工作，不定期对各乡镇工作开展情况进行督查，发现问题，及时整改，按照目标责任和“一票否决”办法，严格考核，兑现奖惩。县乡村工作材料形成专卷，接受省、州、县检查。

各乡（镇）、场要高度重视此项工作，在开展“包村包户”责任制和专业技术人员“一对一”联系制度工作时，要建立干部联系村、户花名册，干部要记录开展工作情况日志。每月25号前上报《实施贫困地区生育秩序整治行动月报表》（附件4）和《生育秩序整治长效节育措施落实情况统计表》（附件5），每季度末上报生育秩序整治工作开展情况报告。

请各乡（镇）、场将生育秩序整治行动的实施方案、领导小组、“包村包户”“一对一”花名册于2017年6月15日前报县卫生和计划生育局基层指导股。

附件2：

“包村包户”责任制的主要任务

1.组织开展经常性计划生育宣传教育，组织发放计划生育入户宣传品，确保每户至少有一份计划生育图文宣传品。

2.每月到所包村了解群众婚、孕、育信息和计划生育工作情况并向乡镇党委、政府专题汇报。

3.及时组织向育龄群众免费发放避孕药具。

4.每季度组织所包村已婚育龄妇女参加计划生育“三查”服务。

5.及时动员已达到政策规定生育数量上限的群众落实长效避孕措施，及时动员不符合政策怀孕对象落实补救措施。

6.协助有关部门做好违法生育对象社会抚养费征收工作。

7.协调落实好各项计划生育奖励优待政策。

8.协调有关部门开展计划生育贫困家庭帮扶工作。

附件3：

专业技术服务人员“一对一”联系制度职责

1.组织乡镇卫生院、妇幼保健和计划生育技术服务机构专业技术人员为已婚育龄妇女特别是已生育二孩及以上的已婚育龄妇女提供计划生育技术指导，使每名已婚育龄妇女有一名固定的专业技术人员为其提供一对一指导服务。

2.经常向联系对象宣传计划生育、优生优育和生殖保健知识；

3.了解联系对象的婚育情况，对符合政策的拟生育对象，宣传动员参加孕前优生健康检查；对已孕妇女，协同做好孕期保健服务；做好科学育儿宣传。

4.向联系对象宣传避孕节育知识，指导选择落实安全、有效、适宜的避孕措施；

5.了解联系对象的避孕情况，发现不符合生育政策怀孕的，及时报告，并协助动员落实补救措施。
