# 若尔盖县人民政府关于调整县人民政府领导分工的通知

若府发〔2017〕32号

各乡（镇）、场，县级机关各部门，各企事业单位：

因工作需要，经十四届若尔盖县人民政府第8次常务会议研究，决定对部分县政府领导分工进行调整。现将调整后的县政府领导分工通知如下。

县长：余开勇

主持县人民政府全面工作。

负责审计工作。

常务副县长：木扎塔

负责县政府日常工作。协助县长分管审计工作。负责财税、监察、人力资源和社会保障、法制、督查、应急管理、外事、保密等工作。

分管县政府办公室（县政府法制办、外事台侨办、政务服务中心、应急办、人民防空办、采购办）、县监察局、县财政局（县国资公司）、县人力资源和社会保障局、县委县政府督查督办室、县政府驻蓉办、县机关事务管理局。

联系县人大、县政协、县委组织部、县委编办、县委党校、县密码管理局、县国税局、县地税局、县住房公积金管理部、县农行、县信用社、保险公司。

常务副县长（挂职）：张锐

负责德阳、浙江杭州对口支援，发改、统计、商务、招商引资、物价、电力等工作。协助木扎塔同志做好县政府日常工作。

分管德阳对口支援若尔盖前线指挥部、县发展改革和经济商务信息化局（成西铁路协调办）、县统计局、县物价局、县以工代赈办、县招商引资办。对接协调浙江杭州对口支援工作。

联系县总工会、县烟草专卖局、县电力公司。

副县长：王文富

负责政法、社会稳定、安全生产、司法等工作。

分管县公安局、县司法局、县安全生产监督管理局。

联系县委政法委、县人武部、县法院、县检察院、特警大队、消防大队、武警中队。

副县长：张禄文

负责城乡建设、交通运输、运政、国土资源、城市管理、通信、城乡环境综合整治等工作。

分管县城乡规划建设和住房保障局（县测绘地理信息局）、县交通运输局（公路运输管理所）、县国土资源局、县城市管理局、县城乡环境整治办。

联系公路分局、电信公司、移动公司、联通公司、铁塔公司。

副县长：刘跃文

负责环境保护、林业、湿地、旅游、工商行政管理、质量技术监督、食品药品监管等工作。

分管县环境保护和林业局（县护林防火指挥部办公室）、县旅游发展局、县工商质量技术和食品药品监督管理局、县景区管理局（花湖旅游公司、一湾旅游公司）、县旅游执法局、若尔盖湿地管理局。

副县长：李雪燕

负责教育、卫生计生、文化、体育、广播影视、新闻出版、群团等工作。

分管县教育局（县招生办、县政府教育督导室）、县卫生和计划生育局（县爱卫办）、县文化体育广电新闻出版局、县广播电视台。

联系县委宣传部（县精神文明办）、团县委、县妇联（县妇儿工委）、县文联、县残联、538中波台、县红十字会等单位。

副县长：唐郁鑫

负责扶贫开发、移民、农业、畜牧、水务、牧民定居工作，协调省核工业地质局、省博览事务局、中石油四川销售分公司对口扶贫等工作。

分管县扶贫和移民工作局、县农业畜牧和水务局（县畜牧兽医服务中心、县防汛抗旱指挥部办公室、县草原防火指挥部办公室）、县牧民定居办。

联系县委农工办。

副县长：华尔丹

负责民政、民族宗教、信访等工作。

分管县民政局、县民族宗教局（县两资办、县少语工委）、县信访局、县森林公安局。

联系县委统战部、郎木寺管理委员会、哲蚌寺管理委员会、索格藏寺管理委员会、县委群众工作局、县佛协、县伊协、县工商联。

副县长（挂职）：李家勇

负责粮食、供销、防震减灾、气象等工作，协助唐郁鑫同志分管脱贫攻坚工作，配合张锐同志做好德阳、浙江杭州对口支援工作。

分管县粮食局、县供销社、县防震减灾局。

联系县气象局、县邮政管理局。

副县长（挂职）：金雷

负责科学技术、知识产权、档案、史志、金融脱贫攻坚等工作，协助木扎塔同志抓好财税工作，协助张锐同志抓好招商引资工作。

分管县科学技术和知识产权局、县档案局、县史志办。

联系县科协。

若尔盖县人民政府
