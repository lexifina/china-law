# 若尔盖县人民政府若尔盖县人民武装部关于印发《若尔盖县基层武装部规范化建设实施方案》的通知

若府发〔2019〕23号

各乡（镇）：

《若尔盖县基层武装部规范化建设实施方案》已经县人民政府、县人民武装部同意，现印发你们，请严格遵照执行。

若尔盖县人民政府  若尔盖县人民武装部

2019年4月18日

若尔盖县基层武装部规范化建设实施方案

为贯彻落实国务院、中央军委《我军后备力量建设“十三五”规划》和省、州党委政府、省军区、军分区有关指示精神，进一步加强我县各乡（镇）武装部规范化建设，筑牢民兵预备役建设基础，提升应急战备水平，特制定本实施方案。

一、组织领导

在县委、县政府的统一领导下，成立基层武装部规范化建设领导小组，由县长余开勇任组长，县人武部部长索南罗尔吾、政委罗康洪和副县长、公安局长王文富任副组长，成员由各乡（镇）长和县人武部军事科科长组成。领导小组办公室设在县人武部军事科，负责制定方案计划，指导各乡（镇）抓好工作落实，组织开展检查验收工作。

二、建设内容

（一）基础设施建设

1.办公室。单独设置专武部长办公室，配置民兵工作专用电脑、打印机、碎纸机、文件柜，悬挂工作职责牌、工作制度牌和“三图”（×××乡（镇）兵员动员工作图、×××乡（镇）人民武装部抢险救灾预案图、×××乡（镇）人民武装部2019年度工作统筹图）。

2.资料室。与办公室合用，配备文件资料柜，柜内主要存放“四本”“五表”“六册”，以及政治工作、战备训练和国防教育等其他有关资料，各类资料摆放有序、保管良好、便于查阅。

3.活动室。与各乡（镇）活动中心、会议室等群众集体活动场所合并设置，悬挂“青年民兵之家”门牌，室内设置必要的课桌椅、图书资料柜（存放相关书籍和报刊）、光荣榜和国防教育园地等，有条件的可配备音响资料和文体器材。

4.战备物资器材库。单独设置民兵战备物资器材库（面积能满足必需物资器材的存放需求），消防和其他应急物资器材可合并设置。按照“三分四定”要求，存放背囊（睡袋、洗漱用品、雨衣、水壶、迷彩服、胶鞋等）、警棍、盾牌、灭火器、镐、钢钎等防暴、防洪、防火、防震器材，有条件的还可以配备油锯、切割机、对讲机及卫星电话等设备。其中，单兵物资（如背囊、作训服）按每个乡（镇）30套配齐，防暴、防洪、防火、防震器材结合自身任务实际酌情配置。悬挂“民兵战备物资器材库”门牌。

5.武装部挂牌。与各乡（镇）党委、政府单位挂牌同样规格并列悬挂“×××乡（镇）人民武装部”挂牌。

（二）完善软件设施

按要求统一配置文件盒、文件夹、“四本”（武装工作会议记录本、武装工作要事记录本、民兵政治教育记录本、民兵外出登记本）、“五表”（民兵组织实力统计表、民兵军事训练统计表、兵役登记统计表、退伍军人情况统计表、地方与军事专业对口情况统计表）、“六册”（基干民兵花名册、现役部队预编预备役人员花名册、退伍军人花名册、地方与军事专业对口人员花名册、预征对象花名册、应征入伍人员花名册）、战备物资器材库出入库登记本、“三图”、工作职责牌、工作制度牌和专武部长办公室门牌。

（三）健全制度机制

1.党管武装制度。各乡（镇）每年至少召开1次党管武装工作会议，学习上级有关指示精神，听取本级武装工作情况汇报，研究解决武装工作重大问题。乡（镇）党委书记每年向上级军事机关进行党管武装工作述职。

2.工作计划制度。根据上级有关要求，每年1月制定年度工作要点，适时制定民兵组织整组、民兵军事训练、兵役征集等专项工作计划，报上级军事机关批准后实施。

3.学习教育制度。按照上级学习教育计划，组织民兵干部进行政治、业务学习，提高民兵干部的思想政治素质和业务工作水平。

4.办公例会制度。一般每季度召开1次专职人民武装干部和民兵营（连）长集体办公会，听取任务完成情况汇报，研究安排工作，查找问题，制定措施。

5.值班执勤制度。担负战备值班任务的基层人民武装部，要坚持昼夜值班，保持通信顺畅，保持民兵分队的良好战备状态，及时正确处置突发情况。

6.请示报告制度。基层人民武装部要定期向上级军事机关和同级党委、政府请示报告工作。受领上级军事机关赋予的任务后，应及时提出建议方案，主动接受领导和争取支持。遇有重大灾情、险情和其他突发情况，必须第一时间请示报告。

7.请假制度。专职人民武装干部离开岗位必须经所在单位主要负责同志同意，并报县人民武装部批准。

8.安全保密制度。加强经常性安全保密教育，严格按照规定做好安全保密工作，确保不发生任何失泄密事件。

三、阶段划分及任务

按照统一部署、同步展开的思路，分四个阶段抓好各项工作。

（一）统筹计划（4月下旬至5月上旬）

在本方案基础上，各乡（镇）结合自身实际制定本级建设方案，于5月10日前派专人或通过党政网报送至县人武部。

（二）实施建设（5月中旬至6月中旬）

各乡（镇）建设方案经县人武部批准后，迅速组织相关人员展开各项建设，确保6月20日前全部完成。

（三）验收讲评（6月底前）

按照先完成先验收和分片区相结合的方法，各乡（镇）完成建设后电话报告县人武部，县人武部组织相关力量到各乡（镇）进行现场检查验收，全部验收后的适当时间组织各乡（镇）专武部长（武装工作负责人）进行集中讲评。

（四）整改落实（7月底前）

各乡（镇）根据县人武部验收讲评情况，有针对性的进行整改，7月底前全部完成，做好8月份接受军分区检查、10月份省军区抽查准备。

四、保障方法

此次基层武装部规范化建设，所需经费从州、县给予各乡镇的基层武装部规范化建设专项经费中列支。各乡（镇）完成建设并通过检查验收后，向县人武部提交建设内容清单、发票复印件、单位对公账号、四川省行政事业单位资金往来结算票据和收条，手续合格后县人武部给各乡（镇）对公账号转入建设资金，与建设施工和采购公司的结算由各乡（镇）实施。为统一标准，软件设施部分由县人武部统一规格，各乡（镇）支付经费；各乡（镇）需要补充的储物架（规格：长2米、宽0.5米、高2米）、背囊（含内装物资）、作训服（区分冬季和夏季）、警棍盾牌数量（作训服含型号）随建设方案上报县人武部。
