# 若尔盖县人民政府关于解除我县非洲猪瘟疫区封锁的决定

若府发〔2019〕44号

2019年5月20日，经农业农村部新闻办公室发布我县降扎乡发生非洲猪瘟疫情。为迅速扑灭疫情，阻止疫情蔓延，根据《中华人民共和国动物防疫法》、国务院《重大动物疫情应急条例》和农业农村部《非洲猪瘟疫情应急预案》等规定，我县立即启动《若尔盖县非洲猪瘟疫情应急预案》Ⅳ级响应，对疫区采取封锁、扑杀、消毒、无害化处理等疫情处置措施，在疫区周边主要交通路口设置10个临时检查消毒站，对过往车辆、人员进行检查和消毒工作，禁止生猪出入疫区，禁止生猪产品流出疫区。

疫区内生猪扑杀完成后，经6周连续监测排查，疫区内未发现新的病例和监测阳性。7月2日，省州专家对疫区进行现场评估验收，我县非洲猪瘟疫情已被扑灭，符合疫区解除封锁的规定。县政府决定，于2019年7月2日24时正式对疫区解除封锁。

若尔盖县人民政府
