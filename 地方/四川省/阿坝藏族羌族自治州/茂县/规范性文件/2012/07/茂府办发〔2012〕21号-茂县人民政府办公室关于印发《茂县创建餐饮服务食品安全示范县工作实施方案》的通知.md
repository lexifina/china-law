# 茂县人民政府办公室关于印发《茂县创建餐饮服务食品安全示范县工作实施方案》的通知

各乡（镇）人民政府、县级各部门：

《茂县创建餐饮服务食品安全示范县工作实施方案》已经县人民政府领导同意，现印发你们，请结合实际，认真组织实施。

茂县人民政府办公室

2012年7月16日

茂县创建餐饮服务食品安全示范县工作

实施方案

根据商务厅、四川省食品药品监督管理局《关于开展餐饮服务食品安全示范工程创建活动的通知》精神，为有效落实餐饮服务食品安全责任，充分发挥餐饮服务食品安全示范单位的引领带动辐射作用，进一步提高我县餐饮服务食品安全保障水平，结合我县餐饮服务食品安全现状和县委、县政府对餐饮服务食品安全工作的要求，制定本实施方案。

一、指导思想

以邓小平理论和“三个代表”重要思想为指导，全面贯彻党的十七大和十七届五中、六中、七中全会以及省第十次党代会精神，深入贯彻落实科学发展观，坚持预防为主、科学监管的方针，大力践行科学监管理念，推行餐饮服务示范工程新举措，以点带面，推动全县餐饮服务食品安全监管工作跃上新台阶，促进我县餐饮服务业持续健康发展，切实保障人民群众饮食安全。

二、目标任务

坚持政府推动与企业争创相结合、分类指导与分级联创相结合、逐步推进与滚动发展相结合、突出重点与全面统筹相结合，以“饮食安全、店容整洁、管理到位、群众满意”为目标，开展餐饮服务食品安全示范县创建活动，其中创建3个示范乡镇，2条示范街，20个示范单位。通过开展示范创建工作，进一步强化第一责任人责任，使餐饮服务食品安全监管部门监管措施落实到位，餐饮服务生产经营行为进一步规范，餐饮服务食品安全水平明显提升，有效预防群体性食物中毒事件发生，为人民群众创造安全放心的餐饮消费环境。

四、职责分工

创建工作在县政府统一领导下，由县创建工作领导小组组织实施。各乡镇、各职能部门要根据本工作方案，负责落实监管职责范围的食品安全监管工作，指导帮助餐饮服务单位加强自律，提高食品质量和安全，改善餐饮食品安全状况。

（一）县食安办：负责统一协调全县创建省级餐饮服务食品安全示范县工作；依法组织开展重大食品安全事故查处，统一发布食品安全重大信息；对县食安委的议定事项、工作部署组织实施和督促检查；研究提出创建省级餐饮服务食品安全示范县工作的实施意见，供食品安全委员会决策。

（二）县财政局：负责示范县创建工作的经费保障。

（三）县公安局：配合相关部门开展餐饮示范县创建工作，严厉打击暴力抗法等违法犯罪行为。

（四）县食药监局：承担创建省级餐饮服务食品安全示范县的日常工作，健全和落实各项工作制度和餐饮服务食品安全应急预案；负责餐饮服务单位的行政许可、量化分级工作；加强对餐饮服务单位的监管；做好农村家宴的指导工作；指导各乡镇（社区）加强餐饮服务食品安全管理。

（五）县经信局：组织开展省级示范县、示范街、示范店命名、考核和验收，负责省级餐饮服务食品安全示范单位遴选推荐工作（国食药监食〔2010〕235号）。并负责餐饮单位酒类的监督管理和牲畜屠宰的管理，防止问题鲜肉流入餐桌。

（六）县旅游局：规范旅游景区、酒店、农家乐等涉旅企业的餐饮食品安全工作，积极配合相关部门开展示范店的信用体系建设，建立经营档案和监管信用档案，强化“企业是食品安全第一责任人”的意识，支持旅游餐饮行业协会充分发挥自律作用，引导和约束企业诚信经营。

（七）县旅游执法局：协助食品药品监管部门开展旅游景区涉旅餐饮企业的整规工作。

（八）县城管局：负责示范街的形象打造和餐饮服务单位餐厨垃圾收集、存放、运输、处置备案。监督管理餐厨垃圾收运处置及处置场地运营管理。

(九)县建设局：切实加强对建筑工地食堂的管理，督促施工企业完善食品安全管理制度，落实食品安全管理责任，改善食堂硬件设施，进一步提高建筑工地食堂食品安全水平，建立长效监管机制，确保建筑工人的身体健康和生命安全。

（十）县教育局：严格按照《学校食堂与学生集体用餐管理规定》对食堂进行管理。落实学校食堂卫生管理制度及岗位责任制，确保食品的质量和安全。

（十一）县卫生局：负责餐饮服务环节从业人员的健康体检工作，预防食物中毒事件的发生，同时积极做好应急救援工作。

（十二）县工商局：按照《无照经营查处取缔办法》（国务院令第370号）依法会同县食药监局对无证无照餐饮服务行为进行规范和查处。

（十三）县工业园区管委会：负责工业园企业食堂的管理，积极配合相关部门开展示范企业的信用体系建设，建立经营档案和监管信用档案，强化“企业是食品安全第一责任人”的意识。

（十四）县广电局：负责指导创建餐饮服务食品安全示范县的社会宣传工作，做好食品安全新闻报道和舆论监督，为创建工作营造良好的氛围；对餐饮食品安全舆情进行监测和研判，指导相关部门妥善处理食品安全问题引发的社会舆论。

（十五）县质监局：负责餐饮企业计量器具的管理，防止缺斤少两、欺诈消费者的行为发生。

（十六）各乡镇政府（社区）：

1.负责建成食品安全放心乡（镇），创建食品安全示范乡（镇）；

2.全面落实本辖区食品安全“两网”建设工作，建立乡（镇）、村（社区）两级食品安全监管体系，健全基层群众监管队伍，90%的村（社区）建有放心店；

3.开展餐饮环节食品安全专项整治，切实加强对辖区学校食堂和餐饮店的管理；

4.农村集体聚餐备案率达90%以上；

5.收集、报送食品安全信息，建立食品生产经营单位基础台帐；受理食品安全投诉，配合处理食品安全事故；开展宣传培训工作，提高群众食品安全知识知晓率和食品消费满意度。

6.建立相应的领导机构，落实分管领导和工作人员，负责具体抓食品安全工作，切实开展好日常工作和相关工作信息的上报；负责落实本辖区示范单位的建设工作和农村家宴的管理工作。

五、示范工程建设的基本标准

（一）餐饮服务食品安全示范县

将餐饮服务食品安全监管工作纳入政府目标考核，建立创建餐饮服务食品安全示范县领导与工作机构，执法监督队伍配备有力，应急管理体系组织健全，财政支持保障充足，辖区内建立餐饮服务食品安全社会监督员队伍，设立投诉举报网络，及时处理群众投诉举报，广泛开展多种形式的食品安全宣传教育，监管工作扎实有效，达到以下基本要求：辖区内餐饮服务单位量化分级管理达到100%，其中B级以上达到80%；辖区内餐饮服务食品及餐具抽检合格率达到95%以上；农村集体聚餐备案率达到90%以上；辖区食品安全应急网络覆盖面达100%；辖区内连续三年以上未发生重大食品安全事故；辖区政府食品安全工作考核目标达到100%；公众对餐饮服务食品安全满意率达到70%以上。

（二）食品餐饮消费安全示范乡镇

餐饮服务食品安全示范乡镇应将食品安全监管工作纳入党委政府目标考核，有相应的工作机构，应急管理体系组织健全；食品安全监管工作有经费保障；辖区内建立餐饮服务食品安全管理员（协管员、信息员）队伍；广泛开展多种形式的食品安全宣传教育，监管工作扎实有效，达到以下要求：乡镇应100%达到县政府有关食品安全考核目标；辖区内餐饮服务单位量化分级管理达到100%，其中B级以上达到80%；辖区内餐饮服务食品及餐具抽检合格率达到95%以上；农村集体聚餐备案率达到90%以上；辖区食品安全应急网络覆盖面达100%；辖区内连续三年以上未发生重大食品安全事故；对村（居）委会食品安全工作考核达到100%；公众对餐饮服务食品安全满意率达到80%以上。

（三）餐饮服务食品安全示范街

街区内不存在无证经营的现象；街区内所有餐饮服务经营单位均应诚信守法经营；配备餐饮服务食品安全社会监督员；街区内餐饮服务经营单位量化分级管理均达到B级以上；街区内餐饮服务食品安全示范单位比例达到50%以上；街区内连续两年以上未发生重大食品安全事故；公众对餐饮服务食品安全满意率达到80%以上。

（四）餐饮服务食品安全示范单位

餐饮服务食品安全示范单位应当诚信守法经营，内部管理制度健全并有效实施，各项措施符合餐饮服务食品安全操作规范，能够有效控制食品安全风险，食品安全保障水平较高，从业人员食品安全管理规范，能够全面承担食品安全责任，并达到以下基本要求：建立并执行索证索票制度，食品原料、食品添加剂、食品相关产品的可追溯率达到100%；量化分级管理被列为B级以上；从业人员健康证持证率达到100%；积极采用“五常法”（常整理、常整顿、常清扫、常清洁、常提高。）或“六T法”（天天处理，天天整合，天天清扫，天天规范，天天检查，天天改进。）等先进管理方法；连续三年以上未发生食物中毒事件。

六、主要工作任务和措施

（一）强化培训。制定计划，组织开展对餐饮单位业主和从业人员进行强化培训，提高餐饮单位人员的饮食安全知识水平和安全意识。一是积极参加省州举办的培训，同时聘请专家对监管工作人员进行法律法规和餐饮管理基本知识、基本技能培训，使工作人员掌握许可的程序、准入条件和标准，掌握日常监督管理的内容和要求；二是培训餐饮服务单位负责人，强化第一责任人的食品安全责任意识，明确餐饮服务经营单位食品安全硬件和管理上的具体要求；三是对餐饮服务业人员分别进行有针对性的全员培训，重点培训原料采购人员、厨师及餐饮服务管理负责人，保证原料安全、操作规范和管理到位；四是利用广播、电视、报刊、板报和发放宣传资料等方式，大力宣传《食品安全法》等法律法规知识，为餐饮服务监管营造社会氛围。要求县内大、中型餐饮单位的业主和管理人员强化培训率达100%；示范街餐饮单位的从业人员强化培训率达100%。

（二）规范餐饮服务许可标准，提高市场准入门槛。严格执行许可标准，规范餐饮服务市场准入。对已取得卫生许可证和餐饮服务许可证的餐饮单位，要按标准进一步完善加工场所的流程和设施，确保达到示范要求。

（三）建立“三项制度”。

1.建立并完善食品原辅料进货台帐登记制度和索证索票制度，全县100%的大、中型餐饮单位都要建立食品原辅料进货台帐登记制度和索证索票制度；示范街100%的餐饮单位都要建立和完善食品原辅料进货台帐登记制度和索证索票制度。

2.建立监督检查公示制度。制订并使用统一的餐饮服务量化监督检查表，采取日常检查和专项检查的办法进行评分，根据评分结果当场评定检查结论，评定结论分三种：情况良好，情况一般，情况较差，监督检查结果以公示牌的形式公示。

3.建立实施承诺制度。全县100%的大、中型餐饮单位和示范街100%的餐饮单位都要建立实施承诺制度，并与监管部门签订食品安全承诺书。

（四）全面落实“五个统一”。

1.统一亮照、亮证和监督公示。全县100%的大、中型餐饮单位的卫生许可证或餐饮服务许可证和工商营业执照统一张贴上墙；全县100%的大、中型餐饮单位、示范街100%的餐饮单位使用统一的监督公示牌，把监督电话、从业人员相片等公开上墙。

2.统一食品加工操作区域和设备设施分类标识。全县100%的大、中型餐饮单位、示范街100%的餐饮单位都要统一标识。

3.统一使用食品原辅料进货台账。全县100%的餐饮单位都要使用统一的食品原辅料进货台账进行管理。

4.统一管理健康证和培训合格证。把全县餐饮单位按大、中、小型三种类型进行分类，建立3种规格的证、照公示栏。全县100%大、中型餐饮单位的健康证和培训合格证统一上墙公示，示范街100%的餐饮单位的健康证和培训合格证统一上墙公示。要求全县餐饮单位的健康证和培训合格证总办证率80%以上，示范街餐饮单位办证率100%。

5.统一管理要求。制订统一的餐饮单位管理要求并上墙公示，全县100%的大、中型餐饮单位、示范街100%的餐饮单位都要统一管理要求。

（五）扎实开展餐饮服务食品安全整顿工作。

严厉查处餐饮单位无证经营行为，重点整顿学校食堂、建筑工地食堂、羌农家乐旅游点、小型餐饮单位。查处采购、使用病死或者死因不明的畜禽及其制品、劣质食用油等行为。加大对熟食卤味、盒饭、冷菜等高风险食品和餐具清洗消毒等重点环节的监督检查力度。全县餐饮单位办理卫生许可证或餐饮服务许可证和工商营业执照总办证率95%以上，示范街餐饮单位办证率100%。

七、工作步骤

（一）组织部署阶段(2012年5月)

制定餐饮服务食品安全示范县创建工作实施方案，组建食品安全示范县创建工作领导小组，确定创建单位，落实创建街道，召开动员会进行工作动员部署。

（二）组织实施阶段(2012年6月—8月底)

1.全面指导督促餐饮单位积极开展创建活动，收集整理创建资料。各乡镇各相关部门将按要求落实具体措施，引导餐饮服务单位达到示范店的标准，并在规定时间内完成目标任务，使全县餐饮环节达到全国餐饮服务食品安全示范县的考核标准。

2.县创建工作领导小组不定期对创建工作进展情况进行督导。

3.充分运用传媒，采取多种形式，开展创建餐饮服务食品安全示范县宣传活动，提升示范创建影响力，同时接受社会和舆论监督。

（三）总结验收阶段(2012年9月)

年底前，对示范创建工作进行自检自查，总结创建工作中的亮点和经验，对存在的问题进行剖析和建议，并形成书面报告，迎接省统一组织的评估验收。县政府将对示范创建工作落实到位，评分结果好的单位，给予表彰奖励；对工作落实不到位，创建效果差的单位给予通报批评。

八、 工作要求

（一）加强组织领导。各成员单位和乡镇要成立创建省级餐饮服务食品安全示范县工作领导小组，负责领导、指导和协调全县餐饮服务食品安全示范工作。各乡镇（社区）、各职能部门要制定实施方案，做好动员部署，分解创建任务，明确创建职责，确保创建工作的顺利实施。

（二）强化协调配合。创建国家级餐饮服务食品安全示范区工作是一项系统工程，各镇（社区）、各职能部门要严格按照职责分工和工作制度要求，加强协调配合、加强信息通报，努力消除监管盲区死角，齐心协力做好创建各项工作。

（三）抓好典型示范。县食安委办公室和县食品药品监督管理局要切实加强对创建工作的督查调研，及时总结好的经验做法，树立典型，及时推广，促进工作的整体推进。
