# 茂县人民政府办公室关于印发进一步加强和规范保安服务管理的通知

各乡（镇）人民政府、县直各部门：

为进一步规范我县保安服务市场，强化保安队伍管理，提高保安服务水平，充分发挥保安队伍在协助公安机关维护社会治安、预防和打击违法犯罪，构建和谐社会方面的积极作用。依据国务院《保安服务管理条例》、《企业事业单位内部治安保卫条例》等有关法律、法规以及上级公安机关关于规范保安服务行业相关文件精神，现结合我县实际，就进一步加强和规范保安服务管理有关工作通知如下：

一、单位自行招用保安员的条件

（一）自行招用保安员的单位应具备的条件

1．依据《保安服务管理条例》第二条规定，机关、团体、企业、事业单位和物业服务企业，统称自行招用保安员的单位。

2．自行招用保安员的单位应当具有法人资格，有符合《保安服务管理条例》条件的保安员，有健全的保安服务管理制度、岗位责任制度和保安员管理制度。

3．自行招用保安员的单位，应当自开始保安服务之日起30日内向阿坝州公安局备案。自行招用保安员的单位不再招用保安员进行保安服务的，应当自停止保安服务之日起30日内到备案的公安机关撤销备案。

4．自行招用保安员的单位不得在本单位以外或者物业管理区域以外提供保安服务。

5．娱乐场所应当依照《娱乐场所管理条例》的规定，从保安服务公司聘用保安员，不得自行招用保安员。

（二）保安人员应具备的条件

年满18周岁，身体健康，品行良好，具有初中以上学历的中国公民可以申领保安员证，从事保安服务工作。申请人经设区的市级人民政府公安机关考试、审查合格并留存指纹等人体生物信息的，发给保安员证。

二、清理整治的范围和重点

（一）整治的重点单位

重点整治厂矿、企业、重点单位、事业单位、娱乐场所、物业管理。

（二）整治的内容

1．未经许可，擅自从事保安服务、保安培训活动的组织或个人的整治和查处。

2．对自行招用保安员的单位审核、备案以及招用不符合规定条件的人员担任保安员的整治和查处。

3．对保安服务公司设立分公司和跨区域开展保安服务未按规定备案的整治和查处。

4．对娱乐场所未按规定与保安服务企业签订保安服务合同，配备专业保安人员的整治和查处。

5．对保安人员违法违规行为的查处和整治。

6．保安从业单位指使、纵容保安员阻碍依法执行公务、参与追索债务、采用暴力或者以暴力相威胁的手段处置纠纷的查处和整治。

7．保安员穿着、佩戴仿制人民警察制式服装、标志的查处和整治。

三、整治的工作步骤和措施

（一）各单位自行清理整治阶段。（5月1日至5月底）

各机关、企事业单位、物业、娱乐场所对照整治的重点内容自行查找整改存在的问题，对无证保安人员一律清退，不得从事保安工作。

（二）公安机关集中清理整治阶段。（6月1日以后）

茂县公安局将按照《保安服务管理条例》、《企业事业单位内部治安保卫条例》及其他相关法律法规对未及时自行清理整改的单位进行严格依法整治和查处。

四、组织领导

茂县公安局成立以党委书记、局长黎永胜任组长，党委委员、副局长赵如全、苏勇任副组长，治安大队大队长和各派出所所长为成员的清理整治领导小组。办公室设在县治安大队，由治安大队长陈健兼任办公室主任，具体负责全县保安服务清理整治行动的组织、指导和协调工作。

五、工作要求

（一）高度重视。全面开展规范保安服务管理工作是为了更加深入贯彻落实《保安服务管理条例》，是充分发挥治安辅助力量作用，深化社会面治安管控、维护当前社会治安稳定的一项重大决策。各单位要充分认识其重要性和必要性，切实统一思想，提高认识。

（二）遵章守法。各机关、企事业单位、物业、娱乐场所要严格遵照《企事业单位内部治安保卫条例》和《保安服务管理条例》相关规定，进行保安队伍的管理和使用。

（三）严肃责任。各机关、企业、事业单位、厂矿、物业、娱乐场所在规定时限内未及时清理本单位不符合规定条件的保安员的，以及其他违反《保安服务管理条例》、《企业事业单位内部治安保卫条例》规定未及时整改的，公安机关将严格依法查处。
