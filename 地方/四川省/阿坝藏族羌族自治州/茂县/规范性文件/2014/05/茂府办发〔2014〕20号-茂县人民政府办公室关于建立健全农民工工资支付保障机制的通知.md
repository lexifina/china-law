# 茂县人民政府办公室关于建立健全农民工工资支付保障机制的通知

各乡（镇)人民政府、县直有关部门：

为贯彻落实《四川省人民政府办公厅关于建立建设施工领域欠薪处理责任制的通知》（川府办发〔2012〕70号）和《阿坝州人民政府办公室关于印发进一步完善农民工工资支付保障机制的意见》（阿府办发〔2013〕14号）精神，根据我县实际，现就建立健全我县农民工工资支付保障机制有关事项通知如下：

一、施工单位责任

在我县境内建设铁路、公路、交通、水利、水电、市政基础设施以及其它基础设施工程项目建设的施工单位，在与项目业主签订工程项目施工合同后5日内，按工程总造价5%的比例将民工工资保证金缴纳到县人力资源和社会保障局指定的银行专户。各施工单位在支付民工工资时，必须按照“按时足额，直接支付”的原则，将民工工资直接支付或以银行转账的方式支付给民工本人，严禁将民工工资支付给“小老板”、“包工头”、“班组长”或其他人。各施工单位支付民工工资的工资表或其它能证明支付工资的有效凭据必须保存两年以上备查。

二、业主单位责任

各业主单位必须加强对工程项目民工工资支付的监督力度，在向工程项目施工单位拨付工程款时，必须依据县人力资源和社会保障部门办理的“民工工资发放审核表”后，方能拨付。工程项目在竣工验收前，若有拖欠工资行为的，业主单位不予验收。

三、有关部门工作职责

县人力资源和社会保障局负责综合协调工作，加强日常执法检查，对涉及拖欠民工工资问题的举报投诉，应加大行政处理、处罚力度。对劳动工资产生的争议，采取“快立、快审、快结”方式解决，提高行政调解和仲裁调解力度，切实维护当事人合法权益。

县城乡规划建设和住房保障局对违法发包分包、挂靠承包、层层分包等违法行为，应加大打击力度。建设项目的施工单位未足额缴纳民工工资保证金的，不予发放施工许可证等开工手续。工程项目在竣工验收前，应把县人力资源和社会保障局出具有无拖欠民工工资的意见作为验收条件，若有拖欠民工工资，该工程项目不予验收。负责协调因工程质量、计量计价、结算争议、劳务承包合同纠纷等引起的工资争议事件。施工单位恶意拖欠民工工资，坚决予以从重处罚，直接纳入黑名单，并清退出本县建筑市场。

县公安局负责打击建设领域的黑恶势力和以讨要工资为名追讨工程款，受理、处理欠薪逃匿案件和涉嫌拒不支付劳动报酬、诈骗犯罪的工资拖欠案件，并对因此引发的堵塞交通、围堵政府机关或用人单位等突发性和群体性事件进行处理。

县司法局负责指导基层调解组织化解农民自建房拖欠劳务费纠纷问题，协调相关部门疏通非企业拖欠劳务费的解决渠道，提供相关法律援助。

县信访局负责《信访条例》等法律法规的普法宣传，教育引导民工严格依法信访，依法维权。

县总工会负责法律宣传监督，积极与有关部门沟通，协调处理工资拖欠问题。

县财政局负责政府性工程款资金筹措及拨付，配合有关部门做好民工工资支付保障工作。

县纪检监察部门负责民工工资工作的监督和问责。

县发展改革、县交通运输、县水务部门负责督促解决铁路、公路、水利水电建设施工企业发放民工工资问题。

县国土资源管理局负责督促解决征地拆迁居民安置小区工程、泥石流和滑坡工程项目的民工工资问题。

县城市管理局负责处理市政、园林、环卫等工程及系统内的民工工资问题。

县文化体育广播影视新闻出版局负责督促解决文化娱乐场所等民工工资问题。

县食品药品监管局负责督促解决餐饮行业民工工资问题。

县工商行政管理局负责监督企业、个体经济组织经营行为，严格注册注销登记管理，协助处理民工工资问题。

县工业园区管委会负责处理园区内工程拖欠民工工资问题。

各施工项目的主管部门负责督促该项目施工单位缴纳民工工资保证金，支付民工工资情况，协调计量计价、追加工程款、结算争议等源头性欠薪案件。在工程项目竣工验收前，有拖欠工资行为的，不予验收。

四、严肃工作纪律

县级有关部门要密切配合，整体联动，互通信息，明确职权，落实责任。要认真督促各项目业主和施工单位严格按照要求全面推进农民工工资支付保障工作，严禁相互推诿、不理不问，对造成严重后果的将严格追究相关责任人责任。

特此通知。
