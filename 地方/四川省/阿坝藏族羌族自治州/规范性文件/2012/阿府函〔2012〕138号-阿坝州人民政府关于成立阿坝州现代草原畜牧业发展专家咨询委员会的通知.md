# 阿坝州人民政府关于成立阿坝州现代草原畜牧业发展专家咨询委员会的通知

阿坝州人民政府

关于成立阿坝州现代草原畜牧业发展

专家咨询委员会的通知

阿府函〔2012〕138号

各县人民政府，州直有关部门：

为强化专业支持和技术支撑，推动我州现代草原畜牧业发展，经州政府研究，同意成立阿坝州现代草原畜牧业发展专家咨询委员会（以下简称“专家咨询委员会”），现将有关事宜通知如下。

专家咨询委员会成员将根据工作需要进行动态调整。

二、专家咨询委员会基本职责及工作要求

（一）专家咨询委员会负责对阿坝州现代草原畜牧产业发展各阶段重大技术问题、建设方案、研究成果、法规执行、经费预算及使用情况等进行研讨、论证和评审；专家咨询委员会的意见将作为阿坝州现代草原畜牧产业发展与决策的重要参考依据。

（二）专家咨询委员会成员在为产业发展提供咨询的过程中，应从国家利益出发，坚持实事求是原则，遵守国家相关的知识产权和技术保密协议，独立、客观、公正、负责地提供个人意见，依照要求按时保质完成咨询任务。

（三）专家咨询委员会办公室设在州畜牧兽医局，由州畜牧兽医局总畜牧师陈刚同志兼任办公室主任，州畜牧兽医局生产信息科科长谢开英、动物疫病预防控制中心主任谭本旭、畜牧工作站站长蹇尚林同志负责处理日常事务。
