# 阿坝州人民政府阿坝军分区关于表扬2011年度征兵工作先进单位的通报

阿坝州人民政府阿坝军分区

关于表扬2011年度征兵工作先进单位的通报

阿府函〔2012〕145号

各县人民政府、县人民武装部，州直有关部门：

在2011年度征兵工作中，各县政府和兵役机关认真执行国务院、中央军委的征兵政策规定和州政府、阿坝军分区的征兵命令，采取有效措施，积极应对“当兵冷”、“征兵难”等问题，狠抓征兵工作落实，圆满完成了省政府、省军区赋予我州的新兵征集任务。

为鼓励先进、树立典型，进一步推动全州征兵工作健康发展，州政府、阿坝军分区决定对阿坝县人民政府征兵办公室、红原县人民政府征兵办公室、汶川县人民政府征兵办公室、松潘县人民政府征兵办公室等4个单位予以通报表扬。

希望受到表扬的单位保持和发扬成绩，戒骄戒躁，再接再厉，在今后的工作中取得更大成绩。各县、州直有关部门要以先进单位为榜样，开拓进取，扎实工作，高标准、高质量完成年度征兵任务，为军队建设、全州经济社会跨越发展和长治久安作出新的贡献。

阿坝军分区、阿坝州人民政府

2012年10月15日
