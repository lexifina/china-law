# 阿坝州人民政府关于通报表扬阿坝州参加第十三届西部国际博览会先进单位的决定

阿坝州人民政府

关于通报表扬阿坝州参加第十三届西部国际

博览会先进单位的决定

阿府函〔2012〕168号

各县人民政府，州直各部门，卧龙管理局：

今年，各县、州直有关部门在组织参加第十三届西部国际博览会（以下简称：西博会）工作中，组织有力、准备充分、推进有序、配合密切，在加强对外联系、提升开放合作水平、深化招商引资等方面取得了显著成效。通过州、县共同努力，本届西博会我州展馆主题突出、特色鲜明，充分展示了灾后重建以来我州在推进经济社会发展中取得的巨大成就、特色优势和发展前景，给参会客商留下了深刻印象，进一步提升了阿坝州知名度和影响力；招商引资推介项目转型实在、结构合理，更加符合我州产业结构调整需要，签约金额和产品贸易金额均创历史新高；科学利用西博会合作交流平台，分别与商务厅、省招商引资局、四川博览局签订了战略合作协议，形成了双方合作交流的长效机制，得到了省领导的充分肯定。

为鼓励先进、树立典型，经州委、州政府研究，决定对州商务局等8个第十三届西博会参会参展组织工作表现突出单位和汶川县等6个招商引资成效显著单位予以通报表扬（名单附后）。

希望受表扬的单位珍惜荣誉、再接再厉、再创佳绩。各县、州直各部门要按照“发展为要、稳定为重、民生为本、团结为根、党建为基”的总体要求和建设“五个阿坝”的工作部署，立足岗位，求真务实，开拓进取，进一步增强做好招商引资工作的责任感和使命感，不断巩固和深化我州参加本届西博会的成果，及早谋划、精心筹备好明年第十四届西博会的参会参展工作，推动招商引资工作再上新台阶，为推进我州跨越发展和长治久安奠定坚实基础。

特此通报。
