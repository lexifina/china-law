# 阿坝州人民政府关于进一步加强行政效能建设的意见

阿坝州人民政府

关于进一步加强行政效能建设的意见

阿府发〔2012〕16号

各县人民政府，州直各部门，卧龙管理局：

为深入推进我州行政效能建设，规范行政行为，提升工作水平，改进机关作风，创造更加规范、高效、诚信、开放的政务环境和发展环境,根据《四川省人民政府办公厅关于印发2012年省政府部门机关行政效能建设工作要点的通知》（川办发﹝2012﹞11号）精神，现就进一步加强我州行政效能建设提出如下意见。

一、深化行政审批制度改革，优化政务服务职能

（一）全面清理行政权力，规范行政审批事项

1.全面清权。按照“谁行使、谁清理”的原则，从具体行使行政职权的机构或岗位入手，依据法律、法规、规章、规范性文件及部门“三定”方案等设定的行政权力，对本部门、本系统的行政权力进行清理。清理内容包括：行政许可权、行政处罚权、行政强制权、行政征收权、行政裁决权、行政确认权、行政给付权、行政征用权、监督检查权、非行政许可审批权、行政事业性收费等;部门重大项目、资金分配、资产处置等重要事项决策权;本单位其他依法行使的行政权力。各部门内部人员录用、调动、任免、奖惩权，财务支配、物资采购、分配等权力由部门自行清理。

2.依法确权。由州、县政府法制办会同编办、政府政务服务中心等部门，依法对各部门上报的行政权力逐项进行审核确认，并提出撤销、合并、保留、调整等意见，及时反馈给部门，经部门再次修改报清理领导小组办公室复核汇总后，报同级政府审定并向社会公布。

3.合理放权。在确权的基础上，对有法律依据、应由基层行使但一直由上级机关越位行使的行政权力和虽应由州级行使但下放后不影响社会管理、有助于提高效率的行政权力，一律下放给基层。在以往下放行政权力的过程中，没有下放或下放不彻底的，一并下放。行政权力下放后，部门职能发生变化的，由州委编办统一审查确定。

4.有效控权。对保留的每一项行政权力都要进行规范和有效控制，使行政权力规范、有序、公开运行。一是严格规范和控制行政审批权。按照行政审批权相对集中改革要求，坚持“应进必进”原则，将确定后的行政审批项目，全部纳入政务大厅实行“一站式”审批办理，按照“充分授权、即受又理”的原则，对窗口审批充分授权，坚决禁止里也办外也办，确保“两集中、两到位”改革的职能归并率和授权率达100%；行政审批项目入驻大厅应进必进率达到100%；即办件当场办结率、承诺件按期办结率均达100%。二是严格规范和控制行政处罚权。凡确认具有行政处罚权的，继续做好行政处罚裁量权的细化、量化及程序规则制定工作，报州政府法制办核准后制定“行政处罚裁量标准”。没有完成细化和量化工作的，一律按行政处罚幅度下限执行。对新出台和修改的法律法规，行政处罚裁量标准实时进行调整。

（牵头单位：州政府法制办；责任单位：各县、州监察局、州政府政务中心、州委编办等州直行政审批部门）

（二）加快政务服务标准化建设

1.行政审批项目标准化。按照州、县政府公布的行政审批事项目录，明确保留的行政审批事项和转变管理方式的公共服务事项的审批程序、审批环节、审批条件，在统一名称、数量的同时，实行动态管理，并按照国家和省的有关要求适时进行清理和调整。

2.行政审批项目流程标准化。依照“八公开”的原则（即：公开设立审批事项的法定依据、申请条件、申报材料、办事程序、办理时限、收费依据及标准、联系方式和投诉渠道），对行政审批事项按规范编制办事流程和指南，简化程序、优化流程、减少办理环节、缩短办理时限，并通过多种渠道向社会公开。

3.服务类型和模式标准化。立足我州实际，以行政审批事项和公共服务事项为主，积极拓展服务领域和服务内容，不断满足企业和群众的服务需求；在做好大厅受理服务的基础上，要积极做好全程代办服务、延时办理服务、预约办理服务、特别通道服务、上门办理服务、信息查询服务和政策法规咨询服务，强化“96196”政务服务热线电话在线值守应答。

4.推行行政审批服务公开承诺制。在州直行政审批部门推行政务服务公开承诺制度。各相关部门主要负责人，要对本部门的行政审批及相关服务事项的办理原则、办理方式、办理时限、办理地点及收费依据和标准等情况向社会公开承诺，接受社会和公众的监督。

（牵头单位：州政府政务中心；责任单位：各县、州监察局、州政府法制办等州直行政审批部门）

（三）加快完善电子政务平台建设

加快完善州级电子政务大厅的格式文本、示范表格等相关数据录入，强化工作时间在线值守，不断提升与申请人互动的服务功能。进一步提升行政审批通用软件系统的运行服务功能，强化窗口前台接件录入系统，到部门后台按流程办理的运行模式，提高办事效率；加强电子政务操作应用培训，结合行政审批通用软件系统、行政效能电子监察系统、电子政务大厅等电子政务建设，加快实现行政审批事项服务网上申请、受理、咨询、查询等服务功能。力争今年底，开通金川、若尔盖、茂县、松潘、黑水县政务中心行政审批通用软件系统和电子政务大厅，实现与省、州联网运行；其余各县明年底完成，实现省、州、县联网同步运行。（牵头单位：州政府政务中心；责任单位：各县、州监察局、电信阿坝分公司、州直行政审批部门）

（四）完善“绿色通道”、并联审批、联合办件服务

建立健全重点建设项目、招商引资项目、重点企业的定期联系机制，完善“政务服务小分队”的服务职能，进一步细化服务措施，创新服务方式，努力做好审批项目“绿色通道”服务和全程代理服务，积极主动地为项目和投资者提供良好的政务服务。凡是涉及两个以上部门的审批事项，按照“统一受理、提前介入、信息共享、同步审查、公开透明、限时办结”的原则，实行并联审批，联合办件。建立首办单位牵头负责制，积极推进审批事项联审会办工作落实。同时，积极探索投资项目、建设项目、市场准入项目的并联审批服务方式，提高服务质量和效率。（牵头单位：州政府政务中心；责任单位：各县、州直行政审批部门）

（五）加快政务服务体系建设

将政务服务体系建设纳入基本公共服务体系建设范畴，将政务服务中心场地等硬件建设纳入基本建设项目投资立项解决。深入推进三级政务服务体系建设，突出抓好县级政务服务中心建设，加快推进乡镇便民服务中心建设，结合创新社会管理、建设和谐社会，将农林、国土资源、计生、民政等行政管理事项和就业、社保、低保、救济及新农合、涉农补贴等便民、利民、惠民帮扶项目等全部纳入便民服务中心，不断拓展服务领域，创新便民服务方式，方便基层群众办事。力争到2013年底，基本完成州、县、乡（镇）三级政务服务体系建设。（牵头单位：州政府政务中心；责任单位：各县、州监察局、州民政局等州直有关部门）

二、推进政务公开，规范行政权力运行

（六）大力推进行政权力公开透明运行

按照推进行政权力公开透明运行工作方案确定的进度要求，实现州直各部门行政权力公开透明运行。依托利用现有的电子政务大厅、电子监察平台、行政执法部门业务专网等载体，充分整合各类电子政务资源，建立州、县互联互通、统一规范的行政权力公开透明运行平台，实现行政权力公开透明运行，确保行政行为依法、透明、廉洁、高效。再公开一部分州级非行政审批职能部门的管理、服务事项及办事程序。（牵头单位：州政府法制办；责任单位：各县、州直有关部门）

（七）规范公共资源交易中心建设

加强招投标活动主体诚信体系建设，建立完善诚信记录，坚持“公开、公平、公正”的原则，进一步改进、优化工程建设项目招标、评标规则，完善政府采购、国有产权交易各个环节的规范程序，确保各项工作“依法、阳光、廉洁、高效”运行。推进电子招标工作,通过发挥现代科技优势解决围标串标、评标专家寻租等突出问题。（牵头单位：州发展改革委、州公共资源交易中心；责任单位：各县、州政府政务中心等州直有关部门）

（八）加强县级政府政务公开

按照国务院办公厅关于开展依托电子政务平台加强县级政府政务公开工作的要求，各县要全面梳理、清理并严格规范信息公开事项、行政职权事项、便民服务事项，编制政务公开和政务服务目录。加强规划设计，整合信息化建设资源，依托全省统一的电子政务平台，加强县级政府政务公开和政务服务工作。（牵头单位：州政府办公室；责任单位：各县、州经信委、州监察局、州财政局、州质监局、州政府法制办、州政府政务中心）

（九）深化基层政务公开

大力推进乡镇（街道）政务公开，建立健全公开制度，规范公开内容，不断完善公开程序、方式及监督管理等配套措施。利用各种便民方式和渠道，及时公开城乡社区居民关心的事项，重点公开“三农”工作、环境保护、土地使用、城乡社会救助等中央和省、州、县保障和改善民生、强农惠农政策等情况以及其他群众高度关心的问题。健全农村集体资金、资产、资源管理制度，建立健全村（居）务监督委员会，完善监督机制，切实加强对村（居）干部的监督，推进村（居）务公开。对已完成治理任务的村务公开和民主管理“难点村”开展“回头看”，巩固治理成果。（牵头单位：州民政局；责任单位：各县、州政府各部门）

（十）大力推进财政信息公开

继续做好政府收支总预算、总决算的信息公开，进一步细化公开内容。有序推进部门预算信息公开，逐步扩大公开范围。稳步推进“三公”经费公开。制定详细的公开方案，细化和完善公开内容，统一公开格式，明确时限要求，确保公开实效。加强对基层财政信息公开工作的指导，完善基层财政专项资金公开内容，积极推进乡镇财政预算信息公开。加大财政专项资金公开、公示力度，进一步扩大公开范围和资金规模。（牵头单位：州财政局；责任单位：各县、州直各部门）

（十一）深入推进工程建设领域信息公开

制订和实施《阿坝州工程建设领域项目信息公开共享平台管理办法》、《阿坝州工程建设领域项目信息公开守信激励和失信惩戒管理办法》，及时制订、发布行业项目信息和信用信息公开目录。根据省行业工程建设不良行为的认定标准、信息管理办法和信用信息运用制度，通过统一平台，实现信用信息的互联互通和互认共享。加大不良行为信息公开力度，基本实现不良行为信息公开全覆盖。按照国家发布的评价指标体系，开展评价活动。（牵头单位：州经信委；责任单位：各县、州发展改革委、州监察局、州城乡建设住房局、州交通运输局、州水务局、州政府政务中心等州直有关部门）

（十二）着力加强公开载体建设

加强政府网站建设和管理，进一步规范政府信息公开目录分类体系和公开流程，促进全州政府信息公开规范统一。加强交通出行、教育教学、居民住房、企业开办、社会保障、医疗卫生等领域资源整合利用，提高在线服务能力。畅通政府和群众互动渠道，办好领导信箱、在线访谈等栏目，增强互动实效。推行政府网站站群集中管理、运维模式，深入开展州政府网站绩效评估，以评促建推动政府网站建设。升级改造电子政务大厅，将行政处罚、征收、强制、确认、裁决、给付及其他行政权力事项逐步纳入，提高电子政务大厅承载和服务能力。创新政府信息公开方式和途径，通过微博、声讯服务平台、3G网络服务平台等拓宽政府信息公开渠道，为公众及时查阅、获取政府信息提供便利。（牵头单位：州政府信息公开办；责任单位：各县、州直各部门）

三、加强监督问责力度，确保政务服务质量

（十三）强化重大决策督促检查

适应深入贯彻落实科学发展观的要求，认真研究督查工作规律，建立健全督查领导体制，创新督查工作运行机制，完善集决策督查、专项查办、结果运用和督查调研于一体的督查工作体系。紧紧围绕重大决策和关系人民群众切身利益的民生政策，加大跟踪督查力度。建立重点工作任务落实情况日常监控长效机制，强化对专项工作、重点工作的现场督查和明察暗访，形成狠抓落实的良好风气。（牵头单位：州委州政府督查室；责任单位：各县、州政府各部门）

（十四）加强行政效能监察

加大网上审批监督、公共资源交易监督等电子监察系统建设工作力度，逐步实现网上申报、网上受理、网上审批、网上电子监察，构建集实时监控、预警纠错、投诉处理、绩效评估、决策分析于一体的电子监察系统。通过电子监察、专项监察、受理投诉、责任追究等方式，不断创新和改进行政效能监察工作方法。积极探索开展行政执法、公共资源交易等方面的电子监察方法，逐步建设全方位的行政效能电子监察系统。开展专项监察，加强行政效能投诉电话“96960”的设立、宣传和管理，拓宽投诉渠道，完善投诉处理机制，及时处理群众诉求。全面推行行政问责制度，明确问责范围，加大责任追究力度。对不履行或不正确履行职责以及行政不作为、慢作为、差作为、乱作为等问题要严肃查处，严格实行责任追究。在实施责任追究时，采取责令公开道歉、停职检查、引咎辞职、责令辞职、免职等方式进行。责任追究由监察机关或者任免机关实施，提出监察建议涉及组织处理的，按照有关规定执行。（牵头单位：州监察局；责任单位：各县、州直各部门）

四、加强机关自身建设，提高政务服务水平

（十五）加强作风建设

要进一步增强各级行政机关工作人员的宗旨意识、公仆意识、大局意识、服务意识、诚信意识和廉洁意识，着力解决行政机关作风方面存在的突出问题。大兴调查研究、开拓创新、艰苦奋斗、求真务实之风，以“治庸提能力、治懒增效率、治散聚合力”为突破口，加大“庸、懒、散”的治理力度，切实改进工作作风。着重围绕机关效率、作风、执行力等关键环节，加大效能监督检查力度。创新监督方式，通过政府网站、报刊、电视、广播等媒体，广泛征求影响全州机关行政效能、损害发展环境的突出问题及整改建议。完善办事群众评价部门窗口及窗口工作人员制度，主动深入到企业、单位和群众中听取意见和建议，自觉接受服务对象的监督和建议。聘请人大代表、政协委员、院校、企业等各界代表作为行风、政风监督员，对机关作风开展明查暗访专项活动，对影响效能建设的不正之风进行曝光，推动机关行政效能建设深入持久地开展下去。（牵头单位：州政府办公室、州监察局；责任单位：各县、州直各部门）

（十六）健全落实“三项制度”

健全行政问责制度，明确问责范围，规范问责程序。指导督促有关部门制定、细化、完善、落实具有针对性和可操作性的“三项制度”（即：限时办结制、首问责任制、责任追究制）。适时对州直机关落实“三项制度”的情况进行督促检查，及时推广好的做法和经验，发现问题及时提出整改意见。（牵头单位：州监察局；责任单位：各县、州直各部门）

（十七）完善制度体系

要把行之有效的做法固化为制度规范，进一步细化完善深化政务公开加强政务服务、深入推进机关行政效能建设的具体制度，继续深化完善“三项制度”配套制度、政府信息公开条例配套制度、公共企事业单位办事公开制度、科学民主决策制度、招投标管理制度、绩效管理办法等制度规范，形成按制度办事、靠制度管人的长效机制。（牵头单位：州效能办；责任单位：各县、州直各部门）

（十八）深入推进绩效管理

修订和完善目标绩效管理办法，建立健全科学合理的绩效评估指标体系和评估机制，进一步深化州政府部门绩效管理，在部门行业系统和内设机构开展绩效管理。深入推进州政府目标绩效管理工作，扎实开展中期评估和系统总结，逐步构建州、县两级规范的政府目标绩效管理体系。扎实做好日常督查考评工作，建立健全绩效问责及结果运用制度，严肃工作纪律，防止弄虚作假，确保绩效管理公正、规范、有序。（牵头单位：州目标办；责任单位：各县、州直各部门）
