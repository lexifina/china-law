# 阿坝州人民政府关于实施征地统一年产值标准的通知

阿坝州人民政府

关于实施征地统一年产值标准的通知

阿府函〔2014〕146号

各县人民政府：

阿坝州新一轮征地统一年产值标准已经省政府审查同意，于2015年1月1日起实施，现予以公布。

在执行新的征地统一年产值标准时，各县要按照相关要求切实做好风险评估工作，完善处置预案，依法做好征地补偿工作，确保新老标准顺利衔接过渡，保障被征地农民合法权益，切实维护社会稳定。
