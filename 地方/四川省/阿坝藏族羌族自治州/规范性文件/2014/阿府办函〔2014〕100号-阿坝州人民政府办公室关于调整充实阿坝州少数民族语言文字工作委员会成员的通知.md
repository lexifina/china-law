# 阿坝州人民政府办公室关于调整充实阿坝州少数民族语言文字工作委员会成员的通知

阿坝州人民政府办公室

关于调整充实阿坝州少数民族语言文字

工作委员会成员的通知

阿府办函〔2014〕100号

州少语委负责指导全州少数民族语言文字工作，做好少数民族语言文字的调查、研究、编译、保护和管理等工作。

二、州少语委办公室及职责

州少语委办公室设在州民委，李华同志兼任办公室主任，阿根同志兼任办公室副主任，具体负责拟订全州少数民族语言文字工作规划并监督实施，组织协调民族语言文字规范化、标准化和信息化工作。其中，藏语言文字规范化管理的具体工作由州编译局负责。

各县要尽快调整充实少数民族语言文字工作委员会及其办事机构，切实加强领导，依法管理少数民族语言文字工作，大力推广少数民族语言文字的规范化使用。

特此通知。
