# 阿坝州人民政府办公室关于成立阿坝州社区治理工作领导小组的通知

阿坝州人民政府办公室

关于成立阿坝州社区治理工作领导小组的通知

阿府办函〔2014〕109号

各县人民政府，州直各部门，卧龙管理局：

为认真贯彻落实《中共四川省委办公厅、四川省人民政府办公厅关于全面深化改革加强基层群众自治和创新社区治理的通知》（川委办〔2014〕27号）精神，进一步加强全州社区治理工作，形成齐抓共管协力推进社区治理工作格局，州人民政府决定撤销全州村务公开协调小组，成立阿坝州社区治理工作领导小组。现将有关事宜通知如下。

一、主要职责

负责制定全州城乡社区治理和村（居）务公开政策，协调解决社区建设工作中的重大问题，指导各地推进社区治理和村（居）务公开。
