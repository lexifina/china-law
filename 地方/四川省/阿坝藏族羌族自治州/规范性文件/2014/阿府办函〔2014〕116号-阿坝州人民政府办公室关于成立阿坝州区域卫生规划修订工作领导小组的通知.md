# 阿坝州人民政府办公室关于成立阿坝州区域卫生规划修订工作领导小组的通知

阿坝州人民政府办公室

关于成立阿坝州区域卫生规划修订工作领导小组的通知

阿府办函〔2014〕116号

各县人民政府，州直有关部门：

为深入贯彻落实《国家卫生计生委、财政部、中央编办、发展改革委和人力资源社会保障部关于推进县级公立医院综合改革的意见的通知》（国卫体改发〔2014〕12号）精神，切实做好《阿坝州区域卫生规划（2011—2020）》修订工作，加快推进我州医药卫生体制改革，优化卫生资源配置，建立体系完整、分工明确、功能互补、密切协作的整合性医疗卫生服务体系，经州政府领导同意，决定成立阿坝州区域卫生规划修订工作领导小组，组成人员如下。

组  长:杨绍林    州政府副州长

副组长:卢晓军    州政府副秘书长

王树云    州卫生局局长

成  员:周敬华    州委编办副主任

余志蓉    州发展改革委副主任

胡昌明    州财政局副局长

李根全    州人力资源社会保障局副局长

泽仁达瓦  州国土资源局局长

领导小组办公室设在州卫生局，由王树云同志兼任办公室主任，负责处理日常工作。该领导小组为临时机构，规划修订工作完成后自行撤消。

阿坝州人民政府办公室

2014年11月19日
