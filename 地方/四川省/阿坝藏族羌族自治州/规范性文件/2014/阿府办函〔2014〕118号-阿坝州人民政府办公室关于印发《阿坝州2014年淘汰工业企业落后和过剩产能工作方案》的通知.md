# 阿坝州人民政府办公室关于印发《阿坝州2014年淘汰工业企业落后和过剩产能工作方案》的通知

阿坝州人民政府办公室

关于印发《阿坝州2014年淘汰工业企业落后和过剩

产能工作方案》的通知

阿府办函〔2014〕118号

各县人民政府，州直有关部门：

经州政府领导同意，现将《阿坝州2014年淘汰工业企业落后和过剩产能工作方案》印发你们，请认真抓好贯彻落实。

阿坝州人民政府办公室

2014年11月19日

阿坝州2014年淘汰工业企业落后和过剩产能工作方案

为加快转变经济发展方式，全力推进川西北生态经济示范区建设，促进全州产业结构调整与优化升级，推进优势特色产业健康发展和节能降耗，确保全面完成全州2014年工业节能降耗目标任务，根据《国务院关于进一步加强淘汰落后产能工作的通知》（国发〔2010〕7号）、《产业结构调整指导目录（2011年版）》要求，结合全州工业经济实际，制定本方案。

一、总体要求

深入贯彻落实科学发展观，以调整产业结构为主线，以生态文明建设为目标，严格执行国家和省关于调整结构、节能降耗、淘汰落后和过剩产能的规定，有计划地关闭和淘汰州内生产工艺装备落后、节能减排不达标、工业污染较重、资源综合利用率低、安全生产条件不达标的高耗能、高污染企业以及“五小企业”。对整体淘汰落后和过剩产能的企业进行全面关停，对淘汰的生产设备进行废毁处理，防止死灰复燃和异地转移。通过淘汰落后和过剩产能，推动各类生产性资源向优势特色产业转移集中，促进全州工业经济持续健康发展。

二、目标任务

2014年，我州计划淘汰落后产能67.8万吨。汶川县漩塔水泥有限责任公司、汶川县朋城水泥有限公司、汶川顺发电熔冶炼有限公司、四川川西磁业有限责任公司、水磨镇银山窝石灰石矿山、水磨镇陈家山杨柳湾二矿、雁门乡麦地沟村二组矿山、汶川县鑫霖矿业公司列入省淘汰落后和过剩产能计划（以下简称“淘能计划”）。其中，汶川县朋城水泥有限公司、汶川县漩塔水泥有限责任公司、汶川顺发电熔冶炼有限公司列入国家淘能计划。

三、工作原则

（一）坚持科学发展、统筹实施原则。按照“尊重科学、结合实际、合理规划、分步实施、多措并举”的工作方针，将淘汰落后和过剩产能与推进优势特色产业结构优化升级、实施“十二五”规划、节能降耗、生态环境保护等有机结合起来，全面推进全州工业经济发展方式的根本转变、发展质量的整体提升。

（二）坚持政策引导、依法淘汰原则。综合运用法律、经济和必要的行政手段，加大对企业的产业政策引导力度，充分发挥产业政策的约束作用和技术标准的门槛作用。认真执行环保、节能、安全、质量、资源利用、职业健康等法律法规，加大产业政策与信贷、环保、安全、节能等政策执行的协调配合力度，严格按照市场准入标准、行业准入条件，规范企业生产经营行为，进一步建立健全全州淘汰落后和过剩产能的长效机制，确保按期完成今年全州的淘能目标。

（三）坚持企业主体、市场导向原则。充分发挥市场配置资源的基础性作用，坚持以企业为主体、市场为导向，利用市场约束和资源约束增强的“倒逼”机制，综合运用差别电价、税收杠杆、信贷政策等手段引导企业自主淘汰落后产能，努力营造有利于落后产能退出的市场环境。

（四）坚持区别对待、优胜劣汰原则。按照我州“十二五”产业发展规划，立足州内产业实际，坚持扶优与压劣相结合、升级改造与淘汰落后相结合、兼并重组与关闭破产相结合，分类指导，有保有压，科学利用和消化已形成的过剩产能，努力提高资源的综合利用率，大力发展循环经济，优化产业布局和产品结构。

（五）坚持积极稳妥、有序推进原则。把解决当前发展问题与实施“十二五”规划结合起来，着力消除制约产业结构调整和淘汰落后产能的体制、机制障碍，科学把握结构调整力度和节奏，有序推进产业升级和结构优化。各淘能主体和责任单位要把淘汰落后和过剩产能与保持企业稳定结合起来，深入细致地做好关停企业和职工的思想工作，切实帮助企业做好转产升级，为企业谋发展、为职工谋利益、为创建和谐社会作贡献。

四、主要措施

（一）建立健全淘能工作机构。成立以州政府分管领导为组长，发展改革、经信、财政、人力资源社会保障、国土资源、环保、安监、质监、银监、国税、地税等部门分管领导为成员的阿坝州淘汰工业企业落后和过剩产能工作领导小组，领导小组办公室设在州经信委，负责日常工作。各县要成立相应的工作机构，切实履行淘能工作职责，明确职责分工，加强协调配合，形成工作合力，做到责任到位、措施到位、服务到位、监管到位。

（二）适度控制固定资产投资规模。各县、州直有关部门要认真执行国家产业政策，严格按照“十二五”产业发展总体规划，把好立项、土地、信贷、环评四个关口，为淘汰落后和过剩产能设定前置条件。投资主管部门在核准新（扩）建项目时，要坚持新增产能与淘汰的落后产能“等量置换”或“减量置换”的原则，防止新增落后产能，应当按照项目是否符合当前产业政策、是否有利于节能减排和资源综合利用、是否有利于保护和改善生态环境进行审批。

（三）严禁落后产能重复和违规扩建。按照国家有关环保、安全、能耗、资源综合利用和行业准入条件等政策法规规定，提高新（扩）建项目的准入门槛。加大对在建和拟建项目的清理整顿力度，对不符合国家产业政策和省、州产业发展规划、供地条件、环境保护、安全生产条件的工业项目，依法停止审批，严防低水平产业重复建设、产能过剩行业和落后产能的无序扩建。

（四）严格执行国家行业准入条件。依法关闭破坏资源、污染严重、能耗高、不具备安全生产条件的落后产能。对达不到行业准入条件的企业要坚决执行差别电价；对单位产品综合能耗高于国家限额标准和同行业先进水平又不及时认真整改的企业要严格实行惩罚性电价。

（五）加大企业技改与创新力度。充分发挥现代科技对产业升级的支撑作用，支持符合国家产业政策的产业和我州优势特色产业，用高新技术与先进适用技术实施技术改造和技术创新。围绕提升技术水平、改善产品品种、保护生态环境、保障安全生产、降低能耗、提高资源综合利用率等重点技改和创新内容，提升现有企业的整体实力和发展后劲；大力支持我州重点骨干企业加快节能降耗、污染治理的技改和创新，努力使我州优势特色产业的发展与全州生态建设同步，得到国家更多的鼓励和支持，变资源优势为产业优势。

（六）着力提高产业集中度。鼓励州内优势骨干企业以资产、资源、品牌和市场为纽带，加快实施兼并、收购、重组落后产能企业，着力推进州内优势特色产业集中化、大型化、基地化建设，提高产业集中度和资源保障度。积极促进新建园区内企业间尾气、废渣、废水的循环利用，大力推动全州循环经济快速发展，切实帮扶淘能重组后的企业走上生产一体化、经营规模化、产品多样化、资源综合利用化的发展道路，为创建资源节约型、环境友好型社会作贡献。

（七）严把招商引资质量关。坚定不移地实施开放合作战略，加大工业招商引资力度，做大做强做优民族工业经济。把好承接发达地区产业转移的质量关口，坚决防止盲目引进工艺落后、能耗高、污染重、资源浪费严重、产品附加值低且属国家《产业结构调整目录（2011年版）》中限制或淘汰类的产业，绝不以牺牲环境和资源为代价，换取短期、不可持续的经济发展。

（八）加大政策调控和处罚力度。强化政策约束与政策激励机制，统筹淘能工作与产业升级、经济发展、环境保护、生态建设、社会稳定的关系，建立健全促进全州落后产能退出的政策体系。对未按时完成淘汰工作任务的企业，质监部门要依法吊（注）销《工业产品生产许可证》；环保部门要依法吊（注）销《工业企业排污许可证》；安监部门要依法吊（注）销《安全生产许可证》；国土资源部门要依法吊（注）销《采矿许可证》。发展改革、经信等部门不予办理企业申报的新建立项、技改备案；经信部门不予办理企业申报进行行业准入公告的有关手续和各种政策性专项资金的申报。国土资源部门要停止审批这类企业新建或扩建项目的新增土地供应；税收部门要落实和完善资源与环境保护税费政策，按照国家规定取消税收优惠政策，并对已取得资源综合利用认证的淘能企业取消认定资格；工商行政管理部门要依法责令淘能企业办理变更经营范围、延迟工商年检、吊（注）销《工商营业执照》；电力主管部门要对其坚决执行差别电价、惩罚性电价直至停止供电；金融机构要对淘能企业禁止发放贷款和新增授信支持，避免信贷风险。

（九）充分发挥企业淘能的主体责任。州内淘能计划内企业要严格遵守环保、安全、节能、质量等法律法规规定，认真贯彻执行国家产业政策，积极履行社会责任与淘能职责，积极主动地淘汰落后产能。

五、工作要求

（一）全面落实责任。各县政府是淘汰落后和过剩产能的责任主体，对本县淘汰落后产能工作负总责，要坚决杜绝地方保护主义，从提升产业结构、增强企业生存力和产品竞争力的角度出发，积极承担起淘汰落后和过剩产能的职责，健全工作机制，采取有力措施，及时解决淘能工作中遇到的突出问题，确保淘能工作顺利进行。要切实承担本行政区域内淘能工作职责，严格执行相关的法律、法规和产业政策措施，组织督导淘能企业按要求与时限淘能，拆除并销毁落后设备设施装置，防止落后产能的异地转移，对未按要求与时限淘能的企业，要依据相关法律、法规责令停产或予以关闭。各淘能企业做为淘能计划实施主体，要严格按照与所在县政府签订的《淘汰落后产能目标责任书》，制定本企业的淘能工作方案，要认真做好本企业职工的思想工作，严禁借淘能损害职工利益，要妥善安置好职工，做好淘汰设备的拆除和废毁处理，严禁淘汰的落后产能死灰复燃。

（二）强化协调配合。州发展改革、经信、人力资源社会保障、国土资源、环保、安监、工商、质监、国税、地税等部门要各司其职、密切配合，共同推进全州淘汰落后产能工作。州经信委要充分发挥牵头单位的职能作用，加强协调沟通，深入企业一线，与企业经营团队一道共商淘汰落后和过剩产能的工作难点，帮助企业解决淘能工作中存在的困难和问题，共谋企业淘能转产与职工安置的出路。

（三）细化工作方案。各县要根据国家产业政策和本工作方案，结合本县节能减排和产业发展年度目标，科学制定2014年淘汰落后和过剩产能工作方案，将淘能任务分解落实到有关部门、企业。各相关单位要及时研究解决淘汰落后和过剩产能工作过程中出现的新情况、新问题，将淘汰落后和过剩产能与实施产业发展规划、企业转产升级、职工安置、再就业培训和促进社会稳定等结合起来，确保各项措施落实到位。

（四）做好职工安置工作。各有关部门要在淘能工作中妥善处理淘能与职工再就业的关系，认真落实和完善企业职工安置政策，依照有关劳动保护的法律、法规与政策妥善安置职工，做好职工社会保险关系转移与接续工作，避免因淘能引发大规模职工集中失业，防止群体性事件发生，确保淘能工作顺利进行和社会和谐稳定。

（五）加强检查督促。各县、州直有关部门要严格按照淘汰落后和过剩产能的目标任务和时间要求，督促企业按时、按要求完成淘汰落后和过剩产能任务，确保淘能工作可核、可查。州人民政府已将淘汰落后和过剩产能工作纳入了2014年度全州政府系统目标考核体系，将适时派出督导组对有淘能任务的县和纳入今年淘能计划企业的淘能任务完成情况进行专项考核督查。州经信委、州环保局等职能部门要强化检查督促；州工业节能监察中心要对州内高载能企业单位产品能耗限额和主要用能设备运行情况进行检查。州政府将对不按规定时限与要求淘汰的企业与落后生产线、设备，依法责令关停；对未按要求与时限完成淘能任务的县进行通报批评，限期整改；对瞒报、谎报淘能进展情况或整改不力、不到位，造成不良影响的县，要依法依纪对有关责任人实行问责。

（六）做好后续安置和舆论引导。各县、州直有关部门要认真指导关停企业深入细致地做好企业转产、职工安置、债务处置等工作，积极争取国家和省的淘能专项资金，帮助企业建设淘能转产项目，尽快形成新的生产能力，实现职工再就业。要大力宣传淘汰落后和过剩产能的重要性，及时总结淘能工作的经验与教训，加强经验交流与推广，加大淘能政策和职工安置政策的宣传力度，及时化解各种社会矛盾，为淘汰落后和过剩产能工作营造良好的社会舆论氛围，确保今年淘汰落后和过剩产能任务的全面完成。
