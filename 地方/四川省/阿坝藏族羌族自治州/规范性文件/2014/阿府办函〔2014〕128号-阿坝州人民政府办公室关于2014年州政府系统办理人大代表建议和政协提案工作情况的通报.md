# 阿坝州人民政府办公室关于2014年州政府系统办理人大代表建议和政协提案工作情况的通报

阿坝州人民政府办公室

关于2014年州政府系统办理人大代表建议和

政协提案工作情况的通报

阿府办函〔2014〕128号

各县人民政府，州政府各部门：

今年，各县和州政府有关部门深入贯彻《阿坝州人民政府关于印发<阿坝州人民政府办理人大代表建议和政协提案办法（修订）>的通知》（阿府发〔2013〕5号）和《阿坝州人民政府办公室关于进一步加强人大代表建议和政协提案办理工作的通知》（阿府办发〔2014〕3号），按照“分级负责、依法办理、注重实效”的原则，在坚持政府统筹办理机制、逐级审核机制的基础上，进一步强化了州政府分管副州长领衔办理、对口副秘书长协助办理的工作机制，完善了对办理过程的全程监管、公开公示和动态答复，圆满完成了本年度的办理任务。现将相关情况通报如下。

经过努力，在法定时限内完成了3件省建议提案、174件州建议提案和26件政协委员建议的办理工作，做到了件件落实、事事回复，较好地完成了办理工作。其中：所提问题已经解决或基本解决的共81件，占建议提案总数的45.8%；所提问题正在解决或需列入规划逐步解决的有63件，占建议提案总数的35.6%；所提问题受客观条件限制或其他原因需以后解决，已向人大代表、政协委员作出解释说明的有33件，占建议提案总数的18.6%。从办理情况反馈意见看，州人大代表、州政协委员对办理工作总体满意，满意和基本满意率达100%。

为进一步推动和促进建议提案办理工作，根据《阿坝州人民政府办公室关于进一步加强人大代表建议和政协提案办理工作的通知》（阿府办发〔2013〕11号），结合2014年度目标绩效管理考评工作，州政府办公室会同州人大常委会人事代表工委、州政协提案委对各县人民政府、州政府各部门2014年建议、提案办理工作进行了评估考核。其中：州公安局、州发展改革委、州人力资源社会保障局、州财政局综合考核得分超过90分，考核等次为优秀，予以通报表扬。

2014年度建议提案办理工作总体情况较好，但仍有个别承办单位不同程度地存在一些问题和不足，主要表现在:一是对办理工作不重视，敷衍塞责、推诿扯皮、久拖不办；二是单位内部分工不明确，办理任务分解不科学；三是答复代拟稿政策把关不严、内容不全、文字质量不高、针对性不强；四是动态答复不主动、不及时，不催不办；五是工作落实不够、办理推动不力等。在今后的工作中，请各县人民政府、州政府各部门认真总结经验，进一步提升办理工作的制度化、规范化、科学化水平，推动政府系统建议、提案办理工作迈上新台阶。

附件：2014年人大代表建议、政协提案办理工作评估考核情况统计表

阿坝州人民政府办公室
