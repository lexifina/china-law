# 阿坝州人民政府办公室关于成立《阿坝藏族羌族自治州实施的变通规定》立法工作领导小组的通知

阿坝州人民政府办公室

关于成立《阿坝藏族羌族自治州实施<四川省城乡规划条例>

的变通规定》立法工作领导小组的通知

阿府办函〔2014〕133号

各县人民政府，州直有关部门：
