# 阿坝州人民政府办公室关于印发2014年全州政府系统网站绩效评估指标体系的通知

阿坝州人民政府办公室

关于印发2014年全州政府系统网站绩效评估指标体系的通知

阿府办函〔2014〕41号

各县人民政府，州政府各部门，卧龙管理局：

现将2014年全州政府网站绩效评估指标体系印发你们，请认真组织学习，围绕政府网站“信息公开、办事服务、公众参与”三大核心功能，结合实际抓好贯彻落实，确保圆满完成目标任务。

附件：1.2014年各县政府门户网站绩效评估指标体系

2.2014年州政府部门网站绩效评估指标体系

3.“中国阿坝州”网站信息保障季度目标分解表

阿坝州人民政府办公室

2014年4月24日

全州政府系统网站绩效评估指标体系
