# 阿坝州人民政府办公室关于下达2014年度工业节能目标的通知

阿坝州人民政府办公室

关于下达2014年度工业节能目标的通知

阿府办函〔2014〕58号

各县人民政府，州直有关部门：

为顺利完成我州“十二五”节能降耗目标任务，在充分考虑各县经济发展状况和工业结构特点的基础上，现将2014年度工业节能目标下达你们。请各县、州直有关部门认真对照目标任务，落实工作责任，强化工作措施，确保年度目标任务圆满完成。

阿坝州人民政府办公室

2014年6月4日
