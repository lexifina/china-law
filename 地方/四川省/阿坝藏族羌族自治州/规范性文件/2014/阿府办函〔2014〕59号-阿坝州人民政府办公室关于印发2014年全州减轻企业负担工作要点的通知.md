# 阿坝州人民政府办公室关于印发2014年全州减轻企业负担工作要点的通知

阿坝州人民政府办公室

关于印发2014年全州减轻企业负担工作要点的通知

阿府办函〔2014〕59号

各县人民政府，州直有关部门：

《2014年全州减轻企业负担工作要点》已经州政府领导同意，现印发你们，请结合实际，认真贯彻落实。

阿坝州人民政府办公室

2014年6月5日

2014年全州减轻企业负担工作要点

为贯彻落实党的十八届三中全会、省委十届四次全会和州委十届五次全会精神，按照《四川省人民政府办公厅关于转发省减负办2014年全省减轻企业负担工作要点的通知》（川办函〔2014〕62号）要求，结合我州减轻企业负担工作实际，制定此工作要点。

一、工作思路

以扶助小微企业为重点，以落实惠企政策为抓手，以规范涉企收费、检查行为等为核心，创新工作方法，完善工作机制，着力解决企业特别是小微企业反映强烈的涉企负担问题，进一步减轻企业负担、激发市场活力、营造良好环境。

二、工作重点

（一）不折不扣落实惠企政策，全力扶助小微企业发展

一是深入贯彻落实国家、省、州出台的一系列关于扶持小微企业发展的政策措施，用足、用活、用好惠企政策，全面激发企业作为市场主体的活力。二是针对企业特别是小微企业反映突出的问题，强化企业服务平台建设和指导服务，积极研究出台符合本县、本部门实际的政策措施，帮助企业解决创业难、转型难、融资难等实际问题。三是加强督导检查，及时发现和纠正惠企政策措施落实不及时、不到位、打折扣等问题。

（二）规范清理涉企收费行为，切实减轻小微企业负担

一是深入开展涉企行政事业性收费项目和行政审批前置经营服务性收费项目专项清理，及时按要求取消、停收、减免相关涉企行政事业性收费项目，对确需政府定价、政府指导价的经营服务性收费项目，严格实行政府定价目录管理。二是开展涉企政府性基金项目专项清理，对企业反映突出的政府性基金项目，按行业和部门权属，积极向上争取政策调整。三是结合行政权力公开透明运行平台建设，建立健全涉企收费目录清单管理制度，完善涉企收费公示和收费明白卡制度，对行政事业性收费项目和政府定价或实行指导价的涉企服务性价格，一律实行目录清单管理，未列入清单的涉企收费项目一律不得收取。四是开展重点领域收费专项治理，积极向上争取并及时降低金融、质检等收费标准，认真清理规范中介服务机构收费行为。

（三）扎实开展涉企负担调研，准确把握企业负担问题

一是围绕企业反映强烈的税负重和流通环节、银行金融业、检验检测、培训服务等收费问题，督促各县、州直有关部门有针对性的开展调研，及时提出对策措施和建议。二是充分发挥州、县减负办的牵头协调作用，适时组织领导小组成员单位开展督促检查，及时发现并协调解决涉企负担中出现的新情况、新问题。三是指导相关企业配合做好企业负担情况网上调查和评价工作，进一步摸清涉企负担情况。

（四）不断探索完善工作机制，确保减负工作长效运转

一是积极探索减轻企业负担工作新思路、新方法，建立减轻企业负担工作交流制度和企业负担问题处理反馈制度。二是进一步完善并实施涉企收费公示、收费明白卡、涉企检查备案公示等减轻企业负担工作制度。三是进一步强化企业负担监测联系点建设，加强企业负担监督员业务培训，进一步发挥企业负担监督员作用。

（五）严肃查处涉企不法行为，有效维护企业合法权益

一是严格执纪执法，坚决纠正个别部门（单位）、中介机构和垄断行业乱收费、乱罚款、乱摊派、乱拉赞助等问题。严肃查处增加企业不合理负担、侵害企业合法权益等违法违规行为。二是构建更加便捷的投诉平台，畅通企业诉求渠道，妥善处理企业反映的问题。三是充分发挥媒体的监督作用，适时曝光典型案例，搞好警示教育。

三、工作要求

（一）加强组织领导，形成工作合力

各县、州直有关部门要高度重视减轻企业负担工作，切实加强组织领导。各有关部门要密切配合，主动作为，形成部门协调、齐抓共管的工作格局。州、县减负办要发挥好牵头协调作用，创新工作方式方法，不断开创减轻企业负担工作新局面。

（二）强化督促检查，确保工作落实

年底，州政府将对各县、州直有关部门减轻企业负担工作任务完成情况进行检查。州减负办要适时对各县、州直有关部门工作落实情况进行督导和考评。

（三）深入宣传教育，营造良好氛围

全面梳理国家、省、州扶持实体经济发展的各项政策措施并汇编成册，通过网站宣传、印送资料、现场咨询等形式，广泛深入宣传，提高企业知晓率。积极宣传各县、州直有关部门开展减轻企业负担工作的新举措、新成效，不断扩大减轻企业负担工作的影响力，努力营造全社会共同关心企业发展的良好氛围。

（四）做好工作总结，全力完成目标

各县、州直有关部门要及时将工作中的好经验好做法、发现的问题和工作建议等报州减负办，并于2014年11月15日前将年度工作任务完成情况报州减负办。
