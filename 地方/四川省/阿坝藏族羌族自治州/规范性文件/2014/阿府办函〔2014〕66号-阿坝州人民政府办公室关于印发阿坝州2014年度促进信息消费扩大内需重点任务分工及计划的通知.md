# 阿坝州人民政府办公室关于印发阿坝州2014年度促进信息消费扩大内需重点任务分工及计划的通知

阿坝州人民政府办公室

关于印发阿坝州2014年度促进信息消费扩大内需

重点任务分工及计划的通知

阿府办函〔2014〕66号

各县人民政府，州直各部门，卧龙管理局：

《阿坝州2014年度促进信息消费扩大内需重点任务分工及计划》已经州政府领导同意，现印发你们，请认真贯彻执行。

阿坝州人民政府办公室

2014年6月16日

阿坝州2014年度促进信息消费扩大内需重点任务分工及计划

按照省政府《关于印发四川省2014年度促进信息消费扩大内需重点任务分工及计划的通知》（川办函〔2014〕65号）精神，为促进我州信息消费全面快速增长，立足实际，制定此分工及年度计划。

一、加快信息基础设施演进升级

（一）制定实施我州“宽带中国”战略实施方案；申报创建“宽带中国”示范城市（城市群）；组织实施2014年阿坝州农村通信建设项目，完成年度目标任务。光纤到户覆盖家庭达到9.92万户，城市宽带接入能力达到30Mbps以上；3G/LTE基站达到1406个，3G/LTE用户普及率达到50%。（责任单位：州经信委、州发展改革委、州财政局、州文广新局、电信阿坝分公司、移动阿坝分公司、联通阿坝分公司、四川广电阿坝分公司。排名第一的为牵头单位，下同）

（二）加快部署下一代互联网。推动政府、学校、企事业等单位网站系统下一代互联网（IPv6）升级改造。启动实施马尔康州级互联网骨干直联点建设。加快推进通信重点项目建设，提升州际通信能力，互联网州际出口带宽达到100Gbps。（州经信委、州发展改革委、州财政局、州文广新局、电信阿坝分公司、移动阿坝分公司、联通阿坝分公司、四川广电阿坝分公司）

（三）在现有城市总体规划的公用设施规划专章中深化完善信息基础设施规划内容；将信息基础设施纳入土地利用总规、交通建设规划、产业园区建设规划，在规划中设立信息基础设施建设专章，纳入研究范围，并予以必要的政策资金支持。（州城乡建设住房局、州发展改革委、州财政局、州环保局、州交通运输局、州国土资源局、州文广新局、州工业园区管委会、成阿工业园区管委会，各县政府）

（四）统筹第三代移动通信（3G）、无线局域网（WLAN）、长期演进技术（LTE）等无线移动宽带网络协调发展，积极推进4G网络建设。进一步优化网络结构，提升网络质量。（州经信委、州发展改革委、电信阿坝分公司、移动阿坝分公司、联通阿坝分公司）

（五）加快通信和广电业务双向进入，在全州推广“三网融合”；推动地面数字电视覆盖网和高清交互式电视网络基础设施建设，加快广播电视模数转换进程，加快建设下一代广播电视网（NGB）。全州数字电视用户数达到10.4万户，NGB覆盖家庭达到0.3万户。（州文广新局、州发展改革委、州经信委、州财政局、电信阿坝分公司、移动阿坝分公司、联通阿坝分公司、四川广电阿坝分公司）

二、增强信息产品供给能力

（一）实施智能终端产业化工程，支持终端与服务一体化发展；支持数字家庭智能终端产业化，推进数字家庭示范应用；加强智能终端、智能语音、信息安全、工业控制系统等关键软件的应用。（州经信委、州发展改革委、州科技局、州财政局、州文广新局、电信阿坝分公司、移动阿坝分公司、联通阿坝分公司）

（二）充分发挥通信与广电运营商集中采购作用，贯彻落实增值税抵扣政策，促进智能终端信息产品结构调整。（州国税局、州地税局、州财政局、州经信委、州文广新局）

（三）依托国家、省新兴产业发展规划和专项资金，大力支持新材料、新能源发展，加快技术突破，推动产业创新发展。（州经信委、州财政局，各县政府）

（四）支持各县探索发展电子信息产业的融资改革模式，利用现有财政资金渠道，鼓励有条件的县政府设立电子信息产业投资基金，引导社会资金投资电子信息产业。（州发展改革委、州经信委、州财政局）

（五）推进阿坝州全媒体信息内容集成播控平台及信息内容服务平台建设。启动通过网络获取视频的互联网电视（OTT）、手机播控平台。（州文广新局、州经信委、州互联网信息办公室、阿坝日报社、电信阿坝分公司、移动阿坝分公司、联通阿坝分公司、四川广电阿坝分公司）

三、培育信息消费需求

（一）支持移动互联网核心技术产业化，吸引中小移动应用开发者，丰富移动应用开发内容。（州商务局、州发展改革委、州经信委、州科技局）

（二）统筹云计算基础设施布局，积极推动云计算服务商业化运营，支持云计算服务创新和商业模式创新。（州经信委、州发展改革委、州财政局、电信阿坝分公司、移动阿坝分公司、联通阿坝分公司）

（三）积极参与“四川省北斗卫星导航综合应用示范工程项目”建设。2014年重点在自然灾害预警与救助、公共安全综合应用、城乡建设、智慧景区管理、林火预警应急与野生动物监护等领域开展应用。（州经信委、州发展改革委、州财政局、州公安局、州城乡住房建设局、州国土资源局、州林业局、州旅游局）

（四）积极支持文化产业发展。引导文化产业示范基地充分发挥示范作用，壮大实力，提升品牌，实现规模化、集约化发展。重点推进藏羌彝文化产业走廊项目建设，促进项目优化整合，形成以点连线、以线带面的藏羌彝文化产业走廊格局。（州文广新局、州发展改革委、州经信委、州互联网信息办公室）

（五）加快快递物流体系建设。将快递园区纳入川西北物流园区整合规划建设，建立大型仓储中心和快件分拨中心。允许快递企业采用小型厢式货车开展快递收投业务，实行快递车辆通行证管理制度。支持建设农村、社区、学校、机关的物流快递配送点。（州商务局、州发展改革委、州经信委、州交通运输局、州邮政局）

（六）夯实电子商务发展基础。以金融集成电路（IC）卡为依托，推动网上支付、移动支付广泛应用。加快电子商务领域标准化建设，加强行业组织建设，发挥其在行业管理、服务、自律中的作用。引进第三方信用认证专业机构，加强网络交易监管，建立网络经营主体数据库，推动数字证书、电子签名、电子发票和电子印章应用。深入推进电子商务可信交易环境建设工作，提升信用水平，保护网络消费者、经营者合法权益。（州商务局、州发展改革委、州经信委、州财政局、人行阿坝州中心支行、州工商局、州质监局）

（七）实施电子商务示范建设。重点培育和打造1－3户省级电子商务示范企业，鼓励电子商务示范企业积极争创国家和省级品牌。深入实施“电子商务拓展市场工程”、“全企入网工程”、“电子商务进万村工程”，在城郊和主要行政村建设电子商务便民服务点，推进城乡协调发展。（州商务局、州经信委、州科技局、州农业局、州财政局）

（八）着力推动农村公共服务体系建设，建设农业农村信息基础设施，加快建设农业生产经营信息化示范基地；推动农产品电子商务快速发展。（州经信委、州科技局、州农业局、州商务局、州文广新局、州气象局、电信阿坝分公司、移动阿坝分公司、联通阿坝分公司）

四、提升公共服务信息化水平

（一）积极申报信息惠民国家示范城市，因地制宜，推动基本公共服务向基层延伸，缩小城乡、区域和不同群体之间的数字鸿沟，加快促进基本公共服务均等化。支持企业参与政府公共服务云平台建设和运营服务；加快推进政务信息化工程建设，建立完善基础信息资源和政务信息资源，推动社会化开放利用。（州发展改革委、州经信委、州文广新局）

（二）全面推进教育信息化“三通二平台”建设，强化教师信息化技能培训和一批试点示范学校建设，逐步推进教育资源公共服务平台和公共管理平台建设，以教育信息化推动教育均衡发展。（州教育局、州发展改革委、州经信委、州财政局）

（三）推进远程医疗和居民健康卡建设。建立完善全州远程医疗会诊信息系统，整合远程医疗资源，促进优质医疗资源共享和卫生服务普惠。建立完善电子病历、电子健康档案，加快推进居民健康卡建设和运用，逐步实现跨机构、跨区域、跨卫生业务的健康信息、就诊信息共享和就医一卡通。全州50%的县级医院建立远程会诊信息系统，开展远程会诊占院外会诊比例达到15%，远程医疗服务量增加15%。100%的三级医院、30%的二级医院建立以电子病历为核心的医院信息系统系统（HIS）并组织开展数字化医院建设评审。全州电子健康档案建档率达到88%。（州卫生局、州发展改革委、州经信委、州财政局、州科技局、州人力资源社会保障局、州人口计生委）

（四）推进金融集成电路卡（IC 卡）应用。进一步扩大金融IC卡应用范围，探索推动金融IC卡在全州公共交通、卫生、旅游行业的应用。进一步完善金融IC卡受理环境，加大金融IC卡发行力度。2014年，推动我州全国性商业银行分支机构金融IC卡发行达到新增银行卡90%以上，股份制商业银行分支机构及邮储银行阿坝分行达到60%以上，金融IC卡多应用城市（马尔康、茂县、汶川、九寨沟）达到30%以上。（人行阿坝州中心支行、州发展改革委、州经信委、州交通运输局、州商务局、州卫生局、州旅游局、州人口计生委）

（五）推进社会保障卡“一卡通”工程，建设人力资源社会保障公共服务系统，参与建设跨地区医疗保险费用省级结算平台，年内实现医疗保险省内异地即时结算。全面开通医疗和社保服务专网，13个县和重点乡镇覆盖新农合专网，实现乡镇新农合报销网络化和医疗卫生健康档案云端化管理。（州人力资源社会保障局、州发展改革委、州经信委、州财政局、州科技局、州卫生局、人行阿坝州中心支行）

（六）建立公共就业信息服务平台，推动就业信息联网。对阿坝公共招聘网进行GIS地图、短信平台、手机客户端等拓展应用，2014年12月正式运行。（州人力资源社会保障局、州发展改革委、州经信委、州财政局、州科技局）

（七）规范互联网食品药品交易行为，推进食品药品网上阳光直购，推行网上交易的在线监测及信用信息记录。（州食品药品监管局、州发展改革委、州经信委、州财政局、州人力资源社会保障局、州商务局、州卫生局、州工商局）

（八）配合开展智慧城市国家级试点示范建设，开展升级试点示范建设，启动实施智能电网、智能交通等工程；支持各县出台鼓励市场化投融资、信息系统服务外包、信息资源社会化开发利用等吸引各类市场主体共同参与智慧城市建设的相关政策。（州发展改革委、州经信委、州科技局、州公安局、州财政局、州国土资源局、州城乡建设住房局、州交通运输局、州文广新局、电信阿坝分公司、移动阿坝分公司、联通阿坝分公司，各县政府）

（九）继续大力推进广播电视村村通、广播“村村响”、“农村公益电影放映”、“农村电影院线建设”工程，统筹有线、无线、卫星等多种覆盖手段，在“村村通”基础上大力推进户户通。合理确定广播电视基本公共服务的节目范围和标准，建立政府主导、社会化发展的农村广播电视公共服务长效机制。参与推进“视听乡村”试点、应急广播村村响国家试点工作，加快全州应急广播系统建设。（州文广新局、州委农工委、州发展改革委、州经信委、州财政局）

五、加强信息消费环境建设

（一）推进身份认证、网站认证和电子签名与支付等网络信任服务，建设电子认证基础设施，推进电子认证体系建设；推进移动金融安全可信公共服务平台应用。（州经信委、州发展改革委、州公安局、人行阿坝州中心支行、阿坝银监分局、州密码管理局、州应急保障中心）

（二）依法加强信息产品和服务的检测、认证，加强应用商店监管，支持建立第三方安全评估与监测机制。（州经信委、州发展改革委、州公安局、州国安局、州质监局、州密码管理局、州应急保障中心）

（三）落实信息安全等级保护制度，加强网络与信息安全监管，推进信息安全动态监测平台、州级政府部门灾备中心建设。（州公安局、州发展改革委、州经信委、州国安局、州保密局、州密码管理局、州应急保障中心、州互联网信息办公室）

（四）加快网络信息安全、个人信息保护等方面的法律制度建设，建立个人信息保护标准规范，加强信息安全检查工作。（州经信委、州公安局、州国安局、州质监局、州政府法制办、州应急保障中心、州互联网信息办公室）

（五）强化行业自律机制，完善企业争议调解机制，健全消费维权渠道。（州经信委、州工商局）

（六）加强互联网基础管理，健全IP地址、域名、网站信息等互联网基础资源库，积极稳妥推进网络真实身份信息注册工作。深入开展互联网专项整治活动，进一步净化网络文化环境。（州应急保障中心、州经信委、州公安局、州互联网信息办公室）

六、完善支持政策

（一）实行公司注册资本认缴制，推进“先照后证”登记制度改革工作试点，放宽互联网企业住所登记条件。（州工商局、州经信委）

（二）大力培育和支持互联网企业通过高新技术企业认定，依法享受高新技术企业所得税优惠税率。（州科技局、州财政局、州国税局、州地税局）

（三）落实研发费用税前加计扣除政策。（州财政局、州科技局、州国税局、州地税局）

（四）按部署积极推进邮电通信业营业税改征增值税改革试点。（州财政局、州经信委、州国税局、州地税局）

（五）落实鼓励软件产业和集成电路产业发展的若干政策。（州经信委、州发展改革委、州财政局、州科技局、州商务局、州国税局、州地税局）

（六）完善信息服务业创业投资扶持政策。（州发展改革委、州财政局）
