# 阿坝州人民政府办公室关于成立阿坝州“十三五”电网规划领导小组的通知

阿坝州人民政府办公室

关于成立阿坝州“十三五”电网规划领导小组的通知

阿府办函〔2014〕85号

各县人民政府，州直有关部门：
