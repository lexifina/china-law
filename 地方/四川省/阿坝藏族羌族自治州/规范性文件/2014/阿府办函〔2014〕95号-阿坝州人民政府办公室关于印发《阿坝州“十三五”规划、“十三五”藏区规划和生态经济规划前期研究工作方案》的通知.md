# 阿坝州人民政府办公室关于印发《阿坝州“十三五”规划、“十三五”藏区规划和生态经济规划前期研究工作方案》的通知

阿坝州人民政府办公室

关于印发《阿坝州“十三五”规划、“十三五”

藏区规划和生态经济规划前期研究

工作方案》的通知

阿府办函〔2014〕95号

各县人民政府，州直各部门：

为统筹做好“十三五”规划、“十三五”藏区专项规划和生态经济规划等中长期规划编制工作，经州人民政府第33次常务会审议通过，现将《阿坝州“十三五”规划、“十三五”藏区规划和生态经济规划前期研究工作方案》印发你们，请遵照执行。

阿坝州人民政府办公室

2014年9月24日

阿坝州“十三五”规划、“十三五”藏区规划

和生态经济规划前期研究工作方案

为科学开展“十三五”规划、“十三五”藏区专项规划和生态经济规划等中长期规划前期研究，及早谋划规划思路，制定本工作方案。

一、总体要求

即将到来的“十三五”时期，是我州与全国全省同步全面建成小康社会的决胜期，是发展生态经济、建设川西北生态经济示范区的关键期，是深化重要领域和关键环节改革的攻坚期。做好“十三五”规划和“十三五”藏区专项规划编制工作，要深入贯彻落实州委十届五次全会精神，切实转变经济发展方式，大力推动生态文明建设和经济社会建设并重的科学发展、幸福美丽目标与富民强州愿景并行的互惠发展，加快建设川西北生态经济示范区，努力把阿坝州打造成四川生态经济增长极，为与全国全省同步全面建成小康社会奠定坚实基础。

在当前内外发展环境复杂、有利条件和不利因素并存的形势下，尤其是在结构调整阵痛期、增长速度换挡期、前期刺激政策消化期的叠加阶段，开展“十三五”规划、“十三五”藏区规划和生态经济规划前期研究工作，要切实把握好当前与长远的关系，正确处理速度、质量和效益三者关系，立足当前我州所处发展阶段，深入思考各地、各领域在全州建设川西北生态经济示范区进程中的目标定位和发展重点，客观分析各县的比较优势和绝对优势，结合形势变化把握好“破”与“立”的关系，组织动员各方力量，加强对结构调整、生态保护与建设、产业发展、基础设施建设、改善民生、招商引资项目落地、金融服务地方经济、公共服务均等化等相关领域重大问题开展研究，提出解决问题的方向和途径，丰富完善发展思路。

二、主要方式

全州“十三五”规划、“十三五”藏区规划和生态经济规划前期研究工作，主要通过聘请专家团队开展县域经济和生态经济研究与州直部门开展行业前期研究相结合的方式开展。

（一）聘请专家团队开展县域经济研究

以政府采购方式聘请由相关专家学者组建的专家团队，开展“‘十三五’促进生态经济视角下县域经济协调发展研究”，并深入各县开展为期40天左右的实地调查研究工作（每个县按3-4天安排，做到全覆盖）。在切实摸清家底、搞好需求分析的基础上，为各地提供咨询决策服务，在经历发展思路由县到片区的整合、片区思路向片区共识的达成，发展思路由片区到州的整合、全州思路向全州共识的达成等环节后，最终由专家团队形成“1 4”（全州“十三五”规划纲要提纲和四大片区区域发展战略思路）研究报告。

（二）聘请机构开展生态经济规划前期研究

以政府采购方式聘请长期专注生态经济领域研究的专业机构，开展生态经济建设相关基础调查、探索路径设计与制度安排等前期研究，为生态经济规划编制提供思路导向。

（三）州直部门开展行业前期课题研究

州直部门围绕产业发展、基础设施、社会民生、生态保护与建设、要素保障等领域开展33个专项课题的前期研究工作（详见附件）。州“十三五”规划领导小组与各相关成员单位签订目标责任书，确保责任落实到位。

（四）各县人民政府承担各专项课题的基础保障工作

根据工作进度，各县人民政府适时、适地与专家团队和州直部门召开各层面、各行业的座谈会和咨询论证会，以加强课题成果与各县县情的深度融合，在“条块”结合的基础上，拟订“十三五”规划纲要提纲、“十三五”藏区规划以及生态经济规划思路。

（五）引进第三方机构对研究成果进行评估论证

聘请第三方研究机构，对县域经济研究成果，“十三五”规划、“十三五”藏区规划和生态经济规划思路进行咨询论证，并根据咨询论证意见作进一步修改完善。

三、时间进度

（一）前期研究启动阶段

2014年8月上旬开始，组织专家团队赴全州开展调研工作，州直部门同步开展行业前期课题研究工作。

（二）思路沟通碰撞阶段

2014年8月上旬至9月20日，全州分四大片区逐一形成区域发展思路，逐一开展各层级的对接研讨，形成共识。

（三）课题成果形成阶段

在相关前期研究成果基础上，2014年12月底前形成四大片区区域发展战略思路、“十三五”藏区规划及生态经济规划思路和全州“十三五”规划纲要提纲，并引进第三方机构对前期研究成果进行评估论证，修改完善后提交州委、州政府审定。

四、加强组织领导

成立以州委常委、州政府常务副州长赵平同志为组长，州政府各位副州长为副组长，州直相关部门主要负责同志为成员的州“十三五”规划领导小组（详见附件），负责领导和组织推进“十三”五规划编制前期研究工作。各县、州直相关部门也要成立相应的机构，切实加强对该项工作的组织领导。
