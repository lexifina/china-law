# 阿坝州人民政府关于废止《阿坝州人民政府关于大力加强旅游市场环境建设与治理工作的意见》和《阿坝州人民政府关于游人服务中心规划布点和建设管理的意见》的通知

阿坝州人民政府

关于废止《阿坝州人民政府关于大力加强旅游

市场环境建设与治理工作的意见》和《阿坝州

人民政府关于游人服务中心规划布点和建设

管理的意见》的通知

阿府函〔2017〕152号

各县（市）人民政府，州政府各部门、各直属机构，卧龙特别行政区，有关单位：

《阿坝州旅游市场综合监管实施意见》（阿府发〔2017〕5号）于2017年5月6日印发执行。经州政府研究，决定废止《阿坝州人民政府关于大力加强旅游市场环境建设与治理工作的意见》（阿府函〔2005〕157号）和《阿坝州人民政府关于游人服务中心规划布点和建设管理的意见》（阿府函〔2008〕23号），自即日起停止执行。

阿坝州人民政府

2017年10月20日
