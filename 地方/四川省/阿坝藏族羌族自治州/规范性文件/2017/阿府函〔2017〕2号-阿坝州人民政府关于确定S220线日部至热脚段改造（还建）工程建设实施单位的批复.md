# 阿坝州人民政府关于确定S220线日部至热脚段改造（还建）工程建设实施单位的批复

阿坝州人民政府

关于确定S220线日部至热脚段改造（还建）工程建设实施单位的批复

阿府函〔2017〕2号

马尔康市人民政府：

你市《关于确定S220线日部至热脚段改造（还建）工程建设实施单位的请示》（马尔府〔2016〕145号）收悉，经研究，现批复如下：

一、同意由马尔康市人民政府作为该项目实施单位组建项目管理法人，负责S220线日部至热脚段改造（还建）工程项目建设管理有关工作。

二、请你市加强同双江口公司的对接协调，加快推进项目前期，确保该项目于今年开工建设。

此复。

阿坝州人民政府

2017年1月12日
