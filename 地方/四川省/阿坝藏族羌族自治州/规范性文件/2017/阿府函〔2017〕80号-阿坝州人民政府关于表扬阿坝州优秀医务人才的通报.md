# 阿坝州人民政府关于表扬阿坝州优秀医务人才的通报

阿坝州人民政府

关于表扬阿坝州优秀医务人才的通报

阿府函〔2017〕80号

各县（市）人民政府，州政府各部门、各直属机构，卧龙特别行政区，有关单位：

近年来，全州卫生计生系统广大干部职工紧紧围绕新时期党和国家的卫生与健康工作方针，按照州委、州政府决策部署，认真履职尽责、不断开拓创新，在精准扶贫、深化医改、服务基层、扎实稳妥实施计划生育政策调整等方面取得明显成效，有力推动了阿坝医疗卫生事业发展。为鼓励先进、树立典型，进一步促进全州卫生计生工作创新发展，经州政府研究，决定对唐远勤等47名同志予以通报表扬。

希望受表扬的同志珍惜荣誉、再接再厉、再创佳绩。全州各县（市）、各部门广大干部职工要以受表扬的同志为榜样，进一步发扬爱岗敬业，团结协作，锐意进取，拼搏实干的精神，全力实施“健康阿坝”建设，为建成“三区一中心”、决胜全面小康社会作出新的更大贡献。
