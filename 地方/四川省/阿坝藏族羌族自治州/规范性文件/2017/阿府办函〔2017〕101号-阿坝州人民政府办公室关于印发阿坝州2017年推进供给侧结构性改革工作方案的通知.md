# 阿坝州人民政府办公室关于印发阿坝州2017年推进供给侧结构性改革工作方案的通知

阿坝州人民政府办公室

关于印发阿坝州2017年推进供给侧结构性改革工作方案的通知

阿府办函〔2017〕101号

各县（市）人民政府，州政府有关部门、有关直属机构，有关单位：

《阿坝州2017年推进供给侧结构性改革工作方案》已经州政府同意，现印发你们，请结合实际抓好贯彻落实。

阿坝州人民政府办公室

2017年12月11日

阿坝州2017年推进供给侧结构性改革工作方案

2017年，是推进供给侧结构性改革的深化之年。按照中央和省委、省政府关于推进供给侧结构性改革的决策部署，根据《四川省人民政府办公厅关于印发四川省2017年推进供给侧结构性改革工作方案的通知》（川办发〔2017〕29号）以及《阿坝州推进供给侧结构性改革总体方案》，制定本方案。

一、年度目标

（一）去产能方面。坚决关停淘汰落后产能，严厉打击“地条钢”，彻底关停全州4户“地条钢”企业。严格控制新上煤炭项目供地批矿。

（二）去库存方面。全州商品住房库存消化周期控制在合理范围内，住房公积金贷款做到应贷尽贷。根据住房建设规划及年度实施计划，结合商品住房可售周期、未开工住宅用地总量等指标，合理确定商品住房用地年度供应规模，缓解房地产库存压力。商业用房和住宅库存压力较大的县（市）消化周期明显缩短。

（三）去杠杆方面。积极引导符合条件的企业通过境内主板、中小板、创业板和新三板、天府（四川）股交中心进行股权融资。支持符合条件企业申报纳入省级上市、挂牌企业后备资源库，为企业股权托管、质押登记和企业股权变更提供服务。支持符合条件企业通过债转股实施资产重组。督促引导银行业金融机构加大对中小微企业的有效信贷投放。

（四）降成本方面。全州实体经济企业成本进一步降低，企业综合经营成本与全省平均水平持平，管理和技术水平进一步提高，企业活力进一步激发，经济质量显著提升。

（五）补短板方面。实现全州5个县（市），239个贫困村，30811名贫困人口实现脱贫的目标。2017年成兰铁路（阿坝段）计划完成投资16亿元，成西铁路争取开工建设。汶马高速计划完成投资60亿元。开工建设九绵高速，加快推进马久高速、汶川-川主寺高速项目前期工作。基本公共服务差距逐步缩小，基本公共服务均等化水平进一步提高。生态环境质量持续改善，严格控制污染物排放总量，全面完成省下达节能减排和环保目标任务。

（六）农业供给侧结构性改革方面。以放活土地经营权为重点，创新农业经营体系，发展适度规模经营，努力提高农业劳动生产率和农业现代化水平。加快推进农村集体产权“多权同确”。支持农村集体经济组织，合理确定发展路径、经营方式，扶持发展壮大农村集体经济。深入开展农民住房财产权抵押贷款试点，盘活农村存量资产，提高农村土地资源使用效率。

（七）培育新动能方面。全面推进创新改革试验，认真落实省下达“9张清单”，稳步积累并逐步提炼一批经验成果。2017年实现战略性新兴产业产值20亿元以上、同比增长15%，技术创新投资4000万元、同比增长20%，全年完成技术改造投资10亿元。全年力争到位国内州外资金78亿元，新引进10亿元以上重大产业项目2个以上，5-10亿元产业项目4个以上。

（八）提升质量效益方面。投入州本级科技项目资金1350万元，争取国家、省科技项目经费2000万元以上，研究与试验发展经费投入强度达到0.18%。单位地区生产总值能耗完成省下达目标任务。城乡居民收入增长、地方一般公共预算收入增长与经济增长基本同步。质量管理体制机制进一步完善。

二、重点任务

（一）扎实有效去产能。

1.部署2017年钢铁去产能工作。依法依规退出不符合国家安全、环保、能耗、质量、国土等法律法规和产业政策的产能，严厉查处生产“地条钢”的企业和超生产经营许可生产的企业，按照“五个彻底”要求，关停并拆除生产“地条钢”相关设备。

责任单位：州经济和信息化委，州安全监管局、州工商局、州质监局、州发展改革委、州公安局、州环境保护局。

2.做好化解过剩产能后续工作。依法做好已退出产能企业的证照注销登记，督促相关企业做好职工安置、维稳和相关债务处置工作,防范化解系统性债务风险。

责任单位：州经济和信息化委，州安全监管局、州财政局、州人力资源社会保障局、州工商局、州公安局、阿坝银监分局、人行阿坝州中心支行、州质监局、州发展改革委、州环境保护局、州国土资源局、州国税局、州地税局。

（二）因城施策去库存。

3.出台关于加快化解商业房地产库存的指导意见和州城镇住房发展“十三五”规划。分解下达棚改货币化任务，与县（市）政府签订目标责任书。发布全州2017年住宅用地年度供应计划分类名单。

责任单位：州城乡建设住房局，州发展改革委、州财政局、州商务局、州国土资源局、州政府金融办、州国税局、州地税局、人行阿坝州中心支行、阿坝银监分局

4.进一步完善房地产市场调控措施，及时发布全州房地产交易、土地供应信息，定期通报各地去库存进展情况，对商品住房消化周期过高的县（市）进行警示，根据市场变化对热点县（市）进行约谈。

责任单位：州城乡建设住房局，州国土资源局、州政府金融办、人行阿坝州中心支行、阿坝银监分局

（三）积极稳妥去杠杆。

5.引导银行业金融机构根据国家产业升级、结构调整目录和我州重点产业发展规划，按照风险可控、商业可持续原则，加强授信机制、业务流程、产品开发等创新，加大对新兴产业、节能环保、生态产业发展和脱贫攻坚的支持力度，进一步增强信贷投放结构与全州经济发展的协调配合。

责任单位：州政府金融办、人行阿坝州中心支行、阿坝银监分局、州经济和信息化委、州财政局

6.贯彻落实好国家、省、州出台的财政、金融、税收等有关支持政策，引导和鼓励银行业金融机构创新金融产品、改进金融服务、扩大信贷投放、提升金融质效，加大对重点领域和薄弱环节的信贷支持。

责任单位：州政府金融办、州经济和信息化委，州财政局、州国资委、州国税局、州地税局、人行阿坝州中心支行、阿坝银监分局

7.出台《阿坝州金融支持脱贫攻坚十三条措施》，加大州内拟上市、挂牌企业培育辅导力度，支持符合条件企业通过主板、中小板、创业板上市和新三板、天府（四川）股交中心挂牌融资。

责任单位：州政府金融办、州工商局、人行阿坝州中心支行、阿坝银监分局

（四）多措并举降成本。

8.降低企业用电成本。制定出台《阿坝州电力能源管理计划（2017年—2020年）》，成立电力能源管理计划领导小组。进一步扩大直购电、富余电市场交易，争取继续以平移法方式传导发电量价差，推进实施直购电政策，争取铝硅精准扶贫电量20亿千瓦时。2017年全州工业企业实施直购电用户增加到27户，力争直购电量实施规模扩大到12亿千瓦时。用好留存电量政策，继续保持留存电量计划35.4亿千瓦时，努力实现安排“飞地”园区留存使用电量1.1823亿千瓦时，切实降低企业用电成本。

责任单位：州经济和信息化委、州发展改革委

9.降低企业融资成本。制定并积极落实《2017年度支持工业发展专项资金总体安排方案》，努力通过企业贷款贴息、财政金融互动奖补，设立中小微企业贷款风险补贴资金等方式，降低企业成本。积极开展工业企业融资需求调查，做好银政企对接工作，进一步缓解“融资难、融资贵”难题。

责任单位：州政府金融办，州经济和信息化委、州财政局、州国资委、州发展改革委、人行阿坝州中心支行、阿坝银监分局

10.深入推进放管服改革，清理州、县（市）两级行政许可目录，与全省同步开展“多证合一、一照一码”改革，全面实行企业简易注销登记改革。督促各地、各有关部门完善“一单两库一细则”，全面推行“双随机一公开”监管制度。

责任单位：州政务服务管理办，州政府法制办、州工商局、州直有关部门、各县（市）人民政府

11.实施高新技术企业、小微企业固定资产加速折旧、研发费用加计扣除等税收优惠政策。落实国家调整房地产交易环节契税、增值税优惠政策。落实符合条件的困难企业依法依规享受税收“减、免、缓”政策。对企业合并、分立、破产等依法给予契税、土地增值税、印花税等税收优惠。

责任单位：州国税局、州地税局，州财政局

12.系统开展清费减负工作，清理规范行政审批中介服务收费，全面清理行政事业性收费和政府性基金，开展涉企收费专项检查，建立政府定价管理的涉企、进出口环节、行政审批前置经营服务收费“三项收费目录清单”制度。

责任单位：州发展改革委、州财政局

13.督促引导物流企业规划实施城市共同配送物流体系和城乡物流配送网点建设。支持物流公司开拓城市社区物流，大力发展电子商务物流。鼓励发展城市共同配送、中心城区集中配送。整合现有物流资源，降低物流综合成本。

责任单位：州政府口岸物流办、州政府物流业发展工作领导小组成员单位、各县（市）人民政府

（五）精准加力补短板。

14.分解下达减贫年度目标任务，坚持“六个精准”要求，对接落实“五个一批”扶贫攻坚行动计划、22个扶贫攻坚专项方案，大力实施区域发展与扶贫攻坚规划，重点扶持3.08万名农村扶贫对象改善生产生活条件，易地扶贫搬迁安置贫困农牧民2956人，继续实施扶贫攻坚、以工代赈、现代农业发展工程、农业公共安全与生态资源保护利用工程。深入实施“金融扶贫惠农工程”，加大金融支持力度。

责任单位：州扶贫移民局、州发展改革委、州财政局、州国土资源局、州农牧局、人行阿坝州中心支行、阿坝银监分局，各县（市）人民政府。

15.实施4773户贫困危房户新居建设，在9个县（市）继续实施幸福美丽新村示范县建设，完善239个扶贫新村公共服务和基础设施配套建设。

责任单位：州发展改革委、州委农工委、州财政局、州城乡建设住房局、州扶贫移民局，各县（市）人民政府

16.开展藏汉“双语”联合宣讲500场次。新建26个乡村学校少年宫，发放安装“户户通”卫星接收设备6186套，实施村级农民健身工程169个。积极开展惠民活动，为农村放映公益电影1.62万场。

责任单位：州委宣传部、州委统战部、州发展改革委、州民宗委、州司法局、州财政局、州文广新局、州体育局、州科协，各县（市）人民政府

17.实施就业社保促进计划，落实更加积极的就业、创业政策，城镇登记失业率控制在4.0%以内，努力实现2014级藏区“9+3”学生初次就业率达95%。努力推进社保扩面，提高城乡低保、医疗救助水平，新建城乡社区日间照料中心75个，为2.94万困难家庭失能老人和80周岁以上老年人提供居家养老服务。

责任单位：州人力资源社会保障局、州发展改革委、州教育局、州民宗委、州民政局、州财政局，各县（市）人民政府

18.深入实施十五年免费教育，重点实施《四川省民族地区教育发展十年行动计划（2011—2020年）》2017年度项目，继续实施“9+3”免费职业教育计划、免费师范生培养计划，落实义务教育经费保障政策等，对建档立卡贫困家庭中职和大学生给予特别资助。力争学前三年和高中阶段毛入园（学）率分别达78.5%和80.0%。

责任单位：州教育局

19.完善公共卫生服务体系。推进包虫病综合防治工作，实施医疗卫生服务人员培训计划和农村订单定向医学生免费培养项目等，适当提高基本公共卫生服务经费标准，为6500名农村孕产妇给予住院分娩补助，为150例贫困白内障患者实施复明手术。

责任单位：州卫计委

20.实现天然林保护全覆盖，继续实施新一轮退耕还林。落实金川崇化水利工程、阿坝若果郎水利工程渠系配套建设项目资金7740万元，2.9万人受益。落实中小河流治理工程中央预算内投资6683万元，重点支持梭磨河马尔康县城区河道综合治理、杜柯河壤塘县城南堤防、白河红原县邛溪镇安曲河段堤防、黑河若尔盖县城区堤防等工程建设。

责任单位：州林业局、州水务局、州发展改革委、州财政局

21.对照国家生态保护红线划定技术组，依据卫星遥感画图提出的《四川省生态保护红线划分建议方案》，在2017年底前完成各县(市)生态红线划定。贯彻落实大气、水、土壤污染防治三大行动计划，制定实施《阿坝州环境污染防治“三大战役”2017年度实施方案》，集中开工建设一批大气、水、土壤污染防治重大项目。积极推进落实流域水污染防治河长制，实施土壤环境监测预警建设行动，启动土壤污染详查，开展土壤环境风险管控试点区建设。

责任单位：州环境保护局、州发展改革委、州经济和信息化委、州水务局、州农牧局、州林业局、州国土资源局、州城乡建设住房局

（六）大力推进农业供给侧结构性改革。

22.调整优化农业产业结构，积极支持农牧业产业化、精深加工、延伸产业链，推动农牧结合、种养循环示范场。建设阿坝、理县等现代农业规范化标准栽培集中示范片5000亩，全州特色农产品产量达到160万吨以上。加快我州畜种改良步伐，提高改良面，坚持引进优质种畜禽，不断提高畜种良种率。2017年，预计我州引进优质种畜（猪、牛、羊）6万头只，优质禽兔4万羽只；开设牦牛冷配点25个，黄牛冷配点11个，猪冷配点1个。不断加快转变畜牧业生产经营方式，2017年预计各类牲畜年出栏同比增长3.5%左右，肉、奶产量同比分别增长3.5%和2%左右。

责任单位：州农牧局、州委农工委、州发展改革委、州林业局、州科技知识产权局、州工商局、州质监局

三、保障措施

（一）细化落实目标任务。州直有关部门要认真对照工作方案，结合职能职责，逐项分解和细化落实本部门牵头的供给侧结构性改革年度重点任务，进一步明确责任人和时间进度要求，实行挂图作战，确保完成既定目标任务。

（二）完善会商和信息报送机制。建立横向联系州直有关部门、纵向联系县（市）的供给侧结构性改革工作信息沟通和联络机制，及时收集推广实施供给侧结构性改革的典型经验和做法。坚持每季度召开供给侧结构性改革的部门会商会议，及时研究解决改革中的困难和问题。

（三）加强督查考核评估。建立健全供给侧结构性改革工作考核评价指标体系，强化年度目标任务督查考核，确保工作方案落地落实。及时掌握改革推进情况，科学评估实施效果，调整完善政策措施。
