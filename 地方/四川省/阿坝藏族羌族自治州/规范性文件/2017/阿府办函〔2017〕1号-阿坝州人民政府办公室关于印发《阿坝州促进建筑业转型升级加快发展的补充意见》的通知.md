# 阿坝州人民政府办公室关于印发《阿坝州促进建筑业转型升级加快发展的补充意见》的通知

阿坝州人民政府办公室

关于印发《阿坝州促进建筑业转型升级加快发展的

补充意见》的通知

阿府办函〔2017〕1号

各县（市）人民政府，州政府各部门，各直属机构，卧龙特别行政区，有关单位：

《阿坝州促进建筑业转型升级加快发展的补充意见》已经州委、州政府研究同意，现印发给你们，请结合实际认真贯彻执行。

阿坝州人民政府办公室

2017年1月9日

阿坝州促进建筑业转型升级加快发展的补充意见

为培育壮大建筑业市场主体，充分发挥建筑业在稳增长、促进就业等方面的重要作用，推进全州经济发展，根据《中华人民共和国民族区域自治法》《阿坝藏族羌族自治州自治条例》和《四川省人民政府关于促进建筑业转型升级加快发展的意见》(川府发〔2014〕30号)精神，现对《阿坝州促进建筑业转型升级加快发展的实施意见》（阿府办发〔2014〕29号）提出以下补充意见。

一、加强招投标管理

（一）由州、县（市）发改部门立项（备案）的政府投资或以政府投资为主的建设项目（包括：房屋建筑、市政基础设施、交通、水利、园林绿化等，地灾治理、生态保护等项目参照本意见执行）的施工、勘察、设计、监理等在本州注册登记具有独立法人资格且符合资质要求的企业中，按招标投标办法确定中标人。在招标投标中不再设业绩条件，企业资质达到规定要求，不得高设资质条件或增设其它资质条件。技术复杂的桥梁、隧道和钢结构等或有特殊施工要求的项目不受此款限制。项目投标企业不足3家及以上不能满足招投标条件，或由国家和省立项（备案）的政府投资或以政府投资为主的建设项目面向全国公开招标。

（二）未在州注册登记具有独立法人资格的建筑企业，承揽我州建设项目，应在州注册分公司。

（三）探索推行勘察设计施工一体化招标，鼓励支持项目业主，采用工程总承包（EPC）模式，将勘察、设计、施工打捆招标，加快项目落地。

二、建立奖励机制

（一）企业注册与升级奖励。2017年1月1日以后在州行政区域内新注册登记且具有独立法人资格的企业，自取得资质之日起一年内税收达到30万元的施工总承包特级、一级、二级、三级企业，分别给予一次性奖励50万元、20万元、10万元、5万元；自取得资质之日起一年内税收达到15万元的工程监理、勘察设计甲级（或综合）、乙级、丙级企业，分别给予一次性奖励10万元、5万元、3万元，其它建设服务类企业参照执行。在州注册具有独立法人资格企业的施工总承包资质每提高一个等级奖励5万元。

（二）促进就业奖励。在州注册企业，解决当地群众50人就业且连续在岗工作3个月以上的，给予5万元奖励，每增加1人给予1000元奖励，最高奖励不超过7万元。

（三）税收奖励。年上缴税收到达或超过300万元的前5名企业，由州人民政府命名为“突出贡献企业”并奖励第一名50万元、第二名30万元、第三名20万元，第四、五名各10万元。

（四）拓展市场奖励。在州外承揽业务年产值超过1亿元的前3名企业，由州人民政府命名为“优秀拓展企业”并奖励第一名50万元、第二名30万元、第三名20万元。

以上奖励由行业主管部门审核，报州人民政府批准后统一奖励。各县（市）可参照制定相关奖励政策。

三、培育支持企业发展

（一）鼓励企业回州。鼓励支持本州籍人员在外注册发展的企业回州注册，享受招商引资、就业创业等优惠政策，在工商注册、资质办理、人员培训、担保贷款等方面给予大力支持。

（二）增强服务实效。建立“一对一”帮扶机制，做好“扶上马、送一程”“量体裁衣式”服务，切实解决企业存在的困难和问题，为企业发展创造良好的市场环境。

（三）加大金融支持。积极协调金融机构加大对在州注册企业的资金支持力度，进一步简化审贷程序，提高信贷服务水平，适当拓宽抵押物范围，探索建立高效服务企业的融资担保模式，切实解决企业发展的资金瓶颈。鼓励企业做大做强，积极创造条件支持企业上市。

四、加强企业诚信建设

（一）建立企业信息登记制度。行业主管部门应登记本行业内从事建筑活动企业的基本信息和承揽业务信息，并与税务部门互联共享。对未如实向行业主管部门登记信息的企业，将其诚信状况纳入重点监控。

（二）建立企业诚信奖惩机制。开展企业诚信评价管理，由行业主管部门将企业的不良记录、良好记录和履约情况等进行量化评价，并依法及时在网上公示，并将企业信用信息与资质审批、评优评奖、招投标挂钩，建立健全“守信者受褒奖、失信者受罚”的诚信体系。

五、保障措施

（一）强化组织领导。各县（市）人民政府、州级各部门要充分认识建筑业在促进我州经济发展、促进就业、推进城镇化进程中的重要作用，建立健全建筑业发展领导小组，创新服务，为企业发展搭建良好平台。

（二）强化部门联动。建立部门与部门、政府与企业之间的沟通机制，畅通联系渠道，发挥职能部门职责，及时研究、协调解决建筑业发展中存在的困难和问题。

（三）强化统计考核。各县（市）统计部门要做好企业的数据统计，指导符合要求的企业入库申报，做到应统尽统。州人民政府将进一步强化对各县（市）建筑业产值目标的考核，并适时开展专项督查。

六、其他事项

本补充意见由州城乡建设住房局负责解释，自2017年1月1日起执行。
