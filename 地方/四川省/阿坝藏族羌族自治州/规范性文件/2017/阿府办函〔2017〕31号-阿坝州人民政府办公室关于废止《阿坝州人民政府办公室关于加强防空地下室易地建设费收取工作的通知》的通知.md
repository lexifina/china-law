# 阿坝州人民政府办公室关于废止《阿坝州人民政府办公室关于加强防空地下室易地建设费收取工作的通知》的通知

阿坝州人民政府办公室

关于废止《阿坝州人民政府办公室关于加强

防空地下室易地建设费收取工作的通知》的通知

阿府办函〔2017〕31号

各县（市）人民政府，州政府各部门、各直属机构，卧龙特别行政区，有关单位：

根据《四川省发展和改革委员会 四川省财政厅 四川省人民防空办公室 四川省住房和城乡建设厅关于进一步规范防空地下室易地建设费的通知》（川发改价格〔2016〕650号）精神，经研究，决定废止《阿坝州人民政府办公室关于加强防空地下室易地建设费收取工作的通知》（阿府办函〔2012〕144号），自即日起停止执行。

阿坝州人民政府办公室

2017年4月15日
