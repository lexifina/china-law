# 阿坝州人民政府办公室关于一季度“中国阿坝州”门户网站内容保障和政府信息公开目录管理系统填报发布情况的通报

阿坝州人民政府办公室

关于一季度“中国阿坝州”门户网站内容保障和

政府信息公开目录管理系统填报发布情况的通报

阿府办函〔2017〕33号

各县（市）人民政府，州政府各部门、各直属机构，卧龙特别行政区，有关单位：

按照《阿坝州人民政府办公室关于2017年全州政府网站目录系统填报和信息报送任务的通知》（阿府办函〔2017〕16号）要求，州政府办公室对各县（市）和州政府各部门、各直属机构2017年一季度“中国阿坝州”门户网站内容保障和政府信息公开目录管理系统填报发布情况进行了梳理、检查。经州政府办公室领导同意，现将有关情况予以通报。

一、“中国阿坝州”门户网站内容保障情况

（一）各县（市）报送情况。一季度，“中国阿坝州”门户网站采用13个县（市）和卧龙特别行政区信息607条，完成季度目标任务152%。其中,松潘、茂县、壤塘3县完成情况良好，完成季度目标任务200%以上；九寨沟、马尔康2县（市）未完成季度目标任务（附件1）。

（二）州级报送情况。“中国阿坝州”门户网站采用59个州政府部门、直属机构信息478条，完成季度目标任务162%。其中,州林业局、州农牧局、州旅发委等16个部门完成季度目标任务200%以上；州邮政管理局、州地税局、州政务服务管理办等13个部门未完成季度目标任务；阿坝银监分局、黄龙管理局、德阿产业园区管委会等8个部门一季度报送信息极少，被采用数量为0（附件2）。

希望完成季度目标任务的单位继续加大信息编发上报力度，做好“中国阿坝州”门户网站内容保障工作。未完成季度目标任务的单位，要深入查找分析原因，制定落实整改措施，立足工作实际，围绕州委、州政府中心工作和公众关切，从拓宽信息渠道入手，深入挖掘素材，切实提高信息质量和时效性，提高信息采用量。

二、政府信息公开目录管理系统填报公开情况

（一）各县（市）公开情况。一季度，全州13个县（市）和卧龙特别行政区在政府信息公开目录管理系统共填报公开信息13050条，完成季度目标任务的189%。13个县（市）和卧龙特别行政区均顺利完成了一季度政府信息公开目录管理系统填报公开任务（附件3）。

（二）州级公开情况。56个州政府部门、直属机构在政府信息公开目录管理系统共填报公开信息2359条，完成季度目标任务的183%。其中,州公路局、州教育局、州国税局等43个部门完成了一季度目标任务；州编译局、州环境保护局、州地税局等13个部门未完成一季度目标任务，黄龙管理局填报公开数为0条（附件4）。

请各县（市）、各部门高度重视政府信息公开目录管理系统填报公开工作，认真贯彻落实《中华人民共和国政府信息公开条例》，根据职能职责确定主动公开的政府信息内容，属于主动公开的政府信息，务必遵循“谁制作谁公开，谁保存谁公开”的原则，在政府信息形成或者变更之日起20个工作日内予以公开。要逐步完善政府信息公开目录体系，提升目录管理信息化水平，做到内容高度整合、表现方式统一、资源全面共享，并通过各地各部门政府网站信息公开专栏向公众提供方便、快捷的信息查询，切实保障公民的知情权、参与权和监督权。

三、2016年度信息公开年报编制和公开情况

（一）县（市）级编制公开情况。全州13县（市）将219个乡（镇）和535个县（市）级行政机关以及与群众利益密切相关的公共企事业单位作为政府信息公开的主体。截至3月31日，全州13县（市）本级均已按时依规完成2016年政府信息公开年度报告填报发布工作,填报发布率达100%；186个乡（镇）和499个县（市）级相关部门完成年报填报发布工作，完成率达91%。但仍有马尔康、金川、小金、若尔盖、红原5个县（市）的33个乡（镇）和36个县（市）级相关部门未按时依规填报发布2016年政府信息公开年度报告。

（二）州级编制公布情况。按照全省政府信息公开目录管理系统组织机构设置情况，州级将61个州级行政机关以及与群众利益密切相关的公共企事业单位作为政府信息公开的主体。截至3月31日，61个州级相关部门均已通过四川省政府信息公开目录管理系统的指定栏目，按时依规完成2016年政府信息公开年度报告填报发布工作，填报发布率达100%。

从公开形式和内容来看，我州各级各部门在填报和发布年度报告主要存在公开主体不明确、编制工作流于形式、公开内容空洞、图表缺失、数据不详等问题。针对以上存在的问题，各县（市）、州政府各部门、各直属机构要按照《条例》规定的年报公开主要内容，找准问题、及时整改，在公开质量、公开载体、公开时效上下功夫。尚未完成年度报告编制工作的县（市）于4月30日前完成编制发布工作。5月上旬，我州将集中开展一次政府信息公开年度报告编制、公布情况的专项督查，对工作落实不到位的进行问责。

四、政府网站运维管理情况

(一)网站抽查情况。2017年第一季度，按照《国务院办公厅关于开展第一次全国政府网站普查的通知》（国办发〔2015〕15号）的普查标准要求，省政府办公厅对全省处于正常运行状态的1870家政府网站开展抽查工作，共发现不合格网站31个，我州“中国·金川”“阿坝州环境保护局”“理县人民政府政务服务中心”网站被抽检为不合格。州政府办公室采取系统扫描和人工复核相结合的方式对全州13县（市）、31个州级部门的54个政府网站进行了常态化监测，发现绝大多数政府网站均不同程度地存在多个栏目为空、多个栏目长期不更新、较多的无效链接、网站运行不稳定等问题。

（二）整改工作情况。针对存在的问题，省、州先后多次下发文件对政府网站整改工作提出明确要求。州环境保护局、金川县政府办公室、理县政府办公室在第一时间对问题网站进行了核查整改，并于4月1日前将问题网站整改情况反馈州政府办公室。州政府办公室检查监测出的网站问题，绝大多数网站主管部门按照要求进行了整改，并按时将整改情况反馈州政府办公室。但仍有州经济和信息化委、州水务局、州统计局、州食品药品监管局、州住房公积金中心、州防震减灾局6个部门未反馈整改情况，请上述单位于4月28日前将网站问题整改情况报送州政府办公室。

下一步工作中，请各县（市）政府办公室、州级部门办公室要切实履行政府网站主管责任，抓好本地区、本部门（系统）政府网站督促检查、整改提高和规范提升工作。要强化政府网站的管理，政府网站相关负责同志及工作人员要认识到位、责任到位、履职到位；要不断加强信息发布、解读回应、办事服务、互动交流等信息内容建设，坚决杜绝政府网站“四不”（不及时、不准确、不回应、不实用）问题的出现。州政府办公室将进一步加强政府网站常态化监测，定期对全州政府网站开展抽查和核查工作，对问题网站主管部门不作为、慢作为的，将对网站相关责任人开展约谈，追究责任，逗硬年终考核。
