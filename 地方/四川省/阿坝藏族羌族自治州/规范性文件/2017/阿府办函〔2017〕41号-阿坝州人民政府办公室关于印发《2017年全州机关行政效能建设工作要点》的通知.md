# 阿坝州人民政府办公室关于印发《2017年全州机关行政效能建设工作要点》的通知

阿坝州人民政府办公室

关于印发《2017年全州机关行政效能建设工作要点》的通知

阿府办函〔2017〕41号

各县（市）人民政府，州政府各部门、各直属机构，有关单位：

为深入推进我州机关行政效能建设，规范行政行为，提升工作效率，创造更加规范、高效、诚信、开放的政务环境和发展环境，现将《2017年全州机关行政效能建设工作要点》印发你们，请认真贯彻执行。

请各责任单位于6月15日、12月15日前，将本单位半年和全年工作开展情况报牵头单位。各牵头单位整理、汇总后，于6月25日、12月25日前报州政府办公室。联系人：钟荣华，电话：2824940。

阿坝州人民政府办公室

2017年5月5日

2017年全州机关行政效能建设工作要点

2017年，全州机关行政效能建设工作的总体要求是：深入贯彻党的十八大及十八届三中、四中、五中、六中全会精神，全面落实习近平总书记系列重要讲话要求，紧紧围绕州委、州政府中心工作，全面加强机关行政效能建设，力求在构建长效机制上取得新进展，在拓展服务领域上迈出新步伐，在推进政务公开上实现新突破，在推动执行落实上收到新实效，在机关作风建设上展现新形象，为建设“三区一中心”、决胜全面小康、建设美丽阿坝提供坚强保障。

一、深入推进依法决策

(一)健全决策机制。

1.探索建立重大行政决策事项目录管理制度，制定重大行政决策事项目录。

牵头单位：州政府办公室

责任单位：州政府各部门、各县（市）人民政府

2.落实重大决策公众参与制度。搭建重大行政决策公众参与平台，按程序公开重大决策的内容、事项和依据等；依法组织相关部门和群众代表参加座谈会、听证会，广泛听取群众特别是厉害关系人的意见建议，提高公众参与度。

牵头单位：州政府办公室

责任单位：州政府各部门、各县（市）人民政府

3.制定《阿坝州重大决策专家论证办法》，健全行政决策咨询论证专家库。

牵头单位：州政府法制办

责任单位：州政府各部门、各县（市）人民政府

4.执行《四川省社会稳定风险评估办法》，建立重大决策社会稳定风险评估机制。

牵头单位：州政府办公室

责任单位：州政府法制办、各县（市）人民政府

5.落实《阿坝州人民政府重大行政决策合法性审查规定》，完善行政机关内部重大决策合法性审查机制，实现合法性审查全覆盖。

牵头单位：州政府法制办

责任单位：州政府各部门、各县（市）人民政府

（二）完善追责机制。

1.严格执行《中国共产党问责条例》《四川省贯彻<中国共产党问责条例>实施办法》《四川省重大行政决策责任追究办法》《关于对州委州政府重大决策部署执行不力实行问责的办法（试行）》。

牵头单位：州监察局

责任单位：州政府各部门、各县（市）人民政府

2.严格实施重大决策终身责任追究制和责任倒查制。对决策严重失误或依法应该及时作出决策但久拖不决造成重大损失、恶劣影响的，追究相关责任人员的党纪政纪和法律责任。

牵头单位：州监察局

责任单位：州政府各部门、各县（市）人民政府

二、深入推进深化行政制度改革

（一）探索推进改革试点。

1.在马尔康、若尔盖、茂县、九寨沟四县（市）探索推进相对集中行政许可权改革试点。

牵头单位：州政务服务管理办

责任单位：州委编办、州政务服务中心，马尔康市、若尔盖县、茂县、九寨沟县人民政府

（二）进一步规范审批事项。

1.完善行政审批事项定期清理、动态调整、及时公布的机制。重点清理行政许可项目的子项。及时公布精简后的行政审批事项目录。

牵头单位：州政务服务管理办

责任单位：州政府各部门、各县（市）人民政府

2. 严格执行国务院取消非行政许可审批事项。严格界定非行政许可审批项目范围，逐步取消非行政许可审批项目。

牵头单位：州委编办

责任单位：州政府各部门、各县（市）人民政府

3.积极承接落实国务院、省政府下放的行政审批事项，确保无缝对接。加强对已取消和调整行政审批事项的衔接和后续监督。对保留的行政审批事项，实行目录化、编码化管理。

牵头单位：州政务服务管理办

责任单位：州政务服务中心、州法制办、各县（市）人民政府

（三）进一步规范权力运行。

1.贯彻执行《四川省权责清单动态调整管理办法》及监管细则。

牵头单位：州政务服务管理办、州委编办

责任单位：州政府法制办、州直行权部门

2.公布州、县（市）两级行政权力清单，实现行政权力清单统一化、目录化、编码化管理，并适时进行动态调整。

牵头单位：州政务服务管理办

责任单位：州委编办、州政府法制办、州直行权部门，各县（市）人民政府

3.强化权力制约。对财政资金使用、国有资产监管、政府投资、政府采购、公共资源转让、公共工程建设等权力集中的部门和岗位实行分事行权、分岗设权、分级授权，定期轮岗，强化内部交流控制，防止权力滥用。

牵头单位：州委编办、州人力资源社会保障局、州政务服务管理办

责任单位：州直行权部门

（四）进一步规范公共资源交易。

1.推进州公共资源交易中心职能转变，完成交易平台层级整合，做好州、县（市）资源交易中心的业务对接。

牵头单位：州政务服务管理办

责任单位：州公共资源交易中心、各县（市）人民政府

2.加快公共资源交易规范化、电子化进程，6月底前实现国家、省、州三级公共资源交易平台系统互联互通，力争年底基本实现公共资源交易全流程电子化。

牵头单位：州政务服务管理办

责任单位：州公共资源交易中心、各县（市）人民政府

三、不断优化政务服务

（一）健全服务体系。

1.全面深化乡（镇）便民服务中心建设，推动州、县（市）、乡（镇）、村四级联动，努力实现政务服务均等化、全覆盖。

牵头单位：州政务服务管理办

责任单位：州政府政务中心、各县（市）人民政府

2.积极推行电子政务，实现网上咨询、申报、受理、审批和结果公示一体化。

牵头单位：州政务服务管理办

责任单位：州政府政务中心、州政府各部门、各县（市）人民政府

（二）加快标准建设。

1.落实行政审批标准化要求，进一步简化、优化、规范行政审批项目的审批条件、程序、时限等要素，逐项完善流程图、办事指南和操作规则，健全审批办法和工作流程，提高审批效率。

责任单位：州政务服务管理办

责任单位：州政府政务中心、州政府各部门、各县（市）人民政府

（三）优化窗口服务。

1.进一步理顺部门之间和部门内部的职能关系，将行政审批和公共服务等行政管理事项纳入政务服务中心办理，做到“两个百分之百”（即：行政审批服务部门进驻中心100%，行政审批服务事项进驻服务窗口100%），实现“一窗式受理、一站式审批、一条龙服务”。

责任单位：州政务服务管理办

责任单位：州政府政务中心、州政府各部门、各县（市）人民政府

2.加强政务服务中心窗口工作人员队伍建设，强化系统培训，提高业务能力和服务水平。

牵头单位：州政务服务管理办

责任单位：州政务服务中心、州政府各部门、各县（市）人民政府

四、扎实推进政府信息公开和基层政务公开

（一）强化重点领域信息公开。

1.按照“五公开”的原则，抓好行政审批、公共资源交易、财政信息、保障性住房、食品药品安全、环境保护、安全生产、扶贫攻坚、价格和收费、征地拆迁和教育等方面的信息公开工作。按时编制政府信息公开年度报告，依法做好政府信息依申请公开工作。

牵头单位：州政府办公室

责任单位：州政府各部门、各县（市）人民政府

（二）强化公开平台载体建设。

1.健全例行新闻发布制度，利用新闻发布会、新闻通气会、组织记者采访、答记者问、网上新闻发布等多种形式发布信息。

牵头单位：州政府新闻办

责任单位：州政府各部门、各县（市）人民政府

2.加强政府网站、政府信息公开目录填报系统建设和管理。做好政府网站普查常态化工作，督促已确定关停、整合的县级部门网站完成关停、整合，解决政府网站“四不”问题。加强政府网站常态化监测服务，按季度通报监测情况，促使其充分发挥信息公开、办事服务、政民互动三大核心功能。

牵头单位：州政府办公室

责任单位：州政府各部门、各县（市）人民政府

（三）强化基层政务公开。

1.扎实推进村（居）政务公开，健全公开制度，规范公开内容，完善公开程序，充分利用各种便民方式和渠道及时公开城乡居民关心事项。

牵头单位：州民政局

责任单位：各县（市）人民政府

2.健全农村集体资金、资产、资源管理制度，完善村（居）务监督机制，完善村规民约，推行“阳光村务”，提升基层治理水平。

牵头单位：州民政局

责任单位：州农业畜牧局、各县（市）人民政府

五、严格监督检查

（一）严格重点督查。

1.建立重点工作任务落实情况日常监控长效机制，完善决策督查、专项督查、结果运用和督查调研于一体的督查工作体系。

牵头单位：州委州政府督查室（目标办）

责任单位：州政府办公室

2.紧紧围绕州委、州政府的重大决策、重要部署、重点工作以及领导批示等，建立督查工作台帐，采用现场督查、明察暗访等方式开展督促检查，确保政令畅通。

牵头单位：州委州政府督查室（目标办）

责任单位：州政府办公室

（二）严格效能监察。

1.完善行政效能监察平台，通过视频、数据、电话、预警纠错等措施，强化政务服务窗口、审批事项、审批单位和责任岗位的实时监控。

牵头单位：州政务服务管理办

责任单位：州政务服务中心、各县（市）人民政府

2.严格执行首问责任、限时办结和责任追究制度，加大跟踪督查力度，推动工作提速增效。

牵头单位：州政府办公室

责任单位：州监察局、州政务服务管理办

3.开展专项监察和政风行风测评工作。

牵头单位：州监察局

责任单位：州政府办公室、各县（市）人民政府

（三）严格绩效管理。

1.完善绩效评估指标体系和评估机制，做好日常督查考评工作，提高机关行政效能。

牵头单位：州委州政府督查室（目标办）

责任单位：州政府办公室

2.建立健全绩效问责及结果运用制度，严肃工作纪律，防止弄虚作假，确保绩效管理公正、规范、有序。

牵头单位：州委州政府督查室（目标办）

责任单位：州政府办公室

（四）严格责任追究。

1.严格监督执纪，受理和处置职能部门移交的问题线索，严肃查处不正确履行职责以及不作为、慢作为、乱作为等涉及行政效能和政风行风的案件。严格执行“一岗双责”和“一案双查”。

牵头单位：州监察局

责任单位：州政府办公室、各县（市）人民政府
