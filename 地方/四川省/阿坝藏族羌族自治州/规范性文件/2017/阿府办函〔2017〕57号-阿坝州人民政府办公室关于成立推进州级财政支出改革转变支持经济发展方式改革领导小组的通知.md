# 阿坝州人民政府办公室关于成立推进州级财政支出改革转变支持经济发展方式改革领导小组的通知

阿坝州人民政府办公室

关于成立推进州级财政支出改革转变支持经济

发展方式改革领导小组的通知

阿府办函〔2017〕57号

各县（市）人民政府，州政府有关部门，有关单位：

为进一步优化财政支出结构，发挥财政资金引导效应和杠杆乘数作用，统筹推进财政支出改革转变支持经济发展方式改革工作，经州政府领导同意，决定成立推进州级财政支出改革转变支持经济发展方式改革领导小组，现将相关事宜通知如下。

一、主要职责

贯彻落实国家和省关于推进财政支出改革的决策部署，研究调整支出结构、盘活存量资金和转变支持经济发展方式的重大事项，统筹推进全州财政支持产业发展工作。
