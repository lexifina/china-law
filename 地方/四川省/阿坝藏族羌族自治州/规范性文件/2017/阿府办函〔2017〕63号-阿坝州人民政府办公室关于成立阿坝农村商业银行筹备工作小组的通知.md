# 阿坝州人民政府办公室关于成立阿坝农村商业银行筹备工作小组的通知

阿坝州人民政府办公室

关于成立阿坝农村商业银行筹备工作小组的通知

阿府办函〔2017〕63号

各县（市）人民政府，州政府各部门、各直属机构，卧龙特别行政区，有关单位：

为扎实推进阿坝农村商业银行筹备工作，经州政府领导同意，决定成立阿坝农村商业银行筹备工作小组。现将相关事宜通知如下。

组  长：于  泳    州委常委、副州长

副组长：卢晓军    州政府副秘书长、金融办主任

郑  琨    人行阿坝州中心支行行长

梁  超    阿坝银监分局局长

刘发斌    州信用联社董事长

成  员：王小兵    州公安局副局长

雷  刚    州财政局副局长

泽仁达瓦  州国土资源局局长

李绍友    州城乡建设住房局局长

白惠蓉    州工商局局长

白  冰    州国税局局长

吴光旭    州地税局局长

筹备工作小组办公室设在州信用联社，由刘发斌同志兼任办公室主任，负责处理日常事务。

阿坝州人民政府办公室

2017年6月27日
