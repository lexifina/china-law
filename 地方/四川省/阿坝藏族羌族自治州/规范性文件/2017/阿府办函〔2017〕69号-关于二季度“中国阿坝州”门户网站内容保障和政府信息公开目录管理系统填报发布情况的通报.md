# 关于二季度“中国阿坝州”门户网站内容保障和政府信息公开目录管理系统填报发布情况的通报

阿坝州人民政府办公室

关于二季度“中国阿坝州”门户网站内容

保障和政府信息公开目录管理系统

填报发布情况的通报

阿府办函〔2017〕69号

各县（市）人民政府，州政府各部门、各直属机构，卧龙特别行政区：

按照《阿坝州人民政府办公室关于2017年全州政府网站目录系统填报和信息报送任务的通知》（阿府办函〔2017〕16号）要求，州政府办公室对各县（市）和州政府各部门、各直属机构2017年二季度“中国阿坝州”门户网站内容保障和政府信息公开目录管理系统填报发布情况进行了梳理、检查，现将有关情况予以通报。

一、“中国阿坝州”门户网站内容保障情况

（一）各县（市）报送情况。二季度，“中国阿坝州”门户网站采用13个县（市）和卧龙特别行政区信息885条，完成季度目标任务130.7%。其中,松潘、茂县、九寨沟、理县4县完成情况良好，完成季度目标任务150%以上；马尔康市连续两季度未完成目标任务。（附件1）。

（二）州级报送情况。“中国阿坝州”门户网站采用59个州政府部门、直属机构信息808条，完成季度目标任务78.4%。其中, 州监察局、州民政局、州防震减灾局、州发展改革委、州旅发委、州气象局等6个部门完成季度目标任务150%以上；黄龙管理局、人行阿坝州中心支行、州林业局等35个部门未完成季度目标任务，未完成任务的州级部门占上报政务信息的州级部门60%；州志办、成阿工业集中发展区管委会、州邮政管理局等4个部门二季度报送信息极少，被采用数量为0，德阿产业园区管委会连续两季度采用数量为零。（附件2）。

希望完成季度目标任务的单位继续加大信息编发上报力度，做好“中国阿坝州”门户网站内容保障工作。未完成季度目标任务的单位，要深入查找分析原因，制定落实整改措施，立足工作实际，围绕州委、州政府中心工作和公众关切，从拓宽信息渠道入手，深入挖掘素材，切实提高信息质量和时效性，提高信息采用量。

二、政府信息公开目录管理系统填报公开情况

（一）各县（市）公开情况。二季度，全州13个县（市）和卧龙特别行政区在政府信息公开目录管理系统共填报公开信息39582条，完成季度目标任务的202%。其中,松潘、黑水、茂县、理县、金川5县完成情况良好，完成季度目标任务200%以上；其余县（市）和卧龙特别行政区均顺利完成了二季度政府信息公开目录管理系统填报公开任务。（附件3）。

（二）州级公开情况。二季度，57个州政府部门、直属机构在政府信息公开目录管理系统共填报公开信息4131条，完成季度目标任务的197%。其中,州公路局、州教育局、州公共资源交易中心等38个部门完成了二季度目标任务；州疾控中心、州审计局、州志办等19个部门未完成二季度目标任务，州安全监管局、州文广新局填报公开数为0条（附件4）。

州工业园区管委会、州水务局、州编译局、黄龙管理局、州审计局、州安全监管局连续两季度未完成目标任务，特予以通报批评。

请各县（市）、各部门高度重视政府信息公开目录管理系统填报公开工作，认真贯彻落实《中华人民共和国政府信息公开条例》，根据职能职责确定主动公开的政府信息内容，属于主动公开的政府信息，务必遵循“谁制作谁公开，谁保存谁公开”的原则，在政府信息形成或者变更之日起20个工作日内予以公开。要逐步完善政府信息公开目录体系，提升目录管理信息化水平，做到内容高度整合、表现方式统一、资源全面共享，并通过各地各部门政府网站信息公开专栏向公众提供方便、快捷的信息查询，切实保障公民的知情权、参与权和监督权。

三、政府网站运维管理情况

2017年第二季度，按照《国务院办公厅秘书局关于2017年第一季度全国政府网站抽查情况的通报》（国办秘函〔2017〕14号）相关要求，州政府办公室采取系统扫描和人工复核相结合的方式对全州13县（市）、40个州级部门的53个政府网站进行了常态化监测，发现12个县（市）和9个州级部门政府网站均不同程度地存在多个栏目为空、多个栏目长期不更新、较多的无效链接、网站运行不稳定等问题（附件5），并督促相关网站主办单位及时整改。在省政府办公厅开展的第二季度全省政府网站抽查中，我州“中国·红原”网站被抽检为不合格。

请各县（市）、各部门办公室切实履行政府网站主管责任，抓好本地区、本部门（系统）政府网站督促检查、整改提高和规范提升工作。一是各县（市）、州级各部门要把学习贯彻《政府网站发展指引》（国办发〔2017〕47号）作为当前政府网站建设工作的重点，切实组织开展专题学习或集中培训，准确把握新时期政府网站建设的指导思想、发展目标、基本原则，全面落实政府网站职责分工、开设整合、功能定位、集约共享、创新发展、安全防护和机制保障等方面的具体要求，切实提高全州政府网站建设和管理水平。二是加强政府网站内容建设，建立完善常态化信息发布机制，加大网站日常检查和公开促改力度，杜绝应付检查突击发布。三是认真做好重要信息转载和网站纠错留言办理等工作，各县（市）、州级各部门政府网站要及时转载国务院、省政府重要信息，要健立健全“我为政府网站找错”监督举报平台网民留言办理机制，及时处理并回复网民留言。
