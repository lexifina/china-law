# 阿坝州人民政府办公室关于进一步加强春节期间森林草原防火工作的紧急通知

阿坝州人民政府办公室

关于进一步加强春节期间森林草原防火工作的紧急通知

阿府办函〔2017〕7号

各县（市）人民政府，州森林（草原）防火指挥部各成员单位：

春节假日即将来临，野外用火明显增多，特别是祭祖扫墓、焚香烧纸、燃放烟花爆竹等活动将显著增加，野外火源管理难度进一步加大，森林草原防火形势十分严峻。为确保广大群众度过一个欢乐详和的新春佳节，现就进一步加强春节期间森林草原防火工作紧急通知如下。

一、进一步加强隐患排查

在春节假日来临前，州、县（市）防火指挥部要全面开展一次森林草原火灾隐患排查，进一步加大景区、林区、牧区、村寨、工地、输电线路等重要部位和节点的火灾隐患排查力度，对出现的新问题、新情况进行梳理，抓好限时整改；同时，对入冬以来发现问题隐患的整改落实情况进行“回头看”，完善防控措施，做到防患于未然。

二、进一步加强宣传教育

要充分利用广播、电视、手机短信、微信等宣传手段，多途径、多渠道加强森林草原防火工作的宣传力度。注重以发生在群众身边的案例以案说法、以案释法，增强广大群众参与森林草原防火工作的主动性，自觉保护森林草原资源。

三、进一步加强火源管理

按照突出重点、属地管理、条块结合的原则，对人员活动密集的重点林区、自然保护区、风景名胜区、森林公园、湿地公园，要严格落实管理单位的防火责任，增设临时防火检查站，增加护林人员，加大巡护力度，加强重点部位火源管控。严禁在林区、牧区吸烟烤火、焚香烧纸、燃放烟花爆竹和孔明灯。重点加强对入山人员的管理，严格执行野外用火审批制度，严厉打击非法野外用火，确保火源不入林、火种不上山。

四、进一步加强值班值守

州、县（市）防火指挥部要统筹安排，严格执行领导带班和24小时值班制度，及时核查反馈卫星热点信息，准确掌握防火工作动态。春节期间，主要领导要亲自带班，亲自安排部署，亲自督促检查。一旦发生火灾，当地主要负责同志要靠前指挥，分管负责同志要深入火灾现场，科学、安全、快速的扑救火灾。

五、进一步加强预案修订

州、县（市）防火指挥部要根据森林草原防火工作的新情况、新特点和新要求，及时修订完善应急预案，做到措施管用、分工合理、责任明确，增强预案的操作性和实效性。

六、进一步加强应急准备

州、县（市）防火指挥部要加强防火队伍建设，宁可备而不用，不可用而不备。备好备足油锯、铁扫把等防火物资，及时检修扑火机具；特别要注重建好应急民兵队伍，重点加强防火隔离带设置等方面内容的培训，接到火情报告快速出动，确保森林草原火灾打早、打小、打了。

七、进一步加强信息报送

要严格落实森林草原火灾报告制度，坚持火灾归口报告原则，要在第一时间及时准确规范报送火情，坚决杜绝有火不报、大火小报等弄虚作假行为，严防因瞒报、漏报、迟报、误报火情而酿成大火和造成重大损失。

八、进一步加强责任落实

要全面落实森林草原防火工作行政首长负责制，明确目标，分解任务，细化责任，真正将森林草原防火责任主体落实到乡（镇）、村组和户，落实到各个基层防火责任单位，做到山有人管、林有人护、火有人防、责有人担。对发生的每一起火灾坚决做到“四个不放过”（事故原因不查清不放过，事故责任者得不到处理不放过，整改措施不落实不放过，教训不吸取不放过）；对因失职、渎职引发火灾造成重大损失的，依法严肃追究相关责任人的责任。

阿坝州人民政府办公室
