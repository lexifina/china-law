# 阿坝州人民政府办公室关于成立马尔康城市建设工作协调领导小组的通知

阿坝州人民政府办公室

关于成立马尔康城市建设工作协调领导小组的通知

阿府办函〔2017〕81号

马尔康市人民政府，州政府有关部门、有关单位：

协调领导小组办公室设在马尔康市政府，由窦孝解同志兼任办公室主任，李绍友同志兼任办公室副主任，负责处理日常事务。

二、工作职责

（一）加强城市规划管理，统筹协调城市总体规划、控制性详细规划、重要地块城市设计的编制、审查、报批工作，高标准推进马尔康市城市规划。

（二）统筹协调推进市政基础设施建设和城区河道治理，协调推进新区开发和旧城改造项目建设，拓展城市空间，完善城市功能，高水平建设马尔康市。

（三）统筹州、市两级力量，增强项目建设过程中规划的统一性、强制性和工作的协调性、有效性，协调推进城市建设。

（四）统筹城市建设项目资金争取，协调项目用地审批和重大项目环保、林地审批、征地拆迁、补偿安置等事宜，保障城市建设各要素需求。

（五）统筹城市建设重大招商项目策划及推介活动，研究制定重大招商项目投资优惠政策，协调解决项目供地等问题。

（六）协调解决城市管理综合执法体制改革中的困难和问题，构建节约、高效的城市综合执法体制，强化城市执法队伍建设和经费保障，提升城市管理运营水平。
