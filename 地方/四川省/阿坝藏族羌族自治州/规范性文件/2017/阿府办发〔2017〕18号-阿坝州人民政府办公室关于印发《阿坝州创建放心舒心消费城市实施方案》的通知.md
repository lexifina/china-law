# 阿坝州人民政府办公室关于印发《阿坝州创建放心舒心消费城市实施方案》的通知

阿坝州人民政府办公室

关于印发《阿坝州创建放心舒心消费城市

实施方案》的通知

阿府办发〔2017〕18号

各县（市）人民政府，州政府各部门、各直属机构，卧龙特别行政区，有关单位：

《阿坝州创建放心舒心消费城市实施方案》已经十二届州人民政府第5次常务会议审议同意，现印发给你们，请认真组织实施。

阿坝州人民政府办公室

2017年6月15日

阿坝州创建放心舒心消费城市实施方案

为着力改善消费环境，提升产品和服务质量，释放消费潜力，促进经济发展，按照全省第二批放心舒心消费城市创建工作部署，州政府决定正式启动“放心舒心消费城市”创建工作，现结合实际，制定本方案。

一、指导思想

以党的十八大和十八届三中、四中、五中、六中全会精神为指导，深入贯彻落实习近平总书记系列重要讲话精神，紧扣“诚信你我、净土阿坝”主题，坚持消费者至上，以全域旅游为切入点，以旅游消费、绿色消费、电商消费、诚信建设为重点，以培育消费热点、优化消费环境、构建维权体系为支撑，充分发挥政府主导作用，引领市场主体和社会公众积极参与，形成“政府主导、企业主体、行业自律、部门联动、群众参与、社会监督”六位一体的共治格局，有力推进“三区一中心”、全面小康和美丽阿坝建设。

二、基本原则

（一）坚持民生为本、发展为要。将消费者满意作为创建的首要目标，激发消费在拉动我州经济增长中的内生动力，促进经济发展、社会和谐。

（二）坚持政府主导、齐抓共建。突出政府主导，坚持属地管辖与行业管理相结合、部门监管与主体自治相结合的原则，落实主体责任，明确职责任务，齐抓共管抓好创建。

（三）坚持因地制宜、科学定位。突出地方特点和资源优势，科学谋划，分类推进，提高创建成效。

（四）坚持标本兼治、注重实效。以薄弱环节为突破口，坚持问题导向，聚焦重点领域，注重源头治理，加大执法力度，创新监管方式，形成常态机制。

三、创建目标

用5年时间，以共建信用体系为统领，以“互联网+”建设为支撑，着力抓好市场主体诚信体系、市场监管执法体系、消费维权共治体系建设，有效保障商品和服务质量，有效保障消费者合法权益，提高消费环境安全度，提高经营者诚信度，提高消费者满意度，提高消费过程体验舒心度。

四、工作任务

（一）立足品牌打造，激发主体活力。

1.做优旅游品牌。围绕全面建成旅游经济强州和川西高原藏羌文化及生态国际旅游目的地等目标，充分发挥资源和区位优势，深度挖掘旅游禀赋，强化旅游软硬环境建设，大力推进旅游产业转型升级和全域旅游建设，深入推进“三态”融合发展和“三微”联动建设，突出特色引领，强化品牌打造，优化产品供给，提升旅游品质，提高旅游舒适度，做优阿坝旅游品牌。

牵头单位：州旅发委。

责任单位：各县(市)人民政府、州发展改革委、州商务局、九寨沟管理局、黄龙管理局、四姑娘山管理局、达古冰山管理局。

2.培育绿色消费。发挥我州得天独厚的资源优势，拓宽绿色领域、发展绿色产品、提升绿色品质、打造绿色产业，加快全州农畜产品质量追溯体系建设，积极申报“三品一标”，做优做强“净土阿坝”区域品牌。加强农畜产品质量安全监督管理，引导农牧业产业结构调整和改善产品品质，确保“菜篮子”安全。

牵头单位：州农牧局。

责任单位：各县(市)人民政府、州林业局、州商务局、州食品药品监管局、州工商局、州质监局。

3.助推电商发展。深入实施“互联网+”“旅游+”发展行动。推进“电子商务进农村”“电子商务聚集区”等建设，壮大电商规模。加快建设旅游电商特色产品体验店，加强商贸促销推广，力争实现社会消费品零售总额逐年增长10%左右。

牵头单位：州商务局。

责任单位：各县(市)人民政府、州旅发委、州工商局。

（二）立足平台打造，构建诚信体系。

4.打造信用平台。即打造“四个一”，建立“一中心一网一码一平台”。“一中心”：建立阿坝州市场主体信用信息交换中心。挖掘市场主体数据，实现旅游、公安、食品药品、工商等部门数据共享，互联互通；“一网”：建立阿坝州市场主体信用信息公示系统。建立信息公示制度、跨部门联动响应和失信惩戒机制，对市场主体实行协同监管，联合惩戒，实现“一处违法、处处受限”；“一码”：建立消费市场主体信用二维码扫描查询维权系统。让消费者通过手机扫描经营场所展示的信用二维码，快速查询经营主体登记信息、信用信息、监管信息和经营信息，通过快捷投诉通道进行快速维权;“一平台”：建立一个微信公众维权平台。引导消费者通过扫描商家二维码的方式进入消费维权平台，了解经营主体情况，快速解决消费纠纷，保障合法权益，拓宽维权途径。通过打造“四个一”，实现市场主体信用信息、部门执法监管动态、消费维权情况等数据有效对接和互联共享，共建诚信信用体系，推进诚信阿坝建设。

牵头单位：州工商局。

责任单位：各县(市)人民政府、州发展改革委、州旅发委、州公安局、州城乡建设住房局、州农牧局、州文广新局、州卫计委、州食品药品监管局、州质监局、州政府金融办、人行阿坝州中心支行、阿坝银监分局、九寨沟管理局、黄龙管理局、四姑娘山管理局、达古冰山管理局。

5.加强诚信教育。加强市场主体诚信经营教育，搭建诚信经营、守法经营、法律法规培训平台，分区域、分行业、分层次举办市场主体培训，指导行业组织加强自律建设，提高“自我约束、自我规范、自我管理”能力，增强市场主体诚信守法意识。

牵头单位：州工商局。

责任单位：各县(市)人民政府、州旅发委、州个私协会、州消委会。

6.实行信用约束。树立信用监管理念，从主要依靠传统行政监管手段向注重运用信息公示、信息共享、信息约束等市场主体信用监管手段转变，制定《阿坝州旅游不良信息公示制度》《阿坝州旅游行业失信惩戒制度》《阿坝州旅游信用信息公示制度》等信用约束制度，构建市场主体信用监管新机制。

牵头单位：州工商局、州旅发委。

责任单位：各县(市)人民政府、州发展改革委、州公安局、州城乡建设住房局、州农牧局、州文广新局、州卫计委、州食品药品监管局、州质监局、州政府金融办、人行阿坝州中心支行、阿坝银监分局、九寨沟管理局、黄龙管理局、四姑娘山管理局、达古冰山管理局。

（三）立足监管职能，构建执法体系。

7.强化旅游市场监管。强化旅游市场综合治理，规范旅游市场秩序，优化旅游消费环境。加强旅行社、导游、演艺团体、涉旅商场商店等重点领域管理，强化旅游从业人员管理，实行旅游市场主体星级评价管理，建立健全旅游市场综合监管机制，抓好《阿坝州旅游市场综合监管实施意见》的落实。完善旅游市场综合监管整治、执法检查、联合巡查、联合办案、联合督查、联席会议等制度，提升依法治旅兴旅水平。

牵头单位：州旅发委。

责任单位：各县(市)人民政府、州发展改革委、州交通运输局、州公安局、州文广新局、州卫计委、州食品药品监管局、州工商局、州质监局、州政府法制办、人行阿坝州中心支行、九寨沟管理局、黄龙管理局、四姑娘山管理局、达古冰山管理局。

8.保障食品药品消费安全。加强对生产、加工、销售和餐饮服务环节食品安全监管，加强药品、医疗器械、保健食品、化妆品等在研制、生产、流通、使用方面的安全监管。深化“食品安全示范县”创建工作，发挥示范引领作用，以点带面，辐射带动全州提高食品安全保障水平。

牵头单位：州食品药品监管局。

责任单位：各县(市)人民政府、州教育局、州环境保护局、州农牧局、州林业局、州工商局、州质监局、九寨沟管理局、黄龙管理局、四姑娘山管理局、达古冰山管理局。

9.强化商品质量监管。开展商品质量和服务质量监管，加大涉旅商品、食品药品、农资、农畜产品、家用电器、服装鞋帽、建材及装饰装修材料等重点商品抽查检验力度，严厉打击制售假冒伪劣商品等质量违法行为，依法公布商品质量安全信息。

牵头单位：州工商局。

责任单位：各县(市)人民政府、州农牧局、州商务局、州食品药品监管局、州质监局。

10.强化产品和特种设备质量安全监管。强化生产领域重点产品质量监管，加强电梯、锅炉、防爆电器、客运架空索道等特种设备质量安全监管。开展计量器具周期检定等专项监督检查，加强计量社会监督，不断拓宽计量监督渠道。

牵头单位：州质监局。

责任单位：各县(市)人民政府、州旅发委、州环境保护局、州安全监管局、州工商局、黄龙管理局、达古冰山管理局。

11.强化价格监管。加强对国家、省、州列名管理的商品、服务价格监管,加强对实行市场调节价的商品、服务价格监督检查，引导大型涉旅商场、商店等以醒目的方式定期公布重点商品与全省其他地区的同期价格，查处价格欺诈等违法行为。

牵头单位：州发展改革委。

责任单位：各县(市)人民政府、州工商局、州消委会。

12.治理虚假广告。坚持诚信宣传导向，加强对误导消费和虚假宣传等侵害消费者合法权益的整治力度。强化广告监管执法，整顿广告市场秩序，严厉查处食品、药品、保健食品、医疗、医疗器械、化妆品、房产等虚假违法广告。

牵头单位：州工商局。

责任单位：各县(市)人民政府、州发展改革委、州城乡建设住房局、州文广新局、州卫计委、州旅发委、州食品药品监管局、州质监局。

13.强化文化消费安全监管。加强公共文化服务体系建设，组织和引导公共文化产品生产、推广和普及工作，监管广播、影视、新闻出版等文化市场，加大文化市场综合执法工作力度。

牵头单位：州文广新局。

责任单位：各县(市)人民政府、州公安局、州工商局、阿坝日报社、州广播电视台。

14.强化商贸流通监管。加强租赁、直销、二手车交易和旧货流通等行业监管，建立健全生活必需品市场供应应急管理、重要消费品储备（肉类、食糖、小包装食品等）管理等机制，加强宾馆酒店、农（牧、藏、羌）家乐、居民服务等商贸服务行业管理，打击侵犯知识产权、商业欺诈等行为。

牵头单位：州商务局。

责任单位：各县(市)人民政府、州科技知识产权局、州公安局、州旅发委、州食品药品监管局、州工商局。

15.强化治安交通管理。加大对经济领域犯罪行为的打击力度。进一步完善交通事故快速处理机制，缩短交通事故处置时间，避免交通事故造成的道路拥堵。

牵头单位：州公安局。

责任单位：各县(市)人民政府。

16.强化住房消费管理。监督执行房屋交易和产权管理、房屋面积与测绘管理、物业管理，加强建筑工程质量安全监管。

牵头单位：州城乡建设住房局。

责任单位：各县(市)人民政府、州工商局、州质监局。

17.强化税务发票管理。加强消费环节商品和服务税务发票管理，引导消费者主动索取发票，督促经营者开具发票，严厉打击不按规定开具发票等违法行为。

牵头单位：州国税局、州地税局。

责任单位：各县(市)人民政府、州公安局。

（四）立足行业规范，提升服务品质。

18.提升交通营运能力。提升交通运输服务质量，统筹推进城乡客运一体化。加强多种运输方式衔接，提升交通运输便捷化、网络化以及多样化、差异化服务水平，加快信息化建设，提升旅游运输服务能力。

牵头单位：州交通运输局。

责任单位：各县(市)人民政府、州公安局、九寨沟管理局、黄龙管理局、四姑娘山管理局、达古冰山管理局。

19.提升金融服务品质。优化金融服务措施，建立健全金融消费者权益保护工作机制，完善金融消费者投诉处理运行工作机制，促进工作的标准化和流程化。深化金融消费者风险责任意识教育和金融知识“六进”活动，有效提升全州群众金融消费素养和自我维权意识。

牵头单位：人行阿坝州中心支行。

责任单位：各县(市)人民政府、州政府金融办、阿坝银监分局、州消委会。

20.提高通信服务质量。推进光纤干线通道建设和宽带扩容工程，实现交通沿线网络全覆盖。深化通信基础设施共建共享，规范通信行业经营行为，完善通信服务措施，提高通信服务质量，保障消费者合法权益。

牵头单位：州经济和信息化委。

责任单位：各县(市)人民政府、州通信发展办、州消委会。

21.提高医疗卫生服务水平。加强医疗行业纠风工作，整顿和规范医疗服务市场秩序，促进基本公共卫生服务均等化。

牵头单位：州卫计委。

责任单位：各县(市)人民政府、州食品药品监管局、州工商局。

22.规范快递服务行为。完善快递业务监督管理体系，监督快递企业遵守快递服务法规，优化服务措施，规范快递经营行为，加强快递企业服务质量的监管，整治快递企业不良现象，查处快递企业违法违规经营行为，发布快递市场监管信息。

牵头单位：州邮政管理局。

责任单位：各县(市)人民政府、州公安局、州工商局、州消委会。

（五）立足机制创新，构建维权体系。

23.推进共治体系建设。一是优化维权平台建设，加强工商12315、食药监12331、质监12365、价格12358、旅游96927、税务12366、金融12363等消费维权热线融合互动，完善网上投诉绿色通道。二是推行三方视频调解，在重点涉旅商场商店、大型商场商店建立远程视频调解系统，实现经营者、消费者、调解组织三方在线调解全覆盖。三是建立消费纠纷经营者首问、先行和解、先行赔付制度，加强先行和解、现场调解、三方在线调解、消费争议调解司法确认等方式的有机融合，监管部门实时跟踪维权动态或必要时介入，逐步提升我州消费者满意度指数。四是实行消费预警，依法发布消费提示、消费警示，引入“诉转案”机制，运用信息化手段适时向社会公示投诉处理结果、行政处罚信息，强化社会监督。五是完善消费维权快速反应、行政执法与司法衔接机制。

五、工作步骤

采取先易后难、典型示范、逐步推开、由点向面拓展的方法，分阶段、分步骤、稳步推进创建工作。

第一阶段（2017年3月—12月）：示范创建。成立阿坝州创建放心舒心消费城市工作领导小组，制定《阿坝州放心舒心消费城市创建工作实施方案》和《阿坝州2017年放心舒心消费城市创建工作计划》。在特色街区、景区、市场、商场、企业、精品村寨等开展示范创建工作。建立阿坝放心舒心消费微信公众平台，设置“一店一码”（即一个经营主体一个微信二维码），力争示范点市场主体“一店一码”全覆盖。开展食品安全示范县、农畜产品质量追溯体系、商品质量消费安全创建工作。

第二阶段（2018年1月—2019年12月）：分类创建。一是品牌创建,在重点企业、特色街区、精品村寨、大型商场、特色市场开展品牌创建工作，发挥品牌效应。二是景区创建,在九寨沟、黄龙、四姑娘山、达古冰山等开展景区创建工作，提升旅游品质。三是行业创建,在旅游、住宿、餐饮、服务、金融、通讯、快递业等开展行业创建工作，促进行业发展。

第三阶段（2020年1月—2022年3月）：全面创建。认真总结前期创建工作，提炼创建经验，巩固创建成果，完善创建措施，拓展创建领域，形成常态运行机制。

六、保障措施

（一）加强组织领导。成立阿坝州创建放心舒心消费城市工作领导小组，负责组织、协调、检查、考核、宣传以及制定工作计划、创建标准、考核办法等工作;领导小组办公室设在州工商局，负责日常工作。各县(市)人民政府要高度重视创建工作，加强组织领导，成立相应机构，制定实施细则。各成员单位要各司其职，密切配合，确保各项目标任务落到实处。

（二）加大资金投入。将创建活动纳入我州经济社会发展规划，州、县(市)人民政府要将创建工作经费纳入同级财政预算予以保障。

（三）加大宣传力度。新闻媒体、成员单位要加大对创建活动的宣传，积极动员企业、行业和消费者主动参与创建活动，营造良好舆论氛围。

（四）严格督查考核。将开展放心舒心消费城市创建工作纳入州政府目标绩效管理。强化任务分解、指导督查、考核评价和追踪问责。州委州政府督查室、州工商局等部门要定期督查创建工作，对监管不力、处置不当、失职渎职的，要严肃问责。
