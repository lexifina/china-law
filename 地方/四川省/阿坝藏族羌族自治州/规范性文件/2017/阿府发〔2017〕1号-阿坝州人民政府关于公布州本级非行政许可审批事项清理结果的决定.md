# 阿坝州人民政府关于公布州本级非行政许可审批事项清理结果的决定

阿坝州人民政府

关于公布州本级非行政许可审批事项清理结果的决定

阿府发〔2017〕1号

各县（市）人民政府，州政府各部门、各直属机构，卧龙特别行政区，有关单位：

按照《四川省人民政府关于取消非行政许可审批事项的决定》（川府发〔2015〕51号）要求，州政府组织有关部门对州本级非行政许可审批事项进行了清理，决定取消非行政许可审批事项6项，将2项非行政权力审批事项转变为政府内部审批事项。

各县（市）、有关部门要认真做好取消事项的落实和衔接工作，不得以任何形式实施变相审批。调整为政府内部审批的事项，不得面向公民、法人和其他社会组织实施审批；要严格规范审批行为，严格限制自由裁量权，优化审批流程，提高办事效率。其余行政权力事项应严格按国家安排做好相应调整。

附件：1.取消的州本级非行政许可审批事项目录（共6项）

2.调整为政府内部审批事项目录（共2项）

阿坝州人民政府
