# 阿坝州人民政府关于命名2016年度民族团结进步创建示范单位的决定

阿坝州人民政府

关于命名2016年度民族团结进步创建示范单位的决定

阿府发〔2017〕2号

各县（市）人民政府，州政府各部门、各直属机构，卧龙特别行政区，有关单位：

2016年，在州委的坚强领导下，全州民族团结进步示范创建工作紧紧围绕各民族“共同团结奋斗，共同繁荣发展”主题，大力弘扬民族团结进步主旋律，深入开展民族团结进步创建活动“七进”，营造了民族和睦、社会和谐、安定团结的良好氛围，促进了社会经济又好又快发展。

为充分发挥示范表率作用，深化民族团结进步创建活动，州人民政府决定对2016年度73个民族团结进步创建示范单位予以命名。

希望被命名的示范单位珍惜荣誉、再接再励，乘势而上、再创佳绩，为我州奋力建设“三区一中心”、全面建成小康社会目标而努力奋斗。
