# 阿坝州人民政府办公室关于印发《阿坝州2018年食品安全重点工作安排》的通知

阿坝州人民政府办公室

关于印发《阿坝州2018年食品安全重点工作安排》的通知

阿府办发〔2018〕19号

各县（市）人民政府，州政府各部门、各直属机构，卧龙特别行政区，有关单位：

《阿坝州2018年食品安全重点工作安排》已经州政府领导同意，现印发给你们，请抓好贯彻落实。

阿坝州人民政府办公室

2018年6月25日

阿坝州2018年食品安全重点工作安排

2018年，全州食品安全工作的指导思想是：以习近平新时代中国特色社会主义思想为指导，认真落实习近平总书记关于“实施食品安全战略，让人民吃得放心”和“四个最严”的要求，以食品安全示范创建为抓手，强化党政同责、属地管理，有效解决突出问题，有效防控风险隐患，确保不发生区域性、系统性重大食品安全事故，切实保障人民群众“舌尖上的安全”。

一、深化“双安双创”

加强督促指导，巩固提升马尔康市省级食品安全示范县创建成果，指导汶川县、松潘县省级食品安全示范县创建工作，组织开展食品安全示范乡镇创建（州食安办负责）。打造“一园四区”绿色防控示范基地，创建出口农产品质量安全示范区。打造黑水县直供港澳蔬菜质量安全示范区5000亩，完成出口港澳备案4000亩。建设国家级绿色食品标准化原料基地2个8.6万亩，省级有机蔬菜标准化示范基地300亩，新申报国家绿色食品蔬菜标准化原料基地2万亩（州农牧局牵头，出入境检验检疫职能管理部门配合）。继续推进“放心肉菜示范超市”创建（州食品药品监管局负责）。扎实开展国家“中国好粮油”行动示范县试点工作（州发展改革委负责）。指导各县（市）政府做好国家级出口食品农产品质量安全示范区创建和复查（出入境检验检疫职能管理部门牵头，州农牧局、州商务局配合）。

二、强化风险治理

制定实施食品安全风险监测方案，开展食源性疾病流行病学调查，推进食源性疾病溯源体系建设。组织开展风险交流，及时发布预警信息（州卫计委负责）。保护农业种养殖环境。深入推进农村水源治理工程，加强水源污染治理。进一步加强土壤污染综合防治，深入开展污染地块安全利用行动，推进耕地质量保护与提升，落实加强粮食重金属污染治理的各项措施（州环境保护局牵头，州财政局、州城乡建设住房局、州水务局、州农牧局配合）。加强种养环节源头治理，健全农产品质量安全监测体系，食品农产品监测总体合格率稳定在97%以上、监督抽检不合格产品处置率达100%（州农牧局负责）。实施粮食质量安全风险监测工作（州发展改革委负责）。加强进口粮食质量安全风险防控（出入境检验检疫职能管理部门牵头，州发展改革委配合）。开展进出口食品安全风险监测工作（出入境检验检疫职能管理部门牵头，州食品药品监管局配合）。组织开展“食品安全宣传周”活动，治理食品安全谣言，做好食品安全舆情风险防范（州食品药品监管局牵头，州级相关部门配合）。强化风险联合研判机制，推动事前预防、事中监控、事后处置有效衔接（州食品药品监管局牵头，州卫计委配合）。组织开展食品安全应急演练，提高食品安全突发事件应对处置能力（州食品药品监管局牵头，州卫计委配合）。

三、加强过程管控

贯彻落实新修订《食用农产品市场销售质量安全监督管理办法》，出台《建立食用农产品产地准出和市场准入衔接机制实施意见》，不断加强食用农产品质量安全监管（州农牧局、州食品药品监管局负责）。鼓励企业实施HACCP（危害分析和关键控制点）管理体系，开展风险分级监管，加大飞行检查力度，严格督促企业落实主体责任（州食品药品监管局负责）。大力实施餐饮业质量提升工程，打造新型餐饮服务食品供应链，鼓励“农餐对接”，促进原料统一加工、集中配送，推动品牌创建（州食品药品监管局牵头，州农牧局、州商务局、州质监局配合）。稳步推进“明厨亮灶”建设。指导和推动全州80%餐饮服务单位完成“明厨亮灶”建设，积极探索“互联网+明厨亮灶”的新模式，提高公众参与度和社会公信力，形成社会共治新格局（州食品药品监管局负责）。继续做好重大活动餐饮服务保障工作（州食品药品监管局牵头，州级相关部门配合）。加大食品安全检验检测力度。坚持问题导向，通过日常监督抽检，及时有效发现问题食品及食品相关产品（州食品药品监管局、州农牧局、州质监局负责）。出台《阿坝州粮食质量安全监管实施办法》，把好粮食收购、储存、出库关口，严防不合格粮食流入口粮市场（州发展改革委牵头，州农牧局配合）。落实检验检疫监管，保障进出口食品安全（出入境检验检疫职能管理部门负责）。推进餐厨废弃物分类利用和集中处置场所建设（州城乡建设住房局牵头，州发展改革委、州经济和信息化委、州农牧局配合）。

四、突出整治重点

深入开展农资打假暨农产品质量安全专项整治，推进生猪屠宰资格清理（州农牧局负责）。组织开展学校食品安全专项整治工作，重点整治无证供餐等违法违规行为，实现学校食堂食品安全量化分级管理全覆盖，食品安全量化分级良好以上的学校（含幼儿园）食堂达到60%。加强对以学生为主要供餐对象的集体用餐配送单位食品安全监管（州教育局、州食品药品监管局负责）。开展校园及周边“五毛食品”整治，坚决取缔无证生产“五毛食品”的“黑窝点”“黑作坊”（州教育局、州食品药品监管局负责）。加强旅游景区食品安全监管。开展旅游景区食品安全专项检查，全面整治旅游景区及沿线食品安全问题。加大节假日期间、“黄金周”、旅游旺季等重点时期监督检查力度，重点加强对旅游团餐接待单位餐饮食品安全监管 (州食品药品监管局、州旅发委负责)。做好高速公路沿线服务区、单位食堂等集体就餐区域食品安全监管工作（州食品药品监管局牵头，州级相关单位配合）。

进一步加强网络订餐食品安全监管，加大对网络订餐违法行为的打击力度，开展网络订餐第三方平台行政约谈，督促第三方平台严把食品安全关（州食品药品监管局负责）。实施农村食品安全治理工程，加强农村群体聚餐食品安全管理（州食品药品监管局牵头，州农牧局、州工商局配合）。继续开展“地沟油”专项整治，防止反弹回潮（州食安办牵头，州级相关部门配合）。开展小作坊专项整治，开展小作坊、小餐饮食品安全监管调研工作，开展保健食品欺诈和虚假宣传专项整治，加强婴幼儿配方乳粉、食盐、茶叶、白酒、畜禽水产品等重点食品监管，加强节假日、汛期、“两会”等重要时段食品安全监管（州食品药品监管局牵头，州级相关部门配合）。

五、加大执法力度

保持打击食品安全违法犯罪行为的高压态势，严厉查处各类食品违法犯罪案件，重点查办群众高度关注的案件。（州公安局牵头，州农牧局、州食品药品监管局、州质监局配合）。重拳整治非法添加、超范围超限量使用添加剂、滥用农兽药等农业投入品、地沟油、“白板肉”等违法行为（州农牧局、州食品药品监管局负责）。加大对网上销售假劣食品的检查力度，严厉查处互联网违法销售食品行为（州食品药品监管局负责）。加大高风险进出口食品查验力度（出入境检验检疫职能管理部门负责）。坚决依法打击食品走私行为（州公安局负责）。加大对食品虚假广告、商标侵权、不正当竞争行为的查处力度，切实保护消费者合法权益（州工商局负责）。落实处罚到人，推动落实违法犯罪人员行业禁入（州食品药品监管局负责）。建立跨部门、跨区域的案件协查、监管衔接等协调联动机制，完善行刑衔接机制，加强行政执法与刑事司法的衔接，及时依法审查、办理食品安全涉刑案件，提升打击合力（州委政法委牵头，州公安局、州农牧局、州食品药品监管局、州质监局配合）。

六、夯实监管基础

将基层食品安全纳入社会治安综合治理，实行网格化服务管理（州综治办牵头，州食安办配合）。加强食品加工、流通、餐饮等过程安全控制关键技术研究与应用，开展通用防腐剂潜在风险研究、食源性危害检测等技术攻关，加强科技成果转化试点示范，运用大数据、物联网技术开展特色食品追溯关键技术研究与运用（州科技知识产权局负责）。继续开展食品药品监管所标准化建设，力争全州基层所标准化建设验收率达到80%。加快基层快检体系建设，确保县级食品快检车全部投入使用（州食品药品监管局负责）。推进食品工业企业诚信体系建设（州经济和信息化委负责）。加强食用农产品追溯体系建设，指导督促做好国家追溯平台试运行工作（州农牧局负责）。加强食品犯罪侦查队伍建设，配强工作力量，配备必要设备，明确职责分工，提升队伍专业化和职业化水平（州公安局负责）。加强食品安全技术、能力、项目等对外合作交流，学习借鉴先进经验做法，提高治理水平（州食安办负责）。

七、营造共治氛围

建立健全食品安全诚信体系。出台《食品安全诚信管理制度》，将食品生产经营相关法人和非法人组织、个人的食品安全信用状况纳入社会诚信体系范围（州食安办牵头，州发展改革委、州农牧局、州食品药品监管局、州工商局配合）。以“食品安全宣传周”等主题宣传活动为载体，开展多种形式的食品安全科普宣教活动，普及和提升社会公众食品安全认知水平。健全食品安全信息发布制度，使公众获知时效性强、内容丰富全面的食品安全信息，充分了解政府做好食品安全工作的决心和监管成效，食品安全消费行为得到有效指导和引导。充分发挥人大代表、政协委员、专家学者、新闻媒体、行业协会代表等各方力量作用，鼓励群众参与监督，营造社会共治良好氛围（州委宣传部、州委政法委、州食品药品监管局负责）。畅通食品安全投诉渠道，开通网络投诉平台，加大“12331”投诉举报电话宣传力度，全面推行投诉举报奖励制度和举报人保护制度，鼓励食品生产经营企业员工举报违法行为，依法维护消费者合法权益，投诉举报核查回复率达100%（州食品药品监管局负责）。
