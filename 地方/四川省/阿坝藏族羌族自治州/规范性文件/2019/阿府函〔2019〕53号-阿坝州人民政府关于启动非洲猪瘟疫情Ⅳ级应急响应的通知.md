# 阿坝州人民政府关于启动非洲猪瘟疫情Ⅳ级应急响应的通知

阿坝州人民政府

关于启动非洲猪瘟疫情Ⅳ级应急响应的通知

阿府函〔2019〕53号

各县（市）人民政府、州非洲猪瘟等动植物疫病防控指挥部各成员单位：

5月20日，经省动物疫病预防控制中心实验室对若尔盖县降扎乡格吉村、热陇村发生疫病的生猪采集的样品进行复核，判定为非洲猪瘟确诊疫情。根据《农业农村部关于印发<非洲猪瘟疫情应急实施方案（2019年版）>的通知》（农牧发〔2019〕5号）和《阿坝州人民政府办公室关于印发〈阿坝州非洲猪瘟疫病防控应急预案〉的通知》（阿府办函〔2018〕90号）要求，我州从即日起启动非洲猪瘟疫情Ⅳ级应急响应，启动应急指挥机构工作，实施非洲猪瘟防控工作日报告制度，组织开展监测排查，对发现的疫情及时采取应急处置措施。各县（市）人民政府、州非洲猪瘟等动植物疫病防控指挥部各成员单位要按照职责分工共同做好非洲猪瘟疫情防控工作。

阿坝州人民政府

2019年5月21日
