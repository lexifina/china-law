# 阿坝州人民政府关于对四川省第十三届人民代表大会第二次会议第347号建议办理情况的函

阿坝州人民政府

关于对四川省第十三届人民代表大会第二次会议

第347号建议办理情况的函

阿府函〔2019〕66号

马俊华代表：

现将您在四川省第十三届人民代表大会第二次会议期间提出的《关于支持松潘县申报“国家级历史文化名城”的建议》（第347号）答复如下。

近年来，阿坝州人民政府高度重视历史文化名城保护开发，不断加大项目申报、资金争取、政策支持力度，精心打造民族地区历史文化名城保护开发样板。

一、松潘县基本情况

松潘县古称“松州”，具有2000多年历史。明朝洪武时期先后设立“松州卫”“潘州卫”并“松潘卫”，松潘由此而得名。自古以来，松潘就是川、甘、青三省商贸集散地，是内地与西羌吐蕃茶马互市的集散地，有“高原古城”“川西重镇”“边陲重镇”“战略要冲”之称。

松潘县文化底蕴深厚，有岷江源的江源文化，有藏羌回汉等多元的民族文化，有厚重的红色文化；有国家级文物保护单位4处、省级文物保护单位3处、州级文物保护单位3处；有羌族多声部民歌、川西藏族山歌等国家级非遗项目5个，回族花灯舞等省级非遗项目10个。1991年，松潘被评为省级历史文化名城。

此外，松潘县旅游资源富集，黄龙风景名胜区享誉国内外；有现代建筑、藏式建筑、羌式建筑、回式建筑、宗教建筑等多元的建筑风貌，多元民族建筑技术与艺术令人神往。

二、申报工作推进情况

（一）强化领导。州、县人民政府高度重视，将松潘县申报国家级历史文化名城纳入重要议事日程，整合城乡建设、文化旅游等部门力量，组建了专项工作组。同时，对应申报程序、标准、要素等，制定工作计划，细化工作举措，明确时间节点、责任部门及责任人，确保申报工作有力、有序、有效推进。

（二）夯实基础。一是投入2.7亿元，实施项目20个，重点对松州古城基础设施进行提档升级，对城内建筑进行风貌改造。同时，新建了“松赞干布、文成公主雕像”等多处景观。二是投入5亿元，建成了松潘新城行政事业单位办公楼、学校、医院及基础设施等40个灾后重建项目。三是加大文物保护力度，重点对古城墙等历史建筑以及回族花灯舞、松州小调、松潘土琵琶弹唱等地方特色文化进行了抢救性保护。四是按照国家《历史文化名城名镇名村保护条例》的相关规定（即：“申报的历史文化名城保护范围内应当有2个以上的历史文化街区”），初步划定松潘县中江、岷山、苍坪等3条历史文化街区，为申报工作打好基础。

（三）精心规划。聘请专业规划编制机构编制了《松潘历史文化名城保护规划（2017—2035）》，对历史文化、历史城区、历史建筑、文物保护单位、民族传统文化、红军长征文化等保护开发进行了系统规划，着力构建完整的（包括有形和无形历史文化遗产及其展示）松潘历史文化名城保护体系。目前，正在组织专家对该规划进行评审。待专家评审通过后，将按程序启动报批工作。

（四）积极汇报。积极与住房和城乡建设厅、文化旅游厅、省文物保护局等省级相关部门密切沟通，联合向国家文化旅游部等主管部门汇报、争取，力争得到支持和帮助，确保申报工作圆满完成。

三、下一步打算

州人民政府将进一步加强与住房和城乡建设厅、文化旅游厅、省文物保护局等省级相关部门的沟通衔接，加快推进《松潘历史文化名城保护规划（2017—2035）》的修编和报批。同时，积极争取支持，筹措资金开展历史文化建筑修缮、历史街区打造、历史文物保护整理等工作，进一步提升松潘县城市品位，为迎接国家和省审查评估打好基础，全力争取申报成功。
