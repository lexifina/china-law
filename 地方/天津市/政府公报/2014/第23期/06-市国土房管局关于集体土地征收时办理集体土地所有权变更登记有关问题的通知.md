# 市国土房管局关于集体土地征收时办理集体土地所有权变更登记有关问题的通知

津国土房地权〔2014〕232号

各区、县国土分局，滨海新区规划国土局，有关处室、有关直属单位：

根据《天津市行政规范性文件管理规定》，《关于规范房地登记有关问题的通知》(津国土房地权〔2009〕327号)、《关于集体土地征收时办理集体土地所有权变更登记有关问题的通知》(津国土房地权〔2009〕486号)有效期即将届满，现将修订后的《关于集体土地征收时办理集体土地所有权变更登记有关问题的通知》重新印发给你们，请遵照执行。

天津市国土资源和房屋管理局

2014年10月28日

关于集体土地征收时办理集体土地所有权

变更登记有关问题的通知

为进一步规范集体土地所有权登记行为，实现集体土地征收与集体土地所有权变更的有效衔接，根据《中华人民共和国物权法》、《天津市土地管理条例》、《土地登记办法》(国土资源部第40号令)的规定，以及《关于依法加快集体土地所有权登记发证工作的通知》(国土资发〔2001〕359号)要求，现就集体土地征收时办理集体土地所有权变更登记有关事项通知如下：

一、各区县人民政府在实施集体土地征收时应由区县国土资源部门收集拟征收土地的《集体土地所有证》。对于未核发《集体土地所有证》的，应核发《集体土地所有证》后，方可申请办理土地征收手续。

各区县国土资源部门将征地文件组卷上报市国土房管局审批时，除提供《市国土房管局关于修订天津市征收土地工作程序的通知》(津国土房资〔2013〕376号)规定的要件外，还应提供《集体土地所有证》。

二、批准集体土地征收前，在《征收土地告知书》中应当明确拟征收土地的《集体土地所有证》记载的土地情况、征地的范围、裁余土地面积等。部分征收的，还应告知集体土地所有权人及时办理所有权变更登记手续。征收土地告知后，集体土地所有权人应填写《征收土地情况确认表》并附拟征收宗地的《宗地图》，就集体土地征收范围等情况进行盖章确认。

进行集体土地征收测绘时，土地测绘机构应一并出具拟征收部分土地及裁余部分土地的《宗地图》等测绘成果，测绘精度应为1：500，出图比例尺可依照《关于印发天津市城镇村庄地籍调查实施细则的通知》(津国土房地权〔2010〕389号)确定。

三、属于按《集体土地所有证》记载范围部分征收的，批准土地征收后，在《征收土地补偿、安置方案公告》中应告知集体土地所有权人及时领取裁余部分《集体土地所有证》。

四、按《集体土地所有证》记载范围整体征收的，区县国土资源部门应根据《土地登记办法》、《天津市土地登记技术规范》的有关规定，凭征收土地批准文件、原《集体土地所有证》、《征收土地情况确认表》以及其他规定文件在产权产籍管理系统上按规定直接办理集体土地所有权注销登记；属于按《集体土地所有证》记载范围部分征收的，区县国土资源部门在办理征收部分集体土地所有权注销登记同时，凭上述要件办理裁余部分集体土地所有权变更登记。集体土地所有权人在领取裁余部分《集体土地所有证》时应提供所有权人身份证明材料，委托他人办理的，还应提供委托书及被委托人身份证明。但土地征收时已收取所有权人身份证明的，不再重复收取。

办理上述登记时，《征收土地情况确认表》作为集体土地所有权变更登记申请书，集体土地所有权人盖章确认的宗地图作为集体土地所有权变更登记指界盖章成果。上述文件在办理土地登记时审核原件，留存复印件并加盖“与原件核对无误”专用章；界址表直接由区县国土资源部门根据集体土地所有权人盖章确认的已征收土地宗地图及《征收土地情况确认表》填写，不再重复指界盖章；《集体土地所有证》由国土资源部门留存原件。上述文件在土地征收批准后，土地征收实施部门应当及时提供给土地登记部门。

五、对于集体土地所有权人拒不在《征收土地情况确认表》中盖章确认的，区县国土资源部门在按《市国土房管局关于修订天津市征收土地工作程序的通知》的规定履行相关程序后，根据征收土地批准文件、原《集体土地所有证》、《征收土地情况确认表》及土地征收时经公证的取证结果等文件办理集体土地所有权变更登记。

六、集体土地征收时未办理集体土地所有权变更登记的，不得办理被征收土地的土地供应手续。

七、已完成集体土地征收但未及时办理集体土地所有权变更登记的，区县国土资源部门应集中进行清理。未供地的，应在办理集体土地所有权变更登记后实施供地；已供地的，应在办理集体土地所有权变更登记后，再为取得国有土地的使用人办理国有土地使用权初始登记。

八、本通知自2014年11月1日起施行，有效期5年。
