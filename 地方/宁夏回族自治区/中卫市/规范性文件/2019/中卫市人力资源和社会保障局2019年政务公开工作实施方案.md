# 中卫市人力资源和社会保障局2019年政务公开工作实施方案

为全面扎实推进市人社局政务公开工作，加大公开力度，加强政策解读，增强公开实效，保障服务对象和人民群众知情权、参与权、表达权和监督权，根据《中卫市2019年政务公开工作要点》的通知》（卫政公开服发〔2019〕1号）要求，结合工作实际，特制定本实施方案：

一、总体要求

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实《中卫市2019年政务公开工作要点》，紧紧围绕市委、市政府中心工作及群众关注关切，以公开明权责、以公开促规范，着力提升政务公开质量，建设人民满意的服务型机关。

二、公开的主要内容及分工

（一）全面落实“五公开”工作机制

1.推进决策公开。凡涉及公共利益和公众权益的重大事项，除涉密外，各单位、科室要主动向社会公布决策草案、决策依据等，通过听证座谈、列席会议、网络征集等多种形式，广泛征集公众意见，并将征集意见的采纳情况要在决策做出前向社会公开反馈。建立企业家参与涉企政策制定机制，听取企业代表和行业协会的意见，增强政策的科学性适用性。我局制定的政策文件，除依法保密的外，要及时通过政务网站、微信、微博等渠道公开发布，推动政策落地落实。（局办公室牵头，局属各单位、各科室负责落实）

2.推进管理公开。结合本单位机构改革和职能优化，主动公开单位主要职责、机构设置及职能。全面推进人社部门权力清单、责任清单公开，根据权责事项取消、下放、承接情况及时进行动态调整。（局办公室、法制科牵头，局属相关单位、科室负责落实）

3.推进执行和结果公开。围绕政府工作报告、发展规划提出的重要事项，特别是国家、区、市部署的重点改革任务、民生举措，推进决策制定、政策执行和落实情况公开。具有行政执法权的单位、科室要认真贯彻执行区、市关于 “双随机、一公开”工作有关文件精神，对照权力清单，对法律法规规章规定的检查事项，及时公开随机抽查结果和查处情况，规范事中事后监管，全面推进“阳光执法”。（局办公室、法制科牵头，局属各单位、各科室负责落实）

4.推进服务公开。围绕“放管服”改革，做好减税降费、“证照分离”改革、政务服务事项公开，在宁夏政务服务网（中卫网上市民大厅）集中公布政务服务清单目录。及时更新审批服务事项，让企业和群众办事更便捷。加快推进社会保险经办大厅和人力资源市场标准化建设，推动线上线下融合，统筹服务资源，统一服务标准，理顺工作机制，强化部门协调，群众和企业必须到现场办理的事项力争“只进一扇门”“最多跑一次”。加强窗口工作人员管理，严肃纪律作风，规范服务行为，切实提高服务效率和质量。（局办公室、法制科牵头，各单位、科室负责落实）

5.推进依申请公开。畅通依申请公开受理渠道，依法保障公众合理的信息需求。进一步规范依申请公开答复工作，严格按照法定时限答复，增强答复内容针对性并明示救济渠道，做到答复形式严谨规范。对公众申请较为集中的政府信息，可以转为主动公开的，应当主动公开。（局办公室牵头，各单位、科室负责落实）

（二）深化重点领域信息公开

6.推进就业创业信息公开。及时发布国家、区、市出台的各项就业创业政策，公布相关补贴申请条件、申领程序、发放结果等信息。公开职业资格目录。推进公共就业服务平台信息化建设，做好“就业援助月”、“春风行动”、“民营企业招聘周”、“高校毕业生就业服务月”等公共就业服务专项活动的宣传，营造公平就业创业环境。（就创局牵头，就业促进科、鉴定中心配合落实）

7.推进社会保险信息公开。及时公开社会保险领域重要政策文件信息，编制发布年度社会保险事业发展情况报告，适时公布阶段性降低社会保险费率的执行情况和实际效果，定期公布参加社会保险情况和社保基金运行情况。（社保局负责落实）

8.推进人事人才信息公开。及时公开人事人才领域重要政策文件信息，主动发布事业单位公开招聘信息。及时发布专业技术人员资格考试、职称评审和重大人才工程实施、人才项目申报等方面信息。（事业单位人事管理科、人力资源科、就业促进科、人事考试培训中心负责落实）

9.推进劳动关系信息公开。主动向社会公开劳动关系、劳动人事争议调解仲裁、劳动保障监察政策措施，适时发布最低工资标准、工资指导线、人工成本变动情况等信息。及时向社会公布重大劳动保障违法案件及查处情况。（劳动保障监察监督局、仲裁院、工资福利科负责落实）

10.做好财政预决算信息公开。按照财政预决算相关要求，做好单位财政预决算、““三公”经费”、采购项目信息、采购结果信息公开。公开内容包括单位职责、机构设置、一般公共预算收支、政府性基金预算收支、机关运行经费等情况。（局办公室、社保局、就创局负责落实）

（三）强化政策解读回应关切

11.对以市人社局名义印发的政策性文件，按照“谁起草、谁解读”的原则，做到政策性文件与解读方案、解读材料同步组织、同步审签、同步部署，提高解读的科学性、权威性、针对性、通俗性。相关政策解读材料应作为规范性文件的附件一同报批，并于局领导签发后3个工作日内挂网发布。年内解读重要政策措施应不少于2次。（局办公室、法制科牵头，各单位、科室负责落实）

12.认真贯彻执行中央、自治区和市委、市政府有关部署要求，切实增强舆情风险防控意识，对减税降费、脱贫攻坚、扫黑除恶、社会保障以及就业创业等群众关心热点，要加强舆情监测、研判、回应，准确把握社会情绪，讲清楚问题成因、解决方案和制约因素等，更好地引导社会预期。落实重大突发事件舆情主体责任，主动与宣传、网信等部门联系沟通，健全完善重大政务舆情信息共享、协同联动、快速反应机制。（局办公室牵头，各单位、科室负责落实）

（四）加强政务公开平台建设

13.推动新媒体平台建设。切实做好网站内容建设和发布审核，把好政治关、政策关、保密关、格式关和文字关。广泛宣传12333微信公众号和12333电话咨询服务平台，进一步扩大影响力和覆盖面。充分发挥政务微信、微博、移动客户端灵活便捷的优势，做好信息发布、政策解读和办事服务工作，进一步增强公开实效，提升服务水平。进一步整合新媒体资源，切实用好管好政务新媒体，明确开办主体责任，健全内容发布审核机制，强化互动和服务功能，切实解决更新慢、“雷人雷语”、无序发声、敷衍了事等问题。（局办公室、社保局、就创局负责落实）

三、工作要求

（一）高度重视，认真组织。各单位、科室要把政务公开工作摆在突出位置，细化工作任务，抓好贯彻落实。

（二）明确责任，提高质量。各牵头科室要严格按照本方案制定的工作职责，落实人员、明确责任，及时报送和上传有关材料，确保各项业务高效衔接、按时按质完成政务公开工作任务。

（三）加强监督，确保成效。局办公室要建立政务公开考核机制，加强对全局政务公开工作的指导和督促检查，确保政务公开工作顺利开展。

中卫市人力资源和社会保障局
