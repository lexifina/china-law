# 关于2019年城乡居民基本养老保险丧葬补助金标准计发的通知

市社会保险事业管理局：

按照自治区组织部、人社厅、财政厅、卫健委《关于2019年城乡居民基本养老保险特殊群体缴费补贴标准及丧葬补助金标准计发有关问题的通知》（宁人社发[2019]48号）文件要求，中卫市（沙坡头区）2018年城乡居民基本养老保险月人均养老金标准为185元，请按照185元/月的标准计发沙坡头区2019年城乡居民基本养老保险丧葬补助金。

中卫市人力资源和社会保障局 中卫市财政局

2019年7月10日
