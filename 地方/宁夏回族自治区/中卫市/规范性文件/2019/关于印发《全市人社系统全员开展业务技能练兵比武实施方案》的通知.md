# 关于印发《全市人社系统全员开展业务技能练兵比武实施方案》的通知

沙坡头区民政和社会保障局，中宁县、海原县人社局，局属各单位、科室：

按照《自治区人力资源和社会保障厅办公室关于在全系统全员开展业务技能练兵比武的通知》（宁人社办发〔2019〕78号）要求，结合工作实际制定《全市人社系统全员开展业务技能练兵比武实施方案》，现予以印发，请认真抓好落实。
