# 关于调整中卫市公共实训基地项目建设领导小组的通知

局属各相关单位、科室、市技工学校：

因原中卫市公共实训基地项目建设领导小组组成人员情况变化，为确保中卫市公共实训基地项目建设顺利推进，提升项目建设管理水平，决定调整项目建设工作领导小组。

组 长：孙尚金 市人力资源和社会保障局局长

副组长：李俊义 市人力资源和社会保障局副局长

耿永杰 市人力资源和社会保障局副局长

万伟中 市人力资源和社会保障局副局长

吴文铭 市职业技术学校副校长

成 员：刘晓燕 市人社局创就科负责人

鲁志成 市劳动保障监察监督局局长

郑 红 市人力资源和社会保障局会计

杜 明 市职业技术学校实训管理中心主任

领导小组下设办公室，万伟中同志兼任办公室主任，成员由刘晓燕、鲁志成、郑红、杜明组成。

领导小组负责对项目的重大事项进行研究部署，定期召开会议研究解决项目建设中的困难和问题，组织对实训楼功能设计进行考察，提出合理化建议，全力推进项目建设，协调上级项目资金政策信息，按工程进度拨付项目资金，对项目建设中的重大事项、进展情况，及时向市政府和分管领导进行汇报。

领导小组办公室具体负责项目建设工作，负责落实领导小组决定事项，严格规范执行项目建设的各环节程序、标准，督促有关责任人和代理、设计、施工、监理单位落实项目责任制，按要求及时上报工程进度，强化项目各个环节的监督检查，保证项目进度和工程质量，监督施工企业在施工过程中严格落实农民工工资支付“1116”工作机制，确保项目施工过程中不拖欠农民工工资。

中卫市人力资源和社会保障局
