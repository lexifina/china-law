# 中卫市就业创业工作领导小组关于认定2家市级创业孵化示范基地的通知

各县（区）人民政府、市就业创业工作领导小组各成员单位：

为进一步加强创业孵化示范基地创建工作，根据《自治区人民政府关于做好当前和今后一个时期促进就业工作的实施意见》（宁政规发〔2018〕11号）和《中卫市人民政府关于加快推进“创新驱动 脱贫富民 生态立市”战略的实施方案》（卫党发〔2018〕1号）精神，市就业创业工作领导小组办公室组织考评工作组对各地申报单位进行了评审验收，并对拟确定的市级创业孵化示范基地进行了公示确认。经市就业创业工作领导小组研究同意，决定认定沙坡头娱岛文化旅游创业孵化示范基地、全通枸杞创业孵化示范基地2家单位为市级创业孵化示范基地，并分别给予每个创业孵化示范基地一次性奖补资金50万元。

各县（区）要加强组织领导，积极推进创业孵化示范基地建设，不断完善支持创业创新政策措施，规范服务流程，提高创业服务水平，增强园区（基地）发展后劲，发挥好示范引领作用，扶持带动更多劳动者创业。要进一步规范奖补资金管理使用，奖补资金主要用于完善和提升创业孵化示范基地功能，不得直补创业实体和个人，不得用于基础设施建设。奖补资金使用由创业孵化示范基地所在人力资源和社会保障部门和财政部门负责监督。

中卫市就业创业工作领导小组
