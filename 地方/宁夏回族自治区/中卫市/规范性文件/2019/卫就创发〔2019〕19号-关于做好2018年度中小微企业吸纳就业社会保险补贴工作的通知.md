# 关于做好2018年度中小微企业吸纳就业社会保险补贴工作的通知

中宁县、海原县就业创业和人才服务局，全市各相关企业：

为认真贯彻落实宁人社发〔2015〕125号、宁人社发〔2015〕148号、宁政发〔2017〕77号和宁政办规发〔2018〕9号文件精神，促进普通高校毕业生就业，鼓励企业吸纳就业困难人员就业，发挥就业创业资金的使用效益，切实把就业优惠政策落到实处，现就发放2018年度社会保险补贴有关事宜通知如下：

一、补贴对象及条件

中小微企业、民办非企业单位和社会团体新招用就业困难人员、普通高等学校全日制专科（高职）以上毕业年度（应届）毕业生、农村建档立卡贫困人口和供给侧结构性改革中化解过剩产能企业职工，签订1年以上劳动合同并交纳社会保险的，给予企业1年的社会保险补贴。中小微企业认定标准按照国家工信部、统计局、发展改革委、财政部《关于印发中小微企业划型标准固定的通知》（工信部联企业〔2011〕300号）规定执行。就业困难人员认定按照自治区人力资源和社会保障厅《关于做好就业援助对象认定管理工作的通知》（宁人社发〔2010〕473号）规定执行。

二、补贴标准

中小微企业、民办非企业单位和社会团体每招用1名就业困难人员、普通高等学校全日制专科（高职）以上毕业年度（应届）毕业生、农村建档立卡贫困人口或供给侧结构性改革中化解过剩产能企业职工，一次性给予1年的社会保险补贴（基本养老保险费、基本医疗保险费、失业保险费）。补贴标准按企业实际缴纳的社会保险费给予补贴，不包括个人应缴纳的社会保险费。社会保险补贴实行先缴后补，所需资金从就业资金中列支。

三、补贴程序

按照属地管理原则，符合条件的企业，向所在地市、县（区）就业创业和人才服务局提出申请。请县（区）高度重视，广泛宣传，确保符合条件的企业应知尽享。沙坡头区符合条件的中小微企业向中卫市就业创业和人才服务局提出申请，并按照申请补贴的类别分别提供以下资料：

1、招用就业困难人员的企业，按要求填写《企业招用就业困难人员社会保险补贴申报表》（附件1），提供营业执照正本复印件，并附就业困难人员相关信息资料（身份证、就业援助对象认定申请表及相关证明材料、《就业创业证》第2、3、7页复印件、劳动合同复印件等）各一份装订成册并加盖公章。

2、招用毕业年度高校毕业生的企业，提供营业执照正本复印件，高校毕业生相关信息资料（毕业证复印件、身份证复印件、劳动合同复印件）各一份装订成册并加盖公章。

3、招用农村建档立卡贫困人口和供给侧结构性改革中化解过剩产能企业职工，提供营业执照正本复印件，建档立卡贫困人口及供给侧结构性改革中化解过剩产能企业下岗职工相关依据，劳动合同复印件各一份装订成册并加盖公章。

四、申报时间

2019年10月31日至2019年12月20日。
