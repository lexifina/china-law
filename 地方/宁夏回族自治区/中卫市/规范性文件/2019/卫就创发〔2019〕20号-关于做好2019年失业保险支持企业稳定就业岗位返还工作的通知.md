# 关于做好2019年失业保险支持企业稳定就业岗位返还工作的通知

中宁县、海原县就业创业和人才服务局及有关企业：

为认真贯彻落实自治区人力资源和社会保障厅、自治区财政厅、自治区发展和改革委员会、自治区经济和信息化委员会《关于进一步做好失业保险支持企业稳定就业岗位有关问题的通知》（宁人社发〔2015〕126号）、《关于失业保险支持企业稳定就业岗位有关问题的补充通知》（宁人社发〔2015〕167号）和宁人社发〔2019〕39号文件精神，进一步做好我市2019年失业保险支持企业稳定就业岗位返还工作（简称“企业稳岗返还”）,现就有关事宜通知如下：

一、返还对象及条件

（一）返还对象

享受稳岗返还的对象为所有符合条件的企业。国家机关、事业单位、社会团体、民办非企业单位、城镇个体经济组织以及其他社会组织等用人单位不适用稳岗返还政策，失信企业不能享受该项政策，“企业稳岗返还”和“经营困难且恢复有望企业稳岗返还”在同一年度只能享受其中一项。

（二）返还条件

申请稳岗返还的企业应具备以下条件：生产经营应符合国家及所在区域产业结构调整和环保政策；参加失业保险并按规定足额缴纳失业保险费12个月以上；2019年未裁员或裁员率低于全区城镇登记失业率（裁员率计算公式为：裁员人数/(2019年年末参保职工人数+裁员人数)×100%）。

二、返还标准及使用范围

（一）返还标准

企业稳岗返还的标准按照该企业及其职工2019年实际缴纳失业保险费总额的50%给予返还（企业实际缴纳失业保险费金额按照税务部门缴费凭证确认）。

（二）返还资金及使用范围

企业稳岗返还主要用于职工生活补助、缴纳社会保险费、转岗培训、技能提升培训等相关支出。

三、返还申请程序及所需资料

（一）申请程序

凡沙坡头区符合享受企业稳岗返还条件的企业向中卫市就业创业和人才服务局二楼3、4号窗口提出申请，中宁县、海原县所属各企业在本县就业创业和人才服务局窗口申请。

（二）申请所需资料

1.申请企业需填报《宁夏回族自治区失业保险支持企业稳定岗位返还申请表》；

2.申请企业需提供稳岗返还报告（企业基本情况介绍、上年度返还资金使用情况说明、本年度人员变动情况说明）；

3.申请企业需提供企业营业执照复印件及法人身份证复印件、最新银行开户许可证复印件；

4.2019年1月-2019年12月社保核定表、税务部门缴费凭证；

以上资料装订成册并加盖公章，社保核定表需加盖社保局业务专用章。

四、申报时间

2019年企业稳岗返还资料上报时间自文件下发之日起至2019年12月31日止。中宁县、海原县参照执行。

注：请各企业尽早核缴12月份失业保险，以便进行企业稳岗返还申报。
