# 关于举办2019年中卫市全民健身节“国庆”《国家体育锻炼标准》暨运动达人赛的通知

中宁、海原县教体局、沙坡头区旅游和文化体育广电局、市直各部门（单位）、各社会团体:

为认真贯彻落实《全民健身条例》,按照自治区体育局社体中心《关于举办2019宁夏《国家体育锻炼标准》推广活动的通知》精神，广泛开展全民健身活动，加快推进体育强国建设，促进我市体育事业发展，着力提高广大群众身体素质，丰富市民体育文化生活。决定于9月28日—29日举办2019年中卫市全民健身节《国家体育锻炼标准》暨运动达人赛，望各单位组织干部职工群众积极报名组队参加。

八、参赛办法

（一）凡在规定年龄内身体健康者均可报名；

（二）《国家体育锻炼标准》暨运动达人赛以个人、家庭报名参加；

（三）运动员比赛时须出示本人第二代居民身份证原件；

九、竞赛办法

（一）按照报名顺序分组（每15人为一组）进行比赛；

（二）参赛运动员按完成组别内所有项目时间长短进行排名；

十、录取名次及奖励

（一）按照报名顺序，每15人为一组，每小组取前三名给与奖励；

（二）总排名前十名的选手颁发运动达人证书；

（二）参与者给与纪念品奖励；

十一、报名和报到

（一）有能力完成竞赛项目且身体健康的健身爱好者均可报名参加，报名后不得无故退赛；

（二）市直各部门将参赛人员名单报至中卫市旅游和文化体育广电局； 联系人：朱蓉 18295258958
