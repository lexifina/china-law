# 关于举办2019全民健身节“鑫华威•华御杯”庆祝建国七十周年全国乒乓球邀请赛的通知

全国各乒乓球俱乐部，市直各部门（单位），中宁、海原县教体局，沙坡头区旅游和文化体育广电局，各企业及社会团体：

为了庆祝中华人民共和国成立七十周年，贯彻落实国务院颁布的《全民健身条例》，更加广泛深入地开展全民健身活动和体育+旅游活动，不断创新和丰富体育健身活动的内容和形式，满足人民群众日益增长的体育健身需求，决定于11月9日-10日举办2019全民健身节“鑫华威·华御杯”庆祝建国七十年全国乒乓球邀请赛，诚邀全国各乒乓球爱好者积极组队参加。

附件1：

宁夏“鑫华威·华御杯”庆祝建国七十年全国乒乓球邀请赛竞赛规程

一、主办单位

中卫市旅游和文化体育广电局

中卫市体育总会

二、承办单位

中卫市直属机关工委

中卫市总工会

中卫市乒乓球协会

中卫市体育中心

三、赞助单位

宁夏鑫华威能源科技有限公司

宁夏华御科技有限公司

四、比赛时间

2019年11月9日-10日在中卫市职工活动中心举办

五、竞赛项目

（一）混合团体(2男1女)，每人只允许出场一次，各参赛队有一名男运动员必须45岁以上。三场二胜，五局三胜。

（二）成年男子单打（2000年9月16日前，1963年9月15日后出生）

（三）成年女子单打（2000年9月16日前，1963年9月15日后出生）

（四）老年男子单打（1963年9月16日前，1954年9月15日后出生）

六、竞赛办法

（一）比赛执行中国乒乓球协会最新审定的《乒乓球竞赛规则》。

（二）团体赛采用分组循环制和决赛采用淘汰制，五局三胜制，每局比赛均采用11分制。单打采用单淘汰制，每局11分。

（三）比赛用球由大赛组委会提供（许绍发+三星塑料球）。

七、参赛办法

（一）成人团体限报64队，参赛资格不限(地区、专业)。

（二）邀请全国各省乒乓球协会或俱乐部和在宁企业组队参加比赛。

（三）所有参赛人员必须是身体健康者，报名运动员需提供县级以上医疗部门健康证明。参赛人员应根据自身身体条件，天气和地理等方面的情况，量力而行参加比赛。

（四）所有参赛人员应由参赛单位或个人办理比赛间的人身意外保险，否则，一切后果自负，主办方不承担任何责任。参赛人员报到时，应提交保单复印件。

八、报名时间与报名办法

报名起止日期：2019年10月21日起至11月3日截止。

（一）参赛运动员报名时应提供：姓名、性别、身份证号、电话、参赛项目。通过微信、电话的方式报名，报名后电话确认报名信息。

（二）报名方法：各代表队将报名表填写好后盖章发至中卫市乒乓球协会。

九、录取名次和奖励

（一）团体取前6名。一等奖1名给与6000元奖励，二等奖2名给与3000元奖励，三等奖3名给与1000元奖励。

（二）个人项目：成年组男、女，老年组男。一等奖1名给与1000元奖励，二等奖2名给与600元奖励，三等奖400元奖励。

十、仲裁委员会及裁判员

裁判长、仲裁委员会成员由宁夏乒乓球协会选派，裁判员由承办单位选派。

十一、相关事宜

（一）2019年11月8日下午3:00在中卫市职工活动中心会议室召开领队、教练员、裁判长会议。

（二）组委会为参赛运动员提供比赛上衣(短袖)和五星级旅游区沙坡头和金沙海门票。

（三）各参赛单位交通、食宿费自理。

十二、比赛要求

（一）运动员、工作人员一律穿运动胶底鞋入场，乒乓球馆内严禁吸烟。

（二）参赛运动员要尊重裁判、服从判罚、自觉维护比赛秩序。

（三）各参赛队提前15分钟到达指定的比赛位置。

（四）裁判长根据比赛进度有权调整比赛顺序和位置。

（五）比赛中出现异议，由领队向组委会提出申述报告，由仲裁委员会仲裁后，将处理结果予以公布，其他人员的申述一律不予受理。

（六）比赛期间各代表队要做好安全预案，明确安全责任人，确保比赛期间（场上场下）不发生安全事故。

十三、本规程最终解释权归中卫市乒乓球协会
