# 市民政局关于印发《中卫市养老机构安全管理标准》的通知

两县一区民政局，各养老机构：

为进一步推进全市养老机构开展安全管理标准化创建工作，提升养老机构安全管理水平，有效预防和减少安全事故，根据市安委办关于印发《中卫市工矿商贸企业安全生产标准化对标对表创建工程实施方案》的通知精神，我们制定了《中卫市养老机构安全管理标准》及《中卫市养老机构安全事故应急救援预案》，现印发给你们，请结合各自实际，研究制定具体落实方案，认真组织实施。

附件：1.中卫市养老机构安全管理标准

2.中卫市养老机构安全事故应急救援预案

中卫市民政局
