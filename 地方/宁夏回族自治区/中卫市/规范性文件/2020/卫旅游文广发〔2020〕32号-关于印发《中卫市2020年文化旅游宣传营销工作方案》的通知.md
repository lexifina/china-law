# 关于印发《中卫市2020年文化旅游宣传营销工作方案》的通知

沙坡头区旅游和文化体育广电局，中宁、海原文化旅游广播电视局，宁夏沙坡头旅游产业集团，各相关涉旅企业：

现将《中卫市2020年文化旅游宣传营销工作方案》予以印发，请各部门按照方案，认真落实，结合旅游营销工作实际，制定各部门年度营销方案，强化旅游宣传，全力推进中卫全域旅游示范市宣传营销工作。

中卫市旅游和文化体育广电局

2020年3月19日

（此件公开发布）

中卫市2020年文化旅游宣传营销工作方案

2020年是全面建成小康社会和“十三五”规划的收官之年，也是“十四五”规划的谋篇之年，为切实做好全年全域旅游宣传营销工作，助力建设全域旅游示范市，特制定本工作方案。

一、总体思路和目标

认真贯彻落实全国旅游工作会议、全区文化旅游工作会议精神和市委、市政府决策部署，围绕全域旅游示范市目标，坚持“宜融则融，能融尽融，以文促旅，以旅彰文”的工作原则，按照“巩固基础市场，拓展周边市场，培育发展潜在客源市场”的工作思路，加快构建传统媒体与新媒体结合，线上线下共促、政府与企业联动”的文化旅游宣传营销机制，精准投放文化旅游形象宣传广告，策划开展主题营销和节事活动，深化文化旅游全民宣传行动，进一步优化文化旅游线路，不断提高中卫文化旅游的美誉度和影响力，确保全市旅游接待人数稳中有增，力争突破1000万人次。

二、重点工作

（一）投放旅游形象宣传广告，实施精准营销

1.区外媒体广告宣传。在自治区文化和旅游厅统一主导下在中央电视台CCTV1\CCTV新闻《午间新闻》、《朝闻天下》投放中卫旅游形象广告。

2.区内媒体宣传。与宁夏电视台、宁夏新闻网、中国旅游报等主流媒体合作，刊发中卫文化旅游专版，采编发布中卫文旅信息，并利用其官网、微信、微博等进行全方位宣传。

3.市级媒体宣传。与中卫市新闻传媒中心合作，开设中卫文旅专栏，利用一端24媒，主体化宣传中卫文化旅游，刊发中卫文化旅游专刊，制作刊播中卫文化旅游发展视频。

（二）整合线上营销网络，实施创新营销

1.提升智慧旅游项目。深化文旅资源和现代科技融合，加快推进智慧旅游项目建设，优化各涉旅企业尤其是重点旅游景区智慧导览、在线预定、支付等系统建设，完善充实旅游大数据分析系统模块，提升文化旅游信息化服务水平，构建文化旅游大数据营销网络。

2.提高自媒体平台关注度。充分整合各部门、景区官方微信公众号、微博、头条号、抖音、美篇等自媒体平台，组建专业运营团队，把网络元素与中卫文化旅游元素相融合，集中发布制作网民喜闻乐见的文化旅游热点视频、美图、旅游攻略等，提高网民关注度，打造中卫旅游新IP。

3.加强网络平台合作。加强与新华网、中国旅游网等主流网站合作，系统化、大规模、全方位推进网络营销。在新浪网、乐途网、驴妈妈旅游网、携程旅游网、国家旅游地理网、爱旅游等知名旅游网站定期发布中卫文化旅游软文，文化旅游攻略，提高中卫文化旅游曝光率。加大在百度、搜狗等搜索平台开展关键词营销，加强与知名OTA平台合作，推出更多优质文化旅游产品。

（三）精心策划主题营销活动，实施品牌营销

1.加强旅游推介。贯彻落实市委、市政府和自治区文化和旅游厅的宣传营销工作部署，发挥主观能动性，借助深圳文博会、海南休闲旅游博览会、上海旅游交易会、海峡两岸文化产业博览交易会，西北旅游营销大会等活动强化中卫文化旅游宣传，在北京、成都、重庆、西安、上海、广东、福建、河北等航线开通城市开展媒体宣传和旅游推介活动，发展和巩固潜在旅游客源市场；积极开展市场调研，分析南北客源市场差异，针对游客需求，推出不同旅游产品和线路设计，在旅游资源差异较大且近几年来卫人数增长较快的省市开展差异化推介和营销活动。

2.举办节事活动。按照月月有活动，打造精品节事活动的要求。策划“放心游宁夏，开心游中卫”系列主题活动，继续做大做强大漠黄河国际旅游节系列节事活动，举办梨花节、乡村文化旅游节、环球旅游盛典、航空嘉年华、枸杞产业博览会、汽车旅游嘉年华、中国宁夏（沙坡头）“星空大会”等节事活动，全方位展示以大漠、黄河、湿地为代表的特色文化旅游资源魅力，推广中卫精品旅游线路、乡村自驾和经典游乐等项目，进一步激活中卫旅游市场，推动旅游门票经济向产业经济的转变。（具体节事活动见附件）。

3.大力发展冬季文化旅游。整合冬季旅游资源，提前谋划冬季旅游活动，联合景区、宾馆、餐饮等部门和企业推出优惠政策和措施，积极开展沙坡头冬季沙漠探险、黄河宫、沙坡头娱岛、中宁双井子冬季冰雪嘉年华等活动，推进改变冬季旅游半年闲状态，丰富冬季旅游业态。

4.实施景区门票优惠活动。鼓励各景区联合推出景区套票，针对区内游客实行免票或者半票优惠政策，借助交通优势，开拓区内市场，吸引宁夏人游中卫。针对福建、湖北等客源市场，实行门票半价优惠政策；针对医护人员、警察等一线工作者，推出特定旅游套票，为中卫旅游赚人气。

（四）发挥专列包机带动作用，实施激励营销

1.实施送团奖补政策。继续巩固中卫旅行社送团基础和成果，修改完善《旅行社送团奖励办法》，调动区内外旅行社向中卫送团的积极性，发挥包机专列对中卫旅游的宣传带动作用，激活中卫旅游客源市场，力争2020年旅游专列达180列，输送游客35万人次。

2.加大乡村旅游扶持力度。对中卫乡村旅游资源进行调研和考察，推出特色乡村旅游线路。指导县区结合自身资源优势和条件，制定实施乡村旅游送团奖补政策，充分发挥旅游扶贫作用，带动乡村文化旅游产业发展，助推全域旅游示范市建设。

（五）深化文化旅游全民宣传行动，推进全民营销

1.组织动员社会力量宣传营销。组织动员交通运输、城市管理等部门、共青团组织和相关企业在高速公路出入口、汽车站、火车站、飞机场、城市广场、加油站、高速公路服务区、宾馆饭店等地设立一批游客咨询服务站点，培训专兼职咨询员，配发旅游宣传资料，深入开展旅游宣传和咨询服务；组织动员各级各部门、各类社会组织和广大干部群众利用各种方式宣传推介中卫旅游资源和特色产品。

2.制作发放旅游系列宣传品。编辑整理中卫旅游宣传推介词，制作中卫旅游宣传片和推介PPT；设计印制《中卫全域旅游宣传册》《中卫旅游手绘地图》等宣传品，配发全市星级饭店、A级景区、旅行社和游客咨询服务中心（站点）、旅游咨询服务车，供游客查阅，并寄送中卫旅游宣传营销代理中心、全国重点旅行社和自驾游、户外运动等社团组织；在中卫机场进出港航班配发中卫旅游宣传品，并利用境内外旅游交易会和重要节假日、重大节会赛事活动集中向境内外旅行商及游客发送旅游宣传品，进一步扩大旅游宣传营销的覆盖面。

（六）强化区域旅游营销合作，实施联合营销

1.建立联合营销模式。充分调动涉旅企业积极性，发挥旅游营销中心和旅游行业协会作用，由市旅游部门负责，两县一区配合，组建专业旅游营销团队，全面分析开展旅游宣传活动，推动中卫旅游宣传营销工作科学化、创新化发展。

2.加强与周边省市互通互送。积极发展旅游合作友好城市，深化与海南省、福建漳州、广东惠州、陕西榆林的旅游合作，进一步凝聚合力，推动中卫与全国重点省市的旅游交流与合作。

3.加强与重点景区合作。继续深化与国内重点旅游景区的合作与对接，形成合力，互推互送，学习其他景区先进营销经验，定期召开旅游合作会议，探讨旅游营销模式，共促旅游产业发展。

4.建立部门营销联动机制。加强与宣传、交通、住建、外事、民航、口岸办、铁路等多部门联动，形成资源共享、政策共推，活动共搞的良好局面。

（七）挖掘历史文化，打造文旅品牌

1.塑造中卫文化旅游形象。开展中卫旅游形象设计征集活动，设计推出中卫旅游新LOGO；结合中卫文旅旅游资源特色，赋予中卫文旅品牌新内涵，推陈出新，推出中卫文化旅游形象宣传广告语。设计中卫旅游广告语和宣传背景，引导全市各行业宣传、张贴中卫旅游品牌宣传标语和条幅。

2.挖掘特色旅游资源。持续深入挖掘“沙漠水城·休闲中卫”旅游品牌形象，针对中卫黄河、沙漠、特色民宿、中宁枸杞产业、海原乡村旅游等特色资源，大力开发旅游产品，统筹开发沙坡头区、中宁县、海原县旅游资源，开发推出研学游、乡村体验、农业休闲观光、文化体验游等特色精品旅游线路，着力打造全域旅游品牌。

3.创建旅游商品品牌。年内扶持2-3家旅游商品研发基地，年内至少推出10种特色旅游商品；完善体制机制建设，成立中卫市旅游商品协会，通过协会整合资源，树立全市商品研发“一盘棋”思想，统筹推进商品研发工作，力争各县（区）推出1-3个具有地方代表性、创意性、特色性的旅游商品。制定切实有效的旅游商品扶持政策，持续举办文创旅游商品大赛，加强对商品研发企业培训。积极申报自治区专项资金支持，通过政策引导、产业扶持，强化商品品牌建设和宣传力度，增强中卫旅游商品吸引力。在沙坡头景区、旅游新镇设立特色旅游展示厅，展示和宣传中卫特色旅游商品。

三、保障措施

（一）加强组织领导。统筹整合各级政府、旅游管理部门、旅游企业的宣传营销资源，建立“横向统筹协调，纵向层层落实”的工作机制，对全市旅游宣传营销实施一体化管理，充分调动区、县政府及旅游企业联合营销的积极性，形成文化旅游宣传营销机制，市县政府部门、企业形成文化旅游宣传营销的合力。

（二）加大资金投入。充分发挥政府资金的引导作用，加大中卫旅游宣传营销专项资金支持额度。市、县区政府配套宣传营销专项资金，旅游企业设立营销资金，制定资金使用计划，协同配合，进行精准投放。

（三）优化环境支撑。完善道路、旅游厕所、游客服务中心等旅游基础及公共服务设施，营造旅游安全、服务优质、环境优美、卫生整洁、热情好客的中卫旅游形象，进一步优化中卫旅游大环境，打造游客满意的旅游目的地。加强中卫文化旅游大数据建设，了解和把握旅游者多样化、多层次的旅游消费需求，为实现我市精准营销打下基础。
