# 关于印发《吴忠市法治政府建设2017年工作要点》的通知

各县（市、区）、市直各有关部门：

现将《吴忠市法治政府建设2017年工作要点》印发给你们，请结合实际认真抓好贯彻落实。

吴忠市人民政府办公室

2017年4月25日

吴忠市法治政府建设2017年工作要点

2017年是全面推进法治政府建设的关键之年，为了深入贯彻落实《吴忠市法治政府建设实施方案（2016-2020年）》(吴党发〔2016〕40号)，加快推进我市法治政府建设，争取到2020年基本建成法治政府，现提出2017年法治政府建设工作要点：

一、重点工作（17项）

1.清理行政审批事项，规范证照管理。继续清理行政审批事项。6月底前，完成对增加企业和公民负担证照的清理，并公布清理结果。（市委编办牵头，各县（市、区），各有关部门负责）

2.对保留的行政审批事项实行目录化、编码化管理。完善行政审批事项目录，实行统一编码，实现动态管理。做好已取消和下放行政审批事项的落实和衔接工作。（市委编办牵头，各县（市、区），各有关部门负责）

3.加快推进相对集中行政许可权工作。加强行政审批制度改革，借鉴先进地方相对集中行政许可权试点经验，探索实行相对集中行政许可权试点。（市委编办牵头，同心县，各有关部门配合）

4.转变政府投资管理职能。深化投融资体制改革，制定并公开《吴忠市企业投资项目核准目录清单》，进一步缩减范围、下放权限，实现政企分开，企业投资主体地位得到确立。（市发改委、财政局牵头，各县（市、区），工信局、人社局、国土局、住建局、环保局、农牧局、商务局、市场监管局、地税局、人行吴忠市中心支行、银监分局等有关部门配合）

5.加强社会信用体系建设。按照国务院和自治区社会信用体系规划纲要，建立健全统一的社会信用代码制度和信用信息共享交换平台，推进企业信用信息公示系统建设，依法保护企业和个人信息安全。（市发改委牵头，商务局、工信局、中级人民法院、人社局、市场监管局、地税局、人行吴忠市中心支行、银监分局等有关部门配合）

6.落实外资管理政策，支持企业对外投资。健全对外投资促进制度和服务体系，支持企业扩大对外投资，推动装备、技术、标准、服务走出去。（市商务局牵头，各县（市、区），发改委、工信局、市场监管局、地税局等有关部门配合）

7.推进社会自治。指导城市社区和行政村修订、完善居民公约和村规民约，实现居民公约和村规民约全覆盖，并引导普遍认同和遵守。加大行业协会、商会章程规章执行监管力度，科学设置行业协会、商会组织机构，完善运行管理机制，规范行业协会、商会法人治理行为，促进社会组织健康发展。（市民政局牵头，各县（市、区）负责，各有关部门配合）

8.严格落实规范性文件管理制度。实行制定机关对规范性文件统一登记、统一编号、统一印发制度。（市政府办牵头，各县（市、区），各有关部门负责）

9.落实政府规范性文件清理制度。完成对现行有效规范性文件的清理，并将清理结果向社会公布。（市政府办（法制办）牵头，各县（市、区），各有关部门负责）

10.完善行政执法权限协调机制。建立健全行政执法权限协调机制，及时解决执法机关之间的权限争议，建立异地行政执法协助制度。（市政府办（法制办）牵头，各有关部门负责）

11.健全公民和组织信用记录，完善守法诚信褒奖机制和违法失信行为惩戒机制。建立完善企业信用记录制度，实现企业信用信息公开查询。建立公民信用记录制度，加强重点人群职业信用建设，建立企业法定代表人和各类职业人员信用档案。完善法人或者其他组织和自然人守法褒奖、违法失信惩戒机制，建立举报奖励制度，保护举报人合法权益。（市发改委牵头，各县（市、区），各有关部门配合）

12.规范执法辅助人员管理。建立执法辅助人员管理制度，明确其适用岗位、身份性质、职责权限、权利义务、聘用条件和程序等。（市政府办（法制办）牵头，各县（市、区），各有关部门负责）

13.加强公务员诚信管理。建立公务员诚信档案，将公务员诚信记录作为干部考核、任用和奖惩的重要依据，编制公务员诚信手册，增强公务员法律和诚信意识。（市委组织部、人社局牵头，各县（市、区），各有关部门负责）

14.完善社会监督和舆论监督机制。建立健全网络舆情监测、收集、研判、处置机制，推动网络监督规范化、法制化。（市委宣传部牵头，各县（市、区），政府办、网信办、监察局、文广局、信访局负责）

15.全面推进政务公开。建成互联网政务信息数据服务平台和便民服务平台，提高政务公开信息化、集中化水平。（市政府办牵头，各县（市、区），各有关部门负责）

16.加强人民调解工作。实现村委会、居委会人民调解组织全覆盖，在城市社区、农村乡镇、企事业单位、行业组织设立人民调解组织，探索建立职业化的行业性专业性人民调解队伍。重点协调解决消费者权益、劳动关系、医患关系、物业管理等方面的矛盾纠纷，完善人民调解、行政调解、司法调解联动工作体系。（市司法局牵头，综治办、中级人民法院、政府办（法制办）配合）

17.加强法治政府建设典型示范。积极开展建设法治政府示范创建活动，培育建设法治政府先进典型。（市政府办（法制办）牵头，各县（市、区），各有关部门配合）

二、进一步深化的工作（29项）

1.加快投资项目在线审批监管平台建设。进一步完善投资项目在线审批监管平台，全面实行投资项目在线审批。（市发改委牵头，各县（市、区），各有关部门负责）

2.全面清理规范行政审批中介服务。根据《自治区党委办公厅  人民政府办公厅关于印发<宁夏回族自治区行业协会商会与行政机关脱钩实施方案>的通知》（宁党办〔2016〕27号），在更大范围内开展试点，力争50%的行业协会商会实现脱钩。（市民政局牵头，各县（市、区），各有关部门配合）

3.加强权责清单管理。全面落实“两个清单”，建立统一的权责清单管理系统，实行动态管理。（市委编办、政府办（法制办）牵头，各县（市、区），各有关部门配合）

4.严格落实行政事业性收费和政府性基金清单制度。继续清理行政事业性收费和政府性基金，落实好已公布取消、停征和减免的收费基金各项政策。进一步清理、整合和规范涉企行政事业性收费和政府性基金项目。继续向社会公示收费基金项目，持续抓好涉企收费清理整顿工作，依法查处乱收费、乱集资、乱摊派等侵害企业合法权益的行为。（市财政局牵头，各县（市、区），各有关部门配合）

5.深化商事制度改革。巩固扩大企业“五证合一、一照一码”和个体工商户“两证整合”成果，推进“多证合一”登记制度改革。推进注册登记全程电子化和电子营业执照。开放企业名称库，逐步实现企业名称自主选择。实行企业、农民专业合作社、个体工商户简易注销改革。加强事中事后监管，建立协同监管机制，实行综合监管，推广随机抽查，探索大数据监管模式。（市市场监管局牵头，国税局、地税局、商务局等有关部门配合）

6.深入推进社会治安综合治理。深入推进平安吴忠创建活动，加强社会治理体制机制、能力、人才队伍和信息化建设，搭建综合治理工作平台。健全落实社会治安综合治理领导责任制，完善立体化社会治安防控体系，有效防范管控影响社会安定的问题，保护人民生命财产安全。提高公共突发事件防范处置和防灾救灾减灾能力。全方位强化安全生产，全过程保障食品药品安全。（市综治办牵头，各县（市、区），公安局、市场监管局、安监局、政府办（应急办）等有关部门负责）

7.推进基本公共服务均等化。落实国家、自治区基本公共服务制度安排，提升我市基本公共服务均等化水平。（市发改委牵头，各县（市、区），财政局、民政局、教育局、卫计局、文广局、人社局、住建局、残联等有关部门配合）

8.建立健全政府购买公共服务制度。继续深入推进政府购买服务制度。规范政府购买服务范围。编制我市政府购买服务指导性目录。加大承接主体培育力度。（市财政局牵头，各县（市、区），各有关部门配合）

9.强化生态环境保护。加快建立和完善有效约束开发行为和促进绿色发展、循环发展、低碳发展的生态文明制度。深化资源性产品价格和税费改革，实行资源有偿使用制度和生态补偿制度。改革生态环境保护管理体制。（市环保局牵头，各县（市、区），发改委、市委组织部、财政局、工信局、监察局、审计局等有关部门配合）

10.健全依法决策机制。落实《吴忠市重大决策程序规定》（吴政发〔2016〕14号），完善市、县两级政府及部门重大行政决策目录，强化决策法定程序的刚性约束。（市政府办牵头，各县（市、区），各有关部门负责）

11.增强公众参与实效。加强公众参与平台建设，市、县两级政府及部门制定、公布重大行政决策事项听证范围，建立听证代表遴选机制，按照法定程序组织听证。（市政府办牵头，各县（市、区），各有关部门负责）

12.提高专家论证和风险评估质量。建立本级政府、本部门行政决策咨询论证专家库。落实重大行政决策风险评估机制。（市政府办牵头，各县（市、区），各有关部门负责）

13.建立重大行政决策后评估机制。行政机关根据实际需要进行重大行政决策后评估，并根据评估情况适时调整和完善有关决策。（市政府办牵头，各县（市、区），各有关部门负责）

14.继续推行综合执法。推进市辖区综合执法，做好市辖区综合执法改革试点工作，积极推进覆盖城乡的跨行业、跨领域综合执法。理顺城管执法体制，加强城市管理综合执法机构和队伍建设，提高执法和服务水平。（市委编办牵头，各县（市、区），各有关部门负责）

15.理顺行政强制执行体制。科学配置行政强制执行权，提高行政强制执行效率。（市委编办、政府办（法制办）牵头，各县（市、区），各有关部门负责）

16.健全行政执法和刑事司法衔接机制。健全行政执法机关、公安机关、检察机关、审判机关信息共享、案情通报、案件移送制度，行政处罚和刑事处罚实现无缝对接。（市检察院牵头，各县（市、区），各有关部门配合）

17.落实行政执法程序规范，建立执法全过程记录制度。严格落实《宁夏回族自治区行政程序规定》（自治区人民政府令第73号），健全行政执法调查取证、告知、罚没收入管理制度，明确听证、集体讨论决定的适用条件。在重点领域推行行政执法全过程记录。（市政府办（法制办）牵头，各有关部门负责）

18.落实重大行政执法法制审核制度。行政执法机关应当明确本部门重大行政执法决定法制审核的范围和标准。凡审核范围内的重大行政执法决定，在拟作出前应当由本部门的法制机构进行审核，未经法制审核或者审核未通过的，不得作出决定。（市政府办（法制办）牵头，各有关部门负责）

19.推行行政执法公示制度。建立本级政府、本部门、本单位行政执法公示制度，公示的内容应随时调整，并及时更新。（市政府办（法制办）牵头，各县（市、区），各有关部门负责）

20.加强行政执法信息化建设和科技、装备在行政执法中的应用。加强行政执法信息化建设和信息共享，有条件的部门建立统一的行政执法信息平台，完善网上执法办案及信息查询系统。（市信建办、财政局牵头，各县（市、区），各有关部门负责）

21.健全行政执法人员纪律约束和考核机制，加强职业道德教育，全面提高执法人员素质。推行行政执法人员平时考核制度，科学合理设计考核指标体系，考核结果作为执法人员职务级别调整、交流轮岗、教育培训、奖励惩戒的重要依据。（市人社局牵头，各县（市、区），市委组织部、监察局等有关部门负责）

22.保障行政执法经费。行政机关履行执法职责所需经费，要纳入本级政府预算，保证执法经费足额拨付。严格执行罚缴分离和收支两条线管理制度。（市财政局牵头，各县（市、区）政府，各有关部门负责）

23.健全依法化解纠纷机制。落实《自治区党委办公厅  人民政府办公厅关于印发<宁夏回族自治区矛盾纠纷排查化解办法（试行）>的通知》（宁党办〔2016〕33号），建立并启用矛盾纠纷排查化解信息系统。建立健全社会矛盾预警机制，利益表达机制、协商沟通机制、救济救助机制。加强群体性、突发性事件预警监测。依法加强对影响或危害食品药品安全、安全生产、生态环境、网络安全、社会安全等方面重点问题的治理。（市综治办牵头，各县（市、区）政府，公安局、市场监管局、安监局、环保局、司法局、网信办等有关部门负责）

24.加强行政复议工作。健全行政复议案件审理机制，要依法加强行政复议能力建设，行政复议机构设置、人员配备要与所承担的工作任务相适应，落实办案场所和有关装备保障。行政复议经费列入本级政府预算。（市政府办（法制办）牵头，各县（市、区）政府，编办、财政局等有关部门负责）

25.完善行政调解、行政裁决、仲裁制度。健全行政调解制度，进一步明确行政调解范围，完善行政调解机制，规范行政调解程序，健全行政裁决制度。有关行政机关要依法开展行政调解、行政裁决工作。完善仲裁制度，提高仲裁公信力。（市政府办（法制办）、司法局、人社局牵头，各县（市、区）政府，各有关部门配合）

26.改革信访工作制度。规范信访工作程序，大力推进网上信访，健全依法及时就地解决群众合理诉求机制。严格落实诉访分离，制定依法分类处理信访诉求工作规程。加强宣传，引导群众在法治框架内解决矛盾纠纷，完善涉法涉诉信访依法终结制度。（市信访局牵头，各县（市、区）政府，各有关部门配合）

27.加强对政府工作人员的法治教育培训。完善学法制度，县级以上各级政府每年至少举办一期领导干部法治专题培训班，县级以上政府领导班子每年应当举办两期以上法治专题讲座。市委党校、行政学院等要把宪法法律列为干部教育的必修课。健全行政执法人员岗位培训制度，行政执法机关每年至少组织开展一次本部门、本单位行政执法人员通用法律知识、专门法律知识、新法律法规等专题培训。加大对公务员任职培训中法治知识的培训力度。（市委组织部牵头，各县（市、区）政府，各有关部门配合）

28.完善政府工作人员法治能力考查测试制度。加强对领导干部任职前法治知识考查和依法行政能力测试，将考查和测试结果作为领导干部任职的重要参考，行政机关每年至少安排两次工作人员集中学法知识培训，培训情况、学习成绩作为考核内容和任职晋升的依据之一。实行公务员晋升依法行政考核制度。对从事行政执法工作的人员，定期组织专门的法律知识培训。行政机关工作人员参加集中学法知识培训考试不合格的，年度考核不得评为优秀等次。（市委组织部牵头，人社局、政府办（法制办）配合）

29.加强法治政府建设宣传引导。大力开展推进依法行政、建设法治政府宣传工作。以报刊、广播、电视、网络等多种媒体形式，广泛宣传法治政府建设目标、工作部署、先进经验、典型做法。（市委宣传部牵头，各县（市、区）政府，各有关部门配合）。

三、工作要求

各县（市、区）、各部门要高度重视，精心组织，党政负责人要履行好推进法治政府建设第一责任人职责，将建设法治政府工作摆在重要议事日程。对本通知确定的年度重点工作，要结合实际，认真安排部署，各牵头单位应及时制定工作方案（工作计划），制定时间进度表，明确可检验的形式，于2017年5月4日（星期四）前报市法治政府建设领导小组办公室（政府法制办）。年底前，各项工作的牵头部门要对所承担的牵头任务进行全面总结，并形成专题报告报送市法治政府建设领导小组办公室。法治政府建设领导小组办公室将适时对年度重点工作及进一步深化的工作情况开展跟踪督查，并于11月底前开展法治政府建设考核。对工作不力、问题较多的，要进行约谈、责令整改、通报批评。
