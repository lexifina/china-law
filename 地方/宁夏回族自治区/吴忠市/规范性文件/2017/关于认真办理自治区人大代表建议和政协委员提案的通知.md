# 关于认真办理自治区人大代表建议和政协委员提案的通知

各县（市、区）人民政府、市政府有关部门：

按照自治区人民政府办公厅《关于认真做好自治区十一届人大七次会议代表建议和自治区政协十届五次会议提案办理工作的通知》(宁政办发〔2017〕45号文件)精神，交我市办理人大代表建议9件、政协委员提案19件。为认真做好办理工作，现就有关事项通知如下：

一、各承办单位要高度重视，严格按照吴忠市人民政府办公室《关于认真做好市五届人大一次会议代表议案建议和市政协五届一次会议提案办理工作的通知》(吴政办发〔2017〕19号文件)相关要求，加强领导，明确责任，认真研究办理，并及时与自治区人大代表和政协委员沟通联系，征求代表和委员意见。

二、市政府督查室将适时督办办理情况，并将办理结果纳入2017年效能目标管理考核内容进行考核。

三、附件1中带“*”的建议，各承办单位务必于7月31日前办理完毕，其它不带“*”的建议、提案于6月20日办理完毕。所有建议提案要严格按照规定格式答复，答复做到意见明确，力戒大话、空话，并根据问题的解决程度，用“A、B、C”准确标出办理结果，经主要领导签字后报送市政府督查室（1份，附电子版，不直接送寄代表委员）。

四、请各承办单位收到建议、提案后，认真核对，按照建议、提案办理责任分工（附件1），从附件2、附件3中查找打印本单位负责承办的建议、提案内容。
