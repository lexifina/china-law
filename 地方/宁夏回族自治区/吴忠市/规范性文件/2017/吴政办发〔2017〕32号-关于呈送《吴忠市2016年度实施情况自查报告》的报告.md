# 关于呈送《吴忠市2016年度实施情况自查报告》的报告

自治区“蓝天碧水·绿色城乡”专项行动领导小组办公室：

根据贵办《关于开展“蓝天碧水·绿色城乡专项行动水污染防治2016年度完成情况考核工作的通知》（蓝天碧水办〔2017〕8号）要求，我市高度重视，组织环保、住建、水务、农牧等部门开展自查，现将《吴忠市<“蓝天碧水·绿色城乡”专项行动水污染防治>2016年度完成情况自查报告》随文呈上，请审阅。

特此报告。

吴忠市人民政府办公室
