# 关于印发吴忠市太阳山政务服务中心运行方案的通知

盐同红三县（区）人民政府，市直有关部门：

《吴忠市太阳山政务服务中心运行方案》已经政府研究同意，现印发给你们，请认真贯彻执行。

吴忠市人民政府办公室

2017年8月11

（此件公开发布）

吴忠市太阳山政务服务中心运行方案

根据市委、市政府《关于盐同红集中连片贫困地区区域发展与脱贫富民攻坚实施意见》精神，为做好太阳山政务服务中心和下马关政务服务中心建设运行各项工作，结合实际制定本方案。

一、工作目标

以利企便民为出发点，以“互联网+政务服务”为支撑，打破集中连片区行政区划界限，着力推进政务信息资源跨部门、跨层级、跨区域协同联动和共享，变“群众跑腿”为“信息跑路”，变“群众来回跑”为“部门（县区）协同办”，加快推进“网上办、集中批、联合审、区域评、代办制”的“不见面、马上办”审批服务模式，最大限度地方便集中连片区企业和群众就近办事，提高工作效率，降低办事成本，切实增强集中连片贫困区群众获得感，打通服务群众“最后一公里”。

二、运行机制

（一）推行民生服务事项“就近能办”。采取“一窗受理、网上运转、限时办结”方式，依托集中连片区乡镇现有民生服务中心，群众既可在大厅直接办理，也可选择到所辖乡镇民生服务中心办理，实现“就近能办”。

（二）推行投资项目事项“综合代办”。采取“一窗受理、统一分办、内部流转、网上运转、限时办结”的模式，分别由派驻政务中心的市级和盐同红三县（区）工作人员，按照投资项目属性和审批权限负责办理，实现“一个窗口进、一个窗口出”的“综合代办”。

（三）构建审批服务事项“集中办理”。将太阳山开发区管委会现有公安、税务、市场监管等政务服务事项，全部纳入太阳山政务服务中心，实现“集中办理”。

（四）推行办理结果“快递送达”。在大厅内设置“邮政快递窗口”，推行办理证照、办理结果快递送达，实现办事 “不见面”。

（五）开辟办事“绿色通道”。对确定的重大工程、重要事项，建立“特事特办”、“一事一议”机制，按照“能快则快、限时办结”的要求，实现“马上办”。

三、主要任务

1.梳理政务服务事项。组织市直有关部门、盐同红三县（区）政府、太阳山管委会开展进驻事项梳理，清理进驻事项名称，建立结构清晰、责任明确、时限合理、高效便捷的政务服务事项流程。

牵头部门：市政务服务中心

配合部门：市委编办、市直有关部门（单位）、太阳山开发区管委会、盐同红三县（区）人民政府

完成时限：2017年8月15日

2.合理布局大厅并设置窗口。根据办理事项及进驻部门（单位）实际情况，大厅共设立综合代办和社会民生两大服务区。设置办事窗口12个、预留备用窗口2个，其中综合代办服务区窗口6个，分别为市级设置投资项目、企业类事项、个人类事项窗口3个，盐同红三县（区）专窗各1个；社会民生事务服务区窗口5个，分别为市公安局太阳山分局、市场监管窗口各1个，税务窗口3个；邮政快递窗口1个。

牵头部门：市政务服务中心

配合部门：市直有关部门（单位）、太阳山开发区管委会、盐同红三县（区）人民政府

完成时限：2017年8月15日

3.建设实体政务服务大厅。本着简洁、节俭原则，对选定实体大厅进行内部装饰改造，设置网络机房，安装布置网线及网络接口，配置电脑、打印机、高拍仪等办公设备，合理布局停车场及绿化设施，建设网上办事大厅和实体大厅“线上线下融合”的服务平台。

牵头部门：太阳山开发区管委会

配合部门：市政务服务中心、信建办、盐同红三县（区）人民政府

完成时限：2017年8月20日

4.配备管理及窗口工作人员。结合中心政务服务管理及窗口服务的需要，本着“精简、效能”原则，共配备人员19名，其中管理人员3名：设主任1名（太阳山管委会现有正科级干部兼任），熟悉综合管理、计算机网络管理人员各1名;窗口工作人员16名,分别为综合代办10名，从市直相关部门选派业务人员4名，分批次轮流坐班1年，轮流坐班顺序依次为市住建、交通、人社、卫计；国土、商务、民政、园林；规划、教育、文广、科技；发改、工信、安监、环保；从盐同红三县（区）各选派2名，其中至少有1名熟悉建设项目投资相关业务的人员；太阳山开发区现有部门选派5名，分别从市公安局太阳山分局、市场监督管理所各选派1名，国税分局选派3名；协调市邮政部门派驻快递业务办理人员1名。

牵头部门：市委编办

配合部门：市人社局、市直有关部门（单位）、太阳山开发区管委会、盐同红三县（区）人民政府

完成时限：2017年8月15日

5.开展岗前培训。对进驻大厅的管理及窗口服务人员开展相关法律法规、政策、业务技能、网络应用、政务礼仪等岗前培训。

牵头部门：市政务服务中心

配合部门：市人社局、信建办、太阳山开发区管委会、盐同红三县（区）人民政府

完成时限：2017年8月18日

6.做好中心网络互联互通和数据交换。指导建设中心网络机房，安装部署 “政务云”、OA办公等平台系统，涉及相关部门（单位）业务系统实现接口开发和数据连接，加快推进部门（单位）之间信息共享和互联互通；协调解决信息平台应用过程中涉及电子政务外网、OA办公、政务云平台等方面的问题。

牵头部门：市信建办

配合部门：市直有关部门（单位）、太阳山开发区管委会、盐同红三县（区）人民政府

完成时限：2017年8月15日

7.挂牌运行。做好挂牌运行的各项筹备工作。

牵头部门：市政务服务中心、太阳山开发区管委会

配合部门：市直有关部门（单位）、盐同红三县（区）人民政府

完成时限：2017年8月18日

8.建设下马关政务服务中心。按照盐同红集中连片贫困地区区域发展与脱贫富民攻坚实施意见精神，依托下马关镇区域发展实际，建设下马关政务服务中心，为辐射区域内各乡镇的企业、群众就近提供“一站式”政务服务。

责任单位：同心县人民政府

完成时限：2017年8月30日

四、保障措施

（一）明确责任分工。各牵头部门（单位）要加强协调，主动担当，积极作为，结合实际制定具体详实的实施方案，进一步明确责任，严格按时间节点不折不扣地抓紧落实；各配合部门（单位）和盐同红三县（区）政府要顾全大局，分工负责，密切配合，全力确保太阳山政务服务中心如期投入运行。

（二）强化考核指导。市政务服务中心负责对太阳山政务服务中心的具体业务指导，太阳山开发区管委会负责政务服务中心的日常管理和正常运转保障。由市政务服务中心与太阳山开发区管委会共同负责政务服务中心效能目标管理考核（包括对各有关派驻部门（单位）、盐同红三县（区）政府政务服务工作延伸考核），考核结果报市考核办。

（三）加强监督检查。市政府督查室对各有关部门（单位）、盐同红三县（区）政府的牵头、配合任务落实推进情况，进行监督检查，对组织不力、敷衍塞责、推诿扯皮，影响工作任务实施进度的单位和个人进行通报，并严肃追究相关责任人的责任。
