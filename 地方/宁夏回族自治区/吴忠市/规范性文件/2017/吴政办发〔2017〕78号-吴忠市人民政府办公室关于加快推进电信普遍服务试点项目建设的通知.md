# 吴忠市人民政府办公室关于加快推进电信普遍服务试点项目建设的通知

各县（市、区）人民政府，市直有关部门、直属有关事业单位，区属驻吴有关单位：

根据《2016年度电信普遍服务补偿试点实施方案》部署，今年全市拟新建电信普遍服务4G基站452座，其中中国铁塔吴忠市分公司承建152座，将于10月底接受国家工信部、财政部、扶贫办验收考核；城际铁路和银西高铁途径利通区、青铜峡市、红寺堡区、盐池县沿线205座，须于2018年1月底前完工。近期，市政府分管领导对电信普遍服务、银西高铁吴卫城际沿线移动通信基础设施建设情况进行专项调研，汇总梳理共有29处基站站点推进速度缓慢，建设困难。为确保项目按期完工，现将有关事项通知如下：

一、要切实提高思想认识。电信普遍服务是贯彻落实党中央、国务院关于农村通信基础设施建设发展的重要部署，也是推进农村宽带发展、助力网络强国建设的重要行动，城际铁路和银西高铁是国家大型重点项目及自治区60大庆献礼工程。各县（市、区）、各有关部门一定要高度重视，尽快成立工作组，召开会议，针对各区域基站存在问题，制定工作方案，细化责任，明确时序进度，切实抓好落实，并于9月底前将落实情况报市政府办公室（市行政中心407室）。

二、要全力促进项目开工。目前全市拟新建452座4G基站中仍有172个未开工，其中电信普遍服务移动通信基站站点17个，这些项目将严重影响总体进度和验收考核工作。各县（市、区）要尽快梳理影响项目开工的突出问题，排除困难，抓紧解决，确保各基站在9月底前全部开工建设。

三、要积极解决突出问题。各县（市、区）、各有关部门要坚持问题导向，加强群众思想教育，引导信教群众科学认识电磁辐射，切实解决阻工、挡工等突出问题。要全力支持吴忠铁塔公司加快5G、室内分布、微站在全市核心商圈、中高档小区、车站、码头等热点区域通信设施建设，确保网络信号全覆盖。市、县两级国土、住建、规划、林业、电力等部门（单位）要主动服务，建立绿色通道，积极解决通信网络建设中规划选址、用地、电力、施工及维护等问题。涉及山地、林地、耕地等占地均按照《自治区人民政府关于公布宁夏回族自治区征地补偿标准的通知》（宁政发〔2015〕101号）文件执行。公安部门要加大对破坏通信基础设施行为打击力度，依法追究恶意挡工和破坏通信基础设施相关人员的法律责任。

四、要切实加强沟通协作。电信普遍服务项目已临近尾声，时间紧、任务重。各县（市、区）、各有关部门要加强沟通，密切配合，完善协调机制，形成工作合力，提升工作效率，推进基站项目建设。10月中旬，市政府督查室将对各县（市、区）、市直有关部门在电信普遍服务项目政策落实、协调问题、任务完成等方面进行督查检查，通报落实情况。
