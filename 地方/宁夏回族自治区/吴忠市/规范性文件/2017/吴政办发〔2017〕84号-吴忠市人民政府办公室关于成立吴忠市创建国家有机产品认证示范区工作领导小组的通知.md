# 吴忠市人民政府办公室关于成立吴忠市创建国家有机产品认证示范区工作领导小组的通知

各县（市、区）人民政府，各开发区、工（农）业园区管委会，市直有关部门：

为加强吴忠国家农业科技园区创建国家有机产品认证示范区工作组织领导，促进创建工作顺利开展，市政府决定成立吴忠市创建国家有机产品认证示范区工作领导小组。现将领导小组组成人员通知如下：

组  长：马玉龙  市政府副市长

副组长：丁  辉  市政府副秘书长

蒋耀强  市市场监督管理局局长

马向东  吴忠国家农业科技园区管委会主任

成  员：张自力  市发改委主任

沙  莉  市科技局局长

拜  萍  市财政局局长

马林华  市国土局局长

苏晓理  市水利局局长

杨晓明  市环保局局长

马长贵  市农牧局局长

杨晓军  市园林局局长

王鹏华  市市场监管局副调研员

王晓明  吴忠国家农业科技园区管委会副主任

领导小组办公室设在吴忠国家农业科技园区管委会，马向东同志兼任办公室主任，王鹏华同志兼任办公室副主任。负责组织协调有关部门制定有机示范区发展规划，协调做好专家评审，负责指导做好有机产品认证示范区的申报和创建工作。

吴忠市人民政府办公室
