# 吴忠市人民政府办公室关于做好2018年民生实事征集工作的通知

各县（市、区）人民政府，各开发区、工（农）业园区管委会，市直各部门、直属事业单位：

经市人民政府研究，决定2018年继续实施为民办实事工程，现就民生实事征集事宜通知如下：

一、基本原则

（一）群众盼望。坚持把群众利益放在首位，把保障和改善民生作为推进经济转型升级和供给侧结构性改革的出发点和落脚点，解决一批群众最关心、最直接、最现实的利益问题。

（二）普遍受益。以人民群众的呼声和意愿为准则，选择办理一批涉及面广、普遍受益、最急需和长期起作用的实事，不断加快富民进程，促进民生普惠，实现成果共享。

（三）财力可行。突出政府在民生实事投入中的主导作用，在财力允许范围内，每年集中大部分新增财力用于改善和促进民生，做到民生实事办理与经济社会发展水平相适应、相匹配。

（四）限期办结。民生实事要具有可操作性，明确具体指标内容，特别是项目类民生实事要明确当年任务量，便于量化考评。需分年度办理的，要明确当年任务量和指标值。

二、征集重点

围绕自治区党委、政府和市委、市政府中心工作，重点从推动创新驱动、脱贫富民、生态立区“三大战略”落实，以及扶弱助困、创业就业、群众安居、社会保障、教育惠民、卫生健康、文化促进、支农惠农、安全保障等方面征集、筛选、确定一批覆盖面广、普惠性强的民生实事。

三、征集形式

（一）各地要通过召开座谈会、专题调研、发放征集表等形式，向人大代表、政协委员、干部群众和社会各界广泛征集。市直各部门（单位）要根据年度项目和资金安排，选取一批具有代表性、全局性，受益面比较广，社会效益显著的实事梳理上报。

（二）市政府办公室通过报纸、电视、网络等媒体发布公告，面向“两代表一委员”、社会各界和广大群众广泛征集2018年民生实事，征集时间为2017年10月17日至10月31日。

（三）坚持把市人大代表建议和政协提案作为选取民生实事的主渠道之一，每年列入民生实事的上年度市人大代表建议和政协提案，原则上不少于当年民生实事总数的30%。

四、几点要求

（一）各地各部门要高度重视2018年民生实事征集工作，认真梳理，突出重点，集中选报，部门（单位）常规性工作不再重复上报。

（二）民生实事要符合我市实际，注重代表性、全局性，选择一批覆盖面广、普惠性强的实事。指标设置要科学严谨、实事求是，既不能保守留底，也不可盲目过大。

（三）各地各部门以正式公文形式，于2017年10月27日前将2018年民生实事征集表(经主要领导签字并加盖单位公章)随文报送市政府办公室（市行政中心418室），电子版文稿发送至wzbzwxx@163.com邮箱。

（四）请市人大常委会办公室和市政协办公室协调安排，从2017年度市人大代表建议和政协提案中，筛选一批涉及面广、普惠性强的实事，于2017年10月27日前反馈市政府办公室。
