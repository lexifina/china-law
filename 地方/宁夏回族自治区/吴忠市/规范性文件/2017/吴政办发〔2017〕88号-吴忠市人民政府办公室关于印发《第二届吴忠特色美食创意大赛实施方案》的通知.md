# 吴忠市人民政府办公室关于印发《第二届吴忠特色美食创意大赛实施方案》的通知

各县（市、区）人民政府，各开发区、工（农）业园区管委会，市直有关部门，直属事业单位：

现将《第二届吴忠特色美食创意大赛实施方案》印发给你们，请认真组织实施。

吴忠市人民政府办公室

2017年10月25日

（此件公开发布）

第二届“吴忠特色美食创意大赛”实施方案

为大力宣传“吴忠特色美食”，实施“吴忠美食”走出去战略，传承、创新“吴忠厨师”烹饪技法，检验“吴忠特色美食技能人才”培养成果，打造“吃在吴忠”美食品牌。结合实际，制定本方案。

一、大赛名称

第二届吴忠特色美食创意大赛。

二、大赛主题

传承饮食文化提升吴忠美食品牌 强化技能人才培训

三、参赛范围

参加“吴忠特色美食技能人才”培养计划并取得职业资格证书人员，市域内从事餐饮烹饪的中式烹饪师、中式面点师和市域外开办餐厅或创办餐饮连锁经营的吴忠厨师。

四、竞赛时间

定于2017年11月2日—11月3日。

五、竞赛地点

吴忠民族美食广场。

六、项目规则

比赛设四个项目，分别为：

1.热菜项目（指定菜品1道、创新创意菜品2道）。

2.凉菜项目（指定菜品2道、创新创意菜品4道）。

3.面点项目（吴忠特色面点面食）。

4.小吃项目（吴忠特色小吃）。

指定菜品是指具有吴忠鲜明特色、知名传统菜肴。竞赛菜品以本地食材为主，符合当地民族风俗习惯。

比赛规则公布于市人力资源和社会保障局网、市就业创业和人才服务局微信公众平台。报名表及作品报告单可从网上下载。

七、奖项设置

大赛设团体奖和单项奖两类，其中：

（一）团体奖：优秀组织奖1个。

（二）单项奖：每个项目设金奖1名、银奖2名、铜奖3名。奖项设置及标准分别为：

金奖：4名，热菜、凉菜项目奖金各10000元；面食面点、小吃项目奖金各8000元。

银奖：8名，热菜、凉菜项目奖金各5000元；面食面点、小吃项目奖金各4000元。

铜奖：12名，热菜、凉菜项目奖金各3000元；面食面点、小吃项目奖金各2000元。

取得竞赛金奖、银奖、铜奖且实操成绩均合格的选手颁发名次荣誉证，纳入吴忠市人才项目库，享受创业扶持政策。

八、报名方式

竞赛采取现场报名和电话报名方式，由市就业创业和人才服务局负责登记报名。各县（市、区）负责组织本辖区参赛选手报名和参赛，选手也可以直接到市就业创业和人才服务局登记报名，市域外参赛选手可通过电话方式先期报名，赛前3个工作日内提供相关资料。报名时需携带本人身份证原件及所在餐饮企业营业执照复印件，填写“第二届吴忠特色美食创意大赛选手报名表”和“第二届吴忠特色美食创意大赛菜品报告单”（一式二份）。竞赛组委会将对参赛人员进行资格审核。

九、报名地点

市人力资源和社会保障局一楼服务大厅（开元大道西544号），报名联系人及电话：王渝惠（0953-2038281）。报名截止日期2017年10月27日18：00。

各有关单位要鼓励动员辖区选手踊跃参赛；各烹饪协会负责通知域内餐饮企业选派选手参赛；吴忠特色美食技能人才培训人员择优参加。参赛人员在参赛期间食宿自理。

第二届吴忠特色美食创意大赛比赛规则

比赛设四个项目，每个项目分别评出个人一、二、三等奖。

1.热菜项目

热菜指定菜品1道，自选菜品2道，菜品要突出市场畅销、技能创新、特色鲜明的特点，现场操作，赛场提供原料，餐具，常用调味品及灶具。操作时限90分钟。

2.凉菜项目

凉菜制作6道（围碟）。其中，指定凉菜2道、自选4道。凉菜制作要求制作精细、美观实用、富有创意。凉菜熟制过程可提前在场外进行，拼摆、刀技造型、口味调整现场操作。操作时限90分钟。

3.面点项目

面点制作2道，制作技法不同，突出地方特色，市场畅销，特色鲜明，色泽鲜艳，原料必须使用本地食材，现场操作。操作时限50分钟。

4.小吃项目

小吃制作1道，突出地方特色，市场畅销，特色鲜明，色泽鲜艳，原料必须使用本地食材，现场操作。操作时限50分钟。

（说明：指定菜品主辅料由大赛组委会提供，自选菜品、面点、小吃项目主料自备）
