# 吴忠市人民政府办公室关于市政府秘书长副秘书长和办公室主任副主任等工作分工调整的通知

各县（市、区）人民政府，各开发区、工（农）业园区管委会，市政府各部门、直属事业单位：

由于人员变动和工作需要，经市政府主要领导同意，现将市政府秘书长、副秘书长和办公室主任、副主任等工作分工调整如下：

马国锋秘书长、办公室主任  在市长、常务副市长领导下，协助处理市政府日常工作。协助市长处理监察、审计等方面的日常工作。主持市政府办公室工作，分管机关事务管理局。

梁  恒副秘书长  协助分管副市长处理科技、国有资产管理、卫生和计划生育、文化体育、广播电视、新闻出版、旅游、文史社科、金融保险等方面工作。分管应急管理科。

丁  辉副秘书长  协助分管副市长处理民政救助、人力资源和社会保障、水务、农牧、园林绿化（林业）、扶贫开发、生态移民等方面的日常工作。分管政务公开科、市志办。

马明军副秘书长  协助分管副市长处理机构编制、财税、国土资源、住建、规划、改革、安全生产、政务服务、公共资源交易、信访和国防动员等方面工作。分管督查室、信息化建设办公室。

刘亚凯副秘书长  协助分管副市长处理发展改革、教育、公安司法、国家安全、环境保护、交通运输等方面工作。分管信息调研科、行政事务科。

夏  琦副秘书长（挂职）  协助分管副市长处理扶贫开发方面工作。

马成义副秘书长  协助分管副市长处理工业经济、信息化建设、民族宗教、商务、经济合作、统计、市场监管、行政审批改革、服务业发展等方面工作。分管政府法制办公室（法制法规科、行政复议科）、外事侨务科。

杨志贵副秘书长  协助秘书长处理政府办公室相关工作。分管政务科。

吴文彪副主任  协助秘书长处理政府办公室相关工作。分管秘书科、文电科。

马文谦党组成员 机关事务管理局局长  主持市政府机关事务管理局全面工作。

马学海副调研员  协助秘书长、分管副秘书长处理政府督查室日常工作。协管政府督查室。

马娟副调研员  协助秘书长、分管副秘书长处理政府法制办公室日常工作。协管政府法制办公室（法制法规科、行政复议科）。

吴忠市人民政府办公室
