# 吴忠市人民政府办公室关于印发《关于进一步加强内部审计工作意见》的通知

市直各部门，直属事业单位，派出机构：

现将《关于进一步加强内部审计工作意见》印发给你们，请认真贯彻落实。

吴忠市人民政府办公室

2017年10月11日

（此件公开发布）

关于进一步加强内部审计工作意见

为进一步加强我市内部审计工作，建立健全内部审计工作机制，更好地发挥内部审计服务改革发展、规范内部管理、促进廉政建设的职能作用，根据《中华人民共和国审计法》《审计署关于内部审计工作的规定》及有关国家法律法规，结合我市实际，提出如下意见：

一、进一步提高对内部审计工作重要性的认识

内部审计是独立监督和评价本单位及所属单位财政收支、财务收支、经济活动真实、合法和效益的行为，以促进加强经济管理和实现经济目标，是国家审计的重要基础和补充，是审计体系的重要组成部分。加强内部审计工作，对于部门单位加强内部管理，防范控制风险，提高管理绩效，促进廉政建设都具有十分重要的意义。部门单位自行开展内部审计工作，由于熟悉行业政策法规和部门工作实际，更有利于及时发现问题，有的放矢分析问题，提出更加符合实际的建议、意见。同时，内部审计结论对内是考核任务目标、兑现奖惩、任免人员的重要依据，对外是审计机关、有关部门或者社会审计组织开展相关工作的参考依据。部门单位要从依法行政、依法管理的高度，深刻认识新形势下加强内部审计的重要性和紧迫性，大力推动内部审计工作，努力为全市经济社会持续健康发展发挥更大的作用。

二、建立健全内部审计制度

（一）加强内部审计力量。各部门、单位都应当按照国家有关规定建立健全内部审计制度，尤其是财政财务收支金额较大或者所属单位较多的部门、单位，管理使用社会公共资金金额较大的事业单位、社会团体、其他组织、国有企业等应当建立健全内部审计制度，并根据本部门单位规模大小、业务性质及实际需求等情况，配备一定数量具有相关执业资格的内部审计人员。

（二）完善内部审计规范。各部门、单位要明确内部审计的组织架构、职能定位、审计内容、审计权限、审计程序、质量控制、审计报告与结果应用等内容，实现内部审计对本单位重要资金、重大项目、下属单位和干部经济责任监督的全覆盖。

（三）明确内部审计责任。各部门、单位主要负责人或相关权力机构应当直接领导内部审计工作，及时研究部署、指导督办内部审计工作的开展。内部审计机构和内部审计人员应当按照国家法律、法规的规定，履行审计职责，组织开展审计事项，报告审计工作。

三、提高内部审计的工作质量和效率

（一）科学定位内部审计重点。各部门、单位应当根据形势要求和自身特点，明确职责定位，突出工作重点，最大程度实现内部审计监督、服务与保障职能。内部审计要将风险防控的关口前移，从事后审计向事前、事中审计转变，推进实现以真实性、合规性为导向的财务审计和以内部控制、风险管理为导向的管理审计同步发展。一是充分发挥内部审计纠错防弊的作用，切实加强对财政财务收支和有关经济活动的审计，加大对中央八项规定落实和“三公”经费管理支出的监督力度，保障公共资金、国有资产、国有资源的安全完整和经济活动的真实、合法、有效。二是充分发挥内部审计推动资产（资源）保值增值的作用，积极开展绩效审计、管理与风险审计，通过揭隐患、促管理、增效益，保障各项政策制度落实，促进单位管理目标的实现。三是充分发挥内部审计保障科学决策的作用，加强对重大决策事项、重大投资项目等全过程跟踪审计，强化对决策民主性、科学性和项目实施规范性以及绩效的监督评价，提高决策水平。四是充分发挥内部审计对权力的监督作用，深化干部经济责任履行情况审计，做到定期轮审、离任必审，形成对权力的长效监督机制，促进领导干部守法、守纪、守规、尽责。

（二）加强内部审计质量管理。各部门、单位应当按照审计法律、法规及内部审计准则等要求，规范内部审计工作，建立完善内部审计质量管理与自我评估机制。积极推进内部审计信息化建设，进一步提高审计工作效率。加强审计资源管理，充分利用单位内部业务资源和相关领域的专家参与内部审计；建立内部审计聘请机制，加强对委托业务的过程控制和后续评价，还要对利用社会审计机构的审计结果形成的内部审计结论负责。

（三）提升内部审计工作价值。各部门、单位要以价值和需求为导向，加强内部审计计划立项、现场实施、报告撰写与成果应用等全过程管理。围绕组织需求，以发现问题、推动解决问题为目标，推广内部审计好的做法和经验。深化细化审计现场实施，坚持揭露问题和深入研判分析并重，做到立说立改，完善制度，充分挖掘现场实施价值。高度重视审计建议，增强审计建议的针对性、操作性、前瞻性，创新内部审计成果应用，完善机制，充分体现审计价值。

四、强化内部审计工作的组织领导和监督指导

（一）加强内部审计工作的组织领导与考核问责。各部门、单位应当加强对内部审计工作的领导，将内部审计工作纳入目标管理内容。要对内部审计机构、审计人员、审计对象、经费保障、相关责任、奖励处罚等做出明确规定，保障内部审计机构和人员履行职责和独立开展工作所必须的权限和条件，解决内部审计工作中遇到的困难和问题；定期研究、部署和检查内部审计工作，听取内部审计机构工作汇报，及时审批年度审计工作计划和审计工作报告；建立健全内部审计结果运用和整改落实机制，督促审计发现问题的整改和综合运用审计成果，切实发挥内部审计的职能作用。相关情况定期在领导干部经济责任审计联席会上通报。

（二）建立健全内部审计工作监督机制。审计机关应当根据《中华人民共和国审计法》、《审计署关于内部审计工作的规定》要求，建立完善对内部审计工作的监督机制，明确负责内部审计的科室和人员，加强与内部审计机构人员的沟通、协调，切实履行对内部审计工作的监督职责。应当加强对各单位建立和开展内部审计工作的指导检查，评估内部审计工作开展情况，纠正内部审计工作存在的问题，依法提出意见和建议。审计机关开展审计

工作时，应当将被审计单位内部审计工作情况作为重要评价内容，对通过内部审计作出的事实清楚、定性准确、结论明确的审计结果，核实后可直接利用。各部门、单位的内部审计工作，接受审计机关的指导和监督，应当主动协助、配合审计机关开展审计工作，定期向审计机关报送内部审计工作情况报告。

（三）加强内部审计队伍建设。审计机关要经常性的开展对内部审计机构人员的业务培训，大力提高内部审计人员的业务水平，可以根据工作需求，组织相关单位内部审计人员承担审计任务或参与专项审计事务。各部门、单位要注重内部审计人员的培养，不断提高内部审计人员的业务素质和理论水平，要求审计人员既要熟悉本部门的行业政策、法规，又要熟悉财经纪律和项目建设等相关知识，能够客观独立地执行内部审计业务。同时能够依法审计，廉洁审计，做到正直坦诚，坚持原则，敢于担当，勤勉尽责，保守秘密。
