# 吴忠市人民政府关于市长副市长和秘书长工作分工的通知

各县（市、区）人民政府，市直各部门、直属事业单位：

因人事变动和工作需要，经市人民政府研究，现对市长、副市长和秘书长工作分工通知如下。

喜清江市长  主持市人民政府全面工作。主管监察、审计等方面工作。

分管市监察局、审计局。

联系市人大常委会、市政协、各民主党派。

张学慧副市长  协助市长负责市政府常务工作，负责机构编制、财税、国土资源、住建、规划、改革、安全生产、行政审批、综合执法、信息化建设、政务服务、公共资源交易、信访和国防动员等方面工作。

分管市政府办公室（法制办公室、外事侨务办公室、应急办）、机构编制委员会办公室、财政局、国土资源局（测绘地理信息局）、住房和城乡建设局（人民防空办公室、综合执法监督局）、规划和城市管理局、安全生产监督管理局、住房公积金管理中心、政务服务中心（公共资源交易中心）、机关事务管理局、信息化建设办公室。

联系市信访督办局、档案管理局，吴忠市国家税务局、地方税务局。

廖允成副市长  协助市长负责民政救助、人力资源和社会保障等方面工作。

分管市民政局、人力资源和社会保障局。

联系吴忠军分区、预备役团，市残疾人联合会。

薛丹副市长  协助市长负责科技等方面工作。

分管市科技局（地震局、知识产权局）。

联系市科学技术协会。

马中勇副市长    协助市长负责文化体育、广播电视、新闻出版、卫生和计划生育、医保、旅游、文史、社科等方面工作。

分管市文化体育新闻出版广电局、卫生和计划生育局、旅游局、广播电视台。

联系市老干部局、吴忠日报社、文学艺术界联合会。

杨金海副市长  协助市长负责工业经济、民族宗教、商务、统计、市场监管、经济合作、服务业发展等方面工作。

分管市工业和信息化局（非公有制经济服务局）、民族宗教事务局、商务局、统计局、市场监督管理局（工商行政管理局、质量技术监督局、食品药品监督管理局、食品安全委员会办公室）、经济技术合作局、服务业促进局、太阳山开发区、金积工业园区。

联系青铜峡新材料基地、市工商业联合会、伊斯兰教协会，国家统计局吴忠调查队、吴忠供电公司、烟草专卖局、中国电信吴忠分公司、中国移动吴忠分公司、中国联通吴忠分公司、中国铁塔吴忠分公司。

王天军副市长  协助市长负责发展改革、公安司法、国家安全、环境保护、交通运输、健康产业发展等方面工作。

分管市发展和改革委员会（物价局、内陆开放型经济试验区领导小组办公室）、公安局、司法局、环境保护局、交通运输局（交通战备办公室）。

联系市中级人民法院、人民检察院，武警吴忠市支队、消防支队、吴忠国家安全局、邮政管理局、邮政公司、道路运输管理局、宁夏公路管理局吴忠分局、中国石油天然气吴忠分公司。

马玉龙副市长  协助市长负责水务、农牧、园林绿化（林业）、扶贫开发、生态移民等方面工作。

分管市水务局（防汛抗旱指挥部办公室）、农牧局、园林管理局（林业局）、扶贫开发办公室、吴忠国家农业科技园区。

联系市气象局、粮食局、秦汉渠管理处、盐环定管理处。

王慧仙副市长  协助市长负责教育等方面工作。

分管市教育局、宁夏民族职业技术学院。

联系市总工会、团市委、市妇联。

宋海燕副市长  协助市长负责国有资产管理、金融保险等方面工作。

分管市国有资产监督管理委员会、金融服务办公室、城乡建设投资开发有限公司、国有资本运营有限公司、开源扶贫担保有限公司、水务投资有限公司、交通投资开发有限公司、现代农业扶贫开发投资有限公司、文化旅游产业投资有限公司、中小微企业创业投资有限公司。

联系吴忠银监分局、人行吴忠中心支行、建行吴忠分行、工行吴忠支行、农行吴忠分行、农发行吴忠分行、中行吴忠分行、吴忠农村商业银行、邮储银行吴忠分行、宁夏银行吴忠分行、滨河村镇银行、石嘴山银行吴忠分行，人保财险、人寿保险吴忠分公司等保险机构。

宋海燕副市长  挂职期间，其分管、联系工作由张学慧常务副市长代管、联系。

马国锋秘书长  在市长、常务副市长领导下，协助处理市政府日常工作。主持市政府办公室（法制办公室、外事侨务办公室、应急办）全面工作。

为提高政府工作效能，确保各项工作高效有序运转，市政府副市长实行AB岗工作制。张学慧、杨金海AB岗，廖允成、马玉龙AB岗，薛丹、马中勇AB岗，王天军、王慧仙AB岗。

吴忠市人民政府

2017年7月7日
