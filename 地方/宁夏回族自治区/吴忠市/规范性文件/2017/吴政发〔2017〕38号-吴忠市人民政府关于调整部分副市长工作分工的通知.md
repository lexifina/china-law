# 吴忠市人民政府关于调整部分副市长工作分工的通知

各县（市、区）人民政府，市直各部门、直属事业单位：

因人事变动和工作需要，经市人民政府研究，现将部分副市长工作分工调整如下：

原由杨金海副市长协助市长负责的商务、经济合作工作调整由何其雄副市长协助负责。原由杨金海副市长分管的市商务局、经济技术合作局调整由何其雄副市长分管。

其他分工不变。

为提高政府工作效能，确保各项工作高效有序运转，市政府副市长实行AB岗工作制。张学慧、宋海燕AB岗，廖允成、马玉龙AB岗，薛丹、马中勇AB岗，何其雄、杨金海AB岗，王天军、王慧仙AB岗。

吴忠市人民政府

2017年8月28日
