# 关于贯彻落实《宁夏回族自治区降低实体经济企业成本实施意见》的通知

各县（市、区）人民政府，市直各部门，区属驻吴单位：

为全面贯彻落实《宁夏回族自治区降低实体经济企业成本实施意见》（宁政发〔2017〕1号，以下简称“降成本30条”），有效降低实体经济企业成本，优化企业发展环境，助推企业转型升级，进一步提升产业竞争力，促进经济持续稳定增长。现将贯彻落实“降成本30条”有关事项通知如下：

一、加强组织领导。成立由市政府主要领导任组长，分管领导任副组长，各县（市、区）、各有关部门主要负责同志为成员的吴忠市落实自治区“降成本30条”工作领导小组（见附件1），领导小组下设办公室，杨金海副市长任办公室主任，具体工作由市工信局承担。领导小组定期对各县（市、区）、各行业政策落实情况进行督查，协调解决落实政策相关问题。

二、落实工作责任。市政府已将“降成本30条”政策逐一细化分解（见附件2），各县（市、区）、各牵头单位要切实承担起“降成本30条”工作第一责任单位的主体责任，按任务分工，制定详细的工作方案，抓紧落实，并于2月10日前报领导小组办公室（市行政中心321室），每月5日前报送前一月政策落实情况。

三、加强宣传引导。领导小组办公室负责邀请自治区相关部门领导、专家来吴召开“降成本30条”政策解读专题宣讲会；在吴忠日报开辟宣传专栏，全文刊发“降成本30条”文件。各县（市、区）要充分利用政府门户网站的影响力，加强政策信息发布；各行业主管部门要通过网站、微信公众号、手机报等宣传平台，扩大宣传覆盖面和影响力。

四、强化督促检查。市委督查室、政府督查室要每季度开展一次“降成本30条”落实情况督查，将督查结果报市委、市政府。领导小组每季度召开一次政策落实情况推进会，领导小组办公室按期整理汇总全市落实情况报告，及时上报自治区政府及相关厅局。
