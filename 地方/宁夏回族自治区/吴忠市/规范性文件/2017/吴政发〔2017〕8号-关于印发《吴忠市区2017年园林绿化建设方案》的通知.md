# 关于印发《吴忠市区2017年园林绿化建设方案》的通知

利通区人民政府，市直有关部门（单位），区属驻吴有关单位：

《吴忠市区2017年园林绿化建设方案》已经市人民政府研究同意，现予以印发给你们，请结合实际，认真组织实施。

吴忠市人民政府

2017年2月13日

吴忠市区2017年园林绿化建设方案

为了加快滨河生态水韵城市建设步伐，提高市区园林绿化水平，积极创建国家森林城市，改善人居环境，促进城市可持续发展，根据《自治区党委  人民政府关于加强城市规划建设管理工作的实施意见》（宁党发〔2016〕27号）、吴忠市委、市政府的总体部署和市区园林绿化工作实际，经过调查研究，制定本方案。

一、总体思路

按照全市第五次党代会确定的加快绿色发展，建设绿色经济示范市，全面建成小康社会的奋斗目标，立足市区绿化实际，坚持“建管并重，量质并举，建改结合，全面提升”的工作思路，全力推进新建道路配套绿化建设，在城市建成区面积和人口增长的同时，实现绿地面积的同步增长，保证各项绿化指标稳中有升；分批实施公园绿地的提质增景改造，逐步完善公园绿地的基础设施，合理调整植物配置结构，不断提升公园绿地的服务功能和景观效果；启动国家森林城市创建活动，编制创建总体规划，对照创建标准，找准差距，补齐短板，以创建促工作，努力实现城市绿化面积的拓展、绿地质量的提高和管养水平的提升，促进城市生态、经济、政治、文化和社会协调发展。

二、建设目标

新建城市绿地430亩，改造提升城市绿地624亩，安装节灌850亩，恢复绿地120亩。市区新增城市绿地430亩，城市绿地总面积达到36600亩，城市建成区绿地率、绿化覆盖率、人均公园绿地面积分别达到40.7%、41.9%和20.1平方米。

三、建设任务

（一）完成8条新建道路绿化建设，面积430亩。

1.朔方路（利红街至东环路）绿化：长1394米，道路两侧各规划2行行道树和50米宽绿化带，绿化面积160亩。绿化设计与利红街以西已建成段一致，行道树树种选择国槐，株距6米；绿化带植物配置从前到后由低到高分三层设计，第一层为12米宽色带造型和花灌木带，选用榆树、金叶榆、紫叶矮樱组成绿、黄、红三色波纹状植物造型，与丁香花灌木带相互镶嵌；第二层为10米宽红太阳李、红宝海棠和樟子松间隔行列式种植的色叶、常青树带；第三层为28米宽旱柳背景树带，地被种植三叶草，形成层次分明、色彩丰富的道路绿化景观。

2.秦渠路（秦汉街至开元大道）绿化：长1371米，道路两侧各规划2行行道树，北侧规划15米宽绿化带，南侧规划50-80米宽绿化带，绿化面积162亩。行道树树种选择刺槐,株距6米；绿化带从前到后依次为丁香、榆叶梅花灌木带，樟子松常青树带，旱柳背景树带，地被种植紫花苜蓿。

3.政通路（蒙恬路至秦汉街）绿化：长1200米，道路两侧各规划2行行道树、4米宽分车带和20米宽绿化带，绿化面积86亩。行道树树种选择馒头柳，株距6米；分车带以金叶榆、紫叶矮樱、侧柏形成色彩鲜明的色块图案；绿化带以樟子松、香花槐、国槐、连翘、贴梗海棠、碧桃等乔、灌木大组团种植为主，地被种植宿根花卉和草坪。

4.纬七路（滨河大道至开元大道）绿化：长1154米，道路两侧各规划1行行道树，绿化面积5.3亩。行道树树种选择垂柳，株距6米。

5.纬五路（清宁街至文化街）绿化：长721米，道路两侧各规划1行行道树，绿化面积3.2亩。行道树树种选择国槐，株距6米。

6.材机厂南路（利华街至利红街）绿化：长931米，道路两侧各规划1行行道树，绿化面积4.2亩。行道树树种选择国槐,株距6米。

7.人和路（蒙恬路至秦汉街）绿化：长1180米，道路两侧各规划1行行道树，绿化面积5.3亩。行道树树种选择刺槐,株距6米。

8.翔庆路（学院路至庆王路）绿化：长900米，道路两侧各规划1行行道树，绿化面积4亩。行道树树种选择河北杨，株距6米。

（二）完成6条新建道路绿化土方填换和节灌安装，面积850亩。

根据市政道路施工进度，计划在2017年内完成春季不具备施工条件的回乐路、新民路、金积大道、344国道、利华街北段、利红街北段等6条道路两侧绿化带土方填换和节灌安装建设任务，建设面积850亩。预计清理渣土15万方，回填土方46万方，打井、接电8处，安装节灌56万平方米。

（三）市区公园、广场服务设施配套项目。

按照“以人为本、提升市民生活质量”的根本宗旨，计划在明珠公园、体育公园、盛元广场、新月广场等市区主要公园、广场内安装园灯488套，电子灭蚊器322个，座椅坐凳816套，垃圾箱670个，维修破损的园路、广场面砖7000平方米，粉刷彩绘园林小品6处。通过配套完善基础功能设施，提升市区园林绿化水平，为广大市民营造良好的休闲、健身和娱乐环境。

（四）滨河市民休闲森林公园2017年度建设任务。

滨河市民休闲森林公园是我市落实《自治区人民政府办公厅印发关于加快市民休闲森林公园建设意见的通知》（宁政办发〔2013〕156号）文件要求，按照“统筹整合、补充完善、改造提升”的总体思路，将城市西区现有水系、绿地、景点规划改造建设的一个大型森林公园。公园规划总面积12675亩，估算总投资1.66亿元。截至2016年年底，公园主要建设任务已经完成。2017年计划对市发改委原批复的《吴忠市滨河市民休闲森林公园初步设计》进行优化和调整，集中资金抓亮点建设，重点完成智园、清丽园、庆华园、两馆一中心的景观改造提升建设，进一步提升公园建设效果。2017年规划建设总面积624亩。其中：智园改造面积24亩，规划将废弃的游泳池、沙滩、攀岩场地打造成一处牡丹专类园，引进栽植适宜本地气候条件的紫斑、粉丹、大乔、二乔、金背大红、芙蓉、黑牡丹、紫牡丹等八个品种的牡丹，分区栽植，提高森林公园的景观效果。清丽园和庆华园改造面积400亩，规划充分利用现有水系和已经成型的森林景观，铺设健身步道，增加亲水平台和木质栈道，补植水生植物和宿根花卉，提升公园绿地的服务功能和景观效果。结合清丽园的绿化景观改造，积极响应亚洲风景园林协会女风景园林师分会在西北地区修建母子公园的号召，在清丽园东北角建设一处占地30亩的“园中园”—“母子公园”，以“亲子、和谐”为主题，倡导“母子和谐”、重视“亲情·感恩”的教育理念，呼吁社会对关爱儿童健康成长给予更多的关注，进一步实现生态环境优化与亲子教育的有机结合，形成吴忠市独具特色的城市森林母子公园，打造具有独特魅力的生态旅游城市名片。两馆一中心改造面积200亩，计划对现有退化草坪进行更新种植，清换表层种植土，改造节灌设施，铺种成品草坪，提升景观档次和效果。

（五）供热管道占用绿地恢复建设和市区绿地苗木补植。

对热电厂供热管道施工占用的开元大道、富平街、友谊路、卫宁路等道路绿化带进行恢复建设，建设面积120亩。对市区现有绿地缺株苗木进行补植，补植各类绿化苗木、花卉85万株。

（六）北片区道路绿化水源井开凿建设。

自2016年热电厂投产以来，市区中水主要供应热电厂生产，无法保障北片区道路绿化正常供水，为解决绿化灌溉水源问题，2017年计划在北片区的河奇路、世纪大道、利宁街、利红街道路绿化带内开凿深水井8眼，安装变压器8台，作为绿化灌溉补充水源使用。

（七）金积工业园区绿化补植。

对金积工业园区的伊佳路西段、伊利路西段、金麦尔街南延伸段、工业大街东延伸段、伊利路等5条道路和企业服务中心院内进行补植和提质增绿建设，建设面积200亩，栽植各类绿化苗木1.6万株，种植草坪0.7万平方米。

（八）采购和摆放鲜花。

按照市委、市政府重大活动的安排和“五一”、“十一”等节日氛围营造的需要，计划采购鲜花20万盆在重要地段予以摆放，烘托气氛。

（九）启动创建国家森林城市。

认真贯彻全市第五次党代会精神，以生态文明理念为引领，积极践行“让森林走进城市、让城市拥抱森林”的宗旨，在2017年启动吴忠市国家森林城市创建活动，以创建工作为抓手，努力提升以园林绿化为主要内容的城市基础设施水平，进一步推进美丽吴忠建设。按照《国家森林城市评价指标》相关规定，计划2017年编制完成《吴忠市森林城市建设总体规划》，经审议后颁布实施，报请国家林业局批准，正式启动国家森林城市创建活动，2019年初步达到验收条件，2020年正式申请国家林业局组织验收。

四、任务分工

市发改委：做好项目审批、立项协调等工作。

市财政局：做好建设资金筹措等工作，并按照绿化工程建设进度及时拨付建设资金。

市国土资源局：负责绿化用地的调整落实，并完成绿化土地征（租）用、绿化用地审批等工作。

市环境保护局：负责办理绿化项目建设环境影响评价手续。

市住房和城乡建设局：负责完成绿化用地（国有土地）附着物拆迁、补偿等工作。

市审计局：负责各绿化工程的审计监督工作。

市园林管理局：1.负责各绿化工程的规划设计、技术指导、综合协调、检查验收等工作；2.负责完成朔方路、秦渠路、纬七路、纬五路、材机厂南路、翔庆路等6条道路绿化建设任务；3.负责完成回乐路、新民路、金积大道、344国道、利华街北段、利红街北段等6条道路两侧绿化带土方填换和节灌安装建设任务；4.负责完成市区公园、广场服务设施配套项目建设；5.负责完成滨河市民休闲森林公园2017年度四园改造建设任务；6.负责完成供热管道占用绿地恢复建设和市区绿地苗木补植建设任务；7.负责完成北片区道路绿化水源井开凿建设任务；8.负责完成20万盆鲜花采购和摆放任务；9.负责筹备国家森林城市创建相关工作。

市规划和城市管理局：1.负责按照城市总体规划要求，确定绿化建设项目位置、四至界限和建设规模，协调配套供电、供水、排水等基础设施；2.负责办理绿化建设项目规划选址手续。

市供电公司：负责深水井水泵设施供电工作。

市城乡建设投资开发有限公司：负责协调接通绿化灌溉水源。

利通区政府：1.配合市国土资源局完成涉及各乡镇的绿化用地的调整、征租等工作；2.负责完成绿化用地（集体土地）附着物拆迁、补偿等工作；3.负责完成辖区内政通路、人和路绿化土地征用和绿化建设任务。

金积工业园区管委会：负责完成金积工业园区伊佳路西段、伊利路西段、金麦尔街南延伸段、工业大街东延伸段、伊利路等5条道路和企业服务中心院内绿化补植和提质增绿建设任务。

吴忠日报社、市电视台：制定宣传方案，及时宣传报道市区园林绿化工作，通报绿化情况及建设进度。

市委督查室、市政府督查室：对各部门、各单位承担工作完成情况进行监督检查，及时通报工作进展，督促各部门、单位按期完成工作任务。

七、实施计划

（一）准备部署阶段。

2016年11月15日—2017年3月20日。进行基础调查、现状测量，编制项目可研报告和初步设计，绘制规划设计图纸，制定实施方案；完成绿化建设用地的征用、租用和地上建筑物、附着物的拆迁和补偿工作；完成规划设计图纸审定、立项批复，工程招标等工作。

（二）组织实施阶段。

第一步：2017年3月21日—6月30日。开展春季绿化大会战，完成8条新建道路绿化土方填换、节灌安装和绿化种植、市民休闲森林公园绿化改造种植等建设任务，完成市区公园、广场服务设施配套、硬化铺装、设施维修等所有建设任务。

第二步：2017年7月1日—11月15日。根据市政道路完工情况，分批完成新建6条道路绿化土方填换和节灌安装任务。

（三）养护管理阶段。

2017年春季完成绿化建设任务后，按照《吴忠市区城市园林绿化养护管理质量标准及技术要点》（试行）的相关要求，适时进行浇水、施肥、除草、病虫害防治等养护管理工作。

八、工作措施

（一）提高认识，加强领导。市直各部门、各单位要充分认识城市园林绿化的重要意义，把思想认识统一到市委、市政府的决策部署上来，一把手负总责，全单位总动员，精心安排部署，组织干部职工，团结一致，坚定信心，投身园林绿化建设。各部门、各单位既要密切配合，相互协作，又要按照任务分工，各负其责，各司其职，调动一切积极因素，挖掘各方面潜力，克服困难，千方百计完成园林绿化任务。

（二）严格审批，规范招标。市区绿化建设项目要严格遵守和执行《吴忠市政府投资项目管理和责任追究办法》关于项目审批、报建等基本建设管理的程序和相关规定，杜绝未批先建或擅自扩大审批规模、改变建设内容、增加资金投入等违规现象的发生。要严格实行工程招标投标制度，本着“公开、公正、公平竞争”的原则，委托专业招标代理中介严格按照建设工程招投标程序办事，实行网上发布公告和网上公开报名，在招标文件编制、投标人资格审查、开标等诸多环节上要严格把关，市招标办、监察局、发改委、财政局、审计局、规划局要派人全程参与监督整个招标评标过程，争取最优秀的施工单位通过竞争获得施工资格。

（三）严格把关，确保质量。各部门、各单位要牢固树立质量第一的思想，严格按照规划设计、操作技术规程和施工要求建设。市园林局要积极发挥业务部门的职能作用，在各单位绿化工作开展过程中，切实加强技术指导，制定建设标准，成立绿化工程质量督导组，分小组对各单位绿化质量进行跟踪检查指导，坚持指导在一线、督查在一线、管理在一线。严格按照苗木质量标准，选择无伤、无病虫、根系及树干新鲜无失水现象的优质苗木，剪除挖、运过程中已折断的树枝、树根，按要求挖坑、填换土方，树木必须栽正，栽植后立即灌透水，对不耐寒的树种可采取基部培土、涂白、绑扎防寒物、涂保护剂及搭设防风障等措施加以保护。在招标工程建设中，委托专业监理单位，认真履行工作职责，从严从细切实把好整地关、种苗质量关、栽植关、管护关和验收关，全面提高绿化工程建设质量和水平。对已建成的绿地，实行绿地长效管理机制，根据地段、位置划分养护等级，推行“三定两查一评比”制度，即：定管护面积、定管护绿地等级、定绿地管护质量标准；定期或不定期地随机检查抽查；实行百分制考核，对管护绿地效果进行评定，年终公布考核结果，切实加强市区绿地的管护水平，确保建成一片、管好一片，出精品、塑形象。

（四）严格考核，落实奖惩。绿化工程施工期间，市委督查室、市政府督查室要加大监督检查力度，定期不定期地深入施工一线，进行明察暗访，了解掌握各部门、各单位任务完成情况，及时通报工作进展，指出存在的差距和问题，督促其改进完善工作。适时组织观摩学习，在媒体上广泛宣传报道，营造你追我赶、争先恐后的竞争氛围。严格实行绿化工作一票否决制，对没有保质保量完成绿化任务的单位，要通报批评、媒体曝光、追究领导责任。
