# 吴忠市人民政府办公室关于市政府2018年度重点督查事项的通知

各县（市、区）人民政府，各开发区、工（农）业园区管委会，市政府各部门、直属事业单位：

为切实推动区、市政府决策部署贯彻落实，确保市政府2018年度各项目标任务按期按要求完成，根据自治区政府《2018年督查工作要点》，结合我市工作实际，梳理制定了《吴忠市人民政府2018年度重点督查事项》。各责任单位要紧盯任务，明确责任，确保2018年各项工作落到实处。

一、加强组织领导，切实落实责任

各县（市、区）、各部门（单位）要按照“一分部署，九分落实”的要求，把落实市政府年度重点督查事项列入重要议事日程，扎实履行抓落实主体责任，主要负责同志要切实担起抓落实“第一责任人”职责，对照年度重点督查事项，细化任务，完善措施，切实抓好督查事项落实，为推动市政府各项工作落实创造良好环境。

二、强化统筹协调，形成督查合力

《吴忠市人民政府2018年度重点督查事项》由市政府牵头组织，各县（市、区）人民政府和市政府有关部门配合参与，采取现场督查、查阅资料等方式进行。各相关部门根据《市政府2018年度重点督查事项》确定的督查内容和时限，配合制定专项督查方案，提前衔接督查事宜，并抽调专人参与督查，确保专项督查活动顺利进行。每项工作督查结束后，市政府督查室将对督查结果进行通报，并对需要整改的工作进行跟踪督查和抽查复核，确保整改到位。对未列入市政府2018年度督查重点的工作，确需市人民政府组织进行专项督查的，相关部门要以正式文件报请市人民政府办公室进行督查立项，经市政府审批同意后，由市政府督查室组织实施。

三、严格考核问责，提高督查实效

督查工作坚持问题导向，建立问题台账，开展精准督查、靶向督查和清单督查，坚持一督到底、跟踪问效。督查结果与全市效能目标考核挂钩，对工作落实不力的予以通报批评、限期整改，并在年度效能目标考核中扣除相应分值；对整改不到位或在贯彻落实重大决策部署中存在突出问题的，提请市政府进行约谈；对因“庸、懒、散、拖”或不作为、慢作为、乱作为造成区、市政府决策部署和重点工作、重大项目落实不到位或者严重滞后的，将按照有关规定严肃问责。
