# 吴忠市人民政府办公室关于政府网站检查抽查情况的通报

各县（市、区）人民政府，各工（农）业园区管委会，市直各部门、直属事业单位：

近期，自治区人民政府办公厅依据《政府网站与政务新媒体检查指标》（国办秘函〔2019〕19号），对全区政府网站开展了监测检查，并将发现问题进行反馈，要求限期整改。同时，我办组织对政府网站进行了抽查。现将有关情况通报如下：

一、存在问题

（一）公开信息出现严重表述错误。利通区、红寺堡区、青铜峡市、盐池县、同心县政府门户网站以及市人社局、交通运输局、文化旅游体育广电局、政务服务中心、原园林管理局5个部门在市政府门户网站上发布的个别信息、文件，被自治区检测出严重表述错误。

（二）公开信息隐含外链（暗链、伪链、商业网站）。利通区、红寺堡区、青铜峡市、盐池县、同心县政府门户网站以及市司法局、人社局、交通运输局、商务和投资促进局、文化旅游体育广电局、市场监管局等部门在市政府门户网站上发布的个别信息、文件，被自治区检测出隐含外链（暗链、伪链、商业网站）。

（三）公布不宜公开文件。个别部门对公文公开属性界定不准确，将请示报告、征求意见复函等文件确定为主动公开文件，在市政府门户网站公开。市交通运输局将信访维稳工作方案确定为主动公开文件，在市政府门户网站公开。

二、工作要求

各县（市、区）、各部门（单位）要进一步提高责任意识，树牢大局观念，完善工作机制，扎实做好政府信息公开工作，确保今年我市政务公开工作取得新成效。

（一）全面自查，严肃整改。本次被自治区通报的五县（市、区）政府和市人社局、交通运输局、文化旅游体育广电局、政务服务中心等部门，要认真分析问题原因，按要求整改到位并举一反三全面自查所有已发布信息。各县（市、区）、各部门（单位）要引以为戒，对照《政府网站与政务新媒体检查指标》，对政府网站和政务新媒体已公开信息开展自查，发现问题、立即整改，自查整改情况6月4日前报市政府政务公开办公室。

（二）完善制度，明确责任。各县（市、区）、各部门（单位）要参照《自治区人民政府办公厅关于进一步规范公文标识政府信息公开属性有关事项的通知》（厅发〔2017〕117号），建立完善公文公开属性标识工作制度，准确标识公文公开属性。健全落实公开信息审核、发布、抽查等机制，明确工作人员、主管部门、分管领导责任，严格落实政府网站信息保密性审查和内容审核工作机制，进一步规范政府网站上传信息内容，确保上传信息准确、合规。

（三）注重时效，提高效能。各县（市、区）、各部门（单位）要坚持“公开为常态，不公开为例外”原则，依法全面、准确、及时公开本部门（单位）政府信息，确保政府门户网站各栏目的内容按时更新，及时办理政府信息公开申请和网民咨询，充分发挥好政府网站“窗口”作用。

本次给予五县（市、区）政府和市人社局、交通运输局、文化旅游体育广电局、政务服务中心等部门通报扣分，并责令限期整改。今后凡是工作不重视，被自治区通报的，一律提请给予单位主要领导和分管领导问责处理。
