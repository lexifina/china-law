# 吴忠市人民政府办公室关于印发《吴忠市高质高效招商引资三年行动方案（2019年-2021年）》的通知

各县（市、区）政府，各开发区、工（农）业园区管委会，市直各部门、直属事业单位，各人民团体，区属驻吴各单位：

《吴忠市高质高效招商引资三年行动方案（2019年-2021年）》已经市政府研究同意，现印发给你们，请认真抓好落实。

吴忠市人民政府办公室

2019年7月5日

（此件公开发布）

吴忠市高质高效招商引资三年行动方案

（2019年-2021年）

为全面贯彻落实习近平新时代中国特色社会主义思想，牢固树立新发展理念，进一步凝聚招商引资合力，推动产业转型升级和提质增效，增强经济发展的动力和活力，推进吴忠市经济社会实现高质量发展。根据《宁夏2019年-2021年高质高效招商引资三年行动计划》等文件精神，结合吴忠市实际，特制定本行动方案。

一、主要目标

2019－2021年，力争招商引资到位资金累计突破1000亿元，年均增长8%左右，其中，服务业投资额不低于总任务的10%；年均引进10亿元以上项目10个，20亿元以上项目5个；外来投资三次产业结构进一步优化，投资和营商环境进一步改善，外来投资质量和效益进一步提高。

二、重点招商区域和产业方向

围绕工业提质扩量、农业提档增效、服务业提速升级，以全市六个工（农）业园区为主要承接载体，瞄准装备制造、新材料、生物医药、能源化工、现代农业、现代服务业、现代纺织七大产业开展招商活动。

（一）京津冀区域。重点围绕制造业阶梯式退出、生物医药产业转型转移、精细化工产业改造升级，开展现代装备制造、生物医药、新材料、节能环保、石油化工、现代中药、绿色食品加工等专题招商。

（二）长三角区域。重点围绕劳动密集型、资源密集型产业转移项目，开展汽车零部件、智能仪器仪表、机械加工、金属（铝）制品加工、纺织服装、化工、新材料等产业招商。

（三）珠三角区域。重点抢抓产能梯度转移、企业抱团转移、战略性产业转移增多的机遇，大力开展现代农业、服装加工、纺织产业、文化旅游、大健康等产业招商。

（四）中部地区（湖南、湖北、山东、河南）。重点开展农业特色产业、制造业、油气化工和煤化工下游产业招商。

三、行动计划

（一）装备制造产业招商行动。以吴忠金积工业园装备制造功能区、青铜峡工业园区杭萧汽车零部件产业基地、金银滩特种汽车装备制造小镇为载体，重点引进智能仪表、智能控制阀、高端铸造、专用精密轴承、农机装备、汽车生产及零配件、特种车辆改造生产等制造企业投资建设生产和研发基地，着力发展铸造、制造产业，建成中高端自动化仪表技术研发基地、西部一流的轴承基地，将吴忠市打造成我国西部重要的装备制造产业基地。每年在京津冀、长三角、珠三角等区域开展不少于5次装备制造产业招商活动。（责任单位：市工信局、商务和投资促进局，金积工业园区、青铜峡工业园区、太阳山开发区）

（二）新材料产业招商行动。借助青铜峡市和太阳山开发区的铝、镁资源优势，重点引进青铜峡铝业集团、宁夏太阳镁业、金昱元化工、嘉华化工等骨干企业的下游公司，投资高端建筑型材（模板）、汽车轮毂、医用铝箔、铝镁合金、碳化硅、特种活性炭、工程塑料制品等项目，开发高性能镁铝合金生产技术，大力推进镁铝合金和铝的多品种化生产，培育壮大先进金属材料、化工新材料、新型节能环保建筑材料、先进复合新材料产业，打造现代化新材料产业基地。每年在东部沿海地区开展不少于5次新材料产业招商活动。（责任单位：市工信局、商务和投资促进局，太阳山开发区、青铜峡工业园区）

（三）生物医药产业招商行动。以太阳山开发区生物医药产业园和利通区健康产业园为载体，重点引进原料药及制剂、中成药及中药饮片、药用包装、医疗器械及设备等方面的国内大型或高端生物医药企业，加快发展以中药饮片、中药提取物、中药制剂为主的医药产业和以健康信息服务、康复护理、健康养老为主的康养产业。发挥同心县、红寺堡区、盐池县优质中药材种植基地优势，引进高附加值的氨基酸、功能性低聚糖、枸杞保健食品等功能性食品和保健品项目。抢抓山东、河北、江苏等地医药企业转型转移的时机，每年开展不少于3次生物医药产业专题招商活动。（责任单位：市商务和投资促进局，太阳山开发区）

（四）能源化工产业招商行动。充分利用石油和天然气储量大的优势，加强与中石油、中石化的合作，引进资金和技术，稳步推进煤油气产能建设。紧盯京津冀、长三角等重点区域的能源化工企业，重点引进油气化工、煤化工产业链向下游延伸的精加工项目，提升煤炭、油气资源来源地加工附加值，推动煤、油、气产业融合发展，形成以煤化工和油气化工为主导的两个百亿新兴化工产业集群。每年开展小分队（驻点）招商4批次。（责任单位：市商务和投资促进局，太阳山开发区、盐池工业园区）

（五）现代农业招商行动。围绕乡村振兴战略、农业农村综合开发，引进休闲观光农业示范园等项目，大力发展功能农业、休闲采摘、健康养生、拓展训练等新型休闲农业，推进农业与旅游、文化等产业深度融合，聚力打造宁夏农业高质量发展先导区。发挥孙家滩国家农业科技园区、五里坡养殖基地示范带动作用，引进国内知名企业参与开发或与本地企业合作，突出规模化、科学化、全产业链模式，稳步扩大奶牛、肉牛、羊养殖规模，提升传统养殖业水平。突出建设产业主产区，做强奶产业、肉牛、滩羊、葡萄酒、胡麻籽油、枸杞、富硒大米、黄花菜等优势特色产业，引进国内高端农业加工和品牌营销企业，重点围绕塑造品牌、提升品牌影响力和市场占有率，着力提升吴忠优质农副产品经济效益和品牌价值，形成种养、加工、销售完整的闭环产业链。每年开展3批次葡萄酒品鉴、美食品尝等宣传推介招商活动。（责任单位：市农业农村局、商务和投资促进局，各县（市、区））

（六）现代服务业招商行动。以全域旅游为引领，主动承接银川都市圈物流服务、休闲养生等功能，围绕传统商贸服务业转型升级、电子商务创新发展、“吃在吴忠”品牌推广等重点，大力引进第三方物流、供应链管理、品牌推广、健康养生等企业，提升服务业发展水平，力促生产服务、流通服务向专业化、高端化延伸。壮大会展业市场主体，引进国际化、国家级和行业内知名展览及会议来吴举办，着力培育绿色食品、葡萄酒等专业性展会，推进展馆多元化经营，延长展会产业链。大力引进休闲农庄、田园综合体、农业主题公园、影视制作等融合发展项目，开发提升精品旅游线路，打造“吃、住、行、游、购、娱”的旅游全产业链和西部特色旅游目的地。每年利用区内外重要展会与节会开展不少于3次现代服务业专题招商推介活动。（责任单位：市商务和投资促进局、文化旅游体育广电局，各县（市、区））

（七）现代纺织产业招商行动。坚持以《吴忠现代纺织产业发展规划（2018-2025）》为指导，抢抓东中部产业转移的契机，加快引进羊毛羊绒深加工、棉纺织、家纺针织、服装成衣等纺织制造和改造升级项目，打造从原料到纱锭、纱线、面料、成衣及家纺的全产业链纺织工业体系，逐步形成羊毛羊绒深加工、棉纺、家纺针织、服装行业同步发展的新格局。围绕优化产业结构、做大产业规模，每年开展3批次纺织产业专题精准招商活动。（责任单位：市工信局、商务和投资促进局，金积工业园区、同心工业园区）

四、具体措施

（一）强化责任落实。突出县（市、区）、开发区、工（农）业园区“一把手”的招商引资主体责任，定期对招商引资工作进行调度，协调解决项目推进中的难点问题。对在谈、签约的重大实体项目实行市级领导联系制度，使签约项目能够早开工、开工项目早投产、投产项目早见效。

（二）创新招商方式。积极开展市县联合招商、园区主导产业招商，建立与中介机构的常态化合作机制，运用委托招商、代理招商等市场化运作模式，开展大数据招商。组建招商服务公司及专业招商队伍，开展专业化招商。推进各行业主管部门与各县（市、区）、园区联合开展行业招商、产业链招商。

（三）改革考评机制。建立科学合理的评估指标体系，把工作成效量化评估与工作开展情况定性评估相结合，既重视评估招商引资项目的总量、规模，更重视评估合同履约率、项目开工率和资金到位率，全面系统准确考核招商引资工作绩效。

（四）优化营商环境。全力贯彻落实《吴忠市优化营商环境措施》25条，加大对符合条件的重点项目在财税、信贷、用地、人才等方面的支持力度。抓好《吴忠市招商引资项目“一站式”服务办法》的落实，加大项目推进服务力度，促成更多对接项目落地。
