# 吴忠市人民政府关于太阳山蒙欣煤化工有限公司用地分割登记的批复

市自然资源局：

你局《关于提请规划建设重大事项工作小组暨土地供应会审小组研究决定有关事宜的请示》（吴自然资发〔2019〕117号）收悉，经市人民政府2019年第21期专题会议研究，现批复如下：

1.同意将位于太阳山开发区洗煤产业区太阳山蒙欣煤化工有限公司26.95公顷（404.25亩）用地分割登记，分割后地块一面积14.8458公顷（222.69亩），地块二面积12.1042公顷（181.56亩）。

2.接此批复后，请按规定办理土地分割手续。

吴忠市人民政府

2019年8月29日
