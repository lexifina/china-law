# 吴忠市人民政府关于采矿权矿区范围的公告

根据《矿产资源开采登记管理办法》和《自治区自然资源厅关于颁发宁夏同心县青龙山西道梁二道山中段石灰岩矿采矿许可证的函》（宁自然资函〔2019〕208号），现对宁夏金昱元德源通矿业有限公司位于同心县青龙山西道梁二道山中段石灰岩矿矿区范围进行公告：

采矿许可证号：C[身份证号略]7687

采矿权人：宁夏金昱元德源通矿业有限公司

地    址：宁夏吴忠市太阳山开发区舍尔山

矿山名称：宁夏同心县青龙山西道梁二道山中段石灰岩矿

矿区位置：青龙山西道梁二道山中段（位于同心县、红寺堡区两县区境内）

经济类型：其他有限责任公司

开采矿种：水泥用石灰岩、制碱用石灰岩

开采方式：露天开采

生产规模：100万吨/年

矿区面积：0.3582平方公里

发证机关：宁夏回族自治区自然资源厅

有效期限：2019年3月22日-2033年10月22日
