# 吴忠市人民政府关于调整部分副市长工作分工的通知

各县（市、区）人民政府，各开发区、工（农）业园区管委会，市政府各部门、直属事业单位：

因人事变动，经市人民政府研究，现将部分副市长工作分工调整如下：

苏慧娟副市长  协助市长负责民政救助、水务、农业农村、退役军人事务、扶贫开发、人防、粮食和物资储备等方面工作。

分管市民政局、水务局、农业农村局、退役军人事务局、扶贫开发办公室，人民防空办公室、粮食和物资储备局、吴忠国家农业科技园区。

联系吴忠军分区、预备役团、残疾人联合会、气象局、秦汉渠管理处、盐环定管理处、宁夏水投吴忠水务有限公司。

张志刚副市长  协助市长负责教育、科技、人力资源和社会保障等方面工作。

分管市教育局、科学技术局（地震局）、人力资源和社会保障局、宁夏民族职业技术学院。

联系总工会、团委、妇联、科学技术协会。

吴忠市人民政府

2019年12月30日
