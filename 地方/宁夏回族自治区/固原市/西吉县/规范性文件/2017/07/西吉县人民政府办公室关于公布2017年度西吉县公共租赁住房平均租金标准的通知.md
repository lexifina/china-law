# 西吉县人民政府办公室关于公布2017年度西吉县公共租赁住房平均租金标准的通知

各乡（镇）人民政府、县直有关部门（单位）：

为进一步做好我县低收入家庭住房保障工作，根据住建厅、财政厅、发改委、国土资源厅《关于公共租赁住房和廉租住房并轨运行的实施意见》，参考固原市公布的公共租赁住房平均租金标准，结合我县经济发展水平、商品住房平均租金和住房困难家庭经济承受能力等因素，拟定2017年度西吉县公共租赁住房平均租金为4.5元/月•㎡。其中：惠安小区及工业园区片区按4元/月•㎡确定，钰秀家园、惠泽苑、怡秀家庭、锦绣家园按5元/月•㎡确定，将台、震湖、新营按照县城的60%，即2.7元/月•㎡确定。

请相关乡镇、部门（单位）严格按照以上租金标准做好贯彻落实，下年度租金标准公布之前现标准将延续。此标准自2017年7月1日起执行。

西吉县人民政府办公室

2017年11月6日
