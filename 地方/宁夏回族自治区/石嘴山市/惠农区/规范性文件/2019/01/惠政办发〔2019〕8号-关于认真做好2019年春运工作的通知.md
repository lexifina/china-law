# 关于认真做好2019年春运工作的通知

惠政办发〔2019〕8号

各乡镇人民政府、街道办事处，区政府各部门、直属单位，驻惠有关单位：

2019年是新中国成立70周年，也是决胜全面建成小康社会第一个百年奋斗目标的关键之年。根据《宁夏回族自治区人民政府关于做好2019年春运工作的通知》（宁春运办〔2018〕1号）、石嘴山市春运工作领导小组办公室《关于认真做好2019年春运工作的通知》（石春运办发〔2019〕1号）精神，2019年春运工作从1月21日开始，3月1日结束，共计40天。为统筹做好我区2019年春运工作，保障人民群众安全满意出行，结合我区实际，现将有关事项通知如下：

一、准确把握形势

春运工作是人民普遍关心关注的民生工作。圆满完成春运任务，为经济社会发展营造良好环境，意义重大。各有关单位要以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九大和十九届二中、三中全会精神，牢固树立“四个意识”，坚决做到“两个维护”，精心准备，科学组织，全力做好2019年春运各项工作，让旅客走得了、走得好、走得安全、走得舒心，切实增强人民群众的获得感、幸福感和安全感。

二、强化组织领导

区人民政府成立由常务副区长张新为组长的春运工作领导小组（详见附件），负责全区春运工作。领导小组办公室（区春运办）设在区交通运输局，庞红阳同志兼任办公室主任，负责春运日常工作。各春运成员单位要结合本辖区、本部门、本行业实际，成立春运工作领导小组，制定春运工作方案、应急预案，加强领导，明确责任，精心组织，周密安排，将春运各项工作要求落实到位。要建立健全春运工作协调机制，加强监测分析，强化督促检查，及时协调解决跨区域、跨部门的突出问题，协同处置突发事件，确保圆满完成春运任务。

三、加强运输保障

市道路运输管理局惠农区运管科、运输企业要科学预测春运需求和客流流量、流向，合理制订运输方案，统筹安排运力资源。要加强道路客运与铁路运输的衔接，根据需要增加班次，及时疏运长途旅客，便利旅客换乘。要加大农村道路客运运力投入，满足城乡群众出行需要。要坚持“以客为主、客货兼顾”的原则，在保证旅客运输的同时，努力兼顾好煤炭、粮食、化肥、鲜活农产品、节日用品等重点物资运输，确保满足企业正常生产和居民生活需要。

四、从严抓好安全生产

各成员单位要深入贯彻落实习近平总书记关于安全生产的重要论述和指示精神，时刻绷紧安全这根弦，坚决克服麻痹思想和侥幸心理，以对党和人民高度负责的态度，全力做好春运安全生产工作。要进一步增强红线意识和底线思维，严格落实党委、政府领导责任、部门安全监管责任和企业安全生产主体责任，将责任落实到岗位、落实到人头，贯穿各个环节。要广泛采取“四不两直”、“双随机”等方式开展春运安全检查，对重大隐患要建立台账，实行挂牌督办，限期整改到位。对拒不整改或多次整改不到位的企业，要纳入安全生产“黑名单”并向社会公布，情节严重的依法追究相关人员责任。

市道路运输管理局惠农区运管科要组织运输企业对运输线路、场站设施、运输设备、管理制度、从业人员深入开展隐患排查，严禁技术状况不达标的车辆、设施、设备投入春运，严禁逾期未检验、逾期未报废的客运车辆和逾期未审验、逾期未换证、记满12分的营运驾驶人参加春运，从严抓好春运资格审验。要认真分析研判春节前后客流趋势，监督企业抓好春运全过程的安全生产工作。

公安、交警部门要严格排查“两客一危”车辆，严禁驾驶证记满12分、交通违法行为未处理的营运客车驾驶人参加春运。要提前启动春运检查站，对客运班车、过境车、危货车辆及七座以上小客车逐一进行检查登记，加大对“三超一疲劳”等交通违法行为的查处力度。各单位要密切配合，充分发挥基层“两站两员”作用，及时劝导、纠正农村面包车超员载客、货车违法载人、酒后驾驶等违法违规行为。各运输企业要加强“两客一危”重点营运车辆动态监控，严格执行凌晨2-5时停车休息或接驳运输制度，坚决杜绝超速超员超载、疲劳驾驶、“客货混装”、非法营运等违法违规行为。要严格执行汽车站安检制度，严防“三品”进站。要提前组织初次参加春运的驾驶人特别是客运包车驾驶人，熟悉运营线路及沿线路况，掌握事故多发点段，防止因道路不熟引发交通事故。

五、强化春运应急管理

各成员单位要在总结以往经验教训的基础上，针对可能出现的低温、冰冻、雨雪等灾害天气和设备故障、延误晚点等旅客滞留突发事件，制定并细化完善应急预案，统筹安排应急救援、应急保障等措施。区气象局要建立气象信息快速通报机制，及时发布灾害天气预警信息。区交通运输局要加强道路巡查养护，备足防滑、防雪材料和除冰除雪设备，确保在冰雪天气时公路安全畅通。市道路运输管理局惠农区运管科、运输企业要完善应急预案，加强风险评估、培训演练、监督检查，紧密衔接管理部门预案，确保预案可执行、有成效。公安、交警部门要加强交通流量监测，针对易堵路段完善疏堵保畅方案，及时疏导车流，防止出现拥堵。区卫生和计划生育局要积极配合交通部门做好车站、运输工具的防疫工作，加强春运期间的医疗卫生应急力量，有效防控突发公共卫生事件。

六、提升服务质量

（一）加强宣传引导。区委宣传部要精心组织春运宣传工作，综合发挥传统媒体和“两微一端”等新媒体作用，突出宣传改革开放以来春运的巨大变化、一线职工爱岗敬业的感人事迹、人民群众的幸福感和获得感、安全诚信文明出行等主题，用身边人、身边事讲好春运故事。要加强对春运舆情的监测分析，及时了解热点焦点问题，积极回应社会关切，做好沟通解释，赢得人民群众对春运工作的理解和支持。各乡镇人民政府、街道办事处，相关单位要积极倡导群众文明出行，抵制交通陋习。

（二）营造“温馨春运”氛围。春运首日，市道路运输管理局惠农区运管科要组织汽车站、运输企业启动“情满旅途”活动，创新活动载体，丰富活动内容，对重点旅客提供母婴室、急救药物等多种便民服务，落实好军人军属优待政策，优化互联网售票服务，提升旅客购票体验，确保活动取得实效。区委宣传部会同团区委、区民政局发动城市青年志愿者，在汽车站、火车站开展文明出行、引导咨询、秩序维护、重点帮扶、应急救援等志愿服务活动，完善志愿服务活动记录，共同营造“温馨春运”氛围。

（三）做好春运各项服务工作。区气象、公安交管部门和运输企业要及时发布天气、交通管制、运力调整等信息，引导旅客、私家车合理安排出行。区人力资源和社会保障局要做好务工人员流向流量信息的收集和分析，及时提供给运输部门，组织务工人员错峰出行，出现人员滞留时及时开展安抚工作。

七、推动信用建设

按照国家发改委、公安部、交通部《关于开展交通出行领域严重失信行为专项治理工作的通知》，各有关单位要继续完善工作机制，深入开展交通出行领域失信治理，强化信用的规范和约束作用。对客运车辆超员、超速，出租汽车拒载、甩客、无证经营，以及旅客“车闹”“霸座”等各类失信行为进行记录和整治。运管部门、运输企业要加强客运服务教育培训，提高从业人员处置不文明行为的能力；鼓励乘客参与运输安全保障，勇于制止影响驾驶员正常驾驶、侵扰公共运输安全的旅客违法行为；配合公安部门打击违法犯罪行为。

八、维护春运秩序

运管部门要继续打击非法运营活动，维护运输市场秩序。公安部门要对车站、运输线路及其周边区域社会治安问题开展清理整治。区发展和改革局要加强运价监管，严肃查处乱收费、乱涨价行为，会同区商务和文化旅游局做好车用燃油燃气供应保障工作。区工业和信息化局要做好铁路客货运输协调工作。各成员单位要畅通投诉举报处理渠道，妥善处理群众反映的问题。

九、落实春运工作制度

各成员单位要严格落实春运24小时值班制度，1月21日前将春运工作联系人信息（单位、姓名、职务、值班电话、手机）报区春运办；自1月21日起每日上午9:00向区春运办报送工作动态，市道路运输管理局惠农区运管科每日报送客流数据（发客量、同比）。春运工作结束后，各有关单位要对春运工作情况进行认真总结，于3月1日前将总结情况报送区春运工作领导小组办公室（区交通运输局）。联系人：夏佳园，联系电话：0952-7011525，邮箱：hnqjiaotongju@163.com。
