# 关于启用中国共产党石嘴山市惠农区委员会全面深化改革委员会等印章的通知

惠党办发〔2019〕25号

各乡镇、街道党（工）委，区直各党（工）委（党组）、总支、支部，驻惠各单位党组织：

根据《中共石嘴山市委办公室、市人民政府办公室关于印发的通知》（石党办发〔2019〕5号）精神，决定自即日起，启用中国共产党石嘴山市惠农区委员会全面深化改革委员会、中国共产党石嘴山市惠农区委员会全面依法治区委员会、中国共产党石嘴山市惠农区委员会国家安全委员会、中国共产党石嘴山市惠农区委员会网络安全和信息化委员会、中国共产党石嘴山市惠农区委员会财经委员会、中国共产党石嘴山市惠农区委员会外事工作委员会、中国共产党石嘴山市惠农区委员会机构编制委员会、中国共产党石嘴山市惠农区委员会审计委员会、中国共产党石嘴山市惠农区委员会教育工作领导小组、中国共产党石嘴山市惠农区委员会农村工作领导小组、中国共产党石嘴山市惠农区委员会政策研究室、中国共产党石嘴山市惠农区委员会全面深化改革委员会办公室、中国共产党石嘴山市惠农区委员会全面依法治区委员会办公室、中国共产党石嘴山市惠农区委员会国家安全委员会办公室、中国共产党石嘴山市惠农区委员会网络安全和信息化委员会办公室、中国共产党石嘴山市惠农区委员会财经委员会办公室、中国共产党石嘴山市惠农区委员会外事工作委员会办公室、中国共产党石嘴山市惠农区委员会机构编制委员会办公室、中国共产党石嘴山市惠农区委员会审计委员会办公室、中国共产党石嘴山市惠农区委员会教育工作领导小组办公室、中国共产党石嘴山市惠农区委员会农村工作领导小组办公室印章各一枚。

同时废止石嘴山市惠农区全面深化改革领导小组、石嘴山市惠农区依法治区领导小组、石嘴山市惠农区国家安全工作领导小组、石嘴山市惠农区农村工作领导小组、石嘴山市惠农区教育工作领导小组、石嘴山市惠农区机构编制委员会、石嘴山市惠农区全面深化改革领导小组办公室、石嘴山市惠农区依法治区领导小组办公室、石嘴山市惠农区农村工作领导小组办公室、石嘴山市惠农区机构编制委员会办公室印章。因不再设立石嘴山市惠农区社会治安综合治理委员会及其办公室、石嘴山市惠农区维护稳定工作领导小组及其办公室、中国共产党石嘴山市惠农区委员会防范和处理邪教问题领导小组及其办公室，印章同时废止。
