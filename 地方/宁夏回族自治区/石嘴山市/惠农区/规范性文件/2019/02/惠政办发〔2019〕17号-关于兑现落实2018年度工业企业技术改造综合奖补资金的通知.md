# 关于兑现落实2018年度工业企业技术改造综合奖补资金的通知

惠政办发〔2019〕17号

各乡镇人民政府、街道办事处，区政府各部门、直属单位，驻惠有关单位、各企业：

为认真贯彻落实自治区、市2018年工业企业技术改造综合奖补资金相关文件精神，加快工业企业技术改造和信息化项目建设，推动我区工业经济提速增效。按照《惠农区2018年工业企业技术改造综合奖补资金落实方案》，经区人民政府研究同意，现就落实2018年度工业企业技术改造综合奖补资金有关事宜通知如下。

一、已通过2018年度市加快工业转型发展奖补政策申报审核的传统产业改造提升项目和“机器换人”项目，以石政办发〔2018〕193号文件确定的补贴额度予以奖补兑现（4户企业，共计314.1万元）

1.宁夏万香源生物科技有限公司奖补200万元

2.宁夏盛晖光伏技术有限公司奖补52万元

3.石嘴山市东明化工有限公司奖补34.9万元

4.宁夏润龙包装新材料股份有限公司奖补27.2万元

二、兑现工业技术改造提升类项目奖补名单（6户企业，共计420万元）

1.宁夏科通新材料科技有限公司硅钙合金产业循环经济升级改造项目奖补60万元

2.宁夏嘉峰化工有限公司年产50000吨硝酸胍联产10000吨精制硝酸胍项目奖补80万元

3.宁夏尼西活性炭有限公司年产12000吨活性炭生产线节能及自动化改造项目奖补60万元

4.宁夏锦华化工有限公司二氧化碳回收及余热、废渣综合利用产业链延长项目奖补80万元

5.宁夏新生焦化有限公司130万吨焦炉（二期）及焦炉设备设施升级改造项目奖补80万元

6.宁夏世东科技有限公司发泡剂深加工项目奖补60万元

三、兑现产业结构优化升级类项目奖补名单（4户企业，共计150.9万元）

1.宁夏彩源科技有限公司年产6000吨有机颜料及年产6000吨硫代卡巴肼项目奖补60.9万元

2.宁夏信立泰化工有限公司年产5000吨纺织助剂项目奖补55万元

3.宁夏杭发汽车零部件有限公司加装年产2000万套汽车万向节轴承碗、万向节总成生产线项目奖补20万元

4.宁夏华昊化工有限公司3万吨铸件加工项目奖补15万元

四、兑现环保设备设施改造类项目奖补名单（3户企业的4个项目，共计125万元）

1.宁夏英力特化工股份有限公司2*150MW机组超低排放改造项目奖补20万元

2.国电宁夏石嘴山发电有限责任公司4*330MW机组综合升级改造项目奖补35万元

3.石嘴山市盛港煤焦化有限公司封闭式储备仓建设项目奖补35万元

4.石嘴山市盛港煤焦化有限公司环保综合治理项目奖补35万元
