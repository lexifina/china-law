# 关于命名惠农区2018-2019年度青年文明号集体的决定

惠团发〔2019〕16号

各乡镇、街道团(工)委，区直有关部门团委、团总支、团支部，直属有关企业团委、团总支、团支部，驻惠有关单位团总支、团支部：

为表彰先进，树立典型，激励更多的青年集体投身青年文明号创建活动，引导广大团员青年立足本职，建功立业，进一步推动我区青年文明号活动深入开展，经过对申报单位的指导、评选，惠农区团委决定命名石嘴山市消防支队惠农大队等4家青年集体为2018-2019年度“惠农区青年文明号”。

希望受到表彰的青年集体珍惜荣誉，再接再厉，不断增强创新意识、服务意识，以一流工作业绩为我区建设作出应有贡献。

附件：惠农区2018-2019年度青年文明号集体名单

共青团惠农区委员会

2019年5月8日
