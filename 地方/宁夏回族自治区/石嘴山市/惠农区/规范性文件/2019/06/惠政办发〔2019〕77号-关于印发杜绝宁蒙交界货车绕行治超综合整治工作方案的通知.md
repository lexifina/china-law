# 关于印发杜绝宁蒙交界货车绕行治超综合整治工作方案的通知

惠政办发〔2019〕77号

各乡镇人民政府、街道办事处，区政府各部门、直属单位，驻惠有关单位：

《杜绝宁蒙交界货车绕行治超综合整治工作方案》已经区人民政府同意，现印发给你们，请结合实际，认真贯彻落实。

惠农区人民政府办公室

2019年6月21日

（此件公开发布）

杜绝宁蒙交界货车绕行治超综合整治工作方案

为切实有效杜绝货运车辆超限超载行为及由此引发的社会乱象，加强第五水源地一级保护区保护工作，按照“有黑扫黑、有恶除恶、有乱治乱”的原则，结合工作实际，特制定本方案。

一、总体目标

为切实保护公路基础设施，保障道路交通安全，维护货运市场秩序，彻底治理违法超限超载行为及由此引发的社会乱象。同时以整治石嘴山市第五水源地一级保护区内交通穿越为重点，消除饮用水水源保护区内潜在风险源，保障人民群众饮水安全。

二、整治重点范围

重点整治宁蒙交界货运车辆途经地段、滨河大道延伸段（麻园路）、110国道宁蒙交界至麻黄沟治超站周边、第五水源地及四合木保护区。

三、整治措施

（一）开展水源地规范性保护管理工作。对第五水源地一级保护区安装围丝、围网等设施，从源头上预防治理；对第五水源地一级保护区内的围丝、围网及标识警示牌等进行更新和修补，加强饮用水水源保护区建设与整治，提高监控、风险防控与应急能力，有效落实管理措施。

责任单位：区农业农村和水务局、市润泽供排水有限公司惠农供排水分公司、宁夏惠安市政产业有限公司。

（二）开展水源地保护区企业取缔整治工作。重点整治饮用水水源一级保护区周边与供水设施和保护水源无关的企业，整治第五水源地一级保护区内生态环境，对私自开采、偷盗国家矿产资源的行为进行打击治理，从源头上杜绝运输车辆穿越水源地保护区。

责任单位：区农业农村和水务局、自然资源局、惠农区环境监察大队、市公安局惠农分局

（三）开展园区企业运输车辆规范运输工作。工业园区要加大对工业园区内的运输车辆的综合整治，加强运输车辆的管理，禁止园区出入货运车辆躲避麻黄沟治超站，从宁蒙交界周边第五水源地及四合木保护区范围便道绕行行为。

责任单位：石嘴山经济技术开发区管委会

（四）封堵绕行便道。实地踏查，按照应封则封，能封尽封的原则，切实采取封堵措施。对在内蒙古境内货车绕行途经的路段，区住房城乡建设和交通局及时上报上级主管部门，沟通对接乌海市、阿拉善盟交通运输部门采取有效措施进行封堵。属于惠农辖区范围内货车绕行途经的路段，主要在货车躲避治超站绕行途经便道采取封堵挖沟、制作安装防护栏等封堵防护措施，从路面管控防护措施上加大封堵力度，杜绝货车绕行情况发生。

责任单位：区住房城乡建设和交通局、自然资源局、农业农村和水务局、石嘴山市公路分局、贺兰山国家级自然资源保护区管理局。

（五）排查治理私设便道收费行为发生。对在宁蒙交界处麻黄沟治超站周边和水源地保护区、四合木保护区范围内私设便道，收取货车司机好处费的“黄牛”行为，公安机关要采取有力措施，坚决予以打击，坚决杜绝此类现象发生。

责任单位：市公安局惠农分局

（六）开展联合治超工作。公路路政、交警、运管、公安、农牧、水务、国土、规划、贺兰山自然保护区管理局等相关部门和单位联合，采取各种有效措施，在第五水源地一级保护区及麻黄沟治超站周边绕行的公路路域范围内开展路面执法工作，坚决打击躲避治超站绕行行为，有效遏制违法货运行为发生，消除对水源地四合木、一般林地的破坏。

责任单位：区住房城乡建设和交通局、自然资源局、市公安局惠农分局、贺兰山自然保护区管理局、交警八大队、麻黄沟治超站等相关职能部门

四、工作要求

（一）强化组织领导，提高政治站位。各责任单位要高度重视宁蒙边界货车绕行治超综合整治工作，这项工作政治性强，要切实提高政治站位，压实工作责任，及时解决工作中存在的问题，切实把行业治乱的责任扛起来。

（二）强化措施，形成最大合力。各责任单位要依据各自的职责，采取各种行之有效的措施，杜绝绕行现象发生。区治超办牵头抓总，统一协调，不定期组织开展联合执法行动，建立地定期督查通报机制。各部门齐抓共管，相互配合，切实形成超限超载治理工作的最大合力。

（三）强化责任担当，确保工作落实。各责任单位要强化责任意识，指派专人负责此项工作，明确工作任务，厘清工作目标，结合扫黑除恶专项斗争，立行立改，以时不我待的工作举措开展宁蒙边界货车绕行治超综合整治工作，确保综合整治工作取得实效，彻底治理违法超限超载行为及由此引发的社会乱象。
