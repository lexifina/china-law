# 自治区水利厅关于规范水利工程施工转包违法分包等违法违规行为认定查处的通知

宁水建发〔2017〕7号

各市、县（区）水务局，各有关单位：

现将水利部《水利工程施工转包违法分包等违法行为认定查处管理暂行办法》（水建管〔2016〕420号）转发给你们，请遵照执行，并就进一步规范我区水利工程施工转包、违法分包、出借借用资质等违法违规行为认定查处，维护水利建设市场良好秩序有关事宜通知如下：

一、深刻认识转包、违法分包、出借借用资质等违法行为对水利工程质量安全的危害，牢固树立依法行政意识，切实履行水利工程建设市场监管职责，对违规行为要“零容忍”“严打击”。

二、加强部门间监管信息互通共享，及时公开信息，加大曝光力度，坚持查实体质量与查市场行为并重，对发现的违法违规行为，属职责权限内的要及时处理，不属于职责权限内的要及时向有关部门通报。经查实的违规行为，要在20个工作日内依规作出处罚决定并将处理结果报水利厅建设管理处核备。

三、强化在建项目稽察检查，坚持日常巡查与集中排查相结合，水利厅将对各单位查处转包、违法分包、出借借用资质等违法违规行为情况列入稽察检查范围，对监管职责履行不到位、处理不及时的单位严肃问责并追究相关责任人责任。

四、加快市场主体信用体系建设，要积极运用不良行为公示、“黑名单”管理、诚信信息采集等信用惩戒手段加大对转包、违法分包、出借借用资质等违法行为的打击力度，提高企业失信成本。凡认定为转包、违法分包、出借借用资质等违法违规行为主体，各单位要及时向自治区水行政主管部门上报不良行为记录。对查实的违法违规行为，自治区水行政主管部门予以信用分处罚，并录入全区水利建设市场 “黑名单”，同时在水利部建设市场主体信用平台和信用宁夏网站向社会公告。

宁夏回族自治区水利厅

2017年1月9日
