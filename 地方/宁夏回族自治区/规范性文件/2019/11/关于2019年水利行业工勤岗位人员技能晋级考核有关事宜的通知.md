# 关于2019年水利行业工勤岗位人员技能晋级考核有关事宜的通知

各市、县（区）水务局，厅属各单位：

按照《自治区水利厅关于做好2019年水利行业工勤岗位人员技能晋级考核工作的通知》（宁水人发﹝2019﹞10号）精神，现就2019年水利行业工勤岗位人员技能晋级考核有关具体事宜通知如下:

一、考核的范围及方式。本次考核竞赛共分为渠道维护工、泵站运行工（含泵站机电设备维修工）、水文勘测工三个工种。凡全区水利行业中原持有以上三个工种职业资格证书、符合晋级资格的人员及从事相关工作、初次确定技术等级人员均可申报。所有符合条件人员均实行自愿申报、单位审核推荐相结合方式。（见附表）

二、考核的组织实施。本次考核由自治区人社厅统一组织，自治区水利厅负责实施。采取理论考核、技能鉴定相结合方式进行。其中，技师以上晋级人员还须参加答辩考核和综合评审。

三、考核的内容。本次考核以各工种技能鉴定考核大纲为主要依据，主要考核晋级人员所掌握的从事本岗位等级工作所要求的理论水平和实际操作能力。

（一）渠道维护工考核内容包括：水利职业道德、灌排工程基本知识、测量知识、渠道及建筑物识图、工程材料基础知识、机械操作、量测水知识、堤顶道路维护、渠道及渠系建筑物防冻、安全生产与环境保护。渠道工程维护、水工建筑物维护、机电设备及信息化设施维护等。按照技术等级分层次进行考核。

（二）水文勘测工考核内容包括：水利职业道德、水文基本概念、降水水面蒸发观测、水位观测、水力学概念与河流流量测验、河流泥沙测验、水质采样、地下水及土壤墒情监测、水文情报水文预报、水文普通测量、误差基础知识、物理量的单位制、量纲和有效数字、水文勘测安全常识。泥沙测验 、水位观测、流量测验、水面蒸发量观测、水文普通测量、泥沙测验 、流量测验、洪水调查等。按照技术等级分层次进行考核。

（三）泵站运行工（泵站机电设备维修工）考核内容包括：水利职业道德、机械识图、机械基础、电气基础、水泵及水泵站、电气设备、泵站自动化、设备操作、设备管理、安全生产等。按照技术等级分层次进行考核。

四、几点说明

（一）为确保考核工作的顺利过渡，本次考核按照强化培训、理论考核、技能鉴定、答辩评审几个程序进行。其中，渠道维护工、水文勘测工培训考核委托宁夏水利电力工程学校组织实施，泵站运行工培训考核委托宁夏红寺堡扬水管理处培训中心组织实施。每个工种强化培训时间不超过5个工作日，每人技能操作考核不超过120分钟。考核整体工作于12月中旬全部结束。

（二）考核时一律由本人持身份证参加。凡出现替考等舞弊行为的，一经发现取消其考试考核资格且3年内不得参加晋级考核。

（三）所有人员考核期间的住宿、交通、鉴定等费用均由个人自理，各单位按照考核日程安排组织参加考核。
