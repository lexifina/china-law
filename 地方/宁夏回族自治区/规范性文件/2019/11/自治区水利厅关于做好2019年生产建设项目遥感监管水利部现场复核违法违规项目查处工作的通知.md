# 自治区水利厅关于做好2019年生产建设项目遥感监管水利部现场复核违法违规项目查处工作的通知

各市县（区）水务局，各有关单位：

根据《水利部办公厅关于开展2019年生产建设项目水土保持遥感监管工作的通知》（办水保函〔2019〕756号）和《水利部办公厅关于下发2019年度遥感监管疑似违法违规项目清单的通知》（办水保函〔2019〕1202号）的安排部署，水利部组织完成了较大扰动图斑的现场复核，最终确定了我区疑似违法违规项目151个。清单涉及我区5市14县（区），其中：银川市69项（含宁东能源化工基地），石嘴山市28项，吴忠市20项，固原市7项，中卫市27项。现将清单下发你们（清单项目详细信息将通过现场复核APP下发），请各市、县（区）逐一核查疑似违法违规项目情况，对确认为违法违规的生产建设项目，在11月底前完成查处工作，并将核查和处理情况通过现场复核系统上传水利部生产建设项目水土保持监管数据库。

各级水行政主管部门要高度重视，认真抓好工作落实。同步做好自治区下发的水土保持违法违规清单项目的查处工作，并将相关情况及时上传监管系统。各单位要安排专人按照“日跟进、周报告”要求，认真填写“2019年生产建设项目遥感监管违法项目查处情况统计表”，及时将工作进展情况上报自治区水利厅水土保持处和自治区水土保持监测总站，水利厅将定期通报各单位违法违规项目查处情况，并对查处工作推进不力的单位进行约谈。
