# 自治区水利厅关于做好黄河防凌工作的通知

沿黄各市、县（区）水务局、有关单位：

为贯彻落实黄委和自治区2019 -2020年度黄河防凌会议精神，切实做好黄河凌汛防御工作，现将有关工作通知如下：

一、认清形势，增强责任担当

近年来，黄河宁夏段防洪工程与非工程体系不断完善，防洪防凌能力得到极大提升。2018年、2019年连续2年大洪水过程后，黄河宁夏段河道流路、河势及滩槽均发生一定变化，水利防洪工程在伏秋汛长期高水位运行，凌汛期水位迅速回落，工程出险可能性仍然较大。根据黄委年度防凌调度预案，拟定本年度宁蒙河段封河流量为800立方米每秒左右，大于多年均值，加之，凌汛期可能出现阶段性低温，黄河宁夏段防凌形势异常严峻。各级水利部门要按照机构改革后水利部门在防汛抗旱方面的职责，围绕监测预报预警、水工程调度和抢险技术支撑等工作，细化实化各级水利部门防凌责任，把黄河防凌各项措施落到实处，切实做到职责明确、任务具体、措施到位。

二、提前备防，夯实防凌基础

一是开展工程维修加固。凌汛前，各地水利部门要组织对水毁工程进行修复，并对河道受顶冲段工程进行维修加固，消除工程隐患。二是强化监测预报保障。水文部门要做好黄河干流水文监测设施维护及调试工作，为凌汛测报提供基础保障。三是建立健全专项预案。按照水利部门在防汛抗旱工作中的职责，编制凌汛防御专项预案，细化各项防御措施，指导各项工作顺利实施。四是提前开展防凌检查。重点检查工程巡查抢险、穿堤建筑物封堵工作准备情况，以及涉河在建工程应急预案修编和措施落实情况等。五是加强涉河设施监管。根据天气和凌情发展情况，提前关停涉河在建工程和码头、拆除浮桥，确保河道行凌畅通和人员设施安全。

三、全力应对，确保措施到位

一是强化会商研判。防御、水文等部门要适时进行内部会商，针对重大天气、封开河期等关键节点，会同气象等部门开展联合会商，研判凌情发展趋势，预筹防御措施。二是强化监测预报。水文部门要加强水文监测和预报工作，及时发布重大天气和封开河预报过程，监测断面凌情、水情变化，并在关键时间节点，加密测报频次，为防凌工作提供依据。三是强化巡查值守。严格落实24小时值班值守，加强巡堤查险，全面掌握水情、凌情、工情变化，遇到突发事件和重大险情及时报告，确保防凌工作规范有序。四是强化宣传引导。加强与新闻媒体的沟通联系，做好凌情宣传报道，开展防凌宣传和涉河人员管理。

四、联防联动，形成整体合力

一是强化信息共享。建立水利与应急、气象等部门间信息共享机制，以及与涉河在建工程、浮桥、码头等管理单位的联络机制，确保凌汛信息传达无盲区、无死角。二是强化抢险保障。发现险情，及时报告、及时处理，做到抢早抢小，遇重大险情，及时提请地方政府和应急部门开展险情处置工作。三是强化技术支撑。水利部门要统筹专业技术力量建立专家工作组，视防凌抢险需要或地方请求，派出水利技术专家，提供抢险技术支撑，协助开展险情处置工作。
