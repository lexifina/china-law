# 自治区水利厅关于公布2018-2019年度水利科技进步奖获奖成果的通知

各市、县（区）水务局，厅属各单位，机关各处室，有关水利企业：

我区水利系统认真贯彻落实习近平总书记关于科技创新的重要论述和来宁视察讲话精神，大力实施科技创新，在水利重点领域和关键技术研究以及成果应用推广等方面取得了明显成效，优秀科技成果不断涌现。为激发广大水利科技人员的积极性和创造性，依据《宁夏水利科技项目管理办法》（宁水科教发〔2010〕12号）和《宁夏水利科技进步奖奖励办法》（宁水科教发〔2012〕13号），水利厅组织对2018-2019年度宁夏水利科技成果进行了评选，现将获奖成果予以公布。

各单位要以习近平新时代中国特色社会主义思想为引领，认真学习贯彻习近平总书记在黄河流域生态保护和高质量发展座谈会上的重要讲话精神，以推进水利高质量发展为引领，不断加强水利科技创新，力争多出成果、出好成果，为加速推动宁夏水利现代化提供有力科技支撑。
