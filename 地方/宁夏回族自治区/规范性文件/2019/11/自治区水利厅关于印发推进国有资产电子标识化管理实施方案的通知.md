# 自治区水利厅关于印发推进国有资产电子标识化管理实施方案的通知

厅属各单位、厅机关处室：

现将《水利厅推进国有资产电子标识化管理实施方案》印发给你们，请认真抓好组织实施。

宁夏回族自治区水利厅

2019年11月20日

（此件公开发布）

水利厅推进国有资产电子标识化管理实施方案

为全面规范和加强水利厅国有资产管理，进一步落实国有资产管理主体责任，提高资产管理质量和效率，按照自治区财政厅《行政事业单位国有资产电子标识化管理试点方案》，结合水利工作实际，制定本实施方案。

一、指导思想

坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九大精神，按照深化财税体制改革的总体部署，理顺和巩固行政事业单位国有资产管理体制，健全行政事业单位资产管理法规制度和内控机制，深入推进资产管理与财务管理、实物管理与价值管理相结合，建立既相互衔接又有效制衡的工作机制和业务流程，着力构建更加符合行政事业单位运行特点和国有资产管理规律、从“入口”到“出口”全生命周期的行政事业单位资产管理体系。

二、目的意义

推进国有资产电子标识化管理是以自治区行政事业单位资产管理信息系统为依托，利用现代信息技术赋予每个实物资产一个电子条码，实现对资产从开始使用到处置整个生命周期的全程跟踪管理。其目的是从根本上杜绝人工盘点中易发生的错、漏、重等现象，避免录入数据人为错误的发生，确保盘点数据的真实可靠，大幅提升资产管理的效率和质量水平。通过对实物资产实行“一物一卡一条码”，有效解决资产管理中账、卡、物不符，资产存量不清，闲置浪费和资产流失等问题，为行政事业单位国有资产管理提供全面、可靠、高效的动态数据管理和决策依据。通过开展实物资产跟踪管理，建立由资产内控管理系统条码模块、条码打印机、条码扫描终端组成的资产条码管理框架，使资产领用、维修、报废等信息同步监控，实现资产的全生命周期管理。

三、目标任务

通过实施水利厅行政事业单位国有资产电子标识化管理，有效落实资产管理主体责任，建立健全科学、规范的资产使用管理规章制度、内部流程、岗位职责和内控体系。充分依托行政事业单位资产管理信息系统的动态管理优势，建立“全面、准确、细化、动态”的水利行政事业单位国有资产基础数据库，实现对水利厅机关和厅属单位国有资产的有效管理，做到账实相符、账账相符、账卡相符。

四、实施步骤

（一）实施范围。

按照资产分类，此次纳入电子标识化管理的资产包括：水利厅机关及厅属各单位所有的办公家具、用具、装具，专用设备、通用设备、文物和陈列品、图书、档案等资产。不包括公共基础设施、土地、房屋及构筑物、车辆以及待报废资产。

（二）工作步骤。

1.准备阶段（11月20日-30日）。各单位在2016年资产清查工作的基础上，再次进行资产清查盘点，确认资产实物与资产账务数据信息的一致性。如果资产量比较大，单位力量薄弱，还可聘请第三方中介机构协助实施。资产盘点完成后，根据资产变动情况和管理权限捋顺资产信息不一致的问题，为实施资产电子标识化管理奠定基础。

2.实施阶段（12月1日-20日）。主要完成以下几项工作：

（1）打印标签。安装条码打印机，将盘点终端与资产内控管理系统联通调试。导出实物资产卡片明细表，并按照资产分类和管理部门打印资产标签。

（2）张贴标签。实现一物一卡一条码，确保卡片、条码与财务、资产信息系统相一致。

（3）变更标签。卡物不符、盘盈、盘亏资产及资产信息变动等应及时更新资产管理系统卡片信息，并进行二次张贴标签。

（4）信息更新。根据电子标识化管理实施情况，及时更新系统资产的使用部门、使用人、存放地点、规格型号等数据，调整财务账、资产账等资产信息，做到账实相符、账账相符、账卡相符，为资产报表编制提供依据。

3.总结阶段（12月21日-31日）。要加强工作研究，认真全面总结资产电子标识化管理工作成果和经验，进一步强化国有资产监管，并为下一步推进其他资产电子标识化管理打好基础。本次资产电子标识化管理工作完成后，各单位可根据工作流程和分工等，研究制定本单位《国有资产电子标识化管理办法》。

（三）设备配备。

本次国有资产电子标识化管理盘点终端和打印设备统一由水利厅购置后按片区或单位调剂使用。盘点终端设备按核算单位，每单位一部。资产条形码打印机分片区配备，并指定一家单位负责使用管理，片区内单位共同使用。

1.银川片区水管单位由唐徕渠、惠农渠、西干渠、汉延渠管理处组成，唐徕渠管理处负责使用管理；

2.银川片区事业单位由水利科学研究院、水文水资源监测预警中心、水利工程建设中心、水利电力工程学校组成，水文水资源监测预警中心负责使用管理；

3.银川片区水调中心办公楼由厅办公室、厅机关服务中心、信息中心、水旱灾害防御中心、水利调度中心、水保监测总站、工程定额和质量安全中心、大柳树水利枢纽工程前期工作中心、灌溉排水服务中心、河湖事务中心组成，机关服务中心负责使用管理；

4.吴忠片区由渠首、秦汉渠、盐环定扬水管理处和水利博物馆组成，秦汉渠管理处负责使用管理；

5.中宁片区由七星渠、固海扬水、红寺堡扬水管理处组成，固海扬水管理处负责使用管理。

五、工作要求

（一）推进水利厅资产电子标识化管理是资产规范化管理的重要举措，各单位要切实加强组织领导，高度重视，分工明确，责任到人，确保工作有序开展。

（二）各单位要结合实际制定工作方案，精心组织资产清查盘点，规范实施资产电子标识化管理工作，确保国有资产电子标识化管理实施工作按期完成。

（三）各单位应加强财务和资产管理部门的密切配合，协同对存在的问题进行分析研究，提出解决问题的办法，并加强与主管部门的协调沟通，及时反映工作进展情况。
