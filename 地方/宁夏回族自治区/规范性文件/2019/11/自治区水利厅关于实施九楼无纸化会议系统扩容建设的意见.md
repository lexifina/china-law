# 自治区水利厅关于实施九楼无纸化会议系统扩容建设的意见

水利信息中心：

你中心《关于水利厅九楼无纸化会议系统扩容建设的请示》（宁水信息发〔2019〕8号）收悉，经研究，意见如下：

一、建设必要性

水利厅九楼无纸化会议系统自建成投入使用以来，保障了水利厅多次重要会议的召开，实现了无纸化会议，提高了会议效率，加快了办公速度，系统充分发挥了高效、便捷、节约的作用。水利厅内设机构改革后，新增了部分机关处室，26套无纸化会议客户端已不能满足开会需要数量，导致部分人员无法使用无纸化会议系统参会，影响会议质量。所以，九楼无纸化会议系统扩容改造十分必要。

二、建设主要内容

基本同意方案中提出的扩容建设内容，按照新增12套无纸化设备，并与原有系统进行集成建设。

（一）新增无纸化设备。

基本同意新增12套无纸化设备，主要包括12台15.6寸超薄电容触摸升降终端、4支嵌入式代表发言单元、2套数字会议主机、12套无纸化客户端会议软件、6张无纸化会议桌、12把会议椅、1台交换机、1批线缆辅材等。

（二）系统集成。

基本同意系统集成方案。要求做好与原系统的无缝对接。

三、投资概算及资金来源

基本同意方案中费用概算，资金来源为水利信息中心信息化运维费用。

四、建设周期

基本同意建设周期80天。

五、有关要求

本项目虽为系统扩容项目，但你中心必须严格按照自治区、水利厅相关采购管理办法、工程项目建设管理办法做好采购、建设实施、资金支付等工作，抓紧时间，确保项目按期完成。
