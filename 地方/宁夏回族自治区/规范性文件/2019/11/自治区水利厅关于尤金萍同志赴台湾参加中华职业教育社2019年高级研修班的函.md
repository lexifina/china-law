# 自治区水利厅关于尤金萍同志赴台湾参加中华职业教育社2019年高级研修班的函

自治区人民政府港澳台工作办公室：

根据《中华职业教育社关于组织2019年赴台培训高级研修班的通知》（社发〔2019〕57号）和中央统战部赴台任务通知书（统外出通〔2019〕108号），经研究，拟派宁夏水利电力工程学校党委书记尤金萍同志于2019年12月3日至12日赴台湾参加中华职业教育社组织的2019年高级研修班，主要学习借鉴台湾职业教育在管理体制、办学机制、课程设置、师资培养、学生社团参与学校管理、校企合作等方面的成功经验和成熟模式，在台湾停留 10天，费用共计2.45万元，费用由出访成员所在单位负担。

宁夏水利电力工程学校党委书记尤金萍同志赴台学习交流事宜，已按照干部管理权限报组织人事部门备案，因公临时出国（境）信息公开表已在单位公开张贴公示，没有接到任何反映。

该同志政治可靠，未参与法轮功组织及其它非法活动。

请予办理相关出境手续。

宁夏回族自治区水利厅

2019年11月6日
