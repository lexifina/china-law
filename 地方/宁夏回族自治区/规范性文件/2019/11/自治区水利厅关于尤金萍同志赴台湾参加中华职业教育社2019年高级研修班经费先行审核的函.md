# 自治区水利厅关于尤金萍同志赴台湾参加中华职业教育社2019年高级研修班经费先行审核的函

自治区财政厅：

根据《中华职业教育社关于组织2019年赴台培训高级研修班的通知》（社发〔2019〕57号）和中央统战部赴台任务通知书（统外出通〔2019〕108号），经研究，拟派宁夏水利电力工程学校党委书记尤金萍同志于2019年12月3日至12日赴台湾参加中华职业教育社组织的2019年高级研修班，在台湾停留10天，费用共计2.45万元，费用由出访成员所在单位负担。

请贵厅予以办理出国经费预算审核。

附件：1.因公出国（境）经费预算明细表

2.因公出国（境）任务和经费预算审批表
