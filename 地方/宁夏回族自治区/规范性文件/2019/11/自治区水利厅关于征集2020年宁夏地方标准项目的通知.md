# 自治区水利厅关于征集2020年宁夏地方标准项目的通知

自治区水利厅厅属各单位，各市、县（区）水务局，各有关单位：

为认真贯彻落实自治区人民政府关于加强技术标准化体系建设精神，进一步做好水利地方标准制修订工作，根据自治区市场监督管理厅的通知要求，现公开征集2020年宁夏地方标准计划项目，具体事项通知如下：

一、申报原则

（一）突出重点，创新驱动。重点围绕水利中心工作和实际需要，加强标准研究和自主创新，加快关键技术、核心技术和专利技术向技术标准的转化。

（二）服务民生，促进发展。切实增强水利地方标准制定的针对性和时效性，符合水利发展的需要，有利于推动我区经济社会高质量发展。

（三）填补空白，完善体系。围绕水利现代化发展需要，结合各部门的实际情况，对没有国家标准、行业标准而又需要在全区水利行业内统一的技术要求，可提出标准制定项目申请，以建立和完善我区水利地方标准体系。

（四）组织有力，措施有效。鼓励科研单位、各业务中心（站）、水管单位、企业均积极参与制定技术技术标准，厅机关业务处室可委托具备技术能力的单位编制。

二、报送要求

（一）对报送的项目要从立项的必要性、可行性等方面进行论证，确保申报项目实施的可行性和有效性。

（二）项目申报材料，包括：宁夏地方标准制修订计划项目汇总表（附件1）、《宁夏地方标准制（修）订项目申报书》（附件2）。

（三）水利厅科技与信息化处对水利地方标准制修订项目进行初步审核，并汇总报送自治区市场监督管理厅进行立项审查。

（四）报送时间：请各申报单位在2019年12月18日前将纸质申报材料（盖章）一式两份报送水利厅科技与信息化处，电子版发送科信处邮箱或水慧通。
