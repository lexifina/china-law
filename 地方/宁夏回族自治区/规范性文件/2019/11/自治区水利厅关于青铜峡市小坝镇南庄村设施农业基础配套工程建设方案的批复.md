# 自治区水利厅关于青铜峡市小坝镇南庄村设施农业基础配套工程建设方案的批复

青铜峡市水务局：

你局《关于青铜峡市2019年大中型水库移民后期扶持年度项目建设方案的报告》（青水发〔2019〕191号）收悉。根据《大中型水库移民后期扶持基金项目资金管理办法》《宁夏回族自治区大中型水库移民后期扶持项目管理办法》，我厅会同自治区财政厅组织对随文报送的《青铜峡市小坝镇南庄村设施农业基础配套工程建设方案》（以下简称《建设方案》）进行了审查。经研究，基本同意该《建设方案》。现批复如下：

一、项目建设必要性

该项目为2019年大中型水库移民后期扶持结余资金项目，项目区位于青铜峡市小坝镇南庄村，属于水库移民安置区。项目区现状土地闲置，通过新建温室，配套高效节水田间管网，为发展蔬菜基地休闲农业提供基础设施，对促进农业增效农民增产，改善水库移民生产生活条件，加快移民致富步伐具有重要的作用。工程建设十分必要。

二、水文和工程地质

（一）基本同意项目区水文分析评价结论。

（二）根据《中国地震动参数区划图》（GB18306-2015）,工程区地震动峰值加速度为0.2g，地震基本烈度为Ⅷ度。

（三）基本同意项目区工程地质评价意见。

（四）基本同意工程天然建筑材料评价结论。

实施阶段应结合施工复核工程地质条件，发生变化时应进行详查，并采取相应工程措施。

三、工程建设任务及规模

（一）工程任务。本工程任务是通过新建温室大棚，配套高效节水灌溉管网系统，调整当地经济作物种植结构，改善水库移民收入，提高生活条件。

（二）工程范围及规模。项目区位于青铜峡市小坝镇人民政府以南，分为三个片区，共布设18座温室，A片区6座，B片区5座，C片区7座。设计灌溉面积38.91亩，新打机井1眼。 受益水库移民342人。

（三）水量供需平衡分析。基本同意灌溉制度设计及水量供需分析成果。项目区种植作物为草莓、桃树、西红柿、辣椒，设计灌溉定额为150～260立方米每亩，灌溉水利用系数0.9。项目区总需水量1.01万立方米，现状可供水量30.72万立方米，水量满足需水要求。

下一步补充成井资料，复核单井出水量，确保水源可靠。

四、工程布置及主要建筑物

（一）工程设计标准。主要建筑物级别为5级。工程地震设防烈度为Ⅷ度。

（二）工程总体布置。

基本同意工程布置方案。项目区分三个片区，A、B片区以现有机井为水源，C片区以新打机井为水源；田间设干管、支管和毛管三级管道。温室外侧布置田间生产道路。

（三）主要建筑物。

1．温室工程

新建温室18座，采用装配式钢拱架，跨度为16米，高5.2米。配套卷帘机36台。

2．道路工程。铺设田间生产道路3条，总长402米，砂砾石路面宽4米，厚15厘米。

3．滴灌工程。

新打机井1眼，单井出水量均为 80立方米每小时；新建泵房建筑面积21.78平方米，采用彩钢结构；安装潜水泵1台，变压器1台。铺设PVC管长287米，管径90毫米，压力等级0.63兆帕；铺设PE管长820米，管径50毫米，压力等级0.63兆帕；铺设毛管长18.87公里，管径16毫米；滴头间距0.3米，滴头流量1.38～2.1升每小时。配套闸阀井3座，保护井12座。

实施阶段进一步优化建筑物结构设计，做好施工图审查工作。

五、工期和投资

（一）基本同意施工进度安排，应于2020年6月底前实施完成。

（二）基本同意工程投资概算编制原则和依据。按照2019年第三季度价格水平，核定工程概算总投资为432.00万元。

六、工程管理

（一）青铜峡市灌排管理中心为项目法人，负责项目前期和项目建设管理。项目竣工验收后，由南庄村村委会负责运行管理和日常维护。

（二）项目法人要严格执行基本建设程序，按照批复的规模、内容、地点、工期和标准实施，严格质量安全监督，确保质量和施工安全。将项目基本情况进行公示，接受群众和社会监督。

（三）要按照项目资金管理的有关规定和批复的建设内容使用资金，及时按进度拨付资金，严禁挤占、截留、挪用和滞留。

（四）青铜峡市水务局要加强项目监督指导，督查项目法人按有关规定及时做好资料整编、竣工决算、审计、验收和移交工作。要会同项目属地相关部门，落实项目运行管理责任和维护资金，确保项目良性运行。
