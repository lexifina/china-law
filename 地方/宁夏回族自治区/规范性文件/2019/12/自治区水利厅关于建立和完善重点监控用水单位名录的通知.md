# 自治区水利厅关于建立和完善重点监控用水单位名录的通知

各市、县（区）水务局：

为深入贯彻“节水优先”方针，落实水资源消耗总量和强度双控行动，按照《国家节水行动方案》和实行最严格水资源管理制度要求，自治区水利厅组织建立和完善重点监控用水单位名录，请各市、县（区）水务局高度重视，抓紧完成重点监控用水单位名录制定工作。

一、目标任务

重点监控用水单位监督管理以提高用水效率和控制用水总量为核心，以名录确定的取用水单位监管为重点，充分利用宁夏水资源管理系统，强化取用水计量监控，完善取用水统计体系，为我区落实最严格水资源管理制度，强化水资源刚性约束提供有力的支撑。

二、名录范围

各级水行政主管部门要依据下述要求，建立本级重点用水户名录：

（一）年取用水量5万立方米及以上的供用水企业。

（二）年取用水量1万立方米及以上的服务业用水单位。

（三）具有专业管理机构的大型、5万亩以上重点中型灌区。

（四）纳入国家重点监控用水单位名录的取用水户。

三、分级管理

自治区水利厅根据用水户关停并转情况，更新了自治区级重点监控用水单位名录（详见附件），请五市提出修改意见，于2019年12月10日前报水利厅法规与水资源管理处。

各市、县（区）水行政主管部门应按照各地实际情况和监督管理要求，自行确定市、县级重点监控用水单位名录。市、县级名录确定后，由相应的水行政主管部门进行公布，并向上一级水行政主管部门备案。

四、有关工作要求

（一）2019年12月底前，各市、县（区）须完成本级重点监控用水单位名录建立工作，并按照正在开展的取水口核查登记有关要求，建立完善用水户监管台账。

（二）重点监控用水单位要全部纳入宁夏水资源管理系统，各级水行政主管部门要按照《宁夏回族自治区水资源税征收管理暂行办法》要求，责令重点监控用水单位安装水量在线监测设施，实现取用水数据在线采集、实施监测和互联共享。

（三）重点监控用水单位名录中的单位发生迁址、兼并、破产以及生产规模和用水量发生较大变化的，有关水行政主管部门要在下一年度1月底前对名录进行修订，并向上一级水行政主管部门备案。
