# 自治区水利厅关于加快推进重大水利项目建设工作的通知

各市、县（区）水务局，厅机关各处室、厅属各单位：

根据国务院推进重大项目建设积极做好稳投资工作和全区重大项目建设工作会议部署，抢抓中央增加专项债规模、发行特种债支持重点领域和重大项目建设战略机遇，按照水利厅重大水利项目推进工作领导小组安排，推进重大水利项目早落地、早开工、早投产、早见效，现就有关事宜通知如下：

一、落实责任, 推进重大水利项目尽快实施

2020年我区新建续建重大水利项目25项，总投资431.5亿元，年度计划完成投资71.3亿元，任务艰巨，责任重大。各地、各部门要把水利项目建设作为守住经济发展的“生命线”的战略高度抢抓落实，成立专门机构，主要领导要亲自抓、负总责，分管领导要具体抓，层层分解责任，一抓到底，确保任务完成不打折扣。一是水利厅重大水利项目推进工作领导小组成员单位要立即行动起来，制定工作方案，组织专人办公，协同推进重大项目建设前期工作、资金落实、进度控制、质量安全和监督检查工作。对各县区计划实施面上项目，要下沉一线，加强指导，做好服务。二是强化项目法人机构建设，加强技术力量配备，明确职责分工，建立健全建设管理制度，落实质量责任，严格建设程序，切实履行好项目建设第一责任人职责。三是各工程运行管理单位要履行所属工程建设现场管理责任，主要领导要亲自主抓，配备专职人员，成立工作专班，常驻工地现场，盯住工程质量，协调解决问题，协同项目法人抓好现场管理。四是各地水务局要在抓好面上水利工程建设的同时，充分发挥纽带作用，协助解决重大工程建设中遇到的征地、移民等社会问题，为顺利推进各项工作创造良好条件。五是各有关单位要打破部门界限，加强沟通协调，共同加快推进重大水利项目建设。项目主管部门要在履行监管职责的同时，主动协调解决各参建单位工作中的问题和困难，法人单位和现场管理单位要签署委托管理协议，划分职责，明确责任，避免扯皮。

二、强化措施，确保重大项目任务完成

（一）加强开工准备协调工作，确保重大水利项目顺利落地实施。各单位要在工程建设各个环节提前谋划，在做前期工作的同时，提前协调项目招投标、征地拆迁、施工准备等工作，逐旬、逐月提出工程建设节点要求，实行以日保旬、以旬保月、按天控制的措施，全面加快工程建设步伐。项目前期工作是推动重大水利项目建设的关键，各责任单位要按照《关于全区重大水利工程前期工作推进责任分工的通知》要求，组织精干力量全力推进前期工作，要积极引进全国水利勘测设计的大院、强院参与我区重大水利项目前期工作；项目可研批复后各有关部门和项目法人单位要立即开展工程开工准备工作，不等不靠，压茬推进工程招投标、征地拆迁、三通一平等施工准备工作；要明确年度投资计划执行目标，将目标细化到月到旬，精心组织、周密安排，及时拨付资金，尽快形成实物工作量。

（二）强化工程建设管理工作，确保重大水利项目建设“四个安全”。工程建设管理要严格落实“四制管理”，进一步完善“项目法人负责、设计单位把关、监理单位控制、施工单位保证、政府部门监督”的工程建设保证体系。各级水行政主管部门要切实履行质量监管责任，强化工程各参建单位监管，实行在建项目“飞检”和“第三方”检测制度。项目法人机构要全面落实工程质量终身责任制和《水利工程建设标准强制性条文》规定，强化管理。要深入开展安全生产风险分级管控和隐患排查治理双重预防机制建设，进一步夯实安全生产工作基础，杜绝安全生产事故发生。严格招标投标管理，加快推进宁夏水利工程电子招投标评标系统应用进程,推进电子招投标系统监督平台建设,防范围标、串标等违法违规行为发生。健全守信激励和失信惩戒机制，切实做到奖优罚劣，发挥信用管理制度的激励和约束作用，严格执行《保障农民工工资支付条例》等相关制度，保障水利行业农民工合法权益。全力做好汛期施工防范应对工作，保障工程建设度汛安全。

（三）扎实落实疫情防控工作，确保重大水利项目建设顺利进行。全国疫情防控形势呈现积极向好的态势，自治区疫情得到有效控制，为有序推进工程复工复产提供有利条件，但各参建单位仍然要按照自治区有关要求严格落实参建单位防疫责任，做到组织机构到位、工作方案到位、物资用品到位、应急预案到位、宣传教育到位，确保安全复工、安心复工。

三、加强监督，保证重大项目安全实施。

（一）落实前期工作调度机制。启动水利项目设计质量提升专项整治，严格落实工程质量终身责任制和水利部《水利工程设计失误问责办法》，建立完善勘察、设计、咨询单位市场主体信用体系，落实设计单位失信联合惩戒机制，加大对设计失误问责惩处力度，实现水利工程设计质量大提升。建立重大水利项目前期工作推进“周报告、旬例会、月调度、月通报”机制，将每项重大工程推进落实情况纳入统一调度，严格按照时限要求及时协调解决项目推进存在的问题。

（二）落实工程建设监督考核制度。按照《宁夏水利工程建设项目项目法人管理办法》规定，从建设程序、现场管理，工程进度、质量安全、资金管理等方面12项内容，对相关项目法人开展年度考核，考核排名靠后、考评结果不合格的项目法人单位将按照办法规定进行问责。进一步强化重大水利项目建设情况月调度制度，按照时限要求及时协调解决项目推进存在的问题。每月25日前，各项目法人要将重大水利项目建设情况报水利厅项目建设管理工作组，形成全区水利重大项目推进情况月报，对重大水利项目建设进行月调度。

（三）建立重大项目建设问效机制。对重点水利项目推进落实情况进行定期监督监察，重点围绕建设进度慢的项目征地拆迁、建设进度和资金拨付环节，有针对性的开展督导，及时纠正项目建设中存在的违规、违法行为，确保干部安全。
