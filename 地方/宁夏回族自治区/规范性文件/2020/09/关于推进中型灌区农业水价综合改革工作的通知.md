# 关于推进中型灌区农业水价综合改革工作的通知

各有关市、县（区）水务局：

根据《水利部办公厅关于持续推进大中型灌区农业水价综合改革工作的通知》（办农水函〔2020〕659号）要求，为推进我区中型灌区农业水价综合改革工作，现就有关事项通知如下。

一、充分认识中型灌区水价改革的重要性

各市、县（区）水务局要高度重视，强化部门协调配合，及时协调解决改革中遇到的困难和问题，扎实推进中型灌区农业水价综合改革，与末级渠系水价改革同步计划、同步实施、同步完成，确保中型灌区农业水价综合改革取得实效。农垦集团有限公司要与有关市、县（区）水务局积极主动对接，确保农垦集团管辖范围内的中型灌区一并开展改革。

二、持续推进灌区供水成本核算和价格调整

按照水利部要求，重点中型灌区中还未开展供水成本核算的要抓紧时间启动，争取年内完成成本测算；已经完成供水成本核算的，要及时向有关部门申请调整供水价格。对选取的惠农区沿山井灌区等5个一般中型灌区也要在年内完成成本测算任务。从2019年开始实施的海原县三塘灌区、同心县下马关灌区、沙坡头区兴仁灌区、中宁县马家塘灌区等6个重点中型灌区的续建配套与节水改造项目，要对照年初编制的农业水价改革实施方案，与工程建设同步完成改革，确保水价改革与建设项目同步完工、同时验收。

三、及时做好信息报送工作

各有关市、县（区）水务局要将本辖区内中型灌区农业水价综合改革工作开展情况，包括灌区基本情况、末级渠系供水成本核算和价格调整情况、灌区供水计量设施建设情况和存在的问题及建议等形成总结报告并填写附表，以文件的形式通过水慧通，于12月10日前报水利厅。
