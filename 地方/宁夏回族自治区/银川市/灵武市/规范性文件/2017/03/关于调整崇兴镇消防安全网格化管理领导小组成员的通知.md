# 关于调整崇兴镇消防安全网格化管理领导小组成员的通知

各村、驻镇企事业单位：

为深入、持续的开展消防安全网格化工作，根据人事变动调整崇兴镇消防安全网格化管理领导小组成员如下：

领导小组下设办公室，办公室设在镇安监办，王跃飞任办公室主任，成员吴桂兰,具体负责日常工作。

各成员单位消防工作职责：

崇兴派出所：负责对全镇消防工作实施监管；依法对生产经营单位等消防安全监管对象进行消防安全监管检查，督促整改火灾隐患，并实施跟踪复查，直至整改；参加火灾事故的应急救援和事后的调查处理协调工作。

崇兴市场监督管理所：配合镇有关部门开展消防安全专项整治；协助有关部门依法查处、取缔、吊销不符合消防安全条件单位的生产、经营资格；依法取缔和打击非法、违法经营危险化学品行为。

镇安监办: 负责全镇生产经营单位的安全生产监管，督促单位落实消防安全主体责任；负责协调重点生产经营单位履行消防安全管理职责；负责指导各村切实履行消防安全管理职责。

镇人武部：制定镇重大突发事件和重大灾害事故应急预案，组织开展演练；参加火灾事故的应急救援.

消防专干:负责全镇消防安全的日常监督检查,及时上报相关的信息资料.
