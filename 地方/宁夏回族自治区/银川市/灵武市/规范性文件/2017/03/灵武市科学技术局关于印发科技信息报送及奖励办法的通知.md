# 灵武市科学技术局关于印发科技信息报送及奖励办法的通知

各办公室：

为使我局信息报送及奖励工作规范化、制度化管理，增强工作意识，转变工作作风，提高工作效率，经局务会议研究，现将灵武市科学技术局科技信息报送及奖励办法印发给你们，请认真遵守执行。

附件：科技信息报送及奖励办法

灵武市科学技术局

2017年3月6日

科技信息报送及奖励办法

1、 根据《灵武市政务信息报送工作实施细则》以及上级有关部门关于信息报送工作的具体任务要求，为全面准确反映我市科技工作现状和工作成绩，高质量完成全局年度信息工作任务，特制定本办法。

2、 局办公室、农社办、科特办、工业及知识产权办、地震业务室为信息主要责任主体，原则要求每室办每月撰写2篇信息，科技信息服务中心、科特办负责科技特派员信息上报及管理工作，原则要求每个信息特派员每月上报1篇信息，如遇重大事项，要及时编写信息上报。全年编发科技信息不少于60期。

3、 所撰写信息要求标题准确，主题突出，内容详实，语句通顺。消息类信息要注重时效性，字数一般在300字左右为宜；调研类、总结类信息要注重经验提炼和汇总，字数一般在1000字左右为宜。

4、 信息稿件一律采用灵武科技信息发文稿纸编印，由信息服务中心主任、分管领导审核后签署意见，报主要领导签发。信息工作人员负责科技信息的登记、编排文号、统计，电子文档及时上报上级有关部门，并将所发信息全部上传灵武科技网。

5、 业务室办必须完成所定任务篇目，在完成任务的基础上给予适当奖励，没有完成的不予奖励。机关干部、科技特派员或信息站点报送采用的信息一篇稿件奖励30元。

6、 被各级报刊（信息）转发的，国家级奖励200元，自治区级（厅级）奖励150元，银川市级奖励100元。被多家报刊（信息）同时转发的，按最高级别的报刊标准只奖励一次。

7、 被各级科技、地震网站转载的，国家级100元，自治区级（厅级）80元，银川市、灵武市政府门户网站及科技网站50元。被多家网站同时转载的，按最高级别的标准只奖励一次。

8、 科技信息每季度统计公示一次，被转发或转载的稿件要附原件证明，否则视为无效。每年年度兑现奖励。
