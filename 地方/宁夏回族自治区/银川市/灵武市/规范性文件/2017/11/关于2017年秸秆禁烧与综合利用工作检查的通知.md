# 关于2017年秸秆禁烧与综合利用工作检查的通知

各乡（镇）、农林牧场：

为切实抓好我市秸秆禁烧工作，严格落实常态化禁烧工作机制，促进秸秆禁烧工作更加有效开展，并为兑现2017年秸秆禁烧以奖代补资金提供依据。根据《银川市2017年秸秆禁烧与综合利用以奖代补实施方案》文件精神，灵武市农牧局决定对各乡（镇）秸秆禁烧工作开展情况进行检查，现就有关事宜通知如下：

一、检查时间

11月上旬，具体时间另行通知。

二、检查内容

依据《灵武市2017年秸秆禁烧与综合利用实施方案》、《银川市2017年秸秆禁烧与综合利用以奖代补实施方案》中秸秆禁烧与综合利用以奖代补考核评分表内容进行检查。重点检查内容如下：

1、是否成立相关组织，是否制定相关措施；

2、是否建立乡村队三级网格化管理机制；

3、巡查记录和工作台账是否齐全；

4、抽查1—2个村是否落实网格化机制。

三、检查方式

采取现场汇报和实地查看相结合的方式进行。

四、具体要求

此次检查工作时间紧、任务重，请各乡（镇）高度重视、积极配合，提前按照检查内容及考核细则准备好汇报材料及相关资料。此次检查结果将作为兑现银川市以奖代补资金的重要依据之一。

灵武市农牧局

2017年11月6日

（此件公开发布）
