# 关于成立崇兴镇农村集体资产清产核资

关于成立崇兴镇农村集体资产清产核资 工作领导小组的通知

各村：

组 长：高 春

副组长：吴国海

成 员：王小军 黄芳红 马生军 田生君 杜正勇

王 平 陈美陟 王立宏 王自瑞 杨少武

赵志芳 马淑萍 杨凤萍 李卫仁 张金忠

杨志明 马跃武 杨文江 杨 军 赵连军

周海鹏 杨保金 吴生智 杜少云 白生忠

领导小组下设办公室，办公室设在财经所，王小军兼任办公室主任，负责农村集体资产清产核资日常工作。
