# 灵武市科学技术局关于调整双拥工作领导小组的通知

各室办：

因领导调整，为进一步做好双拥工作，经局务会议研究决定调整灵武市科学技术局双拥工作领导小组。现将组成人员通知如下：

组 长：陈卫军

副组长：王志军、陈建军

成 员：吴大伟、马作斌、崔 巍、周小华、黄金梅

领导小组下设办公室，办公室设在局农业及社会发展科，负责处理食品安全工作日常事务，工作人员崔巍。

灵武市科学技术局

2018年5月11日
