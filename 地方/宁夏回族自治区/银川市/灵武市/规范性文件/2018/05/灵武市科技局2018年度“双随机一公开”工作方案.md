# 灵武市科技局2018年度“双随机一公开”工作方案

各科室、中心：

为进一步推进“双随机一公开”工作，结合工作实际，制定2018度 “双随机一公开”工作方案。

一、总体要求

坚持依法监管、公正高效、公开透明，加强事中事后监管，规范执法行为。

二、基本原则

检查人员应当遵循合法、公正、公开等原则，认真履行监管任务，严格规范文明执法，遵守保密制度及相关要求。按照分工负责、协作配合原则，依法进行检查。做到内容明确、程序合法、文书规范。

三、“双随机、一公开”抽查工作内容

执法工作人员严格按照“双随机一公开”工作要求开展如下工作：

1、建立2018年度随机抽查对象名录库。名录库主要分为7类项目，从随机抽查对象名录中随机选取抽查对象。对监管职责范围内由于之前造成违法事实，已经被列入安全生产“黑名单”的企业，应当纳入随机抽查名录库。

2、编制随机抽查事项清单。编制随机抽查事项清单，切实做到一张表格管检查，具体实施随机抽查时，除有特殊要求外，均应当按照随机事项抽查清单制作执法检查记录和检查表。

3、开展随机抽查工作前，由震害防御科牵头，从检查人员名录库中随机抽取2名以上检查人员，并负责对检查人员进行必要的业务培训指导。检查人员与抽查对象有利害关系的，应依法回避。科学、合理确定随机抽查比例和频次。随机抽查比例和频次要切合实际，确保必要的随机抽查覆盖面和工作力度。年度采用“双随机”抽查的比例一般不低于30%并逐步提高，暗查暗访一般采用“双随机”抽查的方式。对危险性较大的重点单位每年要实现一次检查覆盖；对列入安全生产“黑名单”的单位每半年要实现一次检查覆盖；对发现存在重大事故隐患的单位，要重点监管，增加执法检查频次，督促整改治理。

4、全面公开监管信息。要将随机抽查工作全流程公开，对抽查依据、抽查主体、抽查事项、抽查方式、抽查程序和抽查结果（涉及商业秘密的内容除外），通过信息平台、网站等向社会公开，接受社会监督。

四、工作要求

1、加强组织领导。推广随机抽查是简政放权、放管结合、优化服务的重要举措。我局根据需要开展或者组织开展“双随机”抽查工作，不断提高市场监管执法水平。

2、周密组织计划。要将“双随机”抽查工作纳入年度工作任务，制定年度随机抽查计划，包括抽查事项、抽查时间和抽查范围等进行公示，便于统一协调部署，避免重复、过多抽查或重点领域监管不到位。

3、严格实施检查。执法检查人员应严格按照每个检查项目的实际开展执法检查。综合运用书检查、实地核查、专项核查和网络监测等监管手段，对抽查项目进行检查。可以依法利用其他政府部门作出的检查、核查结果或者专业机构作出的专业结论作为检查的依据。

4、加强跟踪督导和宣传培训。要加强对随机抽查工作的指导和督查，认真梳理和研究工作中出现的矛盾和问题，确保“双随机”工作责任到位、任务落实。积极探索跨部门联合抽查，切实提高监管效能。要加大宣传力度，加强执法人员培训，不断提高执法能力。

5、严格责任落实。要严格执法、依法履职，对本单位检查结果的合法性、准确性和真实性负责。对落实“双随机”抽查工作进展情况进行通报，促进工作落实。对在随机抽查过程中滥用职权、玩忽职守、徇私舞弊的依照有关规定予以处理。
