# 灵武市发展和改革局关于崇兴镇综合养老服务中心项目初步设计的批复

崇兴镇人民政府：

你镇《崇兴镇人民政府关于崇兴镇综合养老服务中心项目立项的函》（崇政函发〔2023〕3号）及相关资料收悉。经研究，现批复如下：

一、建设必要性

为进一步提升综合养老服务能力，满足不同层次老年群体精细化服务需求，根据市政府〔2022〕26号（十八届第30次）常务会议决定，同意实施崇兴镇综合养老服务中心项目，项目代码：2205-640181-11-01-125042。

二、建设地点

位于灵武市崇兴镇韩渠村。

三、建设内容及规模

新建日间照料中心一座，总建筑面积1430.2㎡，配套电气、暖通、给排水及消防工程；购置床位30张、呼叫器6个、计算机及网络设备5套、监控设备1套；室外配套工程包括水、电、暖外网及消防配套设施，绿化及硬化场地1567.14㎡，新建围墙179.20m。

四、建设期限

2023年3月―2023年10月。

五、招标投标

原则同意你单位招标方案（详见附表）。

六、节能、环保

必须使用节能、环保材料。

七、投资概算及资金来源

项目概算总投资708万元。资金来源为自治区民政厅福彩公益资金360万元及市财政配套资金348万元。

八、有关要求

1.项目推进要严格按照《政府投资条例》（国务院令 第712号）《宁夏回族自治区政府投资管理办法》（宁政规发〔2020〕7号）和《灵武市政府投资项目管理暂行办法》（灵政办规发〔2022〕2号）的相关规定执行。

2.为确保工程质量及进度，该工程必须实行法人责任制、招投标制、合同制、监理制，你单位要在建设中严格按照项目基本建设程序和要求组织实施，并加强项目建设资金的使用和管理。

3.项目建设要严格按照批准的建设规模、内容、标准实施建设，不得随意提高建设标准、改变建设内容、扩大投资规模，如遇建设内容与规模发生重大变更，要及时向市政府及我局申报，待批准后方可调整实施，未经同意，在项目验收时不予认可。

4.项目建成后，6个月内向我局提出竣工验收申请，确有困难的，报我局研究同意后可延期验收，延长期一般不得超过6个月。

此批复下达后，原批复《灵武市发展和改革局关于崇兴镇韩渠村综合养老服务中心项目初步设计的批复》（灵发改发〔2022〕143号）同时废止。初步设计批复文件有效期一般为2年，2年内未开工建设或者未办理其他任何手续的，到期自动失效。
