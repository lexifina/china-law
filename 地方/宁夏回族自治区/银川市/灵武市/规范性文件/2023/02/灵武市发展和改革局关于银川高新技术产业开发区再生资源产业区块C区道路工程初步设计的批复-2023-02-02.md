# 灵武市发展和改革局关于银川高新技术产业开发区再生资源产业区块C区道路工程初步设计的批复

市交通运输局：

你单位报来《灵武市交通运输局关于审批银川高新技术产业开发区再生资源产业区块C区道路工程初步设计的函》（灵交函发〔2022〕130号）文件及相关资料收悉。经核实，该项目已在自治区投资项目在线审批监管平台获得项目代码（2210-640181-18-01-356549）。根据市人民政府2022年14号（十八届第18次）常务会议纪要精神，经研究，同意该项目初步设计，现就有关事项批复如下：

一、建设地点

项目位于灵武市银川高新技术产业开发区再生资源区块马家滩C区。

二、建设内容及规模

新建道路3条，并配备建设雨水、污水、给水、路灯等其他附属设施。其中：南北走向修建一条道路，为1号路，建设长度1.378公里；东西走向修建两条道路，为2号路、3号路，2号路建设长度1.015公里，3号路建设长度1.02公里。三条道路共计3.413公里。1号、2号道路等级为城市次干路，3号道路等级为城市支路。

三、建设期限

2022年12月—2023年9月。

四、招投标

原则同意你单位招标方案，详见附表。

五、节能、环保

必须使用节能、环保材料。

六、投资规模及资金来源

项目概算总投资控制在2962.15万元以内，资金来源为市财政资金。

七、有关要求

1.项目建设要严格按照国家和自治区有关基本建设项目的规定，实行项目法人责任制、监理制、招投标制和合同制，按批复的建设内容及规模实施，加强安全、资金和建设管理，确保工程质量及施工安全。

2.项目实施过程如遇建设内容与规模发生重大变更，要及时向市政府及我局申报，待批准后方可调整实施，未经同意，在项目验收时不予认可。

3.每月按时向我局报送项目建设进度情况。项目完成后向我局提出竣工验收申请。
