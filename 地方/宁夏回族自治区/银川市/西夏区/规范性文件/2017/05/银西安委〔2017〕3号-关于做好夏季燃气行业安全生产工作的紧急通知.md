# 关于做好夏季燃气行业安全生产工作的紧急通知

各镇人民政府，各街道办事处，安委会各成员单位及各燃气企业：

为切实加强夏季高温天气燃气安全管理，杜绝因高温而引发的各类燃气安全事故，保障人民群众生命财产安全。按照国务院《城镇燃气管理条例》、《宁夏回族自治区燃气管理条例》，现将有关事项通知如下：

一、加强组织领导，进一步强化“红线”意识

以习近平总书记、李克强总理关于安全生产系列重要指示批示精神为指导，以深入贯彻落实《中共中央国务院关于推进安全生产领域改革发展的意见》为主线，以“减少一般事故、遏制较大事故、杜绝重特大事故”为工作中心，进一步强化政府领导、部门监管和企业主体“三大责任”，以问题为导向，针对二季度及“端午”节前我区安全生产特殊时段、特殊行业领域存在的苗头性问题、认真开展燃气行业安全生产大检查活动，严格落实“四个一律”要求，解决消除各类事故隐患，做到警钟长鸣，有效防范和坚决遏制重特大事故，确保我区安全生产形势总体稳定。

二、突出工作重点，进一步强化监管防范措施

各镇（街道）、各行业主管部门要按照“属地管理”和“管行业必须管安全、管业务必须管安全，管生产经营必须管安全”的原则，立即组织开展燃气行业安全大检查工作。强化行业主管部门监管责任，各行业主管部门分别牵头负责，认真组织开展燃气行业安全大检查工作。

市场监管局：要加强燃气行业安全隐患排查整治工作，重点排查使用液化气的餐饮经营单位、宾馆饭店、工地食堂等液化气重点使用场所以及液化气经销站点、公共场所燃气设施、汽车加气站等，深入到户、到门店，逐户排查，逐户登记造册，跟踪落实。对存在安全隐患的，立即责令停产停业整改，严格落实整改措施，明确隐患整改时限，确保隐患整改到位。严厉打击使用报废、过期未检及检验不合格钢瓶及在液化气中添加二甲醚等违法违规经营行为。

消防大队：要对各经营场所使用液化气、天然气的加大检查力度，认真排查隐患，确保疏散通道、安全出口畅通和消防设备设施齐全完好，进一步完善消防设施，集中整治违规使用燃气、疏散通道不畅等突出问题，对不具备安全生产条件的经营场所要坚决停产停业整改。

公安分局、交警一 二大队：负责对燃气运输车辆的检查，对超速、超载、疲劳驾驶等交通违法行为予以查处，从严查处擅自实施油改气的机动车辆。负责对各燃气企业和销售站点的防火制度建立、防火人员落实、消防设备配置等情况进行全面检查，对不符合要求特别是防火间距不足的站点，依法责令整改。对无证经营液化气的违法经营者，发现一个，取缔一个，涉及犯罪的移交司法机关予以严肃处理。

各镇（街道）：要加强液化气储配站、供应点以及燃气用户的安全大检查，确保监管到位，不留死角。同时，进一步加强安全宣传教育工作，特别是要加强企业从业人员、餐饮服务人员、社区居民的安全意识和技能，完善群众监督机制，鼓励群众举报，形成燃气安全群管群防格局。鼓励现有使用燃气的餐饮企业及住户，安装燃气泄漏报警自动切断系统，或改为使用电磁炉，提高此类企业的本质安全，防止群死群伤事故发生。

各燃气企业：一是要认真开展燃气用户的入户检查工作，逐户消除事故隐患；二是加大对占压燃气设施的违章建（构）筑物、施工破坏燃气设施等违规行为的巡查力度和密度，加强对燃气管线设施的保护，及时修补损坏、缺失的标识桩（贴）；三是要加强对燃气设施设备的巡查、维护、保养工作，特别是在夏季高温时段要加强巡查，做到高温时段按规定坚持对罐体喷淋降温，定期检查消防器材、安全阀、压力表等特种设备的维护保养情况。四是要认真开展燃气安全知识宣传教育，采取在供气小区、商户张贴宣传画、用气注意事项等方法积极宣传燃气使用常识和应急处置措施，提高用户的安全意识和自我防护技能。

三、落实值班制度，进一步加强应急值守

各镇（街道）、各部门要认真落实24小时值班制度和领导带班制度，确保通信联络畅通。负有安全监管职责和承担专业应急指挥职能的有关部门，要准备足够的应急力量，遇有突发公共事件，按规定及时启动应急预案，妥善进行处置，同时迅速上报有关情况。任何单位和个人不得迟报、瞒报和漏报。各成员单位要加强协作配合和联系沟通，在信息资源、监督执法以及抢险救援等各个环节形成工作合力，确保人民群众生命财产安全。
