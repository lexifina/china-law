# 关于西夏区公务机动车辆定点加油有关问题的通知

各镇人民政府、各街道办事处、政府各部门、直属机构：

《宁夏回族自治区公务机动车辆定点加油管理暂行办法》实施以来，对加强我区各级国家机关、事业单位、团体组织公务机动车辆管理，规范财政支出行为，提高资金使用效益起到了积极的作用。随着近几年公路交通运输建设的推进，现有的部分定点加油站发生了较大变化。为此，自治区财政厅委托自治区政府采购中心就宁夏公务用车定点加油站项目重新进行了公开招标，严格按照采购程序，并结合各标段供应商的油品质量、经营业绩、服务承诺以及加油站区域分布等因素指标，确定了中石油等144家供应商为我区公务用车定点加油站供应商。

根据《自治区财政厅关于宁夏公务机动车辆定点加油有关问题的通知》（宁财采发〔2017〕360号）文件精神，现将西夏区公务机动车辆定点加油有关事项通知如下，请各单位认真执行。

一、请各公务用车单位结合实际，自行选择定点加油卡的使用。选择“原政府采购加油卡”的，仍采用“原政府采购加油卡”的管理办法执行，此卡可在自治区内所有定点加油站使用；选择“中国石油政府采购联名加油卡”的，请携带本单位相关证明材料，到中石油宁夏分公司安排的服务点办理政府采购加油卡的转卡业务，具体结算办法按“中石油政府采购联名加油卡”使用办法执行，此卡限在自治区内中石油的定点加油站使用。以上两卡各单位只能选择其中一种，以便本单位管理。

二、本次确定的定点加油站期限为2017年6月1至2019年6月1日。
