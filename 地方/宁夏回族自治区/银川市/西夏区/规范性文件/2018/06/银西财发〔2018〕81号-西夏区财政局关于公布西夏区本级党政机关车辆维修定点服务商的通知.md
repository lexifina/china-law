# 西夏区财政局关于公布西夏区本级党政机关车辆维修定点服务商的通知

各镇人民政府、各街道办事处、政府各部门、直属机构、人民团体、各有关企业:

为认真落实党政机关厉行节约、反对浪费相关规定，严格控制党政机关行政成本增长，进一步加强西夏区党政机关行政事业单位车辆维修服务管理，西夏区财政局通过公开招标，确定了5家车辆维修定点服务商。现将2018-2020年西夏区本级党政机关行政事业单位车辆维修定点服务商名单及有关事项通知如下:

一、西夏区本级党政机关行政事业单位、人民团体、有关企业车辆维修应当在定点服务商中，结合单位实际自行选择，并在合同价格以内签订具体服务合同。

二、各车辆维修定点服务商应按照投标文件和本次招标文件中明确的服务规范提供服务。

三、此项工作已纳入财政监督管理检查范围，请各单位和服务商严格落实自治区、银川市关于车辆定点维修服务的相关规定。对车辆维修定点服务中存在的违法违规行为，我局将依照相关法律法规进行处理和处罚。

四、本次确定的定点维修维护期限为两年，自2018年6月10日起至2020年6月9日。
