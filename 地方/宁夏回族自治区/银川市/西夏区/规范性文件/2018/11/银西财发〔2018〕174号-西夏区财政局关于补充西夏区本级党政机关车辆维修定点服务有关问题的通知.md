# 西夏区财政局关于补充西夏区本级党政机关车辆维修定点服务有关问题的通知

各镇人民政府、各街道办事处、政府各部门、直属机构、人民团体、各有关企业:

通过各单位公务用车定点维修服务实施情况反馈，并与现有定点维修服务商接洽，现有的定点维修服务商不能满足我区部分车辆维修服务需求。经西夏区人民政府同意，我局委托采购代理机构就西夏区本级党政机关车辆维修定点服务商进行了补充招标，严格按照采购程序，补充了3家服务商作为我区党政机关车辆维修定点服务商。

现将补充服务商公布如下，请各单位认真执行。定点维修服务相关操作事宜请按照《西夏区财政局关于公布西夏区本级党政机关车辆维修定点服务商的通知》(银西财发〔2018〕81号)有关要求执行。
