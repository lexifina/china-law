# 西夏区司法局关于司法行政工作促进民营经济发展实施方案

为减轻民营企业负担、解决民营企业发展难题、营造公平竞争环境，根据司法部出台《关于充分发挥职能作用为民营企业发展营造良好法治环境的意见》的文件精神，西夏区司法局高度重视，结合工作实际，制定实施方案。

一、工作目标

为民营企业发展提供坚实法治保障、营造良好法治环境、提供优质法律服务。围绕减轻民营企业负担、解决民营企业发展难题等方面，创新拓展公共法律服务，法律援助、法治宣传工作积极服务民营企业。

二、任务措施

(一)源头防范，加强普法宣传。一是全面落实普法责任制。推动相关国家机关开展民营企业权益保障法治宣传，切实做到“谁执法谁普法”“谁服务谁普法”，引导各级领导干部强化法治观念和依法行政能力。二是以“法律八进”为载体，深入推进“法律进企业”，帮助民营企业制定法治宣传计划，开展进民企方针政策和法律知识普及活动。二是紧扣重要时间节点开展集中宣传，充分利用“4.26”知识产权日、宪法宣传周等时间点，选取民营企业关注的法律法规或法律热点问题，集中开展大型的普法宣传活动。

(二)主动维权，降低维权门槛。一是发挥公共法律服务平台服务民营企业功能，充分依托三大平台，不断完善实体平台建设，推行“一窗办多事”，实现“前台统一受理，后台分流转办”;激发热线平台活力，提高“12348”热线知晓率，强化服务人员队伍建设;强化网络平台效用，充分发挥互联网高效便利的优势，形成三大平台有机互补的服务新格局。二是建立民营企业矛盾纠纷调解工作机制，加强矛盾纠纷排查，第一时间开展调处，对于矛盾多发的乡镇(街道)人民调解委员会可以设立专门的服务窗口，支持有条件的民营企业建立人民调解组织或者劳动争议调解委员会。三是积极做好民营企业员工的法律援助工作，开辟绿色通道，优先受理，为企业困难职工、下岗职工等困难群体提供法律援助。

(三)创新形式，提供优质服务。完善便民服务机制，推进信息化建设，畅通民营企业员工维权渠道，加强办案质量监管，提供优质服务，依托中国法律服务网、宁夏法律服务网及两微一端，形成多角度、多方位、多层次服务格局，构建与“110”“12345”“12333”“12315”等服务热线平台联动调处机制，及时提供法律咨询、代书、调解、案件诉讼代理等全方面的公共法律服务。

三、组织领导

(一)提高认识站位。各司法所、公共法律服务中心要充分认识进一步做好促进民营区企业经济发展工作，维护民营企业员工合法权益的重要性，按照本方案要求，纳入工作日程，精心组织，确保各项工作措施落到实处，营造良好法治环境，提供优质服务。

(二)加强宣传推广。各司法所、公共法律服务中心要充分发挥微信、微博等新媒体作用，开展丰富多彩的线上线下互动及服务活动，进行全方位宣传，形成活动信息资料及时总结上报。

(三)加强监督管理。司法局将对活动开展情况进行不定期抽查，召开学习交流会分享优秀经验做法，确保活动扎实推进，取得实效。

银川市西夏区司法局
