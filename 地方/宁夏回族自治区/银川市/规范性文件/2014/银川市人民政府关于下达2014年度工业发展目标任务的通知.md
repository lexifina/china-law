# 银川市人民政府关于下达2014年度工业发展目标任务的通知

各县（市）区人民政府，市政府各有关部门，银川经济技术开发区管委会：

2014年度工业经济发展目标任务经市人民政府研究同意，现予以下达。各县（市）区人民政府及银川经济技术开发区务必要围绕目标任务，强化责任，狠抓落实，努力推进产业结构调整，着力提升企业发展质量和效益，促进工业经济稳定增长，确保完成2014年工业经济发展各项目标任务。
