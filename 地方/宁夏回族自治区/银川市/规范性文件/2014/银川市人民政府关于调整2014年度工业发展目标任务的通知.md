# 银川市人民政府关于调整2014年度工业发展目标任务的通知

各县（市）区人民政府，市政府各有关部门，银川经济技术开发区管委会：

因宁夏电力公司数据分解到自治区五市，我市的数据也要相应调整。经市人民政府研究，将2014年度全市工业经济发展目标任务进行调整，现将调整后的县（市）区目标任务予以下达，请认真贯彻执行。
