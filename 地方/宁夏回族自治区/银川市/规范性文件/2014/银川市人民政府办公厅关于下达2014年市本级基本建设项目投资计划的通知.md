# 银川市人民政府办公厅关于下达2014年市本级基本建设项目投资计划的通知

各县（市）区人民政府，市政府各部门、直属机构：

2014年是全面贯彻落实十八届三中全会、自治区十一届三次全会和中央、自治区经济工作会议精神的关键之年，全面做好2014年投资和项目推进工作，对坚持稳中求进总基调，抢抓“两区”、“两大战略”机遇，深入实施“2258”工作思路，加快经济提质增效升级，加快内陆开放实验区核心区建设，努力开创银川跨越式发展新局面意义重大。根据自治区经济工作会议和市委全体（扩大）会议、市两会精神，市人民政府近期研究确定了2014年市本级基本建设项目投资计划，涉及滨河新区、银川综合保税区、银川科技园、阅海湾中央商务区、宁夏生态纺织示范园区、农林水牧、交通、园林绿化、社会事业、城市建设、社会保障等领域，此次下达项目共260个，项目总投资821亿元，2014年年度计划投资257亿元。现将《银川市2014年市本级基本建设项目投资计划表》随文下达，并就有关事项通知如下：

一、强化认识，落实责任

各县（市）区、项目责任单位要深刻领会自治区经济工作会议和市委全体（扩大）会及市两会精神，坚定不移推进经济工作项目化，把加快项目建设作为事关我市经济发展的全局性、战略性任务抓紧抓好。要切实加强对投资工作和项目建设工作的领导，坚持主要领导负总责，分管领导具体抓，具体工作专人办，创新工作方法，压缩办理时限，强化工程质量，确保工作实效。

二、做实前期，确保实效

各县（市）区、各部门和项目单位要按照文件精神，抓紧做好项目各项前期工作，积极落实各方面的建设条件，提高前期工作质量，尽快形成工程量，力促项目早日开工。项目前期工作涉及的各职能部门要根据银政办发〔2013〕187号文件要求和此次《通知》文件精神，主动做好项目审批服务，落实开工条件，推动项目早日落地实施。

三、强化管理，保证质量

在项目建设过程中，要严格执行《宁夏回族自治区政府投资项目管理和责任追究办法》，严格执行项目“四制”管理（法人责任制、招投标制、工程监理制、合同制），完善“代建制”，坚决杜绝“三边”工程（边勘察、边设计、边施工），防止“三超”现象（超规模、超标准、超投资），坚决杜绝“豆腐渣”工程。要强化项目资金管理，做到公开透明，杜绝滞留、挤占、挪用、截留，以及弄虚作假和铺张浪费。不断完善投资项目后评价和责任追究制度，高度重视建设工程安全质量工作，严格落实建设工程安全质量责任制和工程质量终身负责制。认真落实中央和自治区关于治理工程建设领域突出问题相关决定，积极开展工程建设领域突出问题专项治理工作，确保工程进度、工程质量和投资效益。

四、加强督查，严格考核

要加强监测统计分析，建立严格的项目信息报送制度。各县（市）区、各部门和项目单位必须要在每月5日前向市政府督查室、市发改委及时、准确报送上月项目进展信息，做到月度汇总、季度分析、年度总结。要强化项目督查，各县（市）区要进一步完善督查工作制度，形成层级督办网络，确保各项工作落到实处。在推进项目建设过程中，尤其要加强对重点建设项目的服务和监管力度；项目责任单位和各相关部门要采取多种举措做实项目前期，开辟绿色通道，加快审批服务，切实推进项目进度，确保重点建设项目早开工、早达效。市政府督查室、发改委、监察局等部门要定期或不定期对项目进展情况进行全方位督促检查，及时全面掌握工作进度，通报督查情况，便于市委、市政府决策，集中解决项目推进问题，确保目标任务的顺利完成。项目建设审批服务、信息上报、督查通报等情况将全部纳入年底对各部门绩效考核范围之内。
