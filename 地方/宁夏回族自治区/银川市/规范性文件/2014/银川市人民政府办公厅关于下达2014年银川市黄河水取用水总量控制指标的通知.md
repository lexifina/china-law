# 银川市人民政府办公厅关于下达2014年银川市黄河水取用水总量控制指标的通知

各县（市）区人民政府，银川滨河新区管委会：

银川滨河新区作为宁夏内陆开放型经济试验区的核心区，要举全市之力，加快推进滨河新区建设，现将2014年我市黄河水取用水指标分配（具体指标见附件）。请各县（市）区政府及银川滨河新区管委会严格按此指标取水、用水，不得超用。

附件：银川市2014年取用水总量控制指标表
