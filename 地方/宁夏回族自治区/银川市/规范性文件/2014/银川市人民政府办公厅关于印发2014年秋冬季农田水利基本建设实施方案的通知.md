# 银川市人民政府办公厅关于印发2014年秋冬季农田水利基本建设实施方案的通知

各县（市）区人民政府，市政府各有关部门、直属机构：

《银川市2014年秋冬季农田水利基本建设实施方案》已经市人民政府研究同意，现印发给你们，请认真贯彻执行。

银川市人民政府办公厅

银川市2014年秋冬季农田水利基本建设实施方案

一、指导思想

以党的十八大和十八届三中全会精神为指导，按照习近平总书记提出的“节水优先、空间均衡、系统治理、两手发力”的治水思路，紧紧围绕区、市党委、政府关于“转作风抓发展”和“大干150天、努力完成重点工作任务”的安排部署，以“抓投入、促建设，抓管理、保实效，抓改革、活机制，强基础、惠民生”为主题，以促进农民增收、饮水安全、防洪安全为核心，通过开展农田水利基本建设，着力夯实农业基础，促进可持续发展，为全面建成小康社会提供有力支撑。

二、建设思路

全市秋冬季农田水利基本建设总的建设思路是：围绕一个目标，即：通过大搞农田水利基本建设，进一步改善农业生产条件，实现农民增收，保障粮食安全、水安全。坚持二个原则，即：按照全域规划的理念，坚持打破县乡村界限，统一规划、统筹安排，连片推进；坚持整合资金、集中投入，各负其责、各记其功，提高建设标准。突出三个重点，即：一是突出解决民生问题，继续把战边缘、灭死角，解决事关群众利益的“灌水难、排水难、吃水难、行路难、环境差”等热点难点和“最后一公里”问题做为重点；二是突出支持发展高效节水农业，进一步促进农业增效、农民增收；三是突出骨干排水沟综合整治，继续按照“大挖沟、挖大沟、挖深沟”的工作思路，打通“断头沟、竹节沟”，彻底改善农田排水条件。注重六个结合，即：一是结合群众路线教育活动，实行任务分解、结对帮扶、干群共建抓农建的工作机制，将群众反映的问题做到件件有落实、事事有回应；二是结合特色产业发展，坚持“以水定结构、以水定产业、以水定规模、以水促发展”，围绕农业结构调整和现代农业发展，对节水高产经济作物的种植区域，通过修水源、砌护渠、铺管道等措施，配套完善灌排设施，推动特色产业发展。三是结合“美丽乡村”建设，大力实施主干道路大整治、大绿化和农村环境洁净工程，有效改善生产环境、生态环境和农村面貌；四是结合土地集约化经营，通过建设高标准农田、发展高效节水项目，吸引企业、大户参与农建，加快土地集约化经营进程，促进农村土地新型经营主体的发展；五是结合机械化作业，转变农建组织形式，进一步加大机械施工力度，提高工程建设机械化作业程度；六是结合科技创新，大力推广滴管、沟道防塌、自动化控制等新工艺、新技术、新材料，提升农建科技含量。

三、目标任务

一是高标准农田建设：全市秋冬季农田水利基本建设计划建设高标准农田60个片区60.61万亩，其中改造中低产田30.1万亩。新增节水灌溉面积22.87万亩，其中新增高效节水灌溉面积10.07万亩。改善灌溉面积54.53万亩，畦田建设34.97万亩。同时，结合银北地区百万亩盐碱地改良骨干排水工程治理排水沟103条，长；建设防洪工程、节水灌溉工程、人饮工程、中小河流治理项目等重点项目工程47处。

二是“美丽乡村”环境综合整治以及高效节水农业示范区建设：按照自治区党委、政府提出的，以环境优美、农民富裕、民风和顺的“美丽乡村”建设目标，大力实施规划引领、环境整治、生态建设、服务提升、文明创建、农房改造、基础配套等重点工程建设以及主干道路大绿化大整治，全市今年结合农田水利基本建设共打造 “美丽乡村”环境综合整治示范点9个，其中：灵武市、永宁县和贺兰县各建设“美丽乡村”示范点不少于2个，兴庆区、金凤区和西夏区各建设“美丽乡村”示范点不少于1个。同时，为大力推进高效节水农业示范区的建设力度，全市计划建设高效节水农业示范区9个，其中：灵武市、永宁县和贺兰县各建设高效节水农业示范区不少于2个，兴庆区、金凤区和西夏区各建设高效节水农业示范区不少于1个。

（二）骨干沟道治理工程

全市继续按照“大挖沟、挖大沟、挖深沟”的工作思路，实施骨干沟道综合整治工程，要求各县（市）区将骨干沟道综合整治同防洪、排涝、湖泊湿地补水、绿化美化城乡环境结合起来，不断提升骨干沟道治理水平，使之成为银川市又一道靓丽的风景线。全市计划整治骨干沟道89条，长，其中：干沟6条，长；支沟83条，长。整治标准为干沟一侧沟堤宽，另一侧沟堤整治成宽的生产路，沟堤两侧各建成宽林带；支沟一侧沟堤整治成宽的生产路，两侧各种树2-3行。具体任务为：

1.灵武市：清淤整治马弯子沟、张家沟、榆木桥大沟等骨干沟道49条，长146.92公里，其中干沟3条，长35.5公里；支沟46条，长111.42公里。

2.贺兰县：清淤整治银新干沟、立岗镇兰丰沟等骨干沟道19条，长39.65公里。其中干沟1条，长2.0公里；支沟18条，长37.65公里。

3.永宁县：清淤整治永安沟、一排沟两侧附沟等骨干沟道9条，长110公里。

4.兴庆区：清淤整治西丰沟、黄羊沟、八一沟等骨干沟道7条，总长42.5公里。

5.西夏区：清淤整治同庄村五队公路边沟、兴泾镇二支沟、良渠沟等骨干沟道5条，长11.8公里。其中干沟2条，长5.3公里；支沟3条，长6.5公里。

四、进度安排

第一阶段：安排部署、宣传动员（2014年9月）

1.根据制定的方案，分解落实任务，启动全市秋冬季农田水利基本建设大会战。

2.各县（市）区要在前分别召开县、乡（镇）、村级秋季农田水利基本建设动员会，进一步细化任务，落实责任。

第二阶段：典型示范、组织落实（-）

各县（市）区采取项目整合、人机结合、示范带动、领导干部和技术人员包片、包点、包沟渠等形式，快速建成2个以上的高标准示范区，以典型示范带动全面工作，掀起建设高潮。

第三阶段：交流促进、巩固提高（-）

左右召开全市农建现场观摩会，交流经验，查找不足，推动全局。

第四阶段：检查验收、总结表彰（-12月底）

制定全市农田水利基本建设验收奖励办法，对各县（市）区农田水利基本建设完成情况进行全面检查验收，评选获奖等次，兑现“以奖代补”资金，推荐成绩突出的县（市）区参加全区农田水利基本建设竞赛评比。

五、保障措施

（一）科学规划，讲求实效。坚持高起点、高标准、高质量、综合治理。将农田水利基本建设与特色产业、高效节水农业相结合，与发展农业机械化及农业新技术推广相结合，与农村环境整治相结合，实行沟、渠、田、林、路、庄全面整治，提高农田水利基本建设的综合效益。集中解决好群众反映强烈的灌水难、排水难、饮水难、行路难等热点、难点以及“最后一公里”的问题。各县（市）区要根据本地区实际，找准农业生产中的突出问题，抓住重点，将农田水利基本建设、“美丽乡村” 环境综合整治和高效节水农业相结合，通过打造精品亮点示范工程，进一步夯实农业基础，以促进农业增产增收。同时，灵武市、永宁县以巩固提高标准以及抓好一批重点水利工程建设为重点；贺兰县要继续把重点放在解决洪广镇、立岗镇等农田水利建设的边缘死角，集中力量打攻坚战和歼灭战，全力推进农村环境改善和发展高效节水农业；兴庆区以抓好国家投资的项目为重点；金凤区以扩大小畦田节水灌溉面积为重点；西夏区以贺兰山东麓葡萄长廊节水灌溉为重点，各县（市）区力求做到以渠系灌区或整个乡镇做为建设规划区域，高标准、高起点统一规划，集中劳力，分步实施，逐年推进，扩大农田水利基本建设的受益面，使一些一村一队无法解决的重点、难点问题得到彻底解决。

（二）加强宣传，提高认识。各级政府要把农田水利基本建设作为改善农业生产条件、提高农业综合生产能力、发展现代农业、实现农业增效、农民增收的基础性工作来抓，纳入农村工作的重点，充分利用电视、网络、报刊等各种舆论宣传手段，大张旗鼓地宣传农田水利基本建设的重要意义，及时宣传报道各类先进典型，使群众充分认识到搞好农田水利基本建设的重要性，调动群众大干农田水利基本建设的积极性和自觉性，营造热火朝天、比学赶超、苦干实干的良好氛围，把今秋农田水利基本建设工作抓实、抓好、抓出成效。

（三）优化机制，确保投入。进一步优化资金投入机制，各县（市）区要认真贯彻落实中央、区、市关于加快水利改革发展的决定精神，加大本级财政对水利的投入，确保今年农田水利投入的总量和增幅要有明显提高。进一步优化项目整合机制，各县（市）区要按照“统一规划、统筹安排，渠道不乱，用途不变，各投其资，各负其责、各记其功”的原则，科学整合涉及农田水利建设的各类项目，避免重复建设，提高资金的使用效率。进一步优化竞争激励机制，市上继续按照“大干大支持，小干小支持，不干不支持”的原则，全市计划继续安排补助资金1000万，对确定的重点整治沟道、按照规定标准建设的“美丽乡村”环境综合整治示范点和高效节水农业示范区给予资金补助。进一步优化群众投工投劳机制，充分发挥群众在农田水利基本建设中的主体作用，规范引导农民通过“一事一议”的管理程序投工投劳。各县（市）区要将组织群众参加农田水利基本建设与农村社会事务管理相结合，投工与筹资相结合，人力与机械施工相结合，村队组织形式与协会参与组织形式相结合，通过政策宣传、典型引导、干部带动等措施，千方百计动员群众投入。完善和推行核发工票、相互调工和以资代劳等办法，用足用活各项惠农政策，调动群众参与农田水利基本建设的积极性。

（四）坚持标准，确保质量。有关部门要切实履行好各自的工作职责，加强农田水利基本建设的管理，严格质量标准，实行目标管理责任制和责任追究制，建立健全检查、监督、考核、奖罚制度，按照统一的建设标准严格把关，并抽调专门人员，组成督查组深入到各县（市）区进行检查督导，严禁各类花架子工程、面子工程，做到建设一片，成一片，发挥效益一片。在重点项目建设上严格执行项目法人制、招投标制、施工监理制、合同管理制的“四制”管理，确保工程建设质量。要通过样板沟、样板渠、高标准农田样板片，示范带动面上农田水利基本建设，使全市农业基础设施建设整体水平有一个较大提高。

（五）突出重点，严格验收。为高标准、高质量完成全市农田基本建设任务，调动各区县（市）争先创优的工作积极性，市上将根据“黄河杯”竞赛标准，制定严格的考核奖励办法，组织水务、发改委、财政、农牧、林业、政府办公厅、政府研究室等相关部门，并邀请市委政研室、市人大、市政协专委会领导共同组成验收组，对全市秋季农田水利基本建设情况进行全面的检查和验收。今年市财政将继续安排 “以奖代补”资金1000万元，设一、二、三等奖，根据验收评比结果，兑现以奖代补资金。对不能完成建设任务的，取消评奖资格，给予通报批评，并削减下一年度水利项目的配套资金，同时，根据评比结果，上报自治区农田水利基本建设指挥部，推荐参加全区“黄河杯”竞赛评奖。

（六）加强领导，落实责任。为确保今秋农田水利基本建设的顺利实施，切实加强对全市农田水利基本建设工作的组织领导，市农田水利基本建设指挥部将成立由水务、发改、财政、农牧、林业等单位组成的督查组，对各县区进展情况进行督促检查，及时表扬先进，督促后进。各县（市）区也要相应地成立督查组，对本县（市）区的农田基本建设工作进行督促检查，发现问题，及时整改，使各项工作落到实处。同时，把农田水利基本建设作为考核各级领导干部工作能力、工作作风、工作业绩的一项重要内容，严格奖罚制度，逐级签订责任书，层层落实制，做到主管领导亲自抓，分管领导重点抓，一级抓一级，层层抓落实，上下联动，齐抓共管，掀起全市农田水利基本建设的高潮。
