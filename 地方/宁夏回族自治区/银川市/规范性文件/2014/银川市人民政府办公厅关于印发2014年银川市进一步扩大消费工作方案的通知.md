# 银川市人民政府办公厅关于印发2014年银川市进一步扩大消费工作方案的通知

各县（市）区人民政府，市政府各有关部门：

现将《2014年银川市进一步扩大消费工作方案》印发给你们，请遵照执行。

银川市人民政府办公厅

2014年6月10日

2014年银川市进一步扩大消费工作方案

今年以来，受国内外经济增速放缓、外部需求不足等因素影响，全市社会消费品零售总额增长呈现稳中趋缓的趋势，消费对经济增长的拉动作用减弱，为增强商贸流通企业发展信心，加快现代流通基础设施建设，改善消费环境，扩大消费，改善民生，提升全市经济发展的内生动力，根据《商务部 财政部 中国人民银行关于“十二五”时期做好扩大消费工作的意见》和全市2014年第一季度经济形势分析会议精神，现就银川市进一步扩大消费工作安排如下：

一、工作目标

2014年，全市实现社会消费品零售总额395亿元、同比增长13%。

二、主要任务

（一）加大市场主体引进和培育力度，促进实惠消费。

1.加快商贸项目建设和品牌引进力度。协调推进10大商业综合体和星级酒店项目建设，年内建成并开业运营商业综合体3座；协调引进优衣库、阿玛施、德莎等一批国际国内知名品牌落户银川。

2.探索建立品牌消费集聚区，扩大品牌消费。加大商业特色街区培育力度，突出文化休闲主题，出台支持政策，强化名店效应，提升档次水平，充分发挥商圈的聚集辐射效应。

3.加强现代流通体系建设。支持骨干企业发展连锁经营、统一配送、电子商务等现代流通方式，减少流通环节，降低流通成本，更大地让利于广大消费者。

（二）大力发展社区商业，促进便利消费。

1.发展“51015”工程（商业生活服务圈，即5分钟可达便利店和各类服务网点，10分钟可达超市和餐饮店，15分钟可达购物中心）。争取全区“51015”工程试点，大力开展社区商业生活服务圈建设，优化社区商业网点布局，健全社区商业业态，促进和带动社区居民便利化消费。鼓励支持连锁零售、餐饮企业入驻社区，提高社区商业品牌效益；选择一批社区进行试点，鼓励建设菜店、家政服务店、便利店、早餐店、洗染店、维修店、再生资源回收等便民设施，建立健全社区生活服务网点。

2.继续推进社区蔬菜直销店新建和升级改造工程。新建和升级改造一批平均面积100平米左右、钢架结构、水电配套齐全的社区蔬菜直销店。

3.启动电子商务进社区试点。依托社区便利店、社区蔬菜直销店，开展网络零售、网上订货接单、网订店取、送货（服务）上门等业务，逐步建设公益性的家政服务信息平台，推动便民电子商务发展。

（三）培育消费热点，促进大众消费。

1.启动2014年银川大众美食和大众购物消费促进活动。组织大中型商贸企业利用重大节日时点，举办以婚庆、亲情、师生情、迎新等为主题的购物节会等,采用延时服务、有奖销售、优惠赠送、打折促销、上门送货、网络订购、家电以旧换新等方式扩大销售。全年利用周末或节假日在各商业圈和商业广场开展各类户外促销宣传50次以上，做到“无节造节、有节造市”，加大宣传，吸引毗邻地区群众消费。同时，鼓励餐饮企业转型，开展网上订餐配送，走大众化、集聚化、品牌化、连锁化、差异化发展的道路。

2.大力发展会展经济。组织举办好各类大中型展会，带动住宿、餐饮、广告、旅游、文化、休闲娱乐等服务消费。完善银川国际会展中心功能设施，延长会展中心办展时间，提高会展场馆利用效率。协调组织在北京、上海等城市举办银川商品大集，扩大我市名优特色商品的对外销售。

3.培育新型消费热点。鼓励各类商贸流通企业与信息化服务类企业开展合作，重点推动百货副食类、餐饮娱乐类、生活服务类商贸企业与银川电信百业联盟平台开展互惠合作，打造跨行业合作的消费链条，培育新的消费热点。

（四）加快农村现代市场体系建设，扩大农村消费。

1.完善乡镇基本生活服务网络。推进“万村千乡市场工程”企业转型升级，鼓励企业在人口集中的乡镇设立维修、理发、照相、大众浴池等服务网点，推动乡村消费。

2.开展农村促销活动。组织商贸流通骨干企业利用农村集贸市场开展服装、日用消费品、副食品、家电等商品大集、家电下乡大蓬车等活动30场次以上，将物美价廉的商品送到农民群众门口，方便农民消费，拉动农村消费增长。

（五）做好“限下”企业培育入库工作。

加强商贸服务企业的培育力度。年内争取至少50家以上骨干批发零售、住宿餐饮企业“上限”入库。其中：兴庆区培育入库12家以上、金凤区培育入库8家以上、西夏区培育入库8家以上、贺兰县培育入库8家以上、永宁县培育入库6家以上、灵武市培育入库8家以上。对入库企业，市财政每家给予10万元奖励。

三、保障措施

（一）加强组织领导。

1.各县（市）区要加强扩大消费工作的组织领导，切实履行属地管理责任，成立相应的领导小组和机构，统筹规划，明确工作责任，提出工作目标，确保扩大消费工作扎实推进。

2.市直相关部门要密切配合，发挥合力，搞活流通、扩大消费，提升消费对经济增长的拉动作用。

（二）加大财政支持力度。

市财政安排专项资金，支持开展扩大消费和“51015”商业生活服务圈试点建设，重点用于大中型商贸零售企业延时经营电费补贴、大众美食和大众消费促进季宣传奖励、大中型餐饮住宿企业大众化转型奖励、限额以上企业入库奖励、大中型商贸零售企业下乡促销奖励等，完善市场流通体系，扩大城乡居民消费。

（三）降低流通费用。

1.研究出台有关支持会展业等商贸流通业发展的政策，降低流通成本，提高流通效率。

2.市城管、环保、工商、建设等部门对于大中型商贸企业开展户外促销宣传给予大力支持，减少审批环节，减免有关费用，营造有利于扩大消费的环境。

（四）规范统计工作。

进一步研究消费统计的方式方法，完善统计制度；加大统计监督执法力度，规范“限上”企业报送工作，督促企业及时、准确报送数据，做到应统尽统、应报尽报。
