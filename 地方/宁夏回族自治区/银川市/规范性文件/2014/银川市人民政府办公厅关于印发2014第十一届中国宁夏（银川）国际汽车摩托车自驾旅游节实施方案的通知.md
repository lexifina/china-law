# 银川市人民政府办公厅关于印发2014第十一届中国宁夏（银川）国际汽车摩托车自驾旅游节实施方案的通知

各县（市）区人民政府，市政府各部门、直属机构:

为进一步展示自治区和我市的优势文化旅游资源，扩大我市机车运动品牌的影响力，努力打造特色鲜明的国际旅游目的地城市，我市联合自治区旅游局、自治区体育局将于2014年7月25日—29日举办“2014第十一届中国宁夏（银川）国际汽车摩托车自驾旅游节”。现将该活动实施方案予以印发，请各单位按照相关职责要求，认真贯彻落实。

银川市人民政府办公厅

2014年6月19日

2014第十一届中国宁夏（银川）国际

汽车摩托车自驾旅游节实施方案

一、指导思想

以努力把宁夏建设成为“特色鲜明的国际旅游目的地”为目标，以全力打造“西北风情旅游目的地和中国自驾游之都”为推手，总结历届节庆经验，力求在办节思路、办节模式、办节效益上实现突破，加速汽摩自驾旅游节向市场化、产业化、品牌化、国际化方向发展。依托银川等宁蒙陕甘青省区合作城市丰富多彩的自然、文化旅游资源，通过推广、培育、提升“中国宁夏（银川）国际汽车摩托车自驾旅游节”品牌形象，联合打造中国首条西北风情自驾车旅游黄金线路，让游客充分领略宁夏深厚的人文底蕴，时尚的机车文化和激情的城市活力，将银川“中国自驾游之都”这一名片植入人心，吸引更多中外游客来宁观光旅游、休闲度假、商务会展，实现以节庆带动旅游的发展战略。

二、活动主题

世界看我的——魅力、速度、激情、风情

三、活动时间

2014年7月25日—7月29日

四、活动地点

主会场：银川市

分会场：宁蒙陕甘青毗邻合作城市、景区

五、主要活动安排

本届汽摩自驾旅游节共有宁夏魅力、宁夏速度、宁夏激情、宁夏风情四大板块十三项主题活动。

（一）宁夏魅力。

1.2014第十一届中国宁夏（银川）国际汽车摩托车自驾旅游节开幕式

活动时间：7月25日20:00——21:30

活动地点：贺兰山体育场

邀请人员：国家部委（含协会）领导，外国使节参赞，区市领导，车手、俱乐部代表

内容提要：

（1）开幕仪式部分

①升国旗、奏国歌；

②领导致辞；

③领导宣布汽摩自驾旅游节开幕（鸣礼炮）。

（2）演出部分（双语主持）

①魅力—情景巴士（主题思想：以流动歌舞剧形式表现来自世界各地前来参加汽摩节游客欢快、激情的生活情景）；

②风情—由百人志愿者控制大型空中玩偶入场，绕场一周到公交站牌停留展示，随后放置场中央；5尊三太子（世界物质文化遗产）出场引出花车女王,绕场到公交站牌（即主席台旁），三太子气氛喜剧热闹表演与观众互动，花车女王随后到公交站牌（即主席台旁），中间花车法国女歌手经典歌曲演唱，两边花车女王伴舞；

③速度—豪车展示环节，豪华摩托车及超级跑车紧跟花车女王后侧，驶入公交车站（即主席台旁），停留展示，引擎轰鸣及闪灯；

④激情—豪华重型卡车载俄罗斯摇滚乐队，停留公交车站旁（即主席台旁），追光灯跟彩色摇头灯配合外籍乐队表演，冷焰火、彩虹机、气球 、灯光 、烟机全场气氛配合，开场巡游收尾；

⑤全国汽车摩托车俱乐部车手展示入场、酷炫亮相，主持人依次介绍；

⑥汽摩特技表演——世界顶级汽车、摩托车表演队，进行前所未见的特技秀表演（穿插车迷宝贝拉拉队热舞表演）。
