# 银川市人民政府办公厅关于印发银川市人民政府2014年度立法工作计划的通知

各县（市）区人民政府，市政府各部门、直属机构：

《银川市人民政府2014年度立法工作计划》已经十四届银川市人民政府第16次常务会议讨论通过，现印发给你们，并提出以下意见，请一并贯彻执行，执行过程中遇到的问题，请及时向市法制办反映。

一、加强组织领导。政府立法关系到我市经济社会发展大局，关系到广大人民群众的切身利益。承担政府立法项目起草、调研任务的部门要高度重视，建立健全立法工作责任制，确保“任务、时间、人员、责任”四落实。

二、保障立法进度。各立法项目起草部门要严格按照工作责任表（见附件）及时完成起草任务。确有特殊原因，不能如期完成的，起草部门应当及时向市政府提交书面报告，说明情况。

三、深入调研论证。各立法调研项目责任部门要以法律、法规为依据，紧密联系本市实际，深入调查研究，做好调研工作。调研结果要形成书面材料，及时送交市法制办。如条件比较成熟，应及时提请市政府审议。

四、提高立法质量。各起草部门要从大局出发，克服部门利益倾向。对涉及重大民生问题的立法，要严格按照《国务院关于加强法治政府建设的意见》(国发〔2010〕33号)的规定，履行公众参与、专家咨询、风险评估、合法性审查、集体决定的程序，公众关注度高的项目还必须进行听证。草案涉及其他部门职责的，要与相关部门充分协商和沟通，对不予采纳的意见要说明理由，相关部门要给予配合。起草部门要努力提高送审稿的质量，力求做到结构合理、逻辑严密、条理清楚、用语规范，制度切实可行，能够真正解决问题。

五、加强监督检查。市法制办要不断完善立法工作机制，加强与承担政府立法项目起草、调研任务的部门的联系，提前介入各部门的起草工作，及时了解立法计划项目的起草、调研工作进展情况，对立法计划的实施情况进行检查和督促。各有关部门要予以配合。
