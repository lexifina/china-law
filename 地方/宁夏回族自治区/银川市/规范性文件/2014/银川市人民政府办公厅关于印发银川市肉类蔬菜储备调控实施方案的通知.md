# 银川市人民政府办公厅关于印发银川市肉类蔬菜储备调控实施方案的通知

各县（市）区人民政府，市政府各部门、直属机构：

《银川市肉类蔬菜储备调控实施方案》已经市政府第24次常务会议研究同意，现印发给你们，请认真贯彻执行。

银川市人民政府办公厅

2014年9月3日

银川市肉类蔬菜储备调控实施方案

根据国务院、自治区有关文件精神，结合我市实际，为进一步平抑我市肉类蔬菜市场价格，保障肉类蔬菜市场供应，特制定银川市肉类蔬菜储备调控实施方案。

一、基本原则

坚持市场化运作方式，政府给予适当补贴和扶持，建立银川市肉类蔬菜储备调控的长效机制，保证市场供应，平抑肉类蔬菜价格大幅度波动，保障日常消费和满足应急需求。

二、储备调控内容

（一）储备调控菜

1.储备调控品种与规模

结合银川本地居民的生活消费习惯和蔬菜供应情况，对土豆、大白菜、青萝卜（白萝卜）、葱头、莲花菜、胡萝卜等六个品种进行储备，储备量为16000吨，其中土豆3000吨、大白菜3000吨、青萝卜（白萝卜）3000吨、胡萝卜3000吨、葱头2000吨、莲花菜2000吨；对西红柿、辣椒、茄子、芹菜等四个品种进行调控，调控量为4000吨，其中西红柿1000吨、辣椒1000吨、茄子1000吨、芹菜1000吨。

2.储备调控期限

根据银川市气候及消费特点，储备调控蔬菜时间定为每期6个月（当年10月1日—次年3月31日）。储备菜实行动态轮换制度。承储单位应及时落实储备蔬菜计划，并在组织日常经营过程中保持与储备计划相适应的储备规模、结构、质量和管理，其动态库存不得低于承储计划确定的储备规模。

3.招标方式

采用公开招标方式进行招标。

4.投放价格

储备蔬菜投放价格原则上按照企业收储时的价格执行，调控菜零售价原则上执行北环蔬菜果品批发市场前一日批发价，最高不得超过北环批发市场前一日批发价格的5%。

5.投放网点

由市商务局、财政局、物价局在招标确认的承担储备调控菜实施企业所属市辖三区部分肉菜流通可追溯（价格监测）网点进行储备调控菜投放。投放点按照方便购买、三区合理布局、信息可溯、企业申请、择优选取的原则，采取公开方式评审确定。

（二）储备肉

1.储备品种与规模

根据肉品储存期限和市场应急需要，将冷冻牛羊肉、冷冻猪肉作为市级应急储备肉，2014年我市计划储备应急冷冻肉200吨。其中，冷冻牛肉75吨、冷冻羊肉75吨、冷冻猪肉50吨。

2.储备期限

储备期1年（自2013年11月20日-2014年11月19日）。

3.招标方式

采用公开招标方式进行招标。我市具有冷冻肉储藏能力的畜禽定点屠宰加工企业和大型超市公司参与投标。

4.投放价格

市级储备肉进价（成本价）以招标价为准。计划市级储备冷冻牛、羊肉投放零售价19元/500g[低于储备成本价（进价）6元/500g],冷冻猪肉投放零售价10元/500g[低于储备成本价（进价）2元/500g]。

5.投放时间

市级储备肉在春节、开斋节、古尔邦节、国庆节期间分批投放。

6.投放网点

由市商务局、财政局、物价局在市辖三区选择肉菜流通可追溯（价格监测）网点进行储备肉投放。投放点按照方便购买、三区合理布局、信息可溯、企业申请、择优选取的原则，采取公开方式评审确定。

（三）调控肉

1.调控品种与规模

根据市场肉类价格涨幅，将新鲜牛羊肉、新鲜猪肉（五花肉和前后腿肉）作为市级调控肉。计划投放调控肉2000吨。其中，新鲜牛、羊肉1500吨，新鲜猪肉500吨。如市场肉品价格异常，可增加投放数量。每个投放网点每天计划投放政府补贴新鲜牛、羊肉各300公斤；投放政府补贴新鲜猪肉150公斤，各点多投不限，但不予补贴。

2.投放时间

2014年10月1日至2015年2月18日。

3. 投放价格

以低于市场零售价格3元/500g确定投放新鲜牛、羊肉的价格，以低于市场零售价2元/500g确定投放新鲜猪肉的价格,市场零售价格以市物价局公布的数据为准。

4. 投放网点

由市商务局、财政局、物价局在市辖三区选择35个肉菜流通可追溯（价格监测）网点进行调控新鲜牛、羊肉投放；选择25个肉菜流通可追溯（价格监测）网点进行调控新鲜猪肉投放。投放点按照方便购买，三区合理布局，信息可溯，企业申请、择优选取的原则，采取公开方式评审确定。

三、补贴方式与标准

肉类蔬菜储备调控实施企业在储备调控实施期间，每天根据各自投放网点投放的储备调控肉菜数量与价格形成报表，报表加盖公章报市商务局，同时在银川市肉类蔬菜流通追溯管理平台每日报送进销数据，待储备调控结束后，由市商务局、市财政局组成验收小组，通过查验相关数据资料进行验收核算，验收核算后由市财政局将肉类蔬菜储备调控补贴资金划拨实施企业账户。

经测算需安排专项资金3161.05万元用于银川市实施肉类蔬菜储备调控工作，其中：储备菜财政补贴资金预算1259.05万元、调控菜财政补贴资金预算560万元、储备肉财政补贴资金预算242万元、调控肉财政补贴资金预算1100万元。

（一）储备调控菜财政补贴资金预算

1.土豆、大白菜、青萝卜（白萝卜）、葱头、莲花菜、胡萝卜等六种耐储蔬菜

（1）资金占用银行利息。土豆、大白菜、青萝卜（白萝卜）、葱头、莲花菜、胡萝卜等六种耐储蔬菜16000吨货物价值（2014年7月批发价计算）1710万元，按2014年银行贷款基准利率6%上浮50%(人民银行规定商业银行贷款利率在基准利率基础上实行上下浮动,最低下浮10%,最高上浮80%)利率为9%计算，6个月产生的银行利息76.95万元。

（2）蔬菜损耗费。土豆储藏损耗为5%，大白菜储藏损耗为15%，青萝卜储藏损耗为7%，葱头储藏损耗为4%，莲花菜储藏损耗为15%，胡萝卜储藏损耗为7%（损耗率是根据北环批发市场在储藏蔬菜时实际发生的损耗测算），16000吨蔬菜储藏损耗费用为126.1万元。

（3）仓储费。按照当前银川市大白菜、莲花菜、土豆、胡萝卜、青萝卜（白萝卜）、葱头冷库冷藏费100元/吨/月核算，16000吨储备菜储备6个月共需储备费960万元。

（4）装卸费。按照当前银川市蔬菜装卸费15元/吨/次，储藏期内装卸4次，16000吨蔬菜装卸费为96万元。

需要费用1259.05万元。

2.西红柿、辣椒、茄子、芹菜等四种常用蔬菜（非耐储蔬菜）

承担蔬菜价格调控销售的实施企业在调控期间以政府调控指导价进行销售，市财政局按照政府调控指导价35%给予流通环节补贴，流通环节补贴包括配送成本、分拣费用、人工费用、耗材及蔬菜正常损耗等，根据2013年10月1日-2014年3月31日北环批发市场蔬菜批发价格测算，2014年10月1日-2015年3月31日，西红柿、辣椒、茄子、芹菜等四类调控菜批发价格预计分别为4元/公斤、6元/公斤、3元/公斤、3元/公斤，预计补贴费用560万元。

对蔬菜实施储备调控，市财政每年需安排补贴资金1819.05万元，实际补贴资金以实际发生价格为准。

（二）储备肉财政补贴资金预算

主要是冷冻肉储备费用补贴和储备肉投放所产生的价差损失补贴。

1.冷冻肉储备费用补贴

包括储备肉冷藏保管费用补贴和利息补贴。参照中央冷冻肉冷藏保管费用补贴计算办法和2013年银川市市级冷冻肉费用补贴中标价格2100元/吨计算，储备200吨冷冻肉需冷藏保管费用补贴42万元。

2.储备肉投放价差损失补贴

参照2013年元旦、春节冷冻肉投放价差标准，按冷冻牛、羊肉6元/500g、冷冻猪肉2元/500g补贴计算，2014年春节、开斋节、古尔邦节、国庆节投放200吨冷冻肉（其中牛羊肉150吨、猪肉50吨）需财政补贴价差损失200万元。

市级冷冻肉储备投放，预计共需财政补贴资金242万元。

（三）调控肉财政补贴资金预算

1.投放新鲜牛羊肉1500吨，按照3元/500g的补贴标准计算，需财政补贴资金900万元。

2.投放新鲜猪肉500吨，按照2元/500g的补贴标准计算，需财政补贴资金200万元。

实施调控肉投放，预计共需财政补贴资金1100万元。

四、肉类蔬菜储备调控实施企业要求

（一）实施企业网点要设置储备调控肉菜投放专区或专柜，统一悬挂 “政府储备调控蔬菜销售点”、“政府储备调控肉销售点”标识牌或条幅，在销售专区要悬挂公示牌，注明品种及当日价格，同时要设立调控肉投放举报投诉电话、价格举报投诉电话和服务投诉电话，自觉接受监督；建立投诉处置机制，及时处理群众投诉和举报，做到优质商品、优质服务、优良环境。

市商务局举报投诉电话：6889220 6889244

市物价局价格投诉电话：12358

（二）承担肉类蔬菜储备调控投放的实施企业要安排专人负责储备调控肉菜的销售工作，建立购销台账制度，做好销售登记。每天根据各自超市销售的数量与价格及时报送报表。

（三）肉类蔬菜储备调控投放实行限量供应，储备调控菜每人每次10个品种限购7.5公斤，储备调控肉每人每次每个品种限购2.5公斤，仅限个人消费者购买，不得销售给餐饮、食堂等经营性单位。

（四）承担肉类蔬菜储备调控投放的实施企业在投放过程中要严格执行最高限价，要严格把控储备调控肉菜质量及品质，不得以次充好，不得混淆品种，不得惜售，不得“一品多价”，销售的调控新鲜牛、羊肉必须执行统一定价，不得进行分割等次按不同价格销售；销售的猪肉严格执行五花肉、前后腿肉统一定价，不得再进行分割等次按不同价格销售；各投放点销售政府调控肉不得搭售，尤其是销售的新鲜羊肉不得搭售羊油（每个羊后腿带羊尾油不得超过0.5斤），确保市民买到质优价廉的储备调控肉菜。

（五）承担肉类蔬菜储备调控的实施企业要将信息化系统与肉菜追溯系统进行匹配联网，并在银川市肉类蔬菜流通追溯管理平台每日报送进销数据，确保信息可查证。

五、保障措施

（一）建立监管机制

由市商务局、市财政局和市物价局对肉类蔬菜储备调控投放进行检查，加强监督考核和奖罚。各投放点如有违反以上要求，一经查实，将取消该投放点当日投放补贴资金，发生三次以上将取消该投放点所属企业肉类蔬菜储备调控投放资格并列入“黑名单”，三年内不得再申请肉类蔬菜储备调控投放资格，同时取消该企业申报自治区、银川市商务民生各类扶持政策资格。市农牧局要做好肉类蔬菜储备调控企业与我市相关肉类蔬菜生产基地和合作社的对接工作。

（二）政策资金保障

对承储单位在储备过程中发生的合理费用给予必要的补贴，对企业建设和改造仓储设施积极争取相关政策资金扶持。

（三）交通运输保障

建立肉类蔬菜运输“快速绿色通道”，确保肉类蔬菜运输畅通。

（四）社会秩序保障

公安、工商、质监、宗教事务和物价等部门加强执法力度，严厉打击囤积居奇、哄抬物价、牟取暴利、短斤缺两等损害消费者利益以及破坏市场经营秩序、扰乱应急处置工作等违法活动，依法从重从快惩处。

（五）统计分析保障

国家统计局银川调查队会同商务、物价等部门做好肉类蔬菜储备调控投放点价格监测工作，分析投放价格对消费价格指数(CPI)的影响并提出措施。
