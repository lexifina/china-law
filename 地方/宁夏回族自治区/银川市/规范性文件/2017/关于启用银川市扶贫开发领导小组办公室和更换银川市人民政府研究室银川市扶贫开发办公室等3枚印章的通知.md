# 关于启用银川市扶贫开发领导小组办公室和更换银川市人民政府研究室银川市扶贫开发办公室等3枚印章的通知

根据中共银川市委办公厅 银川市人民政府办公厅《关于调整银川市扶贫开发领导小组组成人员的通知》（银党办综〔2017〕8号）文件有关要求，因工作需要，经市政府同意，即日起启用银川市扶贫开发领导小组办公室印章。同时，因原印章陈旧破损，更换银川市人民政府研究室、银川市扶贫开发办公室2枚印章，原印章同时作废。

银川市人民政府办公厅

2017年11月7日
