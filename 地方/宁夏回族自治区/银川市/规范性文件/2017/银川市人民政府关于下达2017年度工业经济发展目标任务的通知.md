# 银川市人民政府关于下达2017年度工业经济发展目标任务的通知

各县（市）区人民政府，市政府各有关部门、银川经济技术开发区管委会：

经市人民政府研究同意，现将2017年度工业经济发展目标任务下达。各县（市）区人民政府及银川经济技术开发区管委会要围绕目标任务，强化措施、狠抓落实，促进工业经济稳定增长，确保完成2017年工业经济发展各项目标任务。

银川市人民政府

2017年2月13日
