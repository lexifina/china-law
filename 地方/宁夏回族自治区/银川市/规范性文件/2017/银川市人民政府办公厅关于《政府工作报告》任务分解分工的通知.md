# 银川市人民政府办公厅关于《政府工作报告》任务分解分工的通知

各县（市）区人民政府，市政府各部门、直属机构：

经市十五届人大一次会议审议通过的《政府工作报告》，是各级各部门谋划好今后五年和做好今年工作的“路线图”。2017年是新一届政府的开局之年，也是供给侧结构性改革的深化之年。各级各部门要认真贯彻落实习近平总书记来宁视察重要讲话精神、中央经济工作会议、农村工作会议精神，围绕自治区党委十一届九次全会、银川市第十四次党代会和区市“两会”安排部署，把落实《政府工作报告》提出的各项目标任务作为履职尽责的重点，以奋发有为、敢于担当的精神状态，善谋善为、善作善成，撸起袖子狠抓落实，确保全市经济社会发展主要预期目标顺利实现。

一要加强组织领导。各级各部门要高度重视、加强领导、统筹兼顾、精心组织。市政府分管领导要靠前指挥，责任单位“一把手”要亲自负责，按照任务分工，认真研究、梳理分解，制定详细的工作推进计划和责任管理清单，严格按照时间节点完成各项任务，确保重大政策、重大改革、重大任务、重大措施落到实处。

二要加强协作配合。各级各部门要立足全局、加强协调，切实提高工作效率。需要多个部门和有关县（市）区共同参与的工作，牵头市长和部门要负起组织协调、牵头抓总的责任，及时与配合部门沟通协商；协同部门要积极主动，密切配合，通过现场会、推进会等方法共同完成好工作任务。尤其是涉及国家、自治区层面的工作，各相关部门要主动对接，争取支持。

三要加强督查问责。各级各部门要对任务进展及完成情况实时自查，做到心中有数。市政府督查室要制定专项督查计划，对各级各部门工作进展情况采取动态抽查和重点督查督办，同时纳入绩效考评业务指标进行考核。对积极作为的要强化激励，对庸政懒政怠政和不作为、慢作为、乱作为等行为进行通报并严肃问责，确保不折不扣完成目标任务，实现本届政府良好开局。

附件：《政府工作报告》任务分解分工

银川市人民政府办公厅
