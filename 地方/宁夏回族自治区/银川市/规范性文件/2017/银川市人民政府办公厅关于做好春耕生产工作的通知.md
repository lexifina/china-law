# 银川市人民政府办公厅关于做好春耕生产工作的通知

各县（市）区人民政府：

一年之计在于春。搞好春耕生产，对于全面做好“三农”工作，确保农业增效、农民增收至关重要。针对今年的气候特点和土壤墒情情况，为切实做好春耕组织生产工作，现将有关事宜通知如下：

一、及时加强与气象部门会商，引导组织适时播种

据气象局测报，我市自去年入冬以来未出现有效降雪，干土层厚度约2公分，0—50公分土壤含水量较上年同期偏低约3%。今年春季气温回升迅速，较历年同期偏高0.8—1.0℃，降水偏少20—30%，土壤失墒散墒加快，起落潮时间偏早，春播适宜期缩短。

2月17日上午，我市预计降温5℃左右，18日气温大幅上升，19日至21日气温下降5℃左右，其中20日夜间有雨雪过程，后期气温逐步回升。综合近期气象条件，农业与气象专家建议：今年春播适宜期可提前至2月23日，争取在3月10日前完成春播。

近期，市、县（市）区两级农牧部门要加强与市、县（市）区两级气象部门会商，及时掌握天气情况、土壤墒情，加强分析研判，指导农民、种粮大户、专业合作社适时播种，确保春耕顺利进行。

二、依法做好农资投入品的市场监管，切实保障农资质量安全

各级农业行政执法部门要加大对农资市场的监管力度，严厉打击假冒伪劣农资产品，净化农资市场，稳定肥料价格；要积极引导广大农民施用配方肥，在完善肥料配方和施肥建议卡的基础上，通过为农民免费提供测土配方施肥技术服务，积极组织引导肥料企业按配方生产和供应配方肥，真正建立起配方肥有效供应网络，确保广大农民用上放心肥、安全肥；要做好对配方肥质量的监管，抽样测定配方肥的养分含量，确保配方肥的施用效果；要以种子、农药、农机及其配件为重点，对农资市场进行联合检查。

三、全面做好春耕机械检修保养，充分发挥农机在春耕生产中的作用

要积极组织农机技术人员进村入户，指导帮助农机手开展农机具检修和调试保养，确保农机具技术状态良好。要充分发挥基层农机推广服务站、农机合作社和农机大户的作用，积极开展集中检修和保养服务，确保在春耕作业前全面完成农机具检修。要根据春耕生产进度，及时调度农机具，提高农机作业效率,确保作业质量。

四、主动做好技术指导服务，提高备春耕科技含量

组织全市农业专业技术人员，深入春耕生产一线，举办培训班，开展科技咨询，发放宣传资料，为农民提供春耕生产技术服务。针对今年农田墒情比往年差的情况，指导农民及早开展春播整地、顶凌耙耱、重耱保墒、早播快播、抢墒播种、应用包衣种子等抗旱措施，充分利用早春回潮墒抢播春小麦，确保在起潮前完成播种。

五、广泛宣传惠农政策，调动农民备耕生产积极性

通过广播、电视等新闻媒体，大力宣传中央1号文件精神和自治区、银川市支农惠农政策，及时把今年备耕形势和任务传达到乡、村和农户，充分调动农民备春耕生产的积极性。
