# 银川市人民政府办公厅关于做好清明节祭扫工作的通知

各县（市）区人民政府，市政府各部门、各直属机构：

为做好2017年清明节祭扫工作，确保群众祭扫活动人身安全，保障人民群众度过一个“安全、文明、和谐、有序”的节日，现将有关事项通知如下。

一、目标任务

从迎接党的十九大胜利召开的政治高度、以对人民群众生命财产高度负责的态度，充分认识清明节祭扫工作面临的形势任务，强化红线意识和底线思维，确保清明祭扫活动平安有序，大力宣传殡葬改革，推行节地生态安葬和绿色殡葬，深化殡葬系统行风建设，努力实现“文明祭祀、平安清明”的工作目标。

二、基本原则和工作重点

坚持以人为本、统一指挥、分级负责、及时应对、科学决策、协调合作的工作原则，分工协作，各司其职，各尽其责，预防为主，果断处置。

以提高应对突发事件的能力为重点，消除隐患、预防火灾和疏导交通，广泛深入宣传、提升服务水平，推进文明生态殡葬祭，要结合清明节群众祭扫活动“短时间、小空间、高密度、多明火”等特点，研究制定工作方案，提前谋划，周密安排，全力做好隐患排查和风险防控工作。

三、明确分工，确保祭扫活动安全有序

安监部门要认真履行安全生产监督管理职责，组织协调相关单位做好安全检查和应急救援，制定应急处置措施。要组织安委会成员单位进行安全检查，做到重点部位、关键环节和重要设备“三个必查”，现场协调落实各项安全防范和交通疏导措施，严防火灾、踩踏和车祸等安全事故的发生。

民政部门作为殡葬工作主管部门，要强化对各殡葬服务场所安全措施的监督检查。要指导和监督各殡葬服务单位切实落实安全管理责任，制定清明期间突发事件应急预案，合理安排祭扫场所及周边交通疏导和火源管控，做好单位内部治安保卫，为群众提供便捷、温馨、周到的服务。要深入开展以“鲜花换纸钱”“丝带寄哀思”等活动，逐步使文明低碳祭扫理念成为社会自觉行为。

公安部门要做好重点祭扫区域交通疏导工作，保障交通畅通，处置祭扫活动中的治安案件。要根据植物园、榆树沟公墓、金山陵园、马鞍山陵园等群众祭扫较集中的地方，合理安排消防警力和消防车辆执勤备勤。要加强交通秩序维护工作，适时增设机动车临时绕行、单行、禁行等标志，采取分流措施，保障祭扫群众和车辆的疏导疏散。要做好清明交通宣传工作，及时播报车辆绕行信息，引导群众错峰祭扫，减少交通拥堵。

交通运输部门要根据清明节的祭扫群众流动特点，提前做好通往陵园、公墓、殡仪馆的道路勘察、标志设置、道路维修、障碍清除等工作，保障道路畅通。要及时增开前往祭扫地区的专线公交车，对人流集中的线路调整班次密度，增设加班车辆。要实时发布便民出行信息，保证祭扫群众乘车需求。

环保部门要强化殡葬活动的生态环境监管，结合城乡环境综合整治改进殡葬服务管理，推广环保殡葬新技术，支持推行节地生态安葬。

卫计部门要在植物园、榆树沟等重点祭扫场所配备医疗救护车辆，做好祭扫活动中突发病人以及突发事件致伤人员的救治工作。

城管部门要对公墓、陵园附近违法占道经营行为进行查处和清理，依法制止沿街烧纸、抛撒纸钱等不文明殡葬祭行为。

林业部门要组织森林和草原防火指挥机构开展森林、草原防火安全检查，加大巡查密度，及时发布森林、草原火险和火灾信息，严格管理野外用火，发现火灾及时扑救。

市场监管部门要加强殡葬用品市场管理，集中清理打击非法生产销售违法违规和封建迷信祭祀用品的行为。

四、 工作要求

（一）加强领导，完善保障工作机制。要在市委、市政府统一领导下，按照属地管理原则，加强组织协调，压实工作责任，强化协同意识，形成“各司其职、各负其责、齐抓共管”的清明节群众祭扫保障机制，确保部门联动、快速反应、形成合力。要加强对殡葬服务单位的指导和检查，督促其切实履行安全管理和服务保障职责。对因工作不力，引发安全责任事故，造成人员伤亡和群众财产损失的，要追究有关负责人的责任。

（二）多措并举，营造良好舆论氛围。清明节是社会各界集中关注殡葬行业的重点时期，也是开展清明文化和殡葬改革宣传的有利时机。要认真策划宣传方案，组织开展形式多样、内容丰富的殡葬改革和安全生产宣传活动，着力加强与公众、媒体的对话交流和良性互动，主动回应社会关切热点问题与群众诉求，凝聚改革共识，营造良好舆论氛围。

要以弘扬厚养薄葬和绿色殡葬理念为主旋律，积极宣传殡葬法规政策和惠民殡葬举措，努力引导群众自觉参与文明低碳祭扫。要充分发挥广播、电视、报纸等传统媒体和网络等新兴媒介的作用，有效增强殡葬宣传活动的影响力和覆盖面，突出“绿色生态、文明节俭、为民惠民、安全祥和”等内容，大力传播殡葬行业正能量，积极配合新闻媒体，宣传文明祭祀的新方式、新风尚，殡葬服务的新内容、新举措，殡葬改革的新政策、新要求和低碳、环保、生态、节地等现代殡葬的新理念，树立殡葬为民服务品牌意识，使清明节活动成为殡葬行业展示为民服务形象的舞台。要积极推广“鲜花祭奠”“居家祭奠”“网上祭奠”“错峰祭奠”“社区祭奠”等新形式，引导群众自觉破除陈规陋俗，抵制低俗愚昧的祭祀行为，倡导科学、文明、环保、健康的祭祀方式。

（三）以人为本，提升殡葬服务水平。各级民政及殡葬管理部门要坚持“以人为本、为民服务、文明健康、优质高效”的工作方针，牢固树立“民政爱民、殡葬为民”的工作理念，持续深化“殡葬服务月”活动，提升人员素质和专业化服务水平，不断改善服务条件，全面公开服务内容、标准、价格等信息，全面推动殡葬改革进程，保障群众知情权，增强殡葬服务公开透明度。

各部门、各相关单位要把清明节祭扫服务保障工作作为社会管理能力的一次集中演练，优化和改进服务管理能力，提升监管执法水平，树立廉洁从业形象，全面维护节日期间的社会稳定。

银川市人民政府办公厅

2017年3月20日
