# 银川市人民政府办公厅关于印发2017亚洲都市景观奖颁奖礼暨银川城市节活动方案的通知

《2017亚洲都市景观奖颁奖礼暨银川城市节活动方案》已经市人民政府专题会议研究通过，现印发给你们，请各单位结合各自工作职责，认真抓好落实。

2017亚洲都市景观奖颁奖礼暨银川城市节

活动方案

2016年10月29日至30日，“2016亚洲都市景观奖颁奖礼暨银川城市节”活动在我市成功举办。通过举办此次活动，充分展示了我市“宜居、宜业、国际化、现代化”的城市建设新成果，有效地提升了我市的城市品牌形象和知名度，增进了我市与亚洲各城市间的友谊，夯实了我市与亚洲各城市间交流合作的基础。

为全面树立我市“碧水蓝天、明媚银川、美丽美好银川”的城市形象，全力推动我市城市景观建设可持续发展，加强与国内外城市间的交流与合作，继续办好“2017亚洲都市景观奖颁奖礼暨银川城市节”系列活动，现制定活动方案如下：

（八）2017中国（银川）国际葡萄酒品鉴大会（西夏区瑞信温泉小镇）。

银川贺兰山东麓葡萄酒产区凭借独特的自然资源和悠久的酿酒传统及现代化的经营方式、酿造技术，吸引了国内外葡萄酒生产企业的关注，一些知名厂商相继在此投资建厂或建立酒庄。该区域已成为国内外知名的中国最佳酿酒葡萄和葡萄酒产区之一。

1.举办活动的必要性。

银川作为西北地区重要的区域中心城市区别于国内乃至亚洲及世界其他城市特质的新名片——盛产葡萄酒的地区。品鉴活动本身将对银川市的知名度宣传将起到极大的促进作用。银川市将“请进来”与“走出去”的方式双轨并行，能够达到事半功倍的效果，提升国际影响力。

同样，银川贺兰山东麓产区或国内其他产区目前需要启动对葡萄酒下游产业（生产葡萄酒所产生的废料）再开发和利用，通过举办品鉴活动极大吸引葡萄酒采购商到银川，对于整个银川产区的葡萄酒产业可持续发展必将起到极大的促进作用。

2.目标。

举办中国（银川）国际葡萄酒品鉴大会，是城市节重要的有机组成部分，也是民众参与的重要途径。对发掘银川葡萄酒文化新内涵，构筑银川葡萄酒之城的城市品牌形象，吸引国内外游客品尝体验，奠定银川葡萄酒之城度假模式基础将起到积极作用，扩大银川葡萄酒之城在全国、亚洲乃至世界的影响力；同样，推动贺兰山东麓葡萄酒产业转型升级和国际的交流合作，吸引更多潜在投资者在银川投资建立酒庄，提升银川酒庄的品质，加速其走向国际化、高端化、品牌化之路，来提升贺兰山东麓葡萄酒在全世界范围内的知名度；并且拉动酒庄针对本地婚庆、会议等活动的市场需求，发挥葡萄酒学院导师优势，增加民众的参与度、娱乐度。
