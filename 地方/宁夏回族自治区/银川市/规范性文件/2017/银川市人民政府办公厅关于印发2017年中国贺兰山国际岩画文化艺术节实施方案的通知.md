# 银川市人民政府办公厅关于印发2017年中国贺兰山国际岩画文化艺术节实施方案的通知

各县（市）区人民政府，市政府各部门、各直属机构：

《2017年中国贺兰山国际岩画文化艺术节实施方案》已经银川市十五届人民政府第2次常务会议研究同意，现予以印发，请认真组织实施。

银川市人民政府办公厅

2017年6月11日

2017年中国贺兰山国际岩画文化艺术节实施方案

为贯彻落实国家“一带一路”倡议和文化强国战略，挖掘贺兰山岩画史前文化和韩美林现代艺术资源优势，打造世界岩画展示基地、岩画学术交流基地、文化产业孵化基地，进一步扩大岩画保护研究国际交流合作，深化岩画文化传承和岩画艺术创新，计划举办2017年中国贺兰山国际岩画文化艺术节。具体方案如下。

一、活动时间

2017年7—10月

二、活动地点

宁夏银川贺兰山岩画遗址公园（银川韩美林艺术馆），部分活动延伸至银川市永宁县、固原市隆德县。

三、活动主题

岩画保护·文化传承·艺术创新·产业融合
