# 银川市人民政府办公厅关于印发2017年全国青少年“未来之星”阳光体育大会执行方案的通知

各县（市）区人民政府，市政府各部门、各直属机构：

《2017年全国青少年“未来之星”阳光体育大会执行方案》已经市政府同意，现予以印发，请认真贯彻执行。

银川市人民政府办公厅

2017年7月7日

2017年全国青少年

“未来之星”阳光体育大会执行方案

2017年8月，全国青少年“未来之星”阳光体育大会将在我市举办。届时，将有来自全国34个省区市（含港澳台）的体育代表团1400余名青少年和青少年体育工作者汇聚银川，参加阳光体育大会各项活动。为全力做好2017年全国青少年“未来之星”阳光体育大会各项筹备工作，特制定如下方案。

一、活动时间

2017年8月8日—12日举行。

二、活动主题

相约美好银川，共享阳光体育。

三、举办单位
