# 银川市人民政府办公厅关于印发2017首届中国·银川文化艺术创意节实施方案的通知

各县（市）区人民政府，市政府各部门、各直属机构：

《2017首届中国•银川文化艺术创意节实施方案》已经市十五届人民政府第2次常务会议研究同意，现予以印发，请认真组织实施。

银川市人民政府办公厅

2017年4月28日

2017首届中国·银川文化艺术创意节

实施方案

为提高文化创意产业发展动能，搭建文化创意交流协作平台，汇聚文化艺术创意设计资源，促进创意成果转化，提升银川文化产业发展核心竞争力，推进国家文化消费试点城市创建工作，我市将于7月下旬举办“2017首届中国·银川文化艺术创意节”。具体方案如下：

一、活动主题

创意银川•智慧生活。

二、活动时间地点

2017年4月—7月，在银川市举行。

三、主办 承办及协办单位
