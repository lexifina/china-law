# 银川市人民政府办公厅关于印发《银川市标准化体系建设发展规划（2016-2020年）重点任务分解》的通知

各县（市）区人民政府，市政府各部门、各直属机构：

为贯彻落实《银川市标准化体系建设发展规划（2016—2020年）》（以下简称《规划》），进一步明确责任，落实任务，协同推进我市标准化体系建设发展各项工作，按照自治区相关要求，现对《规划》明确的重点任务进行分解，并按职责分工下达给你们，请结合实际，认真抓好落实。

银川市人民政府办公厅

2017年6月21日
