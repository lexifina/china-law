# 银川市人民政府办公厅关于印发银川市2017年招商引资工作安排意见的通知

各县（市）区人民政府，市政府各部门、各直属机构：

《银川市2017年招商引资工作安排意见》已经市政府研究同意，现印发给你们，请结合实际，认真抓好贯彻落实。

银川市人民政府办公厅

2016年3月24日

银川市2017年招商引资工作安排意见

为深入贯彻落实中央、自治区经济工作会议精神，进一步扩大有效投资，推动全市综合实力再上新台阶，现就做好2017年招商引资工作安排如下：

一、总体思路

深入贯彻落实市第十四次党代会精神，坚持经济工作项目化，项目工作具体化、精准化，大力实施反梯度和造商引资战略，强化投资驱动和创新驱动，不断扩大招商引资规模，提升招商引资质量，优化招商引资环境，逐步实现招商引资从单一引进向组团式、配套式引进转变，从注重资金引进向注重模式引进转变，从政策优惠引进向政策优化引进转变，为全市经济社会发展作出新贡献。

二、目标任务

到位资金：6月底前，实现全国工商联会议签约合同项目资金1200亿元，全年完成到位资金620亿元以上。

招大引强：全年引进总投资10亿元项目20个以上，中国、世界500强企业3家以上。

招高引新：引进新材料、新能源、先进装备制造、生物医药、现代纺织等领域高新技术企业10家以上，引进通航、大健康、大数据、电竞游戏、物联网、跨境电商、互联网医院等新业态项目20个以上。

招商活动：组织开展好中阿博览会等重大活动，邀请重点领域企业走进银川10批次以上；积极参加自治区组织的国内外重大经贸活动10场次以上，自主举办各类招商推介会10场次以上，对接储备重点目标企业100家以上。

三、重点工作

（一）围绕“百千亿”工程，强化产业集群招商

坚持集约集群发展，聚焦战略投资者、行业龙头及上下游配套企业，抓好招商选资、造商引资、招才引智和精准招商，加快引进一批大项目好项目，延伸壮大产业集群，抢先布局前沿产业，着力打造“四群一链”。

1.壮大优势传统产业。现代纺织产业依托“一城三园”，加快如意氨纶纤维、涡流纺纱等项目建成投产，瞄准国内外知名纺织企业，着力引进服装用、产业用、装饰用纺织品生产项目。积极对接中国纺织工业联合会，借助国家智慧型纺织基地建设，大力引进纺织国资、外资、民企，形成产业配套集聚发展。先进装备制造产业坚持智能制造方向，瞄准战略新兴产业，加大智能化成套输变电设备、精密仪器仪表、机器人等项目引进，助力打造全国智能制造示范基地。新能源产业加快推进卡威、金龙新能源汽车项目建设，积极对接引进万向集团、比亚迪新能源汽车项目，推进武汉众宇氢能项目落地，壮大新能源产业集群。新材料产业加快隆基多晶硅等项目建设，推动宁夏昊晶新材料产业园建设与招商同步发展，不断扩大产业规模。生物制药产业坚持生物医药、生物农业和生物制造协调发展的思路，加快引进生物技术研发及应用项目。旅游产业抢抓全域旅游机遇，对接全国知名旅游投资开发公司，整合旅游资源，开发建设生态休闲、观光度假、西部自驾游、房车基地、葡萄酒庄等特色文化旅游业项目。

2.加快新产业新业态发展。智慧城市产业发挥大数据中心优势，同步加快智慧产业园建设与招商步伐，积极引进云计算、物联网、游戏动漫、智慧制造等新业态项目。加快落实微医、春雨医生等互联网医院启动运营，引进更多互联网医院及关联项目落户银川，打造我国规模最大的互联网医院聚集地。通航产业深化与台湾祐祥、美国太平洋、蝙蝠飞机制造、中信海直等企业战略合作，推动通航产业园飞机组装维修、租赁培训、航空物流、应急救援、旅游观光、通航作业等产业链项目取得突破。健康休闲产业围绕丝绸之路“生命谷”，放大国际医学检验所、丝绸之路生物工程研究院效用，着力引进仿制药生产、小分子中药有效成分提取、新型健康管理与生命科学测试仪器与治疗仪器设备开发、特色植物与动物资源功能食品生产及疑难杂病医院和健康管理中心等领域项目，着力打造“医、养、健、游、娱”融合发展的健康休闲全产业链。

（二）围绕产业定位，强化园区平台精准招商

发挥“6+3”主体作用，突出园区招商优势，围绕先进制造业、战略性新兴产业、加工贸易等特色产业，不断优化园区功能、强化产业链条，着力引进重大项目，打造产业集聚发展的新平台、新载体。

1.突出开放平台优势。围绕加快国际化进程，着力引进国际医疗、国际教育、国际健康、国际物流、国际金融等产业项目。综合保税区定向瞄准国际物流、加工贸易等产业，加大外向型项目引进力度，力争再引进1—2家500强企业。经济技术开发区按照产业链延伸、智能制造产业化的方向招大引强、招高引新，加快对接新加坡力江、SDF轴承中国公司、亿丰集团控股、上海吉控等公司，力争引进轨道交通、精密轴承、机器人等项目3个以上。依托IBI、TMT育成中心，加大知识产权、科研院所、物联网、创意创业项目引进力度，落实相关产业项目5个以上。滨河新区围绕大健康、大旅游、大教育、大制造等重点领域，重点推动华强集团方特乐园、恒天碳纤维基地等项目落地，力争引进旅游、教育、医疗等项目3个以上，努力形成新的增长点。阅海湾商务区围绕中阿博览会永久会址，加大总部经济、现代金融、电子竞技等项目对接，着力引进一批“大个头”的投资企业，力争引进股权投资企业达到500家左右，搭建对外开放新高地。

2.突出园区产业化发展。主动适应产业变革趋势，通过延展产业链条、扶持重大项目、支持科技研发、腾笼换鸟等措施，积极引进大项目特别是全产业链项目，大企业特别是产业集群支柱企业落户园区，着力培育百亿级园区。德胜工业园区依托银川食品产业园，加快中国杞大叔庄园等农副产品加工项目建设，积极引进行业龙头企业，打造食品特色品牌。依托中阿跨境电商产业园、电商创业园、电商物流园等平台，力促国内90%的知名电商物流快递企业入驻园区。推动同济东方医养及幼教、嘉洋钢构养老等项目落地开工，配套引进生产性服务业项目。望远工业园区持续优化产业布局，依托伊品、启元等龙头企业，挖掘产业自身优势，着力引进医药制剂、食品强化剂、饲料添加剂等生产项目，打造全区生物发酵及制药产业基地。围绕卡威新能源汽车、贝鸟新能源电动车等项目引进配套产业，延伸新能源产业链条。银川高新技术产业开发区抢抓“国家外贸转型升级专业型示范基地”建设机遇，整合挖掘“一区五园”优势，着力引进高新技术产业项目，推动南京金龙新能源出口基地建设，提升产业发展水平。灵武再生资源循环经济示范区重点引进工程机械再制造和危化品仓储运输等项目，壮大提升再生资源产业。

3.突出提升园区服务配套能力。引入政府和社会资本合作模式开发建设园区公共服务及基础设施类项目，鼓励社会资本在现有园区中投资建设、运营特色产业园。加强园区融资担保，为中小企业提供融资服务。加快园区生产性服务体系建设，着力引进研发设计、科技咨询、第三方物流、知识产权服务、检验检测认证、融资租赁、人力资源服务等生产性服务业项目。扩大行政审批延伸服务范围，争取更多园区企业享受高效便捷的行政审批服务。优化土地保障，优先保证重大项目土地供应。

（三）围绕重大活动，强化招商引资能力

充分利用各类节会展会，通过“走出去、请进来”等方式，进一步加大企业攻坚和项目引进力度。

1.主动“走出去”。贯彻落实好自治区节会安排，积极参加丝博会、哈洽会、渝洽会等国内知名博览会、经贸洽谈会，组建现代纺织、新能源、新材料、生物医药、智慧城市、健康养老、文化旅游、电子竞技等产业招商小组开展定向对接。强化区市县三级联动机制，瞄准全国工商联会员企业、国内行业龙头企业和重点在谈项目，编制产业招商地图，策划专题赴外招商活动，形成一批签约落地成果。发动各县（市）区、园区力量，自主开展小分队招商对接活动，继续瞄准长三角、珠三角、环渤海湾等地区进行攻坚，储备落实一批新的合作项目。

2.定向“请进来”。发挥中阿博览会“金字招牌”作用，加强与海合会、中阿联合商会等国际民间组织联系，不断扩大经贸、文教、卫生等领域合作。积极对接中国国际贸易促进委员会、宁夏中阿企业发展促进会等组织，利用好中阿卫星数据产业园、中阿金融产业园等载体，着力引进中阿合作项目，提升合作水平。抢抓中国花博会、WCA世界电子竞技大赛、（全球）银川TMF智慧城市峰会等盛会在银举办契机，围绕能源、旅游、金融、花卉、电子竞技、智慧城市等开展产业招商，促成项目合作，实现以会引商。密切与全国工商联关系，对接联络服装、医疗、旅游等重点领域会员企业，组织开展“百名工商联会员企业走进银川”系列活动，再储备一批签约合同项目，确保完成签约目标任务。对接中国对外友好协会“彩虹桥”工程，重点攻坚飞利浦医疗、荷兰帝斯曼等跨国公司，促成项目合作。加强与中国机器人产业联盟联系，邀请国内知名机器人制造企业走进银川，定向对接智能制造项目，进一步拉伸产业空间。同时，发挥驻宁（银）各商协会作用，组织苏商、浙商、闽商、台商等走进银川，通过项目合作、建立园中园等形式，不断壮大来银投资企业规模。

（四）围绕营商环境，强化服务创新

适应新形势新要求，创新招商方式，完善招商机制，提升招商服务，优化招商环境，为项目引进提供优质高效服务。

1.创新招商方式。转变招商观念，逐步从政府主导向政府引导与市场化招商相结合转变。研究出台共享经济发展意见，复制推广产业+基金+资本市场的共享经济模式，放大造商引资效应。积极开展委托招商，定向开展组团式招商，建立“以商招商”奖励机制，不断优化招商引资方式。

2.优化营商环境。围绕企业关心关注的成本、融资、人才等问题，研究出台优化营商环境的意见，推出一批新政策，降低企业制度性、交易性成本，提高政策吸引力。加快智慧政务建设，推动审批流程再造，切实缩短审批时间，提高审批实效。加大银川投资宣传力度，运用好互联网、自媒体等宣传平台，聚焦新经济新产业新模式，提高对外影响力。

3.夯实招商基础。修改完善招商引资考核与奖励办法，调整优化考核指标，细化奖励内容和标准，扩大奖励范围和资金，重奖对我市招商引资作出突出贡献的集体和个人，进一步激发各层面、各界别招商引资积极性。优化招商队伍结构，将懂经济、懂项目运作、有干劲的专业人才充实到招商队伍中，强化产业研究，增强能力，全力打造一支专业化招商队伍，全面提升招商引资工作水平。
