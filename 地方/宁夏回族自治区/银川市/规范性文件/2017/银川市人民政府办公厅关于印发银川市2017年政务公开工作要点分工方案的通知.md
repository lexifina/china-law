# 银川市人民政府办公厅关于印发银川市2017年政务公开工作要点分工方案的通知

各县（市）区人民政府，市政府各部门、各直属机构：

为贯彻落实《国务院办公厅关于印发2017年政务公开工作要点的通知》（国办发〔2017〕24号）和《自治区人民政府办公厅关于印发2017年政务公开工作要点的通知》（宁政办发〔2017〕80号）要求，明确责任分工，抓好工作落实，确保政务公开工作取得实效，现将《银川市2017年政务公开工作要点分工方案》印发给你们，请认真抓好贯彻落实。

一、加强组织领导，有力保障政务公开工作

（一）加强组织领导。各县（市）区人民政府、市政府各部门要充分认识互联网环境下做好政务公开工作的重大意义，转变理念，提高认识，将政务公开纳入重要议事日程，主要负责人亲自抓，分管负责人具体抓，切实做好本地区、本系统信息公开、政策解读、回应关切等工作。各县（市）区人民政府、市政府各部门主要负责人每年至少听取1次政务公开工作汇报，研究推动工作，有关情况和相关工作分工应对外发布。

（二）强化工作保障。各县（市）区人民政府、市政府各部门要整合力量，在2017年6月底前明确承担政务公开工作的机构，配齐配强工作人员。要加强工作经费保障，为工作顺利开展创造条件。要抓好教育培训，支持政务公开工作人员接受相关业务培训。市委党校要将政务公开纳入干部培训课程，着力强化各级领导干部在互联网环境下的政务公开理念，提高指导、推动政务公开工作的能力和水平。政务公开工作人员要加强政策理论学习和业务研究，提升政策把握能力和专业素养。

（三）强化监督考核。要把信息公开、政策解读、回应关切、媒体参与等作为政务公开的重要内容纳入效能考核体系，所占分值权重不应低于4%。市政府办公厅将适时开展政务公开监督检查，对工作推动有力的，予以通报表扬；对工作落实不到位的，予以通报批评；对违反有关规定、不履行工作任务的，依法依规严肃追究责任。

二、落实规定动作，全面推进“五公开”

（一）认真落实《自治区人民政府办公厅关于全面推进政务公开若干重点工作实施方案的通知》（宁政办发〔2017〕74号）要求，各县（市）区人民政府、市政府各部门年内全面完成“五公开”（即决策、执行、管理、服务、结果公开）融入办文办会程序、建立公开内容动态扩展机制等工作，加快制定本单位主动公开基本目录，稳步有序拓展公开范围。对涉及公众利益、需要社会广泛知晓的电视电话会议，要积极通过媒体直播等方式向社会公开，涉及国家秘密的除外。及时公开政策性文件的废止、失效等情况，并在政府网站已发布的原文件上作出明确标注。

（二）推进基层政务公开标准化规范化，按照统一部署，贺兰县要抓好“全国100个基层政务公开标准化规范化试点县”工作，科学制定试点方案，精心推进试点工作，确保取得实效，形成可供推广借鉴的经验做法。未纳入国家试点的其他县（市）区，要主动探索适应基层特点的公开方式和制度机制，形成自身特色亮点。

（三）加大议案建议提案办理结果公开力度，对涉及公共利益、社会广泛关注的议案建议、提案，除涉密或者敏感信息外，原则上都要公开答复全文，接受群众监督。

（四）健全解读回应机制，对市政府出台的涉及经济社会发展大局、关系群众切身利益的重大政策，原则上都要开展政策解读。按照“谁起草、谁解读”的原则，各县（市）区人民政府、市政府各部门要做到政策性文件与解读方案、解读材料同步组织、同步审签、同步部署。严格执行特别重大、重大突发事件最迟5小时内发布权威信息、24小时内举行新闻发布会的时限要求，落实通报批评和约谈制度，确保回应不超时、内容不敷衍。

三、加强平台建设，拓宽政务公开渠道

（一）强化政府网站建设和管理，各县（市）区人民政府、市政府各部门要切实履行对政府网站的监管责任，进一步加强和改进政府网站内容建设、栏目设置，强化搜索查询功能，做好日常监测和季度抽查，及时公开抽查情况；推进政府网站集约化建设，对保障不力的政府网站要关停上移，对功能不全的要改版升级，切实提高管理水平。

（二）按照全国政务服务体系普查要求，全面梳理进驻市民大厅（政务服务中心）服务事项、服务信息公开情况、系统建设情况等，认真组织填报，确保数据信息真实、准确、完整。

（三）加快构建政务新媒体矩阵平台。凡条件具备的县级以上行政机关，年内要开通政务微博、微信等新媒体，并切实用好管好政务新媒体，明确开办主体责任，健全内容发布审核机制，强化互动和服务功能，切实解决更新慢、“雷人雷语”、无序发声、敷衍了事等问题。

（四）加强与新闻媒体的沟通合作与协调联动，在政务公开平台发布权威信息的同时，要充分运用新闻媒体资源开展宣传解读，扩大政务公开的覆盖面和影响力。

各县（市）区人民政府、市政府各部门要结合实际，按照分工方案，进一步分解细化本单位工作任务，抓紧制定具体实施方案或工作安排，在本分工方案公布后20个工作日内在本单位门户网站公开，并报市政府办公厅备案。各牵头单位要按照“谁牵头负责、谁组织落实”的原则和“部门推进、系统保障、集中展示”的要求，加强组织协调，积极推进各项工作落实，并按时汇总工作进展情况；责任单位要根据各自职能，积极支持配合牵头单位抓好落实，及时向牵头单位反馈进展情况。各县（市）区人民政府、市政府各部门要围绕本年度政务公开重点工作，在本单位网站开设相应的专栏或专题，统一集中发布信息。2017年11月30日前，各县（市）区人民政府、市政府各部门要将本分工方案落实情况专题报市政府办公厅。市政府办公厅将采取年初定计划、年中抓进度、年末严考核的方式，适时开展专项督查，全面推进政务公开工作的落实，各县（市）区人民政府、市政府各部门的落实情况将纳入年度全市绩效考核政务公开重要指标内容。

银川市人民政府办公厅

2017年6月21日
