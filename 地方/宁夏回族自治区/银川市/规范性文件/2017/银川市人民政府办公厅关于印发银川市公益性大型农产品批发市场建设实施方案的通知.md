# 银川市人民政府办公厅关于印发银川市公益性大型农产品批发市场建设实施方案的通知

各县（市）区人民政府，市政府各部门、各直属机构：

《银川市公益性大型农产品批发市场建设实施方案》已经市人民政府同意，现印发给你们，请认真抓好落实。

银川市人民政府办公厅

2017年10月19日

(此件公开发布）

银川市公益性大型农产品批发市场建设实施方案

根据财政部办公厅、商务部办公厅《关于开展全国农产品流通骨干网络建设工作的通知》（财办建〔2014〕36号）、商务部等12部委《关于加强公益性农产品市场体系建设的指导意见》（财办建〔2016〕146号）等文件精神，并结合银川实际，制定本实施方案。

一、基本思路和原则

（一）基本思路。

认真贯彻落实《国务院关于深化流通体制改革加快流通产业发展的意见》（国发〔2012〕39号）精神，以便民惠民为宗旨，以改革创新为动力，以减环节降费用提效率为抓手，以现有大型农产品综合批发市场为主体，以股权投资为主要方式，对全市5家大型农产品综合批发市场（银川市北环蔬菜批发市场、宁夏海吉星国际农产品物流有限公司、宁夏润恒农产品市场有限公司、宁夏新世纪冷链物流有限公司、宁夏四季鲜果品蔬菜批发市场有限公司），通过强化公益性基础设施建设，增强市场可持续经营能力，形成批发—配送—零售为一体的全链条公益性农产品流通骨干网络，发挥好公益性流通设施引导和调节市场的作用，增强政府宏观调控能力。

（二）基本原则。

1.加强政府调控。通过财政资金入股，对大型农产品综合批发市场试点进行改造提升，实现国有控股或持有“金股”，加强政府对农产品价格和供应的调控力度。

2.投资与运营分离。政府实施公益性大型农产品批发市场建设投资，国有股权收益主要用于市场监测、信息统计发布、质量安全追溯等功能运营；项目运营按市场规则运作，充分体现市场主体作用，保障社会资本获取合理利润。

3.硬件与机制共建。在加强公益性基础设施建设、增强市场基础设施支撑能力的基础上，着重加强公益性功能发挥的机制建设，建立完善公益性农产品批发市场基础设施投资保障、运营管理和政府监管等方面的长效机制。

二、支持方式、方向和内容

（一）支持方式。

通过市级投资平台对公益性试点市场以股权投资或PPP的方式给予中央财政资金支持，按照《宁夏回族自治区公益性农产品批发市场建设试点实施方案》（宁政办发〔2015〕45号）要求,银川市本级配套7500万元，目前已安排2861万元。

（二）支持方向。

中央资金用于公益性试点市场公益性设施改造，市级配套资金用于公益性零售终端建设。

（三）支持内容。

鉴于目前全市5家大型农产品批发市场基础设施、信息化程度较低，为了切实体现公益性批发市场的作用，中央资金用于支持5家农产品批发市场实施公益性农产品批发市场建设项目，银川市本级财政配套资金主要用于公益性零售终端网络建设。

1.中央资金用于支持公益性大型农产品批发市场主要用于电子结算、市场加工配送、交易展示、（公共）信息平台、电子商务、检验检测、废弃物处理、消防安保、质量追溯等市场公共服务基础设施的改造提升。

2.中央资金用于建设农产品主销区批发和配送体系，支持在产地和销地批发市场建设服务于主产区，具有品牌展示等功能的加工配送中心、冷藏设施、信息中心和销售专区等服务设施。

3.银川市本级配套资金用于支持公益性零售终端体系建设，不断优化和提升社区蔬菜直销店、生鲜直通车、“无人售卖”等服务网络和规模，完善产销衔接体系，着力解决蔬菜等鲜活农产品流通“最后一公里”问题，进一步满足“菜篮子”消费需求，方便群众生活。

三、目标和任务

（一）主要目标。

到2018年底，全面建成以银川市为核心区，覆盖毗邻地区，保障居民消费需求、平抑物价，打通特色优势农产品南下北上、西出东进，流转顺畅、安全高效的全方位多层次通道，促进特色优势农产品结构调整和农民增收，提高我市公益性农产品批发市场的基础设施支撑能力、供应能力、市场运行能力，使通过公益性网络体系销售的鲜活农产品占全市鲜活农产品交易总量的20%左右。

（二）重点任务。

1.打造全市统一的电子结算系统。对全市5家大型农产品批发市场建立统一的信息平台和电子结算系统，组建银川市农产品信息交易结算中心（公司），加强对全市农产品批发市场的监管服务，提升批发市场的信息化和管理水平，结合追溯系统，把好农副产品入口关。

2.提升促进食品安全的能力。设置检验检测中心，开展鲜活农产品检验检测全覆盖，全面落实农产品交易索证索票制度，最终建立来源可追溯、去向可查证、责任可追究的肉类蔬菜流通追溯体系，把公益性农产品批发市场打造成居民消费的放心工程。

3.提升废弃物处理能力。新建或改造全市5家大型农产品批发市场的废弃物处理设施、设备，提升农产品批发市场处理废弃物的能力和市场整体卫生环境。

4.完善配套设施功能。针对不同农产品市场的定位和功能，根据公益性农产品批发市场需求，有针对性地完善市场功能，新建或改造市场内交易展示、分拣配送中心、冷链仓储、地产蔬菜交易区等公益性配套功能区。

5.打造批发配送零售为一体的全链条公益性网络体系。贯彻落实好《自治区人民政府关于加强鲜活农产品流通体系建设的实施意见》（宁政发〔2012〕68号）确定的目标任务，完善标准化菜市场、“菜篮子”连锁超市、社区直销店、流动直通车等零售终端。引导和支持农民专业合作经济组织、骨干流通企业等在永久性基地建设具有预冷保鲜、分拣加工、包装配送等功能的鲜活农产品产地集配中心，引导和支持社会资本在蔬菜集中连片主产区新建一批鲜活农产品冷链设施，为全链条公益性网络体系建设创造有利条件。

四、实施进度

（一）规划布局阶段（2017年10月）。

制定并印发实施方案，开展摸底调查，确定规划点位，办理前期相关手续。

（二）推进建设阶段（2017年10月至2018年10月底）。

严格按照方案，全力推进信息交易结算中心、市场加工配送、交易展示、冷链仓储、（公共）信息平台、电子商务、检验检测、废弃物处理、消防安保、质量追溯等市场公共服务基础设施，开展公益性零售终端建设。

（三）验收总结阶段（2018年10月底前）。

对公益性试点市场和公益性零售终端等公益性设施进行竣工验收，同时做好公益性零售终端运营监管，切实发挥好便民、利民、惠民的作用。

五、资金及股权投资管理

（一）资金来源。

2016年中央财政公益性大型农产品批发市场专项资金，采用政府股权投资或PPP方式，由市商务局、财政局共同委托银川市国有投资平台公司对符合条件的项目进行投资支持。

（二）投资标准。

政府投资所占比例不超过公司股权的40%。

（三）资金拨付程序。

市财政局按照本实施方案将中央财政专项资金一次性拨付至银川市国有投资平台公司，由投资公司与项目单位签订股权投入协议后根据协议拨付资金。

（四）股权投资管理。

市国有投资平台公司为股权投入资金的投资平台，具体与被投资企业或委托公司就投资运营、投资方式、收益回购等内容签订投资（委托）协议，银川市国有投资平台公司行使股东权利。

六、保障措施

（一）进一步强化领导体制和管理机制。

成立由市政府分管副市长为组长，市发改、财政、国土、住建、交通、农牧、商务、市场监管、国资、规划等部门参加的银川市公益性大型农产品批发市场建设工作领导小组，领导小组办公室设在市商务局，实时研究建设中存在的重大问题，创新管理机制，推进公益性大型农产品批发市场建设。

（二）增强政府对农产品市场的调控能力。

按照《中华人民共和国公司法》等法律法规的规定，通过签订具有法律效力的合同、投资协议，修改完善公司章程等途径，切实落实和履行好公益性试点市场在保障市场供应、稳定市场运行、促进食品安全和绿色环保等方面的公益性责任，进一步增强政府调控能力。

（三）制定支持公益性大型农产品批发市场试点建设发展相关政策。

研究出台公益性农产品批发市场税收减免政策、农产品物流配送、城市绿色通道等相关政策。

（四）规范公益性大型农产品批发市场运行管理。

进一步健全和完善公益性大型农产品批发市场基础设施建设、市场管理、质量安全、物流配送等标准，进一步规范批发和零售环节的运行管理，按照物价、市场监管、城管等部门的相关管理规定，严格监管市场业主单位、经营单位的经营行为，进一步提高农产品市场的经营管理水平。

（五）加大宣传，营造良好的工作氛围。

充分发挥报纸、电台、电视台等媒体的舆论导向作用，大力宣传银川市公益性大型农产品批发市场建设的重要意义，营造良好的工作氛围。运用信息、简报、经验交流等多种形式，及时总结和推广工作中的好经验、好做法，推动我市公益性大型农产品批发市场建设工作不断向纵深发展。
