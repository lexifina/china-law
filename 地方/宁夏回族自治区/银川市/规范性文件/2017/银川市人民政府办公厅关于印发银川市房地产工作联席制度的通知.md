# 银川市人民政府办公厅关于印发银川市房地产工作联席制度的通知

各县（市）区人民政府，市政府各有关部门：

为加强房地产市场宏观调控，规范房地产市场秩序，维护房地产行业稳定，及时协调研究解决房地产市场发展中的问题和矛盾纠纷，促进银川市房地产业持续平稳健康发展，结合银川实际制定《银川市房地产工作联席会议制度》，已经2017年11月15日市政府专题会研究同意现印发你们，请认真遵照执行。

银川市人民政府办公厅

2017年12月14日

（此件公开发布）

银川市房地产工作联席会议制度

为加强房地产市场宏观调控，规范房地产市场秩序，维护房地产行业稳定，及时协调解决发展中的问题，促进房地产业持续平稳健康发展，努力改善人民群众居住环境，结合银川实际特制定房地产工作联席会议制度。

一、主要任务

分析研究全市房地产市场发展形势，披露信息，协调应对措施；向市委、市政府提出促进房地产市场健康稳定发展的政策建议；协调解决房地产项目建设中遇到的矛盾和问题，充分实现信息共享，相互沟通，共同探索促进房地产市场健康发展的有效措施；加强对全市房地产市场调研分析和监督管理，依法查处违法违规开发经营行为；依法妥善解决房地产领域突发事件，保护群众合法权益，维护社会和谐稳定。

二、职责分工

成立由市政府分管住建领域的副市长担任房地产联席会议主席，辖区政府和市直各职能部门主要负责人为成员的房地产联席会议。辖区政府和市直各职能部门主要职责为：

三区政府：按“属地管理，分级负责”原则，依法妥善解决辖区范围内房地产领域的群体性、突发性事件，做好房地产问题项目的处置工作，保护群众合法权益，维护社会和谐稳定。

市住房和城乡建设局：负责全市房地产行业管理工作;加强商品房销售、房地产交易管理；负责对勘察、设计、监理、施工企业的管理，房地产开发项目建筑工程质量安全生产的监督、管理。协调落实房地产项目综合验收手续的办理。

市规划局：负责全市房地产开发项目的规划管理工作；协调落实房地产开发项目的商品房屋、社区管理用房、物业服务用房、教育资源布局及车库、车位、环卫等公共服务设施的规划审批、规划核实手续办理；受理并协调解决房地产开发项目涉及的规划问题。

市国土资源局：负责制定房地产开发用地年度供应计划；组织房地产开发项目的土地报批和供应工作;组织开展房地产开发项目土地市场监管及违法违规用地行为的查处工作。

市土储局：负责市政府下达征收决定的国有土地上房屋征收与补偿工作，协调房屋征收、拆迁和安置工作。

市发改委（物价）：负责全市商品房涉房收费的监管工作，规范商品房价格行为。依法查处房地产开发企业在销售价格及涉房收费方面的违法违规行为，受理并协调解决房地产市场中违法违规收费及未明码标价、存在销售价格欺诈等举报投诉。

市市场监督管理局：依法查处利用格式合同实施合同欺诈、危害国家利益、社会公共利益、损害消费者权利违法违规行为；依法对开发小区特种设备使用实施监督检查，对违反法律法规规定的行为进行查处。

市综合执法局：负责房地产开发、销售及经营行为的违法违规案件查处以及住建领域所涉及的各类违法违规案件的查处；负责对房地产户外广告的规范登记，依法查处广告违法违规行为。配合做好房地产领域中发生矛盾纠纷的处理。

市审批局：负责房地产开发事项各类行政许可事项的审批，负责解答有关房地产审批事项的相关事宜。

市财政局：负责研究拟定支持房地产业发展相关财政政策。

市公安局：负责对全市房地产领域违法犯罪行为的侦查调查，依法处理房地产市场发生的治安案件。

市中级人民法院：依法指导房地产问题项目的处置工作。

市统计局：负责全市房地产统计及市场监测工作，定期公布市场统计及监测数据。

市信访局：负责房地产开发项目来信来访的登记、受理、交办、督办。协调责任主体按信访规范处理化解此类信访事项。

市维稳办：负责房地产领域重大不稳定因素的预警和研判，并协调、指导群体性事件的处置。

三、工作制度

（一）房地产工作联席会议原则上每季度召开一次，根据需要，也可临时召集。主要任务是：通报全市房地产业主要指标运行情况，研究房地产市场调控阶段性工作重点；整理汇总需提交联席会议协调解决的有关事项，落实联席会议决定、决议；加强对全市房地产市场管理工作的监督检查。

（二）联席会议议定事项应形成会议纪要，由房地产工作联席会议办公室审签报市政府印发执行。

（三）各成员单位要按职责分工，认真参加联席会议，积极落实联席会议研究确定的各项工作任务，及时协调处理房地产开发项目建设中出现的问题。同时，加强沟通，相互配合，相互支持，形成合力，促进房地产市场平稳健康发展。

四、 工作机构

房地产工作联席会议下设办公室（设在市住建局），由市住建局局长兼任办公室主任。办公室的主要职责是：负责联席会议日常工作；定期对全市房地产工作进行调研，及时通报全市房地产工作情况，并提出建议；组织拟订房地产工作规划、计划并提交房地产工作联席会议研究审定；承担联席会议会务和成员单位日常联络工作；协调督促有关单位落实联席会议议定事项，承担房地产工作联席会议交办的工作。
