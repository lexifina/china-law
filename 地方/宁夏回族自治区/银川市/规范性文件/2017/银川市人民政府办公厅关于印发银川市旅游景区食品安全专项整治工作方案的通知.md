# 银川市人民政府办公厅关于印发银川市旅游景区食品安全专项整治工作方案的通知

各县（市）区人民政府，市政府各部门、各直属机构：

《银川市旅游景区食品安全专项整治工作方案》已经市人民政府同意，现印发给你们，请认真抓好落实。

银川市人民政府办公厅

2017年5月15日

银川市旅游景区食品安全专项整治工作方案

为进一步加强我市旅游景区食品安全工作，规范旅游景区食品经营、消费行为，切实消除旅游景区食品安全隐患，根据自治区人民政府办公厅《关于开展全区旅游景区食品安全专项治理工作的通知》（宁政办发〔2017〕62号）要求，特制定本方案。

一、工作目标

坚持“标本兼治、规范与治理并重”的原则，认真排查和梳理旅游景区食品安全存在的突出问题，建立健全长效监管机制，提升旅游景区食品安全整体保障水平，努力使旅游景区食品经营单位卫生环境整洁、经营行为规范、食品销售索证索票齐全、大中型餐饮服务单位量化分级管理和“明厨亮灶”达到全覆盖。

二、整治范围

全面排查我市所有A级以上旅游景区及其周边的商场、超市、便利店、食杂店、农家乐、餐饮店，高速公路服务区、道路休息点的各类餐饮服务和食品经营单位（以下统称为旅游景区食品经营单位）。加大日常监督检查力度，规范食品经营行为，引导旅游景区及周边食品经营单位诚信、守法经营。

三、整治任务和措施

（一）调查摸底，全面排查食品安全隐患。做好旅游景区食品经营单位摸底调查工作，分层级、分领域建立旅游景区食品经营单位名录，切实做到底数清、情况明，全面排查隐患，积极整改落实，确保旅游景区食品消费安全。

（二）突出重点，集中开展专项治理工作。以旅游景区及其周边商场、超市、食品店、餐饮服务单位、农家乐等场所为重点区域，以枸杞、红枣、甘草等特色食品和保健食品为重点品种，以“端午节”“开斋节”“古尔邦节”“中阿经贸论坛”“十一”等节假日和重大活动旅游高峰为重点时段，以及集体配送单位、旅游团队餐饮服务提供单位和地方传统食品经营者进行重点监督检查。一是整治旅游景区食品经营单位无证照、未亮证经营，未落实食品索证索票、进货查验和台账记录不规范，未落实食品安全管理制度或落实制度不严格、不到位等问题；二是整治旅游景区食品经营单位销售散装食品没有防蝇、防尘、防二次污染以及标识标签不规范，销售“三无”、过期、腐烂、霉变食品等违法经营行为；三是整治旅游景区食品经营单位经营场所卫生环境脏、乱、差，从业人员个人卫生不达标、未取得健康证上岗，景区食品摊贩乱摆乱放，食品经营和加工制作场所离污染源过近、少于25米距离等问题；四是整治经营场所设施不符合要求，布局功能不合理，需要冷冻冷藏的食品未按规定条件贮存，未做到荤素分开、食品原材料、半成品、成品分开存放，存在交叉污染，清洗消毒设备不齐全，食品添加剂管理未严格落实“四专一准确”要求等问题；五是督促景区餐厅和农家乐食品安全监督量化管理动态等级评定进位升级，减少“C”级单位比例。大力推行“明厨亮灶”工作，在旅游景区及周边餐饮服务单位打造“透明厨房、阳光操作”，树立守法经营、诚信经营的良好形象，规范农家乐餐饮服务活动，大力提高农家乐餐饮服务食品安全保障水平。

（三）强化监管，确保制度落实到位。加大对旅游景区食品经营单位的巡查、检查力度，建立检查记录和检查信息公开制度，督促食品经营者严格落实进货查验和索证索票管理制度，确保购进的食品、食品原料、食品相关产品票证齐全，严禁采购和使用病死、毒死或者死因不明的畜禽肉及其制品，严厉打击使用或销售来源不明的食品及食品原料等违法违规行为。规范在景区内外兜售土特产的“游兵散勇”的经营行为，切实保护消费者的合法权益。

（四）落实整改，坚持依法治理。专项整治中发现的问题，逐个建立问题清单和整改清单、销号清单。对危害程度轻微的一般性问题，以监督整改为主，做到问题不整改不放过，坚决防止前整后乱、屡查屡犯；对违法行为，坚决立案查处，禁止有案不查；对已经损害了游客和消费者合法权益的问题，禁止以罚代赔或以赔代罚；对涉嫌“天价”炒作、“宰客”等恶意欺诈，严重损害景区形象的，坚决依法惩处，并建立“黑名单”制度，采取诚信联合惩戒措施，确保惩戒到位；对涉嫌犯罪的，一律移交司法机关依法查办，禁止以罚代刑。

（五）疏堵结合，确保整治取得成效。把专项整治与示范引导结合起来，采取“整治一批、引导一批、规范一批、提升一批”办法，鼓励、指导有条件的旅游景区食品经营单位升级改造经营条件，对小餐饮、小食品摊贩实行集中经营，促使小餐饮、小食品摊贩步入健康发展的轨道。继续推进旅游景区餐饮服务单位量化分级管理和“明厨亮灶”工作，引导督促餐饮服务单位加强环境卫生、设备设施、原料采购贮存、加工操作、餐饮具清洗消毒、食品添加剂使用等环节的隐患排查，及时清理过期食品、腐烂变质食品，优化场所布局，通过透明厨房、视频厨房、网络厨房等多种方式，切实做到食品加工制作重点区域可视、关键环节可知、风险点位可控。

四、任务分工

旅游景区开办者：负责督促相关食品经营者建立健全各项食品安全管理制度，及时报告景区食品经营者季节性开业或歇业情况，积极配合监管部门开展景区食品安全监督检查，严禁无证经营食品。

旅游行政主管部门：将食品安全工作纳入旅游景区、旅游饭店等级划分与评定工作，督促旅游景区管理单位认真履行相关职责。

市场监管部门：针对旅游景区及周边、农家乐餐饮消费特点，以落实餐饮服务提供者主体责任为基础，紧盯食品原料准入关口、食品加工制作过程控制、餐饮具清洗消毒、环境卫生状况等关键环节，加大日常监督检查力度，有针对性地加大节假日和旅游旺季等重点时段食品安全监管，依法查处虚假违法食品广告、销售假冒伪劣商品等违法行为。

物价部门：加大旅游食品市场价格监管，依法查处经营者价格违法违规行为。

城市综合管理部门：依法取缔景区周边乱设摊点及卫生环境脏、乱、差的流动食品摊贩。

公路管理部门：请自治区公路管理局负责监督协调高速公路服务区主管部门积极配合银川市辖区政府和相关部门做好行政区域内高速公路服务区、道路休息点的食品安全管理工作。

五、实施步骤和时间安排

（一）宣传部署阶段（2017年5月16日—5月31日前）。各县（市）区要组织相关职能部门按照本方案要求，制定本辖区详细实施方案，认真安排部署。并通过电视、广播、报纸等媒体，向社会宣传整治工作信息，在景区入口处、游客中心、高速公路服务区、收费站及可以利用的路牌、站牌、宣传牌等明显位置和食品经营场所公示食品经营者的量化分级管理等级等情况，最大限度扩大专项整治的知晓面，既要让旅游景区食品经营者知晓，也要让旅客、游客知晓，努力形成有利于开展整治的舆论氛围。

（二）集中整治阶段（2017年6月1日—10月31日）。各县（市）区要坚持问题导向，集中力量，周密部署，对景区及周边范围食品经营单位开展“拉网式”监督检查，切实解决影响旅游景区的食品安全突出问题，营造安全、放心的旅游市场消费环境。

（三）总结提升阶段（2017年11月1日—11月30日）。各县（市）区要对整治工作进行认真总结，主要包括组织开展旅游景区食品安全整治和日常监管的工作措施，取得的成果和好的经验、查处的典型案例、存在的主要问题，提出相关的意见和建议，研究进一步加强旅游景区食品安全监管的有效措施，积极探索建立长效监管机制，努力提升食品安全管理水平和服务能力。

六、工作要求

（一）加强组织领导。旅游景区食品安全是食品安全整体工作的重要组成部分，也是广大人民群众特别是游客关注的热点问题之一。加强旅游景区食品安全治理，既是维护群众合法权益的需要，也是发展全域旅游的重要保障。各县（市）区、各有关部门要高度重视，加强领导，将本行政区域内旅游景区食品安全专项整治作为2017年的重点任务，主要负责人要亲自过问，分管负责人要靠前指挥，集中时间，组织力量，联合执法，采取有效措施，排查消除隐患，促进食品安全保障水平的提升。

（二）加强日常监管。各县（市）区、各有关部门要根据辖区实际情况，将专项治理和日常监管相结合，加强对重点时段、重点区域、重点单位、高风险食品的集中治理，依法组织开展监督抽检工作，及时发布监督抽检信息。要加强景区及其周边食品小摊贩、小餐饮的日常监管，规范经营行为，全面提高旅游景区食品安全水平。

（三）加强协调配合。由市食安办牵头，组织有关部门开展专项督查，及时发现问题、通报情况、推进落实。各监管部门要强化联合督查检查，建立齐抓共管的部门合作机制，采取现场检查、问题核查、动态监督、随机抽查、明查暗访等多种形式,一级抓一级，层层抓落实，确保专项整治工作取得实效。

（四）强化应急管理。各县（市）区要建立健全应急管理机制，严格落实节假日和重大活动等旅游高峰重点时段值班值守制度，提高事故防范和应急处置能力。要督促旅游景区经营管理者建立食品安全应急预案，一旦发生食物中毒等食品安全事故，迅速采取控制措施，妥善予以处置。

各县（市）区、各有关部门要及时上报整治进展情况，于2017年11月3日前将整治工作总结报送市市场监管局，联系人：王少丽，联系电话：0951—4117315，邮箱：sp4117315@163.com。
