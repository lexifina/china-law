# 银川市人民政府办公厅关于印发银川市油库企业搬迁工作方案的通知

兴庆区人民政府、金凤区人民政府、西夏区人民政府、灵武市人民政府，市政府各有关部门：

经市政府同意，现将《银川市油库企业搬迁工作方案》印发给你们，请认真组织落实。

银川市人民政府办公厅

2017年6月7日

银川市油库企业搬迁工作方案

按照国务院办公厅《关于危险化学品安全综合治理方案的通知》（国办发〔2016〕88号）和自治区人民政府办公厅《关于印发宁夏回族自治区危险化学品安全综合治理实施方案的通知》（宁政办发〔2017〕25号）文件要求，为稳步推进银川市西夏区等4家油库搬迁工作，进一步消除人口密集区危险化学品企业的安全隐患，特制定本方案。

一、总体要求和目标

综合运用法律、行政、经济等手段，加快推进市区油品储运企业退城入园、改造提升、转型发展，优化城市功能布局，拓展企业发展空间，提高土地利用效率，改善城市生态环境，进一步消除城市人口密集区危险化学品储运企业安全隐患，坚决遏制重特大安全事故发生。到2019年11月底前完成兰星、博泰隆等油库企业的搬迁，规划建设银川市油品储备产业园区，完善配套基础设施、物流运输体系，增强油品储运企业发展后劲。

二、搬迁原则

（一）统筹规划原则。

结合《银川市城市总体规划》和《银川市土地利用总体规划》，科学编制工作方案，把优化城市内部空间结构和功能布局作为银川市油库企业搬迁改造的重要内容，合理控制开发强度，统筹规划腾空区域基础设施、生态修复及各类再开发项目；合理确定搬迁改造规模和建设时序，按年度滚动实施。油库搬迁承接地为灵武市甜水河村（占地面积约900亩，该地交通便利，南距307国道和大古铁路500米，北距古青高速600米，距离灵武市中心15公里），将该地规划建设为银川市油品储备产业园。

（二）因企施策原则。

针对拟搬迁油品储运企业生产经营状况、体制机制、产品技术、发展意愿等方面不同情况，分别采取不同的搬迁改造模式，不搞“一刀切”。通过合理设计、有针对性的规划，对有意愿继续从事油品储运事业的企业，努力促成其在搬迁承接地继续开展业务，提升行业综合竞争实力和安全保障能力；对希望退出行业转型发展的企业，妥善解决其土地处置、退二进三等相关问题。

（三）创新推动原则。

创新油库企业搬迁改造的组织模式、资金筹措模式、公共服务设施建设与运营模式、土地治理与开发利用模式，妥善处理政府与企业、银川市与县（市）区、迁出地与迁入地等多方面关系。利用好西夏区老工业基地搬迁改造等政策，全力争取中央、自治区对企业支持，加大招商引资和资产重组力度，共同推进搬迁改造。

三、主要任务

（一）加强调查摸底。市商务局、西夏区、金凤区、兴庆区要对辖区内油库企业进行全面、深入调查摸底，全面掌握企业生产经营状况、体制机制及未来发展意愿，摸清企业对于搬迁改造的真实想法；灵武市要对承接地基本情况及未来规划建设油品储备和运输配送产业园区的各项疑难问题进行深入调查；各相关部门要对搬迁工作涉及本部门职责的各项工作进行深入研究。

（二）制定工作计划。各有关县（市）区、相关部门在调查摸底的基础上，结合职责分工，研究制定本单位落实油库企业搬迁改造工作的方案，有针对性地提出解决问题的办法措施，并提交银川市油库企业搬迁改造推进工作组，工作组办公室在汇集各县（市）区、各相关部门工作方案的基础上，统筹制定全市油库企业搬迁改造年度实施方案，明确当年主要任务、实施进度、保障措施等。

（三）加强搬迁动员工作。西夏区、金凤区要在银川市油库企业搬迁改造推进工作组的领导下，加强政策宣传，全力动员和引导企业进行搬迁改造。对于主动搬迁改造的企业，应给予适当激励；对列入搬迁计划，又拒绝落实搬迁相关工作的企业，取消各种惠企政策，并采取各种限制发展措施倒逼企业搬迁改造。

（四）稳步推进搬迁实施和建设工作。搬迁改造推进工作组要统筹做好搬迁工作实施中的各项重点工作，协调上级政府和部门，及时研究解决存在的主要问题。市商务局、国土局、金凤区、西夏区等部门组织搬迁企业稳步实施搬迁工作，组织推进退出地的统一补偿、储备、出让等事宜，以及承接地的开发、建设等各项工作，各相关部门要按照各自工作职能，具体负责企业搬迁相关推进工作。

（五）抓好企业安置工作。各有关县（市）区、相关部门及市属国资公司要根据油库企业搬迁改造工作进度要求，申请和安排专项资金，积极争取国家关于老工业基地搬迁改造等政策支持，指导搬迁企业妥善解决职工分流安置、社会稳定等各项工作。

四、职责分工

按照油品储运行业安全管理关于“管行业必须管安全”的工作要求和各相关部门工作职责，为有效推进油库企业搬迁各项工作任务落实，责任分工如下:

市商务局：按照全市油品储运企业行业管理职能，负责企业搬迁的总体组织协调工作;进一步摸清三区油品储运企业底数及企业取得有关行政许可、经营资质情况，提出分批关闭、转产和搬迁企业名单;加强搬迁企业油气回收治理，协调落实企业油品经营许可等事宜；汇总提出相关搬迁政策和措施，组织推进企业按期完成搬迁工作。

市安监局：负责做好油品搬迁企业安全生产的监管和统筹协调，对接自治区安监局做好油品搬迁企业的安全生产监督管理和行政许可事项等工作，指导搬迁企业做好规划布局，有效控制和降低安全风险。

市工信局：负责摸清人口密集区油库企业以外的危险化学品生产企业情况，加快推进城市人口密集区危险化学品生产企业关停并转、退城入园工作，积极对接自治区经信委，争取国家、自治区对危化生产企业搬迁的资金支持。

市规划局：负责统筹安排全市危险化学品产业布局，严格执行危险化学品企业安全生产和环境保护所需的防护距离要求，加强规划实施过程监管；配合西夏区、灵武市做好搬迁企业规划选址及企业腾退土地的规划事宜。

市国土局（拆迁办）：负责配合辖区政府完成拟搬迁企业现有的土地权属情况、搬迁企业腾退土地的招拍挂及企业新建用地的土地报批等工作，提出支持企业搬迁的土地补偿相关优惠政策。

市住建局：负责企业搬迁项目建设中涉及民用建筑施工的质量安全监管。

市道路运输管理局：指导督促搬迁企业按照包装、装卸、运输和管理要求，与自治区交通厅对接，提前落实油品储运企业新建项目准入审批和承接地铁路专用线接入事宜。

市环保局：摸清拟搬迁企业环评手续情况，督促指导搬迁企业加强危险化学品废弃处置，加强危险化学品废弃处置过程的环境安全管理，做好企业新建项目环境影响评价工作。

市发改委:负责企业异地搬迁项目的审核、论证和备案工作，争取上级政策资金支持。

市公安消防支队：摸清拟搬迁企业目前消防手续验收情况，指导新建厂区消防安全风险评估。

西夏区政府、金凤区政府：负责制定企业搬迁工作方案，做好搬迁企业全程组织协调工作，进一步摸清辖区人口密集区危险化学品生产企业，确定关停、转产和搬迁企业名单，做好腾退土地的土壤治理和发展规划，争取国家老工业基地搬迁改造资金，提出支持企业搬迁的相关配套政策。督促企业制定搬迁方案，做好选址、审批、规划报建、用地预审、环境影响评价、资金筹措等项目建设前期工作，采取切实可行措施，加快搬迁进度。

灵武市政府：负责搬迁企业承接地土地利用规划调整、油品仓库产业布局规划及基础设施建设等工作，积极协助西夏区政府和金凤区政府做好企业入园的相关工作。

五、保障措施

（一）加强组织领导。

成立银川市油品储运企业搬迁改造推进工作组，分管副市长为组长，市商务局、安监局、发改委、国土局、财政局、规划局、住建局、道路运输管理局、环保局、工信局、公安消防支队和金凤区政府、西夏区政府、灵武市政府等部门为成员单位，定期召开工作协调会，及时研究企业搬迁改造工作中出现的问题和难点，协调推进企业搬迁改造工作。推进工作组办公室设在市商务局，负责牵头组织协调日常工作。

（二）强化督查落实。

为推进各项工作任务的落实，由市政府督查室进行督促检查，全面掌握油库搬迁工作的推进落实情况，对在督查过程中发现本部门或其他部门存在不正确履行职责，不作为、不担当、乱作为行为，影响项目推进的，要按照干部管理权责，上报市纪委进行问责。

（三）注重宣传引导。

充分发挥新闻媒体的舆论导向作用，大力宣传油品储运企业搬迁工作的重大意义，加强面向企业的宣传和引导，提高工作的系统性和连续性。认真做好搬迁企业职工的思想工作，不断提高广大群众和企业业主的认识，营造社会理解、支持油库企业搬迁的社会舆论氛围和工作环境。

六、工作要求

（一）各责任单位要对油品储运企业搬迁工作高度重视，指定专人负责落实。搬迁工作将形成周报制度，各责任单位务必于每周一将本周工作落实情况报领导小组办公室，便于汇集问题，及时研究解决办法和措施。

（二）各责任单位要对照工作任务，认真收集汇总搬迁政策依据和工作推进计划，将收集整理的内容及搬迁政策建议提交领导小组办公室，尽快制定出台油库搬迁改造政策方案，提请市政府研究实施。
