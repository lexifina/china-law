# 银川市人民政府办公厅关于印发首届中国银川互联网电影节实施方案的通知

各县（市）区人民政府，市政府各部门、各直属机构：

《首届中国银川互联网电影节实施方案》已经银川市十五届人民政府第2次常务会议研究同意，现予以印发，请认真组织实施。

银川市人民政府办公厅

2017年6月8日

首届中国银川互联网电影节实施方案

为贯彻落实国务院《关于印发“十三五”国家战略性新兴产业发展规划的通知》（国发〔2016〕67号）精神，探索电影产业与经济社会各领域的融合发展，进一步提升互联网电影产业等新业态发展层次，定于2017年10月在银川市举办2017首届中国银川互联网国际电影节。具体方案如下。

一、活动主题

智慧银川？影视中国？互联发展

二、活动时间地点

2017年6月—10月，在银川市举办。

三、举办单位
