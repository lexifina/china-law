# 银川市人民政府办公厅关于成立银川市人民政府质量和商标战略工作领导小组的通知

各县（市）区人民政府，市政府各部门、各直属机构：

为全面贯彻落实“质量强市”及商标品牌战略，切实加强对质量和商标战略工作的领导，深入推进质量和商标战略实施，提升我市企业综合竞争力。经研究，现对银川市质量兴市领导小组和实施商标战略工作领导小组进行合并，组成银川市人民政府质量和商标战略工作领导小组，原质量兴市领导小组和实施商标战略领导小组名称停止使用。现将合并后的领导小组成员名单通知如下：

领导小组工作职责为：贯彻落实国务院《质量发展纲要（2011—2020年）》和《开展质量提升行动的指导意见》，研究制定我市质量和商标战略工作发展规划及相应扶持政策，负责全市质量和商标战略整体规划和组织领导、政府质量工作考核统筹协调工作，组织召开工作联席会议，开展质量和商标战略工作宣传教育活动，开展中国驰名商标、宁夏著名商标、宁夏名牌及各级政府质量奖的培育、申报工作。

领导小组下设办公室，设在银川市市场监督管理局，彭安民同志兼任办公室主任。上述领导小组和办公室负责人如发生职务变化或所在部门、岗位变动，变动后的人员将自动调整更替，不再另行发文。
