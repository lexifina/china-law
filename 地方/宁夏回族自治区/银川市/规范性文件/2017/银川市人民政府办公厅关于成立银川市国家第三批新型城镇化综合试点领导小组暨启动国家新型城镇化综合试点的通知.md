# 银川市人民政府办公厅关于成立银川市国家第三批新型城镇化综合试点领导小组暨启动国家新型城镇化综合试点的通知

各县（市）区人民政府，市政府各部门、各直属机构：

按照《关于做好第三批国家新型城镇化综合试点工作的通知》文件要求，为加强推进我市国家第三批新型城镇化综合试点工作，经研究成立银川市国家第三批新型城镇化综合试点领导小组，并下设综合试点领导小组办公室，小组成员如下:
