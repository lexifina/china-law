# 银川市人民政府办公厅关于抓紧做好今秋（冬）明春贺兰山东麓葡萄种植园和酒庄生态防护林建设的通知

西夏、永宁、贺兰县人民政府，市直各有关部门：

为深入贯彻落实自治区第十二次党代会及石泰峰同志在全区葡萄酒产业发展座谈会上的讲话，根据10月11日市委专题会议的工作安排，现将加快推进葡萄产业基地生态防护林带建设的工作通知如下，请认真抓好落实。

一、目的及意义

按照党的十八大、十八届五中全会对生态文明建设提出的“要严守城市生态红线，构筑城市生态屏障，联建绿色生态廊道，完善林业产业链条，推动生态文明建设”的总体要求，认真贯彻落实自治区第十二次党代会“生态立区”的战略及市委“绿色、高端、和谐、宜居”的发展理念，打造西部地区生态文明建设先行区，构筑西北地区重要生态安全屏障，紧紧围绕银川市经济社会发展大局，加快推进贺兰山东麓葡萄产业绿色发展，切实处理好葡萄产业发展与保护生态的关系，把生态优势转化为产业优势、竞争优势、发展优势，实现经济社会与生态环境保护共赢。

二、目标任务

根据2015年第28次自治区主席办公会议纪要的要求，企业葡萄种植基地和酒庄生态防护林配套面积不小于酿酒葡萄种植面积的10%。今秋（冬）明春永宁县、贺兰县和西夏区要组织完成本行政区域内建设葡萄种植基地和酒庄生态防护林总面积为1588亩，其中永宁县300亩、贺兰县537亩、西夏区751亩，其中各酒庄具体任务详见附表。

三、工作要求

1.永宁县、贺兰县和西夏区政府要高度重视，认真规划，积极开展今冬明春葡萄种植园和酒庄生态防护林建设。全面排查现有酒庄（企业）2017年之前葡萄种植基地防护林建设情况，对未达到总用地面积10%以上的配套生态防护林或生态防护林不完善的酒庄（企业），今秋（冬）要集中人力、物力，搞好生态林建设，仍然完不成任务的要集中力量在2018年春季全面完成葡萄种植基地和酒庄配套生态防护林建设任务。

2.永宁县、贺兰县和西夏区政府要抓好110国道西侧、贺兰山自然保护区东侧范围内的主干道路、沟、渠的林带建设，以及沿自然保护区东界（北起贺兰山林场、南至永宁县闽宁镇）全长60公里，宽30-50米的乔灌混交生态防护林的建设。各葡萄种植基地和酒庄要按照200亩-500亩的生态防护林网格加快葡萄种植基地和酒庄生态防护林带建设。坚持科学造林，精准到位。苗木选择要适地适树、技术规程要科学到位。种植完成后，永宁县、贺兰县和西夏区要根据营造林技术规程，组织专业技术人员及相关单位、专家进行验收，对验收不合格的要限期进行整改至达到验收标准。同时，生态防护林配套建设以及完善的情况将做为葡萄园考核及酒庄整合达标的重要依据。

永宁县、贺兰县和西夏区要做好葡萄种植基地和酒庄生态防护林节水灌溉配套建设，为明年春季葡萄种植基地和酒庄周边生态防护林建设提供条件。各葡萄种植基地和酒庄的生态防护林建设规划要与葡萄种植、酒庄规划同时规划、同时实施、各县区要同时竣工验收。

3.永宁县、贺兰县和西夏区林业部门要结合造林计划，按年度细化目标任务，不断创新融资模式，建立生态补偿政策，通过提供苗木及技术指导等方式，调动葡萄种植基地和酒庄加快生态防护林的建设积极性。认真落实《银川市社会力量投资建设生态公益林补偿暂行办法》，吸引鼓励全社会力量参与植树造林建设，按照“谁投资、谁受益”的原则，动员企业、社会经济组织开展造林工作。

4.永宁县、贺兰县和西夏区要切实提高对银川市生态屏障体系建设重要性和紧迫性的认识，把思想和行动统一到银川市委、市政府的决策部署上来，把生态绿化工作作为一把手工程，层层分解任务、压实责任，明确责任分工，要把酒庄生态防护林建设任务列入年度目标责任考核的内容中，与经济工作同部署、同监督、同考核。

5.加强督查和验收工作。市葡萄酒产业发展局会同林业局、政府督查室，将加强对这次工作的跟踪督查。对完成目标任务的县（区），市政府将给予以奖代补并通报表彰；对没有完成目标任务的县（区），市政府将予以通报批评并问责相关责任人。
