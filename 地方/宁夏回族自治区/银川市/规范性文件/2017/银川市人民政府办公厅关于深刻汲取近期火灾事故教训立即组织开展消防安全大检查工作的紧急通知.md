# 银川市人民政府办公厅关于深刻汲取近期火灾事故教训立即组织开展消防安全大检查工作的紧急通知

各县（市）区人民政府，市政府各部门、直属机构：

近期，全国连续发生较大以上亡人火灾事故。2月5日17时30分许，浙江台州天台县一足浴店发生火灾，造成18人死亡、18人受伤；2月25日08时22分，江西省南昌市红谷滩新区唱天下量贩式休闲会所停业拆除工程发生火灾，造成10人死亡，13人受伤。就我市而言，今年前两个月，我市已接连发生3起小火亡人事故，火灾形势极为严峻。为认真吸取火灾事故教训，确保全国两会期间全市消防安全形势平稳，市政府决定在全市立即组织开展消防安全大检查工作。现就有关事项通知如下：

一、全面落实消防安全责任

各县（市）区政府、各有关部门要严格落实属地管理和行业监管责任，迅即部署开展本地区、本部门消防安全大检查工作。要本着对人民群众生命财产高度负责的态度，牢固树立责任意识、红线意识，各司其职、各负其责。对涉及消防安全重大问题，主要领导要亲自研究部署、亲自协调解决；分管领导要专门盯、具体抓，带头深入基层、深入现场进行明查暗访；要强化督导检查，确保工作取得实效。要督促社会单位严格落实主体责任，将责任具体落实到各个岗位和每名员工。要以“血的教训”为警醒，狠抓工作落实，对履职不到位、排查不彻底、执法不严格，导致火灾事故发生或安全隐患长期存在的，依法依规严肃追究责任。

二、坚决执行全覆盖排查要求

各县（市）区政府、各有关部门要在前一阶段工作的基础上，集中力量、集中精力，对本行政区域、所管行业的所有单位、场所等，组织开展全覆盖、全方位大排查。要进一步夯实消防安全“网格化”管理，发动乡镇、街道开展排查；发动社区、村队、治安巡防队、微型消防站队员等基层网格力量，持续开展“四清一查”。民政、教育、卫计、文化（文物）、商务、体育旅游等部门要深入推进行业系统消防安全标准化管理，持续开展达标创建工作。公安派出所要认真履行消防安全监管职责，切实加强对小单位、小场所的监督检查。要实行“谁检查、谁签字、谁负责”，并逐一登记造册、建立台账，坚决做到不留死角、不留盲区、不走过场。

三、突出抓好重点场所的排查整治

各县（市）区政府要把商场市场、宾馆饭店、歌舞娱乐等人员密集场所、易燃易爆场所、大型城市综合体、高层地下建筑和施工现场作为排查整治的重中之重。要深刻吸取浙江台州“2.5”火灾、江西南昌“2.25”火灾事故教训，认真开展足疗汗蒸场所、福利机构、学校、医院、残疾人康复等场所的专项治理。要组织专门技术力量，扎实开展装修工地消防安全大检查。要督促社会单位落实消防安全“户籍化”管理和“六加一”措施，强化微型消防站和“四个能力”建设。要坚持执法“零容忍”，牢记“命”字在心、“严”字当头，对排查发现的火灾隐患和违法行为，一律依法查处，决不姑息，该罚款的罚款、该查封的查封、该关停的关停、该拘留的拘留，确保检查一家、整改一家、合格一家。对各级政府挂牌的重大火灾隐患单位，要督促加大整改力度，确保3月底前全部整改销案；对逾期未整改和隐患整改缓慢且危及公共消防安全的，坚决依法予以关停。

四、广泛开展针对性消防宣传教育

各县（市）区政府、各有关部门要围绕落实消防宣传教育“八进”工作，着力推动群众消防安全意识的提高。各级宣传、文广和媒体机构要加大消防安全知识宣传力度，提高消防安全知识滚动字幕、公益广告和火灾警示新闻播出频次。各级安监、人社部门要切实把气焊、电焊从业人员接受消防安全培训纳入职业资格鉴定考核范围。各乡镇、街道要积极发动社区消防宣传大使等消防志愿队伍开展消防宣传活动；要广泛推动社会单位开展以“生命通道体验”为主要内容的疏散逃生演练，确保单位员工人人会逃生；要督促社会单位认真落实消防安全宣传教育主体责任，定期开展消防安全培训，切实提高员工“四个能力”。

各县（市）区政府、各有关部门贯彻落实情况请于3月5日前报市消防安全委员会办公室（联系人：马文婷，邮箱：ycxfaqwyh@126.com）。
