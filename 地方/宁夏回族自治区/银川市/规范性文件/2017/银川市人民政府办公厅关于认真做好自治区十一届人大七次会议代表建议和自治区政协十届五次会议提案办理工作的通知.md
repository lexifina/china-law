# 银川市人民政府办公厅关于认真做好自治区十一届人大七次会议代表建议和自治区政协十届五次会议提案办理工作的通知

各县（市）区人民政府，市政府各部门、各直属机构：

2017年，自治区人民政府转交银川市办理的自治区十一届人大七次会议代表建议18件（主办11、协办7），自治区政协十届五次会议提案38件（主办17、协办21）。为切实做好建议提案办理工作，提高办理质量，确保办理实效，现将有关事项通知如下：

一、进一步加强组织领导，明确责任分工

各承办单位要充分认识建议提案办理工作的重要性，把建议提案办理工作作为一项重要政治任务纳入工作日程，与本单位业务工作同安排、同落实、同考评。要严格落实责任，实行“定责任、定时间、定标准、定质量”，“包调研办理、包工作落实、包征求意见、包代表委员满意”的“四定四包责任制”，制定本单位建议提案办理工作方案。承办单位主要领导要负总责，分管领导具体负责，选派业务能力强、经验丰富的人员具体承办，确保推动有力，务求实效。

二、进一步规范办理程序，确保办理质量

今年我市承办的自治区人大建议、政协提案（详见附件1）分为两类：一是银川市主办类，其中主办自治区人大建议11件（9、42、63、102、106、125、127、139、143、161、163），主办自治区政协提案17件（11、12、14、61、82、119、123、179、254、265、311、339、381、404、457、503、504），承办单位办理完毕后,将银川市主办类答复件直接送寄代表委员征求意见（详见附件6、7、8），将正式文件（含征求意见表、沟通联系卡，领导签批件并电子版）报送市政府督查室；二是银川市协办类，此类建议提案由自治区相关厅局主办，银川市协办，各承办单位要积极配合，办理完毕后，直接将答复件报送主办单位（即自治区相关厅局），同时将电子版传送市政府督查室备案。

各承办单位要明确责任，对于本单位承办的建议提案，要按照“一见面、二沟通、三调研、四答复、五审核、六上报”的办理工作流程，对每一件建议提案要明确专人负责。对建议提案的答复，要意见明确、有实际内容和具体办理措施，答复工作要有针对性，针对问题并突出当年做法，不能以往年工作代替答复，更不能说空话、套话。正式答复文件需经单位主要负责人、市政府分管副秘书长（银川市主办类要经市政府分管副市长）审签，没有审签的答复件不予接受。

各承办单位要严格按照办理时限要求，银川市主办类建议提案，要在8月31日前办复；银川市协办类建议提案，承办单位要在6月30日前将协办意见报送主办单位，确保所有建议提案于8月底前全部办理完毕。

三、进一步加强落实力度，提高办理实效

各承办单位要把解决问题、取得实效贯穿于办理工作始终，根据建议提案的具体内容深入开展调查研究，通过登门拜访、专题调研、召开座谈会、电话联系等多种形式，及时与代表委员沟通交流，了解其意图，听取对办理工作的意见建议，切实推动建议提案的办理和落实。

要牢牢把握“一分部署、九分落实”的办理原则，凡建议提案所提问题能够解决或具备解决条件的，要集中力量尽快解决；因条件限制暂时难以解决的，要列入计划，制定方案，逐步加以解决；确实解决不了的，要向代表委员作出认真诚恳的说明，并及时将进展情况向代表委员反馈。对综合性、全局性、前瞻性较强的问题，要以适当方式报送有关领导，充分发挥建议提案的决策参考作用，提高建议提案的办结率和满意率。

请各承办单位收到本通知后迅速到市政府督查室（1542室）领取建议提案，尽快核实、分解任务，确需变更的，在一周内（按照附件10的要求）提出交改办意见，不得拖延搁置或自行转交其他单位。
