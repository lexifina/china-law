# 银川市人民政府自治区商务厅关于印发2017年宁夏（银川）大众消费促进活动工作方案的通知

各县（市）区人民政府，市政府各有关部门，各重点商贸流通企业：

现将《2017年宁夏（银川）大众消费促进活动工作方案》印发给你们，请遵照执行。

银川市人民政府  宁夏回族自治区商务厅

2017年6月9日

2017年宁夏（银川）大众消费促进活动工作方案

为提升经济发展内生动力，进一步促进大众消费，推动流通领域供给侧结构性改革，根据自治区商务厅《关于做好2017年商务领域扩大消费工作的通知》（宁商通〔2017〕48号）精神，银川市人民政府、自治区商务厅决定联合举办2017年宁夏（银川）大众消费促进活动，特制定本方案。

一、活动主题

培育新热点   引领新供给

二、活动目标

巩固扩大银川市社会消费品零售总额增长首季开门红成果，采取有效促销手段，助推消费提档升级，不断激活消费热点，优化消费环境，挖掘消费潜力，培育新的增长点，完成2017年社会消费品零售总额增长任务，使消费对经济的拉动作用显著增强。

三、活动内容

（一）开展激情之夏大众消费促进季活动，培育消费新热点。

时间：2017年6月至9月

规模：全市重点商贸企业以及骨干商业综合体500余家门店

内容：以新华百货集团“第五届购物季”活动为契机，组织新

百集团、北京华联、华润万家、双宝超市、大阅城、星悦城、悦海新天地、万达、新华联等骨干商贸企业、商业综合体，围绕信息消费、绿色消费、时尚消费、服务消费、农村消费等领域，举办“激情之夏大众消费促进季”活动启动仪式及各项促销活动，在主要商圈进行氛围营造，开展步行街启动日多店“集中促销”、“消费促进季”周末集中促销、“线上线下”融合互动促销、大型“家装节”家电下乡及以旧换新等主题活动，引导骨干商业打折让利，激活全城购买热情。同时，适时采取“线上线下”结合的方式，在毗邻地区开展推介宣传活动，开通微信宣传频道，重点推介银川市“双十”工程建设成果，购物季促销活动等，打造消费热点，吸引周边群众来银消费。

（二）大力开展“欢乐购物季”系列活动

地点：银川市各商业综合体、大中型商场、超市、旅游景点等

规模：全市重点商贸企业及商业综合体500余家门店

内容：邀请迪拜购物节嘉宾出席推广，在主要商圈和街道进行氛围营造，适时开通银川欢乐购物季网上商城，探索DSP营销推送方式，编印银川美食地图，加大在毗邻地区宣传推广力度，组织引导骨干商贸企业、旅游景区、医疗机构、旅行社、文化企业、金融机构、新闻媒体等联动互动、资源共享，实现商文结合、商旅结合、商医结合、商银结合、商媒结合，做到商商联合、跨境融合。通过开展形式多样、内容丰富的促销让利、便民惠民活动，掀起“全城促销”热潮，显著提升企业、景区销售额，激活全市乃至毗邻地区大众消费热情，营造“全城购物”良好氛围，放大银川市区域中心城市功能，实现“商家有利润、百姓得实惠”，带动全市消费市场增长。

（三）切实推进“金凤飞舞·城市乐活会”系列活动

地点：金凤区

规模：金凤区大阅城、新华联购物中心、金凤万达等商业综合体，骨干商贸企业

内容：深入推进“金凤飞舞·城市乐活会”系列活动开展，集合大阅城、金凤万达、新华联购物中心、星悦城等重点商业综合体和新华百货、北京华联等骨干商贸企业的资源，通过商圈+互联网、商圈+体验、商圈+学习、商圈+传承、商圈+文创等形式，发放商业联盟护照，将传统的消费模式转换成以“乐活”为宗旨的体验+创意的新型消费模式，以商圈联动营造购物的良好氛围，打造集旅游、观光、购物于一体的消费嘉年华。

（四）开展以扩大消费为主题的节庆促销，促进便利消费

地点：银川市各大中型商场、超市

规模：全市重点商贸企业

内容：各大中型商场、超市在各级新闻媒体、互联网、手机APP、微信等新兴传播介质以及店内海报、室外LED屏幕、公交车体广告、站牌广告牌等载体上，开展节庆促销、打折促销、满返促销、购物季等节庆促销宣传，实现月月有节庆、周周有热点，吸引本地及毗邻地区群众消费，带动社会消费品零售总额快速增长。

（五）开展名优商品下乡展示展销，激发农村消费

地点：银川市各县（市）区乡镇重点集贸市场

规模：银川市乡镇集贸市场开展名优商品下乡展销活动6场次以上

内容：组织新百电器等骨干商贸企业以大篷车等形式开展百货、家电、副食等名优商品下乡打折销售活动，方便农民购物，带动农村市场消费增长。

（六）开展大中型会展促销，促进时尚消费

地点：银川国际会展中心等人员密集场所

规模：各大中型参展企业、各大中型商超、有关商协会

内容：在银川国际会展中心、星悦城、大阅城、新华联火车站商业广场等地举办会员购物节、国际美食节、百姓购物节、主题汽车嘉年华、奇石博览会等展会、节会或促销专场20场次以上，拉动服装、首饰、食品、汽车、住宿、餐饮等消费增长。

（七）开展名优特商品专场让利打折促销，提升品质消费

地点：银川市各大中型商场、超市

规模：重点企业商贸企业门店

内容：以各商场、超市为主，根据季节和企业自身特点，组织农贸产品、名优特商品专场让利打折促销活动，扩大大众消费。

（八）开展电子商务体验应用展示，培育新型消费

地点：银川市各大中型商场、超市

规模：重点商贸企业门店

内容：引导传统商贸流通企业迎接“互联网+”时代，主动适应电子商务对商业模式的影响，大力发展基于线下实体店和线上虚拟店相结合的O2O经营模式，推动居民生活服务、社区商业、餐饮、休闲娱乐、旅游等领域电子商务应用。适时组织开展电子商务O2O应用展示周宣传活动，组织全市20家以上骨干电子商务企业进行宣传展示展销，推动电子商务消费进家庭。

四、活动要求

（一）高度重视，加强领导

各县（市）区人民政府、市直相关部门要高度重视，开展大众消费促进活动是我市经济转型、推动服务业发展的有力抓手和重要举措，要加强协作配合，全力营造好购物在银川的良好氛围。要安排专人负责，结合实际制定工作方案，细化工作分工，落实责任；要加强沟通协调，形成统筹协调、齐抓共管、共同推进的工作合力；要落实财政资金支持，注重加强舆论宣传，扩大促进消费活动的影响力。

（二）统筹协调，发挥合力

各县（市）区人民政府要切实履行职责，强化对扩大消费工作的组织、经费、人员保障。市宣传、物价、商务、行政审批、城管、环保、市场监管、公安等相关部门要加大支持力度，在企业活动宣传、氛围营造及活动开展等方面开辟“绿色通道”，简化行政审批流程，压缩审批时间，免除场地审批费用，支持重点骨干商贸企业开展户外广告营销宣传。同时，要加强监督检查，坚决杜绝虚假促销、以次充好、虚假打折等侵害消费者合法权益的行为发生，确保消费场所安全。市交通等部门单位要强化沟通协调，针对延长营业时间、通宵营业等促销活动，适当延长公交车辆营运时间。市财政部门要做好对大众促销活动的奖励。

（三）骨干引领，务求实效

各相关商贸企业要切实增强主动性，发挥骨干示范作用，结合日常促销，创新思路，完善机制，力争周周有热点，月月有主题，形成一批影响力大、带动性强的节庆促销品牌，努力让百姓得实惠，让消费对经济增长的贡献更明显。各骨干商贸企业要明确各节庆促销活动的时间和效果，及时向公安、城管等部门报备，确保各项活动规范有序开展。要加大宣传力度，在媒体网络、店内海报等宣传方面突出大众消费主题，并设立文明引导员，在商场电子屏上滚动播放文明礼仪小知识或张贴文明节约小贴士，引导营业员使用文明礼貌用语，营造文明的大众消费氛围。

（四）强化统计，务求实效

各企业要做好数据统计上报工作，做到销售数据应报尽报，市统计局和各县（市）区统计部门要认真研究，在严格遵守相关统计制度的前提下，强化创新，优化“限上”、“限下”统计样本，做到应统尽统，切实反映出促销活动对消费的带动效果。市政府和自治区商务厅将对扩大消费成效明显的骨干商贸企业给予一定的奖励。
