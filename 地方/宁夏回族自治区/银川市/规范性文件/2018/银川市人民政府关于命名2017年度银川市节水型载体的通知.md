# 银川市人民政府关于命名2017年度银川市节水型载体的通知

各县（市） 区人民政府，市政府各部门、各直属机构：

为加快节水型社会建设，全面推动节水型社会发展与水生态文明城市创建，保障节约型社会长期稳步较快发展，根据《国务院关于实行最严格水资源管理制度的意见》（国发〔2012〕3号）和水利部、国家机关事务管理局、全国节约用水办公室《关于开展公共机构节水型单位建设工作的通知》（水资源〔2013〕389号）要求，经自愿申报、层层推荐、综合考察考评，评选出了2017年度银川市节水型载体114家。经市政府2018年第27次常务会议研究，现决定对2017年度银川市节水型载体予以命名。

希望被命名的各节水型载体创建单位，再接再厉，继续巩固和扩大载体建设成果，不断提升载体建设水平，切实发挥示范引领作用，为我市节水型社会建设做出新的更大的贡献。各县（市）区、各有关部门要进一步加大对节水型载体创建工作的指导与支持力度，不断增强辐射带动能力，推动节水型社会建设再上新台阶。

银川市节水型社会建设工作领导小组将对命名的节水型载体实行周期性监查，每两年进行一次复查，对复查不合格的，将责令限期整改，如整改后仍不合格的，将撤销银川市节水型载体称号。
