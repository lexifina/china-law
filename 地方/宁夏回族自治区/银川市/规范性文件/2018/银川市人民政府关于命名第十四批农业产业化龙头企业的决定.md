# 银川市人民政府关于命名第十四批农业产业化龙头企业的决定

各县（市）区人民政府，市政府各部门、各直属机构:

为深入贯彻落实党的十九大精神和中央、自治区农村工作会议精神，培育发展农业产业化龙头企业，加快提升我市农业产业化经营水平，推进我市优势特色产业持续、快速、健康发展,经银川市十五届人民政府第23次常务会议研究，决定将宁夏西月花卉科技有限公司等22家企业命名为第十四批银川市农业产业化龙头企业。

农业产业化龙头企业是推进农业产业化经营的关键，是构建以工促农、以城带乡长效机制的重要载体，对提高农业生产经营组织化程度、促进农民就业和增收、保障主要农产品有效供给等方面都起着重要作用。希望新命名的农业产业化龙头企业再接再厉，大胆创新，锐意进取，充分发挥市场开拓、精深加工和科技创新等方面的辐射带动作用，不断建立和完善与基地、农户利益联结机制，提高自主创新能力和市场竞争力。市直有关部门和各县（市）区要强化指导服务，落实扶持政策，全力支持企业做大做强。同时，要加强对农业产业化龙头企业的监管，实行动态管理，建立健全竞争和淘汰机制，不断提升我市农业产业化发展水平，为全面实现“两个率先”奋斗目标做出新的更大的贡献。
