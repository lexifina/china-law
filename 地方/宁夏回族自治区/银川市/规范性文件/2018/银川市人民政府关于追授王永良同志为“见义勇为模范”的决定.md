# 银川市人民政府关于追授王永良同志为“见义勇为模范”的决定

各县（市）区人民政府，市政府各部门、各直属机构：

2018年7月22日晚八时许，银川市贺兰山沿线突降暴雨引发山洪。西夏区公安分局镇北堡派出所接群众报警称越野车在贺兰山滚钟口与苏峪口路段被山洪所困，请求救援。接到警情后，镇北堡派出所教导员郑建卫立即带领辅警王永良同志赶往现场。在抢险救灾的过程中，王永良同志被夹杂着大量泥沙和碎石的洪水瞬间吞没壮烈牺牲。王永良同志的英雄事迹经媒体报道后，引起社会广泛关注，得到了中央和区、市党委、政府及相关领导的高度赞扬。

王永良同志在面对人民群众生命财产安全遇到危险的时候，临危不惧、挺身而出，有效保护了人民群众财产安全，为此献出了宝贵的生命。王永良同志的行为充分体现了一名共产党员忠诚的政治品格、真挚的为民情怀、良好的职业精神、扎实的工作作风，不愧为党和人民的忠诚卫士；充分体现了在本职岗位上切实履行维护社会稳定，保障人民群众生命财产安全和经济社会发展的首府责任、首府担当，不愧为新时代党和人民的忠诚卫士、不愧为平安银川的建设者和守护者。

为深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，进一步激发广大人民群众投身平安建设的积极性和主动性，在全社会形成“人人参与见义勇为、人人敢于见义勇为”的社会风尚，经市政府研究决定，追授王永良同志“见义勇为模范”称号，并奖励人民币30000元。

希望全体党员领导干部、辅警人员和广大人民群众要学习王永良同志忠诚于党、忠诚于祖国、忠诚于人民的政治本色，学习王永良同志立足本职、顽强拼搏、无私奉献、不怕牺牲的高尚风格，在区、市党委、政府的坚强领导下，不忘初心、牢记使命，敢于担当、善于作为，为习近平总书记“建设美丽新宁夏，共圆伟大中国梦”的殷切期望和全市“两个率先”奋斗目标顺利实现，为“绿色、高端、和谐、宜居”银川建设做出新的更大贡献。

银川市人民政府

2018年10月25日
