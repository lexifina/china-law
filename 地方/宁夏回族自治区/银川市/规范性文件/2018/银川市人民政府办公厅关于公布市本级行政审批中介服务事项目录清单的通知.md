# 银川市人民政府办公厅关于公布市本级行政审批中介服务事项目录清单的通知

市政府各部门、各直属机构：

为深入推进审批服务便民化，根据《中共银川市委办公厅银川市人民政府办公厅关于印发的通知》（银党办〔2018〕70号）和《市政府办公厅关于印发银川市推进审批服务便民化实施意见任务分工方案的通知》（银政办发〔2018〕168号）精神，经市政府同意，现将《银川市市本级行政审批中介服务事项清单》（以下简称《清单》）予以公布，并就有关要求通知如下：

一、建立行政审批中介服务事项目录清单制度。凡《清单》中涉及到的部门(单位)，应按照政务公开要求，在办事大厅、门户网站等场所和平台，公布本部门实施的行政审批中介服务事项清单，接受社会监督。凡未纳入行政审批服务中介服务目录清单的中介服务事项，一律不得再作为行政审批的受理条件，国家另有规定的，从其规定。

二、实行行政审批中介服务事项清单动态管理。根据法律法规立改废释、机构改革和职能调整等情况，行政审批中介服务事项清单实行动态调整。《清单》中相关内容发生变化的，由相关部门在10个工作日内报送市发改委，按照程序审查，审查合格的纳入清单管理，并更新发布。

附件：银川市市本级行政审批中介服务事项清单（27项）

银川市人民政府办公厅
