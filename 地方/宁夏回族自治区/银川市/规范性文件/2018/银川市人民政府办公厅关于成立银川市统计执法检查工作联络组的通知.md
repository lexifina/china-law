# 银川市人民政府办公厅关于成立银川市统计执法检查工作联络组的通知

贺兰县人民政府，市发改委、工信局、财政局、商务局、统计局：

为配合做好自治区统计执法检查组来银工作，银川市人民政府决定成立银川市统计执法检查工作联络组，现通知如下：

组 长：杨有贤 市委常委、常务副市长

副组长：井 胜 市政府副秘书长

孙志强 市统计局局长

成 员：何建勃 市发改委主任

王 琦 市工信局局长

马建国 市财政局副局长

郝春明 市商务局局长

赵 波 贺兰县县长

刘晓天 市统计局副局长

曹庆宁 市统计局副调研员

丁兆江 市统计局办公室主任

王 斌 市普查中心主任

银川市统计执法检查工作联络组（以下简称联络组）负责协助配合自治区统计执法检查组开展工作，做好日常协调和保障任务，制定应急预案，处置突发事件，督导贺兰县及其有关部门和其他检查对象自觉接受调查，如实反映情况，提供资料和证据。孙志强兼任联络组联络员。

联络组下设综合协调小组、后勤保障与应急处置小组，刘晓天兼任综合协调小组组长，赵波兼任后勤保障与应急处置小组组长。

自治区统计执法检查组对贺兰县执法检查工作结束后，联络组自动撤销。

银川市人民政府办公厅

2018年3月28日
