# 银川市人民政府办公厅关于认真贯彻落实区市党委政府领导批示要求扎实做好当前全市民生保障和应急管理工作的通知

各县（市）区人民政府，市政府各有关单位：

12月5日下午14时至17时，宁夏哈纳斯天然气集团有限公司擅自对银川平昊新能源热力有限公司10个供热站停气，造成了南园一村二村、寺南小区、中房富力城、裕民小区、上海新村等11个社区，146万平方米，12754户居民停暖的严重事件。事件发生后，区市党委、政府主要领导和分管领导高度重视，先后作出批示，要求及时依法妥善处置。市政府领导现场督办，住建、公安等部门全力配合、依法处置，停暖区域于12月6日下午13:50全部恢复供暖。当日下午16：30市政府召开全市民生保障和应急管理工作会议，传达了泰峰书记、志刚书记指示精神，对这起事件进行了严肃通报批评，对下一步工作进行安排部署。这起擅自停暖事件是银川平昊新能源热力有限公司和宁夏哈纳斯天然气集团只顾企业局部利益，全然不履行社会责任，置市民冷暖安全、民生保障、群众利益和社会稳定秩序于不顾，扰乱居民正常生活，扰乱公共秩序和社会稳定的严重事件。这一事件之所以发生，除企业自身原因以外也反映出我市在民生保障和应急管理工作中还存在着薄弱环节，需要我们认真吸取教训，举一反三，深入学习贯彻落实区市党委、政府领导指示要求，切实抓好当前民生保障和应急管理工作，现就有关事项通知如下：

一、提高政治站位，高度重视民生保障服务及应急管理工作

民生就是民心，民心就是最大的政治。习近平总书记多次强调，要始终把人民放在最高的位置，想群众之所想，急群众之所急，解群众之所困。在10月31日中央政治局会议上，习近平总书记要求：各地要全面做好冬季各项民生保障，特别是要保障好群众温暖过冬，保障农民工工资及时足额发放，抓好安全生产，加强自然灾害的防治，确保社会大局的稳定。各级各部门要深入学习贯彻习近平总书记关于落实“以人民为中心”的发展思想，全面落实中央和区、市党委政府关于做好当前民生保障、应急管理工作的各项决策部署，切实把涉及供水、供暖、供气、供电、公共交通出行、安全生产、农民工工资清欠等领域的各项民生保障工作放在当前工作的重中之重，急之又急的位置，坚决把民生保障工作做实、做细、做好。要未雨绸缪，把可能发生的问题想在前、解决在前，采取实实在在的措施，坚决遏制容易影响公共秩序、社会问题和民生利益的恶性事件发生，以最坚决的态度，最有力的措施和对人民群众最深厚的感情，做好当前民生保障服务和应急管理工作，确保全市经济社会稳定，人民安居乐业。

二、加强组织领导，深入开展当前民生保障大排查大服务活动

各级各部门要认真总结经验、深刻汲取教训，切实加强组织领导，广泛发动群众，按照目标导向和问题导向，深入组织开展好当前民生保障大排查大服务活动。一要上下联动、形成合力。市住建、人社、民政、公安、交通、安监、气象、供电等部门以及相关企事业单位要制定工作方案，全面部署，抽调精干力量，组成工作小组深入一线，对全市服务保障体系进行拉网式排查，查短板、补漏洞，扎实做好民生保障和应急管理工作。二要注重实效，边查边改。要聚焦群众关心关注的热点难点问题，聚焦供水、供电、供气、供暖、交通出行、农民工工资清欠等重点领域，全面加强排查，切实做到不留死角、不漏问题。要及时发现问题、梳理问题，立说立行、立即整改，让广大人民群众共享改革成果，深切体会到党和政府的温暖。三要将排查整改与宣传教育引导工作相结合。结合全市正在开展的“为企业排忧解困大调研大排查”、“十大产业专题调研”等活动，深入企业开展督查排查工作，尤其是对涉及民生保障的企业要深入开展政策、党建、法制等宣讲工作，切实树牢“四个意识”、提高法治思维。要帮助企业抓运行、抓管理、抓服务、抓应急处置，提升企业正确履行政治责任和社会责任的能力。要帮助企业建章立制，规范“三会一课”等基本制度，加强规范化党组织建设，发挥基层党组织的战斗堡垒作用和共产党员的先锋模范作用。国有企业必须要紧紧围绕市委、市政府工作大局，要在贯彻落实党的路线方针政策、遵守法律法规、诚信合法经营、履行社会责任等方面走在前、做表率。

三、采取有效措施，全面做好当前民生服务保障工作

各级各部门要切实加强组织领导，尽职履责，高度关注供水、供电、供气、供热、交通出行及农民工工资清欠等民生问题，采取有针对性的措施，切实做好当前民生服务保障工作。

市住建局：一要切实抓好供热保障工作。修订完善供热突发事故应急预案，对今冬供热应急工作进行全面安排部署。指导和督促供热企业加强管理，设立24小时供暖服务电话，指导全市58家供热企业成立供热应急抢修队伍，做好28台大型锅炉调峰（备用热源）应急启用工作。督促完成华电“东热西送”主管线与电投热力公司主管线互联互通。抓好供热投诉办理，在出现供热爆管、停暖等突发事件时，确保第一时间赶赴现场组织实施抢修。加大监督监测力度，对于供热系统不稳定、温度上升较慢的区域重点监控，分析研究解决对策，确保居民室温达标。二要切实抓好天然气供应保障工作。修订完善冬季供气保障应急预案，确保供气非正常情况时有效应对。要与供热企业全面签订保供合同，做好供气时段的监控及供气不足的保供工作。做好供气紧张情况下的调剂工作，优先保障公交车辆及出租车的稳定运行。加强燃气安全运营，并会同有关部门定期对长输油气管线进行检查，保障燃气设施安全。三要切实抓好供水保障工作。对各水厂、水源地各类设施、管线、水表进行排查，广泛宣传普及供水设施设备防寒防冻知识，减少冻害影响。增设应急抢险抢修队伍，满足大型供水应急抢险抢修需要。加强对今年回填路段管线的巡查、评估，对重点防控地段进行巡视、排查，并提前做好应急抢修物料准备，防范今冬明春封冻、化冻可能发生的不规则沉降造成的管线断裂问题。对全市所有换热站用水户重点回访，掌握热用户用水需求，全力保障供暖用水。募集抢修协作力量，最大力度地防范大型爆管后路面涌水、结冰造成的二次危害。

银川供电公司: 一要制定今冬明春及“两节”期间电网安全运行保障方案，完善各类电网事故应急处理预案。二要针对今年供电性质由“供电”向“供热”转变，组织各单位对所辖线路、变电站、环网柜等设备开展特巡及隐患排查，重点对“电采暖”涉及线路、设备进行巡视检查，针对夜间及天气突变降温特点，对重要电气连接点、电缆终端头、电缆中间接头和柱上开关进行测温及局放检测，及时消除安全隐患，确保涉及“供热”的供电设备健康稳定运行。

市交通局：一要抓好今冬明春交通安全检查和互查工作，针对春运期间可能出现的区域性低温雨雪、阶段性强降温和持续性雾霾，制定并细化完善恶劣天气、设备故障等各类应急措施。在交叉时段不定时、不定点进行路检路查，加大处罚力度，对于“黑车”依法从重处罚。二要加强公路日常养护巡查，对路基、路面、桥涵及沿线设施进行全面检查，尤其是加大雨雪天气巡路排险工作和对易积冰桥梁、涵洞、急弯、陡坡、高填方、视距不良等路段的定期检查，及时消除隐患。三要进一步加大道路运输安全源头监管力度，督促运输企业切实履行安全生产主体责任，积极采取有效措施加强冬季行车安全管理。切实做好驾驶员冬季行车安全教育和车辆检查维护工作，严把驾驶人员上岗关，严禁车辆带病运行，努力保障交通运输安全。

市人社局：一要组织开展农民工工资支付工作专项督查，全面排查欠薪隐患，摸清欠薪底数，把问题发现在前，防范在先，及时妥善化解，防止小事拖大，蔓延发酵。二要实行拖欠农民工工资案件周通报制度，以“三个清单”形式，对存量案件挂牌督办，记账销号，减少存量，控制增量，争取春节前清零。三要对恶意拖欠、久拖不决、拒不配合的单位和个人，列为重大劳动保障违法行为向社会公布，并记入“黑名单”，实行联合惩戒。同时，加强舆论宣传引导，营造良好的治欠保支环境和氛围。四要严厉打击恶意欠薪违法讨薪违法犯罪行为，对有能力支付而拒不支付或欠薪逃匿者，加快行政执法和刑事司法的有机衔接，从速办理。

市民政局：一要切实保障好“冬春”困难群众基本生活。对照精准扶贫“两不愁三保障”目标要求，深入细致地解决好困难群众吃饭、饮水、取暖、医疗等基本生活问题。严格落实最低生活保障、特困人员供养、医疗救助、临时救助等政策，特别是在春节期间，要提前足额发放最低生活保障、特困人员供养资金。二要做好冬季灾害应急防范处置工作。要采取有效措施，全面排查各类灾害风险隐患，进一步完善应急救助方案，严防雪灾、低温冷冻等灾害，最大限度减少因灾损失，切实保障人民群众生命财产安全。三要深入开展“送温暖献爱心”和走访慰问活动。认真做好优抚对象抚恤补助资金的发放工作，确保抚恤补助资金能及时足额发放到每一位优抚对象手中。认真组织对生活困难的老复退军人、五保户、孤儿、城乡低保对象中的特殊困难户等走访慰问，让困难群众切实感受到党和政府的关心关怀。扎实开展向流浪乞讨人员“寒冬送温暖”活动，确保流浪乞讨人员有地方住、有棉衣穿、有热水喝、有热饭吃。

市公安局：一要继续深入开展扫黑除恶专项行动。严厉打击黑恶势力、涉枪涉暴、黄赌毒等严重危害社会的违法犯罪行为，提高群众安全感，巩固平安银川建设。二要严厉查处打击涉及民生保障、危害公共利益的违法犯罪行为。对涉及水、电、气、暖、公共交通出行等领域的危害公共安全、公共秩序的行为及时查处、严厉打击。三要配合做好农民工工资清欠工作，对无正当理由拒不支付劳动报酬和恶意逃薪等案件从严从快处理，依法保护农民工合法权益。四要认真组织开展“除隐患、查违法、压事故、保安全”专项治理及交通安全生产大检查活动，会同安监、运管等部门，深入公路客运、旅游客运、危化品运输、校车、“营转非”大客车等五类重点车辆企业、单位，对逾期未检验、未报废的车辆以及严重交通违法行为开展“清零”行动，同步加强对企业交通安全主体责任落实情况的检查督促。

市安监局：一要继续深入开展危化品安全专项整治活动。按照12月2日全国危化品安全生产电视电话会议和全市危化品安全生产工作会议安排部署，深刻吸取张家口11.28危化品爆炸事故教训，全面加强危化品安全隐患排查和督察工作，切实消除生产、储藏、运输、应用等各环节的“重大危险源”。二要全面做好今冬明春火灾防范专项整治行动。针对商业聚集区、人员密集场所、城乡结合部等重点区域加强排查整治，消除各类火灾隐患。三要加强烟花爆竹禁售禁放工作，与环保、公安部门配合，科学制定禁放区域和禁放时段，制定方案，及时下发通告，开展联合执法检查。四要做好“元旦”“春节”等重要节假日的安全检查工作，突出重点行业领域和薄弱环节，拉网式排查问题隐患，边查边改，确保节日安全生产。

市气象局：一要加强极端气候影响的预测预报。尤其对冬季大风、低温、雨雪天气过程，及时发布预警信息，做好服务。二要针对今冬明春天气气候特点，重点加强与交通运输、农业、供暖、供水、供电等管理部门的协调沟通，全力做好气象保障服务。三要强化公众气象服务，大力推广银川市气象局官方微信、微博的覆盖面和受众度，丰富宣传内容和手段，提高公众应对气象灾害的能力。

四、加强部门联动，压实责任，认真做好应急值守和信息报送工作

（一）健全应急管理机制。各级各部门要全面加强应急工作机构的协调联动，完善突发事件预测预警、信息报告、应急处置、恢复重建、总结评估等工作机制。要进一步完善市、县两级政府应急联动体系，增强市、县（区）政府应急平台与市住建局、水务局、交通局、民政局等部门专业应急管理信息平台互联互通、信息资源共享。强化各级各类突发事件防范应对工作协调配合，形成统一指挥、反应灵敏、协调有序、运转高效的应急联动机制，实现应急预案、信息、队伍、物资等协调联动、快速反应，实现多部门、多层次、统一高效地开展紧急救援或抢险救灾行动。充分发挥“12345一号通”便民服务平台对非警务事件处置的分流功能，提升“12345一号通”便民服务平台与供水、供电、供气等便民服务平台交互融合、无缝衔接，方便办事群众，提高应急处置实效。

（二）完善应急预案体系。各级各部门要按照银川市突发事件总体应急预案要求，根据实际工作需要和形势发展变化及时编制、修订、完善各类专项应急预案，形成横向到边、纵向到底的应急预案体系。尤其是市住建、交通、人社、民政、安监等涉及民生保障部门要采取有力措施，切实抓好本行业、本领域企事业单位和重点防护目标、重大危险源、危险区域及生命线工程单位等重点行业“一对一”应急预案完善工作，确保应对处置突发事件及时、准确、高效。同时，要全面加强应急预案管理，尤其是针对今冬明春民生保障工作要加强应急演练，做好各类应急预案衔接工作，不断增强应急预案的时效性、科学性和可操作性。

（三）强化值守应急和突发事件信息报告。要进一步建立健全总值班制度和领导在岗带班制度。凡涉及公共安全的部门（单位）、专业监测机构、直接涉及公共事业的企事业单位都要实行24小时值班制度。重要节假日、突发事件、重要活动、重要会议等重大、敏感时段，带班领导要在岗带班，确保政令畅通。要严格落实银川市突发事件信息报告制度和通报制度，不断提升第一时间获取信息的能力。要进一步建立完善信息报告联动机制，公安、卫计、消防等部门及新闻媒体要充分发挥进入现场快、覆盖面广、反应灵敏、手段先进等优势，加强重要信息的收集报告，实现信息共享。公安、宣传等部门要依托新技术、新手段，加强微博、微信、网络媒体等互联网信息的监测分析，及时掌握突发事件线索和影响社会安全稳定的苗头性、趋势性、敏感性信息。突发事件发生后，事发地政府、各工业园区（管委会）和市直有关部门要尽快掌握情况，指定1名现场联络员，要在30分钟内向市委、市政府电话报告，并通报有关县（市）区政府、行业管理部门和专项应急指挥部办公室。较大及以上或敏感性突发事件信息书面“首报”最迟不得超过1小时，一般突发事件信息最迟不得超过2小时，并随时“续报”事态进展情况，最迟不得超过次日下午16时。突发事件现场处置宣布结束后，要及时进行“终报”，终报时间不得超过现场处置结束后2小时。对迟报、漏报甚至瞒报、谎报行为要依法追究责任。在事发现场处置过程中，各级各部门负责同志要保持通讯畅通，全面掌握最新情况，及时准确上报事发现场处置进展情况，贯彻落实区市党委、政府主要领导批示精神。批示办理原则上当天反馈，最迟不超过24小时。
