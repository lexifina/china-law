# 银川市人民政府办公室关于下放行政审批事项的通知

各县（市）区人民政府：

2019年10月12日市人民政府第48次常务会议审议，同意将个体工商户登记、食品生产加工小作坊小经营店生产经营许可等15项行政审批事项下放至县（市）区办理，现予以印发，请认真贯彻落实。

附件：下放行政审批事项清单（第一批）

银川市人民政府办公室

2019年10月28日
