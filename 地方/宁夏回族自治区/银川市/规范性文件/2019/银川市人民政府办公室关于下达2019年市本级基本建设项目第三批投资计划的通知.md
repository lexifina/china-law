# 银川市人民政府办公室关于下达2019年市本级基本建设项目第三批投资计划的通知

各县（市）区人民政府，市政府各部门、各直属机构：

为确保完成市委、市政府确定的年度固定资产投资目标任务，加强项目统筹调度和动态储备，结合近期全市整改创建全国文明城市工作，切实解决影响群众出行和城市环境脏乱差问题，营造良好的宜居宜业环境，市人民政府研究确定了《银川市2019年市本级基本建设项目第三批投资计划》，现随文下达给你们，请按照投资计划认真组织实施，并就有关事宜通知如下：

一、加快前期手续办理

投资计划下达后，项目单位要按照投资计划安排，尽快确定具体包抓领导、经办人，列出前期手续办理清单，按规定和规范编制文本、报批手续，尤其是涉及整改创建全国文明城市大会战的项目，要压实责任，从实从快与前期审批服务部门进行对接申报，取得工作支持，确保手续完备，项目尽快开工达效。涉及前期审批服务的相关部门要依据投资计划，主动靠前服务，优化审批流程，压缩办理时限，提高服务效率，做好资金、规划、土地、供水、供气、供电等要素保障，为整改创建全国文明城市大会战工作和项目推进提供有力保障。

二、推进项目建设进度

各项目单位在前期手续完备的情况下，尽快组织招标投标和施工进场，主要负责人要主动过问、分管领导要具体包抓、经办人要坚持一线工作，要建立项目推进问题台账，实行挂图作战，将工作节点明确到月、到周、到天，倒排工期，全过程跟踪，全方位服务，压茬推进、无缝对接，确保项目如期建成达效。

三、强化项目日常管理

凡规划、用地、环评等前期手续必须按审批服务部门要求依规按序办理；项目严格执行基本建设程序和“四制”（项目法人制、招投标制、工程监理制和合同管理制），坚决杜绝“三边”工程（边勘察、边设计、边施工），防止“三超”现象（超规模、超标准、超投资），坚决杜绝“豆腐渣”工程。强化项目资金管理，做到公开透明，杜绝滞留、挤占、挪用、截留，以及弄虚作假和铺张浪费。严格执行工程质量安全管理法律法规和制度标准，按照“谁主管，谁负责”，强化“政府监督、业主负责、社会监理、企业自检”的质量保证体系，强化安全保障手段，保证工程按要求、按进度、按规范实施。

四、强化调度跟踪服务

进一步加强投资计划执行情况的监督考核，各项目单位必须于每月3日前向市发改委报送上月项目进展信息（包括建设进度、完成投资、资金到位情况和存在的问题等）；并同时向市县统计部门报送项目统计入库信息。市政府将对进度迟缓、影响全国文明城市整改创建工作的项目进行重点督查和通报，对推进不力或迟迟不开工的项目将动态调整出投资计划，并对项目责任单位和责任人给予严肃处理。
