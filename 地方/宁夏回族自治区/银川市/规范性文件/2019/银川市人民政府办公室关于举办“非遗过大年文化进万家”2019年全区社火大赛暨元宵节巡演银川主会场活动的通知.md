# 银川市人民政府办公室关于举办“非遗过大年文化进万家”2019年全区社火大赛暨元宵节巡演银川主会场活动的通知

各县（市）区人民政府，市政府各部门、各直属机构：

为深入贯彻落实习近平新时代中国特色社会主义思想和党的十九大精神，弘扬中华优秀传统文化，营造欢乐祥和、喜庆文明的节日氛围，丰富市民群众节日文化生活，根据自治区文化和旅游厅《关于举办“多彩非遗 扮靓春节”2019年宁夏社火大赛暨元宵节巡演活动的通知》（宁文旅通发〔2018〕11号）要求，现就举办“非遗过大年 文化进万家”2019年全区社火大赛暨元宵节巡演银川主会场活动相关事宜通知如下：

一、活动主题

非遗过大年 文化进万家

二、活动时间及地点

时  间：2月19日（农历正月十五）上午10：00

地  点：银川市人民广场

三、启动仪式

1.特色社火表演队表演（暖场）；

2.银川市政府领导讲话；

3.自治区文化和旅游厅领导讲话；

4.自治区领导宣布全区社火大赛暨元宵节巡演活动正式启动；

5.特色社火队进行集中展演，并依次退场进行沿街巡演。

四、巡演队伍

由银川市各县（市）区经过初赛、复赛选拔推荐，共组织22支优秀特色社火队，2000余人参加全区社火大赛及巡演活动。

五、巡演路线

银川市人民广场（社火队集结地）—人民广场东路—北京东路—凤凰北街—中山公园北门（巡演结束）
