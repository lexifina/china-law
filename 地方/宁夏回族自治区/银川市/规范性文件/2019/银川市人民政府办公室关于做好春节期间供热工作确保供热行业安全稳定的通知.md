# 银川市人民政府办公室关于做好春节期间供热工作确保供热行业安全稳定的通知

各县（市）区人民政府，市政府各有关部门、各供热企业：

2019年度春节即将到来，为了保证全市供热工作的正常平稳，确保我市居民度过一个温暖祥和的节日，现就做好我市春节期间供热工作及安全生产工作有关事宜通知如下：

一、牢固树立以人民为中心的发展思想

各相关部门、供热企业要进一步提高政治站位，牢固树立以人民为中心的发展思想，时刻把人民群众的安危冷暖挂在心上，加大工作力度，主动靠前指挥，诚心优质服务，扎扎实实做好供热应急保障各项工作。要坚持目标导向，明晰各方责任，加快问题解决，正确面对监督，严守党纪政纪法纪，加强统筹协调，确保人民群众温暖过冬。

二、确保供热系统安全平稳运行

（一）今冬采暖期已过半，各有关单位、供热企业要结合本采暖期供热运行情况、居民投诉情况和测温情况，对存在问题或隐患的锅炉、管网、设施设备等部位在节前采取有效措施，必要设备必须进行维修和养护，消除安全隐患，确保节日期间供热系统的平稳运行。

（二）各供热公司必须加强供热负荷，做好站点、小区、楼栋及各户的热力平衡工作。提前做好物资储备、人员配置和后勤保障等工作，确保节日期间燃煤等物资供应到位，煤质保障。加强对供热系统运行情况的检查频次，确保节日期间不停热、不断热。

三、确保供热质量和供热服务

（一）各供热企业要提高运行、维修、客服人员、测温人员综合素质，接访接电和到住户家中处理供热诉求时，工作人员要做到文明用语、礼貌待人、佩戴工牌、有理有据，不得激化双方矛盾。

（二）各县（市）区、市供热物业办等相关单位要安排做好节日期间的供热值班工作，保证对外公布的投诉、报修、测温电话24小时畅通，及时妥善的处理好居民反映的供热问题，不得拒绝居民测温要求。

四、加强供热应急管理工作

（一）市市政管理局、供热物业办负责，在春节前对全市各供热企业落实供热应急保障预案情况进行一次大检查、大排查，确保各项应急保障措施落实到位。

（二）各县（市）区要密切关注节假日期间供热运行和居民投诉情况，对辖区内供热投诉较多、供热不稳定的小区要增派人手、重点监管，督促各供热企业提前采取相关技术措施积极应对，保证供热质量。

（三）各供热公司要做到突发情况及时向12345和市供热物业办报备，同时做好向社区和广大热用户的公示、公告工作，做到信息公开、情况透明，避免因信息沟通不及时造成群众误解。

五、认真落实供热安全生产责任

（一）各供热企业对节日期间的安全生产工作要进行周密的安排部署，制定工作方案，分步骤、分阶段、有时间节点，各项应对措施要清晰明确、有可操作性。提前做好物资储备、人员配置和后勤保障等工作，做到有备无患。

（二）加强有限空间作业安全管理。各供热企业要严格执行有限空间作业审批制度和“先通风、再检测、后作业”的作业规定，不得放松警惕、麻痹大意、违规操作。节前再组织职工开展密闭空间作业培训，并对安全防护用具进行检查，务必确保安全用具合格有效，职工熟知密闭空间作业方法及流程，提高职工对炉膛、阀门井等密闭空间作业事故的应急处置能力，增强作业人员的应急常识和自救互救能力。

（三）加强企业消防安全工作落实。各供热企业要高度重视消防安全工作，建立消防安全工作长效机制，按照国家标准、行业标准、银川市消防规范标准等配置消防设施、器材。节前组织开展消防安全大检查工作，对检查中发现的消防安全隐患、薄弱环节要做到随时发现，随时处理，杜绝火灾事故的发生。

（四）各供热企业要确保节日期间供热质量、供热安全，不得擅自停热、断热，对于欠缴采暖费用的热用户，通过法律渠道予以解决，不得因欠费问题影响居民冬季正常采暖。

供热工作直接关系到社会公众利益，关系到人民群众生活质量，关系到城市经济和社会的可持续发展，各有关单位要主动担当，认真负责，加强供热管理、运行和保障，掌握供热平衡，保证供热质量，建立健全应急预案机制，防止意外事故发生，确保节日期间全市供热工作良好运行，让市民过一个欢乐、平安、祥和的春节！

特此通知。

银川市人民政府办公室

2019年1月31日
