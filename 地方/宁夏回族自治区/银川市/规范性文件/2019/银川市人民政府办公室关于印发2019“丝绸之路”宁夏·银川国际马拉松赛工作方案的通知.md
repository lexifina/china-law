# 银川市人民政府办公室关于印发2019“丝绸之路”宁夏·银川国际马拉松赛工作方案的通知

各县（市）区人民政府，市政府各部门、各直属机构：

《2019“丝绸之路”宁夏·银川国际马拉松赛工作方案》已经市政府同意，现予以印发，请认真贯彻执行。

银川市人民政府办公室

2018年3月5日

（此件公开发布）

2019“丝绸之路”宁夏·银川国际马拉松赛工作方案

2019“丝绸之路”宁夏·银川国际马拉松赛，将于2019年5月在银川举办。为筹备好此项国际性赛事，确保赛事圆满成功，特制定本方案。

一、指导思想

着力把银川国际马拉松赛打造成为品牌赛事和马拉松金标赛事，充分展示银川良好的人文环境、城市面貌和市民精神风貌，进一步推动群众体育和全民健身活动广泛开展，进一步提升运动休闲城市发展层次，为建设“绿色、高端、和谐、宜居”美丽新银川增光添彩。

二、赛事主题

健康、激情、超越。倡导积极健康的生活方式，让每一位参赛者都能享受到健康生活的乐趣，展现挑战自我、不断超越的马拉松精神，用奔跑的方式领略银川“国际湿地城市”的独特魅力和无限活力。
