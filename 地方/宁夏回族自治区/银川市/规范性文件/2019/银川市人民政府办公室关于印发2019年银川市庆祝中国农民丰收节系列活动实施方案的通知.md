# 银川市人民政府办公室关于印发2019年银川市庆祝中国农民丰收节系列活动实施方案的通知

各县（市）区人民政府，市政府各部门、各直属机构：

《2019年银川市庆祝中国农民丰收节系列活动实施方案》已经市政府研究同意，现印发给你们，请认真组织实施。

银川市人民政府办公室

2019年9月17日

（此件公开发布）

2019年银川市庆祝中国农民丰收节系列活动实施方案

为深入贯彻落实好中央关于设立农民丰收节的一系列决策部署，践行“庆祝丰收、弘扬文化、振兴乡村”宗旨，充分展示我市科技强农新成果，乡村振兴新面貌，调动农民的积极性、主动性、创造性，提升农民的荣誉感、幸福感、获得感，确保“2019年银川市庆祝中国农民丰收节活动”圆满成功举办，特制定本方案。

一、活动主题

共庆农业丰收 弘扬农耕文化 助推乡村振兴

二、活动时间

2019年9月23日—10月7日

三、总体要求

以习近平新时代中国特色社会主义思想为指导，以“庆祝丰收、弘扬文化、振兴乡村”为宗旨，按照“务实、开放、共享、简约”的要求，充分发挥农民主体作用，与新中国成立70周年、乡村振兴战略和脱贫攻坚战三大主题紧密结合，进一步营造全社会关注农业、关心农村、关爱农民的浓厚氛围，激发广大农民的积极性、主动性、创造性，为脱贫攻坚、全面建成小康社会、实施乡村振兴战略、加快推进农业农村现代化汇聚磅礴力量，将农民丰收节办成市民的嘉年华、农民的欢乐节、丰收的成果展、文化的大舞台，让全社会都感受到丰收的喜悦。

四、活动安排

活动以庆丰收系列活动为载体，以节为媒、释放情感、欢度国庆、传承文化、寻找归属,唤醒群众对传统农耕文化的记忆，增强文化自信和民族自豪感。总体安排为“1+2+N”，“1”即一个自治区主会场，“2”即一个银川市主会场和一个自治区分会场，“N”即各县（市）区举办的系列活动。其中自治区主会场、分会场和银川市主会场活动于9月23日丰收节当天同时举行，各县（市）区举办的系列活动在9月1日至9月30日陆续开展。以上所有活动使用“中国农民丰收节”组委会指定的统一主题标识。
