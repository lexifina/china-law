# 银川市人民政府办公室关于印发第十一届中国国际商标品牌节银川市工作实施方案的通知

各县（市）区人民政府，市政府各有关部门、有关单位：

《第十一届中国国际商标品牌节银川市工作实施方案》已经市人民政府研究同意，现印发给你们，请依照职责分工，认真抓好落实。

特此通知。

银川市人民政府办公室

2019年3月7日

（此件公开发布）

第十一届中国国际商标品牌节银川市工作实施方案

第十一届中国国际商标品牌节（以下简称商标品牌节）定于2019年7月5日至 7月8日在银川市举办。本届商标品牌节由中华商标协会、银川市人民政府、宁夏回族自治区商务厅、宁夏回族自治区市场监督管理厅、宁夏回族自治区博览局共同主办，银川市商务局、银川市市场监督管理局承办。为扎实做好各项组织筹备工作，确保商标品牌节成功举办，特制定本实施方案。

一、商标品牌节基本概况

（一）名称和主题。

名称：第十一届中国国际商标品牌节

主题：加强商标品牌保护，共建创新发展之路

（二）时间、地点及规模。

活动时间：2019年7月5日至8日（星期五至星期一）

活动地点：

展览—银川国际会议展览中心

平行论坛—银川国际交流中心

规    模：约3500人

（三）组织机构。

指导单位：国家知识产权局
