# 银川市人民政府办公室关于印发银川市“十三五”外向型经济发展规划(修订本）的通知

各县（市）区人民政府，市政府各部门、各直属机构：

为深入贯彻落实习近平新时代中国特色社会主义思想和党的十九大精神，按照自治区党委、政府对“十三五”规划文件进行清理的有关要求及银川市人民政府办公厅《关于对十三五各专项规划及园区规划有关问题修编的通知》，现将《银川市“十三五”外向型经济发展规划（修订本）》印发给你们，请认真贯彻执行。

银川市人民政府办公厅

2019年1月28日
