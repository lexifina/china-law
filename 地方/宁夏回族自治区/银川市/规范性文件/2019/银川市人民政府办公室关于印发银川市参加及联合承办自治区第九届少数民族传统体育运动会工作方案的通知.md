# 银川市人民政府办公室关于印发银川市参加及联合承办自治区第九届少数民族传统体育运动会工作方案的通知

各县（市）区人民政府，市政府各部门、各直属机构：

《银川市参加及联合承办自治区第九届少数民族传统体育运动会工作方案》已经市政府同意，现予以印发，请认真贯彻执行。

银川市人民政府办公室

2019年3月8日

（此件公开发布）

银川市参加及联合承办自治区第九届少数民族传统体育运动会工作方案

由自治区人民政府主办，自治区民委、体育局和银川市人民政府联合承办的第九届全区少数民族传统体育运动会（以下简称民族运动会）将于2019年5月16至21日在银川举行。为做好组队参赛及联合承办工作，特制定此工作方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，以“建设美丽新宁夏、共圆伟大中国梦”为主题，以“平等、团结、拼搏、奋进”为宗旨，充分展示我市少数民族传统体育特色和运动水平，促进少数民族传统体育传承发展，搭建各民族交往交流交融的平台，弘扬中华优秀传统文化，为铸牢中华民族共同体意识，打造全国民族团结进步示范市，推动我市民族团结进步事业再上新台阶做出积极贡献。

二、工作目标

力争“金牌数、奖牌总数和团体总分”三项第一，圆满完成自治区交办的各项承办任务，通过优异的比赛成绩和工作实绩，充分展示银川市改革发展成果和民族团结、社会和谐的精神风貌。

三、参赛项目

本届民族运动会设竞赛项目和表演项目两大类，其中竞赛项目设14项，分别是花炮、珍珠球、木球、武术、民族式摔跤、蹴球、押加、射弩、板鞋竞速、高脚竞速、毽球、陀螺、方棋和民族健身操；表演项目设3类，分别是竞技类、技巧类和综合类。我市组队参加民族运动会设置的所有竞赛项目和表演项目。

四、组建银川市代表团

根据民族运动会总规程、单项规程和我市参赛项目，银川市代表团由237人组成，设团长1人、副团长4人；参赛领队、教练、运动员及工作人员共232人。

五、承办任务

1.氛围营造。在我市三区主要街道和街区，开幕式、闭幕式场馆及比赛场馆周围营造浓厚、热烈的民族运动会氛围。

2.环境卫生。认真开展环境卫生整治工作，美化城乡环境面貌，为民族运动会营造干净、整洁的赛事环境。

3.食品安全。按照自治区民族运动会组委会医疗卫生部工作安排，对运动员驻地宾馆等接待单位的餐饮服务进行监督检查，保证食品安全。

4.交通安保。按照自治区民族运动会组委会安全保卫部工作安排，负责开幕式、闭幕式、运动员驻地、比赛场馆及运动会期间的安全保卫和交通疏导工作。

六、组织领导

为加强对参赛及联合承办工作的组织领导，成立银川市参加及联合承办全区民族运动会筹备工作领导小组，负责总体协调组织工作。

八、工作要求

（一）提高思想认识。筹备工作领导小组各成员单位及相关部门要切实提高政治站位，按照自治区民族运动会组委会和市委、市政府的统一部署及确定的总体目标、任务，周密安排，精心组织，以首府责任、首府标准、首府担当，全力做好各项组织筹备工作，保质保量完成自治区交办的各项承办任务，确保本届民族运动会圆满成功。

（二）强化责任落实。筹备工作领导小组各成员单位及相关部门要切实增强大局意识，树立全市一盘棋思想，加强部门之间的协调配合以及与自治区的衔接沟通，确保筹备工作精益求精、万无一失。要细化工作责任，倒排任务进度，制定详细的单项工作方案和应急工作预案，狠抓工作落实，确保各项工作高效完成。

（三）加强训练备战。各参赛项目组织单位要加强参赛队伍建设，选好配强教练员、运动员及编导人员，刻苦训练，积极备战，切实提高竞赛队伍的实战能力和竞技水平，圆满实现参赛目标；要充分发扬拼搏进取的体育精神，勇争一流，赛出成绩，赛出水平，赛出风格，展现银川代表团的时代风采和良好形象，展示我市精神文明建设和民族团结进步创建成果。

（四）加强氛围营造。要加大宣传力度，强化舆论引导，大力宣传“建设美丽新宁夏，共圆伟大中国梦”的主题，宣传“平等、团结、拼搏、奋进”的宗旨，充分动员全社会力量共同参与筹备组织工作，努力营造“办好民族运动会，当好东道主”的浓厚氛围。要做好民族运动会期间安全保卫和维护社会稳定工作，认真排查各类矛盾纠纷和安全隐患，确保民族运动会平安、顺利举办。
