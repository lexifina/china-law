# 银川市人民政府办公室关于启用银川市人民政府行政复议委员会等单位印章及废止有关单位行政复议专用章的通知

各县（市）区人民政府，市政府各部门、各直属机构：

根据《银川市机构改革方案》（宁党办〔2019〕17号）、《关于印发银川市人民政府相对集中行政复议权试点工作方案的通知》（银政发〔2013〕127号）要求，经市政府同意，启用银川市人民政府行政复议委员会印章、银川市科学技术局等24个单位行政复议专用章；另外原银川市卫生和计划生育委员会等10个单位的行政复议专用章予以废止。印章直径均为4.0厘米。

附件：启用和废止有关行政复议专用章名单和新启用印章印模

银川市人民政府办公室

2019年4月15日

（此件公开发布）
