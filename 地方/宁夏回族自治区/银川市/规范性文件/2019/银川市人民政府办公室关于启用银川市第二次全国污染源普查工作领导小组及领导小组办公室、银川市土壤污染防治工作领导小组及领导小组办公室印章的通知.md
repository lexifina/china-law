# 银川市人民政府办公室关于启用银川市第二次全国污染源普查工作领导小组及领导小组办公室、银川市土壤污染防治工作领导小组及领导小组办公室印章的通知

各县（市）区人民政府，市政府各部门、各直属机构：

为确保我市第二次全国污染源普查工作、土壤污染防治工作顺利推进，经市政府同意，即日起启用“银川市第二次全国污染源普查工作领导小组”“银川市第二次全国污染源普查工作领导小组办公室”“银川市土壤污染防治工作领导小组”“银川市土壤污染防治工作领导小组办公室”印章。

银川市人民政府办公室

2019年9月3日
