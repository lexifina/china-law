# 银川市人民政府办公室关于调整政府副市长工作分工的通知

各县（市）区人民政府，市政府各部门、各直属机构：

经银川市人民政府研究，并报市委同意，现将部分副市长工作分工调整如下：

由孙学庆同志联系银川海关（宁夏出入境检验检疫局）、兴庆海关、银川市烟草专卖局；

由徐华东同志分管银川丝路经济园，银川高新技术开发区；

由张全智同志分管市场监督管理局。

银川市人民政府办公室

2019年5月9日
