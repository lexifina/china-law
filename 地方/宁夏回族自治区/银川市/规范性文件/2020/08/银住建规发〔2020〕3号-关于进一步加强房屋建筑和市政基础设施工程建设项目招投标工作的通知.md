# 关于进一步加强房屋建筑和市政基础设施工程建设项目招投标工作的通知

银住建规发〔2020〕3号

各建设单位、招标代理机构：

为进一步加强我市工程建设领域招标投标活动，依法正确履行好监管职责，结合扫黑除恶专项斗争行业乱象整治工作开展，切实解决我市房屋建筑和市政基础设施工程建设项目(以下简称“工程建设项目”)招投标活动中存在的弄虚作假、围标串标等突出问题，营造良好的营商环境，推动我市招标投标活动健康有序发展，现就有关事项通知如下。

一、规范招投标活动

（一）严格执行必须招标的工程规模及范围标准。按《宁夏回族自治区招标投标管理办法》（宁夏回族自治区人民政府令第103号）等国家、自治区相关规定范围内的工程建设项目，其勘察、设计、施工、监理以及与工程建设有关的重要设备、材料等的采购达到范围标准之规定的，必须招标。

（二）合理设置投标人资格条件。在必须招标的工程建设项目招标公告以及招标文件中，不得擅自扩大招标范围随意提高招标门槛，不得以不合理条件限制或者排斥潜在投标人。工程建设项目招标时，投标人资质等级设置，按照住建部《建筑业企业资质管理规定》执行，技术特别复杂或者具有特殊专业技术要求的建设项目可适当提高投标人资质等级要求。

（三）建设工程项目建设单位（招标人）可自行选择招标代理机构，优先考虑信用综合评分好的工程招标代理机构。招标代理机构承接业务实行项目负责人制，项目组成人员由本机构至少3名中级以上职称专职人员组成，招标代理机构在开展业务时，项目组人员须与填报的《工程招标代理项目信息表》人员信息一致。

（四）在建设工程招标投标活动中对失信被执行人实施联合惩戒，构建一处失信、处处受限的信用监督、警示和惩戒工作体制机制。一是将企业诚信分值纳入评标办法中，企业诚信分值来源于宁夏建筑市场监管服务系统所公布的企业信用分。二是依托“信用中国”、“信用宁夏”、“信用银川”等信用平台查询企业信用、信息，依法对失信被执行人在招投标活动中，采取限制措施。

（五）优化招投标保证金缴纳方式。我市市辖三区房屋建筑和市政基础设施工程项目建设活动中，相关企业可根据实际选择保证保险、银行保函、工程担保等形式进行各类建设工程履约保证。保证保险、银行保函、工程担保合同与现行的现金保证具有同等效力，企业可自主选择，各担保受益人不得拒绝或限制使用。保证保险、银行保函、工程担保合同的保证金额或投保金额及提交时点等，按自治区工程保证金现行规定执行。提升保证金退还效率，招标人与中标人签订合同后5日内，应当向中标人和未中标的投标人退还投标保证金。

（六）推行不见面开标方式。凡进入银川市公共资源交易中心招投标的房屋市政工程施工类项目全部实行电子招投标，采用不见面开标方式。

二、强化日常监管

（一）加强招标代理机构诚信信息管理，完善项目负责人管理制度。重点监督招标代理机构项目组人员身份信息、到岗情况，提高企业自律和诚实守信意识，推进代理机构整体实力提升。

（二）建设工程项目在评标结束后，招标人应当自收到评标报告之日起三日内，将评标结果在“宁夏公共资源交易网”等网站进行公示接受社会监督，公示内容包括评标委员会推荐的中标候选人名单及其排序、投标文件被否决的投标人名称及其被否决原因及依据等其他依法应当公示的内容。

（三）畅通投诉渠道、规范投诉行为。逐步完善工程建设项目招投标投诉处理机制，招标人收到的异议件或市建设工程招标投标管理中心收到的投诉件应符合《工程建设项目招标投标活动投诉处理办法》(国家七部委第11号令)、《住房和城乡建设部关于进一步加强房屋建筑和市政基础设施工程招标投标监管的指导意见》（建市规〔2019〕11号）要求，市建设工程招标投标管理中心要建立健全公平、高效的投诉处理机制，及时受理并依法处理招标投标投诉，加大查处力度。规范投诉行为，投诉书应包括投诉人和被投诉人的名称地址及有效联系方式、投诉的基本事实、相关请求及主张、有效线索和相关证明材料、已提出异议的证明文件。属于恶意投诉的，应追究其相应责任。

三、加大违法行为查处力度

（一）对存在弄虚作假、围标串标，恶意竞标等违法行为的投标人，一经查实，依据《中华人民共和国招标投标法》《工程建设项目施工招标投标办法》等法律法规进行查处，并将查处结果移交市综合执法部门进行处罚，处罚结果通过“宁夏建筑市场监管与诚信信息系统”、“信用银川”等平台向社会公开，情节严重的，取消其一年至三年内参加依法必须进行招标的项目的投标资格。

(二)对评标过程中涉嫌违法、违规的评标委员会成员，依据《中华人民共和国招标投标法》（主席令第21号）、《中华人民共和国招标投标法实施条例》（国务院令第613号）等法律法规进行查处，并将查处结果移交市综合执法部门进行处罚，处罚结果通过“宁夏建筑市场监管与诚信信息系统”、“信用银川”等平台向社会公开，并对违法的评标委员会成员取消评标委员会成员资格，不得再参加任何依法必须进行招标项目的评标；构成犯罪的，依法追究刑事责任。

本通知自2020年8月22日起施行，有效期至2023年8月21日。

银川市住房和城乡建设局
