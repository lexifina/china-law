# 银川市人民政府办公室关于做好2020年清明节祭扫安全服务工作的通知

各县（市）区人民政府，市政府各相关部门：

2020年的清明节正值抗击新冠病毒感染肺炎疫情时期，按照民政部和自治区有关文件精神，经请示市委疫情防控工作领导小组研究同意，现就做好2020年清明节期间祭扫安全保障有关工作通知如下：

一、提高认识，压实责任

当前我市疫情防控形势虽持续向好，但清明节祭扫人员流动和聚集仍存在疫情传播的风险。各县（市）区人民政府和相关部门要进一步强化大局意识和责任担当，严格落实“属地管理”责任，因地制宜，精准施策，进一步加强组织领导，建立健全政府分管领导牵头，公安、民政、卫生健康、市场监管、综合执法等部门密切配合的应急处置机制，全力做好2020年清明节期间的疫情防控和群众祭扫安全保障工作，确保群众生命安全和身体健康。各级民政部门要严格落实一把手负总责、分管领导具体抓、殡葬管理机构督导检查、殡葬服务单位认真落实的安全管理责任制，失职必须追究责任。

二、因地制宜，分类施策

（一）全市殡葬服务机构暂停组织集体公祭、骨灰生态集中安葬等群体性活动和骨灰堂等室内场所祭扫。

（二）市辖三区、永宁县、贺兰县境内各公墓陵园（榆树沟汉民公墓、防火公墓等位于贺兰山自然保护区范围内的公墓除外）在做好控流量、防聚集、强防护、保安全等工作的基础上，有序开放室外祭扫服务。

（三）灵武市清明节祭扫期间是否开放室外祭扫，由当地疫情防控工作领导小组研究决定。

三、多措并举，加强管控

开放室外祭扫配合公墓陵园，要通过宣传，电话、网络预约等形式控制进园祭扫人员数量，引导移风易俗，文明祭祀。所有殡葬服务机构及祭扫场所均应实行进入人员实名登记。 清明期间禁止在街道、广场、居民区、公园、绿地、风景区等公共场所焚烧花圈、纸钱等殡葬祭祀用品；禁止在贺兰山国家级自然保护区、灵武白芨滩国家级自然保护区和其它林地、草地等易失火区域进行烧纸烧香、燃放烟花爆竹等用火行为，严防火灾事故发生。提倡用鲜花、丝带寄语等方式代替传统祭扫方法，推行绿色低碳祭扫。各县（市）区要将农村公益性墓地和历史形成的集中埋葬点纳入祭扫管控范围内，采取有效措施，避免群众聚集性祭扫。

四、履职尽责，提升服务

各殡葬服务机构要按照统一部署，严格落实主体责任，根据当地疫情防控要求及自身设施场地、防控条件等情况，通过平时与丧主建立的沟通渠道，引导群众分时段、间隔性祭扫，科学合理安排祭扫场所承载量；通过祭扫人员流量关口前置管控，查验防疫健康码、测温登记等方法，进行流量监测预警；未佩戴口罩人员禁止进入墓区祭扫；对易造成人员聚集的殡葬服务场所入口及周边强化疏通引导和劝散；增配人员加强祭扫服务引导和园区巡查；严格落实员工自我防护防控措施，防止员工感染；对重点部位、重点环节、重点场所的安全隐患全面开展排查整改，从源头消除火灾、踩踏等各类安全风险，防止发生各类安全事故；要修订完善应急预案，制定具体工作方案，明确应急措施和处置流程，确保疫情防控和安全防范各项措施落实到位，坚决防止发生聚集性疫情和安全生产责任事故。

五、广泛宣传，促进改革

各县（市）区人民政府和相关部门，要加强宣传引导，稳妥应对舆情，充分利用主流媒体、网络平台、微信群广而告之，悬挂横幅、社区宣传栏、印发宣传册等多种宣传形式，广泛宣传疫情防控期间有序管控祭扫服务的意义，充分发挥村（居）委会、红白理事会等基层群众自治组织的作用，宣传移风易俗、丧礼改革，推动殡葬法规宣传，依法规范殡葬行为，自觉破除丧葬陋习，逐步摈弃祭扫活动中焚烧殡葬用品污染环境的行为。要通过宣传做到家喻户晓，人人皆知，营造群防群控、文明祭祀的良好氛围。

六、加强值班，信息畅通

清明节期间，各县（市）区人民政府和各职能部门，要成立祭扫工作领导小组，加强领导，严格值班制度，保障信息畅通，遇到紧急情况务必及时上报。3月22日至4月6日，各县（市）区民政局要每天汇总本地祭扫情况，于当日14时前将情况报市清明祭扫工作办公室（联系电话：5985144）。3月22日前上报值班表和人员名单。4月10日前以书面形式上报2020年清明节祭扫工作总结。

银川市人民政府办公室
