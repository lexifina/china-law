# 银川市人民政府办公室关于启用废止部分政府机构印章的通知

各县（市）区人民政府，市政府各部门、各直属机构：

根据中共银川市委机构编制委员会《关于调整市本级部分事业单位机构编制事项的通知》（银机编发〔2019〕45号）和《关于整和组建市交通运输综合执法支队有关机构编制事项的通知》（银机编发〔2020〕15号）要求，经市政府同意，即日起启用“银川市社会保险事业管理中心”“银川市工程项目代理建设服务中心”“银川市交通运输综合执法支队”3枚印章，原“银川市社会保险事业管理局”“银川市医疗保险事务管理中心”“银川市工程项目代理建设局”和“银川市道路运输管理局”“银川市公路路政稽查支队”5枚印章即日起废止。

附件：启用印章印模样

银川市人民政府办公室
