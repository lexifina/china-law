# 关于公布2019年规范性文件清理结果的决定

各乡镇场、县委各部委、政府各部门、各人民团体、县属各企事业单位及各区市驻县属单位：

根据县委办公室《关于贺兰县机构改革涉及相关工作任务分工的通知》（贺党办发〔2019〕4号）要求，对现行有效的行政规范性文件进行了清理。经清理，继续有效32件,宣布失效10件，废止41件,修改13件。

本决定自公布之日起施行。

附件：1.继续有效行政规范性文件目录

2.宣布失效行政规范性文件目录

3.废止行政规范性文件目录

4.修改行政规范性文件目录

贺兰县人民政府

2019年12月30日
