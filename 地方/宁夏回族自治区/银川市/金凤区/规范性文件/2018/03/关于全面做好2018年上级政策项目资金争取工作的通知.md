# 关于全面做好2018年上级政策项目资金争取工作的通知

各镇人民政府、街道办事处，区政府各部门、单位，市属各派出机构：

为充分调动各部门、各单位向上争取政策项目资金工作的积极性和主动性，科学评价有关部门工作实绩，加快推动金凤区经济社会持续健康发展，经党委、政府研究决定，现就全面做好2018年上级项目资金政策争取工作有关事宜通知如下。

一、提高思想认识，加大争取力度。各部门、单位要充分认识国家、区市政策项目资金对金凤区经济社会发展的带动和支持作用，把争取政策、项目和资金工作摆上重要议事日程，主要领导亲自抓，分管领导具体抓，班子成员集体上，做到领导到位，责任到位，工作到位，落实到位。对重大项目和关键节点，主要负责同志要亲自挂帅，全力以赴做好汇报、沟通和申报争取工作。经发、教育、科技、民政、财政、卫生和计划生育、就业、林业、建设交通、农牧水务、文体旅游等部门是争取上级资金的重点部门，要围绕产业转型升级、基础设施项目建设、社会公共事业建设等方面工作，认真研究国家和区市有关项目发展计划和政策性资金使用方向，及时掌握国家、区市政策及资金调整、变化、投向的新情况，确保完成全年目标任务。

二、明确内容范围，严格考核认定。争取的项目，指未列入年度政府投资基本建设项目计划，由各部门、单位通过积极争取实施的其他项目。包括由国家、自治区、银川市发改委立项的项目；由国家、自治区、银川市各有关部门支持的项目；引入企业或其他组织实施的建成后无偿移交给政府的基础设施或其他项目。争取的资金，指不含国家、自治区、银川市上级部门政策性转移支付的资金，由各部门通过各种渠道对口争取，用于经济社会发展的资金。包括从国家、自治区、银川市财政争取的资金；从国家、自治区、银川市其他部门争取的资金；非财政性无偿资金和实物（主要指社会各界、企业捐赠资金或实物）。争取的政策，指通过努力，争取到国家、自治区、银川市相关行业内优惠政策及在金凤区进行的试点改革工作。认定的标准，指被审核单位有“申报项目资金文件、上级部门批复立项和安排资金的文件”为认定依据。争取政策的认定，以自治区、银川市“三争”工作年终情况通报为认定依据。争取到的社会各界（包括企业）实施的无偿移交给政府管理的项目以决算书金额认定；捐赠物资由物价部门认定；捐赠资金以财政收款收据认定。对两家及两家以上部门联合争取的项目资金，由牵头单位负责协调确定各部门分配比例。争取到转移支付的资金、项目要在任务考核中予以核减。

三、精准把握政策，找准对接要点。各有关部门和单位要精准把握上级政策，紧密结合我区“十三五”规划，找准政策、项目和资金争取的切入点和突破口。

一要深入研究国家和区市产业和投资政策，及时了解和掌握国家、区市投资方向，积极主动反映我区在产业转型、城市建设、科技创新、生态治理等方面的着力点，着重突出区位优势，力争在产业升级改造、城市基础设施建设、创业创新、大气污染治理等方面给予支持。

二要把握好2018年区、市预算支持重点和区、市部门研究、分配、批复项目资金的时间节点，千方百计挖掘项目资金信息，动态跟踪政策变化，有针对性的研究重大政策和重点项目。

三要扎实做好项目前期工作。经发局要组织相关部门围绕“十三五”规划和金凤区2018年经济社会发展要求，设计、编制和整合一批优势项目，建立项目储备库。对项目储备库实行动态管理，根据上级政策的调整，及时清理过时的项目，补充调整新项目，不断提高入库项目质量，使项目库始终保持一批适时对路的项目。要适时将国家和区市投资信息汇编形成《投资指南》向部门和企业定期发布，用信息引导项目争取工作，避免项目争取的盲目性。各部门、单位要结合我区经济发展特点、社会事业发展方向、产业特色优势等，精心筛选一批符合上级投资导向和支持方向的重点项目，加强与区市对口部门的沟通对接，切实增强政策、项目和资金争取工作的可行性、实效性。同时，要抓好项目前期工作，及早梳理申报资料，做实做细项目的谋划、论证、包装等，进一步完善项目库建设，做到有的放矢，提高向上争取项目资金工作的科学性、精准性和有效性。

四、强化沟通协调，形成工作合力。经发、财政、国土、环保等部门要充分发挥职能作用，积极协助各项目单位做好已批准项目开工前各项手续办理，相互补台，确保项目早落地、早开工。财政部门要主动发挥协调指导作用，组织做好与区级、市级对口部门的联系沟通工作，反映金凤区特色优势和急需支持的领域、项目。各部门、单位要把懂业务、能力强的同志安排到政策、项目和资金争取中来，把政策、项目和资金争取工作落实到具体科室、落实到具体责任人，确保争取工作有人抓、不断线。对有望得到国家、区市支持我区的特殊政策，已经上报并有可能列入计划的项目、资金，要明确专人跟踪对接，盯紧关键节点，确保政策、项目和资金尽早落实。

五、严格督促考核，推进工作落实。政研督查室、经发局、财政局要按照各自职能，及时掌握各部门、单位政策项目资金争取工作进度与存在的问题，督促指导各责任单位全力抓好落实。每季度梳理各部门、单位争取的政策、项目和资金落实到位情况，以及试点工作、试点项目、创新工作情况，形成详细清单，向政府报告。各部门、单位每季度末将本单位争取到的政策、项目和资金列出清单（详见附件），经单位领导签字、加盖公章，分别报送政研督查室、经发局和财政局。政府办公室将联合党委办公室、人大办公室、政协办公室、政研督查室对各部门政策、项目和资金争取工作将进行专项督查、通报、公示，并将督查结果作为年终考核的重要依据。今年，对各部门单位争取的试点工作、试点项目、创新工作将一并纳入争取政策情况进行考核，兑现奖罚。同时，强化问责问效，对组织不力、协调不畅、被动应付、推诿扯皮、落实不到位的部门和人员，依据相关规定予以问责，推进政策对接和资金项目争取工作有效落实。
