# 关于印发2018年金凤区应急管理工作要点的通知

各镇人民政府、街道办事处，政府各部门、单位，市属各派出机构：

现将《2018年金凤区应急管理工作要点》印发给你们，请认真贯彻落实。

银川市金凤区人民政府办公室

2018年4月13日

（此件公开发布）

2018年金凤区应急管理工作要点

2018年，金凤区应急管理工作的总体思路是:以习近平新时代中国特色社会主义思想为指导，认真贯彻自治区、银川市关于加强应急管理工作的决策部署及市委“绿色、高端、和谐、宜居”理念,紧紧围绕区委、区政府中心工作，坚持防治结合，以防为主，突出问题导向，强化关口前移，推进应急管理工作重心向风险管控和预防准备转变，进一步加强应急管理体制机制建设，夯实应急管理基础，全面提升应急管理科学化专业化水平，为保障人民群众生命财产安全，加快金凤区“五城五区”建设营造良好的社会安全环境。

一、强化应急值守，规范信息报送工作

（一）严格做好值守应急工作。依据自治区、银川市及金凤区党委、政府有关规定，严格落实24小时应急值班、领导带班制度，确保“零差错”。进一步优化值班工作流程，完善制度，改进手段，切实发挥好突发事件信息接报、分析研判、督导落实等统筹协调作用。

（二）严格做好节假日和重要节点、敏感时期的值班工作。继续抓好“日报告”、“零报告”制度的落实，加强对应急值班工作的督导检查，落实值班室、值班员、值班制度及值班保障，确保值守应急工作到位，联络畅通，运转高效。

（三）建立健全应急管理机构。各部门、单位要完善应急管理工作领导小组，主要负责人为第一责任人，明确专人负责应急管理工作。各专项应急工作机构办公室要切实履行职责，落实专职工作人员，发挥运转枢纽作用，履行值守应急、信息汇总上报和综合协调职责，做好应急管理日常工作。

（四）切实加强基层应急体系建设。加强镇（街道）、社区（村）及学校、医院、商场、驻地企事业单位等基层应急体系建设，镇、街道主要负责人为第一责任人，明确相关责任人员，在党委、政府的领导下做好应急管理工作。

（五）加强信息报送规范化建设。严格落实突发事件信息“三核三报”制度，重要紧急信息边处置、边报告、边落实，坚持“高度敏感，注重关联和敏感信息不分级别”原则，不断提高信息报告的时效性、准确性和统一性。进一步强化信息报送工作，规范信息报告的时限（口头报告不超过30分钟，书面报告不超过一个小时）、内容及责任，实行定期通报制度，确保不出现迟报、瞒报、漏报、谎报等问题。

二、强化资源整合，提高应急处置能力

（一）强力推进风险隐患排查。“按照谁主管，谁负责”的原则，认真落实突发事件风险隐患排查、登记、监控和监测制度，建立健全风险隐患数据库和动态监管体系。组织力量认真开展所辖范围内容易引发重大突发事件、危险区域调查、登记和风险评估工作，建立健全风险隐患信息数据库，编制公共安全风险清单，完善风险管控“一张图”。督促有关部门和单位实时进行检查、监控，积极落实防范措施。完善自然灾害、事故灾难、公共卫生事件、社会安全事件等各级各类监测监控体系。

（二）加强公共安全形势预判。进一步加强和完善民政、安监、卫生计生、公安部门分别牵头，各部门共同参与的公共安全形势分析预判制度，加强对突发事件监测预警信息分析研判，健全多部门分工共享机制，提高监测预警信息快速获取、分析、研判和处理能力。

（三）扩大预警信息覆盖面。充分利用广播、电视、互联网等各种媒体和手段，及时将预测预警信息和防灾避灾措施通知到镇（街道）、社区（村），传递到社会公众中，不断提高预警的实效性和准确度。

同时，各镇（街道）、各部门尤其是应急核心部门要定期做好各类突发事件趋势的预测分析，认真做好研判会商，提早做好防范准备并及时上报政府应急办。

三、强化预案管理，完善应急预案体系

（一）完善应急预案体系。严格按照自治区、银川市应急预案管理办法，做好政府及镇（街道）、各部门应急预案的完善工作。结合实际，不断改进、补充、完善各类预案，形成总体预案、专项预案、部门预案相衔接的应急预案体系。强化应急预案定期修编，不断提高应急预案的时效性、科学性和可操作性，使应急预案管理更加科学规范。

（二）积极推动基层应急预案全覆盖。突出抓好镇（街道）、社区（村）和各类企业等基层组织，学校、医院等公共服务机构，供水、供电、供气等生命线工程，能源、交通等重要部门，大型会展、文化体育旅游等重大活动“一对一”应急预案的编制修订工作，建立健全“横向到边、纵向到底”的应急预案体系。

（三）切实加大应急预案演练力度。强化应急预案演练常态化、规范化、实战化。结合实际制定应急预案演练计划，专项应急预案、部门应急预案每年至少开展 1次应急演练，基层单位应急预案每年至少开展 2次应急演练，各类学校每年至少开展 4次应急演练。及时开展预案演练总结评估，举一反三、查漏补缺，达到提升预案实效，普及应急知识，完善应急准备的目的。演练总结评估报告报政府应急办，作为检验本年度应急演练是否实施的重要依据。

四、强化能力建设，健全应急资源保障体系

（一）加强应急队伍能力建设。在不断加强和提高综合应急救援队伍能力建设的同时，突出抓好抗震救灾、防汛抗旱、森林（草原）防火、气象灾害、地质灾害、非煤矿山、危险化学品、公共事业保障、公共卫生、重大动物疫情等专业队伍能力建设，明确职责任务，建立联动响应机制，注重实战性和可操作性，在科学决策的基础上有效处置。加强企业应急救援队伍、民兵救援小分队和社会志愿者队伍建设，科学配置，优化装备，加强日常训练，提高应急救援队伍实战能力。

（二）加强应急物资保障体系建设。各镇（街道）、有关部门和单位要根据本地区、本行业主要风险源和应急工作实际，突出重点、因地制宜地做好应急物资储备工作；进一步开展应急物资调查摸底工作，完善应急物资储备的品种、规模、布局和方式，充分利用社会力量，多措并举、多种方式开展实物、协议、生产能力等多种形式物资储备，形成储备形式多样化。

（三）推进应急管理专家队伍建设。把应急管理专家队伍作为预防和有效应对突发事件的智力支撑，组织专家积极参与应急管理基础工作调研，指导应急处置事件活动；通过开展政策法规咨询、会商研讨及参与处置等活动，发挥应急专家队伍的辅助决策作用，进一步增强应急决策的科学性。

五、推动重心下移，提升基层应急建设水平

（一）强化基层应急能力建设。把加强基层应急管理工作作为全面履行政府职能的一项重要任务，重心下移，立足基层，夯实基础，扎实推进。通过示范社区、公共安全和防灾减灾科普宣教基地建设，强化基层单位应急能力建设的示范推广，鼓励和引导更多社会力量参与。

（二）实施“第一响应人”培训计划。由消防大队、卫计局牵头负责，安监局、教育局、文体局、建设交通局、商务局、市场监管局配合，组织开展“第一响应人”培训计划，重点对教师、导游、人员密集场所从业人员等实施消防和卫生急救应急能力培训。

六、强化宣教培训，提升公众防灾避险能力

（一）不断加大教育培训力度。有计划的开展应急救护基础知识、应急救援等培训，提升应急人员的专业技能水平。依托相关部门举办应急管理干部培训班，积极普及应急管理知识，进一步提高干部驾驭局势、综合协调、自救互救和应对处置突发事件的能力。

（二）广泛开展应急常识宣传。充分利用广播、电视、报刊、互联网、微博、微信等媒体，结合“防灾减灾日”、“消防日”、“安全生产宣传月”等活动，大力开展应急常识进机关、进企业、进学校、进农村、进社区等活动，向社会大众普及灾害风险知识和自救互救技能，增强公众公共安全意识和社会责任意识。
