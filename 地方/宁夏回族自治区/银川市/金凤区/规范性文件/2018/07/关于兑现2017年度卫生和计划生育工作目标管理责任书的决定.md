# 关于兑现2017年度卫生和计划生育工作目标管理责任书的决定

各镇人民政府、街道办事处，区政府各部门、单位，各人民团体，银川丝路经济园建设服务办公室，银川阅海湾中央商务区服务中心，阅海集团，海阅公司，市属各派出机构：

2017年以来，各部门、单位在区委、政府的坚强领导下，认真贯彻落实全国、自治区和银川市卫生与健康大会精神，把“抓落实”作为主旋律，群策群力、务实重干，圆满完成了卫生和计划生育各项指标任务。

为表彰先进，更好的促进工作，按照《金凤区2017年卫生和计划生育目标管理责任书》规定，依据《金凤区2017年卫生计生综合目标管理责任制考核评估细则》考核结果，决定授予长城中路街道办事处一等奖，奖励6万元；上海西路街道办事处、黄河东路街道办事处、满城北街街道办事处二等奖，各奖励4.5万元；北京中路街道办事处、丰登镇人民政府、良田镇人民政府三等奖，各奖励2.5万元。对在2017年大肠癌、脑卒中筛查项目工作中表现突出的金凤区疾病预防控制中心授予“创新奖”，奖励5000元。对完成部门责任指标突出的教育局、文体旅游局授予一等奖，各奖励5000元；宣传部、组织部、城管局（爱卫办）、财政局授予二等奖，各奖励4000元；妇联、统计局、人社局、民政局、公安分局、政法委授予三等奖，各奖励3000元。

以上奖励资金合计31.9万元，主要用于以奖代补，补充卫生和计划生育工作经费。

希望受表彰的部门、单位珍惜荣誉，不断创新思路，强化措施，攻坚克难，争创一流，奋力推进健康金凤建设，为“金凤跨越”做出更大的贡献。

银川市金凤区人民政府

2018年7月9日
