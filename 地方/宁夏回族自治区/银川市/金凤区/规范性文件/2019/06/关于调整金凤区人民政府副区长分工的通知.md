# 关于调整金凤区人民政府副区长分工的通知

各镇人民政府、街道办事处，区政府各部门、单位，各人民团体，银川丝路经济园建设服务办公室，银川阅海湾中央商务区服务中心，阅海实业集团有限公司，宁夏海阅控股运营有限公司，市属各派出机构：

因人事调整及工作需要，经金凤区人民政府研究，现将政府副区长工作分工通知如下：

张 涛同志 负责金凤区政府常务工作，协助区长分管财税、国资监管、金融、投融资平台、项目融资、金融风险防控化解、工业经济、信息化、发展改革、粮食和物资储备、综合执法、商贸会展、经济技术合作、统计、应急管理等方面的工作。

分管发展和改革局（工业和信息化局、粮食和物资储备局）、财政局（金融工作局）、综合执法局、商务和经济技术合作局、统计局、应急管理局、宁夏海阅资本运营控股有限公司、阅海实业集团。

联系区委网络安全和信息化委员会、区委财经委员会、精神文明建设委员会、工商联、国家税务总局银川市金凤区税务局、国家税务总局银川市税务局第一税务分局、银川市消防支队金凤区大队、交警一大队、交警二大队等单位。联系督导丰登镇全面工作。

刘学礼同志 主持丝路经济园建设服务办公室全面工作。

联系阅海湾中央商务区服务中心。

朱巧南同志 协助区长分管法治政府建设、司法、行政审批、政务服务、科技创新等方面的工作。

分管司法局、审批服务管理局、科学技术局。

联系区委全面依法治区委员会、科协等单位。联系督导上海西路街道办事处全面工作。

周生金同志 协助区长分管民政救助、卫生健康、生态环境、爱国卫生、市场监管等方面的工作。

分管民政局、卫生健康局、爱卫办、蓝天办。

联系银川市场监督管理局金凤分局、银川市生态环境局金凤分局、烟草专卖金凤分局、残联。联系督导满城北街街道办事处全面工作。

李 智同志 协助区长分管公安、国家安全、防邪维稳等方面的工作。

主持公安分局全面工作。

联系政法委、区委国家安全委员会、法院、检察院等单位。

白小龙同志协助区长分管政务督查、外事、政务公开、教育、退役军人事务、民兵预备役、创业就业、人才等工作。

分管政府办公室（政府督查室、政府外事办公室、政务公开办公室）、教育局（政府教育督导室）、退役军人事务局、就业创业和人才服务局。

联系区委军民融合发展委员会、区委外事工作委员会、区委统一战线工作领导小组、区委教育工作领导小组、人武部、人才办等单位。联系督导黄河东路街道办事处全面工作。

高 亮同志 协助区长分管住房和城乡建设、市政管理、防震减灾、人民防空、棚户区改造、自然资源、园林绿化、农业农村、扶贫开发、水务、土地增减挂钩、安居工程建设、物业管理服务、征地拆迁、信访等方面的工作。

分管住房城乡建设和交通局（城市管理局、人民防空办公室、地震局、物业办）、自然资源局（林业和草原局、园林管理局）、农业农村和水务局（扶贫开发办公室、农业综合开发办公室）、信访局、国控公司。

联系区委农村工作领导小组、农调队、供销联社、供电、供水、供气、供暖等单位。联系督导良田镇全面工作。

樊莲再同志 协助区长分管社会保障、医疗保障、文化旅游、广播电视、体育等方面的工作。

分管人力资源和社会保障局、文化旅游体育广电局、医疗保障局。

联系工会、团委、妇联、文学艺术界联合会、银行保险等单位。协助高亮同志分管金融扶贫工作。联系督导北京中路街道办事处全面工作。

为增强政府工作的协调配合，政府领导实行无缺位工作制度，张涛同志与白小龙同志对应AB岗，刘学礼同志与高亮同志对应AB岗，朱巧南同志与樊莲再同志对应AB岗，周生金同志与李智同志对应AB岗。

银川市金凤区人民政府办公室

2019年6月4日
