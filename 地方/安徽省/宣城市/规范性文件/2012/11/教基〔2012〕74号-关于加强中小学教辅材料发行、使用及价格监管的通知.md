# 关于加强中小学教辅材料发行、使用及价格监管的通知

教基〔2012〕74号

各县市区教体局、文广新局、物价局、纠风办，市开发区社会发展局、各市直学校，各有关发行单位：

为规范我市中小学教辅材料发行、代购、使用、价格等环节的管理，切实减轻学生过重的课业负担和家长的经济负担，根据省教育厅、省新闻出版局、省物价局、省纠风办《关于印发安徽省中小学教辅材料使用管理实施意见的通知》（皖教基〔2012〕18号）和省物价局、新闻出版局、教育厅《转发国家发展改革委新闻出版总署教育部关于加强中小学教辅材料价格监督的通知》（皖价费〔2012〕114号）精神，结合我市实际，现就加强中小学教辅材料发行、代购、使用、价格等环节监管工作有关事项通知如下：

一、认真做好教辅材料自愿购买和无偿代购服务。中小学校要认真落实“一科一辅”和学生自愿购买原则，在经市评议公告教辅材料目录范围内，各校可为学生实施无偿代购服务。代购教辅必须是市选定的版本。学生根据自愿原则决定是否选用。任何单位和个人不得以任何形式强制或变相强制学校或学生购买任何教辅材料，不得在经市评议公告教辅材料目录范围以外，在学校宣传、推荐和推销任何教辅材料。学校代购，必须做好服务，不得从中牟利。

二、加强教辅材料发行资质管理。中小学教辅材料必须由新闻出版行政主管部门批准的发行企业发行，任何部门、单位和个人未经批准一律不得从事中小学生教辅材料的发行活动。承担经市评议公告教辅材料的发行单位，应具备中小学教材发行资质。宣城新华书店有限公司及所属分公司承担全市中小学教材发行任务，是全市目前唯一具备教材发行资质的文化企业。各学校应向有教材发行资质的单位为学生无偿代购经市评议公告的教辅材料。

三、承担经市评议公告教辅材料的发行单位在征订发行中要提供优质的服务，要确保教辅材料的质量，要根据各校的需求全面做好免费送书到校服务。

四、加强教辅材料价格监管。各发行单位和学校应严格按照经省物价局和省新闻出版局确认并公示后的价格执行，并严格执行代购收费公示制度。

五、建立工作联系机制，加强监督检查。各级教育行政、新闻出版、价格主管、纠风等部门要加强协作，密切配合，加强对教辅材料市场的综合管理，加强教辅材料选用管理和发行教辅材料单位的资质管理，加强中小学教辅材料价格政策和公示制度执行情况的监督检查，对辖区内教辅材料市场不定期进行联合检查，对违反有关法规政策规定的行为，相关部门要依法从严查处，切实保障国家教辅材料发行、使用、价格等有关政策的贯彻落实。
