# 关于印发《2018年宣城市防震减灾科普宣传教育工作方案》的通知

各县市区科技局（地震办）、局各科室中心（地震台）：

为切实做好全市2018年防震减灾科普宣传教育工作，广泛深入普及防震减灾知识，根据省地震局《关于印发〈2018年全省防震减灾科普宣教工作方案〉的通知》（皖震发防〔2018〕50号）要求，现将《2018年宣城市防震减灾科普宣传教育工作方案》印发给你们，请各地各部门结合实际，研究制定年度宣教工作计划，认真抓好落实。

2018年3月20日

2018年宣城市防震减灾科普宣传教育工作方案

2018年全市防震减灾科普宣传教育工作的总体要求是：深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，深入贯彻习近平总书记关于防灾减灾救灾和科普工作的系列重要讲话精神，增强“四个意识”，紧紧围绕“五位一体”总体布局和“四个全面”战略布局，全面贯彻落实全国、全省地震局长会议部署，着力弘扬减灾文化，着力传播科学知识，不断增强全社会的防震减灾意识，提升公众防震避险能力，为全面推进我市新时代防震减灾事业现代化建设营造良好氛围。

一、工作目标

各地各部门要加大对防震减灾科普宣教工作的重视程度和实施力度，健全政府社会合力的防震减灾科普宣教工作机制，在切实提高防震减灾科普宣教能力上综合施策，在全面提升防震减灾科普宣教覆盖面和实效性上精准发力，促进防震减灾传统科普创新与科普信息化相结合、常态科普与应急时段科普相结合、科普人才队伍建设与繁荣防震减灾先进文化相结合。

二、工作理念

（一）依法科普。全面贯彻落实《中华人民共和国防震减灾法》、《安徽省防震减灾条例》等法律法规要求，按照《宣城市防震减灾“十三五”规划》工作部署，全面推进我市防震减灾科普宣教工作。

（二）创新科普。坚持创新理念，要在继承中创新，在创新中提升，大幅提高防震减灾科普宣教的呈现效果和传播水平，扩大防震减灾科普宣教的参与面和受益面，增强防震减灾科普宣教的针对性和实效性，推进防震减灾科普宣教工作机制、内容创作、表达方式、传播手段等全方位创新。

（三）协同科普。坚持防震减灾科普宣教协力、协同发展，市、县地震部门要主动会同宣传、教体、科技、科协、文化、新闻出版、广电等部门，广泛动员学校、企业、基层组织和社会组织等，形成政府社会合力推进防震减灾“大科普”局面。

（四）全面科普。坚持全面发展、均等发展、普惠发展，进一步健全防震减灾科普宣教传播体系，结合乡村振兴战略，针对城市、农村社会公众的不同需求和特点，通过订制农村群众喜闻乐见的防震减灾科普宣传品、创新农村地区防震减灾科普宣教传播方式、推进防震减灾科普教育基地建设向农村延伸等方式，实现防震减灾科普宣教均等覆盖，防震减灾科普成果全民共享。

（五）精准科普。根据不同受众群体和传播媒体的需求，进一步强化地震科技成果转化，丰富防震减灾科普作品，开展针对性的科普宣教。逐步使公众理性认知地震灾害，认识到震前防御对减轻地震灾害风险的重要意义。

三、主要任务

（一）组织汶川地震十周年纪念专题宣传活动。全市地震系统要积极组织筹备各类专题纪念活动，全方位多角度开展防震减灾科普宣教工作。积极组织参加安徽省首届防震减灾知识大赛，市、县地震部门要把大赛作为在校中学生开展地震安全教育、提高防震减灾科学素质的有利契机，通过多种形式灵活组织辖区内学校参赛。各县市区要积极组织汶川地震十周年纪念宣传活动中，充分扩大宣传活动覆盖面及影响力。

（二）积极参加全国地震科普大会系列活动。中国地震局计划于今年7月召开全国地震科普大会，并相继举办全国防震减灾知识大赛、科普讲解大赛、科普作品征集大赛、地震科普展览、科普论文征集等系列活动。市、县地震部门要积极动员全体干部职工和科普人员，组织参加各类活动，展示宣城地震科普工作水平和宣城地震科普人员风采。

（三）深入推进防震减灾知识“六进”活动。2018年，继续以“进农村”为重点，持续推进防震减灾科普知识“六进”，着力提升公务员、学生和教职工、企业员工、城镇劳动者、社区居民、农牧民等群体的主动防灾、科学避灾、有效减灾和地震自防、自救、互救及抢险救灾能力。全年，各县市区组织防震减灾知识“六进”活动不少于6次。

（四）全面推动防震减灾科普宣教信息化。充分发挥“互联网+地震科普”宣教手段，积极利用门户网站、微博、微信等平台，主动、及时、全面、准确地向社会发布政务信息和科普内容。建立完善科普内容的科学性把关和网络舆情的实时监测，实现防震减灾科普的信息汇聚、精准推送和应用服务。全年，市地震局门户网站发布各类信息不少于200条、微博发布各类信息不少于50条、微信发布各类信息不少于50条，通过新媒体平台组织开展具有一定影响力的互动活动不少于1次。各县市区向市地震局网站报送各类信息不少于10条。

（五）不断提升防震减灾科普基础设施服务能力。加强对防震减灾科普基础设施发展的顶层设计与指导，夯实科普工作基础，充分发挥防震减灾科普馆、地震安全示范社区（小区）、防震减灾示范学校、地震安全农村民居示范点、地震台站的科普教育和传播作用。推动青少年活动中心、妇女儿童活动中心、文化场所、科技场馆、博物馆、农村科普基地等增加防震减灾科普教育内容。引导主题公园、自然保护区、地质公园、旅游景区等公共设施增强防震减灾科普功能。

（六）广泛开展重点时段防震减灾科普宣教。各地要充分利用国家防灾减灾日、唐山地震纪念日、科技活动周、科普日、法制宣传日等重点时段，积极开展防震减灾科普宣教工作。充分利用“平安中国”防灾宣导系列公益活动平台和科普“六进”，推进常态下防震减灾科普宣教工作。强化地震应急期地震科普宣教工作，增强地震灾区公众防范余震及次生灾害的意识和能力。全年，市级组织防震减灾科普宣教大型讲座或培训不少于2场，各县市区不少于1场。

（七）切实加强防震减灾科普宣教人才队伍建设。加大对地震系统工作人员、防震减灾科普宣传队队员、中小学校科普教师、防震减灾科普馆讲解员和防震减灾科普志愿者的培训力度。充分调动地震系统内外科技人员、老科技工作者、教育工作者、志愿者等从事防震减灾科普宣教工作的积极性。全年，市级组织各类科普人员培训不少于1次，各县市区组织参加各类科普人员培训不少于1次。

四、工作要求

（一）提高认识，强化组织。各地要切实提高思想认识，加强组织领导，把防震减灾科普宣教工作摆上重要日程，列入年度工作要点，制定切实可行的年度计划，明确负责防震减灾科普宣教工作的机构和人员，制定目标、分解任务、落实责任，加大政策倾斜，切实落实经费，确保各项任务落到实处。

（二）协调联动，形成合力。各地要将防震减灾科普宣教工作纳入当地规划及年度工作计划，纳入政府年度目标责任考核体系和公共财政预算，完善长效机制。会同宣传、民政、教育、科技、科协、文化、新闻出版广电等部门，广泛动员社会组织和社会力量开展形式多样的科普宣教活动。

（三）监督检查，确保落地。市地震局业务科、办公室、监测中心等部门要协同加强对各项科普宣教工作的监督和指导，强化检查、考核和问责，确保防震减灾科普宣教工作部署到位、措施到位、行动到位、落实到位。各地各部门要围绕各项工作任务要求，全面深化落实，并于3月30日前向报送本单位年度科普宣教工作计划。（联系人：郝洁，电话：2288377）
