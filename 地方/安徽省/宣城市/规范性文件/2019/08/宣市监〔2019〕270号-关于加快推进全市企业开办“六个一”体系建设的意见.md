# 关于加快推进全市企业开办“六个一”体系建设的意见

宣城市六部门关于加快推进全市企业开办

“六个一”体系建设的意见

宣市监〔2019〕270号

各县（市、区）市场监管局、公安局、人力资源和社会保障局、数据资源局（政务服务管理局）、税务局，人民银行各县市中心支行：

为贯彻落实省委、省政府创优营商环境工作部署，按照省市场监管局等六部门《关于加快推进全省企业开办“六个一”体系建设的意见》（皖市监注〔2019〕1号）精神，建立健全压缩企业开办时间工作长效运行机制，现就加快推进全市企业开办“六个一”体系建设提出以下意见：

一、工作目标

对标我国和世行营商环境评价指标，着力巩固完善压缩企业开办时间改革成果，进一步“减环节、压材料、降成本、提效率”，持续提升企业开办便利度，提高群众办事获得感。

----全面实施“一窗受理”。按照一个窗口“能办照、能刻章、能领票”的标准要求，全面建立实体大厅企业开办综合服务窗口，物理整合企业开办各环节、各事项，实现“一窗受理、并行办理、统一发证”。

----全面实行“一网通办”。依托市政务服务网，搭建覆盖全市范围的企业开办网上服务大厅，打造“企业开办一件事”专栏，线上整合企业开办各环节、各业务系统，实现“一次登录、一网办理、零见面审批”。

----全面推行“一次采集”。优化再造企业开办流程，整合精简信息采集事项，对企业开办各环节所需信息通过线上“一网”或线下“一窗”进行“一次采集”，部门间通过信息共享，实现结果互认。

----全面整合“一套材料”。统一全市企业开办提交材料规范，整合各环节、各事项申请表单，取消不必要的采集事项和证明材料，实现“一表填报、一套材料”，将企业开办所需材料压减到6份以内。

----全面落实“一档管理”。依托全省一体的企业开办电子档案管理系统，实现企业开办材料信息统一管理、归集存储，开通网上查询、下载等功能，实现跨部门、跨层级、跨地区间共享共用。

----全面实现“一日办结”。常态化将企业开办压减为企业设立登记、公章刻制、发票申领3个环节，时间压缩至1个工作日内。

二、具体措施

（一）建成实体大厅“一窗式”服务窗口。2019年9月底前，各县（市、区）要依托政务服务中心，建成企业开办“一窗式”综合服务窗口，市场监管、税务、公安等部门集中进驻。在办公场地允许的情况下，将公章刻制服务机构、税务设备服务商等统一整合到政务服务中心“一窗式”综合窗口办理。各地要在政务服务中心设立网上办理自助服务区，建立导办窗口，安排专职人员，引导、帮助申请人通过网上办事大厅办理企业开办事项。

（二）优化互联网“一站式”服务大厅。2019年9月底前，依托市政务服务网建成能够覆盖所有县（市、区）使用的企业开办互联网“一站式”服务大厅，实现企业开办关联事项集成服务、并联办理。将电子税务局、社保登记、公章刻制、银行开户纳入“一站式”服务大厅办理，实现企业办理设立登记时，即可同时填报发票申领、企业参保、刻制公章等信息。通过网上大厅公示商业银行服务网点信息，为申请人提供银行开户在线选择、预约服务。10月1日起在全市实施企业开办事项全程网办“零见面”审批改革。

（三）强力推进企业开办“减环节、压材料、降成本、提效率”。

1.减环节。全面推行企业名称自主申报，强化企业社保登记统一社会信用代码管理，将企业名称自主申报、设立登记、社保登记环节进行整合，实行1个环节、1次办理。优化公章刻制流程，企业可以通过窗口或网上在线选取公章刻制服务机构、在线支付相关费用。对于2019年5月1日以后成立的企业、农民专业合作社、个体工商户首次领取发票的，税务部门不再进行信息补采集和现场实名验证。将税种认定、一般纳税人登记（依申请）、发票申领等业务整合为1个环节办理，提供税控盘现场安装服务或网上预约服务。企业只进行初次申领发票操作的，无需提供银行开户信息。落实企业银行账户开户许可改备案制度，进一步简化开户申请材料，优化开户流程，压缩企业银行开户时间。

2.压材料。建立健全企业开办事项“一套材料、一次填报、一档管理、多方使用”机制。全面推行企业开办申请“一表”填报制度，以企业登记申请表为主表，将其他涉及企业开办需采集的信息整合为附表，申请人一次填报，无需重复提交材料。不得将后续监管性要求、服务性环节前移到企业开办环节，严控搭车进行信息采集。凡是市场监管部门已收取并经认证的材料，后续开办流程中应通过部门间共享方式获取，相关部门不得要求申请人重复提交。申请人选择分段办理的，相关部门应当通过共享方式获取材料，不得要求申请人再次提交前期办理材料和信息。按照上级部门的部署要求，推行电子营业执照在公章刻制、发票申领、银行开户场景下的应用，各部门通过电子证照库共享相关信息，避免申请人重复提交证照材料。通过省电子档案管理系统开放的端口和权限，相关部门可以根据需要直接进行查询、下载使用。

3.降成本。鼓励各地通过购买服务的方式，对公章刻制系统运维、升级改造予以经费保障，对一次性办理企业开办事项的企业，提供免费刻章服务和营业执照、税务发票、公章等免费寄递服务。鼓励各地通过购买中介服务或在窗口配备专职人员，全程免费为企业提供导办帮办服务。严禁指定公章刻制企业，纠正和制止垄断经营、强制换章、不合理收费等现象，通过市场有序竞争，有效降低公章刻制成本。严格落实市场准入负面清单管理规定，严禁违法设定或变相增加工商登记前置审批事项，统筹推进“证照分离”“多证合一”改革，稳步扩大“证照联办”改革范围。

4.提效率。持续提升企业开办网上大厅服务功能，不断优化企业登记全程电子化系统，推行企业标准化登记和智能化审批，鼓励各地开展“同城通办”“审核合一”改革试点，继续扩大银行代办、全程帮办等服务，建立预约办理、容缺审批等机制。鼓励各地合理调配窗口人员排班，逐步推行工作日中午“不打烊”服务。积极推行公章刻制、税控盘安装、企业银行开户立等即办、立等可取、当场办结等服务。打通信息共享通道，提高数据传输质量，2019年年底前，实现市场监管、税务、公安、人力资源社会保障等部门间企业开办信息无缝对接、实时共享。

三、保障措施

（一）加强组织领导。建立全市企业开办“六个一”工作体系，是有效压缩企业开办时间、提升企业开办便利化的制度性保障，是推进长三角区域一体化发展和创优营商环境的重要举措。各地、各有关部门要强化思想认识，提高政治站位，进一步建立健全组织领导和部门协同机制，主动担当作为，狠抓工作落实，高质量高效率推进改革工作。

（二）压实工作责任。在地方党委、政府的统一领导下，各地市场监管部门要发挥牵头抓总作用，会同相关部门确定本地区的施工表、路线图和责任链。各级公安、税务、人力资源社会保障、数据资源（政务服务管理）、人民银行等部门要按照职责分工，细化方案、倒排工期、责任到人。对各地、各相关部门协同推进改革工作情况实施目标考核，纳入绩效管理，切实打通政策落地“最后一公里”。

（三）强化基础保障。各地要针对日益增长的涉企服务需求，建立衔接有序、运转顺畅、保障有力的工作机制，统筹协调解决人、财、物、网络技术等保障问题。要严格落实省政府的部署要求，按照存量企业数与窗口人员数1000:1的比例，配齐配强企业开办窗口人员力量。要进一步加强队伍建设，转变服务作风，提升业务能力，不断提高企业、群众办事的满意度和获得感。
