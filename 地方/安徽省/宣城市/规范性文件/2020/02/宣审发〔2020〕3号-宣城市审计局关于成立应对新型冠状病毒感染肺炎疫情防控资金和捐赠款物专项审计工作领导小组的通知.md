# 宣城市审计局关于成立应对新型冠状病毒感染肺炎疫情防控资金和捐赠款物专项审计工作领导小组的通知

各县市（区）审计局，局机关各科室（中心）：

为全面加强应对新型冠状病毒感染肺炎疫情防控资金和捐赠款物专项审计工作的领导，根据《审计署关于做好新型冠状病毒感染肺炎疫情防控财政资金和捐赠款物审计监督工作的通知》（审财发〔2020〕3号）要求，市局成立应对新型冠状病毒感染肺炎疫情防控财政资金和捐赠款物专项审计工作领导小组。现将有关事项通知如下:

一、成立专项审计工作领导小组

组 长：黄 煌 党组书记、局长

副组长：章 捷 党组成员、副局长

丁宏林 党组成员、副局长

肖远会 总审计师

李诗银 党组成员、市经济责任审计局局长

吴明华 党组成员、副局长

成 员：企业与社会保障审计科、办公室、综合法规科、电子数据审计科、财政审计一科、财政审计二科、金融与外资审计科主要负责同志。

领导小组在局党组的领导下，根据党中央、国务院、省委、省政府及市委、市政府，上级审计机关关于防控疫情工作的部署要求以及局党组具体工作安排，研究应对疫情专项审计相关重大事项，指导和协调解决专项审计工作中的重大问题等。

二、成立工作机构

领导小组下设应对疫情专项审计工作领导小组办公室，作为领导小组的办事机构，领导小组办公室设在企业与社会保障审计科，主任由肖远会总审计师兼任。

办公室承担领导小组的日常工作，主要履行以下职责：统筹全市应对疫情专项审计工作，起草应对疫情专项审计工作方案，组织实施项目审计；具体落实领导小组议定事项，研究提出完成专项审计任务的有关工作建议；指导各审计组开展审计；对审计项目实施统筹管理，起草上报审计信息、工作动态、汇总报告，以及公告稿等材料；承办领导小组交办的其他事项等。
