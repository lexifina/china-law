# 关于印发《铜陵市郊区防洪工程设施安全隐患集中排查治理专项行动方案》的通知

乡、镇人民政府、各办事处：

根据省应急管理厅《关于贯彻落实习近平总书记重要指示精神坚决防范遏制重特大事故的紧急通知》（皖安〔2019〕2号）要求，坚决防范遏制重特大事故，我局制定了《铜陵市郊区防洪工程设施安全隐患集中排查治理专项行动方案》，现印发给你们。请你们按照要求，扎实开展隐患排查治理专项行动，有效防范化解重大安全风险，确保人民群众生命和财产安全。

2019年4月3日

为认真贯彻落实习近平总书记关于江苏响水天嘉宜化工有限公司“3.21”爆炸事故重要指示精神，坚决防范遏制重特大事故，根据省市文件要求，结合我区实际，特制定本实施方案。

一、 指导思想

深入贯彻习近平总书记关于安全生产重要思想，全面落实党中央国务院及省委省政府领导重要指示批示精神，坚持人民利益至上，坚决守住“发展绝不能以牺牲安全为代价”红线，切实做好防洪工程设施安全隐患的排查，最大限度减小汛期带来的灾害损失，确保人民生命财产安全。

二、 工作任务

本次防洪工程设施安全隐患集中排查治理专项行动，重点检查水闸、泵站、水库大坝、泄水和穿堤建筑物、启闭设备、软硬结合部等水利设施重点部位及水利在建工程。任务主要包括排查整治、跟踪督办、总结提高三个方面：

（一）排查整治。按照属地管理原则，各乡镇办需对水闸、泵站、水库大坝、泄水和穿堤建筑物、启闭设备、软硬结合部等水利设施重点部位进行全面排查梳理，对发现的重大安全隐患整改情况要进行逐一确认，制定并落实专项安全防范措施，确保整改到位。

（二）跟踪督办。区水利局对辖区内防洪工程设施存在安全隐患集中排查治理行动工作进行跟踪督办，积极构建安全风险分级管控和隐患排查治理双重预防性工作机制，确保隐患整治到位，专项行动取得成效。

（三）总结提高。各乡镇办要对专项行动跟踪开展情况进行全面总结，包括取得的成效与经验、问题与不足、意见与建议，进一步强化措施，加快推进最严格的安全生产长效机制。

三、

进度安排

（一）全面排查阶段（4月2日-4月10日）。各乡镇办接到专项行动通知后，组织对水闸、泵站、水库大坝、泄水和穿堤建筑物、启闭设备、软硬结合部等水利设施重点部位及水利在建工程进行全覆盖排查梳理，深挖大排查大清理行动工作存在的问题，并将隐患清单报送区水利局。

（二）落实整治阶段（4月11日-4月20日）。各乡镇办对排查存在安全隐患的设施进行严格落实整治。结合实际，针对存在重大隐患的工程设施和薄弱环节要制定详细和周密的整改方案，把检查和整治工作落实到工程设施的每一个环节、岗位和人员。

（三）总结阶段（4月21日-4月30日）。各乡镇办要认真总结集中排查治理专项行动工作经验做法，继续抓好隐患排查、专项治理、监管执法、宣传教育、应急保障工作，超前做好汛期安全防范相关工作，采取有力举措巩固专项行动工作成果。

四、工作要求

（一）高度重视，切实强化水利安全生产责任制落实。

各乡镇办要高度重视，精心组织，时刻紧绷安全生产这根弦，进一步强化安全生产“红线意识”和“底线思维”，克服麻痹思想，杜绝侥幸心理，坚决防止由于认不清、想不到、管不到导致风险、隐患蜕变成生产安全事故，要对本辖区内的在建水利工程安全生产隐患排查负起组织指导责任，也要对本级所属项目安全隐患排查负起直接监管责任。

（二）落实安全监管责任，依法依纪严肃问责。

各乡镇办要把本次安全隐患排查治理专项行动作为促进安全生产的重要举措，切实加强领导，认真落实行业主管部门监管责任，对组织部署不周密、敷衍了事、不负责任、工作措施不得力、进展迟缓和因工作责任不落实、隐患排查不到位、突出问题整改不力，导致辖区内、行业内发生安全责任事故的，将坚决依法依纪严肃问责。
