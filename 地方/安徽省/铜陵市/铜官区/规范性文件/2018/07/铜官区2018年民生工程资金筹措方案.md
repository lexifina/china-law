# 铜官区2018年民生工程资金筹措方案

文件解读链接： http://www.tl.gov.cn/openness/web/display.aspx?id=423937

2018年，区委、区政府决定实施25项民生工程，为保障各项民生工程顺利实施，结合我区实际，特制定本方案。

一、贫困残疾人康复。贫困精神残疾人服药救助省任务数所需资金，市辖区由市承担，超出任务数所需资金由市财政、市残疾人保障金按6:4分担。

残疾儿童抢救性康复训练救助省任务数所需资金由省与市按8:2分担，超出任务数所需资金由市财政、市残疾人保障金按6:4分担；其他项目所需资金由上级财政承担。

精神残疾人患者免费服药所需资金由市、区按5:5分担，其中区承担部分涉及西湖镇、东郊办（以下简称“镇办”）的由区直与其按5:5分担。

二、城乡困难群体法律援助。所需资金扣除上级补助后，由市、区按5:5分担，其中区承担部分涉及镇办的由区直与其按5:5分担。

三、农村环境“三大革命”。改厕按0.2万元/户的投资标准实施，扣除上级财政补助后，市与区1:2分担；

农村乡镇污水处理所需资金扣除上级财政补助后，市与区1:2分担；

农村垃圾中非正规垃圾堆放点整治，市财政按其工程投资的15％进行补助；对市级批准开展农村生活垃圾分类试点工作区所购置的垃圾分类设备，市、区按设备购置资金50％进行补助。上述项目所需资金区承担部分涉及镇办的由区直与其按5:5分担。

四、政策性农业保险。所需资金扣除上级补助和种（养）户承担资金外，由市、区按5:5分担，其中区承担部分涉及镇办的由区直与其按5:5分担。

五、技工大省技能培训工程。企业新录用人员技能培训、退役士兵培训所需资金扣除上级补助后，从市、区就业专项资金中安排。

六、就业扶持工程。所需资金扣除上级补助后，从市、区就业补助资金中安排。

七、智慧医疗与家庭医生签约服务。签约基本项目服务费按签约人数年人均不低于60元安排，其中:基本公共卫生服务项目经费承担不低于50元/年·人，基本医保基金承担不低于10元/年·人。基本公共卫生服务项目资金扣除上级补助后，市与区按8:2分担，其中区承担部分涉及镇办的由区直与其按5:5分担。

八、困难人员救助工程。特困人员供养农村五保供养及运行维护所需资金扣除上级补助后由区承担；

散居孤儿基本生活费保障所需资金扣除上级补助后，由区承担；集中供养孤儿基本生活费保障所需资金扣除上级补助后，由市财政承担。

生活无着人员社会救助所需资金扣除上级补助后，由市、区分别承担；

困难残疾人生活补贴所需资金扣除上级补助后，由市、区按5:5分担；重度残疾人护理补贴所需资金由市、区按5:5分担。

城乡医疗救助市、区按上年度省级财政补助资金总量的20%、10%年安排医疗救助资金；超出部分由市、区按5:5分担。上述项目所需资金区承担部分涉及镇办的由区直与其按5:5分担。

九、城乡居民基本医疗保险。所需资金扣除上级补助和个人缴费后，由市、区按5:5分担，其中区承担部分涉及镇办的由区直与其按5:5分担。

十、城乡居民基本养老保险。所需资金扣除上级补助和个人缴费后，由市、区按5:5分担，其中区承担部分涉及镇办的由区直与其按5:5分担。

十一、社会养老服务体系建设。社会办养老机构床位所需资金扣除上级补助后，由市、区按5:5分担；养老托老服务机构运营补贴所需资金扣除上级补助后，由市与区按3:7分担；

居家养老所需资金扣除上级补助后，市、区按6:4分担；社区居家养老服务“三级”中心建设扣除上级补助后，市、区按5:5分担。

老年人日间照料中心所需资金扣除上级补助后，由市、区按5:5分担；

高龄津贴所需资金扣除上级补助后，由市、区按3:7分担。上述项目所需资金区承担部分涉及镇办的由区直与其按5:5分担。

十二、妇幼健康、计生特扶和职业病防治。免费婚前医学检查所需资金扣除上级补助后，由市、区按5:5分担；儿童计划免疫接种所需资金由上级财政承担。

计划生育家庭特别扶助所需资金扣除上级补助后，由市、区按5:5分担。上述项目所需资金区承担部分涉及镇办的由区直与其按5:5分担。

十三、学前教育促进工程。幼儿资助、公办幼儿园新建、改扩建项目、完善学前教育经费保障机制所需资金扣除上级补助后，由市、区按3:7分担。

十四、义务教育经费保障机制。生均公用经费基准定额所需资金由中央、省、市、区共同分担，中央与地方分担比例为6:4，城市学校在扣除省级以上资金后市、区分担比例为8:2。

向城乡义务教育阶段学生免费提供国家课程教科书并推行部分教科书循环使用制度所需资金由上级财政承担。

城市公办义务教育学校校舍安全保障机制由市建立，所需经费由市统筹安排。

十五、公共文化场馆免费开放。所需资金由中央和市级按5:5分担。

十六、农村文化建设专项补助。所需资金扣除上级补助后，由市、区按5:5分担，其中区承担部分涉及镇办的由区直与其按5:5分担。

十七、秸秆综合利用提升工程。小麦、玉米、油菜20元/亩，水稻按照10元/亩的标准进行奖补，所需资金扣除上级补助后，由市、区按照5:5分担，其中区承担部分涉及镇办的由区直与其按5:5分担。

十八、农产品食品安全工程。食品安全工程所需资金由上级财经承担。

十九、棚户区改造。所需资金除争取中央和省补助外，市财政按3万元/户补助，其余资金通过棚改专债、区财政安排、企业和群众自筹等多渠道筹集。

二十、城市老旧小区整治。所需资金除争取上级补助资金外，由市和区财政按7:3分担。

二十一、民生保险。民生保险所需资金扣除个人缴费后，由市、区按5:5分担；困难老年人意外伤害保险由市、区按5:5分担。上述项目所需资金区承担部分涉及镇办的由区直与其按5:5分担。

二十二、妇幼疾病筛查工程。所需资金由市、区按5:5分担，其中区承担部分涉及镇办的由区直与其按5:5分担。

二十三、环境（大气）污染综合治理工程。所需资金从环保专项等资金中安排。

二十四、公共文化服务提升工程。市文化惠民“四大工程”由市财政承担；区项目由市、区按1:3分担。基层（村、社区）文化管理队伍建设由市、区按5:5分担。上述项目所需资金区承担部分涉及镇办的由区直与其按5:5分担。

二十五、严重精神障碍患者康宁救助。严重精神障碍患者住院所需资金由市、区按5:5分担；严重肇事肇祸精神病人监护补贴所需资金市、区按5:5分担。上述项目所需资金区承担部分涉及镇办的由区直与其按5:5分担。

二十六、民生工程管护资金。扣除上级补助后，由区分项目安排，其中涉及镇办的由区直与其按5:5分担。
