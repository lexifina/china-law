# 铜官区审计机关2023年度审计项目计划

1.重大政策措施落实情况跟踪审计（署定及省定）。

审计目标和重点：以推动中央和省、市、区重大决策部署贯彻落实，促进经济高质量发展为目标，关注政策设计制定、政策统筹、部门协同、配套机制措施建立、主管部门推进措施、具体执行的合理性科学性等情况，做到从政策“最先一公里”到贯彻落实“最后一公里”的全流程、全链条跟踪。

2.铜官区村级集体经济发展情况专项审计调查。

审计目标和重点：以扶持壮大村级集体经济，推动新型农村集体经济高质量发展为目标，重点关注强农惠农政策落实、农村集体“三资”管理情况、项目扶持资金使用绩效、“一村一策”项目实施建设等情况。

二、财政审计

1.2022年度区直预算执行情况和决算草案审计。

审计目标和重点：以促进财政资金规范高效运行管理，促进中央及省重大决策部署贯彻落实，推动现代财政制度建设和财政治理现代化为目标，重点审计财政收支真实合规情况、财政预算分配规范情况、财政资金安全绩效情况、地方政府债务和隐性债务风险管控情况、决算草案的真实合规情况等。

2.2022年度区直部门（单位）预算执行审计。

审计目标和重点：以促进规范部门预算管理，严肃财经纪律，提高财政资金使用绩效为目标，重点关注部门预算编制执行、决算草案编制、预算绩效、财政存量资金、国有资产以及政府采购等管理、落实政府过紧日子要求、“三公”经费和会议费管理使用，以及遵守中央八项规定精神等情况。

3.铜官区社区卫生服务补助资金专项审计调查。

审计目标和重点：以推动基层医疗保障和公共卫生服务项目任务落实，促进全区基本公共卫生服务水平提升为目标，重点关注项目资金分配管理使用、基本公共卫生政策落实情况、各项服务项目实施及绩效情况等。

4.铜官区教育费附加资金专项审计调查。

审计目标和重点：以规范教育费附加专项资金使用管理，提高专项资金的使用效益，促进优化教育资源配置及教育均衡发展为目标，重点关注教育费附加项目资金的分配管理、督查机制以及项目绩效评价等方面的落实情况。

三、经济责任审计

1.根据中办、国办《党政主要领导干部和国有企事业单位主要领导人员经济责任审计规定》（中办发〔2019〕45号）有关要求和区委组织部意见建议，对部门单位主要领导干部履行经济责任情况进行审计。另根据《铜官区领导干部离任经济责任事项交接办法（试行）》（铜官经审〔2018〕1号），对部门（单位）原主要负责人开展离任交接。

审计目标和重点：以强化干部管理监督，促进领导干部履职尽责、担当作为为目标，重点关注贯彻执行中央重大经济方针政策和决策部署，本单位重要发展规划和政策措施制定、执行及效果，重大经济事项决策、执行及效果，财政财务管理和经济风险防范、落实党风廉政建设责任和遵守廉洁从政规定等情况。

四、领导干部自然资源资产离任（任中）审计

1、根据《领导干部自然资源资产离任审计规定（试行）》，及区委组织部意见建议，安排领导干部自然资源资产离任（任中）审计项目。

审计目标和重点：以贯彻落实绿色发展理念、促进领导干部认真履行自然资源资产管理和生态环境保护责任为目标，重点关注领导干部贯彻执行中央生态文明建设方针政策、资源环境约束性指标完成、资源环境监督管理责任履行、资源环境相关资金征管用和项目建设运行等情况。

五、公共投资审计

1、安排区级公共投资审计项目10个。高新区管委会、各镇办社区、区政府各部门、各有关单位公共投资审计项目内审计划，由各单位根据实际情况确定。

政府性投资建设项目审计。根据《中华人民共和国审计法》《铜官区政府投资审计目标和重点：以促进政策措施贯彻落实、完善项目建设管理制度为目标，重点关注项目基本建设程序履行、招标投标、资金管理使用、工程建设管理、工程质量等情况，揭露违纪违法问题，促进反腐倡廉建设，规范工程项目建设管理，提高财政资金使用绩效。
