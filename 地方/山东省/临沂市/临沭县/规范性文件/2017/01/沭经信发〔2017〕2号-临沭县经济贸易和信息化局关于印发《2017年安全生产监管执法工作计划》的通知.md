# 临沭县经济贸易和信息化局关于印发《2017年安全生产监管执法工作计划》的通知

沭经信发〔2017〕2号

局各科室、相关人员：

《2017年安全生产监管执法工作计划》已经局领导研究同意，现印发给你们，请按照分工抓好监督执法检查，认真贯彻执行。

临沭县经济贸易和信息化局

2017年1月5日

2017年安全生产监管执法工作计划

为进一步做好经信系统2017年安全生产监管执法工作，牢固树立“以人为本、安全发展”的理念，认真落实“党政同责、一岗双责、失职追责”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”责任制要求，切实落实安全生产主体责任，规范安全生产执法行为，结合中央、市、县关于2017年安全生产工作的总体安排部署，编制本计划。

一、指导思想

坚持“安全第一，预防为主，综合治理”的方针，牢固树立安全发展理念，以落实企业安全生产主体责任为目标，以开展安全生产各项专项整治行动为载体，进一步提升部门监管能力，强化行业监管，把安全生产贯穿于经信系统工作各个方面、各个环节，全面落实“一岗双责”要求，不断强化责任落实和措施落实，强化安全生产日常监察执法，积极消除各类事故隐患，有效遏制和降低事故总量、坚决防控重特大事故，推动经信系统安全生产形势持续稳定好转。

二、基本原则

（一）坚持依法、文明、廉洁执法的原则；

（二）坚持统筹兼顾和重点突出的原则；

（三）坚持权责统一和公平公开的原则；

（四）坚持分级管理和属地管理相结合的原则；

（五）坚持量力而行和从实际出发的原则。

三、工作目标

严格按照新《安全生产法》要求，深入推进系统各企业全面落实安全生产主体责任，企业各项安全生产管理制度完善，管理措施到人到岗。坚决杜绝重特大事故，切实遏制死亡事故，努力降低一般事故。坚持依法行政、严格执法，强力整治经信系统重点行业和重点企业的安全生产非法违法行为。积极推进安全生产标准化建设和专项整治行动，及时消除隐患，强化源头管理。加强对各镇街的安全生产执法进行检查指导和督查抽查，确保安全生产执法检查工作取得明显成效。

四、检查范围

检查范围为经信系统负责行业监管和业务指导的工业企业、在建工业项目、电力、石油天然气和民爆企业等生产经营单位。

五、检查计划

（一）电力企业

贯彻落实《电力法》及相关条例规定，加强对电力系统的安全管理，重点检查电力设备设施安全管理及运行情况。每季度至少开展日常检查一次，全年检查不少于4次。

责任领导：车加沂

责任科室：电力科

（二）成品油销售企业

督查成品油市场准入资质情况，重点是成品油经营、危化品经营及消防建设等证件完备情况；制度建设情况，安全、消防、应急管理等制度建设情况；安全运营情况，参照《成品油市场督导检查指导手册》检查内容，重点是油库、加油站的安全距离是否满足国家强制标准的要求，安全消防器材和设施配备和使用情况，加油站、油库作业人员执行卸油相关操作规程情况，定期开展应急救援培训和演习情况，散装汽油购销实名登记情况。每季度至少开展日常检查一次，全年检查不少于4次。

责任领导：刘彦彪

责任科室：市场科

（三）民爆企业

加强对金鹰民爆公司老炸药库检查巡视，及时掌握其拆除工作进度，严防企业无照经营行为，确保民用爆炸品销售行业安全稳定。全年检查不少于8次。

责任领导：刘彦彪

责任科室：安全科

（四）长输油气管道

排查整治油气输送管道违法占压、安全距离不足、违规交叉穿越等隐患；排查整治未经审批私自在管道保护范围内特定施工作业，私自穿跨越管道施工作业，私自使用管道专用伴行道路、管道水工防护设施、管道专用隧道等管道附属设施，全年检查不少于8次。

责任领导：刘彦彪

责任科室：安全科

（五）工业建设项目

重点检查技术改造建设项目是否按照“三同时”要求落实安全管理和防护措施，对重点监管的技术改造项目未经安全审查合格，不予办理核准和备案手续。

责任领导：张贵华

责任科室：技改科

（六）其他方面

一是对涉及本系统范围内的安全生产举报投诉查处率达到100%。

责任领导：刘彦彪、车加沂、张贵华

责任科室：电力科、市场科、安全科、信访科

二是陪同迎接上级检查率100%

责任领导：李根深

责任科室：涉及科室

五、工作要求

（一）高度重视，加强领导。树立执法检查和安全管理一盘棋思想，统一思想，深化对安全生产执法监管工作重要性和必要性的认识，各级各部门要认真履行安全生产管理“一岗双责”职责，做到各负其责、到人到岗。

（二）细化措施，严格执法。检查时要认真做好检查记录，完善检查表格，检查结束后要认真总结，对查出的重大隐患、重要问题要及时梳理，加大督促整改力度。严格行政处罚案件审查审批，对每一起行政处罚案件，从法律依据、情节认定、证据收集、处罚标准、程序流程以及文书适用等环节进行仔细审核把关，确保依法行政、规范执法。
