# 关于印发《临沭县交通运输局2017年工作要点》的通知

沭交政字〔2017〕1号

各科室、局属各单位：

《临沭县交通运输局2017年工作要点》已经局党组研究通过，现予以印发，请认真贯彻执行。

临沭县交通运输局

2017年2月20日

2017年是全面深化改革的重要一年，我们将深入贯彻落实党的十八届六中全会精神，紧紧围绕“构建一个体系，夯实两个基础，突出三个重点，做好六项工作”的总体思路，全力推进全县交通运输工作创新发展，打造沂蒙幸福交通品牌。

一、构建一个体系

不断加大综合交通基础设施建设投入，建设县乡村道干支相连、畅通高效的农村交通路网，实现“货运无缝化衔接，客运零距离换乘”，推动水上旅游运输、铁路物流协调发展，积极构建高效能的综合交通运输体系。

（一）加快构筑综合交通基础设施网络。根据《临沭县交通“十三五”发展规划》，按照适度超前的原则，抓好重点基础设施建设，优化基础设施布局，促进基础设施有效衔接，完善城市公共交通体系，加快交通枢纽建设。

（二）加快提高综合运输服务水平。充分发挥交通运输的先行引导作用，大力调整运输结构，进一步优化公共交通网络建设，加强物流园区建设，积极发展资源节约型的运输方式，推广应用节能型交通工具，健全农村物流网络，增强交通运输可持续发展能力。

（三）加快构建立体大交通格局。加强公路、铁路、水运、旅游的协调衔接，按照县政府部署，推进沭河古道等水上旅游开发建设，积极配合加快铁路物流园区建设，开发建设翔龙航空小镇，逐步构建立体大交通格局。

二、夯实两个基础

（一）夯实县乡道路工程建设。计划投资1.44亿元对18.3公里的青石路北段、23.1公里的沭赣路、11.7公里的沭牛路北段进行改造建设，进一步提升县乡公路的通达水平和服务能力。全面完成农村公路的安全生命防护工程，投资380万元，对店头镇月庄桥、石门镇吴棠桥、大兴镇大高埠桥、玉山镇河湾桥进行危桥改造，进一步消除安全隐患。

（二）夯实交通运输行业管理。加强道路、水路运输行业监管力度，积极推动道路运输行业诚信体系建设，全面提升行业服务水平。破解交管所发展面临的难题，充分发挥驻地管理工作职能，不断探索乡镇交管所发展新路子，全面推进交管所规范化建设。认真履行交通运输监察职责，加强对公交和出租车的管理，规范客货运输市场秩序。

三、突出三个重点

（一）突出全省城乡公交一体化示范县建设。计划投资2000万元，新增50亩用地，建设调度中心、加气、加油、充电、车辆保养等附属设施为一体的公交站场。通过市场化运作的方式，投资400万元，建设临沭至唐岭、曹庄、青云、西新庄、石河、吉利埠、前庄318处站点亭牌。在青云镇试点镇村公交的基础上，开通曹庄镇村公交，切实解决农村群众“最后一公里”出行的问题。

（二）突出全省村级公路网化示范县建设。根据全省第三批村级公路网化示范县建设要求，结合交通精准扶贫和优美乡村路建设，加大村级公路建设力度，实现行政村主要街道与邻近公路通达、行政村之间通达、每个行政村建有1-2条主要街道的目标。

（三）突出智慧交通建设。继续创新举措，加大科技投入力度，加强信息化建设，开发建设公路车辆超限超载不停车预检系统、路政养护巡查系统，进一步优化智能公交系统，完善交通运输指挥中心功能，实现对交通运输工作的全方位覆盖，以智能化提升交通运输工作的管理和服务水平。

四、做好六项工作

（一）做好农村公路管护工作。继续落实“县道县管、乡道乡管、村道村管”的分级管理体制，进一步加大路政巡查力度，严厉查处毁路案件，维护农村公路路产路权。继续深入开展农村公路环境综合整治活动，加大路肩、边坡等附属设施整修力度，及时进行绿化补植修剪，努力打造农村公路的畅安舒美。

（二）做好行业安全和稳定工作。加强交通运输行业安全监管，继续做好安全生产岗位实名制和企业安全生产标准化创建工作，深入开展平安行业创建活动，不断提升基层安全生产标准化建设水平。进一步完善社会矛盾预警和监督考核机制，加大信访维稳工作力度，确保行业稳定。

（三）做好物流产业招商工作。继续走出去引进来，加大招商引资力度，推动县内物流项目升级，促进物流业发展。跟进重点物流项目，推进汇商工谷物流项目的建设工作。重点围绕铁路物流园区，加强信息捕捉力度，广泛获取有效招商信息，力争产业招商工作有新突破。

（四）做好干部队伍建设工作。继续加强干部职工的思想教育，提高交通队伍的综合素质。总结“三严三实”、“两学一做”等党的群众路线教育实践活动经验，坚持长期接受教育、保持群众本色，不断把教育实践活动引向深入。深化行业文明创建工作，继续保持省级文明单位荣誉称号。继续加强廉政建设和作风转变，切实提高服务质量和工作效率，创建学习型、创新型、实干型机关。

（五）做好民生实事和帮扶工作。继续加大对联系镇村的帮扶和支持力度，积极争取项目和资金。同时，着力解决好群众关注度高、关系密切的民生实事问题，全面提升交通运输工作群众满意度。

（六）做好交通扶贫工作。严格按照各级关于精准扶贫工作的政策和要求，创新和加强我县交通精准扶贫工作。根据调查摸底情况，加快贫困村道路改造建设，逐步在满足客运条件的贫困村，开通公交线路，加快贫困群众脱贫致富步伐。
