# 关于印发《临沭县交通运输局培育和践行社会主义核心价值观实践活动实施方案》的通知

沭交政字〔2017〕6号

各科室、局属各单位：

经局党组研究，决定印发《临沭县交通运输局培育和践行社会主义核心价值观实践活动实施方案》，请结合各自工作实际认真贯彻执行。

临沭县交通运输局

2017年2月17日

为认真贯彻落实中办《关于培育和践行社会主义核心价值观的意见》和中宣部、中央文明办《培育和践行社会主义核心价值观行动方案》以及市、县关于开展培育和践行社会主义核心价值观工作要求，现结合交通运输工作行业特色，特制定本方案。

一、指导思想

深入贯彻落实党的十八大、十八届三中、四中、五中、六中全会精神和习近平总书记系列重要讲话精神，紧紧围绕社会主义核心价值观24字基本内容，组织引导全县交通运输行业广泛开展形式多样的培育和践行社会主义核心价值观实践活动，深入推进交通运输行业核心价值体系建设，推动社会主义核心价值观内化于心、外化于行，为加快推进综合交通、智慧交通、绿色交通、平安交通、产业交通“五个交通”建设提供强有力的保障，为我县交通运输事业又快又好发展奠定扎实的基础。

二、主要任务

全行业要把“三个倡导”24个字融入到践行交通运输行业核心价值体系的全过程，并以新时期“四讲四有”合格党员为统领，以知促行，切实将社会主义核心价值观贯穿于交通运输行业，引导全体干部职工深入理解、准确把握、自觉践行，提升精神境界，培育行业文明风格。

（一）深入开展宣传教育。继续深入开展“三严三实”、“两学一做”等党员思想教育，做好干部职工诚信教育、孝敬教育、勤劳节俭教育，打牢共同思想品德基础。进一步加深对社会主义核心价值观和交通运输行业核心价值体系的认识，把握内容实质，领会践行要求，结合工作实际，加大核心价值观的宣传力度。通过制作宣传标语、宣传画报以及媒体广告等方式，积极宣传社会主义核心价值观和交通运输行业价值体系，增强传播力和感染力。特别是各个公共服务窗口单位要在醒目位置做好核心价值观公益宣传，大力宣传“三个倡导”24个字。

（二）积极开展主题教育。把交通精神和职业道德作为践行核心价值观和行业核心价值体系的实践载体，深入开展宣讲解读、道德讲堂、廉政教育、红色革命教育等活动以及专题学习、座谈会、报告会等，深化文明旅游、文明交通、文明餐桌和网络文明行动。广泛开展“节俭养德节约行动”，弘扬中华民族吃苦耐劳、戒奢克俭的优良品德。开展“控烟为你我，文明齐分享”行动，大力培育遵守公德、关爱健康的社会风尚，在全行业形成创建无烟单位、争当文明市民的浓厚氛围。深入推进开展网络文明传播行动，鼓励干部职工综合运用论坛、博客、微博、微信等形式，传播文明理念、净化网络环境。深化“我们的节日”活动，积极参与传统节日、党史国史上重大事件纪念日和重要人物纪念日活动。深入开展学雷锋志愿服务活动。以县交通运输局志愿服务队、团支部志愿服务队为重点，广泛开展“邻里守望”志愿服务活动，深入推进关爱空巢老人、留守儿童、农民工、残疾人等活动。持续抓好“讲文明树新风”公益广告宣传，深化交通运输行业干部职工对社会主义核心价值观和行业核心价值体系的理解、把握，教育引导干部职工在交通运输建设、管理、服务等重点领域树立行业良好社会形象，进一步提升交通运输行业在社会上的影响力和美誉度。

（三）广泛开展学习先进典型活动。将思想道德建设和文明创建融入到交通运输行业管理工作当中，创新思维，丰富载体，倡导修身律己，争做文明表率，引导交通运输系统干部、职工及从业人员主动走进“道德讲堂”，活动开展有声有色。认真组织开展培育典型、宣传典型、学习典型的活动，继续深入开展道德模范评选表彰和“我推荐、我评议身边好人”活动、最美人物、时代楷模、凡人善举等学习宣传，引导广大干部职工崇德向善，积极投身实现“中国梦”的实践行列，推动形成“我为人人、人人为我”的良好社会道德风尚，推进社会主义核心价值观和交通运输行业核心价值体系深入践行。

（四）大力开展文明创建活动。将培育践行社会主义核心价值观和文明县创建工作、文明单位创建、城乡文明牵手共建工作融为一体，大力开展争创“文明服务岗”、“文明客运班线”、“文明乘务员”、“文明公交线路”、“文明出租车”、“文明执法窗口”、“文明执法工作者”等活动。通过开展各项文明创建活动，进一步激发全体干部职工干事创业、创先争优的工作热情，提升行业文明服务水平。

三、有关要求

（一）加强领导，健全机制。各科室、单位要切实加强培育和践行社会主义核心价值观实践活动的组织领导，要结合方案内容，开展特色活动，发挥自身优势特点，明确重点目标任务，建立常态化机制，层层抓落实，确保活动顺利开展。

（二）抓好结合，务求实效。各科室、单位要创新工作思路，精心设计活动载体，不断丰富内容，建立和完善切实可行、具有特色、突显实效的实践教育机制，形成培育和践行社会主义核心价值观教育的长效机制，确保活动收到实效。

（三）加强宣传，营造氛围。各科室、单位要充分利用网站、微信微博、新闻媒体、电子显示屏等多种宣传平台，大力宣传社会主义核心价值观教育的内容和重要性，积极宣传交通行业在教育实践活动取得的重要经验和工作亮点，向社会充分展示培育和践行社会主义核心价值观的良好形象。

（四）加强督查，狠抓落实。各科室、单位要严格按照有关要求完成好此项工作，局考核办公室将对各科室、单位参与、开展工作情况进行督导检查。对思想不重视、措施不得力、活动走过场的单位，将追究其责任，确保工作取得实效。
