# 临沭县住房和城乡建设局关于认真做好2017年春节节后复工安全生产工作的通知

沭住建发〔2017〕3号

局属各单位、机关各科室、各相关企业：

为切实加强春节后建筑、市政施工安全生产工作，增强全县建筑从业人员的安全意识，继续推进隐患排查整治体系和安全预防体系，有效防范建筑安全生产事故，实现2017年度安全生产工作良好开局，现将春节节后复工前有关安全生产工作要求通知如下：

一、高度重视节后安全生产复工检查工作

各建设、监理、施工单位要高度重视春节节后复工前安全生产工作的检查，认真落实企业安全主体责任，建立严格的复工安全检查制度，制定有针对性的安全施工措施，防范事故发生。

1、施工项目部要成立项目部节后复工检查小组，由项目经理、技术负责人、专职安全员组成，负责对本项目的节后安全隐患排查工作。

2、各建筑施工企业要成立节后复工安全检查小组，安全检查小组要由企业分管安全的领导担任组长，对企业下属所有要求复工的项目部进行全覆盖、全方位的详细安全检查，并形成检查的书面文件。

3、项目建设单位和监理单位对施工企业检查存在的问题及整改情况进行复查，要明确是否同意复工的意见。检查合格签字盖章后，向县住建局报送复工报告以备抽查。

二、节后安全生产工作要求

（一）切实做好复工前的安全生产培训教育。针对施工人员春节过后出现的思想松懈、注意力不集中、麻痹心理以及新进工人较多的特点。项目部要组织全部从业人员进行一次节后安全教育，尤其是要加强对新进场人员上岗培训，宣讲安全生产方针政策、安全作业规程规定，强调复工后安全注意事项，并重点培训各项安全生产规章制度、操作规程，确保各类人员了解施工区域存在的危险源、风险点，增强各类人员安全意识和遵章守法的自觉性，坚决杜绝恢复生产过程中发生各类安全事故。

（二）紧扣重点，及时消除安全生产隐患。各企业、各项目部要结合工作安排，针对节后安全工作特点，全面排查隐患，重点是深基坑（沟槽）开挖防护、建筑起重设备安全性能、模板支撑体系的可靠性、脚手架及卸料平台稳定性、洞口及临边安全防护牢固性、施工用电、施工现场消防等危险性较大分部分项工程和现场重大危险源安全措施落实情况。对检查发现存在重大安全隐患的项目，一律不得复工生产；对检查发现的各类一般安全隐患，各单位要跟踪督促项目部整改到位。尤其是起重设备、模板支撑、脚手架不符合规范要求的，一律拆除重新安装搭设。

三、加强监管，严厉打击违法违规行为

为确保春节节后复工安全生产工作措施的落实，县住建局将组织专门人员，加强对节后复工安全检查工作的督查，对未经安全检查擅自施工和不具备安全生产条件擅自复工的项目，依据相关法律法规对相关责任单位、责任人按上限严肃处理；公示和通报复工检查中发现的企业、项目、责任人的安全生产不良记录，运用综合手段打击安全生产违法违规行为。
