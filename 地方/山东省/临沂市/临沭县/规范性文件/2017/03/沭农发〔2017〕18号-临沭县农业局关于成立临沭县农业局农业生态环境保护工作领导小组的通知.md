# 临沭县农业局关于成立临沭县农业局农业生态环境保护工作领导小组的通知

沭农发〔2017〕18号

局直各科室单位：

为深入贯彻落实中央、省、市和县委县政府关于农业生态环境保护工作要求，进一步加强我县农业生态环境保护工作，经研究，确定成立临沭县农业局农业生态环境保护工作领导小组。现将领导小组组成人员名单公布如下：

组 长：徐会社 县农业局党组书记、局长

副组长：刘汉忠 县农业局党组副书记、副局长

王新敏 县农业局党组成员、副局长

高文祥 县农业局副局长

柏继德 县农业局党组成员、副主任科员

胡怀华 县农业局党组成员、农技中心主任

刘建文 县农业局党组成员、农经中心主任

成 员：谢国华 县农业局农业综合执法大队大队长

英 伟 县农业局办公室主任

解学涛 县农业局财务科科长

管其锋 县农业局人事科长

李频道 县农业局土肥站站长

王恒华 县农业局环保站站长

徐劲松 县农业局植保站站长

胡 涛 县农业局农技站站长

王文昇 县农业局能源办主任

县农业局农业生态环境保护工作领导小组负责指导、协调全县农业生态环境保护工作，落实国家、省、市、县确定的相关任务和政策措施，组织开展规划编制、工作督导、重大问题调研、重大项目推进等工作。领导小组下设办公室，刘汉忠兼任办公室主任，王文昇、王恒华任办公室副主任，县农业局能源办、县农业局环保站承担日常工作。

临沭县农业局

2017年3月2日
