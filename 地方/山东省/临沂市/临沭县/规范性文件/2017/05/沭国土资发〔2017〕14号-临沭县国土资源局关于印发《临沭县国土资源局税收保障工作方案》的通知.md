# 临沭县国土资源局关于印发《临沭县国土资源局税收保障工作方案》的通知

沭国土资发〔2017〕14号

各国土所、各科室：

现将《临沭县国土资源局税收保障工作方案》印发给你们，请认真贯彻执行。

临沭县国土资源局

2017年5月19日

临沭县国土资源局税收保障工作方案

为进一步健全完善涉税信息采集使用管理长效机制，认真履行法定税收协助义务，进一步推进税收保障工作，根据《临沂市人民政府关于进一步加强税收保障工作的意见》（临政发〔2015〕16号）和《临沭县人民政府办公室关于印发临沭县税收保障工作方案的通知》（沭政办字〔2017〕17号）等，结合国土工作实际，制定本方案。

一、工作任务

（一）健全工作领导机制。局机关成立税收保障协调推进工作领导小组，局长任领导小组组长，分管局领导为副组长，小组成员包括各科室负责人，领导小组办公室设在不动产登记中心，具体牵头负责信息采集、报送及税收保障日常工作协调、调度；各科室确定涉税信息采集联络员，具体负责涉税信息整理，上报。

（二）强化涉税信息采集。每月（季度、年），相关科室按临沭县涉税（费）信息综合管理平台要求及时整理相关涉税信息，统一上报税收保障协调推进工作领导小组办公室，办公室根据系统要求汇总数据，及时导入管理平台。

二、职责分工

（一）领导小组办公室。负责督促各科室按照规定制式和要求报送涉税信息，整理科室上报信息并及时导入管理平台。

（二）各科室。负责整理科室掌握的涉税信息，按要求采集、上报至领导小组办公室。具体包括：土地利用科整理、上报改制企业土地资产处置信息、国有建设用地使用权收回信息、基准地价、土地分类价格信息；土地利用科及土地收储中心整理、汇总上报全县国有土地使用权出让信息统计表；不动产登记中心整理、上报国有建设用地使用权划拨信息、国有建设用地使用权转让信息、国有土地使用权证发放登记信息；耕保科整理、上报建设用地批准明细；执法大队整理、上报全县查处违法转让(受让)土地信息；土地整理中心整理、上报全县土地开发整理项目建设计划；矿管科整理、上报全县采矿权出让（转让）审批信息。

三、工作要求

（一）强化责任意识。各科室要深刻认识到税收保障工作的意义与重要性，切实把税收保障工作与本科室工作结合起来，确保信息采集不遗漏，信息上报不拖拉，积极营造社会综合治税良好局面。

（二）搞好协调配合。领导小组办公室、各科室按照各自职责，密切配合，确保信息准确、及时上报。

（三）强化督查问责。税收保障工作纳入局机关年度工作考核内容，对成绩突出的科室和个人，予以通报表彰；对信息报送不及时、不准确、不完整影响工作开展的，予以通报批评。

附件：临沭县国土资源局税收保障协调推进工作领导小组名单。
