# 临沭县住房和城乡建设局关于进一步加强建设工程勘察质量监督和施工图审查工作的通知

沭住建发〔2017〕28号

局属各单位、机关各科室，各建设、勘察单位：

为规范全县勘察市场秩序，加强建设工程勘察质量管理，进一步做好施工图审查工作，根据《建设工程勘察设计管理条例》、《山东省勘察设计管理条例》、《山东省建设工程勘察质量管理办法》、《山东省建设工程勘察设计市场动态监管办法》以及临沂市住房和城乡建设局《关于加强建设工程勘察质量管理工作的通知》、《关于开展建设工程勘察质量监督管理工作的通知》、《关于印发<政府购买施工图审查服务工作指南（试行）>的通知》等法规规章和文件规定，结合我县实际，现就进一步加强建设工程勘察质量监督和施工图审查工作有关事宜通知如下：

一、建设工程勘察质量监督工作

县住房和城乡建设局（以下简称县住建局）负责临沭县辖区范围内的新建、改建、扩建工程项目勘察工作的监督管理。

（一）自2017年8月1日起，全县建设工程项目勘察工作必须接受县住建局的监督检查。

监督检查的对象为建设工程详细勘察阶段的勘察工作。

（二）勘察单位承揽勘察业务后，应按有关规定根据工程勘察项目规模选派项目负责人；应根据建设工程批准文件、建设单位委托任务书和有关资料，严格按照国家规范编制该建设工程勘察纲要，并于工程勘察开工前向县住建局提报勘察纲要，申办勘察质量监督。县住建局根据勘察单位外业作业时间和土工试验开工日期安排监督检查，对于符合规定、满足勘察要求的勘察工程，开具《临沂市勘察工程外业监督记录表》，对于不符合规定、不满足勘察要求的勘察工程，在《临沂市勘察工程外业监督记录表》上提出整改意见，勘察单位整改完成后形成书面整改报告，送至县住建局施工科。

（三）申报建设工程勘察质量监督需提交的资料：

1、工程勘察质量监督申报表（见附件）；

2、建设工程勘察纲要；

3、建设工程勘察任务委托书或中标文件；

4、建设工程勘察合同；

5、工程勘察项目技术负责人或项目经理、外业作业人员、土工试验人员、资料整理人员的技术资格证件、上岗证件；

6、聘请勘察监理的，提供现场监理人员名单；没有监理的，提供建设单位现场监督人员名单；

（四）对勘察单位实行动态管理，对其不良行为及时记录，纳入《临沂市勘察设计企业管理考核办法（试行）》进行考核。对“项目技术负责人不在现场”以“勘察设计项目负责人不符合要求”对待，对“设备不合格、土工试验不按规程操作、外业不执行勘察纲要等不良行为”以“勘察企业弄虚作假、提供虚假工程勘察资料”对待。

（五）建设单位向施工图审查机构申请《岩土工程勘察报告》审查时，需提供建设工程勘察质量监督申报表、勘察工程外业监督记录表，否则县住建局不得开具勘察审查和施工图审查委托书，图审机构不得进行施工图审查；审查时，应结合外业作业有关图像资料、室内土工试验数据，进行《岩土工程勘察报告》审查。

（六）工程建设必须坚持“先勘察后设计再施工”的基本原则。对于违反基本原则的建设工程，县住建局不予办理施工图审查手续，并按照相关规定进行处罚。

二、施工图审查工作

县住建局负责受理临沭县辖区内建设单位施工图审查申请工作，委托图审机构审查。

（一）审查程序

1、建设单位通过《临沂市建筑市场综合监管信息化平台》进行建设工程报建完成后，向县住建局施工科提出审查申请。

2、县住建局施工科审核报送材料的完整性，对材料齐全的工程项目出具受理通知书，并采用勘察审查委托书和施工图审查委托书的形式委托图纸审查机构进行审查。超限工程项目由县住建局经市级住建部门上报省住房和城乡建设厅。

3、审查机构按规定对报送图纸进行技术性审查，并对审查合格的建设项目发放施工图审查合格证书。

4、审查机构对审查合格的工程项目，报送县住建局进行项目备案；审查不合格的通知建设单位根据审查意见进行修改，并审查修改结果。

（二）报送资料

1、工程勘察审查

（1）发改委立项文件、土地部门审批文件、规划部门审批文件（单体工程规划）；（复印件）

（2）经过备案的勘察合同及备案表；

（3）岩土工程勘察任务书；

（4）岩土工程勘察报告（资质章、注册章）；

（5）临沂市勘察工程外业监督记录表（监督记录表上有整改意见的，必须整改完成后形成整改报告一并报送）；

2、设计审查

（1）建设工程勘察、施工图审查申请表；

（2）发改委立项文件、土地部门审批文件、建设用地规划许可证、建设工程规划许可证；（复印件）

（3）经过备案的设计合同及备案表；

（4）审查合格的岩土工程勘察报告（详细勘察阶段）；

（5）全套施工图图纸（有资质章、注册章；含计算书并注明计算软件的名称及版本；规划面积与图纸面积相差不得超过3%）；

（6）抗震设防专项审查情况表（医院、学校等公共建筑，减隔震须由甲级资质设计）；

（7）建设工程初步设计审查批复（政府投资的大中型项目）；

（8）超限高层建筑工程抗震设防专项审查批复（建筑物地上高度100米以上、建筑面积8万平方米以上，建筑物外形奇特）；

建设单位将以上材料按顺序装订成册，报送县住建局施工科审核，办理《临沭县建设工程施工图审查受理通知书》、《临沭县建设工程勘察受理通知书》、《临沭县建设工程施工图审查委托书》、《临沭县建设工程勘察审查委托书》。要求提供复印件的，提交材料时，需将原件一同提报，待审完原件后退回，留存复印件。

（三）审查内容

通过政府购买服务，受县住建局委托，施工图审查机构应当对施工图设计文件中涉及公共利益、公众安全、工程建设强制性标准的内容进行审查。

具体包括以下内容：

1、是否符合工程建设强制性标准（是指直接涉及工程质量、安全、卫生及环境保护等方面的工程建设标准强制性条文）及建设工程施工图设计文件技术审查要点；

2、地基基础和主体结构的安全性；

3、是否符合民用建筑节能强制性标准，对执行绿色建筑标准的项目，还应当审查是否符合绿色建筑标准；

4、是否符合房屋建筑和市政基础设施工程防雷装置设计标准；

5、是否符合现行消防法规、国家工程建设消防技术标准和其他相关技术标准；

6、施工图审查完成后，对后续受理的设计变更审查问题按照有关规定办理。

7、法律、法规、规章规定必须审查的其它内容。
