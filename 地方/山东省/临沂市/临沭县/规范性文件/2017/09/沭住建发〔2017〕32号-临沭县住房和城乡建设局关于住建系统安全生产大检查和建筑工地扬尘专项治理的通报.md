# 临沭县住房和城乡建设局关于住建系统安全生产大检查和建筑工地扬尘专项治理的通报

沭住建发〔2017〕32号

局属各单位、机关各科室，各建设单位、施工单位：

根据临沂市住房和城乡建设局《关于印发<全市住建系统深入开展安全生产大检查实施方案>的通知》（临建安发[2017]16号）、县安全生产委员会《关于印发〈深入开展安全生产大检查实施方案〉的通知》（沭安发[2017]16号）和县住建局《全县住建系统深入开展安全生产大检查实施方案》的要求，县住建局组织人员对在建工程安全生产和扬尘治理开展了全面深入的检查，现将检查情况通报如下：

一、基本情况

本次检查活动共检查30个工地，下发限期整改通知书18份，查处安全隐患74条， 2个工地被责令停工整改。

二、检查发现的主要问题

（一）建筑工程安全方面

1、企业安全主体责任落实情况。部分施工单位安全生产管理体系不健全，安全责任落实不到位；无当年度安全投入计划；项目部专职安全员配备数量不足，特种作业人员存在无证上岗、人证不符现象；安全检查和安全技术交底流于形式，安全资料不规范，存在粗制滥造现象。个别建设单位未办理安全监督手续，未取得施工许可证擅自施工。

2、风险管控情况。部分项目未建立风险分级管控和重大危险源管理台账，危险性较大的分部分项工程专项施工方案不满足现场基本条件、针对性不强。现场普遍存在的安全隐患有：基坑临边防护不到位；电梯井口防护栏杆未固定；洞口未防护或防护盖板未固定；脚手架搭设不规范，连墙件设置数量不足，纵横向扫地杆设置不规范，悬挑脚手架悬挑梁锚固长度不足；临时用电私拉乱接，开关箱数量不足；起重机械未安装告知、未检测、未组织四方验收擅自使用，未按期维修保养；现场消防器材配置不足，不能满足消防要求。

3、隐患排查与治理情况。个别项目安全意识淡薄，项目部检查记录不全；企业对项目部的考核不全面，检查不细致，未按期复查；项目对建设主管部门提出的隐患整改、回复不及时。

（二）工地扬尘治理方面

个别项目行动迟缓，对住建局提出的扬尘治理措施未能按时落实，现场出入口清扫不及时，进出车辆未按要求冲洗，道路遗洒渣土现象时有发生。

三、下一步工作要求

各企业要对照本次检查发现的问题和不足，按照限期整改和停工整改通知书的要求，认真抓好问题和隐患整改工作，确保所有隐患全部整改到位。下一步，各企业要认真落实安全主体责任，建立健全安全生产责任制，保证安全生产投入。扬尘治理方面，经过此次检查，各项目积极整改，县城内76台塔机安装了塔吊喷淋降尘系统、3个项目已经安装扬尘智能监测仪；自动洗车机、雾炮已成为项目开工的必备设施。下一步，各项目要进一步加大扬尘治理措施，各工地要全部达到“6个100%和一个摄像头”的要求，即：施工现场围挡率、进出道路硬化率、工地物料篷盖率、场地洒水清扫保洁率、密闭运输率、出入车辆清洗率达到100%，出入口安装一个摄像头。要逐步对建筑工地落实“塔吊高空喷淋、外架喷淋、道路喷淋、楼层喷淋、室内移动喷淋”等“五喷淋”措施，将建筑扬尘消灭在源头，有效净化施工环境。各公司、各项目对此次检查提出的隐患要严格按照“定人、定时间、定措施”的原则积极开展整改，强化隐患整改措施，加大隐患治理力度。各相关科室，要进一步加大检查力度，对存在的违法行为，联合有关部门采取有力措施，实施顶格处罚，确保安全生产形势稳定。
