# 临沭县农业局关于印发《农业产业扶贫工作“回头看”突出问题专项整改行动实施方案》的通知

沭农发〔2018〕22号

局直相关科室单位：

《农业产业扶贫工作“回头看”突出问题专项整改行动实施方案》已经局长办公会研究同意，现印发给你们，请遵照执行。

临沭县农业局

2018年2月14日

关于农业产业扶贫工作“回头看”突出问题专项整改行动实施方案

为贯彻落实中共临沭县纪委《关于对扶贫领域问题进行整改的建议》（沭纪建〔2018〕1号）、临沭县扶贫开发领导小组办公室《关于做好扶贫领域问题整改工作的通知》(沭扶办发〔2018〕2号)和临沭县扶贫办、财政局《扶贫资金项目清理自查工作的通知》(沭扶办〔2018〕8号)的通知要求，经局长办公会研究，决定在全县集中开展农业产业扶贫工作“回头看”突出问题专项整改行动，确保农业产业扶贫工作取得实效，特制定本方案：

一、整改目标

开展农业产业扶贫工作“回头看”活动，认真分析梳理涉及扶贫领域的工作业务，排查2013年以来我局牵头开展涉及扶贫的农业项目建设及资金使用，重点排查扶贫资产确权登记、监督管理、收益兑现，特色农业扶贫项目管理及帮扶收益等。排查扶贫工作实施过程中的问题线索，制定整改方案，细化整改措施，进行及时整改，确保“回头看”整改工作取得实效，为打赢脱贫攻坚战提供坚实的保障。

二、整改任务

（一）扶贫项目资金方面：是否存在扶贫项目资金的下达、拨付、管理、使用和项目资金审核报账过程中，擅自改变资金用途问题；是否存在贪污侵占、截留挪用、骗取套取、挥霍浪费问题；是否存在不按项目实施进度拨付资金问题；财政扶贫资金专项审计查处问题是否逐乡逐村逐项整改落实到位等问题。

（二）扶贫项目招投标监管方面：是否存在未按规定履行招标备案手续问题；是否存在规避招标、虚假招标问题；是否存在随意压缩招标时间、简化招标程序、擅自改变招标方式问题；是否存在围标串标问题；是否存在项目招投标过程中暗箱操作、优亲厚友、吃拿卡要等问题。

（三）扶贫项目建设管理方面：是否存在未按招标文件约定签订合同问题；是否存在未按合同约定诚信履约问题；是否存在项目建设过程中工程量变更签证程序违规问题；是否存在项目建设监管不力问题；是否存在项目公开不到位、档案归档不及时、不规范问题；是否存在项目工程建设滞后、进度缓慢问题；是否存在项目竣工验收和审计决算不及时等问题。

（四）扶贫项目管理、资产确权登记、监督管理、收益兑现方面：是否存在扶贫资产收益账目不清、账册不全，漏登少登；是否存在资产无人管理或多头管理；是否存在扶贫资产被挤占挪用或流失；是否存在产权不明晰，扶贫资产被无偿占用或处置；是否存在资产收益分配不公开、不持续，贫困户没有得实惠等问题。

（五）扶贫物资登记发放规范性方面。是否存在扶贫物资闲置滞留未足量发放；是否存在扶贫物资及资金全村吃平均；是否存在未建立台账或台帐信息与贫困户实际不一致；是否存在台账数字不清，姓名、身份证号、数字不精准，台帐与实际有明显错误。是否存在发放过程中优亲厚友不公平；是否存在将扶贫物资侵占私分谋取不正当利益；是否存在将扶贫物资截留挪用；是否存在虚报冒领等问题。

三、组织实施

整改工作从2018年2月13日开始，至2月25日前结束，分三个阶段进行。

（一）认真排查自查，及时纠正整改（2月13日至2月20日）。相关科室单位要按照实施方案要求，认真开展自查自纠，对2013年实施的农业扶贫项目实施情况进行全面排查摸底，对排查出来的问题线索，建立整改台账，逐一列出责任清单，逐项对账整改，确保每件问题都要有处理结果。

（二）严肃扶贫纪律，坚决追责问责（2月21日至2月23日）。对不重视不研究、不安排不落实，隐瞒遮掩、弄虚作假，有问题发现不了、发现问题不整改上报、上报问题不整改，将严肃追究直接责任人和相关领导的责任，依法依规进行处理。

（三）建立长效机制，打赢脱贫攻坚（2月24日至2月25日）。针对“回头看”专项整改工作中发现的问题，相关科室单位要认真分析总结，举一反三，堵塞漏洞。对存在的共性问题，及时反馈，会同相关主管部门研究制定制度措施，建立并完善防止问题发生和反弹的长效机制。

四、工作措施

（一）组织领导

局里成立农业产业扶贫工作“回头看”突出问题专项整改领导小组，由局长任组长，其他班子成员任副组长，各相关科室负责人为成员，加强对我局“回头看”突出问题专项整改行动的组织领导。

李频道 王家埔 徐劲松 王文昇 李军家

（二）强化措施

相关责任科室要按照各自承担的项目，制定好具体排查整改措施，开展好“回头看”突出问题专项整改行动，确保专项整治抓出明显成效。

（三）督导考核

领导小组对整改工作进展情况进行随时调度；并组织督导工作组，深入工作一线进行工作督查检查，行动结束后将对工作完成情况进行考核。

（四）做好总结

相关责任科室2月25日前将排查整改落实情况形成总结经分管领导签字后报局综合科。
