# 临沭县商务局关于印发《创建文明单位实施方案》的通知

沭商务字〔2018〕3号

各科室：

为使我单位精神文明创建活动再上新台阶，局党组决心创建县级文明单位，特制订创建县级文明单位实施方案。现将方案印发给你们，请根据方案做好落实。

临沭县商务局

2018年2月26日

创建县级文明单位实施方案

为使我单位精神文明创建活动再上新台阶，特制订本实施方案。

一、指导思想

贯彻落实党的十九大关于推动社会主义物质文明、精神文明、政治文明、生态文明协调发展，构建社会主义和谐社会等重要思想，按照县级文明单位考核标准，以实现规范化管理为着力点，以创建优美、和谐、文明的工作、生活环境为基础，以提高我局干部员工整体素质为关键，把创建县级文明单位工作作为加强我局内涵建设、提升综合实力的重要载体。

二、创建目标

创建县级文明单位的总体工作目标是：各项创建活动深入开展，创建氛围浓厚，单位风气正，精神面貌好，商务经济成绩突出，各项成绩获得企业和基层认可，商场、超市面貌均有相当的改善。创建档案规范齐全，达到县级文明单位标准，确保创建县级文明单位成功，展示文明、和谐、团结的商务形象。

三、实施步骤

第一阶段：研究制定创建工作方案（2018年2月）。

遵循党的十八大精神、省委、省政府有关创建文明单位的文件精神，结合我局实际，认真研究制定我局创建工作的指导思想、工作目标、工作步骤、方式方法、任务分解、具体要求等。重新修订我局各项规章制度，明确责任，明晰任务。

第二阶段：宣传发动（2018年2-3月）。

召开创建县级文明单位动员大会，安排部署创建工作。组织干部职工深入学习有关创建文明单位的文件精神，充分调动广大职工参与创建工作的积极性和主动性，提高对创建工作重要性的认识，明确创建目标和要求，为创建县级文明单位营造积极的舆论导向。

第三阶段：全面实施（2018年3-7月）。

严格按照县级文明单位的考核标准，坚持硬件、软件一齐抓。在市文明委的指导下，进一步抓好领导班子建设、干部队伍建设、制度建设，加强治安综合治理、环境卫生治理，全面完成创建各项任务。要建立创建专项档案，把创建的规划、年度计划、活动安排及相关材料报市文明办，形成完整的创建档案。每周开展一次有关精神文明创建工作、政治理论、业务知识学习活动。定期对重点单位如商场、超市创建工作开展情况进行检查验收，加强对创建工作的具体指导，及时总结成绩，查找不足。对存在的问题，认真整改并对整改情况进行复查，直至达到验收标准为止。

第四阶段：自查自纠、迎接评估（2018年7-12月）。

根据创建工作情况，及时对前段工作进行总结，并对照考核标准进行自查自纠，认真整改，并做好迎接评估检查的一切准备工作。

第五阶段：巩固提高，常抓不懈。

迎接评估检查只是创建文明单位的一个阶段性工作。我局将从领导体制、工作机制、条件保障、活动开展、考核奖惩等方面建立长效机制，确保创建工作制度化、经常化、持久化，坚持以创促改，以创促建，以创促管，创建结合，把加强精神文明建设作为一项基本任务长期坚持，巩固已有成果，不断创新载体，不断拓宽渠道，使我局精神文明建设水平不断迈上新台阶。

四、创建措施

（一）提高认识，统一思想

文明单位是一项综合性荣誉称号，开展文明单位创建活动是促进物质文明、精神文明、政治文明、生态文明协调发展的重要途径和载体。为此，我局领导班子将每月研究一次创建工作并进行安排部署。

（二）健全组织，加强领导

成立由副局长高志方为组长的创建县级文明单位领导小组，局各科室负责人为组员的创建领导小组。

（三）加强党的建设，以党建促创建

加强全局党的建设是创建县级文明单位的重要考核内容，也是创建县级文明单位的重要措施。要通过抓党建促创建，为创建工作提供坚强的保证。

认真坚持党组中心组学习、党支部理论学习制度，做到学习时间、人员、内容、形式和效果“五落实”，用学习来提升干部素质，增强凝聚力。

加强基层党组织的思想建设、组织建设和作风建设，充分发挥党委的政治核心作用和党支部的战斗堡垒作用。

（四）加强商场环境建设

商场环境建设是商务工作一大难点，我局将把改善商场环境作为创建工作的重点工作来抓。通过悬挂标语、宣传画，等措施，做到既方便群众购物，又整洁美观。

（五）认真搞好自查自纠

从8月底开始，按照创建内容进行一次全面检查，并将检查结果在全局通报。对存在的问题，研究制定具体整改方案，明确责任人，集中时间、集中力量、高效率、高标准地进行整改并对整改情况进行复查。

（六）加强档案建设

规范创建档案资料，做到随时收集，准确无误，及时归档，规范管理。由专人负责，做到随时可以查阅。精神文明档案资料内容按创建县级文明单位考评细则分类整理。

（七）落实责任追究制

创建县级文明单位是反映我局全体职工精神面貌和综合工作水平的综合性系统工程，需要全体员工上下一心，全力以赴，共同努力，以最优异的成果、最佳的精神面貌迎接考核验收。
