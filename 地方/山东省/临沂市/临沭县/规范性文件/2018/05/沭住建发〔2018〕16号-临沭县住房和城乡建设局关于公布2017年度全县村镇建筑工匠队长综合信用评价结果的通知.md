# 临沭县住房和城乡建设局关于公布2017年度全县村镇建筑工匠队长综合信用评价结果的通知

沭住建发〔2018〕16号

根据《临沂市村镇建筑工匠管理办法（试行）》（临建发[2017] 46号）、《临沂市村镇建筑工匠信用评价管理办法（试行）》（临建发[2017]4号）等文件规定，县住建局对2017年度全县村镇建筑工匠队长信用情况进行综合评价确定等级，现将评价情况通知如下:

一、评价范围

2017年度村镇建筑工匠信用评价为2017年4月1日-2018年3月31日期间参与全县限额以下乡村建设工程施工、在各镇街村镇规划建设管理办公室登记备案、并纳入全县村镇建筑工匠实名制监管平台的所有村镇建筑工匠队长。

二、信用评价情况

（一）本次评价以2017年度每位村镇建筑工匠队长信用信息为依据，共对 191名建筑工匠队长进行综合评价。

（二）2017年度村镇建筑工具信用评价结果统计如下：AAA级别工匠队长111名，AA级别工匠队长80名，无A、B、C级村镇建筑工匠队长。

三、信用评价结果运用

（一）按照诚信激励和失信惩戒的原则，信用评价结果在表彰评优和日常监管等工作中作为重要指标予以应用。

（二）年度评价为AAA级、AA级村镇建筑工匠队长优先列入农房改造和政府工程推荐名录。

（三）对年度评价为A、B级的村镇建筑工匠进行一般监管。

（四）对年度评价为C级的村镇建筑工匠实行限制和惩戒机制：

1、限制并取消评先评优；

2、进行乡村建设法律、法规培训；

3、全县通报，各镇街村镇规划建设监督管理机构对其所承揽的工程列为重点监督检查的对象。

附件：2017年度临沭县村镇建筑工匠队长综合信用评价汇总表
