# 临沭县住房和城乡建设局关于印发《全县住建系统安全生产打非专项行动实施方案》的通知

沭住建发〔2019〕1号

局属各单位、机关各科室，各相关企业：

根据省、市、县各级对于安全生产工作的部署要求，经局党组研究，决定从现在起至2019年3月底，在全县住建领域开展打非专项行动，特制定《全县住建系统安全生产打非专项行动实施方案》，现印发给你们，请认真组织实施。

临沭县住房和城乡建设局

2019年1月7日

全县住建系统安全生产打非专项行动

实施方案

按照省、市、县各级对于安全生产工作的部署要求，经局党组研究，决定在全县住建领域开展安全生产打非专项行动，特制定本方案，具体实施内容如下：

一、总体要求

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大精神，坚持以人民为中心的发展思想和生命至上、安全第一的发展理念，按照上级部署要求、结合住建系统实际，在住建系统领域，重点查处和打击未按规定办理安全报监、施工许可等手续或手续不全擅自施工以及无证从事燃气经营等非法行为，严厉打击未批先建、无资质承揽、转包、违法分包、挂靠等非法施工活动，确保2019年住建领域安全生产形势稳定。

二、打非范围和重点

打非范围覆盖全县住建系统各个领域。突出以下几个工作重点：

(一)重点部位

工作重心向基层延伸，突出镇街、农村、城乡结合部等重点部位，比较隐蔽、偏僻、易被忽视的事故易发点等。

(二)重点领域

1、建筑施工领域。严厉打击不办理施工许可、安全监督等法定手续擅自开工的；不具备相关资质或超越资质范围承揽工程的；施工企业主要负责人、项目负责人、专职安全生产管理人员、特种作业人员以及工程监理人员未经培训、无证上岗的；危险性较大的分部分项工程不按规定编制专项施工方案、不按要求组织专家论证的；建筑起重机械不按规定进行备案的；施工现场组织管理混乱，违反安全生产规程，违章操作、违章指挥和违反劳动纪律的；城乡结合部、城中村非法建设等违法行为。

2、燃气领域。严厉打击无证非法生产、经营燃气行为；严厉查处作业人员无证上岗、未经许可擅自从事特种设备充装活动等行为；重点查处企业违规建设LNG自供站，使用未注册登记、未检验的压力容器、压力管道，无证充装液化气等非法行为。

三、时间步骤

专项行动从2019年1月上旬开始，到3月底结束。分三个阶段进行。

（一）企业自查自纠阶段（1月上旬）。县域内的建设、施工、监理以及燃气经营等企业要对所有项目及燃气经营单位开展自查自纠，对查出有安全隐患、问题的，要以项目为单位建立台账，制定整改方案，确保及时整改。能立行立改的，要立即整改。不能立即整改的，要有落实整改计划，安排专人负责，落实整改措施，确保整改到位。不具备安全生产条件的一律停工整顿，特别是发现的危险性较大的分项分部工程存在重大隐患的，要确保全部整改到位。

（二）执法检查阶段（1月中旬—3月中旬）。县住建局将对非法行为集中的行业领域，进行重点执法，组织相关科室开展联合执法检查，重点打击非法行为。对非法建设项目和非法燃气经营企业，加大与相关部门的协调配合，实行“两断三清”（即断水、断电、清原料、清设备、清场地）措施。

（三）总结验收阶段（3月下旬）。县住建局各相关科室、单位，对本领域打非工作开展“回头看”，重点查看因非法行为受到依法处罚的企业是否整治到位；在打非行动中被依法关闭取缔的非法企业是否真正取缔关闭到位，有无死灰复燃的现象。各科室、相关单位要对专项行动开展情况进行总结，在行动实施期间每月13日、27日向县住建局安监站报送“打非”专项行动进展表，并于4月2日前报送专项行动总结。同时，完善相关制度措施，建立常态化“打非”工作机制。

四、有关要求

（一）加强组织领导。住建系统各相关科室及各有关企业要立即动员部署，主要负责同志要亲自抓、负总责，做到层层发动、层层部署、层层检查落实，确保取得实效。各科室单位之间、科室与各企业之间要加强沟通协调，及时解决在检查中遇到的问题，对提出的整改意见认真抓好落实，及时反馈。

（二）严格检查执法。要按照“全覆盖、零容忍、严执法、重实效”的要求，对存在重大隐患和严重非法违法行为的，依法进行处罚，做到查封一批、处罚一批、曝光一批，查出实效。各相关科室要坚持问题导向，突出重要节点，切实提高整治工作的科学性、专业性、精准性和实效性。对行动开展扎实、成效突出的，进行通报表彰；对组织不力、隐患整改不到位的有关单位和企业，给予通报批评，并及时移交临沭县综合执法局进行处罚。对发生事故的，严格按照市政府“三项制度”（安全生产责任事故刑事调查、停产整顿、联合惩戒）进行处理。

（三）强化宣传教育。各相关科室单位、各有关企业要充分利用微信、网络等媒体平台，及时报道打非行动进展情况，宣传典型经验做法，曝光违法违规典型案例。通过组织企业人员集中观看事故警示片、开展安全宣传展、邀请专家宣讲、开展演讲比赛等形式，强化宣传教育效果。

（四）做好举报投诉受理工作。高度重视举报案件的核查、处理工作，接报必查。对群众举报的非法违法生产行为，应及时进行核实和处理。要综合采取突击检查和暗查暗访等方式，真正查出问题，查出成效。加大举报奖励力度，鼓励群众主动举报各类非法违法行为，强化社会监督。

（五）做好调度和总结。各领域要明确专人负责调度工作，要及时上报打非整治专项行动进展情况，认真总结好成功经验和典型做法，于每月28日前形成月度行动总结报告，报送县住建局安监站。
