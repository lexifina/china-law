# 临沭县应急管理局关于印发《宣传方案》的通知

沭应急发〔2019〕1号

各镇街安监办、经济开发区安监局，局各科室、监察大队，应急中心：

为认真学习贯彻中共临沂市委办公室、市政府办公室《关于印发<临沂市党政领导干部安全生产责任制实施办法>的通知》（办字﹝2019﹞17号）（以下简称《办法》）以及市应急管理局《关于开展宣传<临沂市党政领导干部安全生产责任制实施办法>的通知》要求，县应急管理局结合工作实际，制定《临沂市党政领导干部安全生产责任制实施办法》宣传方案，现印发给你们，请认真组织学习宣传和贯彻落实。

临沭县应急管理局

2019年2月2日

《临沂市党政领导干部安全生产责任制实施办法》宣传方案

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入学习贯彻党的十九大精神和习近平总书记关于安全生产的重要论述精神。从维护和促进全县安全生产大局出发，以贯彻《办法》为主线，集中开展一系列多元化、多层次、多类型的宣传活动，在全县范围内大力掀起学习宣传贯彻《办法》的热潮。

二、实施时间

2019年1月中旬-2020年1月中旬。

三、学习宣传活动内容

（一）开展专题培训活动

1、专题学习。各镇街（开发区）安监办（安监局）要将《办法》学习纳入日常学习计划，对《办法》进行专题传达学习。

2、集中学习。认真参加全县组织开展的宣讲工作，同时要结合各地实际，通过召开研讨会、辅导讲座等形式对《办法》出台的意义和具体内容等进行全面学习、解读，把《办法》的各项要求落到实处。

（二）开展全方位宣传

1、电视台、电台。与当地电视台、电台联系合作推出实施《办法》新闻专栏，采取动态报道加访谈的形式，全方位多角度多方面进行宣传报道。积极联系各主流媒体跟踪报道本地区、部门《办法》宣传经验做法等内容。

2、报纸、杂志。在《临沂日报》临沭版开设专栏，围绕《办法》做综合深入的详解和报道，配发系列评论员文章，进一步营造声势好氛围。同时，要积极做好学习宣传贯彻落实情况的宣传报道工作，每月至少2篇以上新闻报道。

3、网络媒体。在中国临沭、临沭发布、临沭手机台、今日头条等新闻网媒及本辖区、本单位的网站、微信、微博公众号发布实施《办法》相关动态新闻。

4、手机报、手机短信。将《办法》通过移动、联通、电信公司手机报和手机短信进行推送。

5、政务信息。充分利用两办信息等宣传载体，向上级有关部门宣传报道《办法》贯彻实施情况和亮点工作。

6、宣传专栏。利用本单位和公共宣传橱窗等阵地，开设《办法》宣传专栏。

四、工作要求

1、提高认识，精心组织。要把宣传贯彻《办法》作为当前一项重要任务，把《办法》集中宣传活动纳入全年安全生产宣传的重点工作，成立宣传领导小组负责具体组织、协调工作。认真研究制定集中学习宣传方案，安排专人负责，迅速组织开展各类学习宣传活动，及时提供新闻线索，做好采访协调工作。

2、把握重点，讲求效果。要把握重点，确保宣传质效并举。综合利用消息、通讯、特写、评论等体裁，拓展宣传广度、延伸宣传深度。要以习近平总书记关于安全生产的重要思想为重点，广泛宣传《办法》实质内涵、创新点和重要意义。同时在开展宣贯活动中注意收集、挖掘、提炼工作亮点，将典型材料及时上报，通过正确的舆论引导，营造浓厚宣传氛围。

3、围绕中心，严格考核。要把《办法》集中宣传活动与日常工作有机结合，实现宣传教育服务于中心工作。市、县将《办法》的贯彻落实情况纳入2019年度总体工作考核，每季度进行抽查督查，并将结果予以通报。各镇街（开发区）安监办（安监局）要将宣传活动开展情况通过信息简报、专项报告等方式（文字总结、宣传资料图片、培训照片等），于每月26日前向县局办公室报送，将本单位宣传活动方案、配档表于2月3日前上报县局办公室。
