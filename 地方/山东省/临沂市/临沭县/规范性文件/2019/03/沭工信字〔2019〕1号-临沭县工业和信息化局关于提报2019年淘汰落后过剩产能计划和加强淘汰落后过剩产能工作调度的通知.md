# 临沭县工业和信息化局关于提报2019年淘汰落后过剩产能计划和加强淘汰落后过剩产能工作调度的通知

沭工信字〔2019〕1号

各镇街企业办（工信办），开发区经发局：

为认真落实好《临沭县人民政府办公室关于印发2018-2020年利用综合标准依法依规推动落后产能淘汰和过剩产能退出工作实施方案的通知》（沭政办〔2018〕156号）精神，现就做好全县2019年淘汰落后过剩产能计划和相关工作通知如下：

一、明确提报内容和范围

按照能耗、环保、安全、质量、技术达不到标准及生产不合格产品或淘汰类产能均属于落后产能的规定要求，本次调度提报范围为化工、铸造、钢铁、水泥等行业2019年计划淘汰的落后及过剩产能；因退城进园、城镇规划布局等原因关闭、搬迁的企业纳入本年度淘汰落后产能计划提报范围。

二、建立淘汰落后产能工作台账

要认真收集2019年计划淘汰落后过剩产能退出企业工商注册、项目备案、环保安全手续等相关材料，建立淘汰落后过剩产能企业档案。严格淘汰工作程序，做好设备拆除环节影像资料留存，形成企业落后产能退出完备的资料。

三、加强调度督导

各镇街、开发区要加强对辖区内企业的调研分析，对提报的2019年计划淘汰落后过剩产能项目，要抓好现场督导和落后产能退出工作，并及时上报工作进展情况。强化综合协调，把握时间节点，统筹推进工作，县工信局将组织进行验收，确保年底前全面完成本年度淘汰计划。

各镇街、开发区要高度重视，认真部署，全面摸排，严格按照附件要求填写相关内容。请于3月12日12:00前通过协同办公将情况表盖章扫描后报县工信局，同时报送表格电子版。
