# 临沭县自然资源和规划局关于成立第三次国土调查工作领导小组的通知

沭自然资规发〔2019〕1号

各国土所，各科室：

为切实做好全县第三次国土调查工作，强化土地资源信息社会化服务，满足社会经济发展和自然资源管理工作需要，经研究，决定成立局第三次国土调查工作领导小组：

一、领导小组

组长：吴清军

副组长：刘宪宝

成员：王维民 李方娟 张莉 季相卫 刘祥征 杨东 王丽华 车亮 袁进 陈忠 李京 景洪璋 段圣秋 张学宾 杨玉田 孙逊 吴清凯 王升 朱淑菁朱崇文 沈铭 王峰 陈庆胜 陆宪涛 胡肖伟

领导小组下设办公室，刘宪宝同志兼任办公室主任，刘祥征同志兼任办公室副主任。办公室主要职责是：编制全县第三次国土调查实施方案，制定工作制度，组织起草国土调查工作的其他文件；编制县本级第三次国土调查工作经费预算；组织第三次国土调查任务的实施；审核各调查组编制的第三次国土调查实施方案，指导各调查组开展第三次国土调查工作；负责对各调查组国土调查成果的核查初验；组织第三次国土调查的宣传工作；承办上级领导机关交办的有关事务。

领导小组办公室下设综合组（技术组）、调查组、核查组（监理组），分工负责本次调查的具体业务和日常管理工作。

综合组（技术组）

组长：刘祥征

成员：薛贺 解中艳

负责整个调查工作的组织协调和办公室的日常工作；负责本次国土调查计划及方案的制定、各调查组调查进度及质量督导、调查成果的审核、调查成果的编写工作；负责第三次国土调查数据的汇总、成果提交工作。

二、调查组

（一）调查A组

组长：丁祥

成员：王岩 于恒方

（二）调查B组

组长：解雷鸣

成员：高岩 钟明娟

负责组织实施城市、建制镇、村庄以及城镇村以外的土地利用现状调查，村庄内部细化调查，永久基本农田调查，所有权界线核实以及各种专项任务的调查入库。

三、核查组（监理组）

组长：刘祥征

成员：刘龙超 侯玉华

根据第三次全国国土调查地类数据质量的内外业核查评价标准，负责地类数据质量的县级核查；指导各调查组开展地类数据质量县级核查。
