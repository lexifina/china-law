# 临沭县自然资源和规划局（县林业局）2019年全县“守护舌尖安全”行动总体方案

沭自然资规发〔2019〕3号

根据国家、省、市、县决策部署，2019年我局继续开展“守护舌尖安全”行动，现制定如下方案：

一、行动目标

（一）总体要求。

以习近平新时代中国特色社会主义思想为指导，以“四个最严”为基本遵循，以“强监管、优服务、提质量、保安全”为基本目标，坚持以人民为中心、坚持问题导向、坚持底线思维，深入推进“食安山东”建设，大力实施餐饮质量安全提升工程，严把从农田到餐桌的每一道防线，全面提高食品安全治理能力和保障水平，努力打造食品安全放心县。

（二）具体任务。

一是全面开展执法检查。对行动相关的食用农产品种养殖单位、食品生产经营单位组织开展监督检查，确保年底全部完成。

二是配合实施监督抽检。在执法检查中，对发现问题的单位，选取存在风险隐患的品种，现场开展监督抽检，查处一批不合格产品。

三是严惩违法犯罪行为。对行动中发现的违法犯罪行为，迅速立案查处，坚决严厉打击。

四是建立健全防控措施。对行动相关的法律法规、规章制度等进行梳理完善，提出针对性的改进措施，建立长效机制。

二、行动重点

针对公众反映强烈的突出问题，根据全县食品安全监督抽检、风险监测、日常监管等情况，重点开展两个方面的专项行动：

（一）农业投入品管控行动。加强农药使用管理，管控农药残留超标问题。严肃查处农药违规使用以及滥用农药等违法犯罪行为。

（二）毛皮动物胴体肉专项整治行动。按照《动物检疫管理办法》、《陆生野生动物疫源疫病监测防控管理办法》等规定，对毛皮动物进行防疫检疫，防范动物疫病风险，做好病死毛皮动物无害化处理工作。不得为毛皮动物胴体出具检疫证明，防止其以合法身份进入食品生产经营领域。严肃查处经营和运输未附有检疫证明、检疫标志毛皮动物胴体的违法行为。按照《毛皮野生动物(兽类)驯养繁育利用技术管理暂行规定》要求，指导养殖单位和屠宰加工企业设立集中取皮加工点（室），督促做好毛皮动物统一取皮加工。做好毛皮动物胴体的无害化处理工作，督促饲养场户建立胴体处理和流向记录，积极引导协调专业病死畜禽无害化处理厂从事胴体肉的收集处理，严禁流入食品、饲料加工等领域。

三、行动要求

（一）提高思想认识。以对人民群众高度负责的态度，把两个专项行动纳入今年的工作重点，切实抓紧抓好，抓出成效。在贯彻落实总体方案的同时，立足实际，组织开展更有针对性的专项行动。

（二）强化部门联动。围绕行动目标和重点，加强协作配合，严格落实食安、农安、公安“三安联动”机制，开展联合执法、联合行动，形成工作合力。

（三）加强社会共治。加大食品安全科普宣传教育，提高群众食品安全知识和维权意识。大力宣传专项整治工作进展和成效，及时公布典型案件，曝光违法违规企业和产品。充分发挥举报奖励制度，公开举报渠道，落实奖励资金。鼓励行业协会健全行业规范和自律机制，引导和督促行业依法生产经营，推动行业诚信建设。

（四）狠抓工作落实。针对行动确定的具体任务,周密谋划部署，推动工作落实。采取重点督查、明查暗访等方式，加大督导检查，确保行动取得实效。

认真做好进展情况统计上报工作，6月27日前和2019年12月26日前，分别报送上半年和全年工作情况书面总结。
