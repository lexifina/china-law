# 临沭县住房和城乡建设局关于印发《全县住建系统2019年“安全生产月”活动方案》的通知

沭住建发〔2019〕11号

局属各单位、机关各科室，各相关企业：

今年6月是全国第十八个“安全生产月”，根据县安委会《关于印发<临沭县2019年“安全生产月”活动方案>的通知》（沭安发[2019]6号）要求，特制定《全县住建系统2019年“安全生产月”活动方案》，现印发给你们，请认真抓好贯彻落实，务求取得实效。

临沭县住房和城乡建设局

2019年5月30日

全县住建系统2019年“安全生产月”

活动方案

2019年6月是全国第十八个“安全生产月”，为进一步加强安全生产宣传教育，增强全民安全生产和应急管理意识，提升公众安全素质，根据县安委会《关于印发<临沭县2019年“安全生产月”活动方案>的通知》（沭安发[2019]6号）要求，现制定《全县住建系统2019年“安全生产月”活动方案》如下：。

一、活动主题和时间安排

全县住建系统活动以“防风险，除隐患，遏事故”为主题， 于2019年6月1日至6月30日统一开展。

二、目标要求

以习近平新时代中国特色社会主义思想为指导，深入贯彻党的十九大和十九届二中、三中全会精神，深入学习宣传习近平总书记关于安全生产的重要论述精神，认真落实各级关于安全生产工作的决策部署。以及时消除安全隐患、有效遏制生产安全事故为目标，落实安全生产责任，突出重点问题整改、典型宣传、隐患曝光和网络宣传、知识普及、有奖举报等内容，开展既有声势又有实效的宣传活动，促进住建系统安全生产水平提升和安全生产形势持续稳定好转，不断增强人民群众获得感、幸福感、安全感，为新中国成立70周年营造良好的安全生产环境。

三、主要内容

（一）开展安全生产宣教活动

1、积极开展以“防风险、除隐患、遏事故”为主题的“安全生产大讲堂”，由住建局分管同志亲自宣讲，深入宣传习近平总书记关于安全生产的重要指示精神，认真宣贯《安全生产法》、《生产安全事故应急条例》、《山东省安全生产条例》等法律法规，广泛开展安全生产教育培训。

2、相关企业主要负责人要面向全体职工讲一堂“安全生产公开课”，大力宣传国家和省市县关于安全生产的决策部署、法律法规、规章制度和知识技能，深入一线班组面对面交流安全生产心得体会。要积极开展专题讲座和培训，邀请本行业领域的安全生产专家开展建筑施工领域安全生产、燃气安全生产专题辅导讲座，并对监督机构监管人员进行精准指导，不断提高监管水平。

3、开展“安全宣传咨询日”活动。6月中旬，住建系统与相关部门利用城市广场等公共场所，采取设置咨询展台、举办展览展示、发放宣传品、开展有奖竞猜、组织安全体验等多种形式，组织现场宣传、咨询服务、体验交流等活动，大力宣传安全生产方针政策、法律法规、安全知识和应急逃生、自救互救方法等，解答社会公众关心的安全生产问题。

（二）深化安全生产专项整治

1、坚持问题导向，集中深化全县房屋市政施工、城镇燃气等安全生产专项治理行动。定于6月中旬开始，开展全县建筑施工领域安全大检查，检查拟采用聘请第三方评估的方式，围绕深基坑、高支模、脚手架、起重机械、地下暗挖、城镇燃气等危险性较大作业安全，加大排查整治力度，完善排查整治台账，闭环整改问题隐患，确保活动期间万无一失。检查将严格事故责任追究，落实安全生产条件复核、资质资格处罚、公开曝光查处情况等处理处罚措施，实施信用联合惩戒，倒逼企业主体责任落实。

2、组织安全文明示范工地现场观摩活动。选定1至2个在建工程作为安全文明施工示范工地，组织建设、监理、施工单位在“安全生产月”期间观摩学习和研讨交流，推广安全生产和文明施工管理先进经验。

（三）开展警示教育和应急演练

1、定于6月中旬在全县住建系统开展建筑施工安全知识竞赛活动，竞赛采用闭卷考试的方式，目的普及建筑安全生产知识，提高建筑施工人员的安全意识，增强自我保护能力。

2、举办体验式安全教育基地开放日活动。活动面向作业工人，使一线操作工人切身体验事故带来的严重后果，增强安全意识，提升自救互救和避险逃生技能；使一线操作工人认识到建筑工地、燃气作业环境复杂，危险源种类多，不断提高应急意识和安全素养。

3、组织一次安全生产应急演练。突出施工坍塌、工地消防安全、高空坠落、有限空间作业、燃气突发事件等事故救援。指导相关单位和企业完善应急预案，切实提高针对性、可操作性。强化实战化应急演练，集中开展一次政企联动的示范性演练，严格做好演练前方案编制交底，演练时协调组织督导，演练后经验总结提升等工作，确保应急演练不走过场，切实检验多部门、多单位协调配合能力，提高安全生产应急处置水平。

（四）积极参与市、县组织的群众性安全文化活动。

1、开展安全生产合理化建议“金点子”评选活动。充分调动全县住建系统职工参与安全生产管理工作的积极性和创造性，激励广大职工围绕企业安全生产，开展合理化建议活动，为企业安全发展群策群力、献计献策，使事故隐患得到有效治理，为全县安全生产工作做出贡献。

2、开展“安全全家福”宣誓活动。为使职工从内心深处认识到遵守规程、按章作业的重要性，增强广大职工搞好自身安全的自觉性，在全县建筑企业开展“安全全家福”宣誓活动，各企业以班组为单位，职工人人拍一张全家福照片，各班组将征集的职工个人全家福汇总整理后制作展板，配上亲情寄语，在建筑工地、燃气经营场所醒目位置悬挂，各班组在职工接班前在全家福展板前进行安全生产宣誓，让亲情真正融入到安全生产之中。

3、积极参加全市“安全生产随手拍”摄影比赛活动。发挥广大干部职工参与安全生产的积极性，用手中的摄影镜头真实记录安全生产工作开展的做法、成效和感人场景，发现和曝光身边的不安全行为、存在的安全隐患，进一步提高一线职工的安全意识和安全素质。

四、保障措施

（一）切实加强组织领导。各有关单位、企业要高度重视，结合实际，认真研究制定工作方案，细化分工，周密部署，确保责任到位、投入到位、措施到位。

（二）确保活动取得实效。紧紧围绕活动主题，聚焦有效遏制生产安全事故，通过开展一系列宣传活动，着力强化全县住建系统安全发展理念，普及安全知识，提高安全素质，增强安全防范能力。注重总结经验，善于发现典型，持续巩固和深化活动成果，推动安全生产形势持续稳定向好。

（三）全力营造浓厚氛围。各有关单位、企业要积极参加相关活动，全面宣传住建系统安全生产面临形势、工作职责、任务目标、重点举措等内容。充分发挥广播、电视、报纸、网站、微博、微信、户外电子显示屏等各种媒体平台作用，在办公地点和建筑工地、燃气经营场所显著位置悬挂“安全生产月”宣传横幅、悬挂安全警示标语，营造 “安全生产月”活动良好氛围。

（四）及时报送活动进展情况。各有关单位、企业，每周四前报送“安全生产月”活动开展情况（电子版），重大活动信息可随时报送。“安全生产月”活动总结7月1日前以书面形式报县住建局安监站。
