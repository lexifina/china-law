# 临沭县自然资源和规划局2019年精准落实林业行业扶贫工作实施方案

沭自然资规发〔2019〕7号

为深入贯彻落实《临沂市林业局关于精准落实林业行业扶贫工作重点任务及2019年工作要点的通知》（临林发﹝2019﹞11号）文件要求，扎实组织开展好2019年林业行业扶贫工作，确保7月底前全面完成林业行业扶贫任务，特制定本实施方案。

一、总体要求

2019年要把林业行业扶贫作风建设作为深入贯彻落实党的十九大精神的重大工作实践和打赢全省脱贫攻坚战的根本保障，切实提高思想认识，明确责任主体，强化责任担当，严格按照有关通知要求，认真梳理、排查整改林业行业扶贫作风问题，加强与县扶贫部门的沟通协调，促进行业扶贫与地方扶贫有效对接。深入贫困群众中间，了解实际需求，精准施策，组织开展好林业行业扶贫活动。

二、林业产业扶贫

各镇街林业站要对林业行业产业扶贫目标任务，进一步细化分解。要落实落细各项数据，建立扶贫台账，精准到户到人到主体到地块。林业龙头企业、合作社帮扶带动的，要统计扶贫户数、贫困人口姓名、家庭住址、身份证号和帮扶带动方式。特色经济林帮扶带动的，除上述指标外，还需统计经济林建设面积、地点等。

三、林业技术扶贫

县自然资源和规划局、县林业发展中心各科室要将科技下乡常态化，要做到扶贫重点范围全覆盖。镇街林业站要确保每个贫困村有1名技术明白人，每个镇街要有3名专业技术员，扶持建立林果技术服务队，力争种植经济林的农户掌握1-2项栽植实用技术，参与1-2项经济林富民产业增收项目。各镇街林业站、局各科室要对林业技术培训建立培训人员台账，对县、镇街、村林业技术人员（明白人）登记造册，并收集保存相关影像、文字资料，并于每月5日前将电子资料上报县自然资源和规划局。

四、护林员岗位扶贫

各镇街林业站要根据贫困人口、生态公益林实际情况，积极探索联合护林、协管护林、临时护林等模式，充分利用护林员岗位开展帮扶带动，并建立相关台账。

五、统筹整合林业项目资金加大行业扶贫支持

县自然资源局将进一步加强林业项目资金统筹整合，加大对贫困地区特别是省扶贫工作重点村的扶持力度。引导鼓励各类经营主体通过土地租赁流转、劳务用工、入股分红、提供苗木、技术服务、收购林产品及生产物资统一供销等各种形式，帮扶带动贫困人口增加收入。各镇街林业站要把帮扶带动贫困人口成效作为林业龙头企业、林业专业合作社及各类示范园评选的重要依据，对积极开展林业帮扶工作的各类经营主体，通过优先为其争取项目资金支持等方式，充分调动全社会参与林业行业扶贫的积极性。

六、加强信息宣传和月报季报制度

各镇街林业站、局相关科室要向帮扶带动的建档立卡贫困人口，宣传讲解林业帮扶政策和帮扶措施。根据本地风俗民情，编辑通俗易懂的林业扶贫宣传标语，印制成宣传资料。针对贫困户和省扶贫工作重点村，利用节日走访慰问、送科技下乡等多种方式，进村入户，用群众愿意听、听得懂、能认同的话语，直接面对面开展有效宣传，不断扩大林业荒野扶贫政策的知晓率和覆盖面，引导鼓励贫困人树立脱贫信心，增强脱贫内生动力。要充分利用各种信息渠道，按时报送统计数据、总结报告和宣传信息。每月5日前将扶贫工作月工作台账上报，每季度最后一个月中旬报送本季度林业扶贫工作总结报告及累计帮扶带动的贫困人口附表等。月报、季报和信息报送情况将作为对镇街年度成效评估的重要参考依据。

七、加强组织领导

为统筹推进落实林业行业扶贫工作，县自然资源和规划局成立由吴清军同志任组长的林业行业扶贫工作领导小组，相关科室（站所）负责同志和业务骨干为林业行业扶贫工作领导小组办公室成员，全面负责林业行业扶贫工作的开展。
