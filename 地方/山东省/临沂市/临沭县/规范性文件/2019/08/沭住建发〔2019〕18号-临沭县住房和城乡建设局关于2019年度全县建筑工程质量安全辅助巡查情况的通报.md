# 临沭县住房和城乡建设局关于2019年度全县建筑工程质量安全辅助巡查情况的通报

沭住建发〔2019〕18号

各建设、施工、监理等相关单位：

2019年7月上旬，县住建局通过采取政府购买服务方式，委托第三方开展了建筑工程质量安全辅助巡查，现将有关情况通报如下：

一、基本情况

第三方辅助巡查机构于2019年7月8日-10日开展了质量安全辅助巡查，共检查工程项目16个（单体工程106个）、起重机械118 台，下达巡查发现问题整改处理通知单8份，共发现隐患问题448项，其中施工起重机械问题91项，工程实体质量问题88项，安全风险管控方面问题269项，重大隐患问题4项。对照检查标准，全县总符合率仅为69.96%，其中施工现场管理风险管控方面符合率71.58%、工程实体质量问题符合率72 %、安全行为问题符合率64.19%。

二、发现的主要问题

（一）管理风险管控方面。发现的主要问题有：缺少部分分项工程的样板验收；变更资料签字盖章不及时；施工升降机、塔机资料不全，与现场不符，缺少塔机顶升后的验收记录；施工日志记录不连续，签字不及时；监理单位监理规划、实施细则内容不全，针对性不强；缺少安全例行检查记录等。

（二）质量风险管控方面。存在单位主要问题有：钢筋制作及绑扎不符合图纸、规范、图集要求；保护层控制不好。混凝土蜂窝孔洞、夹渣、疏松、烂根、露筋现象普遍，缺陷处理无方案、未按方案进行处理。施工缝留置随意，不按方案留置，不按规定凿毛，铺浆处理，夹渣现象普遍，尤其是楼梯梯段板；砌体结构填充墙组砌方法不正确，不预先设计砌块排列图，随意砌筑，存在混砌现象；顶部后塞不密实，后塞时间不符合要求；墙体有透明缝现象，观感质量差；洞口大于30厘米处未设置过梁；墙体拉结筋有不按设计要求贯通的情况；模板配置套数不够，拆模过早，特别是悬挑构件；防漏浆措施不够，漏浆现象普遍；大截面梁支模没有专项方案，不按方案施工。

（三）安全风险管控方面。存在的主要问题有：脚手架搭设与方案不符；落地式脚手架基础排水不畅，地基变形，无垫板或垫板不合格，无钢支座；悬挑式脚手架预埋型钢规格不符合要求，型钢锚固长度不够，特殊部位锚固不足无卸荷设施；立杆、横杆间距不符合方案要求、平网防护不严，大平网道数不够；临边防护不到位，搭设不规范；栏杆高度不够，缺少挡脚板；临时用电使用不符合规范要求；总盘接地不好，有的没有接地；塔机、升降机各限位不按要求安装调试，拆解现象普遍；外用作业吊篮问题较多。不经检测即使用，限位装置缺失，安全保护装置未经检测；钢丝绳接头绳卡数量不足；配重破碎，固定措施无效；不正确使用前支腿；安全防护定型化、工具化有待加强。

三、有关工作要求

（一）高度重视质量安全辅助巡查工作。委托第三方专业机构开展工程质量安全辅助巡查，是县住建局创新工程监管模式的重要举措，今后将不定期在全县在建工程项目中随机抽取检查对象，各建筑企业要高度重视全县建筑工程质量安全辅助巡查，认真做好配合工作，凡巡查抽中的项目要按要求积极配合辅助巡查人员开展巡查，及时提供相关检查资料，坚决避免消极应付、临时停工闭门、陪同干扰巡查等抵触行为。

（二）严格落实隐患整改和处理处罚。对辅助巡查中发现的质量安全隐患问题，各建筑企业要迅速组织人员现场核实处理，严格督促整改，安排专人逐一复核销号，并以此为契机延伸排查梳理、不留死角、不留隐患。对隐患问题严重或整改不力的，县住建局将依法按程序对各责任单位实施处理处罚，并确保处罚结果取得实效，达到处罚一个、警醒一片的目的。

（三）认真对照，举一反三，切实加强质量安全管理。各建筑企业要对照通报的各类隐患问题，举一反三，认真查找工程质量安全工作中的不足，研究制定长效措施，不断加大对各在建工程项目日常管理力度，督促各在建项目持续从质量安全行为、强制性条文、模架脚手架、起重机械、基坑开挖支护、安全防护等方面进行自查自改，以踏石留印、抓铁有痕的劲头切实提升工程质量安全管理水平。
