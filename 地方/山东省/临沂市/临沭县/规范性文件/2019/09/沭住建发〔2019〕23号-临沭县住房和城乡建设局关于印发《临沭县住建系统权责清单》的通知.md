# 临沭县住房和城乡建设局关于印发《临沭县住建系统权责清单》的通知

沭住建发〔2019〕23号

各科室、局属各单位：

根据县委编办、县司法局《关于印发<规范和完善临沭县政府部门权责清单制度实施方案>的通知》（沭编办〔2019〕16号）要求，依据《临沂市住建系统权责清单》内容，结合我县实际，对临沭县住建系统权责事项进行了全面梳理，编制了《临沭县住建局权责清单》。现印发给你们，请认真遵照执行。
