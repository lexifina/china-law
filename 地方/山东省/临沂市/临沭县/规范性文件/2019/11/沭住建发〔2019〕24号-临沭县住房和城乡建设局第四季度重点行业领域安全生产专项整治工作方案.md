# 临沭县住房和城乡建设局第四季度重点行业领域安全生产专项整治工作方案

沭住建发〔2019〕24号

为深化住建领域问题隐患排查整治，有效防范遏制各类生产安全事故发生，确保2019年安全生产形势稳定向好，根据《临沂市安全生产委员会办公室关于印发<2019 年第四季度重点行业领域安全生产专项整治工作方案>的通知》等文件要求，经研究，决定在全县住建领域开展安全生产专项整治行动。特制定如下工作方案：

一、总体要求

以习近平新时代中国特色社会主义思想为指导，按照市委、市政府工作部署和县委、县政府工作要求，持续深化风险隐患专项整治，着力“控风险、除隐患、防事故”，严格落实安全生产责任，狠抓住建领域专项整治，深入排查治理安全隐患，严厉打击各类违法行为，推动我县住建领域安全生产形势持续稳定。

二、任务目标

各相关单位、科室主要负责人要全面落实监管责任，严格落实“一岗双责”责任，牵头组织开展分管行业安全生产专项整治工作。各行业主管单位要严格落实“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，切实担负起主管行业安全生产监督和管理责任，扎实开展好本行业安全生产专项整治行动，深入分析行业安全生产现状，全面排查问题隐患，严厉打击违规违法行为，彻底消除安全隐患。各单位和企业要严格落实安全生产主体责任，加强管理，加大投入，全面排查，整改隐患，确保第四季度建筑领域生产安全。

三、整治范围、时间及内容

（一）整治范围。全县行政区域内的新建、扩建、改建房屋建筑和市政基础设施工程以及城镇燃气领域等。

（二）整治时间。本次集中整治行动时间从现在开始，到12月底结束。

（三）房屋建筑整治内容

1、违法违规建设工程情况。严厉打击非法转包、违法分包、挂靠等违法行为，对不依法办理建设工程质量安全监督手续、未取得施工许可证即擅自开工，肢解发包、层层转包、违法分包、无资质超资质或挂靠承包，要彻底纠正，严厉查处。

2、安全生产主体责任落实情况。建设、监理、设计、施工总承包、专业分包、劳务分包，建筑起重机械租赁、安装、使用等单位安全生产主体责任落实情况，各方责任主体项目负责人安全责任落实情况。

3、从业人员持证上岗情况。施工单位主要负责人、项目负责人、专职安全生产管理人员持有安全生产考核合格证书情况；建筑起重机械司机、安装拆卸工、司索工、架子工等特种作业人员持证上岗情况。

4、安全专项施工方案管理情况。施工单位对危大工程开展专项方案编制、审查、专家论证审批及现场实施情况；监理单位开展专项方案审核、施工现场监理和工程验收情况；建设单位在安全报监时提供清单情况。

5、深基坑工程安全管理情况。深基坑（槽）开挖的防护情况，包括周边防护栏杆、工人专用梯道、同一垂直作业面上下层之间的隔离防护等；深基坑（槽）和边坡作业的合规性情况，包括支护、降（排）水、放坡、安全监测等。

6、模板和脚手架支撑系统安全管理情况。模板和脚手架支撑系统搭设前材料及基础验收、安全技术交底、特种作业人员持证上岗、模架搭设、搭设后检查验收及超过一定规模进行专家论证，使用与检查、混凝土浇筑、现场安全监测、模架拆除以及监督管理等制度执行情况。

7、起重机械安全管理情况。建筑起重机械产权备案（注销）、安装（拆卸）告知、安全档案建立、检验检测、安装验收、使用登记、定期检查维护保养等制度执行情况；拆装人员取得特种作业资格证书，拆装安全技术交底签字盖章，安装、加节、附着、拆除等执行情况；机械类专职安全生产管理人员配备以及企业是否具有相关资质和安全许可证情况。

8、消防安全管理情况。施工现场防火工作落实和动火审批执行情况，认真排查施工现场的易燃、可燃物品堆(存)放、用火用电、疏散通道、消防车通道、消防水源、灭火器配置、重点岗位人员持证情况，以及施工人员生活区（工棚）的用火用电防火措施等，所有建筑工地临建房屋禁止使用非阻燃材料，凡使用彩钢岩棉板的必须达到A级防火要求。

9、镇街村民自建房和各类生产设施建设情况。重点检查限额以下村民自建房和各类生产设施工程质量和施工安全监管工作开展情况、房屋设施质量安全情况。着力解决巡查职责分工不明确、违法建设查处效率不高和质量安全监管不到位的问题，解决房屋设施建设过程中存在的质量安全问题。

（四）市政基础设施工程整治内容

1、是否建立市政工程项目清单，对项目清单及时更新，动态掌握各工地情况。

2、依据标准找出落实安全生产方面的薄弱环节，针对每个工程项目逐一列出问题清单，下发整改通知，检查整改回复落实情况。重点检查大型桥梁、地下综合管网等工程的安全应急预案和落实情况。

3、重点针对施工用电、支架搭设、模板工程、沟槽施工、基坑支护、起重吊装等方面，制定切实可行的安全预案，组织安全应急演练。

4、市政施工企业应组织安全生产技能培训，落实安全培训主体责任，未经培训的人员一律不能上岗，高度重视特种作业人员、施工现场一线施工人员尤其是一线操作工人的安全教育培训，使其掌握安全操作基本技能和安全防护救护知识。

（五）城镇燃气整治内容

1、各燃气企业根据自身情况先行自查，针对容易出现隐患的重点部位、重点环节进行一次全方位、无死角的自我检查，对查到的隐患及时改正，并制定措施，确保安全生产。

2、组织燃气专家对全县所有燃气企业进行安全检查，要求各燃气企业切实提高思想认识，深刻汲取事故教训，举一反三，查找薄弱环节，严格安全管理，狠抓措施落实，切实做好天然气使用安全管理工作。

四、工作步骤

（一）宣传发动阶段（10月21日—11月20日）

各相关单位、科室要深入研究本行业安全生产形势，制定针对性、操作性强的工作方案，统筹推进专项整治工作。要采取制作宣传栏、设立宣传站和悬挂标语横幅等多种形式，大力宣传开展第四季度重点行业领域安全生产专项整治的目的和意义，引导教育各相关单位、建筑企业进一步提高思想认识，克服松懈和麻痹情绪，时刻绷紧安全生产这根弦，坚决抓好安全生产各项工作措施落实，全面加强安全防范，确保全县安全生产形势总体保持平稳。

（二）组织实施阶段（11月21—12月20日）

1、全面排查。结合建筑施工行业、市政施工行业、燃气企业的特点，采取企业单位自查、专家诊断和执法检查等方式，开展拉网式排查，全面摸清风险底数，并建立企业隐患台账和行业隐患台账，对排查出的隐患进行登记，逐项明确责任分工、整改措施等内容。

2、彻底整改。督促生产经营单位及时整改安全隐患，做到措施、责任、资金、时限和预案“五到位”。对重大安全隐患，要按程序报县安委会挂牌督办，重大安全隐患一律停工整改。要严格落实检查整改责任，坚持“谁检查、谁签字、谁验收、谁负责”，加大隐患整改治理力度，严格验收标准，确保安全隐患整改到位。

3、建立长效机制。要综合运用整治成果，既要集中解决排查出的突出问题，又要透过现象看本质，加强综合分析，堵塞漏洞，完善制度，对集中整治行动中的经验做法，及时进行总结提炼，形成长效机制。

4、组织对行业内各建筑项目、市政项目、燃气企业风险隐患自查整改情况进行专项检查；县住建局组成检查组，分行业领域对企业风险隐患排查整治情况进行抽查。

（三）验收考核阶段（12月21—12月31日）

专项整治结束后，由第四季度重点行业领域安全生产专项整治工作领导小组办公室牵头，按照所辖各行业专项整治方案要求，组织开展专项整治分析评估，并将各行业专项整治进行验收考核。各相关单位、科室要强化工作落实，对工作不力、问题突出的，要及时通报批评，督促其加大工作力度。对发生较大以上安全事故的，要组织实施约谈，并依法追究有关单位和人员的责任。各相关单位、科室要在12月31日前，对整个活动开展情况进行梳理，并形成工作报告，上报重点行业领域安全生产专项整治工作领导小组办公室。

五、工作要求

（一）加强组织领导，落实工作责任。各单位、科室和相关企业要切实增强政治敏感性，充分认识开展第四季度重点行业领域安全生产专项整治工作的重要意义，切实加强组织领导，严格责任落实，完善工作措施，推动专项整治工作扎实有效开展。县住建局专门组织成立第四季度重点行业领域安全生产专项整治工作领导小组，领导小组下设办公室，办公室设在局建筑工地扬尘治理办公室，统筹协调专项整治各项工作。各单位、科室要高度重视这次专项整治工作，将其列入重要议事日程，聚焦此次治理重点，全面开展自查工作，逐项梳理职能范围内存在的突出问题，明确下一步整治方向。相关主要负责同志要切实履行“一岗双责”，亲自抓、直接抓、具体抓，真正把专项整治工作抓在手上，扛在肩上，落实到行动中去。

（二）加强督导检查，确保有效推进。为确保本次安全生产专项整治工作不走过场，专项整治工作领导小组办公室将组织专门人员，采取专项检查和明察暗访等多种形式，定期开展督导检查。对整治工作不扎实，甚至走过场、搞形式、做表面文章的，将追究相关责任人的责任，并在全县住建系统进行通报，确保专项工作各项目标任务落到实处。在开展专项整治期间，严格落实安全生产“一票否决”目标责任制。对期间发生较大以上事故或者造成较大负面影响的典型案件，在严厉追究企业主体责任的同时，严肃追究行业监管单位和科室责任。

（三）严格问题排查，建立长效机制。各单位、科室要按照整治工作目标要求，把排查问题、加强监督、完善制度有机衔接起来，协调推进。要把专项整治工作与解决服务群众“最后一公里”问题和加强日常监管结合起来，达到既解决当前突出问题又促进工作长远发展的效果，推动相关问题有效根治和彻底解决，力求专项整治工作取得最大实效。要及时总结专项整治成果，针对存在的问题和漏洞，探索建立加强监督防范的长效机制，落实情况要全程留痕、可追可查，确保第四季度重点行业领域安全生产专项整治工作取得明显成效。
