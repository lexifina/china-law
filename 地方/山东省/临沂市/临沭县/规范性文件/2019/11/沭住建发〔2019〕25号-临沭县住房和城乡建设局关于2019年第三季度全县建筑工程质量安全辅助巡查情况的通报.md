# 临沭县住房和城乡建设局关于2019年第三季度全县建筑工程质量安全辅助巡查情况的通报

沭住建发〔2019〕25号

各建设、施工、监理等相关单位：

按照全县建筑工程质量安全管理工作的总体安排，2019年9月19日—25日，县住建局委托第三方质量安全评估机构，对全县在建工程开展了第三季度质量安全辅助巡查，现将有关情况通报如下：

一、基本情况

本次检查对全县25个在建项目106个单体工程全部实施了安全文明风险评估，对部分工程实施了质量评估。受检工程面积累计129万平方米，约占全县在建工程的76%。检查共涉及建设单位10家，施工总承包企业10家，监理企业11 家，起重机械68台。此次检查共下达整改通知书19份，责令停工整改项目2个，拆除不合格起重机械8台（套），发现隐患问题146项，其中施工起重机械问题20项，安全风险管控方面问题75项，重大隐患问题15项。对照检查标准，总符合率75.1%，其中施工现场安全生产方面符合率74.6%，监理企业管理符合率75.6%。

从这次巡查的情况看,安全生产水平较上次评估有了明显进步，特别是上次参与评估的施工企业效果尤为明显。但各施工企业之间发展不平衡，存在较大差距，作为本县施工龙头企业的临沭县金明寓建筑工程有限公司施工的很多项目，安全生产管理水平提升明显，起到了很好的带头引领作用。

二、存在的主要问题

（一）安全管理方面

1、垂直运输设备：设备本身存在的问题主要有塔吊、施工升降机超期服役；塔机安全保护装置未安装、失效的较多；施工升降机的安全防坠器、高度限位、极限限位不安装、无效的情况均存在；设备检测不严肃，已检测合格的设备实际不合格的现象较多；资料和现场实际设备不对应的现象也一定程度存在。

2、深基坑工程：深基坑支护是历次检查发现的后果影响最大的安全隐患之一，各相关建设及施工单位思想重视程度远远不够。大多数不能按照设计要求进行支护，建设单位未委托有资质的单位进行监测，挖方坡度过陡。有的工程开挖深度达7、8米，周边有建筑物，里面长期住人，存在较大安全隐患。检查人员现场提出了相应的应急措施建议及按设计要求支护降水和委托基坑检测的建议，只有新开工的城投翰林学府工程正在按设计要求施工。

3、高处作业吊篮：多数现场设备老旧、超期服役、设备生产日期不明确、整套设备未经检测、防坠安全器无效、不能按规范进行检测、支撑架多数未使用前支腿、配重不按规定使用、安全绳使用不正确，未固定在可靠构件上等。

4、临时用电：配电系统不合格，接地系统不正确、不完整、无效，做不到三级配电两级保护。三相五线制（即TN-S系统）存在外电防护的工地多数未按要求对外电线路进行防护。配电箱管理混乱，配电设备破损严重、私自接线、箱门敞开的较多。

5、脚手架、卸料平台：连墙件不能正常使用、数量不足；悬挑脚手架、卸料平台的悬挑型钢锚固长度不符合要求，卸料平台放在阳台上，卸荷措施不到位；安全平网防护不严，特别是离墙间距较大，不能及时防护，安全网上杂物较多，不能及时清理。

6、模板工程：模板支撑不能形成有效的支撑体系，特别是高度较大的模板工程和截面较大的工程隐患更大，此类现象在全县在建工地中较为普遍；缺少剪刀撑和与结构连接的杆件；缺少扫地杆或过早拆除；垫板、底座使用不正确；梁底支撑排距过大，大横杆数量不足，做不到双向设置，步数不足，特别是缺少最上一步大横杆。

7、安全防护及安全通道：有些设备缺少防护棚，有些工程安全通道数量不足，有的无安全通道；楼层防护不及时，防护栏杆固定不牢，高度不足，定型化防护栏杆及防护棚使用不多；地下室多数不能有效防护，照明不足，很多工程没有照明设备。

（二）施工质量方面

1、止水梁局部断开；填充墙和砼墙交接处，竖向接缝宽度过窄，砂浆不密实。填充墙顶部横向接缝不饱满；墙体破坏严重；砼质量缺陷处理不规范；屋面保护层分隔缝间距过大；高屋面落水管底部距离大屋面小于200mm，落水斗未固定。

2、阳台部位下层窗顶梁距离上层窗台高度不满足1200mm,不符合防火规范要求。外窗窗台滴水线深度过小；楼梯井滴水线做法不正确，起不到截水作用。抹灰面层后割线槽无防裂处理措施，表面粗糙；防水保护墙不按设计要求施工；后浇带拆除无支护措施；构造柱按框架柱施工，改变构件受力状态。

3、梁施工缝位置留置错误（上部上翻，50mm预留未浇筑砼）；梁板交接处吃模未拆除干净；拉结筋不按设计使用通长筋，有漏放现象；止水梁施工未凿毛。防水卷材横向接头未错开，位于同一平面内；防水卷材供应厂家说明施工工艺为自粘法，现场采用胶浆粘贴法，胶浆与卷材应做相容性试验；砼墙窗台裂缝。

（三）监理企业管理方面

1、有个别工程总监不在现场，甚至监理人员多数不在场，监理日常工作不到位；图纸会审记录、工程变更未建立台账或收集资料不齐全、不及时；监理规划和实施细则缺少扬尘治理、危大工程方面的内容；危大工程控制，这是历次检查评估的必查内容和重点内容，规划和细则中缺少该部分内容，未建立台账，检查验收记录不全，旁站记录不齐。

2、该下发监理通知的没发，下发的通知未及时回复，回复单未及时验收确认，资料不闭合。缺少安全例行检查，检查不及时；旁站记录不齐全，不及时，缺少危大工程旁站记录；隐患排查不到位，没有尽到责任，现场大量质量安全隐患未及时进行排查。

三、检查处理意见

（一）表扬先进。对安全生产方面领导重视、安全生产责任制落实、安全防护措施比较好，得分前三名的临沭县金明寓建筑公司施工的育源华庭南区项目、山东正安建设有限公司施工的翰林学府项目、山东金正阳建筑工程有限公司施工的印象城银座大酒店项目予以通报表扬。

（二）批评后进。对安全管理责任制未落实、现场管理混乱、得分后三名的山东春天建设集团有限公司施工的爱琴海项目、临沂明昊建筑工程有限公司施工的新天名都项目、山东金大陆建筑工程有限公司施工的陆河社区项目给予通报批评，在今后管理和检查时列为重点管理对象。

对以下监理单位给予通报批评：青岛公信建设监理有限公司临沂育才公司临沭陆河社区监理项目部、青岛恩地建设咨询有限公司临沭爱琴海监理项目部、临沭县苍马建设监理有限公司世纪新城二期监理项目部。以上三个监理公司所监理的工程，在检查时总监及监理人员不能到位，存在监理资料内容不全，填写不规范等诸多问题。

四、有关工作要求

（一）全面排查治理，切实消除安全隐患。各单位要认真贯彻落实安全生产工作要求，对当前安全生产工作进行再安排、再部署。开展“决战四季度、决胜2019年”专项行动，立即开展安全生产大排查，推动企业认真落实主体责任。对查出的隐患和问题，能立即整改的要立即整改，不能立即整改的要落实安全防范措施，切实做到措施、责任、资金、时限和预案“五落实”，确保隐患整改到位，有效防范各类事故发生。

（二）突出工作重点，加强起重机械管理。本次检查，要突出施工安全生产特别是建筑起重机械管理这个重点，在检查中存在严重问题的起重机械，必须按照要求进行拆除和整改。各施工、监理单位要建立起重机械使用期间每月检查和日常维护管理使用管理制度，防止设备“带病”作业，发现安全隐患，及时消除。加强起重机械管理作为今后一段时期安全管理工作的重点，对存在问题严重且拒不整改的，发现一起将严肃处理一起。

（三）强化管理意识，落实各方主体责任。进一步强化建设工程参建五大责任主体的管理，重点落实建设单位、施工单位主体责任，杜绝质量安全事故的发生。决不能为追求低造价和不合理工期而忽视工程质量安全；决不能为追求低投入而降低工程质量安全；决不能项目管理部形同虚设，项目经理必须真正地到岗履职；决不能使用不合格原材料，以及偷工减料，粗制滥造，建造不合格工程，给社会和用户带来直接危害。
