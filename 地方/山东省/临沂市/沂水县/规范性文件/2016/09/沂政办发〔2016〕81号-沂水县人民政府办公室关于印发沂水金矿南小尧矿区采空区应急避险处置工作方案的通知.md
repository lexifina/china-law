# 沂水县人民政府办公室关于印发沂水金矿南小尧矿区采空区应急避险处置工作方案的通知

沂政办发〔2016〕81号

许家湖镇人民政府，县政府有关部门：

现将《沂水金矿南小尧矿区采空区应急避险处置工作方案》印发给你们，请认真贯彻落实。

沂水县人民政府办公室

2016年9月6日

沂水金矿南小尧矿区采空区应急避险处置工作方案

经技术专家现场勘查认定，沂水金矿南小尧矿区地下采空区存在较大塌陷隐患，且具有不可控性。为确保周边群众生命财产安全，有效实施应急避险，特制定本方案。

一、工作目标

按照特事特办、急事急办、先保安全、后施治理原则，科学规划建设安置房，对矿区地下采空区影响范围内的群众实施搬迁避让；对采空区影响区域实行封闭隔离；进一步建立完善综合防治长效机制，确保地下采空区治理不发生问题。

二、工作措施

(一)划定影响范围。依据《沂水县废弃矿井采空区核查报告》,组织矿山安全方面专家及技术人员对地下采空区影响范围进行测定，划定影响范围。划定原则为：以《沂水县废弃矿井采空区核查报告》中确定的影响线为基准，预留10米误差外延后再外延10米划定隔离线，隔离线以内区域确定为影响范围。组织影响范围内的群众全部转移到安全地带，并提供临时住所，保障基本生活；对群众自行解决住房的，给予相应房屋租赁补偿。(责任单位：许家湖镇；配合单位：公安局、安监局、国土资源局、财政局及专家技术组)

(二)落实警示措施。根据划定的影响范围全面设置警戒线

和警示标志，沿警戒线分段设置24小时值班岗，组织人员开展全天候轮流值班巡查，严禁人员跨越警戒线进入影响范围，坚决杜绝群众进入影响范围种收庄稼等。落实灾情监测和灾情速报制度，做好日常预防监测，发现异常情况及时上报。(责任单位：许家湖镇；配合单位：公安局、安监局、国土资源局)

(三)实施搬迁避让。对影响范围内的居民实施搬迁避让；认真做好居民原房屋及其它地上附着物调查摸底登记，做到户主明、底数清；相关搬迁补偿严格按照国家有关规定并参照县内片区建设有关标准执行。安置区规划要科学合理、尊重民意，并进行地质隐患危险性评估；用地手续可按设施农用地办理。相关建设要按标准加快推进，确保群众早日入住。(责任单位：许家湖镇，配合单位：住建局、国土资源局、财政局、安监局)

(四)建设隔离围墙。根据划定的影响范围，组织有资质的施工队伍全面建设隔离墙，坚决防止人员进入。隔离墙要科学测算防护高度，应不低于2.2米。隔离墙顶部要加装1米高铁丝防护网，并安置监控设备。按照有关政策对隔离封闭区域内农田实行土地流转。(责任单位：许家湖镇，配合单位：住建局、公安局、国土资源局、财政局、安监局)

三、工作要求

成立以县政府分管领导任组长，相关单位主要负责同志为成员的工作领导小组，统筹协调相关工作开展。相关单位要明确职责，细化责任分工，强化责任落实，抽调专业力量全程参与该区域应急避险处置，确保各项工作有序推进。认真做好治理建设工程的预算、决算和资金使用管理，确保资金使用效益。严格落实建设及监理职责，保证采空区围墙和安置房建设进度和质量，保障施工安全，防止引发次生问题。相关单位要及时做好工作宣传引导，全面普及应急避险知识，进一步提升群众避险意识和安全观念，确保该区域应急避险处置工作有序推进、取得实效。
