# 沂水县民政局关于同意成立沂水县寨子山公共供水协会的批复

沂民字〔2017〕6号

沂水县寨子山公共供水协会筹委会：

你会所报关于成立公共供水协会的材料收悉，经审查材料和现场勘察，所报材料齐全有效，场地设施比较完善，已基本具备了成立条件。经研究，同意成立“沂水县寨子山公共供水协会”。

望协会成立后，认真遵守国家的法律法规，自觉接受登记管理机关和业务主管单位的监管与指导，严格按照《章程》开展活动，依法维护会员合法权益，积极加强自身建设，发挥好协会功能作用，努力为促进镇域经济社会发展贡献力量。
