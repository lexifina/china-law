# 沂水县交通运输局关于农村公路突发事件的应急预案

沂交发〔2017〕8号

为提高突发事件应对能力,控制、减轻和消除农村公路突发事件引起的危害,及时恢复公路交通，根据《安全生产法》、《山东省农村公路条例》及上级有关要求，结合我县农村公路养护管理实际，制定本预案。

一、指导思想

以科学发展观为指导，认真学习贯彻党的十八大、十八届五中、六中全会精神，坚持“安全第一，预防为主，综合治理”的方针，结合我县突发事件总体应急有关事项的精神和市局农村公路系统突发事件应急预案，规范和强化我局对农村公路建设、养护、管理中的突发事件应急工作管理，促进各管理部门形成指挥统一、协调有力、安排有序、决策科学、行动高效、参与广泛的应急管理机制，保障人民群众的生命财产安全，为我县经济建设创造优良的道路运输环境。

本预案所称农村公路突发事件是指：因暴雨、暴雪、冰冻等自然灾害和农村公路上发生的安全生产事故和群体性突发事件等引发的农村公路（桥梁）中断、阻塞的事件。

三、工作职责

1、组织公路（桥梁）防洪、防汛、雪、冰冻抢险及由于自然灾害引发的其他事件。

2、预防和处置公路上发生的安全生产事故和群体性突发事件。

3、维护公路交通秩序，确保公路交通安全畅通。

四、职责分工

（一）应急工作组

应急工作组在应急领导指挥部统一领导下具体承担应急处置工作。应急工作组分为5个应急工作小组：

1、公路抢通小组：由局属相关科室和单位组成。负责组织公路抢修及保通工作，根据需要调度机械及物资；拟定绕行方案并组织实施；负责协调社会力量参与公路抢通工作；拟定抢险救灾资金补助方案；做好除雪剂、防汛编织袋、警示标志牌等防汛物资的储备，并由专人负责管理；承办应急领导小组交办的其他工作。

2、交通安全小组：由局应急指挥中心、安全科和交通监察大队组成。负责对事发地车辆、行人的通行疏导，维护现场交通安全秩序，保障公路安全畅通。

3、运输保障小组：由运输管理处组成。负责协助组织、协调人员、物资的应急运输保障工作。

4、后勤保障小组：由局办公室和事发地交管所组成。负责应急状态期间24小时服务保障工作。

5、新闻宣传小组：由局宣教科组成。负责收集、处理相关新闻报道，及时消除不实报道带来的负面影响，及时通报突发事件影响及应急处置工作进展情况，宣传报道应急处置工作中涌现出的先进事迹与典型。

（二）现场工作组

现场工作组是由应急领导小组指定成立并派往事发地的临时机构。负责具体实施公路抢修及保通工作。

五、应急处置

（一）信息报告

突发事件发生后，事发地交管所应在最快最短时间内报告应急小组。

（二）前期处置

突发事件发生后，事发地交管所应在最短时间内，立即赶往事发地，进行排险和处置，以最大限度减少损失，控制事态扩大。

（三）应急响应

突发事件发生后，指挥部接到报告，经研究分析审定后需动用其它部门的工作组力量时，应向上级部门报告。

各应急工作组接到指令后，应以最快的速度赶赴事发地。

应急小组成员一般情况下应在1小时内到达现场，需要调遣集中待命时，各应急工作小组应在2小时内全部到达指定地点，听候指令。

各单位在指定的时间内到达事发地现场后，统一调度指挥，听从安排，不得以任何借口和理由迟到、缺位，否则，将追究相关人员责任，情况严重的，还将受到党纪、政纪处分。

（四）公路抢险处置

1、一般性处置：事发地交管所先行处置，防止和控制事态扩大。

2、重大事件处置：事发地交管所先行处置后，待应急救援队伍赶到后，统一由指挥部调度指挥，需报告上级部门时，应立即报告，并积极进行抢险。

（五）防汛应急预案

1、人员组织准备。出现险情时，应急工作组迅速合理调配人员，组建防汛抢险突击队，并确保全体成员汛期在本单位24小时集结待命。必须保证人员、机具、车辆、物资最短时间内赶到现场。指挥部要积极与政府部门、派出所、医院取得联系，确保在紧急情况下获得外界增援。

2、车辆物资准备。根据实际情况，公路抢通小组加强协调，做好铁锹、警示标志牌等防汛物资的储备，并由专人负责管理。运输保障小组要提前做好车辆的保养维护工作，确保车辆状况良好，随调随用。

3、通讯保障。加强通讯话务管理和紧急情况下的值班工作，坚持值班报到制度，并随时进行抽查，坚决杜绝脱岗、漏岗现象，确保通讯畅通。应急工作组要实行24小时值班制，随时掌握和逐级上报防汛工作情况，值班领导要坚守工作岗位，干部夜间值班要实行逐级报到制度。

4、巡查保畅。加大巡逻密度，完善快速反应机制，强化施工安全监管，全力预防重特大安全责任事故的发生，确保汛期道路安全畅通。及时掌握天气信息，雨情水情，为防汛抢险提供第一手资料。

（六）暴雪应急预案

1、提前关注未来三天天气预报，做到下雪的气象信息早知道、早准备。

2、巡逻车辆等装备及时检修保养，确保雪天应急预案及时启动。

3、接到暴雪通知后，全体人员提前全部到位，听从指挥部的指挥调遣；同时加大巡逻密度，及时掌握路面积雪、车流量等道路通行情况。

4、准备好安全警示标志，现场需要实施交通管制的时候，及时设置安全警示标志。

5、认真执行值班制度、报告制度；及时报告除雪情况、道路通行情况，确保信息反馈渠道畅通。

6、加强对除雪保畅的所有人员进行安全教育培训，牢固树立“安全第一、加强防范”的思想，避免交通安全事故发生。

（七）紧急情况及处置预案

发生交通事故、挖方路段护坡或山体滑坡造成交通堵塞等其他影响道路畅通、危及大桥安全的突发事件或涉及运送防汛物资、人员的车辆发生事故时，应立即向上级报告，并在指挥部的指挥下参照以上方案采取处置措施。
