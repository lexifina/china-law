# 沂水县供销合作社联合社关于注销沂水县姚店子供销合作社等分支机构营业执照的批复

沂供字〔2017〕6号

沂水县姚店子供销合作社、沂水县院东头供销合作社、沂水县许家湖供销合作社：

你们社报来关于注销分支机构的申请报告已收悉，经县社党组研究决定，因经营手续变更，同意对沂水县姚店子供销社加油站、沂水县姚店子镇供销社桥头加油站、沂水县院东头乡供销社加油站，沂水县院东头供销社为民加油站，沂水县许家湖供销社加油站等五处加油站进行注销营业执照。

沂水县供销合作社联合社

二〇一七年二月十三日
