# 沂水县公安局关于成立基层基础建设三年攻坚战领导小组的通知

沂公通〔2017〕4号

各科、室、队、所：

为全面贯彻落实省厅、市局部署要求，全力推动全县公安机关基层基础建设三年攻坚战扎实有效开展，经县局党委研究，成立基层基础建设三年攻坚战领导小组。现将有关事项通知如下：
