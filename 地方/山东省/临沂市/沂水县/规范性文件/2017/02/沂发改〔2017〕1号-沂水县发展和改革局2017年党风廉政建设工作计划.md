# 沂水县发展和改革局2017年党风廉政建设工作计划

沂发改〔2017〕1号

2017年，是党的十九大开局之年，做好党风廉政建设意义重大。今年工作的总体要求是：全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，深入贯彻习近平总书记系列重要讲话精神，统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，坚决维护以习近平同志为核心的党中央权威，严肃党内政治生活，加强党内监督，推进标本兼治，深化国家监察体制改革，强化监督执纪问责，驰而不息纠正“四风”，保持惩治腐败高压态势，维护好党内政治生态，推动全面从严治党向纵深发展。为切实抓好我局2017年的党风廉政建设工作结合实际，必须扎紧制度笼子，严禁执行监督执纪工作规则，加强领导班子和干部队伍建设，用担当诠释忠诚，以良好精神状态和优异工作成绩迎接党的十九大召开。现将2017年工作计划汇报如下：

一、从严抓思想教育方面。一是加强学习，增强党员干部廉洁自律意识。坚持集中学习制度，及时传达党风廉政建设工作会议精神，部署廉政建设工作计划，突出“两学一做”学习教育，学习《条例》《准则》、中央和省市县关于改进机关作风，密切联系群众的相关文件等，深刻领会新形势下反腐倡廉的重大意义，加强对党员干部的教育，筑牢反腐防线，切实增强党员、干部清正廉洁的自觉性和主动性，做合格党员。二是开展廉政教育专题活动。要结合全局实际，有针对性的开展一些岗位廉政教育、警示教育，通过收听收看报告会、观看廉政电影、组织廉政学习等形式把廉政文化宣传与建设工作融入工作当中，努力在依法从政、廉洁从政，提高服务水平、提升工作效能、加强道德建设上下功夫，进一步增强党员干部廉洁从审的意识和决心。

二、从严抓管党治党方面。一是落实党风廉政建设责任制。签订2017年度党风廉政建设目标责任书，认真落实党风廉政建设责任制进一步强化党组的主体责任和领导干部“一岗双责”责任。二是健全反腐倡廉制度体系。不断深化党务公开，推进政务公开，严格执行领导干部述职述廉制度、个人重大事项报告制度、干部廉政谈话和诫勉谈话制度等制度，通过不断检验和完善，着力提高制度制定的科学化水平，确保反腐倡廉的全面性、针对性、可操作性。切实增强全体干部职工守纪意识和从上至下、从下至上的监督意识。

三、从严执纪监督方面。一是充实党风廉政建设领导小组。充实完善以局长为组长，班子成员为副组长，各科室负责人为成员的党风廉政建设和反腐败工作领导小组，形成局党组统一领导，党政齐抓共管，各科室各司其职的工作格局。把党风廉政建设纳入干部职工年度考核内容。二是明确责任，抓好落实。把党风廉政建设与业务工作紧密结合，研究制定《2017年发展和改革局工作计划》，一起部署，一起落实，一起检查，一起考核，明确局班子成员和各科室负责人的主要工作任务和职责，注重落实，从源头上防治腐败工作。

四、从严抓选人用人方面。一是坚持党管干部原则，坚持正确选人用人导向，落实好干部标准，强化党组织的领导和把关作用，认真执行《党政领导干部选拔任用工作条例》和相关制度规定，规范干部选拔任用工作流程，严格按照规定标准和程序选拔任用干部。二是严格执行领导干部述职述廉制度、个人重大事项报告制度、干部廉政谈话和诫勉谈话制度等制度，严格落实中央《关于防止干部“带病提拔”的意见》，防止干部“带病提拔”的情况。

五、从严抓作风建设方面。一是加强领导干部作风建设。把改进领导干部作风作为我局加强党风廉政建设的重要举措，增强立党为公、执政为民的自觉性和坚定性;从解决干部职工和群众最关心、最现实的利益问题做起，真心实意为干部职工、群众做实事、办好事、解难事。二是推进民主管理。认真执行民主监督机制，定期组织召开班子会议、干部职工会，规范民主管理，继续探索政务公开途径、增强部门管理透明度;每年召开领导班子民主生活会、按时参加县委、县政府和上级党委理论中心组学习，以年度述职述廉会为平台，认真开展领导干部批评与自我批评，主动亮思想，勇于解剖自己，不断提高工作作风。三是进一步加大工作力度，不断推进发改业务工作再上新台阶。拓宽项目融资渠道，抓好资金项目争取管理，争取更多中央预算内资金、国家专项建设基金等政策资金，服务于我县经济社会各项工作发展；抓好重点项目建设，积极申报省、市重点项目，推动“十三五”重点项目建设；抓好服务业发展，加快培育服务业园区、重点服务业项目建设，大力发展服务业企业；抓好精准扶贫工作，全面完成易地扶贫搬迁工作、全面开展光伏扶贫工作；抓好上级政策落实，做好国家级重点生态功能区建设和碳排放权交易工作；抓好规划研究，加强战略性研究、规划性研究以及经济形势的预测分析，切实为县委、县政府当好参谋。

六、从严惩治腐败方面。一是完善各项制度建设，为廉政建设提供保障。通过制定完善《2017年党风廉政建设工作方案》《2017年度发展和改革局绩效考核办法》《沂水县发展和改革局工作制度》等，进一步明确局领导班子和干部职工的工作职责和工作要求。在牵头抓好县里多项重点工作的同时，继续不断完善机关制度、制定档案管理制度、权力清单运行制度、信访接待制度等，积极推动岗位风险点排查机制，真正把各项工作置于阳光之下，置于人民群众的监督之下。主动接受纪委等监察部门监督，落实好与纪检监察派驻组的联席会议制度及重大事项报告制度。二是开展局内廉政风险排查工作，填补制度“空白点”。为进一步加强廉政风险防范，我局将组织对各科室开展廉政风险排查和防控工作，深入排查廉政风险，完善内控制度，开展廉政风险预警，提高预防腐败的针对性和有效性。
