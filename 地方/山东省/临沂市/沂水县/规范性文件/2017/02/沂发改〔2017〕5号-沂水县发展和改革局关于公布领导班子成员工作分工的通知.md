# 沂水县发展和改革局关于公布领导班子成员工作分工的通知

沂发改〔2017〕5号

局机关各科室，服务业办，重点办：

经局党组研究决定，班子成员分工如下：

张希国，局党组书记、局长，主持全面工作，负责全局党风廉政建设。

刘润良，党组成员、服务业办主任，主持服务业办全面工作，分管科室的党风廉政建设。

张德录，重点项目办主任，主持重点办全面工作，分管农村经济科、县域经济科学发展试点（园区经济）工作及分管科室的党风廉政建设。

李海清，党组成员、主任科员，分管工业与高新技术产业科、能源交通和资源环境科、国民经济动员办公室工作及分管科室的党风廉政建设。

刘忠献，党组成员、副局长，分管固定资产投资科、财政金融贸易合作科、政务大厅窗口、廉政建设及党务党建工作及分管科室的党风廉政建设。

崔德收，党组成员、副局长，分管办公室、国民经济与发展规划科、两型办及社会发展科工作及分管科室的党风廉政建设。

赵克，党组成员、副主任科员，分管体制改革综合科、“三引一促”及对接市外资科工作及分管科室的党风廉政建设。

沂水县发展和改革局

2017年2月20日
