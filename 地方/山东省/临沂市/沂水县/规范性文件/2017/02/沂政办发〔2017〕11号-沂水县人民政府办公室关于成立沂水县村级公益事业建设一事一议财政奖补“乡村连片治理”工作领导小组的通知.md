# 沂水县人民政府办公室关于成立沂水县村级公益事业建设一事一议财政奖补“乡村连片治理”工作领导小组的通知

沂政办发〔2017〕11号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

为加强对全县村级公益事业建设一事一议财政奖补“乡村 连片治理”工作的组织领导，经县政府研究，决定成立沂水县村 级公益事业建设一事一议财政奖补“乡村连片治理”工作领导小组。现将成员名单公布如下：

组　长：武开鑫　县政府副县长

副组长：王　健　县政府党组成员、跋山水管处党总支书记

成　员：张晓华　县财政局局长

张洪春　县农业局局长

杨振龙　县住建局局长

程培军　县交通运输局局长

杨明升　县环保局局长

邱　键　县文广新局局长

王金亮　县林业局局长

曹传海　县水利局局长

于化凤　县旅发委主任

王　伟　县体育办主任

李政华　县基层财政管理局局长

武　峰　县农村综合改革办公室主任

领导小组下设办公室，办公室设在县财政局，武峰同志兼任办公室主任。
