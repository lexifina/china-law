# 沂水县人民政府办公室关于印发沂水县主要农作物生产全程机械化推进行动实施方案的通知

沂政办发〔2017〕7号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

《沂水县主要农作物生产全程机械化推进行动实施方案》已经县政府研究同意，现印发给你们，望认真贯彻落实。

沂水县人民政府办公室

2017年2月13日

沂水县主要农作物生产全程机械化推进行动实施方案

为认真贯彻落实国家、省市关于开展主要农作物生产全程机械化推进行动相关部署，加快推进全县主要农作物生产全程机械化，进一步提高农业机械化发展水平，特制定本实施方案。

一、发展思路与目标任务

(一)发展思路

牢固树立创新、协调、绿色、开放、共享的发展理念，围绕转变农业发展方式的总要求，以提高主要农作物生产全程机械化为目标，以小麦、玉米、花生、林果、黄烟等作物为主要内容，着力从耕整地、播种、植保、收获、秸秆处理等重点环节推广先进适用的农机化技术装备，加快推进农作物全程机械化发展和农业转型升级。

(二)目标任务

1、着力推进小麦、玉米等主要粮食作物生产全程机械化。主攻方向：重点提升机械化水平和机械化作业质量，主攻高

效低损收获、宽幅精量播种、干燥机械化、保护性耕作、秸秆综合利用和精准施肥、高效植保。

发展路径：大力推进机械化示范基地，充分利用农机购置补贴、农机报废、农机深松作业政策、保护性耕作项目、基层农机推广补助项目等政策项目，加快推进小麦、玉米播种机、联合收获机换代升级，大力推广应用宽幅免耕精量播种机，并依托小麦联合收获和玉米联合机械化收获等措施全面实行秸秆还田。重点打造典型农机合作社，以合作社为引领推行小麦、玉米机收、秸秆切碎还田、免耕播种“一条龙”作业模式。努力提升玉米机收水平，发展玉米秸秆青贮收获机械化。推进种肥同播、统防统治，推广自走式喷杆喷雾机、植保无人机等现代植保机械，提高施肥、植保机械化、精准化水平。

目标任务：到2020年，小麦免耕播种覆盖率60%以上，玉

米联合机收率80%以上，玉米贴茬直播率95%以上。

2、加快推进花生等经济作物生产机械化。

主攻方向：机械播种、联合收获。

发展路径：在推进耕整地、机械播种、灌溉、植保、施肥等环节机械化技术的基础上，加快推广应用多垄多行大型花生精确 播种联合作业机械、联合收获机械，推进花生种植与收获规范化、规模化生产。

目标任务：到2020年，花生联合收获机保有量110台以上，完成花生联合机收1.5万亩以上。其中，杨庄镇、马站镇、四十里镇、高桥镇等重点乡镇全程机械化程度达到85%以上，带动整个发展区域75%以上。通过花生生产全程机械化重点突破，积聚经验，探索路子，带动提升蔬菜、茶叶等经济作物生产全程机械化水平。

主攻方向：高效植保、机械修剪、机械化采收。

发展路径：以苹果、桃、葡萄为突破口，在重点种植乡镇，围绕中耕、施肥、植保、修剪、采收和田间转运等环节，坚持科研开发与引进示范相结合，大力推广果园开沟施肥机、割草控草机、高效弥雾风送防漂移打药机械、新型果园多功能作业机具或通用平台等配套机械装备，助力现代果业发展。

目标任务：到2020年，在全县重点乡镇建设的示范基地中，通过示范园区辐射带动，大幅度提升果业全程机械作业水平。

4、继续巩固提高黄烟生产机械化水平。

主攻方向：围绕育苗、机耕、移栽、植保、收获、烘烤和拔杆等环节，提高烤烟机械化生产综合水平。

发展路径：完善农业机械设备。在原有的大型拖拉机、微耕机、起垄施肥机、覆膜机、植保机械、拔杆机等基础上，加强黄烟种植收获机械的政策倾斜力度，积极引进其他相关先进设备；提高机械操作能力。注重适应地形进行机械配套，注重小型、通用型机具推广应用，逐步实现辖区内全程机械化操作。

目标任务：到2020年，在全县重点乡镇黄烟种植示范基地及种植户中，通过新技术、新机具推广，进一步提升黄烟生产机械作业水平。

二、工作重点和保障措施

(一)推进农机装备创新示范。结合我县实际，以实施农机装备研发创新计划和创新示范工程为抓手，充分利用各类社会资源，加大先进农机装备研发创新、示范推广力度。鼓励农机生产企业自主创新积极开展全程机械化试验示范，不断加快先进成熟的粮食和经济作物全程机械化生产技术普及应用。依托山东源泉机械有限公司、沂水沭拖机械有限公司、山东明沃机械有限公司等农机企业研发平台，研发推广适合我县山区丘陵机械化的农业机械，推进深松项目、果园机械化、山区小麦玉米机械化发展。同时，促进农技农艺融合，引导农民科学高效进行耕整地、播种、植保、收获、秸秆处理，为机械化作业创造有利条件。

(二)培育农机新型经营主体。加强以农机合作社为重点的农机社会化服务体系建设，鼓励和支持开展规模种植、跨区作业、订单作业，切实提高主要农作物生产的全程机械化程度。在全县范围内根据合作社经营规模、经营重点等进行分类指导、重点打造。加大对农机合作社理事长、管理人员、财务人员培训力度，引导农机合作社提高规范管理水平。

(三)提高农机信息化水平。开展“互联网+农机”推进行动，通过互联网、移动通讯、大数据、云计算、北斗导航等现代技术和手段，加强农机管理部门、农民和农机手的互联互通，在全县深松项目中深入推广信息化技术，搞好远程控制、调度、监督，提升农机管理服务科技化、信息化和智能化水平，逐步实现对小麦、玉米等秸秆切碎还田作业情况通过现代技术手段进行远程控制、调度、监督，提升全县秸秆切碎还田工作质量。

(四)加强组织领导。加大政策扶持力度，充分发挥购机补贴政策导向作用，对重点技术推广的机械优先补贴。积极开展农机手免费培训，提升农机手的技术水平。各级各有关部门要将推进主要农作物生产全程机械化作为加快现代农业发展的一项重点工作来抓，加强沟通协调，搞好统筹规划，明确发展目标，落实工作任务，形成高效的工作推动机制，积极创建全程机械化示范县。
