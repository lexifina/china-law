# 沂水县市场监督管理局2017年成品油抽检实施方案

沂市监字〔2017〕12号

为加强我县流通领域成品油市场监管工作，根据《临沂市大气污染防治2017年攻坚行动方案》和《临沂市经信委2017年度车用燃油品质专项执法检查工作方案》的要求，结合我县实际，特制定本方案。

一、抽检产品

汽油（车用汽油、车用乙醇汽油）、柴油（车用柴油、普通柴油）。

二、检测机构

选择临沂市工商局油品抽检中标单位作为检验单位，并留存其资质证书复印件入卷。

三、抽样方法及数量

（一）抽样方法

在加油站以购买的方式随机抽取经加油站检验合格或以任何方式表明合格的成品油，抽样时，应采取三方会抽的方式进行抽样。

（二）抽样数量

1、抽样基数：在抽样时，抽样基数应不少于抽取样品量。抽样基数由承检机构抽样人员现场测定。

2、抽样数量：所抽样品须为同一规格、同一批次保质期内的合格品，分为送检样品和备份样品。

3、样品确认无误后，由抽样人员与被抽查单位在抽样单上签字、盖章，当场封存样品，并加贴封条，封条上应有抽样人员签名、抽样单位盖章及抽样日期，样品封存应有必要的防拆封措施。

四、时间节点

年度内抽检全县84家加油站，每月抽检加油站数量不低于总数的30%，每季度抽检覆盖率达到100%。抽检中，对新闻媒体披露的、群众投诉突出的、进货渠道不明的、信誉差的加油站作为监测重点。

五、判定原则

经检验，所抽取样品检验项目全部符合标准要求，则判定该批样品合格；若检验项目中有一项或者一项以上不符合，依据标准要求按照其判定规则进行判定。

六、复检

对检测结果有异议时，可按照《流通领域商品质量抽查检验办法》的相关规定进行复检。复检机构出具的复检结论为最终检验结论。

七、二次抽检

对第一次抽检的加油站样品判定为不合格的，在加油站整改完毕后进行二次抽检。对一年内连续两次抽检不合格的加油站按照《山东省工商行政管理机关规范行政处罚自由裁量权办法（试行）》和《山东省工商行政管理系统行政处罚裁量参考基准》的有关规定，依法吊销营业执照。对销售伪劣成品油涉嫌犯罪的，及时移交公安机关。

八、后续处理

（一）结果公示：按照“谁抽检、谁公布、谁负责”的原则，实施抽检的市场监督管理部门认真总结抽检工作情况，及时依法对外进行结果通报。县局组织的抽检工作，抽检结果通过沂水县政府网站进行公示。

（二）处罚公示：认真落实《山东省工商行政管理机关规范行政处罚自由裁量权办法（试行）》和《临沂市大气污染防治2017年攻坚行动方案》的要求，对抽检不合格的加油站，按照从严、从重、从快的原则，一律按法律规定顶格处罚。严格按照《企业信息公示暂行条例》和《工商行政管理行政处罚信息公示暂行规定》等规定，依法公示案件查处情况。
