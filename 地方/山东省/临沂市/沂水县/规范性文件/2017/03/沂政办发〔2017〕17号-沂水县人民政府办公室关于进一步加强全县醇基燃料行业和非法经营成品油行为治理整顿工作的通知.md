# 沂水县人民政府办公室关于进一步加强全县醇基燃料行业和非法经营成品油行为治理整顿工作的通知

沂政办发〔2017〕17号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

为进一步加强全县醇基燃料在生产、经营、储存、使用、运 输等环节安全监管和打击非法违法经营成品油行为，经研究，决定在全县范围开展集中治理整顿行动，现就有关事项通知如下：

一 、进一步提升工作重视程度

根据危险化学品目录(2015版),汽油和闭杯闪点小于等于60℃的柴油属于危险化学品，醇基燃料是以醇类(如甲醇、乙醇、丁醇等)物质为主体配置的燃料，属易燃易爆有毒物品。非法违法生产经营该类产品，对市场正常秩序、对社会安全影响较大，必须坚决予以整治。各乡镇、街道、沂水经济开发区、沂蒙风情 旅游景区(以下简称“各乡镇”)以及各有关部门要切实提高思想 认识，强化责任落实，严格按照安全生产“党政同责、 一岗双责’ 的要求，采取有效措施和办法，认真做好醇基燃料和成品油行业 非法违法行为整顿打击工作，为全县经济社会发展创造良好环境。

二 、进一步明确安全监管职责

根据《安全生产法》《危险化学品安全管理条例》《成品油 市场管理办法》《山东省安全生产行政责任制规定》等法律法规规定，有关单位职责明确如下：

(一)各乡镇落实属地监管责任，并负责辖区内醇基燃料和成品油行业的排查治理和打非治违工作。

(二)县经信局牵头负责成品油行业领域的管理工作和打非治违工作；负责成品油零售市场的监督管理，查处或会同有关部门查处违规经营成品油行为。

(三)县安监局负责危险化学品生产经营和储存单位的安全生产监督管理，依法查处非法经营危险化学品行为。

(四)县公安局、交警大队负责醇基燃料和成品油的公共安全管理，负责运输车辆的道路交通安全管理，查处非法运输、超载运输车辆；对构成犯罪的非法生产、经营、储存行为依法追究刑事责任。

(五)县市场监督管理局负责核发醇基燃料生产、经营企 业和成品油经营企业的营业执照，对流通领域假冒伪劣醇基燃料 和成品油进行查处，依法对无照经营行为进行查处取缔。负责依 照国家技术标准对醇基燃料和成品油质量进行检测，依照技术标 准对醇基燃料灶具的质量进行监督检测，对其包装物、容器的质量进行监督。

(六)县交通运输局负责醇基燃料和成品油运输车辆的安 全生产监督管理，查处不符合资格条件的运输车辆；负责醇基燃料道路运输企业驾驶人员、装卸管理人员、押运人员的资格认定。

(七)县消防大队负责醇基燃料和成品油生产、经营、储 存、使用单位的消防安全监督管理，对不符合消防安全的行为予以依法查处。

(八)县环保局负责对醇基燃料和成品油生产、经营单位 环评手续办理情况进行检查，对其环境保护法守法情况进行监督检查，对存在的环境违法行为予以依法查处。

(九)县食药监局负责餐饮企业的安全管理，督促有关单位加强管理，做好醇基燃料使用过程中的安全管理。

(十)县住建局负责对城镇燃气的安全管理，负责对公用事业用油的安全管理，依法打击城镇燃气非法经营、使用等行为。

(十一)县热线办及时接报有关醇基燃料和柴油非法生产、 经营、运输、使用等的相关举报，对举报内容了解清楚，及时、准确转交有关部门予以依法处理。

(十二)饭店、宾馆、酒店、小吃部等餐饮行业和医院、 学校等机关团体、企事业单位自用醇基燃料日常安全监督管理，分别由其行业主管部门负责。

三、 进一步加强工作组织领导

各级各有关部门要认真对照职责分工，进一步明确责任、明 确具体落实责任单位和人员，加大整治工作宣传力度，完善管控 措施，切实将醇基燃料和成品油安全监管工作真正落到实处。各 乡镇要全面做好辖区各类非法违法生产、储存、经营以及使用醇 基燃料餐饮单位、非法经营成品油单位排查摸底，全面建立台账， 并经乡镇主要负责人签字后向安监、经信等相关行业主管部门分 别报告情况。各部门要按照职责分工，及时组织执法人员，或通 过联合执法等方式，对无证无照经营、违规建设储存设施、不符合安全要求运输车辆行驶等行为从严从重查处。

为确保醇基燃料和成品油行业非法违法行为整治工作顺利 开展，县里分别成立醇基燃料和成品油整治工作小组。醇基燃料 整治工作小组办公室设在县安监局，成品油整治工作小组办公室 设在县经信局。各乡镇、各单位要积极参与配合整治工作小组工作，各有关单位要指派两名工作人员在整治工作小组领导下开展具体工作，确保及时消除隐患，有效防范事故发生。
