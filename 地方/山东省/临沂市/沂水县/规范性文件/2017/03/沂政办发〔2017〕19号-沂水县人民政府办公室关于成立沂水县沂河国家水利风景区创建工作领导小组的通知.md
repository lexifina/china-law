# 沂水县人民政府办公室关于成立沂水县沂河国家水利风景区创建工作领导小组的通知

沂政办发〔2017〕19号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

为充分挖掘我县资源优势，全面推进沂河国家水利风景区创建工作，经研究，决定成立沂水县沂河国家水利风景区创建工作领导小组。现将领导小组成员名单公布如下：

组　长：何法江　县政府副县长

副组长：张德博　沙沟水库管理处主任

王本昌　跋山水库管理处主任

曹传海　县水利局局长

成　员：王俊波　县住建局副局长

孟祥升　县环保局主任科员

张国锋　县林业局副局长、防火办主任

武善广　跋山水库管理处副主任

贾佃明　县水利局工会主席

宋贵宝　县旅游委副主任

刘　超　沂城街道办事处组织委员、农办主任

杨　蒙　许家湖镇副镇长

领导小组下设办公室，办公室设在县水利局，贾佃明同志兼任办公室主任。领导小组组成人员因工作调整的，原组成人员自然免除，由新任职人员担任，不再另行发文。
