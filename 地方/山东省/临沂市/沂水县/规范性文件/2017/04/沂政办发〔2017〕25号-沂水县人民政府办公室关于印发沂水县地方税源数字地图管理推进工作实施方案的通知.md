# 沂水县人民政府办公室关于印发沂水县地方税源数字地图管理推进工作实施方案的通知

沂政办发〔2017〕25号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府有关部门：

《沂水县地方税源数字地图管理推进工作实施方案》已经县政府同意，现印发给你们，请认真贯彻落实。

沂水县人民政府办公室

2017年4月11日

沂水县地方税源数字地图管理推进工作实施方案

为进一步适应“营改增”后地方税源管理形势的新变化，积极用好“互联网+”和大数据新技术，我县确定依托“数字临沂”地理空间云地图，将地理信息系统引入地方税源管理领域，以实现税源“可视、动态、精细”管理，特制定本实施方案。

一、工作原则

(一)依法治税原则。在地方税源数字地图管理推进工作中，各有关部门要依法实施监督和协助管理，及时、准确地向地税部门提供涉税信息。

(二)客观公正原则。不断增强执法管理透明度，保障纳税人合法权益，优化税收环境，确保税收征收管理工作顺利进行。

(三)监督制约原则。县地方税源数字地图管理推进工作领导小组要加强工作领导，认真搞好业务指导，多方接受社会各界监督。(四)积极稳妥原则。各级、各有关部门要充分发挥职能作用，积极配合，稳妥有序地开展地方税源数字地图管理推进工作。

二、工作分工

(一)地税部门。负责全面梳理和落实“金三系统”纳税人基本信息和财产登记信息，选取“金三系统”采集的涉税登记信息和需要调查人员调查确认的土地等信息，形成纳税人基本信息调查核实表，并对调查核实表的内容进行认真核实。在核实确认的基础上，将纳税人信息采集到地方税源数字地图管理系统，与国土地理空间云地图进行匹配和定位，完成纳税人在地图上的标识工作。

(二)国土部门。负责提供全县历年来电子版宗地信息台账、国土地理空间云地图(影像图)、宗地电子地图，不动产登记电子信息以及不动产登记电子地图、电子版纳税人土地使用证号明细。

(三)住建及规划部门。负责提供所有建设用地电子数据信息，以及最新规划项目位置示意图(电子规划图)。其他各有关部门以及各乡镇、街道、经济开发区、沂蒙风情旅游景区要配合地税部门做好纳税人基本信息调查、核实、确认以及电子地图具体推广应用等工作。

三、工作保障

(一)强化组织保障。县里成立以县政府分管领导为组长的领导小组，负责统筹协调相关工作开展。同时，建立例会制度，不定期召开会议，研究解决遇到的问题，安排部署下步工作任务。

(二)建立信息交流制度。各有关部门要积极配合地税部门做好本行业、本系统的信息整理、传递工作，要确定一名精通业务的信息员，负责本单位信息传送，实现信息共享。

四、工作要求

各级、各有关部门要充分认识地方税源数字地图管理推进工作的重要意义，及时与地税部门建立密切协作制度，认真提供涉税信息。要多形式搞好工作宣传，引导纳税人积极提供相关涉税信息，配合做好基本信息调查等工作，确保地方税源数字地图管理推进工作有序开展。
