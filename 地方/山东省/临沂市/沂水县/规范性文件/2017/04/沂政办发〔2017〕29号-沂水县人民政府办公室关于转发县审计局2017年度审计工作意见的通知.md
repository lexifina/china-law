# 沂水县人民政府办公室关于转发县审计局2017年度审计工作意见的通知

沂政办发〔2017〕29号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府有关部门：

现将县审计局2017年度审计工作意见转发给你们，请认真组织落实。

沂水县人民政府办公室

2017年4月20日

沂水县审计局2017年度审计工作意见

为切实做好2017年审计工作，根据《审计法》等相关法律法规规定，按照上级审计机关统一部署，结合我县实际，特制定本意见。

一、总体思路

以党的十八大、十八届三中、四中、五中、六中全会精神为指导，深入学习贯彻习近平总书记系列重要讲话精神，认真落实上级审计会议精神，全面履行审计监督职责，紧跟县委、县政府重大决策部署，紧贴事关经济社会发展全局的重大事项，紧扣涉及人民群众切身利益的重大问题，全力推动审计制度改革，大力创新审计方式方法，着力打造审计铁军，充分发挥审计在党和国家监督体系中的重要作用，努力推动全县经济社会科学跨越发展。

二、审计项目安排原则

(一)围绕中心，突出重点。以提高发展质量和效益为中心，继续开展政策落实跟踪审计，注重上级政策落地生根，促进政令畅通；强化财政预算执行审计，注重预算管理规范，促进财税体制改革；深化经济责任审计，注重权力运行监督，推动依法行政和党风廉政建设；突出政府投资审计，注重规范政府投资行为，提高财政资金使用绩效；推进村居干部审计，注重审计结果运用，为今年村“两委”换届打好基础。

(二)创新管理，提升效能。综合考虑上级审计机关安排项目、县委县政府中心工作等，实施“1+N”大项目审计管理模式，将预算执行与经济责任审计、专项资金审计，经济责任审计与专项审计、政府投资审计相结合，实现由单一审计向联动式审计转变，做到同步安排、协同实施、一审多用、成果共享，在减少工作量、节约审计成本的同时，提高审计工作效率。

(三)科学规划，量力而行。根据上级审计机关要求，结合我县实际，合理确定审计项目数量和范围，做到收放结合、松紧适度，为统筹安排上级审计机关和县委、县政府临时交办项目预留工作量；强化计划执行进度管理，从严控制各环节运行时间，着力提高现场审计效率；在审计任务分配上，力求在各领域保持相对均衡，并根据需要适时调整，以增强审计项目计划的灵活性。

三、审计项目计划安排

(一)国家重大政策措施落实情况跟踪审计(署定)。按照上级审计机关的统一部署，持续开展稳增长促改革调结构惠民生政策措施落实情况跟踪审计。重点审计财政存量资金、行政审批制度改革、公立医院综合改革等3类重大决策部署措施落实情况，严肃查处弄虚作假、隐瞒实情、上有政策、下有对策、有令不行、有禁不止，以及重大履职不到位等问题，促进政令畅通。

(二)专项审计和审计调查项目。一是审计署确定项目。对道托镇进行领导干部自然资源资产离任审计，重点关注履行自然资源资产管理和环境保护责任等情况，揭示资源环境领域存在的突出问题。二是省审计厅确定项目。对全县2016年度地方税收征管情况进行审计，重点揭示税收征收管理中存在的问题，查处税收违法行为。对全县非税收入收缴情况进行审计调查，揭示非税收入管理中存在的普遍性和倾向性问题，提出加强和规范管理的审计建议。三是自定项目。对全县农村义务教育及幼儿园经费进行专项审计，进一步完善教育财务管理机制，健全农村中小学及幼儿园资金支付管理制度，推动我县农村义务教育及学前教育健康发展。

(三)财政预算执行审计。对县财政2016年度预算执行和其他财政收支情况进行审计，并对县物价局、城管执法局、畜牧局、住建局、民政局、经信局、农业局、司法局等8个部门预算执行情况进行审计。重点关注财政收支的真实合法效益、重点专项资金绩效，以及贯彻中央八项规定精神情况，推动财政政策更加积极有效和深化财税体制改革。

(四)领导干部经济责任审计。受县委组织部委托，对50名领导干部进行任期经济责任审计，其中离任审计39名，任中审计11名。重点关注领导干部守法、守纪、守规、尽责情况等。通过审计，促进领导干部依法作为、主动作为、有效作为，更好地服务全县改革发展大局。

(五)政府投资建设项目审计。对全县40个政府投资建设项目进行审计，重点关注建设项目的投资管理、建设管理各个环节以及建设资金筹集、使用的合法性、真实性、效益性，及时查处、纠正项目建设过程中存在的问题，保障建设资金效益，减少损失浪费。

(六)村居干部经济责任审计。根据全市村级督查试点要求，扎实开展第二轮村居干部经济责任审计，对全县1206个独立核算村进行审计。通过审计，进一步强化村居干部的规矩意识，加强农村基层党风廉政建设，推动农村社会和谐稳定。

四、工作要求

(一)严格执行计划，确保完成任务。各级、各有关各部门要从发展大局出发，牢固树立责任意识，高度重视审计工作，自觉接受审计监督，全力支持配合审计部门开展工作，保障审计项目顺利实施。审计部门要严格执行审计项目计划，结合本年度确定的实施项目，及时编制审计工作方案，明确任务、突出重点，细化分工、落实责任，确保按时保质保量完成各项审计任务。

(二)创新方式方法，提升审计质量。财政预算执行、地方税收征管、非税收入收缴等审计(调查)要全部运用AO系统开展审计，拓展审计查处问题整改的深度和广度。经济责任审计要继续采用与组织部门三联合模式，提升经济责任审计成效。政府投资建设项目审计、领导干部自然资源资产离任审计要坚持开门搞审计，积极吸收专业人员参与，着力提高审计工作质量和效率。

(三)突出审计质量，规避审计风险。牢固树立质量意识，把牢审计质量“生命线”。在审计过程中，严格执行《审计机关审计项目质量控制办法》,加强审前、审中、审后的监督检查，加大复核、审理力度，确保审计质量全程控制。严格执行审计业务会议制度，把好审计质量关，规避审计风险。
