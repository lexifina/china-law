# 沂水县人民政府办公室关于进一步繁荣全县群众文化活动的通知

沂政办发〔2017〕33号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各有关部门：

为进一步完善公共文化服务体系，提高群众精神文化生活满意度，现就进一步繁荣全县群众文化活动有关事宜通知如下：

一、扎实推进公共文化设施免费开放工作

各级各有关部门要按照上级规定要求，积极推进公共文化场馆免费开放，做到普及化、均衡化、优质化。县文化馆要在工作日免费开放，图书馆、电子阅览室、尼山书院每周开放时间不少于56小时，县博物馆每周开放时间不少于6天；乡镇文化站、社区综合文化服务中心(文化大院)每周免费开放时间不少于48小时。同时，要积极开展儒家讲堂、专题讲座、“四点半”学堂等特色活动，充分发挥阵地作用，创新服务形式，丰富文化内涵，让广大群众共享文化发展成果。

二、深入开展千场公益演出送基层和电影标准化放映活动

要以群众满意为出发点和落脚点，深入开展好公益演出和电影放映活动。按照“形式多样、雅俗共赏、推陈出新、常演常新”的要求，以县文化馆为主体，以各级文艺团体、庄户剧团为补充，积极开展千场公益演出送基层活动，确保每个村居(社区)每年文艺演出不少于2场，全县全年演出不少于2000场次，打造群众文化活动品牌。积极落实国家“2131”工程要求，坚持抓点带面、梯次推进，加速有关村居(社区)标准化放映点建设进程。各乡镇要借助广播喇叭“村村响”工程平台，开展电影映前宣传，提高群众知晓率，扩大群众参与面，全年放映电影不少于1.2万场次。

三、全力抓好精品文艺创作工作

坚持围绕中心，服务大局，做好“文化+”文章。围绕全县“125”工程，积极开展主题创作，采取舞蹈、相声、小品、书画展等形式进行全面展示，打造对外宣传推介、展示沂水形象的“文化名片”。以党的十九大召开、建军90周年等重要时间节点为主题，创作一批体现社会主义核心价值观、弘扬时代精神和沂蒙精神，传递正能量的优秀文化精品。县文化馆年创作戏剧、曲艺、文学、书画等作品分别不少于20件；各乡镇年创作各类文艺作品不少于10件，力争实现“一镇一作、一村一品”。

四、积极实施广场舞辅导“百千万”工程

针对广场舞在城乡日益繁荣的实际，各级、各有关部门要科学组织，规范引导，有序推进，进一步延伸服务触角，积极推进实施广场舞辅导“百千万”工程。由县文广新局牵头，优选100名左右的文艺辅导志愿者，在全县各行政村开展广场舞培训活动1万场以上。各级、各有关部门要按照分类指导、因地制宜的原则，结合实际合理划分培训辅导点、确定文艺辅导志愿者数量，在各村居按要求开展高标准、高质量的广场舞辅导培训，确保取得实效。每位志愿者负责1个辅导点的广场舞培训工作，培训广场舞节目不少于3个，每年接受县级培训不少于2次，每村每年培训不少于10次，每次培训不少于3小时，培训人员不少于10人。

群众文化工作是社会文化的基础和主体，是全县文化工作的重要组成部分，各级各有关部门要切实加强组织领导，层层落实工作责任，形成同频共振、齐抓共管的工作格局。县文广新局要进一步强化工作协调、业务督导，对相关群众文化活动开展情况进行动态监督，搞好情况调度、工作考评，努力促进全县群众文化活动开展扎实深入、富有成效。

沂水县人民政府办公室
