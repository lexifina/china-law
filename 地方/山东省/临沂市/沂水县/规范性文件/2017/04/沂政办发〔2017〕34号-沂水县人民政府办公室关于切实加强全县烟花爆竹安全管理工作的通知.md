# 沂水县人民政府办公室关于切实加强全县烟花爆竹安全管理工作的通知

沂政办发〔2017〕34号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

4月25日，市政府办公室下发了《关于切实加强烟花爆竹安全管理工作的通知》(临政办字〔2017〕48号),通报了市公安局、安监局对9家烟花爆竹批发企业进行突击检查情况，要求进一步强化烟花爆竹“打非”工作力度，严查企业利用半成品进行非法组装烟花等非法违法行为。按照市里工作要求，结合我县实际，现就做好全县烟花爆竹安全管理工作通知如下：

一、认真部署，立即安排，全面开展烟花爆竹“打非”排查专项行动。根据省政府办公厅《关于深入开展企业安全生产主体责任落实情况专项执法检查的通知》(鲁政办字〔2015〕249号)以及市里相关工作要求，进一步强化“守土有责、守土尽责”意识，认真落实“属地管理”责任，不断强化烟花爆竹“打非”工作。县安委会办公室要牵头抓紧制定排查方案，明确责任、细化措施，全面压实烟花爆竹安全管理工作。各乡镇、各有关部门要立即成立烟花爆竹“打非”工作领导小组，迅速组织开展彻底排查检查。沂城街道、道托镇要严格搞好辖区烟花爆竹批发企业储存仓库检查力度，特别要严查烟花爆竹批发企业是否采购纸箱、纸筒、效果件、黑火药、引火线等半成品、原材料，是否违规在仓库内进行加工组装活动；同时，要对仓库内所有烟花类成品进行逐一核查，凡不具备合法购买合同和道路运输许可手续的，一律认定为非法产品，坚决采取严厉果断措施进行处理。安监、公安、市场监管等部门要根据各自职责，重点排查城乡结合部、城中村、烟花爆竹传统村、出租房屋、废旧厂房、封闭式院落、废弃养殖场、集贸市场等可能出现非法生产、经营、储存烟花爆竹行为的场所，确保无盲区、无漏点。

二、追根溯源，一查到底，依法严肃查处烟花爆竹各环节非法违法行为。加强对非法违法生产、经营、运输行为的源头治理，对生产、经营、运输各环节查获或者事故暴露出的非法行为，一律进行倒查，坚决查清其原材料来源、销售、运输渠道，彻底切断非法行为利益链条。对非法生产烟花爆竹的，要认真查清药物来源和产品销售渠道；对非法经营烟花爆竹的，要深入追查产品来源，查出非法生产窝点；对非法运输烟花爆竹的，要同时追究发货方和托运人的责任。要认真贯彻落实《最高人民法院最高人民检察院公安部国家安全监管总局关于依法加强对涉嫌犯罪的非法生产经营烟花爆竹行为刑事责任追究的通知》(安监总管三〔2012〕116号)精神，对组织、参与非法生产、经营、运输、储存烟花爆竹行为构成犯罪的，要及时提请司法机关依法追究刑事责任。

三、明确重点，依法履职，切实加强烟花爆竹经营企业安全监管。各乡镇、各有关部门要明确重点，从源头上严格把关，切实强化烟花爆竹经营企业安全监管，严格规范企业经营行为。要 深化烟花爆竹经营环节专项治理，坚决落实批发企业“六严禁”和零售点“两关闭”、“三严禁”工作要求。严把零售店许可审批关，严禁零售点“下店上宅”、“前店后宅”和连片经营，从严控制零售店数量。要依法加大对各类违法违规行为的处罚力度，对转包分 包、“三超一改”以及视频监控系统不正常运行的，要按法定上限给予经济处罚，并暂扣经营许可证。凡在储存仓库内从事非法加工生产活动的，一律吊销经营许可证、工商营业执照，并组织实施关闭；构成犯罪的，要提请司法机关依法追究刑事责任。对涉案企业依法决定取缔关闭的，所储存烟花爆竹要及时上报县政府相关部门，在两个月内协调处置完毕，彻底消除安全隐患。

四、落实教育，强化培训，进一步加大烟花爆竹安全宣传引导工作力度。各乡镇、各有关部门要以主流媒体滚动播出、流动宣传车和村组大喇叭广播、在乡村集市等主要公共场所张贴警示标语等多种形式，全面发动群众积极举报非法违法生产、经营、运输、储存烟花爆竹线索。要积极宣传非法违法生产、经营、运输、储存、燃放烟花爆竹引发事故的惨痛教训以及典型案件调查处理问责结果和刑事追责案例，充分发挥典型事故和案件的警示与震慑作用，切实提高震慑力，引导广大群众自觉抵制、主动举报相关非法违法行为，坚决杜绝烟花爆竹非法违法生产行为。

沂水县人民政府办公室
