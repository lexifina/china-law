# 沂水县旅游发展委员会关于同意设立山东旅游有限公沂水营业部的批复

沂旅委发〔2017〕7号

山东旅游有限公司：

你单位关于设立山东旅游有限公司沂水营业部的申请材料收悉，根据《旅游法》、《旅行社条例》有关规定，同意你单位设立山东旅游有限公司沂水营业部。

请你单位做好对营业部的日常管理工作，确保严格按照相关法律法规开展业务。

特此批复。

沂水县旅游发展委员会

2017年4月13日
