# 沂水县供销合作社联合社关于同意入驻“供销e家”地方平台的批复

沂供字〔2017〕17号

沂水供销宜家电子商务有限公司：

你公司《关于入驻“供销e家”地方平台的申请》已收悉。经研究决定，同意授权你公司作为我县唯一一家电商企业入驻“供销e家”地方平台，负责运营和管理，并承担由此产生的相关法律责任。

希望你们认真做好“供销e家”的产品运营管理，严格执行产品审核标准，做到依法依规诚信经营；主动承担地方平台综合服务网点开发，加快构建新型农村电商体系；全力营造覆盖面广、组织紧密、功能完善、服务专业，具有供销合作社特色的农产品和农村电子商务经营服务平台，显著提升服务“三农”能力。

特此批复。

沂水县供销合作社联合社
