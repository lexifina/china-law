# 沂水县供销合作社联合社关于印发《沂水县供销社安全生产风险分级管控与隐患排查双重预防机制建设两个体系建设实施方案》的通知

沂供字〔2017〕18号

各基层社、县直属企业：

根据上级关于进一步加强安全生产风险分级管控与隐患排查治理两个体系建设工作的要求，结合系统实际，制定《沂水县供销合作社联合社安全生产风险分级管控与隐患排查治理两个体系建设实施方案》，现印发给你们，请认真贯彻实施。

沂水县供销合作社联合社

二〇一七年五月二十五日

沂水县供销合作社联合社安全生产风险分级管控与隐患排查治理两个体系建设实施方案

为贯彻落实上级关于进一步加强安全生产风险分级管控与隐患排查治理两个体系建设工作的要求，按照《沂水县安全生产委员会办公室关于印发＜安全风险分级管控与隐患排查治理双重预防机制建设深化年活动方案＞的通知》（沂安办发[2017]39号）的要求，进一步加强系统安全生产风险分级管控与隐患排查治理两个体系（以下简称两体系）建设工作，制定本方案。

一、指导思想

全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，深入学习贯彻习近平总书记、李克强总理关于安全生产系列重要讲话精神，严格落实上级重大举措和断然措施，牢固树立安全发展观念，强化安全生产责任落实，在系统各企业建立风险分级管控体系，全面排查、辨识、评估安全风险，落实风险管控责任，实现对企业风险点实施标准化管控，建立完善隐患排查治理体系，全面排查、及时治理、消除事故隐患，实现对隐患排查治理实施闭环管理，提升安全生产工作水平，确保系统安全生产形势进一步持续稳定。

二、目标任务

（一）建立风险查找机制，全面排查安全风险。坚持关口前移、重心下沉，明确风险点查找、辩识工作的范围和工作要求，全面分析可能发生事故的部位和关键环节，找准、找全安全生产风险点。各企业要制定完善安全风险点查找指导手册，明确安全风险查找的具体依据和标准，要依据指导手册彻底地排查各类安全风险，确保不留死角和盲区，切实查清风险点的分布情况，并建立完整台账。

（二）建立风险研判机制，科学应对安全风险。各企业要经常性组织开展安全风险研判常识培训，提高风险研判工作的科学性、准确性和有效性，更好地指导安全风险管控工作。要综合考虑起因物、诱导性原因、致害物、伤害方式等，合理进行风险分类。

（三）建立风险预警机制，增强风险防控的主动性。充分应用大数据等信息技术，加强安全管理，加强预测预警，对发现的风险点和安全隐患，做到早预警、早干预，及时整治，增强风险管控的主动性和预见性。建立安全生产风险公告制度，要在醒目位置和重点区域设置安全风险公告栏，标明主要安全风险、危害因素、风险预防、事故后果和应急措施等内容。

（四）建立风险防范机制，分级分类管控风险。对排查出的安全风险点，实施跟踪管控，综合运用各种防范手段，建立健全有序高效的防范流程。根据风险评估结果，按照分区域、分类别、分级别网格化的原则，实施风险差异化管理。按照重大风险优先、循序渐进、动态管理原则，实行分级管控。各企业要根据风险研判结果，针对不同类型的安全风险点，从组织、制度、技术、应急等方面，采取有针对性的防范措施，确保把风险消灭在萌芽状态。要针对设备、物品、场所和岗位，定期开展风险评估，建立分级管控制度，制定落实安全操作规程。

（五）构建风险处置机制，确保风险可防可控。制定事故初期处置的程序和基本步骤，强化一线人员在事故初期第一时间化解险情和自救互救的能力。针对不同类型风险点和可能发生的情况，制定科学周密的应急预案，并定期组织有针对性的应急演练和人员避险自救培训，提升应急救援战术水平和科学救援能力。

（六）构建风险责任机制，落实安全管控责任。各企业主要负责人是本企业风险管控工作的第一责任人。要建立安全风险管控责任制，划分最小安全风险网格单元，落实全员网格化管理责任。要制定安全风险排查清单，明确和细化安全风险排查的事项、内容和频次，并将责任逐一分解落实。严格实行责任倒查和责任追究，促进安全生产风险管控主体责任和监管责任落实。

三、具体内容

（一） 经营场所和出租厂房。健全安全管理制度和操作规程，建立隐患清单、责任清单、整改清单；操作人员持证上岗，生产场地和车间张贴安全警示标识，消防器材足量配备，加强员工培训，制定科学周密的应急预案，并定期组织有针对性的应急演练和人员避险自救培训，提升应急救援战术水平和科学救援能力。

（二）出租仓库。建立健全安全管理制度，建立隐患清单、责任清单、整改清单；张贴安全警示标识，配备足量消防器材，定期巡查网点、仓库货物存储情况，严禁存储有毒有害和危险化学品。制定科学周密的事故应急预案，并定期组织有针对性的事故应急演练和人员避险自救培训，提升应急救援实战水平和能力。

（三）出租门店。承租人要合法经营，货架商品摆放整齐，禁止店外经营和超范围经营，严禁经营危险化学品；禁止私拉乱接电线和使用大功率电器，禁止店内生火做饭；配备灭火器械并摆放明显位置，在店内显眼位置张贴安全警示标识。

四、工作要求

各企业要认真学习领会深入开展“两体系”建设、纵横推进“两进四化”的重要意义，进一步提高思想认识。要紧密结合企业所从事行业实际情况，按照县社制定的“两体系”建设工作实施方案要求，认真抓好落实，不断完善、提升“两体系”建设工作水平，逐步形成“点、线、面”有机结合，安全生产风险分级管控的机制、措施更加精准有效，事故防范和安全管理能力进一步提升。县社将对企业工作开展情况进行定期或不定期检查督导，对被动应付、体系建设落后的给予通报批评并限期整改。
