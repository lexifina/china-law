# 沂水县市场监督管理局2017年度工业产品生产企业“双随机”监督检查计划

沂市监字〔2017〕14号

为进一步加强全县工业产品生产企业日常监督检查工作，强化事中事后监管，促进依法履责，督促工业产品生产企业落实产品质量主体责任，根据《中华人民共和国产品质量法》、《山东省工业产品生产企业监督检查实施细则（试行）》、《山东省质监局关于推进“双随机、一公开”监管工作的指导意见》及省、市局文件要求，结合我县工业产品质量监管实际，特制订2017年度工业产品生产企业日常监督检查计划，请认真抓好落实。

一、总体要求及原则

为进一步创新事中事后监管方式，2017年度工业产品生产企业日常监督检查全面采用“双随机、一公开”监管模式，以公开、公正、透明为原则，采取随机方式抽取被检查对象和检查人员，并及时公开检查结果。

二、实施主体及被检查对象

本计划实施主体为县局综合执法大队，被检查对象为辖区内工业产品生产企业，被抽查出企业若为庐山工业园区所属企业，由服务企业办负责检查处理。

县局《2017年度生产许可证获证企业等重点工业企业及资质认定检验检测机构监督管理工作实施方案》（沂市监字〔2017〕9号，以下简称《方案》）中已列入重点工业企业日常监督检查计划的生产企业，按照《方案》要求开展日常监督检查工作。

其他未列入《方案》的工业产品生产企业，按照本计划规定的检查数量、频次、时间节点开展日常监督检查工作。

三、检查方式及内容

（一）根据全国企业信用信息公示系统提供的底数，确定对装饰装修材料、建筑材料、机械设备及配件等15类产品开展日常监督检查，具体抽查频次、时间节点等见2017年度工业产品生产企业日常监督检查计划表（见附件1）。

（二）检查工作按照《山东省工业产品生产企业监督检查实施细则（试行）》规定的程序和内容实施监督检查，采取“双随机”模式开展。在实施监督检查前要以送达（或邮寄、传真）《监督检查通知书》或电话通知等任一方式通知被检查企业，并告知监督检查的有关内容及要求（检查所需表格见附件2-4）。

四、工作要求

（一）检查工作要严格落实“双随机、一公开”要求，将检查计划输入《山东省质监局“双随机”系统》，依据建立的“工业产品生产企业目录库”和“检查人员库”，随机抽取检查企业和检查人员，按照《山东省工业产品生产企业监督检查实施细则（试行）》规定的程序和内容实施监督检查。

（二）严格执法，发现问题及时处理。对监督检查中发现的问题应依法依规及时处理，能现场整改的要求企业立即整改，不能现场整改的要责令其限期整改，对发现存在的违法行为要依法严肃查处。注意保存好检查影像资料和检查档案材料。

（三）落实省市局会议精神，全面开展双随机检查，进一步推进质量监督信息化管理，继续抓好“山东省工业产品质量监督管理系统”使用，结合专项检查整治等重点工作，做好企业摸底调查、执法检查等信息录入，以信息化手段促进监管工作有效开展。

综合执法大队和服务企业办负责对辖区内工业企业的基本信息、产品信息、监督检查信息的核实、录入，负责监督抽查后处理信息、产品质量案件信息的录入和更新；产品质量监督科负责县抽信息的录入，负责对被抽检企业产品信息的核实、录入和更新。对国抽、省抽、市抽及县抽不合格企业的后处理工作由综合执法大队、服务企业办按照《山东省产品质量监督抽查工作规范》《临沂市产品质量监督抽查办法(试行)》要求进行后处理，并及时将后处理结果录入山东省工业产品质量监督管理系统。

监督检查信息按照“谁检查、谁负责、谁录入”的要求，于检查结束后5个工作日内，将监督检查情况录入系统。2017年1-5月监督检查信息、产品质量案件信息请综合执法大队、服务企业办于5月31日前录入系统。系统内现有生产企业的基本信息*必填项的先行核实可登陆全国企业信用信息公示系统（账号、密码见附件5）查询企业基础信息及年报情况。先行核实工作于6月底前完成，系统内其他信息根据“双随机”检查情况随时进行补充和完善。
