# 沂水县人民政府办公室关于成立沂水县土地整治项目实施领导小组的通知

沂政办发〔2017〕37号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

为切实加强对全县土地整治项目实施工作的组织领导，及时研究解决项目选址规划、资金整合、权属调整、工程结算与财务决算审计等重大问题，统筹协调部门职责分工，确保资金投入到位、技术指导到位、监督管理到位，经县政府研究，决定成立沂水县土地整治项目实施领导小组，现将成员名单公布如下：
