# 沂水县人民政府办公室关于印发沂水县2017年度地质灾害防治工作方案的通知

沂政办发〔2017〕40号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府有关部门：

现将《沂水县2017年度地质灾害防治工作方案》印发给你们，望认真抓好贯彻落实。

沂水县人民政府办公室

2017年5月5日

沂水县2017年度地质灾害防治工作方案

为切实做好2017年度地质灾害防治工作，最大限度地减少和避免地质灾害给人民生命财产造成的损失，根据《地质灾害防治条例》(国务院令第394号)、《山东省地质环境保护条例》《山东省地质灾害防治方案》及上级有关工作要求，结合我县实际，特制定本方案。

一、2017年我县地质灾害趋势预测

根据我县1:50000比例尺地质灾害调查，结合地形、地貌、地层岩性、地质构造、降水以及人类工程活动引发地质灾害的可能和强度等因素进行综合预测，在主体地质环境背景基本未变的条件下，汛期地质灾害隐患点发生崩塌、滑坡、泥石流等地质灾害的可能性较大。除自然因素外，铁路、公路、水渠及其他工程建设中的不合理开挖、切坡、爆破震动以及不适当的堆渣、弃渣、填土都可能增加崩塌、滑坡、泥石流发生的可能性。另外，未经治理的地下开采停产矿山采空区引发采空塌陷、地面变形或地裂缝的可能性较大，开发中形成的渣石堆、尾矿库具备形成渣石流的条件，如遇短时间强降雨，发生渣石流的可能性较大。

二、我县地质灾害高发时间

根据地质灾害基础调查，结合我县地质环境特点和以往地质灾害的历史记录，我县突发性地质灾害的发生常与降水密切相关。突发性的崩塌、滑坡、泥石流多发生在5月至9月的汛期，其中6月到8月为地质灾害高发期。具体灾害发生情况将受降雨量控制，当连续降雨达到150毫米或日降雨达100毫米以上时，崩塌、滑坡、泥石流灾害很易发生；当连续降雨达到200毫米或短时间(1日或数小时)降雨达150毫米以上时，崩塌、滑坡、泥石流灾害将可能大量发生。采空塌陷，全年都有可能发生，应加强防范，提早预防。

三、我县地质灾害的发育特征

(一)崩塌：以中小型为主，多发生在坡度为50°以上的陡坡，主要诱发因素是降雨、地表水冲刷以及切坡、采矿等人为工程活动。

(二)滑坡：以小型为主，中型次之，平面形态多呈不规则和舌形，主要分布在山区、斜坡，坡度大多在20°—50°之间，常发生在软质岩体和软硬相间的岩体构成的斜坡，主要诱发因素是降雨、地表水冲刷以及建筑切坡、采矿等人为工程活动。

(三)泥石流：以小型、沟谷型、降雨型、稀性泥石流为主，主要分布在山区、狭谷、沟谷斜坡地带，主要诱发因素是不合理的采矿、修路弃渣弃土、过度砍伐林木等人类工程活动以及强降雨，每年7月发生频率最大。

(四)采空塌陷和地裂缝：以小型为主，采空塌陷主要分布在金矿、铁矿区，诱发因素主要是地下采矿形成大面积采空区；地裂缝主要分布杨庄镇的汞丹山，为地下采矿活动引发。

(二)我县地质灾害防范重点

根据我县正在实施的地质灾害隐患点搬迁避让、治理情况和1:50000比例尺地质灾害大排查成果，将16处地质灾害隐患点确定为2017年沂水县地质灾害防治重点(见附件)。

五、工作要求

(一)加强领导，落实责任。按照“属地管理、分级负责、政府是地质灾害防治责任主体”的原则，各乡镇主要负责人对本地区的地质灾害防治工作负总责，要将地质灾害列入重要议事日程，厘定地质灾害防治事权划分和责任边界，细化实化防治责任，规范应急处置的主体、秩序、权限和责任。各级、各有关部门要认真对照县里明确的防治区域和重点，逐一确定监测、预防责任人，层层落实管理责任制，确保万无一失。县国土资源局要牵头抓好全县面上防治工作措施落实，并会同住建、水利、交通、旅游、林业等部门搞好地质灾害责任鉴定、纠纷调处和防治工程监督、检查；要会同乡镇、村居和企业加强对地质灾害危险区、易发区的动态监测，搞好群测群防。安监部门要督促矿山企业严格落实隐患整改治理措施，确保生产安全。县旅发委要充分考虑汛期降雨可能引发的地质灾害安全问题，科学合理地安排相关旅游活动。矿山企业要加强矿山地质环境监测，制定突发地质灾害应急预案。各有关乡镇、各有关部门要安排必要的资金用于突发性地质灾害应急调查和治理，对因工程建设等人为活动引发的地质灾害治理费用，要按照“谁开发、谁治理”的原则由责任单位承担并限期治理。

(二)搞好调查，编制预案。各有关乡镇要对辖区内的地质灾害隐患点进行全面排查，及时制订防治预案，积极开展汛期应急避险演练。同时要加强地质灾害防治宣传培训工作，全面普及预防、避险、自救、互救、减灾等知识，提高应对突发灾情、险情的能力。要配合县国土资源局把“防灾工作明白卡”和“避险明白卡”发放到地质灾害防灾责任单位、负责人和可能受灾害威胁的群众手中。对已出现突发性地质灾害前兆、可能造成人员伤亡或财产损失的区域，有关乡镇和部门要及时采取防治和避让措施，并按程序上报致灾原因、危害、发展趋势、防治措施。

(三)完善机制，加强联动。各级、各有关部门要进一步完善应急工作机制、应急救援体系，做好灾情、险情应急处置工作。县国土资源局要加强与气象局、地震局、电视台的联系，牵头建立和健全地质灾害气象预报会商和预警联动机制，进一步完善信息发送渠道，及时向地质灾害易发区、隐患点防灾责任人发送雨情、水情、震情等地质灾害预警信息；要加强与有关地勘单位的联系，充分发挥其专业技术力量的作用，为地质灾害应急防治提供技术支撑和服务。各相关单位要履职尽责，汛期实行24小时值班制度，如遇突发地质灾害险情灾情，要立即做好抢险救灾等工作，并按规定迅速上报情况，切实提高地质灾害综合防治水平。县地质灾害防治值班电话：2230786。

(四)落实节点，加快推进。废弃矿井地下采空区防治和安全隐患区治理项目已列入全县2017年度民生重点工程，所在乡镇要倒排工期，加快推进施工进度，确保按节点完成治理任务。对已完成地质灾害搬迁的夏蔚镇上桃峪-西山-崮前崖村、连崮峪村要进行逐户核查造册、建立档案，做好相关收尾工作，确保顺利通过上级验收。对实施的其他工程治理项目，要按目标节点按时完成，并申请上级验收。对危险性较大，一时不能完成搬迁避让治理的地质灾害隐患点，在汛期要通过采取有效的临时避让等措施，确保人民群众生命财产安全。

(五)加强地质灾害危险性评估工作。加强建设用地项目预审和审批，在地质灾害易发区内的建设项目必须进行地质灾害危害性勘察鉴定，履行地质灾害危险性评估相关工作，未开展地质灾害危险性评估的建设项目一律不得开工建设。对擅自开工建设，诱发地质灾害和造成地质灾害隐患、危害他人生命财产安全的，严肃追究相关责任人责任。编制村庄和集镇规划时，应当对规划区进行地质灾害危险性评估。

(六)加强治理项目和搬迁避让项目的后期管护工作。各乡镇在废弃矿井地下采空区治理、安全隐患区治理和其他地质灾害治理以及搬迁避让等工程竣工通过验收后，要安排专人做好安全监管，要对监测设备、工程设施等固定资产安排专人管护，确保不发生危及人民群众生命财产的安全事故。
