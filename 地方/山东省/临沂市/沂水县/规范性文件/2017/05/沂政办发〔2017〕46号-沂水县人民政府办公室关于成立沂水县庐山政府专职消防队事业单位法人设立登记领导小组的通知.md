# 沂水县人民政府办公室关于成立沂水县庐山政府专职消防队事业单位法人设立登记领导小组的通知

沂政办发〔2017〕46号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

2012年7月19日，县政府召开庐山项目区消防站建设协调会议(会议纪要编号〔2012〕第17号),决定按照《城市消防站建设标准》建设一级普通消防站1处，该消防站于2013年8月1日投入执勤，定名为沂水县庐山政府专职消防队。根据《山东省政府专职消防队伍管理办法》(省政府令第271号)及《山东省人民政府办公厅关于印发山东省事业单位、社会团体及企业等组织利用国有资产举办事业单位登记管理办法(试行)的通知》(鲁政办字〔2017〕45号)等有关文件要求，庐山政府专职消防队符合事业单位法人设立登记标准。为更好地完成庐山消防队事业单位法人设立登记相关工作，经研究，决定成立沂水县庐山政府专职消防队事业单位法人设立登记领导小组，现将名单公布如下：

组　长：陈海龙　县委常委、县政府常务副县长

副组长：张晓华　县财政局局长

杨洪华　县事业单位监督管理局副局长

成　员：武传安　县公安局副局长

秦建波　县消防大队政治教导员

王　亮　县消防大队大队长

傅　杨　县冯家庄消防中队副中队长

领导小组下设办公室，办公室设在县消防大队，具体负责庐山政府专职消防队事业单位法人设立登记资料收集、上报，并牵头组建事业单位第一届理事会、指派理事、提请任免理事长，审查事业单位章程草案，监督事业单位按照章程开展活动等工作。
