# 沂水县人民政府办公室关于印发沂水县散煤清洁化治理工作实施方案的通知

沂政办发〔2017〕47号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

现将《沂水县散煤清洁化治理工作实施方案》印发给你们，请认真贯彻落实。

沂水县人民政府办公室

2017年5月26日

沂水县散煤清洁化治理工作实施方案

为扎实做好全县散煤清洁化治理工作，根据上级有关工作要求，结合我县实际，制定本方案。

一、指导思想

按照“全面整治、重点突破、疏堵结合、标本兼治”的原则，坚持统一部署与分级负责、政府推动与市场运作相结合，突出规范煤炭经营市场建设、提高煤炭质量、清洁煤炭推广等重点，全面完成散煤清洁化治理工作任务，进一步改善全县大气环境质量。

二、治理范围

散煤清洁化治理范围覆盖全县乡镇、街道、沂水经济开发区、沂蒙风情旅游景区(以下简称“乡镇”)和村居。重点治理三个领域：乡镇驻地单位和商业活动使用的散煤；农业生产使用的散煤；农村居民生活使用的散煤等。

三、任务目标和时间节点

(一)任务目标。

1.实现煤炭消费总量控制。严格落实临沂市煤炭消费减量替代工作部署，认真执行重点耗煤企业煤炭消费计划，建立健全用煤督查检查台账，全年煤炭消费总量控制在92万吨，推广清洁煤炭3.4万吨、节能环保炉具2260台。

2.严格燃煤质量标准。全县范围内除电厂用动力煤按相关标准执行外，禁止使用和销售含硫量超过0.6%、灰分超过15%的煤炭，禁止选煤洗煤。居民冬季取暖用煤执行以下标准：

(1)民用洁净型煤执行标准为：含硫量≤0.5%,灰分≤25%,热值≥23.83兆焦/千克，挥发份≤12%。

(2)兰炭执行标准为：含硫量≤0.5%,灰分≤10%,热值≥23.83兆焦/千克，挥发份≤10%。

3.加强储煤场地管理。经营性储煤场地要进行密闭式存贮，落实密闭大棚、地面硬化、院内经营、喷淋降尘等措施，防止煤炭扬尘污染。

(二)时间节点。

5月31日前，全县煤炭经营市场完成清理整治。6月30日前，各乡镇规划建设符合标准条件的煤炭经营网点(经营性储煤场),完善土地、环保、市场监管手续，实行挂牌经营，形成完善的网络监管体系。10月31日前，实施清洁煤炭供应，完成农业生产和农民生活清洁煤炭推广替代工作。

四、工作重点

(一)严格煤炭消费管控。加强煤炭质量监管，定期开展工业用煤和煤炭经营专项检查。(由县节能办牵头负责全县散煤清洁化治理及指导工作)

(二)推进乡镇驻地单位和商业活动散煤替代。加快建设清洁能源基础设施、燃气管道、城市集中供热管网，机关、学校、医院等企事业单位实施集中供热、管道天然气、液化气、电等清洁能源替代。(由各乡镇负责组织实施辖区内清洁能源推广替代等工作；县住建局负责城镇燃气管道和集中供热管网延伸建设)

(三)加大散煤经营市场清理整治和监管力度。禁止在农村地区销售、燃用不合格煤炭；严禁不符合标准煤炭直接进入流通、使用环节；坚决取缔禁燃区内销售散煤行为；严肃查处违规生产、经营劣质散煤的行为。(由各乡镇负责协调推进辖区散煤经营市场清理整治和管理工作；县市场监管局负责查处无照经营、超范围经营煤炭以及销售不符合质量标准煤炭等行为；县环保局、城管执法局负责煤炭经营企业及储煤场地的密闭、抑尘和污染防治的监管等工作；县交通运输局负责煤炭道路运输行为的监管等工作；县公安局负责对妨碍行政机关工作人员依法执行职务行为予以处置)

(四)规范煤炭经营市场建设。科学规划全县煤炭经营市场，县级建设1-2处规范的清洁煤专营市场，每个乡镇原则设置2个配送中心(煤炭经营网点、经营性储煤场),实行挂牌经营。(由各乡镇负责组织实施辖区煤炭经营市场的规划和达标建设工作；县国土资源局负责储煤场地建设用地管理方面的工作；县环保局负责煤炭经营企业及储煤场地的密闭、抑尘、防燃监管、环境评价等工作；县市场监管局负责完善市场监管手续；县节能办负责县级清洁煤专营市场的规划建设和煤炭经营网点的登记备案工作)

(五)建设清洁煤炭配送体系。按照“公开、平等、竞争、择优”的原则，建立完善全县清洁煤炭生产供应配送体系。搞好农村清洁煤炭需求状况调查摸底，按市场化要求进行清洁煤炭配送。(由各乡镇负责所辖区域清洁煤炭配送的组织实施工作，并加强对经营网点及工作人员的管理)

(六)制定财政激励政策。清洁型煤和节能环保炉具推广要突出重点领域，发挥示范带头作用。推广一吨清洁型煤补助200元、一套节能环保炉具补助200元(市、县级财政各承担100元)。(由县财政局负责统筹安排资金，落实煤炭补贴政策，并会同审计部门加强财政资金使用情况监管)

五、保障措施

(一)加强组织领导。为加强对工作的组织领导，县里成立由县政府分管领导任组长，县直有关部门负责人为成员的县散煤清洁化治理工作领导小组，并在县节能办设办公室，负责全县散煤清洁化治理工作的组织领导、日常调度、督导检查等工作。各乡镇、各有关部门要切实加强组织领导，严格落实主体责任，密切协作配合，建立健全县、乡镇、村居三级网格化管理体系，确保散煤清洁化治理工作顺利进行。

(二)加强调度督导。全县散煤清洁化治理工作实行定期调度、定期通报制度，由县散煤清洁化治理工作领导小组办公室负责加强日常督导，并及时调度、通报工作进展情况。对工作开展不及时、不到位的，将追究相关单位和人员的责任。

(三)加强宣传引导。各乡镇各有关部门要认真落实散煤清洁化治理工作的有关政策要求，进一步加大宣传引导力度，通过广播、电视、报刊、网络等多种形式，大力宣传清洁煤炭推广替代的重要意义，积极引导使用清洁煤炭，努力营造全社会共同支持清洁煤炭推广工作的良好氛围。
