# 沂水县民政局关于同意成立沂水县勤正慈善基金会的批复

沂民字〔2017〕14号

山东勤正置业有限公司：

你单位所报关于申请成立勤正慈善基金会的材料收悉，经审查材料和现场勘察，所报材料齐全有效，场地设施比较完善，已基本具备了成立条件。经研究，同意成立“沂水县勤正慈善基金会”。望基金会成立后，认真遵守国家的法律法规，自觉接受登记管理机关和相关业务主管单位的监管与指导，严格按照《基金会管理条例》和《章程》开展活动，积极加强自身建设，不断弘扬社会正能量，努力为促进我县经济社会发展贡献力量。

基金会应当于每年3月31日前向登记管理机关报送上一年度工作报告，接受年度检查。

沂水县民政局

2017年5月15日
