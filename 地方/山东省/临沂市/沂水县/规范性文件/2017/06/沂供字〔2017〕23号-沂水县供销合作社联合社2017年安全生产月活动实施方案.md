# 沂水县供销合作社联合社2017年安全生产月活动实施方案

沂供字〔2017〕23号

各基层社、县直属企业：

今年6月是全国统一组织开展的第十六个“安全生产月”，为组织开展好今年的“安全生产月”活动，县安全生产委员会下发了《沂水县2017年 “安全生产月”活动实施方案》，按照上级部署要求，结合我系统实际，制定“安全生产月”活动实施方案如下：。

一、总体要求

以党的十八届六中全会精神和习近平总书记、李克强总理关于安全生产重要指示精神为指导，深入宣传贯彻落实省、市、县安全生产工作重要决策部署，集中开展深入基层、面向群众的安全生产宣传教育活动，普及安全生产知识，提高全民安全意识和安全素养，进一步强化红线意识，推动企业安全生产主体责任落实及安全风险分级管控和隐患排查治理体系建设，坚决遏制事故多发势头、确保全县安全生产形势根本好转提供有力的思想保证、精神动力和舆论支持。

二、活动主题和时间

（一）活动主题：全面落实企业安全生产主体责任。

（二）活动时间：6月1日至30日。

三、活动安排

（一）开展“安全生产月”宣传日活动。

按照县里统一部署要求，6月16日作为“安全生产月”宣传咨询活动日，各企业要积极通过企业内的展板、宣传橱窗、宣传栏、宣传画廊和悬挂横幅及发放宣传材料等方式，围绕“全面落实企业安全生产主体责任”，广泛宣传安全生产方针政策、法律法规、安全科普常识、职业健康知识和应急逃生、自救互救方法，解答职工及公众关心的安全生产问题，营造“安全生产月”活动氛围。

（二）开展企业安全生产主体责任意识“三个一”活动

“安全生产月”期间，各企业要结合自身实际，紧紧围绕“全面落实企业安全生产主体责任”主题，组织开展“三个一”活动。一是企业主要负责人上一堂安全公开课。围绕全面落实企业安全生产主体责任，谈认识、讲体会，摆问题、找差距，定措施、严承诺，向全体员工做出表率。二是开展一次安全生产谈心对话。采取下谈一级方式，企业负责人对部门负责人，部门负责人对班组长，班组长对一线员工，层层开展安全生产谈心对话，充分交流观点看法，认真征求意见建议，深入了解思想动态，促进安全工作落实。三是开展一次安全承诺宣誓。依据法律法规，结合企业自身实际，建立全员安全生产责任制，公示安全生产责任清单，全体人员通过职工大会、部门会、班组会，或张贴责任书、承诺书等形式，向大家做出安全生产庄严承诺，落实“四不伤害”原则（不伤害自己、不伤害他人、不被他人伤害、保护他人不受伤害）。

（三）开展安全警示教育活动。

通过举办事故案例教育展览、组织观看警示教育片、开展反思大讨论等形式集中开展警示教育活动，对典型事故进行剖析，深刻吸取教训，认真查找原因，举一反三，找出本企业存在的安全问题和不足，及时采取对策和措施。用事故教训推动企业落实责任、完善措施，防范同类事故发生，切实做到“一地出事故，全县受警示”。

（四）开展安全生产应急预案演练活动。

按照省、市、县统一部署，各企业要结合实际，在重点部位和场所，围绕汛期安全和商场、超市、宾馆等人员密集场所逃生等内容，开展形式多样的应对各种突发事故的应急避险逃生实战演练。通过演练活动，查找问题，完善预案，提高处置突发事件能力和应急管理水平。安全月期间县安委会办公室将组织人员对各单位演练情况进行检查，并录制音像资料。各单位要将应急预案演练计划、方案、演练情况总结和影像资料于6月29日前报县社安统科汇总。

（五）积极参加群众性及网络安全生产月系列活动。

积极参加各级组织的群众性及国家网络安全生产月系列活动，包括职业病防治、道路交通、消防安全等法律法规为内容的机关企事业单位的答题和知识竞赛，以及安全文化书法、绘画、摄影等有奖征集。

四、工作措施

（一）加强领导，务求实效。各企业要认真按照县社实施方案的要求，结合各自实际，组织召开专题会议进行研究部署，加强领导，细化分工，做到每项活动思想到位、责任到位、投入到位、措施到位。要统筹安排，把开展“安全生产月”活动与日常安全生产工作紧密结合起来，真正达到以活动推动工作，以月促年的目的。突出抓好习近平总书记系列安全生产重要讲话精神宣讲、安全法治宣传、事故警示教育、安全知识传播和应急演练等重点工作，加强工作创新，着力发动基层职工群众积极参与，扩大活动覆盖受众面，务求活动实效。

（二）广泛宣传，营造氛围。各企业要加大宣传力度，扩大宣传声势。在企业、生活区设置安全生产黑板报、壁报栏，张贴安全生产漫画和警句，加强现场管理，倡导安全发展理念，开展警示教育，强化安全生产主体责任。要坚持弘扬主旋律，激发正能量，引导和把握正确的舆论导向，并加大舆论监督力度，营造更加有利于安全生产的浓厚社会氛围。

（三）统一思想，抓好落实。各企业要进一步统一思想，加强组织领导，落实责任，制定活动方案，精心组织部署，确保活动顺利开展，将“安全生产月”活动作为安全发展指导原则的具体行动，为党的十九大胜利召开创造稳定的安全生产环境，

请各企业将“安全生产月”活动方案和总结分别于6月15日和7月1日前报县社安全统筹科。
