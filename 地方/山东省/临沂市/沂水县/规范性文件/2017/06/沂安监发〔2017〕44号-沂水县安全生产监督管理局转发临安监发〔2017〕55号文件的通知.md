# 沂水县安全生产监督管理局转发临安监发〔2017〕55号文件的通知

沂安监发〔2017〕44 号

各乡镇安监办、沂城街道安监办、沂蒙风情旅游景区安监办、沂水经济开发区安监局：

现将市安监局《关于寿光市新丰淀粉有限公司“5.19”粉尘爆炸事故情况通报》（临安监发〔2017〕55 号）通知转发给你们， 请结合本地实际，将本通知迅速转发至所有涉爆粉尘企业，认真抓好贯彻落实，防范粉尘爆炸事故发生。
