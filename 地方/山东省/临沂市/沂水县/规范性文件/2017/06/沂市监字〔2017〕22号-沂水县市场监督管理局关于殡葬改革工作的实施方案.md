# 沂水县市场监督管理局关于殡葬改革工作的实施方案

沂市监字〔2017〕22号

为进一步破除丧葬、祭扫陋习、节约土地、保护生态环境、倡树文明新风，根据6月5日召开的全县殡葬改革工作现场推进会议精神，结合我单位工作职能，制定本方案。

一、指导思想

按照国务院《殡葬管理条例》和《临沂市乡村文明行动移风易俗工作联席会议成员单位工作职责分工》，围绕我县关于殡葬改革工作部署要求，我局大力推进全县殡葬改革工作。

二、目标任务

结合我单位职责，做好殡葬用品市场的规范、监管工作，取缔封建迷信用品生产、销售经营业户，净化殡葬用品市场。

三、方法与措施

（一）分工协作，托清底子

各相关科室、各市场监管所6月9日前完成辖区内全县殡葬用品经营户的调查摸底，全面掌握辖区内棺材制作、销售经营户，封建迷信和丧葬祭祀用品经营户情况，做到底子清，情况明，为推进我县殡葬改革工作，规范整治丧葬祭祀用品市场打下基础。同时做好信息日报告制度，将当日调查摸底情况及时上报县局市场科

（二）结合职能，落实好殡葬改革工作

根据前期调查摸底情况，各相关业务科室、各市场监管所在6月16日前，完成辖区内殡葬用品市场的专项整治工作，并及时将工作开展情况报县局市场科。

1、对符合政策经营的，引导其诚信经营、文明经营，售卖符合节俭办丧要求的丧葬用品。

2、从严查处殡葬用品违法经营行为，重点查处有违文明祭扫的殡葬用品、非法销售人民币图案和样式的各类冥币销售行为，净化殡葬用品市场,坚决查处取缔无照经营和违反县殡葬政策的经营户。

3、以12315消费者申诉举报平台为依托，畅通渠道，方便群众反映非法经营行为，构建群防群治工作格局。

（三）发挥职能优势，加大宣传力度

1、充分发挥市场监管所登记窗口的作用，利用企业法人来办理业务的时机，发放县里印发的殡葬改革宣传材料，向他们宣传殡葬政策，利用他们的影响力更好的进行宣传。

2、利用日常巡查监管和干部联系群众的机会向广大群众和殡葬用品经营者广泛宣传殡葬法规政策，普及科普知识，倡导文明节俭、生态环保、移风易俗的殡葬新风尚。

3、加大对本单位内全体干部职工的宣传教育。大力宣传党员、干部和群众在殡葬改革工作中的先进典型，传播正能量。

四、工作要求

1、统一思想，提高认识。深刻认识殡葬改革工作的重要意义，切实增强责任感和紧迫感，做到思想认识到位，工作部署到位，措施落实到位，宣传引导到位，推动全县殡葬改革顺利进行。

2、加强组织领导。为切实加强对殡葬改革工作的组织领导，成立以孙作军同志任组长，刘沂青同志任副组长，各科室、所负责人任成员的殡葬改革工作领导小组，领导小组下设办公室，具体负责我单位殡葬改革工作。

3、明确职责分工。各相关科室、所要各司其职、密切配合，形成推动殡葬改革工作的强大合力，共同做好殡葬改革工作。
