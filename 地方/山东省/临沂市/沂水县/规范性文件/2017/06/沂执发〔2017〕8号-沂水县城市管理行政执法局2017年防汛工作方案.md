# 沂水县城市管理行政执法局2017年防汛工作方案

沂执发〔2017〕8号

各科室中队、环卫处：

为切实搞好今年我县城区防汛工作，提高我局防汛抗灾处置能力和预警机制，确保城区安全度汛和人民生命财产安全，根据县委、县政府的部署要求，本着“早部署、早安排、早行动”的原则，按照“防大汛、抢大险、减大灾”的要求，结合我局城市管理工作实际和任务要求，特制定本方案。

一、指导思想

以党的十八大和十八届六中全会精神为指导，坚持“安全第一、常备不懈、预防为主、全力抢险”的方针，全面落实城区防汛责任制，认真履行防汛职责任务，加大城区防汛实施物料和设配投入，积极组织城管执法队员、应急队员、基干民兵等进行防汛值班执勤，切实提高城区防洪抢险和防汛救灾能力。

二、工作任务

要继续按照防大汛、抢大险、减大灾的标准做好准备。具体任务是：加大工作巡查、检查力度，对户外广告牌匾、违法建设、市政设施、绿化树木等存在安全隐患的第一时间内书面通知有关单位或个人，并采取依法拆除、固定、维修、修剪等措施，消除安全隐患，避免出现人员伤亡，最大限度的减少公共设施及物资损失，确保城区安全度汛。

三、责任分工

（一）办公室负责应急车辆的调度、夜间值班等后勤保障工作。（值班车辆：鲁QP699P、鲁Q2WW96、鲁Q9WW27、鲁Q3WW60、鲁Q8WW05、鲁Q8WJ25）

（二）财务科负责应急物资、材料的购买，对应急器材所涉及的雨具、防汛工具、铁锨、手电、救生衣等进行更新、增添等，确保应急物资保障供应。

（三）执法督察科做好防汛抢险队员的组织工作和应急仓库的保管，调度应急队员、基干民兵和其他执法队员的集合和调配，做到令行禁止、行动迅速及时，确保应急事件的安全处置。

（四）各科室中队要落实防汛抢险责任制，提高风险防范意识，在日常巡查管理的基础上，加强对大型户外广告、违法建设等方面存在的安全隐患的检查、排查，第一时间进行处置，严禁造成人员伤亡事故的发生。环卫处要按照其工作实际和业务特点，对垃圾填埋场、中转站以及运行车辆的防汛防渗、安全生产等方面的隐患排查，确保环境卫生日常管理万无一失。

四、组织领导

为加强我局防汛工作的领导，成立由主要领导任指挥、分管领导任副指挥、各科室中队负责人任成员的防汛指挥部，指挥部下设办公室，办公室设在执法督察科（值班电话：7323859）。
