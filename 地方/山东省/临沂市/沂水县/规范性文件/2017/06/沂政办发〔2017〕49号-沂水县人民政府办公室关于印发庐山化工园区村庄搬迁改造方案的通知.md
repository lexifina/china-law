# 沂水县人民政府办公室关于印发庐山化工园区村庄搬迁改造方案的通知

沂政办发〔2017〕49号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府有关部门：

《庐山化工园区村庄搬迁改造方案》已经县政府研究同意，现印发给你们，望认真抓好组织实施。

沂水县人民政府办公室

2017年6月1日

庐山化工园区村庄搬迁改造方案

为促进园区健康快速发展，全面落实园区发展规划，切实提高园区内人民群众的生活质量，决定对园区规划范围内剩余的8个村庄进行搬迁改造。为积极稳妥地做好搬迁改造工作，结合实际情况，特制定本方案：

一、搬迁改造原则

结合园区内村庄实际情况，坚持“因地制宜、先易后难、公开、公平与分年度实施”的原则，逐步实施村庄搬迁改造，充分维护广大群众的切身利益。

二、搬迁改造范围、顺序和安置位置

(一)搬迁改造范围：北社村、后南社村、前南社村、柳家庄村、袁家庄村、荆山岭村、永胜村、郭家楼村8个村庄，涉及3545户、1.04万口人。

(二)搬迁改造顺序：计划2018年上半年完成北社村一期的搬迁改造；根据项目建设进度，在确保安全距离的前提下，计划2020年前逐步完成永胜村、郭家楼村、柳家庄村、袁家庄村、荆山岭村的搬迁改造；对位于配套生活区和安全控制区的北社村二期、后南社村、前南社村，逐步纳入棚户区改造。

(三)安置位置：按照总体规划，将北社村搬迁至长乐社区；将后南社村、前南社村、柳家庄村、袁家庄村、荆山岭村、永胜村、郭家楼村7个村庄搬迁至春水社区。

三、保障措施

(一)统一思想，提高认识。庐山化工园区村庄的搬迁安置对于推动园区科学跨越发展具有极为重要的意义，各级各有关部门要切实做好群众的思想工作，注意听取群众的意见和建议，及时把握存在的苗头性、倾向性问题，妥善处置，积极引导广大群众大力支持、推动园区发展。

(二)深入宣传，营造氛围。要通过多种形式向群众深入宣传，讲清村庄搬迁改造与加快园区建设、改善群众生活生产条件的关系，使广大群众充分认识村庄搬迁的重要性、必要性，积极配合做好搬迁改造工作。各新闻单位要通过多种方式及时宣传村庄整体搬迁的重要意义和有关要求，营造良好氛围。

(三)严格政策，依规办事。要本着“以人为本，先安置后拆迁”的原则，切实做好拆迁、补偿和安置工作。要聘请有资质的评估机构，按照国家及省、市有关拆迁补偿法律法规、标准评估后进行补偿。有关乡镇、部门要积极配合做好搬迁改造相关工作，坚决杜绝强搬强拆等行为，确保村庄搬迁安置工作扎实稳妥进行。
