# 沂水县人民政府办公室关于加强集贸市场建设管理和道路交通安全的实施意见

沂政办发〔2017〕50号

各镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

为加强和改进全县集贸市场建设管理及道路交通安全工作，进一步改善城乡环境秩序，提升为民服务和安全保障水平，现就有关事项通知如下：

一、全面加强集贸市场建设管理

严格审批监管，举办集贸市场，必须经市场监管部门依法审批。各乡镇、街道、经济开发区、沂蒙风情旅游景区（以下简称“乡镇”）为集贸市场建设管理主体。市场监管部门应当会同城建部门制定集贸市场发展规划，各乡镇要积极落实并组织实施。

本着谁投资、谁受益的原则，鼓励企业和个人投资建设集贸市场。集贸市场应确定专门管理机构和人员，加强日常规范管理，实行定点定位经营，坚决杜绝外溢占道影响交通安全行为。

（一）排查摸底。各乡镇要全面排查辖区内各类集贸市场，特别要将城乡结合部自发形成的马路市场作为排查重点，详细统计市场名称、位置、集市日期或集中交易时间、临近道路名称、是否存在占道经营问题、是否已经市场监管部门审批等信息，并逐个提出保留或取缔的意见和规范整顿的措施。

（二）集中整治。各乡镇和县直有关部门要组织力量，区分不同情况进行分类规范整顿。对不予保留的市场，要集中力量进行取缔；对确定保留的城区市场，在集市日期或集中交易时间，应设立分时段车辆绕行标志，禁止市场人车混行；对确定保留的农村集贸市场，要全力搞好秩序整顿，坚决杜绝马路市场和占道经营；对国省道两侧30米、县乡道两侧10米内（从公路用地处外缘起算）的集市贸易要全面落实搬迁或关停措施。

（三）规范管理。市场监管局等有关部门负责本着便民、安全原则统筹规划全县集中贸市场，合理确定贸易区域、时间、范围等，重点搞好城区集贸市场规划，特别对裕丰、文诚等市场店外经营、占道经营以及经常性占道售卖字画、花草等的，要引导入店经营、集中经营，到雪山风情街、中和花都等市场“划行归市”经营，切实形成规模、打造品牌。日常管理，城区主干道由城管执法局负责清理整治非许可集市的占道经营、乱摆摊点、流

动摊点行为，特别要严格管控裕丰市场、文诚市场等城区重点市场，确保道路畅通、群众安全。乡镇农村集贸市场由所属乡镇负责加强规范整顿，重点抓好占道经营、乱摆摊点、乱停乱放的清理规范。市场监管局负责抓好集贸市场相关经营行为监管，依法保护消费者权益。公安、交警、消防等部门负责集贸市场及周边的治安管理、交通疏导和消防安全保障。

二、全面提升道路交通安全水平

（一）全面排查整治道路交通安全隐患。按照“全覆盖、横到边、纵到底、零死角”的要求，县道路交通安全专委会要组织力量逐路、逐段、逐口进行拉网式排查，重点搞好道路急弯、陡坡、临水、临崖、事故多发等危险路段安全隐患排查。对排查确定的隐患要建立健全管理台账，落实抄告移交和挂牌督办制度。对发现的隐患问题，要切实做到整改措施、责任、资金、时限和预案“五到位”。对损毁的安全设施要限时修复，重点路段要加设警示标示、设施，并倾斜警力布置，加强路检路查；对损毁路段，能及时修复的要及时修复，不能及时修复的，要采取必要的防范措施，确保行车安全。

（二）深入开展道路交通“打非治违”。深入推进道路交通行业“打非治违”工作。一要加大人力投入力度。交警部门要尽量把警力和装备投入一线，定期上路巡查，不断强化路面监管执法力度，始终保持对道路交通非法违法行为的高压态势。二要突出重点，加强执法监管。要重点查处机动车超速、客车超员、货车

超速超载、疲劳驾驶、酒后驾驶等违法违规行为。农村道路交通要集中整治三轮汽车、低速货车、农用拖拉机载人、摩托车超载和小型面包车非法营运等非法违法行为。要对客运车辆、长途客车、旅游包车、小型面包车、大中型货车、危化品运输车等进行重点整治规范。各乡镇和教育、交警、交通等部门要加强校车管理，严格校车使用许可，打击处理非法接送学生车辆。三要深化“双超治理”等综合整治工作。要采取定点测速、流动测速等措施，加强对事故多发路段的车速和车流量管控；要加大源头监管，严把车辆准入、货源、承运主体、经营主体资格监管等关口，从源头上杜绝超限超载等违规现象发生；要认真落实“一超四罚”制度，对超限超载车辆责令立即停驶，就地就近卸载，及时阻止违法行为；对非法改装车辆，要强制恢复国家标准，从严从重落实处罚措施。

（三）切实加强道路运输安全管理。一要强化道路运输企业安全主体责任。县交通运输部门要督促有关运输企业建立健全安全生产管理机构，加强安全班组建设，严格执行“三不进站五不出站”、长途客运驾驶人停车换人强制休息、“三品检查”、卫星定位动态监管等安全生产制度、规范和技术标准，强化对车辆和驾驶人的安全管理，提足、用好安全生产费用，确保安全运输。二要全面开展大检查。要针对当前外出旅游人员集中、客运包车需求旺盛的特点，迅速开展全面排查，认真审查客运包车尤其是旅游客运包车的运营资质和申请路线，严格审批、发放包车证，

严禁客运包车违规从事与审批资质不相符的经营活动。三要加强监督检查。对违反规定超时、超速驾驶的驾驶人及相关企业依法严格处罚；对安全生产责任制不落实、安全隐患突出的客运包车企业，要立即责令限期整改，经整改仍达不到安全运营条件的，要依法吊销相关资质；对安全管理混乱、存在重大安全隐患的企业，依法责令停业整顿，对整改不达标的按规定取消其相应资质。四要加强营运驾驶员安全素质教育。重点突出对驾驶员的法治意识、安全意识和应急处置能力的教育培训，加强对恶劣天气、复杂道路驾驶常识、紧急避险等方面的教育，不断提高其守法意识、安全意识、安全技能，切实做到依法营运、安全行车。要严格客货运驾驶员从业资格管理，规范客货运驾驶员职业准入，督促运输企业严格客货运驾驶员聘用和管理。

三、切实强化工作保障措施

各乡镇、各有关部门要把加强集贸市场建设管理和道路交通安全管理作为重要工作内容，成立专门的工作机构，落实分管领导和专门人员具体抓好各项管控措施落实。对存在的问题和隐患，相关乡镇和责任单位必须按照相关标准要求高标准、高质量地进行整改。县安委会办公室要成立专门的督查组，对集贸市场建设管理和道路交通安全工作进行专项检查，检查结果及时报县委、县政府。同时，各级各相关部门要深入开展道路交通安全宣传工作，通过广播、电视、报刊、明白纸、微信、短信等形式，广泛宣传道路交通安全知识，把道路交通安全法律法规、政策措

施和典型事例宣传到村居（社区）和各运输企业、货运场站、业主、驾驶员，切实增强全社会道路交通安全意识。
