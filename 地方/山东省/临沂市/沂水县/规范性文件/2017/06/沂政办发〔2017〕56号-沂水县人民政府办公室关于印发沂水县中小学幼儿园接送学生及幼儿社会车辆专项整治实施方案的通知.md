# 沂水县人民政府办公室关于印发沂水县中小学幼儿园接送学生及幼儿社会车辆专项整治实施方案的通知

沂政办发〔2017〕56号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

现将《沂水县中小学幼儿园接送学生及幼儿社会车辆专项整治实施方案》印发给你们，请认真抓好组织实施。

沂水县人民政府办公室

2017年6月16日

沂水县中小学幼儿园接送学生及幼儿社会车辆专项整治实施方案

为切实做好全县中小学生及幼儿上下学乘车安全工作，从根源上解决接送学生社会车辆存在的问题，确定对全县接送学生及幼儿社会车辆开展专项整治，特制定本具体实施方案。

一、指导思想

以《中华人民共和国道路交通安全法》《校车安全管理条例》《中小学幼儿园安全管理办法》和《山东省校车安全管理办法》等有关法律法规为依据，以维护中小学、幼儿园学生的生命安全为核心，按照“属地管理、各负其责、协作配合、全面排查、集中整治”的原则，依法整顿非法接送学生及幼儿社会车辆，进一步健全完善校园周边道路交通安全管理长效机制，有效保障全县中小学生及幼儿上下学乘车安全。

二、整治内容

托清全县中小学幼儿园接送学生及幼儿社会车辆情况，依法查扣并取缔不符合专用校车安全国家标准的社会车辆；对符合专用校车安全国家标准的接送学生及幼儿的社会车辆进行整合，由有资质公司实行统一管理。

三、工作步骤

(一)宣传告知阶段。6月1日之前，各级各有关部门要在学校、幼儿园及周边多形式搞好宣传，并在显著位置设立公开举报电话，鼓励群众举报非法接送学生及幼儿社会车辆接送行为，在全县营造浓厚的整治氛围。县教体局要将《沂水县整治接送学生及幼儿社会车辆告知书》发放到所有接送学生及幼儿社会车辆车主手中，告知其符合专用校车安全国家标准的接送学生及幼儿的社会车辆将进行规范、整合，由有资质公司实行统一管理。

(二)摸底查验阶段。6月6日起，在全面排查摸底的基础上，将符合专用校车安全国家标准的接送学生及幼儿社会车辆情况抄送县交警大队及交通运输局进行审验，确定具体车辆。对不符合标准的，由县交警大队、县交通运输局按照《山东省校车安全管理办法》依法处理、取缔。

(三)整合运营。6月25日起，按照自愿的原则，符合专用校车安全国家标准的接送学生及幼儿的社会车辆车主与县里确定的校车公司签订《委托服务协议书》,由校车公司统一向有关部门办理审查、报批、年检等事项。

四、职责分工

(一)县交警大队：负责依法处理、取缔不符合专用校车安全国家标准的接送学生及幼儿社会车辆；设立监督举报电话；参与校车线路的联合审查；履行校车审批环节中的相关职责。

(二)县交通运输局：负责配合县交警大队依法处理、取缔不符合专用校车安全国家标准的接送学生及幼儿社会车辆；会同教体、交警等部门对相关校车线路进行审查；履行校车审批环节中的相关职责；按照规定标准和管理权限设置校车停靠站点预告

标识和标牌，施划校车停靠站点标线；负责统一设计候车亭式样并建设；对校车运营线路中县道、县道校园门口及周边道路安全隐患进行整治；督促监管提供校车服务的企业全面落实安全责任；监管取得资质的校车维修企业严格按规定做好车辆维修保养，确保车况良好。

(三)县教体局：负责排查摸底全县接送学生及幼儿社会车辆数量；制定下发《沂水县整治接送学生及幼儿社会车辆告知书》;配合县交警大队、交通运输局整顿、取缔不符合专用校车安全国家标准的接送学生及幼儿社会车辆，履行校车审批环节中的相关职责。

(四)各乡镇、街道、沂水经济开发区、沂蒙风情旅游景区：配合搞好辖区校车运营服务、监督、管理及相关工作协调；配合对校车行驶路线中农村公路、校园门口及周边道路隐患进行整改，对非法接送学生社会车辆进行整治；指导所属学校搞好乘车需求、站点布局调查托底。

(五)县校车公司：负责制定公司管理相关规章制度，加强车辆管理服务；统一向有关部门办理审查、报批、发放标牌、年检等事项；搞好校车车内监控设备的安装；强化驾驶人员业务培训，确保车辆状况良好，人员管理到位，日常运行规范有序。

(六)全县各中小学、幼儿园：负责做好学校、幼儿园交通安全教育，及时提出工作意见建议；配合有关部门、校车运营企业做好校车日常管理、乘用。

五、工作要求

接送学生及幼儿社会车辆专项整顿、规范工作事关学生生命安全和社会稳定和谐，各相关部门务必增强工作的责任感和紧迫感，把该项工作列入重要工作内容，做到职责明确、要求具体、措施可行，确保学生及幼儿交通安全。各相关部门要加强沟通，密切协作，确保接送学生及幼儿社会车辆各项管理工作顺利进行。宣传部门要充分利用广播、电视、报刊等媒体，广泛宣传接送学生及幼儿社会车辆整顿、规范的重大意义，营造全社会积极配合、共同参与的良好氛围。各中小学、幼儿园要会同教育、交警、交通部门，认真开展交通安全知识教育活动，提高学生交通安全意识和自我保护意识。集中整顿、规范期间，县里将组织人员以明察暗访的形式，对各相关部门工作开展情况进行督导检查。对措施不力、进展不快、存在问题的单位在全县通报，限期整改到位。
