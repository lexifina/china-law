# 沂水县人民政府办公室关于成立沂水县创建山东省食品(焙烤食品、糖果)质量检验中心工作领导小组的通知

沂政办发〔2017〕67号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府有关部门：

为切实加强对山东省食品(焙烤食品、糖果)质量检验中心创建工作的组织领导，确保各项工作有序推进，经研究，决定成立沂水县创建山东省食品(焙烤食品、糖果)质量检验中心工作领导小组。现将成员名单公布如下：
