# 沂水县经济贸易和信息化局关于印发《沂水县民爆行业2017年“安全生产月”活动实施方案》的通知

沂经信字〔2017〕22号

道托镇经贸办、各相关企业：

《沂水县民爆行业2017年“安全生产月”活动实施方案》已研究确定，现印发给你们，请结合实际，围绕“全面落实企业安全生产主体责任”活动主题，认真抓好贯彻落实。

沂水县经济贸易和信息化局

2017年6月2日

沂水县民爆行业2017年“安全生产月”活动实施方案

为深入宣传贯彻省市和县委、县政府安全生产工作重要决策部署，进一步加强安全生产宣传教育，在全社会弘扬安全发展理念，推动落实企业安全生产主体责任，全面提升全民安全素质，有效防范和遏制重特大事故发生，为党的十九大胜利召开创造稳定的安全生产环境，根据省市县有关文件精神，结合我县民爆行业实际，制定“安全生产月”活动方案如下。

一、总体思路

以党的十八届六中全会和习近平总书记、李克强总理关于安全生产重要指示批示精神为指导，以“全面落实企业安全生产主体责任”为主题，坚持深入基层、面向群众，在全市民爆行业集中开展一系列内涵丰富、形式多样，群众喜闻乐见的安全生产宣传教育，普及安全知识，提高全民安全意识和安全素质，推动企业安全生产主体责任落实，在全系统凝聚弘扬安全发展理念、支持安全生产的共识，为坚决遏制各类事故发生，促进全市民爆行业安全生产形势持续稳定好转，实现“零事故事”故目标提供有力的思想保证、精神动力和舆论支持。

二、活动时间

全县民爆行业“安全生产月”活动于2017年6月在全县民爆行业监管部门、属地乡镇及民爆企业同时开展、同步进行。

三、主要内容

（一）创新开展安全生产宣教活动。一是政策法规对口宣讲活动。县级民爆行业主管部门负责人带头深入民爆行业领域重点企业开展对口宣讲。要大力宣传党中央、国务院关于安全生产的重要决策部署和指示批示、《中共中央 国务院关于推进安全生产领域改革发展的意见》《安全生产法》和《山东省安全生产条例》的主要精神以及对企业落实安全生产主体责任的要求，引导企业牢固树立安全发展理念，强化发展决不能以牺牲安全为代价的红线意识。属地乡镇也要参照执行，由单位主要负责人带头到本地区有关企业宣讲，并开展“安全生产志愿服务宣讲进企业”活动，深入宣传企业对本单位安全生产和职业健康负全面责任、全员安全生产责任制的意义内涵，督促企业强化责任意识，加强安全生产管理，严格落实主体责任。二是开展民爆行业典型经验观摩活动。围绕落实企业主体责任、安全风险分级管控和隐患排查治理体系（以下简称“两个体系”）建设等重点工作，适时组织当地企业负责人和安全管理人员到其他先进企业进行实地观摩，学习先进的安全管理方式和经验做法，对标看齐、示范带动，不断提高企业安全生产工作水平。（责任单位：县经信局，道托镇政府，民爆企业）

（二）开展“6.16”企业安全生产主体责任宣传咨询日活动。

组织属地乡镇、民爆企业根据行业特点，制作安全展板、设置咨询台，采取悬挂横幅、发放宣传资料、播发警示教育片等方式，广泛宣传安全生产方针政策、法律法规、安全科普知识、职业健康知识和应急逃生、自救互救方法，解答社会公众关心的安全生产问题。山东天宝化工爆破器材销售公司沂水分公司要通过橱窗、展板、宣传栏、电子屏等方式，围绕全面落实企业安全生产主体责任进行广泛宣传。（责任单位：县经信局，道托镇政府，民爆企业）

（三）开展企业安全风险公告和隐患排查治理活动。一是组织民爆企业开展“两个体系”专题宣传和教育培训，教育引导全体从业人员牢固树立风险意识，真正掌握风险分级管控和隐患排查治理知识。组织企业开展重大危险源和重大隐患公示公告活动，增强职工群众对10人以上危险作业场所和重大危险源的监测管控、重大事故隐患的辨识治理能力水平。二是动员广大职工、社会公众积极查找身边的事故隐患和“三违”行为，宣传安全生产投诉举报方式、奖励办法，鼓励人民群众通过“12350”热线电话或行业安全监督电话及其他方式，积极举报身边的安全生产事故隐患和各类非法违法生产建设经营行为。三是扎实开展隐患排查治理活动。按照《民爆行业危险化学品安全综合治理工作实施方案》的要求，全面开展民爆行业危险化学品专项整治工作。在电器产品使用管理领域深入开展安全生产督查检查工作，持续开展重大危险源和10人以上危险作业场所隐患排查治理工作，严防电气火灾。（责任单位：县经信局，道托镇政府，民爆企业）

（四）开展安全生产法治宣传和事故警示教育。一是开展安全生产法治宣传。围绕《安全生产法》、《职业病防治法》以及《山东省安全生产条例》、《山东省生产经营单位安全生产主体责任规定》、《山东省安全生产行政责任制规定》、《山东省危险化学品安全管理办法》法律法规和规章，以及民爆行业的标准规范，采取培训、讲座、辅导等形式，组织开展安全生产法律法规系列宣传教育，提高安全生产法治意识，推动落实安全监管责任和企业安全生产主体责任。关注“安全生产月”（www.anquanyue.org.cn）和“国家安监总局宣教中心”官方微信，用足用活安全文化产品。积极参加安全生产月知识竞赛、文化精品征集、特色宣教交流和“全国有了安全月的味儿”随手拍活动。二是开展事故警示教育。鼓励有条件的单位利用相关安全教育类电视专题节目的平台作用，结合行业实际，围绕人民群众关心和企业关注的安全生产重点、热点、难点，开展事故案例警示宣传。在开展“5·20停产反思日”活动的基础上，进一步加强对从业人员的警示教育，强化警示效果。三是及时发布预警和提示信息。结合夏季高温、汛期等安全生产特点，围绕民爆行业领域以及各民爆企业开展“手机短信安全提示群发”、“安全好文章及时发”等群众性安全宣传教育，及时发布安全生产预警信息和安全提示，指导企业有效防范和处置生产安全事故，提高安全防范和风险管控能力。（责任单位：县经信局，道托镇政府，民爆企业）

（五）开展安全生产应急救援演练活动。组织民爆企业按照国家《生产安全事故应急预案管理办法》规定，结合行业实际，开展应急预案、现场处置方案和舆情应对预案的演练工作，强化全员应急救援意识，提高快速反应、科学处置、警戒疏散和现场指挥能力。要加强应急演练评估，总结经验，查找不足，及时修订和完善应急预案，增强预案的针对性和可操作性。（责任单位：县经信局，道托镇政府，民爆企业）

（六）积极参与市、县政府安委会组织的其他活动。除组织企业参加以上各项活动外，督导企业围绕落实企业安全生产主体责任，认真制定本单位“安全生产月”活动方案，动员全员参与、落实责任，有针对性地开展各项活动。如：深化民爆行业“5·20停产反思日”活动；积极参与新闻发布、专家访谈和群众性安全生产活动、“双百谈安全生产”活动、“安全生产齐鲁行”活动；开展远程教育、征文等活动，进一步提升活动效果。（责任单位：县经信局，道托镇政府，民爆企业）

四、工作要求

（一）加强组织领导，明确责任分工。高度重视宣传教育在安全生产工作中的基础性、全局性作用，把“安全生产月”活动纳入全年安全生产重点工作统筹安排。成立专门的活动组织机构，制定实施方案，保障经费投入，分解细化任务，层层落实责任，加强督导检查，确保各项措施落实落细。民爆行业安全监管部门及属地乡镇主要负责人要带头参加1至2次“安全生产月”活动。

（二）突出环境营造，形成浓厚氛围。各有关单位要充分发挥本单位宣传资源优势，集中精力、集中人员，通过电视、广播、报刊、网络、微博、微信、手机客户端等媒体，广泛进行宣传。要在重要场所、关键区域、重点路段等醒目位置悬挂安全生产横幅、标语和口号，持续播放安全生产公益广告，实现安全宣传全覆盖无盲区，在全社会营造浓厚氛围。

（三）创新宣传载体，提高活动质量。各有关单位要创新宣传理念，丰富宣传形式，灵活运用培训、竞赛、咨询、应急演练、执法检查等各种载体，加大宣传频次和力度，形成“安全生产月”宣传的强大声势。要认真组织开展“安全生产月”期间的每一项活动，深入发动广大群众积极参与，扩大活动受众面和影响力，确保活动取得实实在在的成效。

（四）加强工作督导，总结推广经验。县经信局将对活动开展情况进行督导，总结经验，发现问题，持续巩固和深化活动成果，实现以月促年，以年促安，推动安全生产工作水平不断提升。
