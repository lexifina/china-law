# 沂水县供销合作社联合社安全生产百日攻坚治理行动实施方案

沂供字〔2017〕25号

各基层社、县直属企业：

为进一步加强安全生产监督管理，防范各类生产安全事故发生，按照沂水县安全生产委员会《关于印发沂水县安全生产百日攻坚治理行动实施方案的通知》（沂安发［2017］16号）和《关于印发沂水县烟花爆竹百日攻坚治理行动实施方案的通知》（沂安发［2017］52号）要求，结合系统实际，制定安全生产百日攻坚治理行动实施方案如下：

一、工作目标

按照“全覆盖、零容忍、严执法、重实效”的要求，集中100天的时间，通过对所属单位安全隐患排查治理，进一步健全完善安全管理机制，落实安全防控措施，消除安全隐患，降低安全风险，有效防范各类安全事故发生，促进系统安全生产形势持续稳定。

二、工作重点

开展安全生产百日攻坚治理行动，要突出重点行业领域、突出关键部位、关键环节。

（一）人员密集场所。系统内的商场、超市、宾馆、饭店、公共娱乐场所等人员密集场所，一要加强对干部职工的安全生产培训教育，特别是消防安全，要制定单位应急预案，定期组织消防演练，提高员工的应急能力和处置能力。二要定期对电源线路、消防器材、应急灯、消防通道等进行安全检查，做好检查记录，发现隐患立即整改，确保拿的出，用的上。同时坚决杜绝占用、堵塞、封闭疏散通道、安全出口、消防车通道等现象发生。

（二）项目建设工地治理。承担项目建设的企业，一是要做好项目建设前的招投标手续，签订施工合同。二是会同施工单位、监理单位组织对施工现场安全防护设施设置情况、危险性较大的分部分项工程安全管理情况、临时用电安全状况、起重机械设备维修保养情况以及施工现场高处作业设施的稳定性和牢固性等为重点进行排查，对查出的安全隐患，要落实专人负责整改到位，并建立自查档案备查。三是会同监理单位督促施工单位落实好安全教育培训工作，并对施工现场管理人员到位到岗情况、从业人员上岗情况及时进行检查，引导施工单位对建筑施工人员进行团体投保。

（三）电梯。安装使用电梯的企业（单位），重点检查电梯是否注册登记并在检验有效期内，是否制定并严格落实特种设备安全管理制度，是否严格按照国家规范要求在检验有效期满前一个月申请定期检验；检查维保单位是否严格按照国家规定定期进行维护保养，是否制定完善的应急救援预案并定期进行演练；检查在检验有效期内电梯是否有安全隐患，对有隐患的及时进行整改。

（四）老旧、危房。我系统的大部分门店及职工宿舍，都建于上世纪六七十年代，由于建成时间较长，又加上不能及时修缮，大部分已不再适合居住或经营，特别是汛期马上来临，存在着相当大的安全隐患，威胁着职工的生命财产安全。为此，各单位要在原有摸底的基础上，再进行一次检查梳理，对于已经不能再适合居住或经营的门店，能立即修缮的，要在汛期来临前修缮完毕，对于不能修缮的，要立即下达撤离通知书，一律限期撤出使用，并让使用人签好字存档，确保不出现危及职工安全的事故发生。

（五）出租房屋（厂房）。各企业要对本辖区内出租屋（厂房）的消防安全开展全面、深入的安全检查。一是房屋出租人出租房是否申报登记、备案；是否将房屋（厂房）出租作为公共娱乐场所，作为生产、储存、经营依然、易爆、有毒等危险物品，或存在住宿与生产储存经营合用同一场所的“三合一”现象；是否改变房屋结构将房屋分隔出租，导致各类安全隐患。二是出租房屋（厂房）电、气设置是否规范，是否存在私拉电线、是否在屋内使用大功率电气设备；消防通道是否通畅，标志是否明显，是否放杂物、电动车存放和充电堵塞疏散通道现象。

（六）烟花爆竹零售点。为进一步做好下半年烟花爆竹安全生产工作，坚持“安全第一、预防为主、综合治理”的方针。各有关企业一定要加大检查力度，严禁“下店上宅”、“前店后宅”等形式存在，凡是还存有整箱以上大量烟花爆竹的，及时收集整理，按照协议存放到烟花公司的指定仓库，确保不发生安全事故。平时有零售业务的销售点，也不能大量集中存放，要按照安监部门的规定，合理存放，更要注意吸烟、炭炉等明火的安全威胁，同时要配足灭火器等消防器材，防止意外发生。

（七）加油站。系统内各加油站，是否按照消防、安监等部门的规定要求，建立健全各项规章制度，配备配齐消防设备器材，定期进行检查保养，对所有供电线路和用电设备也要定期进行检查，做好防火、防雨工作，确保不安全因素能及时排除。要制定切实可行的消防预案，定期组织员工进行消防训练和安全教育，做到：人人熟悉消防知识，人人会用消防器材，人人树立安全意识，确保不出现任何安全事故。

三、时间安排

百日攻坚治理行动共分三个阶段，从现在起至2017年9月30日完成治理任务。

（一）自查自改阶段（7月底完成）。各企业要按照文件要求，认真开展自查，对排查出的隐患，建立安全生产检查台账，做到治理责任、措施、资金、期限和应急预案“五落实”，要按照《沂水县供销社安全生产风险分级管控与隐患排查治理两个体系建设实施方案》（沂供字［2017］18号）要求，深入开展“两进四化”活动，通过“两个体系”建设，稳步提升企业安全管理水平。

（二）检查阶段（8月至9月上旬）。积极配合县安委会、乡镇政府对企业百日攻坚治理行动工作的检查指导，促进企业隐患和问题整改。同时，县社也将组织相关科室人员，对全系统百日攻坚治理行动进行检查督查，确保各项工作落实到位。

（三）总结汇报阶段（9月30日前完成）。 各企业要对百日攻坚治理和大检查工作开展情况全面总结，梳理存在的问题，提出改进措施，形成总结报告，于9月30日前报县社安全统筹科。

四、工作要求

（一）加强组织领导。安全生产百日攻坚治理行动，是确保安全生产稳定大局，为党的十九大创造安全稳定的重要举措。各企业要高度重视，加强领导，明确责任，制定切实可行的实施方案，认真组织实施，把百日攻坚治理行动与“大快严”集中行动、“两体系建设”’等工作紧密结合，统筹协调、科学实施、务求实效。

（二）严格监督、注重实效。对排查出的各类隐患要盯住不放，一抓到底，对重大隐患要及时上报。对一般隐患要及时整改，做到边查边改、边整边销，确保隐患整改及时到位。要坚持从严监督，对拒不整改或整改无望的单位，做到该停产的坚决停产，该关闭的坚决关闭。

（三）加强汛期安全和应急救援。汛期将至，高温、暴雨、雷电等灾害性天气增多，事故易发多发，各企业对检查发现的可能导致重特大事故发生的重大隐患和严重违法违规行为，要坚决彻底整改和杜绝。加强值班值守，完善应急机制，健全与相关部门信息共享和协调联动机制，强化灾害天气预测预警，防止自然灾害引发的事故灾难。完善应急救援预案，熟练掌握各种事故灾难的应急处置方法，不断提高应急救援和处置水平。

（四）强化责任落实。各企业要强化责任意识，认真开展百日攻坚治理行动，对行动不迅速、工作流于形式的，进行通报批评。对因工作不认真、组织不得力、措施不到位等原因导致事故发生的，严肃追究相关人员责任。
