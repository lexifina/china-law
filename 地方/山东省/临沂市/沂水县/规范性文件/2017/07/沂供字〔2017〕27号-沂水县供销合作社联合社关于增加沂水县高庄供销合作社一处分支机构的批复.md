# 沂水县供销合作社联合社关于增加沂水县高庄供销合作社一处分支机构的批复

沂供字〔2017〕27号

沂水县高庄供销合作社：

你社报来关于增加一处分支机构的申请报告已收悉，经县社党组研究决定，为更好的服务“三农”，同意你社增加沂水县高庄供销合作社正大路宾馆一处分支机构。
