# 沂水县市场监督管理局2017年度电线电缆类商品质量监督抽查实施方案

沂市监字〔2017〕30号

一、任务来源

临沂市工商行政管理局关于转发《山东省工商局关于转发工商总局办公厅开展流通领域电线电缆质量监督检查的通知》的通知、临沂市安全生产委员会《全市电气火灾综合治理工作实施方案》

二、抽检产品种类

电线电缆、电源开关、电源插排

三、抽样区域、抽样对象及抽样时间安排

抽样时间：2017年7月

抽样区域：沂水县境内

抽样对象：沂水县各电线电缆经营业户

四、抽样实施及抽样方法、抽样数量

抽样实施：抽样时，抽样人员不得少于2名，应当向被抽查单位出示组织本次监督抽查开具的《流通领域商品质量抽查检验通知书》和有效身份证件，并履行告知义务，向被抽查单位介绍监督抽查的有关规定后，再进行抽样。抽样时，对辖区内不同经营业户的同一商标同一型号的商品不做重复抽检。

抽样方法：以购买的方式随机抽取经企业检验合格或以任何方式表明合格的产品，所抽取产品的保质期应能满足检验工作的进行。备份样品由经营者免费提供。

抽样数量：此次抽检电线电缆10个、电源开关10个、电源插排10个共30个样品，随机从十户经营者处抽取样品，每户随机抽取2个样品。每个样品两份，其中送检一份，备份一份。抽样基数应大于抽样数量。

抽样单位确立：采用随机摇号的方式，从各监管所上报的辖区经营业户中抽取十户经营业户进行抽样。抽取的业户未经营抽样商品或达不到抽样基数要求的，从该辖区再随机抽取经营业户进行抽检。

五、检测项目

电线电缆抽检项目：1、导体电阻，2、结构检查，3、绝缘护套机械抗张强度，4、绝缘护套厚度，5、标志。

电源开关检测项目：标志、防触电保护、固定式插座的结构、尺寸检查、机械强度、耐热。

电源插排检测项目：标志、防触电保护、接地措施、软缆及其连接、插头和移动式插座的结构、机械强度、耐热、尺寸检查。

六、判定原则

1.合格品：经检验，所检项目全部合格，判定为被抽查产品所检项目合格

2．不合格品：所检项目中任一项或一项以上不合格，判定为被抽查产品不合格

七、异议处理复检

1.对判定不合格产品进行复检时，按以下方式进行：

（1）核查不合格项目相关证据，能够以记录（纸质记录或电子记录或影像记录）或与不合格项目相关联的其他质量数据等检验证据证明。

（2）需对不合格项目的复检时，在规定时效内，有异议的企业向任务下达部门提出复检要求，由任务下达部门核准在其他实验室对备用样检验。当复检结果仍不合格，维持原检验结果不变。当复检结果合格，以复检结果为准。

2．不进行复检的情况：

（1）被检方提出复检时，产品在复检有效期内于正常贮存条件下已损坏的；超出复检期，超出样品保质期等。

（2）法律、法规规定不得复检的其他情况。

八、抽样检验过程中需要注意的其他情况

1、抽取样本严格按照任务分配单上规定的各业态抽检数量抽取。

2、承检机构应提前与沂水县市场监督管理局联系确定抽样时间及地点，按约定时间到达约定地点，承检机构进行抽样，市场监管执法人员配合完成，加封承检机构自备的封条（备注：每份备样需独立封样）。抽样结束后，检验机构应将抽样单（粉联）交所在地市场监管部门。

3、备样封存地：由经营者自行保管。

4、样品购买费用有承检机构先行垫付，和检测费共同结算。

九、承检机构

由县局财务科按照财物程序进行询价，报县局财物领导小组确立。
