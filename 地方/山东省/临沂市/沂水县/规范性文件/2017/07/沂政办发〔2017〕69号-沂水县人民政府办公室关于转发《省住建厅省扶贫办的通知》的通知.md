# 沂水县人民政府办公室关于转发《省住建厅省扶贫办的通知》的通知

关于转发《省住建厅省扶贫办<关于进一步做好建档立卡贫困户危房改造工作>的通知》的通知

沂政办发〔2017〕69号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

省住建厅和省扶贫办联合印发了《关于进一步做好建档立卡贫困户危房改造工作的通知》,现转发给你们，并提出以下要求，请一并认真贯彻落实。

一、明确核查范围。本次核查范围为2016年以来所有建档立卡贫困户(含已脱贫和未脱贫)。

二、明确核查时限。7月15日前，各乡镇人民政府、沂城街道办事处、沂水经济开发区、沂蒙风情旅游景区(以下简称“各乡镇”)将核准公示后签字确认并加盖公章的建档立卡贫困户危房信息核查统计表、汇总表，分别报送县住建局和县扶贫办。

三、深入自查自纠。各乡镇要以本次建档立卡贫困户住房信息核查为契机，对今年辖区内所有建档立卡贫困户进行危房改造申请、危房鉴定、村集体评议和公示、乡镇审核等相关程序内容进行全面自查，确保各项内容真实，程序规范到位，各类公示材料要保存至竣工验收阶段，搞好备查备用。凡是程序缺失或规范不到位的，县里将取消危房改造补助资格。

四、及时启动建设。对经审核有改造意愿的建档立卡贫困户，务于7月25日前完成前期程序并启动开工建设；7月25日前未开工建设的，视为各乡镇自动放弃，并由各乡镇出具书面材料进行说明。

五、严格改造标准。各乡镇要把建档立卡贫困户危房改造质量安全放在第一位，严格按照“五个基本”要求组织施工，严控房屋改造面积，凡是超出面积上限的，一律不予验收。

六、准确录入系统。各乡镇对本次核实后的建档立卡贫困户危房改造信息情况，要及时与县扶贫部门对接，认真梳理相关内容，确保7月31日前完成住建部住房信息系统录入。

建档立卡贫困户危房改造及相关信息关系脱贫攻坚整体成效，关系广大群众切身利益，各乡镇、各有关部门要高度重视，安排专人，严格按上级规定要求做好相关工作，确保我县脱贫攻坚工作顺利进行。
