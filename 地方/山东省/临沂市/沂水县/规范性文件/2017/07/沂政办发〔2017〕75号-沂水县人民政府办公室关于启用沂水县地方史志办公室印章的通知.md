# 沂水县人民政府办公室关于启用沂水县地方史志办公室印章的通知

沂政办发〔2017〕75 号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

根据省市地方史志工作要求，县地方史志编纂委员会办公室 需更名为县地方史志办公室，县编委会办公室已研究通过，现制发“沂水县地方史志办公室”印章1枚，自公布之日起启用。
