# 沂水县人民政府办公室关于印发沂水县创建省级卫生计生综合监督示范区工作实施方案的通知

沂政办发〔2017〕83号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

《沂水县创建省级卫生计生综合监督示范区工作实施方案》已经县政府研究同意，现印发给你们，请认真贯彻落实。

沂水县人民政府办公室

2017年7月26日

沂水县创建省级卫生计生综合监督示范区工作实施方案

为加快推进卫生计生监管职能转变，加强卫生计生监督执法 体系建设，推进全县卫生计生工作依法治理，确定开展创建省级生计生综合监督示范区工作，结合我县实际，特制定本方案。

一 、指导思想

深化卫生计生体制改革，创新监督服务模式，优化工作秩序， 促进管理理念转变，全面强化公共卫生、医疗卫生和计划生育监管，进一步提高服务供给质量，推动全县卫生计生事业科学发展。

二、 工作目标

2017年，创建成省级卫生计生综合监督示范区，建立起政 府主导、部门联动、行业监管、社会参与的卫生计生综合监督管 理体制和工作机制，监督执法体系得到进一步完善，监管职责得 到有效落实，监管水平大幅提高，卫生计生工作秩序和服务质量 明显改善，违法违规行为明显减少，群众自我保护意识和能力明显提升，健康权益得到有效保障。

三、 主要评价指标

卫生计生综合监督工作达到全省先进水平，重点指标保持较高水平，具体如下：

(一)知识普及指标。主要包括示范区卫生计生法律知识宣 传覆盖率、管理相对人相关法律法规知识知晓率、综合监督人员法律法规掌握率等。

(二)行政许可指标。主要包括卫生计生行政许可集中受理率、规范公示率、规范审批率、规范建档率等。

(三)监督检查指标。主要包括管理相对人依法持证率、建 档率、监督覆盖率、规范检测率，相关专业监督频次和监督抽检 合格率、综合评价率、规范管理率，监督抽检任务完成率和结果及时报告率等。

(四)行政处罚指标。主要包括群众举报投诉规范受理办理 率、行政执法和案卷管理规范率、行政处罚公示率。行政复议和 行政诉讼案件逐年下降，无变更或取消行政处罚决定、败诉及国家赔偿案件等。

(五)保障支持指标。主要包括监督协管服务覆盖率、监督 信息报告准确率。行政管理、行政许可、监督检查和行政处罚基 本实现信息化，机构设置、人员配备、监管职能、经费保障、基 础设施、办公设备和取证装备均达到国家和省级要求，近两年内无卫生计生行政部门及其监督机构违法违纪案件等。

(六)特色创新指标。主要包括卫生计生综合监督工作改革创新取得明显成效，独具特色，代表发展方向。

(七)效果评价指标。主要包括卫生计生监督执法效果总体 水平处于全省前列，无社会影响恶劣的重大违法案件，群众对卫生计生服务依法执业水平满意度保持较高水平等。

四、 重点工作内容

(一)完善监督体系建设。结合卫生计生体制改革，有效整合监管资源，健全完善监督网络，建立独立的监督机构，推行一支队伍综合执法，集中承担医疗卫生、公共卫生和计划生育监督 工作；整合乡镇、街道卫生和计划生育监管力量，设立专门的卫 生计生综合监督办公室，全面承担本辖区内公共卫生、医疗卫生 和计划生育工作等监督服务；充分发挥计生专干和乡村医生的作 用，在农村和城市社区设立专兼职综合监督工作协管员，实现监 督服务全覆盖。加快建立卫生计生综合监督与县、乡、村三级联动执法新机制。

(二)提高监管水平。全面履行卫生计生监管职责，深入开展 涉及的法律法规落实情况监督检查，推动落到实处。落实属地管理 责任，实现所有监督对象、监管项目全覆盖。积极探索施行符合我 县实际、富有实效的监管模式，提升监督水平。加快卫生计生行政 执法信息化建设，进一步健全监督执法、行政许可、行政处罚等系统，推动监管过程、执法流程及行政审批基本实现网上办理。

(三)加大执法力度。 规范卫生计生行政监督和行政处罚程 序，细化执法流程，严格执法步骤、环节和时限，不断提高执法 效率和规范化水平。坚持有案必立、有立必办、有办必果，对符 合立案条件的，在法定期限内立案调查，非经法定程序不得擅自 销案或停止案件查办。严格落实行政处罚裁量权适用规则和裁量 基准，严禁滥用自由裁量权。依法查处媒体曝光事件和群众举报 投诉案件，健全案件受理平台，完善调查处理、反馈应对机制。 严格落实行政执法责任制和责任追究制，加强执法监督和层级稽 查。建立顺畅的行政执法与刑事司法衔接机制，健全案件移送标准和程序，完善信息共享、案情通报制度。建立执法案卷评议制度，对行政处罚案卷进行量化评分。健全处罚档案管理措施，妥善保管相关处罚案卷。

(四)规范行政许可。健全完善各项许可审批规章制度，理 顺内部运行机制，逐项编制审批流程图，落实审批责任，确保卫 生计生行政许可标准化、规范化。积极推行集中审批，做到“一 个窗口对外、 一条龙服务、 一站式办结”。严格按照审批标准和 要件进行审批许可，非因法定事由不得额外增加或者附加审批条 件，严禁擅自降低审批标准或更改条件。优化审批流程，压缩审 批时限，提高审批效率。加强行政审批档案管理，所有审批事项均建立独立档案，并妥善保存。

(五)提升服务能力。 加强监督机构标准化建设，卫生计生 综合监督经费纳入财政预算，业务用房、执法车辆、取证工具、 快速检测、信息化能力装备配置等方面能够满足工作需要。着力 加强队伍建设，监督人员配备达到国家或省规定标准；落实监督 执法人员培训规划，提高执法人员业务素质。强化行政执法质量控制，及时发现和纠正行政执法存在的突出问题。

(六)强化法制宣传。综合运用多种宣传途径普及相关法律 法规，提高管理相对人自律能力和广大群众自我保护能力。推行 卫生计生执法监督信息公示制度，依法公示卫生计生服务主体信 用信息和行政处罚案件信息，增强监督执法透明度。建立完善新 闻宣传和信息通报制度，强化对卫生计生综合监督执法的社会宣传，加大对违法案件曝光力度。

(七)注重综合治理。根据卫生计生监管工作需要，建立部门间密切协调机制，强化信息共享，开展联合监督执法，形成卫生监督执法合力。实行有奖举报制度，发挥社会监督作用。

五、 工作要求

成立由县政府分管领导任组长的创建工作领导小组，办公室 设在县卫计局，具体负责工作规划制定、组织实施、综合协调、 督导评估等工作。同时，成立由相关领域人员组成的专家组，负 责技术指导和决策咨询。要建立健全卫生计生综合监督执法体系 建设，加大卫生计生两支执法队伍融合力度，确保工作高效开展。 要加大投入保障力度，提高装备水平，保障示范区建设顺利推进。 要充分发挥各类媒体作用，加强对创建工作的宣传引导，主动回 应社会关注的热点，调动广大群众参与示范区建设的积极性，形 成创建合力。县领导小组办公室要牵头会同有关部门，督导各创 建单位工作开展情况，定期通报创建工作进展情况，对考评不达标的限期整改，确保创建工作取得实效。
