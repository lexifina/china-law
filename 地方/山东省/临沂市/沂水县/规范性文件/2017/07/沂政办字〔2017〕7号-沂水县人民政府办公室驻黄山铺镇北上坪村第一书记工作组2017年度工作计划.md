# 沂水县人民政府办公室驻黄山铺镇北上坪村第一书记工作组2017年度工作计划

沂政办字〔2017〕7号

为认真贯彻县委《关于选派第三批机关干部到村任职第一书记的意见》精神，积极落实“五抓五促”目标任务和“四联八建”工作部署，根据任职两年工作规划，结合2016年工作情况和镇、村实际，特制定2017年工作计划。

一、抓党建促脱贫方面

(一)加强村“两委”班子建设。通过第一书记工作进一步带动村里各项事业发展，提高两委班子依法办事能力，进一步提升村班子的凝聚力和战斗力。积极向党员和村民解读换届选举法，宣传换届选举工作的重要意义和主要程序，做到换届工作家喻户晓，为年底村“两委”换届工作顺利开展打好基础。

(二)加强党员队伍建设。进一步规范支部“三会一课”制度，深入开展党员“两学一做”学习教育，坚定党员理想信念。加强新队伍建设，达到本乡镇中等以上水平，保持党员干部队伍稳定，发挥好党员模范带头作用。2017年，转正预备党员1名。

二、抓扶贫促增收方面

一是积极争取农业局特色农业项目帮扶资金40万元，计划新建蔬菜大棚4个，开展规模化种植，为脱贫提供有力支撑。二是积极争取派出单位帮扶在大棚园区打深井1眼，解决蔬菜大棚冬季用水。三是积极争取50千伏光伏项目落地，项目落地后，预计每年实现村集体增收4万元，对实现脱贫攻坚起到重要作用。2017年，完成剩余7户贫困户10人脱贫任务。

三、抓服务促融合方面

一是落实好村“两委”成员集中办公、集中议事、轮流值班等制度，保证昼夜有人值班，随时随地解决群众实际问题。二是进一步规范村级事务集体决策和严格落实“四议两公开”制度。三是完善村医务室设施，确保医生定期坐诊。四是对图书阅览室实行专人管理，定时开放，方便村民获取知识。五是绿化美化村主要街道，构建良好的乡村文明环境，增强村民的幸福感。计划栽植各类苗木3000株以上。

四、抓民生促和谐方面

协调有关单位做好老党员、贫困户慰问及相关送温暖活动，帮助他们解决实际困难；积极寻求慈善公益机构和爱心人士对贫困儿童进行资助；开展乡村文艺展演、广场舞演出等文体活动，进一步丰富村民的精神生活。

五、抓乡风促文明方面

认真做好推进殡葬改革的相关工作，正确引导村民自觉践行文明新风。

加强领导，精心保障。认真贯彻落实省、市、县精准扶贫工作精神，探索扶贫帮困新思路。继续贯彻县府办、金融办主要领导现场办公和班子成员陪住制度，加大对第一书记工作支持力度，年内投入帮扶资金不少于5万元，确保扶贫帮困经费、物资及人力发挥最大效能，圆满完成年度工作任务目标。

沂水县人民政府办公室
