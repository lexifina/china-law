# 沂水县人民政府办公室关于成立沂水县土地二级市场建设试点工作领导小组的通知

沂政办发〔2017〕79号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府有关部门：

为进一步加强对全县土地二级市场建设试点工作的组织领导，根据国土资源部《关于完善建设用地使用权转让、出租、抵 押二级市场的试点方案》(国土资发〔2017〕12号)要求，经研究，决定成立沂水县土地二级市场建设试点工作领导小组，现将成员名单公布如下：

组　长：陈永生　县委副书记、县政府县长

副组长：陈海龙　县委常委、县政府常务副县长

成　员：张希国　县发改局局长

冯培辅　县经信局局长

杨振龙　县住建局局长

张晓华　县财政局局长

领导小组下设办公室，办公室设在县国土资源局，牛树娟同志兼任办公室主任，刘汝华、郭磊同志任办公室副主任。
