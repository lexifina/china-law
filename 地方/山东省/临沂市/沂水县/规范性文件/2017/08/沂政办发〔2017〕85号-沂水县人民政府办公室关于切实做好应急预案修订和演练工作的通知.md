# 沂水县人民政府办公室关于切实做好应急预案修订和演练工作的通知

沂政办发〔2017〕85号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府有关部门：

为进一步提高应对处置各类突发事件的能力，保障全县人民 群众生命财产安全和社会稳定，根据突发事件应急预案管理的有 关规定和要求，现就做好2017年专项应急预案修订和演练工作通知如下：

一、注重实效，做好应急预案修订工作。 各级各有关部门要 按照“统一规划、分类指导、分级负责、动态管理”的要求，紧 密结合实际，重点研究新情况、新问题，合理确定应急预案修订 内容，提高预案的针对性、实用性和可操作性。 一是要坚持预防 和救援并重，进一步完善相关行业的专项应急预案，全面落实应急处置责任，逐步构建完善的应急预案体系，做到整体预案与单项预案相互贯通、上下衔接，确保预案管用实用。二是要规范专 项应急预案的修订、审批、发布程序，形成预案修订初稿后，要 征求相关部门单位意见，组织专家评审，形成送审稿。专家评审 意见、部门会签意见和送审稿报送县政府应急办，按程序审签后 报县政府审定发布。各有关部门要立足各自职责分工，相互支持， 密切配合，按三年修订一次的标准，认真搞好各自专项应急预案修订工作。

二 、严格程序，落实应急预案备案制度。 应急预案备案是突 发事件应急预案管理中不可或缺的重要环节。各级各有关部门要 严格按照省、市应急预案管理办法要求，做好应急预案备案工作。 一是“县级专项应急预案”要以县政府办公室名义下发，由相关 部门报上级行业主管部门和县政府应急办备案；二是“相关部门 应急预案”要以部门名义下发，同时报上级行业主管部门和县政 府应急办备案；三是“乡镇总体应急预案”由乡镇人民政府编制 并印发实施，报县政府应急办备案。四是“大型活动应急预案” 要在活动举行前15日内报相关主管部门审定，根据需要通过协 同办公系统报县政府应急办备案。五是各有关部门单位要在各自职责范围内，积极做好本单位所属企业的预案修订备案工作。

三、 精心组织，强化应急救援演练工作。 各级各有关部门要 切实组织好应急救援演练工作，相关部门要积极参与，密切配合， 认真落实预案规定的各项响应措施，按期完成演练任务，不断提 高应对处置和应急救援能力。同时，各级各有关部门要结合各自 实际，分层次、分类别，提前筹划，周密部署，组织开展重点突 出、针对性强的应急救援演练。要依据《国务院应急办预案演练指南》,针对应对突发事件的薄弱环节，科学编制演练脚本和实施方案，做到时间、地点、目的、科目、步骤、情景设置、指挥 机构、参演队伍、演练保障等要素完整，流程清晰，节点明确， 让所有参演队伍熟知各自的演练任务。要注重实效，贴近实战， 增强应急演练场景的仿真程度，加强部门联动，防止流于形式。 演练结束后要认真总结、评估，及时发现问题和制定相应整改措 施，不断补充完善应急预案，演练结束后3日内要将演练开展情况连同演练有关图片通过协同办公系统报县政府应急办。

各级各有关部门要根据实际，认真做好本乡镇、本部门应急 预案的修订及演练工作。预案修订要按照县里统一时间要求及时 安排落实。演练计划要提前1个月报送县政府应急办。各级各有 关部门要将本单位专项应急预案和部门应急预案于10月31日前 报送县政府应急办，纸质材料需加盖公章并经主要负责人签字，相应电子版通过协同办公系统发送县政府应急办。

县政府应急办地址：县政府办公楼一楼西侧。

联系电话：0539—2225001。
