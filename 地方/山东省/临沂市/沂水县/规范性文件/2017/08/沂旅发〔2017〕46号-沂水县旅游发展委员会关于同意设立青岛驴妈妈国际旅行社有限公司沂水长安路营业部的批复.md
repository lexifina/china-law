# 沂水县旅游发展委员会关于同意设立青岛驴妈妈国际旅行社有限公司沂水长安路营业部的批复

沂旅发〔2017〕46号

青岛驴妈妈国际旅行社有限公司：

你单位关于设立青岛驴妈妈国际旅行社有限公司沂水长安路营业部的申请材料收悉，根据《旅游法》、《旅行社条例》有关规定，同意你单位设立青岛驴妈妈国际旅行社有限公司沂水长安路营业部。

鉴于你单位正在申请出境资质，你单位的工商营业执照与旅行社业务经营许可证的经营范围（许可经营业务）存在不一致现象，请你单位在特殊时期做好对营业部的日常管理工作，确保严格按照相关法律法规开展业务，在未取得出境经营资质前，不得组织该营业部开展关于出境旅游的招徕咨询服务。

特此批复。

沂水县旅游发展委员会

2017年8月7日
