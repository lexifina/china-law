# 沂水县人民政府办公室关于印发沂水县加油站等成品油行业领域整治提升工作实施方案的通知

沂政办发〔2017〕110号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

现将《沂水县加油站等成品油行业领域整治提升工作实施方案》印发给你们，请认真贯彻落实。

沂水县人民政府办公室

2017年9月14日

沂水县加油站等成品油行业领域整治提升工作实施方案

为进一步加强成品油全过程监管，严厉打击各类违法违规生产经营行为，全面提升油品质量，改善大气环境，确保安全生产，根据上级要求，结合我县实际，制定本方案。

一、总体要求

围绕规范成品油生产经营市场秩序、保障油品质量，进一步健全完善从成品油生产到仓储、批发、加油站和运输企业、车辆、人员严密的全过程监管体系，严格落实成品油生产经营准入标准，坚决取缔非法加油站，深挖成品油生产经营地下窝点，整顿规范成品油生产经营行为，从生产源头到零售终端全面提高成品油质量，实现成品油生产规范、经营有序、供应稳定。

二、工作重点

(一)进一步规范加油站经营行为。对县内所有加油站进行全面摸底排查，并开展规范整治。对环保、安监、消防、经信、规划、土地等手续不完善的，由相关部门责令限期整改完善，逾期未按标准要求完成整改的，依法予以关闭；对存在销售不符合国家质量标准油品、计量作弊、坑骗消费者、偷逃税款、存在安全隐患、假冒其他企业商标标识等违法违规经营行为的，由相关部门依法予以处理，并视情节责令限期整改，逾期未完成整改或整改不到位的，依法吊销相关证照。依法清理取缔非法加油站点。(责任单位：县经信局、安监局、消防大队、市场监管局、环保局、住建局、国土资源局、综合执法局、规划局、国税局，各乡镇、街道、沂水经济开发区、沂蒙风情旅游景区(以下简称“乡镇”))

(二)进一步加强对生产环节的监管。全面排查无证无照涉油生产或调和企业，督促炼油企业健全完善进销台账，并加强对组分油以及国IV标准车用汽、柴油流向的监管；依法严厉查处国IV冒充国V、普通柴油冒充车用柴油、组分油冒充成品油、不合格品冒充合格品等违法违规行为。(责任单位：县市场监管局)

(三)切实保障运输环节油品质量。严格成品油运输企业资质审查，加强专用车辆和设施设备管理。对成品油运输车辆进行实时监控，及时登记并报告车辆运行状态。依法严厉查处成品油运输过程中掺假降质、改装非法流动加油车、非法改装成品油运输车、非法运输车辆运输成品油、不具备从业资格人员非法驾驶和押运成品油运输车等违法违规行为。(责任单位：县交通运输局、交警大队)

(四)进一步加快油品质量升级。认真落实国家发展改革委等11部委《关于进一步推进成品油质量升级及加强市场管理的通知》(发改能源〔2016〕349号)要求，停止县内加油站销售低于国V标准的车用汽、柴油。县内所有加油站供应的普通柴油全部达到国IV标准。(责任单位：县经信局、市场监管局)

(五)进一步加大检测监管力度。各乡镇、各有关部门要采取联合检查、交叉检查、突击检查、随机抽查等方式，每季度开展不少于1次的不定期检查，重点查验加油站供油协议、进货发票台账、油品标识、油品抽检等，并建立完善检查记录和成品油质量抽检档案。市场监管部门要根据《临沂市大气污染防治2017年攻坚行动方案》要求，按照“月月有抽检、月月有处罚、月月有曝光”的原则，统筹安排全年抽检计划，每月抽检加油站、油品仓储和批发企业数量不低于总数的30%,确保本年度内对县内所有加油站、油品仓储和批发企业实现全覆盖抽检。(责任单位：县市场监管局、经信局，各乡镇)

(六)认真做好加油站油气回收工作。10月31日前，县城建成区范围内所有加油站全部安装油气排放处理装置(三次油气回收改造),并完成验收；12月31日前，年销售汽油量大于8000吨的加油站，全部安装油气回收在线监测系统，并按要求校准检测；逾期达不到要求的，一律停业整治。全县所有加油站对油气回收管线液阻、油气回收系统密闭性、气液比、处理装置的油气排放浓度每年至少检测1次。加油站营业过程中要正常使用油气回收设施，并建立油气回收使用台账，其中一次油气回收(卸油过程)要留存监控视频。(责任单位：县环保局、经信局、安监局、市场监督管理局、消防大队，各乡镇)

(七)扎实做好加油站地下油罐防渗改造工作。按照全面治理、分段实施、分批推进的原则，年底前完成正常在营加油站地下油罐更新为双层罐或防渗池设施改造，并由县环保部门做好验收认定并出具验收结论。(责任单位：县环保局、经信局、安监局、消防大队，各乡镇)

(八)着力提升加油站安全管理水平。各乡镇、各有关部门要督促加油站利用地下油罐改造时机，全面改造提升硬件设施安全水平，强化安全运营管理，加强安全操作流程培训，消除安全隐患，坚决杜绝安全生产事故发生。严禁向汽车和摩托车销售普通柴油以及其他非机动车用燃料。散装汽油销售必须持身份证实名登记。(责任单位：县安监局、公安局、消防大队，各乡镇)

三、工作步骤

(一)宣传发动和调查摸底阶段(2017年9月15日-30日)。各乡镇要大力宣传整治提升工作的目标、任务和措施，并组织人员对辖区内油品生产、运输、销售企业进行全面调查摸底，并按照合法经营、整顿改进、依法取缔等分门别类建立专项整治台账。

(二)规范治理阶段(2017年10月1日-31日)。对摸底排查出的需要整顿的企业，由相关职能部门下达限期整改通知书，限期按标准要求予以整改。对逾期未完成整改或整改后仍未达标的，依法采取责令停止经营、查封或没收经营设施、罚款、拆除违章建筑等措施。要对照非法加油站整治台账逐一核实，并现场拍照存档备查。对非法生产企业、非法加油站(点)、非法改装流动加油车等，要坚决取缔并逐一登记造册。

(三)巩固提升阶段(2017年11月1日-30日)。各乡镇要及时组织开展“回头看”活动，坚决防止出现死角和遗漏，把成品油监管工作推向深入。积极推进成品油终端资源整合，加强行业自律，引导我县石化企业以市场为导向，建立成品油零售终端品牌联盟，形成成品油来源渠道、运输、销售等上下游完整的产业链，打造地方成品油品牌。

(四)督导检查阶段(2017年12月1日-31日)。各乡镇通过总结巩固、建章立制后，向县成品油监管联席会议办公室（以下简称“县联席会议办公室”）提报专项整治工作总结及工作台账。县联席会议办公室组织相关部门，成立专项督导组，对各乡镇成品油生产经营企业专项整治工作进行全面督导，对未按要求完成的整治提升任务的，及时采取督办、约谈等措施，并限期整改到位。

四、保障措施

(一)明确工作职责。各乡镇、各有关部门要严格落实属地管理责任和监管责任，切实加强组织领导，强化工作措施，密切协作配合，确保专项整治提升工作取得实效。充分发挥成品油监管联席会议作用，建立健全信息共享和交流渠道，及时协调解决工作中遇到的困难和问题，会商重大案件，规范执法监管行为，形成工作合力。经信、公安、安监、环保、市场监管、交通运输、综合执法、国税等部门要根据职责分工，加强联合执法，健全违法线索通报、移交处置等工作机制，依法严厉打击各类违法违规行为。

(二)加强宣传引导。要充分利用各类媒体，大力宣传成品油生产经营企业专项整治提升工作的重要意义、相关政策及工作成效，积极引导社会公众参与监督，设立并公开举报电话，鼓励群众举报违法违规行为。对群众举报由专人负责，逐一落实，进一步规范市场秩序，维护广大消费者合法权益。

(三)加快企业诚信体系建设。建立完善成品油生产经营企业“黑名单”制度，实行信息发布制度，对抽检不合格的加油站，在抽检不合格结论确定后，每月由经信、市场监管部门联合在新闻媒体公开曝光，同时通过宣传单、微博、微信等形式向辖区内所有加油站及全社会公开曝光。

(四)严格责任追究。进一步加大对油品不达标、安全环保存在问题加油站的管理处罚力度，从严从快落实处罚措施，提高违法成本，强化警示作用。发现一次油品不达标，依法顶格处罚并停业整顿3个月以上；再次发现，情节严重的，依法吊销相关证照。进一步严明执法责任，对油品监管工作落实不到位、查处不得力、整治不彻底的单位，予以约谈或通报批评，并限期整改；对案件查处不力、造成不良社会影响的，视情追责；涉嫌犯罪的，依法追究刑事责任。
