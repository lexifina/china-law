# 沂水县人民政府办公室关于印发沂水县板材行业环保突出问题专项整治提升工作实施方案的通知

沂政办发〔2017〕111号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

现将《沂水县板材行业环保突出问题专项整治提升工作实施方案》印发给你们，请认真贯彻落实。

沂水县人民政府办公室

2017年9月14日

沂水县板材行业环保突出问题专项整治提升工作实施方案

为进一步解决全县板材行业环境突出问题，切实规范生产经营秩序，改善生产经营环境，加强环境保护，特制定本方案。

一、总体要求

根据《大气污染防治法》、《山东省大气污染防治条例》等相关法律法规要求，坚持有序发展与环境保护并重，按照严格管理、分类整治的工作思路，通过开展板材行业环保突出问题专项整治提升，淘汰一批落后企业和产能，依法严厉打击环境违法行为，督促企业完善相关手续，推动企业使用清洁能源，配套环保污染治理设施，全面改善生产经营环境，提升管理水平，倒逼企业加快新旧动能转换，实现板材行业健康协调、规范有序发展。

二、工作重点

(一)突出产业整合，推动产业转型升级。按照“整合壮大一批，规范提升一批，关停淘汰一批”的思路，引导板材骨干企业加大资源整合力度，实现规模扩张、管理规范、提质增效、引领行业的目标，辐射带动配套小微企业协同发展，引领产业转型升级。对相关手续不完善及污染治理不达标的企业，责令停产整治；对整治无望的企业，一律依法予以关停取缔。

(二)突出燃煤污染整治，推广使用清洁能源。各乡镇、街道、沂水经济开发区、沂蒙风情旅游景区(以下简称“乡镇”)要督促企业按上级有关规定要求，使用电、天然气等清洁能源；对辖区内木皮企业生产过程中使用燃煤锅炉、土炉的，要发现一处拆除一处；对压板企业不正常使用清洁能源的，要会同有关部门及时予以停产整顿。

(三)突出污染防治设施改造提升，确保达标排放。各乡镇要督促符合发展规划要求的板材生产企业，配套建设与其生产规模相适应的污染物排放治理设施，对挥发性有机物、粉尘等进行集中收集处理，确保有组织达标排放。

(四)突出规章制度建设，综合整治厂区环境。各乡镇要督促板材企业完善相关手续，建立现场管理制度，健全安全生产、环保等方面的规章制度和操作规程，配备必要的消防器材，合理划分原料区、生产区、成品区等相关区域，做到物料摆放整齐美观、厂区环境清洁卫生、生产过程规范有序。

三、工作步骤

(一)调查摸底阶段(2017年9月15日-28日)。各乡镇要组织专门力量，在前期工作的基础上，对辖区内所有板材企业的手续办理、生产经营、环境卫生等情况，进行全面调查摸底，进一步托清底数，掌握生产经营现状，建立健全工作台账，对符合产业发展规划但不规范完善的企业要及时下达限期整改通知，对不符合产业发展规划的要下达搬迁、取缔通知，为深入开展专项整治提升打好基础。

(二)整治提升阶段(2017年9月29日-10月31日)。各乡镇要督促辖区内板材企业按照环保要求制定整治提升方案，抓好厂区现场管理，全面治理环境问题。生产过程中有热压工序的板材企业，必须配备相适应的挥发性有机废气收集处理设施，对生产过程中产生的废气进行收集处理，做到达标排放；有砂光、锯边工序的，必须配备除尘器、除尘房等粉尘收集设施，加大粉尘污染治理力度，对砂光粉进行综合利用。鼓励企业使用通过中国环境标志产品认证的环保型胶黏剂和水性环保型胶黏剂。对环评手续不完备的企业，由环保部门责令限期整改，按规定程序完善相关手续；未完善手续前不得组织生产。

(三)检查验收阶段(2017年11月1日-30日)。属地乡镇及相关职能部门对板材企业整治提升情况进行跟踪督导。企业整治完成后，乡镇提出验收申请，报县板材行业环保突出问题专项整治提升工作联席会议办公室(以下简称“县联席会议办公室”)和县环保局后，由县环保局负责会同县发改、经信、市场监管、国土资源、安监、中小企业、节能等单位进行现场检查验收。对经验收不达标的，依法责令限期整改；整改后仍不达标的，依法予以关停取缔。

(四)巩固提升阶段(2017年12月1日-2018年5月31日)。通过组织板材企业负责人外出参观学习、现场培训等方式，拓宽企业负责人视野，主动加大资金投入，提升技术装备水平，加快转型升级、新旧动能转换步伐，推动企业健康发展；同时，通过对企业管理、技术、生产岗位人员进行分层次培训等形式，提高职工队伍整体素质和环保意识，巩固和提升整治成果。按照相对集中、培育集群的原则，积极引导、鼓励符合条件的企业进入工业园区发展。

四、保障措施

(一)强化组织领导，落实工作责任。为加强对工作的组织领导，实行板材行业环保突出问题专项整治提升工作联席会议制度，成员单位包括县发改局、经信局、住建局、国土资源局、市场监管局、综合执法局、环保局、安监局、公安局、中小企业局、规划局、节能办、供电公司等单位，在县中小企业局设立办公室，建立健全常态化会商机制，及时协调解决工作中遇到的困难和问题。各乡镇、各有关职能部门要根据方案要求，明确任务目标和时限要求，严格落实责任，细化工作措施，认真研究制定各自整治提升工作具体实施方案，并成立专门机构，抽调骨干力量，切实抓好各自职责范围内的整治提升工作，做到领导到位、措施到位、落实到位。县中小企业局要充分发挥牵头作用，加强与乡镇和相关职能部门的沟通联系，协调调度好面上工作进展情况，扎实推进整治提升工作开展。各乡镇是整治提升工作的责任主体，要严格落实属地管理责任，全面做好宣传教育、组织发动、整改措施落实等工作。县发改、经信、住建、国土资源、市场监管、综合执法、环保、安监、规划、节能、供电等单位，要按照“谁主管、谁负责，谁许可、谁负责”的原则，根据各自工作职责，扎实落实好整改监督落实责任。

(二)强化督导调度，实行通报制度。县联席会议办公室要加强调度督导，实行周调度、定期通报制度。各乡镇要于每周五上午10时前将工作开展情况分别报县联席会议办公室和县环保局。对工作推进不力、进展缓慢、措施落实不到位的，给予通报批评，并限期整改到位；对未按要求完成整治提升任务的，将严肃问责。

(三)强化部门联动，严格执法监管。各乡镇要积极会同有关职能部门依法严厉查处板材企业安全、环境等违法违规行为，重点加大对板材企业整治提升工作的督促检查、监督执法和责任追究，对拒不整改或整改后仍不达标的，要及时会同相关部门依法予以处理。县环保、国土资源、住建、安监、市场监管、规划等部门要充分发挥职能作用，积极为企业完善相关手续提供优质服务，并加强日常管理。

(四)强化宣传引导，营造良好氛围。要充分利用各类新闻媒体，大力宣传板材行业环保突出问题专项整治提升工作的重要意义和整治成效，让板材生产经营业主充分理解并自觉参与、支持专项整治提升工作，尤其要做好关停、拆除设备企业的宣传教育工作，确保专项整治提升工作顺利进行。
