# 沂水县人民政府办公室关于印发沂水县油缸行业环保突出问题专项整治工作实施方案的通知

沂政办发〔2017〕90号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门∶

现将《沂水县油缸行业环保突出问题专项整治工作实施方案》印发给你们，请认真贯彻落实。

沂水县人民政府办公室

2017年9月3日

沂水县油缸行业环保突出问题专项整治工作实施方案

为有效解决全县油缸行业环保突出问题，进一步规范生产经营秩序，改善生产经营环境，加强环境保护，特制定本方案。

一、总体要求

以相关法律、法规、规章为依据，坚持规范发展与环境保护并重，统筹处理环保优先与保障民生和社会稳定的关系，通过开展油缸行业环保突出问题专项整治，淘汰一批落后企业和设备，依法严厉打击环境违法行为，推动企业改造升级，全面改善生产经营环境，进一步提升管理水平，加快推进全县油缸制造企业新旧动能转换，实现油缸行业健康、规范、有序发展。

二、工作重点

以环保突出问题为导向，针对“脏乱差污散”等问题，按照“提升一批、整改一批、搬迁一批、取缔一批”的原则，区分轻重缓急，分类综合施治。

（一）树立标杆。对符合国家产业政策、手续完备的企业，引导其加快新旧动能转换，促进设备升级，提升产品质量，尽快成长为油缸行业标杆企业。

（二）停产整改。对符合国家产业政策和我县产业布局规划，但相关手续不完善及污染治理不达标的企业，责令停产整顿，并限期整改；手续完善、污染治理达标后，方可恢复生产。

（三）整合搬迁。对符合国家产业政策、经过整改可以达到有关要求的，各乡镇、街道、沂水经济开发区、沂蒙风情旅游景区（以下简称“乡镇”）要会同有关部门进行科学规划，鼓励、引导有条件的上述企业进入工业园区，实行集群化、规模化发展。

（四）关停取缔。对无工商营业执照、手续不完备、不符合国家产业政策和我县产业布局规划、生产环境差、设备老旧落后、产品质量低劣、整改无望的企业，实施“两断三清”（断水、断电、清理原料、清理产品、清理设备），一律依法予以关停取缔。

三、工作步骤

（一）摸底排查阶段（2017年9月20日-10月10日）。各乡镇要在前期工作的基础上，对辖区内企业开展“拉网式”摸底排查，做到摸排一家、分类一家，并根据企业实际，分别下达提升、整改、搬迁、取缔通知，建立工作台账。

（二）整治提升阶段（2017年10月11日-11月30日）。根据调查摸排情况，属地乡镇要督促引导企业按照环保要求制定整治提升方案，全面治理环保突出问题。要搞好生产现场改善，积极推行6S管理模式；要将废油漆桶、废液压油桶、废机油、废切削液等全部纳入危险废物规范化管理，并完善管理制度，健全管理责任制，实现危险废物规范化管理、合理化处置。对环评手续不完善的企业，由环保部门责令整改整顿，按规定程序完善相关手续。对手续不完善的，不得组织生产。

（三）检查验收阶段（2017年12月1日-12月31日）。属地乡镇及相关部门对油缸制造企业整改情况进行跟踪督导。企业整治完成后，由县环保局牵头，会同县发改、经信、市场监管、国土资源、安监、中小企业等部门进行现场评估和验收。对经验收不达标的，依法责令限期整改；整改后仍未达标的，坚决予以关停取缔。

四、保障措施

（一）强化组织领导。为加强对工作的组织领导，实行油缸行业环保突出问题专项整治工作联席会议制度，成员单位包括县发改局、经信局、住建局、国土资源局、公安局、市场监管局、综合执法局、环保局、安监局、中小企业局、规划局、供电公司等单位，建立完善常态化会商机制，健全信息共享和交流渠道，及时协调解决工作中遇到的困难和问题。在县中小企业局设立办公室，抽调发改、经信、环保、市场监管、国土资源、安监、住建、规划等部门业务人员，核对乡镇提报数据的准确性、合法性，对环保突出问题整改工作进行全过程监控。

（二）强化责任落实。各乡镇是油缸行业环保突出问题专项整治的责任主体，要结合实际，认真制定分类施治工作方案，明确任务目标和整改期限，严格落实工作责任，扎实推进摸排和整改。各相关职能部门要按照“谁主管、谁负责，谁许可、谁负责”的原则，明确企业整改的标准和目标，并有效整合执法资源，联动执法，督促企业严格落实。供水、供电、供气、供热等单位要严格按照有关要求，对依法关停取缔的企业，采取相应的停止或限制服务等措施。对存在拒不落实整治要求、擅自违法生产、抗拒检查等行为的企业，由公安机关予以坚决打击。对因工作不力出现漏报、漏改、漏治的单位和个人，将严肃追责。

（三）强化调度督导。县油缸行业环保突出问题专项整治工作联席会议办公室要加强调度督导，实行定期调度、定期通报制度，每半月调度一次，各乡镇要于当月16日及次月1日前分别将整治工作进展情况报联席会议办公室和县环保局。对工作推进不力、进展缓慢的，给予通报批评，并限期整改到位；对未按要求完成整治任务的，将严肃问责。

（四）强化宣传引导。要充分利用各类新闻媒体，积极发挥行业协会和商会作用，大力宣传油缸行业环保突出问题专项整治工作的重要意义和整治成效，让企业经营者及社会各界充分理解并自觉参与、支持专项整治工作，确保专项整治工作顺利进行。
