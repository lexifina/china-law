# 沂水县人民政府办公室关于成立国务院安委会安全生产大检查综合督查迎查工作领导小组的通知

沂政办发〔2017〕96号

各乡镇人民政府，沂城街道办事处，沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

为切实加强对国务院安委会安全生产大检查综合督查迎查工作的组织领导，根据市安委会《关于做好国务院安委会安全生产大检查综合督查迎查工作的通知》(临安发〔2017〕24号)要求，决定成立沂水县国务院安委会安全生产大检查综合督查迎查工作领导小组，现将领导小组成员公布如下：

组　长：陈海龙　县委常委、县政府常务副县长

副组长：宋彦山　县安监局局长

冯培辅　县经信局局长

张晓华　县财政局局长
