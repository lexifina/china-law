# 沂水县人民政府关于收回沂水县城市国有资产运营有限公司国有建设用地使用权的决定

沂政发〔2017〕64号

县政府有关部门：

根据《中华人民共和国土地管理法》《中华人民共和国城市房地产管理法》等法律法规规定，经研究，决定收回沂水县城市国有资产运营有限公司位于县城区鑫华西路以南、龙家圈街道公家疃村国有建设用地8440平方米土地使用权，同时注销以上宗地范围内的颁发的国有土地使用证。具体事宜按收回土地协议书执行。
