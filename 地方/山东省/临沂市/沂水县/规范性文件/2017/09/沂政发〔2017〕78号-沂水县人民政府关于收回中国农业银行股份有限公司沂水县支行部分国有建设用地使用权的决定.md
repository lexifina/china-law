# 沂水县人民政府关于收回中国农业银行股份有限公司沂水县支行部分国有建设用地使用权的决定

沂政发〔2017〕78号

县政府有关部门：

根据《中华人民共和国土地管理法》《中华人民共和国城市房地产管理法》等法律法规规定，经研究，决定收回中国农业银行股份有限公司沂水县支行位于道托镇驻地、东红公路以西部分国有建设用地165平方米土地使用权，同时注销以上宗地范围内的颁发的沂国用(1994)字第189号国有土地使用证。具体事宜按收回土地协议书执行。
