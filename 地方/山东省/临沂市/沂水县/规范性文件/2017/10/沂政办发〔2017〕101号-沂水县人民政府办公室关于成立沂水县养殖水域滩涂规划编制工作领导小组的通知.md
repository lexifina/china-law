# 沂水县人民政府办公室关于成立沂水县养殖水域滩涂规划编制工作领导小组的通知

沂政办发〔2017〕101号

各乡镇(街道)人民政府(办事处),沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

为切实加强对沂水县养殖水域滩涂规划编制工作的组织领导，经研究，决定成立沂水县养殖水域滩涂规划编制工作领导小组。现将成员名单公布如下：

组　长：何法江　县政府副县长

副组长：张德博　县沙沟水库管理处主任

王本昌　县跋山水库管理处主任

成　员：张希国　县发改局局长

杨振龙　县住建局局长

张晓华　县财政局局长

牛树娟　县国土资源局局长

杨明升　县环保局局长

于化凤　县旅发委主任

张洪春　县农业局局长

曹传海　县水利局局长

杨春华　县渔业局局长

江兆祥　县规划局局长

领导小组办公室设在县渔业局，杨春华同志兼任办公室主任。领导小组组成人员因职务调整的，原组成人员自然免除，由新任职人员担任，不再另行发文。
