# 沂水县人民政府办公室关于印发沂水县电子商务发展三年行动计划(2017—2019)的通知

沂政办发〔2017〕115号

各乡镇(街道)人民政府(办事处),沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

《沂水县电子商务发展三年行动计划(2017—2019)》已经县政府同意，现印发给你们，请认真贯彻落实。

沂水县人民政府办公室

2017年10月18日

沂水县电子商务发展三年行动计划

(2017—2019)

为优化电子商务发展环境，提升全县电子商务发展水平，根据市府办《关于印发临沂市电子商务发展三年行动计划(2017—2019)的通知》和县委县政府《关于大力发展电子商务加快推进大众创业万众创新的实施意见》等文件精神，结合我县实际情况，特制定本行动计划。

一、指导思想和发展目标

(一)指导思想

坚持“企业主体、政府引导、统筹兼顾、突出重点”的原则，围绕新旧动能接续转换，以构建沂水经济发展新动力、新优势为目标，全面推动电子商务与传统产业深度融合，不断健全电子商务民生服务体系，构建完善电子商务生态链，优化电子商务创新创业环境，切实加快电子商务提质升级，努力把我县建设成为配套设施齐全、服务特色鲜明、带动能力较强的区域性电子商务中心。

(二)工作目标

自2017年起，力争电子商务交易额年均增长30%以上，到2019年，电子商务交易额超过270亿元，跨境电子商务交易额占外贸进出口总额比重超过10%。全县电子商务发展环境更加优越、支撑体系更加完善、创新能力更加强大，电子商务成为沂水经济社会发展新动能、新引擎。

二、主要任务

(一)全力培育电商新主体。深入实施“十百千”骨干电商企业培育工程，重点扶持行业领先、模式新颖和成长性好的企业，充分发挥骨干企业示范引领作用，打造一批特色鲜明、诚信经营、业绩良好的网商企业。进一步提升传统市场应用电子商务水平，积极支持市场企业、商户利用第三方平台，通过开设网店、建设“特色馆”等方式开展电子商务业务；鼓励电商垂直平台打造，加快培育一批在全国具有较大影响力的行业垂直电商平台。

(二)加快电子商务专业园区建设。以儒道、博远等电商企业为依托，建设食品电商垂直平台，打造食品电商产业园。发挥太阳鞋业等龙头企业的带动作用，打造布鞋电商产业园。依托万德广场载体，推进与一达通深入合作，积极引入跨境电商相关服务商，开展电子商务通关、检验检疫、结汇结算“一体化”服务业务，搭建跨境电商产业园。引导现代农业龙头企业与知名电商服务商合作，深入开展电子商务，推进我县地标及名优特农副产品的网上销售。同时，加大电商物流供应链服务商培育，提升配套服务能力。

(三)大力发展农村电子商务。搞好农商互联，强化“互联网+品牌”,拓展农特产品上行渠道，推动农产品标准化、品牌化、电商化发展。深化电商精准扶贫，完善农村电商三级服务体系，全力打造国家级电子商务进农村综合示范县。

(四)壮大电商人才队伍。积极对接专业电商服务团队，“走出去、请进来”,带动本地电子商务企业专业化发展。继续开展“万名电商在行动”培训工程，发动县内发展较好的网商开展实操传授，提高培训转化率，解决企业电商人才需求。

(五)完善电商基础支撑建设。围绕县电商公共服务中心建设提升，引进专业团队运营县级电商公共服务中心，完善电子商务服务体系。加强与知名电商平台合作，推进乡村服务站和合作点建设，进一步完善县、乡镇、村一体化电商服务网络体系。整合物流体系，探索构建物流(快递)企业与电子商务企业合作发展平台，打通农村物流“最初一公里”和“最后一公里”

三、工作重点

(一)电商应用提升工程

1.商贸流通业电商提升专项行动。推进零售业与电子商务融合，支持新零售发展，鼓励城市综合体、购物中心等应用电子商务，支持餐饮、住宿、休闲娱乐、家政服务等企业深化电子商务应用，提升服务质量，促进线上线下融合发展，在城区建设一批智慧商圈。开展“智慧便利店进社区工程”,每年引导15家左右的智慧便利店进驻社区。(责任单位：县商务局)

2.工业制造业电商提升专项行动。以规模以上工业企业为重点，支持工业企业应用电子商务改造提升，完善网络销售渠道体系，大力实施“互联网+智能制造”,打造一批智能制造示范企业。支持云计算与大数据服务企业发展，为工业企业提供专业化、高水平的数据应用、处理与分析服务。到2019年，力争实现规模以上工业企业电商应用全覆盖。(责任单位：县经信局)

3.旅游业电商提升专项行动。以创建国家全域旅游示范县为契机，加快“互联网+旅游”步伐，到2019年，全县4A级以上旅游景区全部实现电子认证快速入园。支持旅游景点通过微信、自媒体等方式进行营销宣传，拓宽网上营销渠道；鼓励旅游电商企业开展对特定旅游群体的网络化精准营销，满足个性化消费需求。支持电商企业与旅游景区合作，探索在旅游景区建设农产品O2O体验店，提供线上下单、线下配送服务。(责任单位：县旅发委、县商务局)

(二)电子商务进农村综合示范工程

4.电子商务进农村专项行动。开展电子商务进农村综合示范创建工作，充分发挥我县农产品和电子商务发展优势，大力推进农商互联，建立产品追溯体系，加强品牌保护工作，扶持本地农产品质量认证企业，打造沂水农产品电子商务品牌，到2019年，全县培育5个以上全国知名农产品网络品牌。进一步完善农村电商三级服务体系，到2018年，在全县建成18个乡镇(街道)电商服务站和200个村级电商服务点，2019年实现全县乡镇、街道和行政村居电子商务公共服务全覆盖，畅通“工业品下乡”和“农产品”进城双向流通渠道。(责任单位：县商务局、县财政局、县扶贫办、县农业局、县供销联社、县市场监督管理局、县邮政公司)

5.电商精准扶贫专项行动。以省定扶贫工作重点村和建档立卡贫困户为重点，深入推进电商精准扶贫，扩大农特产品上行，拓宽特色农副产品销售渠道和贫困人口增收渠道。在全县范围内逐步形成较为完善的电商扶贫行政推进体系、公共服务体系、人才培养体系、政策配套体系、网货供应体系和物流配送体系，建立电商扶贫的长效机制。(责任单位：县商务局、县扶贫办、县农业局、县供销联社、县邮政公司)

(三)跨境电商推进工程

6.跨境电商企业培育专项行动。实行“互联网+外贸”行动计划，实施跨境电商企业培育工程，支持外贸企业借助电子商务实现优进优出，到2019年，50%以上外贸企业利用跨境电商实现进出口。支持跨境电子商务零售出口企业加强与境外企业合作，通过商业模式创新，融入境外零售体系，扩大跨境电子商务规模。支持企业通过跨境电子商务，合理增加消费品进口。(责任单位：县商务局、县国税局、县邮政公司、县市场监督管理局)

7.跨境电商服务体系建设专项行动。加强跨境电商创业园建设，推进与一达通深入合作，并引导园区积极引入跨境电商相关服务商，完善跨境电子商务服务体系。建设跨境电商孵化平台，实施“百家跨境电商”培育工程，为全县中小外贸企业提供出口通关退税等外贸综合服务，推动跨境电商快速发展。(责任单位：县商务局、县国税局、县邮政公司、县市场监督管理局)

(四)电商促进体系建设工程

8.电子商务人才支撑体系建设专项行动。将引进电子商务人才(团队)纳入全县高层次人才队伍建设范围，培养和引进具有全球视野和较强创新意识的国际性电子商务人才(责任单位：县委组织部、县人社局、县商务局)。推动职业院校加强电子商务领域的专业人才培养，鼓励电子商务企业与职业院校对接，推行教产研相结合(责任单位：县教体局)。完善电子商务培训体系，开展面向大学应届毕业生的电子商务技能、面向政府工作人员及企业负责人的电子商务战略决策、面向企业从业人员的职业技能和经营管理能力提升的电子商务精准培训，完善电子商务专家智库和后备人才库(责任单位：县商务局)。

9.电商快递物流协同发展专项行动。鼓励本地快递物流园区建设，招引顺丰、菜鸟、“四通一达”等知名快递企业在我县建设区域分拨中心，打造集仓储、分发、冷链等多功能为一体的现代综合性物流园，提升县内物流快递承载能力。推进快递末端网点建设，支持社区建设快递投送场所，推进末端自提网点建设，优化农村快递末端体系，打通电子商务物流(快递)配送农村“最后一公里”和城市社区“最后一百米”。(责任单位：县邮政公司、县商务局、县交通运输局、县供销联社)

10.电商创新创业载体建设专项行动。依托中小企业创业孵化园区，完善创新创业服务体系，打造电子商务创新创业孵化载体。完善全县电子商务公共服务中心功能，提高服务水平，探索建立电子商务统计监测体系。培育引进电商服务企业，为中小微企业提供业务培训、数据分析、代运营、研发设计等专业服务，构建相对完善的电商创业生态体系。积极鼓励社交网络电子商务发展，支持健康规范的微商发展模式。(责任单位：县商务局、县中小企业局、县统计局、县科技局)

11.电商金融服务提升专项行动。加强对电子商务企业的金融支持，提升对电子商务企业的信贷服务水平，支持电子商务企业发展供应链金融、互联网金融、商业保理等新型融资方式，优化金融资源配置。(责任单位：县金融办、县人民银行、县商务局)

12.电商示范引导专项行动。争创国家、省、市级电子商务示范县、示范镇、示范村、示范基地、示范企业，组织开展县级电子商务示范镇、示范村、示范基地、示范企业创建活动。鼓励示范镇、示范企业开展模式创新，在电商发展方面发挥示范带动作用。到2019年，力争创成国家和省级电子商务示范县，力争创建1家国家级电子商务示范基地，2家以上国家、省级电子商务示范企业，3个市级示范镇，6个市级示范村。(责任单位：县商务局)

四、保障措施

(一)完善推进机制。调整充实沂水县电子商务推进工作领导小组，加强对全县电子商务工作的领导和指导。县电子商务推进领导小组办公室抓好电子商务三年行动计划的督导、调度、协调等工作，各责任单位要制定具体工作措施，落实工作任务，明确时间表、路线图，确保各项工作落到实处。细化部门职能分工，完善商务、经信、发改、农业、旅游、扶贫等部门之间的协调配合机制，形成推动电子商务发展的工作合力。(责任单位：县电子商务推进领导小组各成员单位)

(二)强化财政支持。出台支持电子商务发展的政策措施，服务电子商务发展。加大财政资金支持力度，重点支持电子商务平台建设、电子商务公共服务体系建设、电商试点示范、电商创业创新、电商人才培训等；对在我县举办的具有影响力的电子商务高峰论坛、学术会议和创新创业大赛等活动给予政策、资金支持。发挥县电子商务专项基金作用，撬动金融和社会资本支持建设一批电子商务重点项目。(责任单位：县财政局、县商务局)

(三)加强监管服务。开展网络市场监管与服务示范区创建工作，创新网络市场监管服务模式，加大对假冒伪劣网络商品的打击力度，培树电子商务知名品牌。(责任单位：县市场监督管理局、县经信局)

(四)营造良好氛围。通过在媒体开辟专题、专栏等方式，宣传电子商务发展环境和发展成果，推介电子商务示范企业等典型案例，营造良好电子商务发展氛围。(责任单位：县电子商务推进领导小组各成员单位)
