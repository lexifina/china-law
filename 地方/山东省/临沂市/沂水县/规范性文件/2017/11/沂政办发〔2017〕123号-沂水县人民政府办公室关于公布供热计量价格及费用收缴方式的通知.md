# 沂水县人民政府办公室关于公布供热计量价格及费用收缴方式的通知

沂政办发〔2017〕123号

各乡镇(街道)人民政府(办事处),沂水经济开发区，沂蒙风情旅游景区，县政府有关部门：

为加快推进供热计量改革，保障供、用热双方合法权益，根据省物价局、住房和城乡建设厅《关于推进供热计量价格改革的指导意见》(鲁价格发〔2010〕170号)、《临沂市供热条例》等有关要求，结合我县实际，就全县供热计量价格及费用收缴方式等有关事项通知如下：

一、采暖用户具备分户用热计量条件的，执行两部制热价政策。

供热计量价格实行基本热价和计量热价相结合的两部制热价，并按用户性质分为居民用热价格和非居民用热价格。

基本热价按总热价(面积热价)的30%计算。计算公式为：热费=基本热费+计量热费=基本热价×供热面积+计量热价×用热量。

(一)居民热费=基本热费+计量热费

居民住宅按套内建筑面积每平方米21元为测算依据。

基本热费=基本热价×供热面积=6.3元/平方米×供热面积。

计量热费=计量热价×用热量。

居民用热计量热价=0.1502元/千瓦时(41.73元/吉焦)。

(二)非居民热费=基本热费+计量热费

非居民住宅按建筑面积每平方米34元为测算依据。

基本热费=基本热价×供热面积=10.2元/平方米×供热面积。

计量热费=计量热价×用热量。

非居民计量热价=0.2344元/千瓦时(65.12元/吉焦)。

二、热费收缴方法。

(一)实行两部制热价的用户在供热开始前，按现行面积计费额预交热费，供热结束后按热计量收费办法结算热费。

(二)在供热计量整体改造完成前，居民用户的结算上限为供热计费面积与面积供热价格之积。结算费用低于或等于面积计价金额的，按实际金额结算；高于面积计价金额的，按面积计价金额结算。

(三)因非人为原因造成热计量表计量数据失真的，按面积收费结算。

(四)因供热单位未按期供热或供热期内因施工等影响间断供热的，供热单位按实际未供天数减收热用户的基本热费部分。

(五)供热部门要充分挖掘计量供热节能潜力，负责规范收集热量消耗等相关数据，为进一步完善政策提供科学依据。

三、城乡社区居民委员会的工作场所及非经营公益服务设施、养老机构等社会福利场所的生活服务设施、城乡居民住宅小区公共场所非经营性服务设施，其用热价格执行居民供热价格。

四、本通知自2017-2018年供暖期起执行，由县物价局会同住建局负责解释。

沂水县人民政府办公室

2017年11月10日

根据2019年10月30日《沂水县人民政府对沂水县发展和改革局关于调整城区集中供热价格的请示的批复》（沂政字〔2019〕97号）失效。
