# 沂水县人民政府办公室关于启用沂水县综合行政执法局、沂水县城市管理局、沂水县综合行政执法大队印章的通知

沂政办发〔2017〕130号

各乡镇(街道)人民政府(办事处),沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

根据工作需要，现刻制“沂水县综合行政执法局”印章1枚、“沂水县城市管理局”印章1枚、“沂水县综合行政执法大队”印章1枚，自公布之日起正式启用。
