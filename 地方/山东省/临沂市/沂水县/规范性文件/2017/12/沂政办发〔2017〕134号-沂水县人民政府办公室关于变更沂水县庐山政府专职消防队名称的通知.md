# 沂水县人民政府办公室关于变更沂水县庐山政府专职消防队名称的通知

沂政办发〔2017〕134号

各乡镇(街道)人民政府(办事处),沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

为进一步提升庐山化工园区应急救援能力，经县政府研究决定，依托庐山政府专职消防队改建升级为特勤消防队，并变更名称为沂水县庐山政府专职特勤消防队。该消防队属于县政府利用国有资产举办的公益性事业单位，不纳入机构编制管理，按照非营利性规则从事火灾扑救、应急救援、火灾预防及其他消防辅助性工作。
