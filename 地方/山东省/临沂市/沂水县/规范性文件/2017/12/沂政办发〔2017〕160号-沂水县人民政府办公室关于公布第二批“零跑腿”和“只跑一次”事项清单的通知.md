# 沂水县人民政府办公室关于公布第二批“零跑腿”和“只跑一次”事项清单的通知

沂政办发〔2017〕160号

各乡镇(街道)人民政府(办事处),沂水经济开发区，沂蒙风景旅游景区，县政府各部门：

为方便群众和企业办事创业，打造优质政务服务环境，根据《省委办公厅省政府办公厅关于深化放管服改革进一步优化政务环境的意见》(鲁办发〔2017〕32号)要求，经梳理论证，现将第二批群众和企业到部门办事“零跑腿”和“只跑一次”事项清单向社会公布，其中“零跑腿”事项2项、“只跑一次”事项13项。

凡纳入清单的“零跑腿”事项，群众和企业通过网上或自助终端等方式即可办理，不再要求群众和企业到部门、单位提交申请材料、领取办理结果等手续。凡纳入清单的“只跑一次”事项，部门单位需一次予以办结，不得要求群众和企业重复提交材料、另行领取办理结果等手续。请各部门、单位按照清单承诺运行，切实提速增效，方便群众和企业办事。

附件：1.第二批群众和企业到部门办事“零跑腿”事项清单

2.第二批群众和企业到部门办事“只跑一次”事项清单
