# 沂水县人民政府办公室关于成立沂水县盐业体制改革工作领导小组的通知

沂政办发〔2017〕163号

各乡镇(街道)人民政府(办事处),沂水经济开发区，沂蒙风情旅游景区，县政府各部门：

为稳步推进全县盐业体制改革工作，经研究，决定成立沂水县盐业体制改革工作领导小组。现将成员名单公布如下：
