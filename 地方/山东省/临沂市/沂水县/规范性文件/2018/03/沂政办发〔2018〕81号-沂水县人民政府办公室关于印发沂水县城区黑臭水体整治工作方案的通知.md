# 沂水县人民政府办公室关于印发沂水县城区黑臭水体整治工作方案的通知

沂政办发〔2018〕81号

各乡镇（街道）人民政府（办事处），沂水经济开发区，县政府各部门：

现将《沂水县城区黑臭水体整治工作方案》印发给你们，请结合实际，认真贯彻落实。

沂水县人民政府办公室

2018年3月12日

沂水县城区黑臭水体整治工作方案

为加快推进我县城区黑臭水体整治，进一步提高水环境质量，结合我县实际，制定本工作方案。

一、总体思路

认真贯彻落实中央、省市关于生态文明建设的部署要求，针对城市黑臭水体现状问题与成因，科学制定整治方案，彻底解决黑臭水体污染问题，实现水体污染物总量持续削减、水体环境质量不断提升、人居环境明显改善目标。到2020年，全面消除县城建成区黑臭水体。

二、基本原则

（一）深入调查，科学谋划。从系统性、流域性、整体性出发，持续深入开展城区河道排口、外围排水体系、内源污染、水质现状等基础数据摸底调查，科学编制黑臭水体整治方案。

（二）多措并举，系统治理。坚持问题导向、目标导向，采取清淤疏浚、控源截污、管网建设、生态修复等综合措施，有效提升水环境质量。

（三）属地管理，县镇联动。县直部门健全完善联动机制，有力有序推进整治各项工作。各有关乡镇、街道、沂水经济开发区（以下简称“各有关乡镇”）履行好属地管理责任，精心组织，高效运作，确保整治成效。

（四）常抓不懈，长效管理。健全完善管护制度，落实日常保洁、管护责任，定期开展河道水质监测和综合评估，防止污染反弹。

三、主要措施

坚持因地制宜，根据不同的水体水文水质特征、治理目标和治理阶段，综合采用不同技术措施进行治理。

（一）加强污水管网建设。西城开发建设及城市新建道路全部实施雨污分流，老城区结合旧城旧村改造、棚户区改造、片区开发等有序推进雨污分流改造。用三年时间，对莲旺街、跋山东干渠等沿线14条道路、21.7公里管网实施雨污分流，建设莲旺沟泄洪管道2.5公里、清淤硬化明渠床底950米，建设跋山东干渠污水管网2.8公里。

（二）实施清淤疏浚。对城区沟渠状况进行全面排查，摸清淤积情况、内源污染状况，分类开展生态清淤，清除各类垃圾，彻底实施全段“大扫除”。

（三）整治排污口。全面排查沟渠排污口，并针对不同类别排污口，特别是错接、漏接和直排沟渠的，因地制宜采取封堵、截流、调蓄、防倒灌等工程措施，对所有排污口实施改造或封堵。

（四）控源截污。采取截污纳管和城市面源污染控制等措施，防止外来污水和污染物排入城市水体。截污纳管通过沿河铺设截流管线或合理设置提升泵站等方式，将相关污水全部纳入城市污水收集和处理系统。城市面源污染控制，主要采取建设下凹式绿地、透水铺装、缓冲带和生态护岸、路边植被浅沟、植被截污带等实现。

（五）开展生态修复。搞好生态浮床（浮岛）、生态浮毯、生态基净水、曝气复氧（景观曝气）等技术措施落实，积极构建多样水生动植物生态系统，实现净化水质的目标。

四、工作步骤

（一）制定整治方案。6月10日前，由县住建局聘请中介机构对城区河道沟渠水质进行化验，根据结果对黑臭水体逐一编制整治方案，明确所需的工程措施、年度资金需求和实施周期等。

（二）分年度细化整治项目。各部门、有关乡镇根据黑臭水体整治方案，分年度推进实施整治工程，确保2020年底前完成整治任务。县住建局会同环保局等部门要强化工作措施，搞好日常服务调度，确保工作顺利开展。

（三）评估整治效果。县住建局牵头搞好第三方机构全过程跟踪实施，对城区黑臭水体整治效果组织公众调查、水质监测等，向社会公布整治效果。

（四）加强长效管理。对城区每一个水体的水质管理都明确责任单位，落实相关措施，建立日常监测和养护制度，及时受理群众诉求，确保整治效果长效保持。

五、职责分工

各有关乡镇：根据属地管理原则，搞好辖区内村居生活污水处理和沟渠内（包括莲旺街和东干渠）垃圾清理、淤泥清运及周边卫生综合整治，并建立落实日常监管、清理养护的长效机制。

县住建局：承担整治领导小组办公室职责；负责编制县城区黑臭水体具体整治方案；统筹协调与指导调度整治工作，定期通报整治情况。按照整治方案分年度实施道路建设改造和雨污管网分流工程。牵头做好黑臭水体水质化验及整治效果的综合评估工作。

县财政局：统筹安排城区黑臭水体整治工程财政资金投入；做好融资投资相关工作；安排专业机构委托经费，搞好政府采购协调实施。

县环保局：负责指导各有关乡镇开展周边污染源排查；负责搞好城区黑臭水体涉及工业污染废水达标排放的监管；配合对城区黑臭水体整治工作进行督查。

县综合行政执法局：负责城区河道、沟渠排污口的排查整治工作；督促城区各企事业单位、经营业主做好已有排污管道的截污纳管维护管理工作；做好城区河道、沟渠水面保洁及周边环卫管理、拆违等工作。

县畜牧局：负责城区黑臭水体整治水域涉及范围的畜禽养殖废弃物综合管控、利用等指导和服务。

县水利局：牵头落实好“河长制”工作，加强工作推进落实，确保相关河道不再出现新的黑臭水体。

县发改局：负责城区黑臭水体整治工程的立项、可研等审批工作；负责协调争取上级部门黑臭水体专项资金补助申报等工作。

县国土资源局：负责做好城区黑臭水体整治工程涉及的国土手续办理工作。

县规划局：负责城区雨污分流管网布局；做好水体整治工程涉及的规划手续办理。

县跋山水管处：落实产权单位职责，牵头做好跋山东干渠漏水渠段防渗处理和坍塌渠段维修养护，配合有关乡镇搞好渠道垃圾清运和淤泥清理，确保城区生态补水和排水安全。

六、组织保障

城区黑臭水体整治面广量大，且与群众生活紧密相关。各有关乡镇、部门要从保障民生的大局出发，加大整治工作宣传力度，营造良好舆论氛围，充分调动群众参与水环境治理的积极性、主动性和创造性。县里成立由县政府有关领导任组长，各有关乡镇、部门主要负责人为成员的工作领导小组，领导小组办公室设在县住建局，综合协调推进整治工作。各级各有关部门要高度重视，切实加强领导，全面落实责任，统筹协调安排；要优化完善整治工作组织机构，充实专业人员，全力推进城区黑臭水体整治工作；要进一步细化落实整治措施，明确整治标准、时间表和路线图，按时序进度严格工作推进。县领导小组办公室要加大督查、督促力度，定期督办、定期通报、定期公示，各级各有关部门工作进展情况。县直有关执法部门要加大监管力度，严厉查处对城市水体造成污染与破坏的违法违规行为，健全完善长效监管措施和养护机制，切实巩固黑臭水体整治成果。
