# 沂水县人民政府关于收回沂城街道前小河社区居民委员会使用的部分国有建设用地使用权的决定

沂政发〔2018〕33号

县政府有关部门：

为提高城镇建设水平，根据《中华人民共和国土地管理法》《中华人民共和国城市房地产管理法》等法律法规规定，经研究，决定收回位于龙家圈街道杨家庄子社区以北、县水务公司1万吨水厂以西，沂城街道前小河社区居民委员会使用的部分国有建设用地使用权5828平方米，具体事宜按收回国有建设用地使用权协议书执行。
