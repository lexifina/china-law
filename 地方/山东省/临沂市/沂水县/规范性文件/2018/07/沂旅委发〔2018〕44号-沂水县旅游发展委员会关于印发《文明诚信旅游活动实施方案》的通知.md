# 沂水县旅游发展委员会关于印发《文明诚信旅游活动实施方案》的通知

沂旅委发〔2018〕44号

各旅游企业：

为全力推进我县全国文明城市创建工作，做到创城为民、实事惠民，提升城市文明程度，打击损坏旅游秩序的不法行为，进一步净化旅游市场，维护全县旅游业发展良好环境，经研究决定，在全县旅游企业开展“文明诚信旅游”活动，现将《文明诚信旅游活动实施方案》印发给你们，望认真贯彻落实。

特此通知。

附件： “文明诚信旅游”活动实施方案

沂水县旅游发展委员会

2018年7月30日
