# 沂水县供销合作社联合社关于印发《沂水县供销系统2018年今冬明春安全生产及火灾防控工作方案》的通知

关于印发《沂水县供销系统2018年今冬明春安全生产及火灾防控工作方案》的

通知

沂供字〔2018〕41号

各基层供销社、县直属企业：

为扎实做好系统今冬明春安全生产及火灾防控工作，确保安全生产及消防安全形势持续稳定向好，现将《沂水县供销系统2018年今冬明春安全生产及火灾防控工作方案》印发给你们，请结合实际认真抓好贯彻落实。

沂水县供销合作社联合社

二〇一八十一月二十一日

沂水县供销系统2018年今冬明春安全生产

及火灾防控工作方案

为做好今冬明春安全生产及火灾防控工作，有效防范遏制重特大安全生产及火灾事故的发生，根据县安委会《关于做好冬季安全生产工作的通知》（沂安办发【2018】101号）和《关于印发2018年今冬明春火灾防控工作方案的通知》（沂安发【2018】20号）要求，结合系统实际，县社确定从即日起至2019年全国两会结束，在全系统集中开展今冬明春安全生产及火灾防控工作。具体方案如下：

一、工作目标

认真贯彻落实习近平总书记关于安全生产和消防安全的重要指示精神，按照政府统一领导、部门依法监管、单位全面负责、公民积极参与的原则，严格落实“管行业必须管安全、管业务必须管安全、管生产必须管安全”的要求，积极配合公安、消防、安监局等部门开展的各项治理行动，动员全供销社系统力量，严格落实安全生产及消防安全主体责任，全面深入开展安全生产及火灾隐患排查整治，不断加强安全生产及消防基层基础建设，积极开展安全生产及消防宣传培训，做好安全生产及灭火和应急救援准备，有效预防和减少安全生产及火灾事故发生，确保今冬明春尤其是元旦、春节、元宵节和全国两会期间，不发生有影响的安全生产及火灾事故，促进系统安全生产及消防安全形势持续稳定。

二、阶段划分

今冬明春火灾防控工作分3个阶段：

（一）动员部署阶段（2018年11月25日前）。各企业要结合实际，制定具体实施方案，召开专门会议，明确职责，细化措施，广泛发动，部署到位。

（二）组织实施阶段（2018年11月26日至2019年全国两会结束）。各企业要对照工作方案，认真组织实施，从严从细抓好各项工作措施和责任落实。

（三）总结验收阶段（2019年全国两会结束后2日内）。各企业对今冬明春安全生产及火灾防控工作情况进行总结分析、固化经验做法，健全完善安全生产及火灾防控机制，同时，要整理好材料迎接县里组织的检查验收。

三、工作任务及措施

（一）全面排查整治安全生产及火灾隐患。各企业要结合《关于深入开展系统风险隐患大排查快整治集中行动确保重点行业领域安全生产形势稳定工作方案》（沂供字【2018】36号）和《关于印发<供销系统人员密集场所消防安全专项检查工作方案>的通知》（沂供字〔2018〕40号）要求，针对冬季岁末年初安全生产规律，加强安全生产及消防安全分析研判，找准安全生产及火灾防控薄弱环节，坚持“什么问题突出就重点解决什么问题、什么隐患严重就重点整治什么隐患”的原则，部署开展安全生产及火灾隐患排查整治。各企业首先进行自查，以本次专项行动为契机，对企业内部及所属经营单位、出租房屋、职工宿舍的电源线路、经营设施、消防器材、消防安全通道及昼夜值班巡查制度落实等方面进行全方位检查，对查出的隐患建立台账，制定整改措施，对能立即整改的，要立即整改;对不能立即整改的，制定整改期限，限期进行整改。

（二）加强安全生产及火灾防范宣传教育。各企业要结合消防宣传月活动，围绕“认识火灾、学会逃生”主题，深入开展消防安全“四个能力”建设、“一懂三会”和“三提示”宣传教育活动。充分利用黑板报、宣传手册、手机短信、微信微博等宣传阵地,广泛宣传用电用气、用火消防、交通出行、烟花燃放以及人员密集场所等安全生产和逃生自救常识,集中曝光典型事故案例,提高企业干部职工及公众的安全意识和避险减灾技能。

（三）加强值班值守,强化应急响应和处置工作。各企业要加强应急值守,严格执行领导带班制度，保持信息畅通，实行24小时值班。不断完善充实安全生产及防火逃生应急预案，做到细化实用，可操作性强，确保出现险情后，真正拿的出，用的上，最大限度的发挥预案的应急作用。同时，各企业要结合自身实际情况，不定期的组织安全生产及消防演练活动，着重从消防器材使用，人群疏散，突发险情的应急能力等环节入手，让每一位员工不但能自身熟练掌握逃生技巧，更要做到随机应变，确保在出现险情后，不着急慌乱，正确处置，积极疏散群众，使人民群众的生命财产安全得到充分保障。

四、工作要求

（一）加强组织领导。县社成立冬春安全生产及火灾防控工作领导小组，领导小组办公室设在安全统筹科，承担日常工作的协调及督导。各企业也要成立相应的组织机构，加强指挥调度，确保抓好落实，抓出成效。

（二）严格落实责任。严格落实“一岗双责”制度，进一步强化安全生产主体责任，树立安全生产监管“一盘棋”思想，加强督促检查，层层细化责任，推动各项工作措施落实到位。

（三）加强督导检查。县社成立的领导小组，将不定期的对各企业工作落实情况进行督导检查。对组织有力、成效明显的，提出表扬；对工作不落实、进展缓慢的，通报批评；对发生较大以上安全生产及火灾安全事故的，将严格按照有关法律规定，实施责任追究。

各企业要将工作方案及工作部署情况，于2018年11月底以前报县社安全统筹科（办公邮箱：ysgxtck@163.com）。从12月份起，每月24日前保送当月工作小结，2019年全国两会结束后2日内报送检查台账（复印件）及总结。
