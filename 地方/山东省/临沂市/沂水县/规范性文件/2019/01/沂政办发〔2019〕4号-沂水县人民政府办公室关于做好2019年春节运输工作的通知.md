# 沂水县人民政府办公室关于做好2019年春节运输工作的通知

沂政办发〔2019〕4号

为扎实做好2019年春节运输工作，保障广大旅客安全便捷出行和重要物资顺利运输，确保全县人民度过一个安乐祥和的春节，现将有关事宜通知如下：

一、提高思想认识，加强组织领导

春运工作涉及广大人民群众的切身利益，事关经济发展和社会稳定，是一项重要的民生工程。各级、各有关部门要以习近平新时代中国特色社会主义思想为指导，从讲政治、保民生的高度，进一步增强做好春运工作的责任感、紧迫感。要以实现“便捷春运、温馨春运、平安春运”为目标，科学研判群众出行和重点物资运输需求，创新春运服务举措，努力做到“三早”（早准备、早动员、早部署）“四抓”（抓认识、抓关键、抓责任、抓整改）“五确保”（保安全、保畅通、保服务、保运力、保重点物资）。

为切实加强对春运工作的组织领导，县政府成立春运工作领导小组，并在县交通运输局设立办公室，具体负责全县春运工作的组织领导和统筹协调工作。各成员单位也要成立相应的组织机构，加强沟通协调，共同做好春运各项工作。

二、认真分析形势，提前做好保障

2019年春运自1月21日开始至3月1日结束。初步预测，今年春运期间全县客流量约35万人次，较往年有所下降。预计在1月28日—2月3日（腊月二十三至二十九）、2月7日—2月13日（正月初三至初九）两个时间段，将会出现客流高峰。节前客流量从1月28日（腊月二十三）起将逐渐增大，节后客流高峰将出现在2月10日（正月初六）前后。

各级、各有关部门和运输企业要根据冬季运输工作实际，提前调查预测相关线路旅客流量、流时、流向，制定切实可行的运输方案，加强调度指挥，合理安排运力，保证客货运输安全有序进行。县人社、教体等部门要有针对性地做好在外务工人员、学生的客源情况调查，及时与交通运输部门沟通协调，提前预订车辆、车票，协助运输单位做好运送工作。各运输单位要搞好多种运输方式的调配调度，及时发布交通信息，公布班次调整情况，引导旅客有序流动。同时，要坚持“以客为主、客货兼顾”的原则，在保证旅客运输的同时，统筹做好电煤、粮食等重点物资及肉禽、果蔬等生活物资运输，充分利用春运前和客流波谷时段，努力增加货物运量，全力保障经济运行需求和群众节日生活需要。

三、突出工作重点，强化责任落实

安全是春运工作的首要任务和生命线。各级、各有关部门和运输企业要充分认识春运安全工作面临的严峻形势，进一步增强底线思维和红线意识，坚持把安全作为春运工作的重中之重，按照“党政同责、一岗双责、齐抓共管、失职追责”以及“管行业必须管安全、管业务必须管安全、管生产经营必须管安全和谁主管谁负责”的总体要求，认真贯彻“安全第一、预防为主、综合治理”的方针，针对春运期间可能出现的传染性疾病、恶劣天气、旅客滞留、群体事件等突发情况，分类制定相关预案。同时，要进一步加强春运监管、值班工作，及时发现问题、及早处理到位，防止发生旅客大面积滞留现象，坚决杜绝发生重特大安全责任事故。

各级、各有关部门要进一步明确各自职责分工，认真履职，形成合力。安监部门要对整个春运安全工作进行指导检查和全程督导。交通运输、消防、安监等部门要牵头组织专门力量，对运输设施、油库、汽车站、火车站、水库、河湖码头等重点部位进行全面安全检查，发现问题及时整改，彻底消除隐患。交通运输部门要严把客运经营市场准入关、车辆技术状况关和从业资格关，搞好运力调配，抓好汽车客运站的安全监督；要进一步加强道路危险货物运输安全监管，严格GPS动态监控管理，确保车辆安全运营；要会同公路部门进一步搞好公路巡查管理，配齐标志标识，备足防滑沙料、融雪剂等物料，确保道路安全畅通。公安部门要牵头加强对高速公路、国省道沿线道路巡查，加强治安整治，严厉打击车匪路霸及其他各种侵害旅客合法权益的行为。农业部门要加强农用车辆管理和驾驶员人员教育培训，严禁农用车辆载客。气象部门要密切关注天气变化，及时向运输企业提供预报服务。交警、交通运输等部门要组成春运联合执法队伍，严查酒后驾驶、超员、超速、拒载、甩客、宰客、欺行霸市和未经许可擅自从事营业性运输等违法违章行为，特别是做好汽车站周边的巡查执法工作，从严从快查处群众反映强烈、影响较大的案件，并及时向社会公布查处结果。其他春运工作领导小组成员单位要强化措施，认真履职，扎实做好春运各项工作。

各运输企业要认真履行安全生产主体责任，加大对驾驶员的教育培训和管理力度，及时纠正各种违章经营行为；各运输站场和经营业户要加强对“三品”（易燃、易爆、危禁品）的堵查，严防进站、上车（船），要严格执行“三不进站、六不出站”和冰、雪、雾霾等恶劣天气客车（船）禁行管理规定，达不到安全通行条件的坚决停运。

各级、各有关部门和运输企业要牢固树立“为民、便民、利民”意识，创新服务方式，提高服务质量，及时发布春运动态、运力状况和车辆班次等信息，为旅客出行提供参考和帮助。领导小组其他成员单位要按照各自职责开展工作，并负责调度春运期间各有关单位与春运相关的各项工作。县交通运输部门要充分发挥牵头作用，认真做好统计调度工作，及时总结和推广春运工作中的好经验、好做法。同时，要在春运高峰时间段增派人员，加强值班执勤，强化安全管控，确保春运各项工作安全有序进行。
