# 沂水县人民政府关于沂水县教育体育局更名的通知

沂政发〔2019〕23号

各乡镇人民政府、沂城街道办事处、龙家圈街道办事处、沂水经济开发区管理委员会、县政府各部门：

根据县委、县政府《关于沂水县县级机构改革的实施意见》（沂发〔2019〕2号）精神，决定将县教育体育局更名为县教育和体育局，仍作为县政府工作部门。配备局长1名、副局长3名。其“三定”规定另行印发。

沂水县人民政府

2019年1月11日
