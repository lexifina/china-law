# 沂水县民政局关于同意成立沂水县职工书画家协会的批复

沂民字〔2019〕5号

沂水县职工书画家协会筹委会：

你会所报关于成立职工书画家协会的材料收悉，经审查材料和现场勘察，所报材料齐全有效，场地设施比较完善，已基本具备了成立条件。经研究，同意成立“沂水县职工书画家协会”。

望协会成立后，认真遵守国家法律法规政策，自觉接受登记管理机关和相关业务单位的监管与指导，严格按照《社会团体登记管理条例》和《章程》开展活动，积极加强自身建设，依法维护会员合法权益，为活跃职工文化生活、传承优秀传统文化，促进沂水县经济社会发展发挥积极作用。
