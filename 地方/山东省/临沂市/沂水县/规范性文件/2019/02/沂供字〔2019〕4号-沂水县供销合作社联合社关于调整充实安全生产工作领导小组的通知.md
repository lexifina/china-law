# 沂水县供销合作社联合社关于调整充实安全生产工作领导小组的通知

沂供字〔2019〕4号

各基层供销社、县直属企、各科室：

为落实安全生产责任，夯实安全生产基础，确保全系统的安全生产持续稳定，经县社党组研究，决定调整充实沂水县供销社安全生产领导小组如下：

组　长：武传映 党组书记、理事会主任

副组长：王培军 监事会主任

成　员：段可友 理事会副主任

刘兴会 理事会副主任

李洪新 监事会副主任

安全生产领导小组下设办公室，办公室设在安全统筹科，李洪新同志兼任安全生产领导小组办公室主任，具体负责相关事宜的协调工作，领导小组各成员严格按照管业务管安全、管生产管安全、管行业管安全的要求，认真负责、一岗双责，担当应负的安全管理责任，促进全系统安全生产持续稳定。
