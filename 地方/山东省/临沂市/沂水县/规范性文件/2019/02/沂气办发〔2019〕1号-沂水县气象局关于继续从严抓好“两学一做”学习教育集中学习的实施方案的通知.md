# 沂水县气象局关于继续从严抓好“两学一做”学习教育集中学习的实施方案的通知

沂气办发〔2019〕1号

各科室：

根据中共沂水县委组织部《关于继续从严抓好“两学一做”学习教育集中学习的通知》部署安排，现就县气象局继续从严抓好“两学一做”学习教育集中学习，制定如下工作方案，请大家抓好学习。

沂水县气象局

2019年2月22日

关于继续从严抓好“两学一做”学习教育集中学习的实施方案

根据中共沂水县委组织部《关于继续从严抓好“两学一做”学习教育集中学习的通知》部署安排，现就县气象局继续从严抓好“两学一做”学习教育集中学习，制定如下工作方案。

一、准确把握基本要求

中央明确提出要推进“两学一做”学习教育常态化制度化，并出台专门意见，省、市、县委也作出具体安排。按照上级要求，今年各级党组织要继续从严抓实“两学一做”学习教育，深入学习党章党规，深入学习习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，健全和规范“三会一课”等制度，确保取得实实在在的效果。全局党员要深入分析全面从严治党对本单位、对自身提出的新要求，把“学”与“做”有机结合起来，解决好党员队伍、党的组织生活、党员和党员领导干部教育管理、党支部建设中存在的突出问题，把学习教育的成效体现在做合格党员、建过硬支部的实际行动上，落实到服务全县改革发展稳定的具体实践中。

二、从严落实固定学习日制度，确保学习教育常态化

学习以党支部为单位组织，“两新”组织每月固定1天进行集中学习，局机关每月固定2天进行集中学习的制度不变。要继续深入学习党章党规党纪，学习习近平总书记系列重要讲话，学习十八届六中全会通过的《准则》《条例》等，要结合自身实际制定差异化的集中学习计划，并根据中央和省市县具体部署，及时将上级要求的学习内容列入学习计划。

全局上下要深入贯彻落实习近平新时代中国特色社会主义思想和党的十九大精神，围绕“走在前列，争创强县”目标，牢牢把握发展第一要务，全面加快“激情沂水、创新沂水、友善沂水、品牌沂水”建设步伐。各级党组织要认真学习领会讲话精神，结合“两学一做”学习教育切实抓好贯彻落实。

三、明确需要解决的突出问题

坚持问题导向，带着问题学、针对问题改。全体党员在着力查找和解决好中央和省、市、县委明确的五个方面突出问题的基础上，结合工作实际，有针对性地查找和解决存在的突出问题：

局党支部对照中央和省、市、县委要求，深入查找和分析，列出问题清单，指导各党支部和党员、党员领导干部主动查摆，进一步剖析原因，制定整改措施，坚持即知即改，立行立改，把查找和解决问题贯穿学习教育全过程；对面上普遍存在的共性问题，必要时要开展集中整治。同时，把开展学习教育同抓好党的群众路线教育实践活动和“三严三实”专题教育的问题整改结合起来，持续深入地纠正“四风”、抓好不严不实问题整改。

四、细化明确学习教育内容

党支部书记要为党员讲党课，切实抓好党员集中轮训。要紧密结合“两学一做”学习教育，坚持以学习贯彻党的十八届六中全会精神为主题，以党章党规、习近平新时代中国特色社会主义思想为主要内容，教育引导广大党员进一步增强“四个意识”，严守政治纪律和政治规矩，做“四讲四有”的合格党员和新时期沂蒙好党员。党支部要根据“两学一做”学习教育工作安排，严格落实“三会一课”、“固定学习日”等制度，抓好支部全体党员集中学习讨论。要把党员集中培训工作作为深化“两学一做”学习教育的重要任务，专题研究部署，精心组织实施，增强培训效果；要严肃培训纪律、狠抓学风建设，保证培训时间和质量。全体党员和党员领导干部要严格按照县委要求规定的学习内容，认真抓好党章党规和系列讲话学习；按照规定的要求，自觉做合格党员的表率。在此基础上，深入学习习近平总书记关于机关党建的重要论述，要把解决思想问题和解决实际问题紧密结合起来，切实提高工作成效。

局党支部根据“四讲四有”要求，结合实际细化合格党员的具体标准，引导广大党员增强政治意识、大局意识、核心意识、看齐意识，主动向党中央看齐，向党的理论和路线方针政策看齐，做到坚定共产党人理想信念，牢固树立党的意识、党员意识，强化党的宗旨意识，积极践行社会主义核心价值观，在推动改革发展稳定实践中建功立业。全体党员要立足本职岗位，努力践行道德操守，时刻以肩负的责任警醒和鞭策自己，心存敬畏、守住底线，老实做人、扎实做事。党员领导干部要认真贯彻习近平总书记关于培养造就“四个铁一般”干部队伍要求，认真践行“三严三实”和好干部标准，带头坚定理想信念，带头严守政治纪律和政治规矩，带头树立和落实新发展理念，带头攻坚克难敢于担当，带头落实全面从严治党主体责任，努力在履职尽责强党建上见到新成效，在抓班子带队伍上见到新成效，在转作风提效能上见到新成效，在抓项目提质量上见到新成效。

五、加强组织领导，增强学习教育的实效性

局党支部要切实担负起全面从严治党主体责任，坚决维护以习近平同志为核心的党中央权威，推进“两学一做”学习教育常态化制度化，坚持全覆盖、重创新、求实效，教育引导党员切实把思想和行动高度统一到党中央决策部署上来。要坚持领导带头、分类指导，从严督导、压实责任，形成以上率下、整体联动的整体效应，确保取得实实在在的效果。

在“两学一做”学习教育中，要在“学”上深化拓展，在“做”上见到实效。局党组要引导党员干部按照四讲四有标准，聚焦解决突出问题，结合结亲连心、精准扶贫、党员包片联户等各项工作，搭建党员发挥作用的平台，从具体问题做起来、从具体问题改起，做到政治合格、执行纪律合格、品德合格、发挥作用合格，真正在实际工作中把党员标准立起来，党组织形象树起来。

中共沂水县气象局党总支部

2019年2月22日
