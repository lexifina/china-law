# 沂水县沙沟水库管理处关于公布领导分工的通知

沂沙管字〔2019〕2号

各科室：

为进一步做好管理处各项工作，确保规范有序进行，现将领导分工调整公布如下：

刘柱平同志，主持全面工作,分管财务、人事工作。

刘立旗同志协助主要领导抓日常工作，具体负责党建及党风廉政建设、意识形态、安全生产、招商引资、工程管理、防汛抗旱、工程建设、电力生产、饮用供水、灌区管理、渔业生产、水行政执法、社会管理综合治理等工作。

李志伟同志负责办公室、后勤保障工作。协助主要领导做好财务、人事工作。协助刘立旗同志做好渔业养殖、水行政执法及其安全生产工作。

武玉芳同志负责第一书记工作。

特此通知。
