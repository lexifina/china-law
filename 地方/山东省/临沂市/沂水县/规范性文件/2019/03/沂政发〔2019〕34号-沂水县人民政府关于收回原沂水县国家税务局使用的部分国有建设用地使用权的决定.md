# 沂水县人民政府关于收回原沂水县国家税务局使用的部分国有建设用地使用权的决定

沂政发〔2019〕34号

县政府有关部门：

为提高城镇建设水平，根据《中华人民共和国土地管理法》《中华人民共和国城市房地产管理法》等法律法规规定，经研究，决定收回位于诸葛镇驻地，原沂水县国家税务局所使用的部分国有建设用地使用权390平方米，具体事宜按收回国有建设用地使用权协议书执行。
