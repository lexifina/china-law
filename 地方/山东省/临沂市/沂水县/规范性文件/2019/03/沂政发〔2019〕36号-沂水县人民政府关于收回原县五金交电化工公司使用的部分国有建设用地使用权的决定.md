# 沂水县人民政府关于收回原县五金交电化工公司使用的部分国有建设用地使用权的决定

沂政发〔2019〕36号

县政府有关部门：

为提高城镇建设水平，根据《中华人民共和国土地管理法》《中华人民共和国城镇国有土地使用权出让和转让暂行条例》规定，经研究，决定收回原县五金交电化工公司使用的位于县城区中心街以西45平方米国有建设用地使用权，同时注销以上宗地范围内的国有土地使用证。具体事宜按收回国有建设用地使用权协议书执行。
