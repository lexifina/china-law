# 沂水县教育和体育局2019年教育扶贫工作实施方案

沂教字〔2019〕7号

为深入贯彻党的十九大精神和市教育局、县委、县政府关于教育扶贫工作部署安排，确保全县2019年基本完成教育脱贫攻坚任务，根据国家有关教育扶贫政策，结合全县教育系统实际，制定本方案。

一、指导思想

全面贯彻党中央、国务院和习近平总书记关于精准扶贫工作的重要指示，坚持“治贫先治愚，扶贫先扶智”的扶贫攻坚工作方针，把教育扶贫作为扶贫攻坚的优先任务和教育事业发展的重点工作，全面落实国家教育扶贫政策，大力开展“功能型”、“造血型”教育扶贫，办好贫困村每一所学校，造就优秀教师队伍，培养好每一名孩子，深入推进教育强民、技能富民。

二、目标任务

按照市教育局和县委县政府关于脱贫攻坚工作的部署要求，聚焦教育普及程度全面提高、贫困村幼儿园建设全面完成、困难学生全程资助等扶贫任务，抓重点、补短板、强弱项，采取真招、实招、硬招，完善保障体系，大力推进教育精准扶贫“323”工程升级，基本完成教育脱贫攻坚任务，着力打造惠民生、解民忧、暖民心的教育精准扶贫品牌工程，为全县坚决打赢脱贫攻坚战做出积极贡献。

三、工作任务

（一）着力推进“贫困地区学前教育普及计划”。将省、市扶贫工作重点村中确需建设幼儿园的全部纳入学前教育布局规划，在实施学前教育三年行动计划中予以优先保障。2019年完成新建、改扩建贫困村幼儿园4处，实现贫困村公共学前教育资源全覆盖。（责任科室：学前教育管理中心）

（二）着力构建“城乡学校结对帮扶网络”。充分发挥城乡义务教育学校结对帮扶作用，保障省、市扶贫工作重点村学校在教育教学、学校管理、教师发展、办学条件等方面资源共享、协同发展。2019年各项帮扶工作继续深入开展，取得明显成效。（责任科室：基础教育科）

（三）着力完善“建档立卡贫困家庭学生资助体系”。把对贫困村建档立卡贫困家庭学生资助政策向前延伸到学前教育，往后覆盖到高等教育，建立从学前教育到高等教育的全程资助政策体系。切实抓好已有各项资助政策的贯彻落实，加强各级各类资金的发放管理，简化程序、提高效率、及时拨付，确保资助应享尽享。加大资助政策宣传力度、创新资助政策宣传形式，切实提高学生、家长、社会对资助政策的知晓率。（责任科室：学生资助管理中心）

（四）着力完善“特殊群体儿童关爱服务体系”。建立控辍保学动态监测机制。利用学籍信息系统做好贫困家庭学生标注登记，加强监测，及时发现失学学生。建立学籍系统与扶贫信息系统比对机制，对确为不在学的逐一掌握具体原因，分类制定控辍保学措施。对因家庭原因、个人原因未入学或无法完成义务教育的，开展劝返工作；对贫困家庭学生，劝返后实行精准资助，帮助解决困难；对学习困难或厌学的，做好学业辅导和心理疏导；对上学远的，通过增加寄宿床位、提供校车服务等解决困难；将残疾儿童保学作为重中之重，针对残疾类型、残疾程度和家庭情况，实行“一人一案”，纳入学籍管理，对重度残疾孩子，提供送教上门等服务。继续加强留守儿童关爱保护工作，所有贫困村学校均设置留守儿童关爱室。（责任科室：基础教育科）

（五）着力完善“精准招生培养体系”。建立从学前教育、基础教育、高中中职到高等教育的精准招生培养体系，搭建贫困家庭学生成长成才的“绿色通道”。实施学前教育三年行动计划，健全学前教育公共服务体系，确保学龄前儿童都有机会接受学前教育。建立义务教育入学联控联保机制，确保建档立卡适龄人口都能顺利完成义务教育。高中阶段实现应招尽招，努力让未升入普通高中的初中毕业生都能接受中等职业教育。2019年未升入普通高中的农村初中毕业生接受中等职业教育的比例达到90%。深化就学就业精准帮扶，资助与育人并重，扶贫与扶智结合，对建档立卡贫困家庭学生，培养指导“一人一策”，关爱帮助“一对一”，做到学习生活、就业创业全程跟踪、全程指导、全方位帮扶。（责任科室：学前教育中心、基础教育科、职成教研室）

四、保障措施

（一）强化组织领导。教体局成立教育扶贫工作领导小组，各学校（幼儿园）成立相应的扶贫工作机构，明确相关责任领导、联系人，加强对教育扶贫工作的领导，将责任落实到具体人员、帮扶对象落实到具体学生、建设项目落实到具体学校、工作任务落实到具体时间。强化责任落实导向，建立工作台账，实行按月调度、倒排工期，既保证项目质量，又保证时间进度。

（二）强化措施保障。聚焦重点区域，新增教育脱贫攻坚资金、工作项目、工作举措主要布局于深度贫困区域，并把新增省扶贫工作重点村全部纳入工作范围。聚焦重点群体，通过建立完善贫困学生资助保障、控辍保学、精准招生培养体系，千方百计确保建档立卡贫困家庭学生都能上学、上得起学、上得好学。聚焦重点学校，对贫困村学校的薄弱环节进行再梳理、再研判，列出需求清单，强化重点保障，做到精准帮扶、补齐短板，让贫困村学校教育水平上台阶。

（三）强化监督问责。深入开展全县教育扶贫领域问题整改“回头看”活动，定期开展教育扶贫领域常态化监督工作，紧盯关键节点、重点项目、重大问题，通过跟踪督查、随机抽查、定点检查等方式，动态掌握工作进度，发现问题及时督促解决。坚决杜绝滞留截留、挤占挪用、虚列套取资金现象发生，对教育扶贫资金“动心思、伸黑手”的，坚决查处、绝不姑息，确保专款专用、提高资金使用效益。
