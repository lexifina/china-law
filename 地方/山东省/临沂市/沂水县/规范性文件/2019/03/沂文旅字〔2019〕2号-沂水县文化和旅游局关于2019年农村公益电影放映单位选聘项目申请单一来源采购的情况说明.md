# 沂水县文化和旅游局关于2019年农村公益电影放映单位选聘项目申请单一来源采购的情况说明

沂文旅字〔2019〕2号

县政府采购办公室：

为进一步丰富群众文化生活，根据上级要求，2019年拟为全县1040个行政村放映公益电影。

本项目要求拟为全县1040个行政村放映在2019年不少于1.2万场次，场次完成情况以山东省农村电影数字化放映工程服务平台检测的数据为准。播放节目必须来源于国家电影局电影数字节目管理中心数字电影交易服务平台，放映设备需符合山东省农村电影数字化放映工程要求，其中流动播放器必须与山东省农村电影数字化放映工程服务监管平台完成对接工作，电影放映需接受山东省农村电影数字化放映工程服务监管平台监控。沂水县电影发行放映公司具备《电影放映经营许可证》，具有履行放映所必需的设备和稳定的放映员队伍且具有专业技术资格证，是省级农村数字电影院线在沂水县唯一特约授权站。其电影放映工作连续多年受省级表彰，具有连续从事农村公益电影放映工作10年以上的经验并熟悉当地环境。为保证设备和系统的兼容性、匹配性，保障对接设备统一、服务统一管理维护方便、确保放映内容安全性、节约财政资金，经市场考察及评审专家论证，由沂水县电影发行放映公司实施该项目，拟采用单一来源采购方式。该公司本次初步报价34.8万元人民币。
