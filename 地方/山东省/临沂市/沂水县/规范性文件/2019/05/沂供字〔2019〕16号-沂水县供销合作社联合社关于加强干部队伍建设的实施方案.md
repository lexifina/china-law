# 沂水县供销合作社联合社关于加强干部队伍建设的实施方案

沂供字〔2019〕16号

为深入贯彻落实党的十九大精神和县委工作会议精神，切实解决干部队伍建设在形式主义、官僚主义、不作为、不担当等方面存在的突出问题，推动全面从严治党向纵深发展，进一步转变工作作风，增强“四个意识”、树立四个自信，自觉做到“两个维护”，着力打造一支勤奋好学、爱岗敬业、作风过硬、勇于担当、形象良好的干部队伍，树立供销社“担当奉献、创新有为、振兴供销、争创一流”的单位精神。经县社党组研究决定，为进一步加强全系统干部队伍建设，特制定本方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，聚焦党的十九大对政治建设、思想建设、组织建设、作风建设、纪律建设、制度建设提出的新要求，紧紧围绕县委、县政府中心工作,紧密结合县供销社职能和关系群众切身利益的热点问题，认真解决机关干部队伍中思想、纪律、作风等方面存在的突出问题，切实为建设富裕文明和谐美丽新沂水和供销社综合改革提供坚强组织保障。

二、目标任务

这次加强干部队伍建设活动，主要任务和目标是解决“五个问题”、树立“五种风气”、达到“五个提升”、展现“一种精神”。

一是解决“五个问题”。即着力解决精神不振、信心不够、责任缺失的问题；着力解决学风不浓、本领不够、疲于应付的问题；着力解决工作标准不高、落实不够、作风漂浮的问题；着力解决机制不畅、制度不严、环境不优的问题；着力解决站位不高、要求不严、自律不够的问题。

二是树立“五种风气”。即牢固树立发展至上硬道理、解放思想向外看、更新观念求发展、聚精会神搞建设的良好风气；牢固树立学思践悟、勤奋敬业、学以致用、求真务实的良好风气；牢固树立服务三农、开拓创新、唯旗是夺、发奋进取的良好风气；牢固树立立言立行、勇于担当、积极作为、狠抓落实的良好风气；牢固树立美德至上、严守纪律、艰苦奋斗、清正廉洁的良好风气。

三是达到“五个提升”。即进一步提高政治站位和思想境界；进一步提升工作能力和服务水平；进一步提升工作作风和精神状态；进一步提升创新意识和开拓精神；进一步提升责任意识和担当意识；进一步提升供销队伍干事创业的良好形象。

四是展现“一种精神”。即通过本次活动，展现出“担当奉献、创新有为、振兴供销、争创一流”的单位精神。

三、基本原则

（一）坚持统一部署、全员参与。县社党建办负责对加强干部队伍建设活动的谋划部署分阶段调度安排活动进展情况，人事科具体抓好活动的组织实施，做到人员参与全覆盖无遗漏、查摆整改问题见人见事见思想，切实形成“组织严密、职责明确、上下联动、务实高效”的责任体系和工作落实机制。

（二）坚持强化教育、正面引导。将本次活动与即将开展的“不忘初心、牢记使命”主题教育有效结合，把学习教育放在首位、贯穿始终，通过学习党章党纪党规等制度规定，增强干部的政治自觉、思想自觉和行动自觉，切实把纪律和规矩挺在前面，转变工作作风，增强责任意识。

（三）坚持问题导向、集中整治。对照活动要求，深入查摆问题和问题产生的根源，列出问题清单集中进行整改。

（四）坚持完善制度、常态推进。建立完善效能问责追究、干部监督管理等长效机制，努力使严抓严管干部队伍建设成为常态。

四、方法步骤

为确保加强干部队伍建设活动扎实推进，取得实效，分三个阶段进行。

第一阶段：动员部署、学习教育

一是召开动员大会，传达学习加强干部队伍建设的活动方案，全面部署开展，明确活动的总体要求、工作重点和方法步骤，通过动员教育，提高全员认识,深刻理解加强干部队伍建设的重要性、必要性、紧迫性。

二是集中学习、加强教育。结合“两学一做”学习教育常态化和“不忘初心、牢记使命”主题教育，重点学习党章党规、习近平系列讲话、《中国共产党廉洁自律准则》、《中国共产党纪律处分条例》、《中国共产党问责条例》、中央和省市有关文件、讲话、英雄模范事迹等相关内容，并观看警示教育片。

三是撰写学习体会。在集中学习教育的基础上，紧密结合个人思想工作实际，撰写个人心得体会，重点从理想信念、党性修养、遵规守纪、勤勉尽责等方面谈认识和体会，达到自我教育、自我净化、自我警醒、自我提高的目的。

第二阶段：对照检查、查摆问题

一是深入查摆，剖析根源。认真对照中央、省、市、县的有关规定和要求，结合自身岗位，重点围绕政治站位、思想认识、纪律规矩等方面，查摆自身存在的问题，列出岗位职责清单、问题清单。

二是做好互查工作。通过召开座谈会、谈心谈话、走访基层、发放征求意见表等形式，广泛征求和虚心听取群众、基层供销社特别是工作对象、服务对象对本人工作的意见和建议，结合自查出的问题清单、岗位职责清单，深刻剖析存在问题的症结和根源，撰写发言提纲。

三是进行专题研讨。在认真查摆的基础上。围绕“如何进一步担当作为、凝心聚力加快推进供销社综合改革”，深入开展分析讨论，对照自身查摆不足，剖析原因，并明确整改目标和措施，进一步提升党员干部对加强干部队伍建设重要性、紧迫性的认识。

第三阶段：整改提升、建章立制

一是认真制定整改措施。所有干部要认真梳理对照查摆的突出问题，认真制定整改措施，列出整改清单,建立专项台账，做到一项一项整改、一个一个突破、一件一件销号。

二是梳理完善制度。通过对照检查，查找制度漏洞，一方面抓好制度的“立改废”，做到干部队伍管理有章有制可循；另一方面要严格抓好制度的执行落实，为常态化、长效化推进干部队伍建设提供有效保障。

五、活动要求

（一）加强组织领导。县社成立以主要领导任组长，班子成员任副组长的领导小组，抽调人事科、党建办人员组建干部队伍建设年活动办公室，抓推进、抓落实、抓监督、抓成效。领导小组办公室将采取定点督导和随机抽查等方式，及时了解干部学习情况，防止形式主义、走过场，确保加强干部队伍建设活动取得成效。

（二）落实两个责任。党组书记要认真履行主体责任，要亲自抓、负总责，以上率下，亲自谋划、亲自部署、亲自督查，决不允许敷衍应付、当“甩手掌柜”。要一级抓一级、级级有责任、层层有压力、逐级抓落实。班子成员严格落实一岗双责，对分管科室的“干部队伍建设”负总责。

（三）加强宣传教育。各科室要按照活动的统一部署，通力协作，全力抓好活动的组织实施，在活动开展过程中，要注重正面典型和先进人物的发掘和宣传，用身边人讲身边事，用身边事教育和影响身边人，形成提升正能量、弘扬正风气的舆论氛围。
