# 沂水县供销合作社联合社驻高庄镇朱位村第一书记工作队2019年度工作计划

沂供字〔2019〕8号

为认真贯彻落实县委《关于选派第四批机关干部到村任职第一书记的意见》精神，围绕建强基层组织、助理强村富民、弘扬文明新风、服务保障民生的职责要求，实现抓党建促脱贫、抓党建促乡村振兴，结合两年规划和任职村实际，现制定2019年工作计划。

一、抓党建促规范

1、加强党员教育，继续扎实推进“两学一做”及主题党日活动开展，教育引导党员干部争做合格党员、优秀村干部，提高党员干部带领群众脱贫致富的能力。

2、加强党员队伍建设，培养两名入党积极分子及三名后备干部，同时严格遵守各项工作规范，推进村级各项事业健康发展。

二、抓扶贫促增收

1、建设为农服务中心，促进集体增收。协调资金150万元建设1600平方米为农服务中心一处，为村集体每年增加3万元分成收入。

2、实施科技扶贫，提升发展后劲。加强干部群众教育培训，让群众掌握先进种养技术，了解致富信息，掌握致富方法，增强脱贫致富能力，让村民真正得到实惠，协调资金30万元，建设温室大棚两个，每年为村集体增加3万元的租赁收入，尤其是开拓贫困户视野和发展境界，增强自我发展的能力。

3、成立专业合作社，发展规模化种植。成立沂水县鸿泰大姜专业合作社，规范农业种植能力，借助省市县供销社开展的助力扶贫政策，增加贫困户的收入。

三、抓服务促融合

依托所建为农服务中心，积极开展电商、日用品经营、农资经营便民服务，为美丽乡村建设奠定基础。同时积极宣传各级有关“三农”工作的指示精神和惠农政策，进一步引导村民响应国家政策导向，转变发展理念，提升运用科技水平的综合能力。

四、抓民生促和谐

结合美丽乡村建设，协调相关部门对全村老化的自来水管线重新铺设，准备在沿河路安装太阳能路灯30盏，新硬化路面500米，建设社区中心一处，建设幼儿园一处，满足群众休闲活动的需求，完成时间为2019年10月份。

五、抓乡风促文明

1.建设美丽宜居乡村。借助户户通硬化路等民生项目实施，积极开展村容改貌治丑活动，集中整治“五堆三乱”，对村内沿河路进行绿化美化亮化，推进日常保洁制度化、规范化。

2.倡树良好生产生活习惯。全面推行生姜标准化生产，教育和引导村民积极参与“化肥农药零增长”行动，杜绝秸秆焚烧现象发生，大力倡树移风易俗，积极开展文明、诚信创建、最美系列评选等活动，营造积极向上、比学赶超的浓厚氛围。壮大村广场舞队伍，不断丰富群众精神文化生活。

据2019年工作计划，在驻村工作队工作结束时，村集体经营性增收达到5万元以上。
