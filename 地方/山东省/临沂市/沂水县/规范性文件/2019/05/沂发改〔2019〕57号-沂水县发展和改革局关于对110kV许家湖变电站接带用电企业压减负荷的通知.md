# 沂水县发展和改革局关于对110kV许家湖变电站接带用电企业压减负荷的通知

沂发改〔2019〕57号

各有关用电企业：

为进一步提升供电质量，更好地服务全县企业用电，解决许家湖变电站供电瓶颈问题，县供电公司定于6月11日8：00-6月18日18：00更换110kV许家湖站#1主变（原40MW）为63MW。更换改造期间#2主变（50MW）无法承担全站负荷输出,为确保电网安全运行和居民生活用电，计划对35kV大客户永丰轮胎、昆达生物、鲁州生物以及10kV工业园I线、II线、工业园东线、斜午线所接带的10kV用电企业客户实施有序用电。请各用电企业提前做好生产安排，严格按照供电公司调度指令实施停（限）电或避峰用电，确保电网安全运行。

特此通知。
