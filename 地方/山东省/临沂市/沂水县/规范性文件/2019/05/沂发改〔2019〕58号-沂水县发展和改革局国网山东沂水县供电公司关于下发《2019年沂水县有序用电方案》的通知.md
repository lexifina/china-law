# 沂水县发展和改革局国网山东沂水县供电公司关于下发《2019年沂水县有序用电方案》的通知

沂发改〔2019〕58号

各乡镇（街道）经贸办，各有关电力客户：

为保障全县电力供应，根据市政府、市发改委、市供电公司有关有序用电工作要求，结合我县实际，特编制《2019年沂水县有序用电方案》，现下发给你们，请认真执行。

特此通知。

附件：2019年沂水县有序用电方案

沂水县发展和改革局

国网山东省电力公司沂水县供电公司

2019年5月28日

根据2020年5月10日《沂水县发展和改革局 国网山东沂水县供电公司关于下发<2020年沂水县有序用电方案>的通知》失效。
