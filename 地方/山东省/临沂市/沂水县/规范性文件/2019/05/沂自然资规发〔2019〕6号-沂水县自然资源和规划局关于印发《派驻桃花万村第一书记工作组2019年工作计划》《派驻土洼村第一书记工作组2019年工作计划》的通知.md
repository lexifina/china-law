# 沂水县自然资源和规划局关于印发《派驻桃花万村第一书记工作组2019年工作计划》《派驻土洼村第一书记工作组2019年工作计划》的通知

沂自然资规发〔2019〕6号

局机关各科室、局属各单位：

现将《派驻桃花万村第一书记工作组2019年工作计划》和《派驻土洼村第一书记工作组2019年工作计划》印发给你们，请认真抓好落实。

沂水县自然资源和规划局

2019年5月6日

派驻桃花万村第一书记工作组2019年工作计划

按照县委选派第四批机关干部到村任职的要求，推进精准扶贫、精准脱贫工作，实现“抓党建、促乡村振兴”目标，在充分走访调研的基础上，征求村两委成员和乡镇党委意见建议，结合任职村和派出单位实际，制定2019年工作计划。

一、抓党建，建强基层组织

（一）强化党员政治理论学习，以“支部主题党日”、“三会一课”为契机，深入开展“两学一做”学习教育，按照镇委统一要求，制订完善党员学习制度，定期召开村“两委”组织生活会，提升村“两委”班子成员及党员的政治理论水平，做到第一书记户户到。

（二）发展培养入党积极分子3名，组织村里的高学历人员、致富能手等非党人员，通过集中培训、专人帮扶等方式，做好发展入党积极分子和培养后备干部工作，使其积极的向党组织靠拢，解决党员老龄化和青黄不接的问题。

（三）加强阵地建设，多方筹措资金，硬化村委办公室院落760平，完成广场绿化300平，购置部分办公用品，规范规章制度。

二、抓增收，助力强村富民

围绕村集体经济增收和贫困人口脱贫这两条工作主线，扎实开展工作，确保桃花万村集体经济收入2020年达到5万元以上的目标。

（一）一是做好增收大棚及增收车间的管理及运营，每年可实现村集体收入2万余元。二是协助村集体搞好土地流转，集中经营，可为村集体增收3万元。将村集体山林300余亩进行流转，可以增加村集体经济收入2万元。三是争取上级土地整理资金，10月底前对现有的约4亩零星土地进行整理，当年可增加集体收入10万元，以后每年为村集体增加土地租赁收入3000元。

（二）带领群众增收致富方面，在镇党委政府的领导下，积极配合村“两委”，做好120亩黄烟种植的土地流转工作。争取包扶企业及上级有关部门的支持，建设水利设施，对老桃园进行改造提升。

三、抓乡风，弘扬文明新风

（一）协调县文化部门资金3.6万元，帮助村里建设农家书屋1处。协调县体育部门6.2万元，帮助村里建设文化健身广场1处，丰富村民业余文化生活。

（二）搞好文化大院及农家书屋建设，配备文化娱乐设施，为村民提供开展文化活动的平台。讲诚善、做好人，实施好“四德工程”。广泛开展科普宣传、文艺演出，做好“好媳妇”“好婆婆”评选等活动。

（三）广泛开展科普知识、环保政策等宣传活动。协助配合好村两委做好城乡一体化及清理“三堆”集中整治等工作，美化村居环境，给村民创造舒适的生活家园。

（四）倡导移风易俗，加强宣传引导，提高村民认识，凝聚向上向善正能量，更新村民观念，催动殡葬改革。

四、抓民生，服务保障惠民

（一）大力宣传上级对“三农”工作的决指示精神和惠农政策，积极引导村民进一步转变思想观念，增强发展意识、法治意识和致富意识，克服小农意识，“小富即安”的思想，充分调动起群众脱贫致富的主动性、积极性。

（二）积极做好农村改厕和户户通工作。协助有意愿、有条件改造危房的贫困户进行危房改造，不断改善群众生产生活条件。做到每年与应急管理局共同投入到村里的资金不低于5万元。

（三）改善生产生活条件。多方协调资金，完成新修建2.7公里长生产路两侧绿化。按照“五通十有”要求，积极协调有关部门抓好自来水配套、旱涝保收田、改厕和“户户通”等工作推进，协调电力部门对桃花万村电力设施及线路进行整改。定期组织开展清理“三堆”活动，改善村内环境卫生。

派驻土洼村第一书记工作组2019年度工作计划

根据县委关于选派第四批机关优秀干部到村任职的要求，围绕“抓党建促脱贫、抓党建促乡村振兴”的任务目标和“坚强基层组织、助力强村富民、弘扬文明新风、服务保障民生”工作要求，结合2018年度后续工作及地方党委政府和村委2019年度具体工作安排制定本计划。

一、建强基层组织，夯实党建根基。

（一）指导帮助村党支部落实好“支部主题党日”、“三会一课”、重大议事决策、组织生活会、民主评议党员等各项制度，实行党员量化积分管理。

（二）规范管理村级事务。严格执行“四议两公开”、村务财务公开、民主议事决策等制度，积极开展“结对帮扶”、“党员示范”等活动，不断提升村级治理规范化、制度化水平。

（三）严格落实规章制度。研究出台村级规章制度，坚持“一事一议”，涉及村民利益的事，开展村民代表、党员会议，严格按照程序讨论决定，营造风清气正、干事创业的良好氛围。

（四）做好发展党员和培养入党积极分子、后备干部工作，注重培养吸收年轻有为的优秀人才加入到基层党组织中来，2019年计划新发展党员2名，培养入党积极分子2名，培养后备干部1名。

二、助力强村富民，提升发展质量。

（一）利用新建增收车间，争取合作项目早日开工，安置有条件的富余人员就业，同时增加村集体收入3万元。

（二）电商促进产业增收。将电商、农民专业合作社、村集

体与农户紧密连接在一起，进一步方便群众网上购物和农产品网上销售，不断壮大集体经济，实现集体和村民双增收，可实现集体增收2万元。

三、完善基础设施，保障服务民生。

（一）拓宽村民出行道路。计划向有关部门协调部分资金并自筹一部分资金，对6个生产小组的村民出行道路约5.5公里进行硬化，彻底解决村民出行难题。

（二）协调电力部门投资75万元，安装100KW变压器1台，新架高压线路一条。

（三）协调县水利局扶持资金，做好现有2眼机井的水利配套设施工程，新建200立方的蓄水池2座。

（四）多方筹措资金，计划完成450户自来水户户通工程。

（五）协调相关部门，计划完成2万平方米的户户通道路工程。

（六）做好本村土地增减挂钩项目区的规划调整工作，为下一步的项目实施铺好路打好基础。

（七）自然资源和规划局年内直接投入用于民生事业的资金5万元以上，单位主要领导及班子成员年内走访慰问困难群众不少于1次。

四、弘扬文明新风，建设美丽乡村。

（一）成立村卫生清洁小组，保持村内道路干净洁净，实现硬化、净化、亮化、绿化、美化“五化”并举，2019年10月份以前建成占地400平方米文化广场一处。

（二）开展“双美”评选活动。按照“家庭美、居室美、厨厕美、家风美”的四美要求，评选“美在农家”、“美在我家”示范户，积极推进移风易俗，倡导厚养薄葬新风尚。

（三）组织开展文体活动。组建农村秧歌队，积极开展广场舞推广及文艺演出活动，不断丰富群众精神文化生活。
