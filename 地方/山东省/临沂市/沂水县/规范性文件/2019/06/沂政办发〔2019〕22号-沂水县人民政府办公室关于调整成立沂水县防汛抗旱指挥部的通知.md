# 沂水县人民政府办公室关于调整成立沂水县防汛抗旱指挥部的通知

沂政办发〔2019〕22号

各乡镇（街道）人民政府（办事处），沂水经济开发区，县政府有关部门：

根据机构设置、人员变动情况和工作需要，县政府决定，沂水县人民政府防汛抗旱指挥部调整为沂水县防汛抗旱指挥部，并对指挥部组成单位和人员进行调整。现将调整后的名单公布如下：

指挥部办公室设在县水利局，承担指挥部日常工作，曹传海同志兼任办公室主任，辛涛同志、陈爱民同志任办公室副主任。指挥部下设沂河暨跋山水库防汛指挥部、沭河暨沙沟水库防汛指挥部、寨子山水库防汛指挥部、城区防汛指挥部，分别具体负责沂河、沭河、跋山水库、沙沟水库、寨子山水库和城市防汛工作。沂河暨跋山水库防汛指挥部办公室设在跋山水库管理处，王本昌同志兼任办公室主任；沭河暨沙沟水库防汛指挥部办公室设在沙沟水库管理处，刘柱平同志兼任办公室主任；寨子山水库防汛指挥部办公室设在寨子山水库管理所，王永刚同志任办公室主任；城区防汛指挥部办公室设在综合行政执法局，丁远东同志兼任办公室主任。

指挥部成员调整事宜由指挥部或其办公室行文公布。
