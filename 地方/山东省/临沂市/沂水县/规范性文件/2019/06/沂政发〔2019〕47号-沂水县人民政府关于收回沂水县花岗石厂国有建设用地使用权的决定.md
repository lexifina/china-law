# 沂水县人民政府关于收回沂水县花岗石厂国有建设用地使用权的决定

沂政发〔2019〕47号

县政府有关部门：

根据《中华人民共和国土地管理法》《中华人民共和国城市房地产管理法》等法律法规规定，经研究，决定收回沂水县花岗石厂位于县城区信合家园以东、第三实验小学以南6293平方米国有建设用地使用权，同时注销以上宗地范围内已颁发的沂国用（1996）字第0020号国有土地使用证。

沂水县人民政府
