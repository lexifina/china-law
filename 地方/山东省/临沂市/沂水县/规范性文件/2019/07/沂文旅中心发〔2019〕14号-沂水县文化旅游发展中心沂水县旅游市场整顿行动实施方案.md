# 沂水县文化旅游发展中心沂水县旅游市场整顿行动实施方案

沂文旅中心发〔2019〕14号

为进一步规范全县旅游市场经营秩序，严厉打击各类经营活动的违法违规行为，促进旅游市场健康发展，根据《临沂市文化与旅游市场整顿行动实施方案》部署要求，结合我县旅游行业实际，制定本方案。

一、指导思想

深入学习贯彻党的十九大精神，坚持以习近平新时代中国特色社会主义思想为指导，增强“四个意识”，树立“四个自信”，做到“两个维护”，切实做到守土有责、守土负责、守土尽责，牢固树立整顿管长远、管经常的思想，统一力量，密切协作，着力解决旅游行业违规经营、违法乱纪等突出问题，扎扎实实把旅游领域整顿的各项任务要求落到实处，确保全县旅游市场健康发展。

二、工作重点

（一）旅行社。制定安全管理制度、安全责任制落实情况，应急预案建立及演练情况，旅游包车情况，线上产品是否存在违规、虚假现象，是否涉嫌拒绝签订旅游合同或签订虚假合同、超范围经营、以“不合理低价”招揽游客、以虚假宣传诱导消费、以不正当竞争扰乱市场等行为，是否存在强迫或者变相强迫游客购物、隐瞒购物行程、增加自费项目、向不合格的供应商订购产品和服务等违法行为；导游是否违规违法获得回扣，使用人身攻击语言逼迫购物，擅自改变行程，加购物店等行为；是否存在挂靠承包经营现象，营业网点、旅行社业务对外违规承包、造成恶性竞争行为。

（二）A级景区。消防安全许可情况，设施设备及高危活动项目安全检验许可情况（包括索道、观光车、电梯、滑雪、攀岩、滑索、滑道等设施和游乐设备)，是否核定了景区日最大承载量和瞬时最大承载量，并实行分级监控管理，危险地段、水上旅游项目，是否有专人值守和安排专业救护人员，对节庆活动安全防范和防火是否有预案、有演练，抽查旅游团队导游资质、导游执业APP开启情况；是否存在乞讨现象；景区环境卫生是否达到相应的标准。

（三）星级饭店。消防设施、安全通道等消防安全许可、使用情况，餐饮、卫生许可情况，安全防范和防火是否有预案、有演练，安全措施到位情况。涉外宾馆接收境外电视节目，是否持有相关许可手续，是否符合接收目的、内容、方式和收视对象范围等要求。

（四）安全生产。旅游企业是否有消防和安全生产工作职责，建立健全安全生产制度，是否定期组织员工安全培训和各种防火、灭火、逃生等安全演练，应急照明设施、安全疏散指示标志、禁烟标识和消防器材等设施设备是否符合要求。

（五）旅游厕所。旅游企业是否存在保洁不到位、冲刷不及时、手纸配备不全面，卫生污浊，洁具乱摆乱放，设施设备损坏维修不及时，文明如厕宣传欠缺等现象。

（六)涉黑涉恶线索。景区内旅游购物摊点是否存在采取暴力、威胁等手段，敲诈勒索外地游客的现象；旅游景区是否存在高额返利诱惑，助推出租车司机采取暴力、威胁、诱骗等手段追客赶客非法谋利的现象；旅行社使用的旅游大巴车主是否存在采取暴力、威胁等方式排挤其他合法经营者的现象；旅游企业是否存在工作人员与游客发生纠纷后，纠结多人进行威胁、恐吓、打击报复的现象。

三、实施步骤

（一）企业自查阶段。（7月31日前）

旅游企业要根据实施方案要求，制定本企业的具体方案并部署实施。成立领导小组，明确职责分工，认真开展自查自纠。

（二）集中检查阶段。（8月1日—9月15日）

按照“属地管理、行业自律、各司其职、部门联动、齐抓共管”的原则，针对我县旅游市场违法违规行为，采用线上线下结合、明察暗访与执法检查同步的方式，对我县旅游市场进行综合整顿。

（三）总结提升阶段。（9月16日—10月15日）

各旅游企业针对排查出的问题，严格落实整改措施。根据整改情况开展“回头看”检查，确保整改工作落实到位。

四、工作要求

（一)提高认识，加强领导。各旅游企业要充分认识此次专项整顿行动的重要性，按照统一部署，迅速行动起来，扎扎实实把这次整顿行动组织好、开展好。为切实加强对全县旅游市场专项整顿行动的组织领导，县文旅中心成立全县旅游市场整顿行动领导小组，各旅游企业也要成立领导机构，制定具体的整顿行动方案，明确任务分工，责任落实到人，确保各项工作任务落到实处。

（二）突出监管重点，务求取得实效。各旅游企业要紧紧围绕活动主题，聚焦重点，通过落实一系列整改措施，着力强化高质量发展理念，提高全员素质。要加强工作创新，着力发动员工积极参与，扩大活动覆盖受众面和影响面。注重总结经验，善于发现典型，持续巩固和深化活动成果，不断完善工作制度，推动各项工作质量提升。

（三）认真统计总结，及时报送信息。集中整顿期间，各旅游企业要积极报送活动开展情况，于7月10日前将整顿领导小组及整顿方案报县文旅中心集中整顿领导小组办公室；每周一10：00前报送上周工作进展情况；每月5日前报送上月的工作小结；10月15日前报送整顿工作总结。
