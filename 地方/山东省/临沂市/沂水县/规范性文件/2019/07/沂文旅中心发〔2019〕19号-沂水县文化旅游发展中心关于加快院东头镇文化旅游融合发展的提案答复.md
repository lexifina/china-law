# 沂水县文化旅游发展中心关于加快院东头镇文化旅游融合发展的提案答复

沂文旅中心发〔2019〕19号

王伟山、武玉英、贾孝凤、石庆东委员：

您提出的“关于加快院东头镇文化旅游融合发展”的建议提案收悉，现答复如下：

2019年，我们将一如既往的支持院东头镇文化旅游融合发展，具体措施如下：

一是支持创建省级旅游度假区和国家5A级景区。省级旅游度假区。积极协调争取完成市级初审及会签，并将材料及时上报省政府及相关部门，争取2019年予以批复。同时，继续做好旅游度假区内设施配套和旅游项目打造，进一步丰富旅游业态。国家5A级景区。推动龙冈旅游集团主板上市，争取母基金50亿元的省精品旅游产业基金支持沂水旅游产业发展和萤火虫水洞·地下大峡谷产业链条延伸。把国家5A级景区创建作为各级党委政府的重要工程，全力以赴调动各方资源帮助企业搞好创建工作，发挥企业创建主体作用，加快萤火虫水洞·地下大峡谷旅游区提升，确保达到5A级旅游区标准要求，迎接文旅部暗访验收。

二是持续推进现有项目提升。桃棵子红色旅游区。加强文化产品旅游转化，完善文化场所旅游功能。提高博物馆、文物保护单位等文物资源的旅游利用水平，完善公共图书馆、博物馆、文化馆、科技馆等文化场所的旅游功能。推动非物质文化遗产、民俗展演等进景区、进酒店、进乡村旅游集聚区，推广“景区+游乐”、“景区+剧场”、“景区+演艺”等文化活动模式。峙密山居项目。建设传统文化博物馆、绘画写生大讲堂、徽派古建筑精品民宿区、接待中心服务区、古商业街购物区、松柏雅集生态康养区等。

三是深度挖掘沂水文化，凝聚院东头镇全域旅游形象。借助省内外有重大影响力的营销宣传平台，不断深化与周边省区和城市的旅游文化合作与交流。持续深入提升“山东好客.沂水情长”文化旅游整体形象品牌，注重文旅融合，围绕特色景区文化做文章，联合旅游企业在重点客源市场开展旅游文化宣传营销和业内交流活动。围绕院东头镇特点，开展慢游乡村、主题小镇、精品民宿等产品宣传，策划推出2—3条具有地域影响力的全域大环线、精品小环线等多日游线路。

四是升级打造文化旅游节庆品牌，线上线下同步开启创意推广。提升院东头镇乡村文化旅游节、漂流节、萤火虫节，采茶节等旅游节庆活动举办档次水平，让老牌旅游节庆活动赋予文化新活力，做好包装和宣传，借助节庆效应，提高社会关注度。与院东头镇联合，策划举办一系列创意文化旅游营销推广活动，如“跟着故事游沂水”、“遇见沂水的‘诗和远方’”等征稿、采风、摄影大赛等多种类型的线上线下互动文化旅游活动。积极推进购物旅游发展，结合“沂水十品”品牌建设工作，抓好以“沂水十品”为重点的品牌培育和宣传推广工作。围绕沂水特色，设计一批文创旅游商品，年内筹备举办一次文创旅游商品大赛。
