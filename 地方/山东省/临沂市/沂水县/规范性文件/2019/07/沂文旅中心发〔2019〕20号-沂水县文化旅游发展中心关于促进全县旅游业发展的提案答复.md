# 沂水县文化旅游发展中心关于促进全县旅游业发展的提案答复

沂文旅中心发〔2019〕20号

杨洪春委员：

您提出的关于促进全县旅游业发展的提案收悉，现答复如下：

一、旅游供给侧改革方面

以提质扩容及创新发展为目标，坚持“建设全景沂水·发展全域旅游”发展战略，全面完成文旅融合体制改革，完善精品文化旅游推进体系，深挖文化资源，拓展旅游与文化、农业等融合的广度和深度，打造优质旅游产品，形成“倍增效应”、“叠加效应”，全力推动文旅项目建设，推进旅游产业新旧动能转换，扩大文旅产品供给，设计、生产、销售代表全县旅游形象的旅游商品，释放旅游业发展活力，强化“山东好客·沂水情长”地域文化形象内涵，叫响“全省全域旅游第一县、全市域内创建5A级景区第一县、沂蒙山水田园游第一县”品牌。同时，充分发挥县旅游集散中心、全域旅游服务区、旅游咨询中心等游客服务功能，构建起较为完善的旅游综合服务体系。加快“智慧旅游”建设，探索大数据平台开发运用，不断提升智慧旅游水平，在重点景区、乡村旅游特色村实现Wifi、电子讲解、在线预订、信息推送、数据处理等功能全覆盖。

二、扶持政策方面

一是明确领导责任。各乡镇、部门要认真履行全域旅游发展的主体责任，把做好全域旅游工作列入重要议事日程，确保责任到位、措施到位、落实到位。将全县旅游重点项目分解细化到各有关乡镇和单位，实行县级领导包扶旅游项目责任制，综合施策，强力推进。二是推进统筹发展。发挥县旅游联席会议作用，定期召开会议，加大规划、国土、交通、金融等部门与旅游融合力度，加快形成全域融合发展格局。三是加大财政投入。充分发挥1000万元旅游发展专项资金作用，积极整合小城镇建设专项资金、农业发展专项资金等，向旅游乡镇、旅游板块倾斜。发改、农口、住建、国土、交通、环保等各部门积极争取上级各部门政策、项目，用于支持旅游业发展。四是强化用地支持。国土部门做好旅游重点项目用地保障，重大旅游项目新建、改建、扩建等确需调整土地的，实行“一事一议”政策。

三、人才的培养和引进方面

通过举办培训班、组织考察学习等方式，加强对旅游从业人员的教育培训，切实提高涉旅企业及从业人员经营管理和服务水平。坚持旅游招商引资与招才引智相结合，通过重点旅游项目吸引现代旅游经营管理人才落户沂水。发挥校地合作平台和省乡村旅游培训基地作用，研究县域旅游发展，培育多层次旅游从业人员。积极开展旅游志愿者活动，为游客提供信息咨询、应急救助、投诉引导和文明旅游宣传等服务。

四、国家5A级景区创建方面

在各级各部门的大力支持下，旅游区于2017年2月份通过了原国家旅游局组织的创建5A级旅游景区景观质量专家评审，正式纳入创建名单。在县委县政府的领导下，强化落实创建主体责任及部门分工，全力搞好软硬件提升工作。具体工作情况如下：

全县层面：在成立创建工作领导小组后，县主要领导、分管领导多次召开创建5A级旅游景区工作推进会、现场会、讨论会；县绩考办安排专人靠上，全力督导；各相关部门、乡镇政府积极参与推进，全力盯靠项目，密切配合，及时发现、解决项目推进过程中遇到的困难和问题，确保了创建工作的顺利推进：

1、文旅中心积极做好各部门、乡镇和创建企业的统筹协调工作；组织相关人员到青州、威海、蒙山、沂山等5A景区学习创建工作；同时完成了通往旅游区道路的75块指示牌提升。

2、交通运输局完成了酒文化园至萤火虫水洞的道路拓宽工程及相关绿化；清理了景区周边黑出租；

3、移动、联通、铁塔公司等通讯部门联合作业提升了了景区通讯信号覆盖面及强度，光缆入地已完成；

4、供电公司完成了景区内及出入口高低压线路入地隐蔽施工；

5、邮政局启动了纪念邮戳、纪念信封、明信片等邮政服务；

6、综合执法局实现景区垃圾常态化外运；做了部分创建宣传；

7、卫计局审定了景区的应急救援协议，协调县医院与景区签订了合作协议，同时协调有资质的医师进驻景区；

8、市场监管局：对景区内外农家乐规范化经营进行了督导提升；

9、生态环境局已出具景区空气、噪音、地表水、污水等环境监测合格材料；

10、国税局、地税局、统计局完成了相关数据统计并出具“合格”证明材料；

11、公路局已将省道229龙家圈至姚店子段改扩建为一级公路方案上报省交通运输厅，正在进行审核；

12、宣传部、电视台、网信办：做了大量创建宣传。

13、创建驻地乡镇院东头镇责无旁贷、主动出击，成立了农家乐协会，撤除了景区周边违规牌匾，完成了农家乐改貌提升、指示牌设立更新、沿线房屋粉刷1.2万平、农家乐周边景观绿化带砌垒等工作，对景区周边进行了环境综合整治，将永富庄岭预制场进行了搬迁并绿化完成，对后武家庄三角地带进行了微地形整理，海子路口沿街商铺进行了改造；沿沂邳路从永富庄至烟家庄和从姚店子至桃棵子共栽植松柏、海棠等苗木2000余株及蜀桧近万株，硬化路面2000平方米，完成挡土墙垒彻1000余米；完成坡子及桃棵子概念门建设，完成了大峡谷入口处高炮广告挪移，完成了马家崖、四门洞两条人车分流道路建设及两边绿化美化工程等；与景区共同成立雨披清理小组，专职在沿线道路检查取缔；共同对购物区秩序进行整治，打击内部黑出租。

14、龙家圈街道：进行了广告牌、旅游沿线垃圾、排水沟淤泥清理等环境综合整治工作。

企业层面：旅游区及龙冈旅游集团，组织全体员工召开了创5A誓师大会，依据计划任务书，进行了分组分工，倒排工期，严格对照标准要求进行全方位提升：建设了两处建筑面积均在千平方米以上的游客中心；所有旅游公厕全部达到3A级标准，实现了步行不超过20分钟距离的布局；新建、改扩建生态停车场10万余平方米，可同时容纳大中小客车5000余辆；新布局设置位置牌、导向牌、警示牌、说明牌等标识标牌500余块；对4公里洞内灯光效果进行了全面改造提升；硬化美化旅游道30余公里，添置了景观小品，完善了游客休憩设施，同时新增或改造垃圾桶265个；萤火虫水洞景区新建“月亮小镇”购物场所2400余平方米，大峡谷景区建设、提升购物场所2200余平方米，购物环境、秩序显著改善；已实现无线网络全覆盖、智能停车、电子售检票及智能语音讲解，建成数字虚拟景区，可进行网上游览，建设智慧景区的目标实现；利用外出学习、引进高端专业讲师、岗位培训、定时培训等方式，对旅游区工作人员从服装、礼仪、服务、普通话等方面进行全方位的培训和提升，坚持每日对员工培训5A创建手册、标准化服务,进行军事化训练，引进龙冈舞等，实现了中、英、日、韩、俄等语种的导游配置，全面提升景区服务水平和管理机制。

同时，旅游区加强综合调度，开展档案材料的收集、整理、归档工作。根据创建标准和版式、格式等要求，完成了《服务质量与环境质量评分细则》八大项的档案材料整理工作。

在下步工作中，将按照创建工作总体部署，有计划、有步骤地对旅游交通、游览、旅游安全、卫生、邮电服务、旅游购物、综合管理、资源和环境保护等方面的硬件和软件进行查漏补缺，不断完善提升。具体如下：

（一）景区层面。针对“景区内沿路及可视范围内存在绿化“漏点”，存在卫生死角及垃圾不能及时清扫情形”的问题，建议龙冈集团利用当下绿化有利时机，加大绿化力度，强化卫生责任制，发动全员，及时清扫，坚决清除卫生死角。针对“创建5A氛围不浓，缺乏文化主题及文化氛围”的问题，建议龙冈集团在专家指导帮助下，尽快拿出氛围营造方案，并进一步明晰文化主题，提升整个景区文化档次。针对“仍然存有卖雨披及黑出租的现象”的问题，建议龙冈集团采用短信提醒、雨披免费领取等手段，从源头上进行预防控制，院东头党委政府采用党员干部帮扶、加强巡逻等手段进行综合整治；龙冈集团加派人手在交通运输局的帮助下，坚决消灭黑出租。“旅游购物区工作人员不服从管理，造成脏乱差”的问题，建议龙冈集团在院东头镇、市场监管局、综合执法局的帮助下，尽快拿出切实可行方案并积极实施；针对“景区内部分区域联通、电信信号不畅通”建议由联通、电信公司进行整改提升；针对“服务水平存在差距”的问题，龙冈集团应建立常态化培训机制，采用岗前培训、岗位培训及邀请专家、内外交流、技能比赛、典型带动等各种形式，全面提升员工管理服务水平；针对“照相点、购物区有使用高音喇叭、电子设备进行宣传现象，造成噪声过大”的问题，建议龙冈集团主动联合院东头镇政府及综合执法局等部门，进行全面取缔；针对“投入不足，缺少亮点”的问题，龙冈集团强化创建主体责任，加大投入，并全力打造创建5A工作亮点，实现“亮点效应”；针对“专家智力支持不足”，建议龙冈集团邀请省、国家文化旅游主管部门认可的创建5A知名专家或团队前来模拟暗访及全程指导；“龙冈集团缺少专门领导现场靠上”的问题，龙冈集团尽快明确1名集团领导现场靠上，有效协调解决创建过程中遇到的问题。针对“创建5A工作经验提炼推广不足”的问题，龙冈集团应积极邀请专家，提炼全国范围内可、供同行业参考的创建5A工作经验，并通过各种媒体进行宣传推广；针对“个别停车场未作生态化改造”，建议龙冈集团按照生态停车场的标准，抓紧全部整改完成；针对“网上售票规模不大”，建议龙冈集团安排专业技术人员采取加大宣传、搞好合作、举办活动等方式，提高网上售票率；针对“自动售票系统规模不足”，建议在游客集中区域，增加设备数量，同时积极动员游客进行自助购票。

（二）全县层面。针对“创建氛围不浓”的问题，建议由龙冈集团出资，由文旅中心积极协调，在沿路高炮、建筑物显著位置悬挂创建标语口号，到专家暗访前，争取由宣传部牵头，安排县城及沿路所有机关事业单位前放置宣传标语，所有店面LED屏幕播放创建标语。针对“旅游区外围、主要旅游路段及两侧需要进行环境综合整治”，到专家暗访前，协调综合执法局、公路局、交通运输局及院东头镇、沂城街道、龙家圈街道、黄山铺镇、许家湖镇等按照各自职责范围进行整治。针对“个别外围旅游指示牌需要进行补充完善”，由县文旅中心联合龙冈集团，进行进一步查漏补缺，全面完善旅游公共信息导向系统。针对“两创建主体景区之间连接道路”问题，由交通运输局协调汽车站和景区搞好合作工作，确保旅游专线正常运行；争取交通运输局尽快开展最近连接线的规划论证及具体设计工作；针对“沂邳路破损严重”，争取公路局积极协调省里尽快扩建为一级公路，如时间紧急，可先进行修补。

对于以上工作，必须于8月30日之前全部完成整改。创建5A办公室及沂蒙风情旅游景区管理中心加强调度协调力度，对于存在的问题，及时反馈给各部门，并积极帮助解决。各部门共同努力，全面细致做好各项准备工作，迎接国家文旅部暗访验收，争取一次性通过。
