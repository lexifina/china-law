# 沂水县文化旅游发展中心关于切实抓好“三区同创”旅游重点工作、叫响“全省全域旅游第一县、全市域内创建5A级景区第一县、沂蒙山水田园游第一县”品牌的提案答复

沂文旅中心发〔2019〕21号

邱健委员：

您提出的关于切实抓好“三区同创”旅游重点工作、叫响“全省全域旅游第一县、全市域内创建5A级景区第一县、沂蒙山水田园游第一县”品牌的提案收悉，现答复如下：

2018年以来，县委县政府提出了创建国家5A级旅游景区、国家全域旅游示范区和省级旅游度假区“三区同创”的宏伟目标。目前，在国家全域旅游示范区创建方面，我县专设创建办，细化分解任务，稳步有序推进；在国家5A级旅游景区创建方面，萤火虫水洞·地下大峡谷旅游区已通过5A级旅游景区景观质量评审和省文旅厅专家初评，暗访申请已报文旅部；在省级旅游度假区创建方面，沂蒙风情旅游度假区基础设施提升和重点旅游项目建设有序推进。

一、全力以赴、不遗余力、加快创建步伐

（一）5A级景区

5A级景区创建工作共分三个阶段，2017年2月，我县萤火虫水洞·地下大峡谷景区顺利通过第一阶段的景观质量评审，被正式纳入创建名单；2017年12月，通过了第二阶段省旅发委的专家初评；目前，正在等待第三阶段国家文旅部的专家暗访组暗访。今年以来，围绕创建工作推进，先后赴青州古城、威海华夏城等省内近期创建成功5A的先进景区进行调研学习，进一步明晰了创建路径和思路办法；多次深入创建景区对接调度，初步理清了创建工作的内外部责任事项，并列出了任务清单；就我县5A创建工作与省文旅厅领导进行了汇报对接，省文旅厅领导对创建工作的路线图、时间表进行了指导；起草了《我县5A级景区创建工作推进情况汇报》等调研报告，对我县当前及今后创建工作提出了建议意见；正在协调国家级暗访专家近期对我县创建景区进行模拟暗访。

（二）全域旅游示范区

3月底，召开了全县创建国家全域旅游示范区迎查动员;对照标准要求，完成了所有档案的整理工作;向市文化和旅游局报送了县政府验收申请、自查得分表、得分说明、创建工作汇报、创建汇报视频、汇报PPT以及其他证明材料，市局已报到省文化和旅游厅;完成了全域旅游导览图设置、复合型服务区增设旅游功能、全域旅游服务区标识牌翻新等工作；继续夯实国家全域旅游示范区创建现场的准备工作，等待省厅评审意见。

（三）省级旅游度假区

度假区规划已编制完成，并顺利通过了评审；沂水县人民政府《关于申请设立沂蒙风情省级旅游度假区的请示》已报送市政府；县旅游、发改、规划、国土等部门的申请报告已报送至市旅游、发改、规划、国土部门；同时，积极与省文旅厅、省政府等上级部门对接，了解省级旅游度假区创建的最新动态。

二、下一步工作计划

（一）“三区同创”完善全域发展格局

坚持初心，坚定不移推进“三区同创”。创建国家5A级旅游景区。坚持创建工作力度不减、标准不降，压实企业创建主体责任，充分调动驻地乡镇、部门积极性和主动性，进一步巩固创建成果，及时查漏补缺，争取2019年迎接文旅部专家暗访验收，力争一次创建成功。创建国家全域旅游示范区。依据国家全域旅游示范区验收办法和省市创建工作会议相关要求，加强对上沟通衔接，安排部署任务，全力迎接验收，力争创建成为国家全域旅游示范县。创建省级旅游度假区。积极协调争取完成市级初审及会签，并将材料及时上报省政府及相关部门，争取2019年予以批复。同时，继续做好旅游度假区内设施配套和旅游项目打造，进一步丰富旅游业态。

（二）强化宣传营销实现品牌市场突破

积极实施五大系统营销策略，即：实施品牌营销计划，深入提升“沂水情长”品牌的知名度、美誉度和影响力；实施城市营销计划，不断扩大客源市场规模；实施主题营销计划，灵活开展多主题营销，扩大客源市场；实施活动营销计划，形成全时全域活动营销格局；实施渠道营销计划，切实加强与各大主流媒体的合作，广泛宣传推介“三区同创”和沂水旅游产品。
