# 沂水县文化旅游发展中心关于设立民间美食发明奖”的提案答复

沂文旅中心发〔2019〕22号

邱健委员：

您提出的“关于设立民间美食发明奖”的建议提案收悉，现答复如下：

我们将积极引导支持各乡镇、旅游景区开发当地独具特色的旅游美食，结合“沂水十品”品牌建设工作，抓好以“沂水十品”为重点的品牌培育和宣传推广工作。加大特色美食、土特产、工艺品、文创产品的开发与提升，推进八大碗特色餐饮，沂蒙特色美食体验等项目。以青援食品、鼎福食品两家省级旅游商品研发基地和蒙山龙雾茶博园、沂蒙山酒文化园等企业为带动，东方瑞海温泉度假村、沂河山庄、寰宇大酒店等星级酒店为主导，积极引导企业开发沂水特色美食，形成一定影响力。围绕沂水地域特色，力争年内筹备举办一次民间美食发明大赛。
