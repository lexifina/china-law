# 沂水县文化旅游发展中心关于进一步提升旅游服务质量的通知

沂文旅中心发〔2019〕23号

各乡镇、街道，经济开发区，各涉旅企业：

7月11日，“问政山东”栏目对全省旅游行业进行了问政，现场曝光了山东省会城市群游客集散中心体验项目闲置、设施陈旧，青岛世界园艺博览园4A级旅游景区管理不规范、设施维护不到位等诸多问题。本着举一反三的原则，为加强我县旅游行业高质量发展，持续推动涉旅企业规范经营，进一步提升旅游服务质量，现就有关事宜通知如下：

一、目的意义

进一步提高对旅游服务质量工作重要性的认识，建立健全旅游服务质量长效机制，深入开展旅游服务质量的标准化、规范化、品牌化活动，实现旅游企业规范旅游经营行为、执行服务质量标准、优化服务质量、提高管理水平、遵守职业道德、维护旅游消费者合法权益的目标，促进全域旅游战略深入实施，推动沂水旅游业持续健康发展。

二、工作重点

（一）旅游从业人员服务基本要求

1.文明旅游礼仪：旅游从业人员及时提醒游客维护公共卫生，遵守公共秩序，有序排队，礼让乘车，爱惜公共设施，注意保护文物古迹和生态环境，不大声喧哗、随意插队、乱扔垃圾。

2.仪容仪表：旅游从业人员面容整洁干净，容貌美观自然，精神饱满。女性员工化淡妆，与工种、服务场所协调，不浓妆艳抹。员工名牌戴在胸前，位置统一。

3.服装要求：各岗位服务人员服装式样、色彩有明显区别，便于客人辨认。员工着装要求外套、内衣、鞋袜、裙子、领带、领花等配套统一，整洁、挺括，无污迹、无皱褶。

4.形体要求：站、坐、行要平稳端正，表情自然，符合规范。服务动作要规范、大方。

5.服务态度：主动热情，宾客至上。坚守岗位，遵守纪律，主动为客人提供细微服务。

6.服务语言：服务中，要使用文明用语，不用否定、命令、训诫式语言，不和客人争吵。

7.服务效率：为游客提供服务时，要按照规范程序，按时提供服务。游客提出特别要求的，或因客观原因不能按时提供或完成的服务，要及时向游客作出解释和说明。

（二）旅游企业服务具体要求

1.旅行社服务要求

（1）旅行社在经营活动中应按照核定的经营范围开展经营活动。要诚信经营，遵守商业道德，不得超范围经营。

（2）旅行社制作的宣传品应明码标价，文字通俗易懂，内容准确无误，不能用模糊、不确定用语故意误导、欺骗客人，不得进行虚假广告宣传。

（3）旅行社应对为游客提供服务的餐馆、住宿、交通、娱乐等各接待单位进行认真考察，符合国家有关规定和要求，证照齐全的，方可作为旅行社定点接待单位。

（4）旅行社销售人员应熟悉产品特点、价格及相关的旅游资源、设施、交通情况，耐心向游客解答各种业务咨询。

（5）旅行社向客人出售旅游产品应与游客签订规范的旅游合同，合同要使用规范的语言文字，表述清晰，避免因表述不清引起游客误解，造成纠纷。

（6）旅行社应制作《旅游安全告知书》，提示每位游客阅读告知书，并在告知确认台帐上签字。制作游客意外伤害险购买提示牌，咨询每位游客是否愿意购买保险，提示放弃购买的游客要在告知确认台帐上签字。旅行社组织团队外出旅游前应召开行前说明会，做好目的地旅游安全、宗教习俗等注意事项的告知工作，制作游客安全及文明旅游微信或短信，发送给每位随团游客。

2.旅游景区服务要求

（1）售票接待服务：售票处服务人员应熟练掌握各类票据的价格和使用情况，对游客做好解释说明工作。在售票处明显位置应悬挂符合物价主管部门要求的价格公示牌，向游客公布票价表、购票须知、营业时间、项目介绍和游乐须知等信息。应设置最大承载量公示牌，有专人维护秩序，确保出入口无拥挤混乱现象。

（2）游览接待服务：讲解员必须持证上岗，讲解内容不得随意删减，不得出现强迫或诱导游客消费二次项目的现象。景区可根据情况设有广播室，为游客提供安全提示、文明旅游提示等广播服务，播音内容应能清晰传送至景区停车场、游客中心、出入口等区域。

（3）服务信息指示：科学合理地设置游览指示标志和各类信息符号标志。各主要通道、叉路口应在适当的位置设置引导标牌；各游乐项目的入口处，应在显著的位置设置该项目的《游乐规则》，所有景物景观应设置说明牌。按有关规定和要求设置安全标志，室内项目要有醒目的入、出口标志。安全标志应清晰易辨，不得设在可移动物体上。各类文字说明牌的内容准确，文字规范，字迹清晰，有中英文对照。

（4）游客中心：有咨询服务台，咨询服务到位。导游服务监督到位。休息区、影视区等规范整洁规范。各种标识醒目。提供本旅游景区导览宣传资料，提供饮料及纪念品服务。设电脑触摸屏，具有拐杖、童车、轮椅等人性化服务设施。在游客中心外明示免费服务项目。

（5）公共厕所：公共厕所地面采用防滑瓷砖，随时保持干燥，设置洗手盆、面镜，提供干手器等设施设备，厕位内设手纸架、手纸筐、挂衣钩、搁物台等。有专人负责清洁卫生，做到随时清扫，保持清洁，无蚊蝇、无异味。各种设施设备无破损、无污垢、无堵塞、无滴漏。

（6）停车场：场地平整坚实、卫生整洁，车辆分类停放，整齐有序。应有专门管理人员，并佩带明显标志，指挥车辆进出及停放，保持车道畅通，不发生堵塞现象，加强巡逻，防止砸车、盗窃等违法现象发生。停车场应作到收费合理，明码标价，出具正式票据。

（7）医疗点：含有公共信息图形符号的标识规范、醒目。具有药柜（含日常药品）、床、输液架、氧气袋、担架、听诊器、血压计、急救箱、急救电话等医疗设施设备。具有持证的专门医疗人员。与相关单位有专门运送协议。

（8）购物服务：督促摊点完善证照手续，食品摊点从业人员要办理健康证，保持环境整洁，秩序良好，明码标价，无围追兜售、强买强卖现象，不得出售假冒伪劣商品。

3.星级饭店服务要求

（1）前厅服务：入住登记服务要做到快速、准确，要充分利用客史档案等已有资料，简化手续，团队客人入住登记前，要预先分配好房间；问询服务要做到热情、耐心，答复准确清晰、简明扼要。对暂不能回答的问题，要表示歉意，并尽快查阅有关资料或咨询有关部门后予以答复，不得简单回答“不知道”、“不行”等；预订服务要熟练掌握饭店客房类型、价格以及餐饮、康乐、会议等方面有关情况，准确记录预订房间数、房型、抵离时间、预订人姓名、单位、联系方式、付费方式等有关内容，并进行确认，超额订房要科学合理，确保不发生失约行为；行李寄存及贵重物品保管服务要清楚掌握哪些物品可以寄存、哪些物品不能寄存等方面内容，做好物品检查、单据填写、客人签字确认等工作，确保无错发、冒领等现象发生。

（2）餐饮服务：零点服务员要主动为客人拉椅让座，送上菜单，并及时提供茶水、香巾服务。服务员要熟练运用推销技巧主动向客人介绍菜品，并视情况提醒客人适量点餐，防止浪费。要及时为客人斟倒酒水、更换骨蝶、烟灰缸等餐间服务。应提供菜点打包、酒水寄存等相应服务；宴会服务员要提前做好宴会现场布置，及时引导客人就座，提供分餐服务，宴会期间如安排讲话、祝酒或节目演出等内容，服务员要及时通知厨房，适当调整上菜时间。

（3）客房服务：服务员应先检查房间有无客人遗留物品，一旦发现要及时按有关规定处理。应按照先后顺序对房间进行卫生清理，使用的清洁用具要分区、分类、分型、分色，不能混用。应仔细检查电器设备是否正常，控制按钮是否完好有效、开关自如，一旦发现问题，应及时报有关部门修复。要认真检查房间小食品、茶叶、咖啡、酒水等配备情况，如有消耗，要及时补充。

（三）文明旅游工作要求

1.加强宣传，营造浓厚氛围。一是各涉旅企业要通过播放电子屏、悬挂条幅、张贴宣传画、设置易拉宝等方式，大力宣传文明旅游。二是各涉旅企业要制作《中国公民国内旅游文明行为公约》提示牌，在显著位置进行摆放。三是旅游景区要在公共卫生间、垃圾箱、游乐设施等部位，设置文明旅游公益广告、温馨提示。星级饭店要在客房卫生间、客房床头柜、餐厅点餐区、餐桌、大堂吧、公共卫生间等部位，设置“节约用水”、“节约用电”、“布草清洗”、“适量点餐”、“禁止吸烟”等文明行为、绿色消费温馨提示。旅行社与游客签署旅游合同时，要对文明旅游事项进行告知，要附送文明旅游宣传材料，让游客自阅自学。四是各涉旅企业要进行创意策划，推出免费发放垃圾袋、垃圾换水、文明旅游签名、打包赠送小礼品、文明消费换代金券等能够让游客参与的活动，使文明旅游活动深入人心。

2.强化培训，提升文明服务水平。一是各涉旅企业要对员工开展《山东省文明待客100条》教育培训，提高从业人员文明素质和服务能力。二是各涉旅企业要选拔一批文明旅游引导员，旅游景区要制作并佩戴印有“文明旅游”字样的袖章或绶带，提示游客文明游览，及时制止游客不文明行为；星级饭店要贯彻落实《山东省旅游饭店、餐馆卫生规范100条》标准要求，做好引导游客合理用餐、理性消费工作；旅行社要严格遵守《旅行社行前说明服务规范》和《导游领队文明旅游引导规范》要求，行前坚持召开说明会，向游客讲清楚遵规守纪、文明旅游的要求，讲清楚不文明言行的利害关系，在旅途行程环节落实导游一岗双责，要抓住乘车、入住、用餐、游览等时间节点，向游客宣传普及目的地风俗习惯、禁忌和相关法律，旅途行程中坚持开展文明引导和文明礼仪宣传，并做好行前说明会和带团过程中的文字、图片或视频记录。

3.争先创优，弘扬文明正能量。各涉旅企业要全面落实文明旅游工作的各项要求，开展文明旅游先进单位争创活动。要积极开展美德游客、最美导游评选活动，挖掘文明旅游先进典型，并利用电视、广播、报纸、微信、微博等方式进行宣传报道。

（四）志愿服务工作要求

1.加强宣传，完善服务岗位设置。各涉旅企业要通过播放电子屏、悬挂条幅等方式，大力宣传志愿服务。旅游景区要在游客中心设置志愿服务站，在安保、车辆指挥、售票、检票、讲解、保洁、游乐设施、购物区公平秤等服务窗口设立志愿服务岗；星级饭店要在前台、餐饮吧台设置志愿服务岗；旅行社要在门店内外设置志愿服务岗。

2.强化培训，丰富志愿服务内容。各涉旅企业要对志愿服务者进行岗前培训，统一为志愿者提供旅游志愿服务马甲，确保能够为游客提供便民物品、文明引导、游览讲解、安全提示、旅游咨询等服务。

3.保障安全，解决游客燃眉之急。各涉旅企业要成立旅游应急志愿服务小分队，为游客提供应急救助、叫车、修车、交通疏导等服务。

三、实施步骤

（一）企业自查阶段。（7月31日前）

旅游企业要根据通知要求，制定本企业的具体方案并部署实施。成立领导小组，明确职责分工，认真开展自查自纠。

（二）集中检查阶段。（8月1日—9月15日）

按照“属地管理、行业自律、各司其职、部门联动、齐抓共管”的原则，针对我县旅游市场违法违规行为，采用线上线下结合、明察暗访与执法检查同步的方式，对我县旅游市场进行综合整顿。

（三）总结提升阶段。（9月16日—10月15日）

各旅游企业针对排查出的问题，严格落实整改措施。建立长效机制，确保管理服务质量持续提升。

四、工作要求

（一）强化组织领导。各乡镇、街道、经济开发区及涉旅企业要高度重视，结合《沂水县旅游市场整顿行动实施方案》《沂水县文化旅游发展中心关于迎接中华人民共和国成立70周年旅游安全生产专项整治行动工作方案》，成立专班，明确职责，同步开展好旅游服务质量提升工作。县文化旅游发展中心成立督导组，对各涉旅企业工作开展情况进行督导。

（二）突出工作重点。拥有镇域游客中心的乡镇、街道，要全面梳理排查管理服务问题，确保设施设备、导向标示、旅游厕所、旅游咨询、售票服务等各项工作完善到位。各乡镇、街道、经济开发区要重点对辖区内2A、3A、4A级旅游景区进行检查，督促景区严格落实《旅游景区质量等级的划分与评定》，对严重不符合A级标准要求的，属地党委政府要及时将降低或取消景区等级的意见建议报县文化旅游发展中心。各乡镇、街道、经济开发区要强化对非A级景区和在建涉旅项目的管理，如沂城街道的梅园、雪山彩虹谷休闲运动体育特色小镇、龙家圈街道的灵泉山、泉庄镇的尹家峪田园综合体、院东头镇的峙密山居、经济开发区的沂河度假小镇等项目，积极协调相关业务主管部门开展专项检查。各涉旅企业要紧紧围绕工作重点，通过落实一系列措施，着力强化高质量发展理念，提高全体从业人员素质。

（三）强化宣传引导。各乡镇、街道、经济开发区要加强旅游宣传报道，注重总结推广经验，树立先进典型，公开曝光反面案例。充分发挥社会督导作用，引导广大群众广泛关注、积极参与，扩大活动覆盖受众面和影响面，营造齐抓共管的良好氛围。相关信息、总结与市场整顿、安全专项整治情况一并报送县文化旅游发展中心。

沂水县文化旅游发展中心
