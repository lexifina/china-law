# 沂水县气象局关于升级地面高空辐射酸雨气象数据格式标准化业务软件的通知

沂气办发〔2019〕3号

各科室：

按照《山东省气象局关于开展地面高空辐射酸雨气象数据格式标准化业务切换的通知》（鲁气办发〔2018〕80号）和《山东地面气象观测自动化改革试点实施方案》（鲁气办发〔2018〕79号）要求，我省全部国家级地面气象观测站和高空站完成了地面、高空、辐射、酸雨标准格式数据的业务切换。切换后，国家气象信息中心在对标准格式数据进行全流程监控过程中发现存在标准格式数据无法进入快速质控或CIMISS库等个别情况。针对上述问题，中国气象局组织修订了BUFR模板，改进了地面ISOS软件、高空L波段软件、CTS2.0快速质控软件和MDOS软件。
