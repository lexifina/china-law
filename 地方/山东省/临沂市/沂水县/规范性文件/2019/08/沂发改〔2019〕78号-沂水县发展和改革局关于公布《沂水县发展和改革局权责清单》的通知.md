# 沂水县发展和改革局关于公布《沂水县发展和改革局权责清单》的通知

沂发改〔2019〕78号

各科室,服务业发展中心,重点项目服务中心,能源工作服务中心,信息中心，价格认定中心：

按照县委编办、司法局《关于印发<规范和完善沂水县政府部门权责清单制度实施方案>的通知》要求，我局积极推进权责清单标准化规范化建设，全面梳理县级行政权力责任事项和公共服务事项，编制了《沂水县发展和改革局权责清单》，现予以公布。
