# 沂水县科学技术局关于公布《沂水县科学技术局权责清单》的通知

沂科字〔2019〕22号

各科室、局下属单位:

按照县委编办、县司法局《关于印发〈规范和完善沂水县政府部门权责清单制度实施方案〉的通知》(沂编办〔2019〕50号)要求，根据《临沂市科技系统暨市科学技术局权责清单》，结合我县科技工作实际，对县级科技权责事项进行了全面梳理，编制完成了《沂水县科学技术局权责清单》，现予以公布。
