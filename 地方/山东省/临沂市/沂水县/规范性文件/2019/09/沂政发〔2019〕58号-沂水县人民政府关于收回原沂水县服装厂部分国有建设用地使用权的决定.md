# 沂水县人民政府关于收回原沂水县服装厂部分国有建设用地使用权的决定

沂政发〔2019〕58号

县政府有关部门：

根据《中华人民共和国土地管理法》《中华人民共和国城市房地产管理法》等法律法规规定，经研究，决定收回原沂水县服装厂位于县城区中心街以西10.33平方米国有建设用地使用权，同时注销以上宗地范围内已颁发的国有土地使用证。
