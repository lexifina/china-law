# 沂水县文化和旅游局文化扶贫“补短板、促提升”工作方案

沂文旅字〔2019〕37号

为切实做好文化扶贫工作，确保文化扶贫工作成效，现根据《沂水县脱贫攻坚“补短板、促提升”工作方案》，结合工作实际，制定如下方案。

一、工作目标

突出贫困村文化活动室和文化广场设施器材、规章制度、活动台账、扶持资金管理、作风建设、贫困村广播电视信号通达情况等工作重点，坚持问题导向，全面排查整改，着力补齐扶贫工作短板、提升扶贫工作成效。

二、工作内容

1、文化活动室规范提升工作。要对照各级检查反馈问题，结合工作实际，对贫困村文化活动室进行再次梳理排查，检查中要坚持即查即改，对已达标的文化活动室，要完善管理机制，做好日常维护管理，尚不完善的文化活动室，能当时整改的要当时整改，一时不能整改的要列出单子，定出措施，限期完成整改。

2、文化广场提升改造工作。要按照贫困村文化广场建设标准，对贫困村文化广场提升改造情况进行认真排查，因村施策完善提升。文化广场已达标的，要加强管理和维护；尚未达标的，要本着缺什么补什么的原则，按节点实施好提升工作；改建扩建的，要因地制宜加快推进，确保按期完成改扩建任务，配备好相应的设施器材。

3、广播电视行业扶贫推进工作。要根据广播电视村村通的要求，对贫困村、尤其是拆迁村广播电视信号是否通达、是否正常等情况进行排查，如有达不到要求的，要主动与广播站沟通协调，尽快把问题解决好，确保达到贫困村广播电视信号通达、信号正常的要求。

三、工作要求

1、加强组织协调。这次文化扶贫工作“补短板、促提升”活动是按照县扶贫开发领导小组部署安排进行的，各乡镇文化站要高度重视，将其作为一项重要工作来落实，主动做好沟通协调，积极组织开展文化扶贫问题整改“回头看”，扎实做好整改工作，以整改提升扶贫工作成效。

2、扎实开展活动。各乡镇文化站要按照文化扶贫“补短板、促提升”工作方案要求，进一步细化工作措施，明确时间节点，结合各级检查反馈问题、前期排查整改问题，认真搞好梳理排查，对存在的问题，要明确整改责任，以务实的态度、扎实的作风，尽快落实整改措施，确保问题整改到位。

3、强化督导调度。各乡镇文化站要结合梳理排查，建立整改台账，指导督促贫困村按照节点抓好问题整改，搞好完善提升。县文化和旅游局将对排查发现的问题梳理汇总，建立台账，实行定期调度，跟踪督导，销号管理，并根据进展情况进行抽查，及时协调解决工作中遇到的问题，确保补短板促提升工作取得实效。
