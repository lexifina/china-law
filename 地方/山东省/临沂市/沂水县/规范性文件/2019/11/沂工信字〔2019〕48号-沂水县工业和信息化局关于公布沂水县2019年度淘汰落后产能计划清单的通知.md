# 沂水县工业和信息化局关于公布沂水县2019年度淘汰落后产能计划清单的通知

沂工信字〔2019〕48号

各乡镇（街道）、经济开发区经贸办：

按照《关于印发<2018-2020年利用综合标准依法依规推动落后产能淘汰和过剩产能退出实施方案>的通知》(临经信产字〔2018〕311号)、《关于提报2019年度淘汰落后产能计划的通知》（沂工信字〔2019〕23号）等有关要求，经研究，确定山东连杆总厂有限公司等18家企业相关产能列入沂水县2019年度淘汰落后产能计划清单，现予以公布。

各乡镇（街道）经贸办要加强对清单项目的日常调度和督导，强化综合协调，把握时间节点，依法依规，统筹推进，确保年内全面完成淘汰计划；要督促相关企业及时向社会作出不再恢复相关产能生产的公开承诺；要按照相关要求，做好关键环节影像资料留存和重点手续归集工作，形成完备的淘汰落后产能退出档案。

附件：沂水县2019年度淘汰落后产能计划清单
