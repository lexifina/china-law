# 沂水县人民政府关于调整成立沂水县森林防灭火指挥部的通知

沂政发〔2019〕61号

各乡镇（街道）人民政府（办事处），沂水经济开发区，县政府各部门：

根据机构设置、人员变动情况和工作需要，经县政府研究，决定将沂水县森林防火指挥部调整为沂水县森林防灭火指挥部（以下简称指挥部），对指挥部组成单位和人员进行相应调整。现将调整后的名单公布如下：

指挥部下设办公室，办公室设在县应急管理局，承担指挥部日常工作，耿立江同志兼任办公室主任，张国锋、胡金贵、王玮岽同志兼任办公室副主任。

指挥部下设预防、扑救和物资保障三个工作组，预防工作组设在县自然资源和规划局，负责组织、协调和指导全县森林火灾预防和火情早期处置工作，牛树娟同志兼任组长；扑救工作组设在县应急管理局，负责组织、协调和指导全县较大以上森林火灾扑救工作，耿立江同志兼任组长；物资保障工作组设在县粮食和物资储备中心，负责储备和调出森林火灾救援物资，王清峰同志兼任组长。指挥部成员调整事宜由指挥部或其办公室行文公布。
