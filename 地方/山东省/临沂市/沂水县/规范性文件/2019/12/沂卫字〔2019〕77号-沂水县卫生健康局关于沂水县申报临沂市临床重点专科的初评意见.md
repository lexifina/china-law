# 沂水县卫生健康局关于沂水县申报临沂市临床重点专科的初评意见

沂卫字〔2019〕77号

临沂市卫生健康委员会：

根据《临沂市2019年度市级临床重点专科评选工作的通知》（临卫医发〔2019〕11号）及专业标准要求，沂水县人民医院申报胸外科、消化内科、产科、临床检验科、耳鼻喉科、口腔科6个专业参加评审；沂水县妇幼保健计划生育服务中心申报产科、妇女保健科、儿童保健科3个专业参加评审，经初评，我局同意县医院和县妇幼保健计划生育服务中心参加市级临床重点专科评估，并将积极支持、督促两个单位做好市级评选工作。
