# 沂水县人民政府办公室关于印发沂水县深化科技奖励制度改革方案的通知

沂政办发〔2019〕51号

各乡镇（街道）人民政府（办事处），沂水经济开发区，县政府各部门：

《沂水县深化科技奖励制度改革方案》已经县政府研究同意，现印发给你们，请认真贯彻执行。

沂水县人民政府办公室

2019年12月5日

（此件公开发布）

沂水县深化科技奖励制度改革方案

为深入贯彻落实国务院和省、市关于深化科技奖励制度改革精神，进一步完善我县科技奖励制度，调动广大科技工作者创新创业的积极性、主动性和创造性，制定本方案。

一、总体要求

坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中、四中全会精神，深入落实习近平总书记视察山东重要讲话、视察临沂重要讲话、重要指示批示精神和党中央、国务院对科技工作的决策和部署，围绕实施创新驱动发展战略，改革完善科技奖励制度，进一步提高奖励质量、控制奖励数量、优化奖励结构、规范奖励程序，建立公开公平公正的评奖机制，大力弘扬求真务实、勇于创新的科学精神，营造促进大众创业、万众创新的良好社会氛围，充分调动全社会支持科技创新的积极性，为经济高质量发展注入强大动力。

二、重点任务

（一）修订《沂水县科学技术奖励办法》。借鉴国家、省、市科技奖励改革做法，开展工作调研，及时把握改革动态，结合我县实际，提出改革完善县科技奖励制度的思路和措施，提高科技奖励制度活动的透明度。突出科技奖励的荣誉性，取消由财政出资的科技奖励资金。依据新修订颁布的《临沂市科学技术奖励办法》，完成《沂水县科学技术奖励办法》修订工作，经县政府审核批准后颁布执行。

（二）优化奖项奖种设置。按照国家、省、市深化科技奖励制度改革精神，对接国家、省、市科技奖励体系，结合我县实际，合理设置县科学技术进步奖数量，原则上不超过30件。将县科技进步奖分设为县科学技术最高奖、县科技进步奖。县科学技术最高奖每年原则上1名，县科技进步奖设置一等奖、二等奖、三等奖，其中一等奖、二等奖、三等奖占比为1:2:3。

（三）明确县科学技术奖提名制度。参照《临沂市深化科技奖励制度改革方案》，结合我县实际，由乡镇（街道）、县政府组成部门和直属机构及经县科学技术局认定的其他部门进行提名。

（四）进一步发挥科学技术奖的作用。充分发挥科技奖励的激励和引导作用，促进全县科技奖励设立更加规范有序、成效作用更加明显，将专利、软件著作版权、技术标准纳入科技进步奖申报范畴。

（五）鼓励支持社会力量设立科学技术奖。强化对社会科技奖励业务指导和政策咨询服务，推动社会科技奖励科学化、规范化发展。积极引导民间资金支持社会科技奖励活动，帮助社会科技奖励拓宽资金渠道。

（六）建立申报、提名和评审诚信制度。强化申报单位和个人、提名者和评审专家的诚信意识，明确申报单位和个人、提名者和评审专家的责任和义务，规范申报提名及评审行为，广泛接受社会各界监督，对违规者取消其相关资格，3年内不得提名。

（七）完善以绩效评价为重点的县科学技术奖评价体系。根据《临沂市科技奖励制度改革方案》要求，建立以科技创新质量、贡献为导向的科技奖励评价体系，对不符合国家、省、市产业政策、生态环保、安全生产的项目，实行一票否决。

（八）鼓励支持争获市级以上科技奖励。加大对申报国家、省、市科技奖励的引导和支持力度，指导我县单位和个人向上争取科学技术奖。对获得国家科学技术奖、省部级科学技术奖、市科学技术奖的，统一纳入全县科学技术奖表彰范围，按照《关于做好人才支撑新旧动能转换工作的实施意见》（临发〔2018〕12号）奖励。

三、组织实施

（一）加强组织领导。县科学技术行政管理部门代表县政府，切实加强对全县科技奖励制度改革工作的指导，确保各项改革任务圆满完成。发挥县科学技术奖励委员会的作用，做好奖励改革工作顶层设计、科学规划，指导全县科学技术奖励工作科学规范、公平公正、扎实有效开展。

（二）强化政策支撑。由县科学技术行政管理部门会同县司法行政管理部门负责修订《沂水县科学技术奖励办法》并按程序报县政府批准；由县科学技术行政管理部门负责修改完善《沂水县科学技术奖励办法实施细则》，研究落实县科学技术奖励委员会章程、监督委员会章程、提名办法、分类评价指标体系、评审监督办法、异议处理办法等配套措施。

（三）推动措施落实。各乡镇（街道）、县直各部门要全面贯彻落实国家、省、市深化科技奖励制度改革的部署要求，结合实际，扎实抓好科技奖励改革各项任务落实。
