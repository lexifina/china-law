# 沂水县人民政府关于公布沂水县第三批县级非物质文化遗产代表性项目名录的通知

沂政发〔2019〕67号

各乡镇（街道）人民政府（办事处），沂水经济开发区，县政府各部门：

县文化和旅游局确定了第三批县级非物质文化遗产代表性项目，共12项，经县政府研究批准，现予以公布。全县各级各有关部门要按照《中华人民共和国非物质文化遗产法》《山东省非物质文化遗产条例》等要求，认真贯彻“保护为主、抢救第一、合理利用、传承发展”的工作方针，坚持科学的保护理念，切实做好非物质文化遗产的保护、管理和合理利用工作，为弘扬沂蒙文化、建设经济文化强县作出新的更大的贡献。

附件：沂水县第三批县级非物质文化遗产代表性项目名录
