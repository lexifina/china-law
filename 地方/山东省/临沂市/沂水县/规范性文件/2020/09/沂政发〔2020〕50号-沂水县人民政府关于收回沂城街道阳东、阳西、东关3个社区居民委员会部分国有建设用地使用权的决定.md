# 沂水县人民政府关于收回沂城街道阳东、阳西、东关3个社区居民委员会部分国有建设用地使用权的决定

沂政发〔2020〕50号

县政府有关部门∶

为提高城镇建设水平，根据《中华人民共和国土地管理法》《中华人民共和国城市房地产管理法》等法律法规规定，经研究，决定收回位于县城区长虹南路以东、向阳街以北沂城街道阳东社区居民委员会1225平方米国有建设用地使用权，沂城街道阳西社区居民委员会5768平方米国有建设用地使用权，沂城街道东关社区居民委员会5112平方米国有建设用地使用权，具体事宜按收回国有建设用地使用权协议书执行。

沂水县人民政府

2020年9月22日
