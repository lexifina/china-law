# 沂水县文化旅游发展中心关于印发《党员干部纪律作风集中整顿活动实施方案》的通知

沂文旅中心发〔2020〕23号

为着力解决全体党员干部纪律作风方面可能存在的突出问题,根据县委县政府《关于开展全县党员干部纪律作风集中整顿活动的意见》、县党员干部纪律作风集中整顿活动领导小组办公室《关于印发沂水县党员干部纪律作风集中整顿活动实施方案的通知》要求，特制定本方案。

一、总体要求

坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九大和十九届二中、三中、四中全会精神,聚焦形式主义、官僚主义和纪律作风突出问题,推进精准查摆、精准整改,实现纪律作风根本性好转,切实营造风清气正的良好政治生态,为推动全县旅游行业高质量发展提供坚强纪律作风保障。

二、整顿重点

集中整顿活动,要始终强化问题意识,坚持问题导向,重点查摆和解决以下问题：

(一)政治站位不高方面。

1.贯彻落实上级部署安排、指示要求行动迟缓,态度不坚决;参加会议后对会议精神不汇报、不传达、不学习等问题。

2.政治敏感性不高,发表不当言论,传播小道消息。

3.持之以恒抓作风建设意识不强,上级要求严,抓作风建设就紧,反之就松,平时满足于过得去、不出事。

4.缺乏正确的政绩观,急功近利、脱离实际。

（二）不担当、不作为方面。

5.推诿扯皮、推卸责任,该把关的不把关,该决断的不决断,凡事向上级请示汇报,要求下级贯彻落实。

6.消极应付、行动迟缓,见困难就推,见矛盾就躲,有风险的事不想干,没先例的事不肯干,有难度的事不愿干,凡事先想退路。

7.怕担风险，不敢创新,遇到问题等政策等领导协调等指示批示。

8.精神懈怠,有“守摊子”思想。

9.工作拖沓,不催不动,推拖等靠,偷奸要滑。

10.部门利益至上,协作意识欠缺,职责边界斤斤计较,落实工作推三阻四,该牵头的不牵头,该配合的不配合,该办的事情不办,该落实的打折扣,“踢皮球”“打太极”。

11.要求不严,标准不高,满足于“差不多”“过得去”。

（三）作风漂浮方面。

12.不想学习、不爱钻研,走马观花、流于形式,不能主动学习有关规定要求,满足于听说了、大体上知道了。

13.政策不清、业务不熟,平时不注重学习积累,对新形势新情况不敏感、不掌握,对新常态新决策不适应、不会抓。

14.思维定势、路径依赖,遇到问题时不能妥善处置。

15.新办法不会用,老办法不管用,硬办法不敢用,软办不顶用,遇到问题不会研究,解决问题没有思路。

16,以会议贯彻会议、以文件落实文件,做表面文章、过度留痕,缺乏实际行动和具体措施。

17.抓工作不深不实,浮在面上,流于形式。

18,抓落实重调度、轻督查,满足于工作报告上的“材料政绩”。

（四）执行力差方面。

19.推进工作缺乏主动性、积极性,对安排的工作上传下达,习惯当“二传手”。

20.缺乏“钉钉子”精神,落实力度不足不够,不愿吃苦,缺乏主动。

21.自我要求不高,奉献精神不足,不愿付出、斤斤计较、贪图享受,缺乏吃苦耐劳、身先士卒、克己奉公、无私忘我的思想。

22.动力不足、精神懈怠,缺乏干事创业激情,缺少争先创优意识,不求有功、但求无过。

23.工作标准不高、创新突破不足,完不成任务强调客观理由。

24.拿规章制度作为“挡箭牌”,死板执行程序规定,只说“不能办”、不想“怎么办”,嘴上说着“可以办”,心里念着“不能办”。

25．遇到难题绕着走,碰到问题往后拖。

（五）懒政怠政、为政不廉方面。

26.习惯懒散、为官不为,空喊口号、不抓落实,评头论足、坐而论道。

27.法治意识淡薄,以权谋私捞好处,吃喝卡要“潜规则”,不给好处不办事，给了好处乱办事。

28.习惯“分解责任”,将属于自己的职责转移到下级, 自己无事一身轻。

29.承诺不兑现、程序不规范、办事不公开。

30.乱检查、乱收费、乱罚款,影响投资环境。

31.执法不严、通风漏气,违反程序、执法违法,办人情案、关系案，影响政府公信力。

32.执法不规范,选择性执法,针对领导重视和上级安排的事项搞突击执法。

33.不讲原则,失职失察,对干部管理失之于宽、失之于软，执行纪律不严格,对违反工作纪律问题视而不见,不问责、不处理。

34.对通报的典型案例、他人的违规违纪问题持漠视态度，事不关己高高挂起,不能主动对照查摆,存在侥幸心理。

（六）政令不畅方面。

35．部署推进“中梗阻”,工作落实“等拖靠”,消极怠工、拖拉成性。

36.私设障碍、违规前置，明通暗卡、久拖不决,死抠不能办、强调程序不给办、创新服务不会办,能办不办、该办不办,围绕程序打转转。

37.贯彻落实上级决策部署上打折扣、做选择、搞变通,对县委、县政府的决策部署说三道四,评头论足,变通搪塞,有令不行,有禁不止。

38.首问负责、一次性告知等制度不完善、落实不到位。

39.“老官不管留账”“新官不理旧账”。

(七)工作纪律松弛方面。

40.对纪律作风要求不重视、对违规违纪问题不警醒。

41.不严格遵守工作纪律,无故迟到早退,工作时间干与工作无关的事情。

42.不严格遵守会议纪律,随意缺席、随意替会,频繁出入、接打电话、交头接耳,做与会议无关的事情。

43.工作日午间、节假日值班期间违规饮酒,酒后驾驶机动车辆。

44.不能严格落实领导干部外出请假、报备制度。

（八)漠视和损害群众利益方面。

45．群众观念淡薄,口气粗暴蛮横,对待群众摆“官架子”。

46.漠视群众利益,对涉及群众利益的问题视而不见、无动于衷,态度冷漠、敷衍塞责。

47.门难进、脸难看、话难听,对办事人故意刁难、设卡。

48.落实上级惠民政策不公开、不公正,优亲厚友、弄虚作假,损害群众和集体利益等。

49.便民服务单位和政务服务窗口态度差、办事效率低。

50.服务热线、便民网站、政务APP运行“僵尸化”。

三、方法步骤

（一）宣传发动阶段（9月7日一9月10日)。结合实际制定活动实施方案,组织召开动员会议,成立活动领导小组,深入宣传发动。把加强学习教育、提高思想政治素质贯穿始终,采取个人自学、集中学习、开展警示教育等多种形式,认真学习习近平新时代中国特色社会主义思想和习近平总书记关于全面从严治党、纪律作风建设等方面的重要论述、党章党规党纪等内容,切实增强政治意识、纪律意识和责任意识。

（二)问题查摆阶段（9月11日一9月25日)。全体机关干部对照党章党纪、合格党员标准、岗位职责,以严的精神、实的态度,深入查找班子及个人自身存在的突出问题,深挖思想根源,研究改进措施。通过座谈、走访、设立意见箱、发放征求意见表等多种方式,广泛听取和征集各方面的意见建议,特别要注重听取游客、旅游企业和经营者的意见,认真梳理吸纳,列出问题清单,为集中整改打好基础。

（三）对照整改阶段（9月26日一10月31日)。班子及全体机关干部对照问题清单,制定整改方案,建立整改台账,一项一项整改、一个一个突破、一件一件销号,确保突出问题整改到位,带动纪律作风根本好转。针对查摆出的问题,深入开展自我剖析,找准找实问题根源,明确整改目标和措施,对能够立即整改的要立说立行、即知即改,一时难以整改到位的要限期整改完成。

（四)巩固提升阶段(11月1日一12月10日)。立足实际,对照问题查找制度漏洞,坚持标本兼治,一方面抓好制度的“立改废”,建立健全制度体系,做到有章可循,用制度管权、管事、管人,促进各项工作规范、高效开展;另一方面严格抓好制度的执行落实,为常态化、长效化推进党员干部纪律作风建设提供有效保障。及时梳理总结作风整顿中的好做法、新经验,按照务实管用的原则,将其提炼固化为制度,形成持续推进纪律作风建设的长效机制。

(五)检查验收阶段(12月11日-12月31日)。县文旅中心党员干部纪律作风集中整顿活动领导小组办公室要加强监督检查,认真做好迎查验收工作,并认真总结加强作风建设的经验、取得的成效以及巩固措施,形成书面总结报县领导小组办公室。

四、有关要求

(一)提高政治站位。开展党员干部纪律作风集中整顿活动,是整治形式主义、官僚主义,提高“四个意识”,践行“两个维护”的具体举措,是维护党的形象、巩固党的执政根基的一项重要政治任务,全体机关干部一定要站在讲政治、讲大局的高度,务必抓紧抓实抓好。

(二)严格落实责任。领导小组办公室要进一步落实责任,强化举措,行成层层抓落实的工作局面。党组书记要认真履行第一责任人职责,做到亲自抓、负总责;班子成员和分管领导要认真落实“一岗双责”；全体干部职工要自觉查摆和纠正存在的问题,列出问题清单,明确整改措施,做到有的放矢、对症下药,坚决杜绝搞形式、走过场,坚决社绝无视问题、回避掩盖问题

（三）强化监督检查。领导小组办公室要加大检查督导力度,对单位纪律作风集中整顿情况进行督促检查,有效传导压力、发现问题、掌握动态、促进整改。对思想上不重视、活动走过场的个人,通报批评并责令限期整改，确保活动的每一阶段、每一环节都落到实处。

（四）注重活动实效。各科室要把开展纪律作风集中整顿活动与“125”工程旅游项目推进、“三区同创”等旅游工作有机结合起来，把活动中激发出来的干劲及时转化为做好工作的动力，做到两手抓、两不误、两促进，为推动全县旅游事业转型跨越发展做出积极贡献。
