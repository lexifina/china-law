# 沂水县审计局驻东河北、西河北村第一书记工作组2023年度工作计划

沂审字〔2023〕3号

2023年，县审计局派驻黄山铺镇东河北、西河北村第一书记工作组，以习近平新时代中国特色社会主义思想为指导，深入贯彻落实县委、县政府乡村振兴战略部署要求，进一步加强村级组织建设，完善基础设施，不断发展壮大村级集体经济，努力实现强村富民目标。

一、东河北村2023年驻村工作计划

东河北村位于黄山铺镇驻地东北约2.7公里处，全村339户，918口人，村两委5人，党员41名，村民代表34人，耕地760亩。村民主要收入来源为外出务工和种植业、养殖业。

（一）党建统领，建强基层组织。围绕提升村党支部的组织力和战斗力，指导、协助村党组织实施“主题党日”和“党员量化积分”管理活动。“七一”前夕，组织党员集中外出学习，开阔眼界，并进行一次缅怀先烈、不忘初心、重温入党誓词，提高党员素质。2023年，新发展党员1名。

（二）加大投入，完善基础设施。针对东河北村基础设施不完善，缺少改造资金的难题，积极协调资金，改善村容村貌。对东河北大桥路口破损路面进行整修，硬化村内道路700米，方便群众生产生活。安装太阳能路灯25盏，保障群众夜晚出行安全。

（三）文明助力，促进乡村和谐。为了不断夯实司法调解工作基础，设立司法调解室，规范调解室软硬件，做到五个有，有电脑、有桌椅、有文件柜、有台账、有制度，做到调解原则、调解程序、工作纪律、当事人权利义务等制度上墙，着力把民间矛盾纠纷化解在基层，消除在萌芽状态。

二、西河北村2023年度驻村工作计划

一是抓党建促规范。认真落实以“三会一课”为主要内容的基层组织生活各项制度，组织两委班子成员学习党的二十大精神和习近平总书记系列重要讲话精神，提高法律意识、政策意识和服务意识，强化政策理论学习，提高党性修养。2023年，争取发展党员1-2名，入党积极分子4-5名。

二是抓民生促发展。牢记发展是第一要务，积极争取资金和政策支持，为群众办实事、办好事，完善基础设施，改善群众生产生活条件。对村北的水库进行除险加固，修建蓄水池3个，确保村北山楂园区的用水供应。安装太阳能路灯15盏，方便居民生产生活。

三是抓项目促增收。根据西河北村山楂园区建设规划，为了保持山楂新鲜，便于储存，计划建设一个30米长，14米宽，高4.5米的高标准恒温库，增加群众收入，壮大集体经济，推动实现产业兴旺、农民增收的乡村振兴新局面。

四是抓文明促新风。积极推进移风易俗，引导群众自觉践行文明新风，提升道德修养，形成相亲相爱、向上向善的新风尚。开展敬老扶幼活动，每年中秋节、春节，组织对孤寡老人、残疾人纳入五保户、低保户进行走访慰问，对家庭贫困学生进行资助。

三、保障措施

（一）组织领导方面。审计局高度重视驻村第一书记工作，把该项工作列入单位工作重点，纳入重要议事日程，成立了以局长为第一责任人的工作领导小组，定期开展现场办公，帮助解决工作遇到的困难和问题，确保第一书记驻村工作形成整体合力、取得实效。

（二）组织协调方面。审计局充分利用自身优势，针对任职村基础设施建设的实际情况，多次与水利、林业、交通、财政等各单位联系、对接，争取相关项目和资金支持。

（三）资金投入方面。审计局严格落实上级文件精神，切实加强资金投入，在单位经费紧张的情况下，压缩办公经费，确保每年至少5万元的帮扶资金投入。
