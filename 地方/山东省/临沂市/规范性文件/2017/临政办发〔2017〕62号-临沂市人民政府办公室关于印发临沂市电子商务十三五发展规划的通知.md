# 临沂市人民政府办公室关于印发临沂市电子商务十三五发展规划的通知

二、发展形势

（一）国际电子商务发展形势

1.全球电商产业发展势头强劲，市场规模达22.1万亿美元

2.全球电商产业格局初步形成，印巴等新兴电商市场崛起

3.电子商务新兴业态持续涌现，电商呈多元化发展态势

4.跨境电商将成贸易主要形式，中小企业迎来发展新契机

5.现代物流价值日益凸显，新技术引领电商物流变革

（二）国内电子商务发展形势

1.电商政策密集发布，“十三五”成落实关键期

2.跨境电子商务不断壮大，各地迎来发展新机遇

3.县域电商消费初见成效，农产品进城扩展渠道

4.传统批发商触网成趋势，B2B创新服务不断涌现

5.传统产业资本活跃，以投资促进线上线下融合

6.网络消费扩容，生活服务业成电商发展新热点

7.城市电商发展各有侧重，品牌打造各有机会

（三）临沂市电子商务发展形势

1.电子商务交易规模快速增长，行业应用水平不断提升

2.电商创新创业主体加速孕育，示范创建工作持续推进

3.电商推进工作机制不断健全，交流培训活动初见成效

4.商贸业逐步实现转型升级，专业市场电商化水平亟需提升

5.现代物流业创新发展，“最后一公里”难题亟待解决

6.县域电商取得突破性进展，网络商品品牌效应亟待加强

三、临沂市电子商务发展重点领域研究

（一）县域电商专题研究

1.县域电商发展现状

（1）农村网络基础设施不断完善，农村网民数量持续增长

（2）农产品电商交易活跃，形成多层次电商市场体系

（3）农资电商发展潜力大，电商模式呈现多元化发展

（4）日用品电商平台向农村延伸，物流服务下行通道扩展

（5）农村电商扶贫成为新热点，多方参与助推县域脱贫

2.县域电商发展特点

（1）多项政策促进县域电商试点示范

（2）县域电商融资速度加快

（3）淘宝村镇县建设进入新阶段

3.县域电商发展趋势

（1）县域电商保持快速发展势头

（2）县域电商服务环境日趋改善

（3）县域电商产业链不断延伸

（4）县域电商线上线下融合趋势明显

（5）县域电商的政策支持力度持续加大

附表：我国县域电商新政策（2015）

（二）跨境电商专题研究

1.跨境电子商务发展现状

（1）跨境电商平台模式日趋多样化，跨境电商生态系统逐步形成

（2）海外仓和保税区建设获政策支持，助力跨境电商拓展渠道

（3）自贸区优势与功能定位各有不同，试点城市谋求创新发展

（4）跨境网购消费者数量与规模增加，购物市场及品类不断扩展

（5）地方省市因地制宜发展跨境电商，积极出台新政策与新举措

2.跨境电子商务发展趋势

（1）“一带一路”推动跨境电商跨越式发展

（2）跨境电商线上线下全渠道融合发展

（3）跨境电商出口带动外贸新增长

（4）整合资源优化跨境业务流程

（5）跨境电商发展环境进一步优化

附表：我国跨境电商新政策（2015）

（三）电商服务业专题研究

1.电商服务业发展现状

（1）电商服务业市场规模加速增长，客服外包等成为新增长点

（2）电商服务业服务门类更加丰富，形成日益完善的服务体系

（3）电商服务业主体结构不断优化，集中分布于沿海一线城市

2.电商服务业重点细分行业发展现状

（1）电子商务交易服务业以B2B为主体，B2C占比不断提高

（2）电子商务支撑服务业需求增长，衍生服务快速发展

3.电商服务业发展趋势

（1）在线商业服务生态将成为现代服务业核心

（2）平台模式将成为在线商业服务生态共识

（3）技术创新仍将继续快速推动服务生态创新
