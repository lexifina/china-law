# 临沂市人民政府办公室关于公布临沂市市级第二批“零跑腿”和“只跑一次”事项清单的通知

临沂市人民政府办公室

关于公布临沂市市级第二批“零跑腿”和“只跑一次”事项清单的通知

临政办字〔2017〕192号

各县区人民政府，市政府各部门、各直属机构，临沂高新技术产业开发区管委会，临沂经济技术开发区管委会，临沂临港经济开发区管委会，临沂商城管委会，临沂蒙山旅游度假区管委会，临沂综合保税区管委会，各县级事业单位，各高等院校：

为进一步推进政府职能转变，根据《临沂市深化放管服改革进一步优化政务环境工作方案》（临办发〔2017〕21号），现公布我市市级第二批“零跑腿”和“只跑一次”事项清单。市直有关部门单位要严格按照清单公布事项履行职责，精简办事程序、缩短办理时限，切实做到“零跑腿”或“只跑一次”，着力打造精简高效的政务生态。本通知印发之日起10个工作日内，要将两张清单分别在市政府门户网站、市政务服务中心网站、各部门单位网站公布。

附件：1.临沂市市级第二批“零跑腿”事项清单

2.临沂市市级第二批“只跑一次”事项清单

临沂市人民政府办公室

2017年12月29日
