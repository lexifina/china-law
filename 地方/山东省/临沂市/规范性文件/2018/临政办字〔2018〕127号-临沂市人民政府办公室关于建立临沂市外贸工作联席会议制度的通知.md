# 临沂市人民政府办公室关于建立临沂市外贸工作联席会议制度的通知

临政办字〔2018〕127号

各县区人民政府，市政府各部门、各直属机构，临沂高新技术产业开发区管委会，临沂经济技术开发区管委会，临沂临港经济开发区管委会，临沂商城管委会，临沂蒙山旅游度假区管委会，临沂综合保税区管委会，各县级事业单位，各高等院校：

为推动我市外贸高质量发展，提升贸易便利化水平，培育外贸竞争新优势，市政府确定建立临沂市外贸工作联席会议制度。现将有关事项通知如下：

一、主要职能

在市委、市政府领导下，研究部署、统筹指导我市外贸工作。围绕推动外贸高质量发展，加强外贸形势研判，根据国际市场变化，及时提出应对策略；加强对贸易便利化工作的宏观指导，研究提出贸易便利化政策,落实上级出台的各项措施；优化外贸环境，培育外贸新生态，及时协调解决外贸工作中遇到的重大问题，推动我市外贸工作不断开创新局面；及时完成市委、市政府交办的其他事项。

二、组成单位

联席会议由市发改委、公安局、财政局、交通运输局、农业局、商务局、环保局、林业局、食药监局、法制办、税务局、贸促会、人民银行临沂市中心支行、临沂海关、邮政管理局、临沂商城管委会、临沂综合保税区组成。

三、议事规则

联席会议由市委常委、常务副市长侯晓滨同志担任总召集人，市政府办公室副主任刘恩田同志和市商务局局长吴昌力同志担任召集人，其他成员单位分管负责同志为联席会议成员（名单附后）。联席会议办公室设在市商务局，承担联席会议日常工作，市商务局副局长郭效武同志兼任办公室主任。联席会议设联络员，由各成员单位有关科室负责同志担任。根据工作需要，联席会议可邀请其他相关部门参加。联席会议成员因工作变动需要调整的，由所在单位提出，联席会议确定。

联席会议原则上在每季度结束后的当月20日左右召开，由总召集人或召集人主持。成员单位根据工作需要可提出召开会议的建议。在联席会议之前，召开联络员会议，研究讨论联席会议议题和需提交联席会议议定的事项。联席会议以纪要形式明确议定事项，印发有关部门和单位并抄报市委、市政府。

四、工作要求

联席会议办公室要及时向各成员单位通报情况，各成员单位要按照职责分工，深入研究我市外贸事业发展中遇到的重大问题，制定配套政策措施，提出意见建议，认真落实联席会议确定的工作任务和议定事项。要充分发挥联席会议作用，加强沟通、密切配合，科学研判进出口形势，根据国际市场变化，及时提出应对策略，推动全市外贸工作再上新水平。
