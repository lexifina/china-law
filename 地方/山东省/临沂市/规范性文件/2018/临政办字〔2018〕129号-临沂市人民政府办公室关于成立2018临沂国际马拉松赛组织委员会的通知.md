# 临沂市人民政府办公室关于成立2018临沂国际马拉松赛组织委员会的通知

临政办字〔2018〕129号

各县区人民政府，市政府各部门、各直属机构，临沂高新技术产业开发区管委会，临沂经济技术开发区管委会，临沂临港经济开发区管委会，临沂商城管委会，临沂蒙山旅游度假区管委会，临沂综合保税区管委会，各县级事业单位，各高等院校：

为丰富群众体育文化生活，推动全民健身活动深入开展，进一步展现“大美新”临沂形象，提高城市知名度和影响力，经报请国家体育总局批准，定于2018 年10月21日举办临沂国际马拉松赛。为加强赛事筹备工作的组织领导，经研究，决定成立2018 临沂国际马拉松赛组织委员会。现将组成人员名单公布如下：
