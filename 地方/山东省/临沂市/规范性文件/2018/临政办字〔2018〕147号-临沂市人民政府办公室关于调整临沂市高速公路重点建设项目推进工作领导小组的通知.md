# 临沂市人民政府办公室关于调整临沂市高速公路重点建设项目推进工作领导小组的通知

临政办字〔2018〕147号

各县区人民政府，市政府各部门、各直属机构，临沂高新技术产业开发区管委会，临沂经济技术开发区管委会，临沂临港经济开发区管委会，临沂商城管委会，临沂蒙山旅游度假区管委会，临沂综合保税区管委会，各县级事业单位，各高等院校：

为加快推进京沪高速公路莱芜至临沂（鲁苏界）段改扩建、岚山至罗庄高速公路、新泰至台儿庄（鲁苏界）高速公路、张店至临沂高速公路、董家口至梁山（鲁豫界）高速公路临沂段等工程项目建设，根据工作需要，确定对临沂市高速公路重点建设项目推进工作领导小组进行调整。现将调整后的组成人员名单公布如下：
