# 临沂市人民政府办公室关于成立临沂市实施标准化战略领导小组的通知

临政办字〔2018〕159号

各县区人民政府，市政府各部门、各直属机构，临沂高新技术产业开发区管委会，临沂经济技术开发区管委会，临沂临港经济开发区管委会，临沂商城管委会，临沂蒙山旅游度假区管委会，临沂综合保税区管委会，各县级事业单位，各高等院校：

为深入贯彻党的十九大精神，认真实施标准化战略，全面落实《山东省人民政府关于开展国家标准化综合改革试点工作的实施方案》，发挥标准化在打造沂蒙红色文化高地、乡村振兴沂蒙样板、新旧动能转换、“放管服”改革等重大工作中的基础性、战略性、引领性作用，市政府决定成立临沂市实施标准化战略领导小组。现将领导小组组成人员名单公布如下：

领导小组负责统筹推进各领域标准化工作改革；研究推进实施标准化战略，制定重大规划、政策；定期召开会议，协调解决标准化工作中的重大问题；促进工作落实，加强督促检查。

领导小组办公室设在市质监局，承担领导小组日常工作。黄杰同志兼任办公室主任，杨宗瑞、张春腾同志兼任办公室副主任。
