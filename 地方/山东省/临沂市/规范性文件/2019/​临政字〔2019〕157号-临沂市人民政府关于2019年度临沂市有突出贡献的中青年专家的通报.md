# 临沂市人民政府关于2019年度临沂市有突出贡献的中青年专家的通报

临政字〔2019〕157号

各县区人民政府，市政府各部门、各直属机构，临沂高新技术产业开发区管委会，临沂经济技术开发区管委会，临沂临港经济开发区管委会，临沂商城管委会，临沂蒙山旅游度假区管委会，临沂综合保税区管委会，各县级事业单位，各高等院校：

今年以来，全市各级、各部门深入学习贯彻习近平新时代中国特色社会主义思想，紧紧围绕市委、市政府决策部署，坚持新发展理念，大力实施创新驱动和人才强市战略，努力营造尊重人才、鼓励人才干事创业的良好氛围，培养造就了一大批优秀专业技术人才，为全市加快新旧动能转换、实现高质量发展做出了突出贡献。根据《临沂市人民政府办公室关于印发临沂市有突出贡献的中青年专家选拔管理办法的通知》（临政办发〔2018〕25号）要求，经个人申报、逐级推荐、集中评审、公示考察等程序，市政府确定授予王青华等20名同志2019年度“临沂市有突出贡献的中青年专家”荣誉称号。

希望获得荣誉称号的中青年专家珍惜荣誉，再接再厉，再立新功。各级、各部门要进一步解放思想，抓好以高层次人才为重点的各类人才队伍建设，为全市经济社会发展提供强有力的人才保障和智力支撑。全市广大专业技术人员要以受表彰的中青年专家为榜样，见贤思齐，开拓进取，牢记使命，奋力赶超，进一步提高科学研究水平和社会服务能力，为新时代大美新临沂建设作出更大贡献。
