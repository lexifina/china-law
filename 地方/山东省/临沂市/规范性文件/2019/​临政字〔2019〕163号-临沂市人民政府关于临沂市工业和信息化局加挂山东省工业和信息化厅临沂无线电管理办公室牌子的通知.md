# 临沂市人民政府关于临沂市工业和信息化局加挂山东省工业和信息化厅临沂无线电管理办公室牌子的通知

临沂市人民政府

关于临沂市工业和信息化局加挂山东省工业和信息化厅临沂无线电管理办公室牌子的通知

临政字〔2019〕163号

各县区人民政府，市政府各部门、各直属机构，临沂高新技术产业开发区管委会，临沂经济技术开发区管委会，临沂临港经济开发区管委会，临沂商城管委会，临沂蒙山旅游度假区管委会，临沂综合保税区管委会，各县级事业单位，各高等院校：

为贯彻落实《中华人民共和国无线电管理条例》，进一步做好无线电管理工作，按照《中共山东省委机构编制委员会办公室关于市工业和信息化部门加挂山东省工业和信息化厅xx无线电管理办公室牌子的通知》（鲁编办〔2019〕186号）要求，在市工业和信息化局加挂山东省工业和信息化厅临沂无线电管理办公室牌子，作为省工业和信息化厅派出机构，根据省工业和信息化厅授权在我市行政区域内依法履行无线电管理职责，接受省工业和信息化厅业务指导和监督。

临沂市人民政府

2019年11月25日
