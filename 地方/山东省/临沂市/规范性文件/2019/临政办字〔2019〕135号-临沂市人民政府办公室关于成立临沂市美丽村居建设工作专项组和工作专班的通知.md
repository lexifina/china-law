# 临沂市人民政府办公室关于成立临沂市美丽村居建设工作专项组和工作专班的通知

临沂市人民政府办公室

关于成立临沂市美丽村居建设工作专项组和工作专班的通知

临政办字〔2019〕135号

各县区人民政府，市政府各部门、各直属机构，临沂高新技术产业开发区管委会，临沂经济技术开发区管委会，临沂临港经济开发区管委会，临沂商城管委会，临沂蒙山旅游度假区管委会，临沂综合保税区管委会，各县级事业单位，各高等院校：

为加强对全市美丽村居建设工作的组织领导，市政府决定成立临沂市美丽村居建设工作专项组，负责美丽村居建设工作统筹协调、整体推进和督导落实；成立美丽村居建设工作专班，负责工作调度推动，及时协调解决推进过程中遇到的问题。现将专项组和工作专班成员名单公布如下：

一、美丽村居建设工作专项组成员名单

组 长：侯晓滨 市委常委、常务副市长

成 员：周俊献 市政府办公室副主任

张 韬 市农业农村局局长

曹首娟 市文化和旅游局局长

二、美丽村居建设工作专班成员名单

成 员：唐桂武 市发改委二级调研员

陈常密 市文化和旅游局二级调研员

专项组下设推进办公室，推进办公室设在市住建局，由市住建局分管负责同志任推进办公室主任，抽调专人集中办公。

专项组不刻制印章，不对外正式行文。专项组、工作专班成员职务如有变动，由该成员单位接任负责同志自然替补，并由推进办公室负责通知。
