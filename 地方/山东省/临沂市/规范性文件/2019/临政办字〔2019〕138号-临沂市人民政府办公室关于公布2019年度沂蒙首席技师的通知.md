# 临沂市人民政府办公室关于公布2019年度沂蒙首席技师的通知

临政办字〔2019〕138号

各县区人民政府，市政府各部门、各直属机构，临沂高新技术产业开发区管委会，临沂经济技术开发区管委会，临沂临港经济开发区管委会，临沂商城管委会，临沂蒙山旅游度假区管委会，临沂综合保税区管委会，各县级事业单位，各高等院校：

根据《沂蒙首席技师选拔管理办法》（临政办发〔2017〕21号）有关规定，经市首席技师评审委员会评审、考察、公示等程序，王建强等41名同志被评为2019年度沂蒙首席技师，现予以公布。
