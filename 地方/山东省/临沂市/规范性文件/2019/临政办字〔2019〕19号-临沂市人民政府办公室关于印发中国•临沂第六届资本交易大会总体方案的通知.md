# 临沂市人民政府办公室关于印发中国•临沂第六届资本交易大会总体方案的通知

临政办字〔2019〕19号

各县区人民政府，市政府各部门、各直属机构，临沂高新技术产业开发区管委会，临沂经济技术开发区管委会，临沂临港经济开发区管委会，临沂商城管委会，蒙山旅游度假区管委会，临沂综合保税区管委会，各县级事业单位，各高等院校：

现将《中国•临沂第六届资本交易大会总体方案》印发给你们，请认真组织实施。

临沂市人民政府办公室

2019年3月21日

（此件公开发布）

中国•临沂第六届资本交易大会总体方案

为做好中国•临沂第六届资本交易大会筹备工作，特制定本方案。

一、会议名称、指导思想

会议名称：中国•临沂第六届资本交易大会

指导思想：以习近平新时代中国特色社会主义思想为指导，深入贯彻党的十九大和中央、省、市经济工作会议精神，以供给侧结构性改革为主线，以“聚集金融资源，推进产融结合”为主题，宣传推介临沂经济金融发展优势，搭建金融资本与实体经济交流合作的平台，助力全市经济实现高质量发展。

二、会议时间、地点

会议报到时间：2019年4月15日（星期一）

开幕式时间：2019年4月16日（星期二）

专题活动时间：2019年4月16日-18日

举办地点：开幕式、展区设在临沂国际博览中心，专题活动地点设在蓝海国际饭店沂河店。
