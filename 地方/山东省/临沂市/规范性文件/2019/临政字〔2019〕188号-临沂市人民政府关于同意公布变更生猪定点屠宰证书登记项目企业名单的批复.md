# 临沂市人民政府关于同意公布变更生猪定点屠宰证书登记项目企业名单的批复

临沂市人民政府

关于同意公布变更生猪定点屠宰证书登记项目企业名单的批复

临政字〔2019〕188号

市行政审批服务局：

你单位《临沂市行政审批服务局关于公布变更生猪定点屠宰证书登记项目企业名单的请示》（临审服报〔2019〕236号）收悉。经研究，批复如下：

同意你单位提出的意见，准予山东蒙山食品有限公司仲村分公司等5家生猪定点屠宰企业变更生猪定点屠宰证书登记项目。你单位要积极会同有关部门，按照《生猪屠宰管理条例》等有关规定，认真履行职责，做好审批与监管衔接工作。
