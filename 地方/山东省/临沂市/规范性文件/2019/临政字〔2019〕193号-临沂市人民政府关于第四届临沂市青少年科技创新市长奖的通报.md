# 临沂市人民政府关于第四届临沂市青少年科技创新市长奖的通报

临政字〔2019〕193号

各县区人民政府，市政府各部门、各直属机构，临沂高新技术产业开发区管委会，临沂经济技术开发区管委会，临沂临港经济开发区管委会，临沂商城管委会，临沂蒙山旅游度假区管委会，临沂综合保税区管委会，各县级事业单位，各高等院校:

为贯彻落实《中华人民共和国科学技术普及法》和《全民科学素质行动计划纲要》，增强青少年科技创新能力，提高青少年科学文化素质，鼓励在青少年科技创新活动中表现杰出的中小学生，根据《临沂市青少年科技创新市长奖评选办法》，经临沂市青少年科技创新市长奖评审委员会审议，市政府决定，授予张知新等10名同学“第四届临沂市青少年科技创新市长奖”，授予马瑞麟等10名同学“第四届临沂市青少年科技创新提名奖”，授予高远等10名辅导教师“第四届临沂市青少年科技创新培育奖”，授予山东省临沂第一中学等6所学校“第四届临沂市青少年科技创新组织奖”。

希望获奖单位和个人珍惜荣誉，再接再厉，不断探索创新，提高科学素养，争创更高层次的科技发明。各级各部门、单位和全市科技工作者要大力弘扬科学精神，传播科学思想，倡导科学方法，营造良好氛围，支持关注青少年科技创新活动，为建设创新型社会作出更大贡献。
