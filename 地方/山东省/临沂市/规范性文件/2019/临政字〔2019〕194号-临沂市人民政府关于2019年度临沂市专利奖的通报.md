# 临沂市人民政府关于2019年度临沂市专利奖的通报

临政字〔2019〕194号

各县区人民政府，市政府各部门、各直属机构，临沂高新技术产业开发区管委会，临沂经济技术开发区管委会，临沂临港经济开发区管委会，临沂商城管委会，临沂蒙山旅游度假区管委会，临沂综合保税区管委会，各县级事业单位，各高等院校：

为深入贯彻习近平新时代中国特色社会主义思想，大力实施创新驱动发展战略，加快推进新旧动能转换重大工程，进一步提高知识产权助推产业优化升级水平，根据《临沂市专利奖励办法》规定，经市专利奖评审委员会审议，市政府决定，授予“一种头孢替唑钠化合物及含有该化合物的药物制剂”等5项专利临沂市专利奖一等奖；授予“一种基于计算机视觉的物流仓储监控方法”等10项专利临沂市专利奖二等奖；授予“电感线圈自动焊锡、测试一体机及其工作方法”等24项专利临沂市专利奖三等奖。

希望获奖单位和个人珍惜荣誉，积极创新，再接再厉，再创佳绩。全市各级各有关部门和广大知识产权工作者要以先进为榜样，大力发扬求真务实、开拓创新的精神，不断进行技术创新，加速专利技术成果转化，增强产业核心竞争力，为大美新临沂建设作出更大贡献。
