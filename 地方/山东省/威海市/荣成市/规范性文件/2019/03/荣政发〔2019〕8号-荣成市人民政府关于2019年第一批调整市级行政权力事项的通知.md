# 荣成市人民政府关于2019年第一批调整市级行政权力事项的通知

荣政发〔2019〕8号

经济开发区、石岛管理区、好运角旅游度假区管委会，各镇人民政府，各街道办事处，市政府各部门、单位，市重点企业、成长型企业：

为认真落实《山东省人民政府关于取消下放一批省级行政许可等事项的通知》（鲁政发〔2018〕35号）文件精神，深化“一次办好”改革，持续推进简政放权，根据法律法规规章修改情况，结合实际，对我市市级行政权力事项进行调整，取消市级行政权力等事项3项，其中涉及证明事项1项；承接上级决定下放管理层级或委托实施行政权力事项7项。现将相关目录予以公布，并提出如下要求：

一、由市委编办负责，自本通知下发之日起5个工作日内，将修订后的市级行政许可事项目录和行政权力清单在荣成市政府网站公开，并对事项衔接落实情况进行跟踪督导。

二、市政府有关部门、单位自本通知下发之日起10个工作日内调整进驻市政务服务中心事项和山东政务服务网（荣成）公示事项，对取消的行政许可等事项要制定事中事后监管细则。涉及第二批“全链条”审批事项的部门、单位，要编制“全链条”办理流程图、调整服务指南并及时向社会公布。
