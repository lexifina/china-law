# 泰政办字〔2019〕9号泰安市人民政府办公室关于统筹发展全市欧亚班列工作的通知

各县、市、区人民政府，市政府有关部门、直属单位，省属以上驻泰有关单位：

为加快推动全市欧亚班列持续稳定发展，根据《山东省人民政府关于推动全省欧亚班列统筹发展的实施意见》（鲁政字〔2018〕271号）精神，结合我市实际，现就有关事项通知如下：

一、强化货源组织。加强调查研究，摸清和分析我市重点企业与“一带一路”沿线国家和地区对外贸易情况，根据货源规模、商品结构、货物品种、运输条件、时限要求、企业性质、产地区域和所在国规定等，研究制定符合我市实际的集货方案。引导优势企业不断完善和加强内部控制管理，提升外贸商品质量；深度参与“一带一路”建设，积极扩大对外贸易，实现企业转型升级和品牌价值提升。加强宣传推介，充分利用各种媒体渠道，提升欧亚班列的知晓率和影响力，引导和支持外经外贸、商贸流通企业积极参与境内外商务展会、论坛、庆典活动，着力开拓海外市场，做好欧亚班列货源组织。（市商务局、市发展改革委牵头负责）

二、强化资金支持。严格落实省欧亚班列培育期综合奖补政策，精准、及时对我市欧亚班列货主和货源组织方给予政策性奖补。采取贷款贴息、事后奖补、经费补助、增值税减免等方式，加大对欧亚班列货源企业仓储、物流等集货设施建设的财政支持力度。支持企业灵活利用政策性金融机构融资，建设海外仓等基础设施。引导企业使用人民币结算工具，主动降低交易成本和汇率风险。支持企业扩大信用类债券发行规模，通过发行债券置换高成本融资或用长期债券置换短期债券等形式，降低融资成本。发挥银保合力，创新金融产品和服务，为货源企业提供银行优惠利率贷款。支持银行多渠道打包转让不良资产，稳妥推进市场化法制化债转股，防范和化解金融风险。（市财政局、市地方金融监管局牵头负责）

三、强化综合服务。配合省级运营主体，认真研究中国铁路总公司“量价捆绑”政策及沿线国家运价政策规定，准确掌握国内外相关政策变化和市场价格动态，做好运价优惠方案优化和争取工作，最大限度降低企业运输成本，打造竞争优势。积极争取海关支持，针对我市欧亚班列进出口商品，实施差异化检验监管措施，最大限度精简单证，减少现场检验频次及项目，做到精准抽批、精准检测，进一步提高检验放行效率。深化与班列国内沿线各海关和口岸海关的通关协调机制，协助解决货物通关问题，采取联合检疫等便利化通关措施，简化协调海关手续。探索开展“智慧监管”建设，推动海关、港口、铁路、多式联运中心、联运经营人等多方信息联网，提供全程可视化、智能化的多式联运监管服务，确保进出口集装箱运输安全可靠高效。（市交通运输局、泰安海关牵头负责）

四、强化机制保障。各县（市、区）、各有关部门要认真落实责任分工，切实加强信息共享共用，密切协作配合，及时研究解决我市欧亚班列发展中的突出矛盾和问题，扎实做好各项工作。要积极对接上级单位，尤其要注重强化与省欧亚班列运营平台、中国铁路济南局及中铁集济南分公司的有效沟通交流，不断加大对上争取力度。市发展改革委要按照省欧亚班列财政资金和运营管理绩效考核机制要求，不定期开展监督检查和审计督导，推动我市欧亚班列统筹发展。（市发展改革委牵头负责）
