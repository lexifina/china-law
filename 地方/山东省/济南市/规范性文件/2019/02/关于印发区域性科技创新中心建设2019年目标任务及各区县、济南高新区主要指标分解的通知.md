# 关于印发区域性科技创新中心建设2019年目标任务及各区县、济南高新区主要指标分解的通知

区县科技局、济南高新区科经局，市科技局机关各处室、局属各单位：

为加快建设“大强美富通”现代化国际大都市，深入推进区域性科技创新中心建设，根据《2019年政府工作报告》重点工作责任分工，现对区域性科技创新中心建设2019年目标任务进行调整分解，望认真组织落实，确保完成年度目标任务。

各区县、济南高新区要紧紧围绕全市区域性科技创新中心建设目标任务，结合各自实际，抓重点，解难点，出亮点，努力取得一批突出成果。

市科技局各责任处室（单位）要按照分工研究制定具体落实措施，加强与相关部门和区县的沟通协调，形成推进合力，狠抓工作落实，确保各项任务圆满完成。

各区县科技局、济南高新区科经局于每季度首月10日前将上季度科技创新中心建设工作完成情况报送至市科技局创新协调督导处；市科技局各责任处室（单位）于每月10日前将上月目标任务完成情况，经分管领导签字后报送至市科技局创新协调督导处（同时将电子版发至kjjxtddc@jn.shandong.cn）。
