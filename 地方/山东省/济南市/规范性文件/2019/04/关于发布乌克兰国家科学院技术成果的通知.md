# 关于发布乌克兰国家科学院技术成果的通知

各区县科技局、济南高新区科经局、莱芜高新区企业服务局，市直有关部门，有关单位：

根据省科技厅工作安排，近期省科技厅将与乌克兰国家科学院开展技术成果对接活动，现面向全市企事业单位发布乌克兰国家科学院部分技术成果目录，请各主管部门积极组织企业进行研究和梳理，寻找挖掘合作项目，推动我市国际科技合作工作不断深入。
