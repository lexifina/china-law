# 关于实施2018年度全市科普统计调查工作的通知

各区县科技主管部门、市直有关部门：

根据《科技部关于实施2018年度全国科普统计调查工作的通知》（国科发智〔2019〕131号）和省科技厅有关要求，为组织实施好2018年度济南市科普统计工作，现就有关事项通知如下：

一、提高认识，加强组织领导。科普统计是国家科技统计的重要组成部分，是推动科普事业健康发展的一项基础性工作。各市科技局和市直有关部门要高度重视，将科普统计工作作为一项重要任务，落实保障条件，组织专门力量，集中推进调查工作，确保2018年度科普统计任务顺利完成。

二、认真组织，高质量完成统计调查任务。为切实做好此项统计工作，市科技局制定了《2018年度济南市科普统计调查方案》（附件1），请根据调查方案的具体要求，统筹安排，认真组织落实。要认真总结2017年度科普统计调查工作经验，从覆盖面和数据准确性等方面不断提高统计调查质量。

三、按照进度要求及时报送统计数据。全市科普统计调查具体业务工作由市科技局引进智力与出国培训管理处（科技人才工作处）组织实施。请各区县科技主管部门和市直有关部门按要求在线填报，并填写《2018年度科普统计调查表》（附件2）和《2018年度科普统计填报单位目录清单》（附件3），于2019年5月27日17时前，完成科普统计填报工作。

请各区县科技主管部门、市直有关部门于2019年5月17日17时前，将《科普统计联络员回执表》（附件4）电子版，报送市科技局引进智力与出国培训管理处（科技人才工作处）。此次机构改革中组建和职责优化的单位，由现承担相应职能的单位负责填报（详见附件1）。
