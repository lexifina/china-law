# 关于转发省科技厅《关于组织推荐新建山东省技术创新中心的通知》通知

各区县科技主管部门、有关部门：

现将省科技厅《关于组织推荐新建山东省技术创新中心的通知》转发给你们。请按照通知要求组织实施。相关要求如下。

1.从国家工程技术研究中心、省示范工程技术研究中心中遴选，支持其转建省技术创新中心，为争取建设国家技术创新中心奠定基础；

2.支持具有优势的行业龙头企业、平台型公司、科研院所、高等学校等牵头建设省技术创新中心，要具有广泛联合“政产学研金服用”各方、整合创新资源、形成创新合作网络、组织实施重大科技创新任务的优势和能力。

3.各区县科技主管部门根据工作实际，结合本区县建设“政产学研金服用”创新创业共同体和产业技术研究院的规划布局，立足优势特色产业，按照《山东省技术创新中心管理办法》（鲁科字〔2017〕167号）的规定，择优推荐拟转建或新建的省技术创新中心，并组织有关单位编制省技术创新中心建设方案（编写提纲见附件1和2）；

4.请各区县科技主管部门对建设方案进行审核把关并统一出具推荐函（附件3），于2019年5月16日下班前，将建设方案（纸质版装订一式5份，电子版刻光盘1份）、推荐函和汇总表（附件4）各1份报送到龙奥大厦F802室，收件人：王磊，电话：0531-66608803。

咨询方式：省科技厅资源配置处，0531-66777171
