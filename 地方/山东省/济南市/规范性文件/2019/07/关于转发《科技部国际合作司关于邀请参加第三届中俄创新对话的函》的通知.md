# 关于转发《科技部国际合作司关于邀请参加第三届中俄创新对话的函》的通知

各区县科技局：

中国科技部与俄罗斯经济发展部拟于2019 年9月25-26日在上海共同举办“第三届中俄创新对话”，现将《科技部国际合作司关于邀请参加第三届中俄创新对话的函》转发给您们，“第三届中俄创新对话”具体活动内容详见附件。请以各区县为单位，将有意参加该活动单位的报名回执(函件中附件2）汇总后于8月10日下午5点前提报市科技局邮箱jiyuan@jn.shandong.cn.
