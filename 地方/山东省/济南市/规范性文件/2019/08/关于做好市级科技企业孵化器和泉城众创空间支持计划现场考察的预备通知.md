# 关于做好市级科技企业孵化器和泉城众创空间支持计划现场考察的预备通知

各区（县、功能区）科技主管部门：

为做好市级科技企业孵化器和泉城众创空间支持计划现场考察工作，根据《济南市科技企业孵化器认定和管理办法》（济科发【2017】38号）、《济南市科学技术局关于支持泉城众创空间发展的实施意见（试行）》（济科发【2018】55号）有关规定，并经局领导研究同意，现就现场考察有关事项通知如下：

一、考察专家

考察组由5名专家组成，其中从事孵化器或众创空间管理工作的专家4名、创投专家1名。

二、考察方法

现场考察组通过听汇报、看现场、查阅资料等相结合的方式，对辖区内申报的市级科技企业孵化器和众创空间一并进行现场考察。

三、考察要求

（一）省属以上高校院所申报的众创空间支持计划和“中小学创客空间”按照属地管理原则，纳入所在区（县、功能区）进行考察。

（二）现场考察前，各区（县、功能区）科技主管部门会同财政部门在考察初审的基础上，联合出具书面推荐函（一式四份），分别报市科技局、市财政局。

（三）市级科技企业孵化器和泉城众创空间支持计划申报单位要提前准备好书面申报材料（一式五份，装订成册，申报材料有关内容要与系统材料一致），用于现场考察打分。

（四）在现场考察过程中，对存在以下几种情况的实行一票否决，取消参评资格：1、对查实的提供数据不真实，涉嫌伪造虚假数据的；2、对提供材料中重要指标项表述不清或有缺失影响正式合同考核签订的；3、对存在人去楼空、改头换面、现场造假等严重问题的；4、同一运营单位名下的孵化器和众创空间在孵（入驻）企业重复或场所一致的。

（五）邀请市纪委派驻科技局第八纪检组、市财政局各1名同志参加现场考察，进行全程监督。

（六）各区（县、功能区）科技主管部门要提前安排好考察路线和时间节点，保证现场考察如期顺利进行，具体考察时间另行通知。
