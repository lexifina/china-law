# 关于紧急调度各区县与全国知名高校院所合作项目进展情况的通知

各区县科技局：

根据工作安排，近期市政府将组织召开关于我市与全国知名科研院所合作项目专题会议，调度项目进展情况，研究解决有关问题，加快项目落地，推进项目建设。

请各区县认真梳理本单位2018年以来与国内知名大院、大所、大学签约及对接洽谈情况，现阶段项目进展情况，以及存在的问题与困难。主要包括：1.2018年以来，已经签约落地的合作项目。2.2018年至今，正在洽谈拟签约落地的合作项目。请各区县认真填写济南市与重点科研院签约合作情况调查表（附件1、2），并加盖公章，于9月25日（星期三）下午5点前报市科技局。
