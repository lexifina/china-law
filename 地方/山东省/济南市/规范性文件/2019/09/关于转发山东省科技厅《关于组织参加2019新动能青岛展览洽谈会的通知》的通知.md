# 关于转发山东省科技厅《关于组织参加2019新动能青岛展览洽谈会的通知》的通知

各区县科技局、高新区科经局：

山东省政府定于2019年10月19日-21日，在青岛举办“跨国公司领导人青岛峰会”期间，在青岛同时举办“2019新动能 青岛展览洽谈会”。根据省科技厅要求，现将《关于组织参加2019新动能 青岛展览洽谈会的通知》转发给您们，具体活动内容及安排详见通知。请以各区县为单位，将有意参加该活动单位的报名回执(附件2）汇总后于9月10日下午5点前发送至市科技局邮箱。
