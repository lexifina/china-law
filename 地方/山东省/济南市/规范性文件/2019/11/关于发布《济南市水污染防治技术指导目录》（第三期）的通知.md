# 关于发布《济南市水污染防治技术指导目录》（第三期）的通知

各有关单位：

为深入贯彻济南市人民政府关于《济南市落实水污染防治行动计划实施方案》（济政发〔2016〕17号）和《济南市全面实行河长制工作方案》（济厅字〔2017〕16号）要求，积极为打好饮用水水源水质保护攻坚战、黑臭水体治理攻坚战提供科技支撑，加快推动节水用水、治污排污、水生态修复、河湖湾泊污染防治等领域先进适用技术推广应用，我们面向全市公开征集了水污染防治相关技术成果，并组织行业专家进行了评估论证，编制形成了《济南市水污染防治技术指导目录》（第三期）。

现予发布，供参考。

济南市科学技术局

2019 年11月19日
