# 关于金种子券申领截止时间的通知

各区、县科技局，高新区科经局，有关单位：

根据科技计划年度安排和创新券申领有关规定，2018年申报过金种子科技计划的企业、单位，需尽快登录济南市中小微企业创新券管理平台申领金种子创新券，发放时间截止到2019年11月6日下午5点前，请各单位做好相关通知、申领工作，逾期系统自动关闭，未申领创新券的企业、单位将视为自动放弃。
