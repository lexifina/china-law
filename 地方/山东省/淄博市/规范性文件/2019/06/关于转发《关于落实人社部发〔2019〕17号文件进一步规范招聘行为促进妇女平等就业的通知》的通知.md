# 关于转发《关于落实人社部发〔2019〕17号文件进一步规范招聘行为促进妇女平等就业的通知》的通知

各区县人力资源社会保障局、教育体育局、司法局、卫生健康局、国资委、医保分局、总工会、妇联、人民法院，高新区、经济开发区、文昌湖区组织人事部、人力资源社会保障局、地事局、总工会、人民法院，市就业服务中心，市各经营性人力资源服务机构：

现将省人力资源社会保障厅等9部门《关于落实人社部发〔2019〕17号文件进一步规范招聘行为促进妇女平等就业的通知》（鲁人社字〔2019〕96号）转发给你们，并提出以下意见，请认真贯彻落实。

各区县人力资源社会保障、妇联、工会等部门要建立联合约谈工作机制，及时受理招聘过程中的各类性别歧视举报投诉，促进妇女平等就业；人民法院要依法受理妇女就业性别歧视相关诉讼，通过判决使实施就业性别歧视的单位承担民事责任，为符合条件的遭受就业性别歧视的妇女提供司法救济；司法行政部门要充分发挥妇女维权法律服务团的作用，积极为遭受就业性别歧祝的妇女提供法律服务；国有资产监督管理部门要加强对各级各类国有企业招聘行为的监督与指导；工会、妇联组织要积极为遭受就业性别歧视的妇女提供法律咨询等服务，支持向人民法院提起诉讼，协调相关部门提供必要的法律政策援助；卫生健康、医疗保障等部门要完善落实生育保险制度，按照国家统一部署要求，推进生育保险和职工基本医疗保险合并实施，保障女职工生育保险待遇；教育部门要按照有关政策，积极做好中小学课后服务。

各级公共就业服务机构、各经营性人力资源服务机构要建立解决就业性别歧视工作机制，在招聘条件和发布的招聘信息中不得含有性别歧视内容，切实保障妇女平等就业的权力。
