# 烟城〔2019〕23号：关于加强市区纳管企业排水监管工作的实施意见

芝罘区、福山区、莱山区、牟平区、开发区、高新区综合行政执法局，高新区住建局，市排水服务中心：

现将《关于加强市区纳管企业排水监管工作的实施意见》印发给你们，请认真贯彻执行。

烟台市城市管理局

2019年4月22日

关于加强市区纳管企业排水监管工作

的实施意见

为加强市区纳管企业排水监管，保障城市排水与污水处理设施安全运行，按照《山东省打好渤海区域环境综合治理攻坚战作战方案》要求，依据《城镇排水与污水处理条例》(国务院令第641号)、《城镇污水排入排水管网许可管理办法》(住房和城乡建设部令第 21号)，制定如下意见：

一、总体要求

按照“统筹部署、属地管理”的原则，市城市排水主管部门负责市区纳管企业排水监管工作的行业指导，委托有关机构对市级管理的污水处理厂进水水质和各区排水管网总口进行水质监测，并对市级污水处理厂服务范围内重点纳管企业排水水质进行抽查；市城市管理行政执法部门负责对各区违规排水行为查处工作的业务指导、监督检查和考核。各区城市排水主管部门负责本行政区域内纳管企业排水行为的具体监管工作（其中芝罘区范围内直接接入市级管网的纳管企业排水行为由市城市排水服务中心监管）；各区城市管理行政执法部门负责对辖区内违规排水行为查处工作。

二、工作部署

（一）建立排水管网水质超标通报、排查制度。市城市排水主管部门在各区排水管网总口安装在线监测设备（各区排水管网总口水质监测情况见附件），对各区进入市级管理的套子湾、辛安河、南郊污水处理厂的水质和水量进行在线监测，并委托排水监测机构对各区排水总口进行取样检测，对各区排水管网总口的水质情况进行通报。各区城市排水主管部门要根据通报中水质超标情况进行排查，各区城市管理行政执法部门根据排查情况对违规排水行为进行查处。各区城市排水主管部门每月5日前将上月度排查及查处情况报市城市管理局。市城市管理行政执法部门对查处工作进行监督检查和考核。

牟平区、开发区要按规定对排入区级管理的污水处理厂排水管网总口水质进行定期监测，根据排水管网水质情况进行排查，做好排查、查处工作。

（二）加强对重点纳管企业排水监督管理。市城市排水主管部门委托排水监测机构定期对市级污水处理厂服务范围内重点纳管企业排水水质进行抽查，对抽查发现的违规排水行为下达核查通知，各区城市排水主管部门和城市管理行政执法部门要第一时间进行核查、查处，各区城市排水主管部门10个工作日内将核查、查处情况报市城市管理局。市城市管理行政执法部门对查处工作进行监督检查和考核。

各区城市排水主管部门要加强与所在区生态环境部门的联系沟通，摸清辖区内重点纳管企业的底数，建立完善排水档案，重点摸清可能排放重金属、酸碱等有毒有害废水以及难以生化降解污染物和高盐废水的纳管企业底数。制定年度监督计划，并委托有资质的监测机构定期进行监测。

（三）建立污水处理应急处置机制。市级污水处理厂遇到进水水质和水量发生重大变化可能导致出水水质超标，或者发生影响城镇污水处理设施安全运行的突发情况时，市城市排水主管部门启动应急处置机制，组织相关区城市排水主管部门开展排查。各区城市排水主管部门要会同所在区生态环境部门对重点排水企业、超标污染物涉及企业进行排查，期间每日上报排查情况和查处情况，直至进水水质和水量恢复正常，污水处理厂安全平稳运行。

牟平区、开发区要建立区级污水处理应急处置机制，确保区级污水处理厂安全运行。

（四）强化排水许可准入制度。各区城市排水主管部门要严格落实城镇污水排入排水管网许可管理办法，建立完善排水档案。新建工业企业排放的含重金属、难以生化降解污染物或高盐废水，不得接入城市生活污水处理设施；已运行的纳管企业，各区城市排水主管部门要会同生态环境部门责令限期退出。

三、考核奖惩

各区城市排水和城市管理行政执法部门要充分认识到纳管企业排水监管工作的重要性，要加强组织领导，明确工作责任，严格执行国家、省、市有关规定，确保纳管企业排水监管工作落地、落实。市城市管理局将各区对纳管企业排水的监管、查处工作纳入到年终评先评优，对不作为、不担当、推诿扯皮，严重影响城市排水及污水处理设施运行安全运行的，将根据有关规定上报移交，依法严肃追究相关单位和个人法律责任。
