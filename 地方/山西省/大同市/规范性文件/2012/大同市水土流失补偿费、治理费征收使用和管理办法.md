# 大同市水土流失补偿费、治理费征收使用和管理办法

依据《中华人民共和国水土保持法》和《山西省实施水土保持法办法》及山西省物价局、财政厅、水利厅发晋价涉字（1992）第59号《山西省水土流失补偿费、治理费的征收使用和管理办法》，结合我市实际情况制定本办法。

一、在我市境内从事采矿、采石（砂）、筑路、修建电厂水工建筑、冶炼、化工、炼制砖瓦（瓷器）、石灰等生产开发建设的单位和个人，都要按规定标准交纳水土流失补偿费，并对造成的水土流失按批准的方案进行治理，如不能或不便自行治理，经市、县（区）水土保持监督机构核准后，按规定交纳水土流失治理费，由水土保持部门统一安排治理。

二、水土流失补偿费、治理费的收缴权限；属国、部、省、市级性质的企业事业单位和军办事业单位，由市水土保持监督总站负责收缴；属县（区）及县（区）以下的企业事业单位和个人，由所在县（区）水保监督站负责收缴。

三、征收水土流失补偿费、治理费须持市、县（区）物价局颁发《收费许可证》，使用财政部门印制的行政事业统一收费收据。

四、水土流失补偿费和治理费的管理权限：

1、市收缴的水土流失补偿费，市留70%，上交省10%，返还所属县（区）20%；县（区）收缴的水土流失补偿费80%留县（区）使用，上交市10%，上交省10%，实行分级管理。

2、市收缴的水土流失治理费，由市安排治理；县（区）收缴的水土流失治理费由县（区）安排治理；实行分级管理。

五、水土流失补偿费、治理费属于预算外资金，实行财政专户储存，水保监督部门做出用款计划，财政审批，银行监督使用管理办法。本项资金作为水土保持专项基金，主要用于以下几个方面：

1、水土保持工程的建设，恢复和维修、养护，水土保持乔、灌、草的种植与补植。

2、水土流失监督监测人员的工资、补助，监督监测仪器设备，交通工具的购置和维修。

3、水土保持监督监测规划，勘测和设计。

4、水土保持宣传，培训和教育。

5、群众性的水土保持科学研究。

6、水土保持监督监测有功人员的奖励。

7、建立水土保持预防区、监督管理区、治理区、开发建设区。

8、该项资金的70%用于第一条，其余30%用于第2-7条。

六、收费标准：

1、水土保持补偿费根据生产建设占地面积、破坏面积、开垦五度以上荒地面积，破坏程度及企业性质，在倾斜平原、洪积扇群、冲湖积平原区，每平方米一次性交纳0.2-0.3元；在中低山区，丘陵区、隆起岗地、河谷阶地区每平方米一次性交纳0.3-0.4元。

2、工矿企业和从事采矿、采石（砂）、筑路、修建电厂、水工建筑、冶炼、化工、炼制砖瓦（瓷器）、石灰等单位和个人，对其造成的水土流失应积极治理，不能或不便自行治理的，应按下列标准交纳水土流失治理费。

1、采矿、筑路及其它有破坏地貌、植被行为的，按采挖面积和倾倒占地面积计算，在倾斜平原、洪积扇群、冲湖积平原区每平方米交纳0.3-0.4元；在中低山区、丘陵区、隆起岗地、河谷阶地区每平方米交纳0.4-0.5元。

2、弃土弃渣按实际排放量，在倾斜平原、洪积扇群、冲湖积平原区每立方米交纳2-3元；在中低山区，丘陵区、隆起岗地、河谷阶地区每立方米交纳3-5元；在中低山区、丘陵区、隆起岗地、河谷阶地区每立方米交纳3-5元。为方便起见，也可按照弃渣量折算的产品产量计收。

七、水土流失补偿费可委托有关银行和矿产收购有关部门代收，代收单位从中提取收费总额3%的手续费。

八、本办法由市物价局、市财政局、市水利局在各自职责范围内负责解释。

九、本办法自公布之日起执行。1993年4月1日大同市物价局、大同市财政局、大同市水利局公布的《大同市水土流失补偿费，治理费征收使用和管理办法》同时废止。
