# 大同市教育局“谁执法谁普法”普法责任制工作方案

为全面落实党的十八届四中全会关于实行国家机关“谁执法谁普法”普法责任制的要求，贯彻落实中共中央办公厅、国务院办公厅近日印发的《关于实行国家机关“谁执法谁普法”普法责任制的意见》，强化各级执法部门普法工作责任，提升普法工作实效性，进一步落实好“谁执法谁普法”普法责任制。根据山西省普法办关于报送落实《关于实行国家机关“谁执法、谁普法”普法责任制的意见》文件精神和要求，特制订此工作方案。

一、指导思想

以党的十八大和十八届三中、四中全会精神为指导，按照《中共中央关于全面推进依法治国若干重大问题的决定》提出的“实行国家机关‘谁执法谁普法’的普法责任制”和法治大同的要求，进一步强化部门普法工作责任，扎实推进全市普法工作深入开展，着力构建适应新形势、新任务发展要求的大普法工作格局，推动全社会树立法治意识，为全市经济社会发展营造良好的法治环境。

二、目标任务

认真学习贯彻党的十八大、十八届三中、四中、五中、六中全会和习近平总书记系列重要讲话精神以及中共中央办公厅、国务院办公厅近日印发的《关于实行国家机关“谁执法谁普法”普法责任制的意见》，围绕推进大同市教育系统内部法治化建设，抓好本部门、本系统、本行业内部的普法工作；围绕依法履行工作职能，向主管对象、执法对象、服务对象等宣传履行职能、职责的相关法律法规。

三、工作原则

一是日常工作和普法宣传相结合。将普法宣传教育渗透到日常工作的全过程，利用以案说法、以案普法、以案学法等方式普及法律常识，通过依法办事促进深度普法，通过广泛普法促进依法办事。

二是日常宣传和集中宣传相结合。在日常广泛开展法治宣传的同时，根据自身职能，结合特殊时段和节点，开展各类重点突出、针对性强的集中法治宣传活动，切实增强工作的实效性。

三是全局联动和各负其责相结合。强化各科室对各项工作中相关办事人员和办事单位的指导。落实“谁执法、谁普法”工作责任，强化监督考核，努力形成局党组领导、纪检监督、各科室、单位协作配合、全社会共同参与的教育法治宣传新格局。

四、重要举措

1.明确工作责任。我局在以局长为组长的普法工作领导小组领导下开展普法宣传工作，局长为第一责任人，分管领导及各科室、二级单位负责人为责任人，政策法规科负责日常工作。

2.制定工作计划。局机关和各直属单位需将普法工作纳入各自的年度工作计划，结合单位实际特点、工作重点、具体职责和执法任务，制定法治宣传教育实施方案，明确普法工作目标任务以及拟开展的普法工作，年底及时总结年度普法工作情况。

3.重点普法内容。重点宣传普及行政许可法、行政处罚法、民办教育促进法、教师法、教育法、义务教育法、职业教育法等法律；幼儿园管理条例、民办教育促进法实施条例、校车安全管理条例、教师资格条例、行政机关公务员处分条例等行政法规；学生伤害事故处理办法、教育行政处罚暂行实施办法、教师资格条例实施办法等部门规章以及山西省实施《中华人民共和国民办教育促进法》办法、山西省实施《中华人民共和国职业教育法》办法等地方性法规。

4.落实学法制度。贯彻落实我局制定出台的《大同市教育局机关公务员学法用法制度》，明确学习的内容、时间、任务、方法、目标，定期组织机关干部和党组成员学法，每月不少于1次。

5.完善普法机制。健全面向社会的普法制度，在日常工作以及执法过程中，向服务对象、执法对象宣讲有关实体法和程序法，解答有关法律问题。全面推进执法公开，典型案例定期向社会公众发布。

6.开展普法宣传。每年结合“12.4”国家宪法日，有计划地组织开展面向机关干部职工和社会的法治宣传活动，印发相关普法资料，广泛宣传本单位执法的法律法规。

7.加强法律培训。要大力加强对本单位工作人员特别是执法人员的法律培训，使之熟练地掌握和运用相关的法律知识，正确行使法律赋予的相关权力。把法治教育纳入机关工作人员日常学习和培训的必训内容，确保法治培训课时数量和培训质量。

8.加强检查督促。局普法领导小组要加强对本系统普法工作的指导，及时部署工作任务，提出工作要求，并加强检查督促，确保普法工作责任的落实。

五、相关要求

一是提升工作质量。各科室、单位严格按照本方案要求，及时按各自职能梳理、归集履责所依据的法律、法规及各类政策性文件，严格按照普法工作计划开展法制宣传工作。

二是创新工作方法。做到主题宣传形式多样，创造新经验、新亮点、新典型，及时总结好经验、好做法。

三是强化宣传教育。要充分利用网络、电视、报刊等媒体的作用，大力宣传相关法律法规知识，宣传普法工作中的好人好事，宣讲执法过程中的典型案例。

四是严格监督考核。局普法领导小组每年将组织专人对本系统“谁执法谁普法”责任制落实情况进行督查和考核。对“谁执法谁普法”责任制落实不到位的科室或单位，应责成其采取补救措施予以补救，并在一定范围内进行通报批评。

二、普法对象

全体党员干部和社会大众。

三、普法方式

1.结合“双百”活动，开展习近平总书记全面依法治国新理念新思想新战略系列宣讲。

2.在“七一”前后集中组织开展党内法规宣传教育活动。

3.组织实施“宪法进宾馆”“宪法进万家”“宪法进公共交通场所”等活动，组织开展“12·4”国家宪法日暨宪法宣传周集中宣传活动。

4.加强本部门（系统）法治宣传教育组织机构建设，落实法治建设一把手责任制；党委（党组）召开至少1次专题会议，研究部署普法工作；党委（党组）理论学习中心组集体学法不少于2次；积极组织国家机关工作人员参加旁听庭审活动。

5.贯彻落实市委办公厅、市政府办公厅《关于全面贯彻落实国家机关“谁执法谁普法”普法责任制实施意见》要求，结合自身职能，围绕热点难点问题，积极开展以案释法，把普法工作融于立法、执法、司法、管理和服务全过程。

6.积极创作微视频微动漫、普法短剧、歌曲、书画摄影等法治文化作品，加强法治文化阵地建设。

7.充分利用行业宣传日（周、月）、法律法规颁布施行纪念日等特殊时间节点，运用传统媒体和新媒体面向社会开展专题普法活动。
