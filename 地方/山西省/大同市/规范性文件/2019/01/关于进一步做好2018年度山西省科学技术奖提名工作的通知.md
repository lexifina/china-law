# 关于进一步做好2018年度山西省科学技术奖提名工作的通知

各有关单位（专家）：

为了进一步做好2018年度山西省科学技术奖提名工作，鼓励我省更多符合条件的优秀项目（人选）提名省科学技术奖，充分调动全社会支持科技创新的积极性，省科技厅将2018年山西省科学技术奖提名工作时间延长，“山西省科学技术奖励提名系统”关闭时间延长至2019年2月28日18:00，由于我市提名材料报送前需进行为期七个工作日的公示，请各有关单位（专家）于2月15日前完成系统填报，逾期不予受理。其他相关事项按照山西省科技厅《关于2018年度山西省科学技术奖提名工作的通知》要求执行。
