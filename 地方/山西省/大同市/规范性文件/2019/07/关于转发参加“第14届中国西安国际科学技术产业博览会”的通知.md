# 关于转发参加“第14届中国西安国际科学技术产业博览会”的通知

各有关企业：

按照大同市人民政府办公室通知，2019年第14届中国西安国际科学技术产业博览会，将于8月15日—17日在西安曲江国际会展中心举办。本次博览会主题为“创新驱动发展●产业融合升级”，望涉及军民融合、航天航空、新能源、新材料、节能环保、新能源汽车、新一代信息技术、智能制造、人工智能、电子信息、大数据、无人驾驶、自动识别、生物技术、科学仪器、智慧教育、互联网+、AR/VR、金融服务、现代农业等领域的科技型企业踊跃参加。报名截止时间8月8日
