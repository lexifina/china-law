# 关于发布《大同市市级水污染防治技术指导目录》的公告

为贯彻落实国务院《水污染防治行动计划》、《山西省水污染防治工作方案》、《山西省水污染防治2019年行动计划》、《大同市水污染防治工作方案》和《大同市水污染防治2019年行动计划》,确保实现大同市2019年水环境质量改善目标,加快环保先进污染防治技术示范、应用和推广,市科技局参照《山西省水污染防治技术指导目录》入选技术成果,结合大同市实际情况,修订完善了《大同市市级水污染防治技术指导目录》,现予发布。

《大同市市级水污染防治技术指导目录》所列技术是经工程实践证明了的成熟技术,治理效果稳定、经济合理可行,鼓励推广应用。
