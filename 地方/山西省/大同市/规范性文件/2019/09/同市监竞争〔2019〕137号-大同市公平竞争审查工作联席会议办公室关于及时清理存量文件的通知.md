# 大同市公平竞争审查工作联席会议办公室关于及时清理存量文件的通知

市公平竞争审查工作联席会议成员单位、各县(区)市场监督管理局、市市场监督管理局开发区分局:

为进一步深入贯彻实施公平竞争审查制度,按照全市公平竞争审查工作联席会议第一次全体会议安排部署,结合《2019年大同市公平竞争审查工作重点》(同市监竞争〔2019〕132号)文件精神,现就清理存量文件通知如下,请遵照实施。

一、严格审查增量。各单位、各县(区)在有关政策制定过程中要按要求进行公平竞争审查,未经过公平竞争审查的政策措施等相关文件,一律不得出台。

二、有序清理存量。按照“谁制定,谁清理”的原则,各单位各部门、各县(区)要对照公平竞争审查标准,对现行政策措施及相关文件区分不同情况开展自查,稳妥把握节奏,有序清理和废除妨碍统一市场和公平竞争的各种政策和规定。对市场主体反映比较强烈、问题暴露比较集中、影响比较突出的政策和规定,要尽快废止。对以合同协议等形式给予部分市场主体的优惠政策,以及立即终止会带来重大影响的政策措施,要设置过渡期,留出必要的缓冲空间,对已兑现的优惠政策,不溯及既往。各单位、各部门、各县(区)应当对清理情况形成报告,并按要求及时向社会公开。

2017年及以前的文件,务必于10月31日前全部完成审查,并按照要求填写《公平竞争审查表》;2018年出台的文件,务必于年底前全部完成审查,并按照要求填写《公平竞争审查表》;2019年及以后出台的文件,务必按照要求严格进行审查,并填写《公平竞争审查表》。所有文件完成审查后,均应按年份分别填写《公平竞争审查情况汇总登记表》,并统一上报市市场监督管理局反垄断和反不正当竞争科,另外,市市场监督管理局设立了公平竞争举报电话和邮箱。
