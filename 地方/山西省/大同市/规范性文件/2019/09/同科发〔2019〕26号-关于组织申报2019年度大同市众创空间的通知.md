# 关于组织申报2019年度大同市众创空间的通知

各县(区)科技(教)局,各有关单位:

为贯彻落实中央、省及我市有关文件精神,激发全社会创新创业活力,营造良好的创新创业生态环境,引导和支持众创空间等新型创业服务平台健康发展,大同市科学技术局将开展2019年度“大同市众创空间”认定管理工作。现将有关事宜通知如下:

一、申报依据

依据《大同市众创空间认定和管理办法》(同科发〔2016〕6号)进行申报。

二、组织推荐

各县(区)科技(教)局负责本区域内市级众创空间的组织推荐工作;大同大学负责本校市级众创空间的组织推荐工作。(2016年认定的市级众创空间年满三年,需重新认定)

三、工作流程

(一)众创空间运营主体填写《大同市众创空间申报书》(附件),交由组织推荐单位审核后报送至市科技局。

(二)市科技局与相关部门组成考察小组对提出申请的众创空间进行实地考察。考察包括查验场地面积、创客数量和实际运行情况等。

(三)经市科技局组织专家评审、局务会研究审定、网上公示无异议的众创空间,认定为大同市众创空间。

(四)经认定的大同市众创空间,将依据《扶持众创空间发展专项资金管理办法(暂行)》,予以一定的资金补助。

四、材料受理时间

此次申报工作市科技局材料受理时间截止2019年9月25日,请各组织单位结合自身实际积极组织申报。

五、材料报送

请各组织推荐单位对申报材料审查把关,并按规定时间将《大同市众创空间申报书》(一式5份)报送至市科技局,相关材料电子版发送至所附邮箱。
