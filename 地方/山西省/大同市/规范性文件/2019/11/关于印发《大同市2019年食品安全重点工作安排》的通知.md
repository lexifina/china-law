# 关于印发《大同市2019年食品安全重点工作安排》的通知

各县(区)人民政府,市直各委、局、办:

《大同市2019年食品安全重点工作安排》已经市人民政府同意,现印发给你们,请认真组织实施。

大同市人民政府办公室

2019年9月20日

(此件公开发布)

大同市2019年食品安全重点工作安排

为深入贯彻落实党中央、国务院和省委、省政府对食品安全工作的决策部署,落实“四个最严”要求。强化源头严防、过程严管、风险严控,加快提升食品安全治理能力和保障水平,根据《山西省人民政府办公厅印发山西省2019年食品安全重点工作安排的通知》(晋政办发〔2019〕63号),结合我市实际,现就2019年全市食品安全重点工作作出如下安排:

一、严格落实食品安全责任

1.加强评议考核,完善对地方政府食品安全工作评议考核制度,严格责任追究,明确各级政府和监管部门事权划分,压实部门监管责任,落实食品生产经营主体责任,推动形成一岗双责,权责一致、齐抓共管,失职追责、尽职免责的工作格局。(各级政府,市食安委各成员单位及相关部门按职责分工负责)

2.强化各级食品安全委员会及其办公室在统筹规划、综合协调、督查考核、制度建设等方面的作用,健全部门协调联动机制,协调解决跨部门跨地区食品安全重大问题。(各级政府,市食安办及市食安委各成员单位按职责分工负责)

3、实施“双安双创”示范引领行动,把创建国家食品安全示范城市、省级农产品质量安全县和食品安全示范县与卫生城市、文明城市、旅游城市等创建相结合,统筹部署、全方位推进,推动全市食品安全治理能力、整体水平、产业健康发展水平和群众满意度明显提升。(市食安办牵头,市农业农村局、市市场监管局,各级政府分工负责)

4、执行粮食安全市长责任制有关规定,强化各级粮食行政管理部门属地监管责任,落实承储企业粮食质量安全主体责任,健全超标粮食收购处置长效机制。(市粮食和物资储备局负责)

二、健全完善食品安全法规体系

5.落实新修订的《山西省食品小作坊小经营店小摊点管理条例》,配套完善制度,加强“三小”备案管理,进一步规范“三小”生产经营行为。(市市场监管局、市食安委相关成员单位,各级政府按职责分工负责)

6.加快制修订产业发展和监管急需的食品安全基础标准、产品标准、配套检验方法标准。完善与监管需求相适应的食品补充检验方法,加大对农兽药残留、重金属、食品污染物、致病性微生物和食品标签等标准的制修订。加强食品快检产品评价体系,规范食品快检使用管理,推动食品快检信息平台建设。推进食用农产品、食品追溯标准体系建设。(市农业农村局、市卫健委、市商务局、市科技局、市市场监管局按职责分工负责)

7.健全完善食品安全相关规章制度,厘清食品安全监管边界,明确各级监管职责和监管事权清单,进一步完善食品安全治理的体系制度,实现全链条、全过程、无缝隙监管。(市食安委相关成员单位,各级政府按职责分工负责)

8.建立食用农产品产地准出与市场准入衔接机制,完善农产品(食品)批发市场、食品销售市场、学校、养老机构、建筑工地、旅游景区以及乳制品、肉制品、白酒、食醋生产加工、网络订餐、网络销售等食品安全监管办法。健全铁路、航空餐饮食品安全防控体系,做好铁路、航运、高速公路服务区食品安全管理。组织开展食用林产品种植等生产环节的质量安全监管。(市农业农村局、市商务局、市教育局、市民政局、市住建局、市文旅局、市市场监管局、大秦铁路大同站、市交通运输局、大同机场有限责任公司、市林业局按职责分工负责)

9.加强农产品和食品冷链物流、仓储体系建设,建立覆盖农产品和食品生产、加工、运输、配送、仓储、销售等环节的全程冷链物流体系,着力打造功能完善的全市农产品和食品冷链物流、仓储发展体系。(市发改委、市商务局、市供销社、市农业农村局、市市场监管局等部门按职责分工负责)

三、强化食品安全源头综合治理

10.严把产地环境安全关,实施耕地土壤环境治理保护。强化大气污染治理,加强重点行业挥发性有机物治理。加强流域水污染防治工作。加大农村环境综合整治力度,对建制村开展环境整治。开展重点地区、涉重金属重点污染土壤及重点企业风险排查整治,防止重金属等污染物进入农田。(市农业农村局、市生态环境局、市水务局、市发改委、市工信局按职责分工负责)。

11.严把农业投入品生产使用关,严格执行农药兽药、饲料添加剂等农业投入品生产和使用规定,严禁使用国家明令禁止的农业投入品,严格落实定点经营和实名购买制度。将高毒农药禁用范围逐步扩大到所有食用农产品。落实农业生产经营记录制度、农业投入品使用记录制度,指导农户严格执行农药安全间隔期、兽药休药期有关规定,防范农药兽药残留超标。(市农业农村局负责)

12.净化产地环境,实施化肥农药减量增效、水产养殖用药减量行动,开展高毒高风险农药淘汰工作,推进农药追溯信息平台建设,加强全程绿色防控,推广绿色防控技术。探索建立绿色农业生产标准体系,推进特色农产品全产业链安全风险管控。组织开展农药、兽用抗菌药、农资打假等专项行动。完善市级农产品质量安全追溯信息平台,推进农产品质量安全追溯信息平台应用,健全原产地追溯制度。(市农业农村局、市水务局、市生态环境局按职责分工负责)。

四、严防严控食品安全风险

13.全面落实食品安全风险监测计划任务,积极推进食源性疾病溯源体系建设,加强风险监测结果通报与会商研判,为防控风险提供技术支持。(市卫健委负责)

14.继续开展食用农产品、水产品、林产品质量安全抽检和风险监测。开展进口食品“国门守护”行动,严厉打击食品走私。完善食品抽检制度,加大重点食品、重点项目抽检力度,加强评价性抽检分析结果应用。加大对大宗食品、高风险品种、地方特色食品、历年抽检合格率低食品抽检力度。强化不合格食品核查处置完成率100%要求,落实食品安全抽检信息公开制度。严控收购、储存环节粮食质量安全。完善风险交流制度,定期召开风险会商会议。(市农业农村局、大同海关、市卫健委、市市场监管局、市粮食和物资储备局、市林业局按职责分工负责)

15.强化新收获粮食质量安全监测,及时向有关部门通报监测结果。妥善做好超标粮食收购处置。督促粮食收储企业加强出入库质量把关。严禁不符合食品安全标准的粮食流入口粮市场和食品生产企业。(市粮食和物资储备局、市市场监管局按职责分工负责)

16.规范食品包装材料、容器洗涤剂、生产经营工具、设备等管理。加强对餐饮具集中消毒企业卫生监督检查和产品抽检工作。(市卫健委、市市场监管局按职责分工负责)

17.加强食品安全责任保险管理,推进肉蛋奶和白酒生产企业、集体用餐单位、大宗食品配送单位、中央厨房和配餐单位主动购买食品安全责任保险,鼓励政府将学校食品安全和农村集体聚餐责任险纳入政府财政预算。(市市场监管局、山西银保监局大同分局、市财政局,各级政府按职责分工负责)

五、推动突出问题集中整治

18.加强网络食品经营等新业态的专项整治,落实网络食品交易第三方平台主体责任,网络餐饮服务第三方平台分支机构备案率达到100%,加强网络食品经营事中事后监管,强化餐饮单位入网资质审查、入网后检查、许可资质和量化分级管理等信息公示,加大对网络食品经营违法行为打击力度,涉嫌犯罪的移交公安机关依法严厉打击。(市委网信办、市公安局、市市场监管局、市工信局按职责分工负责)

19.实施餐饮质量安全提升行动,推进“明厨亮灶”,餐饮安全风险分级管理,支持餐饮服务企业发展连锁经营和中央厨房,提升餐饮行业标准化水平,规范快餐、团餐等大众餐饮服务。鼓励餐饮外卖对配送食品进行封签,使用环保可降解的容器包装。大力推进餐厨废弃物资源化利用和无害化处理,防范“地沟油”流入餐桌。(市市场监管局负责)

20.实施校园食品安全守护行动,严格落实学校食品安全校长(园长)负责制,保证校园食品安全,防范发生群体性食源性疾病事件。校园食堂实行大宗食品公开招标、集中定点采购,建立学校相关负责人陪餐制度,鼓励家长参与监督。对学校食堂、学生集体用餐配送单位、校园周边餐饮门店及食品销售单位实行全覆盖监督检查。落实好农村义务教育学生营养改善计划保证学生营养餐质量。(市教育局、市卫健委、市市场监管局按职责分工负责)

21.开展农药兽药残留、兽用抗菌药、蛋禽违规用药、牛羊肉“瘦肉精”生猪屠宰注药注水、水产品“两药”(孔雀石绿、硝基呋喃)生鲜乳违禁物质等违法违规专项整治。开展产地水产品质量安全抽查。建立农产品质量安全“黑名单”制度。深入推进生猪屠宰资格清理,健全农村牲畜屠宰场(点)和疫病防控体系,关停不符合设立条件的生猪屠宰场点。(市农业农村局、市市场监管局、市生态环境局按职责分工负责)

22.做好非洲猪瘟防控工作,持续推动餐厨废弃物资源化利用,积极构建餐厨废弃物管理长效机制。(市发展改革委、市工信局、市住建局、市农业农村局、市市场监管局按职责分工负责)

23.大力实施农村食品安全治理,以农村地区、城乡结合部为主战场,全面清理食品生产经营主体资格,严厉打击制售“三无”食品、农村假冒伪劣食品、“山寨食品”过期食品及虚假宣传等违法违规行为,坚决取缔“黑工厂”“黑窝点”“黑作坊”。净化农村消费市场,提高农村食品安全保障水平。(市农业农村局、市公安局、市市场监管局按职责分工负责)

24.在风险高、大型食品生产企业全面实施危害分析和关键控制点(HACCP)良好生产规范(GMP)管理体系。加强粮食及加工品、乳及乳制品、保健食品、婴幼儿辅助食品等重点食品监管,组织开展食品非法添加和滥用食品添加剂专项治理。加强食品生产经营过程控制,压实生产经营主体责任,食品生产企业自查报告率达到90%以上,婴幼儿配方乳粉和辅助食品生产企业自查率达到100%大型肉制品生产企业产品自检自控率达到100%。摸清“三小”(食品小作坊、小经营店、小摊点)底数,规范生产经营行为。(市市场监管局负责)

25.加快婴幼儿配方乳粉和奶业生产质量安全追溯体系建设,推进重要产品追溯管理平台建设,支持乳制品、奶业生产企业技术改造升级。(市发改委、市工信局、市农业农村局、市商务局、市市场监管局按职责分工负责)

六、严厉惩处食品领域违法犯罪行为

26.对违法行为“处罚到人”,运用法律手段对违法人员进行严厉处罚,大幅提高违法成本。依法严厉处罚违法企业及其法定代表人、实际控制人、主要负责人等直接负责的主管人员和其他直接责任人员,严格落实从业禁止、终身禁业等惩戒措施。加强大案要案联合挂牌督办。加大监管执法力度;做好涉嫌犯罪刑事追究和移送工作。完善食品安全民事和行政公益诉讼。(市委政法委、市法院、市检察院、市公安局、市司法局、市农业农村局、大同海关、市市场监管局按职责分工负责)

27.强化行政执法和刑事司法衔接,始终保持对食品安全犯罪严打高压态势。深入推进食品打假“利剑”行动,加强线索通报、案件移送、情报会商等工作,做好涉案物证保管工作。强化部门协作配合、工作联动,加大对食品走私打击力度。严厉查处食品商标侵权、虚假宣传、虚假广告等欺诈消费者违法犯罪行为,维护食品市场公平竞争秩序。(市委政法委、市法院、市检察院、市公安局、市司法局、大同海关、市市场监管局按职责分工负责)

28.深入推进婴幼儿配方乳粉和保健食品欺诈、虚假宣传专项整治,依法严厉打击传销、虚假宣传、制售假冒伪劣产品等扰乱市场秩序、欺诈消费者等违法犯罪行为。(市委网信办、市公安局、市商务局、市市场监管局按职责分工负责)

29.开展冷库及冷藏食品、食品配送、食盐市场、酒类、食醋市场等专项整治。加强“地沟油”综合治理,推进餐厨废弃物分类利用,规范餐厨废弃油脂收运,推进符合相关法规的肉类加工废弃物、检验检疫不合格禽产品无害化处理工作。(市发改委、市工信局、市生态环境局、市住建局、市农业农村局、市市场监管局,各级政府按职责分工负责)

七、切实加强食品安全监管能力建设

30.构建高效的食品安全监管体系。加快建设职业化检查员队伍。加强检验检测机构监督管理,推进食品检验检测能力验证工作。加强基层食品、农产品质量安全检验监测和食品安全监管执法能力建设。加快推进“十三五”县级食品安全检验检测资源整合项目建设。推动实施食品生产企业监督检查电子化管理,建立完善监督检查数据库。(市市场监管局、市农业农村局,各级政府按职责分工负责)

31.加大食品安全工作经费保障力度,加强基层监管机构条件建设。企业要加大食品质量安全管理方面的投入,构建多元化投入保障机制。(市财政局、市发改委、市市场监管局,各级政府按职责分工负责)

32.加强科技支撑和信息化建设。加快食品安全云服务平台建设,为食品安全社会共治共享提供信息支撑。推进“互联网+食品”监管,重点运用大数据云计算、区块链等技术,建立重点食品追溯协作平台,发挥“智慧监管”作用,提高食品安全管控能力。(市科技局、市工信厅、市农业农村局、市卫健委、大同海关、市市场监管局按职责分工负责)

八、强力推进食品产业提质升级

33.实施乡村振兴战略,推进农业标准化生产,开展农业品牌提升行动,加强地理标志农产品保护,推动绿色食品认证和食用农产品产地准出制度的实施,确保“三品一标”健康发展。(市农业农村局负责)

34.推进食品工业企业诚信体系建设,开展食品工业“增品种、提品质创品牌”专项行动,支持食品工业企业结构调整和转型升级。建立食品生产经营企业信用档案,实行食品生产经营企业信用分级分类管理。加大对失信食品生产经营者联合惩戒力度。(市工信局、市发改委、市商务局、市公安局、市市场监管局按职责分工负责)

35.持续开展“放心肉菜示范超市”创建。实施“阳光操作”“透明车间”工程,学校食堂或供餐单位“明厨亮灶”比例达到70%。全面推行“互联网+食品”、电子追溯监管系统提升行动。落实进货查验和索证索票。(市市场监管局、市教育局按职责分工负责)

36.深化“放管服效”改革,简化准入审批流程。推进实现“网通办”和许可证照电子化应用。对低风险食品及相关产品生产许可探索推行“先证后查”“自主声明”“公开承诺”,食品经营许可审批时限压缩三分之一。(市市场监管局负责)

九、着力构建社会共治共享格局

37.加强食品安全热点问题舆情监测和协调处置,加强信息公开和食品安全新闻宣传报道,正确引导食品安全热点舆论,及时回应社会关切综合治理食品安全谣言,营造良好舆论环境。(市委宣传部、市委网信办、市市场监管局、市食安委各成员单位,各级政府按职责分工负责)

38.开展食品安全宣传周活动,举办“绿色食品宣传月”,开展中小学食品安全教育等活动,利用科技馆、科普网站、科普平台等宣传食品安全科学常识,提高公众食品安全意识。(市委宣传部、市委网信办、市科技局、市教育局、市农业农村局、市市场监管局、市科协、市食安委各成员单位,各级政府按职责分工负责)

39.鼓励行业协会在督促企业诚信守法自律方面发挥更大作用。提高食品安全法律法规、城镇居民食品安全知识知晓率和食品安全满意度。畅通群众维权渠道,鼓励企业内部人员举报食品安全违法违规行为,完善守信激励和失信惩戒机制,实施“黑名单”制度。(市发改委、市工信局、市财政局、市农业农村局、市市场监管局按职责分工负责)

40.进一步发挥食品安全专家队伍作用,为制定和实施食品安全重大政策措施提供咨询意见,为应急处置、事故调查等提供技术支撑。(市食安办、市市场监管局负责)
