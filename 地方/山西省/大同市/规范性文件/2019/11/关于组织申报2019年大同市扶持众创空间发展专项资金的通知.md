# 关于组织申报2019年大同市扶持众创空间发展专项资金的通知

各县（区）科技（教）局，各有关单位：

为贯彻落实《大同市人民政府办公厅关于发展众创空间推进大众创新创业的实施意见》（同政办发﹝2016﹞20号），进一步支持我市众创空间的发展，营造良好的创新创业生态环境，激发全社会的创新创业活力，根据大同市科技局《扶持众创空间发展专项资金管理办法（暂行）》（同科发﹝2017﹞12号）要求，现组织开展扶持众创空间发展专项资金申报工作。具体通知如下：

一、支持对象

经大同市科技局认定的2019年市级众创空间。

二、专项资金补贴范围

2018年1月至2019年10月底：

1、众创空间的开办、厂房改造、场地租赁等；

2、宽带服务接入、公共软硬件开发及购置；

3、开展研发设计、科技金融、创业孵化、成果交易、认证检测等众创服务平台的建设；

4、举办创新创业培训、论坛沙龙、导师咨询、创新创业产品展示等服务活动。

三、申请流程

1、申请众创空间扶持资金需填写《大同市扶持众创空间发展专项资金申请表》（附件1）和《众创空间发展情况报告》（附件2），内容填写时间范围为2018年1月至2019年10月底；

2、申报材料用A4纸双面打印、按顺序将申报书正文和附件简装成册，一式5份按要求签字盖章后报送至所属县（区）科技（教）局；

3、各县（区）科技（教）局对申报材料进行审核，按要求签字盖章后，于12月3日18：00前统一报送市科技局成果转化与区域创新科；

4、市科技局组织专家评审，并依据评审结果确定专项资金扶持计划。

四、其他事项

1、申报材料全部内容应保证真实、有效、准确，提供虚假材料的，一经发现，将取消评审资格，并根据有关规定严肃处理；

2、纸质申报材料报送地址：大同市兴云街2799号文瀛湖办公楼主楼509室市科技局成果转化与区域创新科，电子版发送至23024447＠qq．com。
