# 关于认定大同市全科盟三创孵化园等21家众创空间为市级众创空间的通知

各县(区)科技(教)局,各有关单位:

为了深入贯彻落实省委、省政府《关于强化实施创新驱动发展战略进一步推进大众创业万众创新深入发展的实施意见》(晋发〔2017〕51号)和市政府《大同市推动创新创业高质量发展打造“双创”升级版的实施方案》(同政发〔2019〕58号)文件精神,进一步激发市场活力和社会创造力,现就推动我市创新创业高质量发展、打造“双创”升级版,根据《大同市众创空间认定管理办法》(同科发〔2016〕6号)要求,市科技局组织开展了2019年市级众创空间的认定工作。经过组织申报、受理审查、专家评审、公示等环节,决定认定大同全科盟三创孵化园等21家众创空间为市级众创空间,现予以公布。

请各县区科技管理部门及有关单位切实加强对已认定众创空间的指导和支持。请各市级众创空间主动接受社会和创业者监督,不断创新服务模式,拓展服务功能,提升服务能力,发挥引领示范作用,为加速形成大众创业、万众创新的良好局面,进一步推动创新创业高质量发展,打造“双创”升级版做出贡献。
