# 关于做好2019年全市机关事业单位工人技术等级岗位考核工作的通知

各县(区)人力资源和社会保障局,市直各委、办、局,市直属各事业单位,中央、省驻同各有关单位:

按照山西省人力资源和社会保障厅《山西省人力资源和社会保障厅关于做好2019年全省机关事业单位工人技术等级岗位考核工作的通知》(晋人社厅函〔2019〕257号)的精神,现将我市2019年机关事业单位工人技术等级岗位考核工作有关事宜通知如下:

一、2019年全市机关事业单位工人技术等级岗位考核和工人技师评聘工作继续按照现行规定由政府人力资源和社会保障部门组织实施。

二、全市机关事业单位中符合规定申报条件的技术工人,均可申报本岗位相应初级工、中级工、高级工技术等级岗位考核或工人技师任职资格考核。申报条件中,工作年限和本技术等级岗位工作年限计算至2019年。

三、2019年组织考核的工种为文秘资料员等,具体工种目录见附件1。

未列入目录考核范围的技术工人,可选择相近工种申报考核。相近工种的本技术等级岗位工作年限可以和原技术等级岗位工作年限合并计算。申报相近工种考核,须按管理权限报各级人力资源和社会保障部门同意。

四、申报考核的人员,须填写《山西省机关事业单位工人技术等级岗位考核审批表》(见附件2)或《山西省机关事业单位工人技师任职资格考核审批表》(见附件3)。

各单位按照《山西省机关事业单位工人技术等级岗位考核申报登记表》(见附件4)分类汇总,依申报程序,逐级报各级人力资源和社会保障部门进行资格审查。县区的中、高级工和工人技师、市直单位的初、中、高级工和工人技师的申报材料经县区人社部门和市直主管部门审核后送市工考办汇总,由工考办统一报市人力资源和社会保障局进行资格审查。

各县(区)部分初级工需委托省、市组织考核的,按管理权限进行资格审查后,有关材料一并报送。

五、各县(区)人力资源和社会保障局、市直各单位人事部门要切实担负起工人技术等级岗位考核报名、资格审查、继续教育、考核考试、证书管理的责任。考核合格的初、中、高级工和工人技师,按管理权限由各级人力资源和社会保障部门颁发《山西省机关事业单位工人技术等级岗位证书》或《山西省机关事业单位工人技师任职资格证书》,作为机关事业单位工人上岗和兑现工资的依据。

六、我市申报材料报送地址:御河西路132号办公区(原市委院)主楼五层,市机关事业单位工人技术等级岗位考核办公室。联系电话:0352-5067805。

七、申报截止时间为2019年4月20日。
