# 关于向社会公布2019年第一批重大劳动保障违法行为的公告

为进一步夯实我市保障农民工工资支付工作,加强对重大劳动保障违法行为的联合惩戒力度,促进用人单位遵守劳动保障法律、法规和规章,落实建筑工程项目劳动用工管理“六项制度”,营造不敢欠、不能欠、不愿欠的社会氛围,实现到2020年农民工工资基本无拖欠的目标。根据《重大劳动保障违法行为社会公布办法》(人社部令第29号)、《山西省用人单位重大劳动保障违法行为实施社会公布暂行规定》(晋劳社厅发[2007]152号)和市人力资源和社会保障局等七部门《关于开展根治欠薪夏季行动》(同人社明电[2019]2号)的要求和规定,市全面治理拖欠农民工工资问题协调领导小组办公室决定向社会公布2019年第一批重大劳动保障违法行为。

1、龙建路桥股份有限公司,统一社会信用代码:9102976R(12-1);地址:黑龙江省哈尔滨市南岗区长江路368号,法定代表人:尚云龙。

2019年7月上旬,浑源县人力资源和社会保障局在对在建项目检查中,发现龙建路桥股份有限公司在浑源县四好农村公路田村至驼峰村、驼峰村至屈家坪、屈家坪至井沟村通硬化路工程中未按要求落实治欠保支“六项制度”。浑源县人力资源和社会保障局于2019年8月4日、2019年9月11日先后两次依法向该公司下达《劳动保障监察责令改正决定书》要求其整改,但该公司敷衍塞责拒不整改,存在重大欠薪隐患。

2、大同建云集团建设有限公司,统一社会信用代码:91140200734035907P,住所地:山西省大同市经济技术开发区河清路88号,法定代表人:田云山。

2019年8月,灵丘县人力资源和社会保障局在对其承建的灵丘县风和美苑二期9#、10#楼项目进行检查时,发现其治欠保支“六项制度”均未落实,灵丘县人社局于2019年8月26日、2019年9月25日先后两次下达劳动保障监察责令改正决定书,并多次口头口头催促多次仍不整改,到目前仍未开设农民工工资专户、未参加工伤保险。存在重大欠薪隐患。

3、大同西特鑫电力科技有限责任公司,统一社会信用代码:91140200MA0HMQDA81;地址:山西省大同市平城区御东花园6号商铺,法定代表人:白伟。

2019年9月,云州区人力资源和社会保障局在对在建项目检查中,发现大同西特鑫电力科技有限责任公司周士庄凯巢雅园住宅项目未按要求落实治欠保支“六项制度”。云州区人力资源和社会保障局联合区住房和城乡建设局于2019年9月9日依法向该公司下达《停工整顿通知书》要求其整改,但该公司敷衍塞责拒不整改,存在重大欠薪隐患。
