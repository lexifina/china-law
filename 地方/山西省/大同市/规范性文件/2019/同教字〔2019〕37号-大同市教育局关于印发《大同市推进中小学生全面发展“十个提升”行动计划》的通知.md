# 大同市教育局关于印发《大同市推进中小学生全面发展“十个提升”行动计划》的通知

大同市推进中小学生全面发展“十个提升”

行 动 计 划

为深入贯彻落实党的十九大精神和全国教育大会精神，全面提升中小学生综合素养，培养德智体美劳全面发展的社会主义建设者和接班人，结合我市实际，制定本行动计划。

一、指导思想

以习近平新时代中国特色社会主义思想和党的十九大精神为指导，围绕培养什么人、怎样培养人、为谁培养人这一根本问题，全面贯彻党的教育方针，深入落实立德树人根本任务，把中华民族伟大复兴作为重要使命，践行社会主义核心价值观，培养具有健全人格、健康体魄、文化基础、审美情趣、崇尚劳动和具有社会责任感、创新精神、实践能力的德智体美劳全面发展的合格学生，为学生终身发展奠定坚实基础。

二、工作目标

落实立德树人根本任务，用好课程育人、环境育人、实践育人载体，建立德育一体化管理机制、家校共育机制，健全班、团、队组织队伍，实施提升理想信念、提升安全防范能力、提升传统文化素养、提升阅读能力、提升表达能力、提升运动技能、提升艺术素养、提升劳动技能、提升探究能力、提升实践能力等“十个提升”，让每一位学生根据自身情况，培养兴趣，开发潜能，养成习惯，受益终身。通过“十个提升”，逐步建立和完善以促进学生综合素质提升为统领的德育体系、课程体系、实践体系和评价体系，形成促进学生健康成长、全面发展的教育体制机制和良好的社会氛围。

三、基本原则

（一）因地制宜与因校制宜原则。各县区、学校要立足地区、学校资源，结合学生自身特点，尊重学生身心发展规律，尊重基层首创，因地制宜，因校制宜，不限于“十个提升”内容，鼓励创新，进一步丰富“十个提升”内容。

（二）内涵发展与特色发展原则。将“十个提升”纳入课程体系，根据学校特色，加强校本课程建设，将“十个提升”与教育教学、学校文化密切结合，形成校校有特色、班班有特点、生生有特长的“一校一品”“一校多品”的教育格局。

（三）全面发展与个性发展原则。“十个提升”的实施是落实学生德智体美劳全面发展的具体措施，要面向全体学生，在普及和共同发展的基础上，突出特殊禀赋学生的发现和培养，因生制宜，使学生的个性特长得到充分发展，让更多优秀的孩子脱颖而出。

四、重点任务

1.提升理想信念。坚持德育为首，把立德树人作为根本任务，认真贯彻落实《中小学德育工作指南》，把德育工作贯穿教育教学全过程，实现全员、全程、全方位育人。通过班团队活动、社团活动、社会实践活动等形式，积极培育和践行社会主义核心价值观，弘扬中华优秀传统美德，宣传英雄及身边先进事迹等。让学生做到熟记社会主义核心价值观，让革命英雄先烈成为偶像，让红色及经典歌曲唱响校园，不断提升理想信念、道德境界，引导学生把个人理想融入到实现中国梦的过程，积极投身于实现中华民族伟大复兴的生动实践中。

2.提升安全防范能力。引导学生树立安全意识，加强安全课程建设，结合重大节日、活动、安全教育日等，开展以珍爱生命、防溺水、防交通事故、防校园意外、防校园欺凌、网络安全、禁毒宣传等为内容的安全教育，加强应急演练，积极开展法治教育、心理健康教育，让学生牢固树立“珍爱生命、保护自我”的意识，掌握必要的安全知识和自我保护技能，最大限度预防安全事故的发生。

3.提升传统文化素养。引导学生每天诵读一篇经典诗文。通过诵读活动，提升阅读、感悟能力和语言文字表达能力。学校要将诵读诗文有机融入课堂教学、晨读、课前朗读等活动中，创造性开设吟诵课、朗诵课等，建立各种形式的朗诵、吟诵社团。定期组织并推荐优秀学生参加各级各类诗文诵读比赛活动，为学生提供更多的展示机会。在经典诗文诵读中感受中华优秀传统文化，感悟人生哲理，培养家国情怀，陶冶道德情操，丰富精神世界。

4.提升阅读能力。引导学生每月精读一本纸质书。将读书与个人成长、情感体验相结合，培养学生自主阅读、热爱读书的好习惯。结合实际定期推荐符合学生学段和年龄特点的阅读书目，对推荐书目以外的书籍应当提供必要的选择指导。学校要挖掘潜力，完善图书角、阅读吧、读书小组，举办读书沙龙、阅读征文比赛等活动，组织学生开展不同形式的阅读分享，给予学生必要的阅读指导，同时积极创造条件组织亲子阅读，实现优秀作品感染人、鼓舞人、教育人的引导作用。

5.提升表达能力。引导学生坚持把所见、所闻、所感，不拘形式地记下来，培养记日记（周记）的习惯，鼓励小学一二年级学生用文字、图形、符号等方式记录自己每天的观感，进一步丰富词汇量，锻炼语言和文字表达能力。在课堂教学、团队活动、主题班会等活动中，注重提升学生的逻辑思维和表达能力。通过做一次演讲、讲一个故事、开一场辩论赛、写一篇征文、美文赏析等形式，定期组织班级、年级、学校等不同层次的比赛活动，加强言语表达技能指导。鼓励并推荐优秀学生积极参加各级各类相关活动。

6.提升运动技能。引导学生牢固树立健康第一的理念。学生在校期间自主选择学习2-3项体育运动技能，可以为球类、田径、跳绳等，并熟练掌握其中一项，在体育锻炼中享受乐趣、增强体质、健全人格、锤炼意志。学校要开齐开足体育课程，通过体育课、阳光体育一小时活动及举办年级和学校体育联赛、运动会，组织与体育相关的社会实践活动等，为学生提供多种形式的体育运动技能学习和比赛的机会。

7.提升艺术素养。学生在校期间自主选择学习1-2项艺术才能，包括音乐、舞蹈、器乐、书法、绘画、手工制作等，并熟练掌握其中一项。学校要结合自身和地方文化特色，根据学生学段特点，构建校本课程，组建不同层次的艺术社团和兴趣小组等，由专业教师进行辅导。通过班级才艺表演、联欢会、学校艺术节等形式，为学生艺术才能的学习和展示提供多种平台和机会。农村学校要充分挖掘利用地方民间文化资源，研究开发简便易学、适合学生特点的艺术项目。

8.提升劳动技能。学生每月至少参加一次学校、家庭或自己选择的劳动活动。通过劳动，掌握一定的劳动技能，培养创新思维和实践能力。学校根据学生年龄、学段特点，明确学生参加日常劳动、家务劳动、校外劳动实践等的要求，结合实际情况设置劳动周或校内义务劳动岗，创造条件与社区、敬老院、校外活动基地等合作开展师生劳动活动。鼓励家长自行安排高年级学生参加社会劳动实践活动。以评选各级各类“劳动明星”等形式弘扬劳动精神，教育引导学生崇尚劳动、尊重劳动，懂得劳动最光荣、劳动最崇高、劳动最美丽。

9.提升探究能力。组织学生每学年参加一次研学活动。引导学生在研学活动中熟知乡土乡情，感知传统文化，感受生活的美好，认识祖国的伟大，增强对坚定“四个自信”的理解与认同，树立社会责任感，学会生存生活，学会做人做事，促进身心健康发展。学校要统筹安排好学生研学活动，按照小学阶段以乡土乡情为主、初中阶段以县情市情为主、高中阶段以省情国情为主的原则有序组织开展。研学活动要有深度广度，有组织有指导，尽可能采取小组合作形式，以学生设计为主、教师指导为辅，注重研学的研究性、延续性。提倡家庭和社会共同参与和以家庭为单位的研学。学生每次研学后，要以图片、文字等多种形式与老师、同学分享研学心得。

10.提升实践能力。学生每学年参加一次力所能及的志愿服务活动。引导学生将服务社会、服务他人与实现个人价值有机结合，加深对公民责任、义务的认识和理解，树立服务国家、社会、他人的责任感。学校要结合实际和学生年龄特点，成立志愿者组织，制定年度志愿服务工作计划，开发可行的志愿者服务项目，确定每学年志愿服务总时数。学校要协调社会各界为学生提供社区、环保、敬老助老以及学校的公益服务岗位等多种校内外志愿服务活动项目，同时，鼓励学生自发参加各种社会志愿服务活动。学生参加志愿服务活动切忌形式化、过场化，要由学校团、队组织做好规范的认定记录，并将参加情况纳入市志愿服务体系。

五、保障措施

（一）加强组织领导。各县区、学校要充分理解行动计划实施的重要意义，切实加强组织领导，成立“一把手”为组长的领导小组，根据基本原则制定符合本县区、本校实际的具体实施方案，做到一校一案。要在“十个提升”的实施推进中及时发现典型，总结经验。市教育局将通过观摩、交流、现场会、成果展示等多种形式推广各县区和学校的创新经验。

（二）加强活动保障。构建行动计划实施的长效机制，市县教育部门围绕“十个提升”定期组织形式多样的比赛或展演活动，为实施“十个提升”提供交流展示平台。市教育局将建立全市“十个提升”人才库，为学校、学生选择学习项目、学习内容提供师资保障和资源保证。加强学生社会实践基地建设，积极推动社会场馆向中小学生免费开放。发挥社会行业协会和企事业单位在“十个提升”项目实施中技术和资源的支持作用。

（三）加大宣传力度。学校要充分发挥主渠道、主阵地作用，利用多种形式加强舆论宣传，积极宣传正确的育人观和科学的教育理念，努力营造全社会理解、关心和支持中小学生“十个提升”项目开展的良好育人氛围。
