# 大同市教育局关于加强学校体育工作的通知

各县(区)教育局、市直各学校:

为贯彻落实《国务院办公厅关于强化学校体育促进学生身心健康全面发展的意见》(国办发[2016]27号)、《山西省人民政府办公厅关于强化学校体育促进学生身心健康全面发展的实施意见》(晋政办发[2018]42号)精神,进一步推动我市学校体育教育改革发展,促进学生身心健康、体魄强健、全面发展,现将《大同市教育局关于加强学校体育工作的通知》印发给你们,请认真贯彻执行。

一、指导思想

以习近平新时代中国特色社会主义思想为指导,深入学习贯彻党的十九大和全国、全省、全市教育大会精神,按照《国家中长期教育改革和发展规划纲要(2010-2020年)》的要求,把强化学校体育作为落实立德树人根本任务、培育和践行社会主义核心价值观、推进素质教育的重要举措,以天天锻炼、健康成长、终身受益为目标,坚持课堂教学与课外活动相衔接,坚持培养兴趣与提高技能相促进,改革创新体制机制,全面提升体育教育质量,健全学生人格品质。

二、总体目标

深入推进学校体育工作评价制度,全面提升学生身心健康水平。学校全部实施《国家学生体质健康标准》,体育课时和锻炼时间切实保证,教学、训练与竞赛体系基本完备。中小学校体育场地、设施器材全部达到《国家学校体育卫生条件试行基本标准》要求;学生体育锻炼习惯基本养成,运动能力和体质健康水平明显提升;体育教师各项待遇得到保障。

三、主要任务

(一)强化体育课程

各级各类学校要严格执行国家课程标准,上足上好体育课,不得以任何理由削减或挤占体育课时。保证小学体育课一、二年级每周4课时,三至六年级每周3课时,初中体育与健康每周3课时,高中体育与健康每周2课时。大力推动足球、篮球、排球、冰雪运动等集体项目,积极推进户外体育运动项目,广泛开展田径、游泳、乒乓球、羽毛球、武术等项目,积极挖掘当地民间体育,充实和丰富体育课程内容,逐步形成“一校一品”“一校多品”,做到人人有项目、班班有特色、校校有品牌。

(二)提高教学水平

学校体育教学要加强健康知识教育,制定开展运动项目指南,大力发展校园足球,提高学生专项运动能力,让学生熟练掌握一至两项运动技能。改革创新学校体育发展模式,逐步建立健全学校体育发展长效机制,充分利用现代信息化技术手段,开发和创新体育教学资源,不断增强教学吸引力。学校要关注学生体育能力和体质水平差异,做到区别对待、因材施教,研究推广适合不同类型学校的体育教学方法,提高体育教学质量。

(三)丰富课外体育活动

学校要坚持以全面实施《国家学生体质健康标准》为基础,以“达标争优、强健体魄”为目标,积极开展“阳光体育运动”,让学生走向操场、走进大自然、走到阳光下。要把课外体育活动、运动队训练及比赛活动纳入学校日常教学计划,积极开展阳光体育运动,开展有计划、有目的、有规律的体育锻炼,确保学生每天1小时的体育活动时间,全面实行每天30分钟大课间体育活动制度。积极创建各种体育项目兴趣小组,鼓励学生自觉参加体育锻炼,改善自身的身体形态和机能,达到体质健康标准。幼儿园要遵循幼儿身心发展规律,开展丰富多彩的体育活动。

(四)推动教体协调发展

学校要遵循教育、体育发展规律,通过整合资源、改善场地设施条件、畅通运行机制,不断提升教体结合工作水平。要定期举办综合性、专项性体育竞赛,每年至少举办一次以学校为单位的夏季田径运动会和秋季田径运动会,组建各类运动队、兴趣小组,开展校际、班际等比赛形式的课余体育活动,不断完善中小学足球、篮球、田径、羽毛球、乒乓球等体育联赛制度,推动校园体育活动持续发展。

(五)加强体育师资队伍建设

加强教师队伍建设,按标准配齐配足体育教师,鼓励优秀退役运动员和有体育特长的志愿人员兼任体育教师。保障体育教师在职称(职务)评聘、福利待遇、评优表彰、晋级晋升等方面与其他学科教师同等待遇。科学核定体育教师工作量,调整学校绩效工资分配方案,把组织开展课外活动、学生体质健康测试、课余训练、比赛等纳入教学工作量。鉴于体育教师从事室外工作的特殊性,学校对每周从事8个学时(含)以上室外体育课的体育教师要根据实际,给予室外工作补助和服装补助。体育教师带队获得体育竞赛优异成绩应与教学科研成绩同等对待,对于带队教师给予适当绩效奖励。

(六)加强学校体育设施建设

要加大学校体育设施建设和器材配备力度。学校要按照学校体育器材设施配备标准和《国家学校体育卫生条件试行基本标准》要求,努力提高学校体育教学条件,把学校体育场地设施列为义务教育学校标准化建设的重要内容,建设好学校体育场地设施、配备好体育器材。鼓励中小学共建共享体育场所,积极推进公共体育场所向青少年学生免费或优惠开放,具备条件的学校体育场所设施试行对社会有序开放。

(七)规范考试评价办法

构建课内外相结合、各学段相衔接的学校体育考核评价体系,规范和完善体育运动项目考核和学业水平考试,将体育科目纳入高中阶段学校考试招生录取计分科目,逐年增加体育科目分值。改革体育课程考核机制,突出过程管理,从学生出勤、课堂表现、健康知识、运动技能、体质健康、课外锻炼和参与活动情况等方面进行全面评价。学校要把学生参加体育活动情况、学生体质健康状况和运动技能等级纳入初中、高中学业水平考试、学生综合素质评价体系。初中、高中学校要积极开展培养体育特长生工作。

(八)加强体育质量监测

各学校要全面实施《国家学生体质健康标准》,建立健全学生体质健康档案,每年对所有学生进行体质健康测试,及时上报测试数据。各县区教育局要加大对学校测试数据的抽测复测力度,确保测试数据真实、有效和完整。健全学生视力健康综合干预体系,保障学生充足睡眠时间,共同呵护好孩子的眼睛,让他们拥有一个光明的未来。

(九)健全风险管理机制

各学校要加强体育运动伤害风险管理,明确安全责任。要将体育活动安全教育纳入日常管理和教学活动,加强对学生的安全教育,提高学生的伤害应急处置和救护能力。对体育器材设施及场地进行安全风险分类管理,建立健全学校体育和学生校外体育活动的安全管理制度。建立完善校园意外伤害事件应急处理机制,加强对大型体育活动的管理,做好应急预案,防止发生群体性安全事件。

四、保障机制

(一)强化督导检查

各学校要强化对体育工作的专项督导,定期开展以保证体育教学课时、落实学生每天1小时体育锻炼时间、实施学生体质健康监测为重点的学校体育工作专项督导检查。对学生体质健康水平持续3年下降的学校,在教育工作评估中实行“一票否决”。

(二)保障经费投入

要切实加大学校体育经费投入力度,把体育专项经费纳入学校年度教育经费预算,并做到与教育总经费同步增长。认真落实体育教师的有关待遇。鼓励和引导社会资金支持发展学校体育,多渠道增加学校体育投入。

(三)营造良好环境

通过多种途径加强对体育工作的宣传力度,营造全社会关心、重视和支持学校体育的良好氛围,开展家校共建共育,布置完成好体育锻炼家庭作业。家校要充分发挥在学生体质健康发展中的主导作用,努力培养学生终身体育意识,养成良好的体育锻炼习惯。
