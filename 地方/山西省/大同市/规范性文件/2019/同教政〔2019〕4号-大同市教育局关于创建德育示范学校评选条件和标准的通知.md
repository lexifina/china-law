# 大同市教育局关于创建德育示范学校评选条件和标准的通知

各县（区）教育局、市直各学校：

为切实发挥德育示范学校示范引领作用，进一步加强全市中小学德育工作，落实立德树人根本任务，积极培育和践行社会主义核心价值观，提升全市未成年人思想道德建设工作水平，促进广大中小学生德智体美劳全面发展，特制定大同市德育示范学校创建标准。

一、必备条件

1、高中、完中、四轨以上学校设立政教处，按规定配齐工作人员；其它学校在教导处配备一名副主任专管。

2、德育经费列入预算，达到生均经费10元/年以上。

3、在校生无违法犯罪现象，无重大伤亡事故。

4、在德育工作的一至两个示范方向上确有特色，达到国内、省内先进水平。

5、学校为县级德育示范学校或德育达标先进学校。

二、基本要求（70分）

（一）领导与体制

1、全面贯彻党的教育方针，坚持社会主义办学方向。建立以校长及行政系统为主实施德育的管理体制，把德育落实在教学、管理、服务各个环节之中。（4分)

2、学校要形成较完备的德育教育体系。以育人为根本，正确处理好德智体美劳之间的关系及德育各部分内容的关系；制定学校德育的长远和近期目标；科学规划各教育阶段的内容、途径、方法，建立完整的德育教育体系。（3分)

3、校长要掌握学校德育基本情况，定期研究德育工作，交流经验。在任期目标中，对学生的道德行为合格率、学困生转化率，法制教育普及率及遵纪守法率有明确的具体指标，并能落实。（3分）

4、学校成立由各处室及有关方面负责同志参加的德育工作领导组，分工明确、职责清楚、考核严格。（3分)

（二）队伍建设与物质保障

1、有一支由政教干部、班主任、政治课、思想品德课教师、党务、团队干部组成的信念坚定、业务精湛的德育工作骨干队伍，并能采取有效措施，优化结构，提高素质，为他们创造必要的工作、学习、进修、培训和参加社会实践等条件。（3分)

2、关心德育工作者的待遇，为他们解决后顾之忧。落实班主任津贴费，从事德育工作应计算教学工作量，在评定职称、晋职晋级等方面，优先考虑师德标兵及班主任。（3分)

3、加强教职工思想政治工作，特别重视师德教育，能做到言传身教、为人师表，无体罚、变相体罚学生现象，对全体学生充满师爱。（2分）

4、为德育工作提供物质保障。切实保证德育经费投入，能解决德育工作人、财、物方面的困难和问题。学校建有德育室或校史室(荣誉室)。学校图书馆、资料室中德育类图书、音像资料占总数的30%。（4分)

（三）规章制度与档案资料

1、建立了一套行之有效的德育工作制度。如教职工育人岗位责任制及考评奖惩办法，教师职业道德考评制度，贯彻落实有关文件、法规的实施方案，德育工作表彰奖励办法，学生在校一日常规，学生德育考核制度，班主任工作条例和学生违纪处理办法等。（4分)

2、建立必要的德育工作档案。如：德育管理、大型活动、班主任工作、团队工作、学困生转化、先进典型、理论研究、学生犯罪及重大事故档案等。（3分）

3、各种资料记载翔实完备，入盒入袋，装订成册。（1分）

（四）内容、途径与要求

1、突出爱国主义、集体主义和社会主义教育。《山西省中小学爱国主义教育实施方案》能得到落实。坚持唱国歌、升国旗制度，国旗下讲话有特色。（4分)

2、坚持不懈地抓好日常行为规范的养成教育。道德行为合格率达98%以上。（3分)

3、教书育人、管理育人、服务育人落到实处。有全员育人岗位责任制并能严格考核。（2分）

4、充分发挥课堂教学主渠道作用。各科教师都能坚持采用“双纲”备课，在教学中有机地渗透思想政治教育。政治课和思品课能联系实际，解决学生的思想问题。（4分）

5、开展适应时代发展、社会进步及改革开放迫切需要的素质教育。重视社会实践和劳动教育，并列入教育计划，切实保证。（4分）

6、重视校园环境、校园文化对学生的熏陶和潜移默化的教育作用。校园文明整洁、有浓郁的育人氛围。（4分）

7、重视学困生转化工作。有具体的管理制度和转化措施，转化率达90%以上。（2分)

8、学校、家庭、社会教育密切配合，效果显著。第二课堂活动丰富多彩，寓教于乐。（5分)

9、对学生的德育考核有一套较科学的标准和方法。（3分）

10、建立德育的政策导向机制。德育考核与教职工晋升职务、职称、评优评先挂钩；与学生的评三好生、优秀干部，毕业、推荐保送生等挂钩。（4分)

11、鼓励教职工积极进行德育理论研究，开展各种学术交流活动。有一批在国内、省内报刊公开发表或受县、市级以上单位表彰的优秀论文。（2分)

三、示范方向（30分）

（一）爱国主义、集体主义和社会主义教育

认真贯彻落实《山西省中小学爱国主义教育实施方案》，有本校的特色；“两史一情”和时事政策教育能贯穿于教育的全过程；严格坚持升降国旗制度，且仪式规范、设施标准；学生会唱国歌，懂得尊重和爱护国旗、国徽；重大节日和传统纪念日能有效地进行爱国主义教育；重视对学生和教职工进行集体主义和社会主义教育；有教育基地、经常开展参观、专访、社会调查、研学实践、夏令营、劳动锻炼等教育活动；结合当地和学校的实际，有条件的可编写爱国主义教育乡土教材。

（二）中华民族优良道德传统教育

以《中国优良道德传统》为教材，结合日常行为规范的贯彻开展有效的教育活动，并能有机地贯穿于教学和教职工言行之中，形成良好的教育氛围；坚持反复教育、长期熏陶，逐步形成有中华民族特色、体现时代精神的价值标准和道德规范。

（三）日常行为规范养成教育

根据学生的心理、生理、年龄和认识能力以及道德品质、行为习惯的形成规律，有重点分层次对学生进行养成教育。有实施细则和长期教育、训练、巩固的措施和办法。要求严格，考核科学，效果明显。

（四）适应时代发展、社会进步和改革开放的素质教育

通过各种有效教育途径和活动，培养学生开拓进取、自强自立、艰苦奋斗的精神；加强法制、社会公德和职业道德教育；按照教学计划，抓好音体美教学，陶冶学生情操，提高艺术修养和欣赏水平；积极开展青春期卫生教育和心理健康教育，帮助学生提高心理素质、健全人格、增强承受挫折、适应环境的能力。

（五）全员育人和教学主渠道渗透教育

加强教职工的思想政治工作，做到言传身教，为人师表；制定和完善各种岗位育人责任制，把育人的任务落实到学校教学、管理、后勤服务的各个岗位和环节上；充分发挥课堂教学主渠道作用，教师要做到“双纲”备课，认真挖掘教材中的德育因素，在教学中有意、有机、有效地渗透思想品德教育，做到工作有计划、备课有内容、讲授有体现，学校对渗透教育有要求、有检查、有总结、有典型，定期开展渗透观摩教学、示范课等教学研究活动，不断提高渗透教学水平。

（六）校园文化及环境育人

根据学校和学生特点，开展喜闻乐见、丰富多彩的科技、文化、体育、美育及各种娱乐活动；有德育室、校报、板报、广播、读报栏、校风、校训；教室、图书馆、礼堂等场所悬挂名人画像、爱国诗词、格言，打造书香校园；校园绿化、美化、净化、文明整洁，形成积极向上、健康生动的校园文化氛围，充分发挥校园文化对学生的熏陶教育作用。

（七）国情和时事政策教育

以《国情教育读本》和《中学时事报》为基本教材，并结合学校实际和学生思想实际，开展系统深入的国情和时事政策教育，并在课时、教师、辅导、实践上能得到切实保证，在课堂教学中得到渗透，培养学生关心国家大事、了解国情，要逐步树立正确的政治观点和价值观。

（八）学校、家庭、社会三结合教育

成立了学校家长委员会或家长学校，采用《家长周报》或其它家庭教育教材和资料，对家长讲授科学育人的方法，为子女提供健康的家庭育人环境，建立教师家访、校长接待家长日等制度，及时沟通家校间联系；大力培养家庭教育指导教师，充分发挥优秀家长资源，争取社会各方面的有力支持和配合，形成教育合力，共同关心下一代健康成长。

（九）社会实践与劳动教育

对社会实践和劳动教育有总体规划和具体规定，列入教学计划，在时间、内容、组织、基地、指导教师上得到落实，并能进行认真的考核和总结表彰。有计划地组织学生参加社会调查、生产劳动、科技文化服务、军事训练、参观专访等实践活动。

（十）政治课和思想品德课教学改革

能联系学生思想实际、改革开放和现代化建设的实际，有针对性地进行生动活泼的教育，解决学生的思想实际问题。积极进行教学内容、教学方法的改革，引导学生确立为建设有中国特色社会主义而奋斗的政治方向。

（十一）学生德育考核

对学生的道德品质的考核初步形成一套较科学的考核标准及办法，以写实为主的操行评定能较准确地反映出学生的品德全貌。考核的结果能与毕业、推荐免试生等挂钩，起到正确的导向作用。

（十二）德育理论研究

注重德育理论研究，积极引导教师研究探索学生道德品质、行为习惯、心理素质等发展规律，撰写出一批水平较高的研究成果论文。

（十三）国防教育和军训

通过各科教学渗透国防教育，增强学生的国防意识，坚持对高中学生的军训工作。聘请解放军校外辅导员，对学生进行革命英雄主义和革命传统等教育。

（十四）社会主义核心价值观教育

学校要全面贯彻党和国家的教育方针，坚持育人为本、德育为先，实施素质教育，促进学生健康成长，培养德智体美劳全面发展的社会主义建设者和接班人，把社会主义核心价值观融入学校教育教学各个方面和各个环节。

开展“德育示范学校”创建工作，是树立德育工作示范、创新德育工作新局面，引领全市德育工作进一步发展的重要举措。各县（区）教育局、市直各学校要高度重视，根据上述示范方向，结合各自实际，选择两至三个方向，进行重点示范，认真对照创建标准，扎实做好德育工作，重创建、重过程、重提升，并进行广泛宣传，有计划、有步骤地做好创建工作，并逐步创新总结出有自己特色的经验。
