# 大同市文化和旅游局关于进一步加强“二青会”期间文化娱乐场所及A级旅游景区火灾防控工作的通知

各县(区)文化和旅游主管部门,局属各单位,各文化娱乐场所和A级旅游景区:

根据山西省消防救援总队关于加强“二青会”期间文化娱乐场所及A级旅游景区火灾防控工作的要求,进一步做好“二青会”期间全市文化旅游行业火灾防控工作,严防火灾事故发生,为“二青会”的胜利召开创造安全稳定的环境,现将有关工作要求通知如下:

一是提高认识抓落实。我省“二青会”即将召开,各县(区)文化和旅游主管部门及各级文化市场综合执法机构要切实提高政治站位,严守不发生火灾安全事故底线。严格按照《中华人民共和国消防法》和《消防安全责任实施办法》有关规定以及“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求,研判火灾形势,深入查找薄弱环节,全面开展文化旅游企业火灾安全整治工作。适时组织本辖区企业消防安全责任人和管理人进行一次消防安全约谈培训,明确岗位职责,切实将消防安全责任落实到岗位,明确到个人,层层压实工作责任。

二是全面排查除隐患。各县(区)文化和旅游主管部门及各级文化市场综合执法机构要对辖区内文化娱乐场馆图书馆、A级旅游景区、游客接待中心逐个全面排查,并及时向当地消防部门通报隐患问题,共同督促企业整改落实。积极推动直属单位和行业单位建好用好微型消防站,充分发挥其消防宣传、检查和灭火的职能作用。

三是联合督查遏事故。在“二青会”期间,各县(区)文化和旅游主管部门要与当地应急管理、消防等部门联合开展督导检查,督促企业落实消防安全防范措施。对文化娱乐场所、图书馆、A级旅游景区、游客接待中心发生火灾事故的要严格追究责任,既要查原因,也要查责任、查教训,达到处理一片、警示一片、规范一片的效果。
