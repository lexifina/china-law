# 大同市文化和旅游局关于切实加强文化娱乐场所及星级饭店火灾防控工作的通知

各县(区)文化和旅游主管部门,局属各单位,各文化娱乐场所和星级饭店:

为深入推进“防风险保平安护二青迎大庆”消防安全执法检查专项行动,确保全市文化和旅游行业消防安全形势平稳,根据市消防安全委员会《关于切实加强文化娱乐场所及宾馆酒店火灾防控工作的建议函》要求,进一步加强文化娱乐场所及星级饭店火灾防控工作。现将有关工作要求通知如下:

一、认真梳理风险隐患,进一步提高火灾危险性认识

一是一些文化娱乐场所附设在其他商场、市场、宾馆、酒店等公共建筑物内,有的设在地下室或半地下室内,与其他部分建筑空间没有完善的防火分隔措施;大部分星级饭店也是高层建筑,楼梯间、电梯井、电缆井等竖井林立,且有的未采取防火封堵措施,一旦发生火灾,火势迅速蔓延,扑救难度大。

二是文化娱乐场所和星级饭店的经营者为了吸引顾客,提高场所档次,都要对场所内部进行装饰装修,而且使用大量易燃、可燃材料装修以及生活用品和办公用具,发生火灾时燃烧迅猛易产生有毒气体,影响人员疏散逃生。

三是文化娱乐场所一般采用多种照明和各类音响设备,且数量多、功率大,如果使用不当,容易造成局部过载、短路等而引起火灾;有的文化娱乐场所在营业时还需要使用各类明火或热源,如果管理不当也会引发火灾;星级饭店场所吸烟人员多,尤其是有的客人酒后在客房吸烟,乱扔烟头,极易引发火灾。

四是有的文化娱乐场所、图书馆、星级饭店的安全出口设置数量、设置位置、安全疏散距离、安全疏散指示标志不符合防火设计规范要求,发生火灾严重影响人员疏散逃生。

五是文化娱乐场所、图书馆、星级饭店等单位营业期间人员集中、流动性大,外来人员对建筑内部环境不熟悉,且客房密闭性强,发生火灾不易被发现,人员疏散逃生不及时,容易造成重大伤亡。

二、切实抓好整改落实,进一步降低火灾风险隐患

各县区文化和旅游部门及各级文化市场综合行政执法机构要按照“属地管理”、“管行业必须管安全”的要求,督促各类文化娱乐场所、星级饭店等单位落实消防安全主体责任,加强营业期间防火巡查检查,落实消防安全“三提示”要求,保持疏散通道、安全出口畅通和消防设施器材完好有效,严格用火用电安全管理,加强培训演练和应急值守,坚决遏制重特大火灾事故发生。

一是听取一次火灾防控工作情况专题汇报,重点对文化娱乐场所、图书馆、星级饭店等单位火灾形势进行分析研判,找准薄弱环节和风险隐患,制定一份加强和改进本部门消防安全工作的方案或措施,深入推进文化和旅游系统火灾防控工作,加强调度通报,强化督查检查,抓好工作落实。

二是组织各类文化娱乐场所、图书馆、星级饭店等单位消防安全责任人、管理人进行一次消防安全约谈培训,开展一次火灾警示教育,督促开展“六个一”活动(开展一次消防安全自查,列出一份隐患整改清单,向社会作出一次整改承诺,对消防设施进行一次维护保养,组织一次全员“一懂三会”培训,开展一次应急演练)。

三是会同当地消防部门选取部分大型文化娱乐场所、图书馆、星级饭店开展示范性检查,重点检查各级岗位人员履职,疏散通道、安全出口畅通,用火用电安全管理,消防设施器材完好有效,值班巡查落实等情况,提升行业消防监管水平。选取部分日常消防安全管理规范的单位,通过典型培育和示范引领,推动行业消防安全标准化管理。

四是推动大型文化娱乐场所、图书馆、星级饭店等单位建好用好微型消防站,进一步细化应急预案,加强培训演练,落实值班值守,充分发挥其消防宣传、检查和灭火的职能作用。

五是严格责任追究,对文化娱乐场所、图书馆、星级饭店发生火灾事故的,既要查原因,也要查责任、查教训,通过严惩责任单位和有关部门责任,达到处理一起、警示一片、规范一方的效果。
