# 关于建立健全基本公共文化服务城乡联动机制的通知

各县(区)文化和旅游局、各相关单位:

为全面贯彻落实中央、省、市关于推进现代公共文化服务体系建设的要求,进一步加强大同市基层公共文化服务均等化、标准化建设,积极推进基本公共文化服务城乡联动机制,保障城乡群众基本文化权益,实现文化资源共建共享。特做以下具体安排:

一、纵向联动

(一)文化重心下移方面。实施“送文化”,推动文化重

心下移到基层、到群众;实施流动文化服务、文化服务“四进”

(进社区、进校园、进企业、进乡村)工程、文化馆图书馆总分馆制建设、提升农家书屋、大型文化活动下乡、文化队伍下基层、广播电视“村村通”工程等项目。

(二)培植文化沃土方面。通过各种途径不断开拓渠道,提升群众的文化知情权、参与权和监督权,使文化之树在群众之中真正发芽开花;创建地方性文化活动品牌,通过挖掘、开发农村优秀民间文化资源,培育乡村特色文化,逐步形成“一乡镇(街道)一特色”、“一村(社区)一活动”的文化活动品牌;开展群众性教育培训,市级文化主管部门要在乡镇(街道)一级广泛开展群众性专艺专能、文娱休闲、文化欣赏等方面的培训或讲座;加强志愿者队伍建设;各乡镇(街道)要切实解决社区和乡村文化服务人才不足的问题,通过发动、组织并对部分志愿群众进行专门或专业性培养锻炼,在地方文化服务中充分发挥作用。

(三)乡土文化展示方面。鼓励乡土文化演出,每年以文化庙会、民俗文化大展演、云冈文化旅游系列活动、群众文化系列活动、戏剧票友大赛、广场舞展演、合唱比赛、八音会比赛等大型文化活动为平台,以传统节日、重要纪念日、大型节庆会展为契机,选派各地群众性特色文化剧目参与演出;举办乡土文化比赛,以各级相关机构和单位举办的文体比赛为载体,积极发动组织基层群众,通过激发他们的文化创作和表演热情去参与竞争,发现、锻炼群众文艺骨干,培养乡土文化能人。

二、横向联动

一是要促进文化流动,以搞活“一盘棋”,破除传统体制分灶吃饭的旧格局作为指导思想,各乡镇(街道)、各村(社区)之间要加强文化交流,取长补短,互相促进,共同提高。

二是要发展特色地方文化,各乡镇(街道)要出台培育发展地方特色文化的支持政策,并有意识地组织辖区内的有关村(社区)加强联动,互相交流学习,以形成丰富多彩、花色多样、项目齐全、互为补充的公共文化体系。

三是要构建信息平台、实现信息共享,各乡镇(街道)要以网站的形式创建公共文化服务信息平台,通过信息共享,加强各地之间的文化活动和文化服务联动。

三、内部联动

一是要创新人才流动机制,市直有关文化服务部门要大胆创新人才管理体制,制定灵活的人才政策,在人才建设、人才使用方面独辟蹊径,松绑传统人才聘用、交流方面的约束条件,实现各类文化服务演职人员、管理人员在不同部门之间的动态交流和柔性聘用,做到人尽其才、才尽其用。

二是要共建共享资源,市直各文化服务有关部门要充分发挥主人翁精神,充分利用各自管辖的各种文化资源,开放给广大城乡群众使用。市级文化馆、博物馆、图书馆、职工活动中心、青少年校外活动中心等综合性文化服务设施,以及各乡镇(街道)综合文化站、各村(社区)文化服务中心要切实提供各种文化服务,真正实现公共文化服务资源共享。
