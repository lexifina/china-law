# 大同市文化和旅游局关于印发《国家级非物质文化遗产代表性项目代表性传承人传承活动评估工作方案》的通知

各县(区)文化和旅游局,市非遗保护中心,市直有关单位:

按照山西省文化和旅游厅关于印发《国家级非物质文化遗产代表性项目代表性传承人传承活动评估工作方案》的通知(晋文旅发﹝2019﹞31号)要求,结合我市实际,制定我

市国家级非物质文化遗产代表性项目代表性传承人传承活动评估工作方案。现印发给你们,望认真贯彻落实。

大同市文化和旅游局

2019年4月3日

国家级非物质文化遗产代表性项目代表性传承人传承活动评估工作方案

按照文化和旅游部非物质文化遗产司有关要求,结合我市实际,制定我市国家级非物质文化遗产代表性项目代表性传承人传承活动评估工作方案。

一、评估目的

激励国家级代表性传承人更好开展传承活动,促进非物质文化遗产代表性项目传承发展。

二、评估对象

我市国家级代表性传承人。

三、评估方式

由省文化和旅游厅组织实施,做到国家级代表性传承人自我评估、文化和旅游行政部门实地评估和第三方评估相结合,确保评估结果客观公正。

四、组织机构

根据工作需要,成立国家级非物质文化遗产代表性项目代表性传承人传承活动评估工作组。

组长:李吉

成员:非遗科有关人员、市非遗保护中心有关人员、各县区文化和旅游局非遗科(非遗保护中心)有关人员。

主要职责:审定我市国家级非物质文化遗产代表性项目代表性传承人传承活动评估工作方案,对评估各阶段工作实施统一领导和督查;统筹我市评估工作、组织专人对国家级传承人准备的实证资料进行检查核实,并按照评估指标量化打分;进行评估工作总结。

五、评估内容

此次评估工作重点是对近两年来国家级代表性传承人传承活动开展情况进行评估,包括以下内容。

(一)授徒情况。包括所带徒弟基本信息及其掌握核心技艺状况等。

(二)传艺情况。包括向相关群体如青少年学生传艺情况,参加非遗进校园普及教育活动等。

(三)参与宣传和交流情况。包括参加非物质文化遗产展览、展示以及各种群众性活动;参加对外、对港澳台文化交流活动;参加研讨、座谈、讲座、培训活动等。

(四)项目实践情况。包括从事生产、表演、创作等实践活动。可根据项目类别和国家级代表性传承人实际情况,确定评估内容。

(五)项目资料收集、整理、保存和研究情况。包括收集、保存相关实物或者资料、配合开展非物质文化遗产调查和传承人记录;自行开展或者参与非物质文化遗产整理、研究活动等。

(六)其他相关情况。包括是否变更国籍,在项目所在地社区开展传承情况,以及遵纪守法、社区认同和社会影响等情况。

(具体评估指标请参照附件1)

六、评估结果

根据评估情况,评定该国家级代表性传承人年度传承实践情况的等次,设优秀、良好、一般、不合格等四个档次。

七、工作安排

(一)时间安排

国家级代表性传承人自我评估:2019年4月15日前。

市级文旅部门评估:2019年5月31日前。

省文化和旅游厅及第三方评估:2019年6月20日前。

(二)任务安排

1.自评阶段

由各市文化和旅游行政部门联系协调所属地区的国家级代表性传承人,学习传达评估工作精神,具体负责评估方案的实施,指导国家级代表性传承人按照评估方案要求开展自我评估,做好有关材料的收集、整理和展示工作。

市级文化和旅游行政部门组织专人对国家级传承人准备的实证资料进行检查核实,并按照评估指标量化打分(参照附件2)。

国家级代表性传承人所在项目保护单位为省直的,由项目保护单位负责开展此项工作。

2.抽查阶段

根据各地工作进展和自评情况,评估组适时开展实地督导和抽查评估。

3.总结阶段

各市文化和旅游局、省直有关单位要做好评估工作的总结梳理工作,形成总结报告。报告应包括评估工作基本情况、基本做法、经验及问题等(字数控制在2000字左右),并于2019年6月20日前提交至省文化和旅游厅。

(三)资料准备

1.国家级代表性传承人。对照评估方案,搜集整理与本人年度开展传承活动相关的文本、影像等资料,并逐条对应、有序保管。传承人所在项目保护单位应积极做好协助、协调等配合支持工作。

2.市级文化和旅游行政部门。按照通知要求,提交本市国家级非物质文化遗产代表性项目代表性传承人传承活动评估汇总表(参照附件3)、评估工作总结,需加盖公章(电子版一并提交)。(项目保护单位为省直的,同上)

八、工作要求

（一）高度重视,加强组织协调。各市、各有关部门要高度重视评估工作,准确把握评估方案具体要求,加强与国家级代表性传承人的沟通协调。项目保护单位要压实责任,精心准备相关资料,做到事事有印证,以评估促进优秀传统文化创造性转化创新性发展。

(二)严格标准,精心组织实施。评估工作以鼓励、支持和促进国家级代表性传承人更好开展传承活动为出发点,以工作实绩为核心,以评估指标为准绳,以评估结果为导向,充分体现工作推进、目标达优的总体要求。

(三)狠抓落实,全力推进评估。坚持实事求是、客观公正,准确反映国家级代表性传承人传承活动开展情况。鼓励创新,探索建立便捷有效的国家级代表性传承人传承活动评估机制。评估人员要及时、准确地掌握标准、了解实情,严格把关,全面、客观、合理、公正评估每名国家级代表性传承人传承活动开展情况。
