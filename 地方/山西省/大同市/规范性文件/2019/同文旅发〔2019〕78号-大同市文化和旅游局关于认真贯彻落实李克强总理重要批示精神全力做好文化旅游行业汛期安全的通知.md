# 大同市文化和旅游局关于认真贯彻落实李克强总理重要批示精神全力做好文化旅游行业汛期安全的通知

各县(区)文化和旅游主管部门,局属各单位,各文化旅游经营单位:

5月31日,李克强总理就今年防汛抗旱工作做出重要批示,要求加强协调配合,落实安全责任,防患未然,务必把确保人民生命财产安全工作落实到位。目前,我国已进入汛期,各地旅游旺季即将到来。受异常气候影响,山丘区、滨海、河湖沿岸景区极易发生山洪、泥石流、台风暴潮等洪涝灾害,严重威胁游客人身、财产安全。为了进一步贯彻落实李克强总理重要批示和省委省政府、市委市政府有关加强对汛期安全管理工作的安排部署,强化全市文化旅游行业汛期安全工作,严防安全责任事故发生,现将有关事项通知如下:

一、提高认识,严格落实安全责任

汛期强降水、山洪、泥石流、雷电、高温等自然灾害频发,极易引发旅游安全事故,各县(区)文化旅游主管部门和旅游经营单位要进一步提高思想认识,加强安全监管,重点落实安全生产企业主体责任。各部门、各单位主要负责人要高度重视汛期旅游安全工作,亲自部署,明确重点,按照汛期旅游的规律和特点,突出抓好防暑降温、防雷防汛、防山洪暴发、防地质灾害为重点的汛期旅游安全工作,坚决克服麻痹思想和侥幸心理,有效预防各类旅游安全责任事故发生。

二、结合实际,做好安全隐患排查

各县(区)文化旅游主管部门和旅游经营单位要结合本地区、本单位情况,制定汛期旅游安全检查方案,全面、扎实、有效地开展安全隐患排查工作,及时消除隐患。

一是各旅行社要做好汛期的交通安全等工作。各旅行社在组(接)团之前,要合理安排行程,禁止组团前往正在发生强降水、山洪、滑坡和泥石流等地质灾害的地区旅游,慎重组团到自然灾害易发地旅游;要选择有资质的旅游客运公司,签订规范的租车合同,明确安全保障责任,提供安全优质服务;要加强导游和领队的安全培训教育,加强对游客夏季出行安全教育和指导,坚决禁止在恶劣天气下组织游客参加漂流等旅游项目,对自行参加漂流项目的游客要耐心劝阻;导游员要起到“交通监督员、安全宣传员”的作用,汛期行车时要监督驾驶员,严禁疲劳驾驶、酒后驾驶、无证驾驶、超载、超速等违法行为,要提醒司机注意交通安全及减速慢行,在途经危险路段或游览水上项目要提醒游客注意安全。对老龄和学生团队应当采取积极有效措施,随时清点游客人数,确保游客人身和财产安全。

二是A级旅游景区要切实加强防洪涝灾害、泥石流、滑坡等工作。各旅游景区要制定雨季抢险应急预案,对易滑坡、垮塌的地段进行全面检查,进行加固处理;要加强易受高温、雨水损害和影响的大型娱乐设备、索道、电梯等特种设备的检修维护工作;要在易遭受雷击的游览区域加设避雷装置和警示牌,遇到雷雨天气,要对游客进行疏导,防止洪涝灾害及泥石流、滑坡等带来的危害,根据情况及时关闭相关的设备设施和游乐项目;要加强景区内道路、桥梁、隧道、涵洞、边坡和车辆、船舶的日常维护,加强水上项目的安全管理,严格监测监控,及时发现隐患排除险情;要加强景区内餐饮点食品卫生管理;要加强工作人员夏季安全防范应急救助能力培训;要密切关注当地气象部门的预报预警,做好游客安全警示工作,在极端天气来临之前,立即停业撤人,严防自然灾害引发安全事故。

三是各旅游星级饭店要针对汛期易发生安全生产故障和问题的部位,采取有效措施,加以防范。要切实加强疏散通道、消防设施、应急广播和照明及火源、电源安全检查;要加强电梯、锅炉、高压容器等设施设备安全检查及日常维护;要加强暑期食品卫生安全管理,防止因食物霉变导致的食物中毒事件发生;要规范消防室、监控室等关键岗位工作人员的管理,认真落实安全生产突发事件应急预案,及时消除各种安全生产隐患。

三、强化值守,确保信息畅通无阻

各县(区)文化和旅游主管部门和旅游经营单位在汛期期间要严格落实领导带班、应急值班制度,安排专人24小时值守。值班人员要尽职尽责,坚守岗位,提高应急意识,确保信息畅通、反应敏捷、处理果断、化解及时。遇到突发事件要按规定及时处置并如实上报,不得故意迟报、漏报或瞒报。
