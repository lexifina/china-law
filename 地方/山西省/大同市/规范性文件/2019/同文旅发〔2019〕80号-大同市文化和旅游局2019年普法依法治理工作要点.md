# 大同市文化和旅游局2019年普法依法治理工作要点

2019年是新中国成立70周年,是深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神的重要一年,也是决胜全面建成小康社会的关键之年。市文化和旅游局普法依法治理工作的总体思路是:以习近平新时代中国特色社会主义思想为指引,认真贯彻落实全市“七五”普法规划,严格贯彻“谁执法谁普法”普法责任制,进一步深化文化和旅游系统普法依法治理,充分利用“5.19”中国旅游日、文化和自然遗产日、“9.27”世界旅游日、“12.4”国家宪法日等重要宣传节点,切实推动普法宣传工作,切实加大全民普法力度,建设社会主义法治文化,树立宪法法律至上、法律面前人人平等的法治理念,努力提高法治宣传工作的满意度,深入推进法治大同建设。

一、强化法治宣传教育

1、深入学习宣传习近平新时代中国特色社会主义思想。学懂弄通做实党的十九大精神,真正用习近平新时代中国特色社会主义思想武装头脑、指导实践、推动工作。以庆祝新中国成立70周年为契机,大力宣传党的十八大以来国家法治建设取得的新成就,推动文化旅游系统坚定不移走中国特色社会主义法治道路,积极培育社会主义法治文化,加大全民普法力度,持续增强人民群众在法治建设中的获得感、幸福感、安全感。

2、深入学习宣传习近平总书记全面依法治国新理念新思想新战略。局党组理论学习中心组带头开展习近平总书记全面依法治国新理念新思想新战略学习,大力宣传改革开放40周年特别是党的十八大以来我国法治建设的新成就,结合“不忘初心、牢记使命”主题教育,深入学习宣传党内法规,突出学习宣传新修改的党章,推动全体党员干部牢固树立“四个意识”,坚定“四个自信”,坚决维护党中央权威和集中统一领导,使文化和旅游系统深入了解和掌握全面依法治国的重大意义和总体要求,更好地发挥法治的引领和规范作用。

3、突出宪法宣传教育。坚持把学习宣传宪法摆在首要位置,认真组织实施宣传宪法。积极组织开展“宪法进机关”“宪法进院团”“宪法进剧院”“宪法进景区(景点)”“宪法进市场”“宪法进宾馆”等六进活动,认真组织好“12.4”国家宪法日和宪法宣传周集中宣传活动,灵活利用“5.19”中国旅游日、文化和自然遗产日、“9.27”世界旅游日等宣传平台,大力开展宪法等相关法律法规的宣传活动,弘扬宪法精神、弘扬社会主义法治精神,扩大普法覆盖面,不断增强人民群众宪法意识。

4、深入学习宣传党内法规。加强党内法规的学习宣传,重点学习宣传新修订的党章,积极利用“两学一做”学习教育载体,充分发挥“三会一课”“主题党日”等教育形式,全面提高党内法规宣传教育实效。在“七一”前后集中开展党内法规专题学习、知识竞赛等形式多样的活动,教育引导广大党员干部做党章党规党纪和国家法律的自觉尊崇者、模范遵守者、坚定捍卫者。

5、深入学习宣传相关业务法律法规。将法治宣传教育与市委、市政府的中心工作紧密结合,与文化旅游中心工作紧密结合,与服务市场、游客紧密结合,重点学习宣传法治政府建设、机构改革、文化旅游、地方法规、信访维稳、安全生产、环境保护、脱贫攻坚、能源革命等重点工作相关的法律法规,为文旅工作的顺利推进营造浓厚的法治氛围。丰富学法内容,学习宣传与文化旅游行业领域业务密切相关的专业法律知识。广泛宣传《中华人民共和国旅游法》《中华人民共和国非物质文化遗产法》《中华人民共和国行政处罚法》以及《山西省旅游条例》《大同市旅游条例》《大同市古城保护管理条例》等地方性法规,不断增强文化旅游业务法律法规的社会知晓度,确保地方性法规的贯彻实施。

二、开展主题法治宣传教育

6、服务“文旅振兴”战略。组织开展“文旅振兴,法治同行”主题法治宣传活动,组织编写文化、旅游法律法规汇编、典型案例等宣传资料,推进“法治大同”。围绕防范化解重大风险,加强相关法律法规学习宣传,提高运用法治思维和法治方式化解风险的能力。围绕“文旅振兴”战略,加强文化旅游法律法规的宣传普及,让文化旅游法治观念深入人心。

7、继续深化扫黑除恶专项斗争法治宣传。持续开展“典型案例、法治文化”活动,充分发挥法律顾问作用,增强开展扫黑除恶法治宣传的针对性和有效性,进一步宣传发动群众、警示震慑犯罪,营造文化旅游行业“扫黑务尽、除恶务净”的浓厚氛围,有效打击黑恶势力,维护社会和谐稳定,切实增强人民群众获得感、幸福感和安全感。

8、以人民为中心开展主题法治宣传。以提升人民群众对公共法律服务的知晓率、首选率、满意率为着力点,把法治宣传教育融入公共法律服务全过程,大力宣传诉讼、行政复议、仲裁,调解、信访等方面的法律法规,切实提升广大市民游客依法表达诉求,维护合法权益的意识和水平。

9、着力培育青少年法治信仰。认真贯彻落实《青少年法治教育大纲》和《关于加强青少年法治教育实践基地建设的意见》,利用文化宣传专栏,创排普法舞台剧,编印法律案例小节目等形式,发挥文化旅游普法宣传平台作用,构建学校、家庭、社会“三位一体”的青少年普法模式,充分发挥爱国主义教育基地和红色旅游作用,继续开展以学习宪法为主题的第二课堂和社会实践、红色革命教育活动,推动建立青少年法治宣传教育基地和在中小学设立法治知识课程试点。

三、落实“谁执法谁普法”普法责任制

10、强化“谁执法谁普法”责任落实。结合机构改革,编制文化旅游普法责任清单,明确科室(部门)普法职责任务、方法举措,健全工作制度,实现普法责任对国家机关的广泛覆盖,将“谁执法谁普法”责任人的履职情况纳入年度考核,组织开展文化旅游行业领域“谁执法谁普法”履职评议活动,进一步完善“谁执法谁普法”效果评估。制定文化市场综合行政执法清单,全面梳理执法事项,厘清文化旅游、广播电视、新闻出版、版权电影、文物流通等领域执法权限,整合执法力量,巩固完善“谁执法,谁普法”的普法责任制。

11、持续推进机关干部学法用法。积极参加网上在线“宪法法律学习”,健全机关学法制度,把学法内容纳入机关学习计划,完善学法培训、登记备案等制度;加强机关学法阵地建设,既要依托现有学习园地,也要充分利用单位网站、微信开辟学法专栏。加强贯彻落实情况督导检查,加强法治宣传工作的实效性测评,切实推动面向文化旅游行业领域的法治宣传教育工作。

四、深入推进社会主义法治文化建设

12、推进法治文化阵地建设。加强对法治文化场馆建设的指导,充分发挥图书馆、文化馆现有文化阵地功能,搭建普法宣传平台,努力提升法治宣传教育覆盖率,推动法治文化宣传栏、法治宣传长廊、法治图书室(架)、法治文化墙等阵地建设,力争2019年底实现全覆盖。

13、积极组织开展法治文化活动。加强广播电视等主流媒体法治宣传功能,积极创作普法栏目剧等法治节目,继续推广普法短剧、普法微电影等普法模式。发扬优秀传统文化和历史人文优势,支持文艺院团创作融入法治元素的晋剧、罗罗腔、歌舞等文艺作品开展法治宣传。以文化惠民演出、送戏下乡活动为契机,用话剧《暖泉》、现代耍孩剧《净土》等文艺作品充分体现法治理念,以创排更多的文艺作品形式,生动实践法治宣传精品节目,不断丰富法治文化活动内容。

五、推进多层次多领域依法治理

14、推动法治教育与道德教育深度融合。深化社会主义核心价值观学习教育实践,组织开展培育和践行社会主义核心价值观主题宣传教育活动。贯彻落实《关于进一步把社会主义核心价值观融入法治建设的指导意见》,推进核心价值观融入法治建设,大力弘扬中华优秀传统文化,汲取中华法律文化精华,把法治精神融入乡规民约、家风家训。加强社会主义法治文化建设,广泛开展群众性法治文化活动,满足人民群众日益增长的法治文化需求。

15、组织文艺院团、学校、协会等文化旅游行业领域基层单位开展普法依法治理工作。推动“法律进院团”“法律进企业”和“诚信守法企业”创建等活动,开展树立守法诚信企业家、标杆企业等活动,推动基层单位不断丰富创建内容和形式,增强创建实效。

六、探索推进“智慧普法”

16、加快建设“智慧普法”平台。把“智慧普法”作为提升普法工作实效、增强群众满意度的当务之急,通过现有景区大数据和智能平台,及时了解分析群众法治需求,开辟智慧普法平台,精准推送法治内容,开展体验性、互动式普法新模式。

17、加强新媒体技术普法。充分发挥两微一端等新媒体普法的带动作用,广泛开展“互联网+普法”“新媒体普法”工作,积极运用小程序、小游戏开展普法,提升普法的趣味性。

七、贯彻落实依法治市相关工作

18、贯彻落实市委全面依法治市委员会办公室的决定事

项和工作部署,做好各项工作的协调、督促、检查、推动,促进协作配合,问题共治、工作联动、形成合力。进一步健全普法依法治理工作机制,加强普法依法治理工作自身建设,加大普法依法治理工作的宣传力度。

八、提升普法依法治理工作满意度

19、牢固树立普法依法治理理念。提升普法依法治理工作在文化旅游行业领域的具体实践,坚持人民群众满意度是我们工作根本的落脚点,把人民群众满意不满意作为衡量工作的基本标准,做到普法宣传内容为群众所需、方式为群众喜闻乐见、成效由群众评判。

20、改进和规范检查考核工作。坚持以问题为导向,尽快补齐短板,找准突破口,挖掘工作潜力,注重工作实效,推动文化和旅游系统普法依法治理工作扎实开展。
