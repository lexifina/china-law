# 大同市教育局关于印发《全市教育系统进一步规范中小学校道德与法治课、思想政治课和共青团、少先队活动工作方案》的通知

中小学校道德与法治课、思想政治课

和共青团、少先队活动工作方案

为实施好《中共中央国务院关于进一步加强和改进未成年人思想道德建设的若干意见》、《国家中长期教育改革和发展规划纲要（2010-2020年）》精神，贯彻落实习近平总书记《在学校思想政治理论课教师座谈会上的重要讲话》和《在纪念五四运动100周年大会上的重要讲话》精神，根据国家中小学德育课程标准、共青团、少先队活动课指导纲要要求，现就进一步规范全市中小学校道德与法治课、思想政治课和共青团、少先队活动制定如下方案。

一、指导思想

以习近平新时代中国特色社会主义思想和党的十九大精神为指导，全面贯彻党的教育方针，坚持立德树人根本任务，以培育和践行社会主义核心价值观为主线，充分发挥学校教育主阵地作用，办好人民满意的教育，努力培养担当民族复兴大任的时代新人，培养德智体美劳全面发展的社会主义建设者和接班人。

二、主要措施

（一）进一步规范开展道德与法治课、思想政治课等德育课程。中小学德育课（道德与法治课、思想政治课）是落实立德树人根本任务的关键课程，集中体现国家意志和社会主义核心价值观的教育要求，具有思想性、实践性、开放性、综合性等特征，是学校德育工作的主渠道和主阵地。

1.开齐开足道德与法治课、思想政治课。要严格按照国家规定规范课程开设和课时设置，《道德与法治》课在小学每周2课时，初中每周3课时，《思想政治》课在高中每周2-5课时。确保课程开齐、课时开足，不得随意增减课程和课时。

2.积极实施各学科的德育渗透。落实道德与法治课、思想政治课课程标准要求，寓德育于学科教学内容和教学过程之中，组织各学科教师深入钻研教材，挖掘教材中所蕴含的德育内容，开展学科德育渗透方面的专题优质课、示范课比赛，进一步强化对各学科德育渗透内容的教学评估，使德育渗透科学化、经常化、系列化。

3.加强道德与法治课、思想政治课教师队伍建设。要配齐配强师资力量，选拔政治素质高、个人品德好、业务能力强的教师担任道德与法治课、思想政治课教师，学校书记、校长要亲自讲授思政课，大型集会活动要进行思想品德教育。要加强对道德与法治课、思想政治课教师的培养培训，提高课程实施能力，促进专业发展，提高教育质量。要建立完善激励和保障机制，创设良好的政策环境、工作环境和生活环境，充分调动教师的积极性和创造性。

4.开发实施道德与法治课、思想政治课校本教材。要以促进学生的思想品德教育为目标，结合实际，开发满足学生个性化发展需要的道德与法治课、思想政治课校本课程。要加强对中小学校开发校本课程的指导，抓好试点，逐步推开。要通过开展班队活动、道德实践活动、学校专题活动等形式，组织道德与法治课、思想政治课校本课程的实施。

（二）规范中学共青团工作。青少年是祖国的未来、民族的希望，中学共青团在学校育人工作中承担着重要职能。要切实加强中学共青团工作，有针对性地开展面向学生的思想引领和成长服务工作，帮助他们树立理想信念，养成良好品德，提升综合素质。健全组织生活，规范共青团活动，规范团员教育管理，加强学校基层团组织建设。

1.规范团员教育管理。各学校团委要根据团员教育基本目标的要求严格规范团员发展和教育管理工作。要在从严治党的背景下坚持从严治团，加强对团员发展工作的统筹，制定年度计划，严格规定团员发展标准和发展规范，认真执行团员发展程序，要按照团章有关规定分批次入团，杜绝全员入团、无条件发展、不按程序发展和突击发展现象。

2.落实“三会两制一课”。“三会两制一课”是加强团员思想政治教育和自我教育，强化团员意识，提升基层团组织凝聚力和战斗力的制度保障。各学校团委必须结合实际工作，开展“三会两制一课”相关工作，规范团的组织生活，规范开展主题团课，加强团员教育管理，从而更加紧密地团结在以习近平同志为核心的党中央周围，为实现中华民族伟大复兴中国梦而奋斗。

3.丰富创新共青团活动载体。严格按照共青团中央、教育部关于印发《中学共青团改革实施方案》的通知，开展形式多样的共青团活动。结合实际制定主题团日活动，在“五四”、“七一”、重大历史事件、历史人物的纪念日等时间节点开展一系列主题团日活动，开展14岁青春仪式和18岁成人仪式，大力开展礼仪教育，丰富团员的组织生活，教育引导广大学生在实践中践行社会主义核心价值观，帮助他们树立远大理想筑牢理想信念。

（三）规范中小学少先队活动。少先队活动课程是少先队活动经常化、制度化的重要载体，是中小学教育的重要组成部分，对于加强未成年人思想道德建设，全面实施素质教育具有重要作用。

1.确保少先队活动课时。严格按照国家规定把少先队活动课作为必修的活动课，小学一年级至初中二年级每周安排1课时。各学校要把少先队活动课程纳入教学计划，严格以“少先队活动课”标准名称落实到中小学课表中，不得挤占、挪用。

2.规范教学活动内容。全面贯彻落实全国少工委印发的《少先队活动课指导纲要（试行）》精神，规范少先队活动课教学。少先队活动课程以队会、队课、队仪式、组织生活、实践活动、品牌活动等为实施方式，以中队活动为基本形式常态开展，也可以大队集中开展，或以小队、红领巾小社团等形式灵活开展。

3.丰富少先队活动内容。要尊重少年儿童的主体地位，遵循少年儿童的年龄特点，科学设计少先队活动的内容和形式。要与学校其他教育教学活动有机结合，结合教育内容，采取少年儿童易于接受的方式，组织开展丰富多彩、独具特色的活动，增强少先队活动的主体性和吸引力。不断加强礼仪教育，序时举行入学仪式、入队仪式，深入开展“红领巾寻访”、“动感中队”等主题教育实践活动。在“五四”、“六一”、“七一”等节日开展一系列少先队教育活动，引导少先队员们继承和弘扬少先队的光荣传统，增强少先队员的光荣感和自豪感，激励他们成长为德智体美劳全面发展的社会主义建设者和接班人。

三、工作要求

（一）统一思想认识。各学校要在思想上高度重视，把思想政治工作摆在重要位置，坚持立德树人的根本任务，充分利用课堂教学主渠道作用，把思想政治工作贯穿教育教学全过程，结合实际认真制定课程实施方案。

（二）丰富活动载体。各学校要结合本校实际，创新思路，按照中小学生身心特点和成长规律，不断创新思想政治工作活动载体，运用新媒体新技术丰富活动形式，让广大中小学生通过一系列主题团（队）活动受到启发教育，全面推动思想政治工作向更高、更好发展。

（三）加强教学研究。各学校要通过校际交流、德育论坛、同课异构、课题研究、公开示范课等多种形式，加强道德与法治课、思想政治课和共青团、少先队活动建设工作的教学研究。开展以道德与法治课、思想政治课和共青团、少先队活动为主题的校本培训，依托教研组、备课组组织各学科开展专题教研活动，提高全体教职员工的德育意识和德育工作水平。
