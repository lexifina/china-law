# 山阴县人民政府办公室关于转发山阴县义务教育阶段学校招生工作方案的通知

各乡镇人民政府、县直各有关单位：

山阴县教育局《关于山阴县义务教育阶段学校招生工作方案》，已经县人民政府同意，现转发给你们，请结合实际认真贯彻落实。

山阴县人民政府办公室

2019年4月15日

山阴县义务教育阶段学校招生工作方案

为全面贯彻落实国家、省市有关精神，保障适龄儿童、少年公平接受义务教育的合法权益，规范招生秩序，促进义务教育均衡发展。根据朔州市教育局《关于印发〈2018年朔州市义务教育阶段招生入学方案〉的通知》（朔教发〔2018〕87号）和朔州市教育局《关于做好2018年朔州市普通中小学招生入学工作的补充通知》（朔教函〔2018〕101号）的要求，结合我县实际，特制定本方案。

一、指导思想

全面贯彻党的教育方针，以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九大精神，坚持以推进义务教育均衡发展、办好每一所义务教育阶段学校为目标，保障符合入学条件的每一位适龄儿童、少年顺利入学。不断提高教育治理能力和治理水平，努力解决义务教育发展不平衡、不充分的矛盾，彻底解决“择校热”“择班热”问题，维护我县适龄儿童、少年平等接受义务教育的权利，规范办学行为，净化教育生态，凸显教育公平，促进教育健康发展。

二、实施目标

学校通过“均衡编班”操作，建立科学合理的编班操作机制，树立教育的良好行风，促进学校全面健康发展，实现学校学生编班工作的公开、公平、公正，着力打造“阳光教育”。

三、招生对象

（一）小学一年级入学对象为年满6周岁的适龄儿童。

（二）七年级入学对象为完成小学六年义务教育且具有小学学籍的小学毕业生。

四、基本原则

（一）坚持免试就近入学原则。全县义务教育阶段学校新生入学工作坚持“免试、就近”的原则，各学校不得组织任何形式的入学考试，也不得参考任何考试成绩选择或拒绝学生报名入学。县教育局根据生源、学校的数量、分布以及办学规模等情况，确定各中小学的招生范围和招生数量，确保辖区内符合入学条件的所有适龄儿童和小学毕业生“有学上”。

（二）坚持严格控制轨制和班容量的原则。小学班额不超过45人；初中班额不超过50人。各学校招生报名人数不得突破规制最高限额人数。

（三）坚持均衡配置师资与阳光招生原则。各义务教育阶段学校，在安排班主任和课任教师时，都要均衡搭配；在分配班级时，要坚持公开、公平、公正的原则，全面实行“阳光招生”，做到操作规范、过程透明、结果公开。

（四）坚持以户籍、房产、实际居住地为主要依据确定服务对象原则。户籍、房产、实际居住地是划分小学、初中招生区域及确定招生对象的主要依据。根据学校现有布局规模，既考虑相对就近入学，又兼顾学校班额均衡，并确保外来务工人员子女有学可上。

（五）坚持信息公开原则。全面落实义务教育学校招生、编班信息等“七公开”要求，即招生政策、招生计划、报名条件、招生程序、录取结果、教师配备、编班情况等全部公开，接受群众和社会监督。

（六）坚持操作同步原则。全县各层次学校招生报名分班等工作要在教育局统一安排下进行。

五、操作步骤

（一）学校发布招生简章。各学校必须发布当年学校招生简章，招生简章必须涵盖学校简介、办学宗旨、办学特色、师资情况、招生规模和本方案所有招生要求等。经教育局审核批准后向招生对象和社会发布。

（二）教师安排方案。各学校根据新学期的招生数和班级设置数，按照均衡搭配师资力量的原则，经学校领导班子集体研究讨论，提出班主任人选和各学科教师人选组合。无特殊情况一学年内不得调整教师任课情况。

（三）班级安排。学校根据招生情况，在不突破班容量最高限额的前提下，均衡编班和搭配任课教师。

六、工作纪律

（一）各学校除发布招生简章外，不得以各种考试的不实排名等多种形式搞招生宣传活动，更不得进班宣传招生。

（二）任何学校和个人，不得以任何名义开设重点班和快慢班。

（三）学生入学后一学年内本县内不得转学；一学年后如因客观原因确需本县内转学的必须经教育科技局分管领导批准后，转入学校方可接收，但转入学生班级必须由普教股按不突破最高班额的限制指定所入班级。新生编班后，不得以任何借口换班。

如违反规定，一经查实追究相关人员责任。
