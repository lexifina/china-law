# 山阴县人民政府关于印发山阴县2019年冬季清洁取暖实施方案的通知

各有关乡镇，东、西城管委会，县直各有关单位：

《山阴县2019年冬季清洁取暖工作方案》已经县政府同意，现印发给你们，请认真贯彻落实。

山阴县人民政府

2019年4月18日

山阴县2019年冬季清洁取暖工作方案

为进一步贯彻落实党的十九大精神和习近平总书记关于“推进北方地区冬季清洁取暖”的重要讲话精神，持续推进2019年大气污染防治工作，进一步改善全县空气质量，坚决打赢蓝天保卫战，根据中央、省、市关于打赢蓝天保卫战和清洁取暖相关规划和山阴县人民政府《关于印发山阴县清洁取暖改造工作方案（2018─2020年）》（山政发〔2018〕97号）文件要求，制定本方案。

一、指导思想

坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大精神，认真落实党中央、国务院决策部署，按照省委、省政府和市委、市政府关于大气污染防治工作的部署要求，以改善我县区域环境空气质量为核心，以减少重污染天气为重点，充分考虑现实条件，因地制宜、因村施策，宜热则热、宜电则电、宜气则气、统一规划、统一标准，突出重点、分步实施，保质保量、确保安全，有序推进我县冬季清洁取暖工程，确保大气环境持续改善。

二、基本原则

（一）坚持清洁替代，安全发展。以清洁化为目标，在确保民生取暖安全的前提下，统筹热力供需平衡，单独或综合采用各类清洁取暖方式替代县城建成区和农村地区的取暖用散烧煤，减少取暖领域大气污染物排放。坚守安全底线，构建规模合理、安全可靠的热力供应系统。

（二）坚持因地制宜，尊重民意。统筹考虑能源资源开发利用、大气污染防治与经济社会发展，科学评估，因地制宜，充分考虑居民消费能力，采取适宜的清洁取暖策略，在同等条件下选择成本最低和污染物排放最少的清洁取暖组合方式，优化供热结构，合理配置供热资源。

（三）坚持统筹推进，有所侧重。综合考虑大气污染防治紧迫性、经济承受能力、工作推进难度等因素，统筹推进建成区及农村地区的清洁取暖工作。以县城为中心，充分考虑县城空气质量改善提升，乡村清洁取暖工作优先考虑县城上风向地区，优先考虑经济条件、基础设施较好的乡村推进清洁取暖工作。

三、工作目标

（一）2018年底清洁取暖总体情况

山阴县城建成区内燃煤散户数共有16760户，2017年完成“煤改气”改造户数4603户，集中供热改造户数580户；2018年完成“煤改气”改造户数2356户，集中供热改造户数38户，棚户区改造1030户。截止2018年底，共完成清洁能源取暖改造8607户，清洁取暖覆盖率51.35％。山阴县农村地区燃煤散户共有户数28600户；截止2018年底，共完成4887户，其中采煤沉陷区搬迁2058户；“煤改气”改造户数2829户（其中2017年827户，2018年完成2002户），清洁取暖覆盖率17％。

（二）2019年清洁取暖任务

按照市气防办的要求，2019年，我县县城建成区清洁取暖覆盖率达到70%以上，农村地区清洁取暖率达到40%以上。我县建成区清洁取暖总任务为11732户（16760×70%），已完成8607户，2019年清洁取暖需改造3125户。农村地区清洁取暖总任务为11440户（28600×40%），已完成户4887户，2019年清洁取暖需改造6553户。

（三）2019年清洁取暖计划安排

结合我县能源供应情况、居民经济承受能力和用能习惯，因地制宜推进清洁取暖，在确保居民温暖过冬的前提下，采取集中供暖、煤改气、煤改电等多种形式完成清洁供暖改造，确保完成任务。

县城建成区3125户，主要集中在西城区，其中：惠丰社区210户，广益社区555户，幸福社区845户，德望社区562户，和顺社区72户，集贤社区197户，兴隆社区192户，南街社区168户，北街社区159户，光明社区165户，全部采取集中供热方式改造。

农村地区6553户，其中集中供热1424户，全部在北周庄村实施；煤改气1810户，其中，刘家岭村200户、七里沟村200户、薛圐圙村200户、古城300户、安荣村800户、麻疃村30户、解庄村80户；煤改电3319户，主要集中在邻近县城的北周庄镇实施。

四、职责分工

（一）县人民政府对全县清洁取暖负总责。对全县热电联供集中供热和“煤改气”、“煤改电”工作，合理规划热源、管网布局，合理安排建设时序，加快推进清洁取暖项目建设，有序推进项目落地。

（二）全县建立清洁取暖工作协调机制，共同推进清洁取暖工作。县能源局负责清洁取暖工作的组织、协调、督促的指导工作、协调指导东西城区管委会、各乡镇等做好“煤改电”“煤改气”等清洁供暖相关工作。县环保局负责各类清洁取暖排放标准制定及统筹调度工作。县住建局负责指导推进城镇清洁供暖和建筑能效提升工作。县公共事业管理局负责推进全县热电联供集中供热工程建设。县农委负责协调推进农村清洁取暖工作。县财政局负责清洁取暖财政支持政策研究制定工作。县市场监督管理局负责《特种设备目录》内的锅炉安全节能环保监督检查工作，以及协调做好“煤改气”“煤改电”工程质量验收工作。其他相关部门根据部门职能及工作分工分别抓好落实。

（三）企业承担供暖主体责任，提供优质服务。昱光电厂和永皓电厂要保障热源，为全县减少大气污染提供支撑。公共事业管理局要加快推进县城集中供热管网建设，保障新增用户供热需求；三城天然气公司要进一步改进服务，提升服务质量，及早备足“煤改气”设备，早日实施“煤改气”工程，确保早日完成“煤改气”任务。供电公司要做好“煤改电”等线路改造和“煤改电”电价等相关工作。

五、保障措施

（一）加强组织领导。成立全县清洁取暖工作协调领导组，对全县清洁取暖改造工作进行总体指导和督办，实行例会制度、报告制度、集中调度制度、工程项目联席会议制度等，保障工程有序实施。县长任领导组组长，分管副职任副组长，能源、发改、住建、农委、环保、财政、市场监管、公共事业管理、东西城区管委会、北周庄低碳循环经济工业园区、国网供电公司、三城天然气公司以及各乡镇等负责人为成员，组织协调做好全县2019年冬季清洁取暖日常工作。

（二）多渠道提供资金支持。积极争取上级清洁取暖补助资金，县财政加大投入，确保全县清洁取暖资金投入到位。

（三）完善价格与市场化机制。

1、完善取暖用电价格机制。对居民电采暖试行峰谷时段计价、用电量计价、平段电价计价等多种销售侧电价政策。完善电采暖输配电价政策，参加电力市场交易的采暖用电，峰段、平段执行相应电压等级的输配电价，谷段输配电价按平段输配电价的50%执行。农村地区以村或自然村为单位通过“煤改电”改造使用电采暖或热泵辅助加热取暖，采暖用户与居民家庭“煤改电”采暖执行同样的电价政策。鼓励电蓄热、储能企业与风电、光伏发电企业开展直接交易，建立长期稳定且价格较低的供用电关系。在供暖期对“煤改电”居民用户和执行居民电价的非居民用户，试行电采暖用电市场化竞价采购，鼓励风电等可再生能源发电优先参与交易，予以优先购电保障。

2、完善取暖用气价格机制。管输企业供农村“煤改气”采暖用气门站价格，按居民用气价格执行；供城镇“煤改气”采暖用气门站价格，按现行价格政策执行。居民“煤改气”采暖用气销售价格，按居民用气价格执行。鼓励供热企业与上游供气企业直接签订购销合同，运用市场化交易机制等方式，降低天然气采暖用气成本。

3、完善集中供热价格政策。全县采取集中供暖的城镇，通过热电联产、大型燃煤锅炉、燃气锅炉、生物质锅炉等方式集中供暖的，必须按照超低排放要求进行环保改造并达到规定的排放（回灌）标准后供热。县价格主管部门要统筹考虑改造运行成本、居民承受能力，合理制定居民供热价格。对符合建筑节能标准的建筑，积极推行按用热量计价收费。加大力度推进两部制热价，由供热主管部门牵头，核定耗热量指标，对达到50% 建筑节能标准、具备按用热量计价收费条件的城市新建建筑和完成供热计量改造的既有建筑，实行两部制热价。

（四）保障清洁取暖能源供应。

1、改进集中供暖方式。在适合集中供暖的区域，优先以热电联产满足取暖需求，加快推进热电联产替代燃煤锅炉。优先发展背压式热电联产机组，结合电力系统运行情况严格管理纯凝机组供热改造。热电联产供热区域内，热电联产机组承担基本热负荷，调峰锅炉承担尖峰热负荷，确保热电联产供热区域内热电联产供热率高于80%以上。

2、加快天然气供应能力及电网建设。政府部门及相关企业要认真做好与气源企业的衔接工作，切实保障采暖季电源气源稳定供应。要加快城市储气设施建设进度，积极主动争取多种方式、多种主体的气源供应，建立健全燃气应急储备制度，通过自建、合建、租赁储气设施或购买第三方储气服务、储气气量等方式，逐步具备年平均3天供气量的应急储气能力。实施“煤改气”要按照国家“先规划、先合同、后发展”的要求，在落实气源合同的前提下，严格按计划、有步骤实施。电网公司要加大与清洁取暖相关的配电电网改造力度，服务全县统筹“煤改电”工程的规划和实施。要建立电力和燃气管网快速应急抢修队伍，确保在电力和燃气管网事故状态下，群众生产生活不受影响。

3、加强集中供热管线建设与维护。一是积极推进老旧热力网优化改造，对城市既有供热管网系统进行认真梳理，结合城市道路及管线改造，对运行年限较长及存在安全隐患的管线制定改造计划。鼓励供暖企业将符合接入技术条件的部分纳入集中供暖。二是加强热网整合，形成多热源联合供热环状热网，提高热力网安全可靠性。充分利用热电联产的供热优势，因地制宜发展长距离输送高温水热网。三是合理确定多热源联合供热环状热网的水力工况、热力工况，设置热力网泄漏检测，做好热力网自动化、智能化控制，提高热力网从热源到热用户的自动化、智能化控制水平，降低热力网热耗、电耗、水耗。

（五）加大农村清洁取暖力度。因地制宜，将农村炊事、养殖、大棚用能与清洁取暖相结合，充分利用生物质、沼气、太阳能、罐装天然气、电等多种清洁能源供暖。积极引导建制乡镇驻地村、中心村、旅游村等经济条件较好的农村地区改用燃气或电取暖设施。实施小型燃煤锅炉（炉具）环保改造，逐渐淘汰传统直烧炉，禁止销售不符合国家相关标准的劣质炉具。开展农业大棚、畜禽舍等用煤替代工作。推进现有农村住房建筑节能改造。
