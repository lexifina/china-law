# 山阴县人民政府关于公布第一批行政执法主体的通告

为全面推行行政执法公示制度、执法全过程记录制度、重大执法决定法制审核制度，全面落实行政执法责任制，根据《山西省行政执法条例》，结合我县机构改革职能调整实际，县政府对本级行政执法主体进行了全面清理，共确认24个法定行政执法主体，现予以公布。
