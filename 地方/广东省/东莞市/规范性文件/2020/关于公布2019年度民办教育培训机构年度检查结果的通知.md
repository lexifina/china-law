# 关于公布2019年度民办教育培训机构年度检查结果的通知

各园区、镇（街）宣教文体局（教育局），各民办教育培训机构：

根据《中华人民共和国民办教育促进法》第四十条和省教育厅《关于实行民办学校年度检查制度的通知》(粤教策〔2007〕37号)精神，我局于2019年11月开始，对2019年9月前批准设立的民办教育培训机构（以下简称培训机构）进行了年度检查。现将年度检查结果通报如下：

2019年度，应参加年检的培训机构共1067家，实际参加年检机构870家，其中年检合格的865家，年检不合格5家，不参与年检机构197家（含申请注销办学许可及许可证到期等情形）。

各园区、镇（街）宣教文体局（教育局）要进一步加强辖区内各教育培训机构的日常监督管理，督促各机构依法依规办学。对本年度年检不合格的教育培训机构，要重点督查，限期整改，连续两年年检不合格将吊销办学许可证。各教育培训机构要以年度检查为契机，对照标准，规范办学，不断完善内部管理，进一步提高办学质量和服务水平，为东莞教育现代化建设和学习型城市建设贡献力量。
