# 东莞市发展和改革局公开遴选公务员面试公告

根据《中华人民共和国公务员法》《公务员转任规定》《公务员公开遴选办法》等有关规定，现就东莞市发展和改革局公开遴选公务员面试有关事项公告如下：

一、面试名单

见附件1（按准考证号排序）。

二、面试安排

（一）面试时间

2026年8月1日（星期六）上午。请全部面试考生于当日上午8:30前到面试地点报到，由工作人员统一带入候考室签到。8:40前未进入候考室的，视为自动放弃面试资格。

（二）面试地点

东莞市粮食和物资储备中心（东莞市南城街道体育横路体育中心东面冠军楼一层凯佳羽毛球馆旁）

三、资格复审

（一）请考生务必于面试当天携带下列材料原件或复印件：

1. 本人身份证原件、笔试准考证纸质件。

2. 《东莞市发展和改革局公开遴选公务员报名推荐表》盖章原件，注意请按照干部管理权限加盖组织人事部门公章。

3. 最新的《干部任免审批表》复印件（须更新至2026年7月，应注明2023-2025年年度考核结果）。

4. 本科、研究生各阶段学历、学位证书认证报告纸质件等报考职位要求的资格材料。

考生应对个人提供材料的真实性负责，主要材料不全或信息不实，影响资格审查结果的，将取消面试资格，并按规定将有关情况报我市公务员主管部门备案。

（二）考生因个人原因放弃面试的，须向我局提交放弃面试资格声明（附件2），经本人签名，于7月29日（星期三）18:00前发送扫描件至电子邮箱：rspxk2017@163.com。

四、考察和体检

（一）成绩计算方式

考试总成绩＝笔试成绩×40%＋面试成绩×60%，考试总成绩满分为100分，四舍五入保留小数点后3位。如考生总成绩相同，则按照面试成绩高低顺序确定名次。

（二）考察

根据考生考试总成绩由高到低的顺序确定考察对象。考察对象与遴选计划人数的比例为2:1，考察时间及要求另行通知。

（三）体检

体检将在考察后开展（另行通知），考生体检费用由我局承担。届时请接到体检通知的考生在通知地点集合，由工作人员陪同统一前往体检机构进行体检。

（四）试用期安排

我局对公开遴选拟任职人员设置试用期，试用期为3个月。试用期内，拟任职人员在原工作单位的人事工资关系、待遇不变。试用期满考核合格的，按照有关规定办理转任手续；考核不合格的，回原单位工作。

五、注意事项

（一）请考生保持通讯畅通，准时参加考试。日程安排如有变化，另行通知。

（二）考生应对个人提供资料的真实性负责。

（三）请考生严格遵守公务员面试相关规定，诚信应考，杜绝一切作弊行为。如有违反规定的作弊行为，一经发现查实，坚决取消遴选资格，追究相应责任。

欢迎各位考生对我们的工作进行监督。
