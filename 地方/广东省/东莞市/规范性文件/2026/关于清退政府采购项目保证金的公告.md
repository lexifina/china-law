# 关于清退政府采购项目保证金的公告

各相关供应商：

为进一步优化政府采购营商环境，切实加强保证金管理，妥善解决历史存量保证金长期未退问题，根据《广东省财政厅关于进一步加强政府采购保证金管理工作的通知》（粤财采购〔2022〕7号）、《广东省财政厅关于严格落实政府采购保证金管理有关要求的通知》（粤财采购〔2025〕13号）等文件要求，现对东莞市教育信息中心历年来收取的政府采购保证金开展全面清理清退工作。现将有关事项公告如下：

一、清退范围

凡在东莞市政府采购中心缴纳过政府采购保证金（含投标保证金、履约保证金），且截至本公告发布之日尚未办理退还手续的供应商，均属本次清退范围。具体涉及供应商名单及金额详见附件。

二、办理期限

自本公告发布之日起30个自然日内。请各相关供应商于公告期内尽快联系本单位办理保证金退还手续。

三、办理流程及所需资料

（一）履约保证金退还所需资料

1. 保证金汇入时的转账凭证或收款收据复印件；

2. 《退履约保证金申请表》（详见附件3）；

（二）投标保证金退还所需资料

1. 保证金汇入时的转账凭证或收款收据复印件；

2. 《退投标保证金申请表》（详见附件4）；

（三）其他情形

公司名称或银行账户已变更的，需提供保证金汇入情况说明（详见附件5）。

四、办理地址及联系方式

办理地址：东莞市莞城街道育兴路132号教育信息中心

联系人：梁卫卫

联系电话：0769-22697305

办理时间：法定工作日上午〔9:00〕至〔11:00〕，下午〔14:30〕至〔16:00〕

五、逾期处理方式

公告期满后仍无人认领或未办理退还手续的保证金，本单位将依照相关规定上缴同级国库，不再予以退还。

六、其他事项

1. 东莞市教育信息网络管理中心已于2012年5月24日正式更名为东莞市教育信息中心；

2. 所有提交的复印件材料均需标注“与原件核对无误”，并加盖单位公章；

3. 凡存在项目纠纷、履约争议、涉法涉诉等情形的，暂不予办理清退，待相关争议解决后再行处理；

4. 请各相关供应商相互转告，及时办理。
