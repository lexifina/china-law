# 关于划定中山市二环快速路东段工程公路用地及建筑控制区范围的公告

中山市二环快速路东段工程经中山市发展改革局核准立项，项目初步设计文件已获得中山市交通运输局批准。为切实做好中山市二环快速路东段工程公路建设和管理工作，保障公路完好、安全和畅通，根据《中华人民共和国公路法》、《公路安全保护条例》、《广东省公路条例》有关规定，现将中山市二环快速路东段工程公路用地及公路两侧建筑控制区范围划定公告如下：

一、公路用地范围划定。中山市二环快速路东段工程起于中山港大桥，向南止于博爱七路南侧，路线全长7km，按一级公路兼城市快速路标准设计，主道双向六车道，辅道双向四车道，主道设计速度为：80km/h，辅道设计速度为：40km/h，路基采用整体式路基，宽度70m，项目用地约394亩，投资估算总金额为164873万元。沿线镇区有港口镇、火炬开发区、南朗镇。公路用地划定范围为道路红线内划定范围（详见公路用地图）。

二、公路两侧建筑控制区范围划定。公路两侧建筑控制区范围以《公路安全保护条例》、《广东省公路条例》等相关法律法规规章的最低间距要求进行确定。

三、任何单位和个人应当依法严格执行公路用地和建筑控制区范围的有关规定和要求。城乡规划、公路、国土资源、住房城乡建设、工商、公安等有关主管部门，应当在各自职责范围内协助做好公路建筑控制区管理工作，在规划、出让、审批公路两侧建设用地、建设项目时涉及公路建筑控制区的，应当征求公路管理机构的意见。

四、土地房屋征收管理部门应当加快协调项目沿线镇区等有关单位、村（居）委会，加紧开展道路红线内的土地房屋征收工作。沿线镇政府、火炬开发区管委会应当协助项目法人进入控制区范围内进行项目勘建工作。
