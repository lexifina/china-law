# 关于划定中山市古香林片区沙石公路扩建工程公路用地及建筑控制区范围的公告

中山市古香林片区沙石公路扩建工程经中山市发展和改革局核准立项，项目初步设计文件已获得中山市交通运输局批准。为切实做好中山市古香林片区沙石公路扩建工程建设和管理工作，保障公路完好、安全和畅通，根据《中华人民共和国公路法》、《公路安全保护条例》、《广东省公路条例》有关规定，现将中山市古香林片区沙石公路扩建工程公路用地及公路两侧建筑控制区范围划定公告如下：

一、公路用地范围划定。路线东起城桂公路，起点桩号K0+000，经过东苑南路，下穿于南外环路，西至终点与沙石公路相接，桩号K3+748.156，路线全长3.748公里，按四级公路兼顾城市道路功能标准设计，设计速度30公里/小时，路基宽度13米、19米、30米三种形式。公路用地划定范围为道路红线内划定范围（具体见公路用地范围图）。

二、公路两侧建筑控制区范围划定。公路两侧建筑控制区范围按《公路安全保护条例》、《广东省公路条例》等相关法律法规规章的最低间距要求进行确定。

三、任何单位和个人应当依法严格执行公路用地和建筑控制区范围的有关规定和要求。城乡规划、国土资源、住房城乡建设、工商、公安等有关主管部门，应当在各自职责范围内协助做好公路建筑控制区管理工作，在规划、出让、审批公路两侧建设用地、建设项目时涉及公路建筑控制区的，应当征求公路管理机构的意见。

四、土地房屋征收管理部门应当加快协调沿线镇政府、有关单位、村（居）委会，加紧开展道路红线内的土地房屋征收工作。沿线镇政府应当协助项目法人进入控制区范围内进行项目勘建工作。
