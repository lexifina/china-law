# 中山市人民政府办公室关于对中山盈亮健康科技有限公司等三个重大火灾隐患单位挂牌督办的通知

市各有关单位：

夏季消防检查工作开展以来，排查发现中山盈亮健康科技有限公司、中山阿蓓亚软管有限公司及中山市港利制冷配件有限公司等三个单位存在重大火灾隐患，且单位规模大、整改难度高，一旦发生火灾极易造成群死群伤恶性事故。为全面整治重大火灾隐患，坚决遏制亡人火灾发生，按照《中华人民共和国消防法》相关规定，经市政府研究，决定对上述三个重大火灾隐患单位进行挂牌督办。

火炬开发区管委会、南朗镇政府、港口镇政府要切实落实属地责任，责令上述三个重大火灾隐患单位落实整改措施、整改责任和整改期限，确保按期整改完成，切实维护人民群众生命财产安全。相关工作情况及时报市公安消防局，联系人：关毅明，联系电话：[电话略]。
