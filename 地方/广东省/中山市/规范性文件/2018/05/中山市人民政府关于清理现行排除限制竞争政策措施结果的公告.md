# 中山市人民政府关于清理现行排除限制竞争政策措施结果的公告

为进一步推进全面依法行政，推动公平竞争审查制度建设，切实维护公平竞争的市场秩序，根据国家、省和市有关清理现行排除限制竞争政策措施的工作要求，我市对中山市人民政府成立以来至2018年1月15日期间印发且现行有效的、与公众权利义务或权益有关的市政府（含市府办公室，下同）文件进行了清理。现将清理结果公告如下：

决定对《批转市房地产管理处关于对拨用公房处理意见的请示的通知》（中府〔1994〕83号）等35件文件予以废止。

部门、镇区文件清理结果，由各部门、各镇区向社会公布。

特此公告。
