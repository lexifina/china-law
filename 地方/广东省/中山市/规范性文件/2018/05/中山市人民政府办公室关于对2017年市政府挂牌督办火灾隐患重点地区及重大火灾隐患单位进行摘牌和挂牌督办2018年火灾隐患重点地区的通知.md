# 中山市人民政府办公室关于对2017年市政府挂牌督办火灾隐患重点地区及重大火灾隐患单位进行摘牌和挂牌督办2018年火灾隐患重点地区的通知

火炬开发区管委会，翠亨新区管委会，各镇政府、区办事处，市各有关单位：

2017年5月，市政府对小榄镇的出租屋及工厂企业消防安全问题、大涌镇的违章建（构）筑物消防安全问题、黄圃镇的大岑工业区消防安全问题、南头镇的违章建（构）筑物消防安全问题、古镇镇的场所违规住人消防安全问题进行挂牌督办。2017年12月，市消防安全委员会在各镇区自查验收的基础上，委托第三方机构对小榄、大涌、黄圃、南头和古镇镇火灾隐患整治工作进行评估验收。经综合评定，大涌、黄圃、南头镇按期完成火灾隐患整治任务，验收合格，予以摘牌；小榄镇、古镇镇验收不合格，不予以摘牌。同时，市公安消防局依法组织对挂牌督办的4个重大火灾隐患单位进行复查，全部整改合格，予以摘牌。摘牌的镇区和单位要认真总结整治工作经验，持续深化和巩固整治成效，做好整治工作“回头看”，切实防止隐患反弹。

按照《广东省人民政府办公厅关于公布广东省第九批火灾隐患重点地区整治工作验收结果和挂牌督办第十批火灾隐患重点地区的通知》（粤办函〔2018〕118号），小榄镇被列为全省第十批火灾隐患重点地区之一。按照相关规定，市政府决定对古镇镇的场所违规住人等消防安全突出问题进行挂牌督办整治。被挂牌督办的镇区，要认真学习借鉴其他地区整治工作成功经验，全面分析评估本地消防工作突出问题，制定针对性工作方案，确保全面完成整治任务。市消防安全委员会将于2018年底前组织验收，对完成整治任务的地区予以摘牌销案；对未完成整治任务的地区，继续挂牌督办，并将其作为明年省政府挂牌督办重点地区的重点推荐对象。整治工作验收情况纳入市政府对各镇区年度消防工作考核内容。

古镇镇整治工作方案、工作联系人名单，请于5月20日前报市消防安全委员会办公室。整治工作进展情况，请于每月2日前报市消防安全委员会办公室。联系人：叶水荣，联系电话：[电话略]，传真：23186877。
