# 中山市人民政府办公室关于对2018年市政府挂牌督办火灾隐患重点地区摘牌和挂牌督办2019年火灾高风险区域及重大火灾隐患单位的通知

火炬开发区管委会，翠亨新区管委会，各镇政府、区办事处，市各有关单位：

为全面整治火灾隐患重点地区及重大火灾隐患单位，最大限度减少火灾隐患存量，市政府于2018年5月对古镇镇场所违规住人消防安全问题进行挂牌督办。2019年3月，市消防安全委员会牵头组织11个部门对古镇镇违规住人整治开展验收。经验收评估，古镇镇能按期完成火灾隐患整治任务，违规住人情况大有改善，验收合格，予以摘牌。古镇镇要认真总结整治工作经验，及时整改验收发现的问题，持续深化和巩固整治成效，利用大数据、物联网等技术手段提升消防工作科技化水平，建立违规住人整治长效机制，切实防止隐患反弹。

根据《广东省火灾高风险区域和重大火灾隐患单位整治挂牌督办实施办法（试行）》（粤消安〔2017〕30号）、《消防救援局关于集中开展重大火灾隐患“四个一批”整治工作的通知》（应急消〔2019〕56号）和《重大火灾隐患判定方法》（GB-35181-2017）等，综合各镇区火灾形势、消防工作情况，市政府决定对东凤镇同乐工业园、坦洲永二工业区、南区北溪社区沙田村3个高风险工业园区和中山博览中心 、中山市朗华电子塑胶有限公司、中山市程晟百货有限公司3个重大火灾隐患单位实施挂牌督办。被挂牌督办工业园区所在镇区政府，要认真学习借鉴其他地区整治工作成功经验，全面分析评估本地消防工作突出问题，成立整治工作办公室，制定工作方案，确保全面完成整治任务。被挂牌督办的单位要明确整改责任人，制定整改计划，落实整改经费，在挂牌期间要采取有效措施确保消防安全。市消防安全委员会将于2019年年底前组织验收，对完成整治任务的地区予以摘牌销案；对未完成整治任务的地区，继续挂牌督办，并将其作为2020年省政府挂牌督办重点地区的重点推荐对象。整治工作验收情况纳入市政府对各镇区年度消防工作考核内容。

纳入本次挂牌督办的镇区整治工作方案、工作联系人名单于5月20日前报市消防安全委员会办公室。整治工作进展情况于每月2号前报市消防安全委员会办公室（联系人及电话：叶水荣、郑中越，0760-23880043）。
