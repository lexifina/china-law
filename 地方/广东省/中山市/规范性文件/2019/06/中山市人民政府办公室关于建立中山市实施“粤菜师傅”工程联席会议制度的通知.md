# 中山市人民政府办公室关于建立中山市实施“粤菜师傅”工程联席会议制度的通知

火炬开发区管委会，翠亨新区管委会，各镇政府、区办事处，市各有关单位：

为加强我市实施“粤菜师傅”工程的统筹协调和组织领导，经市政府研究，决定建立中山市实施“粤菜师傅”工程联席会议制度（以下简称联席会议）。现就有关事项通知如下。

一、主要职责

在市委、市政府领导下，统筹协调指导全市“粤菜师傅”工程实施，研究提出“粤菜师傅”工程重要政策意见；强化部门沟通协作与信息共享，促进密切配合、共同推动；督促工作落实，及时通报工作进展，总结推广经验做法。

二、组成人员

总召集人：杨文龙（市政府）

召 集 人：吴军（市政府），洪焰（市人力资源社会保障局）

成 员：徐剑（市委宣传部），黎国喜（市教育体育局），黄玉珊（市财政局），吴镜芳（市人力资源社会保障局），万国富（市农业农村局），郑凯旋（市商务局），邓淑玲（市文化广电旅游局），徐世平（市市场监管局），饶长春（市总工会），麦升涛（团市委），刘浴平（市妇联），袁泉（市供销社）。

三、工作机制

联席会议不纳入市级议事协调机构管理，日常工作由市人力资源社会保障局承担。联席会议成员因工作变动需要调整的，由所在单位向市人力资源社会保障局提出，按程序报总召集人批准。

联席会议由总召集人或总召集人委托召集人召开，原则上每年召开一次，也可根据工作需要不定期召开。各成员单位要认真落实联席会议确定的工作任务和议定事项，相互配合，相互支持，形成合力，共同做好“粤菜师傅”工程各项工作。
