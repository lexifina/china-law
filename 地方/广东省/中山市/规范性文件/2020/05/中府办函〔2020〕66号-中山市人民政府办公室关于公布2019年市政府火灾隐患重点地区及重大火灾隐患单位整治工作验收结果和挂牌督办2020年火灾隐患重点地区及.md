# 中山市人民政府办公室关于公布2019年市政府火灾隐患重点地区及重大火灾隐患单位整治工作验收结果和挂牌督办2020年火灾隐患重点地区及重大火灾隐患单位的通知

火炬开发区管委会，翠亨新区管委会，各镇政府、区办事处，市各有关单位：

2019年5月，市政府对南区北溪社区沙田村、东凤镇同乐工业园和坦洲镇永二工业区等3个火灾隐患重点地区（下称重点地区）和中山博览中心、中山市朗华电子塑胶有限公司、中山市程晟百货有限公司3个重大火灾隐患单位（下称隐患单位）进行挂牌督办。被挂牌督办以来，南区办事处、东凤镇、坦洲镇和各有关单位严格按照“区域全面排查治理 、单位彻底消除隐患”要求，强化组织领导，加大消防安全投入，扎实推进消防安全“网格化”管理，不断加强消防基层基础建设，累计排查整治单位场所2551家，发现并整改火灾隐患7839处，培训群众超5万人次，整改消除隐患单位重大火灾隐患8处，取得了较好工作成效。

2019年12月，在各镇区自查验收基础上，市消防安全委员会委托第三方消防技术服务机构对重点地区整治情况进行实地评估验收。2019年6月至2020年4月，市、镇两级消防救援机构组成联合验收组对3个重大火灾隐患单位进行现场核查验收。经综合评定，除坦洲镇被列为全省第十二批火灾隐患重点地区暂缓摘牌、中山市博览中心未整改完毕外，南区北溪社区沙田村、东凤镇同乐工业园2个重点地区和中山市朗华电子塑胶有限公司、中山市程晟百货有限公司2个隐患单位均按期完成整治任务，验收合格，予以摘牌。摘牌的地区和单位要认真总结整治工作经验，督促整改验收发现的问题，持续深化和巩固成效，切实防止隐患反弹。

根据《中华人民共和国消防法》、《国务院办公厅关于印发消防安全责任制实施办法的通知》（国办发〔2017〕87号 ） 、《 广东省火灾高风险区域和重大火灾隐患单位整治挂牌督办实施办法（试行）》（粤消安〔2017〕30号）等有关规定，综合各镇区火灾形势、消防工作情况，市政府决定对横栏镇茂辉工业区和东区竹苑社区细柏山村2个高风险地区和中山博览中心、中山市民众锦标学校、中山市东区库充市场3家重大火灾隐患单位进行挂牌督办。被挂牌督办的高风险地区所在镇区要认真学习借鉴其他地区整治工作成功经验，全面分析评估本镇区消防工作突出问题，着力解决消防安全责任制落实、火灾隐患排查整治、消防基础设施建设和消防宣传教育培训等方面突出问题，确保全面完成整治任务。被挂牌督办的单位要明确整改责任人，制定整改计划，落实整改经费，采取有效措施确保消防安全。市消防安全委员会将于2020年年底前组织验收，对完成整治任务的地区予以摘牌销案；对未完成整治任务的地区，继续挂牌督办，并将其作为明年省政府挂牌督办重点地区推荐对象。整治工作验收情况纳入市政府对各镇区年度消防工作考核内容。

各镇区重点地区整治工作方案、工作联系人名单，请于5月20日前报市消防安全委员会办公室（市消防救援支队）。整治工作进展情况，请于每月2日前报市消防安全委员会办公室（联系人：叶水荣，联系电话：0760-23880043）。
