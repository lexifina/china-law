# 关于云浮市城区农村集体土地总登记的通告

云浮市人民政府文件

云府〔2012〕50号

关于云浮市城区农村集体土地总登记的通告

根据《土地登记办法》(中华人民共和国国土资源部令第40号)规定以及省国土资源厅、省财政厅、省农业厅《转发国土资源部财政部农业部关于加快推进农村集体土地确权登记发证的通知》(粤国土资地籍发〔2011〕100号)要求，为加强土地管理，维护社会主义土地公有制，保护农村集体和农民个人的合法权益，现决定，从2012年5月21日至2012年10月31日对市城区农村集体土地进行总登记(包括农村集体土地所有权、集体建设用地使用权、宅基地)。请各集体土地权利人届时（具体时间另行通知）出席地籍调查现场，配合工作组进行指界并提供相关文件资料申请土地登记。

特此通告。

二Ｏ一二年五月二十九日
