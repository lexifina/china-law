# 关于印发云浮市城市管理体制机制改革方案的通知

云浮市人民政府办公室文件

云府办〔2012〕107号

关于印发云浮市城市管理体制机制改革方案的通知

云城区人民政府，佛山（云浮）产业转移工业园管委会，市府直属各单位：

《云浮市城市管理体制机制改革方案》已经市委、市政府同意，现印发给你们，请认真贯彻实施。实施中遇到的问题，请径向市城市综合管理局反映。

云浮市人民政府办公室

2012年9月25日

云浮市城市管理体制机制改革方案

根据广东省关于城市基层管理扁平化和推进城乡基本公共服务均等化的要求，进一步深化改革和创新云浮市城区的城市管理体制机制，提升城市管理工作水平，加快推进城市化进程。现结合我市实际，制订本方案。

一、指导思想及基本原则

（一）指导思想。

以科学发展观为指导，树立现代城市管理理念，围绕建设“小政府、大社会”，进一步解放思想，深化城市管理体制机制改革，推进城市管理重心下移，以“城乡基本公共服务均等化”为重点，以整合、优化城市管理资源为基础，以社会多元化为主体，创新城市管理运行机制，推行城市精细化管理新模式，不断提高公共服务效率和质量，建立快捷、高效、协调、便民的城市管理长效机制，全面提高城市综合管理水平，提升城市品位，增强城市竞争力，建设宜居宜业发展环境，为跨越赶超、科学崛起，建设幸福云浮夯实基础。

（二）基本原则。

——坚持解放思想，改革创新。不断解放思想，锐意创新，大胆探索，以深化城市管理体制改革为契机，创新城市管理新机制，提升城市管理工作效能，破解城市管理难题，建设现代化城市。

——坚持以人为本，服务民生。把服务民生、让群众满意作为城市管理工作的出发点和落脚点，不断满足人民群众的需求。坚持把服务民生放于城市管理的优先位置，更加注重增强服务意识，寓管理于服务之中，在改进服务中加强城市管理工作，着力解决好群众最关心最直接最现实的利益问题，努力让城市管理成果惠及广大人民群众。

——坚持统筹城乡，强化基层。以“大城管”格局，统筹推进城市管理各项工作。加快城市管理资源向下延伸，让城市管理资源和服务惠及基层群众，促进城乡基本公共服务均等化，推动城乡协调发展。

——坚持重心下移、事权下放、权责一致。合理划分市、区两级政府的管理权限，明确职责，形成块为主、条为辅的城市管理新格局。推进规划、监督、指导、考核与执行分离，政府主导与社会参与相结合，实现科学、高效运作，推动城市管理和社会管理双提升。

——坚持分步实施，整体推进。综合统筹城市管理体制机制改革，按照先急后缓的原则，重点加快涉及城市管理事权下放的各项体制机制改革，适时推进配套的体制机制改革，推动城市管理长效机制的建立。

二、工作目标

建立健全“党委领导、政府负责、社会协同、公众参与”的城市管理新格局，形成“二级政府、三级管理、四级网络”的城市管理体系，推进城市管理工作不断迈向规范化、制度化、精细化和信息化，全面提升城市公共服务水平，努力把云浮建设成为有特色、有品位、值得作为故乡的宜居宜业平安幸福之城。

——2012年9月底前，完成城区环卫、市政设施、园林绿化和城市管理执法体制改革，初步建立起“横向到边、纵向到底”和协调联动、运转高效的管理新格局。

——2013年12月前，健全和完善云浮市管理委员会相关机制，统筹推进“数字城管”建设，基本建立体现云浮特色，与我市经济社会发展水平相适应的城市管理体系框架。

三、主要任务

全面落实市委、市政府的决策部署，以健全完善与我市城市科学发展要求相适应城市管理体制机制为重点，进一步推进城市管理重心下移，调整市、区城市管理职责与分工，构建职责明晰、全程控制、全面覆盖的城市管理网络，提高城市综合管理效益。

（一）推进管理体制改革，构建高效的城市管理运行体系。

推进城区环卫、市政设施、园林绿化管理体制改革和城市管理执法体制改革，明确市、区城市管理的职责分工。

1．市城市综合管理局将现行负责的城区环卫、市政设施维护、园林绿化管理和城区的城管执法工作移交由云城区政府具体负责组织实施。云城区政府结合自身职能，将相关管理、执法和服务工作向各镇（街）、农村延伸，同时承担与管理权限对等的责任，确保城市管理体制改革后“放得下、接得住、管得好”。

（1）环卫管理方面。

①内容和范围：一是负责市级现行的环卫管理工作，主要包括城市道路、公共场所、广场、河道、绿道的清扫、保洁、上门收集垃圾、洒水洗街、垃圾清运等环卫服务工作；环卫设施（含果皮箱、公厕、压缩站、粪便处理场、垃圾处理场等）管理维护和建设工作；建筑废弃物（渣土余泥）排放的审批、监督管理工作；垃圾处理费征管工作；“三乱”广告的清理工作。二是负责区级现行的城区内街小巷、城中村、城乡结合部等区域的环卫管理工作。三是负责将环卫管理服务工作延伸到农村，综合协调和实施区辖各镇（街）、自然村的环卫管理工作。

②管理标准：按照《城市道路清扫保洁质量与评价》（CJJ/T126-2008）、《云浮市城区环卫项目作业质量标准》执行。采取招标采购的方式购买服务，实施城区环境卫生的日常管理，在服务合同中要明确服务标准、费用和违约处罚，服务费用实行总包干形式支付。

（2）市政设施管理方面。

①内容和范围：一是负责市级现行的市政设施管理工作，主要包括城市道路、桥梁及其他市政设施的管理维护和建设工作；临时占用城市道路、公共场所、桥梁和开挖城市道路、公共场所的审批和管理工作；依附城市道路或桥梁的各类管线铺设的审批和管理工作；市区户外广告设置的审批和管理工作；城市公共资源出让费征管工作；城市道路挖掘修复费征管工作。二是负责推进市政设施管理工作延伸到农村，实施城中村、城乡结合部和各镇（街）、自然村的市政基础设施建设管理工作。

②管理标准：按照《城市道路养护技术规范》（CJJ/36-90)执行。采取招标采购的方式购买服务，实施城区市政设施日常管理，在服务合同中要明确服务标准、费用和违约处罚，服务费用实行总包干形式支付。

（3）园林绿化管理方面。

①内容和范围：一是负责市级现行的园林绿化管理工作，主要包括市区公园、公共绿地、行道树等园林绿化的管理维护和建设工作；恢复绿化补偿费、绿化补偿费征管工作。二是负责推进园林绿化管理工作延伸到农村，实施城中村、城乡结合部和各镇（街）、自然村园林绿化管理维护和建设工作。

②管理标准:按照广东省《城市绿地管养质量标准》（DB44/T269-2005）、《云浮市城区园林绿化综合管养作业质量标准》执行。采取招标采购的方式购买服务，实施城区园林绿化的日常管理，在服务合同中要明确服务标准、费用和违约处罚，服务费用实行总包干形式支付。

（4）城市管理执法方面。一是负责市级现行的城区内市容和环境卫生、市政工程设施、园林绿化方面的城管执法工作。二是负责各镇（街）的城管执法工作。具体管理标准按照国家、省有关城市管理法规执行。

2．在事权下放、重心下移的同时，市城市综合管理局根据我市城市管理事业发展要求，制定市城市管理工作计划，进一步加强对全市城市管理宏观层面和整体上的规划、监督、指导、考核、协调职责，科学设置和调整机构，提高办事效率。改革后市城市综合管理局的职责进行相应调整，划出城区环卫、市政设施、园林绿化管理职责以及环卫、市政设施、园林绿化方面的监察执法职责。保留职责：（1）贯彻执行国家和省有关城市管理工作的方针政策和法律法规，研究拟订相关的地方性规定和管理办法，并监督实施；（2）拟订市城区市政基础设施、园林绿化、环境卫生、市政资源、公共照明、市容市貌等城市综合管理和监察执法方面的中长期发展规划，并监督实施；（3）参与市城区新建、扩建、改建工程项目中的市政、环卫、园林绿化等配套设施的建设规划图纸评审、审批及竣工验收工作；（4）园林绿化企业资质审批；（5）市城区公共照明、管道燃气的管理职责以及监察执法职责；（6）市城区公用事业项目特许经营权出让审批；（7）负责全市本职能范围内的行业管理工作，指导各县（市、区）本职能范围内的工作。新增职责：（1）全市的城市市政基础设施、园林绿化、环境卫生、城管执法方面的监督、考核职责；（2）全市的城市市政基础设施、园林绿化、环境卫生、市政资源、公共照明、市容市貌等城市综合管理和监察执法方面的统计工作；（3）市城管委日常工作的组织、综合、协调职责；（4）“数字城管”职责；（5）城市管理执法方面的市城区大案、要案和跨区（县）域案件的查处工作；（6）市政府交办的重大建设任务。

（二）推进管理机制创新，提高城市科学管理水平。

1．城市管理资源向下延伸，建立城市公共服务资源服务民生机制，推进城乡基本公共服务均等化建设。紧紧围绕城市管理服务方式转变和促进社会和谐的重大现实问题，以城乡基本公共服务均等化为重点，创新城市公共服务机制，推进城市管理资源向镇（街）、农村延伸，使城市基本公共服务全面、平等惠及基层群众，促进城乡协调发展。一是加强城乡管理规划。按照“三规合一”的要求，在严格制订城市发展空间规划和具体建设项目规划的同时，把城区所属镇（街）、农村涉及城市管理的环卫、市政设施，园林绿化等建设内容同步规划，同步设计，促进基层规划与城市同步推进。二是推进市政公用资源建设向下延伸。在抓好市城区市政设施建设的同时，加大对涉及公共环卫设施、市政道路设施、街头景观设施、公园设施、灯饰照明等城市基础设施向镇村延伸的力度，不断改进镇村基础设施建设，改善镇村人居环境，提升形象，推动城市与镇村协调发展。三是推进镇村园林绿化。结合名镇名村建设，指导镇村按照规划加大园林绿化的力度，重点对道路、河道两旁，以及村边闲地、庭园进行绿化美化，实现城乡园林绿化工作统筹推进。四是推进城乡环卫管理。坚持以城带乡，把环卫管理向镇村延伸，加强环境治理，净化村容村貌，按照“户收集、村集中、镇转运、县处理”的方式，明确农村生活垃圾管理部门，乡镇要确保有专责工作人员，村配备专门保洁员，形成稳定的县（市）、镇、村三级管理和保洁队伍，同时，按照垃圾处理场、转运站、收集点同步建设的原则，确保“一县一场”、“一镇一站”、“一村一点”，建立村镇垃圾处理体系，确保村镇生活垃圾清运处置和无害化处理，全面提高农村环境卫生管理水平。

2．以社会多元化为主体，建立各类社会主体参与城市治理工作机制，推进城市管理社会化建设。在推进城市管理重心持续下移的同时，充分调动各类管理主体参与城市管理的积极性和主动性。一是推进城市管理制度建设。充分发挥镇（街）、村（社）、乡（村）的基层组织作用，让其积极参与城市管理工作，根据城市管理工作的要求，结合本区域的实际，收集整理群众的意见和建议，组织村民制定镇（街）、村（社）、乡（村）环境卫生、市政设施、园林绿化等方面的长效管理制度，构建村民自我管理、自我教育、自我服务的长效机制。二是创新社会化运作。充分发挥行业协会和社会组织的作用，科学引导更多具有独立法人资格的社会组织平等竞争参与中心城区、镇（街）主次街道、公共场所、横街小巷、城乡结合部等区域的环境卫生、市政设施、园林绿化等工作，推进城市公共服务社会化运作。三是创新公众参与城市管理的方式。多形式、多渠道开展城市环境卫生、市政设施、园林绿化等方面城市管理知识进社区、进企业、进学校，增强市民的城市文明意识，提高公共道德水平。通过各类社会组织和人民团体开展城市管理知识宣传活动，推进城市管理理念深入人心。同时，通过设立意见箱、聘请行风监督员、座谈走访等多种形式，听取群众意见，拓宽群众投诉渠道，实现城市管理工作与群众零距离沟通联系，让民智、民需得到充分体现，以城市管理的实效取信于民，努力营造人人关注、人人理解、人人参与城市管理的良好社会氛围，真正做到“人民城市人民建，人民城市人民管”。

3．构建“大城管”，建立高位协调联动机制，推进城市管理整体效能提升。按照“高位协调、职能互补、资源整合”的要求，健全由市政府主要领导任主任，市分管领导任副主任，云城区政府和城管、公安、工商、交通、环保、建设等市直相关部门主要负责人为成员的市城市管理委员会。充分发挥市城市管理委员会的高位协调作用，加强对市城市管理工作统筹规划、综合协调、联合执法和研究解决城市管理中重大问题，建立全市城市管理联席会议制度和月度工作例会制度，定期商议城市管理中的重大事宜，分析、协调、解决城市管理中的问题，实现城市管理由“各自为战”转变成为“协同作战”，形成资源共享、齐抓共管的管理格局，初步构建系统整合、运转协调的“大城管”格局，提高城市管理效率。

4．实施“数字城管”，建立综合指挥、应急联动机制，推进智慧城市建设。市城市综合管理局统筹推进“数字城管”建设，提升城市管理的科技水平。一是本着统一规划、统一管理的原则，综合应用计算机、网络、通信等现代信息技术，整合公安、交通、城管等公共信息资源，尽快建立完善我市的城市管理数字化信息平台，实现对城市管理工作的视频实时监控、快速定位和网格化管理，切实提高城市管理水平和管理效率。二是整合城管“12319”热线等信息网络服务平台，强化接受投诉、调度、协调处理、监督职能，统一受理各类投诉、咨询案件，即时协调安排市或区有关部门处理案件，并及时反馈处理结果。同时，综合统筹处理市城区大案、要案和跨区（县）域案件，建立起资源共享、沟通快捷、分工明确、责任到位、反应迅速、处置及时、运转高效的数字化城市管理监督指挥和快速应急联动体系，进一步提升城市管理的快速应急能力。

5．强化督导考评，建立激励奖惩机制，推进城市综合服务效能提升。由市城市综合管理局根据国家、省有关政策和标准，制订相关考评办法，采取月度暗检、季度明检、年度考核相结合的办法，对全市的城市管理工作进行综合考评，考评结果纳入各县（市、区）级政绩考核内容。

四、经费落实

建立城市管理经费投入的市区协同保障机制，将城市管理经费纳入市、区两级财政预算。按照城市管理服务高标准、全覆盖的要求，合理安排环境卫生管理、市政设施维护、园林绿化管理、城市管理执法等各项经费。改革后，云城辖区范围的环卫、市政设施、园林绿化管理三项共需投入概算经费约5189.5万元/年。从2012年9月至2013年7月，市财政按现行市区环卫、市政设施、园林绿化承包项目的合同标准支付投入经费，从2013年8月起，市财政负责投入3500万元/年（含每年收缴的城区生活垃圾处理费），按完成进度和质量拨付，其余由云城区政府负责投入。

五、保障措施

（一）加强组织领导，落实层级责任。

市成立云浮市城市管理体制机制改革工作领导小组，切实加强对方案实施的组织领导，明确工作分工，完善工作机制，落实工作责任。细化城市管理事权下放具体项目，建立健全各项改革保障机制，制定细化工作方案。市城市综合管理局和云城区人民政府要加快理顺关系，调整工作职责。市城市综合管理局及其下属事业单位的“三定”规定结合实际进行相应的调整，由市编委重新制定“三定”规定并印发。

（二）加强宣传引导，努力营造氛围。

加大宣传力度，及时宣传各项改革政策，营造良好的舆论氛围。通过网上公开、媒体发布、咨询会、座谈会等多种形式，强化公众参与，确保改革科学化、民主化、合法化。

（三）加强监督检查，确保改革成效。

市城市管理体制机制改革工作领导小组工作要加强对本方案实施情况的跟踪分析，做好各项工作和政策措施落实的督促检查工作。建立定期督查制度，对改革工作定期开展督促检查，及时将实施情况向市委、市政府报告，并定期进行通报，相互促进，确保各项改革措施落到实处。
