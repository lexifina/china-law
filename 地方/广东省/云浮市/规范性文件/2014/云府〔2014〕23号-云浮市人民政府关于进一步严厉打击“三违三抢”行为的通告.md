# 云浮市人民政府关于进一步严厉打击“三违三抢”行为的通告

云浮市人民政府文件

云府〔2014〕23号

云浮市人民政府关于进一步严厉打击

“三违三抢”行为的通告

根据《中华人民共和国城乡规划法》、《中华人民共和国土地管理法》、《中华人民共和国矿产资源法》、国务院《城市市容和环境卫生管理条例》等法律法规的规定，为切实维护我市城市规划建设和国土资源管理秩序，为全市经济社会加快发展营造良好环境，市政府决定在全市开展进一步严厉打击“三违三抢”，即违法用地、违法建设和违法采矿，抢搭、抢建、抢种行为。现就有关事项通告如下：

一、凡未经国土资源、规划建设、城市管理、林业、农业等行政主管部门批准，擅自占用、出租和买卖土地，破坏耕地、林地，在城市规划区范围、重大基础设施建设和经济社会发展重大项目用地抢搭、抢建、抢种，以及擅自勘查开采矿产资源等行为，均属“三违三抢”行为，一律依法坚决予以取缔和严厉打击。

二、本次打击专项行动的重点范围为：市中心城区，包括云城区云城街道、高峰街道、河口街道、安塘街道、思劳镇、腰古镇、都杨镇，云安县六都镇；各县（市）城市规划区，包括罗定市的罗城街道、附城街道、素龙街道、双东街道，新兴县的新城镇、六祖镇、太平镇、东成镇，郁南县的都城镇、平台镇。

三、“三违三抢”行为人必须在规定期限内(以有关职能部门发出的责令停止建设、停止施工、限期拆除、清理等法律文书为准)自行纠正，逾期未纠正的，依法由同级人民政府书面责成有关部门采取查封施工现场或强制拆除、清理等措施。强制拆除、清理的费用由违法行为人承担。

四、国土资源、规划建设、城市管理、林业、农业等行政主管部门和各县（市、区）、佛山（云浮）产业转移工业园、各相关镇街要切实履行职责，密切配合，进一步加大监管执法力度。对实施“三违三抢”行为的单位和个人，严格依据《中华人民共和国城乡规划法》、《中华人民共和国土地管理法》、《中华人民共和国矿产资源法》、国务院《城市市容和环境卫生管理条例》等规定依法给予相应处罚；构成犯罪的，依法移送公安部门追究刑事责任。涉及党员、公职人员的，要追究党纪政纪责任。妨碍、阻挠执法人员依法履行职责的，由司法机关依法予以严厉打击。

五、欢迎广大人民群众对“三违三抢”行为踊跃举报，市政府对举报人的举报行为将严格予以保密。举报渠道：市府办督查科，举报电话：8988197；市国土资源城乡规划管理局执法监察支队，举报电话：8936669。

六、本通告发文之日起执行。此前发布《关于严厉打击“三违三抢”行为的通告》（云府〔2012〕55号）同时作废。
