# 云浮市人民政府办公室关于印发《广东药科大学云浮校区及周边区域概念规划设计》的通知

云浮市人民政府办公室文件

云府办〔2017〕26号

云浮市人民政府办公室关于印发《广东药科大学云浮校区及周边区域概念规划设计》的通知

云城区、云安区人民政府，市政府各部门、各直属机构：

《广东药科大学云浮校区及周边区域概念规划设计》已经市政府第六届八次常务会议审议通过，现印发给你们。本次概念性规划设计是编制下一层次控制性详细规划的基础和依据，执行过程中遇到的问题，请径向市规划编制委员会反映。

云浮市人民政府办公室

2017年6月2日

注：因附件内容太大，《广东药科大学云浮校区及周边区域概念规划设计》此略，如有需要，可向市规划编制委员会咨询或索取。

公开方式：主动公开

抄送：市委各部委办，市人大办，市政协办，市纪委办，云浮军分区，市中级法院，市检察院，省驻云浮单位，各人民团体，各新闻单位。

云浮市人民政府办公室 2017年6月2日印发
