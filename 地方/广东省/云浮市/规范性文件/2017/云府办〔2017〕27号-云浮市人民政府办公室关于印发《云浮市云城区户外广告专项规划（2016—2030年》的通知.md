# 云浮市人民政府办公室关于印发《云浮市云城区户外广告专项规划（2016—2030年》的通知

云浮市人民政府办公室文件

云府办〔2017〕27号

云浮市人民政府办公室关于印发《云浮市云城区户外广告专项规划（2016—2030年》的通知

云城区人民政府，市政府各部门、各直属机构：

《云浮市云城区户外广告专项规划（2016—2030年）》已经市政府同意，现印发给你们，请认真组织实施。实施过程中遇到的问题，请径向云浮市城市综合管理局反映。

云浮市人民政府办公室

2017年6月5日

注：因附件内容太大，《云浮市云城区户外广告专项规划（2016-2030年）》此略，如有需要，可向云浮市城市综合管理局咨询或索取。

公开方式：主动公开

抄送：市委各部委办，市人大办，市政协办，市纪委办，云浮军分区，市中级法院，市检察院，省驻云浮单位，各人民团体，各新闻单位。

云浮市人民政府办公室 2017年6月5日印发
