# 云浮市人民政府办公室关于印发云浮市中心城区城市历史风貌保护规划的通知

云浮市人民政府办公室文件

云府办〔2017〕28号

云浮市人民政府办公室关于印发云浮市中心

城区城市历史风貌保护规划的通知

各县（市、区）人民政府，市政府各部门、各直属机构：

《云浮市中心城区城市历史风貌保护规划》已经市政府同意，现印发给你们，请认真组织实施。实施过程中遇到的问题，请径向市规划编制委员会和市住房和城乡建设局反映。

云浮市人民政府办公室

2017年6月21日

注：因附件内容太大，《云浮市中心城区城市历史风貌保护规划》此略，如有需要，可向市规划编制委员会和市住房和城乡建设局咨询或索取。

公开方式：主动公开

抄送：市委各部委办，市人大办，市政协办，市纪委办，云浮军分区，市中级法院，市检察院，省驻云浮单位，各人民团体，各新闻单位。

云浮市人民政府办公室 2017年6月21日印发
