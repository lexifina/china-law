# 云浮市人民政府办公室关于印发云浮市行政村“村村通班车”专项行动工作方案的通知（云府办函〔2017〕135号）

云浮市人民政府办公室

云府办函〔2017〕135号

云浮市人民政府办公室关于印发云浮市行政村“村村通班车”专项行动工作方案的通知

各县（市、区）人民政府，市直有关部门：

《云浮市行政村“村村通班车”专项行动工作方案》已经市人民政府同意，现印发给你们，请认真贯彻执行。执行过程中遇到的问题，请径向市交通运输局反映。

云浮市人民政府办公室

2017年11月27日

云浮市行政村“村村通班车”专项行动工作方案

根据《广东省交通运输厅印发关于加快推进全省行政村通客运班车的实施意见的通知》（粤交运〔2017〕698号）的要求，结合《广东省交通运输厅关于下达2017年和2018年未通客车行政村公路改造指令性计划的通知》（粤交规〔2017〕336号）、《广东省公路安全生命防护工程实施方案》（粤交基〔2016〕682号）、《广东省公路管理局2017年重点推进工程项目督导工作方案》（粤公基函〔2017〕372号）等文件精神，以及省政府今年6月29日在阳江市召开的全省推进农村客运工作现场会工作要求，在我市各县（市、区）按规定制定上报的《行政村“村村通班车”专项行动工作方案》基础上，制定《云浮市行政村“村村通班车”专项行动工作方案》。

一、指导思想

深入贯彻落实党的十九大和十八届五中、六中全会精神和习近平总书记对广东“四个坚持、三个支撑、两个走在前列”重要批示精神，加快推进我市“四好农村路”建设，实现我市行政村“村村通班车”目标，促进城乡公共服务均等化，切实落实“十大民生实事”，为我市全面实现小康社会创造良好条件。

二、工作任务目标

“村村通班车”的工作内容主要有两方面：通村公路已符合规定通行技术标准和要求的（路基路面宽度和安全设施等）马上开通该行政村班车，否则通过窄路拓宽和增加公路安全防护设施后，再开通班车。

（一）行政村通达任务。

我市行政村数量为936个，2016年年底已完成行政村通客运班车757个（通达率80.87%），未通客运班车行政村179个。省政府要求剩余通达任务必须在2017、2018年两年内全部完成，其中省下达我市2017年度行政村客运班车通达工作任务为101个，2018年通达任务78个。

至2017年11月，全市2017年已累计完成通达任务55个，因此全市2017、2018年剩余通达任务总数为124个，其中郁南县17个（2017年8个、2018年9个）、罗定市51个（2017年20个、2018年31个）、云安区23个（2017年7个、2018年16个）、新兴县23个（2017年6个、2018年17个）、云城区10个（2017年5个、2018年5个）。

（二）农村公路基础设施改造任务。

（1）窄路拓宽：省下达我市行政村通客车的窄路拓宽改造项目共368.8公里，其中：罗定市172.2公里，新兴县20.4公里，郁南县91.3公里，云城区18.5公里，云安区66.4公里。

（2）安全生命防护工程（安防工程）：省下达我市行政村通客车的公路安全生命防护工程共450.37公里，其中：罗定市189.54公里，新兴县91公里，郁南县79.29公里，云城区6.1公里，云安区84.44公里。

（三）资金筹措任务。

根据省政府工作安排，上述农村公路窄路拓宽和安防工程改造资金来源为两个方面：（1）是省级补助资金。全市此项资金总额约5202.25万元（分别为：罗定市2325.3万元，新兴县618.2万元，郁南县1126.85万元，云城区274.5万元，云安区857.4万元）。（2）各县（市、区）政府自筹资金。全市此项资金总额约12231.15万元（分别为：罗定市5065.2万元，新兴县968.3万元，郁南县2501.25万元，云城区600.5万元，云安区3095.9万元）。

三、主要工作思路和措施

（一）市交通运输部门牵头加强对各县（市、区）行政村通客车工作指导、协调。

为有效支持并指导各县（市、区）制定的“村村通班车”专项行动工作方案的实施，根据上级政策和工作原则，具体明确、细化我市的有关做法和要求，主要有：（1）编制并明确我市农村公路安全生命防护工程和窄路拓宽具体实施方案，并根据各地实施情况的变化及时制定或出台补充工作意见；（2）引导、优化或创新我市山区行政村通客车多元化发展政策和做法，在客运管理上用足用好上级已有政策，创造条件以满足客车通达任务要求；（3）市交通运输、公安、财政、安监、发改、国土规划、林业等部门依职能加强协调联动，积极参与行政村通客车农村公路设施改造的立项、设计、施工、验收和客运行政许可等各项工作，为加快村村通班车创造基础条件；（4）适时召开工作现场会，及时总结和推广各地工作经验；（5）适时组织各地到省内借鉴学习其他地市的有益做法。

（二）加快行政村通客车农村公路的基础设施改造。

以满足通村公路实际通行班车技术条件为导向，在各地对未通客车行政村农村公路现状进行全面摸查基础上，各地要制定年度工作计划，根据工程难度和资金落实及到位情况，按照先易后难的顺序推进农村公路窄路拓宽和安全设施的改造施工，同时根据群众实际出行需要同步配套农村客运站亭建设，确保公路设施改造完成一条、班车通达一条。

（三）加强对各县（市、区）行政村通客车工作的跟踪、监督。

一是根据上级要求及时收集、汇总和报告各地工作开展和进展情况；二是组织市地方公路管理机构和运管机构对各地行政村通客车的安全设施、窄路拓宽改造工作和客车开通工作进行经常性的工作巡查、督导；三是每月定期对各地的工作进展情况进行现场督查，并向全市通报督查情况。

四、职责分工

根据有关法律法规和省政府对“村村通班车”的工作部署，明晰我市“村村通班车”的“一纵二横”工作责任机制。一是强调县（市、区）人民政府为开通农村客运班线、农村公路基础设施建设养护及推进安全生命防护工程、保障农村群众安全出行的责任主体和实施主体，市政府将加强指导与督促工作；二是市交通运输、公安、财政、安监、发改、国土规划、林业等部门依职能和责任实施行业监督、指导、协调。

（一）各县（市、区）人民政府负责完成本行政区“村村通班车”的工作目标任务，具体制定本行政区“村村通班车”专项行动工作方案、农村公路安全生命防护工程和窄路拓宽具体实施方案，并按上述方案具体组织实施；负责筹措本行政区“村村通班车”所需的基础设施改造资金；负责协调本行政区有关职能部门依职责分别开展相关工作。

（二）市交通运输部门作为牵头部门，负责草拟“村村通班车”专项行动工作方案和公路安全生命防护工程、窄路拓宽工程等实施方案报市政府审定，定期开展全市“村村通班车”督查和通报工作；视各地工作推进情况指导各地规范基础设施建设管理，指导县级交通运输部门优化或创新传统客运组织形式，指导和协助县级交通运输部门开展“村村通班车”通行条件审核；组织市地方公路管理机构和运管机构对全市农村公路基础设施建设和运管服务进行经常性工作巡查、指导；县级交通运输部门统筹协调和明确公路安防工程和窄路拓宽工程基建程序管理要求和工程实施主体、开通班车客运企业和客运组织方式、农村客运行政许可手续和客运管理要求等。

（三）市公安部门应加强对县级公安部门的业务指导、检查，参与需市一级进行道路通行条件审核的工作。

（四）市财政部门应及时对接上级补助计划，及时划转到位补助资金；加强对县级财政部门在专项资金支付、使用和管理上的业务指导。

（五）市发改、国土规划、林业和安监部门应相应加强对县级部门的工作业务指导，把农村公路交通安全监管工作纳入安全生产责任制考核。

五、工作要求

（一）加强组织领导。市政府成立以分管副市长为组长、市交通运输、公安、财政、发改、安监、国土规划、林业等部门相关负责人为成员的工作领导小组，负责统一领导和统筹协调推进全市“村村通班车”的工作。各县（市、区）政府应相应成立工作领导小组，具体负责组织落实本行政区“村村通班车”目标任务。市、县两级交通运输部门作为牵头责任部门，要主动加强与相关职能部门的沟通、配合，确保工作目标一致、思路和措施一致。

（二）明确目标责任。各县（市、区）政府须按照各自制定的专项行动工作方案按时保质完成省下达的2017、2018年度工作任务。各县（市、区）交通运输部门按规定审批时限完成辖区有关基础设施建设图纸批复和符合开通条件的行政村通客车行政许可的审批。此外，各级国土规划、林业部门积极协助按各地窄路拓宽建设计划，在法律法规允许范围和指标内优先保障用地指标。

（三）确保资金和用地保障。各地政府可借鉴以往“村村通公路”的“几个一点”经验做法广开资金筹集渠道，应尽可能统筹本地财力，确保“村村通班车”所需缺口资金得到有效落实。同时对部分窄路加宽所需新增用地和新增拆迁，各地政府应优先保障用地指标和优先组织开展基层征地拆迁工作，确保拓宽施工顺利进行。

（四）注重工作实效。“村村通班车”涉及的行政村及其通村公路量多、面广，工作内容分散，各级政府及其各有关职能部门应注重推动民生实事办出实效，在工程实施主体选择、设计图纸编制和审批、工程招投标方式、工程质量评鉴定和验收等方面，在政策和规定允许的前提下尽量简化工作程序和工作内容，提高工作效率。

（五）加强督促检查。市政府将定期组织开展“村村通班车”督查工作，并将督查情况进行全市通报，同时向社会公开，广泛接受社会公众和媒体监督。对“村村通班车”工作推进不力或进展缓慢的县（市、区）政府，予以通报批评，并对其主要领导采取工作约谈措施；对不能按要求完成“村村通班车”任务的县（市、区），将对其有关负责人进行问责。

公开方式：主动公开
