# 云浮市人民政府办公室关于加强和规范行政机关负责人出庭应诉工作的意见（云府办函〔2017〕143号）

云浮市人民政府办公室

云府办函〔2017〕143号

云浮市人民政府办公室关于加强和规范行政

机关负责人出庭应诉工作的意见

各县（市、区）人民政府，市政府各部门、各直属机构：

为贯彻落实《中华人民共和国行政诉讼法》和《国务院办公厅关于加强和改进行政应诉工作的意见》(国办发〔2016〕54号)、《广东省行政应诉工作规定》（广东省政府令第226号），加强和规范我市行政机关负责人出庭应诉工作，促进依法行政，经市人民政府同意，现结合我市实际，提出以下意见：

一、本意见所称的行政应诉是指在人民法院受理的行政诉讼案件中，行政机关作为被告参与诉讼活动的行为；行政机关负责人是指单位的正职负责人、分管被诉行政行为业务的副职负责人或者其他副职负责人。

二、被诉行政机关正职负责人是该行政机关行政应诉的第一责任人，负有组织依法答辩、举证、出庭应诉和履行人民法院生效裁判的责任。

三、被诉行政机关负责人应当带头履行行政应诉职责，积极出庭应诉。正职负责人不能出庭的，由分管被诉行政行为业务的副职负责人出庭;分管被诉行政行为业务的副职负责人不能出庭的，由其他副职负责人出庭。

行政机关负责人出庭应诉的，可以同时委托1至2名诉讼代理人参加诉讼。行政机关负责人不能出庭应诉的，应当委托行政机关相应的工作人员出庭，不得仅委托律师或者外聘的法律顾问出庭，并应当向人民法院提交不能出庭应诉的书面说明。

委托代理人代为诉讼的，必须向人民法院提交授权委托书，受委托的代理人应当熟悉有关法律法规知识和应诉案件情况。授权委托书应当详细载明委托事项和权限。

委托本行政机关的工作人员中，应当至少有1名是被诉行政行为的承办人或者熟悉相关业务的工作人员。

四、在庭审过程中，行政机关应诉人员应当按照《中华人民共和国人民法院法庭规则》的规定着装；应当尊重审判人员，遵守法庭纪律，不得有妨碍、干扰诉讼活动正常进行的行为；应当熟悉案情，充分陈述作出具体行政行为的事实根据、法律依据和理由，并出示相关证据；应当如实陈述、言行规范、举止文明。

五、下列行政诉讼案件，被诉行政机关负责人应当出庭应诉，不得仅委托相应的工作人员或者律师、法律顾问代为出庭：

(一)涉及重大公共利益、社会高度关注的案件;

(二)案情复杂，可能对本行政机关的行政管理或者行政执法活动产生重大影响的案件;

(三)群体性、可能影响到社会稳定、在本市范围有重大影响的案件;

（四）人民法院书面建议行政机关负责人出庭的案件。

六、因委托行政行为发生的行政诉讼案件，由委托行政机关的负责人出庭应诉。接受委托的行政机关或者机构应当承担具体应诉责任，负责准备被诉行政行为的事实、证据、依据、程序等材料，提出应诉答辩的初步意见;委托行政机关负责法制工作的机构负责行政应诉工作的组织、协调和指导。

行政复议机关作为共同被告的行政应诉案件，由作出原行政行为的行政机关负责人出庭应诉。

七、全市各级行政机关应当结合自身实际，制定措施，确保落实负责人出庭要求。

本年度有行政诉讼案件的行政机关，负责人出庭应诉不得少于1件;年度行政诉讼案件在5件以上10件（含本数，下同）以下的，负责人出庭应诉不得少于2件；年度行政诉讼案件在10件以上的，负责人出庭应诉不得少于3件。

行政机关负责人在行政诉讼案件第一审程序或者第二审程序出庭应诉的，均计入出庭案件件数，但是负责人在被诉行政行为第一审程序和第二审程序中均出庭应诉的，出庭案件件数只按1件计算。

行政机关的年度第一件行政诉讼案件，被诉行政机关负责人应当出庭应诉。

八、行政诉讼案件数量较多或者行政执法任务较重的行政机关，应当适时选择典型案件，组织本机关行政执法人员参加行政审判旁听。

九、被诉行政机关负责人出庭应诉的行政诉讼案件，应诉机关应当在收到人民法院生效裁判后向本级政府法制机构备案。

十、行政机关负责人应当尊重和接受司法机关的监督，支持和配合人民法院依法审理行政案件，积极履行人民法院生效裁判。

十一、行政机关出庭应诉、支持人民法院受理和审理行政案件、履行人民法院生效裁判、行政应诉能力建设以及负责人出庭应诉情况纳入年度依法行政考评范围。

市政府制定依法行政考评办法将酌情考虑正职负责人出庭应诉情况。

鼓励行政机关负责人全程参与行政诉讼案件的审理、和解、履行等环节，借助庭审平台有效化解行政争议。

十二、各级人民政府及其工作部门应当将本行政机关依法履行行政应诉职责情况纳入年度法治政府建设情况报告。

十三、市、县（市、区）政府法制机构应当配合人民法院做好行政机关负责人出庭应诉工作的信息反馈，并定期向本级人民政府和上一级政府法制机构报告负责人出庭应诉工作情况。

十四、法律、法规、规章授权组织的负责人出庭应诉工作依照本意见的规定执行。

十五、本意见自印发之日起施行。
