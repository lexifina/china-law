# 云浮市人民政府办公室关于调整2017年度规章制定计划的通知（云府办函〔2017〕145号）

云浮市人民政府办公室

云府办函〔2017〕145号

云浮市人民政府办公室关于调整2017年度

规章制定计划的通知

各县（市、区）人民政府，市政府各部门、各直属机构：

2017年3月31日，市政府办公室印发了《云浮市人民政府办公室关于印发云浮市人民政府2017年度规章制定计划的通知》（云府办函〔2017〕30号），其中《云浮市城市公共汽电车客运管理规定》属于政府规章制定项目，起草责任单位为市交通运输局。因交通运输部以2017年第5号令形式颁布了《城市公共汽车和电车客运管理规定》，于5月1日起正式施行，因此我市不需再制定该专项地方规章。经市政府同意，《云浮市城市公共汽电车客运管理规定》不再纳入市人民政府2017年度规章制定计划。

云浮市人民政府办公室

2017年12月8日

公开方式：主动公开

抄送：市委各部委办，市人大办，市政协办，市纪委办，云浮军分区，市中级法院，市检察院，省驻云浮单位，各人民团体，各新闻单位。
