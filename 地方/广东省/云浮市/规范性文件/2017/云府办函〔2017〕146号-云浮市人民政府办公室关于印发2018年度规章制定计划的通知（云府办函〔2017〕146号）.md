# 云浮市人民政府办公室关于印发2018年度规章制定计划的通知（云府办函〔2017〕146号）

云浮市人民政府办公室

云府办函〔2017〕146号

云浮市人民政府办公室关于印发2018年度

规章制定计划的通知

各县（市、区）人民政府，市政府各部门、各直属机构：

《云浮市人民政府2018年度规章制定计划》业经市人民政府同意，现印发给你们，请认真组织实施，同时提出如下要求，请一并贯彻落实。

一、有起草任务的单位要高度重视，主要领导要亲自抓、负总责，分管领导要具体落实。要组织精干力量，认真调查研究，创新工作思路、方法，确保按照计划高标准完成规章草案的起草任务，并及时上报市政府审批。

二、起草规章，应当深入调查研究，总结实践经验，广泛听取有关机关、组织和公民的意见。听取意见可以采取书面征求意见、网络征求意见、座谈会、论证会、听证会等多种形式。起草的规章直接涉及公民、法人或者其他组织切身利益，有关机关、组织或者公民对其有重大意见分歧的，应当向社会公布，征求社会各界的意见，起草单位也可以举行听证会。起草规章要切实注重规章的合法性、合理性、可行性和可操作性。

三、报送市政府审批的规章草案，必须经起草单位负责法制工作的机构审核和领导班子集体讨论通过，并由起草单位主要负责人签发。向市人民政府报送规章送审稿的请示，应同时提交：1.送审稿文本、条文注释稿和起草说明；2.以各种形式征求意见的书面意见原件和相关会议记录、对意见的采纳情况和理由说明以及对意见采纳情况、理由的反馈等相关材料；3.进行咨询论证、听证的，还应当提供咨询论证报告、听证报告以及咨询材料、论证记录、听证记录等相关材料；4.负责法制工作机构的审核意见、领导班子集体讨论会议记录或者会议纪要；5.起草所依据或者参考的法律、法规、规章和政策文本；6.其他需要提交的有关材料。其中起草说明应对立法必要性和可行性，立法依据、主要内容以及征求意见的处理情况等作出详细说明。无起草说明或相关资料不齐备的，市法制局可退回起草单位重新办理。

四、未按照市政府当年规章制定计划完成市政府规章起草任务的，起草单位应当及时向市法制局提交书面情况说明，并经市法制局提出意见后报市政府决定。

五、规章的制定程序和具体要求按《规章制定程序条例》、《云浮市人民政府拟定地方性法规草案和制定政府规章程序规定》执行。
