# 云浮市人民政府办公室关于印发云浮市加强个人诚信体系建设分工方案的通知（云府办函〔2017〕151号）

云浮市人民政府办公室

云府办函〔2017〕151号

云浮市人民政府办公室关于印发云浮市加强

个人诚信体系建设分工方案的通知

各县（市、区）人民政府，市政府各部门、各直属机构：

《云浮市加强个人诚信体系建设分工方案》已经市人民政府同意，现印发给你们，请认真贯彻执行。执行过程中遇到的问题，请径向市发展改革局反映。

云浮市人民政府办公室

2017年12月18日

云浮市加强个人诚信体系建设分工方案

为贯彻落实《国务院办公厅关于加强个人诚信体系建设的指导意见》（国办发〔2016〕98号）、《广东省人民政府办公厅关于印发广东省加强个人诚信体系建设分工方案的通知》（粤办函〔2017〕442号），深入推进个人诚信体系建设，健全守信激励与失信惩戒机制，提高全社会信用水平，营造优良信用环境，制定本方案。

一、加强个人诚信教育

（一）加强诚信宣传。

1.将诚信教育贯穿公民道德建设和精神文明创建全过程，推行公民诚信守则。（市委宣传部负责。持续实施）

2.集中宣传信用政策法规、信用知识。（市委宣传部、云浮日报社、云浮广播电视台、市发展改革局、人行云浮市中心支行负责。持续实施）

3.宣传推介诚信典型和无不良信用记录者，加强对严重失信行为的曝光和警示教育，以及网络失信案例警示教育。（市委宣传部、云浮日报社、云浮广播电视台、市发展改革局、人行云浮市中心支行负责。持续实施）

（二）加强诚信教育培训。

4.将诚信教育作为中小学和高校学生思想品德教育的重要内容，建立健全18岁以上成年学生诚信档案。（市教育局负责。持续实施）

5.以公务员、金融机构负责人、企事业单位管理者等为重点，广泛深入开展诚信教育。（市编办、人力资源社会保障局、工商局、金融工作局，人行云浮市中心支行按职责分工分别负责。持续实施）

6.加大对信用从业人员的培训力度，培育信用文化，丰富信用知识，提高信用管理水平。（市发展改革局、金融工作局、人行云浮市中心支行、云浮银监分局负责，持续实施）

7.组织编写信用知识读本、社会信用体系建设发展报告。（市发展改革局、人行云浮市中心支行负责。2018年3月底前）

8.加强信用管理学科建设，支持有条件的高校开设社会信用领域相关课程或开设信用管理相关专业。（市教育局负责。持续实施）

二、加快推进个人诚信记录建设

（一）落实信用代码和实名登记制度。

9.落实公民统一社会信用代码制度，加强对个人身份信息查核工作。（市公安局负责。按照国家、省部署实施）

10.在互联网、邮寄递送、电信、金融账户、人事考试、就业和社会保障、医疗卫生等领域落实实名登记制度。（市委宣传部、教育局、公安局、人力资源社会保障局、市卫生计生局，人行云浮市中心支行、市邮政管理局等按职责分工分别负责。按国家、省部署实施）

（二）完善个人诚信记录。

11.推动建立食品药品、安全生产、消防安全、交通安全、环境保护、生物安全、产品质量、税收缴纳、医疗卫生、劳动保障、住房保障、工程建设、道路运输、金融服务、知识产权、文化市场、司法诉讼、电子商务、志愿服务、水电煤气、电信等消费违约领域的个人诚信记录制度。（市公安局、民政局、司法局、人力资源社会保障局、环境保护局、住房城乡建设局、交通运输局、林业局、商务局、文广新局，市卫生计生局、地税局、工商局、质监局、安全生产监管局、食药监局、科技局、金融工作局，市中级人民法院、检察院，团市委，市国税局、人行云浮市中心支行、云浮银监分局，各县<市、区>人民政府按职责分工分别负责。按照国家和省部署实施）

12.率先抓好公务员、企业法定代表人及相关责任人、律师、教师、医师、执业药师、评估师、税务师、注册消防工程师、注册会计师、审计人员、房地产中介从业人员、金融从业人员、导游、社会工作师、国家注册安全工程师等重点人群诚信记录建设，建立信用档案，实现即时动态更新。（市教育局、公安局、司法局、财政局、人力资源社会保障局、住房城乡建设局、卫生计生局、审计局、地税局、工商局、旅游局、安全生产监管局、金融工作局，市国税局，人行云浮市中心支行、云浮银监分局等按职责分工分别负责。按照国家和省部署实施）

13.鼓励金融信用信息基础数据库和个人征信机构开展重点领域个人征信信息的归集与服务，建立征信机构及相关人员信用档案。（人行云浮市中心支行负责。持续实施）

三、完善个人信息安全、隐私保护与信用修复机制

（一）保护个人信息安全。

14.加强个人信用信息数据库建设和安全防护。（市发展改革局、经济和信息化局负责。持续实施）

15.建立健全个人信息查询管理办法，规范信息查询、使用、审查等活动。（市发展改革局负责。2018年12月底前）

（二）加强隐私保护。

16.重点监控金融机构、类金融机构、征信机构、互联网企业、大数据公司、移动应用程序开发企业，严厉查处泄露、篡改、毁损、出售或者非法向他人提供个人信息等行为。（市委宣传部，市公安局、商务局、工商局、金融工作局，人行云浮市中心支行、云浮银监分局等按职责分工分别负责。持续实施）

（三）建立信用修复机制。

17.按照国家统一部署，建立个人公共信用信息纠错、修复机制，制定异议处理、行政复议等有关办理规程。（市发展改革局负责。2018年12月底前）

四、规范推进个人诚信信息共享使用

（一）推动个人公共信用信息共享。

18.按照全国统一标准和规范，组织归集共享个人信用信息。（市发展改革局、经济和信息化局负责。持续实施）

19.依托公共信用信息管理系统，建立个人公共信用信息数据库，通过市政务信息资源共享平台，推动建立跨区域、跨部门、跨行业个人公共信用信息的互联、互通、互查机制。（市发展改革局、经济和信息化局牵头，市公安局、市卫生计生局配合。2018年12月底前）

20.支持个人征信机构将采集的个人在市场经济活动中产生的严重失信记录，推送至省、市和全国信用信息共享平台。（市发展改革局、人行云浮市中心支行负责。持续实施）

（二）积极开展个人公共信用信息服务。

21.依法依规向社会提供个人公共信用信息授权查询服务。（市信用办负责。持续实施）

22.推动有条件的地区和行业建立个人公共信用信息与金融信用信息基础数据库的共享关系，并向个人征信机构提供服务。（市发展改革局、人行云浮市中心支行，各县<市、区>人民政府负责。2018年12月底前）

五、完善个人守信激励和失信惩戒机制

（一）为优良信用个人提供更多服务便利。

23.出台对具有优良信用记录的个人在教育、就业、创业、社会服务等领域给予重点支持的政策措施。（市直各有关部门、各县<市、区>人民政府负责。2018年12月底前）

24.在办理行政许可、行政确认、行政备案、补助申请、税收减免等过程中，对具有优良信用记录的个人和连续三年以上无不良信用记录的行政相对人，可根据实际情况依法采取“绿色通道”和“容缺受理”等便利服务措施。（市直各有关部门负责。持续实施）

25.鼓励社会机构依法依规使用信用信息和信用产品，对具有优良信用记录的个人给予优惠和便利。（市发展改革局、人行云浮市中心支行会同有关部门负责。持续实施）

（二）对重点领域严重失信个人实施联合惩戒。

26.依法依规对以下四类严重失信行为的个人采取联合行政性惩戒措施：一是食品药品、生态环境、国土资源、工程质量、安全生产、交通违法、消防安全、产品质量等领域的严重危害人民群众身体健康和生命安全的行为。二是贿赂、逃税骗税、恶意逃废债务、恶意拖欠货款或服务费、恶意欠薪、非法集资、网络电信诈骗、合同欺诈、公益诈骗、传销、无证照经营、制售假冒伪劣产品和故意侵犯知识产权、出借和借用资质投标、围标串标、虚假广告、侵害消费者或证券期货投资者合法权益、严重破坏网络空间传播秩序、聚众扰乱社会秩序、在国家考试中组织作弊或向他人提供作弊器材、伪造证明材料骗保等严重破坏市场公平竞争秩序和社会正常秩序的行为。三是当事人在司法机关、行政机关作出判决或决定后，有履行能力但拒不履行或不按要求履行法定义务，严重影响司法机关、行政机关公信力的行为。四是拒不履行国防义务，拒绝、逃避兵役，拒绝、拖延民用资源征用或者阻碍对被征用的民用资源进行改造，危害国防利益，破坏国防设施等行为。（市直各有关部门按职责分工分别负责。持续实施）

（三）推动形成市场性、行业性、社会性约束和惩戒。

27.依法依规披露、曝光个人严重失信行为，依托“信用云浮”网站新媒体等形式向社会公开，完善对个人失信行为的举报机制。（市直各有关部门、各县<市、区>人民政府负责。持续实施）

28.推动行业协会、商会等行业组织建立健全会员信用档案，并按照行业标准、行规、行约等方式开展行业惩戒，视情节轻重对失信会员实行警告、行业内通报批评、公开谴责、不予接纳、限制任职、限制发起、劝退等惩戒措施。（市民政局会同市直有关行业主管部门负责。持续实施）

29.支持征信机构采集严重失信行为信息，纳入信用记录和信用报告，引导市场主体应用信用信息和第三方机构评价报告，对严重失信个人采取差别化服务。（市发展改革局、人行云浮市中心支行按职责分工分别负责。持续实施）

六、强化保障措施

（一）加强组织领导。

30.各县（市、区）、各部门要高度重视个人诚信体系建设工作，明确建设任务和时间节点，细化责任分工和具体措施，并加强经费保障。（市直各有关部门、各县<市、区>人民政府负责。）

31.个人诚信体系建设工作纳入“两建”工作年度考核，各有关部门做好考核准备工作。（各有关部门负责。持续实施）

（二）建立健全法律法规。

32.鼓励有条件的地方探索制定个人诚信建设的规范性文件。（市法制局负责。持续实施）

33.围绕个人信息安全、个人隐私保护、实施信用奖惩等，制定工作规范，修订相关管理制度。（市直各有关部门、各县<市、区>人民政府负责。持续实施）

公开方式：主动公开

抄送：市委各部委办，市人大办，市政协办，市纪委办，云浮军分区，市中级法院，市检察院，省驻云浮单位，各人民团体，各新闻单位。
