# 云浮市人民政府办公室关于全面推行阳光招生制度的通知（云府办函〔2017〕153号）

云浮市人民政府办公室

云府办函〔2017〕153号

云浮市人民政府办公室关于全面推行

阳光招生制度的通知

各县（市、区）人民政府，市政府各部门、各直属机构：

为深入贯彻落实党的十九大精神，全面实施依法治教，服务全面建成小康社会总目标，进一步深化我市教育领域综合改革，营造风清气正的育人环境，促进教育公平，办好人民满意教育，经市人民政府同意，现就全市学校实施阳光招生有关事项通知如下：

一、坚持“四项原则”

（一）坚持学前教育公办幼儿园户籍地段优先原则；

（二）坚持义务教育阶段公办学校免试就近入学原则；

（三）坚持高中阶段按学生志愿、择优录取原则；

（四）坚持招生入学公平公正公开原则。

二、落实“三个不准”

（一）不准以权入学。领导干部一律不得“打招呼、递条子”,干扰学校的正常招生秩序。

（二）不准以钱择校。坚决打击以钱择校、借招生之机欺诈和敛财的违法行为。

（三）不准以情择校。坚决反对以情说托、请求教育行政部门或学校违规安排入学行为。

三、执行“四个严格要求”

（一）严格信息公开。每年5月底前,市、县教育行政部门既要将各自招生工作总体方案与各学校“一校一案”向社会进行公布，又要及时将招生政策、学校信息、招生办法、招生过程、招生结果等以有效方式向社会作出公布，同时做好相关宣传释疑工作。

（二）严格规范招生。各级教育行政部门要进一步加强对学校招生工作的指导和规范管理，要在优质教育资源不足、择校意愿强烈的城区，推广热点小学、初中多校划片，科学合理确定片区招生范围，缓解学区房和大班额等问题。要统筹做好县域内城乡学校招生工作，努力稳定乡村学校生源，均衡编班，防止产生新的城镇大班额大校额问题。如片区或学校学位不足需要分流调剂，由教育行政部门统筹安排，任何学校不得无故拒收。同时，严禁各学校以任何方式收取与入学挂钩的捐资助学费、择校费、借读费等各种费用。

（三）严格造册备案。实行范围外录取学生备案制，各地各学校要对包括军人子女、高层次人才子女教育优待政策和随迁子女等范围外录取学生实行备案，专门做册，并注明录取原因，以备各级教育行政部门检查。

（四）严格履职办事。市、县、镇各级公安、住建、工商、房管、人社等有关职能部门以及各镇（街）村委、社区要严格按照程序配合招生工作，保障材料真实准确。教育部门要加强监督，监管招生工作全过程。同时，自觉接受社会监督，各学校校长是招生工作第一责任人，要确保学校招生工作依法依规进行。

四、加强“三个监管”

（一）定期开展专项检查。每年10月由市政府督查室牵头，会教育等部门组成招生工作监督检查组开展专项检查，随机抽查秋季新生入学编班基本情况，核对备案学生名册，对涉及不规范招生行为的，将由检查组作出通报处理。

（二）畅通监督举报渠道。各地教育行政部门要开通监督投诉电话，对人民群众投诉和举报的招生入学问题，要认真逐一核查，对违反招生工作纪律的违法违纪行为，决不姑息，发现一起，查处一起，曝光一起。招生期间将随机邀请新生家长参与同步监督。

（三）严肃处理违规行为。要坚决查处扰乱我市学校招生工作秩序的违法违规行为，对违法违规的单位或个人要严肃处理。

1.对涉及违反“三个不准”的有关公职人员，报纪检监察部门作出处理。涉嫌犯罪的，移交司法机关处理。监护人通过弄虚作假骗取学位，一经查实，追究相关人员责任。对有令不行、有禁不止的单位或个人违法违规干扰招生秩序，情节严重造成重大影响的，追究其党纪政纪责任。

2.涉及违规招生入学的学生，由教育行政部门处理。属义务教育阶段的，由教育部门造册安排回户籍地学校就近入读，属高中阶段的，教育部门将不予建立学籍。
