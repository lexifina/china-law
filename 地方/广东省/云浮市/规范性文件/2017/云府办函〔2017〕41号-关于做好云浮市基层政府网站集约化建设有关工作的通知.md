# 关于做好云浮市基层政府网站集约化建设有关工作的通知

云浮市人民政府办公室

云府办函〔2017〕41号

关于做好云浮市基层政府网站集约化建设

有关工作的通知

各县（市、区）人民政府，市政府各部门、各直属机构：

按照《广东省人民政府办公厅关于推进基层政府网站集约化建设的通知》（粤办函〔2017〕156号）要求，为做切实好我市基层政府网站集约化建设，提高我市政府网站管理水平，现就有关工作通知如下：

一、及时报送政府网站建设情况

（一）县级政府各部门、乡镇政府（街道办事处）政府网站不再单独建设，已建成的原则上必须关停，关停后网站的相关功能整合迁移至县级政府门户网站，以栏目或频道形式呈现。各县（市、区）政府办公室在5月15日前将本辖区拟关停迁移和拟保留的政府网站情况（拟保留的政府网站要提出书面申请）报市政府办公室政务公开科和市经信局信息中心。

（二）市政府各部门、各直属机构对外服务较少及没有人力、财力保障的网站可选择关停。各部门、各直属机构要加快整合内设机构及直属单位网站，原则上1个部门只保留1个政府网站。各部门、各直属机构在5月15日前将所属政府网站有关情况（是否关停或保留的原因理由以及内设机构网站整合方案）报市政府办公室（政务公开科）和市经信局信息中心。

二、制定政府网站集约化建设方案。各县（市、区）政府办公室牵头制定本县（市、区）政府网站集约化建设方案，于5月25日前报市政府办公室（政务公开科）和市经信局信息中心。

三、做好政府网站关停申请。拟关停的政府网站主办单位在6月底前要通过全国政府网站信息报送系统逐级报批申请永久关停。

四、签订拟保留政府网站运维责任书。各级部门政府网站经监测符合全国政府网站普查标准的，分别由市政府办公室以及各县（市、区）政府办公室与各部门签订网站运维责任书，加强网站的运维管理。

五、做好拟关停的政府网站内容迁移。拟关停的政府网站主办单位要同步正常维护至网站数据迁移结束，并在首页显著位置持续1个月悬挂网站关停和内容迁移去向等公告信息。公告期满后及时注销网站域名、注册标识和证书信息。该项工作在12月底全部完成。

各县（市、区）政府办公室是本地区政府网站建设管理的第一责任主体，要切实加强对基层政府网站集约化建设工作的组织领导，按照本通知规定的时间节点要求，强化统筹协调，明确责任分工，加快部署推进。市政府办公室将加强对各县（市、区）政府网站集约化建设工作的监督指导，并适时组织专项督查，对行动迟缓、拖延推诿、未按统一时限要求完成工作任务的，予以通报批评。各县（市、区）政府网站集约化建设工作落实情况纳入全市政府网站考评内容。

云浮市人民政府办公室

2017年4月21日

公开方式：主动公开

抄送：市委各部委办，市人大办，市政协办，市纪委办，云浮军分区，市中级法院，市检察院，省驻云浮单位，各人民团体，各新闻单位。
