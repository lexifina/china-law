# 云浮市人民政府办公室关于印发《云浮市政务公开重点工作任务分工及进度安排方案》的通知

云浮市人民政府办公室

云府办函〔2017〕67号

云浮市人民政府办公室关于印发《云浮市

政务公开重点工作任务分工及进度

安排方案》的通知

各县（市、区）人民政府，市政府各部门、各直属机构：

为贯彻落实《中共广东省委办公厅、广东省人民政府办公厅印发<关于我省全面推进政务公开工作实施意见>的通知》（粤办发〔2016〕22号，下称《实施意见》）和《广东省人民政府办公厅转发国务院办公厅关于全面推进政务公开工作的意见实施细则的通知》（粤府办〔2016〕130号，下称《实施细则》）精神，进一步做好我市政务公开工作，经市人民政府同意，现将《云浮市政务公开重点工作任务分工及进度安排方案》（下称《分工方案》）印发给你们，并提出如下意见，请结合实际一并认真贯彻执行。

一、加强组织领导，切实提高认识。我市的《分工方案》是根据《实施意见》和《实施细则》的精神，结合我市实际进一步细化工作任务、分年度推进而制定的具体实施方案。各地、各部门要高度重视，充分认识《分工方案》的重要性和必要性，切实增强做好政务公开工作的责任感和紧迫感，要进一步加强组织领导，将政务公开工作，特别是重点任务的分工安排纳入本地区本部门工作的重要议事日程，主要负责同志要亲自抓，每年至少听取一次政务公开工作汇报，研究部署推进相关工作; 分管领导要具体抓，全面加强政务公开工作力量配置建设，落实专人专职，定人定岗负责《分工方案》的各项任务，并紧紧围绕深化改革、促进经济发展、改善民生和助力政府建设大力推进信息公开，围绕扩大政务参与主动加强解读回应，围绕增强公开实效加强能力建设。

二、强化措施落实，确保有效推进。政务公开各项重点工作任务涉及面广、时间紧任务重，各地、各部门要认真研究《实施意见》和《实施细则》，精准把握中央和省委、省政府决策部署和工作要求，全面对照《分工方案》提出的33项重点工作部署，明确时间节点和任务安排，结合本地、本部门的实际抓紧制定完成任务的具体措施和办法，并在本方案公布后30个工作日内在本地区本部门政府网站公开。同一项工作涉及多个地区多个部门的，牵头单位要切实负起牵头职责，做好牵头组织、联络协调、督查督办和情况反馈等工作，要拿出切实可行的落实方案，涉及需要相关单位配合的，要主动沟通协商。各相关单位要树立协作意识，根据各自职能，积极密切配合，形成工作合力，确保《分工方案》各项任务按时间要求有效推进和顺利实施。

三、强化监督考核，确保工作落实。为确保《分工方案》各项任务安排得到有效落实，市政府将进一步落实相关的监督考核，完善激励和问责机制，制定督查通报制度，定期通报各地、各部门的实施进度情况。同时，将各地、各部门对《分工方案》每年的落实推进情况列入政府网站年度考评，严格进行考核，对工作落实不到位的，将在全市范围进行通报批评，并追究相关人员责任。各地、各部门也要对本地区本部门落实《分工方案》情况开展跟踪落实，加强监督考核，落实相关问责机制，做到有布置、有督促、有检查、有结果，确保各项工作任务按时按要求完成。各地、各部门均要确定专人负责政务公开信息动态报送工作，工作落实情况要纳入政府信息公开工作年度报告并向社会公布，接受社会监督。
