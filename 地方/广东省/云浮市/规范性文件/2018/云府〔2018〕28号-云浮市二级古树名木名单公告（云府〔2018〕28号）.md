# 云浮市二级古树名木名单公告（云府〔2018〕28号）

云府〔2018〕28号

云浮市二级古树名木名单公告

根据《广东省绿化委员会关于开展新一轮古树名木资源普查建档工作的通知》（粤绿〔2016〕1号）要求，为全面摸清和掌握我市古树名木资源状况，切实加强全市古树名木保护管理工作，市绿委办组织开展了全市古树名木普查建档工作，并建立了科学系统的古树名木保护管理系统。目前，该工作已完成。

经调查统计，全市树龄在300—499年的二级古树名木共计199株，主要为荔枝、红椿和榕树等。根据《广东省古树名木保护条例》的有关规定，现向社会公布《云浮市二级古树名木每木调查表》，或请登录云浮林业局网站查询。

请各古树名木管护责任单位及广大市民认真履行《广东省古树名木保护条例》的有关规定，对所公布的古树名木进行有效保护及管理。

特此公告。
