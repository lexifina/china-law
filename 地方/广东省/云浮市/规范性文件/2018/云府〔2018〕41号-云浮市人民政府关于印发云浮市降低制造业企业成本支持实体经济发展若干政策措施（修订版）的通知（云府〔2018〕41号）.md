# 云浮市人民政府关于印发云浮市降低制造业企业成本支持实体经济发展若干政策措施（修订版）的通知（云府〔2018〕41号）

YFFG2018012

云府〔2018〕41号

云浮市人民政府关于印发云浮市降低制造业

企业成本支持实体经济发展若干政策

措施（修订版）的通知

各县（市、区）人民政府，市政府各部门、各直属机构：

现将《云浮市降低制造业企业成本支持实体经济发展的若干政策措施（修订版）》印发给你们，请认真组织实施。实施过程中遇到的问题，请径向市经济和信息化局反映。

云浮市人民政府

2018年12月4日

云浮市降低制造业企业成本支持实体经济

发展的若干政策措施（修订版）

为深入贯彻习近平新时代中国特色社会主义思想和党的十九大精神，落实党中央、国务院关于着力振兴实体经济的决策部署，落实《广东省人民政府关于印发广东省降低制造业企业成本支持实体经济发展若干政策措施（修订版）的通知》（粤府〔2018〕79号），进一步降低制造业企业成本，支持实体经济发展，制定以下政策措施：

一、降低企业税收负担

在国家规定的税额幅度内，根据《云浮市人民政府关于印发云浮市城镇土地使用税税额标准调整方案的通知》（云府函〔2017〕118号）要求，继续降低城镇土地使用税适用税额标准。在国家规定的税额幅度内，将车辆车船税适用税额降低到法定税率最低水平。降低符合核定征收条件企业的购销合同印花税核定征收标准。允许符合条件的省内跨地区经营制造业企业的总机构和分支机构实行汇总缴纳增值税，分支机构就地入库。全市契税纳税期限统一调整到办理房屋、土地权属变更前。全市各县（市、区）核定征收企业所得税应税所得率按国家规定的最低应税所得率确定。对装备制造等先进制造业、研发等现代服务业符合相关条件的企业和电网企业在一定时间内未抵扣完的增值税进项税额予以退还。2018年-2022年，对境外投资者从中国境内居民企业分配的利润在云浮再投资项目，省奖励云浮的资金，全额用于支持外商在云浮扩大生产经营、新投资鼓励类项目等。（市税务局、市财政局、市商务局负责）

二、降低企业用地成本

划设工业用地控制线，年度建设用地供应计划充分保障工业用地供给：“三旧”改造土地及省追加的新增城乡建设用地优先保障先进制造业需求；纳入省相关“十三五”规划的制造业项目享受省重点建设项目待遇。对于各地优先发展、符合有关产业政策要求的支柱产业且用地集约的工业项目，土地出让底价可按所在地土地等别对应工业用地最低价标准的70%执行。允许对工业项目按照规划确认的用地围墙线内面积出让。工业用地出让最长年限为50年，根据企业意愿，对有弹性用地出让需求的工业企业实行弹性年期出让供地，按照出让年期与工业用地可出让最高年期的比值确定年期修正系数，对届满符合续期使用条件的，可采用协议出让方式续期。以先租后让方式供应的工业用地，租赁期满达到合同约定条件的，在同等条件下原租赁企业优先受让。（市国土规划局、市发展改革局负责）

三、降低企业社会保险成本

适度降低部分社会保险险种费率，根据省统一部署，推动出台《云浮市进一步促进就业若干政策措施》，在2019年阶段性降低用人单位职工基本医疗保险的缴费费率。稳步实施工伤保险费率浮动政策,自2018年7月起实施浮动，并在浮动基础上统一阶段下调各参保单位工伤保险的现行缴费费率，进一步降低工伤保险平均费率水平。从2018年7月起，实施失业保险费率浮动政策，对一定时期内不减员或者少减员的用人单位，适当下浮费率。对依法参加失业保险并足额缴费、上年度未裁员或裁员率低于统筹地区城镇登记失业率的企业，鼓励其申请稳岗补贴，按该企业及其职工上年度实际缴纳失业保险费总额的50%给予稳岗补贴。现行社会保险征收政策维持稳定，在社会保险费征收机构改革到位前，一律保持现有征收政策不变，严禁自行对企业历史欠费进行集中清缴。（市人力资源社会保障局负责）

四、降低企业用电成本

扩大电力用户参与电力交易市场规模。将参加电力市场交易的用户范围扩大到全市产业转移工业园（含产业转移集聚地），以及我市“四新一特”产业中的工业企业，视同列入我市的产业转移工业园项目，参与电力市场交易。支持高新技术、互联网、大数据、高端制造业参与电力市场交易。通过扩大跨省区电力交易规模、降低国家重大水利工程建设基金征收标准、督促自备电厂承担政策性交叉补贴、降低天然气发电上网电价等措施，落实降低全省一般工商业电价，清理和降低电网环节收费。精简企业报装资料，提供客户身份证明、物业权属证明和政府部门要求的相关资料即可报装；缩短用电报装时限，10千伏单电源客户接电时间平均压减至80天以内。压缩业扩配套工程项目行政审批流程和时限，由各地政务中心组织相关单位实施并联审批，电力规划施工报建时间压减至15天以内。推动电力网管沟纳入市政府统一规划，在新建设的城市道路时，政府相关部门应同步建设电力管廊或预留管线位置；对电力基础设施配置用地纳入住宅小区、工业园区的规划审查预控，确保满足电网建设和用户用电需要，针对重要电力管廊，试点推进公共电缆沟资产接收工作。对具备电力承装资质的企业所承建的电力建设项目，供电企业均应无歧视接入电网并及时送电。（市经济和信息化局、市发展改革局、云浮供电局负责）

五、降低企业运输成本

根据省交通运输厅的部署，省属国有交通企业全资和控股的高速公路路段对使用粤通卡支付通行费的合法装载货运车辆，试行通行费八五折优惠。全市停止审批新的普通公路收费项目，取消普通公路收费。（市交通运输局、市发展改革局、市财政局负责）

六、降低企业融资成本

鼓励大型骨干企业设立财务公司，为上下游企业提供低成本融资服务。充分发挥“中征应收账款融资服务平台”等金融基础设施作用，鼓励金融机构为制造业核心企业产业链上下游中小微企业提供应收账款融资。支持政府相关部门加大涉企政务信息公开力度，便利金融机构获取企业信用信息，进一步发挥“广东省（云浮市）中小微企业信用信息和融资对接平台”作用。凡我市“四新一特”产业中的中小微企业，可列入我市中小微企业信贷风险补偿资金企业库，可获得合作的银行业金融机构的信贷支持，享受中小微企业信贷风险补偿政策支持，以及可享受与其合作的银行业金融机构相关业务可执行的优惠利率。推动优质企业上市挂牌融资,根据《云浮市推进企业上市奖励办法》，对在“新三板”成功挂牌的企业以及在深、沪及境外股票市场成功上市和通过买壳、借壳在境内外股票市场成功上市的企业给予一次性奖励。进一步健全中小微企业融资政策性担保和再担保机构。通过发展各类金融机构，解决中小微企业融资难融资贵问题。鼓励企业利用股权出质方式拓宽融资渠道。（市金融工作局、人民银行云浮市中心支行、市银监局、市经济和信息化局、市财政局、市工商局、市商务局、市发展改革局负责）

七、降低企业制度性交易成本

压缩审批时限，企业开办减至5个工作日，工业投资项目核准办结时限减至10个工作日，工业投资项目备案办结时限减至3个工作日。全面推广应用“粤省事”办事平台，继续优化和完善电子证照库，实现政府部门各类审批信息共享共用。对省权限范围内的12类工业产品实行“先证后核”审批模式、4类工业产品实行“承诺许可”审批模式。按省部署建设完善我市网上“中介服务超市”，加强中介服务收费监管。及时公布产业园区（集聚地）规划环评的审查情况。对政府部门所属事业单位开展与本部门行政审批相关的中介服务进行全面清理，原则上2018年底前全部完成转企改制或与主管部门脱钩。（市工商局、市发展改革局、市经济和信息化局、市质监局、市编办、市环境保护局负责）

八、支持工业企业盘活土地资源提高利用率

允许制造业企业的工业物业产权按幢、层等固定界限为基本单元分割，用于引进相关产业链合作伙伴的产业项目。在符合规划、不改变用途的前提下，在工业用地、仓储用地上对工矿厂房、仓储用房进行改建、扩建和利用地下空间，提高容积率、建筑密度的，不再征收土地价款差额。支持和鼓励各地建设高标准厂房和工业大厦，严格遵守工业建筑和高层建筑的消防要求，高标准厂房和工业大厦可按幢、层等固定界限为基本单元分割登记和转让。国家级和省级开发区、产业转移园区（产业转移集聚地）建设的高标准厂房和工业大厦用地，经市政府确认其容积率超过2.0的后，可向省申请返还用地指标。进一步规范工业厂房租售市场管理，工业厂房要直接面向用于发展工业或与工业生产相配套的生产性服务业的市场主体销售或租赁。支持大型骨干企业开办非营利性职业院校（含技工院校），相关用地允许参照公办教育类别以划拨形式提供。（市国土规划局、市经济和信息化局、市住房城乡建设局、市人力资源社会保障局负责）

九、支持制造业高质量发展

培育制造业新兴支柱产业，推动传统产业转型升级，深入实施质量强市战略和标准化战略。推广先进质量管理方法，推动企业建立全员、全方位、全过程的质量管理体系。2020年前财政对我市高端装备制造、绿色低碳、生物医药、数字经济、新材料等新兴支柱产业培育予以重点支持。对上述制造业新兴支柱产业的标志性重大项目落地、关键核心技术攻关、重大兼并重组、颠覆性创新成果转化等给予优先支持。到2020年25%以上规上工业企业设立研发机构，鼓励企业积极申报高新技术企业享受相关优惠政策。2020年前财政对企业开展数字化、网络化、智能化和绿色化技术改造给予重点支持，主营业务收入1000万元以上工业企业可享受技术改造事后奖补（普惠性）政策。大力实施消费品工业“三品”战略、开展传统产业绿色转型升级，推动新工艺新技术应用。大力发展工业互联网，支持工业企业运用工业互联网新技术新模式“上云上平台”实施数字化升级，有效降低企业生产经营成本。（市经济和信息化局、市发展改革局、市科技局、市财政局、市税务局、市统计局、市质监局负责）

十、加大重大产业项目支持力度

对符合我市产业政策、投资额5亿元以上重大制造业项目，实行市直部门专员服务制，专员范围包括发展改革、经济和信息化、财政、人力资源社会保障、国土规划、环境保护、商务等职能部门工作人员。其中投资额10亿元以上项目由厅级干部担任专员，5-10亿元项目由处级干部担任专员，全程负责跟踪服务项目落地和建设。各县（市、区）要参照省、市建立重大制造业项目协调机制，重大项目由县（市、区）领导挂钩服务。对符合《广东省重大产业项目计划指标奖励办法》奖励条件的重大产业项目，可按照相应标准向省申请用地指标奖励，其中对于投资20亿元以上、符合投资强度等相关条件并完成供地手续的重大产业项目，可向省申请全额奖励用地指标。对引进重大产业项目但当年用地指标确有不足的，可按规定向省申请预支奖励指标。（市发展改革局、市经济和信息化局、市财政局、市人力资源社会保障局、市国土规划局、市环境保护局、市商务局负责）

各地、各部门要将政策宣传贯彻落实到企业，落实情况于每年12月15日前报市经济和信息化局，由该局汇总报告市人民政府。省政府已将政策落实情况纳入重点督查范围，市人民政府视情况对各县（市、区）、各部门开展专项督查，对工作不力的县（市、区）、各部门及相关责任人实施问责。市相关部门要加强对县（市、区）的指导和服务，并于1个月内修订出台相关实施细则，已有政策措施相关规定与本规定不一致的，按照本文件有关规定执行。

本政策措施自印发之日起实施，有效期三年。

公开方式：主动公开
