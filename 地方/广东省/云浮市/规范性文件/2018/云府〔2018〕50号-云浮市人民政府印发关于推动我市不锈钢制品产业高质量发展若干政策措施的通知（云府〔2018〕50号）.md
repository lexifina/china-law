# 云浮市人民政府印发关于推动我市不锈钢制品产业高质量发展若干政策措施的通知（云府〔2018〕50号）

YFFG2018019

云府〔2018〕50号

云浮市人民政府印发关于推动我市不锈钢

制品产业高质量发展若干

政策措施的通知

各县（市、区）人民政府，市政府各部门、各直属机构：

现将《关于推动我市不锈钢制品产业高质量发展若干政策措施》印发给你们，请认真组织实施。执行中遇到的问题，请径向市经济和信息化局反映。

云浮市人民政府

2018年12月30日

关于推动我市不锈钢制品产业高质量

发展若干政策措施

不锈钢制品产业是我市的支柱产业之一。近年来，我市深入贯彻创新驱动发展战略，大力支持不锈钢制品产业开展核心技术攻关、建设科研机构和产业创新平台、实施智能化生产技术改造等，取得了重大突破，产业发展质量和效益明显提升。但是，我市不锈钢制品行业仍存在产业链条不完善、企业自主创新能力不强、高端人才缺乏等瓶颈问题，为贯彻落实市委六届四次全会精神，进一步推动我市不锈钢制品产业高质量发展，特制定以下政策：

一、加大对不锈钢制品企业的融资支持和专项资金扶持。全面贯彻落实“五平台五基金”融资政策，结合不锈钢制品产业发展实际，为不锈钢制品企业“量身定做”更多融资政策和融资产品。完善不锈钢制品企业政策融资担保平台建设，推动云浮市普惠融资担保股份有限公司等担保机构加大对不锈钢企业的支持力度，对信用状况良好、生产经营正常的不锈钢制品企业按照贷款本金原则上收取不高于2%的担保费，并与风险程度挂钩。加大新三板发展基金对不锈钢制品企业的支持，着力推动优质不锈钢制品企业股改上市。加大对企业技术改造融资贷款政策支持，对企业开展自动化、智能化生产技术改造项目的，按贷款第一会计年度利息的10%给予企业补助，每年最高不超过10万元。从2019年起，对不锈钢制品产业发展进行倾斜支持，重点在不锈钢制品产业公共技术（服务）平台建设、企业技术改造和技术创新、企业人才引进、融资担保、品牌发展、工业互联网、市场开拓、节能环保等方面给予资金支持。

二、大力支持不锈钢创新中心建设。充分发挥新兴不锈钢创新中心的基础优势以及广东省质量监督不锈钢制品检验站的技术支撑作用，整合全市技术创新资源，将不锈钢创新中心建设成为集技术研发、科技成果转化、产品质量检测、标准服务、金融服务、人才培训、企业咨询等为一体的大型综合性行业服务平台。加大不锈钢创新中心在市级层面的宣传引导和推广，推动全市电子商务、工业设计、法律顾问、品牌推广等各类生产服务业企业进驻该中心，努力将该中心建设成为全省生产性服务业功能区示范单位。加大财政支持力度，将不锈钢制品专项资金优先用于支持不锈钢创新中心相关项目建设。引导扶持不锈钢创新中心与高校、科研机构联合共建新型研发机构，开展科技研发、成果转化、人才培养及产业孵化，努力通过省级、市级新型研发机构认定。大力开展创业项目政企合作，推动各类科技型初创企业落户不锈钢创新中心。

三、着力提高企业自主创新能力。大力支持有条件的不锈钢制品企业创建省级、国家级重点实验室和工程技术研发中心，加快构建以企业为主体的技术创新体系。对新认定的国家级企业技术中心、重点实验室和工程技术研发中心，市给以叠加奖励。如经评审获得国家级专项资金奖励的，按奖励资金20％的比例给予奖励，最高不超过50万元；对新认定的省级企业技术中心、重点实验室和工程技术研发中心，如经评审获得省级专项资金奖励的，按奖励资金10％的比例给予奖励，最高不超过20万元。鼓励不锈钢企业内部科研基础设施或检测设备加入广东省大型科研仪器平台进行开放共享，为企业提供研发实验和产品质量检测等技术服务。贯彻落实省工业设计扶持政策，帮助不锈钢制品企业申报省级、国家级工业设计中心，支持不锈钢创新中心申报工业设计服务平台。支持不锈钢企业参加各类工业设计大赛，对获得各类工业设计大赛奖励的企业，市经信部门优先推荐企业申报省级生产性服务业政策及相关专项资金。

四、加大不锈钢创新人才政策支持力度。大力支持不锈钢制品企业创建博士后科研工作站、博士后创新实践基地，对经过国家、省批准建立的博士后科研工作站、博士后创新实践基地，分别给予50万元、30万元建站启动经费。对不锈钢企业引进各类高层次人才，按有关政策规定给予相应补贴。对成功入选国家、省各类人才工程资助计划的团队或个人，按照国家或省最高资助额的50%给予一次性配套资金扶持。支持企业创建技能大师工作室，对获批设立的国家级技能大师工作室、省级技师工作站、市级名师工作室，市分别给予10万元、5万元、2万元的建设经费资助。支持不锈钢制品企业吸纳高校毕业生，对每年吸收不少于10名以上大学生实习实训的企业，按我市最低工资标准的80%给予该企业大学生实习实训工资补助（每年补助期限最长不超过6个月）。鼓励不锈钢企业与职业院校、技工院校、民办职业培训学校开展校企合作，联合培养技术工人，对开展“招工即招生、入企即入校、企校双师联合培养”等模式新型学徒制的不锈钢制品企业给予不低于每人每年4000元补贴。鼓励不锈钢制品企业完善技能人才激励机制，自主建立制度并评定聘用首席技师。支持企业开展人才评价，对企业结合国家职业标准与生产实际需求开展企业人才评价工作的，给予题库开发经费支持。鼓励和引导不锈钢制品企业开展国际人才交流与合作，促进国际人才与不锈钢产业创新的有效对接。

五、推动不锈钢工业互联网应用发展。支持企业开展“两化融合”、“互联网+”创新试点工作，对获得省“两化融合”贯标试点或省“互联网+”试点项目的不锈钢制品企业，在省级工业互联网政策申报方面优先给予倾斜。支持企业创建省“互联网+先进制造”标杆企业。结合不锈钢制品企业生产经营特点，推动不锈钢制品企业与互联网企业、电信运营商、系统集成商、院校研究机构等各类机构加强产学研和市场合作，加快构建资源丰富、功能齐全、服务完善、创新水平高的不锈钢工业互联网平台。引导我市不锈钢企业核心业务系统向云端迁移，降低不锈钢制品企业信息化投入成本。

六、支持企业开展技术改造升级。大力推广不锈钢制品行业先进生产技术，建立健全促进企业技术改造的长效机制，推动不锈钢制品企业向自动化、智能化、高端化发展。大力实施不锈钢制品行业机器人应用计划，对购买应用机器人等设备开展技术改造的企业，如企业技改项目获得省级企业技术改造设备更新（机器人应用）专题资金补助的，市级财政给以大力支持。落实省级企业技术改造事后奖补政策，鼓励企业加大设备和技术投入，引进和利用先进自动化生产设备等进行技术改造升级，对开展技术改造后获得财政税收增量贡献的企业，按照省有关政策给予事后奖补。支持企业开展省级智能制造试点示范项目建设和公共服务平台项目建设，提高企业自动化和智能化水平，强化公共服务支撑。支持企业技改迁建或扩建，优先安排技改迁建或扩建企业用地、林地指标，支持不锈钢制品企业集聚发展、入园发展、高质量发展。

七、全力降低企业生产经营成本。市县两级政府有关部门要持续深入贯彻落实省降低制造业企业成本支持实体经济发展的若干政策措施，不断完善政策操作指引和细则，不定期到不锈钢制品企业开展上门宣贯，着力解决好政策落实环节的“最后一公里”，确保政策不折不扣落实到企业。着力降低不锈钢制品企业社保费成本，按照省的统一部署，适度降低部分社会保险险种费率，阶段性降低企业单位职工医疗保险缴费费率，对依法参保、裁员率低的企业实行失业保险单位缴费比例适当下调，在全面实施工伤保险浮动费率的基础上，统一阶段下调各参保单位工伤保险现行缴费费率。继续发挥失业保险援企稳岗作用，对上年度依法参加失业保险、裁员率低的企业返还50%的失业保险费。对符合条件的不锈钢制品企业，按规定落实社保补贴、岗位补贴、职业培训补贴、创业资助、租金补贴、创业带动就业补贴等扶持政策。对用工量1000人以上或一次性新增用工200人以上的不锈钢企业，由企业所在地县级人力资源社会保障部门设立就业服务专员，提供全程用工政策对接和协调服务。全面落实国家出口退税有关政策，进一步降低不锈钢制品企业出口成本。

八、支持企业创建自主品牌和参与标准制订（修订）。制定不锈钢制品自主品牌发展目录，对列入自主品牌发展目录的企业、产品、商标进行重点培育，按照储备一批、成熟一批、推荐一批的做法，形成自主品牌创建梯队，加快推动企业创建自主品牌。对获得中国驰名商标的企业，市政府一次性给予30万元奖励；对获得省名牌产品企业，市政府一次性给予10万元奖励；对获得市政府质量奖、提名奖的企业，市政府一次性给予企业20万元和3万元奖励。支持不锈钢制品企业收购国外品牌，对企业成功收购国外品牌的，根据品牌的综合实力评估，按照“一事一议”的方式给予财政支持。大力创建“全国不锈钢餐厨具产业知名品牌创建示范区”。支持企业参与行业标准制定（修订）工作，企业每主导或参与制定（修订）1项国际标准、国家标准、行业标准、地方标准和联盟（团体）标准，市政府一次性给予不超过20万元、10万元、8万元、5万元和2万元的奖励，具体金额按企业参与标准制定（修订）的程度来确定。多家企业参与同一项标准制定的，只对参与程度最高的企业给予奖励。

九、支持企业开拓市场。重点支持不锈钢制品企业参与“一带一路”沿线国家举办的各类行业展会，商务部门牵头组织企业抱团参展，落实国外参展的资金补贴政策，切实帮助企业开拓“一带一路”国际市场。支持不锈钢制品企业参加“广交会”等国内外大型展览会，为不锈钢制品企业争取更多展位，扩大参展规模。深化海关审批制度改革，简化通关手续，优化通关环境。加大国际贸易政策研究和风险预警，引导企业有效规避出口风险。支持新兴县建设国家级不锈钢制品外贸转型升级示范基地。

十、支持企业开展绿色生产和资源综合利用。重点推动不锈钢制品企业开展绿色工厂、绿色设计产品、绿色供应链管理建设，对通过清洁生产审核的企业，优先推荐申报国家、省级节能专项资金。支持企业开展能源审计、能效对标、绿色清洁生产等节能基础工作，帮助企业提高节能环保管理能力和水平。严格规范管理不锈钢制品企业的“三废”排放，着力引进和培育不锈钢废料资源综合利用企业，科学有效处理不锈钢工业固体废弃物，实现资源综合利用。

市直有关部门在贯彻落实以上政策的同时，要着力抓好省“实体经济新十条”、“外资十条”、市“实体经济新十条”、科技创新“1+10”政策、“1+3”柔性引才政策、融资贷款“五平台五基金”政策等一系列惠企政策，加快形成政策叠加效应，推动全市所有不锈钢制品企业享受政策支持。本政策有关内容与我市现有政策有重复的，按照本政策规定为准。同一个企业（项目）不能重复申报享受同一级别的同一项政策。

本政策自公布之日起实施，有效期3年。
