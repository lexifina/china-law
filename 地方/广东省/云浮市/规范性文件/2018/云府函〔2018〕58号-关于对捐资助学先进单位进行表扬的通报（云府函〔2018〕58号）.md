# 关于对捐资助学先进单位进行表扬的通报（云府函〔2018〕58号）

云府函〔2018〕58号

关于对捐资助学先进单位进行表扬的通报

各县（市、区）人民政府，市政府各部门、各直属机构：

近年，市委、市政府积极实施教育优先发展战略，全市上下形成了党委重教、政府抓教、全民兴教、社会助教的浓厚氛围，涌现了一批关心和支持教育事业发展的先进单位，他们奉献爱心、慷慨解囊、积极捐资助学，为我市的教育事业作出了突出的贡献。为表扬先进，树立典型，进一步弘扬捐资助学的良好社会风尚，推动我市教育事业健康快速发展，市政府决定对2012年我市开展教育“创强”工作以来踊跃捐资助学的单位进行表扬，授予广东翔顺集团有限公司等3个单位“捐资助学突出贡献单位”称号，授予广东凌丰集团股份有限公司等9个单位“捐资助学模范单位”称号，授予罗定市罗镜镇教育基金等7个单位“捐资助学表扬单位”称号（名单详见附件）。

希望受表扬的单位珍惜荣誉，再接再厉，继续关心和支持我市教育事业发展。希望社会各界以先进为榜样，积极参与捐资助学活动，在全社会形成共同关心、支持教育事业发展的强大合力，为加快我市建设现代化生态城市和全面建设小康社会做出新的更大贡献。

附件：云浮市捐资助学先进单位表扬名单

云浮市人民政府

2018年5月31日
