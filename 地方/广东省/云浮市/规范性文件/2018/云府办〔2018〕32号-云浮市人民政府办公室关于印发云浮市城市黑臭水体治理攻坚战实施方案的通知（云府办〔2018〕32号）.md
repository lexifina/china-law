# 云浮市人民政府办公室关于印发云浮市城市黑臭水体治理攻坚战实施方案的通知（云府办〔2018〕32号）

云府办〔2018〕32号

云浮市人民政府办公室关于印发云浮市

城市黑臭水体治理攻坚战

实施方案的通知

各县（市、区）人民政府，市直有关单位：

《云浮市城市黑臭水体治理攻坚战实施方案》业经市政府同意，现印发给你们，请认真遵照执行。执行过程中遇到的问题，请径向市住房和城乡建设局反映。

云浮市人民政府办公室

2018年12月14日

云浮市城市黑臭水体治理攻坚战实施方案

2015年国务院印发《水污染防治行动计划》以来，我市各级各部门迅速行动，在治理城市黑臭水体方面取得积极进展，成效较为显著。为全面贯彻落实《住房城乡建设部 生态环境部关于印发城市黑臭水体治理攻坚战实施方案的通知》（建城〔2018〕104号）和《广东省城市黑臭水体治理攻坚战实施方案》（粤建城〔2018〕230号），扎实推进我市城市黑臭水体治理工作，巩固近年来治理成果，加快改善城市水环境质量，结合我市实际制定本方案。

一、总体要求

（一）指导思想。全面贯彻党的十九大和十九届二中、三中全会精神，以习近平新时代中国特色社会主义思想为指导，认真落实党中央、国务院决策部署和全国生态环境保护大会要求，全面整治城市黑臭水体，加快补齐城市环境基础设施短板，确保用3年左右时间使城市黑臭水体治理明显见效，让人民群众拥有更多的获得感和幸福感。

（二）基本原则。

系统治理，有序推进。坚持统筹兼顾，整体施策，全方位、全过程实施城市黑臭水体治理。坚持尊重自然、保护自然，统筹好上下游、左右岸、地下地上关系，重点抓好源头污染管控。坚持从各地实际出发，遵循治污规律，扎实推进治理攻坚工作。坚持雷厉风行和久久为功相结合，既集中力量打好消除城市黑臭水体的歼灭战，又抓好长制久清的持久战。

齐抓共管，形成合力。落实市级统筹、县级实施、部门参与的城市黑臭水体治理体制，上下联动，多措并举，确保工作顺利实施。强化各级政府主体责任，加强部门协调，市住建局、市环保局会同有关部门协同联动，加强指导督促；调动社会力量参与治理，鼓励公众发挥监督作用。

标本兼治，重在治本。坚持指标和治本相结合，力戒形式主义，既严格按照《水污染防治行动计划》规定的时间节点实现黑臭水体消除目标，又通过加快城市环境基础设施建设、完善长效机制，从根本上解决导致水体黑臭的相关环境问题。

群众满意，长制久清。坚持以人民为中心的发展思想，确保黑臭水体治理效果和与群众的切身感受相吻合，赢得群众满意。对于黑臭现象反弹、群众有意见的，经核实重新列入城市黑臭水体清单，继续督促治理。

（三）主要目标。我市需要整治的黑臭水体共8段，根据《广东省水污染防治行动计划实施情况考核规定》（粤环发〔2017〕11号）要求，全省 2016-2020年黑臭水体消除比例平均达到30%、60%、80%、90%、95%，对应我市任务分别为2016年消除3段、2017年消除5段、2018年消除7段、2019年消除8段、2020年消除8段。

二、科学有序推进治理

（一）“一处一策”精准治理。

1.丰收孖带塘下。进一步排查清理塘岸排污口和生活垃圾，包括农民堆肥垃圾；进一步加强对水体周边畜禽养殖企业、作坊的环保监管；进一步加强对周边群众政策、措施宣传。（云城区人民政府牵头，市环保局、市住建局参与）

2.城北西塘-硫矿生活区（涌）。清理周边垃圾，加强日常保洁；进一步加强对周边群众政策、措施宣传。（云城区人民政府负责）

3.南山河（金丰桥—聚乐美食城）。进一步加强对罗桂河、南山河截污管网排查治理和河岸沿线居民管理，确保不扔垃圾入河，清理沿岸小食店非法直排口和南山河底泥。（云城区人民政府、市水务局按职责分工负责，市环保局、市住建局参与）

4.青少年宫背池塘。进一步排查排污口和检修截污管网和垃圾清运，进一步加强对周边群众政策、措施宣传。（云城区人民政府负责）。

5.高峰河支流（硫矿污水处理厂-双坑桥）。加强对河岸违法建筑、非法排污企业和运矿车辆监督执法；完善云硫生活区污水管网，2018年11月底前接入市政管网；督促云硫集团排查整改生活区生产生活污水入河问题，摸清问题根源，精准整改。（云城区人民政府、市水务局、市环保局、市交通运输局、市公安交警支队、市国资委、广东广业云硫矿业有限公司按职责分工负责）

6.高峰河支流（硫矿-三水围）。督促云硫集团编制整改方案解决硫矿选矿厂涌出矿水问题，实行雨污分流，污水引进污水处理厂，达标排放；进一步排查和检修河岸截污管网，加强垃圾清运和打击非法倾倒垃圾行为；进一步加强对周边群众政策、措施宣传。（云城区人民政府、市水务局、市环保局、市交通运输局、市公安交警支队、市国资委、广东广业云硫矿业有限公司按职责分工负责）

7.高峰河（三水围-高峰市场）。进一步排查排污口和检修截污管网，建立管护长效机制；加强对周边群众政策、措施宣传；加强对河岸沿线居民管理，确保不扔垃圾入河。（云城区人民政府负责）

8.高峰河（牧羊路口-高峰河出口）。进一步加强对罗桂河、高峰河截污管网排查治理和河岸沿线居民管理，确保不扔垃圾入河，清理沿岸小食店非法直排口，加强对周边群众政策、措施宣传。（云城区人民政府、市水务局按职责分工负责）

（二）进一步控源截污。

加快推进截污管网建设。进一步加快推进云浮城区（云城、高峰街道）截排系统完善及污水处理厂扩建项目和PPP模式整县推进镇村污水处理设施建设，推动城市建成区污水管网全覆盖、全收集、全处理以及老旧管网改造和破损修复。所截生活污水尽可能纳入城市生活污水收集处理系统，统一处理达标排放。（云城区人民政府、市水务局按职责分工负责，市环保局、市住建局参与）

加强新建小区污染控制。加强建筑工地施工废水排放和小区内排水管网施工质量、竣工验收以及与市政管网驳接的监管工作，督促项目严格按照雨污分流的要求进行施工，保证小区管网与市政管网的连接畅通，确保在工程竣工验收交付使用后按雨水、污水分流的要求正确接入市政雨水、污水管网，并把管网接入情况列为工程竣工验收备案的必备条件。（市住建局牵头，各县（市、区）人民政府负责落实）

深入开展入河湖排污口排查整治。研究制定排污口管理相关文件，组织开展城市黑臭水体沿岸排污口排查，摸清底数，明确责任主体，逐一登记建档。通过取缔一批、清理一批、规范一批入河湖排污口，不断加大整治力度。（市水务局牵头，云城区人民政府、市环保局、市住建局参与）

强化工业企业污染控制。进一步加强对“散乱污”企业监管执法，城市建成区排放污水的工业企业应依法持有排污许可证，并严格按证排污，对超标或超总量的排污单位一律限制生产或停产整治。重点加大对市建成区黑臭水体沿线工业企业的环保监管，相关企业要严格执行有关环保要求。同时加大执法力度，按有关规定对违规违法企业给予严肃处理。（市环保局负责）

加强农业农村污染控制。加强畜禽养殖管理，加快推进畜禽养殖废弃物资源化利用。重点加强对市建成区黑臭水体范围内畜禽养殖企业、作坊的环保监管，相关企业要严格执行有关环保要求。同时加大执法力度，按有关规定对违规违法企业给予严肃处理。（市农业局牵头，各县（市、区）人民政府、市环保局牵头、市住建局、市城管局、市农业局、市畜牧兽医渔业局等部门按职责分工负责）

（三）科学开展清淤和垃圾治理。

科学开展清淤治理。在综合调查评估城市黑臭水体水质和底泥状况的基础上，结合中小河流治理工程，合理制定并实施清淤疏浚方案，既要保证清除底泥中沉积的污染物，又要为沉水植物、水生动物等提供休憩空间。要在清淤底泥污染调查评估的基础上，妥善对其进行处理处置，严禁沿岸随意堆放或作为水体治理工程回填材料。（云城区人民政府、市水务局按职责分工负责，市环保局、市住建局、市农业局参与）

加强水体及其岸线的垃圾治理。全面划定城市蓝线及水体区域管理范围，整治范围内的非正规垃圾堆放点，并对清理出的垃圾进行无害化处理处置，降低雨季污染物冲刷入河量。规范垃圾转运站管理，防治垃圾渗滤液直接入河。及时对水体内垃圾和漂浮物进行清捞，并妥善处理处置。进一步完善垃圾收集转运体系，建立相关工作台账。（市城管局牵头，云城区人民政府、市水务局、市规编委、市住建局、市农业局按职责分工负责）

（四）加强沿岸景观建设。

在满足城市排洪和排涝功能的前提下，因地制宜对河湖岸线进行生态化改造，减少对城市自然河道的渠化硬化，营造生物生存环境，恢复和增强河湖水系的自净功能，为城市内涝防治提供蓄水空间。（云城区人民政府牵头，市水务局、市国土规划局、市林业局按职责分工负责）

三、建立长效机制

（一）严格落实河长制、湖长制。根据中共广东省委办公厅、广东省人民政府办公厅印发的《广东省全面推行河长制工作方案》《关于在全省湖泊实施湖长制的意见》和《广东省河长制办公室关于将黑臭水体整治作为各级河长巡河重要巡查内容的通知》（粤河长办函〔2018〕145号）要求， 2018年底前明确包括城市建成区黑臭水体在内的河湖的河长湖长。各级河长湖长是黑臭水体整治的第一责任人，要切实履行护河、治河职责，严禁虚假巡查、表面巡查、敷衍巡查。对巡河及整治过程中发现的难点、重点问题，各级河长湖长要及时组织研究，明确整治措施、时限、责任部门和责任人，督促落实整治工作。各级河长湖长要将黑臭水体整治情况纳入巡查重点内容，2019年6月底前，基本完成一次黑臭水体清淤疏浚（市河长办牵头，市水务局、市环保局、市住建局参与，各县（市、区）人民政府负责落实）

（二）建立并严格实施“三个一”制度。建立实施黑臭水体“一河（湖）一策”“一河（湖）一台账”“一河（湖）一评估”“三个一”制度，确保完成黑臭水体治理任务。“一河（湖）一策”，按照“发现一个，治理一个”的要求和住房城乡建设部印发的《城市黑臭水体整治工作指南》，结合中央环境保护督察“回头看”最新要求，2019年3月底前全面完成黑臭水体“一河（湖）一策”编制工作，针对每个黑臭水体制定和完善治理方案并加快实施，方案要按照标本兼治、治本为主，远近结合、分步实施的原则，明确治理工程措施和非工程措施、时间节点、责任主体等内容。“一河（湖）一台账”，结合全国城市黑臭水体整治监管平台，建立黑臭水体治理工作台账，详细记录治理进展，分析研判治理效果，及时把握治理动态。“一河（湖）一评估”，按照住房城乡建设部办公厅、原环境保护部办公厅印发的《关于做好城市黑臭水体整治效果评估工作的通知》，由市人民政府组织开展黑臭水体初见成效和长制久清的效果评估，严格落实工程竣工验收、公众评议、水质监测、政策机制建设等检查环节和要求。（市住建局牵头，云城区人民政府、市水务局负责落实，市环保局参与）

（三）加快推行排污许可。强化建成区内排污单位污水排放管理，特别是城市黑臭水体沿岸工业生产、餐饮、洗车、洗涤等单位的管理，严厉打击偷排漏排。对污水未经处理直接排放或不达标排放导致水体黑臭的相关单位和工业集聚区严格执法，严肃问责。2019年底前，城市建成区全面实现污水处理厂持证排污。（市环保局牵头，云城区人民政府、市水务局参与）

（四）加强运营维护。落实河湖日常管理和各类治污设施维护的单位、经费、制度和责任人，明确绩效考核指标，加大考核力度。严格城市生活污水处理设施运营监管，切实保障稳定运行。推进机械化清扫，逐步减少道路冲洗污水排入管网。定期做好管网的清掏工作，并妥善处理清除出的淤泥，减少降雨期间污染物入河。（市水务局牵头，云城区人民政府、市城管局、市住建局按职责分工负责）

四、加强监督检查

（一）开展黑臭水体专项督查。建立季度督查机制，并通报督查结果，对整治不力的水体限期整改。2018年—2020年，市住建局每季度会有关部门建立督查组开展专项督查，督查形成问题清单，交办相关地方政府，实行“拉条挂账，逐个销号”式管理，将有关督查、整改落实情况报市人民政府，并适时开展 “回头查”，每半年向社会公开黑臭水体整治工作进展。市对各县（市、区）加强督查、督促、协调和指导，各县（市、区）人民政府及时开展自查和落实整改工作。（市住建局牵头，市环保局参与，各县（市、区）人民政府负责落实）

（二）定期开展水质监测。2018年-2020年，市环保局每季度要对8段黑臭水体开展包括透明度、溶解氧（DO）、氨氮（NH3—N）等3项指标在内的水质监测，并将检测结果送市住建局。（市环保局负责）

（三）进一步加强监管。云城区人民政府、市水务局严格落实主体责任，切实抓黑臭水体的整治;市住建局认真履行主管部门职责，督促指导做好整治工作以及开展季度督查督办；市环保局按照大气污染和水污染防治有关规定，加强对鼎康瑞洁、云硫集团、金地公司等企业监督执法；市交通运输局、市公安交警支队按照大气污染和水污染防治有关规定，加强对云硫集团、金地公司等企业运矿车辆监督执法；云硫集团和金地公司要严格落实企业主体责任，配合有关部门开展整治工作，按照大气污染和水污染防治有关规定，进一步加强对运矿车辆监管。（云城区人民政府、市水务局、市环保局、交通运输局、市公安交警支队、市国资委按职责分工负责）

（四）进一步加强排查治理。2019年3月底前，在现有基础上，全面核清建成区黑臭水体数量和情况，并按“三个一”制度落实新发现黑臭水体的治理。定期排查建成区黑臭水体数量和情况，“发现一个，治理一个”。被国家和省黑臭水体整治环境保护专项行动发现的黑臭水体，按瞒报处理。（市住建局牵头，市环保局参与，各县（市、区）人民政府负责落实）

五、建立保障措施

（一）加强组织领导。进一步压实责任、强化举措、狠抓落实，确保本方案确定的各项任务按期落实到位；成立黑臭水体整治领导小组，编制黑臭水体整治方案。各县（市、区）人民政府是黑臭水体治理的责任主体，要再次开展全面排查，核清城市建成区内黑臭水体情况；各整治主体要按“一处一册”要求，编制各段黑臭水体治理攻坚方案，明确年度目标、工作计划和措施，每月将工作进展情况报市住建局汇总上报。市人民政府将城市黑臭水体治理工作纳入重要议事日程，按照本方案要求将治理任务分解到各部门、明确职责分工和时间进度，每年年底向省住房城乡建设厅、生态环境厅提交城市黑臭水体治理情况报告。（市住建局、市环保局牵头负责，各县（市、区）人民政府、市水务局负责落实）

（二）严格责任追究。落实领导干部生态文明建设责任制，严格实行党政同责、一岗双责。各级政府要把黑臭水体治理放在重要位置，主要领导是本行政区域第一责任人，其他有关领导班子成员在职责范围内承担相应责任。各级住房城乡建设（水务）、生态环境部门要做好牵头，会同和督促有关部门做好工作，对于推诿扯皮、落实不力的，要提请同级人民政府进行问责；参与部门要积极作为，主动承担分配的任务，确保工作成效。对在黑臭水体治理攻坚战中责任不落实、推诿扯皮、没有完成工作任务的，依纪依法严格问责、终生追责。（纪检监察部门牵头，市住建局、市环保局参与，各县（市、区）人民政府负责落实）

（三）加大资金支持。要统筹整合相关渠道资金支持黑臭水体治理，加大财政支持力度，保障治理工作经费,按照属地管理原则,明确责任主体,做到权责明晰、各负其责。按照谁使用、谁负责的原则，对基本公共服务项目实施绩效管理。结合地方实际创新资金投入方式，引导社会资本加大投入，坚持资金投入同攻坚任务相匹配，不断提高资金使用效益和基本公共服务质量。（市财政局负责）

（四）优化审批流程。落实深化“放管服”改革和优化营商环境的要求，结合工程建设项目行政审批制度改革，加大对城市黑臭水体治理项目支持和推进力度，在严格前期决策论证和建设基本程序的同时，对报建审批提供绿色通道。（市发改局、市水务局、市住建局、市环保局按职责分工负责）

（五）鼓励公众参与。要做好城市黑臭水体治理信息发布、宣传报道、舆情引导等工作，限期办理群众举报投诉的城市黑臭水体问题，保障群众知情权，提高黑臭水体治理重大决策和建设项目的群众参与度。采取喜闻乐见的宣传方式、充分发挥微信公众号等新媒体作用，面向广大群众开展形式多样的宣传工作，引导群众自觉维护治理成果，鼓励群众监督治理成效、发现问题，形成全民参与治理的氛围。（云城区人民政府、市委宣传部、市环保局、市水务局、市住建局按职责分工负责）
