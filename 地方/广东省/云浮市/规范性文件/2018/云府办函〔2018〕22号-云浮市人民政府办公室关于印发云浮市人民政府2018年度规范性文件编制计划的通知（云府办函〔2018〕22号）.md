# 云浮市人民政府办公室关于印发云浮市人民政府2018年度规范性文件编制计划的通知（云府办函〔2018〕22号）

云府办函〔2018〕22号

云浮市人民政府办公室关于印发云浮市

人民政府2018年度规范性文件

编制计划的通知

各县（市、区）人民政府，市政府各部门、各直属机构：

为确保政府规范性文件制定工作的连续性、计划性、科学性和可操作性，进一步提高政府规范性文件质量，经市政府同意，现将《云浮市人民政府2018年度规范性文件编制计划》印发给你们，请遵照执行。

各单位要根据制定规范性文件的要求，对列入计划的项目，组织力量开展调查研究，做好协调、论证、起草、征求意见、合法性审查、集体讨论决定、政策解读等工作。属重大行政决策的，还应依法落实公众参与、专家论证、风险评估、合法性审查、集体讨论决定的法定程序。各单位要加强与市法制局沟通，及时反映规范性文件起草工作进展情况，对涉及面广、影响较大的规范性文件草案，可请市法制局提前介入，参与调研、协调、听证、论证、评估等。市法制局要加强对有关单位规范性文件起草工作的指导，及时跟踪督办，确保规范性文件起草送审工作顺利进行。

对未列入2018年度计划的规范性文件草案，原则上不予考虑，确因市委、市政府中心工作需要临时增加的，起草单位应提出增加制定项目的申请，报市政府分管领导批准后，按照规范性文件编制程序办理。

附件：云浮市人民政府2018年度规范性文件编制计划
