# 云浮市人民政府办公室关于印发云浮市“菜篮子”市长负责制考核实施方案的通知（云府办函〔2018〕28号）

云府办函〔2018〕28号

云浮市人民政府办公室关于印发云浮市“菜篮子”市长负责制考核实施方案的通知

各县（市、区）人民政府，市政府各部门、各直属机构：

《云浮市“菜篮子”市长负责制考核实施方案》已经市人民政府同意，现印发给你们，请认真组织实施。实施中遇到的问题，请径向市农业局反映。

云浮市人民政府办公室

2018年2月27日

云浮市“菜篮子”市长负责制考核实施方案

为认真贯彻落实《广东省人民政府办公厅关于印发广东省“菜篮子”市长负责制考核办法的通知》（粤办函〔2017〕370号）精神，做好“菜篮子”市长负责制考核工作，努力实现生产能力增长、总量满足需求、品种更加丰富、季节供应均衡，价格保持基本稳定，流通条件进一步改善，质量安全水平得到提高，供应保障、应急调控、质量监管能力进一步增强，特制定本实施方案。

一、提高产品生产能力

把发展“菜篮子”产品生产作为促进农民持续增收、保障市场供应的有效手段，加大支持力度，按照区域化布局、标准化生产、产业化经营的要求，不断提高“菜篮子”产品生产能力。

（一）大力发展蔬菜生产。实施设施蔬菜提升工程，继续实行新建设施蔬菜基地奖补政策，加快国家和省、市级蔬菜标准园创建以及蔬菜工厂化育苗厂建设，加快标准化生产技术推广，加快蔬菜新型经营主体和服务主体培育，加大设施蔬菜种植政策性保险，促进全市蔬菜生产水平提升。确保考核年度蔬菜（含食用菌）播种面积、产量达到或高于前三年平均值的98%以上。[责任单位：各县（市、区）政府、市农业局、市发改局、市财政局、市国土规划局]

（二）稳定畜禽、水产品生产。加快部级和省、市畜禽标准化养殖小区、水产品健康养殖基地建设。确保年度肉类、水产品产量达到或超过前五年平均值。[责任单位：各县（市、区）政府、市农业局、市发改局、市财政局、市国土规划局、市环保局]

二、提升市场流通能力

合理规划布局“菜篮子”产品批发市场、农贸市场和社区平价店。规划建设农产品物流中心和冷链综合体，推进蔬菜、畜禽、水产品集中交易，加快市区标准化菜市场改造，增强市场保障能力，构建“菜篮子”产品流通体系。加快推进农产品冷链物流发展，鼓励菜篮子产品生产经营主体建设中小型冷藏设施，推广“微冻液”冷冻冷藏保鲜技术，加强批发市场冷藏设施建设，推广节能环保的冷链运输车辆及相关配送设备。进一步完善和落实鲜活农产品运输“绿色通道”政策，对整车合法装运鲜活农产品的车辆免收车辆通行费。强化产销衔接功能，以“农超对接”等为抓手，积极引导大型零售流通企业以及学校、酒店、大型企业等终端用户与产地蔬菜生产经营主体对接，提高蔬菜零售环节产销对接比重，降低营销费用。

（一）合理规划布局批发市场。对全市“菜篮子”产品批发市场进行科学合理规划布局，将其纳入城市建设规划并按规划实施。[责任单位：市商务局、市经信局、市发改局、市财政局、市工商局、市食品药品监管局、市规编委、各县（市、区）政府]

（二）加强田间收购市场建设。加强蔬菜主产区田间收购站点建设和管理，将田间收购站点建设用地（包括地磅、清洗、分拣、包装、冷藏保鲜库等）纳入设施农业配套建设用地范畴。[责任单位：各县（市、区）政府、市商务局、市农业局、市发改局、市财政局、市国土规划局、市工商局]

（三）加强批发市场建设。加强市区“菜篮子”产品批发市场功能建设和管理，合理布局批发市场场地，市场交易厅（棚）、冷藏保鲜等设施齐全。开展质量安全检测，市场管理规范、收费合理。推进公益性批发市场建设。[责任单位：市商务局、市经信局、市发改局、市财政局、市国土规划局、市工商局、市食品药品监管局、云城区人民政府、市规编委]

（四）加强零售网点建设。市区“菜篮子”产品零售网点（含生鲜超市、农贸市场、菜市场、社区菜店、平价商店、蔬菜社区直通车）密度合理，每个行政社区平均建有2个以上“菜篮子”产品零售网点。[责任单位：各县（市、区）政府、市商务局、市经信局、市发改局、市财政局、市国土规划局]

（五）大力发展现代流通方式。积极推进“菜篮子”电子商务平台建设，加快农民电子商务知识培训，培育农产品电商经营主体，大力发展农村电子商务，扩大农产品网上交易规模。用好价格调节基金，加大社区农副产品平价店（点）、农贸市场直销区建设扶持力度，增加直供直销网点，开展农超对接。[责任单位：市商务局、市经信局、市农业局、市发改局、市财政局]

（六）加强品牌建设。落实各级优质农产品认证政策，加大扶持推广力度，培育一批立得住、叫得响的“云浮品牌”，提升我市“菜篮子”产品知名度和市场占有率。[责任单位：市农业局、市质监局、市发改局、市财政局]

三、强化质量安全监管

全面落实农产品质量安全地方政府属地管理责任，加大质量安全监管投入，加快推进标准化生产以及无公害、绿色、有机蔬菜和地理标志农产品认证。建立完善农产品质量安全监管制度，加强农产品质量安全执法监管，强化检打联动机制，依法查处使用禁用物质的生产、销售行为，不断提升农产品质量安全水平。积极组织开展省级农产品质量安全示范县创建，加强基地环境、水源、水域、农业投入品的综合监管，完善生产经营主体的质量监督和管理，建立生产销售台帐，构建源头备案、过程监督、抽查检验的“菜篮子”产品质量安全监控体系。强化“菜篮子”产品追溯体系建设，积极推动批发市场、农贸市场、超市肉类、蔬菜追溯体系建设。

（一）落实质量安全属地责任。地方政府属地管理责任落实，在力量配备、条件保障等方面大力支持；每年开展市级农产品质量安全执法监督抽查2次以上，监督抽查中发现使用禁用物质的跟进开展执法。省农业厅的年度蔬菜、畜禽产品、水产品质量安全例行监测合格率平均值达到98%以上。[责任单位：各县（市、区）政府、市农业局、市工商局、市质监局、市卫生计生局、市食品药品监管局]

（二）强化“菜篮子”产品追溯体系建设。积极推进肉类和蔬菜等食用农产品追溯体系建设，确保市区批发市场、农贸市场、超市肉类和蔬菜追溯体系覆盖率达到50%以上。[责任单位：市农业局、市商务局、市食品药品监管局、市工商局、市质监局、市卫生计生局]

四、建立调控保障机制

不断健全“菜篮子”工程调控政策体系，加强生产扶持政策，创新调控政策，完善“菜篮子”产品市场供应应急预案，加强“菜篮子”产品价格波动的统计监测，建立“菜篮子”产品储备制度，加强“菜篮子”产品信息监测预警体系和发布平台建设，用好价格调节基金，加大扶持社区农副产品平价店（点）、农贸市场直销区建设力度，强化舆论引导，保障市场稳定。

（一）加强生产扶持政策建设。加大资金投入和政策扶持力度，大力开展“菜篮子”产品生产基础设施建设、技术推广、新型职业农民培育、政策性保险、生产奖补等。[责任单位：市农业局、市财政局、市国土规划局、市环保局、市商务局、市金融工作局、云浮银监分局]

（二）加强市场流通政策建设。强化协调配合，创新流通基础设施建设投融资机制，促进产销对接，提高流通效率、降低流通成本。[责任单位：市商务局、市经信局、市发改局、市财政局、市交通运输局、市农业局]

（三）加强市场供求调控。针对市场供求应急情况，制订相关调控预案，确保极端天气时重要“菜篮子”产品不断档、不脱销。[责任单位：市农业局、市发改局、市财政局、市商务局、市经信局、市交通运输局]

（四）加强市场价格调控。加强“菜篮子”产品价格波动的统计监测，密切关注“菜篮子”产品价格上涨幅度。确保年度城市居民消费价格指数（CPI）中的鲜菜、畜肉、水产品、蛋、鲜果等价格平稳。[责任单位：市发改局、市财政局、市农业局、市商务局]

（五）加强产品储备制度。建立重要“菜篮子”产品储备制度，根据“菜篮子”产品生产消费实际情况，确定耐贮蔬菜、肉类的储备品种和数量，建立规范可行的储备制度并实施。[责任单位：市发改局、市财政局、市农业局、市商务局]

五、加强组织领导

（一）强化工作领导。成立云浮市“菜篮子”工作领导小组，由市委副书记、市长王胜任组长，领导小组下设办公室且配置专职人员。各县（市、区）政府主要负责同志作为“菜篮子”工程的第一责任人，要分解落实年度“菜篮子”产品生产目标任务和责任，建立健全领导协调机制和办事机构，出台扶持政策，优化各项服务，落实工作经费，确保考核期内不发生“菜篮子”产品质量安全突发事件。

（二）明确责任分工。市农业、商务、发改、财政、国土规划、环保、工商、质监、卫生计生、食品药品监管、银监等部门要根据职责分工，协调配合，努力形成工作合力，加快推进“菜篮子”工程建设步伐，认真抓好各项政策的落实。

（三）强化督促检查。市农业部门会同有关单位加强对实施方案落实情况监督检查，市直有关部门及各县、区政府配合做好相关工作。组织开展实施情况调度，定期向市政府报告，确保省政府考核取得好成绩。
