# 云浮市人民政府办公室关于公布云浮市气象灾害防御重点单位（2018年更新版）的通知（云府办函〔2018〕98号）

云府办函〔2018〕98号

云浮市人民政府办公室关于公布云浮市气象灾害防御重点单位（2018年更新版）的通知

各县（市、区）人民政府，市政府各部门、各直属机构：

为切实加强气象灾害应急准备工作，最大限度地避免和减轻气象灾害损失，保障全市经济社会持续发展，根据《广东省气象灾害防御条例》、《广东省气象灾害防御重点单位气象安全管理办法》等有关规定要求，经综合调查和专家评审，更新确定中国石化销售有限公司广东云浮分公司等68家单位为云浮市气象灾害防御重点单位，经市人民政府同意，现予以公布。

各气象灾害防御重点单位及相关部门要根据国家和省气象灾害防御的有关规定，结合云浮市气象灾害防御工作的实际情况，认真落实防御管理职责，强化气象灾害应急准备，努力提高气象灾害防御处置能力。
