# 云浮市人民政府办公室关于废止有关文件的通知（云府办函〔2018〕132号）

云府办函〔2018〕132号

云浮市人民政府办公室关于废止

有关文件的通知

各县（市、区）人民政府、市政府各部门、各直属机构：

根据《国务院办公厅关于开展涉及产权保护的规章、规范性文件清理工作的通知》（国办发〔2018〕29号）和《广东省涉及产权保护的规章、规范性文件清理工作方案》（粤府办〔2018〕25号）的要求，经前期梳理审核并经市政府同意，决定废止符合国务院和省政府要求清理标准的《云浮市人民政府办公室关于印发云浮市促进呼叫中心产业发展优惠办法（试行）的通知》等3份政府规范性文件，从即日起不再执行。
