# 从化区人民政府办公室关于印发《从化区2017年应急管理工作计划》的通知

各镇人民政府、街道办事处，区政府各部门、各直属机构：

《从化区2017年应急管理工作计划》业经区政府同意，现印发给你们，请认真执行。工作中遇到的问题，请向区应急办反映。

广州市从化区人民政府办公室

2017年3月9日

从化区2017年应急管理工作计划

2017年全区应急管理工作的总体思路是：深入贯彻党的十八大和十八届历次全会精神以及习近平总书记系列重要讲话精神，按照省委、省政府、市委、市政府、区委和区政府的部署和要求，以总体国家安全观为指导，践行创新、协调、绿色、开放、共享发展理念，以保障人民利益为根本，坚持目标导向和问题导向相结合，在优化体制、完善机制、健全法制、夯实基础、强化保障、提高能力上下工夫，全面提升应急管理工作水平。重点抓好以下工作：

一、优化应急管理体系

(一)组织实施应急体系建设“十三五”规划。根据《广州市突发事件应急体系建设“十三五”规划》制定从化区突发事件应急体系建设“十三五”规划实施意见，明确责任，细化分工，推进落实。(区应急委成员单位、各镇(街)、园区负责)

(二)加强应急管理组织领导。根据当前公共安全形势及突发事件防范处置工作需要，不断健全本地、本单位应急管理工作领导机构，加强领导，落实责任，优化机制。(区应急委成员单位、各镇(街)、园区负责)

(三)加强应急管理办事机构建设。进一步加强应急管理办事机构建设，充实工作人员，健全工作制度，增强应急管理办事机构的权威性和协调性。(区应急委成员单位、各镇(街)、园区、区编办负责)

二、完善应急管理工作机制

(一)深化军地应急管理合作。根据省、广州市的要求，深化军地应急联动机制建设，整合军地应急指挥系统，构建军地一体、灵活高效的应急指挥体系。健全预备役、民兵参与的应急救援机制，提升突发事件应急救援效能。(区应急办、区武装部牵头负责，区应急委成员单位、各镇(街)、园区参与)

(二)深化应急管理合作。完善从化区与周边区县的跨区域应急合作机制，加强专项应急指挥机构之间的协调联动机制，健全重大突发事件会商机制、风险隐患排查整改机制，加强区域风险隐患、应急队伍、避护场所、物资和专家等数据的共享。(区应急委成员单位、各镇(街)、园区负责)

(三)健全应急征用补偿机制。根据省、广州市做法，结合我区实际，制订《从化区应急征用补偿办法》，进一步规范应急征用补偿工作，调动社会各方参与应急管理工作的积极性与主动性。(区财政局、应急办牵头负责，区应急委成员单位、各镇(街)、园区参与)

三、强化突发事件风险管控

(一)健全风险隐患管控长效机制。根据《广州市突发事件危险源和危险区域管理规定》，摸清突发事件危险源和危险区域现状，完善突发事件风险隐患排查整改及评估会商机制，加强风险规律研究和新技术应用，强化基层风险管控，引导各方力量参与，确保风险隐患得到有效管控。(区应急委成员单位、各镇(街)、园区负责)

(二)强化风险隐患的动态管理。依托应急平台体系和信息技术，开发完善风险隐患数据的实时报送、更新、跟踪督办、分析研判等功能，实现对风险隐患的动态管理。(区应急委成员单位、各镇(街)、园区负责)

(三)强化重点领域的风险隐患管控。加强交通、消防、危险化学品、燃气等重点领域的风险隐患排查整改，组织开展风险隐患排查整改专项督查，确保重要风险隐患有效管控，防止重特大事故的发生。(区城管局、交通局、安全监管局、应急办、公安消防大队牵头负责，区应急委成员单位、各镇(街)、园区参与)。

(四)完善突发事件预警信息发布体系。推进街(镇)、村(社区)、企业和机关事业单位预警信息广播系统建设，进一步扩大预警信息的覆盖面，强化预警信息发布和舆情引导能力。制定预警信息广播系统试点建设方案并做好实施，制订突发事件预警信息发布管理规定，进一步规范预警信息发布工作，为及时、准确、客观、全面发布预警信息提供保障。(区气象局牵头负责，区应急委成员单位、各镇(街)、园区参与)

四、提高应急预案管理水平

(一)加强应急预案动态管理。根据预案管理有关规定，修订《从化区突发公共事件总体应急预案》，完成各专项应急预案及操作手册的修编，汇编全区专项应急预案。进一步强化重要目标、重大危险源、重大活动应急保障等预案的编制和管理。(区应急委成员单位、各镇(街)、园区负责)

(二)强化应急预案演练。认真落实国家、省、市应急预案演练规定，促进应急演练的常态化、规范化。继续以“双盲”突袭式应急演练为重点，开展“应急演练季”活动。进一步完善应急演练评估、组织机制，提升应急演练效能。(区应急委成员单位、各镇(街)、园区负责)

(三)探索巨灾情景构建研究工作。开展极端天气等巨灾情景构建研究工作，梳理巨灾应对的重大事项，科学模拟巨灾情景演化过程和事件后果，分析评估现有应急能力，制订巨灾应急预案，开展应急演练与评估，提升巨灾应急响应和快速恢复能力。(区应急委成员单位负责，各镇(街)、园区参与)

五、健全应急保障体系

(一)加强应急救援队伍建设。在全面梳理本地、本单位应急救援队伍的基础上，根据突发事件防范处置工作需要，进一步优化应急救援队伍体系。健全应急救援队伍日常管理制度，完善指挥调度体系，加强装备配备，强化应急演练，提升应急救援队伍应急救援能力。(区应急委成员单位、各镇(街)、园区负责)

(二)加强应急志愿者队伍建设。继续推动应急志愿者队伍的建设，鼓励公众尤其是具有应对突发事件专业知识与技能的人员加入应急志愿者组织，成为应急救援的补充力量，不断筑牢应急管理工作的社会基础。(团区委、区应急办牵头负责，区应急委成员单位、各镇(街)、园区参与)

(三)深入推进应急避护场所建设。认真贯彻落实《从化区应急避护场所建设规划(2014-2020)》、《从化区应急避护场所建设实施方案》，进一步完善和改造现有应急避护场所，高标准完成中心应急避护场所建设工作。(区住房和建设局牵头负责，区发展改革局、民政局、财政局、国土规划局、林业和园林局、科工商信局(地震局)，各镇(街)、园区参与)

六、提升大型活动应急保障能力

健全完善大型活动隐患排查、预案编制、应急演练、值守应急等工作机制，强化责任落实与工作督办，切实提升大型活动应急保障能力，全力配合做好2017广州《财富》全球论坛、第25届广州国际旅游展等重要大型活动的应急保障工作。(区公安分局、科工商信局、侨外办、文广新局、财政局、应急办牵头负责，区应急委成员单位、各镇(街)、园区参与)

七、提高值守应急水平

(一)健全值守应急网络。进一步加强值班室建设，优化值班设备，抓好基层应急值守培训，试行区政府系统大值班工作，提高应急值守工作的规范化、制度化水平。(区应急委成员单位、各镇(街)、园区负责)

(二)优化信息报告工作机制。进一步规范突发事件信息报告流程，明确信息报告要求，建立健全规范化、扁平化的突发事件信息报告体系;进一步完善信息报告培训、通报、约谈整改等工作机制，提升信息报告的时效与质量。(区应急委成员单位、各镇(街)、园区负责)

(三)强化信息综合分析研判。加强对突发事件信息的综合分析研判，针对重要、复杂、敏感突发事件的防范与应对，提出有针对性的意见与建议，强化值班室的参谋助手作用。(区应急委成员单位、各镇(街)、园区负责)

八、推进应急管理科技支撑体系建设

(一)完善应急管理信息化建设。配合广州市政府推进综合应急平台建设工作。立足互联互通，推进区政府综合应急平台与市的互联互通，实现实时视频会商;实现市区两级应急管理系统突发事件信息的实时报送，各类应急基础数据的共享和分级管理。(区应急办牵头负责，区应急委成员单位、各镇(街)、园区参与)

(二)加强应急管理专家队伍建设。进一步加强应急管理专家队伍建设，健全应急管理专家服务机制，充分发挥应急管理专家在应急决策建议、专业咨询、理论指导和技术支持等方面的作用。完成第二届区应急管理专家换届工作。(区应急委成员单位、各镇(街)、园区负责)

九、推进基层应急管理工作

(一)加强微型消防站建设。进一步加强融合防消合一功能的微型消防站建设，加强对值守应急和社区管理人员的培训，强化微型消防站在“第一现场”和先期处置方面的作用。(区公安消防大队牵头负责，区国土规划局、财政局、各镇(街)、园区参与)

(二)加强基层应急管理“五个一”工程建设。进一步完善基层应急管理“五个一”工程推荐和评审机制，开展 “五个一”工程示范单位复检工作，进一步扩大示范单位辐射带动效应。(区应急办、各镇(街)、园区负责)

十、强化应急管理宣教培训

(一)丰富应急知识宣教形式。充分发挥“5.12防灾减灾日”、“11.9消防宣传日”、“安全生产月”等公众安全宣传活动作用，加大安全与应急科普教育力度;充分运用网络、微博、微信、广播、电视、报刊等，扩大公共安全及应急知识的宣传覆盖面;丰富应急科普形式，协调引进应急动漫科普宣传片在从化广播电视台等进行公益免费播放。(区应急委成员单位、各镇(街)、园区负责)

(二)深化应急管理培训。依托区委组织部、区委党校对各级党政领导干部和应急管理人员实施规范化、常态化应急管理培训。围绕年度应急管理重点工作，有针对性的组织开展应急管理培训。(区应急委成员单位、各镇(街)、园区负责)

(三)深入推进应急安全进校园。深入推进学前儿童应急安全教育工作，发挥应急安全教育试点的辐射和带动作用，进一步推动“儿童生存教育”工程的实施。进一步落实省教育厅有关要求，将安全教育列入中小学教学计划，探索实训式安全教育新模式。(区教育局、区应急办牵头负责，区应急委成员单位、各镇(街)、园区参与)
