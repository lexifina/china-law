# 从化区人民政府关于调整区政府领导工作分工的通知

各镇人民政府、街道办事处，区政府各部门、各直属机构：

根据工作需要，经区政府党组会议研究决定，对部分区政府领导工作分工作如下调整：

区委常委、区人民政府党组成员毛松柏同志联系科协工作。

副区长池贤同志分管来穗人员服务管理工作。

副区长迟军同志分管公共建设项目代建中心工作。

副区长李名扬同志分管林业和园林工作。

副区长李东强同志分管档案、地方志工作。

从府〔2016〕18号文中关于区政府领导的其他工作分工不变。

广州市从化区人民政府

2017年5月16日
