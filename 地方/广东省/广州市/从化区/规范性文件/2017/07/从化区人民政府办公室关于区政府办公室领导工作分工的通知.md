# 从化区人民政府办公室关于区政府办公室领导工作分工的通知

各镇人民政府、街道办事处，区政府各部门、各直属机构：

根据人员变动和工作需要，经区政府办公室党组会议研究决定，现将区政府办公室领导班子成员工作分工通知如下：

林 康 党组书记、主任，主持办公室全面工作，分管法制办、侨外办工作。

薛庆波党组成员、副主任，分管调研科、口岸科;分管办公室财务、工会、共青团、妇联工作。联系财政、民政、文化和新闻出版、旅游、体育、卫生和计生、食品药品监督管理、残联、国资监督管理、金融、流溪温泉旅游度假区、供销、机关事务、农业、档案、地方志、民族宗教、扶贫开发、山区镇建设、工青妇等工作。

梁浩森党组成员、副主任，分管督办科、小汽车定编办;分管办公室扶贫和宣传工作。联系交通、住房和建设、水务、环保、人民防空、中心镇建设、公共建设项目代建、科技、工业、商贸、外经贸、信息化、知识产权、市场监督、整规打假、贸促会、口岸、广东经济开发区等工作。

李延波党组成员、副主任，分管政务信息科;分管办公室党务工作。联系发改(含物价、粮食和统计)、教育、安全生产监督管理、政务管理、信访、地铁等工作。

潘耀东党组成员、应急办主任，负责应急办工作，分管总值班室;分管办公室综治信访维稳工作。联系公安、司法、城管、武装、兵役、消防、来穗人员服务管理等工作。

黄晓鸿党组成员、法制办专职副主任，分管法制科、综合科;分管办公室廉政建设、行政监察工作。联系国土和规划、城市更新、人力资源和社会保障、林业和园林等工作。

利敏红 党组成员、侨务外事办专职副主任，分管秘书科、侨务外事科;分管办公室人事、计生、老干等工作。

区府办领导AB角：薛庆波 李延波

梁浩森 黄晓鸿

潘耀东 利敏红

广州市从化区人民政府办公室

2017年7月27日
