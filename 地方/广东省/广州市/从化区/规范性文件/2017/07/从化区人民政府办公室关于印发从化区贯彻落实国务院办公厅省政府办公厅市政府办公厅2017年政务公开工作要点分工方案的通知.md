# 从化区人民政府办公室关于印发从化区贯彻落实国务院办公厅省政府办公厅市政府办公厅2017年政务公开工作要点分工方案的通知

各镇人民政府、街道办事处，区政府各部门、各直属机构：

《从化区贯彻落实国务院办公厅省政府办公厅市政府办公厅2017年政务公开工作要点分工方案的通知》已经区政府同意，现印发给你们，请认真贯彻执行。

各街镇(园区)、区政府各部门要结合实际制定具体实施方案，提出各具体政务公开事项的责任单位(科办)、实施步骤、完成的时间节点、今后该事项公开的长效机制等。牵头单位要充分发挥组织协调、指导督促作用，推动工作落实。区府办公室将适时对各政务公开事项的落实情况进行督查，将情况报区政府并进行通报。

附件：从化区贯彻落实国务院办公厅省政府办公厅市政府办公厅2017年政务公开工作要点分工方案的通知

广州市从化区人民政府办公室
