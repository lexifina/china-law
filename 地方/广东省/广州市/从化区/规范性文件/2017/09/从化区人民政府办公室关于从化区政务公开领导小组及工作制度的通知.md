# 从化区人民政府办公室关于从化区政务公开领导小组及工作制度的通知

失效时间：2021.03.30

从化区人民政府办公室关于从化区政务

公开领导小组及工作制度的通知

各镇人民政府、街道办事处，区政府各部门：

根据国家、省、市关于全面推进政务公开工作的部署要求，参照国务院和省、市政府的做法，结合我区工作实际，为进一步建立健全政务公开协调机制，明确承担政务公开工作的机构，配齐配强工作人员。现将有关事项通知如下：

一、主要职责

贯彻落实党中央、国务院和省委、省政府，市委、市政府以及区委、区政府关于政务公开工作的方针政策;研究提出全区政务公开工作的政策措施和年度工作重点;协调区各部门抓好政务公开工作任务落实，并加强督促检查;完成党中央、国务院和省委、省政府，市委、市政府以及区委、区政府交办的其他事项。

二、组成单位及职责

领导小组组长由区政府分管政务公开的区领导担任，常务副组长由区政府办公室主任担任，副组长由协助分管政务公开的区政府办公室副主任担任。领导小组成员由各成员单位分管政务公开的领导担任。成员单位及职责如下：

区政府办公室：负责领导小组的日常工作;制定全区政务公开工作要点和分工方案并督促落实;建立健全领导小组工作制度机制，协调督促各成员单位按分工推进所负责的工作。

区委宣传部：做好新闻发布、重大政务活动、重要政策措施的宣传工作;做好网络舆情搜报，指导协调各单位做好处置应对;指导督促各单位用好管好政务新媒体。

区编办：组织督促各单位做好行政审批事项、权责清单的梳理和公开。

区保密局：组织指导各单位做好政府信息公开的保密审查工作，防止在政府信息公开中发生泄密事故。

区监察局：做好我区行政部门政风行风监督信息公开和舆情处置应对。

区发改局：做好我区重大产业政策的发布、经济社会发展的信息公开和新闻宣传，做好宏观政策的发布和解读。

区科工商信局：做好我区推进公共信息资源开放和政府数据开放平台建设工作以及做好科技创新政策公开和解读。

区公安分局：做好警务信息公开、办事项目公开，突发公共安全事件的信息发布，以及我区治安、交通管理等涉警舆情处置应对。

区民政局：做好城乡低保、救助、养老等信息公开和舆情处置应对。

区司法局：做好司法行政系统的信息公开，将重要政府规章和政策文件纳入普法宣传工作。

区财政局(区国资局)：做好一般公共预算收支执行情况公开，组织指导督促全区财政信息公开、国有企业信息公开。

区人社局：做好社保、劳动就业信息公开、政策文件解读和舆情处置应对。

区国规局：做好国土规划领域的信息公开和舆情处置应对。

区环保局：做好环保信息公开和环保类舆情处置应对。

区住房城乡建设局：做好监管城建项目信息公开，住房保障、房地产调控等政策的发布解读及舆情处置应对。

区交通局：做好交通工作的信息公开、政策发布解读及舆情处置应对。

区水务局：做好河涌治理、“三防”、供水等工作信息公开及舆情处置应对。

区文广新局：做好文化广电新闻出版领域的信息公开，根据职能做好政府信息发布、宣传和舆论引导工作。

区卫计局：做好医疗、计生、疫情防控等信息公开和舆情处置应对。

区市场和质量监管局：推进商事登记、消费领域信息公开及政策发布解读，推进产品质量监督抽查信息公开和舆情处置应对。

区安监局：做好安全监管信息公开，做好安全事故信息发布和舆情处置应对。

区食药监局：做好食品药品监管信息公开及舆情处置应对。

区法制办：指导各单位做好政府信息公开的行政复议、行政诉讼的应对答辩，做好依法行政与政务公开工作的衔接协调。

区政务办：做好政务服务和电子政务管理的法律法规、方针政策等信息公开和舆情处置应对。做好全区政府网站的巡查检测、督促整改和考评工作，负责区政府门户网站的运营管理维护工作(目前，该项工作由区科工商信局暂时负责，待职能等移交后由区政务办接管)。

区档案局：做好已接收的主动公开政府信息的管理、利用工作，做好已接收档案的管理和开发利用工作。

区教育局：推进教育领域信息公开，做好与教育相关的舆情处置应对。

区农业局：做好农业、畜牧水产领域信息公开及涉农政策政策解读与舆情处置应对。

区城管局：做好城市管理领域信息公开及舆情处置应对。

区审计局：推进全区审计领域法律法规宣传和审计结果信息公开及舆情处置应对。

区林业和园林局：推进城市绿化和公园管理，森林、湿地和陆生野生动植物政策宣传和信息公开及舆情处置应对。

区城市更新局：做好城市更新政策宣传、改善人居环境和改造成果信息公开及舆情处置应对。

区民防办：做好城市人防领域信息公开及舆情处置应对。

区依法治区办：将法治广州建设与政务公开协调推进，做好法制广州建设考评与政务公开考评的衔接工作。

各镇街(园区)：做好辖区内的政务公开工作，积极参加领导小组有关工作会议，认真落实全区政务公开工作要点和分工方案，按分工要求推进相关工作。

三、工作规则

领导小组不定期召开工作会议，由组长或副组长召集，参加人员为领导小组全体成员或部分成员，必要时邀请其他单位人员参加。建立联络制度，联络科(办)为各成员单位负责政务公开的科室，联络员为科(办)具体经办人员，负责日常工作的联系和协调。

根据工作需要，领导小组对成员单位进行调整。领导小组成员因工作变动需要调整的，由所在单位报送区政务公开工作办公室。

四、工作机构

领导小组下设从化区政务公开工作办公室，办公室主任由协助分管政务公开的区政府办公室副主任兼任，办公室副主任由区政府办公室政务信息科负责人担任，日常工作由区政府办公室政务信息科(加挂从化区政务公开工作领导小组办公室牌子)承担。区政务公开工作办公室日常业务由办公室主任或副主任审定。政务公开重要事项，由区政务公开工作办公室根据需要征求相关单位意见，报领导小组领导审定，或提交领导小组成员会议审议。

五、工作要求

各成员单位要主动研究政务公开工作，积极参加领导小组工作，认真落实全区政务公开文件的部署和领导小组会议议定事项。各成员单位之间要加强协调配合，形成合力，共同推进政务公开各项工作。
