# 从化区人民政府办公室关于印发《从化区2018年政务公开工作要点分工实施方案》的通知

失效时间：2021.03.30

各镇人民政府、街道办事处，区政府各部门、各直属机构：

为贯彻落实《广东省人民政府办公厅转发国务院办公厅2018年政务公开工作要点的通知》（粤府办〔2018〕19号）、《广州市人民政府办公厅关于印发广州市2018年政务公开工作要点分工方案的通知》（穗府办函〔2018〕92号）的部署要求，结合我区实际，区府办公室制定了《从化区20l8年政务公开工作要点分工实施方案》，已经区人民政府同意，现印发给你们，请认真贯彻执行。

各镇（街），区各有关单位要根据本方案中的分工，结合实际制定本单位的具体实施方案，提出各具体任务的责任单位（科办）、实施步骤、完成时间节点、工作要求等，于7月10日前在本单位网站公布，并抓好方案实施。各牵头单位要积极主动组织协调相关责任单位抓好牵头任务的落实。区政务公开办要适时上网检查各单位实施方案的按时公布情况，加强对责任单位特别是牵头单位的督促指导。今年年底，各镇（街），区各有关单位要将落实情况和证明材料报区政务公开办汇总报区政府。各单位落实分工方案的情况，作为年度区政务公开工作考核的重要内容，考核结果纳入法治从化建设检查考核和机关绩效考核。
