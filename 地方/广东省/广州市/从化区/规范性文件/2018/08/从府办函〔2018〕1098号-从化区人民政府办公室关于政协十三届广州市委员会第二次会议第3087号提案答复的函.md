# 从化区人民政府办公室关于政协十三届广州市委员会第二次会议第3087号提案答复的函

孙石康委员：

您提出的《完善城区道路建设规划吸引更多市民选择公交出行》（第3087号）提案收悉。市政府高度重视，积极组织从化区政府等单位进行认真研究办理，并与您于2018年7月17日进行了电话沟通。经综合市会办单位意见，现将有关办理情况答复如下：

一、基本情况

（一）“城南片区”公共交通现状

现从化公交5路在街口街城南片区沙贝村（小院流溪属沙贝村）、赤草村、逸泉大酒店、逸泉山庄都设有公交站点；大凹村、石潭村、流溪御景、流溪河山庄暂无公交通行。

（二）河堤及堤顶路情况

1．提案中的“城南片区”通往市区的河堤为流溪河堤防，该路段堤防已按50年一遇防洪标准进行达标整治，堤顶路只作为防汛通道考虑。目前该段河堤实际上已经成为石潭村、大凹村及周边几个大型市民生活小区通往从化中心城区的主要出行通道。

2．从专业技术角度来说，河堤的功能是防洪，堤顶铺设水泥路面是方便了防汛使用，河堤及路面的设计及建设并未达到公路的设计和使用标准。从行车安全角度考虑，流溪河地面宽度8米，除去两侧不可磕碰的防护带，路面净宽仅为7．4米（部分河堤路段更窄），且弯道设计未设加宽和缓和曲线，在河堤路面会车需要减速让行才能通过，但交通事故仍然频发。

二、提案办理情况

（一）为解决大凹村、石潭村、流溪御景、流溪河山庄居民出行问题，目前开通“城南片区”公交线路已纳入从化区“实施乡村振兴战略三年（2018－2020）行动计划”。从化区已与公交企业负责人对通往石潭村、大凹村的两条线路（一是上述河堤线路、二是经过G105、逸泉山庄右转进入河堤过桥到达流溪御景线路）进行现场勘查，初步确定了公交线路和站点。现已初步拟出的该公交线路的开通方案，从化区将按流程积极推进，加快该片区的群众创造更优质的公共交通出行条件。

（二）正在对该片区交通问题开展前期研究工作，同时已将石潭村、大凹村及周边几个大型市民生活小区通往从化中心城区的问题纳入从化区综合交通规划中统筹考虑。

感谢您对我市交通工作的关心和支持，欢迎您继续对我们的工作提出宝贵意见和建议。

广州市从化区人民政府办公室
