# 从化区人民政府办公室关于印发2019年政务公开工作要点分工方案的通知

各镇人民政府、街道办事处，区政府各部门、各直属机构：

为贯彻落实《国务院办公厅关于印发2019年政务公开工作要点的通知》（国办发〔2019〕14号）和《广州市2019年政务公开工作要点分工方案》（穗府办函〔2019〕83号）的部署要求，结合我区实际，区政府办公室制定了《从化区2019年政务公开工作要点分工方案》（以下简称《分工方案》），经区人民政府同意，现印发给你们，请认真组织实施。现就有关工作通知如下：

一、《分工方案》中明确的牵头单位，要制定具体的实施方案，明确具体任务、工作分工和完成时限，加强实施过程中的督办协调，对整个项目的完成情况和效果负总责。各参与单位要按照牵头单位制定的方案，认真完成本单位负责的工作。

二、按照《中华人民共和国政府信息公开条例》（2019年4月修订）要求，健全政府信息公开工作考核制度、社会评议制度和责任追究制度。各单位落实《分工方案》的情况，纳入政务公

开考核。区政府办公室（区政务公开办）要加强各项工作落实情况的检查督导。今年12月，各单位要对《分工方案》中所列的项目，按注明的评价标准，逐项说明落实情况，包括制定的制度方案、所做的具体工作、取得的进展及效果，以及信息的公开内容、公开时间、公开载体等。区政府办公室（区政务公开办）要阅评各单位报送的情况和资料，结合网上检查核实，逐个单位、逐个项目进行考核评分，汇总成为该单位完成工作要点任务的总分。对工作量大、完成出色、形成经验、走在全国全省全市前列的单位及项目，要进行表扬和推广；对没有实质性开展工作、没有明显工作进展、没有完成既定目标任务的单位和项目，要通报批评，并列出清单进行督促整改。
