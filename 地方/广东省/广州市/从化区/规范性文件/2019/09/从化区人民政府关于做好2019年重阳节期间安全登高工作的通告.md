# 从化区人民政府关于做好2019年重阳节期间安全登高工作的通告

为确保我区重阳节登高活动安全，现将有关事项通告如下：

一、重阳节期间，为确保我区森林防灭火安全和生态安全，除街口街风云岭、太平镇马仔山为可登高活动区外，其它地区实行全面封山，禁止登高。

二、为避免人流过度拥挤，10月6日17时至10月7日7时，禁止全区各单位、企业组织集体登高活动。

三、10月6日7时至10月7日7时，除执行任务的车辆外，其他车辆禁止上可登高活动区。上山执行任务的车辆凭区指挥部发放的通行证，按规定的路线行驶和规定地点停放。

四、为确保安全，重阳节期间禁止登高群众攀爬未开发登山路径的山坡；登高要遵守秩序，不要争先恐后；不要在人多拥挤狭窄的地方聚集；不得滞留在道路两旁和进出口；要看管好携带的儿童和财物。

五、登山群众要遵纪守法，文明礼貌，互让互爱；要讲究卫生，不得随地吐痰便溺或乱丢果皮杂物；要爱护公物，不得损毁公共设施，不得攀折树木或践踏花草。

六、严禁携带枪支弹药、管制刀具等危险品上山；禁止携带烟花、爆竹、孔明灯、氢气球、香烛、灯笼、荧光棒、打火机、火柴、报纸等易燃易爆物品登山。

七、严禁登山时追逐打闹、起哄、滋事、斗殴；不得进行封建迷信活动。

八、提高警惕，严防山火和各种破坏、捣乱事件发生。发现破坏捣乱者，应立即向公安执勤人员报告，或将其交由公安执勤人员处理。如发生意外事故，要听从工作人员指挥，积极配合有关部门做好妥善处置工作。

广州市从化区人民政府
