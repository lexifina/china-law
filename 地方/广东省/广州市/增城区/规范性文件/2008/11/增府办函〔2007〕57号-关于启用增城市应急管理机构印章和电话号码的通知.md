# 关于启用增城市应急管理机构印章和电话号码的通知

( )

增府办函〔2007〕57号

各有关单位：

根据中共增城市委办公室、增城市人民政府办公室《关于成立增城市突发公共事件应急委员会的通知》（增委办文〔2007〕15号）和增城市机构编制委员会《关于印发〈增城市应急管理办公室机构设置、职能配置和人员编制规定〉的通知》（增编〔2007〕11号）精神,增城市应急管理办公室(加挂市应急指挥中心牌子)是市政府突发公共事件应急委员会日常工作机构和市政府办公室内设机构。“增城市应急管理办公室”和“增城市应急指挥中心”印章和电话号码于2007年11月19日起正式启用。

二○○七年十一月十六日
