# 关于进一步加强校车安全管理工作的通知

各镇政府、街道办事处，市府直属各单位：

近期，全国各地相继发生多起校车安全事故，造成多名师生伤亡，校车安全已成为政府和群众关注的焦点问题。为贯彻落实国家、省和广州市切实加强校车安全管理工作的有关要求，有效预防和遏制校车交通事故发生，保障广大师生生命财产安全，现就进一步加强我市校车安全管理有关事项通知如下：

一、加强领导，增强校车安全管理的责任感和紧迫感

校车安全管理工作关系在校青少年儿童的人身安全，关系社会和谐稳定，是当前市委、市政府和人民群众高度关注的重大民生问题。各级各部门要牢固树立“安全第一、预防为主”的意识，切实加强对校车安全工作的领导。市政府成立增城市校车安全管理工作领导小组（以下简称领导小组），由分管教育工作的副市长为组长，分管公安工作的副市长为副组长，成员由市教育、公安交警、交通运输、安监、工商等部门领导组成，负责全市校车安全管理工作的统筹协调、督促指导，领导小组下设办公室（设在市教育局）。各镇街、各相关部门要成立相应的工作机构，严格实行主要领导负责制，坚持一把手全面负责、分管领导具体抓落实，确保各项校车安全管理措施落到实处，保障广大师生人身安全。

二、规范管理，切实落实校车安全管理各项制度

各镇街、各相关部门和校车使用单位要加强对校车安全的监督管理，严格按照有关规定，落实各项管理制度，及时查找和消除安全隐患，做到警钟长鸣，常抓不懈。

（一）严格落实校车申办及驾驶员资格准入制度

申办校车要具备以下条件：属于使用年限8年以下、在广州市属车管部门进行登记和核定载客人数不少于9人的载客汽车；校车的安全技术状况符合《机动车运行安全技术条件》（GB7258－2004）标准并经公安交警、交通、环保部门检验合格；校车已参加机动车交通事故责任强制险、驾乘人员险和承运人责任险；校车已按照《校车标识》(GB24315—2009)的规定喷涂外观标识；校车已安装符合标准的卫星定位汽车行驶记录仪。车辆符合以上条件并经审查合格后方可作为校车使用。严禁未取得校车标牌的车辆用作校车，严厉打击其他车辆非法参与校车营运行为。

校车驾驶员要具备以下的条件：取得相应准驾车型驾驶资格，且有3年以上安全驾驶经历；最近3年任一记分周期违规记分均未达到12分；最近3年内无致人重伤、死亡的交通责任事故记录；无酒后驾驶、醉酒驾驶等机动车记录；身心健康，言行文明，无嗜酒、吸毒等不良习好；无传染性疾病，无癫痫、精神病等病史。

（二）严格落实校车安全日常管理制度

校车使用单位和校车服务提供单位要定期对校车性能、技术等进行检测和检修，对不符合安全标准的校车经检修合格后方可继续作校车使用，经检测合格的校车不得随意改装，对经改装或检修后仍然无法达到安全标准的校车要及时撤销校车资格；要参照营运车辆的检查维护要求，坚持每日出车前、行车中、收车后车辆的日常保养和维护，并做好检查记录；要对校车实行动态管理，建立校车管理台帐和驾驶员、随车照管人员台账，做到底数清、情况明；要建立学生乘车安全制度，制定学生乘坐校车安全守则；要配备随车照管人员，负责清点乘车学生人数，引导、指挥学生有序上下车，确保乘车学生安全落座，及时制止和报告校车超载、驾驶员酒驾等影响校车行车安全的情况；要坚持驾驶员行车教育培训制度，督促校车驾驶员加强日常安全培训学习，对凡是考核不合格的驾驶员，不得继续从事校车驾驶工作。

（三）严格落实校车行驶安全制度

校车使用单位和校车服务提供单位必须落实校车核载制度，严格按照行驶证核定的人数限额乘坐，副驾驶座不得乘坐中小学生和幼儿，对发生超载行为的校车按有关规定撤销校车资格。加强对校车通行路段和中小学、幼儿园周边道路的管控力度，落实校车行车安全常规巡查执法，重点查处校车超员、超速、车证不符、未放置检验合格标志、拼装改装及使用已达到报废标准的机动车的交通违法违规行为。

三、齐抓共管，形成校车安全管理合力

各镇街、各有关部门要按照“谁主管谁负责”“谁审批谁负责”的原则，加强沟通协作，落实职责分工，依法开展校车的安全管理工作，履行校车的安全管理职能。

（一）市教育局：负责指导、监督学校建立健全校车安全管理制度，落实校车安全管理责任；牵头会同市公安交警、交通运输、工商等部门严把校车准入关，配合做好校车手续办理，建立校车管理台账，对校车进行登记备案；负责开展学校交通安全教育；督促校车使用单位遵守校车安全管理各项规定，并将此项工作纳入对中小学和幼儿园年终目标考核范畴；设立校车安全投诉电话，接受群众举报，并对举报事实依法处理，对不属于本部门职责的及时转送相关部门处理；配合交通运输、公安交警部门对非法从事校车营运和校车交通违法行为的处理。

（二）市公安局：严把校车和驾驶员审批准入关，严格按规定办理校车注册、变更登记，审查校车驾驶人资格，落实校车检测工作；对合格校车核发校车标牌，实行统一外观标识管理；加强校车路面管控力度，严查校车超载、超速、疲劳驾驶和酒后驾驶等交通违法行为，协同交通运输部门严厉打击其他车辆非法从事校车营运的行为；配合教育部门组织开展学校交通安全宣传教育。

（三）市交通运输局：负责学校周边辖管道路交通标志的设置维护工作；完善辖管道路校车通行线路安全设施；严厉打击其他车辆非法从事校车营运等违法行为，并及时将情况通报教育、公安部门；牵头组织相关单位将校车纳入增城市交通安全监管中心的监管系统。

（四）市安监局：依法督促各相关部门对校车管理措施的贯彻和落实；依法对校车发生重、特大道路交通事故进行责任追究，依法追究相关人员责任。

（五）增城工商分局：依法对营利性托管中心进行登记注册，协助有关部门查处取缔无证照托管中心；将已登记发照的托管中心情况报领导小组办公室备案；配合教育、公安交警、安监等部门加强对托管中心校车的监管。

（六）各镇街：配合领导小组开展校车安全管理工作；落实属地管理责任，定期或不定期组织力量对辖区内校车实施监督、管理和整治；配合教育部门督促辖区内校车使用单位做好校车及驾驶员、随车管理员的登记、办证工作，加强对辖区内人员的校车安全教育。

（七）校车使用单位：严格按照有关规定购置、租赁和使用校车，依法依规办理校车使用手续；严格按照校车驾驶员条件聘任校车驾驶员；建立校车管理制度、学生乘车安全制度和车辆台帐，落实校车安全维护等各项日常安全管理制度；配合相关职能部门进行校车检查整治；与校车服务提供单位签订校车安全管理责任书，明确安全管理责任，落实校车运营安全管理措施。

四、多管齐下，建立长效机制全面保障校车安全

（一）集中整治与常态管理相结合

各镇街、各相关部门要根据全市统一部署，按照《增城市校车专项整治行动工作方案》（增府办函〔2011〕64号）的工作要求，迅速组织力量部署全市校车的全面排查整治工作，做到“四不漏”（不漏一校、不漏一村、不漏一车、不漏一人）。要坚持集中整治和常态管理相结合的原则，统筹兼顾，加强日常对学校落实校车安全管理各项制度情况的督促检查，形成校车安全管理制度化、科学化、常态化的长效管理机制。

（二）健全监督问责机制

将校车安全管理问责制度落实到各级各部门，对切实履行校车安全管理职责的予以全市通报表扬，对不履行或不正确履行校车安全管理责任的予以通报批评，对不作为、乱作为的依法追究相关责任人员的责任。要坚持责任倒查机制，对不履行校车安全管理责任发生重特大校车安全事故的，严格追究相关人员责任，确保校车安全管理各项工作措施真正落到实处。

（三）加强宣传教育，营造文明交通环境

要利用各种媒体渠道，广泛宣传校车安全管理政策法规，宣传和普及校车安全常识，提高广大师生、家长及群众的自我防护意识，自觉抵制并主动举报各种校车违规行为；要开展校车所有人、管理人及驾驶人安全教育，切实增强安全意识、责任意识、守法意识；要采取形式多样、内容丰富的交通安全主题宣传活动积极普及全民的交通安全意识，营造文明出行、安全驾驶的交通环境。

二〇一二年一月十二日
