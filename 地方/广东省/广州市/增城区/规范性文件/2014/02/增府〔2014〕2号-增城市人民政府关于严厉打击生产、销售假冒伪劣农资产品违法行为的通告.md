# 增城市人民政府关于严厉打击生产、销售假冒伪劣农资产品违法行为的通告

增府〔2014〕2号

为加强我市农业生产资料市场管理秩序，保护经营者和农民等消费者的合法权益，现就进一步严厉打击生产、销售假冒伪劣农资产品的违法行为通告如下：

一、对生产、销售假冒伪劣农资产品的行为，依照《中华人民共和国产品质量法》、《广东省查处生产销售假冒伪劣商品违法行为条例》、《农业生产资料市场监督管理办法》等法律、法规有关规定严肃查处。

二、知道或者应当知道他人生产、销售假冒伪劣农资产品，而为其提供场地、设备、物资、资金等生产经营条件或运输、保管、仓储及网络平台服务的，由工商行政管理、质量技术监督等管理部门依法查处;构成犯罪的，依法追究刑事责任。

三、对检举揭发、协助查处生产、销售假冒伪劣农资产品违法行为有功的单位或个人，按有关规定给予奖励。

四、凡使用暴力、威胁方法阻碍执法人员查处制售假冒伪劣农资产品违法行为的，依法追究刑事责任。

受理制售假冒伪劣农资产品举报电话：82744618。

本通告自发布之日起实施。

增城市人民政府

2014年1月23日
