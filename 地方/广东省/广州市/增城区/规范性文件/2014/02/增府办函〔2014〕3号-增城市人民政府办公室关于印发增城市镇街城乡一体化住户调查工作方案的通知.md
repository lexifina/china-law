# 增城市人民政府办公室关于印发增城市镇街城乡一体化住户调查工作方案的通知

增府办函〔2014〕3号

各镇政府、街道办事处，市府直属各单位：

《增城市镇街城乡一体化住户调查工作方案》已经市人民政府同意，现印发给你们，请认真贯彻执行。执行过程中遇到的问题，请径向国家统计局增城调查队反映。

增城市人民政府办公室

2014年1月21日

增城市镇街城乡一体化住户调查工作方案

为及时掌握各镇街的城乡居民收支和生活状况数据，全面了解各镇街城乡居民的生产、收入、消费、积累和社会活动情况，分析研究城乡居民收入和生活质量的变化，监测村(居)委全面建设小康社会的进程，为各级政府研究制定政策提供基础数据，根据《广东省人民政府办公厅关于开展全省城乡一体化住户调查的通知》(粤办函〔2013〕561号)的要求，结合我市实际，特制定本工作方案。

一、调查目标

通过调查，统计出镇街居民人均可支配收入、镇街城镇居民人均可支配收入和镇街农村居民人均可支配收入，包括工资性收入、经营性收入、财产性收入和转移性收入，及其消费支出等数据。

二、调查范围和对象

镇街城乡居民收支和生活状况调查范围为各镇街辖区内的区域，调查对象是上述区域的住户，具体包括城镇住户和农村住户;既包括以家庭形式居住的户，也包括以集体形式居住的户。不论户口性质和户口登记地，中国公民均以住户为单位在常住地参加本次调查。

三、调查内容和方法

(一)调查内容：主要包括居民现金和实物收支情况、住户成员及劳动力从业情况、居民家庭食品和能源消费情况、住房和耐用消费品拥有情况、家庭经营和生产情况、社区基本情况以及其他民生状况等。

(二)调查方法：抽中的调查户采取流水式日记账，每天逐笔登记家庭成员的收入和消费支出情况，包括现金、其它货币的收入和消费支出，以及住户自产自用的农产品收入和消费支出等。此外，季度和年度采取一次性入户调查方式，由辅助调查员入户调查取得调查户家庭的人口和劳动力及其就业情况，以及家庭的基本情况、农业生产情况等资料。

四、抽样总体、原则及样本量确定和分配

(一)以本镇街调查区域内的村委会和居委会(以下简称村居委)为总体，抽选满足主题调查需要的样本村居委和调查户。

(二)按“以全镇街为总体抽取样本，推算各镇街数据”和“为本级政府服务”的原则，由国家统计局增城调查队统一抽取代表各镇街的调查样本，以便满足镇街研究制定城乡统筹政策与民生政策配套数据的需要。

(三)采用全国住户调查制度规定的随机起点对称等距抽样方法抽取样本村居委和调查户。抽样方法：采用市抽村居委，村居委抽选调查小区，调查小区(人口普查小区)抽宅(户)三阶段抽样方法。

(四)样本量的确定及分配。结合人口普查资料，按照有一定代表性和最省调查经费的原则，确定镇街最小样本量(样本村、居委数量)。根据此原则，确定荔城街、新塘镇抽取样本点为4个，其中居委2个、村委2个;其他镇街抽取样本点为3个，其中居委1个、村委2个。每个样本点为10户，即荔城街、新塘镇40户(其中城镇居民20户、农村居民20户)、其他镇街30户(其中城镇居民10户、农村居民20户)。

五、工作步骤

(一)抽样步骤

1.样本村居委及调查小区的抽选：

(1)将本辖区内全部村居委按人均纯收入高低排队，相对应的家庭常住人口作为辅助指标累计编制成抽样框。

(2)根据分配给各镇街的样本村居委数量，计算抽样距离，按随机起点对称等距抽样方法抽选出满足城乡住户调查的样本村居委。

(3)在抽中的村居委中，再根据人口普查划分的小区，按随机抽取的原则抽选调查小区。

2.调查户的抽选：

(1)在中选的调查小区中，通过全面调查摸底，整理全小区分户常住人口和家庭收入资料，按住户人均纯收入高低排队，相对应的家庭常住人口作为辅助指标累计编制成抽样框。

(2)采用随机抽样方法，抽选确定中选的调查户。

(二)统计调查人员的配备和选聘

为确保城乡住户调查工作顺利开展，各镇街要配备1名以上的兼职统计员负责此项工作，并在中选的样本村居委会中选聘一名村居委干部作为辅助调查员，负责管理抽中户的调查工作。包括检查督促调查户记账，每个月到调查户家里收集调查户的记账本，审核有关收入和支出的数据，逐笔编制电脑录入代码，每季度和年度开展一次性调查，收集调查户的家庭基本情况(人口、就业、住房、农业生产等)。

(三)数据采集、评估及上报时间

1.数据采集。村居委居民的现金收入与支出、实物收入与支出资料通过调查户记账本取得，其余调查内容的资料采用访问调查的方式，在季末和年末由辅助调查员对被调查户进行一次性访问调查取得。

2.数据汇总。采用国家统计局下发的软件进行数据的录入、汇总，分两步进行：先是各镇街自行汇总各调查点的调查数据;然后是在各镇街汇总的基础上，由增城调查队按各镇街当地人口资料加权平均计算出当季、当年城乡居民人均可支配收入。

3.数据质量评估。增城调查队指导各镇街于每季度进行一次城乡住户调查数据质量评估工作。具体是在各镇街每个调查点抽取3个样本户进行检查核实调查户家庭收支情况，以评估当期城乡住户收入和支出调查数据质量。

4.统计调查年度和报表报告期。城乡住户统计调查年度为上年12月1日至本年11月30日。报表的报告期分为年报和季报，其中村居委居民现金收入与支出、村居委住户劳动力就业情况为季报;村居委居民所在村居委的发展情况、家庭基本情况、居住情况和农业生产结构调整与技术应用情况、村居委居民家庭实物收支情况等为年报。

5.报表上报时间。各镇街上报季报时间为每季度的季前7日，也就是3月25日、6月25日、9月25日，第四季度结合年报进行;上报年报时间为每年的12月25日。

(四)实施时间安排

1.准备阶段(2014年1月至2014年2月)

2014年1月上旬，各镇街按照本方案要求抽选调查小区样本;

2014年1月中旬，调查队开展对各镇街统计员进行工作布置和调查业务培训;

2014年1月下旬，各镇街组织开展分镇街城乡一体化住户调查工作宣传动员，选聘、培训辅助调查员;

2014年2月上旬，调查队组织镇街统计员进行调查数据处理程序培训;

2014年2月中旬，各镇街对抽中小区进行住宅摸查，建立住宅名录，抽选调查住宅和调查户。

2.实施阶段(时间：2014年2月下旬起)

2014年2月下旬，各镇街组织中选调查户进行记账业务培训，试记账。

2014年3月起，调查户正式记账。

六、职责分工

(一)增城调查队负责对各镇街统计人员、样本村居委辅助调查员进行有关城乡一体化住户调查制度、收账页、审核、编码、数据处理等业务培训。

(二)市统计局负责协助调查队做好宣传发动、检查指导以及调查数据评估等工作。

(三)各镇街负责对中选调查户家庭收支记账业务的培训，布置调查户开展记账工作，进行数据录入、审核和汇总工作，以及配合调查队做好涉及上级布置的一次性调查。

七、工作要求

(一)认真做好辅助调查员的选聘培训工作和抽中样本的落实工作

在确认调查小区后，各镇街要选聘有责任心、有一定文化水平、熟悉当地情况的村居干部作为辅助调查员，同时要对他们进行系统的培训，在抽选调查住宅后，对住宅内的住户做好落实工作，对不愿意参加记账的住户要耐心细致做好政策宣传和说服工作，打消抽中户的顾虑，保证样本落实工作顺利完成。

(二)扎实做好方案培训和学习工作

各镇街统计员要认真研究学习城乡一体化住户调查有关资料，正确理解调查方案，熟知指标的涵义和口径，熟练掌握调查工作流程和数据处理程序，明确工作规范和质量控制过程;要重点加强对辅助调查员现场调查技能的培训，增强其与调查对象沟通并指导调查户记账的能力;重点加强对抽中调查户的培训以提高记账质量。

(三)加强宣传发动

各镇街要结合分市县城乡一体化住户调查工作积极宣传城乡一体化住户调查工作的主要内容和具体实施步骤，加强对实施方案和数据变化的正确解读，宣传“为国记账”、“为民服务”、“为己理财”等易于被广大群众接受的口号，打消公众对调查的顾虑，提高配合度。

(四)严格按照方案组织实施调查

各镇街要严格按照调查方案开展调查工作，严格按照规定录入上报数据，要深入基层，深入社区，深入调查户，及时了解城乡一体化住户调查工作开展情况，认真解决调查中存在的各种问题，积极指导调查员依法完成国家和地方调查任务，要针对调查实施过程中的重点难点进行研究，寻找合适的实施办法。

(五)切实做好保障工作

各镇街认真解决好工作中出现的各种问题，切实保证人、财、物等与调查工作相适应。增城调查队统一印制记账本发送给各镇街使用，以及为各镇街提供调查数据录入程序。
