# 增城市人民政府办公室印发增城市农村金融改革创新综合试验区工作方案的通知

增府办〔2014〕1号

各镇政府、街道办事处，市府直属各单位：

《增城市农村金融改革创新综合试验区工作方案》已经市人民政府以及省金融办同意，现印发给你们，请认真组织实施。执行过程中遇到的问题，请径向市发改物价局反映。

增城市人民政府办公室

2014年1月7日

增城市农村金融改革创新综合试验区工作方案

为深入贯彻落实省和广州市关于促进农村经济发展以及2012年广东省农村金融工作现场会和2012年广州市农村金融工作座谈会的有关精神，加快我市农村金融服务体系建设步伐，不断创新农村金融服务平台与机制，进一步发挥金融杠杆在新农村建设中的作用，加快统筹城乡发展与“美丽乡村”建设，根据《广州市加快改善农村金融服务工作方案》要求，结合我市实际，制定本工作方案。

一、总体目标

在《广东省建设珠江三角洲金融改革创新综合试验区总体方案》、《广州区域金融中心建设规划(2011—2020年)》和《广州市加快改善农村金融服务工作方案》总体框架下，坚持统筹协调、先行先试、形成特色的原则，深化农村金融体制机制改革，设立新型农村金融组织，创新农村金融产品和服务模式，优化农村金融生态环境，到2015年构建多层次、广覆盖、功能丰富、运行安全的农村金融服务体系，为农村经济社会发展提供全方位的金融支持，创建广东省农村金融改革创新综合试验区。

二、主要原则

(一)统筹谋划，协调推进。统筹谋划农村金融改革创新工作，配套出台财税、信贷、产业和监管政策。市有关职能部门、各相关镇街根据职责分工，加强协调配合，形成合力共同推进农村金融改革创新工作。

(二)先行先试，逐步推广。选定我市2个镇，5个村作为创建广州市农村金融服务示范镇、村，率先开展农村金融改革创新试验，探索和总结建设农村金融体系和改善农村金融服务经验做法，成熟后逐步扩大试点内容和区域范围。

(三)分类指导，形成特色。支持各镇街和金融机构依托自身的优势和专长，根据不同区域“三农”发展及其金融需求特点，创新和丰富农村金融服务内容，打造各具特色的农村金融服务模式。

三、工作任务

(一)积极开展农村金融改革创新试点

1.全力推进广东省农村金融改革创新试验区工作。积极开展农村金融改革创新试点，全面推进示范镇和示范村试点工作的建设，认真总结试点经验并逐步推广，全面改善我市农村金融服务(牵头单位：市发改物价局(金融和上市工作服务中心);支持单位：广州市金融办、人民银行增城支行、市农业局、市新农办、市财政局、市林业园林局、各镇街;时间要求：2015年底前)。

2.选定2个镇(小楼镇、派潭镇)和5个村(中新镇霞迳村、石滩镇岗贝村、小楼镇腊布村、派潭镇高滩村、正果镇黄屋村)作为试点镇和试点村打造农村金融服务示范镇和示范村。按照广州市制订的标准，在试点镇建设农村金融服务街区和在试点村设立农村金融服务点，集中开展各类金融服务及相关配套服务;引导当地金融服务机构集聚发展，积极开展各类农村金融业务，强化金融聚集效应与服务功能，促进地方经济社会发展(牵头单位：市发改物价局(金融和上市工作服务中心);支持单位：广州市金融办、人民银行增城支行、市农业局，各镇街、各金融机构;时间要求：2014年底前)。

3.规划建设四大空间平台。在新塘镇规划建设广州中小企业金融创新服务中心;在荔城街建设互联网金融服务区;在小楼镇建设小楼农业产业孵化和金融服务园;在派潭镇建立农村金融服务街区(牵头单位：市发改物价局(金融和上市工作服务中心)、新塘镇、荔城街、小楼镇、派潭镇;支持单位：省金融办、广州市金融办、人民银行增城支行、市财政局、市国土房管局、市农业局;时间要求：2014年底前)。

4.探索设立资金互助合作社。探索设立服务会员、封闭运行、手续简便、对人信用、保本微利、风险可控的资金互助合作社，为农民专业合作组织发展提供资金支持。2014年成立3家资金互助合作社，成熟后进行推广，优先在试点镇设立资金互助合作社(牵头单位：市发改物价局(金融和上市工作服务中心);支持单位：广州市金融办、市农业局;时间要求：2014年底前)。

5.加快建设农村金融综合服务聚集区。在挂绿湖水利工程核心区规划建设增城农村金融综合服务聚集区(农村金融街)，积极引导当地金融机构聚集发展，大力发展金融后台服务基地，形成辐射东莞、惠州和粤东北广大农村地区的金融综合服务功能区(牵头单位：市发改物价局(金融和上市工作服务中心);支持单位：广州市金融办、人民银行增城支行、广州农商行等金融机构;时间要求：2015年底前)。

6.培育企业发展基金。设立服务中小微企业之“助保贷”基金，规模2亿以上，由财政专项资金作风险补偿金，企业缴纳一定比例“助保金”，并提供一定比例的抵押或担保，由银行根据风险补偿金提供最高可达10倍授信额度(牵头单位：市发改物价局(金融和上市工作服务中心);支持单位：市财政局、各金融机构，时间要求：2014年底前);与金融机构合作，争取省市发改委的资金支持，在市开发区设立服务初创型企业之创业引导投资基金，规模2.5亿以上，充分发挥政府资金的政策引导和杠杆放大作用，引导社会资本投向区域内先进装备制造产业和具有竞争力的高新技术企业，提升企业自主创新能力(牵头单位：市发改物价局(金融和上市工作服务中心);支持单位：广东省发改委、广州市发改委、市财政局、开发区经科信局、各金融机构，时间要求：2014年底前)。

(二)着力完善农村信贷服务体系

7.引导金融机构加大对涉农信贷支持力度。大力支持农业银行、农商银行、农业发展银行、邮政储蓄银行、村镇银行等增城市涉农银行机构扎根农村金融市场，拓展农村机构网点，加大对“三农”的贷款投放力度，各有关镇街在用地、用房、用工上给予优先保障，对入驻农村金融服务缺乏镇街的金融机构给予政策扶持(牵头单位：人民银行增城支行、市发改物价局(金融和上市工作服务中心);支持单位：市财政局、市农业局、市扶贫办、各镇街，时间要求：2015年底前)。

8.积极发展新型农村金融组织。支持做实我市现有的村镇银行，争取其分支机构进村入户，加强对“三农”的金融服务;争取增设2家村镇银行或村镇银行分支机构(牵头单位：市发改物价局(金融和上市工作服务中心)、广州市增城长江村镇银行;支持单位：广州市金融办、人民银行增城支行，时间要求：2015年底前);增设5家以支农金融业务为主的小额贷款公司(牵头单位：市发改物价局(金融和上市工作服务中心);支持单位：广州市金融办，时间要求：2014年底前)。

9.开展信贷产品创新。探索推进农村宅基地使用权、土地承包经营权、林权、果权等抵押贷款试点，鼓励银行机构创新担保方式，进一步加强涉农信贷与涉农保险合作，推动创新信用产品和服务方式的创新(牵头单位：广东银监局、人民银行广州分行营管部;支持单位：广州市金融办、广州市农业局、广州市国土房管局、各镇街，时间要求：2015年底前)。

10.探索金融扶贫机制。市财政在当年的扶贫资金中安排一定经费作为涉农金融机构扶贫信贷的贴息资金，支持和鼓励涉农金融机构向自主创业的贫困户发放低息或免息贷款，减轻贫困户的负担，扶持贫困户通过创业实现脱贫致富(牵头单位：市发改物价局(金融和上市工作服务中心);支持单位：市财政局、市农业局、各镇街、各金融机构，2015年底前)。

(三)大力拓宽资本市场支农渠道

11.培育企业上市增城板块。鼓励企业通过上市进行融资，争取100家以上企业在区域性股权交易中心和“新三板”挂牌，3家以上企业在国内外上市;与国内外著名的专业机构合作，加大对后备上市企业培训，力争培训企业80家以上，进入上市推荐培育期企业20家以上(牵头单位：市发改物价局(金融和上市工作服务中心)、市科经信局、开发区经科信局;支持单位：市企业联席会议成员单位、广州股权交易中心、专业机构，2015年底前)。

12.探索培育区域性农村金融要素市场。与广州农村产权交易所、广州碳排放权交易所合作开展农村土地承包经营权、林权的流转交易;开放环境和林业碳汇资源，建立城乡生态补偿和流转交易机制，在我市设立1至2个广州绿色GDP(地方生产总值)生态调节示范区;以广州农村产权交易所为依托与各村镇集体土地流转机构建设农村产权流转信息系统，形成信息共享机制，并支持广州农村产权交易所积极与当地金融机构共同搭建涉农金融公共服务平台(牵头单位：市发改物价局(金融和上市工作服务中心)、市农业局、市林业园林局;支持单位：广州市金融办、广州交易所集团、市国土房管局、各镇街，时间要求：2014年底前)。

13.拓宽涉农企业直接融资渠道。鼓励设立投资现代农业的股权投资基金，通过股权投资整合上下游产业链条，推动农副产品和水产品的深加工(牵头单位：市发改物价局(金融和上市工作服务中心)、市农业局，时间要求：2014年底前)。

(四)建立健全农村保险服务保障体系

14.扩大政策性涉农保险覆盖面。在提高农房、能繁母猪、水稻、渔业、森林、蔬菜等政策性保险覆盖面的基础上，逐步开展玉米、马铃薯、奶牛、花生等补充保险项目，探索开展荔枝等具有地方特色的涉农保险项目。结合现代农业产业配套项目资金、优惠政策和金融服务项目共同推进涉农保险，健全基层涉农保险协保体系建设，提高保险覆盖面和保障水平(牵头单位：市发改物价局(金融和上市工作服务中心);支持单位：保险业各支公司、市农业局、市林业园林局、市财政局、各镇街，时间要求：2015年前)。

15.建立健全农村保险机构体系。鼓励民间资本进入农村保险领域，研究由大型保险机构与农业龙头企业、市属国有企业合作设立专业性农业保险公司的可行性(牵头单位：广州市金融办、增城市政府;支持单位：广东保监局、广州市农业局，时间要求：2015年底前)。积极研究由农民、农民专业合作组织、农业龙头企业建立互助农业保险组织(牵头单位：广州市金融办、增城市政府;支持单位：广东保监局、广州市农业局，时间要求：2015年底前)。

(五)全面优化农村金融生态环境

16.加强农村社会信用体系建设。成立增城市征信中心;整合有关部门和单位的信用信息，建设增城市农村信用信息数据库，集中处理授权查询，建立农户信用等级评定制度，鼓励和支持涉农金融机构对守信农户、涉农企业实施优惠贷款利率、简化贷款手续等激励措施;开展信用村镇评比工作，营造“守信光荣，失信可耻”的良好信用氛围。成熟后在全市推广(牵头单位：市发改物价局(金融和上市工作服务中心)、人民银行增城支行、市农业局、市科经信局、派潭镇、小楼镇;支持单位：涉农金融机构，时间要求：2014年底前)。

17.完善农村金融基础设施。支持银行机构和第三方支付机构加快农村支付体系建设，通过安装电话POS机、设立助农取款点等方式，实现每一个行政村金融服务全覆盖，解决农村金融服务空白问题;大力推广银行卡支付、手机支付、网络支付等现代支付工具(牵头单位：人民银行增城支行;支持单位：广州农商行增城支行等相关金融机构、市农业局、市发改物价局(金融和上市工作服务中心)、市财政局、市科经信局，时间要求：2015年底前)。加强宣传推广，推动农产品销售款、农民社保基金等资金通过银行卡进行支付(牵头单位：人民银行增城支行、市财政局、市发改物价局(金融和上市工作服务中心)、市农业局、各镇街，时间要求：2015年底前)。增加投放各类自助金融服务终端设备，将存取款一体机等设备布设到镇和行政村(牵头单位：广州农商行增城支行等相关金融机构;支持单位：各镇街，时间要求：2015年底前)。

(六)构建农村金融综合服务平台

18.推广建立农村金融服务站。依托各行政村村委会建设农村金融服务站，分期分批培训服务站人员，为广大农户提供信用信息收集、支农金融产品代理销售、金融知识宣传普及等便民利民金融服务(牵头单位：市发改物价局(金融和上市工作服务中心)、市农业局;支持单位：人民银行增城支行、各镇街，时间要求：2015年底前)。

19.成立金融业协会。成立增城市金融业协会，搭建地方金融机构、金融研究组织及相关企业、经济组织之间的交流和作平台，加强金融机构与政府部门的沟通联系，推动增城市农村金融改革创新综合实验区建设(牵头单位：市发改物价局(金融和上市工作服务中心);支持单位：人民银行增城支行，各金融机构;时间要求：2014年底前)。

20.建设互联网金融服务区，做大做强中小企业融资超市。引入第三方中介机构经营中小企业融资超市网站，为需融资企业和金融机构提供一个长期交流合作的平台，实现实时、快速、方便、有效的融资对接，改善对企业的融资服务，促进我市经济社会发展(牵头单位：市发改物价局(金融和上市工作服务中心);支持单位：人民银行增城支行，各金融机构，时间要求：2014年底前)。

21.建设农村金融理论研究基地。与华南农业大学广东农村经济研究中心合作，在增城建立农村金融理论研究基地，对增城农村金融改革创新综合试验区建设进行基础研究，通过对农村金融服务需求的专业分析，进一步推进增城农村金融改革创新综合试验区的建设(牵头单位：市发改物价局(金融和上市工作服务中心);支持单位：华南农业大学广东农村经济研究中心;时间要求：2014年底前)。

四、保障措施

(一)完善领导机制。建立增城市农村金融工作联席会议制度，由市长任总召集人，分管金融工作的副市长任召集人，成员由市府办、人民银行增城支行、市发改物价局(金融和上市工作服务中心)、市科经信局、市公安局、市民政局、市财政局、市国土房管局、市人社局、市水务局、市农业局、市工商局、市林业园林局、市法制办及各镇街主要负责人组成，负责我市农村金融工作的领导组织和统筹协调。联席会议下设办公室，设在市发改物价局(金融和上市工作服务中心)，办公室主任由市发改物价局主要负责人兼任。各成员单位要根据各自的职责，积极主动开展工作，共同抓好方案落实。各镇街要认真制订本地区农村金融改革创新的工作方案并推进落实。

(二)建立健全监督管理机制。建立农村金融风险监督管理机制，在市农村金融工作联席会议的领导下由市发改物价局(金融和上市工作服务中心)、人民银行增城支行、市农业局负责农村金融的日常监督和管理工作，共同防范和处置金融风险问题，定期向市政府报告农村金融工作进展情况。市发改物价局负责落实市农村金融工作联席会议的决定，统筹、协调各部门开展监管工作;人民银行增城支行负责对各金融机构的利率、资金流向进行跟踪监测;市农业局负责涉农保险项目的推广，协同市发改物价局对资金互助合作社进行监管。

(三)加强政策支持。认真落实国家、省关于鼓励农村金融发展的财税扶持政策，逐步推开涉农信贷增量奖励、扩大涉农信贷税收优惠范围等。从2013年起市财政资金每年安排农村金融建设扶持资金，用于对银行机构和小额贷款公司发放涉农贷款给予风险补偿以及对发展涉农保险项目、完善农村金融组织体系、建设农村金融基础设施、建设农村金融服务示范镇(村)、探索培育区域性农村金融要素市场以及优化农村金融发展环境给予补贴。资金支持政策及资金使用和管理办法另行制定。
