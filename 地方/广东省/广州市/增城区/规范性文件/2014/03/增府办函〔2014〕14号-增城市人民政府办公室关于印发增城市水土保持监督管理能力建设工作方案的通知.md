# 增城市人民政府办公室关于印发增城市水土保持监督管理能力建设工作方案的通知

增府办函〔2014〕14号

各镇政府、街道办事处，市府直属各单位：

《增城市水土保持监督管理能力建设工作方案》已经市人民政府同意，现印发给你们，请认真贯彻执行。执行过程中遇到的问题，请径向市水务局反映。

增城市人民政府办公室

2014年2月17日

增城市水土保持监督管理能力建设工作方案

根据广州市水务局《转发广东省水土保持监督管理能力建设实施方案(修订)的通知》和《广州市水务局转发关于我省水土保持监督管理能力建设分年度考核计划安排的通知》(穗水农村〔2013〕17号)要求，我市必须在2014年12月底前完成水土保持监督管理能力建设任务,并达到省级验收标准。为进一步做好水土保持监督管理能力建设，按时按质完成任务，结合我市实际，特制定本工作方案。

一、指导思想

以科学发展观为指导，践行可持续发展治水思路，深入贯彻《中华人民共和国水土保持法》，建立健全各种规章制度，依法行政，加强监督执法，规范监督管理行为，落实水土保持“三同时”制度，有效遏制人为水土流失，保护生态环境，促进我市经济社会又好又快、可持续发展。

二、工作目标

加强水土保持监督管理能力建设，在2014年12月底前完成我市建设任务,并达到省级验收标准。

(一)“五完善”，指完善水土保持管理、方案审批、现场监督检查、设施验收和水土保持生态补偿等水土保持配套制度。

(二)“五到位”，指全面落实监督管理机构、监督执法人员、办公场所、工作经费和取证设备。

(三)“五规范”，指规范方案审批、监督检查、设施验收、规费征收和案件查处工作。

(四)“五健全”，指健全水土保持督察制度、年度及重大水土流失案件(事件)报告制度、水土保持技术服务管理制度、廉政建设制度和社会监督制度，达到权责明确，公正透明，监督有效。

(五)“保三率”，指提高生产建设项目水土保持方案申报率、实施率和验收率，确保“三率”达标，其中水土保持方案申报率达到90%以上，水土保持方案实施率达到80%以上，水土保持设施验收率达到70%以上。

三、工作内容

对照验收标准(详见附件)，全面开展我市水土保持监督管理能力建设。

(一)完善配套制度

由市水务局制定《增城市水土保持管理细则》和《增城市水土保持监督检查规定》并印发实施;由市水务局牵头会同市发改物价局、市财政局制定《增城市水土保持补偿费征收和使用管理规定》并印发实施;由市水务局牵头会同市环保局、市城乡建设局、市国土房管局、市农业局、市林业园林局等部门制定《增城市开发建设项目水土保持方案编报审批规定》、《增城市开发建设项目水土保持设施验收管理规定》并印发实施。

(二)加强监督管理机构履行职责能力建设

1.落实机构及管理人员。市水务局为我市水土保持主管部门，向有关机构申请在其农村水利科加挂水土保持科牌子，具体履行开发建设项目水土保持方案的审批、监督实施和组织验收行政职责。对监督管理能力建设各项工作进行全面总结，形成书面总结报告，迎接上级检查。设立举报电话、信箱：020—82612123，传真：020—82639609，邮箱：ZCSLGG@163.com。

2.加强监督执法队伍建设。市水政监察行政执法队按职能负责水土保持监督执法，主要负责落实执法取证的设备装备，落实工作经费，持证上岗;组织监督执法人员参加监督管理活动培训，加强监督检查执法力度，确保水土保持监督管理工作的正常开展，确保水土保持监督检查、案件查处等工作公正、公平、及时有效进行;加大宣传力度，加强与发改、建设、环保、国土等部门工作沟通和联系，落实《增城市“十二五”期间水土流失治理工作方案》，理顺审批关系，将水土保持方案作为办理可行性研究报告批复或报批核准的前置条件，清理审批、报批核准的新建或在建项目编报水土保持方案情况;采取有效措施，保障开发建设项目水土保持方案的报批率、实施率和验收率。

(三)规范监督管理工作

1.规范水土保持方案审批。水土保持方案的受理、审查、批复、送达规范，审批机构为市水务局水土保持科，要求严禁出现逾期审批、越权审批等现象，避免已批水土保持方案出现技术性错误。

2.规范监督检查。每年至少对本级及上级审批水土保持方案的生产建设项目开展2次监督检查，对违法违规生产建设项目的批评、通报、曝光等处理符合法律法规和政策的规定。监督检查的各类文字、影像资料要求完整，并按照规定上报、登记、建档。

3.规范水土保持设施验收。水土保持设施验收技术评估、受理、验收、送达规范，有文字记录，不得逾期验收、越权验收和故意刁难建设单位。严格水土保持设施验收标准，确保已验收生产建设项目不出现严重水土保持质量问题。

4.规范规费征收使用。水土保持补偿费征收程序、标准、方式和使用管理规范，征收的费用主要用于水土保持工作，不得擅自降低标准或超标准征收，杜绝“以收代管”、“以收代罚”行为。除生产建设单位无力治理的，不得违规征收水土流失防治费。

5.规范案件查处。立案查处水土保持违法违规案件依据充分，取证方式和程序合法，法律适用正确，文书及执行规范。执法文书符合省监督站统一规定的法律文书格式要求。

(四)健全监督管理制度

1.建立定期工作报告和重大水土流失事件汇报制度。每年1月底前向上一级监督管理机构提交上年度水土保持监督管理工作报告及报表。发生重大水土流失事件(一次水土流失1000立方米以上)1周内向上一级监督管理机构报告，特大事件(一次水土流失10000立方米以上)及时报告。

2.建立廉政建设制度。对水土保持监督管理人员和参与水土保持方案审批、技术评估等技术服务机构及专家，要建立相应的廉政管理机制，加强行风建设，巩固民主评议行风成果，杜绝腐败行为。

3.健全社会监督制度。建立完善水土保持监督管理公示公告制度，公告水土保持方案审批、验收等行政许可依据、程序、条件、时限、内容和结果，公告生产建设项目水土保持监测成果和其他重要事项，做到公开、公正、透明，自觉接受社会各界监督。设立举报电话、信箱并正式公布，规范举报的记录、接收、处理、协调、反馈等各环节工作。

四、职责分工

全市各相关部门必须密切配合联动，各负其责，确保我市水土保持监督管理能力建设工作顺利开展，提高“三率”，按时完成建设任务。

市水务局：为我市水行政主管部门，统筹全市水土保持工作。负责协调水土保持工作和开发建设项目水土保持方案的审批、管理及验收等工作。拟定增城市水土保持监督管理能力建设实施方案;牵头完善水土保持配套制度建设;组织监督执法人员参加监督管理活动培训;开展水土保持监督管理行为规范制度建设;完善水土保持监督管理岗位设置及岗位职责。

结合水法规政策宣传和普法工作，结合办理《广州市施工排水许可证》、《城市排水许可证》审核和排水管网接驳、迁改、临时占用排水设施管理工作，结合办理取水行政审批、城乡供水设施建设管理工作，同时了解项目水土保持报批、实施和验收情况，严格把关，采取有效措施，督促项目业主办理水土保持方案报批手续，否则按规定不予办理相关业务，保障开发建设项目水土保持方案的报批率、实施率和验收率。

市国土房管局：配合整理已办采矿手续的矿山水土保持方案报批情况和土地开发项目水土保持报批情况，并将整理结果报市水务局备案;在执法检查时告知业主补办水土保持方案，并配合督促业主按方案完成水土流失治理任务;在办理新办采矿手续和批复土地开发手续时配合相关职能部门要求业主按法规程序做好水土保持方案报批工作。

市环保局：配合做好开发建设项目水土保持方案的报批和验收工作。负责根据有关法规要求将水土保持方案作为批复环境评价报告的依据之一，对已批环境评价报告的项目抄送市水务局备案，并在环境执法检查时告知项目业主做好水土保持工作，在办理环评审批、验收时要求提供水土保持审批、验收材料。

市城乡建设局：配合做好开发建设项目水土保持措施验收工作。在办理项目开工手续和竣工验收备案时告知办理水土保持方案的报批和验收手续。

市农业局：制定水土流失地区的农田土壤改良、坡耕地蓄水保土的农业耕作措施及组织开展技术推广，监督和指导各镇街开展农田耕地的水土保持工作，将治理情况报送市水务局汇总统计。

市林业园林局：负责在审批采伐手续时按法规要求把好水土保持措施审核关。督促林地使用者及时完成水土流失治理任务(如造林、林地复绿、退耕还林等)，并报送市水务局汇总统计。

市监察局：对各单位落实水土保持工作责任情况进行监督。

市法制办：负责水土保持监督管理相关文件的合法性审查工作。

市编办：配合做好在市水务局农村水利科加挂水土保持科牌子的相关工作。

市发改物价局：负责清理审批、报批核准的新建或在建项目编报水土保持方案情况抄送市水务局备案，并督促其编报水土保持方案。

市公安局：负责协助做好水土保持联合执法检查工作。

市财政局：负责水土保持监督管理能力建设工作所需资金支持。

各镇街：加强建设项目水土保持的巡查、监督工作，发现问题及时向市水行政主管部门汇报，并配合市水行政主管部门开展执法工作;认真做好水土保持政策法规在本级行政区域内的贯彻落实工作，为市水行政主管部门水土保持监督执法提供基本数据资料。

五、进度安排

(一)第一阶段(启动阶段,2012年12月—2013年6月)

1.制定增城市水土保持监督管理能力建设实施方案。

2.召开动员会，全面启动监督管理能力建设工作。

(二)第二阶段(培训研讨阶段,2013年6月—2013年9月)

1.完成市、镇两级执法机构、队伍、装备和办公条件到位工作。

2.组织水土保持监督管理人员系统学习水土保持法律法规及有关业务知识。

3.组织参加全省水土保持监督管理培训班。

4.开展水土保持方案审批制度、现场检查制度、设施验收制度等有关水土保持监督管理制度的讨论，制定完善各项工作制度。

(三)第三阶段(全面推进阶段，2013年9月—2014年10月)

1.加大工作力度，全面推动监督管理能力各项建设工作。

2.定期召开监督管理能力建设情况汇报会，落实能力建设各项目标要求。

(四)第四阶段(总结阶段，2014年11—12月)

1.对监督管理能力建设工作情况进行自查。

2.对监督管理能力建设各项工作进行全面总结，形成书面总结报告，迎接上级检查。

六、保障措施

(一)多方争取资金，安排足够的经费，保障监督管理能力建设的正常开展。

(二)加大舆论宣传力度，及时报导重大事件、介绍先进做法和经验，及时向上级政府部门、市政府及相关部门汇报情况。
