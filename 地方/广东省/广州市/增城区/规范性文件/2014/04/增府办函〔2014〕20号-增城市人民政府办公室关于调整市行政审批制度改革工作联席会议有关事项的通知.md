# 增城市人民政府办公室关于调整市行政审批制度改革工作联席会议有关事项的通知

( )

增府办函〔2014〕20号

各镇政府、街道办事处，市府直属各单位：

为切实做好我市深化行政审批制度改革的各项工作，经市政府同意，现就调整市行政审批制度改革工作联席会议有关事项通知如下：

一、市行政审批制度改革工作联席会议由罗思源市长担任召集人，徐明曦副市长担任副召集人。

二、市行政审批制度改革工作联席会议成员单位包括市编办、市法制办、市发改物价局、市科经信局、市监察局、市民政局、市人社局、市政务办。

三、市行政审批制度改革工作联席会议办公室设在市编办，负责牵头组织指导协调我市行政审批制度改革工作，办公室主任由市编办王宇乾主任兼任。

增城市人民政府办公室

2014年4月11日
