# 关于转发广州市政府办公厅《关于加强社区和城镇消防安全工作的意见》的通知

( )

增府办[2003]9号

各镇政府、沙庄街道办事处，市府直属各单位：

为进一步加强我市社区和城镇消防安全工作，加快城镇消防规划和公共消防设施建设，现将广州市政府办公厅《关于加强社区和城镇消防安全工作的意见》(穗府办[2003]8号)转发给你们，请认真贯彻执行。

二ΟΟ三年四月一日

主题词：城乡建设 消防 意见 通知

抄送：市委各部委办，市人大办，市政协办，市纪委，市武装部，市法院，市检察院，各人民团体，增城报社。

增城市人民政府办公室综合科

2003年4月1日印发
