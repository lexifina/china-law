# 增城市人民政府办公室关于印发2014年增城市政府信息公开工作安排的通知

增府办函〔2014〕21号

各镇政府、街道办事处，市府直属各单位：

《2014年增城市政府信息公开工作安排》业经市人民政府同意，现印发给你们，请认真贯彻执行。在执行过程中遇到的问题，请径向市政务公开工作办公室(设在市府办)反映。

增城市人民政府办公室

2014年4月21日

2014年增城市政府信息公开工作安排

为深入贯彻落实《国务院办公厅关于印发当前政府信息公开重点工作安排的通知》(国办发〔2013〕73号)、《国务院办公厅关于进一步加强政府信息公开回应社会关切提升政府公信力的意见》(国办发〔2013〕100号)精神和《广东省人民政府办公厅关于进一步推进重点领域信息公开的意见》(粤府办〔2013〕38号)、《广州市人民政府办公厅关于印发2014年广州市政府信息公开工作安排的通知》(穗府办〔2014〕8号)的工作部署，结合增城市委、市政府中心工作，现就2014年增城市政府信息公开工作安排如下：

一、大力推进重点领域政府信息公开

各镇街、各部门要积极推行行政审批(市编办牵头)、财政预决算和“三公”经费(市财政局牵头)、保障性住房(市国土房管局牵头)、食品药品安全(市卫生局牵头)、环境保护(市环保局牵头)、安全生产(市安监局牵头)、价格和收费(市发改物价局牵头)、征地拆迁(市国土房管局牵头)等事关民生福祉的政府信息公开。各重点领域牵头部门要进一步规范本部门牵头负责信息公开标准，对公开内容、公开范围、公开渠道、公开时间以及发布格式等提出具体要求，负责编制重点领域政府信息公开目录，依法在本单位网站发布，同时报送市政府门户网站编辑部，在“增城市重点领域政府信息公开”专栏发布，各牵头部门要做好专栏内容保障工作，确保信息及时发布更新。市教育、卫生、科技、文化、国资等部门要分别指导所属学校、医疗卫生机构、科研机构、文化机构和国有企业等公共企事业单位信息公开工作。

二、规范行政审批等职权信息公开

(一)推进行政审批过程和结果公开。各镇街、各部门要结合深化行政审批制度改革、撤市设区要求，结合网上办事大厅建设统一的信息交换平台，实现与各单位行政审批业务系统、行政审批电子监察系统无缝对接，除依法应当保密的内容外，及时向社会公开行政审批项目的审批过程、审批结果以及审批过程中违法违纪责任追究情况等信息。

(二)推进行政权力公开运行。各镇街、各部门要认真清理本单位行政审批、行政处罚等各项职权事项，编制本单位各类行政职权目录和每一类事项的基本信息(内容应包括序号、编码、名称、职权依据、实施主体、实施条件等)，在市政府门户网站“增城市规范行政权力公开运行”专栏上发布。

三、加强政府新闻发布和回应社会关切

(一)推进新闻发言人制度建设。市府办要加强政府新闻发言人制度建设，组织做好市政府领导新闻发布会工作。市政府各部门对涉及本单位的发布议题及记者和网民的提问，要及时、全面、准确提供权威政府信息。

(二)积极回应社会关切。各部门在重要政策法规出台后，要及时利用政府门户网站、微博、微信等方式发布各类权威政府信息，做好重点解读，方便公众知晓、理解、支持政府经济社会发展政策和改革举措。

(三)加强政民互动。各镇街、各部门要加强“领导信箱”、“百姓热线”、“意见征集”、“领导接访”、“在线访谈”、“政务微博、微信”等渠道，健全群众诉求受理、处置、反馈工作制度和机制，对网民反映的问题要逐条反馈，及时为市民群众排忧解难，畅通政民互动渠道。

四、进一步规范政府信息公开机制

(一)完善信息公开组织机构。随着机构改革、部门人员的变更，各镇街、各部门要及时更新本单位的政务公开工作领导小组成员，并安排专人负责本单位的政府信息公开工作。

(二)完善主动公开制度。进一步规范政府信息主动公开的原则、内容、程序和形式，依法依规界定信息公开属性，将本单位制作和保存的政府信息细化分类，编制目录，实现标准化的分类管理。

(三)完善依申请公开制度。各镇街、各部门应当主动公开本单位受理机构的名称、办公地址、办公时间、联系电话、传真号码以及统一规范的政府信息公开申请格式文本等内容，开辟信函、传真、网上处理系统等多种受理渠道，按照《广州市人民政府办公厅关于规范行政机关依申请公开政府信息工作的意见》(穗府办〔2013〕25号)，进一步规范本单位依申请公开的受理、审查、处理、答复程序，参照省政府办公厅和广州市政府办公厅印发的文本格式，结合本单位实际制作依申请公开答复文书。加强对依申请公开工作中复杂疑难问题的研究，及时借鉴总结经验。

(四)完善信息公开保密审查机制。各镇街、各部门要依据法律、法规和国家、省、市有关规定，严格按照“谁公开、谁审查、谁负责”的原则对申请人申请公开的信息进行保密审查，不得公开涉及国家秘密的政府信息。

五、加强业务培训和监督检查

(一)由市政务公开工作办公室牵头，以普及政府信息公开和保密审查基本知识，增强政府工作人员的工作能力为目标，积极开展行政职权公开、政府信息保密审查和公开属性界定、依申请公开政府信息等业务培训。

(二)由市政务公开工作办公室牵头，健全政府信息主动公开、政府信息公开登记统计报送、政府信息公开年度报告、政府信息公开工作考核考评机制。

(三)市监察局要加强对政府信息公开情况的督查，对不按规定公开、假公开的，要严肃批评、限期整改;对因此造成严重后果的，要依法追究相关人员的责任。

(四)由市科经信局牵头，加强对各镇街、各部门政务网站的建设和管理，同时加强市各有关部门对市政府门户网站各栏目内容保障工作的指导和考核。
