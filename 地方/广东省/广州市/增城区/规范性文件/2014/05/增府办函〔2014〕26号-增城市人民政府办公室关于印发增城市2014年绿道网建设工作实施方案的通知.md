# 增城市人民政府办公室关于印发增城市2014年绿道网建设工作实施方案的通知

增府办函〔2014〕26号

各镇政府、街道办事处，市府直属各单位：

《增城市2014年绿道网建设工作实施方案》已经市政府同意，现印发给你们，请认真贯彻执行。执行过程中遇到的问题，请径向市林业园林局反映。

增城市人民政府办公室

2014年5月16日

增城市2014年绿道网建设工作实施方案

为落实省和广州市绿道网建设工作的部署，进一步发挥绿道的功能和效益，加快我市生态旅游文化建设，打造具有增城特色的绿道网，为市民和游客提供一个集休憩、娱乐、健身、观景于一体的绿色公共空间，根据《广东省绿道建设管理规定》、《广东省绿道网建设总体规划(2011-2015)》、《广州市绿道建设管理办公室关于下达2014年绿道建设计划的通知》(穗绿道办〔2014〕1号)和《增城市绿道管理办法》等文件要求，结合我市实际，特制定本实施方案。

一、指导思想

坚持“以人为本、贴近群众、服务民生”的绿道规划建设宗旨，以“政府主导、社会参与，属地管理、部门配合，突出特色、生态环保、可持续发展”为原则，结合我市“水城、花城、绿城”建设，进一步深化和完善全市绿道网的规划建设。

二、工作目标

完善绿道系统建设，实现绿道与城市交通系统的衔接，保护与修复绿道沿线景观的风貌，并对沿线绿道区域的功能进行合理利用，推进城乡互动，提高市民生活品质和促进内需。结合绿道沿线地形地貌、自然资源、人文资源等条件规划多样化的主题游径，提升质量、增加数量、强化运营、挖掘内涵、打造精品，推动增城绿道建设再上新台阶，逐步将增城绿道建设成为市民休闲健身之道、旅游观光消费之道、农民增收致富之道和发展绿色生态经济之道。

三、主要建设任务

根据广州市下达我市2014年新建52公里绿道的工作任务，结合我市实际，今年规划新增建设绿道总长52.8公里，将绿道继续向公园(花园)、景区(景点)、特色乡村延伸，完善绿道网络系统，进一步发挥绿道网的生态、经济、人文综合效益。继续完成2个绿道兴奋点和一条精品线路的规划建设工作。

(一)2014年新增绿道建设任务(52.8公里)

1.正果镇建设任务(18公里)。新建兰溪、畲族旅游观光绿道，沿X293县道途径水口村、兰溪村、畲族村至琵琶园。打造山区特色旅游绿道，沿途观赏原生态自然景观，体验少数民族的别样风情。以绿道为线，串起绿道周边的村庄发展乡村游和农家乐，使得绿道不仅仅成为市民休闲健身之道，同时也发展成为观光消费之道和农民致富之道。

2.派潭镇建设任务5公里。一是党史教育基地绿道(2.5公里)，小径村路口至增城旧县政府，将绿道建设与党史教育基地连接，结合党的群众路线教育，打造一条经典的红色革命道路，提高绿道系统的文化内涵。二是上九陂村旅游观光绿道(2.5公里)，依附白水寨风景旅游区建设绿道，增加景区周边绿道配套功能，提升旅游景区的品质，带动更多乡村的饮食类和服务类产业发展，提升生态旅游经济效益。

3.仙村镇建设任务2公里。仙村乡村、花园绿道，从西南村至荔新公路至紫薇花园园区。以西南村古建筑群为依托，打造乡村特色绿道，连通花园，实现美丽乡村和花园高标准生活圈。完善紫薇花园及周边的交通系统，特别是自行车休闲绿道，此路段作为通向紫薇花园的绿道对提升紫薇花园的功能效益具有重要意义，并通过完善与之相关的配套设施和绿化景观等，提升乡村居民的居住休闲环境。

4.新塘镇建设任务4.8公里。万田花园绿道，万田花园作为新塘镇花园建设的亮点工程，与荔新公路绿道相连接，绿化与配套功能逐渐完善，园区整体地形高低错落、空间开合有置。将园区内的一级、二级、三级道路结合自然资源、人文资源等条件，规划成为多样化的绿道主题游径，比如一级绿道为彩色沥青绿道，二级为普通面砖绿道，三级为特色登山步道，增加绿道形式的多样化，丰富万田花园的主题功能和休闲娱乐方式。

5.增江街建设任务3公里。东湖公园绿道，沿东湖公园周边道路建设环绕湖区与湖区内游迳连接的绿道，发挥东湖公园的生态和休闲功能，为市民提供户外休闲健身的好去处。同时完善东湖公园周边的配套设施，增加绿化景观休闲空间，提高周边居民的居住环境，并与蕉石岭森林公园绿道相连接，形成交通畅流的绿道网络体系。

6.小楼镇、中新镇建设任务20公里(其中小楼镇7公里，中新镇13公里)。小楼约场村至中新福和圩(县道X940)绿道，结合新农村建设，因地制宜，建设休闲景观绿道，沿途穿梭多个乡村，途经冰糖桔生产基地、联安水库等，与增派绿道、中福绿道首尾相接，打造一条观赏田园风光、农副产品产业基地等特色乡村景观的生态绿道。

(二)完善2个绿道兴奋点和1条绿道精品线路

继续完善我市绿道兴奋点和精品线路的建设，构建结构合理、配套完善、交通便捷、功能丰富的绿道网络体系。

1.完善挂绿湖周边和增江画廊绿道兴奋点

一是结合广州城市副中心规划和挂绿湖水利工程建设，打造别具特色的“挂绿湖周边”绿道兴奋点;二是整合现有资源，打造“增江画廊”绿道兴奋点。依托人文、自然资源优势，以方便群众到达和使用为重点，通过完善标识、连接线等方式进行整合，充分考虑步行、骑车的合理活动半径，营造能够满足市民多种活动需求的公共开敞空间，为市民提供多样化、高质量的活动场所和运动健身、文化展示、科普教育、餐饮娱乐、休闲游憩等服务，并与市民活动、城市特色和形象展示、各类品牌等资源紧密结合，使之成为人民群众便于享用、乐于享用，且与绿道无缝衔接的人性化公共活动场所。(责任单位：荔城街、增江街，配合单位：市林业园林局、市文体旅游局、市新农办、市水务局)

2.完善增江画廊之旅绿道精品线路

由挂绿湖绿道至增江画廊绿道至增派路绿道途经挂绿湖、鹤之洲景区、荔江公园、莲塘春色、小楼人家、北回归线、白水寨景区，主要功能为假日休闲、体育健身、乡村旅游。

完善配套设施，绿道沿线包含上述兴奋点，汇集地方特色、凸显文化、旅游、科普等多种功能，集中反映绿道建设成果。(责任单位：荔城街、增江街、小楼镇、派潭镇，配合单位：市林业园林局、市文体旅游局、市新农办、市水务局)

3.提升绿道精品线路系统

(1)绿廊系统。应最大限度地保留原有植被，注重乡土植物的维护和利用及遮荫和绿色隔离功能，兼顾景观和生态效益。

(2)慢行系统。打造集步行道、自行车道于一体的综合慢行道，遵循生态影响最低限度的原则，在满足使用需求的基础上，尽量利用现有河堤、机耕路、园路、道路防护绿带等设置。

(3)服务设施系统。注重户外活动区域和驿站，根据绿道功能设置和管理维护的需要布置驿站、商业服务、游览休憩、科普教育、安全保障、环境卫生等设施。

(4)标识系统。标识要求清晰、完整、详细，式样按照全省绿道网标识《珠三角绿道网标识系统设计》执行，标识的文字、图案、规格和色彩为强制性内容，标识材质、内容设置等可结合实际自行确定。

(5)交通衔接系统。通过开辟绿道出入口、建设绿道连接线、设置交通换乘点、完善停车等措施，提高绿道的可达性。绿道精品线路要求配备自行车运营系统，并实现通借通还。

四、工作要求

(一)高度重视，狠抓落实。各责任单位要高度重视，采取有效措施，狠抓落实，全力推进项目建设，保证在5月前完成绿道规划和设计，并按工程建设的流程要求完善招标等有关手续后，迅速启动施工，确保如期完成工作任务。6月下旬市绿道办将组织对全市绿道建设工作进行现场检查;12月做好迎接广州市绿道办的检查验收。

(二)加强管理，良性发展。在建设绿道的同时，加强绿道运营管理工作，建立政府主导、属地管理的可持续发展长效机制，确保绿道功能不断拓展。要结合各个季节、各个时期的花事活动和传统节庆活动，举办以绿道为主题的各类体验活动，并通过媒体进行推介，并引进社会力量参与绿道运营，利用市场机制不断增强绿道活力。

(三)引进企业，发展产业。要推进绿道与旅游业、交通运输业、文化产业、饮食业、观光农业等关联产业的共同发展，培育一批依托绿道进行餐饮娱乐、休闲养生等的企业，开发绿道纪念品、运动装备、驿站设施、绿色植物、书籍刊物等绿道衍生的产品，形成良性循环、效益突出的绿道产业链。

(四)加强宣传，营造氛围。要建立健全绿道信息发布系统，通过编印绿道地图和指南、策划主题活动、发布绿道公益宣传片等多种形式，加大宣传推介力度，提高市民群众和游客使用和保护绿道的积极性，同时做好绿道建设使用绩效评价，使绿道成为传播和发扬岭南文化进而提升市民生活指数、幸福指数的重要载体。

五、保障措施

(一)组织保障。为加强对全市绿道建设工作，调整完善增城市绿道建设工作领导小组，由市政府分管副市长任组长，市林业园林局局长任副组长，成员由市委宣传部、市财政局、市交通运输局、市城乡建设局、市水务局、市文体旅游局、市城乡规划局、市新农办以及各镇街分管领导组成。领导小组下设办公室(简称市绿道办)，办公室主任由市林业园林局局长兼任。各成员单位要结合各自职能，各司其职，各负其责，形成工作合力，确保如期完成广州市下达的绿道网建设任务。

(二)资金保障。各责任单位根据市相关资金安排进行包干，按照基本建设项目要求管好项目，确保资金安全和高效使用。要充分发挥主观能动性，实现绿道建设资金多元化投入。

(三)机制保障。坚持政府指导、市场运作的绿道建设管理机制。市绿道办制订规划、计划、建设标准和技术指引，充分整合农、林、水等财政资金，将绿道建设与公园(花园)、景区(景点)、农田标准化、林网、水利等项目建设相结合，发挥资金的综合效益。

(四)监督保障。由市绿道办负责对各责任单位的工作进行日常监督检查，检查内容分为工程进度、工程质量、组织管理和配套设施。请各责任单位每月20日前向市绿道办上报月进度表。年底，市绿道办将组织有关部门，对建设工作进行全面检查。
