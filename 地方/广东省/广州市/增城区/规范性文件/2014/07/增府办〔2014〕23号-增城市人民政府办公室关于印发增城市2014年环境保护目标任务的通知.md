# 增城市人民政府办公室关于印发增城市2014年环境保护目标任务的通知

增府办〔2014〕23号

各镇政府、街道办事处，市府直属有关单位：

《增城市2014年环境保护目标任务》已经市人民政府同意，现印发给你们，请认真贯彻执行。在执行过程中遇到的问题，请径向市环保局反映。

增城市人民政府办公室

2014年6月26日

增城市2014年环境保护目标任务

根据广州市人民政府下达我市2014年环境保护目标，结合我市实际，下达对各镇街和相关职能部门的环境保护目标任务。实施环境保护目标任务的单位包括各镇街、市环保局、市科经信局、市公安局、市城乡建设局、市城管执法局、市交通运输局、市水务局、市农业局、市卫生局、市林业园林局、市国土房管局、市城乡规划局、市安监局、市工商局和市质监局共26个单位。

一、年度总体目标

环境空气质量达到《环境空气质量标准》(GB3095-2012)二级标准天数比例同比提高1个百分点，力争细颗粒物(PM2.5)年平均浓度下降5%、可吸入颗粒物(PM10)控制在70微克/立方米以下、二氧化氮(NO2)下降4微克/立方米以上;城市集中式饮用水源地水质达标率保持100%，乡镇饮用水源地水质达标率达60%以上;东江北干流(石龙桥、增江口、西福河口、大墩、新塘、曲夫涌口、旺隆热电码头断面)、增江(莲塘、化肥厂、陆村断面)水质保持达到地表水环境功能区划要求，永和河水质稳定向好;生活污水集中处理率达90%以上;生活垃圾无害化处理率达90%以上;污水处理厂污泥无害化处理率达100%;危险废物(含医疗废物)处理处置率达100%。

二、各镇街年度重点任务

(一)大气污染综合防治

1.认真落实广州市大气污染防治工作方案，按要求做好相关工作。

2.2014年6月底前配合划定高污染燃料禁燃区并大力推进禁燃区建设，组织开展“无煤街道”、“无煤社区”、“无煤村”、“无煤工业园区”创建工作;制定2015年前完成燃煤、燃重油锅炉淘汰或改燃清洁能源工作计划，并确保2014年底前完成广州市及我市分解的在用燃煤、燃重油锅炉淘汰或改燃任务。

3.落实扬尘污染控制属地监管制度，建立辖内扬尘污染控制部门联动机制，建立市、镇(街)、有关施工建设单位三级扬尘控制管理档案;定期组织对本辖区内的各类扬尘污染源尤其是空气质量发布监测点周边扬尘污染源进行检查，每月组织开展对工地扬尘控制措施落实情况的监督巡查，确保每个施工工地每月至少检查1次并做好详细记录，发现问题及时督促整改;加大对建筑施工扬尘申报及治理等方面的宣传，辖内工地扬尘污染投诉率同比下降;2014年底前辖区内经营性露天停车场60%实施硬底化。

4.配合做好加油站、储油库油气排放监督管理工作，每半年开展一次监督检查，对超标排放、擅自停用油气回收治理设施等违法排污行为依法查处，完善日常管理机制。

5.2014年底前，建立辖内挥发性有机物排放源清单;抓好重点区域、行业、示范企业挥发性有机物污染防控;2014年底前基本完成化工企业储罐区油气回收治理，配合开展油气回收在线监控系统建设。

6.贯彻落实《广州市餐饮场所污染防治管理办法》和《广州市人民政府办公厅关于全面推进餐饮业环境管理进一步强化污染综合整治的意见》;2014年6月底前，全面完成通过环保审批和验收的中型餐饮业户(75餐位以上250餐位以下)餐饮业排污许可证核发;所有通过环保审批的产生油烟废气的餐饮业户按照规定安装油烟高效净化设施，城镇中心区、环境敏感区域且油烟超标排放3次以上的中型(75餐位)以上餐饮服务单位100%安装油烟净化设施在线监控装置，位于环境敏感区域且油烟超标排放3次以上的大型餐饮业户应当安装油烟在线监测设施;对油烟超标排放3次以上的中型以上饮食服务业单位实施治理设施委托运营;已建饮食服务业户2014年底前完成清洁能源改造。

7.建立未稳定达标排污企业名单，并每季度更新。

(二)水环境整治

8.按照《广州市实施〈南粤水更清行动计划〉工作方案》及年度计划要求，全面推进9个方面46项水环境综合整治工作;深入排查永和河、增江河、西福河相应河段所属镇街河流(段)的集雨范围和纳污范围内的污染源情况，6月底前完成“一涌一册”，落实环境监管责任，每季度开展巡查，严查违法排污行为，并更新“一涌一册”。

9.做好辖区镇级饮用水水源水质保护工作，确保水质好转，达标率提高;按照广州市乡镇集中式饮用水水源保护区划分技术要求，对水质较差、供水规模较小的小型村镇级集中式饮用水源地，年内要启动饮用水源地优化整合工作，确保2015年底前完成。

10.全面排查辖区内饮用水源保护区，7月底前完成“一源一册”建档工作并每季度更新;清理保护区内各类排污口，依法拆除一级保护区内与保护水源无关的建设项目;新塘镇、荔城街、增江街牵头联合市水务局、市环保局年底前完成饮用水源一级保护区物理围网隔离设施工程。

11.完善饮用水源污染事故应急机制。加强环境安全隐患排查，对饮用水水源保护区内的企业及风险源登记造册;及时处置突发环境事件，并按有关规定上报相关情况。

(三)声环境治理

12.加强噪声污染防治工作，大力整治商业、广场噪声等社会生活噪声，强化对道路交通、建筑工地夜间施工和饮食娱乐服务业等噪声污染的监管，对辖内噪声污染投诉及时进行处理。

(四)辐射与固体废物管理。

13.加强辖区辐射环境安全与防护监督管理，监督生产、销售、使用放射性同位素和射线装置单位及时申领或延续(换发)《辐射安全许可证》，配合开展建设项目竣工环保验收;核技术利用单位安全与防护状况年度评估、废旧放射源收贮率均达100%;配合开展专项执法检查，重点对使用Ⅳ、Ⅴ类放射源的电子标签巡检，巡检率达100%，确保无因监管不力导致的辐射环境事故发生。

14.进一步加强辖区内生活污水处理厂污泥处置的监管，督促企业将污泥交给持有严控废物处理许可证的单位进行处置，严格落实污泥转移联单管理制度。

15.加强辖区固体废物污染防治工作，对纳入监管重点源名单的危险废物产生和经营单位年检查率不低于30%，确保无因监管不力而导致固体废物污染环境事故发生。

16.及时收集、清运、中转生活垃圾，密闭收集运输，辖区内无明显生活垃圾堆放和私自焚烧现象;辖内每个自然村至少建成一个以上生活垃圾密闭收集点，有效收集农村垃圾。

(五)主要污染物总量减排

17.按照市政府下达的年度总量减排任务要求，抓好工程减排、结构减排、监管减排，推进辖区内再生水回用工作，实现本辖区2014年主要污染物总量削减目标。

18.加快推进已建污水处理厂的稳定运行;完善配套污水收集管网，提高辖区生活污水收集率和处理率，力争已建成的污水处理厂达到与设计相匹配的污水处理规模;对已建污水管网缺失的区域或漏接、局部未连通、与生活小区等重点污染源不衔接的管道进行“查漏补缺”，提高原有管网的污水收集能力，提高污水处理厂处理水量和进水浓度;加快乡镇级污水治理设施以及截污管网的建设。

(六)重金属污染防治

19.配合做好重金属污染综合防治“十二五”规划实施考核的各项工作。按计划推进污染源综合整治、落后产能淘汰和清洁生产审核等重点项目实施，积极配合完善更新重金属减排台账强化安全监管和达标治理。

(七)农业源污染防治

20.按照《畜禽规模养殖污染防治条例》(国务院令第643号)有关要求，推进养殖场污染治理设施规范化，加强巡查，保持清拆的“散小乱”猪场的成果。

21.强化露天焚烧监管。建立市、镇(街)、村三级秸秆焚烧监管责任体系，及时处理重点区域露天焚烧行为，每季度通报;建立秸秆综合利用示范点;加强禁止农作物秸秆、城市清扫废物、园林废物、建筑废弃物等生物质露天焚烧行为的宣传教育;禁止以露天焚烧方式回收金属。

(八)挂牌督办

22.认真落实2014年国家、省、广州市环保挂牌督办工作，确保按期完成督办任务。

(九)环境管理与监管

23.加强建设项目环境管理，严格执行环境影响评价制度和“三同时”制度，执行率达100%;严格大气污染物排放项目环保审批，新建排放二氧化硫、氮氧化物、工业烟(粉)尘、挥发性有机物的项目实行区域内现役源2倍削减量替代。

24.贯彻落实《广东省排污许可证管理办法》(省政府令199号)，依法推进企业申领排污许可证工作;监督持证企业废水、脱硫、脱硝、除尘等污染治理设施100%正常运行，重点工业企业污染排放稳定达标;继续督促辖区内工业园外漂染企业落实入园及集中污水处理工作;推进污染源在线监控建设，督促国控、省控、20蒸吨/小时以上锅炉企业应安装主要污染物在线监测系统，并与环保部门联网。

25.加大信息公开力度。督促辖区内国控企业按照《国家重点监控企业自行监测及信息公开办法(试行)》要求，做好自行监测及信息公开工作;对不达标企业督促限期整改、达标排污。

26.按照国家、省、广州市的要求，积极配合开展整治违法排污企业保障群众健康环保专项行动，贯彻落实“两高”环境污染犯罪司法解释，配合开展大气、水源保护、重金属等方面的专项行动，严厉处罚违法行为，对情节恶劣的予以曝光。

27.及时办理群众反映的污染投诉问题，按期办结率达95%，重复信访量控制在25%以内。

28.完成本辖区重点企业清洁生产年度审核计划。

29.积极配合推进环境污染责任保险试点工作。

三、市环保局环保目标任务

(一)组织落实广州市大气污染防治工作方案，按要求做好相关工作。

(二) 2014年6月底前牵头划定高污染燃料禁燃区并大力推进禁燃区建设，组织开展“无煤街道”、“无煤社区”、“无煤工业园区”创建工作;制定我市2015年前完成燃煤、燃重油锅炉淘汰或改燃清洁能源工作计划，并确保2014年底前完成285台在用燃煤、燃重油锅炉淘汰或改燃工作;督促增城经济技术开发区、新塘环保工业园集中供热改造，确保2015年底前完成。

(三)做好营运车辆排气污染防治工作，制定年度计划，联合公安交警部门做好机动车排气污染道路抽检执法工作，严格控制排气超标车辆在辖区内道路行驶。

(四)按照《广州市建设工程文明施工管理规定》和《关于加强建筑工地扬尘污染控制管理的紧急通知》等制度要求，更新快速监测技术手段，建立辖内扬尘污染控制部门联动机制;定期组织对各类扬尘污染源尤其是空气质量发布监测点周边扬尘污染源进行检查。

(五)做好加油站、储油库油气排放监督管理工作，每半年开展一次监督检查，每年进行一次监督性监测，对超标排放、擅自停用油气回收治理设施等违法排污行为依法查处，结合排污许可证核发工作，完善日常管理机制;探索开展加油站、储油库油气回收在线监控系统建设工作。

(六)2014年底前，建立辖内挥发性有机物排放源清单;抓好重点区域、行业、示范企业挥发性有机物污染防控，至少建立2个治理示范工程;2014年底前基本完成化工企业储罐区油气回收治理，并开展油气回收在线监控系统建设;逐步开展新塘港区、增城港区原油、成品油码头的油气回收治理试点。

(七)贯彻落实《广州市餐饮场所污染防治管理办法》和《广州市人民政府办公厅关于全面推进餐饮业环境管理进一步强化污染综合整治的意见》;2014年6月底前，全面完成通过环保审批和验收的中型餐饮业户(75餐位以上250餐位以下)餐饮业排污许可证核发;所有通过环保审批的产生油烟废气的餐饮业户按照规定安装油烟高效净化设施，城镇中心区、环境敏感区域且油烟超标排放3次以上的中型(75餐位)以上餐饮服务单位100%安装油烟净化设施在线监控装置，位于环境敏感区域且油烟超标排放3次以上的大型餐饮业户应当安装油烟在线监测设施;对油烟超标排放3次以上的中型以上饮食服务业单位实施治理设施委托运营;已建饮食服务业户2014年底前完成清洁能源改造。

(八)建立未稳定达标排污企业名单，并每季度更新。

(九)按照《广州市实施〈南粤水更清行动计划〉工作方案》及年度计划要求，全面推进9个方面46项水环境综合整治工作;深入排查永和河、增江河、西福河集雨范围和纳污范围内的污染源情况，6月底前完成“一涌一册”，落实环境监管责任，每季度开展巡查，严查违法排污行为，并更新“一涌一册”。

(十)加快推进饮用水水源一级保护区物理围网建设工作，制定切实可行的工作方案，2014年底前配合新塘镇、荔城街、增江街和水务局完成我市新塘水厂、新和水厂、荔城水厂一级保护区物理隔离设施工程。

(十一)做好正果镇水厂、沙埔水厂、仙村水厂、新和水厂、清源水厂、派潭水厂、小楼水厂、福和水厂、沙庄水厂、朱村水厂、三江水厂、白水寨水厂等12个乡镇级饮用水水源及百花林水库水质保护工作，确保水质好转，达标率提高;按照广州市乡镇集中式饮用水水源保护区划分技术要求，对水质较差、供水规模较小的小型镇级集中式饮用水源地，年内要启动饮用水源地优化整合工作，确保2015年底前完成。

(十二)全面排查荔城水厂、新和水厂、新塘水厂等饮用水源保护区，7月底前完成“一源一册”建档工作并每季度更新;清理保护区内各类排污口，依法拆除一级保护区内与保护水源无关的建设项目。

(十三)完善饮用水源污染事故应急机制。加强环境安全隐患排查，对饮用水水源保护区内的企业及风险源登记造册;及时处置突发环境事件，并按有关规定上报相关情况。

(十四)加强噪声污染防治工作，联合公安、城乡建设和城市管理等部门大力整治商业、广场噪声等社会生活噪声，强化对道路交通、建筑工地夜间施工和饮食娱乐服务业等噪声污染的监管，对辖内噪声污染投诉及时进行处理。
