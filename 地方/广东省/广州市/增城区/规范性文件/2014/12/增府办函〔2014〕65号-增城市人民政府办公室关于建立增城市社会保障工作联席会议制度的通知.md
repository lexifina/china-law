# 增城市人民政府办公室关于建立增城市社会保障工作联席会议制度的通知

增府办函〔2014〕65号

各镇政府、街道办事处，市政府各部门、各直属机构：

为进一步加强我市社会保障工作的组织领导和统筹协调，经市人民政府同意，建立增城市社会保障工作联席会议制度。现就有关事项通知如下：

一、主要职能

按照广州市委、市政府关于广州市社会保障工作的总体部署和工作要求，统筹推进我市社会保障工作的开展;研究执行社会保障有关政策和措施;协调解决社会保障工作中的重大问题;促进相关部门的工作联动和业务协同;指导、督促和检查社会保障有关政策文件的执行和工作任务的落实情况。

二、组成人员

总召集人：罗思源(市政府)

常务召集人：徐明曦(市政府)

召 集 人：许志忠(市人社局)
