# 关于征集2020年区政府十件民生实事的启事

为了更好地关注民生、服务群众，使我区2020年民生实事更好地体现广大人民群众的愿望和要求，现公开向社会征集2020年区政府十件民生实事建议。各公民、法人可将关系国计民生及人民群众利益或惠及城乡群众的事项，在征集时间内按要求填写并通过邮寄、传真、电子邮件等形式反馈至广州市增城区人民政府办公室，经筛选后，将形成2020年政府十件民生实事。欢迎踊跃参与，积极建言献策。

一、征集时间

2019年9月2日—10月8日。

二、征集事项范围

（一）群众基本生活：如涉及食品安全、企业安全生产、住房保障、交通出行、社会治安、公共安全、扶残助残、社会管理、家政服务等方面的事项；

（二）社会事业类：如涉及教育、医疗、就业、社保等方面的事项；

（三）人居环境类：如涉及住房、城市管理、绿化、环保、社区建设、美丽乡村建设等方面的事项；

（四）其他直接涉及群众切身利益的事项。

三、征集事项要求

（一）实效性：“十件民生实事”为年度性即原则上在2020年内可以完成的任务；

（二）可操作性：理由依据明确，实施方式合法合情合理；

（三）普惠性和广泛性：应解决广大群众广泛关注的问题或与日常生产生活密切相关又亟待解决的民生事项。

四、数量要求

公民或法人可选取一件或多件事项报送，事项原则上不超过10件。
