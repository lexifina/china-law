# 关于天河区政府行政规范性文件清理结果的通知

各街道办事处，区府直属各单位：

根据《广州市行政规范性文件管理规定》（市政府令第52号）及《印发〈广州市天河区行政规范性文件审查、评估和清理暂行办法〉的通知》（穗天府〔2010〕35号），天河区人民政府对《关于天河区政府行政规范性文件清理结果的通知》（穗天府〔2010〕6号）中予以保留的行政规范性文件进行了评估清理，现将有关事项通知如下:

一、可继续实施的区政府行政规范性文件2件（详见附件1）；可继续实施的部门行政规范性文件1件（详见附件2）。上述行政规范性文件有效期延长至2016年12月31日，有效期届满后根据实际情况评估修订。

二、修改区政府行政规范性文件3件（详见附件3），修改工作由附件3所标明的部门分别牵头负责；修改部门行政规范性文件1件（详见附件4），由附件4所标明的发布部门分别负责修改并报区法制办前置审查后予以发布。上述行政规范性文件应自本通知印发之日起6个月内完成修改，逾期未完成修改的，该行政规范性文件停止执行。

三、废止（含自动失效）区政府行政规范性文件8件（详见附件5）；废止（含自动失效）部门行政规范性文件19件（详见附件6）。

附件：1.《可继续实施的区政府行政规范性文件目录》

2.《可继续实施的部门行政规范性文件目录》

3.《天河区政府行政规范性文件修改目录》

4.《部门行政规范性文件修改目录》

5.《天河区政府行政规范性文件废止目录》

6.《部门行政规范性文件废止目录》
