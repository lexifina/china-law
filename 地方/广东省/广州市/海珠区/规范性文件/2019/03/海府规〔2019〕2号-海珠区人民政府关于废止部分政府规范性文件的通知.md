# 海珠区人民政府关于废止部分政府规范性文件的通知

各街道、区政府各部门、各直属机构：

为深入贯彻落实新发展理念，建立简明高效的产业促进政策体系，经区政府审议通过，决定废止《广州市海珠区企业上市促进计划工作实施意见》（海府〔2014〕12号）等9份规范性文件。

特此通知。
