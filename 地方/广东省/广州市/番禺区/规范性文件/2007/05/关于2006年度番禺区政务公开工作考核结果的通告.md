# 关于2006年度番禺区政务公开工作考核结果的通告

( )

根据《印发2006年度番禺区政务公开工作考核方案的通知》（番府办〔2006〕83号）的要求，我区2006年度政务公开考核工作经过自评、抽检、评议和公示四个阶段，按照考核内容和考核标准对考核范围内的镇、街及区府直属单位的政务公开工作进行了评分，最终考核等级意见报经区政府批准，现将考核结果进行公布，具体详见《2006年度番禺区政务公开工作考核结果》。

特此通告。
