# 关于增补江奉新、卢树辉同志为番禺区社会信用体系和市场监管体系建设工作领导小组成员的通知

( )

各镇政府、街道办事处，广州大学城管委会、广州南站地区管委会，区府直属各单位：

经区政府研究，决定增补江奉新（区发改局）、卢树辉（区政务办）同志为番禺区社会信用体系和市场监管体系建设工作领导小组成员，江奉新同志兼任领导小组办公室副主任。

广州市番禺区人民政府

二〇一二年十一月六日
