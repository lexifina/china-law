# 关于成立番禺区集体土地确权登记发证工作领导小组的通知

( )

各镇政府、街道办事处，广州大学城管委会、广州南站地区管委会，区府直属各单位：

为加快推进我区集体土地确权登记发证工作，经区政府同意，决定成立番禺区集体土地确权登记发证工作领导小组。领导小组成员名单如下：

组长：戴友华

副组长：叶硕榆（区政府办）、杨瑞勇（区国土房管分局）、李伟贤（区农业局）

成员：李迎春（区政府办、区法制办）、许晨辉（区国土房管分局）、叶文（区城市管理局）、陈志明（区财政局）、梁绮华（区民政局）、江健东（区水务局）、许文（区城改办）、伍建华（沙湾镇）、徐林发（石碁镇）、石伟文（新造镇）、卢炎安（南村镇）、何志明（化龙镇）、曾富强（石楼镇）、麦旺发（东涌镇）、黄伟刚（榄核镇）、刘长欢（大岗镇）、金丹华（市桥街）、梁健辉（沙头街）、潘立强（东环街）、何锡波（桥南街）、罗敏峰（小谷围街）、陈永坚（大石街）、冯福贤（洛浦街）、郭带泉（钟村街）、朱瑞武（石壁街）、李伟成（大龙街）

导小组办公室设在区国土房管分局内，办公室主任由许晨辉同志兼任。

广州市番禺区人民政府办公室

二○一二年四月二十七日
