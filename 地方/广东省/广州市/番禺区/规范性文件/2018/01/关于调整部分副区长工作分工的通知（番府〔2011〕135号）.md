# 关于调整部分副区长工作分工的通知（番府〔2011〕135号）

( )

各镇政府、街道办事处，广州南站地区管委会、广州大学城管委会，区府直属各单位：

因工作需要，经区政府党组会议研究决定，我区部分副区长的工作分工调整如下：

黎伟棠副区长增加分管食品药品监督管理工作，张力仁副区长不再分管该项工作。

其他区政府领导的工作分工不变。

广州市番禺区人民政府

二○一一年六月七日
