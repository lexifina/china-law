# 印发广州市番禺区妇女发展规划（2011—2020年）和广州市番禺区儿童发展规划（2011—2020年）的通知

( )

各镇政府、街道办事处，广州大学城管委会、广州南站地区管委会，区府直属各单位：

《广州市番禺区妇女发展规划（2011—2020年）》和《广州市番禺区儿童发展规划（2011—2020年）》业经区政府常务会议审议通过，现印发给你们，请认真组织实施。实施中遇到的问题，请径向区妇女儿童工作委员会反映。

广州市番禺区人民政府
