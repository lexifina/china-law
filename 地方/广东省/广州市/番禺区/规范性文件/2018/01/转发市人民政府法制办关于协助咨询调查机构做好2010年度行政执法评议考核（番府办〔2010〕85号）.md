# 转发市人民政府法制办关于协助咨询调查机构做好2010年度行政执法评议考核（番府办〔2010〕85号）

( )

各镇政府、街道办事处，广州南站地区管委会、广州大学城管委会，区府直属各单位：

现将市人民政府法制办《关于协助咨询调查机构做好2010年度行政执法评议考核征求意见工作的通知》（穗府法〔2010〕60号）转发给你们，结合我区实际，提出如下意见，请一并贯彻执行。

一、高度重视，认真对待。各级单位要高度重视咨询调查机构对各区县政府、市属部门2010年度行政执法情况的社会公众意见征询工作，树立高度的政治意识和大局观念，切实加强本单位办公场所、办事大厅、执法现场或其他地点的政风行风建设，以一流的组织管理、一流的城市环境、一流的服务水平、一流的社会风尚迎接咨询调查机构对我区2010年度行政执法情况的社会公众意见征询工作。

二、突出重点，注重方法。各级各单位要结合单位工作实际，重点对窗口服务单位和行业公共服务单位的服务意识、服务态度、服务效率、服务质量等方面进行排查，针对苗头性问题和薄弱环节，加大暗访督查力度。要建立健全应急处理机制，及时化解矛盾和纠纷，减少社会负面影响。

三、督促整改，务求实效。对前阶段区纪检监察、纠风部门开展“迎亚运树新风”政风行风专项检查工作中发现的问题及时进行整改，营造我区良好的政务环境和行业服务环境。

广州市番禺区人民政府办公室

二○一○年十二月二日
