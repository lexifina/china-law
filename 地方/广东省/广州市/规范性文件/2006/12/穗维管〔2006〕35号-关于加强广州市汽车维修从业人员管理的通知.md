# 关于加强广州市汽车维修从业人员管理的通知

各区（县级市）维管办，市汽车维修协会，各汽车维修企业和综合性能检测站：

为进一步加强我市汽车维修从业人员管理工作，提高维修从业人员综合素质，确保车辆维修质量，根据《汽车维修业开业条件》、《机动车维修管理规定》、《道路运输从业人员管理规定》、《机动车维修技术人员从业资格考试大纲》及相关法律法规和技术标准的规定，结合我市实际情况，现将加强我市汽车维修从业人员管理的有关事项通知如下：

一、指导思想和工作目标

以邓小平理论和“三个代表”重要思想为指导，以科学发展观促进汽车维修行业发展为工作思路，坚持“政府规范行业，企业管理人员”的原则，利用信息化管理手段，建立维修从业人员技术档案资料库和汽车维修从业人员考试管理制度，用三年时间通过维修从业人员考试，使维修从业人员管理规范、流动有序、整体素质得到提高。

二、汽车维修从业人员分类

汽车维修从业人员分为技术负责人、质量检验员和机修、电器维修、钣金（车身修复）、涂漆（车身涂装）、车辆技术评估（含检测）等人员（指关键岗位）和学徒工岗位。

三、汽车维修从业人员的任职资格

（一）汽车维修技术负责人

1.具有汽车维修或相关专业大专以上（含大专）学历，或具有汽车维修或相关专业的工程师或技师以上专业技术职称。

2.熟悉汽车维修业务，并掌握汽车维修及相关政策法规和技术规范。

（二）汽车维修质量检验员

1.应具备高中以上学历，且具有达到汽车维修工中级技术等级证书，总检验员达到汽车维修工高级技术等级证书。

2.熟悉汽车维修检测作业规范，掌握汽车维修故障诊断和质量检验的相关技术，熟悉汽车维修服务收费标准及相关政策法规和技术规范。

（三）从事机修、电器、钣金、涂漆、车辆技术评估（检测）作业的技术人员

1. 具有初中以上（含初中）学历。

2. 熟悉所从事工种的维修技术和操作规范，并了解机动车维修及相关政策法规。

（四）学徒工岗位

1. 具有初中以上（含初中）学历。

2. 了解汽车维修技术、操作规范及相关政策法规。

四、汽车维修从业人员岗位职责

（一）汽车维修技术负责人

1. 执行国家、地方和行业相关法律、法规、规章、标准和规范。

2. 负责建立和实施企业机动车维修质量保证体系，对质量保证体系进行监控和修订。

3. 负责制定企业各项技术质量管理制度和工艺文件，并组织实施、检查和修订。

4. 负责企业日常技术管理工作，对机动车维修质量负责，组织解决机动车维修中出现的疑难技术问题，对机动车维修质量事故和质量纠纷提出处理意见和改进措施。

5. 负责制定本企业技术开发、技术改造、技术革新方案并组织实施，对技术成果组织推广运用。

6. 负责制定和实施技术培训计划，对机动车维修的新技术、新工艺、新设备、新材料进行培训。

7. 规范经营行为，贯彻执行机动车维修工时定额和收费标准。

（二）机动车维修质量检验员

1. 执行国家、地方及行业相关机动车维修的法律、法规、规章、标准和规范。

2. 负责机动车维修进厂检验，确定维修项目，填写进厂检验单。

3. 负责机动车维修过程的质量监控，填写过程检验单，并指导维修人员对维修车辆的故障进行深入诊断。

4. 负责机动车维修竣工出厂检验，填写维修竣工出厂检验单，签发维修竣工出厂合格证。

5. 协助技术负责人分析处理质量事故和纠纷，提出改进和预防措施，并组织实施。

6. 配合业务员完成机动车或总成维修进厂和竣工出厂的交接工作。

7. 负责对机动车配件的质量进行监控。

8. 负责指导和培训相关人员对机动车维修质量进行检验。

9. 正确执行机动车维修工时定额和收费标准。

（三）机修人员

1. 执行与本岗位相关的法规、规章、标准和规范。

2. 从事发动机、底盘及其控制系统的检测诊断和维修作业。

3. 在生产过程中执行安全操作规程，按工艺规范正确完成发动机、底盘及其控制系统的维修作业。

4. 协助质量检验员工作，对机修质量负责。

5. 指导和培训本岗位其他人员的技术操作。

6. 配合协调其他岗位的工作。

7. 负责本岗位技术问题的收集、整理和上报。

8. 负责本岗位的现场管理。

（四）电器维修人员

1. 负责机动车电器系统的检测诊断和维修作业。

2. 在生产过程中执行安全操作规程，按工艺规范正确完成机动车电器系统的维修作业。

3. 协助质量检验员工作，对机动车电器维修质量负责。

4. 指导和培训本岗位其他人员的技术操作。

5. 配合协调其他岗位的工作。

6. 负责本岗位技术问题的收集、整理和上报。

7. 负责本岗位的现场管理。

（五）钣金（车身修复）人员

1. 负责制定合理的车身修复工艺方案。

2. 从事车身修复作业。

3. 配合协调其他岗位的工作。

4. 指导和培训本岗位其他人员的技术操作。

5. 协助质量检验员工作，对车身修复质量负责。

6. 负责本岗位技术问题的收集、整理和上报。

7. 负责本岗位的现场管理。

（六）涂漆（车身涂装）人员

1. 负责制定合理的车身涂装工艺方案。

2. 从事车身涂装作业。

3. 配合协调其他岗位的工作。

4. 指导和培训本岗位其他人员的技术操作。

5. 协助质量检验员工作，对车身涂装质量负责。

6. 负责本岗位技术问题的收集、整理和上报。

7. 负责本岗位的现场管理。

（七）车辆评估（检测）人员

1. 执行国家、地方和行业相关法律、法规、规章、标准和规范。

2. 负责实施车辆技术评估检测，对检测的车辆作出检测鉴定。

3. 对检测有疑问的车辆进行抽检测试或复检，严格检测标准，对发生的检测质量问题及时处理解决。

4. 协助质量负责人做好检测人员的技术培训，提高业务水平，严格执行国家检测标准，把好质量关。

（八）学徒工

1. 在各岗位技术人员指导下从事车辆维修工作。

2. 协助配合各岗位技术人员跟踪检查维修过程、维修进度和维修质量。

五、汽车维修企业维修从业人员配备要求

（一）一、二类汽车整车维修企业应配备下列人员：

1. 企业管理负责人和技术负责人（均至少1人）；

2. 质量检验员（均至少1名总检验员，一类企业至少2名检验员，二类企业至少1名检验员）；

3. 业务员和价格核算员（均至少1人）；

4. 技术人员总人数：一类汽车整车维修企业不得少于20人，二类汽车整车维修企业不得少于10人。

（二）汽车专项维修业户的人员配备要求：

1. 汽车发动机维修业户应配备企业管理负责人和技术负责人至少1人，质量检验员至少2人，主修工人至少2人；

2. 车身、电气系统、自动变速器维修业户应配备企业管理负责人和技术负责人至少1人，质量检验员至少1人，主修工人至少2人；

3. 车身清洁维护业户主修工人至少2人；

4. 涂漆、轮胎动平衡及修补、四轮定位检测调整、供油系统维护及油品更换、喷油泵和喷油器维修、曲轴修磨、气缸镗磨、散热器（水箱）、空调维修、汽车装璜（蓬布、座垫及内装饰）、门窗玻璃安装业户主修工人至少1人。

（三）技术工人可持多个从业资格证上岗，但只能从事1－2个工种。

六、汽车维修从业人员考试制度

（一）考试对象为全市从事汽车维修的从业人员，考试合格者由市维管处发放《中华人民共和国道路运输从业人员从业资格证》。

从业资格证有效期6年，市维管处将加强对汽车维修从业人员的管理，进行有关法律、法规、规章和职业道德的培训，定期组织学习业务知识和技能，定期组织汽车维修从业考试工作。

（二）考核内容参照《中华人民共和国机动车维修技术人员从业资格考试大纲》建立试题库。

（三）考试形式采取计算机考试系统，分理论考试和技能考核两种形式，单项考试成绩一年内有效。

学徒工只参加技能考核，无需参加理论考核，学徒工从业资格证有效期为3年。

（四）考试时间安排

2007年上半年对市属一、二类汽车维修企业技术负责人和质量检验员组织进行考试，下半年对全市一、二类汽车维修企业技术负责人和质量检验员组织进行考试。

2008年在07年基础上，开展市属专项维修企业各类工种人员组织考试工作。

2009年对全市所有维修从业人员组织考试工作。

七、汽车维修从业人员的准入管理

（一）从事汽车维修的从业人员应参加行业主管部门组织的定期考试并考试合格。申请参加汽车维修从业人员从业资格考试的，应向市维管处提出申请，填写《广州市汽车维修从业人员从业资格考试申请表》，并提供下列材料：

1. 身份证明及复印件；

2. 学历证明及复印件，申请参加技术负责人员从业资格考试的，也可以提供技术职称证明及复印件；

申请质量检验人员从业资格考试的，还应当同时提供机动车驾驶证及复印件和维修技术工作经历证明。

（二）汽车维修企业只能录用通过考试合格的汽车维修从业人员。

汽车维修企业不按规定配备从业人员或录用考试不合格的汽车维修从业人员，按《道路运输行政处罚规定》第十七条第（一）款规定处罚。

八、汽车维修从业人员的退出管理

对经考试合格的汽车维修从业人员，有下列情形的，吊销其从业资格证件：

（一）发生重大汽车维修质量及安全责任事故；

（二）经维修行业管理部门认定，在连续12个月内发生3次违法违规行为的；

（三）不按规定进行资料变更手续及不按规定进行证件年度审验工作的。

九、维修从业人员的流动管理

管理部门采取必要措施确保汽车维修从业人员有序流动，遏制无序流动，避免人才恶性竞争。

（一）技术负责人、质量检验员和中高级技工流动，经本人申请，原用人单位和新用人单位双方在《广州市汽车维修从业人员从业资格证件换发、补发、变更登记表》签注意见，送市维修协会加注意见，报管理部门审批。

（二）其他汽车维修企业从业人员流动，由原用人单位开具介绍信到维修协会备案，填写《登记表》变更新证。

十、工作要求

（一）各级维管部门要根据属地管理原则，加强对汽车维修从业人员的管理，监督汽车维修一、二类和专项维修企业按规定配齐维修从业人员。

（二）市维管处建立汽车维修从业人员管理信息系统，各企业须通过系统上报维修从业人员基本情况、考试达标情况、人员流动情况等从业人员资料。市维修协会应建立维修从业人员档案库。

（三）机动车维修从业人员应当按照维修规范和程序作业，不得擅自扩大维修项目，不得使用假冒伪劣配件，不得擅自改装机动车，不得承修已报废的机动车，不得利用配件拼装机动车。
