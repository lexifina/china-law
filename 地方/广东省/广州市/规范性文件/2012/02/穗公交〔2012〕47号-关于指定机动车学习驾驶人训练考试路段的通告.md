# 关于指定机动车学习驾驶人训练考试路段的通告

根据《中华人民共和国道路交通安全法实施条例》、《机动车驾驶证申领和使用规定》以及《广东省道路交通安全条例》等有关规定，为保障道路交通安全和畅通，现将指定的机动车学习驾驶人训练和考试路段通告如下：

一、训练路段

（一）市中心区：

1.广汕公路段（大观路口至福和路口），训练时间：9：00—16：30，20：00-次日6：00；

2.龙溪大道段（东漖大桥底西侧调头位至五丫口大桥底东侧调头位），训练时间：9：00—16：30，20：00-次日6：00；

3.南洲路段（大沙新村南街口至瀛洲路口），训练时间：9：00—16：30，20：00-次日6：00；

4.新广从公路段（东平路口至福龙路口），训练时间：9：00—16：30，20：00-次日6：00；

5.省道116线段（广汕公路口至大源北路口），训练时间：9：00—16：30。

（二）花都区：省道114线和县道284线段（省道114线将军潭段起，经省道114线县道284线路口，至县道284线皇母山段），训练时间：全天（考试时间除外）。

（三）番禺区：

1.市良路段（沙湾教考场至古坝环形岛），训练时间：全天；

2.市鱼路段（鱼窝头太石路口至天益村口），训练时间：全天；

3.浮莲路段（浮莲路亚运大道路口至石化公路官桥村段官桥牌坊），训练时间：全天。

（四）从化市：明珠大道（省道355线路口至左村路口），训练时间：全天。

（五）增城市：增滩路段（教考场路口至仙塘村口），训练时间：8：30-20：00。

二、考试路段

（一）市中心区：

1.广汕公路段（华南快速干线跨线桥底至班岭村路口）；

2.大观路和华观路段（大观路广汕路口起，经大观华观路口至华观路凌塘村口）。

（二）花都区：省道114线和县道284线段（省道114线将军潭段起，经省道114线县道284线路口，至县道284线皇母山段）。

（三）番禺区：

1.市良路段（沙湾教考场至古坝环形岛）；

2. 浮莲路段（浮莲路亚运大道路口至石化公路官桥村段官桥牌坊）。

（四）从化市：

1.省道355线段（明珠工业园路口至人和路口）；

2.县道286线段（人和路口至横江道班路口）。

（五）增城市：增滩路段（教考场路口至仙塘村口）。

三、机动车学习驾驶人训练、考试期间，指定路段的其他车辆、行人不因训练、考试受通行限制。

四、本通告自2012年 月 日起施行，有效期5年。
