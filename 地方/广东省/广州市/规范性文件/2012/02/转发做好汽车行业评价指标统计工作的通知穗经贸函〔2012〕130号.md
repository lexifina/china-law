# 转发做好汽车行业评价指标统计工作的通知穗经贸函〔2012〕130号

各区、县级市经贸部门：

现将省经济和信息化委《关于做好汽车行业评价指标统计工作的通知》（粤经信商贸函〔2012〕401号）转发给你们。请你们按要求组织辖区内汽车经销商、二手车交易市场、报废汽车回收拆解企业填报相应表格，汇总后于2012年2月29日下班前以书面和电子版形式反馈我委。

二○一二年二月二十三日
