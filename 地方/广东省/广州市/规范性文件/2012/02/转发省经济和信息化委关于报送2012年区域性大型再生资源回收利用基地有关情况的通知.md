# 转发省经济和信息化委关于报送2012年区域性大型再生资源回收利用基地有关情况的通知

各区、县级市经贸部门，各有关企业：

现将省经济和信息化委《关于报送2012年区域性大型再生资源回收利用基地有关情况的通知》（粤经信商贸函[2012]402号，简称《通知》）转发给你们。请按《通知》要求，结合本辖区再生资源回收行业的情况，对已按照《再生资源回收管理办法》（商务部等6部门2007年第8号令）已完善备案手续、且符合辖区内再生资源回收网点规划的企业进行摸查汇总，由本辖区经贸部门提出书面推荐意见，连同《符合条件的区域性大型再生资源回收利用基地汇总表》、相关的基地项目书面材料（含电子文档），于2月21日上午12时前报我委(特种商业处）。

二○一二年二月二十日
