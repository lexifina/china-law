# 关于免费为农民工提供工伤保险待遇纠纷等六类案件法律咨询的通知

各区、县级市司法局，各律师事务所：

为落实《国务院关于解决农民工问题的若干意见》（国发〔2006〕5号）和省、市有关惠民政策，让法律援助惠及更多的农民工，保障农民工的合法权益，现对免费为农民工提供工伤保险待遇纠纷等六类案件法律咨询的有关事项通知如下：

一、律师事务所对因包括工伤保险待遇纠纷、医疗损害责任纠纷、机动车交通事故责任纠纷、水上运输人身损害责任纠纷、追索劳动报酬纠纷及群体性纠纷等六类案件前来的农民工给予免费法律咨询。

二、具体要求和补贴支付方式。（一）律师事务所须指派律师为符合条件的农民工解答法律咨询。（二）律师解答咨询时，必须认真填写《广州市法律援助处法律咨询登记表》，并将咨询人的身份证复印件附卷备案。（三）请各律师事务所专管员于每月上旬将上月本所向农民工免费提供法律咨询情况进行汇总，并填写《广州市法律援助处法律咨询汇总登记表》。每逢星期四下午，各律师事务所可凭《广州市法律援助处法律咨询汇总登记表》一式两份、《广州市法律援助处法律咨询登记表》一份及咨询人身份证复印件到广州市法律援助处领取补贴，补贴将按广州市法律援助处执行的现行标准支付。（四）《广州市法律援助处法律咨询登记表》及《广州市法律援助处法律咨询汇总登记表》可到广州市法律援助处领取或自行复制。

三、本通知自公布之日起施行，有效期5年。相关法律依据变化或有效届满，根据实施情况依法进行评估修订。《关于免费为农民工提供工伤事故损害赔偿等六类案件法律咨询的通知》（穗司发〔2010〕59号）同时废止。
