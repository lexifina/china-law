# 关于印发《广州市文化广电新闻出版局规范行政许可自由裁量权规定》的通知

局机关各处（室）：

为规范行政许可行为，确保行政许可的合法性、合理性，根据《广州市规范行政执法自由裁量权规定》的要求，我局制定了《广州市文化广电新闻出版局规范行政许可自由裁量权规定》。经市政府法制办审查通过，现印发给你们，请遵照执行。

特此通知。
