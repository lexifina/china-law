# 关于认定2012年市中小企业创业示范基地中小企业公共技术服务示范平台中小企业公共服务示范平台的通知穗中小企函〔2012〕19号

各区、县级市中小企业行政主管部门，有关单位：

为贯彻《中共广州市委广州市人民政府关于加快发展民营经济的实施意见》（穗字〔2011〕15号），加快我市中小企业创业基地和公共服务平台建设，进一步提高基地和平台的运行质量和服务水平，构建全方位的创业创新服务链，推动中小企业孵化成长、转型升级和创新发展，根据《印发广州市中小企业创业示范基地管理办法广州市中小企业公共技术服务示范平台管理办法和广州市中小企业公共服务示范平台管理办法的通知》（穗经贸〔2011〕8号）的有关规定，广州市中小企业我局开展了2012年广州市中小企业创业示范基地、广州市中小企业公共（技术）服务示范平台和广州市中小企业公共服务示范平台认定工作。经企业（机构）自愿申报，各区、（县级市）经贸中小企业行政主管部门、市属工商业企业集团、有关协会审核推荐，专家评审和上网公示等程序，现认定广州壹捌伍零创意产业投资有限公司广州1850创意产业基地等8家创业基地为“2012年广州市中小企业创业示范基地”，广州市特种承压设备检测研究院高耗能特种设备能效测试与评价技术服务平台等7个平台为“2012年广州市中小企业公共（技术）服务示范平台”，广州市花都区中小企业服务中心中小企业公共服务平台等6个平台为“2012年广州市中小企业公共服务示范平台”（详见附件），有效期三年。

请各区、县级市中小企业行政主管部门，市属工商业企业集团将本通知转发至申报单位，并加强对市示范基地、示范平台的扶持和管理，引导其充分发挥自身优势，汇聚创业创新资源，为当地中小企业产业转型和结构优化升级提供创业创新服务,推进中小企业孵化成长和创新发展，促进本地区产业集群及特色优势产业的健康、持续发展，提升我市中小企业和民营经济发展水平。
