# 关于组织千家企业参加广货网上行活动的通知穗经贸函〔2012〕833号

各区、县级市经贸部门，有关行业协会：

为贯彻落实全省流通工作会议部署，切实做好“广货网上行”活动，根据省政府印发的《2012年广货网上行活动总体方案》以及省经济和信息化委《关于组织万家企业参加广货网上行活动的通知》（粤经信材料函〔2012〕2644号）的要求，现就我市组织千家企业参加“广货网上行”，应用电子商务开展宣传推广、网络采购和销售活动事宜通知如下：

一、请区、县级市经贸部门按照确定的企业计划数量（各区、县级市计划数及对口联系处室见附件1，也可超过计划数上报）抓紧发动组织辖区内企业参加“广货网上行”活动，并会同工商、质监部门对申报企业进行评审和选定，报我委对口联系处室备案。

二、请市有关行业协会积极组织本行业企业或协会会员单位参加“广货网上行”活动，并对申报企业进行评审和选定，报我委备案。

三、请各区、县级市经贸主管部门，市有关行业协会确定负责“广货网上行”活动的具体负责人和联络员，并于8月28日（星期二）中午前将回执（见附件2）报我委（经贸合作与会展处）。

四、各区、县级市经贸部门和市有关行业协会在组织企业参加“广货网上行”活动时，要严格按照《“广货网上行”活动市场主体遴选暂行办法》（见附件3或在省经济和信息化委公众网上下载）确定的申报条件、材料要求组织企业申报。汇总表（见附件4）及其他申报材料请于8月30日（星期四）中午前正式行文报送我委。8月30日后如有新增参加活动的企业，也请按上述要求及时报送。

附件：1.各区、县级市参加广货网上行活动企业计划数量及对口联系处室表

2.参加广货网上行活动有关单位负责人及联络员回执

3.广货网上行活动市场主体遴选暂行办法

4.参加广货网上行活动企业汇总表
