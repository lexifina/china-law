# 关于印发广州市星光老年之家年度考核和分类资助试行办法的通知

各区（县级市）民政局、财政局：

《广州市星光老年之家年度考核和分类资助试行办法》业经市法制办审查通过，现印发给你们，请认真贯彻执行。执行中遇到问题，请径向市民政局反映。

2012年星光老年之家年度考核工作，以年底为期限完成，参照本办法执行。

特此通知。
