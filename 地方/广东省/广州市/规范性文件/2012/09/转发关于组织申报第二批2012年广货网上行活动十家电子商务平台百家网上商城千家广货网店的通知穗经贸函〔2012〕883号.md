# 转发关于组织申报第二批2012年广货网上行活动十家电子商务平台百家网上商城千家广货网店的通知穗经贸函〔2012〕883号

各区、县级市经贸、信息化主管部门，市属工商业企业集团，各有关企业：

现将省经济和信息化委《广货网上行组委会办公室关于组织申报第二批2012年广货网上行活动十家电子商务平台、百家网上商城、千家广货网店的通知》（粤经信发电[2012]46号，以下简称《通知》）转发给你们，请你们按照《通知》要求，积极做好我市第二批2012年广货网上行活动十家电子商务平台、百家网上商城、千家广货网店的组织申报工作。现将有关事项通知如下：

一、请各区、县级市经贸、信息化主管部门、市属工商业企业集团认真组织企业申报，并对申报材料进行初审。

二、符合申报要求的单位，请按照《通知》要求编制申报材料（纸质材料一式两份，用A4纸打印，简装，不另加封皮，电子版刻录成光盘），送所属区、县级市经贸、信息化主管部门提出推荐意见。各区、县级市经贸部门牵头会区工商、质监部门审查后，将推荐企业名单汇总表及各推荐企业申请材料于9月11日上午10时前报（书面报送函必须注明“已经会同工商、质监等部门对企业申请材料进行了符合性审查”）我委（经贸合作处，地址：广州市府前路1号市府大院综合楼广州市经济贸易委员会501室、504室），以便及时汇总上报省经济和信息化委。

二○一二年九月五日
