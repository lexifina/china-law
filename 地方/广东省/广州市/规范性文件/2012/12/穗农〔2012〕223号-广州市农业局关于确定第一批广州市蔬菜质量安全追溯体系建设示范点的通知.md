# 广州市农业局关于确定第一批广州市蔬菜质量安全追溯体系建设示范点的通知

穗农〔2012〕223号

各区、县级市农业行政主管部门，局属有关单位:

为深入贯彻落实《食品安全法》、《农产品质量安全法》和《国务院办公厅关于统筹推进新一轮“菜篮子”工程建设的意见》(国办发〔2010〕18号)，提高蔬菜生产流通组织化、信息化水平，增强蔬菜质量安全保障能力，现确定我市第一批蔬菜质量安全追溯体系建设示范点20个（见附件），并提出以下工作要求：

一是提高思想认识。蔬菜是城乡居民重要的基本生活必需品，追溯体系的建立有利于促进生产者按照蔬菜安全标准从事生产加工，从源头上提升蔬菜质量安全水平；有利于形成企业信誉积累机制，创立放心蔬菜品牌，提高企业的经济效益。各区、县级市主管部门要切实加强对示范点建设工作的指导，加快蔬菜质量安全追溯体系建设。

二是抓好工作落实。要指定专人负责辖区内追溯系统的建设工作，密切跟踪示范点追溯系统建设过程中运行情况，加大对示范点工作的支持力度和检查力度，着力解决存在问题。要督促本辖区内的示范点落实具体负责人和技术人员，确保示范点的信息录入工作有专人负责。

三是加大宣传力度。积极通过报纸、电视等媒体宣传蔬菜追溯体系建设的意义、目的、措施和效果，引导消费者使用追溯系统的查询平台和查询手段购买可追溯的蔬菜产品，通过市场选择反向引导生产经营者参与质量追溯系统建设。要发布追溯管理先进企业名单，提升消费者对可追溯蔬菜产品和生产经营企业的认知度和信任度。

四是及时总结经验。要认真总结分析蔬菜质量追溯体系示范点建设过程中的成功经验和不足之处，积极探索创新适合本地区的蔬菜质量安全管理手段和办法，并及时向我局（蔬菜办公室）报送工作情况。
