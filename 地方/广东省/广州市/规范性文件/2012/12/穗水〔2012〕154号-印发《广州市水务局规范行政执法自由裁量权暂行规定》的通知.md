# 印发《广州市水务局规范行政执法自由裁量权暂行规定》的通知

局机关各处室、局属各单位：

为完善我局行政执法自由裁量权体系，在已制定《广州市水务局规范行政处罚自由裁量权暂行规定》、《广州市水务局规范行政许可自由裁量权暂行规定》基础上，制定了《广州市水务局规范行政执法自由裁量权暂行规定》，对行政强制、行政裁决、行政征收等其他类型行政执法事项自由裁量权予以规范。现印发给你们，请遵照执行。执行中遇到的问题，径向局政策法规处反映。

广州市水务局

2012年12月22日

公开方式：主动公开
