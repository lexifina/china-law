# 关于进一步明确我市公共就业人才服务机构集体户口挂靠人员办理婚姻登记和计划生育服务证有关问题的通知

广州市人力资源和社会保障局 文件

广州市人民政府法制办公室

穗计生发〔2014〕27号

各区、县级市人口计生局，各公共就业人才服务机构：

为切实做好我市引进人才的服务管理工作，现就进一步明确我市公共就业人才服务机构集体户口挂靠人员办理婚姻登记和计划生育服务证有关问题通知如下：

一、我市公共就业人才服务机构集体户口挂靠人员在办理婚姻登记和计划生育服务证等手续时，公共就业人才服务机构应当及时为其提供户口卡，不得以各种理由拒绝，同时应向其做好计划生育政策的宣传教育工作。

二、人口计生部门在为公共就业人才服务机构集体户口挂靠人员办理计划生育服务证时，不再需要其提供公共就业人才服务机构出具的计生证明，也不再需要公共就业人才服务机构加盖公章。

三、公共就业人才服务机构对集体户口挂靠人员计划生育管理的主要职责是：主动配合当地人口计生部门，积极做好集体户口挂靠人员日常管理、人员变动管理、宣传教育和技术服务等计生管理工作，每半年向当地人口计生部门通报一次人员婚姻变动信息、住址变更情况及联系方式变更情况。

四、人口计生部门、公共就业人才服务机构在为集体户口挂靠人员提供服务和进行管理的过程中，要本着以人为本、积极负责的态度，不得有意推诿、拖延。对有意推诿、拖延的单位及其工作人员，依法追究责任。

五、本通知自印发之日起施行。

广州市人口和计划生育局 广州市人力资源和社会保障局
