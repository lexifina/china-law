# 广州市人民政府金融工作办公室关于印发《广州市小额贷款公司利用未分配利润发放贷款试行办法》的通知

各区、县级市金融工作部门，各家小额贷款公司、广州立根小额再贷款公司：

为支持我市小额贷款公司利用未分配利润发放贷款，增加可用资金，提高经营效益，更好地服务“三农”及小微企业，我办制定了《广州市小额贷款公司利用未分配利润发放贷款试行办法》，现印发给你们，请遵照执行。执行中遇到问题，请及时向我办反映。

附件：广州市小额贷款公司利用未分配利润发放贷款试行办法

广州市人民政府金融工作办公室

2014年5月15日

公开方式：主动公开
