# 广州市发展改革委广州市公安局关于印发广州市户口迁入管理办法实施细则的通知

各有关单位：

为进一步贯彻落实《广州市人民政府印发关于加强我市人口调控和服务管理工作的意见及其配套文件的通知》（穗府〔2014〕10号）之《广州市户口迁入管理办法》，市发展改革委会同市公安局制定了《广州市户口迁入管理办法实施细则》，经市政府同意，现予以公布。请认真贯彻执行，执行中遇到的问题，请径向市发展改革委、市公安局反映。

附件：广州市户口迁入管理办法实施细则

广州市发展和改革委员会

广州市公安局

2014年7月31日

公开方式：主动公开
