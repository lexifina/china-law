# 市国土房管局印发广州市国有建设用地使用权网上挂牌出让规则的通知

从化、增城市国土房管局，各区分局，局属各单位、机关各处室：

为规范广州市国有建设用地使用权网上挂牌出让行为，完善公开出让方式，现将《广州市国有建设用地使用权网上挂牌出让规则》印发给你们，请遵照执行，执行中遇到的问题，请迳与市房地产交易登记中心联系。

特此通知。

市国土房管局

2014年7月17日
