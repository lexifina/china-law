# 市重点企业(项目)服务工作联席会议办公室关于印发广州市企业登记并联办理实施方案的通知穗服务联席〔2014〕1号

市重点企业(项目)服务工作联席会议办公室关于印发广州市企业登记并联办理实施方案的通知

各区、县级市人民政府，市编办，市政府各部门、各直属机构，有关单位：

经市人民政府同意，现将《广州市企业登记并联办理实施方案》印发给你们，请认真组织实施。实施过程中遇到的问题，请径向市重点企业（项目）服务工作联席会议办公室（设在市经贸委）反映。

市重点企业（项目）服务工作联席会议（代章）办公室

2014年6月30日

广州市企业登记并联办理实施方案

按照市委、市政府对审批流程再造、代办服务和商事登记制度改革3项工作有机整合的要求，在商事登记制度改革的基础上，探索“统一受理，同步审批，限时办结，统一送达”的代办服务长效机制，提高公共服务水平和办事效率，特制定本方案。

一、实施原则

（一）规范性和便捷性原则。

整合资源，优化办事流程，提高办事效率，使企业以最短时间、最便捷方式办理《营业执照》、《组织机构代码证》、《税务登记证（地税）》、《税务登记证（国税）》、社保登记和公章刻制备案事项。

（二）公共资源消耗最小化原则。

兼顾各部门原有的管理要求，不增加或少增加财政负担，以最小的改造成本获得较大的改革成效。

（三）提高信息化水平原则。

充分利用商事登记管理信息平台和政务服务信息系统，通过广州市政府信息共享平台进行数据交换，提高企业登记并联办理的信息化水平。

二、工作目标

实现《营业执照》、《组织机构代码证》、《税务登记证（地税）》、《税务登记证（国税）》“一窗受理、四证联发、信息共享”。

三、主要内容

（一）实施范围。

从广州市范围内公司制法人企业（有限责任公司、股份有限公司）的设立登记开始试行，逐步推广到各类企业及其分支机构的设立登记。

（二）并联办理事项。

纳入企业登记并联办理的事项有：1.商事主体设立登记；2.组织机构代码证；3.税务登记证（地税）；4.税务登记证（国税）；5.社保登记；6.公章刻制备案。

四、办理流程

在各政务中心设立“企业登记联办窗”。申请人在“企业登记联办窗”同时申请办理《营业执照》、《组织机构代码证》、《税务登记证》（含地税、国税）、社保登记和公章刻制业务。由工商部门办理《营业执照》；由广州市标准化研究院办理《组织机构代码证》、《税务登记证》（含地税、国税）和社保登记；由公安部门组织公章刻制。申请人接到相关部门通知后，凭业务受理凭证和公章领取以上证照。

以上事项，全部办理时限为6个工作日。具体流程如下（流程图见附件）：

（一）受理登记阶段（当日即办）。

申请人持办理《营业执照》、《组织机构代码证》、《税务登记证》（含地税、国税）、社保登记和刻制公章所需提交的全部申请材料到市（区）政务中心办理以上业务。

申请人到“企业登记联办窗”的工商部门申请办理《营业执照》。工商部门受理申请后，向申请人发放《受理通知书》，并安排联办业务号，指引申请人到“企业登记联办窗”的标准化研究院办理《组织机构代码证》、《税务登记证》（含地税、国税）和社保登记。

申请人按联办业务号顺序在“企业登记联办窗”的标准化研究院提交申请材料，办理《组织机构代码证》、《税务登记证》（含地税、国税）和社保登记。

（二）并联办理阶段（6个工作日）。

工商部门受理企业设立申请后，3个工作日内将获准领取《营业执照》的企业相关信息分别推送至标准化研究院和公安部门。

标准化研究院收到工商部门推送信息后3工作日内，核发《组织机构代码证》、《税务登记证》（含地税、国税）和编制社保登记编码。

公安部门收到工商部门推送的信息后3个工作日内完成公章备案。公安部门收到工商部门推送的信息后，同时通知申请人和公章刻制机构；申请人直接到公章刻制机构缴费，公章刻制机构完成公章刻制后送公安部门备案。

（三）领取证照阶段（当日即办）。

申请人接到工商部门通知后，可到“企业登记联办窗”的工商部门窗口领取《营业执照》和开业通知书；凭已在公安部门备案的公章和《营业执照》到“企业登记联办窗”的标准化研究院窗口领取《组织机构代码证》、《税务登记证》（含地税、国税）和社保登记编码。

（四）上传数据信息。

各单位核发证照后，上传相应的数据信息到广州市政府信息平台的电子证照库。

五、各有关部门职责

（一）市行政审批制度改革工作联席会议办公室。

1.统筹指导企业登记并联办理工作。

2.协调企业登记并联办理实施过程中遇到的有关审批权限、职责分工等问题。

（二）市重点企业（项目）服务工作联席会议办公室。

1.组织企业登记并联办理方案的实施。

2.协调企业登记并联办理的有关部门，做好流程优化和业务对接工作。

(三)市政务办。

1.在各政务中心设立“企业登记联办窗”，将工商部门和标准化研究院办理登记联办业务的岗位调整到毗邻位置。对于场地调整确实存在困难的，应尽量调整工商部门和标准化研究院窗口相近。

2.优化、调整叫号系统。在“企业登记联办窗”的工商部门增设联办业务叫号机，实现工商部门与标准化研究院的业务联办。

3.在各区政务中心公安部门窗口配置政务办统一开发的各类政务信息系统及标准窗口服务设备。

4. 做好商事登记管理信息平台的数据对接和信息推送工作。

（四）工商部门。

1.办理企业设立登记联办业务。

2.在受理企业登记申请后，立即安排联办业务号。

3.及时将企业登记的审核信息和公章刻制信息分别推送给标准化研究院和公安部门。

4.配合市政务办、市科信局做好企业登记信息推送和数据对接工作。

5.配合市政务办做好业务窗口调整和叫号系统设置工作。

（五）质监部门（广州市标准化研究院）。

1.并联办理《组织机构代码证》、《税务登记证》（含地税、国税）和社保登记业务。

2.及时接收工商部门推送的企业登记审核信息。

3.根据税务部门要求，制作电子档案，定期将地税和国税部门所需的档案移交税务部门，做好资料交接工作。

4.配合市科信局做好企业登记信息数据对接工作。

（六）地税部门。

1.授权标准化研究院办理税务登记（地税）。

2.向标准化研究院提供办理委托事项所必须的资料、设备；及时向标准化研究院提供委托代发的税务登记证件所必须的相关证照及表证单书。

3.按期接收由标准化研究院移交的档案资料。

4.对委托工作进行业务指导、跟踪评估，监督抽查。

（七）国税部门。

1.授权标准化研究院办理税务登记（国税）。

2.向标准化研究院提供办理委托事项所必须的资料、设备；及时向标准化研究院提供委托代发的税务登记证件所必须的相关证照及表证单书。

3.按期接收由标准化研究院移交的档案资料。

4.对委托工作进行业务指导、跟踪评估，监督抽查。

（八）公安部门。

1.配合市政务办在各区政务中心的公安部门窗口配置信息系统所需设备。

2.及时接收工商部门推送的公章刻制信息。

3.负责公章刻制和备案工作。

（九）市科信局。

负责政府信息共享平台的维护，提供企业登记并联办理数据、电子证照信息的共享交换支持。

（十）各区政府。

组织、推动辖区实施企业登记并联办理工作。

六、工作步骤和时间安排

（一）准备阶段（2014年7月底前完成）。

完成方案制定、企业登记数据流转接口建设、窗口及叫号系统调整、业务衔接、人员培训等准备工作。

（二）试点阶段（2014年8-12月完成）。

在市政务服务中心及南沙区政务服务中心试行企业登记并联办理，及时总结试点阶段出现的问题，进一步完善操作规程。

（三）推广阶段（2015年）。

在全市各政务中心全面推广企业登记并联办理，实现广州地区全覆盖。

七、保障措施

（一）加强组织协调。

各有关部门要按照方案要求，在职能范围内认真履行审批职责。树立全局观念，明确工作任务，加强部门间的沟通协调，全力推进企业登记并联办理工作。

（二）加强监督考核。

市政务办加强“企业登记联办窗”的日常监督考核。市监察局将并联办理项目纳入广州市行政审批服务暨电子监察系统的监察范围，依法加强对有关审批部门及其人员在履行行政审批职责中执法和效能情况的监察。

（三）加强宣传引导。

充分做好企业登记并联办理方案的宣传工作，营造全社会关心、重视、支持联办工作的良好氛围。在工作中不断总结、修正和完善，建立反馈机制，确保工作质量。

（四）落实经费。

各部门在实施企业登记并联办理工作中，需要增加必要工作设备的，所需资金由各部门按规定申报纳入各部门的年度部门预算，市财政审核安排。

公开方式：主动公开
