# 广州市农业局关于公布2014年度示范性农民专业合作社评选和监测评价结果的通知

各区（县级市）农业局，各有关单位：

根据《广州市示范性农民专业合作社评选和管理办法（试行）》的相关要求，我局联合市发展改革委、财政局、经贸委、工商局、地税局等部门开展了2014年度市级示范性农民专业合作社评选，并对2009～2013年度评选出的30家市级示范性农民专业合作社进行了监测评价。按照合作社自评申报、区（县级市）初审、市农业局初核、联合评审小组评选、网上公示等程序和评选结果，认定“广州市白云区绿韵农家乐鲜花种植农民专业合作社”等6家农民专业合作社为2014年度广州市示范性农民专业合作社，认定2009～2013年度评选出的30家市级示范社继续保留“广州市示范性农民专业合作社”资格。

附件：1．2014年度广州市示范性农民专业合作社名单

2．保留“广州市示范性农民专业合作社”资格名单
