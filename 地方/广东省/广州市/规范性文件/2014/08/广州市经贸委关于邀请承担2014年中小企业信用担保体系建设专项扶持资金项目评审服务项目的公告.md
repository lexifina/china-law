# 广州市经贸委关于邀请承担2014年中小企业信用担保体系建设专项扶持资金项目评审服务项目的公告

各有关单位：

根据《广州市战略性主导产业发展资金管理暂行办法》、《广州市发展改革委 财政局关于下达2014年广州市战略性主导产业发展资金计划的通知》（穗发改〔2014〕95号）和《广州市经贸委 广州市财政局关于组织申报2014年市财政扶持中小企业信用担保体系建设专项资金项目的通知》（穗经贸函〔2014〕636号）的要求，我委拟委托开展2014年市战略性主导产业发展资金中小企业信用担保体系建设专项资金项目评审工作。现将有关事宜公告如下：

一、项目征集的起止日期

2014年8月1日至2014年8月7日。

二、项目承担单位的资质和业务要求

1、在广州地区注册的会计师事务所或分所，具备营业执照和执业证书；分所投标的，必须提供总所出具的授权书。

2、注册会计师不少于20名。

3、具有财政部门核发的会计师事务所或评估执业证书，须提供证书的复印件（加盖投标人公章）。

4、是近期广州市财政局入围会计师事务所或评估机构（2013年3月广州市财政局清产核资资产评估和审计服务资格采购项目中标供应商)。

三、委托事项内容及要求

1、对申请2014年度广州市扶持中小企业信用担保体系建设专项资金的申报材料进行审核，在收齐申报材料后15个工作日内完成本次专项审核工作，并出具综合评审报告。

2、有意参与的单位需提交项目意向书（一式4份，包括申请单位情况介绍），并附以下材料：

（1）单位基本情况表（原件盖章，见附件）；

（2）营业执照副本、组织机构代码证复印件（加盖公章）；

（3）执业证书复印件（加盖公章）；

（4）法定代表人证明书或法人授权委托书（原件）；

（5）开展政府委托工作经验相关证明材料；

（6）工作方案和计划、人力投入、经费使用、提交结果时间、提交内容、服务质量承诺等；

（7）其他投标人认为能证明本单位实力或能胜任本项工作内容的其他材料。

四、合同经费：组织开展2014年中小企业信用担保体系建设专项扶持资金项目评审工作费用不超过19万元人民币。

五、项目意向书请提交：以上书面材料（一式4份含电子光盘并将材料密封、加盖骑缝章）在2014年8月7日前交至广州市经贸委中小企业局(广州市府前路1号综合楼613室，邮政编码：510032，联系人：邱碧娟，电话：83123826，星期一至五8：30-12：00、14：00-17：30)。
