# 广州市发展改革委关于印发广州市轨道交通建设及偿债资金筹集和使用管理办法的通知

各相关单位：

为规范和强化广州市轨道交通建设及偿债资金的筹集和使用监管工作，优化资金支付流程，保障资金需求和提高资金使用效益，有效控制轨道交通建设投资成本，我委制定了《广州市轨道交通建设及偿债资金筹集和使用管理办法》。现印发给你们，请遵照执行。

附件：广州市轨道交通建设及偿债资金筹集和使用管理办法

广州市发展和改革委员会
