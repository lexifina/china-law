# 广州市民政局广州市财政局关于提高我市农村五保供养标准的通知

各区（县级市）人民政府，市各有关单位：

经市政府同意，从2014年7月1日起提高我市农村五保供养标准。现将有关事项通知如下：

一、提高农村五保供养标准

农村五保供养标准按不低于当地上年度农村居民人均纯收入的85%确定。

各有关区（县级市）每人每月农村五保供养标准按以下标准执行：白云区1298元、花都区1230元、番禺区1431元、南沙区1508元、萝岗区1557元、从化市895元、增城市1123元。

二、资金安排

所需五保供养金由各有关区（县级市）财政自行解决。

三、执行时间

新的五保供养标准从2014年7月1日起执行。

四、工作要求

各有关区（县级市）和市各有关单位要根据市委市政府有关要求，全面执行新的农村五保供养标准，及时筹集资金，按时发放到位，切实保障农村五保供养对象基本生活。

五、其他

本通知有效期3年，有效期届满或相关法律政策依据变化的，根据实施情况依法评估修订。
