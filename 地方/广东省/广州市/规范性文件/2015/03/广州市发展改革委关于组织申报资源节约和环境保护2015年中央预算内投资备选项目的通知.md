# 广州市发展改革委关于组织申报资源节约和环境保护2015年中央预算内投资备选项目的通知

各区(县级市)发展改革局：

根据《国家发展改革委办公厅关于组织申报资源节约和环境保护2015年中央预算内投资备选项目的通知》(发改办环资〔2015〕631号，见附件1)和省发展改革委《转发国家发展改革委办公厅关于组织申报 2015 年中央预算内投资备选项目的通知》(粤发改办资环函〔2015〕1119号，见附件2)的要求。为做好我市项目的申报工作，现就有关工作通知如下：

一、各区(县级市)发展改革严格要按照选项范围和条件(见附件3)，认真组织遴选备选项目，切实做好组织协调工作，加强与相关部门沟通，提高上报项目质量。

二、各区(县级市)发展改革局上报的申报备选项目的正式文件中应附备选项目汇总表(含电子版，样表见附件4)。备选项目汇总表中应标注项目核准(备案)、能评审批、环评批复、土地预审、规划选址等审批部门和文号以及资金需求等情况。

三、符合申报要求的重金属污染治理工程项目、重点流域工业点源治理和清洁生产示范项目、节能环保技术装备产业化示范项目，应逐项报送项目材料单行本，列出目录并装订成册，一式四份，内容包括：

1.由甲级资质的咨询设计单位(需提供资质证书的影印件并加盖公章)编制的项目资金申请报告或可行性研究报告。

2.项目审批(备案、核准)文件的复印件。

3.企业基本情况表(样表见附件5)。

4.项目基本情况表(样表见附件6)。

5.节能审查意见或节能登记备案表。

四、请将通过“中央投资项目编报软件”(软件及使用说明在国家发改委互联网政务服务中心-下载专区-软件下载栏目下载最新版本)导出的项目库文件(后缀为imo)电子版，与备选项目汇总表电子版一并发送至 gzzhc@foxmail.com。请认真核对编报系统软件导出的电子版，相关项目信息必须完整并与备选项目汇总表内容一致。

请各区(县级市)发展改革局严格按照有关要求做好组织申报工作，并于4月3日(星期五)前，将申报文件及有关材料报送我委资环处，过期不予受理。

附件：1. 国家发展改革委办公厅关于组织申报资源节约和环境保护2015年中央预算内投资备选项目的通知

2. 转发国家发展改革委办公厅关于组织申报 2015年中央预算内投资备选项目的通知

3. 选项范围的具体内容和要求

4. 资源节约和环境保护2015年备选项目汇总表

5. 企业基本情况表

6. 项目基本情况表
