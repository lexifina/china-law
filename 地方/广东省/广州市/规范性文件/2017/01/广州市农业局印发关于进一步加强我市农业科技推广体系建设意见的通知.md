# 广州市农业局印发关于进一步加强我市农业科技推广体系建设意见的通知

各区农业行政主管部门，局机关有关处室、局属有关单位：

为贯彻落实《农业部关于贯彻实施〈中华人民共和国农业技术推广法〉的意见》（农科教发〔2013〕1号）、《中共广州市委 广州市人民政府关于落实发展新理念加强“三农”工作的意见》（穗字〔2016〕12号）等精神，进一步加强我市农业科技推广体系建设，我局制定了《关于进一步加强我市农业科技推广体系建设的意见》，现印发给你们，请结合本区、本部门的实际，细化措施，强化责任，认真抓好贯彻落实。

广州市农业局

2017年1月19日

关于进一步加强我市农业科技推广体系建设的意见

为进一步加强我市农业科技推广体系建设，充分发挥农业科技推广体系在发展现代农业、保障农产品质量安全和保护农业生态环境等方面的重要作用，结合我市农业农村工作实际，提出如下意见：

一、总体要求

（一）指导思想。全面贯彻党的十八大和十八届历次全会精神，认真落实《中华人民共和国农业技术推广法》等法律法规以及《农业部关于贯彻实施〈中华人民共和国农业技术推广法〉的意见》《中共广州市委 广州市人民政府关于落实发展新理念加强“三农”工作的意见》等相关政策文件精神,按照“完善网络、增强能力、健全机制、提升效能”的工作思路，以转变农业发展方式为主线,以“互联网+农技推广”为驱动，以绿色生态发展和农民增收、农业增效为目标，不断健全完善农业科技推广体系，为加快建成保障有力、生态和谐和示范领先的广州都市型现代农业提供有效服务和技术支撑。

（二）主要目标。通过发展多元农业技术服务组织、促进农业科技协同创新、设立农业科技推广示范基地、创新农技推广方式方法等各种工作措施，不断强化农科教、产学研联结机制，力争通过5年左右时间的努力，基本建成以农技推广机构为主导、农业科研机构和院校为支撑、农业社会化组织广泛参与的，与广州都市型现代农业发展相适应的新型农业科技推广体系，农业科技进步贡献率达70%以上、农业良种覆盖率达97%以上，农业主导品种、主推技术入户率和到位率达99%以上，龙头企业、专业合作社、家庭农场、种养大户等新型农业经营主体吸纳采用新技术能力显著增强。

二、主要任务

（一）促进多元农业技术服务组织发展。

1.充分发挥农业科研和教学单位在农技推广中的支撑作用。根据农业生产需要，通过安排项目资金，支持广州地区符合条件的农业科研院所、教学单位参与农业技术推广，充分利用涉农机构的科研平台和试验示范基地，建立“科研机构和院校+农技推广体系+示范基地+新型经营主体”的成果转化模式，引导科研教学人员深入基层开展农业技术培训和指导服务，集成、熟化、推广农业技术成果，解决农业生产一线的实际问题。

2.鼓励新型农业经营主体积极参与农技推广工作。将农业资金支持政策与技术推广应用工作挂钩，运用好资金扶持、业务指导、订购服务、定向委托、公开招标等方式，多渠道鼓励和支持农民专业合作社、涉农企业等社会组织为农民提供良种良法统用、农资统供、统耕统种统收、病虫害统防统治、农产品统购统销、农机社会化等各种形式的农业产前、产中、产后全程服务，提高农民应用先进技术的组织化程度。支持符合条件的农民专业合作社、涉农企业等社会组织参与农业技术推广项目的实施并给予必要的资金支持。

3.推进村级农业技术服务站点建设。根据农业生产实际和技术推广需要，选择以农业为主导产业的行政村作为试点，以村集体经济组织、农民专业合作社、科技示范户、农民技术人员等为依托，协调村民委员会和村集体经济组织通过提供办公场所和试验示范基地、资助活动经费等方式，稳妥推进村级农业技术服务站点建设。切实发挥基层农技推广机构的技术支撑和服务作用，完善区、镇农技人员与农民技术人员对接机制，加强技术培训、指导，协同解决农技推广难题。

（二）完善农业科技推广平台建设。

1.构建农业科技协同创新与应用示范平台。加强与广州地区农业科研院所和教学单位合作，共建农业科技创新与示范推广平台，在技术研发、集成示范、推广应用、成果转化及人才培养等方面开展全方位合作，探索建立政府推动、市场引导、企业化运作的农业科技成果转移新模式、新机制，促进创新成果与农业产业对接。

2.建设完善农业科技推广示范基地。依托农业科研基地、新型农业经营主体，以及现代农业园区、农标准化示范区等，认定一批影响力大、辐射带动能力强的市、区农业科技推广示范基地，并给予一定资金补助。对大田种植、畜禽养殖、渔业生产等进行物联网改造，建成一批示范性农业物联网应用基地。大力强化农技推广机构与各类示范基地的连线对接，通过“点—线—面”互联互动模式，全面推进农业科技成果转化与推广应用。

3．健全完善“农博士”等农技推广云平台。推进农技推广信息化工作，加快形成“互联网+农技推广”公共服务平台，建设有广州特色的“农博士”信息服务平台、组建好“农博士”专家服务团队，健全基层信息服务体系，全面提升农技推广信息化装备水平和服务能力。

（三）提升农技推广服务效能。

1.遴选推介主导品种主推技术。规范评审规则，坚持广州市农业主导品种、主推技术推介制度，每年遴选产量高、品质优、适应性广、抗性强、稳定性好、在农业生产中起主导作用的一批农作物良种、水产良种、畜禽良种作为主导品种，以及能提高农业生产效率、促进农业节本增效、增强农业资源循环利用、科学防治病虫草鼠害、提升农产品质量安全水平等方面的一批先进成熟技术作为主推技术，面向农业生产推介发布，引导广大农民选用优良品种和先进适用技术，充分发挥良种良法对促进农业增效、农民增收以及保障农产品质量安全和农业生态环境安全的支撑作用。各区可参照市的做法推介发布本区农业主导品种和主推技术。

2.完善农技推广运行机制。深入实施农业科技进村入户工作，遴选一批带动能力强的科技示范村和示范户，大力推行以“包村联户”为主要形式的工作机制和“专家+试验示范基地+农技人员+科技示范户+辐射带动户”的技术服务模式，构建“区有示范基地、镇有示范片、村有示范户”的科技示范网络，实现科技人员直接到户、良种良法直接到田、技术要领直接到人，提高技术入户率和到位率。

3.拓宽农技推广渠道。着力提高农技公共服务水平，积极开展送科技下乡咨询活动、线上线下培训活动、农技应急快速服务、农技热线服务、农技短信服务等，为农业生产经营者提供贴心服务。依托农业科技推广示范基地、农业科普基地等，组织举办农业新品种展示会、农业新优品种擂台赛、主导品种主推技术示范现场会等各类良种良法展示示范活动。

4.提升农技推广信息化水平。把握“互联网+现代农业”发展新机遇，以云计算和大数据为支撑，充分利用广州“农博士”信息服务平台、“农业通”短信平台、微信平台等，采用“专家抢单”等创新应用模式，实现移动互联，为农民提供定向推送的农业信息、远程问诊、技术指导和供求信息服务，提高农技推广工作实效。全面推进信息进村入户工程，促进公共服务体系与基层农业服务体系融合，为农民提供精准、实时的农技推广服务。

5.提高农民应用先进技术能力。加大农村实用人才带头人、农村青年创业致富“领头雁”和新型农业经营主体带头人培训力度。按照农时季节需求，借助培训基地、示范基地、“田间课堂”等平台，运用多种方式，广泛开展农业先进适用技术培训。深入实施新型职业农民培育工程，建立教育培训、规范管理和政策扶持“三位一体”的新型职业农民培育体系，开展全方位、多元化、多层次的培训。全市每年开展农民相关技术培训不少于2万人次，每年培育新型职业农民约2000人。

（四）加快农业科技推广人才队伍建设。

1.推进农业科研人才队伍建设。根据广州人才集聚工程及“羊城创新创业领军人才支持计划”等要求，结合农业科技创新专项、珠江科技新星专项等重大科研项目实施和现代农业产业技术体系建设工作，培养造就农业科技领军人才和青年骨干人才，充分发挥科研人员在科技与生产、集成与示范、教育与推广等方面的重要作用。

2.强化农业技术推广队伍建设。建立培训长效机制，广泛开展基层农技人员知识更新培训，实施基层农技人员轮训工作计划。鼓励、支持在职农技人员到农业院校、科研院所进行专业研修深造，提高专业水平和学历层次。完善农技人员考核评价制度，健全激励机制，落实相关政策待遇，吸引优秀人才从事基层农业技术推广工作。

3.组建农民技术人员队伍。依托农民专业作社、家庭农场以及种养大户、新型职业农民等，综合考虑行政村面积大小、人口总量、产业规模、发展需要等多种因素，择优选配、聘用农民技术员，着力推进村级农技员、动物防疫员、植保员、农产品质量安全管理员、农民信息员等各类村级农民技术人员队伍建设。对选配的农民技术人员按规定落实工作补助，明确工作岗位责任，加强考核培训，提高服务效能和水平，实现责、权、利相统一，切实解决农业技术推广“最后一公里”问题。

三、保障措施

（一）加强组织领导。农业科技推广体系建设是打基础、谋远利、事关全市农业农村经济发展全局的大事，各级农业部门作为农业科技推广工作主管部门，要切实发挥牵头作用，加强组织领导，明确目标任务，落实工作责任。要积极争取同级党委、政府的支持，加强与编制、人事、发改、财政、科技、教育等部门的沟通协调，推动落实有关政策，协调解决农技推广体系建设中存在的突出问题，加大对农业科技推广工作的扶持力度。市、区农业科研教学单位要主动配合，面向广州“三农”需要，立足自身实际，创新服务模式，积极参与农业技术推广工作。

（二）加大投入力度。各级农业部门要充分利用财政管理体制改革完善的契机，积极争取本级政府和有关部门的支持，发挥财政在农业科技推广投入中的主导作用，建立农业科技推广投入稳定增长机制，确保力度不减弱、总量有增加，加大对重大农业技术推广的财政支持力度，加快农业科技成果转化。

（三）营造良好氛围。各级农业部门要加强宣传，让农业科技推广工作深入人心，为制度建设和实施营造良好氛围。要大力宣传农业科技推广工作在现代农业建设中的支撑和保障作用，提升农技推广体系的社会影响力，赢得政府部门、社会各界和农民群众广泛认同。要大力宣传扎根农村、服务农民、成绩突出的科技人员，激励广大农技人员和科研人员深入农村基层和生产一线，努力提升农业科技推广工作实效。
