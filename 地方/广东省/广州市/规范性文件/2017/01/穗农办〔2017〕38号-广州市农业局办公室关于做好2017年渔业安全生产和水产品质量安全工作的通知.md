# 广州市农业局办公室关于做好2017年渔业安全生产和水产品质量安全工作的通知

穗农办〔2017〕38号

关于做好2017年渔业安全生产和水产品质量安全工作的通知

各区渔业行政主管部门、渔政机构，省渔政总队广州支队，市农业技术推广中心，市海洋与渔业环境监测中心：

为贯彻落实国家、省、市关于安全生产的工作要求和市食安办《关于印发<广州市畜禽水产品抗生素、禁用化合物及兽药残留超标专项整治行动实施方案>的通知》（穗食安办〔2016〕14号）精神，确保渔业安全生产和生产环节水产品质量安全，提出如下意见，请结合工作实际，认真贯彻落实。

一、加强培训和宣教力度，切实提高安全生产防范意识和责任意识

（一）加强《广东省渔船安全生产管理办法》的宣贯工作。各区渔业行政主管部门及渔政机构要面向广大渔民和各级政府机构加强宣传贯彻2016年10月1日起施行的《广东省渔船安全生产管理办法》，进一步厘清政府的属地责任与部门的监管责任，促请乡镇人民政府、街道办事处明确渔船安全生产责任人及其职责，督促渔船船东（船长）落实主体责任。

（二）加强渔民安全生产的培训和警示教育。各区渔业行政主管部门及渔政机构要充分借助各种宣传渠道，加大安全生产宣传力度，落实告知制度，教育和引导渔船船东船长、从业人员和渔区干部群众增强做好安全生产隐患排查治理工作的主动性和自觉性。充分利用休禁渔期间组织开展安全生产培训和警示教育，对违法违规渔船、典型事故案例、存在严重隐患问题以及隐患排查治理走过场的渔船要予以曝光。

（三）加强渔业安全用药的宣传培训。渔业行政主管部门全面完成养殖区禁用渔药公告牌的制作和竖立，面向养殖户派发《广州市农业局渔业安全用药必读手册》等宣传资料，全面开展渔业安全用药宣传告知，要到塘、到户，使养殖户明白有关禁令公告是碰不得的红线、高压线。农业技术推广机构要组织举办渔业安全用药的专题培训，将法律底线、违法后果、技术路径等告知所有养殖户，提高养殖户知法守法和违法必究责任意识。

二、加强巡查力度，切实落实各项安全生产措施

（一）落实渔船渔港安全生产巡查制度。渔政机构要按照省渔政总队广州支队制定的《广州渔船渔港安全监管执法巡查工作规范》对渔船渔港安全生产开展量化巡查，发现问题及时整改，消除隐患，确保各项安全生产措施落实到位。巡查内容包括：巡查渔港渔船消防设备配备、安装、使用和维护保养情况；渔船泊位安排、易燃易爆物品存放以及寒潮大风应对防范措施准备落实等情况。巡查渔船救生、消防、通讯、号型号灯配备、安装、使用和维护保养情况；巡查渔船安全生产通信系统终端配备、监控平台管理使用情况。巡查渔船跟帮编队生产、进出港签证、渔船检验、临水作业人员穿着救生衣等制度落实情况。

（二）做好极端气候的渔业安全生产防御工作。渔业行政主管部门和渔政机构要根据季节和气候的变化，督促从业者做好极端天气条件下的渔业安全生产防御工作。冬春两季重点做好渔业防寒工作，发生冰冻灾害天气时及时指导养殖户采取鱼塘及时注水提高水位、增氧、大棚等措施，防止鱼被冻伤、冻死。夏秋两季重点做好台风暴雨防御工作，发生台风暴雨时要重点落实渔船渔港防台风信息通知到位，渔船进港，渔民上岸；指导养殖户及时给鱼塘增氧和降低水位，防止鱼塘漫堤，把灾害造成的损失降到最低。

（三）落实渔业养殖场的巡查制度。渔政机构要按照广东省渔政总队广州支队制定的《广州市渔业养殖监督执法巡查工作规范》，落实渔业养殖场执法巡查量化分级管理，坚持问题导向，针对性地开展巡查，发现一个问题解决一个问题。建立渔业养殖执法巡查档案，每次执法巡查、监督抽查，都必须制作现场记录，现场拍照取证等，并进行养殖执法告知，连同检测报告形成执法巡查卷宗。渔业行政主管部门要督促完善鳄鱼养殖场的安全应急预案，防止鳄鱼出逃伤人。

三、加强执法力度，严厉打击涉渔违法犯罪行为

（一）加大案件查办和惩处力度。渔政机构一旦发现渔业安全生产和渔业产品质量安全的违法行为，要坚决立案查办，精准办案，办铁案，查办一批有影响力的大案要案，加大对重大典型案例的通报曝光力度，充分发挥警示作用，达到“查处一案，教育一片”的威慑效果。

（二）全面落实检打联动工作机制。对风险监测发现的不合格渔业产品，渔政机构要及时组织开展执法调查，要边检查、边整改。对监督抽查检出的不合格渔业产品要开展全面排查，坚决依法进行查处。要加强行政执法与刑事司法的衔接，对涉嫌犯罪的要及时移送司法机关，发挥司法震慑作用，维护公平正义的渔业生产环境。

四、加强督促检查，形成工作机制

各区渔业行政主管部门要制定责任分工方案，明确上述各项工作具体承担机构，确保工作措施落实到位。我局将于6月底和12月底组织开展渔船安全生产与水产品质量安全监督检查行动，监督检查以自查为主，督导检查为辅，责任分工方案列入督导内容。各区要组织开展自查行动，分别于6月25日和11月25日前将自查自纠情况报送我局（渔业处）。我局督查组将通过现场检查、查阅资料、听取汇报、反馈意见等方式，对重点渔港、停泊点、渔船、重点水产品生产基地等安全管理工作进行监督检查，具体督查时间另行通知。
