# 广州市发展改革委转发国家发展改革委办公厅关于组织实施2017年新一代信息基础设施建设工程和“互联网+”重大工程的通知

各区发展改革局、广州开发区发展改革和金融工作局，天河软件园管委会：

现将《广东省发展改革委转发国家发展改革委办公厅关于组织实施2017年新一代信息基础设施建设工程和“互联网＋”重大工程的通知》转发你们，请抓紧办理。有关事项一并通知如下：

一、为保证项目申报质量，请你区对项目申请材料进行认真审核，并指导列入投资项目在线审批管理平台。推荐上报文中，请对所申报项目给出明确的财政资金重复支持审查意见与项目整体审核推荐意见，并对项目所有申报材料的真实性和合规性予以确认。

二、此次申报暂不提交环保、土地、节能、资金筹措等建设条件证明材料。项目获得批复后，请督促项目申报单位落实所有建设条件，并在资金申请下达请示中明确各项建设条件是否已经落实。

三、请于1月6日前，将你区项目申报文件、项目汇总表、项目资金申请报告、项目基本情况表一式三份（附电子版刻录光盘）报送我委（高技术产业处）。

附件：广东省发展改革委转发国家发展改革委办公厅关于组织实施2017年新一代信息基础设施建设工程和“互联网＋”重大工程的通知
