# 广州市发展改革委关于印发广州市2017年重点项目计划的通知

各区政府、市有关部门、项目业主单位：

《广州市2017年重点建设项目计划》（见附件1，以下简称正式项目）和《广州市2017年重点建设预备项目计划》（见附件2，以下简称预备项目）业经市十五届人大一次会议审议通过，现印发实施，并提出要求如下：

一、落实项目业主责任

项目业主作为项目建设的第一责任人，要进一步增强责任意识，坚决避免“等、靠、要”思想，积极、主动地解决问题，加快推进市重点项目建设。对于解决不了的问题，要及时向有关主管部门和市政府报告，争取协调解决。要将项目建设责任层层分解，确保每一件工作都有专人负责，出了问题能够追究，形成一级抓一级、层层抓落实的运作机制。

二、提升政府服务效能

各区政府、市有关部门要按照市委、市政府的部署要求，进一步创新管理服务方式，建立健全市重点项目建设工作联动协调机制，加强沟通，密切配合，加大力度解决项目存在的问题，共同推进项目建设。

市财政、国土规划、环保、建设、水务、林业园林、供水、供电、供气等职能部门要提前介入、主动服务，严格按照市重点建设项目绿色通道管理的时限要求，加快审批进度，加快完善预备项目前期报批手续，促进尚未开工项目早日开工建设。

我委将进一步加大对项目建设进度的督导力度，及时梳理汇总项目推进过程中遇到的突出问题，对于区和部门层面难以协调的重大问题，提请市政府或分管市领导召开专题会议进行协调解决。

三、保障项目要素需求

市国土规划部门要优先保障重点项目用地需求，在控规调整等方面对重点项目优先支持，促进项目早日落地。

继续实施征地拆迁各区总负责制度，各区党委主要负责人为征拆工作的第一责任人，负责按计划进度交付项目建设用地，保障征地和房屋征收工作的落实。

市财政部门要确保财政投资的重点项目建设资金及时、足额到位。对于符合产业引导资金支持范围的项目，有关部门在同等条件下要对市重点项目优先考虑。市金融工作局要会同有关部门，通过举办银企对接会等多种方式，帮助存在资金压力的项目单位解决实际困难。

市人力资源和社会保障部门要按照市的人才引进相关政策，协助重点项目业主单位解决人才入户问题。

四、加大督办检查力度

市府督查室将会同市发展改革委根据市重点项目计划确定的各区、各部门的工作任务，以及市领导协调会和部门协调会议定事项，对各部门、各区完成工作任务情况进行现场督察，确保既定工作目标和决策事项落到实处。同时，对督查、检查的结果定期进行通报，形成各单位共同推进重点项目建设的良好氛围。

五、做好信息报送工作

（一）做好项目节点计划和存在问题报送工作

正式项目和预备项目的业主单位均需会同主管部门制定落实年度工作任务的节点计划，明确关键环节和时间节点，梳理汇总项目当前存在的问题，填写《2017年市重点项目推进工作节点计划及存在问题表》（见附件3），于1月25日（星期三）前报送我委，以便下一步分领域、分类别进行协调督办工作。

（二）做好项目信息月报工作

继续实施市重点项目信息月报制度，正式项目和预备项目业主单位均需于每月底前登陆《广州市重点建设项目信息管理系统》（zdxm．gzplan．gov．cn），填写当月《重点项目信息月报表》（见附件4），包括前期手续报批进度、工程建设进度、投资完成额、项目阶段信息等资料，梳理提出项目存在问题及建议措施，并同时抄送项目主管部门。第一次报送要在3月6日（星期一）前完成（报送1－2月情况）。
