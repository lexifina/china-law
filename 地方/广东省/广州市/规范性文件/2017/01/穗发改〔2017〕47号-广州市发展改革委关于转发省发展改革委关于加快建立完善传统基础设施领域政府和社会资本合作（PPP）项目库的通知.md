# 广州市发展改革委关于转发省发展改革委关于加快建立完善传统基础设施领域政府和社会资本合作（PPP）项目库的通知

各区政府，市国土规划委、住建委、工信委、教育局、交委、水务局、林业园林局、民政局、城管委、广州港务局、城市更新局，市土地开发中心，省机场集团，市城投集团、水投集团、交投集团、广州港集团、地铁集团、广环投集团：

现将《广东省发展改革委转发国家发展改革委办公厅关于加快建立完善传统基础设施领域政府和社会资本合作（PPP）项目库的通知》（粤发改投资函〔2016〕6363号）转发给你们，请按照国家和省通知的时间节点和填报要求，做好有关PPP项目入库及信息完善工作。在今后的工作中，请按照国家发展改革委《传统基础设施领域政府和社会资本合作（PPP）项目库管理办法》明确的PPP项目入库和填报程序要求办理。
