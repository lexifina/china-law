# 广州市住房和城乡建设委员会关于征询对天河智慧城地下综合管廊工程建设通告意见的通知

各有关单位：

天河智慧城地下综合管廊工程为中央财政支持地下综合管廊试点项目，主要沿现状科韵路、科翔路、华观路、柯木塱南路-高唐路、软件西路、横三路、横五路、沐陂西路、凌岑路布置，总长约 19.4 公里，设控制中心 1 座。其建成后将有效避免城市道路反复开挖，优化和集约利用地下空间资源，提高管线安全系数，提升城市景观水平，增强城市基础设施的信息化、现代化管理。我委根据相关法律法规，草拟了《关于天河智慧城地下综合管廊工程建设的通告(征求意见稿)》(见附件)。现向社会公开征求意见,欢迎各界人士提出意见和建议。征求意见时间为2017年2月20日至3月6日,各界人士可通过传真或网络邮件方式反馈意见(传真：83124956,电子邮箱：wuyupeng@gzcc.gov.cn )。
