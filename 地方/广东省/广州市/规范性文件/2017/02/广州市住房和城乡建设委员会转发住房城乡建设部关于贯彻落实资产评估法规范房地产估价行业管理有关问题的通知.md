# 广州市住房和城乡建设委员会转发住房城乡建设部关于贯彻落实资产评估法规范房地产估价行业管理有关问题的通知

各有关企业：

根据《住房城乡建设部关于贯彻落实资产评估法规范房地产估价行业管理有关问题的通知》(建房〔2016〕275号)、《广东省住房和城乡建设厅转发住房城乡建设部关于贯彻落实资产评估法规范房地产估价行业管理有关问题的通知》(粤建房〔2017〕3号)的规定，自2016年12月1日起，对房地产估价机构实行备案管理制度，不再实行资质核准。有关房地产估价机构备案管理的具体事项另行通知。
