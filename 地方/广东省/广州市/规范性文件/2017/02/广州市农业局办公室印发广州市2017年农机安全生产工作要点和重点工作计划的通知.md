# 广州市农业局办公室印发广州市2017年农机安全生产工作要点和重点工作计划的通知

印发广州市2017年农机安全生产工作要点和重点工作计划的通知

各区农机管理部门，市农机监理所：

为加强我市农机安全生产工作，做好农机安全日常监理工作，有计划地推进我市2017年农机安全生产重点工作，我局制定了《广州市2017年农机安全生产工作要点和重点工作计划》，现印发给你们，请结合实际工作贯彻执行。

广州市农业局办公室

2017年2月15日

（联系人：陈武荣，联系电话：36503463）

广州市2017年农机安全生产工作要点和重点工作计划

2017年我市农机安全生产工作的总体思路是：贯彻落实中央、省、市关于农机安全生产工作的决策部署，牢固树立安全生产红线意识，预防和减少农机安全事故发生，坚持“分类管理、分级负责、条块结合、属地管理”的原则，以“平安农机”为目标，以提高农机“三率”为工作主线，以做好日常监理工作为基础，突出重点，求真务实，加强农机安全生产源头管理和隐患排查治理，确保不发生较大以上农机事故，保障人民群众生命财产安全。重点抓好以下工作：

一、落实安全生产责任

坚持“党政同责、一岗双责、齐抓共管、失职追责”，强化农机安全生产属地管理责任和企业（农机户）主体责任，层层签订农机安全生产责任书。实现农机安全生产监管责任全覆盖，确保责任到位、人员到位、经费到位。

二、加强宣传教育培训

切实履行“谁执法、谁普法”的职责，采取多种形式宣传培训农机安全管理法律法规、农机安全生产知识和安全操作技术，提高农机手守法意识、安全生产意识和安全操作技能，预防农机事故发生。

三、加大执法检查力度

建立市区两级量化执法巡查制度，健全执法检查工作台账。通过执法检查和联合执法等方式，查处无牌行驶、无证驾驶、违法载人和未按规定参加年检等各类农机违法行为，促进广大农机手提高守法意识和安全意识。

四、加强安全隐患治理

精心谋划并采取有力措施，切实有效治理农机安全隐患，特别是具有普遍性、危害程度高的安全隐患，实施有效治理。认真做好微耕机安全防护罩、手扶拖拉机后视镜安装、拖拉机安全部件维修维护、安装“三灯”和粘贴反光贴等农机安全隐患治理工作，切实消除隐患，减少事故发生。

五、加强“平安农机”体系建设

稳步推进“平安农机”示范区、镇、村建设，在巩固我市“平安农机”体系创建成果的基础上，力争在两到三年内，新增创建一到两个全国“平安农机”示范区。

六、加强应急管理，提高应急处置能力

加强农机应急管理体系建设。计划组织开展一次全市农机事故应急预案演练，检验和完善市、区农业机械事故应急预案，切实提高我市各级农机部门应急管理能力。

七、加强农机监理规范化建设

加强学习培训，提高队伍服务意识和能力，有序推进业务工作走向规范化、标准化，加强监理业务动态监督，推进业务档案规范化管理，计划组织开展业务规范督导检查行动1次。逐步建成一支规范化、标准化、信息化水平较高和管理服务能力较强的监理队伍。

八、落实重点工作计划

市、区两级农机管理部门在做好日常监理工作的基础上，制定重点工作计划，精心部署，真抓实干，采取有力措施，落实重点工作计划。

市农机监理所负责市本级农机安全生产重点工作计划的实施，发挥引领示范作用，协调指导各区农机部门落实好各区重点工作计划，并配合市农业局农机处做好监督检查，确保农机安全生产各项措施落到实处。
