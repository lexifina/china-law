# 广州市发展改革委转发国家发展改革委办公厅关于境内外资银行申请2017年度中长期外债借用规模有关事项的通知

市金融工作局，各区发展改革局：

现将《广东省发展改革委转发国家发展改革委办公厅关于境内外资银行申请2017年度中长期外债借用规模有关事项的通知》（粤发改外资函〔2017〕582号）转给你们，请通知相关外资银行做好2017年度中长期外债借用规模申报的有关工作，并于2月8日前按照要求将有关材料一式四份报至我委（投资处），以便我委汇总上报省发展改革委。

附件：广东省发展改革委转发国家发展改革委办公厅关于境内外资银行申请2017年度中长期外债借用规模有关事项的通知
