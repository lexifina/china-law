# 广州市信用办关于印发2017年广州市社会信用体系建设工作计划的通知

各区人民政府、市各有关部门：

根据经市政府同意印发的《广州市创建社会信用体系建设示范城市实施方案》，结合工作实际，我办制定了《2017年广州市社会信用体系建设工作计划》，经市信用体系建设领导小组同意，现印发给你们，请认真贯彻落实，并于每季度末报送工作进展情况。一季度信用体系建设工作进展情况请于3月31日前报送我办（电子版同步发送至：gzxyjs＠126．com）。

附件：2017年广州市社会信用体系建设工作计划

广州市社会信用体系建设统筹协调小组办公室

2017年3月23日
