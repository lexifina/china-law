# 广州市农业局关于做好2016年定点供穗生猪财政奖励补贴相关工作的通知

穗农函〔2017〕227号

关于做好2016年定点供穗生猪财政奖励补贴相关工作的通知

各区畜牧兽医行政主管部门，市动物卫生监督所，各有关定点供穗生猪养殖基地：

为引导定点基地生猪供穗，根据《广州市定点供穗生猪养殖基地建设管理办法》（穗农〔2016〕131号）的精神，决定组织开展2016年定点供穗生猪财政奖励补贴工作，现就相关事项通知如下：

一、奖励补贴标准和范围

全年未发现质量安全问题，对直接进入屠宰场的定点基地供穗生猪每头奖励补贴15元，全年每个定点基地补贴总额不得超过500万元。供穗生猪数量达1万头（含）以上的定点基地，补贴全年时段；属于广州市百万头生猪养殖基地，供穗生猪数量未达1万头，但达到年实际出栏量（按区畜牧兽医行政主管部门出具的证明为准）的50%（含）以上的定点基地，补贴《办法》实施前2016年1月1日至2016年7月28日时段。

二、积极落实定点基地供穗生猪奖励补贴工作

（一）定点基地供穗生猪数量核定。请各区畜牧兽医行政主管部门组织辖区内动物卫生监督机构，于3月31日前对广州市定点基地供穗生猪数量统计信息系统2016年度供穗生猪信息进行全面核实，保证纸质登记与信息系统中的记录数据一致。请市动物卫生监督所根据实际情况，组织定点供穗生猪数量抽查核实工作。

（二）定点基地提出供穗生猪奖励补贴申请。材料包括：申请书（范本见附件1）、《定点供穗生猪养殖基地价格调节基金补贴申请表》（附件2）、《定点供穗生猪养殖基地生猪供应情况表》（附件3）、《广州市财政农业专项资金直接支付申请书》（附件4），于3月31日前邮寄或送至我局畜牧处。（供穗生猪数量未达1万头的定点基地，还要提供区畜牧兽医行政主管部门出具的2016年生猪实际出栏量证明。）

（三）出具定点基地供穗生猪数量证明材料。市农业局畜牧处将定点基地申请情况函达各区畜牧兽医行政主管部门。各区畜牧兽医行政主管部门、动物卫生监督机构对申请补贴的定点基地出具供应数量证明，于4月14日前填写《申请奖励补贴定点供穗生猪养殖基地生猪供应数量核定表》（附件5）送市动物卫生监督所。请市动物卫生监督所对相关定点基地供应我市生猪的情况审核、汇总，填写《申请奖励补贴定点供穗生猪养殖基地生猪供应数量核定汇总表》（附件6），于4月28日前连同各区报送的核定表送我局畜牧处。

（四）市农业局根据定点基地供穗生猪情况，对申请材料进行审核，在补贴申请表（附件2）加具意见，连同定点基地供穗生猪数量证明材料（附件5、6）、定点供穗生猪养殖基地认定文件送市发展和改革委员会。由市发展和改革委员会同有关单位复核，报市政府审批后实施补贴。

请各级畜牧兽医行政主管部门、动物卫生监督机构高度重视，积极主动配合定点基地做好财政奖励补贴的有关工作，确保定点供穗生猪财政奖励补贴工作顺利进行。
