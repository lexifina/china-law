# 广州市发展改革委关于转发《广东省综合评标评审专家库专家档案管理办法》的通知

市财政局、市环保局、市住房城乡建设委、市交委、市水务局、市林业和园林局，广州港务局，广州公共资源交易中心，广州地铁集团：

现将《广东省发展和改革委员会广东省档案局关于印发〈广东省综合评标评审专家库专家档案管理办法〉的通知》（粤发改公资办〔2017〕103号）转发给你们，结合《广东省综合评标评审专家库和评标评审专家管理暂行办法》（粤府办〔2016〕128号）有关规定及我市实际，提出如下意见，请一并贯彻执行：

一、要保持与省评标评审专家库的互联互通。各部门现存的依法设立的专家库，应当与省专家库实现互联互通并接受统一管理。

二、要加强对专家档案工作的监督管理。各行业监管部门要加强业务指导和监督管理，落实工作责任，强化专家资格认定和出入库管理。

三、建立完善专家档案管理制度。各行业专家库的日常维护管理机构要按照省的要求，完善评标评审专家档案管理制度，切实做好相关行业专家档案的建档、归档和保管工作，完善专家电子档案信息资料，建立档案目录账册，定期进行检核，确保专家档案的完整、准确、系统、安全和有效利用。

专此

广州市发展和改革委员会

2017年2月28日
