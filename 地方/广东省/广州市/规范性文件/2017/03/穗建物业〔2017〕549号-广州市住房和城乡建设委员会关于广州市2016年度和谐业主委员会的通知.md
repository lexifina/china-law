# 广州市住房和城乡建设委员会关于广州市2016年度和谐业主委员会的通知

各区住房和建设行政主管部门、相关街(镇)、相关业主和业主委员会：

为建设“干净整洁平安有序”物业小区，提高业主的满意度和幸福感，推广我市业主委员会依法依规依约履职的好做法、好经验，发挥正面示范效应，经属地街(镇)、区住房和建设行政主管部门共同推荐，并在市住房城乡建设委网站公开征求社会公众意见，信华花园、大金钟48号大院、芳村花园、麓景雅苑、四季花园、时代广场、万科云山、怡园小区、绿茵岛花园、翠竹园、莲翠苑、映月翠庭等12个物业小区的业主委员会被评为广州市2016年度和谐业主委员会。

特此通知。

广州市住房和城乡建设委员会

2017年3月24日
