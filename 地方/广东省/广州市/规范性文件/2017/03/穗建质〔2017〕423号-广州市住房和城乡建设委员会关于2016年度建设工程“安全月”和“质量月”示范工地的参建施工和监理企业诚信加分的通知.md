# 广州市住房和城乡建设委员会关于2016年度建设工程“安全月”和“质量月”示范工地的参建施工和监理企业诚信加分的通知

各有关单位：

为鼓励广大建筑业企业开展建设工程质量安全生产工作的积极性，我委决定对受表彰的2016年度建设工程“安全月”和“质量月”示范工地参建施工、监理及专业分包企业在施工和监理企业诚信综合评价体系的“广州市安全文明施工样板标准化示范工地”栏目予以加分鼓励(施工、监理企业加2分，专业分包企业加1分)。现将有关事项通知如下：

一、本次加分的企业为《广州市住房和城乡建设委员会关于表彰2016年度全市建筑施工质量安全示范工地的企业和项目负责人的通报》(穗建质〔2016〕2477号(详见附件)，以下简称《表彰通报》)中受表彰的施工、监理及部分专业分包企业，参与多个示范工程的企业只能按一个工程加分，即符合本次加分的施工、监理企业加2分，专业分包企业加1分。

二、按照诚信综合评价系统加分流程，各企业自行登录广州市住房和城乡建设委员会企业诚信档案信息库(网址：http://qyk.gzcc.gov.cn/)录入“广州市安全文明施工样板标准化示范工地”相关证明材料(以附件中的《表彰通报》作为证明材料)，由市造价站进行审核。

三、请各区住建局、市建设工程质量监督站、市建设工程安全监督站、市市政工程安全质量监督站将通知发至所辖示范工地的施工、监理及专业分包企业，按规定进行行填报。

特此通知。
