# 广州市林业和园林局关于道德讲堂开放的通知（穗林业园林通[2017]120号）

机关各处室，防检办、保护办、服务中心：

为深入践行社会主义核心价值观，充分发挥道德讲堂的作用和效能，营造"崇德尚善"的浓厚氛围，积极引导广大干部职工自觉成为道德的传播者和践行者，局道德讲堂自3月17日起，向机关全体干部职工提供免费借阅图书服务。现将有关事项通知如下：

一、道德讲堂由宣传教育处负责管理，逢周五（限工作日）

15:30至17:10开放，提供阅读、借书服务。

二、凭本人工作证（或身份证），每人次限借2本（册），借

阅时间最长不超过30天。

三、借阅图书须在《广州市林业和园林局道德讲堂图书资料

借阅登记表》登记签名，按时归还，不得转借他人。

四、爱惜图书，保持页面整洁，阅后放回原处。如有损坏或

遗失，照价赔偿。

五、调离机关，须及时归还所借阅图书。

六、举止文明，禁止大声喧哗。

广州市林业和园林局

2017年3月17日
