# 关于指定机动车学习驾驶人训练考试路段的通告

为保障道路交通安全和畅通，根据《中华人民共和国道路交通安全法实施条例》、《机动车驾驶证申领和使用规定》以及《广东省道路交通安全条例》等有关规定，现将指定的机动车学习驾驶人训练和考试路段通告如下：

一、汽车训练路段

（一）市中心区：

1.广汕公路段（长岭路口至福和路口），训练时间：9:00-16:30，20:00-次日6:00；

2.龙溪大道段（东漖大桥底西侧调头位至五丫口大桥底东侧调头位），训练时间：20:00-次日6:00；

3. 荔湾区花地河东岸路（渔尾大桥桥底至玉兰路路口路段），训练时间：9:00-16:30、20:00-次日6:00。；

4.南洲路段（大沙新村南街口至瀛洲路口），训练时间：9:00-16:30，20:00-次日6:00；

5.新广从公路段（太和北路路口至福龙路口），训练时间：9:00-16:30，20:00-次日6:00；

6.省道116线段（广汕公路路口至和库路口），训练时间：9:00-16:30。；

7.新港东路（杨青路口以东路段），训练时间：20:00-次日6:00；

8.金山大道东延线（展贸南路B线路口以东路段），训练时间：9:00-16:30。

（二）花都区：

1.省道114线和县道284线段（省道114线将军潭段起，经省道114线县道284线路口，至县道284线皇母山段），训练时间：全天。；

2. 省道114线和省道118线（省道114线将军潭段起向南，经省道114线省道118线路口，至省道118线明主村温屋路口），训练时间：全天（考试时间除外）。

（三）番禺区：

1．市良路段（沙湾教考场至古坝环形岛），训练时间：全天；

2．乐羊羊路全路段，训练时间：全天（考试时间除外）；

3．兴亚三路（亚运大道路口至乐羊羊路路口路段），训练时间：全天（考试时间除外）；

4．亚运大道（北起石清公路路口南至亚运南路路口路段），训练时间：全天（考试时间除外）；

5.亚运南路（兴亚大道路口至乐羊羊路路口路段），训练时间：全天（考试时间除外）；。

（四）从化区：

1.省道355线段（明珠工业园路口至人和路口），训练时间：全天（全天）；

2.县道286线段（人和路口至横江道班路口），训练时间：全天（全天）。

（五）增城区:

1. 省道256路段（荔三公路，建设路路口至沿江路路口），训练时间：全天（考试时间除外）；

2. 增江街沿江东路（增江街鹤州村路段），训练时间：全天（考试时间除外）。

二、电车训练路段

（一）无轨电车。

一号线，中山八路全路段、中山七路全路段、中山六路全路段、解放中路（中山六路路口至惠福西路路口路段）、惠福西路（解放中路路口至人民中路路口路段）、人民中路（惠福西路路口至西堤二马路路口路段）、西堤二马路全路段、六二三路（西堤二马路路口至黄沙大道路口路段）、黄沙大道全路段，训练时间：09:00-15:00、20:00-次日6:00。

二号线，中山八路全路段、中山七路全路段、中山六路全路段、解放中路（中山六路路口至大德路路口路段）、大德路（解放中路路口至起义路路口路段）、起义路（大德路路口至大南路路口路段）、大南路全路段、文明路全路段、越秀南路全路段、广九大马路全路段、白云路全路段、东湖西路（白云路路口至大沙头三马路路口路段）、大沙头三马路全路段、沿江西路（大沙头三马路路口至海印桥底路段），训练时间：09:00-15:00、20:00-次日6:00。

（二）有轨电车。

海珠区有轨电车运营段广州塔至万胜围段，训练时间：全天（运营及考试时间除外）。

三、汽车考试路段

（一）市中心区：

1.广汕公路段（华南快速干线跨线桥底至班岭村路口）；

2.华观路考试路段（华观路火炉山路口至高唐路路口）;

3.番禺展贸东路全段;

4. .番禺展贸南路及其B线全段;

5. .金山大道东（296省道路口至展贸南路B线路口路段）。

（二）花都区：

1．车城大道（省道118线路口至岭西路路口路段）；

2．江北路（车道大道路口至江北3路路口路段）；

3．岭西路（优乐姿北路口至车城3路路口路段）；

4. 省道114线和省道118线（省道114线将军潭段起向南，经省道114线省道118线路口，至省道118线明主村温屋路口）。

（三）番禺区：

1．乐羊羊路全路段；

2．兴亚三路（亚运大道路口至乐羊羊路路口路段）；

3．亚运大道（北起石清公路路口南至亚运南路路口路段）；

4、亚运南路（兴亚大道路口至乐羊羊路路口路段）。

（四）从化区：明珠大道（省道355线路口至左村路口）。

（五）增城区：

1. 省道256线段（荔三公路，建设路路口至沿江路路口）；

2. 增江街沿江东路（增江街鹤州村路段）。

四、电车考试路段

（一）无轨电车。

一号线，中山八路全路段、中山七路全路段、中山六路全路段、解放中路（中山六路路口至惠福西路路口路段）、惠福西路（解放中路路口至人民中路路口路段）、人民中路（惠福西路路口至西堤二马路路口路段）、西堤二马路全路段、六二三路（西堤二马路路口至黄沙大道路口路段）、黄沙大道全路段。

二号线，中山八路全路段、中山七路全路段、中山六路全路段、解放中路（中山六路路口至大德路路口路段）、大德路（解放中路路口至起义路路口路段）、起义路（大德路路口至大南路路口路段）、大南路全路段、文明路全路段、越秀南路全路段、广九大马路全路段、白云路全路段、东湖西路（白云路路口至大沙头三马路路口路段）、大沙头三马路全路段、沿江西路（大沙头三马路路口至海印桥底路段）。

（二）有轨电车。

海珠区有轨电车运营段广州塔至万胜围段。

五、机动车学习驾驶人训练、考试期间，指定路段的其他车辆、行人不因训练、考试受通行限制。

六、本通告自发布之日起施行，有效期5年。
