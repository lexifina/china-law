# 广州市发展改革委关于印发2017年广州市节能监察计划的通知

市工业和信息化委、住房城乡建设委、交委、商务委、质监局、旅游局、港务局，各区发展改革部门，各有关单位：

为贯彻落实节能法律法规，进一步加强用能单位的节能管理，切实发挥好节能监察在落实节能法律法规和政策标准方面的监督约束作用，提高能源利用效率，我委制定了《2017年广州市节能监察计划》（详见附件1），现印发给你们。请各行业节能主管部门和各区节能主管部门认真督促相关用能单位按照有关要求做好自查整改，加强节能管理工作。各有关用能单位认真对照监察内容，切实推进各项节能工作开展。

附件：1．2017年广州市节能监察计划

2．2017年现场监察计划
