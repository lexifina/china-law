# 广州市发展改革委转发省发展改革委关于征集近零碳排放区示范工程试点项目的通知

市直有关部门、各区发改局：

现将《广东省发展改革委关于征集近零碳排放区示范工程试点项目的通知》（粤发改气候函〔2017〕1530号）转发给你们。请组织有关企业和单位积极申报广东省近零排放区示范工程试点项目，有关申请材料请于5月5日前报送我委资环处。
