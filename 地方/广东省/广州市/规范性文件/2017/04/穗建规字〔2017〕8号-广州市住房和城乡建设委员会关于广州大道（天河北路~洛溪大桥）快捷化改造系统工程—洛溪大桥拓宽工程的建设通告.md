# 广州市住房和城乡建设委员会关于广州大道（天河北路~洛溪大桥）快捷化改造系统工程—洛溪大桥拓宽工程的建设通告

广州大道（天河北路~洛溪大桥）快捷化改造系统工程—洛溪大桥拓宽工程是广州市重点市政建设项目，位于洛溪大桥既有桥梁两侧，是为缓解洛溪大桥堵塞问题，打通番禺与广州市区交通瓶颈，完善干线公路网和广州市路网的重要组成部分。经广州市人民政府同意，现将工程建设的有关事项通告如下：

一、广州大道（天河北路~洛溪大桥）快捷化改造系统工程—洛溪大桥拓宽工程建设范围是：北接广州大道，起点位于海珠区三滘立交，跨越珠江沥滘水道后南接105国道，终点位于洛溪大桥收费站南侧。工程线路全长约2.3千米（其中桥长1912米），道路等级为城市主干路，路宽80米，设计车速60千米/小时，在既有大桥东西两侧各建一座13米宽单向3车道桥梁，将现状双向4车道扩建为双向10车道。

二、本工程建设用地涉及海珠区、番禺区征地拆迁安置工作由海珠区、番禺区政府负责，管线迁改工作由市道路扩建工程办公室负责按照国家、省、市有关规定组织实施 。

三、工程范围内的单位和个人应顾全大局，积极支持、配合国家建设，不得阻挠建设工程的测量、钻探、征地拆迁和施工工作。

四、违反本通告，拒绝、阻碍国家机关工作人员依法执行职务的，由公安机关按照有关治安管理处罚的法律规定处理；涉嫌犯罪的，依法移交司法机关处理。

五、本通告自颁布之日起施行，有效期五年。
