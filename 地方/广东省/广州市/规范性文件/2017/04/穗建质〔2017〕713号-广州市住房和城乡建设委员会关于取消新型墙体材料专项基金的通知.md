# 广州市住房和城乡建设委员会关于取消新型墙体材料专项基金的通知

各区住建局，各有关单位：

根据《广东省住房和城乡建设厅转发省财政厅转发财政部关于取消 调整部分政府性基金有关政策的通知》(粤建科〔2017〕81号)要求,现就新型墙体材料专项基金有关事项通知如下:

一、自2017年4月1日起，我市各级建设行政主管部门停止征收新型墙体材料专项基金，请自主征收的各区住建设局及时修改涉及征收新型墙体材料专项基金的办事指南。以前年度预缴的新型墙体材料专项基金仍需严格按照我市现行“返退新型墙体材料专项基金办事指南”予以返退。

二、请各区住建局调整《房屋建筑工程和市政基础设施工程施工许可办事指南》，取消提供新型墙体材料专项基金缴纳证明材料的要求，建设项目办理“房屋建筑工程和市政基础设施工程施工许可”等手续时，无须再提供新型墙体材料专项基金缴纳证明。

三、各区在执行过程中如遇问题，请及时与市建筑节能与墙材革新管理办公室联系。

特此通知。

广州市住房和城乡建设委员会

2017年4月17日
