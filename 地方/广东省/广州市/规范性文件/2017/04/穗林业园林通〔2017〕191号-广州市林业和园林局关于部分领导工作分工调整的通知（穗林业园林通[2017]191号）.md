# 广州市林业和园林局关于部分领导工作分工调整的通知（穗林业园林通[2017]191号）

局机关各处室、局属各单位：

经研究决定，局部分领导工作分工调整如下：

张岳炎专职副总指挥负责森林防火、安全生产、保卫、平安创建、消防及综合治理、维稳工作。分管森林防火处（保卫处、广州市森林防火指挥部）。

黄昭谷巡视员协助张岳炎同志工作，完成局领导交办的其它工作。

其他局领导工作分工不变。

广州市林业和园林局

2017年4月24日
