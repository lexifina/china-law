# 广州市发展改革委关于执行低收入居民消费性减免和补贴政策的通知

各区发改局、开发区市场监管局，广州供电局有限公司，市自来水公司，各燃气企业，广州珠江数码集团有限公司：

根据《广州市人民政府办公厅关于印发低收入居民消费性减免和补贴政策的通知》（穗府办规〔2017〕6号）的要求，我市有关低收入居民消费性减免政策出现调整。请各相关单位严格遵照执行。

附件：广州市人民政府办公厅关于印发低收入居民消费性减免和补贴政策的通知

广州市发展和改革委员会
