# 广州市发展改革委转发广东省发展改革委关于做好政府出资产业投资基金信用信息登记工作的通知

各区政府，市工业和信息化委、市科技创新委、市财政局、市国资委、市金融局、市知识产权局，广州越秀集团、广州金控集团、广州国发集团、广州基金：

现将《广东省发展改革委关于做好政府投资基金信用信息登记工作的通知》（粤发改财金函〔2017〕1955号）转发给你们，请遵照执行。请你单位按照通知要求，认真督促各政府出资产业投资基金管理人做好信用信息登记工作。
