# 广州市农业局办公室转发广东省农业厅关于进一步做好家禽集中屠宰冷链配送和生鲜上市有关工作的通知

各区农业行政主管部门，越秀区食品药品监督管理局，市动物卫生监督所、市畜禽屠宰管理执法支队：

现将广东省农业厅关于进一步做好家禽集中屠宰、冷链配送和生鲜上市有关工作的通知粤农办〔2017〕317号转发给你们，请按照要求切实做好我市家禽集中屠宰冷链配送生鲜上市有关工作。

广州市农业局办公室

2017年6月20日
