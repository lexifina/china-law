# 广州市农业局广州市财政局关于印发2018年度广州市农业产业化贷款贴息项目申报指南的通知

各区农业局、财政局，市属各有关单位：

根据《广州市农业局广州市财政局关于印发广州市农业产业发展专项资金管理办法的通知》（穗农规字〔2017〕2号）有关要求，我市制定了《2018年度广州市农业产业化贷款贴息项目申报指南》，现印发给你们，请按要求认真组织项目申报工作。2018年度贴息期间为2016年7月1日至2017年6月30日，请于2017年7月10日前将纸质材料（一式两份）报送给市农业局发展计划处，并同步进行网上申报。

广州市农业局 广州市财政局

2017年5月19日
