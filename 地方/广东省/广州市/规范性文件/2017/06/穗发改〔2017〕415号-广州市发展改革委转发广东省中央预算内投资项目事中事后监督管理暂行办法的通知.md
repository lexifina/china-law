# 广州市发展改革委转发广东省中央预算内投资项目事中事后监督管理暂行办法的通知

各区发展改革局：

现将《广东省中央预算内投资项目事中事后监督管理暂行办法》（粤发改规〔2017〕3号）转发给你们。按照“谁安排、谁负责、谁监管、谁督促整改”的原则，为进一步压实责任，做好中央预算内投资项目管理工作，现结合我市实际情况，提出以下意见，请一并贯彻实施。

一、明确职责，压实工作责任

市、区发展改革部门业务处（科）室负责对本处（科）室下达、分解的中央预算内投资项目进行日常监管，实行线上监管和线下监管相结合。利用线上监管动态掌握所下达投资计划的执行进度、工程建设进展情况，加强跟踪分析和实时调度；线上发现异常情况要及时到项目现场核实，发现问题及早解决。要加强项目现场检查和指导服务，按照国家和省对中央预算内投资项目开工时间、投资进度要求协调推进项目建设；要督促项目单位严格按照批准的规模和内容进行建设，不得擅自变更建设规模和内容；要促进项目规范建设，确保中央预算内投资资金专款专用，提高资金使用效益。

市稽察办、区发展改革部门承担稽察职责的处（科）室分别负责对市和区中央预算内投资项目进行在线监测、跟踪分析和常态化监督；负责综合汇总全市（区）中央预算内投资项目总体情况及共性问题，提出工作建议及时向领导报告；要加强与省稽察部门的协调沟通衔接，配合做好国家和省对我市中央预算内投资项目检查工作。在项目监督中发现的问题，要及时反馈给相关业务处（科）室跟进处理。

二、分级管理，强化信息填报

建立健全项目单位、区和市发展改革部门的三级信息填报管理机制。区级项目由区发展改革部门业务科室负责联系督促项目单位及时填报项目信息，并在系统上对项目信息及时做好初审和审核工作，上报省发展改革终审；市级项目由市发展改革部门业务主管处室负责联系督促项目单位及时填报项目信息，并在系统上对项目信息及时做好初审和审核工作，上报省发展改革终审。市、区发展改革部门要明确项目信息填报审核管理责任人，落实项目信息填报初审和审核责任，确保数据报送完整、准确和及时。对数据填报不完整、不真实的项目，由信息填报审核管理责任人约谈项目单位督促整改，情节严重的提请上级相关部门收回中央预算内资金。

广州市发展和改革委员会

2017年6月6日
