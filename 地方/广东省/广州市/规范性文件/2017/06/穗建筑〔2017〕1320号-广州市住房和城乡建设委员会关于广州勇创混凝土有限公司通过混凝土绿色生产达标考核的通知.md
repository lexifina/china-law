# 广州市住房和城乡建设委员会关于广州勇创混凝土有限公司通过混凝土绿色生产达标考核的通知

各有关单位：

根据《关于预拌混凝土企业绿色生产达标考核工作有关事项的通知》(穗建筑〔2014〕891号)，广州市散装水泥管理办公室组织考核小组考核，广州勇创混凝土有限公司达到绿色生产标准，通过绿色生产达标考核(通过时间以考核小组考核通过时间为准)。

希望达标企业继续高标准加强绿色生产管理，不断提高预拌混凝土产品质量和绿色环保水平。

全市其他混凝土生产企业要高度重视绿色生产达标考核工作，抓紧实施绿色环保改造，力争早日通过绿色生产达标考核。

广州市住房和城乡建设委员会

2017年6月27日
