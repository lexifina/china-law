# 广州市住房和城乡建设委员会关于征询广州市城市公共基础设施项目（万顷沙—广州东站）工程建设通告相关意见的通知

各有关单位：

为加快推进广州市城市公共基础设施项目(万顷沙—广州东站)工程建设，我委草拟了《广州市城市公共基础设施项目(万顷沙—广州东站)工程建设通告》(征求意见稿)，现就该通告在网上向社会各界征求意见，期限为：2017年7月17日至2017年7月31日。欢迎广大市民、专家、学者提出宝贵意见，可于2017年7月31日前通过信函、传真或网络邮件方式反馈意见至广州市住房和城乡建设委员会。
