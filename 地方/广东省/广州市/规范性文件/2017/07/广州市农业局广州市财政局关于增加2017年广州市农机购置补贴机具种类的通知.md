# 广州市农业局广州市财政局关于增加2017年广州市农机购置补贴机具种类的通知

各区农业（农机）主管部门、财政局，番禺区农业技术推广管理办公室：

为适应我市都市型现代农业发展的要求，提高广大农（渔）民和农业生产经营组织（农业企业、农机专业合作社、农机大户等）的购机积极性，切实落实我市农机购置补贴政策，根据《广州市农业局广州市财政局关于印发广州市农业机械购置补贴实施方案的通知》（穗农〔2016〕125号）、《广州市农业局办公室关于启动市农机购置补贴增加机具种类范围工作的通知》（穗农办〔2016〕164号）文件精神，现确定2017年市农机购置补贴增加机具种类18项，详见《2017年广州市农业机械购置补贴增加机具种类一览表》（附件）。此次增加的机具种类目录是在市场调查、广泛听取农户和农业生产经营组织意见建议、向社会公开征集、各区推荐的基础上，按我市增加机具目录的条件要求提出来的，机具的定档参照《2016年广东省财政农机购置补贴机具补贴额一览表》确定，机具补贴额标准为省补贴额的1．2倍，并已公示无异议。增加机具种类目录列入市财政农业机械购置补贴范围。请你们按照我市农业机械购置补贴实施方案的要求，切实做好我市农业机械含新增机具购置补贴各项工作。本通知自印发之日起实施。附件：2017年广州市农业机械购置补贴增加机具种类一览表广州市农业局广州市财政局2017年7月26日（市农业局联系人：伍俊杰，联系电话：86374625；市财政局联系人：杨晓颖，联系电话：38923578）
