# 广州市发展改革委转发省发展改革委关于印发2017年度省双创示范基地申报指南的通知

各区发展和改革局、天河软件园管委会：

现将《广东省发展改革委关于印发2017年度省双创示范基地申报指南的通知》（粤发改创新函〔2017〕3564号）转发给你们，请按通知有关要求，组织开展区域型和企业示范基地申报工作，并于7月25日前，将申报材料反馈至我委（高技术处），同时将电子版发送至gjsc＠gz．gov．cn。

专此
