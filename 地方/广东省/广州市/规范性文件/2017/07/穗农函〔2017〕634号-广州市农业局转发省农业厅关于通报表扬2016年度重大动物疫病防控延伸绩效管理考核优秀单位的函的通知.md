# 广州市农业局转发省农业厅关于通报表扬2016年度重大动物疫病防控延伸绩效管理考核优秀单位的函的通知

穗农函〔2017〕634号

关于通报表扬2016年度重大动物疫病防控延伸绩效管理考核优秀单位的函的通知

各区农业局，越秀区食品药品监督管理局，市动物卫生监督所：

现将省农业厅《关于通报表扬2016年度重大动物疫病防控延伸绩效管理考核优秀单位的函》（粤农函〔2017〕669号）转发给你们。广州市农业局被评为2016年度重大动物疫病防控延伸绩效管理考核优秀单位，这是全市各级农业主管部门和动物卫生监督机构群策群力、踏实工作的成果。特别是白云区农业局，白云区动物卫生监督所，代表我市接受实地检查，工作扎实细致，为我市获得荣誉做出了突出贡献。希望各单位再接再厉，发扬成绩，提升水平，以更加饱满的热情，做好今年重大动物疫病防控绩效管理工作。

广州市农业局

2017年6月30日
