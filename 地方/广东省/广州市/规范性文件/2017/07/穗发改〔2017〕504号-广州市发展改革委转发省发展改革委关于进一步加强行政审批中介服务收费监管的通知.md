# 广州市发展改革委转发省发展改革委关于进一步加强行政审批中介服务收费监管的通知

各区发展改革局：

现将《广东省发展改革委关于进一步加强行政审批中介服务收费监管的通知》（粤发改价格函〔2017〕3415号）转发给你们，请遵照执行。各区发展改革局要严格按照通知规定，将收费目录清单发布情况和清理规范工作总结形成书面材料，于7月20日前报送我委。

广州市发展和改革委员会

2017年7月6日
