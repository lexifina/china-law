# 广州市发展改革委转发国家粮食局关于认真做好2017年粮食收购监督检查工作的通知

各区发展改革局（粮食局）：

现将省粮食局《转发国家粮食局关于认真做好2017年粮食收购监督检查工作的通知》（粤粮监〔2017〕124号）转发给你们，请结合地方实际抓好贯彻落实，做好2017年粮食收购监督检查及“两个安全”的宣传贯彻工作，确保粮食收购、储存、生产安全。请辖区内有粮食收购行为的区级粮食行政管理部门，按照省粮食局文件要求，分别从7月18日、11月3日起，将粮食收购进度以五日报送形式报市发改委粮食处；分别于9月27日、12月7日前，将辖区内夏粮、秋粮收购监督检查工作总结及《2017年夏（秋）粮收购监督检查情况汇总表》（见转发文附件）报市发改委粮食处。

广州市发展和改革委员会

2017年7月10日
