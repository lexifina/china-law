# 广州市发展改革委关于不再办理商品房屋建设备案项目招标核准的通知

各有关单位：

为落实《广州市人民政府关于建设工程项目审批制度改革的实施意见》（穗府〔2017〕9号）等文件精神，大力推进简政放权、放管结合，优化服务改革，现就我市企业投资商品房屋建设项目招标核准问题通知如下：

一、市（区）发展改革部门不再审核企业投资商品房屋建设项目招标事项（招标范围、招标方式、招标组织形式）。

二、在我市范围内，企业投资商品房屋建设项目由项目单位依法自行确定招标范围、招标方式和招标组织形式。

三、项目单位应依法将企业投资商品房屋建设工程发包给具备相应承接资质条件的承包单位，对承包单位的选择承担相应法律责任，并应依法依规办理后续质量监督管理手续，确保工程质量安全。

本通知自印发之日起实施。

广州市发展和改革委员会

2017年7月11日
