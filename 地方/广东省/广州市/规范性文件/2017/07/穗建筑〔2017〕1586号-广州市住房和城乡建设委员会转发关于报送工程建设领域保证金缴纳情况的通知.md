# 广州市住房和城乡建设委员会转发关于报送工程建设领域保证金缴纳情况的通知

市建筑业联合会，各相关企业：

为贯彻落实国务院和住建部关于规范清理工程建设领域保证金的工作要求，现将《住房城乡建设部办公厅关于报送工程建设领域保证金缴纳情况的通知》(建办市函〔2017〕460 号)转发给你们，请遵照执行：

一、请注册地在本市的建筑企业(不含中央建筑企业)(附件1)认真填写《工程建设领域保证金信息报送工作联系表》(附件2),按《工程建设领域保证金缴纳情况统计表》(附件3)统计填写2016年全年和2017年上半年工程建设领域保证金缴纳情况，于8月2日前将联系表和统计表报送给广州市建筑业联合会(电子版请同时发至：1043457592@qq.com)。从2017年第三季度起，于每季度结束后的 2 日内向市建筑业联合会报送《工程建设领域保证金缴纳情况统计表》。

二、委托市建筑业联合会汇总统计全市建筑企业工程建设领域保证金缴纳情况，市建筑业联合会于2017年8月4日前将汇总的《工程建设领域保证金缴纳情况统计表》报送我委建筑业管理处(电子版请同时发至：jgc@gzcc.gov.cn)。从2017年第三季度起，每季度结束后 4 日内向我委报送书面报告和《工程建设领域保证金缴纳情况统计表》。

三、请各有关单位要高度重视工程建设领域保证金缴纳情况的报送工作，认真部署，落实责任，确保上报数据及时、准确、真实。

特此通知。
