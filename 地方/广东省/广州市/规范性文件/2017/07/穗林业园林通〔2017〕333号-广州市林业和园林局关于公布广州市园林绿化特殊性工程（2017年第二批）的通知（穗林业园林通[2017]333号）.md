# 广州市林业和园林局关于公布广州市园林绿化特殊性工程（2017年第二批）的通知（穗林业园林通[2017]333号）

各有关单位：

为全面提升我市园林绿化品位和景观效果，着力打造绿色生态景区精品建设，根据《广州市工程建设项目招标投标管理办法》（穗府办规〔2017〕5号），经研究，现公布广州市白云山风景名胜区管理局负责建设的白云山山南游览区域品质化提升改造工程为特殊性工程。请各有关单位严格按照法律法规和基本建设程序开展工作。

特此通知。

广州市林业和园林局

2017年7月7日
