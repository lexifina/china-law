# 市金融局关于同意广州市聚富小额贷款有限公司变更公司名称的批复

越秀区金融局：

你局《关于广州市聚富小额贷款有限公司变更公司名称的请示》（越金融〔2017〕200号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定。经审核，现批复如下：

一、同意“广州市聚富小额贷款有限公司”将公司名称变更为“广州市聚富互联网小额贷款有限公司”。

二、请你局督促广州市聚富小额贷款有限公司根据本批复修改公司章程，并自批复之日起30个工作日依法向工商部门办理名称变更手续。

三、广州市聚富小额贷款有限公司完成名称变更后，你局应按照相关政策规定的要求，进一步加强对该公司的管理与服务，督促该公司合规经营并做好风险防控工作。

广州市金融工作局

2017年8月24日

公开方式：主动公开

抄送：省金融办，广州市聚富小额贷款有限公司。
