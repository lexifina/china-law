# 广州市海洋与渔业局转发省海洋渔业厅办公室转发国家海洋局关于印发《建设项目用海面积控制指标（试行）》的通知

黄埔区农林局、番禺区海洋渔业局、南沙区海洋渔业局、增城区农业局：

现将省海洋渔业厅办公室《转发国家海洋局关于印发〈建设项目用海面积控制指标（试行）〉的通知》（粤海渔函〔2017〕748号）转发给你们，请认真贯彻执行。要加强政策宣传，做好与相关部门的沟通衔接，严把用海审查关，集约节约利用海域。政策执行中的经验和问题，请及时总结反映。

广州市海洋与渔业局

2017年8月8日
