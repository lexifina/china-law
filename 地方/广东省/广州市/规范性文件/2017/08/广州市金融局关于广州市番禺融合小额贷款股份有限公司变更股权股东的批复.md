# 广州市金融局关于广州市番禺融合小额贷款股份有限公司变更股权股东的批复

番禺区发改局：

《番禺区发展和改革局关于广州市番禺融合小额贷款股份有限公司变更主发起人及股权股东的请示》（番发改〔2017〕32号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）、《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）以及《关于同意广州市番禺融合小额贷款股份有限公司变更主发起人备案的通知》（粤金贷复〔2017〕31号），经审核，现批复如下：

一、同意广州市番禺融合小额贷款股份有限公司自然人股东刘瑞辉、江绍强和冯毅将分别持有的6%、10%和4%，合计20%的股份转让给广东自由鸟服装有限公司；同意自然人股东冯毅将持股的2%的股份转让给黎倩嫔；同意自然人股东蒋伟楷将持有的5%的股份转让给彭颖茹。本次股权转让后，广东自由鸟服装有限公司持有广州市番禺融合小额贷款股份有限公司20%的股份、刘瑞辉持有10%的股份、彭颖茹持有5%的股份、黎倩嫔持有4%的股份，冯毅、江绍强和蒋伟楷不再持有广州市番禺融合小额贷款股份有限公司任何股份。

二、请你局通知广州市番禺融合小额贷款股份有限公司自批复之日起依法向工商部门办理公司章程变更备案。

三、广州市番禺融合小额贷款股份有限公司完成股权股东变更后，你局应按照相关政策规定的要求，进一步加强对该公司的管理与服务，督促该公司合规经营并做好风险防控工作。

广州市金融工作局

2017年8月14日

公开方式：主动公开

抄送：省金融办，广州市番禺融合小额贷款股份有限公司。
