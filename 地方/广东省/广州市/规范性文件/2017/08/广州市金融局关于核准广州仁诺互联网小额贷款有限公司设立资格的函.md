# 广州市金融局关于核准广州仁诺互联网小额贷款有限公司设立资格的函

越秀区政府：

你区2017年3月17日报来《关于申请在广州民间金融街设立广州海印互联网小额贷款有限公司等的函》收悉。根据《广东省小额贷款公司管理办法（试行）》（粤金〔2009〕10 号）等规定以及《关于广州民间金融街三期小额贷款公司设置等事项的批复》（粤金贷复〔2013〕13号）、《关于支持电子商务企业在广州发起设立互联网特色小额贷款公司有关事项的意见》（粤金贷复〔2014〕7号）等精神，经广州民间金融街小额贷款公司准入审核委员会审核通过及省金融办《关于同意广州仁诺互联网小额贷款有限公司设立资格备案的通知》（粤金贷复〔2017〕49号）备案同意，现核准广州仁诺互联网小额贷款有限公司设立资格。有关事项函复如下：

一、广州仁诺互联网小额贷款有限公司是由广东国盛金控集团股份有限公司主发起设立，依托互联网面向广大中小微企业、商户、个人等提供融资等服务的具有企业法人资格的有限责任公司。

二、广州仁诺互联网小额贷款有限公司注册资本为人民币1亿元，其中主发起人广东国盛金控集团股份有限公司持股45%、深圳市加德信投资有限公司持股27.5%、西藏家家乐购信息技术有限公司持股15%、自然人吴鹰持股12.5%，全部为实收货币资本，由出资人一次性缴足；法定代表人为张巍；住所为广州民间金融街。

三、核准广州仁诺互联网小额贷款有限公司业务范围为：

（一）办理各项小额贷款；

（二）其他经批准的业务。

四、请你区督促广州仁诺互联网小额贷款有限公司落实营业场所，做好营业场所消防及安全验收，依法向公安、工商和税务等部门办理相关手续，并安装广东省小额贷款公司非现场监管系统及在经营场所明显位置挂设市区两级监管部门举报电话牌。

五、请你区督促广州仁诺互联网小额贷款有限公司在2017年10月31日前完成开业筹建工作，并由你区相关部门正式发文至我局提请验收，经我局检查合格后下发准予开业通知书。

六、请你区认真落实监管部门和人员，切实做好对广州仁诺互联网小额贷款有限公司的监督管理和服务工作。

广州市金融工作局

2017年8月24日

公开方式：主动公开

抄送：省金融办，广州仁诺互联网小额贷款有限公司。
