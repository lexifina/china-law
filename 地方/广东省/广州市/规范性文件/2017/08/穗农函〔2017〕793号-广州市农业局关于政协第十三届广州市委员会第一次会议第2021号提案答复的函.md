# 广州市农业局关于政协第十三届广州市委员会第一次会议第2021号提案答复的函

穗农函〔2017〕793号

关于政协第十三届广州市委员会第一次会议第2021号提案答复的函

付伟委员：

您提出的《让农产品电商真正成为农户增收加速器》（第2021号）提案收悉，您的建议具有较强的针对性，所反映的问题比较客观中肯，提出的建议切合实际，对加快农民增收、转变农业发展方式、驱动我市农业提质增效很有价值。我市政府高度重视，积极组织市农业局、商务委、工信委等单位进行认真研究办理，并与您在5月2日、7月27日进行了座谈交流，经综合市商务委、工信委等会办单位意见，现将办理有关情况答复如下：

一、我市农产品电商发展情况

（一）加强总体规划与政策引导。市商务委出台了《关于全市电子商务与移动互联网集聚区总体规划布局的意见》，明确在从化区规划建设农村电子商务产业园；指导从化区制定并出台《从化市加快农村电子商务发展实施方案》，全面优化从化区农村电子商务发展环境。

（二）加强应用，为农村电子商务构建新型支撑体系。建设广州市农产品电商信息发布平台，为全社会提供农业信息共享服务。目前，我市建有广州农业信息网、华南农产品电子商务交易、广州智慧乡村供求等三大农业信息发布平台，以及新建的广州市农业电子商务协会农产品信息展示平台、广州市农业龙头企业协会农产品信息发布平台，为全社会提供农业政策信息、农产品产销信息对接、智慧乡村管理、网上政务办事大厅等服务。截至2017年6月，华南农产品交易网发布批发市场价格信息795634条，零售市场价格信息790656条，市场行情信息、供求信息共47000多条。积极推动电子商务公共服务平台发展，培育了若羽臣、青木科技、云图电商等电子商务代运营平台重点企业，借助代运营平台或龙头第三方平台，加强电商宣传，加快提升我市农产品电商品牌建设、营销策划水平；同时，引导本土农村电商企业、苏宁、阿里巴巴、京东等电商平台与从化、增城等区开展产销对接，推动农产品电子商务发展壮大。支持汇通宝等第三方信息和电子交易服务平台发展，完善物流、支付、服务、安全认证等支撑服务。

（三）强化组织，为农业电子商务构建新型交流平台。2014年，在市农业局的指导下，经市民政主管部门的审批许可，成立了广州市农业电子商务协会。协会现有正式注册会员单位40多家,发展至今，整合了一批集软件开发、信息技术服务、融资信贷、农业种养、农产品加工、交易服务、农业装备配置、食品研究、餐饮管理、电商运营、电商人才培训、物流配送等多个涉及农业电子商务领域的资源，形成农产品电商交流平台，为我市提升农业电子商务服务水平、完善农产品电商平台服务功能、协助农产品经营主体构建农业电商体系提供助力。协会搭建了广州市农业电子商务联盟微信群、广州市农业电子商务联盟微信群QQ群等交流对接平台，有200左右个成员，成员包括市、区农业部门，省市电子商务协会，农业企业，农业专业合作社，专家学者,电商，创客，微商，网络信息技术公司，咨询公司、品牌策划公司等。

（四）典型引领，为农产品电商产业发展树立标杆。我市自2015年起，先后认定了省级惠农信息社39家、省级名特优新农产品电商体验馆12家、市级农业电商示范企业6家，其中1家推荐为省级农业电商示范企业。培育广东苏宁云商销售有限公司、广东云图电子商务有限公司等8个省级农产品电商示范企业。支持农业龙头企业应用电子商务拓展销售渠道，培育出青怡农业、十五分钟等一批农产品电子商务企业。推动清香农产、谭山蜂业等一批农业龙头企业应用电子商务开展线上销售。强化农民合作社市场营销服务，推进“农超”、“农校”、“农企”、“社企”、“农市”等产销对接，建设冷链物流和信息网络系统，对合作社在设立创办、建设营销网络、提供培训服务、申报农产品质量标准认证、建立农产品包装和标识制度等方面给予扶持；鼓励和支持合作社为社员提供培训服务。促进社员实施品牌战略，树立电商思维。

二、存在问题

目前，我市农产品电商发展过程中存在以下问题：

（一）散小农户居多，难以形成规模化、标准化生产。据不完全统计，目前我市散小农户有30多万户，分散于全市10个涉农区，面积超过100亩以上的菜场只有178个，其他97％以上都是种植面积在5亩以下的散小农户。同时，散小农户整体年龄结构偏大、文化偏低，缺乏科学种养意识，生产操作往往凭经验，随意性较大。农业标准化程度不够，导致同样的区域性产品，农产品质量参差不齐。对消费者，难以保证相同的购物体验。

（二）物流配送成本较高，企业盈利较少。大多数农产品保鲜期短，对物流的包装和运输时间都有着比较高的要求，农产品电商企业就需要采用专业的运输技术手段，在冷藏库、冷藏车的建设上投入大量成本，运输成本占了运营成本的25%--30%，再加上农产品附加值较低，配送呈现多点次的特征，这就在很大程度上拉低了企业的利润，农产品物流成本居高不下，运输成本相对于本身价值较为低廉的农产品来说较高，成为我市农业产业全面电子商务化的障碍。

（三）电商人才欠缺，运营能力不强。由于企业的领导对电子商务的认知层面不同，直接造成企业在电商发展方面存在不同的差异。企业的电商运营团队在电商的技能运用上都存在着比较落后的现象，没有专业的培训，他们对电商的技能认知只达到初步阶段（基本只运用在推广宣传方面）。招聘电商专业人才比较困难，大部分涉农企业都设立在郊区，当地的劳动力都偏向城市里发展，造成企业招聘难的现象。而从现阶段的企业调研来看，企业涉农电子商务网站“信息孤岛”现象、网站运营能力不足的现状，真正缺乏的不是软硬件、物流等设施、设备，而是专业的网上运营人才。

（四）消费观念有待提升，农产品标准化建设难度大。部分消费者对农产品在观念上还是存在一定认识误区，普遍认为线下看得到摸得着的产品才使消费者更加安心购买。农产品尤其是鲜活农产品在标准化方面存在先天不足，农产品品类繁多，产品的生产受自然条件影响较大，外观和内在质量及口感、风味差别大，而品质评价的主观因素较强，行业内也缺少统一的要求，因此给网络交易带来很大困难，使得农产品电子商务的推广应用比其它行业要困难得多。

三、下一步工作计划

（一）加大政策扶持力度，培育农产品电商经营主体。依据《国务院办公厅关于促进农村电子商务加快发展的指导意见》（国办发〔2015〕78号）的指导精神,充分发挥现有市场资源和第三方平台作用，培育多元化农村电子商务市场主体，鼓励电商、物流、商贸、金融、供销、邮政、快递等各类社会资源加强合作，构建农村购物网络平台，实现优势资源的对接与整合，参与农村电子商务发展；继续开展惠农信息社、电商体验馆、电商示范企业的评定工作，鼓励及扶持一批农产品经营主体积极开展电子商务渠道建设；指导和支持农业龙头企业、农民专业合作社等对接电商平台，鼓励“三品一标”、“一村一品” 农产品上网销售。

（二）多平台整合，促进农产品的信息发布、推广和交易。以我市三大农业信息发布平台为枢纽，引进苏宁广州馆、淘宝广州馆等第三方电子交易平台，鼓励和吸引农业龙头企业、农民专业合作社借助第三方电商平台，开展农产品销售活动；鼓励种植大户、家庭农场等农业经营主体通过网络获取和发布市场信息；鼓励和引导大学生村官、回乡创业青年建立惠农信息服务点，开展网上代购代销服务。充分发挥广州中心城市的核心优势，结合广州市农产品博览会，开设广州市农产品博览会网上展销平台，将广州市名特优新农产品汇聚展销，实现线上下单现场提货的O2O购物方式，让农村电商搭上互联网的快车，让城里乡间共享“互联网+农业”带来的成果。

（三）构建农业电商人才培训体系。结合我市实际情况，开展农业电子商务师资队伍建设，整合一批专业素质强、农村基层工作经验丰富的电商培训人才，设立农村电商讲师团；根据国家农业部、省农业厅关于推动农村电商发展的工作要求，结合我市实际情况，开展农村电商培训工作，储备农村电商人才，通过有针对性定制式电商培训，进一步提升我市农民对电子商务的网络认知能力，普及农产品电子商务知识与技能；探索适合农村发展的农业电商人才服务模式。充分发挥高等院校、培训机构的人才供应能力及资源优势，鼓励探索适合农村发展的农业电商人才服务模式，构建和完善人才供应体系，为农产品电商发展提供人才支撑。

（四）充分利用行业协会、社会组织的作用，强化我市农业电子商务配套服务功能。支持广州市农业电子商务协会发展，充分发挥其政企沟通交流纽带作用，推动农产品与电子商务融合发展。通过协会整合广州市农业电商资源，开展多媒体、多渠道的网络信息平台建设及推广，打造广州地区集“农村电商舆情监测、农产品市场行情分析、‘互联网+农业’研究”的专业化平台，提供农业电商政务咨询服务、农村电商项目规划、农业电商培训等服务，提升农业电商行业的凝聚力，优化广州市农业电商发展环境，强化我市农业电子商务配套服务功能。

（五）推进农业规模化、标准化生产。一是加快土地确权，推进土地流转，推进规模化生产。我市已集中人员、精力开展农村土地确权工作，确保2017年底完成确权颁证85%以上的目标任务，推进农村土地流转，促进规模化、现代化农业生产。二是通过发展农民专业合作社，提高基层农户的组织化程度，充分发挥合作社的服务功能，推行统一采购供应生产资料、统一技术培训、统一生产标准、统一包装、统一品牌、统一销售的运营模式，提升农产品质量安全水平。三是加大农产品质量安全监管力度，加快农产品质量安全监管体系建设，落实解决农产品质量“最后一公里”难题，保证农产品安全、优质。

（六）加强物流体系建设，积极发展现代农产品流通业。制定《广州市商务发展专项资金电子商务与商贸物流事项实施细则》，将农村电商项目纳入扶持范围。规划建设线上线下融合的农村电子商务产业园、乡镇电子商务创业中心和孵化基地等集聚区。建设支撑农产品电商发展的物流网络体系，提高物流标准化水平，加快农村电商物流发展，加快生鲜农产品物流建设，加大对农产品冷链物流基础设施建设和市场主体培育的政策扶持力度，加大农产品电商物流点覆盖，确保生鲜农产品依托互联网实现快速、充足、有序流通。

感谢您对我市农产品电商工作的关心和支持，欢迎您继续对我们的工作提出宝贵意见和建议。

广州市农业局

2017年8月16日
