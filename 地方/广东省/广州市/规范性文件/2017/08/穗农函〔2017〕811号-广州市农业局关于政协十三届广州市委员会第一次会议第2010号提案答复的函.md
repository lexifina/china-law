# 广州市农业局关于政协十三届广州市委员会第一次会议第2010号提案答复的函

穗农函〔2017〕811号

关于政协十三届广州市委员会第一次会议第2010号提案答复的函

张瑞贤委员：

您提出的《关于水产养殖可持续发展的建议》（第2010号提案）收悉，我市政府高度重视，积极组织市农业局等单位进行认真研究办理，并与您在8月14日进行了座谈交流，经综合市财政局等会办单位意见，现将办理有关情况答复如下：

一、广州市水产养殖扶持政策情况

2017年2月，《中共广州市委办公厅 广州市人民政府办公厅关于印发<广州市发展都市现代农业三年行动计划（2016-2018年）>的通知》（穗办〔2017〕2号，下称《三年行动计划》）提出我市要践行“创新、协调、绿色、开放、共享”发展理念，推进农业供给侧结构性改革，把增加绿色优质农产品供给放在突出位置，加快转变农业生产经营、资源利用和管理方式，推动农业发展由数量增长为主转到数量质量效益并重上来，由主要依靠物质要素投入转到依靠科技创新和提高劳动者素质上来，由依赖资源消耗的粗放经营转到可持续发展上来，推动我市农业向产出高效、产品安全、资源节约、环境友好的现在农业、精品农业、特色农业方向发展。渔业是我市农业的优势产业之一，以水产养殖为主，大力发展水产养殖业，是我市发展都市现代渔业、都市现代农业的重要内容之一。《三年行动计划》明确了我市水产养殖业的主要任务是以供给侧结构性改革为目的，重点推行水产健康养殖模式，建设现代渔业园区，建设鱼塘、越冬棚、设施鱼池和工厂化车间等基础设施，推进政策性水产保险对我市水产养殖的全覆盖等。

2017年，我局联合市财政局印发实施《广州市农业产业发展专项资金管理办法》《2018年度广州市农业产业化贷款贴息项目申报指南》，开展2018年度农业产业化贷款贴息项目申报工作，加大对优秀农业龙头企业的差异化扶持力度；修订并印发《广州市级农业龙头企业认定和运行监测管理办法》《广州市农业局关于开展广州市农业龙头企业申报的通知》，组织各区开展市级农业龙头企业申报工作；草拟《广州市关于发展都市现代农业奖励办法（征求意见稿）》，正在第二次征求市财政局意见，拟对我市龙头企业、示范合作社、家庭农场等新型经营主体，及取得国家、省、市相关荣誉的农业生产单位给予一定的奖励；联合市财政局印发实施《广州市农田、鱼塘基本建设工作实施方案》，到2020年底，按5000元/亩补助标准，完成我市1.5万亩鱼塘基本建设或改造;制定印发了《广州市农民专业合作社扶持项目财政补助方案》，正在起草《广州市示范家庭农场评定、监测和奖励暂行办法》，采取一系列行之有效的扶持和引导措施，促进新型农民专业合作组织和家庭农场的发展壮大。

2017年，市财政安排政策性农业保险保费800万元，首先推出的是政策性水产保险；安排农业产业化贴息及担保贷款贴息资金2091.33万元，对符合条件的农业企业银行贷款进行贴息，帮助农业企业解决融资难问题，扶持农业企业发展壮大；积极落实《三年行动计划》有关任务，扶持渔业设施建设，2017年下达市财政“菜篮子”专项资金5000万元，主要用于种业、畜牧、渔业扶持项目，各区正着手确定扶持项目；2016～2017年，市财政安排鱼塘建设资金5529.5万元，用于升级改造一批鱼塘。

二、加快落实政策性水产养殖保险

《三年行动计划》要求到2018年实现农业保险政策对我市主要农业产业的全覆盖。为落实该项任务，2017年，我局将以政策性水产保险为突破口，首先实现对全市水产养殖业的全覆盖：2月份我局多次召开座谈会调查了解保险需求，3月份制定了政策性水产保险工作方案初稿，发各区政府和有关市直部门征求意见。根据反馈意见修改方案后，我局联合市财政局、金融局向市政府发文请示；7月份获市政府批复同意在全市开展政策性水产养殖保险，目前正拟定需求公开招标采购保险经营机构。

政策性水产养殖保险方案试点范围为养殖面积10亩以上的水产养殖品种（虾、蟹类水产品种除外）。保险责任包括：因暴雨、暴风、台风、龙卷风、洪水、雷击直接造成保险水产的死亡，或者造成增氧机、水泵等不工作发生缺氧间接造成水产死亡；以及因此发生的溃坎、漫坎，致使保险水产逃逸；连续低温天气造成保险水产的死亡；因特定疫病造成保险水产的死亡。由于水产养殖品种、养殖密度和养殖周期各不相同，造成各品种植养殖成本差异较大，市级方案参考了番禺区和花都区试点方案，将由各区根据本地区各品种鱼类成本明细表确定保险金额，由承保农户自主选择各类风险责任计算费率。为方便参保农户了解保险金额和保费的计算方法，方案增加了详细的案例。参保水产保险养殖户只需承保保费的20%，各级财政对保费补贴80%。

三、加大培训和宣传力度，提高水产养殖及管理技术

大力发展科技兴渔，依托我市水产技术推广机构体系，通过提供水产养殖技术服务指导、培训、宣传、养殖病害测报等多种途径，努力提高我市水产养殖及管理技术水平。2017年主要工作内容包括：

（一）以为养殖户服务为宗旨，坚持走群众路线，通过加大经费投入、推送水产信息、开展快速服务等多种方式，不断提高水产养殖病害测报与应急水平。一是安排病情调查专项经费19.5万元，用于测报培训、补贴发放和耗材购置，有力提升基层水生动物病害诊断监测能力，保障我市测报平台稳定、有序开展工作。二是发布水产养殖病害预测预报5期、推送水产类农业通130000条次、通过科技入户、举办各类培训班和农业科技下乡活动等，发放技术生产资料1000多份，将水产养殖主导品种、主推技术、病害防治方法等精准到户，拓宽渔民获得科技知识的渠道。三是开展水产快速服务5次，挽回渔民经济损失1000多万元；启动“5.7水灾”应急机制，向受灾养殖户发放价值4万多元的救灾物资一批，全力保障我市水产养殖持续健康发展。

（二）开展养殖试验示范，全面推进水产科技入户工作。引进水产新品种23个，其中主推品种8个、外来水生动物13个、经济龟类2个。引进、示范推广主推技术6项，重点培育水产养殖示范户11户，示范面积4370亩，带动897户，推广面积17750亩。为示范户提供价值22万元的鱼苗、消毒剂、微生物制剂、池底增氧设备等一批示范材料。编写水产类“农业通”手机短信13万条，服务水产养殖户3500户。

（三）加强培训与宣传。一是举办“广州市水产苗种良种质量控制技术培训”、“广州市水产品质量安全生产技术培训”、“2017年水生动物防疫检疫与病害测报工作交流和技术培训”等培训班8期，培训养殖户共558人次，发放“申报点公告”和“检疫告知书”972份，水产品质量安全宣传手册520份，大力宣传水产苗种产地检疫相关法律法规和政策，努力提高水产养殖户法律意识。二是向社会发布“广州市水生动物防疫检疫中心站关于水产苗种产地检疫申报点的公告”，向市级以上水产苗种场发送公告85份，使水产苗种企业了解水产苗种产地检疫申报流程，明确并牢记法定义务，自觉申报水产苗种产地检疫和接受监督。

（四）建立我市农产品质量安全员队伍。《广州市农业局关于印发广州市街（镇）专职农产品质量安全员队伍建设工作方案的通知》（穗农〔2017〕125号），计划在全市97个涉农街（镇）共配备553名安全员。安全员主要职责包括：推广、普及农产品种养技术标准、安全生产技术和操作规程；指导农产品种养过程中规范使用农药、渔药、肥料、饲料及饲料添加剂等投入品；开展对产品农产品质量安全快速检测工作；协助开展农产品质量安全认证、产地准出和质量检测、质量追溯工作；收集、报送产地农产品安全信息；协助开展农产品质量安全法律法规等政策、知识的宣传和培训教育工作；指导农产品生产经营企业和农民专业合作社建立生产经营档案记录等。安全员队伍的建立，有助于进一步扩大农产品质量安全相关政策以及我市惠农政策的宣传和推广力度，有助于提高农产品生产技术指导服务，有助于解决广大养殖户（特别是散、小养殖户）惠农信息获取渠道窄等问题。

四、开拓创新，不断完善我市农机购置补贴政策

按照《广州市农业局广州市财政局关于印发广州市农业机械购置补贴实施方案的通知》（穗农〔2016〕125号）要求，落实市级财政补助资金和政策。农机购置补贴政策实行自主（全额）购机、定额补贴、区级结算、直补到卡（户），补贴机具种类范围为广东省确定的11大类32个小类80个品目。建设并投入运行“广州市农机购置补贴管理系统”，推进补贴管理信息化，进一步简化补贴程序，方便群众办事，提高工作效率。适应我市都市型现代农业发展需要，在各区开展市场调查、广泛听取农户和其他农业生产经营主体意见，并向社会发出公告征集的基础上，比照市补贴目录的条件要求，首次增补市级目录18个，弥补了农户需求与目录之间的空白。今后，我局将继续完善市农机购置补贴政策，把符合农业生产需要、农户需求较为迫切的农机具增补到市补贴目录范围，促进中央农机购置补贴政策在广州的“稳着陆”。

五、加强水产品产地管理，推进鲜活水产品产销对接

（一）开展食用农产品产地证明试点工作。2017年5月，印发《广州市农业局办公室关于开展食用农产品产地证明试点工作的通知》（穗农办〔2017〕218号），确定2017至2018年6月，在白云区和从化区开展食用农产品产地证明试点工作，试点的农产品主要是蔬菜、食用菌、水果等品种，由试点村和试点企业（合作社）登入广州市农产品质量安全溯源管理平台开具产地证明。试点结束后，将根据试点情况进一步改进完善，争取尽早在全市范围开展全部食用农产品产地证明工作，建立农产品质量安全可追溯制度。

（二）减少流通环节，推进水产品产销对接。为充分保障广大水产养殖户及消费者权益，减少流通环节对水产品销售价格、质量安全等方面带来的负面影响，《广东省海洋与渔业厅 广东省食品药品监督管理局关于开展广东省安全鲜活水产品产销对接监督管理试点工作的通知》（粤海渔〔2017〕122号）明确要建立“产销对接安全水产品创建单位”为核心，以推进安全鲜活水产品“产销对接”为突破口，构建水产品从生产到消费环节的质量安全监管体系，实现水产品源头可追溯、流向可跟踪、信息可查询、责任可追究，在提升水产品质量安全监管能力和水平的同时，维护生产者、经营者和消费者的合法权益。我局与市食药监局正联合商讨建立健全完善水产品追溯管理与市场准入的衔接机制，推动水产品经营单位增强自律意识，更好地树立品牌形象，提高市场竞争力，促进产业提质增效。

六、科学规划，促进我市现代渔业可持续性发展

根据农业部、省海洋与渔业厅的部署，我局正着手修订《广州市水域滩涂养殖规划（2018～2030）》，计划通过充分的调研和论证，在全市范围，科学划分渔业养殖功能区，因地制宜，推广特色养殖品种、养殖模式和养殖技术等，深入推动渔业供给侧结构性改革，推动我市现代都市渔业可持续性发展。现正准备政府采购编制单位，计划2018年6月前完成规划编制并报市政府批准执行。

感谢您对广州渔业可持续发展的关心和支持，欢迎您继续对我们的工作提出宝贵意见和建议。

广州市农业局

2017年8月22日
