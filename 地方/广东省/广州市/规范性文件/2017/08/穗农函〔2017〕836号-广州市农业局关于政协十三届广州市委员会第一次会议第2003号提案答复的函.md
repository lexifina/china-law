# 广州市农业局关于政协十三届广州市委员会第一次会议第2003号提案答复的函

穗农函〔2017〕836号

关于政协十三届广州市委员会第一次会议第2003号提案答复的函

张瑞贤委员：

您提出的《关于发展广州特色农业保险，确保农业持续发展和农村长期稳定的建议》（第2003号）建议收悉，我市政府高度重视，积极组织我局与市财政局、市金融工作局、有关保险公司等单位进行认真研究办理，并与您在8月14日进行了沟通，经综合市财政局、市金融工作局等会办单位意见，现将办理有关情况答复如下：

一、市委、市政府高度重视“三农”保险工作

市委、市政府非常重视政策性农业保险工作，将农业保险作为一项惠民政策贯彻落实。2016年，《中共广州市委 广州市人民政府关于落实发展新理念加强“三农”工作的意见》（穗字〔2016〕12号）第18条“创新农村金融保险服务”明确“扩大农业保险覆盖面、增加保险品种，完善农业保险的保费补贴政策，到2020年实现主导农业产业保险品种全覆盖”。截至目前，我市政策性农业保险已基本覆盖粮食、水果、畜牧等主要产业，下一步将在水产、蔬菜、花卉等产业领域开展政策性农业保险工作。

二、我市农业保险发展取得积极成效

（一）业务规模持续增长，保险覆盖面稳步扩大。我市政策性农业保险从2007年起步,至今已开展17个涉农保险品种,包括 水稻、玉米、花生、甘蔗、马铃薯、奶牛、能繁母猪、渔民、渔船、生猪、家禽、荔枝、龙眼、香蕉、木瓜、农房和森林保险。2016年，承保水稻面积约34万亩，能繁母猪约1.82万头、奶牛0.92万头、玉米0.72万亩、甘蔗1.1万亩、马铃薯800亩、花生72.5亩、农房保险63.27万户、森林面积约257.8万亩，保费总收入约1,994.73万元。2017年上半年承保水果1.35万亩、生猪家禽共187.32万只。2016年，各级财政对我市政策性农业保险保费补贴1,719.84万元，合计已接近保费的86%，提供风险保障147亿元，杠杆效应约855倍，切实发挥了“四两拨千斤”的杠杆作用，也体现了农业保险作为农业生产“稳定器”和农村稳定“缓冲器”的作用。

（二）制定政策性水产保险方案，不断推进政策覆盖。我市2016年水产养殖面积约41.8万亩，年水产品产量48.39万吨，产值约76亿元。水产养殖主要风险包括自然灾害和疾病风险。2017年上半年，我局参考番禺区和花都区试点情况，多次召开座谈会后制订《广州市政策性水产养殖保险试点实施方案》（稿）并向市直有关部门、区政府和保险经营机构征求意见。方案明确“政府推动、市场运作、参保自愿、协同推进”的原则，试点范围为养殖面积10亩以上的水产养殖品种（虾、蟹类水产品种除外）,保险责任包括自然灾害和特定疫病造成水产死亡。各级财政补贴保费80%，由商业保险机构按市场化经营管理。目前市政府已批复方案，很快可以在全市各区实施。

（三）服务体系不断完善，服务能力不断提升。进一步加大产品和服务创新力度，努力探索服务新模式，拓展服务新领域。为服务社会食品安全管理，保障“舌尖上的安全”，积极探索将无害化处理作为保险理赔的前提条件，优化理赔流程，加快形成畜禽保险与无害化处理相互结合、相互促进的运作机制，在增强畜禽饲养业抵制风险能力的同时推进无害化处理。为缓解农业企业和农民专业合作社“融资难、融资贵”问题，我市推出政策性小额贷款保证保险试点，发挥保险担保增信功能，有效放大财政杠杆，覆盖更多的企业，进一步缓解我市农业企业融资难题。

三、下一步工作计划与措施

市委、市政府高度重视政策性农业保险工作，建立了由市农业局、市财政局、市金融局等部门组成的日常联络机制。我市将根据农业供给侧结构性改革和发展实际，响应中央号召，以“扩面、提标、增品”为核心，进一步增加农业保险品种、努力实现我市农业主导产业全覆盖。

（一）优化调整现有保险品种。针对当前个别品种（比如水稻等）的保额无法完全覆盖物化成本的问题，我市将结合省指导意见并结合本地实际开展调查研究，协调财政部门共同优化、调整现有品种的保险金额和费率等。

（二）加快蔬菜、花卉等产业调研，加大广州农业保险创新发展力度。针对蔬菜、花卉等我市主导产业品种还没有在全市范围内开展政策性农业保险工作的问题，我局将结合市委、市政府对“米袋子”“菜篮子”和花卉等产业的发展要求，加快开展保险需求调研，总结试点经验，按产业结构调整方向和“先易后难”的原则，制定蔬菜和花卉等品种的保险实施方案，广泛征求意见后向市政府申请实施。另外，加快研究农产品价格（水产、生猪、家禽批发价）保险，选取部分区先行试点后在全市推广实施。

（三）调研我市农业各类经营主体保险需求，增加多层次的保险产品。近来，各级政府将新型农业经营主体作为支持重点，我局正准备研究制定出台《大力培育和扶持新型农业经营主体的意见》。下一步，将围绕农产品生产、加工、仓储、运输等各环节的风险需求，在现有保险品种之外，由保险公司开发制定精细化、多层次、高保障的保险产品，重点发展特色优势农产品保险、养殖渔业保险、农产品指数保险、设施农业保险等适应广州新型农业经营主体需求的农业保险品种。政府根据不同保险产品提供不同程度的资金补助。

（四）建立健全保险服务体系。按照政策性农业保险需要，为降低农业保险成本，提高保险承保理赔效能，由政府和保险公司共同建立健全市、区、镇、村四级保险服务体系，在农业主产区有农业保险服务中心、主要镇有农业保险服务站、村级有保险服务点，每个服务点都有协保员，保险公司提供培训并提取一定保费收入支付协保员薪酬。

（五）加大各级财政支持力度。加大财政投入，优化调整现有品种的保额以增加保障水平，财政加强各级财政保费补贴资金统筹力度，大力支持政策性农业保险全覆盖，积极协调、研究解决农业重点区保费补贴支出多与当地财政不足的矛盾问题，探索对涉农商业保险实行“以奖代补”的形式等。同时，针对“菜篮子”“米袋子”等不同保险品种提供不同比例的保费奖励或补贴，进一步提高我市农业抵御风险的能力。每年对保险体系建设和运行提供工作经费补助，充分调动农业保险基层服务体系工作人员的积极性。

感谢您对我市农业保险工作的关心和支持，欢迎您继续对我们的工作提出宝贵意见和建议。
