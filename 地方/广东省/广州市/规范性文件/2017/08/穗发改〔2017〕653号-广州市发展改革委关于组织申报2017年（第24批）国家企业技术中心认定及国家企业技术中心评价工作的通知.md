# 广州市发展改革委关于组织申报2017年（第24批）国家企业技术中心认定及国家企业技术中心评价工作的通知

各区发展改革局，天河软件园管委会：

日前，国家发展改革委印发了《国家发展改革委办公厅关于组织开展2017年（第24批）国家企业技术中心认定及国家企业技术中心评价工作的通知》（发改办高技〔2017〕1283号，详见1）。按照国家和省发展改革委要求，请各单位做好以下工作：

一、请各区发展改革局及天河软件园管委会，积极组织辖区内组织辖区内符合条件的企业进行申报并初审，于8月16日前将正式上报文、推荐企业的申请材料（一式四份）及其电子文件（附表用OfficeExcel格式）报送我委（高技术处），以便汇总上报省发改委。

二、请各区发展改革局及天河软件园管委会，积极督促辖区内已认定的各国家企业技术中心所在企业（详见附件2），做好评价材料填报工作，在企业技术中心信息系统认真填报相关材料，并将有关纸质材料（一式两份）于8月21日前报送我委（高技术处）。

专此通知

附件：1．发改办高技〔2017〕1283号

2．我市已认定的国家企业技术中心名单
