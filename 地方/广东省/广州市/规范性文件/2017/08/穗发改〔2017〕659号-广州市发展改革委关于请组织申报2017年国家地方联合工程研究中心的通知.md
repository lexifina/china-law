# 广州市发展改革委关于请组织申报2017年国家地方联合工程研究中心的通知

各区发展改革局、天河软件园管委会：

现将《国家发展改革委办公厅关于请组织申报2017年国家地方联合工程中心方案的通知》（发改办高技〔2017〕1284号，见附件1）转发给你们，请认真组织辖区内符合条件的省级工程研究中心（工程实验室）积极申报并初审（具体名单见附件2），将初审合格的国家地方联合工程研究中心方案（包括相关证明文件）申请表（一式四份，另附电子版光盘），于8月25日前报送我委（高技术处），以便我委综合汇总后上报省发展改革委。

专此通知

附件：1．发改办高技〔2017〕1284号

2．我市已认定的省级工程实验室名单

广州市发展和改革委员会

2017年8月9日
