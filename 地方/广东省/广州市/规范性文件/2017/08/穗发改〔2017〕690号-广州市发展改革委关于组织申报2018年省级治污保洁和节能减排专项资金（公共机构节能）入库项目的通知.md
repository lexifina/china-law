# 广州市发展改革委关于组织申报2018年省级治污保洁和节能减排专项资金（公共机构节能）入库项目的通知

市直有关部门，各区公共机构节能主管部门：

现将《广东省人民政府机关事务管理局广东省财政厅关于组织申报2018年省级治污保洁和节能减排专项资金（公共机构节能）入库项目的通知》（粤府管〔2017〕10号，见附件）转发给你们。请认真对照申报通知要求，组织符合条件的下属单位（所辖区公共机构）进行申报，有关申报材料纸质版一式5份（装订成册并加盖骑缝章）和电子版（刻1张光盘并贴标签）请于8月28日前报送我委资环处。

附件：广东省人民政府机关事务管理局广东省财政厅关于组织申报2018年省级治污保洁和节能减排专项资金（公共机构节能）入库项目的通知
