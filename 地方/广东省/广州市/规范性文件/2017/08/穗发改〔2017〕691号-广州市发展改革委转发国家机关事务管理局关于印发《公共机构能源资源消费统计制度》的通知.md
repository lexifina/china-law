# 广州市发展改革委转发国家机关事务管理局关于印发《公共机构能源资源消费统计制度》的通知

市直各部门，各区公共机构节能主管部门：

现将《广东省人民政府机关事务管理局转发国家机关事务管理局关于印发<公共机构能源资源消费统计制度>的通知》（粤府管〔2017〕11号）转发给你们。请组织下属（本辖区）公共机构认真学习《公共机构能源资源消费统计制度》，切实加强能源资源消费统计工作，确保相关数据填报的准确性和及时性。

广州市发展和改革委员会

2017年8月21日
