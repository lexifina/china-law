# 广州市发展改革委转发电气火灾综合治理工作方案的通知

各区发展改革局（粮食局）、市粮食集团：

现将《广东省粮食局转发省公安厅等七部门关于电气火灾综合治理工作方案的通知》（粤粮监〔2017〕160号）转发给你们，请认真贯彻落实，结合粮食安全生产大检查和夏季消防安全专项检查，切实做好电气火灾综合治理工作，确保不发生电气火灾事故。

广州市发展和改革委员会

2017年8月22日
