# 广州市发展改革委关于印发广州市粮食行业“深化改革转型发展”大讨论活动实施方案的通知

各区发展改革局（粮食局）、市粮食集团：

根据《广东省粮食局关于开展全省粮食行业“深化改革转型发展”大讨论活动的通知》（粤粮人〔2017〕162号）要求，结合我市粮食行业实际，我委制定了《广州市粮食行业“深化改革转型发展”大讨论活动实施方案》，现印发给你们，请认真贯彻实施，确保活动取得实效。

广州市发展和改革委员会

2017年8月28日
