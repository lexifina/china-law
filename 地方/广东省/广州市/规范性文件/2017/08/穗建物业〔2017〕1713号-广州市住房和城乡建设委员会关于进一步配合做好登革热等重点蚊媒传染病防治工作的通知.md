# 广州市住房和城乡建设委员会关于进一步配合做好登革热等重点蚊媒传染病防治工作的通知

各区住建部门、市物业管理行业协会、各物业服务企业：

近日，我市发现了今年首例本地感染登革热病例。市政府高度重视并作出相关批示，要求全市进一步加强防蚊灭蚊工作，有效防控登革热病毒等重点蚊媒传染疾病。根据《广东省爱国卫生工作条例》、《广东省病媒生物预防控制管理规定》和省政府办公厅印发的《广东省全面深化新时期爱国卫生运动实施方案(2015-2020 年)》等有关规定，为防止登革热等蚊媒传染病疫情传播蔓延，现就有关工作事项通知如下：

一、高度重视

各区住房建设行政主管部门要高度重视登革热等重点蚊媒传染病防治工作，认真履行职责，加强检查，督促辖区内物业服务企业积极主动的配合街道、社区居委会开展蚊媒防制工作，确保管理区域内卫生保洁情况良好，降低蚊虫密度，切实保障居民身体健康。

二、积极配合

各区住房建设行政主管部门要督促辖区内的物业服务企业及有关管理单位认真履行物业服务合同，完善小区防蚊设施建设，建设和管理好防蚊闸板、灭蚊灯箱等防蚊灭蚊设施;落实小区灭蚊周记和孽生地清理等日常措施;加强环境治理，及时清除公共环境的各类型积水，定期组织消杀，重点清理庭院沟渠，督促住户清积水，消除人为造成的蚊虫孽生地。

三、加强宣传

市物业管理行业协会要积极倡导会员单位主动配合街道、社区居委会开展蚊媒防治工作。各区住房建设行政主管部门要督促物业服务企业及有关管理单位完善卫生管理制度，在管理区域内组织开展形式多样的灭蚊宣传教育和卫生检查，普及科学灭蚊知识，增强小区居民卫生意识。

特此通知。

广州市住房和城乡建设委员会

2017年8月14日
