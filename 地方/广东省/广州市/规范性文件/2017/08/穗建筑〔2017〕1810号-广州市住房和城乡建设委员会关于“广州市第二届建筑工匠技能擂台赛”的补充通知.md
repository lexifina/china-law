# 广州市住房和城乡建设委员会关于“广州市第二届建筑工匠技能擂台赛”的补充通知

各有关单位：

为提高“广州市第二届建筑工匠技能擂台赛”的建筑工匠竞技水平，增加比赛选手的代表性，现将有关事项补充通知如下：

一、企业报名参赛项目不限，企业参加每个项目的参赛选手报名人数不限(不计辅工)。

二、参赛企业需组织本企业的技术工人进行内部竞赛，将本次项目竞赛题目完成并录制相关视频文件，并将报名参赛选手完成竞赛题目的视频文件(光盘)连同填写盖章好后的报名表，交至擂台赛竞赛工作领导小组办公室。报名截止日期：2017年9月10日。竞赛工作领导小组办公室组织裁判组对选手资料进行初评，按初评成绩排名顺序确定最终参赛选手名单，于2017年9月18日前将参赛选手入选名单通知至各施工企业。竞赛地址：广州市海珠区琶洲互联网创新集聚区工地(广州市海珠区海州路原珠江啤酒厂东门)

三、根据各工种竞赛实际水平情况，按参赛人数一定比例对选手进行奖励，授予“羊城建筑工匠”称号，鼓励获奖选手所在企业根据实际情况对获奖选手进行相应奖励。

特此通知。

广州市住房和城乡建设委员会
