# 广州市住房和城乡建设委员会转发广东省住房和城乡建设厅关于对部分在建房屋市政工程项目进行安全生产专项检查的紧急通知

各区住建局、广州空港经济区国土规划和建设局，市建设工程安全监督站、市市政工程安全质量监督站，各有关单位：

现将《广东省住房和城乡建设厅关于对部分在建房屋市政工程项目进行安全生产专项检查的紧急通知》(穗建电发〔2017〕31 号)转发你们，请各单位结合我委印发的《广州市住房和城乡建设委员会关于印发建筑施工安全生产大检查工作方案的通知》(穗建质〔2017〕1577号)等相关文件要求，认真贯彻落实。

请各区住建局、广州空港经济区国土规划和建设局，市建设工程安全监督站、市市政工程安全质量监督站于2017年8月13日前将纳入此次专项检查的项目数量、排查隐患的情况报送我委工程质量安全处(工作邮箱：gzjwzac@126.com)。

特此通知。

广州市住房和城乡建设委员会

2017年7月31日
