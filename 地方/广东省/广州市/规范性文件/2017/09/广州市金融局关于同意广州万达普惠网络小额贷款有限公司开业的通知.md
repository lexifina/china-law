# 广州市金融局关于同意广州万达普惠网络小额贷款有限公司开业的通知

越秀区金融局：

你局《关于广州万达普惠网络小额贷款有限公司申请开业验收的请示》（越金融〔2017〕219号）收悉。经现场检查，广州万达普惠网络小额贷款有限公司已办理营业执照，悬挂市、区金融工作部门监督举报电话牌匾。经研究，我局同意广州万达普惠网络小额贷款有限公司开业，并就有关事项通知如下：

一、广州万达普惠网络小额贷款有限公司是由大连万达（上海）金融集团有限公司主发起设立，依托互联网面向广大中小微企业、商户、个人等提供融资等服务的具有企业法人资格的有限责任公司。

二、广州万达普惠网络小额贷款有限公司注册资本为人民币10亿元，由主发起人大连万达（上海）金融集团有限公司全额出资，全部为实收货币资本，由出资人一次性缴足；法定代表人为董建岳；住所为广州民间金融街。

三、核准广州万达普惠网络小额贷款有限公司的主要业务范围为：

（一）办理各项小额贷款；

（二）其他经批准的业务。

四、广州万达普惠网络小额贷款有限公司不得从事以下经营活动：

（一）吸收或变相吸收公众存款，组织或参与任何名义、形式的集资活动；

（二）向本公司股东、董事及高级管理人员及其关联方提供贷款；

（三）为银行业金融机构业务提供担保；

（四）同一借款人的贷款余额超过500万元；

（五）经营其他未经批准和法律、法规不允许经营的业务。

五、请你局根据有关文件精神，认真做好监管和服务，指导广州万达普惠网络小额贷款有限公司做好开业工作，并督促该公司向越秀区公安分局、广东银监局和人民银行广州分行报送相关资料。

广州市金融工作局

2017年9月19日

公开方式：主动公开

抄送：省金融办，广州万达普惠网络小额贷款有限公司。
