# 广州市金融局关于同意广州市荔湾信德小额贷款有限公司变更总经理的批复

荔湾区发改局：

你局《广州市荔湾区发展和改革局关于广州市荔湾信德小额贷款有限公司拟任总经理的请示》（荔发改〔2017〕118号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定。经审核，徐增符合任职条件，同意徐增任广州市荔湾信德小额贷款有限公司总经理。

广州市金融工作局

2017年9月15日

公开方式：主动公开

抄送：省金融办，广州市荔湾信德小额贷款有限公司。
