# 广州市金融工作局关于同意广东中庸融资担保有限公司变更公司住所的批复

广东中庸融资担保有限公司：

你公司上报的变更公司住所申请材料收悉。根据《广东省〈融资性担保公司管理暂行办法〉实施细则》（广东省人民政府令第149号）及《印发融资担保公司设立与变更申请材料清单的通知》（粤金〔2010〕51号）要求，经审核，同意你公司住所由“广州市天河区汇彩路38号之一101房”变更为“广州市天河区华庭路4号201之06之2D12房”。

请你公司持本批文到工商行政管理部门办理变更登记注册手续，并携带经营许可证原件来我局办理更换手续。

广州市金融工作局

2017年9月29日
