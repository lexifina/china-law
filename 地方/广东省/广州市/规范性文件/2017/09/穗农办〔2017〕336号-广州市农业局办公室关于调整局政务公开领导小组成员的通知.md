# 广州市农业局办公室关于调整局政务公开领导小组成员的通知

穗农办〔2017〕336号

关于调整局政务公开领导小组成员的通知

局机关各处室、局属各单位：

根据国家、省、市关于全面推进政务公开工作的部署要求，参照市政府做法，结合我局工作实际，经研究决定调整局政务公开领导小组成员，调整后的成员名单如下：

组 长：王健舜 副书记

副组长：李仲铠 副局长

成员由办公室、综合处、法规处、计划处、种业办、农村处、财务处、经管处、质安处、交流合作处、宣教处、种植业处、海洋处、畜牧兽医处、屠管处、渔业处、农产品加工处、组织人事处和市农业信息中心的主要负责同志组成。

局政务公开工作领导小组下设局政务公开工作办公室（设在局办公室），负责局政府信息公开的日常管理和组织协调。局政务公开办主任由局办公室主任兼任。

各成员单位要主动研究政务公开工作，加强协调配合。机关各处室、局属各单位要认真落实市、局关于政务公开的文件和部署，共同推进政务公开各项工作。

广州市农业局办公室

2017年9月4日
