# 广州市发展改革委关于降低我市管道天然气非居民用气销售价格及西气东输二线天然气分销价格有关问题的通知

各管道燃气经营企业：

按照《广东省发展改革委转发国家发展改革委关于降低非居民用天然气价格的通知》（粤发改价格函〔2017〕4694号）要求，现就我市管道天然气非居民用气销售价格及西气东输二线天然气分销价格有关问题通知如下：

一、管道天然气非居民用气价格由4．36元/立方米降低为4．25元/立方米（最高限价，可以下调）。

二、西气东输二线天然气分销价格从2．70元/立方米降低为2．60元/立方米。

三、上述价格自2017年9月1日起实施。

广州市发展和改革委员会

2017年10月13日
