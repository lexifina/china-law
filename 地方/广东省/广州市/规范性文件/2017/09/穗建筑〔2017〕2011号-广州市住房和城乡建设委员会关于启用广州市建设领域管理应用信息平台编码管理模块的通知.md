# 广州市住房和城乡建设委员会关于启用广州市建设领域管理应用信息平台编码管理模块的通知

各建设单位、有关企业：

为整合系统资源、便利企业办事，我委定于今年9月启用广州市建设领域管理应用信息平台编码模块办理全市建设工程项目编码业务。现将有关事项通知如下：

一、自2017年9月21日起，停止原广州市建设工程项目编码及信息登记系统对外服务。建设单位急需申请项目编码(工程编码)的，应在9月20日前完成申请。

二、2017年9月23日-9月24日，原广州市建设工程项目编码及信息登记系统业务数据迁移至广州市建设领域管理应用信息平台编码模块。期间，暂停办理编码业务。

三、自9月25日起，启用广州市建设领域管理应用信息平台编码模块办理全市建设工程项目编码、工程编码业务。各建设单位、相关单位需按新发布的项目编码、工程编码办事指引(详情请见“广州市住房和城乡建设委员会-政务公开专栏-直属单位信息公开专栏-建设和宣教劳保金管理中心-办事指引-编码管理-项目编码办事指引或工程编码办事指引”)要求进行申报。

四、企业在办事过程中如有疑问，请按问题类型拨打业务咨询电话020-81773530，技术支持电话020-83124994。

特此通知。
