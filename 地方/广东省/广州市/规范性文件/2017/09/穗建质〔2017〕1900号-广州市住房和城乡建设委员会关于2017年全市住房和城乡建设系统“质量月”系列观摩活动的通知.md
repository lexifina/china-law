# 广州市住房和城乡建设委员会关于2017年全市住房和城乡建设系统“质量月”系列观摩活动的通知

各区住建局、广州空港委国土规划和建设局，各级质监站，市建筑业联合会、市政协会、监理协会、检测协会、混凝土协会，各相关单位：

根据《广东省住房和城乡建设厅关于组织2017年全省住房城乡建设系统“质量月”现场观摩活动的通知》(粤建质函〔2017〕2521号，以下简称“省厅观摩活动通知”，详见附件)要求，结合《广州市住房和城乡建设委员会转发广东省住房和城乡建设厅关于组织开展2017年“质量月”系列活动的通知》(穗建质〔2017〕1861号)的工作计划，现将2017年我市住房和城乡建设系统“质量月”系列观摩活动有关要求通知如下：

一、现场观摩交流会活动安排

今年，省住房城乡建设厅“质量月”活动在我市广州万达文化旅游城住宅楼项目举行，为高效开展我市“质量月”观摩活动，我市住房和城乡建设系统的“质量月”现场观摩交流会将结合省厅活动举办。

二、“质量月”活动推荐观摩项目

2017年“质量月”活动期间，我委推荐4个观摩项目供各级住建行政主管部门以及企业自由选择观摩，相关介绍和指引请用手机扫描二维码查询(详见附件2)，具体安排如下：

(一)广州万达文化旅游城住宅楼项目

省、市两级住房和城乡建设系统“质量月”活动推荐观摩项目，活动时间、地点与“省厅观摩活动通知”一致。

(二)广州万达文化旅游城商业楼项目

省、市两级住房和城乡建设系统“质量月”活动推荐观摩项目，活动时间、地点与“省厅观摩活动通知”一致。

(三)南沙区榄核镇镇南路南侧地块(2015NJY-9)地块四项目

观摩时间：9月12日至9月14日(星期二至星期四)

工程地点：广州市南沙区榄核镇镇南路南侧

建设单位：广东保利房地产开发有限公司

设计单位：筑博设计股份有限公司

施工单位：中建三局第一建设工程有限责任公司

监理单位：广东重工建设监理有限公司

建筑面积：22.3万㎡

形象进度：主体结构施工

观摩内容：项目施工全工序穿插、质量管理十大标准动作、两图融合、铝膜工艺、深化设计、装配式PC构件(预制楼梯、预制阳台、预制凸窗、预制梯间墙)、轻质隔墙板、高精砌块、薄抹灰或免抹灰、附着式提升脚手架、BIM应用，两图融合与机电装修一体化，PC端及移动手持端APP项目全周期信息化管理。

项目联系人：陈汉桥，联系电话：1866509****。

(四)广州远大住宅工业有限公司

观摩时间：9月12日至9月22日

工厂地点：广州市南沙区南沙大道大同立交桥东侧2号

工厂规模：厂区面积2万平方米，拥有1条流水生产线和1条落地生产线。

生产产品：房建生产12米×3.5米范围内的叠合楼板、内外墙板、楼梯、阳台、凸窗等构件，市政管廊、地下室，整体装配式别墅。

生产能力：年生产构件5万立方。

观摩内容：装配式建筑构件生产流程及质量控制等。

项目联系人：曾志文，联系电话：1868475****。

三、相关要求

(一)请花都区住房和建设局负责“现场观摩交流会”及第一、第二个推荐观摩项目的组织协调工作;请南沙区建设和交通局负责做好第三、第四个推荐观摩项目的组织协调工作。

(二)参加9月11日省、市两级组织的“现场观摩交流会”活动的人员安排如下：

1.各区住建局(广州空港委国土规划和建设局)分管领导、质量处(科)长及各级质量监督站主要负责人参加会议;

2.市住保办、市代建局、市中心区项目办、广州地铁集团、广环投集团、市城投集团各组织2名负责人参加会议;

3.市建筑业联合会组织建筑施工企业负责人100人，市政协会负责组织市政企业负责人40人，市监理协会负责组织监理企业负责人40人，市检测协会组织检测机构负责人10人，市混凝土协会组织混凝土企业负责人10人参加会议。

(三)9月12日下午14:00我委将在第三推荐观摩点举办“质量月”活动分会场启动仪式，并组织到第三、第四推荐观摩点集体观摩，观摩人员请于当天13:30前在第三推荐观摩点报到参加分会场启动仪式，参加人员安排如下：

1.各区住建局(广州空港委国土规划和建设局)、各级质量监督站各安排1名负责人参加;

2.市建筑业联合会组织建筑施工企业负责人30人，市政协会负责组织市政企业负责人15人，市监理协会负责组织监理企业负责人5人，市检测协会组织检测机构负责人3人，市混凝土协会组织混凝土企业负责人3人参加会议。

3.南沙区建设和交通局组织辖区内相关建设业主、施工、监理企业负责人、各建筑工地相关责任主体负责人。

(四)请各单位在9月7日12:00前将《“质量月”现场观摩交流会报名表》(附件1之附件2)邮件发至我委工程质量安全处，各区住建局负责通知区质监站，并统计区质监站参会人员，9月11日、9月12日两次活动参会人员分别注明。

(五)各级建设工程质量监督站组织好各辖区内建筑工地的相关负责人按“省厅观摩活动通知”及我市观摩活动的时间要求自行组织前往省、市两级观摩项目参观学习。

(六)参加观摩的单位及人员需听从现场工作人员安排，按照指定地点停放车辆，遵守观摩活动要求，切实注意人身安全。参观活动人员食宿及交通由所在单位自行解决。

特此通知。
