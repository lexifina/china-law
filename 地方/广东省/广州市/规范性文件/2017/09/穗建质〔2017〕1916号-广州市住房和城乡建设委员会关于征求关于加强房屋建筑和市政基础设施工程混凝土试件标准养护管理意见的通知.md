# 广州市住房和城乡建设委员会关于征求关于加强房屋建筑和市政基础设施工程混凝土试件标准养护管理意见的通知

各相关单位：

为进一步加强我市房屋建筑和市政基础设施工程施工质量管理，规范施工现场混凝土试件标准养护，我委对《关于加强房屋建筑和市政基础设施工程混凝土试件标准养护管理的通知》进行了修订并征求了各相关职能单位的意见后，形成了征求意见稿。现公开向社会公众征求意见，期限为：2017年9月8日至 2017年9月18日。欢迎广大市民、专家、学者提出宝贵意见，并于2017年9月18日前将意见反馈至我委，同时发送电子版至电子邮箱：lijiazuo@gzcc.gov.cn。
