# 广州市住房和城乡建设委员会关于暂停无法达到生产条件企业供应混凝土的通知

各区住建局、空港委国土规划和建设局，各级质量安全监督机构，各有关单位：

目前，广州临海混凝土有限公司等21家具有混凝土专业承包资质的企业(详见附件)处于搬迁、停产的状态，市散装水泥管理办公室对企业的情况进行核查，21企业均无法达到混凝土生产业务条件。市建设工程质量监督站于2017年8月15日起，暂停了这些企业的混凝土质量追踪及动态监管系统账号，为加强预拌混凝土行业的监督管理，促进行业的健康管理，确保我市建设工程混凝土的质量安全，现将有关要求通知如下：

一、为全面预防混凝土企业“甲签乙供”行为，所有处于搬迁、无生产场地、停产且无法达到生产条件的企业不得向外销售混凝土;全市各混凝土使用企业(个人)不得向购买预拌混凝土。

二、各级质量监督机构在日常监督管理过程中，对纳入监管建筑工地的混凝土供应情况进行检查，对发现违规生产的混凝土企业及产生购买的服务的企业要及时上报各级建设行政主管部门予以严肃查处。

三、各级散装水泥管理机构加大对处于搬迁、无生产场地、停产且无法达到生产条件企业的监管力度，不定时对企业进行抽查。

四、各区建设行政主管部门加强巡查，对查实的违规供应的混凝土、施工、监理企业要坚决予以制止，并对相关企业负责人进行约谈、通报。同时，要主动做好服务，对依法达到生产要求条件的企业应及时上报我委予以恢复。
