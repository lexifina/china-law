# 广州市住房和城乡建设委员会关于加强中秋国庆期间建筑工程安全生产管理工作的通知

各区住建局、广州空港经济区管委会，各级建设工程安全监督站，各有关单位：

为进一步加强我市建筑施工安全生产管理，认真贯彻市委市政府关于强化安全生产管理的工作要求，全面落实市主要领导对近期发生安全生产事故的批示精神，结合《广州市住房和城乡建设委员会关于印发建筑施工安全生产大检查工作方案的通知》(穗建质〔2015〕1577号) 的相关要求，切实加强中秋、国庆期间建筑工程安全生产管理工作，现将有关事项通知如下：

一、加强房屋市政工程安全监管

为确保中秋、国庆期间我市建筑施工安全生产形势的稳定，市住建委成立了由委主要领导任组长、分管安全生产的副主任为副组长，委工程质量安全处处长、市建设工程安全监督站站长、市市政工程安全质量监督站站长、各区住建部门、广州空港经济区管委会的主要负责人为组员的专项检查小组，从9月25日开始至10月20日，对全市在建房屋市政项目开展安全生产专项检查。各区住建局、各级建设工程安监站要认真组织，全面、扎实开展安全隐患问题排查，对发现问题要坚持“零容忍”、“严执法”实施处罚，具体要求如下：

(一)督促受监项目各方责任主体单位落实安全生产责任制，要求企业主要负责人亲自部署本单位在中秋、国庆期间承建的施工安全管理工作，落实企业负责人和项目负责人带班检查制度，切实加强施工安全隐患排查，对排查出突出安全隐患的项目，该停工的须坚决停工。

(二)突出重点，深入开展建筑施工安全专项检查。各级要加强对深基坑、高大支模、高层外脚手架、地下暗挖、建筑起重机械安装运行和拆卸、建筑消防、施工用电等施工安全管理重点环节的监管力度，重点对以下内容开展检查：

一是检查专项施工方案是否按照有关规定进行编审、专家论证、技术交底、组织实施和验收。

二是检查高大支模和外脚手架的构造和用材是否符合专项方案的规定，构件材料检测结果是否合格;搭设高度50m及以上的落地式脚手架的分段卸荷措施是否合理和有效，外脚手架连墙件的分布和设置是否符合安全技术规范的规定。

三是检查施工组织设计中的安全技术措施或专项施工方案是否符合工程建设强制性标准;危险性较大的分部分项工程投入使用前是否按规定办理完备的验收手续。

四是检查深基坑、管沟(槽)等地下作业工程的排水、放坡和支护技术方案论证及实施情况;基坑变形监测工作的落实情况;对深基坑支护专项施工方案，检查基坑支护是否注明有效使用时限，专家论证及相关单位审批手续是否齐全;对超过支护有效使用时限的深基坑，必须采取切实有效的处理措施，防止坍塌事故发生。

五是检查建筑起重机械的顶升、拆卸环节的相关工作内容，包括有无签订顶升、拆卸合同，合同是否内容清晰、责任明确，负责作业的队伍是否有起重机械安装的专业承包资质，人员是否持省级住房城乡建设主管部门核发的特种作业资格证，作业前是否按照施工方案和建筑起重机械使用说明书的要求进行技术交底，有无按照使用说明书要求对建筑起重机械进行日常的维护保养;塔吊吊运施工安全是否符合规范要求，作业人员是否遵守吊运操作规程等。

二、工作要求

各区住建局、广州空港经济区管委会、各级建设工程安全监督机构、各相关企业要高度重视中秋、国庆期间的安全生产工作，切实加强组织领导，把安全生产摆在突出位置，严格落实安全责任，认真抓好各项工作落实。制定检查计划，全面彻底排查安全隐患，落实各项安全措施，严防各类安全生产事故的发生。

(一)各单位领导要“一把手”亲自抓、负总责，全面掌握管辖范围内重大危险源的监督和安全事故防控情况;要指导企业组织专业技术人员对现场存在的重大安全隐患进行排查;要坚持属地为主与行业督导相结合、监督检查与企业自查相结合的原则，针对监管工地的特点，明确责任分工，狠抓落实，不留死角。

(二)各建设工程安全监督机构要通过微信、短信、现场检查等方式，对项目管理人员的到位情况和履职情况进行抽查、检查，督促建设、施工和监理等各方责任主体，对于施工安全管理不到位、措施不落实的责任单位和个人依法从严处理，对于发现的安全隐患必须及时跟进处理，做到闭合管理，确保隐患得以消除。

(三)对监管中发现存在严重违法违规行为，或现场存在严重安全隐患，且对监管单位提出的整改要求整改不力的，各监管单位应将其列入重点监控范围，加强监督频次。对整改不力的单位和个人，通过采取动态扣分、记录不规范行为、诚信扣分、警示谈话、全市通报批评、实施行政处罚、限制企业投标报名等方式，有效督促责任单位落实各项整改工作。

(四)各项目要合理安排施工工序，国庆节和重要会议期间不安排高支模砼浇注、起重机械安装顶升等重大危险源作业。

(五)各单位要认真落实国庆节期间值班工作制度，责任到人。安排专人24小时值班，保证信息畅通。遇到紧急、重要情况立即请示报告，及时妥善处理。请各区住建局、广州空港经济区管委会、市建设工程安全监督站、市市政工程安全质量监督站于9月27日前将中秋、国庆节期间值班安排表、10月25日前将开展国庆节前施工安全检查情况以电子文档形式发送至邮箱gzjwzac@126.com。

特此通知。
