# 广州市住房和城乡建设委员会关于转发广州市质量强市办印发广州市发挥品牌引领作用推动供需结构升级实施方案的通知

各区住建局、广州空港委国土规划和建设局，各级建设工程质量监督站，各行业协会：

现将《广州市质量强市办关于印发广州市发挥品牌引领作用推动供需结构升级实施方案的通知》(穗强市办[2017]34 号)转发你们，请你们结合《中共中央 国务院关于开展质量提升行动的指导意见》，深入推进工程质量安全提升行动，不断提升工程质量安全管理水平，主动与质量技术监督局对接，切实培育一批形象品牌突出、质量水平一流的工程建设企业，树立一批在工程建设质量方面具有广泛示范性的全国和行业质量标杆，深化质量强市战略。

附件：广州市质量强市办关于印发广州市发挥品牌引领作用推动供需结构升级实施方案的通知
