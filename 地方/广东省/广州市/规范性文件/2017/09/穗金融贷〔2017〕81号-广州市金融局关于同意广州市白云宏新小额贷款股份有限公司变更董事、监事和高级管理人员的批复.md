# 广州市金融局关于同意广州市白云宏新小额贷款股份有限公司变更董事、监事和高级管理人员的批复

穗金融贷〔2017〕81号

广州市金融局关于同意广州市白云宏新

小额贷款股份有限公司变更董事、

监事和高级管理人员的批复

白云区金融办：

你办《关于广州市白云宏新小额贷款股份有限公司变更董事、监事和高级管理人员拟任人的请示》（云发改金〔2017〕14号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定。经审核，游嘉敏、林志勇、刘东、郑敏珠和游锦容符合任职条件，我局批复如下：

同意游嘉敏、林志勇和刘东任广州市白云宏新小额贷款股份有限公司董事，免去刘潮坚、陈上助和赵素娇董事职务。

同意郑敏珠任广州市白云宏新小额贷款股份有限公司监事长，免去范思斌监事长职务。

同意游锦容任广州市白云宏新小额贷款股份有限公司监事，免去游嘉敏监事职务。

同意刘东任广州市白云宏新小额贷款股份有限公司总经理，免去刘潮铭总经理职务。

广州市金融工作局

2017年9月7日

公开方式：主动公开

抄送：省金融办，广州市白云宏新小额贷款股份有限公司。
