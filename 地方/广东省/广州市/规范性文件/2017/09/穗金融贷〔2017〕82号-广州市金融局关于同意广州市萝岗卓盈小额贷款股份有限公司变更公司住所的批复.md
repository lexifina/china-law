# 广州市金融局关于同意广州市萝岗卓盈小额贷款股份有限公司变更公司住所的批复

穗金融贷〔2017〕82号

广州市金融局关于同意广州市萝岗卓盈

小额贷款股份有限公司变更

公司住所的批复

开发区金融局：

你局《关于审批广州市萝岗卓盈小额贷款股份有限公司变更公司地址的请示》（穗开金融报〔2017〕5号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定。经审核，现批复如下：

一、同意广州市萝岗卓盈小额贷款股份有限公司的住所由“广州市高新技术产业开发区科汇二街15号301（部位：301-3房）”变更为“广州市经济技术开发区东勤路16号自编01”。

二、请你局督促广州市萝岗卓盈小额贷款股份有限公司根据本批复修改公司章程，并自批复之日起30个工作日依法向工商部门办理住所变更手续。

三、广州市萝岗卓盈小额贷款股份有限公司完成公司住所变更后，你局应按照相关政策规定的要求，进一步加强对该公司的管理与服务，督促该公司合规经营并做好风险防控工作。

广州市金融工作局

2017年9月7日

公开方式：主动公开

抄送：省金融办，广州市萝岗卓盈小额贷款股份有限公司。
