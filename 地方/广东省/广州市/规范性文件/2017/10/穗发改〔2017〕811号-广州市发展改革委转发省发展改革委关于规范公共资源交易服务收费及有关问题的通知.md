# 广州市发展改革委转发省发展改革委关于规范公共资源交易服务收费及有关问题的通知

市国土规划委、广州公共资源交易中心：

现将《广东省发展改革委关于规范公共资源交易服务收费及有关问题的通知》（粤发改价格函〔2017〕5069号）转发给你们，请遵照执行。此前与本通知不符的有关文件同时废止。请市国土规划委、广州公共资源交易中心将执行情况（包括清理情况和2016年收费金额）于10月15日前报我委。

广州市发展和改革委员会

2017年9月30日
