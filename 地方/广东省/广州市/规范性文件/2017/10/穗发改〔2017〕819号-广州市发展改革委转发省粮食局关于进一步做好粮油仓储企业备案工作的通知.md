# 广州市发展改革委转发省粮食局关于进一步做好粮油仓储企业备案工作的通知

各区发展改革局（粮食局），市粮食集团：

现将省粮食局《关于进一步做好粮油仓储企业备案工作的通知》（粤粮科储〔2017〕195号）转发给你们，请按照文件要求，加强粮食仓储企业备案管理，以更好地规范国有企业粮油仓储物流设施变更和处置行为。

各区粮食主管部门在每年1月10日、7月10日前统计上报前6个月辖内粮油仓储企业备案情况。其中今年备案情况于12月20日前报我委粮食处，电子版请发至liangsc＠gz．gov．cn。根据《广东省粮油仓储单位备案管理暂行办法》要求，企业备案还

需提供《粮油仓储单位粮油仓储设备情况表》，已备案企业请补充提供，于12月29日前提交所在地区级粮食主管部门。

加强粮油仓储单位及粮油仓储物流设施管理已列入粮食安全责任考核重点考核事项，请各区粮食主管部门加大工作力度，落实粮油仓储物流设施动态管理制度，按时完成企业备案工作。

广州市发展和改革委员会

2017年9月30日
