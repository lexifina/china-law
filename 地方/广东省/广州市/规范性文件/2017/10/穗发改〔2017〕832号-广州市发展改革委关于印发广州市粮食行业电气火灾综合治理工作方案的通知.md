# 广州市发展改革委关于印发广州市粮食行业电气火灾综合治理工作方案的通知

各区发展改革局（粮食局）、市粮食集团：

根据《广东省粮食局转发省公安厅等七部门关于电气火灾综合治理工作方案的通知》（粤粮监〔2017〕160号）和《关于印发广州市电气火灾综合治理工作方案的通知》（穗公〔2017〕290号）要求，结合我市粮食行业实际，我委制定了《广州市粮食行业电气火灾综合治理工作方案》，现印发给你们，请认真组织实施，确保治理工作取得实效。

广州市发展和改革委员会

2017年10月13日
