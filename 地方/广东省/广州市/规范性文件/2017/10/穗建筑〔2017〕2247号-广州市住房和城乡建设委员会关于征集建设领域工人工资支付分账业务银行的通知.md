# 广州市住房和城乡建设委员会关于征集建设领域工人工资支付分账业务银行的通知

各商业银行：

根据《关于印发广州市建设领域工人工资支付分账管理实施细则的通知》(穗建规字〔2017〕10号)和《广州市住房和城乡建设委员会关于实施<广州市建设领域工人工资支付分账管理实施细则>的通知》(穗建筑〔2017〕1344号)(以下简称实施细则)等有关规定，现征集商业银行加入广州市建设领域工人工资支付分账银行名录，具体事项如下：

一、申请条件

(一)申请加入广州市建设领域工人工资支付分账银行名录须满足实施细则中的规定和要求，并履行规定义务。

(二)申请加入广州市建设领域工人工资支付分账银行须开发工人工资专用账户管理系统。

(三)开发工人工资专用账户管理系统须与广州市建设领域管理应用信息平台对接，广州市建设领域管理应用信息平台与银行工人工资专用账户管理系统接口标准(以下简称接口标准)在商业银行提交申请材料时提供。

二、由市建设宣教劳保中心负责广州市建设领域工人工资支付分账银行名录具体管理工作。

三、加入广州市建设领域工人工资支付分账银行名录的商业银行须每年12月15日前向市建设宣教劳保中心汇报年度服务工作情况。

四、满足服务条件要求的商业银行，将分期分批向社会公布。

五、其他

(一)申请时间：发文之日起至2017年10月27日接收申报材料，满足条件的商业银行将纳入首批名录予以公布。2018年1月起,长期接收申报材料，满足条件的商业银行按批公布。

(二)申请材料：见附件1。

(三)申请材料提交方式：

1.电子公文交换系统交换至：广州市住房和城乡建设委员会；

2.书面函寄至：广州市住房和城乡建设委员会(府前路1号大院3号楼，邮编510032)；

3.来人送至:市政府大院3号楼5楼广州市住房和城乡建设委员会保密室。(工作日上午9:00-12:00，下午14:30-17:30收件)。

(四)各商业银行应由业务覆盖广州市全部行政辖区的相应级别地区分行申请，其中设置广东省分行的，应当由广东省分行申请，其他由广州分行申请。
