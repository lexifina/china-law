# 广州市林业和园林局关于对广州市富华工程建设监理有限公司招标违规行为的通报（穗林业园林通[2017]584号）

局属各单位、机关各处室：

广州市儿童公园续建工程，由广州市林业和园林绿化工程建设中心负责建设，并委托广州市富华工程建设监理有限公司进行设计招标，招标公告及招标文件经我局备案、招标工作受我局监管。该项目于2017年8月18日在广州公共资源交易中心（以下简称"交易中心"）网站发布招标公告和招标文件，9月15日在交易中心开评标。评标过程中，评标委员会发现用于评标的招标文件与经我局备案并在交易中心网站发布的招标文件不一致。经调查，相关情况如下：

经对比，该项目在我局备案的招标文件与在交易中心网站发布的招标文件为同一版本，评标委员会用于评标的招标文件和招标代理发售的纸质招标文件为另一版本，其差异在于设计工期中要求完成方案修改、初步设计、施工图设计的时间不同，分别为7个工作日和10个工作日。

评标委员会发现问题后，对投标文件逐一进行比对，对照招标文件讨论后，认为各投标人的投标文件均满足招标文件的要求，其中2家的投标文件因受误导，导致商务得分被评标委员会扣分。经核算，该部分得分是否被扣，并不影响各投标人总分的排名，最终评标委员会推荐了3家中标候选人。

综上，招标文件不一致之处对评标结果没有实质性影响。但由于招标代理工作失误，导致提供的招投标信息不对称，误导了投标人和评标委员会，造成不良影响。经研究，现对广州市富华工程建设监理有限公司的违规行为进行通报批评。

请局属各单位从中吸取教训，引以为戒，加强对工程建设管理人员的业务培训，严格把关招标文件，认真执行招标投标法规文件。请各招标代理机构规范从业行为，严格按照招标投标有关的法律法规开展代理业务，杜绝类似情况的发生。

广州市林业和园林局
