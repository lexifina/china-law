# 市金融局关于同意广州市白云合银泰富小额贷款股份有限公司变更董事的批复

穗金融贷〔2017〕90号

市金融局关于同意广州市白云合银泰富

小额贷款股份有限公司变更董事

的批复

白云区金融办：

《白云区金融办关于广州市白云合银泰富小额贷款股份有限公司变更董事拟任人的请示》（云发改金〔2017〕17号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定。经审核，夏文锋、唐倩萍、黎柏松和黄丹华符合任职条件，我局批复如下：

同意夏文锋、唐倩萍、黎柏松和黄丹华任广州市白云合银泰富小额贷款股份有限公司董事，免去勒海鸣、林炳贤、莫万全、张伟平、王文康、岑钊雄、赵雪峰、冯洁芳和郭福彬董事职务。

广州市金融工作局

2017年10月10日

公开方式：主动公开

抄送：省金融办，广州市白云合银泰富小额贷款股份有限公司。
