# 市金融局关于同意广州市衡誉小额贷款股份有限公司变更公司章程的批复

越秀区金融局：

你局《关于广州市衡誉小额贷款股份有限公司变更章程的请示》（越金融〔2017〕273号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定。经审核，广州市衡誉小额贷款股份有限公司章程变更符合规定，我局批复如下：

一、同意将《广州市衡誉小额贷款股份有限公司章程》第三章第一节第十七条，公司的股东名称、股份数如下：
