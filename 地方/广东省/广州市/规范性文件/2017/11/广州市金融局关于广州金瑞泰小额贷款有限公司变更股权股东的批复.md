# 广州市金融局关于广州金瑞泰小额贷款有限公司变更股权股东的批复

越秀区金融局：

你局《关于广州金瑞泰小额贷款有限公司变更股权股东的请示》（越金融〔2017〕282号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）和《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号），经审核，现批复如下：

一、同意自然人股东张健中将持有的广州金瑞泰小额贷款有限公司20%的股份转让给自然人股东倪骏。转让后，倪骏持有广州金瑞泰小额贷款有限公司25%的股份，张健中不再持有广州金瑞泰小额贷款有限公司任何股份。

二、请你局通知广州金瑞泰小额贷款有限公司自批复之日起依法向工商部门办理公司章程变更备案。

三、广州金瑞泰小额贷款有限公司完成股权股东变更后，你局应按照相关政策规定的要求，进一步加强对该公司的管理与服务，督促该公司合规经营并做好风险防控工作。

广州市金融工作局

2017年11月9日

公开方式：主动公开

抄送：省金融办，广州金瑞泰小额贷款有限公司。
