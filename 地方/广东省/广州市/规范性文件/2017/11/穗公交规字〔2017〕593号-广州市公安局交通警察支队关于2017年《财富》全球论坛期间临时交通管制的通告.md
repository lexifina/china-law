# 广州市公安局交通警察支队关于2017年《财富》全球论坛期间临时交通管制的通告

2017年《财富》全球论坛（以下简称“论坛”）将于2017年12月6日至8日在广州举办，届时将分别在香格里拉大酒店、中山纪念堂、广州塔举办重大活动。为确保论坛各项活动安全顺利进行和道路交通安全畅通，根据《中华人民共和国道路交通安全法》有关规定，决定对各活动现场周边道路实施临时交通管制。现通告如下：

一、香格里拉大酒店周边的临时交通管制措施

（一）12月3日16:00至12月9日12:00期间，会展东路、琶洲大道东、阅江中路（西往东方向，会展西路至科韵路路段）实施交通管制，除持有论坛专用车证的车辆外，禁止其他车辆通行。

（二）12月4日至8日期间每天06:00至24:00,以下范围禁止一切货车进入通行，并视情况对其他社会车辆采取临时交通管制和分流措施：

东面：科韵路（不含）以西；

南面：新港东路（含）以北；

西面：会展西路（含）以东；

北面：阅江中路（含）以南。

（三）12月4日至8日期间全天24小时,以下范围禁止一切危化品运输车辆进入通行，并视情况对其他社会车辆采取临时交通管制和分流措施：

东面：科韵路（含）以西；

南面：凤浦中路（含）以北；

西面：华南快速干线（含）以东；

北面：阅江中路（含）以南。

二、中山纪念堂周边的临时交通管制措施

（一）12月6日15:00至22:30期间，吉祥路（应元路至东风路路段）、连新路（应元路至东风路路段）实施交通管制，除持有论坛专用车证的车辆外，禁止其他车辆通行。

（二）12月6日15:00至22:30期间，以下范围禁止一切货车和危化品运输车辆进入通行，并视情况对其他社会车辆采取临时交通管制和分流措施：

东面：小北路（含）以西；

南面：东风路（含）以北；

西面：盘福路（含）以东；

北面：应元路（含）以南。

（三）12月6日17:30至19:00期间，东风路（东往西方向）将实施临时交通管控和分流措施，请社会车辆绕行环市路、中山路等道路。

三、广州塔周边的临时交通管制措施

（一）12月7日15:00至22:30期间，滨江东路（广州塔路至广州塔码头路段）、艺苑路（艺洲路至滨江东路路段）、广州塔路（北往南方向）、阅江西路（东往西方向，广州塔路至猎德大道路段）实施交通管制，除持有论坛专用车证的车辆外，禁止其他车辆通行。

（二）12月7日15:00至22:30期间，以下范围禁止一切货车和危化品运输车辆进入通行，并视情况对其他社会车辆采取临时交通管制和分流措施：

东面：猎德大道（不含）以西；

南面：双塔路（含）、艺洲路（含）以北；

西面：广州大道（不含）以东；

北面：临江大道（含）以南。

四、执行紧急任务的军警车、消防车、救护车、工程抢险车以及持有通行证件的管制区域内单位、住户的车辆不受上述交通管制措施限制。

五、活动期间，途经活动现场周边道路的车辆和行人请自觉遵守交通规则，服从现场执勤民警和工作人员的指挥，按照交通标志指示通行，以免造成周边交通拥堵。

六、交通管制路段恢复社会交通时间由公安机关交通管理部门根据实际交通情况调整。

七、违反本通告的，由公安机关交通管理部门依法予以处理。

请广大市民提前做好生产生活出行安排，论坛期间减少私家车辆出行，提倡公交出行，文明交通，共同维护我市道路交通安全和畅通。

特此通告。

广州市公安局交通警察支队

2017年11月23日
