# 广州市公安局关于2017广州《财富》全球论坛期间实施陆路入穗及在穗行驶车辆安全检查的通告

为维护社会秩序，保障公共安全，确保2017广州《财富》全球论坛安全顺利举行，广州市公安机关将在2017广州《财富》全球论坛筹备及举办期间，对进入广州市及在广州市内行驶的机动车辆实施安全检查。现将有关事项通告如下：

一、在广州市际、区际主要道路及涉《财富》全球论坛活动有关道路上设立治安卡点，对过往车辆实施安全检查，严禁携带、藏匿或非法运输枪支、弹药、弩、匕首等国家规定的管制器具，爆炸性、毒害性、放射性、腐蚀性物质，传染病病原体等危险物质，淫秽物品及其他违禁物品。

届时，各治安卡点将开设快速查验通道，对担负特殊紧急任务的特种车辆（警车、消防车、救护车、工程抢险车）、具有公务行政标志车辆、持有2017广州《财富》全球论坛专用通行证车辆、“绿色通道”车辆（即整车运送鲜活农产品的车辆，包括新鲜蔬菜、水果，鲜活水产品，活禽畜，新鲜的肉、蛋、奶等）实行快速安检；对可疑车辆，将查验驾驶员的身份证、驾驶证、行驶证，并对车载人员、物品进行安全检查，货运车辆另须查验货单。

二、为缓解因治安卡点安检造成交通拥堵的问题，提高路面通行效率，公安机关将根据道路实际通行能力和交通拥堵情况，对过往车辆实行必要的临时交通管制和采取交通疏导分流等措施。过往车辆应当按照道路交通引导标志或者公安民警的现场指挥行驶。

三、违反本通告构成违反治安管理行为的，由公安机关依照《中华人民共和国治安管理处罚法》依法处理；构成犯罪的，依法追究刑事责任。

四、本通告自2017年11月30日起施行，有效期至12月9日。
