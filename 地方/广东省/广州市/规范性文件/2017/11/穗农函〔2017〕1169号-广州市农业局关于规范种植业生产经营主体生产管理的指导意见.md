# 广州市农业局关于规范种植业生产经营主体生产管理的指导意见

穗农函〔2017〕1169号

关于规范种植业生产经营主体生产管理的指导意见各区农业行政主管部门：

为夯实我市农产品(仅指种植业类农产品，下同)生产企业、专业合作社、家庭农场和种植大户等生产经营主体（下称生产经营主体）标准化生产基础工作，全面落实农产品生产经营者质量安全主体责任，切实加强农产品生产过程质量管控，根据《农产品质量安全法》《农药管理条例》以及省农业厅关于加强农产品生产记录档案工作的通知（粤农办〔2017〕599号）等要求，现就规范生产经营主体生产管理工作提出以下意见：

一、对农产品生产经营主体的管理要求

1.促进农产品标准化生产建设。农产品生产经营主体一头连着市场，一头连着生产基地和千家万户，在推进农业标准化中对农产品生产实行“四统一”（统一品种、统一生产管理、统一产品品牌、统一包装标识）等有天然优势，是我市农产品生产的重要骨干力量。生产经营主体要制定或参照现有各级生产操作技术规程，严格执行生产操作技术规程，加大标准化生产、农业投入品管理和对生产全过程质量控制力度，在农业标准化生产中发挥示范带动作用。

2.开展农药化肥减量行动。科学使用农药化肥，减少农药化肥使用量，是保障农业生产安全、农产品质量安全和生态环境安全，促进农业可持续发展的必由之路。生产经营主体要主动承担起科学使用化肥农药的责任，大力推广高效低毒农药、生物防治和物理化学防治等绿色防控技术，推广使用测土配方施肥和水肥一体化等精准施肥技术，增施有机肥。切实减少农药化肥使用量，提高农产品质量安全水平。

3.完善农产品生产管理制度。健全的生产管理制度是生产经营主体保障农产品质量安全的重要基础。生产经营主体要重点建立或完善农药使用管理制度（附件1）、农业投入品仓库管理制度（附件2）、农产品质量安全管理制度（附件3）、农产品质量安全监测制度等重要制度，明确责任人和相关工作流程。生产管理制度要统一在单位显眼位置公布。

4.建立投入品出入仓管理记录。投入品（指农药、肥料等生产资料，下同）出入仓管理记录采用一品一记，即每一个农药或肥料单独记账，记录内容要包括投入品名称、生产厂家、有关证号、供货单位、安全间隔期、规格、数量、出入仓时间，经手人等要素。投入品出入仓管理记录保留2年以上。（附件4）

5.建立田间生产管理记录。建立健全农产品田间生产记录是落实《农产品质量安全法》和《农药管理条例》的一项重要任务，是从生产环节提升农产品质量安全水平的重要手段。生产经营主体要按照不同的农作物品种，生产场地分区管理，记录农作物定植、使用农业投入品的时间、区域、对象以及名称、用量，农作物采收时间及数量。生产记录中要有开展农药化肥减量行动的相关记录。田间生产管理记录保留2年以上。（附件5）

6.建立农产品产销记录。农产品产销记录应包括采收地块、品种、数量、购买方、联系电话等要素。生产经营主体要逐步实现“生产有记录、流向可追踪、信息可查询、质量可追溯”的农产品质量追溯管理新模式，建立完善的农产品标识及溯源管理制度，提高全市农产品质量安全水平。（附件6）

二、对各级农业行政主管部门的工作要求

1.加强组织领导。各级农业部门要把建立农产品质量安全监管名录和生产记录制度，作为农产品质量安全管理的重要任务，明确主管领导，落实工作责任制，确保本辖区生产经营主体生产记录等各项记录齐全、数据准确。

2.建立生产经营主体监管名录。摸清全市农产品生产经营主体底数，是全面推进农业标准化生产、落实生产经营者质量安全主体责任和实施依法监管的前提。各区要按照属地管理原则，对辖区内所有农产品生产经营主体进行调查摸底、登记备案并建立监管名录；监管名录分类造册后上报我局汇总，建立全市农产品生产经营主体监管名录，并通报相关生产服务指导和质量安全监管执法部门。监管名录每1—2年更新一次。（附件7）

3.加大服务指导和监管执法力度。各级农业生产和行业管理部门要深入基层，切实加强对生产经营主体落实生产记录等制度的工作部署、宣传培训和服务指导；各级农业执法部门根据《农产品质量安全法》《农药管理条例》等法律法规（附件8），把落实生产记录等制度纳入监管执法重要工作日程。

4.健全奖惩激励机制。各级农业部门要凝聚系统内工作合力，坚持标准化生产和依法监管两手抓，切实把生产记录等制度作为夯实标准化生产基础工作抓出成效。要及时总结推广农业标准化生产的好经验、好做法和好典型，优先给予政策扶持。对未建立和保存生产记录的农产品生产主体，依法依规严肃查处。
