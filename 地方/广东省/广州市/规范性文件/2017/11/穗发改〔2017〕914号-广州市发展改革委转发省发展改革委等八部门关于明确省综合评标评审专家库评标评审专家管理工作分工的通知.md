# 广州市发展改革委转发省发展改革委等八部门关于明确省综合评标评审专家库评标评审专家管理工作分工的通知

市工业和信息化委、市财政局、市住房城乡建设委、市交委、市水务局、市林业和园林局、市商务委、市城管委，广州港务局，广州公共资源交易中心：

现将广东省发展改革委等八部门联合印发的《关于明确省综合评标评审专家库评标评审专家管理工作分工的通知》（粤发改公资办函〔2017〕19号）转发给你们，结合我市实际，提出以下工作要求，请一并贯彻执行。

一、请各行业监管部门加强对本行业专家的监督管理，及时依法对专家在评标评审活动中的违法违规行为进行处理。

二、请广州公共资源交易中心认真做好专家入库初审以及日常考评工作；同时，加强与省公共资源交易中心的衔接，尽快做好系统对接，确保省市综合评标评审专家的实时互联共享。

专此

广州市发展和改革委员会

2017年11月6日
