# 广州市发展改革委转发国家发展改革委关于做好2017年天然气迎峰度冬工作的通知

市城管委，各区发展改革局，中国石油西气东输管道公司广东管理处、广东省天然气管网有限公司、广东大鹏液化天然气有限公司，广州发展集团股份有限公司：

现将《广东省发展改革委转发国家发展改革委关于做好2017年天然气迎峰度冬工作的通知》（粤发改能电函〔2017〕5669号）转发给你们，有关事项通知如下：

一、中国石油西气东输管道公司广东管理处、广东省天然气管网有限公司、广东大鹏液化天然气有限公司按照《石油天然气管道保护法》做好天然气长输管道广州段的保护工作。

二、请市城管委组织城市燃气行业迎峰度冬。广州发展集团股份有限公司要认真落实天然气迎峰度冬工作的企业主体责任。

三、各区发展改革局要做好本区能源领域有关监测预警工作。

专此

广州市发展和改革委员会

2017年11月17日
