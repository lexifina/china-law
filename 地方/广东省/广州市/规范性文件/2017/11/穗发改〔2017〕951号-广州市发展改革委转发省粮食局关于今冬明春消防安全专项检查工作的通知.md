# 广州市发展改革委转发省粮食局关于今冬明春消防安全专项检查工作的通知

各区发展改革局（粮食局），市粮食集团：

现将《广东省粮食局关于开展今冬明春消防安全专项检查工作的通知》（粤粮监〔2017〕237号）转发给你们，请按通知要求深入开展辖内粮油仓储企业今冬明春消防安全专项检查工作，排查隐患，坚决防范和遏制储粮储油火灾事故发生，确保“两会”和“两节”期间消防安全。

专项检查期间，请各区、市粮食集团于每月18日前报送当月工作开展情况；“两会”闭幕后1日内，报送专项检查工作总结和消防安全隐患汇总表至我委粮食处（相关表格见转发文附件）。如遇重大情况，及时上报。

广州市发展和改革委员会

2017年11月22日
