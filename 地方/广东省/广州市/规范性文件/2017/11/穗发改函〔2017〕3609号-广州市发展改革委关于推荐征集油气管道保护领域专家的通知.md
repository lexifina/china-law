# 广州市发展改革委关于推荐征集油气管道保护领域专家的通知

天河区发展改革局、白云区城市管理局、黄埔区安全监管局（广州开发区安全监管局）、花都区发展改革局、番禺区安委办、南沙区发展改革局、从化区城市管理局、增城区城市管理局，广州市安全生产协会，中国石油化工股份有限公司广州分公司、中国石化销售有限公司华南分公司、中国石化销售有限公司广东石油分公司黄埔油库（库外管道）、华南蓝天航空油料有限公司广东分公司（厂区外航油管道）、中国石油西气东输管道公司广东管理处、广东省天然气管网有限公司、广东大鹏液化天然气有限公司、惠州市大亚湾华德石化有限公司、中海油销售东莞储运有限公司，其他有关企业单位：

为贯彻落实《中华人民共和国石油天然气管道保护法》、《中共中央国务院关于推进安全生产领域改革发展的意见》，结合《广州市人民政府关于调整广州市突发事件应急管理专家有关事项的通知》（穗府函〔2017〕57号，广州市政府门户网站全文公开）等近期工作安排，充分发挥专家力量在油气管道保护、安全检查、隐患整治、事故调查、防护方案论证、技术支持、宣教培训等工作中的作用，现组织开展推荐、征集油气管道保护领域专家工作，委托广州市安全生产协会建立油气管道保护领域专家库，有关事项通知如下：

一、专家库专家条件

1．本人愿意参加油气管道保护工作主管部门组织的油气管道保护的有关工作，并接受监督与管理；

2．热心油气管道保护工作事业，具有良好的职业道德，熟悉国家在油气管道保护、安全管理等方面的法律法规、政策要求、有关国家标准和技术规范，具有较高的政策、理论水平，在管道保护领域享有一定社会经验；

3．具有中高级技术职称或注册安全工程师、安全评价师等资格，且直接从事安全生产管理5年以上工作经历；

4．能深入现场开展相关业务工作，有较强现场发现、分析和解决事故隐患的能力，有较强的参与事故调查分析能力；

5．身体健康。年龄一般不超过65周岁，具有正高级专业技术职称或享受国务院政府特殊津贴人员可适当放宽。

二、专家工作任务

1．参加油气管道保护领域的建设项目专项评估评审、重大安全保护问题的专题调研，开展安全技术咨询；

2．为油气管道保护领域执法检查工作提供技术支持；

3．为油气管道及其附属设施隐患排查及重大隐患整改验收等提供技术支持；

4．参加管道安全事故应急救援与事故调查，参与同类多发安全事故技术原因分析与对策措施研究工作；

5．为油气管道保护监管、执法和应急救援以及管道保护法律法规、政策、标准、规范、规划的制定（修订）和管道保护安全形势分析提供技术支持；

6．根据本区域管道保护和国内外相关信息，撰写有关形势分析、重大事故调查或事故隐患评估方面的论文、报告或者建议；

7．为油气管道领域安全监管业务培训提供技术支持。

三、专家主要权利

1．提出专家意见时，不受任何单位和个人的干涉；

2．根据规定获得参与各类管道保护相关活动的劳动报酬；

3．对管道保护工作以及专家库的管理提出意见和建议；

4．参加管道保护业务教育培训。

四、专家主要义务

1．受委托开展相关工作时，应按时开展和完成工作；

2．认真执行有关法律、法规、标准，坚持原则，公正、客观地开展工作，不得弄虚作假；

3．严格执行保密制度，不得擅自披露相关信息，保守生产经营单位商业秘密和知识产权；

4．及时填写和更新个人信息，记录和反馈参加工作或活动的情况，积极参与专家年度考评；

5．紧急、危险情况下，可根据油气管道保护工作主管部门安排开展紧急工作。

五、推进征集和遴选程序

申请入库专家应填写《广州市油气管道保护专家认定申请表》（见附件），并附身份证件、职称证书复印件及其他相关证明材料。所需材料（含《资格认定申请表》一式二份及电子版、有关证明文件等），由本人、申报单位于2017年11月30日前将材料报送至广州市安全生产协会（协会地址：广州市越秀区豪贤路88号4楼，联系人：张长银，联系电话：020－83741475，传真：020－83810451；市发展改革委能源处电话：83124563、83123696）。

我委委托广州市安全生产协会将根据申报材料，对申报专家进行审评遴选，确定专家库拟聘专家名单并进行公示后，我委将印发专家库名单。每届聘期三年。
