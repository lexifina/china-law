# 广州市住房和城乡建设委员会关于公布第一批广州市建设领域工人工资支付分账管理业务银行名录的通知

根据《关于印发广州市建设领域工人工资支付分账管理实施细则的通知》(穗建规字〔2017〕10号)、《广州市住房和城乡建设委员会关于实施<广州市建设领域工人工资支付分账管理实施细则>的通知》(穗建筑〔2017〕1344 号)、《广州市住房和城乡建设委员会关于征集建设领域工人工资支付分账业务银行的通知》(穗建筑〔2017〕2247 号)等有关要求，现公布第一批广州市建设领域工人工资支付分账管理业务银行名录(见附件)。

附件：第一批广州市建设领域工人工资支付分账管理业务银行名录
