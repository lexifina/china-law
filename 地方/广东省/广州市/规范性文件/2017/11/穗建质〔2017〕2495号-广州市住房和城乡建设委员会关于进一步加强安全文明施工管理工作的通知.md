# 广州市住房和城乡建设委员会关于进一步加强安全文明施工管理工作的通知

各区住建局、广州空港委国土规划建设局，市市政工程安全质量监督站、市建设工程安全监督站，各有关单位：

2017广州《财富》全球论坛将于12月6日至8日召开，为进一步做好安全文明施工管理工作，有效防范和应对突发事件，确保论坛顺利举办，现对12月3日至9日，房屋和市政工程安全生产管理工作要求通知如下：

一、各区住建局和各建设工程(质量)安全监督站要督促建设工地严格执行《广州市建设工程文明施工管理规定》，落实“六个100%”的文明施工管理标准。一要确保工地围墙整洁，参照《广州市建设工程绿色施工标准化图册》对工地进行围蔽，强化围墙维护保养;二要抓好扬尘控制，出入车辆要冲洗干净，对散体材料和裸露土体要进行覆盖;三要确保施工现场内整洁有序，材料堆放整齐。

二、严禁施工扰民，从12月1日至12月11日暂停夜间施工作业证明办理。禁止夜间施工作业。

三、各单位要加强对重大危险源进行安全评估，如相关防护措施无法保证安全的应停止施工。严格按照《广州市住房和城乡建设委员会关于严格落实住建部进一步加强危险性较大的分部分项工程安全管理的通知》(穗建质〔2017〕1614号)要求开展危大工程管理。12月3日至12月9日，对存在较大施工安全风险的工地暂时停工;不安排爆破、隧道和基坑开挖(停工期间提前落实暗挖隧道撑子面安全防护加固措施)、高大支模浇筑、起重机械安装(顶升)、大型吊装等危险性较大的分部分项工程作业。

四、各单位要高度重视论坛期间值守应急工作，切实增强政治敏锐性，强化底线思维，保持高度警觉，以极端负责的工作态度和严谨细致的工作作风，切实加强对值守应急工作的组织领导，提前做好值班安排，确保思想到位、责任到位、措施到位、人员到位。

五、各单位要强化火灾事故预防工作。针对冬春电气火灾多发的实际，严格落实消防安全责任，通过“自我检查、自我管理、自我整改”，深入推进工程电气火灾防范整治，切实抓好建筑工程消防安全工作，为广州《财富》全球论坛营造良好的安全环境。
