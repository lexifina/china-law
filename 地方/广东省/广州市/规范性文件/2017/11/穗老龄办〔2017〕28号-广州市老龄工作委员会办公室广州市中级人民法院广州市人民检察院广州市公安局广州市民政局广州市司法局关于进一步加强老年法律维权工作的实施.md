# 广州市老龄工作委员会办公室广州市中级人民法院广州市人民检察院广州市公安局广州市民政局广州市司法局关于进一步加强老年法律维权工作的实施意见

穗老龄办〔2017〕28号

各区老龄办、人民法院、人民检察院、公安分局、民政局、司法局：

根据《中华人民共和国老年人权益保障法》，为贯彻落实全国老龄办等六部门《关于进一步加强老年法律维权工作的意见》（全国老龄办发〔2016〕102号）的精神及要求，切实维护、保障老年人合法权益，结合我市实际，提出如下实施意见：

一、深刻认识加强老年法律维权工作的重要意义

党的十八大和十八届三中、四中、五中、六中全会以及国民经济和社会发展“十三五”规划纲要，对应对人口老龄化提出了明确要求。以习近平同志为核心的党中央就加强老龄工作、推动老龄事业发展作出了一系列重要指示批示，对老年人权益保障工作提出了新的更高要求。截至2016年底，我市60岁以上户籍老年人为154.6万，占户籍总人口的17.76%。到2020年，全市老年人口将达185万，老年人口比重将增加至20%。随着老年人口的不断增多，老年人的人身、财产、赡养、婚姻等侵权案件时有发生，老年人利益诉求呈多元化，回应老年人依法维权诉求的责任凸显，保护老年人合法权益工作需要大力加强。面对新形势、新发展、新要求，进一步加强老年法律维权工作，有利于提高老年人生活和生命质量，有利于促进家庭和睦、社会和谐，有利于实现公平正义、安定有序，对推动老龄事业全面协调可持续发展，全面建成小康社会具有重要意义。

二、总体要求

（一）指导思想。全面贯彻党的十八大、十八届三中、四中、五中、六中全会精神和习近平总书记重要讲话精神以及对广东工作重要批示精神，按照推进全面依法治国要求，做好普法宣传教育，注重工作创新，加大老年人合法权益保障力度，推动老年法律维权工作上新台阶。

（二）基本原则。坚持以人为本和强化服务相结合，围绕老年人广泛关注和亟待解决的问题，为老年人提供优先、及时、高效、便利的法律维权服务；坚持创新发展和注重实效相结合，拓展多层次的服务内涵，搭建多支撑的服务载体，提高老年法律维权服务的实效性；坚持普法宣传和依法治理相结合，既要依托各类媒体平台加大老年法律维权宣传力度，又要把法治宣传教育融入工作实践，引导司法人员依法维护老年人合法权益。

三、主要任务

（一）各级人民法院

1．结合广州市作为全国首批试点城市深化实施庭审实质化改革，为老年维权案件开辟绿色通道。参照《广州市中级人民法院关于推行民事案件繁简分流改革的实施方案（试行）》及两个配套工作规程，大力推行“门诊式”庭审机制，配备专门的“快审团队”，在老年人因追索赡养费、养老金、抚恤金、医疗费等提出的诉讼中，对于案件事实比较清楚、权利义务关系比较明确、证据比较充分的简单民事案件，全部纳入“快审”范围，按照快审程序办理，统一排期开庭，集中时间多案同审、多案连审。发挥天河区作为全国法院案件繁简分流示范法院的带动作用，鼓励各区建立独立平台，建设调解速裁中心，推进案件整体繁简分流；优化资源，推行各民事审判庭局部的二次繁简分流；实行类案审理、简案快办、速裁案件平均审理周期控制在1个月内；速执案件2个月内执结。

2．加强对老年人的应诉指导与帮助。从现阶段老年人参与诉讼的能力和条件差异较大的实际出发，在保证程序公正和平等对待的前提下，注重为老年人特别是没有委托律师辩护或代理的老年人参与诉讼提供必要的程序性指导与帮助。强化诉讼权利义务、举证责任、诉讼风险等事项告知工作。参诉老年人提出调取证据申请，符合法律规定或者法庭认为有必要调查、核实的证据，应当依职权调取、核实。重视老年人的合法权益，让有理无钱的老年人打得起官司，让有理有据的老年人打得赢官司，让打赢官司的老年人及时实现权益。

3．加强困难老年人司法救助。完善社会救助制度体系的司法救助内容，拓宽司法救助资金筹集渠道，探索建立较为完备的老年司法救助组织网络，完善诉讼费缓减免制度，对老年人因追索赡养费、抚养费、医疗费等提出的诉讼要严格遵守审限要求，缴纳诉讼费用确有困难的，依法、及时办理案件受理费的减交、缓交、免交审批手续。

4．提高便利老年人案件措施的实效。根据老年人需求和审判工作的实际需要，因地制宜地开展节假日预约办案、就近开庭、巡回办案等工作。对行动不便的老年人，提供网上立案、上门立案、公告网上送达等服务。

5．实现老年人维权案件快立快审快结快执。针对老年人常见的赡养、继承、诈骗等案件，选任民事审判经验丰富的法官、特邀人民陪审员组成分类专案合议庭专门负责审理，有条件的区级法院及市中院可设立“老年维权合议庭”，专门办理老年人维权案件，进一步优化对涉老案件的审判流程和服务，切实依法重点保护老年人合法权益。充分发挥司法调解、行政调解和人民调解的作用，建立专业化、社会化和人性化解决涉老案件的审判工作机制和社会联动机制。对虐待、遗弃老年人构成犯罪的，严格依法追究刑事责任。

6．做好老年人电信网络防诈骗工作。加强对电信网络诈骗犯罪帮助犯、牵连犯、竞合犯等关联犯罪的打击。加大宣传力度，通过法院公众媒体平台、庭审直播等方式适时向社会公布具有重大影响的典型案件，剖析电信网络诈骗犯罪的手法、特点，提出针对性、实用性的防范措施，提高广大群众尤其是老年人对电信网络诈骗的防范意识和防范能力。

（二）各级检察机关

1．综合发挥惩治、预防、监督、教育、保护等检察职能，为老年人法律维权开辟绿色通道，提供优先、及时、便利、高效的服务。快捕快诉制售假冒伪劣老年人保健品、以老年人为对象的非法集资、非法吸收公众存款、电信网络诈骗、遗弃、虐待等侵犯老年人人身及财产安全的犯罪活动。积极配合有关部门加强对非法行医、黑诊所的专项整治，保障老年病人的身体健康权益。强化涉及老年人合法权益诉讼活动的法律监督。重点监督纠正涉及老年人合法权益的案件该立不立、不该立乱立，以及适用强制措施、查封扣押冻结财务不当等问题。加强对涉及老年人赡养纠纷、社会保障等案件审判、执行活动的法律监督。

2．改进控告申诉、民事行政检察办案方式方法。继续深入开展广州市刑事案件速裁程序试点工作，缩短办案周期，提高开庭效率。充分利用检察机关视频接访系统、12309举报网络平台等渠道为老年人提供便捷的服务。对老年人的来访及控告、申诉，开辟优先通道，优先接待、文明接访、快速办理。积极引入律师等第三方参与化解和代理涉法涉诉信访案件。约访时照顾老年人出行和身体状况，必要时进行上门走访或者电话走访。对办案中涉及的低收入、高龄、失能的老年人，优先移送申请司法救助。

3．加大对侵害老年人合法权益的各类职务犯罪查办力度。依法惩治国家工作人员利用养老保险、医疗救助、金融贷款、国家补贴等职务之便向老年人或代办机构索贿、受贿的犯罪，依法惩治在服务保障老年人权益过程中发生的失职渎职等犯罪，严厉打击保障老年人权益方面的不作为、乱作为，加强涉案赃款赃物的追缴返还。

4．严格执行宽严相济刑事政策，依法保障老年犯罪嫌疑人的合法诉讼权利。对于老年涉案证人的询问工作，尽量安排在其家中或适当的场所进行。对老年犯罪嫌疑人当宽则宽，做到依法少捕慎捕，多采取非羁押手段办案。要保障老年人犯罪嫌疑人律师会见权和辩护权，对经济困难不能聘请辩护人的老年被告人，及时联系法律援助机构为其提供辩护帮助。对于老年人犯罪，要充分考虑其犯罪的动机、目的、情节、后果以及悔罪表现等，并结合其人身危险性和再犯可行性，酌情予以从宽处罚。

5．建设老年维权检察网络。市级检察院争取成立“老年维权案组”，专门办理老年维权案件。有条件的区级检察院设立派驻基层检察室，充分发挥派驻基层检察室在老年维权法律监督、自侦办案、化解矛盾和廉政教育中的职能作用。每月指派一名检察业务骨干挂点派驻检察室，结合“平安”建设和检察“五进”活动，深入城乡基层，就涉老违法问题进行释法说理，及时掌握社情民意，排查矛盾纠纷。通过基层检察室创新打造一批基层“检察服务队”。充分整合基层法律教育资源，以志愿加入为原则，以义务服务为主线，以工作机制为保障，并通过“检察服务队”平台长期化、常态化运作，进一步提高派驻检察室工作质量，力求多渠道解决基层老年群众的司法难题。

6．紧紧围绕老年人权益保障活动开展普法和预防教育。通过开展预防咨询、预防宣传等工作，及时告知老年人享有的合法权益，帮助老年人依法维护自身合法权益。

（三）各级公安机关

1．对老年人的申诉、报警和求助，积极开辟绿色通道，做到反应迅速、处置妥当。依托“六位一体”巡逻防控工作机制，快速处置涉老年人的报警求助。发生涉老年人的重大暴力事件时，羊城突击队及各区分局处突分队及时驰援处置。

2．全面开展“飓风2017”专项行动。重点依法惩处盗窃、诈骗、抢夺、敲诈勒索老年人财物和针对老年人的非法集资、电信网络诈骗、传销等违法犯罪行为，积极维护老年人的人身财产权益。贯彻落实《反家庭暴力法》，根据《依法处置涉家庭暴力案件执法指引》，通过接警、调查取证、调解告诫等执法要求，有效预防和制止家庭暴力，切实保护老年人的合法权益。

3．不断提升公安机关服务管理质量，完善老年人扶助举措。在交管、治安、户政、出入境等窗口单位完善老年人扶助举措，配置必要的便利老年人的设施设备，提供预约、绿色通道等照顾性服务。要大力推进“警民通”APP、广州公安微博微信、广州金盾网互联网应用，进一步方便老年群众办证办事。要进一步完善广州市城区“快处快赔”服务点，全面启用交警互联网服务平台和“交管12123”手机APP，采用网页、语音、短信、移动终端4种方式，持续为老年人提供10大类130余项服务；要继续启用户政智能咨询系统，为老年人提供户政业务咨询便利；进一步提升优化出入境“签注易”等公共服务平台，将24条服务专线全部归整至12345热线“一号受理”，切实提高老年人维权案件的来电热线接通率、现场答复率、按时办结率。

4．积极开展老年人风险防范宣传教育。重点关注养老机构、居家养老服务机构、老年大学（学校）等老年人群密集活动的场所，指导做好安全防范和应急预案工作。组织执法民警以案释法，以事释法。走上街头、深入社区，通过宣传展板、发放宣传资料等形式开展对老年人安全防范的宣传教育。依托基层派出所和社区警务室，通过广州公安微博、微信、警视栏目、防诈骗公益广告、电子屏滚动、宣传栏等方式，在执法办案现场和服务窗口等，大力宣传防火、防盗、防诈骗等常识，以及履行职能、职责的相关法律法规，提高老年人风险防范意识和能力。

（四）各级民政部门

1．进一步完善老年人救助和福利制度。完善城乡最低生活保障、特困人员救助供养、医疗救助和临时救助制度，提高老年人社会救助保障水平，确保符合条件的老年人应保尽保、应养尽养、应救尽救。建立健全经济困难的高龄、失能等老年人护理补贴制度，根据经济社会的发展水平不断完善高龄津贴制度，推进“银龄安康行动”全覆盖，提升老年人抵御意外风险的能力。

2．加快社区居家养老服务体系建设。完善全覆盖、多层次、多支撑、多主体的社区居家养老服务体系，深入推进以“大配餐”为重点的社区居家养老服务“3+X”创新试点。落实“关爱十条”，强化对独居、空巢、失能等老年人的服务保障，健全失能老年人长期照顾服务体系。推进互联网+社区居家养老服务，拓展“平安通”服务，实现居家养老服务管理和支付方式电子化、信息化，加强对居家老年人的社会支持。

3．大力提升养老服务质量。全面深化公办养老机构改革，深入开展以“五查五改、对标达标”为重点的养老院质量提升行动，加快实现养老机构服务管理的专业化、标准化、精细化和信息化，出台养老机构服务行业标准及地方标准。完善公办养老机构入住评估轮候机制，进一步提高轮候效率。建立健全机构分类管理和养老服务评估制度，规范养老服务项目和收费标准。

4．推广“社工+义工”为老服务模式。支持引导社会工作者等专业力量在老年维权工作中发挥积极作用，动员养老机构、家庭综合服务中心、居家养老示范中心、长者日托中心、居家养老服务部等为老服务院舍、站点协同落实老年人维权指引和服务。拓展老年法律维权志愿服务网络，引导律师、公证员及其他有相关专长的义工（志愿者）进驻为老服务机构，为老年人普及法律知识并提供法律维权服务。

（五）各级司法行政机关

1．适当放宽老年人申请法律援助的经济困难标准和受案范围。进一步放宽经济困难标准，降低法律援助门槛，将《国务院办公厅关于制定和实施老年人照顾服务项目的意见》有关精神纳入《广州市法律援助实施办法（修订稿）》修订内容；将八十周岁以上、“三无”（无劳动能力、无生活来源、无赡养人和抚养人）、失能半失能、空巢或残疾老年人纳入免交经济困难申报材料范围。逐步将法律援助服务对象扩展到低收入、高龄、空巢、失能等老年群体。为有鉴定需求的老年人开辟绿色通道，简化委托手续、提供上门服务、对符合条件的老年人给予鉴定费用的减免。充分发挥广州市法律援助基金会的作用，为老年人提供免费法律援助等公益项目。

2．开辟老年人法律援助“快速通道”。对符合条件的老年人申请事项实行当日受理、审查，并快速办理。在实施法律援助的过程中，为老年人优先受理、优先审查、优先指派，尽最大可能减少和消除老年人维权的障碍和难度。

3．进一步完善“市－区－街（镇）”三级法律援助网络。以全市12个法律援助机构、304个法律援助站、2083个法律援助联络点为基础，采取多种措施帮助老年人维护权利。引导基层法律服务所不断向社区和农村延伸，拓展老年人法律援助渠道。

4．加强便民服务窗口建设。完善老年维权无障碍配套服务设施，建设“互联网+法律援助”应用服务平台。推行电话申请、邮寄申请、上门受理、网上受理等服务，方便老年人申请法律援助。

5．加强对法律服务机构的管理和为老法律服务业务的指导。鼓励为老年人提供免费或优惠服务。经常组织律师到老年人集中的社区开展老年人免费法律咨询和法律讲座。按照法律援助与“一村（社区）一法律顾问”制度衔接机制，指导基层法律服务所和专家律师为基层社区、村居委或老年活动室提供优质高效的法律服务。组织公证机构不定期为80周岁以上（含80周岁）老年人免费办理遗嘱公证。

6．把化解老年人矛盾纠纷纳入人民调解工作重点。发挥人民调解作用，组织、指导广大人民调解组织及时化解涉及老年人婚姻、继承、赡养等矛盾纠纷。

（六）各级老龄工作机构

1．协调并推动形成老年法律维权工作合力。发挥统筹协调职能，落实《广州市老龄事业发展第十三个五年规划》任务分工，协调各成员单位结合我市实际推进《老年人权益保障法》配套政策的创制，着力推动公、检、法及司法行政等部门针对老年人权益保障状况不断优化有关加强老年法律维权工作的政策措施。建立完善广州老龄立体化宣传平台，会同有关单位开展老年政策法规及老年防诈骗教育，普及老年法律维权知识，增强老年人自尊、自立、自强的自爱意识和自我保护意识，并通过宣传引导营造全社会尊老敬老爱老助老的良好氛围。

2．优化和落实老年优待政策。贯彻落实好省、市《老年人优待办法》，组织对各单位落实老年优待的情况进行检查评估。研究完善保障老年人权益的制度体系，着力推进《广州市老年人优待办法》修订工作，提升老年人优待水平。

3．强化老年人基础信息采集及老龄研究。积极开展老年人生活状况抽样调查，落实老年人口和老龄事业发展数据监测统计调查制度，开展应对人口老龄化的相关课题研究，为制定完善维护老年人合法权益政策提供参考。

4．进一步加强基层老年协会建设。落实广州市《关于加强基层老年协会规范化建设的意见》，研究建立资助基层老年协会建设的配套制度，发挥基层老年协会在联系老年人、听取老年人意见和诉求、调处家庭赡养等纠纷方面的作用和优势。

三、保障措施

（一）加强宣传引导。各有关单位要把老年法律维权相关内容融入到人口老龄化市情教育和法治宣传教育之中，认真落实“谁执法谁普法”的普法责任制，积极开展法律普及教育。要结合自身职责和工作实际，采取普法讲座、以案释法、法律咨询等方式开展预防教育和警示教育，帮助老年人提高自我保护意识，提高社会治理法治化水平。要依托各类媒体平台加强老年法律政策、法律维权知识宣传力度，进一步提升全民遵法守法意识和老年人依法维权意识。

（二）注重调查研究。以维护老年人合法权益为出发点，坚持问题导向，通过实地考察、调研论证等多种方式梳理涉老案件的焦点、难点，不断完善老年法律维权工作机制，明晰工作重点、改进工作方式、提高工作效率。要建立涉老案件的跟踪管理机制，着重关注不同区域、不同领域涉老案件的个性与共性，注重发挥法律政策的正向引领作用，及时回应老年人合法利益诉求，有效解决涉老法律案件。

（三）强化监督检查。各级老龄办协同相关部门做好本地区老年法律维权工作的指导、督促、检查工作。各有关单位要严格按照工作职责和相关法律要求，加强老年法律维权工作。要建立定期督查制度，通过单位自查、检察机关法律监督、老龄工作机构工作检查等方式对各单位老年法律维权工作进展情况予以检查并提出改进措施，实现内部自纠、外部互督、共同促进。

（四）健全工作机制。要合理利用调解方式办理涉及老年人人身、财产、赡养、婚姻等法律案件，提高涉老案件的办理效率。要加强基层法律维权工作队伍建设，拓展司法所、法律援助工作站等基层服务网络辐射范围，落实专人负责法律援助工作。加强“12348”法律服务热线建设，开通老年法律维权专线，为老年人提供专业的法律维权服务。积极参评国家、省组织开展的老年法律维权工作先进集体或先进个人评选表彰活动，鼓励社会工作者、心理专家参与老年人法律维权工作。
