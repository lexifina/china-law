# 广州市林业和园林局关于聘请毛志江等180位同志为第四届广州市林业园林服务质量义务社会监督员的通知（穗林业园林通〔2017〕694号）

局属各单位、机关各处室、各区（县级市）林业园林部门：

为加强我局与市民群众的沟通联系，接受社会各界对市林业园林工作的监督，经研究决定，现聘请毛志江等180位同志为广州市林业园林服务质量义务社会监督员（第四届）。聘期自2018年1月1日至2019年12月30日止。

特此通知。
