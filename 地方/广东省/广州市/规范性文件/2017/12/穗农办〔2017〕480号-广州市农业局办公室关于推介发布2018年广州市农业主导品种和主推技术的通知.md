# 广州市农业局办公室关于推介发布2018年广州市农业主导品种和主推技术的通知

穗农办〔2017〕480号

关于推介发布2018年广州市农业主导品种和主推技术的通知

各区农业（渔业、畜牧）行政主管部门、市农业技术推广中心：

为贯彻落实党的十九大精神，实施乡村振兴战略，深入推进农业科技入户工程，加快农业科技成果转化，引导农民选用优良品种和先进适用技术，充分发挥科技对农业增效和农民增收的支撑作用，根据《广州市农业主导品种和主推技术评审管理办法（试行）》，我局组织遴选了2018年农业主导品种68个和主推技术19项（详见附件），现予推介发布。

附件：2018年广州市农业主导品种和主推技术

广州市农业局办公室

2017年12月18日
