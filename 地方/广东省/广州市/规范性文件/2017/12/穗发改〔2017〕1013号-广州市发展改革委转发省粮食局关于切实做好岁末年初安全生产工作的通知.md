# 广州市发展改革委转发省粮食局关于切实做好岁末年初安全生产工作的通知

各区发展改革局（粮食局）、市粮食集团：

现将《广东省粮食局关于切实做好岁末年初安全生产工作的通知》（粤粮监〔2017〕247号）转发给你们，请结合《广州市发展改革委转发省粮食局关于今冬明春消防安全专项检查工作的通知》（穗发改〔2017〕951号）一并贯彻执行，切实做好安全储粮和安全生产工作，确保我市粮食行业安全生产形势稳定。有关工作信息和总结与今冬明春消防安全专项检查工作要求合并上报。

广州市发展和改革委员会

2017年12月8日
