# 广州市发展改革委关于印发优化城市道路项目组织实施方式创新投融资体制机制工作方案的通知

市住房城乡建设委、财政局、国土规划委、国资委、法制办、城市更新局、空港委，越秀集团、城投集团、珠江实业集团、建筑集团：

《关于优化城市道路项目组织实施方式创新投融资体制机制的工作方案》已经10月9日市长专题会议审议通过，现印发你们，作为各部门开展相关工作依据。请结合实际工作落实好《工作方案》，加快各个企业参与城市道路建设“一企一策”实施方案报批。实施中遇到的问题，径向市发展改革委反映。

广州市发展和改革委员会

2017年12月18日
