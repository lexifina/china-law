# 广州市住房和城乡建设委员会关于建筑业企业历史业绩补录工作的补充通知

各区住建局、广州空港经济区管理委员会、市建设工程招标管理办公室、市建设工程造价管理站，各有关企业：

根据《广东省住房和城乡建设厅关于广东省建筑市场监管公共服务平台业绩补录工作的补充通知》(粤建市函〔2017〕3505号，见附件)的要求，现就建筑业企业历史业绩补录工作调整事宜通知如下：

一、我委“企业网上申报系统”中的“历史项目业绩申报”业务功能已按照《广东省建筑市场监管公共服务平台历史项目登记表》进行调整设置，施工总承包企业、勘察设计企业、监理企业登录“企业网上申报系统”后，在“历史项目业绩申报”业务项中，根据实际情况录入项目基本信息(必填)后，按粤建市函〔2017〕3505 号文的要求录入与本企业相关的环节信息，并上传《历史业绩补录申请材料真实性承诺函》(粤建市函〔2017〕3505号文的附件2)和相应的证明材料电子文件(勘察设计、监理企业的证明材料一般为中标通知或合同;施工企业的证明材料一般为施工许可或竣工验收报告或其他能证明业绩真实的材料)。

企业类别

合同备案信息

勘察设计企业

必填

除施工图审查信息为必填外，可自选与本企业有关的环节信息

二、除项目基本信息为必须录入的环节外，其他环节各单位根据实际情况选择录入，录入的信息取消人工核对，由系统进行自动校验。例如监理企业可以录完项目基本信息后，可选择录入与本企业有关的招投标信息或者合同信息并上传相应证明文件，然后直接提交，如成功提交即可结束上报，如有错误，系统将提示错误信息，各单位按反馈的错误提示信息修改后再自行上报。

三、项目所在地为广州行政区域的或者企业注册地址在广州行政区域的，均可在我委“企业网上申报系统”录入。

四、申报补录业绩的企业，应对申报资料的真实性、准确性负责;历史业绩上传至全国平台后，将无法修改变更。如发现企业弄虚作假，将暂停受理其业绩补录申请，并将其不良行为录入省级平台诚信库。

特此通知。
