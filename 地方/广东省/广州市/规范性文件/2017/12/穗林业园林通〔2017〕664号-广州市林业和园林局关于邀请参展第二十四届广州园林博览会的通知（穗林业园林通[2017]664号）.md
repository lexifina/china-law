# 广州市林业和园林局关于邀请参展第二十四届广州园林博览会的通知（穗林业园林通[2017]664号）

各有关单位：

根据市委宣传部（市花市办）关于 “花城”品牌建设精神，第二十四届广州园林博览会由市委宣传部指导，市林业和园林局主办，越秀区、天河区、番禺区、广州城投集团承办，广州市公园协会、广州市城市绿化协会协办。

为引导园林绿化行业发展，促进学习交流，发动社会公众广泛参与和实践，推动新工艺、新理念、新手法在城市园林绿化造景中的运用，我局拟将此次园博会部分展位向社会企业公开邀展。现将邀展事项通知如下：

一、展会时间和地点

会时间：

2018年

2月

13日

（年廿八）至

3月

2日

（年十五）

展会地点：海心沙、二沙岛、大夫山森林公园

二、参展单位及职责

参展单位：所有园林绿化企事业单位。

职责：具体负责展位方案创作、展位布置及展品维护、园博会结束后原有绿化恢复等工作。

三、资金来源

企业自筹。

四、展园要求

本次广州园林博览会主题为“花开广州，春暖羊城”。参展作品可以围绕绿色发展、花艺园艺、融合绽放、教育与未来、心灵家园等内容，对主题进行深化和演绎。具体会场要求如下：

（一）海心沙、二沙岛会场

1.海心沙：以立体花坛、自然花境、家居园艺为主，打造创新版迎春花市，将赏花和购花结合起来。

现有5个展位向企业进行邀展（位置详见附件1），各展位面积约

700 m2

，资金参考投入不低于30万元。

2.二沙岛：以艺术公园为中心向周边延伸，以展示城市活力和营造现代艺术氛围为主，建设自然花境、立体绿化、园艺雕塑、城市家具等，应用新材料、新技术、新工艺，融入现有的休闲简洁草坪景观，打造时尚、现代、大气的艺术景观。

现有18个展位向企业进行邀展（位置详见附件1），其中包括：

（1）公共展位：3个。各展位资金参考投入不低于20万元。

（2）大型展位：5个，600

（二）大夫山会场

以传统岭南园林永久性室外展位为主，辅以公共绿化节点及花景花带布置。

五、参展流程

（一）方案申报阶段（2017.12.08-2017.12.20）

各参展单位参照附件1企业展位位置图，填写《海心沙、二沙岛会场申报表》（附件2）、《大夫山会场申报表》（附件3），并于

2017年

12月

20日前

将申报表及布展方案送至广州市城市绿化协会（广州市先烈中路79号黄花岗公园内）。

参展单位可自选申报会场。如申报“海心沙、二沙岛会场”的二沙岛地块，“公共展位”和“大型展位”中至少申报一个，“中小型展位”和“绿雕展位”中至少申报一个，即至少申报2种展位类型方案。

（二）方案评选阶段（2017.12.21-2017.12.22）

市林业和园林局组织成立方案评审委员会，负责展位布展方案的评选并审定评选结果。

市城市绿化协会对企业申报材料进行收集整理，上报给方案评审委员会。

（三）公示阶段（2017.12.22-2017.12.23）

市城市绿化协会将方案评选结果进行网上公示。

（四）展园筹备阶段（2017.12.24-2017.12.31）

参展单位对方案进行深化设计，并开展布展前期准备工作。

（五）布展及维护阶段（2018.01.02-2018.03.02）

参展单位实施展位布置，并在园博会展出期间做好展品的维护工作。

（六）评奖阶段（2018.03.02）

为保障展园效果，市林业和园林局将组织专家、学者成立评奖委员会，在园博会展出后期对所有会场的展位进行统一评奖，对获奖单位的奖励方式如下：

1.由市林业和园林局通过获奖通报、颁发获奖证书等方式对获奖单位进行表彰。

2.根据获奖等次，在广州市园林绿化企业诚信综合评价系统中对参展企业适当加分。

3.获奖证书可作为布展人员评定园林绿化助理工程师、工程师、高级工程师的业绩凭证，也可按有关规定作为申报园林绿化、花卉栽培、插花等专业技师的业绩凭证。
