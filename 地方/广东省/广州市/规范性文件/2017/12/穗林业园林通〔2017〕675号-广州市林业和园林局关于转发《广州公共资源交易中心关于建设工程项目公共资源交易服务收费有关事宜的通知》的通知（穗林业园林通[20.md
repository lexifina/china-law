# 广州市林业和园林局关于转发《广州公共资源交易中心关于建设工程项目公共资源交易服务收费有关事宜的通知》的通知（穗林业园林通[2017]675号）

局属各单位、机关各处室：

现将《广州公共资源交易中心关于建设工程项目公共资源交易服务收费有关事宜的通知》（广州公资交函〔2017〕811号）转发给你们，为确保顺利开展招投标交易活动，请各单位根据实际情况，在招标文件中载明向广州公共资源交易中心支付公共资源交易服务费的方式。

特此通知。

附件：广州公共资源交易中心关于建设工程项目公共资源交易服务收费有关事宜的通知
