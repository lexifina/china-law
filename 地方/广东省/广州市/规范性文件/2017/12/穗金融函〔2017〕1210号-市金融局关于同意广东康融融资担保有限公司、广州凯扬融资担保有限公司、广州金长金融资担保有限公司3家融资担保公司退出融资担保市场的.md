# 市金融局关于同意广东康融融资担保有限公司、广州凯扬融资担保有限公司、广州金长金融资担保有限公司3家融资担保公司退出融资担保市场的通知

穗金融函〔2017〕1210号

市金融局关于同意广东康融融资担保有限

公司、广州凯扬融资担保有限公司、

广州金长金融资担保有限公司3家

融资担保公司退出融资

担保市场的通知

广东康融融资担保有限公司、广州凯扬融资担保有限公司、广州金长金融资担保有限公司：

经省金融办批复（见附件1、2），同意你公司退出融资担保市场。请你公司在接到本通知起10个工作日内上交《融资性担保机构经营许可证》，并于30个工作日内向公司登记机关申请办理变更登记或注销登记，并做好有关善后处置工作。
