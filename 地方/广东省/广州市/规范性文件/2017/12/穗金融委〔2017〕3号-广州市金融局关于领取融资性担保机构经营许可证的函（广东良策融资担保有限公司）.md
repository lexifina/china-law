# 广州市金融局关于领取融资性担保机构经营许可证的函（广东良策融资担保有限公司）

穗金融委〔2017〕3号

广州市金融局关于领取融资性

担保机构经营许可证的函

广东良策融资担保有限公司：

你司因变更注册地址申请换发融资性担保机构经营许可证的函收悉。自2017年10月1日《融资担保公司监督管理条例》（国令第683号）实施后，变更注册地址事项不属于行政审批或备案事项，可直接到工商管理部门办理注册地址变更手续。

经核实，你司于2017年11月20日完成注册地址工商变更手续，注册地址已从“广州市天河区花城大道85号8楼05-06单元”变更为“广州市天河区黄埔大道中309号自编3-22-3”，请你司在接到该函后15个工作日内缴回变更前融资性担保机构经营许可证（编号：粤8800009，流水号：00053604），并领取变更后融资性担保机构经营许可证。
