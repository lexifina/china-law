# 广州市金融局关于领取融资性担保机构经营许可证的函（广州市裕丰泰融资担保有限公司）

穗金融委〔2017〕4号

广州市金融局关于领取融资性

担保机构经营许可证的函

广州市裕丰泰融资担保有限公司：

你司因变更注册地址申请换发融资性担保机构经营许可证的函收悉。自2017年10月1日《融资担保公司监督管理条例》（国令第683号）实施后，变更注册地址事项不属于行政审批或备案事项，可直接到工商管理部门办理注册地址变更手续。

经核实，你司于2017年11月22日完成注册地址工商变更手续，注册地址已从“广州市天河区体育西路153号2004房”变更为“广州市天河区天河北路183-187号2509房”，请你司在接到该函后15个工作日内缴回变更前融资性担保机构经营许可证（编号：粤8800199，流水号：00051536），并领取变更后融资性担保机构经营许可证。
