# 市金融局关于同意广州市金诺小额贷款有限公司变更高管的批复

穗金融贷〔2017〕109号

市金融局关于同意广州市金诺小额贷款

有限责任公司变更高管的批复

越秀区金融局：

你局《关于广州市金诺小额贷款有限责任公司变更高管的请示》（越金融〔2017〕320号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定。经审核，王永进、王振龙符合任职条件，我局批复如下：

同意王永进任广州市金诺小额贷款有限责任公司董事，免去严多林董事职务。

同意王振龙任广州市金诺小额贷款有限责任公司财务总监，免去乐恺财务总监职务。

同意撤销黄路副总经理职务。

广州市金融工作局

2017年12月8日

公开方式：主动公开

抄送：省金融办，广州市金诺小额贷款有限责任公司。
