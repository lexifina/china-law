# 广州市发展改革委转发省发展改革委关于垃圾焚烧发电项目垃圾处理量核定工作等问题的通知

市城管委：

现将《广东省发展改革委关于垃圾焚烧发电项目垃圾处理量核定工作等问题的通知》（粤发改价格函〔2018〕537号）转发给你委。请结合我市实际情况制定具体实施意见，并通知各区城管局协助垃圾焚烧发电企业做好相关工作。执行过程中有何问题，请向市发展改革委（价格管理处）反映。

广州市发展和改革委员会

2018年2月14日
