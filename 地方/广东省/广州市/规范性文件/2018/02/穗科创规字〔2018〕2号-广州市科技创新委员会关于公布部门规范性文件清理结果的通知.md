# 广州市科技创新委员会关于公布部门规范性文件清理结果的通知

各有关单位：

为深入推进“放管服”改革、加强生态文明建设和环境保护，加快法治政府建设，推进依法行政，按照省、市部署，我委对2017年5月31日之前公布的部门规范性文件进行了清理。现将清理结果公布如下：

一、保留部门规范性文件13份。

二、修改部门规范性文件6份。

三、废止部门规范性文件4份。

四、宣布失效部门规范性文件25份。

附表：1. 部门规范性文件清理目录(保留)

2. 部门规范性文件清理目录(修改)

3. 部门规范性文件清理目录(废止)

4. 部门规范性文件清理目录(失效)

广州市科技创新委员会

2018年2月4日
