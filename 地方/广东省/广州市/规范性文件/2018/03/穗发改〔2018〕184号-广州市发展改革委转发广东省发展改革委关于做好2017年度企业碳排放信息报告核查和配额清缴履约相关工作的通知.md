# 广州市发展改革委转发广东省发展改革委关于做好2017年度企业碳排放信息报告核查和配额清缴履约相关工作的通知

各有关企业：

现将《广东省发展改革委关于做好2017年度企业碳排放信息报告核查和配额清缴履约相关工作的通知》（粤发改气候函〔2018〕758号）转发给你们。请广州市列入名单的企业按照省的通知要求做好2017年度碳排放信息报告核查和配额清缴履约工作。广州市报告企业请于3月15日前将提交报告系统的2017年度碳排放信息报告（打印盖章，一式两份）报市发展改革委资环处，控排企业请于5月5日前将提交报告系统的2017年碳排放信息报告（打印盖章，一式两份）和核查机构出具的书面核查报告（一式两份）报市发展改革委资环处。

附件：广东省发展改革委关于做好2017年度企业碳排放信息报告核查和配额清缴履约相关工作的通知
