# 广州市发展改革委转发广东省发展改革委关于自备电厂有关收费政策的通知

各区发展改革局，开发区市场监管局，广州供电局：

现将《广东省发展改革委关于自备电厂有关收费政策的通知》（粤发改价格〔2018〕130号）转发给你们，请贯彻执行。在执行过程中，协助通知符合条件的企业按《通知》第二项要求向我委提出书面申请，我委重点对项目工艺流程、资源利用等情况进行核实后，提出初审意见上报省发展改革委审定。执行中如有问题，请及时向我委（价格管理处）反映。

广州市发展和改革委员会

2018年3月15日
