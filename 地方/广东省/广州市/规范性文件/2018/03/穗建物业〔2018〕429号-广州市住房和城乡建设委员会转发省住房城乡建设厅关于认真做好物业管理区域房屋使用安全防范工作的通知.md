# 广州市住房和城乡建设委员会转发省住房城乡建设厅关于认真做好物业管理区域房屋使用安全防范工作的通知

各区住建部门：

现将《广东省住房和城乡建设厅关于认真做好物业管理区域房屋使用安全防范工作的通知》（粤建房函〔2018〕543号，以下简称《通知》）转发给你们，并提出以下要求，请一并贯彻落实。

一、提高认识，落实责任

各区住建部门应当充分认识物业管理区域安全防范工作的重要性和严峻性，深入学习并贯彻落实中共中央办公厅国务院办公厅印发《关于推进城市安全发展的意见》和《通知》，认真履职，将文件精神传达至辖区内所有物业服务企业，督促辖区内物业服务企业做好安全生产工作，切实强化对辖区内物业管理区域安全工作的监管措施。

二、深入排查，督促整改

结合日常巡查工作，督促辖区内各物业服务企业开展全面深入的安全生产自查自纠，发现问题及时督促整改，对拒不配合整改的，告知有关主管部门依法处置。

三、加大宣传，提升意识

督促物业服务企业及有关管理单位定期在在管理区域内组织开展形式多样的安全生产政策法规和安全常识宣传，通过各种有效手段和途径，动员广大业主共同维护小区内的安全，增强业主安全意识。

特此通知。
