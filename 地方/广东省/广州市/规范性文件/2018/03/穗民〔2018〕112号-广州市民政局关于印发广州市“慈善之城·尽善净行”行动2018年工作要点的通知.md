# 广州市民政局关于印发广州市“慈善之城·尽善净行”行动2018年工作要点的通知

穗民〔2018〕112号

各区民政局，局机关有关处室、局属有关单位，全市各慈善组织：

为进一步打造公开透明、廉洁高效的慈善环境，健全慈善事业监管体系，促进我市现代慈善事业健康发展，根据《关于深化“羊城慈善为民”行动创建全国“慈善之城”之“尽善净行”工作方案》和《广州市深化“羊城慈善为民”行动创建“慈善之城”2018年工作方案》，制订了《广州市“慈善之城·尽善净行”行动2018年工作要点》。现印发给你们，请结合实际认真贯彻执行。

广州市民政局

2018年3月24日

广州市“慈善之城 尽善净行”行动2018年工作要点

2017年，我市在创建全国慈善之城中创新开展“慈善之城·尽善净行”行动，取得良好成效。2018年，是我市开展“慈善之城·尽善净行”行动的深化之年。为全面贯彻党的十九大精神，坚持以习近平新时代中国特色社会主义思想为指导，不断增强慈善工作的透明度和公信力，进一步营造公开透明、干净行善的慈善发展环境，为广州创建慈善之城保驾护航。根据《关于深化“羊城慈善为民”行动创建全国“慈善之城”之“尽善净行”工作方案》和《广州市深化“羊城慈善为民”行动创建“慈善之城”2018年工作方案》，围绕政府监管、社会监督、行业自律、内部治理、公开透明等核心任务，制订广州市“慈善之城·尽善净行”行动2018年工作要点如下：

一、修订《广州市募捐条例》

进一步完善慈善信息公开和监督制度，结合民政部对慈善组织信息公开、捐赠领域失信联合惩戒等实施细则，完善广州慈善组织、募捐活动的信息公开事项、监督管理方式以及惩戒措施等规定，为政府有效监管提供法治保障。（牵头部门：市民政局救灾慈善处，配合部门：市民政局宣传法规处、社管局；完成时间：2018年12月）

二、开展清风促善行专项执法

市区民政部门开展慈善专项行政执法工作，参照《广州市慈善募捐行政执法工作指引》，通过深入慈善组织、募捐项目活动场所等方式，达到年度检查监督率不低于5％。市民政局要对各区民政局执法情况进行指导、监督和通报。（牵头部门：市民政局救灾慈善处，配合部门：各区民政局；完成时间：2018年12月）

三、监督慈善扶贫项目实施情况

从扶贫政策落实、项目进展、慈善资金使用等方面对慈善组织参与的扶贫项目进行重点监督，委托第三方社会专业监督机构抽查10个项目开展专项审计，确保扶贫慈善资金用在实处，发挥慈善组织和慈善资金在脱贫攻坚工作中的积极作用。（牵头部门：市民政局救灾慈善处，配合部门：市慈善服务中心、市慈善组织社会监督委员会；完成时间：2018年12月）

四、组织慈善为民月系列活动

通过举办“慈善为民月”活动启动仪式、北京路慈善嘉年华活动、广东扶贫济困日活动等多种宣传形式，引导社会关注慈善诚信，鼓励和规范慈善行为，为慈善之城创建工作营造良好的慈善环境。（牵头部门：市慈善服务中心，配合部门：各区民政局，市民政局救灾慈善处；完成时间：2018年6月）

五、发布慈善力指数评价报告

召开专题新闻发布会，发布区域性慈善力指数评价报告，科学评价广州及各区慈善事业发展水平、潜力等情况，为社会公众提供了解广州慈善的新途径，为慈善组织启发进步方向，推动广州慈善更公开、更均衡、更廉洁发展。（牵头部门：市民政局救灾慈善处，配合部门：各区民政局；完成时间：2018年9月）

六、公布慈善透明度评估结果

通过对慈善组织和项目的基本信息、治理信息、业务信息、财务信息等综合评估，向社会公众公布全市慈善组织慈善透明度评估结果，以引导慈善组织运作的规范化，促进慈善组织自律和他律。（牵头部门：市民政局救灾慈善处，配合部门：市慈善组织社会监督委员会；完成时间：2018年9月）

七、开展百个知名慈善项目晒账单

在9月5日中华慈善日期间，继续开展慈善公众开放日活动，搭建社会公众与慈善组织面对面交流互动平台，参观市区慈善组织，实施百个知名慈善项目晒账单，打造诚信慈善、阳光慈善。（牵头部门：市慈善服务中心，配合部门：各区民政局、市民政局救灾慈善处、广州市广益联合募捐发展中心；完成时间：2018年9月）

八、实施百名慈善人才培优计划

提升民政部门和慈善组织专业人员综合技能，通过“善知学园”、“慈善讲坛”等培训平台，围绕慈善政策法规、募捐活动、财务管理、信息公开、慈善资源链接、违法违规案例分析等重点内容，培养100名适应新时代慈善事业发展需要的现代慈善人才。（牵头部门：市慈善服务中心，配合部门：市公益慈善联合会；完成时间：2018年12月）

九、升级广益联募信息发布平台

在“善捐”（慈善募捐）、“善助”（个人求助）、“善行”（慈善活动）基础上，完成“善品”（慈善电商）和“善知”（能力支持）两大模块，实现捐赠资源、慈善项目与社会救助精准对接，做到捐赠信息实时显示反馈、项目实施进展信息公开反馈查询全流程公开透明，将其打造成为影响全国的“集善地”和全民慈善的便易平台。（牵头部门：市慈善服务中心，配合部门：广州市广益联合募捐发展中心；完成时间：2018年12月）

十、开展慈善读本进校园进家庭活动

传播广府慈善文化，在中小学开展慈善读本阅读计划。以读本为桥梁延伸开展“读慈善书，上慈善课，做慈善事”等丰富多样的活动，教育学生识别慈善组织、慈善募捐标识，区分真慈善活动和虚假骗人行为，并带动家庭参与慈善，推动良好家风建设。（牵头部门：市慈善服务中心，配合部门：市民政局救灾慈善处、市公益慈善联合会；完成时间：2018年12月）
