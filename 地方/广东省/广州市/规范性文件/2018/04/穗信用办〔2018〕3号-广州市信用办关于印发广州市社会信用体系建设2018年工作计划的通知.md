# 广州市信用办关于印发广州市社会信用体系建设2018年工作计划的通知

市社会信用体系建设统筹协调小组各成员单位：

根据国家和省关于社会信用体系建设的各项部署，我办制定了《广州市社会信用体系建设2018年工作计划》，经市社会信用体系建设统筹协调小组同意，现印发给你们，请结合本部门工作实际认真贯彻落实，各牵头单位请于7月和12月将半年和全年工作推进情况报送我办（电子版同步发送至：gzxyjs＠126．com）。

附件：广州市社会信用体系建设2018年工作计划

广州市社会信用体系建设统筹协调小组办公室

2018年4月19日
