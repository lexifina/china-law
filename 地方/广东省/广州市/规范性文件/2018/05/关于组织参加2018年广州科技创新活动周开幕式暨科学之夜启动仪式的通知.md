# 关于组织参加2018年广州科技创新活动周开幕式暨科学之夜启动仪式的通知

各有关单位：

按照《科技部 中央宣传部 中国科协关于举办2018年科技活动周的通知》(国科发政〔2018〕69号)，2018年全国科技活动周将于5月19日至26日举办。为大力宣传近年来广州市科技创新发展取得的重要成果和突出成就，从2018年开始，广州科技活动周更名为广州科技创新活动周。2018年广州科技创新活动周将于5月19日至26日举行，主题为“创新发展 美好生活”。根据安排，2018年广州科技创新活动周开幕式暨科学之夜启动仪式定于5月19日(星期六)18:30在广东科学中心举行(议程详见附件)。

请各单位安排有关负责人或代表拨冗出席开幕式暨科学之夜启动仪式，并将参加人员回执于5月16日传真至市科创委科普宣传处(传真电话：83124156);或用手机扫一扫以下二维码填写回执。

2018年广州科技创新活动周开幕式暨科学之夜启动仪式议程

二、活动地点

广东科学中心主场馆一楼(广州市番禺区大学城科普路168号)

三、主要议程

18:00-18:30 嘉宾签到

19:00-19:05 开场表演

19:05-19:10 领导致辞

19:10-19:15 广州科普创新奖颁奖礼

19:15-19:20 广州市中小学生科普知识竞赛颁奖礼

19:20-19:30 启动仪式
