# 市金融局关于广州凯得小额贷款股份有限公司变更公司章程的批复

开发区金融局：

你局《关于审批广州凯得小额贷款股份有限公司变更公司章程的请示》（穗开金融报〔2018〕332号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定。经审核，广州凯得小额贷款股份有限公司章程变更符合规定，我局批复如下：
