# 市金融局关于广州凯得小额贷款股份有限公司变更高管的批复

开发区金融局：

你局《关于审批广州凯得小额贷款股份有限公司变更高经管理人员的请示》（穗开金融报〔2018〕333号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定。经审核，于钦江、黄礼黎符合任职条件，我局批复如下：

一、同意于钦江担任广州凯得小额贷款股份有限公司董事长兼法定代表人，免去严亦斌董事长兼法定代表人职务。

二、同意黄礼黎担任广州凯得小额贷款股份有限公司职工代表董事及总经理，免去谢育能职工代表董事及总经理职务。
