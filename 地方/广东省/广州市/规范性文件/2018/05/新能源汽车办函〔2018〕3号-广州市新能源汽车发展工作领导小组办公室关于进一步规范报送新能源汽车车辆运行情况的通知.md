# 广州市新能源汽车发展工作领导小组办公室关于进一步规范报送新能源汽车车辆运行情况的通知

各有关单位：

按照《广州市新能源汽车发展工作领导小组办公室关于做好报送新能源汽车及充电设施运行情况工作的通知》及《广州市新能源汽车发展工作领导小组办公室关于进一步做好新能源汽车车辆运行及充电基础设施信息统计工作的通知》要求，我市相关企业能及时、准确报送车辆信息，但实际工作中也存在一些问题：报送数据表未按要求格式填写，自行增加或减少相关内容；报送内容填写不准确，未按规范填写或存在填写错误（如车牌号、行驶证日期）等；数据不真实，如出现累计行驶里程及充电量本月比上月小等情况。为进一步规范新能源汽车车辆运行信息的报送工作，针对上述问题，现就有关工作通知如下：

一、车辆生产企业作为信息报送责任主体，要高度重视，指定专人负责，确保信息及时、准确报送。

二、根据国家及省市有关新能源汽车推广应用工作要求，车辆生产企业需建立车辆运行监控平台，并按照要求接入国家监管平台数据库内，可以进行实时数据传输，企业报送信息数据需从该平台采集，坚决杜绝虚报。

三、各企业应建立车辆及运行情况台帐，做好资料建档工作。对推广应用工作不到位、存在弄虚作假的单位，将视情况予以通报批评，直至取消其新能源汽车地方财政补贴资格。
