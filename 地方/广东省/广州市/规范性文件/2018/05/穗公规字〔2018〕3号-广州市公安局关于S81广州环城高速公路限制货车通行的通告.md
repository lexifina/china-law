# 广州市公安局关于S81广州环城高速公路限制货车通行的通告

为缓解市区道路和S81广州环城高速公路交通堵塞，优化交通组织，确保道路交通安全、畅通，根据《中华人民共和国道路交通安全法》的有关规定，我局决定结合高速路网的变化，将S81广州环城高速公路部分过境货车分流到外围高速道路行驶，请受限货车提前绕道通行。现通告如下：

一、每日7时至22时，禁止15吨以上货车（指核定载质量、牵引质量为15吨及15吨以上的货车、牵引车）通行S81广州环城高速（含北环高速公路和东南西环城市快速路，但不含东南西环城市快速路仑头互通立交至土华互通立交路段）。

二、执行紧急任务的军车、警车、消防车、工程救险车不受上述措施的限制。

三、违反本通告的，由公安机关交通管理部门依法予以处理。

四、本通告自2018年7月1日零时起施行，有效期5年。《关于限制货车通行环城高速公路的通告》（穗公〔2014〕23号）同时废止。

广州市公安局
