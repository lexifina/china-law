# 广州市发展改革委转发关于全面加快推进粮库智能化升级改造和省级平台项目建设的通知

黄埔、番禺、南沙区发展改革局（粮食局）：

现将省粮食局《转发国家粮食和物资储备局〈关于全面加快推进粮库智能化升级改造和省级平台项目建设的通知〉》（粤粮科储〔2018〕87号）转发给你们。请各单位加快推进辖内粮库智能化升级改造项目的建设工作，组织项目建设单位做好项目招标采购前期准备，确保6月底前启动项目招投标工作。抓好项目进度、质量、资金管理工作，落实绩效考核各项规章制度，发现问题及时整改落实。

请各单位指定1名同志专门负责此项工作，并于5月18日前将名单报我委粮食处。从5月起，请各单位于每月3日前填报《项目建设进展情况月报》（详见转发文附件1、2）报我委粮食处。

广州市发展和改革委员会

2018年5月15日
