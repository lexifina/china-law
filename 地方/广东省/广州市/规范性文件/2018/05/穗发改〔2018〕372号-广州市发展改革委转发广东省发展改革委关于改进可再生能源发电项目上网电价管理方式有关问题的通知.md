# 广州市发展改革委转发广东省发展改革委关于改进可再生能源发电项目上网电价管理方式有关问题的通知

各区发展改革局、开发区市场监管局，广州供电局：

现将《广东省发展改革委关于改进可再生能源发电项目上网电价管理方式有关问题的通知》（粤发改价格〔2018〕222号）转发给你们，请遵照执行。

根据广东省定价目录（2018年版）规定，请广州供电局在每季度结束后10个工作日内向省发展改革委报送上一季度新投产相关可再生能源发电项目上网电价执行情况的同时，一并抄送我委。

广州市发展和改革委员会

2018年5月16日
