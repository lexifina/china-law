# 广州市发展改革委转发国家能源局关于减轻可再生能源领域企业负担有关事项的通知

各区发展改革局，广州供电局有限公司：

现将《广东省发展改革委转发国家能源局关于减轻可再生能源领域企业负担有关事项的通知》（粤发改能新函〔2018〕2071号）转发给你们，请遵照执行。并请各区发展改革局转发给区内可再生能源领域企业。

专此

广州市发展和改革委员会

2018年5月22日
