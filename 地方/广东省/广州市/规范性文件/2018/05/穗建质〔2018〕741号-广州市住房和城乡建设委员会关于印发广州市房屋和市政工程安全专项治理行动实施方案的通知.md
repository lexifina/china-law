# 广州市住房和城乡建设委员会关于印发广州市房屋和市政工程安全专项治理行动实施方案的通知

各区住建设局、广州空港委国规建设局、市市政站、市安监站：

为贯彻落实2018年全国、全省安全生产以及住房和城乡建设部建筑安全生产工作的部署，强化建筑施工安全生产管理，有效预防施工安全事故的发生，根据《广东省住房和城乡建设厅关于印发广东省建筑施安全专项治理行动实施方案的通知》（粤建质〔2018〕78号）的工作部署，我委制定了《广州市房屋和市政工程安全专项治理行动实施方案》，现印发给你们，请认真贯彻执行。
