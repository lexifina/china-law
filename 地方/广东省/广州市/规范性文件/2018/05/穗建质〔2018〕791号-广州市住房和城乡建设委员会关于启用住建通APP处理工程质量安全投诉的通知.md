# 广州市住房和城乡建设委员会关于启用住建通APP处理工程质量安全投诉的通知

各有关单位：

为进一步提高我委工程质量安全监管信息化水平，充分发挥广大人民群众的监督监管作用，我委组织开发了住建通APP，开通群众使用APP对在建房屋建筑和市政基础设施工程质量安全存在的问题进行投诉的功能。为切实做好群众质量安全投诉处理工作，现将有关事项通知如下：

一、住建通APP已通过苹果公司应用商店和腾讯手机应用宝对外发布，用户可通过上述应用商店下载安装使用。该APP实现群众利用手机随时对在建工程质量安全问题进行投诉，并跟踪投诉处理情况。

二、群众对工程的质量安全投诉信息通过住建通APP上传至建设工程“一张图”管理信息系统”，经管理员后台审核后，直接派发到监管的监督站进行处理，同时通过手机短信及时通知项目监管的监督员。

三、各监督站应及时督促监督员登录建设工程“一张图”管理信息系统，在规定的时间内核实投诉事项，并跟踪督促施工单位及时处理，处理结果通过“一张图”系统反馈给投诉人。

四、各级建设行政主管部门对投诉处理情况进行抽查，对未及时跟踪处理的监督站、监督员进行约谈、通报批评，同时，质量安全投诉处理情况将纳入我委对各监督站考核评价管理，具体评价规则另行制定。

特此通知。
