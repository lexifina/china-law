# 广州市住房和城乡建设委员会转发广东省住房和城乡建设厅关于房屋建筑和市政基础设施工程质量监督工作指引（暂行）的通知

各区住建局、广州空港委国土规划和建设局，市建设工程质量监督站、市政工程安全质量监督站：

现将《广东省住房和城乡建设厅关于印发房屋建筑和市政基础设施工程施工质量监督工作指引（暂行）的通知》（粤建规范〔2018〕3号）转发你们，请认真贯彻执行。执行中如有意见和建议，请反馈我委，由我委汇总报省住房城乡建设厅。
