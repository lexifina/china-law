# 广州市科技创新委员会、广州市教育局关于公布2018年广州市中学生防震减灾知识竞赛结果暨推荐全国防震减灾知识大赛南部赛区竞赛参赛学校的通知

穗科创字〔2018〕112号

各区科技主管部门、教育局：

在市区两级科技、教育部门及参赛学校的通力合作下， 2018年我市中学生防震减灾知识竞赛取得圆满成功，现将竞赛结果及推荐参加全国防震减灾知识大赛南部赛区竞赛学校名单公布如下：

一、竞赛获奖结果

(一)团体奖

一等奖：广州市执信中学;

二等奖：广州市天河外国语学校(天河区)、广州市第五中学(海珠区)、广州市南沙鱼窝头中学(南沙区);

三等奖：广州市真光中学(荔湾区)、广州市大同中学(白云区)、广州市第17中学(越秀区)、广州市增城区职业技术学校(增城区)、广州科学城中学(黄埔区)、黄冈中学广州学校(花都区)、广州市从化区第三中学(从化区)、广州市禺山高级中学(番禺区)。

(二)个人单项奖

最佳风采奖：广州科学城中学——潘芷柔;

最佳创意奖：黄冈中学广州学校——陈秋伯;

最强王者奖：广州市禺山高级中学——姜悦;

最佳表现奖：广州市天河外国语学校——岳子晗;

非凡突出奖：广州市执信中学——严晓潼。

二、推荐全国赛参赛学校

广州市执信中学。

希望获奖的同学们戒骄戒躁、继续努力，在防震减灾知识学习与传播、宣传教育活动中大显身手，立志为防震减灾事业贡献自己的力量!希望参加全国赛的学校精心组织，充分准备，赛出风格、赛出水平，争取优异成绩，为我市防震减灾事业争光添彩!

特此通知

广州市科技创新委员会 广州市教育局
