# 市金融局关于广州凯得小额贷款股份有限公司变更注册资本及股权股东的批复

穗金融函〔2018〕612号

市金融局关于广州凯得小额贷款股份

有限公司变更注册资本及

股权股东的批复

开发区金融局：

你局《关于审批广州凯得小额贷款股份有限公司变更注册资本的请示》（穗开金融报〔2018〕330号）及《关于审批广州凯得小额贷款有限公司变更股权股东的请示》（穗开金融报〔2018〕332号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定。经审核，广州凯得小额贷款股份有限公司变更注册资本及变更股权股东符合规定，现批复如下：

一、同意广州中味餐饮服务有限公司出资1000万元,将广州凯得小额贷款股份有限公司注册资本从人民币30000万元增加至人民币31000万元，持有广州凯得小额贷款股份有限公司3.23%的股权。

二、请你局通知广州凯得小额贷款股份有限公司自批复之日起依法向工商部门办理公司章程变更备案。

三、广州凯得小额贷款股份有限公司完成注册资本、股权股东变更后，你局应按照相关政策规定的要求，进一步加强对该公司的管理与服务，督促该公司合规经营并做好风险防控工作。

广州市金融工作局
