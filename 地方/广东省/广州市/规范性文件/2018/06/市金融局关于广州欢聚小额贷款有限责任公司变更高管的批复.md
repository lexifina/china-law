# 市金融局关于广州欢聚小额贷款有限责任公司变更高管的批复

越秀区金融局：

你局《关于广州欢聚小额贷款有限责任公司变更高管的请示》（越金融〔2018〕156号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定。经审核，金秉、王蕙符合任职条件，我局批复如下：

一、同意金秉担任广州欢聚小额贷款有限责任公司法定代表人，免去李学凌法定代表人职务。

二、同意王蕙担任广州欢聚小额贷款有限责任公司总经理，免去刘展喜总经理职务。
