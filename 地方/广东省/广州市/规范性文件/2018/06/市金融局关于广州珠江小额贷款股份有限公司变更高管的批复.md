# 市金融局关于广州珠江小额贷款股份有限公司变更高管的批复

越秀区金融局：

你局《关于广州珠江小额贷款股份有限公司变更法定代表人、董事及监事的请示》（越金融〔2018〕138号）收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定。经审核，梁永恒、罗淇锋、林建青、刘岁声符合任职条件，我局批复如下：

一、同意梁永恒担任广州珠江小额贷款股份有限公司法定代表人兼董事长、董事，免去麦燕玉法定代表人兼董事长、董事职务。

二、同意罗淇锋担任广州珠江小额贷款股份有限公司董事，免去李建宁董事职务。

三、同意林建青担任广州珠江小额贷款股份有限公司监事，免去杨伟华监事职务。

四、同意刘岁声担任广州珠江小额贷款股份有限公司监事，免去何雄监事职务。

广州市金融工作局

2018年5月28日
