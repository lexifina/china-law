# 广州市农业局办公室关于组织做好2018年广东省名牌产品（农业类）申报和复审工作的通知

穗农办〔2018〕237号

关于组织做好2018年广东省名牌产品（农业类）申报和复审工作的通知

各区农业（畜牧兽医、渔业）行政主管部门，局属有关单位：

根据广东省名牌产品(农业类)推进委员会办公室和广东省南方名牌农产品推进中心《关于2018年广东省名牌产品（农业类）申报和复审的通知》精神，结合实际，为做好我市省名牌产品（农业类）申报和复审工作，现将有关事项通知如下：

一、相关文件查阅方式

《关于2018年广东省名牌产品（农业类）申报和复审的通知》、《2018年广东省名牌产品（农业类）申报范围指导目录》、《2018年广东省名牌产品（农业类）申报指南》、《2018年广东省名牌产品（农业类）到期复审名单》及相关通知公告请登录“广东省名牌产品（农业类）网”或“广东农业信息网”查阅下载。我市到期复审名单详见附件1。网上申报过程中如有疑问，请拨打联系电话：020-37288229，技术服务电话：400-033-0890。

二、工作要求

（一）高度重视，落实工作责任

广东省名牌产品（农业类）申报和复审工作是加快推进我市农业品牌化的重要工作。因申报工作全部采取网上申报，时效性较强，请各部门及有关单位高度重视，安排专人负责，并将本通知精神传达至辖区内每一个申报和复审企业，并严格按照时间要求报送申报材料。

（二）精心组织，认真开展申报和复审工作

1.时间要求。网上申报截止时间为2018年8月14日。为做好汇总、审核和上报工作，请各区督促各申报主体务必在8月7日前完成网上申报工作，确保申报企业网上申报材料与纸质材料一致。

2.申报程序。分为初评申报和复审申报，申报产品应为单一产品。复审产品中原为系列产品的，要更改为单一产品；不更改为单一产品的，不予复审。具体申报流程请参照《2018年广东省名牌产品（农业类）申报指南》。

3.审核和上报。各区农业（畜牧兽医、渔业）行政主管部门负责对本辖区内初次申报、复审申报企业的申报材料进行认真审核，确保提交材料的复印件与原件相符，填写《2018年广东省名牌产品（农业类）申报区行政主管部门审核意见表》（附件2）并加盖公章，连同申报材料纸质件（一式两份），于8月11日前送我局交流合作处（市场信息处），以便汇总审核上报。凡是没有区农业（畜牧兽医、渔业）行政主管部门推荐意见的申报材料，或申报企业自行报送的，我局一律不予受理。
