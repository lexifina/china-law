# 广州市住房和城乡建设委员会关于印发2018年度重大行政决策事项目录的通知

机关各处室、委属各单位：

《广州市住房和城乡建设委员会2018年度重大行政决策事项目录》已经委主任办公会议审议通过，现予以印发。请建筑业管理处牵头，各单位配合，参照《广州市重大行政决策程序规定》等文件认真组织实施，落实好公众参与、专家论证、风险评估、合法性审查、集体决定等决策必经程序。

特此通知。
