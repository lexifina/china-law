# 广州市民政局转发关于大力培育发展社区社会组织的意见的通知

各区民政局：

为进一步推动我市社区社会组织的健康有序发展，充分发挥社区社会组织在基层治理中的积极作用，现将《广东省民政厅转发民政部关于大力培育发展社区社会组织的意见的通知》（粤民发〔2018〕54号，以下简称《意见》）转发你们，并结合我市实际提出以下意见，请一并贯彻执行。

一、加强组织领导，实施分类管理

各区民政部门要进一步深化对培育发展社区社会组织工作重要性的认识，切实做好社区社会组织的登记管理和培育扶持工作。符合法定登记条件的社区社会组织，到所在区民政部门申请登记，其中符合直接登记条件的可以直接提出申请。对未达到登记条件的社区社会组织，按照不同规模、业务范围、成员构成和服务对象，由街道办事处（乡镇政府）实施管理，加强分类指导和业务指导；对规模较小、组织较为松散的社区社会组织，由社区党组织领导，基层群众性自治组织对其活动进行指导和管理。积极争取党委和政府的重视与支持，推动将社区社会组织发展和管理工作纳入基层政府绩效考核内容和社会治安综合治理考评体系。指导街道（乡镇）党（工）委和城乡社区党组织加强对社区社会组织各项工作的领导，确保社区社会组织沿着正确方向发展。

二、积极推动发展社区社会组织联合会

各区民政部门要围绕加强和创新社会治理、“三社联动”、培育发展社区社会组织、发挥社会组织作用等方面，不断探索创新基层社会治理的途径方式，积极推动发展社区社会组织联合会，结合《中共广州市委政法委员会关于推动进一步加强区和街镇两级平安促进会建设的通知》的要求，将街镇社区社会组织联合会的建设与街镇平安建设促进会的工作相衔接，通过加挂牌子的方式，共同促进街镇社区社会组织联合会和平安建设促进会的发展，并以社区社会组织联合会为平台和抓手，为社区社会组织发展提供登记指导、财务托管、培育扶持等服务，有力促进我市社区社会组织的健康发展，积极引导社区社会组织参与社区社会治理，提供公共服务。

三、建立社区社会组织台帐定期报送制度

为切实掌握各区社区社会组织培育发展情况，摸清底数，我市将建立社区社会组织台帐的月报和季报制度。每个月上旬，各区民政局要将社区社会组织数量统计表（附件1）上报市民政局；每个季度的第一个月（1月、4月、7月、10月）上旬将社区社会组织台帐（附件2）上报市民政局。

专此通知。
