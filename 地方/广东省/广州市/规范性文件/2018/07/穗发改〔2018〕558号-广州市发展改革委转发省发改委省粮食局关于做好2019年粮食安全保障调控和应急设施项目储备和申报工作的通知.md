# 广州市发展改革委转发省发改委省粮食局关于做好2019年粮食安全保障调控和应急设施项目储备和申报工作的通知

各区发展改革局（粮食局），市粮食集团：

现将省发改委省粮食局《关于做好2019年粮食安全保障调控和应急设施项目储备和申报工作的通知》（粤发改服务〔2018〕317号）转发给你们，请组织辖内粮食企业做好申报工作。申报单位须对照通知要求，选取符合条件的项目申报投资需求，于7月5日前填写完《2019年粮食安全保障调控和应急设施项目汇总表》（详见转发文附件）连同所在区发展改革局（粮食局）审核意见报市发改委粮食处（另要提供电子版，邮址：liangsc＠gz．gov．cn）；同时须在重大建设项目库中推送所申报项目，逾期不予受理。在此基础上，请各区发展改革局（粮食局）认真筛选条件成熟、可落实的项目，于8月13日前上报确认的项目清单及单项材料（一式五份，同时提供电子版）。

广州市发展和改革委员会

2018年7月4日
