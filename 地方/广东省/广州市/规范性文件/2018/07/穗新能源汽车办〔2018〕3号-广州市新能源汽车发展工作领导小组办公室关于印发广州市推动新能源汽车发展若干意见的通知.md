# 广州市新能源汽车发展工作领导小组办公室关于印发广州市推动新能源汽车发展若干意见的通知

各区人民政府，市政府各部门、各直属机构，各有关单位：

《广州市推动新能源汽车发展的若干意见》已经市新能源汽车发展工作领导小组同意，现印发给你们，请认真贯彻执行。执行中遇到问题，请径向市新能源汽车发展工作领导小组办公室（设在市发展改革委）反映。
