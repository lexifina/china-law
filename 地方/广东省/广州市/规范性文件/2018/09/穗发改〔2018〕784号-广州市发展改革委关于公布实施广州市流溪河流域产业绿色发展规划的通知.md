# 广州市发展改革委关于公布实施广州市流溪河流域产业绿色发展规划的通知

各区人民政府，市政府各部门、各直属机构：

《广州市流溪河流域产业绿色发展规划》业经市人民政府批准同意，根据《广州市流溪河流域保护条例》有关规定，现予以公布实施。

广州市发展和改革委员会

2018年9月4日
