# 广州市发展改革委关于固定资产投资项目节能审查工作有关事项的通知

市直各单位，各区发展改革部门：

现将《广东省发展和改革委员会　广东省经济和信息化委员会关于印发〈广东省固定资产投资项目节能审查实施办法〉的通知》（粤发改资环〔2018〕268号）转发给你们，请认真贯彻实施。同时，结合《广州市人民政府关于印发广州市工程建设项目审批制度改革试点实施方案的通知》（穗府〔2018〕12号）以及省发展改革委与我委签署的《行政委托授权协议》，现就我市固定资产投资项目节能审查工作通知如下：

一、项目建设单位要按照《广东省固定资产投资项目节能审查实施办法》要求做好固定资产投资项目节能审查工作。节能报告应包括分析评价依据、建设方案的节能分析和比选、节能技术和管理措施、能源消费情况及能效水平评价、对项目所在地完成能源消耗总量和强度目标以及煤炭消费减量替代目标的影响等内容。对于内容深度不符合要求、重要章节内容缺失、能耗计算存在重大缺漏等达不到编制要求的节能报告，节能审查部门可进行退件处理。

二、根据《广州市工程建设项目审批制度改革试点实施方案》，使用市本级统筹财政资金的房屋建筑和城市基础设施等工程（不包括特殊工程和交通、水利、能源等领域的重大工程），以及社会投资项目，节能评价不再作为项目审批条件，需要进行节能审查的项目在施工许可前完成节能审查即可。探索开展节能审查区域评估。对实施区域评估片区内的项目节能审查工作按照区域评估的有关办法实施。

三、节能审查工作按以下权限划分：

（一）国家发展改革委核报国务院审批或核准，以及国家发展改革委审批或核准的项目，其节能审查由省级节能审查部门实施。

（二）年综合能源消费量5000吨标准煤及以上的固定资产投资项目，其节能审查由省级节能审查部门负责。在我市本级和各区发展改革部门办理审批、核准和备案的，其节能审查由市发展改革委受省发展改革委的授权委托实施。

（三）年综合能源消费量1000吨标准煤及以上（或电力消费量满500万千瓦时）、5000吨标准煤以下的固定资产投资项目，其节能审查由市发展改革委实施。

（四）年综合能源消费量不满1000吨标准煤且年电力消费量不满500万千瓦时，以及国家明确不需单独进行节能审查的行业目录中的项目，建设单位应按照相关节能标准、规范建设，节能审查机关不单独进行节能审查。

四、切实加强节能审查工作力度

（一）加强新建项目用能管控。

各区要加强源头管控，摸清本地区新建、计划建设的能源消费量较高的固定资产投资项目，根据本地区能源消费总量和强度“双控”形势，做好项目部署和用能量调配工作，确保完成能源消费控制目标。未按有关规定进行节能审查，或节能审查未通过的项目，项目不得开工建设，已经建成的不得投入生产、使用。

（二）强化事中事后监管。

各级节能审查部门应强化节能审查的事中事后监管，对节能审查意见落实情况进行监督检查，按照《广东省固定资产投资项目节能审查实施办法》对未按要求进行、落实节能审查的项目依法追究责任。进行节能审查的固定资产投资项目在投入生产、使用前，项目建设单位应组织对节能审查意见落实情况进行验收，并将节能验收情况报备节能审查部门。不单独进行节能审查的固定资产投资项目，投入生产后，项目所在地节能审查部门或节能监察部门应组织节能监察抽查。
