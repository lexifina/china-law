# 广州市卫生和计划生育委员会广州市财政局关于印发《广州市卫生村镇创建项目资金管理办法》的通知

各区卫生计生局、财政局：

为贯彻落实省政府办公厅《广东省全面深化新时期爱国卫生运动实施方案（2015－2020年）》（粤府办〔2015〕47号）、市政府办公厅《广州市全面深化新时期爱国卫生运动实施方案（2016－2020年）》（穗府办〔2016〕95号）和市爱卫会《广州市国家卫生镇创建规划（2013－2020年）》（穗爱卫〔2013〕12号）精神，加强和规范我市卫生村镇创建项目资金的管理和使用，现将《广州市卫生村镇创建项目资金管理办法》印发给你们，请认真贯彻执行。

广州市卫生和计划生育委员会 广州市财政局

2018年6月22日

广州市卫生村镇创建项目补助资金管理办法

为贯彻落实省政府办公厅《广东省全面深化新时期爱国卫生运动实施方案（2015－2020年）》（粤府办〔2015〕47号）、市政府办公厅《广州市全面深化新时期爱国卫生运动实施方案（2016－2020年）》（穗府办〔2016〕95号）和市爱卫会《广州市国家卫生镇创建规划（2013－2020年）》（穗爱卫〔2013〕12号）精神，加强和规范我市卫生村镇创建项目资金的管理和使用，特制定本办法。

一、补助对象

各镇（含仍行使镇政府行政职能的街道，下同）、村按照国家、省、市有关卫生镇、卫生村申报和考核办法，积极开展卫生创建工作，经国家、省、市各级爱卫会专项考核命名后，市级财政按照以奖代补的方式给予定额补助。

二、补助标准

市财政对卫生村镇创建项目给予一次性定额补助，所需资金纳入市卫生计生委部门预算。标准为：国家卫生镇10万元，省卫生镇5万元，省卫生村3万元，市卫生村2万元。

三、支出范围

卫生村镇创建经费专门用于卫生镇（村）的卫生创建及巩固工作补助。可用于各镇、村在开展爱国卫生宣传、“三个一”环境卫生整治、卫生基础设施改造、病媒生物防制、登革热防控等，不得用于个人奖励、工资福利性待遇支出方面。

四、结算程序

项目资金实行结算制，结算年度为每年1月1日至12月31日。

各区卫生计生局应于每年3月底前，将结算周期的卫生村镇创建完成情况，书面报市卫生计生委申报补助；市卫生计生委根据各区卫生村镇创建完成情况编制次年经费预算。

市卫生计生委、市财政局按规定将经费转移支付到各区。各区卫生计生局、财政局依据上级爱卫会公布的卫生镇、卫生村的命名文件，按照标准在30日内将经费拨付至相应的镇、村。

五、监督管理

各区卫生计生局应加强对项目资金的安全和管理全过程负责，每年要对资金使用情况开展自查，组织项目的绩效评价和信息公开，并于资金下达后次年1月31日前将项目资金执行情况报市卫生计生委（爱卫处）备案。

各区卫生计生局和财政局可结合当地实际情况，根据本办法制定具体的实施细则，并报市卫生计生委备案。

六、其他

本办法自2019年1月1日起实施，有效期5年。
