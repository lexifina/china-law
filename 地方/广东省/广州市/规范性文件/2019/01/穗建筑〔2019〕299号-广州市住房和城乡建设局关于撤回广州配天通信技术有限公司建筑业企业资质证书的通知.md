# 广州市住房和城乡建设局关于撤回广州配天通信技术有限公司建筑业企业资质证书的通知

广州配天通信技术有限公司，各相关单位：

经2018年度建筑业企业资质“双随机、一公开”监督检查发现，广州配天通信技术有限公司的注册建造师不足，整改期限届满后仍不符合钢结构工程专业承包三级资质标准要求。根据《建筑业企业资质管理规定》（住房城乡建设部第22号令）第二十八条，我局决定撤回广州配天通信技术有限公司的钢结构工程专业承包三级资质。

如广州配天通信技术有限公司对本决定不服，可以自接到本决定之日起60日内，依法向广东省住房和城乡建设厅或者广州市人民政府申请行政复议，也可以在6个月内依法向人民法院提起行政诉讼。

广州市住房和城乡建设局

2019年1月30日
