# 广州市金融工作局关于同意广州普融小额贷款有限公司减少注册资本的批复

穗金融函〔2018〕1691号

广州市金融工作局关于同意广州普融

小额贷款有限公司减少

注册资本的批复

越秀区金融局：

你局《关于广州普融小额贷款有限公司减少注册资本的请示》（越金融〔2018〕298号）收悉。根据《中华人民共和国公司法》、《广东省小额贷款有限公司管理办法（试行）》（粤金〔2009〕10号）、《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）以及《关于调整小额贷款公司发起人股东变更事项审批工作的通知》（粤金〔2013〕39号）的规定，经审核，现批复如下：

同意广州普融小额贷款有限公司注册资本从人民币2亿元减少至人民币1.4亿元。减资后，各股东持股的比例为：法人股东广州普邦园林股份有限公司持有30%的股份，自然人股东梁定文、劳宇辉、钟迅、黄桂卿、张婷、赵嶓分别持有24.29%、18.57%、12.86%、10%、2.86%、1.43%的股权。
