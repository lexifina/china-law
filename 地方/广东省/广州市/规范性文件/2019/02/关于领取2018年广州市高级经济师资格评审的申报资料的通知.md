# 关于领取2018年广州市高级经济师资格评审的申报资料的通知

2018年11月份参加广州市高级经济师资格评审的申报人，请于2019年2月25日至3月8日到广州市越秀区府前路2号府前大厦四楼会议室领取申报资料（2019年开始实施电子证书，通过人员可在系统查询，证书制作完成后自行打印）。申报人领取资料时请注意以下事项：

一、领取资料时间：规定日期的每天9：30至11：30，14：00至16：30（节假日不办理，逾期资料不再保管）。

二、领取资料时须出具本人身份证。（若代领，须同时出具申报人授权书/单位授权说明及申报人身份证复印件和代领人身份证）

三、签收资料前，请检查资料完整性。资料须交回公司人事部门。

如有疑问，请联系广州市经济贸易信息中心，联系人：姚志刚，电话：83123816、83123916。
