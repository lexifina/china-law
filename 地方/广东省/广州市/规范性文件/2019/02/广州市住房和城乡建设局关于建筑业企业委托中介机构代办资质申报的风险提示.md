# 广州市住房和城乡建设局关于建筑业企业委托中介机构代办资质申报的风险提示

各建筑业企业：

近期我局发现部分建筑业企业委托中介机构代办申报建筑业企业资质，并因在资质申报中弄虚作假被我局公开通报，一年内不得再次申请建筑业企业资质。

我局郑重提醒广大建筑业企业不要盲目相信不法中介机构的虚假承诺，不要图省事、循捷径，以免因中介机构代办资质中的弄虚作假行为而受到行政处罚。各建筑业企业应当诚信守法，通过参阅《建筑业企业资质标准》及我局官方网站上的办事指南，自行完成资质申报。

下一步，我局将继续采取多种形式，宣讲资质申报要点，细致做好服务咨询工作，同时依据《广州市住房和城乡建设局关于开展工程建设领域专业技术人员职业资格“挂证”等违法违规行为专项整治的通知》（穗建筑〔2019〕93号），深入开展工程建设领域专业技术人员职业资格“挂证”等违法违规行为专项整治，严肃查处持证人注册单位与实际工作单位不符、买卖租借（专业）资格（注册）证书等“挂证”违法违规行为。

广州市住房和城乡建设局

2019年2月18日
