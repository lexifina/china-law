# 广州市农业农村局关于明确2019-2020年岭南特色水果种植保险定损方式的通知

各区农业主管部门、各保险经营机构：

根据省农业厅、省财政厅、省金融办、广东保监局、省气象局《关于印发〈2018－2020年广东省政策性农业保险承保理赔操作规范>〉2018－2020年广东省政策性农业保险赔付标准>的通知》（粤农规〔2018〕7号）有关规定，结合我市实际，现明确我市2019－2020年岭南特色水果（荔枝、龙眼、香蕉、木瓜、柑、桔、橙、柚）种植保险定损方式为现场定损，赔付标准按《广州市岭南特色水果种植保险赔付标准》执行，承保理赔操作按《2018－2020年广东省政策性农业保险承保理赔操作规范》执行，请各区农业部门和辖区保险经营机构做好政策性岭南特色水果种植保险的宣传和承保工作。
