# 广州市地方金融监督管理局关于广州数融互联网小额贷款有限公司变更高管的批复

越秀区金融局：

越金融〔2019〕20号文收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

同意孙野任广州数融互联网小额贷款有限公司董事、董事长、法定代表人及总经理，免去吕翔董事、董事长、法定代表人及总经理职务。

同意李华任广州数融互联网小额贷款有限公司副总经理，免去李方林副总经理职务。

同意王正明任广州数融互联网小额贷款有限公司财务总监，免去杨大鹏财务总监职务。
