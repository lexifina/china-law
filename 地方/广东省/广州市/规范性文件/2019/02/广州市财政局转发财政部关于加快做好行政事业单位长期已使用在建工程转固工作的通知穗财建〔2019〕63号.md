# 广州市财政局转发财政部关于加快做好行政事业单位长期已使用在建工程转固工作的通知穗财建〔2019〕63号

穗财建〔2019〕63号

广州市财政局转发财政部关于加快做好行政事业单位长期已使用在建工程转固工作的通知

市直各单位，各区财政局:

现将省财政厅《转发财政部关于加快做好行政事业单位长期已使用在建工程转固工作的通知》(粤财建〔2019〕7号，见附件)转发给你们，请按照财政部和省财政厅的要求一并遵照执行，加快做好行政事业单位长期已使用在建工程转固工作，并将长期已使用在建工程转固情况纳入年度资产报告，认真填列《在建工程情况表》，对于已投入使用但未转固的在建工程，要重点说明原因，总结长期已使用在建工程转固管理情况，随年度行政事业单位国有资产报告报我局(行政事业资产管理处)。

广州市财政局

2019年2月21日
