# 广州市信用办关于贯彻落实知识产权（专利）领域、社会保险领域、政府采购领域联合惩戒备忘录的通知

市各有关单位，各区信用办：

为贯彻落实省发展改革委等部门《转发国家发展改革委等38部委印发〈关于知识产权（专利）领域严重失信主体开展联合惩戒的合作备忘录〉的通知》（粤发改信用函〔2018〕550号）（见附件1）、《转发国家发展改革委等28部委印发〈关于对社会保险领域严重失信企业及其有关人员实施联合惩戒的合作备忘录〉的通知》（粤发改信用函〔2018〕551号）（见附件2）、《转发国家发展改革委等29部委印发〈关于对政府采购领域严重违法失信主体开展联合惩戒的合作备忘录〉的通知》（粤发改信用函〔2018〕552号）（见附件3）等文件精神，现提出贯彻意见，请结合工作实际抓好落实。

一、各区、各有关部门需严格按照《广州市人民政府关于印发广州市建立完善守信联合激励和失信联合惩戒机制实施方案的通知》（穗府〔2019〕1号）的规定，开展各领域信用联合奖惩工作。

二、请知识产权（专利）领域、社会保险领域、政府采购领域主管部门，按照国家备忘录规定及时认定各领域惩戒对象，并在认定后3个工作日内将惩戒对象名单信息推送至市公共信用信息管理系统。市信息化服务中心将惩戒名单信息在“信用广州”网上公示。

三、请各区、各部门在行政审批、事中事后监管等工作中通过市公共信用信息管理系统查询失信惩戒对象名单信息，按照国家备忘录的规定，对惩戒对象实施惩戒措施，确保“应查必查，惩戒到位”。

四、请各区、各部门按照《广州市信用办转发关于做好联合惩戒案例归集和信息共享工作的通知》（穗信用办〔2018〕7号）要求，加强联合奖惩案例收集整理，于每月20日前按联合奖惩案例格式（见附件4）报市信用办汇总，电子版请发liaowei＠gz．gov．cn。
