# 广州市发展改革委转发省发展改革委关于印发企业投资项目核准和备案管理实施细则（试行）的通知

各区发展改革局（发展改革和金融工作局）：

现将《广东省发展改革委关于印发企业投资项目核准和备案管理实施细则（试行）的通知》（粤发改规〔2019〕1号）转发你们，并结合《中共广州市委全面深化改革领导小组关于印发广州市营商环境综合改革试点实施方案及分工的通知》（穗改组发〔2018〕6号）中关于全面提升企业投资管理效率的要求，就我市贯彻落实实施细则及有关工作一并通知如下：

一、压减企业投资项目核准和备案办理时限，不得超出办理时限。将核准项目申报材料不齐全或者不符合法定形式的告知期限压减至2个工作日以内，正式受理材料后的办理期限压减至5个工作日以内（含技改项目）。政府核准的投资目录以外的项目一律实行备案制，2个工作日内完成备案工作（含技改项目）。

二、严格依法依规开展企业投资项目核准或备，不得擅自增减审查条件。企业投资项目核准的前置条件仅包括：l．选址意见书（仅指以划拨方式提供国有土地使用权的项目）；2．用地（用海）预审意见（自然资源主管部门明确可以不进行用地预审的情形除外）；3．法律、行政法规规定需要办理的其他相关手续。各区发展改革部门不得将无明确法律法规规定的事项作为企业投资项目核准或备案的前置条件，不得要求企业提供无关的手续、证明材料等。

三、属于企业经营自主权的事项，一律不得作为企业投资项目核准的前置条件。下列事项一律不得作为企业投资项目核准的前置条件：1．银行贷款承诺；2．融资意向书；3．资金信用证明；4．股东出资承诺；5．其他资金落实情况证明材料；6．可行性研究报告审查意见；7．规划设计方案审查意见；8．电网接入意见；9．接入系统设计评审意见；10．铁路专用线接轨意见；11．原材料运输协议；12．燃料运输协议；13．供水协议；14．与相关企业签署的副产品资源综合利用意向协议；15．与相关供应商签署的原材料供应协议等；16．与合作方签署的合作意向书、协议、框架协议（中外合资、合作项目除外）；17．通过企业间协商和市场调节能够解决的协议、承诺、合同等事项；18．其他属于企业经营自主决策范围的事项。

四、不得强制要求项目单位委托中介服务机构编制项目申请报告。企业投资项目申请报告可以由项目单位自行编写，也可以由项目单位自主委托具有相关经验和能力的工程咨询单位编写。任何单位和个人不得强制项目单位委托中介服务机构编制项目申请报告。

广州市发展和改革委员会

2019年2月18日
