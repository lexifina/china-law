# 广州市发展改革委关于全面清查收费目录清单制定发布情况的通知

各区发展改革局：

根据《广东省发展改革委关于督促落实收费目录清单制度的通知》（粤发改价格函〔2019〕340号）要求，现就全面清查收费目录清单制定发布情况有关工作通知如下：

一、请各区对收费目录清单制度落实情况立即开展一次全面自查自纠，对发现存在未制定目录清单、公布内容不完整、更新不及时等问题要立即整改，并在2月25日前完成整改。各区应严格按照“五不进”原则，根据本区价费管理工作实际，参照省发展改革委发布的统一规范样式制定收费目录清单，并在本部门政府网站正式对外发布。省发展改革委将在3月初对各地各部门网站发布收费目录清单的情况进行抽查。

二、请各区对本部门收费目录清单制定发布情况进行清理总结，并于2019年2月25日前将书面材料（附收费目录清单正式发文复印件）报我委汇总。

附件：广东省发展改革委关于督促落实收费目录清单制度的通知

广州市发展和改革委员会
