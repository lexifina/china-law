# 广州市市场监督管理局关于省属广告媒体单位办理广告发布登记的通告

穗市监〔2019〕89号

根据《广东省市场监督管理局关于调整广告监管行政职权事项的通知》(粤市监处字〔2018〕131号)和《广东省市场监督管理局关于广州市工商行政管理局接收原省工商局登记市场主体广告违法行为行政处罚职权有关工作的通知》(粤市监处字〔2019〕37号)的有关要求，为确保我局机构改革过渡期广告发布申请、变更、注销等登记工作的连续性，经过前段时间的调试和准备工作，即日起我局正式开始办理省属广告媒体单位的广告发布登记工作。请申请单位按照《中华人民共和国广告法》第二十九条和《广告发布登记管理规定》(国家工商行政管理总局令第89号)第四条、第五条的有关规定到我局申请办理广告发布登记。

政务公开网址：http://scjgj.gz.gov.cn;

办理地址：广州市天河路112号10楼1005房;

办理时间：星期一至星期五上午8:30-12:00，下午14:00-17:30(星期六、日及法定节假日除外);

咨询电话：020-85596566转1005或020-85583730。

广州市市场监督管理局
