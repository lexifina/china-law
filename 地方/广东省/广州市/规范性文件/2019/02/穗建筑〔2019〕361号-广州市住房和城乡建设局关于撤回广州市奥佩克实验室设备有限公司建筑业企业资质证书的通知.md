# 广州市住房和城乡建设局关于撤回广州市奥佩克实验室设备有限公司建筑业企业资质证书的通知

广州市奥佩克实验室设备有限公司，各相关单位：

经2018年度建筑业企业资质“双随机、一公开”监督检查发现，广州市奥佩克实验室设备有限公司技术工人不足，不符合环保工程专业承包三级资质、建筑装修装饰工程专业承包二级资质要求，整改期限届满后未提交整改材料。根据《建筑业企业资质管理规定》（住房城乡建设部第22号令）第二十八条，我局决定撤回广州市奥佩克实验室设备有限公司的环保工程专业承包三级资质、建筑装修装饰工程专业承包二级资质。

如广州市奥佩克实验室设备有限公司对本决定不服，可以自接到本决定之日起60日内，依法向广东省住房和城乡建设厅或者广州市人民政府申请行政复议，也可以在6个月内依法向人民法院提起行政诉讼。

广州市住房和城乡建设局

2019年2月2日
