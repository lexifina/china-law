# 广州市住房和城乡建设局关于撤回瑞华建设集团有限公司建筑业企业资质证书的通知

瑞华建设集团有限公司，各相关单位：

根据《广州市住房和城乡建设委员会关于开展房屋市政工程安全生产百日攻坚行动工作方案》要求，我局通过“三库一平台”对部分建筑业企业实施建筑业企业资质动态核查。经核查，瑞华建设集团有限公司的水利水电工程专业注册建造师人数不符合水利水电工程施工总承包三级资质标准要求，且整改期限届满仍不符合要求。根据《建筑业企业资质管理规定》（住房城乡建设部第22号令）第二十八条，我局决定撤回瑞华建设集团有限公司的水利水电工程施工总承包三级资质。

如瑞华建设集团有限公司对本决定不服，可以自接到本决定之日起60日内，依法向广东省住房和城乡建设厅或者广州市人民政府申请行政复议，也可以在6个月内依法向人民法院提起行政诉讼。

广州市住房和城乡建设局

2019年2月15日
