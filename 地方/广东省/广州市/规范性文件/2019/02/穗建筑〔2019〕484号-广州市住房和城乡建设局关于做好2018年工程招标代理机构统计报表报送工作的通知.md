# 广州市住房和城乡建设局关于做好2018年工程招标代理机构统计报表报送工作的通知

各有关单位：

为做好2018年工程招标代理机构统计工作，现将《广东省住房和城乡建设厅关于做好2018年工程招标代理机构统计报表报送工作的通知》（粤建市函〔2019〕335号）转发给你们，并将有关事项通知如下：

一、我局委托广州市工程招标代理行业协会负责全市2018年工程招标代理机构统计年报的统计工作。

二、凡企业工商注册所在地在广州市行政区域内且从事工程招标代理活动的企业均应按要求开展统计工作。各机构须于2019年3月31日前登录住房城乡建设部网站（办事大厅－非行政许可信息报送－工程招标代理机构统计报表系统），如实填报2018年度《统计报表制度》要求的各项统计数据，并对本机构上报统计数据的准确性和完整性负责。

三、对没有按住房城乡建设主管部门要求履行统计信息申报义务的招标代理机构，我局将根据《广州市城乡建设委员会关于进一步加强和完善招标代理机构市场行为诚信评价工作的通知》（穗建筑〔2014〕1125号）的有关规定，记录不规范行为、扣诚信分，并予以通报批评；对拒不整改的代理机构列为年度重点核查对象。

特此通知。
