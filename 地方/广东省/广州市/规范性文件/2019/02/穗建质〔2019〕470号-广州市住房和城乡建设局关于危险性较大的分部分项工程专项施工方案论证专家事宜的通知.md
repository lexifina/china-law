# 广州市住房和城乡建设局关于危险性较大的分部分项工程专项施工方案论证专家事宜的通知

各有关单位：

我局重新征求危险性较大的分部分项工程专项施工方案论证专家期间，适逢我市机构改革，部分专业工程监管权责尚未确定，为确保危险性较大的分部分项工程专项施工方案论证等相关工作顺利进行，经研究决定，2019年度广州市危险性较大的分部分项工程专项施工方案论证专家名单暂按《广州市住房和城乡建设委员会关于再次公布广州市危险性较大的分部分项工程专项施工方案论证专家名单的通知》（穗建质〔2015〕1233号）执行，各有关单位应聘请相应专业的专家对危险性较大的分部分项工程专项方案进行论证审查。

特此通知。

广州市住房和城乡建设局

2019年2月27日
