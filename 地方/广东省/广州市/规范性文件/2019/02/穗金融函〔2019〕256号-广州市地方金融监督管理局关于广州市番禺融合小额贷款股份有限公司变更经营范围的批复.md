# 广州市地方金融监督管理局关于广州市番禺融合小额贷款股份有限公司变更经营范围的批复

穗金融函〔2019〕256号

广州市地方金融监督管理局关于广州市

番禺融合小额贷款股份有限公司

变更经营范围的批复

番禺区发改局：

番发改〔2019〕21号文收悉。根据《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

同意经营范围“（一）办理各项小额贷款；（二）其他经批准的业务”变更为“（一）办理各项小额贷款；（二）办理中小微企业融资、理财等咨询业务；（三）其他经批准的业务”。

广州市地方金融监督管理局
