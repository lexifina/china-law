# 广州市地方金融监督管理局关于广州市海珠华银小额贷款股份有限公司变更股权股东的批复

穗金融函〔2019〕258号

广州市地方金融监督管理局关于广州市

海珠华银小额贷款股份有限公司

变更股权股东的批复

海珠区金融局：

海金融报〔2018〕18号文收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

同意自然人股东邹俊伟将持有的广州市海珠华银小额贷款股份有限公司（下称：华银小贷）5%股权转给广州华新集团有限公司，转让后邹俊伟持有华银小贷股权比例为0，广州华新集团有限公司持有华银小贷股权由30%增至35%。

广州市地方金融监督管理局

2019年2月25日
