# 广州市地方金融监督管理局关于广州市海珠华银小额贷款股份有限公司变更高管的批复

穗金融函〔2019〕259号

广州市地方金融监督管理局关于广州市海珠

华银小额贷款股份有限公司

变更高管的批复

海珠区金融局：

海金融报〔2018〕18号文收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

同意方颂任广州市海珠华银小额贷款股份有限公司法定代表人，免去冯耀良法定代表人职务。

广州市地方金融监督管理局

2019年2月25日

（联系人：吴冠，联系电话：020-83171679）

公开方式：主动公开

抄送：省地方金融监管局，广州市海珠华银小额贷款股份有限公司。
