# 广州市农业农村局关于印发加强生猪屠宰环节非洲猪瘟防控工作告知书和生猪屠宰环节非洲猪瘟防控工作承诺书的通知

穗农函〔2019〕305号关于印发《加强生猪屠宰环节非洲猪瘟防控工作告知书》、《生猪屠宰环节非洲猪瘟防控工作承诺书》的通知

荔湾、白云、花都、番禺、黄埔、南沙、从化、增城区农业行政主管部门：

为切实做好非洲猪瘟防控工作，巩固防控成果和防范新疫情发生，进一步规范生猪屠宰活动，保障肉品质量安全，我局制定了《加强生猪屠宰环节非洲猪瘟防控工作告知书》和《生猪屠宰环节非洲猪瘟防控工作承诺书》（以下简称《告知书》、《承诺书》），现印发给你们。请你们按照属地管理原则，于2019年3月5日前将《告知书》、《承诺书》印发辖区内各屠宰企业，经屠宰企业法定代表人签署确认，并将印发和签署情况报我局（屠宰管理处）。《承诺书》一式二份，其中一份由各区生猪屠宰行政主管部门存档，一份由生猪屠宰企业留存遵照执行，确保生猪屠宰活动规范开展。
