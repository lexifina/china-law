# 广州市地方金融监督管理局关于同意广州凯得融资担保有限公司变更高管备案的通知

广州凯得融资担保有限公司：

你公司上报的高管任职备案材料收悉。根据《融资担保公司监督管理条例》（国令第683号）、《关于贯彻执行<融资担保公司监督管理条例>有关事项的通知》（粤金函〔2017〕1151号）等有关规定，经审核，同意以下备案申请：

王丁丁担任广州凯得融资担保有限公司董事。

林伟珊担任广州凯得融资担保有限公司监事。

广州市地方金融监督管理局

2019年3月8日

公开方式：主动公开

抄送：省地方金融监管局。
