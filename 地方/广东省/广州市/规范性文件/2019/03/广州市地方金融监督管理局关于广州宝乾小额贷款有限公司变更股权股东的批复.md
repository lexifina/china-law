# 广州市地方金融监督管理局关于广州宝乾小额贷款有限公司变更股权股东的批复

越秀区金融局：

越金融〔2018〕29号文收悉。根据《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

同意股东掌钱电子商务有限公司将持有的广州宝乾小额贷款有限公司（下称：宝乾小贷）5%股权转给江山永泰投资控股有限公司，转让后掌钱电子商务有限公司持有宝乾小贷股权比例为0，江山永泰投资控股有限公司持有宝乾小贷股权由65%增至70%。

广州市地方金融监督管理局

2019年2月28日
