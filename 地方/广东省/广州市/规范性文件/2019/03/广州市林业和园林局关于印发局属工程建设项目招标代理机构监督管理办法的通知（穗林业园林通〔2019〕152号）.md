# 广州市林业和园林局关于印发局属工程建设项目招标代理机构监督管理办法的通知（穗林业园林通〔2019〕152号）

局属各单位、机关各处室：

为进一步规范我局招标投标活动和招标代理机构的从业行为，切实加强廉政风险防控，营造公开、公平、公正的市场竞争环境，根据《中华人民共和国招标投标法》（中华人民共和国主席令第21号）、《中华人民共和国招标投标法实施条例》（中华人民共和国国务院令第613号）等招标投标相关法律法规和有关规定，结合工作实际，我局制定了《广州市林业和园林局局属工程建设项目招标代理机构监督管理办法》，现印发给你们，请遵照执行。执行过程中遇到问题，请及时向局招标投标管理工作小组反映。

特此通知

广州市林业和园林局

2019年3月1日

广州市林业和园林局局属工程建设项目招标代理机构监督管理办法
