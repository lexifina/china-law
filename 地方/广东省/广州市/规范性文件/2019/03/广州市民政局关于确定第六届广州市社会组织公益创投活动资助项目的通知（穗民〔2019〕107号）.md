# 广州市民政局关于确定第六届广州市社会组织公益创投活动资助项目的通知（穗民〔2019〕107号）

各区民政局，各创投主体：

第六届广州市社会组织公益创投活动经宣传发动、项目征集、专家评审、实地抽查、项目公示等程序，择优确定了141个公益创投项目为第六届广州市社会组织公益创投活动资助项目，现将具体名单印发给你们（详见附件）。

特此通知。

附件：第六届广州市社会组织公益创投活动资助项目名单
