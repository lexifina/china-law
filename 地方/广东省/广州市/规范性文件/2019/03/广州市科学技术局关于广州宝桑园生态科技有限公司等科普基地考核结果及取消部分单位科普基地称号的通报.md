# 广州市科学技术局关于广州宝桑园生态科技有限公司等科普基地考核结果及取消部分单位科普基地称号的通报

各区科技主管部门，各有关科普基地：

根据《广州市科学技术普及条例》(2015版)和《广州市科学技术普及基地认定办法》(穗科创规字〔2017〕1号)规定，我局于2018年9月发布《关于开展2018年度广州市科学技术普及基地的通知》，启动对第二、三、八批市科普基地的考核。

专家组根据《广州市科学技术普及基地认定管理办法》的要求，对广东现代农业科普园等28家市科普基地进行材料和实地考核。认真听取各科普基地近年来科普场馆建设、科普活动经费保障、领导意识、科普计划落实、与外单位协调联络、对外接待、科普活动开展及媒体宣传报道等情况及存在的问题，并进行讨论。根据专家组意见，形成考核意见如下：

一是广州宝桑园生态科技有限公司、广州市气象科普教育基地、广州动物园、广东中医药博物馆、广东海珠国家湿地公园、广州水果世界、广州地学与资源科普基地、广州采芝林中药文化科普基地、广州新能源和可再生能源科普基地、广州市白云山鸣春谷、广东省昆虫与濒危动物标本馆、广东现代农业科普园、广东省土壤科学博物馆、广州市光机电技术科普基地、广州市水鸟世界生态园、广州市舰船科普基地、广州市儿童活动中心、广州图书馆、广州市黄埔区青少年宫、养肺健康科普基地、广州医科大学口腔医院口腔健康知识宣传教育基地、华南师范大学生物标本馆科普基地、广东省微生物真菌标本馆、广州863汽车科普基地、广州市从化区气象局科普基地、广州市中学生劳动技术学校、广州市第四中学科技创新实践科普基地等27家单位重视科普工作，定期更新科普设施，科普基地管理制度健全，并能定期开展形式多样的科普活动，为传播科学知识、提高全民科学素养做出了一定的成绩，考核结果为通过考核，建议继续保留以上述单位市科普基地称号。

二是华夏箱包文化历史博物馆未能按照认定管理办法等相关文件要求做好考核准备，缺少基地建设维护运行的相关制度，缺少开展科普活动的具体内容及相关支撑材料，考核结果为限期整改，一年后重新考核。

三是广州市猎德污水处理厂、广州青少年科技馆、广州市国防教育中心没有提交考核材料，视同放弃考核。经查，广州市猎德污水处理厂、广州青少年科技馆、广州市国防教育中心因场馆运营管理和升级改造等相关问题，自动放弃考核，考核结果为不通过考核，取消市科普基地称号。

另外，广州海洋馆及广州市缔诗兰卡购赞科普教育基地因依托的场地租约到期或已转让，故取消广州海洋馆和广州市缔诗兰卡购赞科普教育基地称号。

希望通过考核的市科普基地进一步发挥在传播科学知识、科学方法和科学精神中的作用，加强科普基地建设，完善科普设施，积极开展各类科普活动，提高科普传播能力，为提高我市公众科学素养做出更大的贡献。
