# 广州市科学技术局关于遴选2019年广州市科技型中小企业评价服务项目实施单位的公告

我局拟公开遴选一家符合资质要求的实施单位完成“2019年广州市科技型中小企业评价服务”工作。现将有关要求公告如下：

一、征集时间

2019年3月18日至2019年3月22日下午17:30。

二、资质要求

(一)在广州市内依法注册设立的具有独立法人资格的社会组织或企事业单位;

(二)具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

(三)有5年以上科技项目管理经验，能够优质高效、按期完成委托的科技型中小企业评价服务工作;优先选择具有相关经验的机构。

三、委托事项

(一)委托事项内容：依据《科技型中小企业评价办法》以及科学技术部火炬高技术产业开发中心、广东省科学技术厅、广州市科学技术局的相关通知，对2019年广州市企业申请进行科技型中小企业评价的信息表进行形式审查、信息抽查、投诉异议处理和日常事务等工作。项目工作包括但不限于：

1. 政策宣讲：在全市举办5场以上科技型中小企业评价政策宣讲。

2. 形式审查：受委托单位通过“评价工作系统”对企业提交的《信息表》及相关附件进行形式审查，形成《科技型中小企业信息审核表》。

3.信息抽查：在年度企业所得税汇算清缴后，通知入库企业进行自查，企业自查后，由省级科技管理部门组织随机确定抽查企业名单，受委托单位在“评价工作系统”对企业提交的资料进行审查。

(二)进度要求：受委托单位应于2019年12月31日前按时按质完成委托项目所有工作。

(三)验收要求：由受委托单位提交工作总结，报我局审定。

四、需交材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

(一)单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)完成同类项目证明，证明本单位实力或能胜任本项工作内容的相关证明材料;

(四)工作实施方案;

(五)报价情况。

五、费用预算

人民币70万元以内。

六、材料提交

以上书面材料(一式五份含电子光盘一份)密封后，请于2019年3月20日17:30前交至广州市科学技术局科技金融处，逾期不予受理(地址：广州市越秀区府前路1号4号楼815室，邮政编码：510030)。

七、咨询电话

020-83124175、83124077(工作日8:30-12:00、14:00-17:30)。

八、合同授予

我局将按内部遴选办法确定本项目最终承担单位，并与其商议签订正式委托合同。
