# 广州市科学技术局关于遴选“2019年广州市科普基地认定、年度评估和考核及科普统计”项目实施单位的公告

我局拟公开遴选一家符合资质要求的实施单位，完成“2019年广州市科普基地认定、年度评估和考核及科普统计”项目工作。现将有关事项公告如下：

一、本项目征集起始日期：

2019年3月18日至3月22日(注：5个工作日)。

二、承担单位的资质和业务要求

(一)在国内依法注册设立的具有独立法人资格的社会组织或企事业单位;

(二)具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

(三)已被授权使用具有在库专家4000人以上规模的专家库，且覆盖高新技术一级领域和一定数量的科普专家;

(四)有5年以上科普项目评审、市科普基地认定、管理和科普统计工作经验，拥有专业评审人员队伍和良好的评审组织能力，能够优质高效、按期完成委托的项目评审、管理工作;优先选择具有同类项目相关经验的机构。

三、委托事项的工作内容及进度要求

(一)委托事项内容：完成2019年广州市科学技术普及基地认定、考核、2018年度广州市科学技术普及基地评估等相关工作，包括制定方案、对申报资料进行形式审查、组织专家进行评审、撰写工作报告等;完成2018年度广州市科普统计工作，包括制定调查方案、发放统计报表、回收统计报表并汇总上报。

(二)进度要求：受托单位应于2019年12月15日前按时按质完成委托项目所有工作，并提交工作总结。

(三)质量要求：

普宣传处话：根据《广州市科学技术普及条例》和《广州市科学技术普及基地认定管理办法》，完成对市科普基地认定、年度评估和考核等相关工作，完成广州市科普统计工作。具体如下：

1.完成2019年新认定的广州市科学技术普及基地的认定申报、形式审查、专家评审、认定结果汇总上报、结果反馈。

2.完成2018年度广州市科学技术普及基地年度评估方案制定、通知发布、申报、形式审查、专家评审、评估结果汇总上报。

3.完成2019年广州市科学技术普及基地三年一度考核方案制定、通知发布、申报、组织专家考核、汇总考核结果。

4.完成2019年广州市科学技术普及基地证书和牌匾的发放。

5.根据广东省科学技术厅相关要求，组织实施2018年度广州市科普统计调查，完成统计方案制定、通知发布、指导统计、回收统计和数据汇总及上报。

(四)验收方式：提供验收报告，报我局审定。

四、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附上以下材料：

(一)单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)证明本单位实力或能胜任本项工作内容的相关证明材料;

(四)工作方案

(五)报价情况。

五、工作经费

人民币55万元以内(包括所有完成事项需要开支的经费)。

六、申请书提交时间、地址

以上书面材料(一式三份含电子光盘一份)密封后在本项目征集期内交至广州市科学技术局科普宣传处(地址：广州市府前路1号市府大院4号楼东座801室，邮政编码：510030)。

七、咨询电话

科普宣传处：020-83124066、83124055(工作日8:30-12:00、14:00-17:30)

八、我局将按内部遴选办法确定本项目最终承担单位，并与其商议签订正式委托合同。
