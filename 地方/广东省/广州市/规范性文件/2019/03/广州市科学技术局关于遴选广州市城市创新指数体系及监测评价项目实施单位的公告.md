# 广州市科学技术局关于遴选广州市城市创新指数体系及监测评价项目实施单位的公告

我局拟公开遴选一家符合资质要求的实施单位，组织开展广州市城市创新指数体系及监测评价工作。现将有关事项公告如下：

一、本项目征集起始日期

2019年3月14日至3月18日。

二、承担单位的资质和业务要求

(一)在国内依法注册设立的具有独立法人资格的社会组织或企事业单位;

(二)具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

(三)具有规范的档案管理制度和保密制度，投标人为企业的，须通过企业档案工作规范测评二类甲级及以上;投标人为事业单位的，须达到事业单位档案管理国家二级水平及以上;

(四)具有一定规模的固定办公场所和必要的办公设施及条件;

(五)主要从事科技统计调查、分析及软科学研究，拥有广州及国内主要城市近五年的主要科技指标数据库，具备采集市、区级科技创新数据以及国内主要城市科技数据能力，与国内权威创新指数评价研究机构建有合作关系，具备开展国内科技创新水平评价研究基础，具有广州市和区的科技创新水平监测研究、评价及发布工作经验，具有良好的沟通能力和项目组织能力，能够高质高效地完成广州创新水平监测研究、评价、指数报告编制及发布等相关工作。

三、委托事项的工作内容及进度要求

(一)委托事项内容：根据广州市科技创新现状，完善相关创新指数评价指标体系，评估广州市及各区综合创新水平和能力，比较广州市与主要城市的创新水平，联合国内权威创新指数研究机构发布广州城市创新指数。项目工作包括但不限于：

1.构建广州市和广州城区创新指数评价指标体系;

2.根据指标体系以及评价模型需要，采集、整理全市、各区评价所需原始数据(含公开数据与非公开数据)，并进行标准化处理;

3.采集与广州进行比较的主要城市权威可比数据;

4.开展广州城市创新评价，对广州及各城区的创新水平进行测度和评价，在评价结果基础上进行创新排名;

5.开展广州与全国主要城市的创新水平比较评价;

6.形成广州城市创新评价结论、相关政策建议，并形成《广州城市创新指数报告》;

7.联合国内权威创新指数研究机构对外公开发布评价结果。

(二)进度要求：于2019年5月30日前提交广州城市创新指数报告。

(三)质量要求：遵循科学研究规律，确保广州城市创新评价指标体系真实有效，准确反映客观事实，按时提交报告。

(四)验收方式：由受托单位提交项目验收申请，提交工作总结报告，报我局审定。

四、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

(一)单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)完成同类项目证明，证明本单位实力或能胜任本项工作内容的相关证明材料;

(四)工作方案，包括项目进度安排、报价及预算明细等;

(五)其他可以佐证机构专业能力、资质、相关工作经验、业绩等情况的材料。

五、工作经费：人民币60万元以内(含专家劳务费)。

六、申请书提交时间、地址：以上书面材料(一式五份含电子光盘一份)密封后，请于2019年3月18日17:30前交至广州市科学技术局发展规划处，逾期不予受理(地址：广州市越秀区府前路1号4号楼410室，邮政编码：510030)。

七、咨询电话：020-83124139(工作日8:30-12:00、14：00-17:30)

八、我局将按内部遴选办法确定本项目最终承担单位，并与其商议签订正式委托合同。
