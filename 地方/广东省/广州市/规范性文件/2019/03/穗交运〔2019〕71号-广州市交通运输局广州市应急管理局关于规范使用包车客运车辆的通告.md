# 广州市交通运输局广州市应急管理局关于规范使用包车客运车辆的通告

穗交运〔2019〕71号

近期，市交通部门在执法过程中发现存在未取得道路旅客运输经营资质的大客车从事非法营运的现象，此类车辆或存在重大安全隐患并危及广大市民生命及财产安全。为规范道路旅客运输经营活动，维护道路旅客运输市场秩序，保障道路旅客运输安全以及乘客的合法权益，为市民提供优质安全的出行服务，根据《道路旅客运输及客运站管理规定》《广东省道路运输条例》等法规规定，现就规范使用包车客运车辆有关事项通告如下：

一、包车客运是指以运送团体旅客为目的，将客车包租给用户安排使用，提供驾驶劳务，按照约定的起始地、目的地和线路行驶，按行驶里程或者包用时间计费并统一支付费用的一种客运方式。

二、道路包车客运企业、车辆及驾驶员需取得交通运输管理部门发放的《道路运输经营许可证》《道路运输证》《道路包车客运经营许可证明》及《从业资格证》，具备相应包车客运经营范围，并确保上述证件信息真实有效。

三、截至2018年12月，广州市共有客运包车企业62家（见附件）。广大市民及用车单位可通过“广东省道路运输管理信息网”首页“包车客运业户”包车客运车辆”及“从业资格证”模块进行在线查询；或通过“广州交通执法”微信公众号中“班车包车查询”模块进行在线查询。

四、根据《交通运输部住房城乡建设部关于促进小微型客车租赁健康发展的指导意见》《广州市客车租赁管理办法》等规定，广州市客车租赁企业仅能提供12座及以下车辆，且不允许提供驾驶劳务。

五、建议广大市民及用车单位在向各包车客运企业租车前，了解包车客运企业的经营资质情况，并核实其相应的资质证件等材料，切勿与个人签订租车协议或合同，切勿租用无道路运输经营许可资质企业的车辆，以免出行安全、服务质量、合法权益得不到有效保障。

六、欢迎广大市民及各用车单位参与社会监督，发现包车客运企业、车辆或相应驾驶员存在道路旅客运输经营资质证件不齐全、客运包车按客运班车模式定点定线运营、行车中玩手机或接打电话等危害安全驾驶的违法违规行为时，可通过广州“12345”政府服务热线、扫描车内张贴的服务评价二维码进行投诉或举报。
