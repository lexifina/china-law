# 广州市交通运输局关于全市统一启用广州市道路路政审批及监管系统的通告

穗交运〔2019〕84号

为贯彻落实《国务院办公厅关于开展工程建设项目审批制度改革试点的通知》（国办发〔2018〕33号）、《广州市人民政府关于印发广州市工程建设项目审批制度改革试点实施方案的通知》（穗府〔2018〕12号）、《中共广州市委、广州市人民政府关于印发<广州市机构改革方案>的通知》（穗字〔2019〕1号）关于“市住房和城乡建设委员会的城市道路（含桥梁、隧道）建设、养护及路政管理职责等整合到市交通运输局”的工作要求，市交通运输局根据《中华人民共和国行政许可法》《城市道路管理条例》等法律法规，组织建设了“广州市道路路政审批及监管系统”（以下简称“系统”）。为做好机构改革职能划转后审批工作顺利实施，提升审批部门行政服务水平，现就有关工作通告如下：

一、定于2019年3月11日起，全市各区统一启用“系统”，建设单位通过政务服务网http://www.gdzwfw.gov.cn/进入系统，市、区市政管理部门通过进入系统（详见附件1系统操作手册）。请各区市政管理部门及时更新本辖区对外办事指南，在做好日常占用、挖掘城市道路审批的组织协调与业务审批工作同时，做好申请单位相关审批业务指引工作，审批材料原则上不得另行增设。

二、审批系统主要分为占道项目管理（占道计划申报）、路政业务审批、GIS地图展示、路政业务信息查询、路政施工监管及路政业务分析统计等模块，各建设单位主要使用“占道项目管理”和“路政业务审批”两大模块。

（一）占道挖掘计划申报

申请单位须按照实际情况在审批系统的“占道项目管理”模块中录入、申报年度、季度及月度调整占挖计划，按季度占挖计划及月度调整计划申请占用挖掘城市道路，并在系统中取得计划号。

1．各建设单位统一在审批系统录入年度拟占道挖掘项目信息，对条件成熟的项目执行“上报”操作。市、区市政管理部门在系统上对上报项目进行初步审核，并对符合整合条件的占道项目予以统筹。其中，花都、南沙、从化、增城区道路挖掘计划的审批由属地区市政管理部门负责。

2．原则上，所有项目均纳入年度计划管理，其中非重点工程项目除与重点项目统筹实施外，尽量安排于7月至8月实施。

3．年度计划实行弹性调整，按季度编制后统一对外发布季度计划。原则上，建设单位每季度可提出1次调整申请，调整项目必须有明确的理由。申请通过的增补项目，建设单位应于3个工作日内在系统中完成录入工作。

4．各建设单位对年度需求库中的占道项目原则上不予修改、撤销、增案，如因用户工程等确需修改、撤销及增案的，需向市交通运输局提交书面申请后方可操作。

5．对于紧急抢修抢险类项目，建设单位应在24小时内补办城市道路占用挖掘许可手续，同时录入系统，纳入年度计划监管。

（二）占用挖掘许可审批

1．建设单位申请单独办理占用、挖掘城市道路审批，使用CA证书登录“系统”填写申请信息并上传申请材料扫描文件（详见附件2《占用、挖掘城市道路审批办事指南》），无需到窗口办理。占用、挖掘城市道路审批实行全市“一个审批系统”，采用全市“一个办事指南”，全过程实行网上办理，无需现场递交资料。

2．建设单位申请联合办理工程建设项目施工许可阶段涉及发改、环保、城管、水务、公安交警、林业、交通等其他相关部门的审批事项，通过广州市工程建设项目联合审批平台（网址：http://lhsp.gzonline.gov.cn/）进行申请，具体联合办理业务申请规则遵照联合审批平台施工许可阶段办事指南。

三、申请人要对提交有关材料的实质内容的真实性及准确性负责。
