# 广州市农业农村局关于报送2018年政府信息公开工作年度报告的函

穗农函〔2019〕282号

关于报送2018年政府信息公开工作年度报告的函

市政务公开办：

根据《中华人民共和国政府信息公开条例》，我局编制了《广州市农业农村局2018年政府信息公开工作年度报告》（以下简称＂《年度报告》＂）及图文解读，拟于近期通过我局政府网站向社会公开发布。根据工作要求，现将《年度报告》函报贵办。

专此函达。
