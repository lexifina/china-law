# 广州市发展改革委转发关于下达粮食安全保障调控和应急设施项目2019年中央预算内投资分解计划的通知

南沙区发展改革局（粮食局）：

根据省发展改革委省粮食和物资储备局《关于下达粮食安全保障调控和应急设施项目2019年中央预算内投资分解计划的通知》（粤发改投资〔2019〕81号），现将广州港南沙港区粮食及通用码头筒仓二期工程2019年中央预算内投资分解计划下达给你们。接文后，请落实项目监管责任，协调财政部门办理资金拨付手续；提醒项目主管部门严格日常监管，了解项目进展情况并对发现问题及时整改；督促项目单位加强建设管理，严格执行有关招投标规定，按照批复的建设规模、内容、标准、筹资方式组织建设，每月6日前将截止上月底项目进展情况的最新数据通过投资项目在线审批监管平台、广东省投资项目在线审批监管平台报送（具体操作详见附件）。

广州市发展和改革委员会

2019年3月15日
