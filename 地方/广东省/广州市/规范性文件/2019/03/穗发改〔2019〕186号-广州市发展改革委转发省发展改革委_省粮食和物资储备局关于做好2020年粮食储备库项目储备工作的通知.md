# 广州市发展改革委转发省发展改革委_省粮食和物资储备局关于做好2020年粮食储备库项目储备工作的通知

各区发展改革局（粮食局），市粮食集团：

现将省发展改革委省粮食和物资储备局《关于做好2020年粮食储备库项目储备工作的通知》（粤发改服务函〔2019〕999号）转发给你们，请各单位组织辖内粮食企业做好申报工作。申报单位须对照通知要求，选取符合条件的项目申报，于4月8日前填写《2020年粮食储备库项目汇总表》（详见转发文附件），经所在区发展改革局（粮食局）审核后，报市发改委粮食处（同时提供电子版，电子邮箱：liangsc＠gz．gov．cn），并在重大建设项目库中推送所申报项目。

广州市发展和改革委员会

2019年3月21日
