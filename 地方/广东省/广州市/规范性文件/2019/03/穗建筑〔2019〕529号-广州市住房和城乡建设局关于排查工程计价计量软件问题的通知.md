# 广州市住房和城乡建设局关于排查工程计价计量软件问题的通知

各有关单位：

近期有个别单位在使用算量软件计算钢筋工程量时，调整了构件透明度令构件及其钢筋不显示，造成钢筋工程量计算与实际存在差异。

请使用造价软件的各建设、施工、造价咨询和其他建筑市场主体单位及时全面排查相关使用软件存在的计价计量问题，尤其是各类钢筋算量软件，并将排查中发现的异常情况于2019年3月20日前报送至广州市建设工程造价管理站审价科（邮箱：1033035571＠qq．com）。请造价软件开发单位及时对计价计量软件进行自查和完善，避免类似问题发生。

广州市住房和城乡建设局

2019年3月8日
