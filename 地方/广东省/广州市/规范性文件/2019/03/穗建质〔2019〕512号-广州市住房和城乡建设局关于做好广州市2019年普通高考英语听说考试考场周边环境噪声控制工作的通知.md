# 广州市住房和城乡建设局关于做好广州市2019年普通高考英语听说考试考场周边环境噪声控制工作的通知

广州空港经济区管委会，各区住建局，市建设工程安全监督站、市市政工程安全质量监督站，各有关单位：

根据《广州市生态环境局关于商请协助做好广州市2019年普通高考英语听说考试考场周边环境噪声控制工作的函》（穗环函〔2019〕461号，见附件）的要求，广州市2019年普通高考英语听说考试将于3月9－10日进行。为做好考场周围环境噪声控制工作，现将有关事项通知如下：

一、高考考场周边500米范围内建设工地，在3月9－10日考试期间，全天不得安排有噪声的施工作业。施工单位应根据此时间安排调整优化施工计划。

二、3月9－10日期间，各建设工地每日自22时至次日6时一律停止夜间施工。

三、请各区住建局、广州空港经济区管委会、市建设工程安全监督站、市市政工程安全质量监督站立即组织摸查考场周边的工地情况，对影响范围的工地实施重点监督检查，督促各工地管理责任单位严格落实本通知要求，发现违规施工的，要依法从严查处。

特此通知。
