# 广州市林业和园林局广州市地方金融监管局印发关于推进广州市林权抵押贷款工作的指导意见的通知（穗林业园林通[2019]120号）

各区人民政府，市各有关单位：

《关于推进广州市林权抵押贷款工作的指导意见》已经市人民政府同意，现印发给你们，请认真组织实施。实施中遇到的问题，请径向市林业和园林局、市地方金融监管局反馈。

广州市林业和园林局

广州市地方金融监管局

2019年3月5日

关于推进广州市林权抵押贷款工作的指导意见

为进一步提升我市农村（林区）金融服务的能力和水平，拓宽林业投融资渠道，促进绿色生态建设、林业产业发展和广大林农增收，根据《中华人民共和国物权法》、《中华人民共和国担保法》、《中华人民共和国森林法》、《中国银监会国家林业局关于林权抵押贷款的实施意见》（银监发〔2013〕32号）、《国务院办公厅关于金融服务“三农”发展的若干意见》（国办发〔2014〕17号）、《国务院办公厅关于完善集体林权制度的意见》（国发办〔2016〕83号）、《林业改革发展资金管理办法》（财农〔2016〕196号）、《广东省完善集体林权制度的实施方案》（粤府办〔2017〕66号）等文件精神，现就推进我市林权抵押贷款工作提出如下工作意见。

一、充分认识推进林权抵押贷款工作的重要意义

林权抵押贷款是指银行业金融机构向从事林业生产经营的单位和个人发放的，以借款人或第三方所有的或有权处分的有效森林资源资产作抵押，主要用于解决借款人林业生产经营资金短缺而发放的担保贷款。推进林权抵押贷款是解决我市林业当前融资难、变现难的有效途径，为林业发展引入资金，解决林农、林企融资难题，助力林农脱贫致富，实现绿色生态发展。同时亦为我市林业深化供给侧结构性改革，从传统林业向现代林业转型升级，重点发展森林培育、森林生态旅游发展、林下经济发展等产业提供金融支持。

各级政府部门要高度重视，林业、金融、国土、财政等部门及相关单位要相互支持和配合，将林权抵押贷款工作作为我市农村普惠金融的一项重要工作来推进实施，完善我市林业投融资机制，实现林业发展、林农增收、农村（林区）发展的良好局面。

二、指导思想

深入贯彻落实党的十九大精神，紧紧围绕统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，牢固树立创新、协调、绿色、开放、共享的发展理念，认真落实国家、广东省和广州市林地林木政策要求，坚持和完善农村基本经营制度，落实集体所有权，稳定农户承包权，放活林地经营权，搭建林权抵押融资平台，动员社会各界力量参与林业生态和产业建设，盘活森林资源资产，推进我市生态文明建设，实现我市林业全面、健康、可持续发展。

三、林权抵押贷款工作的主要目标

按照依法合规、公平诚信、风险可控、惠农利民的原则，积极鼓励和发动我市各类银行业金融机构开展林权抵押贷款及其相关业务，加大对全市林业、林区发展的信贷资金投入，建立一套以林权抵押贷款为核心，各项制度健全、配套机制完善、贷款产品设计合理、风险控制优良的林业金融体系，较好满足林业企业、林业合作社、林业经营户、林农等涉林主体的林业生产经营、森林资源培育和开发、林下经济发展、林产品加工的资金需求。

四、林权抵押贷款工作的主要措施

（一）做好我市林权确权颁证加强林权权益保护。

继续做好集体林地承包确权登记颁证工作。完善林业企业、林业合作社、林业经营户、林农等涉林经营主体的林权确权工作，确保各经营主体可以依法获得林权类不动产权证。逐步建立集体林地所有权、承包权、经营权分置运行机制，不断健全归属清晰、权能完整、流转顺畅、保护严格的集体林权制度，形成集体林地集体所有、家庭承包、多元经营的格局。依法保障林权权利人合法权益，任何单位和个人不得禁止或限制林权权利人依法开展经营活动。

（二）完善我市林权抵押贷款制度体系。

理顺和规范我市林权抵押贷款流程，建立林权登记、林业资产评估、林权抵押贷款、林权流转交易、林权收储、风险管控的制度体系，出台森林资源资产评估管理办法、森林资源资产抵押贷款管理办法等政策性文件，为我市规范有序开展林权抵押贷款工作提供政策依据。

（三）建立健全林权交易统一服务平台。

依托广州农村产权交易所等机构建立林权信息发布、林权资产评估、林权抵押贷款、林权交易等多功能的统一服务平台。加大森林资源资产流转信息公开力度，建设市级森林资源资产流转交易信息平台，公开发布林权流转交易、林权证抵押融资、林权交易市场行情等相关信息，提供林木林地交易信息查询服务、林业及相关企业金融服务、林业中介服务等服务项目。

（四）引导各类金融机构开展林权抵押贷款业务。

支持各类金融机构和专业贷款组织针对林业发展特点，在风险可控和商业可持续的前提下，积极推进林权抵押贷款业务。鼓励广州农村商业银行依托农村网点多、对林业相对熟悉的优势，发挥带头作用，进一步加大林权抵押贷款力度。鼓励金融机构依托大数据、云计算和物联网等技术手段，加强金融产品创新，更好满足林业经营主体发展林下经济、培育和利用森林资源等多元化的融资需求。

（五）完善林权抵押贷款风险分担机制。

建立处置和化解不良贷款长效机制。通过广州市林权交易所等流转平台，处置集体林权抵押贷款中出现的不良贷款，化解贷款风险。探索和鼓励通过多渠道融资的方式设立林业发展基金，以林业发展基金为森林资源的收储与担保提供资金支持。推动开展各类林业保险，构建政策性保险与商业性保险相结合的林业保险体系，切实发挥保险的保障功能，为银行业金融机构开展林权抵押贷款业务提供保障。

五、保障机制

（一）加强组织领导。

推进全市林权抵押贷款工作是一项涉及面广、政策性强、社会影响大、比较复杂的工作。由市政府分管林业的副市长牵头，市发展改革委、市林业和园林局、市金融局、市财政局、市国土规划委等单位组成工作小组协调推进林权抵押贷款工作。

（二）加大资金支持。

研究探索建立我市林业贷款财政贴息制度，完善财政补贴政策，按实际贷款规模和年限给予林业贷款贴息。符合中央林业贷款财政贴息范围规定的，积极申请中央财政贴息；符合本市林业贷款财政贴息范围的，由市级财政给予一定比例的贴息。

（三）加强宣传引导。

鼓励有关部门和金融机构针对农村地区特点，组织开展形式多样的宣传活动，充分借助电视广播、报刊杂志、互联网和村务宣传栏等渠道，大力宣传林权抵押贷款，为开展林权抵押贷款工作创造良好的氛围。
