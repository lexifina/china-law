# 广州市财政局关于同意陈与陈会计师事务所有限公司来广东临时执行审计业务的批复穗财会[2019]11号

穗财会〔2019〕11号

广州市财政局关于同意陈与陈会计师事务所有限公司来广东临时执行审计业务的批复

陈与陈会计师事务所有限公司：

你所报送的关于在广州临时执行审计业务的申请材料收悉。经研究，批复如下：

根据《财政部关于印发〈境外会计师事务所在中国内地临时执行审计业务暂行规定〉的通知》(财会〔2011〕4号)、及广东省财政厅《关于下放“港、澳、台地区会计师事务所对市、县工商机关登记企业临时办理审计业务审批”职能的通知》(粤财会〔2012〕49号)规定，现批准你所来广州临时执行审计业务，并颁发《境外会计师事务所临时执行审计业务许可证》1份，有效期为五年(自作出批准临时执业之日起计算)。你所应当按照《境外会计师事务所在中国内地临时执行审计业务暂行规定》及时进行业务报备。

广州市财政局

2019年3月19日
