# 广州市财政局关于下达2019年农村义务教育学生营养改善计划试点省补助资金的通知穗财教[2019]50号

穗财教[2019]50号

广州市财政局关于下达2019年农村义务教育学生营养改善计划试点省补助资金的通知

从化区、增城区财政局:

根据《关于提前下达2019年农村义务教育学生营养改善计划试点省补助资金的通知》(粤财教〔2018〕363号)及市教育局对该专项的资金分配方案，现将2019年农村义务教育学生营养改善计划试点省补助资金99万元(其中从化区36.7万元、增城区62.3万元)下达给你们。此款收入列“1100245教育共同财政事权转移支付收入”，支出列“20502普通教育”相关项。

请严格按照粤财教〔2018〕363号文的规定加强资金监管，提高资金使用效益。

广州市财政局

2019年3月14日
