# 广州市地方金融监督管理局关于广发互联小额贷款股份有限公司变更股权股东的批复

穗金融函〔2019〕281号

广州市地方金融监督管理局关于广发

互联小额贷款股份有限公司

变更股权股东的批复

越秀区金融局：

越金融〔2019〕26号文收悉。根据《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

同意股东普宁市信宏实业投资有限公司将持有的广发互联小额贷款股份有限公司（下称：广发小贷）22%股权转给广发乾和投资有限公司，转让后普宁市信宏实业投资有限公司持有广发小贷股权比例为0，广发乾和投资有限公司持有广发小贷股权由45%增至67%。

广州市地方金融监督管理局
