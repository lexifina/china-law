# 广州市财政局关于转下达2019年义务教育寄宿制学校公用经费提标省财政补助资金的通知穗财教[2019]51号

各区财政局：

根据《关于追加下达2019年义务教育寄宿制学校公用经费提标省财政补助资金的通知》(粤财教〔2019〕37号，见附件)，现将2019年义务教育寄宿制学校公用经费提标省财政补助资金1,012,475元转下达给你们。此款列“1100245教育共同财政事权转移支付收入”科目，支出列“20502普通教育”相关项。

请各单位严格按照粤财教〔2019〕37号文的规定做好相关工作，加强资金监管，确保专款专用。
