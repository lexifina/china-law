# 广州市科学技术局关于征集广州地区中试平台(基地)的通知

( )

各有关单位：

为进一步落实创新驱动发展战略，更好地推进广州地区成果转化全链条服务，加强广州中试平台(基地)推广应用，为今后政府出台相关政策提供参考依据，现启动广州地区中试平台(基地)的征集工作。

中试平台(基地)是指以企业、科研院所、第三方转移转化服务主体等为依托，围绕前沿产品创制、概念产品试制、产学研联合试验放大等中试需求，具备固定场地、设备条件和中试服务能力，为创新成果进行熟化、二次开发、工程化、工艺化等提供中试服务的产业化开放型载体。

请于2019年5月10日下午17:00前将附件表格及近三年提供的服务(特别是为广州服务)的情况文字总结(约800字)和为广州服务的3个典型案例的电子版发送至指定邮箱，邮件名称请注明：“单位名称+平台名称+中试平台(基地)材料”。
