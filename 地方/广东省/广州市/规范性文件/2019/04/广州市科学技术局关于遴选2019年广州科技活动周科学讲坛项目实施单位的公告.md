# 广州市科学技术局关于遴选2019年广州科技活动周科学讲坛项目实施单位的公告

我局拟公开遴选1家符合资质要求的实施单位，完成在2019年广州科技活动周开幕式上举办的科学讲坛项目工作。现将有关事项公告如下：

一、本项目征集起始日期

2019 年5月5日至5月9日(注：5个工作日)。

二、承担单位的资质和业务要求

(一)在国内依法注册设立的具有独立法人资格的社会组织或企事业单位;

(二)具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

有符合要求的固定办公场所，拥有科学文化领域的专家团队，具有较强的技术实力、专业力量和良好的沟通能力，能够高质高效地完成科学讲坛相关工作。

具有健全的活动策划队伍，专职人员达5名以上，包括活动统筹、内容策划、活动执行、媒体宣传等人员;

具有1年以上科学讲坛相关项目经验，近6个月内独立策划并主办过相关科学讲坛。

具有成熟的媒体整合传播能力，单场次讲坛线上覆盖人群(指阅读量、播放量)不低于600万。

三、委托事项的工作内容及进度要求

(一)委托事项内容：依据广州市科技局的相关通知，完成在2019年广州科技活动周开幕式上举办的科学讲坛的活动方案、内容策划、嘉宾邀约和演讲培训、场地舞美、彩排跟场、宣传推广、活动实施和总结等工作。

(二)进度要求：2019年6月底前完成。

(三)质量要求：受委托单位应按时按质完成委托项目所有工作。

(四)验收方式：由受委托单位提交工作报告，报我委审定。

四、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

(一)单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)证明本单位实力或能胜任本项工作内容的相关证明材料(项目团队及资质情况、同类项目经验、履约能力、信誉或奖项等);

(四)实施方案;

(五)报价情况。

五、工作经费

人民币15万元(包括所有完成事项需要开支的经费)。

六、申请书提交时间、地址

以上书面材料(一式五份含电子光盘一份)密封后在本项目征集期内交至广州市科学技术局引进智力管理处(地址：广州市府前路1号市府大院4号楼西座509室，邮政编码：510030)。

七、咨询电话

020-83124188、83124055(工作日8：30-12：00、14：00-17：30)

八、我局将按内部遴选办法确定本项目最终承担单位，并与其商议签订正式委托合同。
