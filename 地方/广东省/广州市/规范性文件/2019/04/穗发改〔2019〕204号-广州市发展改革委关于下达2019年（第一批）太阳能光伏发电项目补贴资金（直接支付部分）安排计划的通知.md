# 广州市发展改革委关于下达2019年（第一批）太阳能光伏发电项目补贴资金（直接支付部分）安排计划的通知

各有关单位：

我委于今年年初开展2019年（第一批）太阳能光伏发电项目补贴申报征集工作，经审核，各单位申报材料符合条件，共计33个项目，现将2019年（第一批）太阳能光伏发电项目补贴资金下达给你们。

附件：2019年（第一批）太阳能光伏发电项目补贴资金安排表

广州市发展和改革委员会

2019年4月2日
