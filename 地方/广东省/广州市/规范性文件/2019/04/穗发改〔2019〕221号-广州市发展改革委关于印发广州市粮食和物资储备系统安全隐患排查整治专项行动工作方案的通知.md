# 广州市发展改革委关于印发广州市粮食和物资储备系统安全隐患排查整治专项行动工作方案的通知

各区发展改革局（粮食局），市粮食集团：

根据广东省粮食和物资储备局《关于印发广东省粮食和物资储备系统安全隐患排查整治专项行动工作方案的通知》（粤粮科储〔2019〕86号）要求，结合我市实际，我委制定了《广州市粮食和物资储备系统安全隐患排查整治专项行动工作方案》，现印发给你们，请认真贯彻执行，并于5月25日前将专项治理工作情况书面报送我委粮食处。

广州市发展和改革委员会

2019年4月11日
