# 广州市发展改革委转发广东省发展改革委关于电网企业增值税税率调整相应降低我省一般工商业电价的通知

各区发展改革局，广州供电局：

现将《广东省发展改革委关于电网企业增值税税率调整相应降低我省一般工商业电价的通知》（粤发改价格〔2019〕138号）转发给你们，请遵照执行。

根据《广东省发展改革委关于进一步清理规范电网和转供电环节收费有关事项的通知》（粤发改价格〔2018〕375号），转供电主体不得截留降电价政策红利，将降价措施全部等额传导到转供区域内的终端用户。请你们做好相关政策宣传与指导工作

广州市发展和改革委员会

2019年4月25日
