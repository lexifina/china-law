# 广州市发展改革委关于省政协第十二届二次会议第20191041号提案会办意见的函

市住房城乡建设局：

李红等委员提出的《关于推动建设领域工程造价大数据管理，提升粤港澳大湾区高质量发展的提案》（第20191041号）提案收悉。经认真研究，我单位会办意见如下：

一、李红等委员提出的关于做好顶层设计、统一标准建设、提高数据质量、加大推广、引导使用、全面覆盖等建议非常专业、中肯，有利于我省工程造价数据共享、投资项目科学决策和精细管理，进一步提高政府投资项目管理效率，我委将在工作中积极采纳，不断完善政府投资项目管理，提升管理水平。

二、信息平台建设和大数据管理对于投资项目管理意义重大，近年来，我委积极推进固定资产投资项目代码制度。印发《广州市发展改革委广州市工业和信息化委广州市政务办关于进一步落实固定资产投资项目代码制度有关工作的通知》（穗发改〔2018〕782号）。自2018年10月8日起，全市所有固定资产投资项目均需在省在线审批监管平台申请项目代码，包括市、区两级的政府投资项目、企业投资项目，同时带码审批并归集推送信息。下一步，我委将以固定资产投资项目代码制度为切入点，全力配合你局建立工程造价大数据库相关工作，着力提升政府投资项目管理和城市建设管理水平。

以上意见可主动公开。

广州市发展和改革委员会

2019年4月15日
