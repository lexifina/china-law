# 广州市住房和城乡建设局关于印发行政执法全过程记录清单、重大行政执法决定法制审核清单的通知

局直属各单位，机关各处室：

为切实做好推行行政执法全过程记录制度、重大执法决定法制审核制度，按照《广东省人民政府关于全面推行行政执法公示制度执法全过程记录制度重大执法决定法制审核制度的实施方案》、《广州市人民政府办公厅关于印发广州市推行行政执法公示制度执法全过程记录制度重大执法决定法制审核制度试点工作方案的通知》、《广州市重大行政执法决定法制审核办法》的要求，我局进一步梳理行政执法全过程记录及重大执法决定法制审核的清单要点。现将相关清单印发你们，请结合本单位实际，认真贯彻落实。

特此通知。
