# 广州市住房和城乡建设局关于推进装配式混凝土结构工程预制构件质量标准化工作的通知

各区（含广州空港经济区）住建局、局有关直属单位、各有关行业协会、有关企业和单位：

为贯彻落实国务院《深化标准化工作改革方案》和住房城乡建设部《关于培育和发展工程建设团体标准的意见》，依据广州市人民政府办公厅《关于大力发展装配式建筑加快推进建筑产业现代化的实施意见》（穗府办规〔2017〕14号）的精神，推进我市装配式建筑混凝土结构工程预制构件质量标准化管理工作，我局组织广州建筑股份有限公司等34家企业和单位，编制并发布了团体标准《装配式混凝土结构工程预制构件生产质量验收规程》（T/GZBC10－2019，详见附件，可在“全国团体标准信息平台”查询）。

各单位可结合自身工作实际需要参照执行。同时，为提升我市装配式建筑混凝土结构工程预制构件产能和质量，我局鼓励有条件的企业，通过加大投资、转型升级等形式开展装配式混凝土预制构件生产，并参照此规程提升构件生产质量水平。

特此通知。
