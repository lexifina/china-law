# 广州市住房和城乡建设局关于印发《广州市建筑工地车辆冲洗设施设计图集》的通知

各区（含广州空港经济区）住建局，各有关单位：

为进一步提升我市建筑工地文明施工水平，强化工地车辆“一不准进，三不准出”管理，减少城市道路扬尘污染，我局结合绿色施工相关要求及国内外先进城市做法，组织编制了《广州市建筑工地车辆冲洗设施设计图集》。现予以印发实施，各单位在执行中遇到的问题以及好的建议，请及时反馈我局。

广州市住房和城乡建设局

2019年4月24日

附：《广州市建筑工地车辆冲洗设施设计图集》
