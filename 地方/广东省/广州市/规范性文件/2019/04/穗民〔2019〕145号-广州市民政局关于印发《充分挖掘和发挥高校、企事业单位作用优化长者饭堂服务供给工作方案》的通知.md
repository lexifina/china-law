# 广州市民政局关于印发《充分挖掘和发挥高校、企事业单位作用优化长者饭堂服务供给工作方案》的通知

穗民〔2019〕145号

各区民政局：

经市领导同意，现将《充分挖掘和发挥高校、企事业单位作用优化长者饭堂服务供给工作方案》印发给你们，请认真贯彻执行。执行中遇到问题，请径向市民政局反映。

广州市民政局

2019年4月9日

充分挖掘和发挥高校、企事业单位作用优化长者饭堂服务供给工作方案

近年来，我市天河等区充分挖掘高校、企事业单位利用现有优质餐饮服务资源开办长者饭堂，为校内和周边社区老年人提供助餐配餐服务，受到市民群众欢迎和好评。为贯彻落实市委主要领导要求，持续深入实施养老大配餐服务提升工程，挖掘和发挥高校、企事业单位作用，共享优质服务资源，增加优质长者饭堂服务供给，制定方案如下。

一、指导思想和工作目标

以习近平新时代中国特色社会主义思想为指导，全面贯彻落实习近平总书记对广东重要讲话和对广东工作一系列重要指示精神，按照市委、市政府的工作部署，持续优化提升养老“大配餐”服务，充分挖掘并发动高校、企事业单位利用现有优质餐饮服务资源，积极向有需要的老年人开展助餐配餐服务，优化长者饭堂供给，2019年各区要设置一定数量的示范点，进一步完善“市中心城区10－15分钟、外围城区20－25分钟”服务网络，营造共建共治共享的助餐配餐服务新格局，提升老年人的幸福感、获得感、安全感。

二、基本原则

（一）鼓励引导、资源共享。加强统筹规划，以需求为导向推进长者饭堂供给侧结构性改革，鼓励和引导高校、企事业单位及其他社会力量参与老年人配餐服务，共享社会资源，着力解决养老大配餐发展不平衡、不充分的问题，构建高质量的养老大配餐服务体系。

（二）结合实际、按需布点。结合实际情况，充分挖掘各区高校、企事业单位已建成的配餐资源并入老年人配餐服务网络，进一步增强长者饭堂服务供给能力，完善“市中心城区10－15分钟、外围城区20－25分钟”服务网络。

（三）创新模式、共同参与。通过引入高校、企事业单位及其他社会力量，结合已有社区资源等形成合力，推进养老大配餐服务进一步创新，解决好民生企盼，满足老年人多样化、多层次、个性化的养老服务需求。

三、工作任务

（一）开展摸查调研。由各区民政局组织开展辖内高校、企事业单位餐饮服务资源摸查调研，了解地域分布、经营资质、供餐能力、服务意愿等情况，以及掌握周边社区老年人数量和助餐服务需求，完成调研报告并制定工作计划，上报市民政局。（责任单位：各区民政局。完成时限：2019年4月）

（二）强化沟通协调。各区、街镇要加强与辖内的高校、企事业单位沟通联系，主动做好老年人助餐配餐服务的政策解释和宣传发动工作，鼓励有意愿的高校、企事业单位开办长者饭堂，为老年人和重度残疾人提供助餐配餐服务。（责任单位：各区民政局、街道办事处、镇政府。完成时限：2019年6月）

（三）增加供给主体。根据老年人居住分布情况和服务需求半径，以区、街（镇）为单位或分片区统筹规划助餐配餐服务网点，在老年人口密集且高校、企事业单位资源丰富的区域增设长者饭堂，6月底前设置一定数量的示范点，增加优质服务供给。高校、企事业单位举办的长者饭堂，要给予必要的配套支持，并按照市本级助餐配餐服务相关政策给予同等资助。（责任单位：各区民政局、街道办事处、镇政府。完成时限：2019年6月）

（四）创新服务模式。支持高校、企事业单位创新服务模式，开放共享场地资源，设置老年助餐专区，开辟老年助餐窗口，实行分队、分区或错峰用餐制度，在现有供餐能力范围内为老年人提供便利的助餐服务。高校、企事业单位开办的长者饭堂应当向周边社区和老年人、重度残疾人延伸，为附近老年人和有需要的18－59周岁重度残疾人提供助餐配餐服务，不得变相为内部长者饭堂并享受助餐配餐服务补贴。（责任单位：各区民政局、街道办事处、镇政府。完成时限：持续实施）

（五）加强运营管理。落实《广州市食品药品监督管理局广州市民政局关于印发广州市“长者饭堂”经营许可及监管工作指引的通知》（穗食药监食餐〔2018〕30号）规定，将符合条件的高校、企事业单位纳入长者饭堂经营类型，加挂全市统一的“长者饭堂”标识，按照广州市长者饭堂相关文件和食品安全管理规定开展助餐配餐服务。（责任单位：各区民政局、市场监管局。完成时限：持续实施）

（六）提升服务质量。支持高校、企事业单位举办的长者饭堂充分考虑老年人的身体状况和饮食习惯，改善餐食供应，丰富餐食品种，定期更新菜谱，鼓励有条件的开设早、晚餐和周六、日助餐服务。（责任单位：各区民政局、街道办事处、镇政府。完成时限：持续实施）

（七）增强送餐能力。鼓励党员、学生、退休职工干部、低龄健康老人参与志愿服务，发动高校、企事业单位党支部和群团组织开展结对帮扶，建立全职、兼职和志愿者义工队伍相结合的送餐队伍，增强长者饭堂送餐入户能力，为高龄、失能等老年人开展送餐上门服务。（责任单位：各区民政局、街道办事处、镇政府。完成时限：持续实施）

（八）加强宣传报道。利用新闻、报刊、电视、网络等渠道，加大宣传力度，树立典型事例，鼓励高校、企事业单位共建服务平台，共享优质资源，积极参与老年人助餐配餐服务，强化正面宣传引导，发扬社会责任，提高社区老年人的获得感和幸福感。（责任单位：各区民政局、街道办事处、镇政府。完成时限：持续实施）

四、保障措施

（一）加强统筹协调。充分利用市社区居家养老服务创新试点现场会机制，发挥市、区养老服务业综合改革试点工作办公室作用，加强统筹协调，及时研究解决重点、难点问题。各区政府要加强协调推动，区民政局和街、镇负责具体实施，及时反馈工作情况。在推动发展过程中，要注意统筹协调好现有有效长者饭堂和此次拓展饭堂的关系。

（二）加大扶持力度。落实助餐配餐服务各项补贴，保障助餐配餐服务持续健康发展。通过单位冠名等方式支持高校、企事业单位参与养老大配餐服务。

（三）加强督促检查。市民政局、市场监督管理局加强监督检查和业务指导，建立助餐配餐服务工作每月报告、通报制度，定期或不定期组织人员到各区、街（镇）开展明察暗访并进行通报。各区民政局定期将工作推进情况报送市民政局，由市民政局（综改办）统一纳入每两月召开的社区居家养老服务创新改革现场会和每月通报督办范围。

（四）鼓励探索创新。推广天河区等先试先行区的成功经验和做法，支持各区结合实际，探索各有特色的助餐配餐服务优化发展路径，多措并举挖掘并发动高校、企事业单位利用现有优质餐饮服务资源开设长者饭堂，创新服务模式，增强服务供给，为推动全市助餐配餐服务优化发展提供经验。
