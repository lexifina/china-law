# 广州市科学技术局关于做好到期未申请验收科技部、广东省科技型中小企业技术创新基(资)金项目验收工作的通知

穗科字〔2019〕136号

各区科技主管部门，各有关单位：

为进一步加强科技部、广东省科技型中小企业技术创新基(资)金项目管理，根据《科技型中小企业技术创新基金项目监督管理和验收工作规范》(2013年修订版)和《广东省科学技术厅关于科技型中小企业技术创新专项资金项目监督管理及验收的工作规范(暂行)》(粤科高字〔2012〕163号)有关要求，现就做好到期未申请验收的科技部、广东省科技型中小企业技术创新基(资)金项目验收工作通知如下：

一、验收范围

截至2018年底到期未申请验收的科技部、广东省科技型中小企业技术创新基(资)金项目(清单见附件)。

二、验收有关要求

(一)请到期未申请验收项目(详见附件)的承担单位尽快登录对应的网络系统平台【科技型中小企业技术创新网络服务平台(http://210.75.56.1/innofund/)、广东省科技业务管理阳光政务平台(http://pro.gdstc.gov.cn/egrantweb/)】填写及提交验收申请，并于2019年5月30日前按系统填报要求提交一份纸质验收材料(验收申请书和附件)初稿到广州生产力促进中心创新基金服务部(越秀区下塘西路37号702室)，按相关程序完成项目验收工作。对逾期未提出验收申请的项目，我局将采取包括但不限于记入科研诚信严重失信行为数据库、向社会公开不良行为等措施。

(二)请各区科技主管部门协助做好督促验收工作，并将有关督促情况于5月27日前反馈我局。
