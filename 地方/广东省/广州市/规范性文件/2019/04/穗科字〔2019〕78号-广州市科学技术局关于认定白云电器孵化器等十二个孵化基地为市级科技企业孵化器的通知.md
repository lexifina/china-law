# 广州市科学技术局关于认定白云电器孵化器等十二个孵化基地为市级科技企业孵化器的通知

穗科字〔2019〕78号

各区科技主管部门，各相关单位：

根据《广州市科技企业孵化器和众创空间管理办法》(穗科创规字〔2018〕6号)的有关规定，现认定白云电气孵化器(广州市世科高新技术企业孵化器有限公司)、清华珠三角研究院(清华珠三角研究院)、星光映景园(广东灿灿投资有限公司)、智汇Park创业服务中心(广州市长顺投资有限公司)、第四象限孵化器(广州市启赋企业管理咨询有限公司)、HiMonday产业园(广州市林正投资有限公司)、Go!Startup孵化器(广州友融壹合投资管理有限公司)、广州星力动漫游戏产业园(广州星力动漫游戏产业园有限公司)、启梦创业广场(广州启梦科技有限公司)、广州信基中创孵化器(广州信基中创孵化器管理有限公司)、广州创之融孵化器(广州创之融孵化器有限公司)、有米科技双创示范基地(广州米双创信息科技有限公司)等12个孵化基地为市级科技企业孵化器。

请继续加强对孵化器的帮助、辅导和管理，积极推动孵化器高质量发展，营造我市创新创业的良好环境。
