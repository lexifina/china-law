# 广州市财政局关于转下达2019年度省政府来粤留学生奖学金的通知穗财教[2019]55号

穗财教[2019]55号

广州大学、广州医科大学：

根据《关于安排2019年度省政府来粤留学生奖学金的通知》(粤财教〔2019〕38号，见附件1)，现将2019年度省政府来粤留学生奖学金28万元转下达给你们(具体项目金额、功能分类科目、政府和部门经济分类详见附件2)。请加强资金管理，确保专款专用，切实加快预算执行，提高资金使用效益，确保年度绩效目标如期实现。
