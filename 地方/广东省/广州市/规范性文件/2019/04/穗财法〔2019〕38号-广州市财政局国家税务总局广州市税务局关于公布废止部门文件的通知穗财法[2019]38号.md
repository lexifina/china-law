# 广州市财政局国家税务总局广州市税务局关于公布废止部门文件的通知穗财法[2019]38号

穗财法〔2019〕38号

广州市财政局 国家税务总局广州市税务局关于公布废止部门文件的通知

各区财政局，国家税务总局广州市各区税务局、市税务局各派出机构：

按照国家税务总局关于做好税费规范性文件清理工作的要求，市财政局会同广州市税务局对联合转发的文件进行了清理，现将《转发关于印发〈关于个人独资企业和合伙企业投资者征收个人所得税的规定〉的通知》(穗财法〔2000〕1047号)、《转发关于发行福利彩票有关税收问题的通知》(穗财法〔2002〕935号)和《转发关于小型微利企业所得税优惠政策有关问题的通知》(穗财法〔2012〕8号)予以废止。

广州市财政局 国家税务总局广州市税务局

2019年3月29日
