# 广州市财政局广州市住房和城乡建设局国家税务总局广州市税务局关于公布废止部门文件的通知穗财法[2019]39号

穗财法〔2019〕39号

广州市财政局 广州市住房和城乡建设局 国家税务总局广州市税务局关于公布废止部门文件的通知

各区财政局、住建局，国家税务总局广州市各区税务局、市税务局各派出机构：

按照国家税务总局关于做好税费规范性文件清理工作的要求，市财政局会同市住房城乡建设局、广州市税务局对联合转发的文件进行了清理，现将《转发关于个人出售住房所得征收个人所得税有关问题的通知》(穗财法〔2000〕295号)予以废止。

广州市财政局 广州市住房和城乡建设局

国家税务总局广州市税务局

2019年3月29日
