# 广州市财政局关于公布行政执法全过程记录和重大执法决定法制审核清单的通知穗财法[2019]50号

穗财法〔2019〕50号

广州市财政局关于公布行政执法全过程记录和重大执法决定法制审核清单的通知

机关各处室：

为贯彻落实《国务院办公厅关于全面推行行政执法公示制度执法全过程记录制度重大执法决定法制审核制度的指导意见》(国办发〔2018〕118号)要求，推进我局严格规范公正文明执法，我局制定了《广州市财政局行政执法全过程记录清单》《广州市财政局重大行政执法决定法制审核清单》，现予以公布，请遵照执行。清单事项将根据法律法规规章和权责清单修订情况实行动态调整。
