# 广州市财政局关于转下达2019年建档立卡本科生和研究生补助资金的通知穗财教[2019]73号

广州大学、广州医科大学，从化、增城区财政局：

根据《关于下达2019年建档立卡本科生和研究生补助资金的通知》(粤财教〔2019〕46号，见附件1)，现将2019年建档立卡本科生和研究生补助资金162万元转下达给你们(具体项目金额、功能分类科目、政府和部门经济分类详见附件2)。并将有关事项通知如下：

一、本次下达资金主要用于安排2019年建档立卡本科生和研究生补助，以及对粤财教〔2018〕366号文、粤财教〔2018〕295号文待抵扣资金进行清算(附件1)。请抓紧将资金安排到具体项目，切实加快预算执行，并加强资金监管，确保专款专用，提高资金使用效益。年终请按要求统一编列决算。

二、请各单位加强财政资金绩效管理，对本次下达的预算指标和任务，科学合理确定绩效目标，加强绩效目标监控和绩效评价，确保年度绩效目标如期实现。

附件：1.关于下达2019年建档立卡本科生和研究生补助资金的通知

2.广州市2019年建档立卡本科生和研究生学生免学费和生活费补助资金安排表

广州市财政局

2019年4月3日
