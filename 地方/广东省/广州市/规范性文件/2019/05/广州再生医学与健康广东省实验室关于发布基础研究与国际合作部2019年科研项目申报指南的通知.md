# 广州再生医学与健康广东省实验室关于发布基础研究与国际合作部2019年科研项目申报指南的通知

各研究单位：

为提高广州再生医学与健康广东省实验室(以下简称“再生医学省实验室”)原始创新能力，加快重大科技成果产出，基础研究与国际合作部以科学目标和科研成果产出为导向，现征集2019年度科研项目。具体事项通知如下：

一、项目设置及申报要求

2019年度再生医学省实验室基础研究与国际合作部科研项目设创新团队项目、重点研发项目、前沿探索项目。具体要求如下：

(一)创新团队项目

1.支持范围

支持联合国内外优秀科学家组成研究团队，共同围绕一个重要研究方向合作开展创新研究，培养和造就在国际科学前沿占有一席之地的研究群体。

2.申报要求

(1)项目申请人及参与者应当具有基础研究课题或其他从事基础研究的经历。

(2)申请团队应为申请人及核心成员在长期合作基础上形成的研究队伍，包括学术带头人1人，团队核心成员2-5人。

(3)学术带头人作为项目申请人，应当是本领域国际知名科学家，具有正高级专业技术职务(职称);具有较高的学术水平和宏观把握能力、较强的组织协调能力和凝聚力，能汇聚不同学科背景的优秀科研人员组成跨学科研究团队;具有以项目负责人承担973、国家重大科学研究计划及国家重点研发计划、国家自然科学基金创新研究群体项目或同等项目的经历。

(4)团队核心成员(指除学术带头人以外的团队带头人)应当具有正高级专业技术职务，在相关的科学研究领域中取得过出色的研究成果并具有持续发展的潜力。

(5)应当提交5篇申请人本人近5年(2014年1月1日以来)发表的与本次申请相关的第一作者或通讯作者的代表性论文首页(以附件形式上传)。

(6)获批项目团队同时入选省实验室核心团队。学术带头人、核心成员及至少50%项目团队骨干成员(指掌握项目核心理论或核心技术的科研人员，含正高级、副高级、博士、博士后等级别科研人员)须双聘加入省实验室，省实验室作为其第二聘用单位，三方共同签署项目双聘协议。学术带头人和核心成员须保证资助期限内平均每年在省实验室从事研究工作的时间在4个月以上;项目团队骨干成员须保证资助期限内平均每年在省实验室从事研究工作的时间在6个月以上。

3.资助强度

资助年限为三年，资助标准为200-500万/年，资助标准由学术委员会评审后根据团队规模和预计成果进行确定。

4.任务指标

资助标准为200万/年的项目须在执行期间，培养和造就在国际科学前沿占有一席之地的研究团队，培养至少1名有望进入世界科技前沿的青年科学技术人才，培养研究生至少2名;在重要研究方向取得一定进展，解决关键科学问题;团队骨干作为通讯作者在国际权威杂志上，发表SCI论文属于JCR期刊分区表TOP 5%以内(类型Article)至少1篇，且发表SCI论文属于JCR期刊分区表TOP 15%以内(类型Article)至少3篇，完成职务发明至少1项。

资助标准为300万/年的项目须在执行期间，培养和造就在国际科学前沿占有一席之地的研究团队，培养至少1名有望进入世界科技前沿的青年科学技术人才，培养研究生至少2名;在重要研究方向取得一定进展，解决关键科学问题;团队骨干作为通讯作者在国际权威杂志上，发表SCI论文属于JCR期刊分区表TOP 5%以内(类型Article)至少2篇，且发表SCI论文属于JCR期刊分区表TOP 15%以内(类型Article)至少4篇，完成职务发明至少1项。

资助标准为400万/年的项目须在执行期间，培养和造就在国际科学前沿占有一席之地的研究团队，培养至少1名有望进入世界科技前沿的青年科学技术人才，培养研究生至少3名;在重要研究方向取得一定进展，解决关键科学问题;团队骨干作为通讯作者在国际权威杂志上，发表SCI论文属于JCR期刊分区表TOP 5%以内(类型Article)论文至少3篇，且发表SCI论文属于JCR期刊分区表TOP 15%以内(类型Article)至少5篇，完成职务发明至少2项。

资助标准为500万/年的项目须在执行期间，培养和造就在国际科学前沿占有一席之地的研究团队，培养至少1名有望进入世界科技前沿的青年科学技术人才，培养研究生至少3名;在重要研究方向取得一定进展，解决关键科学问题;团队骨干作为通讯作者在国际权威杂志上，发表SCI论文属于JCR期刊分区表TOP 5%以内(类型Article)论文至少4篇，且发表SCI论文属于JCR期刊分区表TOP 15%以内(类型Article)至少6篇，完成职务发明至少2项。

(二)重点研发项目

1.支持范围

支持已有较好基础的研究方向开展深入、系统的创新性研究，推进若干重要领域或科学前沿取得突破。

2.申报要求

(1)项目申请人及参与者应当具有基础研究课题或其他从事基础研究的经历。

(2)重点研发项目申请人应当同时具备以下条件：应当是本领域杰出科学家，具有正高级专业技术职务(职称)，具有较高的学术水平和宏观把握能力、较强的组织协调能力和凝聚力，并已在申报项目相关领域取得突出成绩;具有以项目或课题负责人承担973、国家重大科学研究计划及国家重点研发计划、国家自然基金重点项目或同等项目的经历。

(3)鼓励具有正高级专业技术职务的科学家联合组成研究团队;团队核心成员(除项目申请人以外的团队带头人)不得多于2人;核心成员应当具有正高级专业技术职务。

(4)应当提交5篇申请人本人近5年(2014年1月1日以来)发表的与本次申请相关的第一作者或通讯作者的代表性论文首页(以附件形式上传)。

(5)获批项目团队同时入选省实验室核心团队。项目申请人、核心成员及至少50%项目团队骨干成员须双聘加入省实验室，省实验室作为其第二聘用单位，三方共同签署项目双聘协议。项目申请人和核心成员须保证资助期限内平均每年在省实验室从事研究工作的时间在4个月以上;项目团队骨干成员须保证资助期限内平均每年在省实验室从事研究工作的时间在6个月以上。

3.资助强度

资助年限为三年，资助标准为100-250万/年。

4.任务指标

资助标准为100万/年的项目须在执行期间，培养至少1名有望进入世界科技前沿的青年科学技术人才，培养研究生至少1名;在重要领域取得一定突破，解决关键科学问题;团队骨干作为通讯作者在国际权威杂志上，发表SCI论文属于JCR期刊分区表TOP 10%以内(类型Article)论文至少1篇，且发表SCI论文属于JCR期刊分区表TOP 15%以内(类型Article)至少2篇，完成专利发明至少1项。

资助标准为200万/年的项目须在执行期间，培养至少1名有望进入世界科技前沿的青年科学技术人才，培养研究生至少2名;在重要领域取得一定突破，解决关键科学问题;团队骨干作为通讯作者在国际权威杂志上，发表SCI论文属于JCR期刊分区表TOP 10%以内(类型Article)论文至少1篇，且发表SCI论文属于JCR期刊分区表TOP 15%以内(类型Article)至少3篇，完成专利发明至少2项。

资助标准为250万/年的项目须在执行期间，培养至少1名有望进入世界科技前沿的青年科学技术人才，培养研究生至少2名;在重要领域取得一定突破，解决关键科学问题;团队骨干作为通讯作者在国际权威杂志上，发表SCI论文属于JCR期刊分区表TOP 10%以内(类型Article)论文至少2篇，且发表SCI论文属于JCR期刊分区表TOP 15%以内(类型Article)至少4篇，完成专利发明至少2项。

(三)前沿探索项目

1.支持范围

围绕再生医学省实验室确定的研究方向和长期发展目标，着重支持具有开创性、探索性项目。

2.申报要求

(1)项目申请人应具有正高级专业技术职务(职称)，具有一定的研究基础，具有优青或同等资历的团队优先支持。

(2)获批项目申请人同时入选再生医学与健康省实验室合作团队，需与所在单位和再生医学省实验室签署三方协议。

3.资助强度

资助期限为三年，资助标准为50万元/年。

二、项目布局方向

为提升再生医学省实验室的原始创新能力，重点资助围绕再生医学与健康领域开展的基础及应用基础研究。具体包括以下几个研究方向：

(一)细胞谱系研究

阐明细胞在发育、疾病、再生中的动态变化过程，确定谱系命运决定事件，掌握细胞谱系的原位生物学功能。具体包括：对脑、心、肝、血液、骨骼谱系发生过程的细胞谱系变化过程进行单细胞分辨率的组学定量研究，研究组织、器官中细胞命运动态路径和变化规律，要求对细胞谱系体内、体外进行功能验证。优先支持方向：人类和非人灵长类细胞谱系研究;能够同时获取空间分布的原位信息的技术;以上组织器官的单基因突变发育障碍疾病的谱系发育机制研究;以上组织器官的体内再生功能机制研究。

(二)骨关节与肌肉系统研究

专注于骨骼、肌肉及关节系统开展研究，主要针对骨质疏松、骨折不愈合、多发性骨髓瘤、肿瘤骨转移，骨骼罕见病，骨性关节炎，肌腱炎等骨科损伤与疾病。深入研究疾病的病理生理学，同时基于基础研究，发现新药研发靶点，结合计算机辅助设计出新的药物，包括生物药物，细胞与细胞产品和小分子化学药物。

(三)神经系统及脑科学研究

基于再生医学技术进行神经系统疾病研究，研究神经系统发生、发育过程并发现新的干细胞类型或功能神经细胞新发生发育过程，以模式动物研究中枢神经系统损伤后再生机制，研究神经系统发育障碍从基因型到功能表型之间的分子机制，研究神经细胞类型、神经细胞环路网络与高级认知意识功能之间的决定机制，通过模拟神经系统复杂功能的创新类脑人工智能基础计算理论研究。

(四)心脏系统及心脏相关疾病研究

专注于心脏系统及心衰、心梗等损伤与疾病，整合人类现有的技术，包括基因编辑技术、细胞技术、材料技术、药物技术、信息/人工智能技术，全面认识心脏的发育、病变、老化过程，开发保证正常发育、预防与治疗疾病以及延缓和恢复其衰老的技术方法。

(五)自选方向

围绕包括干细胞、癌症、疫苗、抗体、疾病、生物材料等研究内容在内的再生医学与大健康方向，注意加强生命科学、材料科学、临床医学、计算机科学和工程学等多学科交叉，自主确定研究内容和研究方向。

三、限项要求

1.同一申请人同年只能申请1项省实验室资助项目。

2.作为项目负责人和参与人同年只能获得1项资助。

3.上年度获得省实验室资助项目(创新团队项目、重点研发项目和前沿探索项目)的项目申请人，本年度不得作为申请人申请项目。

4.具有高级专业技术职务(职称)的人员，申请(包括申请人和主要参与者)和正在承担(包括负责人和主要参与者)项目总数合计限为2项。

5. 前沿探索项目每个单位限报5项。

四、申报材料

1.广州再生医学与健康广东省实验室基础研究与国际合作部科研项目申报书。

2.项目申请人和核心成员信息汇总表(签字及加盖公章，另需附项目申请人和核心成员发表论文和承担项目课题证明文件)。

3.项目骨干人事关系所在法人单位出具的同意双聘加入再生医学省实验室的公函(红头文件并加盖公章)。

4.广州再生医学与健康广东省实验室基础研究与国际合作部科研项目合作协议书，即项目负责人、依托单位及省实验室签署的三方协议书(若项目由两个及以上的团队或单位组成，则另需附学术带头人或项目负责人与参与团队负责人签署的合作协议书，内容自行商定)。

5.承诺书(含项目申请人承诺书、查重承诺、医学伦理审查承诺)。

五、项目遴选及管理原则

1.项目采用专家评审并结合集体研究的形式进行遴选。项目管理小组进行项目初选，并采用函评或现场答辩等方式组织学术委员会进行评审。

2.获批项目团队同时入选再生医学与健康省实验室核心或合作团队，项目申请人、核心成员和50%以上骨干成员(指掌握项目核心理论或核心技术的科研人员，含正高级、副高级、博士、博士后等级别科研人员)需与所在单位和再生医学省实验室签署三方协议。双聘加入再生医学省实验室的项目成员及参与项目的研究生，在第一聘用单位同意的前提下，可从项目人员费中获取一定劳务报酬。

3.项目管理小组，对项目过程进行初步筛选和实时监管。对定期提交的项目进展报告进行审查。定期开展讨论会对项目进展情况进行监督，必要时组织学术委员会审查。

4.奖惩制度：定期对项目进行考核，根据项目具体情况及时对项目方向、实施内容和资助金额进行调整。对执行情况优秀的项目增加资助经费并给予持续支持;对未按要求开展研究工作或执行情况不好的项目予以限期整改、削减经费或终止资助。

项目结题时遵照任务指标进行严格审查。对完成任务指标的项目予以结题。对未完成任务指标的项目延期结题或不予结题，任务完成严重不足者，录入项目申请黑名单，取消其此后申请再生医学省实验室项目的资格。

5.经费管理：前沿探索项目可拨付至项目负责人所在单位，创新团队项目和重点研发项目经费原则上不外拨。所有经费均根据项目预算，由省实验室账户直接支出。科研经费分为直接费用和间接费用两个预算大类。各预算科目均不设比例限制，项目负责人应在科研课题申报时认真核实各预算科目的需求情况，其中人员费用应结合项目承担单位实际和相关人员参与项目的全时工作时间，科学合理，实事求是编制。项目负责人可在科研业务开展过程中对预算金额进行调整，其中间接费用和人员费用只能调减，不能调增，如需要调增，须报基础研究与国际合作部审核审批。

6. 获再生医学省实验室资助所有发表论文、申请课题、出版专著、授权专利、获批新药以及申报奖项等均将再生医学省实验室列为署名单位，产生的知识产权按第一聘任单位相关规定处理。
