# 广州市农业农村局关于印发2019年广州市财政农机购置补贴机具补贴额一览表（第一批，更新版）的通知

各区农业农村局，番禺区农业技术推广管理办公室：

根据《广东省农业农村厅关于印发〈广东省2019年农机购置补贴机具补贴额一览表〉（第一批）的通知》（粤农函〔2019〕895号）的要求，我局对市财政农机购置补贴机具补贴额一览表内容进行更新，编制了《2019年广州市财政农机购置补贴机具补贴额一览表》（第一批，更新版）。现印发给你们，请按照执行。此前有关文件与本通知不一致的，以本通知为准。

附件：2019年广州市财政农机购置补贴机具补贴额一览表（第一批，更新版）
