# 广州市科学技术局关于遴选广州国家自主创新示范区重点发展区域及重点专项工作专题研究项目实施单位的公告

我局拟公开遴选一家符合资质要求的实施单位开展广州国家自主创新示范区重点发展区域及重点专项工作专题研究。现将有关要求公告如下：

一、项目征集起始日期

2019年5月27日至5月31日

二、承担单位的资质和业务要求

(一)在国内依法注册设立的具有独立法人资格的社会组织或企事业单位;

(二)具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

(三)有符合要求的固定办公场所;具有与遴选要求相适应的研究团队和较强的研究能力，项目负责人必须具有副高以上的专业技术职称;能够优质、按期完成委托工作。

三、委托事项及要求

(一)委托内容

按照我局要求，开展以下工作：

1、编制《广州综合性国家科学中心科技创新规划前期研究报告》。结合广州创建综合性国家科学中心的空间布局，全面摸查现有科技创新资源和基础条件，深入分析开展相关工作的优势和不足，按照开展综合性国家科学中心建设的要求，提出支撑广州创建国家综合性科学中心的科技创新工作思路、发展方向、目标任务、政策措施等相关意见和建议。

2、编制《广州市科技成果转移转化发展报告》。分析广州市当前科技成果转移转化现状和成效，结合先进地区成果转移转化典型经验和做法，提出提升广州市科技成果转移转化工作成效的对策建议。

(二)进度要求。于2019年12月底前完成编制工作。

(三)质量要求。遵守相关法律法规，根据我局工作要求，确保相关工作按时按质完成，严守工作纪律，不泄露技术秘密和商业秘密。

(四)验收方式。由受托单位提交报告，由我局审定。

四、需提交的材料

有意参与本项工作的单位需提交申请材料，包括：

(一)申请单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)具体服务方案，包括但不限于对工作内容的分析理解、工作实施方案、工作进度安排、人员及硬件保障、服务质量保障;

(四)证明本单位实力或能胜任本项工作内容的相关证明材料，包括但不限于技术团队资质证明材料、曾担任或参与相关工作的证明材料、荣誉或奖项;

(五)报价及预算明细。

五、工作经费

人民币40万元以内。

六、申请书提交时间、地址

以上书面材料(一式三份含电子光盘一份)密封后在本项目征集期内交至广州市科学技术局成果转化与区域创新处(地址：广州市府前路1号市府大院4号楼东座809室，邮政编码：510032)。

七、咨询电话

020-83124097、83124196 (工作日8:30-12:00、14:00-17:30)

八、我局将按内部遴选办法确定本项目最终承担单位，并与其协商签订正式委托合同。
