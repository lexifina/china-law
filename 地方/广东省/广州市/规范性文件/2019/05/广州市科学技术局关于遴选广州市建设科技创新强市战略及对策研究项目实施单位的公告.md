# 广州市科学技术局关于遴选广州市建设科技创新强市战略及对策研究项目实施单位的公告

我局拟公开遴选一家(或联合相关单位)具有资质的实施单位组织开展广州市建设“科技创新强市”战略和对策研究工作。现将有关事项公告如下：

一、本项目征集起始日期：2019年5月10日至5月14日。

二、承担单位的资质和业务要求

(一)在国内依法注册设立的具有独立法人资格的社会组织或企事业单位;

(二)具有独立的财务管理、财务核算和资产管理制度，并依法缴纳税收;

(三)具有一定规模的固定办公场所和必要的办公设施及条件;

(四)主要从事城市发展及科技创新战略决策研究，具有编制科技创新发展报告工作经验，拥有科技创新发展战略研究的专家团队。具有较强的技术实力、专业力量和良好的沟通能力，能够高质高效地完成科技创新领域相关调查研究工作。

三、委托事项的工作内容及进度要求

(一)委托事项内容：深入研究“科技创新强市”内涵特征、评价指标及测度体系，全面分析国内外科技创新强市的发展路径与模式，摸清广州科技创新发展家底与成长特性，分析广州建设“科技创新强市”合理性及可行性，提出建设“科技创新强市”思路与路径。项目工作包括但不限于：

1.研究分析“科技创新强市”的内涵，探索建立“科技创新强市”评价指标及测度体系;

2.分析比较国内外“科技创新强市”的发展路径与模式，深入挖掘广州可借鉴的经验及启示;

3.按照“科学发现、技术发明、产业发展、生态优化”的科技创新发展全链条摸清广州科技创新发展家底及成长特性，分析广州建设“科技创新强市”合理性及可行性;

4.提出广州建设“科技创新强市”思路、路径及相关政策建议，形成研究报告。

(二)进度要求：于2019年7月30日前提交研究报告。

(三)质量要求：遵循科学研究规律，保证调研过程、结果科学客观，按时提交调查报告，研究结果及相关建议对我市建设“科技创新强市”具有借鉴意义。

(四)验收方式：由受托单位提交项目验收申请，提交工作总结报告，报我局审定。

四、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

(一)单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)完成同类项目证明，证明本单位实力或能胜任本项工作内容的相关证明材料;

(四)工作方案，包括项目进度安排、报价、服务团队情况及预算明细等;

(五)其他可以佐证机构专业能力、履约能力、资质、相关工作经验、业绩、奖励情况等情况的材料。

五、工作经费：人民币30万元以内(含专家劳务费)。

六、申请书提交时间、地址：以上书面材料(一式五份含电子光盘一份)密封后，请于2019年5月14日17:30前交至广州市科学技术局综合规划处，逾期不予受理(地址：广州市越秀区府前路1号4号楼413室，邮政编码：510030)。

七、咨询电话：020-83124031(工作日8:30-12:00、14：00-17:30)

八、我局将按内部遴选办法确定本项目最终承担单位，并与其商议签订正式委托合同。
