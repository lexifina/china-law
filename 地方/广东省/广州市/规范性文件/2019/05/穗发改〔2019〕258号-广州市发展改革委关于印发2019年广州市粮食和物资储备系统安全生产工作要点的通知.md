# 广州市发展改革委关于印发2019年广州市粮食和物资储备系统安全生产工作要点的通知

各区发展改革局（粮食局），广州市粮食集团、广东省广弘食品集团有限公司、广州皇上皇集团股份有限公司、广州羊城食品有限公司、广州市农业生产资料公司、广东天禾农资股份有限公司、广东省盐业集团广州有限公司、广州医药有限公司：

根据广东省粮食和物资储备局《关于印发2019年广东省粮食和物资储备系统安全生产工作要点的通知》（粤粮科储〔2019〕81号），结合我市粮食和物资储备系统实际，我委制定了《2019年广州市粮食和物资储备系统安全生产工作要点》，现印发给你们，请认真组织实施。

广州市发展和改革委员会

2019年4月30日
