# 广州市发展改革委转发广东省能源局关于推进分散式风电开发建设有关工作的通知

各区发展改革局，各有关企业：

现将《广东省能源局关于推进分散式风电开发建设有关工作的通知》（粤能新能函〔2019〕240号）转给你们。目前省能源局正组织编制首期《广东省分散式风电开发建设三年滚动计划实施方案（2019－2021年）》，请各区发展改革局按照省能源局要求抓紧组织申报本区近三年开发项目，并于5月17日前将近三年申报项目报送我委能源处，电子版同时发送wangjinwei＠gz．gov．cn。

专此。

广州市发展和改革委员会

2019年4月30日
