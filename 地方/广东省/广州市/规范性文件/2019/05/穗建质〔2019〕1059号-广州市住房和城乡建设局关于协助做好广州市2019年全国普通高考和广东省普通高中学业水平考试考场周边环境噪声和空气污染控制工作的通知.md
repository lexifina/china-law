# 广州市住房和城乡建设局关于协助做好广州市2019年全国普通高考和广东省普通高中学业水平考试考场周边环境噪声和空气污染控制工作的通知

各区住建局、广州空港经济区管委会国规建设局、市建设工程质量监督站、市市政工程安全质量监督站、各有关单位：

根据《广州市生态环境局关于商请协助做好广州市2019年全国普通高考和广东省普通高中学业水平考试考场周边环境噪声和空气污染控制工作的函》（穗环函〔2019〕1365号）的要求，广州市2019年全国普通高考和广东省普通高中学业水平考试将于6月7日至9日进行，为确保给考生创造良好的考试和休息环境，全面做好考场周围建筑工地噪声污染控制工作，现将有关事项通知如下：

一、高考考场周边500米范围内建设工地，施工单位应提前做好施工计划，在6月7日至9日考试期间，全天不得安排有噪声的施工作业。

二、5月31日至9日，各建设工地自22时至次日7时一律停止夜间施工，获准夜间施工的省、市重点工程须制定施工降噪计划，严格控制噪声产生。

三、各区住建局、广州空港经济区管委会国规建设局、市建设工程质量监督站、市市政工程安全质量监督站摸清考点影响范围的工地情况，建立工程台账，落实工地管理责任人，并将工作要求传达到位。考试期间，须安排人员巡查，发现违规施工的，立即坚决制止并严肃处理。

四、我局将对此项工作落实情况进行抽查，对工作不落实的单位和有关人员，将依法依规予以处理。

特此通知。

广州市住房和城乡建设局

2019年5月30日
