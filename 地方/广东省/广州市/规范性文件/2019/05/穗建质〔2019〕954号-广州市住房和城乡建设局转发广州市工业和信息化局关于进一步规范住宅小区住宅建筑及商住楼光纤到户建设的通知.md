# 广州市住房和城乡建设局转发广州市工业和信息化局关于进一步规范住宅小区住宅建筑及商住楼光纤到户建设的通知

各区（含广州空港经济区）住建局、市建设工程质量监督站、各有关单位：

现将《广州市工业和信息化局关于进一步规范住宅小区住宅建筑及商住楼光纤到户建设的通知》（穗工信规字〔2019〕4号）转发你们，请依职能做好住宅小区住宅建筑及商住楼光纤到户建设的相关工作。

广州市住房和城乡建设局

2019年5月11日
