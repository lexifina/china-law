# 广州市科学技术局关于组织申报2019年广州市科技与金融结合专题科技型中小企业信贷风险损失补偿资金池合作银行的通知

穗科字〔2019〕215号

各有关单位：

根据《广州市人民政府办公厅关于促进科技金融与产业融合发展的实施意见》(穗府办〔2015〕26号)、《广州市促进科技金融发展行动方案(2018-2020)》、《广州市科技型中小企业信贷风险损失补偿资金池管理办法》(穗科规字〔2019〕4号)，为促进广州市科技、金融与产业深度融合，推动科技成果转化和培育战略性新兴产业，现组织开展2019年广州市科技与金融结合专题科技型中小企业信贷风险损失补偿资金池合作银行申报工作。有关事项通知如下：

一、组织方式

符合申报指南(见附件1)要求的申报单位全部通过广州市科技业务管理阳光政务平台(http://sop.gzsi.gov.cn/，以下简称阳光政务平台)进行网上申报(征集书模板详见附件2)。申报单位按时提交合作银行征集书、附件证明材料等申请资料。经市科学技术局组织评审和审核等程序后，符合条件的予以立项支持。

二、申报要求

(一)在广州地区设有分行，并设有服务科技型中小企业的科技支行或专门机构，申报主体为广州市分行或以上级别的银行机构;

(二)对广州地区科技信贷实施单独的资金计划政策、风险容忍政策、免责考核政策、专项拨备政策、风险定价政策，有专门服务于科技型中小企业的信用贷款产品;

(三)对广州地区科技型中小企业信贷优化业务流程，具有科技信贷专门产品和创新机制。

三、申报程序

(一)首次申报单位进入阳光政务平台按照要求完成申报注册，获取单位用户名及密码，并完善单位信息。已注册帐号的单位，用原帐号密码登录即可，不需另行注册;

(二)单位用户登录阳光政务平台，生成项目申报人账号、密码;

(三)项目申报人登录阳光政务平台，选择“科技型中小企业信贷风险损失补偿资金池”专项，按申报指南要求在线填写申报书并上传附件材料;

(四)书面申报书及资料(以指南要求为准)按要求送交受理点;

(五)资格审查和项目评审，广州市科学技术局会按照《广州市科技计划项目管理办法》对申报项目进行资格审查和评审，符合条件的择优予以支持。

四、申报时间

(一)申报单位网上申报开始时间为2019年5月27 日17时、网上申报提交截止时间为2019年6月3日 17时。书面申报纸质材料送广州市科技项目评审中心的截止时间为2019年6月5日(星期三)下午17时。

五、注意事项

(一)申报项目需符合本通知中规定的所有申报基本条件和其他相关要求;

(二)阳光政务平台中申报书“申报单位基本情况”的相关内容从单位信息模块中自动读取，请各单位在申报项目前，尽早登录(注册)阳光政务平台填写完善;

(三)为避免项目申报截止时间到期前阳光政务平台网络繁忙耽误申报，请各申报单位或申报人提前做好填报工作，尽早在阳光政务平台提交申报材料;

(四)项目申报单位或申报人提交申报材料后应留意项目状态;

(五)受理的纸质申报材料一律不予退还，统一由市科学技术局按程序处置;

(六)项目申报人及申报单位需自行承担包括知识产权纠纷在内的潜在风险。
