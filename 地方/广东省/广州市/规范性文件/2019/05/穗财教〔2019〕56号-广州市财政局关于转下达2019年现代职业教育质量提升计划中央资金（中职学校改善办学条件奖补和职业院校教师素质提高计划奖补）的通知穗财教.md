# 广州市财政局关于转下达2019年现代职业教育质量提升计划中央资金（中职学校改善办学条件奖补和职业院校教师素质提高计划奖补）的通知穗财教[2019]56号

穗财教〔2019〕56号

广州市财政局关于转下达2019年现代职业教育质量提升计划中央资金(中职学校改善办学条件奖补和职业院校教师素质提高计划奖补)的 通知

市教育局：

根据《关于下达2019年现代职业教育质量提升计划中央资金(中职学校改善办学条件奖补和职业院校教师素质提高计划奖补)的通知》(粤财教〔2019〕33号，见附件1)，现将2019年现代职业教育质量提升计划专项资金(职业院校教师素质提高计划)653.81万元转下达给你局(具体项目金额、功能分类科目、政府和部门经济分类详见附件2、3)。现将有关事项通知如下：

一、请加强资金管理，确保专款专用，切实加快预算执行，提高资金使用效益。年终请按要求统一编列决算。

二、加强财政资金绩效管理，对本次下达的预算指标和任务，科学合理确定绩效目标，加强绩效目标监控和绩效评价，确保年度绩效目标如期实现。同时，接受财政部驻广东省财政监察专员办事处的监督。
