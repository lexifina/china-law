# 广州市农业农村局关于认真做好第六批农业产业化国家重点龙头企业推荐申报工作的通知

各区农业农村主管部门：

现将省农业农村厅《关于做好第六批农业产业化国家重点龙头企业推荐申报工作的通知》（粤农农函〔2019〕1012号）转发给你们，请每个区按要求择优推荐1－2家有意向申报农业产业化国家重点龙头的企业，不得超报；如果没有符合条件的，可以不报。

申报材料包括区农业农村部门推荐文件和《第六批农业产业化国家重点龙头企业申报书》一式两份，材料务必于6月4日前报送至我局乡村产业发展处，逾期不予受理。

我局将对企业申报材料进行初审，并根据企业综合实力、兼顾地区平衡和行业情况等向省农业农村厅推荐2家企业参与全省遴选。

附件：1.关于做好第六批农业产业化国家重点龙头企业推荐申报工作的通知（粤农农函〔2019〕1012号）

2.农业农村部办公厅关于开展第六批农业产业化国家重点龙头企业申报工作的通知（农办产﹝2019﹞6号）
