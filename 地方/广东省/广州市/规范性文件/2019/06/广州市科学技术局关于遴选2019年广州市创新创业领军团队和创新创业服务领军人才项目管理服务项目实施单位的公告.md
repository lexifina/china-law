# 广州市科学技术局关于遴选2019年广州市创新创业领军团队和创新创业服务领军人才项目管理服务项目实施单位的公告

我局拟公开遴选一家具有资质的实施单位完成“2019年广州市创新、创业领军团队和创新创业服务领军人才项目管理服务”工作。现将有关要求公告如下：

一、本项目征集的起始日期：

2019年6月12日至2019年6月18日。

二、项目承担单位的资质和业务要求

(一)在广州市内依法注册设立的具有独立法人资格的企事业单位或社会组织;

(二)具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

(三)已建立或被授权使用具有一定规模的专家库，在库专家4000人以上，覆盖高新技术一级领域;

(四)有5年以上人才项目跟踪管理经验，拥有专业评审人员队伍和良好的评审组织能力，能够优质高效、按期完成委托的项目管理工作;优先选择具有同类项目相关经验的机构。

三、委托事项的工作内容及进度要求

(一)委托事项内容：对2016、2017年入选及2018年拟入选广州市创新、创业领军团队和创新创业服务领军人才共计86个项目进行跟踪管理，实施期一年。项目工作包括但不限于：

1. 开展实地调研，及时掌握上述入选项目发展情况，对于上述入选项目所在单位，每年至少实地走访1次;建立入选团队档案，对入选项目开展日常以及定期的服务管理工作。

2. 对入选团队开展数据统计工作，包括技术进展、人才引进、知识产权产出、经费核销、企业效益、重大成果等，并形成年度报告提交市科技局。

3. 对入选团队组织各类培训，包括项目合同书签订、财政经费管理、项目申报等，协助市科技局指导项目实施。

4. 配合市科技局组织开展面向产业领军人才(团队)的各类座谈、咨询、竞赛等各种活动。

5. 依照市科技局与项目单位签订的合同，组织专家对项目开展中期检查工作，并向市科技局提交检查报告。

6. 承接其他涉及创新、创业领军团队和创新创业服务领军人才项目服务的事务性工作，包括但不仅限于创业领军团队房租补贴申报审核、贷款贴息申报审核等。

(二)进度要求：受托单位应于2020年6月30日前按时按质完成委托项目所有工作，并提交工作总结。

(三)验收要求：由受托单位提交项目验收申请，报我局审定。

四、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

(一)工作实施方案。包括项目进度安排、预算明细、总报价等;

(二)单位基本情况表(原件盖章，见附件);

(三)营业执照副本或登记证书(复印件盖章);

(四)完成同类项目证明，证明本单位实力或能胜任本项工作内容的相关证明材料;

(五)其他可以佐证机构专业能力、团队服务能力、资质、相关工作经验、保障响应、业绩及荣誉等情况的材料。

五、费用预算

人民币50万元以内。

六、材料提交时间、地址

以上书面材料(一式五份含电子光盘一份)密封后，请于2019年6月18日12：00前交至广州市科技局引进智力管理处，逾期不予受理(地址：广州市越秀区府前路1号市府大院4号楼西座510室，邮政编码：510030)。
