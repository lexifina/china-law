# 广州市科学技术局关于遴选《2018年广州科技创新发展报告等年报资料》编制机构的公告

我局拟公开遴选一个第三方机构开展编制《2018年广州科技创新发展报告等年报资料》工作。现将有关事项公告如下：

一、 本项目征集起始日期

2019年6月10日至6月14日(注：5个工作日)。

二、承担单位的资质和业务要求

(一)在国内依法注册设立的具有独立法人资格的社会组织或企事业单位;

(二)具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

(三)有符合要求的固定办公场所，熟悉广州市科技创新发展现状，拥有涉及广州科技创新领域的专业团队，具有较强的综合实力、专业力量和良好的沟通能力，能够优质高效、按期完成委托的工作。

三、委托事项的工作内容及进度要求

(一)委托事项内容：编制《2018年广州科技创新发展报告》;根据《广东科技年鉴》《广州年鉴》《广州百科全书》《地方志》资料、《广州市人民政府决策志》及其他史志工作的征稿要求，收集整理广州地区科技创新发展相关资料;编制《广州科技创新简报》;开展科技创新舆情监控。

编制内容包括：

1. 编制《2018年广州科技创新发展报告》，主要目标是加强广州市科技创新工作宣传力度，总结和交流广州市科技创新工作，全面、准确、及时、有效地反映广州市科技创新发展的情况和亮点。

2. 根据《广东科技年鉴》、《广州年鉴》、《广州百科全书》、《地方志》资料、《广州市人民政府决策志》及其他史志工作的征稿要求，收集整理编制广州地区科技创新发展的相关资料。

3. 完成2019年度共12期左右广州科技创新《简报》的编制工作。

4. 完成2019年度广州市科技创新舆情月度监控及专项舆情监控工作。

(二)进度要求：

1. 完成《2018年广州科技创新发展报告》的通知发布、文稿征集、修改校对、数据校核、资料收集、设计印刷等工作，于2019年9月之前交付正式印刷成品。

2.《广东科技年鉴》、《广州年鉴》、《广州百科全书》、《地方志》资料及《广州市人民政府决策志》的编制工作完成时间分别按广东省科技厅、广州年鉴编纂委员会、广州百科全书编辑部、广州市地方志办公室、广州市人民政府办公厅修志办要求完成。

3. 每月上旬完成上月广州科技创新《简报》编制工作。

4. 开展2019年度广州市科技创新舆情监控工作，每月上旬提交上月舆情监控报告;专项舆情报告按甲方的要求时限完成。

(三)验收方式：由受托单位提交项目验收申请，报我局审定。

四、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

(一)单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)项目实施方案。具体服务方案，包括但不限于对工作内容的分析理解、工作实施方案、工作进度安排;

(四)完成同类项目证明，以及能证明本单位实力或能胜任本项工作内容的相关证明材料;

(五)其他可以佐证机构专业能力、资质、相关工作经验、业绩等情况的材料;

(六)报价及预算明细等。

五、费用预算：人民币47万元以内(含47万元)。

六、申请书提交时间、地址：以上书面材料(一式五份)密封后，请于2019年6月17日17:00前交至广州市科学技术局(地址：广州市越秀区府前路1号大院5号楼401)，逾期不予受理。

七、咨询电话：020-83124118(工作日8:30-12:00，14:00-17:30)

八、评选方式：我局将组成内部评标工作组择优遴选本项目最终承担单位，与其协商拟定正式委托合同。
