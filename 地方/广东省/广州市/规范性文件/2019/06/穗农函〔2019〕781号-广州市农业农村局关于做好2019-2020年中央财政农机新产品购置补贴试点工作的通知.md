# 广州市农业农村局关于做好2019-2020年中央财政农机新产品购置补贴试点工作的通知

穗农函〔2019〕781号

广州市农业农村局关于做好2019－2020年中央财政农机新产品购置补贴试点工作的通知

各区农业农村局，番禺区农业技术推广管理办公室：

根据《广东省农业农村厅广东省财政厅关于做好2019－2020年中央财政农机新产品购置补贴试点工作的通知》（粤农农〔2019〕197号），请你们结合工作实际，积极组织辖区内符合条件的企业开展申报工作，并按要求扎实做好中央农机购置补贴新产品实地验证等工作。

附件：广东省农业农村厅广东省财政厅关于做好2019－2020年中央财政农机新产品购置补贴试点工作的通知（粤农农〔2019〕197号）

广州市农业农村局

2019年5月22日
