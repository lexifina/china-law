# 广州市发展改革委转发国家能源局关于2019年风电、光伏发电项目建设有关事项的通知

各区发展改革局，广州供电局有限公司，光伏发电项目各有关企业和居民：

现将《广东省能源局转发国家能源局关于2019年风电、光伏发电项目建设有关事项的通知》（粤能新能函〔2019〕358号，以下简称《通知》）转发给你们，并就做好2019年风电、光伏发电项目建设工作提出以下意见，请一并贯彻落实。

一、积极推进风电建设

（一）按照《通知》有关规定，我省2019年集中式陆上风电无新增建设规模，因此不再组织竞争性配置工作，请我市已纳入2018年及之前的项目加快建设，做好信息报送工作。其余各风电项目建设单位可积极申报平价上网风电项目，待国家部署申报后由我委汇总上报。

（二）积极推进分散式风电项目建设，待省印发分散式风电开发建设三年滚动计划实施方案后，请各项目单位尽快开展项目核准和建设。

二、继续做好2019年光伏发电项目建设工作

结合我市实际情况，我市光伏发电项目存在以下三类：（1）户用光伏：业主自建的户用自然人分布式光伏项目；（2）普通光伏电站：装机容量在6兆瓦及以上的光伏电站；（3）工商业分布式光伏发电项目：就地开发、就近利用单点并网装机容量小于6兆瓦的户用光伏以外的各类分布式光伏发电项目。

国家对需要补贴的光伏发电项目实行分类管理，结合广州市实际情况，按照户用和非户用组织本年度新建光伏发电项目。

（一）户用光伏项目单独管理。

新建以及《通知》发布前已建成并网但并未纳入国家补贴范围的户用光伏项目，由广州供电局有限公司审核并报我委同意后上报。其中对于新建的户用光伏项目，按照“先建先得”的原则，实行总量控制。具体办法为：2019年度财政部安排新建光伏项目补贴预算总额度为30亿元，其中7.5亿元用于户用光伏（折合350万千瓦），国家能源局于每年年初发布国家补贴支持的户用光伏年度装机总量，每月15日前对外公布当年截至上月底全国累计新增并网装机容量。当截至上月底的当年累计新增并网装机容量超过当年可安排的新增项目年度装机总量时，当月最后一天为本年度可享受国家补贴政策的户用光伏并网截止时间。

（二）普通光伏电站、工商业分布式光伏发电项目全面实行市场竞争配置。

除国家有明确政策规定外，普通光伏电站、工商业分布式光伏发电项目原则上均由地方通过招标等竞争性配置方式组织项目，国家根据补贴额度通过排序确定补贴名单。省将组织普通光伏电站和工商业分布式光伏竞争配置工作，请各区按照《广东省2019年光伏发电项目竞争配置工作方案》（详见《通知》中的附件2）要求，组织上报参与国家竞价项目，于6月24日前将经审核后符合要求的项目及材料报我委。

请各区发改局督促项目单位通过国家能源局门户网站（网址：http://www.nea.gov.cn）登录国家可再生能源发电项目信息管理平台，在7月1日（含）前将2019年拟新建的补贴竞价项目、申报上网电价及相关信息录入。因对信息填报错误、填报不及时导致不能纳入补贴目录及获得电价附加补贴的，由项目单位自行承担相关后果。
