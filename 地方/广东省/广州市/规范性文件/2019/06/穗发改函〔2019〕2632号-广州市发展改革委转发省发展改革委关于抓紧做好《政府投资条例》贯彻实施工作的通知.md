# 广州市发展改革委转发省发展改革委关于抓紧做好《政府投资条例》贯彻实施工作的通知

各区发展改革局（发展改革和金融工作局）：

现将《广东省发展改革委关于抓紧做好〈政府投资条例〉贯彻实施工作的通知》（粤发改投资函〔2019〕2538号）转发你们，并就我市贯彻落实工作一并通知如下：

一、加强《政府投资条例》培训和普法宣传

我市各级发展改革部门要有针对性开展《政府投资条例》（国务院令第712号，以下简称《条例》）学法培训活动，并结合配套措施制定和政府投资年度计划编制等组织开展后续培训活动；要将《条例》作为相关学习培训、考核考试的重要辅导备考内容，督促广大干部深入领会《条例》精神，不断提高发展改革部门依法履职能力，确保《条例》各项规定和要求得到严格执行；要通过组织座谈会、业务培训和交流活动等，引导工程咨询、勘察设计、招标代理、建设施工等单位和个人深入学法，提高依法开展政府投资项目中介服务的履职能力；要会同相关部门按责任落实“谁执法、谁普法”结合广州实际向广大企业和社会公众讲解、宣传《条例》，大力创新普法宣传方式，充分运用各类新媒体，增强社会各界对《条例》的知晓度；要把法规的解读解释贯穿于政府投资具体管理服务的始终，使各相关部门和企业准确理解政府投资行为，形成政府投资项目参建单位自觉遵守基本建设法定程序、社会公众依法表达意见建议和依法开展社会监督的良好局面。

二、全面清理不符合《条例》的现行制度

按照“谁制定、谁清理”的原则，全面清理与政府投资相关的部门规章、地方性法规、地方政府规章、规范性文件，抓紧做好《条例》实施前的各项准备工作。对政府投资方向、资金筹措、投资方式、决策程序、投资计划、监督管理等方面违反《条例》的内容，须统一到《条例》规定上来，有关文件违反《条例》的，应当予以废止，有关文件与《条例》不一致的，应当进行修订。我市各级发展改革部门要按照省发展改革委的要求，组织我市地方性法规的起草部门或主要执法机关，结合《条例》相关内容提出我市相关地方性法规清理意见；于2019年12月31日之前完成修订、废止程序。自2017年7月1日之日起，我市各级各类政府投资管理规定与《条例》规定和精神不一致的，一律停止执行，相关工作以《条例》规定为准。

三、加快《条例》配套制度建设

按照“分级负责”的原则，我市各级发展改革部门结合《条例》的贯彻实施，重点围绕决策程序、资金安排、建设实施、信息共享、绩效管理、事中事后监管等方面完善工作机制和管理制度，特别是要围绕政府投资资金统筹规范使用、项目有序合理安排、加强投资计划与预算衔接、提高项目建设效率等难点问题，不断推进制度创新、完善政策和提升管理等各项工作。相关制度文件请于2019年12月31日之前报送市发展改革委。

广州市发展和改革委员会

2019年6月21日
