# 广州市住房和城乡建设局关于办理建筑工匠入库登记和诚信加分事项的通知

各有关单位：

为弘扬工匠精神，推进建筑产业工人队伍建设，根据中共中央办公厅国务院办公厅《关于提高技术工人待遇的意见》（中办发〔2018〕16号）等规定，现委托广州市建设宣传教育和建筑业劳保金管理中心执行《广州市住房和城乡建设委员会关于完善施工和监理企业诚信综合评价体系的通知》（穗建规字〔2018〕19号）关于对企业和工程项目聘用建筑工匠予以诚信加分的规定，从2019年7月1日起通过广州市建设领域管理管理应用信息平台办理建筑工匠入库登记和聘用建筑工匠诚信加分事项，有关办事指引见附件。
