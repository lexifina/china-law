# 广州市住房和城乡建设局关于印发2019年广州市建筑施工“安全生产月”和“安全生产万里行”活动方案的通知

各区住建局、广州空港委国规建设局，市建设工程安全监督站、市市政工程安全质量监督站、市建设工程质量监督站，各有关协会、企业：

根据《广东省住房和城乡建设厅关于印发<2019年广东省建筑施工“安全生产月”和“安全生产万里行”活动方案>的通知》（粤建质〔2019〕99号）和市委、市政府工作部署，为开展好我市建设施工“安全生产月”和“安全生产万里行”活动，推动全市安全生产形势持续稳定好转，我局制定了《2019年广州市建筑施工“安全生产月”和“安全生产万里行”活动方案》。现印发给你们，请结合实际认真组织开展活动。

广州市住房和城乡建设局

2019年6月3日
