# 广州市住房和城乡建设局关于印发广州市住房城乡建设领域安全生产隐患大排查实施方案的通知

各区住建局、广州空港委国规建设局、越秀区房屋管理局，市市政工程安全质量监督站、市建设工程质量监督站、市建设工程安全监督站、市人防工程质量监督站，各有关单位：

根据《广东省住房和城乡建设厅关于印发<广东省住房城乡建设领域安全生产隐患大排查实施方案>的通知》（粤建质〔2019〕106号）要求，我局决定在全市住建领域开展安全生产隐患大检查。为确保安全生产隐患大检查工作有效实施，现将《广州市住房城乡建设领域安全生产隐患大排查实施方案》印发给你们，请认真贯彻执行。

广州市住房和城乡建设局

2019年6月3日
