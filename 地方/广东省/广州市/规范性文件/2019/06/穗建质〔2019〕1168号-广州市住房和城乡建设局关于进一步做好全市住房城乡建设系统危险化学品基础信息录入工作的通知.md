# 广州市住房和城乡建设局关于进一步做好全市住房城乡建设系统危险化学品基础信息录入工作的通知

各区住建局、广州空港委国规建设局，市市政站、市安监站、市人防站，各有关单位：

根据《广东省住房和城乡建设厅关于进一步做好全省住房城乡建设系统危险化学品基础信息录入工作的通知》（以下简称《通知》，详见附件）要求，自2019年5月20日起，我省已上线运行“广东省危险化学品基础信息管理系统”，启动了全省危险化学品生产、存储、使用、经营、运输和废弃处置各环节的基础信息录入工作。为切实落实《通知》要求，现将有关工作要求通知如下：

一、请各区住建局（含广州空港委国规建设局，下同）、各级安监站按照省、市相关工作部署，结合我局3月25日下发的《广州市住房和城乡建设局关于进一步加强建筑工程涉及危险化学品安全综合治理工作的通知》（穗建质〔2019〕645号）中的附件《住房城乡建设系统涉及危险化学品安全风险的行业品种目录》，指导相关项目开展危险化学品风险摸排和信息录入工作，切实督促相关项目依时间节点准时录入各项信息，并于6月底前完成填报数据的审核工作。

二、请各区住建局、各级安监站于6月28日前报送信息录入工作开展情况书面及电子版。我局将适时通报各单位工作完成情况。
