# 广州市住房和城乡建设局关于印发广州市建设工程绿色施工围蔽指导图集补充（V1.1版）的通知

各区（含广州空港经济区）住建局，各有关单位：

为进一步提升我市建筑施工围蔽的建造水平，加强施工精细化、标准化管理，减少工程固体废弃物排放，我局在《广州市建设工程绿色施工围蔽指导图集（V1.0试行版）》的基础上，增补编制了《广州市建设工程绿色施工围蔽指导图集补充（V1.1版）》。现将该图集印发给你们，请结合两本图集规范开展我市建筑施工围蔽提升工作。各单位在执行中遇到问题或有好的建议，请及时反馈我局。

广州市住房和城乡建设局

2019年6月27日
