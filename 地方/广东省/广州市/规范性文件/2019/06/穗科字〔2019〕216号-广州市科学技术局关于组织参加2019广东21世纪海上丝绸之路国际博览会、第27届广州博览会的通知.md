# 广州市科学技术局关于组织参加2019广东21世纪海上丝绸之路国际博览会、第27届广州博览会的通知

穗科字〔2019〕216号

各有关单位：

广东21世纪海上丝绸之路国际博览会(简称“海丝博览会”)创办于2014年，旨在打造落实“一带一路”倡议的精品工程，树立“做生意、谈合作，到广东”的国际形象。广州博览会是广州市人民政府主办的中外经贸结合的大型博览会，秉承“立足珠三角，面向海内外，服务全中国”的宗旨，发挥国家重要中心城市作用和粤港澳大湾区建设核心引擎作用的重要交流平台。2019广东21世纪海上丝绸之路国际博览会、第27届广州博览会将于8月23日至26日在中国进出口商品交易会展馆合并举办。

近年来，广州市以发展“IAB”(新一代信息技术、人工智能、生物医药)产业与“NEM”(新能源、新材料)产业为主导，不仅吸引了更多的国内外企业在广州落户，也为广州的创新发展带来新机遇。根据广州市政府的安排，广州市科学技术局将在本届博览会设立“科技创新展区”，展示我市近年来的科技创新成果，本届博览会“科技创新展区”的招展和布展工作由全国科研新技术新产品展销中心和广州双威展览服务有限公司负责。现将有关事项通知如下：

一、展览内容

(一)科技政策宣传：科技创新和人才政策、科技金融政策等。

(二)“科技与生活”高科技产品展示：围绕IAB、NEM产业贴近民生的高科技产品或科技成果等。

二、展览规模和方式

为了更好地展示广州科技创新成果，增强会展效果，“科技创新展区”将实行统一特装,参展单位需提供展板喷画的设计稿文件，由我局统一制作。展示形式以展板和实物相结合，展区设有LED大屏幕，可供参展单位视频播放。

三、参展费用

本展区不收取参展单位相关费用。

四、展览时间及要求

(一)展览时间：2019年8月23日至26日

(二)布展时间：2019年8月20日至22日

(三)撤展时间：2019年8月26日下午13:00时

(四)展览地点：中国进出口商品交易会A区3.2展馆

(广州市海珠区阅江中路380号)

(五)各参展企业优先推荐本单位优秀项目和技术含量高的项目参展，以图片、实物、简短文字等展示。

(六)各参展企业于6月20日前将“参展报名表”通过E-MAIL方式发送到全国科研新技术新产品展销中心。

请各区科技部门、高新园区认真组织有关单位积极报名参加，并按要求做好参展工作。
