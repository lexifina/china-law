# 广州市科学技术局关于番禺区外国人来华工作许可业务服务窗口变更的通知

( )

穗科字〔2019〕267号

各有关单位：

根据我市机构改革方案，我局对“广州市外国人来华工作许可”受理机构进行了调整。“番禺区人才交流管理办公室服务窗口”将于2019年7月1日(星期一)起正式停止对外服务。2019年6月28日(星期五)下午5:00前，番禺区辖内的用人单位可继续前往该服务窗口办理“外国人来华工作许可”业务。自2019年7月1日(星期一)起，番禺区辖内的用人单位，可前往“广州市外国人来华工作服务窗口”办理“外国人来华工作许可”业务。“广州市外国人来华工作服务窗口”具体地址和办公时间如下：

一、广州市外国人来华工作服务窗口

1.宜安广场服务窗口，地址：越秀区建设六马路33号宜安广场503室。

2.精典大厦服务窗口，地址：天河区天河路198号南方精典大厦9层14、15号窗。

3.天河人才港服务窗口，地址：天河区软件路13号天河人才港7楼。

二、办公时间

星期一至星期四：上午9:00-12:00，下午1:30-5:00。

星期五：上午9:00-12:00，下午1:30-3:00。

法定节假日除外。

广州市科学技术局
