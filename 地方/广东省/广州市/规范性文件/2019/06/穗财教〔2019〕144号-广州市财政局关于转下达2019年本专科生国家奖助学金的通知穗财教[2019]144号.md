# 广州市财政局关于转下达2019年本专科生国家奖助学金的通知穗财教[2019]144号

穗财教〔2019〕144号

广州市财政局关于转下达2019年本专科生国家奖助学金的通知

市教育局、市体育局、市科协、市总工会、广州大学、广州医科大学：

根据《关于下达2019年本专科生国家奖助学金的通知》(粤财科教〔2019〕19号，详见附件1)，现将2019年本专科生国家奖助学金清算资金14,885,975元转下达给你们(具体项目金额、功能分类科目、政府和部门经济分类详见附件2)。并就有关事项通知如下：

一、请加强资金管理，提高资金使用效益，同时接受财政部广东监管局等有关部门的监督。

二、为贯彻落实党的十九大关于“全面实施绩效管理”的决策部署，切实提高财政资金使用效益，请各学校在组织预算执行中对照你校绩效目标(详见附件1)做好绩效监控，确保年度绩效目标如期实现。同时，请市教育局将我市绩效目标及时分解，做好市内预算绩效管理工作。
