# 政府采购投诉终止处理决定书（麦克兴）穗财采[2019]185号

穗财采〔2019〕185号

投诉人：陕西麦克兴科技有限公司

地址：陕西省西安市杨陵区杜寨村

被投诉人1：广州盛园咨询服务有限公司

地址：广州市白云区鹤龙街黄边北路575号四楼418房

被投诉人2：广州市林业和园林科学研究院

地址：广州市白云区广园中路428号

投诉人在购买被投诉人1组织的“广东广州城市生态系统国家定位观测研究站建设配套仪器设备购置经费”(项目编号：SYZFCG-[2019]002，以下简称本项目)招标文件后，认为本项目招标文件存在不合理条款、违反相关规定，于2019年4月17日向被投诉人1提出质疑，并认为被投诉人1未在规定时间内作出答复，于2019年5月13日向本机关提出投诉，本机关依法受理。

在调查核实期间，投诉人于2019年5月29日向本机关书面提交了《撤回投诉函》，撤销该项目的投诉。根据《中华人民共和国政府采购法实施条例》第五十七条第二款和《政府采购质疑和投诉办法》(财政部令第94号)第三十条规定，本机关决定终止投诉处理程序。

如对上述处理决定不服，可在接到本决定书之日起60天内向广州市人民政府行政复议办公室(地址：广州市越秀区小北路183号金和大厦2楼，电话：83555988)或广东省财政厅(地址：广州市越秀区北京路376号，电话：83170030)提出行政复议申请，或在接到本决定书之日起6个月内直接向有管辖权的人民法院提起行政诉讼。

广州市财政局

2019年5月31日
