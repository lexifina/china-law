# 广州市农业农村局关于政协十三届广州市委员会第三次会议第2003号提案答复的函

舒锐委员：

您提出的《关于水产生态养殖、尾水异位处理的建议》（第2003号）收悉。我市政府高度重视，积极组织市农业农村局、市生态环境局等单位进行认真研究办理，并于6月3日与您进行了沟通交流，您也及时对提案办理工作提出了很好的建议。经综合市生态环境局等单位意见，现将办理有关情况答复如下：

一、关于提倡陆基推水式集装箱养殖模式

陆基推水式集装箱养殖模式离开池塘但又与池塘紧密结合，是跳出池塘又发展池塘的最前沿的技术模式，具有节水节地、高效集污、生态环保、尾水达标、品质提升、智能标准等特点，被农业农村部列入2018年十大引领性技术，是对传统水产养殖方式的重大变革。我局对这一技术高度重视，2018年以来多次组织到南沙区东涌镇水产高科技园现场考察调研。通过调研，我局认为陆基推水式集装箱养殖模式既符合广州生态文明建设的要求，又能提供优质水产品，是广州渔业转型升级实现高质量发展的有效途径之一，将在广州逐步开展示范和推广。

（一）将陆基推水式集装箱养殖模式列入2019年全市农业主要推广技术在全市开展培训推广。今年上半年全市组织举办了6期水产健康养殖水产技术与养殖水生态治理技术培训班，把陆基推水式集装箱养殖模式技术作为重要的培训内容，共培训养殖技术人员、养殖场负责人450人。2019年4月11日，我局又专门组织渔业技术人员和从化区部分养殖户共20多人到顺德基地和南沙基地考察学习，现场观摩和感受陆基推水式集装箱养殖模式技术。

（二）将陆基推水式集装箱养殖模式作为主要模式列入《广州市渔业健康养殖技术模式推广手册》。为推动广州渔业实现高质量发展，我局于2019年3月25日邀请多名专家组织召开广州市渔业健康养殖技术研讨会，研讨编制《广州市渔业健康养殖技术模式推广手册》，陆基集装箱式推水生态养殖技术模式是广州四种健康养殖模式之一。我局根据推广手册制作了宣教视频，在广州全面推广。2019年5月30日我局在南沙区东涌镇水产高科技园现场举办了广州市健康养殖模式专题培训班，70多人参加了培训。

（三）安排专项资金建设陆基推水式集装箱养殖模式示范点。为加强陆基推水式集装箱养殖模式在广州市的推广力度，我局专门安排资金，在广州市农业技术推广中心基地建设集装箱养殖模式示范点，在全市示范推广。目前项目正在抓紧推进落实中。同时指导各区农业农村部门把陆基推水式集装箱养殖模式的设施建设纳入“菜篮子”资金支持补助范围，对养殖户采用陆基推水式集装箱养殖模式技术进行水产养殖的，可以利用“菜篮子”资金可按照不超过项目总投资45％给予补助。

二、关于建议水产养殖尾水异位处理

近年来，广州市委市政府高度重视生态文明建设，大力推动水产养殖绿色发展。2019年3月完成编制和发布《广州市养殖水域滩涂规划（2019～2030）》，对全市的水域滩涂划定了禁止养殖区、限制养殖区和养殖区，并明确要求水产养殖尾水以循环利用为主，对外排放的必须达到排放要求。2018年在全市启动开展了池塘养殖水治理三年行动，印发《广州市池塘养殖水治理三年行动方案（2018～2020）》及其配套政策文件《广州市池塘养殖水治理财政补助和验收方案》和《广州市池塘养殖水生态治理技术指导意见》，对全市经营连片50亩以上共近19万亩池塘养殖水进行检测和治理，对市河长办纳入小微水体的全市1320个鱼塘开展整治，目前正在抓紧推进落实中。提案中提到的“建议养殖尾水异位处理”正是广州市池塘养殖水生态治理的主要技术之一，我们利用异位处理技术在花都区完成1192亩池塘养殖水治理示范点建设，经检测，示范点治理效果明显。陆基推水式集装箱养殖模式也是养殖尾水异位处理的有效技术之一，养殖场如采用这一技术治理养殖水，达到验收要求后同样可以获得财政补贴。

三、下一步工作方向

2019年1月农业农村部等九部委印发了《关于加快推进水产养殖业绿色发展的若干意见》，明确加快推进水产养殖业绿色发展。下一步，我市将以习近平新时代中国特色社会主义思想为指导，努力践行绿水青山就是金山银山的发展理念，加快推进广州渔业绿色发展。一是加快推进鱼塘养殖水治理，通过治理，鱼塘养殖水实现以循环水再利用为主，少量排放的达到受纳水体的水质目标，保护渔业生态环境；二是加大政策扶持力度，大力引导广州渔业向包括陆基推水式集装箱养殖模式在内的绿色、健康、生态养殖模式发展。

感谢您对广州渔业绿色发展的关心和支持，欢迎您继续对广州渔业工作提出宝贵意见和建议。

广州市农业农村局
