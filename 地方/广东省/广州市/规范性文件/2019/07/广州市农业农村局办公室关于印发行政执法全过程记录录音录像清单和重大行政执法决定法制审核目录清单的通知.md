# 广州市农业农村局办公室关于印发行政执法全过程记录录音录像清单和重大行政执法决定法制审核目录清单的通知

各区农业农村主管部门，局机关各处室、局属各单位：

按照《广东省人民政府办公厅关于印发广州市推行行政执法公示制度执法全过程记录制度重大执法决定法制审核制度试点工作方案的通知》（粤府〔2019〕36号）、《广东省司法厅关于开展行政执法公示工作的通知》（粤司函〔2019〕677号）和《广州市司法局关于开展行政执法公示工作的通知》（穗司函〔2019〕784号）要求，根据《广州市农业局办公室关于印发广州市农业局重大行政执法决定法制审核制度的通知》（粤农办〔2017〕330号），结合实际，我局制定了《广州市农业农村局行政执法全过程记录录音录像清单》和《广州市农业农村局重大行政执法决定法制审核目录清单》，现印发给你们。请局机关各处室、局属各单位认真贯彻落实。各区农业农村行政主管部门可参考本清单，结合实际，另行制定本地区清单。
