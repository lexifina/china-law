# 广州市科学技术局关于公开遴选2019-2020年广州市科技报告管理服务实施单位的公告

我局拟公开遴选一家具有相关工作经验的实施单位开展“2019-2020年广州市科技报告管理服务”工作。现将有关事项公告如下：

一、本项目征集起始日期：

2019年7月26日至8月1日。

二、承担单位的资质和业务要求

(一)在广州市内依法注册设立的具有独立法人资格的企事业单位;

(二)具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

(三)有符合要求的固定办公场所，熟悉科技系统业务，具有科技报告管理服务经验，有稳定的技术队伍和较为完善的服务机制;

(四)本项目不接受联合体报名。

三、项目内容及要求

委托事项内容：2019-2020年对广州市科技计划项目的科技报告工作进行常态化管理服务。具体包括：

1.开展科技报告相关政策宣传工作;

2.解答企业日常业务咨询和系统技术咨询，提供辅导服务;

3.开展部分已结题及在研广州市科研类计划项目的科技报告回溯、加工、接收、审核、保存和共享报告等服务，在服务期内收集加工的科技报告不少于1000份;

4.协助处室跟进科技报告呈交系统、审改系统的开发建设工作，提出完善意见和建议;

5.协助开展广州市科技报告呈交数据的清洗、编研、加工工作;

6.协助开展广州市科技报告审核改写数据的合并、PDF转换工作;

7.协助处室对接省科技厅科技报告管理相关工作。

四、项目完成时间：2020年7月31日

五、需提交的材料

有意参与本项工作的单位需提交申请书( 包括申请单位情况介绍)，并附以下材料：

(一)单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)完成同类项目证明，以及能证明本单位实力或能胜任本项工作内容的相关证明材料;

(四)项目实施方案，包括项目进度安排、预算明细、服务保障等;

(五)其他可以佐证机构专业能力、项目实施团队情况、资质、相关工作经验、业绩、信誉奖项等情况的材料;

(六)报价及预算明细。

六、费用预算：人民币45万元以内(含45万元)。

七、申请书提交时间、地址：以上书面材料(一式五份含电子光盘一份)密封后，请于2019年8月1日17：00前交至广州市科学技术局资源配置与管理处，逾期不予受理( 地址：广州市越秀区府前路1号4号楼东座411室，邮政编码：510030)。

八、咨询电话：夏万志，020-83124036 ( 工作日8：30-12：00、14：00-17：30)

九、我局将组成内部评标工作组择优遴选本项目最终承担单位，与其协商拟定正式委托合同。
