# 广州市科学技术局关于公开遴选2019年广州市科技局网站、官方微博、官方微信公众号、第三方平台官方推送号等信息内容维护管理项目实施单位的公告

我局拟公开遴选一个具有经验的实施单位开展“广州市科技局网站、官方微博、官方微信公众号、第三方平台官方推送号等信息内容维护管理”项目工作。现将有关事项公告如下：

一、本项目征集起始日期：

2019年7月1日至7月5日。

二、承担单位的资质和业务要求

(一)在广州市内依法注册设立的具有独立法人资格的企事业单位;

(二)具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

(三)有符合要求的固定办公场所，熟悉科技系统业务，具有运维政务网站、政务微博微信、新闻APP政务号等项目经验，有稳定的内容编辑和技术队伍，以及较为完善的服务机制;

(四)本项目不接受联合体报名。

三、项目内容及要求

委托事项内容：2019年度广州市科技局网站、官方微博、官方微信公众号、第三方平台官方推送号等信息内容维护管理。

(一)广州市科技局官网信息内容维护管理工作

确保信息转载、发布符合有关部门的管理要求和考核要求，不得出现违规信息;并严格按照考核更新频率指标对信息进行更新。

1.开展局官方网站(含原广州科普网，现变更为科普专栏)信息维护更新工作，每天进行信息采编、审核、发布。

2.确保网站上内容的链接可用性、服务可用性。

3.优化完善网站栏目、功能，按要求对网站内容进行整改、调整，补充相关内容。

(二)“广州市科学技术局”微博信息内容维护管理工作

1.做好微博维护建设，适时提出增加影响力的优化建议。

2.根据市科技局要求做好相关微博信息更新。

3.根据市科技局工作热点需求在每个工作日进行内容提炼、编写、推送图文信息。原则上平均每个工作日发布信息5条，特殊情况可多于5条。

4.积极回复粉丝留言。认真做好公众留言审看发布、处理反馈工作，回复留言要依法依规、态度诚恳、严谨周到，杜绝答非所问、空洞说教、生硬冷漠。加强与市科技局具体业务处室的沟通协作，对于群众诉求要限时办结、及时反馈，确保合理诉求得到有效解决。

5.确保信息转载、发布符合有关部门的管理要求和考核要求，不得出现违规信息。

(三)“广州创新”微信公众号信息内容维护管理工作

1.做好微信公众号栏目维护建设，适时提出增加影响力的优化建议。

2.根据市科技局工作热点需求在每个工作日进行内容编写、推送图文信息。重点推送国家、省、市科技系统重要政策文件信息和涉及群众切身利益、需要公众广泛知晓的政府信息。注重运用生动活泼、通俗易懂的语言以及图表图解、音频视频等公众喜闻乐见的形式提升解读效果。

3.注重结合市科技局重大活动(如2019广州科技活动周、科技创新大会等)设置话题、策划活动，探索政民互动新方式。

4.定期对官微关注回复、自动回复、关键词回复进行内容更新。

5.积极回复粉丝留言。认真做好公众留言审看发布、处理反馈工作，回复留言要依法依规、态度诚恳、严谨周到，杜绝答非所问、空洞说教、生硬冷漠。加强与科技局具体业务处室的沟通协作，对于群众诉求要限时办结、及时反馈，确保合理诉求得到有效解决。

6.确保信息转载、发布符合有关部门的管理要求和考核要求，不得出现违规信息。

(四)“广州创新”第三方平台官方推送号信息内容维护管理工作

1.做好广州市科技局第三方平台(包括广州参考、今日头条、澎湃新闻、南方+、抖音)官方推送号的信息内容更新保障工作，确保符合有关管理部门的考核要求。

2.积极回复粉丝留言。认真做好公众留言审看发布、处理反馈工作，回复留言要依法依规、态度诚恳、严谨周到，杜绝答非所问、空洞说教、生硬冷漠。加强与科技局具体业务处室的沟通协作，对于群众诉求要限时办结、及时反馈，确保合理诉求得到有效解决。

3.确保信息转载、发布符合有关部门的管理要求和考核要求，不得出现违规信息。

四、项目完成时间：2019年12月31日

五、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

(一)单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)完成同类项目证明，以及能证明本单位实力或能胜任本项工作内容的相关证明材料;

(四)项目实施方案，包括项目进度安排、预算明细等;

(五)其他可以佐证机构专业能力、资质、相关工作经验、业绩等情况的材料。

六、费用预算：人民币59万元以内。

七、申请书提交时间、地址：以上书面材料(一式五份含电子光盘一份)密封后，请于2019年7月5日17:30前交至广州市科学技术局办公室403室，逾期不予受理。

八、咨询电话：020-83124015(工作日8:30-12:00、14:00-17:30)

九、我局将组成内部评标工作组择优遴选本项目最终承担单位，与其协商拟定正式委托合同。
