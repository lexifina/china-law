# 广州市科学技术局关于公开遴选广州科技创新主要经验成效专题宣传项目实施单位的公告

我局公开遴选广州科技创新主要经验成效专题宣传项目实施单位，现将有关事项公告如下：

一、本项目征集起始日期：

2019年7月19日至7月25日(5个工作日)。

二、承担单位的资质和业务要求

(一)依法注册设立的国有传媒集团及旗下子媒体，具有国家新闻出版部门颁发的新闻媒体资格证书，具有传统媒体、web端网站、新闻客户端app等全媒体融合渠道，要求受众范围全面覆盖但不限于全国范围，并在科技创新领域具备一定的专业性和权威性;或获得授权并能够在上述单位的媒体渠道上发布内容的相关企业;

(二)具有良好的商业信誉和健全的财务会计制度，依法缴纳税收;

(三)有符合要求的固定办公场所，熟悉我市科技创新工作，在广州有稳定的新闻采编队伍和较为完善的服务机制;

(四)本项目不接受联合体报名。

三、项目内容及要求

在主流全国性媒体进行广州科技创新主要经验成效的宣传，结合传统媒体渠道和新媒体渠道进行融媒体宣传。

反映广州科技创新落实和贯彻中央有关部署的最新情况，调研采访并总结广州科技创新在各方面具有全国领先意义的主要经验成效、案例，围绕推动基础科学研究、关键技术突破、科技成果转化以及支持自主研发创新、支持科技型中小企业发展、培养科技人才等主题和内容进行专题宣传，体现广州在粤港澳大湾区建设中作为国家中心城市和综合性门户城市的引领作用，以及培育提升科技教育文化中心功能的有力举措。

四、项目完成时间：2019年11月30日

五、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

(一)单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)完成同类项目证明，以及能证明本单位实力或能胜任本项工作内容的相关证明材料;

(四)项目实施方案。包括宣传策划方案、项目进度安排、预算明细等;

(五)其他可以佐证机构专业能力、资质、相关工作经验、业绩等情况的材料。

六、费用预算：人民币20万元以内。

七、申请书提交时间、地址：以上书面材料(一式五份)密封后，请于2019年7月25日前，交到市政府大院5号楼东座303室，逾期不予受理。

八、咨询电话：李晓银、凌嘉键，020-83124112、83124015(工作日8：30-12：00、14：00-17：30)

九、择优录取。我局将组成内部评标工作组择优遴选本项目最终承担单位，与其协商拟定正式委托合同。
