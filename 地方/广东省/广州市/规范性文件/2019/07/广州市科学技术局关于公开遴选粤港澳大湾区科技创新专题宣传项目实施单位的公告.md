# 广州市科学技术局关于公开遴选粤港澳大湾区科技创新专题宣传项目实施单位的公告

我局公开遴选一家粤港澳大湾区科技创新专题宣传项目实施单位。现将有关事项公告如下：

一、本项目征集起始日期：

2019年7月24日至7月30日(5个工作日)。

二、承担单位的资质和业务要求

(一)依法在广州市注册设立的国有传媒集团及旗下子媒体，具有国家新闻出版部门颁发的新闻媒体资格证书，具有传统媒体、web端网站、新闻客户端app等全媒体融合渠道，受众范围要求全面覆盖但不限于广州市范围，在我市各项工作情况发布中具有较强的权威性，或获得授权能够在上述单位的媒体渠道上发布内容的相关企业;

(二)具有良好的商业信誉和健全的财务会计制度，依法缴纳税收;

(三)有符合要求的固定办公场所，熟悉我市科技创新工作，在广州有稳定的新闻采编队伍和较为完善的服务机制;

(四)本项目不接受联合体报名。

三、项目内容及要求

对广州在粤港澳大湾区建设中的科技创新情况进行宣传，结合传统媒体渠道和新媒体渠道进行融媒体宣传。

(一)以湾区科创为主题，围绕科技创新总体情况，开展采访交流活动，采访在湾区建设中有代表性的专家、人物和研究院校、企业等，集中反映科技创新政策、科技人才支持、科技成果转化、科学装置建设、创新主体培育、科技交流合作等最新情况，并进行深度专题策划宣传。

(二)结合广州创新的官方号，在客户端、网站等设专题页面，形成新媒体传播稿件，制作一图读懂、政策检索及解读小程序等易于传播的新媒体产品，进行全媒体传播。

四、项目完成时间：2019年12月31日

五、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

(一)单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)完成同类项目证明，以及能证明本单位实力或能胜任本项工作内容的相关证明材料;

(四)项目实施方案。包括宣传策划方案、项目进度安排、预算明细等;

(五)其他可以佐证机构专业能力、资质、相关工作经验、业绩等情况的材料。

六、费用预算：人民币60万元以内。

七、申请书提交时间、地址：请于2019年7月30日前，以上书面申请材料(一式五份)密封后，交到市府大院5号楼东座403室，逾期不予受理。

八、咨询电话：李晓银、凌嘉键，020-83124112、83124015(工作日8:30-12:00、14:00-17:30)

九、择优录取。我局将组成内部评标工作组择优遴选本项目最终承担单位，与其协商拟定正式委托合同。
