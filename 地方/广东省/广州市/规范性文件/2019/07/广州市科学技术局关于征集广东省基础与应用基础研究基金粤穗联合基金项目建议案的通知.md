# 广州市科学技术局关于征集广东省基础与应用基础研究基金粤穗联合基金项目建议案的通知

( )

各区科技行政管理部门，各有关高校、科研院所和企业：

为深入实施创新驱动发展战略，着力解决前沿领域创新发展的重大科学问题，支撑粤港澳大湾区国际科技创新中心建设，广东省科学技术厅、广州市人民政府与广东省基础与应用基础研究基金委员会拟共同组织实施广东省基础与应用基础研究基金粤穗联合基金(以下简称粤穗联合基金)。为做好粤穗联合基金申报指南编制工作，现面向全市各区科技行政管理部门，以及广州地区各有关高校、科研院所和国家重点实验室建设依托企业等38家单位(附件1)征集项目建议案。具体要求如下：

一、各区科技行政管理部门，各有关高校、科研院所和国家重点实验室建设依托企业，应结合自身优势与特色学科，兼顾领域平衡，组织高水平团队(原则上要求负责人与团队成员不存在申报省科技计划项目限项情况)，按照项目建议案(附件2)的格式要求，提出不超过3项项目建议案，并明确建议财政支持经费为300万元或100万元。我局将结合建议案提交情况，组织专家咨询，形成指南初稿，报省自然科学基金委。

二、各有关单位提交项目建议案的截止时间为2019年7月18日(周四)下午17:00。项目建议案纸质材料需加盖本单位科技管理科(处)公章后送至我局，并将盖章扫描版及Word文档同步发送到jackyhwxing@163.com。逾期不提交，视同无项目建议案。

专此通知。
