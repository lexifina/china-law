# 广州市科学技术局关于遴选“广州市科学技术局预算绩效管理服务”项目承担单位的公告

我局拟公开遴选一个具有资质实施单位承担“广州市科学技术局预算绩效管理服务”项目工作。现将有关事项公告如下：

一、本项目征集起始日期

2019年7月17日至7月23日(5个工作日)。

二、承担单位的资质和业务要求

(一)在国内依法注册设立的具有独立法人资格的社会组织或企事业单位，有符合要求的固定办公场所;

(二)具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

(三)有符合要求的固定办公场所，熟悉广州市财政局对部门预算的绩效管理要求以及科技系统绩效管理规律，具有科技部门预算绩效管理服务经验，拥有财政预算绩效管理的专家团队，具有较强的技术实力、专业力量和良好的沟通能力，能够高质高效地完成广州市科学技术局预算绩效管理相关工作;

(四)承担单位必须是2019-2021年度广州市财政局绩效管理定点服务资格采购项目(采购项目编号：GZCQC1801FG05034)的28家中标单位之一(见附件1);

(五)本项目不接受联合团体报名。

三、项目内容及要求

委托事项内容：2019年度广州市科学技术局预算绩效管理相关工作。

(一)遴选要求：本次遴选出一个项目单位，承担2019年“广州市科学技术局预算绩效管理服务”项目工作;遴选工作完成后，项目承担单位与我局签订委托服务合同。

(二)委托服务的目标：按照广州市财政局和广州市科学技术局的预算绩效管理相关要求，按时、按质、按量开展广州市科学技术局预算绩效管理的相关工作。

(三)委托服务的内容：

1. 协助开展2019年上半年我局部门支出和项目绩效运行情况监控;

2. 协助开展2018年度我局部门支出绩效评价结果应用;

3. 分析研究我局2018年度部门支出绩效和2019年绩效监控情况，为设置2020年项目绩效指标和绩效目标提供专业指导和建议;

4. 协助我局进一步建立完善专项项目预算绩效指标库，协助建立局预算绩效管理制度;

5. 开展预算绩效管理专题培训;

6. 按要求协助编制《重大项目事前绩效评估报告》。

(四)项目完成时间：2019年10月31日前。

四、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

(一)申请单位基本情况表(原件盖章，见附件2);

(二)营业执照副本或登记证书(复印件盖章);

(三)完成同类项目证明，以及能证明本单位实力或能胜任本项工作内容的相关证明材料;

(四)项目实施方案，包括项目进度安排、预算明细等;

(五)其他可以佐证机构专业能力、资质、相关工作经验、业绩等情况的材料。

五、费用预算：人民币20万元以内。

六、申请书提交时间、地址：以上书面材料(一式五份含电子光盘一份)密封后，请于2019年7月23日17:30前交至广州市科学技术局科技监督与诚信建设处(广州市越秀区府前路1号市府大院4号楼西座403室)，逾期不予受理。

七、咨询电话：020-83124041(工作日8:30-12:00、14:00-17:30)，联系人：许鸿斌。

八、我局将组成内部评标工作组择优遴选本项目最终承担单位，与其协商拟定正式委托合同。
