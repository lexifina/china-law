# 广州市科学技术局关于邀请参加第三届中俄创新对话的通知

各有关单位：

为落实中俄两国元首共识，深化中俄在高技术以及创新领域的交流与合作，中国科技部与俄罗斯经济发展部拟于2019年9月25-26日在上海共同举办“第三届中俄创新对话”。现转发《科技部国际合作司关于邀请参加第三届中俄创新对话的函》(国科外函〔2019〕22号)，并就我市有关工作安排通知如下：

一、 活动时间

2019年9月25-26日

二、 活动地点

上海

三、活动内容

本届对话重点推动中俄双方在人才驱动创新、区域集群创新、创新投融资、创新政策与战略等方面的交流与合作。在本届对话框架下，将举办主旨交流、中俄创新创业大赛、创新合作项目对接会、中俄创新投资合作论坛等活动，并同期举行中俄创新合作协调委员会第三次会议。

四、报名须知

1. 请市内相关科研机构、高校、企业积极参加相关活动，并于8月9日17:30前将报名回执发至邮箱372629225@qq.com。我市汇总报名回执后统一反馈至科技部国际合作司。

2. 本次活动费用由派员单位自理。

3. 活动地点、日程安排以及会务接待等具体事宜待会议承办方在后续通知中做进一步说明。

4. 我市组织活动详情请径向广东科技企业合作促进会(亦称“广东-独联体国际科技合作联盟”)咨询。
