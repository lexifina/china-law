# 广州市住房和城乡建设局关于更新维护企业诚信档案信息库企业基本信息的通知

各有关单位：

我局拟于近期向国家税务总局广州市税务局调取建筑业企业（施工企业、监理企业、招标代理机构）2018年度在我市缴纳的营业税、增值税和所得税等纳税信息，该项工作将以建筑业企业在“广州市住房和城乡建设局企业诚信档案信息库”的企业基本信息作为调取依据，结果将对企业诚信档案评分产生影响。

为确保此次调取纳税信息的准确性和完整性，请各单位高度重视，于2019年8月8日前自行登录“广州市住房和城乡建设局企业诚信档案信息库”检查并更新维护本单位基本信息，确保企业名称、统一社会信用代码等内容正确无误，避免因基本信息问题影响企业诚信得分和市场经营。

特此通知。

广州市住房和城乡建设局

2019年7月23日
