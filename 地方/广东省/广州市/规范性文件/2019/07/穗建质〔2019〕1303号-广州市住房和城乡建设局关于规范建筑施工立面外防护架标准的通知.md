# 广州市住房和城乡建设局关于规范建筑施工立面外防护架标准的通知

各区（含广州空港经济区）住建局，市建设工程安全监督站、市建设工程质量监督站，各有关单位：

为促进城市整体形象和品质提升，改善我市文明施工环境，进一步提升我市建筑工地安全生产标准化、精细化管理水平，加强作业安全防控，现就规范建筑施工立面外防护架标准提出以下要求：

一、外防护架材料标准

建筑施工立面外防护架常用的形式有：钢管脚手架挂密目式安全网、钢管脚手架挂冲孔钢板网、附着式升降脚手架等结构形式。

1．统一颜色标准。建筑施工立面外防护架立面主要材料的颜色选用1272号色（《中国建筑色卡》GB/T18922－2008，见附件1），包括钢管脚手架、密目式安全网、冲孔钢板等材料，具体做法参照附件2。

2．符合安全标准。每种外防护架的材料选型、结构安全等要符合国家、省、市相关标准规定。其中，密目式安全网密度不低于2000目，且耐火性、耐冲击性能、耐贯穿性能等指标应满足《安全网》（GB5725）的要求。

二、提升整改要求

1．从即日起，全市新搭建的建筑施工立面外防护架的材料颜色按照本通知标准执行，并符合安全标准要求。

2．7月31日前，完成对市重点区域（含东风路、黄埔大道、广州大道、珠江新城、金融城、琶洲、广州南站等）已搭建的建筑施工立面外脚手架提升整改工作，将原绿色安全网更换为1272号色密目式安全网（不少于2000目），并将原钢管脚手架改涂为1272号色。

三、有关工作要求

1．加强宣贯。请各区（含广州空港经济区）住建局、市建设工程安全监督站组织对监管项目参建单位进行宣贯和交底；各区住建局要将我局对建筑施工立面、施工围蔽、施工扬尘防护等文明施工要求传达到属地街道，指导其加强对限额以下小型工程文明施工的交底、监管工作。

2．督促整改。各单位要对监管工程进行逐一检查，建立台账，并督促各单位按时间要求完成提升整改工作；要加强对安全防护用品的监管，组织开展安全网等安全材料的检查，对采用不符合国家标准安全网的工程项目按照整改。
