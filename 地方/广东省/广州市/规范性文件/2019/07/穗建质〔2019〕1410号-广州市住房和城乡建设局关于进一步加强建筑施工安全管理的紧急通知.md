# 广州市住房和城乡建设局关于进一步加强建筑施工安全管理的紧急通知

各有关单位：

近期，我市建筑安全生产形势较为严峻，不安全事件时有发生，安全事故风险进一步加剧。为强化安全生产管理，防范遏制生产安全事故，现将具体工作要求通知如下：

一、深刻认清当前建筑安全的严峻形势

今年以来，全国建筑施工领域共发生342起事故，死亡430人，其中，有2起重大事故和9起较大事故。近期，我省、我市接连发生建筑施工安全事故，反映出当前建筑安全形势尤为严峻。我市持续开展建筑施工安全隐患排查行动，发现当前建筑安全生产还存在诸多问题，具体表现在：企业管理形同虚设，工作记录弄虚作假，特种作业人员持假证上岗，建筑设备带病运行，工地隐患普遍存在，监督检查和执法不够严、不够细、不够硬。第三季度历来是我市安全生产的关键期，建筑生产企业进入生产高峰，赶工期、赶进度等情况较为普遍，加之我市步入夏季高温期、主汛期及台风期，高温、暴雨、台风、雷电等气象灾害多发频发，对安全生产影响较大。各有关单位要认真贯彻习近平总书记关于安全生产工作的重要指示批示精神，进一步提高政治站位，牢固树立安全发展理念，坚持以人民为中心，坚守红线意识、底线思维，全面有效落实安全生产责任，防范化解各类安全风险，切实维护好人民群众生命财产安全和社会稳定。

二、切实落实安全生产主体责任

2017年，国务院安委办印发了《关于全面加强企业全员安全生产责任制工作的通知》，2018年4月，省委办公厅、省政府办公厅发布了《关于全面落实企业安全生产主体责任的通知》，2019年3月，我局印发了《关于强化落实建设各方安全生产管理主体责任的通知》，提出了安全生产六强化措施，对建设各方主体责任实行清单制。各有关单位要按以上要求，保障安全生产资金投入，保障工程安全合理工期；建立以企业主要负责人为核心的安全生产带班制度，制定健全的安全生产规章制度和安全操作规程，定期检验落实情况；健全安全管理架构，确保项目经理及专职安全管理人员到位，杜绝“以包代管”现象；加强安全生产费用管理，保证安全生产费用的专款专用和安全生产投入的有效实施；认真开展安全隐患排除，切实消除生产安全事故隐患；加强作业工人的安全教育培训，做好班前安全交底，提高工人安全意识，全面筑牢安全事故防线。

三、持续深入开展安全隐患排查整治工作

今年以来，市区两级住建部门大力开展隐患排查治理工作，累计出动检查组约4万人次，检查工地1．5万项（次），发现安全隐患1．9万条，重大隐患138条，取得了初步的成效，同时也反映出企业安全隐患排查不彻底、工地隐患较多等问题。各有关单位要树立“隐患即事故”的观念，按照我局印发的《2019年建筑施工安全生产专项整治工作实施方案》（穗建质〔2019〕564号）和《广州市住房城乡建设领域安全生产隐患大排查方案》（穗建质〔2019〕1084号）要求，继续深入开展建筑施工安全专项整治行动，突出强化危大工程、建筑起重机械、有限空间等重点领域安全管控，要加强汛期和强降雨后基坑和施工边坡安全监测，严防因土体水压升高导致基坑漏水或突涌导致的事故。加强对物体打击、高空坠落和基坑坍塌等易发安全事故的防范，切切实实不留安全死角，不留安全隐患。各区住建部门和安全监督机构要把企业落实隐患排查治理情况作为重要检查内容，对比企业自查、监督检查之间的“差额”，评估企业隐患排查治理工作是否真正落实。对弄虚作假、工作流于形式及工地隐患较多的有关企业和责任人员严厉追责。

四、加大监督执法力度

为推动我市建筑安全生产形势持续稳定好转，坚决压制事故多发的苗头，各区住建部门要用最严谨的标准、最严格的监管、最严厉的处罚、最严肃的问责，保持安全监管的高压态势，坚决打击各类安全违法违规行为。各区住建部门要将我市近两年发生建筑安全事故的企业列为重点监管对象（见附件），对其承接的项目进行全面检查，并对辖区内今年各类检查巡查发现存在重大安全隐患的企业扎实开展“回头看”工作。对工地管理未有明显改善，安全责任仍未有效落实的施工企业，约谈企业负责人并通报曝光，提请省住房城乡建设厅核查安全生产许可条件，不符合安全生产条件的，依法暂扣其安全生产许可证。

以上工作，请各区住建局于7月30日前完成，并于8月5日前向我局报送有关工作情况（电子版同步发至邮箱：gzjwzac＠126．com）。

特此通知。
