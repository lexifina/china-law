# 广州市民政局关于印发《2019年全市农村低保专项治理工作检查内容及要求》的通知

穗民〔2019〕232号

各区民政局：

为持续推进农村低保专项治理工作，结合我市工作实际，现将《2019年全市农村低保专项治理工作检查内容及要求》印发给你们，请结合实际抓好落实。执行过程中遇到的问题，请径与市民政局社会救助处联系。

广州市民政局

2019年6月29日

2019年全市农村低保专项治理工作检查内容及要求

为深入贯彻党的十九大、十九届中央纪委二次、三次全会精神，落实习近平总书记关于开展扶贫领域腐败和作风问题专项治理的重要指示精神，按照《全国农村低保专项治理方案》《全省农村低保专项治理方案》《全市农村低保专项治理方案》和2019年全国、广东省和广州市民政工作会议要求，结合扫黑除恶专项斗争民政行业领域治理和脱贫攻坚专项巡视整改，围绕“突出重点，全面排查，检查成效，巩固实效”，持续深入推进农村低保专项治理工作。

一、突出重点

（一）整治形式主义、官僚主义。检查农村低保专项治理工作中是否存在搞形式、走过场的问题，检查农村低保经办过程中是否存在不担当、不作为、脸难看、事难办等问题，检查全面从严治党主体责任落实情况，严肃工作纪律和群众纪律。

（二）查处“漏保”“错保”问题。将落实省《关于在脱贫攻坚三年行动中切实做好社会救助兜底保障工作的实施意见》作为治理重点，检查符合条件的重病、重残对象及时纳入低保情况，严肃查处农村低保中的“漏保”“错保”问题。

（三）查处近亲属备案制度不落实问题。将近亲属备案制度建立落实情况作为治理重点，检查是否对低保经办人员和村（居）委会干部近亲属纳入低保情况进行备案，是否做到档案单独存放，重点抽查复核，严肃查处农村低保中的“人情保”“关系保”问题。

（四）查处资金监管风险问题。将农村低保等社会救助资金监管作为治理重点，检查资金使用监管工作开展情况，查找资金监管的薄弱环节和风险点，严肃查处贪污侵占、虚报冒领、截留私分农村低保资金等问题。

（五）查处火化人员数据比对不及时问题。建立火化人员数据长期比对报送机制，区级社会救助部门根据殡葬管理部门实时共享的火化人员数据做好比对工作，及时掌握救助对象的死亡情况，做到线上线下操作同步，实现动态管理、应退尽退。各区民政部门要根据比对和调查结果，及时停发相关待遇，在信息系统内清退，并追回多发放的资金。

（六）查处宣传培训不到位问题。检查各区民政部门是否及时向公众宣传及进行信息公开、对社会救助工作人员培训低保政策情况，特别是对重度残疾人、重病患者等政策培训是否到位。市民政局将根据各地投诉举报、政策咨询工单量等数据，适时通报。

（七）查处信息化系统使用不规范问题。低保申请审核均应在民政综合生活保障信息系统中进行，并将申请材料上传至信息系统。对于已退出低保或经调查核实已确认死亡的对象，要在系统中及时清退。区民政部门和镇（街）要实时更新，严格按照系统名册进行资金发放，使实际低保资金发放、系统发放名册、计财台账等三方面数据保持一一对应。

二、完善机制

（一）健全治理工作台账。建立2019年专项治理工作台账，按季度按省民政厅要求更新工作台账，及时全面掌握各镇（街）工作进度，跟踪督促任务落实。

（二）建立定期报告和通报制度。市将按季度对各区专项治理进展情况进行汇总，及时对各区进行督促指导。按季度收集各区查处的违纪违法典型案例，市民政局会同驻局纪检监察组定期对典型案例进行公开通报。

（三）建立快速响应机制。在市、区、镇（街）三级明确专人负责专项治理工作，制定群众投诉举报值守人员通讯录，对于群众反映强烈的问题，形成上下联动的快速响应机制，提高群众诉求的回应效率。

三、加强实地检查

（一）加强调研指导。对于专项治理工作进展缓慢、成效不明显、上报情况不及时的区，加强实地调研指导，分析问题，查找原因，督促整改，确保专项治理工作深入开展。

（二）加大督办力度。通过信访部门、门户网站、媒体曝光、12345等渠道，收集农村低保经办中的腐败和作风问题线索，对于群众反映的突出问题和重点线索，市民政局将直接督办，不断加大问题线索查处力度。

（三）开展明察暗访。联合驻局纪检监察组等，赴重点区进行明察暗访，掌握基层农村低保经办第一手情况，总结经验，查找问题，提出整改建议。

四、巩固成效

（一）落实主体责任。各级民政部门要把农村低保专项治理作为落实管党治党政治责任的具体行动，主动履行专项治理工作的主体责任，逐级建立工作责任制度，明确责任单位和责任人，细化年度专项治理各项工作目标、任务和完成时限。

（二）落实整改措施。督促各区深入分析专项治理工作中发现的问题，研究提出整改措施，建立问题和整改清单，明确整改时限、责任单位和责任人，边查边改、立行立改。将整改落实情况作为年度绩效评价的重要内容。

（三）开展“回头看”。对2018年专项治理工作发现问题整改情况进行“回头看”，重点查看各项整改措施是否落实到位，列入整改的问题是否按期解决，整改效果群众是否认可。对于整改措施落实不力、整改效果不明显的区进行重点督导。

（四）加大监督力度。指导区民政部门在门户网站及时全面向社会公开农村低保政策、标准和对象有关信息，公开投诉举报电话。适时在民政部门户网站公开各地网址和电话，畅通投诉举报渠道，加大社会监督力度。
