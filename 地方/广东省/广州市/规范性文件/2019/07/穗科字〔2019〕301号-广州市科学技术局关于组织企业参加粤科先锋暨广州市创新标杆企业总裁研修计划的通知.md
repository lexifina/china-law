# 广州市科学技术局关于组织企业参加粤科先锋暨广州市创新标杆企业总裁研修计划的通知

穗科字〔2019〕301号

各相关企业：

为进一步强化企业创新主体地位，抓住建设粤港澳大湾区国际科技创新中心的历史机遇，发挥标杆企业示范引领作用，弘扬企业家精神，根据《广州市人民政府办公厅关于印发广州市重点服务创新标杆百家企业实施办法的通知》(穗府办规〔2016〕10号)，现发动各创新标杆企业积极参与“粤科先锋暨广州市创新标杆企业总裁研修计划”，活动有关情况如下：

一、活动时间

2019年9月至2020年8月。

二、活动目的

“粤科先锋暨广州市创新标杆企业总裁研修计划”系列活动由中国建设银行广州分行、南方报业传媒集团联合举办，广州市科学技术局进行业务指导，通过政府、金融机构、高校和媒体等多方机构联动，搭建平台为标杆企业、产业领军人才企业、创新企业等提供优质服务，助力企业做强做优做大。

三、活动内容

将组织企业参加以下活动：粤科先锋暨广州市创新标杆企业总裁研修班(与中山大学合办)、科技金融沙龙、并购金融沙龙、政策服务、金融服务、知识产权服务、企业宣传等。

本活动为市场行为，以自愿参加为原则，欢迎有需求的企业积极参与。联系人：杨盛恩、周国基，联系电话：

特此通知。

广州市科学技术局
