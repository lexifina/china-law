# 广州市财政局关于转下达2019年城企联动普惠养老专项行动中央基建投资预算的通知穗财保[2019]85号

穗财保〔2019〕85号

广州市财政局关于转下达2019年城企联动普惠养老专项行动中央基建投资预算的通知

越秀区财政局:

根据省财政厅《关于转下达2019年城企联动普惠养老专项行动中央基建投资预算的通知》(粤财建〔2019〕50号)，现将2019年城企联动普惠养老专项行动中央基建投资预算406万元下达给你区，专项用于广州市东山福利院四期工程，款列一般公共预算支出功能分类科目“2081002社会保障和就业支出—社会福利—老年福利”，部门预算经济分类科目“30999 其他基本建设支出”，政府预算经济分类科目“51301上下级政府间转移性支出”。并将有关事项通知如下：

一、此项资金专项用于广州市东山福利院四期工程项目的土建及设备购置等工作。请你局按照《预算法》的要求，及时将资金安排到项目单位，督促相关部门组织实施，切实加快预算执行，加强资金监管，不得挤占、截留或挪用，确保专款专用，并接受财政部广东监管局的监督。年终请按要求统一编列决算。

二、请你局加强财政资金绩效管理，对照国家发展改革委提出的绩效目标，对本次下达的预算指标和任务加强绩效目标监控和绩效评价，确保年度绩效目标如期实现。
