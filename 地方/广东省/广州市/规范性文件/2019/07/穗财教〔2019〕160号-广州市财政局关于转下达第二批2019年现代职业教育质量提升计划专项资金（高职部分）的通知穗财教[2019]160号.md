# 广州市财政局关于转下达第二批2019年现代职业教育质量提升计划专项资金（高职部分）的通知穗财教[2019]160号

穗财教〔2019〕160号

广州市财政局关于转下达第二批2019年现代职业教育质量提升计划专项资金(高职部分)的通知

市教育局：

根据《关于安排第二批2019年现代职业教育质量提升计划专项资金(高职部分)的通知》(粤财科教〔2019〕38号，详见附件1)，现将第二批2019年现代职业教育质量提升计划专项资金(高职部分)2,037万元转下达给你局(具体项目金额、功能分类科目、政府和部门经济分类详见附件2)。并就有关事项通知如下：

一、为落实资金安排，请市教育局于2019年6月18日前将上述资金的分配方案报我局。

二、本项资金不得用于偿还债务、支付利息、对外投资、弥补其他项目缺口等，不得从专项资金中提取工作经费或管理经费，也不得用于基本建设。请加强资金管理，提高资金使用效益，同时接受财政部广东监管局等有关部门的监督。

三、为贯彻落实党的十九大关于“全面实施绩效管理”的决策部署，切实提高财政资金使用效益，请你局在组织预算执行中对照绩效目标(附件1)做好绩效监控，确保年度绩效目标如期实现。同时，请你局将我市绩效目标及时分解，做好预算绩效管理工作。
