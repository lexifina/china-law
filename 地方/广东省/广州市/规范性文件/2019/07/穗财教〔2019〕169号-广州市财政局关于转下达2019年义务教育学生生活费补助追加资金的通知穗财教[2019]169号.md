# 广州市财政局关于转下达2019年义务教育学生生活费补助追加资金的通知穗财教[2019]169号

穗财教〔2019〕169号

广州市财政局关于转下达2019年义务教育学生生活费补助追加资金的通知

天河、白云、黄埔、花都、番禺、南沙、从化、增城区财政局：

省财政厅发来《关于下达2019年义务教育学生生活费补助追加资金的通知》(粤财科教〔2019〕45号，见附件)，现将2019年义务教育学生生活费补助追加中央资金226万元转下达给你们，并相应调减省级资金226万元。该资金收入列2019年“1100245教育共同财政事权转移支付收入”科目，支出列2019年“20502普通教育”相关科目。

请各单位严格按照粤财科教〔2019〕45号的规定做好相关工作，加强资金监管，确保专款专用。
