# 广州市财政局关于转清算下达2019年城乡义务教育公用经费补助资金的通知穗财教[2019]170号

穗财教〔2019〕170号

广州市财政局关于转清算下达2019年城乡义务教育公用经费补助资金的通知

市教育局，各区财政局：

省财政厅发来《关于清算下达2019年城乡义务教育公用经费补助资金的通知》(粤财科教〔2019〕44号，见附件)，现将2019年城乡义务教育公用经费补助资金18110万元(其中中央资金9058万元、省级资金9052万元)转下达给你们，该项资金收入列2019年“1100245教育共同财政事权转移支付收入”，支出列2019年“20502普通教育”相关项。

请市教育局对省下达给我市市本级的省级资金965万元进一步细化，于6月24日前将细化分配方案报我局，并一并明确预算支出经济分类。请各单位严格按照粤财科教〔2019〕44号文的规定做好相关工作，加强资金监管，确保专款专用。
