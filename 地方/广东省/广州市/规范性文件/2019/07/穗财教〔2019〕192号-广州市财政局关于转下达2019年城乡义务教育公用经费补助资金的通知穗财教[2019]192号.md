# 广州市财政局关于转下达2019年城乡义务教育公用经费补助资金的通知穗财教[2019]192号

穗财教〔2019〕192号

广州市财政局关于转下达2019年城乡义务教育公用经费补助资金的通知

越秀、天河、南沙区财政局：

根据省财政厅《关于清算下达2019年城乡义务教育公用经费补助资金的通知》(粤财科教〔2019〕44号)和市教育局分配方案，现将2019年城乡义务教育公用经费补助资金965万元转下达给你们(具体见附件)。

请按照粤财科教〔2019〕44号文的要求推进预算执行，加强资金监管，确保专款专用。
