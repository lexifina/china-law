# 关于取消广州良田肥业有限公司广州市商品有机肥购置补贴供货资格的通知

关于取消广州良田肥业有限公司广州市商品有机肥购置补贴供货企业资格的通知

各区农业农村行政主管部门、各有关单位：

鉴于白云区农业农村局近日对我市商品有机肥供货企业广州良田肥业有限公司作出了行政处罚（穗云农（肥料）罚﹝2019﹞2号），根据《广州市商品有机肥购置补贴实施方案（试行）》（穗农﹝2018﹞210号）规定，现决定取消广州市商品有机肥购置补贴供货企业资格。

特此通知。

广州市农业农村局

2019年8月15日
