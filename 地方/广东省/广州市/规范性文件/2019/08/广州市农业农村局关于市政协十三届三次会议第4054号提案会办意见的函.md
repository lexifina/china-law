# 广州市农业农村局关于市政协十三届三次会议第4054号提案会办意见的函

广州市文化广电旅游局：

根据《广州市文化广电旅游局关于印发市政协十三届三次会议第4054号提案办理工作方案的函》（穗文广旅函〔2019〕1180号）要求，现函告我局会办意见如下：

一、改善乡村发展环境

全市76．66％的行政村达到省定干净整洁村标准，其中地处北回归线沿线的从化区率先实现100％的行政村达到干净整洁村标准。将从化区的良口镇、吕田镇，增城区的派潭镇、小楼镇，花都区的梯面镇等5个镇以及从化、增城、花都3个区的75条行政村纳入省级生态宜居美丽乡村示范镇、示范村创建工作计划，推动北回归线沿线乡村人居环境整治向高质量、高水平方向发展。开展2019年度新型职业农民培育工作。全市共资助农村户籍劳动者技能培训5046人次。

二、推进粤港澳大湾区“菜篮子”建设

开展粤港澳大湾区“菜篮子”平台建设，与香港、澳门签署了粤港澳大湾区“菜篮子”穗港、穗澳联席会议合作机制框架协议等重要文件，与粤港澳大湾区城市、泛珠三角城市及内地城市共36个地级市签署了城际合作联席会议框架协议，规划建设集展贸交易、检验、检疫、通关为一体“一站式”服务的“菜篮子”产品配送中心8个。

三、积极创建现代农业产业园

组织各区积极开展省级、市级现代农业产业园创建工作，目前全市已获省农业农村厅批准创建7个省级现代农业产业园；产业园规划面积共计17万亩，主要建设实施主体41家，预计今明两年投资13亿元。制定《广州市现代农业产业园财政补助资金安排方案》，对除黄埔、南沙、增城以外各区创建的国家级、省级现代农业产业园分别补助1亿元、5000万元。建立资金管理机制，起草《广州市现代农业产业园财政补助资金管理暂行办法》初稿并征求市财政局和各区政府意见。

四、大力培育农业品牌

指导支持农业生产经营单位创立品牌、培育品牌、建设名牌。扎实做好广东省名牌产品（农业类）年度初评复审组织、推荐、指导工作。截至目前，有效期内广东省名牌产品（农业类）163个，数量居全省首位，其中10个产品获评广东省“十大名牌”系列农产品；拥有广东省名特优新农产品109个，其中区域公用品牌22个，经营专用品牌87个；2家企业被评为省十佳“最美农电商”。

五、发展休闲观光农业

目前全市观光休闲农业经营主体将近1800家，市级农业公园20家，省级农业公园1家。截至2018年底，我市共成功创建全国休闲农业和乡村旅游示范县2个、全国休闲农业与乡村旅游示范点1个、省级休闲农业与乡村旅游示范镇5个、省级休闲农业与乡村旅游示范点17个。

以上意见可主动公开。

广州市农业农村局
