# 广州市农业农村局关于政协十三届广州市委员会第三次会议第2032号提案答复的函

崔虹代表：

您提出的《关于大力发展空港农业，振兴乡村特色经济的建议》（第2032号）收悉，这个建议很有前瞻性，市政府高度重视，积极组织我局及其他市直有关部门进行认真研究办理，并与您在8月7日进行了座谈交流，现将办理有关情况答复如下：

一、加强农业基础设施建设和耕地保护，为发展空港农业奠定坚实基础

市政府一直高度重视农业基础设施建设和耕地保护，大力扶持农田水利等基础设施建设，划定粮食生产功能区，落实耕地地力补贴，不断改善农业生产资源和条件。积极整合农田建设资金用于高标准农田建设，2019－2020年度高标准农田建设标准提高至4000元/亩，其中省级财政补助资金1500元/亩，市级财政配套资金2500元/亩。认真落实《广州市农田鱼塘基本建设工作实施方案》，2016－2018年，市级财政共安排3．49亿元补助基本农田建设，全市共完成农田基本建设任务8．94万亩，农田实现了渠相通、路相连、旱能灌、涝能排，综合生产能力大幅度提升。2018年全市划定粮食生产功能区面积41．59万亩，超额完成省级下达任务。落实耕地地力补贴政策，印发《关于做好2019年中央财政耕地地力补贴资金发放工作的通知》，今年我市耕地地力补贴面积预计为141．5万亩。

下一步我市将全力整合高标准农田建设、农田基本建设、高效节水等项目，重点在土地平整、土壤改良、灌溉排水、田间道路、农田防护与生态环境保护、农田输配电和建后管护等方面加大建设管理力度，进一步提高耕地地力和质量。

二、发展现代农业，为打造空港农业平台创造良好条件

当前，市政府紧紧围绕实施乡村产业振兴战略和“粤港澳大湾区”建设，深入推进农业供给侧结构性改革，推进现代农业产业体系、生产体系和经营体系建设，为打造空港平台创造良好条件。

一是全力推进“粤港澳大湾区‘菜篮子’”建设。制定印发《粤港澳大湾区“菜篮子”建设实施方案》和《广州市关于支持“粤港澳大湾区‘菜篮子’”建设的若干意见》。加快推进粤港澳大湾区“菜篮子”广州配送中心建设，举行粤港澳大湾区“菜篮子”建设启动大会，签署穗港、穗澳联席会议合作机制框架协议等重要文件，正式推出以供港澳的质量安全标准为标杆的农产品平台，提升我市现代农业发展水平。

二是积极创建现代农业产业园。制定印发《广州市现代农业产业园建设实施方案（2018－2020年）》，围绕“主导产业突出、现代要素集聚、设施装备先进、生产方式绿色、辐射带动有力”要求，组织实施以优质蔬菜、岭南水果、花卉、水产、畜牧等为主导产业的产业园创建活动，促进农业生产、加工、物流、研发、示范、服务等相互融合和全产业链开发，打造高起点、高标准的现代农业发展先行区，引领带动全市现代农业加速提质增效。目前，全市已有7个现代农业产业园列入省级现代农业产业园建设名单，市级现代农业产业园正在组织申报和评审中。

三是大力培育优质特色农产品品牌。积极引导、支持新型农业经营主体创立品牌，发展名牌产品。2018年我市有效期内省名牌产品（农业类）达163个，数量创历史新高，位居全省首位，其中9个产品获评广东省“十大名牌”系列农产品；拥有广东省名特优新农产品109个，其中区域公用品牌22个，经营专用品牌87个。

下一步，我市将进一步加快粤港澳大湾区“菜篮子”建设，进一步督促指导各区积极创建现代农业产业园，在资金和用地方面大力支持粤港澳大湾区“菜篮子”基地和现代农业产业园建设，支持我市优质特色农产品品牌化发展，为打造空港农业平台创造良好条件。

三、充分利用优势，打造空港农业平台

空港是我市对外窗口，是得天独厚的展销展示平台。下一步我局将按照您的建议，进一步挖掘空港优势，充分发挥我市现代农业发展优势和优质特色农产品品牌优势，打造空港农业平台。

一是打造空港农业品牌。依托空港区位优势，以现代农业产业园区为支撑、企业为引领、合作社为纽带，做大做强花卉、蔬菜、特色水果、优质水产品等的生产、加工、配送和服务业，进一步提升优质特色农产品品牌优势。利用已进驻空港经济区的联邦快递、顺丰速运以及苏宁、唯品会跨境电商等大型企业，向世界各地输出我市名牌农产品。鼓励广东宝桑园健康食品有限公司、广州市朱仔烧腊食品有限公司等龙头企业发展桑果汁、腊肠等航空食品，宣传我市优质农产品加工食品。

二是发展空港农业展销平台。利用空港经济区会展中心平台，通过举办农业博览会、农产品展销等活动，搭建经贸合作平台，鼓励我市农业龙头企业参加重大博览会和各类交流活动，支持农业企业走出去，在更高层次、更大范围参与国际国内经贸合作和产品展示展销，宣传推介名特优新农产品，提高国内外对广州农产品品牌的认知和信赖。如今年6月23日，“增城荔枝世界畅享——2019增城荔枝推介会”在广州白云国际机场举办，增城挂绿、水晶球、仙进奉、北园绿、甜岩、桂味、糯米糍、紫娘喜、红绣球等9款增城名优荔枝在机场华丽展出，向来往旅客展示增城荔枝和荔枝文化，收到不同凡响的效果。

三是打造空港休闲农业带。启动广州市现代农业产业布局规划编制工作，有效形成对我市主要涉农区的整体规划，实现近、中、远郊圈层差异化布局，大力发展都市休闲农业，打造集休闲、旅游、农趣体验、科普、康养、乡村民宿于一体的个性化农业主题公园。以流溪河为纽带，依托区域内农业公园、现代化农业生产基地等资源，打造休闲农业功能区。

感谢您对我市农业产业发展工作的关心和支持，欢迎您继续对我们的工作提出宝贵意见和建议。

广州市农业农村局
