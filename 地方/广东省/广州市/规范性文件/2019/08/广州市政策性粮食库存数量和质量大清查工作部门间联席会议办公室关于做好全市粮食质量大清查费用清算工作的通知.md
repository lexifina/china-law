# 广州市政策性粮食库存数量和质量大清查工作部门间联席会议办公室关于做好全市粮食质量大清查费用清算工作的通知

各区大清查办，市穗粮粮油产品质量检测中心有限公司：

根据《广东省粮食和储备局关于做好全省粮食质量大清查费用清算工作的通知》（粤粮监〔2019〕185号）要求，为做好我市政策性粮食质量大清查费用清算工作，现就有关事项通知如下：

一、样品数量

全市纳入2019年政策性粮食质量大清查的样品共490份，其中市本级341份，区级149份；稻谷350份（市本级288份，区级62份），小麦139份（市本级53份，区级86份），玉米1份。具体样品分布情况详见附件1。

二、费用标准

根据《广东省粮食和物资储备局关于印发广东省政策性粮食大清查质量检查实施方案的通知》（粤粮监〔2019〕48号）要求，大清查扦样及检验费用按照《关于进一步规范粮食质量安全抽检费用等有关事项的通知》（粤粮监〔2017〕103号）有关标准执行，具体为：样品扦样费200元/份；部分项目检验费为400元/份；全项目检验费稻谷1165元/份，小麦1590元/份。部分项目指仅检验质量指标，全项目指同时检验质量和食品安全指标。各粮权单位对应检查费用明细详见附件2。

三、清算方式

根据《广州市政策性粮食库存数量和质量大清查工作部门间联席会议办公室关于印发2019年广州市政策性粮食大清查质量检查实施方案的通知》（穗发改〔2019〕188号）规定，扦样费和检验费按粮权性质，由市、区两级大清查办分别承担并支付。

（一）扦样费的支付方式。市辖区内政策性粮食的扦样费，支付给市穗粮粮油产品质量检测中心有限公司（广州监测站）；跨市储存政策性粮食的扦样费，支付给当地大清查办。具体支付方式由粮权单位与对应扦样单位商定。

（二）检验费的支付方式。市辖区内政策性粮食的检验费，支付给省粮食科学研究所（省监测中心）；跨市储存政策性粮食的检验费，支付给省粮食和物资储备局在《关于全省政策性粮食大清查质量检查有关事宜的补充通知》（粤粮办监〔2019〕62号）中指定的检验单位。具体支付方式由粮权单位与对应检验单位商定。
