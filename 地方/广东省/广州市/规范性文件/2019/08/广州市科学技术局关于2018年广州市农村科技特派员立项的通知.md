# 广州市科学技术局关于2018年广州市农村科技特派员立项的通知

各有关单位：

根据《广州市科技创新委员会关于印发推进农村科技特派员工作实施方案(2018-2020年)的通知》(穗科创字〔2018〕384号)文件要求，现对2018年广州市农村科技特派员20个立项项目通知如下，立项名单见附件。

2018年农村科技特派员项目实施期2年(具体起止时间以合同签订时间为准)。农村科技特派员要严格落实《广州市农村科技特派员申请表》中相关内容，紧密围绕农业科技需求方农业主导产业进行工作。要因地制宜为农业科技需求方健康快速发展提供新技术、新品种等服务，逐渐增加农业主导产业的科技含量，不断提高科技对农业经济的贡献份额，努力实现农业增效、农民增收和农村发展。

农村科技特派员所在单位要严格落实省市关于推进科技特派员制度的相关规定，主动指导和帮助科技特派员围绕技术需求方的需求，发挥单位科技人才、团队和平台的支撑作用，推动农业先进实用技术的推广和应用;指导科技特派员合理使用资金，并加强监督管理。

特此通知。
