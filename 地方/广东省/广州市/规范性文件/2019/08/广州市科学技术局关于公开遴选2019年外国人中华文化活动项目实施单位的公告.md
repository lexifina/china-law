# 广州市科学技术局关于公开遴选2019年外国人中华文化活动项目实施单位的公告

我局拟公开遴选一个单位开展“2019年外国人中华文化活动”项目工作。现将有关事项公告如下：

一、本项目征集起始日期

2019年8月19日至8月23日(5个工作日)。

二、承担单位的资质和业务要求

(一)在广州市内依法注册设立的具有独立法人资格的人力资源相关行业国有企业单位;

(二)具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

(三)有符合要求的固定办公场所，具有可承担50人以上活动的场地，有稳定的公共服务活动策划组织队伍以及较为完善的服务机制，工作人员具有相应的外语水平。优先选择具有政府公共服务活动组织经验的单位;

(四)本项目不接受联合体报名。

三、项目内容及要求

委托事项内容：委托举办2019年外国人中华文化活动项目。受委托方需根据有关要求组织2018年以来新来穗工作(持外国人工作许可证)人员参加活动，主要工作内容包括但不仅限于：

(一)策划组织外国人文化活动

策划组织外国人中华文化活动，活动内容包括外国人来华工作应知应会的法律法规宣传、中华传统文化、岭南文化、在穗工作生活资讯等，力求使参训的外国人通过活动了解在穗相关信息，帮助其加快融入本地工作环境，提高生活工作便利性，并感受岭南文化内涵与魅力，进一步提升广州城市文化形象和国际人才包容度。

(二)开展活动的宣传发动和组织工作

做好文化活动的全市宣传发布工作，共组织6期活动(至少600人次参加)，严格按照有关要求标准和活动方案执行各项活动安排，并配合广州市科技局做好对外宣传工作。

(三)做好活动全程管理及记录

做好活动的全程跟进及管理，并进行活动摄影等档案记录工作，及时将活动情况反馈，并做好项目的实施效果评估工作。

四、项目完成时间

2019年12月31日前。

五、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

(一)单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)完成同类项目证明，以及能证明本单位实力或能胜任本项工作内容的相关证明材料;

(四)项目实施方案，包括项目进度安排、预算明细等;

(五)其他可以佐证机构专业能力、资质、相关工作经验、业绩等情况的材料。

六、费用预算

人民币15万元以内。

七、申请书提交时间、地址

以上书面材料(一式五份含电子光盘一份)密封后，请于2019年8月23日17:30前交至广州市科学技术局专家服务处512室。逾期不予受理。

八、咨询电话

黄琼，020-83124159(工作日8:30-12:00、14:00-17:30)

九、择优遴选

我局将组成内部评标工作组择优遴选本项目最终承担单位，与其协商拟定正式委托合同。
