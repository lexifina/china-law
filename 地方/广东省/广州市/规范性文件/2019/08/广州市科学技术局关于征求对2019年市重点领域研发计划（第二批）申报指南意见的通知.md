# 广州市科学技术局关于征求对2019年市重点领域研发计划(第二批)申报指南意见的通知

( )

各有关单位：

为做好2019年度广州市重点领域研发计划申报工作，现面向社会公开征求对2019年广州市重点领域研发计划(第二批)申报指南的意见。

任何单位或个人有意见建议，可于2019年8月19日前提出书面意见，并加盖单位公章或签署真实姓名，注明有效联系方式。受理地址：广州市越秀区府前路1号广州市科学技术局高新技术处，邮政编码：510032。
