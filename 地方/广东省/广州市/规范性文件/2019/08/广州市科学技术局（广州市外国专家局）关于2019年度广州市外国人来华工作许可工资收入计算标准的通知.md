# 广州市科学技术局(广州市外国专家局)关于2019年度广州市外国人来华工作许可工资收入计算标准的通知

各用人单位：

按照《国家外国专家局 人力资源社会保障部 外交部 公安部关于全面实施外国人来华工作许可制度的通知》(外专发〔2017〕40号)规定，申请办理外国人来华工作许可时，申请人平均工资收入不低于本地区上年度社会平均工资收入6倍的外籍人才符合A类外国高端人才认定标准;申请人平均工资收入不低于本地区上年度社会平均工资收入4倍的外籍人才符合B类外国专业人才认定标准。

根据广州市统计局发布的《2018年广州市城镇非私营和私营单位就业人员年平均工资情况》，广州市2018年城镇非私营单位就业人员年平均工资109879元，折算为城镇非私营单位就业人员月平均工资为9157元。据此，自本通知发布之日起至2020年6月30日止，广州市外国人来华工作许可工资收入计算标准为：109879元/年，9157元/月。

特此通知。

广州市科学技术局
