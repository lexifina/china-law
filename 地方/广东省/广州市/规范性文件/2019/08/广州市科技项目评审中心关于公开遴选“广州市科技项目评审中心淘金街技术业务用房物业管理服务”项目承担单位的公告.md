# 广州市科技项目评审中心关于公开遴选“广州市科技项目评审中心淘金街技术业务用房物业管理服务”项目承担单位的公告

( )

我中心拟公开遴选一家具有物业管理服务资质的实施单位承担“广州市科技项目评审中心淘金街技术业务用房物业管理服务”项目工作。现将有关事项公告如下：

一、本项目征集起始日期

2019年8月20日至8月26日(5个工作日)。

二、承担单位资质

1. 符合《中华人民共和国政府采购法》第二十二条的规定;

2. 必须具有独立承担民事责任能力，并在中华人民共和国境内注册的法人;

3. 在“信用中国”网站(www.creditchina.gov.cn)、中国政府采购网(www.ccgp.gov.cn)相关主体信用记录中未被列入失信被执行人、重大税收违法案件当事人名单、政府采购严重违法失信行为记录名单;

4. 具有物业管理服务相应资质及同类项目经验;

5. 具备履行合同所必需的设备和专业技术能力;

6. 本项目不接受联合体报名。

三、项目内容及要求

负责对淘金街技术业务用房(地址：广州市越秀区淘金街4号一、二楼，建筑面积：790.81平方米)实施物业综合管理，包括入驻前精开荒服务、安全保卫、卫生保洁、设备维护管理等，具体要求见《广州市科技项目评审中心物业管理服务采购需求》(详见附件1)。

项目进场时间为2019年9月，服务期限为一年。

四、需提交的材料

有意参与本项工作的单位需提交申请书并附以下材料：

(一)申请单位基本情况表(原件盖章，见附件2);

(二)项目实施方案(原件盖章，见附件3);

(三)营业执照副本或登记证书(复印件盖章);

(四)证明本单位实力或能胜任本项工作内容的相关证明材料，包括但不限于企业资质证书、管理体系认证证书、企业荣誉证书、同类项目经验文件等。

五、预算金额

人民币280000元以内。

六、申请书提交时间和地址

以上书面材料(一式七份及电子光盘一份)密封并加盖骑缝章，请于2019年8月26日17:30前交至广州市科技项目评审中心综合部(广州市越秀区连新路47号一楼)，逾期不予受理。

七、咨询电话

姚娃丽，020-83577101(工作日8:30-12:00、14:00-17:30)

八、我中心将按内部遴选办法确定本项目最终承担单位，并与其商议签订正式委托合同。
