# 广州市农业农村局关于印发广州市现代化生猪养殖推进计划的通知

穗农〔2019〕128号

广州市农业农村局关于印发广州市现代化生猪养殖推进计划的通知

各区人民政府，市发展改革委、财政局、规划和自然资源局、生态环境局、水务局、市场监管局、林业园林局，广州供电局有限公司：

经市人民政府同意，现将《广州市现代化生猪养殖推进计划》印发给你们，请认真贯彻执行。执行过程中遇到问题，请径向我局反映。

广州市农业农村局

2019年8月6日

广州市现代化生猪养殖推进计划

为大力推进现代化生猪养殖发展，推动生猪养殖高质量发展，贯彻落实《广东省生猪生产发展总体规划和区域布局（2018－2020年）》（粤农农〔2019〕185号）的规划目标，落实“菜篮子”市长负责制考核有关生猪考核任务，制定本计划。

一、发展目标

按照“政府引导，企业运作”的原则，鼓励支持先进生产设施设备的推广应用，优化调整生猪养殖结构，积极发展环境友好、健康生态的生猪养殖基地。通过新、改、扩建等方式推进生猪养殖转型升级，推进生猪养殖现代化、生态化绿色健康发展。2020年全市年出栏生猪不少于30万头，2025年“菜篮子”生猪养殖基地年出栏规模目标不少于45万头。具体任务分配见下表：

二、建设标准

为强化非洲猪瘟防控和防范规模养殖对周边环境带来的影响，鼓励支持“菜篮子”生猪养殖基地按美丽牧场建设标准（详见附件）为参考，高标准、现代化、生态化建设，带动畜禽养殖绿色循环发展。基地建设应采用封闭式饲养方式，实现场区环境清洁、绿化美化，营造清洁生产、美丽宜居的良好生产经营环境，引领示范我市畜禽养殖现代化、生态化发展。粪污收集处理应实施雨污分流，固体粪便采用生产有机肥、液体粪污采用沼气池等厌氧处理、沼液还田利用等方式实现粪污全量收集利用，并采用安装净化装置或“除臭网＋微生物菌”等方式对臭气进行收集处理，减少臭气排放，减少环境影响。

三、保障措施

（一）加强组织领导。各区政府是“菜篮子”生猪养殖基地建设的落实主体，要切实加强组织领导，严格落实“菜篮子”市长负责制，做好“菜篮子”生猪养殖基地的投资主体落实和具体名单的确定，组织区发展改革、财政、规划和自然资源、生态环境、水务、农业农村、市场监管、林业、电力等部门，建立由区领导为召集人的协调机制，简化优化审批手续，压缩审批时间，优先审批办理，为“菜篮子”生猪养殖基地建设的审批手续办理等提供全程指导服务，确保养殖场建设顺利推进、快速见效。

各有关区政府应对标“菜篮子”生猪养殖基地年出栏规模目标任务和基地数量要求，结合本地实际，于本计划印发之日起15个工作日内将“菜篮子”生猪养殖基地项目名称、项目投资主体、项目具体地址、养殖规模以及具体时间节点计划等送市农业农村局。

（二）做好选址指导服务。区农业农村部门、镇（街）要加强“菜篮子”生猪养殖基地选址指导服务，引导企业科学选址。对企业提出选址咨询需求的，区农业农村部门应当会同规划和自然资源、生态环境、林业、水务等相关部门对选址的合法性、合规性给予指导服务。同时，做好动物防疫条件审查的指导服务，优先办理、快速审批。

（三）优先用地审批。规划和自然资源部门要加大“菜篮子”生猪养殖基地用地支持力度，要按照年出栏规模每1万头不少于50亩用地的标准，规划保障养殖用地需求。同时，做好设施农用地备案指导服务工作，优先办理，快速备案审批。对养殖场建设确需配套建设用地、或需在场区外建设大型沼气工程、有机肥厂等专业粪污处理场所的建设用地给予重点支持、优先安排。涉及占用林地的，林业部门要优先办理林地使用审批手续。“菜篮子”生猪养殖基地涉及的建设用地指标，纳入市年度土地利用计划中统筹安排；涉及的林地占用使用指标由林业部门统筹安排，优先审核审批。

（四）加强环境保护手续办理指导服务。生态环境部门要加强对“菜篮子”生猪养殖基地配套污染防治设施建设和环保审批手续办理的指导服务，对涉及的环评、污染防治设施竣工验收和排污许可等环保手续优先办理、快速审批。

（五）加大财政资金扶持力度。进一步加大涉农资金统筹整合力度，支持鼓励“菜篮子”生猪养殖基地现代化建设。对完成建设并投产的，经企业申请、市级农业技术推广机构组织验收，符合建设标准的，市级财政给予一次性奖励。奖励标准以栏舍面积为计算依据，每1000平方米为一档次，每平方米给予一次性奖励200元，栏舍面积达到1000平方米（含1000平方米）不超过2000平方米的，按1000平方米计算，以此类推。其他畜禽养殖场达到现代化美丽牧场标准的，可参照给予奖励。具体实施方案由市农业农村局会同市财政局另行制定。
