# 广州市住房和城乡建设局关于印发《广州市物业服务行业生活垃圾分类专项行动计划》的通知

各区住建局、越秀区房管局，市物业管理行业协会，各物业服务企业：

为推进我市物业服务行业生活垃圾分类工作，根据广州市生活垃圾分类管理联席会议办公室《关于进一步强化重点行业领域生活垃圾分类工作推进方案》的要求，现将《广州市物业服务行业生活垃圾分类专项行动计划》印发给你们，请认真贯彻落实。

专此通知。

广州市住房和城乡建设局

2019年8月23日
