# 广州市住房和城乡建设局关于进一步推进工程建设领域专业技术人员违法违规“挂证”行为专项整治工作的通知

各区住建局、各有关单位：

根据《广东省住房和城乡建设厅广东省人力资源和社会保障厅广东省交通运输厅广东省水利厅广东省通信管理局转发住房城乡建设部办公厅等关于开展工程建设领域专业技术人员职业资格“挂证”等违法违规行为专项整治的通知》（粤建市〔2018〕259号）、《广东省住房和城乡建设厅转发住房和城乡建设部办公厅关于做好工程建设领域专业技术人员职业资格“挂证”等违法违规行为专项整治工作的补充通知》（粤建市函〔2019〕497号）、《广东省住房和城乡建设厅关于全面排查处理工程建设领域专业技术人员违法违规“挂证”行为的通知》（粤建市函〔2019〕754号）要求，为切实推进我市工程建设领域专业技术人员违法违规“挂证”行为专项整治工作，及时总结我市专项整治工作全面排查情况，现提出如下工作要求：

一、各区住建局应积极推进专项整治全面排查工作，梳理排查存疑数据，主动核实清理不实信息，并及时总结全面排查情况，将拒不整改、必须进行行政处罚的违法违规“挂证”行为（含违法违规挂证人员信息、注册单位信息、违法违规事实、处罚建议）逐一梳理汇总，一并于8月26日前报送我局，由我局统一汇总后上报省住房城乡建设厅。

二、各有关企业、人员应高度重视工程建设领域专业技术人员违法违规“挂证”整治工作，积极主动配合“挂证”存疑数据核实工作。部分存在“挂证”行为的企业、注册人员要认清形势，克服观望等待的侥幸心理，主动及时整改，以免受到相应处罚。截止至2019年8月12日，我市仍有635名涉嫌挂证人员、企业未通过“三库一平台”的“挂证”专项整治系统（（网址：http：//113．108．219．40/RegDup）配合上报核实信息，相应名单详见附件。
