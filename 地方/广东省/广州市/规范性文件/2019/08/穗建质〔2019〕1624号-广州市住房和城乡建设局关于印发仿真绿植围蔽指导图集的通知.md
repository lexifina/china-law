# 广州市住房和城乡建设局关于印发仿真绿植围蔽指导图集的通知

各区住建局（含广州空港经济区）、各有关单位：

为进一步提升我市建筑施工围蔽水平，加强施工精细化、标准化管理，我局在《广州市建设工程绿色施工围蔽指导图集（V1．0试行版）》《广州市建设工程绿色施工围蔽指导图集补充（V1．1版）》的基础上，增补了《广州市建设工程绿色施工围蔽指导图集补充——仿真绿植围蔽》，作为装配式轻钢结构围蔽、立体绿化围蔽等的补充。现将该图集印发你们，请结合实际选择使用。各单位在执行中遇到问题或有好的建议，请及时反馈我局。

广州市住房和城乡建设局

2019年8月17日
