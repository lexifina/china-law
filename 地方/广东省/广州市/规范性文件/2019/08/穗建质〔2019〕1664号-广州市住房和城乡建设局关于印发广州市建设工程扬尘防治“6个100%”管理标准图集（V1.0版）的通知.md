# 广州市住房和城乡建设局关于印发广州市建设工程扬尘防治“6个100%”管理标准图集（V1.0版）的通知

各区（含广州空港经济区）住建局、市建设工程质量监督站、各有关单位：

为加强我市建筑工地文明施工管理，切实防治施工扬尘，打赢“蓝天保卫战”，指导企业更好地落实扬尘污染防治“6个100％”管理标准，结合我局已下发的《广州市建设工程绿色施工围蔽指导图集（V1．0试行版）》《广州市建设工程绿色施工围蔽指导图集补充（V1．1版）》《广州市建设工程绿色施工围蔽指导图集补充——仿真绿植围蔽》《关于规范建筑施工立面外防护架标准的通知》《广州市建筑工地车辆冲洗设施设计图集》《关于印发建设工程扬尘防治“6个100％”管理标准细化措施的通知》等相关文件，我局组织编制了《广州市建设工程扬尘防治“6个100％”管理标准图集（V1．0版）》。现将该图集印发给你们，请认真贯彻执行。执行中遇到的问题，请径向市住房城乡建设局反映。

特此通知。

广州市住房和城乡建设局

2019年8月28日
