# 广州市住房和城乡建设局关于组织2019年广州市住房城乡建设系统“质量月”现场观摩活动的通知

各区（含广州空港经济委）住建局，市住房保障办、重点项目管理中心、中心区交通项目管理中心、建设工程质量监督站、散装水泥管理办、建筑节能墙革办、人防质监站，广州建筑集团、广环投集团、市城投集团，市建设工程各相关行业协会，各相关单位：

为深入开展工程质量安全提升行动，进一步提升工程质量安全水平，根据《广州市住房和城乡建设局关于组织开展2019年“质量月”系列活动的通知》（穗建质〔2019〕1651号），我局在4个工程项目开展“2019年广州市住房城乡建设系统‘质量月’现场观摩活动”，并定于9月10日在鱼珠国际木材市场商业改造单元—南片地块（AP0518023）项目举办“2019年广州市住房城乡建设系统‘质量月’现场观摩交流会”。现将有关要求通知如下：
