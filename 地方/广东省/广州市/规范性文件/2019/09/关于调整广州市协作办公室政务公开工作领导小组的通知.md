# 关于调整广州市协作办公室政务公开工作领导小组的通知

机关各处、国内合作服务中心：

根据国家、省、市关于全面推进政务公开工作的部署要求，参照国务院和省政府、市政府的做法，结合我办职能和人事变动情况，调整我办政务公开领导小组（以下简称“领导小组”）及组成人员。现将相关事项通知如下：

一、主要职责

领导小组主要职责包括贯彻落实党中央、国务院和省委、省政府，市委、市政府关于政务公开工作的方针政策；研究提出我办政务公开工作的政策措施和年度工作重点；协调抓好我办政务公开工作任务落实，并加强督促检查；完成党中央、国务院和省委、省政府，市委、市政府交办的其他事项。

二、工作机构

领导小组组长由分管政务公开的办领导担任。领导小组成员由机关各处处长、国内合作服务中心主任担任。领导小组下设办公室，由综合调研处承担办政务公开领导小组办公室职责，综合调研处处长主持政务公开领导小组办公室日常工作。各成员职责如下：

综合调研处：建立健全领导小组工作制度机制，做好组织协调、业务指导、保密审查、督促整改、考核评比、巡查监测、运营维护工作；制定全办政务公开工作要点和分工方案并督促落实；做好新闻发布、重大政务活动和重要措施宣传工作；指导协调机关各处、国内合作服务中心开展网络舆情引导和处置应对。

秘书处：做好一般公共预算收支执行情况公开工作和舆论处置应对工作。

联络处：做好我办权责清单、政务服务办事公开和联系管理驻穗机构的信息公开和舆论处置应对工作。

区域合作处：做好区域合作、对口支援新疆疏附、西藏波密、重庆巫山县，对口帮扶四川省甘孜州和与齐齐哈尔市对口合作工作的信息公开，配合综合调研处做好相关舆论处置应对工作。

对口支援处：做好贵州省毕节黔南东西部扶贫协作、梅州清远产业帮扶和精准帮扶的信息公开，配合综合调研处做好相关舆论处置应对工作。

展贸服务处：做好广州博览会和参会参展的信息公开和舆论处置应对工作。

组织人事处：做好单位职能、领导分工、机构设置和下属单位的信息公开工作。

国内合作服务中心：做好中心信息咨询、友城服务、驻穗机构服务的信息公开和舆论处置应对工作。

三、工作要求

（一）办机关各处、中心要主动研究政务公开工作，积极参加政务公开领导小组工作，认真落实全市政务公开工作部署。各处、中心之间要加强协调配合，形成全力，共同推进政务公开各项工作。

（二）办政务公开领导小组负责考核工作的组织领导，办政务公开领导小组办公室具体负责组织实施。根据工作需要，对各处政务公开工作进行考核评议。

（三）办政务公开领导小组不定期开展政务公开检查工作，政务公开领导小组办公室针对存在问题，及时发出督办通知书。提出具体整改意见和期限，并在期限内督促整改到位。

（四）不定期召开办政务公开领导小组办公室工作会议，学习政务公开业务文件，领会文件精神，及时安排工作，处理日常事务。会同有关处室，及时协调处理群众对政务公开的意见和建议。
