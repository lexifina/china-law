# 广州市农业农村局关于印发2019年广州市财政农机购置补贴机具补贴额一览表（第二批）的通知

各区农业农村主管部门，番禺区农业技术推广管理办公室：

根据《广东省农业农村厅关于印发〈广东省2019年农机购置补贴机具补贴额一览表〉（第二批）的通知》（粤农农函〔2019〕1425号）和《广州市农业农村局广州市财政局关于印发〈广州市财政农机购置补贴实施方案〉的通知》（穗农〔2019〕14号）的要求，结合我市农业生产实际，我局编制了《2019年广州市财政农机购置补贴机具补贴额一览表》（第二批），现印发给你们，请结合实际贯彻执行。

广州市农业农村局

2019年8月23日
