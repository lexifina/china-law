# 广州市卫生健康委关于进一步做好医疗技术临床应用管理的通知

各区卫生健康局，广州地区各有关医疗机构：

现将《广东省卫生健康委关于印发<广东省卫生健康委员会关于医疗技术临床应用管理的实施细则（试行）>的通知》（粤卫规〔2019〕10号，附件1）转发你们，请认真组织学习，完善管理制度，依法加强管理，并就备案管理具体事项提出以下要求，请一并执行。

一、开展范围

广州地区省部属医疗机构、市发证管理医疗机构、各区发证管理医疗机构，分别由实际核发《医疗机构执业许可证》的卫生健康行政部门实施备案。中医医疗机构医疗技术临床应用管理按照省中医药局安排另行通知。

二、备案步骤

（一）自我评估判定。

开展限制类技术的医疗机构，按照国家卫生健康委和省发布的医疗技术临床应用管理规范，从机构、人员、技术和管理等方面的基本要求进行自我评估。医疗机构根据评估结果进行自我判定，不符合条件的不能开展临床应用，符合条件的可以开展，并按规定程序备案。

（二）提交备案材料。

医疗机构开展首例限制类技术临床应用之日起15个工作日内，按要求提交备案材料。2019年8月1日前，根据《广州市卫生计生委转发广东省卫生计生委关于组织开展医疗技术临床应用事中事后监管政策试点工作的实施方案的通知》（穗卫函〔2017〕1355号）要求，完成限制类技术备案的医疗机构应当重新备案。备案材料内容详见《广州市卫生健康委限制类医疗技术备案材料要求》（附件3）。

市卫生健康委发证医疗机构的备案材料，请送我委医政医管处，同时报送纸质版和扫描电子版。地址：广州市越秀区农林下路竹丝岗四马路12号1202室。

（三）完成备案登记。

备案部门收到备案材料后，对材料的完整性进行形式审查。材料不完整的，通知医疗机构补充完整后再次提交备案。材料完整的，于15个工作日内通知医疗机构持《医疗机构执业许可证》副本，在“备注”栏予以注明，加盖公章，并在医疗机构联网管理系统上登记，完成备案。

三、加强台账管理

各区卫生健康局要建立限制类医疗技术备案管理台账，在每个季度的最后一个月30日前，要将辖区内已办理备案的医疗机构及备案技术清单（附件4）上报我委医政医管处邮箱，我委汇总后定期报送省卫生健康委。医疗机构完成备案后需要在国家和省级信息平台填报备案和技术应用管理情况，具体要求另行通知。
