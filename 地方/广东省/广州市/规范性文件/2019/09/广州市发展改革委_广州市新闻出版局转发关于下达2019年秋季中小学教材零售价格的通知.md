# 广州市发展改革委_广州市新闻出版局转发关于下达2019年秋季中小学教材零售价格的通知

一、请市教育局将本通知转发至市属中小学校；各区价格主管部门、新闻出版部门负责将本通知转发至各辖区内所属中小学，并公布价格举报电话，接受社会监督。

二、凡未经省发展改革委核定零售价格的教材或在教材上未注有省发展改革委批准文号的，学生和家长有权拒绝订购。

三、《2019年秋季广东省中小学教材零售价格表》可在“广州市发展和改革委员会门户网站/政民互动/价费查询/教育收费”中查询。
