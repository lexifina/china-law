# 广州市发展改革委关于印发广州市粮食和物资储备系统安全生产大检查工作方案的通知

各区发展改革局，市粮食集团，各物资承储企业：

根据9月2日上午全省粮食物资系统安全生产工作视频会议精神，结合我市实际，我委制定了《广州市粮食和物资储备系统安全生产大检查工作方案》，现印发给你们，请认真贯彻执行。

广州市发展和改革委员会

2019年9月10日
