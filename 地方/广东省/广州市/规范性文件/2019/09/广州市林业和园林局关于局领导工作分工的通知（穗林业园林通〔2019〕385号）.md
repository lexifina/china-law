# 广州市林业和园林局关于局领导工作分工的通知（穗林业园林通〔2019〕385号）

广州市林业和园林局关于局领导工作分工的通知

局属各单位、机关各处室：

根据机构调整和工作需要，经党组会议研究决定，现将局领导工作分工通知如下：

杨国权 党组书记、局长：主持局党政全面工作。

吴 敏 党组成员、副局长：负责园林工程、招投标、绿化管理、义务植树、绿道建设、安全、财务管理工作。负责局主要领导交办的其他工作事项。分管园林工程处、绿化管理处（广州地区绿化委员会办公室、绿道建设管理办公室)，市林业和园林绿化工程建设中心。

陈 迅 党组成员、副局长：负责公园（风景区）、自然保护区、湿地建设保护、野生动植物保护、森林公安、人事、统战、离退休干部管理服务工作。负责局主要领导交办的其他工作事项。分管野生动植物保护处、自然保护地管理处、公园管理处、人事处，白云山管理局、市公安局森林分局、帽峰山景区管理中心（帽峰山林场）、广州动物园、越秀公园、流花湖公园、中山纪念堂管理中心、珠江公园、市儿童公园、市野生动植物保护管理办公室（市自然保护区管理办公室、野生动物救护中心）、市海洋与渔业保护站。

詹宇扬 党组成员、副局长：负责营造林、林政资源、林权、林业有害生物防控、信访、提案议案办理、服务监督、社会综合治理、社会联动服务、改革和产业发展工作。负责局主要领导交办的其他工作事项。分管营造林管理处、森林资源管理处、服务监督处，石门国家森林公园管理中心（大岭山林场）、白水山森林公园管理中心（增城林场）、流溪河国家森林公园管理中心（流溪河林场）、白江湖森林公园管理中心（梳脑林场）、市林业和园林有害生物防治检疫管理办公室。

粟 娟 总工程师：负责规划设计调研、科技研究推广、信息化建设、网络安全、政策法规、行政执法监督、行政许可、行政执法、行政审批工作。负责局主要领导交办的其他工作事项。分管政策法规处（审批管理处）、规划设计处、科技处，市林业和园林科学研究院（市林业和园林科技推广中心）。

许先云 巡视员：负责办公事务、党建、计划生育、保密档案、政务公开、网站平台、爱国卫生、宣传教育、意识形态、中心组学习、精神文明建设工作。负责局主要领导交办的其他工作事项。分管办公室、机关党委，局机关服务中心。

梁湛涛 副巡视员：分管深化改革、产业发展、对口扶贫、工会、妇联、团委工作。负责局主要领导交办的其他工作事项。具体分管改革和产业发展处。协助詹宇扬同志工作。

梅先清 副巡视员：分管安全生产、保卫、平安创建、应急管理、反恐维稳、消防、森林防火、党风廉政建设工作。负责局主要领导交办的其他工作事项。具体分管安全防火处、机关纪委。协助吴敏同志工作。

罗梦珊 副巡视员：分管资金计划、财务、审计、资产管理工作。负责局主要领导交办的其他工作事项。具体分管财务审计处。协助陈迅同志工作。

广州市林业和园林局
