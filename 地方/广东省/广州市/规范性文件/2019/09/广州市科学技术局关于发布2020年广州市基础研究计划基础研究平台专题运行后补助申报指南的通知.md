# 广州市科学技术局关于发布2020年广州市基础研究计划基础研究平台专题运行后补助申报指南的通知

各区科技部门，各有关单位：

为贯彻落实《广州市科技创新促进条例》及市委、市政府关于建设科技创新强市的决策部署，支持能体现广州市特色、库藏不断增加、保存和利用的生物种质资源等科技资源库建设运行，对科技资源公共服务平台给予稳定的运行支持，推动增强公益性、基础性、战略性的科技资源向社会开放共享，现启动2020年广州市基础研究计划基础研究平台专题运行后补助申报工作，现将有关事项通知如下：

一、支持方向与内容

支持方向一、生物种质资源库建设运行。

支持内容：生物种质资源库建设重点支持动物、植物、微生物菌种、土壤等资源的保护和有效开发利用及其科技资源公共服务平台稳定运行。加强资源共享，扶持、引导一批种质资源库进入国家级行列。支持已建设的省市共建生物种质资源库，在原有基础上重点投入，增强资源库对社会的服务能力和共享能力，逐步推动增强公益性、基础性、战略性的创新平台资源共享，为生物种质资源的可持续发展提供有力保障。

支持方向二、科技资源公共服务平台建设运行。

支持内容：推动我市科技资源开放共享，提高资源使用效率，以资源整合为主线，逐步推动增强公益性、基础性、战略性的科技资源资源共享和可持续发展，对科技资源公共服务平台给予稳定的运行支持，整合创新资源，建立共享机制。支持已建成的市科技资源公共服务平台的持续正常运行和开放共享。

二、支持方式及支持强度

本专题采取后补助的方式。对入库的补贴项目按以下其中一种方式、强度支持：

(一)已有省市共建生物种质资源库或市科技资源公共服务平台，按资源库或平台2019年4月至8月发生的建设运行费用给予补贴，最高不超过100万元。

(二)已被认定为国家科技资源共享服务平台的生物种质资源库(名单见附件1)，按资源库或平台2019年4月至8月发生的建设运行费用给予补贴，最高不超过200万元。

补助金额以申报单位提交的生物种质资源库或科技资源公共服务平台2019年4月至8月建设运行费专项审计报告项核定为准。

三、组织方式

各申报单位通过广州市科技业务管理阳光政务平台(http://sop.gzsi.gov.cn/，以下简称阳光政务平台)，按通知要求填报项目申报书并提交有关申报材料，经项目组织单位推荐、市科技局组织评审和审核等程序后，符合条件的予以立项支持或补助。

四、申报对象

本专题面向已建有省市共建的种质资源库平台的市属单位，或已建有市科技资源公共服务平台的市属单位申报。

五、申报基本条件

(一)牵头申报单位应为在广州市行政区域内设立、登记、注册的具有独立法人资格的机构。

(二)申报单位应持续开展生物种质资源库或科技资源公共服务平台的建设运行。

(三)申报单位须符合以下条件之一：

1. 申报单位应具备相应的生物种质资源库或市科技资源公共服务平台资质。

2. 申报单位获得广州市科技计划项目科技资源共享平台、创新平台资源共享以上专题立项并通过验收。

(四)申报单位、合作单位及项目负责人在过去5年内无不良信用记录。

六、申报限制

符合条件的申报单位，申报项目数量不超1项。

七、申报材料

(一)申报需按要求在阳光政务平台填报和提交项目申报书及其他相关附件，其中附件材料应先按相应要求签字盖章后，再扫描上传，并在申报截止日期前提交纸质材料。附件材料包括：

1. 企业法人营业执照、事业单位法人证书或社会组织登记证书。

2. 省、市科技部门共建并获挂牌认定为广东省生物种质资源库(圃)的文件。

3. 获得广州市科技计划项目科技资源共享平台、创新平台资源共享以上专题立项及对应的项目验收证书。

4. 2019年4月至8月生物种质资源库或科技资源公共服务平台建设运行费专项审计报告及2019年4月至8月建设情况总结报告。

(二)申报应如实填写申报材料，并对申报材料的真实性、合法性、有效性负责。凡弄虚作假者，一经发现并核实后，取消申报单位5年内申报市科技计划项目的资格，已获立项的作取消立项或实施终止处理，对相关责任单位(责任人)记录不良信用并通报。

八、申报程序

(一)申报单位注册。申报前应先进入阳光政务平台按要求完成单位用户注册(新开户)，获取单位用户名及密码。已有单位用户账号的不需另行注册。忘记用户名或密码的，通过阳光政务平台的“忘记密码”功能或联系组织单位重置密码。

(二)单位和申报人信息维护。单位用户登录阳光政务平台并完善单位信息，根据需要可创建申报人账号、密码，申报人用户登录阳光政务平台并完善个人信息。

(三)申报。申报人登录阳光政务平台，选择相应的科技计划(专题)类别，在线填写申报材料后，提交至申报单位审核。

(四)审核推荐。申报单位对申报材料进行认真审查，确保申报质量，通过后提交至对应的项目组织单位。项目组织单位对申报材料进行网上推荐(申报单位如需修改申报信息可与组织单位联系，经组织单位网上推荐的项目不再退回修改)。

九、申报时间

申报单位网上申报开始时间为2019年9月26日9:00，网上申报截止时间为2019年10月9日17:00;组织单位网上审核推荐截止时间为2019年10月10日17:00;组织单位报送书面申报材料至受理窗口截止时间为2019年10月14日。

十、注意事项

(一)阳光政务平台中项目申报书“申报单位基本情况”的相关内容从单位信息模块中自动读取，请各单位在申报项目前，尽早登录(注册)阳光政务平台填写完善，并确认“组织单位”是否准确。

(二)应合理安排项目申报书填报和材料提交时间，避免出现在项目申报截止时间到期前阳光政务平台网络繁忙耽误申报。

(三)项目申报受理和评审立项等信息可在阳光政务平台查询。

(四)项目申报人及申报单位需自行承担包括知识产权纠纷在内的潜在风险。

(五)本通知由广州市科学技术局负责解释。
