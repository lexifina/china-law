# 广州市科学技术局关于广州科普网关停后有关事项的通知

各有关单位：

根据政府网站集约化建设要求，广州科普网已于2019年8月5日17：00关停。原网站科普活动信息及科普基地开放信息公布的内容已迁移至广州市科技局网站科普专栏（网址：http://kjj.gz.gov.cn/kpzl/index.html）。现就网站关停后相关信息报送工作通知如下：

一、原广州科普网关于科普活动信息及科普基地开放信息报送程序不变。相关信息请报送至广州生产力促进中心，报送邮箱为：3097554880＠qq.com，联系人：沈婷，020－83491556。

二、原广州科普网科普作品和科普视频资料发布渠道改为广州科普微信公众号。各单位科普作品、科普微视频及科技计划项目成果原需在广州科普网发布的，改在广州科普微信公众号中发布。需发布的成果资料请上传到永久期限的百度云盘，并发送下载链接至邮箱：3214933867＠qq.com，联系人：马红枣，020－81978432。

特此通知。
