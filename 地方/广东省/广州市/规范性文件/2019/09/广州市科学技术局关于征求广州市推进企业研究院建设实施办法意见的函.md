# 广州市科学技术局关于征求广州市推进企业研究院建设实施办法意见的函

( )

各有关单位：

为进一步提高企业创新能力和产业竞争力，推动企业研发机构高质量发展，我局组织起草了《广州市推进企业研究院建设实施办法(征求意见稿)》(见附件)，现面向社会公开征求意见。

任何单位或个人有修改意见的，可于2019年10月12日前提出书面意见，加盖单位公章或签署真实姓名，并注明有效联系方式，以电子邮件方式反馈我局。未按上述要求提出的意见视作无效，不予受理。电子邮箱：nyyfc@gz.gov.cn。
