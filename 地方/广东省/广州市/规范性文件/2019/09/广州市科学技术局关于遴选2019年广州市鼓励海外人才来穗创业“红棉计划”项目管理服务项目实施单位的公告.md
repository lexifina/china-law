# 广州市科学技术局关于遴选2019年广州市鼓励海外人才来穗创业“红棉计划”项目管理服务项目实施单位的公告

我局拟公开遴选一家具有资质的实施单位完成“2019年广州市鼓励海外人才来穗创业‘红棉计划’项目管理服务”工作。现将有关要求公告如下：

一、本项目征集的起始日期

2019年9月30日至2019年10月12日。

二、项目承担单位的资质和业务要求

(一)在广州市内依法注册设立的具有独立法人资格的企事业单位或社会组织;

(二)具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

(三)已建立或被授权使用具有一定规模的专家库，在库专家4000人以上，覆盖高新技术一级领域;

(四)有5年以上人才项目跟踪管理经验，拥有专业评审人员队伍和良好的评审组织能力，能够优质高效、按期完成委托的项目管理工作;优先选择具有同类项目相关经验的机构。

三、委托事项的工作内容及进度要求

(一)委托事项内容：对2019年广州市鼓励海外人才来穗创业“红棉计划”项目进行材料受理、形式审查、网络评审、现场评审和大评委会议评审。

1. 评审方式：形式审查、网络评审、现场评审、大评委会议评审。

2. 专家来源：从受托单位的专家库系统中按项目所属技术领域随机抽取。

3. 评审规则：按照2019年广州市鼓励海外人才来穗创业“红棉计划”项目申报通知、广州市科技计划项目管理办法等相关文件规定，客观、公正、科学的对项目进行评审。

4. 结果反馈

(1)受托单位提交项目形式审查结果至委托单位;

(2)受托单位提交项目网络评审结果至委托单位;

(3)受托单位提交项目现场评审结果至委托单位;

(4)受托单位提交项目大评委会议评审结果至委托单位;

(5)受托单位编写评审报告连同专家签名等相关评审材料报送至委托单位。

5.评审纪律

(1)受托单位及其工作人员、评审专家不得与项目存在利益关系或其他可能影响公正性的关系。

(2)受托单位及其工作人员、评审专家注意项目材料的保密，不得拷贝或截取项目相关技术资料。

(3)受托单位及其工作人员、评审专家对被评审项目的关键技术与商业秘密进行保密，不得将项目有关文件、资料和数据以任何形式对外提供。

(4)评审期间，受托单位及其工作人员、评审专家不得与项目申报单位或人员直接联系、交流。如对项目材料有不清楚之处，应该和委托方联系确认。

(5)受托单位及其工作人员、评审专家注意项目评审结果的保密，不得向外泄露评审结果。

6. 注意事项：

(1)受托单位根据项目申报指南编制评审文件，按要求进行资料整理及形式审查。

(2)为保证评审工作效率和专家评审质量，同一名专家在同一评审时间段内所评审项目不得超过20项。

(二)进度要求：受托单位应于2019年12月30日前按时按质完成委托项目所有工作，并提交工作总结。

(三)验收要求：由受托单位提交项目验收申请，报我局审定。

四、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

(一)单位基本情况表(原件盖章，见附件);

(二)营业执照副本或登记证书(复印件盖章);

(三)完成同类项目证明，证明本单位实力或能胜任本项工作内容的相关证明材料;

(四)工作实施方案。包括项目进度安排、履约能力、项目团队介绍、预算明细、服务保障等;

(五)其他可以佐证机构专业能力、资质、相关工作经验、业绩、奖项、荣誉等情况的材料。

五、费用预算

人民币40万元以内。

六、材料提交时间、地址

以上书面材料(一式七份含电子光盘一份)密封后，请于2019年10月12日17：30前交至广州市科技局引进智力管理处，逾期不予受理(地址：广州市越秀区府前路1号市府大院4号楼510室，邮政编码：510030)。

七、咨询电话

020-83124054(工作日8：30-12：00、14：00-17：30)。

八、我局将按内部遴选办法确定本项目最终承担单位，并与其商议签订正式委托合同。
