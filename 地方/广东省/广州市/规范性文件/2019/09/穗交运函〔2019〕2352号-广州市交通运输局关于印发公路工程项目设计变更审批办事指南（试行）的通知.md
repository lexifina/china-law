# 广州市交通运输局关于印发公路工程项目设计变更审批办事指南（试行）的通知

穗交运函〔2019〕2352号

市道路养护中心、市交通工程造价管理站，黄埔区、花都区、番禺区、南沙区、从化区、增城区交通运输局，广州交投集团、市高速公路有限公司，越秀交通有限公司、广州广从高速公路有限公司，各相关公路建设业主单位：

根据《国务院办公厅关于全面开展工程建设项目审批制度改革的实施意见》（国办发〔2019〕11号）、《广州市人民政府关于印发广州市工程建设项目审批制度改革试点实施方案的通知》（穗府〔2018〕12号）等文件规定，为贯彻落实党中央、国务院关于深化“放管服”改革和优化营商环境的部署要求，制定了《广州市交通运输局公路工程项目设计变更审批办事指南（试行）》，现印发给你们，请遵照执行。试行过程中如遇到问题，请及时向市交通运输局（计划投资处）反映。

特此通知。

广州市交通运输局

2019年9月6日

（此件公开发布）

广州市交通运输局公路工程项目设计变更审批办事指南（试行）

为贯彻落实党中央、国务院关于深化“放管服”改革和优化营商环境的部署要求，根据《国务院办公厅关于全面开展工程建设项目审批制度改革的实施意见》（国办发〔2019〕11号）、《广州市人民政府关于印发广州市工程建设项目审批制度改革试点实施方案的通知》（穗府〔2018〕12号）相关改革精神，结合省、市有关法律法规和文件规定，为指导有关公路工程项目设计变更审批，特制定本办事指南。

一、行政审批事项

（一）事项名称：公路工程项目设计变更审批

基本编码：2015010002

实施编码：11440100007482639F32015010002

实施主体编码：11440100007482639F

实施部门：市交通运输局

（二）实施依据

1．《公路建设市场管理办法》（2015年交通运输部令第11号修正）；

2．《公路工程设计变更管理办法》（2005年交通部令第5号）。

二、行政审批权限

（一）办件的对象及类型

1．服务对象：机关、事业单位、企业；

2．办件类型：承诺件；

3．适用范围：

由市交通运输局批准初步设计的新建、改建、扩建公路工程，且属于重大设计变更和较大设计变更。

有下列情形之一的，造成工程方案和工程规模变化的，属于重大设计变更：

（1）连续长度10公里以上的路线方案调整的；

（2）特大桥的数量或结构型式发生变化的；

（3）特长隧道的数量或通风方案发生变化的；

（4）互通式立交的数量发生变化的；

（5）收费方式及站点位置、规模发生变化的；

（6）超过初步设计批准概算的。

有下列情形之一的，造成工程方案和工程规模变化的，属于较大设计变更：

（1）连续长度2公里以上的路线方案调整的；

（2）连接线的标准和规模发生变化的；

（3）特殊不良地质路段处治方案发生变化的；

（4）路面结构类型、宽度和厚度发生变化的；

（5）大中桥的数量或结构型式发生变化的；

（6）隧道的数量或方案发生变化的；

（7）互通式立交的位置或方案发生变化的；

（8）分离式立交的数量发生变化的；

（9）监控、通讯系统总体方案发生变化的；

（10）管理、养护和服务设施的数量和规模发生变化的；

（11）其他单项工程费用变化超过500万元的，具体规定如下：一是由于建设条件发生变化，路基、路面、桥涵、隧道、路线交叉及交通工程中，单位工程费用变化500万元或同一个项目中同类型多个单项工程费用变化累计超过500万元的；二是不可预见的、突发性的地质灾害，如岩溶、滑坡、采空区等，造成工程处理费用超过500万元的。

一般变更是指除重大设计变更和较大设计变更以外的其他设计变更。

4．不收取许可费用。

（二）分级权限

1．市交通运输局审核上报省交通运输厅审批的项目：交通运输部和省交通运输厅批准初步设计的新建、改（扩）建公路工程项目的重大和较大设计变更。

2．市交通运输局审批的项目：由市交通运输局批准初步设计的高速公路、普通国、省道项目重大和较大设计变更。

3．区级交通运输主管部门审批的项目：由区交通运输主管部门批准初步设计项目。

（三）办结时限

承诺办结时限缩短为5个工作日（法定办结时限为20个工作日）。即自受理申请之日起5个工作日内作出许可决定。

三、行政审批要求

（一）受理条件

1．设计变更建议已经市交通运输局同意；

2．设计图纸已经修编完成。

（二）材料清单

设计变更文件附录A、B、C（原件1份，PDF电子文件1套）。

除附录A（广州市交通运输局公路工程建设项目设计变更建议申请处理表）需市交通运输局盖章确认以外，提交的其他纸质材料均需加盖建设单位单位公章；同时提供电子文档刻录光盘1张，电子文档格式应为原件彩色扫描文件或带电子印章的PDF文件。

（三）办理流程（办理流程图见附件）

1．窗口办理。

（1）需在省在线平台填报项目信息，获取项目代码。

（2）申请人向市政务服务中心相应窗口递交该项申报材料，符合受理清单或经部门确认材料无误的，由市政府服务中心当场收件并向申请人出具《受理回执》，以及将申报材料及时转交市交通运输局。申请材料不全或不符合法定形式的，由受理窗口当场出具《材料补正通知书》，一次性告知申请人需要补正的全部内容。时限：0.5个工作日。

（3）市交通运输局计划投资处（承办处室）接件受理后，初审录入相关信息，时限：0.5个工作日。若市政务服务中心在收件当场未出具《材料补正通知书》的，经审查认为需申请人补正申请材料内容的，应在自出具《受理回执》之日起1个工作日内制作《材料补正通知书》一次性书面告知申请人需要补正的全部内容，并转交市政府服务中心通知申请人；逾期未转交的，自出具《受理回执》之日起即为受理。

（4）市交通运输局承办处室对设计变更文件的标准、规范内容等进行符合性审查，时限：1个工作日。

（5）符合性审查通过后，市交通运输局承办处室将施工图设计变更预算转市交通工程造价管理站进行审核并由该站在10个工作日内出具审查意见（属技术审查环节，不计入审批时限）。市交通运输局承办处室依据市交通工程造价管理站的施工图设计变更预算审查意见，起草项目设计变更批复文件，做出许可决定，时限：3个工作日。若符合性审查不通过，市交通运输局承办处室将直接出具退审通知。

（6）市交通运输局承办处室在政府系统录入办理信息，将办理结果文书转交市政府服务中心，并按规定政务公开。

（7）办理结果由市政府服务中心统一通知申请人领取或者邮寄给申请人（可支持快递）。

2．网上办理。

（1）需在省在线平台填报项目信息，获取项目代码。

（2）申请人登录“广东省政务服务网”网上办事大厅并注册，在线填报业务表单及上传电子材料。若材料文本太大无法上传的，应及时将申请材料及电子件提供给市交通运输局计划投资处（承办处室）。

（3）市交通运输局计划投资处（承办处室）受理，确认材料无误的在系统上出具《受理回执》，并初审录入相关信息，时限：1个工作日。经审查申请材料不全或不符合法定形式的，应在系统出具《材料补正通知书》，一次性告知申请人需要补正的全部内容。

（4）后续办理同窗口受理程序的第（4）至第（7）项。

四、其他

按照《广东省交通厅关于公路工程设计变更管理的实施细则》，其他一般设计变更由建设单位和项目法人审查后决定是否实施，实施结果由建设单位组织审查后报市交通运输局备案。

本办事指南自印发之日起开始执行。文件试行过程中，如有意见请与市交通运输局联系人反映。
