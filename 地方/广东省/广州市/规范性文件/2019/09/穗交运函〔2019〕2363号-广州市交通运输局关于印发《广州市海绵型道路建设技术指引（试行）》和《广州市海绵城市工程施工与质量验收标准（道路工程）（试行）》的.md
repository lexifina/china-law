# 广州市交通运输局关于印发《广州市海绵型道路建设技术指引（试行）》和《广州市海绵城市工程施工与质量验收标准（道路工程）（试行）》的通知

穗交运函〔2019〕2363号

市中心区交通项目管理中心、市土发中心、市代建局、市道路研究中心、市建设科技中心、市广园路建设公司，广州地铁集团、广州交投集团、广州铁投集团、市城投集团：

根据广州市海绵城市建设领导小组有关工作要求，市交通运输局制定了《广州市海绵型道路建设技术指引（试行）》和《广州市海绵城市工程施工与质量验收标准（道路工程）（试行）》（见附件），现印发给你们，请遵照执行。执行过程中如遇问题，请及时向市交通运输局反映。

特此通知。
