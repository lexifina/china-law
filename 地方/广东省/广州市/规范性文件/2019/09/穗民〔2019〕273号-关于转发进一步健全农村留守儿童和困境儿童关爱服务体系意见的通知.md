# 关于转发进一步健全农村留守儿童和困境儿童关爱服务体系意见的通知

穗民〔2019〕273号

各区民政局、教育局、公安分局、司法局、财政局、人力资源和社会保障局、妇儿工委、团委、妇联、残联，市救助管理站（市未成年人救助保护中心）、市社会（儿童）福利院：

现将广东省民政厅、教育厅、公安厅、司法厅、财政厅、人力资源社会保障厅、妇儿工委、团委、妇联、残联《转发民政部等10部委<关于进一步健全农村留守儿童和困境儿童关爱保护体系的意见>的通知》（粤民发〔2019〕74号，以下简称《意见》）转发给你们，并结合我市实际，提出以下意见，请一并贯彻实施。

一、提高站位，切实增强农村留守儿童关爱保护和困境儿童保障工作的责任感

进一步健全农村留守儿童和困境儿童关爱服务体系，不断加强农村留守儿童关爱保护和困境儿童保障工作，是深入贯彻落实习近平总书记关于民生民政工作重要论述的重要举措。各区、各部门要深化认识，秉持“儿童优先、儿童利益最大化”理念，把加强农村留守儿童关爱保护和困境儿童保障工作作为打赢脱贫攻坚战和加强民生保障的重点任务来抓，切实维护农村留守儿童和困境儿童的合法权益，将该项工作落实情况纳入年度重点工作考核评估的重要内容强化落实。

二、精准定位，着力推动未成年人救助保护机构和儿童福利机构实现功能转型和能力升级

《意见》明确了未成年人救助保护机构和儿童福利机构的职能定位，特别是对未成年人救助保护机构的转型升级作出了明确指引。各区要积极整合本区资源，单独建立或依托合适实体机构成立未成年人救助保护中心（儿童福利服务指导中心），承担本区困境儿童救助保护工作，达到每一名需要救助的困境儿童都能得到及时有效救助的目标，杜绝无人监护现象。该项工作必须在2019年9月底前完成。工作的完成情况将纳入市委政法委对各区2019年度综治工作考评。

市、区未成年人救助保护中心要对照未成年人救助保护机构的10项工作职责，进一步健全服务功能，规范工作流程，全面提升对全市农村留守儿童和困境儿童的关爱服务能力。未成年人救助保护机构抚养照料婴幼童能力不足的，可就近委托儿童福利机构代为养育，并签订委托协议。

市社会（儿童）福利院要进一步完善软硬件配置，增强集医、养、治、教、康于一体的综合服务能力，在机构管理、医疗康复、特殊教育、早期干预等工作中起到示范引领作用。番禺、花都、从化、增城区要高质量加快完成儿童福利院升级改造工作，充分发挥儿童福利院的综合服务平台功能，逐步辐射周边村（居），为有需要的农村留守儿童及困境儿童提供专业的替代照料、家庭辅导、专业康复和矫治等服务。

三、狠抓培训，全面提升农村留守儿童和困境儿童工作队伍的规范化专业化职业化水平

《意见》进一步明确了儿童督导员和儿童主任的定义和职责。各区要指导镇（街）、村（居）按要求配齐专（兼）职“儿童督导员”和“儿童主任”，实现全覆盖。对区划调整过程中增加的镇（街）、村（居），要及时配齐儿童督导员和儿童主任，并督促其认真履行职责。各区民政部门负责儿童主任业务培训，每年不少于一次。

市民政局在前期征求各区意见的基础上制定了《广州市儿童督导员、儿童主任工作规范（试行）》（见附件），请各区结合本通知一并贯彻落实。年内，市民政局将印制《广州市儿童督导员、儿童主任工作手册》发至各区，儿童督导员和儿童主任人手一册，进一步规范入户走访记录和动态跟进工作，形成明晰的工作台账。

四、大力倡导，积极引领社会力量广泛参与农村留守儿童和困境儿童关爱服务工作

各区要将农村留守儿童关爱保护和困境儿童保障纳入政府购买服务指导性目录，加大政府购买社会服务的力度，重点购买热线运行、监护评估、精准帮扶、政策宣传、业务培训、家庭探访等关爱服务。民政部门要积极孵化培育儿童服务类专业社会组织，充分发挥社会组织的作用，充实基层儿童工作队伍，协助开展儿童救助保障工作。

五、加强配合，全面形成部门高效协作的关爱保护工作格局

进一步健全农村留守儿童和困境儿童关爱服务体系是一项长期的系统工程。各区、各部门要充分发挥农村留守儿童关爱保护和困境儿童保障工作联席会议制度作用，民政部门充分发挥牵头职能，各部门按照联席会议成员单位职责分工和《意见》的要求，加强沟通协调，切实加强协作，认真履行职责，合力推进农村留守儿童和困境儿童关爱服务工作。
