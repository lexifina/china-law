# 广州市财政局关于转下达2019年第二批中央财政补助医疗卫生机构能力建设资金的通知穗财保[2019]118号

穗财保〔2019〕118号

广州市财政局关于转下达2019年第二批中央财政补助医疗卫生机构能力建设资金的通知

市卫生健康委：

根据省财政厅《关于安排2019年第二批中央财政补助医疗卫生机构能力建设资金的通知》(粤财社〔2019〕161号，详见附件)，现将中央财政安排的2019年第二批中央财政补助医疗卫生机构能力建设资金400万元下达你委广州市第八人民医院，资金支出列“2100299其他公立医院支出”功能科目。请你委督促项目单位切实加快预算执行进度，加强对资金的监督管理，严格按规定的用途使用资金，确保专款专用和资金使用安全规范。

同时，请参照省财政制订的绩效目标表(附件第7页)，科学合理确定并填报项目绩效目标申报表，在9月17日我市收到粤财社〔2019〕161号文的60日内，会同我局联合报省财政厅、省卫生健康委备案，并抄送财政部广东监管局;在组织预算执行中做好绩效监控，确保年度绩效目标实现，自觉接受中央、省有关部门对绩效目标完成情况的考核和监督。
