# 广州市科学技术局关于公开遴选2019-2020年制度廉洁性评估和公平竞争审查服务实施单位的公告

我局拟公开遴选“2019-2020年制度廉洁性评估和公平竞争审查服务”实施单位。现将有关事项公告如下：

一、本项目征集起始日期

2019年10月12日至10月16日。

二、承担单位的资质和业务要求

1. 在广州市内依法注册设立的具有独立法人资格的企事业单位;

2. 具有独立的财务管理、财务核算和资产管理制度，依法缴纳税收;

3. 有符合要求的固定办公场所，熟悉科技系统业务，具有制度廉洁性评估和公平竞争审查服务经验，有稳定的技术队伍和较为完善的服务机制;

4. 本项目不接受联合体报名。

三、项目内容及要求

委托事项内容：2019-2020年广州市科学技术局制度廉洁性评估和公平竞争审查服务。具体包括：

1. 制定相关制度的《廉洁性评估和公平竞争审查》计划，征求专家及群众代表的意见。

2. 结合专家及群众的意见，完成相关制度的《廉洁性评估和公平竞争审查》评估报告。

3. 市科学技术局要求的符合《制度廉洁性评估和公平竞争审查服务》目的和宗旨的其他服务。

四、需提交的材料

有意参与本项工作的单位需提交申请书(包括申请单位情况介绍)，并附以下材料：

1. 单位基本情况表(原件盖章，见附件);

2. 营业执照副本或登记证书(复印件盖章);

3. 完成同类项目证明以及具有制度廉洁性评估和公平竞争审查服务经验的证明材料;

4. 项目实施方案，包括项目进度安排、预算明细、服务保障等;

5. 其他可以佐证机构专业能力、项目实施团队情况、资质、相关工作经验、业绩、信誉奖项等情况的材料;

6. 报价及预算明细。

五、费用预算

人民币14.25万元以内(含14.25万元)。

六、申请书提交时间、地址

以上书面材料(一式五份含电子光盘一份)密封后，请于2019年10月16日17:30前交至广州市科学技术局政策法规与创新体系建设处，逾期不予受理(地址：广州市越秀区府前路1号4号楼东405室，邮政编码：510030)。

七、咨询电话

020-83124026(工作日8:30-12:00、14：00-17:30)

八、其他

我局将按内部遴选办法确定本项目最终承担单位，并与其商议签订正式委托合同。
