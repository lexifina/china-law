# 广州市民政局广州市精神文明建设委员会办公室广州市妇女联合会关于公布广州市2019年十大最美慈善家庭的通知

市直有关单位，各区民政局、文明办、妇联：

为深入贯彻落实习近平新时代中国特色社会主义思想，大力宣传贯彻《中华人民共和国慈善法》，深化“羊城慈善为民”创建，进一步弘扬慈善精神，激发全民向上向善的热情，营造人人慈善为人人的良好社会氛围，由广州市民政局、广州市精神文明建设委员会办公室、广州市妇女联合会联合开展的寻找广州市2019年十大“最美慈善家庭”活动，经推荐（自荐）、网络投票、专家评审、公示等程序，共评选出孙秀玲家庭等10户“最美慈善家庭”，现予以表扬。

希望受表扬的家庭珍惜荣誉，再接再厉，继续在扶贫济困中发挥示范引领作用。全市各级各部门和广大干部群众要以先进为榜样，努力践行慈善精神，勇于承担社会责任，真诚回报社会，积极投身各类慈善公益活动，依法行善弘扬正能量，为我市创建“慈善之城”，打赢脱贫攻坚战，全面建成小康社会作出新的更大的贡献。

附件：2019年广州市十大最美慈善家庭名单

广州市民政局 广州市精神文明建设委员会办公室 广州市妇女联合会

2019年9月23日
