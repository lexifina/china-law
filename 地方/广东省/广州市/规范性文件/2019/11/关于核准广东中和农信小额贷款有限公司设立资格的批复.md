# 关于核准广东中和农信小额贷款有限公司设立资格的批复

广东中和农信小额贷款有限公司（筹）：

你司2019年6月通过广州市越秀区金融部门逐级上报的广东中和农信小额贷款有限公司申报材料收悉。根据《广东省小额贷款管理办法（试行）》（粤金〔2019〕10号）、《关于促进小额贷款公司有序发展有关工作的通知》（粤金贷监〔2013〕1号）等规定，现核准你司设立资格。有关事项批复如下：

一、同意中和农信项目管理有限公司在广州民间金融街发起设立专门为农村中低收入群体提供小额信贷支持的农业特色小额贷款公司，经营区域范围扩大到全省。

二、根据《关于促进小额贷款公司有序发展有关工作的通知》（粤金贷监〔2013〕1号）有关规定，同意广东中和农信小额贷款有限公司初始注册资本不低于1亿元，并在两年内逐步增资至3亿元。

三、广东中和农信小额贷款有限公司注册资本为人民币3亿元，由主发起人中和农信项目管理有限公司独资设立，注册地址为广州民间金融街，法定代表人为李真。

四、核准广东中和农信小额贷款有限公司业务范围为：

（一）办理广东省内的小额贷款；

（二）其他经批准的业务。

五、请你司落实营业场所，做好营业场所消防验收，并到市场监管、税务等部门依法办理相关手续。

六、请你司在批复之日起60个工作日内完成开业筹建工作，并由越秀区相关部门正式发文至广州市地方金融监督管理局提请验收。经广州市地方金融监管局核验开业证照齐备后，给予开业通知，并由广州市地方金融监管局报我局备案。

广东省地方金融监管局

2019年7月16日
