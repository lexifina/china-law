# 关于核准广州易人行小额贷款有限公司设立资格的批复

广州易人行小额贷款有限公司（筹）：

你司报送的广州易人行小额贷款有限公司申报材料收悉。根据《广东省小额贷款管理办法（试行）》（粤金〔2019〕10号）等规定，经小额贷款公司准入审核委员会审核，同意设立广州易人行小额贷款有限公司。有关事项批复如下：

一、广州易人行小额贷款有限公司注册资本为人民币2亿元，由啦啦大湾区信贷有限公司独资设立。

二、核准广州易人行小额贷款有限公司我市业务范围为：

（一）办理各项小额贷款；

（二）其他经批准的业务。

三、请你司落实营业场所，做好营业场所消防验收，并到市场监管、税务等部门依法办理相关手续。

四、请你司在批复之日起60个工作日完成开业筹建工作，并由天河区相关部门正式发文至广州市地方金融监督管理局提请验收。经广州市地方金融监管局核验开业证照齐备后，给予开业通知，并由广州市地方金融监管局报我局备案。

广东省地方金融监管局

2019年9月29日

公开方式：主动公开

抄送：广州市工业和信息化局，广州市市场监管局，广州市税务局，

广州市地方金融监管局，天河区政府。
