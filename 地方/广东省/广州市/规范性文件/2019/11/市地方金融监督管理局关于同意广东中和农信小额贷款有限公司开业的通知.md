# 市地方金融监督管理局关于同意广东中和农信小额贷款有限公司开业的通知

越秀区金融局：

越金融〔2016〕225号文收悉。经现场检查，广东中和农信小额贷款有限公司已办理营业执照，悬挂市、区金融工作部门监督举报电话牌匾。同时，该公司承诺及时安装使用广东省地方金融监督管理局非现场监管系统。经研究，我局同意广东中和农信小额贷款有限公司开业，并就有关事项批复如下：

一、广东中和农信小额贷款有限公司初始注册资本不低于1亿元，并在两年内逐步增资至3亿元，由中和农信项目管理有限公司独资设立；法定代表人为李真；住所为广州市越秀区一德路果菜直街6号二层北侧及103自编之五2区。

二、核准广东中和农信小额贷款有限公司业务范围为：

（一）办理各项小额贷款；

（二）其他经批准的业务。

三、广东中和农信小额贷款有限公司不得从事以下经营活动：

（一）吸收或变相吸收公众存款，组织或参与任何名义、形式的集资活动；

（二）向本公司股东、董事及高级管理人员及其关联方提供贷款；

（三）为银行业金融机构业务提供担保；

（四）同一借款人的贷款余额超过500万元；

（五）经营其他未经批准和法律、法规不允许经营的业务。

四、请你局根据有关文件精神，认真做好监管和服务，指导广东中和农信小额贷款有限公司做好开业工作，并督促该公司向越秀区公安分局、广东银保监局和人民银行广州分行报送相关资料。

广州市地方金融监督管理局
