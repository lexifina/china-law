# 市地方金融监督管理局关于广东广发互联小额贷款股份有限公司变更公司章程的批复

越秀区金融局：

越金融〔2019〕117号文收悉。根据《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，广东广发互联小额贷款股份有限公司章程的变更符合规定，我局同意《广东广发互联小额贷款股份有限公司章程》修改相关内容。

广州市地方金融监督管理局

2019年6月27日

（联系人：李政，联系电话：83171679）

公开方式：主动公开
