# 市地方金融监督管理局关于广州市中庸小额贷款有限公司变更股权股东的批复

越秀区金融局：

越金融〔2019〕229号文收悉。根据《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

同意股东广州市五湖四海集团有限公司（以下简称五湖四海集团）将持有的广州市中庸小额贷款有限公司（以下简称中庸小贷）10%股权，自然人股东冯汝洁将持有的该公司10%股权转让给主发起人股东广州市中庸集团有限公司（以下简称中庸集团）。转让后，五湖四海集团、冯汝洁不再持有中庸小贷股权，中庸集团持有中庸小贷50%股权。

广州市地方金融监督管理局
