# 市地方金融监督管理局关于广州市好屋小额贷款有限责任公司变更注册资本的批复

越秀区金融局：

越金融〔2019〕205号文收悉。根据《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

同意广州市好屋小额贷款有限责任公司注册资本从人民币1亿元增加至1.1亿元，由苏州市好屋信息技术有限公司出资1000万元，增资后股权结构不变（同时变更公司章程相关内容）。

广州市地方金融监督管理局

2019年9月30日

（联系人：李政，联系电话：83171679）

公开方式：主动公开

抄送：省地方金融监管局，广州市好屋小额贷款有限责任公司。
