# 市地方金融监督管理局关于广州市安瑞互联网小额贷款有限公司变更高管的批复

越秀区金融局：

越金融〔2019〕95号文收悉。根据《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

同意薛景博任广州市安瑞互联网小额贷款有限公司董事、总经理及法定代表人，免去郑留强董事、总经理及法定代表人职务。

同意薛飞任广州市安瑞互联网小额贷款有限公司业务总监，免去郭奇业务总监职务。

广州市地方金融监督管理局

2019年5月30日

（联系人：李政，联系电话：83171679）

公开方式：主动公开

抄送：省地方金融监管局，广州市安瑞互联网小额贷款有限公司。
