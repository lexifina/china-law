# 市地方金融监督管理局关于广州市衡誉小额贷款股份有限公司变更股权股东的批复

越秀区金融局：

越金融〔2019〕211号文收悉。根据广东省金融办《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）和《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

同意自然人股东赖素芳将持有的广州市衡誉小额贷款股份有限公司3.7595%股权转给主发起人股东广东海印集团股份有限公司，转让后赖素芳持有该公司股权比例为0，广东海印集团股份有限公司持有该公司股权比例为71.6209%。

广州市地方金融监督管理局

2019年9月30日

（联系人：李政，联系电话：83171679）

公开方式：主动公开
