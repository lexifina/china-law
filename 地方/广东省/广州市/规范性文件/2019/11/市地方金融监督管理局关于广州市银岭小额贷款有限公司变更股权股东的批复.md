# 市地方金融监督管理局关于广州市银岭小额贷款有限公司变更股权股东的批复

越秀区金融局：

越金融〔2019〕76号文收悉。根据《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）和《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

一、同意主发起人股东广州市银岭场地租赁有限公司将持有的广州市银岭小额贷款有限公司（以下简称银岭小贷）21%股份，张勤高将持有的银岭小贷20%股份，戴金星将持有的银岭小贷15%股份，沈满朝将持有的银岭小贷10%股份，刘伟嘉将持有的银岭小贷3%股份转让给广州君泰置业发展有限公司（以下简称君泰置业）；沈满朝将持有的银岭小贷6%股份，朱华有将持有的银岭小贷6%股份，吕旭明将持有的银岭小贷4.8%股份转让给朱云升。转让后，君泰置业持有银岭小贷69%的股份，朱云升持有银岭小贷21%的股份，朱华有持有银岭小贷10%的股份。

二、请你区加强监管，按行业主管部门的最新要求，严防银岭小贷与关联方旗下P2P平台等机构的风险交叉传染。
