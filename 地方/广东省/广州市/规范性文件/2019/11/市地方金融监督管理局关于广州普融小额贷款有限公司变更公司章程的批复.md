# 市地方金融监督管理局关于广州普融小额贷款有限公司变更公司章程的批复

越秀区金融局：

越金融〔2019〕237号文收悉。根据《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）和《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）规定，经审核，广州普融小额贷款有限公司章程变更符合规定，我局同意该公司章程作如下变更：

一、原章程第十六条“公司设董事会对股东负责，董事会成员三名，由股东会选举产生。公司董事会行使下列职权”变更为“公司设执行董事、执行董事对股东负责；执行董事行使下列职权”。

二、原章程第十七条变更为“公司设经理，由股东会聘任或解聘，经理对董事会负责，行使下列职权：（一）主持公司的生产经营管理工作，组织实施董事会（股东会）决议；（二）组织实施公司年度经营计划和投资方案；（三）拟订公司内部管理机构设置方案；（四）拟订公司的基本管理制度；（五）拟订公司的具体规章；（六）提请聘任或者解聘公司副经理、财务负责人；（七）聘任或者解聘除应由董事会聘任或者解聘以外的负责管理人员”。

三、废除原章程中第十八条。

广州市地方金融监督管理局
