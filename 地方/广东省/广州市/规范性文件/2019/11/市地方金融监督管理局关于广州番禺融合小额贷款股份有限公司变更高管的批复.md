# 市地方金融监督管理局关于广州番禺融合小额贷款股份有限公司变更高管的批复

番禺区发改局：

番发改〔2019〕91号文收悉。根据《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

同意刘嘉达任广州番禺融合小额贷款股份有限公司董事长，免去刘瑞辉董事长、董事职务。

同意谢俊升任广州番禺融合小额贷款股份有限公司董事、副董事长，免去冯毅董事、副董事长职务。

同意黎伟明任广州番禺融合小额贷款股份有限公司董事。

广州市地方金融监督管理局

2019年6月27日
