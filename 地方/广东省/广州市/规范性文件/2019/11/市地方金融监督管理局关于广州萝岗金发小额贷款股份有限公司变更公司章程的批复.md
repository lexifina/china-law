# 市地方金融监督管理局关于广州萝岗金发小额贷款股份有限公司变更公司章程的批复

广州开发区金融工作局：

穗开金融报〔2019〕60号文收悉。根据《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，广州萝岗金发小额贷款股份有限公司章程的变更符合规定，我局同意原章程中公司住所由“广州市经济技术开发区科学大道235号601房，邮政编码：510663”变更为“广州市高新技术产业开发区科丰路33号9栋208号”。

广州市地方金融监督管理局

2019年8月28日

（联系人：李政，联系电话：83171679）

公开方式：主动公开

抄送：省地方金融监管局，广州萝岗金发小额贷款股份有限公司。
