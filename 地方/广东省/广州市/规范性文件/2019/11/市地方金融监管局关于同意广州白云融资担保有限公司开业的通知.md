# 市地方金融监管局关于同意广州白云融资担保有限公司开业的通知

广州白云融资担保有限公司：

《关于广州白云融资担保有限公司开业的申请》（云担保〔2019〕1号）收悉。按照《广东省地方金融监督管理局关于同意设立广州白云融资担保有限公司的批复》（粤金监担核（穗）〔2019〕1号）要求，经审核，同意你公司开业。请你公司遵循法律、法规、《融资担保公司监督管理条例》（国务院令第683号）及四项配套制度等有关文件规定，依法依规开展业务。

广州市地方金融监督管理局

2019年7月23日
