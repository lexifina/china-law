# 广州市住房和城乡建设局关于进一步规范我市房屋建筑工程实名制管理的通知

各区住房城乡建设主管部门，空港委规划建设局，市安监站，各有关建设、施工、监理单位：

近期，市住房城乡建设局组织全市在建房建工程实名制管理工作专项检查发现，部分项目实名制考勤管理存在“手工考勤，工人采用生物识别考勤比例偏低”等突出问题。为认真落实《住房和城乡建设部人力资源社会保障部关于印发建筑工人实名制管理办法（试行）的通知》（建市〔2019〕18号，下称部实名办法），同时根据《广东省建设工程领域用工实名管理暂行办法》（粤建规范〔2019〕1号）有关要求，结合我市实名制和工资支付分账平台化管理推广以来的实际情况，现将进一步规范实名制管理的有关要求通知如下：

一、全面升级考勤设备，推行生物考勤

按照部实名办法和《广州市住房和城乡建设局关于在我市房建市政工程贯彻执行省用工实名及工人工资支付专用账户管理办法有关要求的通知》（穗建筑［2019］352号，下称352号文）要求，我市房建新开工工程项目，建筑施工企业应在开工前配备实现建筑工人实名制管理所必须的硬件设施设备，施工现场原则上实施封闭式管理，设立进出场门禁系统，按要求采用人脸、指纹、虹膜等生物识别技术进行电子打卡。我市房建工程优先推荐采用人脸识别技术进行考勤。

为保证上传数据完整、实时、准确，实现实名制各项数据与全国建筑工人管理服务信息平台联通、共享，我市将从2020年1月1日起关闭广州市建设领域管理应用信息平台原有手工考勤功能，且不再开通新增IC卡考勤数据接口，全面实施基于生物识别功能的电子考勤。目前仍在使用手工考勤的在建房建工程，建筑施工企业应按上述要求升级考勤设备，确保项目现场实名制管理工作正常开展。

二、加强监督指导

各区住房城乡建设行政主管部门应立即组织监督指导，进一步规范房屋建筑工程实名制考勤管理，按照352号文要求，在工程项目开工时，核验现场实名制考勤的设备设施是否符合开工条件，确保现场实名制管理工作正常开展，考勤数据真实、准确、及时。

市住房城乡建设局将不定期通过平台数据抽检及现场随机抽查方式对各区在建项目进行监督检查，对落实不到位的项目的相关责任单位予以通报，切实提高我市房建工程实名制管理水平。

特此通知。

广州市住房和城乡建设局
