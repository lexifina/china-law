# 广州市地方金融监督管理局关于广州凯得融资担保有限公司变更董事备案的通知

广州凯得融资担保有限公司：

你司《关于变更公司董事的备案》（穗凯担〔2019〕23号）收悉。根据《融资担保公司监督管理条例》（国令第683号）、《关于贯彻执行<融资担保公司监督管理条例>有关事项的通知》（粤金函〔2017〕1151号）等有关规定，对王成担任广州凯得融资担保有限公司董事事项予以备案。

广州市地方金融监督管理局

2019年10月8日
