# 广州市地方金融监督管理局关于广州复星云通小额贷款有限公司变更注册资本的批复

越秀区金融局：

越金融〔2019〕22号文收悉。根据《关于印发〈广东省小额贷款有限公司管理办法（试行）〉的通知》（粤金融〔2009〕10号）以及《关于〈广东省人民政府2012年行政审批制度改革事项第一批目录〉中融资担保公司小额贷款公司有关事项贯彻意见的通知》（粤金〔2012〕71号）的规定，经审核，现批复如下：

同意广州复星云通小额贷款有限公司注册资本从人民币2亿元增加至人民币4亿元，分别由复星南方投资管理有限公司出资1亿元、上海星鑫投资管理有限公司出资1亿元，增资后复星南方投资管理有限公司持有40%的股份、上海星鑫投资管理有限公司持有35%的股份。

广州市地方金融监督管理局

2019年4月1日
