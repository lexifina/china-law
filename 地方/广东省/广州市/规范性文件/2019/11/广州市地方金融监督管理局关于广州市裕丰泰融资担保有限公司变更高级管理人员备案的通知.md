# 广州市地方金融监督管理局关于广州市裕丰泰融资担保有限公司变更高级管理人员备案的通知

广州市裕丰泰融资担保有限公司：

你公司上报的关于刘兴仪担任广州市裕丰泰融资担保有限公司总经理高级管理人员任职备案材料收悉。根据《融资担保公司监督管理条例》（国令第683号）、《关于贯彻执行<融资担保公司监督管理条例>有关事项的通知》（粤金函〔2017〕1151号）等有关规定，予以备案。

广州市地方金融监督管理局

2019年4月17日

抄送：省地方金融监管局，市市场监管局。
