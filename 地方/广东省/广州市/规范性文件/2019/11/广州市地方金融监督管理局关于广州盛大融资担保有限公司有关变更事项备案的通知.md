# 广州市地方金融监督管理局关于广州盛大融资担保有限公司有关变更事项备案的通知

广州盛大融资担保有限公司：

《关于变更持有5%以上股权的股东，变更董事、监事、高级管理人员的备案书》（2019盛大变字001号）收悉。根据《融资担保公司监督管理条例》（国务院令第683号）和《关于贯彻执行<融资担保公司监督管理条例>有关事项的通知》（粤金函〔2017〕1151号）等有关规定，我局现对如下事项予以备案：

你公司原股东广州奥文投资有限公司将其持有的你公司18%股权转让给上海蓝书信息科技有限公司。转让后，你公司股东构成为广东海瀚科技发展有限公司占股82%、上海蓝书信息科技有限公司占股18%；同时，你公司变更法定代表人、执行董事兼经理为朱亮，变更监事为黄焱。

广州市地方金融监督管理局

2019年11月6日
