# 广州市农业农村局关于印发《广州市生猪屠宰场布局和建设工作方案》的通知

各区人民政府，市发展改革委、公安局、财政局、司法局、规划和自然资源局、生态环境局、商务局、市场监管局、城市管理和综合执法局：

经市人民政府同意，现将《广州市生猪屠宰场布局和建设工作方案》印发给你们，请遵照执行。

广州市农业农村局

2019年11月26日

广州市生猪屠宰场布局和建设工作方案

根据《广东省人民政府关于深化屠宰行业改革完善屠宰管理体制机制的意见》（粤府函〔2017〕364号）、《广州市乡村振兴战略规划（2018－2022年）》和《粤港澳大湾区“菜篮子”建设实施方案》（穗府办〔2019〕60号）的要求，为进一步优化我市生猪定点屠宰场布局，提升生猪屠宰和肉品供应保障水平，结合我市实际，制定本工作方案。

一、总体目标

按照“严格控制总量、合理优化布局、推进企业升级建设”的总体要求，建立与生猪屠宰产业发展和人民生活需求相适应、布局科学合理、生产加工设施先进、产品质量安全标准化的生猪定点屠宰加工体系。2021年底前全市生猪定点屠宰场减至5家，达到生猪定点屠宰厂资质等级4A级及以上标准，实现品牌肉生产经营，确保全市猪肉产品供应及质量安全。

二、规划布局

全市规划建设5家标准化生猪定点屠宰场，分别位于白云、花都、番禺、增城和从化区。其中选址新建的生猪屠宰场，每家占地面积100亩左右。生猪定点屠宰场具体布局设置如下：

（一）白云区1家：以现广州皇上皇集团股份有限公司孔旺记肉业分公司地块为基础升级改造或新选址建设。

（二）花都区1家：新选址建设。

（三）番禺区1家：以原番禺食品有限公司大石分公司地块为基础建设，可根据实际情况升级扩建。

（四）增城区1家：新选址建设。

（五）从化区1家：以现广州市从化食品企业有限公司肉类联合加工厂地块为基础升级改造或新选址建设。

（六）在我市养殖肉猪年出栏20万头以上的生猪养殖企业，申办现代化生猪屠宰、加工、冷链配送一体化企业，按《广东省人民政府关于深化屠宰行业改革完善屠宰管理体制机制的意见》（粤府函〔2017〕364号）要求执行。

三、工作原则

（一）科学规划，合理布局。设置生猪定点屠宰场应综合考虑区域经济社会发展规划、生猪产销特点、交通运输、动物防疫、环境保护要求等因素；生猪屠宰场各功能区域设置应布局合理、资源集中、利于生产、流通有序，提高屠宰场区综合利用效益。相关区政府可结合辖区村级工业园的规划，落实生猪定点屠宰场建设。

（二）标准建设，规范管理。按照《生猪定点屠宰厂资质等级要求（NY/T3348－2018）》4A级及以上标准建设，实现生猪屠宰、肉品加工、冷冻存储、肉品交易等各功能区标准化，建立肉品生产、加工、运输和销售全程冷链管控体系；实行规范化、制度化和肉品生产追溯信息化管理，实现肉品质量信息全程溯源。由市农业农村局出台生猪屠宰场建设指导意见，对生猪屠宰场建设提出具体要求。

四、实施步骤

（一）动员部署阶段（2019年11月）

相关区政府按照本方案规划布局和建设要求，制定本辖区生猪屠宰场建设工作方案，明确工作任务、目标和实施步骤；成立工作领导小组，积极做好宣传发动和工作部署；自方案发布之日起30天内，将本辖区生猪屠宰场建设工作方案和新建生猪屠宰场选址报市农业农村局。

（二）推进建设阶段（2019年11月－2021年12月）

以“政府主导、企业自愿参与”的原则，开展生猪屠宰场建设经营主体确定工作。相关区政府应鼓励和支持生猪定点屠宰场经营者通过股份合作、重组等方式参与生猪屠宰场建设经营或肉品运输配送；优先考虑或积极引导、支持具有肉品品牌注册登记，从事生猪屠宰、肉品配送和一体化经营的生猪屠宰企业牵头组织、参与生猪屠宰场建设经营；2020年2月底前将新选址生猪屠宰场建设经营主体名单报市农业农村局。

相关区政府应督促生猪屠宰场建设经营主体制定生猪屠宰场建设或升级改造方案，经审定后于2020年4月底前报市农业农村局备案；督促生猪屠宰场建设经营主体严格按照制定的建设或升级改造方案和国家、省相关生猪屠宰场建设要求及标准加快建设，确保按期按质完成生猪屠宰场建设或升级改造。

番禺区生猪屠宰场应于2019年12月底前建成并投产，其他升级改造生猪屠宰场应于2020年12月底前完成改造建设并投产；新选址生猪屠宰场应于2021年12月底前建成并投产。

（三）关停规划外屠宰场阶段（2019年11月－2021年12月）

相关区政府应按照本方案生猪屠宰场的规划设置和布局，在保障生猪屠宰产能平稳过渡的前提下，有序关闭本方案规划以外的生猪屠宰场。

1．《关于印发广州市牲畜定点屠宰规划选址意见的通知》（穗屠联办〔2013〕14号）规划外的生猪定点屠宰场须在2019年12月31日前关闭。

2．《关于印发广州市牲畜定点屠宰规划选址意见的通知》（穗屠联办〔2013〕14号）规划原址升级改造的生猪定点屠宰场，除本方案予以保留的，须在2021年12月31日前关闭。

五、保障措施

（一）加强组织领导。生猪定点屠宰场布局和建设是一项重要的民生工程，是保障肉品质量安全的基础。相关区要高度重视，党政主要领导要亲自挂帅，把生猪定点屠宰场布局和建设作为一把手工程亲自推动。按照属地管理的原则，建立健全责任体系，加快推进屠宰场建设，及时研究解决建设工作中的问题。

（二）加强政策扶持。市规划和自然资源、生态环境、农业农村、市场监管、商务、公安等部门要积极支持和加强配合，按照特事特办的原则，加快生猪屠宰企业建设相关事项办理，落实生猪定点屠宰场建设。按照相关政策要求，支持屠宰企业延伸产业链条，对实现生猪屠宰、肉品加工、冷链配送、肉品交易等一体化经营的生猪屠宰企业，应给予政策和财政扶持。

（三）做好财政补偿。对《关于印发广州市牲畜定点屠宰规划选址意见的通知》（穗屠联办〔2013〕14号）规划原址升级改造的生猪定点屠宰场，除本方案予以保留的，在2021年12月31日前平稳关闭的，按其2010年至2012年年均屠宰量每头40元的标准给予相应财政补偿，具体补偿细则参照《广州市农业局广州市财政局关于政策性关闭生猪定点屠宰场补偿的通知》（穗农〔2016〕195号）执行。

（四）维护社会稳定。生猪屠宰场建设及规划外生猪屠宰场关闭工作，涉及土地利用、历史遗留、肉品供应等多方面问题。相关区政府和职能部门要从大局出发，增强责任意识，加强协调，积极引导，及时解决问题、化解矛盾；对影响生猪屠宰场建设及生猪屠宰、肉品经营稳定的黑恶势力行为要及时坚决打击，确保生猪屠宰场建设和规划外生猪屠宰场关闭工作任务按时完成，切实保障社会稳定、猪肉供应稳定。
