# 粤港澳大湾区“菜篮子”建设工作专责小组办公室关于印发粤港澳大湾区“菜篮子”产品配送中心质量安全承检机构管理规范（试行）的通知

穗菜办函〔2019〕13号

粤港澳大湾区“菜篮子”建设工作专责小组办公室关于印发粤港澳大湾区“菜篮子”产品配送中心质量安全承检机构管理规范（试行）的通知

粤港澳大湾区“菜篮子”产品配送中心所在地相关行政主管部门：

根据《广州市人民政府办公厅关于印发粤港澳大湾区“菜篮子”建设实施方案的通知》（穗府办〔2019〕60号）要求，我办（设在广州市农业农村局）牵头制定了《粤港澳大湾区“菜篮子”产品配送中心质量安全承检机构管理规范（试行）》，现印发给你们，请组织实施。实施中遇到问题，请径向我办反映。

粤港澳大湾区“菜篮子”建设工作专责小组办公室

（广州市农业农村局代章）

2019年11月19日

粤港澳大湾区“菜篮子”产品配送中心质量安全承检机构管理规范（试行）

第一条为促进粤港澳大湾区“菜篮子”平台发展和规范相关产品质量安全承检机构承检工作，特制订本规范。

第二条粤港澳大湾区“菜篮子”产品配送中心产品质量安全承检机构（以下简称承检机构）是受委托承担粤港澳大湾区“菜篮子”配送中心产品质量安全检验工作的第三方检验机构。

按照属地管理原则，承检机构由粤港澳大湾区“菜篮子”产品配送中心所在地相关行政主管部门参照第三条规定的条件确定，并报粤港澳大湾区“菜篮子”建设工作专责小组办公室备案。

第三条承检机构应当符合以下条件：

（一）应为具有独立法人资格，不具有独立法人资格的检验机构应经所在法人单位授权，并由其所在法人单位承担法律责任；

（二）应拥有完善的实验室质量管理体系，取得检验机构资质认定（CMA）和通过农产品质量安全检测机构考核（CATL），承担供港澳产品的承检机构还应获得国家实验室认可资质（CNAS），授权检测能力范围涵盖承检任务中相应的产品品种和检测项目；

（三）具有与承担的检验工作任务相匹配的工作人员、仪器设备、实验室环境设施、安全有效的信息管理系统，能够完成检验工作并及时将检验结果和数据报送到粤港澳大湾区“菜篮子”信息平台；

（四）须连续从事农产品检验工作5年以上，或连续承担过3年以上国家级、省级或市级农产品质量安全监督管理部门委托的检验任务；

（五）近3年无违法和违规行为，检验活动能够保证检验结果质量，参加与承检任务相关的能力验证并取得满意结果。

第四条承检机构应当严格按照要求完成以下工作：

（一）按照计划安排和进度要求完成检验任务；

（二）依据粤港澳大湾区“菜篮子”平台产品质量安全监控指标体系要求，结合当地农产品生产投入品使用的实际情况制定监控实施方案进行检测，检测工作完成后，按规定出具有效检验报告，并上传检验报告到粤港澳大湾区“菜篮子”信息平台；

（三）检测过程中发现被检样品存在安全问题的，应当在发现问题并经确认后24小时内将问题或有关情况报委托单位，并留存报告反馈记录备查；

（四）承检机构不得瞒报、谎报、漏报样品检测数据、结果等信息。

第五条检测项目原则上不能分包，确因特殊情况需要分包的，需经粤港澳大湾区“菜篮子”产品配送中心所在地相关行政主管部门或者购买服务机构批准，同时分包人应当满足本规范第三条规定的条件。

第六条承检机构应当承担保密义务，不得泄露、擅自使用或对外发布受检产品安全相关信息，严格遵守国家法律、法规和有关工作纪律要求。

第七条粤港澳大湾区“菜篮子”建设工作专责小组办公室每年定期或不定期组织相关机构对各承检机构进行检查，检查内容包括：

（一）检查承检机构用于承担食品安全检验任务相关的实验室环境、仪器设备、样品存放、管理体系、工作管理制度等相关条件；

（二）检查检验报告、数据报送及结果分析总结报告等材料；

（三）检查检测的原始记录、机构内部质量控制、能力验证或实验室间比对结果等材料；

（四）必要时，采用盲样测试或留样复测等方式查核承检机构检验结果的可靠性；

（五）检查相关保密制度落实情况；

第八条承检机构出现以下情况，委托单位视情节严重程度，应暂停委托检验工作任务：

（一）不能持续满足本办法规定的基本条件的；

（二）漏报受托检测数据、结果等信息的；

（三）未按要求及时报送不合格样品检验报告信息以及结果分析报告的；

（四）盲样测试、留样复测结果不符合要求的。

第九条承检机构出现以下情况，委托单位应立即终止委托检验工作任务，并报粤港澳大湾区“菜篮子”建设工作专责小组办公室，取消该承检机构的备案：

（一）篡改数据、瞒报、谎报检验数据、出具虚假检验报告等行为的；

（二）擅自对外发布或泄漏受托检测数据和分析研判结果等信息，或利用相关数据进行有偿活动的；

（三）检验工作出现差错并造成不良后果的；

（四）擅自将承检任务转交其他检验机构或将项目进行分包的；

（五）其他违反法律法规行为的。

第十条检查中发现承检机构在承担检验任务中存在违法违规行为的，由粤港澳大湾区“菜篮子”产品配送中心所在地相关行政主管部门通报相关部门并依法依规追究其责任。

第十一条承检机构的监督检查结果将作为安排下一年度检验工作任务的依据。

第十二条本办法由粤港澳大湾区“菜篮子”建设工作专责小组办公室负责解释。

第十三条本办法自印发之日起施行。
