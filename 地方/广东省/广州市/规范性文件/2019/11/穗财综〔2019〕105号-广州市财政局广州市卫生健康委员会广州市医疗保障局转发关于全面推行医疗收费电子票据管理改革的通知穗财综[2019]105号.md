# 广州市财政局广州市卫生健康委员会广州市医疗保障局转发关于全面推行医疗收费电子票据管理改革的通知穗财综[2019]105号

穗财综〔2019〕105号

广州市财政局 广州市卫生健康委员会广州市医疗保障局转发关于全面推行医疗收费电子票据管理改革的通知

各区财政局、卫生健康局、市直有关单位：

为深化“放管服”改革，落实“数字政府”建设规划，做好我市全面推行医疗收费电子票据管理改革任务，现将《广东省财政厅 广东省卫生健康委员会广东省医疗保障局关于全面推行医疗收费电子票据管理改革的通知》(粤财综〔2019〕64号，以下简称《通知》)转发给你们，并结合实际提出以下要求，请一并贯彻执行。

一、确定医疗收费电子票据管理改革时间节点。各单位要高度重视，严格按照《通知》要求，结合实际制定工作方案，明确改革时间，2019年11月15日前将工作方案报市财政局(综合处)。各区财政、卫生健康和医保部门要加强协调联动、分工协作、各负其责，确保在2020年12月31日前全面铺开医疗收费电子票据管理改革工作。

二、做好信息系统升级改造和对接。各区财政部门原则上使用财政部统一开发的电子票据管理系统，牵头协调做好医疗收费电子票据改革工作，做到医疗收费电子票据一站式查询、真伪查验和报销入账。

各区卫生健康部门要督促医疗卫生机构做好医疗收费电子票据管理改革，贯彻落实信息系统改造、业务流程调整等工作，按规定使用全国统一式样的医疗收费票据。

医保部门要在2020年9月30日前完成医疗保障系统的改造和升级工作，为各医疗保险定点医疗机构推动医疗收费电子票据管理改革提供支持，做好医疗收费电子票据应用工作。

各医疗卫生机构应按要求加快改造信息系统，调整业务流程，实现与财政、卫生健康、医保部门系统对接，启用全国统一的医疗收费票据，积极主动推进医疗收费电子票据管理改革工作。

三、进一步强化保障措施。医疗收费电子票据管理改革是一项创新性工作，情况复杂，时间紧，任务重。市和区财政、卫生健康、医保部门要精心研究部署，细化工作任务和要求，层层压实责任，确保我市医疗收费电子票据管理改革工作有序推进。要做好沟通协调工作，全面客观了解医疗收费电子票据管理改革情况，及时发现问题和研究解决办法，及时上报上级对口部门。要广泛宣传，让公众充分认识和接受医疗收费电子票据，提高社会认知度，营造良好氛围，实现便民利民服务目标。
