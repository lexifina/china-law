# 市地方金融监管局关于广州白云融资担保有限公司变更董事及高级管理人员备案的通知

穗金融函〔2019〕1091号

市地方金融监管局关于广州白云融资担保

有限公司变更董事及高级管理人员

备案的通知

广州白云融资担保有限公司：

《关于变更公司法人代表、董事的备案申请》（云担保〔2019〕2号）收悉。根据《融资担保公司监督管理条例》（国令第683号）、《关于贯彻执行<融资担保公司监督管理条例>有关事项的通知》（粤金函〔2017〕1151号）等有关规定，对以下事项予以备案：

一、金咏雷担任广州白云融资担保有限公司董事长兼总经理；

二、张琪担任广州白云融资担保有限公司董事。

广州市地方金融监督管理局

2019年7月31日

（联系人：黄剑峰、郑裕凤，联系电话：83171692）

公开方式：主动公开

抄送：省地方金融监管局，市市场监管局。
