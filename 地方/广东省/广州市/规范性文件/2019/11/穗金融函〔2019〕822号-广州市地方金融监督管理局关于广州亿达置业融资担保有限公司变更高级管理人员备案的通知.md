# 广州市地方金融监督管理局关于广州亿达置业融资担保有限公司变更高级管理人员备案的通知

穗金融函〔2019〕822号

广州市地方金融监督管理局关于广州亿达置业

融资担保有限公司变更高级管理人员

备案的通知

广州亿达置业融资担保有限公司：

你司《关于变更公司执行董事、法定代表人、总经理的备案书》（亿达担保字〔2019〕001号）收悉。根据《融资担保公司监督管理条例》（国令第683号）、《关于贯彻执行<融资担保公司监督管理条例>有关事项的通知》（粤金函〔2017〕1151号）等有关规定，现对廖胜昌担任你司执行董事、总经理事项予以备案。

广州市地方金融监督管理局

2019年6月6日

公开方式：主动公开

抄送：省地方金融监管局，市市场监管局。
