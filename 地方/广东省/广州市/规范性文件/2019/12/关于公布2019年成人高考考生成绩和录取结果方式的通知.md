# 关于公布2019年成人高考考生成绩和录取结果方式的通知

广东省2019年成人高考评卷工作已结束，现将考生成绩和录取结果公布有关事项通知如下：

一、成绩和录取结果公布

广东省教育考试院将于11月22日16：00起向在成人高考报名系统绑定的考生手机推送成绩；16:20起，考生可通过省教育考试院官微（ID：gdsksy）小程序和广东教育考试服务网（www.eesc.com.cn）查询成绩。成人高考录取期间，通过上述方式可以获取或查询录取结果。11月26日16:00起，考生可以通过省教育考试院官微小程序自行下载并打印成绩证书。

录取结果公布时间请留意广东省教育考试院官方微信、广东省教育考试院网站、广东教育考试服务网相关公告讯息。

二、考试成绩复核

（一）申请复查程序。考生在获得成人高考成绩后，如对本人某科成绩有疑问，可在11月25日9:00-17：00时前凭准考证到报名所在区招考办提出复查分数的书面申请，并按复查科目填写《2019年成人高考考生申请复查成绩登记表》（见附件1）。复查内容为成绩统计合成是否有误，答卷是否漏评，答卷扫描是否准确,不涉及评分标准掌握的宽严问题。我市各区招考办地址、联系电话见附件2。

（二）复查结果告知。对复查后发现分数有误的考生，广东省教育考试院将对其分数进行更正，更正后的成绩将通过考生报名绑定的手机号告知考生。

附件：1. 2019年成人高考考生申请复查成绩登记表

2. 广州市各区招考办地址、联系电话
