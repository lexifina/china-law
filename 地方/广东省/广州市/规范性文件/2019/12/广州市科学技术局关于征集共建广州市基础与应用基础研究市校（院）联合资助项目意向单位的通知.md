# 广州市科学技术局关于征集共建广州市基础与应用基础研究市校(院)联合资助项目意向单位的通知

各有关单位：

为深入实施创新驱动发展战略，全面支撑粤港澳大湾区国际科技创新中心和综合性国家科学中心建设，贯彻落实《中共广州市委、广州市人民政府关于建设高水平大学的实施意见》《广东省人民政府办公厅关于实施高水平医院建设“登峰计划”的意见》和《广州市加强基础与应用基础研究实施方案》，吸引更多资金投入基础与应用基础研究，我市拟联合相关高校和医院共同设立市校(院)联合资助项目，现面向全市征集共建意向单位。

一、共建单位资格

(一)性质类型。

一是广州地区被列入省、市高水平大学建设的高校。

二是广州地区被列入“登峰计划”(省高水平医院建设)的医院。

(二)基本条件。

具有健全的科研管理、知识产权管理和财务管理制度，以及相应的组织管理机构，具备稳定的自筹研发经费投入能力。

二、出资金额、资助对象和内容

(一)资助比例和金额。

一是联合资助项目出资主体为共建单位，市财政资金发挥引导作用，共建单位每家每年出资额度与市财政出资额度的比例一般不低于3:1。

二是每家共建单位年投入不低于1000万元。

三是市财政总资助额度每年不超过2000万元，具体额度根据参与情况与合作协议确定。

(二)资助对象和内容。

联合资助项目的资助对象为共建单位，资助内容包括市基础与应用基础研究项目、市重点实验室建设项目等。

请有意向共建市校(院)联合资助项目的单位于2020年1月16日17:00前函复我局，函中需明确2021-2025年每年投入市校(院)联合资助项目的金额(模板见附件2)，说明单位科技项目的组织实施条件(模板见附件3);如对《协议书》模板有修改意见，也请一并反馈(模板见附件4)。

专此。
