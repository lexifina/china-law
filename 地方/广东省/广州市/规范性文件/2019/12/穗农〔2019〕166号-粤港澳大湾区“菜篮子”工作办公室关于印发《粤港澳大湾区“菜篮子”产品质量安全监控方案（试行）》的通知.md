# 粤港澳大湾区“菜篮子”工作办公室关于印发《粤港澳大湾区“菜篮子”产品质量安全监控方案（试行）》的通知

穗农〔2019〕166号

粤港澳大湾区“菜篮子”工作办公室关于印发《粤港澳大湾区“菜篮子”产品质量安全监控方案（试行）》的通知

各有关单位：

为保障粤港澳大湾区“菜篮子”产品的质量安全，粤港澳大湾区“菜篮子”工作办公室根据国家相关法律法规和政策规定，研究制定了《粤港澳大湾区“菜篮子”产品质量安全监控方案（试行）》。现印发你们，请遵照执行。
