# 广州市发展改革委关于做好优化营商环境典型经验复制推广工作的通知

各区人民政府、广州空港经济区管委会，市委组织部、市委宣传部、市委政法委，市科技局、市工业和信息化局、市公安局、市司法局、市财政局、市人力资源社会保障局、市规划和自然资源局、市住房城乡建设局、市交通运输局、市水务局、市商务局、市市场监管局、市地方金融监管局、市城市管理综合执法局、市政务服务数据管理局、市港务局、市法院、市税务局、广州海关、黄埔海关：

优化营商环境是市委、市政府深入贯彻落实习近平总书记关于广州实现“老城市新活力”重要指示精神的重大部署，是推动广州更好发挥粤港澳大湾区区域发展核心引擎作用、打造全球企业投资首选地和最佳发展地的重要举措。近年来，全市各区、各部门认真贯彻落实市委、市政府的部署要求，持续优化营商环境，推出了大量改革措施，形成了一批典型经验做法。经市政府同意，决定分批次在全市范围复制推广，推动我市营商环境整体优化提升。现就有关事项通知如下：

一、首批复制推广主要内容

主要包括来源于越秀区、天河区、黄埔区、南沙区的共计12条典型经验：企业开办“线上一网一界面、线下一窗一表单”模式；临电租赁“一站妥”；电力服务保险产品“电能保”；区块链电子发票；二手房交易“一号通办”；企业全生命周期信用监管；全方位多层次行政处罚信息信用修复机制；“一门式”政策兑现服务；创新“12345”审批服务体系；政务服务标准化；进出口贸易环节知识产权司法与行政协同保护新模式；知识产权大保护大协同机制。

二、高度重视复制推广工作

各区、各部门要高度重视典型经验复制推广工作，深刻认识其重大意义，将其作为优化营商环境工作的重要抓手，聚焦市场主体关切的痛点、难点、堵点，加快转变政府职能，持续提升政务服务水平和办事效率，不断释放制度红利，努力推动我市实现“现代化国际化营商环境出新出彩”。

三、切实做好组织实施

各牵头单位要将复制推广工作列入本单位重点工作，切实加强组织领导，认真研究典型经验做法，结合实际制定复制推广的具体路径的细化方案，确保顺利推进。各区、各部门要主动对标先进，相互学习借鉴，打造更多更好更优的优化营商环境典型案例。市发展改革委要牵头会同有关单位对复制推广工作进行跟进检查督促，及时总结推广更多批次的典型经验做法，奋力实现“人人都是营商环境”“处处优化营商环境”。
