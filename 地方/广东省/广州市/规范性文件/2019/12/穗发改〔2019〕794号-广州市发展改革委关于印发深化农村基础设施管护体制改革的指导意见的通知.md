# 广州市发展改革委关于印发深化农村基础设施管护体制改革的指导意见的通知

各区人民政府，市有关单位：

《广州市关于深化农村基础设施管护体制改革的指导意见》业经市政府同意，现予以印发实施。在实施过程中遇到问题，请径向我委反馈。

广州市发展和改革委员会

2019年12月19日

广州市关于深化农村基础设施管护体制改革的指导意见

为深入贯彻习近平总书记关于乡村振兴的重要论述，推进我市农村基础设施管护体制改革，根据《中共广州市委 广州市人民政府关于推进乡村振兴战略的实施意见》（穗字〔2018〕19号）等文件要求，现提出如下意见。

一、坚持“政府主导、多方参与”原则，强化政府投入和主导责任，加大政策支持力度特别是对北部地区的支持力度，进一步加强农村基础设施管护工作。破除体制机制障碍，引导和鼓励社会资本投向农村基础设施领域，提高农村基础设施管护市场化、专业化程度。

二、健全分级分类管护体制，构建多元化管护新格局。农村公路等公益性农村基础设施，有关区政府、镇（街）政府承担管护主体责任，保障管护经费。鼓励社会资本、农村集体经济组织和村民等多方参与管护。农村供水、垃圾处理等有一定收益的准公益性农村基础设施，管护主体由相关区政府明确，通过财政补助、受益者付费、社会筹资、村民筹资筹劳等多渠道落实管护经费。农村供电、电信等经营性农村基础设施，完善市场化运作机制。

三、农村公路按照国家明确的“县道县管、乡村道乡村管”原则，建立健全农村公路养护责任制，明确区、镇（街）、村三级责任清单，完善农村公路管理体系和建制村村道管理议事体制。镇（街）农村公路工作机构负责乡道、村道养护管理工作。农村道路路灯由区政府结合本辖区实际，明确区、镇（街）、村各级管护责任。

四、财政资金投资建设的规模较大的农村水利设施、污水垃圾处理设施等，由区政府或市有关行业主管部门结合市区两级财政出资比例，遵循“归口管理”原则明确管护主体。社会资本投资或社会资本为主、财政资金补助为辅的农村水利设施由产权所有者承担管护责任。

五、农村供电、电信、广播电视等经营性基础设施，建设、运营企业承担管护责任，结合企业盈利状况和政府指导价格完善使用者付费和产品定价机制。市、区两级财政可根据实际情况对北部地区的经营性农村基础设施给予适当补贴，保障其日常管护。

六、上述以外的包括农村公共人居环境、公共管理和公共服务的其他农村基础设施，根据产权所有者、管理者、受益者协商一致的原则确定管护主体，或联合履行管护主体责任。鼓励有条件的区通过各级财政资金保障村级卫生站、村文化活动中心、村级公共厕所、村级图书室等公共管理和公共服务设施的管护经费。

七、加大力度加快推进农村基础设施产权确权工作。财政资金投入为主建设的供水等农村基础设施，由区政府或其授权部门根据相关规定确定产权归属。社会资本投资或以社会资本为主、财政资金补助为辅建设的农村基础设施，建成后形成的资产归投资者所有，或依据投资者意愿确定产权归属。

八、拓宽管护资金来源渠道。推广农村公路“建养一体化”模式，通过政府购买服务等方式，引入专业企业、社会资本建设和养护农村公路。鼓励采取出让公路冠名权、广告权、相关资源开发权等方式，筹资建设和养护农村公路。有条件的镇（街）、村可建立污水垃圾处理受益者缴费制度。鼓励“千企帮千村”企业结对帮扶农村基础设施运行管护。探索设立农村基础设施管护公益性基金，拓宽资金来源渠道。

九、创新管护方式，逐步建立健全市场化、专业化、社会化的管护机制。推广以政府购买服务方式实施农村基础设施管护。有关区可结合本辖区实际，实行分散与统一打包相结合方式，委托第三方运营机构实施建后管护。有条件的区可将城镇周边农村供水纳入城镇供水系统管理，实现城乡一体化管护。鼓励实行委托养护、合同养护和承包养护等管护长效机制。鼓励农村水利设施、污水垃圾处理设施等建设管护推行PPP模式，实现项目建设、运行、管护一体化。

十、鼓励以区、镇（街）、村为管理单元，组建专业化管护队伍，统筹辖区内农村基础设施管护。引导管护机构加强岗位培训和技能提升，推动管护队伍整体素质不断提高。支持发展壮大专业化、市场化、社会化的管护服务企业和社会组织。支持设立公益性管护岗位，优先聘请有劳动能力的困难户。鼓励农业龙头企业、种养大户、职业农民、家庭农场、村民专业合作社等主体参与农村基础设施管护，实现自主管理、自我服务。

十一、有关区政府要结合实际，会商市有关行业主管部门，制定具体可操作的工作方案，确保管护主体明确、管护经费落实、管护责任到位、监管机制有效。市有关行业主管部门要加强监督管理，建立健全日常养护巡查制度，对管理不到位、工作不落实的管护责任单位予以通报，对毁损、盗用农村基础设施行为予以惩处。

十二、加强新闻媒体宣传报道工作，营造全员关注、全程参与、全面管护的良好社会舆论氛围，不断提升农村基础设施管护水平，助推美丽乡村建设取得新的进展，努力在全省乡村振兴中当好示范和表率。
