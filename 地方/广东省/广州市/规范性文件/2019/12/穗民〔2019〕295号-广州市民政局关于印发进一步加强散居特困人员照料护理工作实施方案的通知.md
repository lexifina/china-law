# 广州市民政局关于印发进一步加强散居特困人员照料护理工作实施方案的通知

穗民〔2019〕295号

各区民政局：

为进一步加强和规范散居特困人员照料护理工作，促进特困人员照料护理服务与居家养老服务工作相结合，根据《广州市民政局广州市财政局转发广东省民政厅关于加强特困供养人员护理工作的通知》（穗民规字〔2018〕11号）、《广州市民政局转发广东省民政厅关于做好特困人员照料护理工作有关事项等文件的通知》（穗民〔2019〕135号）、《广东省民政厅关于明确特困人员生活自理能力评估有关问题的通知》（粤民函〔2019〕1756号）、《广东省民政厅办公室关于全面落实特困供养人员照料护理制度的通知》（粤民电字〔2019〕49号）以及《广州市社区居家养老服务管理办法》（穗府办规〔2016〕16号）等文件要求，制定《广州市民政局关于进一步加强散居特困人员照料护理工作实施方案》，现印发给你们，请结合工作实际，认真执行落实。

广州市民政局

2019年11月10日

广州市民政局关于进一步加强散居特困人员照料护理工作实施方案

为贯彻落实国家、省关于特困人员救助供养工作的文件精神，进一步加强和规范散居特困人员照料护理工作，切实保障散居特困人员照料护理权益，特制定本方案。

一、主要任务

（一）开展生活自理能力评估工作

1．散居特困人员生活自理能力评估标准根据年龄、残疾等级等因素确定。

（1）60周岁以上的散居特困人员按照广州市《老年人照顾需求等级评定规范》进行评估。评定为“能力完好”的，认定为全自理；评定为“轻度失能、中度失能”的，认定为半自理（半失能）；评定为“重度失能”的，认定为全护理（全失能）。

（2）60周岁以下的散居特困人员使用《BARTHEL指数评定量表（BI）使用指引》《广州市长护险现场评估表（BI量表）》开展评估工作。分值总计为96－100分的，认定为全自理；45－95分的，认定为半自理（半失能）；低于45分的，认定为全护理（全失能）。

（3）残疾散居特困人员生活自理能力等级参考《残疾人残疾分类和分级》（GB/T26341—2010）标准。四级智力、精神残疾的，可认定为全自理；三级智力、精神残疾的，可认定为半失能；一、二级智力、精神残疾的，可认定为失能。多重残疾类别的特困人员，以其最重类别认定。

残疾散居特困人员使用《老年人照顾需求等级评定规范》或《BARTHEL指数评定量表（BI）使用指引》《广州市长护险现场评估表（BI量表）》开展评估后，结合残疾类别所对应的生活自理能力等级，以其最重级别认定。

2．集中供养特困人员生活自理能力评估工作参照前述要求办理。

（二）提供照料护理服务

1．各区民政部门应在确认散居特困人员生活自理能力等级后形成散居特困人员名单，并及时将名单通知镇人民政府（街道办事处）。

2．镇人民政府（街道办事处）收到名单后，应及时通知居家养老综合服务平台联系散居特困人员，根据散居特困人员生活自理能力等级和照顾护理需求，制定照料护理方案，指引散居特困人员签订照料护理协议（协议范本详见附件1，协议内容可结合当地工作实际作进一步修改完善，但不能减损特困人员的权益），提供照料护理服务。按照穗民规字〔2018〕11号文有关规定，对可择高享受社区居家养老服务的散居特困人员，镇人民政府（街道办事处）应及时指引其签订居家养老服务协议。

3．户籍所在地与居住地同区不同镇（街道）的散居特困人员，户籍所在区民政部门应当及时将名单通知居住地镇人民政府（街道办事处），由居住地镇人民政府（街道办事处）选定居家养老综合服务平台提供服务。

4．户籍所在地与居住地不同区的散居特困人员，由户籍地镇人民政府（街道办事处）选定居住地居家养老综合服务平台提供服务。

（三）资金结算工作

散居特困人员照料护理经费由户籍所在区民政部门于服务当月按照财务管理规定及协议约定支付费用。相关镇人民政府（街道办事处）应予以积极协助配合。

二、工作要求

（一）各区民政部门要在认定散居特困人员救助供养身份后及时落实照料护理责任，确保在批准之日次月起向散居特困人员提供照料护理服务。各区居家养老服务指导中心要认真做好散居特困人员生活自理能力评估工作，指导街镇居家养老综合服务平台提供散居特困人员照料护理服务。居家养老综合服务平台应如实记录服务台账。散居特困人员基本情况发生变化的，户籍所在区民政部门应及时告知提供服务的居家养老综合服务平台。

（二）2019年11月底前，各区民政部门要100%完成散居特困人员生活自理能力评估，100%完成与散居特困人员签订照料护理协议，100%完善社会救助综合服务信息平台中的特困人员信息；12月底前，照料护理费用100%拨付到位。

（三）各区民政部门应于今年内每月5日、15日、25日前将特困人员照料护理情况表（附件2）盖章报送市民政局（社会救助处），电子版报送到邮箱：jiuzhuchu@gz.gov.cn。市民政局将适时组织开展实地督促检查工作，对于工作扎实、成效明显、亮点突出的地区，将予以总结推广；对于工作滞后、措施不力、群众不满意的地区，将进行全市通报，并约谈当地民政部门主要负责人，确保惠民政策落实到位。
