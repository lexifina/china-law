# 广州市财政局关于转下达2019年中职学校国家奖学金和本专科生国家奖助学金补助资金的通知

市教育局、市体育局，市科协、市总工会，广州大学、广州医科大学：

根据《关于追加下达2019年中职学校国家奖学金和本专科生国家奖助学金补助资金的通知》（粤财科教〔2019〕135号，详见附件1），现将2019年中职国家奖学金822,000元、高校本专科生国家奖助学金1,539,860元转下达给你们（具体项目金额、功能分类科目、政府和部门经济分类详见附件2、3）。同时，就有关事项通知如下：

一、为落实资金安排，请市教育局于2019年10月15日前将中职国家奖学金（822,000元）的分配方案报我局。

二、请各单位认真领会中央、省相关政策精神，不折不扣抓好落实，使建档立卡贫困家庭的学生优先获得资助。

三、请各单位及时做好奖助学金以及2019年春季学期国家助学金的增补工作，并加强资金管理，确保专款专用，切实加快预算执行，发挥财政资金效用，同时接受财政部广东监管局等有关部门的监督。

四、为贯彻落实党的十九大关于“全面实施绩效管理”的决策部署，切实提高财政资金使用效益，请各单位在组织预算执行中对照绩效目标（附件1）做好绩效监控，确保年度绩效目标如期实现。同时，请市教育局将我市绩效目标及时分解，做好预算绩效管理工作。
