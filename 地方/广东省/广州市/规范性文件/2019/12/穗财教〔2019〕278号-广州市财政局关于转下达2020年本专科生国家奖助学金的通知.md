# 广州市财政局关于转下达2020年本专科生国家奖助学金的通知

市教育局、市体育局、市科协、市总工会，广州大学、广州医科大学：

根据《广东省财政厅关于提前下达2020年本专科生国家奖助学金的通知》（粤财科教〔2019〕228号，详见附件1），现将2020年本专科生国家奖助学金2,127万元转下达给你们（具体项目金额、功能分类科目、政府和部门经济分类详见附件2）。待2020年预算年度开始后，按照程序拨付使用。在年度执行中，将按照资金分配办法据实清算和调整，多退少补。

请加强资金管理，提高资金使用效益，同时接受有关部门的监督。
