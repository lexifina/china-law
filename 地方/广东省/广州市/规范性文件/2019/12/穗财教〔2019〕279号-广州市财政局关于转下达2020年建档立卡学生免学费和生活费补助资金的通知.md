# 广州市财政局关于转下达2020年建档立卡学生免学费和生活费补助资金的通知

市教育局、市体育局、市科协、市总工会，广州大学、广州医科大学，越秀区、海珠区、荔湾区、天河区、白云区、花都区、番禺区、南沙区、从化区、增城区财政局：

根据《广东省财政厅关于提前下达2020年建档立卡学生免学费和生活费补助资金的通知》（粤财科教〔2019〕237号，详见附件1），现就有关事项通知如下：

一、将2020年建档立卡学生免学费和生活费补助资金共958.5万元转下达给你们（具体项目金额、功能分类科目、政府和部门经济分类详见附件 2）。转移支付各区使用部分，收入列“1100245 教育共同财政事权转移支付收入”，支出列“205 教育支出”相关项。待2020 年预算年度开始后，按程序拨付使用。请各区按照《财政部关于提前下达转移支付指标工作的补充通知》（财预〔2013〕347 号）的要求，及时做好指标安排和分解下达工作，各区使用部分要全额编列下一年度年初预算，并准确列入相关收支科目。请市教育局将补助市本级的资金及时分配至各相关单位，并于 2020年1月5日前将资金分配方案报送至我局。

二、粤财科教〔2019〕237号附件4中我市应负担的2019-2020学年建档立卡学生补助对口帮扶资金已纳入市教育局2020年部门预算安排，请市教育局按照《关于进一步明确教育精准扶贫精准脱贫工作（2018-2020 年）资金筹措方案的通知》（粤财教函〔2019〕142号）要求，于2020年1月3日前将2019-2020学年建档立卡学生补助对口帮扶资金（详见附件3）支付给梅州市、清远市。

三、请各单位严格按照粤财科教〔2019〕237号文的有关要求做好相关工作，加强财政资金的绩效管理，对本次下达的预算指标和任务，结合省和本地区对财政绩效管理的要求，科学合理确定项目绩效目标，做好绩效管理各环节工作，确保资金发挥绩效。
