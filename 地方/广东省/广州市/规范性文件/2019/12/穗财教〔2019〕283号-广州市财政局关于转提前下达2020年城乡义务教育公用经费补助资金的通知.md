# 广州市财政局关于转提前下达2020年城乡义务教育公用经费补助资金的通知

各区财政局：

根据省财政厅《关于提前下达2020年城乡义务教育公用经费补助资金的通知》（粤财科教〔2019〕226号，见附件），现将省2020年城乡义务教育公用经费补助资金94,823万元（其中中央资金36,658万元、省级资金58,165万元）转下达给你们。该资金收入列2020年“1100245教育共同财政事权转移支付收入”，支出列2020年“20502普通教育”相关项。该项目纳入 “2020年上级补助项目”一级项目下达资金，待2020年预算年度开始后按程序拨付使用。

请各区按照《财政部关于提前下达转移支付指标工作的补充通知》（财预〔2013〕347 号）的要求，及时做好指标安排和分解下达工作，全额编列下一年度年初预算，并准确列入相关收支科目。

请严格按照粤财科教〔2019〕226号文的规定做好相关工作，加强绩效运行监控和绩效评价，确保财政资金安全有效，防止出现挤占、挪用、虚列、套取补助资金等行为。
