# 广州市财政局关于转清算2019年及提前下达2020年普通高中国家助学金和免学杂费补助资金的通知

市教育局、各区财政局：

根据《广东省财政厅关于清算2019年及提前下达2020年普通高中国家助学金和免学杂费补助资金的通知》（粤财科教〔2019〕241号，见附件），现将省2020年普通高中国家助学金和免学杂费补助资金1,047,320元（中央资金425,720元，省级资金621,600元）转下达给你们，其中：市本级资金343,675元，支出列2020年“2050204高中教育”一般公共预算支出科目，政府经济分类列“50902助学金”；各区资金703,645元，收入列2020年“1100245教育共同财政事权转移支付收入”，支出列2020年“2050204高中教育”一般公共预算支出科目。该项目纳入“2020年上级补助项目”一级项目下达资金，待2020年预算年度开始后，按程序拨付。

请市教育局于2020年1月6日前将市本级资金细化方案报我局。请各区按照《财政部关于提前下达转移支付指标工作的补充通知》（财预〔2013〕347 号）的要求，及时做好指标安排和分解下达工作，全额编列下一年度年初预算，并准确列入相关收支科目。

请各单位严格按照粤财科教〔2019〕241号文的规定做好相关工作，加强绩效运行监控和绩效评价，确保财政资金安全有效，防止出现挤占、挪用、虚列、套取补助资金等行为。
