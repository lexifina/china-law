# 广州市财政局关于转下达2020年现代职业教育质量提升计划中央专项资金的通知

市教育局、市体育局、市科协、市总工会，广州大学，番禺区财政局：

根据《广东省财政厅关于提前下达2020年现代职业教育质量提升计划中央专项资金的通知》（粤财科教〔2019〕273号，详见附件1），现将2020年现代职业教育质量提升计划中央专项资金2,373万元转下达给你们（具体项目金额、功能分类科目、政府和部门经济分类详见附件2）。转移支付区使用部分，收入列“1100245 教育共同财政事权转移支付收入”，支出列“20503 职业教育”相关科目。并将有关事项通知如下：

一、此项资金待2020年预算年度开始后，按程序拨付使用。请各单位抓紧将资金安排到具体项目，切实加快预算执行，加强资金监管，不得挤占、截留或挪用，确保专款专用。年终按要求统一编列决算。

二、请区按照《财政部关于提前下达转移支付指标工作的补充通知》（财预〔2013〕347 号）的要求，及时做好指标安排和分解下达工作，要全额编列下一年度年初预算，并准确列入相关收支科目。

三、根据全面实施绩效管理工作要求，提高财政资金使用效益，请各单位加强财政资金绩效管理，对本次下达的预算指标和任务，科学合理确定绩效目标，加强绩效目标监控和绩效评价，确保年度绩效目标如期实现。同时，接受财政部广东监管局的监督。
