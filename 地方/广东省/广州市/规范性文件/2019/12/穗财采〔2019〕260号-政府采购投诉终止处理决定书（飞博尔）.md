# 政府采购投诉终止处理决定书(飞博尔)

投诉人：深圳市飞博尔珠宝科技有限公司

法定代表人：徐淑芳

被投诉人1：广东志正招标有限公司

联系人：张小姐

被投诉人2：广州番禺职业技术学院

联系人：钟老师

投诉人参加了被投诉人1组织的广州番禺职业技术学院珠宝玉石鉴定实训室建设项目（项目编号：440100-201908-106174-0028）采购活动，认为中标供应商投标提交的由北京中再联合检验认证有限公司颁发的《环境管理体系认证证书》和《职业健康安全管理体系认证证书》处于暂停状态、属于弄虚作假行为和谎报行为，向被投诉人1提出质疑并对其答复不满意，2019年11月11日向本机关提起投诉，本机关依法受理并开展调查核实。在调查核实过程中，投诉人于2019年12月2日向本机关递交《撤诉申请书》要求撤诉。

根据《中华人民共和国政府采购法》第十三条第一款、《中华人民共和国政府采购法实施条例》第五十七条第二款和《政府采购质疑和投诉办法》第三十条的规定，本机关决定终止本采购项目的投诉处理程序。

如对上述处理决定不服，可在接到本决定书之日起60 天内向广州市人民政府（地址：广州市越秀区小北路183号金和大厦2楼，电话：83555988）或广东省财政厅（地址：广州市越秀区北京路376号，电话：83170030）提出行政复议申请，或在接到本决定书之日起6个月内直接向人民法院提起行政诉讼。

广州市财政局

2019年12月11日
