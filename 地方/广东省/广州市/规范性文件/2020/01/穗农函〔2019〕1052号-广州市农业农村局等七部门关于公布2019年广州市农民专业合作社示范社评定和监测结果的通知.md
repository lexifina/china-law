# 广州市农业农村局等七部门关于公布2019年广州市农民专业合作社示范社评定和监测结果的通知

各区农业农村主管部门，各有关单位：

根据《广州市农业局等八部门关于印发广州市农民专业合作社示范社评定及监测办法的通知》（穗农〔2015〕96号）精神，我市开展了2019年广州市农民专业合作社示范社评定，并对2009—2018年评出的51家市级农民专业合作社示范社进行监测。按照合作社自评申报、区农业行政主管部门初审并推荐、市农民专业合作社联席会议办公室初核、评审小组现场评定和监测、评定结果网上公示等程序，评定“广州市花都区农华蔬菜专业合作社”等6家农民专业合作社（见附件1）为2019年广州市农民专业合作社示范社；继续保留“广州市白云区水沥红葱农民专业合作社”等46家农民专业合作社（见附件2）广州市农民专业合作社示范社资格；取消“白云区丰华霸王花农产品专业合作社、番禺区华名禽畜养殖专业合作社、从化白玉花生种植专业合作社、从化黄龙杨梅种植专业合作社、从化清绿蔬菜专业合作社”等5家合作社（见附件3）广州市农民专业合作社示范社资格。现予以公布。

附件：1.2019年广州市农民专业合作社示范社名单

2.保留广州市农民专业合作社示范社资格的合作社名单

3.取消广州市农民专业合作社示范社资格的合作社名单
