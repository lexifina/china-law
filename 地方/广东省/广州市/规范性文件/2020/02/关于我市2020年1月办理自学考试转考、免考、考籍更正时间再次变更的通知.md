# 关于我市2020年1月办理自学考试转考、免考、考籍更正时间再次变更的通知

(

结合当前疫情防控情况，我市1月办理自学考试转考（转出外省、外省转入、合并准考证）、免考、考籍更正的时间，再次变更为2020年2月10日。上述各项业务办理流程及要求、地点，可通过本网站“自学考试栏目——自考服务平台——办理须知”（网址：http://gzzk.gz.gov.cn/zxks/blxz/）中查阅。

)

结合当前疫情防控情况，我市1月办理自学考试转考（转出外省、外省转入、合并准考证）、免考、考籍更正的时间，再次变更为2020年2月10日。上述各项业务办理流程及要求、地点，可通过本网站“自学考试栏目——自考服务平台——办理须知”（网址：https://gzzk.gz.gov.cn/zxks/blxz/）中查阅。

另，2月25日仍按现有规定时间及要求办理转考（除转出外省业务外）、免考、考籍更正业务。

广州市招生考试委员会办公室

2020年2月1日
