# 广州市商务局中国银行广州分行关于推出广州市“扩内需、稳外需、助企赢”专属金融服务的通知

各区商务主管部门，中国银行广州市各管辖分支行：

为深入贯彻习近平总书记关于坚决打赢疫情防控阻击战的重要指示精神，全面落实党中央、国务院关于疫情防控的决策部署和市委、市政府有关工作要求，积极应对疫情带来的不利影响，广州市商务局会同中国银行广州分行联合为广州市外贸、商贸物流等疫情防控物资保供企业推出“扩内需、稳外需、助企赢”专属金融服务，全力支持有关企业复工复产和持续发展。

一、支持方向

（一）为应对疫情提供医用防护服、隔离服、医用及具有防护作用的民用口罩、医用护目镜、新型冠状病毒检测试剂盒、负压救护车、消毒机、消杀用品、红外测温仪、智能监测检测系统和相关药品等物资运输的物流企业,境外采购疫情防护物资的外贸企业。

（二）复工复产的外贸企业、商贸物流企业。

（三）为应对疫情提供重要生活必需品境外采购和运输服务的外贸企业、商贸物流企业。

（四）为应对疫情提供相关生产原材料、设备境外采购和运输服务的外贸企业、商贸物流企业。

（五）为应对疫情提供仓储、配送等服务的商贸物流企业。

支持企业以中国人民银行总行“全国性重点企业”、广东省疫情防控重点保障企业名单的企业及广州市商务局提供的企业名单为准。

二、专属服务

（一）专属融资通道

1.流动资金贷款

加大企业信贷支持力度，降低资金成本，对中国人民银行总行“疫情防控重点保障企业名单”企业给予最优惠利率，确保符合条件的企业在享受政府财政贴息后实际融资利率低于1.6%；对纳入广东省疫情防控重点保障名单业及广州市商务局提供的重点外贸和商贸物流企业，优先保障信贷规模，一年期流动资金贷款优惠利率最低可至3.15%。

对于受疫情影响较大的小微企业，授信客户提供无还本续贷、展期、增额等支持措施；开通专属融资服务，给予优先放款，单笔300万元以下的普惠金融贷款支持企业线上自主提款；为在中行办理代发薪的小微企业预先核定信用贷款额度，支持相关企业提款用于发放工资，稳定就业；全力支持涉及疫情防控所需药品、物资的小微企业主、个体工商户，予以最高50万元一年期信用贷款的专项政策支持，企业无须承担任何手续费。

中国银行广州分行对广州市商务局推荐的企业，承诺1个工作日内主动对接客户，对于符合国家政策和信贷基本条件的企业实际资金需求，实施“三个即时”（即时上报、即时审查、即时放款），给予优先支持。

2.固定资产贷款

对疫情防控直接相关的企业生产设备、运输设备、仓储物流设施、信息平台改造等提供固定资产贷款支持，根据实际采购需求给予中长期授信额度，并灵活设计还款期限和担保方式，为符合条件的重点企业提供最优惠的贷款利率。

3．票E贴服务

提升票据贴现业务处理效率，着重引导企业通过“中银票E贴”线上申请办理。

4．贸易融资综合服务

满足企业多样化融资需求，提供包括商业发票贴现、综合保理、汇出汇款融资、订单融资、福费廷、出口信保融资在内的多品种贸易融资产品。

（二）专属结算便利

1．在线结算及融资服务

为便利企业结算融资，为企业提供企业网银线上渠道跨境汇款、外币结汇、汇入汇款性质确认与申报、信用证、保函等结算及贸易融资服务。

2．现金管理平台

为便捷企业资金管理，集团客户可通过现金管理平台进行账户管理、收付款管理、跨境资金管理、风险管理等，借助该平台投融资管理功能，通过主账户向银行透支取得临时性信贷资金。

（三）专属保障服务

1．信用担保服务

为帮助外贸企业应对疫情带来的信用风险、降低融资成本，中国银行广州分行提供信用证、保函等产品满足企业特殊时期运营需求，特别是利用品牌资信优势，提供电子汇总征税保函提高进口货物报关、通关效率，实现“先通关、后缴税”；利用全球化网络、多元化平台优势，提供海外代付、协议付款、内保外贷、外保内贷、内保直贷等跨境联动服务。

2．资金交易服务

便利企业汇率避险，疫情期间外贸企业可通过绿色通道开通线上平台在线办理汇率避险产品，并享受外汇资金专属保值增值产品及服务。

三、工作要求

（一）广州市商务局适时将重点外贸和商贸物流企业名单汇总提供给中国银行广州分行，中国银行广州分行将优先与名单中的企业进行对接，提供专属的金融服务支持，并向广州市商务局及时反馈服务信息；中国银行广州分行各辖属分支行应主动对接本区商务主管部门及重点企业，提供金融服务专业意见，并做好企业评估和上报工作。

（二）中国银行广州分行各级机构以优质、快捷、高效的金融服务助力疫情防控工作，对清单内企业提出的金融服务需求快速响应，确保金融服务顺畅。清单企业可与中国银行广州分行各管辖分支行对公业务人员联系，提出专项金融服务申请。中国银行在24小时内完成应急响应，在三个工作日内对符合条件的企业完成审批流程。

（三）中国银行广州分行将根据企业实际业务需求，按照内部风险审批流程和市场化原则，严格落实“展业三原则”，确保业务真实性，依法合规地向企业提供各类专属金融服务。
