# 关于公布我市2020年1月广东省自学考试成绩的通知

(

2020年1月广东省自学考试成绩将于3月31日公布，现将公布本次考试成绩的有关事项通知如下：

)

各区招考办，各自学考试有关考生：

2020年1月广东省自学考试成绩将于3月31日公布，现将公布本次考试成绩的有关事项通知如下：

一、考试成绩公布

2020年1月广东省自学考试成绩由省教育考试院统一公布， 3月31日15时，省教育考试院将通过广东省自学考试管理系统（https://www.eeagd.edu.cn/selfec/）、官微（ID：gdsksy）和广东教育考试服务网（http://www.eesc.com.cn/）向考生提供成绩查询。

二、网上申请课程合格证书

目前广东省自学考试考生在办理申请毕业登记等相关手续时不再需要提供纸质的单科课程合格证书，考试成绩、考籍数据等信息均以广东省自学考试管理系统中的记录为准。考生一般不再需要特意去领取，个别确有需要的，将由考生个人在规定的时间内， 4月6日- 9日自行在网上登记申请领取课程合格证书（https://zikao.gzzk.cn/student/hgzdj.asp），各区考办根据登记记录发放当期的《广东省高等教育自学考试课程合格证书》（发放地址见附件），过期不予补办，合格证书发放时间为4月28日，特殊情况合格证书发放时间另行通知。

三、考试成绩复查

按照国家和省关于做好新冠肺炎疫情防控的工作部署，本次考试成绩复查申请推迟进行，相关的时间安排，将根据我省疫情防控情况另行公布。

请考生持续关注广州招考网、广州招考微信公众号发布的相关信息。
