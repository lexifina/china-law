# 广州市商务局关于邀请参加2020年广州重点境外展会推荐目录评选的通知

各有关境外展览会组展单位：

为贯彻落实国家关于外贸高质量发展的工作要求，加大支持我市企业开拓多元化国际市场的力度，我局将于近期制定2020年广州重点境外展会推荐目录（以下简称“目录”），并采取竞争性评选的方式选择展会，入选目录内的每个展会将对应确定唯一组展单位。现就有关事宜通知如下：

一、展会举办地点及时间要求

展会举办地在境外（含香港、澳门、台湾地区）的展会可参评本目录，优先考虑“一带一路”沿线国家和新兴市场。展会举办时间为2020年5月1日-12月31日。

二、展会举办形式

形式不限，优先考虑以展中展或广州商品自办展形式举行的广州企业整体抱团参展项目；优先选择专业类展会。

三、需提交材料

（一）广州市2020年重点境外展会推荐目录参评项目基本信息表；

（二）组展单位营业执照；

（三）组展单位2019年1-12月份的财务报表或审计报告；

（四）组展单位基本情况介绍、2019年在境外组展情况；

（五）拟申报展会2020年的情况及工作报告（需含以下基本信息：展会举办时间、地点、规模、已连续举办届数、主要展品类别、是否已入选国家/省级重点境外展会推荐目录等基本信息）、2020年举办该展会拟向企业收取的所有费用及明细，如展位费报价（以单一展位、按9㎡计算）等；

（六）该展会2019年参展的情况总结、广州参展企业名单、广州参展企业合同复印件以及收取广州参展企业展位费有关凭证；

（七）2019-2020年该展会广州企业续约率证明材料（与同一企业签订的合同、付款凭证等）；

（八）承诺书。包含招展任务完成情况、承诺无套取政府专项资金扶持等违法行为等。

五、其他要求

有意参加的组展单位请将申报材料一式四份并装订成册（装订标准见附件），加盖组展单位公章，于4月5日前报送至广州市商务局（对外贸易发展处），材料（一）电子版请发至邮箱hebing@gz.gov.cn。

特此通知。
