# 广州市发展改革委关于广州市白云沙亭岗新社区棚改项目节能报告的审查意见

原则同意本项目节能报告（统一项目代码为：2019-440111-47-01-026197）。项目年综合能耗为7400.53吨标准煤（当量值），电力消耗量为4606.14万千瓦时。项目住宅部分年单位建筑面积综合能耗为7.07千克标准煤/平方米，年单位建筑面积电耗为40.65千瓦时/平方米；项目配套公建部分年单位建筑面积综合能耗为9.41千克标准煤/平方米，年单位建筑面积电耗为77.35千瓦时/平方米；项目学校部分年单位建筑面积综合能耗为7.15千克标准煤/平方米，年单位建筑面积电耗为40.21千瓦时/平方米；项目幼儿园部分年单位建筑面积综合能耗为8.08千克标准煤/平方米，年单位建筑面积电耗为43.27千瓦时/平方米；项目地下室年单位建筑面积综合能耗为1.04千克标准煤/平方米，年单位建筑面积电耗为8.33千瓦时/平方米。
