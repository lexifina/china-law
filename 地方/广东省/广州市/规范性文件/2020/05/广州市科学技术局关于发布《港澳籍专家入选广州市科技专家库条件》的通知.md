# 广州市科学技术局关于发布《港澳籍专家入选广州市科技专家库条件》的通知

各有关单位：

为进一步发挥港澳科技专家在广州市科技创新发展中的决策作用，为重大项目评审提供有力支撑，助力粤港澳大湾区国际科技创新中心建设，现发布《港澳籍专家入选广州市科技专家库条件（试行）》，公开征集港澳籍专家。

港澳籍专家入库后，按照《广州市科技专家库管理办法》（穗科创规字〔2018〕3号）使用管理，享有相应的权利和义务。

一、申请流程

（一）请有意向申请入库的港澳籍专家填写《账号申请信息采集表》（附件3），并将表格发送至邮箱kuangminling@gz.gov.cn，申请广州市科技业务管理阳光政务平台账号。

（二）账号生成后，将通过邮件反馈专家账号信息，请专家登录广州市科技业务管理阳光政务平台（http://sop.gzsi.gov.cn），登录后点击“个人信息维护”进入信息填报入口，按指引填写相关信息并提交。

（三）完成信息填写后，请打印《广州市科技专家推荐表》并加盖所在单位公章。《广州市科技专家推荐表》和有关证明材料纸质件请邮递至广州市越秀区下塘西路37号502室，广州生产力促进中心信息工程部收。
