# 广州市商务局关于拨付2019年广州市商务发展专项资金商务诚信和肉菜流通追溯事项肉菜流通追溯方向第二批资金的通知

各有关企业：

根据《广州市商务委关于印发2019年广州市商务发展专项资金商务诚信和肉菜流通追溯事项预算项目库申报指南的通知》（穗商务秩函〔2018〕82号）的相关规定，经审核，现将2019年广州市商务发展专项资金商务诚信和肉菜流通追溯事项肉菜流通追溯方向第二批资金拨付给你单位。

请你单位收到资金后，按现行财务会计制度作账务处理，建立完善的项目和财务档案管理制度，并自觉接受有关部门的监督检查，配合做好专项检查、绩效评价和审计等资金管理工作。

专此通知。

附件：2019年广州市商务发展专项资金商务诚信和肉菜流通追溯事项肉菜流通追溯方向第二批资金安排表
