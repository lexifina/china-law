# 广州市科学技术局关于组织参加第28届广州博览会的通知

各有关单位：

广州博览会是广州市人民政府主办的中外经贸合作的大型综合性展会，是我市与国内外友好地区和城市开展区域合作、发挥广州国家中心城市和粤港澳大湾区建设核心引擎作用的重要交流平台，也是广州市联系对口支援和帮扶地区的重要纽带，在国内各地政府举办的综合性展会中具有较大的影响力和较高的知名度。根据市政府的安排，今年将举办第28届广州博览会，我局将在本届博览会设立“科技创新展区”，展示我市近年来的科技创新成果，该展区的招展和布展工作由全国科研新技术新产品展销中心负责。现将有关事项通知如下：

一、展览内容和招展对象

（一）政策展示：主要展示我市在抗疫情期间所发布的各类扶持政策，包括科技政策、扶企政策、税收优惠政策等。

（二）高科技产品展示：“IAB”（新一代信息技术、人工智能、生物医药）产业与“NEM”（新能源、新材料）产业为主导、贴近民生的高科技产品或科技成果等。

二、展览规模和方式

展区面积约396平方米，为了更好地展示广州科技创新成果，增强展会效果，“科技创新展区”将实行统一特装,参展单位需提供展板喷画的设计稿文件，由我局统一制作。展示形式以展板和实物相结合，展区设有LED大屏幕，可供参展单位视频播放。

三、参展费用

本展区不收取参展企业展位费，展品运输等其他费用由企业自理。

四、展览时间及要求

（一）展览时间：2020年8月28日至31日（4天）

（二）布展时间：2020年8月25日至27日（3天）

（三）撤展时间：2020年8月31日中午12:00后

（四）展览地点：中国进出口商品交易会A区1.2展馆（广州市海珠区阅江中路380号）

（五）各参展企业优先推荐本单位优秀项目和技术含量高的项目参展，通过图片、实物、简要文字介绍等形式展示。

（六）各参展企业请于7月24日前将《参展报名表》通过邮箱方式发送到全国科研新技术新产品展销中心。

请各区科技部门、园区认真组织有关单位积极报名参加，并按要求做好参展工作。
