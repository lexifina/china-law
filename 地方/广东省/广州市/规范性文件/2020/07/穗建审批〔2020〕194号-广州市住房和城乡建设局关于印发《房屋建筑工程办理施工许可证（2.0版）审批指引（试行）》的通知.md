# 广州市住房和城乡建设局关于印发《房屋建筑工程办理施工许可证（2.0版）审批指引（试行）》的通知

各区住建局，广州空港委国土规划和建设局，南沙开发区审批局、广州开发区审批局，市建设工程质量监督站、市建设工程安全监督站，各有关单位：

市工程建设项目审批制度改革试点工作领导小组办公室于2020年6月1日发布实施《关于优化实施房屋建筑工程办理施工许可证（2.0版）的通知》（穗建改〔2020〕11号）。为统一标准，规范指引全市施工许可审批，现配套印发《房屋建筑工程办理施工许可证（2.0版）审批指引（试行）》。执行过程中如有问题和意见，请径向市住房城乡建设局反馈。我局在试行基础上，不断优化更新指引内容。

特此通知。

广州市住房和城乡建设局

2020年7月15日
