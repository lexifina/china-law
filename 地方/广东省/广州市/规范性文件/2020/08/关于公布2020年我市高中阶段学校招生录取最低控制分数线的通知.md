# 关于公布2020年我市高中阶段学校招生录取最低控制分数线的通知

(

经市中招工作领导小组研究批准，现将2020年我市高中阶段学校招生各批次录取最低控制分数线予以公布。

)

各区教育局、招考办，各有关学校：

经市中招工作领导小组研究批准，现将2020年我市高中阶段学校招生各批次录取最低控制分数线予以公布。

特此通知。

广州市招生考试委员会办公室

2020年8月10日
