# 广州市农业农村局关于市第十五届人大第五次会议第20202115号建议答复的函

宋俊文等代表：

您提出的《推动完善“现代都市农业”标准体系创新岭南特色现代都市农业模式》（第20202115号建议）收悉。市政府高度重视，积极组织我局会同市商务局、文化广电旅游局、规划和自然资源局、发展改革委、工业和信息化局认真研究办理，并与您在8月7日进行座谈交流，8月25日进行电话沟通。经综合相关会办单位意见，现将办理有关情况答复如下：

您提出制定、完善岭南特色的“现代都市农业”发展纲要、标准体系和配套政策建议，有利于促进我市农业转型升级，加快农业农村现代化。

都市农业是地处都市及其延伸地带，紧密依托都市的科技、人才、资金、市场等优势，并以优质新鲜农副产品和良好生态环境等服务于都市的农业。它以农业高科技武装的园艺化、设施化、工厂化生产为主要手段，融生产性、生活性和生态性于一体，实现农业高质高效和可持续发展。《全国乡村产业发展规划（2020-2025年）》指出，依托都市农业生产生态资源和城郊区位优势，发展田园观光、农耕体验、文化休闲、科普教育、健康养生等业态，建设综合性休闲农业园区、农业主题公园、观光采摘园、乡村民宿和休闲农庄，满足城市居民消费需求。发展都市农业，推进农业规模化、标准化、集约化、生态化发展，纵向延长农业链条，横向拓展农业功能，助力农业强、农村美、农民富。市委实施乡村振兴战略领导小组办公室印发的《广州市乡村振兴战略规划（2018-2022年）》明确规划“发展枢纽功能突出的都市现代农业”，提出“做优做强乡村优势传统产业，培育壮大新兴产业，深化一二三产业融合发展，构建集散功能突出的都市现代农业产业体系、生产体系、经营体系”，重点抓好调优都市现代农业布局、建设广州现代农业枢纽中心、打造现代农业产业园区、打造粤港澳大湾区“菜篮子”基地等重要工作，并取得积极成效。在市委、市政府正确领导下，在乡村振兴战略领导小组各成员单位共同努力下，我市乡村振兴工作取得积极成效。2019年，全市实现农林牧渔业总产值446.3亿元，同比增长3.2%；第一产业增加值251.4亿元，同比增长3.9%，增速创近10年来新高。

一、主要做法

（一）推进粤港澳大湾区“菜篮子”工程建设。2018年9月以来，在各级领导和有关部门大力支持下，广州以“政府主导、企业主体、市场行为”建设模式大力推进粤港澳大湾区“菜篮子”平台建设。通过向国内外市场输送丰富优质农产品，推动广州打造成为全国优质农产品加工进出口集散地，实现惠民惠商最大化。采用“三个一”运行模式，即：“一个标准供应、一个平台流通、一个体系监管”。平台于2019年9月28日建成运行，已有23个省（区）的111个地级以上合作城市、808个粤港澳大湾区“菜篮子”生产基地、71家产品加工企业，在全国布局15个配送中心或分中心，编制蔬菜、水果、畜禽和蜂产品、水产品、乳及乳制品、食用油及油料产品共六大类监控指标体系，总限量指标值达21210项次，完成《粤港澳大湾区“菜篮子”平台产品质量安全指标体系 蔬菜》《粤港澳大湾区“菜篮子”平台产品质量安全指标体系 水果》《粤港澳大湾区“菜篮子”标识使用规范》3项团体标准编制说明、征求意见，计划于9月下旬发布。共溯源登记超过1500个农产品，产品累计流通量超过24.7万吨。启用粤港澳大湾区“菜篮子”通关（增城）便利区、粤港澳大湾区“菜篮子”展示交易（安圣）中心、粤港澳大湾区“菜篮子”平台指挥中心江南市场工作服务站，促进粤港澳大湾区“菜篮子”生产加工经营主体与市场销售主体有效衔接。

（二）推进现代农业产业园建设。按照突出高科技、集约化、全链条、大品牌的建设思路，围绕“主导产业突出、现代要素集聚、设施装备先进、生产方式绿色、辐射带动有力”的建设要求，组织各区根据区内优势产业，实施以优质蔬菜、岭南水果、花卉、水产、畜牧等为主导产业的产业园建设活动。目前，我市全力创建15个省级现代农业产业园，位列珠三角地区自筹资金建设现代农业产业园的首位，基本实现主要产业、主要涉农区全覆盖。其中，从化区现代农业产业园获批纳入2020年国家现代农业产业园创建管理体系的省级现代农业产业园名单（全国共8家）。

（三）打造现代化生产基地。积极转变农业发展观念，从产量效益型向质量效益型转变，大力引导农业绿色发展、高质量发展，利用先进理念、领先技术、标准化设施打造一批现代化规模种养基地。目前全市建立市级以上农业标准化示范区92个,其中国家级15个，省级21个，市级56个；建有农业农村部畜禽养殖标准化示范场9家、水产健康养殖示范场31家。

（四）发展特色优势农产品。深入贯彻落实省关于发展富民兴村产业的工作部署，立足资源禀赋，突出乡土特色，扎实推进“一村一品、一镇一业”建设。全市获评国家“一村一品”示范村3条、省级专业镇12个、省级专业村102条、市级专业村108条。大力推进农业品牌建设，我市有效期内广东省名牌产品（农业类）182个，总量居全省首位。获评的名牌产品覆盖粮食、蔬果、畜禽产品、水产品、种苗、饲料及饲料添加剂等多个品类。打造广东省名特优新农产品区域公用品牌24个，6个农产品入选全国名特优新农产品名录；增城迟菜心入选中国农业品牌目录2019农产品区域公用品牌。

（五）推进都市农业绿色发展。鼓励使用有机肥和生物农药，去年有机肥使用量超过1.7万吨，下达财政补贴资金约600万元，农药化肥使用量实现持续负增长。全面推广绿色健康生态养殖模式，率先在全省完成20.4万亩连片50亩以上鱼塘养殖水治理，畜禽粪污综合利用率达到85.84%，提前完成国家、省定2020年的目标任务。

（六）发展观光休闲农业。把发展观光休闲农业作为促进城乡产业融合的重要抓手，成功培育省级休闲农业与乡村旅游示范点20个、示范镇6个，省、市级农业公园和市级农业公园创建单位达到106个。“五一”前夕106家农业公园和农业公园创建单位集中开园，5月2日央视《新闻联播》进行相关报道。据不完全统计，“五一”期间全市农业公园和农业公园创建单位共接待游客45万人次，营业收入近2000万元，带动周边乡村餐饮、住宿等服务行业收入达2600多万元，有效拉动我市都市现代农业经济增长。

（七）发展数字农业。加快数字农业发展，为现代农业提供技术保障。研究编制《广州市加快推进数字新基建发展三年行动计划（2020-2022年）》，拟以数字新基建与融合应用相结合，运用新基建的网格化、数字化、智能化优势赋能生产、生活、科技、智慧城市各领域，目前正在公开征求意见。印发《广州市加快5G发展三年行动计划（2019-2021 年）》，以5G网络建设夯实广州智慧城市基石，推动 5G+智慧农业，探索建设广州市增城区5G智慧农业实验区，构建以5G、物联网、大数据为核心技术的综合性智慧农业应用系统，有效整合现有资源，加快推动信息技术与农业产业融合发展。开展场景征集，推进数字技术应用，面向全市征集一批互联网、大数据、人工智能和实体经济深度融合应用案例。通过问卷调查、调研座谈以及专家评审等方式，遴选 73 个优秀数字技术解决方案，在智慧农业领域公布“智慧渔业信息化管理服务平台”“艾米5G数字农田”“从化华隆荔枝产业大数据平台开发项目平台”“FPF 未来猪场智能引擎在集群式楼房智能化猪场的应用”等优秀案例。开展区块链项目征集并评审出15个优秀应用案例，在食药品溯源领域公布“基于大数据和区块链的食药品溯源系统应用示范”等优秀案例，输出现代农业成果。

（八）发展农村电子商务。发动电商平台设立扶贫专区，利用流量支持，为疫情期间贫困地区优质农特产品网上销售提供便利，对入驻电商平台的商户给予政策优惠，为当地电商发展提供技术支持和产品品牌化指导等服务。利用直播电商扩大农特产品销量，充分利用直播电商全景呈现、引流带货、实时互动等特点，帮助贫困地区优质农特产品线上销售，打造“直播电商+扶贫助农”新模式，带动贫困地区农民增产增收。支持电商企业疫情期间通过网络直播将贫困地区优质农产品输送到全国各地，助力我市消费扶贫工程。鼓励社交电商培育当地农特产品牌，支持广州风行集团“风行生活”创新营销模式，充分发挥 O2O 电商平台线下连锁专卖店的前置仓功能，收购从化等区农产品，努力解决农产品进城难问题。引导生鲜电商销售滞销农产品，发挥盒马鲜生、京东、风行生活等生鲜电商能够将农产品从田头直达消费终端的优势，精准对接销售因疫情滞销的农产品。

二、下步工作计划

（一）开展《广州市现代农业产业布局规划》等编制，优化都市现代农业产业布局。科学开展《广州市现代农业产业布局规划》等材料编制工作，以都市农业全产业链发展为方向，进一步完善“现代都市农业”发展纲要、标准和配套政策。通过重大农业项目建设，树立一批都市农业发展示范基地。借助实施乡村振兴有利契机，统筹发动政府各部门共同助力乡村产业发展，同时，结合科技下乡、职业农民培训等多种方式，加深各级政府部门和企业对“现代都市农业”的认识了解，形成共识，推动形成融合发展新模式。

（二）深化粤港澳大湾区“菜篮子”建设，增强我市都市农业辐射带动作用。围绕“立足广州、联结泛珠、服务湾区、辐射内地、面向全球”目标定位，着力打造标准化、现代化、便利化服务平台，着力打造“一平台带两端”格局，构建以广州为枢纽的粤港澳大湾区“菜篮子”生产及流通服务体系，推动粤港澳大湾区“菜篮子”生产加工基地拓展到全国各地优势产区，形成强大的辐射带动和示范效应。

（三）加快现代农业产业园和重点项目建设，提升我市都市农业发展质量。继续抓好省级现代农业产业园创建工作，围绕发展都市现代农业这一根本方向，突出高科技、集约化、全链条、大品牌，打造全省现代农业的示范样板。加大财政扶持力度，落实产业振兴项目用地保障政策，推进生猪、粮食、蔬菜、水果、水产品、花卉等重要农产品的现代化规模化基地建设。

（四）着力打造一批现代化农业公园，增强我市都市农业吸引力。结合乡村振兴战略实施，加强农业与旅游业、创意产业等融合，培育升级一批各具特色的现代化农业公园，打造我市观光休闲农业发展新名片,为广大市民提供更多观光休闲、旅游休闲的好去处。

（五）加快数字农业和农村电子商务发展，提升农业智慧化水平。通过广州市工业和信息化产业发展资金，扶持一批面向小农户的信息综合服务企业和信息应用主体，为小农户提供定制化、专业化服务。进一步开放场景，鼓励新一代信息技术企业不断增强新产品、新应用的供给，提升农业智慧化水平。研究出台《广州市农村电子商务示范企业认定办法》，认定一批我市农村电子商务示范企业；继续指导电商平台开设扶贫专区，推动农产品和休闲农业上网营销；依托市农村电商行业协会等，开展农村电商知识培训，培养农村电商专业人才。

（六）促进一二三产业深度融合发展，提高我市都市农业综合效益。着力提升本地农产品加工业水平，建设一批高标准农产品生产加工基地，提高农产品加工水平，加大生物、环保、信息等技术与农产品加工业的融合力度，适应市场和消费升级需求。大力发展观光休闲旅游农业，推进观光休闲旅游农业与其他产业深度融合。

再次诚挚感谢您对我市都市现代农业工作的关心和支持！欢迎您继续对我们的工作提出宝贵的意见和建议。

广州市农业农村局
