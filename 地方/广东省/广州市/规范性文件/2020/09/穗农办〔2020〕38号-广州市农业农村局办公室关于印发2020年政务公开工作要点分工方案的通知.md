# 广州市农业农村局办公室关于印发2020年政务公开工作要点分工方案的通知

机关各处室、局属各单位：

根据《广州市全面推进基层政务公开标准化规范化工作实施方案》《广州市2020年政务公开工作要点分工方案》等文件，为贯彻落实市政务公开工作部署，局办公室研究制定了《广州市农业农村局2020年政务公开工作要点分工方案》，经局领导同意，现印发给你们。

各处室、单位要落实业务主责，牵头处室和单位要主动抓好落实，会办处室和单位要做好对接配合，确保及时公开相关政府信息。各牵头处室、单位要注意保存好工作资料，以备年度考核查验。局办公室将继续加强政务公开工作督查督办，适时对工作落实情况进行通报。

广州市农业农村局办公室

2020年9月10日
