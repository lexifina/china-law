# 广州市财政局关于回收中央财政2019年医疗服务与保障能力提升（医疗卫生机构能力建设）补助资金的通知

市卫生健康委：

根据《广东省财政厅关于调剂中央财政2019年医疗服务与保障能力提升（医疗卫生机构能力建设）补助资金的通知》（粤财社〔2020〕196号，详见附件），现回收《关于下达2019年第三批中央财政补助医疗卫生机构能力建设资金的通知》（粤财社〔2020〕170号）安排给广州和平骨科医院的补助资金100万元（资金明细详见附件）。

请你委按照有关规定，尽快退回2019年第三批中央财政补助医疗卫生机构能力建设资金指标。
