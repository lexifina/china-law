# 广州市财政局中国人民银行广州分行营业管理部关于印发广州市市本级预算单位银行账户管理办法的通知

市直各单位，国家开发银行广东省分行、广州地区各政策性银行、国有商业银行、邮政储蓄银行、股份制商业银行、城市商业银行、农村商业银行：

为深化财政国库管理制度改革，适应财政预算管理“放管服”改革要求，进一步规范和完善广州市市本级预算单位银行账户管理，根据有关法律、法规和规章规定，结合我市实际，市财政局、中国人民银行广州分行营业管理部联合修订了《广州市市本级预算单位银行账户管理办法》，现印发给你们，请遵照执行。

广州市财政局 中国人民银行广州分行营业管理部

2020年9月7日
