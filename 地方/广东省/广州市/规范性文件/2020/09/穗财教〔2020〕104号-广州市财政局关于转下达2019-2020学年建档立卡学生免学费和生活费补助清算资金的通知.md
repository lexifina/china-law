# 广州市财政局关于转下达2019-2020学年建档立卡学生免学费和生活费补助清算资金的通知

市教育局，从化、增城区财政局：

根据《广东省财政厅关于清算下达2019-2020学年建档立卡学生免学费和生活费补助资金的通知》（粤财科教〔2020〕174号，详见附件1），现将2019－2020学年建档立卡学生免学费和生活费补助资金184万元转下达给市教育局，并回收从化、增城区23.81万元（具体项目金额、功能分类科目、政府和部门经济分类详见附件2），回收资金纳入2020年市区财政资金年终清算。

请市教育局对此项资金作进一步细化，并按照《广州市人民政府关于深化市级预算管理改革防范财政运行风险的意见》（穗府函〔2018〕246号）对细化分配方案审核把关后办理资金拨付手续，落实对资金使用的后续跟踪管理，同时结合粤财科教〔2020〕174号文的规定做好相关工作。
