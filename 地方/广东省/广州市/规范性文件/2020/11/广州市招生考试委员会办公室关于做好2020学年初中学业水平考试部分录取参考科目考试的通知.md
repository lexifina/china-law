# 广州市招生考试委员会办公室关于做好2020学年初中学业水平考试部分录取参考科目考试的通知

(

根据《广州市教育局关于进一步深化高中阶段学校考试招生制度改革的实施意见》（穗教规字〔2018〕8号）、《广州市教育局关于印发〈广州市初中学业水平考试地理生物学信息技术音乐美术等科目考试实施方案（试行）〉的通知》要求，结合我市常态化疫情防控和教育教学实际，现就做好2020学年初中学业水平考试信息技术及音乐、美术现场操作考试的有关事项通知如下：

)

各区教育局，各有关中学：

根据《广州市教育局关于进一步深化高中阶段学校考试招生制度改革的实施意见》（穗教规字〔2018〕8号）、《广州市教育局关于印发〈广州市初中学业水平考试地理生物学信息技术音乐美术等科目考试实施方案（试行）〉的通知》要求，结合我市常态化疫情防控和教育教学实际，现就做好2020学年初中学业水平考试信息技术及音乐、美术现场操作考试的有关事项通知如下：

一、报名

（一）报名对象。

1．具有我市初中学籍的九年级在校学生。

2．具有我市户籍、在外市初中学校就读且计划参加我市2021年高中阶段学校招生录取的九年级学生（简称“外地返穗生”，下同）。

（二）报名时间和办法。

1．具有我市初中学籍的九年级在校学生，由初中学校按照《广州市招生考试委员会办公室关于做好2021年我市高中阶段学校考试招生报名准备工作的通知》要求，11月30日前在“广州市教育综合管理系统”完成姓名、证件号、性别、班级等学籍信息的核验。考生是港澳台身份的，须及时办理港澳台居民居住证，并在学籍系统中更新为港澳台居民居住证证件号。核验无误后，市招考办根据学籍数据统一生成报名数据。报名数据导入广州市初中学业水平考试服务平台后，由初中学校在2020年12月11日前登录平台完成考生名单与信息核对。

2．外地返穗生需在2020年12月7至11日登录报名信息登记网址（http://exam.gzzk.cn/exapi/cj），按照指引填写报名信息，上传身份证、户口簿、学籍信息表等报名资料，完成后确认提交。报名资格由户籍所在区招考办进行审核。网上报名确实存在困难的外地返穗生，可拨打户籍所在区招考办电话进行咨询或预约，按工作人员指引进行报名。已报名参加我市2020年7月的初中学业水平考试地理、生物学考试的外地返穗生无需再次报名，由户籍所在区招考办直接安排和通知考试。

考生须保证报名信息真实、准确，对通过弄虚作假取得报名资格的考生，一经发现将按相关规定取消报名资格，已参加考试的按相关规定取消考试成绩。

（二）考试组织。

1．信息技术考试实行全市统一命题，各区在规定的时间内组织上机考试，考试成绩由计算机自动评定。

2．音乐、美术现场操作考试由学校负责组织实施，考试指引详见附件1和附件2。学校在2020年12月30日前通过广州市初中学业水平考试服务平台上报成绩。返穗生不计算音乐、美术现场操作考试成绩，音乐、美术考试成绩为上机考试或闭卷笔试成绩（满分70分）×100÷70。

3．为防控疫情，减少考生交叉接触，信息技术考试及音乐、美术现场操作考试考点原则上设置在各初中学校。外地返穗生由户籍所在区招考办统筹安排考点。

三、工作要求

（一）初中学业水平考试是义务教育阶段的终结性考试，主要衡量学生达到国家规定学习要求的程度，其考试成绩是学生毕业和升学的基本依据。各区教育局和初中学校要做好相关政策宣传解读和报名发动工作，不得拒绝、阻止或变相劝阻任何符合报名条件的学生报名，要对考生提供报考便利和咨询服务，做好外地返穗生网上报名指引工作。

（二）各区教育局和初中学校要在规定时间内认真细致地做好学籍数据、报名数据的核验校对，确保考生信息真实、准确。要提醒尚未办理身份证、港澳台居民居住证的考生及时办理，以便顺利参加考试。

（三）各区教育局和初中学校要把考生的生命安全和身体健康放在第一位，制定报名和考试疫情防控工作方案，加强报名、考试场所环境卫生消毒和通风，落实预约办理及健康检查制度，确保报名、考试工作安全进行。
