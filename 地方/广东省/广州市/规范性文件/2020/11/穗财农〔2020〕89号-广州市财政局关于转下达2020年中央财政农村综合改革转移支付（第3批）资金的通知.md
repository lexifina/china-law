# 广州市财政局关于转下达2020年中央财政农村综合改革转移支付（第3批）资金的通知

市农业农村局，从化、增城区财政局：

根据《广东省财政厅关于下达2020年中央财政农村综合改革转移支付（第3批）资金的通知》（粤财农〔2020〕93号，附件1）和市农业农村局分配计划，现将2020年中央财政农村综合改革转移支付（第3批）资金和绩效目标转下达给你们（附件2），并就有关事项通知如下：

一、本次下达的资金，支出列“21307 农林水支出—农村综合改革”，经济科目根据支出性质与实际用途列支，年终编报支出决算。

二、请市农业农村局督促指导相关区严格按照有关规定，加强资金使用管理，及时将资金安排到具体项目，加快预算执行。加强财政资金绩效管理，充分发挥资金使用效益，确保年度绩效目标如期实现。

附件：1. 广东省财政厅关于下达2020年中央财政农村综合 改革转移支付（第3批）资金的通知

2. 2020年中央财政农村综合改革转移支付（第3批）资金下达情况及区域绩效目标表

广州市财政局

2020年11月20日
