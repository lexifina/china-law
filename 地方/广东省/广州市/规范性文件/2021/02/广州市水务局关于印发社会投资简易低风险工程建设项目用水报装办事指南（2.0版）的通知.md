# 广州市水务局关于印发社会投资简易低风险工程建设项目用水报装办事指南(2.0版)的通知

各区水行政主管部门，市水投集团：

根据《进一步优化社会投资简易低风险工程建设项目审批服务和质量安全监管模式工作方案（2.0版）的通知》（穗建改〔2020〕28号）要求，我局对《广州市水务局关于制定社会投资简易低风险工程建设项目用水报装办事指南的通知》（穗水资源〔2020〕6号，下称“1.0版”）中社会投资简易低风险工程获得用水中的受理范围和办理时限进行了优化，取消外线管径规模限制、压缩供水单位承诺办理时限，并规定给水接驳外线工程规模大于DN50或长度大于200米的外线工程施工耗时视实际工作量定。

鉴此，我局制定了《社会投资简易低风险工程建设项目用水报装办事指南(2.0版)》，现印发给你们。请各单位督促辖下各供水单位于1月25日前修订本单位有关工作办事指南、印发执行，并向社会公开公示。同时，请督促各供水单位向申请用水单位和个人宣传，以提升申请单位和个人的满意度和获得感。

本办事指南与“1.0版”不一致之处，以本办事指南为准。
