# 广州市水务局关于印发社会投资简易低风险工程建设项目用水报装办事指南(3.0版)的通知

各区水行政主管部门，市水投集团：

为进一步提高办事效率，我局对《广州市水务局关于制定社会投资简易低风险工程建设项目用水报装办事指南（2.0）的通知》（下称“2.0版”）中社会投资简易低风险工程获得用水的办理时限进一步优化，供水单位承诺办理时限调整为5个工作日，即供水单位接到市工程建设项目联合审批平台推送项目信息后4个工作日内自行完成外线工程现场勘测、方案设计，施工完成后1个工作日内装表通水。

现将《社会投资简易低风险工程建设项目用水报装办事指南(3.0版)》印发给你们。请各单位督促辖下各供水单位于7月15日前修订本单位有关工作办事指南、印发执行，并向社会公开公示。同时，请督促各供水单位向申请用水单位和个人宣传，以提升申请单位和个人的满意度和获得感。

本办事指南与“2.0版”不一致之处，以本办事指南为准。
