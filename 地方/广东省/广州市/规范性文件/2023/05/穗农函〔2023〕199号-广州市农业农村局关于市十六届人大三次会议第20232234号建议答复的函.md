# 广州市农业农村局关于市十六届人大三次会议第20232234号建议答复的函

周灿芳等代表：

您提出的《关于推广种植美食蕉的建议》（第20232234号）收悉。非常感谢您对我市香蕉产业发展工作的关心厚爱，提出的问题和建议体现了“树立大食物观”的理念，对我市构建多元化食物生产供给体系、丰富人民群众的餐桌食物选择具有重要意义。市政府高度重视，积极组织我局会同市直相关部门和各区政府进行认真研究办理，并与您在3月7日进行了座谈交流。经综合会办单位意见，现将办理有关情况答复如下：

一、我市香蕉产业发展情况

2022年，我市香蕉种植面积75038亩、产量280366吨，种植面积较2021年减少8603亩。香蕉种植的主要品种有巴西蕉、粉杂1号、广粉1号、本地大蕉等，还有少量农科1号、南天王、皇帝蕉、佳丽蕉等品种，大部分是作为鲜食的品种。香蕉种植面积较大的区主要有南沙区和增城区，其他区有少量零星种植。美食蕉分别在南沙区、增城区和黄埔区有小面积试种。

二、我市农业新品种引进试验和示范推广工作情况

一直以来，我市把农业品种更新换代作为引领和支撑广州农业高质量发展，推进农业农村现代化的重要抓手，大力开展农业新品种引进试验与示范推广工作。一是开展农业新品种引进试验，累计引进了粮食、蔬菜、果树、花卉、水产等新品种3000多个。二是举办广州市农业新优品种擂台赛，推动农作物品种更新换代。三是遴选、推介发布广州市农业主导品种，我市从2007年开始遴选和推介发布年度农业主导品种，至今，共有1021个品种纳入了广州市农业主导品种，其中有6个香蕉品种（农科1号香蕉、大丰1号香蕉、南天黄香蕉、中蕉3号香蕉、中蕉4号香蕉和中蕉9号）和2个粉蕉品种（广粉1号粉蕉和粉杂1号粉蕉）纳入了广州市农业主导品种。四是通过建立示范基地、开展田间展示、举办培训班及开展“轻骑兵”农技服务到田头等多种方式，示范推广良种良法。

三、关于在广州市大力推广种植美食蕉，提高美食蕉市场占有率，构建粮食多元化体系，提高土地资源利用率，促进农民增产增收的建议

目前，美食蕉在我市暂未具备大面积推广的条件。主要原因如下：一是根据自然资源部《国土变更调查规程》（2022年度适用），现状种植香蕉的土地在国土调查中地类将按果园认定，美食蕉种植不得占用永久基本农田和现状耕地。二是目前美食蕉未通过品种登记或认定，暂不适宜大面积推广。根据《中华人民共和国种子法》规定，列入非主要农作物登记目录的农作物在推广前应当登记。香蕉是第一批非主要农作物登记目录中的农作物，必须通过品种登记后才能推广。三是美食蕉主要用作加工原材料，其种植面积取决于加工需求量，只有在其加工产业蓬勃发展的基础上，才能大面积推广种植该品种。但是我市目前还没有以美食蕉为原材料的加工企业，对美食蕉的需求量不大。四是消费市场有待培育。美食蕉作为新品种，直接食用口感不佳，需加工后进食，与普通香蕉品种相比，食用较为不便，广大消费者对其营养价值和保健作用了解不深，没有消费习惯，没有形成消费市场，且缺少收购、加工和营销，尚未形成完整的产业链条。

四、下一步工作计划

（一）加大宣传力度。通过网络媒体多渠道宣传美食蕉的营养价值、保健作用等，推动广大消费者认知认同和食用消费美食蕉，培养开发消费市场，提高农户种植美食蕉的积极性。

（二）加强试验示范。深入开展栽培管理、科学施肥、病虫害绿色防控、农机化种植等技术的研究和试验，开展美食蕉高效丰产栽培技术集成研究，提高美食蕉的产量和品质，为进一步宣传推广美食蕉种植作准备。

（三）优化种植结构。严格落实《广州市人民政府办公厅关于进一步加强和改进耕地保护、严格用途管制的实施意见》，禁止占用永久基本农田和耕地种植美食蕉。深入分析市场需求，了解群众意愿，结合土壤、气候等条件，通过发动农户开展低效果园改造的途径，科学引导改种美食蕉，逐步优化种植结构调整。

（四）加强政策扶持。争取各级资金和政策扶持种植经营主体，支持推动美食蕉种植项目建设。培育种植经营主体发展壮大，推动美食蕉标准化种植，完善产业链条，带动农民增收致富。

感谢您对我市农业农村工作的关心和支持，欢迎继续对我们的工作提出宝贵意见和建议。

广州市农业农村局
