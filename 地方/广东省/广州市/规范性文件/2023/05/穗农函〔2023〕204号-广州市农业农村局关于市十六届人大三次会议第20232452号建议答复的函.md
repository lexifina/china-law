# 广州市农业农村局关于市十六届人大三次会议第20232452号建议答复的函

曾丽晴等代表：

您提出的《关于在碧道建设鱼类科普馆的建议》（第20232452号）建议收悉。我市政府高度重视，积极组织市农业农村局、市水务局、市科技局、市林业园林局及白云、从化区政府等单位进行认真研究办理，并于4月17日与您及其他7名人大代表赴白云区、市水生野生动物保护科普基地开展调研和座谈。经综合市水务局、市科技局、市林业园林局及白云、从化区政府等会办单位意见，现将有关办理情况答复如下：

一、有关工作情况

（一）广州市水生动物科普保护及科普基地建设情况

广州市高度重视水生生物保护救助与科普宣传，积极开展水生生物资源养护工作。一是严把水生野生保护动物行政许可审批关。加强行政审批事中事后监管，落实“双随机、一公开”行政执法检查。二是开展野生动物救助保护及野外放归、增殖放流活动。积极联合农业农村、林业等部门常态化开展水生野生动物放归活动，同时持续开展渔业资源增殖放流活动，2022年全市增殖放流多种水生生物超1500多万尾。三是加强鳄雀鳝等水生外来入侵物种防治工作，加大对外来水生物种科普宣传力度，积极稳妥应对涉水生动物舆情事件。四是严格落实渔业资源保护制度。积极组织实施珠江禁渔、南海伏季休渔，确保水生生物休养生息。五是强化水生野生动物保护宣传。每年11月份定期举办“水生野生动物保护科普宣传月”活动，宣传水生野生动物保护相关法律法规及保护常识、外来入侵物种及防控常识，取得显著宣传成效。六是不断加大水生野生动物执法力度。严厉打击非法驯养繁殖、经营利用、猎捕和滥食水生野生动物等违法行为，起到了良好的震慑作用。

在水生野生动物科普基地建设方面，目前全市共认定省级水生野生动物救护科普基地18家，其中设科普展馆2家，分别是珠江淡水渔业展览中心科普基地和广州市水生野生动物保护科普基地。珠江淡水渔业展览中心科普基地依托中国水产科学研究院珠江水产研究所建立，充分利用珠江所淡水渔业科研、水产科普等相关领域优势及资源条件，开展水生野生动物科普活动。广州市水生野生动物保护科普基地占地面积36000平方米，是集水生野生动物保护、救护、繁育、研究、宣教于一体的科普教育基地。

（二）科普展馆建设运营有关的法律法规等要求

2021年12月，市科技局制定印发《公共科普场馆运营规范》，明确规定公共科普场馆有关基本要求、机构人员、设施设备、科普活动服务、配套服务、安全要求、卫生要求及服务质量管理要求。其中政府投资建设的公共科普场馆建筑面积不少于5000平方米，高校、科研机构、企业等开放的公共科普场馆建筑面积不少于3000平方米。如若在流溪河碧道周边建设科普馆，其选址、建设还应符合《中华人民共和国防洪法》《中华人民共和国河道管理条例》《广东省河道管理条例》《广州市流溪河流域保护条例》等相关法律法规规定要求。

（三）（三）李溪拦河闸坝拟建鱼道工程有关情况

根据《广州市碧道建设实施方案（2020-2025年）》中“通山达海线”工程内容，设立流溪河碧道建设项目，市水务局拟在流溪河碧道花东镇（花都段）李溪拦河闸坝左岸（东电站）规划建设李溪拦河闸坝鱼道工程。该工程属于流溪河碧道建设项目（花都段）中的水生态保护与修复内容，主要建设内容，一是新建鱼道，为流溪河鱼类打通上溯通道，改善生物多样性；二是新建水利部科技推广基地，设置小水电主题展厅和水生态展厅，为公众了解水电历史、水生态科学知识提供窗口。水生态展厅包括水生态修复、流溪河水生生物、水标本展示柜等内容。

目前，项目建设方案处于初步设想和构思阶段，工程建设方案于2023年4月18日上报联审平台，现正征求各单位意见，暂未通过市发展改革委立项和落实资金来源。

二、下一步工作计划

（一）持续抓好水生野生动物救助保护工作

我市将坚持救助和保护并重，一方面利用现有救护平台和基地，持续组织开展野生动物救助保护及野外放归、增殖放流活动，邀请社会公众参与，寓教于行，将动物救助与科普宣传有机结合；另一方面继续加强水生野生保护动物行政许可审批和监管工作，严把审批关、筑牢执法关，将水生野生动物保护工作落到实处。

（二）持续加大水生野生动物科普宣传力度

一是积极宣传《野生动物保护法》《广东省野生动物保护管理条例》《广州市禁止滥食野生动物条例》等法律法规，让群众知法守法，切实提高社会公众认知和守法意识。二是定期开展各类科普宣传活动，如水生野生动物科普宣传月活动、增殖放流等，加强《国家重点保护野生动物名录》、水生野生动物保护和外来入侵物种等知识的宣传科普，切实营造全社会关心关爱野生动物的和谐氛围。

（三）持续跟踪支持科普场所建设

继续密切跟踪代表建议，积极组织各有关区、单位和部门加强沟通联动，认真研究论证，探索推进科普馆建设工作。

衷心感谢您对我市水生野生动物保护与科普宣传工作的高度重视和大力支持，欢迎您继续对我们的工作提出宝贵意见和建议。

广州市农业农村局
