# 黄埔区人民政府关于公布黄埔区第三批区级非物质文化遗产代表性项目名录的通知

各街道、镇，区府属各部门：

区人民政府同意区文化广电新闻出版局确定的第三批非物质文化遗产代表性项目名录（共计1项），现予公布。

各单位要按照《中华人民共和国非物质文化遗产法》和《广东省非物质文化遗产条例》等各项法律法规和政策要求，认真贯彻落实“保护为主、抢救第一、合理利用、传承发展”的工作指导方针，坚持科学的保护理念，制定规划，扎实做好非物质文化遗产代表性项目的保护、传承和管理工作，推动我区非物质文化遗产工作迈向新台阶。

附件：黄埔区第三批区级非物质文化遗产代表性项目名录

广州市黄埔区人民政府
