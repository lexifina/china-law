# 黄埔区人民政府关于广东雄资集团石油大厦地块旧厂改造实施方案的批复

广东雄资石油化工集团有限公司：

根据区城市更新工作领导小组2019年第三次会议精神，经区政府同意，现就广东雄资石油化工集团有限公司黄埔区广海路26号地块旧厂改造实施方案批复如下：

一、改造范围

项目位于黄埔区广海路26号，东侧和南侧均为南岗村民房屋，西至广海路，北至南岗村集体厂房。已纳入城市更新标图建库范围，图斑编号为44011200032；已纳入广州市黄埔区、广州开发区2019年城市更新年度计划（第一批）。项目地块权属人为广东雄资石油化工集团有限公司，本次改造范围用地面积为2648.08平方米（改造范围详见附件1），全部为权属用地。

二、改造模式

同意广东雄资集团石油大厦地块按照《广州市深入推进城市更新工作实施细则》（穗府办规〔2019〕5号）的规定采用“自行改造”方式进行更新改造。根据《关于商请提供广东雄资石油大厦地块规划设计条件的复函》（穗开规划资源函〔2019〕429号），你司自行改造地块面积2559平方米，占比96.64%；无偿交由政府地块为道路用地，用地面积89平方米，占比3.36%（具体以国土规划部门核定为准）。根据《广州市深入推进城市更新工作实施细则》（穗府办规〔2019〕5号），无偿移交政府地块不足15%的部分用地面积为308.21平方米，按整宗用地平均毛容积率4.35计算建筑面积1341.30平方米，按办理土地有偿使用手续时整宗用地国有土地上房屋市场评估均价（不含土地出让金）折算土地价款，纳入应缴交的土地出让金范围上缴财政。土地出让金按照相关规定补交，具体金额以国土规划部门核定为准。

三、规划控制要求

根据《关于商请提供广东雄资石油大厦地块规划设计条件的复函》（穗开规划资源函〔2019〕429号），改造范围地块总用地面积为2648平方米，其中净用地面积为2559平方米，代征道路用地面积为89平方米，用地性质为商业用地兼容商务用地，容积率≤4.5，建筑密度≤40%，绿地率≥30%，建筑限高≤100米。项目地块最终规划指标以国土规划部门核定为准。

四、改造业态要求

改造后项目业态应符合产业布局规划要求。根据你司提出的申请，项目改造后建设湾区石化企业特色商务中心和总部基地，创建区域内石化行业全产业链平台。

五、公益设施建设

根据区城市更新工作领导小组2019年第三次会议审议要求，项目所涉及的市政道路由改造主体将道路用地拆平后无偿移交政府。

六、其他要求

（一）本批复作为你司办理规划、国土等后续审批手续的依据。你司自取得本批复之日起一年内未与国土规划部门签订《国有建设用地使用权出让合同》的，本批复自行失效。

（二）如用地涉及查封、抵押或者土地使用权人与实际使用人不一致的，应由土地使用权人与相关单位或个人解除查封、注销抵押登记或者征得抵押权人、土地实际使用人同意，方可办理相关手续。

（三）自取得用地后10年内，你司需自持经营不低于本项目改造后计容总建筑面积的50%，自持经营期间不得转让给其他人。

（四）该项目自批复之日起三个月内，请你司与区签订批后项目实施监管协议，按照批复的改造实施方案实施改造。

（五）如下一步开发建设中发现不可移动文化遗产，你司须按相关法律法规进行保护。

（六）你司须根据《广州市土壤污染防治行动计划工作方案》开展改造范围内土壤污染防治相关工作。

（七）你司须采取有效措施确保施工建设过程中周边邻近建筑安全，避免对周边建筑产生不良影响。
