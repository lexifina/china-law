# 关于2012年度汕头市科学技术奖励的决定

汕府〔2012〕124号

各区县人民政府，市政府各部门、各直属机构：

为实施“科教兴市”战略、可持续发展战略和自主创新战略，建设创新型汕头，激励企事业单位和广大科技人员进行科技攻关，引进、转化推广科技成果，推进技术创新，开发高新技术产品，推动科技进步，加速我市经济和社会的发展，根据《汕头市科学技术奖励办法》的规定，汕头市人民政府决定，授予“用于女性两癌的彩超诊断系统关键技术研究及产业化”等19项成果为汕头市科学技术奖一等奖；授予“铜电极陶瓷电容器”等22项成果为汕头市科学技术奖二等奖；授予“全比例四驱高速遥控玩具赛车”等13项成果为汕头市科学技术奖三等奖。

全市科技工作者要向获奖者学习，发扬刻苦钻研、求真务实、开拓创新、团结协作的精神，努力进行科技攻关和技术创新，加速科技成果转化，大力发展高新技术产业，为全市加快转变经济发展方式，加速经济结构调整和优化做出重要贡献。具体获奖项目如下：
