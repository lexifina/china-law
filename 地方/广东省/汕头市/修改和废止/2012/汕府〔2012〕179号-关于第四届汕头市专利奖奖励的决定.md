# 关于第四届汕头市专利奖奖励的决定

汕府〔2012〕179号

各区县人民政府，市政府各部门、各直属机构：

为贯彻落实国家和省知识产权战略，深入实施省委、省政府《关于加快建设知识产权强省的决定》，进一步激励自主创新，促进自主知识产权创造、运用和产业化发展，促进产业转型升级，根据《汕头市专利奖励办法》，经汕头市专利奖评审委员会评审，市人民政府决定，授予汕头市超声仪器研究所有限公司的“200810030233．0实时三维医学超声图像的重建方法”等4项专利为汕头市专利金奖，广东金明精机股份有限公司的“201120173414．6叠加式多层共挤模头”等8项专利为汕头市专利优秀奖；授予汕头市华莎驰家具家饰有限公司的“201030183345．8床头柜”专利为汕头市外观设计金奖，广东潮宏基实业股份有限公司的“201030570056．3吊坠（凤影4）”等4项专利为汕头市外观设计优秀奖；授予李德来等10位同志汕头市优秀专利发明人奖。

希望全市广大企业和科技工作者以获奖单位和个人为榜样，深入实施知识产权战略，充分发挥知识产权对经济社会发展的助推器作用，不断提升自主创新能力，为我市发展做出积极贡献。同时，也希望获奖单位和个人再接再厉，乘势前进，在新的起点上不断取得新的成绩。
