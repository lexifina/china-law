# 汕头市人民政府关于奖励荣获第十九届中国专利奖和2017年广东专利奖企业的决定

汕府〔2019〕40号

各区县人民政府，市政府各部门、各直属机构：

在第十九届中国专利奖评选中，汕头市深泰新材料科技发展有限公司的“一种水乳剂型农药体系及其制备方法”等9项专利被国家知识产权局授予中国专利优秀奖，汕头市超声仪器研究所有限公司的“彩色多普勒超声诊断仪（推车式）”等2项专利被国家知识产权局授予中国外观设计优秀奖。在2017年度广东专利奖评选中，广东金明精机股份有限公司的“同心套筒式多层共挤吹膜机头”等5项专利获得第四届广东专利优秀奖。为更好地实施创新驱动发展战略，发挥政府奖励的导向和激励作用，进一步营造激励创新良好环境，市人民政府决定对获得第十九届中国专利优秀奖、中国外观设计优秀奖的汕头市深泰新材料科技发展有限公司等11家企业分别奖励16万元，对获得2017年广东专利优秀奖的广东金明精机股份有限公司等5家企业分别奖励8万元。

全市广大企事业单位要向受表彰的企业学习，深入实施知识产权战略，锐意进取，开拓创新，努力形成更多知识产权新优势，为我市经济转型升级和实现创新驱动发展新常态提供有力支撑。

附件：获得第十九届中国专利奖和2017年广东专利奖项目

汕头市人民政府
