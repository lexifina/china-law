# 关于区委（区政府）办公室领导班子成员分工的通知

各街道、区直各单位、市驻濠江有关单位：

经区委（区政府）办公室主任会议研究决定，现将我办领导班子成员分工通知如下：

赖恒辉同志：区委常委、区委（区政府）办公室主任，主持区委（区政府）办公室全面工作。

郑国裕同志：常务副主任，负责财务管理工作，协助主任处理区委（区政府）办公室日常事务和受委托的专项工作。

陈光杰同志：副主任（保留正科职），负责国安办工作。分管综合二股、外事股、人事行政股（国安股）。

蔡伟强同志：副主任（挂职），负责政研室、深改办工作。分管政研股、改革股、资料股、信息综合室。

蔡光平同志：副主任、主任科员，负责营商环境建设监督局工作。分管综合一股。

詹海洋同志：副主任，负责机关事务管理局工作。分管综合三股、接待股。

郑炯敏同志：副主任，负责工青妇、党史（地方志）、档案局、新闻信息中心工作。分管综合四股、档案馆、新闻信息中心。

林少彬同志：副主任，负责保密委办公室（保密局）、机要局（密码管理局）工作。分管总值班室、秘书股、保密股、机要股。
