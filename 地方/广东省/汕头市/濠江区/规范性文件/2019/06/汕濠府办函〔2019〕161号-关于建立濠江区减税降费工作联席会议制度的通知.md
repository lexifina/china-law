# 关于建立濠江区减税降费工作联席会议制度的通知

各街道办事处，区府直属各单位，市驻濠江有关单位：

为统筹做好我区减税降费工作，区政府决定建立减税降费工作联席会议制度（以下简称“联席会议”）。现将有关事项通知如下：

一、主要职责

全面贯彻落实中央出台的各项减税降费政策，研究我区减税降费实施工作，及时协调工作中遇到的制度难点问题，监督指导各街道、各部门抓好工作落实，统筹协调做好舆论引导工作，完成区委、区政府交办的其他事项。

二、组成人员

召 集 人： 陈锐勇 区政府常务副区长

副召集人：陈光杰 区党政办副主任

马洌槟 区财政局局长

黄俊枝 区税务局局长

成    员：  张永忠 区监委委员、党风政风监督室主任

余晓蓬 区委宣传部副部长

张恭宇 区发展和改革局副局长

杜玉虹 区工业和信息化局副局长

林少炼 区财政局副局长

郑桂宣 区人力资源社会保障局副局长

陈昌勇 区审计局主任科员

三、工作机制

联席会议不纳入区级议事协调机构管理，任务完成后自行撤销，日常工作由区财政局承担。联席会议成员因工作变动需要调整的，由所在单位向区财政局提出，按程序报召集人批准。联席会议运行、调整和撤销等情况，请区财政局及时报区委编办备案。
