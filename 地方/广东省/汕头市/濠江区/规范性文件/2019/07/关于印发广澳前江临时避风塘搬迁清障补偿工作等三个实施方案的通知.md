# 关于印发广澳前江临时避风塘搬迁清障补偿工作等三个实施方案的通知

广澳街道办事处，区府直属有关单位，市驻濠江有关单位：

《广澳前江临时避风塘搬迁清障补偿工作实施方案》《广澳前江临时避风塘搬迁涉及渔船停产补助工作实施方案》《广澳前江临时避风塘搬迁涉及渔船转产补偿补助工作实施方案》等三个方案已经四届九十二次区政府常务会议审议同意，现予以印发，请认真贯彻执行。
