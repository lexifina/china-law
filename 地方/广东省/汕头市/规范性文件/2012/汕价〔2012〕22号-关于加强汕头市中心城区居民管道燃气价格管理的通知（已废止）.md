# 关于加强汕头市中心城区居民管道燃气价格管理的通知（已废止）

关于加强汕头市中心城区居民管道燃气价格管理的通知

汕价〔2012〕22号

金平、龙湖区物价局，濠江区发展规划局、城市综合执法和安监局，各管道燃气经营企业：

为进一步规范和完善汕头市中心城区居民管道燃气价格管理，根据省物价局《关于规范我省管道燃气价格管理的通知》（粤价〔2006〕297号）和市政府批复我局的《汕头市中心城区居民燃气价格定价机制改革方案》（汕府办文〔2011〕2-501号）精神，现就中心城区居民管道燃气价格管理有关问题通知如下：

一、改革居民管道燃气价格定价机制，从原来的管道燃气与瓶装燃气价格联动管理方式改为管道燃气独立定价管理方式。

二、居民管道燃气价格实行政府定价管理，销售价格按合理成本、费用、税金和利润核定，继续采用现行一部制气价（即计量气价）模式和计价办法。

三、管道燃气经营企业需要调整价格的，按规定向市物价局申报，经批准后予以公布执行。

四、保持居民管道燃气价格相对稳定，价格调整时间原则上间隔不少于60天。

五、老用户气价优惠。对2006年12月26日前已缴交（含已签订合同）燃气管道建设配套费用的用户（老用户），继续予以气价优惠。即在5年内（其中已安装尚未开通的用户从开通之日起计），液化石油气价格按300立方予以每立方2元的气价优惠；天然气价格按1000立方予以每立方0.60元的气价优惠。老用户在优惠期满后或规定优惠期内优惠气量用满的，其优惠自行取消，并统一按公布的新用户价格执行。

六、管道燃气服务收费仍按我局《关于中心城区居民用户管道燃气服务项目收费有关问题的通知》（汕价函〔2011〕487号）规定执行。

七、管道燃气经营企业每两个月必须向市物价局报送一次价格执行情况和进货成本变动情况。

八、管道燃气经营企业必须做好管道燃气价格和服务收费的明码标价，列管的服务项目收费必须按规定申领经营服务性收费许可证，亮证收费。

九、本通知自2012年3月1日起执行，有效期至2017年2月28日止。

汕头市物价局
