# 印发关于开展社会保险扩面征缴和高技能人才入户城镇公益宣传活动实施方案的通知

汕府办〔2012〕144号

各区县人民政府，市政府有关部门、有关直属机构：

《关于开展社会保险扩面征缴和高技能人才入户城镇公益宣传活动的实施方案》已经市政府同意，现予印发，请认真组织实施。实施过程中遇到的问题，请迳向市人力资源和社会保障局反映。

汕头市人民政府办公室

2012年9月19日

关于开展社会保险扩面征缴和高技能人才入户城镇

公益宣传活动的实施方案

社会保险扩面征缴和高技能人才入户城镇工作，是今年省政府十件民生实事的重要内容，事关统筹城乡发展和产业转型升级大局，对建设幸福汕头有着十分重要的意义。8月20日，市委李锋书记在全市社会保险扩面征缴、高技能人才入户城镇暨人力资源社会保障信访维稳工作会议上强调，要做细致的宣传和发动工作，充分利用各种宣传媒介，加快推进社会保险扩面征缴和高技能人才入户城镇工作。第十三届14次市政府常务会议也就加大宣传力度等工作提出了具体的要求。为贯彻落实李锋书记的有关指示和市政府常务会议有关精神，积极营造良好氛围，切实推进我市社会保险扩面征缴和高技能人才入户城镇工作，制定如下公益宣传活动方案。

一、宣传形式

（一）宣传活动周。组织市、区（县）、镇（街道）和社区（村居）相关工作人员，深入企业、社区、家庭开展为期一周的集中宣传活动，现场宣讲政策，答疑解惑。（市人社局牵头，各区县人民政府、市委宣传部、市地税局配合）

（二）新闻媒体。在市主流报刊和广播电视开辟社会保险扩面征缴和高技能人才入户城镇工作专题系列报道，通过组织访谈、典型案例剖析等形式，开展政策宣传和解释。电视台在“今日视线”节目采制相关专题宣传，在黄金时段播出公益标语，协调市气象局在“天气预报”栏目加播背景宣传标语；汕头广播电台通过“现场连线”的形式，由电台连线市人社部门相关科室负责人开展宣传活动。（市委宣传部牵头，市人社局、地税局、气象台配合）

（三）网络宣传。在我市主要门户网站及人社部门官方网站开辟社会保险扩面征缴和高技能人才入户城镇工作专题链接，宣传相关政策，与网民网上互动答疑，提供相关资料下载。同时利用市政府网络问政平台开展宣传活动。（市人社局牵头，市委宣传部、市信息中心配合）

（四）短信平台。通过移动、联通、电信的手机报及短信平台，向城乡居民发送公益宣传信息，提高宣传活动受众覆盖面。（市人社局牵头，市委宣传部、市经信局配合）

（五）户外宣传。在公交车、出租车张贴公益宣传标语，或在车载LED显示屏播出公益宣传标语；在各主要路口的大型LED广告屏上播出公益宣传标语。（市人社局牵头，市委宣传部、市交通局、城管局配合）

（六）发放宣传资料。设计印制海报、彩页、小册子等宣传资料，在开展集中宣传活动时组织在人社、税务等办事大厅张贴、散发，组织相关人员、义工在人流比较密集的地点现场派发。（市人社局牵头，各区县人民政府、市委宣传部、市地税局配合）

二、时间安排

宣传活动周计划9月下旬或10月中旬举行，相对集中1周时间，全市同步开展现场宣传活动。

其他宣传活动，在9至12月统筹安排，持续提升宣传效果。

三、经费保障

开展公益宣传活动所需工作经费，由市人社局专项向市财政局申请。

四、工作要求

（一）统一思想，提高认识。推进社会保险扩面征缴和高技能人才入户城镇工作，任务艰巨，时间紧迫。各地各有关单位要将思想统一到市委李锋书记的讲话精神上来，切实加强对宣传工作的组织领导。市人社局、市委宣传部要统筹做好宣传活动的组织协调工作，各区县政府、市地税局等有关单位要主动配合、全力支持，共同营造良好的工作氛围。

（二）把握重点，突出主题。宣传活动中，宣传重点要侧重于宣传企业职工养老保险、城乡居民养老保险和高技能人才入户城镇的好处，参加养老保险是城乡居民、职工应有的权益，引导企业、职工、城乡居民自觉参保，引导符合条件的高技能人才踊跃办理入户城镇手续。为统一宣传口径，本活动方案涉及的具体宣传内容、宣传口号标语、宣传资料等由市人社局、地税局统一提供。

（三）灵活务实，提高效果。要选好宣传突破口，采取针对性强、效果好的宣传方式，更好地引导社会舆论；形式上要力求灵活新颖，使宣传活动更加生动活泼，不断扩大公众参与面；方法上以集中宣传和普遍宣传相结合，既注重集中突出宣传，扩大声势，又要建立长效机制，切实提高宣传工作实效。
