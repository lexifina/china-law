# 印发关于加强我市住房公积金管理的通知

汕府办〔2012〕197号

各区县人民政府，市政府各部门、各直属机构：

《关于加强我市住房公积金管理的通知》已经第十三届18次市政府常务会议审议同意，现予印发，请认真贯彻执行。执行过程中遇到的问题，请径向市房管部门反映。

汕头市人民政府办公室

2012年12月27日

关于加强我市住房公积金管理的通知

为贯彻《住房公积金管理条例》（国务院令第350号）、省政府有关规定和市委十届二次全会提出“努力提高职工住房公积金覆盖率”的工作要求，现就加强我市住房公积金管理，提高和扩大我市住房公积金覆盖面的有关工作要求通知如下：

一、各级要重视加强住房公积金管理工作，将职工缴存住房公积金的工作列入重要议事日程

住房公积金是我国住房保障体系中的一项重要制度，与社保、医保的性质同样列入国家的保障体系。关系到职工基本权益和利益分配问题。近年来，我市职工缴存住房公积金覆盖面逐步扩大，但实际归集率仍不尽人意，只占全市在职职工人数的47％左右，存在许多盲区。如部分国有集体企业、民营私营企业、外资企业，甚至部分辖区机关事业单位至今职工仍未缴存住房公积金，逐步成为社会热点问题。尤其是列入财政预算的教育、医疗系统的广大职工，由于仍未缴存住房公积金，丧失了申请住房公积金贷款的基本权利，职工反映较为强烈。为扩大我市住房公积金覆盖面，保障广大职工的基本权益，推进我市住房公积金事业的发展，各级政府、各部门要高度重视，要从建设幸福汕头，着力解决民生问题，提高人民群众幸福感的政治高度，把建立住房公积金制度作为为民办实事的重要工作来抓，列入重要的议事日程，支持和促进公积金归集扩面工作：一是要抓好市、区（县）二级财政核拨行政事业单位的住房公积金纳入年度财政预算工作。起步时，可以适当降低门槛，今后每年要视财政状况逐步调整提高；二是要监督财政补助、自收自支或经营自筹性质事业单位将职工住房公积金纳入预算；三是要督促各类企业（包括国有、集体、合资、外资、民营企业等用工单位）、社会组织等单位建立职工住房公积金制度，自觉为职工（含已建立劳动关系的临时雇用人员）缴存住房公积金，及时帮助、协调解决缴存工作中出现的问题，以规范用工行为，维护职工利益，逐步形成整体推进，平衡发展的新格局；四是要充分利用各种会议、活动广泛宣传建立职工住房公积金制度的必要性和积极意义，使用人单位，包括民营企业认识到建立住房公积金制度是企业应履行的社会责任和义务，推动缴存扩面工作的有效开展。

二、各有关部门要密切配合，齐抓共管，营造良好的缴存秩序

住房公积金涉及面广，各管理部门要相互支持配合，齐抓共管，创新管理，形成合力，共同努力做好提高住房公积金缴存覆盖面工作。各级政府要筹集资金，克服困难，根据财力状况及人员供养渠道逐步扩大财政核拨核补行政事业单位公积金缴存覆盖面，做好每年度职工住房公积金的预算和资金落实，按时足额拨付；各职能部门要大力支持、配合推进住房公积金的缴存扩面工作，统计部门要及时为住房公积金管理部门提供有关准确、实时的数据；税务部门要支持企业，按政策规定落实企业将缴存住房公积金纳入成本核算；工商、国资委、经信、审计、民政等部门要协助将各类企业、社会团体和民办非企业单位，是否有及时足额为职工（专职人员）缴存住房公积金作为企业等单位的信誉评估内容之一。新闻单位要及时报道我市职工住房公积金管理工作进展情况，加强新闻媒体的宣传和监督力度。

市房产、公积金管理等职能部门要加大住房公积金的宣传力度。利用各种媒体、场合，广泛宣传住房公积金制度的重要意义。要采用不同形式，运用不同方法把住房公积金归集扩面及权益保障宣传到不同层次的群体，特别是要让企业的法人或决策者充分认识到住房公积金的缴存对企业所起的积极意义，是企业保障员工权益，吸引、留住人才、员工的重要条件。要创新工作机制，为住房公积金归集扩面工作提供优质高效的服务。要提高职工购买住房提取、贷款住房公积金的办事效率，减少办事环节，方便广大职工；要根据实际情况，积极为缴存较为困难的单位排忧解难，推进住房公积金归集扩面工作的持续发展；要在确保资金安全的前提下，通过强化管理产生效益，要掌握好政策调整的节奏，依法把握好资金运作渠道，在政策规定的范围内，最大程度发挥资金使用效益，确保资金的增值保值，公积金的增值收益全力支持保障性住房建设。

三、加强监管，确保我市住房公积金的管理和使用安全

住房公积金属大众资金，归职工个人所有。资金归集总额大，国家对住房公积金的管理政策性较强，安全性要求十分严格。各职能部门要切实履行各自职责，切实加强对住房公积金的监管和监督，确保资金管理的安全、依法、规范，防范资金风险。市房产部门要加强对市住房公积金管理中心的指导、监管和协调工作；各级财政部门要加强对住房公积金的财务运作及收益的审核监督；审计部门要加强住房公积金的审计，监督住房公积金规范运作；市住建部门要加强对公积金管理法规、政策执行的监督；人民银行要加强对住房公积金有关账户的管理、监督；银监部门要监督受托银行住房公积金的承办业务；住房公积金归集和受托银行，要从强化金融部门管理的机制上，协助加强对住房公积金安全和正常运作的监管；住房公积金管理中心要健全完善内控制度。形成内外监督的格局，确保资金安全。

今后，住房公积金要逐步纳入各级政府、各职能部门政绩的考核内容，形成齐抓共管的局面，合力推进住房公积金缴存扩面，不断提高我市住房公积金管理工作水平。
