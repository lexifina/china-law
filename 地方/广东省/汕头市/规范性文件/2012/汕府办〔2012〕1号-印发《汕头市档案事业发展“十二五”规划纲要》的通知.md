# 印发《汕头市档案事业发展“十二五”规划纲要》的通知

汕府办〔2012〕1号

各区县人民政府，市政府各部门、各直属机构：

《汕头市档案事业发展“十二五”规划纲要》业经市人民政府同意，现印发给你们，请认真贯彻执行。

汕头市人民政府办公室

二○一二年一月三日

汕头市档案事业发展“十二五”规划纲要

为使我市档案事业更好更快地发展，全方位建立覆盖人民群众的档案资源体系、方便人民群众的档案利用体系和确保档案安全保密的档案安全体系，坚持不懈地围绕党和政府的工作大局创新服务，根据《广东省档案事业发展“十二五”规划纲要》和《汕头市国民经济和社会发展第十二个五年规划纲要》，特制定“十二五”期间全市档案事业发展规划纲要。

一、“十一五”期间全市档案工作的基本情况

“十一五”期间，全市档案工作在市委市政府的正确领导下，在上级档案主管部门的指导下，在社会各界的关心和支持下，以邓小平理论和“三个代表”重要思想为指导，认真贯彻落实科学发展观和国家有关档案工作的方针政策，不断解放思想，开拓进取，扎实工作，为全市经济建设和社会发展作出了应有贡献。2010年12月，全市档案事业发展以优良成绩通过省综合评估。

全市各级档案部门努力发挥档案服务功能，不断拓展服务领域和探索新的服务方式，着力为市委市政府工作大局、民生工作提供优质服务。全面开展了政府信息公开查阅利用工作，机关档案工作、重大项目档案工作、民营企业档案工作、新农村建设档案工作、社区档案工作等领域都实现了新的突破，经济效益和社会效益显著。

全市各级档案部门全面履行档案事业行政管理和档案保管利用两种职能，全市档案事业走上了可持续健康发展轨道。各级档案部门不断创新服务方式，档案利用服务效果明显。全市各级各类档案馆档案资料利用人次从2006年的22691人次增加到2010年的36204人次，年均递增约2702人次；档案资源建设不断加强，馆藏档案大幅增加，结构明显改善，一大批反映汕头特色的档案资料得以进馆，全市各级各类档案馆馆藏档案从2006年的879个全宗287924卷增加到2010年的983个全宗349372卷，年均增加约12290卷；档案得到有效保护，事业空间进一步拓宽；档案工作的各项规章制度不断完善，档案行政执法责任制得到落实，档案行政管理水平全面提升；不断推进电子文件的规范化管理，档案信息化建设步伐加快；多方位培训档案干部，队伍建设进一步加强。

二、“十二五”期间档案事业发展形势分析

“十二五”期间是我市加快转变经济发展方式，加快幸福汕头建设的关键时期。市委九届十次全会指出，要以科学发展为主题，以加快转变经济发展方式为主线，以改革创新为动力，以建设幸福汕头为目标，努力推动科学发展，加快幸福汕头建设。全会提出的我市经济社会发展战略，对我市的发展将产生重大而深刻的影响，也必将对档案工作提出更高要求。全市各级档案部门一定要站在建设幸福汕头的高度来审视档案工作，把握好档案事业发展的战略机遇，着力建立民生幸福档案，服务幸福汕头建设。一是各级领导的高度重视，为档案事业的发展注入了强大的动力。2010年7月6日，省委常委、副省长肖志恒到汕头市档案局（馆）调研时对档案工作寄予厚望，要求档案部门要“以档辅政，以档资政，以档育人”。二是有关加强档案工作系列文件的出台，为档案事业发展提供政策保障。2010年9月3日，市委常委会会议专门听取了我市档案工作的情况汇报。根据会议要求，市委办、市府办分别于10月28日和11月30日出台了《关于加快汕头市档案事业发展的意见》和《关于向市档案馆移交荣誉档案和礼品档案的意见》等加强档案工作的文件，提出了解决一系列档案事业发展的重点难点问题的措施，保证档案事业健康发展。三是各级领导高度重视，档案事业发展列入全市国民经济和社会发展规划，档案工作摆上议事日程。四是经过“十一五”期间的发展，全市档案工作取得了良好的成绩，为“十二五”期间全市档案事业发展奠定了良好的基础。

“十二五”期间是我市档案事业发展的难得机遇，但也面临着一系列问题，制约着档案事业的健康、持续发展。主要表现在：市、区（县）档案工作发展不平衡，档案馆舍建设面积不达标，指导新领域建档工作的面还不够宽，档案信息化建设步伐有待加快，档案经费不足，档案专业人才缺乏等。只有解决好上述问题，档案事业才能在“十二五”期间得到更好更快的发展。

三、“十二五”发展的总体要求

（一）指导思想

坚持以邓小平理论、“三个代表”重要思想为指导，深入贯彻落实科学发展观，紧紧围绕党委、政府的工作大局和国家、省局的总体部署，解放思想，抢抓机遇，以改革创新为动力，以建立覆盖人民群众的档案资源体系、方便人民群众的档案利用体系、确保安全保密的档案安全体系建设为目标，以提升档案服务能力为核心，以档案资源整合、馆舍建设和信息化建设为重点，以档案法制建设为保障，依托教育和人才队伍建设，促进档案事业与经济社会协调发展，为建设幸福汕头作出贡献。

（二）发展思路

始终把为党委、政府中心工作，为经济社会发展和为民众提供优质服务作为出发点和落脚点，适应形势新变化，顺应人民新期待，坚持把服务大局、服务民生和服务社会作为推动档案事业科学发展的主题，完善档案法制建设，优化档案管理体制，加快档案馆舍建设，强化档案资源和档案安全建设，推进档案信息化建设，加强档案干部队伍建设，进一步拓展档案工作领域，大力提升档案文化的影响力和贡献力，更好地为推动科学发展，加快幸福汕头建设服务。

（三）总体目标

努力使全市档案工作取得跨越式发展，力争进入全省先进水平，在“建立覆盖人民群众的档案资源体系、方便人民群众的档案利用体系和确保档案安全保密的安全体系”的建设中取得快速进展。

——市、区（县）档案馆完成新建或改扩建任务，档案馆设施完备、功能齐全，为提高档案管理和服务水平提供保障，市馆及30％以上的区（县）馆达国家二级综合档案馆标准。

——档案法制体系进一步完善，档案法律规章不断健全，依法管理水平进一步提高，档案管理体制不断创新、优化，以人为本的便民利民措施更加有效。

——档案资源进一步丰富，馆藏结构科学合理，档案门类更加齐全。

——档案信息化建设与电子政务建设同步发展，推行市直机关事业单位电子文件在线归档管理，加快推动电子文件中心和数字档案馆（室）建设。

——档案干部队伍建设稳步加强，教育培训工作满足事业发展需求，档案科研质量进一步提高。

——档案服务领域不断拓展，服务影响不断扩大，为经济社会发展服务的能力全面提升。

四、主要任务

（一）档案馆工作。

1、加强档案馆舍和基础设施建设。大力改善市、区（县）两级档案馆档案保管和利用条件，着重解决馆舍不达标、简陋或陈旧这一制约档案事业发展的瓶颈问题。“十二五”期间，力争完成市档案馆的新馆建设任务；龙湖、潮南区档案馆要争取区政府的支持，把新馆建设列入“十二五”规划，尽快立项建设；金平、濠江、南澳等区（县）争取完成馆舍的改扩建或调整；澄海、潮阳区档案馆要做好展厅等功能设施的配套完善工作。力争70％档案馆达到国家规范标准，完成馆舍建设任务。各区（县）档案馆要本着“统筹兼顾，均衡发展”的原则，增加配套设施、设备等现代化管理方面的投入，所需经费应按计划逐年改善，以适应档案事业发展需要。

2、加强档案馆规范化建设。按照档案馆档案安全保管基地、爱国主义教育基地、档案利用中心、政府信息公开查阅中心、电子文件中心“五位一体”功能要求，强化档案馆的主体地位，全面提升全市各级国家综合档案馆基础业务建设水平，推进新型公共档案馆建设。市档案馆及30％以上的区（县）级档案馆要完成国家二级综合档案馆测评验收工作。

3、加强档案资源体系建设。按照“总量增加、结构优化、质量提高”的要求，依法加强档案接收进馆的指导与监督，确保应进馆档案全部接收进馆；加强对各类有参考和凭证价值档案、地方特色档案、声像档案、实物档案、公务礼品档案、荣誉档案的收集或采集，特别注意收集重大事件、重要活动、重点工程以及著名人物和关系人民群众切身利益的民生档案，有重点、有计划地征集散失在民间和国外的珍贵档案。市档案馆要进一步做好市委市政府领导班子重要公务活动、重要外事活动和上级领导来汕调研、视察指导工作以及突发事件的拍摄服务工作，并启动当地新闻视频档案的采集工作。

4、加强档案利用体系建设。深化档案信息资源的开发利用，提高档案馆公共服务能力。加快档案开放步伐，各级综合档案馆档案开放鉴定工作经常化，及时完成到期开放档案的鉴定工作，依法开放应开放的全部档案。围绕党委和政府的中心工作，重大政治、经济活动以及人民普遍关注的社会热点问题，加大对档案信息资源的开发力度，进一步做好政府公开信息的报送和提供利用工作，探索更多惠民便民档案服务方式和手段。加强档案馆文化建设，做好各类档案资料的编研工作，推出一批高质量的档案文化产品。

5、加强档案安全体系建设。始终树立“档案安全关系党和国家利益”、“安全重于泰山”、“安全问题人人有责”的思想，充分认识和高度重视档案安全工作。完善制度，加强管理，健全档案安全保障体系。制定各种档案安全预案，增强应对台风、地震、洪水等突发自然灾害及突发社会事件的能力。加强对档案安全的监督、检查和整改，采取有效防范措施，确保档案实体安全和信息安全。市档案馆重要档案和电子文件实行异地备份。市、区（县）二级档案馆全面完成馆藏国家重点档案的抢救工作，各级档案部门要争取财政资金的支持，增加档案抢救经费的投入。

（二）档案室工作。

1、全市各级机关、团体、企业、事业单位加强档案基础设施建设，加强对各门类应归档文件的控制，确保归档文件准确、完整，档案整理规范，保管科学，利用便捷。

2、继续贯彻国家档案局第8号令，2012年底前全面完成文件材料归档范围和文书档案保管期限表的修订工作，把反映党和国家重点工作、反映本地区和本单位基本职能以及关系广大人民群众切身利益的文件材料列入归档范围。

3、继续以机关企事业单位档案工作标准化管理为手段，加强机关、企业、事业单位档案室档案管理规范化工作，全面提高档案管理工作水平。

4、全市各级机关企事业单位档案室要努力提高档案管理现代化水平。遵循文档一体化、电子文件与纸质文件并存和确保网络安全的原则，把档案信息化纳入本单位办公自动化的总体格局。

5、深化农业农村档案工作，服务社会主义新农村建设。统筹城乡档案工作协调发展，推进覆盖新农村建设各个方面和全体农民的农村档案工作体系。开展创建社会主义新农村建设档案工作示范单位试点工作，加强乡（镇）、行政村档案室建设，鼓励支持农村各种新兴经济合作组织建档，完善集体林权制度改革档案工作，全面开展农村基层组织档案建设工作。

6、探索和建立适应现代企业制度要求的企业档案管理模式。根据新形势的发展，及时研究制定相应的制度、措施，加强国有企业档案工作，推动民营企业档案工作。特别要加强“双转移”园区、高新技术开发区、上市企业等领域的档案工作，确保经济社会发展全过程和各领域形成的档案应建尽建，实现全覆盖。

（三）档案法制建设

1、依据《中华人民共和国档案法》、《广东省档案条例》以及《汕头市档案管理办法》，进一步完善相配套的规章制度，构建依法行政、有效监督、高效服务的档案法制工作体系，增强依法管理档案事业的能力。充实档案行政执法人员队伍，创造良好的法制环境。争取市人大支持，加大档案行政执法检查力度，将档案执法检查纳入人大的执法检查范围，严肃查处档案违法行为。

2、制定《汕头市国家综合档案馆收集档案范围的规定》并报市政府审核批准。各区（县）档案馆完成本馆收集档案范围的制订（修订）工作。适时制定《汕头市重大（重点）建设项目档案管理办法》，进一步加强项目档案的规范化管理。

3、继续开展档案普法教育，争取列入市、区（县）和各系统普法内容。结合全市实际，有重点、有针对性地开展宣传和指导工作，不断创新法制宣传方式，提高干部职工和社会公众特别是各级领导干部的档案法治意识，优化档案工作的社会环境。

4、建立和完善档案行政许可审批制度。市档案局的行政许可审批与市电子监察实时监控系统实行无缝链接。市、区（县）两级档案行政审批逐步实现网上审批，提高时效性和服务效率。

（四）档案信息化建设。

1、加强档案信息化基础设施建设。加强以计算机网络设备和数据库为主要内容的档案信息化基础建设，建立与党政网、政务网相联接的档案信息服务平台，逐步实现面向机关、团体、企事业单位和社会公众的电子文件管理服务和利用服务。积极推进镇（街道办事处）、村委会（社区居委会）档案信息共享工程，逐步普及档案信息进村入户，服务到家。

2、加快数字档案馆建设。按照国家档案局《数字档案馆建设指南》的要求，建立和完善档案、政府信息公开文件机检目录数据库，馆藏档案文件级目录和政府信息公开文件目录全部实现计算机检索，全面开展纸质档案数字化和多媒体档案数字化，基本完成开放档案数字化并向公众提供利用。市档案馆和有条件的区（县）档案馆初步建成数字档案馆，档案全文数字化不少于馆藏的50％。

3、加强电子文件管理工作。各级档案馆（室）要按照统一管理、全程管理、规范管理、便于利用和安全保密的原则，积极贯彻中央办公厅、国务院办公厅《电子文件管理暂行办法》，规范电子文件移交流程，建立电子文件管理和利用系统，探索建立与数字档案馆（室）相适应的电子文件（档案）备份中心。

4、提升档案信息网站水平。以“汕头档案信息网”为平台，建立起面向社会、服务公众的档案网站群，重点建设“政府公开信息查阅中心”和共享平台，为打造阳光政府服务。各区（县）档案信息网要不断充实内容，并与当地政府综合门户网站和“汕头档案信息网”实现链接。各级档案信息网站要进一步扩充网上办事和互动功能，定期公布开放档案目录，发布工作信息，举办网上展览，开展网上目录和全文查询服务，逐步建成“一站式”档案信息资源共享和服务平台。“汕头档案信息网”要充分发挥粤东档案门户网站的作用，办成网上档案业务咨询、指导、培训、信息发布和检索利用的基地，成为全省知名的档案网站。

（五）档案科研和干部队伍建设

1、积极开展档案科学研究。完善档案科研工作机制和管理方式，着力组织、引导对档案事业发展全局有重要影响的重大理论和关键技术研究，重点开展档案管理模式创新与新技术新方法研究、档案实体和信息安全研究，以及档案保护与修复技术设备研发。

2、科学规划加强档案队伍建设和人才发展战略。创新档案人才引进、人才评价、人才激励等人才培养管理新机制，努力营造档案人才培养使用的良好环境，激励档案人才干事创业。

3、按照《关于进一步加强档案人员岗位培训工作几个问题的通知》，制定符合当前档案工作实际的全市档案干部培训目标、任务和措施，进一步完善和规范全市档案干部教育培训制度。

4、加强岗位培训工作。继续实行档案人员持证上岗制度，所有新上岗的档案人员必须在上岗一年内接受岗位培训。根据“学用结合，注重实效”的原则，积极探索岗位培训新模式，突出实用性和技能性，提高培训质量。

（六）档案宣传工作。

1、挖掘馆藏档案资源，开展丰富多样的档案宣传。通过报刊、杂志、电视台、电台、网络等新闻媒体，开辟档案宣传专题或专栏，开展档案学术讲座、专题报告等系列档案宣传活动，扩大档案宣传的广度和深度。

2、充分发挥档案馆爱国主义教育基地的作用。在实现档案馆舍达标建设的基础上，立足档案馆馆藏信息资源，通过举办历史、文化、社会经济建设等各类专题展览，吸引社会群众参观，开展广泛的爱国主义教育活动，使档案馆成为贴近社会公众的公共文化服务中心。

3、围绕社会热点和中心，开展档案文化活动。围绕全市开展的重大活动、事件、纪念日、主题日等举办系列档案主题文化活动，扩大百姓参与面，进一步深化档案的社会影响力。

五、保障措施

（一）各级政府依法加强对档案工作的领导，将档案工作列入政府的议事日程，将档案事业建设列入国民经济和社会发展规划，不断加大投入，使档案事业经费随档案总量的增长以及管理和服务方式的改进不断增加，要将档案馆舍建设、档案抢救保护和档案信息化建设经费纳入本级财政预算统筹安排。各级综合档案馆的档案保管保护费每卷每年应不少于3元。

（二）加强调查研究和档案学术理论研究。深入开展档案工作调研活动，及时总结和推广新经验、新做法；加强档案学术理论研究，不断提高学术理论对档案工作实践活动的引导作用。

（三）加强建档服务。围绕行政机关体制改革和事业单位分类改革，完善档案工作体制机制，做好电子文件与电子档案管理工作，依法及时向同级综合档案馆移交政府信息公开文件和档案。继续开展市直单位档案工作年度评估。继续开展目标管理活动，加强档案基础业务建设，全面提高机关档案工作水平。建立服务于经济发展方式转变的档案工作新模式，积极推动“双转移”园区和高新技术开发园区企业建立档案工作。推进重点企业和龙头企业实施《企业档案工作规范》，开展重大建设项目档案专项验收等工作。

（四）各级档案行政管理部门要切实做好本地区档案事业的统筹规划、建章立制、组织协调、监督指导和信息服务工作；建立档案工作年度考核机制，加强对档案事业的宏观管理，促进档案业务建设的均衡发展；进一步探索整合档案资源和档案资源增值服务的档案管理体制和有效方法，创新体制机制，推进档案工作改革创新，努力服务幸福汕头建设。
