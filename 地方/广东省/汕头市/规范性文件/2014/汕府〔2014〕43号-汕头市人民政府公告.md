# 汕头市人民政府公告

汕府〔2014〕43号

为加强城市道路交通管理，维护交通安全和社会治安秩序，保护人身安全，保护公民、法人和其他组织的财产安全和其他合法权益，提高道路通行效率，根据《中华人民共和国道路交通安全法》第三十九条规定，结合我市实际，现对中山东路（天山路口至金环路口）大型货车通行时间调整公告如下：

一、中山东路（天山路口至金环路口）大型货车通行时间段为：9：00至11：00、15：00至16：30，其他时间仍禁止大型货车通行。

二、大型货车因特殊情况确需在通行时间外行驶中山东路（天山路口至金环路口）的，应当事先报市公安机关交通管理部门备案审查，并按市公安机关交通管理部门制定的时间行驶。

三、本公告自2014年5月1日起施行。未调整事项仍按2010年7月1日所发布《公告》（汕府〔2010〕80号）的有关规定执行。

汕头市人民政府
