# 关于奖励我市荣获第十四届中国专利奖企业的通报

汕府〔2014〕51号

各区县人民政府，市政府各部门、各直属机构：

在第十四届中国专利奖评选活动中，我市西陇化工股份有限公司的“过硫酸钠生产过程中的脱氨方法”和广东奥飞动漫文化股份有限公司的“玩具遥控直升机（空翼号）”等5项专利被国家知识产权局分别授予中国专利优秀奖和中国外观设计优秀奖。

为表彰和激励自主创新，促进形成更多具有自主知识产权的技术和产品，汕头市人民政府决定，对获得中国专利优秀奖和中国外观设计优秀奖的西陇化工股份有限公司、广东奥飞动漫文化股份有限公司等5家企业分别给予16万元奖励。

希望受表彰的企业再接再厉，不断增强自主创新能力，努力创造更多具有自主知识产权的技术产品，推动其产业化发展。全市企业要以获奖单位为榜样，深入实施知识产权战略，充分发挥知识产权对产业转型升级和经济社会发展的重要支撑作用，努力提高技术和产品的竞争力，为我市经济建设作出更大贡献。
