# 关于印发进一步扶持中小微企业发展和民营企业做大做强实施意见的通知（已废止）

汕府办〔2014〕66号

各区县人民政府，市政府各部门、各直属机构：

《关于进一步扶持中小微企业发展和民营企业做大做强的实施意见》已经第十三届50次市政府常务会议审议同意，现印发给你们，请认真贯彻执行。执行过程中遇到的问题，请径向市经信局反映。

汕头市人民政府办公室

2014年6月20日

关于进一步扶持中小微企业发展和民营企业做大做强的实施意见

为贯彻落实《广东省人民政府关于进一步扶持中小微企业发展和民营企业做大做强的意见》（粤府〔2013〕115号），进一步加大对我市中小微企业的扶持力度，促进中小微企业健康发展，加快培育壮大民营骨干企业，结合我市实际，提出以下实施意见。

一、加大对中小微企业的扶持力度

1．继续执行市政府关于《印发汕头市贯彻省人民政府2012年扶持中小微企业发展若干政策措施实施意见的通知》（汕府〔2012〕85号）中的47项政策措施。（详见附表）

2．自2013年8月1日起，对增值税小规模纳税人中月销售额不超过2万元的企业或非企业性单位，暂免征收增值税；对营业税纳税人中月销售额不超过2万元的企业或非企业性单位，暂免征收营业税。（市国税局、地税局负责）

3．对从事蔬菜批发、零售的纳税人销售的蔬菜免征增值税；对从事农产品批发、零售的纳税人销售的部分鲜活肉蛋产品免征增值税。（市国税局负责）

4．符合条件的中小企业信用担保机构按照不超过当年年末担保责任余额1％的比例计提的担保赔偿准备，允许在企业所得税税前扣除，同时将上年度计提的担保赔偿准备余额转为当期收入。符合条件的中小企业信用担保机构按照不超过当年担保费收入50％的比例计提的未到期责任准备，允许在企业所得税税前扣除，同时将上年度计提的未到期责任准备余额转为当期收入。中小企业信用担保机构实际发生的代偿损失，符合税收法律法规关于资产损失税前扣除政策规定的，应冲减已在税前扣除的担保赔偿准备，不足冲减部分据实在企业所得税税前扣除。（暂执行至2015年12月31日，市国税局负责）

5．全面落实国家和省已取消、免征、降低行政事业性收费的各项规定，同时进一步清理、减免我市现有行政事业性收费。自2014年1月1日起2年内，堤围防护费按现行征收标准下调20％；对月营业额2万元以下的中小微企业免征。全面取消治安联防费。（市发改局、财政局负责）

6．加快推进投融资体制改革工作。贯彻落实《汕头市企业投资管理体制改革实施方案》，推进以备案制为主的企业投资项目管理体制，建立高效便捷的企业投资项目并联审批流程，推行网上在线备案，为企业投资提供优质高效服务；贯彻落实《汕头市进一步推动民间投资发展操作方案》，继续谋划推出一批面向民间投资的重大项目，引导民间资本进入基础设施、社会事业、市政设施等领域和战略性新兴产业。（市发改局负责）

7．鼓励各金融机构盘活信贷存量、优化增量，将全年新增贷款部分和“高耗能、高污染”贷款到期回收部分主要用于支持小微企业发展，完善绩效考核机制，适当提高小微企业不良贷款容忍度，力争全年小微企业贷款增速不低于当年各项贷款平均增速、贷款增量不低于上年同期水平。（人行汕头中心支行、汕头银监分局负责）

8．探索开展发行区域集优集合债券，通过政府出资建立直接债务融资发展基金，以一定规模的财政投入撬动十倍乃至数十倍的金融资源，为中小微企业票据融资提供担保支持，拓宽企业融资渠道。（市金融工作局、经信局、人行汕头中心支行、汕头银监分局负责）

9．积极支持本地资本在符合准入条件、承诺自担风险的前提下探索发起设立民营银行等民营金融机构。推动与国家开发银行广东省分行合作共建汕头金融超市，以汕头金融超市为载体建设统贷平台，开展贷款服务外包试点，提升对民营经济和中小微企业社会金融服务水平。（市金融工作局、人行汕头中心支行、汕头银监分局负责）

10．根据国家有关外汇管理政策，改革货物贸易外汇管理方式，简化企业货物贸易进出口收付汇业务办理手续和程序；改进资本项目外汇管理，促进跨境投融资便利化；推动跨境人民币结算，为企业规避汇率风险提供有效途径；实行限时办结制度，全面提升服务效能。调整短期外债余额指标，重点向服务中小微企业的银行倾斜。（人行汕头中心支行负责）

11．鼓励我市中小企业申报挂牌全国中小企业股份转让系统。市财政2014年、2015年，每年安排专项资金300万元，对准备在“新三板”挂牌的已完成股份制改造且通过券商内部审核以及成功在“新三板”挂牌的企业，分别给予奖励。大力支持区域股权交易市场建设，为中小企业提供合法、规范的股权转让和私募融资平台。（市金融工作局、人行汕头中支、汕头银监分局负责）

12．着力完善激励创新的政策制度体系，大力开展科技教育活动，着力改善汕头的创新创业环境。推动中小微企业公共技术服务机构、创业投资机构建设，引导公共技术服务平台为中小微企业创新创业开展基础性、公益性和开放性的专业化技术服务。发挥省级示范公共技术服务机构的辐射带动作用，为中小微企业营造良好的技术创新环境。（市科技局、经信局负责）

13．继续深入实施“四大产业计划”，推动产业技术创新，促进产业转型升级。组建一批产业技术创新联盟，以联盟为纽带，促进联盟内部企业资源整合；搭建产业公共技术服务平台，为联盟企业提供全方位服务；搭建一批产业公共创新平台，大力推动汕头市公共检验检测平台、中国广州分析测试中心粤东分中心、中科院广州技术转移中心汕头分中心、汕头轻工装备研究院、江南大学（汕头）食品及装备研究院以及汕头市电力电器技术研究院等公共创新平台建设，开展行业共性技术研发、科技成果转化、产学研结合等创新服务。（市科技局负责）

14．结合我市玩具、内衣、家居服、日化、印包、特色农业、潮汕美食等优势产业链发展电子商务，促使企业利用电子商务开拓市场、推动生产；举办行业触电交流会等活动，着力引导传统企业运用电子商务开拓市场、利用生产环节的资源优势整合产业链销售环节，占领微笑曲线价值高端；策划组织开展“汕货网上行”、“汕头网购节”、“汕头购物节”等活动，大力推介我市电子商务平台、网上商城和汕货网店；完善汕货网上行官网“汕头购物节”，打造汕货电子商务综合门户，树立汕货品牌形象。继续组织实施好《汕头国家电子商务示范城市创建工作方案》、《汕头市电子商务发展“十二五”规划》。继续组织开展市级现代服务业发展引导资金和促进电子商务发展专项资金竞争性分配工作，支持我市电子商务等现代服务业企业的发展。（市经信局、发改局负责）

二、培育壮大民营骨干企业

15．对列入全省重点支持大型骨干企业目录的民营企业加强跟踪服务工作，确保省相关扶持政策不折不扣落实到位。（市经信局负责）

16．对已报省的年营业收入超10亿元民营企业，争取列为省重点培育对象，加强跟踪服务工作，参照列入目录的大型骨干企业落实相关扶持政策。（市经信局负责）

17．支持民营骨干企业和我市后备骨干企业牵头申报省战略性新兴产业、国家重大科技、重大成果转化、省部（院）产学研合作、省重点实验室等专项资金，加快突破关键核心和产业化技术。（市财政局、经信局、科技局、发改局负责）

18．对民营骨干企业的投资项目优先给予用地保障。民营骨干企业的建设项目用地在符合我市土地利用总体规划、符合国家供地政策、报批条件成熟的，优先给予年度土地利用计划指标的用地保障。（市国土局负责）

19．鼓励银行业金融机构加大对民营骨干企业的信贷支持，对民营骨干企业贷款规模增长较快的银行业金融机构，相关单位可根据各银行机构的贷款支持情况，在申报各级扶持重点金融产业发展专项资金时给予综合考虑。（市金融工作局、财政局、人行汕头中支、汕头银监分局负责）

20．落实上市扶持资金政策，支持民营骨干企业通过发行股票、债券、可转换债、并购私募债等方式并购重组融资。支持符合条件的民营骨干企业参与我市现有地方金融机构改革重组，以及发起设立或参与设立企业财务公司、汽车金融公司、融资租赁公司、股权投资企业、航运保险公司、消费金融公司等新型金融机构。（市金融工作局、人行汕头中支、汕头银监分局、汕头保监分局负责）

21．支持以民营骨干企业为载体，围绕有一定基础的生物制药、节能环保、电子元器件封装、高端电子显示等战略性新兴产业，加大扶持力度，促进产业加快发展；进一步加强中国锆城、航天应用产业园、数据特区等园区建设，加快促进核级锆、卫星导航、信息服务等产业加快发展。（市科技局、经信局、发改局、财政局负责）

22．支持民营骨干企业创建国家级和省级工程技术研究中心、重点实验室、企业技术中心等创新平台。支持以民营骨干企业为主导发展产业技术创新战略联盟，建立联合开发、优势互补、成果共享、风险共担的产学研用合作机制。（市科技局、经信局、财政局负责）

23．鼓励国家级和省级工程技术研究中心、重点实验室、企业技术中心等创新平台向民营骨干企业开放并提供服务。对创新平台服务民营骨干企业给予申报省结构调整、技术创新、中小企业等专项资金项目。（市科技局、经信局、财政局负责）

24．加快民营科技企业创新产业化基地建设，建设一批科技型民营企业自主创新、引进消化吸收再创新、产学研联合创新等产业化示范基地。（市科技局、经信局负责）

25．鼓励民营骨干企业开展强强联合、上下游整合等多种形式的并购重组，提高产业集中度和资源配置效率。鼓励民营骨干企业赴境外收购兼并实体经济、设立研发设计机构、招聘吸收高层次人才、投资办厂、建立营销渠道，参与全球资源整合与经营。（市外经贸局、经信局负责）

本实施意见所列扶持政策措施，国家、省、市有实施年限规定的，按其规定执行。各区县、各有关部门要根据本实施意见，结合实际制定具体实施细则。市政府将对本实施意见各项政策措施的落实情况进行督查。
