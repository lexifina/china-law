# 关于印发2014年全市政府信息公开工作要点的通知

汕府办〔2014〕67号

各区县人民政府，市政府各部门、各直属机构：

《2014年全市政府信息公开工作要点》已经市人民政府同意，现印发给你们，请认真组织实施。

汕头市人民政府办公室

2014年6月18日

2014年全市政府信息公开工作要点

为深入贯彻落实党的十八届三中全会精神，进一步加强政府信息公开工作，根据《广东省人民政府办公厅关于印发2014年全省政府信息公开工作要点的通知》（粤府办〔2014〕26号）和《广东省人民政府办公厅关于进一步推进重点领域信息公开的意见》（粤府办〔2013〕38号），现提出2014年全市政府信息公开工作要点如下。

一、推进行政权力运行信息公开

（一）推进行政审批信息公开。梳理完善并及时公开市级保留实施的行政审批事项目录。按照全省统一的市县行政审批事项通用目录，规范各级行政审批事项名称，实现行政审批管理系统与省网上办事大厅汕头分厅无缝对接，及时公开保留、取消、转移、下放以及实施机关变更等行政审批项目信息。推动建立“办事工作日”制度，明确行政审批法定办理时限和承诺办理时限，选择部分市直部门和地区开展行政审批标准化试点，编制并公开行政审批“办事指南”和“业务手册”。（牵头单位：市编办，参与单位：市电子政务办、市信息中心，市有关单位）

（二）推进政府权责清单信息公开。全面梳理市直有关部门行政审批、行政处罚、行政强制、行政征收、行政给付、行政检查、行政指导、行政确认等职权，编制权责清单，并选择部分市直部门作为试点向社会公布。选择部分地区开展纵向权责清单试点，探索编制并向社会公布市、县级政府部门权责清单。（市编办牵头落实）

（三）推进制售假冒伪劣商品和侵犯知识产权行政处罚案件信息公开。除依法需要保护的涉及商业秘密和个人隐私的案件外，对适用一般程序查办的制售假冒伪劣商品和侵犯知识产权行政处罚案件，要在行政处罚决定作出或者变更之日起20个工作日内主动公开案件名称，被处罚者姓名或名称，主要违法事实和处罚种类、依据、结果，行政处罚方式和期限以及作出行政处罚的机关名称等信息。（牵头单位：市打假办、知识产权局，参与单位：市有关单位）

二、推进财政资金信息公开

进一步加大财政资金管理使用情况的公开力度，让“财政资金”在阳光下运行。要严格按照上级有关部署和规定，认真做好预决算信息、“三公”经费信息、财政专项资金及基本建设项目预算信息、财政审计信息的公开工作。（由市财政局、审计局分别牵头落实）

三、加强公共资源配置信息公开

进一步加强公共资源配置信息公开，主动接受社会监督。要严格按照有关规定，继续推进征地信息、土地供应信息和矿业权出让信息公开，推进国有土地上房屋征收与补偿信息公开，推进保障性住房信息公开，加强公共资源交易信息公开，推进工程建设项目信息公开。（由市国土局、住建局、房管局、公共资源交易管理办公室及各类公共资源交易的行政主管部门分别牵头落实）

四、加强公共服务信息公开

各级教育行政主管部门要及时向社会公开招生、考试、收费等方面的政策规定，督促各级各类学校做好校务公开工作，积极推进中小学信息公开工作。

各级科技部门要全面公开科技项目申报指南、申报情况、评审情况、立项情况、执行管理以及验收情况等信息，及时公开科技计划项目信息。

各级卫生计生行政主管部门要督促医疗卫生机构进一步加大医疗服务收费信息公开力度，依托政府部门网站，发布登记注册的医疗机构执业许可证信息。

各级人社部门要及时发布促进就业创业的政策措施、实施情况以及就业创业各项补贴申领条件、申领程序、管理和审批信息。及时公开事业单位招聘公告、考试成绩和拟聘用人员名单等信息。发布全市企业用工、高校毕业生就业岗位等人才供求信息和市场供求分析情况等信息。

各级民政部门要严格执行最低生活保障审核审批公示制度，逐步健全面向公众的最低生活保障对象信息查询机制，进一步完善异议复核制度。

（以上工作由市教育局、科技局、卫计局、人社局、民政局分别牵头落实）

五、加强公共监管信息公开

要把公开透明作为政府工作的基本制度，切实加强公共监管信息公开。要严格按照国家和省有关规定，认真做好环境信息、安全生产事故信息、食品药品安全信息、价格和收费信息、国有企业信息、事业单位信息、信用信息等公开工作。（由市环保局、安监局、食品药品监督管理局、物价局、国资委、市直有关行业主管部门、市信用办分别牵头落实）

六、推进信息公开平台建设

（一）认真落实汕头市人民政府办公室《关于印发省网上办事大厅汕头分厅政务公开栏目建设工作方案的通知》（汕府办〔2014〕48号）要求，按期完成市、各区县政府信息公开目录系统、依申请公开系统和意见箱建设，完善全市政府信息公开目录信息检索功能。（牵头单位：市府办、电子政务管理办公室、信息中心，参与单位：市有关单位）

（二）认真落实汕头市人民政府办公室《关于转发广东省人民政府办公厅关于印发重点领域信息公开专栏建设方案的通知》（汕府办〔2014〕33号）要求，加快推进政府（部门）网站重点领域信息公开专栏建设，按期完成栏目搭建和内容整合，并做好及时更新工作。（牵头单位：市府办、电子政务管理办公室、信息中心，参与单位：市有关单位）

（三）依托政府网站，积极开展在线访谈和网络专题建设工作，及时发布权威政务信息，主动回应社会关切。（牵头单位：市府办、信息中心，参与单位：市有关单位）

七、加强信息公开机制建设

严格落实信息公开属性源头认定机制。进一步规范政府信息主动公开的原则、内容、程序和形式，将政府信息公开的要求固化为文件办理过程的必要环节，对制作或获取的信息明确标注公开属性。健全信息公开指南、目录更新机制。依托全市政府信息公开目录系统，认真编制并及时更新本单位政府信息公开指南、目录。完善信息公开监督指导机制。结合依法行政考评工作，进一步加强对政府信息公开工作的监督检查。建立健全信息公开工作举报制度，依法及时调查处理。进一步完善政府信息公开保密审查制度，对拟公开的政府信息依法依规做好保密审查。

各地各部门要高度重视政府信息公开，按照国务院部署和省政府、市政府要求，狠抓工作落实。要结合本工作要点与《广东省人民政府办公厅关于进一步推进重点领域信息公开的意见》（粤府办〔2013〕38号），抓紧制定本地区、本部门2014年信息公开工作要点，并及时报市政府办公室备案。2014年11月中旬前，各地各部门要向市政府办公室报送信息公开工作要点落实情况报告，市政府办公室将会同有关部门适时对落实情况进行督查。
