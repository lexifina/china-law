# 转发关于做好2014年全国普通高等学校毕业生就业创业工作的通知

汕府办〔2014〕88号

各区县人民政府，市政府各部门、各直属机构：

经市政府同意，现将《广东省人民政府办公厅转发国务院办公厅关于做好2014年全国普通高等学校毕业生就业创业工作的通知》（粤府办〔2014〕37号）转发给你们，结合我市实际，提出如下意见，请一并贯彻执行。

一、进一步完善促进高校毕业生就业创业的政策措施

进一步完善就业专项资金政策措施，在去年市财政局、人力资源和社会保障局联合印发的《关于进一步加强就业专项资金使用管理的实施意见》（汕市财社〔2013〕120号）确定补贴项目的基础上，继续加大对高校毕业生就业创业资金扶持力度。积极为困难高校毕业生发放求职补贴，凡在本市高校就读的毕业年度内有就业愿望并积极求职的城乡困难家庭高校毕业生和残疾高校毕业生，均可申请享受求职补贴，标准提高到1500元/人；大力鼓励高校毕业生面向中小微企业就业，凡应届高校毕业生在我市中小微企业实现就业，签订1年以上期限劳动合同并按规定参加社会保险的，给予每名毕业生一次性2000元的就业补贴；《印发〈关于做好我市2013年普通高等学校毕业生就业工作的实施意见〉的通知》（汕府办〔2013〕92号）中有关“中小微企业每新招收一名应届高校毕业生，与其签订1年以上期限劳动合同并按规定缴纳社会保险费的，给予1000元的一次性补贴”的政策不再执行，其他各项扶持政策继续有效。高校毕业生自主创业和企业招用高校毕业生可享受相关税收减免优惠政策，按《财政部国家税务总局人力资源和社会保障部关于继续实施支持和促进重点群体创业就业有关税收政策的通知》（财税〔2014〕39号）等有关规定执行。贯彻落实《广东省商务厅广东省财政厅关于组织申报2014年省级加快发展服务外包产业专项资金支持项目的通知》（粤商务服函〔2014〕38号）精神，认真做好对服务外包企业新录用大学生奖励相关政策的组织上报工作。

二、大力做好高校毕业生就业公共服务

今年，市人才智力市场、市劳动力市场已整合为市人力资源市场，并加挂市高校毕业生就业指导中心牌子，各区县人力资源市场、各镇（街道）人力资源和社会保障所要尽快挂牌成立高校毕业生就业指导中心。充分发挥政府人力资源市场的优势，积极为高校毕业生提供就业信息、就业培训、创业就业指导等公共服务。各级人社部门、财政部门要协调配合，加大对全国、全省、全市性专场招聘活动经费等扶持公共就业服务支出的保障力度，大力开展公益性就业招聘服务。通过举办“大型高校毕业生就业洽谈会”、“一企一岗•互济共赢”专场招聘会、“高校毕业生网络招聘月”、“高校毕业生就业服务周”等多种形式的招聘活动，积极为高校毕业生与用人单位对接创造条件。各级人社部门要大力实施离校未就业高校毕业生就业促进计划，建立离校未就业高校毕业生实名信息数据库，根据离校未就业高校毕业生的就业意愿、求职意向、培训要求、专业特长、家庭生活状况等情况，积极组织开展就业帮扶和就业援助。

三、积极鼓励和支持高校毕业生自主创业

贯彻落实国家、省、市扶持中小企业政策，充分利用各级中小企业发展资金，支持各类大学生创业园、创业孵化基地和小企业创业基地建设，为高校毕业生提供创业场所支持。贯彻《印发汕头市商事登记制度改革实施方案的通知》（汕府办〔2014〕57号），积极加快推进工商登记制度便利化改革，实施取消公司最低注册资本限制、“先照后证”改革、缩减办证时限、工商登记注册全程免收费等举措，为高校毕业生申请创办企业和个体工商户开通“绿色通道”。改进和完善小额担保贷款政策，鼓励各金融机构积极探索和完善通过抵押、质押、联保、保证和信用贷款等多种方式，多途径为高校毕业生解决担保难问题。银行业金融机构和相关部门要落实对在电子商务网络平台开办“网店”高校毕业生的小额担保贷款和贴息政策。进一步方便异地生源大学毕业生在我市就业创业落户，对经人社部门批准、符合我市落户政策而又没有落户地址的大学生，依据有关规定，简化对用工单位设立公户申请手续，加快审核审批流程。开展新一轮“大学生创业引领计划”，落实和完善工商登记、场地支持、规费减免等创业扶持政策，帮助更多高校毕业生自主创业。建立健全创业服务体系，加强对大学生的创业指导，为大学生提供创业培训、小额担保贷款、跟踪扶持、政策咨询等服务。加快推进市、区两级创业孵化基地建设，为高校毕业生创业提供低租金、低费率和一站式创业服务。实施“2014年展翅计划—广东大学生就业创业能力提升行动”，帮助高校毕业生提升就业创业能力。组织开展“梦想启航•‘创’造未来”—汕头青年创业大赛，广泛开展创业宣传，营造良好的创业氛围。

各区县、各有关部门要认真贯彻执行历年来一系列行之有效的促进高校毕业生就业创业的政策措施，尤其对今年新出台的扶持政策措施要抓紧制定具体操作办法，加大宣传力度，做好相关服务，方便高校毕业生、用人单位享受优惠政策，确保国家、省、市一系列促进高校毕业生就业创业的政策措施落到实处。

汕头市人民政府办公室
