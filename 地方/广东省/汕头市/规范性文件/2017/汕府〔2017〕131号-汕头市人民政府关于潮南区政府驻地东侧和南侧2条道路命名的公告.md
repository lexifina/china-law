# 汕头市人民政府关于潮南区政府驻地东侧和南侧2条道路命名的公告

汕府〔2017〕131号

为加强地名管理，方便潮南区政府周边机关、企事业单位及人民群众的生产生活和交通出行，使地名管理工作更好地为经济建设服务。根据《汕头经济特区地名管理条例》第二十七条的规定，现对潮南区政府驻地东侧和南侧2条道路命名有关事项公告如下：

一、同意对位于潮南区政府驻地东侧和南侧2条道路进行命名（附命名位置示意图）。具体情况如下：

1、玉峡东路 Yùxiá Dōnglù ：位于潮南区政府驻地东侧，南北走向，南起玉峡南路，北至峡溪路，道路长310米，路宽20米；

2、玉峡南路 Yùxiá Nánlù：位于潮南区政府驻地南侧，东西走向，东起峡溪路，西止峡安路，道路长521米，路宽32米。

二、规范命名后的相关配设。潮南区各相关单位在社会行政管理中，涉及公共交通站点、道路交通指示牌、旅游指示牌、地名标志牌、门楼牌等服务设施的，要规范使用标准地名“玉峡东路”和“玉峡南路”，同时要严格执行相关的国家配设标准。

特此公告，希各知照。

汕头市人民政府

2017年12月14日
