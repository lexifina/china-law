# 关于汕头市2015年度就业工作目标责任制考核评价情况的通报

汕府办〔2016〕90号

各区县人民政府,市政府各部门、各直属机构:

根据《关于印发汕头市就业工作目标责任制考核办法的通知》(汕人社〔2016〕7号)的规定,8月23日至26日,市就业工作联席会议牵头组成考评组,对各区县完成2015年度就业工作目标责任制情况进行了考核评议。经市政府同意,现将考评情况通报如下:

一、基本情况

考评结果显示,各区县党政领导高度重视就业工作,按照就业工作目标责任制的要求,将就业工作纳入地方年度工作计划,及时分解下达年度工作目标任务,强化重点项目对就业的引领作用,在2015年度工作任务繁重的情况下,较好完成各项年度就业目标任务。具体表现为,各区县能及时出台贯彻国家和省、市有关部门各项就业政策的实施意见、办法,能按规定落实税费减免、社保补贴、岗位补贴、职业介绍补贴、职业培训补贴、创业培训补贴、技能鉴定补贴、小额担保贷款和高校毕业生临时生活补贴等各项积极就业政策;积极开展对困难群体的就业援助工作,实施按比例安排残疾人就业,落实就业困难对象的安置就业工作,城镇“零就业家庭”动态归零;职业技能培训工作机制进一步健全,各区县结合当地的主导产业,创新培训模式,建立了多形式、多层次的职业技能培训体系;积极开展城乡一体化公共就业服务和管理工作,部分区县创造条件开展创业带动就业工作,创业带动就业孵化基地和创业培训工作初见成效;就业再就业专项资金纳入财政预算,并按规定严格拨付和管理。

二、考评结果

对照《关于开展2015年度全市就业工作目标责任制考核有关事项》(汕人社〔2016〕148号)规定的评价指标,经认真评议,2015年度我市就业考评结果如下:

优秀:龙湖区、濠江区

良好:金平区、澄海区、潮阳区、潮南区、南澳县

就业是民生之本。各区县一定要准确把握就业工作面临的新形势,增强忧患意识和底线思维,坚定信心,扎实工作,沉着应对各种风险挑战,努力确保就业大局稳定,为经济社会发展和全面深化改革事业作出新的贡献。把就业工作放在经济社会优先发展的战略地位,切实加强对就业工作的领导。认真贯彻落实各项就业创业政策,创造条件鼓励和支持劳动者多渠道就业创业。以就业困难群体为重点,切实加强城乡统一的公共就业创业服务工作。各有关部门要树立全局意识,各司其职,协调配合,以政策更完善、制度更健全、管理更高效、群众更受惠为目的,全力以赴做好就业创业工作,共同推动我市就业创业工作上新台阶。
