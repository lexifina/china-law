# 汕头市人民政府办公室转发关于全面推进政务公开工作的意见实施细则的通知

汕府办〔2017〕7号

各区县人民政府,市政府各部门、各直属机构:

现将《广东省人民政府办公厅转发国务院办公厅关于全面推进政务公开工作的意见实施细则的通知》(粤府办〔2016〕130号)转发给你们,经市人民政府同意,提出如下意见,请结合实际认真贯彻执行。

一、认真学习《实施细则》,不断提高政务公开工作水平。《实施细则》从公开工作全链条出发,对着力推进“五公开”、强化政策解读、积极回应关切、加强平台建设、扩大公众参与、加强组织领导等内容进行了全面细化,各级、各部门要学习贯彻《实施细则》,结合今年开展“作风建设年”活动,不断完善政务公开制度,打造阳光政务体系。

二、加快政务公开工作步伐,全面推进政务公开工作。各地各部门要结合实际,全面推动政务公开制度化、规范化、标准化建设。基本形成决策公开、执行公开、管理公开、服务公开和结果公开体系,信息发布、解读、回应联动水平明显提升,“互联网+政务”平台较为完善,公开制度规范与体制机制进一步健全,基本建立与我市经济社会发展相适应、与人民群众需求相匹配的政务公开新格局。

三、加强组织领导,不断完善监督考核体系。各级、各部门要高度重视政务公开工作,切实加强组织领导。要明确一位领导具体分管政务公开工作,列入工作分工并对外公布。进一步理顺政务公开工作机制,明确专门工作机构,配齐配强专职工作人员。要加强考核监督。把政务公开工作纳入政府绩效考核,所占分值权重不低于4%。
