# 关于2017年第三季度全市政府网站抽查情况的通报

汕府办传〔2017〕132号

各区县人民政府，市政府各部门、各直属机构：

根据《国务院办公厅秘书局关于做好政府网站季度抽查工作的通知》（国办秘函〔2016〕48号）、《国务院办公厅秘书局关于2017年第二季度全国政府网站抽查情况的通报》（国办秘函〔2017〕20号）和《广东省人民政府办公厅关于2017年第三季度全省政府网站抽查情况的通报》（粤府办明电〔2017〕173号）的要求，市政府办公室于8月中旬组织开展了2017年第三季度全市政府网站抽查工作，现将有关情况通报如下：

一、总体情况

三季度全市在线运行的政府网站82个，其中市级政府门户网站1个、市级部门及下属机构网站60个、区县政府门户网站7个和区县政府部门网站14个。按照不低于30%的要求，市府办随机对25个网站进行了健康状况抽查，同时对各区县、各部门办理网民纠错留言、转载重要政策信息、清理废弃域名以及落实集约化建设情况进行了检查。从抽查情况看，大部分政府网站能够认真落实政府网站工作各项要求，加强信息内容建设，不断提升运维保障水平，健康状况抽查合格率达96%（存在突出问题的网站名单附后）。

二、存在问题

（一）部分政府网站常态化运维和监管不到位，信息更新不及时、互动回应不积极、网站无法访问或错链断链等问题依然存在。如：潮南区两英镇政府、潮阳区编办等网站首页更新不及时；六区一县政府门户网站均不同程度存在栏目更新不及时和空白栏目问题；个别单位网站在监测时段内存在无法正常访问情况；还有部分网站未开设民意征集栏目或开展次数较少，政务咨询回复也不够及时。

（二）集约化建设落实情况不到位、工作不规范。目前我市在全国政府网站信息系统中登记的网站已由二季度的121个减至72个，集约化建设取得一定进展，但仍存在一些问题：部分区县对所辖政府网站监管指导不严，个别网站在上级批准关停前已无法访问；潮阳区至今还有拟关停网站未完成相关手续；南澳县旅游网在永久关停后仍违规运行；潮南区城乡规划局网站在发布关停公告后未及时做好数据迁移，导致我市同一批申请关停的网站被省府办驳回重新申请。

（三）落实上级重点工作部署力度不够。近期，我市按照省统一部署，先后组织开展了政府网站“问题地图”清查、政府网站查遗补漏、政府网站安全风险评估与检查等工作，并就政府网站“重要政策信息转载专栏”和“我为政府网站找错监督平台”全覆盖情况进行了检查。在上述任务下达后，部分政府网站主办单位行动迟缓，未迅速部署落实、按时上报情况，经多次催办仍无反馈，对网站和信息安全问题未给予足够重视。

三、下一步工作要求

（一）积极做好《政府网站发展指引》贯彻落实工作。各区县、各部门要认真贯彻落实《国务院办公厅关于印发〈政府网站发展指引〉的通知》（国办发〔2017〕47号，简称《指引》）各项要求，对照《指引》中关于网站开设整合、域名、名称、网页设计、信息发布等标准规范，抓紧对本地区、本部门网站进行优化调整，确保今年12月底前全部完成。要按照《指引》具体要求编制本地区、本部门政府网站监管年度报表和政府网站年度工作报表，于每年1月31日前向社会公开。

（二）切实发挥常态化监管机制作用。各区县、各部门要认真履行运维管理职责，对照国办普查标准，加强信息更新维护，加密网站巡查频次，落实安全管理责任，确保不留死角、不打擦边球。网站改版或整改需要一定时间的，主办单位应申请临时下线（每年只能一次，每次不超过30天），待改版或整改完成后及时恢复上线。市府办将继续做好季度巡查抽检，监督问题网站整改落实情况，对问题严重的网站进行通报批评，确保全市政府网站健康运行。

（三）规范政府网站基本信息更新。各区县、各部门要对全国政府网站信息报送系统中本单位政府网站信息，包括网站名称、ICP备案号、首页网址、网站负责人和联系人信息、栏目地址等进行全面核查，确保网站基本信息准确、完整。今后如遇网站改版、栏目调整、域名变更、人员变动等导致网站基本信息发生变化，各单位应于3个工作日内在系统及时更新并报市府办核准。

（四）提高网民纠错留言办理工作效率，规范重要政策信息转载专栏建设。各区县、各部门网站要抓紧完成“重要政策信息转载专栏”的规范建设，确保在首页显著位置及时转载国务院及省政府重要政策信息；落实专人做好“我为政府网站找错”留言办理，网民留言后必须在1个工作日内通过系统提交办理意见， 逐级上报省府办公厅，超期未答复和答复质量不高被退回重办的，将在下一季度进行通报。

（五）严格按程序推进政府网站集约化建设。各区县、各部门要按照粤办函〔2017〕156号和汕府办〔2017〕41号、汕府办函〔2017〕215号文提出的工作要求，加快推进政府网站集约化建设。对外服务较少及没有人力、财力保障的市直部门网站应将相关功能整合迁移至市级政府门户网站，以栏目或频道形式呈现，实现统一运维。申请永久关停的政府网站主办单位应逐级上报审核；在省府办公厅最终核准前，要持续正常运维至数据迁移结束，并在首页显著位置持续1个月悬挂网站关停和内容迁移去向等公告信息；省府办公厅核准关停后，网站主办单位应及时注销域名、注册标识和证书信息。

（六）做好区县拟保留网站运维管理工作。根据省府办公厅《全省基层政府网站集约化建设拟保留网站名单》，我市4个区县教育信息网延期至2018年6月30日前关停。金平区、龙湖区、潮阳区、潮南区政府要切实履行监管职责，与教育信息网主办单位签订运维责任书，及时发现问题，督促落实整改。同时，抓紧制订4个网站迁移整合方案及工作计划（10月底前书面上报市府办），按规定时间节点完成关停迁移工作。

对此次被通报的存在突出问题网站，有关区县要高度重视，采取有力措施落实整改，于10月20日前将整改情况书面报送市府办。
