# 关于印发脑瘫儿童康复救助意见的通知（已废止）

汕残联〔2017〕3号

各区县残联、人社局、财政局、卫计局,市社保局:

《汕头市残联 人社局 财政局 卫计局关于脑瘫儿童康复救助意见》业经市法制局法律审查,现作为规范性文件予以印发,请认真贯彻执行。

汕头市残疾人联合会

汕头市人力资源和社会保障局

汕头市财政局

汕头市卫生和计划生育局

2017年1月16日

汕头市残联 人社局 财政局 卫计局关于脑瘫儿童康复救助意见

脑瘫作为一种严重的致残性疾患,导致大量患者运动障碍和姿势异常、生活不能自理,其治疗康复综合性强、专业要求高,伴随着不少患者及其家庭漫长的一生。总结近年实践,根据《汕头经济特区残疾人扶助条例》及健康汕头、残疾儿童免费抢救性康复训练等相关政策,特制定本意见。

一、任务目标

(一)完善救助政策,切实减轻脑瘫患者家庭负担;

(二)大幅提高0-6周岁脑瘫儿童矫形器适配、抢救性康复训练专业水平;

(三)完善脑瘫患者“婴幼儿治疗--儿童抢救性康复训练--特殊教育--家庭康复培训--社区康复训练”的救助链条,推动更多患者自理自立;

(四)发挥好汕头市级医院专业优势,大力推动医教结合,重点提升婴幼儿患者康复治疗水平。

二、具体措施

(一)增加汕头市脑瘫儿童门诊康复治疗医保定点机构,扩大短期救助政策覆盖面

1、汕头市中心医院、汕头大学医学院第一附属医院及汕头大学医学院第二附属医院为本市脑瘫儿童指定康复医疗机构。0-6周岁参保人经指定康复医疗机构确认有康复价值、在指定康复医疗机构门诊进行脑瘫肢体综合训练,且参照设置家庭病床办法备案的,其门诊综合训练的基本医疗费用,纳入城乡居民基本医疗保险统筹基金支付范围。脑瘫康复肢体综合训练的门诊基本医疗费用限额为每月2000元,不设起付标准,统筹基金的支付比例为75%。办理备案手续时,参保人年龄在3周岁以前(含3周岁)的,统筹基金每年支付不超过6个月。办理备案手续时,参保人年龄超过3周岁的,统筹基金每年支付不超过3个月。参保人办理备案手续后,应在其备案的医疗机构进行康复就诊。参保人在其办理备案手续以外的医疗机构发生的康复就诊医疗费用,基本医疗保险基金不予支付。

2、本市0-6周岁脑瘫儿童在市残联定点康复医疗机构康复治疗且没有纳入抢救性康复项目资助的,剔除医保报销部分,经医院确认有康复价值的家庭贫困者可通过机构向市残联申请每月每人250元的短期基本康复训练救助,资助时间与医保相关政策同步。由受助对象监护人凭:监护人及儿童户口簿、儿童或监护人银行存折账户、疾病诊断证明的复印件向定点医院提出申请,填写《汕头残联脑瘫儿童医疗康复救助审批表》一式两份,经定点医院审核汇总后,填写《汕头残联脑瘫儿童医疗康复救助经费发放汇总表》一式两份,于每年6月及11月上报市残联审核同意后,直接将救助款划拨至受助对象或监护人银行账号。

3、本《意见》新增纳入我市定点脑瘫康复医疗机构的汕头市中心医院、汕头大学医学院第一附属医院,应尽快完成系统改造、端口设置对接并落实相关业务培训工作,严格按规定为参保患者提供相关康复诊疗服务。相关医院在完备医保经办的有关规范要求后,才纳入医保费用的支付结算。

(二)把市级专业医院纳入承担残联系统抢救性康复项目的定点机构,促进医教结合,加大对脑瘫儿童救助力度

按照《广东省残疾儿童康复救助实施办法》(粤残联〔2016〕86号)机构认定要求,把汕头市中心医院、汕头大学医学院第一附属医院及汕头大学医学院第二附属医院纳入脑瘫儿童定点康复训练机构,承担我省脑瘫儿童抢救性康复救助项目任务。

1、服务对象:广东省户籍、0-6周岁脑瘫患者且需在机构康复训练连续超过半年以上者;

2、申报程序:参照《广东省残疾儿童康复救助实施办法》(粤残联〔2016〕86号)相关规定执行,符合条件的对象由定点机构先登记、建档、收训、按要求向市残联集中申报。经费核拨按市残联、市财政局相关要求执行。

3、资助标准:按全日制每人每月1200元、半日制每人每月600元的标准资助脑瘫儿童康复训练费(每学年10个月,连续训练时间不少于半年)。主要用于:受助对象康复训练、康复效果评估费、家长培训、家庭康复指导、康复档案及训练教材、购买服务等费用。

在此基础上,本市0-6周岁脑瘫儿童按规定享受免费抢救性康复服务,医院预先收取的总费用不得超过国家、省项目补助金额。

享受该项补助的对象,不能同时向市残联申请每月250元的短期基本康复训练救助。

4、服务内容:根据省抢救性康复救助项目规定进行医疗康复或引导式教育训练。要主动发挥好医疗专业优势,从患者实际需要出发,给予最有效的康复手段、训练服务。通过加强与市残疾人康复中心合作,取长补短,把省抢救性康复救助项目要求落到实处。对全日制康复训练患者,需提供免费午餐。

5、信息统计:承担残联系统抢救性康复项目的定点机构,要按照要求对救助对象进行康复训练和阶段性康复效果评估,做好相关资料的审核、收集、存档、上报工作,并录入《贫困残疾儿童康复救助项目数据库管理系统》(http://portal.cdpf.org.cn/sysmgr/);同时,填写残疾儿童抢救性康复项目登记表,将信息在线实时录入《中国残疾人事业业务数据统计管理系统》(http://stats.cdpf.org.cn/netrep/index.jsp)康复台账数据库。

(三)全面提升残联系统及区县免费抢救性康复服务能力

1、认真落实免费抢救性康复政策。在残联系统公办机构康复训练的0-6周岁脑瘫儿童,按国家、省规定标准补助,在市残联定点民办康复训练机构训练的,按市残联、市财政局相关文件精神执行。

2、加强市残疾人康复中心的软硬件建设,充实技术力量。在省二级机构基础上,加强专业建设,力争于2018年底达到省一级机构标准,在训脑瘫儿童90人以上。

3、鼓励、扶持区县残联扩大服务能力,提升脑瘫康复项目质量。与区属医院合作项目,可参照本办法执行。

(四)完善辅具适配政策

着力解决矫形器、站立架等辅助器具质量问题,输送人才接受专业培训,大幅度提高制作装配水平,并根据脑瘫患者生理发育需要,定期免费置换。

(五)把人才培养放在更加重要位置

1、市残疾人康复中心按照上级建设规范,通过设置公益岗位、政府购买服务,加强康复专业人才的培养。加强与广东省残疾人康复中心、香港耀能协会等境内外专业机构合作,走出去、请进来,帮助更多一线人员取得康复专业人员资格认证。

2、完善残联系统与医疗机构专业人员交换实习、交叉培训机制,整合脑瘫儿童医疗、康复、教育手段,提升专业技术水平。

(六)为脑瘫患者家庭提供更多人文关怀

1、鼓励各区县残联和相关机构自行制订补助范围和标准,对在非中心城区进行康复训练, 经济确有困难的本市户籍脑瘫儿童,其负责接送的家属(限一人),补贴其公共汽车交通费用。

2、每三个月一次对家长集中免费培训,向家长普及脑瘫康复知识及康复训练方法,推动脑瘫家庭康复专业化。

3、办好市残联特殊妈妈爱乐团,组织脑瘫、视障、智障、孤独症等类残童母亲进行活动,搭建交流平台,举办心理讲座、医疗康复讲座,缓解脑瘫家庭压力。

(七)强化宣传

办好汕头市脑瘫康复热线(88237008)。制作宣传小册子、宣传海报、公益广告,宣传脑瘫康复知识及救助政策。

三、资金保障

(一)符合医保规定报销的医疗费用按医保政策列支。(二)脑瘫儿童门诊康复短期基本救助在汕头市残疾人医疗康复救助基金或市项目救助经费中列支。

(三)残联系统定点康复机构在训脑瘫儿童康复训练所需经费在国家、省项目救助经费列支。

(四)矫形器、站立架及轮椅适配和置换所需经费在国家、省项目救助经费及市残疾人医疗康复救助基金列支。

四、建立部门协作沟通机制

市残联会同市人社、财政、卫计等部门建立沟通协作制度,结合残疾儿童抢救性康复、健康汕头、推进基本公共卫生服务等项工作,实实在在帮助脑瘫患者解决具体问题。市残联根据本意见实行及相关政策调整情况,及时牵头完善我市脑瘫康复救助措施。

五、本意见由市残疾人联合会负责解释。

六、本意见自2017年2月1日起施行,有效期至2022年1月31日止。有效期届满,经评估认为需要继续施行的,根据评估情况重新修订。为保证救助的连续性,本意见出台前的救助按原意见执行。
