# 汕头市人民政府办公室关于2018年第二季度全市政府网站抽查情况的通报

汕府办传〔2018〕53号

各区县人民政府，市政府各部门、各直属机构：

根据《国务院办公厅秘书局关于做好政府网站季度抽查工作的通知》（国办秘函〔2016〕48号）、《国务院办公厅关于印发政府网站发展指引的通知》（国办发〔2017〕47号，以下简称《指引》）以及《广东省人民政府办公厅关于2018年第二季度全省政府网站抽查情况的通报》（粤府办明电〔2018〕78号）有关要求，市政府办公室组织开展了2018年第二季度全市政府网站抽查工作，现将有关情况通报如下：

一、总体情况

第二季度全市在线运行的政府网站67个。市府办此次随机抽查了27个政府网站的健康情况，并对各区县政府、各部门网站标识码、网站地图等栏目标识规范性和“我为政府网站纠错”办理、落实上级重点工作部署等情况进行了检查。

从检查情况看，大部分政府网站能认真落实国办、省府办公厅和市府办有关要求，加强信息内容建设，不断提升运维保障水平，健康状况总体合格率92.59%（存在较突出问题的网站名单附后）。

二、存在问题

（一）部分网站管理不到位，信息长期未更新、空白栏目等问题依然存在。市公路局网站因首页长期未更新在第一季度全国政府网站抽查中被国办通报，市文广新局网站因首页长期未更新在第二季度全省政府网站抽查中被省府办通报；市知识产权局、市民政局、市供销社等网站部分栏目更新不及时；六区一县政府门户网站均不同程度存在信息更新不及时、空白栏目等问题。

（二）栏目标识不规范。目前，我市各级政府网站大部分已按要求在首页底部列明网站标识码、ICP备案编号、公安机关备案标识、站点地图及添加“我为政府网站找错”监督举报平台入口，但个别网站如市国资委网站因网页底部功能区未添加“我为政府网站找错”监督举报平台入口和公安机关备案标识，在第二季度全省政府网站抽查中被省府办通报；市环卫局、市人才局、市供销合作总社等网站域名不规范，仍以“.org.cn”“.com.cn”“net”为后缀；市旅游网和市环保局等网站未以机构名称命名。

（三）个别网站互动回应栏目建设较为薄弱。如市知识产权局网站年内未开设调查征集栏目；潮阳区政府门户网站1年内未开展调查征集活动；濠江区政府门户网站1年内开展调查征集活动少于6次。

（四）落实上级重点工作不到位。重要政策信息转载不及时，市旅游局、市海洋渔业局、市安监局等“政声传递”转载时间超过12小时。“我为政府网站找错”问题整改不到位，市房管局、市人才局、市教育局等访问较多的网站被网民多次指出内容无法访问或内容不准确等问题。

三、下一步工作要求

（一）进一步加强常态化监管，推进网站规范性管理。市府办将持续做好网站监测抽查工作，结合我市政府网站集约化建设，对拟保留网站加大监管问责力度，确保问题整改到位。各区县、各部门要认真对照并逐项落实《指引》要求，进一步规范政府网站名称、域名和网站标识码、网站地图以及“我为政府网站找错”监督举报平台入口添加等工作。要认真贯彻执行国务院办公厅《“我为政府网站找错”网民留言办理规范》，及时办理省府办公厅转发的网民留言，确保收到网民留言后1个工作日内在系统提交办理意见，并针对网民指出的问题积极落实整改，举一反三，加强网站内容建设。网站日常监测和抽查情况、网民留言办理答复情况、落实上级重点工作部署等情况继续纳入全市政府网站年度考评。

（二）加快推进网站集约化建设，提升我市政府网站整体运维水平。根据省府办公厅要求，市府办将进一步加大对市直部门网站的集约整合力度，实现统一建设、统一管理、统一防护。拟关停的市直部门网站必须在8月15日前按程序完成关停迁移工作，杜绝“擅自关停”“关停不公示”“关停不注销”“关停仍运行”等违规行为。各区县、各部门要积极参与全市政府网站集约化建设，配合做好网站整合迁移工作。

（三）及时更新政府网站基本信息，确保全国政府网站信息报送系统资料无误。各区县、各部门要对全国政府网站信息报送系统中登记的网站信息进行全面核查，包括网站名称、ICP备案号、首页网址、各栏目地址、网站负责人和联系人及联系方式等，确保基本信息准确、完整。如以上信息发生变化，必须及时向市府办（具体联系市信息中心）报备并在2个工作日内通过全国政府网站信息报送系统完成修改更新。

（四）完善网站安全保障机制，保障网站安全运行。各区县、各部门要严格落实网络安全工作责任制，明确分管领导和岗位责任，完善政府网站安全防范和应急处置工作机制，加强重要时期的政府网站风险排查和7×24小时值班值守，会同本地网信、公安、通管等部门切实做好防攻击、防篡改、防病毒、防瘫痪、防劫持、防泄密等工作，确保网络安全事件发生后第一时间响应，第一时间处置恢复。

对此次被通报的问题突出网站，请有关部门高度重视，立即采取有力措施落实整改，于8月8日前将整改情况书面报送市府办。
