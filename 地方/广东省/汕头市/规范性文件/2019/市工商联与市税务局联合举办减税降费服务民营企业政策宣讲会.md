# 市工商联与市税务局联合举办减税降费服务民营企业政策宣讲会

为深入贯彻习近平新时代中国特色社会主义思想和党的十九大精神，根据国家税务总局广东省税务局、广东省工商业联合会关于大力支持服务民营企业发展壮大合作框架协议的要求，推动“减税降费”政策落地生根，确保民营企业尽享改革红利，7月12日，市工商联与市税务局联合在花园宾馆举办了“联手筑税企桥梁，协同享改革红利”减税降费服务民营企业政策宣读会。我会及市税务局相关科室人员，涉税专业服务同心志愿团成员以及我市民营企业家代表共200多人参加了宣读会。

会上，汕头市税务局货物与劳务税科业务骨干方旖旎做政策解读，向民营企业剖析深化增值税改革相关税收政策；尤尼泰广东税务师事务所汕头分所讲师郑翀结合工作案例，对2019年国家“减税降费”政策进行解读。

涉税专业服务同心志愿团成员广东中税佳税务师事务所、汕头市扬正税务师事务所、尤尼泰广东税务师事务所汕头分所在会场设置咨询台，现场为民营企业提供咨询，为企业解决纳税过程中遇到的各种问题。

会议还向与会企业家分放了《深化增值税改革100问》、《小规模纳税人免征增值税操作指南》、《一般纳税人转登记小规模纳税人操作指南》、《加力！减税降费增值税再加力！》等相关减税降费小册子。
