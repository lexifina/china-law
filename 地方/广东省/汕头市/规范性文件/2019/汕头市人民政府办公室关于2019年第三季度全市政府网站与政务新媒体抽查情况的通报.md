# 汕头市人民政府办公室关于2019年第三季度全市政府网站与政务新媒体抽查情况的通报

各区县人民政府，市政府各部门、各直属机构：

根据《国务院办公厅关于印发政府网站发展指引的通知》（国办发〔2017〕47号）、《国务院办公厅秘书局关于印发政府网站与政务新媒体检查指标、监管工作年度考核指标的通知》（国办秘函〔2019〕19号）以及省政府办公厅要求，市政府办公室组织开展了2019年第三季度全市政府网站与政务新媒体抽查工作，现将有关情况通报如下:

一、总体情况

目前我市在全国政府网站信息报送系统登记的政府网站共10个（其中市级门户网站1个、市级部门网站2个、区县政府门户网站7个），在广东省政务新媒体管理系统登记备案的政务新媒体102个。

第三季度，市府办对照国务院办公厅印发的《政府网站与政务新媒体检查考核指标》，对全市在线运行的10个政府网站和41个市直部门频道进行了全覆盖检查，并对各区县、各部门落实网站意识形态工作责任制和网络安全工作责任制、纠错留言办理、问题工单处理、重要时段安全防护等工作进行了抽查。从检查结果看，绝大多数政府网站主办单位能认真落实国办和省政府办公厅有关要求，加强信息内容建设，不断提升运维保障水平，问题整改也比较到位，基本达到国办规定的网站普查标准，总体合格率100%。同时，市府办对102个政务新媒体三项“单项否决”指标（安全问题、内容更新、互动回应）落实情况进行了检查。从检查结果看，绝对大数政务新媒体能够认真做好政务信息发布和互动回应工作，但个别政务新媒体仍存在信息更新不够及时、办事互动功能弱等问题，总体合格率100%。

二、存在问题

（一）网站日常运维存在薄弱环节。

抽查发现，个别网站首页长期不更新或站内多个栏目更新不及时；有的网站发布的办事指南存在“办理地点”等内容不准确问题；部分网站信息审核把关不严，出现严重错别字。

（二）政务新媒体运维管理有待加强。

抽查发现，部分政务新媒体仍存在内容更新不及时、无有效互动功能的问题；个别政务APP维护不到位，导致网民无法正常下载，且客户端内容长期未更新。个别区县未落实监管责任，辖区内已报备注销的政务新媒体仍在违规运作、并未停更、注销帐号。此外，龙湖区、濠江区及澄海区政务新媒体整合力度有待加强。

三、下一步工作要求

（一）夯实网络意识形态工作责任，确保政府网站和政务新媒体安全运行。

各区县、各部门要进一步提高政治站位，坚决落实网络意识形态工作责任制和网络安全责任制，按照“属地管理、谁主管谁负责、谁主办谁负责”的原则，层层压实安全责任。进一步完善网站（含频道）和新媒体内容运维及信息发布审查机制，规范网上留言、网上投诉、网上举报等互动交流平台管理，严格执行上网信息先审后发制度，确保不出纰漏。

（二）进一步完善政府网站功能设置，不断提升政府管理服务水平。

各区县、各部门要按照国务院办公厅最新考核指标要求，建立健全有效咨询建言渠道，完善政民互动留言办理机制，提高留言办理答复的时效性。有对外服务职能的部门，要按照标准规范及时修订、完善办事指南，优化在线服务功能，提供准确实用的网站搜索，不断提升政务服务水平。

（三）继续做好清理规范，促进政务新媒体健康有序发展。

各区县、各部门要严格按照《广东省推进政务新媒体健康有序发展的实施意见》（粤办函〔2019〕90号）和《汕头市人民政府办公室关于印发汕头市推进政务新媒体健康有序发展实施意见的通知》（汕府办函〔2019〕75号）要求，进一步推进本地区、本部门政务新媒体的集约整合工作。区县政府部门原则上不单独开设新媒体账号；对功能定位不清晰、信息长期未更新、不互动无服务、监管不到位的，要坚决关停；已发布停更、注销公告的，要按程序尽快完成注销手续；对功能相近、用户关注度和利用率低的，要清理整合，将信息发布、政民互动、办事服务等功能集成到一个账号，做优做强；对信息更新慢、内容推送迟、交流互动差、办事效率低的，要限期采取措施整改到位。各区县、各部门要认真查缺补漏，及时通过省政务新媒体管理系统对保留的政务新媒体进行备案。同时，主办单位要加强政务新媒体的内容保障和日常监管，提高信息更新频率，保证信息发布、解读回应质量，优化政务新媒体上提供的办事服务和互动交流功能，切实提升各级政府在移动端的办事服务能力。

（四）积极配合省推进政府网站集约化建设，按时保质完成我市政府网站迁移工作。

各区县、各部门要认真按照《广东省人民政府办公厅关于印发地级以上市政府网站集约化工作方案的通知》（粤办函〔2019〕2号）要求，积极配合省、市集约化迁移实施单位做好相关工作，及时反馈使用情况，确保新旧网站无缝衔接，按时保质完成网站迁移工作任务。

对此次通报存在较突出问题的政府网站（含频道），各区县、各部门要高度重视，立即采取有效措施落实整改，于11月25日前将整改情况书面报送市府办。
