# 汕头市人民政府办公室关于“八一”建军节期间开展拥军优属活动的通知

汕府办传〔2019〕32号

各区县人民政府，市政府各部门、各直属机构:

今年是中国人民解放军建军92周年，在“八一”建军节即将到来之际，为扎实做好节日期间拥军优属工作，进一步巩固军政军民团结,加强国防和军队建设，促进经济社会发展和谐稳定，现就有关事项通知如下：

一、广泛开展宣传教育，大力营造浓厚的爱国拥军社会氛围

各地各部门要以习近平新时代中国特色社会主义思想为指引，深入贯彻落实党的十九大、十九届二中、三中全会精神，认真学习贯彻习近平总书记系列重要讲话和对广东的指示批示精神，特别是加强军政军民团结的重要论述。牢牢把握军民融合发展上升为国家战略的时代要求，不断增强广大干部群众的国防观念和拥军意识。充分利用报刊、广播、电视、网络等媒体，大力宣传在党的领导下，军民团结奋斗的光辉历程、携手建立的丰功伟绩；大力宣传驻汕部队忠实履行使命，在参建维稳、抢险救灾、脱贫攻坚中做出的重大贡献和拥政爱民的先进事迹；大力宣传老红军、军队离退休干部、烈军属、残疾军人和转业复员退伍军人为推动国防和军队现代化建设所作的重大贡献；大力宣传社会各界和广大人民群众爱国拥军的动人事迹，在全社会形成“军爱民、民拥军、军民团结一家亲”的浓厚氛围。通过组织干部群众和部队官兵参观革命历史纪念场馆，举办群众性文艺创演、知识竞赛、读书演讲、优秀影视展播和军营开放日等活动，使广大军民在潜移默化中受到革命传统教育和红色基因熏陶，推动形成关心国防、尊崇军人的良好社会风尚。

二、聚焦军队建设改革，积极帮助部队解决实际问题

各地各部门要提高政治站位，着眼国防和军队建设改革实际需求，强化支持军队改革和服务练兵备战意识，推动双拥工作向备战打仗聚焦用力。利用召开“八一”军政座谈会、双拥联席会和走访慰问等时机，主动了解部队建设改革中需要地方支持的事项，倾力帮助转隶移防、新调整组建部队解决战备训练、工作生活等方面遇到的实际困难。配合加快建立健全拥军支前军地协调机制，动员组织各方面力量支持部队遂行演习、战备执勤、应急拉动、维稳处突等任务，跟进搞好场地交通、水电食宿、卫生医疗等保障，为部队提升实战化水平创造良好条件。持续推进助力退役军人安置、助力随军家属就业“双助力”工程，集中协调解决一批退役军人安置、家属随军就业、子女入学转学等方面的问题，切实为部队官兵解除后顾之忧。广泛发动各级双拥工作领导小组成员单位和“两新”组织、志愿者等社会力量，踊跃开展行业拥军和社会化拥军活动。围绕基层部队所需，开展精准拥军，深入到边防、海岛等偏远艰苦连队，广泛开展为基层官兵送温暖、送医疗、送文化、送政策、送服务等“五送”活动。积极协调解决好基层官兵的后路、后院、后代“三后”问题，激发官兵扎根军营、建功立业的政治热情。

三、广泛开展走访慰问，帮助广大优抚对象解决实际困难

各地各部门要按照市委、市政府的安排部署和有关要求，坚持“普遍走访、重点慰问”的原则，把解决退役军人和优抚对象遇到的实际困难作为“八一”期间双拥工作的重要内容，有针对性地搞好调查摸底，用足用活现有政策和救助平台，扎实做好帮扶解困工作。特别是对已安置又下岗失业和因遭遇自然灾害、重大疾病等变故存在特殊困难的，要依托社会保障和救助体系，尽力予以帮助解决，保障好他们的基本生活。对生活特别困难的，要加大帮扶解困力度，明确帮扶目标，发动组织社会力量，积极为他们提供物质资助、精神抚慰、心理援助等精准化、个性化服务保障。各地各部门依托各级办事机构，依法优先、快捷高效办理军人军属涉法涉诉等纠纷，切实维护军人军属和广大优抚对象的合法权益。大力扶持退役军人就业创业，落实各项优惠政策，引导他们投身大众创业、万众创新实践，更好实现自身价值、展现良好精神风貌。

在“八一”期间要开展走访慰问退役军人、优抚对象活动，把走访慰问当作一次暖心行动，科学谋划，精心部署，加强与当地企事业单位沟通协调，进一步细化工作方案，做到不重不漏，确保走访慰问实际成效。通过走访慰问，进一步检查督导优抚安置政策落实情况、进一步了解“光荣之家”牌匾是否悬挂到位，了解他们生产生活情况和思想情况等，积极开展排忧解难和思想疏导工作，切实把党和政府的关心和温暖送到广大退役军人、优抚对象的心坎上。

四、紧贴经济社会发展需求，广泛开展爱民助民惠民活动

驻汕各部队要在完成军事任务前提下，大力弘扬拥政爱民光荣传统，充分发挥自身资源和优势，多办解民忧、惠民生、暖民心的好事实事。认真贯彻中央关于打赢脱贫攻坚战三年行动指导意见，扎实做好定点扶贫工作，组织官兵深入扶贫联系点、援建学校、驻地村镇开展义务巡诊、结对助学、智力帮扶等活动，帮助建档立卡贫困户和特困家庭解决实际困难，密切党和军队与人民群众的血肉联系。围绕驻地建设发展总体规划，相对集中使用义务劳动日时间，为地方经济社会发展贡献力量。野外驻训和演习部队要利用任务间隙，积极为当地群众做好事办实事，加强群众纪律检查监督，维护人民军队良好形象。当前，我省已全面进入主汛期，驻汕部队要密切关注汛情，充分做好抗洪抢险准备，确保遇有灾情迅即出动，全力保护人民群众生命财产安全。

节日期间，各地各部队走访慰问和军民联谊联欢活动要严格落实改进作风要求，坚持俭朴节约，务求实效。活动情况请于8月15日前报市退役军人事务局。

汕头市人民政府办公室

2019年7月12日
