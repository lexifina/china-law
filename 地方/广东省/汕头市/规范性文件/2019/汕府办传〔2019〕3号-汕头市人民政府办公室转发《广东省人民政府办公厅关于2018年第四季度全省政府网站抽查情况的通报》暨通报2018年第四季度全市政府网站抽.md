# 汕头市人民政府办公室转发《广东省人民政府办公厅关于2018年第四季度全省政府网站抽查情况的通报》暨通报2018年第四季度全市政府网站抽查情况的通知

汕府办传〔2019〕3号

各区县人民政府，市政府各部门、各直属机构：

根据《国务院办公厅关于印发政府网站发展指引的通知》（国办发〔2017〕47号）、《国务院办公厅关于加强政府网站域名管理的通知》（国办函〔2018〕55号）和《国务院办公厅秘书局关于做好政府网站季度抽查工作的通知》（国办秘函〔2016〕48号）等要求，现将《广东省人民政府办公厅关于2018年第四季度全省政府网站抽查情况的通报》（粤府办明电〔2018〕214号）转发给你们，并通报我市2018年第四季度政府网站抽查情况，请按照省、市的要求加大工作力度，不断提升我市政府网站运维管理水平和服务能力。

一、总体情况

（一）上级抽查情况。

广东省2018年第四季度政府网站抽查中，我市政府网站抽查合格率100%。

（二）我市抽查情况。

去年以来，我市大力推进基层政府网站关停整合和全市政府网站集约化建设。至2018年第四季度抽查开始前，我市在全国政府网站信息报送系统中登记运行的政府网站由58个缩减为12个（包括1个市级门户网站、4个市直部门网站、7个区县政府门户网站），46个市直部门网站以频道专栏形式整合至市政府门户网站。

按照年度工作安排，结合我市政府网站集约化建设情况，市政府办公室组织开展了2018年第四季全市政府网站抽查，对12个政府网站以及46个市直部门频道专栏健康状况进行了全面检查，并对各区县、各单位落实网站意识形态工作责任制、纠错留言办理、域名规范及重要敏感时期安全防护等工作进行了检查。从检查情况看，大部分政府网站（含频道专栏，下同）能认真落实上级关于政府网站工作的有关要求，加强信息内容建设，不断提升运维保障水平，总体合格率96.6%（存在突出问题的政府网站名单附后）。四季度我市收到“我为政府网站找错”留言38件，均在规定时限内办结。

二、存在问题

（一）个别市直部门网站改为集约化频道专栏后放松日常维护，出现首页或栏目长期未更新问题。市民宗局、市国土局、市城乡规划局“工作动态”等栏目也存在更新不及时问题。

（二）区县政府门户网站信息更新不及时问题较为突出。特别是政府信息公开目录（含区县所属部门公开目录）更新不及时，多次被网民纠错；个别网站的空白栏目问题较严重。

（三）办事指南不准确不规范的现象普遍存在。如市外事侨务局办事指南中时间要素不符合规范，在四季度全省监测中被列为整改问题；不少单位办事指南中咨询监督、法律救济的相关网址已无法访问。

（四）存在严重错别字。潮阳区人民政府门户网站、龙湖政府门户网站以及市外事侨务局频道专栏均出现严重错别字。

三、下一步工作要求

（一）严格落实网站意识形态和安全工作责任制，确保网站安全运行。各区县、各部门要按照“属地管理、谁主管谁负责、谁主办谁负责”的原则，进一步提高政治站位，夯实网站意识形态安全防范和应急处置工作。进一步完善网站内容保障和信息审核发布机制，落实日常巡查和读网制度，规范网上留言、网上投诉、网上举报等互动平台管理，严格执行信息先审后发制度，确保不出纰漏。各单位应切实履行主管主办职责，不得将网站管理责任推卸给技术部门或外包单位。市政府办公室将把网站政治安全问题纳入全市政府网站考评指标，严格执行“一票否决”制，各区县和市直部门网站发生政治安全事件的不得参与当年全市政府网站评优。

（二）加强网站常态化监管，推进网站规范化建设。各级政府网站主管主办单位要进一步加强网站内容和安全日常监管，尤其对涉及单项否决的首页长期不更新、空白栏目、严重错别字等问题要提高自查比例，及时查漏补缺。每月要对本地区、本单位政府网站进行全覆盖检查，如发生安全事件应第一时间向市政府办公室及相关部门报告。同时，要按照《政府网站发展指引》，进一步规范政府网站域名、名称、标识添加等工作。

（三）做好机构改革后涉改单位网站的调整工作。各区县、各部门要根据本地区、本部门机构改革情况，分类施策，切实做好政府网站新建、关停、改版、迁移等工作。新组建单位如需开通政府网站应严格按流程进行，经本部门主要负责同志同意后，向市政府办公室提出申请，逐级审核后报省政府办公厅批准。新建及划归政府序列的网站须按程序在全国政府网站信息报送系统中登记注册，纳入统一监管。撤并整合不再保留的政府部门应做好频道专栏内容迁移。由政府序列划归党委序列且继续保留的网站，须报告省政府办公厅统一商请国务院办公厅在全国政府网站信息报送系统中作相应调整。凡网站基本信息发生变更的，均应及时在全国政府网站信息报送系统中完善更新并逐级报审。

涉改单位应严格按照《国务院办公厅关于加强政府网站域名管理的通知》（国办函〔2018〕55号）要求，及时做好网站域名申请、变更、注销等工作。市政府办公室将对我市行政机关及其内设机构、承担行政职能的事业单位持有的域名进行全面梳理，清理注销不合规的域名、网站已关停但仍未注销的域名，以及被用于非政府网站的域名。其中，域名为“.cn”、“.政务”的，集中反馈至国家域名注册管理机构进行注销，域名为其他顶级域名的，由域名持有者联系相应的注册机构进行注销。

（四）认真做好政府网站2018年度报表编制发布工作。各政府网站主办单位要在全国政府网站信息报送系统中认真填写《政府网站工作年度报表》，于2019年1月31日前在本网站首页突出位置和政府信息公开目录中发布。市政府办公室将开设“政府网站年度工作报表”专栏，汇总发布本地区各类政府网站《政府网站工作年度报表》，发布《政府网站监管年度报表》。

对此次存在突出问题的网站，各区县、各部门要高度重视，立即采取有力措施落实整改，于1月16日前将整改情况书面报送市政府办公室。
