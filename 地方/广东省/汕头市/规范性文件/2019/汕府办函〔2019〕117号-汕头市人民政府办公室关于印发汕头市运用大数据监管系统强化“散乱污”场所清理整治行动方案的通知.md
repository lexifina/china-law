# 汕头市人民政府办公室关于印发汕头市运用大数据监管系统强化“散乱污”场所清理整治行动方案的通知

汕府办函〔2019〕117号

各区县人民政府，市政府有关部门、有关直属机构：

《汕头市运用大数据监管系统强化“散乱污”场所清理整治行动方案》已经市政府同意，现印发给你们，请认真组织实施。实施过程中遇到的问题，请径向市工业和信息化局（市“散乱污”场所清理整治工作领导小组办公室）反映。

汕头市人民政府办公室

2019年6月16日

汕头市运用大数据监管系统强化“散乱污”场所清理整治行动方案

根据《广东省人民政府关于印发广东省“散乱污”工业企业（场所）综合整治工作方案的通知》（粤府函〔2018〕289号）、《关于印发汕头市“散乱污”工业企业（场所）专项整治工作方案的通知》（汕府〔2018〕87号）、《汕头市人民政府办公室关于印发汕头市“散乱污”工业企业（场所）专项整治工作指导意见的通知》（汕府办〔2019〕13号）精神和有关要求，在现有“散乱污”工业企业（场所）专项整治工作的基础上，进一步运用大数据监管系统强化全市“散乱污”场所清理整治工作，制定本方案。

本方案所指的“散乱污”场所：“散”是指不符合当地产业布局等相关规划的企业（场所），没有按要求进驻工业园区（产业集聚区）的规模以下企业（场所）；“乱”是指不符合国家或省产业政策的企业，应办而未办理规划、土地、环保、市场监管、安全、能耗等相关审批或登记手续的企业，违法存在于居民集中区的企业、摊点、小作坊；“污”是指依法应安装污染治理设施而未安装或污染治理设施不完备的企业（场所），不能实现稳定达标排放的企业（场所）。

一、工作思路与目标

（一）工作思路

以“全面推进、分类处置、分步实施、智慧监管”的工作思路，对“散乱污”场所不搞“一刀切”，采取措施“关停取缔一批、整合搬迁一批、升级改造一批”，为我市打赢污染防治攻坚战奠定坚实基础。

（二）工作目标

1.2019年6月15日前，完成汕头市“散乱污”大数据监管系统的建设，建立“散乱污”场所数据基础库。6月30日前，完成现有全市“散乱污”工业企业（场所）综合整治清单的整治任务；运用大数据监管系统排查，加强动态监测清单管理，7月15日前全面完成对列入“散乱污”大数据系统的场所进行逐一排查，建立动态监测清单。

2.2019年8月31日前，完成动态监测清单的整治任务。

3.2019年9月30日前，各区县完成清理整治总结工作，持续巩固整治成果，组织对“散乱污”场所清理整治情况进行复查。

4.2019年12月31日前，完成省对我市“散乱污”场所清理整治工作的检查复查。

二、主要任务

（一）建设“散乱污”场所信息报送和大数据监管系统

运用用电数据信息，建设完成“散乱污”场所大数据监管系统，用大数据手段对各区县、街镇用电等情况进行统计、分析和监测，对异常情况进行预警；将用电异常情况及时发送各区县、街镇进行核查处理。在相关条件具备后，可将用水数据信息与用电数据信息进行整合，纳入监管系统（牵头单位：市工信局、水务局、汕头供电局；配合单位：各区县政府）

（二）组织排查生产经营场所用电用水和废水废气排放情况

各街镇组织对生产及经营场所实行拉网式排查，重点对运用大数据梳理的名单进行排查，并实行清单制、台账制、网格化管理，摸清各生产及经营场所用电量、废水废气排放方式等情况。同时，探索将重点生产及经营场所用水量纳入摸查内容。（牵头单位：各区县政府；配合单位：市工信局、水务局、生态环境局、汕头供电局）

（三）分类处置各类生产经营场所

结合我市实际，建立完善关停取缔、整合搬迁、升级改造三类生产经营场所认定和划分指导性意见（牵头单位：市生态环境局；配合单位：市发改局、自然资源局、工信局、水务局、城管局）。对于排查中发现“散乱污”场所按照我市的有关要求，结合现场排查情况审定分类整治类别，落实采取的整治措施（牵头单位：各区县政府；配合单位：市生态环境局、工信局、水务局、公安局、自然资源局、住建局、城管局、市场监管局、农业农村局、税务局、消防救援支队、汕头供电局）

（四）统筹推进“散乱污”排查整治

各区县、街镇按照《汕头市人民政府办公室关于印发汕头市“散乱污”工业企业（场所）专项整治工作指导意见的通知》（汕府办〔2019〕13号）的要求，强化组织领导、强化整治措施、强化压实责任，统筹兼顾做好现有全市“散乱污”工业企业（场所）综合整治清单的整治、动态监测清单的整治。（牵头单位：各区县政府；配合单位：市工信局、生态环境局、城管局、汕头供电局）

三、实施步骤

（一）建立工作联络和信息报送机制

各相关单位于6月18日前将推进“散乱污”场所清理整治专项工作的单位负责人、部门负责人和工作联络员及联络方式等报市工信局，且各牵头单位在本方案印发后每周五将相关工作进展情况报送市工信局。

（二）按时间节点做好排查整治工作

各区县组织街镇于6月30日前完成现有全市“散乱污”工业企业（场所）综合整治清单的整治任务；7月15日前全面完成对列入“散乱污”大数据系统的场所进行逐一排查，建立动态监测清单；8月31日前完成动态监测清单的整治任务。

（三）开展总结复查工作

各区县应于9月30日前对行政辖区内“散乱污”场所清理整治情况形成总结报告，并及时报送市“散乱污”场所清理整治工作领导小组办公室并抄送市生态环境局、发改局。同时，各区县要持续巩固整治成果，组织对“散乱污”场所清理整治情况进行复查。

四、保障措施

（一）加强组织领导

市“散乱污”工业企业（场所）专项整治工作领导小组更名为市“散乱污”场所清理整治工作领导小组（以下简称“领导小组”），并继续负责统筹“散乱污”场所清理整治工作。同时，将领导小组办公室调整至市工信局，由市工信局局长任办公室主任，市工信局、生态环境局、发改局、水务局和汕头供电局分管领导任办公室副主任，负责领导小组日常工作。同时，领导小组增加市住建局作为成员单位。

各区县要结合实际，建立完善“散乱污”场所清理整治工作领导小组，统筹推进“散乱污”场所清理排查整治相关工作。

（二）落实职责分工

领导小组成员单位要根据各自工作职能和《广东省人民政府关于印发广东省“散乱污”工业企业（场所）综合整治工作方案的通知》（粤府函〔2018〕289号）、《关于印发汕头市“散乱污”工业企业（场所）专项整治工作方案的通知》（汕府〔2018〕87号）、《汕头市人民政府办公室关于印发汕头市“散乱污”工业企业（场所）专项整治工作指导意见的通知》（汕府办〔2019〕13号）有关要求及机构改革后的责任分工，按任务要求完成各项工作。

（三）强化实地排查

各区县要落实主体责任，按照大数据分析分配清单落实属地街镇逐一进行现场排查，结合排查情况审定“散乱污”场所分类整治类别，确定采取的整治措施。对分配清单应做到每一家都有回应，包括排查情况、是否列入新增名单、整治类别和整治措施等。

（四）强化物资保障

“散乱污”场所清理整治工作时间紧、任务重、工作繁琐，领导小组各成员单位、各区县要高度重视，落实专人负责，配备必要人员、物资、资金，确保工作顺利推进。各区县、街镇要落实专职领导负责、统筹协调部门、专人负责排查和汇总，加强车辆保障、执法人员保障和物资保障。市财政局统筹安排各级工作经费，支持“散乱污”场所清理整治工作，资金专项用于大数据监管系统对建设、运行维护及大数据分析等费用。各区县、街镇应对“散乱污”清理整治工作产生的必要费用予以保障。

（五）强化督办问责

市政府批准成立的三个专项督查工作组仍按原来分工安排（市生态环境局负责牵头督查潮阳区、金平区，市发改局负责牵头督查龙湖区、澄海区，市工信局牵头负责督查潮南区、濠江区)，每月对每个区县的指导不少于2次，每次检查场所不少于3家。对南澳县督查检查由市工信局牵头的专项督查工作组负责。在检查督查过程发现工作落实不力、进度慢的区县，市政府将予以通报批评，由区县政府向市政府作书面检讨，市政府将视情况约谈区县政府主要负责同志，依法依规追究相关单位和人员的责任。

（六）强化宣传维稳

通过多种形式加强对“散乱污”清理整治有关政策宣传，让社会各界全面了解“散乱污”清理整治的重要意义。加强宣传推广先进区县、街镇的先进经验，增强示范效果。加强舆论监督，曝光阻碍“散乱污”场所清理整治、生产经营场所违法排污、违法用电等行为，形成有利于“散乱污”清理整治的良好舆论氛围。扎实做好维稳工作，各区县要制定维护社会稳定和安全的预案，积极防范和处置突发事件的发生，努力营造污染小、生态好、效益高的产业环境，增强人民群众的获得感、幸福感。
