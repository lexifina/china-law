# 汕头市人民政府办公室关于印发《汕头市2019年水污染防治攻坚战工作方案》的通知

汕府办函〔2019〕187号

各区县人民政府，市直有关部门，有关直属机构：

《汕头市2019年水污染防治攻坚战工作方案》已经第十四届54次市政府常务会议审议通过，现印发给你们，请认真组织实施。实施过程中碰到问题，请及时向市生态环境局反映。

汕头市人民政府办公室

2019年10月15日

汕头市2019年水污染防治攻坚战工作方案

为深入贯彻落实习近平生态文明思想，全面落实省、市污染防治攻坚战指挥部1号令，全力攻坚国考（省考）断面水质达标，根据《广东省水污染防治行动计划实施方案》《广东省生态环境厅2019年水污染防治攻坚战工作方案》《汕头市打好污染防治攻坚战三年行动计划（2018—2020年）》《汕头市水污染防治行动计划实施方案》要求，制定本工作方案。

一、工作目标

2019年，全市地表水水质优良（达到或优于Ⅲ类）比例达到75%，劣Ⅴ类比例控制在25%以内；梅溪河升平断面水质提升至III类，练江海门湾桥闸断面基本达到V类。县级及以上集中式饮用水水源地水质全部达到或优于III类，保持100%达标，城市建成区黑臭水体消除比例达90%以上；完成国家和省规定的近岸海域水质保护目标；各区（县）水质控制目标详见附件1。

二、工作思路

坚持系统治水。以改善水环境质量为核心，聚焦劣Ⅴ类水体、优良水体、黑臭水体综合治理，突出控制单元防治，统筹推进全流域上下游、左右岸、干支流污染防治，全力攻坚国考、省考断面水质达标。

坚持科学治水。以源头管控和末端处理为核心，既因地制宜、标本兼治、科学施策推进生活、工业、农业农村污染源治理和入河排污口整治，又尊重规律、量力而行、递次推进污水处理设施和管网建设，持续改善水环境质量。

坚持挂图作战。充分发挥河长制湖长制作用，深化水污染形势上图和治理工程列表（“一图一表”），实时动态调度重点断面和重要支流水质状况，及时督导推动重点工程项目建设。

三、主要任务

（一）全面攻坚劣V类断面。全面落实省污染防治攻坚战指挥部2018年1号令及市污染防治攻坚战指挥部2019年第1号令《关于开展全面攻坚国考断面水质达标行动的命令》的要求，全力攻坚练江海门湾桥闸劣V类国考断面，制定实施断面2019年工作方案，实施挂图作战，细化工作措施、任务分工，按照国家及省要求的达标时限倒排工期，统筹推进流域上下游、左右岸、干支流综合治理，抓好源头控制。坚持治标与治本同向发力，统筹推进五大专项行动“治标”，全力攻坚垃圾焚烧厂、印染园区、污水处理厂及配套管网建设三大山头“治本”，着力减少各类污染源排放，实现练江环境综合整治取得阶段性成效，2019年底，练江海门湾桥闸断面水质达到V类。（市生态环境局牵头，市城管局、水务局、农业农村局等参与，各区（县）政府负责落实。以下各项任务均需各区（县）政府落实，不再一一列出）

（二）强化优良水体保护。按《汕头市打好污染防治攻坚战三年行动计划（2018—2020年）》、《韩江榕江练江水环境系统共治工作方案》的要求，重点加强韩江流域水质保护。对已达优良的外砂断面、莲阳桥闸断面加强污染防治，严防水质恶化；重点攻坚梅溪河升平断面水质达标，按照《升平断面水质达标2019年度攻坚方案》要求，抓好断面流域环保基础设施建设、管网配套完善、黑臭水体及河涌整治、工业、农业、生活污染源防控等重点工作，加快流域内22个分散式污水一体化应急处理设施建设。2019年底，大幅度减少升平断面流域污水直排问题，减轻断面污染负荷，确保断面今年平均水质为III类并稳定达标。（市生态环境局牵头，市城管局、水务局、农业农村局等参与）

（三）保障饮用水源安全。依法依规科学优化调整我市饮用水水源保护区，按要求完成县级及以上地表水集中式饮用水水源保护区“划、立、治”工作，依时序依法清理整治饮用水水源一、二级保护区内排污口、违法建设项目、违法网箱养殖等问题。对已完成整治的县级及地级饮用水水源地环境问题开展自查及定期巡查，确保已整改环境问题周边环境改善，杜绝环境问题死灰复燃及新环境问题出现，确保整治工作到位。（市生态环境局牵头，市水务局、城管局等参与）

（四）全力消除黑臭水体。坚持“系统治理，有序推进；多元共治，形成合力；标本兼治，重在治本；群众满意，成效可靠”的基本原则，采取截污控源、河道清淤、引韩江水充灌、生态修复、景观提升等措施，从生活源、工业源、农业源等方面着手，补齐污水收集处理设施短板，大力提升污水收集处理效能，建立河涌管养长效机制。到2019年底，我市建成区黑臭水体消除比例达到90%。（市城管局牵头，市生态环境局、水务局、农业农村局等参与）

（五）着力提升生活污染治理效率。一是强化城镇污水截污纳管建设，着力推进雨污分流管网建设，加强城中村、城郊结合部、老旧小区、工业园区等盲点和薄弱地区配套污水管网及污染支流沿河截污管网建设，推动解决管网未到、污水直排等问题，加强老旧管网、“断头管网”排查与修复连通。2019年，全市新增城市（县级）污水处理管网142.2公里，新增镇级污水处理管网775.7公里，改造中心城区老旧污水管网11公里；二是按照集中式和分散式相结合的原则，加快污水处理能力不足的重点区域流域、人口快速增加的城镇以及建制镇污水处理设施建设，采用分散式污水处理设施弥补部分区域污水集中处理能力不足的短板。2019年，全市新建城市（县城）污水处理设施2座，乡镇污水处理设施全部开工建设。三是年底前完成敏感区域污水处理厂提标改造任务，强化韩江、练江重点区域流域生活污水处理设施建设。进一步明确我市城市生活污水集中收集率、污水处理厂进水生化需氧量浓度等工作目标，提升污水处理设施氨氮进水浓度，2019年镇级以上污水处理设施氨氮平均进水浓度达到19.29mg/L。组织开展城镇污水处理设施运行情况检查，以污水处理量和进水污染物浓度提升检验管网建设成效。（市城管局牵头，市生态环境局、市住建局参与）

（六）着力提高工业污染治理和监管水平。强化工业企业达标治理，水质未达标的控制单元禁止接受其它区域相关主要水污染物可替代总量指标。严格实施国家排污许可制管理和工业污染源全面达标排放计划，严厉打击无证和不按证排污行为。全面清理整治“散乱污”工业企业，重点清理整治练江、升平断面等流域“散乱污”工业企业。集中整治工业集聚区水污染问题，每季度调度水环境管理信息，按要求加强工业集聚区监管，大力推进实施镇村级企业集聚区升级改造。（市生态环境局牵头，市工业和信息化局等参与）

加快推动涉水重污染行业开展清洁生产和落后产能退出，支持企业自愿实施清洁生产技术改造。潮南区纺织印染环保综合处理中心应于2019年底前建成并完成企业入园。潮阳区纺织印染环保综合处理中心应于2020年6月底前建成并完成企业入园。（市工业和信息化局、市生态环境局牵头）

（七）强化农业农村污染治理。科学规范畜禽养殖，大力推进畜牧业转型升级，加快推进规模畜禽养殖场（小区）配套污水处理设施、综合利用和无害化处理设施建设。科学规划水产养殖。推广标准化养殖，严格控制水库、湖泊网箱养殖规模，开展养殖尾水和废弃物治理。全面整治农村生活污水，按照乡村振兴战略及《汕头市农村生活污水治理攻坚三年行动计划暨“源头截污、雨污分流”专项行动方案（2019—2021）》要求，加快推进农村生活污水治理和“源头截污、雨污分流”系统建设；优先治理国考断面水质达标控制单元、饮用水水源保护区及省定贫困村等重点区域范围。2019年年底前，全市自然村生活污水治理覆盖率达60%以上，省定贫困村达100%，练江流域自然村达100%；全市60%以上的自然村实现雨污分流（其中练江流域自然村达到70%以上），45%以上的自然村基本达到“进村入户、源头截污”的标准（其中练江流域自然村达到50%以上，省定贫困村达100%）；污水排放管道收集或暗渠化，已建成的自然村生活污水收集率达90%以上；农村水环境质量逐步好转。（市生态环境局、市农业农村局牵头）

（八）落实水污染防治其它重点工作。加快实施加油站地下油罐更新改造，年底前全部更新为双层罐或完成防渗池设置。加强城镇节水，全力推进节水型城市建设，争取到2020年底符合《国家节水型城市考核标准》的目标。加强近岸海域污染防治，加快实施《广东省近岸海域污染防治实施方案（2018—2020年）》，继续深入开展入海河流综合整治。加强船舶污染和港口码头污染防治。实施入河排污口排查整治，按照“查、测、溯、治”原则，全面查清入河排污口，加强入河排污口水质监测，厘清排污责任并分门别类明确管控要求。（市生态环境局、市水务局、交通运输局、汕头海事局等按职责分工牵头，市工信局、农业农村局、住建局等参与）

四、保障措施

（一）加强组织领导。各区（县）政府是水污染防治攻坚战的责任主体，也是实施本方案的责任主体，要切实加强领导、落实责任、完善措施，在市方案基础上结合实际抓紧制定并实施本区域年度方案，明确项目表、时间表、责任表，将责任细化落实到具体单位和个人，确保各项任务落实到位；强化上下联动和部门协作，定期会商分析研判、预警通报，协同推进水污染防治、水资源保护、黑臭水体整治、污水处理设施建设；进一步充分发挥河长制湖长制作用，细化“河长”水质监测断面，将监测断面的水质目标任务落实到各级“河长”，使各级河长做到治水有责、治水负责、治水尽责。充分发挥市水污染防治联席会议的统筹协调作用，全面推进全流域系统治污。市有关单位要各司其职、通力合作，在各自的职能范围内加强业务指导和支持。

（二）强化挂图作战。各区（县）要在市的基础上加快完善本行政区域内国考断面达标攻坚的“一图一表”，通过“一图一表”，进一步明确时间表、完善责任链，实现工作项目化、项目目标化、目标责任化，进一步推动整治工作提速增效。建立重点工作管理台账，准确、完整记录进展情况，以信息化为抓手，实施“挂图作战”。

（三）强化信息调度。对练江海门湾桥闸断面、梅溪河升平断面实行信息一月一调度，市有关单位及各区（县）应于每月30日前报送本月水污染防治工作开展及两个国考断面重点工作进展信息，市生态环境局结合省最新工作要求及调度情况，动态更新重点攻坚任务清单。在每月30日前按要求在国家水污染防治重点工作实施进展调度系统上填报工作进展情况，12月30日前将全年工作总结及下年度工作计划函送市生态环境局。

（四）强化工作保障。各区（县）政府要强化信息公开，将水污染防治年度方案和进展情况主动向社会公开，接受人民群众监督。切实加强资金、政策保障和科技支撑，优化项目审批流程，确保各类工程项目顺利建设；加强政策聚焦，在重点任务和资金安排上加大倾斜支持力度。

本方案自发布之日起实施，有效期至2019年12月31日。
