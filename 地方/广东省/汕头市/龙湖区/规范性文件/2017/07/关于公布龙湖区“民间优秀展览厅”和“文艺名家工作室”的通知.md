# 关于公布龙湖区“民间优秀展览厅”和“文艺名家工作室”的通知

各街道办事处，各镇人民政府，区政府直属各部门，省、市驻区有关单位：

为健全完善社会力量参与公共文化建设的激励机制，支持民办公益性机构的发展，鼓励民间展览厅对公众免费开放并参与到公共文化服务中来，促进龙湖区公共文化服务方式多元化、社会化。同时，充分发挥区内文化名人名家聚集的优势，推动文艺名家工作室建设。龙湖区政府通过树立典型，进一步加强民间优秀展览厅和文艺名家工作室的专业化、标准化、规范化建设，全面提高民间优秀展览厅和文艺名家工作室的建设管理水平和服务质量，促进优秀文化艺术作品展示研究和地域优秀文化研究传承，充分发挥文艺名家工作室的示范作用和民间优秀展览厅的公共文化服务作用，以点带面，全面提升民间展览厅和文艺工作室的文化影响和社会贡献率，繁荣文化艺术事业，进一步满足人民群众的精神文化生活需求。

经研究，同意广东省岭东美术馆等7个单位为龙湖区“民间优秀展览厅”，汕头市王芝文陶瓷微书工作室等9个单位为龙湖区“文艺名家工作室”。现予公布。
