# 龙湖区2016年主要污染物总量减排自查报告及2017年减排计划

汕头市人民政府：

2016年以来，区委、区政府高度重视环境保护和污染物总量减排工作，始终坚持以科学发展观为指导，以改善环境质量为根本目的，按照主要污染物总量减排要求，根据“多还老帐、不欠新帐”的原则，全面开展工业污染防治，强化环境监管执法，积极推进产业结构调整，大力发展循环经济，完善了减排考核和责任追究制度，形成了政府统筹、环保部门牵头、各职能部门分工负责、全区上下齐抓共管的工作机制，大力实施工程减排、结构减排、监管减排和环保疏浚减排，总量减排工作取得了显著成绩。

一、龙湖区2016年主要污染物总量减排项目完成情况

2016年，根据国家、省、市减排要求和《汕头市龙湖区“十二五”主要污染物总量减排工作方案》，我区认真研究，进行有关测算和完成减排任务的可行性分析，制订了2016年龙湖区年度总量减排计划，确定2016年我区上报的减排项目共9个，汕头市龙湖区外砂锦丰洗熨厂淘汰落后产能、关闭拆除作为水、大气结构减排项目；汕头市艺宇印刷包装有限公司关闭拆除造纸项目作为水结构减排项目；周厝塭完成了农村生活污水处理工程建设，作为水工程减排项目；汕头市万成鑫水产有限公司实施废水处理设施改造，加大了污水处理能力，落实了COD及氨氮工程减排措施，作为水工业监管减排项目；汕头市龙湖区外砂隆盛漂染厂、汕头经济特区永联制衣洗染厂有限公司、汕头市雅园生物工程有限公司按淘汰落后产能要求对锅炉进行报废拆除，作为大气结构减排项目；龙湖区“百河千沟万渠大整治”工程完成16条龙湖区沟渠整治任务作为环保疏浚项目。截止至2016年底，全部减排项目已按要求完成了减排任务，具体完成情况见附件1。另广东金航食品有限公司、汕头市荣达织造厂有限公司结转往年大气污染物削减量。龙湖区2016年度COD共削减84.75吨，氨氮共削减18.68吨。二氧化硫共削减76.71吨，氮氧化物共削减10.76吨。

二、龙湖区2016年总量减排工作情况

2016年是“十三五”开局之年，我区清醒地认识到，减排任务只会增重决不会减轻，我区总量减排工作形势依然非常严峻，任务依然非常艰巨。我们继续加强对减排的重要性和紧迫性的认识，进一步增强忧患意识、危机意识和责任意识，以科学发展观为指导，坚持减排思想不动摇，工作不松懈，力度不减弱，步伐不放缓，以超常规的工作力度、非常的措施和实实在在的成效，确保完成各项减排任务。

（一）加强领导，落实污染减排目标责任。按照市政府的部署，我区严格落实污染减排责任制，切实加强对污染减排工作的组织领导，主要领导认真履行第一责任人的职责，做到亲自抓、负总责。分管领导全面抓落实，把好污染减排的每一个环节，切实把减排工作摆在重要位置。一是我区结合实际情况，认真研究并制定《2016年龙湖区年度总量减排计划》，确定2016年度计划减排项目，明确了各项目减排措施。二是下达《龙湖区2016年主要污染物总量减排工作任务》，对减排目标进行分解和责任落实，将减排目标层层分解到各责任部门和责任领导，促进污染减排工作的落实。三是区环保分局做为全区污染减排工作牵头单位，积极建立主要污染物总量减排工作联动机制，加强对各街道镇污染减排工作的督查和指导，加强与区农业、经信、住建等部门沟通联系，合力推进污染减排。

（二）强化“三大减排措施”，促进主要污染物总量减排。2016年，我区按照国家和省、市的统一部署，在区委区政府的高度重视下，全力加快环境基础设施建设，强化“三大减排措施”，促进主要污染物总量减排，为确保顺利完成2016年度COD、SO2、氨氮和氮氧化物减排任务夯定坚实基础。

1、突出重点，推进工程减排。工程减排是污染物减排的重要抓手，区政府高度重视这项工作的落实，加大对企业治污财政资金的扶持力度，推进了企业工程减排项目的落实。

2、大力开展产业结构升级，推进结构减排。严格执行国家产业政策，把好建设项目环保准入关，坚持把总量削减指标作为建设项目环评审批的前置条件，坚决淘汰落后生产能力，抑制高耗能行业的盲目发展。2016年所有工业结构减排项目已按按淘汰落后产能要求进行拆除关闭。

3、加大执法力度，推进监管减排。一是对重污染行业建设项目，严格环保准入条件，控制新增污染源。二是推行排污许可证和污染物总量控制，做到增产不增污，对污染物超标的企业实施限期整改。三是以整治违法排污企业、保障群众健康环保专项行动为抓手，加大对重点区域和重污染行业的执法力度。四是继续把重点企业开展清洁生产作为污染物总量减排的重要手段，推进清洁生产审核。

（三）完善统计、监测、考核“三大体系”建设，夯实减排基础。按照国家要求，强化污染减排三大体系建设。一是加强减排统计和信息传输基础能力建设。强化部门协调，健全和完善减排统计工作体系，落实重点减排企业主要污染物排放数据网上直报系统和减排措施调度制度。二是积极推进重点污染源在线监控系统建设。加强在线监控设备运行维护，强化对自动监控系统数据有效性的审核及使用，提高污染源日常监督性监测能力。区环保分局每月至少对减排项目进行一次现场监察和监督性监测。三是进一步强化减排考核。将减排指标完成情况纳入我区经济社会发展综合评价体系，作为各级政府领导班子和领导干部综合考核评价以及企业负责人业绩考核的重要内容，实行问责制和“一票否决制”。

（四）积极落实生活污水处理设施建设。周厝塭原来没有配套排水管网系统和污水处理系统，未能纳入城市污水处理厂统一处理，污水经化粪池处理后直接排入黄厝围沟，环境污染较为严重，对纳污水体环境质量存在一定影响。2016年周厝塭居民委员会投资建设生活污水处理工程，日处理规模共276吨/天。该处理设施于2016年2月竣工，同时进行调试和试运行,2016年6月通过了区政府组织的联合验收。

（五）加强现场检查督导。我区把重点减排项目作为一项长期的任务纳入环保日常监管，采取措施，不断深化，狠抓落实。各部门严格按照职责分工，切实履行职责，对检查中发现的问题要求逐一进行整改。在整治督导过程中，区环保分局认真开展整治工作，布置整治任务，联合区农业局、住建局及属地街道（镇）多次开展检查工作，到检查指导重点企业减排工作，督促企业落实各项整治措施。

（六）深入实施“以奖促治”，有效推进减排工作的进度。区政府进一步加大对2016年污染减排项目的资金补助力度，区财政局拨付了220万元作为2016年度龙湖区节能减排专项资金，大力推进污染治理设施建设，有效推进减排工作的进度。

三、龙湖区2017年主要污染物总量减排工作计划

总量减排工作形势严峻，任务艰巨。我们将继续加强对减排的重要性和紧迫性的认识，进一步增强忧患意识、危机意识和责任意识，以科学发展观为指导，坚持减排思想不动摇，工作不松懈，力度不减弱，步伐不放缓，以超常规的工作力度、非常的措施和实实在在的成效，确保完成各项减排任务。

（一）制定“十三五”方案，科学指导“十三五”污染减排工作。“十三五”前半期，按照省、市的部署，印发《汕头市龙湖区“十三五”主要污染物总量减排方案》，科学指导“十三五”污染减排工作的顺利开展。认真研究并制订2017年龙湖区年度总量减排计划，确定2017年度计划减排项目（见附件4）。制定《龙湖区2017年主要污染物总量减排工作任务》，将减排指标分解落实到各有关单位，促进各部门积极参与，密切配合，建立和完善了污染物总量减排工作机制。

（二）加大打击环境违法行为力度，切实强化污染源的监管。继续开展各部门联合行动，严厉查处违法排污行为，确保污染物稳定达标排放；将在工业监管减排和结构减排方面下功夫，积极推进燃煤锅炉淘汰改造工作，继续抓好造纸、印染、水产、电镀、酿造和化工等行业的监管减排。

（三）加快污水集中处理设施建设，推进生活源减排工作。结合市委市政府“千村环境卫生整治”民心工程，按要求开展城乡生活污水与畜禽养殖污染整治工作。一是继续推进农村污水集中处理设施建设。二是对已建成的农村污水处理设施加强运行监管，确保治理设施发挥污染减排作用。三是协助相关部门做好新溪污水处理厂的建设工作。

（四）加大督查力度提高减排项目的认可率。加强现场监察和监督性监测管理，及时上报减排台帐，同时，要充分挖掘全区工业COD的减排量，及时掌握减排项目动态，把减排项目的督查纳入日常监管工作程序，提高减排项目的认可率。

（五）加强宣传发动，确保污染减排全民参与到位。充分运用各种媒体，开展污染减排主题宣传，不断增进企业和公众对污染减排工作的认识、理解、支持和参与。积极倡导绿色生活方式和消费方式，为污染减排工作营造良好的社会氛围。
