# 关于印发2017年龙湖区春季爱国卫生运动工作方案的通知

各街道办事处、镇人民政府，区政府各直属部门，省、市驻区各有关单位：

《2017年龙湖区春季爱国卫生运动工作方案》已经区政府同意，现印发给你们，请认真组织实施。实施过程中遇到的问题，迳向区卫计局反映。

汕头市龙湖区人民政府办公室

2017年2月28日

2017年龙湖区春季爱国卫生运动工作方案

为深入贯彻落实省政府《关于全面深化爱国卫生运动的实施意见》，广泛铺开我区新一轮城乡环境卫生整洁行动，巩固发展国家卫生城市创建成果，进一步推动我区创建全国文明城市工作的深入开展，持续改善我区卫生环境，有效预防控制传染病发生流行，保障市民群众健康，根据《通知》的要求和部署，区爱卫会定于2月27日至3月5日，在全区组织开展全区春季爱国卫生清洁整治专项活动。为确保此次活动顺利进行，特制定本方案。

一、活动主题

“清洁卫生齐动手，预防疾病保健康”

二、活动时间

2017年2月27日-3月5日

三、活动内容

（一）开展爱国卫生宣传和除害防病教育。

各街道、镇、各部门要及早开展春季爱国卫生活动宣传策划，利用网站、微信、微博、宣传海报等宣传手段提前造势，现场举办生动活泼的大型宣传活动、知识讲座等，广泛普及防控人感染禽流感、登革热等除害防病知识，宣传“清洁卫生齐动手，预防疾病保健康”；要通过电视、报纸等主流媒体报道春季爱国卫生清洁整治专项活动，引导机关团体、企事业单位和广大人民群众主动参与爱国卫生运动，营造起热烈的爱国卫生运动氛围，进一步推动我区创建全国文明城市工作的深入开展。

（二）加强农贸市场卫生管理。

当前H7N9流感防控形势严峻，两镇要切实加强禽流感防控工作，落实活禽零售市场“1110”制度，即：“一日一清洗消毒、一周一大扫除、一月一休市以及零存栏”。有关部门要加强农贸市场卫生保洁和消毒，对活禽档口进行彻底清洗消毒。要组织人力，使用高压水枪对活禽档口进行彻底冲洗，做到地面、笼具、用品无羽毛、粪便及其他污物。对活禽档口的场地、笼具、用品要用消毒剂全面喷洒或浸泡消毒。

（三）开展环境卫生整治。

结合创文强管工作，大力开展环境卫生整治。各街道、镇至少组织一次以环境卫生整治、清除卫生死角、病媒孳生地和活禽市场大扫除为主要内容的统一行动，彻底清除背街小巷、城中村、城乡结合部、河道两旁、村庄周边、铁路和公路沿线、农贸市场的卫生死角，重点治理学校、车站、建筑工地等人员聚集场所环境卫生。各街道、镇对本辖区垃圾实施“两清一控”，即清除存量垃圾和水体垃圾，加强垃圾收集转运管理，控制增量垃圾。

（四）开展以灭鼠、灭蚊为主的除“四害”专项整治。

春季是除“四害”工作的重要时间节点，全区各级要组织开展集中统一的除四害专项整治，切断疾病传播途径。各街道、镇要组织发动群众清积水灭蚊虫，对房前屋后、天台楼顶积水容器翻盆倒罐，疏通沟渠、沙井，填平坑洼，清理绿化带、建筑工地积水，排除废旧轮胎、空瓶空罐、盆景、家庭水培植物等易滋生蚊虫部位的隐患。已购买除“四害”工作市场化服务的地区，要在春季爱国卫生运动期间组织专业防制队伍，集中开展以灭鼠、灭蚊为主的除“四害”活动，加强蚊媒密度水平高风险点病媒防制。春季爱国卫生运动结束后，区疾控中心要加强整治效果评估，重点做好蚊媒密度监测评估工作。

（五）组织开展一次全区性爱国卫生运动统一行动。

1.统一行动主场地：金霞街道龙湖村文体广场（祠堂前球场）。

2.统一行动分场地：珠池、新津、龙祥、鸥汀街道，外砂、新溪镇，由各街道、镇参照本工作方案同时组织开展行动。

3.统一行动具体时间：2月27日上午。

4.统一行动活动内容：

（1）清理生活垃圾、建筑垃圾，清理污泥，疏通沟渠；

（2）清理卫生死角，清洗路面及果皮箱等环卫设施；

（3）清除蚊虫孳生地，清理各类废弃物，对所有可能积水的空置容器、废旧轮胎等进行彻底清理；

（4）清理乱贴乱画，背街小巷牛皮癣；清除死角杂物，堵塞鼠洞，消除鼠类生存环境，投放毒鼠谷、喷洒除害药物；

（5）开展健康教育宣传，现场发放健康教育宣传资料及除“四害”药品。

5.主场地统一行动工作安排：

（1）主办单位：市爱卫会，龙湖区政府；承办单位：市爱卫办，龙湖区卫计局。

（2）主场地参加人员：市领导；市爱卫会成员单位领导；区政府有关领导；区爱卫会成员单位领导；志愿者组织（自带工具）；除“四害”专业服务队伍。

（3）主场地任务分工：区政府办公室负责联系落实区领导参加活动等事宜；区卫计局负责主场地组织协调、布置及联系除“四害”专业队伍；金霞街道负责落实劳动工具、转运垃圾的专业人员和车辆，组织动员群众参与活动；区总工会、区妇联、团区委联系协调青年志愿者、职工义工、巾帼志愿者参与活动。

四、工作要求

各街道、镇、各部门要高度重视，切实负起责任，积极组织发动，提供经费保障。各级领导要亲自组织，亲自参与，确保活动不走过场。爱卫会成员各单位要按照爱卫会职责分工，积极开展环境卫生整治活动，发挥部门优势，加强监督管理，提高重点单位、重点部位的环境卫生水平，确保不留死角。

各街道、镇、各部门要做好专项活动筹备和过程记录，及时将活动进展情况和工作简讯报送区爱卫办。2017年3月7日前各街道、镇、各部门报送活动情况记录表、总结和图片、视频等宣传资料；3月14日前区疾控中心报送蚊媒密度监测结果。
