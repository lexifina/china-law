# 关于印发2017年龙湖区高新技术企业培育工作方案的通知

各街道办事处、镇人民政府，区政府各直属部门，省、市驻区各有关单位：

《2017年龙湖区高新技术企业培育工作方案》已经区政府同意，现印发给你们，请认真组织实施。实施过程中遇到的问题，迳向区经信局反映。

汕头市龙湖区人民政府办公室

2017年2月27日

2017年龙湖区高新技术企业培育工作方案

为深入实施创新驱动发展战略，培育一批有规模、有前景的创新型高新技术企业队伍，发展有利于我区产业结构调整优化和经济发展赶超的创新主体力量，完成市下达我区的高企培育目标任务，结合我区实际，特制定本方案。

一、指导思想

把高新技术企业的培育建设作为实施创新驱动发展战略的重要抓手，紧扣发展方向，培育有利于我区产业结构调整优化和经济发展赶超的关键领域创新主体和力量，形成发展新优势。坚持问题导向，从区情出发确定跟进和突破策略，强化高企培育工作，扩大培育范围，大力发动基层企业，培育一批有规模、有前景的创新型高企队伍。围绕高新技术企业申报和培育扶持的相关要求，进一步完善财政支持政策，引导创新资源和创新服务向高新企业集聚，不断壮大高新技术企业群。

二、总体目标

2017年新增高新技术企业50家以上，高新技术企业总数达到123家以上；进入省高新技术企业培育库企业30家。

三、工作安排

（一）摸底调查阶段（2月份）

面向全区范围对科技创新企业进行“地毯式”摸底调查，做好基础数据收集、分析和筛选等工作，全面建立高新技术企业培育对象库。区经信局牵头组织开展摸查工作，区工商局协助提供企业注册信息，知识产权部门提供企业拥有知识产权情况，税务部门提供纳税销售收入增长较快企业信息。各街道、镇要发动所属村居开展全面摸查，掌握辖区高企培育对象的情况。

（二）宣传培训阶段（3月份至4月份）

1．结合我区“企业服务年”活动，多形式多渠道向企业开展高新技术企业政策宣传，提高企业对高新技术企业的认识和申报积极性。区经信局负责编印《高新技术企业申报指南》，各街道、镇分发到辖区每个目标企业。税务部门加大高新技术企业所得税减免、研究开发费用税前加计扣除等政策的贯彻落实和宣传力度，引导更多企业申报高企。

2．区经信局要会同各街道、镇采取多种方式，在政策解析、申报程序、材料编写、研发费用辅助账设置、知识产权和成果转化等方面对企业进行培训，提升企业进行高新技术企业认定申报工作的能力水平。

（三）辅导企业申报阶段（5月份至申报时间结束）

1．区经信局会同各街道、镇建立高新技术企业认定申报企业台账。每个企业按照高新技术企业的标准进行自评，根据不同的具体困难和问题，实行一企一策，逐家跟踪服务，协助企业解决，确保企业顺利申报。

2．鼓励科技服务类企业和中介机构开展高新技术认定服务，帮助企业完善管理制度，做好研发费用辅助账设置、知识产权管理和成果推广等工作，优化申报材料的质量，提升高企认定申报通过成功率。

四、保障措施

1．建立协同推进工作机制。完成高企认定工作任务必须举全区之力协同推进，区经信局、发改局、统计局、商务局、工业园区办、投资中心、国税局、地税局、工商局、科协以及各街道办事处、镇人民政府等单位主要领导必须高度重视高新技术企业培育工作，建立健全高效的企业培育工作机制，落实联络员负责通联工作，及时沟通培育工作中遇到的问题，协同推进各项工作，共同为壮大我区高新技术企业群提供全方位的服务。

2．加强资金保障。奖补资金的及时兑现是培育高企的一项有力举措。区财政局、经信局做好年度高新技术企业申报认定奖励补助资金的预算资金安排工作，确保奖励补助资金及时足额发放。

3．加强工作考核和监督。年度高新技术企业培育任务完成情况将纳入各街道、镇绩效考核指标体系。
