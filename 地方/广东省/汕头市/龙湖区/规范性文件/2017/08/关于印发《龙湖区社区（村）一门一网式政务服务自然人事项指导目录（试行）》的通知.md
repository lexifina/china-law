# 关于印发《龙湖区社区（村）一门一网式政务服务自然人事项指导目录（试行）》的通知

各街道办事处、镇人民政府，区政府各直属部门，省、市驻区各有关单位：

《龙湖区社区（村）一门一网式政务服务自然人事项指导目录（试行）》已经区政府同意，现印发给你们，请认真组织实施。

各街道、镇，各有关部门要结合《区指导目录》，按照服务便民利民、办事依法依规、信息公开透明、数据开放共享的原则，大力推进自然人事项一门一网式政府服务模式改革工作。在执行中遇到的问题，请径向区民政局反馈。

汕头市龙湖区人民政府办公室

2017年3月2日
