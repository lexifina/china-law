# 关于印发龙湖区2017年春运工作方案的通知

各街道办事处、镇人民政府，区政府各直属部门，省、市驻区各有关单位：

《龙湖区2017年春运工作方案》业经区人民政府同意，现印发给你们，请认真组织实施。实施过程中遇到有关问题，迳向区经信局反映。

汕头市龙湖区人民政府办公室

2017年1月9日

龙湖区2017年春运工作方案

2017年春运从1月13日开始至2月21日结束，共计40天。其中春节前15天，春节后25天。为做好2017年我区春运工作，根据国家、省、市有关春运文件要求，结合我区实际，制定2017年春运工作方案。

一、指导思想及工作目标

以党的十八届、十八届三、四、五、六中全会和习近平总书记系列重要讲话精神指导春运工作全局。春运工作关系人民群众的切身利益，区委、区政府高度重视，社会关注度高、影响大，是一项重要的民生工程。各有关单位要从讲政治、保民生的高度，以对人民群众高度负责的态度，进一步增强做好春运工作的责任感和紧迫感，提高认识，精心组织，周密安排，切实抓紧抓好，使广大旅客不仅“走得了”，还要“走得好、走得满意”。

二、组织机构

为加强春运工作的领导，确保春运各项工作措施落到实处，区政府成立春运工作领导小组，由林文光副区长任组长，区政府办公室潘宣丰副主任、区经信局陈仲华局长任副组长，成员单位由区委宣传部、区发改局、财政局、经信局、商务局、人社局、城管局、民政局、卫计局、安监局、环卫局、区公安分局、交警一大队、各街道办事处和各镇人民政府等单位组成。领导小组办公室设在区经信局，由陈仲华同志兼任办公室主任，刘伟志同志兼任副主任。区春运办联系电话：88878612、88831051；传真：88831096。

三、职责分工

春运工作影响范围大、涉及部门多，是一项系统工程，既需要政府部门加强协调配合，也需要企业和社会力量的积极参与和支持。各单位要遵循“统一、效能”原则，按照以下分工职责，有针对性地制定春运工作方案，落实各项切实可行的工作措施，确保圆满完成春运各项任务。

（一）区经信局（区春运办）：要负责制订区春运工作方案，检查、督促各成员单位具体措施落实情况，加强与市春运办的联系，及时传达上级关于春运工作的有关精神和任务部署，衔接和协调处理好市春运办需要我区协办的各项工作。

（二）交警一大队：要加大道路主干线交通事故多发和易堵路段以及客运站场附近道路的指挥疏导力度，及时处理交通事故和突发事件；严肃查处超速、超员、超载、疲劳驾驶等各类交通违法行为，保障春运道路安全畅通。

（三）区公安分局：要强化交通沿线和车站、码头及周边地区的安全保卫防范，加强对参加春运的车辆、船舶，以及客运站场、码头、重点公路桥梁、隧道等大型交通基础设施的防爆反恐和巡逻防控。加大对火车站、汽车客运站等重点区域的警力投入，保障交通行业重点目标、重要设施、交通枢纽、公共交通工具安全。

（四）区委宣传部：要协调新闻媒体做好舆论宣传，广泛宣传春运政策和工作措施，及时报道和发布春运新闻和有关信息，正面引导旅客有序出行。做好突发情况下的舆情工作。

（五）区人社局：要协助外来务工人员互联网团体订票、电话订票等工作，多形式、多渠道开展外来务工人员的慰问和文化娱乐等活动，鼓励外来务工人员留汕过节，营造关心关爱外来务工人员的良好氛围。

（六）区安监局：要督促各有关部门、各有关行业落实安全生产管理责任，牵头各成员单位组成春运安全联合检查组，对全区春运工作进行安全大检查。

（七）区卫计局：要指导各有关单位做好预防流行性疾病传播工作，配合抓好运输工具和运输站场的环境卫生，预防疾病传播，并做好外来务工人员和旅客的应急临时救治准备工作，成立紧急救助小组，准备救护车辆。

（八）区民政局：要做好外来工等困难群体的应急临时救助和庇护工作，加强对流浪乞讨人员的管理和救济工作。

（九）区商务局：要做好外资、商贸企业务工人员的宣传教育和有序流动工作。

（十）区发改局：要做好对汽车、火车客运站周边商铺销售物品的价格监管工作。

（十一）区城管局：要牵头做好各客运站点周边市容秩序的整治工作。

（十二）区财政局：要做好春运工作经费保障，完善应急经费保障工作。

（十三）区环卫局：要加强春运期间的卫生清理工作，特别是要做好火车站前广场周边的保洁工作。

（十四）各街道（镇）：要落实辖区企业民工的宣传教育和有序流动工作，加强对辖区渡口渡运的安全监管，及时介入配合交警部门处置因交通事故引发的群体性事件。参与属地应急处置工作。

四、工作要求

（一）从细从严，强化春运安全监管

要始终把安全放在春运工作的首位，按照“党政同责、一岗双责、齐抓共管、失职追责”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，建立健全安全生产责任体系，逐级抓好责任落实。要进一步强化企业的安全生产主体责任，督促企业认真执行安全管理各项规定，把安全生产责任真正落实到岗位、人员和具体流程，坚决遏制重特大事故发生。各相关部门在组织开展春运安全大检查和专项检查中，要广泛采取不发通知、不打招呼、不听汇报、不用陪同和接待，直奔基层、直插现场的“四不两直”方式，加大暗查暗访和突击检查力度，提高安全检查的针对性，真正做到“全覆盖、零容忍、严执法、重实效”。

（二）加强宣传，营造良好舆论氛围。

要强化春运工作宣传，综合发挥广播、电视、报纸等传统媒体和网站、微信、微博、手机客户端等新媒体的作用，通过专题节目、专栏信息、微信公众号等多种形式，及时全方位地宣传春运有关政策措施、工作安排和运行情况，让社会各界充分了解春运工作和进展。各相关部门要与新闻媒体加强合作，广泛宣传春运一线干部职工、无私奉献、为民服务的先进事迹，弘扬社会正能量，发挥好正面宣传的引导作用。注重以平实的语言树立身边的典型，讲好春运故事，增强感染力，提高认同感，营造良好的舆论氛围。各单位要畅通意见反映、投诉举报的渠道，重视媒体监督作用，对人民群众反映较为强烈的热点和难点问题，要及时回应，做好解释沟通，以赢得人民群众更多的理解和支持。

（三）规范制度，确保信息渠道畅通

春运期间，各单位要实行24小时专人值班和领导带班制度，遇重大突发事件和特殊情况，在及时处理的同时要向市有关部门和区领导报告，不得隐瞒，同时要向社会公布24小时值班、投诉电话。按照市春运办要求，各成员单位应在以下时间节点向我办报送春运工作情况：1月26日前报送节前春运工作情况；2月1日前报送春节黄金周春运工作情况；2月26日前报送春运工作全面总结，以便及时汇总上报。（联系人：庄日炜；联系电话：88878612；传真：88267294；电子邮箱：lhjxjng@126.com)
