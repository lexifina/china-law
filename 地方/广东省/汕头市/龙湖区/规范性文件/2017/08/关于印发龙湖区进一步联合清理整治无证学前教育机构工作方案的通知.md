# 关于印发龙湖区进一步联合清理整治无证学前教育机构工作方案的通知

各街道办事处、镇人民政府，区政府各直属部门，省、市驻区各有关单位：

《龙湖区进一步联合清理整治无证学前教育机构工作方案》业经区政府同意，现印发给你们，请认真组织实施。实施过程中遇到有关问题，迳向区教育局反映。

汕头市龙湖区人民政府办公室

2017年4月1日

龙湖区进一步联合清理整治无证

学前教育机构工作方案

历年来，龙湖区委、区政府非常重视无证幼儿园的清理整治工作，为整顿全区教育教学秩序，结合全市创文形势，创造安全、健康、优质的校园成长环境，决定在全区进一步开展联合清理无证整治无证学前教育机构专项行动，确保整治工作目标的实现。清理整治工作方案如下：

一、工作目标

在全区范围内，对凡未取得教育部门办学许可，开展3—6岁儿童保育教育活动的学前教育机构进行全面清理整治。对符合办园基本要求的责令其限期按程序办理审批手续；对基本具备办园条件、通过整改后能达到办园要求的责令限期整改，对整改后符合办园基本要求的及时办理办园许可证，对整改不到位的予以取缔；对存在重大安全隐患的，依法坚决予以取缔。促进全区民办幼儿园办学行为的规范化，形成健康有序的学前教育发展格局。

二、整治内容

依法取缔无《汕头市民办幼儿园办学注册证》，擅自开展学前教育的幼儿园（办学机构），包括未经审批的打着“培训中心”、“亲子园”名称的变相学前教育、早教机构。

三、组织领导

为加强对清理无证幼儿园工作的组织协调，区政府成立联合清理无证学前教育机构专项行动领导小组，成员如下：

四、时间安排

2017年4月1日开始，为期二个月。

五、工作职责

因我区无证学前教育机构多，情况复杂，清理难度大，各成员单位应明确责任，确保完成工作任务。

（一）两镇及各街道办事处

1．摸查辖区内存在的无证学前教育机构，形成台账报区联合清理无证无证学前教育机构专项行动领导小组办公室。

2．负责牵头辖区派出所、工商所及有关职能部门，组织对辖区内的无证幼儿园开展全面清理取缔行动，并将清查取缔情况反馈给区联合清理无证无证学前教育机构专项行动领导小组办公室汇总。

3．协助发放《致家长一封信》，加大向无证幼儿园幼儿家长的宣传力度，做好被取缔的无证幼儿园办学者、教师及家长的思想工作，加强稳控。

4．发放《致业主一封信》，加大宣传力度，要求业主尽快终止将场地租赁给无证幼儿园使用的行为。

5．清理行动完成后要健全长效管理机制，实行网格化管理，按照“属地管理”原则，加强对无证幼儿园的清查，一经发现，立即牵头有关部门予以清理。

（二）区委宣传部

负责联系本地新闻媒体，做好对联合清理无证幼儿园行动的宣传报道工作。

（三）区综治办

统筹、协调校园安全防范以及清理无证幼儿园专项行动稳控工作。

（四）龙湖公安分局

协调、指挥各派出所按街道部署做好无证幼儿园的全面清理取缔行动。

（五）区教育局

1．统计有证幼儿园办学规模、幼儿就读情况以及无证幼儿园停办后需分流的幼儿人数，摸清并掌握全区无证幼儿园取缔后如何就近入园的基本情况，妥善安置幼儿就读。

2．印发《致家长一封信》，做好前期的宣传发动工作。

3．派员配合街道、镇部署做好无证幼儿园的全面清理取缔行动。

4．负责无证幼儿园清理取缔行动情况的汇总通报。

5．指导接收分流幼儿的幼儿园为幼儿建立学籍。

（六）区工商局

协调、指挥属下各工商所配合、依职协助各有关部门做好无证幼儿园的全面清理取缔行动。

（七）区安监局、区卫计局、区城管执法局、龙湖消防大队

协助街道、镇做好无证幼儿园的全面清理取缔行动。

六、工作要求

（一）加强组织领导。各成员单位要充分认识联合清理无证幼儿园专项行动的重要性和紧迫性，加强领导，切实承担起对无证幼儿园的整治工作责任，确保清理取缔专项行动按时全面完成。

（二）加强协调合作。联合清理行动涉及面广，工作难度大，各成员单位要按照职责分工的要求，积极主动，统一步调，加强协作，形成合力。

（三）加强宣传发动。群众的理解、支持和配合是推进联合清理行动达到预期目标的重要保障，各成员单位要重视做好宣传发动工作，注重工作的方式方法，加强正面宣传和引导，为整顿教育教学秩序营造良好的舆论环境。

（四）加强通报反馈。专项行动期间建立周通报制度，各街道每周五上午下班前将本周清理进展情况通过OA报送区联合清理无证学前教育机构专项行动领导小组办公室；清理无证学前教育机构专项行动领导小组每半个月召开一次情况通报会，通报清理进度，协调解决清理工作中出现的问题，推进工作落实，确保清理工作取得实效。
