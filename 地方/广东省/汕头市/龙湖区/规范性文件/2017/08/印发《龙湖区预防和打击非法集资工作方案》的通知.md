# 印发《龙湖区预防和打击非法集资工作方案》的通知

各街道办事处、各镇人民政府，区直有关部门，省、市驻区有关单位：

《龙湖区预防和打击非法集资工作方案》已经区政府研究同意，现印发给你们，请认真贯彻落实。

汕头市龙湖区人民政府办公室

2016年12月29日

龙湖区预防和打击非法集资工作方案

为进一步做好我区预防和打击非法集资工作，有效防范金融风险，保障人民群众合法权益，维护经济金融秩序和社会稳定，按照省、市有关要求，结合我区实际，制定如下工作方案。

一、指导思想

深入贯彻区委、区政府决策部署，认真落实预防和打击非法集资工作安排，从保障经济安全运行、维护群众合法权益、优化金融生态环境的高度出发，按照属地管理和“谁审批、谁负责；谁监管、谁负责；谁登记、谁负责”的原则，建立健全预防、打击、处置非法集资的工作机制，进一步优化金融生态环境，确保区域不发生系统性金融风险。

二、任务目标

（一）全面排查清理涉嫌非法集资广告。按照省、市统一部署，组织开展涉嫌非法集资广告全面排查清理活动。对报刊、网络、传单、宣传册、电视、户外广告（包括宣传牌、电子屏、公交、公交站点、出租车等）和社区内、办公楼、售楼部等范围内，以各种名义涉嫌从事非法集资广告宣传的，或以返租售、收藏等各种名义变相进行涉嫌非法集资宣传活动的行为进行清理整治。做好持续监管，定期巡查，建立健全涉嫌非法集资广告的日常监管制度，督促广告发布单位增强法律意识和责任意识，加强对从业人员的管理和业务培训。

（二）深入开展防范非法集资宣传教育活动。按照省、市统一部署，组织开展防范和打击非法集资集中宣传，结合当前非法集资活动的新形势、新特点，综合利用电视、报刊、网络、短信等多种手段，组织开展防范和打击非法集资宣传教育活动，突出重点，创新宣传方式方法，确保宣传效果，形成强大舆论攻势，增强公众对非法集资的辨别能力，营造防范和打击非法集资的良好舆论氛围，从源头上遏制非法集资案件的发生。

（三）加大风险隐患排查力度。按照省、市统一部署，集中对全区农民专业合作社、投资咨询公司、理财公司、贷款中介公司、网贷公司、房地产公司等较易发生非法集资的行业和领域开展集中排查。要坚持“打早、打小、打苗头”，始终保持高压态势，坚决将非法集资消灭在萌芽状态。各防范和处置非法集资工作领导小组成员单位分别负责对本辖区、本系统、本行业开展拉网式风险隐患排查，摸清底数，发现问题及时查处，并对隐患排查情况进行认真总结通报。

（四）配合做好公安和上级有关部门对重点案件调查处理的配合工作。在市处非办的指导下，协调区公安局等有关部门做好重点案件信访维稳、舆情稳控等相关工作，并确保网络舆情及信访维稳情况稳定可控。根据工作需要和领导指示，指导、督促有关各街道镇认真做好辖区内企业涉嫌非法集资案件处置工作切实维护全区稳定大局。

三、职责分工

（一）属地管理。区政府对全区预防和打击非法集资工作实施统一部署和协调，各街道镇对辖区内预防和打击非法集资工作负管辖责任，抓好辖区内预防和打击非法集资工作指导、组织协调、宣传教育、风险防范、预警监测、案件先期处置等相关工作。

（二）行业把关。区防范和处置非法集资工作领导小组成员单位按照“谁审批、谁负责；谁监管、谁负责；谁登记、谁负责”和行业归口管理的原则，认真做好主管行业和领域预防和打击非法集资宣传教育、风险防范、预警监测、案件处置等相关工作。

（三）依法处置。各街道镇及各行业主（监）管部门要依据相关法律法规和规定，按照职责分工和工作权限，依法严厉打击非法集资行为，依法妥善处置非法集资活动。

（四）维护稳定。在打预防和打击处置非法集资工作中，要坚持积极稳妥、措施得当、稳定为先的工作原则，认真做好信访维稳和舆情引导工作，全力预防群体性事件发生，确保不发生系统性区域性金融风险。

四、有关要求

（一）高度重视。各街道镇、各行业主（监）管部门要高度重视预防和打击非法集资工作，建立健全预防和打击非法集资工作组织机构，明确专人负责，进一步明确工作职责和工作流程，落实经费保障，确保预防和打击非法集资工作有序推进。

（二）认真落实。各街道（镇）要根据本工作方案的要求，结合本街道（镇）实际情况，制定周密、具体、操作性强的工作措施，确保预防和打击非法集资工作有序开展。

（三）保持通联。区防范和处置非法集资工作领导小组成员单位将本单位防范和处置非法集资工作分管领导和联系人名单报区防范和处置非法集资工作领导小组办公室（区金融局，地址：区政府大楼804室，联系人：陈少溪，电话传真：88263465，邮箱：stlhjrj@126.com）。
