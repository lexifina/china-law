# 关于印发龙湖区免费孕前优生健康创新试点工作实施方案的通知检查改革

各街道办事处、镇人民政府，区政府各直属部门，省、市驻区各有关单位：

《龙湖区免费孕前优生健康检查改革创新试点工作实施方案》业经区政府同意，现印发给你们，请认真组织实施。实施过程中遇到有关问题，迳向区卫计局反映。

汕头市龙湖区人民政府办公室

2017年5月17日

龙湖区免费孕前优生健康检查改革创新

试点工作实施方案

为降低出生缺陷发生风险，提高出生人口素质，根据《汕头市卫生计生局关于开展免费孕前优生健康检查改革创新试点工作的通知》（汕市卫函〔2017〕21号）文件精神，结合我区实际，在我区开展免费孕前优生健康检查改革创新试点工作，特制定本实施方案。

一、指导思想

在区委、区政府的领导下，全面落实科学发展观，以人为本，民生为重，开展免费孕前优生健康检查改革创新试点工作，让每一对政策内计划怀孕夫妇全面享受免费孕前优生健康检查的优质服务，把预防措施落实在怀孕之前，实现预防关口前移，有效降低出生缺陷的发生风险，孕育健康聪明的孩子，为构建幸福龙湖做出新的贡献。

二、工作时间

从2017年5月初起在全区开展此项工作。

三、工作目标

科学普及优生知识，使育龄群众优生科学知识得到普及；建立“以人为本”的多重关怀机制；让每一对符合生育政策、准备怀孕的夫妇都能享受到优质的免费孕前优生健康检查改革创新服务，有效降低出生缺陷发生风险，提高出生人口素质。

（一）通过实施免费孕前优生健康检查改革创新服务，使计划怀孕夫妇优生知识知晓率达到95%以上；

（二）通过行政引导和宣传教育，使计划怀孕夫妇参加孕前优生健康检查的主动性和自觉性不断增强，孕前优生健康检查率逐年提高；

（三）建立健全出生缺陷预防的服务网络和体系，通过开展免费孕前优生健康检查改革创新试点工作，使我区的优生服务能力得到进一步提高，出生缺陷风险逐步降低，出生人口素质逐步提高。

四、工作原则

（一）政府引导。各街道（镇）、区各有关单位要充分认识预防出生缺陷、提高出生人口素质的重大意义，将之纳入经济和社会发展规划，确保配套资金、措施和管理落到实处，探索建立“政府主导、部门合作、专家支撑、群众参与”的工作机制。

（二）群众自愿。孕前优生健康检查须尊重个人知情权和隐私权，签订知情同意书，除法律法规规定外，不得向第三方泄露当事人检查结果。

（三）免费服务。全区符合生育政策、计划怀孕的夫妇，每孩次可以享受一次免费孕前优生健康检查服务。如果接受检查后未按计划受孕，或怀孕后出现流产、死胎、死产再次准备怀孕，应根据需要在医生指导下自费接受孕前优生健康检查。

（四）科学规范。严格按照国家免费孕前优生健康检查项目各项要求，科学普及预防知识，规范开展优生检查，正确进行咨询指导，充分发挥专家作用，强化队伍建设和技术指导监督，注重社会效益。

五、工作内容

（一）目标人群

符合生育政策、计划怀孕的龙湖区户籍人口夫妇（含一方）以及在本地居住半年以上的流动人口夫妇。

（二）服务内容

按照《广东省孕前优生健康检查基本服务内容》规定，为计划怀孕夫妇提供优生健康教育、体格检查、临床实验室检查、风险评估、咨询指导等21项孕前优生健康检查服务。

1、优生健康教育；

2、病史询问（了解孕育史、疾病史、家族史、用药情况、生活习惯、饮食习惯、环境危险因素等）；

3、体格检查：常规检查（包括身高、体重、血压、心率、甲状腺触诊、心肺听诊、肝脏触诊、四肢脊柱检查等）、女性生殖健康系统检查、男性生殖健康系统检查；

4、临床医学检查内容有14项，包括实验室检查9项（阴道分泌物检查：白带常规检查、淋球菌检测、沙眼衣原体检测；血液常规检查：血红蛋白、红细胞、白细胞及分类、血小板；尿液常规检验；血型检验：包括ＡＢＯ血型和Ｒｈ阳／阴；血清葡萄糖测定；肝功能检测（谷丙转氨酶）；乙型肝炎血清学五项检测；肾功能检测（肌酐）；甲状腺功能检测（促甲状腺激素）；地中海贫血检测；G6PD缺乏症检查）；病毒筛查4项（梅毒螺旋体筛查、风疹病毒IgG抗体测定、巨细胞病毒IgM抗体和IgG抗体测定；弓形体IgM抗体和IgG抗体测定）；影像学检查1项（妇科超声常规检查）；

5、风险评估和咨询指导；

6、早孕和妊娠结局跟踪随访。

（三）服务机构

免费孕前优生健康检查各项服务由区妇幼保健计划生育服务中心、龙湖人民医院和汕头大学医学院第一附属医院共同承担。区妇幼保健计划生育服务中心充分发挥计生流动服务功能，深入镇（街）、村（居）开展宣传服务、健康教育、咨询指导、早孕及妊娠结局随访等服务。龙湖人民医院为龙湖辖区内医学检查定点医院，汕头大学医学院第一附属医院为龙湖区市级医学检查定点医院，开展病史询问、体格检查、临床检查、影像学检查、风险评估等服务。符合条件的计划怀孕夫妇可自主选择到定点医院进行相关项目免费检查。

六、资金来源

龙湖区开展免费孕前优生健康检查改革创新试点工作的专项资金，由中央、省财政、市和区级财政按比例承担，并列入年度财政预算安排。承担此项工作任务的医疗机构，按照广东省医疗机构服务价格规定八折收费 ，每年6月和12月由区卫计局审核后，按实际检测人数和项目拨给医疗机构。

七、服务流程

各村（居）委会负责做好本次健康检查的宣传发动组织工作，发放《龙湖区开展免费孕前优生健康检查通知书》，参加健康检查对象持本人身份证和健康检查通知书自主选择到区级或市级定点医院进行相关项目免费检查。

八、有关要求

（一）加强领导。为加强对免费孕前优生健康检查改革创新试点工作的组织领导，积极落实各项保障措施，研究解决工作中出现的问题，确保孕前优生健康检查改革创新试点工作顺利进行。龙湖区成立免费孕前优生健康检查改革创新试点工作领导小组，组长由区政府分管领导担任，副组长由区卫计局、财政局主要领导担任，成员为区民政局、卫计局、妇幼保健计划生育服务中心、定点医院各一位领导。领导小组下设办公室，办公室设在区卫计局，负责开展日常工作。各街道（镇）要相应成立免费孕前优生健康检查改革创新试点工作领导小组，切实加强对此项工作的领导。

（二）明确职责。免费孕前优生健康检查项目是一项造福社会的民心工程，各相关部门要结合职能特点，发挥各自优势，明确职责分工，实现部门协作，整体联动，共同做好项目组织实施工作。

1、区卫计局：负责免费孕前优生健康检查改革创新试点工作的组织协调及检查、绩效评估工作。加强技术服务监督管理，开展人员培训、技术指导和质量控制，通过区、镇、村三级网络举办婚育学（分）校培训班，强化优生科学知识的社会宣传工作，组织发动目标人群进行孕前优生健康检查，做好服务机构和服务对象资格确认工作，制作并向目标人群发放宣传资料，负责免费孕前优生健康检查的报表上报工作。

2、区财政局：负责组织专项资金年度预算编制并及时下达，对资金使用情况进行监督管理。

3、区民政局：利用婚姻登记管理工作平台，配合卫计部门做好宣传教育工作，向新婚登记夫妇发放龙湖区开展免费孕前优生健康检查项目的宣传资料，每月将新婚登记夫妇信息提供给区免费孕前优生健康检查改革创新试点工作领导小组办公室。

4、各街道（镇）：负责做好开展免费孕前优生健康检查改革创新试点工作的宣传发动，计生服务所负责做好早孕及妊娠结局的追踪随访，村（居）委会负责做好目标人群的调查摸底，掌握目标人群信息，对符合条件的人员进行审核，发放《龙湖区开展免费孕前优生健康检查通知书》。各街道（镇）计生办于每月28日前将目标人群信息上报区免费孕前优生健康检查改革创新试点工作领导小组办公室。

（三）开展宣传。充分发挥宣传栏、报刊、广播、网络等媒体作用，加大社会宣传力度，使计划怀孕夫妇及时了解孕前优生健康检查的重要性，提高孕前优生健康检查的人群覆盖率。

（四）规范管理。要结合实际，制定实施细则和相关配套政策，规范工作流程，建立资格确认、免费服务、按例结算、监督检查的工作制度，构建免费孕前优生健康检查改革创新试点工作正常稳定、可持续实施的管理运行体系和技术服务体系。汕头大学医学院第一附属医院按《国家免费孕前优生健康检查技术服务规范》组织培训，成立专家指导小组，充分发挥专家作用，强化队伍建设和技术指导监督。加强项目监督管理，保障专项资金专款专用。定期组织监察、审计等部门对项目组织实施、资金使用等情况进行监督评估。要加强调查研究，及时总结经验，不断完善免费孕前优生健康检查改革创新试点的工作制度和配套措施。
