# 关于印发2017年利用教育资源支持企业发展工作方案的通知

各街道办事处、各镇人民政府，区直各有关部门，省市驻区有关单位，各有关学校：

《2017年利用教育资源支持企业发展工作方案》经区政府同意，现印发给你们，请认真组织实施。

汕头市龙湖区人民政府办公室

2017年6月20日

关于2017年利用教育资源支持企业发展工作方案

为不断优化投资环境，提升服务企业水平，推动龙湖经济社会加快发展，区政府决定进一步加大优质企业扶持力度，从教育资源中安排部分学位解决重点企业员工子女入学问题，全力支持企业发展，特制定本方案。

一、列入提供学位的学校

（一）优质学校：包含小学、初中两个层次，每所学校提供5个名额，其中：

1.小学21所：金中华侨试验区学校、金阳小学大悦城校区、丹霞小学及丹霞小学香域水岸校区（各5个名额）、金涛小学、丽日小学、绿茵小学、锦泰小学、金晖小学、龙湖小学、陈厝合小学、广兴小学、珠池小学、朝阳小学、世贸实验学校、夏桂埔小学、下蓬中心小学、鸥上小学、蓬中华侨小学、新溪中心小学、亿信小学；

2.初中12所：金中华侨试验区学校、丰华学校、世贸实验学校、翠英中学、蓬鸥中学、蓝田中学、广二师龙湖附中、新津中学、谢易初中学、外砂华侨中学、新溪中学、龙湖实验学校；

（二）普通公立学校：包含小学、初中两个层次，每所学校提供7个名额，其中：

1.小学26所：内充公小学、永安小学、辛厝寮小学、周厝塭小学、官一小学、万吉西小学、渔下小学、旦家园小学、华兴小学、蔡社小学、渔五小学、诒铭小学、林厝小学、金洲小学、鄰德小学、龙头小学、华新培英小学、凤窖华侨小学、南侨小学、景峻小学、中头合小学、下头合小学、上三合小学、中三合小学、六份小学、西南小学；

2.初中4所：下蓬中学、渔洲中学、新溪一中、外砂中学。

二、申请学位企业条件

1.上年度纳税额（区级库）在全区排名前10位和建筑业总产值、房地产销售额分别排名前5位的企业；

2.上年度工业总产值、商业销售额在全区排名各前10位且今年1-6月增速分别达到11%、22%的规上、限上企业；

3.上年度工业总产值、商业销售额、社零总额1亿元以上且今年1-6月份规上、限上、限上社零增速分别达到11%、22%和16%以上的企业；

4.上年度工业总产值、商业销售额、社零总额1亿元以下，2000万以上，今年1-6月份规上、限上、限上社零增速分别在全区排名前10名的企业；

5.上年度工业总产值、商业销售额5亿元以上且上年度增速分别达到6.4%、18.5%的规上、限上企业；

6.上年度进口额、出口额在全区排名各前3位且上年度增速达到5%以上企业；

7.上年度7月1日至今年6月30日在龙湖投资公益事业或捐款总额（实到账）达到100万元以上的个人、企业或其它组织；

8.上年度列入省、市重点项目年度实际完成投资额前5位，且超额完成当年度投资计划目标进度的项目单位；

9.上年度新增的“四上”企业，按照上年度规上工业产值、限上商品销售额、规上服务业主营收入大小进行综合排名；

10.上年度新上市的企业，按照在主板、创业板、香港上市和新三板挂牌的类型依次排名，如有相同类型的按照上市时间先后排名；

11.上年度新认定的高新技术企业，按照上年度工业总产值（营业额）排名前5名；

12.龙湖辖区内所有规上工业企业以及今年度列入“四上”企业和高新技术企业培育对象的企业，按照上年度工业总产值（或上年度营业额）进行排名；

对符合以上条件，且在龙湖取得工商登记、纳税、纳入统计的企业，各奖励一个学位名额，用于解决本单位员工子女入学问题（该员工本年度须在龙湖企业缴纳社保，符合以上1、2项的企业可不限本企业员工子女）。同时符合多个条件的企业不重复安排名额，并按每个类型排名最前的确定排序位置。

三、学位奖励方法

（一）优质学位：对符合上述1-11项条件的企业，可申请1个优质（或普通公立学校）学位，分2轮进行排序并依次挑选。

第一轮：包括纳税额前5名、工业总产值前2名、商品销售总额前2名、建筑业总产值前2名、房地产销售额前2名、工业总产值1亿元以上增速前2名、商品销售额1亿元以上增速前2名、社零总额1亿元以上增速前2名以及捐款额第1名的企业。具体排序如下：纳税额第一名、工业总产值第一名、商品销售总额第一名、建筑业总产值第一名、房地产销售额第一名、工业总产值1亿元以上增速第一名、商品销售额1亿元以上增速第一名、社零总额1亿元以上增速第一名、捐款额第一名、纳税额第二名……后面以此类推。

第二轮：对符合申请优质学位条件的企业，剔除第一轮涵括的企业之后按如下方法排序：纳税额第一名、工业总产值第一名、商品销售总额第一名、建筑业总产值第一名、房地产销售额第一名、工业总产值1亿元以上增速第一名、商品销售额1亿元以上增速第一名、社零总额1亿元以上增速第一名、工业总产值1亿元以下2000万元以上增速第一名、商品销售额1亿元以下2000万元以上增速第一名、社零总额1亿元以下增速第一名、上年度工业总产值5亿元以上且上年度增速第一名、上年度商业销售额5亿元以上且上年度增速第一名、上年度进口额第一名且增速达5%以上、上年度出口额第一名且增速达5%以上、捐款额第一名、重点项目投资额第一名、新增“四上”企业第一名、新上市企业第一名、新认定高新技术企业第一名、纳税额第二名……后面依次类推。

符合条件的企业按照第一轮、第二轮的顺序，以及每一轮中具体排名依次申请，各个学校名额选完即止。

（二）普通公立学校学位：符合第12项条件的企业，可申请1个普通公立学校学位，按照排名依次申请，各个学校名额选完即止。

四、入学对象应具备以下条件

1.凡进入小学阶段就读的对象，户口不限，但必须符合教育部门规定的入学条件；

2.凡进入初中阶段就读的对象，应有正式的学籍，德育考核和各学科测评、考查成绩为合格以上。报读龙湖实验学校的，在其面谈测评合格情况下给予优先录取。

五、其它要求

1.区民政局负责牵头摸查汇总上一年度7月1日至今年6月30日在龙湖投资公益事业或捐款总额达到100万元以上的个人、企业或其它组织名单，注明投资或捐款时间和数额；区国税局、地税局协助提供上一年度企业纳税情况，由区财政局负责汇总上一年度纳税额（区级库）全区排名前10名企业名单；区商务局负责汇总上一年进口额、出口额在全区排名各前3位的企业名单；区经信局负责汇总上一年度新认定高新技术企业及今年度高新技术企业培育对象名单，注明去年度企业工业总产值（营业额）；区金融局负责汇总上一年度新上市企业名单，注明上市板块及上市时间；区发改局负责提供上一年度重点项目实际完成投资额前5名单位名单，注明投资数额；以上单位请于6月30日前将名单提供给区统计局。区社保分局负责为申请优质学位的企业员工开具个人参保证明；其他类型由区统计局负责汇总，并连同区民政局、财政局、经信局、金融局、发改局、商务局提供的名单进行排序，于7月10日前报区政府办公室调研室。

2.各类型企业名单确定后，由区政府办公室印发到各街道（镇）及各相关职能部门，再由各街道（镇）及相关部门通知企业。其中，第1类企业中的建筑、房地产企业由区统计局负责通知及审核，第6类企业由区商务局负责通知及审核，第7类企业由区民政局负责通知及审核，第8类企业由区发改局负责通知及审核，第10类企业由区金融局负责通知及审核，第11类企业由区经信局负责通知及审核，其他由各街（镇）负责。在名单尚未确定和印发之前，各街道（镇）及相关部门不得提前接受企业申报。

3.符合条件且需解决就读学生的企业，在接到通知后到所在街（镇）或相关部门领取《龙湖区重点企业员工子女入学申请表》（附后）一式二份，由公司盖章后于7月20日前报所在街（镇）或相关主管部门审核同意后，报区政府办公室（径送区政府大楼801房调研室）。其中，符合第3-12项要求的企业员工需提供所申报企业员工证明和区社保分局开具的个人参保证明，申请普通公立学校学位的无需提供社保证明。小学新生入学需提供户口本和出生证复印件，就读初中的需提供学生手册。

4.区政府办公室收齐申请表和相关资料后，由区有关领导召开相关部门会议研究确定入学对象，交区教育局办理。

5.区教育局负责通知具体学校为学生办理入学手续。

6.学生进入民办初中就读的按学校收费标准缴纳。

7.各街道、镇和各经济职能部门要加大宣传力度，让广大企业及时知晓，更好地推动龙湖经济社会加快发展。
