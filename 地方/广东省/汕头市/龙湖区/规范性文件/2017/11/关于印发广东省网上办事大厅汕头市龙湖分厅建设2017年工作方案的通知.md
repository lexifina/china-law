# 关于印发广东省网上办事大厅汕头市龙湖分厅建设2017年工作方案的通知

各街道办事处、镇人民政府，区政府各直属部门，省、市驻区各有关单位：

《广东省网上办事大厅汕头市龙湖分厅建设2017年工作方案》业经区政府同意，现印发给你们，请认真组织实施。实施过程中遇到有关问题，迳向区电子政务办反映。

汕头市龙湖区人民政府办公室

2017年6月30日

广东省网上办事大厅汕头市龙湖分厅

建设2017年工作方案

为贯彻落实省委、省政府和市委、市政府工作部署，加快推进区网上办事大厅服务体系建设，推行“一门式一网式”政府服务模式，提升“互联网+政务服务”水平，促进政府职能转变，结合我区实际，制定本方案。

一、总体要求

（一）工作思路

围绕“放管服”改革一个核心，依托全区统一的网上办事大厅服务体系，深入推进“互联网+政务服务”，促进“简政放权与全程监管”、“公共服务与一机两页”两个结合，开展网上办事大厅进驻事项优化和规范、网上办事大厅应用提升、政务服务平台与智慧城市建设对接、网上全流程效能监督四项行动，提升政务服务精准化、个性化、智慧化水平。

（二）工作目标

力争到2017年底，全区网上办事“三率一数”稳步提升，全区行政许可事项网上全流程办理率、上网办理率、网上办结率、网上申办事项到现场办理次数达到省、市的考核要求。实现行政许可事项网上全流程办理率达80%以上，上网办理率达70%以上，网上办结率达70%以上，70%以上网上申办事项到现场办理次数不超过1次，20%以上网上申办事项实现零次跑动。加快推进证照 （批文）电子化，深化工商营业执照、完税证明、结婚证、残疾人证等电子证照在业务办理中的应用。

二、开展网上办事大厅进驻事项全面优化和规范行动

加大网上办事大厅行政许可事项服务深度的清理和优化力度，提升进驻事项的办理深度，确保网上全流程办理率达标。加强宣传和应用普及，强化网上服务能力，积极引导公众通过网厅办事，不断提升上网办理和网上全流程办结的业务量，切实提高上网办理和网上办结的水平。完善网厅进驻事项的基本信息、办事指南和业务手册，规范申报材料、优化办事程序、提高办事效率，特别是要依托网厅邮政速递服务功能，为办事人递交材料和领取结果提供便利，最大程度实现办事人零次跑动。要以目标任务倒逼工作落实，积极推进网厅广泛应用，实现行政许可事项网上全流程办理率、上网办理率、网上办结率、网上申办事项到现场办理次数等指标取得新突破，促使网厅服务提速增效，便民利民成效不断凸显。

三、开展网上办事大厅应用提升行动

（一）支撑行政审批权取消和下放。按省、市的统一规范完成网厅其他系统与省事项目录管理系统的对接，实现全区行政许可事项目录的同步更新，推动行政许可事项的整合归类和优化管理。深入开展事项标准化工作，根据《广东省行政许可事项通用目录（2017年版）》，完成区级部门行政许可事项的调整。按照全省统一规范，加快推动我区行政许可事项标准的编写录入。完善行政许可事项目录和标准的动态管理机制，提升行政许可事项标准应用水平。优化和提升区统一申办受理平台功能，逐步推动与部门业务系统、垂直业务系统对接，实现统一申请、统一受理、集中办理、统一反馈的“一网式”政务服务。

（二）优化网上办事服务体验。构建基于云架构的全区 “一张网”，整合导航、申办、认证、查询、咨询与评价等功能，拓展网上办事情景式导航服务，优化事项搜索方式，快速感知用户办事意愿并定位办事入口，及时呈现办事全貌。优化统一身份认证体系，加强引导用户注册，推广实名核验窗口业务，在全区推广应用省统一身份认证平台，实现服务事项一次登录、全网通办、身份信息共享。逐步建立网上办事知识库，优化网上咨询服务，实现有效政民互动。推动网上办事大厅延伸到基层，推进行政服务中心实体大厅与网上办事大厅无缝连接，拓展线上线下一体化服务，实现事项网上直办、就近能办、同城通办、异地可办。

（三）拓展公共服务“一机两页”便捷应用。对照国家“互联网+政务服务”技术体系建设指南，细化公共服务标准，推行公共服务标准化。以办理量大、涉及面广的民生事项为切入点，推动公共服务事项网上办理，全方位增加在线公共服务供给。配合省、市完善网上办事大厅手机版功能，提升个性化服务和精准推送能力，丰富工商、交通、税务、海关、教育、医疗、户籍、出入境、二孩等热点服务内容，推动移动服务向镇街延伸，加快对接第三方支付平台，支撑手机“查、缴、办”一站式服务升级。配合省、市优化企业专属网页和群众个人网页，完善企业找政府服务，结合我区实际拓展特色服务，重点拓展投资审批、税务服务等涉企事项及民生事项，变被动服务为主动服务。

（四）推广应用全省统一电子证照系统。加快组织我区各部门梳理事项与证照的关系，形成本地区的发证清单、用证清单，并列出发证和用证实施计划，完成部门业务系统与电子证照系统对接，推进存量和增量纸质证照及相关证明、批文、鉴定报告、办事结果等材料电子化，逐步实现凡是能通过网络共享复用的材料不再要求企业和群众提交，促进民生服务、投资审批、工商登记等领域的证照应用。逐步完善电子文件归档管理制度。

四、开展网上全流程效能监督行动

（一）健全效能监督体系。坚持“放管”并重，通过网上办事大厅加强对下放权限事项的全程监管。完善区统一申办受理平台的部门内部监督功能，加强对各部门办事环节、办理人等的监督，根据时效、内容、流程等异常情况发出“红牌”、“黄牌”预警信号。利用省网上办事效能监督平台，获取在线实时监管、满意度测评、办事效率及结果运用等指标，实现网上办事效能在线监督和考核。建立行政许可绩效评估机制，制定绩效评分标准，对行政许可进行绩效评估。强化区分厅与省、市网上办事大厅效能监督栏目对接，定期公布网上办事监督结果，接受社会公众监督。

（二）加强网上办事数据在线监测。利用省网上办事大厅数据监测系统，查看本区网上办事数据规范情况和业务情况，实现对全区网上办事过程数据动态监测，自动研判事项网上全流程办理情况，不断提升办事效能。

五、保障措施

（一）加强组织领导。各部门要以目标和问题为导向开展网上办事大厅建设，主要领导高度重视，分管领导具体抓好落实，进一步充实网上办事大厅业务、技术和建设管理力量。区电子政务办全面发挥牵头抓总作用，加强对网上办事大厅建设工作的统筹、协调、监督。区编办要加强对各级各部门行政许可事项标准编写和录入的督促指导，确保按时完成区、镇（街道）二级标准编写录入工作，组织推动公共服务事项标准化工作，为“一门式一网式”政府服务模式改革打好基础。区财政局要做好网上办事大厅建设和“一门式一网式”政府服务模式改革的相关经费保障工作。区信息中心要做好网上办事大厅和“一门式一网式”相关政务系统的技术支撑工作。

（二）加强督办检查。继续加强网上办事大厅工作绩效考核，围绕省、市下达的网厅“三率一数”指标，将考核完成情况纳入政府绩效考核体系，列入区政府重点督查督办事项。区电子政务办、区信息中心要健全网上办事大厅检查机制，对网上办事大厅进行全方位、全流程的日常检查和数据监测，适时通报各部门网上办事大厅工作进展情况，同时抄报区委、区政府相关领导；继续配合省、市做好网上办事大厅效能监督栏目数据核对工作，及时向社会公开网上办事监督、业务办理结果、事项进驻情况等内容。监察机关要加强效能建设的监督问责，督促有关部门落实网上办事大厅效能监督建设职责；对效能建设方面履行主体责任不力、效能监督落实不到位的问题严肃问责并予以通报，对不能按时完成考核任务的单位纳入效能问责。

（三）加强安全保障。落实国家信息安全等级保护制度要求，将安全防护理念融入网上办事大厅各建设阶段，确保网上办事大厅各业务系统开发设计及部署过程遵从安全标准及规范。加强数据安全管理，梳理各业务系统的核心数据资产和所面临的安全威胁。完善技术防范、应急处置方案和措施，定期进行网上办事大厅应急安全响应演练，切实保护信息安全和公民个人隐私。

（四）加强宣传推广。加大网上办事大厅宣传力度，通过宣传报道和品牌推广，逐步提高企业和群众对网上办事大厅的认知度和使用率。开展公众调查和专业评测，主动搜集并及时回应用户提出的问题，提升用户的网上办事体验。要做好网上办事大厅的应用培训工作，切实提高各方对网厅建设的认识，提高业务人员和技术人员的业务能力和办事效率，增强公务人员为社会公众提供网上公共服务的能力，扎实推进各级网上办事大厅的建设。

服务主题分类

名词解释

1.业务量：指办事人提出申请，部门受理且已办结的业务量。

2.网上全流程办理率：指网上全流程办理的事项数占进驻网上办事大厅事项总数的比率。（行政许可事项）

3.上网办理率：指上网申办业务量占总业务量（网上办理和实体大厅办理的事项）的比率。（行政许可事项）

4.网上办结率：指网上全流程办理并办结的业务量占总业务量（网上办理和实体大厅办理的事项）的比率。（行政许可事项）

5.申办事项到现场办理次数：申请人在整个办事过程到现场的跑动次数。
