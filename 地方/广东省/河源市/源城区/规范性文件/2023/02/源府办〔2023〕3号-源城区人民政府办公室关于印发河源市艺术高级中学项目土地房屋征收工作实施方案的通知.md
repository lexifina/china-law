# 源城区人民政府办公室关于印发河源市艺术高级中学项目土地房屋征收工作实施方案的通知

源府办〔2023〕3号

东埔街道办事处，区府直属有关单位：

《河源市艺术高级中学项目土地房屋征收工作实施方案》已经区人民政府同意，现印发给你们，请认真贯彻执行。执行中遇到的问题，请径向东埔街道办事处反映。

源城区人民政府办公室

2023年2月15日

河源市艺术高级中学项目土地房屋征收工作实施方案

河源市艺术高级中学项目是市规划重点建设项目，项目的实施将大力改善市的教育环境，对提升我市教育事业发展和竞争力具有重要意义。为切实做好河源市艺术高级中学项目土地房屋征收工作，促进项目顺利实施，现结合实际，制定本方案。

一、实施范围

河源市艺术高级中学项目位于东埔街道高塘村辖区，项目需征收土地10.5459公顷，其中学校面积6.5035公顷，道路面积4.0424公顷。拟征收集体土地总面积9.5969公顷，其中农用地8.3651公顷（耕地0.8243公顷、园地0.1918公顷、林地6.6824公顷、其他农用地0.6666公顷），建设用地0.9157公顷，未利用地0.3161公顷。土地房屋征收范围涉及东埔街道高塘村红线范围内的土地、房屋及其他地上附着物。

二、时间要求

2023年6月底前全面完成土地房屋征收工作。

三、组织领导

为确保河源市艺术高级中学项目的土地房屋征收工作顺利推进，区人民政府决定成立河源市艺术高级中学项目土地房屋征收工作现场指挥部。其组成人员名单如下：

四、土地房屋征收和安置标准

（一）征地补偿标准按《河源市人民政府关于公布实施征收农用地区片综合地价的公告》（河府〔2021〕15号）执行；其他地上附着物和青苗等补偿标准按《河源市人民政府关于印发河源市市区征地补偿指导标准的通知》（河府〔2017〕61号）执行。

（二）房屋征收补偿及安置根据《国有土地上房屋征收与补偿条例》（国务院令第590号）等法律法规及市政府相关规范性文件执行。

（三）留用地安置按《广东省征收农村集体土地留用地管理办法（试行）》（粤府办〔2009〕41号）和《广东省人民政府办公厅关于加强征收农村集体土地留用地安置管理工作的意见》（粤府办〔2016〕30号）要求，原则上按实际征地红线面积的10%安排留用地，经被征地村集体表决同意选择折算货币补偿而放弃留用地安置，则采取折算货币方式补偿。

五、工作分工

（一）东埔街道办事处：作为项目征收实施主体，具体负责土地房屋征收工作。

（二）区府办公室：作为项目综合协调部门，具体统筹协调各项工作，汇总并报送征地拆迁工作情况，做好后勤保障等工作。

（三）区委政法委、区司法局、区信访局：负责防控项目实施过程中可能产生的风险，积极做好预防措施，协助做好纠纷调解，维护社会稳定。

（四）区教育局：协助项目业主单位市教育局，负责资金筹措，项目配套设施的实施建设，提供该项目用地报批和办证所需的有关批文和证明文件。

（五）区财政局：负责项目资金筹措拨付及监督资金使用工作。

（六）区农业农村局：负责协助项目实施范围内建（构）筑物类别界定。

（七）市自然资源局源城分局：负责代拟土地征收预公告和制订土地征收补偿方案；指导、协调土地征收工作。

（八）区房屋征收办：负责代拟房屋征收补偿方案，协助做好项目房屋征收的前期工作及房屋征收过程中的业务指导和监管。

六、工作经费

（一）土地房屋征收工作经费：按照土地房屋征收补偿总额的5%的标准计算（含土地房屋征收组工作人员的交通费、误餐费、外勤补助80元/人/天、法律服务等费用），由指挥部结合实际工作进度核拨给东埔街道办事处，由东埔街道办事处统筹使用，列入项目成本。

（二）清表清障费：按照实际工作量计算（地表清理经费按照土地征收面积6元/平方米计算，房屋拆除费按照15元/平方米计算），由指挥部核拨给实施单位，列入项目成本。

（三）土地监管经费：按照土地征收面积2元/平方米计算。

（四）征地服务费：按照土地征收面积1元/平方米计算。

七、资金管理

（一）项目征地拆迁补偿资金必须专款专用，东埔街道办事处设立专账，分阶段报项目分管领导审核。任何单位和个人不得截留、挤占、挪用，不得抵扣任何费用，确保补偿资金足额到位。

（二）项目征地拆迁补偿资金，由东埔街道办事处统计汇总报项目指挥部核实后，直接拨付至东埔街道办事处专用账户。

八、工作纪律

凡参加土地房屋征收的工作人员，要严格依法办事、清正廉洁，不得擅自改变补偿安置标准，乱开口子；更不得徇私舞弊，弄虚作假。不按规定办理的，予以严肃处理。
