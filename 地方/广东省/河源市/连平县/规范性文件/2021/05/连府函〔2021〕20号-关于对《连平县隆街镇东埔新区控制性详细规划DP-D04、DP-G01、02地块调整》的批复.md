# 关于对《连平县隆街镇东埔新区控制性详细规划DP-D04、DP-G01、02地块调整》的批复

县自然资源局：

你局《关于请求批准<连平县隆街镇东埔新区控制性详细规划DP-D04、DP-G01、02地块调整>的请示》收悉。根据县城乡规划委员会2021年第一次会议审议意见，经研究，现批复如下：

一、原则同意《连平县隆街镇东埔新区控制性详细规划DP-D04、DP-G01、02地块调整》。

二、规划调整范围位于隆街镇105国道南侧、连平河东侧，涉及用地面积30.36公顷。

三、请严格执行本次规划调整。按照相关法律法规要求，大力做好规划宣传工作，依法加强对地块内各项建设用地和建设活动的规划管理，不断提高规划、建设和管理水平，确保城镇建设健康有序发展。

此复。
