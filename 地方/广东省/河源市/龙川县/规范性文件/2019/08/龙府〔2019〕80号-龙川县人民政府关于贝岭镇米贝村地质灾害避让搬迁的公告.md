# 龙川县人民政府关于贝岭镇米贝村地质灾害避让搬迁的公告

受6月12日强降雨影响，龙川县贝岭镇米贝村发生山体多处大面积滑坡及崩塌等地质灾害，严重威胁了村民的生命财产安全。我县依据《地质灾害防治条例》（中华人民共和国国务院令第394号）等相关规定，聘请广东省地质灾害防治中心专家组对现场勘查和鉴定，并编制了《广东省龙川县贝岭镇米贝村滑坡群特大型地质灾害治理项目实施方案》（以下简称《方案》）。

根据《方案》，现将贝岭镇米贝村受地质灾害威胁应避让搬迁的房屋名单（详见附件）进行公告。
