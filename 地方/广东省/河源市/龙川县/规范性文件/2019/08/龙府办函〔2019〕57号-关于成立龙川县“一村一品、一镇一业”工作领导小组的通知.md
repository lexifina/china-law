# 关于成立龙川县“一村一品、一镇一业”工作领导小组的通知

各镇人民政府，县府直属有关单位：

为全面贯彻党的十九大精神和习近平总书记视察广东的重要讲话精神，落实省委省政府关于发展“一村一品、一镇一业”富民兴村产业的决策部署，根据《关于印发〈广东省农业农村厅“一村一品、一镇一业”建设工作方案〉的通知》（粤农农规〔2019〕2号）《广东省人民政府关于印发〈广东省涉农资金统筹整合实施方案（试行）的通知〉》（粤府〔2018〕123号）等文件要求，经县政府研究，决定成立龙川县“一村一品、一镇一业”工作领导小组。其组成人员名单如下：

组 长：廖小文 副县长

副组长：

丘福源 县政府办公室副主任

黄雪辉 县农业农村局局长

邹思伟 县财政局局长

魏建洪 县扶贫局局长

成 员：

叶俊明 县农业农村局副局长

廖 军 县财政局副局长

张均林 县扶贫局副局长

各镇分管农业农村工作领导

领导小组下设办公室，办公室设在县农业农村局，办公室主任由叶俊明同志兼任，成员由县农业农村局、财政局、扶贫局业务人员组成，负责“一村一品、一镇一业”申报项目初审、上报、公示等工作。

龙川县人民政府办公室
