# 关于印发2017年佛冈县禁养区限养区畜禽养殖清理整治工作方案的通知

各镇政府，各有关单位：

《2017年佛冈县禁养区限养区畜禽养殖清理整治工作方案》业经县政府同意，现印发给你们，请贯彻执行。执行中遇到的问题，请径向县农业局反映。

佛冈县人民政府办公室

2017年6月12日

2017年佛冈县禁养区限养区畜禽养殖清理整治工作方案

为深入解决我县畜禽养殖业环境污染问题，加强畜禽养殖业规范管理，切实维护人民群众的环境卫生权益，结合我县畜禽养殖业污染现状，特制订本工作方案。

一、指导思想

以党的十八大和十八届五中全会精神为指导，以保障环境安全和促进畜牧业持续健康发展为目标，坚持发展与治理并重、属地管理、依法行政、维护稳定的原则，综合运用鼓励引导、执法监督和资金补助等手段，采取关闭、搬迁等措施，开展禁养区、限养区畜禽养殖场的清理整治，规范畜禽养殖行为，有效降低畜禽规模养殖对环境的污染，为佛冈创建国家环保模范城市，全面建设美丽佛冈提供环境安全保障。

二、法律法规和政策依据

主要的依据是：《中华人民共和国环境保护法》、《中华人民共和国畜牧法》、《中华人民共和国水污染防治法》、《畜禽规模养殖污染防治条例》、《饮用水水源保护区污染防治管理规定》、《动物防疫条件审查办法》（农业部令2010年第7号）和《广东省人民政府关于印发广东省水污染防治行动计划实施方案的通知》（粤府〔2015〕131号）、广东省农业厅、广东省环保厅《关于印发广东省畜禽养殖水污染防治方案的通知》（粤农〔2016〕222号）、《清远市人民政府办公室关于印发清远市禁养区限养区畜禽养殖清理整治工作方案的通知》（清府办〔2016〕62号）和县政府《关于印发佛冈县水污染防治行动计划工作方案的通知》（佛府〔2016〕6号）、县政府办公室《关于印发佛冈县实行网格化环境监管体系实施方案的通知》(佛府办〔2016〕21号）、《关于印发佛冈县畜禽养殖业污染整治工作方案的通知》（佛府办〔2016〕30号）、《关于印发佛冈县畜禽养殖区域划分实施方案的通知》(佛府办〔2011〕46号）。

三、清理整治目标

根据《广东省人民政府关于印发广东省水污染防治行动计划实施方案的通知》（粤府〔2015〕131号）和广东省农业厅、广东省环保厅《关于印发广东省畜禽养殖水污染防治方案的通知》（粤农〔2016〕222号）、《清远市人民政府办公室关于印发清远市禁养区限养区畜禽养殖清理整治工作方案的通知》（清府办〔2016〕62号），今年6月30日前完成禁养区内的畜禽养殖场清理、限养区内的畜禽养殖场整治，9月30日前依法关闭、搬迁全县禁养区内畜禽养殖场,全面整治限养区内畜禽养殖场，限养区内畜禽养殖场要加强治理，完善污染处理设施，确保有效降低畜禽规模养殖对环境的污染，以促进我县畜牧业生产与生态环境保护协调发展，保护水资源，改善生态环境，保障人民群众身体健康。

四、工作任务

（一）明确清理整治范围

本次清理整治范围：一是禁养区、限养区内的畜禽养殖场（指常年存栏量为500头以上的猪、3万羽以上的鸡和100头以上的牛的畜禽养殖场），以及达到规定规模标准（参照上述标准）的其他类型的畜禽养殖场。二是《2017年清远市环境保护考核实施方案》中指定的畜禽养殖场关停或搬迁项目。

（二）全面清理禁养区内的畜禽养殖场

对在禁养区范围内和《2017年清远市环境保护考核实施方案》指定的关停或搬迁项目中自愿关闭或搬迁的畜禽养殖场，依法予以补偿。拆迁补贴原则和标准：对在6月30日前与所在镇政府签订《佛冈县畜禽养殖场自愿拆迁协议书》，并在2017年9月30日前按要求完成全部拆迁工作的畜禽养殖场，由县财政给予适当补贴。补贴范围为畜禽养殖栏舍，其他设施如仓库、宿舍、办公楼等不列入补贴范围；畜禽养殖栏舍计算面积以滴水线内为准。补贴标准为：在规定时间内，自行关停并自行拆迁的养殖场按畜场栏舍面积100元/ M2、禽场栏舍面积15元/ M2的标准予以补贴，拆迁费用由养殖户自理；自行关停但需要镇政府组织拆迁的养殖场，按畜场栏舍面积50元/M2、禽场栏舍面积10元/M2的标准予以补贴养殖户，同时由县财政对各镇政府按畜场栏舍面积30元/M2、禽场栏舍面积5元/M2的标准补贴拆迁费用。该补贴标准适用于按规定时间内自行拆迁的禁养区养殖场。

对违反规定，在禁止养殖区域内建设畜禽养殖场、养殖小区的，由县级以上地方人民政府环境保护主管部门责令停止违法行为；拒不停止违法行为的，处3万元以上10万元以下的罚款，并报县级以上人民政府责令拆除或者关闭。在饮用水水源保护区建设畜禽养殖场、养殖小区的，由县级以上地方人民政府环境保护主管部门责令停止违法行为，处10万元以上50万元以下的罚款，并报经有批准权的人民政府批准，责令拆除或者关闭。禁养区内的畜禽养殖场的清理在2017年6月30日前完成。

（三）限养区的畜禽养殖场进行分类整治

限养区内畜禽养殖场要完善污染防治设施，办理相关环保手续，并做好畜禽养殖登记备案，向环境排放经过处理的畜禽养殖废弃物，应当符合国家和地方规定的污染物排放标准和总量控制指标。畜禽养殖场污染防治设施要经过县环境保护主管部门验收合格，并向县环保部门办理排污申报登记，申报领取《排污许可证》。对违反规定，未建设污染防治配套设施或者自行建设的配套设施不合格，也未委托他人对畜禽养殖废弃物进行综合利用和无害化处理，畜禽养殖场、养殖小区即投入生产、使用，或者建设的污染防治配套设施未正常运行的，由县级以上人民政府环境保护主管部门责令停止生产或者使用，可以处10万元以下的罚款。限养区内的畜禽养殖场的整治要在2017年6月30日前全部完成。

五、保障措施

（一）加强领导，明确职责

1.成立机构。禁养区限养区畜禽养殖清理整治工作是一项时间紧、任务重、涉及面广的工作，为切实加强整治工作的领导，县人民政府成立由县长任组长，分管副县长任副组长，各相关部门组成的畜禽养殖业污染整治工作领导小组（成员名单见“佛府办函〔2016〕70号”）。

领导小组下设办公室，办公室设在县农业局，办公室人员从县农业局、县环保局、县财政局、县水务局、县国土资源局抽调。办公室主任由县农业局长兼任，副主任由县农业局、县环保局分管副局长兼任。各镇政府要成立相应工作机构，具体负责辖区内禁养区、限养区畜禽养殖清理整治工作。有关工作完成后，领导小组自行撤销。

2.工作职责。县整治工作领导小组办公室负责全县禁养区、限养区畜禽养殖清理整治的组织协调和日常监管工作。各镇政府、各部门必须以强烈的责任意识和大局意识，加强协调配合，形成合力，共同推进我县禁养区、限养区畜禽养殖清理整治工作的顺利开展。

（1）各镇人民政府。按照属地管理的原则，各镇人民政府是直接责任单位，政府主要领导是第一责任人，负责辖区内禁养区限养区畜禽养殖清理整治工作；要结合当地实际补充细化清理整治工作方案，明确工作步骤，落实工作人员、工作责任和工作措施，充分发挥村级的基层基础作用，切实把整治任务落实到基层；摸清辖区内畜禽养殖场及饲料店、兽药店、市场销售户情况；做好畜禽养殖场规范整治的宣传发动工作，动员、引导养殖场自觉配合规范整治行动；协助相关职能部门对不符合法律法规规定的畜禽养殖场送达法律文书；对违法建设依法组织实施强制拆除；负责清拆后原养殖场的复原、复耕、复绿。

（2）县委宣传部。负责整治行动的宣传报道，营造舆论氛围，引导养殖场户自觉配合整治行动。

（3）县公安局。负责配合各级政府和部门单位开展执法行动，依法打击暴力抗法行为，为整治清拆过程中执法监督工作提供安全保障。

（4）县财政局。负责保障落实补偿资金和整治工作经费，监督检查畜禽养殖场补偿资金和整治专项经费的落实和使用情况。

（5）县国土资源局。依法办理新、扩、改建畜禽养殖场土地使用手续，查处非法占用耕地开展养殖活动的行为。

（6）县环境保护局。一是会同县农业部门开展禁养区畜禽养殖场的清理整治工作的监督管理；二是指导各地开展限养区畜禽养殖场的环境影响评价的审批、排污申报登记工作，督促完成污染整治；三是依法查处禁养区和限养区内畜禽养殖场的违法行为，经查处后拒不停止违法行为的，报县级以上人民政府责令拆除或者关闭；四是对限养区内畜禽养殖场建设完善污染防治配套设施制定一个操作性强的指导意见；五是会同县农业局于2017年6月前提出对《关于印发佛冈县畜禽养殖区域划分实施方案的通知》的修订意见，经县政府批准后实施。

（7）县人社局。负责指导、监督被关闭养殖场与其从业人员解决好劳资关系，协调、指导有关人员转移就业。

（8）县住建局。会同县环保、农业等相关部门组织相关职能部门对城市规划区内违法搭建养殖场所的整治、清拆。

（9）县水务局。协助核定位于水源保护区的畜禽养殖场名单；会同县环保、农业等相关部门做好水库、江河堤内养殖场所的整治、清拆工作。

（10）县农业局。一是会同县环保部门对全县禁养区限养区畜禽养殖清理整治工作进行监督管理；二是依法规范畜禽养殖场生产行为；三是负责对限养内畜禽养殖场的污染治理和废弃物综合利用的指导和服务；四是负责本县辖区内畜禽养殖发展规划的制定；五是负责对禁养区、限养区畜禽养殖场搬迁转产的技术指导和服务。

（11）县林业局。会同县环保、农业等相关部门做好自然保护区、森林公园、林场内畜禽养殖场的整治、清拆工作。

（12）县市场监督管理局。会同县环保、农业等相关部门查处无照经营的畜禽养殖场，对被责令关闭的、转产非畜禽养殖产业的畜禽养殖场依法注销或变更营业执照。

（13）县司法局。指导相关职能部门和各镇政府的行政执法活动，对相关规范性文件进行合法性审查，依法受理行政复议申请，协助县政府有关部门依法做好诉讼等法律事务。

（14）县信访局。负责做好畜禽养殖场污染专项整治行动期间的信访工作。

（15）佛冈供电局。对到期限关闭、拆迁的畜禽养殖场，作停电处理。

（二）资金保障

为做好禁养区畜禽养殖场关闭、搬迁工作，补偿标准及禁养区、限养区内清理整治的畜禽养殖场名单在2017年6月15日前进行公示，补偿资金由县财政负担。整治工作经费原则上由县、镇财政各自负担，镇财政确有困难的，由县财政统筹协调。

（三）加强对禁养区、限养区的监控

县环境保护主管部门应当依据职责对禁养区、限养区畜禽养殖污染防治情况进行监督检查，并加强对畜禽养殖环境污染的监测。

六、工作步骤和要求

全县禁养区限养区畜禽养殖清理整治工作主要采取分步实施，稳步推进的办法进行，时间从2017年4月开始至2017年12月底完成。具体分为部署方案、宣传公示、清理整治、核查巩固四个阶段。

（一）部署方案阶段（2017年4月1日至5月25日）

开展禁养区限养区畜禽养殖场基本情况的前期摸查，印发《佛冈县禁养区限养区畜禽养殖清理整治工作方案》，统一部署整治工作。充分利用各种宣传媒介以及座谈动员、张贴标语、发布公告等形式，宣传农业、环保、国土、林业等相关的法律法规，深入细致做好养殖户的思想教育工作，争取养殖户的理解和支持，为开展整治营造浓厚舆论氛围。

（二）宣传公示阶段（2017年5月25日至6月15日）

根据县农业局4月份对全县规模畜禽养殖场基础信息的摸底情况，各镇政府要加大工作力度，对本辖区内禁养区限养区需清理整治的畜禽养殖场信息进行补充完善和确认核实，逐级汇总上报，由各镇禁养区限养区清理整治工作领导小组办公室最终确认禁养区限养区清理整治的畜禽养殖场名单，连同补偿标准在2017年6月15日前完成公示，并上报佛冈县畜禽养殖业污染整治工作领导小组办公室。

（三）清理整治阶段（2017年6月16日至2017年6月30日）

全县禁养区限养区清理整治的畜禽养殖场名单公示结束后，由县人民政府下达限期清理整治公告，全面开展清理整治。

（四）核查巩固阶段（2017年7月1日至11月30日）

认真核查、总结全县禁养区限养区畜禽养殖清理整治工作情况，各镇要对工作进行总结，总结材料以书面形式于11月30日前上报到县工作领导小组办公室，由领导小组办公室负责对禁养区限养区畜禽养殖清理整治工作完成情况进行监督检查。清理整治工作完成后，各镇政府、各有关部门每年要定期对整治区域“回头看”，加强对禁养区限养区畜禽养殖的日常巡查和监管，落实监管责任措施，确保禁养区畜禽养殖不出现“反弹”和“复养”现象，巩固清理整治工作成果。

（五）工作要求

各镇政府、各有关部门要统一认识，积极推进禁养区限养区畜禽养殖清理整治工作，把整治工作作为促进地区经济社会持续健康发展，保障饮用水水源安全、人居环境权益和社会稳定的高度来抓，确保整治行动落到实处、抓出成效。为及时了解和掌握各镇整治行动落实情况，县工作领导小组办公室将定期对各地整治行动开展情况进行跟踪督查。对整治工作不到位、措施不落实、拆迁面积弄虚作假、没有在指定时间内完成目标任务的镇给予通报批评并限期整改，严重的追究相关人员和领导责任。

各镇政府、部门要加强信息报送，各镇禁养区限养区清理整治工作领导小组及办公室联系人名单于2017年6月20前上报县工作领导小组办公室，从2017年6月起，各镇政府于每月30日前向县工作领导小组办公室报送《禁养区畜禽养殖场清理整治进度情况表》。
