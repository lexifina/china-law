# 佛冈县人民政府办公室关于印发2017年佛冈县食品安全重点工作安排的通知

各镇政府，县政府各部门、各直属机构：

经县人民政府同意，现将《2017年佛冈县食品安全重点工作安排》印发给你们，请认真抓好贯彻落实。执行过程中遇到的问题，请径向县食安办反映。

佛冈县人民政府办公室

2017年8月24日

2017年佛冈县食品安全重点工作安排

根据《国务院办公厅关于印发2017年食品安全重点工作安排的通知》（国办发〔2017〕28号）、《广东省人民政府办公厅关于印发2017年广东省食品安全重点工作安排的通知》（粤府办〔2017〕31号）和《清远市人民政府办公室关于印发2017年清远市食品安全重点工作安排的通知》（清府办〔2017〕46号），结合我县实际，现就2017年我县食品安全重点工作作出如下安排：

一、配合完善食品安全法规标准

推动完善食品安全工作制度，对加快小型食品经营单位、散装食品经营、食品安全管理员、食品从业人员健康检查、学校食堂和企业食堂食品安全等管理制度的制修订工作提出意见或建议。（县食药监局牵头，县教育局、人社局、法制局配合）

加强食品添加剂使用标准的宣传和指导，规范餐饮服务中使用食品添加剂的管理。尊重传统饮食文化习惯，收集整理报送按照传统既是食品又是中药材的品种的基础资料。（县卫计局、食药监局分工负责）

完善食品安全行政执法程序，加强行政处罚法律适用的指导。强化执法监督，开展执法检查，规范执法行为。（县农业局、食药监局、市场监管局、发改局分工负责）

积极配合食品安全地方标准的制定、修订与管理，结合本地实际提出制修订食品安全地方标准的建议和意见。开展食品安全标准宣传、培训，强化标准制定、执行和监管的衔接。（县农业局、卫计局牵头，县食药监局、市场监管局配合）

二、净化食用农产品生产环境

贯彻实施广东省大气、水、土壤污染防治行动计划实施方案，配合开展土壤污染状况详查，以农用地和重点行业企业用地为重点，完成表层样点、深层样点、农产品样点布设和样品采集、制备、流转工作。积极开展耕地质量保护与提升行动，推进农业面源污染防治攻坚行动。配合加大对土壤污染防治研究和技术研发平台的支持力度，加强科技支撑及成果转化。（县国土资源局、环保局、农业局牵头，县住建局、经信局配合）

落实国务院、省和市关于加强粮食重金属污染治理的各项措施，按时完成全县农用地土壤环境质量类别分类，划定粮食禁种区域，严格实施分类管理，严格管控重度污染耕地，处理好调整种植结构和保护农民利益的关系，严防重金属超标粮食流入口粮市场。（县国土资源局、环保局、农业局、食药监局、发改局会同各相关镇政府分工负责）

三、加强食用农产品源头治理

推进农业标准园创建工作，创建县级茶叶标准园1个，水果标准园3个。落实农药、兽药安全间隔期、休药期主体责任，推行规模化生产经营主体农业投入品使用记录制度。深入推进化肥、农药使用量零增长行动，实现2017年农药使用量不超过近3年平均数，主要农作物绿色防控技术覆盖率、农药利用率达到省、市的要求。实施农药经营许可、高毒农药定点经营、兽用处方药管理等制度，推进兽药产品“二维码”追溯管理。推行病虫害、动物疫病统防统治专业化服务，扶持培育经营性服务组织，积极发挥龙头企业、行业协会、合作社等经营性主体的作用，推动政府、企业共同做好动物疫病防治工作。（县农业局负责）

开展农药、禁用兽用抗菌药、生猪屠宰、“瘦肉精”、生鲜乳、农资打假、水产品质量安全专项整治工作，集中治理农兽药残留超标突出问题。（县农业局牵头，县市场监管局配合）

四、严格食品生产经营过程监管

实施食品生产经营风险分级分类管理，规范食品生产经营日常监督检查工作，推行抽检制度化、责任网格化。贯彻“双随机、一公开”原则，强化事中事后监管，加大日常检查、专项检查和飞行检查力度，曝光违法违规企业，倒逼生产经营者落实主体责任。（县食药监局、市场监管局分工负责）

加强食品生产加工小作坊管理，开展桶装饮用水生产行业专项整治，协助省、市有关部门推动大型食品和食品相关产品生产企业实施危害分析和关键控制点（HACCP）体系，督促企业建立食品安全追溯体系。开展创建“放心肉菜示范超市”活动，对5家农贸市场开展食用农产品快速检测，督促食用农产品市场落实食品安全管理责任。实施餐饮业质量安全提升工程，深入推进餐饮服务食品安全量化分级管理、餐饮单位“明厨亮灶”、食品安全示范创建工作，量化分级管理覆盖率、学校食堂“灭C”行动完成率分别达到90%、85%，“明厨亮灶”覆盖所有学校食堂、集体配餐单位、大型餐馆和大型企业食堂，积极创建省级食品安全示范街。加大网络订餐平台和入网经营者监管力度，入网餐饮服务经营者持证率、公示率均达到98%。（县食药监局负责）

开展打击保健食品非法会议营销专项治理。（县食药监局牵头，县公安局、卫计局、市场监管局配合）

加强食品相关产品生产企业监管，规范食品相关产品生产加工及标识标注行为。（县市场监管局负责）

加强“放心粮油”供应网络质量安全监管，全面推进“南粤粮安工程”建设。（县发改局负责）

深入开展农村食品安全治理，排查治理农村及城乡结合部地区突出食品安全风险隐患，强化建立长效监管机制。（县公安局、农业局、食药监局、市场监管局分工负责）

加大对校园及周边地区食品安全治理监管力度，开展学校集体食堂专项整治行动，落实学校食堂食品安全管理责任，严防发生群体性食物中毒事件和食源性疾病事件。（县委政法委、教育局、公安局、人社局、住建局、卫计局、食药监局分工负责）

加强食品摊贩管理，引导食品摊贩进入指定或临时划定区域经营。（各镇人民政府牵头，县住建局、食药监局配合）

五、严密防控食品安全风险隐患

按时完成横向到边、纵向到底的食品安全风险隐患排查工作，建立县、镇两级风险排查台账，实行包干制度，对排查出来的各种风险隐患立即整改。（县食安办负责）

落实省政府民生实事，实现2017年食品检验量达到1.5批次/千人。（县食药监局负责）

根据食品安全风险监测、监督抽检计划，制定并组织实施全县食品、食用农产品、食品相关产品质量安全风险监测、监督抽检方案，抽检不合格食品处理率达到100%。（县农业局、卫计局、食药监局、市场监管局和发改局分工负责）

完善食品安全风险研判机制，推进部门间、地区间风险监测、监督抽检、舆情监测信息共享，用好互联网、大数据，综合分析、评估可能存在的风险和隐患，研究提出防范举措。（县食安办牵头，县环保局、农业局、卫计局、食药监局、市场监管局、发改局配合）

建立风险预警交流机制，及时发布食品安全抽检信息、风险警示或消费提示。加强应急工作，完善重要信息直报制度和直报网络，加强食品安全舆情监测。（县农业局、食药监局、市场监管局、发改局分工负责）

开展供港冰鲜禽畜肉、水产品、蛋品、生鲜乳等重点产品风险监控，保障重大节假日供港澳食品稳定供应。（县农业局、食药监局分工负责）

推广食品安全责任保险制度，鼓励食品生产经营企业投保食品安全责任保险。（县食药监局、人保财险佛冈分公司分工负责）

六、大力促进食品产业转型升级

围绕市场需求调整食用农产品、水产品种植养殖结构，大力推进品牌建设，力争创建广东省名牌产品（农业类）、农产品区域公用品牌、农产品经营品牌以及无公害农产品、绿色食品、有机农产品和地理标志产品（三品一标）3个。（县农业局负责）

推进食品工业结构调整和转型升级，打造食品加工产业集群，引导食品加工企业向主产区、优势产区、产业园区集中，加大技术改造支持力度，促进食品工业增品种、提品质、创品牌。（县经信局、食药监局分工负责）

拓展农业产业链、价值链，推广“生产基地+餐饮门店”和“生产基地+加工企业+商超销售”等产销模式。（县农业局、食药监局分工负责）

加强餐厨废弃物、肉类加工废弃物和不合格畜禽产品的资源化利用和无害化处理，严防“地沟油”流向餐桌。（县发改局、环保局、住建局、农业局、食药监局分工负责）

稳步推进出口食品农产品企业内外销“同线同标同质”工程，发挥“三同”在农业供给侧改革中的作用。（县发改局、农业局、食药监局、市场监管局分工负责）

七、严厉打击食品安全违法犯罪

重拳整治非法添加、超范围超限量使用食品添加剂、违规使用农兽药等农业投入品、制假售假、私屠滥宰等违法行为，加大虚假违法保健食品广告查处力度，严厉打击涉及水产品、乳制品、肉制品、酒类、食用油等与群众日常生活息息相关的食品违法犯罪行为，特别是制售假盐、以工业盐冒充食用盐的违法犯罪行为。加大食品相关产品执法打假力度，加大重点敏感食品走私打击力度，加大食品掺假造假行为刑事责任追究力度。强化部门和区域间案件移送、督办查办、联合惩处等沟通协作，落实重大违法犯罪案件信息发布制度，控制产品风险和社会风险。（县公安局、农业局、食药监局、市场监管局、盐务分局分工负责）

加强食品安全行政执法和刑事司法的衔接（“两法衔接”），从严从重处罚食品安全违法犯罪行为，坚决遏制和打击违法犯罪行为。联合开展打击互联网食品安全、食盐违法犯罪专项行动。探索建立食品违法犯罪案件涉案产品认定专家库，规范食品安全违法犯罪案件取证、移送、入罪、检验结论出具、涉案产品处置等工作。（县委政法委，县公安局、农业局、食药监局、市场监管局、盐务分局分工负责）

八、强化食品安全监管能力建设

强化公安机关食品药品犯罪侦查力量，加强食品、食用农产品、食品相关产品、粮食质量安全监管能力和检验检测机构能力建设，将落实抽检、执法装备、信息化、检验检测机构建设等经费安排纳入年度食品安全考核指标，推动实现业务用房、执法车辆、执法装备配备标准化。（县公安局、财政局、农业局、食药监局、市场监管局、发改局，各镇政府分工负责）

建设职业化检查员队伍，推进检查员队伍专业化、专职化和高效化，实现检查工作常态化、法制化和体系化。（县人社局、食药监局分工负责）

完善食品、食用农产品质量安全追溯体系，加强婴幼儿配方乳粉、婴幼儿配方食品、食用油、酒类、盐等省重点监管食品电子追溯系统建设、应用。（县经信局、食药监局分工负责）

开展镇基层食安办、基层食品药品监管所（两基）规范化建设。（县食安办牵头，县食药监局、各镇政府具体负责）

九、全面落实食品安全责任制

贯彻实施《佛冈县年度食品安全工作考核评价办法》（试行），推动地方各级党委政府落实食品安全“党政同责”，保证监管工作有责任、有岗位、有人员、有手段，支持监管部门履行职责。发挥食品安全委员会统一领导、食安办综合协调作用，强化食品安全工作的统筹协调。(县食安办牵头，各镇政府具体负责)

组织对各镇政府的食品安全监督管理工作进行评议考核，强化评议考核结果运用，考核结果交由干部主管部门作为对各镇政府领导班子和领导干部进行综合考核评价与实行奖惩的重要参考。组织对县级食品安全相关部门的食品安全监管工作进行评议考核，督促监管部门落实食品安全监管责任。（县食安办牵头，县委组织部、县食品安全委员会相关成员单位具体负责）

建立食品安全责任约谈常态化机制，建立健全食品安全责任制和责任追究制度，按照干部管理权限依规依纪追究相关人员责任。（县监察局、食药监局分工负责）

十、深入推进食品安全社会共治

加强食品安全新闻宣传，做好舆论监督，营造良好的舆论环境。（县委宣传部负责）

举办“食品安全宣传周”活动，开展农产品质量检验检测实验室公众开放日活动，深入开展食品安全法律法规宣传。（县食安办牵头，县食品安全委员会相关成员单位分工负责）

强化食品、食用农产品、食品相关产品质量安全科普宣传，开展食品安全科普知识进基层宣传活动，举办食品安全科普展，提高公众食品安全科学素养。（县农业局、食药监局、市场监管局、科协分工负责）

采取多种形式，开展学生食品安全知识和食源性疾病预防常识教育。（县教育局、人社局牵头，县卫计局、食药监局配合）

贯彻实施食品企业诚信管理体系国家标准，开展食品企业诚信管理体系评价，建立健全食品、食用农产品、食品相关产品质量安全信用档案并依法及时向社会公布，对食品生产经营严重失信者开展联合惩戒。（县发改局、经信局、农业局、食药监局、市场监管局分工负责）

加强投诉举报体系能力建设，畅通投诉举报渠道。（县农业局、食药监局、市场监管局分工负责）
