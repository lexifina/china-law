# 关于废止《佛冈县公开摇珠选定佛冈县水务工程施工招标代理机构办法》的通知

各镇政府，县直副科以上单位和省市直管单位：

为维护法制统一，保证政令畅通，根据《水利部关于促进市场公平竞争维护水利建设市场正常秩序的实施意见》（水建管〔2017〕123号）文件精神，经2017年9月8日县政府第十五届17次常务会议研究决定，自本通知下发之日起，废止《印发<佛冈县公开摇珠选定佛冈县水务工程施工招标代理机构办法>的通知》（佛府办〔2016〕25号）。

佛冈县人民政府办公室

2017年9月14日
