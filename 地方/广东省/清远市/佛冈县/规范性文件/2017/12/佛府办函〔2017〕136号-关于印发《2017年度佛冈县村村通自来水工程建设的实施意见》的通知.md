# 关于印发《2017年度佛冈县村村通自来水工程建设的实施意见》的通知

各镇人民政府，县直各单位：

《2017年度佛冈县村村通自来水工程建设的实施意见》已经县人民政府同意，现印发给你们，请遵照执行。执行过程中遇到的问题，请径向县水务局反映。

佛冈县人民政府办公室

2017年12月8日

2017年度佛冈县村村通自来水工程建设的

实施意见

根据《广东省水利厅关于印发<广东省村村通自来水工程建设管理工作指引>的通知》（粤水农水〔2016〕15号）和《佛冈县人民政府办公室印发<佛冈县村村通自来水工程建设方案》（佛府办〔2016〕6号）和县长办公会议纪要〔2017〕10号精神，结合我县的2017年村村通自来水工程建设项目年度计划和各乡镇实际，制定本实施意见。

一、指导思想和总体目标

以改善农村生活饮用水条件、提高供水质量，使老百姓喝上合格自来水为目标，通过完善和提升农村饮水安全工程设施的功能及水平，到2018年底基本形成覆盖全县农村的供水安全保障体系，实现行政村村村通自来水覆盖率90%、农村生活饮用水水质合格率达到90%，农村自来水普及率达到90%以上的目标。

二、实施原则

结合水利部“十三五”农村供水“提质增效升级”建设内容，通过对已建工程进行配套、改造、升级、联网，以及水源保护、水质保障、健全完善工程良性运行体制机制和适当新建部分供水工程等，进一步提高农村集中供水率、自来水普及率、水质达标率和供水保证率。

三、实施方式

（一）建设范围。

建设范围为佛冈县2017年村村通自来水工程建设项目，涉及全县6个镇（乡），27宗项目。主要采用集中式供水方式，通过现有县、镇自来水厂扩网、新建或扩建改造镇级水厂、新建或扩建改造大型村级水厂，解决较为集中的农村人口饮水问题。其余有条件建设的村采用小型集中式或分散式供水解决饮水问题。

（二）实施主体。

各镇的镇级水厂和大型村级水厂(联行政村供水)、单村供水和分散式供水由各镇组建项目法人负责实施。受益的镇、村负责民事协调，县水务部门负责技术指导；县人民政府与各责任镇人民政府签订责任书，确保按计划全面完成建设任务。

项目以“谁积极完成，谁优先奖补”为原则安排实施：即受益村群众积极性高、主动性强的村庄优先实施；项目涉及占地、青苗、水源等民事问题能自行协调解决的村庄优先实施；项目用地平整、施工便道铺设、管沟开挖回填等投工投劳工作完成的村庄优先实施；项目入户管网建设等自筹资金部分，积极主动筹集解决的村庄优先实施。

（三）实施方式。

为加快工程建设，加强建后管理，村村通自来水工程按照“责任清晰、广泛参与、以奖代补、建管合一”的方式实施。

1.各个项目必须明确管理责任主体，建立有效建管机制，确保自来水有偿使用且科学管护。

2.各镇人民政府和各个项目责任主体通过多渠道筹资、发动群众投工投劳等方式完成项目的用地征用、用地平整、施工便道铺设、管沟开挖回填等工作，该部分投入可以作为镇和群众自筹。

3.对施工单项合同预算投资小于100万元的工程项目，由建设单位通过择优选择具备水利施工资质的施工单位、监理单位、质量检测单位实施建设，与施工单位签订《工程施工合同》、《工程安全生产责任书》，严格按照施工图设计方案施工，严格执行项目法人制、建设监理制、合同管理制等有关制度。根据《水利工程质量监督管理规定》水利工程质量监督机构对水利工程质量进行强制性的监督管理。所以，工程项目开工前，必须办理好质量监督手续，否则不得开工。

对施工单项合同预算投资超过100万元（含）的工程项目，必须严格执行水利工程建设相关程序，严格执行项目法人制、招标投标制、建设监理制、合同管理制等有关制度。根据《水利工程质量监督管理规定》水利工程质量监督机构对水利工程质量进行强制性的监督管理。所以，工程项目开工前，必须办理好质量监督手续，否则不得开工。

四、补助范围

佛冈县2017年村村通自来水工程27宗建设项目。

五、补助标准和方式

按照县长办公会议纪要〔2017〕10号精神落实。

六、工程验收

工程按照设计要求建设完成并达到省级村村通自来水标准的项目，且村入户率达到90%以上（含90%）的，由所在镇人民政府组织参建单位进行初步验收，建设单位向县财政局申请进行结算审核。审核后的结算价作为申请奖补资金的依据，完成初步验收的视为申请奖补资金的时间节点。对符合竣工验收条件的项目，由县水务局组织县发改局、县财政局、卫计局等和项目所在镇人民政府、受益村委会、参建各方共同验收。其中，达到招标要求的项目严格按照省村村通自来水工程相关验收办法和规定进行验收；未达到招标要求的项目参照省村村通自来水工程相关验收办法和规定进行验收。

七、建立保障、监管制度

（一）保障制度。

为加强工程建设领导，县成立2017年佛冈县村村通自来水工程建设领导小组，各镇及有关部门应各司其职，加强协调，密切配合，完善协作机制，确保工程建设顺利进行。各镇也要建立工作协调机制，逐级落实目标责任制，明确部门职责。

县村村通自来水工程建设领导小组成员单位具体分工如下：

县委宣传部：负责协调实施工程建设的有关宣传工作。

各镇人民政府：负责各落实自筹资金,协助开展辖区村村通自来水工程项目建设和民事协调工作，组建项目法人实施辖区单村、联村供水和分散式供水项目建设任务。

县发改局：负责项目立项、核准招标方案，协调工程的用电价格管理，按分管权限核定工程的供水价格及监管工作。

县水务局：负责编制工程规划、审查项目设计报告，审批初步设计报告，提出项目建议计划，负责项目技术指导，会同发改、财政、卫计等有关部门对工程进行检查验收，负责工程建后服务体系的建设、监督管理工作，负责水土保持工作。

县财政局：负责财政性资金的筹集、拨付及监管。

县卫计局：负责农村饮水安全水质监测网络建设，农村饮水工程水质监测，项目水质改善技术指导和监督，工程建设项目卫生安全评价和预防性卫生监督。

县国土资源局：负责项目征地的土地预审和评价。

县交运局：负责供水管道和设施在公路、水路横跨和布置的协调监督工作。

县林业局：负责指导林地使用，水源地生态涵养林保护、生态修复等森林资源保护。

县农业局：要加强农业面源污染防治的监督管理工作，切实保护好饮用水源，防止对饮用水源的污染。

县审计局：负责项目财政性资金的审计监督。

县环保局：负责审批项目的环境影响评价，会同水务部门负责工程水源地保护范围的划定，并负责水源地水质保护的监督管理工作。

佛冈供电局：要切实保证工程的用电需求。

（二）监管制度。

一是实行工程建设情况公示制，镇和村要将筹资筹劳的数量、项目资金（实物）的安排使用等情况进行公示，提高工程实施的透明度和有效性；二是镇要建立档案管理制度，包括工程建设的项目申报表、筹资筹劳方案、项目奖补资料、竣工验收报告等相关原始材料；三是建立监督检查制度，县领导小组定期组织对建设奖补项目及资金的合规性、真实性和有效性进行监督检查，对违规操作、截留挪用、骗取村民筹资和奖补资金的行为，要责令纠正，追回资金，并按规定追究相关当事人的责任。

七、考核制度。

我县村村通自来水工程任务由各责任单位具体负责实施，县水务局督办，并将村村通自来水工程建设绩效考核（村村通自来水普及率）指标纳入地方党政领导班子和领导干部综合考核评价内容，没有按规定完成建设任务的按照县长办公会议纪要〔2017〕10号精神落实，建设项目不安排奖补，同时启动问责机制。
