# 关于调整佛冈县学校安全工作领导小组成员的通知

各镇政府，各有关单位：

根据人员变动和工作需要，经县政府研究，决定调整佛冈县学校安全工作领导小组成员。调整后的成员名单如下：

组 长：朱小松 副县长

副组长：曾锦常 县府办副主任

丘韶文 县教育局局长

成 员：冯灼锋 县应急管理局

黄敏韶 县政法委

温明源 县教育局

欧阳汉彬 县公安局

黄华胜 县交运局

何国飞 县水利局

郑启创 县文广旅体局

邝国其 县卫生健康局

欧 军 团县委

领导小组下设办公室，办公室设在县教育局，负责学校安全日常管理工作，办公室主任由温明源同志兼任。
