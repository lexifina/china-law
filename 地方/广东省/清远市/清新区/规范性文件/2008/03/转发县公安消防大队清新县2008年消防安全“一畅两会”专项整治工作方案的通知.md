# 转发县公安消防大队清新县2008年消防安全“一畅两会”专项整治工作方案的通知

各镇人民政府、笔架林场，县政府各部门、各直属机构：

县公安消防大队《清新县2008年消防安全“一畅两会”专项整治工作方案》业经县政府同意，现转发给你们，请认真贯彻执行。执行中遇到的问题，请径向县公安消防大队反映。

二○○八年三月三十一日

清新县2008年消防安全“一畅两会”

专项整治工作方案

清新县公安消防大队

为确保我县在2008年底前完成以整治“三小场所”（小商铺、小作坊、小娱乐场所）和小旅馆、出租屋等存在的“三合一”（住宿、生产、储存经营合用）火灾隐患为重点的消防安全“一畅两会”（畅通消防安全疏散通道和安全出口、会扑救初起火灾、会逃生自救）专项整治工作，预防较大以上火灾事故发生，确保人民生命财产安全，根据全省第六次消防安全责任人会议精神和《印发清远市消防安全“一畅两会”专项整治工作方案和清远市消防安全“一畅两会”专项整治工作指引的通知》（清公消字〔2008〕2号）要求，结合我县实际，制定本方案。

一、整治范围

建筑面积小于200m2的商铺（小商铺）；高度不超过20米、层数不超过6层且单层建筑面积不超过400m2的可燃材料（丙类）加工场所（小作坊）；建筑面积小于200m2的具有娱乐游艺功能的西餐厅、酒吧、网吧等公共娱乐场所（小娱乐场所）；未经消防部门审核、验收的旅馆（小旅馆）；高度不超过24米、层数不超过7层且单层建筑面积不超过500m2的仅供租住的独立房屋（出租屋）。

对于不在上述范围的其他商店、工厂、娱乐场所、旅馆均严格按现行法律法规及国家有关消防技术规范执行。高度超过24米（7层），最大层建筑面积超过500m2出租给人员居住的房屋，应按照旅馆消防技术标准执行，并应取得建筑工程规划许可证、房屋产权证和消防部门行政许可。

二、整治标准

按照清公消字〔2008〕2号规定标准执行。

三、整治原则

（一）属地管理原则。对“三小场所”、小旅馆和出租屋安全隐患的整治实行属地管理，各镇党政一把手为第一责任人。

（二）重点整治原则。各镇、各有关部门要重点督促整改“三小场所”、出租屋和小旅馆“三合一”、“多合一”消防安全隐患，对拒不整改的依法予以查封、取缔、停租，并报县“一畅两会”专项整治工作领导小组办公室予以处罚。

（三）标本兼治原则。坚持查处违法行为和技术改造相结合，消除“三小场所”、出租屋和小旅馆消防安全隐患，建立健全长效管理机制，防止出现反弹。

四、组织领导

（一）组织机构。成立清新县消防安全“一畅两会”专项整治工作领导小组，李向武常务副县长任组长，县公安、环保建设、安全监管、经贸、财政、工商等单位负责人为成员。领导小组下设办公室（设在县公安消防大队），负责日常工作。各镇（场）要相应成立专项整治工作小组，人员从派出所、经济办、安全监管站、工商所等部门抽调组成。

（二）职责分工。

1．县专项整治工作领导小组办公室：负责组织、指导、督促各镇和有关单位开展“三小场所”、出租屋和小旅馆消防隐患专项整治工作；协调有关部门在整治工作中遇到的问题；对全县专项整治工作进行不定期督查，定期召开工作进度通报会，编制工作简报。

2．县公安局：负责处置可能由专项整治工作引发的群体性事件。

3．县公安消防大队：负责组织起草“一畅两会”专项整治工作有关文件；参照清公消字〔2008〕2号要求编印《清新县消防安全“一畅两会”专项整治工作指引》并负责有关治理标准的解释；对“三小场所”、出租屋和小旅馆消防安全技术改造工作提供指导；对拒不执行整改的消防违法行为依法予以处罚。

4．县工商局：负责协助县专项整治工作领导小组办公室依法查处取缔无证照经营行为。

5．县财政局:负责审核、安排专项整治有关费用。

6．县安全监管局：负责对不具备安全生产条件的“三小场所”依法进行查处。

7．县环保建设局：负责对不符合安全条件的液化气经营点和不符合规划要求的建筑物进行查处。

8．县经贸局：负责督促规模以上企业开展自查自纠行动。

9．各镇专项整治工作小组：在县整治办的领导下，开展隐患整治工作的调查摸底，建立档案；按照治理标准开展整治工作并督促无证照经营户办理有关证照。

五、整治步骤

（一）宣传发动、调查摸底及自查自改阶段（2008年3月20日－6月30日）。

1．召开动员大会，明确工作职责和任务。2008年3月中下旬召开县“一畅两会”专项整治工作现场会，学习清远市试点工作经验，对我县“一畅两会”专项整治工作作出具体部署和提出要求，下发专项整治方案和治理标准，层层签订整治工作责任书，确保整治责任落实。

2. 培训各镇专项整治工作小组人员。在2008年4月底前，由县专项整治工作领导小组办公室组织一期专项整治执法培训班，使各镇整治工作小组人员了解治理范围、标准、步骤，熟悉相关法律法规。

3. 全面调查摸底。各镇专项整治工作小组自行开展或委托社会中介机构开展对辖区所有列入整治范围的场所进行摸底调查。并向经营单位、业主（业主不在的，由所在村(居)委会代理)发出《清远市“三小”场所出租屋、小旅馆普查告知登记表》，填写《清远市“三小”场所、出租屋、小旅馆消防安全隐患专项整治检查记录表》，动员各场所对照治理标准开展自查和消除隐患工作。以镇为单位，对摸底调查结果进行分类别统一建立档案，于2008年7月1日前汇总并填写《镇（街）“三小场所”、出租屋和小旅馆调查统计表》报县专项整治工作领导小组办公室。

4. 自查自改隐患。各“三小场所”、小旅馆和出租屋的所有人及使用人在期限内按照整治标准组织自查自改。对查出的安全隐患立即整改；无法在要求期限内整改完毕的，必须先停产停业、停租、停止使用，并采取可靠的措施，确保安全，待整改完毕后方可投入使用。

（二）督查整治阶段( 2008年7月1日－11月30日)。各镇专项整治工作小组根据前期调查摸底数据，对治理场所按照治理标准进行地毯式检查，对未按要求自查自改的或整改不符合要求的，一律依法查封、取缔、停止出租，并上报县专项整治工作领导小组办公室对有关责任人员予以处罚。对拒不接受检查、拒不执行处罚决定的依法从严处理，构成犯罪的，依法追究刑事责任。各镇和县公安局要做好查封、取缔、停止出租后有关人员的安置工作，防止群体性事件的发生。

（三）检查验收阶段(2008年12月1日－12月31日)。县专项整治工作领导小组就安全隐患整改情况，以及当地政府和有关部门履行职责等情况写出专题报告，于2008年12月15日前报市专项整治工作领导小组办公室，接受市专项整治工作领导小组的考核检查，并将结果向社会公布。

六、工作要求

（一）加强领导。消防安全“一畅两会”专项整治工作涉及面广，政策性强，复杂程度高，事关社会治安和稳定。各镇、各有关部门要从构建“和谐清新”的高度，切实加强领导，把这项工作列入各级党委、政府的重要议事日程，党政领导一把手要负总责亲自抓，分管领导要具体抓，精心组织，统筹安排。要根据本方案，制订切实可行的实施工作方案，广泛发动，有计划、有步骤地开展各项工作。

（二）明确职责。各镇要层层落实责任，有关部门要明确职责分工，做到各司其职，各负其责。各镇、各有关部门要下大力气，在人力、财力、物力上全力支持，划拨专项经费，确保整治工作顺利进行。要落实保障措施，积极化解各种矛盾，做好突发事件应急工作，维护社会稳定。凡在专项整治工作中不履行管理职责，或瞒报、漏报、徇私包庇的，由纪检部门依法查处。情节恶劣构成犯罪的，依法追究刑事责任。

（三）加强宣传。县宣传、新闻部门要密切配合，采取多种形式做好专项整治的有关宣传报道工作。各镇要充分利用政务公开栏、村务公开栏、宣传栏、标语等形式对专项整治的范围、内容、要求和自查自改时限进行公告，使整治工作人人皆知，共同参与。

（四）突出重点。在开展“三小场所”、小旅馆和出租屋专项整治工作的同时，要加强对易燃易爆场所、劳动密集型生产企业、人员密集场所，特别是公共娱乐场所、商场、市场、宾馆、酒店、寄宿学校、幼儿园等场所的安全监管。通过“一畅两会”行动的深入进行，促进消防安全防范新技术的推广应用和消防宣传工作的持续开展，促进我县消防安全环境的改善。

（五）建立量化考评体系。各镇专项整治工作实行量化考核制度、督查制度和一票否决制度，县专项整治工作领导小组办公室定期对镇“一畅两会”专项整治工作进展情况进行抽查，并按有关考评办法开展考评。考评不合格的，则该镇的维稳综治及安全生产年度考评不合格。工作不力并造成严重后果的，由县纪检监察部门追究主要领导人责任。

（六）建立联席会议制度。建立由县专项整治工作领导小组成员及各镇工作小组负责人参加的联席会议制度。专项整治期间每月召开一次联席会议，也可根据实际需要不定期召开。会议主要研究部署“一畅两会”专项整治的具体工作，协调解决整治工作中出现的具体问题，及时通报相关工作进展情况。
