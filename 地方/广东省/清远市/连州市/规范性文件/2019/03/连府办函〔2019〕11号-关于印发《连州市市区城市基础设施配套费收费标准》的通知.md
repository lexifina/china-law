# 关于印发《连州市市区城市基础设施配套费收费标准》的通知

连府办函〔2019〕11号

各镇(乡)人民政府，市各有关单位：

《连州市市区城市基础设施配套费收费标准》业经市十五届人民政府第33次常务会议审议通过，现印发给你们，请认真贯彻执行。执行过程中遇到的问题，请径向市住房和城乡规划建设局反映。

附件：连州市市区城市基础设施配套费收费标准调整草案.et
