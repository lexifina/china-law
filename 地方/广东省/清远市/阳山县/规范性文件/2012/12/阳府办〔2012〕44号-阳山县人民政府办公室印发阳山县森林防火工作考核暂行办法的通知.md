# 阳山县人民政府办公室印发阳山县森林防火工作考核暂行办法的通知

各乡镇人民政府，县直有关单位：

《阳山县森林防火目标责任制考核办法（暂行）》已经

2012年

11月

15日

阳山县人民政府第十五届12次常务会议通过，现印发给你们，请按照执行。执行中遇到的问题，请径向县森林防火指挥部反映。

阳山县人民政府办公室

2012

年12月3日

阳山县森林防火工作考核办法

（暂行）

为进一步健全和完善我县森林防火目标责任制考核机制，根据国务院《森林防火条例》和清远市人民政府办公室《印发2012年清远市森林防火工作考核办法的通知》（清府办〔2012〕82号），结合我县实际，制定本办法。

一、考核机构及考核方式

成立以县森林防火指挥部常务副总指挥为组长，指挥部成员参加的森林防火工作考核小组，由该小组负责对乡镇森林防火工作进行年终考核，并由县防火办公室将考核情况报送县委、县人大、县政府、县政协、县纪委和县委组织部备案。森林防火期间，县森林防火指挥部不定期组织督查组对各乡镇的森林防火工作落实的情况进行检查，检查情况将作为森林防火工作年终考核的参考依据。

二、考核内容

（一）责任制建设（10分）。

1．纳入政府年度工作目标责任制考核体系。乡镇要对村（社区）委进行森林防火考核，森林防火工作考核不合格的，在全面工作考核时，降低一个等次，得4分。

2．建立森林防火责任制。乡镇、村（社区）委、村小组、村民、租山造林业主等森林、林木、林地经营单位和个人层层签订森林防火责任书，制定奖罚措施，明确责任，建立和完善档案资料的；乡镇与本辖区中小学校、学校与班主任全部签订森林防火宣传教育责任书，明确森林防火宣传教育和防范责任，建立和完善档案资料的，得3分。

3．划定森林防火责任区。乡镇、村（社区）委、村小组、租山造林业主划定森林防火责任区，明确森林防火责任人，落实森林防火责任，得3分。

（二）机构与队伍建设（15分）。

1．健全森林防火指挥机构。乡镇健全森林防火指挥部机构，配备办公设备，健全森林防火办公室和林业站负责承担森林防火日常工作，安排专职人员负责处理日常工作，建立和完善各项规章制度、档案资料，各项规章制度在办公室上墙悬挂的，得5分。

2．乡镇组建一支20人以上的扑火应急分队, 队员由乡镇干部职工组成,负责扑火组织协调、运输接送、后勤保障和清理看守火场。乡镇建立20人（非镇村干部）以上“平时补贴、有偿扑火”的半专业扑火队伍，配备无线通信工具、阻燃服、二号工具、风力灭火机（每5人2台）等扑火机具。同时，乡镇建立护林消防中队（又称镇级专业扑火队伍），按每5000～10000亩1人的标准配备护林消防人员，并由县、乡镇颁发任命书，其中镇级5～10人，其余护林人员纳入村（社区）委管理，制定管理措施，按划定的责任区，承担其责任区内火源管理、隐患排除和扑救森林火灾工作，得5分

3．乡镇组织村（社区）委、村小组、村民、租山造林业主等森林、林木、林地经营单位和个人建立森林防火村民自治组织和成立经营者护林防火协会，制定和通过森林防火村规民约和管理章程。有森林防火任务的村（社区）委要组建一支20人以上“不发工资、有偿扑火”的森林火灾群众扑救队伍，每人配有二号扑火工具。村（社区）委森林防火各项规章制度要规范上墙，得5分。

（三）森林防火经费（10分）。

1．乡镇按每年每亩林地面积0.5元以上的标准将森林防火经费纳入同级财政预算（林业专项经费除外）。经费投入要有本级财政预算报告，得5分。

2．村（社区）委、村小组、村民、租山造林业主等森林、林木、林地经营单位和个人按照森林防火村规民约或护林防火协会章程，每年按每亩林地面积1.0元的标准筹集森林防火经费，用于聘请护林人员、开展火源管理和采取相应的应急准备措施，得5分。

（四）预防措施（20分）。

1．森林防火宣传教育。设置火源管理警示标志，运用各种宣传媒体，春冬两季各开展一次宣传日活动，采用张贴标语、悬挂横额，乡镇配备一台宣传车流动宣传。同时，积极在中小学校开展“上一堂课、出一期刊、刷一条标语、写一篇作文、致一封家信”等森林防火宣传教育活动，宣传率达到100％的，得3分。

2．非生产性用火管控。森林特别防火期，乡镇严格管控在森林防火区内烧田基草、烧灰积肥、烧炭、烧黄蜂、焗蛇鼠、烧火取暖、烧烤食物、吸烟、燃放“孔明灯”和烧香烛纸钱、燃放鞭炮等用火行为，得3分。

3．生产用火规范管理。乡镇制定科学的、符合当地实际的农事用火、林事用火、进山作业用火等野外生产用火审批制度，规范审批程序。建立生产用火服务机制，设立乡镇“生产用火

119”

服务电话，“一站式”办理用火审批手续。同时，严格遵守和执行野外用火审批制度，对农事用火实行 “三集中”用火规定，有制定计划烧除措施的；对林事用火和进山作业用火实行凭许可证作业，并签订安全用火责任书的；对辖区内凡经批准的农事、林事和进山作业用火落实防范措施，并组织乡镇扑火队协助和进行监烧，且有记录的，得3分。

4．火灾隐患排查整改。乡镇建立森林火灾隐患排查整改机制，森林防火指挥机构经常性开展森林防火“安全大检查、隐患大排除、问题大整改”专项行动。对在森林防火区内排查出的突出问题，列出清单，指定专人负责，责令限期整改，消除隐患。逾期不消除火灾隐患的，由乡镇以上林业主管部门责令改正，并给予处罚，得3分。

5．重点区域防护监控。乡镇建立健全森林高火险区、自然保护区、森林公园、风景名胜区、林区易燃易爆站库、林区重要设施等重要区域的入山管理制度，完善火源封控措施，设立森林防火检查站或哨卡，不准携带火种进山；重点节日和森林高火险期，全面组织火源管理力量对重点保护区域进行防护布控，严防死守，确保森林防火安全，得3分。

6．特殊人群监护管理。乡镇、村（社区）委对痴、呆、傻、疯等精神智障人员进行造册登记，重点监控，明确监护人，落实监护责任和措施；对老人、儿童、中小学生加强防火教育；对流浪人员及时转移，得2分。

7．依法管火治火。加强乡镇林业工作人员的执法培训，将森林防火行政处罚权委托给乡镇的林业管理机构，提高乡镇林业管理机构依法管火治火的能力，促进乡镇做好火灾隐患的排查整改、及时查处违规用火行为和配合森林公安机关侦破森林火灾案件，得3分。

（五）扑救措施（15分）。

1．乡镇制定森林火灾应急处置办法，村（社区）制定协助做好处置森林火灾应急措施。镇、村、组及护林员要建立火情报告网络，做到火情早发现、早报告、早处置，得2分。

2．防火期内，乡镇、村（社区）委会两级落实每天24小时人员值班及领导带班制度，完善值班记录，做好火情信息反馈，做到不迟报、少报、瞒报火情。接到卫星测报热点、火警电话能及时处置，并在2小时内将核查准确的火情信息反馈到县防火办。同时，乡镇森林防火工作机构与森林公安机关建立互通反馈火情信息平台，及时互通反馈火情信息，配合森林公安机关开展侦破工作，得2分。

3．乡镇扑火队积极应用“风力灭火机”等威力较大的扑火机具，风力灭火机按5人一个战斗实体编组，并加强培训演练。发生山火，能及时报告，乡镇迅速启动森林火灾应急处置办法，乡镇领导第一时间赶到现场靠前指挥，将山火消灭在初发小火阶段，得2分。

4．乡镇对风力较大、山高坡陡和强度较大的山火，及时向县森林防火指挥部办公室报告，并将火灾消灭在翌日上午8时时段，做到当日扑灭，得2分。

5．资金保障。县森林防火指挥部启动应急预案Ⅲ级响应和Ⅳ级响应调动县森林消防大队和其他扑火队支援的，所需费用由发生火灾的乡镇政府负责，扑火补助标准按《阳山县处置森林火灾应急预案》（阳府办［2010］36号）规定执行，补助标准：每人10元∕小时，运输车按500元∕辆，伙食按30元∕人，扑火物资消耗按实际计算，扑救森林火灾的运输、后勤供给、扑火物资和扑火队伍补助等资金落实的，得5分。

6．对行政区域边界上的山火，不互相推诿，除确保山火不烧入本行政区域内，且联动联救；烧越行政区域界又无法查明起火点的山火，山火宗数各记1宗，烧山面积按属地进行统计，占2分。

（六）发生率（10分）。

1．热点发生率≤1宗/10万亩，得5分；每超过控制宗数1宗，扣0.2分。林火热点包括违规用火和山火，按省林火卫星测报和群众报告的火情进行统计。报县防火办备案并于当天18时至翌日上午9时作业的林事用火热点（三级以下火险等级天气除外）和申请县防火办现场核实为非林火热点的不作统计，得5分。

2．山火发生率≤1宗/30万亩，得5分；每超过控制宗数1宗，扣0.2分。

（七）受害率（10分）。

1．过火面积受害率≤2‰的，得5分；每超过控制率一个0.2‰点，扣1分。

2．森林面积受害率≤1‰的，得5分；每超过控制率一个0.1‰点，扣1分。

（八）查处率（10分）。

1．违规用火查处率80%以上的，得5分；每降低一个5%点，扣1分。违规用火查处要求查明火因、当事人、作出立案、处罚和结案，并做好建档工作。

2．森林火灾查处率80%以上的，得5分；每降低一个10%点，扣1分。森林火灾案件查处要求查明火因、当事人、作出立案、处罚和结案，并做好建档工作。

（九）倒扣分项目。

（一）森林防火期，乡镇没有落实24小时人员值班及领导带班制度的，每次扣2分（以县防火办抽查值班为准）。

（二）发生森林火灾倒扣分标准。

1．发生森林火灾时，乡镇领导在接到报告后1小时内没有到达火灾现场指挥安全扑救的，每次扣5分。

2．发生森林火灾时，乡镇后勤保障和扑火补助得不到落实的，每次扣5分。

3．每发生1宗到翌日上午8时没扑火明火（含翻火复燃时间，下同）的山火，扣1分，每延长2小时加扣1分。每发生1宗到第二天中午12时没扑灭明火的山火，扣5分，每延长2个小时加扣1分。每发生1宗超过48小时没扑灭明火的山火，扣20分，每延长2个小时加扣1分。发生1宗超过72小时没扑灭明火的山火，考核为不合格。

4．乡镇交界地方发生森林火灾，起火点核查不清的，相关乡镇各记1宗火灾，按乡镇现有界线划分实际过火面积，扣分办法同上。

5．乡镇发生下列情况之一的，每项每宗扣1分：迟报、瞒报、谎报热点与山火性质的；迟报、瞒报、谎报林火热点与山火查处情况的；推诿行政区域边界山火的。

6．森林防火、扑火工作被省、市、县督办和整改的单位，年底经省或市检查验收达不到整改方案标准的，扣10分。

（十）加分项目。

1．年终被市考核组抽中代表县森林防火工作考评的乡镇，按照市森林防火工作考评我县的等次分别进行加分：经市考核组考评我县为“优秀”等次的，加10分；考评为“良好”等次的，加5分。

2． 被省、市森林防火检查组抽检的乡镇并得到省、市通报表扬的，加5分。

3．乡镇扑火队伍被县防火指挥部抽调支援扑救其他地方森林火灾的，每次加5分。

4．乡镇创新森林防火工作，得到省或市广泛推广的，加5分。

三、考核等次

考核结果分四个等次：①考核分在90分以上的为“优秀”；②考核分在80-89分的为“良好”；③考核分在70-79分的为“合格”；④考核分在70分以下的为“不合格”。

在扑救森林火灾过程中发生人员死亡事故的，该乡镇本年度的森林防火考核为不合格。

四、考核结果运用

森林防火工作考核得分纳入乡镇党政正职年度工作目标责任制考核的权重分。森林防火工作考核为不合格的，对乡镇党政一把手扣减奖金30％。

国家级秤架自然保护区，国营杨梅林场、秤架林场、黄坌林场参照本办法进行考核。

五、附则

（一）本办法由县森林防火指挥部负责解释。

（二）本办法自2012年起开始执行，《印发阳山县森林防火目标责任制考核办法的通知》（阳府办[2010]86号）同时废止。
