# 关于成立阳山县2013年违法违规用地查处整改工作领导小组的通知

阳府办函〔2014〕23号

阳山县人民政府办公室关于成立阳山县

2013年违法违规用地查处整改工作

领导小组的通知

各乡镇人民政府，县政府有关部门、有关直属机构：

为加强对我县2013年违法违规用地查处整改工作的组织领导，县政府决定成立阳山县2013年违法违规用地查处整改工作领导小组。组成人员如下：

组 长：唐存伟（副县长）

副组长：李学森（县政府办公室副主任）

甘志科（县国土资源局局长）

成 员：陈彩霞（县法院）

文伟明（县发展改革局）

杨永芳（县科技农业局）

何章建（县公安局）

莫荣存（县监察局）

毛志标（县国土资源局）

孙燕萍（县环境保护局）

张亚坚（县林业局）

曾宪金（县规划市政局）

领导小组办公室设在县国土资源局，办公室主任由毛志标同志兼任。

本机构待该项工作结束后自行撤销。

阳山县人民政府办公室

2014年2月18日
