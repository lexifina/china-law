# 阳山县人民政府办公室关于印发阳山县推进政策性涉农保险实施方案的通知

各乡镇人民政府，县政府有关部门、有关直属机构：

《阳山县推进政策性涉农保险实施方案》已经县人民政府同意，现印发给你们，请认真贯彻执行。执行中遇到的问题，请径向县财政局反映。

阳山县人民政府办公室

2014年8月13日

阳山县推进政策性涉农保险实施方案

为扩大农业保险覆盖范围、提高农业保险服务水平，构建广覆盖、多层次、可持续的政策性农业保险体系，根据我县农村金融改革的总体要求，现就开展政策性涉农保险制定本实施方案。

一、重要意义

政策性涉农保险是农业保险制度的重要组成部分，加快建立和完善政策性涉农保险制度，有利于减少灾害对农民生产生活的影响，稳定和保障农民收入，不断提高农民生活水平；有利于通过保险机制发挥财政支持政策的杠杆效应，使广大农民切实享受到党中央国务院惠农政策带来的效益；有利于促进农村金融市场的培育和发展，为农村经济社会协调发展提供全面的金融服务；有利于扩大保险的覆盖面，提高保险业服务农村经济社会发展的能力。

二、工作目标

（一）扩大农业保险覆盖面。以政策性农业保险、城乡居民医疗等保险业务为基础，努力扩大政策性保险业务覆盖面。创新发展农业保险险种，鼓励开展地方优势农产品保险。

（二）提高农业保险保障水平。创新发展涉农保险业务，健全政策性农业再保险体系，逐步建立财政支持下的农业大灾风险转移分散机制，提高农民农业农村的抗风险能力。

（三）促进农村保险金融发展。加强农业保险与农村信贷相结合，积极推进农村抵押贷款、信用贷款等保证保险，促进保险对农业信贷的支持，缓解农民贷款难问题。

（四）加强农村保险服务网络建设。力争2015年底基本形成制度完善、组织健全、覆盖广泛、保障适度、发展规范的农业保险服务体系，为全县“三农”保险提供有力支持。

三、具体内容

（一）扩大政策性农险覆盖范围

1．森林保险。生态公益林保险保费由财政全额补贴，商品林保险保费由财政补贴60%。在公益林保险全覆盖的基础上，扩大商品林保险范围，提高对其他林农的保障程度，不断增强我县林业的风险抵御能力和恢复能力。

2．水稻种植保险保费由财政补贴80%。通过加大宣传力度，落实财政补贴等调控手段，引导农业企业、农民专业合作组织，种植户等参保，力争2015年底水稻种植保险在全县范围内全覆盖。

3．能繁母猪养殖保险保费由财政补贴88%。继续加大能繁母猪养殖保险的财政补贴力度，农户负担由原来的12元调整为7元/头，争取符合承保条件的能繁母猪做到应保尽保。

4．农村住房保险保费由财政补贴76%，农村五保户、低保户、贫困户的保险费由县财政全额补助。在农户自主自愿的前提下，逐步扩大农村住房保险的覆盖面，不断提高农村住房风险保障水平。

5．渔业保险。近日，《广东省政策性渔业保险实施方案（试行）》已获省政府批复通过，为切实将这一支渔惠渔政策落实好，县财政对符合参保条件的渔民参加渔民人身意外伤害险和渔船财产保险的保费，按不低于35％的比例给予补贴。

6．地方特色品种保险试点。结合地方实际，探索油茶、淮山等保险试点，积极开展地方特色品种保险试点。

（二）提高农业保险保障水平

1．自然灾害公众责任险。健全应对突发性重大自然灾害紧急救助体系，由政府出资办理自然灾害公众责任统一保险，参保人员因不可抗力的自然灾害直接或间接造成人身伤亡损失，一律由保险公司负责赔偿。

2．财产保险及人身意外伤害保险。力争在政策性农村住房保险的基础上，附加人员意外伤害和室内财产保险，进一步扩大风险保障范围，提高农村农民的抗风险能力。

3．城乡居民医疗大病补充保险。加大城乡居民医疗保险的宣传力度，狠抓落实，发挥城乡居民医疗大病补充保险分散风险的功能，减轻患病农民负担的作用。

4．新型农村小额人身保险。以农村低收入群体为对象，通过提供保险费低廉、保障适度、保险单通俗、核保理赔简单的小额人身保险产品，扩大农村保险保障覆盖面，提高我县农村低收入群体的保险保障水平和抵御风险能力。

5．健全政策性农业再保险体系。探索建立政策性农业保险风险保障基金，逐步建立财政支持下的农业大灾风险转移分散机制。

（三）鼓励农业保险与农村信贷相结合

1．积极推进农房、农业装备（设施）、林权、集体土地使用权等抵押贷款保证保险，促进保险对农业信贷的支持，缓解农民贷款难问题。

2．大力开展农户经营、农民创业的小额信用贷款保证保险和农村小额贷款借款人意外伤害保险，争取在农村创业小额贷款试点的基础上，探索建立农业保险与农村信贷有机结合的政银保互动机构，有序引导金融资本投资农业。

（四）建立健全“三农”保险服务体系

积极引导保险公司建立健全农村营销服务网络，加强“三农”基层保险队伍建设，将服务触角延伸到涉农一线，基本形成“覆盖全面、管理清晰、运行规范、服务到位”的保险销售服务体系。
