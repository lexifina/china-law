# 阳山县人民政府办公室关于调整县矿产品交易税费征管工作领导小组部分成员的通知

各乡镇人民政府，县直有关单位：

鉴于人员变动和工作需要，县人民政府决定调整阳山县矿产品交易税费征管工作领导小组部分成员。调整后的成员名单如下：

组 长：唐存伟（副县长）

副组长：王 建（县政协副主席、财政局局长）

唐长远（县政府办公室主任）

成 员：陈伟坚（县发展改革局）

冯智田（县公安局）

谭雄辉（县财政局）

曾飞龙（县国土资源局）

孙燕萍（县环境保护局）

梁国荣（县安全监管局）

黄少刚（县国税局）

陈志坚（县地税局）

吴东强（县水务局）

张其民（县矿产企业局）

领导小组办公室设在县行政服务中心四楼的县矿产品交易税费征管办公室，由谭雄辉兼任办公室主任，陈志坚、杨青（县国税局）担任办公室副主任。
