# 阳山县人民政府办公室关于成立广连高速公路阳山段征地拆迁指挥部的通知

青莲镇、小江镇、岭背镇、黄坌镇人民政府，县政府有关部门，各有关单位：

为加强对广连高速公路阳山段建设征地拆迁工作的领导，确保该项目阳山段征地拆迁工作和建设顺利进行，县政府决定成立广连高速公路阳山段征地拆迁指挥部。组成人员名单如下：

总 指 挥：潘文彬　　县委常委、常务副县长
