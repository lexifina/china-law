# 阳山县人民政府办公室关于调整县矿产品交易税费征管工作领导小组的通知

各乡镇人民政府，县各有关单位：

鉴于人员变动和工作需要，县人民政府决定调整阳山县矿产品交易税费征管工作领导小组。调整后的成员名单如下：

组 长：潘文彬　　县委常委、常务副县长

副组长：梁海东　　县财政局局长

林耀雄　　县政府党组成员、县政府办公室主任

成 员：陈伟坚　　县发展改革局副局长

钟 衍　　县公安局副局长

谭雄辉　　县财政局副局长

张志锋　　县国土资源局副局长

孙燕萍　　县环境保护局副局长

梁国荣　　县安全监管局副局长

黄少刚　　县国税局副局长

陈志坚　　县地税局副局长

吴东强　　县水务局副局长

邓洪普　　县能源矿产局副局长

领导小组办公室设在县社会综合服务中心四楼的县矿产品交易税费征管办公室，由谭雄辉兼任办公室主任，陈志坚、杨青（县国税局）担任办公室副主任。

本机构成员若有变动，由成员单位相应人员自然更替。

阳山县人民政府办公室

2017年2月22日
