# 阳山县人民政府关于城南江滨路国有土地上有关房屋征收的通告

因阳山县江滨路旧城改造项目建设需要，根据《国有土地上房屋征收与补偿条例》（国务院令第590号）有关规定，县人民政府决定征收城南江滨路有关房屋及建筑物。现就有关事项通告如下：

一、征收依据：《城南江滨路国有土地上有关房屋征收决定书》。

征收范围：东至原阳山汽车站（阳山大桥城南桥头）；南至城南大道旁；西至县公路局集资楼；北至连江河边。征收范围为城南大道113号2幢县公路局办公楼宿舍区。

二、征收户数及面积：被征收人共13户，单位公租房3套，铺位5卡及通道1卡。被征收单位的公共建筑面积，建筑基底占地面积约320㎡。总建筑面积2880㎡。

三、房屋处置：被依法征收的上述房屋，同时收回其国有土地使用权。

四、补偿办法：按《阳山县江滨路旧城改造工程国有土地上房屋征收补偿方案》执行。上述被征收房屋由阳山县房屋征收办公室负责组织实施。请房屋被征收人在搬迁期限内，到阳山县房屋征收管理办公室办理土地、房屋丈量、登记和补偿手续，并领取补偿金。

违法建筑、超过批准期限的临时建筑不予补偿；房屋征收范围确定后在房屋征收范围内新建、扩建房屋及改建房屋、改变房屋用途等不当增加补偿费用的，不予补偿。

五、搬迁期限：自2017年3月24日至2017年4月24日止。

被征收人如对房屋征收决定不服，可以自公告之日起60日内向清远市人民政府申请行政复议或6个月内向有管辖权人民法院提起行政诉讼。

被征收人在法定期限内不申请行政复议或者不提起行政诉讼，在补偿决定规定的期限内又不搬迁的，依法强制执行。
