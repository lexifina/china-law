# 阳山县人民政府办公室关于印发《阳山县城市地下综合管廊建设实施方案》的通知

各乡镇人民政府，县政府各部门、各直属机构：

《阳山县城市地下综合管廊建设实施方案》业经县人民政府同意，现印发给你们，请认真贯彻执行。执行过程中遇到的问题，请径向县规划市政局反映。

阳山县人民政府办公室

2017年3月29日

阳山县城市地下综合管廊建设实施方案

为贯彻落实《国务院办公厅关于推进城市地下综合管廊建设的指导意见》（国办发〔2015〕61号）、《广东省人民政府办公厅关于印发〈广东省城市地下综合管廊建设实施方案〉的通知》（粤府办〔2016〕54号）以及《清远市人民政府办公室关于印发〈清远市城市地下综合管廊建设实施方案〉的通知》（清府办〔2016〕61号）的要求，扎实推进我县城市地下综合管廊规划、建设、管理工作，结合我县实际，制定本方案。

一、工作目标

科学编制并贯彻实施阳山县城区地下综合管廊专项规划，到2020年，建成不少于2公里的城市地下综合管廊，“马路拉链”问题得到改善，管线安全水平和防灾抗灾能力明显提升，逐步消除主要街道架空线，城市地面景观明显好转？

二、基本原则

（一）坚持规划先行，适度超前，科学编制和实施专项规划，统筹推进地下综合管廊建设。

（二）坚持从我县实际情况出发，分类确定入廊管线，建设和管理制度同步推行。

（三）坚持试点带动，选择城市发展新区和重点改建区域先行试点，逐步推进实施，努力促使建成管廊发挥社会效益。

（四）坚持政府主导，加大政策支持，充分发挥市场作用，吸引社会资本广泛参与。

三、工作任务

（一）规划先行，在规划阶段保证地下综合管廊顺利建设。

1．编制完善地下综合管廊工程专项规划。按照“先规划、后建设”的原则，县城市规划部门在地下管线普查的基础上，结合给排水、电力、电信等各专项规划，统筹本县各类管线实际发展需要，于2017年11月底前编制完成阳山县城地下综合管廊工程规划，并报县政府批准后实施。地下综合管廊工程规划原则上应与城市总体规划相一致，做好与土地利用总体规划等专项规划的衔接，充分论证比选，确保专项规划科学经济、可操作性强。地下综合管廊工程规划要确定管廊系统总体布局，明确管廊断面形式、入廊管线种类，划定管廊空间位置、配套设施用地等三维控制线，合理确定管廊建设区域和时序，并提出规划层次及行业要求的避让原则和预留控制原则。（牵头单位：县规划市政局，参与单位：县住房城乡建设局、县水务局、县发展改革局、县经济和信息化局、县国土资源局）

2．落实专项规划内容。在控制性详细规划中，落实地下综合管廊工程专项规划的各项要求，必要时，对现有的控制性规划进行修编。在出具规划条件时明确地下综合管廊的建设要求。在工程规划许可审批阶段，对地下综合管廊设计合规情况予以审查。（责任单位：县规划市政局）

（二）研究确定地下综合管廊建设运营管理模式，选定建设运营单位，保障建设资金来源。组建管廊建设运营单位，作为政府投融资平台，加大财政资金投入，鼓励各管线单位参股合作建设综合管廊，积极推广以政府和社会资本合作方式（PPP模式），通过特许经营、投资补贴、贷款贴息等形式，积极吸引社会资本建设、运营地下综合管廊。充分发挥开发性和政策性金融作用，积极协调相关金融机构加大对我县地下综合管廊建设的信贷支持力度。支持符合条件的地下综合管廊运营企业发行企业债券和项目收益票据，专项用于地下综合管廊建设项目。（牵头单位：县规划市政局，参与单位：县代建办、县住房城乡建设局、县发展改革局、县财政局、县国资办、县水务局、县经济和信息化局、阳城镇政府、各管线单位）

（三）合理划定重点建设区域，制定年度建设计划。城市新区、各类园区、成片开发区域的新建道路要根据功能需求同步建设地下综合管廊；老城区要结合地下空间开发、“三旧”改造、城市棚户区改造、道路改扩建、河道治理等，因地制宜、统筹安排地下综合管廊建设。在交通流量较大、地下管线密集的城市道路、地下综合体等地段，城市高强度开发区、重要公共空间、主要道路交叉口、道路与河流的交叉处，以及道路宽度难以单独敷设多种管线的路段，要优先建设地下综合管廊。各有关部门要结合地下综合管廊工程规划和城市建设的需求，在确定近期（年度）城市道路建设项目的同时，同步研究确定地下综合管廊近期（年度）建设项目。（牵头单位：县规划市政局，参与单位：阳城镇政府、县住房城乡建设局、县代建办、管廊建设运营单位、县交通运输局、县水务局、县发展改革局、县经济和信息化局、县国土资源局）

（四）实施年度建设计划，保证管廊建设任务顺利完成。管廊建设单位应将城市地下综合管廊的建设作为年度重点建设任务之一，强力推进综合管廊建设。建立管廊建设项目储备制度，确定2017-2020年四年项目滚动实施计划和年度建设计划，实行项目库管理，有序推进地下综合管廊建设。综合管廊工程建设应严格执行工程项目基本建设程序，落实工程建设各方质量安全主体责任，所在地乡镇政府及有关单位应积极配合，及时完成征地拆迁。（牵头单位：县规划市政局，参与单位：县住房城乡建设局、县代建办或其他管廊建设单位、县发展改革局、县国土资源局、县经济和信息化局、县交通运输局、县水务局、县公共资源交易中心、县房征办、阳城镇政府）

（五）强化管廊工程建设质量安全。将质量安全监管要求贯穿于规划、建设、运营全过程，落实工程质量终身责任永久性标牌制度，接受社会监督。地下综合管廊设计应符合国家、有关行业及省相关现行规范、标准的规定，做到技术先进、经济合理、安全适用。推进地下综合管廊主体结构构件标准化，积极推广应用预制拼装技术，提高综合管廊建设标准化、产业化水平。工程竣工验收后，工程档案应及时收集、整理、归档，以确保工程项目资料完整、正确和真实。（牵头单位：县代建办或其他管廊建设单位，参与单位：县规划市政局、县住房城乡建设局、阳城镇政府）

（六）建立管线入廊管理制度，规范入廊管理。对新建和已建有地下综合管廊的区域，所有管线应按规划要求纳入管廊，不得再另行安排管廊以外的管线位置。在应建地下综合管廊区域，修建城市道路应同步建设地下综合管廊，督促管线单位将既有管线迁移至地下综合管廊。（牵头单位：县规划市政局，参与单位：县住房城乡建设局、县代建办、县水务局、县发展改革局、县经济和信息化局、县交通运输局、阳城镇政府、管廊建设运营单位、各管线单位）

（七）建立健全管廊运营管理制度，强化日常维护。管廊运营单位应建立健全地下综合管廊运营管理制度，加强管廊本体及附属设施日常维护管理，与入廊管线单位签订协议，明确入廊管线种类、时间、费用和责权利等内容，确保地下综合管廊正常运行。（牵头单位：管廊建设运营单位，参与单位：县规划市政局、县住房城乡建设局、县水务局、县经济和信息化局、阳城镇政府、各管线单位）

四、工作计划

（一）2017年11月底前完成地下综合管廊工程专项规划，并自2018年3月起在出具规划条件和工程规划许可审批阶段落实管廊规划内容。

（二）2018年4月底前，确定管廊建设运营模式，确定管廊建设运营单位和建设资金来源。

（三）2018年4月底前，制定管廊近期建设计划和2018年年度建设计划。

（四）2018年12月底前，编制完成管线入廊管理规定、运营管理制度。

（五）2018年12月起，结合市政道路的建设，实施年度综合管廊建设计划。

五、保障措施

（一）加强组织领导。县政府成立“阳山县城市地下综合管廊建设工作领导小组”（以下简称“领导小组”），领导小组由县政府分管负责同志担任，成员由县发展改革局、县经济和信息化局、县财政局、县国土资源局、县住房城乡建设局、县交通运输局、县水务局、县规划市政局、县国资办、县代建办、阳城镇人民政府等单位主要负责同志组成。领导小组下设办公室，设在县规划市政局，负责建立我县城市地下综合管廊建设工作协调机制，统筹协调相关工作，定期组织召开综合管廊工作协调推进工作会议，定期报送、通报工作进展情况。

（二）明确职责分工。领导小组负责研究确定管廊建设运营模式，确定综合管廊建设计划，负责管廊建设资金的筹措、调度，并在每年度末开展综合管廊建设督查工作，监督管廊的建设进度和建设资金的使用情况。

各项工作任务由牵头单位负责，参与单位积极配合，协力推进综合管廊建设各项工作。
