# 阳山县人民政府办公室印发阳山县落实清远市创建国家环境保护模范城市2017年攻坚任务实施方案的通知

各乡镇人民政府，县政府各部门、各直属机构：

《阳山县落实清远市创建国家环境保护模范城市2017年攻坚任务实施方案》已经县人民政府同意，现印发给你们，请认真组织实施。实施过程中遇到的问题，请径向县创模办（设在县环境保护局）反映。

阳山县人民政府办公室

2017年3月29日

阳山县落实清远市创建国家环境保护模范

城市2017年攻坚任务实施方案

为推进实施清远市创建国家环境保护模范城市（以下简称“创模”）攻坚工作，确保完成各项任务目标，按照《清远市人民政府办公室关于印发清远市创建国家环境保护模范城市2017年攻坚方案的通知》（清府办〔2017〕9号）有关要求，结合我县实际情况，制定本方案。

一、指导思想

以党的十八大和十八届三中、四中、五中、六中全会精神及“创新、协调、绿色、开放、共享”五大发展理念为指导，坚持以人为本、坚持环境保护与经济增长并重，紧紧围绕创建国家环保模范城市目标，全民动员、城乡联动，全面推进节能减排，强化城市环境综合整治，突出抓好重点行业、企业污染深度治理，加快环境基础设施建设，改善城市环境质量，全面促进经济、社会、环境协调和可持续发展，在加快发展、绿色发展中实现社会进步和民生改善，做到既提速又转型、既发展又保护，在生态文明之路上迈出更大步伐。

二、总体目标

2017年是“创模”攻坚年，工作目标是：重点突破有差距的指标、巩固已达标的指标、关注有反复的指标，按照《阳山县实施清远市创建国家环境保护模范城市2017年攻坚任务分解表》（附件1），全面启动各项攻坚工程。

积极配合做好“创模”工作的专家预评估和省、国家验收评估工作。清远市初步拟定于2017年5月底前进行专家预评估，2017年8月前申请省级验收评估，通过省级评估后申请国家验收评估。

三、攻坚重点

（一）强化工业企业规范化管理，推进重点工业企业全面达标。加强对一般工业固体废物的管理，对一般工业固废贮存、运输、处置实行全过程管理，建立申报登记制度，规范台账管理制度；严格执行环评、三同时制度，严查未批先建、久试不验等违法项目。加强对重金属污染企业的监管，要求重金属污染企业建立特征污染物月报制度。

（二）进一步科学合理做好统计工作。规范统计规程，使全县规模以上单位工业增加值能耗、单位GDP用水量、万元工业增加值主要污染物排放强度等统计数据实现逐年下降，符合“创模”要求；按照“创模”宣传工作方案的要求，加大宣传力度，开展公众环保满意率、知晓率调查，为“创模”攻坚提供可靠依据。

（三）加强环境综合整治。建立环境空气质量预警制度和联防联动机制，加大工业企业综合整治力度，减少污染排放，深入推进重点行业脱硫、脱硝、除尘治理，加大高污染燃料锅炉污染整治力度，深入开展VOCs企业综合治理工作；加强扬尘污染防治和控制工作，加强道路与运输扬尘控制，遏制施工扬尘污染，整治堆场扬尘；推进机动车污染防治工作，稳步推进“黄标车”淘汰工作，全面推行“黄标车”限行，强化机动车辆监管，严把机动车准入关及油品质量关；调整优化产业结构，加快清洁生产改造；加快调整能源结构，增加清洁能源供应；加强噪声污染防治，强化各类噪声污染源的监控，严格执行机动车禁鸣，严禁建筑工地未经批准夜间施工，禁止娱乐场所超时营业，建立环保、公安噪声管理联动机制，加大噪声污染投诉调处力度。

（四）加快迎检现场准备工作。按照“创模”任务下达的现场迎检准备工作要求，对照附件2进行逐项落实。准备工作要求责任单位一把手狠抓落实，确保按期完成准备工作。根据市工作部署，2017年第一季度将由市分管领导带队，对迎检现场准备工作落实情况开展一次专项督查。

（五）扎实做好“创模”技术指标达标工作。各相关负责单位要明确“创模”指标任务，组织实施各项“创模”工程，落实攻坚措施，巩固或推进各项指标达标，同时完成“创模”各项指标的技术报告；按“创模”规范要求，整理完成各项指标资料档案、重点工程项目档案、迎检现场档案等工作。

四、保障措施

（一）加强领导，落实责任。成立“创模”攻坚指挥部（设在县环境保护局），并根据人员调整和工作需要，适时调整、充实指挥部，确保相关工作的顺利推进。各责任单位要根据需要，一把手作为第一责任人，负责本部门、本单位的全盘“创模”工作，分管领导负责具体工作，指定一名联络员做好与县“创模”攻坚指挥部办公室的沟通联络工作。各责任单位要制定各自的“创模”工作计划和实施方案，将任务层层分解落实，做到一级抓一级，层层抓落实。

（二）明确任务，突出重点。县“创模”攻坚指挥部要进一步完善指挥长例会制度和“创模”联络员会议制度，及时对“创模”工作进行专题研究、部署、指导、协调、督办、检查、考核。各责任单位要根据自身工作需要，建立和完善相应工作制度，及时研究解决相关问题，扎实推进各项工作开展。各责任单位要对未完成工程制定攻坚方案，并在每月的10号、25号前向县“创模”攻坚指挥部办公室报送“创模”工作完成情况。

（三）强化督查，严格问责。县“创模”攻坚指挥部要加强对各责任单位创建进度情况的监督检查，做到进度清楚、把握动态，并对存在问题进行汇总分析和上报，特别是要加大对未达标指标相关工程和工作推进情况的督查督办力度，为预评估提供详实的资料。加强纪律监督，对“创模”工作落实不到位，出现严重失误的，追究单位主要负责人的责任。

（四）投入资金，强化保障。在“创模”攻坚期间，要整合资源，多方筹措资金，确保“创模”工程建设资金及时足额到位，加快“创模”工程进度。同时，相关责任单位要以政策推动和机制创新为重点，充分调动各方面积极性，多渠道、多形式、多领域融资，确保各项“创模”重点建设项目的资金需要。

（五）广泛宣传，营造氛围。加大“创模”活动宣传力度，通过报刊、广播、电视、网络等媒体，针对“创模”工作中的重点、难点及社会关注的热点，有计划、有步骤、有重点地在全市掀起范围广、影响大、形式多种多样的“创模”宣传活动。建立社会监督、公众参与机制，接受社会的监督和情况反映，促进“创模”工作顺利开展。
