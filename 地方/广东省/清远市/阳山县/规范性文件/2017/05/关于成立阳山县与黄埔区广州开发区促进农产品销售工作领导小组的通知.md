# 关于成立阳山县与黄埔区广州开发区促进农产品销售工作领导小组的通知

各乡镇人民政府，县直有关单位：

为落实5月5日黄埔区对口帮扶阳山工作座谈会精神，进一步深化交流合作，拓宽农产品销售渠道，促进农业增效、农民增收，经县委、县政府与黄埔区研究同意，决定成立阳山县与黄埔区促进农产品销售工作领导小组。人员名单如下：

组 长：杨坚强（阳山县副县长）

副组长：林卫忠（黄埔区驻阳山县工作组副组长）

邓奕彬（阳山县政府办公室副主任）

梁文锋（阳山县科技和农业局局长）

成 员：陈志华（阳山县委宣传部副部长）

陈伟坚（阳山县发展和改革局副局长）

杨永芳（阳山县科技和农业局副局长）

谭雄辉（阳山县财政局副局长）

孙燕萍（阳山县环境保护局副局长）

陈志能（阳山县交通运输局副局长）

邓智聪（阳山县林业局副局长）

邝瑞明（阳山县食品药品监督管理局副局长）

何青华（阳山县工商行政管理局副局长）

陈可敬（阳山县质量技术监督局副局长）

陈伟坚（阳山县供销合作社联合社主任）

各乡镇镇（乡）长均为领导小组成员。

领导小组下设办公室，办公室设在县科技农业局，由杨永芳同志兼任办公室主任，具体抓好搭建平台、对接广州市场、促进农产品销售等工作落实。
