# 阳山县人民政府办公室关于成立阳山县与黄埔区合作建设县城九年义务教育阶段学校工作领导小组的通知

阳山县人民政府办公室关于成立阳山县与

黄埔区合作建设县城九年义务教育阶段

学校工作领导小组的通知

各乡镇人民政府，县政府各部门、各直属机构：

为落实5月5日黄埔区对口帮扶阳山工作座谈会精神，在县城建设一所九年义务教育阶段学校，经县委、县政府与黄埔区研究同意，决定成立阳山县与黄埔区合作建设县城九年义务教育阶段学校工作领导小组。人员名单如下:

组 长：潘文彬（阳山县委常委、常务副县长）

副组长：周文华（阳山县副县长）

林 怡（阳山县副县长）

彭 军（黄埔区驻阳山县工作组副组长）

成 员：陈向前（阳山县政府办公室副主任）

唐长远（阳山县教育局局长）

梁海东（阳山县财政局局长）

梁建恒（阳山县国土资源局局长）

杨春晓（阳山县住房和城乡建设局局长）

钟志华（阳山县规划市政局局长）

郭建军（阳山县国有资产管理办公室主任）

何俊斌（阳山县阳城镇镇长）

黄埔区教育局、黄埔区财政局、黄埔区国土资源和规划局相关负责人均为成员，广州开发区区属国企作为代建单位参与工作领导小组。领导小组下设五个工作组。

（一）综合协调组：掌握工作推进情况，建设工程的立项审批、组织协调各专责工作组处理有关情况。（责任单位：阳山县教育局）

（二）用地和民事协调处理组：建设用地征收及地上建筑物的拆迁，处理建设过程中出现的民事纠纷。（责任单位：阳山县阳城镇政府、国土资源局）

（三）规划设计组：学校的规划设计。（责任单位：黄埔区扶贫办、黄埔区教育局、黄埔区国土资源和规划局、阳山县规划市政局）

（四）建设组:建设工程的规划审批和施工许可证的报建手续，按法规要求和基建程序组织施工建设。（牵头单位：阳山县住房城乡建设局、规划市政局、代建办）

（五）保障组：项目建设前期工作与施工期间的建设资金保障；落实学校建成后教育教学设施设备的购置资金。（责任单位：黄埔区财政局、阳山县财政局）

建设工作完成后，该工作组自行撤销。
