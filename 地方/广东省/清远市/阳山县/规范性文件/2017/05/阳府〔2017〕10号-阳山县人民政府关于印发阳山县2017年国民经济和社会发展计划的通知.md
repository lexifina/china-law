# 阳山县人民政府关于印发阳山县2017年国民经济和社会发展计划的通知

各乡镇人民政府，县政府各部门、各直属机构：

《阳山县2017年国民经济和社会发展计划》已经阳山县第十六届人大二次会议审议批准，现印发给你们，请认真组织实施。

阳山县人民政府

2017年5月18日

阳山县2017年国民经济和社会发展计划

2017年，是实施“十三五”规划的重要一年，是推进供给侧结构性改革的深化之年，也是与全省同步率先全面建成小康社会的攻坚之年。今年政府工作的总体要求是：认真贯彻落实党的十八大，十八届三中、四中、五中、六中全会和习近平总书记系列重要讲话，中央和省委、市委经济工作会议，省委十一届八次全会、市委七届三次全会和县委十三届二次全会精神，统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，坚持稳中求进总基调，坚持以“五大发展理念”引领经济发展新常态，坚定不移推进“三个全域、两大攻坚”战略行动，稳增长、促改革、调结构、惠民生、防风险，努力开创各项事业发展新局面。

按照上述要求，今年我县国民经济和社会发展的预期目标为:

——全县生产总值98.85亿元，增长6%左右。其中，第一产业增加值33.31亿元，增长5.3%；第二产业增加值19.07亿元，增长7.6%（工业增加值12.83亿元，增长9.9%；建筑业增加值6.24亿元，增长2.6%）；第三产业增加值46.47亿元，增长5.7%；

——公共财政预算收入4.32亿元，增长7.5%；

——社会消费品零售总额39.6亿元，增长10%；

——固定资产投资总额23.06亿元，增长10%；

——居民消费价格总指数涨幅控制在3%以内；

——城乡居民可支配收入与经济发展同步增长；

——城镇登记失业率控制在2.37%以内；

——常住人口自然增长率控制在13‰；

——节能减排降碳约束性指标完成省市下达的年度计划。

为实现今年经济社会发展预期目标，重点做好如下五大方面工作：

（一）抓项目建设，推进全域绿色产业开发。把握国家重点生态功能区定位，牢固树立绿色发展理念，精准发力，确保有效投资。规划一批重大项目建设，把更多、更大的项目列入重大建设项目库，以固定资产投资拉动经济发展。一是加快新能源项目建设工作。重点加快恒运集团光伏项目，雷公岩、桔子塘、生物质能发电、电网输出配套工程等项目建设工作，强力推进绿色能源产业建设。二是全力抓好小水电技改，力促尽快完成并产生效益，加快连江梯级电站建设，尽快完成界滩电站、黄燕水电站增效扩容技改项目工程。三是推进重点项目建设，为企业排忧解难。重点做好同泰食用油脂有限公司、阳山景润陶瓷色料实业有限公司、县兴阳实业公司等企业的跟踪服务工作。四是加快民生建设项目工程进展，重点建设阳山县省级新农村连片示范建设项目工程、村村通自来水工程、江滨路配套工程、阳山县棚户区改造项目、韩愈文化公园等基础设施建设。

（二）发展旅游事业，推进全域旅游创建。通过旅游开发、推进全域旅游创建，进一步优化阳山人居环境，推动生态环境的进一步优化。

1．抓好龙头旅游精品示范项目建设。加快推动广东第一峰景区国有收购进程，促进第一峰景区扩容提质，争创国家5A级旅游风景区；加快推进阳山关景旅游景区（原神笔山）升级改造，尽快恢复营业；加快推进贤令山风景区基础设施建设，努力把贤令山省级森林公园升级为国家级森林公园，完善北山古寺旅游配套设施。通过上述3个龙头旅游精品示范项目的带动作用，扩大市场影响力，提高客源占有率。此外，加大招商引资力度，力促其他大型旅游项目落地，加快形成特色项目突出、功能结构完整、资源要素聚集、品牌形象鲜明的全域旅游发展格局。

2．培育五个特色小镇。利用“特色资源+小镇”模式，大力打造秤架民族养生旅游特色小镇；利用“特色产业+小镇”模式，精心培育七拱田园美食文化特色小镇；利用“文化+小镇”模式，规划建设黎埠客家风情旅游特色小镇；利用“新农村建设+小镇”模式，全力打造杜步醉美乡村旅游特色小镇；利用“秀水温泉+小镇”模式，整合资源倾力打造小江山水温泉旅游特色小镇。

3．打造十大品牌节庆活动。发挥政府引导作用，发挥社会和企业力量，培育一批具有鲜明特色、适宜游客参与、周期稳定的旅游、文化、体育节庆活动。到2019年，培育多个成熟品牌节庆活动：1-3月有北山古寺祈福节，黎埠梨花节、桃花节，水口萝卜节、徒步节；4-6月有第一峰山花节，阳山关景漂流节，七拱采摘节，茶坑水库环湖马拉松赛、骑行节；7-9月有秤架峡谷避暑节，露营节，登山节，瑶族篝火音乐节；10-12月有乡村美食节、汽车文化节、岭背柚子节、温泉养生节。各镇村以当地文化、特色产品等为依托，自行策划举办相应节事活动。最终形成10大精品旅游节庆活动。

同时，以“美丽乡村+民宿”的模式发展百家乡村酒店及民宿，推出一批“农家乐、民宿、观光农业、观光林业”等项目。梳理生态水系，打造千里生态水系加绿道，使阳山成为旅游环境优美、游客美誉度高的旅游目的地。

（三）补齐民生短板，推进全域文明建设。

1．做好教育工作。适应和引领教育发展新常态，以提高教育质量为中心，以提升学校管理水平为重点，加快推进义务教育均衡优质标准化发展，构建教育现代化新格局。推进第三幼儿园和城东新区小学建设。

2．做好卫计工作。加快发展公共卫生事业，推进基本公共卫生服务均等化。加快创建“省卫生强县”工作。重点推进公立医院改革、卫生资源优化整合和镇村卫生服务一体化管理等工作。切实做好人口和计划生育工作，提高人口素质。重点做好计生阳光管理、强化人口优质服务等工作。

3．做好文体工作。加快文化体育设施建设，开展各项丰富多彩的文体活动，提高精神文明建设水平。

4．做好社会保障工作。一是做好就业保障工作。通过完善创业和人才两个“孵化基地”建设、抓好乡镇人力资源社会保障基层服务平台建设和加强技能培训等，促进就业、创业工作。二是完善社会保障机制。推进社会保险扩面征缴工作，加强基金监管，确保基金运行安全；做好妇女儿童权益保护、残疾人服务工作；完善住房保障制度，切实解决城镇低收入家庭住房困难。

5．开展人居环境整治。我县是清远市唯一采用PPP模式整县推进污水处理设施建设项目建设示范县。今年要大力推进全县13个镇级污水处理设施和158个行政村的农村污水处理设施及其配套收集管网建设。

6．维护社会和谐稳定。全力维护社会稳定和谐，推进公共服务均等化，提高人文素质和健康水平。加大市场监管力度，确保居民生活必需品供应，保持价格总水平基本稳定；继续强化信访工作，加强社会治安综合治理，加强民族、宗教、侨务等工作；增强各种突发事件预警和应对能力，防止和打击电信诈骗、网络诈骗、微信诈骗等新型诈骗手段，防范各类恐怖活动；强化安全生产、食品药品安全监管，推进环保节能，强化质量强县工作，确保人民群众生命财产安全。

（四）全力以赴，推进农村综合改革攻坚。着重从9个方面加大农村综合改革力度：继续大力推进“三个重心下移”工作，充分发挥村级组织作用；继续大力推进“三个整合”工作，充分优化农村资源资金配置；继续大力推进农村金融改革，建立新型农村金融互助体系；继续大力培育发展新型农业经营主体，着力增加农民经营性收入；继续大力建设社会主义新农村和美丽乡村，着力改善农村人居环境；继续大力抓好精准扶贫，打赢脱贫攻坚战；继续大力完善农村社会服务网络建设，为农村农民提供优质服务；继续大力统筹涉农维稳“四大领域”，做好涉农矛盾的排查化解工作；积极稳妥开展农村承包土地的经营权抵押贷款，解决农民贷款难问题。

（五）加大力度，推进农业供给侧结构性改革攻坚。一是抓好现代农业生产基地化建设，发展生态农业、休闲农业、“互联网+”等新业态。二是抓好农业龙头企业，促进农业企业农民专业合作社和家庭农场等新型农业经营主体的发展，切实提高“四大经营主体”的引领带动和市场竞争能力。三是抓好农业品牌创建工作，积极实施农业“三品”工程，突出抓好生态原产地产品保护示范县和农产品质量安全县申报实施以及现代农业示范园建设，并以此为契机，抓好名优特新农产品产业群建设和绿色、有机产品认证工作，创建新的农业特色品牌。四是进一步抓好粮食生产工作，结合加强农业基础设施建设，抓好粮食创高产活动，确保完成全年粮食生产任务。

此外，按照“三去一降一补”的要求，继续推动钢铁行业化解过剩产能，降低企业杠杆率。在减税、降费、降低要素成本上加大工作力度，既补硬短板也补软短板，既补发展短板也补制度短板。着力振兴实体经济，坚持以提高质量和核心竞争力为中心，坚持创新驱动发展，扩大高质量产品和服务供给。
