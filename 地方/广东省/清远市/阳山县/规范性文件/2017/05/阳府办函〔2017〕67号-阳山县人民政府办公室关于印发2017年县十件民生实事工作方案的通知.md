# 阳山县人民政府办公室关于印发2017年县十件民生实事工作方案的通知

各乡镇人民政府，县政府各部门、各直属机构：

经县人民政府同意，现将《2017年县十件民生实事工作方案》印发给你们，请认真组织落实。

阳山县人民政府办公室

2017年5月5日

2017年县十件民生实事工作方案

为保障和改善民生，扎实推进2017年县十件民生实事，确保工作任务顺利完成，结合我县实际，制定本方案。

一、主要内容

2017年我县十件民生实事是提高底线民生保障水平；全面完成7866人年度脱贫任务；提高教育发展保障水平；提升基层医疗卫生服务水平；加快农村困难户危房改造；推进县城内街小巷改造和道路贯通工程建设；推进农村人居环境综合整治；整治县城交通黑点，优化交通组织；推进纯电动公交车项目建设；实施村村通自来水工程建设。

二、任务分解

结合实际，对2017年县十件民生实事进行任务分解（附件1），明确具体工作任务、责任领导、牵头单位及责任人。

三、工作责任及要求

（一）加强领导，细化方案。各单位要坚持“实”字为主，以求真务实的精神和真抓实干的作风，扎实办好民生实事。各牵头部门要由一把手负总责，指定分管领导抓落实，并选派政治素质高、业务能力强的干部具体负责；将目标任务进行细化分解，明确阶段目标、完成时间，落实工作措施，全力推进。

（二）强化推进，定期汇报。责任领导每季度组织牵头单位及有关部门召开一次推进会，通报工作进度，及时解决存在问题，确保民生实事有序推进。从2017年6月起，每月结束后3个工作日内，各牵头单位以表格形式（附件2）将县十件民生实事完成情况报送县政府督查室。

（三）落实资金保障，实行监督机制。实行财政投入情况定期统计通报监督机制，将民生资金的财政财务监督检查及绩效评价运行跟踪监控情况与项目安排拨付相结合，提高资金使用效益。

（四）注重实效，加大督查力度。县政府督查室把推进县十件民生实事工作列为重点督办事项，实时跟进各项重点工作落实情况，定期向县政府报告。对进展滞后的，及时向承办单位发出督办通知书；对工作敷衍塞责的单位，实行行政问责制。
