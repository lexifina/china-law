# 阳山县人民政府办公室关于成立阳山县申报“全国森林旅游示范县”工作领导小组的通知

各乡镇人民政府，县各有关单位：

根据《全国森林旅游示范市县申报命名管理办法》，我县符合“全国森林旅游示范县”申报条件。为做好申报相关工作，经县政府研究，决定成立阳山县申报“全国森林旅游示范县”工作领导小组。组成人员如下：

组 长：廖敬华　　县长

副组长：蔡科友　　县委常委、县政府党组成员

杨坚强　　副县长

成 员：邓奕彬　　县政府办公室副主任

黄松发　　县林业局局长

梁建恒　　县国土资源局局长

邹华鹏　　县统计局局长

钟超波　　县旅游局副局长

戴金绍　　县信息中心主任

江海坚　　县广播电视台台长

张亚坚　　广东南岭国家级自然保护区管理局

秤架管理处负责人

郭平华　　县秤架林场场长

胡伟坚　　县黄坌林场场长

谢震宇　　县贤令山森林公园管理服务所负责人

领导小组办公室设在县林业局，具体负责申报的日常工作，并加强部门之间的协调。办公室主任由黄松发兼任，副主任由钟超波、邓智聪（县林业局）担任，成员由各成员单位负责该项工作的人员组成。

附件：1．“全国森林旅游示范县”申报工作职责分工
