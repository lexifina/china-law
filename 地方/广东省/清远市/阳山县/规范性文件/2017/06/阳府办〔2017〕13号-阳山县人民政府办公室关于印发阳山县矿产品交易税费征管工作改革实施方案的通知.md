# 阳山县人民政府办公室关于印发阳山县矿产品交易税费征管工作改革实施方案的通知

各乡镇人民政府，县政府各部门、各直属机构：

《阳山县矿产品交易税费征管工作改革实施方案》已经县人民政府同意，现印发给你们，请认真贯彻执行。执行过程中遇到的问题，请径向县矿产品交易税费征管办公室（以下简称“县矿征办”）反映。

阳山县人民政府办公室

2017年6月28日

阳山县矿产品交易税费征管工作改革实施方案

为进一步加强全县矿产品交易税费征管工作，建立公平、公正、公开的征管环境，根据有关法律、法规的规定，结合我县实际，制定本实施方案。

一、指导思想

深入贯彻落实“三个全域、两大攻坚”战略行动，积极推动全域绿色产业开发，着力打造阳山绿色矿山产业，加强矿产品交易税费征管，加强矿产品征管队伍建设，增加资源型税收收入，全面加快推进县域经济发展进程。

二、基本原则

按照“标准公开、源头监控、从价计征、按实征收”的原则，强化县财税部门统管职能作用，对矿产企业应缴税收实行“监控产量信息共享、最低标准统一核定”的管理体制。按照“重心下移”原则，发挥县矿征办统筹监管作用，将矿产品交易税费征管职能下放到乡镇，创新完善矿产品交易税收“双重”管理模式。

三、主要做法

为促进全县矿山企业的发展，强化县级征管部门的统筹监管作用，调动乡镇对矿产品税费征管工作的积极性，增加财税收入，将矿产品交易税费征管职能归口乡镇属地管理。

（一）健全完善矿产品交易税费征管组织机构。

1．保留县矿征办。

（1）解聘遣散县矿征办社会招聘工作人员。设立一个月过渡期，过渡期满后，按《劳动法》的相关规定和标准解聘遣散原有77名社会聘请人员，对解聘人员作一次性发放补偿金后遣散，一律不另作工作安置。

（2）加强县矿征办征管力量。由县财政局牵头，会同相关税务、执法职能部门抽调、调整精干力量（含现抽调的11名单位人员），强化县矿征办力量，报县政府批准后启动工作。县矿征办受县人民政府和各执收主体单位委托，归口县财政局管理，全权负责相关矿产企业税收及非税收入的征收、管理、解缴、稽查和综合协调等工作。

2．组建乡镇矿征办。各乡镇组建成立矿征办，抽调精干力量开展矿产品交易税费征管工作。乡镇矿征办归口乡镇属地管理，负责辖区内的矿产企业税收及非税收入的征收、管理、稽查和综合协调等工作，负责辖区内磅秤、监测点的管理工作。乡镇辖区内下设的磅秤、监测点工作人员由乡镇统筹安排，乡镇矿征办人员配套需报备县矿征办批准备案。

（二）健全完善矿产品交易税费征管办法。

1．设立矿产品交易税费征管过渡期。县矿征办原抽调的单位人员继续留用，职能转为监督乡镇管理矿山及矿产品的运输情况和执行矿产品交易税收征收情况，了解、掌握矿产企业税源及税收情况，督促矿产企业依时足额申报纳税。

2．磅秤、监测点的移交管理。县将现有的磅秤、监测点的资产和工作职能下移给属地乡镇政府，交接工作在2017年6月完成。在过渡期间，原磅秤、监测点聘用人员继续留用，乡镇指派工作人员熟悉、掌握磅秤、监测点管理工作。过渡期满后，乡镇管理的磅秤、监测点由乡镇指派1名公益一类以上人员带班工作，其他工作人员由乡镇统筹安排（可视情况进行社会聘用，但需列清聘请人员家庭、社会关系并报备县政府），社会聘请人员的工资待遇由乡镇造册报县政府审批后由县财政统一解决。

3．磅秤、监测点的职能作用。主要矿区的乡镇必须设立磅秤、监测点，矿产品必需凭证运输。矿产品须凭运输证到监测点登记备案，运输出境的矿产品须凭运输证到磅秤点进行登记磅秤。运输证由矿山企业到县矿征办领用、核销。乡镇管理的磅秤、监测点将磅秤数量按月结算，并报国、地税及县矿山监管部门。只有零散矿山的乡镇是否保留现有的磅秤、监测点，由属地乡镇报县矿征收办批准。如果不需要设立磅秤、监测点，必须报县矿征办审批，乡镇要结合当地实际与矿山企业定量定税，防止税源流失。

四、保障措施

（一）加强领导。为确保全县矿产品交易税费征管改革工作顺利推进并取得预期效果，县将成立由县政府领导班子成员担任组长的县矿产品交易税费征管工作领导小组，各有关职能部门负责人、乡镇镇（乡）长均为成员，全面统筹协调全县矿产品交易税费征管改革工作。各乡镇相应成立矿产品交易税费征管改革工作领导小组，政府主要负责同志担任组长，负责辖区内矿产品交易税费征管工作，并报县政府备案。

（二）加强督导。县矿征办要认真履行工作职责，负责拟定集中征管工作年度计划、收支预决算方案和各项管理制度；负责实时监测各矿产企业产量以及产量数据的传输、汇总和联网查询等相关工作；负责指导乡镇矿征办对辖区矿产企业税收及非税收入的征收管理工作；负责全县各矿产企业电子信息监控系统的管理与维护，确保系统正常运行；完成县委、县政府和县财政局交办的其他工作任务。同时，县矿征办要加强与相关职能部门的沟通联系，联动配合，形成合力，县国土资源局、公安局、安全监管局、能源矿产局等有关行政机关和相关乡镇要积极配合，大力支持，对妨碍征收管理工作人员执行公务的，依法从严处理，构成犯罪的，移交司法机关依法追究刑事责任。

（三）加强管理。对矿产企业不按规定及时足额交纳税收及非税收入的，依据有关规定，由县矿征办函告电力、公安等职能部门，对矿产企业实行限电、停止供应火工产品等行政措施，同时由相关部门依法强制执行或申请人民法院强制执行。矿产企业要自觉维护产量监控系统的正常运行，凡故意破坏监控设备，造成数据失真，或有搭桥、更换矿车、停电等弄虚作假行为逃避监控的，由县矿征办联合国税、地税部门按照《中华人民共和国税收征收管理法》等相关法律法规，对该矿产企业和相关责任人予以处罚。对行政执法人员徇私舞弊、玩忽职守或收受贿赂，造成税收及非税收入流失的，依法追究有关责任人的行政责任和纪律责任，构成犯罪的，由司法机关依法追究刑事责任。建立完善举报制度，对举报情况经查证属实的，对举报人给予适当奖励。

（四）加强巡查。县工作领导小组及职能部门要加强对全县矿产品交易税费征管工作的指导、巡查，特别是对乡镇磅秤、监测点的监管，强化税费征管，杜绝税源流失，增加财政收入。对巡查中发现的问题，要及时分析、研究、解决，并视情况需要报县政府决策，对人为过失问题一律追责到底。同时，县职能部门和乡镇要加大宣传力度，通过新闻媒体等宣传渠道，进一步提高税费征管认识，促进产业健康发展，加快县域经济发展进程。
