# 阳山县人民政府办公室关于印发阳山县贯彻落实市政府办公室2017年政务公开工作要点分工方案的通知

阳山县人民政府办公室关于印发阳山县贯彻

落实市政府办公室2017年政务公开

工作要点分工方案的通知

各乡镇人民政府，县政府各部门、各直属机构：

《阳山县贯彻落实市政府办公室2017年政务公开工作要点分工方案》已经县人民政府同意，现印发给你们，请结合实际认真贯彻执行。

各乡镇、各部门要结合实际制定具体工作措施，抓好落实。县政府办公室将根据市政府办公室的部署，适时对落实情况进行专项督查，组织开展第三方评估。
