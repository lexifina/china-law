# 阳山县人民政府办公室关于成立阳山县加强基层医疗卫生服务能力建设项目领导小组的通知

各乡镇人民政府，县政府有关部门、有关直属机构：

为进一步加强我县基层医疗卫生服务能力建设项目的组织领导，全面提升我县医疗卫生服务能力，经县人民政府研究，决定成立阳山县加强基层医疗卫生服务能力建设项目领导小组。组成人员如下：

组 长：廖敬华　　县委副书记、县长

副组长：潘文彬　　县委常委、常务副县长

林 怡　　副县长

成 员：陈向前　　县政府办公室副主任

汤建萍　　县编办主任

张有干　　县发展改革局局长

黄延安　　县经济和信息化局局长

梁海东　　县财政局局长

莫小玲　　县人力资源社会保障局局长

梁建恒　　县国土资源局局长

何　信　　县环境保护局局长

杨春晓　　县住房城乡建设局局长

蔡喜刚　　县卫生计生局局长

黄松发　　县林业局局长

钟志华　　县规划市政局局长

郭建军　　县国资办主任

领导小组下设办公室，设在县卫生计生局，由蔡喜刚兼任办公室主任，何志良（县卫生计生局）、张刚庆（县人民医院）、李建雄（县中医院）、古晏鸿（县妇幼保健计划生育服务中心）担任办公室副主任，负责基层医疗卫生服务能力建设项目日常工作。

阳山县人民政府办公室
