# 阳山县人民政府办公室关于调整阳山县创建国家农产品质量安全县建设工作领导小组的通知

各乡镇人民政府，县政府有关部门、有关直属机构：

根据工作需要和人事变动，经县人民政府研究，决定调整阳山县创建国家农产品质量安全县建设工作领导小组成员。调整后的成员名单如下：

组 长：廖敬华 县委副书记、县长

常务副组长：杨坚强 副县长

副 组 长：邓奕彬 县政府办公室副主任

梁文锋 县科技农业局局长

成 员：唐志荣 县委宣传部副部长

王胜林 县检察院副检察长

张有干 县发展改革局局长

黄延安 县经济和信息化局局长

钟通理 县公安局政委

梁海东 县财政局局长

何 信 县环境保护局局长

马维新 县科技农业局副局长

戴金绍 县信息中心主任

卓战敏 县广播电视台党组成员

各乡镇镇（乡）长均为成员。

领导小组下设办公室和技术支持组，由梁文锋同志兼任办公室主任，杨永芳同志兼任技术支持组组长。办公室和技术支持组工作人员由相关单位人员组成。
