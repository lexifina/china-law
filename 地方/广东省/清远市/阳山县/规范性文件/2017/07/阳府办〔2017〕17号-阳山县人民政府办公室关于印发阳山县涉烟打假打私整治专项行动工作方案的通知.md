# 阳山县人民政府办公室关于印发阳山县涉烟打假打私整治专项行动工作方案的通知

各乡镇人民政府，县政府各部门、各直属机构：

《阳山县涉烟打假打私整治专项行动工作方案》已经县人民政府同意，现印发给你们，请认真抓好组织实施。实施中遇到的问题，请径向县打假办、打私办反映。

联系电话：7801977，邮箱：496173730@qq.com

阳山县人民政府办公室

2017年7月20日

阳山县涉烟打假打私整治专项行动工作方案

为落实《广东省推进涉烟打假打私工作方案》有关要求，严厉打击烟草制假售假、走私贩私违法行为，抓好重点地区和突出问题的整治，维护我县卷烟市场正常经营秩序，制定本工作方案。

一、工作目标

健全烟草打假打私长效工作机制，严格落实涉烟打假打私综治工作责任制。查处一批烟草制假售假、走私贩私大要案，树立典型，形成震慑。全面落实市场清理整治要求，保持烟草打假打私高压态势，不断提升市场净化水平。

二、重点任务和责任分工

（一）充分利用网络、报纸、户外标语、烟草零售户培训等形式和渠道，在居民社区、商业中心、交通枢纽等人流密集地区，加强对烟草专卖法律法规、典型案件及涉烟违法社会危害的宣传。完善举报奖励制度，公开举报电话，畅通举报渠道，提高举报奖励力度，鼓励、支持消费者依法维权，发挥社会公众监督作用，凝聚社会打击合力，推进社会共治。（县烟草专卖局牵头，县打假、打私部门配合）

（二）加强对持有烟草专卖零售许可证经营户的监管，全面查处销售假烟、走私烟违法行为。加大对擅自收购烟叶、无烟草专卖生产企业许可证非法生产烟草专卖品、无准运证非法运输烟草专卖品等违法行为的查处力度，有针对性地开展专项整治。（县烟草专卖局牵头，县公安局、县交通运输局、县市场监管局配合）

（三）加大对无烟草专卖零售许可证销售卷烟违法行为打击力度，对非法印制卷烟商标标识、包装物等违法行为开展专项整治。（县烟草专卖局牵头，县公安局、县市场监管局配合）

（四）加强对道路货物运输经营活动监管，有效切断非法卷烟及原辅材料的运输通道，严厉打击货运场（站）、货物集散地等物流场所非法中转分销卷烟行为，研究制定具体监管措施。（县交通运输局牵头，县公安局、县烟草专卖局配合）

（五）开展对邮政、快递企业的执法检查，严厉打击邮件、快递渠道非法寄递卷烟违法行为，推动寄递企业严格落实邮件、快递实名收寄和收寄验视制度，对不执行相关制度的寄递企业进行查处并责令限期整改。（县邮政集团公司阳山县分公司牵头，县公安局、县烟草专卖局配合）

（六）加强网络交易平台监管，利用大数据分析技术，及时发现和掌握违法线索，对利用互联网搜索引擎和网上商城、微信、QQ群等网络工具非法销售卷烟及原辅材料行为，及时开展专项整治，研究制定规范网络交易平台的具体监管措施。（县市场监管局牵头，县公安局、县烟草专卖局配合）

（七）根据卷烟走私动态，对重点渠道、重点地区采取严厉监管措施，将打击卷烟走私作为国门利剑及打击应节商品走私等联合行动的重点，有针对性地组织区域性打击卷烟走私专项行动。（县打私办牵头，县公安局、县市场监管局、县烟草专卖局配合）

（八）深化情报导侦技术和手段运用，广泛收集情报线索，强化案件经营，按照“打团伙、破网络、抓主犯”要求，深挖涉烟违法行为背后利益链条，加大对涉烟违法犯罪团伙主犯、骨干的追逃、打击力度，集中力量侦办一批涉烟违法大案要案，有力震慑违法犯罪分子，严防涉烟违法犯罪活动反弹蔓延。（县公安局牵头，县市场监管局、县烟草专卖局配合）

（九）进一步完善涉烟打假打私行政执法与刑事司法衔接工作机制，及时将符合《广东省行政执法与刑事司法衔接信息共享平台工作办法》规定的所有案件录入“两法衔接”数据平台，强化数据有效应用，推动解决有案不移、以罚代刑等问题。严查涉烟违法犯罪案件背后的玩忽职守、滥用职权、徇私舞弊、帮助犯罪分子逃避处罚等犯罪行为。（县检察院牵头，县公安局、县交通运输局、县市场监管局、县邮政集团公司阳山县分公司、县烟草专卖局配合）

三、保障措施

（一）健全部门联动工作机制。建立县打假、打私部门间联席会议制度，负责研究部署打假打私重点工作、督促各部门落实打假和打私综治工作责任制、协调查处跨地区跨部门违法案件、组织督导重点案件查处和重点区域专项整治。

（二）加大经费支持和奖励力度。烟草部门依据涉烟打假打私经费管理相关政策，为有关部门开展涉烟打假打私专项行动、侦办涉烟违法犯罪案件、处置罚没非法烟草专卖品等提供必要的经费支持；对参与涉烟打假打私专项行动、侦破符合省部级标准的涉烟打假打私网络案件和督办案件的有功人员给予奖励，对举报有功人员按照相关标准及时、全额支付举报奖励。

（三）强化信息报送和督查考核。县打假、打私办成员单位于每月1日前将上月涉烟打假打私统计数据、重点案件和经验做法等信息分别报送县打假办和县打私办，按时汇报专项行动进展情况，重点案件、经验做法要及时上报。

下一步，县政府将加强对打假和打私综治工作责任制考核，加大烟草打假打私权重，将责任制考核纳入创建平安阳山暨社会治安综合治理工作考评。各相关部门落实打假和打私综治工作责任制情况将列入县政府督查事项，县打假办、打私办将适时组织开展联合督查。

县各牵头部门要围绕工作目标和突出问题，出台具体监管措施，组织本部门在全县范围内开展专项整治行动。各乡镇人民政府、牵头部门要于本工作方案印发15日内，将本地、本部门涉烟打假打私专项整治方案分别报送县打假办和县打私办备案。
