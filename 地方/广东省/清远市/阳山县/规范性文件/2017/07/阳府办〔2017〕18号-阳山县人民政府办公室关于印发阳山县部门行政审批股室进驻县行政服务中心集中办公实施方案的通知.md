# 阳山县人民政府办公室关于印发阳山县部门行政审批股室进驻县行政服务中心集中办公实施方案的通知

阳山县人民政府办公室关于印发阳山县部门

行政审批股室进驻县行政服务中心

集中办公实施方案的通知

各乡镇人民政府，县政府各部门、各直属机构：

《阳山县部门行政审批股室进驻县行政服务中心集中办公实施方案》已经县人民政府同意，现印发给你们，请认真贯彻执行。执行过程中遇到的问题，请径向县行政服务中心反映。

阳山县人民政府办公室

2017年7月31日

阳山县部门行政审批股室进驻

县行政服务中心集中办公实施方案

为加快政府职能转变，切实提升服务效能，建设服务型政府，根据《清远市人民政府办公室关于印发清远市推进行政审批“两集中、三到位”工作实施方案的通知》（清府办〔2014〕14号）和《阳山县人民政府办公室关于印发阳山县推广“一门式、一网式”政府服务模式改革实施方案的通知》（阳府办〔2016〕10号）精神，经县政府和相关部门研究，决定将本县具有行政审批职能单位的审批股室进驻县行政服务中心集中办公。为确保各项工作顺利进行，制定本方案。

一、指导思想

深入贯彻落实党的十八大和习近平总书记系列重要讲话精神，积极转变政府职能，不断提高办事效率和服务质量。坚持“简化高效、便民利民、注重实效”的原则，深入推进行政审批制度改革，建立行为规范、运行协调、公正廉洁的行政审批制度，全力打造服务型政府新平台，为我县“三个全域，两大攻坚”战略行动和经济社会更好更快发展提供优质的政务服务环境。

二、工作目标

落实行政审批“两集中、三到位”关于行政审批股室向行政服务中心集中的工作要求，将全县26个具有行政审批职能单位的审批股室进驻县行政服务中心集中办公（详见附件1），并做到审批权限授权到位、审批事项集中到位、审批过程监督到位。

三、工作内容

（一）职能归并。根据县编办《关于落实行政审批“两集中、三到位”工作的通知》（阳机编办〔2016〕33号），各单位要将所承担的行政审批职能集中归并到行政审批股，落实行政审批职能向一个股室集中的工作要求。相关职能归并或审批权限授权的文件于2017年8月4日前通过阳山县电子政务云平台（OA）报县行政服务中心备案。

（二）审管分离。各单位审批职能整合归并后，行政审批股负责本单位的行政审批事项和公共服务事项的承办、审核、办结和上报。审批事项需现场踏勘、审图、专家论证和审查的，由单位组织实施。各单位要建立完善的管理制度，形成“审管分离、责权并重、公开透明、廉洁高效”的行政审批运行机制。

（三）双重管理。进驻县行政服务中心的行政审批股室工作人员受所属单位和县行政服务中心双重管理。人事关系和工资福利待遇等保留在所属单位，日常工作和纪律执行由县行政服务中心统一管理。

（四）场所配置。县行政服务中心负责为各审批股室配置办公场所。县信息中心做好办公区域系统网络的铺设和管理，涉及到专网办理审批事项的由进驻部门自行完成铺设。

（五）配强人员。各单位要明确负责审批业务的分管领导和股室负责人。进驻县行政服务中心的审批股室原则上不再承担原单位的其它工作，股室工作人员要保持相对稳定，因人事、工作等需要调整的，由所属单位提出调整建议，征得县行政服务中心同意后方可实施。

四、时间安排

各单位要主动联系县行政服务中心，协商进驻的具体时间和办公场所配置等事宜。进驻工作须在2017年8月30日前完成。

五、工作要求

（一）统一思想，加强领导。行政审批股室进驻县行政服务中心集中办公是县委、县政府优化政府公共服务环境的一项重要工作决策，有利于政府及部门加快转变职能，提高行政效率和公信力，更好地为人民群众提供政务服务。各单位要把思想统一到县委、县政府的决策上来，切实把这项工作抓好落实。单位“一把手”要亲自抓、负总责，精心组织，周密部署，确保人员和工作落到到位。

（二）互相配合，各司其职。部门行政审批股室进驻县行政服务中心集中办公是一项系统性工作，各相关部门要相互配合，各司其职，各尽其责。县政府督查室要加强督查、跟踪督办；县监察局要加强行政效能监察，对工作滞后的单位要跟踪督查，对有令不行、阳奉阴违、不按期完成工作的单位和责任人，按照有关规定予以责任追究。
