# 阳山县人民政府办公室转发广东省人民政府办公厅关于广东省电线电缆产品专项整治工作方案的通知

阳山县人民政府办公室转发广东省人民政府

办公厅关于广东省电线电缆产品

专项整治工作方案的通知

各乡镇人民政府，县政府有关部门、有关直属机构：

现将《广东省人民政府办公室关于印发广东省电线电缆产品专项整治工作方案的通知》（粤办函〔2017〕420号）转发给你们，请认真贯彻执行。

开展电线电缆产品专项整治工作是加强对获证企业监管的重要方式，各乡镇、各有关部门要高度重视，按照省电线电缆产品专项整治工作方案要求，加强组织领导，密切协助配合，实施对电线电缆生产、销售、使用的全链条监管，全面清查问题电线电缆，消除质量安全隐患，确保人民群众生命财产安全。
