# 阳山县人民政府办公室关于成立阳山县创建广东省森林小镇及国家森林特色小镇工作领导小组的通知

阳山县人民政府办公室关于成立阳山县

创建广东省森林小镇及国家森林

特色小镇工作领导小组的通知

各乡镇人民政府，县政府有关部门、有关直属机构：

为进一步加强我县创建广东省森林小镇及国家森林特色小镇工作的组织领导，经县人民政府研究，决定成立阳山县创建广东省森林小镇及国家森林特色小镇工作领导小组。组成成员如下：
