# 阳山县人民政府办公室关于成立阳山县城市管理委员会的通知

各乡镇人民政府，县政府各部门、各直属机构：

为进一步加强我县城市管理工作，统筹协调解决城市管理中的重大问题，实现城市管理高效运作，县人民政府决定成立阳山县城市管理委员会。成员名单如下：
