# 阳山县机构编制委员会办公室关于印发保留为县政府部门行政审批必要条件的中介服务事项清单(2017年版)的通知

县直有关单位：

《保留为县政府部门行政审批必要条件的中介服务事项清单（2017年版）》已经县人民政府同意，现印发给你们。为深入推进我县“放管服”改革，规范行政审批中介服务，提高行政效能，提出如下意见，请一并贯彻执行。

一是严格执行清单管理制度。本次公布的52项行政审批中介服务事项清单，包括事项名称、设定依据、实施机构、机构性质、服务时限等要素。清单公布后，凡未纳入清单的中介服务事项，一律不得作为行政审批受理条件实施，并且在推行行政审批标准化过程中，一律不得在申请材料和审批条件中提出相关中介服务要求。

二是及时公开清单。各部门要在本通知印发后10个工作日内，在本部门门户网站和网上办事大厅公开本部门正在实施的行政审批中介服务事项清单，并接受社会监督。同时，要认真听取社会各方面对相关中介服务事项进一步清理规范的意见建议，对取消后能更有利于激发市场活力和社会创造力、增强经济发展内生动力的事项，应进一步加大取消力度；对改由审批部门委托开展技术服务后更有利于降低制度性交易成本、提高行政审批效率的事项，应进一步减轻企业负担。

三是对清单实行动态管理。各部门行政审批中介服务事项清单公布后，要根据法律、法规和规章的立改废释以及国家和省的改革要求实行动态调整。动态调整包括行政审批中介服务事项的增加、取消和要素变更等情形，具体由各部门向县编办提出，并由县编办按程序办理。

四是行政审批中介组织与主管部门脱钩。各部门要按照《阳山县清理规范县政府部门行政审批中介服务工作方案》（阳府办〔2016〕11号）精神，进一步梳理所属事业单位、主管的社会组织及其举办的企业开展行政审批中介服务的情况，对所属（主管）单位开展与本部门行政审批相关中介服务的，应转企改制或与主管部门脱钩。其中，对专业性强、市场暂时无力承接、短期内仍需由所属事业单位开展相关中介服务的，审批部门必须提出改革方案，明确过渡期限，于2017年 12月 31日前报县编办。

五是强化监督管理。各行业主管部门要制定完善行政审批中介服务的规范和标准，强化中介机构的法律责任，并依法加强对本行业中介机构及从业人员执业行为的监管，严格查处故意拖延时间、巧立名目乱收费、出具虚假证明或报告等谋取不正当利益、扰乱市场秩序的违法违规行为。
