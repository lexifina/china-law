# 阳山县机构编制委员会办公室关于第二批清理规范县政府部门行政审批中介服务事项的通知

县直有关单位：

为进一步深化行政审批制度改革，加快政府职能转变，经县人民政府同意，现对第二批14项县政府部门行政审批中介服务事项清理规范，不再作为行政审批的受理条件。

各有关单位要认真做好行政审批中介服务事项的清理规范工作，加快推进配套改革和相关制度建设，加强事中事后监管，保障行政审批质量和效率。对政府部门在审批过程中委托开展的技术性服务活动，必须通过竞争方式选择服务机构，切实落实国家和省出台的服务经费保障措施。对涉及公共安全的行政审批事项，要在清理规范相关中介服务后，进一步强化监管措施，确保安全责任落实到位。
