# 阳山县人民政府办公室关于建立阳山县城市管理工作联席会议制度的通知

各乡镇人民政府，县政府各部门、各直属机构：

为加强城市管理部门之间的沟通协调，及时研究解决城市管理突出问题，部署城市管理重要工作，确保城市管理各项任务落实到位，经县人民政府研究，决定建立阳山县城市管理工作联席会议制度（以下简称“联席会议”）。现将有关事项通知如下：

一、联席会议主要职责

贯彻落实国家、省、市及县委县政府关于加强城市管理的工作部署，统筹协调全县城市管理工作；研究制定全县城市管理中长期规划和促进城市管理的措施方针，协调解决制约我县城市管理工作的热点、难点问题；加强对深入推进城市管理执法体制改革、改进城市管理工作的督促指导、跟踪评估和分析总结；加强重大改革事项的政策宣传，营造良好的舆论氛围；研究部署县委、县政府交办的其他城市管理工作重大事项。

二、组成人员

联席会议组成人员为阳山县城市管理委员会（以下简称“县城管委”）成员单位主要负责人、市民代表。研究具体工作事项时，可视情况召集部分成员参加会议，也可邀请其他单位和专家参加会议。

三、工作规则

（一）根据我县城市管理工作实际和阶段性工作重点，由县城管委主任或主任委托的副主任主持召开，原则上每季度召开一次，根据工作需要，可临时召开会议。联席会议日常工作由县城管委办公室承担，负责对联席会议有关工作的准备、确定会议时间、地点、参加对象等有关事项的联络安排。

（二）各参会单位要按照会议的议程和要求，提出需要会议协调解决的问题，并认真准备相关材料。需提交会议协调解决的重要事项，如内容涉及其他单位的，要在会前进行协商，并将协商情况在会前半个月以书面形式报县城管委办公室；对事先未经协商的事项，原则上不予安排上会。

（三）对会议议定的事项，由县城管委办公室负责形成会议纪要，报县城管委主任或副主任签发后印发执行。各单位在执行中发现问题应及时向县城管委办公室反馈。落实情况由县城管委办公室负责督促检查，并向县城管委主要领导报告。

（四）联席会议可以通过邀请公众旁听，或以广播、电视、网络直播等形式向社会公开审议过程。

（五）每次会议的会议资料均属政府内部文件，由县城管委办公室按要求统一保管。除县城管委主任或副主任同意，否则任何人不得以任何方式获取或向他人直接或间接传送有关资料。

（六）联席会议制度的修改程序为：由于形势发展需要修改时，由县城管委全体会议讨论并经三分之二以上委员通过方可生效。修改后的联席会议制度报县政府备案。

四、工作要求

各成员单位要严格按照联席会议制度的要求，认真落实联席会议议定事项，主动研究我县城市管理工作面临的困难和问题。部门间要加强沟通，互相配合，共同推进全县城市管理工作。

阳山县人民政府办公室
