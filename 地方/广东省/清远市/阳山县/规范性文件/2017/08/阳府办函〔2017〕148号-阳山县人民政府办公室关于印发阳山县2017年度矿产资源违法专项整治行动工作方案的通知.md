# 阳山县人民政府办公室关于印发阳山县2017年度矿产资源违法专项整治行动工作方案的通知

阳山县2017年度矿产资源违法

专项整治行动工作方案的通知

各乡镇人民政府，县政府有关部门、有关直属机构：

《阳山县2017年度矿产资源违法专项整治行动工作方案》已经县人民政府同意，现印发给你们，请遵照执行。执行中遇到的问题，请径向县国土资源局反映。

阳山县人民政府办公室

2017年8月30日

阳山县2017年度矿产资源违法

专项整治行动工作方案

今年以来，据国土部门巡查和群众反映情况，我县矿产资源违法行为仍然存在。为遏制矿产资源违法行为的势头，有效打击矿产资源违法行为，根据《中华人民共和国矿产资源法》和《中华人民共和国矿产资源法实施细则》等规定，特制订本工作方案。

一、总体要求

全面掌握矿产违法违规情况，有效打击矿产资源违法行为，严肃查处整改违法开采行为，遏制矿产资源违法行为的势头，维护法律的严肃性，确保矿产资源有序开发，促进我县经济社会和谐发展。

二、工作步骤

（一）摸底阶段。各乡镇根据土地变更调查、动态巡查和群众线索举报发现的情况，结合省国土资源厅下发的矿产疑似违法图斑数据，认真调查存在的各类违法勘查、违法开采矿产资源行为。迅速开展外业核实工作，逐项填表，及时上交数据，确保数据统计分析的准确性和客观性。各乡镇已将相关统计报表报送县国土资源局，县国土资源局汇总后形成初步核查数据报县政府。

（二）查处阶段（7月8日至11月30日）。县有关职能部门会同各乡镇政府，对违法勘查开采矿产资源问题，依照矿产资源管理等法律法规进行查处。该立案的坚决立案、该复绿的坚决复绿（复绿质量由县林业、农业部门负责检查验收）、该移送的坚决移送，处理事和处理人都要到位。每次行动后，及时向县政府汇报。

（三）整改阶段（12月1日至12月30日）。各乡镇政府负责对当地违法开采矿产点进行复耕复绿，县有关职能部门对各乡镇的复耕复绿工作情况进行检查验收。对不能通过验收的乡镇，由县领导约谈该乡镇主要领导，并限期整改。同时，各乡镇人民政府要大力协助县国土资源局开展矿产管理工作，对已申领矿产开采许可证的矿山要求种植界线桩，并敦促辖区内的矿山企业支持配合，形成齐抓共管新格局。

三、工作要求

（一）高度重视，加强领导。2017年度矿产资源违法专项整治行动面广量大，任务艰巨，必须落实政府组织、部门联动的工作机制，细化任务分工，强化工作责任。为切实加强检查工作的组织领导，协调解决执法检查的有关问题，确保按时保质完成各项工作任务，县政府成立2017年度矿产资源违法专项整治行动工作领导小组，由县政府分管副县长任组长，成员由县国土资源局、林业局、公安局、科技农业局、环境保护局、安全监管局等部门负责人组成。领导小组下设办公室（设在县国土资源局），负责专项行动的各项日常工作。

（二）协调沟通，凝聚合力。各乡镇政府与县有关部门要加强协调沟通，密切配合，凝聚合力，有序开展专项行动工作。在收到行动指令后，必须按照行动具体要求，安排好人员、车辆参与，在行动过程中，听从指挥人员的工作安排和调配。同时，各乡镇政府要做好后勤保障工作。

（三）落实措施，认真整改。

1．对非法采矿点(厂)进行查封，限期复垦土地（耕地），恢复植被，消除地质灾害隐患。依法强制扣押、没收、拆除采矿机械和没收非法矿产品，对妨碍强制执行的一律予以拘留，情节严重的，移送司法机关追究刑事责任。

2．对非法采矿点（厂）切断电源，拆除电力供应设备设施，依法追究违法供电相关人员的责任，并采取封闭非法采矿点（厂）所有进出道路的方式，避免违法行为死灰复燃。

3．对整治矿点实行“三不留，一毁闭”（即不留人员，不留采矿设备，不留建筑物；毁闭开采面，恢复地貌），每个非法矿点整治后，要加强监管，落实具体镇村组三级责任人，公开监督举报电话，并制作公示牌予以警示。

（四）加强宣传，营造氛围。各乡镇各部门在行动完成后，要做好查缺补漏、及时总结。县广播电视台要及时收集、播出专项行动的新闻信息。各乡镇政府和县有关部门要通过官方网站、微信、公告栏等渠道，采用典型案例剖析、加挂宣传横额、派发法律知识手册等方式，加强宣传，营造和谐的矿产资源管理氛围。
