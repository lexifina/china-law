# 阳山县人民政府关于划定阳山冬绿香牌淮山生态原产地产品保护范围的通告

为有效保护阳山冬绿香牌淮山品牌、生产者和消费者利益，根据《生态原产地产品保护评定通则》，划定的阳山冬绿香牌淮山生态原产地产品保护范围为阳山县辖区七拱镇。具体保护范围是东经112&deg;23&prime;27&Prime;至112&deg;41&prime;30&Prime;，北纬24&deg;14&prime;17&Prime;至24&deg;20&prime;55&Prime;。
