# 阳山县人民政府关于划定阳山水时光牌包装饮用水生态原产地产品保护范围的通告

为有效保护阳山水时光牌包装饮用水品牌、生产者和消费者利益，根据《生态原产地产品保护评定通则》，划定的阳山水时光牌包装饮用水生态原产地产品保护范围为阳山县辖区杜步镇。具体保护范围是东经112&deg;37&prime;12&Prime;至112&deg;43&prime;54&Prime;，北纬24&deg;13&prime;34&Prime;至24&deg;22&prime;17&Prime;。水时光牌包装饮用水生产地址：广东省清远市阳山县杜步镇旱坑村委会坝头天子公。

特此通告。
