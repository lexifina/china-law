# 阳山县人民政府关于划定阳山洞冠牌晶宝梨生态原产地产品保护范围的通告

为有效保护阳山洞冠牌晶宝梨品牌、生产者和消费者利益，根据《生态原产地产品保护评定通则》，划定的阳山洞冠牌晶宝梨生态原产地产品保护范围为阳山县辖区黎埠镇。具体保护范围是东经112&deg;22&prime;55&Prime;至112&deg;30&prime;83&Prime;，北纬24&deg;29&prime;15&Prime;至24&deg;30&prime;46&Prime;。
