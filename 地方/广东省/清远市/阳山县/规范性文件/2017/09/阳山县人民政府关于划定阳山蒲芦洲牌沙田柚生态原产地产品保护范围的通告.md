# 阳山县人民政府关于划定阳山蒲芦洲牌沙田柚生态原产地产品保护范围的通告

为有效保护阳山蒲芦洲牌沙田柚品牌、生产者和消费者利益，根据《生态原产地产品保护评定通则》，划定的阳山蒲芦洲牌沙田柚生态原产地产品保护范围为阳山县辖区岭背镇。具体保护范围是东经112&deg;40&prime;18&Prime;至112&deg;49&prime;39&Prime;，北纬24&deg;24&prime;95&Prime;至24&deg;40&prime;41&Prime;。
