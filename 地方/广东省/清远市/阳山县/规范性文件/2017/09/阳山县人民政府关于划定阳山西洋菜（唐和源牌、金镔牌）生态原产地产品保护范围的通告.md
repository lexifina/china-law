# 阳山县人民政府关于划定阳山西洋菜（唐和源牌、金镔牌）生态原产地产品保护范围的通告

阳山县人民政府关于划定阳山西洋菜

（唐和源牌、金镔牌）生态原产地

产品保护范围的通告

为有效保护阳山西洋菜（唐和源牌、金镔牌）品牌、生产者和消费者利益，根据《生态原产地产品保护评定通则》，划定的阳山西洋菜（唐和源牌、金镔牌）生态原产地产品保护范围为阳山县辖区小江镇、黎埠镇、江英镇、秤架乡。具体保护范围是小江镇（东经112&deg;31&prime;67&Prime;至112&deg;38&prime;62&Prime;，北纬24&deg;31&prime;27&Prime;至24&deg;40&prime;33&Prime;）；黎埠镇（东经112&deg;22&prime;55&Prime;至112&deg;30&prime;83&Prime;，北纬24&deg;29&prime;15&Prime;至24&deg;30&prime;46&Prime;）；江英镇（东经112&deg;45&prime;53&Prime;至112&deg;57&prime;35&Prime;，北纬24&deg;28&prime;37&Prime;至24&deg;41&prime;36&Prime;）；秤架乡（东经112&deg;40&prime;47&Prime;至113&deg;01&prime;06&Prime;，北纬24&deg;40&prime;47&Prime;至24&deg;58&prime;47&Prime;）。
