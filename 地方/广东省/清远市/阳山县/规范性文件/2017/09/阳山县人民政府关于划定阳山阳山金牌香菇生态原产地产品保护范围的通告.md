# 阳山县人民政府关于划定阳山阳山金牌香菇生态原产地产品保护范围的通告

为有效保护阳山阳山金牌香菇品牌、生产者和消费者利益，根据《生态原产地产品保护评定通则》，划定的阳山阳山金牌香菇生态原产地产品保护范围为阳山县辖区大崀镇、江英镇、黎埠镇、秤架乡、阳城镇、岭背镇、青莲镇。具体保护范围是大崀镇（东经112&deg;26&prime;27&Prime;至112&deg;31&prime;44&Prime;，北纬24&deg;24&prime;39&Prime;至24&deg;29&prime;11&Prime;）；江英镇（东经112&deg;45&prime;53&Prime;至112&deg;57&prime;35&Prime;，北纬24&deg;28&prime;37&Prime;至24&deg;41&prime;36&Prime;）；黎埠镇（东经112&deg;22&prime;55&Prime;至112&deg;30&prime;83&Prime;，北纬24&deg;29&prime;15&Prime;至24&deg;30&prime;46&Prime;）；秤架乡（东经112&deg;40&prime;47&Prime;至113&deg;01&prime;06&Prime;，北纬24&deg;40&prime;47&Prime;至24&deg;58&prime;47&Prime;）；阳城镇（东经112&deg;33&prime;42&Prime;至112&deg;40&prime;88&Prime;，北纬24&deg;21&prime;23&Prime;至24&deg;30&prime;42&Prime;）；岭背镇（东经112&deg;40&prime;18&Prime;至112&deg;49&prime;39&Prime;，北纬24&deg;24&prime;95&Prime;至24&deg;40&prime;41&Prime;）；青莲镇（东经112&deg;45&prime;64&Prime;至112&deg;53&prime;39&Prime;，北纬24&deg;23&prime;20&Prime;至24&deg;29&prime;54&Prime;）。
