# 阳山县人民政府关于划定阳山阳山鸡（江英鸡牌、旭通牌、冠黄牌）生态原产地产品保护范围的通告

阳山县人民政府关于划定阳山阳山鸡

（江英鸡牌、旭通牌、冠黄牌）

生态原产地产品保护范围的通告

为有效保护阳山阳山鸡（江英鸡牌、旭通牌、冠黄牌）品牌、生产者和消费者利益，根据《生态原产地产品保护评定通则》，划定的阳山阳山鸡（江英鸡牌、旭通牌、冠黄牌）生态原产地产品保护范围为阳山县辖区青莲镇、江英镇。具体保护范围是青莲镇（东经112&deg;45&prime;64&Prime;至112&deg;53&prime;39&Prime;，北纬24&deg;23&prime;20&Prime;至24&deg;29&prime;54&Prime;）；江英镇（东经112&deg;45&prime;53&Prime;至112&deg;57&prime;35&Prime;，北纬24&deg;28&prime;37&Prime;至24&deg;41&prime;36&Prime;）。
