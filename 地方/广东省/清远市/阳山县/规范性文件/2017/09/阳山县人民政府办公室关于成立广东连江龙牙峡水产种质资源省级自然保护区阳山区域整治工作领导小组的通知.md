# 阳山县人民政府办公室关于成立广东连江龙牙峡水产种质资源省级自然保护区阳山区域整治工作领导小组的通知

阳山县人民政府办公室关于成立广东连江

龙牙峡水产种质资源省级自然保护区

阳山区域整治工作领导小组的通知

各乡镇人民政府，县有关单位：

为做好广东连江龙牙峡水产种质资源省级自然保护区阳山区域自查整改工作，促进渔业保护区管理工作规范化和法治化，经县人民政府研究，决定成立广东连江龙牙峡水产种质资源省级自然保护区阳山区域整治工作领导小组。组成人员如下：
