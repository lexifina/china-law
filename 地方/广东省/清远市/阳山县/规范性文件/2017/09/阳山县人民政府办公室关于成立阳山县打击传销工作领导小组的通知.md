# 阳山县人民政府办公室关于成立阳山县打击传销工作领导小组的通知

各乡镇人民政府，县政府各部门、各直属机构：

根据打击传销工作的实际需要，经县人民政府同意，成立阳山县打击传销工作领导小组，负责领导、组织、协调、督导全县打击传销工作。其组成人员名单如下：
