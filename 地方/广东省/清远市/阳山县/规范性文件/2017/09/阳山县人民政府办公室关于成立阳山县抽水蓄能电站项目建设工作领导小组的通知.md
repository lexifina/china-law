# 阳山县人民政府办公室关于成立阳山县抽水蓄能电站项目建设工作领导小组的通知

各乡镇人民政府，县直各有关单位：

为推进我县“全域绿色能源开发”战略，加快绿色能源开发步伐，顺利推进抽水蓄能电站项目建设工作，经县人民政府研究，决定成立阳山县抽水蓄能电站项目建设工作领导小组。组成人员如下：

组 长：潘文彬　　县委常委、常务副县长

副组长：朱昭阳　　副县长

杨坚强　　副县长

成 员：邓奕彬　　县政府办公室副主任

张有干　　县发展改革局局长

梁文锋　　县科技农业局局长

梁海东　　县财政局局长

梁建恒　　县国土资源局局长

何 信　　县环境保护局局长

麦明华　　县交通运输局局长

黄松发　　县林业局局长

张源泉　　县水务局局长

钟志华　　县规划市政局局长

何国华　　阳山供电局局长

何俊斌　　阳城镇镇长

蓝 涛　　七拱镇镇长

李水祥　　县兴阳实业公司总经理

领导小组下设办公室，设在县水务局，由麦明杰（县水务局副局长）任办公室主任，梁洪波（县水务局机电股股长）、梁旋光（县兴阳实业公司副总经理）任办公室副主任，负责领导小组日常工作。
