# 阳山县人民政府办公室关于成立2017年广东省第七届登山节暨阳山乡村旅游文化活动领导小组的通知

阳山县人民政府办公室关于成立2017年

广东省第七届登山节暨阳山乡村

旅游文化活动领导小组的通知

各乡镇人民政府，县政府各部门、各直属机构：

为确保2017年广东省第七届登山节暨阳山乡村旅游文化活动系列活动顺利进行，县政府决定成立2017年广东省第七届登山节暨阳山乡村旅游文化活动领导小组。成员名单如下：
