# 阳山县人民政府办公室关于印发阳山县瓶装液化石油气专项整治行动实施方案的通知

各乡镇人民政府，县政府有关部门、有关直属机构：

《阳山县瓶装液化石油气专项整治行动实施方案》已经县人民政府同意，现印发给你们，请认真组织实施。

阳山县人民政府办公室

2017年10月26日

阳山县瓶装液化石油气专项整治行动实施方案

根据省、市、县安全生产工作部署和《广东省人民政府关于印发广东省气瓶安全监管改革方案的通知》（粤府函〔2017〕134号）、《广东省安全生产委员会办公室关于进一步加强危险化学品安全生产工作的紧急通知》（粤安办〔2017〕73号）、《清远市安全生产委员会关于印发〈清远市安全生产大检查工作实施方案〉的通知》（清安〔2017〕14号）等文件精神，为加强液化石油气流通环节的监督管理，严厉打击非法运输、储存、销售瓶装燃气违法行为，规范城镇燃气经营秩序，及时消除城镇燃气安全隐患，保障民众生命、财产安全，结合我县实际，制定本方案。

一、整治范围

在全县范围内从事瓶装液化石油气经营的单位和个人，瓶装液化石油气送气服务人员。

二、整治重点

（一）将充装好的瓶装液化石油气气瓶从周边地区运入本县进行非法销售。

（二）利用民房、租赁场所、废弃车辆等隐秘场所非法储存、倒灌、分装、销售瓶装液化石油气。

（三）充装过期钢瓶、以次充好、缺斤少两、假冒伪劣等损坏消费者利益的行为。

（四）未领取《燃气供应许可证》私自设立供应点或《燃气供应许可证》年检不合格（失效后）仍继续从事瓶装液化石油气供应活动。

（五）向无资质的单位或个人供应用于销售的液化石油气。

（六）在液化石油气中掺入二甲醚的行为。

（七）在村居流动倒卖倒灌液化石油气的行为。

三、整治步骤

整治活动从10月26日至12月30日，分三个阶段实施。

（一）调查排摸阶段（10月26日至11月10日）。研究制定活动方案，召开整治活动动员会议，建立整治行动指挥部，成立联合整治行动组，明确工作责任。各乡镇、各有关部门对整治对象进行调查摸排，收集掌握非法经营场所的地址、线路、时间、经营动态等信息。做好集中整治工作宣传，通过电视、广播、宣传单、宣传标语等多种宣传方式，全方位、多角度作好宣传发动工作，调动广大市民参与的积极性，营造全社会共同打击液化石油气非法经营行为的良好氛围。

（二）联合执法阶段（10月11日至11月30日）。联合整治行动组集中开展联合执法行动，对存在非法经营液化石油气行为的单位和个人，以及违法从事瓶装液化石油气送气服务人员，将按照相关规定从严从重进行查处。

（三）巩固提高阶段（12月1日至12月30日）。全面复查，巩固成果，对联合整治活动进行总结，完善相关工作措施，针对液化石油气经营市场的难点、热点问题，建立部门联合执法、日常网格监管、突击检查、投诉举报等机制。各乡镇要设立燃气安全管理机构，配备人员，负责各自辖区范围内的燃气安全工作，逐步建立液化石油气经营市场长效监管体系。

四、组织领导

为加强组织领导，推进整治工作顺利开展，成立联合整治工作领导小组。成员名单如下：

总 指 挥：周文华（副县长）

副总指挥：文 龙（县政府办公室副主任）

成 员：潘企祥（县交通运输局副主任科员）

梁国荣（县安全监管局副局长）

何青华（县市场监管局副局长）

曾素芬（县规划市政局副局长）

李天贵（县公安局交警大队大队长）

各乡镇分管安全生产的领导均为成员。

领导小组下设联合整治行动组和办公室。整治行动组由文龙兼任组长，负责召集成员单位开展联合整治行动，行动组组员从成员单位抽调业务骨干组成。领导小组办公室设在县规划市政局，由曾素芬兼任办公室主任，负责收集相关信息，为统一行动提供依据，并记录及汇总行动开展的情况。

县直成员单位将抽调人员、联络员名单（附件1），各乡镇将分管领导、联络员名单（附件2）于11月3日前通过电子政务系统（OA系统）报县规划市政局。

五、工作要求

（一）提高认识，加强领导。非法经营液化石油气具有极其严重的危害性，严重危害人民生命财产和社会公共安全，开展集中整治，是规范液化石油气经营市场秩序、促进液化石油气安全形势持续稳定的重要举措。各液化石油气经营企业要根据整治内容认真开展自查自纠，杜绝违规行为的发生。各乡镇、有关部门要高度重视，落实整治行动的具体工作责任，并加强液化石油气经营的安全监管工作。

（二）加强配合，形成合力。液化石油气监管是一项系统工程，各乡镇、有关部门要加强协作配合和信息互通，建立上下联动、部门联动、区域联动的工作机制，有效解决执法过程中的难点问题，确保本次联合整治活动有序开展。

（三）严格执法，取得实效。严厉打击液化石油气非法经营活动，对检查发现的非法经营行为，一律暂扣现场气瓶及其他非法物品，并对违法者予以行政处罚；对涉案的瓶装燃气运输车辆，由县交通部门予以查扣；对涉及暴力抗法和危害公共安全的，由县公安部门进行查处；发现液化石油气企业和送气服务人员存在违法违规行为的，暂扣其许可证或上岗资格证，由县市政部门按照规定从重进行处罚。

（四）堵疏结合，长效管理。在整治工作中，要坚持执法查处与整顿规范相结合、企业自律与部门监管相结合、集中整治与建立长效机制相结合，在对非法站点、非法行为整治的同时，强化对合法企业的安全监管，规范经营行为，逐步提升液化石油气经营市场规范化水平。
