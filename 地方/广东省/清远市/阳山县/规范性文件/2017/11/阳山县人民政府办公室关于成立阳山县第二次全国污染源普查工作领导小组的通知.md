# 阳山县人民政府办公室关于成立阳山县第二次全国污染源普查工作领导小组的通知

各乡镇人民政府，县政府各部门、各直属机构：

根据《国务院关于开展第二次全国污染源普查的通知》（国发〔2016〕59号）要求，县人民政府决定成立阳山县第二次全国污染源普查工作领导小组。组成人员如下：

组 长：周文华 副县长

副组长：文 龙 县政府办公室副主任

马文权 县环境保护局党组书记

邹华鹏 县统计局局长

成 员：唐志荣 县委宣传部副部长

陈伟坚 县发展改革局副局长

唐宇雄 县经济和信息化局副局长

梁带财 县科技农业局副局长

钟 衍 县公安局副局长

丘国庆 县财政局副局长

黄振杰 县国土资源局副局长

唐剑发 县环境保护局副局长

张文育 县住房城乡建设局副局长

潘企祥 县交通运输局副主任科员

何青华 县市场监管局副局长

吴东强 县水务局副局长

李志锋 县规划市政局副局长

黄国坤 县国税局副局长

陈志坚 县地税局副局长

何国厚 清远连江海事处副处长

领导小组下设办公室，设在县环境保护局，主要负责污染源普查工作的组织、统筹、指导、协调、监督、相关资料收集整理等工作。办公室主任由马文权同志兼任。

该领导小组待普查任务完成后自行撤销。

阳山县人民政府办公室

2017年11月3日
