# 阳山县人民政府关于公布阳山县2017年重大行政决策事项目录的通知

各乡镇人民政府，县政府各部门、各直属机构：

现将《阳山县2017年重大行政决策事项目录》予以公布，请按照《清远市人民政府重大行政决策程序规定》等规定认真组织实施，确保决策程序正当、过程公开、责任明确。

实施过程中遇到的问题，请径向县法制局反映。

阳山县人民政府

2017年12月29日
