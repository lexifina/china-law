# 阳山县人民政府办公室关于印发阳山县政府部门公共服务事项清单（2017年版）的通知

各乡镇人民政府，县政府各部门、各直属机构：

《阳山县政府部门公共服务事项清单（2017年版）》已经县人民政府批准，现印发给你们，请结合如下意见一并贯彻执行。

一、主动公开清单

2017

年12月8日

前，我县将在县政府门户网向社会公布《阳山县政府部门公共服务事项清单（2017年版）》，各有关单位也要主动向社会公开本单位的事项清单；县行政服务中心要根据省政府办公厅《关于做好2017年省级政府网上政务服务评估迎检工作的通知》和《关于进一步做好全国互联网政务服务平台检查及省级政府服务能力第三方评估整改工作的通知》的要求，组织窗口工作人员及时更新网上办事大厅和基层公共服务综合平台相关内容，主动接受社会监督。

二、推进标准应用

县行政服务中心要督促窗口单位更换实体大厅办事指南和业务手册，正确运用标准进行线上线下融合办事。

各有关单位要切实担负起主体责任：一是不断完善事项管理系统的标准化信息。要对新增的事项推行审批标准化，完善事项审批标准化信息。二是严格实施审批标准。要最大限度精简办事程序，缩短办理时限，按标准化办事指南和业务手册办事，切实为企业和群众提供便捷高效的政务服务。

三、实行动态管理

在实施过程中，各单位可根据法律法规规章的颁布、修订、废止以及部门职责变化，及时提出申请，参照《阳山县政府部门权责清单管理办法（试行）》（阳办发电[2016]44号）的要求，动态调整本单位实施的事项。
