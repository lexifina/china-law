# 阳山县外事侨务办公室2017年行政许可实施和监督管理情况评价公告

根据《广东省行政许可监督管理条例》第四十条规定和有关要求，现公告我单位2017年行政许可的实施和监督管理情况。欢迎您客观、真实地对是否存在以下问题进行反映：

1.没有依照法定权限、程序、条件进行审批，或变相实施行政许可，实施了《广东省行政许可事项通用目录（2017年版）》之外的行政审批事项的；

2.没有公开公示行政许可实施主体、依据、条件、期限、流程、裁量标准、收费标准和申请材料、申请办法、申请书格式范文本、咨询投诉方式或公开公示不明确的；

3.受理条件和程序不规范，要求多次补充申请材料的；

4.办理效率低下，办理流程复杂，擅自增减行政审批环节、条件的；

5.不能按期限办理行政许可，不能及时、客观地调查处理投诉举报的；

6.工作人员索取或收受礼物、好处的；

7.实施行政许可过程中要求申请人购买指定商品或者接受指定人员、组织提供的服务的，或者要求申请人参加不必要的付费培训、会议等的；

8.依法需要听证、招标、拍卖、检验、检测、检疫、鉴定和专家评审的事项，指定或者变相指定人员、组织的；

9.没有对被许可人从事行政许可事项活动依法有效实施监督检查的；

10.对没有必要设立行政许可，可以取消或采取事后监督等其他管理方式、调整由行业组织或者中介机构自律管理、通过技术标准或管理规范能有效管理的事项，却没有及时调整的。

如您认为我单位在行政许可实施过程中还存在其他问题，欢迎一并提出意见建议。我们将对您反映的情况和您的个人信息予以保密。

感谢对我单位行政审批评价工作的大力支持！

阳山县外事侨务办公室2017年行政许可

实施和监督管理情况报告

县人民政府：

根据《阳山县人民政府办公室关于落实行政许可实施和监督管理情况年度报告及公布制度的通知》要求，现将我单位2017年行政许可实施和监督管理情况报告如下：

一、基本情况

（一）现有事项及办理情况。我单位现有行政许可1项（华侨回国定居初审），已纳入《阳山县政府保留行政许可事项目录（2016年版）》(阳机编办〔2016〕45号)；并进驻网上办事大厅的事项；全年行政许可的申请、受理和办结数量为0项。

（二）依法实施情况。严格遵守《中华人民共和国出境入境管理法》（2012年）第十三条、《关于印发<广东省人民政府侨务办公室、广东省公安厅关于华侨回国定居办理工作的实施办法>的通知》（粤侨政〔2015〕53号）第十五条规定的权限、范围、程序和条件等情况；不存在变相实施行政许可的现象；去年结合行政许可标准化建设，优化审批流程和简化审批程序，办理时限由原来的15个工作日压缩为5个工作日。

（三）公开公示情况。去年结合行政许可标准化建设，在网上办事大厅等公开公示实施主体、依据、程序、期限、裁量标准、申请材料及办法、收费标准、申请书格式文本、咨询投诉方式等信息的方式、范围等；有关公开公示信息明确、细化。

（四）推行标准化情况。去年，我单位编制印发了标准化《办事指南》和《业务手册》，并在网上办事大厅公开；行政许可事项名称、实施依据、申请条件、申请材料、办理时限、受理范围等要素严格按照《广东省行政审批事项标准编写规范》要求来编制，并减少自由裁量权；本单位的行政许可不涉及中介服务。

（五）创新方式情况。去年,我单位根据省市文件精神，认真开展“一门式一网式”政务服务建设，创新申请受理和办理模式，推进相关事项的网上办理，结合行政审批标准化建设工作，精简优化审批流程、减少办事环节、缩短办事时限等，提高相关事项的办理率，建立相关服务制度。

（六）监督管理情况。已制定并实施有关监管措施，积极对从事行政许可事项有关的监督检查工作，未发现、查处有关违法违纪违规问题；单位内部加强对行政许可实施行为的监督管理；无收到举报投诉案件。

（七）实施效果情况。由于我县暂无华侨申请回国定居，因此暂无发生过华侨回国定居初审业务；通过优化和规范审批流程、政务公开等，为方便行政相对人、提高审批效率等打好了基础。

二、存在问题和困难

暂时未发现存在问题。

三、下一步工作措施及有关建议

下一步，我们将继续做好政务公开等工作，如有华侨申请回国定居，则按规定办理业务。
