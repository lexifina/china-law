# 阳山县人民政府办公室关于征询对清连阳山段出入口沿线进行景观提升意见的函

清连高速公路发展有限公司：

为落实好创建文明县城工作，优化美化我县出入口沿线环境，提升我县城市形象和品位，我县拟对清连阳山段出入口沿线进行景观提升。目前，我县已委托设计单位编制了《清连阳山段出入口沿线景观提升工程设计方案》(草案)。根据方案，拟改造红线范围约100公顷，长约8公里（详见附件），主要内容包含出入口绿化岛，安装挡板（屏），沿线种植绿化、乔木和开花灌木，以及进行建筑立面整治等。为做好清连阳山段出入口沿线景观提升的建设工作，现向贵公司征求意见和建议。

特此致函，请复。

附件：清连阳山段出入口沿线景观提升工程设计方案

阳山县人民政府办公室
