# 阳山县人民政府办公室关于调整阳山县出口食品农产品质量安全示范区建设工作领导小组的通知

阳府办函〔2018〕68号

阳山县人民政府办公室关于调整阳山县

出口食品农产品质量安全示范区建设

工作领导小组的通知

各乡镇人民政府，县政府各部门、各直属机构：

鉴于人员变动和工作需要，县人民政府决定调整阳山县出口食品农产品质量安全示范区建设工作领导小组。调整后的成员名单如下：

组 长：廖敬华　　县委副书记、县长

常务副组长：杨坚强　　副县长

副 组 长：邓奕彬　　县政府办公室副主任

梁文锋　　县科技农业局局长

成 员：黄延安　　县经济和信息化局局长

马维新　　县科技农业局副局长

钟 衍　　县公安局副局长

马文权　　县环境保护局局长

何章建　　县食品药品监管局局长

陈伟强　　县市场监管局局长

文伟明　　县产业转移工业园管委会主任，县招商局、外经贸局局长

陈伟坚　　县供销社主任

江海坚　　县广播电视台台长

卢志满　　县信息中心副主任

何俊斌　　阳城镇镇长

王文东　　江英镇镇长

张秀芬　　大崀镇镇长

曹贝宁　　黎埠镇镇长

罗瑞端　　小江镇镇长

领导小组下设办公室、技术支持组和执行管理组。办公室及技术支持组设在县科技农业局，由梁文锋兼任办公室主任，马维新兼任技术支持组组长；执行管理组设在县市场监管局，由陈伟强兼任执行管理组组长。成员均由相关单位人员组成。

阳山县人民政府办公室
