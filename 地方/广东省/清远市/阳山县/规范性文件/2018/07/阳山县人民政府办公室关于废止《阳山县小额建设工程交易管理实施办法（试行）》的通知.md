# 阳山县人民政府办公室关于废止《阳山县小额建设工程交易管理实施办法（试行）》的通知

各乡镇人民政府，县政府各部门、各直属机构：

为进一步营造我县公平竞争的市场环境，节省行政成本，提高服务效率，根据有关国家《政府采购法》《招标投标法》等法律法规，以及国家有关部委《公平竞争审查制度实施细则（暂行）》相关规定，经县政府十六届第19次常务会议研究决定，《阳山县人民政府办公室关于印发阳山县小额建设工程交易管理实施办法（试行）》（阳府办函〔2016〕174号）予以废止，不再施行。工程建设项目及政府采购项目，按国家《政府采购法》《招标投标法》相关规定及国家发改委、财政部等有关规定执行。现予公布，自公布之日起施行。

特此通知。

阳山县人民政府办公室

2018年7月30日
