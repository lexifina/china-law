# 阳山县人民政府办公室关于印发阳山县城乡规划建设遥感监测图斑核查处理工作方案的通知

阳府办函〔2018〕118号

阳山县人民政府办公室关于印发阳山县

城乡规划建设遥感监测图斑核查

处理工作方案的通知

各乡镇人民政府，县有关单位：

《阳山县城乡规划建设遥感监测图斑核查处理工作方案》已经县人民政府同意，现印发给你们，请认真组织实施。实施中遇到的问题，请径向县规划市政局反映。

阳山县人民政府办公室

2018年7月16日

阳山县城乡规划建设遥感监测图斑

核查处理工作方案

为扎实推进我县城乡规划建设遥感图斑核查处理工作，根据市住建部门转发《广东省住房和城乡建设厅关于开展2017年度（第二期）城乡规划建设遥感监测疑似违法图斑核查和查处工作的通知》的文件要求，结合我县实际，制定本工作方案。

一、工作目标和任务

坚决遏制新增违法图斑，全面清理存量违法图斑，改善城市人居环境，营造良好的生态、生活和生产空间。用3年（2018—2020年）时间，全面完成违法图斑的清理任务，并形成长效管控机制。

二、理顺工作机制

（一）成立工作领导小组。

为加强对该项工作的组织领导，县政府成立工作领导小组，组成人员名单如下：

组 长：周文华（副县长）

副组长：文 龙（县政府办公室副主任）

钟志华（县规划市政局局长）

梁建恒（县国土资源局局长）

成 员：张文育（县住房城乡建设局副局长）

潘企祥（县交通运输局副主任科员）

邓智聪（县林业局副局长）

刘 祥（县水务局副局长）

梁国新[佛山南海（阳山）产业转移工业园管委会副主任]

吕宝良（县公安消防大队教导员）

各乡镇分管领导均为成员。

领导小组办公室设在县政府办公室，由文龙同志兼任办公室主任，县规划市政局、县国土资源局主要领导兼任办公室副主任。领导工作小组办公室负责城乡规划建设遥感图斑核查处理的跟踪、协调以及提请领导小组召开会议处理重大问题等日常工作。为方便沟通联系，领导小组各成员单位要安排好工作联络员，负责接收认定的违法图斑资料和上报查处违法图斑资料等有关工作。

（二）明确部门职责分工。

县规划市政局：负责“一下”疑似违法图斑的数据接收、核查以及“一上”核查数据的上报工作，负责接收“二下”违法图斑的数据接收、任务分派工作；负责与市城乡规划局对疑似违法图斑的认定、核对进行沟通对接；指导县有关执法部门解决专项治理工作中的规划技术问题；负责违法图斑的数据接收，根据各部门职能分派工作任务；负责开展违法图斑查处工作及查处数据上报工作；负责对县规划区范围内重大、涉及面广、难以定性的违法图斑，向领导小组提出处理意见；负责“二上”违法图斑处理结案数据的汇总上报工作。

县国土资源局：负责提供违法图斑涉及项目的相关审批文件，负责对涉及国土违法行为进行查处。

县住房城乡建设局：负责对违法图斑处理方案涉及到建筑安全等问题提供专业审查意见，协助提供违法图斑建设的相关资料。

县交通运输局：负责提供公路建筑控制区内的违法图斑的相关审批文件，负责对涉及公路建筑控制区内的违法行为进行查处。

县林业局：负责提供涉及山林用地的违法图斑的相关审批文件，负责对涉及山林用地的违法行为进行查处。

县水务局：负责提供涉及河堤用地等违法图斑的相关审批文件，负责对涉及河堤用地的违法行为进行查处。

佛山南海（阳山）产业转移工业园管委会：负责协助对管辖范围的疑似图斑的核查和查处工作。

县公安消防大队：负责对违法图斑处理方案涉及消防安全等问题提供专业审查意见。

各乡镇人民政府：负责协助本辖区违法图斑核查工作,负责组织实施本辖区违法图斑查处工作。

（三）完善工作流程。

1．疑似违法图斑核查（即“一下一上”阶段）流程。“一下”是指省住建厅下发疑似违法图斑，各县根据城市总体规划和规划审批情况进行核查，研判是否存在违法建设行为，经核查后将数据上报市城乡规划部门录入省城乡规划建设遥感监测系统。

（1）数据接收。由县规划市政局接收市城乡规划局下发的疑似违法图斑。

（2）规划核查。领导小组各成员单位配合县规划市政局开展核查工作，提供涉及该图斑项目的相关审批文件、协助核准疑似违法图斑定点位置及与图斑权利人做好沟通、解释等工作。县规划市政局对照城市总体规划、控制性详细规划和规划审批情况，做好核查工作，并于7月1日前完成疑似违法图斑核查工作。

（3）沟通对接。县规划市政局将疑似违法图斑核查情况收集汇总后，与市城乡规划局进行沟通对接。

（4）信息上报。与市城乡规划局进行对接后，县规划市政局于7月1日前将疑似违法图斑核查情况上报至市城乡规划局,再由市城乡规划局将疑似图斑核查情况录入上报至省城乡规划遥感监测系统。

2．违法图斑处理（即“二下二上”）流程。“二下二上”是指省住建厅根据各地核查疑似图斑的情况，经审核确定为违法图斑后再次下发任务，由各地进行查处，并将查处情况录入省城乡规划建设遥感监测系统。

（1）数据接收。市住房城乡建设管理局将省住建厅认定的违法图斑发至县规划市政局，县规划市政局将城镇规划区范围内的违法图斑资料按部门职能分类移送各查处责任单位：①未取得规划许可手续，但符合城市总体规划且已取得土地使用权证的图斑，由县规划市政局进行处罚后，督促责令建设方采取改正措施消除规划影响；②未取得规划许可手续和土地使用权证，但符合城市总体规划的图斑，移送至县国土资源局进行处理；③未取得规划许可手续和土地使用权证的建设用地，也不符合城市总体规划的图斑，由县规划市政局进行处理；④已取得规划许可手续和土地使用权证，且符合城市总体规划的图斑，由县规划市政局直接向市城乡规划局提交资料核对消除；⑤县规划市政局在处理上述第①、③的违法图斑时，发现违法图斑涉及非建设用地（农业用地、未利用土地等）、公路建筑控制区内、山林用地和河堤用地等，应及时移送国土、交通运输、林业和水务部门查处。在城镇规划区范围外的违法图斑，由县国土资源局以及各乡镇人民政府负责具体实施查处工作。

（2）依法查处。各查处责任单位按照执法办案程序依法开展调查取证，作出行政处罚。

在进行违法图斑查处时，对于由于历史原因形成且涉及面广、难以定性的违法图斑，由各查处责任单位提供相关情况报领导工作小组办公室，领导工作小组办公室召集有关责任单位共同研讨并制定初步处理方案，并提请至领导工作小组审定。

在进行违法图斑查处时，各查处责任单位负责建立“一案一档”，归档的内容包括违法图斑基础资料、实地核查图片、相关审批文件、违法违规行为查处文书、结案文书及其他有关文件资料。

（3）数据汇总。各查处责任单位于10月20日前将违法图斑查处情况、数据以及“一案一档”材料报县规划市政局汇总。

（4）信息上报。县规划市政局于11月1日前将违法图斑查处情况及数据上报至市住房城乡建设管理局，在报送的同时将有关情况抄送至领导小组办公室。

三、工作要求

（一）提高认识。开展违法图斑查处工作是深入贯彻落实中央城镇化工作会议和中央城市工作会议精神，深化城乡规划管理体制改革，大力推动规划监督方式和手段创新的重要抓手之一，也是落实住房城乡建设部和广东省人民政府共同推进城乡规划建设体制改革试点省建设合作协议的重要举措。各乡镇人民政府、县有关单位必须高度重视，要充分认识到开展城乡规划建设遥感监测工作的重要性，构建规划建设领域的“大数据”和“执法立体网络”，动真动硬，真抓实干，齐抓共管，加大规划实施管控力度，坚决维护规划的权威。

（二）建立联动机制。要制定强有力的措施，建立由乡镇、社区（村）等基层单位和相关部门组成的巡查网络，制定巡查管控方案，划定责任单位和责任区域，借助规划建设遥感监测，严控新增违法建设，对违法行为做到早发现、早制止、早处理，发现一起，查处一起。根据实际情况，准确认定各类违法图斑，依法予以责令停工、限期改正、限期拆除、没收实物或违法收入并处罚款。

各部门要加强沟通，共同研究重大违法案件的认定和处理意见。对违法图斑查处工作信息要相互共享，在立案、调查取证、处理等环节要互相配合，协同推进。严厉查处各类违法建设，依照相关法律法规给予处理，扎实推进违法图斑查处进度。

（三）建立一案一档制度。按照“一个图斑一个卷宗”的原则，以年度为单位对图斑核查处理工作成果进行组卷归档。

（四）严格监督，强化责任。领导工作小组办公室将加强对各部门、各乡镇开展违法图斑工作情况的检查、督导。对工作开展不力、逾期不报数据或瞒报、伪造数据的，予以约谈、警告或通报批评。

（五）强化宣传，发挥舆论引导作用。充分利用广播电视、报纸、互联网等新闻媒体宣传违法图斑处理工作的目的、意义。新闻媒体要进行跟踪报道，客观、准确地向全社会公开违法图斑处理工作进展和取得的成效，营造有利于违法图斑处理工作的舆论氛围。
