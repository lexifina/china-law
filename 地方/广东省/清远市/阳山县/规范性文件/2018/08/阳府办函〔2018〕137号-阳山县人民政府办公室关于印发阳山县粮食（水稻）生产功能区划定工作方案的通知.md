# 阳山县人民政府办公室关于印发阳山县粮食（水稻）生产功能区划定工作方案的通知

各乡镇人民政府，县政府各部门、各直属机构：

《阳山县粮食（水稻）生产功能区划定工作方案》已经县人民政府同意，现印发给你们，请结合实际认真贯彻执行。执行中遇到的问题，请径向县科技农业局反映。

阳山县人民政府办公室

2018年8月9日

阳山县粮食（水稻）生产功能区划定工作方案

为加快我县粮食生产功能区划定，确保粮食安全生产，根据《国务院关于建立粮食生产功能区和重要农产品生产保护区的指导意见》（国发〔2017〕24号）、《广东省人民政府办公厅印发关于建立广东省粮食生产功能区和重要农产品生产保护区的实施方案的通知》（粤办函〔2017〕639号）和《清远市人民政府办公室关于印发清远市粮食（水稻）生产功能区划定工作方案的通知》（清府办函〔2018〕68号），结合我县实际，制定本工作方案。

一、指导思想

全面贯彻党的十九大精神，以习近平新时代中国特色社会主义思想为指导，深入贯彻习近平总书记重要讲话精神，实施藏粮于地、藏粮于技战略，以确保粮食安全为目标，以深入推进农业供给侧结构性改革为主线，以永久基本农田划定成果为基础，将粮食（水稻）生产功能区细化落实到具体地块，优化区域布局和要素组合，促进农业结构调整，提升粮食质量效益和市场竞争力，为推进农业现代化建设、全面建成小康社会奠定良好基础。

二、基本原则

（一）坚持科学划定原则。按照“应划尽划、划足划实、择优划定”原则，结合我县当前水稻种植田块类型、现有水土资源条件、生产现状等因素，科学合理划定粮食（水稻）生产功能区，落实到镇、村和具体的田头地块。

（二）坚持统筹兼顾原则。围绕保粮食产能，充分调动各方面积极性，确保农业可持续发展和我县粮食安全。

（三）坚持政策引导、农民参与原则。完善支持机制和制度保障体系，积极引导农民参与粮食（水稻）生产功能区划定、建设和管护，稳定粮食种植面积，保持种植收益在合理水平。

三、工作任务

（一）工作目标。市下达我县的粮食生产功能区划定任务是15.32万亩（全部为水稻）。按照两区划定任务的要求，2017年全省在产粮大县开展划定试点，2018年底前全面完成粮食（水稻）生产功能区划定，做到全部建档立卡、上图入库，实现信息化和精准化管理。

（二）工作任务。

1．科学有序开展粮食（水稻）生产功能区边界划定。各乡镇在开展划定工作时，应优先将具备以下条件和标准的水田划定为粮食（水稻）生产功能区：

（1）已划定为永久基本农田，土壤较为肥沃，耕地质量等级在五等以上的水田，近年来基本种植水稻的田块；

（2）相对集中连片，原则上平原地区连片水田面积不低于300亩，丘陵地区连片水田面积不低于30亩；

（3）农田水利灌排工程等农业基础设施比较完备，灌溉条件较好，排灌能力满足农业生产需求，生态环境良好，建成或规划建设的高标准农田；

（4）周边涉及农业生产的河道水系通畅、灌溉条件保障、交通相对便利，农用输电线路等设施能满足生产需求，土壤、水体和大气环境质量等符合生产质量安全要求的田块（划入粮食禁止生产区域的，不得划为粮食生产功能区）。

2．逐级分解下达任务。综合考虑当地资源禀赋、发展潜力、产销平衡等条件，根据全县粮食（水稻）生产功能区划定任务，结合各乡镇现有水田面积、永久基本农田面积和现有水稻种植面积等因素，将划定任务分解下达到各乡镇。各乡镇人民政府结合实际，逐级分解落实到村，并结合农村土地承包经营权确权登记颁证工作，细化落实到具体田块。

3．认真做好划定工作。一是深入开展调查。组织各乡镇做好划定前期的摸底调查工作，摸清当地连片水田和水稻种植水田分布情况；将市下达我县15.32万亩划定任务分解到各乡镇，由乡镇按照划定任务和粮食生产功能区连片划入标准，结合农村土地承包经营权确权登记颁证和永久基本农田划定工作，确定分区数量、各区连片面积、分布地点（到村小组）、当前种植作物类型、农田基础设施（机耕路、水利设施等）情况等内容，并明确各环节具体工作要求和职责分工。二是规范开展划定。按照上级部门要求，将划定的粮食（水稻）生产功能区具体地块进行统一编号（明确到镇、村），标明“四至”及拐点坐标、连片面积以及灌排工程、电力交通条件、耕地质量等级、作物类型、承包经营主体、土地流转情况等相关信息。三是进行上图入库管理。依托国土资源遥感监测“一张图”和综合监管平台，建立电子地图和数据库，建档立卡、登记造册，把划定的粮食（水稻）生产功能区地块具体落实到图上，并根据农田实际情况核定修正，及时“上图入库”。

4．落实保护责任。严格粮食（水稻）生产功能区范围内永久基本农田的保护和管理，确保数量不减少、质量不降低、用途不改变，并按照“谁使用、谁受益、谁管护”的原则，将粮食（水稻）生产功能区地块的农业基础设施管护责任落实到经营主体，督促和指导经营主体加强设施管护。由县政府公布各乡镇划定的粮食（水稻）生产功能区，及时树立标志牌，标明地点编号、建设地点、连片面积，组织划定和管理责任单位、立牌单位等。任何单位和个人不得破坏、损坏或者擅自改变粮食（水稻）生产功能区标志牌。

四、保障措施

（一）加强组织领导，落实责任。为更好贯彻落实粮食（水稻）生产功能区划定相关工作，成立以县分管领导为组长、各相关职能部门、各乡镇分管领导为成员的工作领导小组，办公室设在县科技农业局，负责功能区划定、保护工作的组织实施、综合协调和日常事务等工作，确保按时、按质、按量完成功能区划定和建设任务。

（二）明确部门分工。各部门按照职能分工要求加强指导、协调和督查，确保粮食（水稻）生产功能区划定和建设各项工作落实到位。县发展改革部门发挥统筹协调作用，做好粮食（水稻）生产功能区建设与相关专项规划的衔接；县农业部门会同国土资源部门组织和协调粮食（水稻）生产功能区划定、建设各项工作，做好划定、验收、考核评价等工作；县财政部门落实功能区划定工作经费；县水务部门根据粮食（水稻）生产功能区的水资源条件，做好项目规划和资金安排，加强农田水利配套设施建设；县国土资源部门严格控制粮食（水稻）生产功能区范围内耕地占用审批，强化保护并做好上图入库工作；县交通运输部门指导粮食（水稻）生产功能区周边公路网的规划、建设、维护工作；县电力部门做好粮食（水稻）功能区农村电网建设和日常用电保障；县粮食部门进一步加强对粮食收购工作的指导，引导企业优先与粮食生产功能区内种粮农民签订粮食收购订单；同时，县国土、规划、水务、交通、住建、旅游、环保、发改等部门应提前告知部门的规划控制性范围，提供不划入粮食生产功能区的相关依据；其他部门要积极支持粮食（水稻）功能区划定与建设。各乡镇需预留发展用地的，应提交合理的发展需求方案作为不划入依据；同时要成立相应的工作机构，落实人员，负责本辖区内粮食（水稻）生产功能区划定、保护等相关工作。
