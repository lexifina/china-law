# 阳山县人民政府办公室关于成立阳山县反校园欺凌工作领导小组的通知

县各有关单位：

为进一步加强对我县反校园欺凌工作的组织领导，推动各项工作迅速、有序、有效开展，确保校园和谐，经县政府同意，决定成立阳山县反校园欺凌工作领导小组，组成人员名单如下：

组 长：林 怡 副县长

副组长：戴金绍 县政府办公室副主任

唐长远 县教育局局长

成 员：唐志荣 县委宣传部副部长

何立育 县教育局副局长

陈德建 县公安局副局长

卢志满 县信息中心副主任

全县各派出所所长、中小学校校长及法制副校长均为领导小组成员。

领导小组办公室设在县教育局，负责领导小组日常工作，由唐长远同志兼任办公室主任。

阳山县人民政府办公室

2019年3月8日
