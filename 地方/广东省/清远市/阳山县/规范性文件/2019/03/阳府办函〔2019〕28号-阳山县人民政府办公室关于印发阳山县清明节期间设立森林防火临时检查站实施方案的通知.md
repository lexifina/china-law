# 阳山县人民政府办公室关于印发阳山县清明节期间设立森林防火临时检查站实施方案的通知

阳府办函〔2019〕28号

阳山县人民政府办公室关于印发阳山县

清明节期间设立森林防火临时

检查站实施方案的通知

各乡镇人民政府，县政府有关部门、有关直属机构：

《阳山县清明节期间设立森林防火临时检查站实施方案》已经县人民政府同意，现印发给你们，请认真组织实施。实施过程中遇到的问题，请径向县防火办反映。

阳山县人民政府办公室

2019

年3月29日

阳山县清明节期间设立森林防火

临时检查站实施方案

清明节期间野外火源增多，上坟燃烧香、蜡、纸、烛，燃放烟花炮竹增多，给森林带来很大隐患。为切实做好我县清明节期间的森林防火工作，根据《广东省森林防火条例》第二十七条，结合我县实际，特制定本实施方案。

一、指导思想

认真贯彻“预防为主、积极消灾”的森林消防工作方针，落实各项工作措施，确保森林资源和人民生命财产的安全，创造美好的生态环境，实现人与自然和谐共生。

二、工作目标

切实加强领导，落实责任到人，发动全县各镇（乡）、村干部和群众等参与森林防火临时检查站设防与巡查工作，以每个山头地块为落实单元，强势推行文明祭祖。同时以开展多种形式的宣传为先导，营造浓郁的防火氛围，提高全民的森林消防意识，夯实“政府全面负责，部门齐抓共管，群众广泛参与，全社会积极支持”的森林消防工作机制，形成群防群治的工作局面，力争清明节期间不发生森林火灾。

三、工作要求

1．设立森林防火临时检查站站牌，全体检查人员佩带红手袖；

2．各检查组人员按时到位，无特殊情况不得迟到、早退；

3．认真登记上下山人员，详细记录上下山人数；

4．对进入防火区的车辆和人员携带的火种、易燃易爆物品及其他可能引起森林火灾的物品，实行集中保管；

5．现场发放森林防火宣传单、防火戒严令，扩大影响面，使广大人民群众自觉遵守，提高文明祭扫意识。

四、设站时间

清明节期间：清明节法定3天假期，由各乡镇森林防火指挥部负责具体实施。

五、设站位置

清明节期间，全县将设立85个森林防火临时检查站，具体设卡位置：

1．阳城镇5个：高速路旁湟池路口、省道入麻地冲路口、水口上大里路口、神峰山上麦冲路口、省道上石坳路口；

2．青莲镇3个：江佐村垃圾压缩站路口、立德粉厂路口、屋村路口；

3．江英镇2个：田心小洞村路口、三联黄坭塘村路口；

4．杜步镇4个：东山村路口、大路村路口、山坪村路口、石溪康西村路口、湟川村、杜步村、东江村、旱坑村；

5．七拱镇7个：塘坪村深坑路口、塘坪村后垌路口、和平村高垌路口、和平村学发公祠路口、芙蓉村草陂鳗鱼场路口、新圩村杨梅坑路口、新圩村大岗路口；

6．太平镇8个：太平村三和洞入山路口、大城村天升村入山路口、杏棠村水厂路口、围龙村黄屋寨入山路口、沙陂村凤石村内头坑路口、田庄村牛鼻岩牛一和牛二小组路口、清水村雷洞塘光伏入山路口、湖洞村白莲桥路口；

7．杨梅镇4个：坑尾路口、里洞路口、杨梅林场路口、杨梅街；

8．大崀镇5个：松林村候车亭坑口村路口、振民村候车亭下雷小学、大崀村山窝驼花海世界、琶迳村高腱公司路口、坑塘村坑口村路口；

9．黎埠镇23个：黎埠村路口、隔江村路口、联坝村路口、大龙村路口1、大龙村路口2、均安村路口、六古村路口、燕岩村路口、扶村村路口、南村村路口、水井村路口、孟山村路口、保平村路口、凤山村路口1、凤山村路口2、大塘村路口、鲁塘村路口1、鲁塘村路口2、界滩村路口1、界滩村路口2、洞冠村路口、升平村路口、高速出入口路口；

10．小江镇6个：小江公园后背山路口、下坪枫木塘路口、沙寮大坪后岗山路口、沙寮桥桥头、塘冲龙塘村路口、罗汉沙冲村进村路口；

11．黄坌镇7个：黄坌村、雷村村、白屋村、王村村、大坪村、塘底村、高陂村；

12．秤架乡3个：323线将加岸西山路口、323线第一峰路口、323线干坑入口；

13．岭背镇4个：犁头村委会路口、岗头西坑路口、户稠路口、黄屋路口。

六、人员安排

每个森林防火临时检查站点由民兵、公安、行政执法队员以及镇驻村干部、村干部参与检查，其中，设组长1名，每个站工作人员至少3人以上，确保检查工作顺利进行。

各乡镇对此项工作要高度重视，狠抓落实，切实做好清明节期间森林防火各项防范工作，力争清明节期间不发生森林火灾。
