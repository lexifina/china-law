# 阳山县人民政府办公室关于印发阳山县人民政府2019年度规范性文件制定工作计划的通知

各乡镇人民政府，县政府各部门、各直属机构：

《阳山县人民政府2019年度规范性文件制定工作计划》已经县政府十六届第32次常务会议审议通过，现印发给你们，请相关部门抓紧做好县政府规范性文件的调研、起草、论证、修改和审查等各项工作，确保县政府规范性文件制定质量。执行过程中遇到的问题，请径向县司法局反映。
