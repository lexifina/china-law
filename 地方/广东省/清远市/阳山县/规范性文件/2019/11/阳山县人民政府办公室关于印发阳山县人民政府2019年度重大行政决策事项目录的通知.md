# 阳山县人民政府办公室关于印发阳山县人民政府2019年度重大行政决策事项目录的通知

各乡镇人民政府，县政府各部门、各直属机构：

《阳山县人民政府2019年度重大行政决策事项目录》已经县人民政府同意，现印发给你们，请根据《重大行政决策程序暂行条例》（国务院令第713号）等规定，按法定程序认真组织实施。
