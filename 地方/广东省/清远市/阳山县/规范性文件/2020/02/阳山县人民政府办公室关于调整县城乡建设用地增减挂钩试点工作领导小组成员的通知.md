# 阳山县人民政府办公室关于调整县城乡建设用地增减挂钩试点工作领导小组成员的通知

各乡镇人民政府、县直有关单位、驻阳有关单位：

鉴于机构改革和人员变动，县政府决定调整阳山县城乡建设用地增减挂钩试点工作领导小组部分成员。调整后的成员名单如下：

组 长：潘文彬 县委常委、常务副县长

副组长：戴金绍 县政府办公室副主任

黄振杰 县自然资源局副局长

成 员：梁 奕 县发展改革局副局长

唐宇雄 县工业和信息化局副局长

甘文光 县民政局副局长

黄晓芬 县财政局党组成员

张文育 县住房城乡建设局副局长

吴东强 县水利局副局长

杨永芳 县农业农村局副局长

邓智聪 县林业局副局长

唐剑发 市生态环境局阳山分局副局长

领导小组办公室设在县自然资源局，由黄振杰同志兼任办公室主任。

阳山县人民政府办公室
