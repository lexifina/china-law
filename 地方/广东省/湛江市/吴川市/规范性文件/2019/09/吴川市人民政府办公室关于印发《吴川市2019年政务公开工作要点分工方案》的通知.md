# 吴川市人民政府办公室关于印发《吴川市2019年政务公开工作要点分工方案》的通知

吴川市人民政府办公室关于印发吴川市2019年政务公开工作要点分工方案的通知

各镇人民政府，各街道办事处，市府直属各单位:

为贯彻落实《广东省人民政府办公厅关于转发国务院办公厅2019年政务公开工作要点的通知》（粤府办〔2019〕9号）和《湛江市人民政府办公室关于印发湛江市2019年政务公开工作要点分工方案的通知》（湛府办函〔2019〕59号）的部署要求，市政府办公室制定了《吴川市2019年政务公开工作要点分工方案》，经市人民政府同意，现印发给你们，请认真组织实施。现就有关工作通知如下：

一、分工方案中明确的牵头单位要制定实施方案，明确具体任务、工作分工和完成时限，加强实施过程中的督办协调，对整个项目的完成情况和效果负责。各参与单位要按照牵头单位制定的方案，认真完成本单位承担的工作。

二、各镇（街道）政府（办事处）、市府直属各单位要对分工方案表中所列的项目，按注明的评价标准贯彻落实，落实情况报告于今年12月16日报市政府办公室（政务信息股），报告内容包括所做的具体工作、进展、取得的效果和下一步工作措施等。各单位落实本分工方案的情况，将纳入绩效考核，市政府办公室加强各项工作落实情况的检查督导。

附件：吴川市2019年政务公开工作要点分工方案
