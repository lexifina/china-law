# 吴川市人民政府关于印发吴川市工程建设项目审批制度改革实施方案的通知

各镇人民政府，各街道办事处，市经济开发区管委会，吴川工业园管委会，市府直属有关单位：

《吴川市工程建设项目审批制度改革实施方案》业经市委十三届第99次常委（扩大）会议、第十六届市政府第68次常务会议研究通过，现印发给你们，请认真贯彻执行。执行中遇到的问题，请径向市工程建设项目审批制度改革工作领导小组办公室（市住房和城乡建设局）反映。

吴川市人民政府

2019年9月17日
