# 吴川市人民政府关于公布规范性文件清理结果的通知

为加强对我市规范性文件的监督管理，保障规范性文件的合法性和有效性，根据《国务院关于加强市县政府依法行政的决定》（国发〔2008〕17号）和《湛江市人民政府办公室关于开展全市规章规范性文件清理工作的通知》（湛府办〔2019〕5号）的精神，市人民政府对我市历年来以市人民政府或市人民政府办公室名义制发的规范性文件进行了全面清理。清理结果为：废止规范性文件38件、失效规范性文件7件、修订规范性文件5件、保留规范性文件6件。现予以公布。

附件：1.吴川市规范性文件清理情况表（废止类）
