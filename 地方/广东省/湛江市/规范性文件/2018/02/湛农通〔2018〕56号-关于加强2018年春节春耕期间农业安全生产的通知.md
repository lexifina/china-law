# 关于加强2018年春节春耕期间农业安全生产的通知

湛农通〔2018〕56号

各县（市、区）农业局（农业事务管理局）、农机局（总站）：

为贯彻落实2018年2月7日广东省安全生产工作紧急电视电话会议精神，汲取2月5日韶钢煤气泄漏事故的教训，结合我市农业农村工作的实际，现就进一步加强我市2018年春节春耕期间的农业安全生产工作通如下：

1、各单位领导班子春节春耕期间必须至少集中研究一次农业安全生产工作，对2018年春节春耕期间的安全生产作出具体的部署。

2、各地要结合农业生产的特点，针对各类农业从业人员和生产过程、农机使用、农资（种子、农药、肥料等）供应等各环节，认真排查安全隐患，涉气单位要特别注意用气的安全，切实制定具体的工作方案，并组织实施。各单位各部门安全生产第一责任人必须亲自检查各项安全措施的落实情况，切实履行安全生产责任。

3、春节期间要安排人员值守，保证相关人员及应急电话畅通，发现问题积极应对并按规定及时上报。

请各县（市、区）于2月14日（星期三）下午下班前将各单位春节期间值班人员安排情况和2018年春节春耕期间农业安全生产工作方案报湛江市农业局农业综合行政执法支队（应急办）。湛江市农业局将对该项工作开展相关的执法检查。
