# 关于印发《湛江市农业局2018年工作要点》的通知

湛农通〔2018〕113号

各县（市、区）农业局（农业事务管理局），局各科室、下属单位：

为贯彻落实党的十九大精神和习近平新时代中国特色社会主义思想，深入推进乡村振兴战略实施，根据省农业厅和市委、市政府的工作部署和要求，我局制定了《湛江市农业局2018年工作要点》。现印发你们，请结合实际，认真抓好落实。

湛江市农业局

2018年3月23日

公开方式：主动公开
