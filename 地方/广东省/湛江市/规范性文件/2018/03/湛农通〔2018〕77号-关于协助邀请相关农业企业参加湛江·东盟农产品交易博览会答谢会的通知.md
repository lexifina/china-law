# 关于协助邀请相关农业企业参加湛江·东盟农产品交易博览会答谢会的通知

湛农通〔2018〕77号

各县（市、区）农业局（农业事务管理局）：

根据市委、市政府的部署，进一步加强与东盟国家的对接，打造与东盟国家的交流合作平台，服务我市农业产业做大做强，我市成功举办了两届湛江·东盟农产品交易博览会（简称“东盟农博会”）。在各个相关部门的精心策划指导和全力推动下，东盟农博会越办越好，得到省农业厅和市委、市政府的充分肯定，引起海内外业界的积极关注和踊跃参与，成为服务我省农业企业走出去、促进农业经济发展的重要平台。

2018湛江·东盟农产品交易博览会（简称“2018东盟农博会”）拟定于2018年6月8—10日在湛江国际会展中心举办。为宣传推广东盟农博会，吸引更多农业企业参与东盟农博会，并答谢相关农业企业一直以来支持和参与东盟农博会，现定于2018年3月9日下午在湛江君豪酒店金橄榄厅举办湛江·东盟农产品交易博览会客户答谢会。现通知如下：

1、请按照附件1要求协助组织辖区内农业企业参加答谢会。

2、请于3月6日前将参会回执及参加人员名单（附件2）回复至湛江·东盟农博会筹委会办公室。
