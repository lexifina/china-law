# 关于上报2017年冬种农作物品种种植面积的通知

湛农通〔2018〕95号

各县（市、区）农业局（农业事务管理局）：

根据省种子管理总站《关于上报2015年冬种农作物品种种植面积的通知》（粤种【2016】8号）要求。为更好掌握我市各地区2015年冬种农作物品种种植情况，现将玉米、甘薯、马铃薯、蔬菜品种种植面积统计表发给你们（报表在广东农业信息网-业务中心-种子管理总站下载），请各单位认真做好填报工作。报表要翔实反应所辖区内的品种种植情况，除表列品种外，当地有较大种植面积的其它品种也要一并填报，报表加盖公章后于3月18日前上报湛江市农业局农产品质量安全监管与种子管理科，同时报送电子版到zjzzglk@126.com。

湛江市农业局

2018年3日13日
