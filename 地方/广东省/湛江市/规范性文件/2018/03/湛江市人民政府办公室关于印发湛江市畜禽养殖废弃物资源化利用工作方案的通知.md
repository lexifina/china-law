# 湛江市人民政府办公室关于印发湛江市畜禽养殖废弃物资源化利用工作方案的通知

各县（市、区）人民政府（管委会），市府直属各单位：

《湛江市畜禽养殖废弃物资源化利用工作方案》已经市人民政府同意，现印发给你们，请认真贯彻执行。执行中遇到的问题，请径向市畜牧兽医局、市环境保护局反映。

市畜牧兽医局、市环境保护局要会同有关部门对本方案落实情况加强督促检查，并向市人民政府报告、向各县（市、区）人民政府、湛江经济技术开发区管委会、南三岛滨海旅游示范区管委会通报工作进展。

湛江市人民政府办公室

2018年3月18日
