# 关于成立湛江市农业局扫黑除恶专项斗争领导小组的通知

湛农通〔2018〕217号

各县（市、区）农业局（农业事务管理局），农机局（总站），局机关各科室、直属单位：

为贯彻落实市委、市政府关于开展扫黑除恶专项斗争的部署要求，扎实推进农业系统扫黑除恶专项斗争，经局党组研究，决定成立湛江市农业局扫黑除恶专项斗争领导小组。
