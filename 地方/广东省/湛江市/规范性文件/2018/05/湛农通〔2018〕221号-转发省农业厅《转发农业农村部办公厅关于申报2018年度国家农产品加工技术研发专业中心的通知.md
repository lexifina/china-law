# 转发省农业厅《转发农业农村部办公厅关于申报2018年度国家农产品加工技术研发专业中心的通知

湛农通〔2018〕221号

各县（市、区）农业局（农业事务管理局）：

现将省农业厅《转发农业农村部办公厅关于申报2018年度国家农产品加工技术研发专业中心的通知》（粤农办〔2018〕252号）转发给你们，请你们通知要求，积极组织符合条件范围的农产品加工企业参与申报，并于6月8日前，将申报材料一式6份报至我局农产品加工管理科，并发送电子版材料，我局将择优推荐上报省农业厅。
