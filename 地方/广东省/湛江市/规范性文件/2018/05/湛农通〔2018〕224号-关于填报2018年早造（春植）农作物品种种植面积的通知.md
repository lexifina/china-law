# 关于填报2018年早造（春植）农作物品种种植面积的通知

湛农通〔2018〕224号

各县（市、区）农业局（农业事务管理局）：

为掌握我市早造（春植）农作物品种种植情况，请认真填好2018年早造（春植）各类作物品种种植面积统计表，相关表格(在广东农业信息网-业务中心-种子管理处http://www.seedgd.com/下载)。报表要翔实反映所辖区内品种种植情况，除表列品种外，当地有较大种植面积或种子生产量较大的其它品种也要在表内添加齐全一并填报。报表加盖公章后于6月15日前上报湛江市农业局农监与种子管理科，同时报送电子版到zjzzglk@126.com。
