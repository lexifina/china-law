# 关于组织企业参加粤台高效农业发展交流会的通知

湛农通〔2018〕229号

各县（市、区）农业局（农业事务管理局）：

2018湛江·东盟农产品交易博览会将于2018年6月7日在湛江国际会展中心举办，会议期间将举办粤台高效农业发展交流会活动。为组织开好这次交流会，现就有关事项通知如下：

一、交流会时间：2018年6月8日上午9:00—12:00。

二、参加人员

（一）各县（市、区）农业局分管领导1名；

（二）市级以上农业龙头企业负责人各1名。

三、交流会地点：湛江喜来登酒店五楼华威2号厅。

四、报到时间：2018年6月8日上午8:30—9:00。

请县（市、区）农业局按照名额安排表所分配的名额积极发动企业参会，参会人员回执请于2018年6月5日前发回我局信息科邮箱（zj3220023@126.com），请参会人准时到会。

附件：1．粤台高效农业发展交流会市级以上农业龙头企业参会名额安排表

2. 参会人员回执

3. 2018湛江·东盟农产品交易博览会粤台高效农业发展交流会方案
