# 转发关于组织申报2018年农村一二三产业融合发展产业兴村强县示范项目的通知

湛农通〔2018〕265号

各县（市、区）农业局（农业事务管理局）：

现将省农业厅《关于组织申报2018年农村一二三产业融合发展产业兴村强县示范项目的通知》（粤农财〔2018〕10 号）转发给你们，根据农业农村部、财政部计划建设一批乡土经济活跃、乡村产业特色明显的农业产业强县要求，以农业产业强镇为示范实施载体，广东省每个地级市可推荐1-2个申报名额。

请各县（市、区）农业局结合实际，严格按照省农业厅的创建条件与申报要求，经报请县级人民政府后，以县级人民政府为申报主体实行自主申报。县级人民政府对所申报材料真实性、准确性、可行性负责。县级人民政府审核申报材料并盖章确认后，所有申报材料一式10份于2018年6月25日前正式书面行文报送湛江市农业局（同时报送电子版至湛江市农业局农产品加工管理科邮箱），以便按程序报省审批。

附件：省农业厅《关于组织申报2018年农村一二三产业融合发展产业兴村强县示范项目的通知》（粤农财〔2018〕10 号）
