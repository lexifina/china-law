# 转发关于2018年广东省名牌产品（农业类）申报和复审的通知

湛农通〔2018〕268号

各县（市、区）农业局（农业事务管理局）：

为更好地做好广东省名牌产品（农业类）申报和复审工作，现将《关于2018年广东省名牌产品（农业类）申报和复审的通知》（详见附件1）转发给你们。请按如下要求一并做好申报和复审工作：

1、申报和复审。重视农业品牌建设，唱响“品牌强农”主旋律，请各县（市、区）农业局积极组织相关企业开展2018年广东省名牌产品（农业类）申报和复审工作。

2、审核和推荐。完成网上申报后，请各县（市、区）农业局对企业报送纸质申报书和相关材料原件审核，确保提交材料与原件相符后，填写审核推荐表（详见附件2）。

3、报送和时间。请各县（市、区）农业局于8月10日前将纸质申报书（一式两份）和审核推荐表报送至湛江市农业局，地址：湛江市赤坎区百园路63号。
