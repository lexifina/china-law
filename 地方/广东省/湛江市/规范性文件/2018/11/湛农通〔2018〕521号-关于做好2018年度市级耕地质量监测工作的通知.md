# 关于做好2018年度市级耕地质量监测工作的通知

湛农通〔2018〕521号

各县（市、区）农业局（农业事务管理局）、市农检中心：

为准确掌握全市耕地质量变化动态，对各地耕地质量提升行动实施效果进行科学评价，推动我市农业供给侧结构性改革和绿色农业发展，我市于2017年在国家级、省级耕地质量长期定位监测点的基础上，建立了市级耕地质量监测网络，布设监测点长期开展耕地质量监测工作。为继续做好2018年度市级耕地质量监测工作，现就有关事项通知如下：

一、认真开展好监测点土壤样品采集工作

每年秋收后，各地须于12月底前完成监测点位的野外调查与取样。大田土壤样品采取深度为0-20cm，蔬菜地为0-30cm。采用“X”法、“S”法或棋盘法其中的任意一种方法，均匀随机采取5-10个采样点，充分混合后，用四分法留取2kg。采样工具用木铲、竹铲或不锈钢土钻等。一袋土样填写两张标签，内外各一，同时要填报《田间作业记载表》。如果去年没有填报《市级耕地质量监测点基本情况记载表》和《市级耕地质量监测点土壤剖面性状记载表》的，今年需要补报。土壤样品采集后，要尽快风干，去除植物残体、石块后装袋，连同相关表格寄到我局种植业管理科，表格同时发送电子版（空白表请自行到电子邮箱zj3220060@163.com的收件箱下载，密码为123456）。

二、在雷州市增设2个监测点位

为进一步完善我市耕地质量监测网络，2018年在雷州市增设2个监测点位，编号为zj031-zj032。请雷州市从省农业厅《关于认真做好耕地质量等级调查和肥料使用情况调查工作的通知》（粤农办〔2017〕577号）中规定的备选点中自行选点作为新增的监测点。监测点一经选定后非因特殊原因不得随意变更调整，因此所选监测点必须具有代表性和延续性，所在田块在较长时期内应不会转做非农用途；尽量避免与省耕地肥料总站的耕地质量长期定位监测点（即原地力监测点）、2017年布设的市级耕地质量监测点在同一乡镇，实在无法避免在同一乡镇的，应在相距较远的田块进行选点。增设的监测点位需填报以上三种表格。

三、由湛江市农产品质量安全监督检测中心承担土壤样品检测、保存任务

参照国家级、省级耕地质量监测相关工作要求，市级监测点土样的检测任务主要是检测土样的pH、有机质、全氮、水解性氮、有效磷、速效钾等6项指标，并对土样进行长期保存。经局党组会议讨论通过，现将2017、2018年度市级耕地质量监测共62个土样的检测、保存任务下达给市农检中心承担，市农检中心在收到土样后及时开展土样检测工作，并将检测报告反馈我局种植业科。

四、保障监测工作经费

今年的监测相关工作经费，由我局在2018年农业配套资金中的农业项目管理工作经费安排解决，其中各地土样采集补助经费详见附件1；安排市农检中心2017、2018两个年度的土样检测、保存补助经费3.1万元。请你们收到通知后抓紧时间将本单位的银行账户的账号、户名、开户行等信息发到我局种植业科电子邮箱。
