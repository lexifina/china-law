# 关于转发《吸纳“三长”等进入县、市镇（街道）科协领导机构》的通知

湛农通〔2019〕70号

各县（市、区）农业局（农业事务管理局）：

现将省科学技术协会、省卫生健康委员会、省教育厅、省农业农村厅《关于吸纳“三长”等进入县、市镇（街道）科协领导机构的通知》（粤科协联〔2018〕23号）转发给你们，请认真研究文件内容，鼓励有关人员进入县、乡镇（街道）科协领导机构任职、兼职、挂职，推进我市农业产业发展。

附件：《关于吸纳“三长”等进入县、市镇（街道）科协领导机构的通知》（粤科协联〔2018〕23号）

湛江市农业农村局

2019年2月14日
