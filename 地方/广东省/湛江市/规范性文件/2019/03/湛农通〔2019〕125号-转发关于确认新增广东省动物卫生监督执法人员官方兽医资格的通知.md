# 转发关于确认新增广东省动物卫生监督执法人员官方兽医资格的通知

湛农通〔2019〕125号

各县（市、区）农业农村（畜牧兽医）局、湛江经济技术开发区农业事务管理局、南三岛滨海旅游示范区社会事务局：

现将省农业农村厅《关于确认新增广东省动物卫生监督执法人员官方兽医资格的通知》（粤农农函〔2018〕131号）转发给你们，并就有关事项通知如下：

一、省农业农村厅2018年确认新增723人（详见附件2）官方兽医资格，同时取消271人（详见附件3）官方兽医资格。本次确认的官方兽医，省农业农村厅不再制发《广东省官方兽医证》，官方兽医编号请按照之前规则，分县（市、区）编号。

二、请各地于 2019年1月31日前在全国兽医队伍信息管理系统(http://202.127.42.62/EXAMVET/reg/login.jsp）中的官方兽医信息管理子系统对新增官方兽医信息进行录入。官方兽医离开动物及其产品检疫和其他相关动物卫生监督执法岗位的，应当取消其官方兽医资格，并及时在系统中注销。

三、各地如有符合官方兽医资格条件的新增人员或需要调整的人员等，请以县（市、区）为单位统一于3月15日前将名单报送我局兽医科。

附件：1. 省农业农村厅《关于确认新增广东省动物卫生监督执法人员官方兽医资格的通知》（粤农农函〔2018〕131号）

2. 广东省动物卫生监督执法人员官方兽医资格确认人员名单

3. 广东省动物卫生监督执法人员官方兽医资格取消人员名单
