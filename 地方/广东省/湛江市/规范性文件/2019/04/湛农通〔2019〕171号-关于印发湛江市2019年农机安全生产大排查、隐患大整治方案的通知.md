# 关于印发湛江市2019年农机安全生产大排查、隐患大整治方案的通知

湛农通〔2019〕171号

各县（市、区）农业农村局（农业事务管理局）：

为了深入贯彻落实习近平总书记、李克强总理、李希书记、马兴瑞省长和郑人豪书记、姜建军市长等领导同志关于江苏响水天嘉宜化工有限公司“3·21”特别重大爆炸事故有关重要批示指示精神，深刻吸取江苏响水天嘉宜化工有限公司“3·21”特别重大爆炸事故教训，举一反三，全面开展各行业领域安全生产大排查、隐患大整治工作，防范遏制较大以上生产安全事故，按照《中共湛江市委办公室湛江市人民政府办公室关于深刻吸取江苏响水“3·21”爆炸事故教训做好全市安全生产大排查、隐患大整治工作的通知》（湛委办发电〔2019〕8号）要求和3月27日全省、全市安全生产工作视频会议部署，结合我市农机安全生产实际，制定了《湛江市2019年农机安全生产大排查、隐患大整治方案》，现下发给你们，请认真贯彻落实。

湛江市农业农村局

2019年4月8日

公开方式：主动公开
