# 关于加快推动政策性农业保险实施的通知

湛农通〔2019〕237号

各县（市、区）农业农村局（农业事务管理局）：

为更好落实省厅《关于印发2018－2020年广东省政策性农业保险实施方案的通知》（粤农规〔2018〕2号）文件精神，加快推动湛江市政策性农业保险实施，做好此项顺民意、谋民利、得民心、解民忧的惠民利民工程，现就有关事项通知如下：

一、充分认识政策性农业保险的意义

实行政策性农业保险，是创新政府救灾方式，提高财政资金使用效益的一项重要举措。对于分散农业风险，增强农业防灾减灾能力，完善和补充农业农村社会保障体系，促进农民收入可持续增长具有重要的作用。目前我市已进入雨季，雷暴、强降雨、台风天气多发，对农业生产危害极大。加快推动政策性农业保险工作，进一步完善农业风险防范体系，维护农民切身利益，符合广大农民群众的心愿。

二、加强组织领导，明确责任分工

政策性农业保险工作政策性强、涉及面广，各单位要高度重视，精心组织，切实抓好政策性农业保险的各项工作。当前各县（市、区）机构改革刚结束，部门重组、职责划转正处于衔接期，各单位要发挥主导作用，明确牵头领导、责任部门、专人负责此项工作，确保政策性农业保险工作的连续性、稳定性、有效性，防止工作断档、推诿扯皮、不作为现象发生。

三、落实属地管理责任，顺畅通联协调机制

各县（市、区）是本区域政策性农业保险管理主体，要加强责任感、紧迫感，要严格执行《2018-2020年湛江市政策性农业保险实施方案》（湛农通〔2018〕292号），根据本地实际情况，制定政策性农业保险实施细则和监管措施，切实把这项惠农支农政策落到实处。各县（市、区）要加强与经办机构的联络沟通，共享数据资料，及时掌握承保理赔、查勘定损情况，主动协调承保机构与农户的利益争端。

四、加快建立健全基层服务体系，提高服务水平

各县（市、区）要结合本地实际，主动作为，督促经办机构加快建立健全政策性农业保险基层服务体系，推动经办机构切实履行实施主体职责，扎实做好业务宣传、承保理赔、查勘定损和防灾减损等各项保险服务工作。在农户自愿投保的前提下，做到“愿保尽保”。对于农户在承保理赔、查勘定损过程中所反映的问题诉求，相关部门要主动协商经办机构妥善解决农户的合理诉求。对于不符合政策要求的，也要耐心做好解释工作。

五、强化宣传引导，进一步提高政策性农业保险社会效应

各县（市、区）要高度重视政策性农业保险工作，把宣传作为落实政策、推动工作的重要手段，推动宣传工作制度化、常态化，发挥宣传的正向推动和巩固提升作用。通过形式多样、内容丰富的宣传，扩大社会层面对政策性农业保险正面认识，持续增强社会公众的风险意识和保险意识，充分调动广大农户和相关各方的参与积极性，提高参保率。突出加强对保险条款、政策、原则和内涵等方面的宣传，准确把握和认真解释政策性农业保险保障“直接物化成本”的特点，引导投保农户树立合理预期，切实增强宣传的针对性和有效性，着力提高政策的知晓度和满意度。

六、其他事项

各县（市、区）于4月29日前向我局报送分管领导、工作联系人的姓名、职务、联系电话。并于5月17日、7月10日、9月10日前报送第一季度承保情况、上半年承保情况及工作开展情况汇报、第三季度承保情况。
