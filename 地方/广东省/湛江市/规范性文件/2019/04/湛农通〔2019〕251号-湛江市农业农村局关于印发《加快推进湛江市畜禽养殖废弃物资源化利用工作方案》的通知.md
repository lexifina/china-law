# 湛江市农业农村局关于印发《加快推进湛江市畜禽养殖废弃物资源化利用工作方案》的通知

湛农通〔2019〕251号

各县（市、区）农业农村局（农业事务管理局）：

为加快推进我市畜禽养殖废弃物资源化利用工作，现将《加快推进湛江市畜禽养殖废弃物资源化利用工作方案》印发给你们，请认真贯彻执行。执行中遇到的问题，请径向湛江市农业农村局反映。

湛江市农业农村局

2018年4月29日

（联系人：钟伟宏 联系人：3227890）
