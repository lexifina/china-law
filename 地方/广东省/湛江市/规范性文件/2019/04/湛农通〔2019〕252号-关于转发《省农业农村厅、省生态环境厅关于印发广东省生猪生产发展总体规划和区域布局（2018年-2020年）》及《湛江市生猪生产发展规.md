# 关于转发《省农业农村厅、省生态环境厅关于印发广东省生猪生产发展总体规划和区域布局（2018年-2020年）》及《湛江市生猪生产发展规划和区域布局（2019）》的通知

湛农通〔2019〕252号

各县（市、区）农业农村局（农业事务管理局）：

为做好当前我市生猪生产发展总体工作，确保畜牧业稳定发展，现将省农业农村厅、省生态环境厅《关于印发广东省生猪生产发展总体规划和区域布局（2018年-2020年）的通知》（粤农农〔2019〕185号）及《湛江市生猪生产发展规划和区域布局（2019）》转发给你们。请各地主管部门根据文件精神，结合实际，制定当地具体发展规划和区域布局，并认真抓紧落实。

附件：1. 省农业农村厅、省生态环境厅《关于印发广东省生猪生产发展总体规划和区域布局（2018年-2020年）的通知》（粤农农〔2019〕185号）

2. 湛江市生猪生产发展规划和区域布局（2019）
