# 转发关于做好近期恶劣天气防御工作的紧急通知

湛农通〔2019〕253号

各县（市、区）农业农村局，广东省渔政总队湛江支队：

现将《关于做好近期恶劣天气防御工作的紧急通知》（粤农农电〔2019〕12号）转发给你们，请按照通知要求，认真抓好汛期渔船安全监管和本次恶劣天气的防御工作，切实落实值班值守，及时发布预警预报，做到不留任何隐患。
