# 转发关于填报2018年度广东农业品牌经济调查表的通知

湛农通〔2019〕257号

各县（市、区）农业农村局（农业事务管理局），各有关企业：

为贯彻落实“粤字号”品牌强农实施意见要求，扎实做好农业品牌建设工作，建立品牌监测机制，全面掌握农业品牌发展情况，现将省农业农村厅《关于填报2018年度广东农业品牌经济调查表的通知》转发给你们，现面向有效期内的广东省名牌产品（农业类）和入库的广东省名特优新农产品生产经营主体开展2018年度农业品牌经济调查表填报工作。有关事项通知如下：

一、报送内容及方式

请有效期内的广东省名牌产品（农业类）、省“十大名牌”系列农产品和入库的广东省名特优新农产品生产经营主体，在广东省名牌产品（农业类）网（www.gdmpxt.org）上凭原有帐号登录系统，进入“2018年农业品牌调查”栏目，如实填报调查信息。

二、填报时间要求

请各县（市、区）认真做好组织协调工作，广泛发动并督促报送主体单位于5月19日前完成经济调查表填报工作。

系统填报技术服务电话：4000330890。
