# 关于印发《湛江市农业农村局2019年扎实推进产业精准扶贫工作方案》的通知

湛农通〔2019〕287号

各县（市、区）农业农村局（农业事务管理局），局各相关科室：

为实现脱贫攻坚“三年攻坚、两年巩固，到2020年如期完成”总体目标，要举全局之力，多措并举，进一步扎实推进产业精准扶贫工作，坚决完成我局新时期精准扶贫精准脱贫的工作任务。为此，根据湛江市扶贫开发领导小组关于印发《湛江市2019年精准扶贫责任清单》(湛扶组〔2019〕10 号)的通知，经研究决定，现将《湛江市农业农村局2019年扎实推进产业精准扶贫工作方案》印发你们，请遵照落实。

湛江市农业农村局

2019年4月8日
