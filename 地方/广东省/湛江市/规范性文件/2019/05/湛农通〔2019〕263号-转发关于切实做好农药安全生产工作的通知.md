# 转发关于切实做好农药安全生产工作的通知

湛农通〔2019〕263号

各县（市、区）农业农村局（农业事务管理局）：

现将广东省农业农村厅《关于切实做好农药安全生产工作的通知》（粤农农办〔2019〕352号）转发给你们，请按照通知的要求，高度重视，切实履行安全生产责任，深入开展安全生产检查，严格执法，坚决消除安全隐患，加强宣传培训，提高安全生产意识和水平。各县（市、区）农业农村局（农业事务管理局）要对本辖区农药安全生产监管工作进行全面总结，内容包括主要做法经验、取得成效、存在问题、整改情况及意见建议，认真填写《农药安全生产检查情况表》，于每年11月15日前报送总结和情况表到我局种植业管理科（植保植检办公室）。

附件：省农业农村厅《关于切实做好农药安全生产工作的通知》（粤农农办〔2019〕352号）

湛江市农业农村局
