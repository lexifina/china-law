# 关于公布湛江市2018年度农民专业合作社市级示范社和市级示范性家庭农场名录的通知

湛农通〔2019〕313号

各县（市、区）农业农村局（农业事务管理局）：

根据《湛江市农业局关于湛江市市级农民专业合作社示范社评定及监测办法（试行）》和《湛江市市级示范性家庭农场认定管理办法（试行）》，按照“自愿申报、择优推荐、从严评定”的原则，经组织发动、自愿申报、县级农业部门审核把关和择优推荐，市级实地抽核、专家评审、局党组会议讨论和网上公示，决定评定雷州市那毛福平种养专业合作社等3家农民专业合作社为我市2018年度农民专业合作社市级示范社，雷州市荣奇家庭农场等19家家庭农场为我市2018年度市级示范性家庭农场（名单见附件），现予公布。

附件：1．湛江市2018年度农民专业合作社市级示范社名单（3 家）

2．湛江市2018年度市级示范性家庭农场名单（19家）

湛江市农业农村局

2019年5月14日
