# 关于组织企业代表参加2019广东·东盟农博会的通知

湛农通〔2019〕334号

各县（市、区）农业农村局：

2019广东·东盟农产品交易博览会（东盟农博会）将于5月30日至6月2日在我市海东新区奥体中心举办。为办好这次会展，东盟农博会筹委会特邀农产品大宗采购商——北京一亩田新农网络科技有限公司、广东一人一亩田网络科技有限公司以及先进农业技术供应商——摩泰科水管理（深圳）有限公司和以色列纳安丹（广西）有限公司参会，并举办一亩田农产品B2B电子商务推介会及以色列滴灌技术推介会，推介会将重点推介新型农产品销售模式，推介以色列先进和种植管理技术，对全面拓宽我市农产品销售渠道，降低企业种植养护成本和提升企业种植管理能力有借鉴作用。

请各县（市、区）农业农村局积极组织发动辖区内种植企业、合作社以及家庭农场自行前往东盟农博会会场参加推介会。有关事宜请及时与我局市场信息与交流合作科或筹委会联系。
