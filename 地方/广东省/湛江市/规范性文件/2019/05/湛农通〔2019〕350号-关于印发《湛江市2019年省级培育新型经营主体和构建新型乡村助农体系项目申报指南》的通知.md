# 关于印发《湛江市2019年省级培育新型经营主体和构建新型乡村助农体系项目申报指南》的通知

湛农通〔2019〕350号

各县（市、区）农业农村局（农业事务管理局），局直属单位：

根据省农业农村厅2019年省级涉农转移支付资金区域绩效考核目标和《关于提前下达2019年省级涉农转移支付资金的通知》（粤财农〔2018〕314号）、《关于下达2019年省级涉农转移支付资金的通知》（粤财农〔2019〕66号），其中下达给我市2019年培育新型经营主体和构建新型乡村助农服务体系项目资金290万元，现将《湛江市2019年省级培育新型经营主体和构建新型乡村助农体系项目申报指南》印发给你们，请按你们照该申报指南要求认真组织做好项目申报工作。

附件：湛江市2019年省级培育新型经营主体和构建新型乡村助农体系项目申报指南

湛江市农业农村局

2019年5月28日
