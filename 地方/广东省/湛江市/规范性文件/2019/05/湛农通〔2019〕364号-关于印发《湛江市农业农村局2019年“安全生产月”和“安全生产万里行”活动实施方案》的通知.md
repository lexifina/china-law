# 关于印发《湛江市农业农村局2019年“安全生产月”和“安全生产万里行”活动实施方案》的通知

湛农通〔2019〕364号

各县（市、区）农业农村局（农业事务管理局），局相关科室及局属单位：

根据市安全生产委员会《湛江市2019年“安全生产月”和“安全生产万里行”活动方案》（湛安〔2019〕12号）要求和部署，结合我市农业安全生产工作实际，现将《湛江市农业农村局2019年“安全生产月活动”和“安全生产万里行”实施方案》印发给你们，请认真贯彻落实。

湛江市农业农村局

2019年5月29日

公开方式：主动公开
