# 关于成立湛江市农业农村局资产管理领导小组的通知

湛农通〔2019〕479号

局各科室、直属单位：

为加强我局资产管理，维护国有资产的安全和完整，优化资产配置，提高资产使用效率，现成立湛江市农业农村局资产管理领导小组，组成如下：

组 长：龙锦贤 调研员

副组长：孙诚志 办公室主任

陈保强 人事科科长

朱逢莉 计划财务科科长

成 员：梁世华 办公室副主任

吴 景 办公室副主任科员

潘红波 办公室副主任科员

黄 真 计划财务科副主任科员

林华珍 计划财务科科员

吴智扬 办公室科员

领导小组办公室设在局办公室，负责领导小组日常工作，孙诚志同志兼任领导小组办公室主任。

湛江市农业农村局

2019年7月1日
