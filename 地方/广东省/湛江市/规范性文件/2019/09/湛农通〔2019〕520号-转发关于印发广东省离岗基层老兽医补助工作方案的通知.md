# 转发关于印发广东省离岗基层老兽医补助工作方案的通知

湛农通〔2019〕520号

各县（市、区）人民政府（管委会）：

最近，经省人民政府同意，省农业农村厅、财政厅、人力资源和社会保障厅联合印发了《关于印发广东省离岗基层老兽医补助工作方案的通知》（粤农农[2019]325号，见附件1）。市政府高度重视这项惠民工作，要求市农业农村局牵头会市财政局、市人力资源和社会保障局等有关单位认真贯彻落实（市府办文件呈批表见附件2）。省农业农村厅要求，各地级以上市要在11月10日前完成离岗基层老兽医身份认定工作，在12月10日前将离岗基层老兽医生活困难补助发放情况报省农业农村厅、财政厅、人力资源和社会保障厅备案。现将《通知》转发给你们，并结合实际，提出如下意见，请一并贯彻落实。

一、高度重视，积极组织实施。离岗基层老兽医补助关乎基层老兽医福祉，事关民生，是党和政府对离岗基层老兽医关心关怀的体现，各地各部门要高度重视，按照《广东省离岗基层老兽医补助工作方案》要求，抓细抓好，落实到位，积极落实补助资金，确保补助政策不打折扣。

二、严格审核，认真做好身份认定工作。各地要组织相关部门和乡镇政府，严格按照《广东省离岗基层老兽医补助工作方案》要求，组成精干得力的认定工作小组，认真做好离岗基层老兽医身份申报审核认定等工作，确保不漏一人。

三、把握尺度，稳妥做好政策解读工作。要把握好宣传尺度和口径，各地农业农村部门对内要加强宣传发动，做好政策解读，推进《广东省离岗基层老兽医补助工作方案》落实。对外要把握好尺度，不过分宣传和解读，避免引起其他群体的攀比，引发不稳定因素。

四、统筹推进。我市对工作年限低于10年的离岗基层老兽医补助标准和工作方案正在起草和征求意见阶段，待市政府同意后方能印发；但对其身份申报审核认定等工作与10年以上离岗基层老兽医身份申报审核认定等工作一并进行；各县（市、区）要在11月3日前完成离岗基层老兽医身份认定工作，并将有关资料报市农业农村局、市财政局、市人力资源和社会保障局复核。

五、严肃政策纪律。各级政府和部门要严格按照相关政策要求，规范操作，加强监管。
