# 转发关于离岗基层老兽医补助政策的补充通知

湛农通〔2019〕531号

各县（市、区）农业农村局（农业事务管理局、农业农村和水务局）、财政局、人力资源和社会保障局：

现将省农业农村厅、财政厅、人力资源和社会保障厅联合印发的《关于离岗基层老兽医补助政策的补充通知》（粤农农〔2019〕421号）转发给你们，请严格按照补充通知要求做好离岗基层老兽医的补助发放工作，现就有关事项通知如下：

一、严格审核把关。认真对照补充通知中“关于离岗基层老兽医补助发放对象问题 ”做好离岗基层老兽医身份认定的审核把关工作，做到符合条件的离岗基层老兽医不漏一人，不符合条件的不多一人，在确保依法依规的前提下，真正将这项惠民政策落到实处。

二、加快身份认定进度。各地要加快身份认定进度，加快人员的资格审核和公示，确保按时保质保量完成离岗基层老兽医的补助发放工作。

三、建立资格审查机制。为避免出现生活困难补助发放对象情况变更或去世后其他人冒领补助，各地要建立生活困难补助领取资格审查机制，定期核查领取补助人员的有关情况。

附件：《关于离岗基层老兽医补助政策的补充通知》（粤农农〔2019〕421号）
