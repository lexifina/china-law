# 关于2020年湛江市菠萝、深海网箱养殖优势产区现代农业产业园建设项目入库申报的通知

湛农通〔2019〕535号

各县（市、区）农业农村局（农业事务管理局、农业农村和水务局）：

根据省人民政府办公厅办公室《关于建设农业优势产业带（区）及现代农业产业园工作的签报》和省农业农村厅《关于组织开展2020年优势产区和特色产业现代农业产业园申报工作的通知》（粤农农计〔2019〕26号）精神，我市综合考虑决定组织申报湛江市菠萝、深海网箱养殖优势产区现代农业产业园（以下简称“优势产区现代农业产业园”），现向社会公开遴选一批项目实施主体和入库项目。请符合条件的企业抓紧时间上报，逾期不予受理。

附件：1.2020年湛江市菠萝优势产区现代农业产业园建设项目入库申报指南
