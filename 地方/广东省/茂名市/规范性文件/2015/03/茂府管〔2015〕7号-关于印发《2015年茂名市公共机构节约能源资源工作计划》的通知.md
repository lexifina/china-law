# 关于印发《2015年茂名市公共机构节约能源资源工作计划》的通知

(

各区、县级市公共机构节能主管部门，茂名滨海新区、高新区、水东湾新城管委会，市直有关单位：

现将《2015年茂名市公共机构节约能源资源工作计划》印发给你们，请认真贯彻执行。各地、各单位（系统）要结合各自实际制定工作计划，狠抓工作落实，共同推进我市公共结构节约能源资源工作再上新台阶。各区、县级市，茂名滨海新区、高新区、水东湾新城和市直有关单位要在3月30日前将本地、本单位（系统）2015年公共机构节约能源资源工作计划报送到

茂名市政府机关事务管理局。

茂名市人民政府机关事务管理局

2015年3月25日

（联系人：梁镇江，联系电话和传真：2838993）

2015年茂名市公共机构节约能源资源工作计划

2015年茂名市公共机构节约能源资源工作的总体思路是：紧紧围绕生态文明和绿色茂名建设目标任务，深入贯彻落实《公共机构节能“十二五”规划》和《广东省2014-2015年节能减排低碳发展行动方案》、《广东省“十二五”后半期节能行动计划》工作部署，以建立完善制度标准体系和工作机制为支撑，以推进重点工作为抓手，以开展宣传教育为保障，以提高能源资源利用效率为方向，重点推进以合同能源管理模式开展综合节能改造，充分发挥公共机构在全社会节能中的示范带动作用，共同推进我市公共机构节能工作再上新台阶。

一、合理分解下达节能目标任务，确保完成年度目标任务

2015年，全市公共机构节能目标为：人均综合能耗和水耗同比分别下降2.8%，单位建筑面积能耗同比下降2%。各区、县级市和市直有关单位（系统）要落实责任，将节能目标任务合理分解下达到所管辖的各级公共机构，采取切实措施，确保全面完成年度节能目标任务。

二、加强制度标准体系和工作机制建设，夯实工作基础

（一）逐步建立完善的制度标准体系。尽快完善《茂名市公共机构节能管理办法》、《茂名市公共机构合同能源管理办法》等制度标准的制定工作。各区、县级市和市直有关单位（系统）要结合实际尽快制定本地、本单位（系统）公共机构节能配套政策文件和制度标准，逐步推动全市公共机构节能工作步入规范化、法治化轨道。

（二）强化监督检查和评价考核。建立健全公共机构节约能源资源评价考核和监督检查问题导向工作机制，推动节能监督检查常态化、制度化。将节约能源资源目标完成情况、能源资源消费统计、节能管理远程培训、节能监察、计量器具配备和管理、节约型公共机构示范单位创建、节水型单位建设、采用合同能源管理模式开展既有建筑综合节能改造、购买新能源汽车、能源审计、推进绿色建筑等工作，纳入2015年度公共机构节能目标责任评价考核内容。加大节能监察和计量器具配备检查力度，力求监督检查做大做实。

（三）加强信息综合利用和督办工作。建立市、区（县级市）、镇三级公共机构节能通讯员制度，推进公共机构节能信息报送和信息交流，提高信息辅助决策服务水平。建立公共机构节能工作督办机制，定期通报全市公共机构节能专项工作完成情况，做好重点工作的督办落实。

（四）加强工作调研和业务指导。强化公共机构节约能源资源分类指导，重点加强对教育、科技、文化、卫生计生、体育、地税等系统、重点用能公共机构和重点工作推进不力地区的业务指导和专题调研。积极开展国家节约型公共机构示范单位、合同能源管理模式和新能源汽车考察调研工作。

（五）加强技术支撑体系建设。加大公共机构节能政策课题研究力度，探索建立公共机构节能技术顾问单位长效机制，夯实公共机构节能工作技术支撑和理论支持。

三、强化节能日常管理，落实节能措施

（一）提高统计工作质量。落实《公共机构能源资源消费统计制度》，进一步完善公共机构名录库，扩大统计范围，开展统计培训和统计数据会审，加强统计数据质量检查，按时保质保量完成统计工作。

（二）推进计量器具配备和管理。按照《公共机构能源资源计量器具配备和管理》要求，开展能源资源消费分户、分区、分项计量工作，完善计量器具配备检定，加强日常管理和培训。

（三）开展能源审计。对重点用能公共机构等单位开展能源审计，根据能源审计结果，采取提高能源资源利用效率的措施，实施既有建筑综合节能改造，提高公共机构能源资源利用水平。

四、完成节约型公共机构创建任务

（一）确保完成第二批节约型公共机构示范单位创建任务。严格按照国家确定的创建名单，采取切实措施，加大工作力度，有序推进我市第二批节约型公共机构示范单位创建工作。各地、各单位（系统）要加强组织领导和沟通协调，给予政策和资金支持，定期开展检查和评估，督促创建单位落实实施方案提出的创建内容，组织做好评价验收工作，确保完成国家下达的创建任务。

（二）突出重点用能单位（系统）节约能源资源的示范带动作用。落实《广东省2014-2015年节能减排低碳发展行动方案》要求，协调指导教育、文化、卫生计生、体育系统组织推进节约型高校、节约型医院、节约型文化场馆、节约型体育场馆建设工作，确保完成我市节约型公共机构建设任务。

（三）组织推进节水型单位建设工作。会同市水务局继续推进我市节水型单位建设工作，大力推广使用节水技术和节水器具，组织开展节水型单位申报、验收工作。

五、推广合同能源管理模式，积极开展综合节能改造

（一）大力推进以合同能源管理模式开展综合节能改造。加强政策引导，进一步发挥市场机制在公共机构节能改造中的主导作用，鼓励采用合同能源管理模式开展公共机构既有建筑综合节能改造。落实《广东省绿色建筑行动实施方案》，在公共机构新建建筑和国家机关既有办公建筑维修改造中严格执行绿色建筑标准。

（二）开展重点用能单位和系统（部位）节能改造。集中力量继续做好党政机关集中办公区、高校、医院等重点用能单位和数据中心、空调、照明、食堂等重点用能系统及部位的节能改造。

六、大力推广应用节能新产品、新技术

（一）有序推进新能源汽车购买工作。落实《政府机关及公共机构购买新能源汽车实施方案》和《广东省人民政府办公厅转发国务院办公厅关于加快新能源汽车推广应用指导意见的通知》（粤府办〔2014〕48号）要求，结合我市公务用车改革进程，制定我市政府机关及公共机构购买新能源汽车实施方案，组织做好我市政府机关及公共机构公务用车优先采购新能源汽车工作。

（二）加快推进LED照明产品推广应用工作。贯彻落实《广东省推广应用LED照明产品实施方案》，强化督促指导，组织开展公共机构高效节能照明产品改造。鼓励采用合同能源管理模式，开展以LED照明产品为主要内容的既有建筑综合节能改造。全市各级公共机构节能主管部门要率先完成室内LED照明产品改造。

七、深入开展节能宣传教育工作，加强能力建设

（一）组织做好公共机构节能宣传工作。创新宣传模式，积极利用广播电视、报刊、政府网等传统主流媒体和微博、微信等新媒体开展日常宣传活动，组织开展公共机构节能宣传月和低碳日系列宣传活动，做好我市节能宣传作品征集和获奖作品宣传推广工作。以节能专题报告会、现场会、展览展示会等形式，举办丰富多彩的专题宣传活动。

（二）加强能力建设。建立健全节能教育长效机制。积极参加国家机关事务管理局和省政府机关事务局组织开展的公共机构节能管理干部培训班、第三期公共机构节能管理远程培训等教育培训活动，继续分层次、分专题开展全市公共节约能源法、合同能源法、节水及计量和能源审计等专题培训工作。

八、做好“十三五”规划编制工作

组织开展“十二五”时期公共机构节能工作情况调研，全面梳理各项工作进展情况，认真总结取得的成绩和经验，查找存在的问题和不足，突出节能重点领域改革要求和工作重点，认真做好《茂名市公共机构节能“十三五”规划》编制工作。

（二）加快推进LED照明产品推广应用工作。贯彻落实《广东省推广应用LED照明产品实施方案》，强化督促指导，组织开展公共机构高效节能照明产品改造。鼓励采用合同能源管理模式，开展以LED照明产品为主要内容的既有建筑综合节能改造。全市各级公共机构节能主管部门要率先完成室内LED照明产品改造。

七、深入开展节能宣传教育工作，加强能力建设

（一）组织做好公共机构节能宣传工作。创新宣传模式，积极利用广播电视、报刊、政府网等传统主流媒体和微博、微信等新媒体开展日常宣传活动，组织开展公共机构节能宣传月和低碳日系列宣传活动，做好我市节能宣传作品征集和获奖作品宣传推广工作。以节能专题报告会、现场会、展览展示会等形式，举办丰富多彩的专题宣传活动。

（二）加强能力建设。建立健全节能教育长效机制。积极参加国家机关事务管理局和省政府机关事务局组织开展的公共机构节能管理干部培训班、第三期公共机构节能管理远程培训等教育培训活动，继续分层次、分专题开展全市公共节约能源法、合同能源法、节水及计量和能源审计等专题培训工作。

八、做好“十三五”规划编制工作

组织开展“十二五”时期公共机构节能工作情况调研，全面梳理各项工作进展情况，认真总结取得的成绩和经验，查找存在的问题和不足，突出节能重点领域改革要求和工作重点，认真做好《茂名市公共机构节能“十三五”规划》编制工作。
