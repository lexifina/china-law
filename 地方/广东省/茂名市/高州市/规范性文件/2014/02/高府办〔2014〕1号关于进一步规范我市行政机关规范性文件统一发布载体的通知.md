# 高府办〔2014〕1号关于进一步规范我市行政机关规范性文件统一发布载体的通知

各镇人民政府，各街道办事处，市府直属各单位：

为加强行政机关规范性文件管理，促进依法行政，根据《国务院关于加强市县政府依法行政的决定》、《广东省行政执法责任制条例》、《广东省行政机关规范性文件管理规定》、《广东省法治政府建设指标体系（试行）》及《茂名市人民政府办公室关于进一步规划我市行政机关规范性文件统一发布载体的通知》（茂府办〔2013〕61号）等有关规定，现就进一步规范我市行政机关规范性文件发布载体管理有关事项通知如下：

一、市政府以及市直部门规范性文件的统一发布载体为市政府门户网站。

二、自本通知印发之日起，未按本通知要求在规定载体统一发布的规范性文件一律无效，不得作为行政管理的依据。

三、各镇人民政府（街道办事处）均要建立规范性文件统一发布制度，发布载体由各镇人民政府（街道办事处）决定。

高州市人民政府办公室

2014年1月28日
