# 高府办函〔2014〕17号印发高州市2014年城市管理综合整治工作方案的通知

各镇人民政府，各街道办事处，市府直属有关单位：

《高州市2014年城市管理综合整治工作方案》业经市人民政府同意，现印发给你们，请认真贯彻执行。执行中遇到问题，请迳向市创文办反映。

高州市人民政府办公室

2014年1月20日

高州市2014年城市管理综合整治工作方案

为强化城市管理，创造良好的市容环境，维护市民正常的工作和生活秩序，根据有关规定，结合我市开展创建省文明城市、省卫生城市和实施“城乡清洁工程”的实际，决定在2014年1月至4月底开展城市管理综合整治。特制定本工作方案。

一、整治目的

通过阶段性的集中力量，针对城市“脏乱差”突出问题、重点区域进行从严整治，使市区的市容市貌、环境卫生、交通秩序等更加适应城市发展的需要，确保创建省文明城市、省卫生城市和“城乡清洁工程”工作得到有效实施，推进宜居城乡、文明幸福高州建设工作。

二、整治任务和内容

按照市委办、市府办《关于印发〈高州市创建广东省文明城市实施方案〉的通知》（高办发〔2010〕5号）和《关于印发〈高州市“城乡清洁工程”实施办法〉的通知》（高办发〔2011〕2号）的有关要求，落实从严整治和规范化管理措施，具体整治任务和内容为：重点街道“四清理”、主要街道“五规范”、整个城区“六整顿”。

（一）重点街道“四清理”是：1、清理无证照经营；2、清理非法集市及路边市场；3、清理室外经营行为和占道经营饮食摊档；4、清理违规设置、摆放广告灯箱（牌匾）行为。

（二）主要街道“五规范”是：1、规范经批准临时占用公共场地等的经营行为；2、规范市区内建设工地的建设行为；3、规范各建设工地的土方开挖、建筑余泥和穿越城区过境公路的散装物体运输的运输行为；4、规范城市建成区内驳接雨水、污水进入地下排水系统和开挖街道安装管线行为；5、规范市区的士、公交车辆营运秩序。

（三）整个城区“六整顿”是：1、整顿各类乱搭建和乱拉挂，重点是各住宅小区的乱搭建行为；2、整顿车辆乱停放行为；3、整顿乱丢垃圾、乱吐痰、乱张贴、乱涂画行为，整治卫生死角，强化门前“三包”责任，完善公共卫生责任区的清扫和保洁制度，消除“四害”孳生地；4、整顿非法营运和二轮、三轮摩托车的违章候客行为；5、整顿市区违规饲养禽畜行为；6、整顿市区超标播放高音喇叭（音响）、违规施工、违规燃放烟花爆竹造成噪声扰民行为。

三、整治重点和目标要求

（一）整治重点：突出抓好穿越城区过境公路的整治，确保畅通，严格管治中山路、府前路、文明路、光明路、高凉路、东方大道、茂名大道、冼太大道、桂圆路等重点街道（路），规范管理潘州中路、南新路、观山路、南关街、解放街等主要街道；完善规范公园路、广场路、沿江路和城区中小学校周边环境等公共场所的临时占道经营行为，强化城区江河的清洁整治。

（二）目标要求：重点街道和主要街道内无流动摊贩，临街门店入室经营，店面整洁，无超越门槛摆放商品、灯箱（广告牌匾）、伸缩篷(遮阳伞)和水泥墩等杂物；其他街道临街门店和临时摊档经营规范，无越线经营和移位经营行为，无乱摆放(设置)灯箱（广告牌匾）、伸缩雨篷、遮阳伞和水泥墩等杂物；所有街道和公共场所无影响市容秩序的“六乱”(乱摆卖、乱停放、乱搭建、乱拉挂、乱扔垃圾、乱堆放)现象。

五、责任分工

为确保综合整治行动顺利进行并取得良好效果，各相关职能部门要各司其职，各负其责，依法依规严格整治。

（一）查处无证照经营（由市工商局牵头负责，市卫生局、市文广新局配合）。

（二）清理市场以外的违规摊档、非法集市、路边市场（由市城监大队牵头负责，市工商局配合）。

（三）清理临街店铺的室外经营行为和占道经营的饮食店铺（由市城监大队牵头负责，市工商局、市卫生局、市食品药品监管局配合）。

（四）清理违规设置、摆放广告灯箱（牌匾）行为（由市城市规划管理局、市城监大队负责）；治理道路两侧控制区内非法广告设施设置行为(由市交通运输局牵头负责，市公安局、市公路局、市城市规划管理局配合)。

（五）规范经批准临时占用公共场地等的占道经营行为（由市城市规划管理局、市城监大队负责）。

（六）规范市区内建设工地的建设行为（由市住建局负责）。

（七）规范各建设工地的土方开挖和建筑余泥的运输行为（由市城市规划管理局牵头负责，市城监大队、市公安交警大队、市区中队配合）；加强对穿越城区过境公路散装物体运输车和矿泥运输车的监管，从严查处撒漏污染道路行为（由市交通运输局牵头负责，市公路局、市公安交警大队、市城监大队配合）。

（八）规范建成区内驳接雨水、污水进入地下排水系统和开挖街道安装管线行为（由市城市规划管理局牵头负责，市供电、供水、广播电视、通信等部门配合）。

（九）规范市区的士、公交车辆营运秩序（由市交通运输局牵头负责，市公安交警大队配合）。

（十）整顿各类乱搭建和乱拉挂，重点是各住宅小区的乱搭建行为（由市城市规划管理局、市城监大队负责）。

（十一）整顿不按公安交警部门划定位置停放机动车辆的乱停放行为，完善重点街道、主要街道交通标线（由市公安交警大队、市区中队负责）；完善城区街道人行道车辆停放标线（由市城监大队负责）。

（十二）整顿乱丢垃圾、乱吐痰等行为（由市环卫处负责）；清理河道的漂浮物和搭建物(由市水务局负责)。

（十三）整顿乱张贴行为（由市工商局牵头负责，市城市规划管理局配合）；主要街道的乱张贴整治工作由市城监大队督促承包公司落实。

（十四）整顿市场内环境卫生（由市场物业管理中心和开设市场的主管单位负责）。

（十五）整顿卫生死角，完善公共卫生责任区的清扫和保洁制度，消除“四害”孳生地（由市爱卫办牵头负责，各街道办、市城市规划管理局配合）。

（十六）整顿非法营运和二轮三轮摩托车的违章候客行为（由市公安交警大队牵头负责，市交通运输局配合）。

（十七）整顿市区违规饲养禽畜，尤其是违规养犬行为（由市公安局牵头，市畜牧兽医水产局、市爱卫办配合）。具体按照《高州市城区犬类管理专项整治实施方案》（高府办函〔2007〕50号）规定执行。

（十八）整顿市区生活噪声和建筑噪声。清理市区内安装超标高音喇叭（音响）、在市区道路上巡回播放商业广告的宣传车造成的噪声扰民行为（由市环保局牵头负责，市公安局、工商局、文广新局和城市规划管理局配合）；整顿市区违规燃放烟花爆竹造成噪声扰民行为（由市公安局牵头负责，各街道办配合）。

（十九）各单位、门店要落实门前“三包”（包卫生、包秩序、包绿化美化），自觉履行门前“三包”及公共卫生责任区的清扫保洁义务，重点是落实门前乱张贴的清理（由各街道办牵头负责，市创文办、市爱卫办配合）。

六、保障措施

（一）加强组织领导。各有关职能部门要在市城市管理综合整治工作领导小组的统一领导、指挥和协调下开展专项整治工作，按照工作分工，将任务层层分解落实，确保整治工作有计划、按步骤顺利实施。

（二）科学统筹安排。城市综合治理工作涉及面广、任务重，各职能部门要加大工作力度和强度，全力以赴投入综合整治工作之中，确保按规定时间完成工作任务；要统筹兼顾，科学安排，按计划要求抓紧抓好工作落实，做到集中整治与业务工作两不误、两促进。

（三）强化舆论宣传。要充分发挥新闻媒体舆论导向作用，利用简报、电视、广播、网络等宣传媒介，广泛宣传城市综合整治工作的重要意义和取得的成效，推动城市综合整治工作深入开展。

（四）强化制度管理。规划、住建、公安、工商、环保、卫生、食品药品监管、交通运输、文化等相关职能部门要严格执行《行政处罚法》和城市管理的有关法律法规、政策，共同做好城市管理行政执法工作。要建立健全一系列城市管理的相应制度，以制度管人，以制度管事，形成城市管理的长效机制。在整治过程中，有关部门要严格执行情况报告制度。从1月至3月为集中整治时间，集中整治时间内各单位、各工作组要将每周开展整治工作情况书面报市创文办（电话：6665599,邮箱：cjb6665599@163.com）。

（五）加强督促检查。为有效促进整治工作的开展，市创文办负责对城市综合整治工作进行督促、检查和指导。重点督查各部门各单位是否按工作部署和要求实施整治，对整治工作不力和整治不合格的部门、单位以督查简报的形式进行通报。
