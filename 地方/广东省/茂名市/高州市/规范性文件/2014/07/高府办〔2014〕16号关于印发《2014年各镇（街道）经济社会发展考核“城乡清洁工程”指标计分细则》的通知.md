# 高府办〔2014〕16号关于印发《2014年各镇（街道）经济社会发展考核“城乡清洁工程”指标计分细则》的通知

高府办〔2014〕16号

印发《2014年各镇（街道）经济社会

发展考核“城乡清洁工程”指标

计分细则》的通知

各镇人民政府，各街道办事处，市府直属有关单位：

《2014年各镇（街道）经济社会发展考核“城乡清洁工程”指标计分细则》业经市人民政府同意，现印发给你们，请认真贯彻执行。执行中遇到问题，请迳向市住建局反映。

高州市人民政府办公室

2014年7月8日

2014年各镇（街道）经济社会发展考核

“城乡清洁工程”指标计分细则

根据《茂名市2014年各县（市、区）经济社会发展考核指标及评分办法》要求，2014年各县（市、区）经济社会发展考核新增加了“城乡清洁工程”指标，由城乡生活垃圾无害化处理率、环卫设施建设运营和环境卫生保洁清运等3个二级指标组成，每个指标均按100分制独立计算，权重分别占总分的21%、21%和58%。为相应做好我市“城乡清洁工程”考核计分工作，结合我市实际，制定本计分细则。

一、镇（街道）生活垃圾无害化处理率

（一）计分标准。

主要考核各镇（街道）生活垃圾无害化处理水平，指标满分为100分，用镇（街道）生活垃圾无害化处理量（吨）与镇（街道）生活垃圾产生量（吨）的比率乘以100，得出的积再乘以21%（该项所占权重）即是该项所得分数。

（二）有关说明。

1、计算公式。

镇（街道）生活垃圾无害化处理率（%）=镇（街道）生活垃圾无害化处理量（吨）&divide;镇（街道）生活垃圾产生量（吨）&times;100%。

2、数据来源。

（1）镇（街道）生活垃圾无害化处理量：以各镇（街道）生活垃圾收运至茂名市垃圾焚烧厂实际处理的垃圾量作为评价指标的依据。

说明：具体的数据由茂名市垃圾焚烧发电厂提供的账单为准，如遇有同一车垃圾是由两个或两个以上镇（街道）的垃圾量组成的，该量的核算则由镇（街道）工作人员与垃圾运输车司机同时确认为准。

（2）镇（街道）生活垃圾产生量：各镇（街道）圩镇、村庄等生活垃圾产生量总和。按照茂名市考核的计算标准，城区生活垃圾产生量以每人每日1公斤计算，镇（街道）、村庄以每人每日0.5公斤计算。

（3）人口数据：由市统计部门提供，采用常住人口数。

3、资料要求。

（1）茂名永诚环保资源开发有限公司（垃圾焚烧发电厂）提供高州市进场垃圾过磅称重数量的月度记录、垃圾处理费收取记录和票据等台账资料。

（2）市垃圾清运公司提供各镇（街道）转运垃圾重量的月度记录和票据等台账资料。

（3）镇（街道）提供转运垃圾重量的月度记录和票据等台帐资料。

说明：原则上要求收运双方每月要核准垃圾处理量。

二、环卫设施建设运营

指标满分为100分，从站、点建设及运营状况等三个方面进行考核计分，得分再乘以21%（该项所占权重）即是该项最后所得分数。

（一）镇（街道）垃圾转运（压缩）站（20分）。

计分标准：建成运营垃圾转运（压缩）站，购置垃圾运输车及其他相关工具，有专职驾驶及管理员，原则上按照“一镇（街道）一站一车一员”的标准核定。未建成垃圾转运（压缩）站的该项不得分。

计分方式：实地抽查项目建设和配备情况。

（二）村（居）垃圾收集点（50分）。

计分标准：镇（街道）主要道路两侧科学设置一定数量的垃圾收集点，各自然村要建适当数量的垃圾收集点。

计分方式：以村（居）委、市级各试点村、公路沿线及饮用水源流域沿岸村庄为重点，实地抽查垃圾收集点规划布点和建设使用情况。每条自然村建成一个垃圾收集点，以一村一点为单位，对没有建成垃圾收集点的自然村，扣一分一个村庄，扣完为止。

（三）站、点建设运营效果（30分）。

计分标准：根据镇（街道）生活垃圾转运（压缩）站建成及运营状况，分优、中、差三个等次，考核结果分别为30分、20分、10分，未建成运营的不得分。

计分方式：现场查看项目建设进度和运营管理情况，查阅有关资料。生活垃圾转运（压缩）设备保持正常工作状态，转运站管理人员熟悉压缩设备操作程序、站内排污、除臭设施完善，环境安全、保持文明整治的站容站貌为优，每缺少两项则依次评定为中、差。

三、环境卫生保洁清运

“环境卫生保洁清运”指标由新闻媒体曝光或群众投诉举报、专项检查或督查、整改落实和加分奖励四部分组成，满分为100分，四部分综合得分再乘以58%（该项所占权重）即是该项最后所得分数。

（一）新闻媒体曝光或群众投诉举报（10分）。

计分标准：茂名、高州两级督查每曝光一个环境卫生问题点扣0.5分，对群众投诉举报经查实的，每个环境卫生问题点扣0.5分，扣完为止。

计分方式：被新闻媒体（含报刊、电视台）在固定栏目曝光的环境卫生问题，群众通过电话、信函、信访、电子邮件等渠道向市宜居办及有关部门投诉的环境卫生问题。由市宜居办汇总统计有关情况（含时间、详细地点、类别、状况、媒体名称等），并列入扣分台账。同一地点的同一问题在整改期限内再次曝光的，不予重复扣分。同一地点的同一问题未得到有效整改并被再次曝光的，予以双倍扣分。

（二）专项督查（60分）。

计分标准：市“城乡清洁工程”专项督查组发现问题的，每个环境卫生问题点扣1分，扣完为止。

计分方式：市“城乡清洁工程”专项检查、督查组对全市各镇（街道）实施“城乡清洁工程”情况进行督查，内容及方式等详见《高州市实施“城乡清洁工程”督查巡查工作制度》。督查发现的环境卫生问题经市“城乡清洁工程”督查组研究决定后列入扣分台账。

（三）整改落实（20分）。

计分标准：茂名、高州两级市宜居办下发督办函后未及时整改的，每个环境卫生问题点扣1分，扣完为止。

计分方式：市宜居办对群众投诉、媒体曝光、专项督查、上级交办等未及时整改的突出问题下发督办函，涉及的镇（街道）应在3天内反馈整改情况（含书面整改情况、整改前后对比相片或整改视频等资料）。逾期未反馈的，视为未及时整改，列入扣分台账。同一地点多次被下发督办函的，按原扣分标准双倍扣分。

（四）加分奖励（10分）。

对在本年度积极配合做好迎接上级检查工作的镇（街道）给予加分奖励，迎检工作认真细致，受到上级好评的加1-10分。具体奖励分数由市宜居办根据迎检效果进行评定。
