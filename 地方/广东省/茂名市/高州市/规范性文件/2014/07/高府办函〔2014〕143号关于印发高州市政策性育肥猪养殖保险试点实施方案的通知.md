# 高府办函〔2014〕143号关于印发高州市政策性育肥猪养殖保险试点实施方案的通知

高府办函〔2014〕143号

印发高州市政策性育肥猪养殖

保险试点实施方案的通知

各镇人民政府，各街道办事处，市府直属有关单位：

《高州市政策性育肥猪保险试点实施方案》业经市人民政府同意，现印发给你们，请遵照执行。执行中遇到问题，请与市畜牧兽医水产局联系。

高州市人民政府办公室

2014年6月17日

高州市政策性育肥猪养殖保险试点实施方案

为贯彻落实国家生猪产业政策，促进高州生猪生产健康稳步发展，根据《农业保险条例》、财政部《关于2013年度农业保险保费补贴工作有关事项的通知》（财金〔2013〕7号）、广东省政府办公厅《关于大力推广政策性涉农保险的意见》（粤府办〔2012〕50号）、茂名市政府办公室《关于印发茂名市政策性育肥猪养殖保险试点实施方案的通知》（茂府办明电〔2014〕14号）的精神，结合我市生猪生产实际，特制定本方案。

以邓小平理论、“三个代表”重要思想为指导，深入贯彻落实科学发展观，以服务“三农”保障民生为宗旨，利用保险市场机制，开展政策性育肥猪养殖保险试点及对保险病死育肥猪无害化处理，保障我市生猪产品质量安全，减少生猪疫病传播和病死猪只对环境的污染，增强养殖户抵御风险能力，推动生猪生产业持续健康发展，促进农业安全、农民增收、农村稳定。

（一）三兼顾。即兼顾养殖户缴费能力、兼顾财政补贴能力、兼顾保险公司风险承受能力。

（二）多予少取。不以盈利为目的，在农民自愿参保的前提下，保险公司以优惠费率承保，各级政府给予农民一定比例保费补贴，并以其他优惠政策引导农民参保。

（三）积极稳妥推进。即遵循“先行试点，逐步完善，适时推广”的总体思路，按照“政府引导、市场运作、自主自愿、协同推进”的方式，积极稳妥地推进政策性育肥猪养殖保险试点工作。
