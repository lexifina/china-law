# 高府办函〔2014〕154号关于印发高州市实施“城乡清洁工程”督查工作制度的通知

(

高府办函〔2014〕154号

关于印发高州市实施“城乡清洁工程”

督查工作制度的通知

各镇人民政府，各街道办事处，市府直属有关单位：

《高州市实施“城乡清洁工程”督查工作制度》业经市人民政府同意，现印发给你们，请认真贯彻执行。执行中遇到问题，请迳向市宜居办反映。

高州市人民政府办公室

2014年7月10日

高州市实施“城乡清洁工程”督查

工作制度

为确保“城乡清洁工程”督查工作扎实有效开展，考核结果公平、公正，结合我市实际，制定本工作制度。

一、指导思想

以科学发展观为指导，认真贯彻落实党的群众路线教育实践活动精神，按照“造声势、加投入、树榜样、强责任”的工作要求，进一步增强各镇（街道）的责任意识，深入推进“城乡清洁工程”，不断改善城乡面貌和提升人居环境水平，努力建设美丽高州。

二、工作机构

市宜居城乡建设工作领导小组负责组织、指导全市“城乡清洁工程”督查工作的开展，日常工作由市宜居城乡建设工作领导小组办公室（设在市住房和城乡建设局，以下简称“市宜居办”）负责。成立市“城乡清洁工程”专项督查组，组长由市副处级以上领导干部担任，成员从市、镇（街道）两级有关单位人员，以及部分人大代表、政协委员和群众代表等组成的人员库中随机抽取。

三、工作内容

（一）生活垃圾无害化处理率。

通过查阅镇（街道）垃圾转运的数量记录、运收双方垃圾处理交收记录和票据等台账资料核查垃圾处理量。

（二）环卫设施建设运营情况。

1、镇（街道）垃圾转运（压缩）站。实地检查项目建设进度、运营管理及垃圾转运等情况。

2、村（居）垃圾收集点。实地抽查各镇（街道）街区、自然村垃圾收集点规划布点和建设使用情况。

（三）环境卫生保洁清运情况。

1、镇（街道）建成区：墟街区主次干道、公共场所、内街小巷、住宅小区、农贸市场、城乡结合部、主要出入口等干净整洁、保洁到位；

2、主要交通道路：高速公路出入口，国道、省道、县道、村道和铁路沿线清洁卫生，无垃圾乱丢乱堆；

3、车站站场：汽车站、公交车站等站场清洁卫生；

4、河流、干渠、湖泊池塘的水面无漂浮垃圾，沿岸、堤坝清洁卫生；

5、各村庄：路边、河边、池边、公共区域无垃圾乱丢乱堆；

6、环卫设施设备：垃圾桶（箱）按规定摆放，无散落垃圾；垃圾收集点垃圾及时清运，周边无成堆垃圾。

（四）难点热点督查。

1、群众反映强烈且长期得不到解决的难点问题；

2、新闻媒体曝光督办的整改问题；

3、地区或单位相互推诿的卫生死角；

4、各类督办案件的整改情况；

5、上级部门及领导交办的事项。

四、工作方式

市督查组每月不定期对各地城乡生活垃圾无害化处理率、各级环卫设施、核查群众投诉情况、回访整改落实和环境卫生保洁清运等情况等进行督查。具体工作程序如下：

（一）市宜居办在督查前制定督查计划（含路线安排等），组织落实督查人员、督查任务和督查时间。

（二）对督查中发现的环境卫生问题，督查人员须准确记录时间、详细地点、类别和卫生状况，拍摄照片或录像。

（三）督查组各成员根据相关计分标准，对督查地区的环卫设施、保洁清运等情况进行打分或扣分，并签名确认后提交市宜居办列入考核台账存档。

（四）督查人员须于督查后1日内将有关情况报送市宜居办。对初次发现但影响较大的环境卫生问题，督查后，市宜居办将专项督查发现且列入考核扣分台账的环境卫生问题以督办函的形式发给各有关镇（街道），跟踪督促限期整改。

（五）对茂名、高州两级“城乡清洁工程”专项督查组检查发现并以督办函形式督促整改的环境卫生问题，经督查人员回访仍未进行有效整改的，由市宜居办按“整改落实”类进行扣分。

五、工作监督

（一）计分通报。

每月，市宜居办将日常督查情况汇总整理并予以通报；每季度，市宜居办将各地城乡生活垃圾无害化处理率、环卫设施和保洁清运的得分情况进行汇总排名，及时报告市委、市政府和公开通报。年终按照4个季度的得分情况进行综合排名。

（二）督办问责。

对各镇（街道）热点、难点、重点及突出的环境卫生问题，要逐步建立健全“日常督查（督办函）→督促整改→回访检查→提请问责”工作机制，督促落实整改责任人和整改时限，督促完善长效管理机制，及时跟踪整改情况。对在实施“城乡清洁工程”工作中不履行、不正确履行职责或履行职责不力，造成不良影响和后果的行为，将提请市委、市政府进行问责。

六、工作要求

（一）督查人员要以高度负责的态度，客观公正、实事求是地记录实地督查状况，准确记录时间、详细地点、类别和卫生状况等，并拍摄清晰的照片存底。

（二）督查人员要自觉遵守廉洁自律的有关规定，不得在督查行动前，以任何形式通知各有关地区，不得接受镇（街道）款待。

（三）市宜居办及督查组工作人员要注意做好环境卫生问题、图片资料的整理、归档保存和备份，做到工作可查询，问题有着落，推进督查工作的规范化、制度化。

（四）各镇（街道）、各有关单位和个人根据督查要求，要及时提供与督查事项有关的文件、资料和情况，如实反映有关问题，按时回复整改落实情况。)
