# 高府办函〔2014〕162号印发高州市落实2014年茂名市挂牌督办环境问题工作方案的通知

有关镇人民政府，有关街道办事处，市府直属有关单位：

《高州市落实2014年茂名市挂牌督办环境问题工作方案》业经市人民政府同意，现印发给你们，请认真贯彻执行。执行中遇到的问题，请迳向市环保局反映。

高州市人民政府办公室

2014年7月25日

高州市落实2014年茂名市挂牌督办

环境问题工作方案

为贯彻落实党的十八届三中全会和习近平总书记系列重要讲话精神，深入贯彻落实科学发展观，加快解决重点环境问题，保障人民群众环境权益，确保完成上级部门对我市重点环境问题的挂牌督办任务，使白沙河流域水污染治理取得根本性好转，根据茂名市环境保护局、茂名市监察局《关于2014年茂名市挂牌督办环境问题的通知》（茂环〔2014〕73号）的要求，结合我市实际，特制定本方案。

一、加强组织领导

为加强对我市挂牌督办环境问题整治工作的领导，成立高州市落实2014年茂名市挂牌督办环境问题工作领导小组，由李德市长任组长，杨润星副市长任副组长，市府办、市监察局、市经信局、市环保局、市畜牧兽医水产局、市供电局及石鼓镇、金山街道、石仔岭街道等单位主要负责人为成员。领导小组下设办公室（在市环保局办公），负责协调日常具体工作，由市环保局局长兼任办公室主任。石鼓镇、金山街道办和市直有关部门也要相应成立落实2014年茂名市挂牌督办环境问题工作领导小组，由主要领导任组长，分管领导任副组长，采取切实措施，按时按质完成任务。

二、制定措施、明确责任

各有关镇（街道）、市直有关部门要高度重视挂牌督办工作，将其作为整体推进环境保护工作的有力抓手和重要突破口，制定详细的污染整治方案，细化每一宗督办事项，明确整治目标和期限。于7月30日前将整治方案及责任人分别报市环保局、市监察局。各有关镇（街道）要进一步将责任分解落实到镇干部、村干部，明确具体的责任人，并认真组织实施，按要求在规定时限完成。

三、加强检查指导

市环保局要充分发挥行政监管部门主力军作用，加强对挂牌督办环境问题整治工作的跟踪、督促和指导，依法查处环境违法行为，确保整治工作顺利开展。各有关镇（街道）要加强对辖区内的企业、养殖场监督检查，发现环境违法问题及时制止，及时汇报。市监察局要充分发挥纪检监察的作用，通过开展检查、强化考核问责和查处违纪违法案件等方式，督促有关部门认真履行职责，推动环境问题挂牌督办工作深入开展。

四、加强执法检查，严厉打击环境违法行为

进一步加强对白沙河流域的重点污染源的日常监督管理，加大环保执法力度，坚决打击环境违法行为。整治期间，对白沙河流域的重点污染源以及制革、化工等污染源，实行每月2次以上的检查制度，确保污染企业已建成的治理设施正常运行，减少不正常的污染负荷对白沙河水体的污染冲击，减少污染物的排放。

五、职责分工

各相关镇政府（街道办）、相关职能部门要高度重视茂名市挂牌督办任务，建立以市政府统一领导、各相关部门齐抓共管的上下联动的工作机制，形成工作合力，有序推进和落实整治任务，确保按时按质完成茂名市挂牌督办任务（任务分工见附件）。各相关镇政府（街道办）作为其辖区的整治工作主体，要按属地管理原则，切实承担起责任，想方设法，采取切实有效措施，积极开展整治行动。
