# 高府办函〔2014〕202号关于成立高州市市区一河两岸工程建设工作领导小组的通知

(

高府办函〔2014〕202号

关于成立高州市市区一河两岸工程建设

工作领导小组的通知

各镇人民政府，各街道办事处，市府直属有关单位：

因城市建设发展需要，经市政府领导研究，决定成立高州市市区一河两岸工程建设工作领导小组。其组成人员名单如下：

组 长：何 哲 市委常委、常务副市长

副组长：杨润星 副市长

成 员：何兆茂 市府办副主任、市政府机关事务管理局局长

余洪志 市城市规划管理局局长

凌培杰 宝光街道党委书记

梁华东 潘州街道党委书记

吕龙起 市国土资源局副局长

黄 颖 市财政局副局长

邱 严 市公安局副局长

肖 钢 市住建局总工程师

古 斌 市水务局党组成员、办公室主任

陈兵兵 市城乡投公司总经理

领导小组下设办公室（办公室设在市政府办公楼103室），由何兆茂兼任办公室主任，陈兵兵兼任办公室副主任。

该项工作完成后，该领导小组及其办公室自行撤销。

高州市人民政府办公室

2014年9月30日)
