# 高府办〔2014〕31号转发省政府办公厅印发广东省政府系统值班工作规范的通知

(

各镇人民政府，各街道办事处，市府直属各单位：

现将省政府办公厅《印发广东省政府系统值班工作规范的通知》（粤府办〔2012〕55号）转发给你们，经市政府领导研究，我市提出如下意见，请一并贯彻执行。执行中遇到问题，请迳向市政府总值班室反映。

一、进一步强化值班力量

各镇政府（街道办）要设立值班室，挂镇（街道）值班室牌子，实行24小时值班，不能以门岗代替值班室。要选派政治可靠、责任心强、业务熟悉、有较强综合分析能力和协调处理能力的值班人员，安排专职人员实行24小时轮流值班。市应急委各成员单位要继续强化值班力量，完善领导带班、人员值班、信息报送、应急处置等各项工作机制，确保能够及时处置各类突发事件。各镇（街道）、各部门要加强值班人员业务培训，不断提高值班人员的业务水平；要积极为值班人员创造良好的工作条件，妥善解决值班人员的轮休、值班补贴和生活待遇问题，建立值班人员轮岗机制；要充分依托市应急平台体系，扩建和完善信息化值班系统，不断提高值班室信息化水平。

二、继续做好信息报送工作

（一）信息上报。凡属报告范围的突发事件，事发镇（街道）和市有关部门必须在事发后立即向市政府总值班室报告，最迟不得超过1小时。对于一些本身比较敏感的突发事件，或发生在敏感地区、敏感时间，或可能演变为较大以上突发事件信息的报送，不受报送分级标准限制。紧急情况下，可先通过电话口头报告，并在30分钟内书面报告，确保我市能够在1小时内上报。

（二）信息核报。各镇（街道）、各单位接到市政府总值班室要求核报的突发事件信息，要在15分钟内反馈，确保我市能够及时向上级政府反馈。如遇特殊情况，确实无法按要求时间核报，要在规定时间内及时解析原因，并按市政府总值班室要求继续做好续报等相关工作。

（三）信息报告责任主体。各镇（街道）党政办、各有关单位办公室是向市政府总值班室报告突发事件的责任单位。各镇（街道）党政办主任、应急管理机构负责人和各有关单位办公室主任、应急管理机构负责人是突发事件信息报告的具体责任人。要切实履行报送突发事件的相关职责，坚持带头值班，加强应急值守，帮助支持有关人员及时报送突发事件信息。具体从事值班和信息工作的人员是突发事件信息报告工作的直接责任人。要认真执行有关规定和制度，保证在第一时间向市政府总值班室报告突发事件信息。

三、严格责任追究制度

市政府对全市值班工作进行考核。市政府办公室建立突发事件报告工作考核和通报制度，加大考核和督查力度，定期检查和通报各镇（街道）、各有关单位值班工作和突发事件报告工作情况。带班领导和值班人员脱岗、空岗的，一经查实，将严肃批评，对贻误工作的要追究责任。对故意迟报、轻报、漏报、谎报、瞒报突发事件信息的相关单位和责任人，责令其深刻检讨，取消其当年评先进资格。对造成重大影响或严重后果的，要追究第一责任人和直接责任人责任。

高州市人民政府办公室

2014年11月4日
