# 高府办函〔2014〕206号印发高州市2014年社会保险扩面征缴工作实施方案的通知

(

各镇人民政府，各街道办事处，市府直属有关单位：

《高州市2014年社会保险扩面征缴工作实施方案》业经市人民政府同意，现印发给你们，请认真贯彻执行。执行中遇到的问题，请迳向市人社局反映。

高州市人民政府办公室

2014年10月9日

高州市2014年社会保险扩面

征缴工作实施方案

为全面贯彻落实《中华人民共和国社会保险法》，扩大社会保险覆盖面，提高社会保险费缴费率，切实维护广大劳动者的合法权益，确保社会保险基金安全运行，实现人人享有社会保障的目标，根据茂名市人社局、茂名市地税局《关于印发〈茂名市市直2014年社会保险扩面征缴工作实施方案〉的通知》（茂人社〔2014〕109号）和市政府办公室《关于下达2014年企业养老保险欠费追缴及扩面任务的通知》（高府办函〔2014〕140号）精神，结合我市实际，特制定本方案。

一、指导思想

以《社会保险法》及其有关政策法规为依据，以社会保险法执法检查数据为基础，认真贯彻落实省、市社保扩面征缴工作会议精神，组织开展社会保险扩面征缴清算行动，核查督促用人单位依法参加社会保险，做到应保尽保、应收尽收，确保2014年度社会保险征缴目标任务圆满完成。

二、工作目标

（一）健全基础台账。指导用人单位对在岗职工的参保人数、缴费工资、缴费年限、缴费比例等情况进行自查，逐一登记造册，建立本单位职工参保基础台账。

（二）提高参保率。督促用人单位自2014年1月1日起，依照“全员、足额”的原则为在岗职工参保，解决已参保企业参保率不高，少报、漏报、瞒报缴费基数的问题，重点核查非公有制企业，动员无雇工的个体工商户、未在用人单位参保的非全日制从业人员以及其他灵活就业人员积极参保，实现人人享有社会保障的目标。

（三）提高缴费率。对拖欠养老保险的用人单位进行逐个追缴，责令限期补缴，对恶意拖欠和拒绝缴纳养老保险费的行为，依法作出行政处理；落实滞纳金政策，解决因高额滞纳金而无法缴纳历史欠费问题，从而提高缴费率。

（二）强化工作措施，保证行动成效。

1、加大宣传力度，提高用人单位参保积极性。工作组要广泛宣传社会保险参保政策，重点宣传社会保险缴费制度、基数标准、统筹层次和退休待遇等政策，促使用人单位及其员工关心、理解和支持社会保障事业，强化参保意识，提高用人单位及其员工参保自觉性。

2、 加大征缴力度，促使用人单位现场填报缴费。工作组要利用上次社会保险法执法检查结果，重新核算用人单位工资发放表，检查是否办理社会保险登记，是否全员足 额缴费，并填写用人单位缴费情况相关表格；对未参保人员，工作组要依法督促用人单位法定代表人现场填写《社会保险费明细申报表》，并限期到市地税服务大厅 申报缴费。

3、 加大处罚力度，强制用人单位实时缴费。对用人单位不办理社会保险登记的，社会保险行政部门要责令限期改正，逾期不改正的，依照《社会保险法》相关规定进行 处罚；对未按时足额缴纳社会保险费的用人单位，地税部门要及时责令其限期缴纳或者补足，逾期仍不缴纳的，依照《社会保险法》相关规定进行处理；对有能力缴 费的却不依法缴费或恶意拒绝缴费的钉子户和欠费大户，立即申请新闻媒体予以曝光，强制用人单位全员参保。

（三）工作时间及注意事项。

社会保险扩面征缴清算缴费集中在10月～12月，各组车辆由组长所在单位及相关镇（街道）安排；各单位工作人员由组长统一安排，统一行动；各相关人员要携带社会保险参保缴费有关表格，做好现场办理缴费手续的准备；每周由李康副市长主持召开会议，组长汇报进展情况，并做好情况通报。

各镇（街道）要参照本方案，自行成立由镇政府（街道办）领导任组长，纪委、地税、人社、经济办等部门为成员的社会保险扩面征缴工作领导小组，积极开展社会保险扩面征缴工作。石鼓、潘州、山美、宝光、石仔岭、金山等6个镇（街道）要落实10至15名工作人员与相关督查组人员一起在今年10月中旬至11月中旬对属地企业逐一进行督促检查。
