# 高府办函〔2014〕227号关于成立高州市水电站暂停运行解网工作领导小组的通知

(

有关镇人民政府，市府直属有关单位：

根据茂名市水务局《转发国家能源局南方监管局、广东省水利厅关于暂停珠坑水电站等36宗小水电站并网运行的通知》（茂水〔2014〕98号）文件精神，为了做好我市石板镇高章电站等6宗水电站暂停并网运行的解网工作，经市政府领导研究，决定成立高州市水电站暂停运行解网工作领导小组。其组成人员如下：

组 长：邓锡君 副市长

副组长：张 枢 高州供电局局长

谢桂禄 市水务局局长

成 员：冯少衡 市水务局副局长

冯 芳 市科工商务局副局长

邱 严 市公安局副局长

程 岳 市监察局副局长

邓振杰 市财政局副局长

钟友明 市安监局副主任科员

彭灼全 石板镇党委书记

吴文波 荷花镇党委书记

黄华胜 深镇镇党委书记

陈昌永 东岸镇党委书记

肖锦超 高州供电局营业部主任

龙锦庆 市水务局农电股股长

领导小组下设工作组，由高州供电局牵头，领导小组成员单位分别派员参加，负责有关水电站暂停运行解网具体工作。电站暂停运行解网工作结束，该领导小组及其工作组自行撤销。

高州市人民政府办公室

2014年11月12日
