# 高州市人民政府办公室关于印发高州市2017年依法行政工作要点和责任分工的通知

各镇人民政府，各街道办事处，市府直属各单位：

《高州市2017年依法行政工作要点和责任分工》业经市人民政府同意，现印发给你们，请认真组织实施。实施过程中遇到的问题，请迳向市依法行政工作领导小组办公室（设在市政府法制局）反映。

高州市人民政府办公室

2017年3月20日

高州市2017年依法行政工作要点和责任分工

2017年，我市依法行政工作以党的十八届四中、五中、六中全会精神为指导，全面落实国务院《全面推进依法行政实施纲要》、《国务院关于加强市县政府依法行政的决定》和《国务院关于加强法治政府建设的意见》精神，紧紧围绕市委、市政府的中心工作，加大依法行政工作统筹力度，突出重点，狠抓落实。各项工作重点和责任分工如下：

一、提高行政机关工作人员依法行政的意识和能力

（一）落实各级领导干部学法制度。对全市科级以上领导干部分批进行学法培训和依法行政考试，成绩报市人大常委会及市委组织部备案，作为考察领导干部综合素质和晋升的依据。对拟任市直部门领导干部职务的，要进行任职前的法律知识考试，其结果作为任职的参考依据。把宪法法律和全面依法治国列入党委（党组）中心组学习内容，列为市委党校的必修课。（市委组织部、市委宣传部、市委党校、市司法局、市人力资源和社会保障局负责）

（二）加强行政机关工作人员学法。在各类公务员培训班中安排至少2课时学习十八届四中全会关于依法治国的精神。在行政执法人员招录考试中设置专门的法律知识考试题目。加强公务员初任法律知识培训，加大公务员学法考核力度。市政府法制局组织对行政执法人员的学法培训，并进行法律轮训和抽考，记入公务员年度培训学分。（市委组织部、市司法局、市人力资源和社会保障局、市政府法制局负责）

二、加强依法行政的统筹规划力度

（三）推进法治政府建设的总体设计。贯彻《高州市法治政府建设“十三五”规划（2016—2020年）》，对我市中长期依法行政工作进行全面部署；配合市依法治市办，为推进依法行政、建设法治政府提供制度保障。（市政府法制局负责，市政府各部门配合）

（四）加强依法行政考核工作。将依法行政考核纳入市年度检查考核，完善行政机关考核指标体系，加强依法行政考核和落实科学发展观、平安高州考核工作的联动，将考核结果作为对政府领导班子和领导干部综合考核、奖励惩处、晋职晋级的重要内容。（市政府法制局负责，各镇政府、街道办和市政府各部门配合）

（五）深入开展高州市依法行政示范单位创建活动。在市政府部门选择 3—5 个部门、选择若干个镇（街道）开展创建活动，推动依法行政创建工作向基层延伸。（市政府法制局负责，各镇政府、街道办和市政府各部门配合）

三、进一步转变政府职能

（六）加强对行政审批事项的规范管理。进一步完善行政审批事项目录管理、动态调整和监管制度。全面清理我市政府部门非行政许可审批事项，清理完毕后不再保留“非行政许可审批”这一审批类别。逐步清理规范技术审查等行政审批前置中介服务工作。（市编办负责，市政府各部门配合）

（七）推进行政审批标准化建设。根据省开展行政审批标准化工作要求，规范市、镇（街道）、社区（村）三级事项的目录，统一主项、子项设置及名称。严格规范事项的实施依据、审批对象、审批类别等基本要素，实现市、镇（街道）、社区（村）同一事项名称、类别相同，同一层级的同一事项的子项设置、实施依据、审批对象、审批类别相同。未纳入目录的事项（涉密事项除外）不得实施审批或变相实施审批。编写格式统一规范的行政审批事项业务手册和办事指南，优化重组行政审批要素、梳理再造行政审批流程、细化量化裁量标准。（市编办、市政管办负责，各镇政府、街道办和市政府各部门配合）

（八）推进权责清单制度。在完成全部政府部门权力和责任清单编制工作的基础上，加强动态管理。推进企业投资体制改革，积极推进负面清单管理工作。完成政府职能转变、机构改革和职能调整。根据新一轮政府机构改革的要求，按照政府工作部门调整的情况，重新明确行政执法主体、执法依据和执法行为，并向社会公布。（市编办、市政府法制局、市发改局、市政管办负责，各镇政府、街道办和市政府各部门配合）

（九）加强政务服务。推进审批事项“全市联网通办”，推行行政审批“前台综合受理、后台分类审批、统一窗口出件”。下放居民办证权限，实现服务窗口前移。推行“三证合一”工商登记制度，营造市场化、法治化、国际化营商环境。大力推进“一卡、一号、一格、一网、一窗”等“五个一”建设。（市编办、市政管办、市工商局，各镇政府、街道办和市政府各部门配合）

四、加强制度建设

（十）认真落实规范性文件制定程序和公众参与制度。完善规范性文件审查机制和制度廉洁性评估。拓宽文件合法性审查的专家参与力度，建立合法性审查专家委员会，提高规范性文件的质量。建立规范性文件制定说明与文本同时公布的文件解读机制。完善规范性文件的动态监管机制，对即将到期的规范性文件，要及时跟踪处理。开展消除市场壁垒、转变政府职能的规范性文件清理工作。加强对全市规范性文件的统计、分析和总结，推行规范性文件年度分类分析制度。（市政府法制局负责，各镇政府、街道办和市政府各部门配合）

（十一）严格执行《高州市重大行政决策程序规定》。健全和推行重大行政决策目录管理制度，保障年度决策目录的贯彻执行。严格落实重大行政决策公众参与、专家咨询、风险评估、制度廉洁性评估、合法性审查、集体讨论决定的法定程序。（市府办、市政府法制局负责，各镇政府、街道办和市政府各部门配合）

（十二）进一步规范公众参与重大行政决策过程。完善重大民生决策公众咨询监督委员会制度。完善重大行政决策社会稳定风险评估制度，科学确定风险等级，形成风险评估报告，对于风险等级较高的，应当暂缓讨论决定或者不予讨论决定。（市委维稳办、市政府研究室负责，各镇政府、街道办和市政府各部门配合）

（十三）完善行政决策的合法性审查。完成政府合同示范文本制定工作，研究制定政府合同履行监管和政府合同档案管理制度等配套制度。健全完善行政机关内部重大决策合法性审查机制，未经合法性审查或者经审查不合法的，不得提交讨论。（市政府法制局负责，各镇政府、街道办和市政府各部门配合）

（十四）建立健全政府法律顾问制度。建立政府法制机构主管的，以政府法制机构人员为主体、吸收专家和律师参加的法律顾问队伍，逐步形成市、镇（街道）两级政府法律顾问。完善政府部门聘请常年法律顾问制度，探索建立法律顾问服务工作绩效考评机制。（市政府法制局、市司法局负责，各镇政府、街道办和市政府各部门配合）

（十五）推动建立市属国有企业法律顾问制度。健全和完善市属国有企业的内部法律顾问制度，务实、分类推进以总法律顾问制度为核心的国有企业法律风险防控体系，加强市属国有企业高级管理人员、企业法律顾问与有关行政部门法制机构沟通机制建设，为市属国有企业有效规避、减少和防范法律风险。（市政府法制局和市科工商务局负责，各镇政府、街道办和市政府各部门配合）

五、深化政务公开

（十六）健全政府信息公开机制。进一步深化政府信息公开的体制机制，在公开便民上有明显改善。加强全市统一的政府信息公开管理平台建设，建立统一的政府公告发布平台。（市府办、市政管办、市政府法制局负责，市政府各部门配合）

（十七）深化政务公开内容。推进决策公开、执行公开、管理公开、服务公开、结果公开，重点公开部门权责清单、部门预算、公共资源配置、重大建设项目批准和实施、社会公益事业建设等领域的政府信息。推动审计结果公开。进一步完善信息公开检索的便民措施。（市府办负责，市政府各部门配合）

（十八）落实规范性文件的统一登记、统一编号、统一公布制度。所有的行政规范性文件要按照政府信息公开要求和程序主动公开。（市府办、市政府法制局负责，各镇政府、街道办和市政府各部门配合）

六、严格规范公正文明执法，强化行政执法监督

（十九）完善行政执法程序。制定执法标准化流程并向社会公开。建立登记立案、监督检查、调查取证、行政决定等行政执法全过程记录制度。除国家、省已制定统一的行政执法文书格式文本外，市级行政执法部门制定统一的行政执法文书格式文本，经市政府法制局审查后公开。（市政府法制局负责，各镇政府、街道办和市政府各部门配合）

（二十）全面落实行政执法责任制。建立行政执法案件统计、分析、报告、公示制度，探索行政执法效果民意评价制度，完善行政执法职权、执法主体、执法依据动态管理系统和行政执法电子监察系统。重点监督检查多头执法、选择性执法和执法不规范、不严格、不透明、不文明现象。对我市的文化、教育、交通和安全生产等领域开展专项行政执法监督检查。对不依法行使职权或者不履行法定义务的行为予以查处。（市政府法制局、市监察局负责，各镇政府、街道办和市政府各部门配合）

（二十一）依法惩处各类与群众切身利益密切相关的违法行为。加大食品药品、安全生产、环境保护、劳动保障、交通运输等重点领域基层执法力度；加大对社会危害较大、直接损害群众利益的违法行为的执法力度。（市政府各部门负责）

七、强化对行政权力的制约，完善行政监督体系

（二十二）以规范和约束公权力为重点，加大对政府内部权力的制约。强化重点领域的内部监督，完善内部监督流程，对财政资金分配使用、国有资产监管、政府投资、政府采购、公共资源转让等权力集中的部门和岗位实行分事行权、分岗设权、分级授权，定期轮岗。（市编办、市审计局负责，各镇政府、街道办和市政府各部门配合）

（二十三）强化政府层级监督和专门监督。充分发挥行政复议的个案监督功能，加大对行政复议决定和行政复议意见书履行的监督。依法独立发挥市审计、监察等部门专门监督的作用，建立常态化监督机制。推进对公共资金、国有资产和领导干部履行经济责任情况的审计监督全覆盖。进一步健全完善问责机制。（市监察局、市审计局、市政府法制局负责，各镇政府、街道办和市政府各部门配合）

（二十四）接受司法监督。建立行政机关执行人民法院生效判决、裁定和司法建议书、检察建议书监督制度。继续推进行政机关负责人出庭应诉工作。提高行政复议机关在《中华人民共和国行政诉讼法》修改后的行政应诉能力，加强行政应诉机构和应诉工作人员的保障工作。（市政府法制局负责，各镇政府、街道办和市政府各部门配合）

八、依法化解社会矛盾纠纷

（二十五）以行政复议规范化建设为抓手，推进复议工作。实行全市行政复议决定网上公开。执行《广东省行政复议案件庭审办法（试行）》，规范行政复议庭审规则。（市政府法制局负责，各镇政府、街道办和市政府各部门配合）

（二十六）健全社会矛盾纠纷预防化解机制，完善调解、仲裁、行政裁决、行政复议、诉讼等有机衔接、相互协调的多元化纠纷解决机制。健全行政裁决制度，强化行政机关解决同行政管理活动密切相关的民事纠纷功能。加强落实行政调解制度，充分发挥行政机关在化解行政争议和民事纠纷中的作用，推动建立行政调解与人民调解、司法调解相衔接的大调解联动机制。（市司法局、市信访局、市政府法制局负责，各镇政府、街道办和市政府各部门配合）

（二十七）建立涉法涉诉信访依法终结制度。努力推动形成化解矛盾靠法的良好法治环境，推动在法治框架下解决社会矛盾。（市委政法委、市信访局负责，各镇政府、街道办和市政府各部门配合）

九、加强依法行政保障

（二十八）增强政府法治工作队伍力量。优先提拔使用法治素质好、依法办事能力强的干部。强化政府法制机构对部门法制机构的业务指导与监督。增强法制机构的专业化程度，调配精干的法律专业人才，法制队伍中法律专业人员的比例不少于50%。（市委组织部、市人力资源和社会保障局、市政府法制局负责，各镇政府、街道办和市政府各部门配合）
