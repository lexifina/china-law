# 高州市人民政府办公室关于印发2017年市政府常务会议专题学法计划的通知

《2017年市政府常务会议专题学法计划》业经市人民政府同意，现印发给你们，请认真贯彻执行。

高州市人民政府办公室

2017年3月16日

稿报市政府办公室。
