# 关于调整高州市创建国家级农村职业教育和成人教育示范县工作领导小组成员的通知

各镇人民政府，各街道办事处，市府直属有关单位：

根据工作需要，经市政府领导研究，决定调整高州市创建国家级农村职业教育和成人教育示范县工作领导小组成员。调整后其组成人员如下：

组　　　长：朱春保　市委副书记、市长

常务副组长：岑解明　副市长

副　组　长：陈沛超　市教育局局长

张伟成　市政府金融工作局局长

成　　　员：李　杰　市发改局局长

王　森　市人社局局长

龙国源　市农业局局长

钟荣伟　市林业局局长

钟健瑜　市畜牧兽医局局长

吴小英　市教育局副局长

邓振杰　市财政局副局长

朱国彬　高州农校副校长

赖治锋　市广播电视大学校长

李罗雄　市教师进修学校副校长

陈文友　市职业技术学校校长

赖德光　市第一职业技术学校校长

领导小组下设办公室(在市教育局办公)，负责组织、指导和协调创建国家级农村职业教育和成人教育示范县日常工作，由陈沛超兼任办公室主任，吴小英兼任办公室副主任。

创建工作结束后，领导小组及其办公室自行撤销。

高州市人民政府办公室

2017年4月18日
