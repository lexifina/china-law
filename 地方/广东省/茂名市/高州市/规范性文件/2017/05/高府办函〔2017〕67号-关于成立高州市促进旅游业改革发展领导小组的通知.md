# 关于成立高州市促进旅游业改革发展领导小组的通知

各镇人民政府,各街道办事处，市府直属有关单位：

为加快推进我市旅游业改革发展，经市政府领导研究，决定成立高州市促进旅游业改革发展领导小组。其组成人员如下：

组 长：朱春保 市委副书记、市长

副组长：岑解明 副市长

领导小组在市政府的领导下，统筹协调全市旅游业改革发展工作，其职能包括：对全市旅游工作进行宏观指导；提出促进旅游业改革发展的方针政策；协调解决旅游业改革发展中的重大问题；研究旅游业改革发展中的其他重要工作；完成市政府交办的其他事项。领导小组下设办公室（在市旅游局办公），负责日常具体事务，由张晓寅兼办公室主任。
