# 关于成立高州市“4•3”安全事故调查组的通知

(

高府办函〔2017〕72号

关于成立高州市“4·3”安全事故

调查组的通知

石仔岭街道办事处,市府直属有关单位：

2017年4月3日17时45分左右，位于高州市工业大道41号石仔岭街道的高州市瑞恒房地产开发有限公司将旧厂房改造为其办公室时，一面墙发生崩塌，造成1人死亡。为尽快查明事故原因，妥善处理事故，经市政府领导研究，决定成立高州市“4·3”安全事故调查组。其组成人员如下：

组 长：曾 春 市委常委、常务副市长

副组长：张秀育 市府办副主任、市道口经济园区管理中心主任

安华文 市安监局局长

程 岳 市监察局副局长

成 员：谢明贵 市公安局副局长

陈旭华 市政府法制局副局长

肖 钢 市住建局副局长

蔡茂仁 市安监局副局长

潘思源 市人社局副主任科员

黄 志 石仔岭街道办副主任

黄戈华 市总工会副部长

汤成涛 市安监局执法大队大队长

苏倩玲 市安监局执法大队副大队长

邀 请：赖明虎 市检察院副检察长

调查工作结束后，该调查组自行撤销。

高州市人民政府办公室

2017年4月20日
