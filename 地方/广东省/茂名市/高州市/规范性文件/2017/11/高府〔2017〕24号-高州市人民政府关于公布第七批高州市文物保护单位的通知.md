# 高州市人民政府关于公布第七批高州市文物保护单位的通知

各镇人民政府，各街道办事处，市府直属各单位：

市政府核定市文化广电新闻出版局确定的第七批高州市文物保护单位，现予公布。各镇（街道）、各有关单位要依照《中华人民共和国文物保护法》等法律法规的规定，认真贯彻“保护为主、抢救第一、合理利用、加强管理”的方针，切实做好文物的保护、利用和管理工作。

附件：第七批高州市文物保护单位名单

高州市人民政府
