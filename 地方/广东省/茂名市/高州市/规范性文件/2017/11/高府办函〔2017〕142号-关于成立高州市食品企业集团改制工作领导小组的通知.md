# 关于成立高州市食品企业集团改制工作领导小组的通知

各镇人民政府，各街道办事处，市府直属有关单位：

根据我市2017年《政府工作报告》决定事项，市食品企业集团为改制试点企业。为做好市食品企业集团改制工作，经市政府领导研究，决定成立高州市食品企业集团改制工作领导小组。其组成人员如下：

组 长：曾 春 市委常委、常务副市长

副组长：梁逸峰 市政协副主席、市财政局局长

肖 娴 市食品企业集团总经理

成 员：黄健鹏 市发改局副局长

陈 林 市人社局副局长

莫 迪 市工商局副局长

陆树松 市科工商务局党组成员

冯少衡 市社保局副局长

邓光海 市食品企业集团副总经理

领导小组下设办公室(在市食品企业集团办公)，负责日常具体工作，由肖娴兼任办公室主任。办公室人员为：赖焕辉(市发改局)，李文嘉(市人社局)，邓庆(市工商局)，陆畅杰(市科工商务局)，陈开健、徐国伟、徐国谋(市食品企业集团)。改制工作完成后，该领导小组及其办公室自行撤销。

高州市人民政府办公室

2017年7月26日
