# 关于成立高州市国有企业改革工作领导小组的通知

各镇人民政府，各街道办事处，市府直属有关单位：

根据我市2017年《市政府工作报告》中关于市国有企业改革工作的精神，为做好市国有企业改革工作，经市政府领导研究，决定成立高州市国有企业改革工作领导小组。其组成人员如下：

组 长：曾 春 市委常委、常务副市长

副组长：梁逸峰 市政协副主席、市财政局局长

成 员：王 森 市委组织部副部长、市人社局局长

李 杰 市发改局局长

庄家银 市科工商务局局长

黄 飞 市国土资源局局长、市工业园管理中心主任

陈昌永 市工商局局长

陈福文 市政府法制局局长

黄第源 市人社局副局长、市社保基金局局长

黄汉良 市财政局副局长

领导小组下设办公室（在市国资办办公），负责日常具体工作，由余永伟（市国资办副主任）任办公室主任。根据市国有企业的改革情况，以“一企一思路”为原则，成立市国有企业改革工作小组，相关人员从相关职能部门抽调。

领导小组不设立公章，发文经组长签署意见后，由市财政局代章。

改革工作结束后，该领导小组及其办公室自行撤销。

高州市人民政府办公室

2017年7月31日
