# 印发高州市推进落实涉烟打假打私工作方案的通知

各镇人民政府，各街道办事处，市府直属有关单位：

《高州市推进落实涉烟打假打私工作方案》业经市人民政府同意，现印发给你们，请认真组织实施。实施中遇到问题，请迳向市打假办（联系电话：6688225）、市打私办（联系电话：6696196）反映。

高州市人民政府办公室

2017年8月4日

高州市推进落实涉烟打假打私工作方案

为落实省、茂名市关于涉烟打假打私工作的相关部署要求，进一步推进全市涉烟打假打私工作，根据《茂名市人民政府办公室关于印发茂名市推进落实涉烟打假打私工作方案的通知》（茂府办函〔2017〕116号）要求，结合我市实际，制定本工作方案。

一、工作目标

建立健全打假打私长效工作机制，严格落实涉烟打假打私综治工作责任制。狠抓重点地区和突出问题整治，保持打击高压态势，集中力量查处一批大案要案，着力解决我市近年来烟草打假打私中较为突出的非法中转分销和过境走私等问题，遏制涉烟违法犯罪行为反弹势头。严格责任追究，打击涉烟违法犯罪黑恶势力和保护伞，净化卷烟市场环境。

二、重点任务和责任分工

（一）充分利用网络、报纸、户外标语、烟草零售户培训等形式和渠道，在居民社区、商业中心、交通枢纽等人流密集区域，加强对烟草专卖法律法规、典型案件及涉烟违法社会危害的宣传；完善举报奖励制度，公开举报电话，畅通举报渠道，提高举报奖励力度，鼓励、支持消费者依法维权，发挥社会公众监督作用，凝聚社会打击合力，推进社会共治。（市烟草专卖局牵头，各镇政府、街道办配合）

（二）严厉打击无烟草专卖零售许可证销售卷烟违法行为；加强对持有烟草专卖零售许可证经营户的监管，全面查处销售假烟、走私烟等违法行为；加大对擅自收购烟叶、无烟草专卖生产企业许可证非法生产烟草专卖品、无准运证非法运输烟草专卖品等违法行为的查处力度，有针对性地开展专项整治。（市烟草专卖局牵头，市公安局、市交通运输局、市工商局配合）

（三）加大对无照经营烟草专卖品违法行为打击力度，对非法印刷卷烟商标标识、包装物等违法行为开展专项整治。（市工商局牵头，市公安局、市科工商务局、市烟草专卖局配合）

（四）加强对道路货物运输经营活动的监管力度，有效切断非法卷烟及原辅材料的运输通道，严厉打击货运场（站）、货物集散地等物流场所非法中转分销卷烟行为，研究制定具体监管措施。（市交通运输局牵头，市公安局、市烟草专卖局配合）

（五）开展对邮政、快递企业的执法检查，严厉打击邮件、快递渠道非法寄递卷烟违法行为，推动寄递企业严格落实邮件、快递实名收寄和收寄验收制度，对不执行相关制度的寄递企业进行查处并责令限期整改。（市邮政分公司牵头，市公安局、市烟草专卖局配合）

（六）加强网络交易平台监管和合作，利用大数据分析技术，及时发现和掌握违法线索，对利用互联网搜索引擎和网上商城、微信、QQ群等网络工具非法销售卷烟及原辅材料行为开展专项整治，研究制定规范网络交易平台的具体监管措施。（市工商局牵头，市公安局、市科工商务局、中国电信高州分公司、中国移动高州分公司、中国联通高州分公司、市烟草专卖局配合）

（七）根据我市陆路走私卷烟违法动态，加强情报线索经营，对重点渠道、重点地区采取严格有效的监管措施，将打击卷烟过境走私作为“国门利剑”及打击应节商品走私等联合行动的重点，有针对性地组织区域性打击卷烟走私专项行动。（市打私办牵头，市公安局、市工商局、茂名海关驻高州办事处、市烟草专卖局配合）

（八）发挥正面监管职能，做好风险分析和布控，加强对货运渠道烟草专卖品进出口业务和旅检渠道的监管力度，坚决查处违法行为。强化情报线索经营，注重开展区域协同联动，严厉打击团伙性卷烟走私犯罪活动，力争“破网除链”。（茂名海关驻高州办事处牵头，市工商局、市烟草专卖局配合）

（九）深化情报导侦技术和手段运用，广泛收集情报线索，强化案件经营，按照“打团伙、破网络、抓主犯”要求，深挖涉烟违法行为背后利益链条，加大对涉烟违法犯罪团伙主犯、骨干的追逃、打击力度，集中力量侦办一批涉烟违法大案要案，有力震慑违法犯罪分子，严防涉烟违法犯罪活动反弹蔓延。（市公安局牵头，市工商局、市烟草专卖局配合）

（十）进一步完善涉烟打假打私行政执法与刑事司法衔接工作机制，及时将符合《广东省行政执法与刑事司法衔接信息共享平台工作办法》规定的所有案件录入“两法衔接”数据平台，强化数据有效应用，推动解决有案不移、以罚代刑等问题。严查涉烟违法犯罪案件背后的玩忽职守、滥用职权、徇私舞弊、帮助犯罪分子逃避处罚等犯罪行为。（市检察院牵头，市公安局、市交通运输局、市工商局、茂名海关驻高州办事处、市科工商务局、市邮政分公司、市烟草专卖局配合）

三、保障措施

（一）健全部门联动工作机制。建立市涉烟打假打私联席会议制度，由市打假办和市打私办主要负责人分别担任召集人，市打假、打私成员单位负责人为成员。联席会议负责研究部署打假打私重点工作、督促各镇（街道）落实打假和打私综治工作责任制、协调查处跨区跨部门违法案件、组织督导重点案件查处和重点区域专项整治。联席会议设联络员，负责部门间工作层面的协调和信息报送；根据工作需要，可从成员单位抽调熟悉业务的工作人员短期集中办公。市打假办和市打私办要牵头研究制定线索通报、案件协查等制度，协调和推动跨区跨部门联合执法。

（二）加大经费支持和奖励力度。市烟草专卖局要依据涉烟打假打私经费管理相关政策，为各镇（街道）和有关部门开展涉烟打假打私专项行动、侦办涉烟违法犯罪案件、处置罚没非法烟草专卖品等提供必要的经费支持；对参与涉烟打假打私专项行动、侦破符合省部级标准的涉烟打假打私网络案件和督办案件的有功人员给予奖励，对举报有功人员按照相关标准及时、全额支付举报奖励。执法部门收缴的假冒和走私卷烟在结案后一律予以销毁，防止流入市场。烟草部门应配合做好鉴定、价格估算、处理和销毁工作。

（三）强化督查及责任制考核追究。各镇（街道）要加强打假和打私综治工作责任制考核，加大烟草打假打私权重，将责任制考核纳入创建平安高州暨社会治安综合治理工作考评。各镇（街道）落实打假和打私综治工作责任制情况列入市政府督查事项，由市打假办和市打私办会同市相关部门分别成立督导组，对各镇（街道）落实打假和打私综治工作责任制情况，特别是重点区域专项整治情况进行督查，对打假打私重大案件进行督办。

（四）规范打假打私信息报送。一是各镇（街道）及市涉烟打假打私联席会议成员单位每月4日前将上月涉烟打假打私统计数据、重点案件和经验做法等信息分别报送市打假办和市打私办，市涉烟打假打私联席会议成员单位要及时将重要打假打私信息分别报送市打假办和市打私办。二是重特大案件查处和涉烟打假打私过程中出现暴力抗法、阻扰执法，或者造成人员伤亡、引发群体事件等突发事件的，按照有关规定分别报送市打假办、市打私办和相关部门。三是开展专项整治和案件查处过程中，发现与其他地方或者部门相关的线索，要于3个工作日内通报相关地方或者部门。

各镇（街道）要完善涉烟打假打私工作机制，保障专项工作经费，围绕本方案确定的重点任务和区域特点，研究制定专项整治方案。各镇（街道）分管打假打私工作的负责人要定期召集会议研究部署本镇（街道）涉烟打假打私工作。市各牵头部门要围绕工作目标和突出问题，出台具体监管措施，组织本部门在全市范围内开展专项整治行动。各镇（街道）和市各牵头部门应于本工作方案印发30日内，将本镇（街道）、本部门涉烟打假打私专项整治方案分别报送市打假办和市打私办备案。
