# 关于调整高州市职业教育工作领导小组成员的通知

各镇人民政府，各街道办事处，市府直属有关单位：

根据工作需要，经市政府领导研究，决定调整高州市职业教育工作领导小组成员。调整后其组成人员如下：

组 长：朱春保 市委副书记、市长

副组长：曾 春 市委常委、常务副市长

梁逸峰 市政协副主席、市财政局局长

成 员：张秀育 市府办副主任、市道口经济园区管理中心主任

陈沛超 市教育局局长

王 森 市委组织部副部长、市人社局局长

李 杰 市发改局局长

庄家银 市科工商务局局长

陈昌永 市工商局局长

陈福文 市政府法制局局长

龙国源 市农业局局长

袁海峰 市信访局局长

王育波 市地税局局长

吴 耿 市公安局党委副书记

领导小组下设办公室（在市教育局办公），负责日常具体工作。由陈沛超兼办公室主任，吴小英（市教育局）、梁光（市人社局）任办公室副主任，所需工作人员从有关部门抽调。

高州市人民政府办公室

2017年10月16日
