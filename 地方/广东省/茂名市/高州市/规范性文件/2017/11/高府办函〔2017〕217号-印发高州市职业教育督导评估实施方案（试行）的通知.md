# 印发高州市职业教育督导评估实施方案（试行）的通知

各镇人民政府，各街道办事处，市府直属有关单位：

《高州市职业教育督导评估实施方案（试行）》业经市人民政府同意，现印发给你们，请认真贯彻执行。执行中遇到的问题，请迳向市教育局反映。

高州市人民政府办公室

2017年11月7日

高州市职业教育督导评估实施方案（试行）

为贯彻落实《中华人民共和国职业教育法》、《国家中长期教育改革和发展规划纲要（2010-2020年）》和《教育部关于印发〈中等职业教育督导评估办法〉的通知》（教督〔2011〕2号），促进我市职业教育健康可持续发展，特制定本实施方案。

一、指导思想

将教育督导工作与我市创建国家级农村职业教育和成人教育示范县工作有机结合，推动政府切实履行发展职业教育责任，引导学校提高管理水平，提升我市职业教育基础能力，促进全市职业教育健康可持续发展。

二、督导评估原则

（一）突出学校主体，引导自评自诊。督导评估要充分发挥学校的主体作用，深入学校自评自诊，引导学校“自我规划、自我诊断，自我改进。”

（二）关注现场常态，减轻迎评负担。督导评估以查阅资料、访谈、实地考察、问卷调查等方式进行，关注学校现场常态，减轻学校迎评负担。

（三）侧重诊断服务，助力学校发展。充分发挥评估的诊断功能，切实为学校健康发展提供有价值的反馈信息和对策建议，提供教育决策参考。关注学校未来的发展需要，注重督学与督政相结合，以评促管，以评促建，以评促改，督促相关部门充分履行管理职责并为学校提供资源支持。

三、督导评估对象

全市中等职业技术学校。

四、督导评估组织与实施

职业教育督导评估由高州市人民政府教育督导室（以下简称市教育督导室）按照本方案有关规定统一组织，视情况可聘请第三方职业教育专家参加；督导评估每年对各学校督导评估一次。

市教育督导室统一制订督导评估指标体系及评估办法，组织督学培训，选派或外聘专家组成督导评估组，统筹指导、组织、监督督导评估工作的实施。督导评估组由市教育局委派，督导评估后撰写报告报送市教育督导室审定。

五、督导评估的内容与要求

督导评估的内容以促进我市职业教育内涵发展、自主发展、持续发展为根本出发点，重点体现以下督导评估要素：

（一）经费投入。着重评价中职预算内教育经费占预算内教育经费问题的比例、中职生均预算内教育事业旨与普通高中之比、中职生均预算内公用经费占生均预算内教育事业费的比例、学校实习实训设备投入、教师培训费占全校教师年度工资总额的比例、免学费和国家助学金情况等。

（二）办学条件。注重评价中等职业学校等级情况、生均实训场地建筑面积、生均仪器设备价值、教学用计算机拥有量、专任教师生师比、省市县级专业带头人或骨干教师的比例、研究生学历或硕士学位以上教师比例、“双师型”教师比例、高级专业技术职务教师比、教师学历达标率、兼职教师比例、教师培训规模、学校管理等。

（三）学校管理。注重评价学校依章程制定学校管理制度，完善学校内部管理、教育教学制度的做法、经验和成效等。

（四）发展水平。注重评价高中阶段招生普职比、职业培训规模、中职毕业生初次就业率、中职教育教学改革及发展特色等。

六、督导评估的基本方法

（一）自评与外评相结合。学校建立并实施自诊制度，以客观性的信息与主观性的自我反思相结合为主要手段，对自身优势和存在不足形成客观、深刻的认识，形成自我改进的策略。督导对学校的自诊报告进行核实，对学校的自评方法与结果进行再诊断，并提出改进建议，以促进自评与外评良性互动、互补。

（二）多元化信息采集。以查阅纸质资料为主的评估方式，通过学校现场观察、座谈、访谈、观课、数据核查等多种形式，从管理人员、教师、学生、家长、社区人士等多方面采集充足的可靠信息，采用定性与定量分析相结合、多方信息相互印证的方法，对学校办学水平作出综合评价。

七、督导评估程序与要求

（一）学校自查。

各学校按照督导评估指标要求，重点针对学校办学条件、学校管理、发展水平开展自评自诊。自评自诊应基于事实性材料作出判断，将主观性的自我反思活动建立在客观性的调查研究的基础上。在总结经验的基础上，发现问题、归因研究，采取积极措施加以改进。

学校自评自诊应成为一项长效的重要工作机制，成为一个持续、动态的过程，融入学校日常管理系统。各学校每年12月底前进行自查自评，并将自评结果报市教育督导室。

（二）督导评估。

1．确定受评学校。市教育督导室视情况确定受评学校名单。

2．督导评估预告。督导评估前一个月，市教育督导室向受评学校内发督导评估预告。

3．资料预查。受评学校提交自诊报告等佐证资料的电子文本。督导评估组到校督导前，预先查阅学校相关数据，对学校办学情况进行初步了解，提高实地督导的针对性和工作效率。

4．实地督导。督导评估组对受评学校的实地督导评估时间分别为半天。督导评估组主要通过访谈、实地考察、问卷、资料查阅等方式采集信息。

八、督导评估结果的认定与运用

（一）实地督导评估工作完成后，督导组在10个工作日内形成书面督导评估报告，报市教育督导室。评估报告中，督导评估组应依据评估方案对学校作出评价，指明办学成绩和优势、存在问题与不足，提出学校整改意见或后续发展建议，以体现督导评估诊断性、针对性和发展性。

（二）评估报告经市教育督导室审核后，正式反馈给各学校，各学校应根据督导评估报告的意见建议，着力改进学校工作。市教育督导室对已督导评估的学校的改进情况组织专项回访。

（三）督导评估结果作为对学校和校长年度考核的重要依据。

九、其他事项

根据本实施方案，市教育督导室负责制定评估工作细则组织试行，并依据实践需要不断修订完善。未尽事宜由市教育督导室负责解释。
