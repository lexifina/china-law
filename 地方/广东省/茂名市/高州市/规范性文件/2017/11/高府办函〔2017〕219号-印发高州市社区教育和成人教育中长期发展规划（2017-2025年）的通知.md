# 印发高州市社区教育和成人教育中长期发展规划（2017-2025年）的通知

各镇人民政府，各街道办事处，市府直属有关单位：

《高州市社区教育和成人教育中长期发展规划（2017-2025年》业经市人民政府同意，现印发给你们，请认真贯彻执行。执行中遇到问题，请迳向市教育局反映。

高州市人民政府办公室

2017年11月7日

高州市社区教育和成人教育中长期

发展规划（2017-2025年）

为加快推进我市社区教育和成人教育发展，构建全民终身教育体系，全面建设全民学习、终身学习的学习型社会，现根据国家、省和茂名市大力发展农村社区教育和成人教育有关文件精神，结合我市实际，特制定本规划。

一、指导思想

坚持以“创新、协调、绿色、开放、共享”的发展理念为引领，以服务高州经济和社会发展，满足全体社会成员学习需求为宗旨，以提高农村和城市居民的思想文化素质、职业技能、创业能力、文化生活质量为目的，以乡镇成人文化技术学校和社区学校建设为突破口，整合各种教育培训资源，促进各类教育的协调发展，逐步建立起适应新农村建设和社区建设以及居民学习需求的社区教育与成人教育管理体制、运行机制和教育培训模式，多渠道、多层次、多形式开展各类教育培训活动，为社会各界不同年龄、不同层次、不同职业的受教育者提供开放的、多样的、及时的教育机会，最大限度满足农村和社区发展以及社会成员对教育的需求，促进区域经济和社会发展。通过创建学习型组织，逐步构建起我市终身教育体系，为促进我市经济和社会全面发展提供智力支持和人才保证。

二、目标任务

进一步建立和完善适应社会主义市场经济体制，满足人民群众终身学习需要，与经济社会需求和劳动就业紧密结合，形式多样、灵活开放的具有高州特色的现代社区教育与成人教育体系。在城区，以街道社区学校建设为抓手，巩固和发展一批社区教育阵地，最大限度满足社区成员对教育的多样化需求，促进社区居民整体素质和生活质量的提高，促进区域经济和社会的发展，逐步形成学习型社区和学习型城市。在乡镇，加快乡镇成人文化技术学校与镇文化站等功能大体相同的单位整合资源，进一步建立健全市、镇、村三级成人教育培训网络，重点突出乡镇成人文化技术学校的骨干作用。全面实施农村劳动力转移培训工程、农村实用人才培训工程，完善工作机制，扩大培训规模，提高培训质量，促进农村劳动力合理有序转移和农民脱贫致富。

三、主要措施

（一）进一步理清社区教育和成人教育发展思路。学习贯彻全国职业教育工作会议和省、茂名市关于职业教育工作文件精神，坚定不移地把社区教育和成人教育作为教育工作的战略重点抓紧、抓好，抓出成效。采取积极措施，抓好重点，打造特色，切实推动我市社区教育和成人教育再上新台阶。

（二）进一步加快整合乡镇成人文化技术学校资源。加快乡镇成人文化技术学校与镇文化站等功能大体相同的单位整合共享资源，提高乡镇成人文化技术学校基础能力和办学水平，提升农村成人教育服务当地经济社会发展的能力。积极利用各种教育资源，办好镇村两级成人文化技术学校，形成以县级职教中心为龙头、镇级成人文化技术学校为骨干、村级成人文化技术学校教学点为基础、各类培训机构积极参与的农村职业教育和成人培训网络，使其成为人力资源开发、农村劳动力转移培训、技术培训与推广、扶贫开发和普及高中阶段教育的重要基地。

（三）实施示范性学校建设计划。加快建设茂名市级示范性社区学校和成人文化技术学校，开展以成人教育为主，融婴幼儿早期教育、青少年校外教育、老年人教育、下岗工人和失业农民培训、新农村建设等内容丰富、形式多样的教育培训活动，构建多元化的终身学习体系，基本满足社区市民多样化的教育需求，促进终身教育体系和学习型社会建设。

（四）实施“全民素质提升工程”。 一是开展婴幼儿早期教育项目。依托幼儿园开展婴幼儿早期教育实验，开发运用0-3或4-6不同年龄段的早教课程，积极为社区居民科学育婴、科学早教服务。二是开展青少年校外素质教育。深入推进社会实践大课堂资源基地等校外教育平台建设。加强民办教育培训机构信用等级评估，积极引导社会培训机构面向青少年开设公益性课程，为青少年素质提升提供更多选择。三是开展成人教育培训。深化我市城乡劳动力统筹大培训，在市社区教育和成人教育工作领导小组统一部署下，开展企业职工培训、新型农民培训、劳动力转移培训、再就业、创新创业、后备劳动力等培训。加强农村实用技术人才培养和劳动力转移培训，提高农民工素质，大力培养新型职业农民。加强弱势人群提高生存技能培训，积极为社区各类残疾人提供教育服务。继续开展扫盲教育，至2025年文盲率控制在1.5%以下。积极推进家政等各类人员培养培训工作，提升从业人员整体素质。四是开展老年教育。进一步整合老年教育资源，扩大老年教育的规模，提高老年教育的水平，保障老年人应当享受的学习权利，最大限度地满足老年人的教育需求，提升老年人的生活质量，提高老年人的晚年生活幸福指数。至2025年，全年全市老年教育人数占60岁以上人口比重73%以上。五是开展新市民教育培训。建立健全新市民的学习保障机制，让他们与本地居民共同享有平等受教育的权利，广泛开展面向新市民的社区教育活动，以丰富的教育内容、灵活的培训形式和公益化教育宗旨吸引他们积极参加各类学习培训活动，丰富他们的业余生活，转变他们的生活方式，提高他们融入城市的能力。至2025年，全年新市民教育培训人数占新市民人数的85%。

（五）加强师资队伍建设。落实国家、省和茂名市相关文件精神，按要求配备乡镇成人文化技术学校和社区学校专职教师。发挥热心社会公益事业的老干部、老教师、老党员，参与社区教育和成人教育管理。有计划地培养社区学校和成人文化技术学校教师，提高全市社区教育和成人教育师资队伍的整体素质。努力建设一支以专职人员为骨干、兼职人员和志愿者为主体，相对稳定的社区教育和成人教育师资队伍。

（六）加强学校信息化建设。以国家级农村职业教育和成人教育示范县展示与交流平台为基础，逐步推进社区学校和成人文化技术学校信息化建设，为社区教育和成人教育提供宣传、学习、交流、沟通的平台。

（七）加强课程（读本）建设。社区教育和成人教育课程（读本）建设是丰富社区教育和成人教育资源，满足群众多样化学习，促进社区教育和成人教育内涵发展的重要举措。鼓励乡镇成人文化技术学校和社区学校的教师根据辖区内实际情况，大胆编写具有区域特色的社区教育和成人教育课程（读本）。至2025年，全市基本形成“一镇一品牌，校校有特色”的发展格局。

四、保障机制

（一）成立领导小组，确保组织领导。成立以市政府分管教育副市长为组长，各有关部门负责人为成员的社区教育和成人教育工作领导小组，以加强对我市社区教育和成人教育工作的领导。定期召开会议，研究解决全市社区教育和成人教育工作的重大事宜。领导小组下设办公室（在市教育局办公），具体负责全市社区教育和成人教育工作的组织、协调。由市教育局局长任办公室主任，市教育局和市人社局分管副局长任办公室副主任。

（二）强化工作职责，建立考核机制。将社区教育和成人教育列入教育事业发展规划和目标，进一步明确责任领导和责任部门，建立长效考核机制和常态化运行体系。各级社区教育和成人教育领导机构要定期召开会议，研究、部署、检查社区教育和成人教育工作，确保工作顺利开展。

（三）加大投入，确保工作经费。进一步落实社区教育和成人教育专项经费，并保证逐年增加。要足额筹措社区教育和成人教育经费，重点支持乡镇成人文化技术学校和社区学校建设、师资培养、农村实用人才培训、劳动力转移培训、创新创业、下岗失业人员技能培训等。

（四）大力宣传，建立激励机制。利用各种新闻媒体宣传社区教育和成人教育的重要性，举办“农村成人教育成果展”、“社区教育成果展”等，扩大社区教育和成人教育影响力，争取全社会的广泛支持。建立目标考核奖惩机制，将社区教育和成人教育列入年度目标考核范围和教育督导评估范畴，实行全面的监督评估，保证社区教育和成人教育工作健康发展。
