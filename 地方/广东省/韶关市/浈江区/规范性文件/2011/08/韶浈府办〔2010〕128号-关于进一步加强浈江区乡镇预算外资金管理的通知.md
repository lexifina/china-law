# 关于进一步加强浈江区乡镇预算外资金管理的通知

( )

韶浈府办〔2010〕128号

各镇人民政府，区府直属有关单位：

为规范乡镇预算外资金的管理，根据财政部下发《财政部关于将预算外资金管理的收入纳入预算管理的通知》（财预 [2010] 88号）精神，我区为进一步加强乡镇预算外资金的管理，现要求各镇政府、各相关部门按照如下事项严格执行：

一、各乡镇的非税收入（不含社会抚养费、教育收费）定为乡镇固定收入，由各乡镇按有关规定统筹使用；

二、乡镇非税收入必须上缴区财政专户，纳入预算管理；

三、原则上各乡镇财政所每月20日前，将各镇的非税收入由镇财政专户上缴区财政专户，区财政按月及时安排预算拨款；

四、以前的文件规定与本通知相抵触的，以本通知为准；

五、本通知涉及财政体制由区财政局负责解释。

二〇一〇年九月二十五日
