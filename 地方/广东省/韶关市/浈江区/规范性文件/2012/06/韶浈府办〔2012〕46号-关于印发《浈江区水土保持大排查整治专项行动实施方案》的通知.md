# 关于印发《浈江区水土保持大排查整治专项行动实施方案》的通知

韶浈府办〔2012〕46号

各镇人民政府、办事处，区府直属及驻区有关单位：

《浈江区水土保持大排查整治专项行动实施方案》业经区政府同意，现印发给你们，请认真贯彻执行。执行过程中遇到问题，请径向区水务局反映，联系电话：8255961。

二〇一二年五月八日

浈江区水土保持大排查整治专项行动实施方案

为防治和治理水土流失，保护和合理利用水土资源，减轻水、旱灾害，改善生态环境，确保我区水土保持工作有序开展，水土资源的可持续利用。根据《中华人民共和国水土保持法》及相关法律法规的规定，结合我区实际，在全区范围内组织开展水土保持大排查整治专项行动，为确保专项行动顺利开展并取得实效，特制定本实施方案：

一、组织领导和职责分工

（一）组织领导。成立由区政府副区长黄祖平同志任组长，区水务局局长李志斌任副组长，区发改局、区物价局、区国土分局、区住建局、区农业局、区林业局、区文新局、区产业转移园管委会、区旅游局、区供电局、区水政监察大队等单位负责人为成员的专项行动工作领导小组，领导小组办公室设在区水政监察大队。

（二）职责分工。区水务局和区水政监察大队主要负责专项行动的日常工作，各成员单位派出专人开展水土保持工作，并负责日常工作的上传下达。主要对辖区内从事房地产开发，开办经济（技术）开发区、旅游开发区，修建铁路、公路等基础设施、采矿、采石、养殖场、砖瓦窑经营性取土等生产建设活动的单位和个人编报送审《水土保持方案》核算的水土保持补偿费数额进行实地核查。办公室负责对此次专项行动的日常工作安排，做好此次专项行动的资料收集等工作。

二、工作任务

（一）行动目标。通过核查房地产开发，开发区、旅游项目，修建铁路、公路等基础设施、采矿、采石、养殖场、砖瓦窑经营性取土等生产建设活动的单位和个人，编报送审的《水土保持方案》核算的水土保持补偿费数额，对不按实际破坏植被面积和缴费标准计算补偿费的业主及设计单位，提出《水土保持方案》评审意见，要求重新复核实际破坏植被应缴费的面积，确保依法足额征收土保持补偿费。

（二）核查重点。对房地产开发，开发区、旅游项目，修建铁路、公路等基础设施、采矿、采石、养殖场、砖瓦窑经营性取土等生产建设，征占土地面积在1万平方米以上或挖填土石方总量在1万立方米以上的开发建设项目。

（三）依法依规征收。根据此次核查的开发建设项目，按照编制的《水土保持方案报告书》或《水土保持方案报告表》依法征收水土保持补偿费。

三、行动步骤与工作措施

（一）调查摸底与宣传阶段（5月16日至5月31日）。一是加大新修订的《水土保持法》宣传力度，提高全区各行政部门和全区人民群众参与水土保持工作的意识；二是对辖区范围内的建设项目进行水土保持专项检查，对没有依法编报《水土保持方案》的开发建设项目，责令限期补报；切实掌握建设项目《水土保持方案报告书》编制情况，编报送审的《水土保持方案》核算的水土保持补偿费数额。

（二）集中整治阶段（6月1日至6月30日）。6月组织一次全区范围的集中清查整治行动，对经营性取土等生产建设活动的单位和个人，编报送审的《水土保持方案》核算的水土保持补偿费数额进行实地核查，对不按实际破坏植被面积和缴费标准计算补偿费的业主及设计单位，提出《水土保持方案》评审意见，要求重新复核实际破坏植被应缴费的面积，确保依法足额征收土保持补偿费。对没有依法编报《水土保持方案》的开发建设项目，逾期不补报的，依法查处。

（三）总结提高阶段（7月1日至7月10日）。要深入分析非法占用水土保持工作开展的难点问题，积极探索水土保持工作管理长效机制。要多在职能管理上剖析不足，找准薄弱环节，尤其是开发建设项目的审核审批、现场巡查、监督检查等环节进行自查自纠，对此次水土保持专项行动的先进经验和有效做法，要认真总结，加强推广学习。

四、工作要求

（一）高度重视，周密部署。要充分认识开展水土保持工作的重要性和紧迫性，增强工作责任感和使命感，把思想和行动统一到专项行动的部署上来，结合实际，加强组织领导、加强联动，确保行动取得良好效果。

（二）加强检查，确保成效。注重实施，讲求实效，在落实水土保持方案中，着眼和注重实施，加强方案实施监督检查，杜绝为了方便施工或降低造价成本而造成新的水土流失和忽视水土保持质量的现象，严肃查处敷衍塘塞、应付了事等做法，杜绝豆腐渣工程。

（三）收集信息，及时反馈。高度负责，精心组织，自始至终把水土保持工作作为与主体工程同等重要的建设任务，列入重要议事日程，常议常抓，齐抓共管。加强专项行动的信息统计上报工作，及时报送行动进展情况，重大情况及时上报。
