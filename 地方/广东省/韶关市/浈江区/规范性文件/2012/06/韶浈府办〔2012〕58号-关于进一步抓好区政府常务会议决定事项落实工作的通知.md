# 关于进一步抓好区政府常务会议决定事项落实工作的通知

韶浈府办〔2012〕58号

各镇人民政府，办事处，区府直属各单位及驻区有关单位：

为进一步完善区政府常务会议运作机制，提高区政府常务会议决定事项落实效率和质量，经区政府领导同意，现就有关要求通知如下：

一、严格把关，确保审议事项高质上会

（一）主办单位要对拟提交区政府常务会议审议事项进行深入调研、充分论证、广泛征求意见，确保上会议题符合中央政策和地方实际，具有必要性和可行性；情况复杂、意见分歧较大的议题，在呈批过程中需经区政府分管领导协调后再提交常务会议审议。

（二）主办单位要对拟上会文稿认真准备、严格把关，并由单位主要负责同志签发上报，确保文稿质量，为常务会议顺利审议打好基础。

二、严格时限，确保议定事项高效落实

（三）经区政府常务会议审议通过以区政府或区政府办公室印发的文件，不需修改的，由区政府办公室立即办理印发；需作个别修改的，主办单位要根据常务会议意见修改后在2个工作日内（从会议结束第二天起算，下同）上报区政府，由区政府办公室审核办理，2个工作日内办结。

（四）经区政府常务会议审议原则通过、需作部分修改的文件，主办单位要在5个工作日内上报区政府，由区政府办公室审核办理，2个工作日内办结；区政府常务会议原则通过、需作部分修改且需补充征求意见的文件，主办单位要在7个工作日内上报区政府，由区政府办公室审核办理，2个工作日内办结。

三、加强督办，确保议定事项及时回报

（五）有关重点项目建设、体制机制改革等需较长时间分阶段、分步骤推进的议定事项，主办单位要每月定期向区政府办公室反馈办理进展情况，并明确单位责任领导具体跟进，区政府办公室按照职责分工做好跟踪督办工作。

（六）区政府常务会议审议未通过的议题，主办单位要按常务会议的具体意见抓紧办理。如需再次提交区政府常务会议审议，由区政府办公室根据区领导批示和实际情况另行明确上报时限。

（七）主办单位要按《区政府常务会议决定事项通知》要求及时反馈办理进展情况；区政府办公室将及时汇总并向领导报送《区政府常务会议决定事项执行情况》汇报，并视具体情况予以通报。

区政府工作会议议定事项，参照上述要求办理。

二〇一二年六月五日
