# 浈江区人民政府办公室关于印发《浈江区农村公路管理养护体制改革实施方案》的通知

韶浈府办〔2014〕30号

各镇人民政府，区府直属及驻区有关单位：

《浈江区农村公路管理养护体制改革实施方案》业经区政府同意，现印发给你们，请认真贯彻执行。执行过程中遇到问题，请迳向区地方公路管理站反映，联系电话：8867890、8883746。

韶关市浈江区人民政府办公室

2014年5月6日

浈江区农村公路管理养护体制改革实施方案

为加强农村公路养护管理工作，建立和完善公路养护管理机制，保障农村公路完好、安全、畅通，充分发挥公路在我区经济社会发展和人民生活中的重要作用，根据中华人民共和国《公路法》、国务院办公厅《关于印发农村公路管理养护体制改革方案的通知》（国办发〔2005〕49号）、省政府办公厅《转发国务院办公厅关于印发农村公路管理养护体制改革方案的通知》（粤府办〔2005〕96号）等法律和文件精神，结合我区实际，制定如下实施方案。

一、指导思想和目标任务

（一）指导思想

全面贯彻落实科学发展观，按照加强政府公共服务职能的要求，坚持农村公路建设、管理和养护并重的原则，强化各级交通主管部门的管理养护职责，理顺管理体制，建立健全以政府投入为主的稳定养护资金渠道，强化资金使用和管理，积极推进农村公路养护市场化进程，促进我区农村公路持续健康发展，为建设社会主义新农村和构建和谐社会提供强力支撑。

（一） 目标任务

按照省政府和省交通主管部门的统一部署，整体建立起符合我区农村实际和社会主义市场经济要求的农村公路管理养护体制，保障农村公路的日常养护和正常使用，实现农村公路管理养护的正常化和规范化。

二、明确职责、建立健全以区为主的农村公路管理养护体制

按照“统一领导、分级管理，以区为主、镇村配合”原则，将农村公路管理养护纳入各级政府的工作职责，纳入正常行政管理和公共管理服务的范畴，正确处理好建设和养护的关系，真正把建养并重的方针落到实处，确保农村公路管理养护体制改革顺利推进。

（一） 明确职责

1. 区人民政府：是本区农村公路管理养护的责任主体，分管交通工作的区政府领导是我区农村公路管理养护的责任人。主要职责：组织筹集本行政区域农村公路养护资金，制定出台各乡镇有关农村公路管理、养护以及养护资金筹措方面的具体职责；监督各镇人民政府做好辖区内农村公路及其设施的保护工作。

2. 区地方公路管理站：负责全区县道的日常养护管理工作；负责乡道、村道养护的监督指导工作。主要职责：编制上报公路建设、养护计划并按照批准的计划组织实施，编制上报农村公路建设、养护工程预算；管理农村公路养护资金；负责县道公路的路产路权保护、路政管理和县道公路的建设、管理和养护工作等；对全区乡道、村道公路日常养护进行监督指导，确保养护质量符合相关养护规范要求；接受上级业务部门对管养工作的监督。

3. 各镇人民政府：须设置农村公路管理养护机构，负责辖区内农村公路的日常管理养护工作；配合区地方公路管理站解决路群关系，无偿提供县道公路养护的取料、堆放和施工场地；负责乡道和村道公路的路政管理和路产路权保护；负责乡道和村道的改建、危桥加固或改建、公路事故隐患路段的整治和安全保障工程的建设等；负责筹集本辖区乡道、村道养护配套资金，组织沿线群众义务投工投劳共同做好农村公路养护工作；向区人民政府和区地方公路管理站书面提出对农村公路管理养护的意见和建议。

（二）理顺农村公路管养的责任主体

1. 乡道是指经省交通主管部门或省公路管理机构批准、核定、登记在册的通往行政村的主干道。村道是指经上级部门核定登记在册的通往自然村村庄的公路。

2. 各镇人民政府负责乡道、村道的建设和管养工作。主要工作为：（1）乡道的路面保洁、路肩培护、边沟疏通、边坡培护、道路绿化、防护工程完善及修复、路面大修及中修、水毁抢修及修复、交通安全标志和标线的设立及管理维护、路政管理等由各镇人民政府负责。（2）乡道和村道的改建、危桥加固及改建、公路事故隐患路段的整治及安全保障工程的建设等。其中乡道和村道的路产路权仍属原投资建设的当地政府或村委会。

3. 自然村村道的养护仍由村委会负责。

4. 各镇的养护工作情况将列入区年终绩效考评。

（三）机构设置和人员编制

我区地方公路管理站现有登记在册的农村公路总里程为487.837公里，其中县道73.527公里，乡道304.104公里，村道110.206公里。

1. 区地方公路管理站对农村公路管理养护工作人员重新定岗定员，具体定员定岗标准按国家和省的相关标准严格执行。成立浈江区农村公路养护道班，负责全区县道公路养护管理工作。

2. 各镇人民政府要明确一名副职领导，负责本辖区农村公路养护工作，并成立地方公里管理办公室，并配备1名专（兼）职工作人员，负责辖区内的农村公路管理养护的具体工作。

3. 各村委会要配备一名相对固定交通公路专干，负责辖区内的农村公路管理养护的具体工作。

三、资金筹措、使用和管理

（一）农村公路养护资金由省、市下达的公路养护费，市财政补助资金、区财政预算安排资金和乡镇自筹资金等构成。

（二）农村公路养护资金筹措：一是省、市拨给的专项补助资金；二是区政府按省的要求统筹本级财政预算，县道、乡道、村道均按每年每公里500元标准筹措；三是各镇人民政府按辖区内的道路里程，乡道、村道均按每年每公里100元的标准进行配套养护管理资金，以保证农村公路的正常养护。

（三）各镇人民政府积极拓展农村公路养护资金筹资渠道，要充分利用“一事一议”政策，引导沿线村民义务投工投劳养护农村公路。同时积极鼓励包括受益企事业单位在内的社会捐赠资金、单位赞助资金、个人捐款用于农村公路养护。

（四）为保证农村公路养护资金的安全使用，区地方公路管理站要设立农村公路养护资金专用帐户，并根据农村公路养护计划，综合平衡，统筹安排，专款专用。

区财政配套资金由财政部门拨付给区地方公路管理站农村公路养护资金专用帐户。

区地方公路管理站按养护计划，按季度将农村公路养护资金拨付各镇人民政府用于辖区内农村公路养护。

（五）区地方公路管理站负责对各镇人民政府农村公路养护质量进行检查，并每季度出具养护质量检查报告，作为拨付农村公路养护资金的依据。

（六）各有关部门要加强对农村公路管理养护资金使用的规范化管理，建立健全内部财务管理制度，任何单位或个人不得截留、挤占和挪用公路养护和建设资金。
