# 翁源县人民政府办公室关于印发《翁源县市政消火栓管理规定》的通知

翁源经济开发区管委会，粤台农业合作实验区翁源核心区管委会，青云山省级自然保护区管理处，各镇政府，铁龙林场，县政府各部门、各直属机构：

《翁源县市政消火栓管理规定》已经县政府十五届第20次常务会议通过，现印发给你们，请认真贯彻落实。
