# 柳城县人民政府办公室关于印发柳城县2012年实施退耕还林工程配套荒山荒地造林方案的通知

柳城政办〔2012〕11号

柳城县人民政府办公室

关于印发柳城县2012年实施退耕

还林工程配套荒山荒地造林方案的通知

各乡镇人民政府：

为完成自治区下达我县退耕还林工程配套荒山荒地造林5000亩的任务，经县人民政府同意，现将《柳城县2012年实施退耕还林工程配套荒山荒地造林方案》印发给你们，请认真组织落实。

二○一二年二月二十八日

柳城县2012年实施

退耕还林工程配套荒山荒地造林方案

根据自治区发展和改革委员会、自治区林业厅《关于下达广西退耕还林工程配套荒山荒地造林2011年中央预算内投资计划的通知》（桂发改投资〔2011〕1144号）文件精神，2012年我县将实施自治区下达的5000亩退耕还林工程配套荒山荒地造林任务。为确保全面完成造林任务，结合我县实际，特制订本方案。

一、指导思想

以“三个代表”重要思想为指导，积极贯彻西部大开发战略，落实“退耕还林、封山绿化、以粮代赈、个体承包”十六字方针，以建设“生态柳城”为目标，实行退耕还林、荒山造林、发展沼气、扶贫攻坚相结合，把握设计、种植、验收等主要环节，加强组织领导，强化工作措施，巩固几年来的退耕还林工程建设成果，努力完成本年度工程建设任务，实现我县林业又好又快发展。

二、建设规模及内容

（一）建设规模

根据上级下达的退耕还林工程配套荒山荒地造林任务，我县2012年实施退耕还林工程配套荒山荒地造林建设规模为5000亩。任务安排到全县12个乡镇，按照工程造林标准（单片种植面积不低于30亩）和先报先给的原则，种植连片珍贵树种十亩以上的（自治区推荐的树种）优先给予全额补助。如所报的面积超过5000亩任务的，则按核实面积的总数来相应按百分比形式减少面积，以实际造林并经县林业局作业设计面积为准。

（二）建设内容

在商品林区的宜林荒山荒地营造林5000亩，种植林种为乔木，以桉、松为优势树种的生态林。

三、实施步骤和时间安排

（一）2012年3月上旬，开展项目的宣传发动工作，通过媒体、标语等形式公开项目情况。

（二）2012年3月底，各乡镇林业站根据农户的申请，核实并上报退耕还林面积、地点、林种、树种。

（三）2012年4月，县林业局组织技术人员深入现场开展外业调查，进行造林作业设计，编写作业设计说明书，并上报市林业局审批。

（四）2012年5月底，完成全部的造林任务。

（五）2012年6—8月，开展自检工作，完善项目档案材料，迎接上级主管部门的检查验收。

四、投入概算与资金来源

（一）投资估算。

项目总投资估算范围包括当年营林工程投资和其它费用。工程建设总投资375万元,其中：

1.国家政策性补助：配套荒山荒地人工造林（乔木）中央补助标准为300元／亩（主要用于购买苗木和肥料补助）。全县工程建设造林5000亩，国家政策性补助共计150万元。

2.群众投工投劳或自筹：主要用于营林生产（包括整地、定植、补植等）125万元，抚育管护100万元，共计225万元。

（二）资金来源。

全县退耕还林工程配套荒山荒地造林建设所需资金合计375万元，资金来源主要是国家财政投入和群众自筹。

1. 国家财政补助150万元，占投资的40%。

2. 群众投工投劳或自筹225万元，占投资的60%。

（三）报批程序。

造林业主向乡镇人民政府提出申请→乡镇林业站上报退耕还林面积、地点、林种、树种→县林业局现场核实地块、面积→县林业调查规划设计队设计→柳州市林业局批复通过→县人民政府组织相关部门验收合格后→签订配套荒山荒地造林合同→公示7天→发放补助款。

五、工程管理

（一）种苗管理。要搞好种苗建设规划和生产计划，确保种苗生产与退耕还林在树种、数量、质量、进度等方面的有机衔接。要加强对种苗生产的质量管理、检查监督和检验检疫，加强种苗市场行政执法力度，坚决制止垄断种苗市场、哄抬种苗价格的行为，严厉打击种苗销售中的不法行为，维护农民合法权益。

（二）财务管理。按国家退耕还林补助资金管理办法的有关规定，实行专款专用，严禁截留、挪用项目建设资金。项目建设资金使用实行报账制管理，并接受上级或同级审计部门的监督。

（三）质量管理。严格实行“三环节”质量管理，即事先指导、中间检查和施工验收，确保从栽植到抚育等各生产环节给各造林户以技术指导。

（四）档案管理。建立和完善工程项目档案管理。各乡镇对项目档案的管理要配备专人负责，要及时将造林资料进行归档管理。

六、保障措施

（一）实行目标责任制，各乡镇主要领导负总责，分管领导具体抓，安排专人负责，层层落实责任制。

（二）落实好专项工作经费。

（三）县林业局要相应成立质量监督检查组，把好工程质量关。实行退耕还林工程荒山荒地造林公示和举报制度，设立举报信箱，公开举报电话，使退耕还林各项工作接受社会监督。

（四）责任到人，实行责任追究制，做到“谁设计，谁参与，谁签名，谁负责”，确保工程质量。

（五）依法治林，巩固退耕还林成果。加大宣传《森林法》、《森林法实施条例》、《退耕还林条例》等有关保护林地资源的法律法规，加强林政执法队伍建设，加大执法力度，加强对现有资源的保护，依法严厉打击毁林开垦行为，坚决杜绝“边退边垦”的现象发生。
