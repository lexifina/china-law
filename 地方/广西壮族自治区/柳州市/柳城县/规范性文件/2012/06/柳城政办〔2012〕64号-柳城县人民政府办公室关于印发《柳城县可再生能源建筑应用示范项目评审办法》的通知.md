# 柳城县人民政府办公室关于印发《柳城县可再生能源建筑应用示范项目评审办法》的通知

柳城政办〔2012〕64号

柳城县人民政府办公室关于

印发《柳城县可再生能源建筑应用示范项目评审办法》的

通 知

各乡镇人民政府、华侨经济管理区,县直各单位：

为规范我县可再生能源建筑应用示范项目的评审工作，经县人民政府同意，现将《柳城县可再生能源建筑应用示范项目评审办法》印发给你们，请遵照执行。

二O一二年五月十一日

柳城县可再生能源建筑应用示范项目评审办法

第一条 为提高可再生能源建筑应用示范项目(以下简称项目)管理的科学性、公正性，规范项目评审工作，根据《柳城县可再生能源建筑应用专项资金管理暂行办法》(柳城政办〔2012〕63号，以下简称管理办法)，制定本办法。

第二条 县可再生能源建筑应用办公室对本县申报的材料进行登记、造册，建立项目库，统一管理。

第三条 由县住建局、县财政局对项目申报材料进行初步筛选，列入项目库。对有下列情况之一的，不予列入：

（一）项目所采用的技术、设备不具备安全性；

（二）提供资料与实际情况不符；

（三）不符合所在区域的建筑节能标准；

（四）申报手续不完备，申请报告编写不符合规定；

（五）已获得可再生能源建筑应用相关的资金支持；

（六）利用可再生能源实行集中供热、供冷但未实行按用热(冷)量计量收费的项目；

（七）不符合管理办法有关规定。

第四条 县住建局、县财政局联合组织专家，从项目库中选取一定比例的项目，组织专家进行集中评审，并对项目示范增投资提出审核意见。

项目主要依据可再生能源建筑应用示范项目申请报告进行评分，详见《可再生能源建筑应用示范项目评分表》(附件1)，评审内容如下：

（一）技术先进，是指可再生能源应用技术的先进性；

（二）适用可行，包括实施单位和技术支持单位、运行维护、施工工艺、产品设备、风险；

（三）经济合理，包括增量成本、常规能源替代量、费效比(增量成本／节能效益)；

（四）示范推广，包括项目的区域代表性、建筑类型代表性、其他资源节约措施、后评估保障措施。

第五条 可再生能源建筑应用示范项目评审专家的组成。

(一)由县住建局、县财政局共同选择可再生能源建筑应用、建筑节能、财务、项目管理等方面的专家组成项目专家库；

(二)县住建局、县财政局从专家库中抽取专家组成专家评审组；每个专家评审组一般为3-5人，评审组应包含建筑、土木工程、建筑设备、工程造价等方面的专家，并指定一名专家组长；

(三)评审专家应具有对国家和项目负责的态度，具有良好的职业道德，坚持原则，独立、客观、公正地对项目进行评审，评审专家应具有高级专业技术职务；

(四)评审专家如与申报项目存在利益关系或其他可能影响公正性的关系的，应当申请回避。

第六条 县住建局、县财政局对评审合格的项目确定后进行公示，公示期十日，如有重大问题，经查实后取消示范资格。

第七条 本办法由县可再生能源建筑应用工作领导小组、县住建局、县财政局负责解释。

第八条 本办法自印发之日起执行。
