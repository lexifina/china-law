# 柳城县人民政府办公室关于增补调整柳城县资助贫困家庭子女上学工作领导协调小组成员的通知

柳城政办〔2012〕76号

柳城县人民政府办公室

关于增补调整柳城县资助贫困家庭子女上学

工作领导协调小组成员的通知

各乡镇人民政府、华侨经济管理区，县直各相关单位：

鉴于县资助贫困家庭子女上学工作领导协调小组部分成员变动和工作需要，经县人民政府研究，决定对县资助贫困家庭子女上学工作领导协调小组成员进行增补调整。现将调整后的领导协调小组成员名单通知如下：

组 长：温 剑 县委常委、宣传部部长、副县长

副组长：吕金凤 县委办副主任

胡振球 县政府办副主任

郑文勇 县政府办副主任

陈庆龙 县教育局局长

成 员：陆文元 县委宣传部副部长

李秀红 县民族局局长

杨明光 县教育局副局长

梁胜光 县教育局党委副书记

龙玉庄 县教育局纪委书记

李海燕 县民政局副局长

黄柳毅 县扶贫办副主任

秦舒宇 县总工会副主席

李 苗 团县委副书记

杨 葵 县妇联副主席

吴迪智 县残联副理事长

罗崇贵 广西柳城农村合作社银行副行长

领导协调小组下设办公室，办公室设在县教育局，负责领导协调小组日常工作。办公室主任：陈庆龙（兼），工作人员由领导协调小组成员单位有关人员组成。
