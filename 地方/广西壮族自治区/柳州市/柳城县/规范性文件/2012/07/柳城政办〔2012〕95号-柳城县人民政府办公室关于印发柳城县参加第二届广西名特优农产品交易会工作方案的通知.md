# 柳城县人民政府办公室关于印发柳城县参加第二届广西名特优农产品交易会工作方案的通知

柳城政办〔2012〕95号

柳城县人民政府办公室

关于印发柳城县参加第二届

广西名特优农产品交易会工作方案的通知

各乡镇人民政府、华侨经济管理区，县直各有关单位：

经县人民政府同意，现将《柳城县参加第二届广西名特优农产品交易会工作方案》印发给你们，请认真组织实施。

二O一二年六月十九日

柳城县参加第二届广西名特优农产品

交易会工作方案

为做好参加第二届广西名特优农产品交易会的筹备工作，根据《柳州市人民政府办公室关于印发柳州市参加第二届广西名特优农产品交易会工作实施方案的通知》（柳政办〔2012〕147号）文件精神，特制定本方案。

一、指导思想

以“三个代表”重要思想为指导，深入贯彻落实科学发展观，进一步解放思想、完善机制，围绕产业升级、消费升级和适应市场需求，以名特优农产品交易会为平台，以做强柳城县加工农产品品牌为抓手，以扩大加工农产品销售市场为重点，以强化产品创新、打造名牌产品、加大宣传和流通体系建设为依托，着力解决我县农产品质优价廉与市场影响力不足的矛盾，推动我县农业产业化、农产品加工业实现跨越式发展，促进农业增效和农民增收。

二、交易会规模和参展对象

（一）交易会规模：交易会共设468个标展展位，安排柳州市36个标展展位，其中柳城县5个标准展位。

（二）参展对象：我县农产品生产、加工、流通企业，农民合作社，种养加工大户均可参展。国家、自治区、市级农业产业化龙头企业原则上都要参展。

建议参展企业及产品：广西日田药业集团（蚕丝被系列、丝绸系列产品）；广西国营伏虎华侨农场茶厂（茶叶系列产品）；柳城县天地自然食品有限公司（脱水果蔬加工产品）；柳城县太平野森林食品有限公司（牛腊巴产品）；广西柳城县成霖农业科技有限公司（食用菌产品）。

三、交易会时间和地址

2012年6月28日至7月4日。玉林市国际会展中心。柳州市展区位于二层展馆第3区(详见第二届广西名特优农产品交易会展馆方案布置图)。

四、交易会活动内容

（一）展会形式

以销售农产品加工品为主，成果（技术、产品）展示为辅；通过现场展销、展示，推动贸易合作。

（二）主要活动

主要包括会前新闻发布会、采购商专场、开幕式、招商贸易洽谈与签约仪式、产品展示和销售、活动评比、总结表彰等。

六、参展产品要求

家禽和宠物活体产品不作为参展产品。参展产品原则以初、深加工的农产品为主，应当符合以下条件：

（一）柳城县企业、农民合作组织、种、养、加工、流通大户生产加工销售的名特优农产品，以及相关技术、物流服务产品。

（二）实体产品原则上要有注册商标或合法授权贴牌，需经过清洗、分级、包装、加工等处理，以分装或包装形式展示销售，杜绝“三无”产品进场展示销售。

（三）加工类食品产品必须具有全国工业产品生产许可证（食品生产许可证）。参展时，企业须备好工商营业执照、食品生产许可证复印件，产品有效期内以及有效期内检疫证、质量安全检验检测报告原件。

七、布展及进度安排

（一）布展要求

1.各乡镇、华侨经济管理区、各单位要认真宣传发动、组织农产品生产、加工、流通龙头企业、农民合作社、种养加工大户积极参展，认真筛选本辖区参展主推产品，落实参展企业（合作社、大户），组织、帮助企业（合作社、大户）做好参展农产品确认、产品宣传资料等参展准备工作。

2. 各乡镇、华侨经济管理区、各单位要负责征集企业(合作社、大户)产品推介数码图片3-5张，图片画面要清晰，图片类型为“JPG”或“GIF”，图片大小为5M以上，文字说明控制在300字以内，同时注明联系电话、传真、电子邮箱、通信地址，以方便识别联系，并将图文宣传资料上交县筹备小组办公室。

（二）工作进度安排

1.6月12日前，召开领导小组成员会议，布置参展事宜，将各乡镇、华侨经济管理区、各单位、各参展单位、个人的负责人、联络员姓名、联系电话、电子邮箱上报县筹备小组办公室。

2.6月16日前，各乡镇、华侨经济管理区、各单位确定参展企业(合作社、大户)、产品以及产品数量、负责人联系方式，上报县筹备小组办公室。

3.6月18日前，各乡镇、华侨经济管理区、各单位将征集的参展企业(合作社、大户)图文宣传资料上传至县筹备小组办公室。

4.6月25日前，各乡镇、华侨经济管理区、各单位组织各参展企业(合作社、大户)将产品和相关物品送到指定地点装车起运。具体时间和地点以电话通知为准。

5.6月27日前完成特装及布展。

6.6月28日前代表团全体成员到达交易会举办地点参加活动。

（三）其他

1.展位费、展位用电和安保费由自治区组委会统一承担。

2.各单位参展、参会人员交通、食宿、布展等费用自理。

3.其他未详事宜请及时与县筹备小组办公室联系。

八、保障措施

（一）提高认识，加强领导

参加本届交易会是促进我县农业产品流通、销售，推动我县特色产业优化升级，增加农民收入的重要举措。各乡镇、华侨经济管理区、各有关部门要高度重视，切实抓紧抓好筹备展出工作。

（二）精心组织，周密部署

县筹备小组办公室要制定切实可行的工作方案，认真、细致地推进有关工作，确保我县参展产品水平高、影响大、成效实。各乡镇、华侨经济管理区、各有关单位要加大工作力度，统一协调组织本辖区相关企业参加展销、招商引资、产品推介、贸易促进、宣传和后勤服务等工作，并及时与县筹备小组办公室沟通有关情况。

（三）加强沟通，密切配合

各乡镇、华侨经济管理区、各有关部门要根据工作职责，发挥各自优势，积极、主动地开展工作，及时协调解决有关问题，形成工作合力全面完成交易会各项参展任务。各乡镇、华侨经济管理区、各有关部门于6月15日前将各参展负责人、联络员名单和参展产品名称、数量上报县筹备小组办公室，联系人：肖志亮、朱云峰，联系电话：肖志亮[电话略] 朱云峰[电话略] 电子邮箱：nyj7618653@163.com。
