# 柳城县人民政府办公室关于对全县法定单位名称使用壮汉两种文字书写牌匾情况进行检查的通知

柳城政办〔2012〕97号

柳城县人民政府办公室

关于对全县法定单位名称使用壮汉

两种文字书写牌匾情况进行检查的通知

各乡镇人民政府，县直各办、局、中心，各人民团体，各企事业单位：

自治区人民政府于1984年明文规定全区法定单位要使用壮汉两种文字书写牌匾，《自治区人民政府办公厅关于重申使用壮、汉两种文字书写挂牌的通知》（桂政办〔1991〕59号）对相关情况进一步作出了明确规定，要求各法定单位应在单位名称牌子上冠上壮文。今年是国务院颁布《壮文方案》55周年纪念日，为进一步贯彻落实党和国家的民族语文政策法规，自治区民语委将于今年6月—8月对全区法定单位名称使用壮汉书写牌匾情况进行全面检查。为做好迎检工作，根据《自治区民语委关于开展全区法定单位名称使用壮汉两种文字书写牌匾情况进行检查的通知》（桂民语委〔2012〕9号）和《柳州市民语委关于做好全市法定单位名称使用两种文字书写牌匾情况检查汇报工作的通知》（柳民语发〔2012〕2号）要求，现将有关事项通知如下：

一、检查对象

全县法定单位。重点是：各乡镇政府大门、县政府行政中心大门挂牌，县政府行政中心大院外各单位挂牌，包括党政机关及其二层机构。

二、检查时间安排

各单位要在6月28日自查和整改完毕，县人民政府将组织政府督查室和县民语办于6月30日前进行检查。市民语委将于7月上旬对各县进行抽查，自治区民语委将于7月30日前进行复查。

三、自查和整改要求

（一）已有壮汉文字牌匾的单位，将牌匾的照片传到县民族局，要求文字清晰，以便县民族局检查壮文及书写格式是否准确。

（二）没有壮汉文字牌匾的单位，请持本单位证明并将单位的规范名称提供到县民族局，县民族局翻译壮文后，由本单位按规范格式自行制作。
