# 柳城县人民政府办公室关于认真贯彻落实广西壮族自治区规范性文件制定程序规定的通知

柳城政办〔2014〕34号

柳城县人民政府办公室

关于认真贯彻落实广西壮族

自治区规范性文件制定程序规定的通知

各乡镇人民政府、华侨经济管理区，县人民政府各组成部门：

规范性文件是行政机关实施法律法规规章、履行行政管理职能的一种重要的载体和方式，对于政府推动改革、发展经济、维护秩序、服务社会起着重要的作用。目前，各单位各部门在规范性文件制定程序中还存在一些问题：

一、缺乏规范性文件制定规划和计划

部门在制定规范性文件时没有对文件的必要性、所要解决的主要问题、拟确立的主要制度等进行研究。

二、起草规范性文件过程中部门间缺少协商

规范性文件往往涉及多个部门的职责或者与多个部门关系紧密。为此，规范性文件的起草部门应当与其他部门充分协商，争取取得一致意见；对充分协商不能形成一致意见的，在上报规范性文件送审稿时应当说明情况和理由。目前，部门制定规范性文件过程中忽视与其他部门协商，在没有广泛征求意见、集体讨论，在没有进行充分酝酿、论证的情况下，便草草出台规范性文件，缺乏制定规范性文件所必需的民主程序。

三、没有严格落实规范性文件发布前应当由法制办审核的制度

按《广西壮族自治区规范性文件制定程序规定》的要求，部门起草的规范性文件送审稿，经县法制办对规范性文件草案进行合法性审查，再提请县人民政府审议。目前，多数规范性文件的起草部门直接将送审核稿交县政府办公室审核，影响到规范性文件的质量，达不到应有的社会效果。

为规范规范性文件制定程序，维护社会主义法制统一，保证法律、法规和规章的正确实施，使大家进一步了解规范性文件制定的相关要求，避免上述问题的发生，各单位各部门要认真贯彻落实《广西壮族自治区规范规范性文件制定程序规定》，确保县级人民政府制定的规范性文件质量。
