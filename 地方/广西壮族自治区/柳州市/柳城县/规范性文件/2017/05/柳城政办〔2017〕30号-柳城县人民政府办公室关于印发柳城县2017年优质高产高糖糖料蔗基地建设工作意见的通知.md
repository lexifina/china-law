# 柳城县人民政府办公室关于印发柳城县2017年优质高产高糖糖料蔗基地建设工作意见的通知

柳城政办〔2017〕30号

柳城县人民政府办公室

关于印发柳城县2017年优质高产

高糖糖料蔗基地建设工作意见的通知

各乡镇人民政府、华侨管理区，县人民政府各组成部门：

《柳城县2017年优质高产高糖糖料蔗基地建设工作意见》已经县第十七届人民政府第6次常务会研究通过，现印发给你们。请结合实际，认真组织实施。

柳城县人民政府办公室

2017年5月4日

柳城县2017年优质高产高糖糖料

蔗基地建设工作意见

为进一步加快发展我县蔗糖产业，稳定甘蔗种植面积，提高单产，稳定总产，确保我县优质高产高糖糖料蔗基地（以下简称“双高”基地）建设任务的完成，特制定我县2017年优质高产高糖糖料蔗基地建设工作意见。

一、“双高”基地甘蔗种植计划

2017年全县“双高”基地计划种植甘蔗50000亩。

二、补贴政策

（一）补贴标准：

1.在“双高”基地内的宿根蔗、宿根翻蔸种蔗、短效作物改扩种蔗，每亩给予100公斤“杨柳”牌复混肥和50元机耕费补贴。

2.在“双高”基地内将长效作物如黄化水果、桉树、绿化苗木等挖蔸改扩种蔗的，每亩按1000元的标准给予补贴；连片3亩以上（含3亩）的，另外给予每亩150元的钩果蔸补贴。

（二）补贴范围：大力推广和重点扶持高产高糖甘蔗新品种，主要补贴桂柳05/136、桂柳一号、福农41号等优良品种，符合种植技术要求的，给予每吨补贴500元。

（三）资金来源：所需补贴资金和实物由县糖业局统筹安排。

三、工作要求

（一）长效作物改种蔗挖蔸前，由县糖业局牵头测量长效作物种植面积，并拍照存档备查。

（二）补贴面积以实际验收的面积为准。

（三）凡种植淘汰品种的种植户不享受补贴政策。

（四）各乡镇、各单位要结合实际情况，加大“双高”基地种植的宣传发动工作，深入蔗区，引导和指导农民种植甘蔗，积极帮助群众解决在甘蔗种植过程中遇到的困难和问题，确保按时按质完成“双高”基地建设任务。

（五）各乡镇、各单位要加强“双高”基地甘蔗种植后的田间管护，动员农户及时防治病虫草害，及时防旱排涝防倒伏，确保单产、糖分目标的实现。

四、补贴政策实施时限：自本文下发之日起至2017年9月30日止。

本意见由县糖业局负责解释。

公开方式：主动公开

抄送：县委各部门，各人民团体。

县人大常委会办公室，县政协办公室，县法院，县检察院。

柳城县人民政府办公室 2017年5月5日印发
