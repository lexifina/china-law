# 柳城县人民政府办公室关于界定柳城云片糕实施地理标志产品保护范围的通知

柳城政办〔2017〕56号

柳城县人民政府办公室关于

界定柳城云片糕实施地理标志产品

保护范围的通知

各乡镇人民政府、华侨管理区，县人民政府各组成部门：

为持续保持柳城云片糕的特有品质，进一步挖掘其丰富的地域文化特色和品牌内涵，提高其在国内外市场的影响力和竞争力，促进柳城云片糕特色产品产业的进一步发展、升级，带动地方加工食品产业增收致富，根据《地理标志产品保护规定》（国家质量监督检验检疫总局第78号令）的规定，经柳城县人民政府研究决定，将柳城云片糕申报地理标志产品保护地域范围界定为：

柳城县辖9镇3乡2个华侨管理区（大埔镇、龙头镇、太平镇、沙埔镇、东泉镇、凤山镇、六塘镇、冲脉镇、寨隆镇、社冲乡、马山乡、古砦仫佬族乡，柳城华侨管理区、伏虎华侨管理区），共121个村委会、16个社区居委会、1710个村民小组。
