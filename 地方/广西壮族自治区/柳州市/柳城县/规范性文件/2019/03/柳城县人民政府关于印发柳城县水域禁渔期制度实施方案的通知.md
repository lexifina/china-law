# 柳城县人民政府关于印发柳城县水域禁渔期制度实施方案的通知

各乡镇人民政府、华侨管理区，县人民政府各组成部门：

《柳城县水域禁渔期制度实施方案》已经县人民政府批准，现印发给你们，请认真贯彻执行。

柳城县人民政府

2019年6月28日

（公开方式：主动公开）

柳城县水域禁渔期制度实施方案

为贯彻落实《自治区农业农村厅关于印发2019年内陆水域禁渔期制度实施方案的通知》（桂农厅发〔2019〕30号）精神，根据《关于做好2019年柳州市水域禁渔期工作的通知》（柳渔牧函发〔2019〕5号）要求，结合我县实际，制定本方案。

一、禁渔范围

柳城县水域全境（养殖水域除外）。

二、禁渔时间

每年3月1日0时至6月30日24时，禁渔时段为4个月。

三、管理目标

禁渔期内，除休闲渔业、娱乐性垂钓外，禁止所有捕捞作业；禁止任何部门在禁渔期内组织垂钓活动；禁止所有餐馆、酒楼、集贸市场销售野生江鱼。各相关部门以陆上检查为主，把好码头、水上停泊点、市场管理工作，同时坚持水陆结合，切实加强水上监督检查，确保柳城县水域禁渔期制度的顺利实施，努力实现“江上无生产渔船，水中无作业网具，市场无捕捞江鱼”的“三无”管理目标。

四、组织分工

（一）组织机构。

成立柳城县水域禁渔工作领导小组成员，在领导小组的统一领导下，开展柳城县水域禁渔工作。

领导小组下设办公室（设在县农业农村局），办公室主任：韦丽梅（兼），副主任：罗泽玲（县渔政渔港监督管理站副站长），负责实施柳城县水域禁渔期制度的日常管理工作。各成员单位抽调一名业务骨干负责联络工作。

（二）部门分工。

县农业农村局：全面负责柳城县水域禁渔工作的实施和协调，县渔政渔港监督管理站具体负责管辖江段违规捕捞作业行为的查处、禁渔工作的宣传发动、登记在册渔船渔业用油财政补助申报、渔民服务、提供登记在册渔民的信息等工作。

县财政局：负责安排柳城县水域禁渔工作经费，解决禁渔期间登记在册渔民的生活补贴等问题。根据《柳州市人民政府办公室关于柳州市珠江禁渔期间渔民生活补助有关问题的批复》（柳政办函〔2012〕5号）要求，做好辖区登记在册渔民的生活补助。柳城县登记在册渔船的数量和财政补助资金见附件。

县公安局：负责对妨碍、干扰禁渔工作的行为依照《中华人民共和国治安管理处罚法》严肃处理，构成犯罪的，移交司法部门依法追究刑事责任。

县市场监管局：负责查处集贸市场内违法经营水生野生动物及其产品的行为。

县民政局：负责柳城县水域禁渔期间捕捞人员及家庭的社会救助工作，将生活困难并符合城乡低保条件的纳入城乡低保救助。

县交通运输局：负责打击渔船非法营运行为，协助对其他船舶非法捕捞行为的查处。

五、实施步骤

（一）准备阶段（3月1日以前）

1.宣传发动。县农业农村局以及各乡镇人民政府、华侨管理区要进行层层宣传发动，将有关柳城县水域禁渔的文件精神传达至各有关渔业生产单位和个人。要充分利用各种新闻媒体宣传柳城县水域禁渔制度，在渔村、码头、水上停泊点、市场等场所悬挂横幅、张贴标语、通告，通过发放宣传手册、宣传车（船）巡回广播和出版墙（黑板）报等形式进行宣传，确保柳城县水域禁渔制度家喻户晓，取得渔民和群众的理解、支持与配合。

2.加强检查与指导。县农业农村局要立足于抓早、抓实，积极组织落实好禁渔监督管理的执法队伍、执法船艇等相关准备工作。县渔政监督管理机构必须确保应禁渔渔船在3月1日0时前一律封网，要采取措施防火、防盗，消除隐患，做好禁渔安全工作。

3.签订责任状。县渔政渔港监督管理站要与渔船主签订责任状，责任要落实到船、到人。

（二）实施阶段(3月1日0时至6月30日24时)

1.严格监督检查。重点查处违法捕捞、破坏渔业资源的行为。要从实际出发，采取自查与交叉检查相结合，水上检查与市场检查相结合，重点突击检查与常规检查相结合，明查与暗访相结合等灵活多样的措施，共同把禁渔管理工作抓好。禁渔前期，要以查处违规作业和销售违规渔获物为突破口，积累执法经验；禁渔中期，要做好人工增殖放流工作，要安排好节假日工作，做到工作不断，秩序不乱；禁渔后期要加强宣传教育和监督，防止渔民提前开捕，并做好资源监测和本辖区禁渔期间所涉及的渔船数、渔民数和查处违规案件等情况的统计工作。

要坚决禁止渔船非法从事旅游运输活动，严厉打击渔船从事旅客搭载等违章行为。

2.加强信息报送。禁渔期间，柳城县水域禁渔工作领导小组办公室要及时掌握本辖区禁渔进展动态，认真总结禁渔进展情况、典型案例及成功做法，每月底报送一次给柳州市水域禁渔工作领导小组办公室，突发情况要及时报告。

3.建立举报制度。设立禁渔举报电话，在报刊、电视、网络公布禁渔举报电话号码，接受广大渔民群众和舆论的监督。对群众举报事项经登记后，要明确负责查处的部门、要求和时限，同时，要严格遵守保密制度和工作纪律，不得泄露举报人及有关举报情况，切实维护举报人的合法权益。

4.切实做好服务。禁渔期间，县农业农村局要积极开展对专业渔民的技能培训，并指导他们做好船舶修理、网具修补等服务工作。各乡镇人民政府、华侨管理区和有关部门要妥善解决禁渔期间专业捕捞渔民特别是困难渔民的生产生活问题，确保社会稳定。禁渔结束前，要做好供油等后勤服务保障，确保渔船、渔民在6月30日24时后能正常下水生产。

（三）总结验收阶段（6月30日至8月31日）

禁渔工作结束后，县禁渔工作领导小组要及时认真总结，肯定成绩，查找不足，提出解决的意见和建议，于7 月15日前以书面总结形式报送柳州市水域禁渔工作领导小组办公室。迎接上级的检查。

禁渔期间，向登记在册渔民发放相应的生活补助，如在禁渔期内违反禁渔期有关规定的，除按相关法律法规予以处罚外，不予发放下一年度的生活补助。同时，做好下一年度柳城县水域禁渔期登记在册渔民生活补助财政预算。
