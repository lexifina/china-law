# 柳城县人民政府办公室关于印发柳城县国土空间总体规划（2020-2035年）编制工作方案的通知

各乡镇人民政府、华侨管理区、县直各有关部门：

《柳城县国土空间总体（2020-2035年）编制工作方案》已经县人民政府同意，现印发给你们，请认真组织实施。

柳城县人民政府办公室

2019年7月12日

（公开方式：主动公开）

柳城县国土空间总体规划（2020-2035年）编制工作方案

根据《广西壮族自治区自然资源厅关于贯彻落实全国自然资源工作会议精神开展国土空间规划编制前期工作的通知》（桂自然资发〔2019〕8号）、《柳州市人民政府办公室关于柳州市国土空间总体规划编制工作方案》的通知（柳政办〔2019〕8号）精神，要求组织开展柳城县国土空间总体规划（2020-2035年）（以下简称“空间规划”）编制工作。市县国土空间总体规划是对市、县域范围内国土空间开发保护做出的总体安排和综合部署，是制定空间发展政策、开展国土空间资源保护利用修复和实施国土空间规划管理的蓝图，具有基础性、综合性和约束性，是编制相关专项规划和详细规划的依据。科学编制国土空间规划，以规划引领经济社会发展，是全面贯彻党的十九大精神和习近平生态文明思想的重要举措，是党治国理政的重要方式，是中国特色社会主义发展模式的重要体现。为做好柳城县国土空间总体规划（2020-2035年）编制工作，提升柳城县国土空间品质和利用效率，推动形成绿色发展方式和生活方式，根据自然资源部和自治区自然资源厅部署要求，结合柳城实际，制定本工作方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届三中全会精神，坚持新发展理念，统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，以绿色发展和高质量发展为主线，以人民为中心，围绕新时代自然资源和国土空间开发利用保护新战略，大力推进生态国土建设，绘制未来美丽国土一张蓝图。立足柳城县资源环境禀赋和经济社会发展阶段特征，深入实施“生态立县、富民强县”发展战略，把柳城县建设成为环境优美、经济发达、商业繁荣、行居方便、文化昌盛的现代化县城。加强统筹协调，兼顾开发与保护，发挥空间规划的战略引领和刚性管控以及对各专项规划的指导约束作用，全面提升柳城县国土空间治理能力和水平，促进柳城经济社会发展更高质量、更有效率、更加公平、更可持续。

二、基本原则

（一）落实国家和自治区战略。紧紧围绕“两个一百年”奋斗目标，充分落实市委、市政府重大战略部署，整体谋划新时代柳城国土空间开发保护格局，构建以空间规划为基础、以用途管制为主要手段的国土空间开发保护制度。

（二）体现国家意志。自上而下编制各级国土空间总体规划，下级规划要服从上级规划，相关专项规划、详细规划应与总体规划确定的约束性指标和管控要求相一致。

（三）坚持底线管控。优先布局关系粮食安全、生态安全、环境安全、经济安全和文化传承空间，实现柳城县永续发展。促进提升国土空间利用质量和效益，提高自然资源节约集约利用水平，实现高质量发展。

（四）坚持以人为本。把人们对美好生活的向往作为规划编制的出发点和落脚点，处理好人与自然的关系，提升人居环境质量，改善人民生活品质，增强人民的幸福感。

（五）坚持“多规合一”。落实主体功能区战略和制度，充分吸收原土地利用总体规划、原城市总体规划和各相关规划成果，编制统一的国土空间总体规划，实现国土空间总体规划管理全域覆盖、全要素管控，形成统一衔接、功能互补、相互协调的国土空间总体规划体系。

三、工作目标

围绕区域协调发展、乡村振兴、可持续发展、建设美丽中国等国家重大战略，按照以土地利用方式促发展方式转变，引领构建科学适度有序的空间治理体系，明确规划定位和管控要求，实施主体功能区战略和制度，落实国土空间总体规划确定的各项重点任务和调控目标，统筹当前与长远、局部与整体，统筹协调土地开发、利用、整治和保护。同时，立足柳城县资源环境禀赋、经济社会发展阶段特征和国土空间保护开发中存在的突出问题，通过规划编制力求解决柳城县国土空间保护、开发和治理中存在的突出问题，切实促进柳城县资源环境与经济社会协调、可持续发展。

四、规划思路与技术路线

（一）县级。

以“双评估”和“双评价”工作为基础，摸清柳城县两规实施以来取得的成效、存在的问题和面临的形势，明确区域发展的优势资源和短板因素。在科学研判发展趋势、面临问题挑战的基础上提出国土空间发展战略目标，构建柳城县域交通基础设施网络格局、生态保护格局、历史文化保护格局。在确定的国土空间开发、利用、保护格局框架内，统筹划定三区三线，优化交通基础设施、公共服务设施、水系、绿地等要素配置，明确国土综合整治和生态修复目标、分阶段规划实施目标和重点任务、下位规划需要落实的管控指标、边界和要求，并提出规划实施的保障措施。

(二)中心城区。

开展县城发展战略研究，明确县城性质和县城职能，确定县城规模和县城发展方向。优化完善县城空间内部结构，合理安排居住、公共设施、工业、仓储、市政公用设施、绿地等不同功能用地布局。统筹协调综合交通、市政基础设施、公共服务设施和公共安全设施要素配置，对历史文化保护、城市景观风貌、地下空间开发和城市设计等提出原则要求，凸显县城特色和品味。加强分项引导，划分规划单元，确定单元指引和政策要求，并提出应当编制的相关专项规划和要求。

五、主要任务

（一）厘清规划本底数据。

收集整理经济社会、土地利用、城乡建设等各类统计数据和空间信息，摸清柳城县耕地、林地、矿产等资源禀赋及开发利用现状；加强人口社会发展、新型城镇化建设、中心城用地布局、产业发展格局、地下空间与资源利用等基础性研究，为制定规划提供科学依据。

（二）评估规划实施成效。

深入开展现行土地利用总体规划和城市总体规划实施双评估，从规划指标执行、规划用途管制、两规差异冲突、规划实施管理、土地资源开发利用与人口、产业等经济社会发展的匹配性、规划编制方法、规划体系等方面，全面总结本轮规划实施以来取得的主要成效和面临的突出问题，提炼建议和创新思路，为开展国土空间总体规划编制工作厘清问题、明确目标、提供治理方案。

（三）开展重大事项研究。

根据规划实施评估结果，以问题为导向开展系列重大问题研究，为空间规划成果编制提供支撑。结合本地实际，开展人口与城镇村体系发展研究、生态环境保护与生态红线划定研究、耕地保护与永久基本农田优化研究、城镇开发边界划定研究、全域国土综合整治研究、产城融合与发展研究、综合交通体系研究、公共服务设施布局研究等相关专题研究。

（四）明确规划战略目标。

围绕“两个一百年”奋斗目标，按照“五位一体”总体布局，落实国家、自治区和柳州市重大战略决策部署，协调区域发展、乡村振兴、主体功能区战略、可持续发展等战略，统筹柳城县当前与长远、局部与整体、需求与可能，提出2035年柳城县国土空间发展目标，明确各项约束性指标和引导性指标。

（五）确定国土空间格局。

围绕基础设施互联互通、生态环境共治共保、城镇密集地区协调规划建设、公共服务设施统筹配置等方面要求，提出国土空间保护、开发、修复、治理等总体格局，确定全域城镇（镇村）体系；在资源环境承载力评价和国土空间开发适宜性评价的基础上，结合主体功能定位，确定全县国土空间总体规划分区，优化和确定生态红线、永久基本农田、城镇开发边界等“三条控制线”和生态空间、农业空间和城镇空间等各类管控空间。

（六）明确城乡规划管控要求。

落实国土空间发展目标，从城市空间、公共中心、历史保护、城乡风貌等方面细化城乡规划管控要求。提出城镇开发边界内集中建设区总体空间结构，明确商业、居住、工业等功能片区总体布局；建立全覆盖均等化公共中心网络，明确公共服务体系建设要求及原则；弘扬优秀传统文化，延续历史文脉，明确城乡历史文化遗产保护要求，划定城市“紫线”；改造城乡景观，提升城乡空间品质，提出城乡风貌改造原则和建设方针；划定城市开发边界内战略留白空间，应对未来发展的不确定性，用于重大事件、重大功能项目建设。

（七）推进国土空间生态修复。

明确国土空间生态修复目标、任务和重点区域；安排国土综合整治和生态修复重大工程、重点项目，提出整治和修复的规模、布局以及时序安排；明确各类自然保护地范围边界，提出生态保护修复的原则和要求。

（八）分解落实指标和任务。

落实柳州市国土空间总体规划下达的主要约束性指标，按照生态文明建设和绿色发展优先的要求，统筹考虑“三位一体”耕地保护、生态国土建设、资源节约集约利用、区域协同及城乡融合发展等目标，分解落实各乡镇的主要规划控制指标；提出应当编制的各类专项规划，以及空间规划对详细规划、专项规划的分解落实要求，落实规划实施传导机制。

（九）优化规划实施保障。

深化规划体制机制研究，优化规划实施的具体路径、手段和政策工具，从健全国土空间用途管制、落实规划实施责任、完善规划实施激励与约束机制、建立开放共享的国土空间基础信息平台等方面加强规划实施激励手段，促进规划科学编制和高效实施。

（十）编制各类规划。

按照国家和自治区的工作部署，组织编制详细规划、村庄规划和其他专项规划，落实国土空间总体规划的各项约束性指标和刚性管控要求。

六、规划范围和期限

县级国土空间总体规划范围为柳城县全域土地面积，其中用地指标安排涉及柳城县乡镇，用地指标布局主要涉及柳城县城区及下辖各乡镇镇区范围。乡镇总体规划范围为乡镇全域土地面积。

规划基期年为2019年，近期目标年为2025年，远期目标年为2035年。

七、县级规划成果

（一）专题研究报告。

1.柳城县土地利用总体规划和城市总体规划实施评估。主要研究内容和目标：总结现行规划实施以来取得的主要成效和面临的突出问题，为开展国土空间规划编制工作厘清问题、明确目标、提供治理方案。

2.柳城县人口与城镇村体系研究；主要研究内容和目标：围绕区域发展战略，结合人口发展、产业基础提出县域城镇体系，以及县中心城区城镇村体系、村庄类型和村庄布点原则。结合“一带一路”、国家西部大开发等重大区域发展战略，确定柳城在全区、柳州市域等不同尺度上的区域定位，围绕区域定位，提出柳城县城镇村体系规划。

3.柳城县生态环境保护和红线划定研究。主要研究内容和目标：摸清生态环境本底条件，提出生态环境保护策略，明确生态保护格局，划定生态保护红线。

4.柳城县耕地保护与永久基本农田优化调整研究。主要研究内容和目标：分析耕地保护与建设的现状情况，按照耕地“三位一体”保护的总体要求，落实全县及各乡镇耕地保有量目标，落实耕地占补平衡，调整优化永久基本农田，划定基本农田储备区。

5.柳城县全域国土综合整治研究。主要研究内容和目标：明确国土空间生态修复目标、任务和重点区域，安排国土综合整治重点工程的规模、布局和时序，明确自然保护地范围，提出生态保护修复要求，提高生态空间系统性和完整性，明确自然灾害防治的主要目标和措施。

6.柳城县城镇开发边界划定研究。主要研究内容和目标：在划定生态保护红线和永久基本农田的基础上，根据柳城县资源环境承载力和适宜性评价结果，围绕建设适度、宜居、美丽的生活空间目标划定城镇开发边界。

7、柳城县产城融合与发展研究。主要研究内容和目标：综合考虑柳城县发展条件和趋势，摸清柳城县产城发展总体情况，找出产城融合发展中存在的主要问题，提出产城融合发展的总体思路和用地布局方案。

8.柳城县综合交通体系研究。主要研究内容和目标：明确县域交通基础设施网络格局，统筹安排县域交通等基础设施布局和廊道控制要求，明确重要交通枢纽地区选址预控。

9.柳城县公共服务设施布局研究。主要研究内容和目标：摸清柳城县公共服务设施现状和短板，提出公共服务设施建设标准和布局要求，促进公共服务设施均等化配置。

（二）县级规划成果。

柳城县国土空间总体规划（2020-2035年）成果，包括文本、说明、图件、数据库、国土空间规划信息平台及监测预警系统等。

（三）乡镇级规划成果。

大埔镇等12个乡镇国土空间总体规划（2020-2035年）成果，包括文本、说明、图件、数据库等。

八、时间安排

根据自然资源部的工作部署和安排，2019年全面部署开展五级三类的国土空间总体规划编制，2020年前基本编制完成县级国土空间总体规划编制和数据库建设工作，并开展国土空间总体规划监督评估预警管理信息平台建设，有序开展专项规划和详细规划的编制工作。柳城县国土空间总体规划编制推进进度如下：

（一）启动阶段（2019年4月-5月）。按照自然资源部和自治区自然资源厅工作部署，成立空间规划编制工作领导小组和办公室，制定工作方案，落实工作经费，明确规划编制组，召开全县动员会议。

（二）现行规划评估阶段（2019年4月-7月）。对柳城县现行土地利用总体规划和城市总体规划实施情况进行评估，评估现行规划实施管理取得的成效，找出空间资源利用和布局的主要问题及“两规”主要差异，深入分析原因，为空间规划的编制奠定基础。

（三）专题研究阶段（2019年5月-12月）。对重点区域进行深入调研，与相关部门开展调研对接，做好与第三次国土资源调查成果的对接应用；开展人口与城镇村体系发展研究、生态环境保护与生态红线划定研究、耕地保护与永久基本农田优化研究、城镇开发边界划定研究、柳城县产城融合与发展研究、全域国土综合整治研究、综合交通体系研究、公共服务设施布局研究等相关专题研究。

（四）规划成果编制阶段（2020年1月-8月）。以第三次国土资源调查初步成果为基础，在同步完善专题研究成果的基础上，根据区域发展目标定位、城镇与产业发展、综合交通发展等用地需求，综合耕地保护、生态保护、城乡融合等因素，科学划定生态红线、永久基本农田保护红线以及城镇开发边界，明确城镇、农业、生态等各类空间，确定柳城县及各乡镇规划控制指标和用地布局，提出县城功能分区和管控要求，编制形成县级规划成果征求意见稿。

（五）规划成果论证审查阶段（2020年9月-10月）。充分征求社会公众、各领域专家和有关部门意见，组织听证、论证和专家审查；根据收集反馈的意见以及柳州市下达的主要规划控制指标，对县级规划成果进行修改完善，形成报批稿。同步完成柳城县国土空间总体规划信息平台建设以及规划数据库建设成果。

（六）规划成果报批和数据库建设阶段（2020年10月-12月）。将柳城县国土空间总体规划成果按法定程序上报审批。

（七）乡镇级规划和村庄规划编制阶段。结合自治区及柳州市的时间要求，适时组织开展乡镇国土空间总体规划，有开发建设和保护修复需求的村做到村庄规划应编尽编。

九、保障措施

（一）加强组织领导。为加强规划编制工作统一领导，成立柳城县国土空间总体规划编制工作领导小组，县人民政府主要领导任组长，分管副县长任副组长，成员由县自然资源和规划局、县发改局等部门和乡镇主要领导组成。领导小组下设办公室，办公室设在县自然资源和规划局。各成员单位要统一思想、提高认识、积极参与、主动作为，确保规划编制工作顺利推进。

（二）强化技术支撑。建立专家咨询机制，在自治区自然资源厅、市自然资源和规划局的指导下，聘请自治区、柳州市以及柳城县相关领域权威专家作为此次规划编制的专家团队，对编制工作中的技术问题进行咨询、指导。

（三）落实经费保障。将空间规划编制工作经费纳入柳城县本级财政预算，并严格按照有关规定使用，保障项目顺利进行。

（四）全程公众参与。坚持“开门编规划”，使规划编制的过程成为广纳民意、集中民智、凝聚民心的过程。通过各种媒介加大规划编制宣传力度，主动开展规划编制工作解读，普及规划理念方法，提高公众对规划的认知。规划方案形成后多征求意见、多方案比选，倡导公众积极参与，为规划编制建言献策。规划批复后要及时公开，推进形成共谋、共用、共享的规划实施方式。
