# 柳城政规〔2023〕3号柳城县人民政府关于印发柳城县集体土地及房屋征收补偿安置标准的通知

柳城政规〔2023〕3号

现将《柳城县集体土地及房屋征收补偿安置标准》印发给你们，请认真贯彻执行。

柳城县人民政府

柳城县集体土地及房屋征收补偿安置标准

为确保我县集体土地及房屋征收工作的顺利实施，结合我县实际，制定如下补偿安置标准。

一、征收补偿安置依据

（一）《中华人民共和国土地管理法》；

（二）《广西壮族自治区实施〈中华人民共和国土地管理法〉办法》；

（三）《广西壮族自治区人民政府办公厅关于做好新一轮征地区片综合地价的通知》（桂政办函〔2023〕6号）；

（四）《柳州市人民政府办公室关于做好新一轮征地区片综合地价实施的通知》（柳政办函〔2023〕9号）；

（五）《柳城县人民政府办公室关于做好新一轮征地区片综合地价实施的通知》（柳城政办函〔2023〕3号）。

二、征收范围及区片分类

（一）征收范围：本县行政区域范围内因项目建设需要征收的集体土地及房屋、青苗等附着物。

（二）按有关法律规定，对征地补偿标准实行分区域制：一类区大埔镇；二类区东泉镇、沙埔镇、凤山镇、六塘镇；三类区太平镇、寨隆镇、冲脉镇、马山镇、社冲乡；四类区龙头镇、古砦仫佬族乡。

四、土地征收奖励标准

从征地工作组入户开始计算，在20日内交出土地的被征地户，奖励为15000元/亩；在30日内交出土地的被征地户，奖励为10000元/亩；逾期未交出土地的，不给予奖励。

五、房屋征收补助及奖励标准

（一）主房征收补助、临时安置补助标准：在过渡期限内，被征收人自行安排住处的，每户一次性给予2000元的房屋搬迁补助费。以宗地户为单位，按每月每户1000元的标准，一次性发放一年的临时安置补助费。

（二）搬迁奖励：以宗地户为单位，在20天内签订征收补偿安置协议书，并于规定时限内自行搬迁完毕，给予一次性搬迁奖励10000元/宗地户；在40天内签订征收补偿安置协议书，并于规定时限内自行搬迁完毕的，给予一次性搬迁奖励5000元/宗地户；逾期不予享受奖励政策。

（三）其他：

1.自改营业性铺面执有营业执照、获得经营许可并且在征收公告发布前实际经营的，按20000元/户的标准给予停产停业补助。未执有营业执照但实际经营达6个月以上的，按10000元/户的标准给予停产停业补助。

2.拆迁有产权纠纷的房屋，应实行证据保全，产权纠纷不影响房屋拆迁的实施。

3.县城规划范围内征收房屋补偿原则上采取货币补偿、房屋产权调换和回建地调换三种补偿安置方式，被征收人只能选择其中一种补偿安置方式。回建安置房按照土地利用总体规划和城市总体规划设计要求，实行统一规划、统一设计、统一安置。县城规划区外征收房屋实行货币补偿安置方式，被征收房屋为被征收人唯一住房的，被征收人可以在符合土地利用总体规划和村庄规划的条件下，重新选址建设。

4.征收土地范围内被拆迁的房屋和建（构）筑物经依法补偿后拒不搬迁的，按照法律法规及政策的规定依法拆除。

六、柳城县行政区域内青苗和地上附着物补偿标准的适用原则

本通知印发之日起，县行政区域青苗和地上附着物补偿标准按本通知规定执行；在本通知印发前，项目的征地补偿安置方案已经县政府批准的，该项目的青苗和地上附着物的补偿标准仍按该项目方案规定的补偿标准执行。

七、地上附着物征收丈量方法

（一）按中华人民共和国国土资源行业标准《土地勘测定界规程》（TD/T 1008—2007）对项目红线范围内的地上建（构）筑物进行丈量、绘制草图、登记评估造册。

（二）地上建筑物为房屋的，建筑面积丈量登记按照国家颁发的《房产测量规范》（GB/T17986.2—2000）规定的建筑面积计算规则标准执行。

八、违法用地、违法建（构）筑物处理

（一）《征地公告》发布后抢种、抢挖、抢建的农作物、林木、鱼塘、水塘、水井、水池、水柜等建（构）筑物一律不予补偿；凡属违章建（构）筑物一律不予补偿。

（二）《征地公告》发布后，在征收红线范围内抢建的建（构）筑物、抢种的作物一律不予补偿。

九、法律保障和工作要求

（一）青苗、建（构）筑物的争议、纠纷均由所在地乡镇相关部门调处。调处不成，进入法定程序，青苗、建（构）筑物补偿款公证存蓄，任何单位、组织和个人均不得以此为由干扰、阻挠征收工作。

（二）在实施征收土地工作中，当事人有违法行为的，由有关行政机关依法给予处罚；构成犯罪的，依法追究其刑事责任；造成经济损失的，同时追究其民事责任。

十、国家重大项目工程建设征收土地上青苗及附着物补偿另有规定的，从其规定。

本通知未作规定的事项，按国家、自治区法律法规规定执行；本通知与国家、自治区有关法律法规、文件规定不一致的，按国家、自治区法律、法规、文件执行。

十一、本补偿标准自印发之日起生效，《柳城县人民政府关于印发柳城县集体土地及房屋征收补偿安置标准的通知》（柳城政规〔2020〕8号）自行终止。
