# 大坡乡人民政府关于印发《大坡乡2017年春季重大动物疫病防控工作实施方案》的通知

各村民委，乡直各相关单位：

为贯彻落实《中华人民共和国动物防疫法》，切实做好我乡重大动物疫病防控工作，确保全乡养殖业健康发展，结合我乡实际，制定本实施方案。现印发给你们，请遵照执行。

大坡乡人民政府

2017年3月2日

大坡乡2017年春季重大动物疫病

防控工作实施方案

为贯彻落实《中华人民共和国动物防疫法》，切实做好我乡重大动物疫病防控工作，确保全乡养殖业健康发展，根据我乡实际情况，特制定本方案。

一、指导思想

以科学发展观为指导，认真贯彻执行“加强领导、密切配合、依靠科技、依法防治、群防群控、果断处置”的动物防疫方针，确保畜牧业健康发展、确保人畜安全。

二、工作目标、任务

今年春季重大动物疫病防控工作的主要目标任务是：努力确保不发生区域性重大动物疫情，抓好高致病性禽流感、口蹄疫、高致病性猪蓝耳病、猪瘟等四种重大动物疫病的强制免疫，确保应免畜禽免疫密度达100%，免疫抗体合格率保持在70％以上，动物免疫档案记录规范、完整。鸡新城疫、狂犬病、炭疽、猪链球菌病等非强制免疫病种按计划免疫到位。

三、工作内容

（一）切实加强疫苗管理、抓好免疫注射。一要按计划组织好各类动物生物制品的供给，认真做好疫苗的发放、领用、结存等台账记录。按要求进行疫苗运输和储存，做好冰箱、冷库日常维护和温度记录，保证冷链系统各环节不出差错，同时要加大对疫苗的监管力度，规模养殖场自购疫苗要及时备案，使用不合规定疫苗要严肃追究相关责任人责任。二要高度重视春季动物集中免疫工作，克服麻痹思想、松懈思想和侥幸心理，切实提高思想认识，统筹安排部署，积极协调配合，保障工作措施落实到位。三要抓好高致病性禽流感、高致病性猪蓝耳病、口蹄疫、猪瘟等四种动物疫病的强制免疫工作，确保应免尽免，强化二次免疫，保证应免动物的免疫密度达100%，免疫抗体合格率达70%以上。四要指导养殖场制定科学免疫程序，配合县水产局抓好免疫效果监测和免疫质量评估。

(二）加强疫情监测和预警预报，及时消除疫情隐患。坚持“定时、定点、定量、定性”监测制度，切实抓好口蹄疫、禽流感、高致病性猪蓝耳病、猪瘟、布鲁氏菌病、狂犬病等重点疫病的流行病学调查、监测。对举报的可疑动物疫情要及时进行核查，妥善处置，排除隐患。根据县水产局监测结果进行风险评估，及时预警预报动物疫情。

（三）切实抓好H7N9禽流感防控工作。要进一步加大对活禽经营市场、养殖场的监管工作力度， 配合县水产局扩大监测范围，增加监测频次，及时掌握实情。要切实加强活禽经营市场管理，严格落实休市消毒制度，确保活禽经营市场各项防控措施落实到位。

（四）切实抓好人畜共患病、常见疫病的防控。对生猪布鲁氏菌病要加强监测；对牲畜炭疽、猪链球菌病、家犬狂犬病等要扎实做好免疫注射。发现阳性人畜共患病牲畜，必须按规定扑杀、无害化处理，严防感染到人。对猪流行性腹泻、传染性胃肠炎等常见猪病，要采取综合防治措施加强防控，遏制疫病流行、蔓延。

（五）强化动物产地检疫，确保畜禽产品质量安全。

要严格实施产地检疫，加强对动物饲养以及畜禽调运等环节的监督检查，防止动物疫病跨区域传播。对没有按规定实施重大动物疫病强制免疫的畜禽，要坚决执行“不许出证、不许流通、不许屠宰”的制度，真正做到“以监促检，以检促免”。要加强动物及其产品交易市场尤其是活禽交易市场的监管，对没有动物检疫合格证明的畜禽，禁止进入交易市场销售，对逃避或抗拒检疫、免疫以及经营病死畜禽及其产品的，要坚决依法从严查处。

1.切实做好产地检疫。完善动物检疫申报点建设，畅通货主申报检疫的渠道。坚持动物检疫全程监管的原则，对受理的每一起检疫申报，切实做到到场、到户、到点实施现场检疫，要努力做到动物产地检疫面达100%，动物产地受检率达100%以上。

2.要严格检疫证章标志管理。专人专管，严格抓好检疫证明、标志的领取、发放、使用管理，严厉打击伪造、变造、转让、买卖证章标志违法行为，维护证章标志的严肃性。

3.加大监管力度，严查动物防疫违法行为。严格养殖环节监管，重点加强对动物饲养环节防疫条件、免疫档案、标识加施、强制免疫、投入品使用、病死动物无害化处理等的监督管理，建立监管档案。

（六）切实加强病死动物无害化处理监管。要强化属地管理，落实处置责任，完善监管体系，开展对养殖等环节死亡动物无害化处理的专项检查、监管，严厉打击不按规定处置死亡动物等违法行为。要根据本地实际，加快推进病死猪无害化处理基础设施建设，探索建立病死动物无害化处理及监管长效机制。

（七）做好突发疫情应急工作。做好应急物资储备，储备好足够的疫苗、消毒剂、消毒器械和防护服等防控应急物资，及时充实专家队伍人员。一旦发生疫情，要按《重大动物疫情应急条例》规定的程序，启动应急预案，采取坚决措施，实施应急处理，把疫情控制在疫点，严防扩散，不留后患。

四、实施时间、步骤

（一）第一阶段，宣传部署。2017年3月1日-5日，做好工作部署、目标分解、责任落实、防疫物资、经费筹备及宣传发动等工作。

（二）第二阶段，组织实施。2017年3月6日-4月26日，做好免疫注射、各种防疫工作记录以及信息采集等工作。

（三）第三阶段，验收总结。2017年4月27-30日，完成乡本级的春防验收工作，包括免疫密度、信息采集以及材料归总整理等工作。

（四）第四阶段，迎接考核。2017年5月上旬（具体时间按融安县重防指挥部的通知），迎接自治区或柳州市重防指挥部的春防考核。

（二）确保动物防疫经费落实到位，制定明确的免疫奖惩标准。乡级财政严格按规定落实好应急储备金等经费和其它防疫工作运转经费等，确保动物防疫工作顺利开展。

1.村防疫员的工作报酬。春防结束后根据《融安县乡镇动物防疫承包实施方案》和《动物防疫承包业务考核办法》等相关规定进行业务考核，按考核结果兑现劳务报酬，实施奖惩。

2.如实填报动物养殖档案。要求：①免疫示范屯的动物养殖档案必须规范填写；②面上屯每本养殖档案不低于25户养殖户（少于25户的可以合并几个屯填写）。

（三）及时督查，保证春防工作实效。乡人民政府加大对村级动物防疫工作的督查力度，及时组织人员进村、入户、入场督查指导。集中免疫结束后，及时组织验收，对动物免疫抗体合格率未达标的，要及时组织力量进行强化免疫，确保免疫效果。

（四）按时报送信息。春防期间，各村村防疫员要按时报送免疫进度、免疫登记表和免疫档案等材料：
