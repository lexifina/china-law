# 关于印发融安县2017年特种设备安全隐患排查和治理方案的通知

各所、局机关各股、室、大队、稽查局：

现将《融安县2017年特种设备安全隐患排查和治理方案》印发给你们，请认真贯彻执行。

2017年4月25日

融安县2017年特种设备安全隐患

排查和治理方案

为进一步做好全县特种设备安全生产工作，着力消除特种设备事故隐患，预防和减少特种设备安全事故的发生，确保特种设备的生产、使用安全，按照县委、县政府和市质监局的统一布置，结合我县实际，特制定本方案。

一、工作重点

以涉及民生、人员密集场所、盛装危险化学品的高风险特种设备为重点，突出对学校、幼儿园和医院、车站、客运码头、商场、公园、活动（会议）场馆等公众聚集场所的特种设备，以及客运索道、大型游乐设施和盛装毒性程度极高的危害介质、易燃易爆介质的承压类特种设备，组织开展安全隐患排查和治理。

二、工作目标

特种设备使用单位安全主体责任得到有效落实，特种设备安全隐患得到进一步排查和有效治理，风险防控与隐患排查治理长效机制进一步完善，遏制重特大事故和重大影响事件的发生，防范系统性、区域性、行业性的特种设备事故。

三、组织领导

为加强对特种设备安全生产工作的组织、领导和实施，我局成立“特种设备安全隐患排查和治理工作领导小组”， 领导小组组长由分管特种设备工作的副局长担任，各所、局机关各股、室、大队、稽查局及中心负责人为组员的组织机构。在县委、县政府以及市质监局统一领导下，加强与安全生产监管部门、行业主管部门的协调联动，充分发挥检验机构、行业协会等特种设备安全相关方的作用，要落实企业主体责任，突出重点，攻克难点，务求取得实效。

四、进度要求

2017年2月开始至2017年12月结束，分三个阶段进行。

（一）动员部署阶段（2017年2月至3月）。制定工作计划，认真开展动员部署，做好内部宣传，做到全员发动；确保把特种设备安全隐患排查和治理的要求传达到相关使用单位。

（二）全面实施阶段（2017年3月至10月）。组织特种设备使用单位认真开展全方位、全过程的自查自纠，持续动态排查消除各类安全隐患，确保所使用设备的安全运行；实施过程监督检查和督查等，及时研究解决工作中的问题，确保特种设备隐患得到有效治理。

（三）总结阶段（2017年11月至12月）。认真总结经验成果，做好工作收尾，形成总结报告。

五、工作要求

（一）按照《关于制定2017年度特种设备安全日常监督检查计划的通知》（柳质监办发〔2017〕1号，以下简称《检查计划》）及本方案要求，开展特种设备使用单位安全隐患排查和治理工作，对《检查计划》制定的重点监督检查特种设备使用单位及纳入本方案“工作重点”的特种设备使用单位列为重点监督检查对象，对其他特种设备使用单位可按一定比例以“双随机”原则开展监督抽查。要依据《特种设备现场安全监督检查规则》，对特种设备使用单位实施监督检查，并对使用单位开展安全隐患排查和治理情况进行检查，督促其落实整改；对于拒不整改或整改不到位的，及时报告地方政府和上级监管部门。

（二）督促检查特种设备使用单位落实安全生产主体责任。对照相关法律法规、安全技术规范等要求，实施全方位、全过程的特种设备安全隐患排查，不放过任何一个环节，不漏掉任何一个疑点，重点对特种设备是否进行使用登记、安全管理制度和操作规程是否建立并有效实施、人员持证和培训是否符合要求、设备档案是否完备、设备是否在检验有效期内、经常性维护保养和定期自行检查是否到位、安全附件和安全保护装置是否在有效期内等进行检查；督促特种设备使用单位建立隐患台账，列出问题清单，逐一落实整改，要做到责任、措施、资金、时限和预案“五落实”，到期未完成安全隐患整改、无法保证安全时，应停止使用相关设施设备，并及时报告地方政府和上级部门。

（三）加强信息统计和报送。

各所、局机关各股、室、大队、稽查局及中心按要求对隐患排查和治理情况做好信息统计和报送工作（见附表），在每季度末25日前向县局特种设备安全监察股报送特种设备使用单位自查自纠和对使用单位的监督检查、抽查情况。
