# 关于印发融安县市场监督管理局2017年第二季度安全生产大检查实施方案的通知

各所、局机关各股、室、大队、稽查局及中心：

为全面贯彻落实党中央、国务院、自治区党委、政府、市委、市政府和县委、县政府关于安全生产工作的一系列方针政策和要求，于即日起至6月底在全系统开展为期三个月的安全生产大检查，现将《融安县市场监督管理局2017年第二季度安全生产大检查实施方案》印发给你们，请认真贯彻执行

2017年4月28日

融安县市场监督管理局2017年第二

季度安全生产大检查实施方案

为贯彻落实党中央国务院、自治区、柳州市党委政府和县委县政府关于安全生产工作的一系列方针政策和要求，根据县安委办《融安县安全生产委员会关于开展全县第二季度安全生产大检查的通知》（融安委办〔2017〕9号）文件要求，结合我局实际，特制定本方案。

一、工作目标

为认真贯彻落实自治区第二季度防范特大安全事故电视电话会议精神，按照区、市、县安全生产工作部署，进一步落实企业安全生产主体责任，切实预防和减少事故发生，确保全县安全生产形势持续稳定好转，为党的十九大胜利召开创造稳定的安全生产环境。

二、检查范围

此次安全生产大检查的范围是全县所有乡（镇）、行业（领域）的生产经营单位和人员密集场所。在全面检查的基础上，重点加强对道路交通、非煤矿山、尾矿库、危险化学品、烟花爆竹、冶金有色、水上交通、铁路、民航、建筑施工、人员密集场所、特种设备、民爆器材等行业（领域）的检查。

三、检查内容

（一）各类生产经营单位证照是否齐全;是否建立健全事故隐患排查治理制度。

（二）生产经营单位主要负责人是否组织开展对本单位事故隐患排查治理工作；是否定期组织安全生产管理人员、工程技术人员和其他相关人员排查本单位的事故隐患；是否对排查出的事故隐患，按照事故隐患的等级进行登记，建立事故隐患信息档案，并按照职责分工实施监控治理。

（三）重点行业（领域）打击非法违法行为和专项整治落实情况。

（四）汛期安全防范措施落实情况。

四、加强应急值守，严防自然灾害引发生产安全事故

第二季度，进入雷雨高温季节，各单位要认真落实联动机制，加强针对雷雨、高温天气的预报、预警、预防工作，督促企业认真开展风险评估、隐患排查和应急物资储备等工作，落实雷雨、高温天气下的设备检修维护及安全防范措施，严防各类生产安全事故。要进一步完善应急预案并加强演练，健全完善应急协调联动和快速反应机制。要切实加强值班值守工作，提早安排节目和重点时段值班，严格执行领导干部到岗带班、关键岗位24小时值班制度和事故信息报告制度，一旦发生事故或紧急情况，立即请示报告，并及时有效开展应急救援和处置工作。

五、工作要求

（一）加强组织领导。各单位要按照“党政同责、一岗双责、齐抓共管”的要求，强化领导，周密部署，细化责任，狠抓落实，务求实效。

（二）强化措施落实。一是按照“全覆盖、零容忍、严执法、重实效”的要求，对发现的隐患，要立即整改，不能立即整改的要限期整改。在规定时限内未完成整改的必须停产整顿。凡发现未按规定开展隐患排查整治或整治不力或未按规定上报隐患排查和分析情况的，一律依法给予行政处罚。各单位要将检查发现的重大事故隐患和安全问题及时上报县局，并做好整改情况的跟踪督导。

（三）各单位结合汛期期间安全生产检查和“六一”、端午节等节假日，加强对各辖区的矿山（尾矿库）、危险化学品、烟花爆竹、大型游乐设施、客运索道、人员密集场所、消防、特种设备等行业的排查力度，对历次检查中发现的事故隐患进行梳理、归类、汇总、督促整改，确保隐患整改落实到位，力争消除一批事故隐患。

（四）县局要组织对各单位开展安全隐患大检查大整治工作的督查。

（五）做好总结。大检查大整治活动结束后，各单位要认真总结，并于6月29日前将书面总结（包括下发的相关文书、检查记录及图片资料），加盖单位公章报送县局市场股，联系人：覃晴，电话：8153653，同时将电子文档报送市场股邮箱。此次大检查工作要纳入各单位年度安全生产履职考核。
