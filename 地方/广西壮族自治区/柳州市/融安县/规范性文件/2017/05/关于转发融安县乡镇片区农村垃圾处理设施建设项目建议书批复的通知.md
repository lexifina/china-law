# 关于转发融安县乡镇片区农村垃圾处理设施建设项目建议书批复的通知

融安县住房和城乡建设局：

现将柳州市发展和改革委员会《关于融安县乡镇片区农村垃圾处理设施建设项目建议书的批复》（柳发改规划〔2016〕751号）转发给你单位。请严格按照通知要求做好各项工作，抓紧组织好项目实施，确保项目如期建成，发挥效益。

附件：《关于融安县乡镇片区农村垃圾处理设施建设项目建议书的批复》 （柳发改规划〔2016〕751号）

融安县发展和改革局

2017年5月2日

公开方式:主动公开
