# 关于印发融安县餐饮监管权责划分的通知

各所、县局餐饮股：

现将《融安县餐饮监管权责划分》印发给你们，请认真贯彻实行。

2017年6月12日

融安县餐饮监管权责划分

为贯彻落实党的十八届六中全会精神，落实属地原则，强化监管职责，提高监管效能，建立职责清晰、高效运作、上下联动的食品监管工作机制，结合我县工作实际，现就县、乡餐饮监管权责划分作如下规范：

一、基本原则

（一）属地管理，分级负责。落实餐饮安全监管地方政府负总责，强化监管责任，形成“属地为主，条块结合”的餐饮安全防控体系，加强食品监督管理，并结合风险程度等因素，实行分级分类管理。

(二）理顺关系，分工协作。按照决策权、执行权、监督权既相互制约又相互协调的要求，理顺股、所之间的权责关系，明确各自职责，着力解决上下职责不清，工作衔接不紧的问题，实现全程无缝监管。

二、管理内容、属地管理

(一)管理内容：全县餐饮服务单位。

(二)属地管理：全县除了长安镇分为长安和城东2个片区外，每个乡镇均为一个片区，共13个片区。

1.餐饮股：管辖县城内的10所学校及县域12家大型饭店(名单附后)；

2.城东片：管辖长安镇以融江河为界的东面县城、村屯所有餐饮单位（餐饮股管辖的餐饮服务单位除外）；

3.长安片：管辖长安镇以融江河为界的西面县城、村屯所有餐饮单位（餐饮股管辖的餐饮服务单位除外）；

4.大坡片：管辖大坡乡所有餐饮服务单位；

5.大将片：管辖大将镇所有餐饮服务单位；

6.板榄片：管辖板榄镇所有餐饮服务单位；

7.雅瑶片：管辖雅瑶乡所有餐饮服务单位；

8.浮石片：管辖浮石镇所有餐饮服务单位；

9.东起片：管辖东起乡所有餐饮服务单位；

10.大良片：管辖大良镇所有餐饮服务单位；

11.潭头片：管辖潭头乡所有餐饮服务单位；

12.泗顶片：管辖泗顶镇所有餐饮服务单位；

13.沙子片：管辖沙子乡所有餐饮服务单位；

14.桥板片：管辖桥板乡所有餐饮服务单位。

三、日常监督检查权责划分

(一)餐饮股：除负责管辖的10所学校食堂及12家大型饭店外，按照上级管理部门的工作要求，结合我县实际，对全县重点监管对象开展日常监督检查；分解并下达指标任务，统计相关信息上报；监督检查及指导各乡镇所餐饮日常监督工作开展情况。

（二）乡镇所：负责本乡镇辖区餐饮日常监管、专项整治、行政执法、宣传引导、隐患排查、督促监管对象整改落实工作、办理食品违法案件等职责；做好乡镇重大活动食品安全保障工作；协助局餐饮股做好监管工作。

四、权责划分的工作要求

（一）提高认识，加强领导。明确餐饮监管权责划分，提高行政服务效能。各乡镇所要从全局的高度，充分认识这项工作的重要性和必要性，增强政治意识、大局意识和责任意识，切实加强领导，周密部署，精心组织，积极推进，确保辖区内食品药品监管职责落实到位。

（二）密切配合，抓好落实。加强沟通，密切配合，因地制宜，积极探索有利于强化食品药品安全监管的工作机制。抓紧研究制定各项配套制度，对已经明确的权责，要进行量化、细化，明确分工，责任到人，确保工作顺利推进，取得实效。

附：餐饮股监管的服务单位

十所学校：融安县高级中学、融安县第二中学、融安县初级中学、融安县实验中学、融安县实验小学、融安县实验幼儿园、融安县第二实验小学、融安县第三实验小学、、融安县职业技术学校、融安县特殊教育学校。

十二家大型饭店：融安县五福缘饭店、融安县大广饭店、融安县金冠酒家、融安县大三元酒家、融安国际大酒店、融安县红楼大酒店、融安县幸福酒楼、融安县酒泉新都大酒店、融安县林工商公司林苑大酒店、融安县河东建新酒楼、融安县建新大酒店、融安县东园饭店。
