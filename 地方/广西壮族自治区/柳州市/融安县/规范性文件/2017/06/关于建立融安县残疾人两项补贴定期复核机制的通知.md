# 关于建立融安县残疾人两项补贴定期复核机制的通知

各乡（镇）民政办、残联：

根据《广西壮族自治区困难残疾人生活补贴和重度残疾人护理补贴实施办法》（桂政办发〔2015〕120号）和《关于建立残疾人两项补贴定期复合机制的通知》（柳民发〔2017〕22号）精神，为做好我县困难残疾人生活补贴和重度残疾人护理补贴（以下简称残疾人两项补贴）定期复核工作，实现应补尽补、应退尽退的动态管理。现结合我县实际，建立定期复核机制如下：

一、高度重视，确保落实

残疾人两项补贴制度是贯彻落实党中央、国务院决策部署，加强民生保障工作，推动小康社会全面建成的重要举措。2017年残疾人两项补贴工作已纳入自治区人民政府为民办实事项目，并列入绩效考评重要内容。为此，要高度重视残疾人两项补贴工作，深入基层调查，加强宣传，使符合条件的残疾人都能享受到国家的补贴政策，并将其纳入年度重要绩效考评项目。

二、定期复核的内容和方式方法

（一）定期复核的时间：每年开展一次定期复核工作。

（二）人工比对内容及方式方法：一是各乡镇民政办内部要开展享受最低生活保障残疾人、特困供养残疾人、纳入孤儿保障残疾人、因公致残人员、享受福利性生活补贴（津贴）、护理补贴（津贴）的老年人等五项信息比对；二是乡镇民政办、残联经办人员及村（居）委会要加强信息互通，与县残联开展残疾人户籍变化、残疾等级变化和残疾人死亡三项信息比对；三是县民政局与人社局、组织部开展领取工伤保险生活护理费人员、领取福利性生活补贴（津贴）、护理补贴（津贴）的离休人员相关信息比对。以上三项比对内容的人员信息各有关部门应在开展复核工作前10个工作日内将相关人员名单提供给残疾人两项补贴经办人员。

（三）残疾人两项补贴经办人员应在10个工作日内完成比对工作，并将不再符合资格条件的残疾人的相关信息（不符合资格条件的具体原因）收集整理（最好制表统计），同时提出相关意见（制作填写残疾人退出两项补贴意见表）送县民政局审定，并将有关意见于10个工作日内书面通知残疾人。

（四）为切实维护残疾人合法权益，县民政局会同残联适时了解困难残疾人生活补贴和重度残疾人护理补贴资金发放与使用情况，各乡镇要建立困难残疾人生活补贴和重度残疾人护理补贴发放公示制度，每季度在各村公示一次，接受社会监督。

三、不定期复核的内容和方式

各乡镇工作人员要加强平时走访困难群众工作，向村了解困难对象的生产生活状况，并及时将了解到的残疾人两项补贴对象资格条件变化情况，每个季度必须通过书面形式反馈给县民政局一次，县民政局收到意见反馈后在5个工作日内组成联合工作调查组会同乡镇派出2名以上工作人员进行调查核实，并将调查核实情况反馈上级领导审定。

四、处理复核申请

被认定不符合资格条件的申请人，或被停发困难残疾人生活补贴和重度残疾人护理补贴的补贴对象，可在收到县民政局的书面告知之日起15个工作日内提出一次复核申请。县民政局应自受理复核申请之日起15个工作日内将复核意见送达申请人。经复核，符合申请人资格条件的，应按规定发放补贴，对已停发的补贴应予以补发。

五、接受群众信访举报及处理方式

县民政局、残联在收到群众信访举报后，应在5个工作日内组成联合工作调查组会同乡镇派出2名以上工作人员对举报内容进行调查核实。调查人员应在10个工作日内向县民政局提交调查报告，县民政局在收到调查报告5日内作出审定意见并书面通知残疾人。
