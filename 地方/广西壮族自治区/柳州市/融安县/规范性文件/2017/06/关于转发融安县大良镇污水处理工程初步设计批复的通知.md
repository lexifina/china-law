# 关于转发融安县大良镇污水处理工程初步设计批复的通知

融安县住房和城乡建设局：

现将柳州市发展和改革委员会《关于融安县大良镇污水处理工程初步设计的批复》（柳发改规划〔2017〕271号）转发给你单位。请严格按照通知要求做好各项工作，抓紧组织好项目实施，确保项目如期建成，发挥效益。
