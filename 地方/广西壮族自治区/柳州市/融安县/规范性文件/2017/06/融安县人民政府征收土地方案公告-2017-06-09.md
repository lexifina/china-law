# 融安县人民政府征收土地方案公告

根据《中华人民共和国土地管理法》第46条、《中华人民共和国土地管理法实施条例》第25条和自治区土地管理法实施办法的有关规定，自治区人民政府于2017年5月11日批准我县征收集体土地0.1901公顷。现将经自治区人民政府批准的《征收土地方案》内容和有关事项公告如下：

一、建设用地项目名称

融安县2016年第一批次乡镇建设用地。

二、征收集体土地位置及四至

融安县沙子乡沙子村民委员会（具体位置以县国土资源局的勘测定界图为准）。

三、被征地村（组）及面积

征收土地总面积0.1901公顷（2.8515亩），地类为旱地、其他林地、田坎、农村宅基地，用地涉及融安县沙子乡沙子村民委员会。

四、土地补偿费和安置补助费标准

五、该项目用地被征收土地不涉及农业人员安置。

六、在公告之日起十五日内，被征收土地四至范围内的土地所有权人、使用权人持土地权属证书或其它有关证明材料，到县国土资源局办公室办理征地补偿登记，请相互转告。

七、从本公告之日起，抢建、抢种的地上附着物不予办理补偿登记。

八、土地所有权人、使用权人在规定期限内不办理征地补偿登记将视为放弃其应有的权益。
