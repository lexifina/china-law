# 关于印发《土地权属纠纷调处工作实施方案》的通知

融国土资字〔2017〕19号

局机关各股室、二层单位：

经研究决定，现将《国土资源局土地权属纠纷调处工作实施方案》印发给你们，请认真遵照执行。

2017年7月7日

融安县国土资源局土地权属纠纷调处工作实施方案

为了全县经济发展和社会和谐稳定的需要，根据《融安县土地山林水利纠纷调解处理工作实施方案》的相关规定，结合我局实际，制定加强调处工作的方案如下：

一、加强领导，建立健全调处机构。

（一）由局长负总责，由一名副局长负责领导、安排、指挥、协调权属纠纷调处工作，成员为各股室、二层单位负责人。

（二）由政策法规与信访股负责土地权属纠纷的调处工作，涉及有关部门要积极配合。

（三）安排专职调处工作人员1名，常驻县调处中心专职办案。另两名政策法规与信访股工作人员根据工作需要可随时协助办案。

二、继续深入乡镇村进行对《条例》及有关法律、法规的广泛宣传，进一步提高广大干部群众的法律意识，减少土地权属纠纷的发生。

三、始终坚持“以事实为根据，以法律为准绳”的办案原则，加强土地权属纠纷的调处力度，按法定期限完成当年立案的土地权属纠纷案件，确保2017年新发案件结案率达到90%以上，在案件调处过程中，尽量以协议结案为主，切实做到“案结事了”。

四、严把案件质量关。

（一）要求调处人员对每一起案件都要认真地进行实地勘查，深入细致的调查取证，对有关证据进行分析研究，并提出处理意见。

（二）对土地权属纠纷案件由经办人提出处理意见，再由政策法规与信访股审核，提交局会审会进行讨论决定。

五、认真排查，责任到人。

2017年，对全县的土地权属纠纷进行了逐一排查，并将案件进行逐一分析，落实责任到人。注意把握个案性质，对案件按“轻、重、缓、急”进行分类，及时组织人员调处。

六、加强调处制度建设

完善调处土地纠纷案件的流程、程序公开、上墙，调处案件档案做到齐全、完备、一案一档并按时归档。对每起案件都进行分析研究，做好案件讨论记录。做好调处案件的统计工作，按季度上报。

公开方式：主动公开
