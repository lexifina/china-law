# 关于印发融安县2017年“两会”特种设备安全专项检查工作方案的通知

各所、局机关各股、室、大队、稽查局：

现将《融安县2017年“两会”特种设备安全专项检查工作方案》印发给你们，请认真贯彻执行。

2017年8月16日

融安县2017年“两会”

特种设备安全专项检查工作方案

第14届中国—东盟博览会、中国—东盟商务与投资峰会 (以下简称“两会”)将于9月12日至15日在南宁市举行。为确保2017年“两会”期间全市特种设备安全形势稳定，结合当前我县实际，制定本方案。

一、指导思想和工作目标

在县委县政府的领导下，根据市质监局及县安委办的部署安排，坚持“安全第一、预防为主、综合治理”的方针，严格特种设备安全责任制，全面落实企业主体责任、地方属地管理责任，开展特种设备安全检查，有效防范和坚决遏制特种设备重特大事故发生，为“两会”顺利举行创造稳定的安全生产环境。

二、工作机构

为做好 “两会”期间特种设备安全工作，决定成立“两会”特种设备安全工作领导小组，在县委、县政府及市质监局的领导下开展工作。

组　长：李燕回 县市场监督管理局局长

副组长：覃荣星 县市场监督管理局副局长

成员由各所、局机关各股、室、大队、稽查局及中心主要负责人，县局特种设备安全监察股股长担任。

“两会”特种设备安全工作领导小组主要职责：制定全县“两会”特种设备安全专项检查工作方案，指导、督促和协调各部门开展“两会”特种设备安全专项检查工作，督促各部门按本方案要求上报特种设备安全专项检查工作情况和总结。

领导小组下设办公室，承担“两会”特种设备安全工作领导小组日常工作。办公室主任由县局特种设备安全监察股股长兼任，成员由局机关各股、室、大队、稽查局及中心主要负责人担任。办公室设在县局特种设备安全监察股。

三、专项检查时间

从即日起至9月中旬“两会”结束。

四、专项检查内容

（一）使用单位安全管理制度建立和执行情况。

主要包括特种设备安全管理机构设立和管理人员落实情况；安全责任制建立、执行情况和企业安全主体责任落实情况；安全教育培训、操作规程等制度建立和执行情况；特种设备档案、作业人员档案的建立和管理情况；建立事故报告、处理、责任追究制度和执行情况；特种设备隐患治理、监控情况；特种设备事故应急救援工作情况。

（二）特种设备安全状况。

主要包括使用的特种设备是否经过制造监督检验和安装（改造、重大修理）监督检验合格；特种设备的使用是否按行政许可要求进行使用登记；是否按技术规范要求进行定期检验合格并在有效期内；特种设备的操作人员是否经过安全教育培训，是否按规定持有有效的《特种设备作业人员证》；特种设备的安全附件和安全保护装置是否按规定进行校验（检定），是否能有效工作；特种设备的运行是否按要求有真实的运行记录，是否在规定范围内运行；特种设备是否经过正常的维护保养，是否有日常维护保养记录，对维护保养中发现的问题是否得到及时、合理的处置；生产使用单位是否制定具有针对性的应急预案，是否具备应急救援能力，是否按预案要求进行演练，应急救援装备和急救物品的配备、存放、检查维护是否符合要求；电梯使用单位是否制定电梯管理办法和三角钥匙管理制度等，是否及时张贴使用标志。

五、工作要求

（一）加强组织领导。要进一步提高对“两会”期间特种设备安全工作极端重要性的认识，切实加强组织领导，强化红线意识和忧患意识，按照“党政同责、一岗双责、齐抓共管、失职追责”的要求，全面落实特种设备安全责任和管理措施，确保“两会”期间安全稳定。要成立由主要领导任组长的工作领导小组，结合实际情况，制定特种设备安全工作实施方案，精心组织实施。党政一把手必须亲力亲为、亲自动手抓，召开专门会议，专题研究部署“两会”期间特种设备安全工作。

（二）加强舆论宣传。要充分利用广播、电视、网络、报纸等各种媒体，广泛宣传特种设备安全知识。要充分发挥舆论监督和群众监督的作用，及时纠正特种设备安全生产违法违规问题，全力营造人人关心“两会”安全生产的良好氛围。

（三）突出重点，狠抓落实。要突出重点，确定加强监管的重点场所、重点企业、重点设备。加强检查，发现隐患要督促企业做出书面整改计划、限期整改到位并按时复查，对严重危及安全或企业拒绝整改的，依法依规进行处理，必要时报当地政府协调处理。

（四）沟通协调，形成合力。要主动与政府各部门联系，积极参与政府各部门组织的活动，加强沟通协调，切实负起责任，精心组织，周密安排，密切配合，形成工作合力。

（五）加强应急值守工作。要严格执行领导干部到岗带班制度、24小时安全值班制度和事故报告制度，确保特种设备安全信息及时、准确、畅通。要做好值班信息的报送工作，及时掌握情况、沟通信息，遇有紧急重大情况按规定及时如实上报，

（六）加强工作总结报告。于9月15日前，特设股及时将“两会”特种设备安全工作汇总并上报市质监局及县安监局。
