# 关于对融安县涉改公务用车上缴加油卡相关事宜的通知

融公办字〔2017〕4号

各公务用车涉改单位：

为不折不扣落实自治区巡视组巡视反馈意见及贯彻落实中央八项规定精神，根据公务用车改革管理办法相关规定，切实规范我县公务用车使用及管理，防止公务用车使用管理违规现象的发生。我县将对全县范围内公务用车管理使用情况开展清查活动，请各涉改单位认真做好如下工作：

一、认真落实公务用车加油卡管理规定，公车管理坚持做到“一车一卡”，涉改车辆做到“卡随车走”。各单位要对参与公车改革车辆原使用的加油卡上缴情况进行重点检查，认真核对本单位的车辆加油卡情况，车辆已经参与车改不再保留在本单位的，一律不得保留原车辆的加油卡。

二、认真抓好涉改车辆原公车加油卡统一上缴工作。涉改车辆原公车加油卡及余额统一上缴县公车办（公车办设在县发改局）。请各有关单位如实填写《融安县参改车辆加油卡情况表》（见附件），经主要领导签字同意后，将附件表格纸质版、加油卡及现金于2017年9月30日上午下班前上缴县公车办。

请各涉改单位高度重视，认真对待涉改公务公车加油卡上缴工作，各涉改单位要高度重视此项工作，把整治公车管理使用存在问题作为遏制隐形腐败的一个重要抓手，作为落实自治区巡视精神及自治区贯彻落实中央八项规定精神“回头看”交叉检查发现问题整改工作和扎实推进“作风建设年”的重要举措，切实增强政治意识和大局意识，单位主要领导要亲自抓负总责，杜绝数据瞒报、漏报。县公车改革领导小组将组织对各有关单位涉改车辆加油卡上缴情况进行检查核查，对数据材料及油卡报送出现严重拖延的、上报情况余实际不吻合存在瞒报漏报的，或将单位公务加油卡用于私车加油或套现等情况的，县公车办将如实向县纪委汇报，予以严肃问责。

未尽事宜，请联系县公车办，联系电话：8151876。
