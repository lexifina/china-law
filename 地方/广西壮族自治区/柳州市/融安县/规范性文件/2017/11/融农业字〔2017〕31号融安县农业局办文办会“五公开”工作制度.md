# 融农业字〔2017〕31号融安县农业局办文办会“五公开”工作制度

各乡（镇）农业技术推广站，水产畜牧兽医站，局直各单位：

根据上级文件精神要求，进一步推进行政决策、执行、管理、服务、结果（以下简称“五公开”），全面推进新形势下政务公开，保障人民群众知情权、参与权、表达权、监督权，我局为着力推进“五公开”落实到办文、办会工作中而制定本制度。

一、需要公开的文件

拟制的各类政务类规范性文件。

二、公开形式

自治区政府信息公开统一平台、融安县政府门户网站等。

三、公开流程

（一）公文文稿草拟。承办站、股拟制政务类公文时，按公文编辑格式编辑文稿（包括页面设置、字体、段落等），应在发文稿纸及文稿中固定设置公开属性源头认定环节，即明确主动公开、依申请公开、不公开三类政府信息公开属性，随公文一并报批。拟依申请公开和不公开的，要依法依规说明理由。

（二）分管领导审批。公文文稿(政策文件、解读方案)经局法规股规范性审核后，由承办站、股报分管领导审批。

（三）办公室审核。办公室对公文文稿(政策文件、解读方案)进行审核及校对。

审核重点:

1. 是否标明了主动公开、依申请公开、不公开的其中一项，并随公文一并报送;如公文按依申请公开或不公开的，查阅是否附有法定的说明理由。如不符合这两条的，按退文处理。

2. 是否填报了保密审查选项。

3. 审核公开属性，必须坚持“以公开为常态、不公开为例外”原则，结合工作实际，参照上报稿标注的公开属性，审核标注文稿的公开属性，确保做到应公开尽公开。

4. 出台有关政策的是否有政策解读方案，如没有的，按退文处理。对政策性文件文稿、解读方案明确提出处理意见，坚持政策性文件与解读方案同步组织、同步审签、同步部署。

（四）主要领导审批。公文文稿(政策文件、解读方案)由局办公室报主要领导审批。

（五）文件印发。承办站、股将公文文稿(政策文件、解读方案)电子版发办公室编制印发。

（六）公开。正式文件印发后，属主动公开的，由办公室在自治区政府信息公开统一平台或融安县人民政府门户网站公开。

二、办会程序“五公开”

（一）需要公开的会议。以本单位名义召开的涉及公众利益、需要社会广泛知晓的会议、电视电话会议。

（二）公开形式。会议公开的形式有网站、微信、微博等新媒体以直播、录播或稿件形式公开推送。

（三）公开流程

1、拟写召开会议的通知、方案等文件。

2、在文件报批的同时标明会议公开属性、公开形式等，并在公开形式中列举标注网站、微信、微博等公开方式。
