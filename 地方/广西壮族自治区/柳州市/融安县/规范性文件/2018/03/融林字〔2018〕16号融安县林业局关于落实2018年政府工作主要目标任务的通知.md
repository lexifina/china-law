# 融林字〔2018〕16号融安县林业局关于落实2018年政府工作主要目标任务的通知

融林字〔2018〕16号

融安县林业局关于落实

2018年政府工作主要目标任务的通知

各乡（镇）林业站，局属各单位：

为认真落实县委第十七届人民代表大会第三次会议通过的《政府工作报告》提出的各项目标任务，按照《融安县人民政府关于2018年政府工作主要目标任务分解的通知》（融政发﹝2018﹞5号）精神，为推进各项工作的高效开展，现通知要求如下：

一、各有关单位要根据分解的2018年工作任务，结合实际，落实专人负责，确保各项工作任务按质按量如期完成。

二、各责任单位主要领导对落实和完成所承担的任务事项负总责，明确相关人员具体抓落实，各有关单位要积极主动与相关单位沟通联系，通力合作，共同做好工作。

三、各责任单位负责抓落实，实行定期材料汇报制度并根据工作需要不定期汇报。每季度对工作进展情况进行小结，分析工作中出现的新问题、新情况，提出解决办法和措施；在年中（6月中旬）作一次书面总结汇报，年末（12月中旬）将全年工作完成情况进行总结（包含工作进展情况、主要做法、存在问题和困难、来年工作计划等内容）。

四、政府工作主要目标任务完成情况纳入年终绩效考核。

2018年3月23日

公开方式：主动公开

融安县林业局办公室 　 2018年3月23日印发
