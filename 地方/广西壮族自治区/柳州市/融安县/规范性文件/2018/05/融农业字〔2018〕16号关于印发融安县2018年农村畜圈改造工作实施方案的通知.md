# 融农业字〔2018〕16号关于印发融安县2018年农村畜圈改造工作实施方案的通知

关于印发融安县2018年农村畜圈改造

工作实施方案的通知

各乡（镇）人民政府：

根据柳州市水产畜牧兽医局文件《关于转发自治区农业厅关于印发农村畜圈改造工作指导意见的通知》（柳渔牧发〔2018〕19号）精神，为了贯彻落实自治区和柳州市相关文件要求，根据我县实际情况，制定本实施方案。现印发给你们，请结合实际，认真组织实施。

融安县农业局

2018年5月10日

融安县2018年农村畜圈改造工作实施方案

根据柳州市水产畜牧兽医局文件《关于转发自治区农业厅关于印发农村畜圈改造工作指导意见的通知》（柳渔牧发〔2018〕19号）精神，为了贯彻落实自治区和柳州市相关文件要求，根据我县实际情况，制定本实施方案。

一、高度重视，目标明确

“改圈”是“美丽广西·宜居乡村”活动中“基础便民”专项活动的重要内容，是2018年自治区政府工作报告内容之一，并纳入设区市绩效考核体系。我县应将“改圈”工作作为重点工

作狠抓落实。2017年我局制定印发了《融安县2017年农村畜圈改造工作实施方案》的通知（融渔牧函〔2017〕17号），2017年在全县上下的共同努力下，“改圈”工作取得了阶段性成效。截至去年底，全县落实改圈农户数48户，完成任务总数的50.5%。根据自治区下达的任务，2018年我县改圈任务是47户。各乡镇要进行摸底调查，确定改圈农户名单和改圈模式，根据“美丽乡村”工作进度安排，我县改圈工作必须在2018年9月30日前底完成改造验收。

二、因地制宜，推进示范点建设

改圈工作要因地制宜、有所针对，结合当地农户生活习惯、养殖状况、自然条件，区别对待。可采取建设养殖小区、建设独立畜圈、原址改造、退养农户处理、统计错误对象处理等多种方式改造。有改圈任务的乡（镇）要通过建立改圈示范点，充分发挥示范点的示范作用，辐射带动周边农户进行畜圈改造。

三、主要任务

（一）开展改造农村圈舍调查摸底工作。

（二）推进农村畜圈改造建设工作，加强对农村畜圈改造具体实施的指导、监管和督促。

（三）做好改造农村畜圈验收工作促进改造工作顺利推进和确保任务全面完成。

四、具体工作措施

（一）乡镇政府和村两委组成的工作组，开展入村、入户调查，摸清改圈农户具体情况，并登记造册，为有针对性开展改造农村圈舍打下良好基础。针对调查摸底情况，与农户共同协商，根据当地土地实际和农户意愿，提出改造圈舍的具体建设改造方案，确定需要改造圈舍面积、需要建设完善储粪房、储液池或沼气池等配套设施情况，将调查摸底情况登记造册，作为指导改造圈舍和改造完成验收依据。

（二）改造农村畜圈要因地制宜、有所针对，结合当地农户长期畜禽养殖状况、自然条件和群众客观要求，做到区别对待、分类指导，不搞“一刀切”。具备集中养殖的，实行集中建圈、小区养殖；不具备条件的，实施单户改造，分户养殖。

（三）新建设的畜禽圈舍要与人居房屋保持一定的距离，四周墙面坚固保暖、通风透气，房顶防雨结实、地面硬化防渗漏，配套设施位置规划合理实用，栏舍建设的面积针对不同畜禽合理配套。

（四）对改造完成的农村畜圈，乡镇上报到县水产畜牧兽医局，由县水产畜牧兽医局组织各有关部门、乡镇和村委会人员组成验收工作组，进行项目建设完工验收，改造完一户，验收一户，补助资金拨付一户，验收组人员不少于3人。核验按照前期改造圈舍的具体建设改造方案进行验收，验收工作要到户、到点，通过验收出具验收意见并签字确认，验收不通过要出具限期整改意见。

五、工作进度安排

（一）2018年5月20日之前登记造册，明确各乡镇畜圈改造任务。要求各乡镇对符合要求并有意向改造圈舍的农户造册登记和备案，并上报到县畜牧水产兽医局。

（二）2018年5月21日—2018年 8月31日“圈舍”选址、建设阶段。“圈舍”选址、建设，工程全面实施，并在实施过程中做好监督、指导、整改、汇报工作，确保工程进展顺利。

（三）2018年9月 工程验收阶段。组织相关部门对全县“改圈”工程进行全面验收，工程材料收集、整理、归档和发放工程补助资金。

六、工作要求

（一）加强组织领导。局主要领导负总责，分管领导具体抓，由县畜牧管理站具体负责技术解释。畜圈具体改造工作由乡镇技术人员具体负责建设过程中的技术指导。

（二）改造对象、改造技术要求请参照自治区农业厅《关于印发农村畜圈改造工作指导意见的通知》（桂农业发[2018]32号）文件精神执行。

（三）做好技术指导。各乡（镇）和村屯必须落实专人负责畜圈改造建设项目监管，做好项目施工安全和质量监督。

（四）按时上报进度。实行畜圈改造项目进度月报告制度，各乡（镇）于每月20日前上报工作进度，县畜牧管理站负责收集汇总上报县政府主管部门。各乡（镇）在实施畜圈改造项目中注意收集项目改造前后照片、户主身份证复印件、户主农村信用社存折（卡）复印件等证明材料，以便上级核查。联系电话：8150707。

七、做好备案验收，严格资金发放

各乡镇要摸清任务农户情况，做到“一户一策”，做好改造工作的进度跟踪和备案，按照原《广西壮族自治区水产畜牧兽医局办公室关于改圈工程工作进度的补充通知》要求，在每月20日前将《2018年农村畜圈改造工作情况统计表》（将作为绩效考核评分依据，见附件2）报送到县畜牧管理站，收集开工、完工等的佐证材料，严把验收关，落实奖补资金发放工作。

八、加强宣传服务，及时督导进度

各乡镇要加大宣传和发动力度，做到多渠道多方式宣传，发挥能动性，做好农民群众思想工作，使农民群众从“让我改”逐渐转变到“我要改”，积极主动参与改圈工作。强化指导和服务，健全技术指导服务队伍，注重培养村中带头人和技术能人，做到指导服务精准到位，不留死角，县局将适时开展督导工作。
