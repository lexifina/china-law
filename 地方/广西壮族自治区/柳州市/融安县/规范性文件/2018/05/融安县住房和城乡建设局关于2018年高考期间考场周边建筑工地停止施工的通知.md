# 融安县住房和城乡建设局关于2018年高考期间考场周边建筑工地停止施工的通知

各有关建设、施工、监理单位：

2018年全国高考、中考统一考试即将举行，为进一步加强中、高考期间我县建筑工地噪声污染控制管理工作，营造良好的考试环境，给广大考生创造一个安静的学习、休息和考试环境，现将有关事项和要求通知如下：

一、施工企业要严格执行《广西壮族自治区建筑施工现场文明卫生基本要求》等规定，施工现场应在规定时间：

（7:00-12:00，14:00-22:00）内施工，噪声不得超过85分贝。因特殊工序需连续施工的，应当向有关行政管理部门提出申请，并告示周边居民。

二、6月1日至6月27日为建筑工程中、高考期间的噪声禁止期，各施工单位及施工项目部要提前合理安排作业施工，避免在此期间进行连续作业或连续夜间施工，严禁产生环境噪声污染的建筑工程施工作业。各施工单位在高考期间（6月1日至8日）和中考期间（6月24日至27日），我县城区考场周边在建工地一律停止施工，其余不在学校周边的施工现场，夜间施工不得超过22:00，请各有关单位及工地(详见附件)予以支持和配合。

三、各建设、监理单位要按照施工现场安全文明有关规定，督促和配合施工单位加强中、高考期间环境整治，严禁向施工企业提出有关违反中、高考期间建筑工地噪声污染控制管理工作要求。

四、各企业和工程项目部，要指派专人具体负责中、高考期间的施工噪声管理工作，以“安全生产月”活动为载体，加强这一时期的自查，及时处理有关施工噪声方面的举报和投诉，树立良好的文明施工形象。县质安站在中、高考期间将增加检查频次，对违反规定的施工、监理等责任单位和责任人依法严肃查处，并将不良行为录入其信用记录，确保“两考”的顺利进行。

五、考试期间，县质安站将对考场周边建筑工地的停工情况进行全天监督，一经发现有未停止施工的工地，要对相关企业进行严肃处理。
