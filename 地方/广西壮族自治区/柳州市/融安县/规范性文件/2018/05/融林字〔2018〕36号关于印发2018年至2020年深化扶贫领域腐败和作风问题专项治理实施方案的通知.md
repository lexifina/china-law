# 融林字〔2018〕36号关于印发2018年至2020年深化扶贫领域腐败和作风问题专项治理实施方案的通知

融林字〔2018〕36号

关于印发2018年至2020年深化扶贫领域

腐败和作风问题专项治理

实施方案的通知

各乡（镇）林业站，西山林场，局属各单位：

经局党组研究，现将《融安县林业局关于深化扶贫领域腐败和作风问题专项治理实施方案》印发给你们，请结合实际，认真贯彻落实。

2018年4月8日

融安县林业局关于深化扶贫领域

腐败和作风问题专项治理实施方案

为全面贯彻落实党的十九大精神和习近平总书记关于打赢脱贫攻坚战以及开展扶贫领域腐败和作风问题专项治理的系列重要讲话和指示批示精神，根据《广西壮族自治区林业厅办公室印发开展扶贫领域作风问题专项治理实施方案的通知》（桂林办字〔2018〕5号）、《柳州市林业局〈关于印发2018年至2020年深化扶贫领域腐败和作风问题专项治理实施方案的通知〉》（柳林通字〔2018〕30号）和《中共融安县纪律检查委员会关于印发〈2018年至2020年全县深化扶贫领域腐败和作风问题专项治理实施方案〉的通知》（融纪发〔2018〕6号）要求，结合工作实际，现就全县林业系统2018年至2020年深化扶贫领域腐败和作风问题专项治理（以下简称“专项治理”），制定如下实施方案。

一、目标任务

全面贯彻党的十九大精神，以习近平新时代中国特色社会主义思想为指导，坚决贯彻落实中央、自治区、市委和县委脱贫攻坚决策部署，坚持精准扶贫精准脱贫基本方略，坚持目标导向，强化责任担当，强化问题意识，利用三年左右的时间，着力解决林业扶贫领域存在的落实主体责任不到位、工作措施不精准、项目资金管理不到位、工作作风不扎实等问题，深化扶贫领域腐败和作风问题治理，查改作风建设薄弱环节，全面系统清除作风问题形成根源，较真碰硬压缩作风问题滋生空间，严惩严治形成对作风问题的强大震慑，标本兼治构建作风建设长效机制，扎实推进林业精准扶贫、精准脱贫工作，全力为我县贫困人口持续增收脱贫提供有力支撑。

二、治理重点

（一）贯彻落实扶贫工作部署不到位的问题。贯彻落实党的十九大精神和党中央、自治区党委、市委和县委关于打赢脱贫攻坚战的重大决策部署态度不坚决、工作不扎实。履责不力、监管不严、推诿扯皮，不作为、慢作为、乱作为，重审批轻管理、重拨款轻监督、重进度轻实效、重管本级轻管下级。制定配套措施、细化落实方案、推进组织实施不及时不到位。林业产业项目选择与当地资源优势和贫困户个体特征结合不紧密，存在项目同质化倾向。新型林业经营主体对贫困户吸纳和带动能力不强，利益联结机制不规范、不紧密。产业扶贫典型和模式总结推广不够。

（二）反对扶贫领域腐败不力的问题。对林业扶贫领域贪污侵占、行贿受贿、虚报冒领、截留挪用、挥霍浪费、吃拿卡要、优亲厚友等突出问题查处不力。对林业扶贫项目、资金分配、审批、招投标、验收等环节违规操作、滥用职权、以权谋私、监督不力的问题。

（三）扶贫工作作风不扎实的问题。在脱贫攻坚工作中搞形式主义、官僚主义，表态多调门高，行动少落实差，执行中央、自治区党委、市委和县委决策部署搞变通、打折扣，盲目决策、弄虚作假、数字脱贫等问题。部分项目推进缓慢，资金兑现迟缓，部分森林生态效益补偿基金难兑付，退耕还林补助资金兑现滞后，会计基础工作不规范，项目及档案资料管理不规范，以及对监督检查中发现的线索不处理、不移送、不整改等问题。帮扶单位组织不力、措施不硬、工作不实，帮扶干部作风漂浮、纪律松懈，办事拖拉、推诿扯皮，驻村工作队员不驻村以及不作为、慢作为、乱作为等问题。

（四）扫黑除恶专项斗争推动不力的问题。坚持把扫黑除恶同反腐败、基层“拍蝇”结合起来，同开展扶贫领域腐败和作风问题专项治理结合起来，重点治理林业部门党员干部和其他行使公权力的林业从业人员采取暴力、威胁等手段，把持扶贫资金安排的行为。重点治理林业系统放纵、包庇重点打击的黑恶势力，甚至于黑恶势力上下勾结、收受贿赂、通气说情，以及在扫黑除恶专项斗争中态度消极暧昧，不作为、慢作为、乱作为等问题。

三、工作措施

（一）强化线索排查和处理。畅通线索来源途径，积极与财政、农业、审计等部门加强联系协作，及时发现掌握问题线索；开展本部门本单位资金和项目使用管理数据比对工作，及时排查发现资金和项目使用管理中的问题线索；建立巡察督查制度，及时梳理在每季度监督检查、审计监督、考核评估中发现的线索。每月20日前向派驻纪检组移交问题线索清单和处置台账，对发现的重要问题线索做到第一时间报告、第一时间处理、第一时间移交。

（二）强化问题自查自纠。2018年4-5月份，结合专项治理问题重点，对监管责任落实、扶贫领域腐败和作风问题集中开展一次自查自纠活动。对本部门自查发现的个性问题立即整改，对深层次、普遍性的问题认真研究，建章立制，认真加以解决。同时，根据脱贫攻坚和产业扶贫规划，指导相关单位加强项目论证和实施，按规定落实林业扶贫项目资金公告公示制度，接受群众和社会监督，加快在建项目实施，提高项目建设效益。加大群众身边腐败问题的查处力度，杜绝挤占、挪用涉林扶贫领域资金和侵占群众利益的现象发生。结合巡察督查加强对每一笔资金每一个项目的核查督察，力争每季度开展一次督查核查，核查的资金和项目要达到50%以上。重点扶贫资金项目要实现“全覆盖”。

（三）加强指导和服务。从政策解读、规划制度、资金支持、主体带动、机制构建、技术帮扶、市场营销、品牌打造等方面，指导县内林业企事业单位围绕林业供给侧结构性改革，大力发展现代林业，调整产品品种、品质、品类结构，优选特色产业项目，搞好精准对接，扩大林业产业扶贫覆盖面，切实增强贫困村贫困户的“造血”功能。全面推进党务、政务、村务和各领域办事公开，将扶贫政策、项目、资金等信息以通俗易懂的方式向群众公开，真正让群众看得懂、能判断、能运用，确保脱贫攻坚工作在阳光下运行。

（四）加强结果的运用。年度内，结合巡察督查开展对专项治理工作调研不少于2次，重点查找监督执纪问题存在的漏洞，加强和改进措施。深入挖掘好经验、好做法，树立典型，营造良好工作氛围。深入分析本部门脱贫攻坚工作中责任落实、监督管理、制度执行、问题整改、作风建设等方面的突出问题，进一步强化指导、强化监管、堵塞漏洞。

四、工作步骤

专项治理工作2018年1月开始至2020年底结束，其中2018年为集中查处阶段，重点结合今年作风整治活动，对问题线索进行大起底、大排查、大治理，消除“存量”；2019年为建章立制阶段，重点出台相关制度，堵塞漏洞，建立健全“不能腐”的机制，遏制“增量”；2020年为巩固提升阶段，重点开展专项治理“回头看”活动，巩固和深化成果。

五、工作要求

（一）提高政治站位。脱贫攻坚是全面建成小康社会的标志性指标。从近年通报的扶贫领域典型案件来看，反腐败和作风问题仍然一定程度存在，严重影响脱贫攻坚工作落实，严重侵害贫困群众利益，严重损害党和政府形象。决战脱贫攻坚战，打赢作风攻坚战是关键。各单位要从讲政治、顾大局的高度，充分认识深化扶贫领域腐败和作风问题专项治理的重要意义，结合“乡村振兴战略”实施，结合国家机构改革和职能调整，结合“不忘初心、牢记使命”主题教育，增强“四个意识”，强化责任担当，切实转变作风，自觉从思想上政治上行动上同以习近平同志为核心的党中央保持高度一致。

（二）加强组织领导。为加强对扶贫领域腐败和作风问题专项治理工作的领导，成立融安县林业局深化扶贫领域腐败和作风问题专项治理工作领导小组（见附件1）。坚持把专项治理贯穿林业扶贫全过程，以上率下，带头示范，以强的态度、实的标准、严的纪律抓好自身作风建设。各单位要认真履行职责，主要负责人要亲自研究部署、亲自督导检查，指导本单位林业扶贫领域反腐败和作风建设，解决存在的突出问题，确保专项治理工作有效务实。

（三）坚持立行立改。按照有部署、有措施、有责任、有监督的要求，查找问题、进行整改，特别是对影响林业扶贫政策措施落实的突出问题，对帮扶单位组织不力、措施不硬、工作不实的问题，对基层干部和群众反映强烈的问题，迅速纠正、坚决整改。坚持立行立改与制度建设相结合，对发现的问题，追根溯源，举一反三，完善政策措施，加强制度建设。贯彻从严要求，对林业扶贫领域作风问题专项治理不安排、不督促、不落实或发现问题不整改的，严肃追究责任。

公开方式：主动公开
