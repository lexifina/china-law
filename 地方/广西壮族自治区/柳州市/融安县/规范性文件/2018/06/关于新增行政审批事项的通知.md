# 关于新增行政审批事项的通知

各股（室）、二层单位：

根据《广西壮族自治区人民政府关于取消下放和调整一批行政许可事项的决定》（桂政发〔2018〕29号）精神，涉及我单位依法律法规新增的行政许可事项1项。请局属各股（室）及二层单位做好新增事项的落实工作，不断提高管理科学化、规范化、法治化水平。

附件：依法律法规新增的行政许可事项（共1项）

2018年6月17日

公开选项：主动公开

融安县住房和城乡建设局 2018年6月17日印发
