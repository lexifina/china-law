# 融安县桥板乡对2017年度第120170020900177项社会评价群众意见建议的情况说明

根据自治区2017年度社会评价意见建议及整改工作要求，我单位高度重视，专项研究2017年度自治区绩效考评群众反馈意见建议整改工作，开展调查研究。现将情况说明如下:

桥板乡人民政府收到自治区2017年度社会评价意见关于：“柳州市融安县桥板村贫困户种养补贴还没得，之前说2017年年年底发的，但是现在都2018年初了，别的村7-8月都得发了，只有桥板村没发，希望种养补贴能尽快下发的建议后立即组成专门人员进行调查。

通过调查电话沟通、群众走访等方式调查桥板乡桥板村支书、主任、副主任，贫困户代表韦荣明、黄业像，黄群，张维学，覃小后，何善仁，罗壮等人以及桥板村新寨屯、东安屯、前村屯、里村屯屯长。

通过调查得到结论是“桥板乡政府对于贫困户的产业发展非常重视，大力宣传鼓励他们发展种养产业，并指导他们申请、验收的相关工作，桥板村包村组对于贫困户发展的产业，只要是按上级文件规定种养经营的，都立即验收并上报请款。发展不同产业时间不一样，验收时间跟请款批次不一样，并没有存在只验收不请款，不发放款项的现象。”

下一步工作计划

我乡将加强对产业奖补政策的宣传，并及时进行验收，完善材料上报，做到产业奖补资金的及时请款发放，同时对一些贫困户发展了产业，但在验收时出现不合格的情形时，要耐心做好解释工作。
