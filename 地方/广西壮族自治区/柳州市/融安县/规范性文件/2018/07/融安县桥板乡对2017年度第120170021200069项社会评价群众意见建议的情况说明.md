# 融安县桥板乡对2017年度第120170021200069项社会评价群众意见建议的情况说明

柳州市融安县桥板乡对2017年度第120170021200069项社会评价

群众意见建议的情况说明

根据自治区2017年度社会评价意见建议及整改工作要求，我单位高度重视，专项研究2017年度自治区绩效考评群众反馈意见建议整改工作，开展调查研究。现将120170021200069情况说明如下:

桥板乡人民政府收到自治区2017年度社会评价意见第120170021200069项：柳州市融安县桥板乡江边村的群众家有5-6个人吃饭，只有一个人工作，乡里面的干部说他家什么都有，不是贫困户，希望村里面的领导能认真调查贫困的标准。桥板乡立即组成专门人员进行调查。

一、调查情况

包村组通过走访调查、召开群众代表会议交流讨论，大部分群众非常认可政府开展识别贫困户的工作方法、步骤和结果，政府工作组认真按照入户评估表的项目评估识别贫困户，经过每年的贫困户动态调整，已达到识别精准，工作得到进一步完善。群众非常认可政府对贫困地区的帮扶投入力度，农村基层设施和环境得以很大改善，同时也调动了所有贫困户发展生产的积极性，生活质量得到进一步提高，提前脱掉了贫困的帽子。

二、下一步工作计划

（一）加强宣传，主动引导。贫困户的认定经过了精准识别、层层筛选、逐级把关，充分考虑了诸多因素，得到了群众的认可，但是在现实中仍然有个别群众对政策的认识有误差，需要进一步的引导和帮助，需要进一步的加大宣传力度。

（二）全屯推进，分步实施。立足当前、着眼未来，因屯因人、分类指导，把每屯每户群众对政策的了解度，作为工作的切入点，尽可能把工作做在前面，尽可能降低各类矛盾的发生。

（三）公平公正，清晰透明。严格贫困户的评定、认定的条件和程序，通过精准识别、民主评议、张榜公示等方式，公开评定政策、评定标准、审批程序、审批结果，实现阳光操作，全过程接受群众和社会的监督，从各方面尽力提高群众的满意度。
