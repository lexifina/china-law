# 融安县投资促进局产业大招商工作实施方案

为贯彻落实全区、全市年度工作会议暨县域经济发展、乡村振兴推进大会精神，深入实施广西产业大招商三年行动计划，根据《广西2018年重点产业大招商工作方案》（桂政办电[2018]181号），现结合我局实际，制定实施方案如下：

一、加强组织领导

成立融安县投资促进局产业大招商工作领导小组，负责领导和统筹推荐重点产业大招商工作和招商引资重点工作，组织开展产业大招商工作中的重大事项和重要活动。

（一）领导小组人员分工：

组 长：韦人韬 党组书记、局长

副组长：明恒燕 副局长

卢建铭 副局长

成员：韦丽鲜、莫冰冰、曾意、梁雪

（二）工作职责：

韦人韬党组书记、局长负责统筹领导本局产业大招商工作、指导产业大招商工作领导小组办公室工作。

1.负责统筹传统产业、战略性新兴产业招商引资工作，统筹承接产业转移工作及招商引资重大项目协调推进工作。通过招商引资加快传统产业转型升级激发新动能。收集策划招商引资项目，积极组织开展新能源产业专题招商、大健康产业专题招商等专题招商活动，积极对接拜访行业知名企业。力争引进一批高质量产业项目。

2.负责招商引资重大项目协调推进工作。抓好全县招商引资重点项目协调推进，制定融安县领导联系招商引资重点项目表和重点企业表、项目清单和问题清单。负责亲商安商“三大平台”建设，确保营商环境举报投诉平台、招商引资项目代办服务平台年内建成使用。负责新制造及新材料产业专题招商工作。组织开展专题招商活动，积极对接拜访行业知名企业，力争引进一批高质量产业项目。

产业大招商工作领导小组下设办公室，办公室设在局办公室，办公室主任由莫冰冰同志兼任，负责局产业大招商工作领导小组日常协调、后勤保障和公文办理工作。负责局领导交办事项。

二、 完善工作机制

要将产业大招商工作作为一项长期工作和重要任务，突出重点，强力推进。要抓紧建立完善各项长效机制，确保产业大招商工作取得务实成效。

（一）建立学习机制。工作组要围绕工作职责，制定学习培训及调研计划，加强业务学习培训和调查研究，深入了解掌握相关产业发展规划、产业政策和产业发展规律、招商引资重点工作特点和规律。

（二）建立沟通协调机制。工作组要加强与县投资促进委员会各成员单位的沟通协调，制定精准招商活动方案，推动产业大招商工作深入有序开展。

（三）建立工作考评机制。

完善工作组内部考评，做到年初有计划、年内有活动、年终有总结，全年有考评。将产业大招商工作纳入局机关年度绩效考评，通过严格考评、压实责任，打造专业团队，强化担当作为，推动招商引资各项重点工作顺利开展。
