# 坡政发〔2019〕2号关于印发《大坡乡2019年春节文化活动

各村民委，乡直各相关单位：

经研究，现将《大坡乡2019年春节文化活动实施方案》印发给你们，请认真组织实施。

融安县大坡乡人民政府

2019年1月11日

大坡乡2019年春节文化活动实施方案

2019年春节即将到来，为丰富和活跃春节期间群众文化生活，营造欢乐喜庆、文明祥和、节俭安全的节日氛围，进一步弘扬传统文化，深入贯彻落实党的十九大精神，歌颂全乡政治稳定，社会安定，经济发展的大好形势，让全乡人民度过一个安乐、祥和、文明、喜庆的春节。现就2019年春节文化活动安排如下：

一、指导思想

以党的十九大精神为指导，深入贯彻落实科学发展观，紧紧围绕乡党委、乡政府总体工作部署，充分展现我乡经济社会发展新面貌、新变化，提升文化软实力，激励和鼓舞全乡人民脚踏实地，努力工作，开拓进取，不断满足人民群众日益增长的精神文化需求，积极推进和谐大坡建设。

二、活动安排

（一）活动形式

以九个行政村为主，在乡政府所在地举行。乡春节文化活动由政府牵头，岗伟、同仕、下寨、星上、星下、治安、福上、福下、六局九个行政村参与。

（二）时间安排

2019年2月4日至2月19日进行。

（三）活动要求

春节文化活动要在确保安全的基础上，要贴近群众、形式多样、喜闻乐见营造喜庆氛围。各村要高度重视，精心策划。

（四）活动总体预算

预计：28000元（贰万捌千元）

（五）大坡乡文化活动安排

1、篮球比赛

初定于正月初三至初四进行，大坡街道及各村委、机关单位等篮球队参加。经费开支6000元，设一、二、三等奖各一名，分别奖励1000元、800元、600元；鼓励奖若干名，各奖励300元。

负责人：[姓名略]

工作人员：韦德贤 覃文锋

2、舞狮

初定于正月初一进行。经费开支2000元，主要用于制作狮头、购买炮仗及红包，醒狮从供电公司门口绕大坡街一圈，最后到乡政府门前抢悬空吊在高处的红包。

负责人：[姓名略]

工作人员：覃文锋

3、文艺汇演

初定于2月11日白天进行。经费开支7000元，包括舞台布置、音响设备、工作人员和队员的车油费及餐费在内。演出单位有外请一个演出团队加上大坡乡各村文艺队。

负责人：赵 勇 龚建军

工作人员：韦 超 覃文锋 覃家况 覃 硕 王邦华

4、乒乓球赛

初定于正月初五白天举行。经费开支4000元，以各村为单位组织团体赛，要求每个队上场队员4男1女，奖励前三名，各奖励600元、500元、400元，鼓励奖若干名，各奖励200元。

负责人：[姓名略]

工作人员：龚建军 覃文锋 韦彩甲

5、各村文体活动

定于春节期间举行，经费开支9000元。由各村上报活动方案，每个村活动经费1000元。

三、组织领导

为保证春节文化活动的顺利进行，成立大坡乡春节文化活动领导小组，负责整个活动的组织、指挥和协调工作，组成人员如下：

组 长：莫 洋 乡党委书记

副组长：谭世波 乡党委副书记、乡长

雷稳祺 乡党委副书记、人大主席

成 员：赵 勇 覃元鲜 龚建军 覃文锋 覃家况

覃 硕 王邦华

领导小组下设办公室，办公室设在乡文广站，办公室主任由龚建军同志担任。负责春节期间文化活动的组织协调工作。

四、有关要求

（一）各村和参与单位要高度重视，加强领导，细化责任，密切配合，积极组织参加春节文化活动，强化安全责任意识。

（二）派出所要做好春节文化活动期间的安全保卫工作，交警中队要加强春节期间文化活动的交通疏导工作。

（三）春节文化活动期间，各村要发挥两委会阵地和农家书屋的资源优势，以积极、文明、健康的文化活动占领基层文化阵地，丰富群众春节文化生活。
