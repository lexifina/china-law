# 融林字〔2019〕3号关于下达2019年度林木采伐限额的通知

各乡（镇）人民政府：

自治区林业局已将2019年度森林采伐限额下达我县，经研究，现将采伐限额下达给你们，通知如下：

一、采伐限额优先安排受灾林木、改造种植金桔林木、建档立卡贫困户、特困户、危改户，以及去年已申请采伐未得指标解决的林木。为发展我县香杉、金桔产业，各乡镇政府严格做好审核把关工作。

二、采伐限额只能用于2019年度采伐，不得跨年度使用，乡镇负责组织做好核实工作。

三、各乡镇尽快做好核实和上报林农林木采伐设计工作，于2019年5月30日前按程序上报县林业局审批，逾期不上报的，剩余限额全县统筹调配使用。

2019年1月15日

公开方式：主动公开

融安县林业局办公室 　 2019年1月15日印发
