# 融林字〔2019〕5号关于印发《融安县林业局2019年春节期间烟花爆竹禁限放工作实施方案》的通知

各乡（镇）林业站，局属各单位：

现将《融安县林业局2019年春节期间烟花爆竹禁限放工作实施方案》印发给你们，请认真贯彻落实。

2019年1月18日

融安县林业局2019年春节期间烟花爆竹

禁限放工作实施方案

为切实做好烟花爆竹禁限放工作，根据融安县大气污染防治联席会议办公室《关于做好融安县2019年春节期间烟花爆竹禁限放工作的通知》（融大气办〔2019〕2号）要求，结合我局实际，制定本实施方案。

一、工作目标

在县委、县政府的统一领导下，以深化环保模范城市、文明城市创建为目标，通过广泛、深入、持续的宣传发动，争取广大群众对不燃放烟花爆竹的理解和支持，提高广大群众环保文明意识，自觉不燃放烟花爆竹，逐步形成绿色、环保的生活习惯，促成社会新风尚的形成。

二、工作要求

（一）强化组织领导

成立融安县县林业局烟花爆竹禁限放管理工作领导小组，由局长覃卢成任组长，副局长、局党组成员谢振兴、黄先纲、莫承锋任副组长，各乡（镇）林业站，局属各单位负责人为成员，领导小组下设办公室，具体负责领导小组日常工作，并对禁限放工作开展情况进行督导检查，确保工作实效。

各单位要从建设平安融安的角度出发，站在维护群众生命财产安全，保障社会公共安全的高度，深刻理解烟花爆竹禁限放工作的重要性和必要性，要将禁限放工作作为春节期间重点工作来抓，切实履行职责，迅速动员部署；明确工作任务，明确工作目标，细化工作方案，确保禁限放工作稳步推进。

（二）强化宣传发动

各单位要将宣传教育作为禁限放工作首要任务，开展全方位的宣传教育工作。要开展以“做快乐的弃炮族，绿色环保过春节”为主题的集中宣传活动，提倡“少燃放一组烟花爆竹，多呼吸一口新鲜空气”的环保理念，呼吁群众勤俭节约，少放、不放烟花爆竹。各乡（镇）林业站，县森林公安局要利用LED电子屏幕滚动播出的形式对“做快乐的弃炮族，绿色环保过春节”主题进行宣传，局办公室在县政府门户网站、微信群等网络媒体及印制宣传标语进行宣传。倡导干部职工及家属、周边社区居民少放或不放烟花爆竹，过安静、祥和的春节。

（三）强化责任落实

各乡（镇）林业站，局属各单位负责人是烟花爆竹禁限放工作的第一责任人，要亲自部署，亲自检查，狠抓落实。要将宣传教育等工作任务落实到位。

（四）强化日常管理

根据禁限放工作特点和规律，针对燃放烟花爆竹的习俗，对干部职及家属采取宣传教育的方式，提前告知、积极劝阻。

要切实发挥护林员的作用，突出重点区域、时段、环节的巡查管护，确保早发现、早处置。在重点燃放时段组织专门力量，引导群众安全、有序燃放，对违规燃放行为进行提示、劝阻，并认真履行报告义务。

各单位要就春节期间干旱、大风、空气重污染等极端天气情况做好应急相关准备工作。同时，要认真收集整理开展活动的材料、总结、图片（标注图片说明）、影像等资料，进行规范整理，并于 2019 年3 月4日前以电子邮件的形式报送至局办公室（邮箱：raxlyj@163.com）。

附件1

融安县林业局2019年春节期间不燃放烟花爆竹倡议书

林业系统全体干部职工及广大群众朋友们：

大家好！

“爆竹声声辞旧岁，梅花点点报新春”，燃放烟花爆竹是人民群众表达节日喜庆之情的传统习俗之一，但是春节期间集中大量燃放烟花爆竹严重污染环境，损害人体健康，影响市容市貌，造成大量安全隐患。为此，融安林业局真诚地向广大群众朋友们发出倡议：

一、过一个低碳环保年。春节期间不燃放或少燃放烟花爆竹，采用电子爆竹、鲜花、喜庆音乐等方式庆祝节日，最大限度降低由燃放烟花爆竹造成的环境污染。低碳环保过年，让融安县的天更蓝、空气更清新，环境更优美。

二、过一个安全祥和年。不运输、储存、销售、携带和燃放烟花爆竹；不在明令禁止的安全保护单位和公共场所随意燃放烟花爆竹；在相对允许的区域燃放，也要选择符合质量标准、污染较少的产品，尽量做到不燃放、少燃放。

三、过一个文明健康年。利用微博、微信等方式，向亲朋好友宣传不燃放烟花爆竹的益处，努力把不燃放烟花爆竹变成广大群众朋友的自觉行为，凝聚起保护环境的正能量。做好引导和劝导工作，以自己的积极行动带动和影响身边的人。

我们真诚希望大家告别烟花爆竹，从身边做起，从点滴做起，爱护环境，过一个低碳环保、安全祥和、文明欢乐的猪年春节！着力营造文明、安全、宜居环境，守护融安碧水蓝天，建设生态美丽融安！
