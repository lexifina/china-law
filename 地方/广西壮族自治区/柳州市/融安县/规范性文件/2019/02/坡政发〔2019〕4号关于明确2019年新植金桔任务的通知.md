# 坡政发〔2019〕4号关于明确2019年新植金桔任务的通知

坡政发〔2019〕4号

大坡乡人民政府

关于明确2019年新植金桔任务的通知

各村民委、乡直各单位：

根据《融安县人民政府办公室关于印发,融安县金桔产业发展工作实施方案（2019-2020年）>的通知》（融发〔2018〕142号）文件要求，为全面完成了2019年的我乡金桔生产工作任务，加快金桔产业发展步伐，促进全乡脱贫攻坚工作，实现农业增效、农民增收、农村发展，经研究，结合实际，特制订大坡乡各村2019年金桔生产任务分配方案。希望各村、各单位和全乡干部群众要认真贯彻落实县委、县人民政府和乡党委、政府关于金桔产业发展的决策部署精神，把金桔产业发展列入本单位重点工作来抓，进一步提高服务“三农”意识，认真履行职责，加强沟通、协作，开拓进取、勇于担当，在金桔生产工作中彰显才能，为我乡金桔产业发展做出突出贡献。

为切实增强工作实效，金桔生产工作的考核列入绩效考评工作，并强化对该考核结果的运用，作为任务单位或个人评优、评先的参考依据。
