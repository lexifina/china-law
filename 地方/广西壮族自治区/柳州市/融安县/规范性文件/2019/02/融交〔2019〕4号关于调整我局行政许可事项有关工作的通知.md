# 融交〔2019〕4号关于调整我局行政许可事项有关工作的通知

局属各二层单位、股室：

根据融安县行政审批制度改革工作领导小组办公室《关于落实取消下放和调整一批行政许可等事项的决定》（融审改办发〔2019〕3号）精神，我局对1项行政许可事项的审批层级和部门进行调整，工作要求如下：

一、各二层单位、股室应按照县审改办部署对调整行政许可事项及时调整行政许可事项目录和行政审批标准化目录库，加强工作人员业务培训和检查指导，确保调整到位、监管到位。

二、各二层单位、股室应按照县审改办部署对调整行政许可事项完善权责清单，并将申请调整权责清单报审表报县审改办；完善权责运行流程，将申请调整权力运行流程报审表报县政管办。

附件：调整审批层级和部门及名称和依据的行政许可事项目录

2019年2月18日
