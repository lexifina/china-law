# 融人社发〔2019〕12号关于认定2019年融安县第一批就业扶贫车间的通知

融人社发〔2019〕12号

关于认定2019年融安县

第一批就业扶贫车间的通知

各乡（镇）人民政府，泗顶矿区管理处，县直各有关单位：

为更好地贯彻落实国家、自治区积极就业政策,促进贫困家庭劳动力就近就地转移就业,让贫困家庭早日脱贫致富,根据《广西壮族自治区人民政府关于做好当前和今后一段时期就业创业工作的通知》(桂政发〔2017〕48号)和《柳州市人民政府办公室关于印发的通知》(柳政办发〔2018〕19号)等文件精神,按照企业资源、乡镇推荐的原则，经实地调查核实,将广西融安桔乡里农业有限公司认定为2019年融安县第一批就业扶贫车间。

请就业扶贫车间因地制宜,创新发展模式,搭建更好的就业平台,积极吸纳我县贫困农村劳动力到车间务工，帮助贫困群众实现脱贫致富。各乡（镇）、县各有关单位要积极鼓励和引导有条件的企业到镇、村设立生产车间,加强组织引导贫困家庭劳动力等人员就近就地转移就业,为我县脱贫攻坚工作作出新的贡献。

融安县人力资源和社会保障局 融安县财政局

融安县扶贫开发办公室

2019年2月18日

公开方式：主动公开

融安县人力资源和社会保障局办公室 2019年2月18日印发
