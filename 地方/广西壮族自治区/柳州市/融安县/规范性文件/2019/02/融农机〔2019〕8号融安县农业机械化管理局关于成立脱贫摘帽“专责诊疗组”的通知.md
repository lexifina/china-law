# 融农机〔2019〕8号融安县农业机械化管理局关于成立脱贫摘帽“专责诊疗组”的通知

关于成立脱贫摘帽“专责诊疗组”的通知

各乡（镇）农机站，局直属各二层单位：

2019年是融安县脱贫摘帽攻坚之年。为了深入贯彻落实中央、自治区、柳州市和融安县脱贫摘帽工作精神，做到统筹协调安排、整体统一推进，确保工作顺利完成。经研究决定成立融安县农机局脱贫摘帽“专责诊疗组”，工作组成员名单及职责如下：

一、大将镇设洞村、龙妙村组长：曾宪忠

1.大将镇设洞村小组：卢绍荣、莫经斌、李世安

2.大将镇龙妙村小组：黄继京、黄恒

二、工作职责：

1．安排、指导、督促、检查所负责片区范围内的“一户一册一卡一档”填写、信息核对、制定和实施脱贫计划和帮扶措施、宣传惠农方针政策、开展感恩教育、脱贫摘帽“双认定”等六项帮扶工作。对六项工作及时进行查缺补漏并修改完善，把好本单位帮扶工作的质量关。

2．负责抓好第二帮扶联系人督查检查发现问题的整改落实，确保分片负责贫困户的各项工作顺利达标。

3．对分片负责贫困户“两不愁三保障”及“八有一超”指标达标情况进行全面排查，跟踪了解进展情况，动员和指导贫困户依靠自身努力解决问题，对贫困户自身无法解决或解决进度缓慢的问题，实时向包（驻）村工作组和单位主要领导反馈，并对指标达标情况进行跟踪。

4．根据全县扶贫工作需要，按照联系村包（驻）村工作组的工作安排，完成其他临时性扶贫工作。对照国家和自治区各项检查考核评估要求，配合包（驻）村工作组做好各项迎检工作。

5．参加县、乡、村举办的各类扶贫业务培训班（会），进一步提升业务水平。
