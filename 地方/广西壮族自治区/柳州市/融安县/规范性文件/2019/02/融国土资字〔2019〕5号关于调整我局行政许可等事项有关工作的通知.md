# 融国土资字〔2019〕5号关于调整我局行政许可等事项有关工作的通知

各股室、二层单位：

根据融审改办发〔2019〕3号《关于落实取消下放和调整一批行政许可等事项的决定》文件精神，我局新增1项行政许可事项，对1项中介服务事项进行调整。

各有关股室应按照县审改办部署对新增行政许可事项及时调整行政许可事项目录和行政审批标准化目录库；编制、修订行政许可操作规范及其流程图和办事指南，加强工作人员业务培训和检查指导，确保调整到位、监管到位。

各有关股室应按照县审改办部署对调整行政许可事项完善权责清单，并将申请调整权责清单报审表报县审改办；完善权责运行流程，将申请调整权力运行流程报审表报县政管办。

附件：1.融安县国土资源局清理规范和新增为行政审批必要条件的中介服务事项目录（共1项）

2.调整审批层级和部门及名称和依据的行政许可事项目录（共1项）
