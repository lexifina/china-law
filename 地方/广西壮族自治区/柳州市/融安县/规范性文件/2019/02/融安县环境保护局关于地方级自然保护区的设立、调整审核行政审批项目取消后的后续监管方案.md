# 融安县环境保护局关于地方级自然保护区的设立、调整审核行政审批项目取消后的后续监管方案

为进一步贯彻落实《广西壮族自治区人民政府关于取消下放和调整一批行政许可等事项的决定 》（桂政发（2019）6号）以及《 关于落实取消下放和调整一批行政许可等事项的决定》（融审改办发〔2019〕3号）文件精神，做好地方级自然保护区的设立、调整审核行政审批项目取消后续监管工作，现结合实际，制定该项目取消后的事中事后监管方案：

一、取消行政许可项目基本情况

项目名称： 地方级自然保护区的设立、调整审核（D13021）

取消依据：《广西壮族自治区人民政府关于取消下放和调整一批行政许可等事项的决定

》（桂政发（2019）6号）、《 关于落实取消下放和调整一批行政许可等事项的决定》（融审改办发〔2019〕3号）。

二、监管依据

1.《中华人民共和国自然保护区条例》第二十条 县级以上人民政府环境保护行政主管部门有权对本行政区域内各类自然保护区的管理进行监督检查。

2.《中华人民共和国自然保护区条例》第三十三条 因发生事故或者其他突然性事件，造成或者可能造成自然保护区污染或者破坏的单位和个人，必须立即采取措施处理，及时通报可能受到危害的单位和居民，并向自然保护区管理机构、当地环境保护行政主管部门和自然保护区行政主管部门报告，接受调查处理。

三、监管措施

（一）监督检查对象

融安县行政区域内自然保护区管理机构

（二）监督检查方式

通过现场检查、开展日常环境监督管理等方式进行。

（三）检查内容

在自然保护区范围内是否有环境污染、生态破坏等环境违法行为。

（四）监督检查程序

(1)部分检查下发检查通知，部分检查实行随机抽查；

(2)持有效执法证进行检查，人数不得少于2人；

(3)根据检查情况，视情处理各类情况(需要整改的，依法依规下达整改通知；对需要纳入行政处罚的，依法办理。)；

(4)做好现场检查书面记录，相关材料归档。
