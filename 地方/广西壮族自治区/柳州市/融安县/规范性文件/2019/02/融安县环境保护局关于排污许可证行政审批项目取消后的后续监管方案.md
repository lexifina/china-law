# 融安县环境保护局关于排污许可证行政审批项目取消后的后续监管方案

为进一步贯彻落实《广西壮族自治区人民政府关于取消下放和调整一批行政许可等事项的决定 》（桂政发（2019）6号）以及《 关于落实取消下放和调整一批行政许可等事项的决定》（融审改办发〔2019〕3号）文件精神，做好排污许可证行政审批项目取消后的后续监管工作，现结合实际，制定该项目取消后的事中事后监管方案：

一、取消行政许可项目基本情况

项目名称： 排污许可（D13006）

取消依据：《广西壮族自治区人民政府关于取消下放和调整一批行政许可等事项的决定

》（桂政发（2019）6号）、《 关于落实取消下放和调整一批行政许可等事项的决定》（融审改办发〔2019〕3号）。

二、监管依据

1.《中华人民共和国环境保护法》第十四条 县级以上人民政府环境保护行政主管部门或者其他依照法律规定行使环境监督管理权的部门，有权对管辖范围内的排污单位进行现场检查。被检查的单位应当如实反映情况，提供必要的资料。检查机关应当为被检查的单位保守技术秘密和业务秘密。

2.《中华人民共和国水污染防治法》第三十条 环境保护主管部门和其他依照本法规定行使监督管理权的部门，有权对管辖范围内的排污单位进行现场检查，被检查的单位应当如实反映情况，提供必要的资料。检查机关有义务为被检查的单位保守在检查中获取的商业秘密。

3.《中华人民共和国大气污染防治法》第二十九条　环境保护主管部门及其委托的环境监察机构和其他负有大气环境保护监督管理职责的部门，有权通过现场检查监测、自动监测、遥感监测、远红外摄像等方式，对排放大气污染物的企业事业单位和其他生产经营者进行监督检查。被检查者应当如实反映情况，提供必要的资料。实施检查的部门、机构及其工作人员应当为被检查者保守商业秘密。

三、监管措施

（一）监督检查对象

融安县纳入排污许可分类管理名录的企业事业单位和其他生产经营者。

（二）监督检查方式

通过现场检查、开展日常环境监督管理等方式进行。

（三）检查内容

按排污许可证的规定进行证后监管。

（四）监督检查程序

(1)现场检查并实行随机抽查；

(2)持有效执法证进行检查，人数不得少于2人；

(3)根据检查情况，视情处理各类情况(需要整改的，依法依规下达整改通知；对需要纳入行政处罚的，依法办理。)；

(4)做好现场检查书面记录，相关材料归档。
