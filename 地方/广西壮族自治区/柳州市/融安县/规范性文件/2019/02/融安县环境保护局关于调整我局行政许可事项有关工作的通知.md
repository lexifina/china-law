# 融安县环境保护局关于调整我局行政许可事项有关工作的通知

局属各股、室，环境监察大队，监测站：

根据《广西壮族自治区人民政府关于取消下放和调整一批行政许可等事项的决定 》（桂政发（2019）6号）以及《 关于落实取消下放和调整一批行政许可等事项的决定》（融审改办发〔2019〕3号）文件精神，我局取消2项行政许可事项，新增1项行政许可，调整设定依据事项2项。

各有关股室对取消的行政许可事项，不得再实施审批，也不得以备案、审查、核准等形式进行变相审批；要切实加强事中事后监管，防止出现监管真空。要按照县审改办部署对取消行政许可事项及时调整行政许可事项目录和行政审批标准化目录库，确保调整到位、监管到位。

各有关股室应按照县审改办部署对调整行政许可事项完善权责清单，并将申请调整权责清单报审表报县审改办；完善权责运行流程，将申请调整权力运行流程报审表报县政管办。

附件：1.融安县环境保护局取消的行政许可事项目录（共2项）

2.融安县环境保护局调整的行政许可事项目录（共2项）

3.融安县环境保护局新增的行政许可事项目录（共1项）

融安县环境保护局
