# 融人社发〔2019〕11号关于财政全额拨款单位缴费方式的通知

各乡（镇）人民政府，泗顶矿区管理处，县直各单位：

2019年1月23日，柳州市“互联网+人社”系统切换上线,在全市范围内优化参保单位社会保险费缴费方式，所有参保单位可通过“银社直连”信息平台与银行信息系统联网按时足额缴纳各项社会保险费，传统的缴费方式在“互联网+人社”系统无法进账及提供基金收款收据。

为方便单位缴纳各项社会保险费，保证社会保险费按时足额到账，决定从2019年3月起，机关事业单位基本养老保险费个人缴费部分由县财政局代扣，当月发放工资时退回各单位基本户;单位缴费部分由各单位向县财政局请款，通过财政支付做回本单位基本户，再由各参保单位按《单位社会保险缴费通知书》上应缴保险费按月足额缴入县社会保险事业局对应的社会保险基金收入户，请参保单位配合执行。

特此通知。

融安县人力资源和社会保障局 融安县财政局

2019年3月11日
