# 融林字〔2019〕13号关于转发《农业农村部办公厅关于做好农村沼气设施安全处置工作的通知》的通知

各乡（镇）人民政府:

现将农业农村部办公厅《关于做好农村沼气设施安全处置工作的通知》（农办科[2019]2号）转发给你们，请认真贯彻落实，并在2019年6月30日前将辖区内报废沼气池按村屯统计好报到融安县农村能源办公室，以便指导农村沼气设施业主做好安全处置工作，组织专业技术人员或委托专业机构进行专业拆除、填埋或改造，彻底解决安全隐患。

附件：1.《农业农村部办公厅关于做好农村沼气设施安全处置工作的通知》（农办科[2019]2号）

2.2019年融安县农村沼气设施分类处置表

2019年3月11日

公开方式：主动公开

融安县林业局办公室 　 2019年3月11日印发
