# 融农字〔2019〕32号关于印发《融安县2019年特色农业品牌创建方案》的通知

各乡（镇）人民政府，各有关单位：

经研究，现将《融安县2019年特色农业品牌创建方案》印发给你们，请结合实际，认真组织实施。

2019年4月20日

融安县2019年特色农业品牌创建方案

根据《关于促进贫困地区农产品产销对接的实施意见》（桂政办发〔2018〕130号）精神和《融安县2019年“5+2”特色产业产销对接实施方案》，为发展我县“5+2”特色农产品产业，加快推进我县“三品一标”和农产品区域公用品牌建设，引导和支持我县开展绿色、有机、地理标志农产品认证和国家农产品区域公用品牌申报，推进质量兴农绿色兴农品牌强农，促进贫困户增收，助力脱贫攻坚，特制定本方案。

一、指导思想

全面贯彻落实党的十九大和十九届二中、三中全会精神，以习近平新时代中国特色社会主义思想为指导，认真落实中央、自治区以及市级关于实施乡村振兴战略和打赢脱贫攻坚战的决策部署，紧紧围绕乡村振兴、农业供给侧结构性改革和现代特色农业高质量发展，采取有力措施，以提速发展绿色食品、有机农产品、农产品地理标志为重点，同时稳步发展无公害农产品，提速扩大“三品一标”规模，增加“三品一标”产品供给量，培育特色农产品品牌，提高我县经济整体水平。

二、工作目标

围绕我县“5+2”特色农产品产业，2019年，力争融安县新增认证登记“三品一标”农产品2个以上，有效期内获农业农村部认证“三品一标”产品总个数达到18个以上。推进“三品一标”品牌和国家农产品区域公用品牌建设，培育一批有影响力和较强竞争优势的融安农产品品牌，助农增收。

三、主要措施

（一）加强组织领导，重抓工作落实。一是积极争取我县党委、政府重视支持，把发展“三品一标”列入当地党委、政府的重点工作范围。二是加强对“三品一标”工作的领导，细化落实目标任务，确保完成我县“三品一标”工作的目标要求。三是加强绩效考核。根据自治区和柳州市对绿色、有机高品质农产品等的要求，按时完成上级部门下达“三品一标”培植绩效任务。

（二）强化推进举措，加大支持力度。加强统筹，落实责任，广泛组织、发动企业、农民合作社、家庭农场等主体，积极申报“三品一标”，重点发展绿色食品、有机农产品和农产品地理标志产品，加快发展速度。积极主动对接财政部门，将自助区、市级“三品一标”认证补贴经费及时足额补助到“三品一标”生产经营主体，加大对“三品一标”基地建设、品牌建设和宣传、推介、展销等的投入，并努力保持扶持支持政策的稳定性，积极发挥政策的正向拉动作用，激励企业发展“三品一标”产品，推动融安县“三品一标”加快发展。

（三）严格全程监管，确保“三品一标”质量。一是规范认证审核程序，严格执行审查标准，把好“三品一标”准入关，推行建立绿色食品、有机农产品内检员先培训后申报机制，推进企业内检员前置条件审查工作，确保认证质量。二是全程严格督促执行“三品一标”有关标准，全程监管，严格按标准生产，突出抓好生产主体严格按照相应的标准使用农药、肥料等投入品，确保“三品一标”农产品质量安全。三是开展“三品一标”农产品产地监测和产品抽检、例行抽检等监管工作，强化责任意识和风险意识，防控风险，确保“三品一标”产品抽检合格率达到98%以上。

（四）提高品牌意识，树立“三品一标”品牌。“三品一标”是绿色优质安全农产品品牌，我县要加强宣传和营销，指导各获证企业积极用标，形成企业品牌。同时积极组织获证企业参加自治区和柳州市组织的绿色食品博览会、农交会地标专展等展会，开展营销推介活动，拓展市场。

四、补贴办法

（一）补贴标准

1.无公害农产品：第一个产品补贴1.2万元，第二个产品补贴0.6万元，第三个产品以上每个产品补贴0.3万元，5万元封顶。

2.绿色食品：第一个产品补贴3万元，第二个产品补贴0.6万元，第三个产品以上每个产品补贴0.3万元，5万元封顶。

3.有机产品：第一个产品补贴3万元，第二个产品补贴0.6万元，第三个产品以上每个产品补贴0.3万元，5万元封顶。另外，国外有机认证机构认证的有机产品补贴3万元。（如有机产品是加工产品，以加工产品为补贴对象）

4.农产品地理标志每个产品补贴5万元，国家级农产品地理标志示范样板补贴8万元。

（二）补贴审定程序

根据自治区农业农村厅“三品一标”认证补贴方案，获补助企业提供相关证书及申请资料，县农业农村局审核后进行补贴。
