# 融安县政务服务监督管理办公室关于公布全县证明材料清理清单的通知

各乡（镇），各相关单位：

为深化简政放权、放管结合、优化服务改革，持续优化我县营商环境，根据《广西壮族自治区人民政府办公厅关于做好全区证明材料清理工作的通知》（桂政办发201927号）精神，自治区统一组织开展减证便民专项行动，编制形成《广西壮族自治区取消的证明材料清单（自治区级）》、《广西壮族自治区取消的证明材料清单（市级）》、《广西壮族自治区取消的证明材料清单（县级）》、《广西壮族自治区取消的证明材料清单（乡〔镇〕级）》、《广西壮族自治区基本证照凭证清单》、《广西壮族自治区村（居）民委员会保留的证明材料》6张清单（以下简称“6张清单”），现将有关事项通知如下：

现将涉及融安县取消的证明材料清单在融安县政府门户网站（/）予以公布，请各乡、镇和各部门按照要求抓好落实。

附件：1. 广西壮族自治区取消的证明材料清单（县级）

2. 广西壮族自治区取消的证明材料清单（乡〔镇〕级）

3. 广西壮族自治区基本证照凭证清单

4. 广西壮族自治区村（居）民委员会保留的证明材料
