# 融林字〔2019〕20号关于成立2019年度扶贫“专责诊疗组”的通知

局属各单位：

2019年是融安县脱贫摘帽攻坚之年。为进一步压紧压实全局脱贫攻坚工作责任，提升全局脱贫攻坚工作质量和成效，做到责任到人、职责清晰、各负其责、合力攻坚、措施精准、为全县今年如期打赢脱贫摘帽攻坚战推波助力。根据融安县委、县政府《关于进一步压紧压实全县扶贫工作责任坚决打赢脱贫摘帽攻坚战的决定》（融发〔2019〕2号）文件精神，经局党组研究，决定成立融安县林业局扶贫 “专责诊疗组”，具体工作安排如下：

一、总体要求

组建扶贫帮扶“专责诊疗组”，从本单位选派2—10名思想政治素质好、扶贫业务精、工作认真负责、身体健康的干部组成扶贫帮扶“专责诊疗组”，负责对本单位帮扶干部联系的所有贫困户的结对帮扶工作进行诊疗，对帮扶质量负总责，确保本单位结对帮扶工作“零差错”、高质量。

扶贫帮扶“专责诊疗组”组长由本单位扶贫工作分管领导担任，负责组织协调和督促检查工作。安排“专责诊疗组”成员分片负责贫困户范围。

“专责诊疗组”成员从3月1日起正式开展工作，至全县脱贫摘帽核验通过后结束。

二、工作职责

1．安排、指导、督促、检查所负责片区范围内的“一户一册一卡一档”填写、信息核对、制定和实施脱贫计划和帮扶措施、宣传惠农方针政策、开展感恩教育、脱贫摘帽“双认定”等六项帮扶工作。对六项工作及时进行查缺补漏并修改完善，把好本单位帮扶工作的质量关。

2．负责抓好第二帮扶联系人督查检查发现问题的整改落实，确保分片负责贫困户的各项工作顺利达标。

3．对分片负责贫困户“两不愁三保障”及“八有一超”指标达标情况进行全面排查，跟踪了解进展情况，动员和指导贫困户依靠自身努力解决问题，对贫困户自身无法解决或解决进度缓慢的问题，实时向包（驻）村工作组和单位主要领导反馈，并对指标达标情况进行跟踪。

4．本局对“专责诊疗组”反馈的问题要对症下药，采取有效措施，帮助其解决实际困难。

5．根据全县扶贫工作需要，按照联系村包（驻）村工作组的工作安排，完成其他临时性扶贫工作。对照国家和自治区各项检查考核评估要求，配合包（驻）村工作组做好各项迎检工作。

6．参加县、乡、村举办的各类扶贫业务培训班（会），进一步提升业务水平。

三、组织保障

“专责诊疗组”成员实行半脱产工作，各站、股、室要合理安排其工作岗位和工作任务，确保其有充足时间集中精力开展脱贫攻坚工作。“专责诊疗组”成员视工作完成情况自行安排进村时间，2019年前三季度每月至少1次，第四季度每周至少2次。同时，对当地党委政府和包（驻）村工作组安排的其他结对帮扶工作，必须无条件配合。“专责诊疗组”成员下村期间的考勤由选派单位负责登记，按照我县差旅费有关标准，兑现下乡差旅补助。

四、责任追究

1．凡所负责片区范围内的帮扶工作在“一户一册一卡一档”填写、扶贫信息一致、有针对性的落实脱贫计划和帮扶措施、宣传惠农方针政策、脱贫摘帽“双认定”等六项工作中任何一项出现问题的，或被国家、自治区、柳州市通报批评（黑榜）的，追究分片负责“专责诊疗组”成员责任。

2．凡对包（驻）村工作组和第二帮扶联系人督查检查反馈的问题3日内不整改的或整改不到位的，追究分片负责“专责诊疗组”成员责任。

3．凡对所负责片区范围内的贫困户“两不愁三保障”及“八有一超”等指标情况未全面排查和掌握的，或未及时将存在问题和困难上报包（驻）村工作组和所在单位的、导致考核不通过或不能脱贫的，追究相关“专责诊疗组”成员责任。
