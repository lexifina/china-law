# 关于将沙子乡供销合作社划归泗顶镇供销合作社代管的通知（融供销﹝2019﹞1号）

关于将沙子乡供销合作社划归泗顶镇供销合作社代管的通知

来源：县供销社

发布日期：2019-05-20 16:54

作者：县供销社

关于将沙子乡供销合作社划归泗顶镇供销合作社代管的通知

各股室、乡（镇）供销社、直属公司：

融安县沙子乡供销合作社由于单位人员已大部分退休、长期外出或其他原因，现已无人管理。为更好地开展供销合作社的综合改革工作，经县社研究决定，从即日起，将融安县沙子乡供销合作社划归融安县泗顶镇供销合作社代管。请沙子乡供销合作社、泗顶镇供销合作社做好相关交接工作。

融安县供销合作社联合社

2019年5月8日
