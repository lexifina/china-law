# 坡政发〔2019〕7号关于进一步明确2019-2020年特色产业精准扶贫以奖代补“鸡”项目验收标准的通知

坡政发〔2019〕7号

大坡乡人民政府

关于进一步明确2019-2020年特色产业精准扶贫以奖代补“鸡”项目验收标准的通知

各村民委员会，乡直各有关单位：

近年来，大坡乡紧紧围绕解决“两不愁三保障”的目标，充分践行“绿水青山就是金山银山”发展理念，努力把山清水秀的生态优势转化成经济发展的优势，精准施策，因地制宜，大力推广“大坡飞鸡”产业扶贫模式，带动贫困户脱贫成效明显；建立健全产业链，做大做强“大坡飞鸡”区域特色品牌，不断推进产业向现代农业纵深发展，“大坡飞鸡”已经成为我乡经济发展的重要引擎。

为进一步推进“大坡飞鸡”产业的健康可持续发展，推动产业向高产值迈进，提高农民收入，切实解决“大坡飞鸡”近年来不断凸显的扶贫产业奖补验收标的不清晰、鸡苗品种不一、来源不明、免疫情况不明、脱温时间不够等几个影响产业发展的大问题，经乡党委、乡人民政府研究决定，从产业奖补的角度着手规范“大坡飞鸡”的产业发展。现将大坡乡特色产业精准扶贫“鸡”项目的验收标准明确如下：

1.鸡的补助标准为15元/羽，验收时达30羽以上（含）；

2.购买的鸡苗必须为由大坡乡人民政府认可的“大坡飞鸡”种鸡孵化场提供出壳鸡仔的脱温场（自己孵化的除外）提供的鸡苗（与“大坡飞鸡”种鸡孵化场合作的脱温场名单附后，对后续增加合作的名单将进行及时更新和公布）；

3.自购入脱温鸡苗起养殖时间为3个半月以上；

4.自繁自养孵化的鸡苗饲养要达4个半月以上。

5.本通知自下文之日起开始执行，在文件下发之前购买的鸡苗，不论出处均予以验收，之后买的鸡苗，不是在“大坡飞鸡”种鸡孵化场提供出壳鸡仔的脱温场（自己孵化的除外）的则不予验收。

扶贫产业奖补验收由各村组织开展。各包村组、村“两委”干部、驻村工作队、帮扶联系人及时将该文件精神及时宣传到每一户贫困户。对于今后仍有贫困户反映不知政策无法落实奖补的，由相应包片干部、帮扶人负责解释和处理。

附件：大坡乡认可的与“大坡飞鸡”种鸡孵化场合作的脱温场名单

大坡乡人民政府
