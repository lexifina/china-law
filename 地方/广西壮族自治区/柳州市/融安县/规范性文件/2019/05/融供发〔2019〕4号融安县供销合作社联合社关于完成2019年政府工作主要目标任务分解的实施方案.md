# 融供发〔2019〕4号融安县供销合作社联合社关于完成2019年政府工作主要目标任务分解的实施方案

融安县供销合作社联合社关于完成2019年政府工作主要目标任务分解的实施方案

各股室：

根据《融安县人民政府关于2019年政府工作主要目标任务分解的通知》（融政发〔2019〕4号）精神，结合单位实际，制定本工作实施方案，请认真遵照执行。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，认真贯彻落实党中央、国务院和自治区党委、政府的决策部署，深入学习贯彻习近平总书记赋予广西的“三大定位”新使命、提出的“五个扎实”新要求和“建设壮美广西

共圆复兴梦想”重要题词精神，以及市第十二次党代会第四次会议精神和县委十四届六次全会精神，全面发力，推进供销社综合改革工作，以崭新面貌迎接新中国成立70周年。

二、工作要求

（一）要切实把2019年政府工作主要目标任务纳入重要工作日程，立足工作实际，制定实施方案和时序表，建立台账，确保各项工作任务按质按量如期完成。

（二）要实行“主要领导负总责，分管领导具体抓”的工作责任制，做到各项目标任务有人管、有人抓，确保不缺项、不漏项。

（三）要全力支持、通力配合牵头单位，坚持实行定期汇报制度，并根据工作需要不定期汇报。

（四）要根据工作职责，仔细对照牵头单位转交阅处的问题，认真查摆原因，切实做到查漏补缺。

（五）要提前5个工作日内，将本单位的总结送至牵头单位汇总。

（六）各股室分别于6月10日前、12月10日前将本股室负责工作目标任务完成情况上报办公室。

三、主要工作目标任务

（一）总体目标：巩固提升脱贫攻坚成果，实现整体脱贫摘帽目标。

1、项目：强化保障压实责任。

（1）工作目标任务：全力开展“脱贫摘帽攻坚年”活动，以巩固扶贫成果、提升脱贫质量为关键，坚决打赢脱贫摘帽的决定性战役。认真履行扶贫工作各项制度，定期开展“回头看”，杜绝侥幸轻敌思想，激励广大干部职工心怀忧患、保持斗志，紧盯各项脱贫指标不放松，开展自查自纠，聚焦问题整改，查缺补漏，持续强化政策落实、工作落实、责任落实，高质量实现贫困户脱贫摘帽，年度实现8户20人脱贫。

分管领导：陈松

责任部门：合作指导股

完成时限：2019年10月

2、项目：全力夯实脱贫根基。

（2）工作目标任务：继续打好产业扶贫、村集体经济发展战役，加强产业扶贫、教育扶贫、健康扶贫、就业创业培训、社会保障、危旧房改造等政策宣传力度。坚决支持贫困户“自主造血”，增强可持续发展能力，实现长期稳定脱贫。积极转变工作思路，启动脱贫攻坚与乡村振兴战略的有机承接，结合村集体经济发展资金，进一步整合基层供销社资源，加快基层供销社社有资产升级改造，促进农村一二三产业融合发展，助推脱贫成效更上新的台阶。
