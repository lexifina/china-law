# 融安县交通运输局道路货物运输站（场）经营许可取消后的事中事后监管工作方案

根据《国务院关于取消下放一批行政许可事项的决定》（国发〔2019〕6号）和《自治区审改办关于做好国务院决定取消和下放一批行政许可事项落实工作的通知》（桂审改办发〔2019〕3号）和《市审改办关于落实国发〔2019〕6号取消和下放一批行政许可事项工作的通知》（柳审改办发〔2019〕4号）精神，为扎实做好道路货物运输站（场）经营许可后续监管工作，我局结合工作实际，制定道路货物运输站（场）经营许可取消后续监管工作方案。

一、取消行政审批项目基本情况

（一）项目名称：道路货物运输站（场）经营许可。

（二）取消依据：《国务院关于取消下放一批行政许可事项的决定》（国发〔2019〕6号）。

二、监管依据

（一）中华人民共和国道路运输条例(2016年2月6日修正版)第三十九条 申请从事道路运输站(场)经营、机动车维修经营和机动车驾驶员培训业务的，应当在依法向工商行政管理机关办理有关登记手续后，向所在地县级道路运输管理机构提出申请，并分别附送符合本条例第三十六条、第三十七条、第三十八条规定条件的相关材料。县级道路运输管理机构应当自受理申请之日起15日内审查完毕，作出许可或者不予许可的决定，并书面通知申请人。

（二）2008年7月23日交通运输部《关于修改〈道路货物运输及站场管理规定〉的决定》（中华人民共和国交通运输部令2012年第1号）。

三、监管措施

根据《国务院关于取消下放一批行政许可事项的决定》（国发〔2019〕6号）精神，按以下措施做好监管工作：

（一）建立健全道路货物运输站（场）经营者备案制度，及时公布相关信息。

（二）加强对道路货物运输站（场）生产经营的监督管理，通过“双随机、一公开”监管等方式，依法查处违反道路货物运输经营管理规定的行为。

（三）加强对道路货物运输站（场）经营业户的信用监管，建立黑名单制度，向社会公开失信企业名单，并实施联合惩戒，深入推进道路货物运输站（场）经营的诚信体系建设。
