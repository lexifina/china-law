# 融安县卫生健康局关于自治区下放护士执业注册行政审批项目承接工作方案

局各股室、二层单位：

为进一步贯彻落实《广西壮族自治区人民政府关于取消下放和调整一批行政审批项目的决定》（桂政发〔2016〕75号），做好自治区政府卫生健康委护士执业注册行政审批项目下放接收工作，实现审批项目下放与接收的“无缝对接”，现结合工作实际，制定行政审批权接收工作方案：

一、承接行政审批项目基本情况

项目名称：护士执业注册

项目性质：行政许可

设定依据：《护士条例》（2008年1月31日中华人民共和国国务院令第517号公布，自2008年5月12日期实施）第八条规定：申请护士执业注册的，应当向拟执业地省、自治区、直辖市人民政府卫生主管部门提出申请。收到申请的卫生主管部门应当自收到申请之日起20个工作日内做出决定，对具备本条例规定条件的，准予注册，并发给护士执业证书；对不具备本条例规定条件的，不予注册，并书面说明理由。

二、下放主体和承接主体

下放主体：自治区卫生健康委

承接主体：融安县卫生健康局

三、承接项目的权限承接后的审批权限

融安县卫生健康局按照属地管理原则，由自治区政府卫生健康委下放的护士执业注册项目审批权限具体内容和权限划分为：根据《护士条例》第八条规定：护士注册（含首次注册、延续注册、重新注册、变更注册、注销注册）（具体权限按自治区政府、部门下放方案表述）

四、接收方式和交接时间

（一）接收方式为：直接接收

（二）2019年 5月 17日前，由自治区政府卫生健康委受理的项目，仍继续由原受理单位负责办理；2019年5月17日起，融安县范围内该项目由我单位负责实施。
