# 关于印发《融安县高级中学2019年中考定向推荐生录取办法》的通知

各乡（镇）中心校、中学，县直各校，局二层机构：

现将《融安县高级中学2019年中考定向推荐生录取办法》印发给你们，请认真贯彻执行。

融安县教育局

2019年6月13日

融安县高级中学2019年中考定向推荐生

录取办法

根据柳州市教育局《关于印发柳州市2019年初中学业水平考试和高中阶段学校招生工作方案>的通知》（柳教基〔2019〕58号）、《融安县2019年初中学业水平考试和高中阶段招生工作方案》（融教字〔2019〕34号）文件精神，为促进我县义务教育均衡发展，经研究，决定从融安县高级中学2019年招生计划指令性指标中，划出51%的名额作为推荐指标，定向分配给全县各公办初中学校。具体实施办法如下：

一、定向推荐生入围条件

入围定向推荐生必须同时具备以下条件：

（一）参加融安县2019年初中毕业升学考试的应届毕业生。

（二）全县公办初中学区学生。学区学生指具有融安县户籍，从初一起始年级开始在学区学校就读，并一直在该学区学校读至毕业的学生。2018年秋季学期起，因易地扶贫搬迁由本县乡下初中转学到县实验中学、县初级中学、长安镇第一中学的毕业生若初一起始年级在原校及现所在学校连续读至毕业，属于学区学生，其推荐指标放回原就读学校，参加原就读学校定向推荐，由现所在学校将名单报县教育局，县教育局汇总后发原就读学校，原就读学校再审核是否符合定向推荐生条件。

（三）申请就读融安县高级中学定向推荐生的考生，中考总成绩必须达到C+等及以上。

（四）考生综合素质评价达B等。

（五）考生物理、化学、信息技术操作技能考试均为合格。

二、推荐和录取程序

（一）为确保定向推荐生招生录取工作公平、公正、公开，各初中学校要负责对本校初三年级的学区生身份进行鉴定，并于6月25日前在校内公示本校符合定向推荐资格的所有考生名单，并公布举报电话，接受师生、家长和社会监督（公示期3天）。公示结束无异议后，各学校把所有符合定向推荐资格的考生名单（纸质版及电子版）交县招生办。县教育局下达给各学校定向推荐生的指标（附件1），各初中学校也要及时在校内进行公示。

（二）各初中学校在中考成绩公布后，应召开家长会，向家长宣传定向推荐生推荐录取的有关政策。

1．符合定向推荐条件的学区生以自愿为原则，向所在学校提出书面申请，填写《融安县2019年中考定向推荐生报名申请表》（附件2），考生及其法定监护人必须在报名申请表上签字确认。

2．对符合推荐条件却放弃推荐资格的学生，必须填写《融安县2019年初中学校学区生放弃中考定向推荐生推荐资格确认表》（附件3），考生及其法定监护人必须在确认表上签字确认。

3．在学校规定的时间内没有上交申请表或确认表的考生，视为自动放弃推荐资格。

4.《融安县2019年初中学校学区生放弃中考定向推荐生推荐资格确认表》由学校存档备查。学校要尊重学生意愿，不能对申请定向推荐的学生进行筛选。各初中学校不得动员在推荐指标范围内的考生放弃中考定向推荐生推荐资格，否则其指标全部转入现场网上统一报名指令性招生指标录取，不再由学校另行补充。

（三）县教育局按照下达各初中学校的推荐指标，召集招生办及招生学校（融安高中）相关负责人共同研究，在各初中学校符合推荐条件且提出书面申请的考生中按照中考总成绩从高到低择优录取，根据推荐指标确定定向推荐生录取名单（在同等条件下建档立卡贫困户毕业生优先录取），并把名单发到各初中学校公示3个工作日。

（四）各初中学校将确定的定向推荐生录取名单在校内公示3个工作日无异议后，按规定时间和要求将公示结果以书面形式上报县招生办。

（五）若学校定向推荐生指标用不完的，其剩余指标全部转入现场网上统一报名指令性招生指标。

（六）定向推荐生的录取在我县普通高中第一时段报名开始之前完成，已录取的定向推荐生不能再参加现场网上报名录取，不得再转录其他学校。

（七）县招生办将拟定录取的定向推荐生名单在柳州中考招生网上进行公示。

三、加强对定向推荐生推荐和录取工作的管理

（一）我县的自治区示范性普通高中定向生推荐和录取工作坚持公平、公正、公开的原则。各初中学校要根据定向推荐生的推荐条件，严格按程序进行推荐。

（二）县招生办和各初中学校要做好相关信访工作，及时处理好学生和家长的投诉及信访。我县的投诉电话为：8134680（县教育局教育股）、8139156（县招生办）。

（三）各学校、县招生办及相关部门要做好整个推荐和录取资料的收集、整理和保管工作。

（四）在实施过程中，必须严格按本办法规定的有关条件和要求进行操作，任何单位和个人不得弄虚作假，如违反本办法的，取消考生的入围、入学资格和学校2019年的评优资格，在全县教育系统进行通报，并按违反国家招生纪律的有关规定严肃查处有关责任人。
