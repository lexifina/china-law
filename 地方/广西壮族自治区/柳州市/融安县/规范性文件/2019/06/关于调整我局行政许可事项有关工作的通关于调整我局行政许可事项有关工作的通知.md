# 关于调整我局行政许可事项有关工作的通关于调整我局行政许可事项有关工作的通知

局属各二层单位、股室：

根据融安县行政审批制度改革工作领导小组办公室《关于落实取消承接一批行政许可等事项的决定》（融审改办发{2019}5号）精神，我局取消1项行政许可事项，工作要求如下：

一、各二层单位、股室对取消的行政许可事项，不得在实施审批，也不得以备案、审查、核准等形式进行变相审批；要切实加强事中事后监管，防治出现监管真空。要按照县审改办部署对取消行政许可事项及时调整行政许可事项目录和行政审批标准化目录库，确保调整到位、监管到位。

二、各二层单位、股室应按照县审改办部署对调整行政许可事项完善权责清单，并将申请调整权责清单报审表报县审改办；完善权责运行流程，将申请调整权力运行流程表报县政管办。
