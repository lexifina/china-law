# 浮石镇人民政府关于2018年度自治区社会评价反馈意见建议(四类整改事项)的回访解释情况说明

根据融安县督查和绩效考评办公室《关于做好2018年度自治区社会评价反馈意见建议整改工作的通知》的文件要求，经梳理，涉及我单位关于2018年度自治区社会评价反馈意见建议(四类整改事项)有3条，现将相关回访解释情况说明如下：

一、整改事项

1、被访者觉得上面传达下来的政策和优惠群众还是不了解，希望有什么都可以透明，让群众都了解。

2、浮石镇东江村贫困户精准扶贫工作有人弄虚作假。

3、浮石镇隘口村干部蔡敏雄扶贫工作不到位，真正困难的人没有得到帮助，把扶贫名额给了自己亲戚。

二、整改时限

无法整改。

三、理由依据

1、上级传达的优惠政策一是由帮扶人入户对贫困户进行宣传，并发放宣传材料；二是由各村（屯）粘贴宣传画报公示和召开群众会的方式宣传政策，已宣传到位。

2、在实地走访调查中没有发现该情况，问题反映太空乏，无法具体查证。

3、经核实，蔡敏雄是浮石镇卫生院临聘人员，是非在编人员，没有参与扶贫工作，没有扶贫工作任务。

浮石镇人民政府
