# 融发改规字〔2019〕39号关于融安县东起至石门仙湖景区公路工程

融安县交通运输局：

你单位报来《关于审批融安县东起至石门仙湖景区公路工程可行性研究报告的请示》及相关材料收悉。经研究，现批复如下：

一、原则同意融安县东起至石门仙湖景区公路工程可行性研究报告。

二、广西投资项目在线审批监管平台项目代码:2019-450224-48-01-024482 。

三、项目地址:起点位于东起乡竹山屯附近，接东起至桂柳高速湖洞出口公路（工可），路线总体走向由北往南，主要沿现有四级公路布设，经竹洞门、良村、英村、四兴、太平辽，终点位于大良镇石门门仙湖景区大门。

四、建设规模及内容：设计里程约15.251公里，采用双车道三级公路标准，全线设计速度为30公里/小时，路基宽为7.5米。

五、总投资及资金筹措：项目总投资17756.6142万元。资金来源为申请中央资金及地方配套。

六、接文后，请严格按照基本建设程序要求，做好项目的下一阶段工作，并于每月6号前登录广西投资监管平台填报截至上个月底项目进度情况。

融安县发展和改革局

2019年7月26日
