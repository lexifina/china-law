# 融教字〔2019〕56号融安县教育局关于启用新公章的通知

各乡（镇）中、小学，幼儿园，县直各校，局二层机构，各有关单位：

根据《中共融安县委办公室

融安县人民政府办公室关于印发〈融安县教育局职能配置、内设机构和人员编制规定〉的通知》（融办〔2019〕25号）精神，我局作为县政府的职能部门，承担全县教育事业各项工作。因原“融安县教育局”公章使用年限长久，已破损，字迹模糊，为保证公章的合法性和严谨性，决定自2019年7月9日起启用新公章“融安县教育局”（编号4502241010267），原公章“融安县教育局”（编号4502241001645）同时作废。
