# 关于印发《融安县行政审批局行政许可事项目录（2019年）》的通知

局各股（室），县政务协调中心：

为了进一步推动行政许可事项目录清单管理，促进依法行政，提高办事效率，切实方便企业和群众，现将《融安县行政审批局行政许可事项目录（2019年）》印发给你们，请认真贯彻执行。
