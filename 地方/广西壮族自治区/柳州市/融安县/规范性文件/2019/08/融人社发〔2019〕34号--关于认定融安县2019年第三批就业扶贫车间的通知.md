# 融人社发〔2019〕34号--关于认定融安县2019年第三批就业扶贫车间的通知

各乡（镇）人民政府，泗顶矿区管理处，县直各有关单位：

为更好地贯彻落实国家、自治区积极就业政策,促进贫困家庭劳动力就近就地转移就业,让贫困家庭早日脱贫致富,根据《广西壮族自治区人民政府关于做好当前和今后一段时期就业创业工作的通知》(桂政发〔2017〕48号)和《柳州市人民政府办公室关于印发的通知》(柳政办发〔2018〕19号)等文件精神,按照企业申请、乡镇推荐的原则，经实地调查核实,以下20家企业被认定为融安县第三批就业扶贫车间。融安县第三批就业扶贫车间名单如下：

融安县丰硕种植基地

融安县潭头聚源木业有限公司

融安县富源木材加工厂

融安县东潭村木材加工厂

融安县六朗木材加工厂

融安县玉融木材加工厂

融安县木琴木材加工厂

融安县六岭木材加工厂

融安县硕香农场

融安巾帼大坡飞鸡养殖专业合作社

融安县超盈木材加工厂

融安县家和农场

融安县鲲鹏养鱼专业合作社

融安明发木业有限公司

融安县大森生态休闲农庄

融安县赣融木业有限公司

融安县顺天水果种植专业合作社

融安县坡马木材加工厂

融安乐兴竹木加工厂

融安县车田茶叶专业合作社

请就业扶贫车间因地制宜,创新发展模式,搭建更好的就业平台,积极吸纳我县贫困农村劳动力到车间务工，帮助贫困群众实现脱贫致富。各乡（镇）、县各有关单位要积极鼓励和引导有条件的企业到镇、村设立生产车间,加强组织引导贫困家庭劳动力等人员就近就地转移就业,为我县脱贫攻坚工作作出新的贡献。

融安县人力资源和社会保障局 融安县财政局

融安县扶贫开发办公室

2019年8月22日
