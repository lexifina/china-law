# 融农字〔2019〕22号关于认定大坡乡福上村大坡飞鸡养殖产业基地的通知

各乡（镇）人民政府、各贫困村委员会：

为贯彻落实《融安县产业开发专责小组关于及时组织申报贫困村特色产业基地的通知》（融扶领产发[2018]4号）及融安县产业开发专责小组关于开展融安县2018年贫困村特色产业基地实地认定的通知精神，在各乡（镇）推荐和农业科技专家评审的基础上，经审核，认定大坡乡福上村大坡飞鸡养殖产业基地为融安县第三批特色产业基地（名单附后）。

附件：融安县第三批特色产业基地名单

融安县农业农村局

2019年8月29日
