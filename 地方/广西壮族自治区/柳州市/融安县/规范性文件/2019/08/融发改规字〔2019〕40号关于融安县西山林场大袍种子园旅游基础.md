# 融发改规字〔2019〕40号关于融安县西山林场大袍种子园旅游基础

融安县文化体育广电和旅游局：

你单位报来的《关于2019年融安县西山林场大袍种子园旅游基础设施项目立项的函》及相关材料收悉。经研究，现批复如下：

一、原则同意融安县西山林场大袍种子园旅游基础设施项目立项。

二、广西投资项目在线审批监管平台项目代码：2019-450224-48-01-024793。

三、项目建设地点：融安县长安镇安宁村大袍屯。

四、建设规模及主要内容：

建设1条宽度约1.2米，长度约2600米的登山旅游步道，1座观景平台；8张休憩椅及护栏，1座AAA旅游厕所。

五、总投资及资金来源：项目总投资匡算275万元，资金来源为自治区旅游发展专项资金。

六、请据此批复开展下阶段工作，并于每月5号前登录广西投资项目在线审批监管平台填报截至上个月底项目进度情况。

融安县发展和改革局

2019年7月29日

公开方式：主动公开
