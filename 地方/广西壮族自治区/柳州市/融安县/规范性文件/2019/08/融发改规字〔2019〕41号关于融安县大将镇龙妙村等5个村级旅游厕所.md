# 融发改规字〔2019〕41号关于融安县大将镇龙妙村等5个村级旅游厕所

融安县文化体育广电和旅游局：

你单位报来的《关于2019年融安县大将镇龙妙村等5个旅游厕所建设项目立项的函》及相关材料收悉。经研究，现批复如下：

一、原则同意融安县大将镇龙妙村等5个村级旅游厕所建设项目立项。

二、广西投资项目在线审批监管平台项目代码：2019-450224-72-01-024794。

三、项目建设地点：大将镇龙妙村、浮石镇鸬鹚洲村村头、浮石镇鸬鹚洲村村尾、浮石镇桥头村、大良镇和南村西村屯。

四、建设规模及主要内容：

大将镇龙妙村龙溪河谷农庄新建面积为60平方米的旅游厕所1座；浮石镇鸬鹚洲村村头新建面积为90平方米的旅游厕所1座；浮石镇鸬鹚洲村村尾新建面积为60平方米的旅游厕所1座；浮石镇桥头村新建面积为60平方米的旅游厕所1座；大良镇和南村西村屯新建面积为60平方米的旅游厕所1座。

五、总投资和资金来源：项目总投资匡算87万元，资金来源为自治区2019年旅游发展基金补助地方项目资金。

六、请据此批复开展下阶段工作，并于每月5号前登录广西投资项目在线审批监管平台填报截至上个月底项目进度情况。

融安县发展和改革局

2019年7月29日

公开方式：主动公开
