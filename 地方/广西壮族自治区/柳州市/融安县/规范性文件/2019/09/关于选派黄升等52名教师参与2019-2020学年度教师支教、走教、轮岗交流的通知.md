# 关于选派黄升等52名教师参与2019-2020学年度教师支教、走教、轮岗交流的通知

各乡(镇)中心校、中学，县直各校（园），局二层机构：

为推进县域教师轮岗交流，合理配置教师资源，促进城乡教育均衡发展。根据《关于做好2019-2020学年度柳州市中小学市级支教轮岗和县（区、新区）域内教师轮岗交流工作的通知》（柳教人〔2019〕98号）、《关于做好2019-2020学年度自治区中小学教师支教走教工作的通知》（柳教人〔2019〕97号）和《关于组织开展2019-2020学年度广西优秀退休教师乡村支教计划的通知》(桂教师范〔2019〕31号)要求，经学校推荐及资格审核，决定选派黄升等 52名教师参加2019-2020学年度教师支教、走教、轮岗交流工作。具体名单如下：

一、选派参与柳州市“三区”支教教师名单

黄升等5人。（详细名单见附件1）

二、选派参与柳州市城中区跟班学习教师名单

左琳琳等11人。（详细名单见附件2）

三、选派参与柳州市“三区”走教教师名单

蓝江等14人。（详细名单见附件3）

四、选派参与县域内学校轮岗交流教师名单

李天芬等 20人。（详细名单见附件4）

五、选派参与广西优秀退休教师乡村支教教师名单

杨建敏等2人。（详细名单见附件5）

请各校及时通知参与支教、走教、轮岗交流的教师于9月10日前到位，并做好支教、走教、轮岗交流教师的交接和后勤保障工作。

附件：1. 选派参与柳州市“三区”支教教师名单

2. 选派参与柳州市城中区跟班学习教师名单

3. 选派参与柳州市“三区”走教教师名单
