# 融农字〔2019〕23号关于印发《融安县农业综合行政执法改革机构人员划转实施方案》的通知

局属各有关单位:

为落实《融安县农业综合行政执法改革实施方案》，做好有关单位机构人员划转工作，结合我局实际，制定了《融安县农业综合行政执法改革机构人员划转实施方案》。现印发给你们，请认真贯彻执行。

融安县农业农村局

2019年10月15日

信息公开选项：主动公开

融安县农业综合行政执法改革机构人员划转

实施方案

为落实《融安县农业综合行政执法改革实施方案》，做好有关单位机构人员划转工作，制定如下实施方案。

一、总体要求

根据《融安县农业综合行政执法改革实施方案》调整的职责，坚持“先立后破，不立不破”“编随事走、人随编走”的原则统筹谋划，周密安排，通盘考量，合理调配，做好机构人员划转工作，确保机构改革平稳有序推进。划转的人员是指随相关职责调整，需要划转的执法人员。

二、主要任务

（一）整合执法职能

将县农业行政综合执法大队、县农机安全监理站、县动物卫生监督所、县渔政渔港监督管理站、县水政监察大队整合，组建成县农业综合行政执法大队。将兽医兽药、生猪屠宰、饲料、动物卫生、种子、肥料、农药、农机、水利、农产品质量等分散在县农业农村局内设机构及所属单位的行政处罚以及与行政处罚相关的行政检查、行政强制职能剥离,整合到县农业综合行政执法大队，由其集中行使。

（二）划转执法机构人员

按照“编随事走、人随编走”的原则，将县农业行政综合执法大队、县水政监察大队、县动物卫生监督所、县渔政渔港监督管理站站和农机监理站的执法职能进行整合，组建55个编制的县农业综合行政执法大队。

1.原县农业行政综合执法大队整建制（8名编制8名人员）划转入县农业综合行政执法大队。

2.原县水政监察大队（12名编制在编10名人员），现5名编制4名人员划入县农业综合行政执法大队，其余7个编制6名人员划转到县水土保持监督管理站。

3.整建制划转渔政渔港监督管理站（4名编制3名人员）入县农业综合行政执法大队。

4.整建制划转动物卫生监督所（29名编制29名人员）入县农业综合行政执法大队。

5.原融安县农机安全监理站（9名编制8名人员）划转入县农业综合行政执法大队。

6.融安县农业技术推广中心1名人员、融安县农机化推广技术服务站1名人员划转入县农业综合行政执法大队。

三、组织实施

（一）提高政治站位。机构人员划转是机构改革的一项重要工作。各涉改单位要教育引导广大干部职工，牢固树立“四个意识”，讲政治顾大局，增强组织性，服从统一安排，正确对待进退留转，自觉拥护改革、支持改革、参与改革。

（二）加强组织领导。机构人员划转在县机构改革领导小组统一领导下，有组织、有步骤、有纪律推进。县机构改革领导小组办公室负责划转工作的监督指导，县改革领导机构要切实加强对机构人员划转工作的组织领导和协调落实，及时解决划转过程中遇到的困难和问题。

（三）迅速有序推进。本方案印发后，主管部门加强与县改革领导小组办公室县委编办沟通衔接，尽快组建融安县农业综合执法大队，保持各项工作任务的连续稳定，确保融安县农业综合行政执法改革在9月底前顺利完成。

（四）严明工作纪律。要严格执行机构改革政治纪律、组织纪律、机构编制纪律、干部人事纪律、财经纪律、保密纪律,坚决做到令行禁止。融安县农业综合行政执法队伍不同性质编制目前保持现状，待中央统一明确政策后，逐步加以规范。全面清理规范临时人员和编外聘用人员，严禁使用辅助人员执法。涉改单位资产随人员编制一并划转，严禁借改革之际擅自划转、移交、处置资产。在划转过程中不得自行其是,不讨价还价,不推诿扯皮,不拖延时间,不搞无原则纠纷,对违反纪律、不按要求划转,影响正常工作、造成不良后果的,纪委监委机关要严肃问责。
