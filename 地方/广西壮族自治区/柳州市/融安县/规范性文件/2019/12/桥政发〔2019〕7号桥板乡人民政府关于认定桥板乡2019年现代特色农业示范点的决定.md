# 桥政发〔2019〕7号桥板乡人民政府关于认定桥板乡2019年现代特色农业示范点的决定

桥政发〔2019〕7号

桥板乡人民政府关于认定桥板乡2019年

现代特色农业示范点的决定

各村民委、乡直各有关单位：

今年以来，各村委、各部门认真贯彻中央和自治区实施乡村振兴战略的重大决策部署，积极落实《广西现代特色农业示范区建设增点扩面提质升级（2018-2020）三年行动方案》、《柳州市现代特色农业示范区建设增点扩面提质升级三年行动方案（2018-2020年）》及《融安县现代特色农业示范区增点扩面提质升级行动方案》精神，加快推进各级现代特色农业示范区创建工作，涌现出一批要素集中、产业集聚、技术集成、经营集约的现代特色农业示范区，为推进我乡农业转型升级、加快发展现代农业起到了很好的示范带动作用。

为激励先进、树立典型，乡人民政府组织专家组对2019年各村申报的现代特色农业村级示范点进行考评，根据考评结果，经乡人民政府同意，决定授予桥板乡阳山村柑橘种植示范点等4个示范点“桥板乡现代特色农业村级示范点”称号。

希望获得“桥板乡现代特色农业村级示范点”称号的示范点进一步深化经营组织化、装备设施化、生产标准化、要素集成化、特色产业化，争创乡级示范园，并在不断提升示范点发展水平的同时，加快带动拓展区、辐射区农业发展、农民增收、农村建设。各村委、各相关部门要认真总结推广现代特色农业示范点建设经验，进一步解放思想，加大改革创新力度，扎实推进我乡现代特色农业示范园建设工作。

附件：2019年桥板乡现代特色农业村级示范点名单

桥板乡人民政府
