# 融审字〔2020〕3号关于成融安县审计局2019年年度考核委员会的通知

局属各股室、投资中心：

为加强对我局干部职工年度考核工作的组织领导，规范年度考核工作程序，确保年度考核工作客观公正、注重实绩。根据县委组织部《关于做好2019年度全县机关年度考核工作的通知》（融组通〔2020〕15号）的要求，经局党组研究，决定成立融安县审计局2019年年度考核委员会，具体名单如下：

主  任：覃启辉     局党组书记、局长

副主任：葛时波     局党组成员、副局长

肖勇发     局党组成员、副局长

委  员：戴吉红     办公室主任

秦雪婷     财政金融审计股长

杨艳欢     政府投资项目审计中心主任

黄  勇     政府投资项目审计中心审计员

考核委员会负责考评融安县审计局2019年度在职在编干部职工年度考核工作。考核委员会下设办公室，由戴吉红同志兼任办公室主任，负责年度考核的具体实施工作。

融安县审计局

2020年2月26日
