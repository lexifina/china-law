# 2019—2020年融安金桔产业贷款贴息扶持办法

根据《融安县人民政府办公室关于印发《融安县金桔产业发展工作实施方案（2019-2020年）》的通知》（融政办发〔2018〕142 号）、《中共融安县委办公室 融安县人民政府办公室关于印发《融安县清理柑橘黄龙病病树改种融安金桔补贴方案（2019—2020年）》等14个方案的通知》（融办发〔2019〕34号）中《融安金桔种植贴息贷款管理办法（试行）》精神，为充分发挥财政资金的杠杆和撬动作用，带动更多社会资金投入金桔产业，推动融安金桔产业转型升级，加快桂北特色水果产业带建设，实现产业富民的目标，制定本扶持办法。

一、扶持对象

（一）金桔产业贷款对象。具有良好信用，无金融机构历年不良欠款、遵守国家法律和有关法规，年龄在60岁以内，身体健康，具有完全民事行为能力的自然人或国家规定可以作为借款人的农业经营主体，非自然人贷款对象应为在融安注册登记的涉农企业、农民合作组织和家庭农场。

（二）申请贴息贷款的条件及申请时间。2019－2020年新种滑皮金桔、脆蜜金桔自然连片10亩以上，通过种植第二年复核验收并获得奖补的农业企业、农民专业合作社、家庭农场和种植大户。2019－2020年新种植户申请贴息贷款时间截止2021年12月31日。

二、贷款申请程序、用途和方式、利率、额度及期限

（一）贷款申请程序。符合贷款条件的对象到所在乡（镇）人民政府填写贷款申请书和申请表（详见附件2、附件3），各乡（镇）于每月25日前完成初审后，将贷款申请统计表（详见附件4）和申请材料送县农业农村局审核，县农业农村局审核后送县财政局审查，县财政局于10个工作日内完成实地审查，并以书面形式完成审批，通过审批的贷款申请，由县财政局直接送融安农村商业银行办理贷款调查等审查事项。融安农村商业银行对贷款申请进行独立审查，符合放款条件的申请人，由融安农村商业银行与贷款申请人签订贷款协议，办理放款手续。

各乡（镇）同时向融安农村商业银行当地营业网点报送当月贷款申请统计表，由融安农村商业银行对贷款申请先行受理审查。

（二）贷款用途。金桔产业贷款主要用于生产性开支，包括果园基础设施建设、土地流转费用、农机设备购置、种植管理和农资等支出，不得用于消费性支出。贷款用途在贷款合同中约定，由贷款银行负责监督借款人的借款用途。

（三）贷款方式、利率、额度及期限。参见金桔产业贷款合作协议书（详见附件1）。金桔产业财政贴息贷款执行年利率4.75%，贷款额度最高为每亩6000元，贷款资金按分期发放，贷款第一年每亩发放3000元，第二年每亩再发放3000元。贷款最高本金限额不超过50万元。贴息年限最长为4年，贴息每年结算1次，每年年底经验收合格后给予贴息。贴息贷款到期，种植户负责向银行还清贷款。

三、利息支付及贴息办法

（一）利息支付。借款人根据贷款合同约定，按合同银行结息周期偿还贷款利息。

（二）财政贴息。融安农村商业银行以季度为周期统计借款人的相关贴息材料，送县农业农村局审核；县农业农村局按程序向县人民政府请款后，将贴息资金拨入借款人账户。

（三）贴息额度及期限。在批准的贴息贷款期限及额度内按执行年利率4.75%进行贴息。借款人贷款额度未达到6000元/亩的，按实际贷款额度贴息；借款人贷款期限未达到最高贴息期限4年的，按实际贷款年限贴息。罚息和逾期利息由借款人自行负担。

四、贷后管理

各乡（镇）人民政府和县农业农村局要配合融安农村商业银行，加强金桔产业贷款用途监督，定期核查借款人果园建设和管理情况，确保贷款用于金桔产业生产性开支。对将贷款用于非生产性开支的借款人，立即取消其贷款财政贴息。县财政局要加强贴息资金监管，定期检查贴息资金使用、拨付和管理情况，确保资金安全和专款专用。

五、本办法自印发之日起实行，融安县人民政府关于印发《2017—2020年融安金桔产业贷款贴息扶持办法》的通知（融政发〔2017〕5号）同时废止。

甲方：广西融安农村商业银行股份有限公司

为加快融安县金桔产业的发展，充分发挥财政性资金的引导带动作用，探索新的支农惠农方式，切实增加对金桔产业的资金投入。经双方友好协商，达成如下合作协议：

一、合作内容

甲方在符合国家金融政策和融安农村商业银行信贷管理规定的条件下，向融安县内金桔种植业主发放贷款。

（一）贷款对象的确定

扶持对象为滑皮金桔、脆蜜金桔等种植业主。甲方接到借款申请人的借款申请后，按自身业务管理规定独立开展贷款“三查”工作，并最终决定是否发放贷款。在手续、资料齐全的情况下，7个工作日内发放贷款。

（二）贷款方式、规模及期限

1.抵押贷款。即借款人在取得贷款时需提供符合甲方要求的抵押物。贷款额度为每亩6000元以内，期限4年以内。

2.小额保证贷款。即借款人在取得贷款时需提供符合甲方要求的保证人担保，且保证人负连带责任，或者采取互助金担保方式。贷款额度为每亩6000元以内，期限4年以内。

3.联保小额贷款。即借款人在取得贷款时需提供符合甲方要求的3至5人组成联保小组，小组成员相互承担连带保证责任。贷款额度为每亩6000元以内，期限4年以内。

4.信用贷款。即借款人在取得贷款时无需提供任何担保。贷款额度为每亩6000元以内，期限4年以内。

借款人可选择以上任何一种方式获得贷款，甲方也可根据借款人的信用程度、经营规模、综合还款能力等实际情况要求借款人以抵押、保证或联保的方式办理贷款手续。

贷款原则上不允许展期。

（三）贷款利率及利息支付

贷款利率按年利率4.75%执行，利率变更方式为固定不变。贷款利息实行按季结息，由借款人按照贷款合同约定存入结算账户，由甲方于结息日进行扣划。

（四）财政贴息利率及范围

在县财政局批准的贷款期限及额度内，按借款合同约定的贷款执行利率计算贴息。罚息和逾期利息由借款人自己负担。

贴息按季结算，利息先由借款人按照贷款合同的约定自己先行支付，甲方按季度进行汇总并提供相关凭据给县农业农村局，经审核无误后20个工作日内存入借款人账户。

（五）加大宣传动员工作力度

各乡镇、各单位要通过各种方式，大力宣传“融安金桔产业贷款”和“融安金桔产业贷款财政贴息”的重要意义、申请条件和办理程序，融安农村商业银行各营业网点要摆放相关宣传材料，对“融安金桔产业贷款财政贴息”的扶持对象、贷款程序及优惠条件进行介绍，供广大客户查阅。

二、权利及义务

（一）县农业农村局有义务指导种植业主用好信贷资金，发展生产，并及时向甲方通报贷款户的情况。如贷款户有不良贷款行为，乙方有义务协助甲方对贷款户进行调查、了解，配合好贷款的收回。

（二）若贷款无法回收，造成的贷款损失由甲方承担，乙方不承担责任。

三、其它事项

（一）本协议有效期六年，从2020年1月1日起至2025年12月31日止。

（二）合作过程中如有异议或因市场、种植条件变化需要对原协议条款进行修订或补充的，双方应以协商方式解决，协商一致后可签订补充协议，补充协议与本协议具有同等法律效力。同时，本协议履行过程中产生的异议不影响甲方和借款人已经签订的借款合同的履行。

（三）本协议书一式四份，甲乙双方各持两份，具有同等法律效力。自双方签字盖章之日起生效。
