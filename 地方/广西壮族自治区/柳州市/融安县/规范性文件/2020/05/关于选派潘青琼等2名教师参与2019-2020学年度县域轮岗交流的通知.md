# 关于选派潘青琼等2名教师参与2019-2020学年度县域轮岗交流的通知

各乡（镇）中心校、中学，县直各校、局二层机构：

为推进县域教师轮岗交流，合理配置教师资源，促进城乡教育均衡发展。根据《关于做好2019-2020学年度柳州市中小学市级支教轮岗和县（区、新区）域内教师轮岗交流工作的通知》（柳教人〔2019〕98号）和关于印发《融安县中小学教师队伍轮岗交流工作方案（2019-2020）的通知》（融教字〔2019〕78号）要求，经本人申请及资格审核，决定选派潘青琼等2名教师参加2020年春季学期轮岗交流工作，轮岗交流时间：2020年5月10日至2020年7月31日止。
