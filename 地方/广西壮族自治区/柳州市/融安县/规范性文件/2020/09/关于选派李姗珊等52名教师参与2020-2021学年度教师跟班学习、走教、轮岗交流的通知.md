# 关于选派李姗珊等52名教师参与2020-2021学年度教师跟班学习、走教、轮岗交流的通知

各乡(镇)中心校、中学，县直各校，局二层机构：

为推进县域教师轮岗交流，合理配置教师资源，促进城乡教育均衡发展。根据《关于做好2020-2021学年自治区及柳州市中小学教师支教走教工作的通知》（柳教人〔2020〕46号）和《自治区教育厅关于组织开展2020-2021学年广西优秀退休教师乡村支教工作的通知》（桂教教师〔2020〕19号）要求，经各学校推荐及资格审核，决定在2020-2021学年度选派李姗珊等6名教师参与柳州市城中区跟班学习（见附件1）；选派罗艳诗等16人参与“三区”走教（见附件2）；选派蓝有科等 28人参与县域内学校轮岗交流（见附件3）；选派肖集梅等2人参与广西优秀退休教师乡村支教（见附件4）。

请各学校及时通知参与跟班学习、走教、轮岗交流的教师于9月7日前到位，并做好交流教师的工作交接和后勤保障工作。

附件：1. 选派参与柳州市城中区跟班学习教师名单

2. 选派参与“三区”走教教师名单

3. 选派参与县域内学校轮岗交流教师名单

4. 选派参与广西优秀退休教师乡村支教教师名单
