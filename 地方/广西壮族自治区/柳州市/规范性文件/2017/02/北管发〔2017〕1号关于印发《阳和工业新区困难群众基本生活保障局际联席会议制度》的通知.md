# 北管发〔2017〕1号关于印发《阳和工业新区困难群众基本生活保障局际联席会议制度》的通知

各有关单位：

为全面贯彻落实国务院第162次常务会议以及《民政部关于贯彻落实国务院第162次常务会议精神做好困难群众基本生活保障有关工作的通知》（民电〔2017〕6号）和《自治区民政厅转发民政部关于贯彻落实国务院第162次常务会议精神做好困难群众基本生活保障有关工作的通知》（桂民电〔2017〕3号）文件精神，进一步做好新区困难群众基本生活保障有关工作，现制定《北部生态新区困难群众基本生活保障局际联席会议制度》，请各成员单位认真贯彻落实。

附件：北部生态新区困难群众基本生活保障局际联席会议制度成员名单

柳州市北部生态新区管理委员会

2017年2月23日

北部生态新区困难群众基本生活保障

局际联席会议制度

为进一步做好困难群众基本生活保障工作，贯彻落实国务院第162次常务会议精神做好困难群众基本生活保障有关工作要求，加大力度对城乡低保对象、受灾群众、特困人员、孤儿和监护缺失的未成年人、贫困残疾人和重度残疾人、生活无着落流浪乞讨人员、困难优抚安置对象等各类困难群众进行救助。经研究决定，建立新区困难群众基本生活保障局际联席会议制度。

一、主要职能　　在新区管委会领导下，研究拟订完善困难群众基本生活保障的重要制度、政策、体制和机制，定期研究解决新区城乡低保对象、受灾群众、特困人员、孤儿和监护缺失的未成年人、贫困残疾人和重度残疾人、生活无着落流浪乞讨人员、困难优抚安置对象等各类困难群众基本生活保障问题，推动有关困难群众保障政策落实到困难群众身上；统筹做好最低生活保障与医疗、教育、住房等其他社会救助政策以及促进就业、扶贫开发政策的协调发展和有效衔接；加强部门配合，研究解决救助申请家庭经济状况核对跨部门信息共享问题，使困难群众基本生活保障工作更加及时、公正、有效，让广大困难群众得到社会救助的温暖和关怀；督导推进新区社会救助体系建设；完成管委会交办的其他事项。

二、成员单位　　联席会议由社会事务局、经济发展局、财政局、人力资源和社会保障局、规划建设环保局、柳东公安分局、社会管理综合治理委员会、党群工作部、总工会、阳和街道办事处等10个部门和单位组成。管委会分管民政工作的副主任担任联席会议召集人，各成员单位有关负责同志为联席会议成员（名单附后）。联席会议可根据工作需要，邀请其他相关部门参加。联席会议成员因工作变动需要调整的，由所在单位提出，联席会议确定。联席会议办公室设在社会事务局，承担联席会议的日常工作。联席会议设联络员，由各成员单位有关科室的负责同志担任。

三、工作规则　　联席会议原则上每年召开一次例会，由召集人或召集人委托的同志主持。根据新区管委会领导同志指示或工作需要，可以临时召集会议。在联席会议召开之前，召开联络员会议，研究讨论联席会议议题和需提交联席会议议定的事项。重大问题需经联席会议讨论后，由新区管委会报市人民政府决定。四、工作要求

各成员单位要按照职责分工，主动研究困难群众基本生活保障工作有关问题，及时向管委会提出需联席会议讨论的议题，认真落实联席会议确定的工作任务和议定事项，及时处理困难群众基本生活保障工作中需要跨部门协调解决的问题。各成员单位要互通信息，相互配合，相互支持，形成合力，充分发挥好联席会议的作用。
