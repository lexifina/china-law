# 阳管发〔2017〕43号柳州市阳和工业新区管理委员会关于印发柳州市阳和工业新区百企入村帮扶工程工作实施方案的通知

园区各企业：

现将《柳州市阳和工业新区百企入村帮扶工程工作实施方案》印发给你们，请结合文件内容，认真遵照执行。

柳州市阳和工业新区管理委员会

2016年6月9日

柳州市阳和工业新区管委办    2017年6月9日印发

柳州市阳和工业新区百企入村帮扶工程工作实施方案

百企入村结对帮扶工程实施六年来，在新区企业的大力支持下，成果不断得到发展壮大，每年都有新的企业加入，捐款数额逐年增加，受助群体逐渐扩大，逐步形成了阳和工业新区“以工带农，工业反哺农业，和谐共进全面建成小康社会，维护社会稳定，促进经济发展，打造和谐阳和”的良好局面。现结合新区实际情况，特制定本方案。

一、目标任务

以工业的快速发展带动农村的生产发展为总体目标，在大力发展工业的基础上，帮助和扶持三农发展。引导园区企业在正常的生产经营基础上，强化社会责任，在资金和就业方面，给困难的村屯、农户、贫困学子予以支持和帮助。

（一）开展企业结对子帮扶工程，资助困难家庭中的大学生完成学业；针对各村大中专毕业生和待业青年，由园区企业提供相应岗位，帮助实现就业和再就业。

（二）结合浙江万向系统慈善基金会“四个一万工程”，帮扶新区孤儿成长、特困生读书、残疾儿童生活及孤寡老人养老。帮助阳和、社湾、六座三个村开展“美丽阳和?生态乡村”工作，完成相应的基础设施建设，改善村民生活环境。

三、实施方案

（一）充分调动，号召企业。召开百企入村帮扶工程企业座谈会，向到会企业说明上一年度善款使用情况（详见附件1、附件2），并与企业一同探索政企联合帮扶的新模式，同时号召园区更多的企业参与帮扶，充分调动企业的积极性。善款筹集期限为座谈汇报会后的十天内。（捐款账户信息：柳州市阳和工业新区招商服务中心；开户行：柳州银行阳和支行；账号：7050 6015 2011 1000 0401）

（二）深入调研，摸清情况。根据新区帮扶工程目标，联合各村委会展开全面工作，对新区六座、社湾、阳和三个村村民子女待业情况、困难村民子女入学情况、特困村民生活保障情况、各个村屯基础设施建设情况等进行深入细致的摸底调查，建立村民待业子女、村民子女就学情况、特困村民生活保障和各村屯基础设施建设情况的电子档案，做到村民子女待业人数清、技能特长清、就业需求清、入学困难村民人数清、致困原因清、困难程度清、基础设施情况清。

（三）感恩企业，学子回报。（时间：学生暑假期间）

接受企业捐款帮扶的贫困学子，与企业签订双方《帮扶捐助协议》。按照协议约定，当年受助学子，次年暑假须到捐助企业进行实习，实习内容则由企业安排，实习事宜由阳和管委会负责监督和跟进。

（四）政企扶持，共同捐助。为了解决群众实际困难，加强与群众的联系，进一步深化服务群众的意识，管委会今年继续采取政企扶持的方式，将从“百企入村帮扶工程”项目经费中出资5万元，与新区企业一并进行助学帮困。

（五）阳光操作，加强监督。坚持公平、公正、公开的原则，实行阳光操作。对接受援助的家庭及个人基本情况和援助的企业名称以及该企业援助的方式，均统一进行公示和汇报，接受群众监督。对帮助对象实施动态管理，保证真正困难的村民能得到实实在在的帮助。

（六）总结经验，拓展帮扶。积极拓展帮扶新形式，由经济帮扶转变为思想帮扶，帮助贫困户转变思想观念，企业鼓励、带领和指导贫困户以及农村有志青年进行自主创业，帮扶活动由助学、助贫、助残逐步拓展到帮助农村改善基础设施，搞活农村文化建设以及解决农村富余劳动力等方面，让群众能够彻底摆脱贫困。
