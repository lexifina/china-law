# 关于转发《自治区住房城乡建设厅关于严防“地条钢”死灰复燃的通知》的通知

各有关单位：

现将《自治区住房城乡建设厅关于严防“地条钢”死灰复燃的通知》（桂建质〔2018〕15号）转发给你们，请严格按照文件要求贯彻落实。自治区住建厅将把是否开展自查自纠活动、是否建立钢材进场台账、是否有“地条钢”进入工地现场作为2018年的全区层级监督检查、第二次工程质量安全监督检查的重点检查内容之一，请各单位做好迎检准备。

各施工、监理企业将本文转发到项目部，按照要求落实自查自纠、问题整改；各检测机构加强对进场钢材的检测核查；市质监处要加大巡查力度，发现使用“地条钢”的项目要立即责令整改；各县区住建局、柳东建设局要按照文件落实本辖区内的防范打击工作。市质监处、各县区住建局、柳东建设局对监管中发现使用“地条钢”的项目要及时将有关情况上报我委。
