# 关于评标专家王娇、梁柳林、陈婷的处理决定

房屋建筑和市政基础设施工程评标专家王娇（身份证号450203********0741）、梁柳林（身份证号450205********0028）、陈婷（身份证号610103********2867）因在河池市参加广西现代职业技术学院综合楼建设工程监理服务项目评标时，未按招标文件规定的评标标准和方法评标，动态考核均扣15分，于2018年7月3日被河池市住房和城乡建设局发文通报批评（河住建〔2018〕158号），造成不良影响。现根据《柳州市房屋建筑和市政基础设施工程评标专家考评办法》中“参加异地评标被当地招投标监管部门记录不良行为的考核扣20分”、“评标专家在一个计分周期内一次被扣20分的，暂停12个月评标资格”的规定，决定对王娇、梁柳林、陈婷管理考核均扣20分，并自2018年7月6日起在全市暂停十二个月评标专家资格。

柳州市住房和城乡建设委员会

2018年7月5日
