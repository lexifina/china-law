# 北管发〔2018〕41号柳州市北部生态新区（阳和工业新区）管理委员会关于北部生态新区（阳和工业新区）本级广告服务实行定点管理的通知

北部生态新区（阳和工业新区）各预算单位，各政府采购定点供应商：

为规范政府采购行为，提高政府采购效率，减少采购环节，根据《中华人民共和国政府采购法》、《中华人民共和国招标投标法》和《广西壮族自治区财政厅关于公布2018-2019年广西政府集中采购目录及限额标准的通知》（桂财采〔2017〕26号）等有关规定，结合北部生态新区（阳和工业新区）实际需求，我委通过公开招标方式确定了北部生态新区（阳和工业新区）广告服务定点供应商，确定了本期招标采购的中标定点供应商及让利幅度（详见附件）。现将有关事项通知如下：

一、广告服务定点采购的适用范围、采购限额标准和有效期

（一）定点采购的适用范围及采购限额

北部生态新区（阳和工业新区）本级各预算单位所涉及的广告服务凡年度政府采购计划单项预算金额或批量预算金额在50万元以下（不含50万元）采购的，实行定点采购；在各中标定点供应商中进行选择确定。

（二）广告服务采购范围包括：户外画布制作安装、板报、海报设计制作、门牌、条幅制作、室内外广告制作、安装、维护、拆卸等。

（三）定点采购的有效期限

广告服务定点供应商及让利幅度的有效期限为2年，自2018年9月1日起至2020年9月1日止(有效期内如遇政策调整的，按调整后的政策执行）。有效期内各采购人与定点供应商签订的合同至2018年9月1日前仍未执行完毕的，该合同约定的期限内继续有效。

二、广告服务定点供应商采购的程序

（一）采购人根据批复的政府采购预算，编制政府采购计划，并报财政局备案。

（二）采购人凭已备案的政府采购计划，按以下要求确定定点供应商：

广告服务一次批量采购金额在50万元以下（不含50万元）的，由采购人按照公布的定点供应商及联系方式，与供应商联系，通过充分洽谈价格和货比三家的方式，选择相应定点供应商，并确定采购价格（不能高于中标优惠价格）。一次批量采购金额在50万元以上的，需要按政府采购程序委托政府采购代理机构通过其他采购方式进行采购。

（三）合同书备案

采购人或者定点供应商在双方签订合同书后的五个工作日内，将合同书报送新区财政局备案（合同书需附上该项目的中标通知书）

（四）定点供应商按合同要求提供货物和服务。

（五）采购人组织履约验收。

（六）资金结算：采购人按合同验收货物后，按照现行国库集中支付管理有关规定，自行与定点供应商结算。结算时，定点供应商必须出具正式销售发票。

三、监督管理

（一）各采购人要充分利用定点供应商承诺的优惠率和中标价格，获取更高的优惠率或更低的价格及优质的服务；合同签订并验收合格后，应按时办理费用支付的手续；不得借政府采购之名为非本部门或个人采购定点货物或服务，不得向定点供应商提出超出定点合同规定的其他要求。

（二）定点供应商必须在每季度的前五个工作日内，以书面和电子邮件的方式向新区财政局提交最新报价，要求明确列明出厂标准配置、备品备件、选配改配件、增减配置基准价格和优惠后折扣率及优惠价（最高限价）；中标供应商未按要求提供的，本季度视为自动放弃该季度的定点供应商供货资格。（联系电话：0772-3512901，邮箱地址：yhqczj2003@163.com）

（三）新区财政局将不定期检查各定点供应商或向采购人征求各定点供应商的履约及服务情况，若发现定点供应商有下列行为的，将作为下一期北部新区（阳和工业新区）定点采购评判的依据之一。

1.无正当理由拒绝供货，遭采购人投诉的；

2.擅自抬高货物的市场价或未按中标价格优惠率给予优惠的；

3.未能按约定及时或指定地点供货的；

4.提供的货物或服务不符合招标文件要求和投标文件承诺的；

5.不按时向采购人开具正式的销售发票的；

6.不按时报送季度最新报价的；

7.向采购人提供回扣或其他不正当利益的；

8.弄虚作假，拒绝接受相关部门监督检查的；

9.因违法违规被行业主管部门取消经营资格的；

10.有其他违法违规行为的。
