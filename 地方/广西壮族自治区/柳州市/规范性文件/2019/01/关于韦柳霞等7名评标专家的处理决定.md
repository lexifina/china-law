# 关于韦柳霞等7名评标专家的处理决定

柳州市公共交通配套工程（一期）PC轨道梁预制场（二期）项目在办理招标投标书面情况报告备案时，我委招标办发现评标专家韦柳霞、梁崇宏、李凤新、陈策、刘宁生、赵泽霞、邹卫东编写的评标报告内容不完整，未记录联合体投标人信息。根据《柳州市房屋建筑和市政基础设施工程评标专家考评办法》（柳建管字〔2018〕5号）附件2评标专家管理考评评分表第2点“各级抽查、检查、备案中发现评标报告的编写不认真或内容不完整的，扣3分”的规定，决定对韦柳霞、梁崇宏、李凤新、陈策、刘宁生、赵泽霞、邹卫东等7名评标专家管理考核扣3分。

柳州市住房和城乡建设委员会

2019年1月25日
