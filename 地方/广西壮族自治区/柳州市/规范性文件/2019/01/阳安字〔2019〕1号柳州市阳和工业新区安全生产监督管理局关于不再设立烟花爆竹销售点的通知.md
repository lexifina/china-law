# 阳安字〔2019〕1号柳州市阳和工业新区安全生产监督管理局关于不再设立烟花爆竹销售点的通知

各有关部门、企业：

根据《柳州市人民政府关于确定禁止燃放烟花爆竹时段、区域的通告》（柳政规〔2019〕2号）的文件规定，2019年起阳和工业新区纳入柳州市烟花爆竹禁放区域，从即日起至新规定出台之日，柳州市阳和工业新区范围内不再设立烟花爆竹销售点（包括长期点和临时点），特此通知。
