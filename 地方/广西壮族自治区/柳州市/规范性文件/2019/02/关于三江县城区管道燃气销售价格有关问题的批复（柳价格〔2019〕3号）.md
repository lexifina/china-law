# 关于三江县城区管道燃气销售价格有关问题的批复（柳价格〔2019〕3号）

三江县物价局：

你局报来《关于调整三江县城区管道天然气销售价格的请示》(三江报〔2017〕7号)收悉。根据《广西壮族自治区物价局关于印发〈广西壮族自治区定价目录〉的通知》（桂价综〔2018〕25号）、《广西壮族自治区物价局关于建立居民生活用气阶梯价格制度和长输管道天然气门站价格与居民生活用气价格联动机制问题的通知》（桂价格〔2015〕101号）及《广西壮族自治区物价局关于管道燃气配气价格管理及有关问题的通知》（桂价格〔2018〕112号）的有关规定，经研究，对三江县城区管道燃气销售价格有关问题批复如下:

一、配气价格

1.居民用气配气价格最高不超过1.52元/立方米。

2.非居民用气综合配气价格最高不超过1.52元/立方米。即按年度计算，燃气企业非居民各类用气综合加权平均配气价格不得超过1.52元/立方米。

二、居民生活用气销售价格

1.居民生活用气实行阶梯价格制度，第一档用气价格为4.2元/立方米。

2.建立居民生活用气价格联动的机制，以2016年12月22日柳州市价格成本调查监审分局《三江县燕钧天燃气有限责任公司天然气成本监审报告》（柳价成字〔2016〕23号）审核的燃气加权平均购进价格2.61元/立方米（含运价不含税）为联动基准价格。

3.特殊用户。对学校、养老福利机构（经民政部门批准设置的）等执行居民气价的非居民用户，暂不实行阶梯气价，气价水平按当地居民第一档、第二档气价平均水平，即现行居民生活用气价格的1.1倍执行。以上价格均保留到分，分以下四舍五入。

三、管道燃气销售价格联动

管道燃气销售价格联动按照《广西壮族自治区物价局关于管道燃气配气价格管理及有关问题的通知》（桂价格〔2018〕112号）有关规定执行。燃气企业要按规定将价格调整情况报价格主管部门备案。

四、其他事项按照《广西壮族自治区物价局关于建立居民生活用气阶梯价格制度和长输管道天然气门站价格与居民生活用气价格联动机制问题的通知》（桂价格〔2015〕101号）和《广西壮族自治区物价局关于管道燃气配气价格管理及有关问题的通知》（桂价格〔2018〕112号）有关规定执行。

上述批复从2019年4月1日起开始执行。执行过程中遇到问题，请及时反映。
