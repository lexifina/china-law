# 北管发〔2019〕2号关于印发《柳州市北部生态新区（阳和工业新区）深入推进诚信建设制度化实施方案》的通知

各局、办，阳和街道办，各派驻机构：

根据国务院《社会信用体系建设规划纲要（2014—2020年）》、中央文明委《关于推进诚信建设制度化的意见》、自治区文明委《关于推进广西诚信建设制度化的实施意见》和市委文明委《柳州市深入推进诚信建设制度化实施方案》的工作要求，现将《柳州市北部生态新区（阳和工业新区）深入推进诚信建设制度化实施方案》印发给你们，请结合实际认真组织实施。

柳州市北部生态新区管理委员会

2019年1月26日

政府信息公开选项：主动公开

柳州市北部生态新区办公室                    2019年1月26日印发

柳州市北部生态新区（阳和工业新区）深入推进

诚信建设制度化实施方案

为认真贯彻习近平新时代中国特色社会主义思想和党的十九大精神，进一步落实国务院印发的《社会信用体系建设规划纲要（2014－2020年）》，大力培育和践行社会主义核心价值观，全面推进法治社会建设，深入推动新区诚信建设制度化、规范化、长效化，结合新区实际，制定本方案。

一、指导思想

高举中国特色社会主义伟大旗帜，以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，深入学习贯彻党的十九大精神，以培育和践行社会主义核心价值观为主要目标，以加强社会信用体系建设为基础，以创建国家文明城市为抓手,以褒扬诚信、惩戒失信为重点，以形成有利的社会舆论为推动，进一步推动完善信用法规制度建设,建立健全守信受益和失信惩戒机制,不断完善长效工作机制和运行机制。

二、工作目标

通过大力推进诚信建设制度化，切实加强政务诚信、商务诚信、社会诚信和司法公信建设，力求在治理重点领域、解决突出问题上有新突破，在激励守信、惩戒失信上有新成效，全社会诚信意识普遍增强，长效工作机制和运行机制不断建立完善，守信光荣、失信可耻的舆论环境、经济环境、社会环境进一步形成。

三、工作原则

坚持以人为本、教育为先，把培育诚信价值观念作为长期任务；坚持制度保障、规范约束，把推进征信系统全覆盖作为重要基础；坚持德法并举、刚柔相济，把道德教化与依法制裁作为有效手段；坚持政府有力推动、企业主动作为、社会共同参与、公民普遍响应，把政府、企业和社会力量汇集于推进诚信建设各方面各环节；坚持问题导向、集中治理，把不断取得阶段性成果作为回应人民群众关切的重要标志，力求在治理重点领域、解决突出问题上求突破，在激励守信、惩戒失信上见实效，使全社会诚信意识普遍增强，诚信风尚日益形成，诚信体系日益完善。

四、工作任务

（一）推进四大领域诚信管理制度建设

新区要在政务诚信、商务诚信、社会诚信、司法公信四个领域建立健全系统完备、科学规范、运行有效的制度。

一要建立政务诚信制度。以提高政府部门诚信形象为根本，加强政府诚信建设。建立健全政务和行政承诺考核制度，严格履行政府向社会作出的承诺，将社会信用体系建设纳入政府绩效考评指标体系。积极推进重大事项公示和听证制度，提高决策和施政透明度，加强对权力运行的社会监督和约束。

二要建立商务诚信制度。建立安全生产、流通领域、金融领域、税务领域、价格领域、工程建设领域、政府采购领域、招标投标领域、交通运输领域、电子商务领域、统计领域、中介服务领域、会展广告等领域诚信管理制度，推动和督促企业落实社会主体责任。大力推进企业信用等级分类管理制度，实施企业信用评价结果与审批审核事项关联应用，引导企业诚信经营。

三要建立健全社会诚信制度。加快完善医药卫生、教育科研、社会保障、知识产权、社会组织和自然人等方面的信用制度建设。建立健全职业信用报告制度，把诚信作为食品、医药卫生等与人们生活密切相关行业执业资格准入的基本要求，引导从业人员讲求职业操守、恪守诚信规范。

四要建立司法公信制度。加强市公安局柳东分局、司法所的公信建设和从业人员的信用制度建设，逐步完善司法管理体制和司法权力运行机制，推进司法公开，加强对司法活动的监督。建立健全责任追究机制，深入推行“阳光办案”“阳光司法”，努力让人民群众在每一个司法案件中感受到公平正义。

（二）大力推进诚信奖惩制度建设

新区各部门要建立健全诚信奖惩制度，努力形成褒扬诚信惩戒失信、守信光荣失信可耻的良好社会风尚。

一是建立政策导向机制。经发局在确定经济社会发展目标和发展规划时要把讲社会责任、讲社会效益、讲守法经营、讲公平竞争、讲诚信守约作为重要内容，形成有利于弘扬褒奖诚信的良好政策导向。

二是建立完善失信惩戒机制。要按照失信类别和程度，综合运用经济、行政、社会管理等多种手段，建立多部门、跨地区的联合惩戒措施。建立各行业黑名单和市场退出机制，使失信者在注册登记、金融信贷、招标投标、就业消费、交通出行等方面受到限制，提高失信成本。

（三）大力推进诚信发布制度建设

各行业主管部门要积极推动本行业依据法律法规，按照客观、真实、准确的原则，建立诚信红黑名单制度，把恪守诚信者列入“红名单”，把失信违法者列入“黑名单”，发布失信惩戒措施。在法院等部门发布失信被执行人名单的基础上，要逐步扩大诚信发布制度的实施范围，发布食品药品安全、企业产品质量、环境安全、人力资源社会保障、纳税情况、债务偿付情况等方面的“黑名单”，对列入“黑名单”的失信者，要共同依法实施惩戒。同时，对以上几个方面依法经营、诚信守信的单位，要列入“红名单”，并定期向社会公布，逐步形成扬善抑恶的制度机制和社会环境。

（四）培育和规范信用服务市场

发展各类信用服务机构，引进国内外知名信用服务机构，培育发展本土信用服务机构，逐步建立多层次、全方位的信用服务组织体系。推动政府部门在社会管理和公共服务领域带头使用信用产品和服务，鼓励金融机构、企事业单位和个人利用信用产品和服务防范信用风险。大力支持信用服务产品开发和创新，推动信用保险、信用担保、商业保理、履约担保、信用管理咨询及培训等信用服务业务发展。加强对信用服务市场的全面监管，形成政府监管、市场监管和社会监督有机结合。加强信用服务机构自身建设，强化内部控制，全面提升信用服务机构诚信水平，推动建立信用行业自律组织。加快信用人才培养，大力开展面向信用从业人员的专业培训，支持有条件的高校开设信用管理专业。

（五）完善诚信监督体系建设

坚持行政监管、行业管理、社会监督相结合，努力构建多层次、全过程、广覆盖的监督体系，对各类社会信用主体实施有效监管，从源头上遏制失信行为。有关职能部门要针对失信易发多发的行业和领域，加大监管力度，提高监管效能。要适时邀请人大代表、政协委员深入生产企业、服务窗口、公共场所明察暗访，提出意见建议。行业协会等社会组织要发挥自律作用，加强服务和管理，对业内成员认真监督约束。要建立健全有奖举报制度，鼓励人民群众举报失信违规行为。大众传媒要积极开展建设性舆论监督，营造守信光荣、失信可耻的舆论氛围。对借舆论监督之名实施敲诈勒索的假新闻、假媒体、假记者，要及时发现，严肃查处，提高媒体公信力。

（六）大力开展突出问题专项整治

把长远制度建设和解决当前突出问题相结合，以解决当前突出问题为突破口，为长远制度建设创造有利条件。新区各部门要经常梳理、排查经济社会发展中不诚不信的突出问题，尤其是人民群众普遍关注的失信败德行为，有针对性地开展专项整治。食药所要严厉打击制售假冒伪劣、有毒有害食品药品的黑工厂、黑窝点、黑作坊、黑渠道，严惩重处食品药品违法犯罪；市工商局柳东分局要严厉打击各种非法传销活动，狠抓社会影响大、涉案地区广的大案要案；经发局要扎实推进“质监利剑”行动，严厉打击产品质量违法行为；市公安局柳东分局要严厉打击利用电话、网络诈骗犯罪行为，保护群众财产安全；党群部要深入推进整治网络谣言专项行动，抓一批重大案件，列出一批“黑名单”；规建局要将住房保障、市政设施破坏、不按要求建设等有关失信行为的个人和企业纳入社会诚信建设制度的内容。

（七）着力营造诚信建设的法治环境

深化法治宣传教育。深入宣传全面推进依法治国的重大意义，深入宣传法治建设的主要内容，健全普法宣传工作机制。结合落实新区普法工作规划，深入宣传合同法、产品质量法、食品安全法、环境保护法、消费者权益保护法、征信业管理条例等法律法规，弘扬社会主义法治精神，增强人们的尊法、学法、守法、用法意识。突出抓好法律法规学习培训，增强带头守法意识，提高依法行政能力。组织法律专业人员和志愿服务队伍深入村镇、社区、机关、学校、企业等城乡基层，普及诚信方面的法律知识，增强人民群众遵纪守法观念和依法保护自身权益的能力。

（八）切实加强诚信教育

要把诚信教育作为新区诚信建设制度化的基础工作，突出抓好重点领域、重点人群的诚信教育。

一是突出企业主体诚信教育。各类企业要开展全员诚信教育，建立职工诚信考核评价制度，使诚信成为企业职工的基本规范。经发局、投促局、行政审批局、市工商局柳东分局要把诚信教育作为对企业服务管理的重要内容，融入到证照颁发、业务办理的流程中，把守信履约要求作为对企业年度考评的重要依据。

二是抓好公共服务人员诚信教育。要深入开展公务员诚信、守法和道德教育。增强公务员法律和诚信意识，党员干部要以身作则，做守信的表率。认真贯彻政府信息公开条例，提高决策和施政透明度，提升政府公信力。引导医务人员崇尚服务理念，大力弘扬“医者仁心、救死扶伤”的医德。

三是抓好学校师生的诚信教育。坚持育人为本、德育为先，把诚信落实到教育教学和管理服务各环节。构建有效衔接的诚信教育体系，在各学校的德育课、思政课以及道德实践中强化契约精神教育、专题法制教育，研究建立学生诚信评价考核办法。建立和规范体现诚信内涵的礼仪制度，把诚信嵌入到开笔礼、毕业典礼等仪式中。切实加强师德建设，强化诚信执教、为人师表理念，以人格魅力为学生展示“行为世范”。依法依规严肃惩戒学术造假、论文抄袭、考试作弊等失信行为，引导师生以诚立身、诚信做人。

（九）广泛开展诚信主题实践活动

坚持教育引导、制度规范和实践养成相结合，运用生动有效的实践载体，引导人们把诚信理念转化为自觉行动。文明村镇、文明单位、文明社区、文明校园等群众性精神文明创建活动，要把诚信建设的要求贯穿到内容安排中、体现到工作各环节。党群部要运用好“道德讲堂”，讲好诚信故事，积极传播诚信理念和道德规范。各行各业要结合业务和生产经营实际，开展各具特色的诚信实践活动，引导人们立足岗位践行诚信规范。生产企业作为实体经济的基础环节，要以“质量第一”为主题，广泛开展“诚信做产品”活动。用规范的管理制度、精细的工艺流程、严格的质量标准，把诚信渗透在产品生产和售后服务的各个环节。特别是食品药品生产企业，更要树立以义取利的义利观，以诚敬之心，以高度负责的精神生产优质产品，让广大人民群众“吃得安全，用得放心”。商贸流通企业作为市场秩序的关键环节，要以“履约守信”为主题，开展诚信经营示范创建活动，倡导公平交易、以诚待人，构建诚信商业环境。市工商局柳东分局要开展“守合同重信用”企业公示活动。窗口部门作为直接服务人民群众的基层单位，要以“人民满意”为主题，开展“服务承诺”活动，用礼貌热情的态度、周到高效的工作，提供高质量服务，提升公众美誉度。

（十）大力营造“诚信建设万里行”宣传氛围

落实党中央、国务院、中央文明委关于社会信用体系建设的决策部署，厚植社会主义核心价值观，广泛动员新区各方面力量，大力开展“诚信建设万里行”主题宣传活动，进一步扩大社会信用体系建设影响力，推动社会信用体系建设纵深发展。

一是权威媒体资源全面集结，配合全市主要媒体及重点新闻网站统一开设“诚信建设万里行”专栏，在重要版面、重点时段及网站首页显著位置开展相关宣传报道。

二是信用建设进展全方位展示，配合各重要媒体、新闻网站将阐释诚信建设内涵、解读现行制度政策、介绍实践做法、剖析典型案例，通过新闻报道、言论评论、专题节目、微博、微信、微电影等形式，覆盖全市各领域各行业的新中式、全景式宣传报道。

三是正面宣传与舆论监督相结合，既围绕新区诚信建设情况大力宣传正能量、弘扬主旋律，又激浊扬清、惩恶扬善，聚焦群众反映集中的突出问题开展监督通报。

四是诚信建设宣传案例广泛征集，新区各领域各行业要充分挖掘诚实守信主体的感人事迹和鲜活案例，曝光电信诈骗、虚假广告、侵权假冒、非法集资等严重失信典型；梳理新区各领域各行业信用建设的成功经验和生动案例，积极宣传和推广信用建设好做法和创新亮点。

五、工作要求

（一）加强领导，完善机制

新区各部门要把诚信建设制度化摆上重要位置，贯穿到经济社会发展各领域，推动诚信建设与业务工作同部署同落实。坚持重点突破、整体推进，坚持持之以恒、久久为功，坚持落细落小落实，以诚信建设制度化的良好效果，构建诚实守信的经济社会环境。要建立相应的统分结合的工作机制，形成齐抓共管的良好局面。

（二）加强协调，凝聚合力

积极构建各部门共同推进、广大市民群众共同参与的诚信建设格局，形成齐抓共管、共建共享的良好局面。新区各部门要将诚信建设和部门工作职能相结合，制定推进诚信建设制度化的具体工作措施，明确时间表、路线图，抓紧抓实、抓出成效。建立工作台账，做好工作资料（方案、总结、宣传活动图片、视频等）的收集整理，并把相关资料报送党群部、经发局。为确保国家对城市“诚信建设万里行”宣传工作的考核，新区各部门每月定期上报“诚信建设万里行”宣传案例至经发局邮箱（yhjjj168@163.com），由经发局统一组织上报至市发改委。

（三）加强督办，严格考核

党群部将会同有关部门，建立健全诚信建设长效督办考核机制，加强对重点任务落实情况的检查督导，定期督查通报。严格考核奖惩，严肃执纪问责，确保工作落实落地。
