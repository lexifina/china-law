# 转发《自治区住房城乡建设厅关于切实做好2019年春节期间全区住房城乡建设系统安全生产和社会维稳工作的通知》

各有关单位：

为切实做好我市建设领域安全生产和社会维稳工作，确保节日期间社会和谐稳定，现将《自治区住房城乡建设厅关于切实做好2019年春节期间全区住房城乡建设系统安全生产和社会维稳工作的通知》（桂建管〔2019〕7号）转发给你们，请认真贯彻执行。

请各县区住建局、柳东建设局、北部生态新区规建局于2019年2月2日前将2019年春节值班安排表以电子版的方式报送至我委建管科（邮箱：200406jgk@163.com），联系人：卢理喆，联系电话：2828072。
