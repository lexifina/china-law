# 阳管发〔2019〕2号关于印发《阳和工业新区城市特殊困难家庭帮扶济困实施办法（试行）》的通知

各局、办，阳和街道办，各村委、社区：

现将《阳和工业新区城市特殊困难家庭帮扶济困实施办法》印发给你们，请认真贯彻实施。

柳州市阳和工业新区管委会

2019年2月1日

政府信息公开选项：主动公开

柳州市阳和工业新区办公室 　 2019年2月1日印发

阳和工业新区城市特殊困难家庭帮扶济困

实施办法（试行）

为切实做好阳和工业新区（以下简称新区）城市特殊困难家庭帮扶济困工作，保障其家庭共同生活成员的基本生活，根据《社会救助暂行办法》（国务院令第649号）、《关于印发<广西壮族自治区城乡困难群众院医疗救助暂行办法>的通知》(桂民发〔2013〕51号)、《柳州市城市居民最低生活保障实施办法》（柳政发﹝2012﹞54号）、参照《阳和工业新区脱贫攻坚教育帮扶实施方案》（阳管发〔2016〕61号）等文件精神和相关规定，结合新区实际制定本办法。

一、帮扶济困对象

凡患有广西壮族自治区认定的29种慢性病或27种重大疾病之一（疾病目录详见附件），且符合下列条件之一的：

（一）新区建档的城市低保、低收入家庭（以下简称城市特殊困难家庭），其共同生活的家庭成员在辖区范围内连续居住满一年的；

（二）截至2018年12月31日，在辖区内连续居住满一年的非新区户籍人口，且在户籍所在地是建档的低保、低收入家庭的。

二、帮扶济困措施

（一）医疗保障措施

1.为在新区范围内城市特殊困难家庭共同生活的家庭成员全额购买基本医疗保险（已投保的不再重复购买）。

2.在国家政策规定可报销的范围内，对经城乡基本医疗保险、大病保险、其他补充医疗保险、商业保险报销后剩余的部分给予报销，但全年报销金额累计不得超过30000元。

3.因行动不便且需医疗帮扶的，由阳和街道社区卫生服务中心及医疗志愿者定期上门服务。

（二）教育帮扶措施

1.学前教育阶段。子女在新区居住地就近入园的，除就读非普惠性幼儿园（指高于柳州市公立幼儿园收费标准30%以上的幼儿园）外，由新区给予每人每年2000元保育费补助。

2.义务教育阶段。子女在本辖区范围内的中、小学校上学的，由新区给予每人每年1500元生活补助。

3.普通高中、中职教育阶段。子女在本市范围内普通高中、中职学校上学的学生，由新区给予每人每年3000元教育补助。

4.高等教育阶段。对在全国普通高校（大专及大专以上学历院校）就读的，由新区给予每人4000元一次性生活补助。

（三）就业援助措施

1.设置便民服务点，安置有自主创业需求的帮扶济困对象摆摊经营。

2.开发新区公益性岗位，优先安排帮扶济困对象就业，做好就业指导工作。

3.落实就业再就业政策。依托新区人力资源市场，对符合条件的帮扶济困对象，优先办理就业失业登记证服务，优先提供职业介绍，优先提供就业援助服务等。

三、申请审批程序

（一）个人申请

凡符合申请城市特殊家庭帮扶济困条件的家庭，以户口簿户主为申请人，实际共同生活的家庭成员为整体，以书面形式向户籍所在地或长期居住地的社区居委会提出申请，并提交下列材料：

1.申请书；

2.居民户口簿、家庭成员居民身份证原件和复印件;

3.家庭成员患特殊重大疾病的提供县级以上医院近期（半年内）疾病证明或病历，并提供半年内因此并就医的发票；患特殊慢性病的提供县级以上医院签发的慢病卡、病历或医疗发票；

4.家庭成员中有残疾人的应提供残疾证，有失业人员的提供《就业失业登记证》；

5.家庭成员收入证明，包括单位出具的工资证明、领取养老金的证件或有关凭证、领取失业保险金的证件或失业保险机构出具的证明等;

6.在校生提供在校证明；

7.离异家庭需提供合法有效的离婚证件，离婚协议书或判决书；

8.独生子女家庭提供《独生子女父母光荣证》；

9.家庭成员名下所有银行账户半年内流水记录；

10.其它相关材料。

非新区户籍的低保、低收入家庭中非保障对象的申请人还需提交下列材料：

1.户籍所在地无房产、地产、或其他不动产的证明；

2.在户籍所在地未参与分红、无征地款的证明；

3.在户籍所在地为获得相同或相似帮扶的证明；

4.其他相关材料。

申请时应当以书面形式声明接受管理部门对其家庭的入户调查及其他方面的核查。

（二）社区居民委员会受理

社区居民委员会在受理申请人的申请后，要对申请人所提供的申请材料及家庭实际收入进行初步核查。包括书面材料审核和入户调查，入户调查人员不少于3人且无利害关系，其中至少有1名街道办事处工作人员。核查后对申请人的有关情况进行张榜公示，公示期不少于5日。公示期满无异议的，经社区居民委员会集体开会讨论、民主评议后，确定为拟帮扶济困对象并上报街道办事处复核和初审。社区居民委员会应在收到申请人申请之日起20个工作日内完成调查核实和张榜公示工作。

（三）街道办事处复核和初审

街道办事处对社区居民委员会上报的申请材料进行复核和初审，并将申请材料和初审意见上报新区社会事务局审批。街道办事处应在接到社区居民委员会报送材料之日起5个工作日内完成初审上报工作。

（四）社会事务局审批

新区社会事务局对街道办事处报送的申请材料进行审查，对符合条件的申请应当作出书面批准；对不符合条件的，应当作出不批准的书面决定。新区社会事务局应在接到街道办事处报送材料之日起10个工作日内将审批意见通过社区居民委员会送达申请人。

（五）公示公开

街道办事处接到新区社会事务局的帮扶济困申请审批意见后，应通知社区居民委员会在居民集中居住地、政务公开栏张榜公布人员名单、家庭人口、家庭总收入及享受帮扶济困保障情况，张榜公示时间不少于5日，公示确认群众无异议后，再实施相关帮扶政策或发放相关保障金。

（六）资金发放及政策实施

城市特殊困难家庭帮扶济困实行“即时受理、逐级审批”制度，对符合条件的申请对象，经公示无异议后，由街道办事处牵头办理相关资金的申请和相关政策的组织实施。

四、动态管理

（一）城市特殊困难家庭成员在享受本办法规定的帮扶济困政策后，其申请人应当在每季度末月份内书面向受理的社区居民委员会上报1次家庭变化情况（包括经济收入、人口、户籍、住址等）。对于家庭困境已解除的，应当停止享受相关帮扶济困政策。如隐瞒不报，一经发现，立即停发并追回其骗领的相关保障款物；构成犯罪的，依法追究刑事责任。

（二）对决定停止享受城市特殊困难家庭帮扶济困政策待遇的，街道办事处应当书面说明理由，并告知当事人。

五、附则

（一）本办法由新区社会事务局负责解释。

（二）本办法自发布之日起施行。
