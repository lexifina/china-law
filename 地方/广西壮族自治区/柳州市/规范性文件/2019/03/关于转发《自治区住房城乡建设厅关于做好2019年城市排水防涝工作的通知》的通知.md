# 关于转发《自治区住房城乡建设厅关于做好2019年城市排水防涝工作的通知》的通知

各有关单位：

为全面贯彻落实党的十九大精神，进一步做好我市排水防涝工作，现将《自治区住房城乡建设厅关于做好2019年城市排水防涝工作的通知》（桂建城〔2019〕10号）转发给你们，请按照通知要求认真抓好落实，确保我市2019年安全度汛，现将相关要求通知如下：

一、强化排水防涝工作机制落实

一是要加强组织领导，强化防大汛、防极端强降雨意识，进一步夯实工作责任；二是要建立健全与各部门的信息共享机制，进一步强化信息共享，各部门密切配合，有序、有效开展排水防涝工作，形成工作合力；三是要积极做好宣传引导，切实提高公众防灾自救能力；四是要加强所辖乡镇的监督指导，严格落实内涝灾害报告制度，及时将灾情报告进行收集并核实整理。

二、认真做好安全度汛准备

一是要认真开展全面巡查工作，加强管渠清疏，进一步强化设施维护，狠抓安全管理，确保排水防涝设施稳定运行；二是要做好应急准备，落实排水防涝应急预案，强化抢险应急演练，因地适宜大力补齐“物防”，进一步完善物资储备管理制度及调用流程；三是要加强应急响应，进一步做好救援安置工作。

三、加快易涝点整治工作

进一步完善易涝点整治实施方案，加快推进汛前易涝点整治项目实施，严控工程质量把关，确保汛前未能整治到位的易涝点有临时应急处置措施，做好应对措施安全度汛。
