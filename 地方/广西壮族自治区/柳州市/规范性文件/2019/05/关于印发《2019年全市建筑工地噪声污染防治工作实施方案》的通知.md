# 关于印发《2019年全市建筑工地噪声污染防治工作实施方案》的通知

各有关单位：

根据《关于印发<柳州市2019年噪声扰民整治实施方案>的通知》（柳噪整治办〔2019〕12号）要求，为助推我市创建文明城市建设工作，倡导绿色施工理念，以创造良好的人居环境为目标，进一步优化安全文明施工，同时为了切实推进2019年噪声扰民整治工作，最大限度保障群众身心健康，维护社会稳定，促进环境、经济和社会协调发展，结合我局工作职责，特制定《2019年全市建筑工地噪声污染防治工作实施方案》，现印发给你们，请各单位认真贯彻执行。

附件：2019年全市建筑工地噪声污染防治工作实施方案

柳州市住房和城乡建设委员会
