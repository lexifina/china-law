# 北管发〔2019〕27号关于印发《柳州市北部生态新区（阳和工业新区）经济稳增长工作实施方案》的通知

各有关单位：

现将《柳州市北部生态新区（阳和工业新区）经济稳增长工作实施方案》印发给你们，请结合文件内容，认真贯彻执行。

柳州市北部生态新区管理委员会

2019年6月14日

柳州市北部生态新区（阳和工业新区）

经济稳增长工作实施方案

为贯彻落实自治区、柳州市工业高质量发展大会和经济稳增长会议精神，坚持新发展理念，扎实有效地推进新区经济转型升级和高质量发展，促进经济稳增长，特制定本方案。

一、工作目标

（一）当前目标（2019年5-6月）

规模以上工业总产值：阳和工业新区规模以上工业总产值控制在合理区间（确保高于柳州市规模以上工业总产值增速2%以上）; 北部生态新区产值核减控制在合理区间。

固定资产投资：北部生态新区固定资产投资增速26%以上，阳和工业新区固定资产投资增速5%以上。

工业投资：北部生态新区工业投资增长15%以上, 阳和工业新区工业投资增长10%以上。

规模以上企业培育：北部生态新区（阳和工业新区）新增上规工业企业6家以上。

限额以上企业培育：阳和工业新区准入库企业（新开办）新增1家以上。

（二）全年目标（2019年7-12月）

规模以上工业总产值：阳和工业新区规模以上工业总产值控制在合理区间（确保高于柳州市规模以上工业总产值增速3%以上），北部生态新区产值核减控制在合理区间。

固定资产投资：北部生态新区固定资产投资增速26%以上，阳和工业新区固定资产投资增速5%以上。

工业投资：北部生态新区工业投资增长15%以上,阳和工业新区工业投资增长10%以上。

规模以上企业培育：北部生态新区（阳和工业新区）培育上规工业企业16家以上。

限额以上企业培育：阳和工业新区培育限额以上企业6家以上。

二、重点任务

（一）着力推进工业经济稳增长

1.坚定信心，狠抓工业企稳回升。全面落实新区问题库制度和项目推进管理制度，以问题为导向，以党工委、管委会领导联系企业制度和项目联系制度为抓手，通过加大企业服务力度与项目服务力度，帮助企业解决生产经营中出现的问题与困难，协调项目推进过程中出现的痛点与难点，与企业一起并肩作战，全力以赴控下滑、抓复产，促增量，推动工业经济稳增长。

（责任单位：经发局、投促局、财政局、人社局）

2.着力培育上规入统企业，增强经济发展后劲。重点培育新建投产和规下转规上企业，加大扶持、服务力度，专人对接，全年力争培育上规工业企业16家以上；全年力争培育限额以上企业6家以上。

（责任单位：经发局、投促局、财政局、阳和税务局）

3.强化调度，做好经济运行监测。通过实施工业经济运行月报制度及工业运行月度会议机制，对汽车及零部件、机械等重点行业，车桥、上汽、利和、银海铝业等重点工业企业进行监测监控，做好企业产值预测工作,及时主动发现问题，把握运行态势。通过召开经济运行分析会，“企业家沙龙”“中小企业服务月”，企业调研等形式，针对正常生产企业、经营困难企业、停产半停产企业，“一企一策”研究解决办法，提出科学可行建议，协调各类要素，推动企业提速增效。

（责任单位：经发局、沙塘镇政府、石碑坪镇政府）

4.引导企业加大创新投入，提升企业创新能力。引导和支持工业企业创建国家、自治区、市级企业技术中心、重点实验室、工程技术研究中心、工业设计中心、工程实验室和工程研究中心。积极鼓励企业申请专利，对授权发明专利、实用新型专利、外观设计专利落实好相关政策。积极鼓励企业主导或参与国际、国家、行业标准制定修订工作（全年力争企业获得技术创新（技术中心、工程技术研究中心等）10件以上，新增高新技术企业10家以上）。

（责任单位：经发局、财政局）

（二）引导和支持企业开拓市场

1.做好企业产品推介。加强对外开放合作，组织重点产业举办专场推介会，抓好汽车、机械等行业领域的企业对接、项目洽谈、产品推介等工作。

（责任单位：经发局、投促局、财政局）

2.鼓励企业积极参加会展活动。积极组织园区企业参加会展，对参加重大会展活动的企业，在场地租赁、公共布展等费用方面给予配套补助支持。力争全年组织30家以上企业参加自治区东盟博览会、汽车、工程机械及零部件博览会等会展活动。

（责任单位：经发局、投促局、财政局）

（三）精心组织实施好“项目建设提速年”活动

1.抓好项目投资及建设推进工作。充分发挥投资对稳增长的关键作用，抓好8项自治区层面重大项目、11项迎接新中国成立70周年重点建设项目、126项市级层面重大项目等建设。

（责任单位：经发局、重大办、规建局、行政审批局、投促局、柳北征地办、阳和征拆办、北城集团、轨道集团）

2.抓好工业项目投产增量工作。以加快推进新区32项工业高质量发展项目为抓手，重点做好方盛车桥低地板大型客车桥齿轮项目、华泰家具年产30万套家具搬迁扩建等10个竣工技术改造项目的投产和达产工作，稳定增量。加快推进广西博睿恩半固态压铸铝合金模板、利和实业汽车电子及传感器产业园等6个新开工项目提前实现竣工投产，形成新的增量。做好鑫裕塑胶产200万件塑料件、永信机械汽车车身件智能化生产基地、青岛九洲年产320万套汽车车身零部件自动化生产基地、中科机器业机器人自动化生产基地等项目前期工作，力争第二季度实现开工。力争全年新增产值20亿元。

（责任单位：经发局、投促局、行政审批局、规建局）

（四）强化项目要素支撑保障

1.抓好征地拆迁，保障项目供地。围绕当前正在建设和计划推进的重点项目，加快征地拆迁进度。做好用地保障工作, 提前谋划，保障工业用地指标需求，优先保障战略性新兴产业项目的用地需求（北部生态新区在6月底前整理出约500亩可供挂牌出让的工业用地，阳和工业新区9月底前整理车桥新能源项目约200亩可供挂牌出让的工业用地）。

（责任单位：柳北征地办、阳和征拆办、市自然资源和规划局北部分局、规建局、投促局、北城集团、轨道集团、沙塘镇政府、石碑坪镇政府）

2.加快项目前期工作。利用自治区优化营商环境百日攻坚行动这一契机，具有审批职能的各部门要积极探索研究“容缺后补”“绿色通道”“按需分期”等审批形式，全面推广博睿恩项目建设模式, 通过实施项目手续“预审制”，提前介入，实现工业项目“拿地即开工”，全面加快项目落地建设进程。

（责任单位：规建局、行政审批局、市自然资源和规划局北部分局、经发局、市市场监督管理局北部分局）

3.争取项目建设资金。积极争取自治区、柳州市基础设施建设专项资金，助推新区项目建设。力争全年基础设施建设专项资金超过1亿元。

（责任单位：经发局、财政局、北城集团）

（五）落实优惠政策，切实减轻企业负担

1.落实税收优惠政策。贯彻落实党中央、国务院部署，推进深化增值税改革工作，按照《关于深化增值税改革有关政策的公告》（财政部税务总局 海关总署公告2019年第39号），做好增值税一般纳税人发生增值税应税销售行为或者进口货物，原适用16%税率的，税率调整为13%；原适用10%税率的，税率调整为9%等政策落实工作。加强退税服务工作（对符合条件的部分纳税人欠税行为按照《中华人民共和国税收征收管理法》规定，经广西壮族自治区税务局批准，可以延期缴纳税款，但最长不得超过三个月）。

（责任单位：阳和税务局、财政局、经发局）

2.落实社保优惠政策。贯彻落实国家社保费率“双调低”政策：调低费率，城镇职工基本养老保险单位缴费比例从20%降至16%；调低费基，就业员工平均工资计算口径从城镇非私营单位在岗职工平均工资改为全口径城镇单位就业人员平均工资。落实《关于实施阶段性降低企业职工基本养老保险费率予以自治区级及以上产业园区工业企业财政补贴有关问题的通知》（柳人社发〔2018〕190号），进一步降低企业负担。

（责任单位：人社局、财政局、经发局、阳和税务局）

3.落实降低企业用电成本政策。积极推动符合条件的园区企业参与市场化电力交易，力争全年有40家企业参与用电交易，为企业节约用电成本超过1000万元。落实一般工商业平均电价再降低10%的降价政策。

（责任单位：经发局、财政局）

4.落实新区优惠政策。积极落实好已出台的《人才引进与培养实施办法》《促进现代制造业发展扶持办法》《创新券》等政策。

（责任单位：经发局、投促局、人社局、财政局、行政审批局）

5.帮助企业争取各级资金扶持。积极服务企业发展，帮助园区企业申请上级技术改造、科技项目、两化融合、节能技改等相关工业奖励，鼓励和引导园区企业转型升级和提升自主创新能力。力争全年各级资金扶持累计超过5000万元。

（责任单位：经发局、财政局）

（六）加强对企业融资支持

1.争取上级基金支持。积极对接自治区、柳州市支持实体经济发展的产业引导基金、双创基金，强化项目策划包装，争取自治区、柳州市引导基金、双创基金对新区工业发展的更多支持。力争全年获得上级基金支持超过3000万元。

2.加快产业发展引导基金建设投入使用。积极探索模式，加快成立产业引导基金，发挥财政资金杠杆作用，推动产业发展。力争年内设立产业发展引导基金总规模达到3亿元以上。

（责任单位：财政局、北城集团、经发局）

3.加大信贷资金支持力度。加大对工业企业信贷支持力度，对汽车及零部件、战略性新兴等产业中有竞争力、有市场、有效益的优质企业继续给予信贷支持。积极向自治区、柳州市金融争取针对园区企业的优惠政策，帮助企业获得更多的金融支持。力争全年累计获得信贷资金超过5000万元。

（责任单位：经发局、财政局）

（七）着力推进一批智能产业项目落地，快速形成工业产能

围绕建设智能电网产业园和打造智能制造产业集聚区的战略目标，实施精准选商、靶向招商，重点支持广西南网运营有限公司开展产业链招商，力争今年实现智能电网项目招商“零突破”以及15家左右智能制造企业项目落地开工。

（责任单位：投促局、经发局、规建局、柳北征地办、市自然资源和规划局北部分局、北城集团、沙塘镇政府、石碑坪镇政府）

三、保障措施

（一）高度重视，加强稳增长工作组织领导。工业是新区经济发展的主要支撑力量，各部门、各单位要认清形势，高度重视工业经济发展，落实促进稳增长的各项政策措施、不断优化企业发展环境，促进经济在合理区间运行。

（二）统筹推进，保障各项工作措施全面落实到位。各部门要及时与上级主管部门和新区相关部门对接，形成市区联动机制与工作合力。结合本部门职责细化任务，明确工作节点，确保各项工作落实到位。

（三）加强督办。新区绩效办将《柳州市北部生态新区（阳和工业新区）经济稳增长工作实施方案》纳入年度目标绩效考核，对各单位落实情况进行督查考核，并对考核结果进行通报。

附件：柳州市阳和工业新区党工委、管委会领导联系服务企业责任分工表

公开方式：主动公开
