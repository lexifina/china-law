# 阳管发〔2019〕29号柳州市阳和工业新区管理委员会关于建立阳和工业新区餐厨剩余物监管工作协作联动机制的通知

各有关单位：

根据《广西壮族自治区人民政府重大动物疫病防治指挥部关于建立自治区本级餐厨剩余物监管工作协作联动机制的通知》（桂重防指发〔2019〕1号）、《柳州市餐厨废弃物管理办法》（柳州市人民政府令第2号）和柳州市人民政府重大动物疫病防治指挥部《关于进一步做好非洲猪瘟防控切实加强餐厨剩余物（泔水）及生猪产品监管工作的通知》（柳重防指发〔2018〕9号）等文件精神，为切实加强阳和工业新区非洲猪瘟防控工作，切断通过餐厨剩余物传播疫病途径，现就非洲猪瘟防控期间建立阳和工业新区餐厨剩余物监管工作协作联动机制通知如下：

一、工作任务

进一步明确在非洲猪瘟防控期间新区规划建设环保局、社会事务局、市执法局北部分局、阳和工商所、阳和食药所等部门监管职责，切实加强餐厨剩余物收集、运输、储存、处理各个环节监管，禁止餐饮服务提供者向养殖场（户）提供餐厨剩余物，禁止养殖场（户）使用餐厨剩余物饲喂生猪，切断非洲猪瘟通过餐厨剩余物传播的途径。

二、工作措施

（一）加强养殖户使用餐厨剩余物（泔水）的排查

社会事务局要组织村级动物防疫员进村入户，对养殖场（户）进行全面排查，了解和掌握本辖区使用餐厨剩余物（泔水）饲喂生猪的养殖场（户）基本情况，对使用餐厨剩余物（泔水）饲喂生猪的养殖场（户）进行登记造册，将其列入重点监管对象。同时要通过组织培训、印发宣传材料等方法，大力宣传使用餐厨剩余物(泔水)养猪的严重危害性，督促养殖场（户）落实生物安全措施，严禁养殖场（户）用餐厨剩余物（泔水）饲喂生猪。

（二）强化餐厨剩余物（泔水）的监管

阳和食药所牵头，协调新区规划建设环保局、社会事务局、市执法局北部分局、阳和工商所等部门指导、督促做好宾馆、餐饮店、单位食堂等餐厨剩余物（泔水）的管理，强化餐厨剩余物（泔水）产生、收集、转运、处置等环节的全链条监管，有效防止非洲猪瘟病毒通过餐厨剩余物（泔水）传播。市执法局北部分局要强化餐厨剩余物（泔水）流通环节的监管，督促产生餐厨剩余物（泔水）的业主落实生物安全措施，凡发现违反餐厨剩余物（泔水）监管规定的行为，要依照相关法律严厉查处。

三、协作联动机制

（一）信息交流制度。新区规划建设环保局、社会事务局、市执法局北部分局、阳和工商所、阳和食药所应相互通报本部门在日常监管活动中获取的餐厨剩余物产生的种类、数量、流向情况，餐厨剩余物无害化处理和资源化利用情况，餐厨剩余物产生、收集、运输、处理单位违法行为的处理情况，投诉、举报的处理情况等信息。对通报涉及本部门监管职能范围的，及时采取措施进行处理。

（二）联合执法制度。新区规划建设环保局、社会事务局、市执法局北部分局、阳和工商所、阳和食药所要围绕新区餐厨剩余物监管的重点、难点、突出问题研究提出解决措施，在餐厨剩余物日常监管过程中发现的违法行为超出本部门查处职能范围时，应迅速与具体负责的部门联系，开展联合执法行动，依法进行处理。

四、工作要求

禁止餐厨剩余物饲喂生猪是当前防控非洲猪瘟必须落实的一项重大举措，《柳州市餐厨废弃物管理办法》（以下简称《办法》）已于2018年10月1日起实施，各单位、各部门要严格按照《办法》的规定，加强餐厨剩余物的监管，同时要积极探索餐厨剩余物无害化处理的方法，逐步推进餐厨剩余物的资源化利用和无害化处理，各部门切实履行好主体责任和监管责任，在餐厨剩余物产生、收集、转运、储存、处置全过程形成监管闭合链条，不出现漏洞，不出现脱管。要建立长效监管、联防联控机制，严格落实监管责任，为打好打赢新区非洲猪瘟防控“阻击战”提供有力保障。
