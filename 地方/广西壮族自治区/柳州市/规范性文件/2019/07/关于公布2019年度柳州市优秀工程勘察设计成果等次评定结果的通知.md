# 关于公布2019年度柳州市优秀工程勘察设计成果等次评定结果的通知

各有关单位，各县、区住房城乡建设局、北部生态新区规划建设环保局，各有关勘察设计单位：

2019年度柳州市优秀工程勘察设计成果等次评定活动已经结束。本次评定共收到市内外12个勘察设计单位申报的参评项目74项。经专家评定委员会评定，共评出柳州市优秀建筑设计38项，其中一等等次13项、二等等次19项、三等等次6项；柳州市优秀市政公用工程设计12项，其中一等等次4项、二等等次5项、三等等次3项；柳州市优秀工程勘察与岩土工程13项，其中一等等次7项、二等等次5项、三等等次1项。

评定结果已在柳州市住房和城乡建设局官网进行了公示。公示期满，现将2019年度柳州市优秀工程勘察设计成果等次评定结果予以公布（详见附件）。

希望各获奖单位及获奖工程技术人员再接再厉、再创佳绩。同时，希望我市的工程勘察设计单位和广大工程技术人员秉持创新意识、坚持质量提升、追求技术进步，创作出更多适用、经济、绿色、美观的工程建设项目，为提高我市的城市建设水平做出新的贡献。
