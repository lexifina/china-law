# 关于收集柳州市建筑产业现代化发展试点城市相关影像资料的通知

各有关单位：

2016年，我市被列为自治区建筑产业现代化综合试点城市（以下简称“试点城市”）。近几年来，在各单位的大力支持和积极配合下，我市在推进试点城市建设取得了新突破，装配式建筑生产基地相继建成投产，一批装配式建筑示范项目开工建设。为大力推进装配式建筑产业发展，更好地总结我市装配式建筑产业推广成果，为行业提供可复制经验，现广泛收集与装配式建筑相关的影像资料制作试点城市成果展，具体要求如下：

一、资料收集范围

自我市被列入试点城市以来，各单位（含新开工、在建、竣工项目和生产基地等）重大事件（含各级领导视察）、重要活动、标志性节点以及其它具有代表性的、与装配式建筑相关的影像资料。

二、资料标准

报送的照片可以是装配式建筑项目、生产基地、企业宣传、新技术推广、获区级以上科学技术类奖项及荣誉等照片，要求画质清晰，构图巧妙，为相机高清原片（含手机拍摄）；视频可以是企业、装配式建筑项目、生产基地的宣传片或航拍视频。报送的拍摄照片和视频场景要符合操作规范、文明施工、基本建设手续完善等有关要求。

三、报送要求

各单位应指定专人负责收集、整理、筛选具有典型性、代表性的照片和视频资料，内容选定后要自行编号，并为每张照片、每段视频编写附注简要说明，注明拍摄时间、地点、内容等信息，请各单位按附件要求填写，于7月5日前发送电子邮件至邮箱lzszjwkjk@163.com。
