# 关于终止阳和工业新区防洪Ⅳ级应急响应的通知

新区防汛抗旱指挥部各成员单位：

根据柳州市防汛抗旱指挥部7月11日9时发布的《关于终止防洪Ⅳ级应急响应的通知》（柳防指〔2019〕14号）文件要求，鉴于本次强降雨对我市的影响已经结束，主要江河水势平稳，柳州水文站水位为77.88米，自7月11日9时00分起，终止柳州市防洪IV级应急响应。经阳和工业新区防汛抗旱指挥部研究决定，自7月11日9时00分起，阳和工业新区同步终止防洪IV级应急响应。

请各成员单位继续组织做好后期防汛工作。

柳州市阳和工业新区管理委员会

2019年7月11日
