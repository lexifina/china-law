# 关于转发《自治区住房城乡建设厅关于广西建筑施工扬尘噪音监测管理公共服务平台上线试运行的通知》的通知

柳建管字〔2019〕53号

关于转发《自治区住房城乡建设厅

关于广西建筑施工扬尘噪音监测管理

公共服务平台上线试运行的通知》的通知

各有关单位：

现将《自治区住房城乡建设厅关于广西建筑施工扬尘噪音监测管理公共服务平台上线试运行的通知》（桂建函〔2019〕220号）转发给你们，请各单位高度重视，认真抓好贯彻落实，切实做好建筑施工扬尘噪音监管平台链接录入工作，进一步做好我市建筑施工扬尘治理和大气污染防治工作，提高建筑施工噪声防治管理水平，优化安全文明施工，创造良好的人居环境，提升我市城市环境质量，助推我市全国文明城市的创建。

附件：关于广西建筑施工扬尘噪音监测管理公共服务平台上线试运行的通知（桂建函〔2019〕220号）

柳州市住房和城乡建设局

2019年7月17日
