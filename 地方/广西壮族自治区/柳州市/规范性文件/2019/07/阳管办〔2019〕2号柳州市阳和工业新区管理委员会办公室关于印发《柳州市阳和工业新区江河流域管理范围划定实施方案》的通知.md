# 阳管办〔2019〕2号柳州市阳和工业新区管理委员会办公室关于印发《柳州市阳和工业新区江河流域管理范围划定实施方案》的通知

各局、办，阳和街道办事处，各有关单位：

现将《柳州市阳和工业新区江河流域管理范围划定实施方案》印发给你们，请认真贯彻落实。

柳州市阳和工业新区管理委员会办公室

2019年6月28日

柳州市阳和工业新区江河流域

管理范围划定实施方案

江河是水资源的重要载体，加强江河流域管理保护，对于保障防洪、供水、生态安全，促进经济社会可持续发展具有重要意义。依法划定江河流域管理范围，明确江河流域管理边界线是加强江河流域管理保护的基础性工作，也是中央全面推行河长制湖长制明确的任务要求。为进一步深入实施河长制，落实江河流域边界空间管控，提升管护成效。结合新区实际，制定本实施方案。

一、基本情况

阳和工业新区位于柳州市东部的桂海高速公路静兰出口处，规划总面积约90平方公里。新区由两个自治区级经济技术开发区组成——即1992年自治区人民政府批准的古亭山经济技术开发区和1994年自治区政府批准的柳州市阳和开发区。托管1个街道办事处、三个行政村和4个社区，辖区内共有9条河流，其中流域面积在50平方公里以上的河流共有1条（柳江干流阳和新区河段），流域面积50平方公里以下的河流共有8条，全部列入河长制江河湖库名录。目前，新区设有总河长1名、河长1名（兼），街道总河长2名、河长3名（其中1名为总河长兼任），村级河长7名，建立健全了新区、街道、村三级河长体系，所有河流均实现了河长全覆盖。

二、目标任务

（一）工作目标。根据江河流域岸线的自然条件和特点、沿江河流域地区的经济、社会发展水平及岸线开发利用程度，针对岸线保护与开发利用中的主要矛盾，结合流域或区域在生态保护、防洪减灾、水资源利用等方面的规划目标，统筹协调经济社会发展和相关行业、部门对岸线保护利用的要求和需求，在2020年底前完成新区辖区内江河流域管理范围划定的工作。

（二）工作任务。严格按照桂政办发〔2019〕34号及《自治区河长制办公室关于做好江河湖库管理范围划定相关工作的通知》（桂河长办〔2019〕18号）工作部署推进新区江河湖库管理范围划定工作。根据文件要求，最高层级河长、湖长为县级负责同志的江河湖库，以及最高层级河长、湖长为乡级负责同志且管理任务较重的江河湖库，于2020年底前完成。管理任务相对较轻的农村江河湖库，于2021年底前完成。地处无人区域的河湖及部分国界河段，可根据管理实际需要，开展管理范围划定工作。

三、工作步骤

（一）根据新区实际，制定实施方案（2019年3月-4月）

制定本辖区内江河流域管理范围划定实施方案，于4月底报市河长制办公室备案。待《柳州市江河湖库管理范围划定实施方案》正式印发后，根据方案要求做相应修改并印发。

（二）开展摸底调查与资料收集工作（2019年4月-5月）

2019年5月底前，完成对辖区内流域面积50平方公里以下河流管理范围划定的基本情况调查摸底，并按河流管理范围划定的要求做好资料收集等划定准备工作。

（三）全面实施推进（2019年6月-2020年12月）

根据自治区试点示范工作的经验总结，并按照本实施方案确定的时间表和路线图，全面加快推进阳和工业新区江河流域管理范围划定工作，强化细化节点控制，确保如期完成划定工作任务。具体时间表详见附件。

（四）验收、公告、总结（2021年1月-2021年12月）

江河流域管理范围划定工作完成后，由阳和工业新区管理委员会对新区负责的江河流域管理范围划定成果进行验收，验收合格后由阳和工业新区管理委员会公告实施。新区对江河流域管理范围划定工作进行全面总结，将管委会公告、图件和相关验收资料归档。

四、工作保障

（一）加强组织领导。为迅速部署、推进新区江河流域管理范围划定工作，新区各有关部门及相应的河长要切实加强组织领导，建立政府主导、河长牵头、相关部门分工协作的工作机制，组建工作组，创新工作方式，明确部门职责及责任人员，确保按期完成江河流域管理范围划定工作任务。

（二）强化联动落实。新区社会事务局、经济发展局、财政局、规划建设环保局、行政审批局、市自然资源和规划局北部分局、市行政执法局北部分局、阳和街道办事处等部门要按照《阳和工业新区全面推行河长制工作方案》的职责分工，协同推进江河流域管理范围划定工作的组织实施，形成工作合力。对重点难点事项要充分发挥河长会议协商机制作用，及时协调解决划界中遇到的问题。

（三）加强指导宣传。新区各有关部门要积极组织学习，提升业务能力，确保业务水平满足工作需要。要广泛宣传江河流域管理范围划定工作的重要意义，普及江河流域管理保护法律法规相关知识，形成全社会理解、支持江河流域管理范围划定工作的良好氛围。
