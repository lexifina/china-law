# 阳管发〔2019〕41号关于印发《柳州市阳和工业新区2019年保护发展森林资源目标任务》的通知

各有关单位：

为将新区保护发展森林资源目标责任制落到实处，结合新区森林资源等状况制定了《柳州市阳和工业新区2019年保护发展森林资源目标任务》，现印发给你们，请结合新区实际，认真组织实施，全面完成年度各项指标任务。

附件：柳州市阳和工业新区2019年度保护发展森林资源目标任务

柳州市阳和工业新区管理委员会

2019年7月1日

公开方式：主动公开

柳州市阳和工业新区管委办 　 2019年7月1日印发
