# 阳管发〔2019〕43号关于印发《柳州市阳和工业新区保护发展森林资源目标责任制检查考评细则》的通知

各有关单位：

根据《柳州市阳和工业新区保护发展森林资源目标责任制检查考核办法》，新区制定了《柳州市阳和工业新区保护发展森林资源目标责任制检查考评细则》，现印发给你们，请认真组织实施。

附件：柳州市阳和工业新区保护发展森林资源目标责任制检查考评细则

柳州市阳和工业新区管理委员会

2019年6月30日
