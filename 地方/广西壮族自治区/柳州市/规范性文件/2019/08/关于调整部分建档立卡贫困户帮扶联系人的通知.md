# 关于调整部分建档立卡贫困户帮扶联系人的通知

各局、办，阳和街道办事处，市执法局北部分局：

因新区部分领导干部人事变动，为进一步统筹做好“一帮一联”工作，确保新区脱贫攻坚工作顺利开展，经研究，决定对以下4户建档立卡贫困户的帮扶联系人进行调整。

一、具体调整帮扶联系人事宜

（一）廖开盛户（六座村高烟屯）：该户原帮扶联系人为原北部生态新区（阳和工业新区）人力资源和社会保障局局长梁寒冰，现调整为柳州市城市管理行政执法局北部生态新区分局副局长王伟；原帮扶对接工作人员为北部生态新区（阳和工业新区）规划建设环保局韦治锋，新帮扶对接工作人员由王伟副局长自行安排。

（二）赖强华户（六座村高烟屯）：该户原帮扶联系人为原北部生态新区（阳和工业新区）人力资源和社会保障局副局长何小兰，现调整为北部生态新区（阳和工业新区）人力资源和社会保障局副局长郭建；原帮扶对接工作人员为北部生态新区（阳和工业新区）人力资源和社会保障局彭贵明，新帮扶对接工作人员由郭建副局长自行安排。

（三）黄新华户(六座村狮子头屯): 该户原帮扶联系人为北部生态新区（阳和工业新区）社会事务局局长罗全文，现调整为北部生态新区（阳和工业新区）社会事务局副局长王菲；原帮扶对接工作人员为北部生态新区（阳和工业新区）社会事务局李冀露，新帮扶对接工作人员由王菲副局长自行安排。

（四）夏秀容户（社湾村一队）：该户原帮扶联系人为原阳和工业新区征地拆迁办公室主任麻春展，现调整为阳和工业新区征地拆迁办公室副主任郭文斌；原帮扶对接工作人员为阳和工业新区征地拆迁办公室杨军，新帮扶对接工作人员由郭文斌副主任自行安排。

二、工作要求

（一）原帮扶联系人要主动对接，做好各项帮扶工作的交接，协助新帮扶联系人尽快与帮扶贫困户建立联系，了解帮扶对象现阶段情况，确保新区精准扶贫工作的顺利完成。

（二）除本次调整之外，其它建档立卡贫困户的帮扶联系人不变。

柳州市阳和工业新区管理委员会

2019年7月26日
