# 关于转发《自治区住房城乡建设厅关于启用广西建筑业企业诚信评价分的通知》的通知

各有关单位：

根据自治区住房城乡建设厅相关文件要求，决定于2019年8月15日起正式启用广西建筑业企业诚信评价分，现将《自治区住房城乡建设厅关于启用广西建筑业企业诚信评价分的通知》（桂建管〔2019〕42号，见附件）转发给你们，请各县（区）住建局、柳东建设局、北部生态新区（阳和工业新区）规建局按文件时间节点要求完成辖区内相关企业不良行为信息录入工作并做好诚信信息入库审核工作；各建筑业企业按文件时间节点要求做好相关奖项的录入工作。

附件：自治区住房城乡建设厅关于启用广西建筑业企业诚信评价分的通知（桂建管〔2019〕42号）

柳州市住房和城乡建设局

2019年8月5日
