# 关于刘泽伟等5名评标专家的考评处理决定

我市招标办近期在办理招标投标书面情况报告备案时发现，评标专家刘泽伟、朱梅华、周国恩、高益峰在参加柳州市白沙小学迁建工程--1#、2#教学综合楼、综合体育馆、连廊、1#门卫室、2#门卫室、地下室及室外工程施工评审时对企业信誉实力评审错误；评标专家陈庆健在参加壶东苑6#楼、幼儿园及地下室工程施工评审时存在资信评审错误。

根据《柳州市房屋建筑和市政基础设施工程评标专家考评办法》（柳建管字〔2018〕5号）中附件2评标专家管理考评评分表第3点“各级抽查、检查、备案中发现评委未严格按照评标办法进行评审的，或出现评审错误的考核扣5分”的规定，决定对评标专家刘泽伟、朱梅华、周国恩、高益峰、陈庆健等5名评标专家管理考核扣5分。

柳州市住房和城乡建设局

2019年9月3日
