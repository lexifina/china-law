# 关于印发《柳州市房屋建筑和市政工程检测电子招标文件范本（2019版）》的通知

各有关单位：

为进一步规范我市房屋建筑和市政工程检测电子招标投标活动，我局修订了《柳州市房屋建筑和市政工程检测电子招标文件范本（2019版）》（以下简称《柳州市检测电子招标文件范本》），现印发给你们。

《柳州市检测电子招标文件范本》自2019年9月1 起实施。《柳州市检测电子招标文件范本》与柳州市公共资源交易平台配套使用，凡我市、县、区内进入公共资源交易服务中心集中交易的检测电子招投标项目，必须使用《柳州市检测电子招标文件范本》。

《柳州市检测电子招标文件范本》由我局招标办负责解释，如在实际执行过程中遇到问题，请各单位或个人及时将意见和建议反馈至我局招标办。由于该招标文件范本页数较多，请各单位登录柳州市住房和城乡建设局网站（http://www.lzhc.gov.cn/）或柳州市公共资源交易中心网站（http://ggzy.liuzhou.gov.cn/），在“通知公告”栏中自行下载。
