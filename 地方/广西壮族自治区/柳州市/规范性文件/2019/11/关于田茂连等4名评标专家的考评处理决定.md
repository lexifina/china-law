# 关于田茂连等4名评标专家的考评处理决定

柳州市2019年桂中花苑棚户区旧住宅小区综合整治工程10kV配电工程在办理招标投标书面情况报告备案时，我局招标办发现评标专家田茂连、霍彦、李扬川、唐曼红未严格按照评标办法进行评审，在形式性评审中存在评审错误。

根据《柳州市房屋建筑和市政基础设施工程评标专家考评办法》（柳建管字〔2018〕5号）中附件2评标专家管理考评评分表第3点“各级抽查、检查、备案中发现评委未严格按照评标办法进行评审的，或出现评审错误的考核扣5分”的规定，决定对评标专家田茂连、霍彦、李扬川、唐曼红等4名评标专家管理考核扣5分。

柳州市住房和城乡建设局

2019年11月26日
