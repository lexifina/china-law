# 北管发〔2019〕42号关于印发《柳州市北部生态新区全面实施“双随机、一公开”监管部门工作联席会议制度》的通知

各有关单位：

现将《柳州市北部生态新区全面实施“双随机、一公开”监管部门工作联席会议制度》印发给你们，请结合实际，认真贯彻执行。

柳州市北部生态新区管理委员会

2019年11月4日

柳州市北部生态新区全面实施“双随机、一公开”监管部门工作联席会议制度

为切实加强对“双随机、一公开”工作的领导，加强部门间协调配合，推动“双随机、一公开”工作的顺利推进和有效落实，经北部生态新区管委会同意，建立柳州市北部生态新区全面实施“双随机、一公开”监管部门联席会议（简称联席会议）制度。

一、联席会议主要职责

（一）贯彻落实中央和省、市、辖区关于全面推行“双随机、一公开”的决策部署和工作安排，协调督促本辖区全面实施“双随机、一公开”工作。

（二）在北部生态新区管委会领导下，统筹推进辖区内市场监管领域部门联合“双随机、一公开”监管工作；

（三）审议审定落实实施“双随机、一公开”工作方案、相关制度和考核标准，制定相关措施。

（四）确定“双随机、一公开”监管工作年度实施任务、目标、措施，并负责各自部门任务、目标、措施及责任的落实。

（五）协调解决实施“双随机、一公开”监管工作中的重点难点问题。

（六）督促各有关部门全面实施“双随机、一公开”制度，建立健全推行“双随机、一公开”工作体系，落实市委、市政府、北部生态新区管委会确定的工作目标和任务。

二、联席会议成员单位

由市市场监督管理局北部生态新区分局、北部生态新区规划建设环保局、市北部生态新区生态环境局3个单位组成，市市场监督管理局北部生态新区分局为牵头单位。

市市场监督管理局北部生态新区分局主要负责人为联席会议召集人，各成员单位有关负责同志为联席会议成员。相关成员名单因工作变动等原因需要调整的，由所在单位提出，报联席会议确定。

三、联席会议工作机构及职责

联席会议办公室设在市市场监督管理局北部生态新区分局，办公室主要承担各成员单位的召集工作，组织、协调、督促、推动各成员单位落实职责分工，协调组织各成员单位联合开展部门联合“双随机、一公开”监管、“一单两库一细则”录入等方面工作，以及联席会议交办的其他日常工作。

联席会议设联络员，由各成员单位指定1名业务科室负责人担任。联络员因工作变动需要调整的，由所在单位及时调整，报联席会议办公室备案。主要任务是落实联席会议确定的工作部署，承担联席会议办公室交办的会议组织筹备、宣传、联合抽查、信息交换等方面工作，具体推进落实本部门承担的“双随机、一公开”工作任务。

四、联席会议工作规则及工作要求

（一）联席会议根据需要定期或不定期召开会议，由召集人或召集人委托的同志主持，必要时可以由召集人临时主持召开联席会议。为落实联席会议确定事项，可以适时召开联络员会议，全体或者部分成员单位参加。根据工作需要，可邀请其他相关部门参与特定事项的专题研究。

（二）联席会议以会议纪要的形式明确议定事项，印发有关单位并抄报北部生态新区管委会，重大事项按程序报批。

（三）各成员单位要按照职责分工，主动研究“双随机、一公开”及事中事后监管中的重大问题，指定专人做好本单位“双随机、一公开”监管工作，指导对口部门落实推进“双随机、一公开”工作，认真落实联席会议确定的工作任务；按要求准时向联席会议办公室报送工作情况。

（四）联席会议办公室负责组织对各部门落实政策措施情况和任务完成情况进行督促检查。
