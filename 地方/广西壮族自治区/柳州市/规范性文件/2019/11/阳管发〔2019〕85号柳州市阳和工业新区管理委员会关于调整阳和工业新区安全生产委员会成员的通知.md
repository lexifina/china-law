# 阳管发〔2019〕85号柳州市阳和工业新区管理委员会关于调整阳和工业新区安全生产委员会成员的通知

阳和工业新区安全生产委员会下设办公室（简称阳和安委办），为阳和工业新区安全生产委员会的日常机构，具体负责综合管理和监督新区的安全生产工作。阳和安委办设在阳和工业新区安全生产监督管理局，办公室主任由安全生产监督管理局局长邱振华担任，办公室副主任由人力资源和社会保障局副局长谢华华、财政局副局长蒙新华、规划建设环保局副局长陆慧专、阳和街道办事处副主任韦岳文、社会事务局副局长侯琳、社会治安综合治理委员会办公室副主任覃树、安全生产监督管理局副局长温志强担任，办公室人员从成员单位抽调。
