# 北管发〔2019〕62号关于印发《北部生态新区秸秆禁烧工作实施方案》的通知

各成员单位：

现将《柳州市北部生态新区秸秆禁烧工作实施方案》印发给你们，请认真贯彻执行。

柳州市北部生态新区管理委员会

2019年12月16日

柳州市北部生态新区秸秆禁烧工作实施方案

为有效解决秸秆露天焚烧问题，打赢蓝天保卫战，推进新区环境空气质量改善，根据《中共中央国务院关于全面加强生态环境保护坚决打好污染防治攻坚战的意见》、《自治区党委督查室自治区政府督查室关于办理自治区党委书记鹿心社同志对秸秆禁烧批示的督查通知》（桂督查〔2019〕89号）和柳州市委、市政府关于秸秆禁烧的部署要求，结合新区实际，制定本方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，牢固树立生态优先、绿色发展理念，贯彻落实党中央、国务院和自治区党委、政府大力推进生态文明建设的决策部署，坚持资源节约和保护环境的基本国策，坚持走绿色、低碳、可持续发展道路，综合施策，形成秸秆露天禁烧长效机制。

二、工作目标

按照“属地管理、疏堵结合、以禁促用”的原则，强化组织领导，完善政策措施，建立责任机制，在新区范围内禁止秸秆露天焚烧，确保“不见烟雾、不见火光、不见黑斑”，改善因秸秆焚烧造成的环境空气污染。

三、主要任务

（一）建立健全秸秆禁烧管控机制

1.在市人民政府发布秸秆露天禁烧区划定通告前，新区范围内任何时间、任何气象条件及空气质量状况下都不允许进行秸秆露天焚烧。

2．实行网格化管理，按照“属地管理、源头控制”的原则，北部生态新区管委会对新区范围内秸秆禁烧工作负总责，新区主要领导为禁烧工作第一责任人，沙塘镇人民政府、石碑坪镇人民政府主要负责人为本辖区禁烧工作直接责任人。两镇要完善和强化“镇管片、社区（村）落实、各户联防”的禁烧工作机制，强化管理网格职能，明确各网格责任人和监管人，按责任区域设立责任标牌，确保秸秆禁烧责任细化到地块和人。

（二）加大巡查密度，严格执法检查

1.柳北区城市管理行政执法局要加大巡查密度，严格执法检查。对露天焚烧行为应依据《中华人民共和国大气污染防治法》《广西壮族自治区大气污染防治条例》相关规定进行处理；对拒绝、阻碍秸秆禁烧监督管理人员执行公务的，由市公安局柳北分局按照《治安管理处罚法》规定进行处罚；构成犯罪的，依法追究刑事责任。沙塘镇人民政府、石碑坪镇人民政府要成立秸秆禁烧专职巡查队，配合柳北区城市管理行政执法局及时制止焚烧行为，快速处置完毕并拍照取证。

2.拓宽露天焚烧火点发现举报渠道。充分发动群众监督工作，鼓励举报焚烧秸秆行为。

（三）加大禁烧宣传力度

要充分发挥广播、电视、报刊、网络等载体和微博、微信、APP等新媒体的舆论引导和监督作用，多层次、多角度深入开展形式多样、生动活泼、贴近生活的秸秆禁烧宣传教育活动。沙塘镇人民政府、石碑坪镇人民政府应采取村内宣传广播、张贴通告、村口悬挂横幅标语、移动宣传车和发放宣传册、签订责任书等多种方式，大力宣传秸秆禁烧的相关法律法规和焚烧危害，充分调动群众监督、举报和制止露天焚烧秸秆行为的积极性，教育引导广大农民群众积极参与到禁烧工作中来。

四、组织机构

为高效推进秸秆禁烧工作，特成立柳州市北部生态新区秸秆禁烧工作领导小组，负责统筹规划、动员部署、组织协调、督查落实秸秆禁烧管控工作。领导小组办公室设在北部生态新区生态环境局。成员如下：

五、职责分工

（一）两镇政府职责

沙塘镇人民政府、石碑坪镇人民政府是秸秆禁烧工作的直接责任人，直接负责组织实施本行政区域内秸秆禁烧工作；组织乡镇、村屯、街道社区等力量开展秸秆禁烧大巡查，严格防止在禁烧区发生焚烧秸秆事件；配合北部生态新区完成上级部门下达的工作目标任务，具体落实秸秆禁烧的宣传教育工作；制定出贯彻落实方案，报送至北部生态新区秸秆禁烧工作领导小组备案。

（二）有关部门职责

北部生态环境局：负责督促各部门依法做好秸秆露天焚烧管控，指导建立网格化监管机制，落实各级责任体系；负责组织秸秆禁烧的宣传教育工作。

规划建设环保局：配合北部生态环境局协调各相关部门开展秸秆禁烧工作及汇总各部门材料报送。

经济发展局：负责督促新区企业禁止露天焚烧固体废物，配合做好秸秆禁烧工作。

党群工作部：配合做好秸秆禁烧宣传，营造良好氛围。通过网络、电视、报社、政务信息、微信公众号、微博平台等媒介及时向公众宣传秸秆禁烧相关规定和焚烧危害，提高群众的知晓率及主动参与积极性。

财政局：统筹安排资金，保障秸秆禁烧工作开展，并对资金进行监督管理。

绩效办：对相关部门秸秆禁烧工作开展情况进行督查检查，纳入绩效考核内容进行考核。

柳北区自然资源局：负责引导做好林业规范种植工作，避免在林业种植过程中发生计划“烧除”（炼山）情况；负责对护林员进行禁烧工作的培训、宣传；协助做好秸秆禁烧工作。

市公安局柳北分局：负责依法处理拒绝或妨碍秸秆禁烧监督管理人员执行公务的违法行为。

柳北区城市管理行政执法局：严格巡查值守制度，全面加强露天焚烧管控，通过值班巡查、遥感飞机等手段严密监控露天焚烧，加强日常巡查检查，发现露天焚烧要及时制止；严厉查处屡禁不止、蓄意违法露天焚烧的行为。

其他各职能部门：按照职责分工协助做好秸秆禁烧工作。

六、工作要求

（一）严格落实责任。沙塘镇人民政府、石碑坪镇人民政府及新区各有关部门要各司其职、各负其责。两镇要成立相应的领导小组，完善镇、村、组三级管理网格队伍，制定切实可行的禁烧工作方案，设立禁烧举报电话，切实做到镇干部包到村、村屯干部包到户、田块包干到人。成立秸秆焚烧巡查组，明确具体责任人，充分发挥基层组织的作用，严防死守，发现火点要及时扑灭、及时查处，防止秸秆焚烧现象。将秸秆禁烧工作任务具体到镇（乡）、国规站、村（屯）、组。

（二）强化禁烧关键环节。新区各部门要进一步建立和完善工作联动、大气污染会商、区域联防联控、宣传引导、违法惩处和责任追究等秸秆禁烧工作推进机制，细化完善禁烧网格化管理，强力推进秸秆禁烧工作；要加强对征而未用地、河渠滩涂地、城市上风方向、重点旅游通道、高速公路及国省干线公路沿线、与相邻县、城区之间区域和重大活动期间的督查力度，发现焚烧火点及时处理，做到时间上不留空档、空间上不留死角。对拒绝、阻碍秸秆禁烧及禁止烧荒监督管理人员执行公务的，由市公安局柳北分局依照相关法律法规进行处罚。

（三）严格督查考核制度。在秋冬季（榨季）期间，北部生态新区秸秆禁烧工作领导小组对新区的秸秆禁烧工作情况进行暗访或不定期督查，对秸秆禁烧工作不力、造成大气严重污染的部门，予以通报批评。绩效办根据生态环境部卫星遥感监测结果和省、市、新区三级督查巡查情况，按照火点个数对相关责任部门实施绩效扣分；对于出现大面积秸秆焚烧现象，造成恶劣影响的，加倍扣分。对因焚烧秸秆影响交通安全或造成人员伤亡、财产损失等严重后果的，依法依纪追究当事人和相关责任人的责任。

（四）其他。指定1名秸秆禁烧工作联络员，做好相关必要台账，及时报送开展秸秆禁烧有关情况至规划建设环保局，对不按时报送的单位，将依据有关规定实行效能问责。
