# 阳管发〔2019〕94号关于印发《柳州市阳和工业新区“壮美广西·智慧广电”工程实施方案》的通知

各局、办，阳和街道办：

《柳州市阳和工业新区“壮美广西·智慧广电”工程实施方案》已经阳和工业新区管理委员会同意，现印发给你们，请结合实际认真贯彻落实。

柳州市阳和工业新区管理委员会

2019年11月29日

柳州市阳和工业新区

“壮美广西·智慧广电”工程实施方案

为贯彻落实国家和自治区关于推动传统媒体和新兴媒体融合发展的决策部署，根据《柳州市人民政府办公室关于印发柳州市“壮美广西·智慧广电”工程实施方案的通知》（柳政办〔2019〕110号）要求，为推动媒体融合发展、巩固意识形态阵地、促进广播电视高质量发展、弥补广电公共文化服务不平衡不充分的现状、助推脱贫攻坚，结合新区实际，制定本方案。

一、总体要求

（一）指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，坚持正确的政治方向，贯彻新发展理念，坚持以人民为中心的发展思想，以推进广播电视高质量发展为主线，以深化广播电视与新一代信息技术融合创新为重点，通过实施“壮美广西·智慧广电”工程，推动广播电视智能化发展、综合化应用，从功能业务型向创新服务型转变，开发新业态、提供新服务、激发新动能、拉动新消费，为加快建设现代制造城和打造万亿工业强市、建设壮美广西提供有力支撑。

（二）工作目标

通过实施柳州市阳和工业新区“壮美广西·智慧广电”工程，力争用3年时间，到2021年，运用互联网技术构建全新的广播电视传播体系，实现从“看电视”到“用电视”的转变，让人民群众能够享受更加满意、更加丰富、更加优质的广播电视服务，实现广播电视智慧化生产、智慧化传播、智慧化服务和智慧化监管，新区广播电视内容生产、传播网络、服务生态和安全监管水平跨入全市前列；广电网络实现光纤化、互联网协议（IP）化、智能化；智慧广电成为服务新区数字经济、数字政府、数字社会和民生建设的重要平台。

二、主要任务

（一）推进新区“壮美广西·智慧广电”内容生产体系建设

推进新区高清电视发展项目建设。完成广电网络所有标清单向机顶盒更换工作，实现传输网络升级，实现全网高清化。

（二）建设“壮美广西·智慧广电”传播网络体系

1.推进新区数字广西“广电云”村村通户户用工程建设。2019-2021年完成新区新增发展数字广西“广电云”用户257户。

2.推进新区广电网络IPv6项目建设。协同推进基于互联网协议第六版（IPv6）在广电网络中的部署与应用。积极配合推进广播电视基础网络全面支持IPv6，大力推进新区广电网络升级改造，实现广播电视领域内容、平台、网络、终端全流程IPv6部署，实现市辖广播电视媒体网站系统支持IPv6访问。2021年，广电网络满足支持IPv6业务接入和承载需要，安全保障体系实现全面升级。

（三）推进新区“壮美广西·智慧广电”服务生态体系建设

推进广西智慧广电家庭项目在新区应用。2019-2021年，进一步丰富和拓展广播电视服务经济社会的功能，推动广播电视与政务、商务、教育、医疗、旅游、金融、农业、环保等相关行业的合作。

三、保障措施

（一）加强组织领导。成立阳和工业新区“壮美广西·智慧广电”工程领导小组，组长由党工委委员、管理委员会副主任担任，副组长由社会事务局局长担任，成员由财政局、社会事务局和阳和街道办事处各1名负责同志担任。领导小组办公室设在社会事务局，办公室主任由社会事务局局长兼任。

（二）落实工作责任。社会事务局负责监督工程实施，阳和街道办事处协调各村委积极配合完成此项工作，广西广播电视信息网络股份有限公司柳州分公司具体实施工程建设，各部门要统筹做好新区“壮美广西·智慧广电”工程的组织、管理和推进工作，制定项目建设实施方案，明确分工、落实责任，切实把各项工作落到实处。

（三）加强政策扶持。各部门要积极争取将“壮美广西·智慧广电”工程纳入新区经济社会发展规划统筹部署，合力推进。要充分争取和利用各级各类资金，加大对“壮美广西·智慧广电”工程的投入，支持“壮美广西·智慧广电”工程建设。
