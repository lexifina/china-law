# 关于印发鹿寨县项目资金配套工作经费管理办法（2014年修订）的通知

各乡镇人民政府，县直各单位：

《鹿寨县项目资金配套工作经费管理办法（暂行）》已经县人民政府研究同意，现将印发给你们，请贯彻执行。

2014年5月4日

鹿寨县项目资金配套工作经费管理

办法（2014年修订）

为鼓励调动县属各单位、各部门向上级争取资金的积极性，加大向上级争取资金工作的力度，促进全县经济和社会各项事业又好又快的发展，结合我县实际，特制定本办法。

一、配套工作经费的原则

县人民政府每年在财政预算内安排一定数量的资金用于对各单位、各部门争取上级支持资金配套相应的工作经费。配套工作经费的申请和使用应遵循以下原则：

（一）促进我县经济发展的原则。

（二）实事求是的原则。

（三）配套工作经费用于项目的原则。

二、配套工作经费的范围和对象

配套工作经费的范围：争取上级对我县经济建设和各项社会事业发展方面及其他专项用途的各类资金（含实物换货币的项目，如争取征地指标等），重点是项目建设资金。

配套工作经费的对象：鹿寨县所属各乡镇人民政府、县直各党政机关、行政事业单位。

三、工作经费配套的标准

（一）上级全额负担资金的项目

1．在无上级政策文件的情况下，主动向上级业务部门争取到的各类无偿资金且不要求配套项目资金的予以争取资金2%的工作经费配套。

2．在有上级政策文件的情况下，主动向上级业务部门争取到的各类无偿资金且不要求配套项目资金的给予争取资金0.5%的工作经费配套。

（二）需要配套资金的项目

1．在无上级政策文件的情况下，主动向上级业务部门争取到的各类无偿资金，但要求配套项目资金且配套项目资金的比例小于项目资金20%的，给予争取资金1.5%的工作经费配套。

2．在无上级政策文件的情况下，主动向上级业务部门争取到的各类无偿资金，但要求配套项目资金且配套项目资金的比例大于项目资金20%的给予争取资金1%的工作经费配套。

3．在有上级政策文件的情况下，主动向上级业务部门争取到的各类无偿资金但要求配套项目资金且配套项目资金的比例小于项目资金20%的，给予争取资金0.3%的工作经费配套。

4．在有上级政策文件的情况下，主动向上级业务部门争取到的各类无偿资金，但要求配套项目资金且配套项目资金的比例大于项目资金20%的，给予争取资金0.2%的工作经费配套。

（三）每年都有的项目资金按照年项目资金的增量部分予以1%的工作经费配套。

（四）共同争取资金的工作经费安排：两个以上部门共同完成的争取上级支持资金，分清该项目资金的主要争取部门和配合部门。由两个部门共同争取的，主要争取部门占配套工作经费金额的70％，配合部门占配套工作经费金额的30％；由两个以上部门共同争取的，主要争取部门占配套工作经费金额的60％，各配合部门合计占配套工作经费金额的40％。

四、配套工作经费申请程序

各部门、单位要于每年3月底前向县人民政府报告上年度争取上级支持资金的情况，同时上报争取资金的有关项目前期文件、申请投资计划及其他有关审批文件、上级部门下达的投资计划、追加指标文件、拨款通知单、银行到帐单等有关资料交县财政局，按财政资金管理使用程序报县政府审批同意，由县财政局拨付到各单位经费帐户。上报材料要分类逐项按每笔款项不同的数额列出清单，不得共同计算，未申报的视为放弃，超过上报期限的不再受理。

争取上级支持资金以当年实际到帐为准。当年申请次年到位的，列入下年度申报。

五、配套工作经费使用范围

配套工作经费用于项目申报前期工作及获上级资金项目实施过程中的各项费用支出，主要包括编制项目建议书及可行性研究报告、编制环评报告、勘察、初步设计、施工图设计、组织专家评估、招标代理等前期工作费用及申报、实施项目时的监理服务、项目验收、差旅、办公等支出，不得用于发放个人补贴及各项奖励。

六、监督检查

每年年底县人民政府组织监察局、审计局、财政局对各单位的配套资金使用情况进行检查，对违反使用规定的，除收回配套工作经费外将给予通报批评。

七、附则

本办法从2014年1月1日起执行。

抄送：县委各部门，各人民团体，县人大办、政协办，县法院、检察院，县工商联。

鹿寨县人民政府办公室 2014年5月5日印发
