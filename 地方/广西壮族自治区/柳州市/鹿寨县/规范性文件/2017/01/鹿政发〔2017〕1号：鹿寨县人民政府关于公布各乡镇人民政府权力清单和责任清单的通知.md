# 鹿政发〔2017〕1号：鹿寨县人民政府关于公布各乡镇人民政府权力清单和责任清单的通知

鹿政发〔2017〕1号

鹿寨县人民政府关于公布

各乡镇人民政府权力清单和责任清单的通知

各乡镇人民政府，县直各单位：

根据《鹿寨县推行乡镇人民政府权责清单制度实施方案的通知》（鹿政办发〔2016〕68号）精神，各乡镇人民政府的权力清单和责任清单已经县第十七届人民政府第7次常务会议审议通过，现予以公布，并将有关事项通知如下:

一、各乡镇人民政府权力清单和责任清单，以及制定的权力运行流程图，需在鹿寨政府门户网站、各乡镇网站和各乡镇政务服务中心的办事窗口设置固定板块予以公布。

二、各乡镇人民政府权力清单和责任清单具有刚性约束力，各乡镇要严格按照权力清单和责任清单行使职权，严格执行“法无授权不可为、法定职责必须为”，不得擅自变更权力、变相行使已取消、下放的权力事项，切实维护权力清单和责任清单的严肃性、规范性、权威性。

三、各乡镇人民政府权力清单和责任清单实行动态管理，各乡镇人民政府权力清单和责任清单的调整，由各乡镇人民政府提出，经县机构编制部门审核后报县人民政府审定。

四、各乡镇要以此为抓手，进一步完善权力运行机制。县政府督查室、县机构编制、监察、绩效管理等部门要建立有效监督检查机制，确保权力清单和责任清单制度的实施。
