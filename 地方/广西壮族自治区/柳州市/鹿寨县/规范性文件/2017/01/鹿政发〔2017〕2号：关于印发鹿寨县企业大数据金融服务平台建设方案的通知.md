# 鹿政发〔2017〕2号：关于印发鹿寨县企业大数据金融服务平台建设方案的通知

鹿政发〔2017〕2号

鹿寨县人民政府关于印发鹿寨县企业大数据金融服务平台建设方案的通知

各乡镇人民政府，县直各单位：

根据我县社会经济发展情况，为综合评价我县企业发展状况，缓解中小企业融资难的现状，扶持我县的中小企业茁壮成长，同时促进我县企业扶持和招商选资良好有序进行，《鹿寨县企业大数据金融服务平台建设方案》已经县第十七届人民政府第6次常务会议审议通过，现印发给你们，请认真贯彻执行。

2017年1月9日

鹿寨县企业大数据金融服务平台实施方案

根据我县社会经济发展情况，为缓解中小企业融资难的现状，拟运用新产品、新商业模式，大力发展电子商务，顺势而为，乘势而上，通过引进大数据技术、运用云计算等新一代信息技术发展电子商务新业态，综合评定我县企业发展状况，为企业申报企业扶持政策、金融信贷等提供评级，扶持我县的中小企业茁壮成长，同时促进我县招商选资良好有序进行，特制定《鹿寨县企业大数据金融服务平台实施方案》。具体如下：

一、工作任务及实施步骤

（一）工作任务

本方案工作任务为建成鹿寨县企业大数据金融服务平台（以下简称平台）。平台主要是针对政府行政职能设计的为中小微企业、政府管理服务的定制平台，包括数据检索、数据体检、信用跟踪、经济治理、信用应用等板块，以政府为主导开展社会治理，依托金电联行的大数据技术和分析优势，利用平台开展信用体系建设，提供大数据社会治理服务，社会数据管理、信用评价、信用融资及金融风险管理等服务，加入更多社会资源为企业和政府管理服务。

主要内容为：建成一个集信用信息采集、存储、处理、展示、分析等数据服务于一体的企业大数据金融服务平台，充分运用大数据先进理念、技术和资源，加强对区域内企业的信用信息服务和监管，满足职能部门和金融机构在区域内中小微企业融资及市场监管等工作中的信用信息需求，提高政府服务水平和监管效率，降低服务和监管成本。平台将结合全国性信息数据库与鹿寨县的区域性数据，建立具有鹿寨县特色的企业信用信息数据库；建立适合鹿寨县企业评价服务的征信标准，确保数据安全、规范数据采用；充分挖掘信用数据的价值，提供企业信用信息的发布、查询与评价等服务；具备规模化的筛选和跟踪能力，满足日常监管需要；强化信用信息的公开、推广信用产品的使用，探索建立有鹿寨县特色的中小微企业信用服务长效机制。

平台以鹿寨县辖区企业为扶持对象，将有融资需求的企业，通过平台录入日常生产经营数据后生成的金融信用报告推荐给合作的担保公司、商业银行等金融机构，利用企业信用贷款贴息等补助形式，大力实施鹿寨县信用贷款工程，使信用信息良好、有劳动能力、有贷款意愿和一定还款能力的商户能够得到信用贷款；同时对于申请政府扶持政策的企业也可通过平台对企业申报材料真实性给予核实。

（2实施步骤

第一阶段，建成鹿寨县企业大数据金融服务平台。将政府的政务公开信息、企业的基础信息、职能部门的信息同时录入平台，并要求政府各职能部门定期导入数据，税局定期更新税务数据，金电联行公司定期更新自有接入的20多个国家部委办局和200多个行业数据，为我县规模以上和限上企业或需要评优、评先的企业进行体检。平台建成后首批为我县规模以上和限额以上100家企业进行免费体检，并将其体检报告推送至合作的银行等金融机构，为有资金需求的且满足信用评分标准的企业提供信用贷款，并为企业、政府、金融机构制定不同的电脑客户端，方便各部门查询和信息管理。

第二阶段，搭建制度平台。为保障平台健康、稳定运行，健全企业评价体系的记录、共享、使用机制，需要搭建企业评价制度体系，构建中小微企业评价体系服务平台。首先确定各部门的权限，制定数据的定期征集制度、数据信息的分类和使用制度、数据信息的监督制度、数据信息的管理制度，形成全方位的制度体系。

第三阶段，在搭建信用信息融资服务平台的同时，可以逐步将平台扩展，开展多种金融服务。在搭建信用信息平台的基础上，扩大平台的使用范围，提高平台的使用率，不断积累企业信息，为平台提供多维度的数据。

（二）经费保障。平台搭建经费71万元，其中平台建设费66万元，两年运营维护费5万元。资金列入县级财政预算安排。

三、结果运用

依托大数据理念、技术和资源，通过对数据采集、挖掘、清洗、分析和应用，为鹿寨县人民政府建立以大数据为基础的信用服务应用，把企业管理和政府服务相结合、为辖区园区管理者提供决策依据，为金融机构提供信息支撑。通过平台实现企业和政府双方都更透明，政府部门之间的数据共享更深入。利用平台促进政府服务水平提升，惠及企业、金融机构等多重社会主体。通过平台为县域内中小企业提供信用评价及体检，为企业对接金融机构、政府扶持资金、招投标项目等多种资源服务，有效的促进了辖区内的中小企业健康、平稳发展。

具体功能如下：

（一）企业信用报告查询服务。包括企业信用记录检索、企业族谱检索服务、环境分析服务、企业定位服务、企业信用跟踪服务等；

（二）县域内企业运行分析。包括企业状态分析、企业对比分析、企业业务活动监管、重点企业监控等；

（三）县域经济活力与创新。包括商业环境评价、企业信用记录检索、企业董事监事高级管理人员分析等；

（四）企业风险预警。包括风险预警防控、资质到期提醒；

（五）企业信用报告。包括企业信用报告应用领域、内容以及标准。
