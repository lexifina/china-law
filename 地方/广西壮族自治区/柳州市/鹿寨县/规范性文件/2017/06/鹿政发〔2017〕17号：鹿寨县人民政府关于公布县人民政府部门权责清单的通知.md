# 鹿政发〔2017〕17号：鹿寨县人民政府关于公布县人民政府部门权责清单的通知

鹿政发〔2017〕17号

鹿寨县人民政府关于公布

县人民政府部门权责清单的通知

各乡镇人民政府，县直各单位：

根据自治区、柳州市关于深化权责清单工作、推行政府部门权力清单和责任清单“两单融合”的工作部署，县人民政府对2016年公布的县人民政府部门权力清单和责任清单进行“两单融合”，修订形成新的县人民政府部门权责清单，并已经县第十七届人民政府第18次常务会议审议通过。现就有关事项通知如下：

一、本次“两单融合”后县级保留的县人民政府部门权责清单，在县人民政府门户网站、编制清单的部门网站设置固定板块予以公布。

二、经县人民政府审定的部门权责清单具有刚性约束力,县直各部门要严格按照权责清单行使职权，严格执行“法无授权不可为、法定职责必须为”，依法规范行使法定的权力，并全面履行与权力事项相对应的责任，不得擅自变更权力、变相行使已取消、下放的权力事项，切实维护权责清单的严肃性、规范性和权威性。

三、县人民政府部门权责清单实行动态管理，根据法律法规规章的颁布、修订、废止和国务院、自治区调整行政审批事项以及部门职能变化情况，及时调整完善县人民政府部门权责清单。县人民政府部门权责清单的调整，由县直相关部门提出，报县机构编制部门按规定程序办理。

四、县直各部门要进一步完善权力运行机制。县人民政府督查部门和县机构编制、监察、绩效管理等部门要加强监督检查，确保县人民政府权责清单切实发挥应有作用。县直各部门要聚焦权力行使易发多发问题的关键环节，适应政府管理从事前审批向事中事后监管方式的转变，强化部门行使权力的事中事后监管责任，建立健全监管和问责机制，努力推进法治政府、责任政府建设。
