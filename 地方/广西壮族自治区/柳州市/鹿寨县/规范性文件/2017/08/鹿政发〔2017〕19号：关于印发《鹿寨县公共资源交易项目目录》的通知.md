# 鹿政发〔2017〕19号：关于印发《鹿寨县公共资源交易项目目录》的通知

鹿政发〔2017〕19号

鹿寨县人民政府

关于印发《鹿寨县公共资源交易项目目录》的

通知

各乡镇人民政府，县直各单位：

为加快落实《国务院办公厅关于印发整合建立统一的公共资源交易平台工作方案的通知》（国办发〔2015〕63号）、《广西壮族自治区人民政府办公厅关于印发整合建立统一的公共资源交易平台实施方案的通知》（桂政办发（2016）13号）和《柳州市人民政府关于印发柳州市整合建立统一的公共资源交易平台实施方案的通知》（柳政发〔2016〕34号）工作要求，积极有序推进各类公共资源交易纳入统一平台体系，根据《柳州市人民政府关于印发的通知》（柳政发〔2016〕69号），结合我县实际，对《鹿寨县公共资源交易项目目录》（以下简称《目录》）进行调整并予以公布，现就有关事项通知如下：

一、严格按照《目录》载明的项目范围开展公共资源交易活动。凡列入《目录》并且达到集中交易标准的项目，应纳入鹿寨县公共资源交易平台集中交易；因特殊情况暂不纳入的，须上报县人民政府批准。未列入《目录》的项目，由项目业主自主选择是否进入鹿寨县公共资源交易平台。

二、公共资源交易行政监督管理部门按照职责分工，推进列入《目录》并且达到集中交易标准的项目，纳入鹿寨县公共资源交易平台集中交易工作，对不按规定集中交易的违法违规行为依法予以查处。凡进入鹿寨县公共资源交易平台集中交易的项目（含自主选择进入），按照统一的规则和标准交易，行政监督管理部门应加强集中监管。

三、公共资源交易行政监督管理部门根据国家、自治区、柳州市、鹿寨县有关规定，分析梳理本行业公共资源交易管理和配置情况，凡符合市场化配置条件的公共资源交易项目，按照“成熟一项、推动一项、进场一项”的原则，及时上报县人民政府审定，补充列入《目录》;依法不再纳入公共资源交易平台集中交易的项目，经县人民政府批准后可调整出《目录》。

四、本《目录》自印发之日起施行。

附件：《鹿寨县公共资源交易项目目录》
