# 鹿政发〔2017〕20号：关于公布第五批鹿寨县文物保护单位的通知

鹿政发〔2017〕20号

鹿寨县人民政府

关于公布第五批鹿寨县文物保护单位的通知

各乡镇人民政府，县直各单位：

为保护我县文化遗产，进一步丰富我县历史文化内涵，县人民政府核定县文体新广局确定的寨沙仁里邓氏祠堂、黄冕三里寨墙、寨沙浪州炮楼、寨沙全波龙岩寨墙、民国中渡县政府大楼等5处具有历史、科学、艺术价值的文物点为第五批鹿寨县文物保护单位。现公布5处文物保护单位名单以及保护范围,文物保护单位所在乡镇、各有关部门要按照《中华人民共和国文物保护法》等法律法规,进一步贯彻“保护为主、抢救第一、合理利用、加强管理”的工作方针，科学规划，妥善处理文化遗产保护与经济发展、人民群众生活条件改善的关系，认真做好我县文物保护单位的保护、管理和合理利用工作。

附件：第五批鹿寨县文物保护单位目录

2017年8月9日

公开方式：主动公开

察院，自治区、市驻鹿各单位。
