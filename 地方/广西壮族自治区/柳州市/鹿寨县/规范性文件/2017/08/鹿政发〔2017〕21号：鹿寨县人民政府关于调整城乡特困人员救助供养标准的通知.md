# 鹿政发〔2017〕21号：鹿寨县人民政府关于调整城乡特困人员救助供养标准的通知

鹿政发〔2017〕21号

鹿寨县人民政府

关于调整城乡特困人员救助供养标准的通知

各乡镇人民政府，县直各单位：

为切实保障城乡特困人员的基本生活，根据《广西壮族自治区人民政府关于进一步健全特困人员救助供养制度的实施意见》（桂政发〔2016〕79号）文件精神,以及我县经济社会发展水平和物价指数的变化，经研究，决定调整我县城乡特困人员救助供养标准，即：城市特困人员救助供养标准为680元/人·月，农村特困人员救助供养标准为400元/人·月，从2017年1月1日起执行。

2017年8月9日

公开方式:主动公开

抄送：县委办、县人大办、县政协办，县法院、县检察院。

鹿寨县人民政府办公室 2017年8月9日印发
