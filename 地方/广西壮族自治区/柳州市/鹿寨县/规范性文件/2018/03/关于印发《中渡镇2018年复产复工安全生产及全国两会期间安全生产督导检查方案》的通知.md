# 关于印发《中渡镇2018年复产复工安全生产及全国两会期间安全生产督导检查方案》的通知

各村（居）民委、镇安委会各成员单位：

为切实做好企业复产复工安全生产工作，确保全国“两会”期间全乡安全生产形势稳定，根据县安委会有关文件要求，制定《中渡镇2018年复产复工安全生产工作及全国“两会”期间安全生产督导检查方案》，现印发你们，请结合实际认真抓好落实。

中渡镇人民政府

2018年3月2日

中渡镇2018年复产复工安全生产工作及全国“两会”期间安全生产督导检查方案

为切实做好企业复产复工安全生产工作，确保全国“两会”期间全市安全生产形势稳定，根据市安委会有关文件要求，制定如下督导工作方案。

一、督导检查时间

即日起至全国两会结束，具体时间由各小组结合实际情况确定。

二、督导检查方式

成立督导检查领导小组，由镇领导带队对烟花爆竹、危险化学品、景区、非煤矿山等行业的重点企业开展检查，并督促、指导各村委辖区内烟花爆竹、危险化学品、景区、非煤矿山等行业的企业落实复产复工和全国“两会”期间安全生产有关工作要求。

三、督导检查重点内容

检查重点：（1）中心校：厨房用水用电、宿舍用水用电、体育设施安全稳固情况，教学楼楼道疏散通道及逃生标志、警示标识、灭火器材配备情况以及安全隐患排查落实整改情况等。

水电站方面，检查防护警示牌设立情况，护栏设立情况、禁止入内警示标牌设立情况；施工现场方面，检查安全施工制度牌设立情况、工人佩戴安全帽情况、企业主投入安全生产资金及设备情况、企业开展安全生产培训情况、是否强令冒险作业情况以及安全隐患排查整治落实情况等。

旅游景区方面，检查游客住宿用水用电安全状况、旅游设施安全状况、景区工作人员安全知识培训情况、救生抢险设施和安全人员配备情况、客房疏散通道及灭火器材配备情况。

交通运输方面，检查是否存在无证驾驶、超员超载超速等交通违法行为，车辆是否检验合格、是否购买强制保险等；农机是否非法载人等。

危险化学品方面，检查加油站、集镇煤气供应站，证照是否齐全，安全距离是否符合规定，安全隔离设施是否完好、安全操作是否合规，检查烟花爆竹是否安全存放。

（6）施工工地方面，检查施工现场安全施工制度牌设立情况、工人佩戴安全帽情况、企业主投入安全生产资金及设备情况、企业开展安全生产培训情况、是否强令冒险作业情况以及其他安全隐患排查落实整改情况等。

（7）非煤矿山方面，重点排查采石场通风、提升运输、排水、供电等系统，针对采掘工作面可能存在坍塌、火灾、爆炸和采空区垮塌等情况，对边坡、排土场等存在安全隐患一律不得复工复产。

（8）其他企业，主要检查各种安全生产制度是否完善，设备设施是否安全有效，复产复工前是否对生产设备进行检查，对员工是否进行安全生产知识培训。

四、督促整改

对检查出现的安全隐患，须立即责成责任人限期整改，并跟踪落实责任人隐患整改的落实情况。

五、通报制度

对检查发现的安全隐患，经检查组提醒后仍拒不落实整改措施的，镇人民政府将对其予以书面通报批评。

六、行政处罚和人事处分

对检查发现的安全隐患，经检查组提醒后仍拒不落实整改措施，情节严重的，依法应予行政处罚的，镇人民政府将报请县安监局对其给予行政处罚。

依法应对责任人进行处分的，依据《安全生产法》、《行政机关公务员处分条例》、《事业单位人事管理条例》等法律法规进行处分。

属于上级主管部门管理的单位或者人员，镇人民政府将书面行文函告其主管部门， 并提出处分建议。
