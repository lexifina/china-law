# 关于印发《中渡镇2018年民兵组织整顿实施方案》的通知

各村（居）委会：

经研究决定，现将《中渡镇2018年民兵组织整顿实施方案》，印发给你们，请结合实际情况，认真贯彻执行。

中渡镇人民政府

2018年3月8日

信息公开方式：主动公开

中渡镇党政办公室　　　 　 2018年3月8日印发

中渡镇2018年民兵组织整顿实施方案

根据县人民武装部《关于明确“十三五”时期民兵组织规模结构的通知》文件指示精神，结合本镇实际，制定如下实施方案：

一、指导思想

根据军委国防动员部的总体部署要求，以及广西军区《民兵调整改革方案》，结合鹿寨实际，经过系统分析研判，“十三五”期间，鹿寨县民兵平时主要担负协助维护社会秩序、参加抢险救灾、支援地方建设等任务，战时担负安全警戒、维护社会秩序、保交护路、保障军兵种部队作战和参加联合防空、地面防卫作战、应急应战力量补充等任务。

二、组织领导

为加强我镇民兵组织整顿工作的组织领导，特成立2018年国防后备力量队伍组织整顿工作领导小组，成员名单如下：

组 长：韦家东 镇党委副书记、镇长

副组长：古树忠 镇党委委员、武装部长

成 员：莫瑞祥 镇党政办常务主任

韦丽琼 镇团委书记

李仁兵 镇派出所所长

陈 科 镇卫生院院长

韦 昌 镇武装干事

领导小组下设办公室，办公室设在镇武装部，办公室主任由镇武装干事韦昌同志兼任，具体负责处理整组工作日常事务。

三、主要任务

我镇民兵组织经过今年的组织整顿，布局更趋合理，结构明显改善，质量建设逐步提高。2018年度的民兵组织整顿工作，要在巩固以往工作成果的基础上，按照“任务牵引、因地制宜、分类指导、突出重点”的要求，将基干民兵组织主要整合为应急救援、勤务保障两大类进行编组，打牢后备力量遂行作战保障和非战争军事行动任务的组织基础。我镇民兵队伍坚决完成上级下达的各种任务，以及平时抢险救灾、社会维稳、处置突发事件和应急救援等非战争军事行动任务。

四、组织编成

今年上级赋予我镇基干民兵任务数162人，组建各类分队3支。（一）应急民兵分队65人，（二）专业民兵分队96人，（三）特殊力量分队1人。

五、方法步骤

全镇民兵组织整顿工作分为组织准备、组织实施和检查验收三个阶段，从2018年3月1日开始，至3月20日结束。

（一）组织准备阶段（2018年3月1日-2018年3月8日）在调查研究的基础上，搞好潜力调查、需求分析，制定组织整顿工作计划，抓好业务培训；二是搞好调查摸底，对本区域的适龄青年，复转退伍军人和符合服预备役条件人员进行一次细致的摸底，切实掌握第一手资料；部署整组任务，搞好宣传教育。

（二）组织实施阶段（2018年3月8日-2018年3月15日）按照组织整顿工作的要求，合理划分工作阶段，分步骤抓好工作落实。要广泛开展组织整顿宣传教育，增强全民的国防意识，提高广大人民群众参加、支持民兵预备役工作的积极性。要严格执行政策，准确掌握标准条件，审定出入对人员，调整组织，配备干部，修订活动制度，补充完善基本设施，搞好簿册表的填写，组织基干民兵集结点验。

（三）整理归档迎接检查验收阶段（2018年3月15日-3月20日）主要工作是：按照《民兵组织整顿检查验收标准》，搞好整组资料的完善和归档，组织开好点验大会。

六、标准和要求

组织落实是民兵预备役工作的基础，是政治、军事落实的前提，也是逐行各项任务的基本保证。各村要把整组工作作为当前应急作战准备最紧迫的任务，周密组织部署，加大工作力度，为提高民兵预备役部队战斗力奠定坚实的基础。

（一）认清形势任务，突出整组重点，提高后备力量建设质量。随着形势变化、任务拓展和市场经济的不断发展，民兵建设面临许多新情况、新问题。新形势下，后备力量建设既面临许多矛盾和问题，也面临难得的发展机遇。各村一是要充分认清新形势下预备役部队和民兵的地位作用，充分认清搞好组织整顿工作的重要意义，充分认清本级在组织整顿实施过程中肩负的责任，坚持把做好组织整顿工作作为提高后备力量建设质量的基础性工程，是当前和今后一个时期民兵建设改革发展的重要任务，加大工作力度，狠抓工作落实，努力提高我镇民兵队伍尤其是重点分队的建设质量。二是要突出实战需求，抓好新编分队组建。要按照“编为用，建为战”和有利于组织领导，有利于提高质量，有利于执行任务的原则抓好编组，扩大编组范围，提高在编人员的退伍军人比率，党员比率，专业对口比率和在位率。三是突出维稳应急，加强应急分队建设。应急队伍是维护社会稳定的一支骨干力量，也是地方防卫作战的重要力量，要不断完善应急分队建设，使之成为社会维稳，抢险救灾和处置突发事件的突击力量。

（二）以科学发展观指导我镇民兵组织建设，解决问题促发展。一是要解决编组质量不高的问题。二是要解决交叉重叠编组问题。三是要解决分队建设不规范的问题。四是要解决基干民兵日常管理难的问题。

（三）加强组织领导，确保组织整顿工作落到实处。一是要成立领导小组。村主要领导要亲自挂帅。二是要把整组工作作为第二季度的中心工作，认真组织实施。三是要抓好民兵的管理教育，开好点验大会。各村要加强民兵的跟踪管理教育，严格注销假制度，确保人员在位率不得低于90%。
