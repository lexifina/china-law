# 关于印发2018鹿寨中渡古镇国际越野跑嘉年华赛医疗卫生救援应急方案

各乡镇卫生院，县直各医疗卫生单位：

为保障2018鹿寨中渡古镇国际越野跑嘉年华赛运动员意外伤害及期间发生自然灾害、事故灾难、公共卫生、社会安全事件等突发公共事件（以下简称突发公共事件）发生后，各项医疗卫生救援工作能迅速、高效、有序地进行，增强医疗卫生部门应对各类突发公共事件的应急响应能力，提高医疗卫生救援水平，最大限度地减少人员伤亡和健康危害，保障人民群众身体健康和生命安全，维护社会稳定。根据《中共鹿寨县委办公室 鹿寨县人民政府办公室关于印发2018鹿寨中渡古镇国际越野跑工作方案的通知》、《鹿寨县突发公共事件医疗卫生救援应急预案》，特制定本方案。

一、指导思想

以党的十九大精神及习近平新时代中国特色社会主义思想为指导，确保2018鹿寨中渡古镇国际越野跑嘉年华赛期间医疗卫生救援保障工作迅速、高效、有序地进行，最大限度地减少人员伤亡，维护人民群众身体健康和生命安全，促进社会稳定。

二、适用范围

本方案适用于2018鹿寨中渡古镇国际越野跑嘉年华赛期间运动员意外伤害及发生于本县域范围内的突发公共事件所导致的人员伤亡、健康危害的医疗卫生救援工作。

三、医疗卫生救援指挥机构及职责

为规范医疗卫生救援应急工作流程，提高医疗卫生救援水平，最大限度地减少人员伤亡和健康危害，特成立医疗卫生救援应急指挥小组（以下简称指挥小组）。成员如下：

指挥小组负责2018鹿寨中渡古镇国际越野跑嘉年华赛期间统一指挥、协调运动员意外伤害及突发公共事件的医疗卫生救援工作。指挥小组下设应急办公室，办公室主任由潘声平兼任，副主任由黄宝卫、张坤旭兼任。应急办公室的主要职责为协调2018鹿寨中渡古镇国际越野跑嘉年华赛期间发生的运动员意外伤害及突发公共应急事件的医疗卫生救援工作。

四、医疗卫生救援应急响应

接到突发公共事件医疗卫生救援报告后，医疗救援应急指挥小组有关负责人应迅速到位履行职责，及时组织实施相应的突发事件应急预案，并立即报告县人民政府，经批准启动县级医疗卫生救援应急响应，迅速组织实施现场救援、病员转运和院内救治等。若发生食物中毒等事件，立即配合有关部门开展调查处置。

五、医疗卫生救援保障

为确保2018鹿寨中渡古镇国际越野跑嘉年华赛期间（5月19日）运动员意外伤害及突发公共事件医疗救援应急工作的有序开展，从而在医疗救援处理过程中能做到现场指挥及时果断，事故报告及时准确，事故处理认真负责，特要求做好如下保障工作：

（一）设立现场医疗救护站点

具体医疗急救站点详见附件（2018鹿寨中渡古镇国际越野跑嘉年华赛事医疗保障人员安排表）。主要承担2018鹿寨中渡古镇国际越野跑嘉年华赛赛道运动员的突发意外卫生救援工作。

（二）做好急救备勤工作

1.鹿寨县人民医院为运动员突发意外伤害定点收治单位。县人民医院、县中医医院及中渡镇中心卫生院要做好期间120急救备勤工作。各单位要做好救治准备，在接到突发事件医疗卫生救援报告后，院长要指示本院立即开通“绿色通道”，安排相关科室做好急救的准备工作。县人民医院、县中医医院做好与柳州市120的请求联系工作。

2.各乡镇卫生院应做好急救备勤工作。各乡镇卫生院应组建好后备医疗急救组，保证急救车辆正常运行、医疗设备正常运转，相关人员电话通畅，确保意外发生时调度及时敏捷投入施救工作中。

（三）强化县120急救指挥分中心工作

县120急救指挥分中心接到报告电话后，立即调派足够的急救车辆保证救援工作及时有效地开展。并同时及时把有关情况上报县卫生计生局值班人员。

（四）突发公共卫生事件应急救援保障

县疾病预防控制中心做好应对2018鹿寨中渡古镇国际越野跑嘉年华赛期间食物中毒事件流行病学调查应急准备工作，安排好人员和相关设备，随时待命；县卫生计生监督所做好期间生活饮用水、公共场所卫生监督工作。两个单位负责做好应急保障风险评估。

六、工作要求

（一）为切实做好2018鹿寨中渡古镇国际越野跑嘉年华赛医疗卫生救援工作，各单位领导要高度重视、精心组织、周密部署，确保期间医疗保障工作及时、高效、有序开展。

（二）期间其他乡镇卫生院组建好后备医疗急救组，保证急救车辆正常运行、医疗设备正常运转，相关人员电话通畅，确保意外发生时调度及时敏捷投入施救工作中。

（三）各单位抽派的医护人员及司机（见附件）已开展了相关培训工作，请各相关人员务必服从安排、认真负责、严守岗位，保持电话通畅，随时做好运动员意外伤害的医疗保障工作。

（四）县120急救分中心指挥人员要坚守工作岗位、工作认真负责，保证快速接报、迅速安排、合理调车、及时汇报。

（五）若有突发事件发生，相关单位及个人要做好信息汇报及保密工作，不得随意向外发布伤病员有关信息。县卫生计生局要及时向县人民政府报告有关情况。
