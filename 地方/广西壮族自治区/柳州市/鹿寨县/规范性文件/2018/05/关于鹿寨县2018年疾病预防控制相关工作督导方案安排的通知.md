# 关于鹿寨县2018年疾病预防控制相关工作督导方案安排的通知

各乡镇卫生院、县直医疗卫生单位：

为切实做好全县疾病预防控制工作，全面掌握工作开展动态，及时发现、解决存在问题，我局将组织开展对结核病和麻风病防控、疟疾防治、基本公共卫生服务项目、慢性病管理、重性精神疾病管理、艾滋病防治、免疫规划管理、传染病防控与卫生应急等工作进行督查指导。现就相关工作要求如下。

一、各单位要按照2018年卫计工作要点和疾病预防控制工作任务，做好各项疾病防控工作。

二、县疾病预防控制中心负责具体督导指导任务。要求现场督导检查后将情况反馈被检查单位，针对发现的问题及时出具督导指导意见书，督促各单位落实整改措施。

三、各单位要加强组织领导，针对存在问题要及时组织整改，并将整改情况反馈给县疾病预防控制中心。

四、根据中央八项规定要求，督导组到各单位督查要厉行勤俭节约，严格遵守廉洁从政有关规定。

附件：2018年全县疾病预防控制相关工作督导安排。

2018年5月17日

公开方式：主动公开

鹿寨县卫生和计划生育局办公室 2018年5月17日印发
