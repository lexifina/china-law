# 寨沙镇人民政府关于印发《寨沙镇2018年“美丽广西·宜居乡村”农村改厕改厨实施方案》的通知

各村民委：

现将《寨沙镇2018年“美丽广西·宜居乡村”农村改厕改厨实施

方案》印发给你们，请结合实际情况，认真贯彻执行。

2018年5月23日

寨沙镇2018年“美丽广西·宜居乡村”

农村改厕改厨实施方案

为持续贯彻落实自治区“美丽广西·宜居乡村” 活动部署，根

据鹿寨县住房和城乡建设局《鹿寨县2018年农村改厕改厨工作实施方案》文件精神，为确保按期完成上级下达的工作任务，结合全镇加快生态文明建设及村庄环境整治工作，特制定本实施方案。

一、总体要求

深入贯彻落实党的十九大精神，以习近平新时代中国特色社会主义思想为指导，围绕人民对美好生活的向往，持续改善农村人居环境，建设美丽宜居乡村为目标，通过实施农村“改厕改厨”工作，建成符合实际、满足群众生活基本需求、经济适用、卫生方便的农村无害化卫生厕所和干净清洁厨房。

二、目标任务

2018年，寨沙镇要完成农村改厕1600户，农村改厨1600户（各村指标数详见附件1）。

三、资金安排

根据桂财建〔2018〕35号文件精神，2018年度农村厕所改造户均补助1200元，农村厨房改造户均补助700元。其中，自治区财政负责50%，市级财政补助30%，县级财政配套20%。

四、改造对象

结合我镇农村改厕、改厨工作实际情况，合理确定改造对象。改厕对象确定的顺序为：无厕户和旱厕户优先，有卫生厕所但未达到无害化处理条件次之，再到有无害化厕所但非卫生厕所的农户。在确定农村改厕改厨对象时，应结合脱贫攻坚工作，对建档立卡贫困户、五保户、低保户、残疾人家庭、计生困难家庭等5类特殊对象给予优先保障。

五、改造内容及标准

按照“群众自愿、补贴基本、经济可行”的原则，由农民根据自身条件选择基本型、舒适型或小康型的建设类型。

一是改造农村厕所。以改善居住条件、预防疾病传染、提高宜居水平为目标，按照“统一标准、统一设计、统一生产”的要求，以建设和完善“两池一洗”（化粪池、便池、冲洗设备）为主要内容，参照广西农村三格式无害化卫生厕所建造标准，对1600户农村厕所实施无害化卫生厕所改造。要引导农村户厕进院入户，因地制宜选择标准化的无害化处理设备或设施。用水条件较好的村屯，倡导建设水冲式厕所，推广使用三格化粪池；沼气池较普及的村屯，积极开展利用沼气池实施无害化卫生厕所改造。干旱缺水的村屯，可以选择建设节水型无害化卫生厕所或者增加负压式节水冲洗装置。

新建或改造无害化卫生厕所的农户，在保障“两池一洗”设施建设的基础上，农户可按舒适型或小康型改造厕所，铺装瓷砖、增加采光通风、添置卫浴设备，提高舒适程度，同时规范使用卫生厕所，形成良好的卫生习惯。

二是改造农村厨房。以建设干净整洁卫生、满足基本功能、管线安装规范、烟气排放良好的清洁厨房为目标，对1600户农户厨房实施以“改灶、改台、改柜、改管、改水”为主要内容的改造，按照“五改”标准，以及缺什么、补什么的要求建设农村清洁厨房，整体提高农村厨房卫生整洁程度。改灶，即改用节能灶具，增加排烟装置；改台，即对厨房灶台、案台铺装瓷砖，增加通风、采光；改柜，即将厨房敞开式橱柜改为密闭式橱柜；改管，即将厨房的电线、燃气管线、沼气管线等进行固定、归整；改水，即改造厨房上下水道、储水池、洗菜池等设施，做好厨房排水与化粪池或村屯排污系统的连接。对于已具备基本功能，但设施布局不当、摆放凌乱、整体较差的厨房，应参照农村清洁厨房的基本要求进行归整，达到干净、明亮、整洁的基本要求。经济条件较好的农户要在实施“五改”的基础上，可以增加瓷砖铺装面积、选用成品厨具橱柜、提高舒适整洁程度，彻底解决黑、脏、乱问题。

六、改造范围

改造活动在全镇22个村同步进行。改厨改厕必须100%完成全覆盖的村屯：传统村落及2014、2015年“美丽柳州”乡村建设综合示范村屯、“美丽柳州.生态乡村”示范村提升建设的村屯、2017年“美丽柳州”乡村建设综合示范村屯、自治区级绿色村屯、自治区乡土特色示范村屯、农业核心示范区村屯、柳州市每年评出的十大美丽乡村、易地扶贫搬迁、脱贫村等重点村屯。

七、工作步骤

（一）动员摸底阶段（2018年3-4月）。根据上级有关文件要求，制定工作方案。按照鹿寨县的工作安排，根据下达的目标任务，组织开展入户调查统计，准确摸准未达到无害化卫生厕所户数；加强宣传发动工作，确定实施改造的村屯、对象和改造内容，开展项目设计和资金测算；按照村民自愿申请、村委集中评议公示、乡镇审查核定、县审批的程序确定各改造户及改造内容，由镇政府与改造村屯、改造村屯与改造农户签订改造任务承诺书，明确改厕改厨的内容和完成时限，落实任务指标，理顺工作环节，营造良好氛围。

（二）建设实施阶段（2018年10月30日前）。按照自治区既定的改造标准、设备标准、验收标准，根据实际情况合理选择建设方式，并在规定时限内完成改造项目建设任务。以农民自建、联建、群众组织专业队伍、农村工匠承包、企业参与等推进项目建设。项目建设应按照先易后难、先重点后一般、整村推进的原则循序推进。

（三）验收支付阶段（2018年12月31日前）。在11月底前组织并完成辖区范围内的项目验收，配合县住房和城乡建设局在12月上旬组织相关部门抽查核验。按照一户一档收集整理项目档案材料，建立农村厕所改造数据库。2018年11月30日前形成改造工作报告。2018年12月31日前完成资金支付。

八、工作要求

（一）加强领导，明确责任。落实地方工作责任，镇人民政府是农村改厕改厨工作的责任主体，负责组织发动各村群众，召开会议，宣传政策，审核公示各项资金补助情况，协调处理供料、供电、供水等问题及工程管理等事项。驻村工作队负责指导村委会开展项目建设，参与项目调查及审核工作，及时完成上级交办工作。村委会负责配合乡镇宣传发动，带领群众筹资投劳、协助施工，处理纠纷、质量监督等事项。各相关部门各司其职，做好涉及本部门的相关工作。

（二）因地制宜，因村施策。“两改”的前提是保障基本。活动开展必须从各地实际出发，区分不同情况，突出分类指导。改厕改厨的基本要求是完善“两池一洗（化粪池、便池、冲洗设备）”和实施“五改（改灶、改台、改柜、改管、改水）”，建设基本型、舒适型和小康型三种不同类型。经济条件较好的农户，可以适当提高装修标准、添置更多的设备，提高舒适程度；经济条件一般的农户和贫困户，改造的重点在于具备基本功能、满足基本需求，干净、整洁、卫生。在实施过程中要注重整体提升，不搞过度拔高，不搞盲目攀比。要根据经济发展条件和各村各户实际，考虑地形地貌、农业生产方式、疾病流行特征、农户生产生活习惯以及农村现有资源条件等方面因素，制定不同工作方案。要探索切合本地实际强调经济性和可行性，尽可能做到“一村一策”“一户一策”。

（三）加强监督，确保资金安全。要切实加强资金使用过程的监管，严肃财经纪律，确保财政补助资金使用安全、高效，把资金补助到最需要的农户。补助资金绝不能远邻近亲，绝不能重复享受，绝不能套用。要充分利用新闻媒体，大力宣传农村“两改”政策，对违反廉政纪律的索贿、受贿的典型案例予以公开曝光，加强社会舆论监督，营造良好的社会氛围，让农民感受到党好的政策。

（四）群策群力，共同推动。政府要作为，农民要主动，积极引导社会资本参与建设。一是引入新机制。充分挖掘当地人力资源，以专业队伍、建筑工匠为主力，农民投工投劳，能人带头、工匠领衔，鼓励村民自发组建劳务队伍、农民成立工程承包施工队参加项目建设。二是要积极探索，敢于创新。在去年“两改”已有的工作模式上，大胆推广政府+企业+农户的模式，大力推广使用合格一体式三格化粪池等成套设备，让有资质的企业参与进来，加快“两改”进度，确保按期完成任务。

（五）强化指导，确保质量。要做好改造任务的组织实施，加强技术指导服务，组织村委、自然村屯具体负责人员和施工人员，进行专业技术规范培训，保证管理和施工人员掌握技术，按规范施工；要确保工程质量和施工安全，每个村屯要落实专人负责监管质量，督促施工人员把好质量关，防止偷工减料、降低标准。改造后的厕所应达到无害化标准，确保工程质量和使用寿命符合标准要求，符合国家标准，并且质量达标。要建立健全改厕改厨质量管理制度，实行工程质量和安全责任制，加强质量巡查监督，在保证安全和控制成本的前提下，严把质量关，改造后必须达到主要部件合格、结构安全和基本功能齐全，要建成放心工程、效益工程。项目完成后，应制定相应的管理措施，后续使用管理应以村民自管为主。

（六）加强督查，确保成效。各村要加强对项目进度的跟踪管理，自2018年5月份起，于每月1日、10日、20日前将本村项目进展情况报送至镇人民政府。

（七）奖补引导，量力而行。“改厕、改厨”是利民的好事，但也是农民的家事，要突出农民的主体地位，尊重农民意愿，坚持农民自愿的原则，不搞硬性摊派，不搞强迫命令，主要通过宣传、教育、鼓励、帮扶来引导农民群众积极参与项目建设。

（八） 完善基础档案。要认真复核需上报的统计数据，特别是农户厕所已达到无害化标准的，要予以确认并完善档案，确保数据真实、准确；将已改造并且达标的农户信息全部录入系统，基本实现“一户一档”，为迎接各项检查评估打好基础。
