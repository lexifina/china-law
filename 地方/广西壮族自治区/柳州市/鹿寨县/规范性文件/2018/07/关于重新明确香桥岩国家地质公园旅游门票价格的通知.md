# 关于重新明确香桥岩国家地质公园旅游门票价格的通知

鹿寨县旅游发展局：

根据《广西壮族自治区人民政府关于在市场体系建设中建立公平竞争审查制度的实施意见》（桂政发〔2016〕58号）文件精神，为体现我县旅游市场的公平性，现对《关于调整香桥岩国际地质公园旅游门票价格的批复》（鹿价字〔2011〕18号）文中批复事项重新明确如下：

一、全票价格为60元/人·次（含组团旅客）。

二、70岁以上老人（凭有效证件）、身高1.2--1.4米（含1.4米）儿童价格为30元/人·次，1.2米以下（含1.2米）儿童免费。

三、因公致残的人民警察、革命伤残军人、现役军人免费。
