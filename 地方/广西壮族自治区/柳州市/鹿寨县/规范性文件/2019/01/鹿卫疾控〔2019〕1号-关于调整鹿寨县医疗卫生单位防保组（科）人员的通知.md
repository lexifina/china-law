# 关于调整鹿寨县医疗卫生单位防保组（科）人员的通知

鹿卫疾控〔2019〕1号

关于调整2019年鹿寨县医疗卫生单位防保组（科）人员的通知

各乡镇卫生院，县直各医疗卫生单位：

鉴于部分单位防保组（科）工作人员变动，为使我县疾病预防控制和公共卫生服务工作队伍得到保障，决定调整各单位防保组（科）人员。各单位防保组（科）人员要保持稳定，未经我局同意，任何单位或个人不得随意变换其工作岗位。调整后的人员名单如下：

一、县直医疗卫生单位

县疾病预防控制中心免疫规划管理科：潘原勇、韦桂华、郭思明、彭万芬、廖梅姣、卢开雪、王霄雯

县人民医院：肖存燕、覃盼、何秀英、赖宇萍

县中医医院：吕艳菊、黄艳玲

县妇幼保健院：李琳燕、张 唯

二、乡镇卫生院
