# 关于转发《关于做好全区医师定期考核工作的通知》的通知

各乡镇卫生院，县直各医疗卫生单位，驻鹿厂(场)医院，民营医院，各个体诊所，县公安局、教育局各医务室：

现将《广西定考办关于做好全区医师定期考核工作的通知》（桂医定考办〔2019〕1号）转发给你们，请各单位按文件做好本年度医师定期考核工作。现将我县相关工作通知如下：

从2019年起，全区医师定期考核启用新改版升级的“国家卫生健康委员会医师定期考核信息登记管理系统”（https://renew.cmda.net）进行报名、考核和登记管理。采取“互联网+”医师定期考核的模式（医师使用手机“医师服务”APP在线考核），在规定的时间节点内进行考核。各项要求及时间节点详见《广西定考办关于做好全区医师定期考核工作的通知》（附件1）。

启用新系统后，医疗机构、医师个人信息将从电子化注册系统导入，只有完成电子化注册的医疗机构内已经完成电子化注册的医师才能进行定期考核相关操作。新的医疗机构账号详见附件2，初始密码为机构账号后六位，初次登录之后系统会提示更改密码。各医疗机构负责定期考核工作负责人务必先登录医疗机构账号，完善本机构基本信息，特别是科室设置（如本医疗机构内注册有内科的医师，则务必设置内科，否则本机构内注册内科的医师将无法完成个人信息编辑，后续则不能进行定期考核工作）。

各医师个人账号为进行电子化注册时所注册的身份证号，密码为该身份证号后六位，首次登陆后系统会提示更改密码。

未尽事宜请与我局医政医管股联系，联系电话：6815093。
