# 鹿政发〔2019〕5号：鹿寨县人民政府关于印发《鹿寨县推进工业高质量发展建设现代制造城任务分解表》的通知

鹿政发〔2019〕 5 号

鹿寨县人民政府

关于印发《鹿寨县推进工业高质量发展建设现代制造城任务分解表》的通知

各乡镇人民政府，县各有关单位：

根据《中共柳州市委员会 柳州市人民政府关于印发的通知》（柳发〔2018〕15号）、《柳州市人民政府督查室关于对柳州市推进工业高质量发展建设现代制造城重点任务进展情况开展持续跟踪督查的通知》（柳政督发〔2018〕87号）文件，为进一步促进鹿寨县工业高质量发展， 经县委、县人民政府同意，现将《鹿寨县推进工业高质量发展建设现代制造城的任务分解表》印发给你们，并就有关事项通知如下：

统一思想，提高认识

为深入贯彻习近平总书记对广西工作重要指示精神，依据鹿心社、陈武同志在推进柳州市工业高质量发展建设现代制造城会上的重要讲话，县委、县人民政府做出推进鹿寨县工业高质量发展建设现代制造城的重大决策部署。全县各部门要高度统一思想，充分认识推进工业高质量发展、建设现代制造城的重大意义。齐心协力建设高端、智能、绿色、高效的现代制造城。

制定方案，落实责任

各牵头单位要对工作任务逐条研究、准确把握，明确工作目标、主要措施、完成时限、责任人员等，要担负起组织协调、督促检查、情况汇总和报告反馈的职责。各责任单位要积极主动配合牵头单位做好工作，及时向牵头单位反馈落实情况。

汇总信息，及时报送

一是各责任单位对照主要任务内容，每季度月底向牵头单位报送工作进展情况；各牵头单位汇总整理，于每季度结束后次月2日前将进展情况报送县科工贸局，由县科工贸局汇总后于每季度结束后次月5日前报送县委、县政府。报告内容主要包括工作完成总体情况、经验做法、存在问题及原因、下步工作意见建议等。配合单位和牵头单位报送的报告需经单位领导签发并将盖章版和可编辑版通过电子政务公文交换系统报送，对不按期上报的单位，将依据有关规定实行效能问责。

加强督考，确保落实

县委督查室、县政府督查室要突出重点，适时对各单位责任目标完成情况开展督促检查。县绩效办将推进鹿寨县工业高质量发展建设现代制造城重点任务纳入全县绩效考核内容进行考核。要通过强化督查检查和绩效考核，确保各项工作目标和任务按时按质完成。
