# 关于印发2019年全县基层卫生健康工作要点的通知

各卫生医疗机构:

根据2019年全国基层卫生健康工作会议、自治区卫生健康委办公室《关于印发2019年全区基层卫生健康工作要点的通知》和柳州市卫生健康委《关于印发2019年全市基层卫生健康工作要点的通知》（柳卫基卫〔2019〕10号）文件精神，我局制定了《2019年全县基层卫生健康工作要点》，现印发给你们，请结合实际，认真贯彻落实。

2019年4月25日

公开属性：主动公开

鹿寨县卫生健康局办公室 2019年4月25日印发

（网络传输）

2019年鹿寨县基层卫生健康工作要点

2019年全县基层卫生健康工作的总体要求如下:全面贯彻落实党的十九大、十九届二中、三中全会精神和根据2019年全国基层卫生健康工作会议、自治区卫生健康委办公室《关于印发2019年全区基层卫生健康工作要点的通知》精神和柳州市卫生健康委《关于印发2019年全市基层卫生健康工作要点的通知》（柳卫基卫〔2019〕10号文件精神，进一步做好我县基层卫生健康工作，助推健康鹿寨建设。

（一）实施广西基层医疗卫生机构能力建设行动计划。加快2018年乡镇卫生院能力建设项目进度，配合自治区开展乡镇卫生院能力建设实施情况中期评估工作，推动2019年乡镇卫生院能力建设项目申报工作。加大对我县基层医疗卫生机构能力建设支持力度。组织开展全县村卫生室标准化建设摸底调查，指导各乡镇推进产权公有(政府办)村卫生室建设。2019年预计有新增业务用房1600平方米。积极向政府争取基层医疗卫生机构能力建设行动计划实施方案(2017-2020年)其中的乡镇基础设施建设和设备购置资金。

（二）做好优质服务基层行活动。扎实推进做好优质服务基层行活动各项工作，重点提升基层机构医疗卫生服务能力；加强医疗质量安全管理，加强基层医疗卫生机构特色科室建设，持续提升基层医疗卫生服务能力和服务质量；对达到基本标准或推荐标准的基层医疗机构进行逐级审核、验收，推动达到推荐标准的乡镇卫生院且符合相关条件参加二级医院评审。

（三）启动社区医院建设试点。遴选具备较好条件的基层医疗卫生机构作为自治区社区医院建设试点，坚持基层机构防治结合的功能定位和公益性质，在现有乡镇卫生院的基础上，加挂社区医院牌子。

二、强化基层医疗卫生人才队伍建设

（一）落实基层医疗卫生人才培养工作。2019年计划招录村卫生室订单定向医学生25人左右，做好生活补助的申请和下拨工作。配合做好订单定向医学本、专科生的培养和全科医生的转岗培训工作，配合落实订单定向医学本、专科毕业生的就业安排工作。

（二）做好基层人才培训项目。做好中央补助广西基层卫生人才能力提升培训项目实施工作，对67名在岗管理人员、全科医生、护理人员及乡村医生等进行业务培训，提升乡村医生基本医疗和基本公共卫生服务能力。

（三）加强乡村医生队伍管理。落实《广西壮族自治区乡村医生从业管理办法》，加强乡村医生的准入和退出管理。做好乡村医生执业证书有效期满再注册工作。加快推进乡村一体化管理工作，推动乡村医生实行“乡聘村用”。加快完善乡村医生养老生活补助政策。

（四）做好全科医生培养、聘用工作。配合推进全科医生使用激励机制改革，提升全科医生职业吸引力。鼓励和引导优秀医疗卫生人才到乡镇卫生院从事全科医疗工作。配合做好特岗全科医生的招聘及人员管理工作，落实特岗全科医生待遇。指导、配合做好全科转岗培训合格的医师执业注册工作，缓解基层医疗卫生机构全科医生紧缺的问题。

三、做实做细家庭医生签约服务

（一）稳步实施家庭医生签约服务。坚持“签约一人、履约一人、做实一人”的基本目标，推动家庭医生签约服务与医保支付方式改革、分级诊疗制度建设等改革工作的衔接，健全家庭医生签约服务支持政策，加强政策宣传；完善家庭医生签约服务信息系统，加快实现签约服务信息化。

（二）规范开展家庭医生签约服务。指导各乡镇严格按照《关于规范家庭医生签约服务管理的指导意见》(国卫基层发〔2018〕35号)，规范开展家庭医生签约十一项服务。切实发挥家庭医生团队的咨询服务、健康教育、重点人群随访等基本作用，积极推进个性化服务。组织开展家庭医生签约服务业务培训。

（三）健全完善签约服务评价和激励机制。督促各县(区、新区)落实《柳州市家庭医生签约服务包及收付费实施方案(试行)》、《柳州市家庭医生绩效考核方案 (试行)》和《柳州市改革完善全科医生培养与使用激励机制实施方案》等文件精神，规范和完善签约服务内容、收付费标准、绩效考核、激励机制等；扩大内部分配自主权，推动设立全科医生津贴项目，提高家庭医生收入待遇。

四、提升基本公共卫生服务绩效

落实地方财政事权和支出责任，足额保障基本公共卫生服务项目经费。配合自治区开展基本公共卫生服务项目实施十年绩效评估，总结基本公共卫生服务项目实施效果，推广典型经验，落实资金奖惩挂钩制度。稳步推进电子健康档案向个人开放，提高健康档案利用率。建立以全科医生为核心的基本公共卫生服务团队，加强服务内容的防治结合。强化高血压、糖尿病患者、严重精神障碍患者、结核病患者等规范管理，启动糖尿病医防融合管理试点工作。加大宣传力度，开展国家基本公共卫生服务项目宣传活动，持续提高居民知晓率。

五、推动深化基层医疗卫生机构综合改革

（一）进一步完善基层财政保障和激励机制。落实提供基层医疗卫生机构结余资金中用于职工福利基金和奖励基金比例的政策。进一步探索基层医疗卫生机构人事薪酬制度改革，完善基层医疗卫生机构“托低不限高”的绩效工资政策。指导各乡镇卫生院按照“两个允许”，合理核定基层绩效工资总量和水平，允许基层自主确定基础性和奖励性绩效工资比例。推动完善基层医疗服务价格相关政策，提高诊疗费、手术费、护理费等医疗服务收入占总收入的比例。

（二）加快推进医联体、县域医共体建设。大力推进三(二)一医联体建设，配合推进县域医共体建设，乡镇卫生院参与率达到70%以上。

（一）加快推进远程医疗服务。指导各乡镇卫生院按照《广西国家级贫困县基层医疗卫生机构临床服务服务能力提升试点项目实施方案》要求，落实好试点地区基层远程医疗建设项目，加快构建以远程影像、远程心电、远程会诊等中心为主要应用的基层远程医疗服务体系。

（二）推动建立互联网+家庭医生签约服务。进一步完善基于人口健康信息平台的广西家庭医生签约服务系统的建设应用，支撑家庭医生依托信息化手段为居民提供在线签约、在线预约、在线咨询、在线随访、健康管理、报告查询、延伸处方等服务。

（三）推进基层医疗卫生机构信息系统互联互通。建立基层卫生管理信息系统，配合推动广西基层医疗卫生机构管理信息系统运行使用；依托人口健康信息平台，推进基本医疗、电子健康档案、计划免疫、妇幼保健、精神卫生等系统与基层机构信息系统的互联互通，减轻基层负担。

七、加强党风廉政和行风建设

加强学习和有效落实《中国共产党纪律处分条例》，认真履行“一岗双责”，不断加强理想信念、党纪法规和从政道德教育，增强廉洁从政意识，切实抓好党风廉政建设和反腐败工作。改进工作作风，配合相关部门将基层医疗卫生机构行风建设纳入年度工作目标，从思想道德机制、管理机制、制约机制入手，完善相关规章制度，狠抓源头管理，重点规范医药购销活动，促进医疗服务三合理(合理用药、合理检查、合理诊疗)，打击骗取医保和救助资金等行为。
