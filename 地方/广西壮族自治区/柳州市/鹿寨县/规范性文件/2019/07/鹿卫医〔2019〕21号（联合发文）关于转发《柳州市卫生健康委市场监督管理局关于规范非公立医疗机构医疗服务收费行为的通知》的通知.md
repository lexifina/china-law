# 鹿卫医〔2019〕21号（联合发文）关于转发《柳州市卫生健康委市场监督管理局关于规范非公立医疗机构医疗服务收费行为的通知》的通知

鹿卫医〔2019〕21号

关于转发《柳州市卫生健康委 市场监督管理局

关于规范非公立医疗机构医疗服务收费

行为的通知》的通知

各民营医院，各个体诊所、门诊部：

现将柳州市卫生健康委 市场监督管理局《关于规范非公立医疗机构医疗服务收费行为的通知》（柳卫财务〔2019〕5 号）转发你们，并提出以下要求：

一、各民营医院，各个体诊所、门诊部认真清理本医疗机构正在开展的医疗服务项目、价格及收费标准，并在醒目位置进行公示。于7月22日前将公示栏拍照图片传至局医政体改和中医股存档。

二、县卫生健康局、市场监督管理局联合适时对该项工作进行督查。

县卫健局联系人：罗炳丽，6815093，邮箱：chubb@126.com；

县市场监督管理局联系人：韦任飞，6462011。
