# 鹿政发〔2019〕14号：鹿寨县人民政府关于公布第六批鹿寨县文物保护单位的通知

鹿政发〔2019〕14号

鹿寨县人民政府

关于公布第六批鹿寨县文物保护单位的通知

各乡镇人民政府，县直各单位：

为保护我县文化遗产，进一步丰富我县历史文化内涵，县人民政府核定县文体广旅局确定的中渡东门码头、中渡护城河城墙、中渡飞机洞炮楼等3处具有历史、科学、艺术价值的文物点为第六批鹿寨县县级文物保护单位。现公布三处文物保护单位名单以及保护范围、建设控制地带。文物保护单位所在乡镇、各有关部门要按照《中华人民共和国文物保护法》等法律法规,进一步贯彻“保护为主、抢救第一、合理利用、加强管理”的工作方针，科学规划，妥善处理文化遗产保护与经济发展、人民群众生活条件改善的关系，认真做好我县文物保护单位的保护、管理和合理利用工作。

附件：第六批鹿寨县县级文物保护单位目录

2019年9月17日

公开方式：主动公开

抄送：县委各部门、各人民团体，县人大、县政协，县法院、县检察院，自治区、市驻鹿各单位。

鹿寨县人民政府办公室 2019年9月17日印发
