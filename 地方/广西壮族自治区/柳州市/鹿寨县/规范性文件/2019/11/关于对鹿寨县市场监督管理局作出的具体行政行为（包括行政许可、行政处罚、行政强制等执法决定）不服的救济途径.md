# 关于对鹿寨县市场监督管理局作出的具体行政行为（包括行政许可、行政处罚、行政强制等执法决定）不服的救济途径

1.公民、法人或者其他组织认为鹿寨县市场监督管理局作出具体行政行为（包括行政许可、行政处罚、行政强制等执法决定）侵犯其合法权益的，可以自知道该具体行政行为（包括行政许可、行政处罚、行政强制等执法决定）之日起六十日内向鹿寨县人民政府或者柳州市市场监督管理局提出行政复议申请。

2.公民、法人或者其他组织不服复议决定的，可以在收到复议决定书之日起十五日内向鹿寨县人民法院提起诉讼。复议机关逾期不作决定的，申请人可以在复议期满之日起十五日内向鹿寨县人民法院提起诉讼。

3.公民、法人或者其他组织直接向鹿寨县人民法院提起诉讼的，应当自知道或者应当知道作出行政行为之日起六个月内提出。
