# 鹿卫字〔2019〕102号关于印发《行政执法记录信息调阅监督制度》的通知

县卫生计生监督所，局机关各股室：

为推进卫生健康行政执法行为，规范行政执法程序，根据《中华人民共和国行政处罚法》和国家档案管理的有关规定，结合工作实际，我局制定了《鹿寨县卫生健康局行政执法记录信息调阅监督制度》。现印发给你们，请遵照执行。

附件：鹿寨县卫生健康局行政执法记录信息调阅监督制度

鹿寨县卫生健康局

2019年11月11日

公开方式：主动公开

鹿寨县卫生健康局办公室  2019年11月11日印发
