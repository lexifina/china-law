# 鹿卫爱卫〔2019〕4号关于印发《2019年鹿寨县健康中国行实施方案》的通知

鹿卫爱卫〔2019〕4号

关于印发《鹿寨县2019年健康中国行活动实施

方案》的通知

县教育局、扶贫办、妇女联合会，各医疗卫生单位：

为贯彻落实全国推进健康中国行动电视电话会议精神，扎实做好2019年健康中国行主题宣传活动，大力推进健康教育于健康促进工作，倡导践行健康生活方式，全面提升城乡居民健康素养水平，助力全县脱贫攻坚工作，完成健康扶贫相关工作目标和年度居民健康素养促进行动计划任务。根据柳州市卫生健康委等4部门印发的《柳州市开展2019年健康中国行活动暨健康柳州行主题宣传活动方案》（柳卫宣传〔2019〕4号）精神。现将《鹿寨县2019年健康中国行活动实施方案》印发给你们，请结合实际，认真贯彻落实。

鹿寨县卫生健康局 鹿寨县教育局

鹿寨县扶贫开发办公室 鹿寨县妇女联合会

2019年11月18日

公开方式：主动公开

鹿寨县卫生健康局办公室 2019年11月18日印发

（网络传输）

鹿寨县2019年健康中国行活动实施方案

为深入贯彻落实党的十九大精神和党中央、国务院脱贫攻坚战略决策部署和贯彻落实全国推进健康中国行动精神，根据柳州市卫生健康委等4部门印发的《柳州市开展2019年健康中国行活动暨健康柳州行主题宣传活动方案》（柳卫宣传〔2019〕4号）精神，决定在全县范围内开展2019年健康中国行主题宣传活动，推进健康教育与健康促进工作，倡导践行健康生活方式，全面提升城乡居民健康素养水平，助力全县脱贫攻坚工作。具体活动方案如下。

一、活动目标

广泛动员各方力量，开展多种形式多样的活动，积极传播健康知识和技能，引导树立健康观念，提高全县居民的健康素养水平。

二、组织管理

县卫生健康局、扶贫办、教育局、妇联共同作为活动主办单位，建立部门联合、部门协同、资源共享、协调推进的工作机制。县卫生健康局负责组织协调。卫生健康、扶贫、教育、妇联等部门负责组织开展健康中国行活动。

主题和时间 （一）活动主题

2019年我县健康中国行活动主题为“健康促进助力脱贫攻坚暨健康科普进万家”。重点围绕《广西贫困地区健康促进三年攻坚行动实施方案（2018-2020年）》（桂卫发〔2018〕15号）》，加强健康科普进万家宣传活动力度，提高健康教育服务能力，引导全县居民树立健康观念、养成健康行为、提高健康素养水平。

（二）活动时间

定于11月到12月在全县范围内开展。11月下旬在中渡镇寨上村召开全县活动启动会，开展“健康促进助力脱贫攻坚暨健康科普进万家”主题宣传活动，各乡镇在活动期间内选择1个贫困村开展相应主题宣传活动。

县卫健局、扶贫办、教育局、妇女联合会共同作为活动主办单位，建立部门协同、资源共享、协调推进的工作机制。县卫健局结合实施《广西贫困地区健康促进三年攻坚行动实施方案（2018-2020年）》，积极组织开展健康教育进学校、家庭、社区、企业、机关活动，切实提高居民健康素养，助力实现健康扶贫目标任务。教育部门以提升学生健康素养为重点，深入开展“师生健康中国健康”主题健康教育活动，围绕儿童青少年近视防治、心理健康、艾滋病防治等重点主题开展宣传活动。妇女依托线上线下妇女之家，面向广大妇女宣传普及卫生保健、科学育儿、健康养护、“两癌”防治等知识；聚焦农村和贫困地区，开展巾帼健康大讲堂，引导妇女从自身做起，带动家庭成员树立健康意识、养成良好的行为习惯和生活方式，提高健康水平。

（一）集中示范活动

11月下旬，县卫健局、扶贫办、教育局、妇女联合会在中渡镇共同组织开展集中宣传活动启动仪式，以摆放健康教育宣传展板、组织县级三家医院、疾控中心开展慢性病义诊咨询、发放健康科普知识资料等形式的集中倡导活动，启动鹿寨县健康中国行“健康助力脱贫攻坚暨健康科普进万家”主题宣传活动。

（二）分项特色活动

1.县人民医院：活动当天派2-3名专家到中渡镇开展常见病义诊活动。11月到12月，开展“健康讲座进社区，健康科普惠大众”主题宣传活动，结合健康素养66条、三减三健、自救互救等内容，依托巩固健康促进医院、健康扶贫等工作，开展形式多样的健康教育和科普宣传活动不少于2场次；同时在医院门诊大厅摆放健康教育宣传展板，利用医院视频设施播放健康教育相关宣传视频。

2.县中医院：活动当天派2-3名专家到中渡镇开展常见病义诊活动。11月到12月，组织健康科普专家在县内各部门、企事业单位开展中医养生保健进机关活动不少于2场次；同时在医院门诊大厅摆放健康教育宣传展板，利用医院视频设施播放健康教育相关宣传视频。进一步加强中医健康教育宣传，提升人民群众健康素养水平。

3.县妇幼保健院：活动当天派2-3名专家到中渡镇开展常见病义诊活动。11月到12月，开展“关注全生命周期 护航妇女儿童健康”系列科普宣传活动，主要开展妇幼健康大讲堂、世界母乳喂养周主题宣传、中国预防出生缺陷日科普宣传。

4.县疾控中心：活动当天派2健康教育骨干到中渡镇开展健康教育宣传活动。11月到12月开展“灵动儿童、阳光少年健康行动”健康科普主题宣传活动，针对学生近视、肥胖、脊柱弯曲等重点常见病和危险因素，有针对性的开展健康教育进校园活动不少于2次，普及健康科普知识，提高健康科普知识的可及性，引导儿童青少年形成自主行为健康意识，养成健康行为方式，全面提高儿童青少年身心健康水平。

5.各乡镇卫生院：11月到12月，在本乡镇开展“健康促进助力脱贫攻坚暨健康科普进万家”主题宣传活动，重点开展健康义诊和咨询、健康及急救知识互动、医疗卫生常识普及；同时在医院门诊大厅内摆放健康教育宣传展板，利用医院视频设施播放健康教育相关宣传视频，积极宣传卫生健康、疾病防治知识。

（三）组织开展健康教育骨干培训

11月底前，各乡镇卫生院推荐1-2名健康教育骨干至爱卫办建立县域内健康教育专家库。疾控中心负责加大对健康教育骨干的培养力度，帮助基层提升健康教育服务能力。

五、工作要求

（一）各医疗卫生单位要高度重视，切实加强组织领导，精心组织，周密安排，积极发动社会各界广泛参与，发挥各自优势，形成合力。要明确专人负责，把此次活动和日常的健康教育、健康扶贫、健康素养促进行动等工作统筹部署，确保主题宣传活动扎实有效。

（二）要加大宣传力度，充分利用各类媒体广泛宣传健康扶贫和贫困地区健康促进三年攻坚行动等工作进展，普及健康素养知识与技能，总结提炼好做法、好经验，积极宣传报道工作亮点和先进典型。

（三）县医院、中医院、妇幼保健院、疾控中心和各乡镇卫生院要严格按照要求完成各自承担的分项特色活动，宣传普及卫生健康科学知识，发挥健康科普专家的专业技术能力，满足人民群众对权威健康科普知识的需求。

（四）各医疗卫生单位要认真总结有效做法和经验亮点，并于11月30日前将活动总结、相关图片、视频等资料报至爱卫办邮箱。
