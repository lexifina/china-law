# 鹿政发〔2019〕17号：鹿寨县人民政府关于认定2019年鹿寨县现代特色农业乡级示范园村级示范点的决定

鹿政发〔2019〕17号

鹿寨县人民政府

关于认定2019年鹿寨县现代特色农业乡级

示范园和村级示范点的决定

各乡镇人民政府，县直各单位：

今年以来，各乡镇、各单位、各部门以习近平新时代中国特色社会主义思想为指导，大力实施乡村振兴战略，按照《鹿寨县2019年现代特色农业示范区增点扩面提质升级行动工作方案》要求，积极创建现代特色农业乡级示范园、村级示范点，为我县农业转型升级起到很好的示范带动作用。

为激励先进、树立典型，根据《广西现代特色农业示范区工作厅际联席会议办公室关于开展第七批广西现代特色农业核心示范区考评工作的通知》要求，我县组成专家组对2019年鹿寨县现代特色农业乡级示范园、村级示范点进行验收考评。根据考评结果，决定认定鹿寨县鹿寨镇古丁糖料蔗“双高”示范园等10个示范园为乡级示范园，认定鹿寨县鹿寨镇波井村前进三红蜜柚种植示范点等46个示范点为村级示范点。

希望获认定的乡级示范园、村级示范点再接再厉，严格项目建设管理，继续做好提质升级工作。各乡镇、各单位、各部门要认真总结推广现代特色农业乡级示范园、村级示范点建设经验，带动农业发展、农民增收、农村建设，为加快我县现代农业发展作出新的更大贡献。
