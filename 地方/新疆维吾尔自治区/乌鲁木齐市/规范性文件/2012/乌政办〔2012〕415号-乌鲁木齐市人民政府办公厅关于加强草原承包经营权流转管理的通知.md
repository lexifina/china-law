# 乌鲁木齐市人民政府办公厅关于加强草原承包经营权流转管理的通知

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区（头屯河区）、高新技术产业开发区（新市区）管委会，市属各委、局、办：

为了规范草原承包经营权流转行为，加强草原承包经营权流转管理和服务工作，进一步完善草原承包制度，落实草原生态补助奖励机制，根据《中华人民共和国草原法》《中华人民共和国农村土地承包法》《新疆维吾尔自治区实施<中华人民共和国草原法>办法》《新疆维吾尔自治区实施<中华人民共和国农村土地承包法>办法》以及农业部《农村土地承包经营权流转管理办法》（农业部第47号令），结合实际，现将我市加强草原承包经营权流转管理工作有关事宜通知如下：

一、市、区（县）两级草原行政主管部门要加强对草原承包经营权流转管理和服务工作，落实草原承包经营权流转备案和报告管理制度，对草原承包经营权流转情况进行监督检查，调解当事人之间发生的纠纷，纠正违反法律、法规、规章的流转行为，具体工作由各级草原监理机构负责。

二、草原承包经营权可以按照平等协商、自愿、有偿的原则依法流转。未实行承包和未办理《草原使用证》的草原不得进行流转。草原承包经营权流转不得改变草原的畜牧业用途；流转的期限不得超过承包期的剩余期限；不得损害利害关系人和农村集体经济组织的合法权益；在同等条件下，本集体经济组织成员享有优先权；受让方应当具有从事畜牧业生产的能力，并依法履行保护建设和合理利用草原的义务。

三、草原承包经营权可以采用转包、出租、互换、转让或者其他方式流转。采取转包、出租、互换或者其他方式流转的当事人双方应当向发包方和区（县）草原行政主管部门备案。

四、以转让方式流转承包草原的，应当事先向发包方提出转让申请，经发包方同意，受让方应当与发包方确立新的承包关系，原承包方与发包方在该土地上的承包关系即行终止。以转让、互换方式流转承包草原的，当事人要求登记的，应当向县级以上地方人民政府申请登记。未经登记，不得对抗善意第三人。

五、牧民承包经营的草原在本集体经济组织内部以转让方式流转的，由承包方和受让方达成流转意向，共同向发包方提出申请，经发包方同意后，到区（县）草原行政主管部门办理报告手续。牧民承包经营的草原以转让方式流转给本集体经济组织以外的单位和个人的，由承包方和受让方先达成流转意向，再共同向发包方提出申请，经本集体经济组织成员的村（牧）民会议三分之二以上成员或者三分之二以上村（牧）民代表的同意，并经乡（镇）人民政府批准后，到区（县）草原行政主管部门办理报告手续。

六、各区（县）草原行政主管部门和草原监理机构应当及时向已达成流转意向、发包方和承包方共同在本村公示15天后无异议的，符合草原承包经营权流转条件的承包方提供统一文本格式流转合同，并指导双方签订合同和进行合同鉴证。对流转合同中有违反法律法规的约定，要及时予以纠正，并且依法办理草原承包经营流转备案和报告手续，以及《草原承包合同》和《草原使用证》变更手续。依法形成的流转关系应受到法律保护。

七、各区（县）草原行政主管部门和草原监理机构应当监理草原承包经营权和流转情况登记档案，及时准确记载草原承包经营权流转情况。

八、各区（县）草原行政主管部门和草原监理机构要加强对草原承包经营权流转的清理整顿工作，对符合法定条件的，依法办理相关手续。对违法进行草原承包经营权流转的，依法进行处理。此项工作须在2012年11月底前完成。

九、各区（县）人民政府和草原行政主管部门要进一步做好草原承包工作，加快《草原使用证》发放工作，2012年底前必须完成《草原承包合同》和《草原使用证》的换发、补发等发放工作。

十、市、区（县）两级草原行政主管部门和草原监理机构要认真贯彻乌鲁木齐市人民政府办公厅《关于全面制止非法流转草原的通知》(乌政办〔2011〕325号）精神，严厉打击非法随意流转草原承包经营权，扰乱社会经济秩序，非法占有、破坏草原的行为以及买卖、开垦、擅自改变草原用途的违法行为，以维护全市正常的草原管理秩序和稳定的社会环境。
