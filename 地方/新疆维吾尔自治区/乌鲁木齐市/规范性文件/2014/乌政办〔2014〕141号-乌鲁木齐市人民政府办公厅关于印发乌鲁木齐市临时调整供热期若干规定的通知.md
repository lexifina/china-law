# 乌鲁木齐市人民政府办公厅关于印发乌鲁木齐市临时调整供热期若干规定的通知

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区（头屯河区）、高新技术产业开发区（新市区）、甘泉堡经济技术开发区管委会，市属各委、局、办，各相关单位：

《乌鲁木齐市临时调整供热期若干规定》已经市人民政府同意，现予印发，请认真遵照执行。

2014年6月17日

乌鲁木齐市临时调整供热期若干规定

为加强城市热力管理，进一步提升供热服务质量水平，维护供用热双方的合法权益，根据《乌鲁木齐市城市热力管理条例》等有关法规，制定本规定。

一、临时调整供热期的气候依据

根据气象预测，在供热期开始前10日内或供热期结束后10日内，室外平均温度连续五天低于5℃或最低温度连续五天低于0℃，以及发生强降雨、雪等可能造成生命财产损失的异常低温情况时，市人民政府可以依法对供热期进行临时调整，决定提前供热和延期停热。

二、临时调整供热期工作程序

（一）由市供热协调指挥部办公室在每年9月30日前后和次年4月6日前后组织市建委、市财政局、市气象局、市供热行办和水、电、燃气等各能源供应单位或部门进行会商，提出是否提前供热或延期停热的意见后报市人民政府审批，并组织做好各项准备工作。

（二）市供热协调指挥部办公室接到市人民政府下达的提前供热或延期停热指令后，应立即组织各区（县）人民政府、各级供热管理部门及各供热企业，根据职责分工，做好提前供热或延期停热的各项工作，并向社会公示。

（三）全市供热企业应按要求在每年9月30日前全部完成依法由供热企业负责维修、养护的供热设施检修改造、管网注水、设备冷运行和燃气购置等各项准备工作，具备随时按指令提前启动供热的条件。

（四）各供热企业接到提前供热或延期停热的指令后，应立即执行，在规定的时间范围内实现居民用户室温达到规定标准。各区（县）人民政府、各级供热管理部门应对辖区内供热企业提前供热或延期停热的情况进行监督、检查。各供热企业不得以任何形式、理由拒绝执行提前供热和延期停热的指令。

三、临时调整供热期的时间范围

提前供热开始时间不得早于供热期开始前第10日，延期供热结束时间不得晚于供热期结束后第10日。

四、资金补贴

对供热企业根据指令提前供热或延期停热而增加的运行费用，由市建委会同市财政局研究制定具体补贴办法。其中，对居民住宅和公益性用热户，根据核对后的实际燃气用量，全额予以补贴。对非居民住宅和非公益性用热户，由用热户自行承担供热费用。

五、监督措施

对不执行市人民政府提前供热或延期停热指令的供热企业，依法予以处罚，并向全社会公布曝光，将其纳入供热行业不诚信企业名单。造成恶劣后果的，由主管部门追究其主要领导的责任，并依照行业有关规定予以处理。
