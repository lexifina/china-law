# 乌鲁木齐市人民政府办公厅关于进一步加强燃气和供热管网保护工作的通知

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区（头屯河区）、高新技术产业开发区（新市区）、甘泉堡经济技术开发区管委会，市属各委、局、办，各相关企业：

为进一步加强我市燃气和供热管网安全监管工作，严厉打击破坏、损坏燃气和供热管网的违法行为，确保市政公共基础设施安全，现就有关事项通知如下：

一、统一思想，充分认识管网保护工作的重要性

燃气和供热稳定供应涉及人民群众切身利益，关系社会经济发展和社会稳定。各单位要进一步统一思想，高度重视，充分认识地下燃气和供热管网安全稳定运行的重要性，切实增强管网保护意识，认真履行工作职责，严格落实建设施工安全管理的有关要求，采取有效措施，加大管网保护力度，确保地下燃气和供热管网安全运行。

二、明确职责，形成齐抓共管工作格局

（一）加强属地监督管理。按照市委、市人民政府权限下放工作的安排部署，各区（县）人民政府要落实燃气和供热管网安全稳定运行监管责任，明确分管领导，签订责任状，落实安全生产责任制。各区（县）建设主管部门要加强燃气和供热企业运营服务监督管理，提高事故应急处置能力，确保地下燃气和供热管网安全稳定运行。按照属地管理原则，各区（县）人民政府负责监控辖区内工程施工现场落实地下燃气和供热管网保护措施，督促各燃气和供热企业做好地下燃气和供热管网日常检查工作。

（二）履行企业主体责任。一是工程建设、施工、监理单位要互相监督，共同做好地下燃气和供热管网保护工作。工程建设单位承担防止施工破坏地下管线的主要责任，负责调查、移交施工现场及毗邻区域内地下管线资料；建立与施工单位、地下管线权属单位的联络对接机制；审定地下管线防护措施；组织实施工程施工影响区域内的管线迁改、保护工作，并承担相关费用。工程施工单位承担防止施工破坏地下管线的直接责任，负责制定施工方案和应急预案，会同地下管线权属单位制定管线防护措施；机械开挖前进行人工坑探，并设置现场管线标识；施工前申报监理单位审批认可；坑探范围内未发现标注管线或与管线资料存在差异的停止施工，经地下管线权属单位现场核实确认，完成复核并补充相关资料后施工。工程监理单位负责审查施工单位地下管线防护安全专项方案，对施工单位进行动土作业审批认可，在相关工程施工时开展地下管线防护重点检查。二是燃气和供热企业承担各自管线安全管理的主体责任。加大对市政道路和居民庭院内地下燃气和供热管网的巡查频次，及时发现和处置安全隐患；主动与建设、施工单位及社区物业公司就地下燃气和供热管网保护进行对接，制定管线安全防护标准和管线迁改、保护技术方案；做好地下燃气和供热管网工程档案管理，对管线精确定位，为工程建设、设施保护、应急抢险等提供可靠技术支持和保障；加强应急值班，确保服务电话24小时畅通，抢修队伍在发生突发事件时能够及时到位。

（三）明确部门职责分工。市建委负责督促各区（县）人民政府落实燃气和供热管网安全稳定运行责任，加强燃气和供热运营服务监督管理，制定地下燃气和供热管网保护相关法规和制度。市城管委（行政执法局）负责督促道路开挖建设单位做好开挖范围内地下燃气和供热管网的保护工作，监督建设单位按照管道安全保护告知事项和安全施工要求进行施工。市住房保障和房产管理局负责督促物业公司进一步提高地下燃气和供热管网保护意识，对在辖区内道路施工开挖可能影响地下燃气和供热管网安全的，物业公司要按照“主动配合、靠前服务”的原则，及时了解掌握施工有关情况，切实加强施工监管，保障安全。市林业局（园林局）负责督促园林绿化施工单位严格落实建设施工相关安全规定，做好园林绿化工程设计和建设涉及地下燃气和供热管网的摸底工作，避免在管线上方种植根深植物以及损坏地下燃气和供热管网等情况的发生。各区（县）建设主管部门负责加大对施工单位的宣传教育力度，督促各施工单位按照“先摸清地下设施情况，后开展施工建设”的原则组织施工，杜绝施工损坏燃气和供热管线设施的现象发生。

三、严格惩处，加大事故责任追究力度

对于违规施工、恶意施工损坏或危害地下燃气和供热管网安全的责任单位和责任人，依据《乌鲁木齐市燃气管理条例》、《乌鲁木齐市城市热力管理条例》等法律、法规严肃处理；构成犯罪的，依法追究刑事责任。
