# 乌鲁木齐市人民政府办公厅关于进一步加强城市周边非法砂场关停清场工作的通知

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区（头屯河区）、高新技术产业开发区（新市区）管委会，市国土资源局、环保局、水务局、公安局、国土资源执法监察支队、国网乌鲁木齐供电公司：

为进一步做好中央环保督察迎检工作，根据《关于印发<乌鲁木齐市迎接中央环保督查重点环境问题整改清单>的通知》（乌党办发〔2017〕65号）《关于印发乌鲁木齐市突发环境问题限期整改方案的通知》（乌政函〔2017〕97号）有关要求，现就全市非法砂场关停清场工作有关事宜通知如下：

一、各区（县）要对本辖区内已认定的无证非法砂场立即开展关停、清场，对设备（附着物）进行拆除，并做好安全保障工作。由国土资源执法监察机构责令企业进行地质环境治理恢复，对拒不执行整改要求、不落实治理责任的企业，依法追究相关责任人法律责任；对采矿证过期的砂场，各区（县）政府要立即开展关停工作，下发停产通知书，对拒不停产的企业移交国土资源执法监察机构依法进行查处；各区（县）要按照《关于做好接受中央环保督察第一批档案资料收集整理工作的通知》要求，收集整理辖区非法砂场关停、清理、设备（附着物）拆除和生态修复资料，由市国土资源局指导各区（县）统一目录和封面格式，统一归档，做到一案一档（非法沙场具体名单见附件）。

二、对于历史遗留、责任人灭失且符合我市矿山地质环境治理规划的未进行生态修复的采砂场，由各区（县）政府编制治理项目可研报告，报送市国土资源局。由市国土资源局申请国家、自治区矿山地质环境治理专项资金进行治理恢复。

三、各区（县）和市国土资源局要进一步履行属地管理和行业监管职责，进一步加强对非法采砂行为的巡查检查工作力度，对新发现的无证非法采砂行为，各区（县）政府要及时关停、清场，对生产生活设施进行拆除，并移交国土资源执法监察机构依法进行查处。

四、对我市在采矿证有效期内的合法矿山，各区（县）要督促砂场业主参照建筑工地“七个百分百”的要求，严格落实扬尘污染防治工作，对拒不落实的企业，由环保部门依法进行查处。

五、各区（县）政府、各有关部门要高度重视，立即开展相关工作，确保7月31日前完成整改，并将整改情况报市国土资源局。对工作开展不力，整改工作不落实、不彻底的相关区（县）及部门要严肃问责，并追究相关责任人责任。

六、各区（县）、各有关部门要明确牵头领导，落实责任人，层层抓好工作落实；要进一步明确责任分工，加强协调配合，对工作中遇到的问题要及时沟通，形成齐抓共管、共同推进的合力，确保此项工作按期完成。

附件：《非法砂场统计表（49家）》
