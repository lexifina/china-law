# 乌鲁木齐市人民政府办公厅关于加强乌鲁木齐市医学重点专科建设的​实施意见

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区（头屯河区）、高新技术产业开发区（新市区）、甘泉堡经济技术开发区管委会，市属各委、局、办，各相关单位：

加强医学重点专科建设是深化医药卫生体制改革、推进分级诊疗制度建设、提高医疗质量和服务水平的重要举措。为深入贯彻落实《健康中国“2030”规划纲要》和自治区《关于贯彻落实<国家创新驱动发展战略纲要> 的实施意见》（新党发﹝2016﹞41号）、《关于推进新疆丝绸之路经济带核心区医疗服务中心建设方案的通知》（新政发﹝2015﹞85号）、《关于自治区分级诊疗工作的实施意见》（新政办发﹝2016﹞7号），加快完善我市医疗卫生服务体系，增强医学重点专科建设的引领和辐射作用，提出如下实施意见：

一、指导思想

认真贯彻落实党的十八大、十八届二中、三中、四中、五中、六中全会以及习近平总书记系列重要讲话精神和第二次中央新疆工作座谈会、全国卫生与健康大会、全国科技创新大会以及自治区科技创新大会精神，以区域医疗卫生发展规划为依据，以全民健康保障需求和医疗惠民需要为导向，以提高专科医疗技术水平和医疗服务能力为主要内容，努力构建一批具有我市医学特色和行业特点的、在自治区乃至国内有一定影响力的医学重点专科品牌，为深化医药卫生体制改革，完善医疗卫生服务体系，加快卫生事业发展提供科技和智力保障。

二、建设原则

（一）坚持科学规划的原则。医学重点专科的设置要符合区域卫生事业发展总体规划，要在对区域内和周边国家医疗服务需求、学科发展趋势、专科诊疗水平、专业技术队伍和学科带头人等方面进行充分调研和论证的基础上科学规划，对基础较好、实力较强、发展前景较大的专科进行重点投入和重点建设。同时，在加强医学重点专科建设的过程中，必须注意其它专科的同步发展，为重点专科发展提供有力支持。

（二）坚持错位发展的原则。按照区域卫生事业发展规划要求，相同的专科原则上只确认一个重点建设项目，避免重复建设和无序竞争；对不同层次、不同专业的专科建设，按照不同要求和标准进行分层管理和指导，形成各类专科协同发展的良好态势。

（三）坚持合作开放的原则。实施人才培养与专科建设双轮驱动战略，积极搭建平台，采取多种方式与国际、国内具有明显优势的专科团队，在临床、教学、科研、学术交流、人员培训等方面开展深入合作，发挥资源整体效益。

（四）坚持特色明显的原则。优化区域内医疗卫生资源，以提高医疗质量、临床疗效为核心，以突出特色、打造品牌专科为重点，全面提升乌鲁木齐市医疗服务能力和水平，逐步形成具有较高技术水平和特色明显的医学重点专科。

三、建设目标

到2020年，培育具备国家级医学重点专科建设条件的7个（现为1个）以上，具备自治区级医学重点专科建设条件的25个（现为14个）以上，建成市级医学重点专科40个以上，重点培养10名在自治区内有较高知名度的学科带头人，重点推广20—30项先进适宜技术。通过医学重点专科建设工作，使区域内卫生资源配置更加优化，医学诊疗行为更加规范，医疗技术水平和医学服务能力显著提高，医疗卫生服务体系更加完善，为群众提供更加“安全、有效、方便、价廉”的医疗服务。

四、主要任务

（一）建立医学重点专科管理制度。

结合区域内医疗卫生资源现状抓紧研究制定符合我市医学重点专科建设特点的配套政策，充分发挥行业主管部门在规划编制、目标定位、任务实施、成果推广、监督评估等方面的作用，建立健全医学重点专科建设项目申报、评估与公布、建设与管理、考核验收和监督检查制度，加强和促进各部门管理协同，为全面深化医药卫生体制改革、全面建成更高水平的小康社会提供有力支撑。

（二）提高医学重点专科服务能力和技术水平。

以专科发展需要为出发点，购置专科系统化建设关键设备，瞄准国内外医学科技发展前沿，学习和引进安全有效、经济适用并在国内有竞争力的新技术、新项目，提高专科服务能力和技术水平，逐步形成自己的技术特色和专科品牌，积极开展适宜卫生技术推广项目，壮大专科的辐射力和影响力，争取建成“十三五”国家区域医疗中心西北地区专科医疗中心。

（三）实施医学重点专科科技创新项目。

深入实施创新驱动发展战略，加大对医学重点专科研究领域的科技创新项目支持，以科研项目研究为龙头，以医学重点专科建设为依托，实施专科主攻方向的医学研究，以规范和指导临床工作，有效组织跨单位、跨部门、跨学科的研究队伍，集中优势科研力量开展联合攻关，增强卫生科技的核心竞争力，提高重大疾病的防治水平。探索医学重点科技项目落地、本地研究和加工生产，聚集产业集群。

（四）推进医学重点专科人才队伍建设。

建立以创新为导向的卫生人才培养机制，健全卫生人才培训制度，创新卫生人才培养模式，拓宽人才成长通道，充分发挥用人单位在人才培养、引进和使用中的主导作用。加快学科带头人的引进和培养，建立合理专科人才梯队，充分发挥人才的技术优势，塑造一批具有良好的政治素养、高尚的职业道德、较高的学术水平、较强的创造能力的创新型专科骨干，形成一支专业、年龄、学历（学位）和专业技术职称结构合理，技术力量雄厚、具备可持续发展能力的专科人才队伍。

（五）开展医学重点专科对外合作及学术交流。

采取“走出去、请进来”的方式，与疆内外科研院所、医疗机构建立附属、教学、培训关系，加强与丝绸之路经济带沿线国家地区卫生领域的交流合作，促进专科在人才培养、科研实力、技术水平等方面的提升，借力推动医学重点专科发展。积极参加国内外学术交流，了解专业发展动态与前沿，积极举办国家级、自治区级继续医学教育学习班和高级研修班，为专业发展搭建交流和发展平台。

五、保障措施

（一）加强组织领导。成立市医学重点专科建设领导小组，领导小组主要负责全市医学重点专科建设的统筹协调、整体推进。领导小组下设办公室，办公室设在市卫生计生委，主要负责领导小组日常工作，负责细化行动计划和督促落实工作。各区（县）、各相关部门、单位要建立健全领导机制，密切协作配合，按照本部门工作职责制定具体实施方案，细化工作措施，明确年度和阶段性目标任务。要把医学重点专科建设主要任务纳入到《乌鲁木齐市卫生事业“十三五”发展规划》，将医学重点专科建设贯穿于深化医药卫生体制改革、健康中国建设的全过程，给予支持。

（二）明确部门职责。市属各相关部门要按照深化医药卫生体制改革要求，明确责任，抓好落实。市卫生计生委负责牵头落实医学重点专科建设规划、编制和人才培养，研究政策措施，稳步推进医学重点专科建设；市医改办要把医学重点专科建设列入医改主要内容认真落实；市人社局要在医学重点专科人才引进方面制定有利于人才发展的优惠政策；市科技局要在医学重点专科科研立项与成果管理等方面给予政策倾斜。

（三）实施目标管理。认真落实医学重点专科建设责任制，医学重点专科承建单位负责本单位医学重点专科的建设与管理，制定专科建设与发展计划，并组织落实，建设单位主要领导是医学重点专科建设第一责任人，负责具体落实保障措施；专科带头人或负责人是医学重点专科建设的执行人，具体负责建设方案中各项任务的实施和各项指标的落实。对项目实施全过程实行动态管理和定期考核评估，对列入建设项目的临床医学重点专科，根据周期建设目标每半年组织专家考核一次，对未按规定的要求和进度实施建设或达不到相应建设目标的医学重点专科，予以警告并限期整改；对不能如期改进达到要求的撤销建设项目并追回拨款，确保医学重点专科建设项目落实到位。

（四）加大资金投入。财政部门对确定为重点专科建设的项目，要给予一定的资金支持，并加强对重点专科建设经费使用的监管，严格实行专款专用。各重点专科所在医院要在医疗收入中按一定比例安排资金配套，确保专科建设顺利实施。

（五）健全激励机制。根据医学重点专科建设特点，建立以科技创新质量、贡献、绩效为导向，与岗位职责目标相统一的收入分配制度和稳定增长机制，促进重点专科的健康发展。绩效分配改革和职称评定中要注重体现科技创新贡献，向科技创新人才倾斜，调动和激励科研人员开展创新型研究项目。对学科带头人和专业骨干要在科研项目立项、外出进修，参加国内外学术交流等方面优先选送，对有特殊贡献的专业人员予以重奖，对专科优势突出，在自治区乃至全国产生较大影响的重点专科和诞生高水平学术论文或科研成果的医学重点专科，予以表彰和奖励。

（六）营造浓厚氛围。通过广播、电视、网络、报刊等各类媒体，加大对市医学重点专科的宣传力度，重点对专科特色、学科带头人以及发展成果进行宣传，通过举办不同形式的研讨会、交流会，加强与国内外相关专业领域的交流合作，提高重点专科的知名度，为市医学重点专科建设营造良好舆论氛围。

2017年8月7日
