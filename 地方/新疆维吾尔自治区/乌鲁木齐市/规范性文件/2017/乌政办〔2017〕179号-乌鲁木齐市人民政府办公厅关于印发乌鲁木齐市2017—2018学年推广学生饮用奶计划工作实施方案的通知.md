# 乌鲁木齐市人民政府办公厅关于印发乌鲁木齐市2017—2018学年推广学生饮用奶计划工作实施方案的通知

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区（头屯河区）、高新技术产业开发区（新市区）、甘泉堡经济技术开发区管委会，市属各委、局、办，各相关单位：

《乌鲁木齐市2017—2018学年推广学生饮用奶计划工作实施方案》已经市人民政府同意，现印发给你们，请认真遵照执行。

2017年8月11日

乌鲁木齐市2017-2018学年推广学生饮用奶计划工作实施方案

为进一步做好2017—2018学年我市推广学生饮用牛奶计划工作，切实改善全市中小学生营养状况，提高青少年身体素质，扩大乳品消费，按照自治区推广学生饮用奶计划工作总体部署，结合我市实际，特制定本方案。

一、实施范围

全市九年制义务教育阶段学生，涉及全市256所中小学、4个特教学校和2个儿童福利机构，共计307220名青少年（市教育局2016年12月学生人数统计数据）。

二、配送原则

由市学生饮用奶领导小组办公室组织成立乌鲁木齐市学生饮用奶产品采购与配送招标领导小组，通过政府采购确定招标代理机构后，委托中介机构于8月31日前完成申请我市学生饮用奶产品配送的学生饮用奶定点生产企业的招标工作。配送方式采取半进校和指定网点配送两种方式。新学年推广学生饮用奶计划政府补贴政策保持不变。

三、工作要求

按照“属地管理、分级负责”的原则，各区（县）、各部门要积极配合，各负其责，确保我市推广学生饮用奶计划工作各环节责任落到实处。

（一）各区（县）人民政府要把推广学生饮用奶计划工作纳入议事日程，明确职责，落实责任，加大资金投入，进一步加强和完善推广学生饮用奶计划工作管理机构。各区（县）学生饮用奶领导小组办公室要设立专人负责推广学生饮用奶计划管理工作，充分发挥组织、协调和监管职能，积极配合市学生饮用奶领导小组办公室解决好本辖区内学生饮用奶计划推广工作中存在的问题。

（二）充分发挥各部门的监管职能，加强和规范各环节管理工作。市教育、农牧、商务、食药、卫计、交警等部门要按照各自职责规范各环节工作程序。各部门之间要加强协调与配合，发现问题，及时解决，逐步形成由市人民政府统一领导、市学生饮用奶领导小组办公室总体协调、各部门加强监管、各区（县）学生饮用奶办公室具体组织实施的工作格局。

1．市学生饮用奶领导小组办公室（市农牧局）职责

（1）负责全市推广学生饮用奶计划工作的组织、协调，研究制定工作实施方案，完善各项管理和考核制度，组织定点生产企业招投标工作，负责统一监制、发放奶券，组织奶券审核确认及结算工作。同时开展电子奶券试点工作。

（2）负责加强奶源基地监管，以加强奶牛养殖小区建设、加快标准化奶站建设为重点，积极推进奶牛集中饲养、集中机械化挤奶和统一疫病防疫。建立学生饮用奶定点生产企业、学生饮用奶奶源基地备案制度，组织相关部门加强巡查和抽检，定期组织进行相关法律、法规以及管理要求、技术培训，确保学生饮用奶基地奶源的质量安全。

（3）定期组织召开协调工作会议，及时解决学生饮用奶推广工作中存在的重大问题。负责组织学生饮用奶各类投诉问题移交办理，对各区（县）和成员单位办理结果进行督促落实。

2．市教育局职责

（1）负责监督检查各学校学生饮用奶奶券发放情况和登记管理工作情况，组织落实全市九年制义务教育阶段学生人数的核定工作。依据每年教育事业统计数据，于每年8月31日前将全市九年制义务教育阶段学校及学生人数汇总上报至市学生饮用奶领导小组办公室（市农牧局）。

（2）组织开展学生、学生家长有关学生饮用奶补贴政策、饮奶知识以及学生饮用奶生产相关情况的宣传工作。

（3）对各区（县）教育局、各学校推广学生饮用奶计划工作落实情况进行监督检查。

3．市商务局职责

（1）负责学生饮用奶配送网点的选择、确定，研究制定配送网点管理制度。

（2）定期公布网点设置情况，对不符合配送要求、配送不及时和违规配送的网点予以取缔，加强对指定网点的监管。

（3）负责协调处理配送环节有关投诉和问题，并提出处理意见。

4．市食药局职责

（1）负责对学生饮用奶定点生产企业进行质量安全监督管理。负责乳制品销售环节的监督管理，对违法生产的行为，依法查处。

（2）根据乌鲁木齐市学生饮用奶办公室的要求开展学生饮用奶质量安全抽检工作。

（3）负责处理学生饮用奶产品质量投诉和问题。

5．市发改委职责

加强对学生饮用奶产品销售价格的监督检查。

6．市财政局职责

（1）按照市教育局提供的每学年学位生人数变化情况，对政府补贴资金进行测算。

（2）负责学生饮用奶政府补贴资金组织落实和结算工作，按照学生饮用奶资金结算程序和管理办法，加强对学生饮用奶政府补贴资金的管理。

（3）监督检查各区（县）、市本级奶券分级审核确认、奶券监销工作情况。

7．市政府新闻办职责

加大有关推广学生饮用奶计划工作的政策宣传，负责公布推广学生饮用奶计划相关信息。

8．市卫计委职责

对有关学生是否因饮奶后出现不适症状或引发其它病症问题进行调查处理，并出具调查和诊断结果报告。

9．市公安局交警支队职责

结合我市交通状况，根据市学生饮用奶领导小组办公室确认的定点生产企业目录和市商务局选择、确定的学生饮用奶配送网点，合理安排学生饮用奶供应企业配送车辆的通行路线和时间，并办理相关通行手续。

四、督导评估和管理督查

（一）市学生饮用奶领导小组将按照《乌鲁木齐市推广学生饮用奶计划工作考核标准》组织有关部门对各区（县）、各部门实施学生饮用奶计划工作情况进行督导与考核评价，督促指导各项工作落到实处。各区（县）、各部门要加强日常监管工作的落实，及时总结经验，加强推广学生饮用奶计划工作的信息报送工作，发现问题，及时反馈。

（二）充分调动教育、卫生、食药、商务、农牧等部门的积极性，整合资源，加快推进我市学生饮用奶计划工作体系的建立。相关部门要服从大局，协调配合，形成各尽其职、密切协作、相互支持、共同推进的工作局面。同时，各部门要严格按照现行法规和职责，加强对推广学生饮用奶计划工作各环节的管理和监督，严厉查处违法行为。

（三）各区（县）学生饮用奶管理机构、各相关部门于2017年9月10日前将2016—2017学年推广学生饮用奶计划工作总结纸质材料（包括电子版）报市学生饮用奶领导小组办公室。
