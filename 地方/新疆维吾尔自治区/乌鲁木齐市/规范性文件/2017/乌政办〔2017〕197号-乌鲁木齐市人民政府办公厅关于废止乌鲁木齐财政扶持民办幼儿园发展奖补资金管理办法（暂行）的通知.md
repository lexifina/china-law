# 乌鲁木齐市人民政府办公厅关于废止乌鲁木齐财政扶持民办幼儿园发展奖补资金管理办法（暂行）的通知

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区（头屯河区）、高新技术产业开发区（新市区）、甘泉堡经济技术开发区管委会，市属各委、局、办：

2017年8月2日，中共乌鲁木齐市委办公厅、乌鲁木齐市人民政府办公厅联合下发了《关于印发<乌鲁木齐市实施15年免费教育的意见>的通知》（乌党办发﹝2017﹞95号），对15年免费教育工作进行了全面安排部署。据此，市人民政府于2015年下发的《关于印发乌鲁木齐财政扶持民办幼儿园发展奖补资金管理办法（暂行）的通知》（乌政办﹝2015﹞36号）已与当前管理实际不适应，为确保政令畅通，全面贯彻 “教育惠民”政策，现决定将《关于印发乌鲁木齐财政扶持民办幼儿园发展奖补资金管理办法（暂行）的通知》（乌政办﹝2015﹞36号）予以废止，不再继续执行，不再作为行政管理的依据。

2017年8月30日
