# 乌鲁木齐市人民政府办公厅关于印发乌鲁木齐市加强铸造行业规范管理的工作方案的通知​

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区（头屯河区）、高新技术产业开发区（新市区）、甘泉堡经济技术开发区管委会，市属各委、局、办：

《乌鲁木齐市加强铸造行业规范管理的工作方案》已经市人民政府同意，现予印发，请认真贯彻执行。

2017年9月20日

乌鲁木齐市加强铸造行业规范管理的工作方案

为进一步完善我市铸造行业规范管理，引导其健康、有序和可持续发展，促进铸造行业节能减排和转型升级，根据《中华人民共和国环境保护法》《中华人民共和国大气污染防治法》和国家工信部《铸造行业准入条件》等法律法规，结合我市实际，制定本方案：

一、工作意义

铸件是我市主导产业的基础配件，铸造行业为装备制造业等产业发展提供了基础支撑，对促进我市工业经济发展发挥着重要作用。但是，我市现有铸造企业普遍存在规模小、能耗高、污染重、设备简陋、生产环境恶劣等问题，亟待解决。各区（县）、各相关部门要充分认识加强铸造行业规范管理的重要性，按照“淘汰一批、整合一批、提升一批”的目标，加大对铸造行业规范管理力度，协助落后企业转型升级，提高铸造企业的现代化生产水平，实现环保达标、节能减排，推动全市铸造行业持续健康发展。

二、工作目标

2017年12月前，对全市违法生产的铸造企业予以取缔关闭。2018年12月前，通过整合和升级，引导全市所有铸造企业全部达到国家工信部《铸造行业准入条件》规定标准。

三、工作重点

（一）严格铸造生产线项目建设管理。

全市所有新、改建铸造生产线必须符合国家工信部《铸造行业准入条件》和环保相关标准，以及我市产业布局。未达标准、不符合我市产业布局的一律不予审批。〔责任单位：市发改委、经信委、规划局、国土资源局、环保局、各区（县）人民政府〕

（二）规范企业生产经营。

严厉打击违法铸造企业，坚决关停无证无照、违法建设、不具备安全生产条件、工艺落后、环境污染严重的铸造企业；限期整改一批证照齐全，但未达到国家工信部《铸造行业准入条件》及环保排放标准的铸造企业，督促其尽快达到相关规定。〔责任单位：市环保局、城管委、工商局、安监局、经信委、各区（县）人民政府〕

（三）鼓励企业整合升级。

鼓励开展企业间整合重组和技术交流，集中技术和设备，壮大企业规模，培育壮大龙头企业。引导铸造企业合理选择低污染、低排放、低能耗、经济高效的铸造工艺，配备相应先进的生产和环保设备。支持和鼓励现有铸造企业积极开展清洁生产，依法进行清洁生产审核，大力推广清洁生产技术，不断提高清洁生产水平。鼓励采用电熔化代替冲天炉熔化，严禁使用3吨以下冲天炉等国家已明令淘汰的设备。〔责任单位：市经信委、环保局、各区（县）人民政府〕

（四）加强对铸造企业中频炉使用的监管。

对全市铸造企业进行普查。对企业和生产线项目名称、主要生产设备、配备冶炼设备情况、生产情况等进行调查；对企业使用中频炉数量、加工能力、原材料采购来源、产品种类及销售去向逐一进行核实登记，做到一企一档。预防和杜绝铸造企业使用中频炉生产和出售钢坯（锭）和钢材行为。〔责任单位：市经信委、质监局、工商局、各区（县）人民政府〕

四、工作步骤

（一）调查摸底阶段（2017年9月20日—2017年9月30日）：各区（县）对本辖区内所有铸造企业进行深入细致的排查，并登记造册、建档备查，确保不漏一家一户。

（二）查处取缔阶段（2017年10月1日—2017年12月31日）：严厉打击违法铸造企业，坚决关停无证无照、违法建设、不具备安全生产条件、工艺落后、环境污染严重的铸造企业。

（三）整合提升阶段（2018年1月1日—2018年12月31日）：以国家工信部《铸造行业准入条件》和环保达标排放为标准，督促各铸造企业实施整合重组和技术改造，提高铸造行业的整体水平。

五、工作要求

（一）加强部门联动。各区（县）政府和各相关部门要严格履行工作职责，密切配合，齐抓共管，合力推进铸造行业规范管理工作。加强对企业的政策指导，引导企业达到国家工信部《铸造行业准入条件》的相关标准。对需取缔关闭的企业，要联合执法，采取强制措施，确保应关停企业全部依法关停到位，避免关停企业死灰复燃。

（二）落实扶持政策。鼓励企业进行整合和提档升级。对新上全自动造型、浇铸整套设备，引进具有国际及全国领先水平加工设备的铸造企业，按照有关规定给予奖励扶持。对进行环保技术改造和设备投资的企业，按照有关规定给予奖励扶持。

（三）加大宣传力度。各区（县）政府和各相关部门要深刻认识铸造行业规范管理的重要意义，加强舆论引导，加大宣传力度，增强工作自觉性、主动性，引导企业发挥主体作用。

（此件公开发布）
