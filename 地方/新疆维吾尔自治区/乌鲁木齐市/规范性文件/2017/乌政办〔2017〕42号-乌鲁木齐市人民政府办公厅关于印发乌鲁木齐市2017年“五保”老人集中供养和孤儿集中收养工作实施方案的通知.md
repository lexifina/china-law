# 乌鲁木齐市人民政府办公厅关于印发乌鲁木齐市2017年“五保”老人集中供养和孤儿集中收养工作实施方案的通知

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区（头屯河区）管委会、高新技术产业开发区（新市区）、甘泉堡经济技术开发区管委会，市属各委、局、办，相关单位：

《乌鲁木齐市2017年“五保”老人集中供养和孤儿集中收养工作实施方案》已经市人民政府同意，现予印发，请认真贯彻执行。

2017年3月13日

乌鲁木齐市2017年“五保”老人集中供养和孤儿集中收养工作实施方案

为进一步保障和改善民生，提高我市“五保”老人和孤儿生活服务水平，根据自治区人民政府《关于全面建立“五保”老人集中供养和孤儿集中收养制度的实施意见》（新政发〔2017〕3号）、自治区人民政府办公厅《关于印发<2017年“五保”老人集中供养和孤儿集中收养工作实施方案>的通知》（新政办发〔2017〕8号）精神及自治区第九次党代会关于“力争到2020年有意愿的五保老人全部实现集中供养、孤儿全部实现集中收养”的重要部署，结合我市实际，现就我市2017年“五保”老人集中供养和孤儿集中收养工作提出如下工作方案。

一、基本情况

我市现有公办福利机构8所。其中，市级儿童福利机构1所；农村敬老院7所（县级1所，乡镇5所，公建民营1所）。床位886张，其中“五保”老人供养机构床位386张、儿童福利机构床位500张。全市现有“五保”老人483人，集中供养100人，分散供养383人，集中供养率21%，空置床位286张，床位空置率为74%；现有孤儿348人，集中收养孤儿250人，分散收养98人，集中收养率72%，空置床位152张，床位空置率30.4%。

目前，我市“五保”老人集中供养和孤儿集中收养工作主要存在机构床位多、集中供养率偏低，部分区（县）供养标准未能适时调整等问题.

二、重要意义

“五保”老人、孤儿是最为困难、最需要关心、关注、关爱的特殊困难群体。全面建立“五保”老人和孤儿集中供（收）养制度，是贯彻落实国务院关于健全特困人员救助供养制度有关要求和自治区第九次党代会精神的具体举措，是落实我市社会稳定和长治久安总目标的有力抓手，是保障改善民生、提高特困人员生活质量，努力增进各族群众福祉的有效途径，是打赢脱贫攻坚战、全面建成小康社会的迫切需要。    各区（县）、各部门要高度重视，充分认识做好这项工作的重要性和必要性，切实担负起推进有意愿“五保”老人和孤儿集中供（收）养工作的责任，为实现我市社会稳定和长治久安总目标打下坚实的基础。

三、目标任务

（一）完成空置床位集中供（收）养任务。积极动员引导“五保”老人和孤儿入住供（收）养机构，确保到2017年底现有各类供（收）养机构空置床位利用率达到100%，实现“五保”老人集中供养386人，集中供养率80%；孤儿集中收养348人，集中收养率达到100%。

（二）改造提升现有机构设施，完善服务功能。加快推进现有服务机构建设改造和设施达标，重点加强农村敬老院和儿童福利指导中心项目建设。对现有基础设施进行改（扩）建和设施改造、维修。2017年全面完成现有8所公办福利机构的改造提升任务，确保改造后的机构达到或超过自治区要求的供（养）条件。

（三）确保公办福利机构管理规范、高效运转。配齐、配强供（收）养机构管理服务人员，加大资金保障力度，提高供（收）养标准和服务水平，推进机构高效运转，进一步提升“五保”老人和孤儿的幸福感、获得感。

四、具体措施

（一）加强宣传引导，提高集中供（收）养率。根据民政部《关于贯彻落实<国务院关于进一步健全特困人员救助供养制度的意见>的通知》（民发〔2016〕115号）、《乌鲁木齐市五保供养办法》（乌政办〔2014〕182号）精神，严格资格认定，落实审批程序，确保符合条件且有意愿的分散供养“五保”老人和散居孤儿实现集中供（收）养。各区（县）人民政府、有关部门要通过广播、电视、报纸等媒体广泛宣传集中供（收）养有关政策，主动上门入户，逐户宣传引导“五保”老人和孤儿入住供（收）养机构，提高入住率，确保到2017年底有意愿的“五保”老人和孤儿集中供（收）养率分别实现80%和100%。

（二）改造提升现有供（收）养机构。

1.改造提升农村敬老院。根据我市“五保”老人集中供养实际需求，各区（县）对现有的农村敬老院进行改建、扩建和维修改造。改造提升后，达到抗震要求和消防验收标准，并按照《老年养护院建设标准（建标144—2010）》相关规定，设置相关辅助用房、配齐设施设备。单张床位面积、无障碍设施、应急呼叫系统设施以及消防符合生活不能自理特困人员照料护理要求，维稳安保一键式呼叫系统、安保器材、安全监控系统等符合安保要求。

2.完善儿童福利机构配套设施，提升服务功能。加快推进自治区儿童福利指导中心项目建设。对市儿童福利院现有基础设施、居室、活动室、康复室等辅助用房进行维修改造，配备相关学习、康复设施设备。完善服务功能，提升服务水平，充分利用现有资源发挥最大效益。

3.统筹各类资源。公办养老机构，优先保障“五保”老人集中供养，在完成我市有意愿“五保”老人集中供养任务后，可面向社会老人开放。供（收）养机构挪作他用的，要坚决予以收回，并全部用于“五保”老人集中供养和孤儿集中收养工作。

（三）合理设置机构和人员编制。

1.机构设置和人员编制。区（县）、乡（镇）政府举办的“五保”老人集中供养机构和市级孤儿集中收养机构，为民政部门管理的公益性事业单位，具体机构设置事宜，由市级机构编制管理部门按照管理权限审批，相关区（县）要按照《关于转发自治区机构编制委员会<关于明确农村敬老院有关机构编制事宜的通知>的通知》（新民发〔2014〕140号），于2017年上半年落实乌鲁木齐县中心敬老院、达坂城镇敬老院、米东区羊毛工镇敬老院、米东区三道坝镇敬老院、米东区柏杨河中心敬老院院长人员到位工作，并按程序进行事业单位法人登记。

“五保”老人和孤儿医疗、教育与我市医疗、教育制度相衔接，分别按照《乌鲁木齐市城乡困难居民医疗救助办法》《乌鲁木齐市城乡困难居民教育救助办法》给予救助。按照属地管理和分级诊疗的原则，建立健全医疗卫生机构与养老机构合作机制，各定点济困医疗机构负责“五保”老人和孤儿诊治工作。

2.专业人员及护理人员配备。根据《老年社会福利机构基本规范》（MZ008-2001）、《儿童福利机构基本规范》（MZ010-2001）和相关规定，“五保”老人集中供养机构和孤儿集中收养机构应结合实际需要，配备护理人员、社会工作专业人员、心理疏导员、专职康复技师及驾驶员、厨师、保安、保洁等工勤人员。其中“五保”老人集中供养机构的护理人员按照与失能失智老人不低于1：3、与生活自理老人不低于1：10的比例配备；孤儿集中收养机构的护理人员与健全儿童按照1:6的比例配备，与婴儿和残疾儿童按照1:1.5的比例配备。供（收）养机构专业人员、护理人员、工勤人员的配备数量和条件，由区（县）人民政府确定，实行动态管理。

（四）经费保障。

1.集中供（收）养机构改造建设经费。“五保”老人供养和孤儿收养机构改建、扩建、基础设施完善和改造提升，所需资金在中央、自治区给予补贴基础上，以区（县）财政负担为主，利用财政预算资金、福利彩票公益金和社会捐助资金等途径筹集。

2.集中供（收）养对象基本生活保障经费。“五保”老人集中供养基本生活保障经费，按照《乌鲁木齐市农村五保供养办法》（乌政办〔2014〕182号）规定，由各区（县）结合实际，按照不低于本区（县）农牧民上年度平均生活水平确定本区（县）农村五保供养标准，报市民政局备案后公布执行，要求于2017年7月1日前完成达标任务。孤儿集中收养基本生活保障经费，贯彻执行《乌鲁木齐市加强孤儿保障工作实施意见》（乌政办〔2012〕439号），按照每人每月不低于1000元标准执行（除中央补助资金外，其余由市级财政保障）。

3.集中供（收）养机构聘用人员经费。“五保”老人集中供养机构聘用人员所需经费，由自治区、区（县）财政共同负担；市级孤儿集中收养机构聘用人员所需经费，由市级财政负担。机构护理人员工资标准按照不低于当地最低工资标准的2倍确定，工勤人员工资标准按照不低于当地最低工资标准确定。

4.集中供（收）养机构运转经费。“五保”老人集中供养机构和孤儿集中收养机构所需办公、水、电、暖、气、通讯及设施设备维护、维修等运转经费，由区（县）财政足额保障。

五、保障措施

（一）加强组织领导。“五保”老人供养和孤儿收养，是各级人民政府的重要职责。各区（县）、各有关部门要高度重视“五保”老人集中供养和孤儿集中收养工作，切实把思想认识统一到自治区党委、政府的重大决策部署上来，将供（收）养机构改造建设纳入重要议事日程和重点工作计划。各级人民政府要成立由主要领导任组长，相关部门负责人为成员的工作领导小组，强化组织领导，落实区（县）、乡（镇）人民政府主体责任，加强机构设置、人员配备、管理服务和资金保障，统筹推进本行政区域内“五保”老人集中供养和孤儿集中收养工作，确保工作任务完成。

（二）推进精准实施。各区（县）、各有关部门要进一步加强对“五保”老人集中供养和孤儿集中收养工作制度的宣传、引导，制定完善相关政策，引导“五保”老人和孤儿到机构集中供（收）养。要根据《国务院办公厅关于加强孤儿保障工作的意见》（国办发〔2010〕54号）和《民政部关于印发特困人员认定办法的通知》（民发〔2016〕178号）精神，严格认定条件和程序，建档立卡、精准造册，确保“五保”老人集中供养和孤儿集中收养工作实现对象认定精准、资金补助精准。“五保”老人集中供养和孤儿集中收养工作要采取层层签订目标责任书，分步推进。各区（县）要以目标定进度，进一步细化实施方案，细化任务分解。

（三）明确部门职责。建立健全“党委领导、政府负责、民政牵头、部门协调、社会参与”的工作机制，推进工作和责任落实。民政部门要发挥牵头作用，负责督促各区（县）推进“五保”老人集中供养和孤儿集中收养工作；财政部门要落实供（收）养机构建设经费、供养经费、聘用人员工资和运转经费；发展改革部门要将集中供（收）养工作纳入国民经济和社会发展规划，争取中央预算内资金，支持供（收）养机构项目建设；机构编制部门要积极协调落实供（收）养机构人员编制；人社部门要做好供（收）养机构服务人员招聘调配工作，并积极开展护理人才职业技能培训；卫生计生部门要优先审核审批供（收）养机构开办医疗机构，并加大对集中供（收）养机构的服务能力建设和技术指导力度；教育部门要加强对社区行政服务与管理、老年服务和学前教育类的人才培养，积极妥善安置集中收养适龄孤儿接受学校教育。

（四）强化监督检查。各区（县）、各有关部门要将“五保”老人集中供养和孤儿集中收养工作落实情况作为民生工程重要内容，建立健全“五保”老人集中供养和孤儿集中收养工作的检查验收机制，定期组织开展专项督查、抽查。加大“五保”老人集中供养和孤儿集中收养工作推进力度，加强资金管理使用监督检查，严肃查处挤占挪用、虚报冒领等违纪违法行为。完善责任追究制度，加大行政问责力度，对因责任不落实造成严重后果的单位和个人追究相关责任。市人民政府将适时组织相关部门，对各区（县）“五保”老人集中供养和孤儿集中收养工作推进情况进行专项督导检查，对完成任务较好的区（县）予以表彰，对没有按期完成任务的区（县）予以通报批评。

（五）鼓励社会参与。强化宣传引导，积极鼓励各类社会组织、社会工作服务机构、企事业单位支持和参与“五保”老人集中供养和孤儿集中收养机构的建设和服务管理工作。积极引导志愿者、社会各界人士关心关爱“五保”老人、孤残儿童，共同营造敬老爱幼的良好社会氛围。
