# 乌鲁木齐市人民政府关于取消部分行政许可事项的决定

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区（头屯河区）、高新技术产业开发区（新市区）、甘泉堡经济技术开发区管委会，市属各委、局、办：

根据自治区人民政府《关于取消中央指定地方实施行政审批事项的决定》（新政发〔2016〕111号）和《关于自治区第三批取消中央指定地方实施行政许可事项的决定》（新政发〔2017〕98号）精神，经市十六届人民政府第3次常务会议研究同意，市人民政府决定取消4项行政许可事项：

1.设立旧机动车鉴定评估机构审批〔市商务局（粮食局）〕。

2.拍摄市级文物保护单位审批（市文化局）。

3.权限内公章刻制审批（县级公安机关）。

4.三级物业服务企业资质的审批〔区（县）住房保障和房产主管部门〕。

为切实做好取消事项的后续衔接工作，提出以下工作要求：

（一）各区（县）、各相关部门要认真做好取消行政审批事项的落实工作，对公布取消的事项要坚决停止审批，不得以事前备案、核准性备案等名义实行变相审批。同时，要做好相关清单的动态调整工作，在收到本决定5个工作日内完成本部门、本区（县）行政许可事项清单及行政权力清单和责任清单的修订和公布工作，并报本级审改办备案。

（二）切实加强事中事后监管，防止出现管理真空。各级各相关部门要进一步细化措施和工作方法，市商务局（粮食局）和市文化局要通过畅通投诉渠道，加强实地检查，提高监管效能等方式，对相关经营活动和行为进行监管；县级公安机关要建立统一的公章治安管理信息系统，逐步实现公章刻制网上备案、信息采集及公众查询；市住房保障和房产管理局要建立物业服务企业黑名单制度、信息公开制度，指导区（县）做好相关工作，推动行业自律。上述部门要在收到本决定30个工作日内，将建立、完善的监管措施、办法，以正式文件形式报市审改办（市委编办）审核、备案。各区（县）要积极做好相关落实工作。

（三）各区（县）、各相关部门要进一步明确和优化行政许可事项工作流程，大力压缩办事环节和工作时限，切实提高行政审批制度改革的系统性、协同性、针对性和有效性，不断提高政府管理科学化、规范化和法治化水平。

2017年10月2日
