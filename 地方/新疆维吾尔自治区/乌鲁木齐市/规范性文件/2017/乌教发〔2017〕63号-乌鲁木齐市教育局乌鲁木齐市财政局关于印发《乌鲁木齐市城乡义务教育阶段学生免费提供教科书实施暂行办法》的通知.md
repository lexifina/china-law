# 乌鲁木齐市教育局乌鲁木齐市财政局关于印发《乌鲁木齐市城乡义务教育阶段学生免费提供教科书实施暂行办法》的通知

各区县财政局、教育局，市属各学校：

根据《关于印发新疆维吾尔自治区进一步完善城乡义务教育经费保障机制实施方案的通知》（新政发【2016】102号）精神，市教育局、市财政局共同制定了《乌鲁木齐市城乡义务教育阶段学生免费提供教科书实施暂行办法》，请遵照执行。

2017年7月31日

乌鲁木齐市城乡义务教育阶段学生免费提供教科书实施暂行办法

第一条　根据《国务院关于进一步完善城乡义务教育经费保障机制的通知》（国发〔2015〕67号）及《关于印发新疆维吾尔自治区进一步完善城乡义务教育经费保障机制实施方案的通知》（新政发〔2016〕102号），从2017年春季学期开始，为乌鲁木齐市城乡义务教育阶段学生免费提供教科书。

第二条　按照自治区免费供应义务教育学校教科书科目表，向义务教育阶段学生（含全市公办、民办学校）免费提供教科书。

第三条　免费教科书资金，国家规定课程由中央全额承担（含出版发行少数民族文字教材亏损补贴）；地方课程由自治区本级和乌鲁木齐市按9∶1比例共同承担，并根据中央及自治区文件适时调整。乌鲁木齐市所需地方课程资金按照学校隶属关系由各级财政承担。

第四条　各相关学校要按照自治区教育厅《免费教科书循环使用制度》的要求，做好中小学免费教科书的循环使用工作。

第五条　各区（县）教育局、各学校要认真贯彻执行教育惠民相关政策，向广大家长、学生宣传、解释相关规定。义务教育阶段学生教科书按照国家课程设置严格采购制度，地方教材选定按自治区教育厅相关政策执行。

第六条 各学校不得选用其他课本或自编教材作为校本教材向学生单独收费。禁止任何单位和部门在发放免费教科书时搭售教辅用书及其他资料。

第七条 各区（县）教育、财政部门要建立有效的监督检查机制，防止发生违法违纪问题。

第八条　本办法由市教育局、市财政局负责解释。
