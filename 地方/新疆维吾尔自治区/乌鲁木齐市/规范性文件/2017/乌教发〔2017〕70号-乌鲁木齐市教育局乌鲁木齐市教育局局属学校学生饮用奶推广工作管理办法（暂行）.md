# 乌鲁木齐市教育局乌鲁木齐市教育局局属学校学生饮用奶推广工作管理办法（暂行）

局属各学校：

为了加强市教育局局属学校学生饮用奶推广工作的管理，规范学生饮用奶券的领取、发放和使用，依据《新疆维吾尔自治区“学生饮用奶计划”暂行管理办法》（新政办发〔2009〕78号）和《关于印发乌鲁木齐市2016-2017学年推广学生饮用奶计划工作实施方案的通知》（乌政办〔2016〕110号）制定本办法。

一、学生饮用奶券的领取

1、学校向市教育局领取学生饮用奶券时，必须如实上报《乌鲁木齐市本级学生饮用奶推广申报表》。

2、《乌鲁木齐市本级学生饮用奶推广申报表》中的“在校生人数”一栏必须按照本校申报学生饮用奶券当月的在校实际就读学生人数填列。

3、每学期期初，学校领取学生饮用奶券时应向市教育局上报本校学生花名册、在校班级人数统计表及《乌鲁木齐市本级学生饮用奶推广申报表》。学期中间的月份，在领取学生饮用奶券时，只上报《乌鲁木齐市本级学生饮用奶推广申报表》，如有人数变动，还要上报学生人数变动情况说明及学生的转学证明。

4、每年8月，学校向市教育局预报本学期在校学生人数时，在校班级按照实际人数上报，新学年招收的新生按照预估人数上报。

二、学生饮用奶券的发放

1、学校向本校学生发放的学生饮用奶券，必须加盖本校公章，并据实填写学生的姓名和学号。

2、学校向本校学生发放学生饮用奶券时，应由本校发放学生饮用奶券的部门组织班主任按班级领取，并在发放表上签字。班主任再组织本班学生在学生饮用奶券背面认真填写姓名和学号，并在发放表上签字。班主任和学生签字后的发放表必须存档，保管期限不少于5年。

3、内初班的学生饮用奶券采用由学校统一与学生饮用奶中标企业联系，企业将学生饮用奶直接送进校园，学校德育处每天给学生发放一袋牛奶，坚决杜绝学校采取用学生饮用奶烧奶茶等其他形式发放学生饮用奶。

4、对于学生丢失的学生饮用奶券一律不予补发。

三、学生饮用奶券的使用

1、学生饮用奶券只能按照“一人一券”据实发给学校实际在读学生。

2、不得将本月由于各种原因多领的学生饮用奶券作为福利或者奖励发给本校教师和学生。

3、对于本月多领的学生饮用奶券应如实写明多领的原因并退还市教育局，由市教育局统一登记造册进行销毁。

此办法从即日起执行，由市教育局负责解释。

2017年8月12日
