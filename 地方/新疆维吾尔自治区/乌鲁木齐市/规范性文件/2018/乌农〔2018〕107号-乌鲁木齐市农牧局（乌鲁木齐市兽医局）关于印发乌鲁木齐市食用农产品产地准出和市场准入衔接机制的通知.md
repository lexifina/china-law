# 乌鲁木齐市农牧局（乌鲁木齐市兽医局）关于印发乌鲁木齐市食用农产品产地准出和市场准入衔接机制的通知

各区（县）农牧局、市场监督管理局：

为加强我市食用农产品质量安全监管，实现食用农产品产地准出和市场准入的无缝衔接，确保农产品消费安全，维护公众健康，根据《中华人民共和国食品安全法》、《中华人民共和国农产品质量安全法》等相关规定，结合我市实际，市农牧局和市食药局联合制定了《乌鲁木齐市食用农产品产地准出与市场准入衔接机制》，现予以印发，请遵照执行。

附件：乌鲁木齐市食用农产品产地准出和市场准入衔接机制

2018年6月19日
