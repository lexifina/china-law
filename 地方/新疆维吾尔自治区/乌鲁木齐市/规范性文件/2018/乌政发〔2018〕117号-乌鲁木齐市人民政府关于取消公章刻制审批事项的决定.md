# 乌鲁木齐市人民政府关于取消公章刻制审批事项的决定

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区（头屯河区）、高新技术产业开发区（新市区）、甘泉堡经济技术开发区管委会，市属各委、局、办：

根据《国务院关于第三批取消中央指定地方实施行政许可事项的决定》（国发〔2017〕7号）精神，按照《关于取消部分行政许可事项的决定》（乌政发〔2017〕130号）要求，经市人民政府研究决定：

一、取消公章刻制审批

取消由市公安局实施的“权限内公章刻制审批”事项。将各区公安分局实施的“权限内公章刻制审批”改为“权限内公章刻制备案”。

二、工作要求

市公安局要抓紧做好取消和变更事项的后续衔接工作，建立、完善相关配套措施并组织实施。

（一）对取消的“权限内公章刻制审批”事项要坚决停止审批，不得以事前备案、核准性备案等名义实行变相审批，并在收到本决定5个工作日内完成本部门的行政许可事项清单和权责清单的调整、公布、备案等工作，切实做到“清单之外无权力”。

（二）制定出台公章刻制备案工作规范，明确备案流程、所需材料，以及事中事后监管措施、办法，并在收到本决定30个工作日内，以正式文件形式报市审改办备案。同时，通过加强培训指导、监督检查和定期考核等，确保公章刻制备案管理工作在各区公安分局和县公安局有序开展。

（三）建立和完善公章管理信息系统，逐步实现公章刻制网上备案、信息采集及公众查询。

2018年10月9日
