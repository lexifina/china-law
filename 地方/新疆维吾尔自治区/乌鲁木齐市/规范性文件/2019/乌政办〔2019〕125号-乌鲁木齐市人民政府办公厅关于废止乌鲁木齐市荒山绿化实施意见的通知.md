# 乌鲁木齐市人民政府办公厅关于废止乌鲁木齐市荒山绿化实施意见的通知

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区(头屯河区)、高新技术产业开发区(新市区)、甘泉堡经济技术开发区管委会，市属各委、局、办:

2011年4月25日以市政府办公厅名义印发的《关于印发乌鲁木齐市荒山绿化实施意见的通知》(乌政办〔2011〕130号)的主要内容与现行法律法规及上级政策规定不一致。为维护法制统一、确保政令通畅维护公民、法人和其他组织的合法权益,营造我市经济社会发展的良好法制环境，现决定将《关于印发乌鲁木齐市荒山绿化实施意见的通知》(乌政办〔2011〕130号)予以废止，不再继续执行，不得作为行政管理的依据。实施荒山绿化企业和个人的权利和义务，以新出台的相关政策规定为准。

2019年10月24日
