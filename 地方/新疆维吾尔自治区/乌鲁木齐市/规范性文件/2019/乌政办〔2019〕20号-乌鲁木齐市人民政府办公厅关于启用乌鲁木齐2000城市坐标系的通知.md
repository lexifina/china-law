# 乌鲁木齐市人民政府办公厅关于启用乌鲁木齐2000城市坐标系的通知

乌鲁木齐县、各区人民政府，乌鲁木齐经济技术开发区（头屯河区）、高新技术产业开发区（新市区）、甘泉堡经济技术开发区管委会，市属各委、局、办：

根据《中华人民共和国测绘法》，经原国家测绘地理信息局批准，我市自 2019年2月1日起，启用乌鲁木齐 2000城市坐标系， 现将有关事项通知如下：

一、乌鲁木齐2000城市坐标系是我市唯一合法的相对独立的平面坐标系统。

二、乌鲁木齐2000城市坐标系与现行乌鲁木齐市独立坐标系转换、衔接的过渡期为 2019年2月1日至2021年12月31日。届时，将停止使用1954北京坐标系、1980 西安坐标系和现行乌鲁木齐市独立坐标系。

三、市自然资源局和市城乡规划管理局共同负责启用乌鲁木齐2000城市坐标系工作的组织实施，为各区（县）、各部门现有测绘地理信息成果坐标转换提供技术支持和服务；负责完成市级基础测绘成果向乌鲁木齐2000 坐标系转换，并向社会提供使用。市属相关部门负责本部门启用乌鲁木齐2000城市坐标系工作的组织实施和本部门测绘地理信息成果的转换。

四、各区（县）负责本辖区启用乌鲁木齐2000城市坐标系工作的组织实施，完成本级测绘地理信息成果向乌鲁木齐2000城市坐标系的转换，并向社会提供使用。

2019年2月3日
