# 乌鲁木齐市人民政府关于划定新建高速铁路乌鲁木齐新客站及相关工程铁路线路安全保护区的通告

为加强新建高速铁路乌鲁木齐新客站及相关工程铁路线路普速铁路运输安全，保障铁路运输通畅，保护人民群众生命财产安全，根据《铁路安全管理条例》（国务院令第639号）第二十七条规定，现将乌鲁木齐市辖区内新建高速铁路新客站及相关工程铁路线路安全保护区划定有关事项通告如下：

一、新建高速铁路乌鲁木齐新客站及相关工程铁路线路包含：雅山至平安巷段；沙依巴克区四号涵洞至乌鲁木齐站段；乌鲁木齐站至乌奎高速段；乌昌大道至乌奎高速段。

二、铁路线路安全保护区的范围，从铁路线路路堤坡脚、路堑坡顶或者铁路桥梁（含铁路、道路两用桥）外侧起向外的距离为10米。

三、新建高速铁路乌鲁木齐新客站及相关工程铁路线路安全保护区与公路、城市道路、建筑控制区和石油、电力及其它重要设施保护区重叠的，各自保护区并存，但在保护区重叠区域内，各方的相关行为应符合国家法律法规、行业标准的相关安全管理规定。

四、在铁路安全保护区划定后，铁路部门应当结合用地实际进行勘界、设立标桩等工作，铁路沿线的有关企事业单位、组织和群众应当给予支持和配合。

五、铁路沿线从事生产、生活或者其他活动应当遵守《铁路安全管理条例》（国务院令第639号）的相关规定。

特此通告。

2019年12月25日
