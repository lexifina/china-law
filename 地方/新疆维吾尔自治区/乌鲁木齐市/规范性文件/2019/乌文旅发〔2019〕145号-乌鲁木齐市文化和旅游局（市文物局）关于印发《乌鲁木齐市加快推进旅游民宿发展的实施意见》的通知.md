# 乌鲁木齐市文化和旅游局（市文物局）关于印发《乌鲁木齐市加快推进旅游民宿发展的实施意见》的通知

各区县文化体育旅游局、发改委、公安局、财政局、自然资源局、规划局、生态环境局、建设局、农业农村局、市场监督管理局：

经市人民政府同意，现将《乌鲁木齐市加快推进旅游民宿发展的实施意见》印发给你们，请结合实际，遵照执行。

2019年10月24日

乌鲁木齐市加快推进旅游民宿发展的实施意见

民宿是指利用当地民居等闲置资源，经营用房不超过4层，经营用客房数量不超过14个标准间（或单间），建筑面积不超过800㎡，民宿主人参与接待，为游客提供体验当地自然、文化与生产生活方式的小型住宿设施，包括但不限于客栈、庄园、宅院、驿站、山庄等。为充分利用我市旅游资源多样化优势，抢抓民宿经济发展机遇，推进全域旅游发展和旅游业转型升级，大力促进旅游消费，助力我市由全疆旅游集散地向国际旅游集散地和旅游目的地转变，现提出以下意见：

一、总体要求

（一）指导思想。以习近平新时代中国特色社会主义思想为指导，深入贯彻新时代党的治疆方略，按照自治区党委“1+3+3+改革开放”的决策部署和市委确定的聚焦总目标、抓好“三件大事”、建设“六个首府”工作要求，围绕全面实施旅游兴疆战略、推进乡村振兴战略，牢固树立新发展理念，践行“绿水青山就是金山银山”的科学思想，把民宿业发展与乡村振兴、城市治理等工作结合起来，依托我市独有的自然资源和人文禀赋优势，强化政策激励，逐步形成布局合理、规模适度、特色鲜明的民宿业发展格局，为推进全市旅游业高质量发展提供强有力的新动能支撑。

（二）发展原则。

1、坚持规划引领，有序发展。民宿发展规划要与其它上位规划和专项规划相衔接，按照“保护生态、因地制宜、彰显特色、合理布局、有序发展”的要求，坚持生态保护优先，在自然环境优美、文化底蕴深厚、基础设施相对完善的城乡重点区域布局发展民宿，分步实施、有序推进。

2、坚持政府引导，市场参与。按照政府引导、市场运作、多元参与、形式多样的要求，强化政府在政策扶持、规范管理、公共服务、环境营造等方面的作用，发挥市场配置资源的决定性作用，引导社会资本、专业团队、创客队伍等参与民宿建设，鼓励市属国有企业进入民宿发展领域，鼓励村集体和农户自主创业，形成利益共享、多元建设的良好格局。

3、坚持彰显特色，品质服务。突出民宿建设经营的创新创意，突出乌鲁木齐地域特色和民族文化特色，注重个性化、特色化的设计构思，不断提升品质内涵，打造展示乌鲁木齐历史文化、红色文化、民俗文化、地域文化、都市休闲文化的靓丽名片。坚持把安全舒适放在首位，制定民宿基本标准，明确民宿规划、选址、建设、运营的相关要求，完善政策措施，引导民宿经营主体严格依法经营，推动民宿产业有序健康发展，通过提升服务品质，增强吸引力和美誉度。

（三）基本目标。从2019年起，力争到2022年实现全市民宿产业规范化、规模化发展，集中打造3个民宿集聚区、不少于800家民宿，其中五星级民宿30家，四星级民宿100家，基本形成乌鲁木齐民宿品牌。

二、主要任务

（一）统一规划布局。高起点编制民宿发展规划，明确空间布局、建设重点和主要任务，做好民宿发展的宏观引导和环境影响评价。各区（县）应结合各自实际，明确民宿发展重点区域，制定本区域民宿发展年度计划和行动方案。

（二）优化资源配置。民宿选址要与国土空间规划以及环境、旅游、乡村等专项规划相衔接，符合水源保护、生态环保、山体保护、文物保护、建筑安全、消防安全、防灾避灾等基本条件。鼓励盘活闲置资源，积极探索回购、租赁、置换、退出等模式，将村集体闲置用房、老庭院、旧厂房、旧校舍、农户闲置房等用于民宿发展。建设完善水、电、路等民宿基础设施、公共服务配套体系，在有条件的民宿集聚区实现“两通（通客车、通网络）”“两建（建停车场、建标牌标识）”。

（三）加强规范管理。制定我市民宿管理办法，明确全市民宿产业发展定位、行业标准、服务规范、管理职责等。按照市级指导、区（县）联审、乡镇（街道）村（居）委会申报的思路，完善民宿业发展监管机制。简化民宿申办手续，由民宿业主提出申请，村（居）委会乡镇（街道）签署意见，区（县）联审办公室统一组织相关职能部门进行核验联审。鼓励区（县）结合实际，运用网络优势，优化流程，开辟绿色通道。推进“放管服”改革，便捷登记报备，对经营民宿的农户或经营主体放宽名称登记，允许从事民宿经营活动的市场主体，使用“民宿”作为企业（个体工商户）名称以及经营范围的具体经营项目进行申请，并实行住所（经营场所）申报制度，对符合登记条件的，即可予以登记。适当放宽民宿市场准入，优化特行许可办理，对符合消防安全技术要求的民宿经营主体须接入公安部门统一核准的旅馆业信息管理系统。推进消防安全管理创新，对利用村民自建房屋改造的民宿，符合本意见定义民宿标准，建筑防火要求按照《住房城乡部公安部国家旅游局关于印发农家乐（民宿）建筑防火导则（试行）的通知》（建村﹝2017﹞50号）执行。公安、生态环境、卫生健康、市场监管等部门负责创新管理举措，加强分类指导。加强事中事后监管，相关职能部门、各区（县）及乡镇（街道）要落实好日常监督管理及属地监管责任，开展执法检查、协同监管，规范民宿经营，建立并完善记录、抽查和惩戒的事中事后监管制度和平台，对违反法律法规、告知承诺管理办法的要及时查处。成立市旅游民宿协会，加强行业管理及行业自律，积极引导民宿经营者资源共享、行业自律、诚信经营、有序发展。

（四）强化政策扶持。加强用地保障和支持，优先利用农村存量民居资源发展民宿产业，支持鼓励农村集体经济组织，社会资本以多种方式参与民宿产业的建设。农村土地综合整治、集体建设用地减量化等盘活的建设用地，优先用于农业和乡村旅游（民宿）产业配套设施建设。对民宿新建的配套服务接待设施，符合相关规划，可实行“点状”供地。加大财税支持力度，市财政每年从旅游发展专项中安排资金用于对星级民宿进行奖补及宣传促销，按照城镇民宿、乡村民宿不同类型，对民宿发展工作排名靠前的区（县）进行表彰。各区（县）要制定具体的实施意见和相应的扶持政策，运用税收优惠、财政补助、贷款贴息、奖补结合等方式，充分调动各族各界群众、社会资本参与旅游民宿发展的积极性。鼓励民宿企业积极参与会议、公务接待、职工疗休养等政府采购项目。强化金融服务，鼓励金融机构创新金融产品和服务方式，拓宽民宿企业融资渠道，加大对民宿产业的信贷支持。按照国家统一部署，依法开展农村土地经营权抵押贷款试点，引导金融资源配置到乡村民宿产业发展。支持推出符合民宿经营特点的保险产品。

（五）打造品牌体系。坚持整体推进与重点突破相结合，在全市选取不同区域、不同类别、不同特色的精品民宿试点，扶持打造民宿建设样板。实施民宿发展品牌培育工程，以保留乡土景观、延续乡村生活、民俗文化体验、以市民周末、周边休闲及盘活闲置资源为目的，优化旅游民宿产品供给结构，引导经营业主创新发展，突出单体民宿的个性化、主题化，积极培育形成一批具有鲜明本地特色的乌鲁木齐民宿品牌。对全市民宿品牌实行统一标识、统一宣传、统一推介，切实提升我市民宿品牌的知名度和影响力。

（六）创新运营模式。探索多渠道投入机制，引导资源主体、资本主体、经营主体、从业主体等共同推进民宿业发展。鼓励城市和乡村有意愿的组织、个人改造现有住房或租赁民房开办民宿，支持社会各界人士返乡创业开办民宿，鼓励“合作社+农户”“公司+农户”等民宿合作发展模式。鼓励通过注册乡村旅游投资开发公司、组建民宿（农家乐）合作社、村民入股等方式整村连片发展旅游民宿。积极引进民宿品牌企业、知名平台公司、专业化团队重点参与打造民宿示范项目，吸引文化、科技、设计等专业特长人才及大学毕业生等参与民宿项目投资开发。充分利用互联网经济时代的技术优势，提高民宿经营管理效率，拓展“互联网+”营销渠道，通过手机APP以及知名电商平台承接客源。创新“民宿管家”托管服务，发挥专业团队和技术人才优势，强化规划设计、管理创新，着力培育一批民宿连锁企业。

（七）推进产业融合。积极开发民宿体验新产品，引导商务休闲、户外运动、生态观光、乡村生活、养生度假、怀旧体验等旅居要素与民宿发展有效融合，构建个性化的城市旅居模式、高端化的度假旅居模式、创意化的休闲聚落模式、产业化的主题庄园模式等，提升民宿价值，形成我市独特的民宿魅力和品牌。创新商业模式，推进“民宿+生态、旅游、电商”等模式，带动民宿附加产品开发、创新、销售，加强上下游产业链发展，满足多元消费需求，带动关联产业发展，拓展市场消费渠道。

（八）建设人才队伍。加强民宿从业人员专业培训，鼓励支持民居所有人和当地居民参与培训，通过开展民宿发展论坛、课程讲座、外出考察调研等方式，分层次地对民宿相关经营管理人员、服务人员、民居所有人以及当地有意开办民宿的居民开展系统培训，不断提高对民宿新业态的认知和专业化管理服务水平。加大民宿发展高层次人才引进培养力度，对外地来乌投资、从事民宿管理经营且具有高学历的管理人才，享受市级相关人才政策。在市属院校设立旅游民宿管理研究课程，建立旅游民宿人才库。每年选取一批优秀大学生民宿创业点，重点扶持一批“民宿经济带头人”。

三、保障措施

（一）加强组织领导。乌鲁木齐市旅游产业发展工作领导小组定期研究解决民宿业发展中遇到的重大问题，统筹协调推进全市民宿业健康发展。各成员单位要按照各自职责加强对民宿的指导和监管，协同配合，形成合力。要加强民宿经济运行监测分析，及时准确把握全市民宿产业运行态势，增强民宿经济运行分析的时效性、前瞻性、针对性和指导性。

（二）强化主体责任。各区（县）要结合本地实际，建立推进工作机制，明确工作机构和人员，加强组织协调，统筹谋划产业发展布局，制定民宿管理配套实施细则，强化保障措施，落实工作任务，切实承担民宿发展主体责任。

（三）广泛宣传引导。充分利用网络、电视、报纸、新媒体等多种形式和渠道，大力宣传民宿业发展的新理念、新思路、新经验，将民宿宣传推介纳入全市旅游市场营销体系中，加强民宿品牌营销推介。开展民宿业发展领域的政策法规辅导、改革创新总结评估、典型典范提炼推广等工作，进一步营造有利于民宿业发展的良好社会环境。
