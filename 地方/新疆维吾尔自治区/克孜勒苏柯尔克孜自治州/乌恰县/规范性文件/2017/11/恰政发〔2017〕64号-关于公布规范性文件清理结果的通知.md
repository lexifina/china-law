# 关于公布规范性文件清理结果的通知

各乡（镇）人民政府,玛依喀克管委会,县直各部门、各直属机构：

为维护法制统一和政令畅通，深入推进“放管服”改革，确保各项改革措施有效落实，根据《中共中央国务院〈法治政府建设实施纲要（2015－2020年）〉》（中发〔2015〕36号）、自治区人民政府办公厅《关于开展政府文件全面清理工作的通知》（新政办发〔2016〕50号）和克州人民政府办公室《关于开展政府文件全面清理工作的通知》（克政办发〔2017〕26号）文件要求，乌恰县人民政府法制办对1980年至2016年期间由乌恰县人民政府、政府办公室发布的规范性文件进行了全面清理。现将清理结果公布如下：

一、县人民政府决定，确认《关于印发〈乌恰县农村五保供养工作实施细则〉的通知》（恰政发〔2005〕39号）等23件规范性文件继续有效（见附件1）

二、县人民政府决定，宣布《关于职工生活和部分公共用煤补贴办法的通知》（恰政字〔1984〕85号）等48件规范性文件废止（见附件2）。

上述确认继续有效的规范性文件，有效期与本通知下发前连续计算，上述宣布废止的规范性文件，自本通知下发之日起不再执行。

附件：1、继续有效的规范性文件目录

2、废止失效的规范性文件目录
