# 关于印发《2018年质量技术监督工作要点》的通知

局机关各科室、稽查队、各直属事业单位：

依据自治区人民政府年度工作部署、国家质检总局工作任务安排和自治区质监局工作要求，结合我局工作实际，制定《2018年度质量技术监督工作要点》。现印发给你们，请认真贯彻执行。

克州质量技术监督局

2018年4月8日

克州质监局2018年工作要点

2018年是贯彻落实党的十九大精神的开局之年。克州质监局各项工作的总体要求是：以习近平新时代中国特色社会主义思想为统领，按照自治州党委、政府和自治区质监局工作总体部署，坚持聚焦总目标、服务总目标、落实总目标，围绕“抓质量、保安全、促发展、强质监”的工作思路，贯彻落实自治区质量强区战略，大力实施质量强州战略，深入开展质量提升行动，全面提高质监服务企业、服务民生的水平和能力，努力开创自治州质量管理工作新局面。

一、质量管理工作

（一）实施质量强州战略

1、深化质量强市（县）建设，积极开展“全疆质量强市示范城市”创建工作。（责任领导：托连·哈那提白克责任科室：质量监督科责任人：於长风完成时限：2018年10月底前）

2、强化质量工作督查考核。推动构建“党委领导、政府主导、部门联合、企业主责、社会参与”的质量工作格局。完善政府质量考核机制，优化考核指标体系，加强考核结果运用，充分发挥考核的激励和导向作用，促进各县（市）人民政府开展质量提升行动、落实质量强州战略。做好自治区对自治州政府质量考核的沟通对接工作。（责任领导：托连·哈那提白克责任科室：质量监督科责任人：於长风完成时限：2018年10月底前）

（二）开展质量提升行动

1、贯彻《中共中央国务院关于开展质量提升行动的指导意见》。协调各县（市）、各部门做好质量提升工作，组织开展好质量提升行动。（责任领导：托连·哈那提白克责任科室：质量监督科责任人：於长风完成时限：2018年10月底前）

2、持续推进“百千万质量强企”工程。督促各县（市）、将实施“百千万质量强企”工程作为落实质量强州、质量强县战略、开展质量提升行动的重要抓手，继续开展质量知识普及教育，拓展线上、线下培训模式，争取培养更多小微企业“质量明白人”。（责任领导：托连·哈那提白克责任科室：质量监督科责任人：於长风完成时限：2018年10月底前）

3、开展“服务零距离、质量零缺陷”质量技术服务活动。聚焦中小企业质量提升瓶颈问题，开展“服务零距离、质量零缺陷”质量技术服务活动，建立完善质量技术服务协同机制，综合运用政策制度、质量管理、计量、标准、认证认可、检验检测等质量工具，为企业提供全链条协同服务。（责任领导：托连·哈那提白克责任科室：质量监督科责任人：於长风完成时限：2018年10月底前）

（三）推进实施名牌战略

做好名牌产品申报和宣传工作。组织开展2018年新疆名牌产品申报工作。加强名牌产品宣传推广，积极组织企业参加自治区品牌故事大赛，营造讲质量树品牌的社会氛围。（责任领导：托连·哈那提白克责任科室：质量监督科责任人：於长风完成时限：2018年10月底前）

（四）强化质量基础建设

1、做好质量统计分析工作。提高年度产品质量分析报告和相关专题分析报告的编撰，为政府和相关部门宏观决策提供参考。做好质监系统年度综合统计工作。（责任领导：托连·哈那提白克责任科室：质量监督科责任人：於长风完成时限：2018年10月底前）

2、加强质量诚信体系建设。进一步完善企业质量信用档案数据库和产品质量信用记录平台。组织开展企业质量信用报告发布活动。落实《自治区质量失信企业名单管理办法》，发挥部门间诚信信息的联动机制作用，加大对质量违法行为的惩戒力度。（责任领导：托连·哈那提白克责任科室：质量监督科责任人：於长风完成时限：2018年10月底前）

二、产品质量监督工作

（一）大力加强产品质量监管

1、加大重点产品质量监督抽查力度。结合自治州实际，重点围绕涉及人体健康、人身财产安全的产品、影响国计民生和公共安全的重要工业产品，配合自治区做好产品质量监督抽查工作，积极争取财政支持，增加抽查经费，切实落实产品质量监督抽查制度，针对重点产品开展质量监督抽查工作，加大监督抽查不合格产品后处理力度，充分发挥监督抽查在发现质量问题、维护质量安全中的重要作用。（责任领导：托连·哈那提白克责任科室：质量监督科、稽查队责任人：於长风、刘厚下完成时限：2018年10月底前）

2、强化重点产品质量安全监管工作。加强重点工业产品质量安全监管，重点开展危险化学品及包装物、烟花爆竹、电线电缆等生产企业专项监督检查。组织企业开展自查自纠、各县（市）市场监督管理部门开展排查整治，自治州进行督查督导，确保排查到位、整治到位。加强重点消费品质量安全监管，重点抽查日用消费品，针对性开展质量提升活动，维护消费品质量安全。加强重点农资产品质量监管，突出抽查农用薄膜和化肥，针对问题企业加大质量整治和依法查处力度，督促企业提升产品质量水平。（责任领导：托连·哈那提白克责任科室：质量监督科、稽查队、特种设备安全监察科责任人：於长风、刘厚下、梁军完成时限：2018年10月底前）

3、加强工业产品许可证证后监管工作。对保留行政审批的产品，按照突出风险管理，加强事中事后监管的原则，采取年审、生产条件现场检查与产品质量监督抽查相结合的监管措施，加强日常监督检查工作，及时发现和查处问题，对不符合法定条件的，不能保证质量安全或出现重大质量安全事故的，按照规定坚决落实退出机制，依法撤销、吊销、注销行政许可，提高证后监管工作有效性。对取消生产许可管理的产品，持续组织开展监督抽查工作，强化事中事后监管力度。（责任领导：托连·哈那提白克责任科室：质量监督科责任人：於长风完成时限：2018年10月底前）

（二）积极推进产品质量提升。严格质量监督抽查后处理工作。针对监督抽查产品质量不合格的企业，加大依法依规处理力度，及时将质量状况和监督抽查结果向当地政府和相关部门予以通报；加大不合格产品的曝光力度，以市场机制倒逼质量提升；严格落实产品质量监督抽查及后处理管理要求，强化执法查处工作，严厉打击生产伪劣产品违法行为，加强对问题企业的整改复查工作，督促企业强化质量安全主体责任，切实落实整改措施，提升产品质量水平。（责任领导：托连·哈那提白克责任科室：质量监督科稽查队责任人：於长风刘厚下完成时限：2018年10月底前）

（三）健全质量监督机制。有序推进产品质量监督抽查制度改革。结合克州实际，规范完善产品质量监督抽查管理制度，有序推进检验机构抽检分离工作，提高监督抽查科学性和公正性。（责任领导：托连·哈那提白克责任科室：质量监督科责任人：於长风完成时限：2018年10月底前）

三、计量和标准化工作

（一）全面助力质量提升

1、全面开展“优化计量提质增效”活动。围绕振兴实体经济和提质增效的要求，聚焦企业在质量控制、分析测试、仪器仪表检定校准等方面存在的突出计量难点和痛点问题，有针对性地为小微企业实施计量精准施“测”服务。（责任领导：马黾责任科室：标准计量科责任人：刘玲完成时限：2018年10月底前）

2、开展民生计量器具检查工作。重点检查仓储物流业、医疗服务业的医用计量器具、贸易结算计量器具，确保计量公平、百姓放心、行业规范。（责任领导：马黾责任科室：标准计量科责任人：刘玲完成时限：2018年10月底前）

3、认证认可产品领域。对实验室、汽车配件、低压配电箱和儿童玩具的强制性认证产品进行检查，规范行业秩序、打击无证或超范围生产行为。（责任领导：马黾责任科室：标准计量科、稽查队责任人：刘玲、刘厚下完成时限：2018年10月底前）

4、开展日常压力表、燃气表、加油机、加气机、医疗设备、衡器、检测实验室等计量器具检定工作，烧结普通砖、砂石料、化肥、汽柴油等委托检验工作。（责任领导：马黾责任科室：质量与计量检测所责任人：张洁完成时限：2018年10月底前）

5、做好检验检测设备、计量标准器量值溯源工作，做好法定计量检定机构到期复验工作。（责任领导：马黾责任科室：质量与计量检测所责任人：张洁完成时限：2018年10月底前）

6、积极争取自治州财政部门专项资金支持，开展计量新建标项目试运行及考核申报工作。（责任领导：马黾责任科室：质量与计量检测所责任人：张洁完成时限：2018年10月底前）

7、加强社会公用计量标准体系建设。依法全面系统梳理社会公用计量标准，推进社会公用计量标准新建，有效利用社会资源，快速提升计量公共体系服务社会经济发展的能力。（责任领导：马黾责任科室：质量与计量检测所责任人：张洁完成时限：2018年10月底前）

（二）提升计量服务经济社会发展水平

1、助力提高环境监测数据质量。按照国家、自治区、自治州安排对重点排污单位在用计量器具进行摸底、检查。（责任领导：马黾责任科室：标准计量科、计量与质量检测所责任人：刘玲、张洁完成时限：2018年10月底前）

2、持续开展计量专项监督检查。部署开展环境监测类、安全防护类、农产品收购等计量器具专项监督检查等，打击净含量不准，黑心秤等计量违法行为，保护消费者的合法权益。（责任领导：马黾责任科室：标准计量科、稽查队责任人：刘玲、刘厚下完成时限：2018年10月底前）

（三）深化计量体制机制改革。落实中央和自治区、自治州“放管服”改革要求，进一步下放计量业务行政许可事项，继续优化计量行政许可事项程序。（责任领导：马黾责任科室：法制宣传科责任人：买买江·艾沙完成时限：2018年10月底前）

（四）做好标准化工作。

1、积极开展企业标准化工作,认真落实督促建立全州生产企业产品标准目录。积极开展地方标准审核、发布、备案工作。（责任领导：马黾责任科室：标准计量科责任人：刘玲完成时限：2018年10月底前）

2、成立克州标准化工作领导小组，制定本地标准化发展战略实施意见或规划。帮助已被申报成功的单位做好示范区后续管理工作。（责任领导：马黾责任科室：标准计量科责任人：刘玲完成时限：2018年10月底前）

四、质监执法打假“质监利剑”行动工作

（一）保持对重点产品和区域执法打假的高压态势

1、全力开展质量违法线索摸排。坚持全面摸排与及时处置相结合，紧紧围绕关系人体健康和人身、财产安全的产品和易发、高发质量违法行为的重点地区，广泛开展质量违法线索搜集，快速开展执法检查行动。（责任领导：马黾责任科室：稽查队责任人：刘厚下完成时限：2018年10月底前）

2、深入开展“质监利剑”行动。加大对关系国家计民生的消费者反映强烈的日用消费品和重要工业产品的执法打假工作力度，重点围绕儿童玩具、食品相关产品、农资、建材、汽车及配件、油品等重点产品开展“质检利剑”行动；开展涉及安全生产的消费产品、烟花爆竹、危化品、特种设备等专项整治行动。坚持以严厉查处制售假冒伪劣大案要案为重点，始终保持执法打假的高压态势。（责任领导：马黾责任科室：稽查队、特种设备安全监察科责任人：刘厚下、梁军完成时限：2018年10月底前）

3、推动淘汰落后产能化解工作。充分运用执法打假手段，重点加强对钢铁、水泥等高能耗、高污染行业的产品质量整治，坚决打击无证生产、产品质量不合格强制性标准要求等违法行为。严厉打击生产“地条钢”的违法行为，防止“地条钢”死灰复燃，守住高质量发展底线。（责任领导：马黾责任科室：稽查队责任人：刘厚下完成时限：2018年10月底前）

4、深入开展“双打”工作。全面落实全国及自治区“双打”办部署要求和工作任务，加大“双打”工作力度，建立健全长效机制，全面推进行政处罚案件信息公开工作。（责任领导：马黾责任科室：稽查队、法制宣传科责任人：刘厚下、买买江·艾沙完成时限：2018年10月底前）

5、加强消费品召回监管职责。开展汽车配件打假治劣专项行动，查处汽车产品不符合国家强制性标准和未经强制性认证等违法行为。督促企业主动履行召回义务，进一步动员消费者参与召回工作，及时主动报告产品缺陷信息，营造人人关注、人人参与缺陷产品召回工作的良好氛围。（责任领导：马黾责任科室：稽查队责任人：刘厚下完成时限：2018年10月底前）

（二）不断提升执法规范化

1、加大12365系统建设和应用力度。认真开展质监局长接线日活动，健全工作机制，提高服务质量。充分应用12365热线平台，推动执法办案全过程录入12365系统，对办案力度薄弱的地区和单位进行重点督办，利用12365信息化系统建设，加强执法工作日常和定期考核。（责任领导：马黾责任科室：稽查队责任人：刘厚下完成时限：2018年10月底前）

2、加大对执法人员的检查指导和考核力度。加强对基层执法办案的检查、指导和考核、严格落实执法责任制，对疑难案件和跨区域案件加强会商。对有令不行、有禁不止、执法不作为、失职渎职、违法执法行为的人员和单位，严肃处理。（责任领导：马黾责任科室：稽查队、法制宣传科责任人：刘厚下、买买江·艾沙完成时限：2018年10月底前）

3、加大执法协作力度。建立健全多部门、跨区域执法联动机制、建立上下协调、部门联动、区域协作、协查协办的工作机制.健全质量违法行为记录及公布制度，完善行政执法与刑事司法衔接工作机制，深入推进“两法衔接”工作。（责任领导：马黾责任科室：稽查队、法制宣传科责任人：刘厚下、买买江·艾沙完成时限：2018年10月底前）

五、特种设备安全工作

（一）强化特种设备监管

1、继续开展特种设备攻坚战，以遏制重特大事故和重大影响事件为目标，以涉及民生、人员密集场所、盛装危险化学品等高风险特种设备为重点，开展特种设备重大安全隐患排查和治理。全州特种设备死亡人数控制在0.55人/万台以下。督促特种设备检验检测所及三县一市，做好标本兼治遏制特种设备重特大事故的工作。（责任领导：马黾责任科室：特种设备安全监察科责任人：梁军完成时限：2018年10月底前）
