# 关于进一步健全和完善政府法律顾问制度的通知

各乡（镇）人民政府，玛依喀克管委会，县直各单位：

2015年以来，乌恰县人民政府认真贯彻中共中央 国务院《法治政府建设实施纲要（2015-2020年）》，建立了以政府法制机构人员为主体、吸收专家、律师参加的法律顾问队伍和框架体系，法律顾问在政府制定重大行政决策、推进依法行政中发挥了积极作用。

2016年6月16日，新华社受权公开发布了中共中央办公厅、国务院办公厅《关于推行法律顾问制度和公职律师公司律师制度的意见》（中办发〔2016〕30号），意见明确提出“2017年底前，中央和国家机关各部委，县级以上地方各级党政机关普遍设立法律顾问、公职律师，乡镇党委和政府根据需要设立法律顾问、公职律师，国有企业深入推进法律顾问、公司律师制度，事业单位探索建立法律顾问制度，到2020年全面形成与经济社会发展和法律服务需求相适应的中国特色法律顾问、公职律师、公司律师制度体系。”

为进一步贯彻文件精神，切实提高全县政府法律顾问工作水平，增强政府法律顾问工作的针对性和实效性，结合2017年度法治政府建设绩效考核结果，现就进一步健全和完善政府法律顾问制度有关事项通知如下：

一、健全完善政府法律顾问队伍建设机制。各乡（镇）政府、玛依喀克管委会和政府部门要按照中办发〔2016〕30号文件要求，依托本级政府、本部门法制机构建立健全政府法律顾问制度，确保法制机构的法律顾问职责落实到位、符合履职要求的专业人员配备到岗,充实政府法律顾问主体力量。法律事务较多的工作部门应当配备与工作任务相适应的专职人员担任法律顾问；法律事务较少的可以配备兼职人员履行法律顾问职责。乡镇政府、玛依喀克管委会可以根据工作需要，配备专职或者兼职人员履行法律顾问职责。

政府各工作部门可以统一外聘法律顾问，为本部门提供法律服务。严格遴选聘请专家和律师担任政府法律顾问的条件和程序，建立多元化、多渠道购买政府法律顾问服务机制。要充分发挥公职律师的作用，公职律师履行行政机关法律顾问承担的职责，可以受所在单位委托，代表所在单位从事律师法律服务。

二、健全规范政府法律顾问事务办理台账。政府各部门要建立健全法律顾问工作规则、年度支付政府法律顾问经费、纳入法治政府建设考核评价指标等工作相关制度。建立政府法律顾问工作档案和管理台账，对照法律顾问参与重要行政规范性文件合法性审查、参与案件及重大决策的研究讨论、协助处理重大涉法事件、起草有关法律文书或法律意见书、参加重大项目谈判、合同和协议的合法性审查签订等工作以及参与其他法律事项服务等工作内容逐项落实，并预先收集相关台账资料备查。

三、健全完善政府法律顾问管理考核机制。聘请专家和律师担任政府法律顾问的，实行推荐、审核制度。聘请专家担任法律顾问的，聘用单位应当在征得其所在单位同意后与专家签订服务合同；聘请律师担任法律顾问的，聘请单位应当与其所在的律师事务所签订服务合同。各单位可以根据本单位的实际情况，对外聘法律顾问进行相关考核。通过对外聘法律顾问一定期间内的业务量、工作态度、专业水平等方面进行考核，对于考核合格的顾问按工作量和工作绩效给付报酬，特别优秀的可设立相关奖项予以嘉奖，对于考核不合格的顾问予以解聘，保证政府法律顾问团队的专业水准。行政机关要将法律顾问、公职律师经费列入财政预算，为法律顾问、公职律师开展工作提供必要保障。

各乡（镇）、各部门主要负责同志要按照《中共中央办公厅、国务院办公厅关于印发〈党政主要负责人履行推进法治建设第一责任人职责规定〉的通知》（中办发〔2016〕71号）精神，认真履行第一责任人职责，认真抓好政府法律顾问制度的实施。国有资产监督管理部门要督促其监管的国有企业落实法律顾问、公司律师制度，并开展监督检查。司法行政部门要按照律师法的规定加强对公职律师、公司律师的监督管理工作。
