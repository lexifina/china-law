# 乌恰县文体广电局关于2018年至2020年脱贫攻坚工作规划

为进一步加强乌恰县脱贫攻坚工作，强化任务落实，扎实有效地推进乌恰县公共文化服务体系建设，确保乌恰县文化建设专项脱贫攻坚有成效，结合本部门工作实际，制定本规划。

一、指导思想

全面贯彻党的十九大精神，以习近平新时代中国特色社会主义思想为指导，贯彻落实中央、自治区、自治州关于决胜深度贫困地区脱贫攻坚的决策部署，紧紧围绕社会稳定和长治久安总目标，坚持以人民为中心的发展思想，坚持精准扶贫精准脱贫基本方略，坚持专项扶贫、行业扶贫、社会扶贫、援疆扶贫、协作扶贫“五位一体”协同攻坚机制，坚持“十个聚焦发力”，以解决深度贫困区域突出制约问题为重点。通过全面开展文化扶贫，到2020年实现我县与全疆同步基本建成现代公共文化服务体系，实现基本公共文化服务均等化。

二、主要目标

到2020年，在全县基本建成覆盖城乡、便捷高效、保基本、促公平的现代公共文化服务体系。公共文化服务的内容和手段更加丰富，服务质量显著提升，管理、运行和保障机制进一步完善，文化人才队伍进一步发展壮大，政府、市场、社会共同参与公共文化服务体系建设的格局逐步形成，各族群众基本文化权益得到更好保障，基本公共文化服务均等化水平稳步提高。

三、基本原则

——坚持正确导向。坚持以人民为中心，以社会主义核心价值观为引领，弘扬优秀中华文化，巩固基层文化阵地，形成积极向上的精神追求和健康文明的生活方式。

——坚持政府主导。因地制宜、科学规划、分类指导，按照克州基本公共文化服务实施标准积极稳妥推动实现基本公共文化服务均等化，切实保障各族群众基本文化权益，促进实现社会公平。

——坚持社会参与。坚持政府主导和社会参与相结合，引入市场机制，激发各类社会主体参与公共文化服务的积极性，增强内外发展活力，不断满足人民基本文化需求和多样化文化需求。

——坚持共建共享。加强统筹管理，建立协同机制，明确责任，优化配置各方资源，以标准化推动均等化，做到物尽其用、人尽其才，全面提升综合效益，共享文化发展成果。

——坚持改革创新。以改革促发展、促繁荣，创新公共文化服务内容和形式，促进公共文化与相关产业融合发展。深度发掘乌恰县各类特色文化资源，鼓励基层探索，积极开展试点，注重总结推广，发挥示范引领作用。

四、主要任务

（一）统筹推进公共文化服务均衡发展

1.完善县级公共博物馆、图书馆、文化馆、全民健身中心等文化设施建设。加快县博物馆提升改造项目、综合训练中心项目建设进度，确保年底前正常使用。

2.坚持因地制宜、合理布局、突出特点、突出品位，对乡（镇）、村（社区）综合文化站等进行查漏补缺、填平补齐建设。在原乡（镇）、村（社区）文化站（室）的基础上优化建设集宣传文化、党员教育、科学普及、普法教育、体育健身、文艺展演、阅读推广等多功能于一体的基层综合性文化服务中心。

3.落实中宣部支持新疆基层宣传文化建设项目，做好波斯坦铁列克乡“巴所宣教”示范点续建项目。

4.继续做好“文化大院”标准化建设，充分管好用好自治区配备的“文化大院”设备。

5.落实国家、自治区基本公共文化服务指导标准，配齐县、乡、村三级全民健身活动场地、灯光设备，为开展文体活动提供保障。

6.统筹城乡公共文化资源配置，实施“城市反哺农村文化工程”和开展城乡“结对子、种文化”活动。推广以县级文化馆和图书馆为中心、镇级文化站为分馆、村级公共服务中心为服务网点的总分馆制。县级图书馆配备流动文化服务车，开展流动服务和数字服务，在各乡（镇）逐步开展“数字文化乡（镇）示范点”，在村（社区）逐步开展“数字文化驿站”建设工作，运用“移动图书馆”和“科普大篷车”等，打通公共文化服务“最后一公里”。

7.完善农村广播电视有线网络建设，实施村村通宽带工程；推进农村地区广播电视用户接收设备配备工作，建设农村广播电视维修服务网点；建立管理登记台账，抓好人员管理，实现贫困村贫村户广播电视村村通、户户通设备全覆盖。8.扶持特殊群体享有均等服务。切实保障好老年人、未成年人、残疾人、农民工、农村留守妇女儿童、生活困难群众等特殊群体的基本公共文化权益。开展面向老年人、未成年人的公益性文化艺术培训服务、演展和科技普及活动；将农民工文化建设纳入常住地公共文化服务体系，以公共文化机构、社区和用工企业为实施主体，满足农民工群体尤其是新生代农民工的基本文化需求；开展学龄前儿童基础阅读促进工作，向中小学生推荐优秀出版物等文艺作品，分学段有序推进优秀传统文化教育；将中小学生定期观看优秀爱国主义影片，城区有条件的中小学定期参观博物馆纳入中小学教育教学活动计划；实施青少年体育活动促进计划；加大乡、村少年宫项目建设；将“妇女之家”、“儿童家园”纳入村级公共服务中心建设；逐步实施公共文化场所无障碍设施，支持残疾人文化艺术和体育健身类活动内容。

（二）增强公共文化服务发展动力

9.拓宽文化科技卫生法律和爱国爱教宗教服务“五下乡”的内容和形式，将“巴扎宣教”与“五下乡”有机结合起来，县歌舞团文艺下乡每年深入基层演出场次不少于80场（次）。

10.落实好广播电视“户户通”和“大喇叭”工程建设标准，做好全县9乡2镇、34个行政村“大喇叭”设备的维护管理工作，进一步消除盲点、盲区，切实让党和政府的声音传递到千家万户。

11.实现“十三五”期间行政村“农家书屋”全覆盖目标任务，用好用活“东风工程”“万村千乡文化惠民行动”等文化惠民工程，建立县、乡、村三级台帐发放机制，确保各类宣传品、宣传资料及时更新到位。

12．按照农村电影放映“2131工程”的要求，积极开展农村电影放映工作，全年放映任务不低于上年目标。

13.组建农村文艺演出队、农牧民红歌合唱队、柯尔克孜牧民舞蹈队（广播体操队）、农牧民志愿服务队、农牧民讲故事队、农牧民宣讲队、农牧民书画队、农牧民网宣队、农牧民时装模特队、农牧民体育运动队、农牧民民族民间文化传承队、农牧民“大喇叭”宣传队等“十二支文化队伍”，积极开展文化志愿服务，建立文化志愿服务制度，构建参与广泛、内容丰富、形式多样、机制健全的文化志愿服务体系，不断培育文化志愿服务品牌。

14.扩大文化交流合作。利用好对口援疆省市的优势，积极搭建密切的文化交流合作渠道和对外合作交流平台。支持县级文艺演出团体、公共文化服务机构赴对口援疆省市开展演出和文化遗产展览等活动，不断提升乌恰县的社会影响力和知名度。

（三）加强公共文化产品和服务供给

15.丰富优秀公共文化产品供给。大力开展优秀文化遗产和高雅艺术进乡村、进社区、进校园、进军营、进企业，推进送文艺、送书、送电影下乡等项目和优秀出版物推荐活动。

16.优化公共文化服务效能。深入推进公共图书馆、博物馆、文化馆免费开放、错时开放，通过开展图书展、读书比赛、书画展览、文艺培训、全民健身等各类文体活动，大力宣传免费开放政策，全方位推进公共文化机构互联互通。充分利用广播、电视、网络双向互动功能，为各级政府部门便民服务提供窗口和平台。

17.开展丰富多彩的公共文化活动。依托地方特色文化资源和优势文化项目，利用好村级综合性文化服务中心这一载体，调动好各乡村文艺骨干、民间艺人、文化带头人的作用，由村委会、驻村工作队牵头，积极组织村民开展多种类型的比赛、演出等活动，确保村级文化常态化开展；积极组织各类文艺团体深入基层开展多种形式的文化惠民活动。

18.利用各乡（镇）、村（社区）“大喇叭”，开办以服务村民、贴近村民生活为宗旨，集资讯、好人好事表扬、双语学习、信息发布、娱乐为一体的广播节目。

19.以“建设美丽新疆、共圆祖国梦想”为主题，积极开展“乡村大舞台”活动，推动广场文化活动健康发展。

20.制作涉农涉牧广播电视节目，创作、摄制一批农村种植、养殖类科普类文艺作品。

（四）推动公共文化服务与科技融合发展

21.提升公共文化服务现代传播能力。运用宽带互联网、移动互联网、党员干部现代远程教育网等手段，拓宽公共文化资源传输渠道。不断升级改造县电视台、广播站、政府门户网站等主流媒体的采、编、制、播系统，加快数字化转型和传播平台建设步伐。

22.推进公共文化服务数字化建设。实施公共文化机构数字化建设、文化信息资源共享、直播卫星广播电视和地面数字电视公共服务、农村数字电影放映、城乡电子阅报屏建设等项目，构建标准统一、互联互通的公共数字文化服务网络。

（五）创新公共文化管理体制和运行机制

23.建立由县委、县政府分管领导为组长，县文体广电局牵头，乡（镇）及县直有关部门参与的乌恰县现代公共文化服务体系建设管理体制和运行机制，完善公共文化服务体系建设协调联席会议制度，加快推进公共文化服务体系建设。

24.切实转变政府职能，逐步从单纯“办文化”向“管办结合，以管为主”转变。以转换机制、增强活力、改善服务为重点，推进政府购买公共文化服务，加大社会力量参与公共文化服务。

25.建立健全公共文化服务考评体系。建立公共文化机构绩效考评制度，考评结果作为确定预算、收入分配与负责人奖惩的重要依据。重点监督和评估重大文化项目资金的使用、实施效果和服务效能。建立群众评价和反馈机制。探索建立公共文化服务第三方评价机制，增强公共文化服务评价的客观性和科学性。

（六）加大公共文化服务保障力度

26.各级党委、政府要充分认识加快构建现代公共文化服务体系的重要意义，主要领导要切实负起责任，加强组织领导，各乡（镇）、县直各相关单位要根据乌恰县基本公共文化服务实施标准，进一步明确基本公共文化服务项目、硬件设施和人员配备的保障要求，结合实际制定专项行动计划，明确责任和时间表、路线图，集中力量推进工作落实；积极做好宣传和舆论引导工作，营造全社会支持和参与现代公共文化服务体系建设的良好氛围。

27.建立健全公共文化服务财政保障机制，加大各级财政公共文化服务经费支持力度并逐年增长，保障公共文化服务体系建设和运行；积极争取国家、自治区项目资金的支持力度；加强对公共文化服务资金管理使用情况的监督和审计，开展绩效评价。

28.鼓励和引导社会力量参与。认真落实现行鼓励社会组织、机构和个人捐赠公益性文化事业所得税税前扣除政策规定；引导社会力量捐建或独资兴建各类公共文化设施；支持包括文化企业在内的社会各类文化机构参与提供公共文化服务。

29.加强基层文化队伍的建设和管理。落实各级各类公共文化服务机构人员编制，每个乡（镇）综合文化站（中心）编制配备1-2名工作人员；每个村（社区）文化室设立1个公共文化服务岗位；将公共文化服务专业人才培养纳入国民教育和职业教育体系；建立详细的管理类台账，对文化站（室）内的图书进行定期更新，满足各类查阅者需求；积极培育基层文化带头人，加强乡土文化人才队伍建设。

30.认真落实国家、自治区、自治州关于加快构建现代公共文化服务体系建设的相关法律法规和措施要求，切实提高公共文化服务的法治化水平，增强执行力。县委宣传部、县文体广播影视局每年将组织相关部门对各乡（镇）构建现代公共文化服务体系建设情况进行绩效考评。
