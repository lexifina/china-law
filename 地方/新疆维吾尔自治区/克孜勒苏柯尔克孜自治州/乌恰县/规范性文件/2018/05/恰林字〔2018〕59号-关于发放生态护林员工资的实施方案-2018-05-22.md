# 关于发放生态护林员工资的实施方案

为加强对建档立卡贫困人口生态护林员（以下简称生态护林员）的管理工作，切实调动生态护林员的积极性，充分发挥好生态护林员的职能作用，更好地保护森林资源，巩固造林绿化成果，改善生态环境，实现生态补偿脱贫一批的目标，达到即管护森林资源，又增加贫困户稳定收入的目的，结合乌恰县实际，制定本方案。

一、生态护林员的主要职责

2016年聘用生态护林员75名，2017年林业局结合正在开展的精准扶贫工作，从乌恰县9个乡人民政府中选聘100名热爱林业的精准扶贫户担任生态护林员，现生态护林员共计175名。

为强化生态护林员的责任心，林业局与每个生态护林员签订了生态护林员管护合同，明确了生态护林员的管护区域、面积、四至界限，明确了管护要求，明确了甲乙双方的权利与义务。还明确被聘用的生态护林员要依法对管护区域内的林地进行日常巡护，及时报告森林火警和森林火灾隐患，及时发现并报告管护区域内乱砍滥伐、乱捕滥猎、乱挖滥占等破坏森林资源的行为，并协助该局及时查处，接受该局的监管和指导。对故意或重大过失未能履行合同规定管护义务的，林业局将责令生态护林员予以整改，对拒不整改或整改后仍不合格的生态护林员，林业局有权扣减被选聘的生态护林员的工资，情节严重的，可解除护林合同。

《管护合同》实行一年一签，每月管护工资为833元，所有被选聘的生态护林都通过该局的岗前培训后正式上岗履职。

二、资金来源资金由中央财政安排，按每人每年1万元的购买劳务服务补助标准测算，2016年克州下达我县75万元专项资金已发放完成，现2016年生态护林员需继续补助；2017年100万专项资金已全部到位，主要用于对建档立卡贫困人口生态护林员的劳务补贴，一年平均每人劳动报酬共计1万元，2017年12月，生态护林员专项资金共计175万元已全部到位。

三、护林员的工资发放方式

1.生态护林员实行定员、定额管理，建立生态护林员管理制度。

2.为保证劳务费切实发放到生态护林员手中，招聘的生态护林员补助资金由县林业局负责拨付到各乡镇财政所，再由乡镇政府负责发放，补助标准为833元/每月，全年补助为10000元。

3.护生态林员实行一年一聘，合同聘用，动态管理。县林业局与选用的护林员签订公益林管护合同，管护合同期为一年。管护人员必须按照合同履行管护义务，承担管理责任。
