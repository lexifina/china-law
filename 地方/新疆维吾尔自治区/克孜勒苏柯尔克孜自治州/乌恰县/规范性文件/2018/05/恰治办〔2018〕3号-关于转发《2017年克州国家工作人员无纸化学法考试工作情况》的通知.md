# 关于转发《2017年克州国家工作人员无纸化学法考试工作情况》的通知

恰治办〔2018〕3号

有 效 性

来 源

乌恰县依法治县领导小组办公室

各乡（镇）党委、人民政府，玛依喀克管委会，县直及驻县各单位，各企事业单位、人民团体：

《2017年克州国家工作人员无纸化学法考试工作情况通报》(克治办〔2018〕3号)文件，现转发给你们，请各单位各部门一定要从推进全面依法治国和落实新疆总目标的战略高度，提高对国家工作人员无纸化考试工作的重要性认识，真正把无纸化学法考试工作作为法治建设的重要抓手，作为加强干部队伍建设的有力平台，切实抓紧抓好。
