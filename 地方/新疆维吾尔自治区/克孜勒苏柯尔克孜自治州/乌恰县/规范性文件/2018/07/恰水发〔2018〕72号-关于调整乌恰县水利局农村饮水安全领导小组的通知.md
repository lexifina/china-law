# 关于调整乌恰县水利局农村饮水安全领导小组的通知

恰水发〔2018〕72号

有 效 性

来 源

乌恰县水利局

各科室、各站所：

组 长：李 毅 局长

副组长：塔瓦尔地·哈地尔艾力 党组书记

成 员：马国成 副局长

包新民 总工

司拉依·阿洪别克 副总工

司亚旭 建管中心主任

努尔克里迪·吾守尔 质监站站长

领导小组下设办公室，办公室主任由马国成兼任担任，司亚旭负责办公室日常工作。

乌恰县水利局
