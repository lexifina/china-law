# 乌恰县畜牧兽医局专项工作检查方案

根据上级业务主管部门要求，结合重大动物疫病防控、畜禽废弃物资源化利用、污染源普查、合作社防疫条件审查、种公羊补贴项目审核等工作需要，经局务会议研究，组建三个检查组，分赴各乡镇村开展业务工作联合检查，检查方案如下：

一、检查时间：2019年2月27日——3月4日

二、检查内容：

(一）乡镇兽医站：

1、了解各乡各畜种实有牲畜存栏数、出栏数、幼畜数、商品数、良种数等基本情况（查看工作台账）；

2、了解掌握各乡实有合作社、药浴池、配种站及相关设施设备（实地查看，建立台账）；

3、检查各乡人民政府及养殖场、合作社畜禽调运备案手续情况；

4、掌握合作社登记备案情况；

5、掌握各乡镇兽药店登记备案情况；

6、对种公畜补贴项目进行审核，掌握项目实施情况和资金拨付、使用、管理情况；

7、流行病学调查工作；

8、准确掌握各乡官方兽医（检疫员）、兽医和村级防疫员在岗在位和履职情况，了解掌握乡党委政府对畜牧兽医工作支持情况（人员、经费、车辆、物资），了解掌握主要困难诉求。

（二）实地检查

1、合作社：

（1）检查合作社防疫条件合格证办理情况及是否达到防疫条件要求；

（2）调运牲畜备案、隔离、消毒、检测、补免等情况；

（3）检查合作社土地审批、建设等手续；

（4）检查合作社补助经费使用情况；

（5）检查种公畜补助项目资金档案资料；

（6）开展畜禽养殖废弃物资源化利用和污染源普查；

2、配种站、药浴池：

项目实施情况和使用、管理、运行情况；

3、兽医店：

（1）登记备案情况；

（2）检查兽药进销台账；

（3）过期兽药、兽用物资无害化处理情况；

（4）政策宣传，按要求申报。

四、工作要求：

1、各组要认真履职尽责，严格按要求掌握了解情况，如实填写相关表格，做好相关记录，不允许弄虚作假，3月3日下午下班前将检查结果以书面形式上报局主要领导，为会议研究下步工作提供详实的第一手资料。

2、各组要本着“宽严相济、体恤基层、服务百姓”的原则开展工作，既要检查出基层确实存在的突出问题，又要做好业务指导和组织协调工作，以实际行动服务基层、推动工作。

3、各组要按规定严格管理好人员和车辆，外出检查期间，不允许公车私用，不允许吃拿卡要，不允许干与工作无关的事情，一经发现，严肃从重处理。
