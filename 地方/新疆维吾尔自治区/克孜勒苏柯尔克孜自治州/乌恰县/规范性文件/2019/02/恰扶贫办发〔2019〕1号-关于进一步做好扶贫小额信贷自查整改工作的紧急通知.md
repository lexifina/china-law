# 关于进一步做好扶贫小额信贷自查整改工作的紧急通知

各乡：

针对中央第六巡视组脱贫攻坚专项巡视反馈意见涉及扶贫小额信贷突出问题，自治区扶贫开发领导小组办公室高度重视，对自查整改工作下发紧急通知，现将有关要求通知如下：

一、高度重视自查整改工作

扶贫小额信贷是金融精准扶贫的重点措施，也是较为关注的焦点问题。各乡要高度重视，对2016年以来所有发放的扶贫小额信贷对象、额度、期限精准等情况开展“回头看”，对存在问题整改情况进行逐一核实、全面摸排。

二、自查整改内容

一是要明确责任落实，2016年以来各乡开展扶贫小额信贷工作安排部署、落实情况。

二是核查贷款对象审查不精准问题。要核查是否存在一户多贷、向非建档立卡贫困户发放贷款、向不符合条件贫困户发放贷款、冒领贷款等情况。

三是核查贷款使用不精准问题。要核查是否存在贷款用于消费、建房或修房、购置家庭用品、婚丧嫁娶、治病、上学等情况，是否存在贷款闲置，户贷企用，以贷款入股，违规享受贴息，发生偿还风险等情况，是否存其他问题。

四是开展扶贫小额信贷政策宣传，干部业务培训情况。

五是对历次督查巡查、审计、绩效考核、成效考核提出扶贫小额信贷问题整改情况。

三、工作要求

（一）加强宣传，对扶贫小额信贷政策要进行在宣传，各级扶贫干部对扶贫小额信贷政策弄懂弄通，不能推脱责任，特别要重视对建档立卡贫困户的宣传，使贫困户也要知晓政策内容。

（二）认真对照检查，举一反三，自查自纠，并形成自查整改报告，于2月7日12点之前报县扶贫开发办公室。

（三）自治区已启动扶贫小额信贷工作问责机制，对贷款发放、使用监管不力出现的问题将要进行严肃追责问责，各乡要高度重视，按时完成自查整改工作。

乌恰县扶贫开发办公室

2019年2月4日
