# 乌恰县文旅局2019年脱贫攻坚项目情况公开公告

经县扶贫开发领导小组研究确定2019年涉农整合资金项目由县文旅局实施2个，涉及资金868.05万元，分别是旅游扶贫农家乐项目421.85万元、文旅扶贫基础设施建设446.2万元。现将项目有关情况公示如下：

一、旅游扶贫农家乐项目

1.实施地点。巴音库鲁提乡克孜勒阿根村。

2.建设内容。进行农家乐园区道路硬化（4m宽，300m长），农家乐两座（800㎡，钢架结构，含二装及附属），传统毡房5座（100根，含底座及配套），15㎡小木屋4座，鱼塘修缮，木栈道（1.5m宽，300m长），农家乐大门，特色养殖园，小品景观，种植园土方回填，网围栏及防护设施，娱乐设施。

3.资金来源及规模。投入资金421.85万元，其中少数民族发展资金280万元，2019年中央农业生产发展资金（统筹整合部分）128.74万元，2019年退牧还草工程中央基建投资预算（拨款）（统筹整合部分）13.11万元。

4.实施期限。2019年。

5.实施单位及责任人。乌恰县文化体育广播电视和旅游局责任人：刘俊莉

6.绩效目标。项目运营后，带动20个贫困人口就业，增加贫困人口年收入19.6万元，助力脱贫攻坚。

7.带贫减贫机制。1、该旅游产业基地建成后，资产交接给巴音库鲁提乡克孜勒阿根村委会进行管理，租金收益所得全部收归村委会集体所有，由村两委班子专题会议研究收益如何分配，收益分配给由村民代表大会公选出来的贫困户所有，受益贫困户进行公告公示。发展订单旅游产业，在承包方承包后，承包合同我们将要求承包方食材、用工等方面，所有一切尽可能的从克孜勒阿根村贫困户家中购买，产业规模化后，将不断发展订单农业、订单畜牧业，拓宽克孜勒阿根村贫困户的收入来源渠道，不断增加贫困户收入。将该旅游产业基地打造成一个集旅游观光、休闲、素质拓展等综合性的旅游度假基地，不断增加收入，发展旅游产业。

四、文旅扶贫基础设施建设

1.实施地点。吉根乡斯姆哈纳村。

2.建设内容。在乌恰县吉根乡斯姆哈纳村新建西极塔1座，栈道1000米，阳光创业商店2个，旅游厕所1座，停车场1000㎡，亭子1个，西极石雕标志1个，四级道路27000平方米。

3.资金来源及规模。投入资金446.2万元，其中财政扶贫资金50万元，2019年中央旅游发展基金补助地方项目资金17.2万元，2019年旅游发展专项资金（统筹整合部分）45.5万元，2019年中央扶贫专项资金260.7万元，2019年中央农村公益事业财政奖补资金（涉农资金整合部分）72.8万元。

4.实施期限。2019年。

5.实施单位及责任人。乌恰县文化体育广播电视和旅游局责任人：刘俊莉

6.绩效目标。项目运营后，带动49个贫困人口就业，增加贫困人口年收入46.55万元，助力脱贫攻坚。

7.带贫减贫机制。该旅游产业基地建成后，资产交接给吉根乡斯姆哈纳村委会进行管理，租金收益所得全部收归村委会集体所有，由村两委班子专题会议研究收益如何分配，收益分配给由村民代表大会公选出来的贫困户所有，受益贫困户进行公告公示。旅游产业基地建成后，以柯尔克孜族文化为底蕴，从食、住、行、游、购、娱六类旅游基础要素为主，发展旅游服务业，获得收益。
