# 关于成立乌恰县审计局普法依法治理工作领导小组的通知

恰审办〔2019〕3号

有 效 性

来 源

乌恰县审计局

局各科室：

为认真抓好“七五”普法工作，落实好党的十九大和十九届二中、三中全会、全国两会精神，加强社会主义法治文化建设，突出社会主义核心价值观要求，更好地完成普法依法治理各项目标任务，经局党组研究，确定成立乌恰县审计局2019年度普法依法治理工作领导小组，以成员如下：

组  长：孟向江 （党组书记、副局长）

副组长：赵丽   （党组成员、副局长）

成  员：古拉衣木·司马衣、韩亚东、坎吉、王虹

领导小组下设办公室，古拉依木·司马衣负责具体文件整理报送等工作。

(此件公开发布）
