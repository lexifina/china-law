# 关于畜牧兽医专业人员购买保险的通知

各乡镇、局各站所畜牧兽医人员：

乌恰县现有牲畜35万左右，畜牧兽医工作人员和村级防疫员注射疫苗或检测工作中经常接触动物。布病，结核病等某些疾病易传染给至工作人员，为减轻畜牧兽医专业人员的后顾之忧，减少工作人员治疗费用现申请购买保险，需要购买保险人员149名，其中正式工80名，村级防疫员69名。每人保险费300元，共计： 149×300=44700元（肆万肆仟柒佰元整），资金自筹。

乌恰县畜牧兽医局

2019年4月3日
