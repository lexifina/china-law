# 关于印发《乌恰县2019—2021年产业扶贫暨长效机制建立指导意见》的通知

为贯彻落实党中央、国务院、自治区、自治州关于产业扶贫和产业振兴相关文件会议精神，根据《乌恰县2019年脱贫攻坚巩固提升工作方案》，结合乌恰县实际，现制定《乌恰县建立产业扶贫长效机制指导意见》（以下简称《指导意见》）。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻党的十九大和自治区、自治州相关会议精神，紧紧围绕社会稳定和长治久安总目标，以新发展理念为引领，以农业供给侧结构性改革为主线，以农业提质增效、贫困户就业增收为核心，以“良种、良法、良好的组织方式”为抓手，培育壮大扶贫产业，为扶贫巩固提升提供有力支撑。

二、基本原则

（一）坚持市场主导。在产业发展中，坚持以市场为导向，坚持公平竞争、反对垄断。发挥各乡、村、群众在产业发展中的主体作用，政府按照“资金跟着项目走、项目跟着产业走、产业跟着规划走、规划跟着贫困户走”的要求，建立扶持机制。

（二）坚持突出特色。全县产业扶贫坚持培育壮大畜牧业、林果业、花卉苗木、旅游四大产业。形成布局合理、产业鲜明、链条完整、共享发展的新格局。

（三）坚持开放创新。坚持对外开放，促进产品“走出去”和技术引进来。坚持党建引领，以“党总支+合作社+农户”模式，推动“三变”（即资源变资产、资金变股金、农民变股东）；鼓励各种有利于发展的创新创造。

（四）坚持绿色发展。牢固树立“绿水青山就是金山银山”的发展理念，推进质量兴农、绿色兴农、品牌兴农，对农产品质量问题采取“零容忍”；在产业发展中禁止污染环境、破坏生态的行为。

三、发展目标

全县扶贫产业按“4+n”规划布局，即四大产业，多条增收措施。

四、带贫机制

（一）资产连接。即贫困户通过资产方式与合作社（产生利益连接（资源变资产），资产连接方式主要是土地、树木等，提倡合作社租用、按销售额比例分成（土地、树木分成在20%以内），使贫困户获得有“租金收入”。

（二）资金连接。即贫困户通过资金投入方式与合作社产生利益连接（资金变股金）。资金连接方式主要提倡保底分红，使贫困户获得稳定的“股金收入”，本金随时可退还贫困户，合作社要提供财产担保。财政投入的扶贫资金，在确保本金安全的前提下，可以折股给贫困户投资到合作社，生产性固定资产可分股到户。

（三）劳务连接。即贫困户通过劳务投入方式与合作社及其成员产生利益连接，使贫困户获得“薪金收入”。资产连接方式可长期聘用、临时聘用、劳务合作社派遣不固定（记工分）务工等形式。

（四）产品连接。即贫困户通过家庭生产商品加盟方式与合作社产生利益连接。产品连接主要是合作社提供技术指导，统一销售。

五、鼓励探索发展新模式

（一）鼓励三权分离。鼓励农村土地所有权、承包权（农户）、经营权（生产者）分离，促进土地流转，实现规模化生产。国有资源资产采取所有权、经营权分离，国有企业只从事资源资产管理，不从事日常经营活动。

（二）鼓励股份到户。产业到户项目中，在坚持群众认可、风险可控、固定分红的原则下，可采取项目统一建设，股份量化到户模式。

（三）鼓励保本固定分红。多人合作的公司、合作社或农场，鼓励一人主管，多人建议，分红上采取一人向多人保本年度固定分红。

（四）鼓励专业化分工。鼓励各合作社、公司相互联合，各自从事自己擅长的环节，促进分工和生产效率提高。

（五）鼓励“互联网+农业”。鼓励线上线下一体化、先定制后生产、变生产为服务等模式创新和发展。

（六）鼓励三产融合。鼓励农民合作社、农场将生产基地、加工厂、观光体验旅游业融合发展。

六、扶持措施

（一）精准对象。贫困户自愿选择符合全县产业发展方向的，可以申请扶贫资金扶持。一般户可申请部门资金扶持，产业组织可申请产业组织扶持、贷款贴息、保险扶持。同时，各乡村在项目储备、建立项目库时，要在产业扶贫相关原则下确定产业，防止盲目发展，出现小、散、乱。

（二）促进两头。以促两头，带中间，推进全产业链发展。一是重点扶持基地建设环节。包括：标准化种植、养殖、加工基地建设、技术提升、品种引进等。二是重点扶持销售环节。包括对外营销、品牌建立、包装等。

（三）以奖代补。在产业发展中，要鼓励一部分经济主体、群众先发展，带动其他群众，不能搞行政命令“一刀切”。扶持方式坚持以奖代补，积极性高的多支持、积极性低的少扶持、没有积极性的暂不扶持，坚决消除等、靠、要思想。扶持标准各相关部门可在此《指导意见》原则上自行制定。

（四）年度排名。每年底分畜牧、林果、苗木三个行业，针对产业组织进行全县排名，排名又分基地建设情况、带贫情况、销售情况排名。县委、县政府按排名靠前的给予年度表彰奖励。同时、对产业扶贫作出贡献的单位和个人也给予表彰奖励。

七、保障措施

（一）加强组织领导。县以产业扶贫专项组作为产业扶贫的领导机构。畜牧业责任单位为农业农村局、畜牧局；林果业责任单位为林业局；花卉苗木产业责任单位为农业农村局、供销社负责；旅游业责任单位为旅游局；多条增收措施责任单位为商经委、社保局。各乡各部门也要成立相应的组织领导机构，落实责任。

（二）严守相关纪律。一是坚持群众满意底线。项目建设直接受益群众满意率80%以上；二是不越生态红线。所有项目建设不能破坏环境，不能碰国家生态保护红线；三是不碰纪律高压线。所有项目建设要严格按相关规定进行，遵守相关纪律。

（三）建立容错纠错。在坚持相关法律法规的原则下，鼓励大胆实践，对创新创造中出现的过失，可容错纠错，不追究责任。

（四）建立工作机制。一是产业扶贫专项组成员单位每两月召开一次专题会，总结经验、解决问题、推进重点工作。二是对工作采取“三定”定量、定人、定时，提高办事效率。三是每年对具体项目开展项目绩效评价，并排名通报实施和后续管理单位。
