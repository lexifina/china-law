# 乌恰县审计局对乌恰县膘尔托阔依乡萨孜村、塔尔尕拉克村饮水安全巩固提升改造工程（一标段）竣工决算进行审核的通知

恰审结通〔2019〕44号

有 效 性

来 源

乌恰县审计局

乌恰县中小型公益性水利工程建设管理中心：

根据《中华人民共和国审计法》第二十二条的规定，我局决定派出审核组，自2019年4月23日起，对你单位组织实施的乌恰县膘尔托阔依乡萨孜村、塔尔尕拉克村饮水安全巩固提升改造工程（一标段）进行竣工决算审核，必要时将追溯到相关年度或延伸审核有关单位。请予以配合，对所提供资料（包括电子资料）的真实性、完整性负责，并进行书面承诺。

审核组组长：张鹏

审核组成员：王山宝（主审）、王新平

廉政监督员：马麦提阿孜·麦麦提伊布来音
