# 2019年乌恰县市场监督管理局“安全生产月”活动方案

以习近平新时代中国特色社会主义思想和党的十九大精神为指引，以树立安全发展理念，弘扬“生命至上、安全第一”的思想为主题，以宣贯《中华人民共和国特种设备安全法》、《新疆维吾尔自治区电梯管理办法》、《食品安全法》、《药品管理法》等法律法规和落实安全生产主体责任为主线，通过开展系列贴近实际、贴近生活、贴近群众、贴近基层的质量安全宣传教育活动，进一步促进社会公众特种设备、食品、药品安全意识的全面提升，为乌恰县经济社会发展营造稳定的安全生产环境。

二、活动内容

（一）开展特种设备安全宣传“七进”活动。

要针对保障特种设备安全运行的重点工作，全面开展特种设备安全进企业、进学校、进社区等“七进”宣传教育活动，以此为契机，用群众喜闻乐见的方式通俗易懂地宣传习近平新时代中国特色社会主义思想、党的十九大精神，大力加强《中华人民共和国特种设备安全法》、《新疆维吾尔自治区电梯管理办法》、《食品安全法》和《药品管理法》等政策法规的宣传。明确《安全生产法》、《中华人民共和国特种设备安全法》、《食品安全法》和《药品管理法》对企业安全生产的主体责任，牢固树立“安全第一、生命至上”的安全意识，进一步推动特种设备、食品、药品安全理念的宣传普及和安全行为习惯的培养，努力提高全社会安全生产防范的意识和能力。

（二）开展安全宣传咨询日活动。

做好“6·16”安全生产宣传咨询日活动。加大普法宣传力度，通过展板、安全操作讲解、发放宣传单、安全咨询特种设备安全教育系列等形式，向社会公众传播安全生产理念、思路、措施和行为规范，宣传特种设备安全政策法规、科普常识、应急处置、自救互救方法，解答群众关切的安全问题。

（三）开展电梯、压力容器、大型游乐设施、厂矿企业的特种设备及危化品生产安全专项整治检查行动。

结合日常监督检查和乌恰县特种设备分布情况，认真开展特种设备安全检查和专项整治行动。要加大“六一”期间对公园大型游乐设施的安全检查；加大对夏季旅游场所特种设备的安全检查；加大对住宅高层、商场、医院等人员密集场所电梯运行的安全检查；加大对液化气气瓶充装的安全检查；加大对危险化学品企业进行监督检查，严格落实企业主体责任，坚决叫停无证生产行为；加大对厂矿企业使用的特种设备进行安全检查，确保不留死角、杜绝安全事故的发生；坚决遏制特种设备及危化品生产使用过程中的违法行为，保障特种设备及危化品生产安全运行，保护人民生命财产安全。

（四）组织特种设备应急救援演练活动。

以人员密集场所电梯、危化品泄露等设备为重点，联合相关部门、组织相关单位开展特种设备、危化品安全应急救援演练活动，并可将应急救援演练活动作为“安全月活动”的启动仪式强化宣传，提高从业人员及社会公众的防灾、逃灾、避灾和自救、互救能力，并通过演练优化应急预案，完善应急准备，提高实战能力，努力提高特种设备及危化品安全事故应急处置能力和应急管理水平。

（五）开展食品药品专项整治活动。

深入食品、药品经营、使用单位开展安全隐患排查整治执法工作，重点监督检查前期排查出的安全隐患整改落实情况，对整改不力和新出现的违法违规行为严肃处理，确保药品安全和质量安全，防患于未然。以餐饮店、学校食堂为重点对象，以餐厨垃圾废弃食用油脂专项整治为重点内容，大力规范餐饮单位经营行为，严防餐饮服务食物中毒事件发生。

（六）开展安全事故警示教育活动。

紧密结合“七进”活动，以近年来发生的特种设备安全典型事故案例为素材开展警示教育，把别人的教训当作身边的教训。也可结合宣贯、培训，通过集中组织观看事故警示教育片，研究分析事故的规律和特点，吸取教训、总结经验，进一步提高防范事故的能力。

乌恰县市场监督管理局
