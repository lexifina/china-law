# 关于乌恰县畜牧专业合作社专项清查工作摸排情况汇报

根据自治州党委农办等11个部门联合下发的《自治州开展农民专业合作社“空壳社”专项清理工作方案》的通知（克党农〔2019〕7号）要求和县委副书记、县长司亚尔·哈兰的批示精神，4月25日，乌恰县畜牧兽医局召开专题会议，以集中清理“空壳社”为重点，依法清理、分类处置、做好统筹安排，强化部门协作，落实属地责任，在对全县畜牧专业合作社发展情况前期摸底排查的基础上，重点对2019年3月31日前登记注册的各个正在运行的畜牧专业合作社进行清查、摸清底数、掌握实情。

乌恰县现有畜牧专业合作社59家，其中3家未在市场监督管理局登记，9家已注销、12家正在办理注销（现在注销公示期），其余35家中有正常运营的26家合作社和准备重新运营的9家合作社。通过实地询问合作社法人、社员、村“两委”班子成员等了解和掌握合作社运行情况、发展状况，掌握享受政府补助和贴息贷款次数、金额、用途及债权债务等情况。经摸底排查，正常运营的26家合作社中具有“空壳社”特征的合作社有4家，具体情况如下：

1、无农民成员实际参与、无实质性生产经营活动以及因经营不善停止运行的合作社为乌恰县库克地别农民专业合作社1家。该合作社2013年已享受“菜篮子”畜产品生产扶持资金项目补助30万元，现因2018年10月其丈夫买买提托连去世后，无人经营，所有合作社社员均已退出。其98只羊交由同村牧民托养。养殖场无实际性经营。现申请注销。

2、无农民成员实际参与的有3家。其中，乌恰县迭木加依落农牧业综合开发农民专业合作社2018年10月因合作社基建工程耗资较大，严重缺资金，社员未能分红，合作社社员已全退股。现无农民成员实际参与。其余2家乌恰县乌鲁克恰提阿克摸依诺克养殖业农民专业合作社和乌恰县双心农牧业综合开发农民专业合作社均无农民成员实际参与合作社经营。

准备运营9家的合作社中可以定性为“空壳社”的合作社有8家，具体情况如下：。

1、无农民成员实际参与的合作社有2家，分别为乌恰县欧尔都牛羊育肥特色养殖业合作社和乌恰县巴柯塔拉怡农牧业综合开发农民专业合作社等；

2、无实质性生产经营活动的合作社有2家，分别是：乌恰县吉根乡阿力克木养殖业农民专业合作社和乌恰县吉根乡加哈勒麦养殖业农民专业合作社等；

3、无农民成员实际参与以及因经营不善停止运行的合作社为乌恰县喀拉铁列克特色养殖业农民合作社1家。

4、无农民成员实际参与、无实质性生产经营活动以及因经营不善停止运行的合作社有3家。分别是：乌恰县阿曼

农民专业合作社、乌恰县玛依喀克牧民定居区叶力库提牛羊育肥特色养殖业农民专业合作社以及乌恰县桃花渔业农民专业合作社等。

在排查工作过程中，该35家合作社同时存在以下的共性问题：

1、合作社社员、法人对农民专业合作社的现实意义、运营方式以及利益分配方式等认识和理解不透，农民专业合作社理事长、社员以及财务管理等人员的思想观念落后。

2、大部分畜牧专业合作社有生产经营活动，只具有法律形式，而没有按章程运作，运行管理不规范，没有严格的分工制约机制，财务管理混乱，不能提供财务账目、凭证或银行流水的印证资料等，无法提供社员理事共商共议会议记录等相关印证材料。

3、大部分不能提供农民参股、分红协议等相关印证材料，造成无法验证有无农民成员实际参与经营是否属实，存在提交虚假登记材料或者以欺诈手段取得登记的“挂牌社”“一人社”等情况。

4、通过现场查看合作社经营场所硬件建设、挂牌，实有牲畜品种、数量和《统一社会信用代码证》、《动物防疫条件合格证》、《合作社章程》、管理制度等资料有不同程度的缺失，同时《动物防疫条件合格证》绝大部分已过期。

乌恰县畜牧兽医局

2019年5月15日
