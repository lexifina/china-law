# 关于印发乌恰县2019年“放管服”改革工作要点的通知

各乡（镇）人民政府，乌恰县推进政府职能转变和“放管服”改革协调领导小组各成员单位:

《乌恰县2019年“放管服”改革工作要点》已经乌恰县人民政府同意，现印发给你们，请结合实际，按照以下要求一并认真贯彻落实。

1.各乡（镇）、各部门要高度重视乌恰县2019年“放管服”各项改革工作任务，各专项组、牵头单位、责任单位要进一步提高政治站位，严格按照任务分解和工作要求，认真履行工作职责，抓紧抓实抓好，共同推动各项“放管服”改革任务得到落实。

2.各单位要严格按照责任分工，主动作为、狠抓落实。牵头单位要严格履行主体责任，充分发挥牵头抓总作用，主动加强与责任单位的沟通和联系，仔细梳理所承担的工作任务，要进一步细化目标责任分解的内容，动态掌握工作进展情况，按要求向各专项组报送目标任务完成情况、存在的问题和下一阶段工作计划。（其中，第一项，优化营商环境，激发市场活力，由优化营商组〈乌恰县发改委〉负责，第二项，激励创业创新，增强内生动力，由激励创业创新组〈发改委〉负责，第三项，深化商事改革，便利企业经营，由深化商事制度改革组〈市场监督管理局〉负责，第四项，改善社会服务，扩大公共保障改善，由社会服务组〈教育局〉负责，第五项，加快平台建设，推进网上为民服务工作，由综合组〈人民政府办公室〉负责）。

3.各乡（镇）、各专项组要指定专人负责，加强与牵头单位的组织协调和沟通配合，及时掌握工作进度和完成情况，确保各项“放管服”改革任务顺利完成。并将各牵头单位报送的情况汇总整理后的完成情况、存在的问题和下一阶段工作计划于5月29日前、10月29日前以书面（含电子版）一并报送乌恰县人民政府办公室。乌恰县人民政府督查室将以各专项组为重点，加强跟踪督查，定期通报完成情况。

2019年5月20日

乌恰县2019年“放管服”改革工作要点

“放管服”改革是2019年自治区深化改革的重要任务之一。全县上下要坚持以习近平新时代中国特色社会主义思想为指导，贯彻落实党的十九大和十九届二中、三中全会精神，贯彻落实以习近平同志为核心的党中央治疆方略、特别是社会稳定和长治久安总目标，根据党中央、国务院“放管服”改革决策部署，按照自治区党委“l+3+3+改革开放”工作部署，认真贯彻落实自治区、自治州党委和乌恰县委关于“放管服”改革工作安排，聚焦总目标，以简政放权放出活力和动力、创新监管管出公平和秩序、优化服务服出便利和品质为目标，着力释放稳定红利，稳步推进“放管服”改革，进一步减轻企业负担，降低运行成本，提升优化营商环境，提高政府服务效率和水平，推动经济高质量发展，促进社会稳定和长治久安。

一、优化营商环境，激发市场活力

（一）破除各种不合理门槛和社会资本市场准入限制

1.进一步减少社会资本市场准入限制，全面清理取消在外商投资准入负面清单外领域针对外资设置的准入限制，实现市场准入内外资标准一致，落实外商投资管理制度。全面实施新版市场准入负面清单，并在县人民政府门户网站发布，实现清单事项网上公开便捷查询，推动“非禁即入”普遍落实。（乌恰县发改委、商务科技和工业信息化局牵头，乌恰县财政局等相关部门配合）

2.规范有序推进政府和社会资本合作PPP项目建设，在核查清理后的PPP项目库基础上，加大对符合规定的PPP项目推进力度，督促各单位、各部门依法依规落实已承诺的合作条件，吸引社会资本进入公路、旅游、环保、污水垃圾等领域。（乌恰县发改委、财政局牵头，各相关部门配合）

3.组织开展招投标领域专项整治，消除在招投标中对不同所有制企业设置的各类不合理的限制和壁垒，严格落实《必须招标的工程项目规定》，赋予社会投资的房屋建筑工程建设单位发包自主权。任何单位不得违法限制或排斥本地区以外的建筑企业参加工程项目投标，严禁强制或变相要求外地建筑企业在本地设立分公司或子公司。（乌恰县住建局牵头，各相关部门配合）

4.推动缓解中小微企业融资难融资贵问题。人民银行会同有关部门疏通货币信贷政策传导机制，综合运用多种工具，细化监管措施，强化政策协调，提高政策精准度，稳定市场预期。抓好扶贫再贷款、支小再贷款、中小企业高收益债券、小微企业金融债券、知识产权质押融资等相关政策落实。（人行乌恰县支行牵头，各相关部门配合）

5.推动银行机构根据民营企业融资需求特点，借助互联网、大数据等新技术，设计个性化产品满足企业融资需求，落实不盲目停贷、压贷、抽贷、断贷的政策措施，防止对民营企业随意减少授信、抽贷断贷“一刀切”等做法。推动银行业金融机构认真落实《新疆银行业小微企业金融服务工作监管考核评价办法（试行）》和金融机构绩效考核与小微信贷投放挂钩的激励机制。严格执行银保监会“七不准”“四公开”制度，督促有关金融机构坚决取消和查处各类违规手续费，除银团贷款外，落实“两禁两限”规定，禁止向小微企业收取贷款承诺费、资金管理费，严格限制向小微企业收取财务顾问费、咨询费等费用，减少融资过程中的附加费用，降低融资成本。（人行乌恰县支行负责）

6.加强诚信政府建设，把政府诚信作为优化营商环境的重要内容，建立健全“政府承诺+社会监督+失信问责”机制，开展政府机构失信问题专项治理，凡是对社会承诺的服务事项，都要履行约定义务，接受社会监督，没有执行到位的要有整改措施并限期整改，对整改不到位、严重失职失责的要追究责任。要监测评价城市政务诚信状况，组织开展政府机构失信问题专项治理。要梳理政府对企业失信事项，提出依法依规限期解决的措施，治理“新官不理旧账”等问题。（乌恰县发改委牵头、各乡〈镇〉人民政府，各部门配合）

7.以治理混淆行为、商业贿赂、禁止虚假或误解宣传、侵犯商业秘密、有奖销售禁止情形、利用互联网不正当竞争为重点，在全县范围内加大“保健”市场重点行业、重点领域的事中事后监管力度，依法严厉打击虚假宣传、虚假广告、制售假冒伪劣等违法行为。推进社会组织综合监管体系建设，通过年度检查、随机抽查、等级评估、行政约谈、抽查审计、专项审计信息公示等方式加强事中事后监管，加大执法力度，依法查处社会组织违法行为。（各乡〈镇〉人民政府，乌恰县市场监督管理局牵头，乌恰县商务科技和工业信息化局、公安局、商务局、卫生健康委员会等部门配合）

（二）推动精简进出口环节监管证件

8.进一步优化通关流程和作业方式，推动精简进出口环节监管证件，能退出口岸验核的退出实现统一申报单证、统一作业系统、统一风险研判、统一指令下达、统一现场执法。2019年底，实现进出口整体通关时间在2017年基础上压缩三分之一以上。推广单一窗口应用，主要业务（货物、舱单、运输工具）应用率达到90%。（伊尔克什坦海关、吐尔尕特海关牵头，各相关部门配合）

9.降低进出口环节合规成本和推进通关便利化。认真落实国务院确定的降低集装箱进出口环节合规成本的要求，制定公布口岸收费目录清单，加强督促检查，确保落实到位。（乌恰县财政局牵头，乌恰县市场监督管理局、交通运输局、发改委、商务科技和工业信息化局、伊尔克什坦海关、吐尔尕特海关配合）

（三）推动外商投资和贸易便利化

10.切实保障外商投资企业公平待遇，实现市场准入内外资标准一致，落实以在线备案为主的外商投资管理制度，并组织对外资企业在政府采购、资金补助、资质许可等方面是否享有公平待遇进行专项督查。尽快提出对地方性法规废止或者修订建议，完成规章和规范性文件的废止或者修订工作。进一步促进外商投资，会同有关部门积极推进重大外资项目建设，将符合条件的外资项目纳入重大建设项目范围，或依申请按程序加快调整列入相关产业规划，给予用地审批等支持，加快项目环评报告审批进度，推动项目尽快落地。推进自治区投资项目在线审批监管平台一体进程，加快项目审批管理服务“一网通办”（各乡〈镇〉人民政府，乌恰县发改委牵头，乌恰县商务局、司法局、财政局、自然资源局、住建局、商务科技和工业信息化局、生态环境局等部门配合）

11.深化税制改革，推进结构性减税，推动小微企业享受减半征收所得税等优惠政策落地。落实出口退税政策，加快出口退税进度，执行简并退税率，推动实体经济降成本、保持外贸稳定增长。对信用评级高、纳税记录好的企业简化手续、缩短退税时间。严格执行外商再投资暂不征收预提所得税政策，适用范围从鼓励类外资项目扩大至所有非禁止项目和领域。全面推行无纸化退税申报，提高退税审核效率，尽快实现电子退库全联网全覆盖，实现申报、证明办理、核准、退库等业务网上办理。同时，要采取切实有效的措施防范和坚决打击骗取出口退税行为。（各乡〈镇〉人民政府，乌恰县财政局、税务局牵头，各相关部门配合）

（四）减轻企业税费负担

12.查处整治公章刻制领域行政垄断案件，严禁各级公安机关指定公章刻制企业，纠正和制止垄断经营、强制换章、不合理收费等现象。（各乡〈镇〉人民政府、乌恰县公安局、市场监督管理局负责）

13.加强协同配合，形成工作合力，重点加大清理政府部门、国有企业拖欠民营企业中小企业账款工作力度，确保完成清欠任务。（各乡〈镇〉人民政府，乌恰县商务科技和工业信息化局负责）

14.落实好国家出台各项降费减负政策，清理规范涉企行政事业性收费项目，对不合法不合规、重复设置等收费项目要坚决予以取消。根据财政部政府性基金和行政事业性收费目录清单“一张网”管理规定，对目录清单实行动态调整实时更新。（各乡〈镇〉人民政府，乌恰县发改委、财政局负责）

15.整治政府部门下属单位、行业协会商会、中介机构等乱收费行为，取消非法违规收费、降低收费标准，坚决纠正取消行政审批后中介机构和部门下属单位变相审批及违法违规收费、加重企业负担等现象。督促各有关部门对下属单位涉企收费情况进行一次全面清理，整顿部门下属单位利用行政权力违规收费行为。（各乡〈镇〉人民政府，乌恰县发改委、市场监督管理局牵头，各相关部门配合）

16.清理没有法律、行政法规依据或未经国务院批准的涉企保证金，严格执行已公布的涉企保证金目录清单。进一步降低涉企保证金缴纳标准，推广以银行保函替代现金缴纳保证金的做法。（各乡〈镇〉人民政府，乌恰县商务科技和工业信息化局、财政局牵头，各相关部门配合）

17.推动金融类协会规范合理收取会费、服务费，减轻企业负担。检查行业协会商会收费情况，纠正不合理收费和强制培训等行为，并建立健全行业协会商会乱收费投诉举报和查处机制，分析全县生态环境举报信息，对群众反映突出的生态环境问题开展预警，并采取具体的应对措施。（各乡〈镇〉人民政府，人行乌恰县支行负责）

18.加强对厂房租金的监督检查和指导工作，落实管控责任，切实做好管控工作，严厉打击囤积厂房、哄抬租金等违规行为，对问题严重的县（市）及相关部门要严肃追究责任。（各乡〈镇〉人民政府，乌恰县市场监督管理局牵头，各相关部门配合）

（五）推进不动产登记改革

19.2019年底前，流程精简优化到位，不动产登记数据和相关信息质量明显提升，所有一般登记、抵押登记业务办理时间力争分别压缩至10个、5个工作日以内。依托自治区网上政务服务平台，推动“互联网+不动产登记”，加快推进不动产抵押登记全程电子化系统建设。2019年底，州、县（市）实现“互联网+不动产登记”（乌恰县自然资源局牵头，乌恰县住建局、税务局等相关部门配合）

20.推行房屋交易、不动产登记、税收征缴“一窗受理、信息推送、并联办理”，2019年底前，全县实现“一窗受理、并联办理”。房屋交易备案1.5个工作日办结。（乌恰县住建局、自然资源局、税务局负责）

（六）推进工程建设项目审批制度改革

21.进一步压减工程建设项目审批时限，推行全流程、全覆盖的工程建设项目审批制度改革，统一审批流程，精简审批事项和条件、下放审批权限、合并审批事项、压减审批时间，全县实现工程建设项目审批时间压缩至120个工作日以内完成。依托自治区政务服务平台工程建设项目审批系统，统一公开办事指南、办理流程、政策法规和标准规范，工程建设项目实现统一受理、并联审批、实时流转、跟踪督办、信息共享。（各乡〈镇〉人民政府，乌恰县住建局牵头，各相关部门配合）

22.全面梳理工程建设项目审批事项，努力实现。“一张蓝图”统筹项目实施、“一个系统”实施统一管理、“一个窗口”提供综合服务、“一张表单”整合申报材料、“一套机制”规范审批运行。指导基层制定各审批阶段“一张表单”，将所有行政审批、各类评估、中介服务、市政公用服务以及备案事项纳入并联推进。（各乡〈镇〉人民政府，乌恰县住建局牵头，各相关部门配合）

23.制定“多规合一”工作方案，以国民经济和社会发展规划、城乡规划、土地利用总体规划为基础，综合各类规划对空间的需求，形成城市空间布局“一张图”，完善城乡规划综合数据库，与网上行政审批系统对接，实现资源共享、协同办理。（各乡〈镇〉人民政府，乌恰县自然资源局牵头，各相关部门配合）

24.制定施工图联合审查办法，按照“统一标准、联合审查、结果互认、共同监管”原则，将消防、人防等部门的技术审查等纳入施工图联审。（各乡〈镇〉人民政府，乌恰县住建局牵头，各相关部门配合）

25.积极推广“区域评估”，明确项目准入标准和条件，纳入用地建设条件，项目单位不再单独申请评估。（各乡〈镇〉人民政府，乌恰县住建局牵头，各相关部门配合）

26.落实自治区联合验收管理办法，明确参与部门、验收标准等，将联合验收工作纳入工程建设项目审批制度管理平台管理。（各乡〈镇〉人民政府，乌恰县住建局牵头，各相关部门配合）

（七）加快水电气暖等服务领域改革
