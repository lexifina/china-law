# 关于各乡镇做好脱贫攻坚迎国检工作农村广播“户户通”电视覆盖、乡村文化室设施规范管理检查的通知

各乡（镇）人民政府、玛依喀克管委会：

为扎实做好脱贫攻坚迎国检准备工作，全面真实体现县脱贫攻坚工作，乌恰县文化建设专项组根据乌恰县脱贫攻坚迎国检预方案工作要求，乌恰县文化建设专项组为保障全县各乡（镇）村文化活动室、农村“户户通”用户能够看上电视，确保脱贫攻坚迎国检顺利开展，乌恰县各乡（镇）村对文化活动室设备规范使用、“户户通”用户能够正常收听收看广播电视进行摸底排查，在摸底过程中出现收看不到广播电视用户及各乡（镇）村文化活动室不规范的及时反馈至县电视台、文化图书馆、“村村通”办公室负责人。
