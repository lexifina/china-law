# 关于征集举报财政惠民惠农财政补贴资金“一卡通”管理使用中违纪违规线索的公告

为认真贯彻习近平新时代中国特色社会主义思想以及党的十九大和十九届二中、三中全会精神，贯彻落实习近平总书记关于脱贫攻坚重要指示精神，坚决整治群众身边腐败问题，助力打赢脱贫攻坚战，根据自治区、自治州统一安排部署，即日起对全县财政惠民惠农补贴资金“一卡通”管理问题进行专项治理，现向社会征集举报违纪违规线索：:

一、受理举报范围

2017年-2018年以来乌恰县境内涉及的惠民惠农财政补贴资金“一卡通”管理中存在的问题，重大事项可追溯至以前年度。

二、受理举报内容

1、惠民惠农财政补贴资金发放中发现的私自保管代管、违规扣留扣押群众“一卡通”银行卡（存折）的问题。

2、在惠民惠农财政补贴资金申请审核及办卡过程中优亲厚友、吃拿卡要、以权谋私等问题。

3、通过收买欺骗等手段、用无关人员身份证件办理“一卡通”虚报冒领财政惠民惠农补贴资金。

4、利用群众“一卡通”银行卡（存折）截留挪用、“雁过拔毛”骗取套取惠民惠农财政补贴资金。

5、违规办理涉农“一卡通”银行卡（存折）、一户多卡、人卡分离、空挂卡套取、骗取惠农惠民补贴资金的情况。

6、其他违纪违规线索。

三、 受理举报方式

县财政局举报电话：0908-4623075

受理时间：上午10：00-13:30；下午4:30-8:00
