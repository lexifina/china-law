# 乌恰县审计局对棚圈建设项目竣工决算进行审核的通知

恰审结通〔2019〕65号

有 效 性

来 源

乌恰县审计局

乌恰县波斯坦铁列克乡人民政府：

根据《中华人民共和国审计法》第二十二条的规定，我局决定派出审核组，自2019年4月23日起，对你单位组织实施的棚圈建设项目进行竣工决算审核，必要时将追溯到相关年度或延伸审核有关单位。请予以配合，对所提供资料（包括电子资料）的真实性、完整性负责，并进行书面承诺。

审核组组长：马麦提阿孜·麦麦提伊布来音

审核组成员：王山宝（主审）、王新平

廉政监督员：张鹏
