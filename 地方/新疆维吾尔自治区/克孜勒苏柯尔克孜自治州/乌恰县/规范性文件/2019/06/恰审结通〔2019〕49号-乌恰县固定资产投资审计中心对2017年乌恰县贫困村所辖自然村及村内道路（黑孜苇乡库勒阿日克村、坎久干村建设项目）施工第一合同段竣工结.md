# 乌恰县固定资产投资审计中心对2017年乌恰县贫困村所辖自然村及村内道路（黑孜苇乡库勒阿日克村、坎久干村建设项目）施工第一合同段竣工结算进行审核的通知

恰审结通〔2019〕49号

有 效 性

来 源

乌恰县审计局

乌恰县交通运输局：

根据《中华人民共和国审计法》第二十二条的规定，我中心决定派出审核组，自2019年4月10日起，对你单位组织实施的卡拉贝利水利植纽工程移民安置交通设施恢复改建道路项目进行竣工结算审核，必要时将追溯到相关年度或延伸审计有关单位。请予以配合，对所提供资料（包括电子资料）的真实性、完整性负责，并进行书面承诺。

审计组组长：张鹏

审计组成员：王山宝（主审）、王新平

廉政监督员：马麦提阿孜·麦麦提伊布来音
