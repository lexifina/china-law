# 关于持续巩固和加强脱贫攻坚相关工作的通知

各乡扶贫开发领导小组，县扶贫开发领导小组成员单位：

为切实巩固脱贫成果、提升脱贫质量，推进农牧民群众稳定增收，坚决实现与全州全区全国同步进入小康，根据《中共中央、国务院关于打赢脱贫攻坚战三年行动的指导意见》精神以及“摘帽不摘责任、摘帽不摘政策、摘帽不摘帮扶、摘帽不摘监管”的工作要求，为持续巩固和加强脱贫攻坚相关工作，现将有关事宜通知如下：

一、持续稳定扶贫干部队伍

2019年4月自治区人民政府批准我县退出贫困县序列之后，各乡村、各部门重视程度明显松劲，甚至出现撤摊子、歇歇脚的现象，导致一个阶段工作直线下滑，特别是乡、村作为脱贫攻坚主战场，出现扶贫专干调整频繁、专职不专干、信息数据错误不断、项目推进实施缓慢、档案资料严重遗失等一系列问题，严重影响了脱贫攻坚工作，暴露出乡村及县直各部门主要领导对决胜脱贫攻坚战思想认识偏差、工作政治站位不高、责任落实不力等现象，尤其是忽视了扶贫专职队伍在打赢脱贫攻坚战决胜全面建成小康社会的重要作用。

目前距离乌恰县兑现“同步小康”的承诺仅剩531天，国家第三方评估检查组提出的畜牧产业发展、旅游资源挖掘、基础设施建设、口岸经济发展等四个方面问题以及县域产业基础薄弱、政策脱贫占比高、群众内生动力不足等短板亟待有效解决，巩固脱贫成果、提升脱贫质量，实现全面小康任重道远。各乡、县直各单位要深刻汲取前一阶段工作教训，坚决杜绝刀枪入库、马放南山、解甲归田等麻痹松懈思想，切实树立长期作战精神，始终把脱贫攻坚巩固提升工作放在首位，坚决做到靶心不变、队伍不散，坚决保证386名扶贫专干队伍的稳定，除组织调整外，所有扶贫专干、大数据信息管理员不得调整、不得撤换。如因辞职、调离、工作队队员调整等原因必须进行调整的，需向县扶贫开发领导小组办公室报备，并及时补充；要进一步压实扶贫专干工作责任，实行实名制管理模式，明确资金项目、信息数据、小额信贷、档案资料等各项重点工作具体责任人；要保证工作专职专干，所有扶贫专职副书记（副乡长），扶贫专干、大数据信息管理员不得兼职其他工作，不参与值班备勤等扶贫以外工作，要常态化抓好扶贫专干业务培训，不断提升扶贫干部队伍业务素质，着力打造一支脱贫攻坚的专业化、职业化队伍。

二、全面细化工作任务

（一）继续巩固和扩大脱贫攻坚成果。坚持稳定脱贫与巩固提升有机结合，既要加大对未脱贫人口的帮扶力度，又要做好已脱贫人口“防返贫”和新产生贫困人口的帮扶工作，切实做到脱真贫、真脱贫；要从针对贫困的脱贫攻坚举措逐步调整为针对全县农牧民持续稳定增收的日常性帮扶措施，并纳入乡村振兴战略架构下统筹安排；要全面总结脱贫攻坚的典型事迹和特色亮点，坚持和推广脱贫攻坚中的好经验、好做法、好路子。

（二）继续抓好问题整改。全力以赴抓好各级反馈问题整改工作，确保件件有部署、有结果、有落实、有成效，以问题整改倒逼工作水平提升。

（三）继续打造特色支撑产业。充分结合区域特色和优势，深度挖掘传统农牧业、电商、旅游、庭院经济、转移就业、自主创业、边贸经济等产业潜能，培育一批符合本地发展的优势产业，实现“一乡一业、一村一品”。

（四）继续抓好项目建设。坚持资金跟着项目走、项目跟着规划走、规划跟着需求走，在严禁触碰“九条红线”的前提下，支持所有符合“四个有利于”要求的扶贫项目，逐级建立完善规范项目库，统筹力量推动年度项目任务保质按期完成。

（五）继续抓好金融扶贫工作。用足用好扶贫小额信贷政策，坚决做好信贷资金使用的跟踪和服务，切实保证贫困户利用信贷资金发展生产增收；重点做好2016年以来小额信贷资金还贷工作，按照还贷计划，及时督促到期还贷户及时还贷。

（六）继续抓好信息数据管理工作。强化数据管理培训，规范信息录入，切实做到用数据说话、用数据决策、用数据管理、用数据考核，应识尽识、应扶尽扶。

（七）继续抓好档案管理。要全面做好档案资料交接和归档工作，特别是驻村工作队调整期间，要逐项建立脱贫攻坚档案资料交接清单目录，切实保证移交档案资料完整不缺失，前后工作有延续。各乡各村要明确一名档案管理人员，专人专管；要注意收集整理后续脱贫攻坚工作开展过程的各类资料、典型经验、特色亮点、信息图片等资料，及时整理归档，切实使档案工作有连续性。

（八）继续做好抓党建促脱贫。充分发挥第一书记作用，统筹驻村各支力量，合力推动脱贫攻坚。完善驻村工作队带培机制，着力把致富能手培养成党员，推动党员带头致富、带领致富。鼓励和支持农牧民党员创办领办农牧民专业合作社、致富项目等，帮助党员提升创业致富能力。

三、工作要求

（一）进一步提高思想认识。各乡各村，各扶贫开发领导小组成员单位要深刻认识决胜脱贫攻坚战的重大意义，深刻认识全县距离实现小康目标的巨大差距，深刻认识自身在推进脱贫攻坚中的短板与不足，坚持咬定目标不放松，全面践行习近平总书记关于扶贫开发工作的重要论述，将脱贫攻坚工作原来针对建档立卡户转变为现在针对所有农牧民群体，确保如期实现所有人的“小康”，为乡村振兴奠定扎实基础。

（二）进一步转变工作作风。各乡党政主要领导、村第一书记、驻村工作队要坚决把脱贫职责扛在肩上，把脱贫任务抓在手上，拿出“不破楼兰终不还”的决心、“敢教日月换新天”勇气，攻坚克难，乘势前进，认真对照国家、自治区第三方评估检查过程中发现和反馈意见，摸清辖区短板缺项，统筹所有力量推动整改完善提升，切实做到无缺项、无遗漏、无盲区。

（三）进一步营造宣传氛围。坚持正确宣传导向，大力弘扬中华民族扶贫济困、乐善好施的传统美德，引导和鼓励社会各界关注、参与巩固提升脱贫成果事业。加强对农牧民的政策宣传和思想教育，倡导自力更生、艰苦奋斗精神，树立勤劳致富、脱贫光荣的正确导向，坚定农牧民依靠自身巩固提高的信心和决心，不断增强农牧民内生动力和自我发展能力，从思想上、行动上实现脱贫、巩固提升、同步小康。

（四）请各乡于2019年7月22日18:00前将扶贫专干、大数据信息员名单经乡党委书记签字后（含电子版），报县扶贫开发领导小组办公室数据管理组备案。
