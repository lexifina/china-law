# 关于农产品质量安全检验检测中心招聘专业技术人员的请示

恰农字〔2019〕133号

有 效 性

来 源

乌恰县农业农村局

2019年1月31日至2月3日，自治区农业农村厅农产品质量安全监管处“双认证”现场评审考核专家组一行，对我县农产品质量安全检验检测中心进行为期3天的现场评审，虽然“双认证”通过现场评审考核。但评审专家提出：我县检测人员配备方面存在严重短板，缺乏相关专业的技术人才。为加快我县农产品质量安全检验检测中心“双认证”资质认定工作，确保检测中心各项检测顺利开展，严格落实好上级下达的检测任务，切实为我县农产品质量安全提供客观、真实、有效的检测报告，现急需招聘农产品质量安全检测专业技术人员4名。

妥否，请批示。

2019年7月24日

（此件公开发布）
