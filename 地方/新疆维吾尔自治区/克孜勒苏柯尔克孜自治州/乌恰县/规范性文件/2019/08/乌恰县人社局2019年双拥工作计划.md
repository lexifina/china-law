# 乌恰县人社局2019年双拥工作计划

根据县双拥委员会关于2019年双拥工作的要求，我局围绕创建“双拥模范单位”工作的总体要求，加强领导，周密安排，为进一步做好双拥工作，增进军政军民团结，促进军地建设，推动县各项事业科学发展作出新的贡献，经研究，特制定本双拥宣传教育工作计划：

一、指导思想

深入学习贯彻习近平强军思想和军民融合发展理念，加快推进军民融合深度发展，促进军政军民团结和民族团结，坚持双拥“深入人心、深入家庭、深入社区、深入社会”的方向，突出“固我国防、强我边防”重点、抓好“军地共建、融合发展”主题，发扬“天山雪松根连根、乌恰人民心连心”传统，扎实工作，开拓进取，互帮互助，共融共赢，奋力开创乌恰军政军民团结、社会和谐稳定、人民安居乐业的新局面。

二、结合深入学习贯彻党的十九大精神，增强做好双拥工作的使命感和紧迫感

1、紧密联系工作实际，切实加强双拥工作的宣传力度。充分利用墙报、横幅、标语、宣传栏等形式，以“双拥宣传教育月”、“国防教育月”、“征兵宣传月”为契机，大力宣传国防知识，大力宣传双拥光荣传统和加强军民团结的重要性。

2、紧密结合人社系统普法宣传活动，大力宣传《国防法》、《兵役法》、《人民防空法》、《保护军事设施法》等法律法规，以及有关双拥和优抚安置的政策法规，宣传有关拥军优属的各项优质优惠服务措施。

三、努力为部队办实事办好事，不断为加强国防建设和促进军民团结做出新贡献。

1、根据人社局现有条件，积极为部队建设提供优质服务。

2、八一建军节期间，局双拥工作领导小组将组织拥军慰问，深入到部队慰问人民子弟兵，召开军民座谈会，努力为部队办实事，解决实际问题。

3、采取走出去和请进来相结合的做法，开展国防知识、革命传统和拥军知识教育讲座，进一步提高全体人员的拥军意识，促进军民团结。

四、强化工作职责，明确工作责任，不断推进双拥工作的创建活动。

1、加强领导。坚持局主要领导亲自抓双拥工作，亲自指导双拥工作和国防宣传教育，亲自参加双拥重大活动等。

2、强化责任。坚持把双拥工作纳入局重要议事日程，纳入局年度工作规划，扎实开展工作，确保局双拥工作得到顺利实施。

3、注重软件。坚持做好双拥工作资料的收集、整理工作，及时总结工作中好的做法和新的经验，并根据要求，及时上报各种材料。

乌恰县人力资源和社会保障局
