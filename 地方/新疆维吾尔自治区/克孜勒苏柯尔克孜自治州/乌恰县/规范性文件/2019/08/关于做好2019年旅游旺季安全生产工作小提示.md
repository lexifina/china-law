# 关于做好2019年旅游旺季安全生产工作小提示

1.做好自然灾害防范工作。今年以来，全县天气过程复杂，多种自然灾害并生，各景区、旅游企业一是坚持监测预警预防，强化各项应急准备，全力开展抢险救援。二是坚持抓基层打基础，加强防震减灾基础性工作。三是继续抓好森林草原防灭火工作。

2.抓好防汛抗洪工作。密切监视雨情水情汛情险情灾情变化，定期参加气象、地质研判会商，进一步细化实化重大险情处置方案，及时落实各项措施，确保人民群众生命财产安全。

3.严防行业食品安全事故。旅游餐饮单位特别是星级饭店、星级农家乐、旅游民宿要进一步加强食品企业诚信体系建设，落实企业食品质量安全主体责任，建立食品安全自查制度。

4.做好特种旅游安全工作。进入旅游旺季以来，特种旅游项目日益增多，安全风险成倍增长，要切实做好辖区内特种旅游项目安全风险排查管控工作，严格项目审批，加大监管力度，严防安全事故。

5.博物馆、图书馆、文化馆、歌舞团等场所要做好火灾防范工作，结合2019年火灾防控工作要求，配合相关职能部门，全面排查各类火灾隐患，落实安全防范措施，确保不发生各类火灾事故。

6.各类公共文化场所，特别是KTV、网吧、歌舞厅等人员聚集场所要落实安全生产主体责任和隐患闭环管理，深入排查治理消防安全隐患。

7.加强各类大型文化和旅游活动的安全管理，要确保各类文化和旅游活动的安保举措全落实、安全责任全覆盖。

8.结合旅游旺季市场特点，加强对旅游景区、游乐场及公园等场所安全监管，确保游乐设施安全，特别是具有危险性的户外特种旅游项目审批，防范涉旅事故发生。对客流量大的景区要根据承载能力及时采取有效措施进行合理疏导、控制客流，防止拥挤踩踏等事故发生。

9.旅行社要严禁租用无营运资质的旅游车辆，核实车辆车况安全，严防司机疲劳驾驶；及时关注天气及路况，根据天气状况及时调整团队行程，坚决预防涉旅交通事故的发生；强化对出疆出境游客的行前教育，特别是出境旅游团队的境外安全工作。

10.导游领队人员要做好安全提醒提示和预警处突工作，确保出境游客的生命财产安全。

11.各旅游景区（点）、星级饭店要对消防设施设备定期进行检查、维修和保养，尤其是要抓好电梯、压力容器、运输索道、电路电线等危险项目的管理；要加强对电源和火源的管理，确保行业消防安全。

12.加强对本行业从业人员的教育培训，进一步提高从业人员安全生产能力，要组织力量，充分发挥各类媒体作用，采取多种形式，对贯彻落实安全活动进行宣传，要进一步强化对游客的舆论宣传，引导广大游客关注、支持并积极参与旅游安全行动，营造良好的安全氛围。
