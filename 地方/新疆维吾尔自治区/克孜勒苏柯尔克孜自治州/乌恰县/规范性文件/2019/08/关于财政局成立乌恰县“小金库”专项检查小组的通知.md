# 关于财政局成立乌恰县“小金库”专项检查小组的通知

各乡（镇）、县直各部门：

为全面落实自治区党委第一巡视组反馈意见整改要求，进一步严肃财经纪律，从源头上堵塞财务管理漏洞、斩断不良作风的“资金链”，坚决制止和杜绝私设“小金库”等违规问题的发生。乌恰县财政局决定在全县范围内开展“小金库”专项治理工作，经财政局会议研究决定成立乌恰县

“小金库”专项检查治理检查小组。

一、总体要求

坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大、十九届二中、三中全会精神，深入学习贯彻习近平总书记重要讲话精神，认真贯彻中央巡视工作方针，对标巡视巡察发现的问题为重点，查漏洞、抓反弹、补短板，进一步明确责任、加强督查、严肃问责、整肃立规，进一步严肃财经纪律。

二、工作目标

各乡镇、各行业部门要充分认识此次“小金库”专项治理的重要性，认真组织自查自纠，不走过场，自查面达到100%。在单位自查自纠基础上，财政局牵头，相关部门配合，选取部分单位开展重点检查。通过开展专项治理，坚决纠正和查处各种形式的“小金库”，建立和完善长效机制，着力解决好人民群众反映强烈的“小金库”问题，从源头上斩断不良作风的“资金链”。

三、检查小组成员

谢芳芳

（财政局乡财局局长）

沈斌玉

（财政局国库支付中心主任）

郭北娜

（财政局农业科科员）

祖新虹

（财政局监督科科员）

四、工作要求

检查小组通过查看会计凭证、会计账簿，突击盘库，重点检查保险柜及存物柜等形式对私设“小金库”及违反财经纪律的行为实行“零容忍”，严格执纪问责，使财经纪律真正成为带点的“高压线”，对检查中发现的各种违法违规问题，要主动上报并责令问题单位限期整改到位。
