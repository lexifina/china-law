# 乌恰县固定资产投资审计中心对乌恰县巴音库鲁提乡巴音库鲁提村防渗渠建设工程竣工结算进行审核的通知

恰审结通〔2019〕112号

有 效 性

来 源

审计局

乌恰县中小型公益性水利工程建设管理中心：

根据《中华人民共和国审计法》第二十二条的规定，我局决定派出审核组，自2019年9月20日起，对你单位组织实施的乌恰县巴音库鲁提乡巴音库鲁提村防渗渠建设工程进行竣工结算审核，必要时将追溯到相关年度或延伸审核有关单位。请予以配合，对所提供资料（包括电子资料）的真实性、完整性负责，并进行书面承诺。

审核组组长：周有瑾

审核组成员：蒲利伟（主审）、贺文建

廉政监督员：马麦提阿孜·麦麦提伊布来音
