# 关于转发自治州《关于转发〈自治区关于举行2019年度全疆国家工作人员无纸化考试的通知〉的通知》的通知

各乡（镇）、玛依喀克管委会、县直机关、企事业单位、驻县各部门：

现将自治州《关于转发〈自治区关于举行2019年度全疆国家工作人员无纸化考试的通知〉的通知》转发给你们，请各乡（镇）、各单位（部门）按照文件要求，认真开展好此项工作。此次考试是“12·4”国家宪法日系列宣传活动之一，各乡（镇）、各单位（部门）要高度重视，主要领导带头参加答题活动，明确专门人员负责组织答题活动。有条件的单位要设立考场，集中组织本单位人员进行答题。各单位、各部门管理员要切实做好服务、协调工作，及时解决学员在考试过程出现的问题，确保考试顺利进行。县依法治县办将把此次考试工作纳入2019年度普法依法治理工作考核。工作总结（纸制版分管领导签字盖章）于2020年1月11日前报县委全面依法治县委员会办公室（司法局）。
