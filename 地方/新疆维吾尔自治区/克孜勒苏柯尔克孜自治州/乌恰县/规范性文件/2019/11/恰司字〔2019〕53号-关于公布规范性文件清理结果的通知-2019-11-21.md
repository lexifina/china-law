# 关于公布规范性文件清理结果的通知

各乡（镇）人民政府,玛依喀克管委会,县直各部门、各直属机构：

为维护法制统一和政令畅通，深入推进“放管服”改革，确保各项改革措施有效落实，根据《中共中央国务院〈法治政府建设实施纲要（2015－2020年）〉》（中发〔2015〕36号）、《自治区加强行政规范性文件制定和监督管理工作的实施意见》,乌恰县司法局对2017年11月公布继续执行的23件规范性文件（恰政发〔2017〕64号）以及公布之日起至2019年10月31日以乌恰县人民政府、政府办公室新发布的规范性文件进行了全面清理。现将清理结果公布如下：

一、确认关于印发《乌恰县孕产妇系统保健管理办法既实施方案》的通知（恰政发〔2005〕38号）等13件规范性文件继续有效（见附件1）

二、宣布《关于印发《乌恰县农村五保供养工作实施细则》的通知（恰政发〔2005〕39号）等13件规范性文件废止（见附件2）。

上述确认继续有效的规范性文件，有效期与本通知下发前连续计算，上述宣布废止的规范性文件，自本通知下发之日起不再执行。
