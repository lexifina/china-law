# 乌恰县工业园区双语幼儿园等18所幼儿园附属工程（二标）竣工结算进行审核的通知

恰审结通〔2019〕109号

有 效 性

来 源

乌恰县审计局

乌恰县科学技术教育局：

根据《中华人民共和国审计法》第二十二条的规定，我局决定派出审核组，自2019年11月2日起，对你单位组织实施的乌恰县工业园区双语幼儿园等18所幼儿园附属工程（二标）进行竣工结算审核，必要时将追溯到相关年度或延伸审核有关单位。请予以配合，对所提供资料（包括电子资料）的真实性、完整性负责，并进行书面承诺。

审核组组长：周有瑾

审核组成员：李宝军、刘延乐

廉政监督员：张鹏
