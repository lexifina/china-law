# 关于成立乌恰县林业和草原局国土绿化工作领导小组的通知

恰自然资发〔2020〕95号

有 效 性

来 源

自然资源局

局所属各站（所）、各科室:

为推进全县国土绿化工作，确保县域国土绿化持续健康发展，现结合林草系统实际工作情况，成立乌恰县林业和草原局国土绿化工作领导小组，其领导小组成员如下：

组  长：阿曼吐·马坎（自然资源局党组书记）

副组长：刘毅（自然资源局党组成员）

阿吉别克·萨迪尔（林管站站长）

柴春强（草原站党支部书记）

买买吐尔干·铁木尔（草原监理所所长）

成  员：宋永珍（纪检干事）

托合提比比·吐尔干（财务人员）

龚军（项目办负责人）

李茂银（林政资源科科室长）

高吉强（造林科负责人）

努尔汗·阿不力达（林果业、种苗、野生办负责人）

胡明珠（造林科工作人员）

乌恰县林业和草原局国土绿化领导小组办公室设在自然资源局二楼林业办公室。

实行组长负责制，办公室主任由刘毅同志担任，阿吉别克·萨迪尔、柴春强、买买吐尔干·铁木尔负责协助办公室主任，宋永珍负责工程项目全程监查工作，龚军负责施工质量及质量验收，李茂银、高吉强负责国土绿化提升日常事务，托合提比比·吐尔干负责资金管理，努尔汗·阿不力达负责林果业和种苗统计，胡明珠负责档案收集归档。

2020年5月28日
