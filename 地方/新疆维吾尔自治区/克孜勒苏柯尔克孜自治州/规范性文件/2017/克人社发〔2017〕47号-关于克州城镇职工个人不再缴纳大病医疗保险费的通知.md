# 关于克州城镇职工个人不再缴纳大病医疗保险费的通知

克州社会保险管理局,各县(市)人力资源和社会保障局、社会保险管理局及有关单位:

根据《自治区城镇职工大病保险实施方案(试行)》(新人社发〔2016〕154号)文件规定，克州城镇职工大病医疗保险费从城镇职工基本医疗保险基金中按每人每年36元支出，个人不缴费。

本通知自2017年1月1日起执行。

克州人力资源和社会保障局

2017年1月11日

（此件公开发布）
