# 关于印发《克孜勒苏柯尔克孜自治州应急物资储备管理办法》的通知

各县（市）人民政府，自治州人民政府各工作部门、各部门管理机构：

《克孜勒苏柯尔克孜自治州应急物资储备管理办法》已经自治州人民政府同意，现印发你们，请认真贯彻执行。

2017年3月21日

克孜勒苏柯尔克孜自治州应急物资储备管理办法

第一条为切实加强克孜勒苏柯尔克孜自治州（以下简称“自治州”）救灾物资管理，增强预防和处置突发事件的物资保障能力，根据《中华人民共和国突发事件应对法》《新疆维吾尔自治区实施〈中华人民共和国突发事件应对法〉办法》《自治州人民政府突发公共事件总体应急预案》等规定，制定本办法。

第二条本办法所称应急物资，是指为预防和应对自然灾害、事故灾难、公共卫生、社会安全等突发事件所必需的保障性物资和装备,主要分为处置突发事件所需的应急救援物资、生活必需品和应急处置装备三大类。

第三条应急物资储备管理工作，坚持以人为本、突出战备，统筹协调、科学储备，统一领导、分级负责，拓展形式、节约实效的原则。

第四条自治州突发事件应急管理委员会统一领导全州应急物资储备调配工作。负责研究建立全州应急物资储备管理制度，确定应急物资储备工作分工，审核重要物资储备的品种、数量以及经费保障等；加强与邻近地区在应急物资方面的联动协作，根据需要向自治区请求应急物资支援等。

第五条自治州突发事件应急管理委员会办公室（以下简称“自治州应急管理办公室”）负责指导、检查全州应急物资储备工作，重点检查各行业单位的物资储备管理制度建设与物资储备情况、工作机制建立完善情况、数据库和信息化支撑情况等；按自治州突发事件应急管理委员会要求，负责全州应对处置各类突发事件的物资调运工作；配合自治州监察、财政、审计、价监等部门监督检查应急物资储备专项经费使用情况。

第六条自治州突发事件应急管理委员会相关成员单位根据各自职能，分别承担州本级应急物资储备任务，并按照国家、自治区和自治州党委、政府规定，建立本行业系统的应急物资储备制度和管理体系。

（一）州发改委负责指导各相关职能部门做好应急物资储备专项规划及申报审批；负责粮食、食盐、食用植物油等计划管理、应急物资的储备和有关协调工作。

（二）州经信委负责成品油、天然气、煤炭等重要生产要素的协调保障和紧急调度工作；负责协调方便食品、饮用水、帐篷、衣服、被褥等救灾物资的紧急生产；负责应急类医药的申请自治区储备给予紧急调运；负责食盐的计划管理和有关协调工作；负责协调各电信企业和相关单位做好灾区或事发地应急通讯保障等工作；负责煤矿生产安全事故应急处置物资的储备；负责监督指导煤矿企业建立必要的应急物资和设备储备。

（三）州公安局负责交通事故处置、消防救生、反恐、防爆等应急物资储备。州公安消防支队负责以灭火救援任务为主的应急物资储备，负责地震等灾害救援装备物资的储备。

（四）州民政局负责救灾生活必需品等应急物资的储备，指导、监督基层救灾应急措施落实和救灾款物发放。

（五）州国土局负责地质灾害类应急物资的储备。

（六）州环保局负责环境污染事件监测、调查所需应急物资的储备，负责督促指导企业储备相关处置物资。

（七）州住建局负责城市防汛、供水、供暖、供气、排水、大雪、冰冻灾害等应急物资和大型相关机械设备的储备、调用和管理。

（八）州交通局负责应急物资运输、公路抢险除险所需工程机械等应急物资的储备；负责水上安全生产所需的应急物资的储备。

（九）州水利局负责防汛抗旱类应急物资的储备。

（十）州农业局负责农作物重大病虫害防治、农作物种子、化肥等应急物资的储备。

（十一）州林业局负责森林防火、林业有害生物防控、陆生野生动物疫源疫病监测与防控、重大沙尘暴应急监测和防控物资的储备。

（十二）州畜牧局负责重大动物疫病防控应急物资的储备。

（十三）州商务（招商）局负责城市生活必需品政府储备的综合协调及肉类、食盐、蔬菜等“菜篮子”应急物资的储备；负责做好日常基本生活必需品等应急救援物资的协调调度工作。

（十四）州卫计委负责统筹协调各类应急药品、救护设备、疫苗及相关防护物资的日常储备。

（十五）州安监局（州安全生产委员会办公室）负责安全生产事故应急处置所需物资的储备；负责协调和指导各机关、企事业单位及工矿企业建立必要的应急自救物资及设备储备。

（十六）州人防办负责便携式应急防空警报装备的储备；负责处置人防工程事故所需应急物资的储备。

（十七）州地震局负责地震灾害监测预警应急物资的储备。

（十八）州气象局负责灾害性天气监测预警应急物资的储备。

（十九）阿图什供电公司负责电力保障应急物资的储备。

（二十）阿图什火车站负责铁路应急物资的储备。

（二十一）中国石油新疆喀什销售分公司克州经营部负责本行业领域应急物资的储备。

（二十二）州红十字会负责做好部分救灾生活物资储备。国（境）内外红十字会、民间组织、爱心企业、个人捐赠救灾款物的接收、分发；依据自身职能承担的应急工作。

其他有关部门和单位依据自身职能和承担的应急工作任务，储备相应的应急物资，并建立相应的管理制度。

各部门和单位应结合区域和行业易发突发事件特点，合理布局、科学规划物资储备库建设，建立各行业应急物资储备目录、储备数据库和调运信息平台，指导行业科学储备，完善应急物资更新流转机制。

第七条应急物资储备采取政府储备、商业储备、社会储备等形式。

政府储备以实物储备为主，有关部门根据需要，报请同级人民政府审批同意后，采购一定数量的应急物资与装备，进行实物储备。

商业储备采取实物储备与生产能力储备相结合的方式，政府与企业签订协议，企业在储备一定数量实物的同时，保证一定规模的生产能力储备，紧急情况下确保应急物资的生产和供给。社会储备倡导全社会积极捐助、捐赠应急物资，鼓励基层单位、家庭、公民个人根据法律规定和实际条件进行应急物资储备。

第八条应急物资调用按照“先近后远、先主后次、满足急需”的原则进行。通常情况下，各职能部门自行调用本部门或本系统的应急物资；如遇紧急情况或需要调用多个职能部门应急物资，以及需要由自治州人民政府统一处置并动用储备物资时，由自治州应急管理办公室根据自治州突发事件应急管理委员会的要求统一调用。

应急物资使用后应尽快保质保量补充，有保质期限的物资应及时检查更新。

第九条各县（市）人民政府负责同级应急物资的储备。

第十条在应急物资储备严重不足、需要征用社会物资时，经本级突发事件应急管理委员会同意，可实行“先征用、后返还、合理补偿”的办法，向社会征用应急物资。

被征用的物资在使用完毕或突发事件处置工作结束后，应及时返还；物资被征用或征用后毁损、灭失的，应当依法予以补偿。

第十一条按照现行事权、财权划分原则，各级财政分级负担应急物资储备经费，做好具有应急物资储备职能部门储备应急物资经费保障工作。各部门严禁挪用或占用应急物资储备经费。监察、审计等部门按职能分工，负责监督检查经费使用情况。中央、自治区驻州单位的物资储备所需经费，按现行经费来源渠道解决。

第十二条特殊情况下应急物资储备所需经费，可按照特事特办原则，报经同级政府批准后先拨付使用，后补办相关手续。

第十三条应急储备物资应按照政府采购法有关规定组织实施。

（一）根据自然灾害预警判断和救灾物资使用情况，与财政部门确定本级救灾物资采购和储备计划，按照政府采购政策规定，采取公开招标的方式采购救灾物资。

（二）为应对突发重大自然灾害，现有救灾物资储备的数量和品种不能满足应急救助需要时，民政部门可根据上年度本级救灾物资库存情况，结合本级对救灾物资的需求提出物资采购方案（包括采购资金来源、物资品种数量、产品技术参数等），经本级人民政府批准可采取单一来源等方式进行紧急采购。对不宜长期保存的生活类救灾物资，由民政部门会商财政部门确定与有关生产厂家、商铺签订紧急供货协议。

（三）州本级救灾物资的采购由州民政局提出方案，并严格按照政府的有关规定组织实施。

第十四条承担物资储备任务的有关部门和单位，应当对储备物资实行动态电子数据管理，建立相应的动态数据库，每季度末将相关数据填报到自治州应急管理办公室。

第十五条对在应急物资储备工作中做出突出成绩的单位和个人，按照有关规定给予表彰奖励；对工作不力的单位和个人，予以通报批评，情节严重的依法追究责任。

第十六条各县（市）人民政府和承担自治区、自治州应急物资储备任务的相关部门和单位，要根据本办法，结合本地、本部门和单位实际制定相应的应急物资储备制度，并报自治州应急管理办公室备案。

第十七条本办法自发布之日起实施。
