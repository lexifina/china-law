# 关于印发《克州基层干部职工学历提升工程实施方案》的通知

各县（市）人民政府，克州基层干部职工学历提升工程领导小组成员单位：

《克州基层干部职工学历提升工程实施方案》已经克州人民政府和新疆广播电视大学同意，现印发你们，请认真贯彻落实。

克孜勒苏柯尔克孜自治州人民政府 新疆广播电视大学

2017年6月23日

（此件公开发布）

克州基层干部职工学历提升工程实施方案

为认真贯彻落实中央治疆方略，促进克州稳定发展，按照自治区党委副书记、教育工委书记李鹏新同志的指示要求，进一步提升克州基层干部队伍整体学历层次，更好地安心扎根基层，服务基层，经克州人民政府与新疆广播电视大学充分协商，特制定本实施方案。

一、培训目标

紧紧围绕社会稳定和长治久安总目标，认真贯彻落实中央和自治区党委的重大决策部署，努力建设一支政治上强、能力上强、作风上强的高素质基层干部职工队伍，计划利用五年时间实施克州基层干部职工学历提升工程，每年计划招收4000人，累计招生20000人左右，将克州基层干部职工的学历从高中/中专学历提升到大专学历、大专学历提升到本科学历，使克州一线的基层干部职工学历层次上一个新台阶，为实现克州社会稳定和长治久安总目标提供坚强保证。

二、实施时间

暂定为五年（2017年7月至2022年7月期间学生入学）。

三、学习专业

本科专业（17个专业方向）：金融学、会计学、学前教育、小学教育、法学、汉语言（双语）、机械设计制造及其自动化、土木工程、园艺、护理学、公共事业管理（卫生事业管理方向）、公共事业管理（教育管理方向）、英语、行政管理（村镇管理方向）、行政管理、计算机科学与技术、水利水电工程。

专科专业（24个专业方向）：会计、金融学、法学、汉语言（双语）、英语、护理学、文秘、教育管理、农产品加工与品质管理、药学、健康管理、学前教育、小学教育、行政管理、畜牧、畜牧兽医、农村经济管理、园艺技术、园林技术、林业技术、水利水电工程与管理、计算机信息管理、计算机网络技术、建筑施工与管理。

注：以上未列相关医学专业将适时开设。

四、招录对象

克州在岗在编干部职工

五、入学条件和方式

（一）本科（专科起点）：已获得国家承认专科及以上学历，并在中国高等教育学生信息网（学信网）上可查询者。

（二）专科：具有高中（含普通高中、职业高中）、中专、技工学校学历者。

（三）入学方式：凡达到相应层次入学条件，根据相关部门每年下达的招生计划，经本单位政审及批准后即可注册入学。

六、学习方式

学习期间，学生以网上或手机APP自学为主，专业部分核心课程由新疆广播电视大学协同新疆农业大学、新疆医科大学、新疆师范大学、新疆警察学院等高校组成教学团队前往克州广播电视大学及阿合奇教学点、乌恰教学点、阿克陶教学点进行面授辅导，也可通过云教室向学校授课（每学期2-4次）。

七、考试方式

采用形成性考核（平时成绩+考勤+作业）与终结性考核（学期末考试）相结合的方式进行，考核方式根据专业灵活安排。

八、学制和毕业

（一）最低学习年限2.5年（正式入学注册起算）

（二）修满所学专业规则规定最低毕业学分，即可毕业。本科最低毕业学分71学分，专科最低毕业学分76学分。

（三）符合毕业要求，通过毕业审核，由国家开放大学颁发相应层次的毕业证书；本科层次毕业生达到相应专业学位授予条件，学生本人申请，经国家开放大学学位委员会审核通过，可授予相应学士学位。

九、费用

（一）收费标准

1.本科：理工农医类75元/学分（2.5年学费共5235元左右），文史类65元/学分（2.5年学费共4615元左右）；

2.专科：60元/学分（2.5年学费共4560元）；

3.注册建档费：100元/生；

4.考试费：20元/门·次；

5.教材费根据实际教材定价；

6.学费缴纳可一次性支付或按学期上交。

（二）支付方式

本专科学费由学员个人承担，毕业后学员凭发票和毕业证到所在单位审核，财政报销学费的30%，在岗在编干部职工的学费报销部分按照职工隶属关系分级承担，州直干部职工报销部分由州财政承担，县（市）干部职工报销部分由县（市）财政承担。注册建档费、考试费及教材费由学生本人承担。

（二）职责分工

克州党委组织部、克州人力资源和社会保障局：负责“基层干部职工学历提升工程”学员的组织、协调和指导工作。

克州发改委：负责“基层干部职工学历提升工程”学员学费的审定工作。

克州财政局：负责“基层干部职工学历提升工程”学员毕业后凭发票和毕业证报销学费的相关工作。

克州公安局:负责“基层干部职工学历提升工程”学员的政审工作和学员身份核对。

克州教育局：负责“基层干部职工学历提升工程”的组织、协调和指导工作，下发春、秋季招生通知和招生名额分配计划。

新疆广播电视大学：负责远程学历教育双语平台的建设、远程学历教育双语课程资源建设、考试工作的组织协调、学员毕业审核和毕业证书的发放等工作；负责教师团队组建；承担面授辅导教师往来路费、住宿费及课酬津贴等费用。

克孜勒苏广播电视大学及各县教学点：负责学员学籍注册、学籍管理、学生教务管理、教学管理及教学组织等日常工作，负责基层干部职工学历提升工程工作领导小组办公室安排的其他工作。

各县（市）政府：负责各县（市）基层干部职工学历提升工程学员的组织、协调和指导工作。

（三）费用分成及支付方式

1.注册建档费、考试费按国家开放大学现行相关规定执行。

2.学分费：新疆广播电视大学50%（含向国家开放大学缴纳部分），克孜勒苏广播电视大学50%。新疆广播电视大学的50%由克孜勒苏广播电视大学分三次向新疆广播电视大学缴纳。正式入学注册取得学籍收取总费用的30%，第二学年收取30%，第三学年收取40%。

十一、保障措施

（一）每年由克州教育局下发春、秋季招生通知和招生名额分配计划，各县（市）、州直各单位、各部门按计划组织学生报名。

（二）各派出单位必须保证学员的面授时间（面授时间为周六、周日），确保学员在学习期间的待遇不受影响。

十二、其他

（一）新疆广播电视大学投入50万元为克孜勒苏广播电视大学及所属三所县级电视大学建设4间云教室。

（二）新疆广播电视大学负责教师团队组建。

（三）新疆广播电视大学承担面授辅导教师往来路费、住宿费及课酬津贴等费用。
