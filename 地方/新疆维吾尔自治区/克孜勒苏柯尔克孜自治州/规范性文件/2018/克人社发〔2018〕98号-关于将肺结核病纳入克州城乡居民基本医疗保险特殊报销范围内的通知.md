# 关于将肺结核病纳入克州城乡居民基本医疗保险特殊报销范围内的通知

各县（市）人力资源和社会保障局、社会保险管理局、各定点医疗机构：

为进一步做好克州结核病防治工作，有效遏制结核病流行，减轻城乡居民肺结核患者的医疗费用负担，按照《关于改进完善全区新时期医疗卫生有关工作的实施意见》（新政办发〔2018〕62号）文件精神，根据克州结核病疫情与防治工作现状，现将肺结核病纳入克州城乡居民基本医疗保险特殊报销范围内，具体有关事项通知如下：

一、覆盖范围、诊治对象及报销机构

（一）覆盖范围：克州城乡居民基本医疗保险统筹范围；

（二）诊治对象：克州参加城乡居民基本医疗保险中患肺结核参保人员；

（三）门诊报销机构：克州一级以上（含一级）定点医疗机构；

（四）住院报销机构：克州二级以上（含二级）定点医疗机构。

二、诊断标准

（一）肺结核门诊就诊

1.肺结核可疑者指具有结核中毒症状（低热、乏力、盗汗等）或伴呼吸道症状者（咳嗽、咳痰2周以上，或伴咯血），或通过健康体检发现的肺部阴影疑似肺结核者；

2.诊治肺结核的定点医疗机构要严格按照《中华人民共和国卫生行业标准肺结核诊断标准（ws288-2008）》、卫生部《中国结核病防治规划指南》、《肺结核门诊诊疗规范（2012年版）》等一系列诊治规范对可疑肺结核患者做出病例诊断。

（二）肺结核住院治疗

具有以下指征的活动性肺结核患者可考虑住院治疗：

（1）存在较重合并症或并发症者；

（2）出现较重不良反应，需要住院进一步处理者；

（3）需要有创操作（如活检）或手术者；

（4）合并症诊断不明确，需要住院继续诊疗者；

（5）其他情况需要住院者。

三、医疗费用报销标准及结算方式

（一）门诊费用报销标准：根据十二五规划要求结核病初筛及确诊患者门诊免费检查项目纳入医保报销范围，具体项目请各结核病定点医疗机构严格按文件执行，门诊检查费用报销比例为100%。

（二）住院费用报销标准：耐药性肺结核患者在二级以上（含二级）医院每次住院报销比例为90%；耐多药肺结核治疗费用纳入大病统筹。

（三）费用结算：门诊发生的费用和住院费用，由各医疗机构先行垫付，每月报社保机构审核后及时拨付。

（四）住院肺结核报销项目：符合住院指症需住院治疗的肺结核病患者，统一执行自治区《基本医疗保险药品目录》、《基本医疗保险诊疗目录》《基本医疗保险医疗服务设施标准》。

各县（市）按本通知要求，统一思想、提高认识，切实增强责任感、使命感，加强政策宣传，确保决策部署落实到位。

克州人力资源和社会保障局
