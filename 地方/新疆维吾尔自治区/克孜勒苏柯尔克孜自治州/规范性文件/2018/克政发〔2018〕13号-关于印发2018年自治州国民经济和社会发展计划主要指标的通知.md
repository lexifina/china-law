# 关于印发2018年自治州国民经济和社会发展计划主要指标的通知

各县（市）人民政府，自治州人民政府各工作部门、州直各单位：

为贯彻落实自治区人民政府《关于印发2018年自治区国民经济和社会发展计划及主要指标的通知》（新政发﹝2018﹞13号）文件精神，现将自治州2018年国民经济和社会发展计划主要指标印发你们，请据此安排好本县（市）、本部门的工作。

附件：自治州2018年国民经济和社会发展主要指标计划表

2018年4月16日
