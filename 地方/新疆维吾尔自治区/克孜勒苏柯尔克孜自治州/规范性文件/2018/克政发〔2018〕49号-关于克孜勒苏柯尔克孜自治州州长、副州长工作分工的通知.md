# 关于克孜勒苏柯尔克孜自治州州长、副州长工作分工的通知

各县（市）人民政府，自治州人民政府各工作部门、州直各单位：

根据工作需要，经自治州人民政府研究，决定对州长、副州长工作进行分工。

一、州长迪力夏提・柯德尔汗 全面负责自治州人民政府的领导工作，主管审计工作。

二、各副州长协助州长负责有关方面的工作

1.张 强负责自治州人民政府常务工作，协助州长分管审计工作；负责深化改革、财政、税务、金融、国土资源、国有资产经营管理、统计、人力资源和社会保障、政务公开、对口援疆等方面的工作。分管州政府办公室（接待处、法制办、电子政务办）、发展和改革委员会（援疆办、粮食局）、财政局、人力资源和社会保障局、国土资源局（国土资源执法监察支队、测绘局）、统计局、审计局、税务局、机关事务管理局、行政服务中心（公共资源交易中心）、驻乌办事处、驻京联络处。

联系州人大、政协、驻州部队、援疆前方指挥部，联系国家统计局克孜勒苏调查队、驻州金融、保险、证券分支机构，协调兵团方面的工作。

2.李小联 负责华能集团对口援助克州工作，负责水利建设、水能开发等方面工作，分管水利局、河（湖）长办、水管处、水电勘测设计院、科技局、科协。

联系水文局、无线电管理局、邮政管理局、邮政公司、通信公司。

3.王新刚负责工业经济和信息化、工业园区、招商引资和口岸、文化体育广播影视、安全生产、旅游等方面工作。分管经济和信息化委员会、商务局（招商局）、贸促会、吐尔尕特口岸管委会、伊尔克什坦口岸园区管委会、文化体育广播影视局（新闻出版局）、安全生产监督管理局、矿山救护队、旅游局。

联系文联、柯文出版社、地方志办公室、档案局、国网克州供电公司。

4.贺学理负责民政、双拥、老龄、卫生和计划生育、外事、地震、慈善、各类自然灾害救灾救济、应急管理工作。分管民政局（双拥办、老龄办）、卫生和计划生育委员会（计生协会）、疾控中心、人民医院、维吾尔医医院、中心血站、妇幼保健计生服务中心、外事（侨务）办公室、侨联、地震局、残联、红十字会。

联系气象局。

5.刘振福 负责环境保护、住房和城乡建设、道路交通、市场监管、质量技术监督、食品药品、人民防空等方面工作，分管环境保护局、住房和城乡建设局（农村安居工程领导小组办公室）、交通运输局、工商行政管理局、质量技术监督局、食品药品监督管理局、人民防空办公室。

联系公路局、道路运输管理局、路政管理局，协调铁路机场运输等方面的工作。

6.吐逊・肉孜负责民族宗教、语言文字、林业、牧业生产、脱贫攻坚、供销、信访等方面的工作。分管民族宗教事务委员会（民族语言文字委员会）、伊协、林业局、畜牧兽医局、扶贫办、供销社、信访局。

联系工商联、社会主义学院。

7.司亚尔・哈兰负责乌恰县人民政府的工作。

8.麦丽燕・司马义协助抓民政、救灾救济、环境保护、工商行政管理、质量技术监督等方面的工作，负责教育工作。分管教育局（双语办）、教育督导室、电大、职业技术学校。

联系残联、红十字会。

9.季 辉协助抓脱贫攻坚工作，负责农业农村、农牧业机械化等方面工作，分管农业局、农机局、农业技术推广中心。

10.胡朗民 协助抓科技、人防、地震、政府法制等方面的工作。

11.姜 东协助抓工业经济和信息化、商贸流通、招商引资、口岸、工业园区和喀什经济开发区伊尔克什坦口岸园区等方面的工作，分管喀什经济开发区伊尔克什坦口岸园区、驻吉代表处。

联系海关、边检。

12.吴顺恩协助抓脱贫攻坚、国有资产管理、投资公司、金融、保险、证券等方面的工作。

联系总工会、共青团、妇联。

13.梁玉刚 负责公安、司法、国家安全等方面的工作。分管公安局、司法局。

联系国家安全局、克孜勒苏监狱。

2018年10月3日
