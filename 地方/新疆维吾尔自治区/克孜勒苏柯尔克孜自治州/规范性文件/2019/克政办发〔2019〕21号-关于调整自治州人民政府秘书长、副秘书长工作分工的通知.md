# 关于调整自治州人民政府秘书长、副秘书长工作分工的通知

各县（市）人民政府，自治州人民政府各工作部门、州直各单位：

因人事调整和工作需要，自治州人民政府决定对秘书长、副秘书长工作分工进行调整。现将调整后的工作分工通知如下：

秘书长 张海滨

协助州长、常务副州长处理州政府日常事务，负责州政府机关工作和机关党的建设。协助分管副州长处理政务公开（“放管服”改革）、审计、人力资源和社会保障、畜牧兽医、机关事务管理、驻外机构等方面的工作。

协调州政府副秘书长的工作。

副秘书长、信访局局长

迪力夏提•哈力克

协助分管副州长处理公安、司法、国家安全、信访、退役军人事务、应急管理、地震等方面的工作。

副秘书长 秘洁

协助分管副州长处理教育（语言文字）、科技、民政、卫生健康、医疗保障等方面的工作。

副秘书长、自然资源局党组书记

邢金春

协助分管副州长处理自然资源管理、林业和草原、生态环境等方面的工作。

副秘书长 田江

协助分管副州长处理综合经济、工业经济、信息产业、深化改革、道路交通、水利建设、工业园区建设、外事、脱贫攻坚、电力等方面的工作。

副秘书长 热斯别克•阿不都克日木

负责阿图什市吐古买提乡科克塔木村“访惠聚”驻村工作。

副秘书长、文化体育和旅游局党组书记

布帕提曼•买买提依布拉音

协助分管副州长处理文化体育和旅游（文物）、广播影视等方面的工作。

副秘书长、办公室主任

黄健

协助分管副州长处理民族宗教、住房和城乡建设（人民防空）、市场监督管理等方面的工作。

负责州政府办公室工作，联系州党办、人大办、政协办。

副秘书长 李勇

协助分管副州长处理国有资产管理、金融、保险、投资公司、口岸管理、商贸流通、招商引资、农业农村、供销等方面的工作。
