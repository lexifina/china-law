# 关于取消、承接和调整一批行政许可事项的通知

各县（市）人民政府，自治州人民政府各工作部门、州直各单位：

为进一步推动简政放权、放管结合、优化服务改革向纵深发展，根据《中华人民共和国行政许可法》有关规定，结合国务院《关于取消和下放一批行政许可事项的决定》（国发〔2019〕6号）精神，自治州人民政府组织各相关部门对行政许可事项目录进行了彻底清理，决定取消、承接和调整行政许可事项47项。其中取消行政许可事项4项；承接和下放行政许可事项12项；调整行政许可事项31项。

各县（市）、各部门要抓紧做好取消和调整后的行政许可事项的落实和衔接工作，切实增强简政放权的协调性、事中事后监管的有效性、公共服务的便利性，坚决维护公平公正的市场秩序，推动经济高质量发展。

附件：1.取消的行政许可事项目录

2.承接和下放管理层级的行政许可事项目录

3.调整的行政许可事项目录

2019年6月28日

(此件公开发布）

附件1

取消的行政许可事项目录

一、州气象局（1项）

1.在一般气象台站的探测环境保护范围内实施危害气象探测环境的建设工程项目的审核

取消依据：《新建扩建改建建设工程避免危害气象探测环境行政许可管理办法》（中国气象局令第29号）

二、州文化体育和旅游局（2项）

1.为制作出版物、音像制品拍摄馆藏三级文物的审批

取消依据：关于取消中央指定地方实施审批事项的决定 （新政发〔2016〕111号）

2.拍摄市级文物保护单位审批

取消依据：关于取消中央指定地方实施审批事项的决定 （新政发〔2016〕111号）

三、阿图什公路管理局（1项）

1.因抢险、防汛需要修筑堤坝、压缩或拓宽河床进行爆破作业及其它危及国省道、管辖范围内专用公路、公路桥梁、公路隧道、公路渡口安全活动的许可

取消依据：机构改革权限划入交通运输厅

1.权限内农作物种子经营许可证的核发

2.拖拉机驾驶培训学校（培训班）资格核准

（四）司法局（1项）

1.对基层法律服务工作者执业核准

2.建设工程竣工消防验收

三、原州文化体育广播影视局调整至州文化体育和旅游局（2项）

1.举办健身气功活动及设立站点审批

2.旅行社经营许可证审核

四、原州文化体育广播影视局调整至州委宣传部（6项）

1.设立从事包装装潢印刷品和其他印刷品印刷经营活动的企业审批

2.印刷业经营者兼营包装装潢和其他印刷品印刷经营活动审批

3.从事包装装潢印刷品和其他印刷品印刷经营活动的企业变更印刷经营活动审批（不含出版物印刷）

4.印刷业经营者兼并其他印刷业经营者（不含出版物印刷企业）审批

5.印刷业经营者因合并、分立而设立新的印刷业经营者（不含出版物印刷企业）审批

6.设立从事印刷经营活动的企业的审批

五、原州文化体育广播影视局调整至州广播电视局（3项）

1.权限内设立、终止广播电台、电视（含广播电视台、教育电视台）及变更台名、台标、频道、节目设置范围或节目套数的审核

2.设立广播电视节目制作经营机构的审批

3.引进境外电视剧、动画片的许可

六、原州工商局、食品药品监督管理局、质量技术监督局调整至州市场监督管理局（9项）

1.企业核准登记

2.权限内核发药品经营许可证

3.核发医疗器械第三类经营许可证

4.权限内核发麻醉药品、第一类精神药品运输、邮寄证明

5.核发食品生产许可（含变更、换发补发和注销事项）

6.计量器具强制检定

7.申请计量授权核准

8.特种设备作业人员资格许可

9.计量标准考核

七、州住房和城乡建设局（人防办）调整至州自然资源局（2项）

1.权限内城市规划区建设项目选址审批，子项名称：城市、镇、国家级和自治区级各类开发区（园区）总体规划确定的建设用地范围以内城乡规划项目选址意见书的审批

2.权限内建设用地规划许可审批

八、州应急管理局调整至州卫生健康委员会（1项）

1.职业卫生安全许可。子项名称 ：不涉及中央和自治区企业的职业卫生安全许可

1.对传染病病人尸体或者疑似传染病病人的尸体进行解剖查验的审批
