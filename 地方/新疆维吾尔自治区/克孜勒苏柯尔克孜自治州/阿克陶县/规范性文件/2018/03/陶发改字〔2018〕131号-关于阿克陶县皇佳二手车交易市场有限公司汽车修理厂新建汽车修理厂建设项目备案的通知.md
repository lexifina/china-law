# 关于阿克陶县皇佳二手车交易市场有限公司汽车修理厂新建汽车修理厂建设项目备案的通知

陶发改字〔2018〕131号

有 效 性

发文单位

阿克陶县发展和改革委员会

发布机构

发展和改革委员会

阿克陶县皇佳二手车交易市场有限公司汽车修理厂：

你公司《关于阿克陶县县皇佳二手车交易市场有限公司汽车修理厂新建汽车修理厂建设项目立项的请示》收悉。经研究，同意你公司的项目建设计划，现就有关事项通知如下:

一、同意阿克陶县皇佳二手车交易市场有限公司汽车修理厂新建汽车修理厂建设项目备案，并纳入2018年固定资产投资计划。

二、建设规模：建设规模10亩；主要建设内容：1、维修综合服务楼940平方米；2、办公用房250平方米；3、职工宿舍180平方米；4、食堂40平方米；5、仓库等设施860平方米；6、停车棚850平方米；7、辅助设施、进出道路及停车场350平方米。

三、项目建设地点：阿克陶县火车站旁。

四、投资及资金来源：项目总投资为350万元，资金来源为企业自筹。

五、投资人：阿力木·那斯尔

本通知自下发之日起，有效期两年，请抓紧时间办理相关手续，尽早开工建设。

阿克陶县发展和改革委员会

2018年3月27日
