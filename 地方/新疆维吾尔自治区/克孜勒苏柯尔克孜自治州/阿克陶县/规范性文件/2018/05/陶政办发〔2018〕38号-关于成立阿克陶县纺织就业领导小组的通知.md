# 关于成立阿克陶县纺织就业领导小组的通知

各乡（镇、场）人民政府，县人民政府各有关单位：

为贯彻落实自治区党委、人民政府关于促进新疆纺织服装产业健康可持续发展的工作部署，聚焦社会稳定和长治久安总目标，坚决打好脱贫攻坚战，促进我县各族群众就近就地就业，经县人民政府研究，决定成立阿克陶县纺织就业领导小组，组成人员如下：

领导小组下设办公室，办公室设在县商经委，办公室主任由刘爱同志兼任。办公室成员从各相关单位抽调。

领导小组主要职责：

（一）负责落实自治区、自治州安排的纺织服装就业工作的总体目标和阶段性目标任务，确定阿克陶县纺织服装就业工作的总体目标和阶段性目标任务，研究重大问题、部署重点工作、协调推进纺织服装发展的总体布局。

（二）负责审定《阿克陶县纺织服装就业工作年度行动方案》，纺织服装产业发展的重要文件和各部门提交的政策措施，各部门提出的项目安排建议和资金分配方案。

（三）负责督查指导各相关部门落实国家和自治区、自治州产业扶持政策。

（四）负责承担自治州党委、人民政府交办的其他事项。

领导小组办公室主要职责：

（一）按照阿克陶县纺织服装就业工作领导小组的部署，协调纺织服装产业发展中的重大问题，研究相关部门提出的政策建议和资金分配方案，提交领导小组审议。

（二）负责组织编制《阿克陶县纺织服装就业工作年度行动方案》，提交领导小组审定，与各相关部门标签订目标责任书。

（三）负责组织起草向自治州有关部门汇报纺织服装产业发展情况的报告和国家对新疆产业发展政策调整建议，提交领导小组审议。

（四）按照领导小组的工作安排，组织对年度行动方案确定的工作任务开展督查考核。

（五）负责承担阿克陶县纺织服装就业工作领导小组交办的其他事项。
