# 关于做好政府门户网站集约化建设和政务公开工作的通知

县直各有关单位、各直属机构：

根据《中共中央办公厅、国务院办公厅印发〈关于全面推进政务公开工作的意见〉的通知》（中办发〔2016〕8号）和《国务院办公厅关于加强政府网站信息内容建设的意见》（国办发〔2014〕57号）文件要求，为进一步加强我县政府网站管理和政务公开工作，扎实推进“互联网+政务服务”和政府门户网站集约化建设工作，提升政府网站权威发布、解读政策、热点回应、引导舆论的能力和水平，建设整体联动、高效惠民的网上政府，现就做好政府网站集约化建设和政务公开工作相关事宜通知如下：

一、各部门（单位）主要领导要亲自抓政务公开工作，分管领导负责协调督促，常抓不懈，并按照本单位工作量（见附件1）明确1-2名具有一定文字功底和计算机能力的干部从事政务公开工作，及时收集、整理、发布公开内容，如有人员变动，请及时进行交接，并报县人民政府电子政务办备案。

二、各部门（单位）要建立健全公开属性确认制度和“谁制作、谁发布、谁负责”的保障机制，实行分级管理，严格把关，严防涉密信息上网。

三、各部门（单位）要做好网站改版前期工作，梳理栏目设置及页面设计。要严格按照《阿克陶县人民政府门户网站栏目责任分解表》（见附件1）内容，将本单位栏目内容纸质版和电子版整理归类，以保障栏目适时更新发布。

四、县人民政府办公室信息督查室、电子政务办将对栏目更新情况进行日常监测和月度抽查，对未按要求及时更新栏目内容的部门（单位）予以全县通报；对违反政务公开有关规定、不履行公开义务或公开不应当公开事项，并造成严重影响的，将追究部门（单位）主要领导责任。同时，将各部门（单位）信息公开栏目更新情况纳入年终绩效考评。

请各部门（单位）于5月11日前将负责政务公开工作分管领导、工作人员花名册（见附件2），于5月20日前将本单位栏目内容整理收集情况（见附件1）纸质版加盖公章（含电子版）报送县人民政府电子政务办公室。
