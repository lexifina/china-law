# 关于成立阿克陶县国家级电子商务进农村综合示范项目工作领导小组的通知

各乡（镇、场）人民政府，县直各有关单位：

2017年，阿克陶被国家财政部、商务部、国务院扶贫办确定为2017－2018年度国家级电子商务进农村综合示范县。为进一步加强对电子商务进农村综合示范工作的组织领导，建立健全统筹协调工作机制，深入推进电子商务进农村工作，经县人民政府研究，决定成立阿克陶县国家级电子商务进农村综合示范项目工作领导小组，具体如下：

二、各成员单位工作职责

县人民政府办公室：加强政府网电商专栏建设，统筹协调电子商务进农村各项工作的落实。

县商经委：负责组织电子商务进农村综合示范县各项工作，整合完善县域商贸流通、仓储物流、商业网点、售后服务等资源，负责示范县工作方案的制定与落实。

县委宣传部：总结推广经验，加大典型示范宣传力度，营造电商氛围。

县委组织部（访惠聚办公室）：负责整合各村贫困户农副产品资源，协调各村电商扶贫工作。

县统计局、审计局：负责县域电商工作各项数据统计工作（网络销售额、网络购买额、电子商务交易额）、县域所有电子商务企业营收数据统计和电商服务业渗透情况调查及跟踪。

县团委、县妇联、县残联：负责推荐电商优秀创业者及残疾人创业青年。

县发改委（旅游局）：将电子商务项目列入年度计划，并支持项目建设；负责全县的旅游产品电子商务的推广培训工作，结合全域旅游做好“互联网+特色旅游”的电子商务应用工作，并做好旅游产品提供企业的质量监管工作；搭建旅游企业综合服务微信平台。

县财政局：建立完善的资金与项目管理制度，做好项目资金拨付工作，加强动态监管，确保资金使用安全与规范；负责电商公共服务中心及各乡（镇）、村电商服务站点金融业务接入。

县人社局：负责建设县级电子商务人才中心，组织申报自治区级、自治州级电子商务人才培养基地；组织开展电子商务人才培训工作。

县文广局：负责整合宣传资源对电子商务工作宣传推广。

县扶贫办：协助实施电子商务进农村综合示范项目，完善各乡（镇）、村做好电商服务站点建设工作。将电商扶贫纳入脱贫攻坚总体部署和工作体系，做好电商扶贫工作。

县市场监督管理局、国税局、地税局：负责协助办理项目开展所需各项资质，监管项目运营的各环节，建立电子商务市场秩序监管机制和电子商务信用评价制度，每月出具制度应用材料。

县农业局、林业局、畜牧兽医局：负责提供全县初级农、牧产品相关资料，组织农、牧产品收购及电商销售，参与构建阿克陶县农产品第三方线上交易平台。

县民政局：负责做好电子商务协会筹建前期准备工作，提供成立电商协会所需的各项支持和协会运作的后期服务。

县交通运输局、邮政公司：利用各自优势，进行资源整合，积极推进仓储中心、分销平台、物流快递、基层网点的建设工作；保障县、乡、村三级物流体系及冷链体系正常运行。

县科技局：负责做好技术交流，创办本地创业大赛，申报创业项目、申请专项资金等工作。

县水利局、供电公司：负责各乡（镇）、村电商服务站点水利及供电业务接入。

县网信办：负责县域电子商务公共平台日常信息管理。

县江西工业园区管委会：负责提供电商公共服务中心、物流配送中心、冷链仓储中心场地，并加强对园区电子商务企业的管理。

县供销社：负责做好规范和推进相关重点品类农业专业合作社建设，协调全县农民专业合作组织开展网络营销，推进农村基层供销网点进行电子商务服务转型升级。

各乡（镇）、村：负责辖区内服务站点建设、宣传及推广，支持农村电商服务站点网络服务平台建设，推进农村流通设施及商务服务信息联网等项目的实施，建立开展“电商创业典型”推动工作，积极配合合作企业做好电商进农村工作。
