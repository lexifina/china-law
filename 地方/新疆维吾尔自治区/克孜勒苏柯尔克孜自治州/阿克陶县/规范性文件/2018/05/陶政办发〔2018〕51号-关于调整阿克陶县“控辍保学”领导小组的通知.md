# 关于调整阿克陶县“控辍保学”领导小组的通知

各乡（镇、场）人民政府、社区管委会，县直各有关单位：

因人事变动及工作目标调整（县政府所在地，小学在校生辍学率控制在0.4%以下，初中在校生辍学率控制在0.8%以下；农牧区所在地，小学在校生年辍学率控制在0.5%以下，初中在校生辍学率控制在1%以下。县政府所在地，小学适龄儿童、初中适龄少年入学率均达100%；农村小学入学率达100%以上，初中适龄少年入学率达99%以上。牧区小学、初中入学率均达99%以上。视力、听力、智力三类残疾适龄儿童、少年义务教育阶段入学率分别达到90%以上，且逐年有所提高），经县人民政府研究，决定对阿克陶县“控辍保学”工作领导小组进行调整，调整后组成人员如下：
