# 关于保留和废止规范性文件的通知

各乡（镇、场）人民政府，县直各有关单位、各直属机构：

为维护法制统一和政令畅通，深入推进“放管服”改革，确保各项改革措施有效落实，根据《中共中央 国务院<法治政府建设实施纲要（2015—2020年）>》（中发〔2015〕36号）、自治区人民政府办公厅《关于开展政府文件全面清理工作的通知》（新政办发〔2016〕50号）要求，县人民政府法制办对1954年至2016年期间由县人民政府（含革委会）、政府办公室发布的规范性文件进行了全面清理。现将县本级予以保留继续有效的62件、废止的19件规范性文件予以公布。
