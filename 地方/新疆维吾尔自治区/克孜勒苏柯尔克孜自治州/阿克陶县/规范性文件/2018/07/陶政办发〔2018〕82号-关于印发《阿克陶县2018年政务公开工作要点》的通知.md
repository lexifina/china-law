# 关于印发《阿克陶县2018年政务公开工作要点》的通知

各乡（镇、场）人民政府，县直各有关单位、各直属机构：

《阿克陶县2018年政务公开工作要点》已经由县人民政府研究同意，现印发给你们，请结合实际，认真贯彻落实。

阿克陶县人民政府办公室

2018年7月30日

（此件公开发布）

阿克陶县2018年政务公开工作要点

为贯彻落实习近平新时代中国特色社会主义思想和党的十九大、十九届二中、三中全会精神，贯彻落实习近平总书记关于新疆工作的重要讲话和重要指示精神，贯彻落实以习近平同志为核心的党中央治疆方略，特别是社会稳定和长治久安总目标，贯彻落实党中央、国务院关于全面推进政务公开工作的系列部署，坚持统筹兼顾、突出重点，大力推进决策、执行、管理、服务、结果公开，不断提升政务公开的质量和实效，推动转变政府职能、深化简政放权、创新监管方式，促进经济社会持续健康发展，助力建设人民满意的服务型政府。根据《关于印发〈新疆维吾尔自治区2018年政务公开工作要点〉的通知》（新政办发〔2018〕58号）精神，结合实际，制定阿克陶县2018年政务公开工作要点。

一、着力加强公开解读回应工作

把公开透明作为政府工作的基本要求，坚持以公开为常态、不公开为例外，政府全体会议和常务会议讨论决定的事项、政府及其部门制定的政策，除依法需要保密的外应及时公开，以公开促进依法行政和政策落地见效，充分保障人民群众的知情权。

（一）围绕建设法治政府全面推进政务公开

1.制定出台涉及公共利益、公众权益的政策文件，要对公开相关信息作出明确规定，使政策执行更加阳光透明。（县人民政府办公室牵头，各乡（镇、场）人民政府，县直各有关单位落实）

2.结合政府机构改革和职能优化，做好政府部门权责清单调整和公开工作，强化对行政权力的制约和监督，推动政府部门依法全面规范履职。（县人民政府办公室牵头，各乡（镇、场）人民政府，县直各有关单位落实）

3.进一步推进人大代表建议和政协委员提案办理结果公开，对社会广泛关注、关系国计民生的建议和提案，承办单位原则上要公开答复全文。（县人民政府办公室牵头，各乡（镇、场）人民政府，县直各有关单位落实）

4.建立市场准入负面清单信息公开机制。（各乡（镇、场）人民政府，县直各有关单位）

5.全面实施“双随机、一公开”监管，多渠道全方位及时公开综合监管和检查执法信息，提高监管效能和公正性，增强监管威慑力和公信力。（各乡（镇、场）人民政府，县直各有关单位）

（二）围绕重点领域加大主动公开力度

6.抓好重大建设项目批准和实施、公共资源配置、社会公益事业建设等领域政府信息公开制度的贯彻落实。（各乡（镇、场）人民政府，县国土资源局、县商经委、县发改委、县人社局、县教育局、县民政局等涉及三大重点领域的相关部门）

7.各乡（镇、场）人民政府及县直各有关部门要把重点领域信息公开纳入主动公开基本目录。在政府信息公开工作年度报告中公布重点领域信息公开情况，接受社会监督。（各乡（镇、场）人民政府，县国土局、县商经委、县发改委、县人社局、县教育局、县民政局等涉及三大重点领域的相关部门）

8.推动各乡（镇、场）人民政府及县直各有关单位全面公开财政预决算信息。（县财政局牵头，各乡（镇、场）人民政府及县直各有关单位落实）

9.规范公开地方政府债务信息。（县财政局、县审计局，各乡（镇、场）人民政府，各有关单位）

10.结合实际选取本地区本行业社会关注度高的重大建设项目，重点做好中标结果公示、合同订立及履行情况、征收土地方案、征地补偿安置方案等信息的公开工作。（各乡（镇、场）人民政府，县公共资源交易中心、县发改委、县委编办、县国土资源局、县住建局、县环保局、县交通局、县水利局等有关单位）

11.依法做好公共资源交易公告、资格审查结果、交易过程信息、成交信息、履约信息以及有关变更信息的公开工作。（各乡（镇、场）人民政府，县公共资源交易中心，县直各有关单位）

12.借助自治区、克州公共资源交易平台实现公共资源交易数据共享平台体系，加快实现公共资源配置全流程透明化。（县公共资源交易中心、县发改委、县财政局、县住建局、县国土资源局、县国资局、县商经委、县交通运输局、县水利局、县环保局、县行政服务中心等有关单位）

13.进一步推进精准扶贫精准脱贫、社会救助托底保障、食品安全、重大环境事件等信息公开，充分运用政府网站等技术手段实现公开的信息可检索、可核查、可利用。（各乡（镇、场）人民政府，县扶贫办、县民政局、县市场监督管理局、县环保局等有关单位）
