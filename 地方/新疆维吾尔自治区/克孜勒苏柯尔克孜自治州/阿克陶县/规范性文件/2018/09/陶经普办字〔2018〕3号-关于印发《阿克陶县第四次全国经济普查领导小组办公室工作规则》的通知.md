# 关于印发《阿克陶县第四次全国经济普查领导小组办公室工作规则》的通知

各经济普查办公室，阿克陶县第四次全国经济普查领导小组组成部门及各工作组：

现将《阿克陶县第四次全国经济普查领导小组办公室工作规则》印发给你们,请结合本部门的实际情况认真贯彻执行。
