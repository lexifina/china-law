# 关于制定县青少年校外活动中心收费标准的批复

县青少年活动中心：

为支持教育事业健康发展，根据县青少年校外活动中心提交《关于申请调整青少年校外活动中心收费标准的报告》，申请新增培训收费项目，较大范围的拓宽了培训类别，依据《政府定价成本监审办法》、自治区发改委（新财综字〔2000〕131）号、（新计价费〔2004〕1529号）文件，经我委研究批复如下：

经审核，县青少年校外活动中心属于县教育局下属公立培训机构，其固定资产、专用培训设备等由中央公益性彩票基金免费资助，主要支出有水、电、暖、材料费、修理费，在教职工多数属于财政供给兼职教师，社会聘用教师较少，总体成本支出较低。

考虑到该校属于公立性质培训机构，且建校初衷是注重社会效益，不以盈利为目的。经我委对市场调查后综合研究，按照保本微利的原则制定收费标准，具体收费标准见附件。2019年以前下发有关收费标准一律作废。
