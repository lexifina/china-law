# 关于推进政务新媒体健康有序发展的通知

各乡（镇、场）人民政府，县人民政府各有关单位、各直属机构：

为推进政务新媒体健康有序发展，提升政府网上履职能力，努力建设人民满意的“指尖上的网上政府”。近期，自治区人民政府办公厅、自治州人民政府办公室先后转发了《国务院办公厅关于推进政务新媒体健康有序发展的意见》的通知，现转发给你们，请认真组织学习并结合以下要求做好贯彻落实。

一、加强组织领导，明确管理责任。要充分认识在移动互联网环境下做好政务新媒体工作的重要意义，将此项工作纳入重要议事日程，加强领导，明确责任。县人民政府办公室为政务新媒体工作的主管单位，各部门(单位)办公室或指定相关科室主管本部门（含二级局）本系统的政务新媒体工作。主管单位负责推进、指导、协调、监督政务新媒体工作。行业主管部门要加强对本行业承担公共服务职能的企事业单位新媒体工作的指导和监督。按照“谁开设、谁主办”的原则确定政务新媒体主办单位，履行政务新媒体的规划建设、组织保障、健康发展、安全管理等职责。

二、加快清理整合，落实监管责任。要严格按照集约节约的原则统筹移动客户端等应用系统建设，对功能相近、用户关注度和利用率低的政务新媒体尽快清理整合或关停。严格规范开设政务新媒体，严把内容发布审核关，严格落实安全管理责任，建立健全“三审三校”信息公开制度和应急预案。强化第三方平台保障能力，持续改进服务，为政务新媒体工作开展提供便利。各部门(单位)政务新媒体按照主管主办和属地管理原则，接受宣传、网信部门有关业务统筹指导和宏观管理。

三、加强考核评价，严格追责问责。各部门(单位)要将政务新媒体工作列入年度绩效考核，制定考核评价办法，建立健全责任追究制度，对违反规定发布转载不良或有害信息、破坏网络传播秩序、损害公众权益的，要严肃追究相关部门和人员责任。人民政府办公室将适时对有关工作落实情况进行督促检查和考核评价。

请各乡（镇、场）人民政府、政府各部门（单位）于2019年2月26日前，将政务新媒体清理整合和规范管理情况，以及分管领导、主管单位及负责人名单（包括姓名、性别、单位、职务、联系方式）形成文字材料。经主要领导审核签字加盖公章后与电子版一并报送至阿克陶县人民政府电子政务办公室。
