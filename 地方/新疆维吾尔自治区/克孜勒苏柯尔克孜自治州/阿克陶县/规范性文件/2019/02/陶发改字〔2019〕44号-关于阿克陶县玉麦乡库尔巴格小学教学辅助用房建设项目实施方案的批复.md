# 关于阿克陶县玉麦乡库尔巴格小学教学辅助用房建设项目实施方案的批复

阿克陶县教育局：

你局《关于申请审批阿克陶县玉麦乡库尔巴格小学教学辅助用房建设项目实施方案的报告》及实施方案已收悉。经我委研究后批复如下：

一、同意建设阿克陶县玉麦乡库尔巴格小学教学辅助用房建设项目所有建设内容。

二、项目建设规模及内容：新建教学及辅助用房，建筑面积1400平方米，及配套附属工程。

三、工程总投资及资金来源：项目总投资310万元，资金来源为教育扶贫资金。

四、项目建设地点和建设年限：阿克陶县玉麦乡库尔巴格小学院内，建设期为2019年3月至2019年7月。

五、项目法人：阿克陶县教育局。

六、请严格按照招投标法的有关规定，委托具有相应资质的招标代理机构组织开展工程招标工作。

七、请你局严格按照基本建设项目和财务管理制度的各项规定，加强项目组织、管理，督促建设单位尽快落实项目，不得随意调整项目建设地点、规模和内容。对项目资金设立专门账户，专款专用，严禁截留、转移、侵占、挪用和超投资建设。认真落实项目公示制、法人责任制、招投标制、监理制和合同制。做好项目档案管理工作，确保项目建设顺利进行。

阿克陶县发展和改革委员会

2019年2月21日
