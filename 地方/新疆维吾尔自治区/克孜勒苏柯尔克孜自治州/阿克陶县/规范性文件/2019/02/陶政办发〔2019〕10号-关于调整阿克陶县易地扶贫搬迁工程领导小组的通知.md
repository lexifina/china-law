# 关于调整阿克陶县易地扶贫搬迁工程领导小组的通知

各乡（镇、场）人民政府，县人民政府各部门、各直属单位：

根据人事变动和工作需要，县委办公室于2019年1月17日印发了《关于调整阿克陶县深度贫困地区脱贫攻坚工作领导小组的通知》（陶党室字〔2019〕4号）文件，根据文件内容和县领导指示，对照自治区、自治州易地扶贫搬迁工作职责分工，结合各相关单位职责，县人民政府决定调整阿克陶县易地扶贫搬迁工作领导小组，调整后的组成人员如下：

二、主要职责

（一）领导小组职责：对全县易地扶贫搬迁工作负总责。统筹推进易地扶贫搬迁各项工作，制定符合实际的工作方案及计划、建设任务、下达资金计划等工作。定期组织召开专题会议，协调解决易地扶贫搬迁工作重大问题，深入指导推进易地扶贫搬迁工作。严守政策红线，聚焦关键环节，确保政策执行到位。组织开展督查检查工作，对各级督查稽查中发现的问题，督促各成员单位、各乡镇认真进行整改、举一反三，确保问题见底清零。强化执纪问责力度，对屡教不改的部门、乡镇负责人，根据问题的严重程度，将问题线索提交同级纪委监委予以查处。

（二）领导小组办公室职责：负责协调推进领导小组日常工作，加强同成员单位的联系沟通，掌握全县易地扶贫搬迁进展情况，及时做好上情下达、下情上报工作，并负责撰写领导小组会议纪要、汇报材料等日常工作。

（三）成员单位职责

县发改委：负责积极争取易地扶贫搬迁专项中央补助资金，编制上报易地扶贫搬迁规划和年度计划；研究制定支持易地扶贫搬迁工程的有关政策措施；会同县住建局抓好年度易地扶贫搬迁项目申报和实施方案审批工作；会同相关部门抓好易地扶贫搬迁安置点配套项目的协调、资金整合工作；会同县扶贫办强化搬迁群众后续脱贫措施，统筹农业、畜牧、人社等部门加大产业扶持、转移就业、生态扶贫力度，指导水利、交通、电力部门做好基础设施配套建设。

县扶贫办：负责全县易地扶贫搬迁工作的统筹调度，协调解决易地扶贫搬迁工作中遇到的相关困难，准确核定建档立卡贫困人口中易地扶贫搬迁脱贫人口数量，提供全县易地扶贫搬迁贫困户清单，建立工作台账，严格审核程序，加强培训指导和政策宣传；指导督促相关乡镇有序推进易地扶贫搬迁和安置工作，并按相关政策指导各乡镇搬迁户后续产业发展及落实相关扶持政策，按规定、分年度、有计划地组织实施，确保搬得出、稳得住、能脱贫，从根本上解决生计问题。

县住建局：负责组织实施易地扶贫搬迁安置房建设和安置点供水、排水、供电、供热等基础设施配套及公共服务设施工程建设项目，做好前期规划、勘察设计以及招投标手续，坚持项目法人制、招投标制、合同管理制，严格按照项目建设程序进行建设，抓好项目管理，加强质量和安全监督，确保工程质量按时竣工。

县教育局：负责做好易地扶贫搬迁人口适龄子女入学等后续教育保障工作，优先支持迁入地教育基础设施建设，完善搬迁安置区学前教育、义务教育等学校布局，全面落实教育资助政策，确保搬迁子女应助尽助。

县公安局：负责督促、协调各乡镇做好易地扶贫搬迁对象户籍迁移落实工作。

县财政局：负责资金组织及中央预算内投资资金支付，加快资金支付速度；负责易地扶贫搬迁专项资金管理；负责加强项目资金监管，实行公告公示制度，主动接受社会各界和搬迁群众监督。

县人社局：负责易地扶贫搬迁群众职业技能培训、就业创业指导、劳务输出等后续帮扶力度；负责做好搬迁人员社会保险关系转移接续，及时将搬迁人员纳入安置区社会保障覆盖范围。

县国土资源局：负责保障易地扶贫搬迁工程项目建设用地计划，将搬迁对象宅基地复垦列入城乡建设用地“增减挂钩”范围，搞好旧宅基地、旧村庄复垦和城乡建设用地“增减挂钩”。

县环保局：做好搬迁户原居住点生态环境恢复工作，科学划定禁养区、限养区和适养区。

县交通运输局：负责落实、指导、协调推进易地扶贫搬迁安置区道路基础设施配套建设，用好道路扶贫资金。

县水利局：负责落实、指导、协调推进易地扶贫搬迁安置区人畜安全饮水工程，优先安排易地扶贫搬迁安置区水利项目。

县农业局：负责指导相关乡镇开展易地扶贫搬迁迁出区土地流转工作；落实好农业产业扶贫，积极引导发展特色农业，着力夯实安置区后续产业发展基础。

县林业局：负责指导相关乡镇做好迁出区域造林绿化工作；负责易地扶贫搬迁项目永久占用林地审核上报工作，并积极吸纳符合条件的贫困劳动力作为生态管理员，解决部分困难群众就业难题；做好搬迁对象种植业相关后续产业发展落实、服务工作。

县畜牧兽医局：负责指导相关乡镇做好搬迁区轮畜、休畜和禁牧工作；做好搬迁群众草场流转、联户并畜、牲畜转移及检疫工作；做好搬迁对象养殖业相关后续产业发展落实、服务工作。

县文广局：负责对易地扶贫搬迁目的、意义、政策和做法进行多渠道、多形式的宣传，消除搬迁群众的思想顾虑，使党中央、自治区党委和州党委易地搬迁优惠政策家喻户晓；负责易地扶贫搬迁安置区文化室、广播电视信号覆盖等配套基础设施建设。

县卫生局：全面改善安置区医疗卫生基础设施条件，负责安置区卫生室建设，提高医疗卫生服务能力；负责指导相关乡镇做好搬迁人口基本公共卫生服务，加强卫生健康知识宣传教育和普及工作，引导群众养成良好的生活习惯。

人民银行阿克陶县支行：负责督促、指导、协调相关金融机构做好安置区金融服务相关工作。

农业发展银行阿克陶县支行：负责配合相关部门做好安置区金融服务相关工作。

国网阿克陶县供电公司：负责协调推进易地扶贫搬迁安置区电网配套基础设施建设。

相关乡人民政府：贯彻执行易地扶贫搬迁的有关政策，做好政策宣传，及时解决搬迁群众反映的困难和问题；负责组织按规定的程序实施旧房拆除复垦，做好与搬迁户签订搬迁安置旧房拆除协议，并建立旧房拆除台账。
