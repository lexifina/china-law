# 关于阿克陶县木吉乡电力入户项目初步设计的批复

阿克陶县木吉乡人民政府：

你乡《关于对阿克陶县木吉乡电力入户项目初步设计的请示》及山东省环能设计院股份有限公司新疆分公司编制的《阿克陶县木吉乡电力入户项目初步设计》收悉。经研究，现批复如下:

一、工程建设规模：木吉村火山口新建35千伏线路2.7公里，安装一台容量400千伏安35千伏/0.4千伏变压器，新建低压线路0.48公里，新装户表23户，投资139.81万元；琼让村新建低压线路1.37公里，投资25.34万元；牧场新建低压线路0.97公里，新装户表68户，投资25.6万元。

二、工程总概算：项目估算总投资190.75万元。资金来源为涉农整合资金。

三、工程设计、施工必须满足国家和自治区有关节能、环保的要求。

四、项目负责人：[姓名略]·艾依提巴依。

项目实施中要严格执行项目法人责任制、招投标制、工程监理制等制度，你局要加强项目管理，抓紧做好各项施工前准备工作，确保项目尽早开工建设。
