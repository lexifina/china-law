# 关于阿克陶县克孜勒陶乡电力入户项目初步设计的批复

阿克陶县克孜勒陶乡人民政府：

你乡《关于对阿克陶县克孜勒陶乡电力入户项目初步设计的请示》及山东省环能设计院股份有限公司新疆分公司编制的《阿克陶县克孜勒陶乡电力入户项目初步设计》收悉。经研究，现批复如下:

一、工程建设规模：乌尔都隆窝孜村3小队定居房生活用电新建低压线路0.2公里，安装户表19户，投资6.546万元；建设从克孜勒陶乡至托云都克村到克孜勒陶乡10千伏线路14.96公里，投资301.34万元；塔木柏孜定居点安装1台容量160千伏安35千伏/0.4千伏变压器，新建低压线路0.27公里，新装户表238户，投资70.477万元。

二、工程总概算：项目估算总投资378.36万元。资金来源为涉农整合资金。

三、工程设计、施工必须满足国家和自治区有关节能、环保的要求。

四、项目负责人：[姓名略]·伊萨克。

项目实施中要严格执行项目法人责任制、招投标制、工程监理制等制度，你局要加强项目管理，抓紧做好各项施工前准备工作，确保项目尽早开工建设。
