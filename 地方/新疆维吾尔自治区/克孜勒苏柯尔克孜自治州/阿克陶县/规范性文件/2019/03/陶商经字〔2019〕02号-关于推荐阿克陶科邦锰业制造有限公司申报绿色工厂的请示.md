# 关于推荐阿克陶科邦锰业制造有限公司申报绿色工厂的请示

陶商经字〔2019〕02号

有 效 性

发文单位

阿克陶县商务科技和工业信息化局

发布机构

阿克陶县商务科技和工业信息化局

克州工信局:

根据《新疆维吾尔自治区工业和信息化厅关于推荐第三批绿色制造名单的通知》（新工信环资〔2018〕1号）要求，依据程序，经企业自评及自主申报，经我委初核，阿克陶科邦锰业制造有限公司符合绿色工厂推荐条件，现报克州工信厅给与复审和推荐。

妥否，请批示

阿克陶县商务科技和工业信息化局

2019年2月27日
