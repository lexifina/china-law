# 关于阿克陶县供水改扩建二期工程初步设计的批复

阿克陶县住房和城乡建设局：

你局《关于对阿克陶县供水改扩建二期工程初步设计的请示》及新疆四方建筑设计院有限公司编制的《阿克陶县供水改扩建二期工程初步设计》收悉。经研究，现批复如下:

一、工程建设规模： 1、新建阿克陶县毛达湾水厂清水池（8000m³）一座； 2、新建阿克陶县毛达湾水厂至阿克陶镇，给水玻璃纤维增强塑料加砂管DN800管，管长4353m，玻璃纤维增强塑料加砂管DN500管，管长1261m；。

二、工程总概算：项目总投资1000万元，资金来源为中央预算内资金。

三、工程设计、施工必须满足国家和自治区有关节能、环保的要求。

四、项目负责人：[姓名略]。

项目实施中要严格执行项目法人责任制、招投标制、工程监理制等制度，你局要加强项目管理，抓紧做好各项施工前准备工作，确保项目尽早开工建设。
