# 关于阿克陶县人民医院传染病区改扩建项目初步设计的批复

陶发改字〔2019〕133号

有 效 性

发文单位

阿克陶县人民政府

发布机构

发展和改革委员会

阿克陶县人民医院：

你单位《关于对阿克陶县人民医院传染病区改扩建项目初步设计的请示》及新疆四方建筑设计院有限公司编制的《阿克陶县人民医院传染病区改扩建项目初步设计》收悉。经研究，现批复如下:

一、工程建设规模：1、计划将原疾控中心旧楼四层楼面积为2028.9平方米，改造后面积为3927.90平方米。2、将原妇幼保健站旧楼三层楼面积为1106.22平方米，改造后面积为2259.77平方米。

二、工程总概算：项目总投资900万元，其中：700万为江西援助，200万为医院自筹。

三、工程设计、施工必须满足国家和自治区有关节能、环保的要求。

四、项目负责人：[姓名略]。

项目实施中要严格执行项目法人责任制、招投标制、工程监理制等制度，你局要加强项目管理，抓紧做好各项施工前准备工作，确保项目尽早开工建设。
