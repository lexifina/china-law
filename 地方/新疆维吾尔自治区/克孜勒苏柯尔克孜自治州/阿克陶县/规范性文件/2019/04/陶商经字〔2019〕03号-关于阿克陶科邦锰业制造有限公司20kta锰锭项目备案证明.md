# 关于阿克陶科邦锰业制造有限公司20kt/a锰锭项目备案证明

陶商经字〔2019〕03号

有 效 性

发文单位

阿克陶县商务科技和工业信息化局

发布机构

阿克陶县商务科技和工业信息化局

阿克陶科邦锰业制造有限公司：

你公司上报的阿克陶江西工业园区阿克陶科邦锰业制造有限公司厂区内建设20kt/a锰锭项目我局已收悉，经我局研究，同意你公司的建设方案，现将有关事项通知如下：

项目名称：阿克陶科邦锰业制造有限公司20kt/a锰锭项目，项目总投资3840.81万元，其中：固定资产3840.81万元。资金筹措方式全部为企业自筹。

建设地点：阿克陶江西工业园区阿克陶科邦锰业制造有限公司厂区内。

项目建设期限：2019年4月15日至2021年4月15日

请据此证明到国土资源、环境保护、城市规划等相关的部门依法办理有关许可手续。

本备案证明有效期两年。

阿克陶县商务科技和工业信息化局

2019年4月15日
