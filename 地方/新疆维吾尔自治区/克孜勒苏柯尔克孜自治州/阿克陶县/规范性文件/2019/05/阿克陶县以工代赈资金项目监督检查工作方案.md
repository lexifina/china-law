# 阿克陶县以工代赈资金项目监督检查工作方案

为进一步加强对阿克陶县2018年以工代赈项目建设的推进监管与服务工作，更好地完成以工代赈项目建设任务，保证资金使用安全，明确各分管行业部门县级领导以及项目建设单位的责任，督促各建设单位精心策划，全力实施，安全高效的完成年度建设目标任务，特制定本工作方案。

一、各部门责任

（一）县发改委职责。县发改委作为项目建设法人单位的主管单位，主要履行以下职责：

1、负责协调、督促所管项目的前期工作进展情况。协调完成选址、土地、环评手续，负责可研报告、初步设计、施工图设计以及概预算的审查，取得项目审批或核准文件，督促完成拆迁、施工场地水、电、路等外部配套条件。

2、负责沟通、衔接所管项目资金落实情况。加强和上级部门的联系和对接，落实上级补助资金，督促落实配套资金，帮助企业做好贷款等融资工作。

3、负责跟踪、检查、监督所管项目建设进展情况。监督落实项目“五制”，督促和指导项目法人依法签订和执行合同。督促项目建设进度，监管项目资金使用，开展项目专项检查、督查，解决项目开展过程中遇到的困难和问题。监督项目的工程决算、审计和竣工验收工作。

（二）项目法人（项目建设单位）职责。项目法人是项目实施的第一责任人，对项目实施负总责，主要履行以下职责：

1、积极开展项目报批工作。合理安排前期工作计划，落实土地、选址、环评手续，委托具有相应资质部门开展项目前期工作，报审可研报告、初步设计，施工图设计及概预算，负责项目招投标，落实施工场地的拆迁、供水、供电等履行合同责任。

2、加强施工监督。制定项目工作推进计划，落实工程建设的进度衔接、投资控制、质量保证和安全生产措施。落实甲方代表施工现场监督，监督施工、监理单位严格履行投标承诺和合同责任，认真按施工技术规范和设计图施工。监督施工质量、安全监督和隐蔽工程以及主要设备材料和主要工程的检查验收，控制工程的随意变更，监督施工、监理单位人员到位、施工记录、监理日志等填报，工程资料的收集整理等。

3、要依据基本建设财务管理制度，设立财务机构或指定财务负责人及专职财务人员，按项目单独建账、单独核算，建设资金专款专用，并按进度付款。

4、监督协调施工方与项目所在乡、村严格落实以工代赈项目劳务报酬发放制度。除技术复杂的工程外，必须组织当地群众参加工程建设，并根据项目建设工期和工程所需劳务量，本着群众自愿，照顾到面，同等优先安排具有劳动能力的特困户的原则，尽可能多地为贫困群众创造就业机会。劳务报酬发放数额不得低于该项目中央资金的10%；劳务报酬中，向建档立卡贫困人口发放的比例应不低于该项目劳务报酬的50%。在发放过程中务必做到公平、足额、及时发放，严禁克扣和拖欠劳务报酬。切实保证劳务报酬发挥“以工代赈”增加当地农民收入的作用。

5、组织参建各方对工程进行自验。自验合格后，要及时上报负责初步验收的行业主管部门。配合上级部门，行业主管部门稽查、督查，配合审计部门的决算、审计等工作。

（三）相关部门职责

1、各项目审批单位要勇于担当，不得以“前置审批为由”而拒绝本单位的签批。

2、统计部门要及时跟进做到应统尽统，对500万元以下的小项目提出合理化建议，进行分类打包统计。

3、住建、环保、国土、财政、公共资源交易中心部门要积极推进项目的各阶段程序进程，确保项目能够及时完成申报、审批、招投标等手续。

二、项目建设的进度信息、督查信息和考评制度

1、项目进度数据及信息每周三由建设单位上报一次，发改委进行统计。

2、建设单位在每周四下午17点前，将本周资金拨付计划报县发改委汇总，由发改委报县财政局，在每周五上午11:00（北京时间）开拨款会，对建设单位制定的拨款计划进行讨论研究，通过的拨款计划在一周内必须完成拨付。

3、为强化管理加快以工代赈项目实施进度，将对项目进展缓慢不力的项目建设单位下达项目督办通知单，该单将作为督查依据，收到督办通知单的建设单位须在2日内提出有效整改方案（整改方案中要确定整改时限），并将整改方案列入项目督办回执单中，报回县发改委。
