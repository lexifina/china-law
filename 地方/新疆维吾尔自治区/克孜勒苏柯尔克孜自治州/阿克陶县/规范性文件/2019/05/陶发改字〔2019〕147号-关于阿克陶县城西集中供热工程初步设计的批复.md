# 关于阿克陶县城西集中供热工程初步设计的批复

陶发改字〔2019〕147号

有 效 性

发文单位

阿克陶县人民政府

发布机构

发展和改革委员会

阿克陶县住房和城乡建设局：

你局《关于对阿克陶县城西集中供热工程初步设计的请示》及新疆煤炭设计研究院有限责任公司编制的《阿克陶县城西集中供热工程初步设计》收悉。经研究，现批复如下:

一、工程建设规模：拆除原有锅炉房设备，更换1台6.0MW电极式锅炉及其辅机，以及配套供电系统设备。

二、工程总概算：项目总投资1000万元，资金来源为中央预算内资金。

三、工程设计、施工必须满足国家和自治区有关节能、环保的要求。

四、项目负责人：[姓名略]。

项目实施中要严格执行项目法人责任制、招投标制、工程监理制等制度，你局要加强项目管理，抓紧做好各项施工前准备工作，确保项目尽早开工建设。
