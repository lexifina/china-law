# 关于拨付2019年重点生态功能区转移支付的通知

阿克陶县林业局：

为推进生态文明建设，提高重点生态功能区所在地政府基本公共服务保障能力，按照自治区财政厅《关于下达2019年重点生态功能区转移支付预算（第二批）的通知》（新财预〔2019〕96号）、自治州财政局《关于下达2019年重点生态功能区转移支付（第二批）的通知》（克财预〔2019〕99号）文件精神，现拨付你单位2019年重点生态功能区转移支付资金1450万元。 该项补助列入“1100226重点生态功能区转移支付收入”科目。请你单位收到补助资金后，要将转移支付资金用于生态护林员补助，加快财政支出进度，加强资金使用管理。

附件： 2019重点生态功能区转移支付分配表

阿克陶县财政局

2019年6月3日
