# 关于调整工伤认定工作领导小组的通知

局属各科室、社保局：

为做好工伤认定工作，因人事调整，经人社局党组会议研究决定，对工伤认定工作领导小组成员进行调整，具体组成人员如下：

组长：申新梅（社保局党支部副书记、局长）

成员：张志元（劳动人事争议仲裁院院长）

欧阳亮（人社局工伤办干部）

海热提·买买提明（劳动监察大队负责人）

张秀水（社保局干部）

领导小组下设办公室，办公室主任由申新梅同志兼任，负责工伤认定工作。

阿克陶县人力资源和社会保障局
