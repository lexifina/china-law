# 阿克陶县气象局关于领导班子成员工作分工

经2019年8月10日阿克陶县气象局班子成员会议研究决定，对领导班子成员工作进行分工，具体如下：

党支部书记、局长王海东：主持阿克陶县气象局全面工作。对克州气象局和阿克陶县委、人民政府负责。负责县气象局党的建设；主持制定和领导实施阿克陶县气象事业的发展规划、计划。

班子成员、台长艾买提江·阿布力米提：人影工作、后勤保障。

班子成员、副局长郝海霞：协助党支部书记、局长分管党的建设、扶贫、精神文明创建、目标管理、信息宣传、政策法规、财务（基本建设、计划财务等）、人影工作。

分管：办公、财务

班子成员、副局长外力：协助党支部书记、局长分管综合观测、技术网络与装备保障、气象服务、农业气象、应急减灾、预报预测、科研、三农专项、纪检监察。

分管：气象台、纪检

以上各位班子成员及领导除履行好本职工作外，还应认真完成党支部书记、局长安排的其它工作任务。

阿克陶县气象局

2019年8月10日
