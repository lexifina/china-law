# 阿克陶县气象局关于成立“不忘初心、牢记使命”主题教育领导小组的通知

为确保“不忘初心、牢记使命”主题教育工作有力有序推进，经研究，决定成立局“不忘初心、牢记使命”主题教育领导小组，现将领导小组成员名单公布如下：

组  长：王海东（党支部书记、局长）

副组长：郝海霞（副局长）

成  员：艾买提江·阿布力米提（气象台台长）

刘璐（党员）

彭彤江（党员）

领导小组下设办公室：由郝海霞同志任主任。

附件：局“不忘初心、牢记使命”主题教育领导小组及办公室工作职责。

阿克陶县气象局党支部

2019年8月20日
