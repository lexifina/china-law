# 关于调整阿克陶县食品安全委员会成员的通知

各乡（镇、场）人民政府，县直各有关单位、各直属机构：

阿克陶县食品安全委员会主要职责：分析全县食品安全形势，研究制定全县食品安全工作重要政策和措施；安排部署、指导协调全县食品安全工作；督促各乡（镇、场）人民政府、社区管委会和有关部门履行食品安全监管职责；协调指导重大食品安全事故处置工作。

阿克陶县食品安全委员会下设办公室，办公室设在县市场监督管理局，承担阿克陶县食品安全委员会的日常工作。办公室主任由路新勇同志兼任，副主任由雪来提·阿克尤里同志兼任。
