# 阿克陶县气象局关于成立新型冠状病毒肺炎疫情防控工作领导小组的通知

阿克气〔2020〕1号

有 效 性

发文单位

阿克陶县气象局

发布机构

气象局

各股室：

为科学、有效、及时应对新型冠状病毒感染肺炎疫情，切实保障公众健康，阿克陶县气象局决定成立阿克陶县气象局新型冠状病毒感染的肺炎疫情防控工作领导小组，现将领导小组成员名单公布如下：

组  长：王海东（党支部书记、局长）

副组长：艾买提江·阿布力米提（气象台台长）

成  员：郝海霞（副局长）

外力·吾甫尔（副局长）

李勤（干部）

彭彤江（干部）

古丽拜合热姆·巴特尔（干部）

库巴尼其别克·呼杰克（干部）

领导小组下设办公室：由艾买提江·阿布力米提同志任主任。负责协调处理日常疫情防控工作。

工作要求：

严格落实24小时应急值班值守、疫情日报告零报告等工作制度，对发现的问题，及时上报局办公室，全力做好辖区内疫情防控工作。

阿克陶县气象局

2020年2月19日
