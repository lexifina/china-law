# 关于公开投诉举报电话的通知

为认真落实自治区纪委监委、人社厅关于深化整治损害群众利益问题的部署要求，持续巩固“不忘初心、牢记使命”主题教育专项整治成果，推动整治损害群众利益问题常态长效，根据自治区人社厅《深化整治损害群众利益问题实施方案》的工作部署，做好我县深化整治损害群众利益工作，切实解决好我县拖欠农民工工资问题及清理整顿人力资源市场秩序，方便群众反映问题，现将举报电话予以公布，接受社会各界监督。

受理范围：

1、违反劳动保障法律的行为发生在2年内的；

2、有明确的被投诉用人单位，且投诉人的合法权益受到侵害是被投诉用人单位违反劳动保障法律的行为造成的；

3、属于劳动保障监察职权范围并由受理投诉的劳动保障行政部门管辖；

4、未经许可或各类从事人力资源服务经营活动的，特别是未经许可擅自从事互联网招聘等职业中介活动的行为；

5、人力资源服务机构未依法开展人力资源服务业务，包括参与签订不实就业协议，不履行信息审查义务，发布虚假信息或含有歧视性内容信息，哄抬或操纵人力资源市场价格、扣押劳动者居民身份证和其他证件、向劳动者收取押金、捆绑收取流动人员人事档案管理费等违法违规行为；

6、用人单位发布虚假信息，组织虚假招聘活动，骗取劳动者财务的欺诈行为，侵害劳动者平等就业权利，违法发布涉及劳动者户籍、居住地及治愈患者或密切接触者与疫情相关的歧视性招聘信息。

工作日（周一至周五）上午10:00-13:30，下午16:30-20:00。
