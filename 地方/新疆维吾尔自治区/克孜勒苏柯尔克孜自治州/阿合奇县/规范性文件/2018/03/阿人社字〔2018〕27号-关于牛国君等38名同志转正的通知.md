# 关于牛国君等38名同志转正的通知

各相关单位：

根据《关于录用牛国君等44名同志为乡镇参照公务员法管理工作人员的通知》（阿人社字[2017]51号）文件相关精神，自治区选派的第27批留疆战士牛国君等38名同志试用期已结束，经个人申请、单位鉴定及考核合格，同意牛国君等38名同志于2018年1月1日按期转正，请办理相关转正手续。

转正的38名人员如下：

1．阿合奇镇政府5人：牛国君、张旭、王郭平、王英华、王鹏飞；

2．苏木塔什乡政府5人：张彦刚、赵德品、刘思彤、梁亮兵、美丽吾提·金恩斯；

3．哈拉奇乡政府4人：崔伟超、吕涛然、李帅帅、吐尔洪·热索里；

4．哈拉布拉克乡政府3人：王涛、张强、叶尔扎提；

5．马场6人：袁宇航、巩雪峰、黄坤、周尹、张生云、沙拉木江·帕哈尔丁（工资关系在哈拉布拉克乡发放）；

6．色帕巴依乡政府5人：辜昭、窦增录、张帅祥、星生涛、胡安·阿德力别克；

7．库兰萨日克乡政府5人：蔡帅鹏、任思远、甘彪、陆婷、叶尔哈那提；

8．良种场5人：何昌华、左雷、周杰、赵玉才、米热依·加汗（工资关系在库兰萨日克乡发放）。
