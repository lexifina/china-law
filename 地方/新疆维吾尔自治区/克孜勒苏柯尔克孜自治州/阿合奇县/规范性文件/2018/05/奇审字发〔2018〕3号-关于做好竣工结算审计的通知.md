# 关于做好竣工结算审计的通知

一、结算审核报告中必须要放的内容：

1.要求放置公司要求出具的目录、审核报告、审核清单项、定案表、资质证书等内容外，还必须放置以下内容：

（1）立项批复（2）中标通知书、中标下浮率复印件（3）合同复印件（4）竣工验收报告（5）项目相关的变更签证及变更图（变更签证资料编号按顺序与结算审核中的内容相对应）（6）议标的定标资料（7）项目平面示意图及部分简易图纸，尤其是附属项目必须放置全部图纸（8）中介审计公司看现场取证记录及图片（取证记录要求必须有施工、建设及监理三方的项目负责人、中介公司参与人员签字盖章）（9）如有重大变更、涉及金额较大，除提供签证外必须有图片资料（10）变更后合同中无单价依据，自己组价单价分析及材料询价资料（11）其他与工程造价及管理有关的资料(12)委托咨询合同。

2.定案表：（1）如是通过随机抽取有下浮率中标的，定案表中送审价必须按规定下浮率下浮后填写。（2）审计资料提交审计局时定案表中相关信息必须填写完整（建设方、施工方、审核单位的法人、负责人签字，日期填写完整，加盖单位盖章清晰）。

3.项目完成审计报告书必须胶装，要有编印页码的目录，并在每一页资料上按要求编排页码。

二、项目完成提供资料要求

乙方项目实施完成后，先提供1份按要求装订完整的审核报告提交甲方审核，同时交给电子版文件：包括审计方案、审计证据、审计工作底稿、审计报告，计价、审核、算量、图纸等软件备份，以及其他与项目造价有关的电子版文件。

三、审核报告要求

报告为审计局提供4份（不含公司自己留存的），各公司在自己报告内容的基础上，要求报送我局审计报告必须包含以下内容：

一、建设项目基本情况：（字体：黑体，三号）

1.项目建设内容：描述项目建设具体的相关内容。要有建设地点，且建设地点要有GPS坐标，水利、公路或实施区较广项目每个地点不得少于两个GPS坐标。（字体：仿宋GB2312，三号）

2.资金来源

四、建设项目审计情况（字体：黑体，三号）

1．立项文件名称、内容概要、立项日期（字体：仿宋GB2312，三号）

2．招标内容：招标日期，招标方式，中标日期、中标价、评标方式、下浮率（如果有）、中标单位

3.合同签订：签订日期，内容情况（基本内容、合同价及合同价格形式），项目施工工期。

4.变更情况：变更共有几个，分别写出变更时间及内容概要。

5.项目竣工验收情况：实际完成的开、竣工日期，竣工验收完成日期及结果（合格、优秀、不通过等）。

6.项目付款情况：依据甲方提供资料，截止审计日，项目已付款**万元，付款进度**%。

三、审计结果（字体：黑体，三号）

包括项目的名称、施工单位名称、合同价款、送审金额、审定金额、核减金额、核减率。（字体：仿宋GB2312，三号）

核增或核减情况内容，要有具体内容及描述。

（一）建设工程项目工程造价多计造价**万元。（字体：楷体GB2312，三号）

…………（字体：仿宋GB2312，三号）

（二）建设项目管理方面存在的问题

1.项目管理不规范（字体：仿宋GB2312，三号）

（1）提供资料情况：主要反映项目资料提供方面的情况，根据自己公司的要求，主要是立项、招标资料电子版、图纸电子版、竣工图及电子版、隐蔽工程验收及确认资料等相关的要求提供无法提供的。

（2）提供资料不规范情况：竣工验收单、签证及其他与项目有关（尤其是和造价有关，造成确认模糊的）重要资料格式不符合要求、说明内容不完善的具体情况。

2.招投标过程是否符合流程及要求，如不符合，说明具体情况。（如少于3家投资公司或其他等等）

3．项目竣工结算审计价超过中标价**%（10%以上填写具体数字。）

4.工程内容变更约金额**万元，占合同价**%。（变更内容打印1份详细清单）

5.合同内工程单价偏差较大，或工程量计算不准、漏项等原因引起工程造价金额**万元，是合同价的**%。（变更内容打印1份详细清单）

6.项目管理中存在的其他问题，分项进行列明，并说明具体情况。
