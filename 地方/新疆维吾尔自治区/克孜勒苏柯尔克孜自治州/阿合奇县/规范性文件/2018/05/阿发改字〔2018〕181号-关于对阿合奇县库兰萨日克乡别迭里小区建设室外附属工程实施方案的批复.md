# 关于对阿合奇县库兰萨日克乡别迭里小区建设室外附属工程实施方案的批复

阿合奇县库兰萨日克乡人民政府：

你单位《关于审批阿合奇县库兰萨日克乡别迭里小区建设室外附属工程实施方案的请示》（阿库政字〔2018〕22号）、《关于库兰萨日克乡别迭里小区建设室外附属工程实施方案的审查意见》（阿建字〔2018〕56号）均收悉，经研究，我委原则上同意该方案，现将有关事项批复如下：

一、项目名称：阿合奇县库兰萨日克乡别迭里小区建设室外附属工程。

二、建设单位：阿合奇县库兰萨日克乡人民政府。

三、项目建设地址：阿合奇县库兰萨日克乡别迭里村。

四、项目建设规模及主要内容：144户平房小区室外配套工程，路面长度1871米，其中6米宽路的414米，4米宽的路1057米，每米600元，预计造价180万元，硬化面积按每户进户路24平方，共3456平方米预计造价60万元；其他资金用于给水管网1526米，管径为DN150，材料为钢丝网骨架聚乙烯复合管，水压承力1.2Mpa；给水阀门井50座，是砖混结构，新建排水管网2705米，管径为DN300，材料为HOPE塑料管，水压承力1.0Mpa；排水阀门井207座，是砖混结构；化粪池大小300立方米太阳能灯150盏，相变6个，强电：镀锌钢管5200米，弱电：镀锌钢管2760米x3,144户地热采暖系统安装及铺设，每户80㎡，面积合计11520㎡,自来水管道3500米，检查井45个，水表144个。

五、该项目总投资及资金来源：该项目计划总投资700万元。

资金来源为2018涉农资金整合。

六、建设年限：2018年。

请你单位在项目建设期间，切实加强监督检查和管理。严格按照国家、自治区、自治州有关规定，履行基本建设程序，加强项目资金管理，严把工程质量关，确保工程如期建成。

阿合奇县发展和改革委员会

2018年5月12日
