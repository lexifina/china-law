# 关于对阿合奇县哈拉布拉克乡克孜朗渠道改扩建工程初设报告（代可研）的批复

阿合奇县水利局：

你单位《关于审批阿合奇县哈拉布拉克乡克孜朗渠道改扩建工程初设报告（代可研）的请示》（阿水字〔2018〕83号）、《关于对阿合奇县哈拉布拉克乡克孜朗渠道改扩建工程初设报告（代可研）的审查意见》（阿水字〔2018〕82号）均收悉。经研究，我委原则上同意该方案，现批复如下：

一、项目名称：阿合奇县哈拉布拉克乡克孜朗渠道改扩建工程

二、项目建设单位：阿合奇县水管站。

三、项目选址：阿合奇县哈拉布拉克乡克孜朗。

四、项目建设内容和规模：工程渠首及引水渠控制灌溉面积0.65万亩，设计引水流量为0.7m3/s，加大流量为1.0 m3/s。引水渠首等别为Ⅴ等小（2）型工程。主要建筑物包括渠首（冲砂闸、溢流堰、进水闸，导流堤）、渠道及建筑物。主要建筑物、次要建筑物均为5级。5级建筑物设计洪水重现期10年，校核洪水重现期20-30年。经设计洪水分析计算，引水渠首的防洪标准对应10年一遇的设计洪水流量991m3/s，20年一遇校核洪水流量1329.0m3/s。

建设内容：工程新建渠首1座，改造渠道1条，长1.026km，新建和改建渠系建筑物7座。其中：引水渠首1座 ，测水桥1座，过洪桥涵6座。

五、该项目总投资及资金来源：该项目总投资620万元，其中：建筑工程费419.14万元、金属结构设备及安装工程6.68万元、临时工程费29.58万元、独立费用83.44万元、预备费26.94万元、环境保护工程4.63万元、水土保持工程15.81万元、水情测报系统建设费用33.78万元。

资金来源为中央预算内以工代赈资金（该项目系纳入2018年财政涉农资金整合项目库项目，编号AHQ-60）。

六、建设年限：2018年

请严格执行项目法人责任制、招投标制、监理制、合同管理制。严格按照所批复的建设规模和内容实施，不得擅自变更。

阿合奇县发展和改革委员会

2018年5月13日
