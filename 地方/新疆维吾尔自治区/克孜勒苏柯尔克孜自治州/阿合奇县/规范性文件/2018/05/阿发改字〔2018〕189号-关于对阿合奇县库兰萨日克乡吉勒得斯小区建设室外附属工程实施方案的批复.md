# 关于对阿合奇县库兰萨日克乡吉勒得斯小区建设室外附属工程实施方案的批复

阿合奇县库兰萨日克乡人民政府：

你单位《关于审批阿合奇县库兰萨日克乡吉勒德斯小区建设室外附属工程实施方案的请示》（阿库政字〔2018〕23号）《关于阿合奇县库兰萨日克乡吉勒德斯小区建设室外附属工程实施方案的审查意见》（阿建字〔2018〕64号）均收悉，经研究，我委原则上同意该方案，现将有关事项批复如下：

一、项目名称：阿合奇县库兰萨日克乡吉勒德斯小区建设室外附属工程。

二、项目建设单位：阿合奇县库兰萨日克乡人民政府。

三、项目选址：阿合奇县库兰萨日克乡吉勒得斯村。

四、项目建设规模及主要内容：80户楼房小区硬化面积2500㎡，绿化面积4500㎡，彩砖地面1200㎡，化粪池大小100m³。

五、该项目总投资及资金来源：该项目计划总投资290万元，其中200万来源于2018涉农资金整合，90万元为中央专项资金。

六、建设年限：2018年。

请你单位在项目建设期间，切实加强监督检查和管理。严格按照国家、自治区、自治州有关规定，履行基本建设程序，加强项目资金管理，严把工程质量关，确保工程如期建成。

阿合奇县发展和改革委员会

2018年5月21日
