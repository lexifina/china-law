# 关于对阿合奇县哈拉奇乡水冲式公共厕所项目实施方案的批复

阿合奇县哈拉奇乡人民政府：

你单位《关于审批哈拉奇乡水冲式公共厕所项目实施方案的申请》（哈政字【2018】82号）、住建局《关于阿合奇县哈拉奇乡水冲式公共厕所项目实施方案的审查意见》（阿建字【2018】67号）均已收悉。经研究,我委原则同意该方案，现批复如下：

一、项目选址：哈拉奇乡阿合奇村、布隆村、哈拉奇村。

二、项目建设主要内容：3间砖混结构40平方米水冲式公共厕所，还包括化粪池，排污管道、室内外装修、土锅炉、灯具、电力照明、水电接入、洗手池等。

三、该项目总投资及资金来源：该项目总投资75万元，资金来源为财政涉农资金整合。

四、建设年限：2018年

请严格执行项目法人责任制、招投标制、监理制、合同管理制。严格按照所批复的建设规模和内容实施，不得擅自变更。

阿合奇县发展和改革委员会

2018年5月22日
