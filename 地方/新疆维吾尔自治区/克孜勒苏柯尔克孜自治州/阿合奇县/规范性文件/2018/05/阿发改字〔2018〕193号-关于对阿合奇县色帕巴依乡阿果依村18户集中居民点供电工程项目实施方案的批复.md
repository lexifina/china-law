# 关于对阿合奇县色帕巴依乡阿果依村18户集中居民点供电工程项目实施方案的批复

阿合奇县色帕巴依乡人民政府：

你单位《关于阿合奇县色帕巴依乡阿果依村18户集中居民点供电工程项目实施方案审批的请示》（色政字【2018】50号）、住建局《关于阿合奇县色帕巴依乡阿果依村18户集中居民点供电工程项目实施方案的审查意见》（阿建字【2018】65号）均已收悉。经研究,我委原则同意该方案，现批复如下：

一、项目选址：阿合奇县色帕巴依乡阿果依村。

二、项目名称：阿合奇县色帕巴依乡阿果依村18户集中居民点供电工程项目

三、项目建设主要内容：阿果依村18户集中居民点小区室外供电工程100千瓦公变一台及相关配套。

三、该项目总投资及资金来源：该项目总投资20万元，资金来源为财政涉农资金整合。

四、建设年限：2018年

请严格执行项目法人责任制、招投标制、监理制、合同管理制。严格按照所批复的建设规模和内容实施，不得擅自变更。

阿合奇县发展和改革委员会

2018年5月23日
