# 关于对阿合奇县苏木塔什乡大蒜、马铃薯储藏库建设项目实施方案的批复

阿合奇县苏木塔什乡人民政府：

你单位《关于审批大蒜、马铃薯储藏库建设项目实施方案的请示》（苏政字〔2018〕62号）、《关于大蒜、马铃薯储藏库建设项目实施方案的审查意见》（阿建字〔2018〕74号）均收悉，经研究，我委原则上同意该方案，现将有关事项批复如下：

一、项目名称：阿合奇县苏木塔什乡大蒜、马铃薯储藏库建设项目。

二、项目建设单位：阿合奇县苏木塔什乡人民政府。

三、项目建设地址：阿合奇县苏木塔什乡苏木塔什村原砖厂。

四、项目建设规模及内容：新建500平方米大蒜、马铃薯存储窖1座。

五、该项目总投资及资金来源：该项目总投资100万元，资金来源为财政涉农资金整合。

六、建设年限：2018年。

请你单位在项目建设期间，切实加强监督检查和管理。严格按照国家、自治区、自治州有关规定，履行基本建设程序，加强项目资金管理，严把工程质量关，确保工程如期建成。

阿合奇县发展和改革委员会

2018年5月25日
