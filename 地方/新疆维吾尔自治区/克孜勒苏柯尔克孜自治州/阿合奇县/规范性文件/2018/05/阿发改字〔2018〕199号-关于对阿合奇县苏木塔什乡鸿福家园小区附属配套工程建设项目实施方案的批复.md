# 关于对阿合奇县苏木塔什乡鸿福家园小区附属配套工程建设项目实施方案的批复

阿合奇县苏木塔什乡人民政府：

你单位《关于审批阿合奇县苏木塔什乡鸿福家园小区附属配套工程建设项目实施方案的请示》（苏政字〔2018〕72号）、《关于审批阿合奇县苏木塔什乡鸿福家园小区附属配套工程建设项目实施方案的审查意见》（阿建字〔2018〕72号）均收悉，经研究，我委原则上同意该方案，现将有关事项批复如下：

一、项目名称：阿合奇县苏木塔什乡鸿福家园小区附属配套工程。

二、项目建设单位：阿合奇县苏木塔什乡人民政府。

三、项目建设地址：阿合奇县苏木塔什乡苏木塔什村。

四、项目建设规模及主要内容：48户楼房小区其中壁挂炉、室外供排水1200米、供电线路及变压器相关配电配套设施，小区硬化、道路、围栏、值班室、化粪池一座及其设施、自来水管网、排水管网、监控设施设备。

五、该项目总投资及资金来源：该项目总投资220万元，资金来源为财政涉农资金整合。

六、建设年限：2018年。

请你单位在项目建设期间，切实加强监督检查和管理。严格按照国家、自治区、自治州有关规定，履行基本建设程序，加强项目资金管理，严把工程质量关，确保工程如期建成。

阿合奇县发展和改革委员会

2018年5月25日
