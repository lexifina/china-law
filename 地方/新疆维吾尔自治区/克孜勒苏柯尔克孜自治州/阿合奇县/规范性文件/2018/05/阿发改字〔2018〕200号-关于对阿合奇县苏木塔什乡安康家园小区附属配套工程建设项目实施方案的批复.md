# 关于对阿合奇县苏木塔什乡安康家园小区附属配套工程建设项目实施方案的批复

阿合奇县苏木塔什乡人民政府：

你单位《关于审批安康家园小区附属配套工程建设项目实施方案的请示》（苏政字〔2018〕69号）、《关于审批安康家园小区附属配套工程建设项目实施方案的审查意见》（阿建字〔2018〕71号）均收悉，经研究，我委原则上同意该方案，现将有关事项批复如下：

一、项目名称：阿合奇县苏木塔什乡安康家园小区附属配套工程。

二、项目建设单位：阿合奇县苏木塔什乡人民政府。

三、项目建设地址：阿合奇县苏木塔什乡阿合塔拉村。

四、项目建设规模及主要内容：56户楼房小区室外供排水、供电线路及变压器、供暖管道、小区内硬化、道路等，化粪池200立方，围栏、值班室一座、监控设施设备。

五、该项目总投资及资金来源：该项目总投资170万元，资金来源为财政涉农资金整合。

六、建设年限：2018年。

请你单位在项目建设期间，切实加强监督检查和管理。严格按照国家、自治区、自治州有关规定，履行基本建设程序，加强项目资金管理，严把工程质量关，确保工程如期建成。

阿合奇县发展和改革委员会

2018年5月25日
