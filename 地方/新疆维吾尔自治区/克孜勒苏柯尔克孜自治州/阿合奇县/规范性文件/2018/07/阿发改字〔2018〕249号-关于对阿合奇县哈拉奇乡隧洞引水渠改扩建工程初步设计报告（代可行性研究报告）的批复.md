# 关于对阿合奇县哈拉奇乡隧洞引水渠改扩建工程初步设计报告（代可行性研究报告）的批复

阿合奇县水利局：

你单位《关于审批阿合奇县哈拉奇乡隧洞引水渠改扩建工程初步设计报告（代可研）的请示》(阿水字〔2018〕115号)、《关于阿合奇县哈拉奇乡隧洞引水渠改扩建工程初步设计报告（代可行性研究报告）的审查意见》（克水利字〔2018〕129号）均收悉。经研究，我委原则上同意该方案，现批复如下：

一、项目名称：阿合奇县哈拉奇乡隧洞引水渠改扩建工程；

二、项目建设单位：阿合奇县水利管理站；

三、项目建设地点：阿合奇县哈拉奇乡；

四、项目建设主要内容及规模：项目控制灌溉面积4.03万亩，改造引水渠道1.086km，扩建进水闸1座，交通桥2座，连接段4处。本项目的工程级别为4级，水工建筑物级别为5级；

五、该项目总投资及资金来源：工程概算总投资为431万元，资金来源为中央预算内以工代赈资金（该项目已通过新疆维吾尔自治区投资项目联合审批平台申报，项目编码：2018-653023-76-01-010441）；

六、建设年限：2018年。

请严格执行项目法人责任制、招投标制、监理制、合同管理制。严格按照所批复的建设规模和内容实施，不得擅自变更。

2018年7月14日
