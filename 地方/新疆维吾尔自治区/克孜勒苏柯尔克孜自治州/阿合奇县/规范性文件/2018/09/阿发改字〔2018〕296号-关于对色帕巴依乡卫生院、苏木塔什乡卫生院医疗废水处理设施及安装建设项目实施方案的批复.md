# 关于对色帕巴依乡卫生院、苏木塔什乡卫生院医疗废水处理设施及安装建设项目实施方案的批复

阿合奇县卫生局：

你单位报来的《关于审批色帕巴依乡卫生院、苏木塔什乡卫生院医疗废水处理设施及安装建设项目实施方案的申请》（阿卫发【2018】93号）、《关于对色帕巴依乡卫生院、苏木塔什乡卫生院医疗废水处理设施及安装建设项目实施方案的审查意见》（阿建字【2018】136号）收悉，经研究，现将有关事项批复如下：

一、项目名称：色帕巴依乡卫生院、苏木塔什乡卫生院医疗废水处理设施及安装建设项目。

二、项目法人及建设地点

项目法人：阿合奇县卫生局。

建设地址：阿合奇县色帕巴依乡卫生院、苏木塔什乡卫生院。

三、建设年限：2018年。

四、建设内容：医疗污水处理设施2套、化粪池建设安装及接通污水管网等建设项目。

五、总投资及资金来源：该项目概算总投资为48万元，资金来源于色帕巴依乡卫生院、苏木塔什乡卫生院自筹资金。

请你单位会同有关部门在项目建设期间，切实加强监督检查和管理。严格按照国家、自治区、自治州有关规定，履行基本建设程序，加强项目资金管理，严把工程质量关，确保工程如期建成。

2018年9月11日
