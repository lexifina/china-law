# 阿合奇县2018年度财政预算执行和其他财政收支情况审计的通知

奇审通〔2018〕1号

有 效 性

10年

发文单位

阿合奇县审计局

发布机构

阿合奇县审计局

阿合奇县财政局：

根据县政府工作安排，按照《中华人民共和国审计法》第二十二条的规定及《新疆维吾尔自治区国家建设项目审计监督条例》第十三条规定，我局决定派出审计组，自2018年4月21日起，对阿合奇县2017年度财政预算执行和其他财政收支情况进行就地审计。重大事项追溯到相关年度。请予以配合，并提供有关资料（包括电子数据资料）和必要的工作条件。你单位法定代表人和财务主管人员要对所提供资料的真实性、完整性作出承诺。

审计组组长：徐图

成      员：张斌、王立霞、王新、杨钰红、夏琳

廉政监督员：张斌

阿合奇县审计局

二O一九年一月三十日
