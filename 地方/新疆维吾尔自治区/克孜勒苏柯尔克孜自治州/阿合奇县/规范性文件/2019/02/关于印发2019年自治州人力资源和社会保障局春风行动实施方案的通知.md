# 关于印发2019年自治州人力资源和社会保障局春风行动实施方案的通知

各县市人力资源和社会保障局：

现将《2019年自治县人力资源和社会保障局春风行动实施方案》印发给你们，请认真抓好贯彻落实，并及时上报相关工作落实情况。

克州人力资源和社会保障局

2019年2月13日

2019年自治州人力资源和社会保障局春风行动实施方案

为认真贯彻落实中央经济工作会议和中央农村工作会议精神，落实党中央和自治区党委工作部署，牢牢聚焦总目标，扎实推进就业扶贫工作，推动其他援疆省市企业转移就业常态化、疆内跨地区转移就业常态化、就地就近转移就业常态化、旅游产业带动就业常态化、稳定就业常态化，实现转移就业新发展。克州人力资源和社会保障局定于2月中旬至3月中旬在全州开展“2019年春风行动”。现将有关事项通知如下：

一、活动主题

促进转移就业，助力脱贫攻坚。

二、活动时间

2019年2月12日至3月15日。

三、服务对象

（一）农村建档立卡贫困劳动力；

（二）有就业创业意愿的农村劳动力；

（三）城市困难农民工；

（四）有用工需求的用人单位。

四、活动目标

（一）使有转移就业意愿的农村劳动力特别是建档立卡农村贫困劳动力得到便捷的政策咨询、岗位信息、职业指导和职业介绍。

（二）有转移就业意愿的劳动者得到职业技能培训。

（三）有创业愿望的劳动者得到创业培训、创业服务，符合条件的都能享受相应政策扶持。

（四）有用人需求的企业和各类单位得到招聘服务，动员更多用人单位吸纳农村劳动力。

（五）使有转移就业意愿的农村劳动者特别是建档立卡农村贫困劳动力了解相关法律法规，进一步提高依法维护劳动经济权益的意识。

五、活动内容

（一）做好活动宣传。各县（市）要在春风行动期间，以“劳动最光荣、幸福在奋斗、脱贫靠自我”为主题开展专项宣传活动，选树一批贫困劳动力就业脱贫典型，组织外出务工人员讲述务工经历和体会，示范引领贫困劳动力等人员就地就近转移就业，转移其他援疆省市企业就业，激发劳动脱贫内生动力。

（二）收集供求信息。各县（市）要认真做好企业用工需求情况调查和农村劳动力特别是贫困家庭劳动力就业需求调查摸底。以乡镇为单位，全面收集劳动者求职意愿和就业服务需求；以县（市）为单位，全面了解本地重点企业、重点项目及其他地州市企业的招聘需求。对掌握的信息整理汇总，分门别类，为发布信息提供服务做好准备。

（三）开展招聘活动。各县（市）结合实际组织开展形式多样的“专场招聘会”“企业招聘面对面”“送岗位下乡”等活动，将企业用工信息及时提供给农村劳动者。把岗位信息、培训项目、扶持政策直接送村进户到人，实现“点对点”有效对接。深度贫困地区要发挥主观能动性，主动到北疆、东疆等用工企业对接，开发落实能够实现稳定就业的岗位。各县（市）要加大与其他援疆省市前方指挥部的对接、与其他省市企业的对接、与正规人力资源机构的对接，加大对接力度和频次，多方位开发就业岗位。

（四）抓好技能培训。落实脱贫攻坚“冬季攻势”，开展培训专项活动，大规模开展就业、基本劳动素质和就业技能等培训。分批分层分类坚持不懈抓好培训，做好就业基础性工作；开展包括感党恩教育、法律常识、务工常识、军训、劳动纪律等7项内容的标准化培训，增强其就业适应能力。各县（市）人社部门积极对接沟通，做好农村贫困人口转移就业培训。

（五）推进就业扶贫。各县（市）要聚焦提高劳务组织化程度和深度贫困地区建档立卡贫困劳动力就业，更加有力的落实政策服务措施。开展更有针对性地招聘活动、因地制宜到村到户到人送岗位上门。组织更多贫困劳动力参加技能培训，提高就业能力。阿图什市、阿克陶县要主动深入深度贫困乡（镇），认真落实自治州州内协作扶贫工作方案，点对点做好就业扶贫工作。

（六）优化就业环境。要在本县（市）集中开展清理整顿人力资源市场秩序专项行动，打击职业介绍领域的违法犯罪活动，优化农村劳动者转移就业环境，治理农民工工资拖欠，维护农村劳动者合法权益。要着力推进公共就业服务向基层延伸，提供就近便捷的就业服务，帮助农村劳动者解决生产生活困难，使他们切实感受到党和政府的温暖关怀，创建“转得出，留得住”的农村劳动力就业长效机制。

六、工作要求

（一）加强组织领导。各县市人力资源和社会保障局要高度重视，提高政治站位，把做好春风行动作为贯彻落实中央和自治区党委要求的具体举措，加强协作配合，制定有针对性的工作方案，明确责任分工，认真组织实施，充分发挥部门优势，广泛动员干部群众参与，形成合力，确保实效。

（二）精心谋划筹备。各县（市）要提前谋划，精心筹备，利用活动开展的有利时机，促进更多农村富余劳动力实现转移就业。要严密制定春风行动方案，精心组织实施，确保活动安全，提高活动实效。

（三）加强信息宣传。春风行动期间的重要活动、重大举措要利用媒体广泛宣传。活动期间现场图片（附简要文字说明）以及有关新闻和信息线索以电子邮件形式及时报送克州人力资源和社会保障局就业促进科。

（四）及时统计总结。各县市人力资源和社会保障局要加强与上级部门的沟通联系，及时准确做好统计、汇总和上报工作。各县市人力资源和社会保障局于2019年2月15日前分别上报本部门春风行动方案、春风行动联系人和联系方式，并于2019年3月7日前上报本部门开展春风行动情况总结和统计表。重大活动和重要情况及时报告。
