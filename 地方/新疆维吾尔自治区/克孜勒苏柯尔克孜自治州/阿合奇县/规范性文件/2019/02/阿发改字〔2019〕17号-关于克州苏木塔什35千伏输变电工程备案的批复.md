# 关于克州苏木塔什35千伏输变电工程备案的批复

阿发改字〔2019〕17号

发布日期

2019-02-16 12:22

发文单位

发改委

发布机构

发改委

国网新疆电力有限公司阿合奇县供电公司：

你单位报来的《关于国网阿合奇县供电公司克州苏木塔什35千伏输变电工程项目备案申请》克奇供综〔2019〕3号已收悉，该建设项目属于备案项目，实行备案管理。经研究，同意备案。

一、项目名称：克州苏木塔什35千伏输变电工程。

二、建设规模及内容：本工程新建35千伏变电站1座，新增主变2台，容量12600千伏安，35千伏线路27.5千米。

三、项目总投资及资金来源：该项目总投资3055万元，资金来源为企业自筹。

四、项目建设期：2019年

请你单位认真落实环境保护部门对环保的预审意见，履行好有关审批手续。

此备案通知有效期为一年。

阿合奇县发展和改革委员会

2019年2月14日
