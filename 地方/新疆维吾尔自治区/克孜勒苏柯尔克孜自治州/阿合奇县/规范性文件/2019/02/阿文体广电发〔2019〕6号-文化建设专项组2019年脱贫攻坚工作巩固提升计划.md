# 文化建设专项组2019年脱贫攻坚工作巩固提升计划

根据《关于巩固提升脱贫攻坚成果坚决防止返贫实施意见》的通知(新扶贫领发〔2019〕 3号)文件精神，全面巩固拓展脱贫攻坚成果，强化精准脱贫后续扶持发展工作举措，不断巩固拓展脱贫攻坚成果。进一步强化任务落实，推进阿合奇县公共文化服务体系建设，结合工作实际，现制定文化建设专项组2019年脱贫攻坚工作巩固提升计划，如下：

一、指导思想

2019年，是新中国成立70周年，是全面建成小康社会关键之年，以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大和十九届二中、三中全会精神，贯彻落实习近平总书记关于扶贫工作的重要论述，贯彻落实以习近平同志为核心的党中央治疆方略、特别是社会稳定和长治久安总目标，坚持精准扶贫精准脱贫基本方略，坚持外界帮扶和扶智扶志相统一，结合乡村振兴战略实施，建立健全巩固提升脱贫攻坚成果长效机制，强化精准脱贫后续扶持发展工作举措。贯彻落实自治区、自治州关于巩固提升脱贫攻坚成果的决策部署，坚持以人民为中心的发展思想，坚持精准脱贫基本方略，通过对全县10个深度贫困村全面开展文化扶贫，到2020年基本建成现代公共文化服务体系，实现基本公共文化服务均等化。

二、工作目标

（一）提高政治站位，加强政治理论学习

坚决贯彻落实习近平总书记关于扶贫工作的重要论述。深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，提高政治站位，始终在政治上思想上行动上同以习近平同志为核心的党中央保持高度一致。深入学习贯彻习近平总书记关于扶贫工作的重要论述，并列入局党组学习计划，不断增强打赢脱贫攻坚战的责任感紧迫感和使命感。坚决贯彻落实自治区、自治州党委关于脱贫攻坚的工作部署要求。认真学习贯彻自治区党委九届六次全体会议、经济工作会议和农业农村工作会议精神,学习贯彻自治州党委十届四次全体会议，学深学透，入脑入心。突出自查自纠，对所发现的问题限期整改，做到群众满意。

（二）强化组织领导,高度重视

加强基础设施建设，坚持抓重点、攻难点、强弱项、补短板，着力解决贫困户通广播电视问题。为保证我县广播电视户户通正常运行，农牧民群众顺利看上电视、保证行政村覆盖文化活动室及场所，并充分发挥活动室及场所作用，阿合奇县党委、政府高度重视文化建设工作，成立专项领导小组。坚定自觉地把思想和行动统一到党中央和自治区、自治州党委、政府脱贫攻坚系列决策部署上来，认真安排、周密部署，严格落实，组织工作人员做好此项工作。对全县23个行政村广播电视、村级文化室、文化场所进一步加强管理。

（三）压实工作责任，全面部署

坚持一把手负总则原则，根据相关文件要求，一是制定本县内户户通运行方案，安排专人负责本地户户通设备的安装调试，定期组织维护人员开展村村通户户通设备巡检维修，开通监督、投诉和服务电话，在机顶盒上粘贴自治区监督电话和本地县维修服务电话，解决了咨询、报修、设备维护“最后一公里”的问题。规范用户信息档案，严格按照规范和要求，建立健全用户信息档案，使用户信息有据可查，做到一村一档、一户一表，为村村通户户通用户信息规范化建设奠定了坚实的基础。二是无线台争取在2019年完成机房搬迁工作。

（四）营造良好的舆论氛围，强化工作落实情况

一是通过广播电视、宣传栏等平台，加大宣传力度。深入宣传习近平总书记关于扶贫工作的重要论述，宣传党中央关于精准扶贫脱贫的重大决策部署，宣传自治区、自治州党委和县委关于打赢精准脱贫攻坚战，强化政策举措，宣传脱贫攻坚典型经验及成就等内容。二是抓好文化惠民工作，群众公共文化活动不断丰富。阿合奇县文工团按照突出公益属性，强化服务功能，增强发展活力的要求，做好“政府购买公益性文艺演出”等文化惠民活动，丰富农牧民精神文化生活，完成全年不少于80场次的下乡演出任务。将农村电影放映作为助推进文化精准脱贫、农村精神文明建设的一项重要内容，放映场次向贫困村倾斜，实现深度贫困村每年任务量只增不减。深入开展公益电影“进农村、进社区、进学校、进军营”等活动，按照“一村一月一场电影”的要求，保障贫困村每月至少放映一场电影，确保高质量完成全年播放不少于276场次的放映任务。三是加大资金投入,加快公共文化服务阵地和基层综合文化服务中心建设。做好免费开放工作,文化馆、图书馆各类场所全部按规定时间对外免费开放，每周开放时间不少于40小时。同时,积极组织开展内容丰富、形式多样的文化活动；各乡镇文化站在做好日常管理和设施维护的基础上,举办各类培训班、演出等活动。利用各乡镇综合文化站、村农家书屋等基层文化阵地,大力宣传党的扶贫攻坚政策。

（五）完善扶贫项目库建设

严格执行《新疆维吾尔自治区县级脱贫攻坚项目库建设管理暂行办法》的相关要求，着力推进完成脱贫攻坚目标，根据年度扶贫计划，实施动态管理，及时充实和完善项目库，确保年度扶贫绩效考核目标顺利完成。

（六）建立脱贫攻坚资金保障机制

一是落实国家、自治区各类文化惠民政策和各项补助资金，规范发放、加强监管，惠民政策和补助经费要优先保障深度贫困村。二是加大力度向上争取一批公共文化建设项目和资金。按照国家“基本公共文化服务指导标准”，加大深度贫困村公共文化建设投入，完善投入机制，着力推动公共文化设施薄弱的贫困村改变面貌。

（七）切实抓好问题整改工作

继续对所涉及的问题进行梳理完善、整改落实，及时完善整改台账和方案，对照其他问题进行举一反三自查，确保整改工作落实到位。重点加强对一些容易犯的错误问题的及时发现和解决。

三、组织保障

（一）强化组织领导。要落实领导责任，明确文化扶贫工作职责和抓落实的管理体制。重点围绕任务分工、责任划分、措施制定等工作，确保文化建设扶贫有抓手。梳理本地文化建设扶贫工作汇报机制，建立健全数据库管理、考核自查等机制。

（二）加强沟通协调。积极与各乡（镇）、场、扶贫部门加强共沟通协调，建立协作联信息通报制度，及时发现和解决工作中存在的问题，共同推进文化建设专项精准扶贫工作。

（三）广泛运用媒体。通过电视广播、宣传栏、专题栏等平台，持续加强文化建设脱贫攻坚宣传教育力度，营造全社会关心扶贫、支持扶贫、参与扶贫的良好氛围。
