# 关于克州雪霕110千伏变电站二期扩建工程备案的批复

阿发改字〔2019〕18号

发布日期

2019-05-06 12:25

发文单位

发改委

发布机构

发改委

国网新疆电力有限公司阿合奇县供电公司：

你单位报来的《关于国网阿合奇县供电公司克州雪鲀110千伏变电站二期扩建工程项目备案申请》克奇供综〔2019〕4号已收悉，该建设项目属于备案项目，实行备案管理。经研究，同意备案。

一、项目名称：克州雪鲀110千伏变电站二期扩建工程。

二、建设规模及内容：本新增主变1台，容量为50兆伏安，新增110千伏线路32千米。

三、项目总投资及资金来源：该项目总投资3017万元，资金来源为企业自筹。

四、项目建设期：2019年

请你单位认真落实环境保护部门对环保的预审意见，履行好有关审批手续。

此备案通知有效期为一年。

阿合奇县发展和改革委员会

2019年5月4日
