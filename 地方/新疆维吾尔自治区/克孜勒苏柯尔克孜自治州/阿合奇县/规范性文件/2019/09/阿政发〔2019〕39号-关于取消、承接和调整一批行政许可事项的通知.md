# 关于取消、承接和调整一批行政许可事项的通知

各乡（镇）、场，县人民政府各工作部门、县直各单位：

为进一步推动简政放权、放管结合、优化服务改革向纵深发展，根据《中华人民共和国行政许可法》有关规定，结合国务院《关于取消和下放一批行政许可事项的决定》（国发〔2019〕6号）精神，县人民政府组织相关部门对行政许可事项目录进行了彻底清理，决定取消、承接和调整行政许可事项23项。其中取消、变更行政许可事项2项，承接上级下放行政许可事项12项，调整行政许可事项9项，取消、承接和调整后进驻县行政服务中心行政许可事项共96项。

各部门要抓紧做好取消和调整后的行政许可事项的落实和衔接工作，切实增强简政放权的协调性、事中事后监管的有效性、公共服务的便利性，坚决维护公平公正的市场秩序，推动经济高质量发展。
