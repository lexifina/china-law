# 吐地行〔2014〕228号关于公布规范性文件清理结果的通知

各县（市）人民政府、地直各部门：

为维护社会主义法制统一和政令畅通，全面推进依法行政，加快建设法治政府，根据自治区人民政府办公厅《关于开展规范性文件清理工作的通知》（新政办发〔2014〕35号）精神，地区行署组织对2013年12月31日前以地区行署和行署办公室名义发布的规范性文件进行了全面清理，确认继续有效的规范性文件61件，废止或失效的规范性文件8件。现将继续有效的规范性文件目录、废止或失效的规范性文件目录予以公布，继续有效的规范性文件请按照执行，宣布废止或失效的规范性文件自本通知下发之日起不再执行。

附件：1.规范性文件清理结果目录（一）（继续有效的规范性文件）

2.规范性文件清理结果目录（二）（废止或失效的规范性文件）
