# 【已废止】吐政办〔2017〕175号关于印发吐鲁番市运动员教练员奖励实施办法的通知

各区县人民政府、示范区管委会，市政府各部门、各直属机构：

《吐鲁番市运动员教练员奖励实施办法》已经市政府同意，现印发你们，请认真贯彻执行。

吐鲁番市人民政府办公室

2017年10月9日

吐鲁番市运动员教练员奖励实施办法

第一条   为实现吐鲁番市奥运会、亚运会、全运会金牌零的突破，促进全市竞技体育的可持续发展，充分调动全市各体育训练单位、教练员培养高水平体育后备人才的主动性、积极性，根据《新疆维吾尔自治区参赛各类大型运动会奖励办法》（新政办发〔2013〕128号）有关规定，特制定本办法。

第二条   奖励资金主要用于对吐鲁番市竞技体育做出特殊贡献的单位和个人。具体指在奥运会、世界杯、世锦赛、亚运会、全运会、自治区全运会、自治区锦标赛上夺得前三名的运动员及培养、输送该运动员的教练员和培训单位；输送到自治区优秀运动队的运动员及培养教练员和培训单位。

第三条   奖励资金由吐鲁番市文化体育广播影视局通过多种方式筹集，保持奖励资金账户不少于一百万元。

第四条   奖励资金由资助方和吐鲁番市文化体育广播影视局共同管理，在吐鲁番市文化体育广播影视局设立奖励资金专户。

第五条   根据运动员参加重要比赛的级别分为四个档次，对获得前三名的运动员及培养教练员和培训单位给予奖励，对输送到自治区优秀运动队的运动员及培养教练员单位和训练单位给予奖励，具体奖励标准见附表。

第六条   对年度符合奖励标准的单位和个人进行造册，在奖励资金账户中提取相应的资金进行奖励，并在有关媒体公布、公示。根据运动员所获荣誉的重要程度确定奖励仪式的规格与规模。

第七条   本办法由吐鲁番市文化体育广播影视局负责解释。

第八条   本办法自2017年12月1日起执行。

附件：吐鲁番市运动员、教练员奖励标准
