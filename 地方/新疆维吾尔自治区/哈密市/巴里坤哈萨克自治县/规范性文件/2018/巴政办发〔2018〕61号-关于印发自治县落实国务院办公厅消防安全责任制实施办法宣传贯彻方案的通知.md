# 关于印发自治县落实国务院办公厅消防安全责任制实施办法宣传贯彻方案的通知

巴政办发〔2018〕61号

关于印发自治县落实国务院办公厅消防安全责任制实施办法宣传贯彻方案的通知

各乡（镇）人民政府、农牧场区，各有关单位：

《巴里坤哈萨克自治县落实国务院办公厅消防安全责任制实施办法宣传贯彻方案》已经县人民政府研究同意，现印发给你们，请认真贯彻落实。

2018年6月20日

巴里坤哈萨克自治县落实国务院办公厅消防

安全责任制实施办法宣传贯彻方案

为深入贯彻落实《消防安全责任制实施办法》（国办发〔2017〕87号）（以下简称《办法》），进一步完善消防工作责任体系，不断提高公共消防安全水平，为自治县经济社会发展、人民群众安居乐业创造良好的消防安全环境，按照自治区人民政府关于《办法》的宣贯通知要求，切实做好《办法》宣传贯彻工作，结合自治县实际，制定本方案。

一、工作目标

以习近平新时代中国特色社会主义思想为统领，紧紧围绕社会稳定和长治久安总目标，充分利用各类宣传媒介，迅速组织开展内容丰富、形式多样、声势浩大、贴近群众的宣贯活动，深入宣传《办法》的精神实质和主要内容。

二、工作步骤

（一）动员部署阶段（2018年6月10日前）。

组织广大干部职工尤其是领导干部，认真学习领会《办法》的主要内容、精神实质，进一步统一思想，真正掌握《办法》出台的意义、确定的原则和明确的目标任务，各乡（镇）、各部门（单位）负责人要专题学习《办法》，并结合国务院消防工作考核内容要求，指导如何做好消防工作，切实增强履行消防职责的能力。

（二）集中宣传贯彻阶段（2018年6月10日至9月30日）。

1．依托村（社区）宣传栏或横幅，不断更新《办法》宣传贯彻内容，扩大宣传覆盖面和影响力，6月25日前全部张贴到位。责任主体：各乡（镇）

2．各乡（镇）、各部门（单位）要利用政治学习深入开展《办法》学习活动，全面提高公民消防法律素质，不断提升全社会抗御火灾的整体能力，促进社会和谐稳定，于6月25日前全部干部职工培训到位。责任主体：各乡（镇）、县公安局、县住建局、县市场监督管理局、县文广新局、县教育局、县卫计委、县安监局、县民政局

3．利用户外屏幕、大型广告牌、楼宇电视、LED显示屏等宣传阵地滚动播出《办法》宣传贯彻标语，营造良好的工作氛围， 6月25日前在户外媒体滚动播放。责任主体：县消防大队

4．县广播电视台播出专题节目，解读《办法》颁布实施重要意义，播出宣传贯彻工作动态信息。巴里坤政府网、“零距离”要发布《办法》原文，宣传报道工作动态及典型做法。责任主体：县委宣传部、县文广新局

5．将《办法》宣传贯彻工作纳入各级干部培训计划中，在2018年党校主体班中开设培训课程，充分调动一切宣传力量，利用一切宣传阵地，深入宣传《办法》的精神实质和主要内容。责任主体：县委党校

（三）建章立制

各乡（镇）、各部门（单位）结合实际制定具体的消防安全责任制实施措施，进一步深化政府统一领导、部门依法监管、单位全面负责、公民积极参与的消防工作格局，健全落实社会消防工作长效机制，提升消防安全管理水平。

三、工作要求

（一）高度重视，精心组织。各乡（镇）、各部门（单位）要站在为落实总目标而创造良好消防安全环境的高度，把《办法》宣传贯彻工作作为当前的一项重点工作，集中力量，大张旗鼓地开展内容丰富、形式多样的社会化宣传教育和培训活动，力争在最短时间内使《办法》走进机关单位，走进千家万户。

（二）严格标准，务求实效。各乡（镇）、各部门（单位）要组织全体干部职工进行集中学习，真正领会《办法》的精神要旨，坚持学以致用，用《办法》指导工作实践。重点做好党校、党政机关、企事业单位、消防安全重点部位的宣传，切实培养出管理层面的消防“明白人”。

（三）强化协作，整体推动。各相关部门要加强协作配合，形成整体合力，紧紧围绕宣传贯彻《办法》，组织开展有针对性、有声势、有特色的宣传贯彻活动，全面推动《办法》各项内容落到实处。

（四）及时报送宣传贯彻情况。各乡（镇）、各部门（单位）及时制定宣传贯彻方案，于6月8日前将宣传贯彻方案（纸质版加盖公章）报送至县消防大队参谋室，每月30日前（截止10月）将《国务院办公厅〈消防责任制实施办法〉宣传贯彻情况统计表》及相关图片、截图等佐证资料（纸质版加盖公章）报送至县公安消防大队。
