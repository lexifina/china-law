# 关于印发库尔勒市粮食生产功能区和重要农产品生产保护区划定与建设工作方案的通知

各乡、镇、场，各有关单位：

根据自治区人民政府《关于建立粮食生产功能区和重要农产品生产保护区的实施意见》（新政发〔2018〕28号），自治区农业厅、国土资源厅、发改委《新疆维吾尔自治区粮食生产功能区和重要农产品生产保护区划定与建设工作方案》（新农技〔2018〕109号）及关于印发《巴州粮食生产功能区和重要农产品生产保护区划定与建设工作方案》（巴政发〔2018〕120号）文件精神，确定库尔勒市划定粮食生产功能区以正播玉米为主，面积5万亩；重要农产品保护区以棉花为主，面积120万亩。为统筹推进我市粮食生产功能区和重要农产品生产保护区（以下简称“两区”）划定与建设工作，结合实际，制定本方案。

一、总体要求

（一）划定目标

力争用3年时间完成库尔勒市125万亩“两区”地块的划定任务，其中：玉米生产功能区5万亩，棉花生产保护区120万亩，做到全部建档立卡、上图入库，实现信息化和精准化管理；力争用5年时间基本完成“两区”建设任务，形成布局合理、数量充足、设施完善、产能提升、管护到位、生产现代化的粮食生产功能区和重要农产品生产保护区，确保我市农业产业水平有效提升。

（二）划定标准

“两区”划定具备以下条件：一是基础条件相对较好。水土资源条件较好，坡度在15度以下的永久基本农田；相对集中连片，原则上连片面积不低于500亩；农田灌排工程等农业基础设施比较完备，生态环境良好，未列入退耕还林还草、耕地休耕试点及城乡发展规划用地等范围；优先将已建成的高标准农田、规划建设的高标准农田及具备改造条件的永久性基本农田划入“两区”。新划定的“两区”农田土地利用现状应当是耕地，耕地内的作物现状应当是粮棉等作物。二是生产相对稳定。具有玉米和棉花的种植传统，近三年播种面积基本稳定。三是功能作用长期有保障。结合永久基本农田划定成果，与主体功能区、新一轮土地利用、城乡建设、交通运输、水利等规划衔接，确保划定的“两区”在较长时间内不被重大建设征占用。

（三）划定要求

按照划定标准和《粮食生产功能区和重要农产品生产保护区划定技术规程》的相关要求，以第二次全国土地利用现状调查和永久基本农田划定的图件、数据为基础，结合农村土地承包经营权确权登记颁证工作，将划定任务落实到具体地块并统一编号，明确土地面积、灌排工程条件、作物类型、承包经营主体和土地流转等信息。依托国土资源遥感监测“一张图”和综合监管平台，建立电子地图和数据库，建档立卡、登记造册。

（四）划定依据

综合考虑我市各乡镇场（含国家农作物原种场，以下简称“各乡镇场”）农业资源禀赋、发展潜力、产销平衡等情况，结合我市粮棉生产实际，玉米生产功能区划定主要依据各乡镇场热量条件、种植区划和综合生产能力等因素，划分为1个片区（正播晚熟区）、涉及16个乡镇场；棉花生产保护区划定主要依据各乡镇场积温、无霜期、水资源条件和综合生产能力等因素，划定为1个片区（早中熟棉区）、涉及16个乡镇场。

二、划定类别及区域

（一）粮食生产功能区。以正播玉米为主，划定生产功能区5万亩，涉及7乡2镇7个国有农牧场（详见附件2）；

（二）重要农产品生产保护区。以棉花为主，划定生产保护区120万亩，涉及7乡2镇7个国有农牧场（详见附件2）。

三、工作要求

（一）科学统筹划定工作

各相关单位、乡镇场要强化互联互通，紧密结合实际，统筹资源禀赋、发展潜力、产销平衡等情况，衔接土地利用、农业发展、城乡（郊）建设、交通建设等规划，结合永久基本农田划定和农村土地承包经营权确权登记颁证工作，站在全局高度，认真谋划确定“两区”划定区域，制定工作方案，明确工作目标，统筹规划“两区”划定工作。

（二）分解落实划定任务

根据自治区、自治州下达的“两区”划定任务和我市现有永久基本农田保护面积以及粮食和重要农产品实际种植面积情况，市政府将划定任务分解落实到各乡镇场，各乡镇场在综合考虑自身实际情况的基础上，按照划定标准和任务，将“两区”面积细化分解到村（组）、分场（队）。

（三）稳步推进划定工作

根据“3年划定、5年完成”的总体要求，按照“科学统筹、分步实施、稳步推进”的原则，2019年在7乡2镇7个国有农牧场完成玉米生产功能区5万亩的划定工作；在7乡2镇7个国有农牧场完成棉花生产保护区120万亩的划定工作，2021年前完成“两区”划建工作。

（四）摸清划定区域情况

以乡镇场为基础，采取内业、外业相结合的方式，在摸清区域地块情况的基础上，推动划定工作。一是搜集永久基本农田划定、第二次全国土地调查有关图件、影像等数据资料，确定“两区”划定的初步区域范围，开展图上作业；二是实地调查核对划入“两区”地块情况，搜集划入地块基本信息等；三是完善“两区”划定图斑，形成准确的图斑和数据。

（五）全面形成划定结果

根据工作要求，做好“两区”划定数据测绘搜集，开展上图入库、建档立册，并逐级汇总地块图斑及信息，形成上下衔接、规范统一的信息系统。每季度3号前将“两区”划定地块图斑和数据汇总报送市农业局。在加强数据安全保障，保证“两区”信息安全的前提下，实现信息互通、资源共享。

四、进度安排

（一）谋划部署阶段（2018年12月—2019年1月）。根据实际，细化制定具体实施方案，将任务分解落实到乡镇场、村（组、队）；启动“两区”划定工作，开展宣传发动、组织学习培训、组建技术队伍、开展技术培训、做好前期准备等工作。

（二）重点推进阶段（2019年2月—2019年3月）。在普惠一乡三场试点开展划定工作。划定工作由市人民政府统一协调，组织实施。技术保障由自治区统一招标的技术单位负责。一要依次进行图上作业和实地调查核对，完成玉米生产功能区、棉花生产保护区划定的底图制作、统一编码、实地勘查、面积量算、分布图编制等，标明“四至”及拐点坐标，形成准确图斑和数据；二要进行划定图件的审核公示并设立标志牌；三要整理“两区”划定的基础资料、图件、表册和文本成果，经质量检查合格后，通过软、硬件系统设备，建立“两区”电子地图和数据库，建档立卡，登记造册。

（三）总结验收阶段（2019年4月—2019年5月）。完成普惠一乡三场玉米生产功能区和棉花生产保护区的划定任务。开展阶段性总结，为全市其他乡镇场完成划定任务积累经验，提供样板。

（四）全面完成阶段（2019年6月—2019年8月）。全面完成库尔勒市玉米5万亩，棉花120万亩的“两区”划定任务。

（五）核查验收阶段（2019年9月—2019年11月）。采取审核、检测和实地抽查相结合的方式对划定成果检查验收。在技术依托单位对划定成果自检自验基础上，各乡镇场公告公示划定成果、市人民政府牵头组织检查验收，撰写总结验收材料。经检查验收合格后，市农业局会同市档案局，做好“两区”划定成果档案资料整理、归档、统计和汇交等工作，形成库尔勒市“两区”布局电子地图和数据库，并做好迎接州、区“两区”划定工作的检查验收。

五、保障措施

（一）加强组织保障。成立库尔勒市“两区”划定工作领导小组（详见附件1）。办公室设在市农业局，分设综合协调组、技术服务组、专家指导组，工作人员从成员单位抽调。

（二）明确部门分工。各有关部门要加强指导、明确分工、落实责任、加强协作，确保各项任务落到实处。“两区”划定具体工作由市农业局牵头，市农业局、国土资源局、发改委、财政局会同有关部门确定“两区”划定任务，制定相关划定、验收、评价考核操作规程和管理办法，做好上图入库工作。市国土资源局负责提供永久基本农田划定成果等资料；市水利局负责提供农田水利建设现状及规划等资料；市农经局负责提供农村土地确权登记颁证成果等资料；市发改委会同有关部门做好统筹协调，适时组织第三方评估。市财政局会同有关部门加强财政补贴资金的统筹和整合，优化资金使用方向。

（三）强化宣传培训

充分利用各种新闻媒体、周一升国旗、干部下沉基层、农民夜校等方式，开展多层次、多形式、持续性的宣传，营造良好的工作环境和舆论氛围。加强基层领导、干部培训力度，确保基层干部、技术人员全面领会政策文件精神，熟悉业务操作流程，明确划定方法，掌握操作要领，提高技术水平，确保“两区”划建工作有理、有序、有效推进。

（四）加强监督考核

市人民政府将与相关单位和各乡镇场签定责任书，并把“两区”划定纳入相关单位、各乡镇场年底绩效考评，建立“两区”划定工作联席会议制度，定期听取“两区”划定工作汇报，及时研究解决划定工作中出现的问题。同时强化对“两区”划建和管护工作的监督检查、评价考核和追责问责，对工作棚架、落实不到位、敷衍塞责严重影响工作进程的，将依法依规严肃处理。
