# 关于印发库尔勒市整治“保健”市场乱象百日行动工作方案的通知

各乡、镇、场，各街道办事处，市政府各部门，市属各单位：

《库尔勒市整治“保健”市场乱象百日行动工作方案》经市人民政府同意，现印发你们，请认真贯彻落实。

库尔勒市人民政府办公室

2019年2月1日

库尔勒市整治“保健”市场乱象百日行动工作方案

为深入贯彻落实党中央、国务院领导重要批示精神，规范“保健”市场经营秩序，治理“保健”市场乱象，维护消费者合法权益，促进社会和谐稳定，按照国家市场监督管理总局等13部委《关于开展联合整治“保健”市场乱象百日行动的通知》（国市监竞争〔2019〕12号）和自治区市场监督管理局等12部门《关于印发<开展联合整治“保健”市场乱象百日行动工作方案>的通知》（新市监竞〔2019〕19号）及《巴州联合整治“保健”市场乱象百日行动工作方案》要求，决定自2019年1月8日至4月下旬在全市联合开展打击、清理、整顿“保健”市场乱象百日行动（以下简称百日行动），现结合我市实际，制定方案如下：

一、指导思想及总体要求

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党中央、国务院领导对整治“保健”乱象的重要批示精神，提高政治站位，牢固树立以人民为中心的发展理念，紧紧围绕社会稳定和长治久安总目标，从维护社会和谐稳定、保障和改善民生的高度，充分认识开展“百日行动”的重要意义。加强对重点行业、重点领域、重点行为的事中事后监管，依据《反不正当竞争法》《广告法》《产品质量法》《食品安全法》《消费者权益保护法》《电子商务法》《价格法》《旅游法》《中医药法》《老年人权益保障法》《直销管理条例》《禁止传销条例》《无证无照经营查处办法》《医疗机构管理条例》《互联网信息服务管理办法》等法律法规，严厉查处各种违法行为，集中查办、曝光一批典型案件，形成高压态势，有效遏制“保健”市场乱象，探索建立长效机制，切实增强人民群众获得感、幸福感、满意度。

三、整治重点

（一）重点行业及领域：与人民群众日常消费密切相关的保健食品、药品、医疗器械以及宣称具有“保健”功能的其他食品、器材、用品、用具等相关日用消费品；宣称具有“保健”功能的净水器、空气净化器等日用家电；宣称具有“保健”功能的金银玉器等穿戴用品；宣称具有“保健”功效的服务等。

（二）重点场所及区域：提供会议营销活动的写字楼、宾馆酒店；容易发生“保健”产品推销活动的居民区、旅游区、农村场镇、农村集市、城乡结合部以及公园、车站、码头等人员密集场所；销售对象主要为老年、病弱群体的“保健”类店铺。

（三）重点时段：春节等节假日、“3·15”国际消费者权益日等。

（四）重点行为：对商品和服务作虚假或引人误解的商业宣传行为；发布虚假违法广告行为；保健食品中非法添加非食用物质及宣传治疗作用的行为；制售假冒伪劣产品行为；无证无照经营行为；价格违法行为；故意拖延或无理拒绝消费者合理要求行为；违规直销和传销行为；未经许可经营旅行社业务行为；以“保健”为名开展的各种违法违规行为等。

四、任务分工

（一）严厉查处虚假宣传行为。一查明示或暗示食品或日用品具有保健、疾病预防或者治疗等功能，对商品作虚假或者引人误解的商业宣传行为；二查假借健康讲座、专家义诊、免费检查、免费体验、赠送礼品、组织旅游等形式，向老年、病弱等特定群体作虚假或者引人误解的商业宣传的行为；三查利用国家机关、医疗单位、学术机构、行业组织的名义，或者以专家、知名人士、医务人员和消费者等名义，对商品作虚假或者引人误解的商业宣传行为；四查经营者对其自身资质、所获荣誉等经营者信息作虚假或者引人误解的商业宣传行为；五查利用虚构原价、虚假打折、不明码标价等价格违法手段对商品作虚假或者引人误解的商业宣传行为。（市工商局、市食药局牵头，市卫计委、市民政局等部门配合）

法律依据：《反不正当竞争法》《价格法》《老年人权益保障法》等。

（二）严厉查处非法组织会议营销行为。一查在许可登记的经营场所外，集中招徕消费群体组织销售食品、保健食品、医疗器械等商品的违法行为；二查流窜各地开展会议营销活动无营业执照、无食品、药品经营许可证的无照经营行为；三查利用会议营销模式销售“三无”产品、不合格产品、“傍名牌”产品或质次价高产品行为；四查在会议营销活动中发布虚假广告或利用现场演说进行虚假宣传的欺骗性销售行为；五查在会议营销活动中采取雇用“托儿”假装购买和多次退返上次小额购物款的引诱式销售行为；六查利用会议营销模式非法招募直销员、违规组织直销培训，发展传销人员、开展传销活动的行为；七查为非法会议营销提供场所等便利条件的行为。（市食药局牵头，市工商局、市住建局、市文体广影局、市旅游局等部门配合）

法律依据：《食品安全法》《无证无照经营查处办法》《反不正当竞争法》《广告法》《直销管理条例》《禁止传销条例》等。

（三）严厉查处组织虚假交易的违法行为。一查网络交易领域“刷单炒信”，使消费者对产品的销售状况产生误解的行为；二查缺乏科学的评奖依据和评奖标准，组织虚假的商品或者经营者荣誉评比的违法行为；三查为虚假宣传行为提供技术手段等其他便利条件，帮助他人进行虚假宣传的违法行为。（市工商局牵头，市党委网信办等部门配合）

法律依据：《反不正当竟争法》等。

（四）严厉查处重点领域广告违法行为。一查医疗、药品、医疗器械、保健食品等重点领域的违法广告，以互联网、电视、广播、报刊、户外为重点媒介，重点查处含有断言功效、保证安全性、说明治愈率等内容的违法广告；二查欺骗、误导消费者的虚假广告，重点查处违法广告代言行为，严禁利用健康养生节目栏目变相发布医疗、药品、医疗器械、保健食品广告；三是加大对互联网广告的监测力度，构成犯罪的，依法追究刑事责任。（市工商局牵头，市食药局、市公安局、市文体广影局、市党委网信办等部门配合）

法律依据：《广告法》《互联网信息服务管理办法》等。

（五）强化完善保健食品市场管理。加强保健食品生产、经营环节监管，加大监督抽检力度，确保保健食品生产经营者严格按照《食品安全法》开展生产经营活动。重点查处保健食品的标签、说明书与注册或者备案的内容不一致，保健食品中非法添加非食用物质等违法行为。（市食药局牵头，市工商局、市质监局等部门配合）

法律依据：《食品安全法》等。

（六）严厉查处以“保健”为名开展的各种违法违规行为。重点查处以中医药“预防”、“保健”、“治未病”等为名，或假借医学理论和术语欺骗、诱使、强迫消费者接受非法诊疗，谋取不正当利益的行为。（市卫计委牵头，市食药局、市工商局等部门配合）

法律依据：《中医药法》《医疗机构管理条例》等。

（七）严厉查处制售假冒伪劣产品行为。重点查处伪造产品产地，伪造或者冒用他人的厂名、厂址，伪造或者冒用认证标志等质量标志，掺杂、掺假，以假充真、以次充好，以不合格产品冒充合格产品等违法行为。以农贸集市、边远农村为重要区域严厉打击侵害农村消费群体的制售假冒伪劣产品行为，构成犯罪的，依法追究刑事责任。（市工商局、市食药局、市公安局、市质监局等部门按职责落实，各成员单位按职责落实）

法律依据：《产品质量法》《食品安全法》等。

（八）加大对故意拖延或无理拒绝消费者合理要求行为的监管力度。重点查处对消费者提出的修理、重作、更换、退货、补足商品数量、退换货和服务费用或者赔偿损失等合理要求，故意拖延或者无理拒绝的行为，依法维护消费者的合法权益。（市工商局牵头，各成员单位按职责落实）

法律依据：《消费者权益保护法》等。

（九）严厉查处传销和违规直销行为。一是重点打击以“资本运作”、“连锁销售”、“电子商务”、“基金发售”、 “红色旅游”、“原始股投资”、“消费储蓄”、“网络资本运行”、“网络游戏”等名义开展的传销和网络传销行为；二是重点打击直销企业及其分支机构以直销为名从事传销的行为；三是重点查处直销企业及其分支机构（经销商）的虚假宣传行为，依法严厉打击通过寻找特定群体锁定顾客群，利用产品招商会、推介会、分享表彰会等方式，打着直销旗号，以直销企业名义在产品推销过程中作夸大或虚假宣传行为；四是重点查处直销企业及其分支机构违规组织直销培训、违规招募直销员、擅自在未批准区域开展直销业务等违规违法行为。（市公安局、市工商局、市商经委按职责落实，各成员单位按职责落实）

法律依据：《反不正当竟争法》《直销管理条例》《禁止传销条例》等。

（十）严厉打击未经许可经营旅行社业务的行为。重点查处以免费赠送旅游为噱头销售“保健”产品（服务），并组织消费者进行旅游活动的行为。（市食药局、市旅游局、市文体广影局按职责落实，各成员单位按职责落实）

法律依据：《反不正当竞争法》《旅游法》等。

（十ー）加强线上线下一体化监管。一是严格落实网络实名制管理要求，强化ICP备案、域名和IP地址等互联网基础资源管理；二是查处互联网领域的虚假宣传、虚假广告、销售假冒伪劣产品、网络传销等违法行为；三是加强对网络自媒体发布虚假信息的清理，依法处置违法违规平台、账号等，进一步加强对辖区内电子商务平台的指导和规范。（市党委网信办、市工商局按职责落实，各成员单位按职责落实）

法律依据：《反不正竞争法》《禁止传销条例》《电子商务法》《互联网信息服务管理办法》等。

五、工作措施及进度

整治“保健”市场乱象百日行动时间安排：从2019年1月8日开始，为期100天，分三个阶段进行。

（一）宣传及排查阶段（1月8日至1月13日）

通过各投诉举报热线平台、案件管理等系统，梳理近年来与“保健”市场违法行为相关的投诉举报、行政处罚案件、“双随机”抽查、产品抽检、部门转办、媒体曝光等发现的突出问题，应用大数据分析，确定重点检查对象。充分利用网络、广告、直销监测平台，加强风险分析研判，提高“百日行动”的针对性、预见性。通过电视、报纸、网络等媒体，并采取发放宣传资料、约谈经营者等方式，加强对“百日行动”的集中宣传，引导广大消费者树立正确消费理念，提高对“保健”市场违法营销的防范意识和识别能力。及时报道行业动态，树立正确的舆论导向。向经营者广泛宣传法律法规知识，引导教育其自觉守法经营，督促整改涉嫌违法行为。公布投诉举报方式，畅通投诉举报渠道，鼓励广大群众积极参与，最大限度拓展信息来源。

（二）集中执法阶段（1月14日至4月18日）

针对重点行业、重点领域、重点行为集中开展监督检查和案件查处。

一是开展执法专项检査。各成员单位要安排执法人员，针对重点行业和领域开展专项监督检查，对采用会议、讲座等形式进行聚众式营销活动的，采取突击检查、现场监管等方式，加大实地监督，发现涉嫌违法的迅速取证并采取相应执法措施。

二是开展对重点企业的突击检查。对排查摸底和宣传发动阶段发现的有较大违法嫌疑的经营者，开展全方位监督检查，重点查看企业证照、宣传资料、员工培训资料和销售模式等，深入挖掘搜集违法证据。

三是严肃查处违法违规行为。对有证据证明涉嫌违法的经营者，及时依法立案调查，重点查处一批情节严重、性质恶劣、社会反响强烈的违法案件。

四是开展集中约谈，加强行政指导。对“百日行动”中发现的问题，召集重点企业、相关经营者、行业协会，通报查处的典型案例，提出进一步规范的要求，督促自觉整改违法行为。

（三）总结提升阶段（4月下旬）

各成员单位对“百日行动”中的好经验、好做法进行总结，提炼形成规范“保健”市场的有效监管模式，进行宣传推广，推动建立库尔勒市“保健”市场长效监管机制。

六、工作要求

（一）统一思想认识。“保健”市场乱象是长期存在的顽疾，社会反响强烈，人民群众深恶痛绝。各成员单位务必高度重视，统一思想，以对人民群众高度负责的态度，切实把整治“保健”市场乱象百日行动作为当前重点工作，抓紧抓好，抓出成效。

（二）强化责任落实。各成员单位要严格按照方案要求，突出重点，措施有力，确保“百日行动”各项任务落到实处。建立健全工作责任制和责任追究制，对责任不落实、监管不作为、情况不报告、问题不解决的单位和工作人员，要严肃追究责任。

（三）注重综合治理。要发挥部门间协同机制，统筹发挥职能作用，综合运用多种手段，通过检查抽检、约谈企业、信息公示、下架召回、警示处罚、信用惩戒、撤销吊销、行刑衔接等，形成“百日行动”的震慑力，达到査处一批案件，规范一个行业的目的。

（四）加强社会共治。鼓励群众对违法行为投诉举报，通过法律武器维护自身权益。要公开举报渠道，充分发挥新闻媒体的作用，对“百日行动”中查处的典型案件进行宣传报道。鼓励行业协会建立健全行业规范和自律机制，引导和督促行业依法生产经营，推动行业诚信建设，科普产品常识。

（五）及时报送信息。各成员单位要建立百日行动信息报送制度，加强信息报送工作，安排专人负责，及时上报工作开展情况和查办的案件情况。每月5日和20日前报送“百日行动”情况统计表，2019年4月10日前报送本单位“百日行动”工作总结（包括整体情况、主要措施、存在的问题、下一步工作安排、工作图片等）。各成员单位要将本单位工作情况报送库尔勒市整治“保健”市场乱象百日行动专项工作组办公室。各单位要确定一名联络员，2月17日前，将联络员的姓名、单位、职务、工作电话、手机、电子邮箱纸质版领导签字加盖单位公章后报送至市工商局201办公室，电话：0996-2501831 ，联系人：王军，秦瑶。
