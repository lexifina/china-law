# 关于印发库尔勒市2019年地下水超采区治理工作方案的通知

各乡、镇、场，各有关单位：

为完成我市地下水超采综合治理任务，构建治理长效机制，推动地下水超采常态化治理，根据《库尔勒市地下水超采区治理方案》（2016年-2030年）、《库尔勒市地下水超采区综合治理规划》（2016年-2030年）文件精神，结合实际，特制定本方案。

一、总体要求

（一）指导思想

坚持“节水优先、空间均衡、系统治理、两手发力”的新时期治水方针，积极推动实施国家节水行动，以实现地下水采补平衡、良性循环及水资源可持续利用为目标，构建适水发展的农业种植体系、高效节水的灌溉工程体系、科学合理的水资源配置体系，持续压减地下水超采量，促进水资源与经济社会及生态环境协同发展。

（二）基本原则

坚持目标导向，推动任务落实。以完成地下水超采治理阶段目标为导向，坚持建设管理并重、治理保护同步，确保压采目标实现。

坚持节水优先，综合治理施策。强化水资源承载能力刚性约束，量水而行、以水定产，合理控制水资源开发程度，提高水资源利用效率，根据水资源状况、水源条件、种植结构等因素，因地制宜确定地下水超采综合治理措施。

坚持政府主导，社会共同参与。充分调动全社会各方面积极性、主动性、创造性，努力使广大群众成为节水压采的实施主体、受益主体，推进地下水超采综合治理工作常态化、可持续。

（三）治理范围

本次治理范围为库尔勒市全部行政区域。

二、治理目标

根据《库尔勒市地下水超采区治理方案》（2016年-2030年）文件要求，2019年压减地下水超采量为8126万m3。

三、治理措施

（一）退地减水

持续推进退地减水工作，库尔勒市2019年退地任务为6.16万亩。

（二）高效节水

加快节水灌溉工程建设和技术推广，实施高效节水工程，库尔勒市2019年新增高效节水面积为4万亩。

（三）落实最严格水资源管理制度

严格落实“三条红线”，健全取用水总量控制指标体系，建立覆盖全市行政区域的取用水总量控制指标体系，切实保障用水总量与当地水资源、水环境承载能力相适应。

（四）完善水资源监测体系

严格机电井取水计量管理，实行井电双控取用地下水管理制度。加快推进水资源监控能力建设，完善井电双控地下水资源监控平台，提高水资源管理信息化、现代化水平。

（五）严格取用地下水管理

地下水禁采区严禁新打取水井，不得新增地下水取水量；地下水限采区除生活用水更新井外，一般不得开凿新的取水井。严格执行取用地下水审批规定，未经审批的取水井，电力部门一律不得安装供电设施。

（六）切实加大执法力度

按照《中华人民共和国水法》、《新疆维吾尔自治区取水许可管理办法》、《新疆维吾尔自治区地下水资源管理条例》，整合机构职能，明确事权责任，强化地下水监督管理执法工作，开展水利、国土、环保、林业、农业联动机制，严厉打击各种水事违法行为，对拒不缴纳地下水费的用水户，情节严重的，吊销取水许可证，协同电力和各乡镇场采取断电、封井措施，依法从严查处非法取用地下水行为，确保地下水资源的有序监管。

四、保障措施

（一）加强组织领导

我市是一个水资源严重匮乏的城市，各乡镇场、各有关单位要充分认识地下水压采的重要性和必要性，充分认识地下水压采治理是一项紧迫而意义深远的工作，以高度的整治责任感抓好地下水压采工作。切实履行职责，强化组织领导，认真安排部署，加强各单位、部门配合，统筹各方利益，加大工作力度，完善地下水管理方面的制度措施，保证地下水超采区治理顺利实施。

（二）落实目标任务

各乡镇场必须按照《库尔勒市2019年地下水压采量计划表》（详见附件），严格计划用水管理，严格落实定额指标，确保完成年度地下水超采区治理任务。

（三）加大宣传力度

各乡镇场、各相关单位要加大地下水超采治理宣传力度，充分结合“世界水日”“中国水周”等重要节日，利用报纸、电视、网络等强势媒体，利用周一升国旗、农牧民夜校、下沉入户走访等，广泛宣传，营造氛围，全力助推形成共识。

附件：库尔勒市2019年地下水压采量计划表
