# 关于成立第三届法律专家咨询委员会的通知

各乡、镇、场、市政府各部门、市属各单位：

法律专家咨询论证制度是建设法治政府，推进政府决策科学化、民主化、法制化的必然要求，是落实国务院《全面推进依法行政实施纲要》和《关于加强法治政府建设的意见》的重要举措。市人民政府决定成立第三届法律专家咨询委员会，聘请蒋家开等15名同志为市人民政府第三届法律专家咨询委员，聘期2年（2019年1月1日至2020年12月31日）。法律专家咨询委员要按照《库尔勒市人民政府法律专家咨询工作规则》的要求，结合政府事务发挥自身专业优势，积极负责地履行职责，为库尔勒市法治政府建设发挥积极作用。
