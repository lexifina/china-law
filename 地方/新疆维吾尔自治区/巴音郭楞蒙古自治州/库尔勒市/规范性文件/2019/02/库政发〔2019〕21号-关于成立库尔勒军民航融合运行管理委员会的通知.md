# 关于成立库尔勒军民航融合运行管理委员会的通知

各乡、镇、场，各街道办事处，市政府各部门，市属各单位，库尔勒机场：

为贯彻落实中央、自治区、自治州关于军民融合发展重大战略思想，根据十九届中央军民融合发展委员会第二次会议通过的《“十三五”国防科技工业发展规划》、《关于推动国防科技工业军民融合深度发展的意见》、《“十三五”期间推动军事后勤军民融合深度发展的实施意见》意见，经库尔勒市人民政府、中国人民解放军94040部队、中国人民解放军94062部队与新疆机场（集团）有限责任公司库尔勒机场研究决定，成立库尔勒军民航融合运行管理委员会，委员会组成人员及主要职责如下：

二、工作职责

（一）传达贯彻国务院、中央军委、空军、民航局、自治区有关军民合用机场融合发展工作指示精神。

（二）研究确定军民航深度融合的总体方案和保障措施。

（三）统筹协调解决全局性、跨单位的运行保障问题。

（四）指导、推动、督促军民航深度融合发展政策法规落实。

（五）审定各类协议、工作计划、专业保障预案、联合演练方案。

（六）“低、慢、小”飞行器防控及应急处置。

（七）净空，鸟情，自然环境联合巡视，分析及防控。

（八）总结分析库尔勒军民合用机场管理情况，推广军民融合好的经验做法。

（九）需要委员会决策的其它事项。

三、机构设置

委员会下设办公室，办公室设在库尔勒（且末、若羌）机场，办公室主任由胡海宽同志兼任，办公室副主任由倪海峰、刘建辰同志兼任，贾天鹏、孙宾同志负责联络，办公室主要负责：1.协调处理军民深度融合的日常工作；2.组织筹备联席会议；3.制定人员联合培训计划，并组织实施；4.督促检查工作计划的落实；5.完成委员会交办的其它事项。

四、工作制度

（一）委员会联席会议至少每半年召开一次，由委员会主任或副主任主持。遇有特殊情况或必要时，可由委员会主任或副主任决定临时召开。

（二）委员会的日常事务由委员会办公室负责承办，并负责委员会的会务及文秘工作，负责委员会决议或落办事项的督查，并向委员会报告。

（三）委员会的议题可由委员会主任或者副主任确定或委员会委员或委员会办公室提出，议题经审核确定后，于会前1日送交委员会办公室。

（四）委员会形成的文字及音像文件材料，由委员会办公室严格按照相关保密规定负责收集、整理、移交归档。
