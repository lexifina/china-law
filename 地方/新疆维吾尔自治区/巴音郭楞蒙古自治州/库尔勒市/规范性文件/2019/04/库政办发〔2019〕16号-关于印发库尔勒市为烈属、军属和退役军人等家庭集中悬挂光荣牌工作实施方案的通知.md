# 关于印发库尔勒市为烈属、军属和退役军人等家庭集中悬挂光荣牌工作实施方案的通知

各乡、镇、场，各街道办事处，市政府各部门，市属各单位：

《库尔勒市为烈属、军属和退役军人等家庭集中悬挂光荣牌工作实施方案》已经市人民政府研究同意，现印发你们，请认真组织实施。

库尔勒市人民政府办公室

2019年4月1日

库尔勒市为烈属、军属和退役军人等家庭集中悬挂光荣牌工作实施方案

为认真落实《国务院办公厅关于印发〈为烈属、军属和退役人等家庭悬挂光荣牌工作实施办法〉的通知》（国办发﹝2018﹞72号）、《自治区退役军人事务厅关于印发〈为烈属、军属和退役军人等家庭集中悬挂光荣牌工作实施方案〉的通知》（新退役军人发电﹝2019﹞14号）有关要求，弘扬拥军优属优良传统，推进军人荣誉体系建设，切实做好全市悬挂光荣牌工作，制定本方案。

一、悬挂光荣牌工作的重要意义

悬挂光荣牌工作是贯彻落实习近平总书记关于加强退役军人管理保障、健全服务保障体系、完善相关政策制度、维护军人军属合法权益等一系列重要指示批示精神的具体体现；是落实中央决策部署、弘扬拥军优属优良传统、推进军人荣誉体系建设、贯彻落实新疆社会稳定和长治久安总目标的重要举措，是维护烈属、军属和退役军人等合法权益的重要标识，是开展革命传统教育、做好优抚工作的重要内容，对提高退役军人社会地位、崇高职业，增强荣誉感、使命感、幸福感，激发广大官兵爱国强军、巩固国防具有重要意义。

二、悬挂对象

悬挂光荣牌对象为烈士遗属、因公牺牲军人遗属、病故军人遗属（以下统称“三属”）家庭和中国人民解放军现役军人（以下简称现役军人）家庭、退役军人家庭。

同时具备两个以上悬挂光荣牌条件的家庭，只悬挂一个光荣牌。

三、悬挂原则

悬挂光荣牌工作坚持彰显荣誉、规范有序、分级负责、属地落实的原则。光荣牌由自治区退役军人事务厅统一制作，光荣牌称号统一为“光荣之家”，各乡镇场、街道牵头组织落实本行政区域内光荣牌悬挂工作。

四、实施步骤

（一）分批实施。市退役军人事务局根据接收自治州光荣牌时间，结合各乡镇场、街道退役军人和其他优抚对象信息采集人数，统筹安排光荣牌发放时间、批次和数量，下发“光荣之家”牌匾。各乡镇场、街道收到光荣牌后，要认真查验光荣牌是否变形、表面是否破损、文字是否清晰等，严禁发放、悬挂不合格的光荣牌。

3月31日开始，各乡镇场、街道开展第一批光荣牌悬挂任务；4月30日前完成既有全部对象悬挂光荣牌任务。

（二）安装悬挂。

1.悬挂位置。光荣牌的安装悬挂位置应尊重悬挂家庭的意愿，一般应悬挂在其大门适当位置，保证醒目、协调、庄严、得体、稳固。因建筑结构、材质等因素不适合悬挂的，可在室内客厅醒目位置摆放。

2.悬挂仪式。3月31日起各乡镇场、街道举行集中悬挂光荣牌启动仪式，邀请烈属、军属、退役军人、现役军人代表和社会各界群众代表参加。乡镇（场）人民政府、村（居）民委员会、社区要举行悬挂仪式，仪式举办地点和形式可结合当地实际确定，有条件的城镇社区可利用文化广场，基础设施条件较薄弱的农村可选择在村委会，仪式一般由乡镇（场）人民武装部部长、“访惠聚”驻村（社区）工作队队长或村两委（社区）负责人主持，安排退役军人或悬挂家庭代表发言，力求悬挂仪式隆重简朴、气氛热烈，悬挂仪式上要为悬挂家庭户主佩戴绶带和红花。

3.悬挂方法。仪式结束后，统一安排专门工作小组分赴各个家庭进行安装悬挂，并拍摄悬挂光荣牌照片（一张戴绶带红花授牌照、一张领导挂牌照、一张挂牌后合影照），要通过简朴庄重的方式增强悬挂“光荣之家”牌匾家庭的荣誉感、获得感、幸福感，感受到党和政府的关心关爱和社会的尊崇。以后的悬挂、更换光荣牌工作原则上在每年春节或建军节前进行。

（三）建档立卡。各乡镇场、街道要建立健全建档立卡制度，结合退役军人和其他优抚对象信息采集工作，对悬挂光荣牌家庭进行全面摸底调查，要做到底数清晰、不错不漏，悬挂光荣牌对象准确，并建档立卡，汇总相关信息和统计数据，及时录入全国退役军人和其他优抚对象信息采集系统，加强信息数据管理。悬挂光荣牌时要安排专人负责，逐一登记造册，由悬挂家庭签字确认。

（四）完成时间。各乡镇场、街道悬挂光荣牌工作必须于4月30日前完成，并向市退役军人事务局上报悬挂光荣牌工作总结。从3月31日起每周报送光荣牌悬挂工作进展情况。

五、工作要求

（一）加强组织领导。各乡镇场、街道主要领导要充分认清做好悬挂光荣牌工作的重要意义，切实提高政治站位，加强组织领导，周密安排部署，制定实施方案，强化经费保障，确保悬挂光荣牌对象准确、档案齐全。

（二）加强宣传报道。集中悬挂光荣牌工作政治性强，社会关注度高，各乡镇场、街道要采取多种形式做好舆论宣传，引导广大人民群众和退役军人充分认识悬挂光荣牌的重要意义，营造全社会尊崇烈属、军属的氛围，让每个悬挂家庭成为一个国防教育点，激发现役军人和退役军人倍加珍惜荣誉，矢志精武强能，退伍不褪色，继续在工作岗位上为实现新疆社会稳定和长治久安总目标及经济社会发展贡献力量。

（三）加强监督检查。市退役军人事务局将根据市党委、市人民政府的安排部署，加强对悬挂光荣牌工作的指导和监督，及时跟踪工作进展情况，帮助解决工作中遇到的困难和问题，对工作不及时、不到位的，将责令限期整改，通报批评；造成严重后果的，依法严肃处理，严肃追责。
