# 关于调整库尔勒市应对气候变化及节能减排工作领导小组成员的通知

各乡、镇、场，各街道办事处，市属各单位、各部门：

为统筹推进全市应对气候变化及节能减排工作，根据库尔勒市机构改革、人员变动情况和工作需要，市人民政府决定调整库尔勒市应对气候变化及节能减排工作领导小组组成人员。现将调整后的名单通知如下：

二、领导小组职能

研究决策库尔勒市节能工作发展战略；审定库尔勒市节能减排发展规划和开展节能减排工作的有关政策、法规；部署库尔勒市节能减排工作各项任务，指导库尔勒市重大节能减排工程的组织实施；督促检查节能减排工作开展情况，协调解决库尔勒市节能工作中的重大问题。

三、领导小组办公室的主要职责

负责库尔勒市节能减排领导小组办公室的日常工作。

（一）组织成员单位研究提出库尔勒市节能减排的战略目标和规划（草案），报领导小组审定；

（二）根据库尔勒市实际，组织各相关部门制定节能减排实施方案与年度推进计划，提交领导小组审定；

（三）拟定库尔勒市节能目标责任考核工作计划提交领导小组审定；

（四）组织相关部门制定和完善促进库尔勒市节能减排政策措施；

（五）统筹安排库尔勒市节能减排财政专项资金；

（六）完成领导小组交办的其他工作。
