# 关于成立库尔勒市工程建设项目审批制度改革工作领导小组的通知

各乡、镇、场，各街道办事处，市政府各部门，市属各单位：

库尔勒市是今年自治区建设工程项目审批制度改革试点城市，为确保我市建设工程项目审批制度改革试点工作有组织、有计划、有步骤的顺利实施，经市人民政府研究，决定成立库尔勒市工程建设项目审批制度改革工作领导小组。其组成人员如下：

组 长：苏来曼·玉色因 库尔勒经济技术开发区党工委

书记、市党委副书记、市长

副组长：黄新平 市党委常委、常务副市长

金世鹏 副市长

成 员：任民杨 市住建局党组书记、副局长

孙新明 市住建局局长、园林局局长

孙建华 市发展和改革委员会主任

曹光栋 市商务和工业信息化局局长

闵建兵 市财政局局长

汪 旭 市人社局局长

谭险峰 市自然资源局局长

杨 剑 市生态环境局局长

张建水 市交通运输局局长

卡德尔江·亚森 市水利局局长

董书伟 市文旅局局长

刁殿强 市应急管理局局长

谭 俊 市气象局局长

阿不都吉力力·依明 市消防大队教导员

领导小组下设办公室，办公室设在市住建局，任民杨兼任办公室主任，孙建华、谭险峰兼任办公室副主任，具体负责改革试点中的日常工作，加强与各成员单位衔接协调。各成员单位根据领导小组及办公室工作安排，做好职责权属范围内工作。
