# 关于调整亚洲开发银行贷款西北三省区林业生态发展项目库尔勒项目协调领导小组的通知

各乡、镇、场，街道办事处，市政府各部门，市属各单位：

根据人事变动和工作需要，市人民政府决定调整亚洲开发银行贷款西北三省区林业生态发展项目库尔勒项目协调领导小组，调整后组成人员如下：

组 长：黄新平 市党委常委、常务副市长

副组长：热依木江·克里木 市党委常委

霍金龙 副市长

成 员：孙建华 市发展和改革委员会党组书记、主任谭险峰 市自然资源局局长

艾海提·艾沙 市农业农村局局长

张义智 市林业和草原局局长

卡德尔江·亚生 市水利局局长

杨 剑 市生态环境局局长

张小梅 市城乡防护林管理处副处长

领导小组下设办公室在市林业和草原局，张义智同志兼任办公室主任，具体负责协调项目组织实施的日常工作。

今后成员单位人员变动，按工作分工和组织任命，由接替人员担任并履职，不再另行发文。

库尔勒市人民政府办公室

2019年4月15日
