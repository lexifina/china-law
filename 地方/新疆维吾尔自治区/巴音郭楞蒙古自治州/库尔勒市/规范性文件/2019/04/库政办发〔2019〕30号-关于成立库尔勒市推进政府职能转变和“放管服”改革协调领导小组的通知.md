# 关于成立库尔勒市推进政府职能转变和“放管服”改革协调领导小组的通知

各乡、镇、场，各街道办事处，市属各单位、各部门：

为认真贯彻习近平新时代中国特色社会主义思想，贯彻落实党的十九大和十九届二中、三中全会精神，贯彻落实习近平总书记关于新疆工作的重要讲话和重要指示批示精神，贯彻落实以习近平同志为核心的党中央治疆方略、特别是社会稳定和长治久安总目标，贯彻落实自治区、自治州党委“1 3 3 改革开放”工作部署，深入推进简政放权、放管结合、优化服务改革，加快政府职能深刻转变，建设人民满意的服务型政府，市人民政府决定将库尔勒市推进职能转变协调小组的名称改为库尔勒市推进政府职能转变和“放管服”改革协调领导小组（以下简称协调领导小组），作为库尔勒市人民政府议事协调机构。现将协调领导小组组成人员及主要职责通知如下：

（二）协调领导小组主要职责

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党中央、国务院和自治区、自治州党委、政府决策部署，围绕推动高质量发展，统筹研究推进政府职能转变和“放管服”改革重要领域、关键环节的重大政策措施，研究拟提请市人民政府常务会议审议的有关重要事项，协调推动解决重点难点问题，指导督促各部门落实改革措施，更大限度激发市场活力、调动人的积极性和社会创造力。协调领导小组下设综合组、精简行政审批组、优化营商环境组、激励创业创新组、深化商事制度改革组、改善社会服务组、法制组、督查组、8个专项组。协调领导小组办公室设在市人民政府办公室。

二、协调领导小组各专项组及主要职责

（一）综合组

组长由市党委常委、常务副市长黄新平同志担任，成员由市党委宣传部副部长、文明办主任陈耀明，市人民政府办公室副主任于军、鹿昌平，市党委改革办党支部书记李伏军，市发改委主任孙建华，市行政服务中心主任冉庆娟组成。

负责协调领导小组及其办公室的日常工作；负责沟通协调各专项组工作，建立“放管服”改革工作机制；组织开展政府职能转变和“放管服”改革重大问题调查研究，围绕政府职能转变和“放管服”改革开展理论研究，对重点改革事项进行第三方评估，提供政策咨询，向协调领导小组提出工作建议；收集汇总相关信息资料，编发工作简报；联系部门组织媒体做好政策宣传解读和舆论引导工作。

（二）精简行政审批组

组长由副市长金世鹏同志担任，成员由市住建局局长、园林局局长孙新明、市发改委主任孙建华，市自然资源局局长谭险峰，市生态环境局局长杨剑，市司法局局长陈金潭、市市场监督管理局局长陈明炜、市行政服务中心主任冉庆娟组成。

负责牵头推进库尔勒市行政审批制度改革、投资审批制度改革、工程建设项目审批制度改革。放权方面，协调推进清理和规范各类行政许可等管理事项，继续清理精简投资项目审批、工程建设项目审批、核准等事项，推行区域评估、联合评审、并联审批等。监管方面，规范行政审批行为，审核并督促落实取消下放审批事项的事中事后监管措施。服务方面，协调推进行政审批标准化，打造全市一体化政务服务平台，推进审批服务便民化，持续开展减证便民行动，提高政府服务质量和效率。

（三）优化营商环境组

组长由市党委常委、副市长周广新同志担任，成员由市发改委主任孙建华、市财政局局长闵建兵、市自然资源局局长谭险峰、市水利局局长卡德尔江·牙生、市林业和草原局局长张义智、市生态环境局局长杨剑，市住建局局长、园林局局长孙新明、市商务和工业信息化局局长曹光栋、市市场监督管理局局长陈明炜、市行政服务中心主任冉庆娟组成。

负责牵头优化营商环境，提高综合竞争力，打造竞争新优势。放权方面，推进实行全市统一的市场准入负面清单制度，清理废除妨碍统一市场和公平竞争的各种规定做法。扩大外资市场准入，促进民间投资，提升贸易便利化水平。监管方面，清理规范审批中介服务，全面推行依清单收费，完善收费监管制度，持续清理规范涉企收费。服务方面，加强产权保护，推动健全知识产权保护体系。加快水电气暖、银行等公用事业领域改革，提升服务质量效率。加强政务诚信建设，建立健全营商环境评价机制。

（四）激励创业创新组

组长由市党委常委、副市长张亚松同志担任，成员由市发改委主任孙建华、市教育局局长徐红、市科学技术局局长刘友文、市财政局局长闵建兵、市人社局局长汪旭、市市场监督管理局局长陈明炜组成。

负责牵头推进实施创新驱动发展战略，打造大众创业、万众创新升级版，推进新旧动能接续转换。放权方面，协调推进科研经费使用和管理方式改革创新，赋予科技人员更大自主权，提高创新成果转化效率，激发创业创新活力。监管方面，对新兴产业量身定制包容审慎的监管模式和标准规范，坚守安全和质量底线。服务方面，协调推动各类主体融通创新，破解创业创新融资难题。改革分配机制，健全保障体系，促进人才合理流动。深化职业资格管理制度改革，加强公共就业和职业技能培训服务，完善对新就业形态的支持措施。

（五）深化商事制度改革组

组长由市党委常委、副市长周广新同志担任，成员由市市场监督管理局局长陈明炜、市发改委主任孙建华、市生态环境局局长杨剑、市交通运输局局长张建水、市农业农村局局长艾海提·艾沙、市文化体育广播电视和旅游局局长董书伟、市税务局局长邓新卫组成。

负责牵头深化商事制度改革，加强和完善市场监管，维护公平竞争市场秩序。放权方面，压缩企业开办时间，全面推开“证照分离”改革，深化“多证合一”改革，推行简易注销改革。监管方面，健全以“双随机、一公开”监管为基本手段、以重点监管为补充、以信用监管为基础的新型监管机制，推进跨部门联合监管和“互联网＋监管”。规范执法行为和自由裁量权。服务方面，发挥标准的引领和规范作用，强化标准体系，健全认证认可检验检测体系。

（六）改善社会服务组

组长由副市长艾尔肯·哈米尔丁同志、副市长王红春同志担任，成员由市教育局局长徐红、市公安局副局长孙卫刚、市民政局局长李江梅、市司法局局长陈金潭、市人社局局长汪旭、市卫健委主任陆新民、市医疗保障局局长吐尔洪·早尔东组成。

牵头负责协调推进教育、卫生健康、养老、社保以及社会管理等领域“放管服”改革，为人民群众提供便捷高效、公平可及的公共服务。放权方面，协调推进放宽服务业市场准入，调动市场力量增加非基本公共服务供给。监管方面，强化对政府窗口服务的监督，加强公共服务质量监管。服务方面，简化优化民生事项办理流程和手续，推进养老保险、医疗保险等事项异地联网办理。充分运用“互联网＋教育”“互联网＋医疗”等模式，增强优质公共服务资源辐射效应。

（七）法治组

组长由副市长艾尔肯·哈米尔丁同志担任，负责对政府职能转变和“放管服”改革措施进行合法性审核，及时提出修订相关法规规章的建议方案，推动相关法规规章立改废释工作，及时将成熟的改革经验制度化等。

（八）督查组

组长由市党委常委、常务副市长黄新平同志担任，负责督促检查政府职能转变和“放管服”改革各项措施贯彻落实情况，核查督办各专项组提出的各部门和单位改革中存在的问题，以及社会对有关改革反映强烈的问题。

综合组的日常工作由市人民政府办公室承担；精简行政审批组的日常工作由市人民政府办公室承担；优化营商环境组的日常工作由市发改委、商务和工业信息化局、市场监督管理局承担；激励创业创新组的日常工作由市科技局承担；深化商事制度改革组的日常工作由市市场监督管理局承担；改善社会服务组的日常工作由市教育局、市人社局、市卫健委、市民政局承担；法制组的日常工作由市司法局承担；督查组的日常工作由市人民政府办公室督查室承担；专家组的日常工作由市党委改革办承担。各专项组负责调查研究本领域社会反响大、群众意见集中的问题，协调相关部门对重点难点问题合作攻关，提出改革建议。各专项组的改革建议按程序提交协调领导小组会议审议。各专项组的工作职责和组成可根据工作需要调整。协调领导小组成员和各专项组组长、成员需要调整的，由所在单位书面向协调领导小组办公室提出，由综合组按程序报批。

三、有关要求

（一）协调领导小组要牢固树立“四个意识”，坚定“四个自信”，做到“两个维护”。充分发挥好推进“放管服”改革工作的统筹指导和督促落实作用。各专项组要根据职责分工，细化分阶段重点工作，制定可量化、可考核、有时限的目标任务。对跨领域、跨部门、跨层级的重大问题，要加大研究协调力度，及时督促解决，推动各项改革协同配套、整体推进。要尊重基层首创精神，及时总结推广各部门和单位典型经验做法。

（二）各部门和单位要自觉扛起改革重任。涉及本部门和单位的改革任务，要及早落实，该放的权坚决放，该办的事加快办，该服务的服务好，大力推动我市“放管服”工作先行先试。主要负责同志要进一步提高政治站位，切实负起领导责任，亲自抓好职责权属范围内改革任务的部署、协调和落实。

（三）各部门和单位要完善政府职能转变和“放管服”改革推进机制，因地制宜，探索创新，创造更多管用可行的“一招鲜”。要主动对标先进，相互学习借鉴，形成竞相推进“放管服”改革的生动局面，努力为实现社会稳定和长治久安总目标提供坚强保障。
