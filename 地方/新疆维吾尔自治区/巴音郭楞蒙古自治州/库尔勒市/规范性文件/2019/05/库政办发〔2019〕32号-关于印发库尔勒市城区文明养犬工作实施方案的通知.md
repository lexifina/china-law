# 关于印发库尔勒市城区文明养犬工作实施方案的通知

各乡、镇、场，各街道办事处，市政府各部门，市属各单位：

《库尔勒市城区文明养犬工作实施方案》已经市十届人民政府第23次常务会议审议通过，现印发你们，请认真贯彻落实。

库尔勒市人民政府办公室

2019年5月4日

库尔勒市城区文明养犬工作实施方案

为规范市民文明养犬行为，保障公民身体健康和人身安全，控制犬类伤人、犬吠扰民和动物检疫，净化市容环境、维护社会秩序，根据《库尔勒市城区养犬管理条例》《城市市容和环境卫生管理条例》等相关法律、法规，及自治州养犬管理工作会议精神，结合库尔勒市实际，决定在全市建成区开展规范“文明养犬”行为工作，特制定本方案。

一、指导思想

认真贯彻落实以习近平同志为核心的党中央治疆方略，特别是社会稳定和长治久安总目标，以“规范管理、强化监管、文明养犬”为指导，以解决市民关注的热点、焦点问题为突破口，以“管理犬、先管人”为目标，坚持“宣传为先，整治跟后，办证为主，收容为辅”的工作原则，通过工作开展，促进广大市民和养犬人遵守法律法规，切实增强市民依法养犬、文明养犬、规范养犬意识，保障人民群众生命健康和安全，维护广大市民和养犬人的合法权益，进一步营造和谐、文明、优美的生活环境。

二、组织机构

市人民政府成立由分管副市长为组长的养犬管理工作领导小组，成员由市公安局、住建局、卫健委、市场监督管理局、生态环境局、畜牧兽医局、园林局、城管大队、住建局行业办及各近郊乡、街道等部门主要负责人组成，领导小组下设养犬管理办公室，具体负责组织、指导、协调、监督、检查养犬工作，办公室设在市住建局。由市畜牧兽医局建设犬只留检所，配备专业技术岗位动检员和车辆，保障经费正常运行。

三、管理职责及各部门分工

（一）流浪犬的管理

各近郊乡、街道、社区、物业小区按照“属地管理”“网格化管理”原则对辖区流浪犬进行抓捕，市住建局（市城管大队养犬办）负责收集并统一移交畜牧兽医局下属的犬只留检所进行检疫、免疫，对病犬进行无害化处理，对健康犬放留检所进行收容。市环卫局协助畜牧兽医局对疫犬、病犬、有害犬进行无害化处理。

（二）有主犬的管理

各近郊乡、街道、社区、物业负责对辖区有主犬的登记审批、日常监管（包括犬类散养行为）及宣传工作，协调和处理辖区居民因养犬而引发的各类矛盾纠纷，协助各部门做好犬类管理工作。按照养犬人申请、所在街道审批、市畜牧兽医局检疫、社区发证挂牌、市住建局（市城管大队养犬办）备案的程序对有主犬进行日常管理。各社区、物业对小区住户进行文明养犬宣传，制作文明养犬宣传栏，悬挂文明养犬宣传标语。各近郊乡、街道、社区、物业小区对本辖区养犬工作进行日常监管，对不文明养犬行为制止无效的，及时通知市住建局（市城管大队养犬办）配合管理，依法查处。各近郊乡、街道定期、不定期组织各部门进行不文明养犬执法大清查工作。市畜牧兽医局做好检疫、免疫工作，发放检疫证并配置犬类电子标签，建立管理台账，做好与街道社区登记办证环节中的衔接工作。

（三）大型犬、烈性犬的管理

根据《库尔勒市城区养犬管理条例》第七条规定，禁止饲养烈性犬、大型犬。对于不符合规定的犬只从源头上进行制止，严把审批关、不予办证。

市卫健委：负责狂犬病人的诊治、人用狂犬病疫苗的注射和狂犬病疫情监测及狂犬病防治知识的宣传。

市市场监督管理局：负责犬只经营活动的监督管理等工作并做好台账。

市生态环境局：负责规模化犬类养殖的环境监管和评估等工作并做好台账。

市园林局：负责旅游区、风景带、公园广场等场所犬只的日常管理工作。

市发改委、财政局：依据相关职责，做好配套政策和资金的保障工作。

市住建局行业办：督促检查各物业小区对所属小区住户进行文明养犬宣传，制作文明养犬宣传栏，悬挂文明养犬宣传标语，对流浪犬进行抓捕。

市住建局（市城管大队养犬办）：负责养犬管理日常巡查工作，查处无证养犬、不文明养犬、街面流动售犬及放任犬只随地便溺等影响市容环境卫生的行为；对各街道社区、物业小区、园林局管理、制止无效的不文明养犬行为进行依法查处；为各街道、社区、物业小区提供犬类抓捕工具，集中收集社区、物业小区、辖区单位抓捕的流浪犬，并移交畜牧兽医局下属的犬只留检所；定期了解社区、小区、公园、景区、商业区等公共场所的犬类活动情况，不定期组织各部门协助街道开展不文明养犬行为执法大清查工作。

市公安局：有效处理好犬只伤人、犬吠扰民等工作，查处及清理城区禁养犬只（送留检所），排除有关部门在开展养犬管理工作中遇到的各种阻碍执法、执行公务的行为。对违反养犬管理规定、干扰他人正常生活、性质恶劣造成严重影响的行为，严肃处理，达到“惩戒一起、警示一片”的良好效果。

加快养犬管理平台建设，利用数字化、信息化手段科学管理。养犬管理平台的建设是数字城管大数据平台的一个子系统，也是智慧城市建设的重要组成部分。

四、工作目标

重点解决以下问题：一是限养区饲养禁养犬（烈性犬、大型犬）问题；二是无证养犬和不文明养犬、遗弃犬问题；三是遛犬不拴犬链、不戴嘴罩问题；四是遛犬不清理粪便的问题；五是携犬出入公共场所扰民、污染问题；六是养犬影响邻里生活的问题；七是不服从犬类管理、阻碍执法或暴力抗法问题。

五、实施步骤

（一）宣传摸底阶段（5月1日— 5月31日）

加大人力、物力、财力的投入，各近郊乡、街道、社区、村委会、物业公司等单位，在小区、广场、公园等人群集中区及宠物医院、商业中心进行宣传，鼓励市民参与规范“文明养犬”行为活动，遵守“文明养犬”有关规定，并对违规养犬，严重影响市民安全和生活的行为进行曝光。各近郊乡、街道、社区、物业小区在本辖区开展全市有主犬摸底统计和登记、审批、办证工作，做到底数清、情况明。畜牧兽医部门的检疫办证工作同步跟进。

（二）集中规范阶段（6月1日—9月30日）

主要针对违规饲养烈性犬、大型犬、溜犬不束犬链外出、不及时清理犬类粪便的行为实施严管重罚，对一些“犬患”问题突出的小区、路段、广场等区域，集中开展规范工作。解决一批市民关注、反应强烈的重点区域；曝光、处罚一批违反养犬管理规定、性质恶劣造成严重影响的养犬人以及饲养犬只干扰他人正常生活等行为；犬只伤人的，养犬人、管理人或者有过错第三人应当承担受害人的医疗费用，并依法赔偿受害人的其他相应损失。

（三）巩固提高阶段（10月1日—11月30日）

集中力量对前期重点规范的区域实施“回头看”，及时发现和解决存在的问题，对携犬外出不束犬链及犬只外出随地便溺犬主不及时清理的不良行为，依据条例实施处罚或采取曝光等手段给予惩戒，达到“惩戒一起、警示一片”的良好效果。要以落实新疆社会稳定和长治久安总目标为契机，全面规范我市文明养犬管理的各项工作，加强日常管理，落实管理责任，巩固规范成果。要对存在问题严重的区域进一步加强规范，举一反三，查漏补缺，对因各种因素未登记上牌的犬类及时予以办证并依法进行处罚。

（四）检查验收阶段（12月1日— 12月31日）

由养犬管理工作领导小组对规范工作进行全面的检查和考核验收，以量化考评的形式实施考核，成绩纳入城市管理综合长效考核指标体系。

六、工作要求

（一）提高思想认识，加强组织领导。各有关部门和各近郊乡、街道要从规范“文明养犬”行为是事关民生福祉、事关社会和谐、事关文明城市形象的高度出发，充分认识加强犬类管理工作的重要意义，切实采取有效措施把此项工作抓好、抓实、抓出成效。各部门要加强协调配合、发挥各自职能作用，真正形成齐抓共管的良好局面。要层层动员发动，时时宣传引导，强化检查指导监督，加大经费、装备、人员的投入，及时解决工作中遇到的问题，确保行动取得实效。

（二）加强宣传引导，倡导文明养犬。各近郊乡、街道和社区采取入户宣传、发放宣传资料、走近社区举办文明、科学养犬讲座等形式宣传法律、规章及违规养犬给市民身体健康带来的危害，并向社会发布通告、倡议书，倡导依法、文明、科学养犬。通过新闻媒体，向社会各界和广大市民宣传《库尔勒市城区养犬管理条例》《城市市容和环境卫生管理条例》和《中华人民共和国治安管理处罚法》以及规范工作的重点和目标，要联合举办“文明养犬”宣传咨询活动，通过深入宣传，营造浓烈氛围，广泛调动广大市民参与支持规范“文明养犬”行为的积极性和主动性。

（三）深入调查摸底，建立清单台账。按照“属地管理”原则，由各近郊乡、街道，以社区为单位，逐户、逐个单位进行普查。重点要摸清辖区内养犬总数、饲养犬类、交易的单位和个人等情况，并建立完善管理台账，为今后犬类管理法规修改和执法工作提供准确依据。同时，在调查过程中，多收集广大市民对犬类管理的建议以及对规范“文明养犬”行为的工作意见。

（四）强化巡查整治，集中清理规范。各近郊乡、街道、社区要组织各部门执法力量，对违规养犬突出的区域进行重点规范。对“犬患”问题突出的区域，要突出清理个人饲养禁养犬为重点，集中力量、集中时间、集中治理。要注意发现、制止携犬进入公共场所、不束犬链、随地便溺等管犬不力行为，应即时向养犬人说明，禁止携犬进入公共区域，带犬外出必须束犬链并由成年人牵引。

（五）注重方式方法，严肃工作纪律。要注意发现收集一些有关规范“文明养犬”行为工作中反映社情民意的信息，对于群众反映违规养犬的举报、投诉，各责任部门和单位要及时受理，做好记录，迅速处置，妥善处理，及时上报。对工作中遇到的疑难问题，要及时请示报告。要吃透政策精神，既要坚持人性化管理，开展耐心细致的说服教育，又要注意灵活运用政策，坚决防止简单粗暴，避免激化矛盾。

（六）加强信息汇总，及时总结上报。领导小组成员单位要加强整治情况、相关信息的收集和报告工作，要指定专人负责，每月至少报一次工作动态，坚持月小结和阶段性总结，重大情况及时上报。
