# 关于印发库尔勒市取水许可区域限批及分级管理权限制度实施意见的通知

各乡、镇、场，各街道办事处，市政府各部门，市属各单位：

《库尔勒市取水许可区域限批及分级管理权限制度实施意见》已经市十届人民政府第23次常务会议审议通过，现印发你们，请认真抓好贯彻落实。

库尔勒市人民政府办公室

2019年4月30日

库尔勒市取水许可区域限批及分级管理权限制度实施意见

为贯彻落实最严格水资源管理制度，加强我市取水许可管理，确保全市用水控制在用水总量指标内。根据《新疆维吾尔自治区取水许可管理办法》（2014年4月17日自治区第十二届人民政府第15次常务会议讨论通过并发布施行）精神，结合我市实际，特制定本实施意见。

一、实行取用水总量控制制度

（一）依据《巴州（含二师）用水总量控制方案》和《库尔勒市用水总量控制方案》有关要求，全市批准的取用水总量不得超过自治州下达的用水指标。

（二）对取水总量接近控制指标的区域，应当限制新增取水，优先保障低消耗、低排放和高效益的产业发展，对不符合国家产业政策或列入国家产业结构调整指导目录中淘汰类的、产品不符合行业用水定额标准的、在城市公共供水管网能够满足用水需要却通过自备取水设施取用地下水的、地下水已超采地区抽取地下水的、建设项目节水设施未与主体工程同时设计的、用水定额超出国家、行业或地方标准的项目以及其他不符合法律法规和最严格水资源管理制度要求的建设项目取水申请，不予批准。

对取用水总量超过总量控制指标的区域，暂停审批新增取水的建设项目（除公共管网未覆盖的生活用水外），可在区域用水总量控制框架下，通过“水资源用途调整”、水权交易及退地减水等来解决新建项目取用水。

（三）根据划定的禁采区、限采区，从严控制超采区取水，除生活用水外，一律不再审批新的机井。城市公共供水管网已经覆盖、水质水量能够满足需求的区域，原有自备井一律封停，禁止取用地下水。公共供水不能完全满足用水需求的区域，限量开采地下水。公共供水管网尚未覆盖的区域，应当创造条件延伸公共供水管网，逐步停止取用地下水，并封停取水设施。

二、取水许可区域限批

（一）年取水量100万立方米以下（含100万立方米）审批程序

项目及个人地下水年取水量在100万立方米以下（含100万立方米）的，按照行政区域报市水行政主管部门初审、报州水行政主部门复核，由州人民政府审批，由所在市水行政主管部门核发取水许可证。

（二）年取水量在100万立方米以上审批程序

项目及个人地下水年取水量在100万立方米以上的，按照行政区域报市水行政主管部门初审、报州水行政主部门复核，由州人民政府审批，由州水行政主管部门核发取水许可证，取水所在地市水行政主管部门履行监督管理职责。

（三）结合库尔勒市地下水管理要求，全市范围内机电井应当安装智能计量设施，并接入市地下水远程监控平台系统。

三、其他日常取水许可管理各项工作严格按照《新疆维吾尔自治区取水许可管理办法》有关规定贯彻落实。
