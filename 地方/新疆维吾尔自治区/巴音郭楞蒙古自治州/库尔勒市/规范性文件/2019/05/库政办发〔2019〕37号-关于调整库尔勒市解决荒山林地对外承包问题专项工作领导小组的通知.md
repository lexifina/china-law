# 关于调整库尔勒市解决荒山林地对外承包问题专项工作领导小组的通知

各乡、镇、场，各街道办事处，市属相关部门：

为全面掌握库尔勒市荒山林地承包情况，切实解决龙山周边荒山林地对外承包用地手续办理问题，现将库尔勒市解决荒山林地对外承包问题专项工作领导小组成员调整如下：

组 长：黄新平 市党委常委、常务副市长

副组长：霍金龙 副市长

成 员：谭险峰 市自然资源局局长

闵建兵 市财政局局长

张义智 市林草局局长

孙新明 市住建局局长

卡德尔江·亚生 市水利局局长

黄亭鸿 市信访局局长

陈金潭 市司法局局长

高清江 市征收办主任

张小梅 市城乡防护林管理处副处长

乔 新 市城建集团总经理

领导小组下设办公室在市林草局，张义智同志兼任办公室主任，负责相关具体工作。办公室成员组成如下：

张义智 市林草局局长、城乡防护林管理处处长

谭险峰 市自然资源局局长

孙新明 市住建局局长

周玉儒 市住建局副局长

张小梅 市城乡防护林管理处副处长
