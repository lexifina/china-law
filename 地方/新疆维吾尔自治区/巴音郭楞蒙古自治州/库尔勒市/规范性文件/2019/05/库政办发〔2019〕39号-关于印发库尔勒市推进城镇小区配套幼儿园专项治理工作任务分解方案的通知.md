# 关于印发库尔勒市推进城镇小区配套幼儿园专项治理工作任务分解方案的通知

各乡、镇、场，各街道办事处，市政府各部门，市属各单位：

《库尔勒市推进城镇小区配套幼儿园专项治理工作任务分解方案》已经市人民政府同意，现印发你们，请认真组织实施。

库尔勒市人民政府办公室

2019年5月16日

库尔勒市推进城镇小区配套幼儿园专项治理工作任务分解方案

为深入贯彻落实《中共中央 国务院关于学前教育深化改革规范发展的若干意见》《国务院办公厅关于开展城镇小区配套幼儿园治理工作的通知》（国办发〔2019〕3号）、《自治区城镇小区配套幼儿园专项治理工作方案》（新政办发〔2019〕45号）、《关于印发<库尔勒市城镇小区配套幼儿园专项治理实施方案和库尔勒市普惠性民办幼儿园认定及财政扶持管理办法（试行）>的通知》（库政发〔2019〕34号）等精神，进一步完善库尔勒市学前教育公共服务体系，不断扩大全市普惠性学前教育资源供给，促进库尔勒市学前教育普及普惠安全优质发展，制定本方案，具体如下：

一、政策依据

严格遵循《中华人民共和国城乡规划法》和《城市居住区规划设计标准》（GB50180），老城区（棚户区）改造、新城开发和居住区建设、易地扶贫搬迁应将配套建设幼儿园纳入公共管理和公共服务设施建设规划，并按照相关标准和规范予以建设。原则上城镇配套小区建设幼儿园辐射半径不大于300米，居住人口规模为5000-12000人，住宅数量约为1500-4000套。

二、目标任务

（一）工作目标。根据国务院办公厅《关于开展城镇小区配套幼儿园治理工作的通知》（国办发〔2019〕3号）和《自治区城镇小区配套幼儿园专项治理工作方案》（新政办发〔2019〕45号）相关要求，到2020年，全市学前三年毛入园率达到85%，普惠性幼儿园覆盖率（公办幼儿园和普惠性民办园在园幼儿占比）达到80%，其中公办幼儿园占比为50%。

（二）工作任务。将我市达到1500-4000户人口规模的小区内15所非普惠性民办幼儿园纳入治理范围，委托办成普惠性民办幼儿园；新建9所幼儿园，每个幼儿园办成建制为12个班规模的公办幼儿园。

三、责任分工和完成时限

（一）普惠性幼儿园治理工作。

1.根据国家和自治区配建标准，统筹规划城镇小区配套幼儿园，对需要治理的15所已开办民办幼儿园报市党委、市人民政府给予普惠性幼儿园政策扶持、减免全部或部分房租等相关费用方面的支持。制定返还土地出让金、减免或全免租金、分年补贴租金的方案和具体措施，代表政府与开发商或产权人进行谈判，促使非普惠性民办幼儿园办成普惠性民办幼儿园。对上级给予的奖补资金向普惠性幼儿园倾斜。

牵头部门：市自然资源局

配合部门：市财政局、教育局

完成时限：2019年5月25日

2.核准确定普惠性幼儿园的公用经费补贴标准、补助渠道和补助措施，制定《库尔勒市普惠性幼儿园公用经费补贴政策或办法》，研究分析1600元生/年（暂定）补助标准是否合理，多渠道寻找政策依据和资金来源，对普惠性幼儿园公用经费补助工作提出解决方案，促使非普惠性民办幼儿园办成普惠性民办幼儿园。

牵头单位：市财政局

配合部门：市教育局

完成时限：2019年5月25日

3.按照《关于印发<库尔勒市城镇小区配套幼儿园专项治理实施方案和库尔勒市普惠性民办幼儿园认定及财政扶持管理办法（试行）>的通知》（库政发〔2019〕34号）相关要求，做好普惠性幼儿园具体收费等级界定，积极与上级发改部门对接，尽快做好认定工作。确定普惠性幼儿园性幼儿园等级收费的依据和一级、二级、三级幼儿园的普惠性收费标准。逐步建立普惠性幼儿园保教费指导限价与物价指数联动机制，科学合理制定普惠性幼儿园保教费认定标准。

责任单位：市发改委

配合部门：市教育局

完成时限：2019年5月25日

4.通过以奖代补、派驻公办教师等方式，引导和支持民办幼儿园提供普惠性服务。制定对普惠性民办幼儿园教育扶持工作方案，对上级给予的奖补资金向普惠性幼儿园倾斜；支持普惠性幼儿园加强教师队伍建设，派驻公办教师提高普惠性幼儿园保教质量；向普惠性幼儿园派驻业务能手开展师资培训，帮助普惠性幼儿园提高管理和保教工作水平；发挥园长工作室引领作用，建立结对帮扶机制。

责任单位：市教育局

配合部门：市财政局

完成时限：2019年5月25日

（二）公办幼儿园新建工作。

1.参与小区配套幼儿园建设项目规划布局，对需要补建、改建、新建的项目要按程序及时办理审批、核准或备案手续。2019年9月初完成108号小区、中博春天花园小区、恒友巴音西路小区、华源圣地欣城小区等4所幼儿园项目立项；2019年11月初完成54号小区、巴音小区、36号小区3所幼儿园项目立项。

责任单位：市发改委

配合部门：市教育局

完成时限：2019年11月1日

2.根据国家和自治区配建标准，统筹规划城镇小区配套幼儿园，将小区配套幼儿园必要建设用地及时纳入国土空间规划，按相关规定划拨建设用地。2019年9月初完成108号小区、中博春天花园小区、恒友巴音西路小区、华源圣地欣城小区等4个小区配建幼儿园规划并同步列入建设计划；2020年9月初幼儿园建设完成后，由市自然资源局牵头，市教育局、财政局、住建局等部门组织验收，办理产权移交手续。2019年11月初完成54号小区、巴音小区、36号小区配建幼儿园规划并同步列入建设计划。

责任单位：市自然资源局

配合部门：市教育局、财政局、住建局

完成时限：2020年9月1日

3.监管城镇小区配套幼儿园的建筑设计、施工建设、验收、移交的具体工作落实，牵头制定《库尔勒市小区配套幼儿园建设管理办法》。对108号小区、中博春天花园小区、恒友巴音西路小区、华源圣地欣城小区、巴音小区、36号小区、54号小区、71号（苇业小区）小区幼儿园等8所配建幼儿园进行施工建设质量监督管理，督促开发商（施工单位）按期完成建设。

责任单位：市住建局

配合部门：市教育局

完成时限：2020年9月1日

4.从2019年5月开始，由市自然资源局牵头与开发商协商对康都时代花园小区幼儿园进行置换并移交市教育局。

责任单位：市自然资源局

配合部门：市财政局、教育局

完成时限：2019年7月30日

5.完成108号小区、中博春天花园小区、恒友巴音西路小区、华源圣地欣城小区、巴音小区、36号小区、54号小区、71号（苇业小区）小区、康都时代花园小区等9所幼儿园交接工作，切实把移交的9所民办幼儿园办成公办幼儿园。一是由市教育局申报，相关部门按照程序做好机构设置、法人登记、编制核定、师资配备等方面的工作，提出工作建议，市教育局按照公办幼儿园标准进行预算（含人员工资、办公经费、设施设备采购等）报财政部门审批。二是以政府购买服务的方式，于2019年9月完成实施方案，提出预算报财政部门审批。

责任单位：市教育局

配合部门：市党委编办，市财政局、人社局

完成时限：2020年11月1日

四、工作要求

（一）加强组织领导，统一思想认识。各有关部门、单位要积极行动起来，迅速把思想和行动统一到市党委、政府的决策部署上来，统筹协调，密切配合。各单位主要领导是城镇小区配套幼儿园专项治理工作的第一责任人，要将城镇小区配套幼儿园专项治理工作纳入党政重要议事日程，明确任务、职责、时间节点，倒排工期，挂图作战，本着高度负责的态度确保各专项工作落实到位，确保我市按照国家和自治区规定的时间保质保量完成工作任务。

（二）加强部门协作，强化责任落实。各单位按照城镇小区配套幼儿园规划、建设、移交、办园各个环节的工作要求，加快建立相应工作机制。各相关部门要相互配合、联审联管，形成工作合力，稳步推进，主要领导要亲自安排部署，将任务分解到人，定期检查落实。各单位要按照分解方案，结合实际，制定切实可行的工作措施，建立台账，细化分解任务，确保各项任务落地见效。各责任单位要将负责的工作进展情况向市人民政府分管领导汇报，确保各项工作落到实处。

（三）加强督促指导，严格责任追究。市人民政府将组织督查组定期对各单位推进城镇小区配套幼儿园专项治理情况进行督查，督查结果将纳入对各级党政领导干部的绩效考核内容并实行责任倒查。对推进城镇小区配套幼儿园专项治理工作不力、工作进展缓慢的单位和个人进行通报批评，对问题突出的追究相关责任人的责任。
