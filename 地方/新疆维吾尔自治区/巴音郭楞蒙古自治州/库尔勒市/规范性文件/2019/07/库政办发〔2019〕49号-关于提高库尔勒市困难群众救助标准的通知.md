# 关于提高库尔勒市困难群众救助标准的通知

各乡、镇、场，各街道办事处，市政府各部门，市属各单位：

为切实保障城乡困难群众的基本生活，确保困难群众基本生活水平与我市经济社会发展水平相适应，根据自治区民政厅、财政厅《关于提高全区困难群众救助标准的通知》（新民字〔2019〕62号）精神，结合我市实际，经市十届人民政府第28次常务会议审议通过，决定调整提高全市城乡困难群众基本生活救助标准。现就有关事宜通知如下：

一、城乡低保标准

（一）城市低保标准由428元/月/人提高至456元/月/人。

（二）农村低保标准由3804元/年/人提高至3900元/年/人。

二、分类施保标准

全市分类施保标准继续按现行标准执行，即：城市低保对象中的60岁以上老年人97元/月/人、重病患者32元/月/人、一二级残疾人57元/月/人、三四级残疾人10元/月/人、未成年人22元/月/人；农村低保对象中的60岁以上老年人39元/月/人、重病患者27元/月/人、一二级残疾人44元/月/人、三四级残疾人5元/月/人、未成年人（非重病、残疾）22元/月/人，未成年人（还属于残疾、重病）17元/月/人。分类施保标准采取叠加计算，即同时属于老年、未成年、残疾、重病中两种的，可合并计算其分类施保金。

三、特困供养救助标准

（一）基本生活保障标准。城市特困人员基本生活标准由集中660元/月、分散470元/月，统一提高到800元/月；农村特困人员基本生活标准由集中520元/月提高到700元/月，分散由343元/月提高到500元/月。

（二）照料护理标准。按照特困人员生活自理能力和服务需求，自理、半自理、全护理特困人员照料护理标准分别为100元/月、300元/月、500元/月。

四、孤儿基本生活保障标准

社会福利机构供养孤儿每人每月不低于1100元、社会散居孤儿每人每月不低于800元标准。

五、流浪乞讨给养费标准

市社会救助站内受助人员伙食补助提高到每人每天26元。

六、执行时间

此次调整提高后的城乡低保标准和平均补助水平从2019年7月1日起执行，其他救助标准从2019年1月1日起执行。

七、工作要求

（一）加强领导，形成工作合力。各乡、镇、场、街道，相关部门要进一步完善政府领导、民政牵头、部门配合、社会参与的运行机制，全力配合民政部门做好政策落实和监督管理等各项工作。及时发现工作中存在的问题，积极协调解决，为开展困难群众基本生活保障工作提供有力的组织保障。

（二）加强监管，提高资金效能。市民政部门、各乡、镇、场、街道要根据工作实际，坚持公开、公平、公正，严格按照程序进行资料申报，加强对民政专项资金的监管和使用，确保民政资金及时、足额发放到群众手中，将惠民政策落实到位、服务群众。

（三）加强宣传，落实惠民政策。要采取多种形式，充分运用广播电视、报刊、网络等媒体，广泛宣传惠民政策，在全社会营造积极参与支持困难群众基本生活保障工作的浓厚氛围。
