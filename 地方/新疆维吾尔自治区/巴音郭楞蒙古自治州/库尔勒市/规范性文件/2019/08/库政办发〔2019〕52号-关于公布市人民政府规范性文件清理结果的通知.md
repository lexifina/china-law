# 关于公布市人民政府规范性文件清理结果的通知

各乡、镇，各街道办事处，市政府各部门、市属各单位：

为贯彻落实党中央、国务院关于推进依法行政、建设法治政府的部署和要求，根据《自治区关于加强行政规范性文件制定和监督管理工作的实施意见》（新政办发〔2019〕31号）和《自治州关于开展涉及机构改革和与现行开放政策不符规范性文件专项清理工作的通知》（巴政办发〔2019〕26号）精神和要求，市人民政府组织市各有关部门对2003年1月1日至2018年12月31日，以市人民政府和市政办名义制定的52件规范性文件进行了清理，清理结果已经市十届人民政府第33次常务会议审议通过，现公布如下：

一、确认库尔勒市人民政府《关于印发《库尔勒市干部保健医疗管理实施办法》的通知》（库政办〔2006〕103号）等35件规范性文件继续有效。

二、废止库尔勒市人民政府办公室《关于印发《库尔勒市城镇特困群体社会救助资金筹集管理使用实施细则》的通知》（库政办〔2003〕140号）等17件规范性文件。

上述废止的规范性文件，自公布之日起不再执行；继续有效的规范性文件，有效期自发布之日起计算，凡未列入继续有效目录的规范性文件，今后不得作为行政管理的依据。
