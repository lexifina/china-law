# 关于做好库尔勒市城镇小区配套幼儿园建设移交管理工作的通知

各乡、镇、场，各街道办事处，市政府各部门，市属各单位：

为深化我市学前教育改革，建立健全城镇小区配套幼儿园建设管理保障机制，不断扩大城区公共学前教育资源，根据《国务院关于当前发展学前教育的若干意见》（国发〔2010〕41号）、《中共中央 国务院关于学前教育深化改革规范发展的若干意见》、《国务院办公厅关于开展城镇小区配套幼儿园治理工作的通知》（国办法〔2019〕3号）以及《自治区城镇小区配套幼儿园专项治理工作方案》（新政办发〔2019〕45号）等相关文件精神，经市十届人民政府第33次常务会议审议通过，现就有关事项通知如下：

一、工作目标

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，落实全国教育大会部署，坚持以人民为中心的发展思想，聚焦全市城镇小区配套幼儿园规划、建设、移交、办园等环节存在的突出问题，进一步提高学前教育公益普惠水平，优化教育资源合理配置，依法依规落实城镇居住区配套幼儿园建设规定，着力构建以普惠性资源为主体的学前教育公共服务体系，按照“属地负责、因地制宜、分类指导、长效治理”的原则，坚持政府主导、部门联动，切实加强城镇小区配套幼儿园的专项治理工作，有效解决“入园难”“入园贵”问题，满足人民群众对学前教育的期盼。

二、工作内容及措施

（一）适用范围及原则。2011年以来建设的商品住宅、保障性住房、安置房小区配套幼儿园的规划、建设、移交与管理，适用本实施方案。本实施方案所称开发建设单位，包括商品房小区开发企业和履行保障性住房小区、安置房小区建设责任的责任单位。新建住宅小区配套建设幼儿园工作应当坚持统一规划、合理布局、规范建设、及时移交、公益办学的原则，办成公办幼儿园或普惠性民办幼儿园。市人民政府办公室负责组织协调，市自然资源局、住建局和教育局、发改委、财政局等部门负责本实施方案的具体落实。市人民政府相关部门应当履行各自职责，并建立健全执法合作、信息共享等部门联动机制，共同做好新建住宅小区配套幼儿园的规划、建设、移交与管理工作。

（二） 规划用地管理。土地出让要求：市自然资源局在土地出让时，将招拍挂或协议出让的用地内需配套建设的幼儿园纳入建设项目，幼儿园用地免交土地出让金。

（三）建设管理规定

1. 建设工程设计方案审核。对于需要配套建设幼儿园的新建住宅小区项目，市自然资源局、住建局等规划建设行政主管部门应按照规划条件和土地出让合同的要求，在审查小区建设工程设计方案总平面阶段及核发建设工程规划许可证阶段的同时，审核设计方案是否满足相关规划规范要求；在方案审查时应邀请市教育局参加，市教育局对幼儿园的规划设计提出意见；开发建设单位在申报施工图审查阶段，审图机构负责审核配套幼儿园的施工图设计文件是否满足《托儿所、幼儿园建筑设计规范》（JGJ39-2016）、《幼儿园建设标准》（建标175-2016 ）的有关规定。

2. 建设工程设计方案变更。开发建设单位应当按照规划条件和土地出让合同中规定的配套幼儿园的规模、设施标准等设置要求进行建设。未经规划建设行政主管部门批准，开发建设单位不得擅自缩减或修改配套幼儿园规模，不得擅自改变配套幼儿园的

位置。确需变更的，应经原审批部门批准后，按照相关法律法规

的规定执行。

3. 配套幼儿园建设动态监管。市自然资源局、住建局等规划建设行政主管部门应当将配套幼儿园的建设纳入住宅小区项目的工程勘察设计、工程质量、施工安全、工程竣工验收等建设过程进行动态监管。

4. 竣工验收。配套幼儿园建设和装修应与住宅小区开发建设同步进行。幼儿园建成装修后，开发建设单位应按规定及时组织相关部门进行竣工验收。

配套幼儿园的验收必须与住宅小区项目的验收同步进行。在办理住宅小区项目联合验收手续时，申请验收项目有要求设置配套幼儿园的，市教育局参与该项目的联合验收，对配套幼儿园的具体位置、面积、功能、建设标准等是否符合验收要求进行把关。

配套幼儿园未与住宅小区项目同步建成的，或者建设不符合规划条件或建设工程规划许可要求的，市自然资源局、住建局等规划建设行政主管部门不予办理工程竣工验收备案手续。

（四）移交和办证

1. 配套幼儿园的权属。配套幼儿园属国有公共教育资源，由开发建设单位代建，经验收合格后，将产权移交市教育局，由市教育局统一管理和使用，禁止将配套幼儿园进行分割、转让、出租、抵押或改变用途。本通知下发前已私有化和挪作他用的配套

幼儿园需在3年内完成移交，用于举办公办幼儿园或普惠性民办

园。

2. 配套幼儿园管理职责。市教育局负责全市配套幼儿园的移交统筹工作，负责配套幼儿园的管理和使用等工作。

3. 配套幼儿园移交程序。工程验收合格备案后，开发建设单位须在180个工作日内，将配套幼儿园移交市教育局，同时做好相关手续和资料的交接工作（包括工程前期手续、竣工图纸等所有工程档案材料），提供移交清单，由市教育局签署接收意见。市教育局在收到开发建设单位移交报告书后，对移交项目完成情况进行核实，向开发建设单位书面反馈移交意见。符合接收条件的，在180工作日内办理移交，签订《移交协议书》。配套幼儿园需办理有关权属转移或变更手续的，开发建设单位及相关职能部门应积极给予协助。

4. 配套幼儿园的管理使用。完成移交或回购的配套幼儿园，市教育局应及时行使职能，研究制定幼儿园的办学体制和招生范围，并保证该住宅小区内的幼儿优先入园，认真执行国家和自治区、自治州、库尔勒市有关公办幼儿园或普惠性民办园收费政策，按等级收费，严格收费行为。

5. 相关费用及安全责任分解。住宅小区配套幼儿园的建设和装修费用由开发建设单位出资。住宅小区配套幼儿园装修标准分

土建部分和水电部分，具体详见附表《库尔勒市住宅小区配套幼

儿园装修标准》，开发建设单位应按不低于附件标准进行装修。

住宅小区开发建设单位须负责移交前配套幼儿园所产生的费用及相关安全责任，并应承担国家和自治区、州、库尔勒市规定的质量保修期内相应质量保修责任和维修费用；移交涉及确权办证的费用由接收部门负责，移交后的装修施工、日常管理运营使用所产生的费用及相关安全责任，由使用和管理部门负责。如土地出让合同另有约定的，按出让合同的约定执行。

政府投资建设的保障性住房或安置房小区配套的幼儿园和由开发建设单位以出让形式取得建设地块的房地产项目配建的幼儿园建成后由开发建设单位移交给市教育局管理，移交过程中产生的契税、登记费等相关费用给予减免。

（五）责任分工

市发改委：负责配套幼儿园基本建设项目审批备案。

市自然资源局：对市教育局编制的城区幼儿园专项规划是否符合总体规划，应以本实施方案确定的规划标准为依据，在报请市人民政府审批前提出审查意见。负责将配套幼儿园纳入住宅小区规划设计条件，并明确配套幼儿园的用地面积和建设规模等指标，严格审查住宅小区的规划建设方案，确保幼儿园规划到位；结合方案审查，邀请市教育局对配套幼儿园建设方案的初步设计进行审查，在规划核实阶段邀请市教育局参与项目规划核实；未按规定配套幼儿园或配套幼儿园未随所在住宅小区同步建成的，不予核发规划验收合格证明。凡含有幼儿园规划的地块，在国有土地使用权出让和土地划拨前，预留幼儿园建设用地。幼儿园选址应将配套幼儿园建设位置、用地面积、建设规模等在土地出让方案中明确，在国有建设用地使用权出让合同中明确由开发建设单位按要求进行无偿配建。按照控制性详细规划对配套幼儿园提出规划条件，并严格按照规划条件及相关程序进行审批。在设计方案审批时应听取市教育局意见。督促开发建设单位按照批准的设计方案进行建设，确保配套幼儿园与住宅小区同步交付使用；对经批准的规划所确定的学前教育设施和教育用地，要维护其严肃性，不得随意改变用地性质。办理配套幼儿园房地产权属登记。

市住建局：负责配套幼儿园项目在施工后督促开发建设单位按照批准的施工图纸进行建设，确保配套幼儿园与住宅小区同步交付使用；组织市教育局等有关职能部门对配套幼儿园进行竣工验收。督促开发建设单位按合同或协议约定，在幼儿园竣工验收合格180个工作日内组织实施移交工作；督促开发建设单位及时向教育行政主管部门无偿移交配套幼儿园的前期相关手续、竣工图纸、验收手续等所有工程档案材料。

市教育局：参与住宅小区配套幼儿园的规划设计方案审查；做好配套幼儿园的接收、管理和使用工作，并及时办理幼儿园相关登记、审批等手续，确保办成公办或普惠性民办幼儿园。制定全市幼儿园布局专项规划，联系市自然资源局和住建局做好配套幼儿园布局和建设指标的审查工作。根据市人民政府的要求加强对小区配套幼儿园的管理，严格贯彻执行国家、自治区有关政策规定，坚持正确的办园方向，科学管理幼儿园，强化安全管理，规范办园行为，不断提高幼儿园的保教质量和办园水平。

各街道办事处（社区）及近郊乡（铁克其乡、恰尔巴格乡、英下乡）：履行发展学前教育的主体责任，主动推进新建小区配套幼儿园建设，在相关部门的积极支持下，负责做好配套幼儿园的补建、回收以及新移交配套幼儿园的管理等工作，确保将配套幼儿园举办成公办幼儿园或普惠性幼儿园。

开发建设单位：出让合同中约定移交的，在幼儿园竣工验收合格后180个工作日内，无偿将配套幼儿园产权移交市教育局，并无偿交付给市教育局管理和使用，同时移交与幼儿园建设相关的前期手续、竣工图纸等所有工程档案材料。

四、工作要求

（一）加强组织领导，统一思想认识。各有关部门、单位要积极行动起来，迅速把思想和行动统一到市党委、政府的决策部署上来，统筹协调，密切配合。各相关单位主要负责人是城镇小区配套幼儿园建设移交管理工作的第一责任人，要将城镇小区配套幼儿园建设移交管理工作纳入重要议事日程，明确任务、职责、时间节点，倒排工期，挂图作战，本着高度负责的态度确保我市按照国家和自治区、自治州规定的时间保质保量完成工作任务。

（二）加强部门协作，强化责任落实。各单位按照城镇小区

配套幼儿园建设移交管理各个环节的工作要求，加快建立相应工作机制。各相关部门要相互配合、联审联管，形成工作合力，稳步推进，主要负责人要亲自安排部署，将任务分解到人，定期检查落实。各单位要按照分解方案，结合实际，制定切实可行的工作措施，建立台账，细化分解任务，确保各项任务落地见效。各责任单位要将负责的工作进展情况向市人民政府分管领导汇报，确保各项工作落到实处。

（三）加强督促指导，严格责任追究。市人民政府将定期对各单位落实城镇小区配套幼儿园建设移交管理工作进行督导，对推进城镇小区配套幼儿园专项治理工作不力、工作进展缓慢的单位和个人进行通报批评，对问题突出的追究相关责任人的责任。
