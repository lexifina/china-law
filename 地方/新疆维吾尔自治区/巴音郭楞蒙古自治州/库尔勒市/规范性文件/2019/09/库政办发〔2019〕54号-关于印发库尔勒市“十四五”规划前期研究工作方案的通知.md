# 关于印发库尔勒市“十四五”规划前期研究工作方案的通知

各乡、镇、场，各街道办事处，市政府各部门，市属各单位：

《库尔勒市“十四五”规划前期研究工作方案》经市人民政府同意，现印发你们，请认真贯彻落实。

附件：1. 库尔勒市“十四五”规划前期研究工作方案

2. 关于成立库尔勒市“十四五”规划编制工作领导小组的通知

库尔勒市人民政府办公室

2019年9月12日

附件1

库尔勒市“十四五”规划前期研究工作方案

为贯彻落实国家、自治区、自治州“十四五”规划编制工作会议精神，充分发挥前期研究对规划编制的指导作用，扎实做好库尔勒市“十四五”规划前期研究工作，特制定本工作方案。

一、总体要求

“十四五”时期，是我国由全面建成小康社会向基本实现社会主义现代化迈进的重要时期，也是新疆社会全面稳定、加快经济高质量发展的关键时期。今年是“十四五”规划编制启动年，开展“十四五”规划前期重大问题研究，要以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大和十九届二中、三中全会精神，贯彻落实习近平新时代中国特色社会主义经济思想，贯彻落实习近平总书记关于新疆工作的重要讲话和重要指示精神，贯彻落实以习近平同志为核心的党中央治疆方略、特别是社会稳定和长治久安总目标，贯彻落实自治区党委“1 3 3 改革开放”工作部署和州党委及市党委工作要求，坚持稳中求进工作总基调，坚持新发展理念，坚持推动高质量发展，坚持以供给侧结构性改革为主线，坚持深化市场化改革、扩大高水平开放，加快建设现代化经济体系，不断增强人民群众的获得感、幸福感、安全感，努力实现我市社会稳定和长治久安，促进经济社会高质量发展作出贡献。

二、研究方法

课题研究要以社会稳定和长治久安总目标为统领。要坚持联系实际、注重实效的原则，更加突出课题研究成果的针对性、实用性，原则上以各责任单位自主研究为主，形成责任单位牵头、相关部门配合的工作格局，实现优势互补，共同攻关，形成高质量的研究成果，为科学编制“十四五”规划奠定基础。

三、研究课题

做好“十四五”规划前期研究，必须全面梳理、总结“十三五”时期的发展现状、存在问题及原因，深化研究事关库尔勒社会稳定和长治久安、经济社会高质量发展的全局性、前瞻性、关键性重大问题，提出“十四五”时期的重点任务、重大政策、重大工程项目和重大改革举措。

（一）库尔勒市“十四五”规划思路研究

研究要点：科学评价库尔勒市“十三五”经济社会发展主要成绩和突出问题，重点研究国际国内区内环境对库尔勒市“十四五”发展的影响，“十四五”时期库尔勒市经济社会发展的阶段性特征、趋势及面临的机遇和挑战，研究提出“十四五”库尔勒市经济社会发展的指导思想、基本思路、遵循原则、主要目标，以及发展的重点任务、重大战略、政策措施。

责任单位：市发改委

配合单位：市教育局、科技局、商务和工信局、民政局、财政局、自然资源局、生态环境局、住建局、交通局、水利局、农业农村局、文体和旅游局、卫健委、统计局、应急管理局、市场监管局、税务局

（二）库尔勒市“十四五”乡村产业振兴发展研究（在编：《库尔勒市乡村振兴战略规划（2018-2022年）》〈初稿〉）

研究要点：总结分析“十三五”时期农业产业发展现状、存在问题和增长潜力，围绕保持农民持续增收，以推进“种养加、粮经饲”一体化，优化农业产业结构，提出“十四五”时期乡村产业振兴的目标任务、思路及重点措施。

责任单位：市农业农村局（畜牧兽医局）

配合单位：市商务和工信局、人社局、自然资源局、生态环境局、住建局、交通局、水利局、文体和旅游局、林业和草原局

（三）库尔勒市“十四五”种植业发展研究

研究要点：总结“十三五”时期种植业发展现状、存在问题，围绕建立现代化农业产业体系，提出种植业发展的目标任务、思路及重点措施。

责任单位：市农业农村局（畜牧兽医局）

配合单位：市水利局、林业和草原局及各乡（场）

（四）库尔勒市“十四五”香梨产业发展研究

研究要点：总结分析“十三五”时期香梨产业发展现状、存在问题，围绕建立香梨产业标准化、集约化、产业化、市场化体系，创建一二三产业融合发展试点，提出香梨产业发展的目标任务、思路及重点措施。

责任单位：市林业和草原局

配合单位：市自然资源局、生态环境局、住建局、农业农村局（畜牧兽医局）、交通局、水利局、商务和工信局

（五）“十四五”水利发展研究

研究要点：总结“十三五”时期水利发展现状、存在问题，围绕“十四五”时期农业发展、工业生产、居民用水等对水安全保障和水资源需求，提出水利发展目标任务、思路和重要举措。

责任单位：市水利局

配合单位：市生态环境局、自然资源局、住建局、交通局、农业农村局（畜牧兽医局）、卫健委、林业和草原局

（六）“十四五”工业经济高质量发展研究

研究要点：总结分析“十三五”工业经济发展现状、存在问题及发展潜力，围绕招大引强，培育产业，扶持企业，壮大经济总量，打造增长新引擎等，提出推动工业经济增长的目标任务、思路和重要举措。

责任单位：市商务和工信局

配合单位：市统计局、发改委、上库园区经发局、塔什店镇、西尼尔镇、普惠乡、普惠农场、普惠牧场、经济牧场

（七）“十四五”石油石化产业发展研究（已编：《上库工业园区发展规划》）

研究要点：深入分析石油石化产业发展现状及前景，围绕立足现有产业资源，延伸石油石化产业产业链，提出石油石化产业发展的目标任务、思路及重点项目及保障措施。

责任单位：上库园区管委会

配合单位：市发改委、商务和工信局、自然资源局、生态环境局、商务局，库尔勒海关

（八）“十四五”商贸和现代服务业高质量发展研究

研究要点：总结分析“十三五”时期商贸和服务业发展现状、存在问题和增长潜力，围绕打造全疆物流次枢纽、南疆特色农产品集散中心和家政服务业发展，提出推动商贸和服务业高质量发展的目标任务、思路和重要举措。

责任单位：市商务和工信局

配合单位：市统计局、发改委、上库园区经发局、市场监管局

（九）库尔勒陆港型国家物流枢纽建设中长期发展规划研究

研究要点：重点研究库尔勒市经济社会与物流业发展总体情况和枢纽建设的空间布局、功能定位、建设模式、运行设计、预期成效等。

责任单位：市发改委

配合单位：市商务和工信局、交通运输局、库尔勒海关、库尔勒车务段、库尔勒经开区经信局

（十）“十四五”交通发展规划分析研究

研究要点：总结“十三五”时期交通运输发展现状，围绕深化国家交通枢纽示范市，研究环城高速、绕城高速、高速铁路，推进多式联运，提出“十四五”全方位一体化综合交通枢纽和交通体系的总体思路、实施路径、重点工作和保障措施。

责任单位：市交通运输局

配合单位：市发改委、生态环境局、自然资源局、住建局、市林业和草原局、卫健委、水利局、农业农村局（畜牧兽医局）

（十一）“十四五”文体旅产业发展研究（已编：《库尔勒市城市旅游规划2012-2025》《库尔勒市乡村旅游规划2016-2030》）

研究要点：分析库尔勒市文化和旅游发展面临的制约因素和机遇挑战，科学评估我市文化和旅游资源，研究文化和旅游发展的方向、目标、路径、模式和举措，提出文化和旅游融合发展的重点领域、重点项目、保障措施，推动文化和旅游融合发展。

责任单位：市文体和旅游局

配合单位：市发改委、自然资源局、生态环境局、农业农村局（畜牧兽医局）、交通局、商务和工信局、市场监管局、林业和草原局

（十二）库尔勒市“十四五”医康养一体化发展研究

研究要点：着重研究医康养一体化发展研究基础条件、基本思路、发展目标、重点举措和保障措施。

责任单位：市民政局、卫健委

配合单位：市发改委、财政局、自然资源局，第一人民医院，第二人民医院

（十三）“十四五”教育布局规划研究

研究要点：深入分析库尔勒市教育资源现状，围绕建设南疆教育高地的目标任务，统筹推进教育资源均衡化发展、城乡教育一体化发展，提出幼儿园、中小学、高中及职业教育布局方案。

责任单位：市教育局

配合单位：市发改委、市财政局、自然资源局

（十四）城市功能提升战略研究

研究要点：结合我市发展现状，围绕丝绸之路经济带核心区重要支点城市、新疆次级旅游集散中心战略目标，探索商贸、旅游、现代农业及其他特色产业等多业态驱动的新型城镇化路径，优化提升小城镇城市功能。

责任单位：市住建局

配合单位：市自然资源局、生态环境局、水利局、农业农村局（畜牧兽医局）、林业和草原局

（十五）“十四五”城市基础设施研究

研究要点：深入总结“十三五”时期城市基础设施发展现状，全面分析道路、供水、排水、燃气、污水处理、垃圾处理等城镇基础设施存在问题，围绕建设现代化区域中心城市的目标，提出“十四五”城镇基础设施重点项目，资金筹措方案等。

责任单位：市住建局

配合单位：市自然资源局、财政局

（十六）“十四五”生态环境保护研究

研究要点：围绕大幅改善生态环境质量、推动经济高质量发展、加强生态文明建设主要目标，重点开展“十四五”生态环境形势分析、如何与污染防治攻坚战相衔接、生态环境保护和生态修复的定位、生态文明制度建设、环境监管水平提升、规划实施保障机制等方面研究，摸清生态环境保护基础条件，理清面临的机遇和挑战，研判未来环境形势，明确发展思路。

责任单位：市生态环境局

配合单位：市发改委、自然资源局、住建局、水利局、农业农村局（畜牧兽医局）、卫健委、林业和草原局

（十七）“十四五”防范化解地方政府债务风险研究

研究要点：分析地方政府债务风险现状，提出“十四五”财政收支任务，研究持续规范化、制度化管理地方政府债务的措施，提升化解隐形债务能力和地方专项债发行能力和政府增信平台。研究如何按照政策规定用足、用好地方政府债券发行政策，为地方经济发展提供财力支撑。

责任单位：市财政局

配合单位：市发改委、教育局、住建局、交通局、水利局、农业农村局（畜牧兽医局）、文体和旅游局、卫健委、医疗保障局、林业和草原局

（十八）“十四五”巩固脱贫攻坚战成果研究

研究要点：坚持精准扶贫精准脱贫基本方略，以狠抓脱贫巩固、坚决防止返贫、确保脱贫成效高质量和可持续为着眼点，聚焦脱贫攻坚边缘户持续稳定脱贫和贫困人口较多的非贫困村能力提升，采取力度更大、针对性更强、作用更直接、效果更持续的措施，围绕增加农产品产值和附加值、增加就业等方面，全力推进脱贫巩固工作，实现贫困人口经营性收入、工资性收入、财产性收入持续增长，实现1317户3561名建档立卡贫困人口脱贫巩固提高无返贫。

责任单位：市扶贫办

配合单位：市扶贫开发领导小组成员单位

（十九）国土空间现状与形势分析研究（《库尔勒市国土空间规划》编制工作正处于对现行“两规”实施评估报告，资源环境承载力评价和空间适宜性评价专题研究报告阶段。）

研究要点：在对库尔勒市土地利用总体规划和城镇体系实施评估、资源环境承载能力和国土空间开发适宜性评价的基础上，分析我市空间发展现状，掌握我市空间开发秩序、开发强度和对本地区未来可持续发展具有重大影响的问题，分析对促进人口、经济、资源、环境的空间均衡发展，促进城乡空间均衡发展，落实新发展理念和高质量发展的重要意义。

责任单位：市自然资源局

配合单位：市发改委、商务和工信局、生态环境局、住建局、交通局、水利局、农业农村局（畜牧兽医局）、卫健委、林业和草原局

（二十）“十四五”能源消费总量和强度“双控”目标任务措施及《“十四五”节能降耗综合工作方案》研究

研究要点：汇总、分析我市“十三五”能耗强度和总量控制进展情况，总结、分析存在的问题和原因。分析展望“十四五”能耗“双控”趋势，对我市节能潜力进行比较分析，结合实施能耗“双控”的实践经验以及“十四五”生态文明建设要求，提出“十四五”能耗“双控”的对象范围、目标建议、分行业分解建议方案和《库尔勒市“十四五”节能降耗综合工作方案》，为相关决策提供参考和借鉴。

责任单位：市发改委

配合单位：市统计局、商务和工信局、生态环境局、住建局、交通局、农业农村局（畜牧兽医局）、机关事务管理局、科技局、市场监管局

（二十一）实施创新驱动发展战略研究

研究要点：围绕科技创新型城市建设，强化创新第一动力支撑，在把握科技创新规律和趋势基础上，分析我市创新能力、创新环境存在的问题，借鉴国内先进经验，研究深化科技体制改革的方向和路径，在建立健全产业链、创新链、资金链的协同机制，推动技术、人才、资本等创新资源集聚和高效配置机制，强化创新成果转化的激励机制等方面提出对策建议。

责任单位：市科技局

配合单位：市卫健委、农业农村局、住建局、商务和工信局、财政局、市场监管局、林业和草原局、公安局、文体和旅游局、上库园区

四、研究安排

（一）研究方式

课题责任单位分别牵头负责课题研究组织工作，坚持自主编制和借用外力相结合，组织精干力量全程融入委托方面团队，切实提高规划的有效性和实用性。

（二）进度安排

1. 各责任单位按程序组织开展课题研究。

2. 各责任单位2019年9月20日前向市发改委提交课题研究初步成果报告，并组织开展征求意见、评审等工作；2019年10月31日前向市发改委提交课题研究正式成果报告及评审意见报告。

3. 各责任单位2019年11月30日前将课题成果上报市人民政府。

4. 市发改委2019年12月20日前完成库尔勒市国民经济和社会发展“十四五”规划基本思路报告，上报市人民政府审定。

五、保障措施

（一）加强组织领导。成立库尔勒市“十四五”规划编制工作领导小组，统筹推进规划编制工作。领导小组办公室设在市发改委，市发改委抽调精干力量组成工作专班，全面对接规划编制单位，负责库尔勒市“十四五”规划前期研究、基本思路和规划纲要编制工作。

（二）把好研究质量关。各责任单位要切实发挥牵头抓总作用，认真组织开展课题研究工作。要组织骨干力量深入开展实地调研座谈、对外交流学习等活动，分析存在问题、研究面临形势，将课题研究成果融入到本行业本领域“十四五”发展思路。

（三）推进成果转化运用。根据专题研究成果，各有关部门要及时梳理再研究，进一步细化所在行业“十四五”发展目标及思路，提出一批重大工程项目、重大政策、重大改革举措，争取纳入国家、自治区、自治州“十四五”规划盘子，并为编制“十四五”规划纲要和专项规划打下坚实基础。
