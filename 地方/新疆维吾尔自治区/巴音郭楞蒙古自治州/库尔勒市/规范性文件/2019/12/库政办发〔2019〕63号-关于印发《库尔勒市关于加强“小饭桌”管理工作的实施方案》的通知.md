# 关于印发《库尔勒市关于加强“小饭桌”管理工作的实施方案》的通知

各乡、镇、场，各街道办事处，市政府各部门，市属各单位：

《库尔勒市关于加强“小饭桌”管理工作的实施方案》已经市十届人民政府第44次常务会议审议通过，现印发你们，请认真组织实施。

库尔勒市人民政府办公室

2019年12月20日

库尔勒市关于加强“小饭桌”管理工作的实施方案

为进一步加强学生“小饭桌”的监督管理，规范学生“小饭桌”经营行为，保障学生校外委托的餐饮食品安全，根据《新疆维吾尔自治区食品小作坊、小餐饮店、小食杂店和食品摊贩管理条例》相关规定，以及《自治区关于加强“小饭桌”管理工作指导意见》（新市监食经〔2019〕139号）文件要求，结合我市实际，制定此方案。

一、总体要求

坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻习近平总书记关于新疆工作的重要讲话和重要指示精神，贯彻落实以习近平同志为核心的党中央治疆方略、特别是社会稳定和长治久安总目标，贯彻落实食品安全监管“四个最严”要求，全面加强学生“小饭桌”规范管理，明确学生“小饭桌”监管职责，推进学生“小饭桌”经营向科学化、制度化、规范化方向发展，切实保障学生“小饭桌”食品安全。

二、成立“小饭桌”管理工作领导小组

组 长：周广新 市党委常委、副市长

副组长：杨新宇 市市场监督管理局党组书记

成 员：徐 红 市教育局局长

孙新明 市住建局局长

陆新民 市卫健委主任

孙卫刚 市公安局副局长

席 敏 市消防救援大队大队长

各乡镇场、街道办事处行政主要负责人。

“小饭桌”管理办公室设在市市场监督管理局，办公室主任由杨新宇同志兼任。市食安办（食品消费监督管理室）承担库尔勒市“小饭桌”管理工作领导小组办公室的日常工作。

三、职责任务

学生“小饭桌”的监督管理按照属地管理的原则，各有关部门按照职责做好指导和监管工作。

（一）乡镇场、街道办事处负责本辖区学生“小饭桌”的备案管理工作，核发备案卡，如实记录学生“小饭桌”开办者的姓名、住址、联系方式、经营地点等信息，于每月20日将相关情况报送至“小饭桌”管理办公室，并配合做好监督检查工作。

（二）市市场监督管理局负责辖区内学生“小饭桌”餐饮服务食品质量安全日常监管，做好开办者的食品安全知识培训。从业者每年应接受不少于40小时的餐饮服务食品安全集中培训，持有有效培训合格证明。

（三）市卫健委负责配合食品安全监督管理都门制定食品安全事故处置方案，对健康受到危害的人员进行医疗救治，对食物中毒事件进行流行病学调查。

（四）市住建局负责辖区内学生“小饭桌”生活、餐厨垃圾的收集、运输、处置等环节的监督检查。

（五）市公安局负责辖区内学生“小饭桌”治安管理工作，配合做好相关监督检查。

（六）市教育局负责指导辖区内的学校对学生进行食品安全知识宣传教育工作。

（七）市消防救援大队负责辖区内学生“小饭桌”消防安全的检查和指导，督促开办者做好消防安全工作。

四、实行备案管理

学生“小饭桌”实行备案管理。学生“小饭桌”的开办者须向经营所在地的乡镇场、街道办事处登记备案领取备案卡，并提供下列备案申请材料：

（一）申请书；

（二）申请人身份证明复印件；

（三）餐饮服务流程说明、设备设施清单，经营场所面积和可容纳就餐学生人数说明；

（四）开办者及从业人员健康证明；

（五）食品安全承诺书；

（六）消防安全承诺书。

申请人委托他人办理备案申请的，代理人应当提交授权委托书以及代理人的身份证明文件。

五、加强日常管理

（一）学生“小饭桌”开办者为学生食品安全和人身安全的第一责任人，应严格遵守《中华人民共和国食品安全法》《新疆维吾尔自治区食品小作坊、小餐饮店、小食杂店和食品摊贩管理条例》《新疆维吾尔自治区消防条例》等有关法律法规规定，切实加强食品安全工作，接受家长和社会监督。经营场所应当符合下列要求：

1．严禁使用易燃材料装修、装饰经营场所。要配备必要的灭火器、灭火毯等消防器材。除厨房外，其他部位不得存放、使用液化石油气罐；高层建筑内的学生“小饭桌”经营场所严禁使用液化石油气罐。

2．开办者及从业人员每年至少进行一次健康检查，取得并持有有效健康证明。

3．餐饮服务操作间、用餐间、卫生间应分别设置，人均就餐面积不得少于1.5平方米，加工操作场所应保持干净整洁。地面应使用防滑、防渗、易清洁材料铺设，内墙应铺设1.5米以上高度瓷砖墙裙，天花板应加装防霉、防水设施，门、窗应安装防蝇、防鼠、防尘设施。经营场所应配备清洗、消毒、保洁、冷冻、冷藏、食品留样、废弃物收集等设施设备，并确保正常使用。

4．经营者要建立健全进货查验、清洗消毒、健康检查、食品留样、应急处置等食品安全制度。一是食品原料的采购必须索证索票并进行登记，“小饭桌”采购食品原材料时应查验销售者的相关证件和检验（检疫）合格证明，索取销售发票，做好采购登记，不得采购和使用腐败变质或有异常的食品原料。二是具备上下水等基本加工操作条件，饮用水水质应符合国家《生活饮用水卫生标准》(GB5749)要求。三是实行留样制度，设专用留样冷藏设施，每种食品留样量不少于 100克，在冷藏条件下存放 48 小时以上并做好记录。四是食品和非食品应该分开存放，食品储存应设层架离地离墙10厘米存放。

5．要建立健全应急处突、防火检查、灾难自救和紧急疏散等相关制度。

（二）学生“小饭桌”开办者应当按照《新疆维吾尔自治区食品小作坊、小餐饮店、小食杂店和食品捕贩管理条例》的有关规定，诚信自律，守法经营；经营活动应当符合食品安全、环境卫生、消防安全等要求，保证所经营的食品卫生、无毒、无害。学生“小饭桌”经营场所内不得圈养宠物；严禁超范围超限量使用食品添加剂；不得向学生供应冷荤类食品、生食类食品、裱花蛋糕、四季豆、鲜黄花菜、野生蘑菇、发芽土豆等高风险食品以及法律法规禁止加工的其他食品；严禁在室(屋)内、应急通道、安全出口停放电动自行车或堆放杂物。

（三）各有关部门要加强对辖区内学生“小饭桌”的监督检查，督促学生“小饭桌”开办者建立并严格执行食品、食品原料、食品相关产品的进货查验、从业人员健康管理制度、食品安全管理制度及岗位责任制，规范经营管理；在校园周边等醒目位置及时公示监督检查结果。

（四）消费者投诉举报电话，市住建局：0996-2293079；市教育局：0996-2168236 ；卫健委：0996-2168402 ；市消防救援大队：96119；市市场监督管理局：12315。各有关部门对投诉举报学生“小饭桌”存在安全、卫生、消防、环保等问题线索的，要及时组织调查处理、督促整改，不符合规范要求的不得经营，对发现的违法违规行为，依法依规予以处理；涉嫌犯罪的，应当依法移送公安部门。

（五）各有关部门应结合实施餐饮业质量安全提升工程，探索创建一批设施齐备、制度健全、管理规范的学生“小饭桌”示范店，通过参观学习、召开现场会等形式总结推广好的经验和做法，逐步提高学生“小饭桌”食品安全管理水平；通过食品安全宣传教育和信息公示，引导在校中小学生到经营规范的学生“小饭桌”就餐。

（六）各有关部门要全面落实监管责任，各司其职，密切配合，做到齐抓共管，要引导家长不定期参观学生“小饭桌”并陪伴孩子就餐，形成部门监管、家长监督的社会共治局面。
