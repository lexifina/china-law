# 关于对和静县总体规划（2012-2030年）的批复

首页 / 政务公开 / 政策文件

关于和静县新建酱菜辣椒厂项目建设用地的批复

2016-01-02 00:00

和静县

和静县人民政府：

你县《关于和静县新建酱菜、辣椒厂建设项目用地的请示》（静政发〔2015〕95号）收悉。现批复如下：

一、同意你县在土地利用总体规划调整后所确定的范围内使用国有未利用地2.1114公顷，作为和静县新建酱菜、辣椒厂建设项目用地，用途为工业用地，以出让方式供地。

二、请据此批复，按有关规定办理用地手续。建设用地批后实施情况报州国土部门备案，州国土部门对项目用地供应情况进行跟踪检查。

自用地批准之日起两年内未进行建设使用的，本批复自动失效。

巴音郭楞蒙古自治州人民政府

2015年12月15日
