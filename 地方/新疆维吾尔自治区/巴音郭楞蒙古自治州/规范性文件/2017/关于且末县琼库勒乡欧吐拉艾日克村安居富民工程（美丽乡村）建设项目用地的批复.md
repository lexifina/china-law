# 关于且末县琼库勒乡欧吐拉艾日克村安居富民工程（美丽乡村）建设项目用地的批复

且末　琼库勒乡　安居富民　用地　批复

且末县人民政府：

《关于且末县琼库勒乡欧吐拉艾日克村安居富民工程（美丽乡村）建设项目用地的请示》（且政发〔2017〕157号）收悉。现批复如下：

一、同意你们在土地利用总体规划调整后所确定的范围内使用集体土地28.0148公顷，其中农用地13.1581公顷（耕地10.4002公顷、园地0.8449公顷、林地0.1453公顷、其他农用地1.7677公顷）、建设用地14.8567公顷，作为且末县琼库勒乡欧吐拉艾日克村安居富民工程（美丽乡村）建设项目用地，土地用途为农村宅基地用地，以划拨方式供地。0.1453公顷林地经且末县林业局认定为非林地，实地踏勘后认定为未利用地。

二、请据此批复，按有关规定办理用地手续。建设用地批后将实施情况报州国土部门备案，州国土部门对项目用地的供应情况进行跟踪检查。

三、自用地批准之日起两年内未进行建设使用的，本批复自动失效。

巴音郭楞蒙古自治州人民政府

2017年9月14日
