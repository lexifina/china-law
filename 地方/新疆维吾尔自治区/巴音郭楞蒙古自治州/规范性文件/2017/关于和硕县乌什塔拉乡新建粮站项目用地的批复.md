# 关于和硕县乌什塔拉乡新建粮站项目用地的批复

和硕 乌什塔拉乡 粮站 项目用地 批复

和硕县人民政府：

《关于和硕县乌什塔拉乡新建粮站项目用地的请示》（硕政发〔2017〕6号）收悉。现批复如下：

一、同意你们在土地利用总体规划调整后所确定的范围内使用国有未利用地3.9994公顷，作为和硕县乌什塔拉乡新建粮站项目用地，土地用途为仓储用地，以划拨方式供地。

二、请据此批复，按有关规定办理用地手续。建设用地批后将实施情况报州国土部门备案，州国土部门对项目用地的供应情况进行跟踪检查。

自用地批准之日起两年内未进行建设使用的，本批复自动失效。

巴音郭楞蒙古自治州人民政府

2017年4月7日
