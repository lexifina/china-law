# 关于和硕县实施乡镇规划2017年第一批（农村三项）建设项目用地的批复

和硕县人民政府：

《关于和硕县实施乡镇规划2017年第一批（农村三项）建设用地的请示》（硕政发〔2017〕47号）收悉。现批复如下：

一、同意你们在土地利用总体规划范围内使用集体土地0.9926公顷，其中农用地0.9247公顷（耕地0.9247公顷）、建设用地0.0679公顷，作为和硕县实施乡镇规划2017年第一批（农村三项）建设项目用地，土地用途为公共基础设施用地，以划拨方式供地。

二、请据此批复，按有关规定办理用地手续。建设用地批后将实施情况报州国土部门备案，州国土部门对项目用地的供应情况进行跟踪检查。

三、自用地批准之日起两年内未进行建设使用的，本批复自动失效。

巴音郭楞蒙古自治州人民政府

2017年12月15日
