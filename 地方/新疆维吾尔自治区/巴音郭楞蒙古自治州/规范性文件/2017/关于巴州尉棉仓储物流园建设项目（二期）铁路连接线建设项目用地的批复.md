# 关于巴州尉棉仓储物流园建设项目（二期）铁路连接线建设项目用地的批复

尉犁县人民政府：

《关于巴州尉棉仓储物流园建设项目（二期）铁路连接线建设项目用地请示》（尉政发〔2017〕109号）收悉。现批复如下：

一、同意你们在土地利用总体规划调整后所确定的范围内使用国有未利用土地6.0754公顷，作为巴州尉棉仓储物流园建设项目（二期）铁路连接线建设项目用地，土地用途为交通运输用地，以出让方式供地。

二、请据此批复，按有关规定办理用地手续。建设用地批后将实施情况报州国土部门备案，州国土部门对项目用地的供应情况进行跟踪检查。

三、自用地批准之日起两年内未进行建设使用的，本批复自动失效。

巴音郭楞蒙古自治州人民政府

2017年12月15日
