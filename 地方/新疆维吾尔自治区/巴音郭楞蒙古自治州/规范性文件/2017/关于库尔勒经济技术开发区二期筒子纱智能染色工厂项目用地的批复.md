# 关于库尔勒经济技术开发区二期筒子纱智能染色工厂项目用地的批复

库尔勒　开发区　智能染色　工厂　用地　批复

库尔勒经济技术开发区管委会：

《关于库尔勒经济技术开发区二期筒子纱智能染色工厂项目用地的请示》（库开管发〔2017〕87号）收悉。现批复如下：

一、同意你们在土地利用总体规划调整后所确定的范围内使用国有未利用地3.6496公顷，作为库尔勒经济技术开发区二期筒子纱智能染色工厂项目用地，土地用途为工业用地，以出让方式供地。

二、请据此批复，按有关规定办理用地手续。建设用地批后将实施情况报州国土部门备案，州国土部门对项目用地的供应情况进行跟踪检查。

三、自用地批准之日起两年内未进行建设使用的，本批复自动失效。

巴音郭楞蒙古自治州人民政府

2017年9月14日
