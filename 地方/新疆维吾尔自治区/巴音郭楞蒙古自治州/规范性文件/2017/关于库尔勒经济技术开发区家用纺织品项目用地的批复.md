# 关于库尔勒经济技术开发区家用纺织品项目用地的批复

库尔勒 开发区 纺织品 项目 用地

库尔勒经济技术开发区管委会：

你们《关于库尔勒经济技术开发区家用纺织品项目用地的请示》（库开管发〔2017〕11号）收悉。现批复如下：

一、同意你们在土地利用总体规划调整后所确定的范围内使用国有未利用地1.1563公顷（折合17.34亩），作为库尔勒经济技术开发区家用纺织品项目用地，用途为工业用地，以出让方式供地。

二、请据此批复，按有关规定办理用地手续。建设用地批后将实施情况报州国土部门备案，州国土部门对项目用地的供应情况进行跟踪检查。

自用地批准之日起两年内未进行建设使用的，本批复自动失效。

巴音郭楞蒙古自治州人民政府

2017年3月4日
