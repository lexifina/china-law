# 关于焉耆县实施乡镇规划2017年第三批（农村三项）建设用地的批复

焉耆县 2017年 第三批 建设用地 批复

焉耆县人民政府：

《关于焉耆县实施乡镇规划2017年第三批（农村三项）建设用地的请示》（焉政发〔2017〕34号）收悉。现批复如下：

一、同意你们在土地利用总体规划范围内使用集体农用地1.2347公顷，其中耕地1.2157公顷、林地0.0061公顷、其他农用地0.0129公顷，作为焉耆县实施乡镇规划2017年第三批（农村三项）建设项目用地，土地用途为公共基础设施，以划拨方式供地。

二、请据此批复，按有关规定办理用地手续。建设用地批后将实施情况报州国土部门备案，州国土部门对项目用地的供应情况进行跟踪检查。

三、自用地批准之日起两年内未进行建设使用的，本批复自动失效。

巴音郭楞蒙古自治州人民政府

2017年7月21日
