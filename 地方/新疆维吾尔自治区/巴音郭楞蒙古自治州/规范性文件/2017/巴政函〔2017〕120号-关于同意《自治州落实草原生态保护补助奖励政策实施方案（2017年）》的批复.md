# 关于同意《自治州落实草原生态保护补助奖励政策实施方案（2017年）》的批复

草原 生态保护 补助 奖励 批复

州畜牧兽医局、财政局：

你们《关于上报〈巴音郭楞蒙古自治州落实草原生态保护补助奖励政策实施方案（2017年）〉的请示》（巴牧发〔2017〕60号）收悉。经州人民政府研究，同意你们提出的自治州落实草原生态保护补助奖励政策实施方案（2017年），其中：实施草原禁牧面积1626.31万亩，落实草畜平衡面积8806.8万亩，请认真遵照执行。

巴音郭楞蒙古自治州人民政府

2017年7月12日
