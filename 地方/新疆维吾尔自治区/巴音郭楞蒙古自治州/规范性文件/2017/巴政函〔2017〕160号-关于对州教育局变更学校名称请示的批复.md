# 关于对州教育局变更学校名称请示的批复

州教育局：

你局《关于变更学校名称的请示》（巴教发〔2007〕138号）收悉。根据国家事业单位登记管理局修订的《事业单位登记管理暂行条例实施细则》，经州人民政府研究，现批复如下：

一、同意巴音郭楞蒙古自治州蒙古族高级中学更名为巴音郭楞蒙古自治州第三中学。

二、同意巴音郭楞蒙古自治州蒙古族小学更名为巴音郭楞蒙古自治州第一小学。

请你局依照规定做好更名有关工作。

巴音郭楞蒙古自治州人民政府

2017年8月30日
