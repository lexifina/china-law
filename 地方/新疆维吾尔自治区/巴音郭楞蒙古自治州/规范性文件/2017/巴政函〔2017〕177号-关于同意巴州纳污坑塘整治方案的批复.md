# 关于同意巴州纳污坑塘整治方案的批复

州环保局：

《关于审批和公开巴州纳污坑塘整治方案的请示》（巴环发〔2017〕231号）收悉。经州人民政府研究，同意你局制定的巴州纳污坑塘整治方案，按要求及时向社会公开。
