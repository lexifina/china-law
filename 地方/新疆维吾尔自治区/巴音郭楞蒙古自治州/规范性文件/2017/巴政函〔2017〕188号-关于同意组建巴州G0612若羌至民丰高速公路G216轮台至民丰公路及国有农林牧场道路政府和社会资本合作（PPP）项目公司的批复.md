# 关于同意组建巴州G0612若羌至民丰高速公路G216轮台至民丰公路及国有农林牧场道路政府和社会资本合作（PPP）项目公司的批复

组建 G0612 若羌 民丰 高速公路 PPP 项目 批复

州交通运输局：

你局《关于组建成立巴州G0612若羌至民丰高速公路、G216轮台至民丰公路及国有农林牧场道路项目政府和社会资本合作（PPP）项目公司的请示》（巴交发〔2017〕334号）收悉。经研究批复如下：

同意巴州交通投资有限公司（政府出资代表）与社会资本方（中铁城市发展投资集团有限公司）共同组建G0612若羌至民丰高速公路、G216轮台至民丰公路及国有农林牧场道路政府和社会资本合作（PPP）项目公司。请按有关程序办理。

巴音郭楞蒙古自治州人民政府

2017年10月10日
