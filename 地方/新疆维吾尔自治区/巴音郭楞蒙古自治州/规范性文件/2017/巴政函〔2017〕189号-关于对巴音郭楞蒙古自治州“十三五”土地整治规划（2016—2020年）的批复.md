# 关于对巴音郭楞蒙古自治州“十三五”土地整治规划（2016—2020年）的批复

各县市人民政府，州人民政府各部门、各直属单位，库尔勒经济技术开发区管委会，各园区（开发）管委会：

州国土资源局《关于提请下发巴音郭楞蒙古自治州土地整治规划（2016—2020年）的请示》（巴国土资发〔2017〕198号）收悉。现批复如下：

一、原则同意《巴音郭楞蒙古自治州土地整治规划（2016—2020年）》（以下简称《规划》）。

二、《规划》是自治州开展土地整治的基本依据，具有重要的指导作用。《规划》的实施要深入贯彻落实新发展理念，按照“开发与节约并重、快速发展与可持续开发并重”的原则，坚持最严格的耕地保护和节约集约用地制度，进一步优化城乡用地结构、增加有效耕地面积，提高耕地质量，改善生态环境，统筹安排土地整治工作，协调土地整治保护、产业发展、扶贫开发、城乡建设和生态环境保护的关系，促进土地资源永续利用和经济社会可持续发展。要稳步推进农民居住条件改善、农村基础设施建设、农业产业化发展和农村环境治理，进一步发挥土地整治在新农村建设和城乡统筹发展中的作用。

三、各县市、各部门、各单位要统一思想，增强大局意识和责任意识，切实加强对《规划》实施的组织领导，充分发挥《规划》的指导和规范作用。州国土资源局要切实抓好《规划》的组织实施，做好全州土地整治的管理协调工作。各县市、各部门、各单位都要坚决维护《规划》的权威性和严肃性，确保自治州“十三五”期间土地整治工作规范有序开展。

巴音郭楞蒙古自治州人民政府
