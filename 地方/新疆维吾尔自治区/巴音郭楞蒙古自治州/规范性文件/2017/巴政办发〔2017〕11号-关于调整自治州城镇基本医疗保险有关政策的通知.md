# 关于调整自治州城镇基本医疗保险有关政策的通知

各县市人民政府，州人民政府各部门、各直属机构，库尔勒经济技术开发区管委会，各园区（开发区）管委会：

为进一步提高自治州城镇基本医疗保险人员医疗待遇，减轻患者负担，按照社会保险基金“以收定支，收支平衡，略有结余”的原则，结合自治州城镇基本医疗保险基金历年运行情况，经自治州第十四届人民政府第3次常务会议同意，对自治州城镇医疗保险有关政策进行调整，现就有关事项通知如下：

一、城镇职工基本医疗保险待遇调整

（一）提高城镇职工基本医疗保险统筹基金最高支付限额。一个统筹年度内，城镇职工基本医疗保险统筹基金最高支付限额由6万元提高至8万元。

（二）提高城镇职工基本医疗保险门诊特殊慢性病、门诊大病限额标准。一个统筹年度内，城镇职工基本医疗保险门诊特殊慢性病限额标准：糖尿病由4500元提高至5200元；冠心病由5000元提高至5800元。门诊大病限额标准：各类恶性肿瘤（含白血病）门诊放化疗、慢性肾功能衰竭门诊透析（血液透析、腹膜透析）治疗、器官移植术后抗排斥及免疫抑制治疗由60000元提高至80000元。城镇职工基本医疗保险门诊特殊慢性病、门诊大病限额标准累计计入城镇职工基本医疗保险统筹基金最高支付限额。

二、城镇职工、居民基本起付线标准调整

（一）城镇职工基本医疗保险住院起付标准：一级医疗机构住院起付标准由175元调整为150元，县二级定点医疗机构住院起付标准由260元调整为300元，州二级定点医疗机构住院起付标准由300元调整为400元，三级定点医疗机构住院起付标准由400元调整为600元，转外就医定点医疗机构住院起付标准由700元调整为900元。已办理异地居住就医登记手续的退休人员按州域内起付线标准执行。

（二）城镇居民基本医疗保险住院起付线标准：一级医疗机构住院起付标准由150元调整为100元，县二级定点医疗机构住院起付标准仍为260元，州二级定点医疗机构住院起付标准由300元调整为400元，三级定点医疗机构住院起付标准由300元调整为500元，转外就医定点医疗机构住院起付标准由300元调整为600元。

三、转诊转院报销政策调整

凡未按规定逐级办理转诊转院手续在本区域外住院的（不含异地安置人员），降低符合政策范围内支付医疗费的报销比例，即在正常报销比例的基础上，下降20%予以报销。异地安置人员在安置地之外住院的，无特殊原因的，参照此办法执行。

四、以上政策调整自2017年3月11日起执行
