# 关于转发《国家农业综合开发办公室关于印发的通知》的通知

首页 / 政务公开 / 政策文件

关于进一步加强和规范州管国有企业监督管理工作的意见

2017-12-11 00:00

规范 国有企业 管理 意见

各县市人民政府，州人民政府各部门、各直属机构，库尔勒经济技术开发区管委会，各园区（开发区）管委会：

为贯彻落实《中共中央、国务院关于深化国有企业改革的指导意见》（中发〔2015〕22号）和自治区党委、政府关于加强国企监管的有关要求，深入推进国有企业改革，有效解决当前州管国有企业经营管理中存在的突出问题，进一步加强和规范国有企业监督管理工作，推动州管国有企业做大做优做强，确保国有资产保值增值，结合我州实际，提出以下意见。

一、进一步明确国资委监管职责

（一）明确出资人职责机构权限。州国资委代表州人民政府履行出资人职责，是负责监督管理企业国有资产的特设机构，依法享有企业所有者权益和资产收益、参与重大决策和选择管理者等出资人权利。

（二）明确国有企业国有资产管理内容。州国资委负责企业国有资产产权登记、产权界定、产权划转、产权处置、资产评估监管；审核所监管企业资本金变动、股权转让及发债方式；负责所监管企业的对外担保管理；指导和监督检查企业清产核资工作；负责企业资产统计、综合评价等基础管理工作，对企业资产质量、财务状况、经营成果、发展能力等情况进行分析和评价，定期向州人大常委会、州人民政府报告企业国有资产运营状况；负责国有及国有控股企业资产处置，审核资本金变动、股权转让及落实企业国有资产产权交易监督管理制度，促进企业国有资产产权合理流动，防止企业国有资产流失；按照国家产业政策和自治区、自治州国民经济和社会发展规划，对企业的发展战略、规划、投资方向和投融资总量进行监督管理，建立专家评审制度；负责对国有及国有控股企业的国有资产进行预算管理，执行国有资本收益收缴，编制国有资本经营预算草案，并对资本收益的使用进行监督。

（三）明确国有资产监督职责。州国资委代表州人民政府依法向州直国有独资企业、国有独资公司派出监事会和向控股、参股企业派出监事。监事会和派出监事依照国家、自治区和国资委有关规定履行监督职责；依据国家和自治区有关规定，制定完善所监管企业经济责任审计工作制度，负责对直接监管企业负责人进行离任和任期的经济责任审计工作；建立企业财务顾问制度，依法对直接监管企业财务进行监督，建立和完善国有资产保值增值指标体系，通过统计、稽核对所监管国有资产的保值增值情况进行监管，维护国有资产出资人的权益；直接监管企业须定期向州国资委报告财务状况、生产经营状况和国有资产保值增值状况。

二、进一步加强国有企业领导人员管理

（四）加强领导人员选拔任用管理。建立符合社会主义市场经济体制和现代企业制度要求的企业领导人员选用机制。州国资委通过法定程序，按照管理权限，除由州党委管理的企业党政领导人员外，州国资委任免或者建议任免授权监管企业的下列人员：国有独资企业的经理、副经理、财务负责人和其他高级管理人员；国有独资公司的董事长、副董事长、董事、监事会主席和监事；依照公司章程，向国有资本控股公司股东会、股东大会提出董事、监事人选，推荐董事长、副董事长和监事会主席人选；依照公司章程，向国有资本参股公司提出董事、监事人选。

（五）加强国有产权代表履职管理。国有产权代表要对行使职权结果负责，对失职、失察、重大决策失误等过失承担责任，对违反法律法规的规定承担法律责任。国有产权代表在履职过程中，要对重大事项及时请示报告。公司股东会、董事会和监事会决策、决定重大事项的，国有产权代表应提前15个工作日将事项报告，并按照回复意见正确行使表决权，会议结束后5个工作日内要将表决结果以书面形式反馈报告。国有产权代表未按规定请示报告或报告虚假情况的，州国资委要视情况给予诫勉谈话、警告，造成严重后果的给予免职或依法追究经济、法律责任。州国资委负责组织考核国有产权代表，全面考核德、能、勤、绩等方面的表现，突出考核个人品德、业务能力、分管工作完成情况、廉洁从业等内容。考核结果作为国有产权代表表彰、提拔、留任、降职、免职以及作为薪酬和奖金核定、发放的主要依据。考核结果及相关评价材料记入考核对象个人档案。

（六）加强国有企业负责人薪酬管理。州国资委负责所监管企业工资分配管理工作。要加快建立有效的激励约束机制，健全所监管企业的绩效评价指标体系，着力用清晰的目标和与贡献相适应的薪酬激励和约束企业负责人，依据目标完成情况确定考核等级，实现企业负责人薪酬增长，企业职工工资增长和企业经营效益同比例增长。规范企业负责人薪酬统计和资料管理，严禁兼职领取薪酬和奖金，建立薪酬追索扣回机制，加强退休及离岗企业负责人的薪酬管理。州国资委每年6月30日前督促直接监管企业负责人报告薪酬兑现情况。

（七）加强廉洁从业管理。切实落实国有企业反腐倡廉“两个责任”，国有企业党组织要切实履行好主体责任，派驻的纪检机构要履行好监督责任。加强党性教育、法治教育、警示教育，引导国有企业领导人员坚定理想信念，自觉践行“三严三实”要求，正确履职行权。建立切实可行的责任追究制度，与企业考核等挂钩，实行“一案双查”。加强对国有企业领导干部任职期间及离职和退休后从业行为管理。

三、进一步规范国有企业重大事项监管

（八）规范报告程序。要对重大事项实行分类管理，厘清核准、报备、报告相关程序。

1．须核准的重大事项有：国有独资企业、国有独资公司、国有资本控股公司的合并、分立、改制、上市、解散、申请破产；国有独资企业、国有独资公司增加或减少注册资本、分配利润、发行债券、投资、转让国有股权等事项，按有关法律或行政法规规定报州人民政府批准；国有控股公司增加或者减少注册资本、分配利润、发行债券、投资、转让国有股权等事项，依照有关法律、行政法规以及公司章程规定，由股东会、股东大会或董事会决定的，国有股东代表须按照州国资委的指示提出提案、发表意见、行使表决权，并将其履行职责的情况和结果及时报告州国资委；国有参股企业合并、分立、改制、上市，增加或者减少注册资本，发行债券，对外进行投资，为他人提供大额担保，转让财产，进行捐赠，分配利润，以及解散、申请破产等事项，遵照公司章程的规定，由股东会、股东大会决定的，国有股东代表须按照州国资委的指示提出提案、发表意见、行使表决权，并将其履行职责的情况和结果及时报告州国资委；国有监管企业资产处置，处置金额500万元（含500万元）以上的，其资产处置方案报请州人民政府审定；处置金额占企业上年末资产总额10%以下或500万元以下的（处置金额与处置比例的选择按从低原则），由州国资委批准；国有监管企业清产核资，资产核销金额达到500万元（含500万元）以上的，由州国资委审核后报州人民政府审定；资产核销金额在500万元以下的，由州国资委审批；企业为他人担保事项，国有独资企业、国有独资公司须报州国资委审批，国有控股公司遵照公司章程的规定，由股东会或董事会决定的，国有股东代表须按照州国资委的指示提出提案、发表意见、行使表决权，并自股东会或董事会闭会之日起5个工作日内将履行的有关情况书面报告州国资委；企业中长期发展规划、年度对外投资计划、主营业务外的年度固定资产投资计划，国有独资企业、国有独资公司及其重要子企业须报国资委核准，国有控股公司遵照公司章程的规定，由股东会或董事会决定的，国有股东代表须按照州国资委的指示提出提案、发表意见、行使表决权，并自股东会或董事会闭会之日起5个工作日内将履行的有关情况书面报告州国资委；企业收入分配制度改革方案，国有独资企业、国有独资公司由州国资委核准，国有控股公司遵照公司章程的规定，由股东会、股东大会决定的，国有股东代表须按照州国资委的指示提出提案、发表意见、行使表决权，并自股东会或董事会闭会之日起5个工作日内将履行的有关情况书面报告州国资委；公司章程的制定或修改，国有独资公司由州国资委批准，国有控股公司、国有参股公司遵照公司章程的规定，国有股东代表须按照州国资委的指示提出提案、发表意见、行使表决权，并自股东会或董事会闭会之日起10个工作日内将履行的有关情况书面报告州国资委；按有关规定应报州国资委核准的其他重大事项。

2．须报备的重大事项：国有独资企业、国有独资公司、国有控股公司领导班子成员（非董事、监事）的聘任或解聘，及财务负责人和重要子企业主要负责人的聘任或解聘；企业主营业务内年度固定资产投资计划；企业年度财务预算方案、决算方案；企业资产处置，处置金额占企业上年末资产总额10%以下的；企业对外捐赠；次年6月30日前须报备企业负责人薪酬兑现情况；企业制定的“三重一大”实施办法；按有关规定应向州国资委报备的其他重大事项。

3．须报告的重大事项：涉及损害国有资产权益的仲裁、诉讼或者企业国有资产被有关机关查封、冻结、扣押的；企业发生重大安全生产和环境破坏事故造成企业人员伤亡和财产损失的；企业发生越级、集体上访事件的；企业管理层持有本企业和所属控股、参股企业股份；企业主要领导人员出国（出疆）；按有关规定应报告的其他事项。

（九）规范投资行为。

1．重大投资前：国有监管企业要在每年3月10日前将经董事会审议通过的年度投资计划报州国资委。年度投资计划主要包括以下内容：投资主要方向和目的；投资规模及资产负债率水平；投资结构分析；投资资金来源；重大投资项目情况。州国资委要依据相关法律、法规和国有资产监管规定，从投资项目实施的必要性、对企业经营发展的影响程度、企业投资风险承受能力等方面履行出资人审核把关程序，并对有异议的项目在收到相关材料后20个工作日内向企业反馈书面意见。必要时，可委托第三方咨询机构对投资项目进行论证。

2．实施过程中：出现重大事项、重大调整、重大问题等情况，要在情况出现10日内向州国资委书面报告。重大情况包括：对外投资额、资金来源及构成进行重大调整，将使企业负债过高，超出企业承受能力的；股权结构发生重大变化，导致控股权发生转移的；投资合作方违约，出现严重损害企业利益情况的；年度投资亏损超过企业（集团）净资产1%（含1%）以上的，或单项亏损超过50万元（含50万元）以上的。

3．投资完成后：编制年度投资完成情况报告，并于下一年1月31日前报州国资委。年度投资完成情况报告包括但不限于以下内容：年度投资完成总体情况；年度投资效果分析；重大投资项目进展情况；年度投资后评价工作开展情况；年度投资存在的主要问题及建议。

（十）规范责任追究。完善国有企业领导人员责任追究制度，建立重大决策终身责任追究制度，对违反规定、未履行或未正确履行职责造成国有资产重大损失以及其他严重不良后果的，严肃追究责任。企业领导人员违反履职行为规范，造成国有资产损失的，依据《公司法》《企业国有资产法》相关规定处理。

本意见由州国资委负责解释，自发布之日起实施。县市国资监管机构及国有企业和其他国有企业参照执行。
