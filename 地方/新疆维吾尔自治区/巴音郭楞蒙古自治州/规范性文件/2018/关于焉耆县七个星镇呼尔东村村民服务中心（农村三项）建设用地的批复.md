# 关于焉耆县七个星镇呼尔东村村民服务中心（农村三项）建设用地的批复

焉耆　七个星镇　呼尔东村　服务中心　农村三项　用地　批复

焉耆县人民政府：

《关于焉耆县七个星镇呼尔东村村民服务中心（农村三项）建设用地的请示》（焉政发〔2018〕36号）收悉。现批复如下：

一、同意你们在土地利用总体规划调整后所确定的范围外使用集体土地1.4592公顷，其中：农用地（耕地）1.4592公顷，作为焉耆县七个星镇呼尔东村村民服务中心（农村三项）建设用地，土地用途为公共设施用地，以划拨方式供地。

二、请据此批复，按有关规定办理用地手续。建设用地批后将实施情况报州国土部门备案，州国土部门对项目用地的供应情况进行跟踪检查。

巴音郭楞蒙古自治州人民政府

2018年10月15日
