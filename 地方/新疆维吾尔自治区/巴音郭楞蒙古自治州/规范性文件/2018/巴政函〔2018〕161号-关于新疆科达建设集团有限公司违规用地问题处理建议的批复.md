# 关于新疆科达建设集团有限公司违规用地问题处理建议的批复

库尔勒经济技术开发区管委会：

《关于对新疆科达建设集团有限公司违规用地问题处理建议的请示》（库开管发〔2018〕130号）收悉。经研究，同意州国土资源局提出的意见（巴国土资发〔2018〕150号），请严格按照相关政策要求依法做好后续工作。

此复。

巴音郭楞蒙古自治州人民政府

2018年9月20日
