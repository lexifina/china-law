# 关于印发《自治州城市环境保护管理长效机制》的通知

各县市人民政府，州人民政府各部门、各直属机构，库尔勒经济技术开发区管委会，各园区（开发区）管委会：

《自治州城市环境保护管理长效机制》已经州人民政府同意，现印发给你们，请认真贯彻执行。

巴音郭楞蒙古自治州人民政府办公室

2018年7月24日

自治州城市环境保护管理长效机制

为深入贯彻党中央、国务院关于生态文明建设系列决策部署，全面落实自治区党委生态环境保护工作要求，认真践行环保优先和绿色发展理念，结合州情实际，特制定本长效机制。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大和十九届二中、三中全会精神，贯彻落实习近平总书记关于新疆工作的重要讲话和重要指示精神，贯彻落实党中央治疆方略特别是社会稳定和长治久安总目标，坚持以习近平生态文明思想为引领，聚焦自治区党委“1+3+3+改革开放”总体部署，统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，牢固树立和践行新发展理念，理顺城市管理体制，创新城市管理模式，提高城市管理效能，按照“谁主管、谁负责”“谁决策、谁负责”原则和“管发展必须管环保、管行业必须管环保、管生产经营必须管环保”原则，建立责权统一、科学精细、全面覆盖、运行顺畅的城市管理长效机制。

二、工作任务

（一）加强城市建筑工地扬尘污染防治

1.强化建设单位对施工扬尘治理工作力度，将施工扬尘治理费用列入工程概算，在工程承包合同中明确相关内容，并及时足额支付。施工单位要建立施工扬尘治理责任制，编制扬尘控制专项方案，在施工现场公示扬尘治理主要措施、责任人、主管部门等信息，并及时向当地主管部门报送施工扬尘治理措施落实情况。

2.渣土运输单位要建立工程渣土（建筑垃圾）运输扬尘污染防治管理制度和相关措施，全面落实“全封闭施工、场地坪硬化、车辆冲洗、预拌混凝土使用、烟尘排放控制、易扬尘物质处置、高空垃圾处理、渣土密闭运输、施工湿法作业、视频监控”等扬尘污染防治10项强制性规定，严格按照《自治区建筑工地重污染天气应急预案》，采取有效应对措施，加强控尘降尘工作力度。

3.在大风天气期间，负责施工项目的主管部门要及时劝告施工单位主动停工，对暂不能停工的工程，要严格落实施工扬尘污染防治强制性措施。对施工场内道路、砂浆搅拌场所及土方开挖、爆破、拆除、切割等易产生扬尘的作业（工序）要采取洒水降尘措施或设置喷淋设施。建筑工地的建筑垃圾运输车辆离场前要按照要求进行冲洗作业，不得带泥驶离工地。

责任单位：各县市人民政府，州住建局、环保局、交通运输局、水利局、林业局，库尔勒经济技术开发区管委会

（二）建筑工地噪声污染防治

4.在噪声敏感建筑物集中区域内，禁止夜间进行产生环境噪声污染的建筑施工作业，但抢修、抢险作业和因生产工艺上要求或者特殊需要必须连续作业的除外。因特殊需要必须连续作业的，需出具县级以上人民政府或者其有关主管部门的证明，同时告知附近居民。

5.施工现场宜选用低噪声、低振动的设备，强噪声设备宜设置在远离居民区的一侧，并应采用隔声、吸声材料搭设防护棚或屏障。

6.工程项目各参建单位要加强施工作业管理。建设单位不得强令施工单位违反施工规程进行施工活动；施工单位要合理规划作业时间；监理单位要加强监督检查，及时制止施工噪声扰民行为发生。

7.加强中高考期间施工噪声专项巡查力度。对发生噪声扰民的工程项目，要坚决责令立即整改；对整改不力或情节严重的，将严格按照有关法律法规进行处罚。

责任单位：各县市人民政府，州住建局、环保局、教育局，库尔勒经济技术开发区管委会

（三）加强城市上宅下店餐饮油烟和噪声污染防治

8.依法取缔非法占用公共场所露天经营餐饮、烧烤（夜宵排档），有效规范临时设摊餐饮经营行为，严厉查处未安装油烟净化设施和不正常使用油烟净化设施行为，大力改造沿街直排油烟场所。

9.禁止在居民住宅楼、未配套设立专用烟道的商住综合楼以及商住综合楼内与居住层相邻的商业楼层内新建、改建、扩建产生油烟、异味、废气的餐饮服务项目。

责任单位：各县市人民政府，州住建局、环保局、卫计委、食药局、工商局，库尔勒经济技术开发区管委会

（四）加强居民小区垃圾收集处置工作

10.通过设立宣传点、发放宣传单等多种方式，向小区居民和社会各界宣传垃圾倾倒规则。生活垃圾收集点的设置位置原则上要方便业主，道路两侧和住宅出入口应设置废物箱。物业服务企业要制定环境卫生管理规定、环境卫生质量标准、卫生设施维护保养办法、防疫应急预案等规章制度。建立环境卫生设施资料档案，明确保洁区域，实行保洁责任制。

11.公共区域、道路和公共设施设备要保持整洁，保洁措施应结合当地不同季节的气候环境，根据服务等级规定，制定工作措施。生活垃圾坚持分类收集，配置密闭式垃圾收集容器，并配备专用垃圾清运车清运。同时，按照有关规定对公共区域有害生物预防和控制，投放药物应事先公告，投药点要有显著标识。

12.各物业企业要根据小区的相关规定，做好垃圾容器清洁处理工作，建立垃圾清运台账。对发现垃圾桶装满时，要及时向环卫部门报告，做好登记。物业企业要对垃圾设施进行及时清洁，对已破损严重的垃圾桶要及时更新。

责任单位：各县市人民政府，州住建局、环保局、卫计委，库尔勒经济技术开发区管委会

（五）合理设置城市通讯基站

13.无线电管理机构是基站管理的主管部门，负责基站的建设、监督和管理工作。各级发改、环保、国土、住建、交通、公安、城管等部门要按照各自职责，协同做好基站管理工作。原则上要求城市通信基站由铁塔公司统一规划布局建设，各运营商不再单独建设通信基站。基站规划布局要具有相关资质的专业机构编制选址论证报告，确保布局合理及居民生产生活不受影响。

责任单位：各县市人民政府，州无线电管理局、环保局、发改委、国土资源局、住建局、交通运输局、公安局，库尔勒经济技术开发区管委会

（六）加强规划批前审核

14.建设项目开工建设前要严格履行规划审批手续，建设项目的环境影响评价文件未依法经审批部门审查或者审查后未予批准的，建设单位不得开工建设。

责任单位：各县市人民政府，州住建局、环保局、发改委、财政局、国土资源局、水利局、农业局、交通运输局、安监局、公安局、无线电管理局、工商局、食药局、卫计委，库尔勒经济技术开发区管委会

三、保障措施

（一）加强组织协调。各县市人民政府、库尔勒经济技术开发区管委会要建立健全城市管理例会制度，定期召开专题会议，督促检查城市管理措施落实情况，研究解决城市管理中的重大问题，对检查中发现的问题要及时督办。进一步完善工作制度，推进数字化城管工作机构、处置流程、考核体系的规范化建设。

（二）严格监督考核。依托数字化城管平台，组织开展城市综合管理的日常考评工作，每季度汇总通报考评情况并在媒体上公布。运用综合电子监察平台，将城市综合管理工作纳入电子监察范畴。发挥市民监督和政风行风监督员的作用，加强城市综合管理长效机制落实情况的宣传与监督。对有关职能部门的考评，要纳入目标责任制综合绩效考评范围。

（三）加大资金投入。按照城市建设管理和管养体制，州、县市两级财政要对城市管理必需经费予以保障，确保城市管理配套资金逐年增长。对环卫设施相对偏少及中心城区保洁机械化作业率偏低的情况，要适量添置作业机械，增设垃圾收集容器，加快公厕、垃圾中转站等设施建设步伐，着力提高中心城区环卫管理水平。同时，适当增加城管协管员、市容秩序管理员、环卫职工的待遇，进一步提高工作积极性。

（四）加强宣传教育。积极引导居民养成积极向上、健康文明的生活方式，全面提高居民整体文明素质。不断扩大城市管理志愿者队伍，动员更多居民关心、支持和参与城市管理。畅通政府与居民沟通渠道，充分发挥“12319”城管热线的桥梁和纽带作用。积极组织开展城市管理热心市民评选活动，营造全社会齐抓共管的良好氛围。

（五）强化督导问责。州人民政府将对各县市、各部门、各单位长效机制建立落实情况进行跟踪督查，确保长效机制建立工作落地生根。对政策执行不力、工作棚架的，依据有关规定，启动党政领导问责程序，对党政主要负责人和其他责任人实行问责追究，严肃处理。
