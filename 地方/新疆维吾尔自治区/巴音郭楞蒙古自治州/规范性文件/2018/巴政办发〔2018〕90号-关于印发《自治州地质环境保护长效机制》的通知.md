# 关于印发《自治州地质环境保护长效机制》的通知

各县市人民政府，州人民政府各部门、各直属机构，库尔勒经济技术开发区管委会，各园区（开发区）管委会：

《自治州地质环境保护长效机制》已经州人民政府同意，现印发你们，请认真贯彻执行。

巴音郭楞蒙古自治州人民政府办公室

2018年9月6日

自治州地质环境保护长效机制

为深入贯彻党中央、国务院生态文明建设决策部署，加快推进自治州生态文明建设，有效控制人类经济活动对地质环境的影响和破坏，结合我州实际，制定本长效机制。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九大和十九届二中、三中全会精神，贯彻落实以习近平同志为核心的党中央治疆方略特别是社会稳定和长治久安总目标，认真践行习近平生态文明思想，牢固树立新发展理念，聚焦自治区党委“1+3+3+改革开放”总体部署，统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，以中央环保督察为契机，以改善生态环境质量为核心，以解决地质环境领域突出问题为重点，以深化改革为动力，推进生态文明环境保护各项工作，为建设美丽巴州奠定坚实基础。

二、保护对象

重点是矿山地质环境保护与恢复。

三、总体目标

2018年底前完成自然保护区内矿山企业的退出和矿山地质环境恢复治理工作；2019年底前完成已闭坑矿山、政策性关闭砂石、黏土、小煤矿等地质环境恢复治理工作及巴州矿山地质环境保护与治理规划编制；2021年底前完成城市周边矿山搬迁工作；2025年底前所有矿山企业达到自治区级绿色矿山建设标准。

四、主要任务

（一）开展矿山地质环境现状调查。以中央环保督察为契机，在对历年已关闭矿山（废弃矿山、政策性关闭矿山）调查摸底的基础上，组织专业队伍重点对68个关闭矿山、368个生产矿山（含在建矿山）开展矿山地质环境调查工作，全面查明在建矿山、生产矿山、废弃矿山、政策性关闭矿山地质环境问题的类型、分布、规模和危害程度。（牵头单位：州国土资源局；责任单位：州环保局、安监局、畜牧局、林业局，各县市人民政府）

（二）明确治理责任。各县市人民政府立即开展矿山地质环境问题认定，对计划经济时期遗留或责任人灭失的矿山地质环境问题，由各县市人民政府负主体责任，统筹组织有关部门分工负责、分类施策，加大资金筹措力度，逐步解决遗留问题；对在建或生产矿山造成的地质环境问题，由矿山企业负主体责任，按照矿山地质环境保护与恢复治理方案要求，实行“边开采、边治理”，做好本矿山地质环境恢复和综合治理。积极鼓励第三方治理，地方政府、矿山企业可采取“责任者付费，专业化治理”的方式，将产生的矿山地质环境问题交由专业机构治理，提高治理效率和质量。（牵头单位：各县市人民政府；责任单位：州国土资源局 、环保局、安监局、畜牧局、林业局）

（三）制定治理方案。在开展巴州矿山地质环境详细调查基础上，根据矿山地质环境调查和责任划分情况，以自然保护区、重要景观区、居民集中生活区的周边和重要交通干线、河流湖泊直观可视范围“三区两线”及基本农田保护区等为重点，制定矿山地质环境恢复和综合治理方案。通过划定重点治理分区，明确治理时间表，统筹部署，分步实施，确保工作目标实现。（牵头单位：州国土资源局；责任单位：州财政局、环保局、农业局、畜牧局、林业局）

（四）强化源头预防。严格矿山开发准入管理，把保护放在优先位置，严格执行矿产资源规划，落实规划分区管理制度，严格落实生态红线制度。严格审批新建矿山，对规模小、布局不合理、采矿技术方法落后、严重破坏地质环境的已建矿山，全部依法进行产能优化或关停。加强资源综合利用，推进尾矿和废石综合利用，从尾矿和废石中提取有价值组分、生产高附加值建筑材料，以充填、无害化农用和生态应用为重点，加快先进适用技术推广应用，组织实施尾矿和废石综合利用示范工程，不断提高尾矿和废石综合利用率，扩大综合利用产业规模，减少对生态环境的影响。（牵头单位：州国土资源局；责任单位：州环保局、畜牧局、林业局、煤炭局，各县市人民政府）

（五）完善相关政策。整合已有政策，根据实际情况，探索出台整合政策与资金、吸引社会资金投入矿山地质环境治理的有关政策措施，构建“政府主导、政策扶持、社会参与、开发式治理、市场化运作”的矿山地质环境恢复和综合治理新模式，切实提高治理成效。完善用地政策，根据不同矿种和开采方式，建立差别化、针对性强的矿业用地政策，对因采煤塌陷（非安全生产责任事故）或其他矿山地质灾害造成的农用地或其它土地损毁，按照土地变更调查工作要求和程序开展实地调查，经审查通过后纳入年度土地变更调查进行变更，涉及农用地变更为未利用地，按照审查及认定规范和程序报批。完善矿产资源开发政策，在符合规划、保障安全的前提下，依法开发存量资源，为区域综合治理提供资金保障。合理调整矿产开发布局，对伴生矿优化开采顺序，对采石取土成区连片、问题集中的地方，依法依规进行矿产资源开发整合，落实矿山地质环境问题的主体责任。加快推进绿色矿业发展示范区和绿色矿山建设，促进矿产资源开发与生态环境保护协调发展。（牵头单位：各县市人民政府；责任单位：州国土资源局、环保局、安监局、畜牧局、林业局、煤炭局）

五、保障措施

（一）组织保障。自治州成立以分管副州长为组长，分管副秘书长任副组长，州发改、财政、国土、环保、住建、交通、煤炭、县市人民政府等为成员单位的地质环境保护工作领导小组。领导小组办公室设在州国土资源局，负责领导小组日常事务工作，办公室主任由州国土资源局局长兼任。领导小组在州人民政府统一领导下，按照部门职责权属，加强联动、密切协作，加大矿山地质环境监管力度，扎实推进历史遗留矿山地质环境问题的恢复治理，督促矿山企业切实履行矿山地质环境恢复治理主体责任。

（二）资金保障。各县市要加大资金投入，拓宽资金渠道，加快探索和充分利用第三方治理模式，鼓励社会资金参与，为废弃矿山、政策性关闭矿山等历史遗留的矿山地质环境治理恢复提供支持。按照“谁治理、谁受益”的原则，充分发挥财政资金引导带动作用，加快构建“政府主导、政策扶持、社会参与、开发式治理、市场化运作”矿山地质环境恢复治理新模式。

（三）监督保障。强化开发和保护过程监管，坚持“谁开发、谁保护，谁破坏、谁治理”的原则，把矿山地质环境恢复治理责任落实到矿产开发全过程，确保所有生产矿山全面担负起治理恢复的主体责任。对每一座矿山逐一排查、逐一落实治理方案，将矿山地质环境保护和治理恢复的责任与工作落实情况，作为矿山企业信息公示和“双随机、一公开”的重要内容和抽检的重要方面，强化对采矿权人主体责任的社会监督和执法监管。对拒不履行恢复治理义务的矿山企业，将其纳入政府管理相关信息向社会公开，列入矿业权人异常名录或严重违法名单。情节严重的，依法依规严肃处理。

（四）宣传保障。各县市要积极培育生态文化，牢固树立矿产资源既是重要自然资源也是重要生态要素的理念，组织好世界地球日、土地日、防灾减灾日等主题宣传活动，树立理性、积极的舆论导向，加强资源环境国情宣传，普及矿山地质环境保护法律法规和科学知识。充分利用电视、广播、报纸、网络等多种媒体形式对矿山地质环境恢复和综合治理正反两方面典型案例进行宣传报道和曝光，引导全社会形成保护矿山地质环境的良好舆论氛围。
