# 关于和硕县松乔庄园葡萄酒庄建设项目用地的批复

和硕县人民政府：

《关于和硕县松乔庄园葡萄酒庄建设项目用地的请示》（硕政发〔2019〕23号）收悉。现批复如下：

一、同意你们在土地利用总体规划调整后所确定的范围外使用国有土地0.6667公顷，作为和硕县松乔庄园葡萄酒庄建设项目用地，土地用途为工业用地（涉农），以出让方式供地。

二、请据此批复，按有关规定办理用地手续。建设用地批后将实施情况报州自然资源局备案，州自然资源局对项目用地的供应情况进行跟踪检查。
