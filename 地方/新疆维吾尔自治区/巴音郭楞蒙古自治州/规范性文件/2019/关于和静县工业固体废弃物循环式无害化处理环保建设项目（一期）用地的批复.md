# 关于和静县工业固体废弃物循环式无害化处理环保建设项目（一期）用地的批复

和静 工业 固体 废弃 处理 用地 批复

和静县人民政府：

《关于和静县工业固体废弃物循环式无害化处理环保建设项目（一期）用地的请示》（静政发〔2019〕30号）收悉。现批复如下：

一、同意你们在土地利用总体规划调整后所确定的范围使用国有未利用土地2.6497公顷，作为和静县工业固体废弃物循环式无害化处理环保建设项目（一期）用地，土地用途为工业用地（环保类项目），以出让方式供地。

二、请据此批复，按有关规定办理用地手续。建设用地批后将实施情况报州自然资源局备案，州自然资源局对项目用地的供应情况进行跟踪检查。

巴音郭楞蒙古自治州人民政府
