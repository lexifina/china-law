# 关于同意库尔勒市设立梨香街道办事处的批复

库尔勒市　设立　梨香　办事处　批复

库尔勒市人民政府：

《关于库尔勒市建设街道、团结街道拆分后行政区划确认的请示》（库政发〔2018〕115号）收悉。根据《中华人民共和国地方各级人民代表大会和地方各级人民政府组织法》、《关于进一步规范行政区划调整申报材料中有关问题的通知》（新民发〔2012〕64号）有关要求及自治州第十三届人民政府第40次常务会议纪要精神，现批复如下：

一、同意你市设立梨香街道办事处，隶属于市人民政府管辖，街道办事处驻地为德凌社区。

二、梨香街道办事处行政区域范围：东以环城北路为界，南以库尉大道为界，西以石化大道为界，北起圣果路，经如意路及其延伸段止。

三、建设街道办事处行政区域范围作相应调整，其行政区域范围为：东以库鲁克山为界，南至圣果路—如意路—环城北路及其延伸段，西以石化大道为界，北起孔雀河经老218国道，至库鲁克山止。

你市要严格执行中央关于厉行节约规定和国务院“约法三章”要求，严格按照“精简、统一、效能”原则设置梨香街道办事处各类机构，严格执行国家相关政策，加大区域资源整合力度，按照土地资源集约优化原则，促进区域经济社会健康协调发展。

此复。

巴音郭楞蒙古自治州人民政府

2018年12月29日
