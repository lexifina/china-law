# 关于对自治州第十四届人大三次会议第1—1号议案的答复

徐正新、拉静生、王军、阿不来提·热合曼、袁宁、刘洪兵、徐红梅、陈哲学、王立辉、马涛、梁茵、阿同古丽、艾合买提·买买提明、雷洪、艾合买提·居马代表：

你们在自治州十四届人大三次会议上提出《关于优化营商环境进一步支持民营经济发展的议案》（第1—1号）已收悉。经认真研究，现答复如下：

民营经济是我州经济发展的生力军，是国民经济和社会发展的重要力量。州党委、政府高度重视民营经济发展，认真贯彻落实习近平总书记关于民营经济发展的重要讲话和重要指示批示精神，贯彻落实中央、自治区关于促进民营经济发展的各项政策措施，通过加强政策扶持引导、强化服务体系建设、优化营商投资环境等多种举措，大力支持全州民营经济加快发展。2018年，全州民营经济市场主体已达131767户，其中：民营企业22609户、个体工商户109158户。民营企业从业人员15.6万人次，个体工商户从业人员18.3万人次，民营经济为全州贡献了50%左右的城镇劳动就业、60%左右的税收、80%以上的企业数量，民营企业在促进经济发展、推动技术进步、满足社会需求、促进就业等方面发挥着不可替代的重要作用。为加快民营经济健康发展，我们主要做了以下方面工作：

一是强化政策制定与落实。深入贯彻党中央、国务院关于促进民营经济发展决策部署，认真落实自治区党委“1+3+3+改革开放”工作部署和《自治区党委 自治区人民政府关于大力促进民营经济健康发展的若干意见》精神，制定下发《关于大力推动非公有制经济加快发展的实施意见》《自治州优化提升营商环境十大行动方案》等文件，鼓励、支持和引导民营企业加快转型升级、强化自主创新、提升发展质量，促进民营经济持续健康发展。

二是推动金融服务非公经济。出台《自治州加强金融服务实体经济发展实施方案》《银行业金融机构支持巴州经济社会发展财政激励考核办法（试行）》等，搭建政银企合作平台，组织开展中小企业和金融机构对接活动，帮助企业解决融资难等问题。2018年，银行业对我州各类企业贷款投放67亿元；与金融机构达成签约意向172亿元，履约率达77%。

三是加快推进上市融资步伐。积极开展产权交易市场试点工作，为全州中小企业进行股权流通、开展直接融资提供良好机遇。截至目前，我州已有全安药业、石大科技等3家企业成功挂牌“新三板”，并入选自治区百家成长性企业23家，拟上市后备企业达30余家。

四是完善中小微企业服务体系。建立服务联盟，积极开展线上线下相结合的服务，加快中小企业公共服务平台建设，为中小企业提供科技、技术、政策咨询服务。目前，全州现有自治区认定中小企业公共服务示范平台2家、示范“窗口”1家，小企业创业示范基地2家，2018年，全州举办中小微企业创业等培训200余次，服务中小企业达500余家。

自治州十四届人大三次会议将关于优化营商环境进一步支持民营经济发展的议案确定为1号议案后，州人民政府高度重视议案办理工作，专门成立以政府分管领导为组长，州党委统战部、政研室，发改、工信、财政、自然资源、商务、市场监督、税务、行政服务、铁路、电力、通信等部门单位主要负责人为成员的议案办理工作领导小组，多次召开领导小组会议，研究分析当前我州民营经济发展现状、面临形势及存在问题，通过构建联系机制、落实优惠政策、加强政务服务、优化营商环境等措施，全力支持民营经济发展。

（一）加强组织领导，形成促进民营经济发展的强大合力。一是加强对促进民营经济发展工作的领导，明确了牵头协调服务部门，健全相应工作机制，加大统筹协调和服务力度。建立自治州大力促进民营经济健康发展部门联席会议制度，坚持每月召开一次联席会议，畅通与民营企业沟通渠道，及时协调解决民营经济和中小企业发展中的问题。二是坚持问题导向，不定期组织召开专题会议、民营企业代表座谈会，对民营企业商会代表在会上提出的突出问题，联席会议办公室（州工信局）进行汇总分类，认真研究分析，提出协调解决分工方案，及时提交联席会议研究。三是根据自治区干部包联企业要求，正在建立自治州党政领导干部联系民营企业和行业协会（商会）制度，实行定点帮扶，做到州县联动、部门协同、分类指导、精准施策，着力构建亲清新型政商关系。

（二）强化政务服务，营造良好发展环境。一是坚定不移聚焦总目标、落实总目标，用总目标统一思想、统一认识、统一步调、统一行动，始终把维护稳定作为压倒一切的政治任务、重于泰山的政治责任，确保社会大局持续稳定、长期稳定、全面稳定，持续释放稳定红利，为包括民营经济在内的各类市场主体发展创造良好环境。二是成立专班强化“放管服”“最多跑一次”改革试点任务落实，下决心优化审批事项、精简办事流程、放宽市场准入，搬掉企业“障碍物”、打开“玻璃门”。加快建设完善自治州一体化在线政务服务平台，尽快打通各部门之间数据壁垒、初步实现“一网通办”，年底前完成工程领域审批缩减到120天以内。三是严格规范税收征管，坚持“无风险不检查、无审批不进户、无违法不停票”，对正常生产经营的企业做到少打扰乃至不打扰，保障纳税人正常经营的发票需求。

（三）拓宽发展空间，激发民间投资活力。一是落实民营企业市场平等准入政策，全面实施市场准入负面清单制度，对负面清单以外的行业、领域、业务等，各类市场主体均可依法平等进入。二是拓宽民间投资领域，在交通、水利等基础设施及旅游、医疗、养老服务、教育商贸物流等领域，支持民间资本组建或参股相关产业投资基金参与投资运营；支持和鼓励民营企业参与造林工程、退耕还林还草、退牧还草工程等生态工程建设。三是落实公平竞争审查制度，清理和废止阻碍民营企业参与公平竞争的各项规定，严禁滥用市场支配地位排除民间资本、限制民间资本进入自然垄断行业的竞争性业务。坚决禁止以限定经营、购买、使用特定经营者提供的商品和服务的方式限制竞争。

（四）坚持多措并举，缓解民营企业融资难问题。一是加强对民营企业的信贷支持，鼓励金融机构根据自身业务特点强化服务，在客户准入、资源配置、绩效考核、产品创新等方面，加大对民营企业的倾斜性支持，明确国有大型商业银行对小微企业贷款增长30%的硬指标任务。二是积极组织各家银行企业深入企业，组织召开银政企对接会，搭建银企合作平台，建立定期协调会商机制，解决银企信息不对称问题。三是按照国务院部署，依法依规开展清理拖欠民营企业、中小企业欠款工作，坚决纠正一些政府部门、大企业利用优势地位以大欺小、拖欠民营企业帐款的行为，年底前全面完成欠款“限时清零”。

（五）推进改革创新，提高民营企业竞争力。一是大力培育民营经济市场主体，突出抓好一批规模大、效益好、前景广的重点民营企业，更好发挥民营经济在高质量发展中的生力军作用。支持民营企业进行技术创新、更新改造。引导企业加大技术中心建设力度，强化产学研合作。二是积极支持组织民营企业参加各类商业性展会、推介洽谈活动，支持民营企业开拓市场；利用“银河培训工程”，组织重点民营企业参加管理、运营、融资等培训；充分发挥巴音职业技术学院、新疆红旗技校等院校作用，加强职业技术培训，组织举办多种形式企业上市、企业管理等培训班，全方位打造高素质企业人才队伍。三是积极支持发展混合所有制，鼓励民间资本参与我州国有企业改制重组或国有控股企业增资扩股以及企业经营管理，进一步扩大民营经济投资领域，增强企业发展活力。支持农产品流通企业及新型农业经营主体开展农超对接、农批对接、农商互联、直销直供等多种模式的产销对接活动。

（六）坚持平等保护，为民营企业发展提供有力法治保障。一是妥善处理涉及民营企业的民商事、行政案件，依法支持民营企业合理诉求。不断提高行政部门履职水平，在安监、环保等领域执法不搞“一刀切”，最大限度降低对涉案企业正常生产经营活动的不利影响。二是坚决落实依法保护民营企业、民营企业家财产权和民营企业知识产权的政策措施，规范行政执法行为。同时，结合当前我州开展的扫黑除恶专项斗争，依法打击针对民营企业经营者的违法行为。三是不断完善法律服务体系，由州司法局牵头，全面清理不合理的妨碍民营企业发展的政府规章和规范性文件；加强法治宣传引导，深入推进“法律进企业、进商会、进机关”活动。

当前，面对新形势、新变化、新要求，我州民营企业面临着许多困难和挑战，个别民营企业家对加快发展信心不强、动力不足，加之个别县市、部门落实政策不到位、营商环境欠佳以及融资难融资贵等诸多问题，一定程度上阻碍着民营经济发展壮大。针对这些问题，我们将在今后的工作中，突出抓好以下几方面的工作。

一是强化财政资金支持。支持民营企业公共服务体系建设和技术创新、固定资产投资、自身创业和解决就业等项目建设，增加自治州科技三项经费对中小微企业科技项目和产学研合作项目的支持力度；建立和健全多层次的政策性中小企业信用担保体系，构建政银企的多方合作机制。加大政府采购对民营经济发展的支持力度，支持民营企业参与PPP项目。对中小微企业免征部分管理类、登记类和证照类行政事业性收费。

二是落实税收优惠政策。认真贯彻落实惠及民营企业的各项税收优惠政策，指导符合条件的民营企业用好政策。积极落实低电价政策，争取自治区扩大巴州直接交易试点企业交易量，加大发电企业直接交易试点监控力度，扩大直接交易试点企业的交易规模范围；做好铁路需求量摸底调查，帮助企业落实铁路运价下降现行运价政策；在法律、法规和政策允许的范围内，简化企业税收征管手续。认真开展企业减负政策宣传，建立实施涉企收费目录清单调整机制，切实减轻企业负担。

三是加大金融支持力度。推动民营企业股份制改造，完善民营企业上市扶持引导机制。建立企业上市后备资源库，将具有上市潜力、成长性好的民营企业及时纳入全州企业上市后备资源库中，并及时向自治区推荐纳入自治区百家成长企业名单，帮助其在中小板、创业板及新三板上市融资。支持符合条件的民营企业通过发行短期融资券、集合票据、区域集优、企业债券、中小微企业私募债等形式进行融资。

四是帮助企业开拓市场。积极组织民营企业参加各类商业性展会、推介洽谈活动，支持民营企业开拓市场；支持农产品流通企业及新型农业经营主体开展农超对接、农批对接、农商互联、直销直供等多种模式的产销对接活动；鼓励农产品加工企业在京津沪等内地发达省份建立特色农产品综合展厅、销售专区；引导大企业与民营企业开展多种形式的经济技术协作，构建良好利益机制。

五是完善公共服务体系。大力推进中小微企业公共服务平台建设，不断完善中小企业公共服务平台功能，提高服务水平和能力。加快推进自治州中小微企业电子商务平台建设，重点在农产品加工、医药、能源化工、特色旅游等领域培育一批集交易、物流、支付等服务于一体的行业电子商务平台。

再次感谢你们对自治州民营经济发展工作的关心和支持。

2019年7月12日
