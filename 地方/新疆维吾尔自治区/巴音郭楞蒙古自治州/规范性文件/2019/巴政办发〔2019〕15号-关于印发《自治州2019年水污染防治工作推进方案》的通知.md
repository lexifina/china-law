# 关于印发《自治州2019年水污染防治工作推进方案》的通知

各县市人民政府，州人民政府各部门、各直属机构，库尔勒经济技术开发区管委会，各园区（开发区）管委会：

《自治州2019年水污染防治工作推进方案》已经州人民政府同意，现印发你们，请认真贯彻实施。

巴音郭楞蒙古自治州人民政府办公室

2019年3月29日

自治州2019年水污染防治工作推进方案

为贯彻落实党中央、国务院和自治区党委、政府关于水污染防治系列决策部署，进一步推动水污染防治各项工作，持续改善水环境质量，结合自治州实际，制定本方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，贯彻落实习近平生态文明思想，贯彻落实全国生态环境保护大会精神、特别是习近平总书记重要讲话精神，贯彻落实党中央治疆方略、特别是社会稳定和长治久安总目标，认真落实自治区党委“1+3+3+改革开放”工作部署和自治区、自治州生态环境保护大会精神，牢固树立新发展理念和“绿水青山就是金山银山、冰天雪地也是金山银山”的理念，以改善流域水环境质量为核心，以保障饮用水水源地安全和改善不达标断面水质为重点，加快补齐水生态环境质量短板，实现水环境质量稳步改善，水生态安全得到有效保障。

二、工作目标

2019年，全州六条监测河流（孔雀河、开都河、车尔臣河、迪那河、黄水沟、塔里木河）的14个监测断面水质优良（达到或优于Ⅲ类）比例达到100%。博斯腾湖17个监测断面水质优良（达到或优于Ⅲ类）比例好于2018年。饮用水水源水质达到或优于《地下水质量标准》Ⅲ类比例100%，全州2个地下水环境质量考核点位水质级别与2014年水质级别相比保持稳定。

三、分区管理

（一）实施以水质改善为核心的分区管理。依据国家划定的陆域控制单元，实施流域、水生态控制区、水环境控制单元三级分区管理。控制单元重点落实水污染防治目标、任务措施、工程项目及总量控制、环评审批、排污许可与排污权交易等环境管理措施。通过推进控制单元分级分类防治，因地制宜综合运用水污染治理、水资源配置、水生态保护等措施，提高污染防治的科学性、系统性和针对性。

（二）推进控制单元分级分类防治。《重点流域水污染防治规划（2016—2020年》中，共涉及我州2个优先控制单元和5个一般控制单元，2个优先控制单元进一步细分为1个水质改善型和1个防止退化型单元。

四、工作任务

《巴音郭楞蒙古自治州水污染防治工作方案》（巴政发〔2016〕52号）中明确的2019年持续开展的重点工作任务不在本方案中列出，各县市、各有关部门要严格按照文件要求抓好落实。（以下工作任务，责任单位为各县市人民政府、库尔勒经济技术开发区管委会的不再列出）

（一）工业污染防治

1﹒加强工业企业环境执法，按照已确定的不符合国家产业政策及行业准入条件的“十小”企业清单，列出年度执法检查计划，强化环境监察执法后督察，杜绝“十小”企业死灰复燃。将其他不能稳定达标排放的工业企业废水治理工作纳入年度计划并进行改造。（牵头单位：州生态环境局；配合单位：州工信局、发改委、自然资源局）

2﹒提高工业集聚区污染治理和风险防控水平。且末工业园区矿产品加工园要尽快完成污水集中处置设施建设并安装在线监控设施；已建成投运的园区，要完善工业园区污水集中处理设施。实现废水分类收集、分质处理，入园企业排放的污水应在达到国家或地方规定的排放标准后接入集中式污水处理设施处理，园区集中式污水处理设施总排口按要求安装自动监控系统、视频监控系统，并与生态环境主管部门联网。焉耆县、和静县、和硕县、博湖县人民政府于2019年3月31日前制定工业园区、工业集聚区中水回用综合利用方案，确保2020年全部中水回用或综合利用。（牵头单位：州工信局；配合单位：州生态环境局）

3﹒推动实施工业污染源全面达标排放。严格落实排污许可制度，逐步实现将所有工业污染源纳入在线监控范围。深化网格化监管制度，全面落实“双随机、一公开”制度，持续保持环境执法高压态势。依法依规对违法排污单位及相关人员实施联合惩戒。（牵头单位：州生态环境局；配合单位：州工信局、公安局、市场监督管理局）

4﹒加大超标排放整治力度。实施“黄牌”和“红牌”管理制度，每年分季度向社会公布“黄牌”和“红牌”企业名单，实施分类管理；对超标现象普遍、超标企业集中的县市人民政府采取通报、挂牌督办、约谈、区域限批等措施。（牵头单位：州生态环境局；配合单位：州工信局）

（二）城镇生活污染治理

5﹒推进海绵城市建设。各县市根据海绵城市建设项目和具体指标，积极开展试点并推进海绵城市示范区、海绵性建筑与小区、海绵型城市道路和广场等示范项目建设。到2020年，确保各县市20%以上的面积达到目标要求。（牵头单位：州住建局；配合单位：州水利局、发改委、工信局、林草局）

6﹒继续推进污水处理设施建设。库尔勒市、轮台县2019年底完成城镇生活污水处理厂一级A提标改造工程。博斯腾湖流域各县市新改扩建乡镇污水处理设施须达到一级A排放标准。焉耆、和硕、博湖、和静县人民政府2019年3月31日前完成城镇生活污水中水回用或综合利用方案制定，2020年城镇生活污水全部实现中水回用或综合利用。（牵头单位：州住建局；配合单位：州发改委、生态环境局、水利局）

（三）推进流域水生态保护

7﹒严格水资源保护。一是控制用水总量。落实最严格水资源管理制度，严守“三条红线”控制指标，建立覆盖全流域的取用水总量控制指标体系，推进消耗总量与消耗强度双控制度管理，制定年度减水目标及对策措施。严格实施取水许可制度，对取用水总量已达到或超过控制指标的区域，暂停审批其建设项目新增取水许可。（牵头单位：州水利局；配合单位：州发改委、工信局、住建局、农业农村局）二是严控地下水超采。到2020年地下水超采得到严格控制，使严重超采区全部变为一般超采区，一般超采区变为采补平衡区。严格实施水资源有偿使用制度，依法加强水资源费征收和使用管理。水利部门牵头制定各流域用水总量、井电双控考核体系并组织考核，考核结果纳入各县市环境保护绩效考核。（牵头单位：州水利局；配合单位：塔里木河流域巴音郭楞管理局、州自然资源局、住建局、发改委、工信局、财政局、农业农村局、林草局、畜牧兽医局）三是完善水资源保护考核评价体系。建立万元国内生产总值水耗指标等用水效率评估体系，节水目标任务完成情况纳入各县市政府政绩考核。加强水功能区监督管理和用途管制，从严核定水域纳污总量，执行水功能区限制纳污红线。完善入河（湖）排污口设置的审查管理，加强入河（湖）排污口日常监管，限制审批新增取水和入河（湖）排污口。（牵头单位：州水利局；配合单位：塔里木河流域巴音郭楞管理局，州发改委、生态环境局）四是全面推行河（湖）长制。严格落实河（湖）长制规定和方案，构建河湖管理保护长效机制。（牵头单位：塔里木河流域巴音郭楞管理局；配合单位：州水利局、生态环境局、发改委、财政局、自然资源局、住建局、交通运输局、卫健委、农业农村局、林草局、畜牧兽医局）

8﹒深化流域污染防治。实施“增淡截污”治水工作。以涉及水质改善型优先控制单元的博斯腾湖为重点，加强上游来水科学合理调度、清污分流，增加黄水沟入湖淡水量。北四县积极组织开展拆除排拦河坝、封堵入河湖排污口等集中整治工作。流域管理部门开展黄水沟入博斯腾湖生态输水工作，2019年、2020年视黄水沟来水情况，每年向博斯腾湖输水1.5亿立方米以上。（牵头单位：塔里木河流域巴音郭楞管理局；配合单位：州水利局）

9﹒防治地下水污染。一是各县市以集中式地下水饮用水水源、石油化工生产销售企业、矿山开采区、工业园区、危险废物堆存场、垃圾填埋场、再生水利用区等周边地下水环境为重点，开展地下水污染调查和基础环境状况调查评估。对排查出的各类人为污染地下水饮用水源环境问题开展综合治理。（牵头单位：州生态环境局；配合单位：州自然资源局、水利局、发改委、工信局、住建局、卫健委、应急管理局）二是建立健全水污染突发事件应急预案和技术储备体系，2019年6月底，各县市人民政府完成水污染突发事件应急预案备案，进一步强化应急储备设施建设。（牵头单位：州生态环境局；配合单位：州水利局、自然资源局）三是加快推进加油站防渗改造工作。2019年6月底前完成库尔勒市、和硕县加油站地下油罐双层罐改造或防渗改造工作（2017年未完成重点工作任务）。（牵头单位：州商务局；配合单位：州生态环境局、应急管理局、住建局、公安局、市场监督管理局）

10﹒保护河湖（库）湿地。一是保护水和湿地生态系统。加强河湖水生态保护，禁止侵占自然湿地等水源涵养空间，已侵占的要限期恢复。（牵头单位：州林草局；配合单位：州生态环境局、发改委、财政局、自然资源局、住建局、水利局、农业农村局、畜牧兽医局）二是研究实施人工湿地育苇收费机制。2019年3月底前，博斯腾湖流域北四县开展辖区内人工育苇面积、人工育苇需水量科学测算，并形成人工育苇水资源论证报告。水利部门根据博斯腾湖流域现有人工湿地面积水资源论证结果核定生态用水总量指标，严禁无用水指标新增人工湿地面积，2020年起工业和城镇生活污水严禁排入湿地。流域管理部门和水利部门加快研究制定人工湿地生态用水有偿使用制度，2020年后博斯腾湖流域全面实施人工湿地育苇收费机制，用市场机制解决人工育苇用水问题。（牵头单位：塔里木河流域巴音郭楞管理局；配合单位：州水利局）

11﹒防治富营养化。认真落实生态环境部《关于加强固定污染源氮磷污染防治的通知》要求，对开都河流域实施入湖河流总氮排放控制，加强内源污染控制，加大湖滨带保护与修复力度。（牵头单位：州生态环境局；配合单位：州水利局、林草局）

（四）加强饮用水水源环境安全保障

12﹒加快推进饮用水水源规范化建设。在全州已基本完成乡镇及以上地下水集中式饮用水水源保护区划定的基础上，开展定期监测和调查评估；依法清理集中式饮用水水源保护区内违法建筑及排污口。加快城市备用水源建设。加强农村分散型饮用水水源保护，按照国家部署开展化工企业聚集区周边地表水及地下水饮用水水源安全防控体系建设示范试点；深入实施农村饮水安全工程，推进污染治理和水质保护。（牵头单位：州生态环境局；配合单位：州水利局、发改委、财政局、住建局、卫健委）

13﹒加强监测能力建设和信息公开。以水源空间布局为核心，优化调整上游水环境监测网络。推进水源环境风险全过程管理，建立健全水源风险评估和预警预报系统，定期公布集中式饮用水水源水质监测信息。（牵头单位：州生态环境局；配合单位：州水利局、发改委、财政局）

14﹒加强严格饮用水水源污染控制，2019年底前完成县级城市饮用水水源地环境保护专项整治工作。（牵头单位：州生态环境局；配合单位：州水利局、发改委、财政局、住建局、卫健委）

五、保障措施

各县市、各有关部门、各单位要严格按照方案要求，制定2019年水污染防治工作方案，确保各项任务全面完成，并于3月31日前，将本县市和本部门2019年落实水污染防治工作方案及责任领导、工作人员名单报州生态环境局。
