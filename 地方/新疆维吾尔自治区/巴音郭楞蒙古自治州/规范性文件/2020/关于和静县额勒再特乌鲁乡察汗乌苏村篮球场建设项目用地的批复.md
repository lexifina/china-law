# 关于和静县额勒再特乌鲁乡察汗乌苏村篮球场建设项目用地的批复

和静县人民政府：

《关于和静县额勒再特乌鲁乡察汗乌苏村篮球场建设项目用地的请示》（静政发〔2020〕54号）收悉。现批复如下：

一、同意你们在土地利用总体规划调整后使用国有未利用地0.2278公顷，作为和静县额勒再特乌鲁乡察汗乌苏村篮球场建设项目用地，土地用途为公共管理与公共服务用地，以划拨方式供地。

二、请据此批复，按有关规定办理用地手续。建设用地批后将实施情况报州自然资源部门备案，州自然资源部门对项目用地的供应情况进行跟踪检查。
