# 关于地州市福利彩票机构绩效工资考核分配指导意见

伊犁哈萨克自治州、各地(州、市)民政局、福利彩票发行中心：

根据《国务院办公厅关于印发分类推进事业单位改革配备 文件的通知》(国办发〔2011)37号〕精神和自治区人民政府办公厅《转发自治区人力资源和社会保障厅、财政厅关于自治区其他事业单位绩效工资实施指导意见的通知》(新政办发【2013】144号)、自治区人力资源和社会保障厅、财政厅《关于印发自治区区直其他事业单位绩效工资实施办法的通知》(新人社发【2014】87号)精神和要求，结合各地福利彩票销售机构运行状况和销售工作实际，制定本指导意见。

一、指导思想

为充分发挥绩效工资的杠杆作用，按照“多劳多得、不劳 不得、优绩优酬”的原则，实行科学考核、绩效挂钩、按劳分 配，建立自主灵活、符合我区福利彩票销售工作特点的激励分 配机制，进一步发挥绩效工资的激励导向作用，充分调动各地 福彩机构工作人员的积极性和主动性，提高工作质量和效率，促进我区福利彩票事业持续全面健康发展。

二、 基本原则

(一)坚持按劳取酬，效率优先，兼顾公平的原则。

(二)坚持向关键岗位、业务骨干和做出突出成绩的工作人员倾斜的原则。

(三)坚持“绩效考核挂钩”的原则。

(四)坚持公开、公正、公平考核的原则。

三、 绩效工资实施范围及时间

绩效工资适用于各地(州、市)福利彩票发行中心所有在岗工作人员，其中：在编在岗人员以当地人社局核定的标准及 批复的时间进行组织实施；聘用在岗人员按照国家用工相关规定实行合同制管理，可参照在编在岗人员岗位分配系数执行。

四、 绩效工资总量核定

(一)绩效工资水平

各地(州、市)福彩中心绩效工资水平原则上与原执行的 上年度福利彩票机构销售绩效奖励保持一致，总量核定基本维 持上年度销售绩效奖励水平。对年人均绩效工资水平高于当地 调控线部分征收调节基金，具体征收管理办法按自治区及当地有关政策文件执行。

(二)绩效工资分配

各地(州、市)福利彩票发行中心的绩效工资包括基础性绩效工资和奖励性绩效工资。

1、基础性绩效工资分配。基础性绩效工资按照自治区及当地规定的地方津贴补贴标准的60%及保留地区补贴(含保留额),一般按月发放。

2、 奖励性绩效工资分配。奖励性绩效工资包括以自治区及当地规定的地方津贴补贴标准的40%、纳入绩效的活工资、年终一次性奖金及核增绩效工资。各地(州、市)福利彩票中心根据本单位实际情况，研究制定绩效工资分配办法，各岗位分配级差要保持合理衔接，突出关键重点岗位。单位主要领导 的奖励性绩效工资，由自治区福利彩票发行中心根据业务考核 结果统筹考虑确定，控制在所在单位工作人员人均奖励性绩效工资相应倍数以内进行有效分配，并与所在单位工作人员的绩效工资水平保持合理关系。

(三)各地(州、市)福利彩票发行中心根据本单位福利彩票工作开展情况提出奖励性绩效工资核增意见，核增部分必 须符合相关规定，经当地民政局初核、自治区福利彩票发行中心审核后，报当地人力资源社会保障局核定。

五、 绩效工资考核

(一)各地(州、市)福利彩票发行中心根据本单位实际情况，研究制定绩效工资考核办法，科学设置单位考核项目， 合理划分绩效考核项目资金。主要考核职工工作的德、能、勤、 绩、廉等方面，具体内容包括：工作作风、工作纪律、工作态 度、履行岗位职责、工作量大小、完成工作时间、上级安排的其他工作任务情况等，重点考核工作实绩。

(二)奖励性绩效工资由各地(州、市)福利彩票发行中 心根据彩票销售量、安全运行、重点工作等情况，依据考核结 果、绩效分配办法和有关财务制度组织发放。奖励性绩效工资 可依据每季度或半年考核结果发放，也可根据福利彩票销售情况及工作开展情况采取按月预发方式。

(三)考核分配办法由各地(州、市)福利彩票发行中心 领导班子集体研究，经单位职工代表大会(职工大会)通过后，经批准后并在本单位公开。

(四)原年终一次性奖金可根据当地考核结果，结合个人实际水平年底单列发放。

(五)各单位实施绩效工资后，对病(事)假、旷工或未履行岗位职责的人员，可按照本单位考核办法并依据聘用合同或有关规定，扣减基础性绩效工资和奖励性绩效工资。

六、 经费保障

(一)各单位实施绩效工资所需资金，按照全疆福利彩票系统业务费实行自治区集中统一管理的相关规定(新财综 【2013】4号文)要求，列入本单位当年支出预算，经自治区福利彩票发行中心审核汇总后，报自治区财政厅统一核定。

(二)退休人员增加补贴所需资金，按原经费渠道列支。

(三)各单位一律不得自行提高绩效工资标准和扩大实施范围，不得在核定的绩效工资总量外自行发放津贴、补贴或奖 金，不得突破核定的绩效工资总量，不得违反规定的程序和办 法进行分配。按照规定发放的绩效工资， 一律以银行卡的形式发放，不得发放现金，并依法代扣代缴个人所得税。对违反政策规定的，坚决予以纠正，并进行严肃处理。

七、相关要求

(一)各地(州、市)福彩中心要高度重视绩效工资实施 工作，成立专门工作机构，明确工作职责、工作内容和工作目 标，统筹安排好本单位绩效工资的实施工作，及时、准确完成 审批及上报工作，以便自治区财政厅统一核定全疆福利彩票系

统绩效工资总量资金。

(二)绩效工资关系到广大职工的切身利益，各地(州、 市)福彩中心要切实发挥好绩效工资的杠杆作用，科学缜密制 定绩效考核及绩效工资分配方案，规范福利彩票机构内部运行 机制，充分调动广大干部职工的工作积极性和主观能动性，确保全区福利彩票工作继续又好又快发展。

(三)各地(州、市)福彩中心要严格把握好有关政策规 定，主动与当地人社部门沟通衔接，耐心细致地向单位职工做好政策解释和思想政治工作，确保绩效工资工作平稳实施。
