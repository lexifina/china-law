# 关于推行节地生态安葬的实施意见

伊犁哈萨克自治州民政局、发展改革委、科技局、财政局、国土资源局、环培保护局、住房城乡建设局、农业局、林业局，各地州市民政局、发展改革委、科技局、财政局、国土资源局、环境保护局、住房城乡建设局、农业局、林业局：

为认真贯彻落实中办、国办《关于党员干部带头推动殡葬改革的意见》（中办发〔2013〕23号）和民政部等九部委《关于推行节地生态安葬的指导意见》（民发〔2016〕21号）文件精神，紧紧围绕社会稳定和长治久安总目标，推行我区节地生态安葬，提出如下实施意见。

一、充分认识推行节地生态安葬的重要性和必要性

坚持节约资源、保护环境、以人为本、保障群众殡葬需求是殡葬改革的基本方向，是法治殡葬、绿色殡葬、惠民殡葬、人文殡葬的客观要求，也是生态文明建设的重要组成部分。近年来，自治区党委、政府高度重视殡葬改革，实行火葬，改革土葬，革除丧葬陋俗，积极倡导和推行节地生态安葬，探索采用树葬、塔葬、骨灰，存放等安葬方式，取得了积极成效。但总体上看，我区节地生态安葬设施供给不足、方式单一，节地生态安葬观念不强，节地生态安葬率不高，激励引导、规范监管的制度机制不完善，节地生态安葬设施供给不足，火葬区遗体火化率下滑明显，农村土葬改革区乱埋乱葬、滥占耕（林）地现象严重，城乡墓位面积超标、墓位上修建比较夸张的构筑物、过度使用不可降解材料等问题突出，浪费了大量的自然资源，破坏了生态环境，特别是"三股势力"利用殡葬活动传播宗教极端思想，进行渗透活动，迫切需要加以解决。

鼓励和引导群众采用树葬、沙漠（戈壁）葬、骨灰存放、深埋等不占地或少占地、少耗资源、少使用不可降解材料的方式安葬骨灰（遗体），是以节约土地、保护环境为目的的节地生态安葬，较好地促进人与自然和谐发展。因此，推行节地生态安葬，是减轻群众负担，保障群众基本安葬需求的有效途径；是移风易俗，弘扬社会主义新风尚的重要举措；是促进生态文明建设，造福子孙后代的必然要求。各地要充分认识推行节地生态安葬的重要性和紧迫性，加强组织领导，统筹规划节地生态安葬设施建设，积极稳妥推广节地生态葬式葬法，建立节地生态安葬奖补激励等政策措施，为建设大美新疆、和谐新疆做出贡献。

二、统筹推进节地生态安葬健康持续发展

（一）统筹规划，努力加强节地生态安葬设施建设。各地要根据现有安葬设施情况和未来需求，把握总量、扩大增量、优化存量，科学规划建设节地生态安葬设施，强化安葬设施的生态功能。重点加强可提供树葬、小型墓、骨灰存放、立体安葬等多样化节地生态安葬的城镇公益性公墓、骨灰堂等基本殡葬公共服务设施建设。每个县（市、区）可分别规划建设1座民、汉公益性节地生态公墓。农村公益性节地生态墓地由县（市、区）统一规划建设，1个村或相邻几个村可规划建设1处公益性节地生态墓地。原则上新建城镇公益性公墓的节地生态安葬率达到100%。对现有乱埋乱葬的坟墓，要区分情况，分类处置。对成片乱埋乱葬的坟墓，当地政府可采取绿化等方式予以遮挡；对零星或无法遮挡的坟墓，当地政府让其迁移到公益性墓地；对毁林造坟、毁田造坟以及在其他规划功能建造坟墓和墓位面积超标的，当地政府要坚决依法查处。新建和改造农村公益性墓地，严格执行墓位占地面积规定，减少使用不可降解材料，提高节地生态化墓地安葬程度。要建立长效管理机制和责任追究办法，从制度上杜绝乱埋乱葬和丧葬陋习。争取到"十三五"末，在巩固和提高全区火化率和公墓安葬率的基本上，较大幅度提高节地生态安葬比例，建成一批具有示范效应的节地生态安葬设施，初步形成覆盖城乡的节地生态安葬公共服务网络，乱埋乱葬、墓位面积超标得到有效治理，节地生态、移风易俗新风尚成为殡葬活动主流。进一步加强穆斯林殡葬设施建设，保障穆斯林群众节地生态安葬需求。

（二）推进改革，努力推动节地生态安葬葬式葬法。按照积极有步骤地实行火葬、改革土葬的原则，依法推行遗体火化、骨灰或遗体公墓内集中安葬。在火葬区人口密集区，积极推行骨灰堂（塔、廊、墙）等少占地存放骨灰的立体安葬方式，推动树葬、沙漠（戈壁）葬等不占地、不保留骨灰的生态安葬方式。倡导骨灰安葬面积小于国家和自治区规定标准的节地型墓位，提倡地面不建墓基、地下不建硬质墓穴，墓碑小型化、微型化，最大限度降低硬化面积，并鼓励家庭成员采用合葬方式提高单个墓位使用率。在土葬区，遗体应在公墓或农村公益性墓地内集中安葬严禁乱埋乱葬，倡导安葬占地面积低于国家和自治区标准的节地型墓位，减少地面硬化面积，鼓励墓碑小型化、微型化。尊重少数民族丧葬习俗，鼓励和支持少数民族群众选择"地宫多层"等地下立体节地生态葬式葬法。

（三）强化服务，努力提高节地生态安葬服务水平。针对节地生态安葬服务内容和特点，要创新服务模式，落实服务标准，优化服务流程，积极提供网上预约、服务热线、咨询窗口、上门服务等便捷方式，提升服务质量，拓展服务内涵。加强安葬后续管理与服务，注重绿化美化环境，引导文明低碳祭扫，积极鼓励墓穴循环使用。激励公办公墓的示范带头作用，提供多种可供群众选择的节地生态安葬服务产品，及时为群众提供精准、优质、高效的便民、利民殡葬服务，提高群众认可度和满意度。

（四）文化引领，努力培育节地生态安葬思想理念。把推行节地生态安葬与倡导厚养薄葬、保护生态环境、造福子孙后代结合起来，培育节地生态、绿色环保的安葬理念。充分依托和利用现有殡葬设施，建设生命文化示范节地生态安葬基地，打造优秀殡葬文化传承平台。积极推广现代殡葬文化和节地生态殡葬产品，坚决抵制迷信低俗、奢侈浪费等不良丧葬风气，切实增强节地生态安葬的主动性和自觉性。大力倡导鲜花祭扫、网络祭扫、踏青遥祭等文明低碳祭扫方式，积极开展集体祭扫、社会公祭、家庭追思活动，弘扬现代殡葬文化，引导群众逐步从重实地实物祭扫转移到精神传承上来。

三、切实强化节地生态安葬的保障措施

（一）加强组织领导，强化部门协同。紧紧围绕社会稳定和长治久安总目标，建立党委领导、政府负责、民政牵头、部门协作、社会参与的工作机制，将节地生态安葬和积极抵御宗教极端思想渗透作为深化殡葬改革的重要内容，纳人"十三五"规划，加强目标管理和绩效考核，确保政策措施落到实处。民政部门要牵头做好节地生态安葬组织实施及服务保障工作，加强目标管理与审批监管；国土资源部门应加强对具有一定节地生态安葬功能的公益性安葬（放）设施的土地供给；国土资源、住房城乡建设等部门应各司其职，应依法查处毁田（林）造坟等乱埋乱行为；发展改革、财政、民政等部门要完善惠民殡葬政策和节地生态安葬奖补激励措施；科技、环境保护部门要推动环保殡葬新技术、新产品研发应用，加强对节地生态安葬设施和殡葬活动中的生态环境监管；注重发挥村（社区）、乡（镇、街迫）等基层（社会）组织优势，探索建立乱埋乱葬以及宗教极端思想渗透报告及预警机七、地方文件头文明低碳祭，教月、子且杀杀属、身边工作人员转观念破日做殡葬改单的践行有、小犯有、与领者。依法纠正和查处党员干部尤其是部去世后遗体违规土辩、乱理乱葬、超标准建墓立碑等行为建立激励机制，买施奖补制度。要贯彻落实自治区殡葬惠民政策，按照本、广覆盖、可持续"的原则，逐步扩大救助范围，提高救助标准，使殡葬曲逐步由"补缺型"问"晋思型"转变，逐步实现基本殡葬服务均等化。逐步建立自治区节地生态安葬奖补激励机制，指导和带动有条件的地方建立节地生态安葬必补制度，把树葬、沙漠葬、戈壁葬、格位存放等不占地或少占地方式以及土葬区遗体深埋不留坟头和"地宫多层"安葬等节地生态葬式葬法，纳人奖补范围，对带头推行可降解环保用品的殡葬服务单位和使用者亲属，给予适当奖励或补贴。群众有意愿且有条件的地区，可为不保留骨灰者建立统一的纪念设施，利用重要传统节日组织开展祭奠活动，缅怀逝者、教育后人。

（四）强化宣传引导，营造舆论氛围。要利用清明节等重要群众祭扫时机，充分发挥媒体、殡葬服务机构、基层组织和社会组织作用，用群众喜闻乐见的方式，宣传节地生态安葬的重要意义，推进安葬活动"去极端化"。开展节地生态安葬示范活动，鼓励有条件的地方大胆探索、先行先试，推广好的经验做法。加强群众节地生态安葬和治丧活动的正向宣传引导，培育和树立厚养薄葬、节地生态、文明节俭、移风易俗的殡葬新风尚。

（五）注重能力建设，推行节地生态安葬。各有关部门要树立全局意识，加大对节地生态安葬工作的支持力度，保障基本建设用地，加强规划引导和政策指导。冬地要做好节地生态安葬设施和女葬万式的规划建设，打造节地生态安葬精品工程更加强对殡葬服务人员培训刀度，着刀提开十部职工的生态文明素养。要注重总结估努力研究解决推行节地生念女葬工作中的难点问题，完善相关政策措施。
