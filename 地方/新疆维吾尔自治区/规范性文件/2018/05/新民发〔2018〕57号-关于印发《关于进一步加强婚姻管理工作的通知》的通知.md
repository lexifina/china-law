# 关于印发《关于进一步加强婚姻管理工作的通知》的通知

伊犁哈萨克自治州民政局、人民法院、公安局、司法局、卫生计生委、宗教局、妇联；各（地、州）市民政局、人民法院、公安局、司法局、卫生计生委、宗教局、妇联：

为深入贯彻落实党的十九大和十九届二中、三中全会精神，贯彻落实以习近平同志为核心的党中央的治疆方略特别是社会稳定和长治久安总目标，进一步加强婚姻登记管理工作，自治区民政厅等七部门制定了《关于进一步加强婚姻管理工作的通知》，现印发你们，请结合实际，认真贯彻实施。

关于进一步加强婚姻管理工作的通知

坚持以习近平新时代中国特色社会主义思想为指导，贯彻落实党的十九大和十九届二中、三中全会精神，坚决贯彻以习近平同志为核心的党中央的治疆方略特别是社会稳定和长治久安总目标，切实把自治区关于推进南疆民族人口结构优化会议精神落到实处，进一步加强婚姻登记管理工作，坚决治理南疆地区早婚、离婚率高等问题，根据国家和自治区有关婚姻管理的法律法规及《新疆维吾尔自治区去极端化条例》《关于转发<自治区高级人民法院等六部门关于加强对婚姻领域违法行为综合治理工作的意见>的通知》（新社综〔2014〕11号），现就进一步加强婚姻管理工作通知如下：

一、提高认识，深刻理解加强婚姻管理工作的重要性

近年来，在自治区党委、人民政府的坚强领导下，各地、各有关部门紧紧围绕社会稳定和长治久安总目标，在宣传贯彻《中华人民共和国婚姻法》《中华人民共和国人口与计划生育法》和《中华人民共和国妇女权益保障法》，完善婚姻管理制度、严厉打击婚姻领域违法行为等方面，取得了明显成效。全区各族群众的婚姻法治观念不断增强。特别是通过严厉打击宗教极端思想干涉婚姻家庭，早婚、离婚率高等问题得到一定程度遏制。但是，仍然要清醒地认识到宗教极端思想的流毒尚未完全根除，婚姻管理工作还有薄弱点：一是我区特别是南疆地区依然存在早婚、父母包办婚姻等现象；二是离婚财产分割、孩子抚养归属等问题较为突出，妇女儿童的合法权益尚未得到有效保障；三是高离婚率导致单亲家庭孩子增多，在缺少家庭温暖的情况下，极易受到宗教极端思想侵袭，极易被“三股势力”引诱、裹胁。这些问题既制约了南疆少数民族人口素质和生活水平的提高，又给新疆社会稳定带来了严重影响。

各地、各有关部门要站在实现新疆社会稳定和长治久安总目标的战略高度，进一步提高对加强婚姻管理工作重要性的认识，加强婚姻管理工作是贯彻落实以习近平同志为核心的党中央的治疆方略特别是社会稳定和长治久安总目标、自治区党委决策部署的具体行动，是全面提高我区特别是南疆人口素质的重要举措，是如期完成脱贫攻坚任务、决胜全面建成小康社会的必然要求。各地要增强“四个意识”，提高政治站位，以强烈的使命感和责任担当，高度重视早婚、离婚率高带来的严重危害，从本地区实际出发，采取法律、政策、行政等措施，努力把婚姻管理纳入法制化轨道，坚决遏制早婚、离婚率高等问题。

二、综合施策，坚决遏制早婚、离婚率高现象

强化各地主体作用和各部门职能作用，加强婚姻管理，健全工作机制，严格管理责任，夯实具体措施，坚决遏制早婚、离婚率高现象，坚决制止和纠正婚姻家庭领域的违法行为。

（一）引导形成积极健康的婚恋导向。各地、各有关部门要认真贯彻自治区党委办公厅、自治区人民政府办公厅《关于贯彻落实<关于实行国家机关“谁执法谁普法”普法责任制>的意见》（新党办发〔2017〕31号）精神，按照谁执法谁普法的原则，充分发挥广播、电视、网络等各种媒体的宣传优势，坚持以先进文化为引领，通过通俗易懂、喜闻乐见和群众易于接受的形式，在全区范围内广泛、持久、深入开展婚姻家庭法律法规宣传教育，提高群众法治意识和依法维权能力，教育引导群众树立文明、健康、理性的婚恋观念，为加强婚姻管理工作创造良好的社会氛围。卫生计生部门、妇联组织要充分发挥工作优势，开展“婚育新风进万家活动”，定期在南疆巡回对青年妇女和在校学生开展法律法规、晚婚晚育和家庭美德教育宣传活动；民族宗教部门要重视发挥爱国宗教人士的作用，遏制宗教极端思想对婚姻管理工作的干扰和破坏；民政部门要加强《中华人民共和国婚姻法》宣传，倡导和谐美好的婚育新风，引导广大群众摒弃早婚、草率离婚等违法和不良行为；司法部门要通过加强法治宣传，坚决抵制宗教极端思想，弘扬社会主义核心价值观，使南疆四地州的早婚、离婚率高问题得到有效遏制。

（二）强化婚姻家庭纠纷预防化解机制。各地、各有关部门要健全党政主导、部门联动、社会参与的工作格局，充分发挥人民法院、公安、司法、妇联等部门职能作用，完善各部门之间的衔接联动机制，积极贯彻落实自治区妇联等六部门印发的《关于深入推进自治区婚姻家庭纠纷预防化解工作实施意见》（新妇字〔2017〕50号），以人民调解、行政调解、司法调解为主要渠道，及时受理婚姻家庭纠纷投诉，积极推进婚姻家庭辅导，为群众免费提供法律咨询、心理辅导和婚姻家庭危机干预，预防和化解婚姻家庭纠纷，缓解离婚率高问题。加强对离婚案件的调解和教育疏导工作，法院在审理离婚案件时，视案情对离婚案件的夫妻感情是否破裂作出认定，对于一时赌气、子女教育、家务琐事等矛盾，可适当延缓审判时间，确定冷静期，化解夫妻矛盾，对尚有和好希望与可能的婚姻，要通过多渠道开展离婚前调解、法律咨询服务，阻止草率和冲动型离婚。以家庭和谐促进社会稳定，进一步增强人民群众的安全感和幸福感。

（三）严格婚姻登记管理工作。各级民政部门要强化行政服务管理，促进婚姻管理工作法制化、规范化、信息化。加强婚姻登记机关依法行政水平和执法督导检查，严格执行《中华人民共和国婚姻法》等有关法律法规，加强婚姻登记部门管理，把好婚姻登记关，在申请办理结婚登记时，需提供双方户籍所在地的村（社区）出具无三代以内血缘关系的证明；坚决杜绝违规操作和违规办证问题，严肃查处婚姻登记人员违规办理婚姻登记、玩忽职守、滥用职权等行为；建立婚姻登记信息向有关部门（人民法院、公安、司法、卫计等）公开或资源共享机制，充分发挥村（社区）在婚姻管理中的作用，做好对婚姻当事人婚姻状况核实以及驻村（社区）寺管会婚姻服务管理，防范宗教极端思想干扰婚姻登记，从源头上杜绝早婚。积极做好群众办理离婚手续前的调解工作，最大限度地化解矛盾；进一步严格离婚预约登记制度，延长离婚预约登记时间，最短不能低于三个月，在离婚预约期限内，在夫妻双方中任何一方户口所在地的村（社区）最少开展3次以上调解并有调解内容及调解结果记录；夫妻双方仍坚持离婚的，在预约结束后持离婚调解书到民政部门办理离婚手续；严格按照《中华人民共和国婚姻法》规定，对拒不签订夫妻共同财产合理分割协议、不承担子女抚养义务或者协议产生分歧的，一律不予办理离婚手续。

（四）严格婚姻财产分割。各级人民法院在审理离婚案件时，要分清个人财产、夫妻共同财产和家庭共同财产，坚持男女平等，保护妇女、儿童的合法权益，照顾无过错方，依法支持对非过错方的赔偿请求。离婚分割夫妻共同财产时，对隐藏、转移、变卖、毁损夫妻共同财产，或伪造债务企图侵占另一方财产的一方，应当少分或不分。离婚后，另一方发现有上述行为的，可以向人民法院提起诉讼，请求再次分割夫妻共同财产。人民法院对前款规定的妨害民事诉讼的行为，依照民事诉讼的规定予以制裁。加大法官的释明力度，对法律意识欠缺的当事人，在庭审过程中适当增加法律讲解，包括法律对夫妻财产如何认定、过错方的惩处、彩礼的返还等。完善法院在审理离婚案件中的主动调查机制。家庭财产分割，涉及存款、股票、保险等当事人无法调取的证据，法院应积极依职帮助相对弱势一方调取相关证据，确保婚内财产公平合理进行分割。

（五）严格户籍管理。各级公安部门要以人口精准核实登记专项工作和整治无户籍人员管理专项行动为契机，加强户口登记管理，深入推进户口清理整顿工作，及时维护人口信息，确保各地“假、重、错”户口问题得到全面彻底清理。建立落实户口清理整顿工作责任制，按照“谁办理、谁负责，谁出具证明、谁负责”的原则，层层签订责任状，将责任落实到村委会、社区（街道）、警务室，并通过民警入户走访等有效措施，及时发现掌握为早婚更改实际年龄、离异家庭子女不随父母落户和随意变更户籍等问题，坚决依法依规严惩。

（六）严厉打击违法行为。各地、各有关部门要坚决贯彻《新疆维吾尔自治区去极端化条例》和新社综〔2014〕11号等文件要求，健全和完善各部门间的联动机制，形成社会参与的工作格局，充分发挥人民法院、公安、司法、妇联、民政等部门职能作用，严厉打击宗教极端思想和非法宗教活动对婚姻家庭的干预。积极配合公安机关，重点对早婚、重婚、骗婚等非法婚姻行为进行集中打击，着重打击伪造公章、婚姻证书、户籍证明、公证文书等违法犯罪行为；严厉打击父母包办、买卖婚姻、家庭暴力和其他婚姻家庭领域违法行为，坚决遏制早婚、离婚率高等问题。

各级民族宗教工作部门要加大对宗教教职人员的教育培训管理，广泛宣传男女平等的基本国策及《婚姻法》等相关法律法规，增强宗教教职人员和信教群众遵守法律法规的自觉性和主动性。加强国家和自治区有关宗教事务管理政策法规的贯彻落实，积极配合有关部门依法严厉打击和防范非法宗教活动干涉婚姻的违法行为，坚决杜绝违反政策法规念“尼卡”、说“塔拉克”及其他形式的违法行为。

各级卫生计生部门要进一步开展好“婚育新风进万家”活动，大力宣传普及计划生育政策法规及相关知识，严格落实计划生育政策。加强人口和计划生育信息统计，严格再婚人员生育审批，加强孕前型服务管理，加大流动人口计划生育管理工作力度。严肃查处非婚生育和违法生育。

各级妇联组织要积极贯彻落实《中华人民共和国反家庭暴力法》，加强对家庭暴力行为的有效干预，健全维权工作网络，加强反家庭暴力法制宣传，及时提供心理辅导等危机干预服务，推动将心理服务纳入城乡基本公共服务体系。配合公安机关、法院依法处置家庭暴力行为，严防矛盾激化升级。

三、加强领导，确保各项保障措施落实到位

（一）加强组织领导。各地要切实统一思想、提高认识，紧紧围绕社会稳定和长治久安总目标，坚持党委领导、政府主导、部门协调，发挥好基层主体作用，加强婚姻管理工作。细化工作措施，明确工作职责，建立健全工作机制，将加强婚姻管理工作所需必要经费纳入同级财政预算予以保障。

（二）推进信息共享。民政、法院、公安、卫生计生等部门要加强对各类人口户籍和婚姻状况信息的登记管理与共享，充分利用国家人口基础信息库数据，实现对婚姻登记当事人基本信息的查询核证，为各级婚姻登记机关提高婚姻登记的准确性、完整性和有效性提供保障，为全面掌握婚姻基础信息提供科学依据。

（三）严格监督检查。加大监督检查力度，限期改正。对因思想不重视、措施不得力、工作不务实，导致早婚、离婚率高等问题得不到有效纠正，带来严重后果的，要约谈其主要负责人；对辖区内发生非法宗教干预婚姻等严重问题的，要依法依规追究相关单位和责任人的责任。
