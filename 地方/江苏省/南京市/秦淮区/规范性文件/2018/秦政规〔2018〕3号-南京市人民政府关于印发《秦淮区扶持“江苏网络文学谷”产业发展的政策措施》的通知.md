# 南京市人民政府关于印发《秦淮区扶持“江苏网络文学谷”产业发展的政策措施》的通知

南京市秦淮区人民政府关于印发《秦淮区扶持“江苏网络文学谷”产业发展的政策措施》的通知

（秦政规〔2018〕3号）

各街道办事处，区政府各部门，各直属单位：

现将《秦淮区扶持“江苏网络文学谷”产业发展的政策措施》印发给你们，请认真遵照执行。

南京市秦淮区人民政府

2018年9月25日

秦淮区扶持“江苏网络文学谷”产业发展的政策措施

一、扶持范围

本意见适用于在秦淮区注册并落户“江苏网络文学谷”（以下简称“文谷”）且经区文谷项目领导小组办公室备案的网络文学人才以及网络文学相关产业链企业[1]。

二、扶持政策

（一）鼓励网络文学人才落户

（1）鼓励网络作家及产业链人才落户。鼓励网络文学人才在“文谷”设立并注册个人工作室且在本区缴纳个税。工作室第一个完整年度营业收入在10万元以上(含10万元，下同)50万元以下的，一次性奖励3000元；在50万元以上100万元以下的，一次性奖励5000元；100万元以上的，一次性奖励1万元。如为市、省或中国作协成员，自设立之时起，分别再给予1000元、2000元、3000元奖励。自在本区缴纳个税之日起，第一个完整年度个税对区经济贡献部分给予最高全额奖励。

（2）鼓励网文IP人才到国内外名牌高校、院所研修，经认定后给予研修费用最高50%补助，最高不超过5万元。

（3）鼓励名家大师落户。对被认定为“大师工作室”[2]的，在“文谷”投资设立企业或工作室，经认定，自设立年度起给予三年内免200平方米办公场所租金，面积超出部分，给予80%房租补贴，最高超出面积不超过200平方米。在执行《南京市文化发展专项资金（人才类）管理使用办法》资助标准基础上，周期内再给予一定工作经费，最高不超过30万元。

（二）鼓励网络文学企业落户

1、鼓励网文企业落户

（4）鼓励企业落户。对企业租用办公用房自设立或引进年度起三年内，给予最高500平方米50%的房租补贴；实际到账注册资金1000万元以上的，给予最高500平方米80%的房租补贴。

（5）优先扶持初创网络文学产业链企业。对于经认定的潜力初创成长企业，确有5名以上全职员工在文学谷办公的，对企业租用办公用房自设立或引进年度起三年内，按人均办公面积8平方米给予房租“两免一减半”的扶持政策，每家企业最高可申请办公面积不超过200平方米，超过的参照本意见其他条款执行。

（6）鼓励有行业积累和行业资源的初创企业落户。创始人有行业知名互联网公司[3]中层以上任职经历，或原先已经是网络文学公司（年销售额不低于2000万元）副总经理以上职位，初次到本地创业并注册，经项目申报并认定，给予入选项目最高50万元创业启动资金。同时协助申报创业南京等人才项目。

（7）鼓励行业内已经有一定影响力的团队或企业落户“文谷”，经认定，可参照不低于前述第（6）条，一事一议。

2、加快网络文学产业发展

（8）支持网文平台积极签约网络作家。落户在“文谷”的网文平台，自落户之日起，第一个完整年度新签约网络作家版权收入（总计不低于100万元）所产生的对区经济贡献部分，给予该平台最高100%奖励，第二年给予最高80%奖励，第三年给予最高60%奖励。且该平台与网络作家签约年度不得低于5年，每年新签约作家数量不得低于50个，签约作品不得低于100部。

（9）支持网文平台拓展渠道。落户在“文谷”的网文平台，每拓展一个新的互联网传播渠道，且该渠道每年销售分成给该平台收入不低于200万元的，经认定，给予每个渠道拓展奖励2万元。

（10）持续扶优扶强。对于设立或引进三年以上的网文企业：

年营业收入500万元以上1000万元以下且同比增长不低于 20%的，认定为年度成长型文创企业，给予最高200平方米房租“两免一减半”及面积超出部分当年度50%的房租补贴，单个企业补贴面积一般不超过400平方米。

年营业收入1000万元以上5000万元以下且同比增长不低于20%的，给予当年度最高50%的房租补贴，单个企业补贴面积一般不超过600平方米。

年营业收入5000万元-2亿元的优质网文企业，给予当年度最高50%的房租补贴，单个企业补贴面积一般不超过1500平方米，当年对区贡献比上一年新增部分100%用于支持企业发展。

年营业收入2亿元以上的骨干网文企业，给予当年度最高50%的房租补贴，单个企业补贴面积一般不超过2000平方米，当年对区贡献比上一年新增部分100%用于支持企业发展。

3、鼓励产业链企业发展壮大

（11）研发补助：对经认定的重点研发类项目按实际研发投入最高15%予以补助。

（12）贷款贴息：对企业为发展文化创意产业所发生的银行借贷资金，最高按银行同期贷款基准利率予以贴息补助，每年贴息不超过100万元。

（13）参展补助：鼓励企业参加省、市、区组织的重点文化创意产业会展，给予展位费用最高50%补助，单个企业每年补助总额不超过50万元。

（14）播出补助：在中央台、省级卫视首次播出的电视剧、 纪录片，分别给予最高每集6万元和2万元补助，每部作品补助总额不超过150万元。在中央台、省级卫视（含卡通上星频道）首次播出的原创动画作品，分别给予最高每分钟800元和500元补助，每部作品补助总额不超过100万元。在全国院线首映的电影作品，票房达到5000万元以上的，最高奖励50万元；票房达到1亿元以上的，最高奖励 100万元。

（15）销售补助：自主研发的游戏产品获得国家新闻出版广电总局批准并正式上线运营的，年度销售总额首次达到 1000～5000万元的部分按1.5%给予补助，超过5000万元以上的部分按2.5%给予补助，补助总额不超过200万元。

4、提升资本运作和管理能力

（16）鼓励创投机构或国内外上市公司投资网文产业。对获得创投机构或国内外上市公司投资额累计达1000万元以上的网文企业，经研究，可最高给予三年房租补贴，补贴面积一般不超过1000平方米，并以上年度对区贡献为基数，对企业三年新增贡献部分给予资助。

（17）支持文谷产业园建设。经区“文谷”领导小组项目办备案，网文及相关产业链企业承租面积首次达到5000平方米，给予“文谷”运营管理平台50万元奖励。

（三）鼓励文创品牌打造

（18）支持文创精品佳作。获得全国、江苏省“精神文明建设五个一工程奖”的作品分别给予100万元、30万元的一次性奖励。对获得其他重大奖项的动漫游戏、影视节目、网络文学等原创作品，经认定，最高给予 20万元的一次性奖励，同一企业当年奖励总额不超过 30万元。列入国家、省级文化出口重点企业的，一次性分别给予50万元、20万元的奖励。

（19）支持品牌活动。由我区网文企业主办，举办地设在我区，在江苏省乃至全国有较大影响的特色文化创意活动，经审核备案，可给予50%的经费支持，资助总额不超过100万元。

以上（8）—（19）政策补助总额以企业当年对区贡献为限。

三、配套服务政策

1、健全金融服务和财政支持体系。加大财政投入力度，设立区文化产业专项扶持资金，设立专项奖励资金和风险补偿资金池；支持网络文学企业挂牌上市；支持银行业金融机构创新融资服务，加大对网络文学企业信贷支持。以上政策比照区科技创新系列政策执行。

2、营造创新创业发展氛围。支持鼓励各类网络文学创新组织，积极参加“赢在南京”系列国际创新创业活动，打造“江苏网络文学创新大赛”品牌，定期举办以创客、创新、创业为主题的论坛、大赛、沙龙等活动。认真落实有关人才安居政策，制定人才健康服务、教育服务等保障办法，多渠道解决人才子女教育、家属安置、医疗保健等问题。提高行政效率，加快智慧城区建设，加大对网络文学重大事项及人物的宣传，营造优质服务环境。

四、附则

1、申报评审、监督管理等程序另行制定管理办法。

2、本意见自发布之日起 30天后施行，2018年度符合本意见扶持条件的，可参照执行。具体由“文谷”项目领导小组办公室会同区财政局负责解释。

[1] 包括但不限于以下相关产业链企业：文学、音乐、游戏、动漫、影视、直播、综艺等。

[2] 大师认定包括：三年内入选“中国网络作家富豪榜”；主流网络文学网站签约作家列入“白金作家”或同等级别作家；由省级以上新闻出版局、省级以上作协、中国互联网百强企业或中国文化企业30强主办的网络文学奖项评选的获奖作家。

[3] 如BATJ（百度、阿里、腾讯、京东），爱奇艺，喜马拉雅，掌阅，网易，360等。
