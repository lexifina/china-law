# 关于命名天宁区区级农业龙头企业的通知

开发区管委会、各街道办事处、区有关企业：

农业龙头企业是推动农业产业化发展的骨干力量，对推进城乡一体化进程具有重要意义。为进一步推动我区农业龙头企业的发展，依照《常州市天宁区农业产业化区级龙头企业认定与运行监测管理暂行办法》的实施意见，现认定常州食品有限公司为天宁区农业产业化经营重点龙头企业。

希望常州食品有限公司要充分发挥龙头企业的示范带动作用，加快转型升级的步伐，为促进我区经济社会发展作出新的更大的贡献。全区各级各部门要进一步加大对农业产业化经营龙头企业的扶持力度，落实有关政策措施，共同为龙头企业的发展创造有利条件。

常州市天宁区人民政府

2012年12月25日
