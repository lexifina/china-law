# 区政府关于印发《常州市天宁区2013年国民经济、社会发展计划执行情况与2014年国民经济、社会发展计划》的通知

开发区管委会、各街道办事处，区各办局：

《常州市天宁区2013年国民经济、社会发展计划执行情况与2014年国民经济、社会发展计划》已经区第十五届人民代表大会第三次会议审议通过，现印发给你们，请认真贯彻落实。

常州市天宁区人民政府

2014年2月24日

常州市天宁区2013年国民经济、社会发展计划

执行情况与2014年国民经济、社会发展计划

一、2013年计划执行情况

2013年，全区上下以“推进城市更新、打造品质之区”为战略目标，以加快转变发展方式为主线，以改革开放和科技创新为动力，以保障和改善民生为根本，积极抢抓苏南现代化示范区建设机遇，立足长远，主动谋划，争先创优，真抓实干，向实现现代化迈出了坚实的步伐。

（一）关于主要指标完成情况（见表一）

全年完成地区生产总值438.82亿元，增长11.6%；全社会固定资产投资完成290.23亿元，增长17.38%，其中服务业投入256.05亿元，增长20.77%，占全社会固定资产投资的88.2%；公共财政预算收入41.63亿元，增长5.02%；社会消费品零售总额344.12亿元，增长16.15%；服务业营业收入1504.16亿元，增长23.59%；实际到账外资3亿美元，增长149.89%；工商登记注册外资4.17亿美元；城镇居民人均可支配收入37620元，增长12%。

（二）关于重点项目计划完成情况

2013年，重点项目的全程代理制进一步完善，督查力度进一步加强。通过加强服务，为亚玛顿等项目启动提供了前期手续的协调和保障，积极向上争取点供土地指标234亩。全区96个重点项目全年预计完成投资216.25亿元，完成计划的83.19%，其中，工业投资完成17.68亿元，服务业投资完成171.68亿元，基础设施投资完成25.84亿元，社会事业投资完成1.05亿元。四药研发中心、万都商业广场等10个市重点项目完成年度计划投资的110%。

（三）关于征收项目计划完成情况

2013年，我区积极推进征收工作，共计15个项目启动实施，征收住宅1220户，非住宅230户，完成征收面积130万平方米。其中，经济发展和城市建设类：青龙生活区1-8#、1-9#地块，凤凰东路东侧、老运河南侧、青洋路西侧、劳动路北侧改造项目（一期），常药厂西侧地块（一期）改造，胡一胡二地块改造，优胜路东侧、劳动东路南侧、青洋路西侧、中吴大道北侧（二期），采菱老工业园地块，刘塘浜南侧地块，兰鑫织造及周边地块，青龙生活区（水投1号）地块；社会事业和基础设施类：晋陵南路（光华路—中吴大道）改扩建工程，桃园路（和平北路—延陵中路）改扩建工程，新堂北路（飞龙东路—龙城大道）改扩建工程，常州市轨道交通1号线配套工程—文化宫站周边疏解道路改造工程、同济桥改造工程，青果巷改造项目。

二、2014年计划目标

（一）2014年主要预期目标

根据区委九届五次全会决策和部署，2014年全区国民经济和社会发展主要预期目标建议如下：

——地区生产总值增长9％；

——公共财政预算收入增长5％；

——全社会固定资产投资增长12%；

——服务业营业收入增长20％；

——社会消费品零售总额增长15％；

——实际到账外资30000万美元；

——城镇居民人均可支配收入增长11％。

（二）2014年重点项目建设计划

进一步推进重大项目建设，强化重大项目的支撑作用，推动转型升级、特色发展。2014年初步安排87个市、区两级重点项目，年度计划投资185.9亿元。其中，列入市重点投资计划项目14个，年度计划投资38.2亿元；服务业项目71个，年度计划投资171亿元。

三、2014年旧城改造计划

2014年，我区拟实施37个旧城改造项目，涉及新城建设、城市综合体建设、现代服务业提升、旧城老村改造、道路建设五个方面。具体分别是：雕庄街道芳田村地块、茹家塘地块、杨家塘地块、远华纺织周边地块、原钢材现货市场周边地块、常编厂周边地块、老三集团以北地块、健民制药地块；青龙街道丁莫村地块、常青村东方西路周边地块（青龙西路以南，东方西路以东）、常青村（青龙西路以南，东方西路以西）、常青村（东方西路以东，规划道路以南）、三里村高架沿线地块；茶山街道田家炳中学周边地块、张太雷故居周边地块、灯芯绒厂北侧地块、丽华一村大板房改造、高成天鹅湖南侧地块、光华路南侧丽华路东侧地块；红梅街道卫星村委杨板村地块、二五三厂周边地块、北环新村大板房改造、宁家塘周边地块、钱家村周边地块、常高技周边地块；天宁街道火车站南广场地块、中联商场及周边地块、陆家村地块、东印厂及周边地块；兰陵街道堵家塘及周边地块、农副公司及周边地块、地铁大厦周边地块、荡南吴家村地块、欧尚北侧地块、浦前华家村地块、荡南北侧地块、中凉亭汽摩配市场周边地块。

四、2014年重点工作计划

（一）狠抓重点项目，保持平稳增长

把工作的重点聚焦项目，把有限的资源聚焦项目，把服务的对象聚焦项目，进一步提升服务质量和效能，更大力度推进重点项目建设。做好今年市、区重点项目督查推进工作，全力以赴确保有效投入。加速推进项目。攻坚开工难题，针对未开工重点项目，加大跟踪服务力度，以现场办公促督查，全力协调解决突出难题，确保天晟二期、万都广场等16个续建项目年内竣工达产。高效服务项目。坚持服务“下沉”，全力推进项目审批全程代理制度。加快启动天美日用品、恒隆线材等新开工项目建设，上半年开工率达60%，全年完成投资90亿元。强化领导挂钩服务，市、区重点项目由区领导挂钩、街道属地负责。强化区、街联动，实行项目推进每周报送、每月督查，及时掌握进展情况，协调解决存在问题。提前谋划项目。聚焦城市综合体、楼宇经济等重点领域，着重挖掘一批符合国家产业政策、有利于推动产业结构调整升级和战略性新兴产业发展的大项目、好项目，促进产业提档升级、完善城市功能和改善社会民生。主攻项目引进、招商引资，在盘活区域有限存量的基础上，引进增量、扩大存量，增强发展后劲。

（二）深入创新驱动，形成先导优势

把科技创新作为天宁新一轮发展最大、最新的动力，狠抓创新主体、创新载体和创新环境建设，不断提升科技要素对实现现代化的贡献率。一是高效利用资源，加快平台建设。充分发挥天宁高新技术创业服务中心、新动力高新技术创业服务中心等孵化平台作用。引进科技含量高、产品附加值高的研发中心和企业入驻。高标准建设新能源材料科技产业园、凤凰新城生命健康产业园等六大园区，全年完成投入26亿元。二是充分利用天宁的区位优势，大力推进重大载体建设。加快恒生科技园、黑牡丹科技园、中华纺织博览园建设，力争到2015年全区形成科技研发孵化面积 50万平方米。依托优质地块、优质楼宇、优质商业网点，大力推进总部楼宇建设。三是继续推进产学研合作，优化创新环境。推动建立由企业、高校、科研机构和其他组织共同参与的产业技术创新联盟，引导创新要素向企业集聚；加快构建支持创新、鼓励创新的管理体制、运行机制和支撑体系；引进掌握核心技术的领军型创新创业人才项目25个、领军人才25名。

（三）大力发展现代服务业，培育特色优势

以转型升级为主线，重点发展现代商贸、金融服务、文化旅游三大产业，依托楼宇稳步发展商务服务、电子商务、科技服务等新兴产业，实现服务业“发展提速、比重提高、结构优化”。新增重点服务业企业100家，服务业营业收入力争突破1800亿元，服务业增加值占地区生产总值的比重提升到70.5%。一是合理规划服务业发展布局。做强文化宫中央商务区。加快实施中联大厦地块改造等项目，优化提升万博北岸及文化宫地下广场商业业态，打造常州高端购物中心。同时加快启动南、北广场项目，配套建设商务主导型大型综合体，强化中心商圈的购物、休闲、娱乐、美食、都市旅游等功能的整合。打造凤凰新城和天宁新城两大副商圈，引进集商务办公、休闲娱乐、酒店餐饮、商业商贸、总部经济、金融服务、品牌教育等业态。二是加强业态集聚效应。主题化、特色化推进城市综合体建设，加快建设九洲新世界、弘阳广场和中华纺织博览园。重点推进东经120金融商务区建设。全力打造劳动路数码，飞龙路家居等特色街区。推进青洋路两侧业态调整，逐步形成创意产业配套区、科技创新示范区、生产性服务业集聚区。大力发展青洋路高速道口经济，引进常药和中通等大型物流企业，加快建设现代物流园。三是主题化发展楼宇经济。针对凤凰新城、火车站南北广场、中吴大道、通江路、青洋路、东经120等重点区域，合理规划一批设施齐全、配套到位的高品质商务楼宇，启动生命人寿保险大楼、佳程大厦建设，做好万都广场、九洲新世界等重点楼宇招商。

（四）合理整合空间资源，提升城区品质

针对天宁资源现状和未来发展方向的要求，深入调查研究，坚持集约发展，提升城区品质，高水平打造精品城区。有序推进三旧改造。全面梳理“三改”区域，加快规划策划，按照轻重缓急排出拟实施地块，制定改造方案。积极创新工作理念和方法，探索政府主导、市场开发、土地入股等改造模式，加大组织推进力度。高效推进征收工作。确保全年完成征收120万平方米，确保市政项目征收进度，加快实施重点征收项目，全面清结常化厂、火车站北广场等18个结转项目。

（五）积极发展文化产业，放大品牌效应

挖掘和整合天宁的文化资源，培育和放大天宁的文化品牌，推动全区文化产业的发展繁荣。一是放大名人文化、运河文化、古街文化资源。推动文化与旅游、体育、休闲等产业的嫁接联动。结合古运河申遗，积极推进工业遗存的保护开发，打响运河文化品牌。深入研究街区规划方案，展示古城风貌。创意化发展文化旅游，争取启动5Ａ级天宁名胜旅游区创建工作。二是推进文化产业项目。加快推进报业传媒大厦、中华纺织博览园等一批文化创意产业项目，着力引进广告设计、动漫制作等文化企业，确保全区文化产业增加值占地区生产总值比重达5.3%。三是丰富开展文化活动。推进区老年大学、文化中心、图书馆建设，争取做好国家、省、市级项目，继续深化道德讲堂建设，进一步提升市民文化素养。

（六）为民办好实事，维护社会稳定

始终把保障和改善民生作为政府工作的出发点和落脚点，创新社会管理，统筹推进各项社会事业协调发展，不断提升天宁人的幸福感和自豪感。一是优化教育资源。深入实施教育现代化新三年行动计划，放大教育集团的品牌效应，实现优质教育资源全覆盖，推进学校特色发展，提升集团化办学水平。二是优化区域卫生服务。积极引进优质资源，提升公共卫生服务能力，改善基本医疗卫生服务水平，新建和整合提升社区卫生服务中心、服务站8家。三是优化社区建设项目管理。实施一批老社区改造项目，同时积极探索新型社会服务项目，改造提升城中村、次新小区、安置小区安防设施，全面提升百姓的幸福感和满意度。四是强化作风建设。进一步梳理行政审批事项，简化审批手续，优化服务。注重调查研究，掌握真实情况，了解群众所盼、所急、所需，为基层送政策、解难题，实现好、维护好、发展好群众的最根本利益，树立为民、务实、清廉、高效的机关形象。五是深化平安、法制天宁建设。完善社会稳定风险评估机制，深入开展社会矛盾多元化调处工作，化解信访积案。大力实施法制惠民工程，突出治安问题专项治理，增强群众安全感。加大安全生产隐患排查及整治力度，营造安全发展环境。
