# 区政府办公室关于印发《天宁区2014年行政机关领导干部学法计划》的通知

开发区管委会、各街道办事处，区各办局：

经区政府同意，现将《天宁区2014年行政机关领导干部学法计划》印发给你们，望认真贯彻落实。

常州市天宁区人民政府办公室

2014年5月28日

天宁区2014年行政机关领导干部学法计划

为充分发挥领导干部学习法律的表率作用，进一步提高全区行政机关领导干部运用法治思维解决问题的能力，推进依法行政，建设法治政府，结合天宁区实际，制定本计划。

一、区政府常务会议学法安排

全年安排2次区政府常务会议学法活动。

（一）第一次学法活动

学习时间：2014年上半年（具体时间另行通知）。

学习方式：集中学习。

学习内容：国务院《社会救助暂行办法》。

参加人员：区政府区长、副区长；区政府办公室主任；列席会议的区政府部门和街道办事处负责人。

责任单位：区政府办公室、区民政局、区政府法制办。

（二）第二次学法活动

学习时间：2014年下半年（具体时间另行通知）。

学习方式：集中学习。

学习内容：《江苏省物业管理条例》。

人员范围：区政府区长、副区长；区政府办公室主任；列席会议的区政府部门和街道办事处负责人。

责任单位：区政府办公室、区房管局、区政府法制办。

二、区行政机关领导干部专题法制讲座安排

全年举办2期区行政机关领导干部专题法制讲座。

（一）第一次法制讲座

学习时间：2014年上半年（具体时间另行通知）。

学习方式：集中学习。

学习内容：依法行政相关知识。

人员范围：全区行政机关科级以上领导干部。

责任单位：区司法局、区政府法制办。

（二）第二次法制讲座

学习时间：2014年下半年（具体时间另行通知）。

学习方式：集中学习。

学习内容：国务院《国有土地上房屋征收与补偿条例》。

人员范围：全区行政机关科级以上领导干部。

责任单位：区司法局、区政府法制办。

常州市天宁区人民政府办公室 2014年5月28日印发
