# 区政府关于公布天宁区非物质文化遗产重点项目及代表性传承人的通知

各街道办事处、区各办局：

自2003年以来，全区积极开展非物质文化遗产的普查、发掘和申报保护工作，取得了阶段性成果。经逐级、分批次申报和公布，已被确定为各级重点保护名录项目的有31个，其中区级21个、市级5个、省级3个、国家级2个；已被确定为各项目的各级代表性传承人58名，其中省级8名、国家级2名，现一并予以公布。
