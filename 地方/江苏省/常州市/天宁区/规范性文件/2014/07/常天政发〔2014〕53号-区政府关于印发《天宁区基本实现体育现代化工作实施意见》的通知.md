# 区政府关于印发《天宁区基本实现体育现代化工作实施意见》的通知

开发区管委会、各街道办事处，区各办局：

现将《天宁区基本实现体育现代化工作实施意见》印发给你们，请认真组织实施。

常州市天宁区人民政府

2014年7月15日

天宁区基本实现体育现代化工作实施意见

为深入贯彻落实区委区政府关于率先基本实现现代化的决策部署，紧紧围绕“推进城市更新、打造品质天宁”总体战略，促进我区体育事业在“十二五”期间又好又快发展，大力推动天宁区公共体育服务体系建设，不断满足人民群众日益增长的体育需求，根据国家、省市关于体育基本现代化工作要求，现就我区基本实现体育现代化工作提出如下实施意见。

一、指导思想

以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，紧紧围绕率先基本实现体育现代的总目标，以满足人民群众多元化体育健身需求为出发点，加强体育公共服务体系建设，提升体育公共服务水平，切实为人民群众提供更优质、更便捷、更全面的体育公共服务和体育消费产品，努力实现体育强区向体育基本现代化跨越。

二、发展目标

体育健身意识普遍增强，体育健身设施进一步完善，体育健身活动蓬勃开展，体育参与率明显提高，体育社会化程度大幅度提高，体育社会组织网络与服务体系更加完善，竞技体育综合实力和竞争力不断提升，体育产业和体育市场不断繁荣规范，体育管理和人才队伍建设不断加强，积极探索具有区特色的体育现代化发展道路，推动全社会的体育思想观念、管理方式、运作机制、消费意识的进步与转变，实现全区体育基本现代化。

三、主要任务

（一）体育文化的现代化

积极推广现代体育理念，继续弘扬十七届省运会形成的开拓、拼搏、专注和团队精神，着力打造新时期天宁体育文化。把关心市民身体健康作为民生幸福工程的头等大事来抓，广泛传播健康、向上、积极、丰富的体育文化价值理念，为市民提供更多更好的体育公共服务产品，让体育成为市民的生活习惯和方式。搭建体育和其他文化门类互动平台，通过讲座、报纸、网站、博客、微博等多种渠道宣传体育文化，发挥体育文化在建设现代文化城市中的积极作用，实现体育文化的大繁荣。

（二）群众体育的现代化

深入贯彻《全民健身条例》，全区所有街道实现体育总会、老年人体育协会、社会体育指导员协会和至少2个体育单项协会的全覆盖，100%的行政村（社区）建立2个以上体育社会组织。加强国民体质研究和体质监测服务，建立国民体质监测服务系统，形成国民体质监测的预警机制，实施体质监控和追踪研究，定期公布体质监测结果，引导市民关注体质和健身。全区建有区级全民健身活动中心1个、街道级全民健身活动中心5个以上,各类区级体育协会总数达15个，市级社区体育俱乐部总数达16个。每万人拥有晨（晚）练健身站（点）6个以上。区每四年举办一次综合性运动会，街道每两年举办群众喜闻乐见、趣味性、竞技性结合的体育赛事，学校每年举办一次校运会。全年举（承）办或参加省级以上群体赛事（活动）1次以上，通过举（承）办或参加省、市、区赛事活动，打造“一街一品牌、一街一特色”的全民健身品牌。

（三）竞技体育的现代化

通过天宁区少年儿童业余体校，保持市区联办男子足球运动队、市队区办艺术体操运动队规模，成绩处于全省领先位置，逐步完善竞技体育后备人才培养体系，提高业余训练成绩，为国家、省市输送各类体育人才，争创国家竞技体育高水平后备人才基地。健全体育竞赛制度，每年举办全区小学生春秋两季田径运动会和篮球、足球、排球、羽毛球、乒乓球、棋类、冬季三项等体育赛事。创建一批省市级体育传统（特色）学校，常年正常开展业余体育项目训练，积极承办市级以上体育赛事。

（四）体育产业的现代化

坚持“政府主导、社会参与、市场运作”的方向，通过红梅街道的国家级社区体育健身俱乐部的辐射作用，与英派斯健身品牌团队合作，形成“政府购买服务”方式，创新运营管理模式，鼓励引导社会力量投资体育产业，逐步实现投资主体多元化，不断提高体育健身服务和体育竞赛产品的质量，推进体育产业健康发展。积极开展形式多样的群众性体育活动，丰富体育活动内容，提高体育活动效果，大力提倡体育项目创新，积极引进适合不同人群的新型体育项目,鼓励社会组织举办各种体育竞赛、展示、表演活动，吸引市民参与，逐步提高参与体育健身消费活动的人次数。

（五）体育设施的现代化

制定出台《天宁区公共体育服务体系建设三年行动计划（2014-2016年）》，全面推进区、街道、社区（村）、居民小区（自然村）四级公共体育设施网络建设，加强对各级各类公共体育设施的管理，规范服务标准，扩大服务的内容。建立包括学校体育设施和社会体育设施的体育服务网络，实行多层次、多时段、多种优惠的多元化服务，为市民提供更多便利。建设一批“10分钟体育健身圈”示范社区，积极创建市级全民健身示范工程和市级社区体育健身俱乐部，做好健身设施维护管理工作，百姓满意率100%。加强教体结合，符合开放条件的学校体育设施全部向社会开放，依托学校体育场馆建设，挂牌街道的全民健身活动中心。

（六）人才队伍的现代化

增加体育组织尤其是基层体育组织的数量，培育和发展体育社团，加强群众性体育组织、体育团队的管理，帮助自发性体育群体增强自我组织和管理能力，建立体育骨干培训、培养体制，鼓励有组织地进行体育活动，不断扩大有组织活动的体育人口。加强社会体育指导员培训，实行分类指导和体育教学服务，每年免费培训各类社会体育指导员100名以上，每万人拥有社会体育指导员36人以上。建立完善公共体育服务队伍，鼓励运动员、教练员、体育老师、体育科研人员积极参与，实施公共体育服务人员轮训计划，定期开展技能培训，提高健身组织服务质量。

四、实施步骤

（一）动员部署阶段（2014年2月-2014年5月）

1.制订《天宁区基本实现体育现代化工作实施意见》和指标评估体系。

2.成立天宁区基本实现体育现代化建设工作领导小组，明确各职能部门任务和职责。

（二）全面实施阶段（2014年6月-2015年10月）

1.召开全区基本实现体育现代化建设工作会议，全面部署试点工作。

2.进行指标评估体系论证，完善充实和确认。

3.各职能部门对照《实施意见》，细化分解工作任务，落实工作措施，全面推进试点工作。

（三）总结评估阶段（2015年末）

1.对基本实现体育现代化各项指标完成情况进行全面的检查考核。

2.对全面实施工作进行总结，并提出下一轮体育发展新的目标和要求。

五、保障措施

（一）落实责任

各街道和各职能部门位要从落实科学发展观、构建和谐社会的高度，根据体育基本现代化的要求和步骤，组织实施基本实现体育现代化工作。由区基本实现体育现代化工作领导小组组织指导全区基本实现体育现代化的实施工作。各相关部门、单位要建立相应组织机构，统一领导，加强协调，建立完整、高效的管理制度，健全调研、决策、落实、反馈等一整套行之有效的运行机制。进一步分解工作任务，组织协调相关工作，确保试点工作真正落到实处、取得实效。各成员单位要充分发挥综合、协调、参谋、服务作用，建立健全工作责任制，明确责任主体，加强合作和支持，有效形成工作合力，层层落实，步步落实，确保实施工作的顺利推进。

（二）强化保障

根据基本实现体育现代化工作要求，完善政府对体育事业的投入机制，体育事业经费列入各级财政预算，并随经济的发展稳步增长，为基本实现体育现代化工作的顺利实施提供资金保障。要进一步加强对基层体育健身设施、公共体育场馆的建设和管理，加大对重大品牌体育赛事、优势运动项目、体育组织发展等方面的资金扶持力度，推动体育事业与体育产业的全面协调可持续发展。建立多渠道、多层次的体育资金筹措机制，按照“谁投资、谁受益”的原则，鼓励社会资金、外资等对体育发展的投入，增强体育事业的发展活力。

（三）完善督查

各街道和各职能部门要高度重视并切实做好督查工作。要健全督查机构，完善督查职能，做到人员到位，责任到位，落实到位，必要时建立专项督查制度。督查部门要充分发挥作用，加强跟踪反馈，抓好督查落实。要把督查工作和排忧解难结合起来，在督查过程中，努力转变作风，提高效率，坚持深入一线，坚持调查研究，坚持实事求是，搞好督查催办，并善于提出意见和建议，切实完成好实施过程中的督查任务，推动重点工作的落实。要把督查工作和创新创优结合起来，深入研究新时期体育事业面临的新形势、新任务和新要求，正确认识和把握新时期体育发展规律，抓住当前工作中存在的突出问题、主要矛盾和薄弱环节， 坚持改革创新，破解难题、突破瓶颈，全面提升体育发展水平。
