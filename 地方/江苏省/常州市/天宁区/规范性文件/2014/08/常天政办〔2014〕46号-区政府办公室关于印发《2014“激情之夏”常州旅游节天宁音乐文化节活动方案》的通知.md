# 区政府办公室关于印发《2014“激情之夏”常州旅游节天宁音乐文化节活动方案》的通知

天宁街道办事处，区有关部门：

现将《2014“激情之夏”常州旅游节天宁音乐文化节活动方案》印发给你们，请认真贯彻落实。

常州市天宁区人民政府办公室

2014年8月14日

2014“激情之夏”常州旅游节

天宁音乐文化节活动方案

为贯彻落实省、市旅游局“畅游江苏”活动要求，加强常州城市形象宣传，进一步打造天宁城市旅游节庆品牌，同时丰富广大市民文化生活，促进天宁城市旅游发展和提升，现制定2014“激情之夏”常州旅游节天宁音乐文化节活动方案。

一、活动时间

2014年8月22日—8月26日

二、活动地点

天宁商都

三、组织机构

成立2014 “激情之夏”常州旅游节天宁音乐文化节组委会，负责整个活动的组织协调工作。组委会成员名单如下：

组委会下设办公室，办公室设在区旅游办，吴静同志兼任办公室主任，吕强、石建忠兼任办公室副主任。

四、主要内容

1.非物质文化遗产和创意手工艺品展销、现场展示。

2.特色小吃、美食现场制作。

3.民俗与现代艺术表演（民族舞、劲歌热舞、乐器演奏、杂技魔术等）。

4.喝啤酒比赛等现场互动游戏。

五、主办单位

常州市天宁区人民政府

六、工作分工

1.区旅游办：活动策划、方案制定、衔接协调、落实费用。

2.区教育文体局：非遗展示和相关表演。

3.区委宣传部：活动宣传报道。

4.天宁街道：现场秩序、保安工作、开幕式观众组织。

5.区城管局：制定停车方案，负责沿线周边环境及卫生、安全保护。

6.区环卫处：负责现场安排垃圾筒及每日垃圾清运。

7.天宁交巡警大队：制定交通疏导方案，维护现场交通秩序；指挥领导、观众、演员车辆停放。

8.天宁消防大队：负责活动期间消防安全。

9.区公安分局水门桥派出所：负责活动期间现场治安管理。

10.区卫生局：负责全场食品安全管理。

七、工作要求

各部门要高度重视本次活动，切实加强“旅游节”活动的领导，落实专人负责，加强协调，注重配合。活动开展期间，区领导小组成员和相关单位、部门的领导要按各自的职责分工，切实履行活动组织和现场维护的责任，积极搞好各项协调工作，确保2014“激情之夏”常州旅游节天宁音乐文化节活动圆满成功。
