# 区政府办公室关于印发《常州市天宁区12345政府公共服务承接平台筹建方案》的通知

开发区管委会、镇政府、各街道办事处，区各办局、公司：

《常州市天宁区12345政府公共服务承接平台筹建方案》已经区政府常务会议讨论通过，现印发给你们，请认真贯彻执行。

常州市天宁区人民政府办公室

2017年1月19日

（此件公开发布）

常州市天宁区12345政府公共服务

承接平台筹建方案

为贯彻落实《常州市12345政府公共服务平台筹建方案》（常政办发〔2016〕172号）文件要求，加快推进区级承接平台筹建工作，确保平台建设质量并如期投入运行，结合天宁工作实际，特制定本筹建方案。

一、组织领导

（一）区级联席会议。建立由区政府分管领导任总召集人，镇（街道）、区相关部门分管领导为成员，办公室（综合科）负责人为联络员的联席会议制度，负责平台建设及运行管理中重大事项的决策、组织协调和监督检查。联席会议办公室设在区政管办，具体负责日常工作。

（二）工作推进小组。平台筹建期间，由区政府办公室分管副主任牵头，会同区编办、信访局、财政局、人社局、政管办等部门，负责推进落实12345承接平台建设具体工作。

二、机构设置

（一）调整相关职能机构。将原区信访局内设的12345政府公共服务平台管理办公室调整为区政管办的内设机构，相关职能一并划转，并更名为“12345公共服务管理科”，承担12345政府公共服务承接平台的行政管理、监督考核和对外协调职能。

（二）设立区便民服务中心。参照市机构设置模式和天宁实际，整合区社会治理服务中心职能，成立天宁区便民服务中心（挂社会治理服务中心牌子，副科级事业单位），统筹考虑机构设置及人员配备，承担便民服务体系建设、12345承接平台日常运行以及社会治理联动平台运行管理等职能。

（三）其他成员单位。镇（街道）、各相关部门指定办公室（综合科）并配备专（兼）职人员负责平台工单办理工作。

三、平台建设

（一）区政管办统一负责12345承接平台硬件场地建设，并按照要求设置调度区、展示区和办公区，核定相关工作岗位，配备专职人员负责市平台派发工单的转承办事宜。区级机关后勤管理服务中心配合区政管办确定办公地点。

（二）区相关部门、镇（街道）、村（社区）参照设立承接平台，明确分管领导及1—2名专（兼）职工作人员。

（三）区、镇（街道）、村（社区）承接平台按照要求统一使用全市12345一体化公共服务平台软件系统，与市级平台形成四级互联互通的信息网络，打破信息壁垒，实现12345公共信息的共享、事项处理的联动、平台的实时监控、大数据的全面利用以及现有政府公共服务类微信微博等平台与12345平台的对接融合。

四、整合步骤

由区政管办梳理汇总各成员单位对外公开的投诉咨询电话，按照要求与市政管办对接确定整合时间和进度，同时做好与目前区信访局12345平台的交接工作。

五、经费承担

区12345承接平台建设经费，包括硬件建设费用、软件系统的接入使用费用以及平台的运维费、办公经费、聘用人员费用等，统一纳入财政预算。镇（街道）、村（社区）以及其他成员单位的相关费用自行解决。

六、考核措施

将12345承接平台建设工作列入2017年度区委区政府重点工程（项目），各成员单位纳入全区机关部门作风建设考核。承接平台运行管理办法另行制定。
