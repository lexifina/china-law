# 区政府关于调整区政府领导工作分工的通知

开发区管委会、镇政府、各街道办事处，区各办局、公司：

因区政府领导人事变动，根据工作需要，并报区委同意，决定对区政府领导分工进行调整。具体分工如下：

许小波：主持区政府全面工作，兼管机构编制、监察、财政、审计、人民武装、人事、外事、体制改革、开发区建设方面工作。

分管区政府办公室、编办、监察局、财政局、审计局、外事办。

郑 亚：负责区政府常务工作，分管发展改革、服务业、物价、重点项目建设、政务服务管理、国有资产、集体资产、住房、统计、保密、政府法制、房屋征收与补偿、开发区东扩融合发展区建设、常州天宁建设发展集团有限公司、江苏舜宁投资建设有限公司方面工作。协管体制改革、开发区建设工作。

分管发展和改革局（物价局、服务业发展办）、房产管理局、统计局、政管办、国资办、法制办、征收办、常州天宁建设发展集团有限公司、江苏舜宁投资建设有限公司。

周登蓉：分管工业经济、经济协作和信息化、金融业（银行、保险、证券）、环保、安全生产、常州金融商务区建设方面工作。协管企业改制。联系工商联、供电工作。

分管经济和信息化局（中小企业局、金融办）、环境保护局、安全生产监督管理局。

联系国税一分局、国税五分局、地税一分局、地税四分局、地税五分局和相关金融机构、供电公司。

陈旭光：分管公安、综治、消防、司法、国家安全、应急管理、信访方面工作。

分管综治办、信访局、司法局、公安天宁分局、应急办。

联系天宁交警大队、天宁消防大队。

管黎芳：分管教育、文化、体育、文化产业、民族宗教、台侨事务、档案、建议提案办理、老年大学方面工作。协管办公室、车改房改工作。

分管教育文体局、民族宗教事务局、侨办。

联系档案局、总工会、团区委、妇联、台办。

方 力：分管商务、招商、外资、外贸、外经、楼宇经济、农村、农业、水利、防汛防旱方面工作。协管外事工作。

分管商务局（招商服务中心）、农业局（水利局）。

联系农工办。

张洪兵：分管民政、双拥、社区建设、卫生计生、食品药品监管、市场建设管理、质量技术监督、老龄、机关后勤管理服务、信息中心、科技促进中心管理、残疾人、妇女儿童、红十字会、健康养老服务业集聚区建设方面工作。协管人民武装工作。

分管民政局（社区办）、卫生和计划生育局、市场监督管理局（食药监局、食安委办）、老龄办、区级机关后勤管理服务中心、信息中心。

联系科协、残联、红十字会。

岳 军：分管建设、城市管理、旅游、民防、国土、规划、交通运输方面工作。

分管建设局（地震局）、城市管理局（行政执法局、监督指挥中心）、旅游办、民防局。

联系国土天宁分局、规划天宁分局、天宁运管所。

顾 潮：分管科技、科技园区建设、知识产权、人力资源和社会保障、高新技术创业服务、江苏常州人力资源服务产业园建设方面工作。

分管科学技术局（知识产权局）、人力资源和社会保障局、常州市天宁高新技术创业服务中心、江苏常州人力资源服务产业园。

常州市天宁区人民政府
