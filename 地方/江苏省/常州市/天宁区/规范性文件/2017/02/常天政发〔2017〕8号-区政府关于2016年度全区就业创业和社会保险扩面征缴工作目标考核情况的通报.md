# 区政府关于2016年度全区就业创业和社会保险扩面征缴工作目标考核情况的通报

开发区管委会、镇政府、各街道办事处，区各办局、公司：

2016年，全区各级各部门认真贯彻区委区政府的重大决策部署，稳步推进就业创业工作，有序实施全民参保计划，迎难而上抓好社会保险扩面征缴工作，圆满完成了各项目标任务，实现了“十三五”人社工作的良好开局。经考核，决定对郑陆镇人民政府、雕庄街道办事处、青龙街道办事处、茶山街道办事处、红梅街道办事处、天宁街道办事处、兰陵街道办事处、区发展和改革局、区教育文体局、区财政局、区人力资源和社会保障局、区卫生和计划生育局、区市场监督管理局、区统计局、区总工会、地税第五税务分局等16个单位予以通报表扬。

希望受表扬的单位珍惜荣誉，再接再厉，紧扣“两聚一高”总体部署，坚持锐意进取，积极创新实干，努力把我区人力资源和社会保障各项工作做细做实、做优做亮，为建设“强富美高”品质新天宁作出应有的贡献。

常州市天宁区人民政府

2017年2月27日
