# 区政府办公室关于调整政府办主任、副主任工作分工的通知

开发区管委会、镇政府、各街道办事处，区各办局、公司，区政府办公室各挂牌机构、内设科室：

因人事调整及工作需要，经研究并报区政府同意，决定对政府办主任、副主任工作分工作如下调整：

杨琪同志主持区政府办公室全面工作，兼管信息中心，统筹协调民防局、法制办、侨办、应急办、区级机关后勤管理服务中心等部门工作，分管财务科。

顾雪春同志主持区级机关后勤管理服务中心工作，负责车改、房改、科促中心管理等工作。

狄舜尧同志负责协调发展改革、服务业、物价、重点项目建设、政务服务管理、国有资产、集体资产、住房、统计、保密、政府法制、房屋征收与补偿、商务、招商、外资、外贸、外经、楼宇经济、农村、农业、水利、防汛防旱、开发区东扩融合发展区建设、天宁建设发展集团有限公司、江苏舜宁投资建设有限公司等方面工作，负责应急管理、接待工作，分管应急管理科、接待服务科。

李汉田同志负责协调工业经济、经济协作和信息化、金融业（银行、保险、证券）、常州金融商务区建设、建设、城管、环保、安全生产、旅游、民防、国土、规划、交通运输等方面工作，负责政务信息工作，分管信息调研科。

田耀芬同志负责协调教育、文化、体育、文化产业、民政、卫计、食品药品监管、市场建设管理、质量技术监督、民族宗教、台侨事务、双拥、社区建设、老龄、机关后勤管理服务、妇女儿童、残疾人、红十字会、老年大学、档案、建议提案办理、健康养老服务业集聚区建设等方面工作，负责电子政务、政务公开、办公室内部行政管理、文书、档案、保密工作，分管秘书科、督办科，协管信息中心。

李小利同志负责协调科技、科技园区建设、知识产权、人力资源和社会保障、高新技术创业服务、常州人力资源服务产业园建设、公安、综治、消防、司法、国家安全、信访等方面工作，负责政策研究、综合文稿工作，分管综合科。

常州市天宁区人民政府办公室
