# 区政府关于成立天宁区城市道路交通委员会的通知

开发区管委会、镇政府、各街道办事处，区各办局：

为进一步提升城市道路交通规划、建设和管理水平，完善城市道路交通长效综合管理机制，营造更加畅通、有序、安全、文明的城市道路交通环境，区政府决定成立天宁区城市道路交通委员会。成员名单如下：
