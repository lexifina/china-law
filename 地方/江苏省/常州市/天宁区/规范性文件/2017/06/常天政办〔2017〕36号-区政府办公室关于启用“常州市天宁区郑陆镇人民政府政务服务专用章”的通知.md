# 区政府办公室关于启用“常州市天宁区郑陆镇人民政府政务服务专用章”的通知

开发区管委会、镇政府、各街道办事处，区各办局、公司：

根据区委办公室、区政府办公室《关于印发<常州市天宁区郑陆镇机构编制实施方案>的通知》（常天委办〔2016〕7号）精神，郑陆镇人民政府下设便民服务中心，负责统一受理、集中办理进驻中心的行政审批、行政权力及其他管理服务事项。为确保中心办理事项流转顺畅，经研究决定，自即日起启用“常州市天宁区郑陆镇人民政府政务服务专用章”，用于集中进驻郑陆镇便民服务中心事项的受理和办理，视同于郑陆镇人民政府公章，区政府各部门不得要求郑陆镇在上报的便民服务中心集中受理和办理的事项材料上另行加盖条线业务印章。

特此通知。

常州市天宁区人民政府办公室

2017年5月31日
