# 区政府办公室关于印发《天宁区基层综合性文化服务中心建设三年行动计划（2017-2019年）》的通知

开发区管委会、镇政府、各街道办事处，区各办局、公司：

《天宁区基层综合性文化服务中心建设三年行动计划（2017-2019年）》已经区政府研究通过，现印发给你们，请认真贯彻执行。

常州市天宁区人民政府办公室

2017年8月2日

（此件公开发布）

天宁区基层综合性文化服务中心

建设三年行动计划（2017-2019年）

为贯彻落实党的十八届三中全会提出的“整合基层宣传文化、党员教育、科学普及、体育健身等设施，建设综合性文化服务中心”的精神，根据《国务院办公厅关于推进基层综合性文化服务中心建设的指导意见》《省政府办公厅关于推进基层综合性文化服务中心建设的实施意见》以及《常州市基层综合性文化服务中心建设三年行动计划（2017-2019年）》的要求，结合我区实际，特制定本行动计划。

一、指导思想

按照中央和省关于构建现代公共文化服务体系的部署要求，着眼于打通公共文化服务的“最后一公里”，坚持需求导向、服务大局、统筹规划、共建共享，以适应社会主义新农村建设和新型城镇化、城乡一体化建设要求为原则，以满足基层群众多样化的基本公共服务需求和保障基层群众基本文化权益为根本，以强化资源整合、创新管理机制、提升服务效能为重点，发挥政府主导作用，加强部门协同，全面提升镇（街道）、村（社区）综合性文化服务中心建设、管理和服务水平，促进基本公共文化服务标准化、均等化，为建设“强富美高”品质新天宁提供强大精神动力和文化支撑。

二、目标任务

基层综合性公共文化服务中心集宣传文化、党员教育、科学普及、普法教育、卫生计生、便民服务、体育健身等各类公共服务功能于一体。总体目标是：2017年底，全区50%的村（社区）建成达到《常州市村（社区）综合性文化服务中心建设标准》的综合性文化服务中心；2018年，覆盖率达到75%；2019年底，实现全区标准化综合性文化服务中心全覆盖。

三、重点工作

1．合理规划布局

村（社区）综合性文化服务中心设施建设要从基层实际出发，中心面积和功能应当与服务人口数量和服务半径相适应。采取盘活存量、调整置换、集中利用等方式进行，不搞大拆大建。主要依托村（社区）文化活动室、党组织活动场所、城乡社区综合服务设施、闲置中小学校、新建住宅小区公共服务配套设施以及其他城乡综合公共服务设施，在明确产权归属、保证服务接续的基础上进行集合建设，并配备相应器材设备。

2．整合文化资源

严格按照《常州市村（社区）综合性文化服务中心建设标准》，进一步完善行政村（社区）综合性文化服务中心的服务功能。基本服务项目重点围绕文艺演出、读书看报、广播电视、电影放映、文体活动、展览展示、教育培训等方面。以村（社区）综合性文化服务中心为终端平台，整合各级分散独立、用途单一的基层公共文化资源和服务，推广基层综合性文化服务中心“1+X”模式，在做好各项基本公共文化服务的基础上，因地制宜开展地域特色文化服务，增加基层公共文化产品和服务供给，促进优化配置和共建共享，实现人、财、物统筹使用，形成一套符合实际、运行良好的管理机制和运行机制。

3．抓好队伍建设

村（社区）综合性文化服务中心设立不少于1个由政府财政购买的公益性文化岗位。发挥村委会和社区居委会的群众自治组织作用，由村委会或社区居委会确定1名兼职工作人员，引导居民积极参与村(社区)综合性文化服务中心的建设使用。鼓励大学毕业生、大学生村官、志愿者等专兼职从事基层综合性文化服务中心管理服务工作，扶持业余文艺团队和乡土文化能人开展文化活动，充分发挥文化志愿者在文艺编排和活动组织中的重要作用。

实行村（社区）文化管理员岗位目标责任制。对现有队伍进行全面培训，镇（街道）、村（社区）文化专兼职人员每年参加集中培训时间不少于5天。组建一支扎根基层、专兼职结合、综合素质较高的基层文化管理队伍，提升基层公共文化服务效能，充分发挥文化凝聚人心、增进认同、化解矛盾、促进和谐的作用，更好地满足群众多样化的基本公共服务需求。

四、实施步骤

（一）宣传启动阶段（2017年3月）

1．成立天宁区村（社区）综合性文化服务中心建设工作小组。

2．召开动员大会，全面部署工作任务。

（二）组织实施阶段（2017年4月至2019年11月）

1．确定全区2017-2019年村（社区）综合性文化服务中心逐年达标建设名单。

2．镇、各街道统一思想，协同推进，按照《常州市村（社区）综合性文化服务中心建设标准》要求制定改造升级计划，并组织实施。

3．明确村（社区）综合性文化服务中心服务的项目、数量、规模和质量要求，推动综合性文化服务中心宣传文化、党员教育、科学普及、普法教育、卫生计生、便民服务、体育健身等公共服务职能的有机结合，保证公共服务中心的规范有效运行。

（三）中期督查阶段（每年的9月）

1．组织相关部门对当年度村（社区）综合性文化服务中心建设工作情况的进行中期督查，指导推进综合性文化服务中心建设。

2．召开村（社区）综合性文化服务中心建设现场会，总结推广先进经验，以点带面，全面推进全区村（社区）综合性文化服务中心建设。

（四）总结验收阶段（每年的12月）

向上级部门报送当年度村（社区）综合性文化服务中心建设工作总结，接受上级部门对全区建设工作的检查验收。

五、保障措施

（一）加强组织领导

为确保村（社区）综合性文化服务中心建设工作的顺利开展，成立以分管区长为组长，区教育文体局局长为副组长，组织部、宣传部、农工办、发改、科技、民政、司法、财政、人社、建设、卫计、总工会、团委、妇联、残联、规划天宁分局等部门为成员单位的天宁区村（社区）综合性文化服务中心建设工作小组，逐步建立健全政府统一领导，相关部门大力支持、紧密联动的工作机制。镇、各街道成立相应工作小组，统筹负责所属村（社区）综合性文化服务中心建设的组织协调和推进工作。村委和居民委员会承担综合性文化服务中心使用和管理的主体责任。

（二）扎实推进实施

将基层综合性文化服务中心建设的目标任务列入全区年度为民办实事项目。利用区政府门户网站、媒体以及各类公共文化设施宣传橱窗、电子屏、展板等多渠道宣传行政村（社区）综合性文化服务中心建设工作。每年9月，召开全区行政村（社区）综合性文化服务中心建设现场会，总结推广先进经验，梳理解决相关问题，切实推进全区基层综合性文化服务中心建设。

（三）健全考评机制

把基层综合性文化服务中心建设纳入政府公共文化服务考核指标，制定比较完善的工作管理制度和考核评价体系。2017-2019年，每年年终，严格对标《常州市村（社区）综合性文化服务中心建设标准》，组织对村（社区）综合文化服务中心建设工作情况进行检查验收，发现先进典型、加强选树宣传，直面存在问题、提出工作建议。2019年底，实现全区村（社区）基层综合性文化服务中心全覆盖；2020年，迎接市级验收。

（四）强化投入支撑

村（社区）综合性文化服务中心建设所需资金纳入财政预算，切实予以保障。坚持政府主导、社会参与的原则，发挥政府投入的带动作用，落实对社会力量参与公共文化服务的各项优惠政策，鼓励和支持企事业单位、社会组织和其他社会力量通过直接投资、赞助捐助等方式，参与行政村（社区）综合性文化服务中心建设。

常州市村（社区）综合性文化服务中心建设标准

根据省政府办公厅《关于推进基层综合性文化服务中心建设的实施意见》，对照《江苏省行政村（社区）综合文化服务中心建设标准》，参照相关部门对基层组织建设的标准要求，特制定我市村（社区）综合性文化服务中心建设标准。

一、面积标准

村（社区）综合性文化服务中心建筑面积不得少于300平方米，室外建有1个以上文体广场，面积不得低于300平方米。综合性文化服务中心内部及周围环境整洁、卫生，场地硬化、绿化。辖市（区）统一“XX村（社区）综合性文化服务中心”标识，悬挂在醒目位置。

二、功能标准

1．一个宣传栏：位置可根据场地实际来安排，具备防风防雨雪等条件，实际使用面积不小于8平方米。

2．一站式服务大厅：设置群众专座和等候区域。有条件的村（社区）设电子触摸屏，为群众提供及时便捷的电子信息服务。

3．一间多功能室： 主要用于宣传文化、党员教育、社区教育、科技普及、普法教育等培训或村（社区）会议、小型演出等。配备相应数量的桌椅，有线电视、宽带、电脑、音响等远程教育设备接入齐全。

4．一个县（区）级图书馆分馆（或图书室）：面积不少于80平方米，拥有1200种1500册以上的图书，报刊不少于10种，年新增图书不少于80册；有1台专门用于图书借阅“通借通还”一卡通的电脑，有3台以上用于共享工程基层服务点数字化建设的电脑；有可供群众阅读的桌椅10张以上。

5．一个中老年文体活动室：主要用于琴棋书画、吹拉弹唱等乡土草根文化的创作、研讨与传承。

6．一个妇女儿童文体活动室：主要用于妇女儿童娱乐活动、文娱活动排练、乡土文化技艺传承等。

7．一个体育健身室：备有乒乓球台、健身器材等。

8．一个调解室兼法律服务工作室：设有调解必备的桌椅和村居法律顾问办公场所。

9．一个卫生室（计生服务室）：可以设置在综合性文化服务中心内，也可以在附近分设。

10．一个居家养老服务中心（站）：按照民政部门标准设置。

11．一个生活用品超市和农资超市（庄稼医院）：有条件的镇村设置，可以在综合性文化服务中心内，也可以在附近分设。

三、管理和服务标准

1．整合宣传文化、党员教育、科学普及、社区教育、农技推广、卫生计生、便民服务、体育健身等各类公共服务资源，制定比较完善的管理措施和各项规章制度，加强对设施的使用、维护管理，确保国有资产的安全、完整和有效使用。

2．设立公开宣传栏，分设党务、村务、财务、信息宣传等栏目，做到“村（社区）两委”三年任期目标和本年度为民办实事计划以及党务、村（社区）务、财务按规定公开，村（社区）级重大事项及时公开，定期开展图文形式的法制宣传教育。

3．设立不少于1个由政府财政购买的公益性文化岗位，有至少1名专（兼）职人员负责中心的日常管理。通过辖市（区）、镇（街道）两级统筹和购买服务等方式解决人员不足问题。鼓励大学生村官、志愿者等专兼职从事村（社区）综合性文化服务中心管理服务工作。加强业务培训，村（社区）文化专兼职人员每年参加集中培训时间不少于5天。

4．向群众免费开放，在醒目位置标明服务内容、开放时间和注意事项。实行错时开放，提高利用效率。

5．积极组织引导群众文体活动，为老年人、未成年人、残疾人、农民工和农村留守妇女儿童等群体提供有针对性的文化服务，推出一批特色服务项目。文体活动全年不少于6次；由妇女儿童参加的文化娱乐活动不少于4次；每个月为村民、居民放映一场国产新片（院线上映不超过2年）；建有2支以上业务文艺团队。

6．利用现代远程教育设备，对党员干部集中组织学习，每年都有对党员群众开展的集中科技培训。发布致富信息主动及时、社区继续教育富有成效。

2﹒指导推进农家书屋、社区书屋和数字公共文化等重点惠民项目建设。

3﹒协助整合基层公共资源，推动基层综合性文化服务中心和中小学文化资源共建共享。

4﹒推动标准化街镇社区教育中心建设。

5﹒指导推进公共体育设施向社会免费或低收费开放，参与基层综合性文化服务中心建设，实现共建共享。

6﹒协助整合基层公共文化资源。

二、区委组织部

指导基层综合性文化服务中心党员教育工作。

三、区委宣传部（区文明办）

1﹒指导有关基层公共文化建设重点任务的贯彻落实，协调推进基层综合性文化服务中心建设相关工作。

2．把基层综合性文化服务中心建设纳入文明城市、文明村镇创建基本指标，协调推进文化志愿者深入基层开展公共文化服务。

3﹒指导和协调基层公共文化资源整合。

4. 宣传基层综合性文化服务中心工作和取得的成果，扩大公共文化服务体系建设的社会影响，积极推动建设工作顺利进行。

四、区委农工办

将农村基层综合性文化服务中心纳入农村工作整体规划。

五、区发改局

指导督促镇、各街道加大基层重大公共文化设施建设项目统筹力度。

六、区科技局

1﹒推动基层综合性文化服务中心吸纳传播科技信息、科技知识。

2﹒协助整合基层公共文化科技资源，推动科普场馆逐步免费开展公共文化服务。

七、区民政局

1﹒指导和协调基层综合性文化服务中心与社区建设、社会组织管理、社区设施标准化建设等一体发展，推进城乡社区文化建设。

2﹒协助对基层综合性文化服务中心人员进行培训。

3﹒协助整合基层公共文化资源。

1﹒指导推进基层综合性文化服务中心普法教育工作。

2﹒指导和协调基层公共文化资源整合。

做好基层公共文化设施建设的有关经费保障工作，为基层综合性文化服务中心的建设和运行提供财力保障，对资金的使用做好监管。

十、区人社局

1﹒指导制定和完善推进基层综合性文化服务中心人才队伍建设相关政策措施。
