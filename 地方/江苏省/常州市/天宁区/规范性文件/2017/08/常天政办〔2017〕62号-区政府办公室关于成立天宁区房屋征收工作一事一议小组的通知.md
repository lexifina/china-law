# 区政府办公室关于成立天宁区房屋征收工作一事一议小组的通知

开发区管委会、镇政府、各街道办事处，区各办局、公司：

因房屋征收工作需要，根据国务院《国有土地上房屋征收与补偿条例》和省、市、区有关规定，经研究，决定成立天宁区房屋征收工作一事一议小组，组成人员名单如下：

组 长：季卫东 区委办公室副主任、区房屋征收与补偿办公室主任

成 员：蒋汉达 区检察院职务犯罪预防局局长

庄金涛 区房屋征收与补偿办公室征收管理科科长

小组下设办公室，办公室设在区房屋征收与补偿办公室，由周琳燕同志任办公室主任，庄金涛同志、李健同志、皇甫照楠同志为办公室工作人员。房屋征收工作一事一议小组成员具体职责包括：（1）对房屋征收工作中涉及非住宅征迁的重大疑难问题进行研究讨论，并提出相关处理意见；（2）对房屋征收项目中个案问题进行研究讨论，并明确相关处理意见；（3）受天宁区房屋征收项目论证评审小组委托，对符合特殊困难补助条件的被征收人的补偿标准进行讨论，并提出相关处理意见；（4）承办天宁区房屋征收项目论证评审小组交办的其他事项。

常州市天宁区人民政府办公室
