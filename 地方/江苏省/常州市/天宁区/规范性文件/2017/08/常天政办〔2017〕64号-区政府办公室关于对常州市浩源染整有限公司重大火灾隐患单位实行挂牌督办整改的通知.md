# 区政府办公室关于对常州市浩源染整有限公司重大火灾隐患单位实行挂牌督办整改的通知

雕庄街道办事处，区各有关单位：

为了加大对火灾隐患的检查督促整改力度，保障社会公共消防安全，区消防大队根据上级要求在全区范围内开展人员密集场所检查工作，发现常州市浩源染整有限公司存在以下重大火灾隐患：

厂区东北侧染色车间二楼设置员工宿舍，且该车间为丙类车间，不符合《住宿与生产经营合用场所消防安全技术要求》（GB703-2007）第4.1条的规定。

根据《常州市重大安全生产事故隐患单位挂牌督办暂行办法》，经区政府组织论证，决定对常州市浩源染整有限公司重大火灾隐患单位进行挂牌督办。

希望各单位要高度重视挂牌督办工作，属地街道要牵头落实整改措施，联合各有关部门，督促企业在8月20日前搬离现员工宿舍内居住人员。整改期满后，由市消防支队联合区消防大队组织验收，并将验收结果报区政府。对完成整改、消除安全隐患的，摘除“重大火灾隐患单位”警示牌；对因工作不到位、逾期未完成整改工作的，依法进行处罚；对因工作不到位、措施不落实而导致发生重大火灾事故的，依法严肃追究相关责任人的责任。

常州市天宁区人民政府办公室

2017年8月2日
