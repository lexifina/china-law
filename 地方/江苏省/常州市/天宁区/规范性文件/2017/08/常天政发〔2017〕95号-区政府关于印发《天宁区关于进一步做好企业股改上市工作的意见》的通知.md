# 区政府关于印发《天宁区关于进一步做好企业股改上市工作的意见》的通知

开发区管委会、镇政府、各街道办事处，区各办局、公司：

《天宁区关于进一步做好企业股改上市工作的意见》已经区政府研究同意，现印发给你们，请认真贯彻执行。

常州市天宁区人民政府

2017年8月17日

（此件公开发布）

天宁区关于进一步做好企业股改上市

工作的意见

为抢抓多层次资本市场体系建设机遇，推动我区企业加快股改上市步伐，鼓励和引导企业通过资本市场优化资源配置、加快制度创新、促进转型发展，推动一批主业突出、成长性强、发展潜力大的企业做大做强，结合我区实际，特制定本意见。

一、总体要求

充分利用当前资本市场改革发展的有利时机，积极引导和推动企业股份制改造，按照政策推动、企业主动、部门联动、机构互动的工作思路，健全企业股改上市工作机制，完善政策服务体系。支持上市（挂牌）企业开展直接融资和并购重组，促进资源优化整合与产业转型升级，丰富融资形式，推动全区经济健康快速可持续发展。

二、发展目标

积极实施上市企业培育行动，鼓励有条件的企业加快建立现代化管理制度，实施股份制改革，加快推进一批符合国家产业政策、主业突出、成长性好、带动力强的企业对接资本市场，大力推动上市（挂牌）企业开展并购重组与再融资。

到2019年末，全区培育主板（含中小板）、创业板及境外上市企业9家，新三板挂牌企业21家，推动39家企业完成股改，在企业转板升级方面取得突破，形成主板（含中小板）、创业板、新三板及其他场外市场多渠道并举的格局，为全区经济的持续快速发展提供坚强有力的支撑。

其中：2017年，推动亚东科技联交所上市，培育“新三板”挂牌企业6家，12家企业完成股改；2018年，推动千家万铺等主板上市，培育新三板挂牌企业7家，13家企业完成股改，力争科威环保、恒丰特导率先实现转板升级；2019年，推动艾贝服饰、仁千电气等主板上市，培育新三板挂牌企业8家，14家企业完成股改（详见附件1-4）。

三、政策措施

（一）市级扶持政策

根据《常州市加快企业股改上市十六条》（常政发﹝2017﹞107号）文件精神，股改上市企业享受以下政策：

1.企业改制设立股份有限公司，同一控制下进行合并、分立、股权转让等重组，涉及土地、房产等资产变更、过户所缴纳的流转税、契税、土地增值税对地方贡献部分，由市、区财政分别给予企业奖励。

2.企业改制设立股份有限公司，企业审计或评估中出现的净资产增值所缴纳的企业所得税对地方贡献部分，由市、区财政分别给予企业奖励，用于企业技术改造和产品研发。

3.企业改制设立股份有限公司，将未分配利润、资本公积、盈余公积等转化为股份所缴纳的个人所得税对地方贡献部分，由市、区财政分别给予纳税人奖励。

4.企业改制设立股份有限公司过程中，凡涉及无证土地、房产的权证办理及转换土地、房产权属性质的，由各相关部门按照“尊重历史、依法合规”原则，指导和帮助企业完善相关产权确认程序和变更登记手续，并办理相关权证。

5.企业改制设立股份有限公司过程中，所涉及的国土、房管、税务、商标、专利、商检、金融、社保、科技、文化、建设、规划、公安、环境保护、安全生产、食药监管、质量监督、交通运输、卫生监督等方面的资质或行政许可事项，由市金融办会同各有关部门建立“绿色通道”，帮助完善相关手续；对涉及证照办理的，市权范围内只收取工本费。

6．与保荐机构签订上市保荐协议、进入上市实质性运作程序的企业，经市上市工作领导小组审核确认后，自签订协议年度起三年内，当年比上年度所缴纳的企业所得税对地方新增贡献部分，由市、区财政分别给予企业奖励（企业上市当年不再享受）。

7．成功上市首发的企业，予以一次性100万元奖励。

8．已上市企业通过增发、配股等方式成功实现再融资，且募集资金75%以上（含）投入本地项目建设或并购产业链上下游企业的，按照募集资金额予以奖励：筹资1亿元以内的奖励50万元，筹资1亿元以上（含）的奖励100万元。

9.企业通过资产重组等方式“借壳”上市并取得上市公司控制权的，将注册地迁入本市并承诺三年内不变的，予以一次性100万元奖励。

10．新三板挂牌企业通过定向增发等方式实施直接融资，且募集资金75%以上（含）投入本地项目建设的，按实际到位资金5‰的比例予以奖励，最高不超过50万元。

（二）区级奖励政策

根据《天宁区关于促进企业加快利用资本市场实现转型发展的意见》（常天政办﹝2017﹞4号）文件精神，股改上市企业享受以下政策：

1.企业在实施新三板挂牌、境内外上市等资本运作过程中，完成股份制改造并经工商部门登记的，由天宁区财政奖励企业100万元。

2.企业成功在新三板挂牌的，向股转公司提交挂牌申请材料并取得受理通知书后，由天宁区财政奖励企业50万元。企业通过资产重组等方式取得新三板挂牌公司控制权并将该企业迁至天宁区的，由天宁区财政奖励企业50万元。

3.企业在主板上市的，向中国证监会报送上市申报材料并取得受理通知书后，由天宁区财政奖励企业50万元；成功首发上市后，由天宁区财政奖励企业50万元。企业成功在境外上市的，由天宁区财政奖励企业100万元。企业在新三板挂牌后转至主板成功上市的（含境外上市），由天宁区财政奖励企业100万元。企业通过资产重组等方式“借壳”上市并取得上市公司控制权，且将上市公司总部迁至天宁区的，由天宁区财政奖励企业100万元。

四、工作举措

（一）强化组织领导，建立联动机制

切实发挥区股改上市工作领导小组职能，深化协调联动，建立区股改上市工作联席会议制度。联席会议由区股改上市工作领导小组办公室（以下简称“区上市办”）召集，原则上每季度召开一次，确有特殊情况可临时召开会议（详见附件4）。开发区、镇、街道要及时梳理企业在股改上市过程中遇到的各类问题，区上市办按问题事项进行分类，初步拟定问题责任部门后进行分配，相关职能部门按照时限要求进行处置并答复。对暂时无法解决的难题，提交区股改上市工作联席会议讨论处置（详见附件5）。

（二）强化企业储备，实现梯队发展

持续选择符合国家产业政策、质地优良、成长性好的新兴企业，及时补充上市后备库，按照“上市一批、辅导一批、培育一批、储备一批”的工作思路，分类引导、精心培育。开展地毯式走访，“一对一”宣传到位。开展系列活动、主题培训，丰富企业家眼界，充分调动企业股改上市积极性。打造板块、行业股改上市典型标兵，通过处理共性历史遗留难题，提振企业股改上市信心。

（三）强化督导考核，落实工作责任

做好上市工作，关键要在细化任务、明确责任上狠下功夫。结合市政府股改上市考核意见，明确考核办法，切实把企业上市的任务纳入责任目标中，明确工作标准，严格落实责任，做到工作量化到位、任务分解到位、责任落实到位，务求有责任、有进度、见实效。
