# 区政府办公室关于印发《天宁区“50个工作日内完成工业建设项目施许可证领取”流程优化方案》的通知

开发区管委会、镇政府、各街道办事处，区各办局、公司：

经区政府研究同意，现将《天宁区“50个工作日内完成工业建设项目施工许可证领取”流程优化方案》印发给你们，请结合实际，认真贯彻执行。

常州市天宁区人民政府办公室

2017年9月5日

（此件公开发布）

为深化建设项目审批制度改革，促进职能转变，效能提升，推动投资项目加快落地，进一步激发市场活力，争创发展新优势，按照《市政府办公室关于印发〈“50个工作日内完成工业建设项目施工许可证领取”流程优化方案〉的通知》（常政办发〔2017〕124号）要求，制定本方案。

一、工作目标

紧紧围绕“工业建设项目从立项到取得施工许可证50个工作日内完成”的要求，进一步深化建设项目代办（帮办）工作机制，重构工业建设项目审批流程，按照“一窗受理、提前服务，分段并联、限时办结”的工作方式，形成工业建设项目审批“路径最优、材料最简、时间最短”的新模式，有效降低企业制度性交易成本。

二、实施范围

（一）辖区内所有工业建设项目审批工作均适用本方案。

（二）工业建设项目审批分为“前期指导、多评合一、规划审批、联合审图、施工许可”五个阶段，由于“联合审图”和“施工许可”两个市级审批权限暂未下放，前三个阶段由区级审批部门负责，后两个阶段与市级审批部门做好衔接协调。

（三）本意见适用于办理事项的通常状态，包括工业建设改扩建项目，情况特别复杂的除外。

三、工作内容

（一）建立区“工业50”项目调处机制。由区政务办牵头，组织区发改局、建设局、环保局、民防局、消防大队、国土分局、规划分局等涉建部门，成立项目服务协调小组，建立联席会议制度，保障项目审批有序推进。

（二）设置“工业50”专窗。在区政务服务中心预受理窗口设置运行操作“工业建设项目施工许可证50个工作日完成”的服务专窗，统称“工业50专窗”，统筹区内所有工业建设项目审批服务工作。

（三）建立属地“代办”、部门“帮办”机制。镇、各街道整合相关资源，成立工业建设项目代办机构，培育代办员；区涉建部门建立“帮办”机制，明确帮办员队伍。属地代办机构（代办员）负责提供全流程审批事项的代办服务；区涉建部门（帮办员）针对审批流程中涉及部分市级权限的事项，为基层代办员提供帮办服务。

（四）制定项目审批标准。依法律法规，结合工业企业建设项目具体特点，制定各审批环节的条件、材料、程序标准，统一审批要求。

（五）优化审批服务流程。在不违反法律法规的前提下，整合各审批部门的环节，设计最优审批路径，形成固定的审批流程和联办模式。

四、工作流程

工业建设项目审批服务由项目属地的镇、街道基层代办人员（以下简称“基层代办员”）负责全程代办，工业50专窗工作人员负责责任阶段内的组织、协调和管理，区审批部门依职能做好相关工作，具体流程如下：

（一）技术性预审阶段

在工业项目土地招拍挂前期工作期间，由基层代办员全程配合项目意向单位（以下简称企业）开展相关工作。

1．在与企业签订招商协议后，基层代办员帮助企业向工业50专窗提出前期预审申请。（报送“规划条件”“招商协议”和“预审申请”）

（1）工业50专窗收到项目“预审申请”一日内，告知国土、规划分局相关信息。国土分局指导代办员帮助企业继续“土地招拍挂”进程；规划分局指导代办员帮助企业编制建设项目规划设计方案和绿化设计方案，基层代办员配合企业委托有相应资质的设计单位完成设计方案编制（20日内）；工业50专窗实时了解取得土地进展情况，把控各审批部门提前预审的时序要求。

（2）规划设计方案完成后，向工业50专窗递交。窗口接收后组织发改、建设、环保、民防、消防、规划等审批部门联合指导方案修改完善。基层代办员配合企业修改完善设计方案。

（3）设计方案审查通过后，区发改局出具立项预审意见（3日）、环保局出具环保审批预审意见（3日）、规划分局出具规划设计方案预审意见（5日）、建设局出具绿化方案预审意见（5日）、民防局出具人防审批预审意见（3日）、消防大队出具消防审批预审意见（3日），并指导下一步审批要求。

如有项目部分审批内容涉及市级权限，区级条线部门帮助代办员与市级条线沟通协调后，出具预审意见。

规划分局出具规划设计方案预审意见时，指导企业开展施工图设计工作。

2．基层代办员配合企业根据预审通过的规划设计方案，委托环评、能评等中介机构开展相关技术报告编制工作（30日内）。

（1）技术报告编制工作完成后，基层代办员配合企业将相关技术报告一同提交工业50专窗。窗口协商发改局、环保局明确相关评审事宜，评审工作由发改局、环保局各自负责展开，基层代办员配合企业根据评审意见修改完善。

（2）评审通过后，发改局出具能评预审意见、环保局出具环评预审意见（5日）。

3．基层代办员配合企业在规划设计方案预审阶段，可提前完成地质勘探，同步完善施工图设计，规划设计方案和施工图设计可按需结合，适时同步开展。在规划设计方案预审通过后，将施工图分别提交区工业50专窗和市联合审图中心。规划分局、市联合审图中心同步开展审图工作，并出具初审意见。基层代办员配合企业根据审查意见进行修改完善（15日）。

审图通过后，规划分局出具施工图预审意见、市建设局审图中心出具施工图预审技术审查通过单(2日)。

（二）行政性审批阶段

1．区级审批权限内容

（1）企业通过招拍挂获取土地且涉建部门技术性预审通过后，基层代办员配合企业准备发改局的正式立项、能评，规划设计方案审查等审批事项的申请材料，并一同提交工业50专窗。窗口按照容缺受理的原则一次接收材料，一日内转发发改局、规划分局同步开展审批，所容缺材料由窗口统筹部门相互补齐（并联审批：立项7日、能评10日、规划设计方案审查5日内）。

（2）发改局立项手续完成后，工业50专窗通知代办员帮助企业提交环评报告、绿化设计方案审查、用地规划许可证审批、人防设施审批等材料。窗口按照容缺受理原则接收材料后分发各审批部门同步审批，所容缺材料由窗口统筹部门相互补齐。（并联审批：环保18日、其他部门 5日）

（3）市规划审批窗口出具建设用地规划许可证后，工业50专窗通知代办员帮助企业提交建设工程规划许可证、规划施工图审查所需材料及规划施工图预审意见，转规划分局审批（5日）。

2．市级审批权限内容

（1）市规划审批窗口出具建设工程规划许可证后，工业50专窗通知代办员帮助企业向市联合审图中心提交施工图审查所需材料。市联合审图中心进行施工图审查（7日）。

（2）取得施工图设计文件审查合格书后，基层代办员配合企业按照市城乡建设局的要求实行施工合同、监理合同、质量监督、安全监督网上备案和施工许可证办理（8日）。由区建设局协调市城乡建设局提供过程指导和工作帮助。

3．办理相关缴费手续。区级层面由规划分局负责牵头流转缴费手续，市级层面由代办员帮助企业办理相关缴费手续。

以上流程适用于未取得土地的工业新建项目和改扩建项目。存量土地改扩建项目也可提出“预审申请”，由项目服务协调小组分析项目具体情况后，采取选择性“技术预审”与“行政审批”交错或并联的推进方式，最大限度缩短审批周期。

五、工作要求

（一）统一思想认识。镇、街道、涉建部门要高度重视工业建设项目审批改革工作，围绕提升审批效率服务项目、服务发展的共同目标，协同推动“工业建设项目施工许可证50个工作日完成”工作取得实效。区政务办要在工业50专窗配置2至3名业务熟、能力强、年纪轻的专职人员，确保窗口能发挥牵头、组织、协调作用。

（二）突出机制创新。镇、街道、涉建部门要把机制创新作为推动工业建设项目审批改革的重要抓手，创新服务方式，实行“容缺受理”，推动“不见面”审批，切实提升工业建设项目审批效率。

（三）推行全程代办。要进一步加强镇、街道代办和涉建部门帮办服务体系建设。代办队伍要实施全程代办，保姆式服务，解决好企业因信息不对称造成的办事难、效率低的问题，助力工业建设项目审批改革顺利开展。

（四）加强考核评价。细化“工业建设项目施工许可证50个工作日完成”的改革考核指标，建立完善考评要求和规则，跟踪工业建设项目审批情况，科学分析评价辖区内建设项目的工作情况，以考评考核促进审批效能进一步的提升。
