# 区政府办公室关于对南京银城物业服务有限公司晋陵北路分公司（高成天鹅湖小区）实行重大火灾隐患单位挂牌督办的通知

茶山街道办事处，区各有关单位：

为加大火灾隐患督促整改力度，保障公共消防安全，区消防大队在全区范围内开展“夏季消防安全大检查”专项行动，发现南京银城物业服务有限公司晋陵北路分公司（高成天鹅湖小区）存在以下重大火灾隐患：

1. 小区火灾自动报警系统，不能正常使用。

2. 小区消防管网漏水，室内消火栓系统不能正常使用。

3. 小区消防管网漏水，自动喷淋系统不能正常使用。

4. 小区消防联动控制系统无法正常工作。

上述4项隐患违反了《中华人民共和国消防法》第十六条第一款第二项、第二十一条第二款的规定。根据《常州市重大安全生产事故隐患单位挂牌督办暂行办法》，经区政府组织论证，决定对南京银城物业服务有限公司晋陵北路分公司（高成天鹅湖小区）实行重大火灾隐患挂牌督办。

希望各单位要高度重视挂牌督办工作，属地街道要牵头落实整改措施，联合各有关部门，督促企业在2018年12月31日前完成整改，确保小区消火栓和自动喷淋供水正常，消防联动系统使用正常。整改期满后，由市消防支队联合区消防大队组织验收，并将验收结果报区政府。对完成整改、消除安全隐患的，摘除“重大火灾隐患单位”警示牌；对因工作不到位、逾期未完成整改工作的，依法进行处罚；对因工作不到位、措施不落实而导致发生重大火灾事故的，依法严肃追究相关责任人的责任。

常州市天宁区人民政府办公室

2018年6月25日
