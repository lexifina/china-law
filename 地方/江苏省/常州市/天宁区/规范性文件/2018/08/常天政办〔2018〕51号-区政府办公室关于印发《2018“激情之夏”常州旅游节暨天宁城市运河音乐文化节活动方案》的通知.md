# 区政府办公室关于印发《2018“激情之夏”常州旅游节暨天宁城市运河音乐文化节活动方案》的通知

天宁街道办事处，区各相关单位：

经区政府研究同意，现将《2018“激情之夏”常州旅游节暨天宁城市运河音乐文化节活动方案》印发给你们，请认真贯彻执行。

常州市天宁区人民政府办公室

2018年8月20日

（此件公开发布）

为贯彻落实《市政府办公室关于印发<2018“激情之夏”常州旅游节活动方案>的通知》（常政办发〔2018〕89号）文件精神，，进一步提升天宁旅游在全国的知名度，扩大天宁旅游的影响力，同时结合天宁大运河文化带建设和天宁区创建“国家全域旅游示范区”等重要工作，让广大市民和游客享受天宁旅游的发展成果，彰显天宁“六个最”，促进天宁城市旅游健康和谐发展，现制定2018“激情之夏”常州旅游节暨天宁城市运河音乐文化节活动方案。

一、活动时间

2018年8月31日-9月22日

二、主办单位

常州市天宁区人民政府

三、组织机构

成立2018“激情之夏”常州旅游节暨天宁城市运河音乐文化节活动组委会，负责整个活动的组织协调工作。组委会名单如下：

四、活动内容

（一）2018“激情之夏”常州旅游节暨天宁城市运河音乐文化节开幕式

活动时间：2018年8月31日（星期五）18：00-21：45

活动地点：红梅公园文笔塔广场

主要活动：1.开幕式

2. 音乐文化（国际）艺术等表演

3. 有奖知识竞答

（二）2018常州“文笔诗词吟诵”大会

活动时间：2018年9月7日（星期五）18：30-21：00

活动地点：红梅公园文笔塔北侧小广场

主要活动：1.诗词吟诵

2. 现场书画展示

3. 评弹表演

4. 汉服舞蹈表演

（三）2018“多彩天宁 助你荧”第二届荧光夜跑活动

活动时间：2018年9月15日（星期六）18:30-20:30

活动地点：红梅公园

主要活动：健步走或慢跑6公里

（四）东坡文创市集暨东坡文创联盟成立仪式

活动时间：2018年9月22日（星期六）14：00-20：00

活动地点：天宁商都街区

主要活动：东坡文创联盟成立大会、天宁旅游文化产品展示

五、责任分工

1.天宁街道：现场秩序、安保工作、开幕式观众组织。

2.区委宣传部：活动宣传报道。

3.区旅游办：活动策划、方案制定、衔接协调、经费协调。

4.区教育文体局：非遗展示和相关表演。

5.区财政局：活动经费保障。

6.区城管局：制定停车方案，负责沿线周边环境及卫生、安全保护。

7.区环卫处：负责现场安排垃圾桶及每日垃圾清运。

8.区卫生和计划生育局：现场医疗急救医生和药品的提供。

9.区市场监督管理局：制定食品安全预案，负责全场食品安全管理。

10.区公安分局水门桥派出所：制定治安、反恐保障预案，负责活动期间现场治安管理。

11. 天宁交警大队：制定交通疏导预案，维护现场交通秩序;指挥领导、观众、演员车辆停放。

12.天宁消防大队：制定消防安全预案，负责活动期间消防安全。

13.常州市天宁城市建设开发有限公司：负责提供场地、活动组织、实施和各类协调等工作。

14.红梅公园：负责提供场地、现场安保和卫生工作。

六、工作要求

活动开展期间，组委会成员单位牢记分工、恪守职责，积极完善活动组织，协调各项工作，切实履行现场安全维护相关责任，确保2018“激情之夏”常州旅游节暨天宁城市运河音乐文化节活动圆满成功。
