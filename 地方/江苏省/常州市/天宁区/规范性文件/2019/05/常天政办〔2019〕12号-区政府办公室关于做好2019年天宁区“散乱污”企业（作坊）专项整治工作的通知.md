# 区政府办公室关于做好2019年天宁区“散乱污”企业（作坊）专项整治工作的通知

开发区管委会、镇政府、各街道办事处、东青办，区各有关部门：

为切实贯彻落实中央环保督察“回头看”、省级环保督察、省委巡视反馈意见整改工作要求，根据《区政府关于印发〈天宁区开展“散乱污”企业（作坊）专项整治工作方案〉的通知》（常天政发〔2018〕58号）、《区政府关于印发〈天宁区2019年打好污染防治攻坚战工作方案〉的通知》（常天政发〔2019〕30号），现就做好2019年天宁区“散乱污”企业（作坊）专项整治工作通知如下：

一、整治目标

积极践行习近平生态文明思想，加快推动绿色发展转型升级，以改善环境质量为核心，坚持标本兼治、防治并举，持续深入开展“散乱污”企业（作坊）专项整治行动，切实巩固整治成果，建立健全长效管理机制。

二、整治范围

按照常天政发〔2018〕58号文件规定，对相关行业（包括但不限于）的“散乱污”企业（作坊）开展进一步排查整治，落实依法取缔一批、整合搬迁一批、改造提升一批的整治要求。

三、时间安排

（一）摸底排查（5月—6月）

开发区、郑陆镇、各街道、东青办开展全面宣传发动，在前期排查整治基础上，组织对辖区内“散乱污”企业（作坊）开展补充调查，填写分类整治清单（附件1），制定整治计划，于6月30日前报区打好污染防治攻坚战指挥部办公室备案。

（二）全面整治（7月—10月）

开发区、郑陆镇、各街道、东青办以及区各相关部门按照职责分工，积极推进整治工作，确保6月30日前全面完成2018年整治清单规定的整治任务（未完成整治名单见附件2），10月31日前基本完成补充清单各项整治任务。

（三）考核验收（11月—12月）

年底前，开发区、郑陆镇、各街道、东青办严格对照“散乱污”企业（作坊）的认定标准、整治要求对本辖区整治工作进行自查自评。对完成整治的企业（作坊），按程序审核后，纳入日常监管；对逾期未完成治理改造任务或改造后仍达不到规定整治要求的，坚决依法关停。区打好污染防治攻坚战指挥部办公室会同区相关单位对各板块整治工作完成情况进行抽查评估、考核验收。

四、工作要求

1. 强化责任落实。开发区、郑陆镇、各街道、东青办切实履行整治属地主体责任，进一步加强“散乱污”企业（作坊）专项整治工作组织领导，健全工作机制；及时上报整治过程中的突出难点问题，积极寻求解决方法。各职能部门按照职责分工，加强督查指导，确保整治标准落实到位；强化联动执法，为专项整治提供坚实的法律保障。

2. 加强宣传曝光。开发区、郑陆镇、各街道、东青办应在辖区内向社会发布“散乱污”企业（作坊）专项整治工作方案，通过张贴通告、标语等形式广泛深入地宣传整治要求；充分利用广播、电视、报纸、网络等媒体，持续加大宣传引导力度，及时公开整治工作进展，形成严厉打击“散乱污”企业（作坊）的舆论氛围。

3. 突出重点攻坚。各单位对中央环保督察“回头看”、省级环保督察反馈意见及交办信访件中涉及的“散乱污”问题进行重点推进，对整改方案进行科学论证，按时序进度推进落实方案规定的各项整改措施，确保问题及时整改、及时销号。

4. 健全长效管理。严格网格化管理，建立专门工作制度，严格厂房出租管理，严禁已关闭的“散乱污”企业（作坊）死灰复燃，防止新增“散乱污”企业（作坊）；一旦出现，立即取缔。

5. 严格督查考核。区打好污染防治攻坚战指挥部办公室会同区相关部门加大对“散乱污”企业（作坊）专项整治的督查考核力度，对整治工作中弄虚作假、瞒报漏报、推进不力或监管责任不落实以及逾期未完成整治任务的单位和责任人，依法依规严肃追责。

6. 落实信息报送。请各单位迅速组织实施“散乱污”企业（作坊）专项整治。6月25日前，开发区、郑陆镇、各街道、东青办确定2019年分类整治清单，并上报区打好污染防治攻坚战指挥部办公室。7月份起，开发区、郑陆镇、各街道、东青办每月25日前报送工作进展及整治情况。
