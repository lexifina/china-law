# 区政府关于杨旭同志工作分工的通知

开发区管委会、镇政府、各街道办事处、东青办，区各办局、公司：

经常州市天宁区第十六届人民代表大会常务委员会第十七次会议任命，杨旭同志担任区政府副区长。

经研究，杨旭协助周登蓉同志分管科技、工业和信息化、市场监督管理方面工作。履行分管范围内安全生产工作职责。

协管科学技术局、工业和信息化局、市场监督管理局。

常州市天宁区人民政府

2019年6月28日
