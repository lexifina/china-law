# 区政府办公室关于印发《2019年天宁区停车建设和管理工作实施意见》的通知

开发区管委会、镇政府、各街道办事处、东青办、区各办局、公司：

《2019年天宁区停车建设和管理工作实施意见》已经区政府同意，现印发给你们，请认真贯彻执行。

常州市天宁区人民政府办公室

2019年8月9日

（此件公开发布）

2019年天宁区停车建设和管理工作实施意见

为全面贯彻公安部、中央文明办、住房和城乡建设部、交通运输部联合印发的《城市道路交通文明畅通提升行动计划（2017—2020）》（公通字〔2017〕16号）和省住建厅、发改委、公安厅、交通厅、物价局、民防局联合印发的《关于推进实施“停车便利化工程”的意见》（苏建城〔2018〕151号），深入落实《常州市城市交通畅行工程三年行动计划（2018—2020年）》《常州市停车建设和管理工作三年行动计划（2018—2020年）》《常州市停车专项规划（2018—2035）》，市政府办公室关于印发《2019年常州市市区停车场建设和管理工作实施意见》的通知（常政办〔2019〕74号）深入推进实施“停车便利化工程”，进一步强化工作指导与监督，制定本实施意见。

一、指导思想

坚持以习近平新时代中国特色社会主义思想和党的十九大精神为指引，牢固树立以人民为中心的发展思想，围绕推进城市精细化管理，按照统筹协调、综合治理、系统推进的要求，从供需两端发力，合理引导停车需求，因地制宜、多措并举，切实解决市民停车不便的问题，努力探索建立适应城市发展规律的停车供应服务管理体系，进一步提升人民群众的获得感、满意度。

二、工作内容

1．成立天宁区停车建设和管理工作的专门机构，全面负责全区停车规划、建设、管理和相关组织协调工作。

2．推动停车设施有序增长，推进新建、改扩建学校建设停车场和接送中心；试点建设“空间集约、性价比高、推广性强”的停车设施；增加重点区域公共停车泊位供应，持续推进机关和企事业单位停车设施、人防设施开放共享，挖潜老旧小区内部停车资源。

3．按市统一部署做大做强市智慧停车管理平台，完成车位预约和停车场共享开放试点建设，完成中心区域路内停车泊位设置、智能化改造和管理；积极推动“常州停车”APP纳入“我的常州”智慧平台。

4．开展临街建筑退红线区域停车综合整治，加强对非机动车停车秩序的管理。

5．加强对停车建设和管理工作的评价，强化对开发区、各街道和区有关单位的督促指导；建立健全停车场备案管理和年审考核机制。

6．加强公众参与度，多形式、多渠道积极宣传停车建设和管理相关工作。

三、目标任务

（一）开发区、各街道办事处

开发区和各街道办事处按照评价细则（详见附件1），负责做好属地停车建设和管理工作。年内实现全区新增3400个停车泊位。

（二）区各有关单位

按《常州市停车建设和管理工作三年行动计划（2018-2020年）》（常停联〔2018〕1号）明确的责任分工，区各有关单位按各自职责重点开展以下工作：

1．加快公共停车场建设

（1）推进学校停车场和接送中心建设，城区范围内的新建、改扩建学校要按照需求科学配置地下停车场和接送中心，进一步缓解学校周边道路交通压力（区教育局牵头，开发区和各街道办事处，区发改局、公安天宁分局、自然资源天宁分局、区住建局配合）。

（2）制定关于机关、企事业单位等内部停车泊位对外开放政策，推动停车共享，提高现有停车位使用效率，年内至少推动5个停车场对外开放共享（区住建局牵头，开发区和各街道办事处，区发改局、公安天宁分局、自然资源天宁分局配合）。

2．推进停车综合整治

（1）加强临街建筑退红线区域停车管理。按照《常州市城市道路管理实施办法》的有关要求，认真落实新建项目退红线区域内的停车设施设置和建设审批工作，要求退红线区域内的停车泊位实施智能化建设，统一接入市智慧停车管理平台进行智能化管理（区住建局牵头，开发区和各街道办事处，公安天宁局、自然资源天宁分局、区城管局配合）。

（2）加强路内停车管理。按照路内停车管理的要求，完成中心区域路内停车泊位的统一施划、编号、安装地磁，并统一接入市智慧停车管理平台实施智能化管理。加强路内停车秩序整治，强化违停贴单、监控抓拍、记分处罚，对违停车辆实行强制拖移，对不规范停放等行为进行查处。（公安天宁分局牵头，开发区和各街道办事处，自然资源天宁分局、区住建局配合）

3．实施智慧停车管理

（1）年内确保完成8000个公共停车泊位接入市智慧停车管理平台目标。加快推进路内停车泊位、道板停车泊位的智能化改造，年内完成中心区域的路内停车泊位、部分道板停车泊位及对外开放停车场接入市智慧停车管理平台。（区住建局牵头、开发区和各街道办事处、市城建集团配合）

（2）根据《常州市非机动车停放管理办法》，明确非机动车停放管理标准和要求，统一施划城区道路两侧非机动车停车区域，完善城区公共自行车的布点设置和管理。加强对城区道路两侧非机动车停车秩序的管理和执法。（区城管局牵头，开发区和各街道办事处配合）

四、工作保障

（一）加强组织保障

1．抓好顶层设计，建立评价机制。由区停车建设和管理工作联席会议办公室负责组建评价工作小组，落实对开发区和各街道办事处的工作评价，依照《江苏省“停车便利化工程”实施工作考核评价办法（试行）》，结合我区停车建设和管理工作实际，按照年度工作要求，制定每年度工作目标任务。

2. 明确目标责任，推动项目管理。开发区和各街道办事处、各有关单位要对照确定的工作内容和目标任务，积极推动项目化管理，制定项目化实施方案，将工作目标细化分解，责任到人，形成横向到边、纵向到底的项目责任管理体系。同时，开发区和各街道办事处要加强对本地区工作的统筹实施，按要求制定本地区停车建设和管理工作目标任务并上报区停车建设和管理工作联席会议办公室。

3．建立联动机制，形成工作合力。区停车建设和管理工作联席会议办公室与开发区和各街道办事处、各有关单位应建立部门联动的工作机制，协调统筹停车建设和管理工作，建立健全年度、季度、月度停车例会制度，区各有关单位、开发区和各街办事处要及时通报工作进展情况，研究解决工作中存在的问题，指导、帮助基层单位开展停车建设和管理工作，增强工作合力与推进力。

（二）加强监督评价

1．建立常态化监督工作机制。评价工作小组开展经常性检查，督促工作加快推进；区停车建设和管理工作联席会议办公室通过例会、工作简报、工作会议等形式，对领导重视、行动有力、成效明显的单位予以表扬，对重视不够、措施不力、进展缓慢的单位予以通报批评。

2．制定科学可行的评价措施。评价工作小组于年底通过现场督查、查阅台账、实地抽查等方式，对开发区和各街道办事处开展的年度停车建设和管理工作实施评价，并适时将评价结果纳入城市长效综合管理考核。

3．积极推动第三方满意度调查。年底，市、区停车建设和管理工作联席会议办公室委托第三方开展停车建设和管理工作年度公众满意度调查，调查结果纳入评价内容。

（三）加强宣传引导

1．加大舆论引导力度。总结典型经验和先进做法，通过多种媒体、多种渠道、多种形式，广泛宣传停车建设和管理工作成效，积极营造良好的舆论氛围。

2．扩大公众参与度。注重群众满意度和获得感，积极创造条件和机会，邀请市民群众参与停车建设和管理，出谋划策，提出意见建议。主动接受人大代表、政协委员及群众的监督，真正将实事办好、好事办实。
