# 区政府关于调整区政府领导同志工作分工的通知

开发区管委会、镇政府、各街道办事处、东青办，区各办局、公司：

根据工作需要，并报市委、区委同意，区政府领导同志分工作如下调整：

许小波同志主持区政府全面工作，兼管财政、审计、人民武装、外事方面工作。

分管区政府办公室（大数据管理局）、财政局、审计局、外事办。

郑亚同志负责区政府常务工作，负责发展改革、服务业、价格、重点项目建设、人力资源和社会保障、应急管理、政务服务管理、国有资产、集体资产、统计、政务公开、粮食和物资储备、对口支援、经济协作方面工作，联系气象方面工作。履行分管范围内安全生产工作职责。

分管发展和改革局、人力资源和社会保障局、应急管理局、行政审批局（政务管理服务办公室）、统计局、国资办、江苏常州人力资源服务产业园管委会、常州天宁建设发展集团有限公司。

周登蓉同志负责科技、科技园区建设、工业和信息化、市场监督管理、金融、常州金融商务区建设、高新技术创业服务方面工作，协管商务、楼宇经济、外事、招商中心工作，联系意识形态、统一战线、工商联、税务、通讯、供电、口岸方面工作。履行分管范围内安全生产工作职责。

分管科学技术局、工业和信息化局、市场监督管理局（知识产权局）、地方金融监督管理局（区政府金融工作办公室）、常州市天宁高新技术创业服务中心，协管商务局。

联系民族宗教事务局、侨办、台办、科协、工商联和天宁税务局、相关金融机构。

陈旭光同志负责公安、司法、信访、国家安全方面工作。履行分管范围内安全生产工作职责。

主持公安天宁分局工作，分管司法局、信访局。

联系天宁交警大队。

管黎芳同志负责教育、民政、社区建设、卫生健康、退役军人事务、双拥、文化、体育、旅游、文物、机关后勤管理服务、电子政务、妇女儿童、残疾人、红十字会、建议提案办理、老年大学和江苏常州健康养老服务业集聚区建设方面工作，协管办公室、车改房改工作，联系人民武装、医疗保障、广播电视方面工作。履行分管范围内安全生产工作职责。

分管教育局、民政局、卫生健康局、退役军人事务局、文化体育和旅游局、区级机关后勤管理服务中心、电子政务中心。

联系地方志办、总工会、团区委、妇联、残联、红十字会、驻区部队。

方力同志负责焦溪古镇申遗方面工作。履行分管范围内安全生产工作职责。

分管江苏舜宁投资建设有限公司。

岳军同志负责住房和城乡建设、城市管理、农业农村、水利、扶贫、人防、自然资源、生态环境、房屋征收与补偿方面工作，联系交通运输、铁路、林业、水文、不动产登记交易方面工作。履行分管范围内安全生产工作职责。

分管住房和城乡建设局（人防办）、城市管理局（综合行政执法局）、农业农村局（水利局）、供销合作总社、房屋征收与补偿办公室。

联系自然资源天宁分局、天宁生态环境局、交通运输综合行政执法支队天宁大队。

陈卓同志协助周登蓉同志分管金融、常州金融商务区建设方面工作。履行分管范围内安全生产工作职责。

协管地方金融监督管理局（区政府金融工作办公室）。

杨旭同志协助周登蓉同志分管科技、工业和信息化、市场监督管理方面工作。履行分管范围内安全生产工作职责。

协管科学技术局、工业和信息化局、市场监督管理局。

常州市天宁区人民政府
