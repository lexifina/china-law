# 关于印发《常州市提取住房公积金用于偿还住房贷款的规定》的通知

各住房公积金缴存人：

现将《常州市提取住房公积金用于偿还住房贷款的规定》予以印发，自2024年11月1日起施行。原《关于提取住房公积金用于偿还住房贷款的具体规定》（常公积金﹝2017﹞21号）同时废止。

对于2024年已办理过偿还商业性住房贷款提取住房公积金的缴存人，常州市住房公积金管理中心在2024年12月31日前不再受理偿还商业性住房贷款提取申请。

常州市住房公积金管理中心

2024年10月15日

(此件公开发布)

常州市提取住房公积金用于偿还住房贷款的规定

为充分发挥住房公积金的住房保障作用,切实减轻缴存人的还贷压力，根据《常州市住房公积金管理办法》等文件规定，制定提取住房公积金用于偿还住房贷款的规定。

一、偿还本市住房公积金贷款（含公转商补息贷款）提取

（一）逐月还贷提取

本规定所称逐月还贷提取，是指缴存人委托常州市住房公积金管理中心(以下简称中心)每月提取本人住房公积金账户内的存储金额，通过转账方式按月偿还本市住房公积金贷款或公转商补息贷款。

1. 申请对象

申请对象为在本市已办理住房公积金贷款或公转商补息贷款且尚未还清的借款人及其配偶，包括共有产权人及其配偶。

2. 提取额度

申请人逐月还贷提取的金额为每月应还住房公积金贷款或公转商补息贷款的本息额(含逾期部分)，提取后住房公积金账户余额不能为0。

申请人住房公积金账户的存储金额大于当月应还贷款本息额的，则足额提取归还贷款；申请人住房公积金账户的存储金额小于当月应还贷款本息额的，按住房公积金账户实际金额提取归还贷款,不足部分从借款人还贷银行账户中扣收。

3. 申请材料

（1）申请人身份证件原件；

（2）《不动产权证》或《商品房买卖合同》原件；

（3）申请人为借款人配偶或共有产权人配偶的，还需提供证明夫妻关系的结婚证或户口簿原件；

（4）若由他人代办的，还需提供代办人身份证件原件。

4. 其他

贷款本息已结清或公转商贷款终止贴息的，逐月还贷提取委托自动终止。

（二）提前部分还贷提取

本规定所称提前部分还贷提取，是指缴存人提取其住房公积金账户内的存储金额，提前偿还部分本市住房公积金贷款本息。

1. 申请对象及条件

申请对象为本市住房公积金贷款的借款人及其配偶，包括共有产权人及其配偶。

申请提取时须同时满足下列条件：

（1）申请时本市住房公积金贷款尚未还清；

（2）申请时贷款没有逾期，且贷款剩余期限不少于一个月。

2. 提取额度

申请人提前部分还贷提取的金额应小于该笔住房公积金贷款的剩余本息，提取后住房公积金账户余额不能为0。

3. 申请材料

（1）申请人身份证件原件；

（2）《不动产权证》或《商品房买卖合同》原件；

（3）申请人为借款人或共有产权人配偶的，还需提供夫妻关系证明材料原件；

（4）若由他人代办的，还需提供代办人身份证件原件。

4. 其他

（1）每月15日、20日、25日(遇节假日往后顺延)和最后一个工作日为扣款日，遇到银行扣款数据未返回时，中心不予受理提前部分还贷提取。

（2）办理公积金贷款提前部分还贷提取的，申请人应与中心重新约定剩余贷款的月还款金额，调整借款期限，但不得超过借款合同订立的借款期限。如委托他人代办的，受托人须为住房公积金贷款的借款人或还款人之一。

（三）提前还清提取

本规定所称提前还清提取，是指缴存人提取住房公积金账户内的存储金额，提前还清本市住房公积金贷款本息余额。

1. 申请对象及条件

申请对象为本市住房公积金贷款的借款人及其配偶，包括共有产权人及其配偶。

申请提取时须同时满足下列条件：

（1）申请时本市住房公积金贷款尚未还清；

（2）申请时贷款没有逾期。

2. 提取额度

申请人提前还清提取的金额不得超过该笔住房公积金贷款的剩余本息，提取后住房公积金账户余额不能为0。

3. 申请材料

（1）申请人身份证件原件；

（2）《不动产权证》或《商品房买卖合同》原件；

（3）申请人为借款人或共有产权人配偶的，还需提供夫妻关系证明材料原件；

（4）若由他人代办的，还需提供代办人身份证件原件。

4. 其他

（1）每月15日、20日、25日(遇节假日往后顺延)和最后一个工作日为扣款日，遇到银行扣款数据未返回时，中心不予受理提前还清提取。

（2）若提取总额等于贷款剩余本息额的，可即时转账还清贷款；若提取总额小于贷款剩余本息额的，不足部分借款人应自筹资金结清。

（四）公转商贷款提前还贷提取

本规定所称公转商贷款提前还贷提取，是指缴存人提取其住房公积金账户内的存储金额，提前偿还公转商补息贷款本息。

1. 申请对象及条件

申请对象为在本市已办理公转商补息贷款且尚未还清的借款人及其配偶，包括共有产权人及其配偶。

申请提取时须同时满足下列条件：

（1）申请时本市公转商补息贷款尚未还清；

（2）申请时贷款没有逾期。

2. 提取额度

申请人公转商贷款提前还贷提取的金额不超过该笔公转商补息贷款剩余本金，提取后住房公积金账户余额不能为0。

3. 申请材料

（1）申请人身份证件原件；

（2）《不动产权证》或《商品房买卖合同》原件；

（3）申请人为借款人或共有产权人配偶的，还需提供夫妻关系证明材料原件；

（4）若由他人代办的，还需提供代办人身份证件原件。

4. 其他

（1）每月15日、20日、25日（遇节假日往后顺延）和最后一个工作日为扣款日，遇到银行扣款数据未返回时，中心不予受理公转商贷款提前还贷提取。

（2）申请人须及时到贷款银行办理后续还贷手续，办理期限不得晚于次月末，实际还贷金额不得少于提取金额。逾期未还或少还的，中心终止贴息且不再为该笔贷款办理公转商贷款提前还贷提取。

二、偿还异地住房公积金贷款提取

本规定所称偿还异地住房公积金贷款提取，是指在本市范围以外办理住房公积金贷款的缴存人，提取其本市住房公积金账户内的存储金额，用于偿还其异地住房公积金贷款本息。

（一）申请对象及条件

申请对象为异地住房公积金贷款的借款人及其配偶，申请时在本市无未还清的住房公积金贷款或公转商补息贷款。

(二)提取额度

申请人偿还异地住房公积金贷款提取的金额不超过申请提取时住房公积金账户内的存储金额；贷款结清的，提取金额不超过贷款结清当月之前（含当月）的住房公积金存储金额。所有申请人提取总额不超过该笔异地住房公积金贷款的累计还贷本息额。

提取后住房公积金账户余额不能为0。

（三）提取频次

偿还异地住房公积金贷款提取不限提取次数，但提取总额不超过该笔异地住房公积金贷款累计还贷本息额；贷款结清的，同一笔异地住房公积金贷款只允许提取一次。

(四)申请材料

1. 申请人身份证件原件；

2.《不动产权证》复印件（或《商品房买卖合同》原件）、《借款合同》原件、异地公积金中心出具的累计还贷本息额的证明材料原件；

3. 申请人为借款人配偶的，还需提供证明夫妻关系的结婚证或户口簿原件；

4. 若由他人代办的，还需提供代办人身份证件原件。

5. 授权公积金中心通过数据共享、信息核验等方式获取或核查相关信息的，对应的申请材料无需重复提供。

三、偿还商业性住房贷款提取

本规定所称偿还商业性住房贷款提取，是指已办理商业性住房贷款的缴存人，提取其住房公积金账户内的存储金额，用于偿还其商业性住房贷款本息。

（一）申请对象及条件

申请对象为商业性住房贷款的借款人及其配偶，包括共有产权人及其配偶。

申请提取时须同时满足下列条件：

1. 申请时在本市无未还清的住房公积金贷款或公转商补息贷款；

2. 申请时商业性住房贷款已正常还款一期以上，且没有逾期。

(二)提取额度

申请人偿还商业性住房贷款提取的金额不超过申请提取时住房公积金账户内的存储金额。所有申请人提取总额不超过申请时核定的该笔商业性住房贷款未还清贷款本息总额。

提取后住房公积金账户余额不能为0。

（三）提取频次

偿还商业性住房贷款提取不限提取次数，但提取总额不超过核定的该笔商业性住房贷款未还清贷款本息总额。

申请人也可委托中心每月提取本人住房公积金账户内的存储金额，转账存入商业性住房贷款借款人的还贷银行账户。

(四)申请材料

1. 申请人身份证件原件；

2.《不动产权证》（或《商品房买卖合同》）、《借款合同》原件；

3. 申请人为借款人或共有产权人配偶的，还需提供证明夫妻关系的结婚证或户口簿原件；

4. 若由他人代办的，还需提供代办人身份证件原件；

5. 授权公积金中心通过数据共享、信息核验等方式获取或核查相关信息的，对应的申请材料无需重复提供。

（五）其他

1. 有多笔商业性住房贷款的，只能选择其中一笔办理偿还商业性住房贷款提取，直至还清后方可选择另一笔。

2. 委托他人代办的，受托人须为商业性住房贷款的借款人及其配偶，包括共有产权人及其配偶。

3. 中心将定期对商业性住房贷款的状态进行核查，经核查贷款已结清的，不得办理提取。
