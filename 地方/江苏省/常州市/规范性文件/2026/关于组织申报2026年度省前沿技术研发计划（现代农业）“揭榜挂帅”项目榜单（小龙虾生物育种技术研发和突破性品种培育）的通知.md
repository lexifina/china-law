# 关于组织申报2026年度省前沿技术研发计划（现代农业）“揭榜挂帅”项目榜单（小龙虾生物育种技术研发和突破性品种培育）的通知

废止日期：2026-06-23

内容概述：关于组织申报2026年度省前沿技术研发计划（现代农业）“揭榜挂帅”项目榜单（小龙虾生物育种技术研发和突破性品种培育）的通知

关于组织申报2026年度省前沿技术研发计划（现代农业）“揭榜挂帅”项目榜单（小龙虾生物育种技术研发和突破性品种培育）的通知

各辖市、区科技局，常州经开区科促局，各相关单位：

江苏省科学技术厅、江苏省财政厅关于发布《2026年度省前沿技术研发计划（现代农业）“揭榜挂帅”项目榜单（小龙虾生物育种技术研发和突破性品种培育）的通知》（苏科资发〔2026〕76号），现转发给你们，并就具体申报事宜通知如下：

1.揭榜单位应为江苏省境内具有独立法人资格的单位，鼓励企业、高校、科研院所跨区域联合攻关。联合揭榜的，所有参与单位应签订联合揭榜协议，明确任务分工和协议签署时间。

2.揭榜单位对申报材料的真实性和合法性负有法人主体责任，严禁虚报项目、虚假出资、虚构事实及包装项目等弄虚作假行为，经费预算应根据项目实际需求科学制定，不简单按省财政资金控制数和自筹比例设置。

3. 经费资助：省拨经费不超过300万元，不超过项目总预算的50%，其中：企业牵头申报的项目省拨经费不超过项目总预算的30%。实施期限不超过3年。

4.项目负责人须为申报单位的在职人员（与申报单位签订劳动合同），并确保在职期间能完成项目任务。有在研省科技计划项目的负责人，不得牵头申报本项目。已有在研“揭榜挂帅”项目的企业不得牵头申报本项目。

5.申报时间：请各申报单位于2026年6月22日（星期一）17:00前完成网上申报及提交，逾期不予受理。

6.联系人:焦宏伟　汤夕勤，联系电话：85681539
