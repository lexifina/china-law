# 常州市金坛区人力资源和社会保障局关于金坛区贫困人员参加城乡居民基本养老保险有关规定的通知

（坛人社发〔2018〕132号）

各镇（区）人民政府（管委会），区各部委办局、区直属单位：

为认真贯彻《省人力资源社会保障厅 省扶贫办 省民政厅 省残联关于精准实施城乡居民基本养老保险扶贫工作的意见》（苏人社发〔2018〕230号）、《关于我市市区低收入人口参加城乡居民基本养老保险有关规定的通知》（常人社发〔2018〕205号）精神，按照精准扶贫精准脱贫基本方略，实现困难群体参加社会保险全覆盖，现将我区贫困人员参加城乡居民基本养老保险有关规定通知如下：

一、充分认识社会保险扶贫工作意义

开展社会保险扶贫是贯彻落实党中央、国务院打赢脱贫攻坚战决策部署和全面建成更高水平小康社会的重要举措，也是提升社会保险工作科学化、精细化的重要途径。从全局和政治高度，充分认识社会保险扶贫的重要意义，增强工作责任感、使命感和紧迫感，全力抓好社会保险扶贫工作。

二、落实城乡居民基本养老保险相关扶贫政策

认真落实有关社会保险扶贫政策，努力推进困难群体应保尽保，切实减轻困难群体参加城乡居民基本养老保险的缴费负担。对本轮建档立卡未标注脱贫的低收入人口、低保对象和特困人员等我区户籍的贫困人员，参加我区城乡居民基本养老保险的，由区财政按我区城乡居民基本养老保险最低缴费档次为其代缴。对上述贫困人员，符合条件的，由区社保经办机构按我区标准发放城乡居民基础养老金，实现困难人员100%参保登记、100%为其代缴保费、100%享受城乡居民基本养老保险待遇，保证贫困人员有更多收入来源。

三、做好城乡居民基本养老保险扶贫政策的实施工作

相关部门要建立健全工作协调机制和信息共享机制，扶贫办、民政、残联等部门负责提供贫困人员数据信息。区社会保险经办机构要共同做好困难群体动态管理，掌握准确的人员信息。区财政部门负责做好资金保障工作。加大政策宣传力度，切实做好这部分困难群众参保工作，努力把好事办好，让困难群众满意，确保完成城乡居民基本养老保险扶贫工作目标任务。

四、其他

本通知自2019年1月1日起执行。
