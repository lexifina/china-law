# 常州市金坛区城市管理局关于规范建筑垃圾运输管理的通知

各建筑垃圾运输单位，局属各相关部门：

为进一步规范建筑垃圾运输管理，减少大气扬尘，改善人居环境，依据《建设部关于纳入国务院决定的十五项行政许可的条件规定》（建设部令第135号）《城市建筑垃圾管理规定》（建设部令第139号）和《市政府关于印发<常州市市区建筑渣土处置管理办法>的通知》（常政发〔2019〕19号）《常州市金坛区人民政府关于印发<金坛区城区建筑垃圾管理暂行办法>的通知》（坛政规〔2017〕1号）《常州市金坛区人民政府关于印发<常州市金坛区打赢蓝天保卫战行动计划实施方案>的通知》（坛政发〔2019〕43号）等规定和要求，现就我区建筑垃圾运输规范管理工作通知如下：

一、实施范围

常州市金坛区所有从事建筑垃圾（主要包括工程垃圾、拆除垃圾、工程渣土等）运输的单位。

二、主要内容

1.我区所有从事建筑垃圾运输的车辆实行“七统一、一必须”管理制度。“七统一”是指统一密闭装置、统一安装顶灯、统一单位标识、统一外观颜色、统一放大车辆号牌、统一安装安全警示标识、统一安装定位系统。“一必须”是指建筑垃圾运输车辆必须纳入本地进行统一管理。

2.目前已在我区城管局备案的建筑垃圾运输车辆，不得擅自变更挂靠公司，如挂靠公司因经营不善、破产、注销等因素造成挂靠车辆无法生产作业的，需由该公司提出申请，方可将所有车辆整体挂靠其他公司。

3.已备案运输公司新增建筑垃圾运输车辆必须为符合“七统一、一必须”标准的新型环保智能垃圾车，且为该公司自有。

4.新公司备案，须自有5辆以上符合“七统一、一必须”标准的新型环保智能垃圾车。

5.凡不符合“七统一、一必须”的运输车辆一律不得在我区从事建筑垃圾运输。

6.金坛区域内建筑垃圾运输单位处置建筑垃圾，必须向区城管部门提出运输申请，经核准取得《金坛区建筑垃圾处置证》后，方可按要求处置建筑垃圾。

三、具体要求

1.提高思想认识。各建筑垃圾运输单位要高度重视，进一步提高思想认识，与区城管部门加强密切配合，共同做好建筑垃圾运输规范管理工作。

2.严格督查检查。区城管局将对运输单位和车辆开展集中整治，纳入诚信考核，对不符合“七统一、一必须”要求的，进行约谈，暂停运输核准，直至退出我区建筑垃圾运输市场。

3.严格规范执法。任何公民、法人或其他组织在建筑垃圾处置管理过程中有违法违规的，一律按照法律、法规、规章的规定进行处罚。

本通知自2019年6月30日起执行。
