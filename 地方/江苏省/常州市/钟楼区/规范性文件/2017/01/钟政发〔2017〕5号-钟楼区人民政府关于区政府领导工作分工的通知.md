# 钟楼区人民政府关于区政府领导工作分工的通知

镇政府，开发区管委会，各街道办事处，区各办局，各直属单位：

经研究决定，区政府领导工作分工如下：

董彩凤同志主持区政府全面工作，兼管人事、机构编制、监察、财税、国有资产、审计、外事、人民武装等方面工作，分管编办、监察局、财政局（国资办）、人力资源和社会保障局、审计局、外事办，联系人大、政协、人武部等单位。

何海平同志负责教育、文化、体育、卫生计生、妇女儿童、对口援助、民族宗教、地方志等方面工作，分管教育文体局、卫生和计划生育局、民族宗教局，联系总工会、团委、妇联、红十字会、关工委、老年体协、档案局等单位。

张菁同志负责民政、社区建设、双拥、老龄、农业、农村、水利、防汛防旱、环境保护、残联等方面工作，分管民政局（老龄办）、农业局（水利局）、环境保护局、残联，协管人力资源与社会保障、人民武装等工作，联系农工办等单位。

朱亚林同志负责司法、安全生产、信访、公安、消防、国家安全、应急管理、维稳等方面工作，分管司法局、安全生产监督管理局、公安分局、应急办，联系法院、检察院、信访局、机要保密局、交巡警大队等单位。

芮春祥同志负责规划、国土、城市建设、城市管理、房管、交通运输、民防等方面工作，分管建设局（地震局、征收办）、城市管理局（行政执法局、监督指挥中心）、房产管理局、民防局，联系规划分局、国土分局、运管所、市轨道办等单位。

常州市钟楼区人民政府

2017年1月12日
