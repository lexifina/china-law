# 区政府办公室关于成立创建省级众创社区建设领导小组的通知

镇、开发区、各街道，区各有关单位：

为贯彻国家创新驱动发展决策部署，落实省委提出的“两聚一高”的战略任务，大力推进大众创新创业，加快我区众创社区建设工作，经研究，决定成立钟楼区创建省级众创社区建设领导小组。具体名单如下：

成 员：孙立峰 区委组织部副部长、区人才办主任

周伟奇 区委宣传部副部长

朱希贤 区发改局局长

杨文娟 区教文局局长

刘 刚 区科技局局长

陈 静 区财政局局长

孙兰勤 区人社局局长

张 鹏 区商务局局长

管晓东 钟楼经济开发区管委会副主任

领导小组下设办公室，办公室设在区科技局，由刘刚同志兼任办公室主任。

钟楼区人民政府办公室

2017年3月16日
