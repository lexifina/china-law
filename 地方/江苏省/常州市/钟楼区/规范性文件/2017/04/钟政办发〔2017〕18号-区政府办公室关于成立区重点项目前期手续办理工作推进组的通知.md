# 区政府办公室关于成立区重点项目前期手续办理工作推进组的通知

镇、开发区、各街道，区各办局、直属单位：

为更好协调重点项目前期手续办理，加快重点项目建设进度，经研究，决定成立区重点项目前期手续办理工作推进组，具体名单如下：

常务副组长：朱希贤 区发改局局长

副 组 长：沈雪峰 区发改局副局长

成 员：李光春 区建设局副局长

吴志明

区环保局副局长

朱 怡 规划分局副局长

江 敏 国土分局副局长

姚汉涛

消防大队大队长

推进组要建立定期例会制度，每月对区级以上（含区级）重点项目的进展情况、存在问题进行梳理汇总，研究制定针对性的工作举措。同时，要加强与各板块的沟通衔接，帮助项目建设单位完善相关手续，加快项目建设进度，提高服务效率和水平。

钟楼区人民政府办公室

2017年4月10日
