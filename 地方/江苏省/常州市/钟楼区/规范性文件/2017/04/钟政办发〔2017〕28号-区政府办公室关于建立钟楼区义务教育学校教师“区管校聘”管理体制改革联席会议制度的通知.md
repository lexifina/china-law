# 区政府办公室关于建立钟楼区义务教育学校教师“区管校聘”管理体制改革联席会议制度的通知

镇、开发区、各街道，区各相关部门：

为深入贯彻《省政府关于统筹推进城乡义务教育一体化促进优质均衡发展的若干意见》（苏政发〔2017〕1号）精神，推动义务教育学校教师交流轮岗制度化，经研究，决定建立钟楼区义务教育学校教师“区管校聘”管理体制改革联席会议制度，现将有关事项通知如下：

一、联席会议主要职责

（一）制定义务教育学校教师“区管校聘”管理体制改革方案，协调解决方案实施过程中的突出问题。

（二）建立义务教育学校教师编制和岗位动态调整机制，每年研究确定各义务教育学校教师编制和岗位数量。

（三）健全义务教育学校教师交流轮岗制度和激励保障机制，每年研究确定各义务教育学校教师流出和流入数量，尽快实现区域内同学段学校岗位结构大体相当

、骨干教师比例大体相当。

（四）完善义务教育学校教师补充机制，每年研究确定补充数量。

（五）协调解决联席会议成员单位提出的其他自事项。

二、联席会议成员组成

联席会议由副区长何海平同志任召集人，区编办、教文局、财政局、人社局负责同志为成员（详见附件1）。联席会议可根据议题需要，请其他相关部门同志列席参加。

联席会议办公室设在区教文局，由杨文娟同志任办公室主任，各相关部门派员参加（详见附件2）。

三、联席会议及办公室工作规则和要求

（一）区教文局在全面调研的基础上，向联席会议办公室提出各义务教育学校教师编制和岗位设置、各义务教育学校教师流出和流入、招聘补充教师等一系列初步方案。

（二）联席会议办公室将教文局提出的初步方案征求编办、财政局、人社局的意见，形成方案审议稿，提交联席会议审议，并以会议纪要的形式明确议定事项。

（三）每年7月底前，联席会议办公室召开会议，落实联席会议确定的事项，明确交流轮岗的教师名单和去向、招聘补充教师的名单。

（四）每年8月底前，完成当年教师交流轮岗、招聘补充工作；9月底前，区教文局向社会公示教师交流轮岗情况。
