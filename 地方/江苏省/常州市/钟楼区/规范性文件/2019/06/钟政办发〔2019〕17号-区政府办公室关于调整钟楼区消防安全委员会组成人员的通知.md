# 区政府办公室关于调整钟楼区消防安全委员会组成人员的通知

开发区、镇、各街道，区有关办局、直属单位：

因机构、人事变动和工作需要，区政府决定对钟楼区消防安全委员会组成人员进行相应调整。调整后的成员名单如下：

副主任：

吴 伟 区政府办主任

朱 斌 区应急管理局局长

姚汉涛 区消防救援大队大队长

吕 军 常州市交通运输综合行政执法支队钟楼执法大队副大队长

区消防安全委员会办公室设在区消防大队，承担区消防安全委员会日常工作，姚汉涛同志兼任办公室主任。今后除区消防安全委员会主任、副主任外，委员会成员如有变动，由成员单位自行调整，并报区消防安全委员会，不再另行发文。
