# 区政府办公室关于成立钟楼区化工产业安全环保整治提升领导小组的通知

开发区、镇、各街道，区各有关办局，直属单位：

根据《常州市化工产业安全环保整治提升实施方案》和《钟楼区化工产业安全环保整治提升实施方案》文件要求，为有效防范遏制化工产业重特大事故，牢固树立以人民为中心的发展思想，坚持安全第一、生态优先、绿色发展，加快推动化工产业转型升级和高质量发展，经研究决定，成立钟楼区化工产业安全环保整治提升领导小组（以下简称：领导小组），并下设办公室。现将有关事项通知如下：

一、主要职能

领导小组在区政府领导下，统筹协调推进全区化工产业安全环保整治提升工作。对全区化工产业安全环保整治提升工作进行指导、调度、督查、通报，协调解决整治提升工作中的重大问题。

二、成员单位

领导小组组长由分管副区长担任，副组长由钟楼区工业和信息化局、钟楼区应急管理局、钟楼生态环境局主要领导担任，领导小组成员由钟楼区发展和改革局、钟楼区工业和信息化局、钟楼区司法局、钟楼区财政局、钟楼区人力资源和社会保障局、钟楼区住房和城乡建设局、钟楼区农业农村局、钟楼区商务局、钟楼区应急管理局、钟楼区市场监督管理局、钟楼区统计局、钟楼区信访局、钟楼区地方金融监督管理局、钟楼公安分局、钟楼生态环境局、钟楼自然资源分局、钟楼区税务局、钟楼消防大队18个部门分管领导组成，并可根据工作需要，邀请其他相关部门参加。领导小组成员因工作变动需要调整的，由所在单位提出，报领导小组确定。领导小组成员名单见附件1。

全区化工产业安全环保整治提升工作日常管理由领导小组办公室(以下简称：区化治办)统一负责。区化治办设在区工信局，下设综合协调组、环保整治提升组、安全整治提升组。办公室主任由区工信局主要领导兼任，副主任由区工信局、区应急管理局，钟楼生态环境局部门分管领导担任，并分别兼任各组组长。区化治办人员名单见附件2。

三、工作规则

领导小组根据工作需要定期或不定期召开会议，由组长或副组长主持。成员单位根据工作需要可以提出召开领导小组会议或联络员会议的建议。领导小组以会议纪要形式明确会议议定事项，由领导小组办公室印发有关方面并上报区政府，重大事项按程序报批。

四、工作要求

领导小组各成员单位要按照职责分工，主动研究化工产业安全环保整治提升工作中的重大问题，认真落实领导小组会议议定事项。各部门要密切配合，充分发挥领导小组及办公室作用，形成高效运行的长效工作机制。领导小组办公室要及时向各成员单位通报有关情况。开发区、镇、各街道都要相应成立领导小组和办公室。
