# 区政府办公室关于成立钟楼区招标拍卖挂牌出让国有建设用地使用权工作领导小组的通知

开发区管委会、邹区镇政府、各街道办事处，区各有关单位：

为加快推进我区国有建设用地使用权的招标拍卖挂牌出让工作，经研究，决定成立钟楼区招标拍卖挂牌出让国有建设用地使用权工作领导小组，成员如下：

组 长：芮春祥 副区长

副组长：程晋平 钟楼自然资源分局局长

施宏伟 区政府办副主任

成 员：朱希贤 区发改局局长

须晶晖 区工信局局长

刘 刚 区科技局局长

陈 静 区财政局局长

李恒栋 区住建局局长

王 旭 区商务局副局长

宋志平 钟楼生态环境局局长

江 敏 钟楼自然资源局分局副局长

领导小组下设办公室，办公室设在钟楼自然资源局分局，由程晋平同志兼任办公室主任，江敏同志兼任办公室副主任。

常州市钟楼区人民政府办公室

2019年8月30日
