# 省政府办公厅关于深入推行科技特派员制度的实施意见

苏政办发〔2017〕124号

各市、县（市、区）人民政府，省各委办厅局，省各直属单位：

为完善我省科技特派员制度，帮助农民依靠科技增收致富，根据《国务院办公厅关于深入推行科技特派员制度的若干意见》（国办发〔2016〕32号）和省第十三次党代会“两聚一高”有关部署，制定本实施意见。

一、目标要求

（一）总体要求。深入贯彻落实习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，牢固树立创新、协调、绿色、开放、共享的发展理念，按照“坚持改革创新、突出农村创业、加强分类指导、尊重基层首创”的要求，着力完善科技特派员制度，着力壮大科技特派员队伍，着力提升科技特派员层次和能力，着力构建科技特派员创新创业与服务载体，进一步激发广大科技特派员创新创业热情，引导各类科技创新创业人才和单位整合科技、信息、资金、管理等现代生产要素，深入农村基层一线开展科技创业和服务，与农民建立“风险共担、利益共享”的共同体，在培育发展农村优势特色产业和农业新型经营主体、培养新型职业农民、推动农村大众创业万众创新、促进农村一二三产业融合发展等方面不断取得新成效、新突破，为我省率先实现农业现代化、推进特色田园乡村和“强富美高”新江苏建设提供更加有力的科技支撑。

（二）工作目标。到2020年底，建立完善政府引导与市场运作相结合的科技特派员创新创业推进机制，探索建立适合不同地区、不同产业特点的科技特派员服务模式，全省科技特派员队伍规模达7万人、实现涉农县（市、区）科技特派员服务全覆盖，建设农村科技服务超市500家以上、科技特派员工作站500家以上、“星创天地”200家以上，形成一批高水平科技特派员创新创业与服务载体，全省科技特派员制度不断完善、环境条件进一步优化、促进农民增收致富更加有效。

二、重点任务

（一）提升农业科技创新支撑能力。面向现代农业和农村发展需求，围绕科技特派员创业服务过程中的关键环节和现实需要，积极推进农业科技创新，在良种培育、肥药创制、食品加工、疫病防控、设施农业、农业物联网和装备智能化、土壤改良、食品安全以及农村民生等方面取得一批新型实用技术成果，形成系列化、标准化农业技术成果包，并加快科技成果示范应用和产业化，为科技特派员农村科技创业提供技术支撑。

（二）推动农村特色产业培育发展。围绕农村优势特色产业关键技术需求和急需解决的技术难题，支持科技特派员帮助地方制定完善优势特色产业发展规划，整合科技资源，加强技术攻关，提供配套服务。积极推广应用农村实用技术，试验示范最新科技成果，大力培育“一县一业”和“一村一品”，做到供需对接、双向选择、品牌经营，有效提升科技服务“三农”能力和水平，促进农村优势特色产业提档升级。

（三）完善新型农业社会化科技服务体系。建立完善以农村科技服务超市、星创天地、高校新农村发展研究院等为主体的新型农业社会化科技服务体系，推进科技特派员工作站建设，进一步整合科技、信息、资金、管理等现代生产要素，支持科技特派员面向农业特色产业和新型经营主体开展科技创新创业和服务。大力推动“互联网+服务”，提高农村科技服务与创业信息化、智能化水平。整合科技特派员力量，推进新农村发展研究院联盟建设与运行。深入开展科技镇长团、送科技下乡、挂县强农富民工程等多种形式的品牌活动，为广大科技特派员开展科技服务提供广阔天地。

（四）支持农村科技创新创业活动。鼓励科技特派员以技术、资金等方式入股，创办领办农业科技企业、农村专业技术协会、农业专业合作社等新型经营主体，与农民结成利益共享、风险共担的经济联合体，形成科技特派员服务基层的长效机制。鼓励高等院校、科研院所通过许可、转让、技术入股等方式支持科技特派员转化科技成果，保障科技特派员取得合法收益。吸引社会资本参与农村科技创业，形成多元化、多层次、多渠道的融资机制，加大对科技特派员创业企业的支持力度。对农民专业合作社等农业经营主体，落实减税政策，积极开展创业培训、融资指导等服务。

（五）助推科技精准帮扶。聚焦全省低收入人口脱贫、经济薄弱村发展和重点片区整体帮扶，深入实施精准扶贫、精准脱贫。瞄准经济薄弱地区存在的科技和人才短板，支持科技特派员以培育特色产业、促进一二三产业融合发展为突破口，大力开展创业式扶贫，增强农民创新创业和自我发展能力，加快脱贫致富奔小康进程。

三、保障措施

（一）强化组织领导。成立由省科技厅牵头，省财政厅、省人力资源社会保障厅、省农委等部门参加的省科技特派员农村科技创业行动协调指导小组，加强顶层设计、统筹协调和政策配套，形成部门协同、上下联动的组织体系和长效机制，为推行科技特派员制度提供组织保障。各市、县（市、区）要将科技特派员工作作为加强农村科技创新创业的重要抓手，建立健全多部门联合工作机制，结合实际制定本地区推动科技特派员创新创业和开展科技服务的政策措施，推动科技特派员工作持续深入开展。

（二）加大经费投入。各地要发挥财政资金引导作用，强化农业科技社会化服务奖补、“三区”科技人员专项等各类科技计划对科技特派员工作的集成支持。加大对科技特派员工作的经费投入，为科技特派员开展农业科技园区、科技服务超市、农业科技型企业、农业专业合作社、家庭农场等创新创业服务提供有力支持。鼓励社会资本参与科技特派员农村社会化科技服务活动，加快建立具有地方特点的多元投入机制。

（三）落实选派政策。普通高等院校、科研院所、职业学校等事业单位对开展农村科技公益服务的科技特派员，5年内实行保留原单位工资福利、岗位、编制和优先晋升职务职称的政策，其工作业绩纳入科技人员考核体系；对经批准离岗深入农村开展科技创业的，5年内保留其人事关系，与原单位其他在岗人员同等享有参加职称评聘、岗位等级晋升和社会保险等方面的权利，期满后可根据本人意愿选择辞聘创业或回原单位工作。结合实施大学生创业引领计划、离校未就业高校毕业生就业促进计划，动员金融机构、社会组织、行业协会、就业人才服务机构和企事业单位为大学生科技特派员创业提供支持，完善人事、劳动保障代理等服务，符合规定的要及时纳入社会保险。

（四）营造良好环境。建立科技特派员考核评价指标体系和退出机制，实行动态管理和监测，完善科技特派员统计报告制度。大力宣传科技特派员农村科技创业的先进事迹和奉献精神，组织开展科技特派员巡讲活动，激励更多的科技人员、企业和机构踊跃参与科技特派员农村科技创新创业和服务。对作出突出贡献的优秀科技特派员及团队、科技特派员派出单位以及相关组织管理机构等，按照有关规定予以表彰。
