# 江苏省提高技术工人待遇政策五问

为切实提高技术工人待遇，我省出台了《关于提高技术工人待遇的实施意见》，这是我省针对技术工人待遇制定的第一个系统性政策文件。那么，哪些是技术工人？哪些属于高技能领军人才？高技能领军人才享受哪些待遇？技术工人哪些情况下可以破格晋升职业资格？省政府办公厅政务公开办联合省人力资源和社会保障厅，为您作简明问答。

一、哪些是技术工人？哪些属于高技能领军人才？

技术工人是指取得初级及以上职业资格、职业技能等级或具有相当技能水平的劳动者。职业资格分为初级、中级、高级、技师和高级技师5个等级。职业技能等级也分为5个等级，由低到高分别是五级至一级，分别对应职业资格的初级、中级、高级、技师和高级技师。

高技能领军人才是指获得全国劳动模范、全国五一劳动奖章、中华技能大奖、全国技术能手等荣誉以及享受省级以上政府特殊津贴的高技能人才；获得江苏技能大奖荣誉人员；获得江苏省劳动模范荣誉的技师、高级技师；获得江苏省有突出贡献中青年专家荣誉的高技能人才；获得世界技能大赛金牌的选手。

二、高技能领军人才能享受哪些待遇？

在政治待遇上，纳入党委联系专家范围，定点联系、定期座谈、走访慰问；推荐作为党代表、人大代表、政协委员人选；选配到工会、共青团、妇联等群团组织中挂职或兼职；推荐当选省劳动模范、省五一劳动奖章、省有突出贡献中青年专家。

在经济待遇上，鼓励企业建立股权期权等中长期激励制度，设立特聘岗位津贴、带徒津贴，参照高级管理人员标准落实经济待遇；鼓励企业建立企业年金和商业补充医疗保险。参与市级以上科技计划项目的，所在单位根据其实际贡献给予绩效奖励。

在社会待遇上，与高层次人才同等享受购买自用商品住房、省内就医就诊和体检安排等方面待遇政策。子女入园及义务教育阶段入（转）学，由所在地人民政府及其教育部门按照“就近就便、适当照顾”原则，协调有关学校（幼儿园）提供便利。被引进的高技能领军人才，可享受当地提供的人才公寓、房租补贴，零门槛落户。企业首席技师可参照享受正高级工程师待遇。

三、技术工人享有什么待遇政策？

工资分配方面。鼓励企业在工资结构中增加体现技术技能价值的部分，或在关键技术、关键工序和紧缺急需岗位实施协议工资、项目工资、年薪制。鼓励企业根据实际情况，发放体现技术水平价值的补助性津贴。

工资增长方面。政府相关部门适时适度提高最低工资、高温津贴等标准。国有企业高技能人才人均工资增幅不低于本单位管理人员人均工资增幅。在非公有制企业推进工资集体协商，确定技术工人工资水平并实现合理增长。

长效激励方面。技术工人可享受促进科技成果转化有关政策，鼓励企业制定技术工人技能要素和创新成果按贡献参与分配的办法，对高技能人才实行技术创新成果入股、岗位分红等激励。

四、政府对企业职工提升技能有哪些政策支持？

参加职业培训的技术工人可按规定享受职业培训补贴和职业技能鉴定补贴。高技能人才“师带徒”相关费用可按规定从职工教育经费中列支。纳入新型学徒制培养范围的企业，可按规定享受培训补贴。每年建设一批国家级、省级高技能人才培训基地和大师工作室；组织10个职业（工种）高级技师进行岗位技能提升培训，并给予相应资金支持。

构建覆盖重点行业、特色行业的技能大师工作室、江苏大工匠工作室、江苏工匠工作室、劳模创新工作室、职工创新工作室、青年创新工作室网络，培养一批掌握关键技术的产业技能大师和历史经典工艺传承技能大师。

五、技术工人能否申报专业技术职称？哪些情况下可以破格晋升职业资格？

我省各类企事业单位中在工程技术领域生产一线岗位，从事技术技能工作的高级工、技师、高级技师，可按规定分别申报工程技术系列的助理工程师、工程师和高级工程师职称。

世界技能大赛获奖选手、有突出贡献的个人；解决重大工艺技术难题和重大质量问题、技术创新成果获得省部级以上奖项、“师带徒”在职工素质提升、职业技能竞赛、生产工艺革新等方面业绩突出的，可按规定破格晋升职业资格。
