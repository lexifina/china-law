# 无锡市江阴市人民政府关于《新增相对集中行政许可权事项清单》的通知

（澄政发〔2019〕57号）

各镇人民政府，各街道办事处，各开发区管委会，市各委办局，市各直属单位：

为贯彻落实省委、省政府关于市县机构改革方案要求，深化相对集中行政许可权改革，进一步推进审批服务便民化工作，经市人民政府研究决定，新增划转“广告发布登记”等16项行政许可事项至市行政审批局，自2019年8月15日起正式交接。现将《新增相对集中行政许可权事项清单》印发给你们，请遵照执行。
