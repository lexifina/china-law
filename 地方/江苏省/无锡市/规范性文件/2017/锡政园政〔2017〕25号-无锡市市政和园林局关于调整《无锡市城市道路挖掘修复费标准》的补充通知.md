# 无锡市市政和园林局关于调整《无锡市城市道路挖掘修复费标准》的补充通知

（锡政园政〔2017〕25号）

各区城管局、惠山区交通运输局、无锡市政设施管理处、各有关单位：

为减轻管线单位负担，使城市道路更好的服务社会经济发展。经与各管理部门和各管线单位就城市道路挖掘基数进行充分协商，根据江苏省住房和城乡建设厅《省住房城乡建设厅关于印发<江苏省城市道路挖掘修复费标准（2016版）>的通知》（苏建城【2016】682号）文件精神，现确定城市道路（快速路、主干路、次干路、支路）挖掘基数暂取0.9。

以上基数选取从2017年9月1日起执行，原《关于调整<无锡市城市道路挖掘修复费用标准>的通知》（锡政园政【2017】4号）2017年9月1日起暂停执行。以后基数选取将根据市场情况作适时调整。

无锡市市政和园林局

2017年8月17日
