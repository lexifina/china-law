# 中共无锡市委办公室无锡市人民政府办公室关于印发《无锡国家文化出口基地建设实施意见》的通知

为充分发挥无锡国家文化出口基地的集聚、引领和示范作用，推动全市对外文化贸易高质量发展，根据贯彻落实《国务院关于加快发展对外文化贸易的意见》按照和商务部、中宣部、文化和旅游部、国家广播电视总局等部门部门对国家文化出口基地建设的要求，充分发挥无锡国家文化出口基地的集聚、引领和示范作用，推动全市对外文化贸易高质量发展，特制定如下实施意见如下。

一、总体要求

（一）指导思想。

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大精神，认真践行开放发展新理念，积极推进全面开放战略，坚持通过积极“引进来”和、主动“走出去”并重，，创新文化贸易发展的体制机制，，促进对外文化贸易转型升级，推动文化贸易做大做强，在更大范围、更广领域、更高层次参与国际文化合作与竞争，把更多具有中国特色和无锡元素的优秀文化产品和服务推向世界，努力把无锡建设成为具有鲜明特色和国际影响力和鲜明特色的文化出口基地。

（二）基本原则

1. 坚持总量提升与质量优化相结合。支持文化企业发展壮大，鼓励文化企业积极开拓国际市场，、扩大文化出口总量，引导文化企业创新发展模式、优化出口结构，推动我市文化产业整体规模不断扩大、综合实力显著提高。；努力提升文化出口质量水平，促进经济结构调整和产业转型升级，实现我市文化产业整体规模的不断扩大和竞争力的显著提高。

2. 坚持政府引导和企业主导相结合。积极构建机制灵活、优势突出的政策体系，充分发挥企业在文化贸易多元化发展中的主体作用，营造有利于文化产业和文化贸易发展的良好环境。

建立和完善有利于文化产业和文化贸易发展的政策体系，构建机制灵活、优势突出的文化贸易多元化发展格局，营造对外文化贸易发展的良好环境；调动企业的积极性，充分发挥企业创新发展、提质增效的主体作用，做大做强无锡文化贸易。

3. 坚持传统产业提升和新兴产业拓展相结合。在巩固和提升发展传统文化贸易产业的基础上同时，顺应文化贸易的新趋势新特点，大力培育新兴文化贸易产业，不断适应文化贸易新趋势、新特点，加快推动无锡文化贸易全方位、高质量发展。

4. 坚持扩大文化产品出口和促进文化服务出口相结合。既着力提高文化出口产品的技术含量，促进更多高科技、高附加值产品出口；又着力提高文化服务的国际化和专业化水平，扩大文化服务出口份额。

（三）主要目标。

力争到2020年，培育一批具有较强国际竞争力的文化企业和文化出口品牌，建设若干具有较强带动作用的国际文化交易平台，形成一套具有较强示范作用的文化贸易创新发展模式，推动全市文化产业国际化水平不断提升，促进文化出口基地建设取得显著成效高质量发展，无锡文化软实力进一步增强，努力在国家文化出口基地建设中走在前列。

1. 、规模稳步扩大。进一步做大我市文化出口的规模，不断提升无锡文化产品和服务在国际市场上的影响力，力争到2020年，文化服务贸易企业数、文化出口额等指标年均增长10%以上。

2. 、特色更加鲜明。进一步做强特色文化和文化旅游产业，不断扩大影视制作、网络文化、创意设计等新兴文化服务领域的出口规模，提升高科技、高附加值文化产品出口占比。

3. 、企业做大做强。到2020年，力争力争培育出口3000万美元以上的文化出口龙头企业3家以上，出口500万美元以上具有品牌影响力和较强示范作用的文化出口骨干企业15家以上，出口200万美元以上具有培育潜力的文化出口优质企业20家以上。，省级以上文化出口重点企业（重点项目）20个以上。

二、重点任务

（一）优化功能布局。加强战略研究和统筹规划，对全市各板块市（县）区的发展现状和资源优势等进行综合考量，、科学规划整体设计，避免区域间重复建设和同质竞争打造一批具有示范、辐射、带动作用的文化产业园区（基地）和平台，形成分工合理、重点突出、各具特色、相互融合、覆盖全市的文化贸易发展布局，打造一批具有示范、辐射、带动作用的文化产业园区（基地）和平台。江阴市、宜兴市发挥乐器、紫砂等特色民族文化产品出口优势，进一步放大海澜集团飞马水城、宜兴竹海等文旅品牌效应，发挥乐器、紫砂等特色民族文化产品出口优势，在海澜集团飞马水城和宜兴竹海等旅游资源的基础上，进一步整合文化旅游休闲产业资源，同时用好用足发挥江苏金一文化发展有限公司等重点企业和、宜兴陶瓷文化创意产业园等重点企业重点园区资源优势，积极推动创意设计和文化旅游出口；锡山区和、惠山区充分整合利用荡口古镇和、阳山桃文化等特有的自然人文资源，积极发展民俗文化及生态休闲国际旅游业；梁溪区依托蓉运壹号等创意产业园等，着力发展创意设计产业，推动文化创意产业跨门类、跨要素、跨行业发展，加快江南古运河旅游度假区文商旅融合进程；滨湖区突出无锡（国家）数字电影产业园、无锡（国家）工业设计园、无锡太湖国家旅游度假区、灵山文化等特色品牌优势，重点发展影视科技、工业设计、佛教文化等产业；新吴区进一步做大做强文化数字内容产业，当好信息技术领域“文化+“文化+”商业模式的排头兵，加快建设无锡国家动画产业基地和动漫游戏产业振兴基地。全市市级层面要大力发展数字影视制作中心、国内外剧本交流交易中心、外观设计专利信息中心、超级云计算中心、动漫作品版权服务、新媒体技术等公共服务平台，为文化贸易企业提供技术支撑和服务保障。（责任单位：市委宣传部、市文广新局、市商务局，各市（县）区，无锡经济开发区）

（二）打造特色优势。加快培育形成集数字电影后期制作、影视剧拍摄、动漫游戏、版权交易、影视教育培训等为一体的影视动漫产业链，吸引跨国影视传媒企业、著名影视工作室入驻，实现影视文化产业专业层次、产业集聚度、产业品牌影响力的提升发展；加快培育形成以工艺美术设计、建筑设计、环境设计、视觉设计、、汽车外观及工装模具设计等为一体的创意设计产业链，强化文化创意产品研发，提高产品出口附加值，扩大文化创意品牌影响力，提高产品出口附加值；加快培育形成集数字传媒、互联网广告推广、移动通讯应用服务、多媒体应用与内容制作等为一体的新媒体产业链，打造国内领先的新媒体产业基地；。加快促进数字出版、演艺策划、文化经纪代理等其他新兴行业发展，进一步推动国际文化交流传播；加快促进数码影像设备、3D打印等国际先进水平的高科技文化产品制造业发展，鼓励文化贸易企业加大对文化出口产品和服务的研发投入，开发具有自主知识产权的核心技术；加快促进优秀传统文化品牌化发展，继续加大对宜兴紫砂、惠山泥人、锡绣、民族乐器等特色文化产品出口的支持力度，促进优秀传统文化品牌化发展；加快促进文化旅游融合发展，充分发挥无锡旅游资源丰富的优势，注重历史文脉传承，加快全域旅游示范区建设，推进文化旅游的融合发展。（责任单位：市委宣传部、市文广新局、市商务局、市科技局、市旅游局，各市（县）区，无锡经济开发区）

（三）做大做强市场主体。聚焦影视动漫、创意设计、新媒体等重点领域，坚持引企、引资、引智相结合，加快引进和培育一批基地型、龙头型文化产业项目。支持倍视文化、凤凰画材、灵山集团、慈文传媒、央视网络等重点企业发展，加快培育更多创新力强、发展潜力大的成长型骨干企业，充分发挥其在产业集聚、示范引领、扩大出口等方面的支撑作用。支持文化企业对国际先进技术的消化、吸收和再创新，大力培育自主知识产权和品牌，不断提高企业的核心竞争力。鼓励有实力的文化贸易企业跨地区、跨行业、跨所有制兼并重组和上市融资，争创国家文化出口重点企业和重点项目。扩大外资在文化服务和文化产品制造行业的市场准入，引进国外资本和先进技术，进一步发展VR（虚拟现实）、AR（增强现实）、3D打印设备等高科技文化制造业，积极引进国外广告、建筑、艺术设计和影视、动漫、游戏、数字媒体等文化创意产业及相关技术服务业。扩大外资在文化服务和文化产品制造行业的市场准入，引进国外资本和先进技术，进一步发展VR（虚拟现实）、AR（增强现实）、3D打印设备等高科技文化制造业，积极引进国外广告、建筑、艺术设计和影视、动漫、游戏、数字媒体等文化创意产业及相关技术服务业。（责任单位：市文广新局、市商务局、市旅游局、市金融办，各市（县）区，无锡经济开发区）

（四）强化加快市场开拓市场。积极开展文化贸易专题对接交流活动，有针对性地组织文化贸易重点园区和企业组团参加境内外文化类重点展会，通过集中参展、统一宣传，特别是加强与“一带一路”沿线国家和地区的文化产业合作，展示无锡文化产业整体形象，帮助企业深入开拓国际市场。围绕“走出去”，有针对性地组织文化贸易重点园区和企业组团参加境内外文化类重点展会，特别是加强与“一带一路”沿线国家和地区的文化产业合作；通过集中参展、统一宣传，开展文化贸易专题对接交流活动，展示无锡文化产业整体形象，帮助企业深入开拓国际市场。围绕“请进来”，充分借助各特色园区和龙头企业的优势，积极面向海内外举办一批有影响力的国际性文化创意类展会活动，为市场拓展和加深合作搭建良好平台。。加快文化与科技融合的步伐，鼓励文化贸易企业借助电子商务、众筹众包、资本输出、创意输出等新型交易模式拓展国际业务，推动文化出口多样化。加快文化与科技融合的步伐，鼓励文化贸易企业借助电子商务、众筹众包、资本输出、创意输出等新型交易模式拓展国际业务，推动文化出口多样化。（责任单位：市商务局、市文广新局、市科技局、市外办、市科技局，各市（县）区，无锡经济开发区）

（五）强化人才支撑。深入实施“太湖人才计划”系列人才政策，积极对接和争取国家、省人才政策的支持，加大高端文化人才和创作设计团队的引进力度，吸引其更多高层次人才来锡投资创业。积极发展文化创意高等教育和职业教育，调整或新设一批符合市场需求的实用性专业学科，加强创作、技术、管理等专业人才的培养。鼓励文化贸易企业自主培养人才和建设实训基地，做好从业人员的教育培训工作。（责任单位：市文广新局、市人才办、市人社局、市商务局、市教育局，各市（县）区，无锡经济开发区）

（六）加强加大财税支持。落实国家对重点鼓励的文化产品和文化服务出口的税收优惠减免政策，支持文化企业申报技术先进型服务企业，享受相关税收优惠政策。充分发挥中央、地方各级扶持政策对文化贸易的促进作用，积极组织相关园区、企业、机构和专家人才等进行申报，扩大政策受益面努力实现扶持政策效益最大化。支持有条件的企业申报国家文化出口重点企业和重点项目，对出口业绩增长和自主品牌培育良好的企业，在营销渠道建设、境外参展、国际资质认证、公共服务平台建设、人才培养等方面给予资金扶持。（责任单位：市委宣传部、市文广新局、市商务局、市科技局、市财政局、市税务局）

（七）完善金融服务。进一步优化和完善文化产业投融资服务体系，引导社会资本投入，更好地形成政府基金、社会基金、民营资本共同支持文化产业发展的合力格局。鼓励银行、信保机构开发更多符合文化贸易企业业务需求特点的信贷创新产品，对重点文化贸易项目和企业实施知识产权贷款及其他非抵押类贷款新模式。用好中信保等出口信用保险平台，对文化类自主创新产品或服务出口予以重点支持。通过政府引导、政银保合作，建立中小微文化企业融资风险补偿机制，加大对中小微企业的金融支持。积极争取国家服务贸易基金对文化贸易创新创业项目的支持。（责任单位：市商务局、市文广新局、市财政局、市金融办）

（八）提升便利化水平。对文化出口企业，在开辟绿色通道、简化通关手续等方面提供海关便捷服务，积极支持国家文化出口重点企业申报成为海关高信用企业。优化创新保税监管服务模式，提高境外艺术品、藏品入境的通关效率，为艺术品进境提供通关便利，为国外拍卖行提供进境预展服务。推进文化贸易投资的外汇管理便利化，确保文化出口相关跨境收付与汇兑顺畅，简化跨境人民币结算手续和审核流程，提升结算便利，降低汇率风险。鼓励境内金融机构开展境外项目人民币贷款业务，支持文化企业从事境外投资。依法减少对文化出口的行政审批事项，简化手续，、缩短时限，将有关文化贸易管理事项纳入国际贸易“单一窗口”。（责任单位：市商务局、市文广新局、市税务局、无锡海关、市外管局）

（九）加强知识产权保护。加大文化知识产权宣传力度，开展相关法律法规的培训教育，提升文化贸易企业知识产权创造、运用、管理和保护能力，营造有利于文化知识产权保护的环境。研究建立文化知识产权价值评估体系，加强文化知识产权保护国际合作，为文化贸易企业提供海外知识产权、法律体系及适用等方面咨询，积极支持和帮助文化企业开展涉外知识产权维权工作。促进版权授权体系发展，大力培育省级以上优秀版权示范企业和版权贸易基地。严厉打击文化市场的假冒伪劣侵权行为。（责任单位：市文广新局、市工商局、市委宣传部、市商务局）

（十）创新事中事后监管。完善文化贸易重点企业运行监测机制，综合文化产品和服务进出口的规模、结构、竞争力、国际流向等方面的信息，探索建立文化产品和服务进出口监测平台，形成各相关政府部门信息共享、协同监管，、社会公众参与监督的监管体系，确保国家文化安全。建立文化贸易市场主体信用记录，纳入无锡市信用基准评价系统，构建失信联合惩戒机制。（责任单位：市商务局、市文广新局、市工商局、市统计局、市税务局、无锡海关、市外管局）

三、保障措施

（一）健全工作机制。成立无锡国家文化出口基地建设推进工作领导小组，由市委分管领导任组长、市政府分管领导任副组长，宣传、商务、文广新、组织、教育、科技、财政、人社、工商、统计、旅游、外办、金融、税务、海关、外管等相关部门和各市（县）区、无锡经济开发区为成员单位，加强对全市文化贸易工作的指导和统筹协调。鼓励引导文化贸易企业组建行业协会，充分发挥其在优化信息服务、扩大国际交流、增强行业自律、维护企业权益等方面的作用。加强政府、行业协会、企业间的三方联动，整合各方力量，建立促进文化产业国际化发展的良好机制，合力推动全市文化贸易加快发展。

（二）加强抓实统计考核。全面落实商务部办公厅、中宣部办公厅、文化部办公厅、新闻出版广电总局办公厅、海关总署办公厅印发的《对外文化贸易统计体系（2015）》和国家统计局印发的《文化及相关产业分类（2018）》，进一步完善文化贸易重点企业信息库，在综合外汇管理部门国际收支平衡表（BOP）数据和海关进出口数据的基础上，加强文化贸易重点企业统计直报工作，积极探索建立文化贸易统计指标体系。加大对全市文化贸易发展的考核力度，强化相关部门和各市（县）区的责任意识。

（三）营造良好环境。进一步优化政府服务，加强土地、水电、人力资源等生产要素的配套供给，降低文化企业运营成本；加快文化领域“放管服”改革，依法依规放宽文化产业准入政策，降低门槛、简化程序，为文化企业营造更有吸引力的投资环境。开展多渠道、全方位开展文化贸易政策宣传，增进文化企业和文化工作者对文化贸易政策的了解，加强宣传推广和交流，形成全社会共同关注、支持文化贸易发展的良好氛围。

各市（县）区地区、市（县）区、各有关部门要按照本意见的要求，切实加强组织领导，明确任务，落实责任，完善和细化相关政策措施，扎实做好各项工作，确保基地建设取得实效。
