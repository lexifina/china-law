# 中共无锡市委办公室无锡市人民政府办公室关于印发《无锡市现代农业高质量发展行动计划》的通知

一、总体要求

以习近平新时代中国特色社会主义思想为指导，认真贯彻中央和省、市决策部署，牢固树立新发展理念，落实高质量发展要求，以实施乡村振兴战略为总抓手，以农业供给侧结构性改革为主线，以推进一二三产业融合发展为导向，深入实施产业强市主导战略和创新驱动核心战略，聚焦特色产业，聚集资源要素，强化创新引领，突出集群成链，延长产业链、提升价值链、完善服务链，培育发展新动能，不断扩大优质绿色品牌农产品比重，坚定不移走“产业结构优、质量效益高、经营主体强、装备技术精、路径模式新”的乡村产业发展道路。到2021年，我市农业产业布局进一步优化，特色产业优势进一步彰显，融合发展成效进一步显著，持续发展活力进一步增强，农村一二三产业融合发展增加值与农业增加值之比有较大幅度提高，农业增加值率、土地产出率、劳动生产率等主要指标保持全省前列，努力打造现代农业高质量发展的先导区、示范区、样板区。

二、主要行动

（一）产业提质行动

1. 优质稻米。全市水稻种植面积稳定在60万亩左右。重点推广南粳、苏香粳系列优质食味水稻种植。重点推进宜兴杨巷、宜兴芳桥、江阴华士、锡山东港等4个省级味稻小镇建设项目，争取再建成2个；推进无锡锡山国家级现代农业产业园水稻园和宜兴兴杨现代农业产业园、江阴华西现代农业产业园2个省级园区水稻项目建设；建设10个左右市级优质稻米产业基地，全市优质食味水稻推广面积占比达到65%以上。

2. 精细蔬菜。全市常年蔬菜面积稳定在20万亩左右，重点提升发展6.5万亩市属蔬菜基地。优化蔬菜产业结构，重点发展精品、特色蔬菜，支持蔬菜大棚等设施装备更新改造升级，推进江阴、宜兴、惠山蔬菜基地建设，培育壮大蔬菜生产龙头企业，提升地产蔬菜品牌价值，确保地产蔬菜质量，保障菜篮子供给和稳定菜篮子价格。

3. 特色果品。全市果品种植面积稳定在22万亩左右。重点发展水蜜桃、葡萄、杨梅、醉李、梨、枇杷等地方特色果品产业，鼓励发展樱桃、火龙果、百香果等新兴果品产业，推进产业集中，壮大产业规模。推进阳山蜜桃小镇、璜土葡萄小镇等省级特色小镇建设，推进大浮杨梅、鸿山葡萄、东港梨花、张渚板栗、太华青梅等产业特色小镇建设，发展规模化生产基地和龙头企业。

4. 名优茶叶。全市茶园面积稳定在8万亩左右。重点发展宜兴红、阳羡茶、无锡毫茶、太湖翠竹等区域公用品牌，整合茶叶资源，增强带动能力，提升品牌形象。加强茶叶生产基地改造，实行标准化、生态化生产，推进赏茶、制茶、品茶相结合模式，提升综合效益。支持茶叶龙头企业做大做强，发展产业化联合体，做强茶叶品牌。推进宜兴张渚、锡山斗山等茶旅文化小镇建设，提升融合发展水平。

5. 特种水产。全市水产养殖面积稳定在20万亩左右。进一步培育具有无锡区域特色的长江三鲜、太湖三白、河荡三青等三大系列特色水产品养殖。支持水产种苗培育，建设一批水产新品种繁育基地。推进工厂化水产养殖、生态综合种养等新型养殖模式发展，推动水产产业转型升级。

6. 花卉园艺。全市花卉种植面积在现有基础上进一步扩大，争取达到2万亩左右。支持花卉种子种苗产业发展，发展蝴蝶兰、兰花、月季、玫瑰等特色花卉产业，发展优质苗木及林下经济。培育花卉种业龙头企业。发展设施花卉种植，支持各类花卉主题园区建设。同时，统筹发展生态畜禽、特种养殖、品质药材、珍稀菌类等特色产业，不断优化我市农业产业结构。

（二）创新驱动行动

1. 推进“农业+”融合发展。加快深化“两大融合”，持续拓展乡村产业发展的广阔空间，以特色种养业为基础，通过生产经营方式创新提升、产业延伸、功能拓展、资源开发利用等途径，促进一二三产全面发展、融合发展。重点发展农业与文化、康养、教育、电商、休闲等产业融合，形成“农业+”多业态发展态势。到2021年，全市建设农村一二三产业融合发展项目20个以上。

2. 大力发展农产品精深加工。重点突破我市农产品加工转化能力的不足，着力培育有竞争力的农产品加工龙头企业，提升农产品加工转化附加值。在锡山国家现代农业产业园和宜兴现代农业产业示范园配套建设农产品加工集中区。围绕农业主导产业发展农产品精深加工，延长农业产业链。积极引进适应消费升级需求的农产品精深加工企业，提升产业层级，带动产业发展。推进实施一批农业龙头企业升级改造重点建设项目，到2021年，全市农业规模加工企业达到100家以上，农产品加工产值与农业总产值之比达到4.3:1。

3. 推进农业技术创新。着力完善现代农业产业技术体系，推进政产学研合作、农业产业技术创新战略联盟、现代农业众创空间建设。以企业为主体，围绕农业重点领域开展关键技术研发，组织实施一批农业科技项目。积极与南京农业大学、江南大学、中国水产科学研究院淡水渔业研究中心、江苏省农科院等高等院校、科研院所共建农业科技成果转化平台，定期组织农业科技成果信息交流，开展紧密合作。到2021年，组织实施农业科技创新重点建设项目15个以上。

4. 推进农机化和农机装备转型升级。围绕重点产业和重要作业环节，积极推进农机装备“两全”建设，实现粮食生产全程机械化，推进高效设施农业机械化作业全覆盖。围绕蔬菜全产业链示范推广先进适用机械装备，实现种植、收获等薄弱环节的突破；依托果品、茶叶等标准园、规模生产基地，开展重点基地机械化作业；开展自动化、智能化水产养殖设备应用推广；依托菜篮子工程蔬菜基地、重点果蔬产业基地，支持发展农产品粗加工，发展农副产品真空预冷、贮藏保鲜、清选、分级、烘干等机械装备。发展农产品质量追溯、农业物联网设施，提高农副产品附加值和经济效益。到2021年，全市农作物耕种收综合机械化率达到90%以上，其中主要粮食作物综合机械化率达到93%以上，设施农业、水产养殖、果茶和农产品初加工机械化率总体达到55%左右。

5. 推动智慧农业建设。大力实施数字农业战略，支持重点领域和重点主体加快应用物联网技术，着力提升农业数字化、网络化、智能化发展水平。加快建设无锡“农业云”，积极建设种植、养殖领域农业物联网创新中心，实施“互联网+”农业工程，推动物联网技术在大田种植、设施栽培、水产养殖、畜禽养殖、农产品质量安全等农业生产各领域各环节的推广应用，以信息化助推现代农业高质量发展。到2021年，组织实施智慧农业建设重点项目30个以上，培育一批农业物联网引领企业。6. 加快农产品品牌建设。发挥品牌引领作用，树立农业品牌建设的示范典型，加大品牌培育力度，加强品牌管理，提升品牌价值，增强市场竞争力。打造一批高品质、有影响的“老”字号、“锡”字号农业区域公用品牌、企业品牌和产品品牌“新三品”，促进农业质量效益提升。突出农产品区域公用品牌建设，积极组织开展农产品区域公用品牌征集工作，打造宜兴阳羡茶叶、杨巷大米、阳山水蜜桃等一批有影响力的农产品区域公用优秀品牌。到2021年，全市培育具有一定规模的农产品区域公用品牌10个以上，绿色食品、有机农产品总数达到300个以上，种植业绿色优质农产品比重达到60%以上。

（三）主体培育行动

1. 培育发展新型经营主体。大力培育提升专业大户、家庭农场、农民专业合作社、农业企业，做大做强农业产业化龙头企业。构建集约化、专业化、组织化、社会化相结合的新型农业经营体系。扶持发展农产品加工、流通和农业社会化服务，建设现代物流体系，健全农产品营销网络，建设标准化和规模化的原料生产基地。引进知名大型现代农业企业集团。清理空壳合作社，提升薄弱合作社。帮助大中专毕业生、新型职业农民、务工经商返乡人员领办农民合作社、兴办家庭农场。到2021年，培育市级以上农业龙头企业170家以上，市级以上家庭农场200家以上。

2. 培育发展农业产业化联合体。以农业龙头企业为核心，各类合作社、农场等新型农业经营主体参加，围绕重点主导产业，组建经营联盟，实现不同经营主体间的联合合作，促进小农户与现代农业有机衔接。到2021年，培育市级以上农业产业化联合体30家以上。

3. 培育发展新型农业服务主体。鼓励各类主体发展高端加工服务、流通服务、营销服务。以公共服务为依托、社会化组织为主体，健全专业高效的社会化服务体系。重点依托供销合作社经营网络，加快流通方式和业态创新，拓展供销合作社经营领域，由主要从事流通服务向全程农业社会化服务延伸、向全方位城乡社区服务拓展，在农资供应、农产品加工流通、农业科技服务等重点领域和环节为农民提供便利实惠、安全优质的服务。

4. 加强人才队伍建设。围绕产业发展需求，以打造农业高端人才、农业科技推广人才、新型职业农民为重点，全面加强农业人才队伍建设，重点培育壮大农业企业家队伍。着力引进农业高端人才、农业科技创新团队。大力开展农技推广人员岗位培训和专业技能培训，着力提高农技人才队伍建设水平。鼓励与农业高等院校合作办班、委托或定向培养等途径，集中培养一批农业生产经营后继力量。加强新型职业农民和乡土人才培育工作，提升从业技能和素质。到2021年，全市培育新型职业农民1万人次以上。

（四）载体建设行动

1. 推进农业产业强镇建设。把农业产业强镇建设放到各地构建现代农业产业体系、生产体系、经营体系中去系统谋划，大力培育乡土经济、乡村产业；建立完善农民利益联结机制，促进农民增收致富，确保广大农民尤其是小农户实实在在分享发展成果；整合相关渠道资金，聚焦产业发展的关键领域和薄弱环节加大投入力度，通过政府与社会资本合作、政府购买服务等方式，推动农业产业强镇发展。到2021年，建设国家级农业产业强镇、省级特色小镇（农业）10个以上。

2. 推进现代农业园区建设。确保无锡国家现代农业示范区建设和监测评价工作走在全国前列，确保无锡锡山国家现代农业产业园创建全省领先。继续抓好6家省级现代农业产业园建设和监测工作，抓好江阴华西、宜兴兴杨省级现代农业示范园建设，确保通过省级验收。深入推进“百企建百园”工程，吸引工商资本投资现代农业园区建设。到2021年，全市建成“百企建百园”现代农业园区100家以上。

3. 推进土地依法有序流转。在不违背承包农户意愿、不损害农民权益、不改变土地用途、不破坏农业综合生产能力和农业生态环境的前提下，稳妥推进土地依法、规范、有序流转，确保土地流转面积稳步增长、水平稳步提高，为现代农业规模化发展提供支撑。到2021年，全市农业规模化经营比重争取达到85%以上。推进农业适度规模经营，发展与农业产业业态相适应的多种形式规模经营，不断提高农业产出效益。充分发挥农村产权交易平台作用，规范流转交易行为，提高交易透明度和管理信息化水平。积极发挥金融保农护农作用，开展农村承包地经营权流转履约保证保险试点。

4. 推进农业开放合作。充分利用好国际国内“两种资源”“两个市场”，抓住“一带一路”发展的历史性机遇，做好我市农业开放合作的国际文章。积极走出去和引进来，与“一带一路”沿线国家开展市场拓展、技术合作、人才培养和信息交流。建设外向型农业园区和农产品供应基地，支持优势特色农产品走出国门。发挥无锡市农商协会和无锡市优农联盟两个重要平台的作用，支持企业引进国际资本、科技和人才，推动产业转型和高质量发展。

（五）绿色引领行动

1. 开展美丽田园建设。结合美丽乡村建设，统筹开展美丽田园建设。在耕地整理归并的基础上，按照净化、绿化、美化的要求，打造一批美丽田园项目，探索总结可复制推广的经验。到2021年，全市建成美丽田园项目10个以上。

2. 开展绿色生态循环农业建设。坚持绿色生态引领，积极探索建立适合我市特点的生态循环农业发展模式，推进种养产业合理布局和良性发展。全面优化产业功能布局，培育种养结合、生态循环、环境优美的循环农业发展典型。到2021年，全市化肥、农药施用总量在2018年基础上再分别降低3%以上。

3. 开展高标准农田建设。以永久基本农田保护区、粮食主产区和重要农产品生产保护区为重点，提高规划设计水平，加大投入力度，提高建设标准，充实建设内容，坚持建管并重，切实提升高标准农田建设和管理水平。到2021年，全市高标准农田比重达到85%以上。

4. 开展耕地轮作休耕。建立健全耕地轮作休耕体系，鼓励集中连片实施，有条件的地方以行政村为单位整建制推进。积极引导种植大户、农民合作社等新型农业经营主体参与，发挥示范带动作用。重点在太湖流域一级保护区进行轮作休耕模式探索，到2021年，争取全市耕地轮作休耕一遍。

三、保障措施

1. 坚持规划引领。围绕农业高质量发展目标，充分发挥规划重要引领作用，坚持多规合一、科学决策、统筹推进，着眼现有农地作用发挥和基本农田保护利用，优化农业结构调整空间布局和实施路径。按照先规划后建设的原则，根据五大行动，制定实施计划，细化工作措施，逐年组织推进，推动任务落实，提升工作成效。

2. 突出项目抓手。围绕现代农业高质量发展，狠抓农业领域重点项目建设，将各项重点工作目标任务落实到具体项目上，认真编制年度项目建设计划，推动各类项目落地落实。发挥好项目的示范带动作用，推动形成一批农业高质量发展示范典型、示范集群，充分展示无锡产业兴旺的良好形象。

3. 完善联农机制。进一步完善订单带动、利润返还、股份合作等新型农业经营主体与农户的利益联结机制，让农民成为现代农业发展的参与者、受益者。支持龙头企业与农户共同设立风险保障金。允许将财政资金特别是扶贫资金量化到农村集体经济组织和农户后，以自愿入股方式投入新型农业经营主体，让农户共享发展收益。

4. 强化政策保障。强化用地保障，积极探索针对现代农业高质量发展的“点供”政策；依法依规开展农村集体经营性建设用地入市改革；有序开展县域乡村闲置集体建设用地、闲置宅基地、村庄空闲地、厂矿废弃地、道路改线废弃地、农业生产与村庄建设复合用地等土地综合整治，盘活建设用地重点用于乡村新产业新业态和返乡入乡创新创业；完善我市设施农业用地管理办法。加大财政资金整合力度，优化支出方向，重点用于支持现代农业高质量发展项目建设。用足用好无锡乡村发展振兴投资基金，支持现代农业相关项目建设。支持小微企业融资优惠政策适用于乡村产业和农村创新创业，强化省农担公司无锡分公司及市“惠农贷”风险补偿基金的担保融资增信功能，鼓励通过实施担保费用补助、业务奖补等方式支持乡村产业贷款担保，拓宽担保物范围，加大乡村产业项目融资担保力度。支持和培育我市符合条件的农业企业在境内外上市融资。

5. 加强组织协调。建立健全农业农村部门抓总，相关部门协同配合、社会各界积极参与、农民群众充分得益的工作机制。加强农业高质量发展统计监测工作，明确统计口径，完善监测体系，强化阶段性推进和年度考核。各地要围绕发展规划和目标，细化各项工作举措，明确主攻方向和重点环节，突出典型培育，安排好阶段性工作任务，落实好具体工作举措，着力解决实际工作中遇到的困难和问题。突出农民和农业企业的主体地位，集聚先进要素，凝聚发展合力，增强农业农村发展新动能。
