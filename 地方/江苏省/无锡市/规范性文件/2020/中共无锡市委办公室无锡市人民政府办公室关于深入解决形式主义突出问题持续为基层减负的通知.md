# 中共无锡市委办公室无锡市人民政府办公室关于深入解决形式主义突出问题持续为基层减负的通知

2019年，全市上下以无锡列入中办统计样本城市为契机，以开展“不忘初心、牢记使命”主题教育为动力，认真贯彻落实“基层减负年”各项措施，制定下发“减负21条”，着力解决困扰基层的形式主义突出问题，取得了明显成效。2020年是高水平全面建成小康社会和“十三五”规划收官之年，也是统筹推进疫情防控和经济社会发展的大考之年，各项工作任务艰巨繁重，更加需要以优良作风狠抓工作落实。根据《中共中央办公厅关于持续解决困扰基层的形式主义问题为决胜全面建成小康社会提供坚强作风保证的通知》、《中共江苏省委办公厅关于深入解决形式主义突出问题持续为基层减负的通知》要求，紧密结合无锡实际，我市深入解决形式主义突出问题、持续为基层减负工作工作总的要求是：深入学习贯彻习近平总书记关于持续为基层松绑减负的重要指示批示精神，全面贯彻落实党中央和省委、省政府决策部署，坚持标准不降、力度不减，紧盯老问题和新表现，全面检视、靶向治疗，坚持减负和减压并重，加强源头治理和制度建设，着力在巩固拓展上下功夫、见实效，进一步把广大基层干部干事创业的手脚从形式主义的束缚中解脱出来，为高水平全面建成小康社会、建设“强富美高”新无锡、当好全省高质量发展领跑者提供坚强有力的作风保障。

一、持续筑牢克服形式主义的思想政治根基

1. 巩固拓展“不忘初心、牢记使命”主题教育成果。深学笃行习近平新时代中国特色社会主义思想，把深入解决形式主义突出问题、持续为基层减负工作作为树牢“四个意识”、做到“两个维护”的重要标杆，不断增强克服形式主义的思想自觉和行动自觉。将力戒形式主义官僚主义纳入不忘初心、牢记使命的制度体系，深入抓好市委《关于在“不忘初心、牢记使命”主题教育中专项整治形式主义官僚主义加重基层负担问题的实施方案》的贯彻落实，建立健全理论学习、检视问题、抓实整改长效机制。组织各级干部深入学习习近平总书记关于力戒形式主义官僚主义重要论述选编，推动广大党员干部在严格党内政治生活中锤炼坚强党性，做到讲政治、践初心、担使命。

2. 牢固树立正确政绩观。教育引导党员干部始终坚持实事求是的思想路线，始终牢记人民利益高于一切，切实把对上负责与对下负责统一起来。把学习贯彻新发展理念作为干部教育培训的重要内容，健全完善符合新发展理念要求、体现高质量发展领跑者导向的综合考核指标体系，引导各级干部更加自觉地贯彻落实新发展理念，坚定不移用以破解难题、推动发展。

二、坚决纠治决策落实中的形式主义问题

3. 完善推动重大决策部署落实机制。加强政治监督，深入排查各地区各部门在贯彻落实党的理论和路线方针政策上存在的政治偏差，着力纠治“不用心、不务实、不尽力”等问题，严肃查处不敬畏不在乎、空泛表态、敷衍塞责、弄虚作假、阳奉阴违行为，完善推动中央和省决策部署落实机制。加强对习近平总书记重要指示批示精神贯彻落实情况的督促检查，完善清单管理、推动落实、监督检查等工作机制，确保总书记重要指示批示精神在无锡落地生根。

4. 着力破除疫情防控、脱贫攻坚等工作中的形式主义。围绕统筹疫情防控和经济社会发展各项政策措施的落地落实，实行跟进监督、精准监督和全程监督。加强对疫情防控、复工复产工作中发文开会的统筹管理，召开会议尽量采用网络视频等形式，减少疫情期间人员聚集，防止多头重复向基层派任务、要表格。精准施治脱贫攻坚中的形式主义官僚主义问题，对搞数字脱贫、虚假脱贫的严肃问责。

三、有效防止文山会海反弹回潮

5. 进一步精简文件。市级层面继续发挥示范带动作用，守住精简文件的硬杠杠，对各地区各部门发文情况实施动态监测、及时预警，确保发至县级的文件比2019年只减不增。既严控向县级以下发文数量，又要精简基层向上级报文的数量。重点控制县一级对下发文数量，确保年内发至镇（街道）的文件比2018年减少三成以上。严格控制表格数量，年内省市要求县级以下填报的表格要比上年有较大幅度减少。着力提升文件质量，严格按规定控制文件篇幅，不发不切实际、内容空洞的文件。对在发文方面改头换面、明减实不减的，及时督促纠正。

6. 从严控制会议数量。制定落实会议年度计划，加强动态监测预警，确保各级会议数量比2019年只减不增。重点加强县一级会议管理，要求镇（街道）党政主要负责同志参加的会议，原则上每周不超过1次。进一步提升会议质量，不开应景造势、不解决问题的会议。严格落实8月份“无会月”制度，原则上除重大紧急事项外，市级层面不召开全市性会议。

四、切实规范面向基层的督查考核工作

7. 严格计划备案管理。加强督查检查考核计划管理和监督执行，确保市和市（县）区各级的督查检查考核事项比2019年只减不增。纳入市级计划的督查检查考核事项，不得要求基层配套开展。从市级督查检查做起，持续改进方式方法，从以明查为主向明查暗访相结合转变，切实提高督查检查的精准度和实效性，注意纠正阵仗声势大、层层听汇报、大范围索要台账资料等做法。完善年度综合考核办法，优化季度监测、半年评估和年终考核，对现场考核内容实行申报审核制度。推动相关部门督查检查考核结果互认互用，加大基层对上级机关反向评议力度。

8. 巩固专项整治成果。对清理整合后保留的“一票否决”、签订责任状事项以及面向基层的创建示范活动，实行清单管理；清单以外的，不得违规开展。在村（社区）办公场所“牌子乱象”专项清理基础上，严格落实准入机制，强化长效监管，对发现的违规授牌挂牌问题及时责令整改。坚决纠正过度留痕，优化工作评价标准和方法，科学合理使用微信工作群、政务APP。清理规范基层政务新媒体，对功能定位相近、用户关注度和利用率较低、基层无力维护的政务新媒体，要清理整合。

9. 减轻企事业单位负担。高度重视并着力解决出现在企业、学校、医院、科研单位的形式主义官僚主义问题，编制实施针对企事业单位的监管检查事项清单，严格“照单检查”、依法监管，避免“多头执法、多层执法、随意执法”。聚焦生态环境、安全生产等重点领域，整合监管业务系统，构建省市一体化在线监管平台。深化拓展“放管服”改革，推进“互联网+服务”系统建设，让“数据”多“跑腿”，让干部群众少“跑路”。

五、进一步提高调查研究实效

10. 加强调研统筹。充分发挥市委、市人大、市政府、市政协秘书长和办公室主任联席会议制度作用，对市领导有关调研活动进行统筹安排，避免同一时间到同一地方扎堆调研。下基层调研要轻车简从，不搞层层陪同，不得要求主要负责同志出面接待。省市主要领导到基层调研，严禁下级板块主要领导接送站、搞宣传指示牌等形式主义。市主要领导到基层考察调研，市（县）区陪同的负责同志不超过3人，镇（街道）只安排1位负责同志陪同；其他市领导到基层考察调研，市（县）区、镇（街道）分别只安排1位负责同志陪同。市级机关部门要统筹安排好本单位的调研活动，减少一般性工作调研，防止扰乱基层正常工作秩序。

11. 改进调研方式。调查研究要发扬求真务实作风，坚持问题导向，大力倡导“四不两直”方式，更多开展随机调研、蹲点调研、解剖麻雀式调研，在求深、求实、求细、求准、求效上下功夫，察实情、听真话、取真经，不作秀、不走“经典路线”。市级机关制定政策要全面深入了解实际情况，注意倾听基层干部群众意见，了解政策措施落实中存在的问题和不足，着力增强决策服务的针对性和可操作性。政策执行中要注意听取基层干部群众意见，适时调整完善。

六、健全完善干部担当作为激励机制

12. 树立担当干事的鲜明用人导向。深化理想信念教育，加强治理能力和专业能力培训，使广大党员、干部深刻认识到减负不是减担当、减责任，更不是降低工作标准和要求，自觉把初心落在行动上、把使命担在肩膀上，提高担当作为的真本领。深化落实“五突出五强化”选人用人机制，强化综合考核结果运用，注重在疫情防控、复工复产、应急处突、打好三大攻坚战等重大斗争中考察识别干部，把“愿作为、能作为、善作为”的干部选出来用起来，大力激发广大干部锐意进取、担当作为的精气神。将“三项机制”充分运用到干部队伍建设中，市级层面编发一批典型案例，推动各地区各部门各单位真正为担当者担当、为负责者负责。

13. 加大对基层干部关心爱护力度。深入实施公务员职务与职级并行制度，职级晋升向在疫情防控和基层一线作出突出贡献的人员倾斜。落实公务员及时奖励《办法》，突出时效性，加大激励力度。加强对基层干部特别是困难艰苦地区和疫情防控、脱贫攻坚一线干部的关心关爱，把带薪休假、津补贴等待遇保障制度落到实处。推动村（社区）书记激励保障《实施细则》落到实处，完善企业年金制度。全面落实社区工作者薪酬制度，建立自然增长机制，对街道社区企业身份聘用人员及社工人员实行加班轮休及加班补贴政策。

14. 精准审慎实施谈话函询和问责。加强对信访举报的综合研判，对举报反映仅列出违纪或职务违法、职务犯罪行为名称但无实质内容的不予受理，避免不必要的函询。着力提高问责的精准度，坚持实事求是、依规依纪依法，运用好监督执纪四种形态，让被问责者心服口服。纪检监察机关要加强对举报行为的分析甄别，注意发现异常举报行为，有重点地进行查处；属于诬告陷害的，要依规依纪依法严肃处理，并对查处的诬告陷害典型案件通报曝光。正确对待、合理使用被问责和受处分的干部，做好受处理处分干部重新任用请示报告审核工作，严格认定标准和区分不同情形，对影响期满、表现突出的干部，该用的大胆使用，最大程度保护干部积极性。

七、深化治理改革向基层放权赋能

15. 精准有效推进放权。贯彻中央、省决策部署，研究制定加强基层治理体系和治理能力现代化建设的政策文件，推动构建党的领导、人民当家作主和依法治理有机统一的基层治理体制机制。市和市（县）区两级根据省级《赋予乡镇（街道）经济社会管理权限指导目录》，因地制宜制定赋权清单，推动更多社会资源、管理权限和民生服务下放到基层。建立健全镇（街道）权力清单，稳步推进“放管服”改革综合授权。加强政务服务事项标准化建设，推进省市县三级政务服务无差别办理。

16. 科学规范“属地管理”。厘清不同层级、部门、岗位之间的职责边界，按照权责一致要求，建立健全责任清单，防止层层向基层转嫁责任。市级编制实施乡镇、街道属地管理事项主体责任和配合责任清单，各市（县）区确需委托或交由基层行使的职能事项，需报市级机构编制部门审核，并由市（县）区党委政府批准实施。进一步推进社区工作准入机制和合法性审查措施，强化“双向评议”、居民满意度测评等约束机制，切实抓好《村（社区）盖章事项清单》《村（居）民委员会依法履行职责事项清单》和《村（居）民委员会依法协助工作事项清单》的贯彻落实，推动村（社区）工作依法准入、规范准入。

17. 增强社区服务功能。加强社区平台建设，落实基层基本公共服务功能配置标准。健全城乡社区服务体系，满足不同群体的多样化服务需求，推进政府向社会力量购买服务，提高社区服务社会化水平。促进社区政务及公共服务资源整合共享、业务协同联动，完善面向居家养老、家政服务、社区电子商务等领域的各类信息服务载体，提升社区服务效能。

18. 强化镇（街道）财力保障。市与市（县）区两级进一步推进事权与支出责任改革，完善转移支付制度，深入实施市区镇（街道）基本公共服务均等化财力保障机制奖补机制，重点扶持财力薄弱、刚性支出压力较大的镇（街道），提高镇（街道）财政保障运行和服务发展能力。

19. 充实基层工作力量。公务员招录计划向镇（街道）倾斜，做好定向招录工作。未经县级党委组织部门同意，上级机关不得从县乡机关借用人员，新录用镇（街道）公务员未满最低服务年限的，不得交流或借用到上级机关。推进编制资源向基层倾斜，按照“编随事走”的原则，从上往下跨层级调剂行政编制和全额拨款事业编制给镇（街道）。大力推进事业单位调整优化，推动机构编制资源向发展最吃劲的部位流动、向最繁忙的一线倾斜，着力补齐公共卫生、公共安全、应急管理等领域短板弱项。深化拓展村（社区）党组织带头人队伍建设工程，落实“县乡共管”制度，加大后备干部队伍建设力度。

20. 加强基础数据信息共享。加快城市大数据中心建设，扎实构建全市统一的数据共享交换体系，推进有关社会治理信息系统互联互通、数据赋能、精准推送，提高基层社会治理信息化服务效能。健全完善城管、综治、12345热线等政务工作平台，持续优化网格化社会治理项目，加快形成“基层吹哨、部门报到”工作格局，切实减轻基层社区网格员工作负担。

八、坚持以上率下狠抓工作落实

21．加强组织领导。充分发挥市和市（县）区整治形式主义突出问题为基层减负领导小组的作用，加强统筹协调和督促指导，健全工作机制，推动工作落实。各地区各部门党委（党组）要切实履行主体责任，及时制订和落实具体工作方案，坚持一级做给一级看，抓好本级带下级。

22．健全长效机制。把防止和克服形式主义官僚主义融入巡察检查、党委督查、干部考察考核、民主生活会、年度述职等制度，推动政治监督和政治督查常态化、长效化。总结推广一批勇于担当、一心为民、真抓实干的好经验好典型，通报曝光一批形式主义官僚主义典型案例。

23．注重实干实效。市级机关部门要发挥示范带头作用，落实改变工作作风的硬措施，着力解决形式主义突出问题，持续为基层减负。各级党委（党组）要统筹抓好为基层减负工作和年度各项重点工作，奋力夺取疫情防控和经济社会发展双胜利。

以上通知，请认真贯彻执行。
