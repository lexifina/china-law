# 泰州市姜堰区人民政府关于加强企业用工服务工作的意见

（泰姜政规〔2019〕3号）

各镇（街道）人民政府（办事处）、各园区管委会、区有关委办局、区有关单位：

为进一步优化营商环境，促进我区经济高质量发展，切实帮助企业缓解用工难问题，推进强富美高新姜堰建设，现结合当前工作实际，提出如下意见：

一、建立用工需求预报制度

1. 建立重大项目用工评估制度。对拟落户我区的重大项目进行可行性评估时，对项目的预期人力资源需求、就业岗位、职业技能要求等一并开展评估、谋划。（发改委、人社局）

2. 建立企业用工需求信息库。重点收集企业用工量、工种、待遇等方面的基础数据，定期汇总企业用工需求信息，并通过区、镇（街道）、村（居）三级平台、报刊、“姜堰智慧就业”APP等媒介及时发布。（人社局、工信局、各镇街园区）

3. 建立企业用工监测制度。将全区支柱重点以上企业纳入用工监测范围，定期对企业的基本情况、缺工人数、工资水平、人员构成及增减等情况进行监测，分析研判企业用工趋势，指导企业制定用工预案。将缺工50人以上的企业列为重点服务企业，实施“一企一策”，提升精准服务效率。（人社局、工信局、各镇街园区）

二、加强用工服务平台建设

4. 发挥公共人力资源服务机构作用。公共人力资源服务机构定期组织开展大型、专场、联动等各类人力资源交流洽谈会。利用公共就业服务网，线上线下齐发力，打造 “现场招聘+网络招聘”多元模式，促进供需双方有效对接。（人社局）

5. 加强劳务合作基地建设。深入推进劳务合作基地建设，定期组织用工需求较大的企业赴劳务合作基地开展现场招聘和劳务洽谈活动，引导外地劳动力来姜就业。鼓励企业与区内外职业院校合作，采取“订单+冠名”式的人力培养模式，为企业培养人力资源。利用周边人力资源产业园的辐射效应，引进高端人力资源机构来我区设立分公司，实现人力资源服务共享。（人社局、各镇街园区）

6. 引导外出务工人员返乡就业创业。充分依托人力资源和社会保障基层服务平台，利用节假日、农忙季节等外出务工人员返乡之际，在行政村（居）通过广播、公告栏、宣传车等途径，发布企业用工需求信息，宣传就业创业政策，引导农民工在家门口就业创业。（人社局、各镇街）

三、进一步优化用工环境

7. 发挥企业用工主体作用。充分发挥市场在人力资源配置中的决定性作用，强化企业招工、用工的主体责任。树立以人为本、立足长远的用工理念，依法实施劳动保护、社会保障，提升薪酬待遇，加强用工安全管理，改善生产、生活环境。加强企业文化建设，强化外来务工人员的人文关怀，完善员工培训与培养机制，实现待遇留人、感情留人、事业留人。（区用工服务工作领导小组成员单位、各镇街）

8. 优化外来务工人员服务。相关部门要做好外来务工人员的后勤保障工作，开通绿色通道，为他们提供落户、入学、就医、购房、援助等方面的优质服务。（区用工服务工作领导小组成员单位、各镇街）

四、加大资金政策扶持力度

9. 场租、物管、水电等费用补贴。对在我区设立分公司，每年为我区企业提供人力资源50人以上并在我区缴纳社会保险满6个月的区外人力资源服务机构，自公司注册之日起3年内，给予场租费、物管及水电等费用补贴，最高每年不超过2万元。（人社局、财政局）

10. 人力资源输送补贴。鼓励各类服务机构、职技院校积极为我区企业输送人力资源。各类服务机构、职技院校同一年度组织50人以上区外人力资源初次到我区企业就业并缴纳社会保险满6个月的，按照不高于500元/人给予补贴，重复输送人员不予补贴。（人社局、财政局）

11. 企业稳岗补贴。依法参加失业保险并按时缴纳失业保险费、上年度末未裁减人员或裁员率低于我区城镇登记失业率且财务制度健全、管理运行规范的企业可享受企业稳岗补贴，补贴标准为企业及其职工上年度实际缴纳失业保险费总额的50%。（人社局、财政局）

12. 企业社会保险补贴。鼓励企业招用就业困难人员，与之签订劳动合同并缴纳社会保险费的，按实际缴纳的社会保险费给予企业最长不超过3年的社会保险单位缴纳部分补贴。（人社局、财政局）

13. 岗位技能提升补贴。依法在我区参加失业保险且累计缴纳失业保险费12个月以上的企业职工，参加技能提升培训，取得《职业资格证书》的，初级（五级）给予600元补贴、中级（四级）给予1000元、高级（三级）给予1200元补贴，纳入我区急需紧缺职业（工种）目录的，补贴标准可在培训鉴定成本范围内按规定上浮。（人社局、财政局）

14. 考核奖励。每年年底对各类服务机构按输送人员数量、员工流失率、处理突发事件等情况进行考核奖励，组织50人以上稳定就业满一年的，给予20000元奖励；组织100人到200人稳定就业满一年的，给予40000元奖励；组织200人到300人稳定就业满一年的，给予60000元奖励；组织300人以上稳定就业满一年的，给予80000元奖励。（人社局、财政局）

五、强化用工服务组织保障

15. 健全组织领导。企业用工服务工作是我区一项重点工作，各镇（街道）负责企业用工服务的具体组织实施，重点做好人力资源的储备和招引工作。企业用工服务工作领导小组成员单位应发挥联动作用，扎实推进各项工作，切实解决企业用工过程中的实际困难。（区用工服务工作领导小组成员单位、各镇街）

16. 加强企业管理。因企业原因发生重大劳资纠纷、拖欠工资以及安全生产教育、培训保障措施不到位的，不在补贴范围内；对在补贴过程中弄虚作假的，追回已发放奖补资金，并依法追究相关责任主体的法律责任。（人社局）

17. 保障资金渠道。财政部门负责奖补资金的调度和安排。（财政局）

18. 强化资金监管。加强企业用工服务补贴资金的审计和监察，并定期开展专项审计。（监委、审计局）

本意见由区人社局负责解释，自2019年7月1日起施行。

泰州市姜堰区人民政府

2019年6月5日
