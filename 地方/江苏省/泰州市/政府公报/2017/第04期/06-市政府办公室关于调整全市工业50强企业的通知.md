# 市政府办公室关于调整全市工业50强企业的通知

各市（区）人民政府，泰州医药高新区管委会，市各有关部门（单位），工业50强企业：

2016年，在全球经济低位徘徊、国内经济增速换挡的背景下，全市工业企业积极应对经济下行压力，主动适应、引领经济发展新常态，大力实施创新驱动发展战略，着力提升供给质量和效率，不断开拓国际国内市场，保持了平稳较快发展，规模实力持续壮大，质量效益明显提升。

根据50强企业滚动发展、动态管理的原则，经市政府研究决定，明确扬子江药业集团有限公司等企业为全市工业50强企业。希望各地、各有关部门进一步加大对50强企业的指导和服务，落实相关政策，为50强企业营造良好的发展环境。各50强企业要积极抢抓机遇，率先转型发展，努力做优做强，不断增强对全市工业经济发展的带动力和支撑力，为全市工业实现具有转型创新含金量的发展作出新的更大的贡献。

附件：全市工业50强企业名单

泰州市人民政府办公室
