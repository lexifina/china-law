# 市政府关于公布2017年泰州市政府重大行政决策事项目录的通知

各市（区）人民政府，泰州医药高新区管委会，市各委、办、局，市各直属单位：

为规范市政府重大决策行为，促进依法决策、科学决策、民主决策，提高决策质量和效率，根据《泰州市重大行政决策事项管理办法》，市政府办公室编制了《2017年泰州市政府重大行政决策事项目录》，并经市委、市政府研究同意，现予公布。请各地、各有关部门按照有关程序规定和要求，认真做好目录事项的起草、决策、实施等各项工作。
