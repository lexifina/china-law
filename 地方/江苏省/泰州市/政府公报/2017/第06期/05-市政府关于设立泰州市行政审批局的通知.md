# 市政府关于设立泰州市行政审批局的通知

各市（区）人民政府，泰州医药高新区管委会，市各委、办、局，市各直属单位：

根据省委办公厅、省政府办公厅印发的《关于同意无锡等地相对集中行政许可权改革试点方案的复函》（苏办〔2017〕12号）精神和《省编办关于明确泰州市政务服务中心机构规格的批复》（苏编办复〔2017〕48号），设立泰州市行政审批局，为市政府工作部门；将原在市政务办挂牌的市政务服务中心改为单设，为市行政审批局的下属事业单位，机构规格相当于正处级。

市行政审批局主要负责市级相关部门划转行政审批事项的审批职责。市政务服务中心主要承担组织、协调、监督、考核、管理进驻中心的部门和单位依法、高效办理行政审批和公共服务事项。

泰州市人民政府
