# 关于印发《泰州市2019年农村人居环境整治实施方案》的通知

各市（区）委农村工作领导小组，市级机关有关部门：

现将《泰州市2019年农村人居环境整治实施方案》印发给你们，请遵照执行。

中共泰州市委农村工作领导小组

2019年4月9日

泰州市2019年农村人居环境整治实施方案

为认真贯彻中央、省、市农村工作会议精神，切实打好农村人居环境整治这个实施乡村振兴战略的“第一仗”，根据相关文件要求，结合实际，制定我市2019年农村人居环境整治实施方案。

一、总体要求

坚持以习近平新时代中国特色社会主义思想为引领，自觉践行“绿水青山就是金山银山”的发展理念，学习借鉴浙江省“千万工程”经验做法，坚持以农民为中心，突出“补短板、强弱项、抓重点”，从农民群众反映和需求最强烈的问题入手，将农村垃圾、污水、厕所粪污治理和村容村貌提升作为主攻方向，整合政策，汇聚资源，强化措施，持续改善和提升农村人居环境，满足广大农民日益增长的美好生活需要，为高水平全面建成小康社会、建设“强富美高”新泰州、促进乡村全面振兴奠定坚实基础。今年要完成70%以上的整治任务。

二、重点任务

1.全面开展村庄“三清一改”行动。根据省委农办等17个部门联合印发的《江苏省农村人居环境整治村庄清洁行动方案》统一部署，以“清洁村庄助力乡村振兴”为主题，动员广大农民群众重点开展“三清一改”行动，即清理农村生活垃圾，清理村内塘沟，清理畜禽养殖粪污等农业生产废弃物，改变影响农村人居环境的不良习惯。实现村庄内垃圾不乱堆乱放，污水无乱泼乱倒，粪污无暴露，杂物堆放整齐，房前屋后干净整洁，村庄环境干净、整洁、有序，村容村貌明显提升，长效保洁机制建立，村规民约普遍形成，村民清洁卫生文明意识普遍提高。

2.突出主攻“村庄污水治理”短板。把2019年作为“村庄生活污水治理突破年”，全面启动村庄污水治理市（区）一体化建设，全力推进PPP项目落地生根。建制镇污水集中处理率达75%以上，全市40%的行政村建有生活污水处理设施。指导各地统筹实施市（区）、乡镇、村区域治理，实现污染治理与资源利用相结合、工程措施与生态措施相结合、集中与分散相结合，切实提高治理成效。坚持先建机制、后建工程，建立常态化、长效化的运行维护机制，确保村庄污水治理设施一次建成、长久使用。

3.全面推进“1123”示范镇村建设工程。围绕“乡村振兴走在全省前列”的目标定位，坚持把实施乡村振兴战略作为全市农业农村工作的总抓手。在全市启动实施100个乡镇集镇区、100个示范引领村、200个特色发展村、300个集聚提升村的“1123”工程建设计划。集镇区整治重点围绕生活垃圾、辖区河道、乱堆乱放、占道经营、户外广告、各类杆线、建设工地、交通秩序八个方面，同时注重提升基础设施建设水平和公共服务水平。按照乡村振兴“产业兴旺、生态宜居、乡风文明、治理有效、生活富裕”的要求，对100个示范引领村（含特色田园乡村）、200个特色发展村、300个集聚提升村，制订标准，明确任务，分层次、分类别、分区域梯次推进创建工作，形成“点上有精品、线上有风景、面上百花园”的区域格局，打造泰州乡村振兴工作的特色。各市（区）自今年起全面启动“1123”示范镇村工程建设。其中，30%的乡镇今年完成集镇整治和建设任务，40%的村完成示范创建任务（即今年创建40个示范引领村、80个特色发展村、120个集聚提升村）。

4.提升村容村貌。开展农村道路环境综合整治，持续推进“四好农村路”建设。完善通村组道路、入户道路建设，充分利用本地资源，合理选择路面材料，基本解决村内道路泥泞、村民出行不便等问题。开展农村危房、破旧房、空关房调查，分别加强修缮整治、拆破让地、合理利用。整治乱拉乱接，鼓励有条件的村庄开展各类杆线整理。充分利用房前屋后等零散土地种植乡土植物和果蔬作物，鼓励庭院绿化，开展庭院美化行动。因地制宜组织开展植树绿化活动，优选生态环境基础良好、积极性较高、具有一定规模的自然村庄开展绿化示范村建设。有序完善村庄公共照明设施。深入开展城乡环境卫生整洁行动，推进卫生乡镇、卫生村和健康乡村争创工作。深入开展乡村生态文明建设示范活动。

5.引导养成人人爱护农村环境的良好习惯。制定有利于养成人人爱护农村环境良好习惯的村规民约，引导群众自觉形成良好的生活习惯。加强健康教育工作，广泛宣传卫生习惯带来的好处和不卫生习惯危害影响，提高村民清洁卫生意识，营造形成良好习惯的浓厚氛围。采取多种形式，鼓励村委会与村民签订形成良好习惯的公约，开展良好习惯文明家庭评定活动，树立先进典型，形成示范效应。

三、保障措施

1.切实加强组织领导。农村人居环境整治行动由市农业农村局牵头指导推动，各有关部门按照农村人居环境整治职责分工参与组织实施。各地要将此项工作纳入党委政府重要议事日程，统筹推进村庄清洁整治各项行动。市（区）党委政府主要负责同志要亲自部署、亲自动员、亲自推动，切实抓好组织实施工作。乡镇、村的党组织书记担任村庄清洁“指挥长”，负责辖区的村庄清洁行动。各地要加强督促检查，发现问题，及时解决。要建立按季督查通报、半年考核排名制度，确保任务明确、责任落实、有序推进。

2.制定年度行动计划。各市（区）要在摸清底数、总结经验的基础上，抓紧编制当地2019年农村人居环境整治行动计划。行动计划要明确年度具体目标、重点工作任务（尤其要突出明特色、强弱项、补短板）、牵头单位及责任单位、时间安排、资金筹措方案、农民参与机制、考核验收办法等内容，尽可能深化、细化、具体化。

3.加强督查考核验收。将农村人居环境整治行动纳入城乡建设高质量发展评价指标体系和乡村振兴考核体系，作为对市（区）、机关部门及个人综合绩效考核的重要内容。相关部门定期组织督查指导和考核评估，评估结果向市委、市政府报告，向市（区）党委、政府通报，并以适当形式向社会公布。考核评估结果与市级考核激励资金和支持政策直接挂钩。

4.发挥基层组织作用。发挥村级党组织战斗堡垒作用、党员干部模范带头作用，发动群众、组织群众，确保各项整治任务落地见效。健全村民自治机制，充分运用“一事一议”民主决策机制，完善农村人居环境整治公示制度，保障村民权益。鼓励农村集体经济组织通过依法盘活集体经营性建设用地、空置农房及宅基地使用权等途径，多渠道筹措资金，用于农村人居环境整治与美丽乡村建设，营造清洁有序、健康宜居的生产生活环境。

5.加快构建长效机制。鼓励各地建立健全村庄公共环境保洁制度，推动形成民建、民管、民享的长效机制。鼓励各地进一步完善村规民约，明确村民维护村庄环境的责任和义务，实行“门前三包”制度，切实增强农民群众自觉性和主动性，持续开展各项整治工作，确保村庄常年保持干净、整洁、有序。鼓励各地结合美丽乡村建设、绿美乡村创建等，激励引导农民群众主动爱护和维护环境卫生，培养良好卫生意识和文明生活习惯。
