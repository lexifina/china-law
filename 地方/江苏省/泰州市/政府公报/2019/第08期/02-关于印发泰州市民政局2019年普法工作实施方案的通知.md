# 关于印发泰州市民政局2019年普法工作实施方案的通知

机关各处室、局属各单位：

现将《泰州市民政局2019年普法工作实施方案》印发给你们，请结合实际认真抓好落实。

泰州市民政局

2019年7月31日

泰州市民政局2019年普法工作实施方案

为深入贯彻落实国家机关“谁执法谁普法”责任制，根据泰州市法宣办、司法局《关于印发的通知》（泰法宣办〔2019〕10号）和《泰州市国家机关“谁执法谁普法”普法责任制实施办法》（泰办发〔2018〕24号）文件精神，结合我局实际，现就2019年度普法工作制定如下方案。

一、指导思想

全面贯彻党的十九大和十九届二中、三中全会精神，坚持以习近平新时代中国特色社会主义思想为指导，围绕“加大全民普法力度，建设社会主义法治文化，树立宪法法律至上、法律面前人人平等的法治理念”的要求，结合民政工作实际，进一步突出重点、健全机制、注重实效，全面推行以案释法，推动执法、服务、管理与普法的深入融合，为深入推进和谐泰州建设营造良好的法治环境。

二、工作任务

（一）积极开展普法服务“新八进”活动

各相关责任处室（单位）要深入贯彻落实《关于开展普法志愿服务“718行动”的实施意见》，有针对性地开展普法志愿服务进新时代文明实践中心（所、站）、进园区、进企业、进乡村、进学校、进家庭、进公共场所、进单位活动，形成普法服务“新八进”格局。宣传重点内容包括：1.党的十九大和十九届二中、三中全会精神，以及“习近平总书记全面依法治国新理念新思想新战略”；2.宪法、党内法规及其他国家基本法律；3.村民委员会组织法、城市居民委员会组织法、婚姻法、殡葬管理条例、社会救助暂行办法等重点法律法规；4.其他相关的法律法规。

（二）全面落实以案释法制度

按照市法宣办《关于在全市建立“以案释法”工作制度的实施意见》（泰法宣办〔2015〕13号）文件要求，严格落实以案释法主体责任，健全完善以案释法工作机制，建立典型案例收集、整理、筛选工作机制，建立定期发布、宣讲、季度报表等制度，建立典型案例库，依托“以案释法”宣讲队，常态化推进“以案释法基层行”活动。各相关责任处室（单位）每年报送网站以案释法案例不少于4例，“以案释法基层行”宣讲活动不少于2次，在市级新闻媒体制作以案释法类节目（栏目）每季度不少于1期，向市法宣办报送征集评选以案释法、法治宣传教育活动和法治创建典型案例各1例。

（三）大力推进法治文化建设

1.强化民政系统内普法教育工作。着眼于单位法治建设的薄弱环节，结合我局工作实际做好相关法律法规政策的教育培训工作。办公室重点抓好干部职工学法，举办“法治大讲堂”活动不少于2次，全体工作人员学法不少于40学时，确保全体人员法宣在线平台学习不少于5000积分。人事教育处组织党委中心组专题学法不少于2次，依托道德讲堂开设法治专场不少于1次，增加法律知识问答、法律宣传等法治教育环节。社会救助处依托民政助理培训班，对全市民政助理开展1次普法讲座。

2.加大基层群众法治宣传力度。依托网站、“泰州民政”微信公众号，借助村（社区）宣传橱窗，利用报纸、电视台新闻媒体开辟专版专栏，开展形式多样的公益普法宣传活动。社会组织管理处加强普法类公益组织扶持力度，结合社会组织的注册登记管理，强化社会组织成员学法培训，动员各级各类公益性社会组织参与普法志愿服务活动。

3.加强部门联动抓好主题法治宣传教育活动。人事教育处结合大走访大落实新风行动、“双基双强”行动、新时代文明实践志愿服务、党员义工周末广场集中服务、“阳光扶贫”等主题活动，认真开展法治宣传教育活动。基层政权和社区治理处配合司法局等部门推进民主法治示范村（社区）、“崇德尚法”新型村（社区）创建活动，推进自治、法治、德治“三治合一”工作。社会组织管理处联合相关部门，在开展各类公益服务项目创投大赛中，增加法治宣传类服务项目。相关处室（单位）积极组织开展“12.4”国家宪法日、“四绿”行动、扫黑除恶等主题法治宣传教育活动。

4.打造民政普法特色创新项目。社会事务处依托社会组织进驻社区、婚姻登记处等活动，开展婚姻法等法治宣传，重点打造“有爱有家”婚姻家庭辅导创新项目。围绕“结婚前、结婚后、离婚前、离婚后”四个关键期，通过婚姻法、收养法、未成年人保护法政策宣传，开展婚恋教育引导、婚内心理调适、婚姻危机疏导及离婚后的情感辅导等服务。

三、工作要求

（一）加强组织领导。根据机构改革单位职能和人事变动，调整普法工作领导小组成员（见附件1）。各处室、各单位要高度重视“谁执法谁普法”“谁服务谁普法”工作，根据普法清单确定本年度普法工作重点，形成“有部署、有落实、有总结”的工作格局。

（二）严格考核奖惩。建立健全激励奖惩和责任追究机制，将普法工作落实情况列入法治建设考核的重要方面，纳入内部绩效考核的重要内容。领导小组对各处室、各单位普法工作落实情况进行年度和阶段性评估检查，对开展普法工作成绩突出的处室（单位）和个人予以奖励，对执法犯法、违法用权等行为进行通报批评并责令整改，确保普法工作取得实效。

（三）强化宣传报道。各处室、各单位要结合各自职责，认真研究部署，制定具体工作方案，不断创新法治宣传手段和方法，积极开展普法宣传工作,并将相关活动信息及资料及时报送办公室汇总。

（四）注重经费保障。财务审计处将普法经费专门列项纳入部门预算，按照“专款专用、及时拨付”的原则，及时核拨经费，保障法治宣传工作有序顺利开展。同时加强对普法经费投入、支出的监督管理，定期进行跟踪检查，最大限度地发挥经费的使用效益。
