# 泰州市交通运输局关于印发轻微违法行为不予处罚一般违法行为从轻减轻处罚清单（3.0版）和不予实施行政强制措施清单（2.0版）的通知

（泰交规〔2024〕1号）

各市（区）交通运输局，局属各事业单位，局机关各处（室）：

为深入贯彻落实国务院《优化营商环境条例》，进一步优化营商环境，持续推行柔性执法，根据《江苏省道路运输条例》等有关法律法规修正情况和省交通运输厅免罚清单调整情况，结合我市交通运输执法工作实际，重新梳理并研究制定了《轻微违法行为不予处罚一般违法行为从轻减轻处罚清单（3.0版）和不予实施行政强制措施清单（2.0版）》（以下简称《清单》）（见附件），现印发给你们，请遵照执行。

《清单》自2024年10月24日起施行，有效期至2029年10月23日。《市交通运输局关于印发涉企轻微违法行为不予处罚一般违法行为从轻减轻处罚清单（2.0版）和不予实施行政强制措施清单的通知》（泰交规〔2023〕1号）同时废止。
