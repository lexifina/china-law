# 淮安市淮阴区区政府关于进一步鼓励企业挂牌上市的意见

（淮政发〔2019〕13号）

高新区、各园区管委会，商贸服务中心，各镇（街道）政府（办事处），区各委办局，区各直属单位：

为进一步调动区内企业上市以及在新三板和区域性股权交易市场挂牌积极性，鼓励和引导一批有一定规模、业绩优良、成长性好、注册地在我区并有挂牌上市意向的企业，通过挂牌上市做优、做强、做大，充分发挥上市企业带动我区经济发展的示范引领作用，现根据《市政府关于进一步鼓励企业上市的意见》（淮政发〔2011〕42号）和《市政府关于鼓励企业在新三板和区域性股权交易市场挂牌的实施意见》（淮政发〔2013〕186号）精神，结合我区实际，提出如下意见。

一、企业在挂牌或上市过程中，涉及整体改制或变更设立股份有限公司的，对审计评估后净资产增值部分应缴纳的企业所得税，以及因上市要求对以前年度应补缴的税收，由税收所属地财政按照其缴纳的税收地方留成部分给予补贴。

二、企业为挂牌或上市将资本公积、未分配利润和盈余公积转增股本的，依法缴纳的个人所得税，由税收所属地财政按照其缴纳的个人所得税地方留成部分给予补贴。

三、企业为挂牌或上市而改制、重组、变更设立股份有限公司，其土地、房产、车船等权证在过户过程中缴纳的增值税（营业税）、契税、房产税、土地增值税等，由税收所属地财政按照其缴纳的税收给予补贴。

四、企业改制为股份有限公司，因业务、资源、股权重组，涉及变更注册登记，办理土地、房产、商标及供水、供电、供气、通信等变更手续，企业产权评估登记、交易，土地、房屋测绘等，所涉及到的各项地方规费，在区权范围内予以免收。

五、企业自正式启动上市程序（股改挂牌）后，因新增利润产生的企业所得税比上年新增企业所得税地方留成部分，由税收所属地财政按照新增企业所得税地方留成部分给予全额补贴，补贴期限3年。企业上市后，不再享受补贴。

六、企业为上市改制设立的股份有限公司，区发改委、工信局、财政局、科技局等有关部门，在申报国家及省市高新技术产业化基金、国家高新技术产业项目配套资金、中小企业专项资金、科技型中小企业创新发展专项扶持资金、国债项目财政贴息资金等各类政策性资金方面给予优先支持。本区范围内担保公司优先提供担保等金融服务。

七、企业为上市需规范办理不动产权证的，在符合相关政策法规的前提下，国土资源、住房城乡建设等部门要及时予以解决；对扩大再生产、募投项目所需用地，优先安排指标并及时报批，保障用地。原以划拨方式取得的土地，可办理土地出让手续。可通过先租赁后出让方式获得用地。对上述情况下企业缴纳的契税等税费，其地方留成部分由税收所属地财政给予补贴。

八、设立区企业上市扶持引导资金。区政府在每年财政预算中安排专项资金300万元，用于企业上市奖励、补贴及培训费等，实行专户管理，专款专用。

九、通过以奖代补方式，积极推进企业上市工作。区内每上市1家企业，争取市政府奖励300万元。

十、“新三板”挂牌企业奖励政策。拟挂牌企业向全国中小企业股份转让系统有限公司上报挂牌申请文件并受理的，给予20万元的奖励；成功挂牌后，再给予50万元奖励，企业成功挂牌后，募集资金80%（含）以上用于我区范围内生产性、经营性项目（房地产项目外）建设的，按照融资额的2%比例给予奖励，最高奖励30万元。

十一、区域性股权交易市场挂牌奖励政策。股份有限公司在江苏股权交易中心、上海股权托管交易中心等区域性股权交易市场成功挂牌后，一次性奖励80万元。

十二、强化企业上市培育鼓励，鼓励全区各单位扶持培育招商引资企业上市，企业上市成功后，区政府对企业上市过程中提供优质服务的单位给予供优质服务奖。对实现上市所募集资金在本区投资的，视同招商引资完成额。鼓励上市后备企业开展股权融资，对实现股权融资所获得资金在本区投资的，视同招商引资完成额。每培育1户企业在四板挂牌，视同引进1个投资1000万元的工业项目，每培育1户企业在三板挂牌，视同引进1个投资2000万元的工业项目，每培育1户企业在主板（中小板、创业板、科创板等）上市，视同引进1个1亿元工业项目。

十三、加强企业上市目标考核奖励。将上市工作纳入相关部门的年度目标考评，由区上市工作领导小组办公室制定考核办法进行考核，对实现挂牌上市的部门给予加分。

十四、加强企业及帮办服务人员业务培训，培训费用从区企业上市扶持引导资金中列支。

十五、加强企业上市人才引进工作，对区内企业引进的资本运营人才，由区政府上报市政府批准，享受淮安市人才引进优惠政策和待遇。

十六、加强企业上市帮办服务工作，区成立企业上市工作领导小组，成员由区金融办、财政局、税务局、发改委、工信局、市管局、国土局、住建局、科技局、高新区等部门组成，领导小组办公室设在区金融办。对企业上市过程中涉及到的特殊疑难问题，可由区企业上市工作领导小组召集相关部门集中会办，采取一企一议、特事特办的办法解决。

十七、鼓励企业异地买“壳”上市，将上市公司注册地迁至我区且投资项目在我区，视同改制上市，享受本意见规定的相关优惠和奖励政策，并在办公用房租赁、帮办服务等方面给予优待。

十八、设立区企业上市投资风险基金，区政府在财政预算（或区融资平台）中安排1000万元，专门用于扶持异地企业在淮注册上市，对拟在淮注册上市的企业参股投资，扶持发展，企业上市后政府退出股份，上市企业承担风险投资财务成本。（投资入股：投资总额不超过1000万元，持股比例不超过25%，不控股；阶段参股：在有受让方的情况下可随时退出股份；投资收回：收取本金和财务费用）。

十九、企业应与区上市工作领导小组办公室（简称上市办）签订企业上市工作协议，严格考核，并约定不得因自身原因主动退出上市程序或上市后将注册地（总部）外迁，否则所获得的政府各种奖励或补贴等，如数收回上缴同级财政。

二十、符合条件的企业应向区上市办提出享受优惠政策的书面申请，经初审报区企业上市工作领导小组批准后执行。

本意见由区政府负责解释，具体解释工作由区政府办公室商金融办承担。如与上级政策相抵触按上级文件规定执行。本意见自发布之日起执行。

淮安市淮阴区人民政府
