# 盱眙县人民政府关于加强全县水库安全管理的通告

（盱政发〔2019〕17号）

为确保全县中小型水库安全运行，保障人民群众生命财产安全和供水安全，保护库区生态环境，依据《中华人民共和国水法》、《中华人民共和国防洪法》、《中华人民共和国水污染防治法》、《水库大坝安全管理条例》、《江苏省水库管理条例》等法律、法规的规定，现就有关事宜通告如下：

一、严禁在水库大坝管理和保护范围内从事爆破、打井、采石、采矿、挖沙、取土、修 坟等危害大坝安全的活动。

二、严禁在水库大坝管理和保护范围内从事高密度人工养殖、垂钓、游泳、放养畜禽、 种植农作物、露营、毒鱼、电鱼、炸鱼、堆放杂物、倾倒垃圾、排放废水废液和挖筑鱼池等污染水质、破坏水库生态环境的活动。

三、严禁损毁坝顶交通道路、入库道路、涵洞、管理房、溢洪道等水库工程设施。

四、在水库管理范围内从事任何建设行为的，必须依法进行洪水影响评价，取得水行政主管部门的批准。

五、任何单位和个人都有保护水库设施及水库环境的义务，有权对破坏水库管理设施、库区生态环境、污染水质的行为进行举报。（举报电话：0517-88212936）

六、水库管理单位要加强对水库库区的日常巡查，坚决制止可能影响水库安全和污染水库水质的行为；如发现有违法行为，及时上报至水行政主管部门，并依法进行处理；构成犯罪的，依法追究刑事责任。

七、对阻挠水库管理单位正常管理和执法部门执行公务的，由公安机关按照《中华人民共和国治安管理处罚法》相关条款给予处罚；构成犯罪的，依法追究刑事责任。

八、本通告自发布之日起施行。

盱眙县人民政府

2019年4月26日
