# 盐城市人民政府关于废止盐城市烟草制品零售点布局管理办法的通知

盐政发〔2019〕59号

各县（市、区）人民政府，盐城经济技术开发区、盐南高新区管委会，市各委、办、局，市各直属单位：

根据国务院“放管服”改革要求，经研究决定，《盐城市烟草制品零售点布局管理办法》（盐政规发〔2015〕7号）文件自2019年10月1日起废止。相关新规定由盐城市烟草专卖行政主管部门重新制定印发。

盐城市人民政府

2019年9月8日

（此件公开发布）

抄送：市委办公室，市人大常委会办公室，市政协办公室，市监委，

市法院，市检察院，盐城军分区。

盐城市人民政府办公室 2019年9月12日印发
