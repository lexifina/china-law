# 盐城市人民政府办公室关于对市级现代服务业集聚区进行优化调整的通知

盐政办发〔2019〕48号

各县（市、区）人民政府，盐城经济技术开发区、盐南高新区管委会，市各委、办、局，市各直属单位：

为贯彻落实市委七届八次全会精神，优化提升全市现代服务业集聚区发展布局，进一步强化集聚区对服务业高质量发展的支撑带动作用，经12月4日市政府常务会研究同意，将原有的24家市级现代服务业集聚区优化调整至18家。

现代服务业集聚区是加快服务业发展的重要抓手，对推动产业升级、优化产业结构、提升城市能级具有重要意义。各地各部门要高度重视服务业集聚区建设工作，加大对市级现代服务业集聚区的培育力度，进一步健全组织机制、完善基础设施、突出平台建设、强化招商引资，着力提升集聚区发展层次和水平，加快推动现代服务业高质量发展。

附件：市级现代服务业集聚区优化调整名单
