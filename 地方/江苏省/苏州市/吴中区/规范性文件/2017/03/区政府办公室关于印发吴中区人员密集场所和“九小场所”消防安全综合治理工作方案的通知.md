# 区政府办公室关于印发吴中区人员密集场所和“九小场所”消防安全综合治理工作方案的通知

各镇政府、街道办（场），区各办、局、公司，各垂直管理部门，度假区、开发区、高新区管委会及所辖各部门、农业园区、太湖新城，穹窿山风景管理区管委会：

经区政府同意，现将《吴中区人员密集场所和“九小场所”消防安全综合治理工作方案》印发给你们，请结合实际，认真贯彻执行。

苏州市吴中区人民政府办公室

2017年3月15日

（此件公开发布）

吴中区人员密集场所和“九小场所”消防安全综合治理工作方案

为全面加强对全区人员密集场所和“九小场所”的综合治理，依法排查整治火灾隐患，进一步健全完善火灾防控体系，区政府决定在全区范围内组织开展人员密集场所和“九小场所”的综合治理行动，特制定如下工作方案：

一、工作目标

按照“一年全面启动、两年强化落实、三年巩固提升”的目标，在安全风险分级管控的基础上，依法排查治理人员密集场所和“九小场所”火灾隐患，深入开展“三合一”场所火灾隐患整治，规范单位消防安全自我管理，规范建筑消防设施的设置、运行及维护保养，全面落实社会单位消防安全主体责任，建立健全消防安全社会治理体系，以信息化为引领，充分应用消防“大数据”平台，分析研判、预警提示、精准治理，坚决杜绝重特大尤其是群死群伤火灾事故，有效遏制小火亡人，确保全区火灾形势持续平稳。

二、综合治理任务

（一）人员密集场所

1．治理范围

符合消防安全重点单位界定标准的商场、集贸市场、学校、医院、宾馆饭店、公共娱乐场所、福利机构、客运车站候车室和劳动密集型企业等人员密集场所。

2．治理重点

建筑消防设施是否完好有效；“微消防”平台应用是否规范；单位消防安全主体责任是否落实。

3．时间和步骤

（1）动员部署（2017年3月20日前）。

各镇（区、街道）按照本方案要求，结合本地实际，制定具体实施方案，明确专门组织和排查人员，召开专门会议，发布通告，迅速部署开展工作。

（2）自查自纠（2017年3月21日~2017年12月31日）。

人员密集场所单位对照治理重点开展自查，填写《人员密集场所自查自纠记录表》和自查自纠承诺书，按消防监督管辖分级分别报送吴中、度假区消防大队和属地派出所，2017年6月30日前完成首次上报，之后每季度集中上报一次。对自查发现和监管部门检查发现的管理问题、火灾隐患和消防违法行为及时整改，整改期间要加强临时性防范措施确保消防安全。

（3）分级排查（2017年3月21日~2019年6月30日）。

区消委会于2017年3月21日~2017年7月31日、2017年8月1日~2017年12月31日、2018年1月1日~2018年12月31日分三次组织对全区人员密集场所单位进行排查，吴中、度假区消防大队和属地派出所要按照监督管理分工，严格依法履行职责，逐个场所开展监督检查，每次排查时对于整治对象检查不少于一次。

2019年1月1日~2019年6月30日，区消委会将组织对全区人员密集场所单位进行集中整治。吴中、度假区消防大队和属地派出所对检查发现的火灾隐患和消防违法行为，严格依法执法，督促单位整改火灾隐患，落实自动消防设施维护专业维护保养和联网监测，规范消防安全主体责任落实，对于整治对象检查不少于一次。

（4）协同治理（2017年3月21日~2019年12月31日）。

区商务、市场监管、文体、教育、卫计、民政、交通运输、旅游和安监等相关行业主管部门要充分发挥部门监管作用，将人员密集场所消防安全综合治理纳入每年安全生产重点工作内容，加强行业内业务指导，加强对治理对象的消防安全检查，推行消防安全标准化管理，并与区消防部门齐抓共管、形成合力，统筹推进治理工作，从整体上提升火灾防控水平。

（二）“九小场所”

1．治理范围

除消防安全重点单位以外的小商店、小学校（含幼儿园、各类社会培训机构）、小医院（含诊所）、小餐馆、小旅馆（民宿）、小棋牌室、小歌舞厅、小网吧、小美容（含洗浴、足浴）等场所（设于人员密集场所消防安全重点单位内的上述小场所纳入人员密集场所整治对象）。

2．治理重点

重点检查用火、用电是否规范；是否违规存放易燃易爆物品；防火分隔是否规范；消防设施器材配备是否规范并完好有效；安全疏散是否符合要求；是否存在违反《消防法》第十九条所明确在生产、储存、经营场所违法居住的“三合一”火灾隐患。

3．时间和步骤

（1）动员部署（2017年3月20日前）。

与人员密集场所专项治理同步开展动员部署，制定具体实施方案，明确专门组织和排查人员，发布通告。

（2）排查摸底（2017年3月21日~2017年6月30日）。

以镇（街道）为基本单元，以行政村（社区）为网格，组织综治办、安监办、派出所、市场监督管理局、村（居）委会等基层力量，对片区内“三合一”、“九小场所”开展“拉网式”排查，摸清场所名称、规模、性质、数量以及安全隐患等基本情况，登记造册。

（3）宣传培训（2017年3月21日~2019年12月31日）。

消防部门将派专人进行授课，切实解决查什么、怎么查和如何改的问题，属地派出所要配合当地安监办等机构组织辖区“九小场所”负责人分片开展消防安全教育培训。

（4）集中整治（2017年7月1日~2017年12月31日）。
