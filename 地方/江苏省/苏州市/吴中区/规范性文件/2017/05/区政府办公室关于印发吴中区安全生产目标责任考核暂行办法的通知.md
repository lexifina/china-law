# 区政府办公室关于印发吴中区安全生产目标责任考核暂行办法的通知

各镇政府、街道办（场），区各有关部门，度假区、开发区、高新区管委会及所辖各有关部门、农业园区、太湖新城，穹窿山风景管理区管委会：

经区政府同意，现将《吴中区安全生产目标责任考核暂行办法》印发给你们，请认真贯彻执行。

苏州市吴中区人民政府办公室

2017年4月26日

（此件公开发布）

吴中区安全生产目标责任考核暂行办法

为进一步健全我区安全生产目标责任考核体系，全面落实安全生产监管责任，确保安全生产各项指标在上级下达的年度预控指标以内，预防安全事故的发生和更好地消除安全隐患，促进全区安全生产形势的长期稳定，根据《中华人民共和国安全生产法》、《中共中央、国务院关于推进安全生产领域改革发展的意见》、《苏州市安全生产目标责任考核暂行办法》（苏府办〔2006〕96号）、市政府〔2013〕106号专题会议纪要精神，结合吴中区实际，制定我区安全生产目标责任考核暂行办法如下：

一、考核对象

（一）各镇（区）、街道；

（二）区安全生产预控目标各责任单位；

（三）除区安全生产预控目标各责任单位外的其他区安全生产委员会成员单位。

上述单位以下简称“被考核单位”。

二、考核原则

明确目标，落实责任，严格考核，一票否决。

三、考核内容

（一）安全生产年度预控目标完成情况；

（二）重大事故隐患排查与整改情况；

（三）安全生产基础工作情况。

被考核单位有以下情况之一的，目标责任考核实行“一票否决”：

（一）辖区内企业（单位、场所）发生一起及以上较大生产安全事故的；

（二）辖区内或系统内事故实际死亡人数超过年度预控指标10%的；

（三）未能完成重大事故隐患挂牌整改任务的；

（四）由于事故隐患未能及时消除而导致较大事故发生的。

四、考核程序

年终由被考核单位根据年度安全生产目标、任务完成情况以及目标责任考核标准（另行规定）进行自我考核，并将年度安全生产工作总结和自我考核结果书面报区安全生产委员会办公室。

区安全生产委员会组织由区安监局、监察局、财政局、公安分局、总工会等部门人员参加的考核组，对被考核单位的安全生产年度目标任务完成情况进行考核。

考核组根据被考核单位安全生产目标责任考核情况，提出考核奖惩建议，报区政府审核同意后实施。根据规定，对完成年度安全生产目标任务的单位进行奖励；对完成情况差的单位，予以通报批评。

五、奖励资金

根据市政府〔2013〕106号专题会议纪要要求，区政府建立安全生产考核奖励专项资金200万元，列入区财政年度预算。

六、奖励标准

安全生产目标责任考核奖励分为目标考核奖、单项考核奖和工作奖三个部分，由区安全生产委员会给予奖励。

（一）目标考核奖。设乡镇目标考核奖和预控目标考核奖，奖励总金额控制在100万元。

1. 乡镇目标考核奖。设特别奖，一、二、三等奖，奖励总金额控制在80万元。奖励对象为各镇（区）、街道主要领导、分管领导、安全生产综合监管部门负责人和相关工作人员。

2. 预控目标考核奖。奖金总额控制在20万元。奖励对象为区安全生产预控目标责任部门（单位）的主要领导、分管领导和相关工作人员。

（二）单项考核奖。设隐患排查整改奖和专项整治奖两类，奖励总金额控制在40万元。隐患排查整改奖的奖励对象是各镇（区）、街道隐患排查整改工作的监督管理部门；专项整治奖为年度各类专项整治工作的奖励，具体整治项目依据当年度工作目标任务确定，奖励对象是区安全生产专项整治工作责任部门。

（三）工作奖。设工作创新、信息化建设、工作协作、争先创优等若干项，奖励总金额控制在60万元。奖励对象为年度安全生产工作任务完成较好的区安委会各成员单位主要领导、分管领导和相关工作人员。

七、其他事项

（一）各镇（区）、街道要根据各自区域内企业的总数，按1家企业不低于200元的标准，设立安全生产目标责任考核奖励资金，并结合本办法制定相应的安全生产目标责任考核奖励方案。

（二）鉴于每年度考核情况略有不同，各奖项及奖金根据考核结果可作适当调整。

（三）本暂行办法自2017年起施行。

（四）本暂行办法由区安全生产委员会办公室负责解释。
