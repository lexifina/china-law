# 关于加强全区国有（集体）资产食品经营租赁管理的通知

各镇政府、街道办（场），区各有关部门，度假区、开发区、高新区管委会及所辖各有关部门、农业园区、太湖新城，穹窿山风景管理区管委会：

为进一步贯彻落实新《食品安全法》，规范食品生产经营活动，从源头提升全区食品安全监管水平。经区政府同意，决定对全区出租用于食品生产经营的国有（集体）资产进行排查摸底，督促产权人（或实际控制人）加强对出租资产的日常监管，清退无证无照租赁户。现将有关事项通知如下：

一、排摸清退范围及责任单位

1. 各区属国有（集体）公司资产出租用于食品生产经营的（由区国资局负责）；

2. 各镇（区）、街道资产（含农贸市场内商铺）出租用于食品生产经营的（由各镇<区>、街道负责）；

3. 直管公房出租用于食品生产经营的（由区住建局负责）；

4. 各股份经济合作社资产出租用于食品生产经营的（由各镇<区>、街道负责）；

5. 其他国有（集体）资产出租用于食品生产经营的（由实际产权人或区相关主管部门负责）。

二、排摸清退内容

1. 核实租赁单位或个人是否已办理营业执照、食品生产或食品经营许可证（或原食品流通许可证和餐饮服务许可证），对于无证无照的承租户督促并限期办理相关证照；

2. 核实租赁单位或个人有无超范围开展经营活动，有超范围经营的应立即制止，限期整改，并通报区市场监督管理局，拒不整改的，要坚决清租；

3. 加强对租赁经营户生产安全管理，发现食品安全隐患的要及时督促改正；

4. 对于无证经营且无法办理相关证照的要坚决进行清租，有涉嫌从事犯罪行为的要及时移交公安部门处理。

三、相关要求

（一）提高思想认识，加强组织领导。根据新修订的《食品安全法》第一百二十二条、一百二十三条等相关条款规定，业主（单位或个人）将房屋出租给他人从事食品或食品添加剂生产经营，负有核实经营方证照的责任。对明知租赁方从事《食品安全法》第一百二十二条、一百二十三条规定的违法行为，仍为其提供生产经营场所或其他条件的，由县级以上人民政府食品药品监督管理部门责令停止违法行为，没收违法所得，除以相应的罚款；使消费者合法权益受到损害的，应当与生产经营者承担连带责任。新修订的《食品安全法》的正式施行，对于从源头加强食品安全管理，增强食品安全监管工作的规范性、科学性和有效性，防范食品安全事故发生，切实保障广大人民群众的身体健康和生命安全，具有十分重要的意义，各部门要提高思想认识，确实履行好“谁出租、谁负责”的职责，加强组织领导，指定专人负责，做好与区市场监督管理局的工作对接，把此次排摸清退行动做实、做细。

（二）明确工作任务，认真梳理核实。各责任单位要进一步加强对新修订的《食品安全法》的研究，明确此次梳理核实的目的、任务和内容，按照要求完成好此次排摸清退工作，摸清底数，对于不符合食品安全要求的承租单位或个人，要坚决清租，消除安全隐患。同时加强对租赁单位或个人的监管，尽责履职，确保在本单位所管理的资产内不发生食品安全问题，并按要求填好核查表，于7月30日前将核查表敲章原件及电子版上报至区食安委办公室（电话：65270587；邮箱：65270587@163.com；地址：太湖西路160号103室）。以后承租户如有变动，应每年整理汇总上报区食安办。

（三）加强协同配合，完善工作机制。食品安全工程是一系统工程，涉及面广，需要多部门协同配合，形成合力，共同推进。此次梳理核查范围较广、涉及部门较多，各部门要密切协调，对碰到的困难和问题，加强研究，整合力量，从推进依法行政的高度，共同做好核查清理工作，并以此次核查为契机，完善工作机制，加强部门间协作，形成信息通报制度，提高全区食品安全工作水平。
