# 市政府办公室关于转发太仓市2014年度生态文明建设目标任务书的通知

各镇人民政府，太仓港经济技术开发区管委会，新区管委会，科教新城、旅游度假区管委会，娄东街道办事处，市各委办局，各直属单位，健雄学院：

现将苏州市生态文明建设工作领导小组办公室下达的《太仓市2014年度生态文明建设目标任务书》（苏生态文明办〔2014〕14号）转发给你们，请结合各自工作职能和任务，认真贯彻实施，确保完成我市2014年度生态文明建设目标任务。

太仓市人民政府办公室

2014年6月20日

太仓市2014年度生态文明建设目标任务书

一、总体目标

坚持以科学发展观为指导，认真贯彻落实党的十八大、十八届三中全会和省委十二届五次、六次全会精神，深入开展节能减排，加快产业结构调整，大力发展低碳经济，切实加强环境保护，全力打造宜居环境，2014年，单位GDP水耗300立方米/万元。单位GDP能耗下降率、单位GDP二氧化碳排放降低率完成上级下达的目标，主要污染物化学需氧量、氨氮、二氧化硫、氮氧化物削减量为0.0763、0.0086、0.0636、0.3894万吨，削减率为2.73、4.45、3.26、12.23%。空气质量达到二级标准以上天数的比例大于62%，监测断面水质好于Ⅲ类比例达到50%。

（责任单位：发改委、经信委、环保局、水利局，各镇区、街道）

二、重点工作

（一）生态空间保护行动

1.优化国土开发格局

按照人口资源环境相均衡、经济社会生态效益相统一的原则，科学布局生产、生活、生态空间。严守“生态红线”，控制生态空间开发强度，加强生态空间管制，完成生态红线区域划定和保护方案编制，扩大保护范围，明确保护要求，落实管理机构，确保生态红线区面积占比达9%以上，受保护地占比达到20%以上，生态用地比例达55%以上。

（责任单位：发改委、环保局、住建局、国土局，各镇区、街道）

2.加强自然资源保护

深化节水型社会建设，年用水量100万吨以上用水户建成节水型企业单位，推广节水新技术新产品，加强节水技改，扩大节水载体覆盖面，推广农业节水灌溉技术。2014年，万元工业增加值用水量降到13.5立方米以下，农业灌溉水有效利用系数达0.649。

加强地面沉降监测和防治，巩固地下水禁采成果。

实施最严格的耕地保护和节约用地制度，控制城乡建设用地总规模，不断提高单位土地投入产出效率。2014年，耕地保有量保持49.89万亩，单位GDP建设用地占用率下降率达8.7%。

保护自然湿地，逐步修复退化湿地，实施天镜湖、长江口森林公园等生态湿地建设，扩大湿地保护面积。严格水面保护，保证水面率不降低。2014年，自然湿地保护率达50%。

实施生物多样性保护战略与行动计划， 加强外来入侵物种的防范和控制，严格防控加拿大一枝黄花、桔小实蝇等各类有害外来物种。

加强风景名胜资源保护和管理，切实保护地方园艺品种。

（责任单位：水利局、农委、国土局、环保局、太仓检验检疫局、住建局、旅游局，各镇区、街道）

3.推进绿色苏州建设

构建沿长江防护林体系，加大沿河湖、沿山体、沿道路绿化力度，在产业集中区周围建设绿化隔离带，大力实施生态公益林保护工程，全面推进森林抚育工作。2014年，新增森林面积0.4万亩，实施森林抚育面积0.5万亩，新增省级公益林0.15万亩，重点公益林面积增加到0.84万亩，林木覆盖率达到16.9%以上。

（责任单位：农委、住建局，各镇区、街道）

（二）经济绿色转型行动

1.优化产业结构和布局

合理规划产业布局，严格执行化工、印染、造纸等项目的准入政策，全面推动区域协调发展。加快传统产业的提升发展，大力发展战略性新兴产业。积极发展现代服务业。大力发展现代物流、金融、软件和服务外包、商务、科技和信息、现代商贸、绿色房地产和社区服务等产业，建设服务业集聚区；加快发展生态旅游业，合理开发旅游资源。2014年，高新技术产业产值达到680亿元，服务业增加值占地区生产总值的比重提高到44.5%。

建设“四个百万亩”工程，加大农业基础设施和生产设施建设力度，推进农业设施化、标准化、现代化建设。全面推广测土配方施肥，着力实施化肥农药减施、氮磷生态拦截工程等建设，大力推进无公害农产品、绿色、有机食品种植基地建设。加强秸秆综合利用。2014年，“三品”基地占耕地比例达90%，秸秆综合利用率达95%以上，规模化畜禽养殖场和养殖小区配套污染治理设施覆盖率达60%以上、粪便无害化处理及资源化利用率达92%。

全面加快全市工业经济转型升级步伐，围绕战略性新兴产业引领发展、传统产业提升发展的工作总基调，强化不达标企业关闭及落后产能淘汰工作，将电镀、印染、皮革、化工、酿造、工业气体制造及分装、小家具、小冶金、小铸造、低水平废旧材料回收处理等行业确定为关停和淘汰的重点。完成“关闭不达标企业、淘汰落后产能、改善生态环境”专项行动计划年度目标任务。

（责任单位：发改委、经信委、旅游局、科技局、农委、国土局、环保局、安监局，各镇区、街道）

2.强化节能减排

优化能源结构。加快发展热电联产，控制煤炭消费总量；完成列入国家发改委关停名录的小火电机组的关停任务；调整能源消费结构，推广使用清洁能源，建设太阳能光热利用、光伏发电示范工程。

大力组织实施节能工程，严格控制高耗能高排放行业过快增长，着重抓好工业、建筑、交通运输、公共机构等重点领域，以及钢铁、水泥、电力等重点行业和年耗能3000吨标准煤以上的重点用能单位节能工作。推进节能新技术和新产品的应用；深化“能效之星”创建活动，提高企业节能降耗水平。

健全总量监测预警、统计、考核三大体系，强化结构减排，落实工程减排，推进科技减排，完善管理减排，大力实施重点减排项目，确保减排任务顺利完成。

（责任单位：发改委、经信委、住建局、交通局、环保局、质监局，各镇区、街道）

3.推行循环清洁生产方式

大力发展循环经济，全面推进园区循环化改造，完成列入改造计划的园区实施方案编制工作。持续开展国家级生态工业园区建设工作，省级以上生态工业园区建成比例达100%，积极开展工业循环经济示范企业（基地）创建活动。推动再生水利用，城镇污水处理厂尾水再生利用率达13%。完善生活垃圾收运体系，推动垃圾分类回收利用的试点工作，新增5个垃圾分类小区。

全面推行清洁生产，推进清洁生产对标创先活动，对污染物排放超标或超过重点污染物排放总量控制指标的企业，使用或排放有毒、有害物质的企业以及超过单位产品能源消耗限额标准构成高耗能的企业实施强制性清洁生产审核。2014年，完成20家重点企业清洁生产审核评估和6家企业自愿性清洁生产审核工作，建成3家工业循环经济示范企业。

加快国家低碳试点城市建设，全面推进低碳经济试点示范，深入推进低碳全民行动，加快建立以低碳排放为特征的产业体系、生产方式和消费模式。

（责任单位：经信委、环保局、水利局、水处理公司、城管局、发改委、港区管委会，各镇区、街道）

（三）环境质量改善行动

1.综合治理大气污染

完善大气污染联防联控和监测监控体系，实时公布大气环境质量监测信息。全面开展霾天气监测预警工作。防治酸雨、灰霾和光化学烟雾污染，实施2014年蓝天工程行动计划；积极推进电力、钢铁等重点行业烟气脱硫脱硝以及重点工业企业烟、粉尘提标改造工程，削减污染物排放总量。开展化工园区环境综合整治和督察，对化工园区以及石化、炼油、电子、制药、涂装等重点行业开展挥发性有机物污染专项治理。开展城区餐饮油烟整治行动。强化扬尘污染防治，整治混凝土搅拌站，整治工地、道路、堆场、裸地扬尘。加强部门联合执法，严格执行“黄标车”限行措施，深入开展本地、外地旅游、厂包、专线客车“冒黑烟”集中整治行动和长效管理，积极推进老旧机动车辆淘汰报废。建立和完善机动车检测管理机制，采用工况法进行柴油车环保检测。2014年，机动车环保检测率达95%，机动车年审同步检测率达100%。确保油库、加油站、油罐车的油气回收装置正常运行。

（责任单位：发改委、环保局、经信委、住建局、水利局、国土局、交通局、公安局、气象局、质监局，各镇区、街道）

2.全面提升水环境质量

深入推进“河长制”、“断面长制”管理，强化河道综合治理和长效管理，实施七浦塘拓浚以及盐铁塘、浏河、半泾河小流域水环境整治工程，扎实推进生态清淤、水生态修复、岸线绿化等工作，促进水环境质量持续改善。强化水质监控预警和应急能力建设，确保饮用水安全。防治水上交通运输污染，回收处理船舶污油水和船舶垃圾。贯彻实施《全国地下水污染防治规划》，规范开展地下水环境监测，完成重点地区地下水环境状况调查评估任务。

（责任单位：发改委、水利局、环保局、交通局、国土局，各镇区、街道）

3.积极防治土壤污染

在国务院《土壤污染防治行动计划》、《全省土壤环境保护和综合治理行动计划》和苏州市土壤污染防治工作方案印发实施后，按照相关要求抓好辖区土壤污染防治工作。严格执行国家规划环评和项目环评有关政策，在规划环评和排放重金属、有机污染物的工矿企业项目环评文件中强化土壤环境影响评价的内容。新增工业用地必须开展土壤环境调查评估，并报市环保部门备案。开展场地污染排查，建立污染场地档案。加强土壤环境监管能力建设。开展污染场地土壤综合治理与修复试点示范，确保土地转换用途后的安全利用。

（责任单位：环保局、国土局，各镇区、街道）

4.推进生态人居建设

加强环境综合整治，推进城北河区域综合整治工程，实施基础设施、绿化景观及配套工程建设，优化城乡生态风貌。突出农村环境整治，建立长效管理机制，巩固村庄环境整治成果，完成全覆盖拉网式农村环境连片整治年度时序任务，加快推进农村生活污水处理、垃圾分类试点、畜禽粪便污染防治、农村卫生改厕等重点工作，农村环境质量稳步改善。按照《畜禽规模养殖污染防治条例》有关要求，开展辖区畜禽养殖污染摸底调查，在此基础上加快畜禽规模养殖污染防治工作。

开展城市内河和农村河道水环境综合整治工程，实施城区水环境综合整治十八港南枢纽工程，开展清淤疏浚，实施硬质护坡生态化改造，新建、改建河湖护岸采用生态护岸的比例达到90%，增强河流自净能力。加强城乡噪声污染防治管理，开展“绿色护考”等专项行动，巩固噪声达标区成果，改善城市声环境质量。

进一步提高城市绿地布局的均衡性，加快太仓市中心城区绿化景观改造和新区中央公园建设，提高公园绿地服务半径覆盖率，打造以乡土植物为主的绿地系统，严格保护古树名木，提升园林绿化品质。2014年，城市（县城）建成区绿地率达39.4%、绿化覆盖率达42%，建制镇建成区绿化覆盖率41%。深入开展绿色村庄建设活动，把村旁、宅旁、路旁、水旁作为绿化重点，形成点线面相结合的村庄绿化格局。2014年，规划布点村庄绿化覆盖率达到23.7%，新增绿化示范村5个。

（责任单位：发改委、环保局、农委、农办、卫生局、水利局、住建局、公安局、交通局、各镇区、街道）

5.加快环境基础设施建设

大力推进城镇污水处理厂、农村生活污水处理设施及其配套管网、垃圾处理设施建设，完成太湖水污染防治目标任务。完善城区环卫基础设施，提高已建农村生活污水处理设施正常运行率，新建规划布点村庄同步完善管网建设，全部实现雨污分流。2014年，城市（县城）污水处理率提高到97.5%，建制镇污水处理率提高到89.5%，规划布点村庄生活污水处理率达66.5%以上；建制镇污水处理设施（含接管）覆盖率、城市（县城）污水处理厂污泥规范化处理率、生活垃圾中转设施覆盖率、城乡生活垃圾无害化处理率、镇村生活垃圾集中收运率达到100%，农村无害化卫生户厕普及率达99%。

积极推进危险废物规范化处理设施建设，完成太仓市柯林固废处置有限公司搬迁扩建以及顺惠金属制品有限公司扩建项目，严格实施危险废物经营许可证和转运联单制度，加强医疗废弃物管理和处置，医疗废弃物安全处置覆盖所有建制镇，并向行政村延伸。2014年，危险废物处理率达100%，工业固体废弃物处置率达到99%。

（责任单位：水利局、水处理公司、城管局、卫生局、环保局，各镇区、街道）

6.完善风险防范体系

加强环境风险防控管理与应急处置，有效防范和遏制重特大环境污染事故发生。开展环境安全大检查和环境风险企业隐患排查和整治工作，加强对生产、储存危险化学品企业监管和危险化学品运输管理。定期开展环境应急演练，提高环境应急能力。

强化对涉重企业的监管，落实苏州市重金属污染综合防治实施方案，按计划完成列入省环保厅“十二五”重金属规划中的年度任务，重金属污染得到有效控制。加强电磁辐射环保宣传和环境监管，加强对电视发射塔、广播台（站）等大型电磁辐射设施的管理。

（责任单位：环保局、安监局、交通局、公安局、水利局、广电总台、移动公司、电信公司、联通公司、供电公司，各镇区、街道）

（四）生态生活全民行动

1.强化健康生活保障

加强饮用水源地保护，确保饮用水安全，完成集中式饮用水源地达标建设并通过省验收，巩固和完善“备用水源、深度处理、严密检测、预警应急”的饮用水安全保障体系，实行“双源供水、双重保障”，推进自来水深度处理、城乡供水管网和二次供水设施改造，强化水质监控预警和应急能力建设，确保供水水质全面稳定达到《生活饮用水卫生标准》要求。集中式饮用水源地水质达标率保持100%，区域供水覆盖率达100%。

完善食品安全风险监测和检验检测体系，依法从严从重打击各类食品安全违法犯罪活动，坚决防范各类食品安全事故的发生。

（责任单位：环保局、水利局、卫生局、农委、质监局，各镇区、街道）

2.推动生活方式绿色化

积极倡导厉行节约的生活方式，党政机关带头开展反对浪费行动，严格落实各项节约措施。强化资源回收意识，鼓励个人和家庭养成资源回收利用习惯。

发展绿色建筑，新增绿色建筑评价标识项目面积28.84万平方米，大力推广安全耐久、节能环保、施工便利的绿色建材。推进既有建筑节能改造，机关办公建筑和大型公共建筑在进行装修、扩建、加层等改造以及抗震加固时，综合采取节能、节水等改造措施；老旧小区利用出新和环境整治、既有建筑抗震加固等时机，同步推动屋面、外墙、门窗、楼道等部位的节能改造，全年完成6.5万平方米既有建筑节能改造面积。

落实公交优先战略，鼓励城乡居民选择公共交通工具出行。加强城市步行和自行车交通系统建设，大力发展城市公共自行车网络。

加快推进殡葬基础设施和殡仪服务市场建设，实现基本殡葬公共服务均等化。积极倡导和树立殡葬文明新风，引导公众选择树葬、可降解骨灰葬、骨灰撒海（江）等生态安葬方式。

（责任单位：宣传部，机关事务局、商务局、供销合作总社、住建局、交通局、民政局，各镇区、街道）

3.引导消费模式绿色化

深入推进限塑工作，严格限制一次性用品的生产、销售和使用。禁止销售、使用含磷洗涤用品。采取有效措施支持能效标识产品、节能节水认证产品、环境标志产品和无公害标志食品等绿色标识产品的生产、销售和消费。

认真落实《节能产品政府采购实施意见》和《环境标志产品政府采购实施意见》，积极推行绿色采购，提升绿色采购在政府采购中的比重。推进绿色办公，推进节约型、环保型机关建设，党政机关率先使用节水设备和节能灯具，进一步推行“无纸化办公”、视频会议等电子政务，提倡节约使用、重复利用纸张、文具等办公用品。

（责任单位：商务局、工商局、财政局、机关事务局，各镇区、街道）

（五）生态文化传播行动

1.培育苏州特色生态文化

大力倡导和树立“尊重自然、保护自然，科学发展、和谐发展，当代公平、代际公平，全民参与、全球参与”的现代生态理念，把“生态优先、环保至上”方针作为培育生态文化的鲜明导向。加强历史街区、古民居、古村落、古河道、古井、古桥以及历史文化名城名镇名村等文化遗产的保护管理，建设生态文明教育基地，展示地方特色生态文化。

2.加强生态文明宣传教育

积极推进生态创建，开展生态文明示范企业创建活动，实施美丽镇村建设纲要，开展“百村示范、千村整治提升”行动；大力开展生态旅游示范区、生态工业园区、生态文明示范企业、生态文明镇村、美丽镇村、绿色学校、绿色社区等创建活动，市级以上生态村占比达到95%。

（责任单位：组织部、宣传部、农办，文广新局、经信委、教育局、环保局、住建局、旅游局，各镇区、街道）

3.强化生态文明共建共享

大力推进环境信息公开，及时向社会公布节能减排、生态建设、环境质量等信息。实行有奖举报，鼓励检举揭发各种环境违法行为。动员广大群众积极参与生态文明建设活动，依法保障群众的知情权、参与权、表达权和监督权。

（责任单位：市领导小组，宣传部，政府办公室、经信委、环保局，各镇区、街道）

（七）生态制度创新行动

1.强化法制建设

落实《苏州市生态补偿条例》，实施促进低碳经济、节能减排、清洁生产、生态补偿、污染防治、资源循环再生利用、循环型园区建设的法规、规章和规范性文件。

严格执行环境影响评价制度，加强项目全过程环境管理，确保建设项目环保“三同时”执行率达到100%。加强部门协作，完善环保、住建、水利、农委、国土资源等部门联动执法机制。进一步畅通环保投诉渠道，及时处理污染事故和矛盾纠纷。加强环保行政执法与刑事司法的有效衔接，严厉打击破坏资源、污染环境、损害生态的违法犯罪行为，落实“三审合一”集中审判工作机制。

（责任单位：法院、检察院，政府法制办、环保局、住建局、水利局、农委、国土局、公安局，各镇区、街道）

2.健全决策机制

健全体现科学发展观要求的政绩考核体系，在经济社会发展综合评价体系中增加资源消耗、环境损害、生态效益等体现生态文明建设状况的指标考核权重，把生态文明建设指标和工作实绩作为评价干部政绩的重要内容。

（责任单位：组织部，发改委，各镇区、街道）

3.加强政策调控

加大生态文明建设工程资金投入力度，确保财政用于环境保护和生态建设支出的增幅高于经济增长速度。进一步完善政府引导、市场运作、社会参与的多元投入机制，2014年，全社会环保投入占GDP比重达3.9%。

深化资源环境价格改革，落实差别化环境价费政策，配合省相关部门对脱硫设施投运率不达标的电厂扣减脱硫电价。落实危险废物处置收费政策，促进危险废物处置设施建设和运营的多元化、产业化、市场化。

进一步完善环保信用体系建设，继续开展企业环保信用评价及信用管理工作，建立环保信用信息共享及失信联动惩戒机制，推动企业环保信用评价结果在行政许可、采购招标、评先评优、信贷支持、资质等级评定、安排和拨付有关财政补贴资金等工作中广泛应用，扩大化工、印染、造纸等高环境风险行业企业环境污染责任保险推行范围，加强企业环境风险管理。

（责任单位：财政局、物价局、环保局、中行太仓支行，各镇区、街道）

4.建立合作机制

广泛开展生态文明建设各领域、各层面的经验交流与技术合作，重点学习和借鉴先进地区在产业转型升级、污染防治、生态保护等领域的先进经验和做法。

（责任单位：市领导小组，环保局，各镇区、街道）

1.加强组织领导

分解落实生态文明建设三年行动计划的目标任务，明确责任分工。按照“工作项目化、项目目标化、目标责任化”的要求，实施2014年生态文明建设“十大工程”和重点项目，加强工程项目的组织管理和督查，确保重点项目的顺利实施。

（责任单位：生态文明办，监察局，各镇区、街道）
