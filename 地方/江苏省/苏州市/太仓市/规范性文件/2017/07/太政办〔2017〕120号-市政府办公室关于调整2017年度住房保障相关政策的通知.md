# 市政府办公室关于调整2017年度住房保障相关政策的通知

各镇人民政府，太仓港经济技术开发区管委会，太仓高新区管委会，科教新城、旅游度假区管委会，娄东街道办事处，市各委办局，各直属单位，健雄学院：

为进一步完善我市住房保障体系，提高住房保障工作力度和保障水平，实现“应保尽保、住有所居”的工作目标，根据省、苏州市文件精神，结合我市实际情况，经研究，决定对我市2017年度住房保障政策作如下调整：

调整住房保障对象收入线标准

最低收入标准，即城乡低保标准，家庭人均月收入从810元调整到875元；低收入标准，家庭人均月收入从2090元调整到2256元；中等偏低收入标准，家庭人均月收入从3340元调整到3610元。

各类保障对象的家庭人均月收入以市民政部门核定的结果为准。

二、确定住房保障购房补贴标准

为切实解决我市中等偏低收入及以下住房困难家庭的住房问题，让符合住房保障条件的家庭有更多的住房选择途径，根据《太仓市住房保障购房补贴发放规定》（太政发〔2017〕54号），购房补贴标准按2016年度本市新建普通商品住房市场均价的50%左右计算，定为每平方米5100元。
