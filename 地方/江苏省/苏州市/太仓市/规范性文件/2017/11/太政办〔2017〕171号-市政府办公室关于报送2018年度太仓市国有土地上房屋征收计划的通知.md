# 市政府办公室关于报送2018年度太仓市国有土地上房屋征收计划的通知

各镇人民政府，太仓港经济技术开发区管委会，太仓高新区管委会，科教新城、旅游度假区管委会，娄东街道办事处，市各委办局，各直属单位，健雄学院：

根据《太仓市国有土地上房屋征收与补偿暂行办法》规定，现就报送2018年度太仓市国有土地上房屋征收计划的有关事项通知如下：

一、上报原则

1．征收计划应当符合《国有土地上房屋征收与补偿条例》第八条公共利益界定的六种情形。涉及保障性安居工程建设和旧城区改建项目的，应当纳入国民经济和社会发展年度计划。凡未列入年度计划的征收项目将不得实施房屋征收；

2．凡上报的征收计划必须要有规划红线图。

二、征收计划范围

本市行政区域范围内国有土地上的征收项目。

三、相关要求

1．各单位加强项目前期研究，2018年不具备启动条件的征收项目，原则上不列入2018年度房屋征收计划；

2．房屋征收计划为年度计划，以前年度已列入房屋征收计划的项目，如当年度未发出暂停办理相关手续的，应当重新报送，列入2018年度房屋征收计划；

3．项目的上报数据要合理，要全面考虑项目推进情况，不重不漏。每个项目应注明项目性质，并按住宅、企业、商业及其它等分类报送搬迁户数、搬迁面积。

四、上报形式

纸质表格一份（加盖单位公章），每个征收项目附规划红线图一份；电子表格一份，发至邮箱(taicangzsk@163.com)。

五、上报时间

请各有关单位于2017年12月20日前将计划表报送至市房屋征收服务中心（太仓市郑和西路11号）。联系人：张国良、何建平；联系电话：53537457；传真：53537457。
