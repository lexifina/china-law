# 市政府办公室关于调整2018年度住房保障相关政策的通知

各镇人民政府，太仓港经济技术开发区、太仓高新区、旅游度假区管委会，科教新城管委会，娄东街道办事处，市各委办局，各直属单位，健雄学院：

为进一步完善我市住房保障体系，提升住房保障工作力度和保障水平，实现“应保尽保、住有所居”的工作目标，根据省、苏州市文件精神，结合我市实际情况，经研究，决定对我市2018年度住房保障政策作如下调整：

一、 调整住房保障对象收入线标准

最低收入标准，即城乡低保标准，家庭人均月收入从875元调整到945元；低收入标准，家庭人均月收入从2256元调整到2436元；中等偏低收入标准，家庭人均月收入从3610元调整到3897元。

各类保障对象的家庭人均月收入以市民政部门核定的结果为准。

二、适当调整安置住房认定条件

申请人家庭已享受城乡一体化（村改社区）拆迁安置政策（含宅基地、安置住房或货币安置等方式），其名下的住房在申请住房保障前转让满十年，并且与直系亲属现有住房合并计算低于住房保障标准（人均20平方米）的，视为无自有住房，可以申请租赁补贴住房保障方式，但不享受实物配租、经济适用住房及购房补贴的保障方式。

三、调整住房保障购房补贴标准

根据《太仓市住房保障购房补贴发放规定》（太政发〔2017〕54号），2018年购房补贴标准按2017年度本市新建普通商品住房均价的50%计算，即从2017年的每平方米5100元调整为每平方米6217元。
