# 市政府办公室关于做好2018年政府信息公开年度报告编制发布工作的通知

各镇人民政府，太仓港经济技术开发区管委会，太仓高新区管委会，科教新城、旅游度假区管委会，娄东街道办事处，市各有关部门和单位：

根据《中华人民共和国政府信息公开条例》和《苏州市政府办公室关于做好2018年度政府信息公开报告编制发布工作的通知》要求，为切实做好2018年全市政府信息公开年度报告编制和发布工作，现就有关事项通知如下：

一、精心组织

编制发布政府信息公开年度报告，是一项制度安排，对推进政务公开，保障人民群众知情权、参与权、表达权、监督权有着重要意义。各地各部门要高度重视，按照《政府信息公开条例》《省委办公厅省政府办公厅关于全面推进政务公开工作的实施意见》（苏办发〔2016〕45号）要求，精心组织年报编制发布工作，认真总结分析本年度政务公开工作开展情况及成效，准确规范完整填写有关统计数据信息，确保形成内容全面、数据详实、重点突出的政府信息公开年度报告。

二、编制要求

2018年政府信息公开年度报告应包括以下内容：《政府信息公开条例》第三十二条规定的主动公开、依申请公开等6个方面内容；《市政府办公室关于印发太仓市2018年政务公开工作要点实施方案的通知》（太政办〔2018〕169号）要求的工作要点落实情况，有牵头任务的责任部门要重点报告任务完成情况；《省委办公厅省政府办公厅关于全面推进政务公开工作的实施意见》（苏办发〔2016〕45号）、《省政府办公厅印发关于全面推进政务公开工作实施细则的通知》（苏政办发〔2017〕151号）各项工作任务推进进展情况。各地各部门要加强报告的统计数据审核工作，对统计信息中涉及的新闻发布、行政复议、行政诉讼等情况，应与有关部门沟通确认。要做好机构改革后年报编制工作的有序衔接，机构改革中涉及到职能转移的部门要及时与原部门沟通衔接，确保有关统计数据不重复报送。

三、集中发布

各地各部门要在2019年2月底前通过太仓市人民政府门户网站信息公开平台将2018年政府信息公开年度报告向社会公开。鼓励通过微信、微博、移动客户端等渠道实现不同版本的精准推送，提高年报的到达率、知晓度。市政府办公室将对各地各部门的年度报告编制发布情况进行检查，将结果纳入年度考核。

四、其他事项

请各地各部门按以下要求做好统计表、重点领域政务公开工作总结的填报工作：

（一）信息公开情况统计表。请各地区各部门填写《政府信息公开情况统计表》（附件2）和《政府信息公开申请来源统计表》（附件5），按照指标填报说明（见附件4、6）进行统计。请市委宣传部填写《政府信息公开情况统计表》（附件3），按照指标填报说明（见附件4）进行统计；市委编办无需填报统计表。本通知及表格的电子文档可到QQ工作群446834076下载。

（二）重点领域政务公开工作总结。要求尽可能用统计数据分析解读，无需面面俱到，文字要精炼朴实。请市委宣传部提供互动交流、舆情回应和政策解读情况。对于《市政府办公室关于印发太仓市2018年政务公开工作要点实施方案的通知》（太政办〔2018〕169号）以及《市政府办公室关于推进公共资源配置领域政府信息公开的实施意见》（苏府办〔2018〕248号）、《市政府办公室关于推进重大建设项目批准和实施领域政府信息公开的实施意见》（苏府办〔2018〕314号）、《省政府办公厅关于推进社会公益事业建设领域政府信息公开的实施意见》（苏政办发〔2018〕101号）要求的政务公开任务，请相关责任单位提供所牵头、参与政务公开任务的落实情况。

（三）报送时间。请各地各部门于2019年2月18日前将统计表、重点领域政务公开工作总结（纸质版加盖公章、电子版发至邮箱）报市政府办公室。联系人：仲海涛，联系电话：53952450，传真：53521300，电子邮箱：39559147@qq.com。
