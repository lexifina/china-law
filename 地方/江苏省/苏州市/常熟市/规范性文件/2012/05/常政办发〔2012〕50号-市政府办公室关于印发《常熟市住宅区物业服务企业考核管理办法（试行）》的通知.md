# 市政府办公室关于印发《常熟市住宅区物业服务企业考核管理办法（试行）》的通知

常政办发〔2012〕50号

各镇人民政府、碧溪新区（街道办事处）、东南街道办事处，常熟经济技术开发区、东南开发区，服装城，虞山尚湖旅游度假区（虞山林场），市政府各部门（直属单位）：

经研究，现将《常熟市住宅区物业服务企业考核管理办法（试行）》印发给你们，请认真贯彻执行。

二〇一二年四月二十七日

常熟市住宅区物业服务企业

考核管理办法（试行）

为了加强对物业管理活动的监督管理，规范我市物业服务企业经营行为，提高物业服务水平，保障业主和物业服务企业的合法权益，维护住宅区和谐稳定。根据《苏州市住宅区物业管理条例》、市委、市政府《关于进一步加强城市管理的工作意见》（常发〔2010〕57号）、《常熟市住宅区物业管理实施办法》（常政发规字〔2011〕2号）、《关于进一步推进我市住宅小区物业管理工作的实施意见》（常政发〔2011〕29号）等有关规定，结合我市物业管理工作实际，特制定本办法。

一、考核对象

在本市范围内从事住宅物业管理活动的物业服务企业，包括在本市注册的和在外地注册的具有物业管理资质的物业服务企业。

二、考核的组织领导

市住房和城乡建设局（具体由市房产管理处实施，以下简称市住建局（房管处））成立市物业服务企业考核领导小组，负责对全市住宅区物业服务企业的考核工作。

三、考核内容

1．住宅区物业服务企业基本情况：主要内容为依法经营、机构设立、规章制度、档案管理、科学管理、社会信誉等。

2．住宅区物业管理工作情况。

3．企业的诚信档案。

四、考核方法

1．每年1月对上年度物业管理工作实施考核。

2．对每家住宅区物业服务企业全年考核设定的综合达标总分为100分，其中企业基本情况评分表（见附件1）占30%，住宅区物业管理工作情况（见《常熟市住宅区物业管理工作考核办法（试行）》）占70%。

3．企业基本情况由市住建局（房管处）进行考评；住宅区物业管理工作情况考核调取属地政府对住宅区物业管理工作情况的考核汇总结果，将每家物业服务企业管理的住宅区考核分的简单算术平均数为最终住宅区物业管理工作情况得分。

4．建立物业服务企业信用档案，年终根据信用档案的记录在各企业考核分数的基础上加（减）分（见附件2）。

五、考评结果

企业全年的综合考评分数=企业基本情况考评得分×30%+住宅区物业管理工作考评得分×70%±企业诚信行为分。

物业企业服务工作考评结果分为四个考核等次，设“良好”、“合格”、“基本合格”、“不合格”四个等次。综合评分在85分（含85分）以上的为“良好”；综合评分在70～84分的为“合格”；综合评分在60～69分的为“基本合格”；综合评分在60分以下的为“不合格”。

六、考评结果的运用

1．每年的考评结果由市房产管理处在相关网站公布，接受社会舆论监督。

2．考核结果作为企业年终评优的依据，考评结果为良好的物业服务企业，才能参加年度物业管理先进企业的评比。

3．凡评为年度物业管理先进企业可在下一年度前期物业管理招投标中加信誉分1分。信誉分在一年内有效，最多不超（含）2次中标后清除信誉分。

4．凡年度综合考核为“不合格”的物业服务企业，将通报批评并限期整改，对整改不力的，记入企业信用档案，情节严重的将报请上级部门吊销资质证书。

九、本考核办法自2012年5月1日开始执行。

附件2：

物业服务企业诚信行为分加减分标准

一、在考核年度内，企业在物业管理行业方面有以下情况之一的，经核实后对企业予以加分。

1．企业获得行业主管部门省级及省级以上表彰的（包括管理的物业项目），加2分，企业内有个人获得省级表彰的，给企业加1分；

2．企业获得行业主管部门苏州市级表彰的（包括管理的物业项目），加1分，企业内有个人获得苏州市级表彰的，给企业加0.5分；

3．企业为构建和谐小区，为业主做出具体实事，并得到小区业主广泛认可或好评，经核实后，加1分；

4．企业在推行市场化进程中有重大举措的，经验被推广或召开现场会，加1分；

5．在市级以上新闻媒体上被表扬的加1分。

二、在考核年度内，企业在物业管理行业方面有以下行为之一的，经核实后对企业进行扣分。累计扣分超过10分的，则当年考评结果为不合格。

1．企业因违反《物业管理条例》规定，受市级主管部门通报批评的一次扣5分；

2．因企业责任被市级新闻媒体曝光披露的一次扣2分；

3．因企业责任被业主投诉的扣1分，下达整改书整改不力的扣3分；

4．因存在严重物业管理问题，造成业主集体到政府部门上访的一次扣5分；

5．主管部门督办事项不能及时完成的一次扣1～2分；

6．因企业责任给业主工作、生活造成严重后果的扣5分；

7．未经法定程序撤出管理服务项目的，每个项目扣10分；

8．虽经法定程序撤出管理服务项目，但因物业服务企业管理不善造成管理环境恶化、共用设施设备瘫痪或不能正常运转等严重情况的，每个项目扣5～10分；

9．前期物业管理阶段，未成立业主委员会而退出的（不包括物业企业协助项目和平过渡，未造成影响的），每个项目扣10分；

10．处理问题和矛盾态度恶劣，致使矛盾激化的，每发生一起扣1～3分；

11．物业服务合同终止时，未按规定移交资料和物业管理用房，每发生一起扣5分；

12．物业服务企业超资质承接项目，出租、出借、转让资质证书的，每发生一起扣10分；

13．其他违反法规、政策，经教育仍不改正的，每件扣1～2分。
