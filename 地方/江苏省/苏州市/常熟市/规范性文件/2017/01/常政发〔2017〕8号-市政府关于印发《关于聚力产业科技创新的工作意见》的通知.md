# 市政府关于印发《关于聚力产业科技创新的工作意见》的通知

常政发〔2017〕8号

各镇人民政府、碧溪新区（街道办事处）、东南街道办事处，常熟经济技术开发区、常熟高新技术产业开发区，服装城，虞山尚湖旅游度假区（虞山林场），市政府各部门（直属单位）:

经市政府第79次常务会议讨论通过，现将《关于聚力产业科技创新的工作意见》印发给你们，请认真贯彻执行。

常熟市人民政府

2017年1月12日

关于聚力产业科技创新的工作意见

为深入实施创新驱动发展战略，全面推进科技创新体制综合改革，加快构建企业为主体、市场为导向、产业为支撑、常创常新的创新创业生态体系，着力补齐科技创新短板，打造体制优势明显的产业科技创新高地，实现精明增长，现提出以下工作意见。

一、加强创新政策制度供给

1．扩大普惠政策受惠面。执行好对企业研究开发费用加计扣除、高新技术企业减按15%的税率征收企业所得税、职工教育经费税前扣除等政策，政策优惠金额年增幅目标按照高于当年财政收入增幅的一定比例确定。建立咨询服务机制和项目鉴定机制，设立研发费加计扣除政策咨询平台，及时受理和解答企业在费用归集、研发项目确定等方面的咨询，提供宽松便捷的研发费用加计扣除纳税服务。（责任部门：国税局、地税局、财政局、科技局）

2．支持企业开展研发活动。鼓励企业开展研发管理体系标准化认证，支持企业通过股权、期权等形式对核心研发人员给予奖励。企业委托外部机构或个人进行研发活动所发生的费用，按照费用实际发生额的80%计入委托方研发费用并加计扣除。委托外部研究开发费用实际发生额应按照独立交易原则确定。企业在研发过程中购买的非专利技术，用于继续开展研发活动，未形成无形资产计入当期损益的，在按规定据实扣除的基础上，按照本年度实际发生额的50%，从本年度应纳税所得额中扣除；形成无形资产的，按照无形资产成本的150%在税前摊销。允许企业研发费加计扣除部分已形成企业年度亏损，用以后年度所得弥补，但结转年限最长不得超过5年。（责任部门：国税局、地税局、财政局、科技局）

3．打通科技成果转移转化通道。对科研院所等事业单位以科技成果作价入股研究院、技术转移机构等新型研发机构的，依规实施股权和分红激励政策，允许其管理层和核心骨干持股，且持股比例上限放宽至30%。其转化职务科技成果以股份或出资比例等股权形式给予科技人员个人奖励时，对符合财政部、国家税务总局财税﹝2016﹞101号文件规定的股权激励和技术入股，经向主管税务机关备案，可实行递延纳税政策。因技术成果作价入股、申请科技贷款等情形产生的成果评估费给予60%资助，最高不超过20万元。对转化科技成果的工业企业，最高按照技术合同交易额的20%，给予最高50万元的后资助；对引进的国内外重大创新成果转化项目，最高按技术合同交易额的20%，给予最高300万元的后资助。（责任部门：国税局、地税局、财政局、科技局）

4．提高科技人员科技成果转化收益。鼓励并支持以技术转让或者许可方式转化职务科技成果。科技成果完成单位未规定、也未与科技人员约定奖励和报酬的方式和数额的，应从技术转让或者许可所取得的净收入中提取不低于50%的比例用于奖励；以科技成果作价投资实施转化的，从作价投资的股份或者出资比例中提取不低于50% 比例用于奖励；在研究开发和科技成果转化中作出主要贡献的人员，获得奖励的份额不低于奖励总额的50%。（责任部门：科技局）

二、深化科技创新体制机制改革

5．实施科技投入结构性改革。在常熟产业升级基金中设立科技创新产业引导基金、双创人才创业投资基金、新型研发公司基金等专项基金，引导优秀的创业投资资本、创业投资机构以及社会资金积极参与，重点支持两区两园，优先投向高新技术企业、初创期科技型企业、战略性新兴产业、企业研究院、省级以上科技企业孵化器、新型研发机构等领域。设立“科技小巨人”培育企业、小微企业、企业研发机构、创新载体和企业科协科技创新券，适当扩大支持覆盖范围。完善科技计划绩效为导向的财政支持制度，组织实施一批科技创新项目，设立工业攻关、前瞻性研究、农业科技与社会发展、科技基础设施、科技企业上市助力、军民融合、主导产业1+N等科技专项。（责任部门：人才办、发改委、财政局、科技局、科协）

6．改革国有创投企业股权交易制度。允许国有创投企业在股权交易时采用估值方式实行事后备案。国有创投企业对创业企业开展股权投资及股权退出时，应按国际通用的估值方法对拟投资企业的投资价值进行估值，根据估值结果进行股权投资并明确退出方式。股权投资前，应当根据尽职调查情况、行业分析、财务分析、估值结果，撰写投资项目分析报告，并按公司章程、管理协议等有关规定履行投资决策程序。退出时也要履行尽职事宜，按照《中华人民共和国公司法》的规定履行相关决策程序，就股权退出事项作出决议。企业履行内部决策程序后，应按照相关规定向国资监管机构办理核准、备案手续。（责任部门：国资办、科技局）

7．实施国有创投企业管理人员跟投制度。对完全市场化的投资项目，国有创投企业管理人员对投资项目可选择或同时使用以下三种方式进行跟投：一是团队强制跟投。对公司确定并投资的项目，其项目团队（人员）应跟随投资。单个投资比例原则上在1%～10%，实际额度由公司根据项目实际情况确定。二是公司管理人员跟投。鼓励中层及以上管理人员对公司确定的投资项目跟投，原则上管理人员出资总额不超过项目投资总额的10%（不含团队强制跟投部分）。三是组合基金跟投。由项目团队、公司管理人员、投资引导基金（包括上级财政支持）共同设立组合基金，对公司确定的投资项目跟投，跟投比例不超过投资总额的20%。跟随投资与主投股权遵循“同进同出，同股同利”的原则，跟投过程中的账务处理、融资支持等事项按有关规定或行业规则执行。（责任部门：国资办、科技局）

8．提升创新载体运营水平。全市科技园区基本建立扁平化、公司化运作平台和管理机制，以两区两园为重点建设以平台开发、产业服务、科技基础设施建设、投融资服务为主的科技园区管理开发公司。实施科技园区（大学科技园、科技创业园、农业科技园等）、重点创新平台管理机制改革提升，按照社会经济管理职能和所有者职能分开的原则，对管理公司实行规范管理和股份制改造，建立现代企业管理制度和法人治理结构。试点开展公司管理层股权激励试点工作，允许技术、管理骨干持股，且持股比例上限放宽至30%，并在股权激励审批、国有资产评估、激励资金来源等方面给予支持。（责任部门：国资办、各科技园区和重点创新平台所在地政府、科技局）

三、大力构筑良好创新生态

9．推进企业研究院建设。重点鼓励企业通过自主投资、联合科研院所等方式建立具有独立法人资格的企业研究院。企业研究院可在政府项目承担、职称评审、人才引进、建设用地、投融资等方面享受相应科研机构同等待遇。对符合产业规划、城乡总体规划、土地利用总体规划的企业研究院项目按工业用地供地政策管理，在土地利用计划指标中优先安排建设用地，在用地评价时按专项服务业项目建设用地对待，在项目投资强度和固定资产投资规模要求上不设门槛，工业区内按工业用地、其他规划区内按科教用地同等价格出让（相关政策按《苏州市专项服务业项目建设用地出让实施意见》苏府〔2011〕217号执行）。企业利用自有土地建设企业研究院的，简化审批流程，减免相关规费。在常熟产业升级基金中设立新型研发公司基金参与企业研究院建设，对重大的企业研究院（海外研究院）建设项目，可按一事一议方式给予支持。鼓励企业研究院核心技术人员和团队以科技成果、现金等形式入股，常熟产业升级基金以天使方式投资企业研究院公司，引入股权激励奖励核心技术人员和团队。（责任部门：科技局、财政局、发改委、国土局、规划局、人社局）

10．加快新型研发机构建设。鼓励对研究院管理层实施股权激励、年薪制度和岗位流动制度，鼓励支持研究院对孵化项目、产业化项目实行跟随投资。取消新型研发机构等对科研人员的绩效支出比例限制，对劳务费不设比例限制，探索建立协议工资、项目工资等新型薪酬制度，落实科研人员兼职兼薪政策，参与研究院项目的非研究院人员及聘用的研究人员均可参照我市科学研究和技术服务业从业人员平均工资水平，根据其在项目研究中承担的工作任务确定劳务费，其社会保险补助纳入劳务费科目列支。支持大学研究院开展产业重大关键技术集成开发和科研单位技术成果到研究院进行二次开发，并通过向企业转移转化和联合企业攻关等形式实施技术成果产业化。企业用于研发活动而购买的大学研究院技术成果或委托大学研究院进行技术研发所发生的支出，纳入企业研发费用加计扣除政策支持范围。（责任部门：人社局、科技局、国税局、地税局）

11．建立创新产品推广使用机制。编制自主创新产品推荐目录，将市级以上领军人才企业、高新技术企业等科技型企业研发生产并首次投放市场的创新产品纳入目录，鼓励财政性资金在同等条件下优先采购和推广应用创新产品，促进创新产品规模化应用。建立健全符合国际规则、支持采购创新产品和服务的政策体系，加强对创新产品研制企业和用户方的双向支持，通过预留份额、评审优惠和合同分包等方式提高中小企业政府采购比例。探索通过科技保险等方式建立创新产品“首购首用”风险补偿机制。（责任部门：财政局、人才办、发改委、经信委、科技局）

12．加大公共科技服务供给。建立科技资源共享机制，推动和完善科技信息服务体系建设，编制行业创新资源与领军人才分布图，建立比较完善的产业科技合作项目库和专家资料信息库，为企业技术创新提供信息和技术支撑。开展重大经济、科技活动知识产权分析评议、产业预警分析，推进知识产权运营、保险、托管、质押融资等新型服务。推进基于大数据的科技创新创业服务云平台建设，通过数据中心实现市科技计划、科技金融等主要业务的全流程管理，为省级科技创新体制综合改革试点的示范应用建设打造信息支撑平台。构建创新协作网络，支持行业骨干企业牵头组建国家级或省级产业技术创新战略联盟。对新认定为国家级、省级产业技术创新战略联盟的，分别给予牵头单位一次性300万元、100万的资助，给予参加单位一次性10万元的奖励。对参加国内外高新技术产品展览会（国际、国家级），按照展位费用的50%给予后补助。（责任部门：科技局、知识产权局、商务局、经信委）

成立由市政府主要领导任组长，分管领导任副组长，市有关部门为成员的工作领导小组，具体负责综合协调、组织考核、指导监督等工作。凡享受本市各类财政奖励政策的企业，在同一政策年度内执行就高原则，不重复享受。本市级原有科技创新政策措施与本意见不一致的，以本意见为准。

本意见自2017年1月1日起执行。
