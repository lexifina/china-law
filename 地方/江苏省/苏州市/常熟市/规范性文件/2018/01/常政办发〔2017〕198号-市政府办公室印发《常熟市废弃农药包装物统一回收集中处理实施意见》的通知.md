# 市政府办公室印发《常熟市废弃农药包装物统一回收集中处理实施意见》的通知

常政办发〔2017〕198号

各镇人民政府、碧溪新区（街道办事处）、东南街道办事处，常熟经济技术开发区、常熟高新技术产业开发区，服装城，虞山尚湖旅游度假区（虞山林场），市政府各部门（直属单位）:

经市政府第8次常务会议讨论通过，现将《常熟市废弃农药包装物统一回收集中处理实施意见》印发给你们，请认真贯彻执行。

常熟市人民政府办公室

2017年9月29日

常熟市废弃农药包装物统一回收

集中处理实施意见

农药是现代农业生产的基本生产资料，废弃农药包装物已成为不可忽视的农业生态污染源。为了全面推进农业水环境治理，有效解决废弃农药包装物造成农业面源污染的问题，消除对农业、农村生态环境乃至公共安全潜在的隐患,现就我市实施废弃农药包装物统一回收集中处理工作提出如下实施意见：

一、基本思路

实施废弃农药包装物回收处理事关生态环境保护和美丽乡村建设,关系农民利益、人民身体健康和社会稳定。要坚持公益化扶持、社会化服务、企业化运作、长效化管理的原则，通过定点回收、分类整理、集中存放、规范处理的工作途径，实现常熟区域废弃农药包装物全面回收，保障水源、土壤、空气等生态环境质量，保护青山绿水良田，为建设精致常熟营造良好生态环境。

二、实施办法

1．回收范围：主要对本市内实际使用产生的废弃农药包装物进行全面回收，不回收非农药包装物和市外流入农药包装物。

2．实施主体：为更好地提升市农药集中配送网络体系为农服务作用，扩大服务功能，明确由农药集中配送企业----常熟市农业生产资料有限公司为实施主体，具体组织下属各农药配送站点进行废弃农药包装物回收。

3．工作流程：定点回收—分类整理--集中转运--专库储存—有资质单位无害化处理。各农药配送站点回收废弃农药包装物之后，由市农资公司定期将各配送站点回收的农药包装物运至农资配送中心专库存放，实行专人负责，定期办理相关手续，委托有资质的运输单位统一运输到具有相应资质的危险废物经营单位进行集中焚烧处理。

三、具体要求和标准：

1．统一配置用具。各回收点要统一配置相应的回收桶或回收袋，便于分类归集整理，安全存放。专业人员须配必要的防护用品。

2．统一回收价格。根据全市实际农药销售情况，实行分类回收、确定回收价格标准，按件计价。农药废弃包装物回收的价格标准为：瓶装按每件0.30元回收；袋装按每件0.10元回收；支装按每支0.05元回收。

3．统一集中处理。市农资公司根据环保部门公布的危险废物经营单位名单确定废弃农药包装物具体处置单位，并签订处置合同，定期交危险废物经营单位进行集中处理，确保废弃农药包装物回收处置工作的规范化、科学化。

四、资金来源

废弃农药包装物的回收处置是一项公益事业，由市政府每年安排专项资金，对各环节所需资金给予财政补贴。具体包括以下几项费用：①废弃农药包装物回收费用。②分类整理包装、防护用品等费用。③常熟市农资公司和回收站点各给予0.07 元/袋（瓶、支）的工作补贴④危化品焚烧处理费（含运输费）。⑤宣传费用。⑥电子平台软件等其他一次性费用。废弃农药包装物回收费用和回收补贴资金采取预拨和审核结算相结合的办法，与农药集中配送财政补贴资金结算同步进行。

五、组织领导

1．成立领导小组。市政府成立由市政府办、市供销总社、农委、财政局、环保局等部门组成的工作领导小组，各成员单位要按照市政府的统一部署，研究制定废弃农药包装物回收处理工作的相关政策和措施，研究解决工作中出现的新情况、新问题。各成员单位要切实履行职责，通力协作，密切配合，强化监督。市供销合作总社负责牵头实施废弃农药包装物回收工作，并会同农委、财政局、环保局做好农药包装物回收、处置费用和补贴的审核结算等工作；市农委负责定期开展检查，查处违规回收废弃农药包装物行为，做好废弃农药包装物回收处置的宣传培训；市财政局负责农药包装物回收、处置费用和补贴的审核工作，并按规定及时拨付回收、处置费用和工作补贴；市环保局负责废弃农药包装物无害化处理的监管工作。

2．加强宣传引导。废弃农药包装物回收是助推现代农业发展，保障自然生态环境的一项重要举措。各镇（区）各部门要通过多种形式，引导推广使用高效低毒低残留农药,广泛开展农业环保知识和因乱扔农药包装物造成环境污染，破坏生态环境违法犯罪等方面宣传，帮助农民树立农药包装物回收的社会责任感，激发市民主动参与保护环境意识，为精致常熟建设营造良好氛围。

3．加强监督管理。市供销总社、农委、财政局、环保局等相关部门要加强对责任主体的监督管理。市供销合作总社要加强对日常回收进行考核监督，制订考核办法，与回收实施主体签订《废弃农药包装物回收工作责任书》，严肃回收纪律，严格按规定操作，确保安全。根据考核结果拨付财政补贴，确保财政资金用到实处。如发现违规回收和自行处置废弃农药包装物现象，回收费用由违规责任人自行承担，取消财政补贴，直至追究法律责任。

本办法自 2018年1月1日起执行。
