# 市政府办公室印发《常熟市新动能产业发展人才扶持政策实施办法》的通知

常政办发〔2019〕111号

各镇人民政府，各街道办事处，常熟经济技术开发区、常熟高新技术产业开发区、常熟国家大学科技园、虞山高新区（筹）、虞山尚湖旅游度假区（虞山林场）、服装城管委会，市各委办局、直属单位（公司）:

经市政府第37次常务会议讨论通过，现将《常熟市新动能产业发展人才扶持政策实施办法》印发给你们，请认真贯彻执行。

常熟市人民政府办公室

2019年9月2日

（此件公开发布）

常熟市新动能产业发展人才扶持政策实施办法

为进一步优化人才发展环境，推动新动能产业加速发展，促进产业结构转型升级，根据《常熟市新动能产业发展扶持政策》（常办发〔2019〕102号）和市委第91次常委会要求，制定本办法。

一、实施原则

本办法主要适用于新动能产业目录清单企业内的相关人才，具体由各板块对扶持对象的资格进行审核认定，市相关部门根据审核结果落实各项扶持措施。

二、扶持内容

（一）关于人才落户

1．扶持对象：新动能产业目录清单企业中层及以上干部、本科及以上工作人员。

2．操作流程：（1）申请落户人员向所属企业提出落户需求；（2）企业汇总本单位落户需求后统一向所属板块提出落户申请；（3）板块对申请落户人员情况进行审定并出具符合新动能产业发展人才落户政策的相关证明；（4）申请落户人员凭板块出具的审核证明及其他相关资料至公安局办理落户手续。

（二）关于个人所得税奖励

1．扶持对象：新动能产业目录清单企业中层及以上干部、本科及以上工作人员，且上一自然年度在本市工作并在本市缴纳工薪收入个人所得税。

2．操作流程：（1）每年4月，由企业汇总本单位符合奖励条件的人员名单及其个人所得税缴纳清单向所属板块申报；（2）板块会同税务部门对企业申报信息审核确认后上报市财政局、人才办备案；（3）市财政局将在册名单人员缴纳的个人所得税地方留成部分通过财政体制结算至各企业所属板块；（4）由企业所属板块实施奖励兑付工作。

3．操作说明:申报对象在我市范围内获得的人才奖励金额参照人才政策有关规定，并按就高不重复原则进行奖励。

（三）关于就医绿色通道

1．扶持对象：新动能产业目录清单企业高管或高级技术人才。

2．操作流程：（1）目录清单企业汇总本单位符合就医绿色通道扶持政策的人员信息后向企业所属板块进行申报；（2）板块对企业申报的高管或高级技术人才信息核实审定后上报市卫健委；（3）市卫健委根据板块的审定结果将相关信息录入就医绿色通道信息化识别系统，并核发就医绿色通道卡。

3．由卫健委负责落实服务保障各项具体措施。

（四）关于子女入学支持

1．扶持对象：新动能产业目录清单企业高管或高级技术人才。

2．操作流程：（1）目录清单企业汇总本单位高管或高级技术人才子女入学需求后向企业所属板块进行申报；（2）板块对申报子女入学需求的企业高管或高级技术人才信息核实审定后上报市教育局；（3）市教育局根据全市入学需求申报情况统筹调剂所需学位至相关板块，由板块负责具体学位分配工作。

3．操作说明：具体操作事项参照《常熟市领军型人才、高层次紧缺人才、外商和市外投资企业高层管理人员、军转干部及港澳台侨商等子女入学（园）实施意见》（常政办发〔2015〕181号）执行，并允许非起始年级转学插班，保证符合条件对象全部入学就读。

三、其他事项

1．扶持对象及其所属企业应对申报材料的真实性负责，若存在虚假申报等行为的，一经查实，列入信用失信记录，取消扶持资格，并按规定追究相关人员法律责任。

2．企业所属板块应当共同协助做好申报及后续管理等相关事宜，并对申报内容严格审核把关。

3．本办法所列扶持内容可与现行人才政策同时享受，个税奖励按就高不重复原则处理。

4．本办法自2019年6月25日起施行，有效期3年。
