# 常熟市政府关于公布2018年以前规范性文件清理结果的通知

市政府关于公布2018年以前规范性文件

清理结果的通知

（常政发规字〔2019〕3号）

各镇人民政府，各街道办事处，常熟经济技术开发区、常熟高新技术产业开发区、常熟国家大学科技园、虞山高新区（筹）、虞山尚湖旅游度假区（虞山林场）、服装城管委会，市各委办局、直属单位（公司）:

根据《江苏省规范性文件制定和备案规定》要求，市政府对2018年12月31日以前本级政府制定的120件规范性文件进行了全面清理。共计89件继续有效，16件废止，4件宣布失效，11件拟修改。根据《中华人民共和国政府信息公开条例》规定，现将清理结果予以公布，请认真贯彻执行。
