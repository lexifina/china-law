# 市政府办公室印发《常熟市关于进一步推动绿色殡葬改革工作的实施意见》的通知

常政办发〔2019〕72号

各镇人民政府，各街道办事处，常熟经济技术开发区、常熟高新技术产业开发区、常熟国家大学科技园、虞山高新区（筹）、虞山尚湖旅游度假区（虞山林场）、服装城管委会，市各委办局、直属单位（公司）:

经市领导同意，现将《常熟市关于进一步推动绿色殡葬改革工作的实施意见》印发给你们，请结合实际，认真贯彻执行。

常熟市人民政府办公室

2019年6月11日

（此件公开发布）

常熟市关于进一步推动绿色

殡葬改革工作的实施意见

殡葬改革工作事关人民群众切身利益，事关精神文明和生态文明建设。近年来，特别是党的十八大以来，殡葬改革深入推进，殡葬公共服务能力明显改善，殡葬治理水平不断提升，殡葬事业取得较大发展。但要看到，殡葬改革工作是一项长期艰巨的任务，殡葬改革发展水平与人民群众期待需求、与经济社会发展要求还有一定差距。为进一步增强殡葬改革动力，激发殡葬事业发展活力，更好地满足人民群众殡葬服务需求，促进殡葬事业健康可持续发展，结合我市实际，提出如下意见。

一、指导思想

全面贯彻党的十九大精神，以习近平新时代中国特色社会主义思想为指导，坚持以人民为中心的发展思想，践行新发展理念，科学规划布局，落实惠民殡葬政策，完善骨灰堂建设和管理，大力推进殡仪服务中心建设，倡导绿色殡葬、文明殡葬，加强殡葬行业的依法监管和规范运行，树立殡葬文明新风，推动殡葬改革和殡葬事业更好服务于保障和改善民生，促进精神文明和生态文明建设。

二、基本原则

（一）公平可及，群众受益。把以人民为中心、满足群众殡葬需求作为出发点和落脚点，坚持推进殡葬改革与完善殡葬服务供给相结合，优化殡葬资源配置，完善殡葬服务网络，建立基本殡葬服务制度，实现基本殡葬公共服务均等化。

（二）坚持改革，移风易俗。坚定不移推行殡葬改革，把尊重生命、绿色文明的理念贯穿于殡葬改革全过程，大力弘扬社会主义核心价值观，把文明节俭治丧、节地生态安葬、文明低碳祭扫转化为人们的情感认同和行为习惯，传承发展优秀传统文化，破除丧葬陋俗，树立殡葬新风尚，促进人与自然和谐共生。

（三）政府主导，社会参与。充分发挥政府在推动殡葬改革中的主导作用，建立健全基本殡葬公共服务体系，完善监管体制机制，全面加强殡葬行业监管。积极推进殡葬服务供给侧结构性改革，引导社会力量有序参与，满足群众多样化殡葬服务需求。

（四）因地制宜，分类指导。坚持实事求是，因地制宜，注重统筹规划和协调；坚持政策引导，加强组织推进，实行分类指导，促进殡葬改革规范有序发展。

（五）统筹协调，综合治理。坚持在各级党委和政府统一领导下开展工作，强化民政部门行业监管责任，完善部门协同监管机制，加强基层工作力量，建立健全组织有力、职责明确、协调顺畅的领导体制和工作机制。发挥基层群众自治、行业协会自律、社会监督等方面作用，创新监管手段和治理方式，实现政府、社会、市场优势互补，良性互动。

三、总体目标

进一步落实和完善惠民殡葬政策，全面提升惠民殡葬服务能力和水平；加快以公益性骨灰堂和殡仪服务中心建设为重点的殡葬设施建设，完善群众治丧场所；强化骨灰堂内部管理，提升殡葬服务水平；倡导和鼓励绿色生态葬法，引导文明节俭办丧，革除丧葬陋习；实现殡葬改革有序化、殡葬设施现代化、殡葬管理规范化、殡葬服务优质化、散坟整治常态化、节地安葬生态化、祭祀习俗文明化。

四、主要任务

（一）健全工作机制，落实惠民殡葬政策。在全面实施惠民殡葬政策的基础上，建立和完善惠民殡葬工作机制，优化殡葬服务内容、程序和标准，建立便民惠民殡葬服务和信息网络，形成以基本殡葬服务为主体、选择性服务为补充的服务格局，努力提升惠民殡葬服务的能力和水平。

（二）完善服务供给，加快殡仪设施建设。按照“放管服”改革的要求，完善市场准入条件，探索供给主体和供给方式多元化，强化事中事后监管，引导各类主体规范提供服务，丰富殡葬产品供给，满足群众个性化、多样化的殡葬服务需求。加快推进殡葬信息化建设，创新殡葬服务与“互联网+”融合发展的新途径、新模式、新业态，打造智能便民、阳光透明、规范有序的殡葬服务市场环境。同时，继续加强对已建骨灰堂的改造升级，有序扩建停车场地、道路、绿化、照明和休息场所，拓展服务功能。大力推进殡仪服务中心建设，认真规划、合理选址，切实为人民群众特别是集中居住区居民提供集守灵、休息、用餐等功能为一体的集中办丧场所。

（三）依法规范管理，提升殡葬服务水平。根据《常熟市骨灰堂管理办法》，切实加强对骨灰堂的规范化管理，制定统一的规范标准，定期开展考评，落实属地政府年度检查和日常监管。禁止新建、扩建墓地，严格遵守2004年确定的墓区界址，不得扩大原有墓穴规模。对现有虞山墓区内的墓穴，按照20年使用年限实行退出机制，使用期满后一律停止使用。

（四）加快散坟整治，落实绿色生态安葬。仍未完成散坟搬迁的镇（街道）应加快推进，可采取就地深埋或统一搬迁至骨灰堂等方式进行，并及时组织力量将原墓区用地、墓穴占地复耕还田（林）。同时，探索研究殡葬改革理论和机制创新，加强殡葬科技成果应用，创新骨灰安葬方式，推进骨灰处理多样化，推广节能减排的殡葬设备和一次性可降解骨灰盒的使用，倡导居民采用生态绿色方式安葬逝者骨灰，适时推广可降解骨灰盒葬和海（江）葬等生态葬法。

（五）推进移风易俗，树立现代殡葬理念。充分利用各种有利时机，广泛开展殡葬政策法规的宣传，各殡仪服务场所要加大孝文化宣传，弘扬先进殡葬文化，积极倡导文明节俭办丧，引导群众自觉破除丧葬陋俗。同时，结合实际，制定文明殡葬的村规民约，充分发挥村（居）委会、红白理事会等基层群众自治组织作用，增强人民群众参与殡葬改革的自觉性。

五、奖补政策

（一）骨灰堂格位管理费减免标准。因拆迁需要迁移的骨灰或自愿从墓穴中迁移的骨灰（遗骨）安放在骨灰堂的，免除五年存放维护管理费；特困人员、重点优抚对象骨灰安放在骨灰堂的，免除存放维护管理费；离休干部夫妻双方骨灰安放在经营性骨灰堂的，格位费可享受7.5折优惠；烈士骨灰安放到骨灰堂的免除所有费用。

（二）基本丧葬服务费用减免标准。在本市范围死亡并在本市殡仪馆办理火化的人员（含本市户籍在外地死亡并在外地办理火化的人员），免除殡葬基本服务项目费用，免费金额标准为：普通殡葬专用车遗体接运费补贴200元；遗体消毒费30元；三天内普通冷藏柜遗体存放费180元；普通火化设备遗体火化费600元；骨灰盒费500元。减免费用最高限额1510元。其它收费标准按照市发改委相关收费政策执行。另外，城乡低保对象和低保边缘重病困难对象、特困人员、重点优抚对象死亡的，由市殡仪馆免费提供普通告别厅使用；公安机关经办处理的无名、无责尸体按实际发生额结算。所需费用由市级财政负担。

（三）绿色殡葬的补贴标准。在政府指定区域办理可降解骨灰盒葬手续，由死者生前户籍所在镇（街道）民政办负责实施，经办人填写《常熟市绿色殡葬补贴申请表》，凭身份证、户口簿、户口注销证明、遗体火化证明等相关材料到死者生前户籍所在镇（街道）民政办办理补贴手续，每例2000元，所需费用由市级财政负担。海（江）葬由苏州市或常熟市民政部门统一组织，并在指定的时间和区域内实施。经办人凭身份证、户口簿、户口注销证明、遗体火化证明等相关材料到常熟市殡葬事业管理所办理手续，每例补贴2000元，所需费用由市级财政负担。

六、保障措施

（一）强化属地管理，落实工作责任。各镇（街道）要严格按照现行的殡葬政策法规，加强对辖区内骨灰堂和殡仪服务中心等殡葬设施的管理，明确岗位职责，健全规章制度，配备工作责任心强、热爱殡葬事业的同志从事殡葬服务岗位，积极配合民政部门开展从业人员职业培训、考核，加强人才队伍建设，建立以岗位责任与绩效考核为基础的综合考评制度，提高殡葬行业职工整体素质和能力。深入开展殡葬改革示范项目和理论创新、机制创新活动，努力形成既符合实际又具有特色的殡葬改革和发展模式，确保殡葬改革有序推进和社会稳定。

（二）加强部门协作，形成工作合力。坚持政府主导、分工协作、行业规范、齐抓共管的原则，共同推进殡葬改革持续深入开展。民政部门要牵头做好殡葬管理政策标准制定和殡葬改革的组织实施，负责骨灰堂、殡仪服务中心等殡葬基础设施建设的业务指导，督促各镇（街道）抓好散坟整治和骨灰堂的管理，引导民间殡葬习俗的有效转变，协调相关部门做好殡葬服务行业相关整治工作。组织人事部门要及时掌握党员干部治丧情况，加强党员干部教育管理，严格执行党员干部带头推动殡葬改革要求。宣传部、文明办要做好殡葬改革宣传引导工作，将移风易俗、文明办丧纳入文明创建活动内容。发展改革部门要加强对殡葬事业发展的规划，建立殡葬事业公共投入和稳定增长机制，加大对提供基础殡葬服务的殡葬设施建设支持力度。公安部门要加强对本部门出具的非正常死亡证明的管理，依法查处丧事活动中违反治安管理、交通管理和私自改装车辆运输遗体的行为，积极推进殡葬信息共享，发现死亡人员未销户线索的，及时核对、注销。财政部门要落实保障殡葬公共设施建设资金和运行管理经费，支持节地生态安葬奖补政策，落实惠民殡葬政策，保障殡仪馆遗体处理设备的环保疾控改造所需资金落实到位。自然资源部门要依法加强殡葬设施规划和建设管理，保障纳入规划的殡葬设施用地需求，做好节地生态安葬设施用地统筹安排，联合相关部门纠正和查处违法违规建设殡葬设施、建坟等行为。生态环境部门要参与制定本地区殡葬总体规划，指导支持火化机环保改造，强化殡葬活动的生态环境监管。文化部门要配合做好殡葬改革宣传工作，与相关部门配合创新发展殡葬文化，查处殡葬活动中封建迷信行为和低俗不健康活动。卫生健康部门要加强对医疗机构出具死亡医学证明和医疗机构太平间的管理，配合殡葬管理部门做好遗体的管理和接运，指导殡仪服务单位做好卫生防疫工作。市场监管部门要配合查处制造、销售不符合国家技术标准、封建迷信丧葬用品等违法行为，要加强殡葬服务收费管理，查处殡葬价格不按规定公示、违规乱收费、限制价格竞争等违法行为，要查处殡葬行业中的不正当竞争、垄断及其他损害竞争秩序和侵犯消费者合法权益的违法行为。宗教事务部门要依法规范宗教活动场所建设骨灰存放设施和丧葬活动行为。基层党组织、村（居）委会、红白理事会、老年人协会等要充分发挥作用，广泛动员群众积极参与殡葬改革，积极倡导殡葬文明新风。

（三）坚持党员干部带头，强化示范引领。严格落实中央八项规定精神和党员干部带头推动殡葬改革的要求，增强党员干部政治意识和纪律意识，提高党规党纪的约束力。党员干部要依法开展殡葬活动，骨灰集中安葬，带头文明节俭治丧，自觉参加节地生态安葬，实行文明低碳祭扫。要加强对直系亲属和身边工作人员的教育管理，约束他们参加丧葬活动行为。对于党员干部去世后，在治丧、办丧活动中存在的封建迷信活动现象和违规土葬、装棺再葬、超标建墓、大操大办等行为，要依法依规依纪严肃查处，为社会树立正确导向。

（四）加强殡葬监管，推进行风建设。认真研究殡葬改革工作中遇见的实际问题，制定公平公正的行业政策。坚持把以人为本、服务群众作为行风建设和纠风工作的主要内容，积极开展民主评议和行风建设示范单位创建活动，落实惠民殡葬政策。要在各殡葬服务场所显著位置公布服务项目、收费标准、文件依据、减免政策、服务流程、服务规范及举报电话，实行服务承诺和服务问责制，防止和纠正利用行业特殊性损害群众利益问题的发生。

（五）加强宣传工作，确保有序发展。坚持正确的舆论导向，积极整合各种资源，充分利用清明、大寒等有利时机，运用多种形式围绕“惠民殡葬、文明祭扫、生态殡葬”等内容进行持续有效的宣传，有组织地开展殡葬宣传进社区、进乡村、进家庭活动；报刊、电视、互联网等新闻媒体要主动配合，倡导文明新风，宣传先进典范，丰富殡葬文化，营造舆论氛围，推进殡葬改革的法制化、规范化、常态化。

该意见自2020年1月1日起施行。
