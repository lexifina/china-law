# 关于下发《关于切实加强课外阅读提高学生综合素养的实施意见》的通知

各小学、九年一贯制学校、新市民子女学校：

为推进各校深入实施素质教育，引导、激励学生“多读书、读好书、好读书、会读书”，提高思想文化修养，促进自身精神成长，我们制定了《关于切实加强课外阅读 提高学生综合素养的实施意见》(以下简称《实施意见》)，现正式下发。

希望各校认真组织学习，根据《实施意见》精神，加强组织领导，制定实施计划，扎实开展学生课外阅读活动，为学生的全面发展和终身发展奠实基础，并以此为突破口与载体，不断丰富学校内涵建设，努力提升学校办学水平。

张家港市教育局

二〇一二年五月八日

（此件主动公开）

关于切实加强课外阅读 提高学生综合素养的实施意见

为全面贯彻党和国家的教育方针，认真贯彻落实《江苏省中小学管理规范》、《苏州市深化素质教育，丰富校园生活，促进学生全面发展的三项规定》等文件精神，切实提高学生的综合素养，特制订本实施意见。

一、指导思想

以《义务教育语文课程标准》（2011年版）为指导，根据学生认知特点、心理特征与身心发展规律，按年级选择适合学生阅读的童话、寓言、故事、诗歌散文作品、长篇文学名著、科普科幻作品等作为必读书目与选读书目（不包括《义务教育语文课程标准》推荐的优秀诗文篇目），切实开展形式多样的读书活动，努力构建完备合理的评价体系，引导、激励学生“多读书、读好书、好读书、会读书”，吸收古今中外优秀文化，提高思想文化修养，促进自身精神成长。

二、目标任务

培养学生广泛的阅读兴趣，扩大阅读面，增加阅读量，小学六年课外阅读总量不少于145万字；加强对阅读方法的指导，让学生逐步掌握精读、略读、浏览、摘抄、批注、写读书心得笔记等基本方法，提高阅读能力，养成“边读边思考”、“不动笔墨不看书”等良好的阅读习惯；注重优秀文化的熏陶感染，引导学生形成正确的世界观、人生观、价值观，提高思想道德修养与审美情趣，逐步形成良好的个性与健全的人格，为全面发展和终身发展奠实基础；积极营造“书香校园”，切实推进课程改革，深入实施素质教育，着力加强学校特色建设与文化建设，不断丰富学校内涵建设，努力提升学校办学品位。

三、重点工作

（一）丰富阅读资源，让学生“有书读”

进一步加强学校图书室、阅览室、读书廊等阅读阵地建设，按《张家港市小学生课外阅读推荐书目》要求，通过正规渠道添置能满足各年级学生阅读需求的必读书目与选读书目；健全借阅、管理等制度，周一至周五全天向学生开放，双休日、节假日定时向学生开放。有条件的学校，应建设并向学生开放数字图书馆、电子阅览室。切实加强班级图书角建设，倡导通过教师、学生、家长“捐书共建”、“图书漂流”等方式，丰富并让学生共享优质图书资源。

（二）营造阅读氛围，让学生“爱读书”

大力营造浓郁的阅读氛围，激发学生课外阅读的兴趣。充分利用学校小广播、校园电视、网站、橱窗、廊道等阵地与渠道，推荐优秀课外读物，普及课外阅读知识，介绍课外阅读方法；图书室、阅览室等场所应设置“新书推荐”、“读者园地”等栏目，布置富有教育性、激励性的读书励志名言等内容；各班要开辟课外阅读专栏，定期展示学生的读书摘抄、读书心得等内容；同时，要通过印发告学生家长书、“家校路路通”等方式与渠道，指导学生家长参与读书活动，形成“家校共读”的良好氛围。

（三）优化阅读指导，让学生“会读书”

努力优化对学生课外阅读的指导，着力做到“四个保证”：指导教师保证，由语文教师具体负责对本班学生进行课外阅读内容的选择、方法的指导、成效的评价等工作；指导时间保证，原则上利用下午综合文体活动（“学校少年宫”活动）时间或语文综合实践活动时间，每两周不少于1课时；指导内容保证，根据《张家港市小学生课外阅读推荐书目》，引导教师精心制定指导计划、选定指导内容、设计指导流程；指导成效保证，认真开设“好书推荐课”、“心得交流课”、“名篇鉴赏课”、“疑难讨论课”等形式多样的阅读指导课，指导学生掌握阅读方法，提高阅读能力。

（四）创新阅读活动，让学生“多读书”

不断创新方式方法，因校制宜开展丰富多彩的阅读活动，力求做到“三个结合、六项落实”：将课外阅读与语文课堂教学有机结合，由课内延伸到课外；将课外阅读与“学校少年宫”活动（综合文体活动）有机结合，实现活动内容与组织方式等的有效整合；将课外阅读与学生寒暑假生活要求有机结合，融合“三会”要求。晨诵午读活动落实，每周不少于1次；师生共读活动落实，每两周交流读书体会不少于1次；亲子阅读活动落实，每学期以班级为单位进行汇总、反馈等不少于1次；研讨活动落实，每学期开展课外阅读专题教研活动不少于1次；阅读大赛活动落实，每学期开展优秀读书笔记评比、“故事大王”比赛、读书知识竞赛等活动不少于1项；读书节活动落实，每年不少于1次。

（五）改进阅读评价，让学生“乐读书”

积极改进阅读评价，努力推动课外阅读深入持久开展。强化“阅读之星”、“书香少年”、“书香班级”等评比表彰活动，激发学生的阅读动力，培养学生的阅读习惯，提高学生进行课外阅读、班级组织开展课外阅读的整体水平；推行“小小藏书家”、“书香家庭”等评选活动，推动学生家庭藏书、家庭读书；探索建立学科评价机制，将必读书目的基本内容纳入语文学科期末考试考查中，引导、督促教师认真组织开展课外阅读活动，不断提高学生课外阅读的实效。

四、保障措施

（一）强化组织领导

市教育局成立小学生课外阅读领导小组，由分管局长任组长，基础教育科、教学教研室相关成员为组员，具体负责全市小学生课外阅读的组织、指导、考评等工作。各校要成立相应的领导小组，由校长任组长，分管教学的副校长任副组长，组员由教导处、德育处、总务处等部门人员担任。学校领导小组要科学规划、认真组织开展学生课外阅读活动。

（二）加大宣传力度

各校要通过举办家长学校、召开家长会、编发课外阅读简讯、图书馆网页开辟课外阅读专栏、建立师生课外阅读博客等方式与途径，宣传学校开展课外阅读的重要意义、具体安排、活动动态等内容，争取家长的认同、支持与参与；要通过《张家港日报》、张家港电视台、张家港教育信息网等媒体，宣传学校开展课外阅读的成功经验与取得的成果，扩大开展课外阅读的影响力。

（三）加强考核评估

各校要建立与完善对教师组织指导学生开展课外阅读的考评机制，加强过程性检查与考核，将考核结果与评优评先等相挂钩。市教育局将定期评选表彰“课外阅读优秀指导教师”以及“书香教师”，适时开评“张家港市书香校园”；同时，将加强对各校开展学生课外阅读的专项调研，并将调研结果纳入“学校文化建设达标（先进、示范）学校”评估中。
