# 关于调整城北、城东、城西派出所管辖区域的通知

张公发〔2012〕134号

各警署、各派出所、直属各单位、机关各部门：

为进一步明确和方便治安、户籍管理和110接处警、案件侦办等工作，根据开发区（杨舍镇）村（居委）行政管辖调整的相关情况，市局决定对城北、城东、城西派出所管辖区域进行调整。现将相关情况明确如下：

1. 将华昌路以东原城北派出所辖区区域划归城东派出所管辖。具体为：原城北派出所管辖的华昌路以东（以路面中心线为准）、张杨公路以南、东横河以北、大寨河以西（以河中心线为准）城东村东区区域划归城东派出所管辖。

2. 将原城西派出所管辖的国泰北路以西、长兴路以南、东横河（以河中心线为准）以北、西二环路以东（以路面为准）区域划归城北派出所管辖，原泗港杨港村户籍仍由城西派出所管理。

3. 为确保工作的连续性，将城西派出所陈东庄村社区民警郝科调入城北派出所，将城北派出所城东村东区社区民警刘志军调入城东派出所，户口协管员和村级联防队员随社区民警一并划归相应派出所管理。

4. 调整时间为 2012年9月1日零时。

特此通知。

张家港市公安局

二○一二年八月二十日
