# 关于认真学习贯彻张家港建县（市）50周年纪念大会精神的通知

各警署、各派出所、直属各单位、机关各部门：

10月28日隆重举行的张家港建县(市)50周年纪念大会，是我市在特殊的历史时刻，召开的一次承前启后、继往开来的重要会议，是一次凝聚人心、激励斗志的鼓劲会，更是一次续写辉煌、再创伟业的动员会。深入学习贯彻张家港建县(市)50周年纪念大会精神，对于全市上下加快建设现代化港城具有重要的现实意义。根据市委统一部署，现将学习贯彻张家港建县(市)50周年纪念大会精神的有关要求通知如下：

一、精心组织，深入开展形式多样的学习教育。

各单位要充分认识学习好、贯彻好、落实好张家港建县(市)50周年纪念大会精神的重大意义，把开展形式多样的学习教育作为当前队伍思想政治工作和政治理论学习的一项重要内容，高度重视，精心组织。 一要 组织全体民警集中观看纪念大会实况录像和电视文献纪录片《沙洲的崛起、张家港的辉煌——纪念张家港建县(市)50周年》，深刻感受张家港建县(市)50年发展的辉煌成就，进一步坚定勇立潮头、争当示范的信心和决心； 二要 组织全体民警认真学习省委常委、苏州市委蒋宏坤书记和市委徐美健书记纪念大会重要讲话精神，深入开展学习讨论活动，畅谈感想感悟，深刻领会、准确把握讲话精神实质，激励广大民警与时俱进弘扬张家港精神，积极投身港城现代化建设的伟大实践； 三要 组织民警参观“沙洲的崛起、张家港的辉煌——张家港建县(市)50周年成就展”，让广大民警充分了解张家港50年发展的卓越成就、辉煌足迹，进一步激发自豪感和责任感。

二、深刻领会，准确把握纪念大会的精神实质。

学习贯彻好建县（市）50周年纪念大会精神，关键要深刻理解、准确把握纪念大会的精神实质，重点做到“五个深刻领会”： 一是 深刻领会张家港50年的光荣历程，就是一部“敢抢敢拼创奇迹”的奋斗史诗，就是一首“样样工作争第一”的激昂赞歌，就是一个“改革创新求突破”的时代典范，就是一座“团结拼搏谋大业”的不朽丰碑，牢记过去50年永载史册的不懈探索。 二是 深刻领会奋勇争先的精神力量、开拓进取的拼搏豪情、永争一流的理想信念，是引领张家港不断率先领先、激励张家港不断创造奇迹、指引张家港不断勇往直前的立身之本。 三是 深刻领会始终坚持发展才是硬道理，始终坚持把思想领先作为引领行动率先的最强动力，始终坚持走全面协调可持续发展的路子，始终坚持抓好各级领导班子建设，是张家港人创造无愧于历史、无愧于时代的瞩目成就的关键所在。 四是 深刻领会坚持“永争第一、永立潮头”的发展豪情，坚持“改革创新、敢于突破”的开拓精神，坚持“统筹协调、共建共享”的民本宗旨，坚持“凝心聚力、永葆活力”的机制保障，是勇敢担当历史赋予的神圣职责、不断把张家港现代化建设事业推向新的高度的重要保证。 五是 深刻领会我们所肩负的历史使命，充分认识到勇当苏南现代化建设的排头兵，始终走在全国县域经济的最前列，继续争做全国文明建设的新典型，全力打造全国城乡统筹的示范区，是张家港在新一轮大发展中勇立潮头、争当示范的目标追求和必然选择。

三、结合实际，切实把学习贯彻的成效转化为推动工作的强大动力。

学习贯彻张家港建县(市)50周年纪念大会精神，必须在指导实践、推动发展、力求实效上下功夫，把推动工作的实际成果作为衡量学习贯彻情况的重要标准。要把学习贯彻纪念大会精神，与做好党的十八大安保工作结合起来，与全面完成全年各项目标任务结合起来，把学习贯彻会议精神中激发出来的活力转化为维护全市社会治安稳定的实际行动、转化为攻坚克难的坚定信心、转化为推动各项工作创新突破的强大动力，激励全体民警在率先基本实现现代化的伟大征程中作出更大的贡献。

各单位要认真对照年度工作既定目标任务和党的十八大安保工作的各项要求，进一步强化措施，狠抓落实，确保圆满完成全年目标任务和“十八大”安保工作。在此基础上，要进一步解放思想，立足“全国优秀公安局”的高点定位，科学谋划明年各项目标任务和工作重点，推动全市公安工作和队伍建设科学发展，为张家港的现代化建设勇挑重担，争作贡献。市局政治处要牵头负责学习贯彻活动的开展，并会同市局纪委、督察队对学习贯彻情况进行跟踪检查，确保取得实效。市局机关党委要牵头组织好机关、直属单位民警“张家港建县（市）50周年成就展”参观活动。

请各单位于11月13日前将学习贯彻张家港建县（市）50周年纪念大会精神情况报市局政治处组教科，活动中好的经验做法请及时报送。

张家港市公安局

二○一二年十一月一日
