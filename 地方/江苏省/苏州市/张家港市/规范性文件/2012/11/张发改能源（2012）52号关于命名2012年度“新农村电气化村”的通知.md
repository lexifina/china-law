# 张发改能源（2012）52号关于命名2012年度“新农村电气化村”的通知

杨舍镇、大新镇、凤凰镇新农村电气化建设领导小组：

根据国家电网公司《新农村电气化建设考评工作管理办法》和江苏省电力公司《关于做好新农村电气化建设考评验收工作的通知》(电农〔2007〕14号)文的要求，我市按照建设标准认真组织实施了新农村电气化建设，经张家港市新农村电气化建设领导小组会苏州供电公司专家组检查验收，杨舍镇福前村等25个行政村（社区）符合新农村电气化村建设标准，现决定给予命名。张家港市2012年“新农村电气化村”名单：

1．杨舍镇7个村：福前村、西闸村、乘航村、蒋桥村、七里庙村、五新村、杨港村；

2.大新镇6个村：桥头村、段山村、朝东圩港村、新凯村、大新村、新海坝村；

3.凤凰镇12个村：双龙村、魏庄村、安庆村、鸷山村、夏市村、高庄村、清水村、恬庄村、双塘村、凤凰社区、港口社区、西张社区。

张家港市发展和改革委员会

江苏省电力公司张家港市供电公司

2012年11月26日
