# 关于进一步加强学生上学与放学管理的通知

各初中、小学：

为进一步落实《江苏省中小学管理规范》、《苏州市执行“三项规定”、落实“五个严格”、保证一小时运动，全面提高教育质量实施意见》等法规文件精神，确保学生健康成长，现就规范学生上学与放学管理，提出如下意见：

一、加强学习，领会精神

要认真学习市教育局下发的《关于调整小学作息时间的通知》、《关于执行2012年秋冬季作息时间的函》等文件，切实把握相关规定，进一步增强以生为本、规范办学、精细管理等意识。

二、组织调查，研究对策

要对学生上学以及家长接送孩子等情况进行调查分析，重点了解需早到校、晚离校的学生与原因，以及家长接送孩子对校门口交通秩序带来的影响等问题，并根据实际情况，研究解决的具体办法。

三、落实举措，优化管理

1.加强门卫管理，强化学校保安的工作职责；主动与公安交警等部门联系，进一步健全校门口护导学生制度。

2.教育学生遵守作息时间安排，不要过早到校。对有特殊情况需早到校的学生，不能拒之门外，应安排学校行政领导与教师值班，引导学生开展课外阅读、体育锻炼等活动，并切实加强安全教育与管理。

3.学校各年级段应根据实际情况进行错时放学，按时静堂；小学应组织学生排队，由班主任或任课教师将学生护送到校门口或其他指定地点。

4.加强对家长接送孩子的管理，引导家长根据学校的作息时间适度提前到校，不在校门口长时间逗留；有条件的学校应分年段或班级划分家长等候区。

5.对家长不能按时来接的学生，学校应安排人员，热情耐心地做好看护以及与家长的沟通联系等工作。
