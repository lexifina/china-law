# 关于公布“五有五好”关工委建设先进学校的通知

各镇(区)教卫文体办公室(综合办)：

按照我局张教〔2012〕11号文件要求，各学校要积极创造条件，努力推进“五有五好”关工委的创建工作，争取年内有一批学校通过验收。近期，我局关工委与市关工委领导组成评估验收组，对南丰、凤凰两镇有关学校“五有五好”关工委的创建工作进行了评估验收。通过验收，现将“五有五好”关工委建设先进学校的名单公布如下：

南丰中学 南丰小学 凤凰中学 港口学校 凤凰小学

张家港市教育局

张家港市关心下一代工作委员会

二〇一二年十一月二十八日
