# 2014年度水利宣传工作实施意见

机关各科室、各单位：

近年来，全市水利系统高度重视水利宣传工作，结合自身实际，开拓创新，锐意进取，积极营造了全社会了解水利、关注水利、关心水利的良好氛围。2014年是全市现代化三年行动计划承前启后的关键之年，又是全市“810成效比拼年”，为进一步服务好全市水利工作大局，现就2014年度水利宣传工作提出如下实施意见。

一、强化思想认识

抓好水利宣传工作，有利于深入反映我市水利现代化发展取得的成就，有利于大力宣传我市加快推进水生态文明建设的新实践，有利于全面展现我市水利人创先争优的新形象，有利于切实增强全社会对水利工作的认知度。为此，全市水利系统要进一步统一思想认识，强化组织领导，加大宣传投入，将全市水利宣传工作不断推向高潮。

二、突出宣传重点

做好水利宣传工作，必须围绕中心、服务大局，要注意突出工作重点，依据重大政务活动、中心工作和重点工程建设，有计划、有组织地抓好落实。一要围绕重点工程建设抓好宣传及信息报送。随着我市“810”工程及一批重点水利工程的深入推进，为水利宣传工作开展提供了难得的机遇。各单位（科室）要积极深入建设一线，及时采写报道，宣传工程建设的意义，扩大水利工作影响。二要围绕阶段性中心工作抓好宣传及信息报送。要结合不同时期水利工作特点，有针对性地指导和推动工作开展。紧紧抓住水法宣传周、冬春农田水利建设、防汛抗旱、最严格水资源管理制度试点等时机，多渠道利用媒体，广造声势，扩大影响，全力推动各项阶段性重点工作的扎实开展。三要围绕水利行业能力建设和党的群众路线教育实践活动抓好宣传及信息报送。宣传各单位创新水利工程管理机制，建立完善农村河道市场化运作模式，大力报道水行政执法中，严格执法、廉政勤政的良好形象，及时报道各级领导和社会各界重视水利、关心水利、支持水利的典型事例。

三、拓展宣传渠道

一是与行业主流媒体建立合作机制。通过与全国影响力的《中国水利报》、《中国水运报》等专业媒体的合作，建立定期报送联动机制，全面扩大我市水利工作影响力。二是借助市级媒体开展水利宣传。充分利用张家港市“一报两台”以及市级机关各类工作简报、信息内刊等载体，多形式、多方位宣传水利工作。三是不断优化局水利网站内容。认真收集整理全系统水利工作信息，及时更新局水利网站，注重收集编撰各地水利工作的经验做法，充分发挥水利网站在传播信息、交流工作和示范导向方面的重要作用。四是继续做好《港城水利》工作简报编辑工作。作为了解水利工作的重要信息平台，我局将继续做好每月一期《港城水利》简报报送工作。五是强化舆情信息的搜集和整理。舆情信息是上级领导决策参考的重要依据，与一般的工作信息有所不同，各单位（科室）通讯报道员要按照上级部门要求，多渠道采集舆情信息，保质保量完成报送任务。

四、加强目标考核

信息采编与报送是做好水利宣传的基础。机关各科室、系统各单位要高度重视日常工作信息的收集、撰写工作，并及时向局办公室报送相关信息。局办公室要及时对上报信息进行整理编撰，择优录用。为进一步增强各科室、单位报送信息的积极性，对信息报送情况进行考核，考核结果列入年度绩效考评。

（一）数量要求。机关科室、事业单位每月报送信息不少于2条。

（二）考评办法。信息报送考核实行百分制，由基本分（36分）、录用分（34分）、质量分（10分）、其他加分（20分）共四项构成。

1、基本分项（上限36分）。各科室、单位每月完成规定数量（2条）得2分，缺1篇扣1分，超额1篇加0.5分。

2、录用分项（上限34分）。被局水利网站、《港城水利》录用的信息，每篇加1分；被《张家港日报》或市级条线部门录用的信息，每篇加2分；被市委《张家港信息》内刊或苏州市级媒体录用的信息，每篇加3分；被省及省以上媒体录用的信息，每篇加4分。同一篇信息被不同媒体多次录用，以最高分计分，转载的不计分。

3、质量分项（上限10分）。全年上报信息录用的比例分：（录用数量/上报数量）×10分。

4、其他加分项（上限20分）。各单位（科室）能结合工作职能，年内至少完成一篇高质量的调研报告，每篇加3分，被局年度汇编录用的，每篇加5分；各单位（科室）牵头负责一期《张家港日报》水利专版报道的，加5分；各单位（科室）配合做好一期《张家港日报》水利专版报道的，加3分。
