# 关于印发《2014年度张家港市农业委员会依法行政工作意见》的通知

2014年我委依法行政工作要坚持以邓小平理论、“三个代表”重要思想和科学发展观为指导，深入贯彻党的十八大和十八届三中全会精神，围绕农业中心工作，紧扣“810成效比拼年”主题，以强化“三农”服务工作，促进农业增收、农民致富为出发点和落脚点，准确把握法治机关建设面临的新形势、新任务、新要求，不断加强对依法行政工作的组织领导、统筹协调和督促指导，切实提高行政服务绩效，深入推进科学民主决策机制，着力提升制度建设质量，不断提高行政执法水平，大力化解社会矛盾纠纷，全面推进我委依法行政工作的制度化、程序化和规范化，为农业现代化建设提供坚实的法治保障。

一、加快转变职能，切实提高行政服务绩效

1.依法履行部门职责职能。以转变政府职能为核心，提高社会管理和公共服务效能。依据法律法规和“三定”方案，进一步明确工作职能和权限，规范系统内重点岗位的人员职责、工作规范、办事纪律等内容，杜绝行政不作为、乱作为现象，为我市现代农业发展提供优质、高效、便利服务。

2.提高行政审批服务效能。围绕合法、合理、正确、完整的原则，建立健全科学合理的管理和监督机制，认真开展行政审批事项清理，创新农业行政审批方式，规范行政审批行为，优化审批流程，压缩审批时限，提高行政服务效能。

3.加大政务信息公开力度。严格执行《中华人民共和国政府信息公开条例》，对依法应当主动公开的信息，及时、准确、具体地向社会公开，重点推进重大政策、项目和社会热点、媒体关注、涉及民生的政务信息公开工作。继续加强重大突发事件和群众关注热点问题的公开，客观公布事件进展、政府举措、公众防范措施和调查处理结果。强化对农业网站的管理，及时发布农业政务工作信息。充分利用12345便民服务平台和12345网络问政综合信息平台功能优势，加强与农民、市民网上互动，及时回应民意诉求，促进部门阳光行政。

4.推进行政权力公开透明运行。巩固深化行政权力网上公开透明运行工作成果，做好网上权力库的日常维护和完善工作，农委系统各单位要根据法律法规的规定，及时更新修改权力库的内容，细化行政处罚裁量标准，做到行政处罚案件全部通过网上运转。积极推进行政权力网上运行工作与行政审批中心事项办理、与部门核心业务、与行政绩效管理的有效衔接。

二、完善行政决策机制，深入推进科学民主决策

5.规范重大行政决策程序。根据《张家港市人民政府重大行政决策程序规定》，科学界定重大行政决策范围、事项和权限，严格遵循公众参与、专家论证、风险评估、合法性审查、廉洁性审查以及集体讨论决定等程序。广泛邀请公众参与，明确参与的途径、渠道和形式，增强公众代表性，扩大参与的覆盖面，逐步形成公众参与的意见反馈机制。建立健全重大行政决策听证制度，对涉及重大公共利益和人民群众切身利益的决策事项都要组织听证，并将听证意见作为决策的重要依据。建立健全专家咨询论证制度，将专家咨询意见作为决策的重要依据。建立健全决策风险评估机制，围绕合法性、合理性、可行性和可控性等方面，对重大决策事项进行法律风险、道德风险、稳定风险和舆论风险进行评估，风险评估报告作为决策的重要依据。

6.健全行政决策后评估机制和纠错问责机制。完善重大决策落实情况报告、执行情况监督检查与决策效果评估制度，选取1件直接关系民生、对经济社会发展有较大影响的决策事项进行重点评估，通过民意调查、定期检查、专项督查、绩效评估等形式，收集分析决策实施相关信息，重点了解决策执行情况以及实施效果，及时优化调整决策内容，最大限度地减少决策失误造成的损失和影响，确保决策科学、执行有力。建立健全重大决策事项讨论记录备案制度，讨论意见、表决结果和表决方式的记录，作为决策检查和问责依据。建立健全决策责任追究机制，实现决策权和决策责任、执行权与执行责任相统一。

三、规范文件审核管理，着力提增制度建设质效

7.加强规范性文件审核。充分发挥部门法制机构的职能作用，把好文件审查关，确保规范性文件内容的合法性、政策的连贯性、逻辑的严密性和操作的可行性。对涉及人民群众切身利益的规范性文件，通过座谈会、听证会、论证会和网络征求意见等多种方式，广泛听取相关部门、专家学者和社会公众的意见，及时反馈意见采纳情况。加强对制度的廉洁性审查，及时发现和预防制度漏洞，提高制度建设的科学化水平。

8.加大规范性文件后评估力度。坚持科学严谨、实事求是的原则，综合考量规范性文件实施情况和社会反响，对事关经济社会发展全局和人民群众切身利益的重要规范性文件进行客观调查和综合评价，为完善政策规定、改进行政管理、提升工作绩效提供客观依据和决策参考。积极探索委托第三方评估、专家咨询论证和公众评议等多样化的评估方式，确保后评估结果的科学性、客观性。建立公众参与规范性文件监督工作制度，适时召开规范性文件点评会，邀请法律专家、依法行政联系点、人大代表、政协委员、社会公众等多方群体参与点评，提高规范性文件的质量。

9.严格规范性文件管理。围绕现代农业发展，根据社会关注、实践急需、条件成熟的标准，科学统筹安排年度规范性文件立项计划。严格执行规范性文件统一登记、统一编号、统一发布制度和备案制度，确保规范性文件的备案率、及时率、规范率均达到100%。完善规范性文件动态管理机制，坚持“立、改、废”相结合，定期清理与上位规定不一致、与现代农业发展要求不适应、与政策体系不协调的规范性文件，及时公开文件清理目录，对拟修改的规范性文件统一列入下年度规范性文件制定计划，确保政策措施的连续性、系统性和协调性。严格执行《江苏省规范性文件制定和备案规定》，及时做好规范性文件的备案工作。

四、加强执法规范化建设，不断提高行政执法水平

10.强化重点领域监管执法力度。继续深入贯彻落实《中华人民共和国农产品质量安全法》和《江苏省农产品质量安全条例》等相关法律法规，大力推进农产品质量安全执法，把农产品质量安全作为农业行政执法的重要内容，切实保障人民群众的根本利益。加强农业投入品监管，根据农时生产季节，制定年度农资打假行动方案，有序组织开展农药、种子、肥料、兽药、饲料等农资质量安全专项整治，从生产源头上保障农产品质量安全。加强农资生产、经营企业的监督检查，加大案件查处和农资产品质量抽检力度。加强与相关职能部门之间的信息共享和协调联动，建立健全联合执法机制，加强行政执法与刑事司法的衔接，及时向公安、检察机关移送涉嫌犯罪案件。

11.规范农业行政执法行为。健全执法制度建设，建立更加科学合理的执法机制，切实做到严格规范公正文明执法。制定农业行政执法监督工作计划，深入推进行政执法责任制，全面落实行政执法案卷评查、评议考核、责任追究等制度，建立健全行政执法风险评估和防范控制机制，不断提高执法规范化、制度化水平。严格执行重大行政处罚、行政许可备案制度和行政执法调查取证规则，实行重大行政处罚、行政许可案件实行全程监管，做到执法案卷格式规范、要素齐全、归档及时。完善行政处罚自由裁量权制度和适用规则，严格规范裁量权行使，确保处理违法行政行为的手段和措施适当、适度。推进执法信息化建设，加强执法装备，注重运用科技手段，提高执法科技含量。

12.加强农业行政执法队伍建设。严格农业行政执法人员资格管理，严格执法纪律，完善农业行政执法人员库，进一步约束和规范执法行为。全方位、多渠道开展农业行政执法人员法治文化素养提升工程，严格落实行政执法人员资格培训、法律知识更新培训和注册考试等制度，鼓励通过自学考试、在职教育等系统学习方式，切实提升全系统行政执法人员接受法律大专以上教育的比例，提升执法人员法律专业水平。

五、加强体制机制创新，依法化解涉农矛盾纠纷

13.深入推进行政调解工作体制。完善农业行政调解工作办法，建立健全行政调解组织体系，依法开展涉农投诉行政调解，充分发挥行政调解在处理农业生产事故中的重要作用。开展行政调解法律依据梳理工作，界定、细化农业行政调解职责范围，提高行政调解工作质量。认真做好行政复议和信访工作，完善行政调解、行政复议与信访的衔接机制，对应当通过复议、诉讼等法律程序解决的信访事项，积极引导当事人通过法律途径解决。加强行政调解与人民调解、司法调解的有序衔接。

14.深化行政指导工作。把行政指导工作与具体业务工作结合起来，逐步把行政指导转变为一种常态性、日常性的工作，成为服务型机关建设的重要品牌。综合运用行政合同、行政规划、行政奖励、行政给付等柔性管理方式，实行全程说理式执法、互动式执法、执法事项提示、轻微问题告诫、突出问题约谈、重大案件回访制度化，提高行政执法效率，减少行政争议，实现行政管理的最优化。

六、落实各项保障措施，全面推进依法行政

15.加强依法行政组织领导。加强对依法行政工作的组织领导和部署，明确主要负责人为依法行政工作第一责任人，形成一级抓一级、逐级抓落实的领导体系。研究制定我委依法行政工作考核指标体系，列入全委工作计划和考核目标中。部门法制工作机构要提高政治素质、法律素养和业务能力，认真履行职能，主动当好单位依法行政方面的参谋、助手和法律顾问。相关执法单位也要明确依法行政工作的组织机构，加强法制工作和执法工作人员配备，改善依法行政工作条件。

16.提高依法行政意识和能力。以领导干部学法、党委中心理论组学习、法律知识更新培训等为抓手，以提高全委公职人员宪法意识和法制观念为重点，完善和落实学法制度、培训制度，提高我委系统干部职工运用法治思维和法治方式深化改革、推动发展、化解矛盾、维护稳定的能力。通过“5+X”公务员能力培训、公务员法规“天天问、月月学”、领导干部学法导读等方式，推动全委公务人员严格依法办事、依法履职。

17.营造良好的法治农业环境。围绕农业“六五”普法规划，制定年度法制宣传教育工作意见，明确培训主体、对象、内容和形式，充分发挥农干校、农业网站及新闻媒介等传媒作用，进一步加大涉农法律、法规宣传普及力度。创新普法宣传形式，开展形式多样的法制宣传教育活动，提升普法宣传质量和社会效果。

张家港市农业委员会

2014年3月6日
