# 关于抓紧实施畜禽养殖污染治理工程的通知

各镇（区）农服中心（农副办）、各镇动物防疫站：

畜禽养殖污染治理，是生态文明建设的一项重要内容。今年是新一轮畜禽养殖污染治理工程（2012-2015年）的第二年，也是关键一年，但从实施情况来看，总体上进度较慢，到目前为止，全市仅有8个养殖场完成治理任务，占全年治理任务数（36个）的22.2%。为加快推进畜禽养殖污染治理工程，确保按时完成治理任务，现就做好当前畜禽养殖污染治理工作通知如下：

一、切实强化防治工作职责。根据国务院《畜禽规模养殖污染防治条例》（以下简称《条例》）规定，环保部门负责畜禽养殖污染防治的统一监督管理，农牧部门负责畜禽养殖废弃物综合利用的指导和服务，各镇负责本行政区域的畜禽养殖污染防治工作。各镇（区）要对照市农委、市财政局“关于开展新一轮畜禽养殖污染治理工程的通知”（张农发[2013]104号、张财农[2013]57号）（以下简称《通知》）中明确的治理任务计划，对今年计划治理的36个畜禽养殖场逐个上门落实治理内容、治理时间，确保保质保量按时完成治理任务。

二、严肃落实养殖场主体责任。《条例》明确了畜禽养殖场的畜禽养殖污染防治的主体责任，因此，要加强《条例》的宣贯，督促养殖场主动开展畜禽养殖污染防治，对不能按时建设污染防治配套设施或者配套设施不合格的，养殖场将承担被依法处罚的后果。

三、加快推进配套设施建设。今年计划治理的36个养殖场的配套设施建设内容已在《通知》中明确，各镇（区）要按照10月底前完成配套设施建设、12月底前全面完成治理任务的要求，倒排时序进度，落实施工队伍，督促养殖场尽早签订施工协议，按时开工建设。各镇动物防疫站要加强施工质量监督，保证工程建设质量。

张家港市农业委员会
