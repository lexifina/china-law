# 教育局关于同意成立“张家港阳光教育集团”的批复

张家港市阳光学校、张家港市蓝天学校、张家港市金城学校、张家港市红蕾学校、张家港市阳光聚丰幼儿园：

你们提交的《关于成立“张家港阳光教育集团”的申请》收悉。根据《中华人民共和国民办教育促进法》、《民办非企业单位登记管理暂行条例》等法规文件精神，经研究，同意你们成立非独立法人的“张家港阳光教育集团”（以下简称“集团”）。成立“集团”后，各成员单位原有的单位性质、隶属关系、办学地址、管理体制、人事关系、经费渠道、法人地位等不变。

希成立“集团”后，认真制订“集团”章程，完善有关组织架构，以“集团”为新的平台，加强各成员校（园）的资源整合，提高资源利用效益，切实丰富内涵建设，不断提高办学水平，进一步为新市民子女提供优质的教育。

张家港市教育局

2014年5月26日
