# 关于成立老海坝节点综合整治工程项目法人的请示

张水发〔2014〕13号

市政府：

为巩固老海坝节点，提高堤防稳定性和河床抗冲能力，维护河势稳定，保障我市防洪安全，保护岸线及后方沙钢等特大企业安全，计划实施老海坝节点综合整治工程。工程可研已于2013年8月由省发改委以苏发改农经发〔2013〕1242号批复，工程估算投资54897万元，建设内容包括抛石、钻孔灌注桩等。工程拟分两年实施，计划2014年5月开工，2015年全面完成。为规范工程建设管理，根据国家有关工程建设管理要求，经研究，拟成立张家港市老海坝节点综合整治工程建设管理处，作为项目法人负责该项目的建设管理工作。建设管理处设主任1名，副主任3名，技术负责人1名，财务负责人1名，下设工程建设、安全保障、综合等3个工作组，由水利局、财政局、安监局、沙钢集团等单位抽调人员组成。

主任：张海峰
