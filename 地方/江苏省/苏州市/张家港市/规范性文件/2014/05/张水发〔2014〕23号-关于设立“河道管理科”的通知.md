# 关于设立“河道管理科”的通知

张水发〔2014〕23号

机关各科室、各事业单位：

为贯彻落实省政府、苏州市政府“关于加强河道管理‘河长制’工作意见”的精神，2014年3月20日市两办下发了《印发<关于全面推行河道管理“河长制”工作的实施意见>的通知》(张委办〔2014〕12号)。现根据文件精神，经研究决定：设立河道管理科。王鹏同志兼任科长，谢宇超同志兼任副科长。

河道管理科承担市河道管理“河长制”工作领导小组办公室日常工作。主要负责市河道管理“河长制”工作领导小组确定事项的落实；组织相关部门定期不定期对全市“河长制”工作进行巡查监督；落实“河长制”工作信息沟通和情况通报制度；建立、健全河道管理“河长制”绩效考评体系，对全市河道管理“河长制”绩效工作实行规范管理、量化管理等。

特此通知。
