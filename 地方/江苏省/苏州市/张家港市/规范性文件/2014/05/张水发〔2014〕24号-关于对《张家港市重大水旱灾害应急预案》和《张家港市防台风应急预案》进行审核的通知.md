# 关于对《张家港市重大水旱灾害应急预案》和《张家港市防台风应急预案》进行审核的通知

张水发[2014]24号

市政府：

根据《省政府办公厅关于做好突发事件应急预案修订工作的通知》及张家港市应急管理办公室《关于做好突发事件应急预案修订工作的通知》要求，我局组织对2007年市政府办公室印发的《张家港市重大水旱灾害应急预案》和《张家港市防御台风预案》进行了修订。苏州市防汛防旱指挥部对以上两个预案进行了审核并出具了审核意见（见附件1）。我局根据苏州市防指审核意见对预案作了进一步修改完善。现将修改后的预案上报，请予以审核并印发。

特此请示。

附件：1．关于《张家港市重大水旱灾害应急预案》、《张家

港市城市防洪应急预案》和《张家港市防台风应急

预案》的审核意见（苏市防〔2014〕15号）

2．《张家港市重大水旱灾害应急预案》

3．《张家港市防台风应急预案》
