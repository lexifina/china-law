# 关于批准朱江等同志预备党员的通知

直属各单位、机关各部门党支部：

希望新加入党组织的同志以共产党员的标准，时时处处严格要求自己，珍惜荣誉，谦虚谨慎，戒骄戒躁，再接再厉，开拓进取，认真践行党的宗旨，带头弘扬张家港精神，充分发挥共产党员的先锋模范作用，服务群众，心系百姓，以更好的精神状态、更大的工作力度全力投入各项公安工作，以实际行动体现共产党员的先进性，为全面建设“实力张家港、美丽张家港、幸福张家港，争当苏南现代化建设排头兵” 作出新的贡献。
