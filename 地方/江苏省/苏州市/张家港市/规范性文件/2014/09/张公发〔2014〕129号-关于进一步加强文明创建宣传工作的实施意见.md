# 关于进一步加强文明创建宣传工作的实施意见

各警署、各派出所、直属各单位、机关各部门：

今年以来，市委、市政府对全市文明机关、文明单位创建工作提出了更高的要求，制定了更为详细的创建工作绩效考评实施办法和考评体系。其中，在基本指标的全部5个大项和浮动指标的3个大项中，均对文明单位创建宣传工作细分了具体类目和指标要求。8月上旬，市委宣传部、市文明办再次下发《关于加强改进先进典型学习宣传工作的通知》。为认真贯彻上级文件精神，进一步做好全市公安机关文明机关、文明单位创建工作，更好地向全社会展示公安机关的辛勤工作和良好形象，现就进一步加强文明单位创建宣传工作提出如下实施意见：

一、文明创建宣传重点

根据文明机关、文明单位考评体系的具体考评项目和内容，重点要抓好以下几个方面的宣传:

1.公安机关充分发挥公安职能，打击各类违法犯罪、维护社会治安稳定、保护群众生命财产安全的各类工作举措、重大典型案例、取得的成效。

2.在公安工作和文明创建中推出的服务经济社会发展、服务企业、服务群众，以及创新社会管理的新举措、新做法。

3.公安机关开门纳谏，积极回应民声，为保平安、保稳定所做的工作、取得的成绩和及时化解矛盾，切实排查消除治安隐患的突出成果。

4.在公安各条战线、各个岗位涌现出的道德模范、身边好人，在公安基层工作中发生的感人故事。

5.公安民警深入开展“走访送”活动，为群众做好事、解难事的实际举措和社会反响。

6.公安机关成立志愿者队伍，开展关爱未成年人、弱势群体等志愿服务活动，以及各单位组织的结对帮扶、共建活动。

二、具体工作要求

文明机关、文明单位创建工作是全局的一项中心工作，各单位、各部门务必要高度重视，认真对待，切实做好以下几个方面工作：

1.要做好先进工作经验的上报工作。

各派出所、各单位要根据文明创建宣传重点，及时向市局政治处报送相关工作情况。 市局明确，各派出所申报张家港市级文明单位、文明单位标兵，以及苏州市局以上表彰荣誉称号的，其先进工作经验、工作成效必须在该年度张家港市级以上主流媒体或公安条线主管媒体作过专题或重点宣传报道。

2. 要做好身边好人的推荐上报工作。

“身边好人”是指能够模范遵守公民道德规范，在日常工作、生活和人际交往中品德高尚、事迹感人的人物。“身边好人”分为助人为乐、见义勇为、诚实守信、敬业奉献、孝老爱亲等5个类别。各单位要积极挖掘身边先进民警、警辅人员，及时向市局政治处宣传科报送，并由政治处宣传科扎口，每月向市级媒体推荐宣传。

3.要做好先进典型的选树宣传工作。

市局明确，每年评选的“六十佳”先进个人，其先进事迹必须要有一定的公众知晓度，在该年度张家港市级以上主流媒体（包括报纸、电视、电台）、市局互联网“警界群英”、苏州市局内网主页“好警纪事”等栏目报道或刊登过。市局推荐苏州市级以上个人高等级荣誉的，其先进事迹将从这些报道中筛选。

同时，政治处宣传科要充分发挥职能作用，切实加强对先进个人的挖掘、选树和对外宣传报道工作，要大力宣传公安民警打击犯罪、为民服务的先进事迹，宣传公安民警艰苦奋斗、攻坚克难的优良作风和无私奉献、一心为民的良好情操，展示形象，赢得支持，不断提高群众满意度。

三、相关注意事项

1. 市局政治处要切实担负起文明创建牵头部门的职责，加强对基层所队文明创建工作的指导、督促和协调，确保我局在创建工作中取得好的成绩。

2.各单位在创建工作中要注重不断探索、创新公安工作、群众工作、文明建设、社会管理的新举措、新方法，及时总结经验、成效。要大力开展先进典型的选树、学习和宣传工作，努力树立新时期人民警察的良好形象。

3.各单位要及时报送相关工作举措、工作经验和先进事迹，注重信息的创新性、时效性和生动性，文字材料、图片请通过“督导平台”队伍建设、外宣文化栏目报送。
