# 教育局关于同意设立南丰幼儿园东沙园区的批复

南丰镇人民政府：

你镇《关于对东沙幼儿园实施一体化管理的请示》收悉。经研究，同意你镇将东沙幼儿园并入南丰幼儿园，设立南丰幼儿园东沙园区,在师资队伍、教育教学、财产财务等方面实行一体化管理。希加强对南丰幼儿园东沙园区的投入和管理，推动区域内教育资源合理配置，进一步丰富幼儿园内涵建设，提高教育质量和办学水平，推进学前教育优质均衡发展。

张家港市教育局

2014年9月16日
