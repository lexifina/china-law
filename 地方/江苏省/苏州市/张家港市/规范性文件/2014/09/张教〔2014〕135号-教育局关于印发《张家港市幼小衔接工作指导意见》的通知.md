# 教育局关于印发《张家港市幼小衔接工作指导意见》的通知

各小学、幼儿园、九年一贯制学校、民办新市民子女学校：

现将《张家港市幼小衔接工作指导意见》印发给你们，请遵照执行。

张家港市教育局

2014年9月23日

（此件主动公开）

张家港市幼小衔接工作指导意见

为加强幼儿园与小学教育的衔接，有目的、有计划地提高小学一年级新生的适应性，更好地促进衔接期学生身心的健康发展，特对本市幼儿园和小学的衔接教育提出如下指导意见。

一、指导思想

1.树立科学正确的教育观，以儿童立场为幼小衔接教育的根本宗旨，幼儿园教育与小学教育相互配合，真正在发现儿童中引领儿童成长，为儿童成长提供无限可能性。

2.通过幼小衔接活动帮助儿童实现从幼儿园到小学两个不同阶段教育的平稳过渡，让儿童能愉快地适应小学阶段的学习生活，保持身心的健康、和谐发展。

3.幼小衔接活动的开展，要充分尊重儿童的年龄特点和身心发展规律，努力体现后继学习和未来社会对儿童发展的要求，充分体现科学性、整合性和趣味性。

二、教育目标

（一）幼儿园目标

1.具有较强的入读小学的愿望和兴趣，向往小学的生活，具有积极的情感体验。

2.初步了解小学的学习活动特点和课堂教学规范，对各类学习活动形成好奇心和求知欲。

3.注重培养良好的学习品质，初步养成良好的学习习惯、生活习惯，重视培养社会交往能力，建立初步的规则意识、任务意识。

（二）小学目标

1.热爱小学生活，感受学习的乐趣，情绪积极稳定，体质不断增强，得到充分的成长激励。

2.尽快了解并逐渐适应小学的学习和生活环境，懂得各种要求和规则，并养成良好的习惯。

3.帮助孩子愉快度过幼儿园到小学的这一过渡期，逐渐学会处理小学学习生活中的各种新变化，在良好的师生关系、生生关系中实现成长。

三、工作建议

（一）幼儿园

1.培养幼儿良好的学习习惯。

教师和家长不超前教授和强化训练拼音等小学学习内容，及早培养幼儿专注倾听、积极发言、认真阅读、正确握笔等良好的学习习惯，逐步增强幼儿及时完成作业等任务意识和遵守时间的意识，提高幼儿的自主规划能力、解决困难的能力等。

2.培养幼儿良好的生活能力。

教师和家长要逐步提高幼儿入厕、梳洗、穿戴等生活自理能力，逐步提高幼儿的劳动服务能力，及早增强幼儿的安全防范意识，不玩危险品、不轻信陌生人的话、不违反交通规则、不吃无证店内食物等；帮助幼儿了解小学生的常规，逐步增强幼儿遵守规则的意识；逐步提高幼儿的交往能力。

3.培养幼儿积极的入学心理。

教师和家长要教育幼儿学会控制自己的情绪，逐步增强自控能力；了解并减缓幼儿的心理压力和心理焦虑，提高幼儿的自信心和受挫能力；通过参观、参与小学环境和活动，激发幼儿对小学生活的好奇和向往，帮助其自然顺利地过度、较快地融入新的环境。

（二）小学

1.整体规划衔接教育

小学要树立主动向幼儿园衔接的意识，对衔接教育活动进行整体规划。要把衔接教育纳入学校工作计划，把集中性的幼小衔接活动与日常性的教育活动结合起来；要提前介入，将衔接教育活动与相关幼儿园大班的教育活动结合起来，与新生暑期活动结合起来。

2.努力营造环境氛围

要努力营造符合儿童年龄特点的校园环境氛围。小学低年级区域在环境布置上可参照幼儿园的设计，努力体现丰富性、趣味性和人文关怀，尽可能减少生硬的禁止性、命令性要求，努力做到以疏代堵；各种活动要尊重儿童的年龄特点，使活动具有趣味性、游戏性、生活性、综合性。

3.精心组织衔接活动

要精心组织新生入学系列活动。在认真研究衔接期学生身心特点的基础上，结合学校实际，精心规划设计和组织新生入学前、开学第一天、第一周、第一月、第一学期、第一学年、第二学年的活动。提倡入学前组织开展相关的亲子活动，入学第一天举行富有创意的新生入学仪式，让新生尽快适应新学校、新老师，融入新集体，爱上新的学习生活。

4.大力改进课堂教学

一年级要实行零起点教学，坚决杜绝在新生入学初期随意拔高教学要求。学校要每学期组织低年级教师去幼儿园听课，组织开展专门的教学研究活动，借鉴幼儿园游戏教学的理念，大力改进低年级的课堂教学，避免课堂教学中出现生硬灌输、形式单调、教师态度过于严厉等现象，努力使低年级的课堂教学既生动活泼，又扎实有效。

5.探索实践衔接课程

要把幼小衔接活动纳入一年级课程计划中，积极开发和探索衔接课程，提高课程实施的有效性。鼓励学校开设专门的衔接教育课，对相关学科的内容、课时等进行必要的调整和整合，积极进行英语长短课型等实验探索。要注意使小学与幼儿园保持课程内容和教育理念上的连续性，注意课程目标的小步化、课程内容的生活化和统整化、课程实施的活动化、游戏化，课程评价的多元化。提倡赏识和鼓励教育。

6.积极推进评价改革

鼓励小学借鉴幼儿园成长档案记录袋等形式，进行学生评价方式的改革。学校要与家长协同，借助相关软件和现代教育技术手段，为学生建立实物档案与电子影像等成长记录，记录学生的基本资料、个性发展情况、成长故事等。新生入学应注意共享相关幼儿的成长档案，以便于全面了解学生，因材施教。

（三）互动

1.加强幼儿园与小学的互动，形成幼小联系的机制。在大班第二学期，幼儿园要邀请有关小学校长、低年级骨干老师到幼儿园给家长、孩子和老师开设讲座或者上课。组织大班孩子参观小学，通过各种活动方式，引导幼儿充分感知和体验小学生活。增加小学生与幼儿的互动。小学可安排学生利用课余时间回到幼儿园，给小朋友讲一讲小学的学习生活故事；幼儿园也可安排幼儿主动与小学生交往。通过交流互动，让幼儿获得更多有关小学生活的问题、信息和体验。幼儿园和小学教师要相互了解。要专门组织相关园校老师的衔接教育沙龙、课堂教学研讨，了解不同学段对学生生活、教育的一些基本行为习惯要求、教材教法等，提高教师实施衔接教育的自觉性、针对性和有效性。

2.重视与家长的交流互动。要加强与家长的沟通和对家长的引导。积极利用家长会、网络媒体、家长手册等，开展丰富、有效的幼小衔接宣传活动，让家长充分了解孩子的成长规律和幼儿园、小学教育的不同要求，真正做到家园、家校共育，切实提高幼小衔接活动的有效性。要引导家长合理安排子女入小学前两个月的暑假生活，重点巩固已经形成的良好行为习惯，积极宣传小学“零起点教学”的意义，引导家长不盲目让孩子参加校外学科类培训。要重点关注特殊学生，对个别情绪特别焦虑的孩子，学校要主动会同家长开展具有针对性的教育，使每一个孩子都能顺利、愉快地度过幼小衔接阶段。
