# 关于上报《张家港市农田水利规划修编》的请示

张水发〔2014〕45号

张家港市人民政府：

根据《关于开展<县级农田水利规划>修编工作的通知》（苏水农〔2014〕29号）文件要求，市水利局牵头并会同市发改委、财政局、国土局、农委等部门在《张家港农田水利规划》（2010版）基础上，深入调查研究，摸清现状，联合编制了《张家港市农田水利规划》（修编版）（以下简称《规划》）。《规划》于10月17日通过了苏州市水利局及张家港市水利、发改、财政、国土、农业、规划等部门专家的评审，并针对评审专家意见进行了修改。现将修改后《规划》报请市政府，请予审批。

特此请示。

附件：《张家港市农田水利规划》报告

张家港市水利局

2014年11月11日
