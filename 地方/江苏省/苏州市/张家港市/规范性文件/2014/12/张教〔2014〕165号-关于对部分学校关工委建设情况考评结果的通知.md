# 关于对部分学校关工委建设情况考评结果的通知

各镇（区）教卫文体办公室（综合办），各有关中小学校:

按照中共苏州市委教育工委《关于开展关工委工作常态化建设合格学校考核的通知》要求，近期，教育局关工委与市关工委领导对金港、大新两个镇的有关学校关工委建设情况进行了考核评议。现将考评结果达到苏州市关工委常态化建设合格学校的名单公布如下：

南沙中学、护漕港中学、港区初级中学、后塍学校、金港中心小学、港区小学、中兴小学、德积小学、南沙小学、新塍小学、后塍小学、大新中学、大新中心小学。

张家港市教育局

张家港市关心下一代工作委员会
