# 关于印发《2017年度交通运输系统城市管理、爱国卫生及健康建设工作意见》的通知

机关各科室、各企事业单位：

现将《2017年度交通运输系统城市管理、爱国卫生及健康建设工作意见》印发给你们，请遵照执行。

附件：2017年度交通运输系统城市管理、爱国卫生及健康建设工作意见

张家港市交通运输局

2017年1月20日

（此件公开发布）

2017年度交通运输系统城市管理、爱国卫生及健康建设工作意见

一、指导思想

以党的十八大和十八届三中、四中、五中、六中全会精神为指导，紧紧围绕局党委工作中心，增强创建意识，巩固创建成果，开展群众性健康教育活动，努力提高干部职工的城市管理、爱国卫生、健康建设水平；落实环境整治和除“四害”长效管理措施，创建文明、洁美、宁静的城市环境，为张家港经济社会协调发展做出新的贡献。

二、工作目标

1.严格按照国家卫生城市、优秀管理城市和文明城市的考核标准，积极争创“城市管理”、“爱国卫生”、“健康建设”先进单位。

2.各单位全年检查考核平均分不低于95分（以地区爱卫办考核公布为准）。

3.深化城市管理、爱国卫生和健康建设宣传，确保健康知识普及率100%、入户率100%，卫生知识知晓率100%、食品加工从业人员持证率100%。

4.认真抓好病媒生物工作，有效控制和减少“四害”密度。

5.认真抓好卫生防疫工作，积极预防“艾滋病”、“H7N9禽流感”及其他传染性疾病。

6.强化行业卫生管理，提高行业卫生水平，杜绝食物中毒事故发生。

7.落实城市管理规定，加强“门前五包”、确保“门内达标”，做好单位内外环境卫生和绿化管护工作。

8.落实数字化城管工作，提高案件办结率。

9.落实禁放烟花爆竹工作，禁放率达100%，夜景亮化工程达到上级要求。

10.加强全市候车亭和洗车场、维修店等三类维修企业的日常保洁管理工作，分段包干、落实责任，确保全天候整洁。

11.落实全市文明道路、社区“同创共建”工作。

12.落实控烟和垃圾分类工作。

13.完成市城管委、爱卫委下达的年度目标任务。

三、工作要求

1.加强领导，明确责任。各单位要建立健全城市管理、爱国卫生、健康建设等工作领导小组，切实加强对城管爱卫健康工作的领导，不断健全和完善组织管理机构和网络，加强日常监督，狠抓措施落实，层层签订和落实责任制，做到年初有计划、具体工作有措施、平时有检查、基础管理有台账、年终有总结，严格考评奖惩制度，确保城市管理、爱国卫生、健康建设各项工作取得实效。

2.加大宣传力度，全面开展健康教育。各单位要充分利用各种宣传阵地，采取多种形式认真学习城市管理、爱国卫生、健康建设的法律、法规和有关业务知识；对重点行业，要坚持经常开展卫生科普知识和健康知识教育活动，积极参加全市统一组织的“健康大讲堂”等公民健康素养提升工程活动，提高卫生与健康意识，养成自觉维护公共卫生的良好习惯；要进一步强化全员城管创优意识、卫生意识、传染病防治意识和全民参与意识；要以“爱国卫生月”、“城市管理月”等活动为载体，营造城市管理、爱国卫生、健康建设活动宣传氛围。

3.落实各项措施，全力抓好各项具体工作。（1）认真落实市委、市政府关于城市管理的规定，继续抓好禁放烟花爆竹管理工作（市区为二环路以内、张杨公路以南禁止燃放，镇区以各镇规定为准）。继续开展全市城乡环境综合整治行动。（2）加强夜景灯光管理，即市区各有关单位每逢重大节日和每周六、周日晚均要开2—3小时夜景灯光，其他特殊任务另行通知。（3）各单位要做好内外环境卫生管理，切实做到“门前五包、门内达标”。（4）系统内的宾馆、饭店、食堂及公共场所卫生合格率及“三证”持证率均为100%。（5）根据病媒生物的生态习性、季节特性及繁殖规律等因素，开展春冬季“灭鼠”和“灭蚊蝇突击周”等除害活动。各单位要根据上级统一部署和要求，有计划、有步骤、有重点、分阶段抓好除“四害”工作。以统一行动和突击消杀相结合、专业队伍与群众运动相结合的方法，严格控制和杜绝阳性孳生地，各种病媒生物密度控制在国家标准以内，病媒生物传染病得到有效控制。不生产、买卖、储存或使用“毒鼠强”。（6）运管处要加强对客运站场、公交车、客车、出租车、公交候车亭的保洁督查工作；维管处要抓好洗车场、维修店等三类维修企业的保洁监督工作；汽运集团要加强公交车、出租车和公交候车亭等的保洁工作；车站和驻交通大厦各单位要落实控烟工作；局机关和各事业单位要认真开展垃圾分类试点工作。（7）市区各单位要落实全市文明道路、社区洁美“同创共建”活动，积极参与、全力做好各项工作。（8）各相关单位要按照分工认真落实“数字化城管”工作，提高办结率。

4.加强检查，严格考评。各单位要坚持每月卫生自查不少于一次，局将每季度对各单位组织一次卫生工作考评，并根据需要适时组织单项性检查和抽查，考核成绩作为年终卫生先进评比的主要依据。
