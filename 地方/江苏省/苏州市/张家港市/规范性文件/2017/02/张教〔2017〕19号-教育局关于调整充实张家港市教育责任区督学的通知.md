# 教育局关于调整充实张家港市教育责任区督学的通知

各镇（区）教卫文体办公室（综合办），各中小学、幼儿园：

为顺应新形势，落实新要求，实现新跨越，根据《教育部关于印发<督学管理暂行办法>的通知》（教督〔2016〕2号）等文件精神与我市实际，决定对部分督学进行调整。现将调整充实后的名单公布如下：

一、总督学（1人）

杨志刚 市委教育工委书记，市教育局局长、督导室主任

钱洁雅 市教育局副局长

赵建华、彭胜生、侯友成
