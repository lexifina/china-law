# 张家港市公安局关于印发《实施推进全市老旧小区安防综合整治工作意见》的通知

各警署、各派出所、直属各单位、机关各部门：

现将《实施推进全市老旧小区安防综合整治工作意见》印发给你们，请结合实际，认真执行。

张家港市公安局

2017年3月28日

（此件公开发布）

实施推进全市老旧小区安防综合整治工作意见

为切实加强我市老旧小区安全防范工作，有效压降老旧小区可防性案件警情，着力提升群众安全感和治安满意度，全面深化推进社会治安防控体系升级版建设，根据上级公安机关和市局党委部署要求，现制定老旧小区综合整治工作实施意见如下：

一、指导思想

以全市公安工作会议精神为指导，紧紧围绕立体化信息化社会治安防控体系升级版建设要求，坚持政府主导、社会参与、业主自治，着眼长远、标本兼治，市级统筹、属地负责，突出重点、分步实施的原则，通过开展老旧小区安防综合整治，着力解决老旧小区建设标准不高、基础设施陈旧、功能配套不全、日常管理制度不健全、可防性案件警情高发等群众普遍关心、反映强烈的平安建设、环境改善问题。通过综合治理改造，努力实现老旧小区基础设施完善、安防、技防功能提升、环境整洁有序，为居民打造一个环境优美、秩序井然、适宜人居的良好生活环境。

二、工作目标

分批实施推进全市老旧小区安防综合整治工作，力争2到3年时间，完成全市30个左右居民住宅小区安防改造。

三、组织领导

市局成立老旧小区综合整治工作领导小组，副市长、局长周斌伟任领导小组组长，副局长陈菊新、闻振平、赵剑锋、黄晟及各警署署长任领导小组副组长。人管、信科、消防、政治处等警种部门为领导小组成员单位。领导小组在人管大队下设办公室，负责动员部署、统筹协调、情况掌握、检查指导和督查考核等工作，由人管大队大队长周健任办公室主任。具体职责分工如下：

人口管理大队：负责牵头组织、统筹协调全市小区安防综合整治工作，负责工作督导推进、情况通报以及考评工作。

信科大队：负责制定老旧小区安防改造技术标准，做好技防设施建设指导服务；负责实有人口视频门禁管理系统的开发建设和应用维护。

消防大队：负责老旧小区消防整治的业务指导工作。

政治处：负责全市老旧小区安防综合整治的宣传发动工作。

警署：承担本警署老旧小区安防综合整治工作的主体责任，结合辖区实际，确定老旧小区安防综合整治名单，制定具体实施工作计划，落实项目化管理推进；积极争取党委政府支持，落实建设资金。

派出所：承担小区安防综合整治工作的具体责任，实施开展老旧小区安防改造工作，指导社区、物业公司等落实小区人防、技防、物防等长效管理措施。

四、整治内容

老旧小区安防综合整治工作主要包括技防设施改造和消防设施改造两个方面，具体工作内容如下：

（一）技防设施改造

1.建设“实有人口视频门禁管理系统”。在小区单元门口安装实有人口视频门禁管理系统；将门禁系统、视频监控系统、报警系统及实有人口管理集合起来，通过本平台，对居民小区人员信息进行采集和比对，实时记录并上传门禁事件及相对应的照片与视频资料，实现门禁数据与实有人口管理报警联动的一体化网络信息系统，为公安机关侦查破案、打击防范、治安管理等提供技术支持；为各政府部门提供数据支撑；

2.建设完善高清视频监控系统。建设完善小区出入口，机动车、非机动车集中停放区及出入口，住宅楼出入口，重要机房门口，主要活动场所，主要道路等部位高清视频监控系统；

3.建设车辆抓拍、车辆管理、人脸识别系统。在小区出入口车行通道建设车辆抓拍系统、车辆管理系统，在小区出入口人行通道建设人脸识别系统；

4.建设周界报警系统或周界监控系统。封闭小区周界（包括围栏、栅栏）、不设门卫岗亭的出入口、消防出入口安装周界报警系统；封闭小区周界、与外界相通的河道以及半封闭、开放式小区与外界相通的所有通道安装周界监控系统；

（二）消防设施改造

1.消防水源完善。对小区消火栓等设施进行排查，对存在部件缺损、锈死、漏水、埋压、圈占等影响消火栓使用功能的及时维修和管理，对不满足国家规范设置标准的及时增补；

2.电动车管理。电动车不得在楼梯间、疏散通道、安全出口、消防车通道和救援场地等公共区域停放或充电，建设有喷淋、灭火器、感烟火灾探测报警器等消防设施器材及定时充电、自动断电等功能的充电设施，满足消防安全的电动车库（棚）；

3.微型消防站建立。在社区建立有人员、有器材、有战斗力的“微型消防站”，按照“3分钟到场”要求划定最小灭火单元，分为多个微型消防站，覆盖整个小区范围，并建立相应的快速指挥调度体系。

五、工作计划

按照三年期建设要求，全市每年完成10个老旧小区安防综合整治工作。2017年的实施计划如下：

（一）调查摸底阶段（4月15日前）

各警署组织对辖区老旧小区治安状况开展全面调查摸底，结合可防性案件警情高发、流动人口聚居等治安状况确定本地区老旧小区整治范围，并将今年首期11个老旧小区（含先行试点的杨舍镇城西七里庙小区）的整治名单以及项目责任人上报市局。具体名额分配如下：杨舍警署完成3个；锦丰、金港、乐余警署各完成2个（其中大新、南丰各1个）；塘桥、凤凰警署各完成1个。各警署必须明确一名副署长具体负责项目建设推进（名单请填写附件4）。

（二）制定方案阶段（4月底前）

各警署按照“一区一策”的要求，完成每个老旧小区安防整治建设方案以及预算编制；组织专家评审，小区居民公示并收集意见，修改完善方案，并报市局审核。

（三）建设实施阶段（5至10月）

各地按照建设方案，进行项目招标以及工程施工，11月底前完成工程建设。其中，先行试点的杨舍镇城西七里庙小区要在6月底前完成工程建设，以便召开现场会观摩推广。

（四）竣工验收阶段（11月）

市局组织对各地进行工程竣工验收，并组织相关的总结评比工作。

六、工作要求

(一)加强协作配合，落实工作保障。各单位、各部门要对照在老旧小区安防综合整治工作中的职责任务，既要做到各负其责、各司其职，又要做到通力协作，共同推动项目落地，确保工作质效。要大力推动党委政府领导责任，主动争取党委政府重视支持，努力推动老旧小区安防综合整治工程纳入党政重点实事项目，多渠道落实综合整治资金保障。

(二)实行项目管理，确保有序推进。老旧小区安防综合整治工作要坚持安全、质量、进度、效益的统一，实行项目化推进，建立定期会商机制，按时上报工作进度。坚持综合整治与专项整治相结合，统一组织、分类指导、分步实施，实现改造工序高效集成，整治过程安全可控，工程质量符合标准。

（三）强化建设管理，保证工程质量。一是在建设规划上，要按照“因地制宜”、“一区一策”、“既有硬性建设标准，又有个性建设需要”等要求，在充分摸底调查、评估论证基础上科学编制建设方案。二是建设方案应满足国家、行业现行标准和规范的强制要求，确保工程质量（建设标准详见附件）。三是做好长效管理，要明确责任主体，建立有效的管理体系，要坚持建管并重，重在管理，将老旧小区安防综合整治工作成效落到实处。

（四）加强宣传教育，营造良好氛围。在实施推进过程中要重视宣传发动，充分利用各种媒体，通过各种形式，大力宣传老旧小区安防综合整治工作的重要意义，积极争取居民群众的参与、支持和理解。属地派出所要积极发动街道办、社区居委会、物业公司等管理力量，逐户做好宣传教育，引导广大居民群众树立自觉参与社区安防工作的意识，突出业主的主人翁责任感。
