# 关于印发《2017年张家港市农业委员会社会治安综合治理和平安建设工作意见》的通知

委属各单位：

现将《2017年张家港市农业委员会社会治安综合治理和平安建设工作意见》印发给你们，请结合本单位工作实际，认真贯彻实施。

张家港市农业委员会

2017年3月6日

（此件公开发布）

2017年张家港市农业委员会社会治安综合治理和平安建设工作意见

为全面贯彻落实中央和省、苏州市政法工作和社会治安综合治理创新工作会议精神，根据《2017年张家港市社会治安综合治理和平安建设工作要点》（张综委〔2017〕1号）要求，结合工作实际，特制定2017年度张家港市农业委员会社会治安综合治理和平安建设工作意见。

一、主要任务

2017年，农委社会治安综合治理和平安建设工作的主要任务是：认真贯彻落实党的十八大和十八届三中、四中、五中、六中全会及习近平总书记系列重要讲话精神，紧扣农业供给侧结构性改革主线，按照张家港市“十三五”现代农业建设实施意见，认真贯彻执行农业法律法规和支农扶农政策，切实做好动物疫病和植物病虫草害防控工作，强化渔业生产、农机作业的安全监管和护林防火措施的落实，推进农产品质量安全建设，保障农业生产和农产品质量安全，有效预防和妥善处置信访问题，维护社会稳定，进一步提升社会治安综合治理和平安建设工作水平。

二、工作重点

1．创新完善新形势下预防化解矛盾纠纷的方法途径。认真贯彻中央、省和苏州市关于完善矛盾纠纷多元化解机制的意见精神，着力推动开放共治，通过购买服务、项目外包、保险等市场化方式化解矛盾、防控风险，切实形成党委领导、政府主导、综治协调、有关部门负责、各方面参与的工作格局。健全行政复议案件审理机制，完善仲裁解决纠纷机制，探索创新协商、中立评估、第三方调处等矛盾纠纷化解机制，有效化解各类社会矛盾。

2．严防重大群体性事件。准确把握经济发展新常态下社会矛盾新动向，结合农业防灾减灾，准确把握可能带来社会不稳定的风险点，加强源头预防和应急处置，严防发生重大群体性事件。严格落实社会治安综合治理和平安建设工作责任，扎实做好情报信息、教育稳控等工作。主动做好应急处置准备，坚持未雨绸缪，超前做好力量、装备、预案等各方面保障，确保一旦发生重大突发敏感案事件，能够在党委政府统一领导下，按照现场处置、舆论引导、社会面管控“三同步”的要求，快速反应、妥善应对、高效处置，严防因执法不规范、考虑不周全、处置不妥当引发舆论炒作、诱发不和谐不稳定事端。

3．深化系列平安创建活动。深入开展平安站所、平安行业、平安条线等系列平安创建活动，推动实行项目化运作，纳入综治和平安建设绩效考核，努力形成条块结合、上下联动、共创平安的良好局面。农委综治办要充分发挥统筹协调、考核检查作用，推动主管部门履行牵头职责、督促工作措施落实、开展考核创建活动，确保不发生严重影响社会和谐稳定的重大案（事）件。深化“联系点共建”活动，加大共建力度、丰富共建内涵、创新共建形式，提高共建实效，形成典型经验，真正把部门工作优势融进基层平安创建中。

4．加强重大动物疫病防控。落实工作责任，扎实开展动物防疫工作，进一步提升重大动物疫病防控水平。切实做好口蹄疫、禽流感、高致病性猪蓝耳病等重大动物疫病免疫工作，确保免疫密度达到100%。加大动物免疫监管力度，严格落实动物防疫员工作制度，加强对养殖户的指导，强化免疫监测，巩固提高动物免疫水平，确保免疫效果；同时，加强野生动物日常监测，防止疫源疫病传入。围绕畜禽健康养殖场建设，认真实施“两减六治三提升”专项行动，大力开展养殖污染治理，指导养殖户开展生态健康养殖，改善养殖生态环境。以规模养殖场动物防疫规范化示范场创建活动为抓手，针对畜禽混养、防疫制度不完善、防疫设施落后等问题，规范畜禽养殖行为，切实消除防疫隐患。

5．加强植物病虫草害防治。针对病虫草害对农林业生产带来的不利影响，在强化植保防控技术研究、健全重大生物灾害应急预案的基础上，设立防控应急队伍，建立健全应急服务组织，实行统一农药配方、统一用药时间、统一用药方法，进一步提高植物病虫害防治水平，提升突发自然灾害的应急处置能力。强化检疫工作，定期组织调查，设立阻截带，对生产和调运的种子种苗严格检疫，严防生物灾害现象发生、发展。

6．加强渔业生产安全监管。突出长江禁渔、增殖放流、打非整治、渔业许可等重点，不断加强生态建设，切实提高渔业资源养护、水域生态维护工作水平。扎实开展隐患排查治理、渔船检验，切实加强安全监管，确保渔业生产安全。认真做好群众来信来访工作，及时、妥善调处涉渔水工纠纷和渔业水域污染事故，切实维护渔民合法权益。

7．加强农机安全作业监管。层层落实农机安全责任，加大宣传力度，增强安全意识，强化源头管理，规范执法行为，履行农机安全监管职责，全面开展农机安全作业专项整治，切实防范农机生产事故。推进“平安农机通”、农机及司乘人员保险等工作，以农机安全生产促进农业丰收、农民增收。

8．加强护林防火措施落实。坚持“预防为主、积极消灭”的方针，落实森林防火行政领导负责制，加强宣传与现场管理，针对重点地段、重点时段开展监督巡查，强化火源管理和可燃物管理，严禁在林内吸烟、玩火。加强基础设施和队伍建设，健全森林防火24小时值班制度、日报制度、火情报告制度，开展防火演练，提高预防和扑救森林火灾的综合能力，确保不发生重大森林火灾。

9．加强农产品质量安全建设。以国家农产品质量安全县建设为抓手，坚持宣传引导、服务指导、突出重点、标本兼治的原则，加强源头监管，实行全程监控，建立长效机制。大力推进农业标准化生产，完善质量追溯体系建设，提升监管能力。深入开展农资打假专项治理行动、农产品质量安全专项执法行动等专项整治，严厉打击、严肃查处各类违法违规行为。对涉及刑事责任的违法行为，坚决移送司法机关追究当事人的刑事责任，切实保障农业生产安全和农产品质量安全。

10．积极预防和妥善处置信访问题。围绕农业生产过程中影响社会和谐稳定的源头性问题，进一步健全组织领导体系和运转机制。将社会稳定风险评估作为出台重大决策、项目、事项的前置程序，从源头预防社会矛盾纠纷的发生。针对基层和农民反映的各类问题，及时介入、妥善调处，力争把矛盾纠纷化解在萌芽状态，最大限度增加和谐因素，为现代农业发展创造更加和谐稳定的环境。

三、保障措施

1．强化组织领导。实行领导班子是综治责任集体，主要领导负总责、分管领导具体负责、其他领导“一岗双责”的领导体制，切实加强组织领导和责任落实。按照“谁主管、谁负责”的原则，农委与各事业站所、直属企业签订《社会治安综合治理和平安建设工作目标管理责任书》，明确目标任务、工作要求和考核与奖惩办法。委属各科室站所要对照各自职责，认真抓好落实，做到“管好自己的人，看好自己的门，办好自己的事”。同时，加强配合，不断强化协调机制，构建统一协调、各尽其职、全委“一盘棋”的工作格局。

2．注重工作实效。各单位要围绕年度工作目标，结合实际，制定年度综合治理和平安建设工作计划，落实具体措施，培育亮点工作，确保安全稳定。要加大检查力度，对存在问题及时上报，抓紧整改。综合治理和平安建设工作纳入各单位年度考核评优，对各项工作到位、成效明显的，在年度考核时予以评优倾斜，对发生影响社会稳定重大问题的，取消单位先进评选资格，并对有关人员依法依规实施问责。

3．加大宣传力度。要围绕我市十三五现代农业建设目标，以农业法律法规和国家方针政策等为主要内容，以农委系统公职人员、农民等为主要对象，运用现代传媒技术拓展平安建设宣传的内容和形式，全面落实“七五”普法规划，提高农委系统干部职工对综合治理和平安建设工作的知晓率、参与率。同时，提高新媒体时代社会沟通能力，增强政治敏锐性和政治鉴别力，把握方向、把准基调，突出正面宣传，积极传播政法综治工作“正能量”。
