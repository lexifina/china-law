# 市政府印发关于加强新建住宅区配套服务设施规划管理的指导意见的通知

各镇政府，冶金工业园、常阴沙现代农业示范园区、双山岛旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：

经市政府同意，现将《关于加强新建住宅区配套服务设施规划管理的指导意见》印发给你们，请认真贯彻实施。

张家港市人民政府

2017年 3月22日

（此件公开发布）

关于加强新建住宅区配套服务设施

规划管理的指导意见

为提升新建住宅区规划建设水平，合理配置新建住宅区配套服务设施，创建方便、舒适的居住生活环境，根据《中华人民共和国城乡规划法》《江苏省城乡规划条例》《苏州市城乡规划条例》《苏州市居家养老服务条例》《苏州市新建住宅区服务设施规划管理规定》等相关法律法规和政策文件，结合本市实际，提出如下指导意见：

一、基本原则

（一）以人为本，着力提升居住品质

突出“为民、利民、便民”宗旨，按照与住宅同时设计、同时施工、同时投入使用的要求，合理配置新建住宅区配套服务设施，提升居住品质，改善居住环境。

（二）分类指导，全面优化功能配置

按照住宅区配套服务设施的分类要求，对公益性、物业和商业服务设施的管理实行分类指导，差别管理，全面优化住宅区配套服务设施的功能配置。

（三）齐抓共管，共同构建和谐环境

建设单位要强化住宅区配套服务设施建设的主体责任意识，严格按照相关标准和要求建设住宅区配套服务设施。相关部门根据各自职能分工，共同监督管理新建住宅区配套服务设施的规划、建设、移交和使用，构建和谐宜居的居住环境。

二、功能分类

按照不同的产权属性和使用特点，新建住宅区配套服务设施分为三类：

（一）公益性服务设施：是指为住宅区以及周边居民提供公益服务的设施，具有公共产品属性，包括社区居委会、幼托、文化、体育健身、卫生服务、居家养老和公用设施等。

（二）物业服务设施：是指为住宅区物业服务、管理等提供保障的物业配套设施，包括物业服务用房和物业服务经营性用房。

（三）商业服务设施：是指在一至三类居住用地（不包括商住混合用地）上建设的，为住宅区居民提供日常生活需要的商业等服务的设施。

三、建设标准

新建住宅区可按照以下标准和要求，合理配置配套服务设施：

（一）公益性服务设施

公益性服务设施一般应选择地面以上的非居住房屋，宜沿城市道路设置独立的出入口并对外开放。公益性服务设施所在楼层原则上不得高于三层，且不得设置在住宅楼下部；确需设置在住宅楼下部的，应当采取有效措施避免对上部住宅的干扰。分期开发建设的新建住宅区，其按规定需配建的公益性服务设施，原则上应在完成该住宅区开发建设总量的50%之前建设完成并投入使用。

1．新建住宅区应当按照社区布点规划，合理建设社区居委会用房（包括办公、活动、服务用房等）。市区二环路内的社区居委会用房建筑面积不少于500平方米，二环路以外的社区居委会用房建筑面积不少于800平方米。集中建设的拆迁安置住宅区居委会用房建筑面积不小于住宅区地上建筑面积的5‰，且不少于800平方米。社区居委会用房底楼建筑面积不少于200平方米，且房屋布局适宜社区设置一站式服务站。社区居委会用房产权归属地镇（区）政府（管委会）所有。

2．新建住宅区应满足居民健身需求，合理设置体育健身设施。新建住宅区原则上按照室内人均建筑面积不低于0.1平方米、室外人均用地不低于0.3平方米的标准（每户按3人计算，下同），配套建设群众健身相关设施。室内的体育健身用房可以设置于地下；室外单块活动场地要结合住宅区绿化集中设置，原则上不少于200平方米（短边不宜小于10米），并做好噪音防护等措施。新建住宅区的体育健身用房产权归建设单位所有，其中新建拆迁安置住宅区的体育健身用房产权归属地镇（区）政府（管委会）所有。

3．新建住宅区应满足居家老年人的养老服务需求，合理设置居家养老服务设施。新建住宅区按照不少于30平方米/百户的标准，安排社区居家养老服务设施。居家养老服务设施一般规划在住宅区出入口附近等老年人出入方便的地段；没有配置电梯的，所在楼层不得高于三层。居家养老服务设施产权归民政部门所有。

4．集中建设的拆迁安置住宅区需设置事宴厅（红、白喜事场所）的，建筑面积原则上不少于200平方米（具体建筑面积根据住宅区规模测算），地段应当相对独立，不得设置在住宅楼下部。事宴厅产权归属地镇（区）政府（管委会）所有。

5．幼托、文化和卫生服务等公益性服务设施的设置，按照控制性详细规划的要求确定。

6．开闭所（配电房）、煤气调压站、通信、信报箱等公用设施的设置，按照相关法律、法规、规范等执行。

（二）物业服务设施

物业服务用房应当是地面以上的房屋，由建设单位装修，具备独立、正常使用功能，相对集中安排在住宅小区中心区域或者住宅小区出入口附近；未配置电梯的物业，物业服务用房所在楼层原则上不得高于三层。物业服务用房设置在住宅楼内的，应当具有独立的通道。

新建住宅物业管理区域内，建设单位原则上按照不低于地上地下总建筑面积4‰且不低于地上建筑面积7‰的比例配置物业服务用房，低于100平方米的按照100平方米配置，并无偿移交。其中，用于业主委员会议事活动用房的，应当按照配置物业服务用房的比例合理确定，一般按照建筑面积20-40平方米配置。

集中建设的保障性住房（包括拆迁安置房、经济适用房、廉租房等）还应当按照不低于总建筑面积的3‰，增加配置物业服务经营性用房，收益用于弥补物业服务费不足。

电梯井、管道井、楼梯间、垃圾房（道）、变电室、消防控制室、设备间、公共门厅、过道、地下室、车库（棚）、人防工程等，以及室内层高不足2.2米的房屋不计入物业服务用房面积。

物业服务用房产权归住宅区全体业主所有。增配的物业服务经营性用房产权归属地镇（区）政府（管委会）或建设单位所有。

（三）商业服务设施

新建住宅区商业服务设施建筑面积原则上按照150-370平方米/千人的标准配置，其中新建拆迁安置住宅区商业服务设施建筑面积原则上不大于住宅区总建筑面积的5%。商业服务设施产权归建设单位所有。

具有特殊功能的商业服务设施（如菜场等），应当按照规划要求建设使用，建设单位不得擅自改变其规划功能。

四、保障措施

（一）明确职责分工

规划部门应当在新建住宅区建设项目规划设计条件中注明有关配套服务设施的规划要求，并在办理后续规划方案审核、核发建设工程规划许可证和规划核实时，严格按照相关指标要求，审核配套服务设施配置，做好源头把控；新建住宅区建设项目涉及社区居委会用房、居家养老服务设施的，应当在审核规划方案时征求民政部门的意见。

民政部门要加强对社区居委会和居家养老用房功能布置的业务指导，优化后期使用和管理，强化服务投入。

体育部门要深化研究体育健身设施的功能设置和场地布局，根据上级有关规定制定相关标准，为细化设计和后续使用提供指导。

国土部门要按照规划明确的功能，办理新建住宅区配套服务设施的产权登记确认。

房管部门要加强对物业服务设施规划建设的指导、监督和管理。

土地储备中心要在土地出让文件中对各类新建住宅区配套服务设施的产权归属进行明确。

各镇（区）和城投集团要加强对新建拆迁安置住宅区的规划管理，保障配套服务设施建设，确保拆迁安置住宅区的居住品质。

（二）加强协同配合

新建住宅区配套服务设施的规划管理涉及到诸多领域，相关部门和各镇（区）要各司其职、密切配合，共同做好相关工作。新建住宅区配套服务设施的产权归属单位，应当就建设、移交等事项主动与建设单位进行对接。

（三）营造良好氛围

相关部门要加大宣传力度，引导媒体对新建住宅区配套服务设施管理工作进行正面宣传，带领群众共同营造创建美丽城市的社会氛围。强化群众参与，突出群众监督，使配套服务设施管理工作公开透明。

本指导意见适用于本市出让或划拨的国有建设用地上新建住宅区配套服务设施的规划管理工作，自公布之日起施行；施行前已出让或划拨的国有建设用地，执行出让或划拨时的有关规定。
