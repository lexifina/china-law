# 市政府关于同意相关新建住宅区归属“绿景雅苑”地名命名的批复

杨舍镇人民政府：

你镇《关于将新建住宅区地名归属“绿景雅苑”的请示》（杨政发〔2017〕3号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将你镇位于平安路东侧空地东侧、中兴路南侧、绿景雅苑一期西侧、振兴路北侧范围内的新建住宅小区归属为“绿景雅苑”二期，沿用地名为“绿景雅苑”。地名标志汉语拼音拼写形式：LVJING YAYUAN。“绿景雅苑”二期规划占地面积62000平方米、总建筑面积176000平方米，多层1幢、高层7幢共982户（套）。“绿景雅苑”二期归属后的“绿景雅苑”位于平安路东侧空地东侧、中兴路南侧、蒋锦路西侧、振兴路北侧范围内，规划占地面积131000平方米、总建筑面积378000平方米，多层2幢、高层14幢、影城楼1幢，共1976户（套），绿化率45%。

请按照《地名标牌 城乡》（GB17733—2008）国家标准，及时做好楼幢号牌、单元牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2017年4月7日
