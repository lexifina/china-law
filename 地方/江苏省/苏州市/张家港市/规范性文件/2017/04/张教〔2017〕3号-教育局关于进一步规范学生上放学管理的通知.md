# 教育局关于进一步规范学生上放学管理的通知

各初中、小学：

为进一步落实《义务教育学校管理实施标准》《江苏省中小学管理规范》等法规文件精神，确保学生平安、健康成长，现就进一步规范学生上学与放学管理要求如下：

一、正确把握规定要求

要认真研读市教育局下发的《张家港市小学“规范办学行为”重点要求》《张家港市初中“规范办学行为”重点要求》《关于调整城区初中学校作息时间的函》等文件，正确把握对学生上学与放学在时间、安全等方面的规定，切忌片面理解、机械执行，坚决杜绝早晨将早到校的学生关在校门外面、到学校规定时间才打开校门让学生进校的现象。

二、切实加强调查研究

要对学生上学以及家长接送孩子等情况进行调查分析，重点了解需早到校、晚离校的学生及其原因，观察、分析上学与放学高峰时段校门口道路的交通流量与通行压力等情况，并根据校情生情路情，主动与公安、城管等部门联系，一起研究维持交通秩序、保障学生交通安全等的新思路、新方式、新机制。

三、着力优化常态管理

要突出以生为本，坚持规范办学，创新管理举措，构建长效机制，重点做好四项工作。

1.加强教育引导。要通过晨会、班会（队）、“乐教乐学”“家校路路通”“翼校通”、家长“QQ”群以及微信群等途径与平台，将作息时间告知每位学生及家长，并引导学生和家长根据居住地到学校的路程，合理安排上学或接送时间，尽量避免过早到校。

2.完善错时措施。学校各年级段应根据实际情况，推行错时上学和放学，并引导家长接送孩子不在校门口长时间停留。放学时，应要求班主任或任课教师将学生护送到校门口或其他指定地点，按时“静堂”“静校”；有条件的学校，应分学段或班级划分家长等候区。

3.落实值班护导。加强门卫管理，强化学校保安的工作职责；协同公安交警、组织家长志愿者等，进一步加强上放学时段校门口的值勤护导。对有特殊情况需早到校的学生，经家长申请、办理相关手续后应“随到随进”，不能“拒之门外”，让他们在学校周边逗留玩耍；同时，要安排学校行政领导与教师值班，引导他们开展课外阅读、体育锻炼等活动，并加强安全教育与管理。对放晚学后家长不能按时来接的学生，应组织参加“四点半学校”，并提供多元、适切的教育与服务。

4.强化检查督促。各校要组织校行政领导、班主任等人员，对学生早上到校与放学的情况加强自查，及时发现并化解矛盾与问题；对突出矛盾或重大问题，应报教育局安管科、基教科等相关职能科室协同解决。教育局将把各校对学生上放学的管理，纳入挂牌督导、专项督导与安全常规检查中，组织进行常态化、随机性督查，并通报督查结果。
