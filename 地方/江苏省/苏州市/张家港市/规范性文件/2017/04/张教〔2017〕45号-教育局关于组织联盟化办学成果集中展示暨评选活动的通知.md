# 教育局关于组织联盟化办学成果集中展示暨评选活动的通知

各学校联盟、教育集团，各直属单位：

根据《关于进一步加强学校联盟建设提升教育优质均衡发展水平的实施意见》（张教〔2015〕93号）、《教育局关于成立张家港市梁丰初级中学联盟等14个学校联盟的通知》（张教〔2015〕98号）及《2017年度张家港市教育工作要点》（张教〔2017〕2号）等文件精神，决定组织联盟化（含集团化，下同）办学项目建设成果集中展示暨评选活动。现就有关工作通知如下：

一、展示暨评选范围

全市各学校联盟、教育集团。

二、展示暨评选条件

参与联盟化办学项目建设成果集中展示暨评选活动须同时满足以下两项条件：

（一）学校联盟（教育集团）组建的教师发展、德育工作、课程建设、课堂教学、教育科研、学校文化、学生社团等项目组，工作卓有成效、富有特色，其经验、特色得到同行充分认可或是专题文章在苏州市级以上媒体公开发表（获奖）。

（二）围绕发挥优质学校资源优势和品牌效应，缩小城乡学校办学差距，努力实现城乡一体、优质均衡的联盟化办学目标，项目组建设有效推动了本联盟（集团）优质教育教学资源的共建共享，项目建设成果较好展示了在联合办学进程中联盟（集团）内各校或大多数学校在某些工作上的共同发展与进步。

三、集中展示基本形式

联盟化办学项目建设成果集中展示的基本形式为“1+X”,“1”为必选项目，即教师发展项目，展示联盟创新教师培养方法，在核心学校支管支教、成员学校顶岗学习等工作中取得的明显成效；“X”为自选项目，即联盟特色项目，展示德育工作、课程建设、课堂教学、教育科研、学校文化、学生社团等项目组建设中最富特色的1～2个项目。

四、展示暨评选步骤

（一）实行自主申报（2017年5月底前）。各学校联盟、教育集团对照集中展示暨评选条件，确定“1+X”（即教师发展项目+自选项目）个优秀项目参与市级集中展示暨评选活动。

2017年5月31日前，各基础教育学校联盟（集团）、扬子江职业教育集团分别将《联盟化办学优秀项目集中展示暨评选活动申报表》（附件）纸质稿送交教育局基教科、职社科及人事科。

（二）确定展示项目（2017年6月底前）。教育局基教科、职社科、人事科等科室会同教研室等直属单位组织专门人员对各学校联盟（教育集团）申报的项目进行筛选，最后确定参与集中展示暨评选活动项目（由教研室牵头拟发入选集中展示暨评选活动项目通知）。

（三）组织集中展示（2017年11月底前）。联盟化办学项目建设成果集中展示暨评选活动原则上与第十九届课堂教学改革经验交流活动相结合，由基教科、职社科、人事科会同教研室制定具体工作方案后及时予以公布。

（四）进行表彰激励（2017年12月底前）。设立联盟化办学项目建设优秀成果奖，并以组织团队外出研修、邀请专家讲学等方式给予优秀项目以激励支持。
