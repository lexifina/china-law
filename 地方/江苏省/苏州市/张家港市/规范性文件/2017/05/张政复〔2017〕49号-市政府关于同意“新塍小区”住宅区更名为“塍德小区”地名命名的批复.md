# 市政府关于同意“新塍小区”住宅区更名为“塍德小区”地名命名的批复

金港镇人民政府：

你镇《关于“新塍小区”更名为“塍德小区”的请示》收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将你镇“新塍小区”更名为“塍德小区”。更名后的“塍德小区”共有两个区域：一部分位于文星南路东侧、张家巷弄(规划道路暂命名)南侧、大张家巷西侧、南横港河北侧范围内；另一部分位于新塍路东侧新塍村门面房东侧、新塍花苑路南侧、文星南路西侧、新塍农贸市场北侧范围内，占地面积共计333333平方米，总建筑面积350000平方米，多层102幢2470户，社区用房1幢，绿化率为35%。地名标志汉语拼音拼写形式：CHENGDE XIAOQU。

请按照《地名标牌 城乡》（GB17733—2008）国家标准，及时做好楼幢号牌、单元牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2017年5月31日
