# 关于同意设立5家民办非学历教育机构和1个教学点的批复

各相关单位：

根据举办者的申请，依据《中华人民共和国民办教育促进法》和《江苏省民办非学历教育机构设置和管理办法》等有关法律法规及规范性文件规定，经材料审核与现场勘察，同意设立张家港市和达教育培训中心等4家民办非学历教育机构。依据《张家港市民办非学历教育机构审批和管理办法》关于“四星级及以上的教育机构可申办设立教学点”的政策规定，经审核验收，同意设立教学点1个。具体名单如下：

一、新设立的民办非学历教育机构

1.张家港市和达教育培训中心

办学许可证号：教民13205827zx01031号。办学地址：张家港市沙洲西路113号；举办者：王昱欢；校长：王昱欢；办学内容：中小学假期助学辅导、艺术类培训。

2.张家港市利得斯教育培训中心

办学许可证号：教民13205827zx01041号。办学地址：张家港市沙洲西路121号；举办者：於健；校长：於健；办学内容：中小学假期助学辅导。

3.张家港市优特教育培训中心

办学许可证号：教民13205827zx01051号。办学地址：张家港市沙洲中路118号；举办者：葛磊；校长：毛海祥；办学内容：英语培训。

4.张家港市理想教育培训中心

办学许可证号：教民13205827zx01061号。办学地址：张家港市港城大道239号；举办者：张立珊；校长：张立珊；办学内容：英语培训。

5.张家港市圣乔治教育培训中心

办学许可证号：教民13205827zx01071号。办学地址：张家港市白鹿路1号；举办者：黄蓁；校长：许琳燕；办学内容：婴幼儿素质拓展培训。

上述单位办学许可证有效期限为2017年5月29日～2022年5月28日。请依照有关法律法规，及时到民政局、税务局、公安局等单位办理相关手续。

二、新设立的教学点

张家港市长三角教育培训服务中心教学点：

教学点地址：张家港市人民西路369号。新申办的教学点，其办学活动须由张家港市长三角教育培训服务中心统一实施，并承担责任。

上述新设立的民办非学历教育机构和教学点由我局主管，今后，其招生简章和广告应向我局报批备案。若对许可规定范围内的举办者、办学地址、办学内容等项目有变更要求，应提前向我局提出书面申请，由我局核准同意后方可执行。

此复。

张家港市教育局
