# 关于印发《张家港市农业委员会2017年依法行政和普法工作实施意见》的通知

委属各科室、各单位：

根据省、苏州市农委有关会议精神和市政府办公室《关于印发2017年张家港市法治政府建设工作要点的通知》（张政办〔2017〕27号）要求，结合我委实际，制定了《张家港市农业委员会2017年依法行政和普法工作实施意见》，现印发给你们，请认真贯彻实施。

张家港市农业委员会

2017年6月1日

（此件公开发布）

张家港市农业委员会2017年依法行政和普法工作实施意见

2017年我委依法行政和普法工作将深入贯彻落实党的十八大和十八届三中、四中、五中、六中全会及省、苏州市农委有关会议精神，根据市政府办公室《关于印发2017年张家港市法治政府建设工作要点的通知》（张政办〔2017〕27号），紧紧围绕农业中心工作，进一步落实行政审批体制改革，推进科学民主决策，加强行政执法规范化建设，全面提升农委系统依法行政工作能力和水平，为我市现代农业建设提供坚强的法制保障。

一、坚持职责法定，全面开展法治建设

1.扎实推进农业“放管服”。制定2017年张家港市农业依法行政和普法工作实施意见，按照简政放权、放管结合、优化服务的要求，进一步明确目标要求，分解落实任务，确保各项改革措施落到实处。

2.做好行政审批事项梳理承接。坚持“法定职责必须为，法无授权不可为”原则，对市政府公布的涉及我委权力清单，合理、清晰地界定部门职能和权限，规范系统内重点岗位的人员职责、工作程序、办事纪律等内容。对国家、省和苏州市取消和委托下发的农业行政审批事项，及时认真做好对接工作，规范农业行政行为。推进权力清单优化和清理，加强行政审批事中、事后监管。根据全省“互联网+政务服务”体系建设要求，按照“三级四同”（即省市县三级权力名称、类型、依据、编码相同）和“目录之外无审批”的要求，对行政审批项目进行梳理，做到“应上尽上”，所有事项均可在江苏政务服务“一张网”上办理。

3.逐步完善“双公示”制度。逐步推进农业信用信息“双公示”工作，开展信用管理项目应用试点，发布企业信用红黑榜，加大信用宣传力度，与市场监管等部门协作，做好红黑榜的运用，营造守信激励、失信惩戒的氛围。对农委办结的行政许可和行政处罚事项，及时上传，在中国张家港等网站上进行公示。

4.严格落实文件法制审核。严把文件法制审查关，加强对以农委（林业局）名义印发的文件的法制审核，及时发现和预防制度漏洞，保证文件的合法性、严密性、可操作性。围绕现代农业发展，根据社会关注、实践急需、条件成熟的标准，科学统筹安排年度规范性文件立项计划。对涉及规范性文件的，必须通过征求意见、召开座谈会、听证会、论证会等公共参与形式，广泛听取相关部门、专家学者和社会公众意见，及时反馈意见采纳情况，增强规范性文件的科学性、民主性。严格执行《江苏省规范性文件制定和备案规定》，及时做好规范性文件的备案工作。

5.全面发挥法律顾问作用。坚持法律顾问制度，进一步加强事前合法性审核和法律风险的防范。开展法律顾问普法工作制，根据工作需要编制《农业法律知识解读》电子期刊。完善法律顾问工作规则和考核办法，定期对法律顾问的工作业绩、业务能力、履职态度进行全面考核，确保法律顾问在制定重大行政决策、推进依法行政等方面发挥更加积极的作用。

6.继续推动创新社会治理。利用现有优势，继续在全国率先探索政府购买农业公益性服务机制，重点开展农作物种子统一供应、农药集中配送、集中育秧服务、畜禽疫病防控、测土配方肥料推广等工作。对涉农公益性服务项目政府购买的主体、内容、操作办法等做出系统规定，逐步建立健全符合地方实际、具有前瞻性和操作性的政府购买服务工作机制。

二、规范行政程序，推进科学民主决策

7.实施重大决策目录管理。严格落实《张家港市重大行政决策程序规定》及其操作细则，重大行政决策事项实行目录化管理，将涉农的重大行政决策事项目录实行动态管理并对外公开。

8.实施重大决策过程管控。严格执行重大行政决策过程中的公众参与、专家论证、风险评估、合法性审查、廉洁性审查以及集体讨论决定等法定程序。对重大行政决策事项，需要通过召开座谈会、论证会、听证会或者以其他方式充分听取相关各方意见。落实重大行政决策风险评估机制、合法性审查机制，建立重大行政决策全过程记录和档案管理制度，确保合法合规。

9.实施重大决策责任追究。建立重大决策终身责任追究制度及责任倒查机制，确保重大行政决策规范运行，对决策严重失误、未按程序执行以及依法应该及时作出决策但久拖不决造成重大损失、恶劣影响的，严格追究主要负责人和相关责任人员的法律责任。建立健全决策实施情况后评估制度，完善后评估成果的运用。

三、规范执法行为，加强行政执法监管

10.稳步落实“双随机、一公开”。按照《省政府办公厅关于建立双随机抽查机制加强事中事后监管的通知》、《省农委建立“双随机、一公开”抽查机制加强事中事后监管工作的实施意见》精神，确定农委“两库一清单”，即随机抽查事项清单、市场主体名录库和行政执法人员名录库。按照“双随机”要求，加强行政执法跟踪与监督。

11.完善执法全过程记录制度。按照行政执法过程全程留痕的要求，强化程序意识，细化执法流程，制定农业行政执法全过程记录工作制度，开展农业行政执法全过程记录课题研究，不断修订与完善制度，做到执法规范、流程科学合法，确保证据无缺失、无瑕疵。

12.强化执法协作和案件查处。加强与公安、市场监管、供销等部门的执法协作。加强农委内部监管科站的沟通协调。加强农业行政执法与刑事司法衔接。突出重点时段、重点领域、重点品种，加大案件查处力度，严厉打击制售假劣农资和禁用农业投入品、危害农产品质量安全等违法行为。

四、加强普法宣教，提升系统法治水平

13.落实日常普法学习制度。继续依托领导干部学法、党委中心理论组学习、“5+X”公务员能力培训、法律知识更新培训等法律学习活动载体，组织4次以上领导干部集体学法活动，组织40学时以上的机关工作人员的法律学习培训等，全面强化全委公职人员宪法意识和法治理念，提升系统公职人员运用法治思维和法治方式的能力。

14.加强学法普法宣传教育。做好中央、省、苏州市有关农业政策法规的传达贯彻，抓好《江苏省实施〈中华人民共和国农业技术推广法〉办法》和新出台的《农药管理条例》等法律法规的释法宣传。以放心农资下乡进村宣传周、农民培训工程、农产品质量安全宣传周、国家宪法日等为契机，深入开展各类农业法制宣传活动，通过现场解答、法律咨询、发放宣传资料、悬挂宣传横幅、播放宣传视频等宣传形式，宣传与我市农业现代化建设息息相关的法律法规，有效拓宽广大农业生产者、人民群众的法律知识面，提高普法工作的实效性。

15.抓好执法人员学习培训。切实贯彻落实七五普法和省农委《关于加强全省农业系统领导干部及工作人员学法用法工作的实施意见》，举办系统内行政执法人员培训班，加强农业行政执法队伍建设，丰富基层农业执法人员法律法规理论知识，增强行政执法业务能力，不断提高依法治农水平。通过农委统一培训和行业条线培训相结合的办法，力求行政执法人员学习培训总学时在15日以上，建设一支素质高、能力强的执法队伍。

五、化解各类矛盾，维护农业行业稳定

16.积极化解农业生产矛盾。强化法律在维护群众权益、化解社会矛盾中的权威地位，健全社会矛盾预警、利益表达、协商沟通、救助救济等机制，畅通群众利益协调、权益保障法律渠道。完善农业行政调解工作办法，建立健全行政调解组织体系，依法开展涉农投诉行政调解，充分发挥行政调解在处理农业生产事故中的重要作用。

17.积极维护农业行业稳定。坚持规范信访行为和规范信访工作两手抓，促进以法治思维和法治方式化解信访问题。加强农业重大信访事项社会稳定风险评估，对苗头性、倾向性信息强化跟踪分析，及时掌握信访动态。要结合日常农业技术指导与服务，积极帮助农民和种田大户等，协调处理农业生产中的各类事故和矛盾，确保社会稳定。
