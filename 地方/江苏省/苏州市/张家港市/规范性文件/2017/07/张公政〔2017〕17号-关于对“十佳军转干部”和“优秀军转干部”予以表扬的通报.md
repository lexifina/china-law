# 关于对“十佳军转干部”和“优秀军转干部”予以表扬的通报

各警署、各派出所、直属各单位、机关各部门：

近年来，全市公安机关广大军转干部在市局党委的坚强领导下，传承和发扬人民军队的光荣传统，以优良的纪律作风和过硬的意志品质，立足岗位，默默奉献，在维护稳定、打击犯罪、服务群众等方面做出了突出成绩，为我市公安工作转型升级科学发展贡献了重要力量。

在“八·一”建军节来临之际，为表彰先进，鼓舞士气，进一步激发广大军转干部立足岗位、建功立业的工作热情，市局组织开展了“十佳军转干部”和“优秀军转干部”评选活动。经各单位民主推荐，各警署、各警种部门审核上报，综合考虑倾向基层一线、注重工作实绩等因素，市局决定：授予蒋一龙等10名同志“张家港市公安局十佳军转干部”称号，授予周万水等8名同志“张家港市公安局优秀军转干部”称号，颁发证书和纪念章，并通报表扬。

希望受到表彰的同志珍惜荣誉，发扬成绩，再接再厉，再创佳绩。全市公安机关广大民警要以先进为榜样，认真学习贯彻习近平总书记在全国公安机关英雄模范立功集体表彰大会上的重要讲话精神，紧紧围绕全面深化公安改革、大力推进“四项建设”和市局党委聚焦创新强警、护航“四大路径”的工作布局，全力以赴做好各项安保维稳工作，以实际行动维护人民群众利益，确保全市社会大局持续稳定，为全市率先高水平全面建成小康社会创造平安稳定环境，以优异成绩迎接党的十九大胜利召开！
