# 市政府关于印发关于进一步加强新时期民政工作的意见的通知

各镇政府、冶金工业园、常阴沙现代农业示范园区、双山岛旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：

经市政府同意，现将《关于进一步加强新时期民政工作的意见》印发给你们，请认真贯彻实施。

张家港市人民政府

2017年7月7日

（此件公开发布）

关于进一步加强新时期民政工作的意见

为进一步推进民政工作科学发展，更好地为全市经济社会又好又快发展大局服务，现就进一步加强新时期民政工作提出如下意见：

一、提高认识，准确把握新时期民政工作目标任务

“十三五”时期，是我市全面建成更高水平小康社会的关键阶段，也是经济社会发展的重大转型期和重要机遇期。围绕全面落实张家港市民政事业发展“十三五”规划，适应新时期民政从“小民政”向“大民政”、“传统民政”向“现代民政”的发展趋势，充分发挥民政在社会建设中的骨干作用，突出普惠性、保基本、均等化、可持续方向，紧扣现代民政工作“法治化、标准化、社会化、专业化、人文化、信息化”特征，夯实基层民政基础，增加公共服务供给，创新提供方式，全面调动各类社会群体的积极性、主动性和创造性，提高人民群众的参与度和全社会的凝聚力，实现民生幸福、社会和谐目标，全力争当全省现代民政示范县市排头兵，努力让港城人民过上更有品质的生活。

二、突出重点，努力推进民政工作全面协调发展

（一）完善城乡社会救助救灾体系。进一步健全城乡居民最低生活保障制度，优化居民家庭经济状况核对机制，有效拓展救助内涵，提升整体救助能力和水平。搭建社会救助关爱服务平台，设立困难群众基本信息库和项目援助库，引导和链接各种社会力量参与，针对困难群众个性化需求，从单纯的物质救助向精神帮扶、文化需求、技术能力等领域拓展，实现精准帮扶。提高城乡居民防灾减灾意识和对自然灾害风险综合防范防御能力。

（二）构建多层次社会养老服务体系。以苏州市居家和社区养老服务改革试点工作为契机，重点发展居家和社区养老，推进“互联网+” 养老服务，实现养老服务供给与老年人需求的精准对接。加快养老服务社会化步伐，支持为老服务企业或社会组织通过兼并重组、连锁经营、承接政府购买服务等方式做大做强，3年内由社会力量运作的社区居家养老服务设施占比达到90%以上。全力推动公办养老机构改革，吸引全国优秀养老服务企业落户我市，开展合作经营，到2018年底，镇（区）公办养老机构实现100%公建民营。加快推进医养融合，到2020年底，全市护理型床位占养老床位总数70%以上。

（三）加快社会福利事业发展。努力培养市民崇德向善意识，稳步推动社会福利由“补缺型”向“适度普惠型”、特殊群体向社会公众转变。积极开展以扶贫济困为重点的慈善活动，着力打造“阳光慈善”系列项目品牌。鼓励镇、村两级“自募自用”，推动慈善回归民间。加大政府向慈善组织购买服务力度，支持慈善组织开展活动。加强“中华慈善日”宣传活动，广泛弘扬慈善理念，慈善城市综合指数保持在全国前列。

（四）全面提高新时期双拥工作水平。全力争创全国双拥模范城“七连冠”，高标准争建省级双拥模范城，大力推动军民融合深度发展，不断深化“双拥在基层”和社会化拥军活动，培育规范拥军优属社会组织，建立完善基层拥军优属服务平台，着力破解涉及军民切身利益的重难点问题，全力解决涉及官兵切身利益的退役军人安置、随军家属就业、军人子女入学等“后路”“后院”“后代”问题。

（五）提高社会专项事务服务管理水平。推动移风易俗，深化殡葬改革，推广文明祭扫、文明办丧，生态安葬。强化区划地名工作的规范化、社会化和专业化，优化地名文化建设。依法开展婚姻和收养登记工作。切实加强救助管理规范化建设。

三、强本固基，着力提升城乡社区治理水平

认真贯彻落实《中共中央国务院关于加强和完善城乡社区治理的意见》，着力解决目前我市城乡社区仍普遍存在的社区自治和服务功能不强、基层群众自治活动的内容和载体相对单一、社区治理参与机制还不健全、政府部门包办过多、社会力量和市场主体的参与缺乏长效机制等瓶颈问题，努力开创新形势下城乡社区治理新局面。

（六）深入开展试点工作。认真完成好国家农村改革试验区新增试验任务——以农村社区为基本单位的村民自治试点、江苏省社区治理和服务创新实验区两项试点任务。通过社区治理“六个化”举措（党引民治实效化、社区协商制度化、基层治理法治化、治理主体多元化、服务体系社会化、信息资源统筹化），扩大社区参与，促进社区融合，推动社区自治，全面提升城乡社区治理法治化、科学化、精细化水平和组织化程度，促进城乡社区治理体系和治理能力现代化。按照试点任务要求，到2018年，全市范围内全面推行各项试点举措，形成以党建引领为方向，以合法合规为原则，有序参与、充满活力的基层民主自治体系；到2019年，进行总结评估，形成理论创新、实践创新和制度创新的示范成果，形成“多元主体共谋、多层协商共治、多方联动共推”的城乡社区治理新格局。

（七）持续为社区减负增效。落实《关于推进城乡社区减负增效的实施意见》（张委办〔2016〕11号）相关规定，开展减负增效“回头看”工作，重点督查社区工作机构、挂牌、阵地、创建达标评比项目、台账、盖章证明事项、考核等减负内容，防止工作一阵风、前清后滥。依据社区工作事项清单落实社区工作事项准入制度，应当由基层政府履行的法定职责，不得要求基层群众性自治组织承担。加快建设张家港市智慧社区平台，实现一号申请、一窗受理、一网通办，强化“一门式”服务模式的社区应用。

（八）引导社会组织健康有序发展。大力培育发展社区社会组织，实行社区社会组织登记备案双轨制，支持鼓励在城乡社区开展为民服务、养老照护、公益慈善、促进和谐、文体娱乐和农村生产技术服务等活动的社区社会组织，到2020年，全市每万人拥有登记社会组织数12个，社区社会组织备案数超2900个。稳妥推进社会组织直接登记制度，完善社会组织信息“双公开”制度，创新社会组织事中事后监管方式，探索社会组织联合监管机制，建立社会组织“异常名录”和“黑名单”，扎实推进社会组织党建工作。

（九）发展壮大基层社工队伍。制定进一步支持发展专业社工机构的政策文件，支持各类社工机构健康、可持续发展。提升基层社会工作专业服务能力，到2020年，持证社工人数达到2200人，民办社工机构达到60家。

（十）稳步推进社区服务社会化。充分发挥市社区发展基金会功能作用，推进社区服务社会化，力争到2020年底，基本实现城市社区全覆盖，农村社区覆盖率不低于30%。稳步推进“全科社工”模式，把原来社区工作站分条线接待居民的“咨询类、办理类、求助及反映问题类”行政事务，实行“全能通办”，因地制宜探索建立不同类型的“全科社工、全能服务”社区工作机制，并通过实行“统一标准、统一培训、统一规范、统一绩效、统一保障”等举措，着力提高全科社工能力素质。

四、加强领导，全面提升基层民政能力建设水平

（十一）健全民政工作组织领导机制。各镇（区）每年不少于一次专题会议研究民政工作，对于社区、养老、双拥、社会救助、慈善福利等系统性较强的工作，要主动协调、积极作为。按照预算编制规定将民政工作经费列入同级财政预算，民政资金实行专款专用，严禁挤占和挪用。加速推动社会参与，在法律法规没有禁止的民政基本民生服务和市场公共服务领域，允许社会力量进入。

（十二）进一步加强基层民政队伍建设。一是充实和保障基层民政力量。严格按照《市政府办公室转发关于切实加强镇（区）民政机构建设的若干意见的通知》（张政办〔2013〕46号）有关要求，进一步落实、规范镇（区）民政机构设置，充实和保障民政管理服务人员配备。二是持续提升民政队伍能力素质。通过业务培训、绩效比拼、岗位练兵等举措，提升民政队伍法治化、信息化、专业化等综合能力，不断适应新形势。三是探索建立民政专干队伍长期稳定机制。因地制宜总结推广锦丰等地做法，积极改进和探索专干队伍管理、激励机制，激发和保障基层民政工作人员干事创业的积极性，保持村、社区民政专干队伍的专业化和长期稳定。四是夯实基层民政工作基础。树立大民政理念，鼓励和引导村、社区两委干部职工参加社工考试，学习和掌握民政政策法规，增强为民服务本领。

（十三）重视民政公共服务设施建设。各镇（区）要把基本养老服务、城乡社区、殡葬设施等民政公共服务设施建设作为民生建设的重要项目列入规划，通过政府实事工程等方式加以推进，促使民政公共服务设施不断完善，规划布局更趋合理，综合保障能力持续增强。

（十四）加强民政信息化建设。依托信息化建设，梳理全市涉及救助、救灾、慈善、养老等散布在各政府部门和党群组织的资源清单，收集整合各类民间资源，建立民政社会服务信息支持体系，为社会公众特别是困难群众搭建“社会救助关爱中心”等社会综合救助服务平台、社会福利信息平台、社会事务信息平台。各镇（区）要积极主动运用民政信息化建设成果，提高全市民政社会服务科学化和社会化水平。
