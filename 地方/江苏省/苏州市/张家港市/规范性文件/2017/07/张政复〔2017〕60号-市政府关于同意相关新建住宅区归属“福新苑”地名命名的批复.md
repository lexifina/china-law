# 市政府关于同意相关新建住宅区归属“福新苑”地名命名的批复

杨舍镇人民政府：

你镇《关于将新建住宅区地名归属“福新苑”的请示》（杨政发〔2017〕24号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）和有关法律法规规定，经研究，同意将你镇位于福锦路东侧、晨丰公路南侧农田南侧、国兴路西侧、福新苑一期北侧范围内的新建拆迁安置房归属为“福新苑”二期，沿用地名为“福新苑”。地名标志汉语拼音拼写形成：FUXIN YUAN。“福新苑”二期规划占地面积51740平方米、总建筑面积120430平方米，共建小高层8幢、高层4幢共794户（套）。“福新苑”二期归属后，“福新苑”位于福锦路东侧、晨丰公路南侧农田南侧、国兴路西侧、福新路北侧。规划占地面积117873平方米、总建筑面积276307平方米，共建小高层13幢、高层12幢共1750户（套），社区服务用房1幢，绿化率约39%。

请按照《地名标牌 城乡》（GB17733—2008）国家标准，及时做好楼幢号牌、单元牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2017年7月13日
