# 市政府关于同意“勤星苑”地名命名的批复

杨舍镇人民政府：

你镇《关于“勤星苑”地名命名的请示》（杨政发〔2017〕27号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将你镇位于勤星村1—4组仓库东侧、乘航西路南侧勤星村1—4组民宅南侧、民星路（新建道路暂命名）西侧、

新建规划道路北侧

范围内的新建住宅小区命名为“勤星苑”。地名标志汉语拼音拼写形式：QINXING YUAN。“勤星苑”规划占地面积40198平方米、总建筑面积82918平方米，小高层8幢、社区用房1幢，共528户（套），绿化率36%。

请按照《地名标牌 城乡》（GB17733—2008）国家标准，及时做好楼幢号牌、单元牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2017年7月13日
