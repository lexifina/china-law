# 教育局关于明确学校收费形式规范非税操作流程的通知

各中小学、幼儿园：

根据张家港市教育局、张家港市财政局、张家港市物价局《关于进一步规范我市学校服务性收费和代收费的通知》（张教[2017]96号）文件精神，为加强我市学校收费管理，规范学校非税收入收缴管理制度，方便家长缴费，提高收费效率，现对学校非税收入收缴的相关规定及学校收费形式明确如下：

一、非税收入收缴规定

1．非税收入资金管理范围包括行政事业性收费、政府性基金、国有资源（资产）有偿使用收入、国有资产经营收益、资本经营收入、彩票公益金、罚没收入、以政府名义接受的捐赠收入、主管部门集中收入、政府财政资金产生的利息收入等。

2．除国家另有规定外，各学校收费应使用张家港市财政局统一印制的“张家港市非税收入一般缴款书”，并严格执行国家有关规定，不得擅自多收、少收或不收。

3．非税收入收缴实行“单位开票、银行代收、财政统管”的管理方式，单位应将非税收入直接缴入财政非税收入专户，不得截留、挤占、挪用，不得开设非税收入过渡性帐户，不得将非税收入缴入其他帐户。

4．学校收取的服务性收费和代收费，凡列入《关于进一步规范我市学校服务性收费和代收费的通知》（张教[2017]96号）的收费项目，均使用“张家港市非税收入一般缴款书”。

二、学校收费形式要求

学校开学收费时点性强，收费集中，量大任务重，不得采用批量现金收款。为适应互联网+时代家长的需求，方便学生家长缴费，推荐学校采用银行互联网平台、家长自主缴费方式进行收费：

1．各公办学校要高度重视家长的诉求，切实增强服务意识，主动与当地财政部门及本校财政非税专户开户银行取得联系，配合财政部门和银行做好互联网收费平台建设，提供多种收费方式供家长自主选择：（1）家长无银行卡的到指定银行办卡，手机下载银行手机客户端完成缴费。（2）家长有银行卡的无需到其他银行新办卡，手机下载银行手机客户端完成缴费。（3）用电脑登陆网上银行缴费。（4）请已经开通手机客户端的朋友代缴。各民办学校也要积极跟进，与开户银行协商，加快互联网平台开发。

2．为满足学生家长多样化的缴费需求，学校在提供互联网缴费服务方式的同时，应提供银行柜台缴费、直接收取现金等服务方式。各校应安排专人收取家长现金后代缴，凡收取现金代缴的，应在当日内完成，并将代缴信息及时通知家长。

3．各校应准确提供学生信息、收费项目、收费标准等基础性数据给指定银行，确保2017年秋季学期能为家长提供互联网缴费服务。

4．各校应通过告家长书将缴费操作流程（由银行提供）告知家长，也可以在学校公示栏张贴，由家长选择登录银行网址或手机扫二维码进行缴费。为防钓鱼短信，网址和二维码不得通过短信形式发送，并告知家长。
