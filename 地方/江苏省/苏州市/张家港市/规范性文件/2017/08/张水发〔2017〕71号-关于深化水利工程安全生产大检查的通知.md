# 关于深化水利工程安全生产大检查的通知

局机关各科室、各直属企事业单位:

为进一步强化水利工程安全隐患排查整治，有效防范安全事故发生，结合我市安全生产大检查的方案，经研究决定，将水利工程安全生产大检查时间延长至2017年12月31日，并对按张水发﹝2017﹞61号文成立的督查组及分工进行调整，详见附件1。

各督查组在根据相关安全生产工作方案，组织开展督查的同时，要以建筑工地易发生的机械伤害、触电、高处坠落、坍塌、物体打击、场（厂）内专用机动车辆等事故的防治措施的落实情况，运行水利工程的结构物安全、金属结构、电气自动化设备设施、安全标示标牌等为重点，强化现场隐患排查，发现隐患，督促及时整改，并通过跟踪检查，确保隐患消除。

附件：1、水利局安全生产督查组成员名单及分工安排

2、关于开展全市水利安全生产大检查的通知（苏市水〔2017〕230号）

3、关于印发《水利安全生产“百日行动”专项方案》的通知（张水发〔2017〕44号）

4、关于开展水利安全生产“百日行动”、人员密集场所和危化品安全生产、汛期及夏季高温水利安全生产专项督查工作的通知（张水发〔2017〕61号）

5、关于印发《张家港市水利工程建设领域安全生产执法“百日会战”行动实施方案》的通知（张水发〔2017〕63号）

6、关于开展全市水利安全生产大检查的通知（张水发〔2017〕64号）
