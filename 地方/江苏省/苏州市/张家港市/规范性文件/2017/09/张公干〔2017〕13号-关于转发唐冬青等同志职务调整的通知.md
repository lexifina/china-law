# 关于转发唐冬青等同志职务调整的通知

各警署、各派出所、直属各单位、机关各部门:

接市委张委组〔2017〕181号、203号、230号文件通知、市政府张政人〔2017〕27号、40号文件通知：

唐冬青同志任市公安局主任科员，免去市公安局党委委员、纪委书记职务；

张旦忠同志任市纪委第十八派驻纪检组组长（驻市公安局），免去市公安局法制大队大队长职务。

特此通知。

张家港市公安局

2017年9月6日

（此件公开发布）
