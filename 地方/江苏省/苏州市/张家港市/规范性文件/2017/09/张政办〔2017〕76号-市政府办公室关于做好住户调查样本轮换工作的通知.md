# 市政府办公室关于做好住户调查样本轮换工作的通知

各镇政府，冶金工业园、常阴沙现代农业示范园区、双山岛旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：

为更好地反映城乡居民收入消费状况，监测居民收入分配格局和生活质量，根据国家统计局统一安排，2017年在全国开展新一轮住户调查样本轮换工作。此次轮换我市共抽中20个行政村（社区），作为新的住户调查点，且五年不变。记账工作分两轮实施，第一轮记账三年，第二轮记账两年，每轮各抽取200户居民作为记账户，新一轮的调查户将从2017年12月开始记帐。为确保圆满完成各项工作任务，现就有关事项通知如下：

一、高度重视，充分认识住户调查的重要意义

住户调查是反映城乡居民收入消费状况，监测居民收入分配格局和生活质量的一项重大统计调查。住户调查样本轮换是为了防止调查样本老化、保证样本代表性的必然需要，是确保住户调查数据质量的重要举措。全面、准确、真实的住户调查是各级党委政府科学决策、精准施策的重要依据，对精准扶贫、富民增收、反映“聚焦富民”工作成效等具有十分重要的意义。

二、明确责任，确保样本轮换工作的有序推进

为确保全市住户调查样本轮换工作的顺利进行，统计部门要严格按照国家和省统一制定的样本轮换方案和具体细则实施，依法依规组织开展样本轮换。发改委、公安局、民政局、财政局、人社局、住建局、规划局、卫计委等有关部门要密切配合，积极支持，依法协助做好调查摸底、开户及试记账等相关工作。各镇（区）要切实加强组织领导，明确分管领导和职能科室职责，督促各行政村（社区）及时聘请责任心强、工作认真负责的同志担任辅助调查员。抽中行政村（社区）要积极配合，落实人员，按照上级统计部门的统一部署，有条不紊地开展各项工作，确保调查工作有序推进。

三、密切配合，全力保障调查工作的顺利开展

一体化调查工作是一项系统的工程，需要各镇（区）、市各有关部门、行政村（社区）齐抓共管，协同配合，合力推进。住户调查及样本轮换的费用，按照分级负担的原则，将住户调查所需经费（包括会议培训费、辅助调查员调查补贴、调查户记账补贴和慰问费、调查样本轮换费等）列入当年的财政预算，记账户补贴确保每年略有增长并按时足额拨付到位。要加大宣传力度，扩大社会各界对住户调查的知晓度，提高调查对象的积极性和配合度，为住户调查样本轮换和日常工作的开展营造良好的氛围。
