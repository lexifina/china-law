# 市政府关于同意锦丰镇增设沙洲社区等3个社区居民委员会的批复

锦丰镇人民政府：

你镇《关于成立锦丰镇沙洲社区居民委员会、天福社区居民委员会和联兴社区居民委员会的请示》（锦政发﹝2017﹞12号）收悉。经研究，现批复如下：

一、根据市委、市政府《关于进一步加强城乡社区建设管理的意见》（张委发﹝2011﹞63号）等文件规定，同意你镇增设沙洲社区、天福社区、联兴社区3个社区居民委员会。

二、管辖范围

（1）沙洲社区居民委员会为：东至华昌路、南至书院路、西至清源路、北至兴联路。

（2）天福社区居民委员会为：东至杨锦公路、南至星火村五组、西至油车港、北至港丰公路。

（3）联兴社区居民委员会为：东至永新路、南至锦店路、西至杨锦公路、北至润忠路。

三、你镇要按《居民委员会组织法》等规定建好沙洲社区、天福社区、联兴社区居民委员会，并根据区域入住人员规模变化，及时强化人员配备，保障社区用房需要，落实社区建设管理经费，不断提升社区建设管理的内涵和水平。

此复。
