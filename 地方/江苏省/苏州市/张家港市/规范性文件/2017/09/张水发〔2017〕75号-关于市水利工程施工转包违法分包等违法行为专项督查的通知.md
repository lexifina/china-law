# 关于市水利工程施工转包违法分包等违法行为专项督查的通知

各有关单位：

为维护我市水利建设市场秩序，规范水利施工企业行为，保证工程质量和施工安全，决定开展我市水利工程施工转包分包等违法行为专项督查。现将有关情况通知如下：

一、督查范围

全市在建水利工程。

二、督查时间

2017年9月上、中旬。

三、督查小组

组 长：陈杏明 陶 雷

组 员：财务科、水政水资源科、监察室、水政大队、工管科、水建科、基建办相关人员。

四、督查方式

1、“四不两直”：即不发通知、不打招呼、不听汇报、不用陪同接待、直插企业、直插现场。

2、查阅相关施工资料。

3、询问相关人员并进行笔录。

五、督查重点内容

1、施工项目部管理机构人员组成。

2、工程《资金安全合同》执行情况。

3、分包合同，设备租赁、采购等合同及发票。

六、其他要求

1、请各有关单位于9月5日之前将在建工程（附件）及时提交局基建办。联系人：赵珂；联系电话：58186061。

2、请各有关单位通知在建工程施工项目部将材料准备齐全并存于现场。督查时项目部不能提供证明材料的，将被勒令停工整改，并作进一步处置。

3、对在督查中发现的转包、违法分包、出借借用资质等违法行为的，我局将依法进行调查，按照《水利工程施工转包违法分包等违法行为认定查处管理暂行办法》（水建管﹝2016﹞420号）进行认定，依据《招标投标法》《合同法》《建设工程质量管理条例》《招标投标法实施条例》等法律法规进行处罚，并将处罚情况上报上级水行政主管部门，列入失信黑名单。

特此通知。
