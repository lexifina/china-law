# 关于调整市科学技术局领导工作分工的通知

局机关各科室，生产力促进中心：

因人事变动，经局长办公会议研究，确定局领导、副主任科员分工如下：

黄祥亮：党组书记、局长，主持全面工作，分管党的建设、组织人事、科技规划、财务方面工作，联系保税区(金港镇)、高新技术产业开发区。

周晓成：党组副书记、副局长，负责科技人才、科技载体建设、科技金融、人才项目产业化方面的工作。协助党组书记负责党建党务工作。分管科技人才科、科技载体建设科，联系经济技术开发区(杨舍镇)、冶金工业园(锦丰镇)。

俞萍：党组成员、副局长，负责机关党建、市级科技计划、创新积分、绩效考核、科技宣传、精神文明建设、机关内部管理、信息化系统、工会、妇联等方面的工作。完成局党组交办工作。分管办公室，联系塘桥镇。

朱晨阳：党组成员、副局长，负责高新技术产业化、知识产权方面的工作，分管高新技术发展及产业化科、专利科，联系乐余镇、凤凰镇。

张天若：党组成员、副局长，负责政产学研合作、科技镇长团方面的工作，分管产学研合作科，联系南丰镇、大新镇。

孙东亮：副局长，负责农业科技和社会发展、可持续发展实验区、科技活动周筹备、科技统计、科技服务、技术市场、科技创新展示中心、创新创业梦工场方面的工作，分管农业与社会发展科、生产力促进中心，联系常阴沙现代农业示范园区。

陈晓芹：副主任科员，协助做好工会工作，参与高新技术发展及产业化科工作。

穆兰：副主任科员，协助做好党建相关工作。

特此通知。
