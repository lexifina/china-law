# 关于下达2017年度张家港市先进制造产业领跑重点项目计划（第二批）的通知

保税区企业服务管理局、经开区经济服务局、冶金园经济服务局凤凰经济发展和改革局、各镇经济服务中心、常阴沙现代农业示范园区管委会:

为进一步认真落实好市委“1+3”文件精神，我委围绕《张家港市先进制造产业领跑计划实施意见》工作要求，以“智能制造、结构调整、节能减排”为三大主攻方向，以超千万元技改项目为主要支撑，加快推进优势传统产业转型升级。现经镇(区)推荐申报，决定在2017年度第一批78个项目的基础上，再重点推进第二批60个先进制造产业领跑项目，其中:其中智能制造类项目43个、结构调整技改类项目11个、节能减排类项目6个。现将先进制造产业领跑重点项目计划(第二批)印发给你们，一是请各镇(区)对列入计划的项目，督促企业完善项目建设相关手续。二是进一步明确工作责任，强化项目服务保障，优化项目建设环境，及时协调解决项目建设中的困难和问题。三是实施月报制度，各镇(区)要及时跟踪重点项目进展情况，并于每月月报制度，各镇(区)要及时跟踪重点项目进展情况，并于每月28日前将项目进度情况通过政务网报市经信委。
