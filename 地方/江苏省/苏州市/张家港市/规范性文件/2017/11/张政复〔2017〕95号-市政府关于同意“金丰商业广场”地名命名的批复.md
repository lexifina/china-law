# 市政府关于同意“金丰商业广场”地名命名的批复

张政复〔2017〕95号

来源：市政府发布时间：2017-11-03 10:56:00访问量：字体【大中小】

金港镇人民政府：

你镇《关于“金丰商业广场”地名命名的请示》收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将你镇位于金港路东侧、镇山路南侧、金成小区西侧、金成小区北侧范围内的新建商业广场命名为“金丰商业广场”。地名标志汉语拼音拼写形式：JINFENG SHANGYEGUANGCHANG。“金丰商业广场”规划占地面积9710平方米、总建筑面积34000平方米，多层3幢。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2017年11月3日
