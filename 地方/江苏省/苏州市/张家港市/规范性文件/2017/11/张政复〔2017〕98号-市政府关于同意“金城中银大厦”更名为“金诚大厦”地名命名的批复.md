# 市政府关于同意“金城中银大厦”更名为“金诚大厦”地名命名的批复

张政复〔2017〕98号

来源：市政府发布时间：2017-11-24 17:10:00访问量：字体【大中小】

杨舍镇人民政府：

你镇《关于“金城中银大厦”更名的请示》杨政发〔2017〕49号，收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将你镇“金城中银大厦”（系标准地名，地名批复文号：张政复〔2013〕36号），地名标志汉语拼音拼写形式：JINCHENGZHONGYIN DASHA，位于港城大道东侧、人民中路南侧、纪澄河西侧、通运路北侧更名为“金诚大厦”。“金诚大厦”占地面积10093平方米，总建筑面积59878平方米，高层1幢。地名标志汉语拼音拼写形式：JINCHENGDASHA。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2017年11月24日
