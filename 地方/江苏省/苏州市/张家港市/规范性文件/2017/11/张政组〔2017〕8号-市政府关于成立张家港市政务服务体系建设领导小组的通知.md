# 市政府关于成立张家港市政务服务体系建设领导小组的通知

张政组〔2017〕8号

来源：市政府发布时间：2017-11-30 14:24:00访问量：字体【大中小】

各镇政府，冶金工业园、常阴沙现代农业示范园区、双山岛旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：
