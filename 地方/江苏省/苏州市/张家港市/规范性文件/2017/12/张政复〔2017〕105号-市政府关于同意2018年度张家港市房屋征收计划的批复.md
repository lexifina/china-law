# 市政府关于同意2018年度张家港市房屋征收计划的批复

张政复〔2017〕105号

来源：市政府发布时间：2017-12-07 15:32:00访问量：字体【大中小】

市住房和城乡建设局：

你局《关于批准2018年度张家港市房屋征收计划的请示》收悉。现批复如下：

一、2018年度张家港市房屋征收计划涉及项目9个，共53户、27750平方米（详见附件），同意将上述9个项目纳入市政府《关于2017年国民经济和社会发展计划执行情况与2018年国民经济和社会发展计划》报告，并提请市十四届人大二次会议审议。

二、要严格按照国务院《国有土地上房屋征收与补偿条例》和《张家港市国有土地上房屋征收与补偿暂行办法》有关规定，规范有序推进房屋征收工作，全力保障被征收人的合法权益。

此复。

附件：《2018年度张家港市房屋征收计划表》

张家港市人民政府
