# 市政府关于同意“胡同路”道路命名的批复

塘桥镇人民政府：

你镇《关于“胡同路”命名的请示》悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将位于南起塘桥镇南环路、北至华芳路的道路命名为“胡同路”；

地名标志汉语拼音拼写形式：HUTONG LU。

接批复后，请及时与当地公安及有关部门联系，按照《地名 标志》（GB17733—2008）国家标准制作、设置道路标志牌、门号牌及桥梁标志牌。

此复。

张家港市人民政府

2017年12月21日
