# 市政府关于同意杨舍镇范围内两条道路命名的批复

张政复〔2017〕109号

来源：市政府发布时间：2017-12-21 17:38:00访问量：字体【大中小】

杨舍镇人民政府：

你镇《关于杨舍镇范围内两条道路命名的请示》收悉。经研究，同意对你镇申报的2条新建道路予以命名。具体批复如下：

1.同意将位于跃进河西侧，南起长兴路、北至北二环路的道路命名为“范泾路”；

地名标志汉语拼音拼写形式：FANJING LU。

2.同意将位于南起章卿村村民委员会，北至张杨公路的道路命名为“新闸路”；

地名标志汉语拼音拼写形式：XINZHA LU。

接批复后，请你们及时与当地公安及有关部门联系，按照《地名 标志》（GB17733—2008）国家标准制作、设置道路标志牌、门号牌及桥梁标志牌。

此复。

张家港市人民政府

2017年12月21日
