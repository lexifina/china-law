# 教育局关于公布2017年张家港市级骨干教师复评结果的通知

各镇（区）教卫文体办公室（综合办）,各中小学、幼儿园,各直属单位：

按照《教育局关于做好2017年张家港市级骨干教师复评考核工作的通知》（张教〔2017〕124号）要求，今年对进入复评期的张家港市学科教改（德育、学术）带头人、教学（德育）能手、教坛（德育）新秀的骨干教师进行了复评。现将复评考核结果予以公布（见附件）。

希望各校、各单位进一步贯彻落实《教育局关于进一步推动教师队伍专业发展的指导意见》（张教〔2015〕1号）精神，牢固树立“教师是教育改革和教育质量提升的根本力量”的思想，积极创新机制，采取有效措施，不断提升教师专业发展水平，为我市教育高位优质均衡发展提供坚强的人才支撑。

希望全体教师进一步明确专业发展方向，确立发展目标，主动追求，积极作为，在专业发展道路上不断攀登，早日成长为有情怀、有思想、有智慧的教育家型优秀教师。

附件：2017年张家港市级骨干教师复评考核结果

张家港市教育局
