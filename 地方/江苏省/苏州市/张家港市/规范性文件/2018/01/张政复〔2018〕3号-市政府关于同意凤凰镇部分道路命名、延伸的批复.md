# 市政府关于同意凤凰镇部分道路命名、延伸的批复

凤凰镇人民政府：

你镇《关于凤凰镇部分道路命名、延伸的请示》收悉。经研究，同意对你镇申报的2条新建道路、2条道路延伸予以命名。具体批复如下：

一、新建道路（2条）

1.同意将位于凤凰湖西侧，南起凤恬路、北至凤凰大道的道路命名为“望山路”；

地名标志汉语拼音拼写形式：WANGSHAN LU。

2.同意将位于金谷路西侧，南起望湖路、北至映山路的道路命名为“润祥路”；

地名标志汉语拼音拼写形式：RUNXIANG LU。

二、道路延伸（2条）

1.同意将原“汉江路”南起凤凰大道、北至长江路向南延伸至“凤凰路”，延伸后的“汉江路”南起凤凰路，北至长江路；

地名标志汉语拼音拼写形式：HANJIANG LU。

2. 同意将原“中山路”南起凤凰大道、北至嘉泰路向南延伸至“凤恬路”，延伸后的“凤恬路”南起凤恬路，北至嘉泰路；

地名标志汉语拼音拼写形式：ZHONGSHAN LU。

接批复后，请你们及时与当地公安及有关部门联系，按照《地名 标志》（GB17733—2008）国家标准制作、设置道路标志牌、门号牌。

此复。

张家港市人民政府

2018年1月16日
