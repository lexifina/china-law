# 市政府关于同意“文教路”道路命名的批复

南丰镇人民政府：

你镇《关于“文教路”道路命名的请示》收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将对你镇位于永祥园（拟命名）以南，南起永联路，北至钢村路的道路命名为“文教路”。

地名标志汉语拼音拼写形式：WENJIAO LU。

接批复后，请你们及时与当地公安及有关部门联系，按照《地名 标志》（GB17733—2008）国家标准制作、设置道路标志牌、门号牌。

此复。

张家港市人民政府 2018年2月23日
