# 市政府关于同意金港镇福民村村庄规划的批复

金港镇政府：

你镇上报的《关于报批<金港镇福民村村庄规划>的请示》收悉。经研究，现批复如下：

一、原则同意你镇上报的《金港镇福民村村庄规划》。规划范围为金港镇福民村村域范围，规划面积521.66公顷。

二、要加强与金港片区总体规划、土地利用总体规划等规划的衔接，坚持保护耕地、集约利用土地，提高土地利用效率；要从农村实际出发，尊重村民意愿，体现地方和农村特色，优化村庄生产、生活环境，提高村庄发展和建设整体水平。

三、经市政府批准的《金港镇福民村村庄规划》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府 2018年2月23日
