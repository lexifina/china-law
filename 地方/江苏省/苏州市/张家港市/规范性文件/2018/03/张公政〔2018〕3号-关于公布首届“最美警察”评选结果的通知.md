# 关于公布首届“最美警察”评选结果的通知

各警署、各派出所、直属各单位、机关各部门：

2017年以来，全市公安机关牢记习近平总书记“四句话、十六字”总要求，忠诚履职、真抓实干，打赢了党的十九大安保维稳“一场硬仗”，推动了立体化信息化治安防控体系和公安党建“两个升级”，实现了治安掌控能力、公安综合绩效、队伍能力素质“三大提升”，高标准完成了市委市政府和全市人民交给的各项任务，谱写了人民公安忠于党、人民公安为人民的时代赞歌。

为充分发挥先进典型的示范效应，展现新时代港城公安民警大爱至伟、守护正义的“最美”风采，营造学习先进、争当先进的浓厚氛围，市局在全市公安机关组织开展了首届“最美警察”评选活动，经各单位民主推荐、相关部门初审初评、网上公示、内外网宣传投票等程序，市局党委决定：
