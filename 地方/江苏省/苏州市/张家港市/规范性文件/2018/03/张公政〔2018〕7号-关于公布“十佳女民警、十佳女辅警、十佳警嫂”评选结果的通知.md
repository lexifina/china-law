# 关于公布“十佳女民警、十佳女辅警、十佳警嫂”评选结果的通知

各警署、各派出所、直属各单位、机关各部门：

2017年以来，我局广大女民警、女辅警立足本职、积极作为，在服务公安中心工作、推动张家港公安创新发展中做出了突出贡献；广大警嫂顾全大局、无私奉献，为民警解除后顾之忧，给予了公安工作极大的支持。

为了充分发挥先进典型的示范效应，市局组织开展了“2017年度张家港市公安局十佳女民警、十佳女辅警、十佳警嫂”评选活动，经各单位民主推荐、相关部门初审初评等程序，市局党委决定：
