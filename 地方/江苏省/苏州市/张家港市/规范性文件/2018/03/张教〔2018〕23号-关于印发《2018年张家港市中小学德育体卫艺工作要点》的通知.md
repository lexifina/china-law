# 关于印发《2018年张家港市中小学德育体卫艺工作要点》的通知

各中小学：

现将《2018年张家港市中小学德育体卫艺工作要点》印发给你们，请学校认真组织学习，结合工作实际，扎实推进各项工作。

张家港市教育局

2018年3月6日

（此文件主动公开）

2018年张家港市中小学德育体卫艺工作要点

2018年全市中小学德育体卫艺工作的总体要求是：全面贯彻党的十九大精神，以习近平新时代中国特色社会主义思想为指导，以建办优质教育为总体目标，以立德树人为根本任务，以推进“三聚两先”为工作动力，积极进取，开拓创新，不断提升工作质量和管理水平，努力开创全市中小学德育体卫艺各项工作新局面。

一、坚持以德育为先，全面提高德育工作实效

2018年，全市中小学德育工作要全面贯彻教育部《中小学德育工作指南》和教育局新学年“三聚两先”工作要求，立足社会主义核心价值观教育，积极探索培育和践行社会主义核心价值观的有效途径与方法；深入实施中小学品格提升工程和校园引领文明工程，推进文明校园建设；聚焦学生核心素养，丰富德育课程及活动体系；鼓励学校德育工作多样化、个性化和创新化发展，组织开展学校德育共同体建设、德育整体展示、德育特色学校认定等活动；建立和完善系统化育人机制，实现德育工作与党建、课程建设、校园文化、群团等工作融合，努力推进学校教育、家庭教育和校外教育的全方位融合发展，全面提升我市中小学生的思想道德素质。在夯实学校德育工作基础上，继续推进和深化好习惯养成教育、心理健康教育、家庭教育、德育队伍建设、共青团建设等重点工作，努力抓落实、求实效、出成果。

1.平台化抓好德育队伍建设。加强德育队伍建设，打造一支以班主任为主体、以学科教师为支撑的“1+x”德育队伍，努力形成全员育人的良好氛围。组建市级德育讲师团，充分发挥德育名师对全市的示范引领作用。举办德育工作论坛，组织德育校长、德育主任和班主任就学校德育工作话题开展主题式交流。重点落实好《学校班主任工作室建设与管理办法（2017～2019）》，真正把加快青年班主任成长落到实处。组织开展第11届班主任基本功竞赛，力争在苏州市级班主任基本功竞赛中再创佳绩。大力加强学科德育队伍建设，充分挖掘和整合学科德育课程资源，强化学科课程活动中的德育渗透，推行学生成长导师制，开展学科德育工作研讨和学科德育优秀案例评选等活动，真正把立德树人、全员育人的理念和要求落到实处、取得成效。

2.专题化推动好习惯养成教育实践。全面落实教育局《关于进一步推进“5+x”好习惯养成教育的指导意见》，加强好习惯养成教育的顶层设计和过程实施，切实将好习惯教育贯穿于小学、初中、高中全学段全过程并取得明显实效，今年要突出三个专题：即好习惯养成教育课程资源开发、好习惯养成教育评价模式构建、好习惯养成教育实施队伍建设，开展专题化的深度研究和交流展示，形成特色经验和德育品牌。着力营造好习惯养成教育氛围，举办教师好习惯随手拍摄影作品、学生好习惯个人微视频、家长好习惯微课堂系列评比等活动。

3.区域化推进家庭教育工作。全面贯彻教育部《关于加强家庭教育工作的指导意见》，落实《张家港市深化家庭教育工作实施意见》，全方位拓展家庭教育实施途径，创新家庭教育方式方法，调动并整合学校、相关单位和社会组织等多方力量，全面提升我市家庭教育水平。依托张家港市家庭教育服务中心，以家教指导专业化、家教知识课程化、家教培训阵地化、家教评价标准化为导向，有效落实家长在家庭教育中的主体责任，充分发挥学校在家庭教育中的引领作用，积极整合社会在家庭教育中的支持功能。全面实施家庭教育队伍建设、课程体系开发、培训咨询体系建设和评价标准建设四大工程，努力实现“家长尽职称职、孩子健康成长、家庭文明和谐”的家庭教育工作总目标，把家庭教育打造成为全市深化未成年人思想道德建设的新品牌和精神文明建设的新亮点。完善学校三级家委会，创新家校共建共育方式，积极开展“行走的父母成长课堂”、“心树林家育、心育沙龙”、“与心灵相约与幸福同行”家教咨询、“幸福家长驿站”等家庭教育品牌活动。组织参加苏州市中小学家庭教育课程项目集中培训与研讨活动，定期开展家庭教育论坛等活动，年内举办苏州市级家庭教育工作成果展示会。

4.过程化提升心理健康教育实效。认真贯彻苏州市教育局《关于全面加强学生心理教育的若干意见》，切实抓好“两个”落实：一是落实新一轮心理健康教育师资培训，通过进阶培训、资质培训、骨干培训，全力提升学校心理辅导水平；二是落实三类心理健康教育校本课程，即通式普惠课程、主题讲座课程、特殊需要课程，确保半数以上学校开足开好课程，取得明显成效。加强班级心理观察员学习培训、学校心理辅导室必备档案资料规范管理和学校心理辅导室实地抽查等工作，完善中小学生心理健康预警和监护网络。依托市未成年人健康成长指导中心（市家庭教育服务中心）和市心理健康教育中心教研组，定期开展中小学心理健康教育教学研讨活动，提高全市中小学心理健康教育教学质量。组织参加苏州市中小学心理健康教育优质课评比、心理健康教育名师工作室评选和心理健康教育特色学校评选等活动，进一步提升全市中小学心理健康教育水平，促进广大中小学生健康成长。

5.多样化建设学生成长平台。打造中小学社会实践活动、社团活动和志愿者活动三大学生成长平台，组织学生积极参加各类社会实践活动、社团活动、志愿者活动和研学旅行等丰富多彩的校内外活动。开展张家港市和苏州市优秀校园志愿服务项目、优秀校园志愿服务管理员、年度十佳中小学生社团、社团建设先进学校等相关评选展示活动，更好地实现让学生融入自然、关注社会、提升自我的育人目标。建设政府主导、各方参与、多元联动的社会教育支持格局，加快形成社会教育支持网络，构建全方位、全天候育人的社会教育支持体系，为广大青少年的健康成长和全面发展搭建多样平台。积极实施教育局与文广新局签订的全面战略合作协议，有效整合文化教育资源，大力开展中华传统文化教育，实现以文化人、以美育人。

6.项目化夯实学校共青团工作。年初制定下发《关于进一步加强全市教育系统共青团工作的实施意见》，举办中小学、幼儿园团组织书记培训班，定期开展共青团工作交流和研讨活动。开展学习型团组织建设，围绕青年教师综合素养提升项目，开展教育信息技术、教学基本功竞赛等系列活动。推动团组织服务职能转变，围绕“伴你共成长”志愿服务项目，开展团组织“志愿者+教育”品牌行动。提升团组织感召力，围绕团市委“青字号”工程，开展中学中职团组织年度项目申报评选活动，推进中学中职共青团“361工作体系”建设。

7.系列化完善德育管理机制。统筹安排好全年中小学校德育共同体建设、常态调研、整体展示和特色认定等活动，推动中小学校德育工作的实践探索和创新发展。一是围绕重点工作，由学校自主申报，组建一批德育研究共同体，申报相关课题，开展协同研究，实现共同发展。二是对学校的德育工作开展常规调研，了解学校在常态下如何搞好学校环境建设、育人氛围营造、学生养成教育、德育活动开展、重点项目推进、特色品牌打造等工作，促进学校德育工作规范实施、有效开展。三是定期组织开展学校德育工作整体展示，充分展现学校德育工作的做法、经验和成果，发挥对全市学校的示范引领作用。四是进行每2年一次的德育特色学校认定工作，引导各校围绕德育重点工作进行个性化、校本化的探索与创新，打造德育品牌，形成办学特色，以特色品牌引领学校的整体发展。2018年7月市教育局将认定一批市级德育特色学校。

二、坚持以素质为本，努力促进学生全面发展

2018年，全市各中小学要进一步推动体育、艺术、卫生与健康教育的改革与发展，加强学校内涵建设和特色办学，提升教育现代化水平，实现教育优质均衡发展。围绕国家、省、市关于学校体卫艺工作要求，继续大力开展丰富多彩的学校体卫艺活动，丰富学生校园生活，促进学生综合素质的全面提升。

1.扎实开展“阳光体育”拓展行动。一是深入推进“体教结合”，广泛开展“阳光体育”活动，以“三大球”联赛为杠杆，进一步推动学校体育改革，在校园内形成青少年热爱体育、崇尚运动的浓厚氛围。二是加快推进校园足球运动的普及和提高，加强对校园足球工作的督导，举办张家港市首届青少年校园足球文化节系列活动，力争承办2018年江苏省青少年校园足球现场推进会，完善校园足球特殊人才入学升学扶持政策，加大足球教练员和裁判员的培训力度，进一步提升全国青少年校园足球试点县的整体工作水平。协助做好第二十一届全国“贝贝杯”U12青少年足球赛和“贝贝杯”U14青少年室内五人制足球赛组织工作，不断提升“贝贝杯”品牌的知名度和影响力。三是做好全国青少年校园篮球特色学校创建工作，发掘和培育乒乓球、手球、网球、武术、桌式足球等特色体育项目，营造特色体育运动的良好氛围，全面提升学校体育运动水平。四是组织初三体育中考、学生体质健康测试以及中小学生秋季田径运动会等常规体育比赛活动。

2.全面推进美育普及行动。一是切实加强学校艺术教育管理工作，认真贯彻落实《学校艺术教育工作规程》及《评估方案(试行)》的要求，积极推进艺术类课程建设，深化艺术教学改革，探索学生艺术素质测评方法，全面提高学生的审美素质和能力。二是组织张家港市第三届中小学生艺术节各项比赛活动，在项目选择、规则制定和奖项设置等方面作优化调整，以便推出更多优秀作品和优秀人才参加苏州市第三届艺术节的各项比赛。重点打造并确保已经通过苏州市节目复选的三个节目能在2018年省级比赛中脱颖而出，顺利参加2019年在苏州市举行的全国第六届中小学生艺术节。三是举办2018年张家港市第二届美术教师美术作品双年展、第六届“百名小书法家、百名小画家”评选、千名小画家同绘港城绘画、2所美术特色学校参加苏州市教育局“金色大厅”作品展等活动，努力为学校美术教育的百花齐放和师生的全面发展搭建平台。四是加快推动艺术教师的专业成长，邀请专家分专业、分阶段、分兴趣组织艺术老师培训，让每一位艺术教师至少在一项专业技能和创作上有所特长。

3.不断深化学校健康教育行动。一是认真贯彻执行《学校卫生工作条例》，进一步加强学校卫生工作，改善学校卫生环境、教学卫生条件和食品安全设施，营造健康、卫生、文明的校园环境。二是组织学校相关人员对食堂食品卫生“五常法”管理的再学习、再提高，并常态化运用到实际管理和操作中去。会同市场监管等部门增加双随机抽测，加大通报和处罚力度，强化责任追溯制度，有效杜绝隐患发生。三是探索学校与专业医疗机构合作共建的可行性研究，加大校医和保健医生的专业培训力度，重点落实学校传染性疾病的发现、处置和防控措施。四是进一步加大健康促进学校的创建力度，尤其要扩大金牌学校的创建比例，梳理还未创建铜牌的学校，确保2018年度创建完成。五是做好学校红十字会、垃圾强制分类等有关工作。

4.科学指导国防教育统一行动。2018年，我们将改变以往高中军训“各自为政”的做法，实现军训管理的规范化、军训课程的标准化和教官安排的统一化。通过人武部、部队、军事院校等组织一支素质过硬、作风优良的军训教官队伍，研发一套标准化的军训活动课程，切实解决学校军训工作的后顾之忧，不断提升学校军事训练和国防教育成效与质量。
