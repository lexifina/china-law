# 关于印发《张家港市市级行政事业单位通用办公设备和办公家具配置标准》的通知

张财资[2018]3号

各有关单位：

根据《中央行政单位通用办公设备家具配置标准》（财资〔2016〕27号）、《江苏省省级行政事业单位通用办公设备和办公家具配置标准》（苏财规〔2017〕17号）的要求和资产配置标准动态管理的原则，市财政局和市级机关事务管理中心结合我市社会经济发展水平、市场价格变化等因素，制订了《张家港市市级行政事业单位通用办公设备和办公家具配置标准》（以下简称《标准》），现印发给你们，请遵照执行。
