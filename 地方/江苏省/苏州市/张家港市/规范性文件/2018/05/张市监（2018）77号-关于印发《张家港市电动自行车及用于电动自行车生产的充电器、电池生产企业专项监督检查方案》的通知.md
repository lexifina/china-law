# 关于印发《张家港市电动自行车及用于电动自行车生产的充电器、电池生产企业专项监督检查方案》的通知

各科(室)、分局、大队、协会:

近期，与电动自行车相关的交通、消防伤亡事故频发，市委、市政府高度重视，为进一步加强电动自行车及用于电动自行车生产的充电器、电池产品质量监管，督促企业落实质量安全主体责任，严厉打击假冒伪劣违法行为，根据苏州市政府《市政府办公室关于印发全市“331”整治火灾隐患百日专项行动方案的通知》(苏府办[2018]122号)及苏州市质监局《关于开展全市电动自行车及用于电动自行车生产的充电器、电池生产企业专项监督检查工作的通知》(苏质技监稽发[2018]号)要求，我局制订了《张家港市电动自行车及用于电动自行车生产的充电器、电池生产企业专项监督检查方案》，请遵照执行

张家港市市场监督管理局

2018年5月23日

(此件公开发布)

张家港市电动自行车及用于电动自行车生产的充电器、电池生产企业专项监督检查方案

近期，与电动自行车相关的交通、消防伤亡事故频发，市委、市政府高度重视，为进一步加强电动自行车及用于电动自行车生产的充电器、电池产品质量监管，督促企业落实质量安全主体责任，严厉打击假冒伪劣违法行为，根据苏州市政府《市政府办公室关于印发全市“331”整治火灾隐患百日专项行动方案的通知》(苏府办[2018]122号)及苏州市质监局《关于开展全市电动自行车及用于电动自行车生产的充电器、电池生产企业专项监督检查工作的通知》(苏质技监稽发[2018]号)要求，决定自即日起开展电动自行车及用于电动自行车生产的充电器、电池(蓄电池、锂离子电池和原电池)生产企业专项监督检查，具体工作方案如下:

一、检查范围

电动自行车及用于电动自行车生产的充电器、电池(蓄电池、锂离子电池和原电池)生产企业。

二、检查时间

即日起至6月10日。

三、检查要求

1.摸清底数。由各分局对辖区电动自行车及用于电动自行车生产的充电器、电池(蓄电池、锂离子电池和原电池)生产企业进行全面的排摸，建立生产企业信息库。对电动自行车生产企业，与现有生产许可证企业信息库比对，对已掌握企业更新信息，未掌握企业立即补充进入信息库。

2.现场检查。

一是对电动自行车生产企业在严格按照生产许可证证后监管要求实施证后监管的基础上，重点检查是否严格按照标准组织生产;是否存在假冒伪劣、无证生产等违法行为;是否存在安全隐患并重点关注配套电池、充电器重要原材料。现场监督检查情况，及时输入许可证监管信息系统。对发现的问题，要督促整改并进行现场核对。

二是对用于电动自行车生产的充电器、电池(蓄电池、锂离子电池和原电池)生产企业重点检查企业是否严格按照标准组织生产，是否存在安全隐患，全面实施整治。

三是对整治工作中发现的问题立即严格依法处理;对假冒伪劣、无证生产等违法行为依法查处，严厉打击;对不再生产电动自行车的生产企业，满足办理注销手续的企业督促办理注销手续。

3.信息报送。即日起，每天上报电动自行车及用于电动自行车生产的充电器、电池(蓄电池、锂离子电池和原电池)生产企业专项监督检查情况汇总表(见附件)，每周五上报周工作小结至市局产品质量监管科。专项行动结束后3日内，报送专项检查工作总结，有严重违法行为的，随时报送。
