# 市政府关于2017年度张家港市和谐劳动关系示范企业的通报

各镇政府，冶金工业园、常阴沙现代农业示范园区、双山岛旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：

2017年，在市委、市政府的正确领导下，市协调劳动关系三方委员会认真落实《关于在全市深入开展争创“劳动关系和谐企业”活动的实施意见》（张委办〔2010〕25号）精神，积极推动我市劳动关系和谐企业构建工作，在促进企业稳定发展、维护职工合法权益等方面发挥了积极作用，全市涌现出一批成效突出的先进典型。

为弘扬榜样力量，强化示范引领，扎实推进我市省级和谐劳动关系综合试验区建设工作，进一步促进全市和谐劳动关系构建，经推荐、审核，并报市政府同意，确定江苏金陵体育器材股份有限公司等10家企业为“2017年度张家港市和谐劳动关系示范企业”，现予以通报（名单附后）。

希望受通报的企业发扬成绩，珍惜荣誉，立足新起点，再创新佳绩，更好地发挥示范带动作用。全市广大企业要以受通报的企业为榜样，进一步解放思想，积极实践，扎实构建和谐劳动关系，为推动我市经济社会高质量发展作出新的更大贡献！

附件：2017年度张家港市和谐劳动关系示范企业名单

张家港市人民政府
