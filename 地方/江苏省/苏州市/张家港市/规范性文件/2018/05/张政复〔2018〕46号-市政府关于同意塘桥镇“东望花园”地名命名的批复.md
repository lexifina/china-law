# 市政府关于同意塘桥镇“东望花园”地名命名的批复

张政复〔2018〕46号

来源：市政府发布时间：2018-05-04 12:02:00访问量：字体【大中小】

塘桥镇人民政府：

你镇《关于“东望花园”地名命名的请示》（塘政发〔2018〕22号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将你镇位于浏泾塘东侧、富民路南侧、维达路西侧、新风河北侧范围内的新建住宅小区命名为“东望花园”。地名标志汉语拼音拼写形式：DONGWANG HUAYUAN。“东望花园”规划占地面积27484平方米、总建筑面积63533平方米，多层8幢、高层2幢，共443户（套），绿化率为35%。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好楼幢号牌、单元牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府 2018年5月4日
