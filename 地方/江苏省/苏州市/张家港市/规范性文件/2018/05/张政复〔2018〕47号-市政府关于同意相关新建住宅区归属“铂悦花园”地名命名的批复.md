# 市政府关于同意相关新建住宅区归属“铂悦花园”地名命名的批复

杨舍镇人民政府：

你镇《关于新建住宅小区归属“铂悦花园”的请示》（杨政请〔2018〕8号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将你镇位于东方新天地东侧、老宅基路南侧、南湖路西侧、勤星路北侧范围内的新建住宅小区归属为“铂悦花园”二期，沿用地名为“铂悦花园”。地名标志汉语拼音拼写形式：BOYUE HUAYUAN。“铂悦花园”二期规划占地面积17204平方米、总建筑面积52000平方米，高层住宅2幢、商业楼1幢、幼儿园1幢，共96户（套）。“铂悦花园”二期归属后，“铂悦花园”位于白子港路东侧、老宅基路南侧、南湖路西侧、棋杆路北侧范围内，规划占地面积128230平方米、总建筑面积417000平方米，多层住宅22幢、高层住宅16幢、商业楼1幢、幼儿园1幢，共2351户（套），绿化率35%。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好楼幢号牌、单元牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府 2018年5月4日
