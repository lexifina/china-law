# 市政府关于同意杨舍镇“熙悦花园”地名命名的批复

张政复〔2018〕49号

来源：市政府发布时间：2018-05-04 11:54:00访问量：字体【大中小】

杨舍镇人民政府：

你镇《关于“熙悦花园”地名命名的请示》（杨政请〔2018〕11号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将你镇位于星河湾东侧、东横河南侧、市公安消防大队城西中队西侧、泗杨路北侧范围内的新建住宅小区命名为“熙悦花园”。地名标志汉语拼音拼写形式：XIYUE HUAYUAN。“熙悦花园”规划占地面积67263平方米、总建筑面积210000平方米，多层住宅16幢、高层住宅7幢、商业服务楼2幢，共1066户（套），绿化率为36%。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好楼幢号牌、单元牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府 2018年5月4日
