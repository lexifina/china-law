# 市政府关于同意金港镇“香山麓院”地名命名的批复

张政复〔2018〕50号

来源：市政府发布时间：2018-05-10 10:53:00访问量：字体【大中小】

金港镇人民政府：

你镇《关于“香山麓院”地名命名的请示》（金政请〔2018〕1号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将你镇位于博翠名邸（规划空地暂定名）东侧、南横泾河南侧、江海南路西侧、香南西路北侧范围内的新建住宅小区命名为“香山麓院”。地名标志汉语拼音拼写形式：XIANGSHAN LUYUAN。“香山麓院”规划占地面积39098平方米、总建筑面积58084平方米，多层20幢，共234户（套），绿化率为40%。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好楼幢号牌、单元牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府 2018年5月10日
