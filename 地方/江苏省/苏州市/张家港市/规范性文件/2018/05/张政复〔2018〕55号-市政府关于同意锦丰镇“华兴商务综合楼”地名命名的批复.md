# 市政府关于同意锦丰镇“华兴商务综合楼”地名命名的批复

张政复〔2018〕55号

来源：市政府发布时间：2018-05-11 16:46:00访问量：字体【大中小】

锦丰镇人民政府：

你镇《关于“华兴商务综合楼”地名命名的请示》（锦政发〔2018〕12号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将你镇位于健康新村东侧门面房东侧、合兴花苑南侧、杨锦公路西侧门面房西侧、华山路北侧范围内的新建商务楼命名为“华兴商务综合楼”。地名标志汉语拼音拼写形式：HUAXING SHANGWUZONGHELOU。“华兴商务综合楼”规划占地面积7700平方米、总建筑面积3843平方米，1幢5层，绿化率为10%。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府 2018年5月11日
