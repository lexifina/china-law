# 市政府关于同意相关新建住宅区归属“联峰雅园”地名命名的批复

南丰镇人民政府：

你镇《关于将新建住宅小区归属“联峰雅园”的请示》（南政请〔2018〕6号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将你镇位于南丰阳光花苑东侧、新民西路南侧的空地南侧、育才北路西侧、南丰东路北侧的民房北侧范围内的新建住宅小区归属为“联峰雅园”三期，沿用地名为“联峰雅园”。地名标志汉语拼音拼写形式：LIANFENG YAYUAN。“联峰雅园”三期规划占地面积12400平方米、总建筑面积28700平方米，小高层6幢，共144户（套）。“联峰雅园”三期归属后，“联峰雅园”分为两个区域：一期、二期位于育才北路东侧、新民西路南侧的空地南侧、振兴北路西侧、南丰东路北侧，三期位于南丰阳光花苑东侧、新民西路南侧的空地南侧、育才北路西侧、南丰东路北侧的民房北侧。规划占地面积34772平方米、总建筑面积128700平方米，小高层15幢、高层3幢，共754户（套），绿化率35%。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好楼幢号牌、单元牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2018年5月25日
