# 市政府关于同意凤凰镇“朗樾名邸”地名命名的批复

张政复〔2018〕58号

来源：市政府发布时间：2018-05-25 17:10:00访问量：字体【大中小】

凤凰镇人民政府：

你镇《关于张家港市凤凰镇“朗樾名邸”地名命名的请示》（凤政发〔2018〕37号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将你镇位于朗润花园东侧、凤凰大道南侧、金谷路西侧、映山路北侧范围内的新建住宅小区命名为“朗樾名邸”。地名标志汉语拼音拼写形式：LANGYUE MINGDI。“朗樾名邸”规划占地面积64292平方米、总建筑面积142619平方米，多层13幢、高层4幢，共866户（套），绿化率为30%。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好楼幢号牌、单元牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府 2018年5月25日
