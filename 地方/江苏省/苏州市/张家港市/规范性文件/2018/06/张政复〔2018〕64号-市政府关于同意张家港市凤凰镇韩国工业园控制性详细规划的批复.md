# 市政府关于同意张家港市凤凰镇韩国工业园控制性详细规划的批复

凤凰镇政府：

你镇上报的《关于报批<张家港市凤凰镇凤凰山地块控制性详细规划>和<张家港市凤凰镇韩国工业园控制性详细规划>的请示》（凤政发〔2018〕39号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《张家港市凤凰镇韩国工业园控制性详细规划》。规划范围为东至汉江路、飞翔路、苏虞张公路，南至凤恬路、映山路、凤凰大道，西至魏庄路，北至长江路，规划面积406.59公顷。

二、要加强与城市总体规划、土地利用规划、凤凰镇总体规划等相关规划的有机衔接、融合，协调处理好规划区域与周边区域的关系，保障土地科学、合理与集约利用。

三、经市政府批准的《张家港市凤凰镇韩国工业园控制性详细规划》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府 2018年6月12日
