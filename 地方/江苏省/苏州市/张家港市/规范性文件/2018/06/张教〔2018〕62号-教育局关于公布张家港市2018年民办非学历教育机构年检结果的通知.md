# 教育局关于公布张家港市2018年民办非学历教育机构年检结果的通知

各民办非学历教育机构：

为依法实施对民办非学历教育机构的监督管理，促进我市民办教育事业健康发展，根据《中华人民共和国民办教育促进法》、《江苏省民办非学历教育机构设置和管理办法（修订）》等法律法规及规范性文件要求，市教育局对全市民办非学历教育机构进行了年度检查，根据材料审核和现场抽查情况，依法认定年检结论。现将结果公示如下：

一、依法注销（含自行申请注销）办学资格单位名单

1.张家港市圣乔治教育培训中心

2.张家港市启潜教育培训中心

3.张家港市海澜教育培训中心

4.张家港市恒星教育培训中心

5.张家港市安艾艾迪软件和服务外包培训中心

6.张家港市优博特教育培训学校大成广场教学点

依法注销的民办非学历教育机构，自注销之日起，立即停止办学活动，并妥善处理好学员的善后工作。

二、年检合格单位名单

认定张家港市经贸职业学校等157家（含新审批）民办非学历教育机构年检合格（具体名单见附件）。

根据相关法律法规要求，将以上机构通过张家港市教育信息化公共服务平台（http://www.zjgedu.cn）向社会公示，接受监督。

希望各民办非学历教育机构，进一步改善办学条件，强化服务意识，规范办学行为，坚持诚信办学，不断提高办学质量和整体效益，为满足居民多样化学习的需要、建设学习型社会作出应有的贡献。

希望全市各级各类学校、社会团体，积极通过有效方式方法，教育引导学生或家长：要理性看待校外培训，不要盲目跟风和加重学生课外负担；要谨慎选择培训机构，自觉抵制无证机构和强化应试等违规培训，保证未成年人快乐健康地成长成才。
