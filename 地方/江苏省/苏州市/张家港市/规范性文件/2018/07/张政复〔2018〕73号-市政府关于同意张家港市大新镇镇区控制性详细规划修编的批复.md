# 市政府关于同意张家港市大新镇镇区控制性详细规划修编的批复

张政复〔2018〕73号

来源：市政府发布时间：2018-07-20 17:35:00访问量：字体【大中小】

大新镇政府：

你镇上报的《关于报批〈张家港市大新镇镇区控制性详细规划修编〉的请示》（大政发〔2018〕25号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《张家港市大新镇镇区控制性详细规划修编》。规划范围为东至港城大道、南至港丰公路、西至朝东圩港、北至沿江公路，规划面积746.41公顷。

二、要加强与城市总体规划、土地利用规划、大新镇总体规划等相关规划的有机衔接、融合，协调处理好规划区域与周边区域的关系，统筹安排基础设施和公共服务设施建设，保障土地科学、合理与集约利用。

三、经市政府批准的《张家港市大新镇镇区控制性详细规划修编》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2018年7月20日
