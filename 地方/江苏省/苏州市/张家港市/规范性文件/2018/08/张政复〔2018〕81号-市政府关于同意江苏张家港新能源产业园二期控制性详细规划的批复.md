# 市政府关于同意江苏张家港新能源产业园二期控制性详细规划的批复

张政复〔2018〕81号

来源：市政府发布时间：2018-08-09 11:15:00访问量：字体【大中小】

塘桥镇政府：

你镇上报的《关于报批江苏张家港新能源产业园二期控制性详细规划的请示》（塘政发〔2018〕44号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《江苏张家港新能源产业园二期控制性详细规划》。规划范围：东至双丰路，南至永进路，西至奚浦塘，北至华妙河，规划面积134.93公顷。

二、要加强与城市总体规划、土地利用规划、新能源产业园概念性规划等相关规划的有机衔接、融合，科学研究区域功能定位和产业发展策略，协调处理好规划区域与周边区域的关系，保障土地科学、合理与集约利用。

三、经市政府批准的《江苏张家港新能源产业园二期控制性详细规划》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2018年8月9日
