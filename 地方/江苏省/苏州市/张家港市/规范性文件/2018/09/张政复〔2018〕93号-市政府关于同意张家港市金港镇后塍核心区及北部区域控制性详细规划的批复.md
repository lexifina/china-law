# 市政府关于同意张家港市金港镇后塍核心区及北部区域控制性详细规划的批复

张政复〔2018〕93号

来源：市政府发布时间：2018-09-14 10:05:00访问量：字体【大中小】

金港镇政府：

你镇上报的《关于报批〈张家港市金港镇后塍核心区及北部区域控制性详细规划〉的请示》（金政请〔2018〕15号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《张家港市金港镇后塍核心区及北部区域控制性详细规划》。规划范围：东至港华路，南至张杨公路，西至中华路-健康路，北至晨丰公路-澄杨路，规划面积3.11平方公里。

二、要加强与城市总体规划、土地利用规划、金港片区总体规划等相关规划的有机衔接、融合，协调处理好规划区域与周边区域的关系，统筹安排基础设施和公共服务设施建设，保障土地科学、合理与集约利用。

三、经市政府批准的《张家港市金港镇后塍核心区及北部区域控制性详细规划》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2018年9月14日
