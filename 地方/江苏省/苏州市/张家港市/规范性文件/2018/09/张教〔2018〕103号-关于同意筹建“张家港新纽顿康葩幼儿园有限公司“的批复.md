# 关于同意筹建“张家港新纽顿康葩幼儿园有限公司“的批复

张家港新纽顿幼儿园：

你提交的《关于开办张家港新纽顿康葩幼儿园有限公司的申请》收悉。根据《江苏省学前教育条例》、《关于加快学前教育优质多元发展的实施意见》（张政发规〔2011〕22号）等法规文件精神，经材料审核和实地察看后研究决定，同意由你投资筹建“张家港新纽顿康葩幼儿园有限公司（简称：张家港新纽顿康葩幼儿园）”。

张家港新纽顿康葩幼儿园有限公司办园地址在张家港市购物公园欧陆风情街，属民办全日制幼教机构，隶属张家港市教育局管理。希按照筹建方案，根据“中华人民共和国行业标准托儿所、幼儿园建筑设计规范”、“江苏省优质幼儿园标准”等相关标准实施，待筹建完毕，取得房屋安全合格意见书、消防合格证明、卫生许可证明等材料，验收评估后再确认是否正式审批，未获正式审批前不得招生。

张家港市教育局

2018年9月25日
