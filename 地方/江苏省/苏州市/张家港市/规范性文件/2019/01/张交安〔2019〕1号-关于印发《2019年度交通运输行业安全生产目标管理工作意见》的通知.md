# 关于印发《2019年度交通运输行业安全生产目标管理工作意见》的通知

机关各科室、各企事业单位：

现将《2019年度交通运输行业安全生产目标管理工作意见》印发给你们，请结合本单位实际，认真贯彻执行。

张家港市交通运输局

2019年1月9日

（此件公开发布）

2019年度交通运输行业安全生产目标管理工作意见

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯 彻党的十九大和市委全会精神，紧紧围绕局党委工作中心， 深入贯彻《安全生产法》、 《江苏省安全生产条例》等法律法规和中央领导同志关于安全生产工作的指示精神，坚持“安全第一、预防为主、综合治理”的方针，坚守“发展决 不能以牺牲安全为代价”这条不可逾越的红线，严格落实“党 政同责、一岗双责、齐抓共管、失职追责”责任体系，以“压 事故、保安全、保稳定、保畅通、保重点工程建设”为目标， 以全面落实安全生产及行业安全监管责任制为抓手，加强隐 患排查治理，强化基础，依法监管，全面推进各项安全生产 工作，不断提高保障人民群众安全出行和经济社会安全发展的能力，确保全市交通运输安全生产形势持续稳定。

二、年度目标

1.总体目标

杜绝重特大恶性责任事故，确保辖区航道畅通，不发生 因管理不善而造成航道严重阻塞事故，不发生重特大船舶污 染水域事故，有效控制较大及以上生产安全、火灾、行车责 任事故，避免和减少管理责任事故，确保实现苏州市交通运输局、张家港市人民政府下达的年度安全目标。

2.具体目标

(1)交通直属企事业单位不发生死亡3人或3人以上的 重特大交通事故，行车事故责任死亡率控制在0.75人/千万 车公里以内；生产安全事故死亡率控制在0.11人/千人以内， 重伤率控制在0.33人/千人以内；不发生火灾、机电设备和其他意外事故；尘毒作业点合格率80%以上；粉尘、毒物消除IV级危害。

(2)辖区内河通航水域不发生死亡3人或3人以上的重 特大水上交通事故，水上搜救成功率95%以上，事故起数、 伤亡人数控制在苏州市局下达的指标内；辖区航道、船闸不 发生因管理不善而造成24小时以上航道阻塞事故；确保不发生因监管不到位导致的重特大船舶污染水域事故。

(3)运输市场秩序进一步规范， “三关一监督”责任有 效落实，全市道路旅客运输和危险货物运输违章现象继续减少，不发生因监管不到位导致的重特大道路交通事故。

(4)交通在建工程不发生生产安全死亡事故；新、改、扩建交通建设项目安全设施“三同时”制度得到有效落实。

(5)交通通行保障能力明显提高，继续推进“公路安保 工程”,交通安全设施进一步完善，按期完成年度危桥改造 任务，干线公路优良率保持在99%以上，航标正位率和发光 率达100%;不发生因养护不到位引发的道路交通和水上交通重大责任事故；交通公共突发事件应急处置能力持续增强。

三、工作措施

1.抓组织领导，全面落实行业监管职责。

(1)夯实“党政同责、 一岗双责、齐抓共管、失职追责”责任体系。严格执行《张家港市安全生产“党政同责、 一岗 双责”实施细则》规定，健全各级安全生产组织建设，落实 局领导班子成员以及各级各部门和单位领导班子成员安全  生产工作职责。加大对各行业领域安全生产工作的监督力度，对重点工作推进不力、重大隐患整改缓慢或者连续发生事故 的行业和单位，以督办、约谈等形式，督促责任单位落实整 改，强化工作责任。同时，全面开展各单位“党政同责、 一岗双责、齐抓共管、失职追责”履职情况考核。

(2)落实交通行业管理部门安全监管职责。按照“谁主 管谁负责、谁审批谁负责、谁发证谁负责”原则，以及“管 行业必须管安全、管业务必须管安全、管生产经营必须管安 全”要求，执行“一岗双责”和“一票否决”制度。 一是在 充分发挥交通各职能部门行业安全监管作用的基础上，依托 全市安全生产监管协同联动机制，强化内外联动，积极做好 全局性和全市性的安全联动，对事故多发、问题突出、非法 违法行为屡禁不止的地区和企业实施重点打击，严惩非法违法行为，净化安全生产环境；二是推行安全监管重心下移、 关口前移，充分发挥基层交管所和各企业的安全管理职能， 安全管理更加贴近基层、深入企业，拓展安全管理覆盖面， 提高管理效能；三是充分利用和依托交通运政监控平台、苏 州市道路货物运输业务管理系统、不停车超限检测系统、机 动车维修管理技术信息系统、江苏省港口安全监管与应急管 理系统等信息化管理手段，强化交通运输行业安全监管力度，确保交通运输安全、畅通；四是创新监管方式，持续加全监管应急管理系统建设，优化工作程序，规范录入系 统数据，及时发现和整改问题，充分发挥该系统“安全监管 全方位全覆盖、问题处置全流程闭环管理”的功能，进一步提高安全管理水平。

(3)落实交通生产经营单位安全主体责任。交通运输生 产经营单位是安全生产的责任主体，必须严格贯彻落实《安 全生产法》、《江苏省安全生产条例》等法律法规、规章制 度与技术标准，做好教育培训、安全投入、隐患排查、应急 救援等方面的重点工作，进一步提升企业本质安全水平。同 时，加大事故责任追究力度，对事故责任单位进行约谈，对 企业提出改进要求，督促企业从根本上转变观念，落实安全生产主体责任。

2.抓标准化建设，强化基础管理。

按照省厅、苏州市局及市安委会的要求，从基础管理着 手，在安全管理体制机制、安全投入、安全文化、监督检查、 隐患治理、应急管理、台账资料、规范执法等方面下功夫。  加强宣传引导，推动公路水路客运、危险化学品运输、危险品内河港口作业、交通工程施工等行业企业提优升级。进一步督促引导其他行业企业开展安全生产标准化和平安交通 建设，提高企业本质安全水平。同时强化出租房屋的安全管理，完善出租用房名册及安全检查、隐患治理工作台账，实 行出租房检查整改全过程记录，确保隐患排查整改的闭环管理。

3.抓队伍建设，提高全员素质。

一是要按照《安全生产法》、《江苏省安全生产条例》和 上级交通主管部门相关规定，强化安全监管机构建设，将能 吃苦、责任性强的同志充实到安全监管队伍中来，建立一支 懂技术善管理、敢担当肯吃苦的安全监管队伍；二是根据《省 政府办公厅关于在我省重点行业领域试行安全总监制度的 通知》(苏政办发〔2015〕81号)和市安委会的统一部署，进一步加大建立安全总监制度的宣贯力度，向广大企业辐射 安全总监制度的长处和优势，鼓励有条件的企业全面实行安 全总监制度；三是提升安全生产管理专业化水平。围绕安全 生产突出问题组织专业培训，提高各级安全生产管理人员的 履职能力。在抓好管理队伍的同时，要重视交通安全文化建 设，加强宣传，提高素质。以“安全生产月”和“消防宣传 月”等活动为抓手，认真学习贯彻中央领导同志关于安全生 产工作的一系列指示精神和《安全生产法》、《江苏省安全生 产条例》等法律法规、行业标准及文件；安全教育与时俱进， 加强针对性，确保教育内容、对象、时间、质量、效果五落 实；要以一线操作人员、农民工、外包施工企业人员为重点  落实新工人“三级教育”,强化法定安全培训，组织职工采 取集中培训、专题讲座、技术练兵等多种形式和寓教于乐方 法，推动安全文化建设，真正达到学有所长、教有所获、干有所用的目的。

4.抓行业职责，强化监管能力。

严格执行《安全生产法》、《江苏省安全生产条例》、《地方党政领导干部安全生产责任制规定》、《张家港市各镇(区)人民政府(管委会)、市有关部门和单位安全生产工作职责规定》、 《张家港市安全生产委员会工作规则》以及《张家  港市安全生产“党政同责、 一岗双责”实施细则》,履行交通运输行业安全监管职责。公路管理部门要围绕“公路安保工程”,以国省干线、桥梁、公路下穿为重点，坚持建、养、 管并重的方针，不断提高公路通行条件和公路好路率；加强对辖区公路的日常巡查和隐患排查力度，突出对农村公路的管理，积极探索农村公路管养有效途径，不断提高安全通行 条件。航道管理部门要坚持以“平安航道”为目标，强化干线航道的建设、养护及管理工作，不断提高航道通航保证率。 坚持管理创新与基础工作并重，着力提高安全监管的能力和效果。坚持以目标管理为抓手，推动安全责任的有效落实。

全力构建安全、优质、有序的航道通航环境，推动港航服务 水平再上新台阶。地方海事部门要继续加大通航水域、水上作业监管力度，完善水上风景区旅游船艇备案制度；要以保 畅通为重点，加强水上从业人员的教育和培训，狠刹超载等 违法行为，加强水上危险品运输的监督管理，深化水上交通 安全专项整治，全面落实整治措施，按期实现各项整治工作 目标；要完善水上搜救体系和机制建设，以完善水上搜救中 心建设为契机，健全比较完善的水上救助、船舶污染防治和 水上交通安全“三位一体”的水上应急救援机制。 内河港口 管理部门要会同辖区镇(区)政府(管委会)加强内河港口 码头的安全监管，排查治理事故隐患，重点抓好港口危险货物作业安全监管；要以内河港口码头综合整治提升行动为契机，依法取缔一批、有序纳规一批、优化提升一批，有效提高内河港口码头企业的本质安全度。船闸管理部门要加强船闸安全管理，做好引航道秩序管理、危险品运输船舶过闸管理、通闸管理等安全工作。运管部门(运政稽查)要严把“三关一监督”,不断完善运输市场准入制度，严格执行驾驶员从业资格制度，确保营运驾驶员素质能够适应职业要求；要继续深入推进长途客运车辆和危险化学品运输车辆安全隐 患专项整治，严格落实长途客运车辆、危险化学品运输车辆凌晨2时至5时停车休息措施，从严整治非法载客、无资质运输危险品等违法违规行为；要认真贯彻《汽车客运站安全生产规范》,督促汽车客运站严格落实“三不进站，六不出站”制度；要积极配合相关部门开展道路交通安全专项整治。 机动车维修管理部门要加强客运、危运车辆维修企业和检测站的安全重点监管，加强对专业运输车辆技术状况的检测，  把好车辆维修、保养审验关；要严格执行交通运输部对超长 途、危险品运输车辆的技术要求，对达不到营运车辆技术要求或已到报废年限的车辆坚决不予检测，确保营运车辆技术性能良好。交通工程质量监督站要根据《江苏省公路水运建 设工程安全监管规定》,加强对市交通道路建设指挥部的工程项目实施安全监管，严把施工单位安全资质关，重点做好 高处坠落、坍塌、起重伤害、用电用火等事故预防工作；要求施工单位使用合格的安全管理人员、特种作业人员和特种机械设备参与工程施工，并按照《江苏省公路水运工程“平安工地”建设考核评价标准》(2016年版)在施工现场规范设置安全标志和安全防护设施；要积极督促施工单位落实三 级安全教育制度和监理单位履行安全监理职责。各交管所要 根据职能调整的实际，加强与公路、地方海事、运管、航道、  维管及镇(区)安监部门的协调与沟通，协助行业管理部门  履行交通运输行业源头安全监管职能，为地方社会经济建设 服务。局机关要认真履行局安委会和安委会办公室职责，定 期向苏州市局和市安委会汇报行业安全监管情况，定期督查 职能部门行业安全监管和系统企业安全管理情况，并给予必 要的帮助和指导，局领导将定期和不定期地按照“四不两直”的要求开展安全生产督查，确保安全形势持续稳定。

5.抓应急管理，强化应急防范。

健全各级应急管理组织，科学修订交通运输各类应急预 案，并按规定发布。今年重点抓好相关应急预案继续修编工 作，并对以往修编发布的预案进行回头看。要根据实际情况有计划安排应急演练活动，组织开展专项预案、综合预案的 桌面推演和实战演练活动，演练活动要有计划、有措施、有 总结，不断提高各类突发事件现场应急处置能力。对交通运输应急保障队伍、应急物资、应急装备的储备进行全面梳理， 确保满足应急响应需要。严格执行隐患排查治理月报告制度，建立重大隐患动态监控机制，督促企业有效落实隐患排 查治理的各项措施，在规定期限内完成各级挂牌督办隐患的整改任务。做好交通运输社会稳定风险评估，按照“应评尽评”的要求将社会稳定风险评估作为交通出台重大决策、项目、事项的前置程序，严格按照风险评估的工作流程做好评估工 作，从源头上预防社会矛盾纠纷的发生，确保不发生未经社 会稳定风险评估的决策、项目和事项出台而影响社会安全和稳定。

6.抓重点管理，强化措施落实。

(1)积极推进交通运输行业安全风险分级管控和隐患排

查治理双重预防机制建设。各行业管理部门要根据存在的主 要风险隐患可能导致的后果，结合本行业领域实际，研究制 定区域性、行业性安全风险和事故隐患辨识、评估、分级标 准，制定安全风险管控措施，指导企业全面开展安全风险辨 识，对辨识出的安全风险划分安全风险等级，绘制企业、区域 安全风险空间分布图，分级分类制定安全风险管控措施，建 立安全风险公告警示制度。要督促相关行业企业积极开展隐 患排查治理自查、自改、自报闭环管理，做到责任、措施、 资金、时限和预案“五落实”,实现隐患排查治理自查、自改、自报的闭环管理，确保落实风险管控措施。

(2)认真落实“平安交通”建设三年行动计划年度任务。各行业管理部门要根据“平安交通”建设三年行动计划 及“任务清单”,细化年度任务，明确时序进度，落实具体 举措，“平安交通”建设与日常工作有机融合，与安全专项 整治行动有机结合，保持好工作的连续性，确保各项目标任务顺利完成。

(3)全面强化安全生产执法。 各行业管理部门要强化

执法权威，增加执法刚性。突出重点环节和关键部位，与属地安监、公安等部门及时沟通协调，采取联合执法、集中执 法等方式，加大对各种非法违法行为的打击力度，消除各类安全隐患。以《中华人民共和国安全生产法》第九十四条、 九十六条及九十八条等相关规定为突破口，对企业主体责任 落实不到位的违法行为树立典型案例，利用媒体加大安全生产执法工作宣传。

(4)突出道路客运的安全管理。督促客运企业严格执行上级部门对长途夜班车、高等级公路行驶、出租车等有关  安全规定，坚持营运驾驶员上岗证制度，严把驾驶员资质审  核关，坚决杜绝私招私聘驾乘人员；严格合同管理，加大风险抵押和上路上线检查、稽查、处罚力度；加强对车辆的定  期检测、强制维护和例行保养，杜绝车辆带病运行，确保运  输安全；发挥GPS 和行车记录仪的监控功能，强化对公交车、 出租车、长途客车和旅游包车的实时监控及过程监控，确保  安全行驶。港城汽运集团公司要根据公安、教育部门的要求，同时抓好校车的日常安全管理，落实安全生产主体责任。

(5)突出危货运输和危化品港口的安全管理。督促危 货运输企业加强危货运输车辆(船舶)的特别检验和定期检 查，专用消防器材、安全应急包和有关危险品运输标志要齐 全、到位、有效；要采取切实可靠措施，防止抛、冒、滴、 漏、撞车、翻车，切实加强危货运输安全管理工作；要发挥 好 GPS的实时监控作用，确保危货运输车船的安全运行。督促危化品港口企业认真贯彻新修订的《港口危险货物安全管理规定》和省厅、苏州市局相关文件要求，进一步加强我市内河港口危险货物作业安全管理工作，深化“平安港口”建设，促进我市内河港口健康有序发展。

(6)突出交通在建工程的安全管理。 督促交通工程施 工单位坚持做到工程建设安全管理与质量管理并举、并重  认真把好安全资质关(施工单位应有安全资质证书，法人代 表、项目经理、安全员有安全资格证，电焊工、电工、机动 车驾驶员、架子工等均有特种作业操作证);要重视合同管 理、用工管理、施工现场以及工程机械管理，逐步形成以项 目管理为对象、以工程安全为核心的安全监管体系；要加强 总体施工方案中安全方案的审查，对技术复杂、风险性大的 分部分项工程，要制订安全专项方案，并组织专家进行审查； 要加强对建设、施工、监理单位安全管理行为的日常监督检查，深化“平安工地”建设。

(7)加强事故隐患排查治理。各单位要继续深入开展 事故隐患排查治理工作，要将隐患排查治理工作贯穿于安全 生产的始终，坚持把隐患看作事故来抓；要认真查找薄弱环 节，开展隐患普查登记，定期组织跟踪安全隐患排查治理活 动，对各类隐患进行再排查和再整改，对市级挂牌督办的涉 及交通运输领域的重大隐患，要建立台账，加快整改步伐； 对各类重大隐患，要建立一患一档，进一步落实事故隐患跟 踪督办和企业整改责任，确保事故隐患整改责任、措施、资 金、时限和预案“五到位”;要进行跟踪落实，实现隐患上 报、核查、整改、验收、销号闭环管理，确保整改到位；对列入各级政府挂牌的重大隐患，强化督办，确保按时整改到；要开展危险源的识别、评估，严格危险源点管理，对重 大危险源实行分级管理，推行“危险源点监控法”,确保重点部位安全可靠。

(8)突出消防安全管理。各单位要按照消防“四个能力” (消除火灾隐患能力、组织扑救初起火灾能力、组织人员疏散逃生能力、消防教育培训能力)建设的要求，加强仓库、办公室等场所消防规范化管理，尤其是车站、码头等人员密 集场所和出租房屋更要严格消防安全管理，配备必要完好的 消防设施设备，提升单位防灾抗灾能力、应急救援能力、事故处置能力，有效预防火灾事故的发生。

(9)认真做好季节性、重大节日、重大活动和假日旅游运输安全工作。要按照上级统一部署，结合本行业实际，认 真开展“春运”、 “安全生产月”、 “安康杯”竞赛、  “119 消防宣传”和各类安全生产专项治理活动，营造安全声势，倡导安全文化，整体推进安全管理工作。

四、检查、考核与奖罚

1.检查。局、行业管理部门分别对各行业组织日常安全 检查、节假日和季节性的安全检查，主要领导全年不少于六 次，其他班子成员全年不少于8次。各企业单位自行组织的安全检查每月不少于一次。

2.考核。

(1)局组织对各单位安全生产责任制考核分上半年度、 年度两次。考核内容分控制指标和工作要求两部分，总分为100分，其中指标考核占25分，工作考核占75分。相关个性化工作，根据完成情况另行酌情加扣分。

(2)各单位要根据局制订的责任考核细则，研究制订内部考核细则，单位内部考核一年不少于两次。

3.奖励。考核综合得分为优秀的单位经过评选，由局进行表彰奖励或推荐上级进行表彰。

4.处罚 。一是实行安全“一票否决”,对综合得分较差 的单位，取消有关评先评优的资格，并通报全系统；二是对 违反安全生产法律法规而造成重大生产性事故、火灾事故及

其他重大安全责任事故的单位，将按国家规定予以处罚。
