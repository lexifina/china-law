# 关于给辅警刘飞等同志予以奖励的决定

各警署、各派出所、直属各单位、机关各部门：

为表彰先进，鼓舞士气，根据《张家港市公安局警务辅助人员奖励实施办法》有关规定，市局决定对下列6名同志给予嘉奖奖励，颁发证书和奖金：

刘 飞  城东派出所

周 斌 城西派出所

韦亚新 东莱派出所

汪继毛 乘航派出所

方 威 德积派出所

周付兵 巡特警大队卡口三中队

希望受到表彰的同志谦虚谨慎、戒骄戒躁，珍惜荣誉、再创佳绩。全市广大辅警要以先进为榜样，进一步解放思想、锐意进取，敢于负责、勇于担当，全力推动“快警务”实战模式开花结果，为保障全市社会持续平安稳定作出新的更大贡献。

张家港市公安局

2019年1月9日

（此件公开发布）
