# 关于公布张家港市第一批食品安全初级检查员评定结果的通知

张市监（2019）11号

各科(室)、分局，大队、协会:

根据省局《关于印发加强全省食品药品监管系统食品安全检查员队伍建设指导意见的通知》、苏州市局《关于印发苏州市食品药品监管系统食品安全检查员 管理办法(试行)的通知》等要求，市市场监管局按照规定程序开展了食品安全检查员培训及初级检查员资格评定工作。经评定，66人具备了食品安全初级检查员资格,现予以公布(见附件)。

附件：张家港市第一批食品安全初级检查员名单

张家港市市场监督管理局

2019年1月25日
