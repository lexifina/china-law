# 市政府关于同意张家港市湿地保护规划（2018—2030）的批复

市农业委员会（林业局）：

你委《关于报请批准<张家港市湿地保护规划（2018—2030）>的请示》（张农发〔2019〕5号）收悉。经研究，现批复如下：

一、原则上同意你委（林业局）组织编制的《张家港市湿地保护规划（2018—2030）》（以下简称《规划》）。规划期为2018—2030年，其中近期为2018—2023年，远期为2024—2030年。

二、要按照《规划》要求，围绕“一带、一核、四区”的总体布局，着力推进湿地恢复和综合治理，逐步形成布局合理、类型齐全、功能完善、规模适宜的湿地自然保护生态体系，全面修复和提升湿地生态系统。

三、经市政府批准的《规划》是指导我市湿地建设和管理的重要依据，要建立健全规章制度，加大执法管理力度，切实增强各镇（区）和相关部门的衔接，促进港城经济、社会和生态全面协调高质量发展。

此复。

张家港市人民政府

2019年1月26日
