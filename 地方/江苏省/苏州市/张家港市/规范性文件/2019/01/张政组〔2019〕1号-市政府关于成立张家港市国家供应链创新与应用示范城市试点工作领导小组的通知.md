# 市政府关于成立张家港市国家供应链创新与应用示范城市试点工作领导小组的通知

张政组〔2019〕1号

来源：市政府发布时间：2019-01-11 13:36:00访问量：字体【大中小】

各镇政府，冶金工业园、高新技术产业开发区、常阴沙现代农业示范园区、双山香山旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：

为进一步做好我市供应链创新与应用示范城市建设工作，经研究，决定成立张家港市国家供应链创新与应用示范城市试点工作领导小组。领导小组成员名单如下：
