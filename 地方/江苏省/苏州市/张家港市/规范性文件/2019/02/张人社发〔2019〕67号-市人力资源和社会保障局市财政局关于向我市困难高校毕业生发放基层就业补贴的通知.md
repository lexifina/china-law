# 市人力资源和社会保障局市财政局关于向我市困难高校毕业生发放基层就业补贴的通知

各镇（区）、各有关单位：

根据市政府《关于做好当前和今后一个时期促进就业工作的实施意见》（张政发〔2019〕18号）有关要求，为落实好引导鼓励高校毕业生到乡镇（街道）、村（社区）社会管理和公共服务岗位就业工作，对符合条件的我市困难高校毕业生发放基层就业补贴。具体事宜通知如下：

一、补贴对象

通过年度开发基层公共服务岗位计划，经招聘安置到基层公共服务岗位就业的低收入家庭、困难家庭和就业困难高校毕业生。

二、补贴标准

符合条件的高校毕业生按3000元/人标准给予一次性基层就业补贴。

三、申请条件

（一）上年度通过开发基层公共服务岗位帮扶低收入家庭、困难家庭和就业困难高校毕业生就业工作，并经招聘安置后实现就业的困难高校毕业生，且就业岗位与招录岗位一致；

（二）用人单位与高校毕业生签订1年以上期限劳动合同并交纳社会保险费；

（三）申报时和补贴发放时，申请人均应为在录用单位参保状态。

四、申报程序

符合条件的高校毕业生应于到岗次年3月底前填写《张家港市基层就业补贴申请表》（见附件），由本人至市人力资源管理服务中心提出补贴申请。市人力资源管理服务中心对困难高校毕业生申请基层就业补贴资格进行审核，无误后在我市政府网站（www.zjg.gov.cn）上公示5个工作日。经公示无异议的，将补贴资金拨付至毕业生个人银行账户。

五、其他

（一）补贴所需资金由财政部门统筹安排。

（二）本通知自2019年2月26日起执行。
