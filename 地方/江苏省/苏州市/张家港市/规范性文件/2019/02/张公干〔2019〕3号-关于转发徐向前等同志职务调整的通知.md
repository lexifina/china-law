# 关于转发徐向前等同志职务调整的通知

各警署、各派出所、直属各单位、机关各部门:

接市委张委组〔2018〕210号、张委组〔2019〕18号、25号、57号文件通知，市政府张政人〔2018〕37号、张政人〔2019〕2号、4号、6号文件通知：

徐向前同志任市公安局政委、党委副书记，免去市公安局副局长职务；

赵煜斌同志任市公安局主任科员，免去市公安局政委、党委副书记、委员职务；

邬海安同志任市公安局党委副书记（正科级），免去市公安局副局长职务；

殷沪飞同志任市公安局副局长，免去市公安局政治处主任职务；

戴冷松同志任市公安局副局长；

沈军、唐新荣同志任市公安局党委委员；

徐高峰同志任市公安局党委委员、政治处主任（试用期一年），免去市公安局指挥中心主任职务；

刘军同志任市公安局副主任科员。

特此通知。

张家港市公安局
