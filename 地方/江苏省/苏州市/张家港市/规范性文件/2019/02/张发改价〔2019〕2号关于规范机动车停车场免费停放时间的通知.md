# 张发改价〔2019〕2号关于规范机动车停车场免费停放时间的通知

各机动车收费停车场：

为进一步规范机动车停放服务收费行为，维护经营者和消费者的合法权益，根据《苏州市机动车停车场管理办法》（苏府第147号令）、《张家港市机动车停放服务收费管理办法》（张政发规〔2018〕2号）等规定，现就张家港市机动车停车场免费停放时间调整通知如下：

张家港市范围内，实行政府定价、政府指导价的道路泊位及公共停车场免费停放时间由原来的不少于15分钟调整为不少于30分钟。具体为：停车30分钟以内（含）免费，停车时间超过30分钟的按照实际停车时间计费。

本通知于2019年3月1日起执行。

请各相关停车场做好免费停放时间的调整工作。

张家港市发展和改革委员会

2019年2月21日
