# 市政府关于同意张家港市凤凰镇韩国工业园（FHHG-01-02基本控制单元）控制性详细规划调整的批复

张政复〔2019〕11号

来源：市政府发布时间：2019-02-11 16:24:00访问量：字体【大中小】

凤凰镇政府：

你镇上报的《关于报批〈张家港市凤凰镇韩国工业园（FHHG-01-02基本控制单元）控制性详细规划调整〉的请示》（凤政请〔2019〕2号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《张家港市凤凰镇韩国工业园（FHHG-01-02基本控制单元）控制性详细规划调整》。规划调整范围为东至苏虞张公路、南至凤恬路、西至魏庄路、北至凤凰大道，规划面积98.11公顷。

二、经市政府批准的《张家港市凤凰镇韩国工业园（FHHG-01-02基本控制单元）控制性详细规划调整》是指导该区域建设和管理的重要依据。要严格执行规划，达到通过规划调整引导该区域开发建设更加科学合理的目的。

此复。

张家港市人民政府 2019年2月11日
