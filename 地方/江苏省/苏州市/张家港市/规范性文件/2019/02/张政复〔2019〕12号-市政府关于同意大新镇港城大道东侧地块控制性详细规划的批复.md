# 市政府关于同意大新镇港城大道东侧地块控制性详细规划的批复

大新镇政府：

你镇上报的《关于报批〈大新镇港城大道东侧地块控制性详细规划〉的请示》（大政发〔2018〕55号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《大新镇港城大道东侧地块控制性详细规划》。规划范围：东至现状工业用地和规划浦东路，南至镇界，西至港城大道，北至规划浦北路，规划面积138.7公顷。

二、要加强与城市总体规划、土地利用规划、大新镇总体规划等相关规划的有机衔接、融合，协调处理好规划区域与周边区域的关系，科学研究区域功能定位和产业发展策略，保障土地科学、合理与集约利用。

三、经市政府批准的《大新镇港城大道东侧地块控制性详细规划》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府 2019年2月11日
