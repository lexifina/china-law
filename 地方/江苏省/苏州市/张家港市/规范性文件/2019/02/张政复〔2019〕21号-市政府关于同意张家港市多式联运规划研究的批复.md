# 市政府关于同意张家港市多式联运规划研究的批复

市交通局：

你局上报的《关于报批〈张家港市多式联运规划研究〉的请示》（张交发〔2019〕9号）收悉。经研究，现批复如下：

一、原则同意你局上报的《张家港市多式联运规划研究》。规划研究范围为张家港市行政区域范围。规划研究期限至2035年，其中近期规划至2020年，中期规划至2025年，远期规划至2035年。

二、要加强与城市总体规划、土地利用规划、综合交通规划等相关规划的衔接，深化多式联运通道等级与线位预控，统筹安排交通基础设施建设，打造对内高效联通、对外强力辐射的货运体系。

三、经市政府批准的《张家港市多式联运规划研究》是指导我市多式联运体系建设的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2019年2月27日
