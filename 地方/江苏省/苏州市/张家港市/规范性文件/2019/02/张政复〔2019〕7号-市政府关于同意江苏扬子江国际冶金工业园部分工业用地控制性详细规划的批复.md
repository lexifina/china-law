# 市政府关于同意江苏扬子江国际冶金工业园部分工业用地控制性详细规划的批复

锦丰镇政府：

你镇上报的《关于报批〈江苏扬子江国际冶金工业园部分工业用地控制性详细规划〉的请示》（锦政发〔2019〕2号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《江苏扬子江国际冶金工业园部分工业用地控制性详细规划》。规划范围：分为5块用地，分别为常通路西北侧工业地块、五棵松路东北侧工业地块、北中心河两侧地块、华润路西侧地块和锡通高速公路两侧地块，规划面积128.46公顷。

二、要加强与城市总体规划、土地利用规划、锦丰镇总体规划等相关规划的有机衔接、融合，协调处理好规划区域与周边区域的关系，科学研究区域功能定位和产业发展策略，保障土地科学、合理与集约利用。

三、经市政府批准的《江苏扬子江国际冶金工业园部分工业用地控制性详细规划》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2019年2月11日
