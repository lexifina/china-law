# 市教育局关于同意张家港市常青藤实验中学增加小学学段及变更校名的批复

张教〔2019〕26号

张家港市常青藤实验中学：

你校《关于增加小学学段及变更学校类型、办学内容、校名的申请》及相关材料收悉。经研究，同意增加小学学段，学校类型由完全中学变更为十二年一贯制学校，办学内容由全日制初高中教育变更为全日制中小学教育，将“张家港市常青藤实验中学”更名为“张家港市常青藤实验学校”。

学校名称变更后，原办学性质不变。学校在新审批范围内办学，要不断加强学校管理，聚合优质资源，拓展发展空间，提升办学品质。

张家港市教育局

2019年2月14日
