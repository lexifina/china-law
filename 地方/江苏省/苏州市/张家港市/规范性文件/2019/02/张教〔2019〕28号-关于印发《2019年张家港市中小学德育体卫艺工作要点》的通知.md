# 关于印发《2019年张家港市中小学德育体卫艺工作要点》的通知

各中小学：

现将《2019年张家港市中小学德育体卫艺工作要点》印发给你们，请各校结合工作实际，认真贯彻落实，扎实推进各项工作。

张家港市教育局

2019年2月25日

（此文件主动公开）

2019年张家港市中小学德育体卫艺工作要点

2019年全市中小学德育体卫艺工作的总体要求是：以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大精神，认真落实全国教育大会部署，以建办优质教育为总体目标，以立德树人为根本任务，以推进“三聚两先”为工作引领，进一步解放思想、开拓创新，不断提升学校德育体卫艺工作水平，努力培养德智体美劳全面发展的时代新人。

一、德育工作

1.建设融合德育品牌。全面贯彻教育部《中小学德育工作指南》，以“融合德育”作为张家港区域德育工作特色与品牌，积极探索新时代学校德育工作的新特点、新内涵、新方法、新途径。以习近平总书记关于教育工作的系列重要讲话精神引领全市德育工作向纵深推进和发展，实现德育目标、内容、方法、途径等各方面的深度融合，推动德育工作与课程建设、党建、团队建设、文明校园创建、社会实践活动、新时代文明实践等工作的全面融合，努力打造张家港市新时代德育工作新品牌。聘任知名德育专家担任教育智库成员，组织德育工作专题研讨和学习交流活动。组织开展品格提升工程项目的申报、培育和展示活动，努力打造学校德育工作新亮点。深入推进学校劳动教育，努力培养德智体美劳全面发展的时代新人。

2.深化养成教育实践。对照2017年10月教育局下发的《关于进一步推进“5+x”好习惯养成教育的指导意见》，以好习惯养成教育课程资源开发、评价模式构建、实施队伍建设三个专题，开展专题化研究并形成阶段性成果。坚持问题导向，提炼经验、查找不足，进一步找准我市好习惯养成教育与中小学生品格提升项目的融合点，以创新德育实践方式、特色资源开发、学生发展指导，完善区域推进模式。继续着力营造好习惯养成教育氛围，举办教师好习惯随手拍摄影作品、学生好习惯个人微视频、家长好习惯微课堂系列校级、市级评比活动。

3.抓实德育队伍建设。完善中小学班主任激励机制，不断提高班主任队伍专业化发展水平。启动德育干部工作讲坛，在德育校长、德育主任中就学校德育管理工作话题开展主题式交流，鼓励德育干部带头上班会课、团（队）课，结合学校德育工作整体展示予以落实。落实好《学校班主任工作室建设与管理办法（2017～2019）》，选树表彰一批2017～2019年度优秀学校班主任工作室。依托市级班主任基本功竞赛，打造一支会做、勤思、善言的青年班主任团队，将赛前集训和选拔培养相结合，形成比赛梯队，力争在苏州市级班主任基本功竞赛中再创佳绩。推进学科德育建设，发挥全科、全员、全程德育功能。

4.提升心理教育实效。认真贯彻2017年苏州市教育局1号文件《关于全面加强学生心理教育的若干意见》，抓好新一轮心理健康教育师资培训，全力提升学校心理辅导水平；落实三类心理健康教育校本课程，确保学校开足开好课程并取得明显成效。加强班级心理观察员学习培训、学校心理辅导室必备档案资料规范统一和学校心理辅导室实地抽查等工作，完善中小学生心理健康预警和监护网络。依托市家庭教育服务中心（市未成年人健康成长指导中心）、戴小燕心理名师工作室，定期开展中小学心理健康教育教学研讨活动，提高全市中小学心理健康教育教学质量。

5.建好学生成长平台。打造中小学社会实践活动、社团活动和志愿者活动三大学生成长平台，组织学生积极参加各类社会实践活动、社团活动、志愿者活动和研学旅行等丰富多彩的校内外活动。开展张家港市和苏州市优秀校园志愿服务项目、优秀校园志愿服务管理员、年度十佳中小学生社团、社团建设先进学校等相关评选展示活动。开展“三色花开·快乐成长”未成年人社会实践活动、新时代文明实践志愿服务活动和中华优秀传统文化进校园等活动，构建全方位、全天候育人的社会教育支持体系，为广大青少年的健康成长和全面发展搭建多样平台。

6.深化家庭教育服务。以“养正：家国一体，德心相荣”为方向引领，推动全市家庭教育服务工作向纵深发展。组织开展“幸福家长驿站”“心树林”志愿服务等常态化活动。加强多方合作，创新平台建设，完善家庭教育学习培训咨询体系。制作完成《港城父母新成长》音频微课程，作为父母家庭教育成长普惠教育课程，免费发放给全市从幼儿园到初中三年级的学生家长。组织全市家长学习家庭心理健康教育成长课《港城父母心成长》课程。规划和实施全市家庭教育、心理健康教育专兼职教师的鹰架建设。举办全市家庭教育研讨会，组织各类专题培训等活动。

7.夯实学校共青团工作。全面贯彻落实全省“智慧团建”工作电视电话会议和全省初中学校“积分入团”现场推进会精神，对照团省委“磐石工程”的各项要求，抓牢基层团组织在基础团务（团干部“双述双评”、团员发展和教育管理、团员身份认定）的各项工作机制。丰富“青年学习社”活动内容和形式，深入开展“青年大学习”行动和“张家港精神”学习宣传活动，探索打造有亮点的重点品牌，形成高质量的学习产品，持续掀起“青年大学习”热潮。举办中小学、幼儿园团委（支部）书记培训班，推动学习型团组织建设，围绕青年教师综合素养提升项目，开展教育信息技术、演讲等系列活动。

8.推进新时代文明实践工作。深入推进教育系统新时代文明实践工作，设立教育系统新时代文明实践志愿服务指导中心和展示平台，具体组织和指导学校开展文明实践志愿服务活动，做好志愿者的组织管理、学习培训和督查评估等工作。成立张家港市教育系统新时代文明实践志愿服务支队，以项目为单位组建10支新时代文明实践志愿服务分队，指导各中小学、幼儿园和直属单位成立新时代文明实践志愿服务小队，延伸拓展新时代文明实践工作内容和方式，推动形成常态化、长效化的教育系统新时代文明实践工作机制。

二、体育工作

1.推进阳光体育运动。落实“健康第一”理念，深入持久开展阳光体育运动，组织阳光大课间活动检查和评比；实施田径振兴计划，组织中小学生阳光体育“田径精英赛”，提高全市中小学田径运动水平；组织三大球、乒乓球、冬季三项、啦啦操等体育比赛活动，发掘和培育手球、武术、轮滑、桌式足球等特色体育项目；以“三大球”联赛为杠杆，进一步推进学校体育改革，形成青少年热爱体育、崇尚运动的浓厚氛围；制定2019年体育中考方案，推进体育中考改革，圆满完成体育中考任务；开展2017-2019年度中小学体育特色学校认定工作，不断提升学校体育工作水平。

2.提升校园足球水平。完善校园足球领导小组办公室人员配备和工作职能，加强对校园足球工作的统筹协调，优化全市足球教育资源配置，进一步提升全国青少年校园足球试点县（区）的整体工作水平。组织全国青少年校园足球特色学校和张家港市足球特色幼儿园申报和督查工作，完善考评激励机制。继续推行以足球为核心的“三大球联赛”，完善联赛制度，规范过程管理，提高校园足球的参与度和普及率；探索校园足球文化宣传的途径和形式，举办第二届校园足球文化节系列活动；调动社会力量参与各级联赛，共同营造全社会关注校园足球的良好氛围；建设青少年足球运动学校（贝贝足球学校），加大校园足球优秀人才入学升学扶持政策，进一步拓宽升学通道，形成优秀人才梯队；深化与校外足球培训机构的合作，加强与外省市和兄弟学校的交流，充分发挥足球外教的示范引领作用。加大对足球教练员和裁判员的培训力度，逐步解决足球师资紧缺问题。协助承办第22届全国“贝贝杯”青少年足球赛，高质量承办2019年江苏省青少年校园足球现场推进会，推动我市校园足球向更高水平发展。

三、美育工作

1.深化美育普及行动。加强学校美育工作管理，推进艺术课程建设，深化艺术教学改革，丰富和创新艺术教育的内容和形式，全面提高学生的审美能力和艺术素养。规范艺术课程实施，加强艺术教学研讨，组织2019年初三学生音乐、美术素质测试。组织第四届中小学生艺术节、“童话里的世界”、第六届“百名小书法家、百名小画家”评选、千名小画家同绘港城绘画、2所美术特色学校参加苏州市教育局“金色大厅”作品展、戏曲进校园等活动，丰富学生校园文化生活，努力为学校艺术教育的百花齐放和师生的全面发展、各现所长搭建平台。

2.提高学校美育质量。2018年我市共有10余项艺术类作品在江苏省第六届中小学生艺术节中获奖，部分节目将入选全国六艺展活动，积极配合苏州市教育局做好展演、观摩、交流等工作，高标准打磨入展作品，确保在全国六艺展活动中精彩亮相。与少年宫、美术馆等机构合作，为艺术老师提供个人或团队展示平台，促进全市艺术教育水平的整体提升。开展2017-2019年度中小学艺术特色学校认定工作，组织学校艺术特色展示活动，促进学校加强和改进艺术教育工作，不断提升学校艺术工作水平。

四、卫生与健康教育工作

1.强化学校卫生工作。贯彻《学校卫生工作条例》，加强学校卫生工作，改善学校卫生环境和教学卫生条件，强化食品、饮用水等安全管理。积极探索政府购买服务或学校与专业医疗机构合作建办校医室，加大校医和保健老师的专业培训力度。加强学生常见传染病的发现、处置和防控工作，落实常态工作机制，真正做到“早发现、早报告、早隔离”。落实《张家港市生活垃圾强制分类工作实施方案》，推进学校垃圾强制分类工作，开展垃圾强制分类示范学校评比，不断巩固和扩大校园垃圾强制分类工作成果。开展学校教师应急救护技能培训，做好红十字会有关工作。

2.推动健康教育工作。落实教育部《综合防控儿童青少年近视实施方案》，在全市中小学广泛开展防近主题教育活动，制定明确的工作目标，通过切实可行的教育手段，降低学生的近视发病率。深化环保教育，在全市中小学广泛开展“保护母亲河——绿动长江”主题教育活动，助力我市的“清江行动”。加大江苏省健康促进学校的创建力度，扩大金牌学校的创建比例并巩固创建成果。组织中小学健康素养知识学习和竞赛活动，提高中小学生的健康意识和水平。

五、其它工作

1.深化学生军训工作。加强与市人武部合作共建，进一步健全军训工作机制，规范军训工作管理，提高军训工作质量。编制张家港市高中新生军训手册，丰富军训活动课程，实现军训工作的制度化、规范化、科学化。

2.做好版权登记工作。作为张家港市版权工作站之一，2019年将在提升学校版权工作意识和质量上下功夫，积极上传作品，做好版权登记，争创优秀版权工作站。
