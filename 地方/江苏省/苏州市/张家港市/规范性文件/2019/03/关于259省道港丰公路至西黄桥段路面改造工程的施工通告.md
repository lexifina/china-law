# 关于259省道港丰公路至西黄桥段路面改造工程的施工通告

因259省道港丰公路至西黄桥段路面改造工程施工需要，将于2019年3月15日至2020年6月30日对259省道港丰公路至西黄桥段采取双向各封闭一个快车道的交通管制措施，其中新开河桥采取半幅封闭施工另半幅双向通行的交通管制措施，南横套桥采取全封闭施工。届时，请过往车辆和行人提前绕道行驶，由于道路施工给您带来的不便，敬请谅解。
