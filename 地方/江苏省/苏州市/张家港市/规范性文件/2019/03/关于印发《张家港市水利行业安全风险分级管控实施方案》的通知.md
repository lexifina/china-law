# 关于印发《张家港市水利行业安全风险分级管控实施方案》的通知

各有关单位：

为防范遏制重特大事故，构建安全风险分级管控和隐患排查治理双重机制，水利部印发了《关于开展水利安全风险分级管控的指导意见》（水监督﹝2018﹞323号），省水利厅印发了《江苏省水利行业防范遏制重特大事故构建双重预防机制安全生产源头管控和安全准入工作实施方案》（苏水办安﹝2017﹞17号），为进一步规范和强化我市水利行业安全风险分级管控工作，市水务局制定了张家港市水利行业安全风险分级管控实施方案。现印发你们，请认真贯彻执行。

附件1

张家港市水利行业安全风险分级管控实施方案

为贯彻落实党中央、国务院和省委、省政府关于安全生产工作的决策部署和水利部关于开展水利安全风险分级管控的指导意见》（水监督﹝2018﹞323号）及《江苏省水利行业防范遏制重特大事故构建双重预防机制 安全生产源头管控和安全准入工作实施方案》（苏水办安﹝2017﹞17号）要求，全面构建安全风险分级管控和隐患排查治理双重预防机制，进一步规范和强化我市水利行业安全风险分级管控工作，现结合我市水利工作实际，制定本实施方案。

一、总体要求

坚持“安全第一、预防为主、综合治理”方针，推动水利安全风险预控、关口前移，建立水利安全风险管控体系，健全水利工程安全风险分级管控工作制度和规范，实现水利生产经营单位安全风险自辨自控、水行政主管部门有效监管的安全风险管控工作格局，提升水利安全风险防控能力，科学防范和有效遏制水利生产安全事故，促进我市水利安全生产形势持续平稳。

二、着力构建水利生产经营单位安全风险管控机制

1、全面开展安全风险辨识。

水利生产经营单位主要负责人全面负责，组织全体员工对本单位进行全方位全过程的安全风险分析辨识，参照《企业职工伤亡事故分类》（GB6441-1986）《生产过程危险和有害因素分类与代码》（GB/T13861-2009）等标准，确定安全风险类别和等级，在建工程按《水利水电施工危险源辨识与风险评价导则（试行）》（办监督函﹝2018﹞1693号）进行辨识。

2、科学评定风险等级

水利生产经营单位要根据危险源类型，采用相适应的风险评价方法，确定危险源风险等级，要制定科学规范的安全风险分析、辨识、评估、登记建档和分类定级制度。安全风险等级从高到低划分为重大、较大、一般和低四个等级，分别用红、橙、黄、蓝四种颜色标示。要依据安全风险类别和等级建立安全风险数据库，绘制“红橙黄蓝”空间分布图。其中，水利水电工程施工危险源辨识评价及风险空间分布图绘制，由项目法人组织有关参建单位开展，重大安全风险应填写清单、汇总造册，并报告市水务局，危险物品重大危险源要按照规定同时报市应急管理局备案。

3、有效管控安全风险

水利生产经营单位要从组织、制度、技术、应急等方面对安全风险进行有效管控，逐一明确责任部门、责任人和管控措施，对重大危险源和重大安全风险要重点管控，并高度关注危险源风险的变化情况，动态调整危险源、风险等级和管控措施，确保安全风险始终处于受控范围内。风险管控措施要形成“一企一册”，并报市水务局备案。要建立安全风险警示和公告制度，在单位、工地醒目位置设置公告栏，在存在安全风险的岗位设置告知卡，公布和标明岗位主要风险、预防和应急措施等。

三、健全完善双重预防安全风险监管体系

1、加强安全风险和隐患安全监管

市水务局将加强对辖区内重大安全风险和重大事故隐患的监督管理，逐一现场督查，以推动水利生产经营单位加快实施管控整治措施。市水务局将根据水利经营单位安全风险管控和隐患整治情况，确定重点防控单位，每季度逐级确认上报，实施差异公动态监管，依据安全风险等级，对水利生产经营单位实施分类分级管理，对安全风险管控措施落实不到位、事故隐患整改不及时的水利生产经营单位，有针对性地开展指导督办、及时改进。市水务局将加强重大安全风险信息共享、预警预报和应急响应，建立完善联防联控机制，增强防范抵御事故风险的能力。

2、强化安全风险管控和隐患排查治理信息化建设

水务局将充分利用水利安全生产信息上报系统，实现和水利生产经营单位之间的互联互通、信息共享，并督促水利生产经营单位将所有辨识出的风险的排查出的隐患全部录入信息上报系统，并将管控和整治情况及时录入，逐步形成本地区安全风险和事故隐患数据库，通过信息上报系统，督促水利生产经营单位履行隐患自查自纠自报主体责任，对每一个环节做到痕迹化，实时监控隐患整改情况。

四、加强安全生产源头管控和安全准入

1、明确规划设计安全要求

水利工程前期规划要将安全风险管控纳入规划分析，加强可行性研究报告和初步设计报告中《劳动安全与工业卫生》专篇的编制和审查，对工程建设期和运行期的安全采取有针对性的防范措施，实行重大安全风险“一票否决”。水利工程项目的选址和布局要充分考虑安全生产因素，严格遵循有关法律法规和标准规范要求，严控与其他行业管线、工程、设施等的安全防护距离，严格落实水利建设工程勘察设计安全质量终身负责制。要按照“谁批准谁负责、谁建设谁负责”原则，明确安全管控责任人。

2、严格行业领域安全准入

对水利生产经营单位和生产经营活动，严格安全生产准入条件限制，对不符合安全生产条件、没有依法取得安全生产许可证的，严格执行“一票否决”。各项目法人要严格督促落实水利建设项目安全设施和职业病防护“三同时”制度，将建设项目安全设施和职业病防护设施作为竣工验收技术鉴定和工程验收的重要内容。

3、加强从业人员安全素质准入

严格落实国家有关生产经营单位负责人、安全管理人员和特种作业人员的相关要求，加强对水利水电施工企业三类人员的培训考核，严格审查外协单位从业人员的安全素质，建立健全生产安全事故重大责任人员职业和行业禁入制度。强化从业人员入职安全培训、警示教育、继续教育和考核管理，提升从业人员安全意识和技能。

市水务局将加强对安全风险管控工作的监督指导，对辖区内在建工程、运行工程和相关单位安全风险管控情况进行分类指导和监督检查，并把安全风险分级管控工作情况作为水利安全生产监督管理工作重点，加以检查考核。
