# 关于调整经开区（杨舍）警署部分派出所管辖区域的通知

各警署、各派出所、直属各单位、机关各部门：

根据《市政府关于同意杨舍镇调整村、居委会设置和管理区域的批复》，为确保调整后各项公安业务工作的有效衔接和正常有序开展，进一步明确和方便治安管理、户籍管理、110接处警、案件侦办等工作，市局决定对城中、城东、城南、城西、乘航、东莱、晨阳派出所管辖区域进行调整。现将相关情况明确如下：

1.将原城中派出所管辖的朱港巷路以南区域划归城南派出所管辖；

2.将原城西派出所管辖的永安路以西、沙洲西路以北、东横河以南、西二环路以东区域划归城中派出所管辖；

3.将原城西派出所管辖的沙洲西路以南、西二环路以东区域划归城南派出所管辖；

4.将原乘航派出所管辖的东二环路以西、东横河以南、南二环路以北区域划归城东派出所管辖；

5.将原晨阳派出所管辖的港城大道以东、南套河以北、福新路以南、福锦路以西区域划归东莱派出所管辖；

6.调整时间为2019年3月20日0时。

特此通知。

张家港市公安局

2019年3月19日
