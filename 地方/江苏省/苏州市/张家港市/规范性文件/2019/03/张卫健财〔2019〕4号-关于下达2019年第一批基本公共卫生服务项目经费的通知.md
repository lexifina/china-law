# 关于下达2019年第一批基本公共卫生服务项目经费的通知

张卫健财〔2019〕4号

各镇(区)财政所、社区卫生服务中心：

现将省财政厅苏财社(2018)123号下达的基本公共卫生服务项目经费1032万元下达你们，列2019年度“医疗卫生---公共卫生---基本公共卫生服务”支出。

请各镇(区)按照规定，专款专用，并及时、足额安排镇级配套经费。

附件：2019年第一批基本公共卫生服务项目经费表

张家港市卫生健康委员会   张家港市财政局

2019年3月21日
