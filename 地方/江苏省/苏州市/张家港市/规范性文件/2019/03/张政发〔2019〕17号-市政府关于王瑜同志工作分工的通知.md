# 市政府关于王瑜同志工作分工的通知

各镇政府，冶金工业园、高新技术产业开发区、常阴沙现代农业示范园区、双山香山旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：

因人事变动，经研究决定，王瑜同志负责民政、文化、广电、旅游、体育、退役军人事务、人民武装、双拥、地方志、残疾人方面的工作，协助金融、政务服务管理方面的工作。

分管市民政局、文体广电和旅游局、退役军人事务局。

联系市档案局、新闻出版局、民族宗教事务局、人武部，驻张家港部队，团市委、市文联、残联、社科联，市融媒体中心（传媒集团）（筹）、江苏有线张家港分公司。

张家港市人民政府

2019年3月13日
