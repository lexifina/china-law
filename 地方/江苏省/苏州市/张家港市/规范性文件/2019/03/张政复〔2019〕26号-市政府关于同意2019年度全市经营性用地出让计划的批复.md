# 市政府关于同意2019年度全市经营性用地出让计划的批复

张政复〔2019〕26号

来源：市政府发布时间：2019-03-25 15:57:00访问量：字体【大中小】

市自然资源和规划局：

你局上报的《关于审核批准2019年度经营性用地出让计划的请示》（张资规发〔2019〕5号）收悉。经市政府第24次常务会议审议，现批复如下：

一、同意2019年度经营性用地出让计划规模为1850亩，其中：市城投集团370亩、保税区（金港镇）200亩、经开区（杨舍镇）330亩、冶金工业园（锦丰镇）100亩、高新区370亩、塘桥镇160亩、乐余镇80亩、凤凰镇110亩、南丰镇60亩、大新镇70亩。

二、你局要会同各镇（区）和相关部门综合考虑市场需求、资金安排、用地指标等方面因素，统筹兼顾，科学安排，确保全市土地出让交易工作有序推进。

此复。

张家港市人民政府

2019年3月25日
