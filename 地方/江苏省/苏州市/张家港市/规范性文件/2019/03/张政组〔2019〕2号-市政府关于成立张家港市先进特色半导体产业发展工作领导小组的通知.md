# 市政府关于成立张家港市先进特色半导体产业发展工作领导小组的通知

各镇政府，冶金工业园、高新技术产业开发区、常阴沙现代农业示范园区、双山香山旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：

为进一步加快推进我市先进特色半导体产业发展，经研究，决定成立张家港市先进特色半导体产业发展工作领导小组。领导小组成员名单如下：
