# 关于同意建办“张家港市菁华幼儿园有限公司”的批复

刘义：

你提交的《关于建办张家港市菁华幼儿园有限公司的申请报告》收悉。根据《民办教育促进法》《营利性民办学校监督管理实施细则》等法律、法规精神，经审核，同意你与林朝晟、孙奎共同投资建办“张家港市菁华幼儿园有限公司（简称：张家港市菁华幼儿园）”；法定代表人为刘义；总投资2200万元，注册资金200万元；地址在张家港市塘桥镇胡同社区；办学许可证编号为：132058260000169；设计规模为5轨15班，每班招生人数为25人以内，招生总人数为375人以内；属营利性民办全日制幼教机构；隶属张家港市塘桥镇管理。

在今后的办园过程中，如需变更举办者、法人、地址、性质、规模等，应向张家港市教育局报批，待审核通过后方能实施。每年须持办学许可证及相关材料到张家港市教育局办理年审手续，年审不合格应在规定期限内整改；连续两年年审不合格的，撤销举办资格。

希根据《江苏省学前教育条例》《关于加快学前教育优质多元发展的实施意见》（张政发规〔2011〕22号）等文件精神，尽快完善办园条件，合理配备保教人员，着力规范办园行为，切实加强常规管理，不断提升保教质量，努力促进我市学前教育优质多元发展。

张家港市教育局

2019年3月13日
