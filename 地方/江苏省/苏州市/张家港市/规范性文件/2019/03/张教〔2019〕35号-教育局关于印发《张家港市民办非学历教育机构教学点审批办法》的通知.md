# 教育局关于印发《张家港市民办非学历教育机构教学点审批办法》的通知

张教〔2019〕35号

各民办非学历教育机构：

为进一步规范我市民办非学历教育机构教学点的审批程序，根据江苏省教育厅发布的《江苏省民办非学历教育机构设置和管理办法（修订）》（苏教规〔2017〕6号）、苏州市教育局发布的《苏州市校外培训机构设置标准》（苏教民社〔2018〕16号）、《关于明确校外培训机构审批登记相关问题的通知》（苏教民社〔2019〕2号）等文件精神，结合我市实际，我局研究制定了《张家港市民办非学历教育机构教学点审批和管理办法》。现印发给你们，请认真贯彻执行。

附件：张家港市民办非学历教育机构教学点审批和管理办法

张家港市教育局
