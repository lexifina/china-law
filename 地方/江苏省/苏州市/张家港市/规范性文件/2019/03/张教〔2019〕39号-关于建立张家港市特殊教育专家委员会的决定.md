# 关于建立张家港市特殊教育专家委员会的决定

市教育局、民政局、卫健委、财政局、残联：

为贯彻国家《残疾人教育条例》和教育部等七部委《第二期特殊教育提升计划（2017—2020年）》精神，落实《江苏省第二期特殊教育提升计划（2017—2020年）》要求，进一步加强张家港市特殊教育工作的组织领导，加快推进我市特殊教育事业发展，全面实施融合教育，经研究，决定建立张家港市特殊教育专家委员会。
