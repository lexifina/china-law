# 教育局关于同意筹建“张家港市金宝贝之星幼儿园有限公司“的批复

张家港铂悦宝贝文化教育发展有限公司：

你公司提交的《关于开办张家港市金宝贝之星幼儿园有限公司的申请》收悉。根据《江苏省学前教育条例》、《关于加快学前教育优质多元发展的实施意见》（张政发规〔2011〕22号）等法规文件精神和《关于金宝贝幼儿园（筹）相关事宜协商会的会议纪要》（张经建纪要〔2019〕2号）意见，经材料审核和实地察看后研究决定，同意由你公司投资筹建“张家港市金宝贝之星幼儿园有限公司（简称：张家港市金宝贝之星幼儿园）”。

张家港市金宝贝之星幼儿园有限公司办园地址在张家港市南湖路与勤星路交界处，属民办营利性全日制幼教机构，隶属杨舍镇人民政府管理。希按照筹建方案，根据“中华人民共和国行业标准托儿所、幼儿园建筑设计规范”、“江苏省优质幼儿园标准”等相关标准实施，待筹建完毕，取得房屋、消防、卫生、食品经营等许可证明，并进行验收评估后再确认是否正式审批，未获正式审批前不得招生。

张家港市教育局

2019年3月25日
