# 张管安办〔2019〕3号关于印发《张家港市石油天然气输送管道风险排查整治专项行动实施方案》的通知

张管安办〔2019〕3号

各油气输送管道企业：

根据《苏州市石油天然气输送管道风险排查整治专项行动实施方案》的通知（苏管安办〔2019〕4号）要求，结合近期国家、省一系列关于安全生产工作的决策部署，全面贯彻落实3月5日苏州全市安全生产工作电视电话会议精神，针对我市管道保护工作现状，市油气输送管道安全生产专业委员会制定了《张家港市石油天然气输送管道风险排查整治专项行动实施方案》，现印发给你们，请遵照执行。
