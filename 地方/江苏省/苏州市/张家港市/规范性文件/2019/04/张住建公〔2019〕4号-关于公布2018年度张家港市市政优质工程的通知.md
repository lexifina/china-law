# 关于公布2018年度张家港市市政优质工程的通知

各市政施工企业：

2019年3月，我局委托市市政协会组成现场检查组，对全市申报的13项张家港市市政优质工程项目进行了现场检查。综合评定南苑东路改造工程一期项目南苑东路东西段改造工程等8项工程为“2018年度张家港市市政优质工程”，现予以公布。希望各获奖单位再接再厉，继续发扬创优精神，进一步加强工程质量管理，努力提高我市市政工程质量水平，为张家港市城市建设作出新的贡献。
