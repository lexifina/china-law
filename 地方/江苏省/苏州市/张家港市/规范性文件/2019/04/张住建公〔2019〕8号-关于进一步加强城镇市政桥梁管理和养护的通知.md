# 关于进一步加强城镇市政桥梁管理和养护的通知

塘桥镇、乐余镇、南丰镇、大新镇人民政府，常阴沙现代农业示范园区管委会，保税区规建局、经开区建设局、冶金工业园规建局、高新区规建局、凤凰镇建设局：

根据《省住房城乡建设厅关于印发城市桥梁安全防护设施隐患排查整治工作方案的通知》（苏建城〔2018〕928号）和《省住房城乡建设厅关于迅速开展住房城乡建设领域安全生产大检查工作的紧急通知》（苏建传〔2019〕6号）、《江苏省住房和城乡建设厅关于印发<江苏省城市桥梁和地下道路养护管理情况评价标准>的通知》（苏建城〔2018〕911号）等文件精神，为进一步提升城镇市政桥梁管理水平，落实桥梁养护工作，保障桥梁安全运行，现将有关事项通知如下：

一、摸清城镇市政桥梁底数。各区镇要对各自建成区范围内（杨舍镇包含城区城中村及开放式小区）的城镇桥梁进行全面排查，摸清底数，填写、完善“城镇桥梁统计表”（附表一），并在此基础上，梳理完成“城镇市政桥梁信息统计表”（附表二）。

二、全面开展城镇市政桥梁安全隐患排查整治。加大城镇市政桥梁安全隐患排查整治力度，对于特大、特殊结构、特殊重要桥梁和老旧桥梁要根据实际情况加大检查频率，必要时对桥梁结构和运行状况开展实时监测，及时发现、处置病害，消除隐患，做到即知即改。对于已评定为隐患桥梁和危桥的，要落实专项资金，明确整治方案，尽快完成加固改造，及时采取限行措施，消除安全隐患。

三、做好城镇市政桥梁安全防护设施隐患排查整治工作。全面排查、摸清桥梁安全管理现状，重点排查防撞护栏、防撞垫、限界结构防撞设施、分隔设施等安全设施，对排查出的安全隐患，限期完成整改。

四、加强城镇市政桥梁信息管理。要按照《城市桥梁养护技术规范》要求，建立“一桥一卡”，并依据桥梁分类，明确桥梁养护等级，落实桥梁检测与评估制度。要将城镇市政桥梁纳入“江苏省城市桥梁信息管理系统”，及时做好基础资料的收集、整理、录入和更新工作，以强化动态监管。

五、严格城镇市政桥梁养护管理。各区镇要根据《江苏省城市桥梁和地下道路养护管理情况评价标准》（苏建城〔2018〕911号）要求，进一步健全城镇市政桥梁养护管理制度，落实监管单位和养护单位，保障养护经费，并严格按照《城市道路交通设施设计规范》（GB50688-2011）、《城市桥梁设计规范》（CJJ11-2011）等标准相关要求，认真做好养护管理工作，把桥梁安全运行措施落到实处，防止出现“失管失养”的现象。

六、相关要求。

1、附表一“城镇桥梁统计表”、附表二“城镇市政桥梁信息统计表”加盖公章后连同分管领导及联络员信息于5月6日前报住建局政务网邮箱。

2、各区镇开展城镇市政桥梁安全隐患排查整治和桥梁安全防护设施隐患排查整治工作的有关情况（包括采取的工作措施、隐患排查及整治情况、下一步工作打算等），要形成书面报告，并于5月30日前报住建局政务网邮箱。

3、5月24日前完成城镇市政桥梁纳入“江苏省城市桥梁信息管理系统”的信息录入工作。
