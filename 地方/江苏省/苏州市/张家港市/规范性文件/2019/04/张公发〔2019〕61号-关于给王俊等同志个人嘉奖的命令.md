# 关于给王俊等同志个人嘉奖的命令

各警署、各派出所、直属各单位、机关各部门：

为表彰先进，鼓舞士气，激励斗志，根据《公安机关人民警察奖励条令》的规定，特命令：给下列6位同志各记个人嘉奖一次，颁发证书和奖金：

1．王 俊，凤凰派出所副所长

2．敖鸿彪，网警大队副中队长

3．蒋小祥，城北派出所民警

4．朱 斌，交警乐余中队副中队长

5．王海龙，妙桥派出所副所长

6．蔡志超，法制大队民警

希望受到表彰的同志谦虚谨慎、戒骄戒躁，珍惜荣誉、再创佳绩。全市公安机关和广大民警要以先进为榜样，在习近平新时代中国特色社会主义思想指引下，深入学习贯彻党的十九大精神，牢记职责使命、锐意奋发进取，全力以赴做好当前各项公安保卫工作，为保障全市社会持续平安稳定、推动张家港公安高质量发展走在最前列作出新的更大贡献！

此令。

公安局长 周斌伟

2019年4月1日

（此件公开发布）
