# 关于进一步明确职工基本医疗保险个人账户用于购买商业健康保险产品有关事项的通知

各有关单位：

根据苏州市《关于城镇职工医疗保险个人账户用于购买商业健康保险的通知》（苏人保医〔2012〕8号）等有关文件、《关于城镇职工医疗保险个人账户用于购买商业健康保险的通知》（张人社规〔2012〕24号）、《关于调整张家港市社会基本医疗保险政策的通知》（张人社发〔2013〕47号）以及《市政府关于印发张家港市社会基本医疗保险实施细则的通知》（张政发〔2017〕42号）的精神，为了规范我市职工医疗保险个人账户购买商业健康保险产品，现对有关事项作进一步明确：

一、对象范围

参保人员医疗保险个人账户往年结余金额超过3000元的部分，可以按照自愿原则购买商业健康保险。

二、使用额度

医疗保险个人账户往年结余金额在3000元（不含）以上、6000元（含）以下的，往年结余金额在6000元（不含）以上的，可分别使用1000元和2000元购买商业健康保险。

三、商业健康保险产品

商业健康保险产品应该符合提高医疗救助力度，减轻参保人员医疗费用负担，与城镇职工基本医疗保险待遇错位发展的基本原则，经过中国银行保险监督管理委员会（原中国保险监督管理委员会）备案，并报张家港市医疗保障局备案。经审核符合条件的列入本市职工基本医疗保险个人账户用于购买商业健康保险的产品目录。

特此通知。
