# 张发改〔2019〕11号关于成立政策性粮食库存数量和质量大清查督导自查领导小组的通知

机关各科室、粮食质量监测站、各相关企业：

政策性粮食库存是维护国家粮食安全的重要物质基础，为全面掌握政策性粮食库存情况，防范化解风险隐患，确保国家粮食储备安全，根据《张家港市政策性粮食库存数量和质量大清查督导自查工作方案》，决定成立政策性粮食库存数量和质量大清查督导自查领导小组。成员名单如下：

组 长：袁政国 市发展和改革委员会主任

龙凤清 市发展和改革委员会副主任（市粮食和物资储备局局长）

副组长：蔡惠良 市发展和改革委员会党组成员（市粮食和物资储备局副局长）

成 员：乔方晖 原粮食局主任科员、监督检查科科长

刘 娟 原粮食局监察审计科科长

项亚杰 原粮食局购销调控科科长

聂 登 市粮食质量监测站副站长

张家港市发展和改革委员会

2019年4月2日
