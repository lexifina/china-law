# 张发改价〔2019〕7号关于下调张家港市居民生活用管道天然气价格的通知

张家港港华燃气有限公司：

根据国家发改委《关于调整天然气基准门站价格的通知》（发改价格〔2019〕562号），从2019年4月1日起将江苏省居民用气基准门站价格从每立方米2.04元调整为2.02元。结合省、苏州市有关要求，经研究，决定对《关于疏导张家港市居民生活用管道天然气价格的通知》（张发改价〔2019〕6号）规定的我市居民生活用管道天然气销售价格作相应下调。现通知如下：

一、下调居民生活用管道天然气销售价格

居民生活用管道天然气销售价格下调0.02元/立方米，调整后居民生活用管道天然气销售价格为每立方米2.75元。按照“阶梯价差保持不变”的规定，居民用气第一、二、三档气价仍然按照1：1.2：1.5的比例安排，调整后居民用气阶梯价格见下表：

对学校、养老福利机构等执行居民气价的非居民用户，不实行阶梯气价，气价水平仍按居民第一、二档气价的加权平均水平确定，销售价格调整为每立方米2.79元。

二、实施范围、执行时间及相关要求仍执行《关于疏导张家港市居民生活用管道天然气价格的通知》（张发改价〔2019〕6号）。

三、请燃气企业加强政策宣传解读和引导，切实将增值税改革的红利全部让利于用户，争取社会各界理解和支持。
