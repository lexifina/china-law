# 张发改价〔2019〕8号关于下调张家港市非居民用管道天然气销售价格的通知

张家港港华燃气有限公司：

根据国家发改委《关于调整天然气基准门站价格的通知》（发改价格〔2019〕562号），鉴于天然气增值税税率调整，从2019年4月1日起，江苏省天然气基准门站价格从每立方米2.04元调整为2.02元。我市非居民用管道天然气销售价格作相应下调，现将有关事项通知如下：

一、非居民用、其他（公用事业）用管道天然气销售价格每立方米下调0.02元。调整后，我市非居民用管道天然气销售价格为每立方米3.105；其他（公用事业）用管道天然气销售价格为每立方米2.925元。

二、实施时间从2019年4月1日起执行。

三、请天然气经营企业认真做好宣传解释、准确抄表、价格结算工作，确保调价政策平稳实施。

张家港市发展和改革委员会

2019年4月3日

（此件公开发布）
