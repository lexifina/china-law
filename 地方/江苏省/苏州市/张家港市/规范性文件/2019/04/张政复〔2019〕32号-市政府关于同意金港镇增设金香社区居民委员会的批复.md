# 市政府关于同意金港镇增设金香社区居民委员会的批复

张政复〔2019〕32号

来源：市政府发布时间：2019-04-23 16:49:00访问量：字体【大中小】

金港镇人民政府：

你镇《关于设立张家港保税区（金港镇）金香社区居民委员会的请示》（金政请〔2019〕5号）收悉。经研究，现批复如下：

一、根据市委、市政府《关于进一步加强城乡社区建设管理的意见》（张委发〔2011〕63号）等文件规定，同意你镇增设金香社区居民委员会。

二、金香社区居民委员会管辖范围：东至张家港河，南至张杨公路，西至江海中路，北至镇山路。

三、你镇要按《居民委员会组织法》等规定建好金香社区居民委员会，并根据区域入住人员规模变化，及时强化人员配备，保障社区用房需要，落实社区建设管理经费，不断提升社区建设管理的内涵和水平。

此复。

张家港市人民政府

2019年4月23日
