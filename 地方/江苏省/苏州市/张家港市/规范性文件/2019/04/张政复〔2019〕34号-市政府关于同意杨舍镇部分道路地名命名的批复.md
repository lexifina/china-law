# 市政府关于同意杨舍镇部分道路地名命名的批复

杨舍镇人民政府：

你镇《关于杨舍镇“新农路”等部分道路命名的请示》（杨政请〔2019〕6号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意对你镇申报的4条新建道路予以命名、1条道路予以更名。具体批复如下：

一、道路命名

1．同意将你镇位于庆安西路东侧，东起庆安社区卫生服务站、西至庆安桥东侧的道路命名为“庆安东路”。地名标志汉语拼音拼写形式：QINGAN DONGLU。

2．同意将你镇位于原庆安村内，东起庆安村11组、西至农鹿南路的道路命名为“寺基弄”。地名标志汉语拼音拼写形式：SIJI LONG。

3．同意将你镇位于乘航桥东侧，东起农鹿南路、西至乘河东路的道路命名为“群丰路”。地名标志汉语拼音拼写形式：QUNFENG LU。

4．同意将你镇位于新农花苑东侧，南起南二环路、北至暨阳湖大道的道路命名为“新农路”。地名标志汉语拼音拼写形式：XINNONG LU。

二、道路更名

同意将你镇位于晨阳社区范围内，南起顺字圩埭、北至晨阳路的“新农路”（地名批准文号：张地办〔2006〕27号）更名为“纯兴路”。地名标志汉语拼音拼写形式：CHUNXING LU。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好道路标志牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2019年4月23日
