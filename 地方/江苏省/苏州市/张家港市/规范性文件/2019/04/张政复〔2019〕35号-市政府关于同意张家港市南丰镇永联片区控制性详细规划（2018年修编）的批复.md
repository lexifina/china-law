# 市政府关于同意张家港市南丰镇永联片区控制性详细规划（2018年修编）的批复

南丰镇政府：

你镇上报的《关于报批张家港市南丰镇永联片区控制性详细规划（2018年修编）的请示》（南政请〔2019〕4号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《张家港市南丰镇永联片区控制性详细规划（2018年修编）》。规划范围：东至红旗路、南至七干河及永南河、西至妙丰公路及永南路、北至泗兴港，规划面积12.69平方公里。

二、要加强与城市总体规划、土地利用规划、南丰镇总体规划等相关规划的有机衔接、融合，深化规划地块发展定位和功能布局研究，协调处理好规划区域与周边区域的关系，统筹安排基础设施和公共服务设施建设，保障土地科学、合理与集约利用。

三、经市政府批准的《张家港市南丰镇永联片区控制性详细规划（2018年修编）》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2019年4月25日
