# 关于举行张家港市第二十一届职业院校师生技能竞赛的通知

各职业院校：

为落实全国、省关于完善技能大赛制度的文件精神，树立“比技能、促质量、谋发展”的教学观念，创新人才培养模式，推进“双师型”教师队伍，结合职教展示月活动要求，经研究，决定举办张家港市第二十一届职业院校师生技能竞赛。现将具体方案通知如下：

一、竞赛主题

关注学生成长  共襄职教成果

二、竞赛组织

本次竞赛由市教育局、市总工会、市人力资源和社会保障局联合主办，由企业赞助冠名。设立竞赛组委会（名单另行公布），组委会办公室设在市教育局职教科。相关事务联络由教研室职教组负责，联系电话：58691081。

三、报名要求

1.项目：竞赛设29个比赛项目，其中10个项目同时为教师参赛（详见附件）。

2.报名

（1）教师参赛项目，必须报足规定人数。学生参赛，必须不低于“至少”参赛人数。

（2）部分项目仅为一校开设专业，需有两位教师分别辅导选手，作为两个学生组参赛。同时邀约校企合作单位，在明确竞赛技术要求前提下，同练同赛。

（3）在2018年1月1日之后未获得苏州市赛一等奖及以上奖项的学生，方可报名参赛。参赛对象不分中职、高职、技工，统一设定为学生组一个级别。

报名截止时间为4月12日（周五）。报名时注明项目所属专业系部（第二职中除外），备注学生班级（报名电子表格另行公布）。

四、竞赛安排

1.部分一校开设专业项目在五月初组织比赛，部分项目将在职教展示月活动中进行展演。

2.教师组项目在5月下旬组织比赛。

3.学生组项目在6月10日—15日之间组织比赛。

五、其他要求

1．教研室做好竞赛集训专项调研，指导学校规划参赛条件，辅助教师做好赛前训练。

2.组委会成立4—6个技术指导小组，每小组设组长一名，技术副组长一名，组员2—3名，协助教研室做好赛前调研，比赛命题、组织、安排.

3.教研室在充分调研基础上，结合学校上报本学年实训内容安排，针对参赛项目所属系部，学生所在班级，与技术指导小组一起，对参赛学生所在班级进行技能抽测，抽测时间为4月15日—5月25日之间，抽测班级（实训项目）数不少于本次参赛学生上报班级总数的30%，抽测学生数不少于班级总人数的30%。具体抽测方案由教研室规划制定。

竞赛组委会将在五月上旬公布技术文件，对竞赛组织与安排作出明确要求。请各院校及早做好集训准备，以关注学生常态实训质量，关注学生学习兴趣入手，积极规划参赛，高质量做好赛前集训。

本次比赛首次引进国际先进赛制的无人机和无人车竞赛项目，请相关学校高度重视、积极参赛，该项目涵盖编程、创建、操控等多项技能，能极大提升学生的逻辑思维能力和临场应变能力，对于响应国家人工智能技术在我市的推广，起着重要的作用。该项目具体的细则将近期下发，总工会也将安排人员对参赛人员进行专项培训。
