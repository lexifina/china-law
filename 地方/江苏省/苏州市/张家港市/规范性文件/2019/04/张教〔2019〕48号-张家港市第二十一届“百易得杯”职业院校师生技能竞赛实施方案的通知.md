# 张家港市第二十一届“百易得杯”职业院校师生技能竞赛实施方案的通知

各职业院校：

根据《关于举行张家港市第二十一届职业院校师生技能竞赛》（张教〔2019〕45号）文件要求，各职业院校已完成项目组建、选手选拔与报名工作。本届竞赛共设立29个项目，除“无人机与无人车”项目需集训指导之后上报，其余28个项目，全市五所职业院校500人报名参赛，其中教师选手70名，学生选手430名，开设项目、参赛人数为历届市级竞赛之最。组委会与参赛学校和有关行业技术协会做了细致沟通，在大量的专项调研、技能抽测基础上，形成本届竞赛实施方案，现公布如下：

一、竞赛组织

1．本届竞赛冠名为“百易得杯”，由江苏百易得医疗科技有限公司提供赞助。

2．成立竞赛组委会，全面负责竞赛整体组织与管理。名单见附件1。

3．由开放大学、中专校、第二职中、第三职中、舞蹈学校分别承办部分项目，各校分管专业技能副校长担任赛点负责人。

二、比赛时间

比赛分三个阶段进行。第一阶段为5月28日（周二）、29日（周三），举行“汽车机电维修”等9个项目学生组，以及部分一校参赛的教师组项目比赛。第二阶段为6月5日（周三），举行剩余教师组项目比赛。第三阶段为6月12日（周三）、13日（周四），举行其余学生组项目比赛。详见《张家港市第二十一届“百易得杯”职业院校师生技能竞赛安排表》（见附件3）。

三、技术说明

1.由组委会统一组织命题。将邀请省市竞赛指导专家、技术平台参与方、行业协会、本市骨干教师参与命题。

2.比赛环境、设备、条件、试题均参照最近省赛方案要求；试题技术难度约等于近年来省赛技术难度的50—60%，比赛用时一般在省赛项目规定用时的70—80%。

3.各竞赛项目技术方案将于赛前二周公布，部分项目比赛环境、备料及工量具清单将同期公开。

4.仅一所学校报名参赛的项目，由学校联系合作企业，以竞赛技术方案为蓝本，在校企合作模式角度预先进行沟通，由企业派出青年员工同题同赛，或选派技术骨干参与项目评分。

四、奖项设置

1.参赛选手奖

以单项参赛人数（组数）的80%设奖；一、二、三等奖数量分别为参赛总数的20%、30%、30%；（获奖选手的成绩必须达到项目最高成绩的50%，否则空缺）。参赛人数（组别）少于5人（组）不设一等奖，仅设二等奖1人（组），三等奖2人（组）；参赛人数少于3人（组）（含3人）不设一、二等奖，仅设三等奖1人（组），颁发奖品与奖状。

2.指导教师奖

对获得一、二等奖选手的指导教师设立指导教师奖。

3.职业资格证书

对应具有职业资格证书的比赛项目，成绩合格（总成绩的60%及以上）者同时颁发中级工职业资格证书。

五、其它安排

1.本次竞赛经费由主办单位、冠名单位共同筹集和承担。

2.本次竞赛不收取参赛费。评委、选手、送赛人员在赛点的用餐由赛点学校统一安排。

3.请各校提前安排好送赛车辆，每个赛点派1名行政蹲点负责，确保师生安全。

4.无人机与无人车项目，组委会将安排第三方专人指导培训，之后再组织报名与比赛。文化艺术类三个项目，参赛学校在5月22日（周三）上报参赛作品名称。
