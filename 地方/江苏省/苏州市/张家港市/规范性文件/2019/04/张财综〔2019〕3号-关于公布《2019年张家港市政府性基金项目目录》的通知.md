# 关于公布《2019年张家港市政府性基金项目目录》的通知

各镇政府，冶金工业园、高新技术产业开发区、常阴沙现代农业示范园区、双山香山旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：

为加强政府性基金管理，根据江苏省财政厅《关于公布2018年江苏省政府性基金项目目录的通知》（苏财综〔2019〕11号）、关于公布《2019年度苏州市政府性基金项目目录》的通知（苏财预〔2019〕30号），结合张家港市实际执行情况，我们编制了《2019年张家港市政府性基金项目目录》（截止2019年4月23日），予以公布。现就有关事项通知如下：

一、本通知发布后，凡未列入《基金目录》的政府性基金项目，我市相关部门应当停止执行，公民、法人和其他社会组织有权拒绝支付。2019年4月23日以后国家和省新增、调整、取消政府性基金等政策，按其文件规定执行，我市财政将动态向社会公布。

二、各部门要严格贯彻落实本通知的规定，认真进行对照清理，取消不合法、不合理的政府性基金项目，对超过规定标准的要坚决予以降低，对扩大范围的行为要予以纠正。

三、本通知发布后，《2018年张家港市政府性基金项目目录》（张财综〔2018〕3号）同时废止。
