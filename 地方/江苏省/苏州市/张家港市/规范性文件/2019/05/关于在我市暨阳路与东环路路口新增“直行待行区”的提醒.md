# 关于在我市暨阳路与东环路路口新增“直行待行区”的提醒

为了缓解我市暨阳路与东环路口交通流量大、早晚高峰期拥堵状况，市公安局交警部门通过实地调查，现将暨阳路东西方向放行方式由原来的先直行后左转变为先左转后直行。同时，为充分利用路口资源，提高路口车辆通行效率，新增了“直行待行区”。

一、什么是“直行待行区”

“直行待行区”是在路口直行车道前端，伸入路口内的区域施划一条或多条直行待行车道作为直行机动车的等候区。

二、“直行待行区”的作用

为了缓解交通压力，提高车辆通行能力，路口设置“直行待行区”可以利用左转信号灯亮起的时间引导直行车辆向前有序移动，提高了路口直行车辆的通行率。

我市暨阳路与东环路路口，东向西、西向东双向直行车道都多出来一段等待区域，路口的道路交通标志牌上标有：左转弯放行时，直行车进入待行区。

三、如何正确进入“直行待行区”？

1、当市民驾车直行通过十字路口遇上红灯时，就可以做好进入“直行待行区”的准备。

2、在左转指示灯变绿左转放行时，直行车辆即可前行到“直行待行区”，等待直行信号为绿灯。

3、当直行信号变为绿灯后，在直行待行区内的车辆就可以直行通过十字路口。

四、交警提醒

设置“直行待行区”只是特殊路口采取的特殊措施。考虑到全市道路交通路口放行特点以及港城驾驶人的驾驶习惯，仅在该一个路口进行尝试和探索，请广大驾驶人行经该路口时注意观察，按照路口的信号灯、交通标志标线指示行驶。
