# 关于印发《张家港市聂凌峰能源科技有限公司新建LNG供应站项目施工图设计文件技术审查意见》的通知

张住建公〔2019〕9号

张家港市联峰能源科技有限公司：

根据《省住房城乡建设厅关于规范城镇燃气设施建设和运行管理工作的若干意见》（苏建规字〔2014〕1号）和《市住房城乡建设局关于开展燃气设施工程施工图专家会审的通知》（苏住建设〔2015〕1号）规定，我局组织有关专家，于2019年5月13日对你单位报审的“张家港市联峰能源科技有限公司新建LNG供应站（项目代号：TXLNG19-005）”的施工图设计文件进行了技术审查。现将专家技术审查意见印发给你们，请你单位会同并督促设计单位按照专家组技术审查意见修改完善设计。修改完成后，对审查意见的回复及变更图纸，须经专家组组长复核确认。同时将有关复审意见及对会审意见的回复，报我局审核。

附件：“张家港市联峰能源科技有限公司新建LNG供应站（项目代号：TXLNG19-005）”施工图设计文件技术审查意见

张家港市住房和城乡建设局

2019年5月15日
