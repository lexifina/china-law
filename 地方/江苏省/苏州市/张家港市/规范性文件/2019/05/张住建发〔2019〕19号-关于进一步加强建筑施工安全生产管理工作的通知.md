# 关于进一步加强建筑施工安全生产管理工作的通知

各镇（区）、相关部门，各建设单位、施工企业、监理企业：

为进一步提升我市建筑施工安全生产管理水平，提高工程安全监管实效，着力构建工程安全生产管理长效机制，确保我市建筑施工安全生产形势持续平稳，根据《省住房和城乡建设厅关于通报扬州市广陵区“4.10”基坑坍塌事故情况和全面落实建筑施工领域重大安全风险隐患防控措施的通知》（苏建质安〔2019〕147号）、《省安全生产委员会办公室关于近期两起建筑施工较大事故情况的通报》（苏安办电〔2019〕11号）文件精神，现将相关工作通知如下：

一、加强从业人员实名制管理

严格执行《市住房城乡建设局关于进一步加强建筑从业人员实名制管理的通知》（苏住建建〔2019〕11号）和《张家港市工程建设领域农民工实名制管理实施细则》（张住建规〔2017〕1号）等相关规定，全面推进受监工程实名制管理，对施工和监理企业的项目管理人员及现场作业人员进行实名制考勤，强化对施工现场主要管理人员到岗履职的监管。对实名制管理工作不达标、到岗率不符合要求的，取消该工地参与各类优质工程、标准化星级工地、示范监理项目等评选资格，在施工和监理企业动态考评中扣分，并视情节给予企业和相关人员信用扣分、通报批评、不良行为记录等惩戒措施。在工伤保险理赔过程中，市住建局安监站根据平台录入的人员信息进行证据采集，如因人员信息缺失而影响工伤认定和待遇支付的，由相关施工等单位自行承担责任。

二、强化施工企业动态考评结果应用

修订完善全市施工企业动态考评办法，突出施工现场管理，统一考评标准，涵盖工程安全（35%）、质量（35%）和市场行为（30%）三个方面的主要内容，努力推动考评结果与市场准入、预选承包商、信用评价的联动。试行动态考评得分与工程招投标业绩得分直接挂钩，即将各施工企业半年度动态考评得分与全市同类施工企业半年度平均动态考评得分的分差按10%折算后的分数，计入施工企业动态考评业绩得分（未考评企业不得分）。施工企业动态考评业绩得分的加分上限为1.5分，超过1.5分的按1.5分计算，计分结果小数点后保留两位（四舍五入）。评标办法采用经评审的最低投标价法、合理低价法及综合评估法的招标项目，招标人应将施工企业动态考评业绩得分作为评审因素单列，并在招标文件中予以明确。采用有限数量制进行资格预审的招标工程，招标人如在“有限数量制资格预审办法”中已经使用施工企业动态考评结果的，在评标过程中不再另行加（减）分。专业承包施工企业动态考评业绩得分另行发文规定。

三、健全对行业违法违规行为的联合惩戒制度

采取定期考评、专项检查、重点抽查相结合的方式，加大对工程转包、违法分包、挂靠、违法发包等违法违规行为的查处，一经发现即依法严肃处理，并视情节给予不良行为记录、通报直至限制市场准入或清出市场。加快构建行业诚信体系，按照《全国建筑市场各方主体不良行为记录认定标准》《全国建筑市场注册执业人员不良行为记录认定标准》，对建筑市场各方主体、注册执业人员的不良行为进行认定记录。建立安全隐患和事故责任企业、个人联合惩戒制度，并视情节和不同等级风险隐患实施阶梯处理，予以通报、限制市场准入或清出市场，抄报省住建厅建议暂扣其安全生产许可证。

突出项目经理和项目总监安全质量违法违规行为记分管理，统一记分尺度和运用。

1.根据《建筑施工项目经理质量安全责任十项规定（试行）》中建筑施工项目经理质量安全违法违规行为记分管理规定的相关要求，严肃查处项目经理质量安全违法违规行为，并进行记分。项目经理在一个记分周期（12个月）内，累积记分超过6分的，相关部门对其负责的工程项目实施重点监管,增加监督执法抽查频次；累积记分达到12分的,相关部门依法责令该项目经理停止执业1年；情节严重的,建议有权部门吊销执业资格证书，5年内不予注册；造成重大质量安全事故的，终身不予注册。项目经理在停止执业期间,应当接受主管部门组织的质量安全教育培训，其所属施工单位应当按规定程序更换符合条件的项目经理。

2.根据《建设工程项目总监不良行为记录和管理办法（试行）》，总监业绩考评在一年度中累计被扣分值达到6分的，对其不良行为予以记录，给予诫勉谈话并组织强制性培训；扣分值达到12分的，对其不良行为予以记录，暂停从业1年；扣分值达到20分的，抄报省建设厅，并建议注销其注册资格。各企业总监的平均得分作为监理企业的行为得分，并作为综合考评的主要依据。

四、拓展和创新施工现场安全生产监管

1.加强施工现场安全教育培训。施工现场设置安全文明教育宣讲台、安全自查镜等，督促施工企业开展岗前安全培训教育和安全技术交底，落实企业主要负责人、项目负责人、安全管理人员和特种作业人员持证上岗制度。强化施工企业“三类人员”安全生产知识继续教育，提高全员素质和安全生产意识。督促施工企业对照“三违”现象清单开展自查自纠，及时制止和查处违章指挥、违章作业、违反劳动纪律的行为。项目建设期间，建设单位负责人、项目经理、总监、安全员每月定期组织开展安全生产总结部署会议，并做好视频记录，市住建局将不定期抽查安全生产会议台账及视频资料。

2.开展高处坠落事故专项防治。督促工程参建各方严格执行《建筑施工安全检查标准》（JGJ59-2011）、《建筑施工高处作业安全技术规范》（JGJ80-2016）等国家规范标准，结合工程特点编制高处作业专项施工方案，加强高处坠落风险控制。加强对安全防护用品配备、使用情况的检查，突出临边、洞口等易发高处坠落事故部位防护措施的落实，不断提高安全防护标准化、工具化、定型化水平。对各类防护措施未保障的责任单位、责任人进行通报批评，严格按照相关规定对责任单位和责任人予以处罚，情节严重的抄报省住建厅，暂扣其安全生产许可证30日。发生亡人事故的项目立即全面停工，建设单位组织各方责任主体开展自查自纠，全面排查消除安全隐患，自查合格后报市住建局履行复工程序后方可复工。

3.推进建筑工地信息化管理。开展标准化安全管理，试点数字化工地、智慧工地。全市建筑面积5000平方米以上房屋建筑工程均应安装使用视频监控系统，并与智慧工地系统联网，保证规定点位的视频画面能在项目现场办公室、监管部门办公PC端播放。项目现场办公室PC端必须保存各点位至少1个月的视频录像，否则取消项目和企业各类评优评先资格。视频监控点布置原则上要求覆盖整个施工现场，监控点数量要同时满足扬尘和安全监控需要，视频监控点安装位置应选取反映整个项目施工情况的最合理位置，应能显示重大危险源和工程主体的施工状况。主要安装位置如下：工程项目主要出入口处、工程运输车辆冲洗处、工程最高点（塔机顶端）、重大危险源、安全宣讲台、生活区、加工区等部位。在使用过程中，项目部应做好监控设备的维保工作，发现故障应及时采取措施进行排查，恢复视频监控系统正常运行。

房屋建筑面积5000平方米（市政等工程占地20000平方米）以上的在建工程需安装PM10、噪声等工地扬尘在线监测设备，并与生态环境主管部门联网。施工单位应购买和使用符合标准的工地扬尘在线监测设备，全面负责扬尘在线监测设备的安装、调试和使用，确保系统正常运行并将数据实时传输至属地生态环境部门管理平台。

凡项目部故意污损设备、断网或采取其它手段影响视频监控和在线监测系统正常运行的，一律责令停工整改、通报，取消项目和企业的所有评优评先资格，有关企业及其责任人予以不良行为记录。

4.压实建设单位安全生产责任。对房地产开发和政府投资工程业主单位实行安全生产责任承诺制度，严禁未报先建、违法发包，严格控制低价中标，不得指令施工企业盲目抢工期、赶进度，确保安全文明措施费用保障到位，对未落实上述承诺的建设单位，予以不良行为记录、通报，存在违法违规行为的，从严查处。凡属房地产开发企业的，暂缓核发楼盘预售许可或下一个开发楼盘的施工许可；凡属政府投资工程业主单位的，暂缓核发下一个项目施工许可。

5.充分发挥监理单位项目管理作用。监理单位应当结合危大工程专项施工方案，编制监理实施细则，并对危大工程施工实施专项巡视检查。监理单位发现施工单位未按照专项施工方案施工的，应当要求其进行整改；情节严重的，应当要求其暂停施工，并及时报告建设单位。施工单位拒不整改或者不停止施工的，监理单位应当及时报告建设单位和建设行政主管部门。

本通知自2019年5月1日起实施。
