# 关于印发张家港市住房和城乡建设局扫黑除恶工作制度的通知

局机关各科室、下属各单位：

为进一步贯彻落实扫黑除恶专项斗争，建立健全扫黑除恶专项斗争长效工作机制，高效推进扫黑除恶专项斗争深入开展，经研究决定，制定如下扫黑除恶工作制度，现印发给你们，请认真贯彻执行。

附件1：张家港市住房和城乡建设局扫黑除恶协作协商通报联

动制度；

附作2：张家港市住房和城乡建设局扫黑除恶线索管理制度；

附件3：张家港市住房和城乡建设局扫黑除恶保密工作制度；

附件4：张家港市住房和城乡建设局扫黑除恶督查通报制度。

张家港市住房和城乡建设局

2019年5月5日

（此件公开发布）

附件1

张家港市住房和城乡建设局扫黑除恶协作协商通报联动制度

为充分发挥建设系统有关单位的职能作用，进一步加强部门间协同作战，实行协作协商通报联动制度。

1.市住建局扫黑除恶专项工作领导小组办公室（以下称局扫黑办）负责具体业务，并与省住建厅、苏州市住建局、市扫黑办、市公安局进行联系，相关科室、下属单位应积极配合，协作联动。

2.局扫黑办主要工作任务是传达学习贯彻上级关于扫黑除恶专项斗争的工作决策部署等；定期通报市住建局扫黑除恶专项斗争的有关工作进展情况；分析研究市住建局扫黑除恶专项斗争的工作形势，协调解决工作中存在的问题；研究其他需要解决的问题。

3.各科室、各下属单位每周五向局扫黑办报送本周扫黑除恶工作开展情况及下周工作安排，每月召开一次扫黑除恶专项斗争领导小组成员会议，推进扫黑除恶专项斗争相关工作，通报前一阶段扫黑除恶工作落实情况。

附件2

张家港市住房和城乡建设局扫黑除恶线索管理制度

1.线索收集。各科室、各下属单位应当全面收集所管辖领域内涉黑涉恶犯罪线索。收集涉黑涉恶犯罪线索的渠道包括：群众通过电话、信函、网络举报、媒体报道曝光；犯罪嫌疑人自首；督查、检查过程中发现的违法犯罪行为；上级机关批转交办；领导批办；相关单位或其他部门执法执纪中发现的违法犯罪行为等。

2.线索转办。对收集的线索，各单位要建立《涉黑涉恶线索登记册》和《涉黑涉恶线索移交台账》，对收集所有线索当日统一登记，逐一填写呈阅单，1个工作日内提出拟处理意见，次日内转办，3个工作日内完成移交，各单位要指定一名案件线索管理专员，负责线素的收集和移交。

3.线索移交。部门在开展工作中发现有关涉黑涉恶犯罪线索，由各部门提出拟办意见，在3个工作日内将《涉黑涉恶线索移送单》及有关证据、证明材料复印件等相关材料呈分管领导审批后移交至局扫黑办。局扫黑办收到相关材料后，应在1个工作日内呈单位主要领导审阅，经领导审阅后，最迟不超过2个工作日报送苏州市住建局和市扫黑办。发现有涉黑涉恶党员干部、黑恶势力“保护伞”或涉黑涉恶案件背后的腐败问题等有效线索的，局扫黑办应在3个工作日内将《涉黑涉恶线索移送单》及有关证据、证明材料复印件等一并移送派驻纪检监察组。

4.线索责任追究。对泄露、扩散与案件线索有关的信息、资料；向涉案人员通风报信；压、漏、改或擅自处理案件线索；利用案件线索对有关人员进行敲诈勒索或接受宴请、财物等；未经领导批准向其他部门和个人提供线索材料；因移交不及时致使案件线索漏报的，根据情节轻重，给子相应纪律处分，构成犯罪的，移送司法机关追究法律责任。

附件3

张家港市住房和城乡建设局扫黑除恶保密工作制度

1.文件流转保密。所有文件，特别是涉密文件，在收发、传递送阅、打印、办理、保管、归档过程中，必须建立明确的责任制，防止文件丢失和发生泄密事件，极密文件要按规定的范围阅读和传达，不经批准，不许随意扩大范围，未经有关领导批准，不得转发、打印和复印机密文件。

2.档案资料保密。办公室的文书档案统一由专人进行管理。

3.会议工作保密。扫黑除恶专项斗争领导小组及其办公室和专项工作办公室召开的各种会议，凡涉及党和国家秘密以及有关事项不能公开的，都应保密。会议作出的决定和讨论中涉及保密事项的，除由有关部门和人员进行传达办理外，其他人员不得在正式公布会议内容之前向外透露。

4.情报信息保密。检举、揭发科级以上党政领导干部或科级以上党政领导班子中党政领导干部的重要问题的有关事项；未公布的正在立案查处的重要违纪案件的具体案情；市扫黑除恶专项斗争相关部门查办的涉黑涉恶案件的决策、方案和案件材料，均为秘密级事项工作。信访举报材料列入密级管理，个人不得擅自携带外出或者复制、拍摄、翻录。

附件4

张家港市住房和城乡建设局扫黑除恶督查通报制度

一、督查范围

局各科室、下属各单位。

二、督查内容

1.扫黑除恶专项斗争会议精神传达情况、宣传发动情况。

2.本部门、单位管辖行业领域扫黑除恶专项斗争工作开展情况。

3.涉黑涉恶线索摸排、管理、移交情况。

4.制定周扫黑除恶工作总结及周扫黑除恶工作安排情况。

三、督查方法

1.集中督查。每季度对各部门、单位以及管辖行业领域开展扫黑除恶专项斗争情况开展一次集中督查。

2.随机抽查。对涉及群众利益的重点行业领域、区域，不预先通知、不预定单位、不定期地开展抽查，加强对扫黑除恶工作任务执行过程和落实情况的督促指导。

3.调研查访。根据局扫黑办及市扫黑办的要求，采取座谈交流研讨、发放问卷调查表、测评表、征求意见表等多种形式，深入基层掌握实情、听取意见，总结经验、查找问题，分析原因、研究对策，为破解难题、推动创新提供理论支持和实践依据。

四、结果应用

1.沟通反馈。督查组应向被督导单位及时反馈督导工作情况，肯定好的经验做法，指出存在主要问题，提出整改意见和建议，加强沟通协调，督促指导各部门、单位做好扫黑除恶专项斗争工作，并对整改落实情况进行跟踪回访。

2.绩效运用。督查和问题整改情况作为重要内容纳入年度考核，并作为日常考评和推优评先的重要依据之一，真督实查、形成常态。

3.责任追究。对在督导巡查和明察暗访中，同一项工作2次被通报批评的，将对具体责任人进行约谈；3次以上被通报的，主要负责人在年终考核中不得评先评优；对敷衍塞责、弄虚作假、落实不力情节严重或造成不良影响的，严肃问责；涉嫌违纪的线素和作风方面的突出问题，接照管理权限移交有关部门进行处理。
