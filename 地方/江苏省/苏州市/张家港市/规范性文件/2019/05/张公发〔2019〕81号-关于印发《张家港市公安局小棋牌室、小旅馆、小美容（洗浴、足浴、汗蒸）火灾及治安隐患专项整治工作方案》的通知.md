# 关于印发《张家港市公安局小棋牌室、小旅馆、小美容（洗浴、足浴、汗蒸）火灾及治安隐患专项整治工作方案》的通知

各警署、各派出所、直属各单位、机关各部门：

现将《张家港市公安局小棋牌室、小旅馆、小美容（洗浴、足浴、汗蒸）火灾及治安隐患专项整治工作方案》印发给你们，请认真遵照执行。

张家港市公安局

2019年5月13日

（此件公开发布）

张家港市公安局小棋牌室、小旅馆、小美容（洗浴、足浴、汗蒸）火灾及

治安隐患专项整治工作方案

为进一步整顿小棋牌室、小旅馆、民宿以及洗浴、足浴、汗蒸经营市场，遏制无照棋牌室、黑旅馆、非法民宿的增长势头，防止洗浴、足浴、汗蒸行业成为涉黄涉娼的滋生土壤，防止棋牌室成为赌博滋生土壤，同时也为消除火灾隐患，保障群众生命财产安全，进一步巩固“331”专项行动整治成果。经张家港市公安局研究决定，结合“扫黑除恶专项斗争”和全市整治“九小场所”及小微企业火灾隐患专项行动方案，现在起至年底，市局将全面启动小棋牌室、小旅馆、小美容（洗浴、足浴、汗蒸）专项整治工作，切实加小旅馆、小美容（洗浴足浴汗蒸）消防和治安管控力度，全力压降棋牌室赌博警情和旅馆、洗浴、足浴、汗蒸行业涉娼警情，确保火灾隐患显著降低。

一、目标任务

1.全面摸清小棋牌室、小旅馆、小美容（洗浴、足浴、汗蒸）场所火灾隐患底数，开展彻底的集中排查整治，确保全市331专项行动成果更加巩固，确保全市火灾隐患显著降低，确保全市火灾形势稳定好转。

2.小区住宅、车库内无照棋牌室数量大幅减少，黑旅馆、非法民宿得到取缔，无证旅馆和棋牌室增长势头得到有效控制。住宅、村民自建房改作棋牌室、旅馆、洗浴、足浴、汗蒸得到全面整顿。

3.取得营业执照的棋牌室和小美容(洗浴、足浴、汗蒸)场所和已取得特种行业许可证的小旅馆治安、消防硬件设施全面达标，业主依法规范经营意识不断增强。

4.棋牌室赌博、扰民，小旅馆未履行实名登记，洗浴、足浴、汗蒸行业涉黄涉娼等突出治安问题得到有力打击，棋牌室警情和卖淫嫖娼警情呈持续下降态势。

二、工作措施

1.调查摸底。市局将结合本地实际开展排查工作，全面摸清辖区棋牌室、小旅馆（凡对外营业、接待旅客住宿的的旅馆、黑旅馆、民宿、网约房等床位数小于50张的场所）以及小美容（建筑面积较小的洗浴、足浴、汗蒸的场所）的数量和信息，确保全面见底。全面掌握经营业主信息、房屋所有人、安全责任人身份信息及电话、房屋性质（住宅和非住宅）、建筑面积、棋牌桌数、床位数、包厢数量、存在的治安和消防隐患，并依据各辖区实际及时组织对小旅馆、小美容（洗浴、足浴、汗蒸）进行专项清理整顿，特别是棋牌室要重点梳理小区住宅、车库内开设的无照棋牌室，并结合辖区赌博警情分布确定1—2个重点整治地区和3-5家重点整治棋牌室。排查情况填写《小棋牌室排摸登记表》、《棋牌室汇总表》、《棋牌室整治重点一览表》。2.开展全面安全检查。市局将对辖区内小棋牌室、小旅馆、小美容（洗浴、足浴、汗蒸）治安、消防硬件设施开展安全大检查。对照《江苏省特种行业治安管理条例》、《江苏省公共场所治安管理条例》等相关法律法规和“331”整治火灾隐患专项行动

实体化工作专班印发的《全市整治“九小场所”及小微企业火灾隐患专项行动方案》的要求，规范其硬件设施。对治安、消防硬件设施不合格的，坚决责令限期改正，给予警告;整改不到位的，坚决停业整顿。

3.加大宣传教育。与辖区内各小棋牌室、小旅馆、小美容（洗浴、足浴、汗蒸）分别签订《棋牌室规范经营承诺书》、《旅馆业治安责任书》、《娱乐服务场所治安管理责任书》，由棋牌室

经营人填写《棋牌活动室经营情况自述材料》，对黑旅馆、民宿签订《无证无照旅馆经营业主告知书》，并对业主开展法制宣传，告知无照经营及聚众赌博的法律后果和开展火灾隐患专项整治的重要性和必要性，大力营造整治氛围。

4.开展全面清理整治整改。对属于无证无照经营但符合领取营业执照、特行证条件或者相关备案手续的，限期办理相关证照和备案；不符合领照条件或在规定期限内未办理相关证照、备案的，依法处理。对检查中发现不属于本部门管理问题，将及时抄送相关行政执法部门由其依法查处，对赌博、扰民的棋牌室，不履行实名登记的旅馆，经告知仍非法经营的黑旅馆和民宿、涉黄涉娼的洗浴、足浴、汗蒸场所，将依据《中华人民共和国治安管理处罚法》、《江苏省公共场所治安管理条例》、《江苏省特种行业治安管理条例》等相关法律规定进行治安和行政处罚，构成违法犯罪的，依法追究刑事责任。对排查发现的火灾隐患场所，坚决及时整改；对不能立即整改及拒不整改的火灾隐患场所，坚决停产停业停租并持续跟进落实整;对拒不停产停业停租、拒不纠正的火灾隐患场所及火灾隐患严重且拒不整改的责任人，坚决

追究法律责任;对因不落实主体责任而被采取停产停业等措施的场所房东及经营人，全部纳入信用“黑名单”，实施失信联合惩戒，通过持续高压，确保完成整治行动目标任务。
