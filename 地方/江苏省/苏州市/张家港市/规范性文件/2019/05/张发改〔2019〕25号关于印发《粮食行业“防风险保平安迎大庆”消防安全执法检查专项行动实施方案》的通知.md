# 张发改〔2019〕25号关于印发《粮食行业“防风险保平安迎大庆”消防安全执法检查专项行动实施方案》的通知

张发改〔2019〕25号

机关各科室、粮食质量监测站，粮食购销总公司、吉泰贸易有限公司、各粮油购销有限（责任）公司：

根据国务院安委办和省、市消防办统一部署及我市消防办制定的《全市“防风险保平安迎大庆”消防安全执法检查专项行动工作方案》，结合我市粮食行业的实际，制定了《粮食行业“防风险保平安迎大庆”消防安全执法检查专项行动实施方案》，现印发给你们，请认真落实，确保工作取得实效。

附件：粮食行业“防风险保平安迎大庆”消防安全执法检查专项行动实施方案

张家港市发展和改革委员会

2019年5月10日
