# 张发改〔2019〕27号关于做好夏粮收购期间安全生产工作的通知

机关各科室、粮食质量监测站，粮食购销总公司、各粮油购销有限（责任）公司：

紧张的夏粮收购工作即将开始，为认真贯彻落实上级部门有关安全生产工作的文件精神，切实保障夏粮收购期间的安全生产，确保夏粮收购工作顺利进行，现就有关事项通知如下：

一、加强领导，完善夏粮收购期间的安全生产保障机制。单位主要负责人要组织召开一次安全生产形势分析会，并开展一次收购前安全生产检查工作；要制定收购期间安全生产工作方案，明确分工，落实责任；在收购期间，各单位要加强值班制度和巡查制度，及时发现并整改安全隐患；总公司要在每个库点设立安全监督员，负责现场车辆指挥和纠察违章行为；要协调相关部门做好收购现场秩序维护工作，防止出现群体性事件。机关要组织开展一次安全生产大检查，对各单位夏粮收购准备情况进行检查；机关职能科室要加强与气象、水利等部门的沟通协调，注意收集降水、雷电、水文等基础资料，深入分析影响夏粮收购安全生产的不利因素，加强预警预报工作，及时指导企业做好防范工作；收购期间，各分管领导和机关工作人员要加强检查频率，现场检查指导工作时，要将安全生产工作作为重要检查内容，及时提醒企业做好安全生产工作。各级人员在收购期间，要保持通信畅通，发生事故要及时上报，并及时落实应急预案。

二、规范操作，切实做好夏粮收购期间的安全生产工作。各单位要加强设备的检查与维护，认真开展岗前安全生产和业务培训，严格按规程作业，防范设备伤人事故发生。要加强用电管理，定期检查输电线路和电器设备的运行状况，坚决纠正不良用电习惯，防止出现人员触电和因电火灾事故。要严格按设计标准和程序入仓装粮，严禁超标准、不对称装粮。要加强对满仓状态的老旧仓房的检查，防止发生仓房倒塌事故。要加强收购现场运输车辆管理，防止车辆伤人事故发生。要重视职工职业健康，注意合理安排工作，防止因疲劳发生人为安全生产事故。

三、因地制宜，认真开展安全生产宣传工作。夏粮收购期间，正值全国第十八个、全省第二十六个“安全生产月”活动，各单位要认真开展以“防风险、除隐患、遏事故”为主题宣教活动。粮食购销总公司要在各骨干库悬挂2019年“安全生产月”活动宣传横幅、张贴宣传画。其他单位或库点，也要利用宣传栏或黑板报、张贴宣传标语等形式进行宣传。

四、严格措施，切实做好储粮化学药剂管理工作。夏粮入库后，要及时做好粮食保管工作。在粮食熏蒸过程中，各单位要严格对储粮化学药剂采购、运输、储存的管理，切实防止储粮化学药剂丢失、自燃、爆炸等安全事故的发生。进行熏蒸作业前，必须制定熏蒸作业方案，要对各类熏蒸作业事故的应急处置做出安排，并报市局备案。进行熏蒸作业时，应在作业区域设立警告标识，并严格按程序，由有资质的人员实施作业，防止人员中毒、火灾、爆炸等事故发生。
