# 张发改价〔2019〕10号关于公交28路票价的批复

张家港市港城公共交通有限公司：

你公司《关于28路公交线路优化的请示》收悉。由于线路优化调整，公交28路站点设置发生变化，根据《关于印发〈张家港市公共汽车客运价格管理实施细则〉的通知》（张价规〔2012〕1号）精神，重新核定其票价如下：

一、调整后的行驶路线和站点：

28路行驶路线（西线）：

汇金中心首末站—东苑路—人民东路—人民中路—人民西路—国泰中路—暨阳西路—永安路—暨阳湖大道—港城大道—新泾西路—新泾中路—南湖路—北庄路—暨阳湖大道—华昌路—东苑路—沙洲东路—老宅路—人民东路—东苑路—汇金中心首末站（东线反之）；

28路途经站点：

汇金中心首末站、勤丰苑、东渡大厦、检察院、电视大学、市政府、国贸酒店、世纪广场、广电大厦、邮政局、君悦大厦、悦丰新村、杨舍实验学校、人民保险、悦盛花苑东门、第一人民医院南门、万红五村、清水湾东、西湖苑东、暨阳湖大道长安路口、蓝湖湾、镜湖公园、暨阳湖金融街、旺西花苑、新泾西桥（东线）、新泾路港城大道口、新泾路紫荆路口、苏园北门、新泾路南湖路口、南湖路新泾路口、中联铂悦、凤凰台、暨阳湖实验学校、暨阳湖大道河西南路口、客运站、交运时代广场、帝景豪园东门、儿童福利院、梁丰生态园北门（东线）、民丰苑、教育服务中心、图书馆、文化中心北、汇金中心首末站。

二、票价：28路全程票价为1元/人。

三、你单位应按规定做好线路的明码标价、优惠政策落实和优质服务工作。

张家港市发展和改革委员会

2019年5月27日
