# 关于印发2019年度城管局文明城市创建迎检任务分解表的通知

机关各科室，执法大队、数字化城管、市容管理处，路灯管理所，各执法中队：

为全面深入推进我市创建文明城市工作，根据市文明办《文明指数测评单位责任分解》，制定了《2019年度城管局文明城市创建迎检任务分解表》。现印发给你们，请按照任务要求抓好落实。督查专班要跟进开展专项督查，对问题整改落实不力或上级实地检查考核中被通报问题的将严肃问责。

张家港市城市管理局

2019年5月17日

（此件公开发布）

2019年度城管局文明城市创建迎检任务分解表

执法大队：责任条目总数：40

1.主次干道

（1）无小广告乱张贴、乱涂写、乱挂晒、乱搭建等现象，饭店无露天烧烤现象；

（2）主干机动车道无被侵占现象，人行道、非机动车道无被违规占用现象，盲道、缘石坡等无障碍设施无被侵占现象；

（3）公共场所文明有序，无乱扔杂物、随地吐痰、损坏公共设施(路灯、垃圾箱、中转站等)、宠物粪便不及时处理、躺卧公共座椅现象及其他不文明行为；

（4）无违章停车（机动车、非机动车）现象、无停车乱收费现象；

（5）对经营性公共场所管理规范有序，无店外经营、占道经营、路边设摊等现象；

（6）无城管人员粗暴野蛮执法现象；

（7）户外广告用字规范，无陈旧破损的户外广告（楼顶、灯箱等）、无乱设广告牌和单位铭牌现象。

2.商业大街

（8）无小广告乱张贴、乱涂写、乱挂晒、乱搭建、乱设广告牌等现象,饭店无露天烧烤现象；

（9）主干机动车道无被侵占现象，人行道、非机动车道无被违规占用现象，盲道、缘石坡等无障碍设施无被侵占现象；

（10）公共场所文明有序，无乱扔杂物、随地吐痰、损坏公共设施(路灯、垃圾箱等)、宠物粪便不及时处理、躺卧公共座椅现象及其他不文明行为；

（11）无违章停车（机动车、非机动车）现象、无停车乱收费现象；

（12）对经营性公共场所管理规范有序，无店外经营、占道经营、路边设摊等现象；

（13）无城管人员粗暴野蛮执法现象；

（14）无播放高音喇叭招揽顾客现象；无盯人拉客，盯人散发小广告现象；

（15）户外广告用字规范，无陈旧破损的户外广告（门头、竖式灯箱等）；

3.背街小巷

（16）无小广告乱张贴、乱涂写、乱堆放、乱挂晒、乱设广告牌等现象；

（17）公共场所文明有序，无乱扔杂物、随地吐痰、损坏公共设施(路灯、垃圾箱等)、宠物粪便不及时处理、躺卧公共座椅现象及其他不文明行为；

（18）无违章停车现象、无停车乱收费现象；

（19）对经营性公共场所管理规范有序，无店外经营、占道经营、路边设摊等现象；

（20）无城管人员粗暴野蛮执法现象；

（21）户外广告用字规范，无陈旧破损的户外广告（楼顶、灯箱等）；

4.公共广场

（22）无小广告乱张贴、乱涂写、乱堆放、乱挂晒、乱设广告牌等现象；

（23）公共场所文明有序，无乱扔杂物、随地吐痰、损坏公共设施(路灯、垃圾箱等)、宠物粪便不及时处理、躺卧公共座椅现象及其他不文明行为；

（24）无违章停车（机动车、非机动车）现象，无停车乱收费现象；

（25）无占道经营现象、乱设流动摊点等现象；

（26）无城管人员粗暴野蛮执法现象；

5.景区（公园）景点

（27）无城管人员粗暴野蛮执法现象；

6.长途汽车站

（28）无城管人员粗暴野蛮执法现象；

7.公交车站

（29）无小广告乱张贴、乱涂写、乱设广告牌等现象；

（30）公共场所文明有序，无乱扔杂物、随地吐痰、损坏公共设施(垃圾箱等)、宠物粪便不及时处理、躺卧公共座椅现象及其他不文明行为；

（31）无城管人员粗暴野蛮执法现象；

（32）经营性公共场所管理规范有序，无占道经营；

8.农贸（集贸）市场

（33）无违章停车（机动车、非机动车）现象、无停车乱收费现象；

（34）无城管人员粗暴野蛮执法现象；

9.中小学及周边环境

（35）周边200米内无流动摊贩；

10.建筑工地（围挡）

（36）运输渣土车辆驶出工地时无渣土抛洒现象；

11．居民小区（开放式）

（37）环境卫生干净整洁，无乱扔杂物、无随地吐痰现象；

（38）无乱张贴、乱涂写、乱堆杂物，无乱搭乱建现象；

12.户外广告

（39）督促有电子显示屏等相关载体的单位（部门）发布公益广告不低于50%；

（40）查处未经审批设置广告；

市容管理处：责任条目总数：28

1.主次干道

（1）环境卫生干净整洁，垃圾清运及时、有分类收集垃圾箱；

（2）公共场所无损坏公共设施(垃圾箱、中转站等)；

（3）每隔500米至少有1处公共卫生间的指示牌；公共卫生间保洁及时，无明显异味；出入口设有轮椅通道、扶手或缘石坡道等无障碍设施；至少有1个方便残疾人、老年人、伤病人或孕妇儿童使用的带扶手的坐便器或蹲便器；

（4）隶属河道内无垃圾、杂物、蓝藻；

2.商业大街

（5）环境卫生干净整洁，垃圾清运及时、有分类收集垃圾箱；

（6）公共场所无损坏公共设施(垃圾箱等)；

（7）每隔500米至少有1处公共卫生间的指示牌；公共卫生间保洁及时，无明显异味，出入口设有轮椅通道、扶手或缘石坡道等无障碍设施；至少有1个方便残疾人、老年人、伤病人或孕妇儿童使用的带扶手的坐便器或蹲便器；

（8）隶属河道内无垃圾、杂物、蓝藻；

3.背街小巷

（9）环境卫生干净整洁，垃圾清运及时、有分类收集垃圾箱；

（10）公共场所无损坏公共设施(垃圾箱等)；

（11）公共卫生间保洁及时，无明显异味，出入口设有轮椅通道、扶手或缘石坡道等无障碍设施；至少有1个方便残疾人、老年人、伤病人或孕妇儿童使用的带扶手的坐便器或蹲便器；

（12）隶属河道内无垃圾、杂物、蓝藻；

4.公共广场

（13）环境卫生干净整洁，垃圾清运及时、有分类收集垃圾箱；

（14）公共场所无损坏公共设施(垃圾箱等)；

（15）每隔500米至少有1处公共卫生间的指示牌；公共卫生间保洁及时，无明显异味，出入口设有轮椅通道、扶手或缘石坡道等无障碍设施；至少有1个方便残疾人、老年人、伤病人或孕妇儿童使用的带扶手的坐便器或蹲便器；

（16）隶属河道内无垃圾、杂物、蓝藻；

5.公交车站

（17）环境卫生干净整洁，垃圾清运及时、有分类收集垃圾箱；

（18）公共场所无损坏公共设施(垃圾箱等)；

6．居民小区（开放式）

（19）垃圾箱（桶）完好、整洁、密闭，垃圾箱房周围无垃圾散落、污水外溢现象；

（20）装修垃圾、大件垃圾、绿化垃圾规范管理，无混入生活垃圾现象；

（21）垃圾实现分类投放和驳运；

（22）小区路面无宠物粪便；

7.城区河道保洁（隶属）

（23）河道内无垃圾、杂物；

8.室外公共厕所

（24）出入口设有轮椅通道、扶手或缘石坡道等无障碍设施；

（25）至少有1个方便残疾人、老年人、伤病人或孕妇儿童使用的带扶手的坐便器或蹲便器；

（26）配套设施完好；

（27）无乱张贴、乱涂写现象；

（28）保洁及时，无明显异味；

路灯管理所：责任条目总数：7

1.主次干道

（1）公共场所无损坏公共设施(路灯等)；

（2）路灯装灯率100%，亮灯率≥99%；

2.商业大街

（3）公共场所无损坏公共设施(路灯等)；

（4）路灯装灯率100%，亮灯率≥99%；

3.背街小巷

（5）公共场所无损坏公共设施(路灯等)；

（6）路灯装灯率100%，亮灯率≥95%；

4.公共广场

（7）公共场所无损坏公共设施(路灯等)；
