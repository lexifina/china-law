# 市政府关于同意凤凰镇部分道路地名命名的批复

凤凰镇人民政府：

你镇《关于对凤凰镇部分道路进行命名的请示》（凤政请〔2019〕9号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意对你镇申报的5条新建道路予以命名、3条道路起止点予以调整。具体批复如下：

一、新建道路

1．同意将你镇位于汤桥路东侧，南起镇北路、北至汤桥路的道路命名为“孙家堂路”。地名标志汉语拼音拼写形式：SUNJIATANG LU。

2．同意将你镇位于锦栏路东侧，南起镇北路、北至李太堂（自然村落）的道路命名为“马陆路”。地名标志汉语拼音拼写形式：MALU LU。

3．同意将你镇位于镇北路南侧，南起曹家湾（自然村落）、北至镇北路的道路命名为“粮站弄”。地名标志汉语拼音拼写形式：LIANGZHAN LONG。

4．同意将你镇位于204国道西侧，东起204国道、西至三干河的道路命名为“吴湖路”。地名标志汉语拼音拼写形式：WUHU LU。

5．同意将你镇位于凤北路东侧，南起凤凰路、北至凤恬路的道路命名为“金凤路”。地名标志汉语拼音拼写形式：JINFENG LU。

二、调整道路

1．同意将原“映山路”东起飞翔路、西至友谊路向东延伸至望山路、向西延伸至苏虞张公路。延伸后的“映山路”东起望山路、西至苏虞张公路，地名标志汉语拼音拼写形式：YINGSHAN LU。

2．同意将原“凤凰大道”东起金谷路、西至魏庄路向东延伸至凤恬路。延伸后的“凤凰大道”东起凤恬路、西至魏庄路，地名标志汉语拼音拼写形式：FENGHUANG DADAO。

3．同意将原“永庆路”南起方基、北至凤恬路向南延伸至马路。延伸后的“永庆路”南起马路、北至凤恬路，地名标志汉语拼音拼写形式：YONGQING LU。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好道路标志牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2019年5月23日
