# 关于加快推进张家港市养老志愿者服务工作的实施意见

志愿服务是现代社会文明进步的重要标志，是加强精神文明建设、培育和践行社会主义核心价值观的重要内容。截止2018年底，我市共有60周岁以上老年人25.38万，老年人占户籍人员比例27.31%,人口老龄化、高龄化、空巢化趋势日益明显。面对养老服务的巨大需求，探索将志愿服务和养老服务相结合，构建政府主导全民参与的养老服务新模式，是完善养老服务体系建设的必然要求。现就加快推进全市养老志愿服务工作提出如下意见：

一、总体要求

(一)指导思想。全面贯彻落实党的十九大和十九届二中、三中全会精神，紧紧抓住社会主义核心价值观体系建设这个根本，按照张家港市志愿服务“项目化推进、社会化运作、专业化服务”的总体思路，大力弘扬“奉献、友爱、互助、进步”的志愿者精神，促进全市养老志愿服务整体水平提高，加快健全我市养老服务体系建设，切实提升广大老年人的获得感、幸福感和安全感。

(二)基本原则。坚持服务大局、统筹发展的原则，把支持和发展养老志愿服务纳入全面建成小康社会、打造港城升级版总体要求，统筹城乡、行业和不同类型的志愿服务组织发展；坚持科学规划、实践探索的原则，构建合理的组织架构，建立完善的工作机制，提供有力的组织保障；坚持以人为本、广泛参与的原则，倡导自愿参与与志愿服务理念，尊重和保护志愿者的服务意愿和权益；坚持科学高效、互相交流的工作原则，不断创新养老志愿服务的管理方式、方法，加强市镇村之间、各类志愿服务组织间的交流，形成紧密联系、互为补充的养老志愿服务工作格局。

(三)主要目标。基本建成与经济社会发展相适应，布局合理、管理规范、服务完善、充满活力的养老志愿服务体系；养老志愿服务环境得到优化，形成注册管理、资金支持、人才培育等配套政策；养老志愿服务范围不断扩大，基本覆盖机构、社区、居家各领域、老年人生活各方面，涌现一批公信度高、带动力强的养老志愿服务组织；养老志愿服务功能有效发挥，涌现一批群众欢迎、社会影响好的养老志愿服务项目，让志愿服务成为营造尊老敬老社会氛围的重要渠道，成为提升社会服务水平、改善民生福祉的有力助手，成为增进社会信任、维护社会稳定、促进社会和谐的有生力量。

二、工作机制

(四)成立养老志愿服务行业组织。由民政部门牵头成立养老志愿者协会，整合全市养老志愿服务资源；制定全市性的养老志愿服务工作政策和指导性文件；负责培育建立专业型养老志愿服务团队，引导村、社区及社会志愿团队共同参与养老志愿服务；负责全市养老志愿服务项目的发布、志愿者招募和活动组织等。张家港市养老志愿者协会设在市亲情(虚拟)养老院。

(五)开发养老志愿服务信息平台。张家港市养老志愿服务信息平台提供老年人照料、康复、精神关爱等方面志愿服务内容，建设定位为“友爱港城”的二级平台，与“友爱港城”平台数据共享、共通；开发手机端服务平台，实现养老志愿者在手机端注册登记、活动报名、扫码签到、活动结果网上公示的一体化工作流程。

(六)加强养老志愿者专业培训。引入养老机构、社工机构、行业专家等资源，组建养老志愿服务讲师团，定期开展养老志愿者培训；采取知识技能和实务培训相结合的方式开展老年人心理、养老服务技能、应急处置能力、团队凝聚力等的培训，提高养老志愿服务专业化能力；加强养老志愿者培训工作的交流与考核。

(七)培育孵化养老志愿服务团队和项目。突出养老志愿者协会孵化、培育职能，积极吸引有能力、有意愿的社会热心人士加入养老志愿者团队，着力培养一批社会公信力强、专业水平高、热心公益的养老志愿者团队。认真研究分析老年人需求，不断优化养老志愿服务项目，建立养老志愿服务供需对接机制，打造一批老年人获得感强，可复制、可推广的养老志愿服务品牌项目。

(八)建立养老志愿者礼遇机制。研究制定《养老志愿者礼遇办法》,整合社会资源，兑现养老志愿者礼遇，表彰激励养老志愿服务优秀典型，弘扬志愿精神。在此基础上，学习先进地区经验，在时机成熟时，逐步探索符合我市市情的“时间银行”志愿服务模式。

三、工作要求

(九)加强组织领导。要充分认识养老志愿服务的重要意义和作用，尽快制定切实可行的推进措施。各相关部门、各区镇要切实将养老志愿服务作为精神文明建设的重要内容，纳入议事日程，加强组织领导，集中力量推进工作落实。一方面要在养老志愿服务活动所需的人、财、物方面给予必要支持，另一方面要不断更新工作理念，创新养老志愿服务的手段、方式，切实抓好养老志愿服务项目的扶持、引导、推广工作。

(十)完善工作保障。实施“学雷锋志愿服务伙伴计划”,在市慈善总会设立养老志愿服务专项基金，通过定向捐赠、缴纳会费等方式给予养老志愿服务工作必要的经费支持；安排专职工作人员负责养老志愿者协会日常工作，实现志愿服务项目发布、活动进展、志愿者积分等信息及时更新，实现养老志愿工作的连续性和可持续性；保障养老志愿者的权益，提供必要的餐饮、保险、经费补助和统一的志愿服务证件、标识、服装等。

(十一)加大宣传推广。做好宣传和舆论引导工作，形成全社会支持和参与养老志愿服务的良好氛围。各相关部门、各区镇要充分利用报纸、广播、电视等传统媒体以及网络、微信等新兴媒体，加大对养老志愿服务的宣传和推广。对先进典型要及时总结推广，充分展示养老志愿服务项目成果、养老志愿者及团队风采，营造尊老敬老的社会风尚，吸引更多志愿者加入养老志愿服务。
