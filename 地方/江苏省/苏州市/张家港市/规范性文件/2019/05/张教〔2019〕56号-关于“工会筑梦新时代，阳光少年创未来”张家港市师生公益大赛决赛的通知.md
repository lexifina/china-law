# 关于“工会筑梦新时代，阳光少年创未来”张家港市师生公益大赛决赛的通知

张教〔2019〕56号

各中小学、幼儿园：

本次“工会筑梦新时代，阳光少年创未来”张家港市师生创意公益大赛即将进入决赛，现将决赛有关事项通知如下：

一、决赛时间

2019年5月19日，上午9：00-11：00

二、决赛地点

张家港市白鹿小学

三、决赛安排

1.公益项目路演：进入决赛的20个公益项目小组，每组进行2-3分钟的路演。（具体参赛名单，详见5月17日微信公众号）

2.评选颁奖：由主办方组建的评选小组，评选出10个决赛获奖项目并颁奖。

3.建议参赛的班级组织亲友团（20个人），到现场观摩。

4.决赛当日，将进行现场视频直播，直播入口在微信公众号上。

张家港市教育局

张家港市总工会

共青团张家港市委员会

2019年5月17日
