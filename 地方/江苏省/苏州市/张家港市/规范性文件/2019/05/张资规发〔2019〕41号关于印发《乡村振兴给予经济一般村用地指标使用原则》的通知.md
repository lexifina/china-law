# 张资规发〔2019〕41号关于印发《乡村振兴给予经济一般村用地指标使用原则》的通知

各镇人民政府：

为更好落实上级关于实施乡村振兴战略的重大决策部署，充分发挥自然资源和规划基础保障作用，结合我市实际情况，我局制定了《乡村振兴给予经济一般村用地指标使用原则》，现印发给你们，请予参照执行。

张家港市自然资源和规划局

2019年5月15日

（此件公开发布）

乡村振兴给予经济一般村用地指标使用原则

1.经济一般村申报扶持指标应由经济一般村填写申请书，经所在区镇审核通过后上报市自然资源和规划局。申请书中应明确所建项目基本情况（包括投入、产出分析、具体地块四址）、项目开竣工时间，项目应与《关于提升全市产业用地综合利用水平实施意见》（张政办抄〔2019〕2号）要求相匹配。

2.扶持指标取得后应专项用于村级经济发展，不得用于房地产项目（地块）。扶持指标项目5年内不得销售或转让，项目如有特殊原因确需转让的需相关部门会商同意，并补交获得土地指标时同期价款。经济一般村单独或联合申请的,按照“一村二楼宇”政策供地，如与其他企业（单位）联合申请的，按正常招拍挂程序出让供地。

3.扶持指标为年度计划指标，如涉及占补平衡指标、征地成本、税费等由各镇自行解决。

4.使用扶持指标项目除正常的开竣工验收外，需由市自然资源和规划局会相关职能部门及所在地区镇进行联合验收，确保指标用于经济一般村提高村级收益。如验收中发现不符合要求，则在该区镇“三优三保”指标或竞购取得指标中直接扣除。

5.以区镇为单位，2019年安排符合条件总数的50%扶持指标，2020年安排剩余数。本次扶持指标执行两年，2020年12月31日前拨付完毕，逾期不申报视作放弃。指标使用时间要求按张家港市指标管理办法规定执行。
