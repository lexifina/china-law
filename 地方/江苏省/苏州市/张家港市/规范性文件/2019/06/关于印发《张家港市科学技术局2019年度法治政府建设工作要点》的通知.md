# 关于印发《张家港市科学技术局2019年度法治政府建设工作要点》的通知

局各科室、生产力促进中心、科技人才服务中心：

现将《张家港市科学技术局2019年度法治政府建设工作要点》印发给你们，请结合工作实际，抓好落实。

(此件公开发布)

张家港市科学技术局

2019年6月6日

张家港市科学技术局2019年度法治政府建设工作要点

为全面落实《张家港市贯彻落实<法治政府建设实施纲要(2015-2020年)>实施方案》,推进市科技局依法全面履职，增强政府公信力和执行力，根据《2019年张家港市法治政府建设工作要点》,结合我局实际，制定市科技局本年度法治政府建设工作要点。

一、提高政治站位，强化统筹部署。

坚持把党的领导贯彻到法治政府建设过程，强化单位主要负责人履行推进法治建设第一责任人职责，在本单位形成“主要领导亲自抓、分管领导配合抓、中层干部具体抓”的法治政府建设工作格局。围绕法治政府建设年度目标任务，结合我局实际，制定年度工作计划，推动法治建设各项工作依规落实。年内，局领导班子研究法治政府建设工作不少于2次。

二、加强宣传教育，营造良好氛围。

领导干部带头学法，将法律法规学习纳入党组理论学习中心组的重要内容，每季度组织至少一次领导班子专题学法，全年确保不少于4次。围绕《中华人民共和国宪法》、党纪党规、保密管理及与科技工作相关法律法规和法条案例，开展形式多样的全员学法活动，提升干部职工法治意识。年内，根据本单位中层正职新任职情况，适时组织任前法律知识考试。全面推进“七五”普法规划落实，积极履行部门普法职责，组织动员全体干部职工参与各类普法专题活动；组织实施“红堡超市”法治惠民服务行动。三、续聘法律顾问，保障依法履职。继续聘请专职律师担任本单位法律顾问，为日常各项行政工作依法开展提供基础保障。建立完善法律顾问履职档案，按要求落实法律顾问履职考核及聘任合同报备工作。切实发挥法律顾问“智囊”作用，在重大决策作出前、重大项目立项前、重大协议或重要合同签订前，提请法律顾问对相关工作程序、材料等开展全面的法务审查。吸纳法律顾问加入“红堡超市”志愿服务队伍，为全市各类科创企业提供基础法律服务。

四、健全决策机制，规范决策行为。

制定市科技局“三重一大”集体决策制度，明确动议事项范围及决策程序，进一步强化对决策过程的刚性约束，以明文制度规范决策程序、降低决策风险，确保各项行政决策依法合规、科学合理。对企业科技创新积分统计、张家港市科技计划项目评审立项等公众关注度较高、涉及面较广的决策事项，做到主动公开、及时回应、妥善解释。

五、落实简政放权，推进职能转变。

根据市统一安排，做好机构改革后部门行政权力事项清单的调整，以及相关事项在省政务服务网上的维护工作，确保社会公众打得通电话、理得清流程、找得到地点、办得好业务。认真落实“放管服”改革要求，加快张家港市科技计划项目管理系统改版建设，通过优化系统交互设计，显著改善企业用户使用体验。提升外籍人士来华工作证签发服务效率，依托“外国人来华工作管理服务系统”,创新事中事后监管机制，形成科学管理、互联共享、协同监管、便捷高效的外籍人士工作管理体系。六、规范公文制发，深化政务公开。加强本单位起草制发各类公文文件的过程管理，确保内容符合经济社会发展趋势和要求，文字逻辑严密、表述严谨、格式规范，不与上位法相抵触。认真贯彻落实《中华人民共和国政府信息公开条例》,坚持“公开为常态、不公开为例外”原则，以“张家港市人民政府”门户网站、“张家港科技”微信公众号、张家港市科技创新服务平台等为公开主阵地，加强机关职能、机构设置、政策法规、工作通知、政务动态等内容的公开，切实履行主动公开职责。

七、强化法治思维，自觉接受监督。

提升全体干部职工自觉运用法治思维和法治方式推动科技工作有序开展的能力，严格按照法定权限、规则、程序办事，确保不逾界越轨。自觉接受人大代表、政协委员及社会各界对本单位的监督评议，主动邀请市纪委监委派驻纪检监察组参与科技创新工作中的重大活动、重要会议和重点环节。通过构建全方位、立体化、法治化的监督格局，确保科技创新工作运转于法治阳光下。
