# 关于对《苏州市机动车驾驶人网上在线学习交通安全法律知识免于记分管理办法》第二条修改决定的公告

为进一步加强机动车驾驶人记分学习教育，切实提高交通安全意识，保障道路交通安全畅通，苏州市公安局交通警察支队2019年4月对《办法》第二条修改意见即“本办法规定的非现场查处的道路交通安全违法是指被电子监控设备记录且按照相关法律法规规章规定应记分值为6分（含）以下的道路交通安全违法行为，一个记分周期内累计免于记分不超过6分”，向社会公开征求意见，经对公众反馈意见汇总，98%参与人赞成修改。
