# 关于对华山路近港华路路段封闭改造的施工通告

因220千伏晨阳至晨港线路工程电缆土建工程施工需要，华山路将实行全封闭施工。封闭路段为华山路靠近港华路段，封闭时间为2019年6月15日至2019年7月15日。

届时，上述路段在对应时间段内禁止车辆、行人通行，请过往行人及车辆绕道而行，禁止进入封闭区域。施工期间给您带来的不便敬请谅解！

张家港市交通运输局
