# 关于定点医疗机构2017年度医疗费用年终决算的通知

市医保经办机构、各定点医疗机构：

根据《张家港市社会医疗保险定点医疗机构医疗费用结算管理办法》（张人社规〔2015〕2号）和《关于定点医疗机构2017年度医疗费用结算的通知》（张人社发〔2017〕50号）相关规定，现将有关定点医疗机构2017年度年终决算事项通知如下：

一、重新核定2017年度预算基数

各定点医疗机构2017年度预算基数以2016年度决算总额为基数，根据《关于定点医疗机构2017年度医疗费用结算的通知》设定的增幅重新核定（下文中的“预算基数”即为重新核定后的预算基数）。

二、门诊医疗费用年终决算

（一）医院

1、根据各定点医院实际就诊人数、年度初核定的均次费用指标、所在级别医院的平均人次人头比，确定各医院门诊医疗费用合理发生额。将合理发生额同门诊预算基数进行对比，不足部分（门诊A）予以补足。相关计算公式如下：

①门诊医疗费用合理发生额＝实际就诊人数×平均人次人头比×均次费用指标；

②门诊A=门诊医疗费用合理发生额－门诊预算基数。

2、为规范医疗行为，引导医院严控住院指征，建立门诊总额浮动激励机制，对实际住院率（住院率=住院人数/门诊人数）低于全市平均住院率（16.38%）的医院，增加门诊决算总额（门诊B）。实际住院率每低于全市平均住院率1个百分点，再增加门诊A值的10%，依次类推（增加计入比例见表1）。根据门诊A值和门诊B值的和确定门诊决算总额的合理增加额（门诊C）。相关计算公式如下：

③门诊B＝门诊A×增加计入比例；

④门诊C＝门诊A+门诊B。

3、根据门诊预算基数与门诊C值之和不超过门诊实际费用的原则，确定各医院门诊决算总额，并结合门诊实际基金结付率进行结付。

（二）其他门诊类医疗机构

对实际门诊费用未超预算基数的定点单位，根据门诊次均费用指标提高3%后，按实际人次确定其门诊决算总额（不高于实际费用），并结合门诊实际基金结付率进行结付。

对实际门诊费用超过预算基数的社区卫生服务中心（站），超过门诊决算总额100%以内的部分按95%补偿，并结合门诊实际基金结付率进行结付；超过门诊决算总额100%以上部分不予补偿。对实际门诊费用超过预算基数的口腔诊所及其他门诊部，根据《关于定点医疗机构2017年度医疗费用结算的通知》规定，不予补偿。

三、住院医疗费用年终决算

1、根据各医院的实际就诊人数、平均住院天数（参照《关于印发张家港市2018年度公立医院绩效考核评价方案的通知》，确定二级以上医院不超过7.5天、一级医院不超过7天）、所在级别医院的平均床日费用、平均住院人次，确定各医院住院医疗费用合理发生额。将合理发生额同住院预算基数进行对比，不足部分（住院A）予以补足。相关计算公式如下：

①住院医疗费用合理发生额＝实际就诊人数×平均住院人次人头比×平均床日费用×平均住院日；

②住院A=住院医疗费用合理发生额－住院预算基数。

2、为引导合理住院，严控住院医疗费用，建立住院总额浮动下调机制。根据实际住院率与全市平均住院率（16.38%）的差额情况，扣减住院决算总额（住院B）。对实际住院率低于全市平均住院率的，不予扣减；实际住院率每超过全市平均住院率1个百分点，扣减住院A值的3%，依次类推（扣减比例见表2）；根据住院A值和住院B值之差确定住院决算总额的合理增加额（住院C）。相关计算公式如下：

③住院B＝住院A×扣减比例

④住院C＝住院A-住院B
