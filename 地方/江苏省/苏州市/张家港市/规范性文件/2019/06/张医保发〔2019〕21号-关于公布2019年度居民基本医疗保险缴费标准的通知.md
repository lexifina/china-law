# 关于公布2019年度居民基本医疗保险缴费标准的通知

各有关单位：

根据《市政府关于印发张家港市社会基本医疗保险实施细则的通知》（张政发〔2017〕42号）文件精神，经市政府批准，现将2019年度居民基本医疗保险缴费标准有关事项通知如下：

一、2019年度我市居民基本医疗保险筹资标准为每人1270元/年，其中：参保居民个人缴费270元/年，市、镇两级财政补助每人1000元/年。

二、各类参保居民的个人缴费包含20元大病保险费用。

三、请各有关单位按照本通知要求，认真组织做好本市居民医疗保险的参保缴费工作。

张家港市医疗保障局

张家港市财政局

2019年6月15日
