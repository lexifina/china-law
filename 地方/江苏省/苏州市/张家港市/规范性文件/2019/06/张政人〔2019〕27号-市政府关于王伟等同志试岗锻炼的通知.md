# 市政府关于王伟等同志试岗锻炼的通知

各镇政府，冶金工业园、高新技术产业开发区、常阴沙现代农业示范园区、双山香山旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：

经研究决定：

王伟同志任张家港经济技术开发区商贸局副局长；

牛楠同志任江苏扬子江国际冶金工业园组织人事局副局长；

顾琪同志任江苏扬子江国际冶金工业园科技招商局（发展改革局）副局长；

季春晨同志任张家港高新技术产业开发区科技招商局副局长。

以上同志均为试岗锻炼，试岗锻炼时间二年。

张家港市人民政府

2019年6月1日
