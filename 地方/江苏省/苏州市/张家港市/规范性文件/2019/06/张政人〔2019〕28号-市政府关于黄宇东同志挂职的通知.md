# 市政府关于黄宇东同志挂职的通知

各镇政府，冶金工业园、高新技术产业开发区、常阴沙现代农业示范园区、双山香山旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：

经研究决定：

黄宇东同志挂任张家港经济技术开发区财政局副局长，挂职时间一年，挂职期满后不再办理免职手续。

张家港市人民政府

2019年6月1日
