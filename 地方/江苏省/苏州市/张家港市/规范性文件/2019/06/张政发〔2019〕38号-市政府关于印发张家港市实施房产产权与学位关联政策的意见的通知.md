# 市政府关于印发张家港市实施房产产权与学位关联政策的意见的通知

各镇政府，冶金工业园、高新技术产业开发区、常阴沙现代农业示范园区、双山香山旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：

经市政府同意，现将《张家港市实施房产产权与学位关联政策的意见》印发给你们，请认真贯彻落实。

张家港市人民政府

2019年6月6日

（此件公开发布）

张家港市实施房产产权与学位关联政策的意见

为合理优化张家港市学校（幼儿园）资源配置，更好地保障适龄儿童、少年公平有序入学（园），根据《中华人民共和国义务教育法》《江苏省实施<中华人民共和国义务教育法>办法》《江苏省学前教育条例》等法律文件，认真贯彻执行《关于印发2014年苏州市区义务教育阶段学校入学工作意见的通知》（苏教〔2014〕4号）、《2018年苏州市区小学与初中地段生认定办法》（苏教基〔2018〕22号）相关政策规定，结合我市实际，现制定如下意见：

一、政策主要内容

从2019年秋季入学开始，我市幼儿园、义务教育学校招生实行同一合法固定住所（本意见特指具有住宅房屋产权证或通过生效法律文书取得房屋产权的居住用房，商业、办公、工业用房、车库等非居住用房除外）每五年认定一户家庭的幼儿园及义务教育学段学位，即某一合法固定住所已认定一户家庭学位，该房产若在使用学位起的五年时间内更换产权所有者，就不能再作为施教区（服务区）的认定依据。

相关说明：

①“每五年”的计算时间是从该房产上一次学位开始使用的时间算起；

②该政策自2019年7月1日起实施；

③执行此政策，原来对房屋性质、取得权证时间、产权拥有人等相关要求不变。

二、政策实施原则

（一）坚持依法办事。实施房产产权与学位关联政策，严格按照相关法律、法规要求，与苏州市相关政策保持高度一致，实现苏州市政策的平稳落地。

（二）坚持统筹推进。政策实施前办理入学的家庭子女，信息不录入查询系统。政策实施后，凭房产证入学家庭的房产信息及时录入系统，方便市民查询。不同学段凭房产入学登记、查询不受相关影响。

（三）坚持以人为本。化解矛盾的同时，确保购得房产家庭子女就近入读公办学校，具体问题具体解决，确保相关家庭子女正常入学。

三、政策实施保障

（一）加强宣传，提高认识。以服务学生、方便家长为宗旨，完善服务措施，优化服务项目。认真做好政策解读、电话咨询、来访接待、实施意见公示等服务工作。

（二）加强督查，推动落实。招生期间，市教育局纪检监督小组对各校招生过程进行明查暗访和随机督查；政策实施过程中，学校定期提供查询服务，确保操作规范，切实提高社会认可度、家长满意度。

（三）加强管理，规范操作。按照《江苏省义务教育学籍管理规定》要求，充分利用全国中小学生学籍信息管理系统组织实施招生入学工作，严格实行“一人一籍、籍随人走”，提高学籍管理信息化水平。
