# 市政府关于给在《张家港年鉴（2018）》编纂工作中作出突出贡献的集体和个人记功和通报表扬的决定

各镇政府，冶金工业园、高新技术产业开发区、常阴沙现代农业示范园区、双山香山旅游度假区管委会，市政府各部门、市直属各单位（公司），各条线管理单位：

由中共张家港市委党史地方志办公室负责编纂的《张家港年鉴》，自1996年创刊以来，已连续出版23卷，总文字量2500多万字，是查存史料、制定决策、开展研究的重要资料。2019年1月，《张家港年鉴（2018）》获评第六届全国年鉴编纂出版质量评比最高奖——综合特等奖，并囊括框架设计、条目编写、装帧设计以及检索、编校质量和出版时效4个单项特等奖，完成了特等奖“三连冠”的目标。此外，《张家港年鉴》还实现了全国年鉴编校质量检查评比特等奖的“八连冠”、江苏省年鉴奖最高奖项的“五连冠”。

为鼓励先进，进一步发挥好《张家港年鉴》的作用，打造好这张地方文化名片，市政府决定对有关集体和个人予以记功和通报表扬。

一、给予中共张家港市委党史地方志办公室记集体三等功一次。

二、给予汪丽菁同志记个人三等功一次。

三、给予张洁等6名同志分别通报表扬一次。

希望受到表扬的集体和个人珍惜荣誉、再接再厉，继续做好《张家港年鉴》编纂利用工作。全市各镇（区）、各部门和广大干部群众要以先进为榜样，与时俱进大力弘扬张家港精神，锐意进取、务实苦干，为我市全力打造“港城发展升级版”、奋力推动高质量发展走在前列作出新的更大贡献！
