# 市政府关于同意张家港市乐余镇总体规划修编（2018—2030）的批复

乐余镇政府：

你镇上报的《关于报批〈张家港市乐余镇总体规划修编（2018—2030）〉的请示》（乐政发〔2019〕34号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《张家港市乐余镇总体规划修编（2018—2030）》。规划范围为乐余镇行政区域，规划面积78.62平方公里。规划年限为2018—2030年，其中近期为2018—2023年，远期为2024—2030年。

二、要加强与城市总体规划、土地利用规划、综合交通规划等相关规划的有机衔接、融合，加快编制完善各专项规划及地块控制性详细规划，进一步健全完善区域规划体系；要充分发挥规划的引导控制作用，统筹区域内产业发展、资源配置和公共服务设施建设，打造产城融合、宜居舒适、配套完善的生态城镇。

三、经市政府批准的《张家港市乐余镇总体规划修编（2018—2030）》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2019年5月27日
