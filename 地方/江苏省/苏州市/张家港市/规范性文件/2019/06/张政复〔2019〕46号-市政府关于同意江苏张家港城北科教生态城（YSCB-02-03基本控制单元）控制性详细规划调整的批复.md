# 市政府关于同意江苏张家港城北科教生态城（YSCB-02-03基本控制单元）控制性详细规划调整的批复

张政复〔2019〕46号

来源：市政府发布时间：2019-06-01 15:08:00访问量：字体【大中小】

市自然资源和规划局：

你局上报的《关于报批〈江苏张家港城北科教生态城（YSCB-02-03基本控制单元）控制性详细规划调整〉的请示》（张资规发〔2019〕35号）收悉。经研究，现批复如下：

一、原则同意你局上报的《江苏张家港城北科教生态城（YSCB-02-03基本控制单元）控制性详细规划调整》。规划调整范围为东至杨锦公路、南至振兴路、西至华昌路、北至长兴路，规划面积104.5公顷。

二、经市政府批准的《江苏张家港城北科教生态城（YSCB-02-03基本控制单元）控制性详细规划调整》是指导该区域建设和管理的重要依据。要严格执行规划，达到通过规划调整引导该区域开发建设更加科学合理的目的。

此复。

张家港市人民政府

2019年6月1日
