# 市政府关于同意张家港市城北科教新城YSCB-03-02基本控制单元控制性详细规划的批复

张政复〔2019〕48号

来源：市政府发布时间：2019-06-06 11:06:00访问量：字体【大中小】

市自然资源和规划局：

你局上报的《关于报批〈张家港市城北科教新城YSCB-03-02基本控制单元控制性详细规划〉的请示》（张资规发〔2019〕36号）收悉。经研究，现批复如下：

一、原则同意你局上报的《张家港市城北科教新城YSCB-03-02基本控制单元控制性详细规划》。规划范围：东至规划新城路、南至长兴路、西至港城大道、北至北二环路，规划面积36.46公顷。

二、要加强与城市总体规划及土地利用规划等相关规划的有机衔接、融合，深化规划地块发展定位和功能布局研究，协调处理好规划区域与周边区域的关系，统筹安排基础设施和公共服务设施建设，保障土地科学、合理与集约利用。

三、经市政府批准的《张家港市城北科教新城YSCB-03-02基本控制单元控制性详细规划》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2019年6月6日
