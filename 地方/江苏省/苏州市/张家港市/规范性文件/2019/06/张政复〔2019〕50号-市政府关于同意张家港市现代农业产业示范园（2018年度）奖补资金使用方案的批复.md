# 市政府关于同意张家港市现代农业产业示范园（2018年度）奖补资金使用方案的批复

张政复〔2019〕50号

来源：市政府发布时间：2019-06-12 14:53:00访问量：字体【大中小】

常阴沙现代农业示范园区管委会：

你委《关于报批张家港市现代农业产业示范园（2018年度）奖补资金使用方案的请示》（现农政发〔2019〕26号）已收悉。经研究，现批复如下：

一、原则同意《张家港市现代农业产业示范园（2018年度）奖补资金使用方案》（以下简称《使用方案》）。

二、你委要按照实施乡村振兴战略的总要求，加快推进我市现代农业产业示范园项目建设，精准把控实施进度，切实加强资金管理水平，提高资金使用效率，努力打造高水平现代农业产业示范园。

三、经市政府批准的《张家港市现代农业产业示范园（2018年度）奖补资金使用方案》是指导和规范我市现代农业产业示范园专项资金下拨使用的重要依据，要严格按照《使用方案》要求，履行好资金使用程序，确保资金使用到位、项目顺利实施。

此复。

张家港市人民政府

2019年6月12日
