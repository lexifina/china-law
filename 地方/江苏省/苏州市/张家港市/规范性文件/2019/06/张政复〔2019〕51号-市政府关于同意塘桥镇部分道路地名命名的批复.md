# 市政府关于同意塘桥镇部分道路地名命名的批复

塘桥镇人民政府：

你镇《关于塘桥镇部分道路命名的请示》（塘政发〔2019〕21号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意对你镇申报的3条现有未命名道路予以命名。具体批复如下：

1．同意将你镇位于妙丰公路西侧，南起虎旋路（现有道路拟命名）、北至永昌路的道路命名为“永旋路”。地名标志汉语拼音拼写形式：YONGXUAN LU。

2．同意将你镇位于走马塘南侧，南起张家港市禄德针织有限公司、北至走马塘的道路命名为“勤丰路”。地名标志汉语拼音拼写形式：QINFENG LU。

3．同意将你镇位于永昌路南侧，东起妙丰公路、西至金村路的道路命名为“虎旋路”。地名标志汉语拼音拼写形式：HUXUAN LU。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好道路标志牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2019年6月17日
