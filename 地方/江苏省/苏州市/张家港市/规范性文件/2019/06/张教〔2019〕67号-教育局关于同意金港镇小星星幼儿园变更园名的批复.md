# 教育局关于同意金港镇小星星幼儿园变更园名的批复

张教〔2019〕67号

金港镇小星星幼儿园：

你园关于变更园名的申请收悉。根据民政部门规范社会组织名称的相关规定，经研究，同意将“金港镇小星星幼儿园”更名为“张家港市小星星幼儿园”。

幼儿园园名变更后，原法人、性质、规模、地址等不变。幼儿园要在原审批范围内办园，不断加强幼儿园管理，切实提高保教质量，努力为适龄幼儿提供优质教育。

张家港市教育局

2019年6月19日
