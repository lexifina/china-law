# 关于公布“四有”好教师教育故事案例获奖结果的通知

各镇（区）教卫文体办公室（综合办）,各中小学、幼儿园，各直属单位：

为更好地树好师德典型，讲好师德故事，弘扬师德正能量，进一步做好新时代教师职业行为十项准则的贯彻落实工作，根据《关于进一步加强新时代教师职业行为十项准则系列文件贯彻落实工作的通知》（苏教人师〔2019〕10号）精神，市教育局开展了“四有”好教师教育故事案例征集活动。经过专家认真评审，共有106篇案例获奖，案例获奖结果见附件。
