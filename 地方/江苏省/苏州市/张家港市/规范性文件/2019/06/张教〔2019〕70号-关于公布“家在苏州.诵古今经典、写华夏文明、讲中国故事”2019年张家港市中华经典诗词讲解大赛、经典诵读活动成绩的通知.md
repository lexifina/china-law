# 关于公布“家在苏州.诵古今经典、写华夏文明、讲中国故事”2019年张家港市中华经典诗词讲解大赛、经典诵读活动成绩的通知

张教〔2019〕70号

各中小学、幼儿园：

为贯彻落实中央办公厅、国务院办公厅《关于实施中华优秀传统文化传承发展工程的意见》和全国教育大会精神，全面深入实施中华经典诵读工程，根据教育部语用司《关于举办2019年中华经典诵写讲大赛的通知》（教语用司函〔2019〕16号）、苏州市《关于举办“家在苏州·诵古今经典、写华夏文明、讲中国故事”2019年苏州市中华经典诵写讲大赛的通知》（苏语委〔2019〕4号），张家港市语委、市教育局在全市举办了“家在苏州·诵古今经典、写华夏文明、讲中国故事”2019年张家港市中华经典诗词讲解大赛、经典诵读活动，并择优推荐参加苏州市、江苏省比赛。现公布张家港市比赛结果。
