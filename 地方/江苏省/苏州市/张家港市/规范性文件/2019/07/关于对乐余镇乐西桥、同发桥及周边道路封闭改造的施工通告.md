# 关于对乐余镇乐西桥、同发桥及周边道路封闭改造的施工通告

因乐余镇乐红桥(又名乐西桥)、同发桥老桥拆除重建，从2019年7月21日至2019年12月31日对乐西桥、同发桥及周边道路进行封闭施工。

届时，上述路段在对应时间段内禁止车辆、行人通行，请过往行人及车辆绕道而行，禁止进入封闭区域。施工期间给您带来的不便敬请谅解！

特此通告

张家港市交通运输局

张家港市公安局交通警察大队
