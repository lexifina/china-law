# 市人力资源和社会保障局市医疗保障局关于公布2019结算年度社会保险缴费基数的通知

市社会保险基金管理结算中心、市人力资源管理服务中心，各有关单位：

根据苏州市人力资源和社会保障局、财政局、医疗保障局《关于转发〈省人力资源社会保障厅省财政厅省医疗保障局关于发布2019年度社会保险有关基数的通知〉的通知》（苏人保养〔2019〕19号）文件规定，结合我市实际，经市政府同意，现将我市2019结算年度（2019年7月1日至2020年6月30日）社会保险缴费基数等事项公布如下：

一、2019结算年度参加我市企业职工社会保险的单位和职工缴纳社会保险费的基数上限为202104元（16842元/月），下限为37920元（3160元/月）。

二、参加企业职工社会保险的灵活就业人员，2019结算年度的社会保险缴费基数调整为八档，各档次标准分别为：一档为3160元/月；二档为4048元/月；三档为5657元/月；四档为7894元/月；五档为10131元/月；六档为12368元/月；七档为14605元/月；八档为16842元/月。2019结算年度前已参保灵活就业人员未选择变更缴费基数档次的，仍按上一结算年度选择的缴费基数档次执行。

三、参加企业职工社会保险的个体工商户，2019结算年度的社会保险缴费基数调整为八档，各档次标准与灵活就业人员的社会保险缴费基数标准一致。2019结算年度前已参保个体工商户未选择缴费基数档次的，按第二档标准执行。

四、参加企业职工社会保险的单位和职工，2019结算年度内补缴社会保险费的缴费基数，按不低于4048元/月执行，但最高不得超过7956元/月。

五、2019结算年度参加我市机关事业单位社会保险的单位和职工缴纳养老保险费的基数上、下限标准按省人社厅规定执行，缴纳职工基本医疗、生育、工伤、失业保险费的基数上限为289236元（24103元/月），下限为73080元（6090元/月）。

六、在2019结算年度内办理退休（职）手续的参保职工，按张政发〔2017〕42号文规定补缴医疗保险费的，补缴基数为48576元/年。
