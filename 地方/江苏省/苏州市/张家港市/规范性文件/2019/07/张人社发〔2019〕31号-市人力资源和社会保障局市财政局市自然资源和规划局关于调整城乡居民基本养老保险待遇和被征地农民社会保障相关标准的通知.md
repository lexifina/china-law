# 市人力资源和社会保障局市财政局市自然资源和规划局关于调整城乡居民基本养老保险待遇和被征地农民社会保障相关标准的通知

市社会保险基金管理结算中心，各镇（区）人力资源和社会保障服务中心、国土资源分局（所）、财政分局（所、财经办）：

经市人民政府同意，现对调整城乡居民基本养老保险待遇和被征地农民社会保障相关标准通知如下：

一、城乡居民基本养老保险基础养老金标准

（一）调整对象

2019年6月30日在册的城乡居民基本养老保险待遇领取人员。

（二）调整标准

1．普遍调整。基础养老金按每人每月30元标准增加。

2．适当倾斜。2019年6月30日年满65周岁（以居民身份证为准，下同）不足70周岁、年满70周岁不足75周岁、年满75周岁不满80周岁以及年满80周岁以上的人员，每人每月分别增发5元、10元、15元、20元。

（三）其他

1．2019年7月1日后到达养老年龄按月领取城乡居民基本养老保险待遇的人员，其基础养老金标准按同年龄城乡居民基本养老保险待遇领取人员的基础养老金标准执行。

2．2019年7月1日至2020年6月30日期间到达65周岁、70周岁、75周岁、80周岁的待遇领取人员，从2020年7月起按对应年龄段基础养老金标准执行。

3．农村退养干部按《关于调整农村退养干部待遇的意见》（张委办〔2012〕30号）执行。

4．各镇村自行发放待遇的其他人员，各镇应根据经济社会发展水平同步调整。

二、被征地农民社会保障标准

（一）第四年龄段被征地农民征地保养金标准

按《关于认真做好征土工安置工作的通知》（张政发〔1992〕223号文）、《关于印发〈张家港市实施《苏州市征用土地暂行办法》的办法〉的通知》（张政发〔2000〕102号）、《关于印发〈张家港市征地补偿和被征地农民基本生活保障暂行办法〉》的通知》（张政发〔2004〕71号)规定产生，且2019年6月30日在册享受征地保养金的第四年龄段被征地农民，按每人每月10元标准增加。

（二）养老年龄段被征地农民养老补助金标准

按《市政府关于印发张家港市征地补偿和被征地农民社会保障办法的通知》（张政发规〔2016〕3号）规定产生，且2019年6月30日在册按月享受养老补助金的养老年龄段被征地农民，养老补助金调整标准为：

1．普遍调整。养老补助金按每人每月40元标准增加。

2．适当倾斜。2019年6月30日年满65周岁不足70周岁、年满70周岁不足75周岁、年满75周岁不足80周岁以及年满80周岁以上的人员，每人每月分别增发5元、10元、15元、20元。

3．2019年7月1日至2020年6月30日期间到达65周岁、70周岁、75周岁、80周岁的待遇领取人员，从2020年7月起按对应年龄段养老补助金标准执行。

（三）待遇衔接

1．按张政发〔1992〕223号、张政发〔2000〕102号、张政发〔2004〕71号文规定征地，且在2019年7月1日后新产生的第四年龄段（含张政发〔1992〕223号文规定到达法定退休年龄）被征地农民，涉及2019年6月30日前的征地保养金，按原规定执行；2019年7月1日后按470元/月执行。上述对象中，凡男满60周岁及以上、女满55周岁及以上且只享受征地保养金的，可享受同年龄城乡居民基本养老保险待遇领取人员的基础养老金。

2．按张政发〔1992〕223号文产生，且于2008年12月底前到龄、同时按月享受征地保养金和遗属定期救济费或只享受征地保养金的被征地农民，可按同年龄城乡居民基本养老保险待遇领取人员的基础养老金增加部分增发。

3．按张政发规〔2016〕3号文规定征地，且在2019年7月1日后新产生的养老年龄段被征地农民，涉及2019年6月30日前的养老补助金，按原规定执行；2019年7月1日后按同年龄养老年龄段被征地农民的养老补助金标准执行。被征地前已参加城乡居民基本养老保险的人员，同时享受省政府规定的最低标准基础养老金。资金列支渠道分别为被征地农民社会保障资金和城乡居民基本养老保险基金。

4．按张政发〔1992〕223号、张政发〔2000〕102号、张政发〔2004〕71号文产生的第四年龄段被征地农民，其按月享受的征地保养金和其他养老待遇的合计数（含2019年度增资部分，但不包含城乡居民基本养老保险基础养老金适当倾斜增加部分），自2019年7月1日起，低于按张政发规〔2016〕3号文产生的养老年龄段被征地农民养老补助金（含2019年度增资部分，但不包含养老补助金适当倾斜增加部分）与省定最低基础养老金合计数的，予以补足，所需资金随征地保养金的列支渠道执行。

三、社会保障资金计算标准

2019年7月1日起，劳动年龄段被征地农民和养老年龄段被征地农民社会保障资金，以2018年本市农村居民人均可支配收入（32664元）20%（按月折算为544元）计算确定。

四、执行时间：从2019年7月1日起执行。

五、资金来源：此次调整基本养老金所需资金，仍按原支付渠道列支。
