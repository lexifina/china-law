# 关于给“黄牛”整治集中行动工作组等集体以及余跃飞同志等个人嘉奖的命令

各警署、各派出所、直属各单位、机关各部门：

为表彰先进，鼓舞士气，激励斗志，根据《公安机关人民警察奖励条令》的规定，特命令：

一、给“黄牛”整治集中行动工作组记集体嘉奖一次，颁发证书。

二、给下列14位同志各记个人嘉奖一次，颁发证书和奖金。

1.余跃飞，治安大队民警

2.张 源，行动技术大队民警

3.沈 伟，经侦大队民警

4.陆凌云，治安大队民警

5.孙铁彪，城南派出所民警

6.丁云兵，城北派出所民警

7.付金标，巡特警大队卡口二中队（黄旗桥）民警

8.徐彬元，交警大队保税区中队副中队长

9.徐梦蛟，城西派出所民警

10.陈庞虎，警务保障室副主任

11.李 萍，政治处副主任

12.吴 昊，交警大队政秘股副股长

13.魏宏达，指挥中心民警

14.莫钰峰，法制大队民警

希望受到表彰的集体和个人谦虚谨慎、戒骄戒躁，珍惜荣誉、再创佳绩。全市公安机关和广大民警要以先进为榜样，以习近平新时代中国特色社会主义思想为指引，牢牢把握“对党忠诚、服务人民、执法公正、纪律严明”的总要求，以新中国成立70周年大庆安保维稳为主线，主动作为，积极履职，为保障全市社会持续平安稳定，推动张家港公安高质量发展走在最前列作出新的更大贡献！

此令。

公安局长  周斌伟

2019年7月17日
