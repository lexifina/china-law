# 关于印发《医疗保险按病种付费病种目录和结算标准》的通知

各定点医疗机构：

根据《省政府办公厅关于进一步深化基本医疗保险支付方式改革的实施意见》（苏政办发〔2018〕6号）、《江苏省医疗保障局关于印发2019年全省医疗保障工作要点的通知》（苏医保发〔2019〕15号）要求，结合我市实际，经分析统计和专家论证，制定了《医疗保险按病种付费病种目录和结算标准》，现予印发。本通知从2019医保结算年度起执行。

附件：医疗保险按病种付费病种目录和结算标准
