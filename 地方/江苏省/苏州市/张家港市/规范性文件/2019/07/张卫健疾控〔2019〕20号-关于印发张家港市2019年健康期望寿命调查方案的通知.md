# 关于印发张家港市2019年健康期望寿命调查方案的通知

各镇（区）社区卫生服务中心，市疾病预防控制中心：

我委制定了《张家港市2019年健康期望寿命调查方案》，请认真组织实施。

张家港市卫生健康委员会

2019年7月16日

（此件主动公开）

张家港市2019年健康期望寿命调查方案

随着现代社会的快速发展，经济和生活水平的提高，人们对健康的追求不再只专注于延长寿命或增加期望寿命，而是更多的注重生活质量。目前“健康寿命”作为评价人口总体健康状况的指标，已经被联合国和世界卫生组织认可，并在全世界得到普遍的推广和使用。2016年，中共中央、国务院印发的《“健康中国2030”规划纲要》指出，到2030年要实现人均健康预期寿命显著提高的目标。国务院办公厅印发的《中国防治慢性病中长期规划（2017－2025年）》也提出要逐步提高居民健康期望寿命，努力全方位、全周期保障人民健康。为首次掌握我市居民的健康期望寿命，评价全市居民的生存质量，动态观测居民的健康变化，特制定本实施方案。

一、目的

1. 计算全市居民健康期望寿命，评价居民的生存质量；

2. 分析影响我市居民健康的主要相关危险因素，动态观测居民的健康变化。

二、调查对象

张家港市18岁及以上户籍居民。总样本量共3100人。

三、抽样设计

采用多阶段分层整群随机抽样设计：第一阶段，全市每个镇（区）随机抽取1-2个村（居委会）；第二阶段，在抽中的每个村（居委会）随机抽取居民户；第三阶段，在选取的居民户中随机抽取1名符合要求的调查对象。

按照PPS分配，各镇（区）最低调查样本量如下：杨舍镇（含城区）747人、金港镇（含双山岛旅游度假区）694人、锦丰镇402人、塘桥镇384人、凤凰镇260人、乐余镇223人、南丰镇189人、大新镇150人、现代农业示范园区56人。在每个抽中的村（居委会）内，根据户籍底册随机抽取居民户。考虑不应答情况，先抽取多于期望样本量30%的户数。如在第一批抽中的户数内未完成期望的样本量，则根据剩余任务量再抽取第二批住户。在选中的居民户中，利用Kish表选取1人进行调查。各镇（区）村（居委会）抽样结果如下：

杨舍镇（含城区）：东莱村、新民村；金港镇（含双山岛旅游度假区）：滩上村、东山村；锦丰镇：协仁村；塘桥镇：周巷村、镇中村；凤凰镇：湖滨社区；乐余镇：永利社区；南丰镇：东港村；大新镇：桥头村；现代农业示范园区：常东社区。

四、调查内容与方法

本次调查采用集中调查和入户调查相结合的方式，利用问卷星（企业版）开展在线调查。主要包括以下几方面内容：

1. 社会人口学信息：包括性别、职业、民族、年龄、婚姻、文化、收入等；

2. 健康状况：慢性病、活动限制、抑郁情绪、睡眠状况、EQ-5D；

3. 健康行为：吸烟、饮酒、体力活动（IPAQ简表）、饮食；

4. 自评健康情景问卷：健康状况描述；

5. 情景评判：问卷以询问的方式进行调查，不能由被调查者自行填写。

五、调查程序

1.宣传发动。各镇（区）社区卫生服务中心根据市疾控中心的统一部署做好辖区内调查人群的前期抽样，制定内调查计划。采取多种形式开展宣传和动员工作，向居民介绍此次调查的目的和意义，争取调查对象的理解和配合。

2.人员培训。市疾控中心组织对各镇（区）社区卫生服务中心参加调查的人员开展统一培训，内容包括：健康期望寿命相关知识、各类调查问卷填写说明及质量控制技术等，所有参与调查的工作人员均应经过培训考核合格后方可参加调查。

3.问卷调查。调查员对筛查对象实行预约通知并签署知情同意书，面对面询问筛查对象相关信息后在线填写《张家港市2019年健康期望寿命调查问卷》（附表）。调查问卷内容包括个人基本情况、健康状况、健康行为、客观情景评判。

4.报告撰写。市疾控中心对全市所有调查资料进行统计分析，计算张家港市居民健康期望寿命，并对影响居民健康期望寿命的主要危险因素进行分析，撰写调查报告。

六、质量控制

1. 由问卷星（企业版）设置问卷信息逻辑错误、异常数值及缺漏项自动判定及强制提醒功能。

2. 各镇（区）社区卫生服务中心负责辖区内现场调查的质量控制，确保调查信息真实、准确。在三次上门未调查成功而放弃该户时，应从候选户中按顺序递补。

3. 市疾控中心负责全市调查全过程质量控制，随时了解各镇（区）调查工作进展情况及质控情况，及时给予指导和反馈。对各镇（区）抽取不少于5%的kish表和问卷进行电话复核，复核一致率要求在95%以上。

七、调查经费

本次调查经费从健康期望寿命调查专项经费（由市疾控中心另行下发文件，拨付至各调查点）中支出，主要用于调查对象误工补助和调查人员误餐、加班等补助。

八、进度安排

2019年7月：制定调查方案，完成调查前抽样和调查员培训。

2019年8～9月：完成现场调查，开展质量控制。

2019年10月：调查数据整理及清洗。

2019年11～12月：开展数据分析，撰写调查报告。

九、工作要求

1.加强组织领导，落实调查任务。市疾控中心、各镇（区）社区卫生服务中心要明确分管领导和责任部门，制定切实可行的工作方案，成立调查工作小组，相互沟通、密切协作，制定最便捷、最优化的调查流程，确保调查工作落到实处。

2.加强宣传发动，确保调查进度。本次调查工作涉及人员广泛，市疾控中心、各镇（区）社区卫生服务中心要加大对调查工作的宣传力度，准确掌握调查工作进度，确保全市调查人数满足最低样本量要求，调查数据能够有效反映出我市居民健康期望寿命水平，为相关健康政策的制定提供依据。

3.加强质量控制，提高调查质量。市疾控中心要做好调查前技术培训，确保每位调查人员准确掌握调查要领和相关要求，在正式调查开始前及时开展预调查，统一规范相关问卷内容的解释口径。各镇（区）社区卫生服务中心要根据实际情况建立单位内部调查质控体系，有效开展问卷质控，确保调查数据真实、客观。
