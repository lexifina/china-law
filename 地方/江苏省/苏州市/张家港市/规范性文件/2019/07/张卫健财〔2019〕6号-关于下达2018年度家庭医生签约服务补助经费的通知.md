# 关于下达2018年度家庭医生签约服务补助经费的通知

各镇(区)财政所、社区卫生服务中心：

根据市委办公室、市政府办公室《关于印发张家港市2018年民生实事项目的通知》文件精神，家庭医生签约服务补助经费按市、镇两级财政3:7的比例分担，现将2018年度家庭医生签约服务市级补助经费下达给你们，请各镇(区)按照规定，专款专用，并及时、足额安排镇级配套经费。

附件：1.2018年度家庭医生签约服务经费下达明细表

2.2018年度大病困难群众、计生特殊困难家庭医生签约服务费用补助明细表(镇区)

3.2018年大病困难群众、计生特殊困难家庭医生签约服务费用补助明细表(包干医院)

4.2018年度社区医生个性化家庭签约服务费用补助明细表
