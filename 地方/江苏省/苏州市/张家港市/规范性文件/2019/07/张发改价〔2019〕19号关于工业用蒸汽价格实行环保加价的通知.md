# 张发改价〔2019〕19号关于工业用蒸汽价格实行环保加价的通知

各供热企业:

根据国家、省环保政策要求，结合近年来热电企业超低排放环保改造投入成本增加的实际情况，经对热电企业脱硫、脱硝、超低排放投入成本调查，决定适当增加环保汽价。现将有关事项通知如下：

一、对已安装超低排放设施并通过超低排放验收（包括自主验收）的热电企业，自通过验收的次月起，蒸汽价格另加4元/吨；对超低排放运行不正常的企业，次月起取消加价。

二、各热电企业在提交超低排放验收（包括自主验收）资料并经我委同意后执行。

三、上述价格自发文之日起执行。

张家港市发展和改革委员会

2019年7月29日
