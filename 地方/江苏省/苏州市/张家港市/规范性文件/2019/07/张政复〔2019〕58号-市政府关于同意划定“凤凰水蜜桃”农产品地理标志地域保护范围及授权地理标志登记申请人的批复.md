# 市政府关于同意划定“凤凰水蜜桃”农产品地理标志地域保护范围及授权地理标志登记申请人的批复

张政复〔2019〕58号

来源：市政府发布时间：2019-07-22 14:58:00访问量：字体【大中小】

市农业农村局：

你局《关于划定“凤凰水蜜桃”农产品地理标志地域保护范围及授权地理标志登记申请人的请示》（张农发〔2019〕88号）收悉。经研究，现批复如下：

一、根据《农产品地理标志管理办法》（农业部令2007年第11号）和《农产品地理标志登记程序》（农业部公告2008年第1071号）有关规定，同意将凤凰镇行政区相关地域划定为“凤凰水蜜桃”农产品地理标志地域保护范围，地理坐标为东经120°21′~120°52′，北纬31°43′~32°02′，保护面积为78.7平方公里。

二、根据《农产品地理标志登记申请人资格确认评定规范》（农质安发〔2015〕11号）相关规定，同意授权凤凰镇农业服务中心作为“凤凰水蜜桃”农产品地理标志登记申请人，并负责具体相关工作。

批复。

张家港市人民政府

2019年7月22日
