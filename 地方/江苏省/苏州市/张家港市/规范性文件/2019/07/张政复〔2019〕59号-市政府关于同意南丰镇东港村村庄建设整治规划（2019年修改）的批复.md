# 市政府关于同意南丰镇东港村村庄建设整治规划（2019年修改）的批复

张政复〔2019〕59号

来源：市政府发布时间：2019-07-22 14:36:00访问量：字体【大中小】

南丰镇政府：

你镇上报的《关于报批〈南丰镇东港村村庄建设整治规划〉（2019年修改）的请示》（南政请〔2019〕9号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《南丰镇东港村村庄建设整治规划》（2019年修改）。规划范围为南丰镇东港村村域范围，规划面积4.38平方公里。

二、要加强与南丰镇总体规划、土地利用规划等相关规划的衔接、融合，坚持保护耕地、集约利用土地，提高土地利用效率；要从农村实际出发，尊重村民意愿，体现地方和农村特色，优化村庄生产、生活环境，提高村庄发展和建设整体水平。

三、经市政府批准的《南丰镇东港村村庄建设整治规划》（2019年修改）是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2019年7月22日
