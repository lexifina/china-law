# 市政府关于同意张家港市塘桥镇TQTZ-01地块控制性详细规划的批复

张政复〔2019〕61号

来源：市政府发布时间：2019-07-22 14:32:00访问量：字体【大中小】

塘桥镇政府：

你镇上报的《关于报批〈张家港市塘桥镇TQTZ-01地块控制性详细规划〉的请示》（塘政发〔2019〕24号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《张家港市塘桥镇TQTZ-01地块控制性详细规划》。规划范围：塘桥镇刘村村委西侧、永南河南侧，规划面积3.92公顷。

二、要加强与城市总体规划及土地利用规划等相关规划的有机衔接、融合，协调处理好规划区域与周边区域的关系，保障土地科学、合理与集约利用。

三、经市政府批准的《张家港市塘桥镇TQTZ-01地块控制性详细规划》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2019年7月22日
