# 教育局关于同意张家港市外国语学校附属幼儿园终止筹建的批复

张教〔2019〕81号

张家港市外国语学校：

根据市自然资源和规划局的认定，阳光锦程小区配建的幼儿园属于小区配套幼儿园。按照《国务院办公厅关于开展城镇小区配套幼儿园治理工作的通知》（国办发〔2019〕3号）精神，小区配套幼儿园应办成公办幼儿园或普惠性民办幼儿园。你校《关于不再举办普惠性民办幼儿园的报告》收悉。经研究，同意你校终止筹建活动。《教育局关于同意筹建“张家港市外国语学校附属幼儿园”的批复》（张教〔2016〕139号）废止。

张家港市教育局

2019年7月22日
