# 关于印发高血压、高血脂和糖尿病《慢病用药优选目录》的通知

各定点医疗机构:

根据《关于推进高血压、高血脂和糖尿病患者用药进社区的实施方案》（张医保发〔2019〕35号）要求，我局组织相关专家对高血压、高血脂和糖尿病患者用药药品品规进行了遴选，征求了卫生健康委的意见，汇总得出《慢病用药优选目录》，并进行了社会公示，现将《慢病用药优选目录》印发给你们。请各社区卫生服务中心结合实际，填写《苏州市药品年度采购计划量调整表》，加盖公章后，报送至市医疗保障局医药价格和招标采购科（含excel电子版）。

附件：1.《慢病用药优选目录》
