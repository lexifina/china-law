# 关于分解下达2019年度能源消耗总量和强度“双控”目标的通知

各镇(区):

根据《中华人民共和国节约能源法》和《江苏省节约能源条例》有关规定，为认真贯彻落实国家、省和苏州对“十三五”期间节能减排工作的总体部署部署和要求，经研究，现将2019年度能源消耗总量和强度“双控”目标分解下达给你们。各镇(区)要将节能降耗作为推进生态文明建设的有力举措作为实现高质量发展、绿色发展的重要抓手，明确任务、层层分解、落实责任、加强跟踪、强化措施、周密部署、科学组织，确保全市完成单位地区生产总值能耗降低4.2%的约束性目标。
