# 市政府关于同意锦丰镇部分道路地名命名的批复

锦丰镇人民政府：

你镇《关于锦丰镇三兴农贸市场附近道路命名的请示》（锦政发〔2019〕18号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意对你镇申报的2条现有未命名道路予以命名。具体批复如下：

1．同意将你镇位于沙钢厚生新村南侧，东起厚生二村、西至人民路的道路命名为“厚生弄”。地名标志汉语拼音拼写形式：HOUSHENG LONG。

2．同意将你镇位于久生村6组北侧，东起厚生二村、西至人民路的道路命名为“久生弄”。地名标志汉语拼音拼写形式：JIUSHENG LONG。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好道路标志牌、门号牌及桥梁标志牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2019年8月7日
