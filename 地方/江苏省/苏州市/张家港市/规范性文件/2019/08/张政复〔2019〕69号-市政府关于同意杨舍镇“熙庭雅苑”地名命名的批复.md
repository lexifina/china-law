# 市政府关于同意杨舍镇“熙庭雅苑”地名命名的批复

张政复〔2019〕69号

来源：市政府发布时间：2019-08-16 16:41:00访问量：字体【大中小】

杨舍镇人民政府：

你镇《关于〈熙庭雅苑〉地名命名的请示》（杨政请〔2019〕23号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将位于你镇泗港路以东、暨阳西路以南、河滨路以西、梁丰西路北侧空地以北范围内新建的住宅区命名为“熙庭雅苑”。地名标志汉语拼音拼写形式：XITING YAYUAN。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2019年8月16日
