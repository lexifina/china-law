# 市政府关于同意塘桥镇部分道路地名命名的批复

塘桥镇人民政府：

你镇《关于塘桥镇部分道路命名的请示》（塘政发〔2019〕35号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意对你镇申报的6条现有未命名道路予以命名。具体批复如下：

1．同意将你镇位于西旸路（拟命名）东侧，南起张杨公路、北至东张组农田的道路命名为“辟尘路”。地名标志汉语拼音拼写形式：PICHEN LU。

2．同意将你镇位于辟尘路（拟命名）西侧，南起妙丰公路、北至七干河的道路命名为“西旸路”。地名标志汉语拼音拼写形式：XIYANG LU。

3．同意将你镇位于西旸塘东侧，南起永进路、北至妙桥中路的道路命名为“沿河街”。地名标志汉语拼音拼写形式：YANHE JIE。

4．同意将你镇位于张杨公路北侧，东起辟尘路（拟命名）、西至西旸路（拟命名）的道路命名为“创富路”。地名标志汉语拼音拼写形式：CHUANGFU

LU。

5．同意将你镇位于长茂街（拟命名）北侧，东起金村路、西至张家港市骏超针织服饰有限公司的道路命名为“园茂街”。地名标志汉语拼音拼写形式：YUANMAO JIE。

6．同意将你镇位于园茂街（拟命名）南侧，东起金村路、西至恬杏路的道路命名为“长茂街”。地名标志汉语拼音拼写形式：CHANGMAO JIE。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好道路标志牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2019年8月22日
