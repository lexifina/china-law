# 市政府关于同意大新镇部分道路地名命名的批复

大新镇人民政府：

你镇《关于大新镇新湖东路、新湖西路和新幼路命名的请示》（大政发〔2019〕34号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意对你镇申报的3条现有未命名道路予以命名。具体批复如下：

1．同意将你镇位于国泰北路东侧，南起新湖南路、北至新湖北路的道路命名为“新湖东路”。地名标志汉语拼音拼写形式：XINHU DONGLU。

2．同意将你镇位于国泰北路西侧，南起新湖南路、北至新湖北路的道路命名为“新湖西路”。地名标志汉语拼音拼写形式：XINHU XILU。

3．同意将你镇位于新湖中路北侧，东起海坝路、西至新湖东路（拟命名）的道路命名为“新幼路”。地名标志汉语拼音拼写形式：XINYOU LU。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好道路标志牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2019年8月22日
