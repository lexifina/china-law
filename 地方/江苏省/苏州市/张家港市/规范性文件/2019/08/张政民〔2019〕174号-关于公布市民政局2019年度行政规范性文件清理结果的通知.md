# 关于公布市民政局2019年度行政规范性文件清理结果的通知

局机关各科室、局属各单位：

根据市推进依法行政建设法治政府领导小组办公室《关于开展2019年度行政规范性文件清理工作的通知》（张法政办〔2019〕4号）的要求，我局对截至2019年6月5日前制定的，现行有效的5份行政规范性文件进行了清理。经研究，《张家港市居民最低生活保障实施细则》（张政民规〔2013〕1号）、《关于进一步培育发展和规范管理本市社会组织的若干意见（试行）》（张政民规〔2013〕3号）、《关于加快培育发展本市专业社会工作机构的若干意见》（张政民规〔2013〕4号）、《关于规范本市社会组织财务管理的意见》（张政民规〔2013〕5号）、《关于印发张家港市推行绿色殡葬实施办法的通知》（张政民规〔2014〕1号）继续施行。

张家港市民政局

2019年8月6日
