# 关于公布2018～2019学年课程建设先进学校、安全教育先进（示范）学校、德育特色学校、依法治教先进学校认定结果的通知

各（区）镇教卫文体办公室（综合办），各中小学、幼儿园，各直属单位、机关各科室：

根据教育局《关于在2018～2019学年继续组织开展项目化活动的通知》（张教〔2018〕106号）文件精神，教育局组织相关职能科室经过严格考评，现将“课程建设先进学校”“安全管理特色项目学校”“体育、艺术特色学校”“依法治教先进学校”的认定结果公布如下：

一、课程建设先进学校（40所）

1.中学（13所）

梁丰高级中学、沙洲中学、暨阳高级中学、张家港高级中学、乐余高级中学、港口学校、第一中学、东渡实验学校、三兴学校、港区初级中学、塘桥初级中学、南丰中学、南沙中学

2.小学（19所）

塘市小学、青龙小学、崇真小学、金港中心小学、大新中心小学、南丰小学、合兴小学、乘航小学、乐余中心小学、中兴小学、港区小学、东莱小学、南沙小学、徐市小学、梁丰小学、凤凰中心小学、妙桥小学、沙洲小学、福前实验小学

3.幼儿园（8所）

机关幼儿园、南苑幼儿园、南丰幼儿园、东湖苑幼儿园、锦丰中心幼儿园、大新中心幼儿园、东莱幼儿园、妙桥幼儿园

二、安全管理特色项目学校（30所）

1.交通安全管理特色项目学校（11所）

塘桥中心幼儿园、南沙幼儿园、外国语学校、云盘小学、第三职业中学、金港中心幼儿园、乘航小学、白鹿小学、东莱小学、锦丰中心幼儿园、实验幼儿园

2.消防安全管理特色项目学校（4所）

暨阳高级中学、德积小学、南丰幼儿园、东渡实验学校

3.事故预防管理特色项目学校（6所）

花园浜幼儿园、实验小学、大新中心小学、塘桥初级中学、合兴小学、青龙小学

4.食品安全管理特色项目学校（7所）

凤凰中心幼儿园、江帆小学、港区幼儿园、常青藤实验学校、锦丰中心小学、万红幼儿园、暨阳实验小学

5.校车安全管理特色项目学校（1所）

南丰小学

6.实习安全管理特色项目学校（1所）

中等专业学校

三、体育、艺术特色学校

（一）体育特色学校（35所）

1.中学（16所）

第八中学、护漕港中学、中等专业学校、大新实验学校、第三职业高级中学、暨阳湖实验学校、港口学校、梁丰初级中学、南沙中学、南丰中学、暨阳高级中学、第六中学、港区初级中学、合兴初级中学、张家港高级中学、第三中学

2.小学（19所）

泗港小学、合兴小学、实验小学、白鹿小学、凤凰中心小学、塘市小学、暨阳实验小学、乐余中心小学、云盘小学、万红小学、福前实验小学、南丰小学、德积小学、南沙小学、新塍小学、中兴小学、青龙小学、徐市小学、江帆小学

（二）艺术特色学校（12所）

1.中学（4所）

第二中学、东渡实验学校、张家港高级中学、第一中学

2.小学（8所）

白鹿小学、云盘小学、梁丰小学、金港中心小学、南丰小学、锦丰中心小学、暨阳实验小学、大新中心小学

中兴小学、东莱小学、合兴小学、白鹿小学、塘市小学、徐市小学、金港中心小学、沙洲小学、妙桥小学、凤凰中心小学

3.幼儿园（18所）

万红幼儿园、花园浜幼儿园、东莱幼儿园、南丰幼儿园、福前实验幼儿园、东湖苑幼儿园、乘航幼儿园、江帆幼儿园、鹿苑幼儿园、实验幼儿园、泗港实验幼儿园、杨舍中心幼儿园、港口幼儿园、凤凰中心幼儿园、兆丰幼儿园、城北幼儿园、塘桥中心幼儿园、飞翔幼儿园

希望受表彰的学校再接再厉，同时希望其他学校以先进为榜样，认真贯彻落实我市教育系统“三聚两先”行动计划，以建办平衡充分发展的优质教育为目标，落实“立德树人”根本任务，持续加强内涵建设，不断提升办学质量，为我市打造“港城发展升级版”贡献教育力量。
