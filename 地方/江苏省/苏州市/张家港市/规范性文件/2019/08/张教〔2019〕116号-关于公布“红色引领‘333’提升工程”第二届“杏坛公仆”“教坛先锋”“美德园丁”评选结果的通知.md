# 关于公布“红色引领‘333’提升工程”第二届“杏坛公仆”“教坛先锋”“美德园丁”评选结果的通知

各中小学、幼儿园，各直属单位：

为进一步推进教育系统“红色引领333提升工程”，充分发挥典型引领，大力宣传和弘扬先进人物的先进事迹，经个人申报、学校推荐、小组评议、市教育局公示等环节，确定王丽芳等10位同志为“杏坛公仆”；王建娟等10位同志为“教坛先锋”;丁云吉等10位同志为“美德园丁”。现将具体评选结果公布如下（见附件）。

希望新评选产生的“杏坛公仆”“教坛先锋”“美德园丁”三类对象以此为新的起点，充分发挥典型示范引领作用；全体教师要以先进典型为榜样，积极作为，努力工作，为建办人民满意的教育作出应有的贡献。
