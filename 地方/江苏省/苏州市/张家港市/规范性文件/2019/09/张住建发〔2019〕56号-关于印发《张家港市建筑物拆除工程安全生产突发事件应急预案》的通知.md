# 关于印发《张家港市建筑物拆除工程安全生产突发事件应急预案》的通知

各机关科室、各企事业单位：

现将《张家港市建筑物拆除工程安全生产突发事件应急预案》印发给你们，请认真组织实施。

张家港市住房和城乡建设局

2019年9月17日

（此件公开发布）

张家港市建筑物拆除工程安全生产突发事件应急预案

为防止和减少建筑物拆除工程安全生产突发事件造成的人员伤亡、财产损失和社会影响，维护正常的社会秩序，根据《中华人民共和国突发事件应对法》、国务院《建设工程安全生产管理条例》和《张家港市突发公共事件总体应急预案》等有关规定，本着“安全第一、预防为主、积极应对、有效处置”的原则，结合我市建筑物拆除工程管理工作实际和施工行业特点，特制定本应急预案。

一、适用范围

在我市行政区域范围内符合《张家港市建筑物拆除行业管理规定》规定的建筑物拆除工程，在拆除施工活动过程中发生或可能发生的安全生产突发事件，适用本应急预案。

本应急预案所称的突发事件是指在建筑物拆除施工过程中遇到恶劣天气自然灾害或因施工方法失当、机械操作失误或施工安全隐患排查整治不到位造成或可能造成人员伤亡或重大经济损失的安全生产突发事件。

二、应急指挥体系及职责分工

（一）应急指挥体系设置

成立张家港市人民政府房屋征收办公室建筑物拆除工程安全生产突发事件应急指挥办公室（以下简称市拆除应急办），应急指挥系统实行“统一指挥、分级负责、属地管理、条块联动”的管理模式。

市拆除应急办设在张家港市人民政府房屋征收办公室，统一组织协调全市建筑物拆除工程突发事件的应急救援工作。

各区（镇）按照属地管理的要求，设立相应的应急指挥机构，接受市拆除应急办的统一指挥，组织处置好辖区范围内建筑物拆除工程施工现场的应急救援工作。

各建筑物拆除施工企业建立以分公司负责人为第一责任人的应急救援工作领导小组，明确安全生产分管负责人，具体承担本企业建筑物拆除工程施工现场的应急救援工作，并接受市拆除应急办和各辖区应急机构的工作指导和指令调度。

（二）各指挥系统的主要职责

1. 市拆除应急办主要职责

（1）督促、检查、指导各区（镇）和建筑物拆除施工企业建立相应的应急指挥机构和应急救援队伍。

（2）督促、检查、指导各区（镇）应急指挥机构和建筑物拆除施工企业制订、修订本部门、本单位的应急预案。

（3）迅速接受并及时传达上级部门的命令和指示，及时收集、整理、分析建筑物拆除工程安全生产突发事件信息，对发生的安全生产事故信息及时报告市应急管理办公室。

（4）组织专家指导、参与各区（镇）建筑物拆除工程安全生产突发事件的应急处置，配合参与市政府安全生产监督管理部门组织的建筑物拆除工程安全生产事故调查。

（5）根据建筑物拆除工程突发事件的危害程度、大小和各区（镇）或建筑物拆除施工企业的援助请求，合理调度各建筑物拆除施工企业的应急救援队伍和应急救援装备。

2. 各区（镇）应急指挥机构主要职责

（1）制订本辖区内建筑物拆除工程突发事件应急预案，并成立相应的安全生产突发事件应急指挥机构，并将应急预案及应急指挥机构设置情况报市拆除应急办备案。

（2）及时传达落实市拆除应急办下达的应急指令，定期组织开展辖区建筑物拆除工程突发事件应急演练，并适当配备应对突发事件所需的装备器材。

（3）检查落实辖区内建筑物拆除施工企业应急预案制订情况、应急救援队伍建立情况和应急装备器材购置配备情况。

（4）根据拆除工程施工和天气变化状况，及时组织对辖区拆除工程施工现场易发生危险的部位和环节进行隐患排查，并督促建设单位和拆除施工企业做好预防、监控措施。

（5）组织开展辖区内建筑物拆除工程安全生产突发事件的应急处置，及时了解情况，并根据突发事件的危害程度、事故大小，及时向市拆除应急办报告拆除工程安全生产突发事件信息和处理建议，防止突发事件事态扩大。

3. 建筑物拆除施工企业主要职责

（1）制订本企业拆除工程突发事件应急预案，建立由企业主要负责人和分管安全生产经理、技术负责人为主要成员的企业生产安全突发事件应急工作领导小组，并报市拆除应急办和所属辖区应急指挥机构备案。

（2）抽调有常年工程管理经验、熟悉拆除施工技术、熟练施工机械操作和有特殊工种技能的专业技术人员，组建常态化的企业应急救援队伍，配备必需的应急救援装备器材，并报市拆除应急办和所属辖区应急指挥机构备案。

（3）接受市拆除应急办或所属辖区应急指挥机构下达的应急指令，服从应急救援队伍或应急救援装备调度安排，确保每年至少开展一次拆除工程突发事件应急演练。

（4）根据拆除工程施工和天气变化状况，对拆除工程施工现场易发生危险的部位、环节及时进行隐患排查，并采取相应的预防、监控措施。

（5）及时开展本企业拆除工程安全生产突发事件的应急处置，积极采取有效措施防止事态扩大，并按规定向市拆除应急办及所属辖区应急指挥机构报告突发事件信息。

（6）拆除工程生产安全突发事件处置期间，服从市拆除应急办或所属辖区应急指挥机构的统一领导、组织、指挥和协调，保障应急处置所需的人员和物资，妥善做好突发事件调查和善后处理工作。

三、监测与预警

（一）信息监测。处置建筑物拆除工程安全生产突发事件坚持早发现、早报告、早处置和预防为主的原则。各区（镇）应急指挥机构以及拆除工程的建设单位、拆除施工企业要建立拆除工程重大危险源档案、辩识体系和监测制度，科学评估可能发生的突发事件及其严重性、可控性和影响程度，定人、定时、定向交叉进行检查和监测，及时发现危险源和突发特征、事故征兆。

（二）预警级别。拆除工程的突发事件按照发生的紧急程度、发展势态和危害程度等因素，由低到高划分为一般（Ⅳ级）、较重（Ⅲ级）、严重（Ⅱ级）、特别严重（Ⅰ级）四个预警级别，依次采用蓝色、黄色、橙色和红色表示。

蓝色等级（Ⅳ级）：拆除施工可能危及施工现场人员或毗邻区域人员生命财产安全的一般（Ⅳ级）以上突发事件，事件即将发生，事态可能会扩大。

黄色等级（Ⅲ级）：拆除施工可能危及施工现场人员或毗邻区域人员生命财产安全的较大（Ⅲ级）以上突发事件，事件已经临近，事态有扩大的趋势。

橙色等级（Ⅱ级）：拆除施工可能危及施工现场人员或毗邻区域人员生命财产安全的重大（Ⅱ级）以上突发事件，事件即将发生，事态正在逐步扩大。

红色等级（Ⅰ级）：拆除施工可能危及施工现场人员或毗邻区域人员生命财产安全的特别重大（Ⅰ级）突发事件，事件会随时发生，事态正在趋于严重。

（三）信息报告。发现拆除工程危险源突发特征或事故征兆后，拆除工程的建设单位、拆除施工企业要立即报告本单位主要负责人和项目负责人。拆除施工企业主要负责人会同企业安全生产突发事件应急工作领导小组或项目负责人对危险源突发特征或事故征兆研判后，应按照突发事件的级别及时报告所属辖区应急指挥机构。辖区应急指挥机构对信息进行研判后，要第一时间通过电话向市拆除应急办和辖区报告信息，并在1小时内作出书面报告。市拆除应急办接到报告后应迅速报告上级应急指挥机构。

（四）预警支持。市拆除应急办及各区（镇）应急指挥机构要建立值班制度，设立24小时值班电话，值班室要掌握本部门应急指挥机构领导和所有成员的联系方式，以及上级应急指挥机构的值班电话，指定专人值班并负责突发事件报告工作。

四、应急响应

市拆除应急办和各区（镇）应急指挥机构、拆除施工企业应按照本应急预案要求，按照职责分别做好建筑物拆除工程安全生产突发事件的应急处置工作。

（一）先期处置。发生或确认即将发生拆除工程较大以上突发事件，各区（镇）应急指挥机构或相关拆除施工企业负责同志要迅速赶赴现场，视情况成立现场应急指挥机构，组织人力、物力立即开展先期处置，及时对事件的性质、类别、危害程度、影响范围、防护措施、发展趋势等进行评估上报。当恶劣天气自然灾害、事故灾难发生后，应当按照《中华人民共和国突发事件应对法》第四十九条的规定，及时采取应对措施。先期处置一般程序和措施：停止拆除施工；转移、疏散或者撤离易受突发事件危害的人员；加强安全警戒，维护现场秩序；采取措施，控制事态发展；报告上级应急指挥机构，必要时请求支援。

（二）分级响应。接到拆除工程突发事件监测预警信息后，各有关部门和单位应按照预警信息立即作出响应，按照早控制、早解决的原则进入相应的应急工作状态，及时启动相关的应急响应，履行各自所应承担的职责。四个预警级别的突发事件应当按照《中华人民共和国突发事件应对法》第四十四条、四十五条的有关规定采取相应的应对措施。对于先期处置未能有效控制事态，需要市政府或市拆除应急办协调处置的特别重大、重大突发事件，根据市政府领导指示或者实际需要，或者应辖区应急指挥机构的请求，市拆除应急办提出处置建议向市政府领导报告，经批准后启动相关应急响应。

(三)指挥协调。需要市政府或市拆除应急办协调处置的特别重大、重大、较大突发事件，由市拆除应急办负责人赶赴事发地，或派出工作组、专家组，按照市应急管理办公室或市政府领导指示，视情调集应急救援队伍，统一指挥或指导有关区（镇）开展应急处置。属于一般突发事件，由事发地辖区应急指挥机构报告辖区领导后启动应急响应，采取应急措施开展应急处置。

（四）应急结束。突发事件危害因素基本消除，应急处置工作即告结束。特别重大、重大突发事件，由市政府应急管理办公室宣布应急结束；较大和一般突发事件，由市拆除应急办或事发地辖区宣布应急结束。突发事件应急处置结束的一般条件和情况：突发事件的危险性已得到有效控制或消除，确保不会发生耦合事故；现场无关人员已全部撤离，整改措施已经辖区应急指挥机构审查同意。

（五）后期处置。事发地按照国家有关规定，组织突发事件损害调查核定工作，积极稳妥、深入细致地做好善后处理工作，对事件损失情况、恢复施工能力、可利用资源等作出评估，对在应急救援中伤亡的人员依法给予抚恤，并迅速组织实施。

（六）评估总结。突发事件应急处置结束后15日内，事发地应急指挥机构要及时对应急处置工作进行总结评估，提出加强和改进同类事件应急工作的改进建议和意见，以书面形式报市拆除应急办。市拆除应急办于每年年初对上年度发生的突发事件及其应对工作进行全面总结、分析和评估，并向市政府报告。

五、其他事项

（一）市拆除应急办针对有可能发生的建筑物拆除工程安全突发事件，组织实施紧急救援工作并协助上级部门进行事故调查处理，在实施过程中根据不同情况随机进行处理。

（二）各建筑物拆除施工企业要根据条件和环境的变化及时修改和完善预案的内容，掌握预案的内容和相关措施。确保在紧急情况下按照预案的要求，有条不紊的开展突发事件应急处理工作。

(三)发生建筑物拆除工程突发状况后，事故单位应立即报告，各有关部门负责人在接到事故发生信息后必须在最短时间内进入各自岗位，迅速开展工作。对任何失职、渎职行为都要依法追究责任。

（四）本预案自公布之日起实施。
