# 关于给茅庆平等同志战时嘉奖的命令

各警署、各派出所、直属各单位、机关各部门：

为表彰先进，鼓舞士气，激发斗志，根据《公安机关人民警察奖励条令》规定，特命令：给下列6位同志分别记个人嘉奖一次，颁发证书和奖金：

1．茅庆平，常阴沙派出所副所长

2．张占鹏，法制大队民警

3．赵 鑫，治安大队民警

4．周明刘，南沙派出所副所长

5．胡嘉诚，大新派出所民警

6．王 腾，鹿苑派出所民警

希望受到表彰的同志珍惜荣誉、戒骄戒躁，再接再厉、再创佳绩。全市公安机关和广大民警要以先进为榜样，以更加昂扬的斗志、更加饱满的热情，全力以赴做好各项安保维稳工作，确保全市社会大局持续稳定，以优异成绩向新中国成立70周年献礼！

此令。

公安局长　周斌伟

2019年9月14日
