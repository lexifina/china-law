# 关于重新明确村集体经济组织资产财务管理人员岗位称呼和岗位职责的通知

各镇农经管理部门：

随着农村改革的不断深入，以村集体资产为对象的农村经营管理内容、管理方式、管理手段发生重大变化，同时我市已经全面实施村级财务“第三方”代理记账，村会计不再记账,村会计和村出纳的工作职责发生了变化。为适应当前管理需要，也为培养一支业务精通、素质过硬的基层农经管理队伍，根据《江苏省农村集体资产管理条例》和上级有关规定，经研究，将村级集体经济组织资产财务管理人员岗位称呼和岗位职责重新明确如下：

一、岗位称呼

原具体负责村集体经济组织资产财务管理的村会计，根据现有农村组织架构和当前管理需要，以及基层群众的传统，明确为村会计（资产管理办主任）。村出纳明确为村报账员（资产管理员）。以上由各镇（区）根据组织人事管理要求明确。

二、村会计（资产管理办主任）工作职责

1.编制财务收支预算，落实预算执行，编制财务收支决算，抓好财务日常管理；

2.定期不定期开展清产核资，抓好农村集体资产管理信息化建设；

3.落实农村集体资产资源流转全部进场交易；

4.参与建设项目立项、招投标、建设和工程审计管理；

5.参与经济合同签订和租金收缴管理；

6.落实社区股份合作制改革、政经分开等农村改革工作；

7.做好农村土地承包经营权、土地流转管理工作；

8.做好财务公开、“e阳光”、民主理财等民主监督工作；

9.做好农村一次分配、二次分配和涉农惠农补贴发放工作；

10.参与村下属集体企业管理；

11.配合村级财务“第三方”代理机构做好财务代理记账工作；

12.负责与上级农经管理部门工作对接，做好各类农经管理情况的统计、报表、分析、上报工作；

13.配合做好村级阳光综合审计工作；

14.做好农村公益事业“一事一议”工作；

15.做好财务、资产等农经管理档案管理工作；

16.其他农经管理及领导交办工作。

三、村报账员（资产管理员）工作职责

1.按照有关审批程序逐笔审核原始凭证，所有收支业务按规定及时结报;

2.负责将村务卡和备用金结算卡的支出明细与银行对账单每月进行核对,做好村务卡及银行存款日记账登记工作；

3.核对有关账目，对“第三方”代理返还的财务报表应及时对账，发现错误及时纠正；

4.做好各种有价证券、票据等保管和使用工作;

5.配合做好民主理财、财务公开、“e阳光”微信公众号等民主监督工作;

6.做好其他农经管理及村会计（资产管理办主任）交办工作。

张家港市农业农村局
