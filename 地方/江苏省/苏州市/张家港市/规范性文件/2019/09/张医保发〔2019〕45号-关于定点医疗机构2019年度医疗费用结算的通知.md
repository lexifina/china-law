# 关于定点医疗机构2019年度医疗费用结算的通知

市医保经办机构、各定点医疗机构：

根据市人社局、财政局和卫计委联合下发的《张家港市社会医疗保险定点医疗机构医疗费用结算管理办法》（张人社规〔2015〕2号）精神，现就2019年度（2019.7-2020.6）定点医疗机构医疗费用总额预算指标及年终决算的有关事项通知如下：

一、2019年度定点医疗机构医疗费用总额预算指标

1.门诊总额预算指标：职工医保以2018年度（2018.7-2019.6）预算基数(不超过2018年度实际医疗费用)为基数，对各定点医疗机构2018年度门诊次均费用和门诊人头人次比等指标与同级别定点医疗机构的平均值和本医疗机构前三年的平均值进行考核，根据各定点医疗机构的考核结果，结合服务人群及能力建设情况，分别确定2%至5%的浮动增长率。居民医保继续不设增幅。

2.住院总额预算指标：职工医保以2018年度（2018.7-2019.6）预算基数以及因新技术新项目开展增加的决算总额之和(不超过2018年度实际医疗费用)为基数，对各定点医疗机构2018年度百门诊人数住院率、住院人均费用、平均住院日、病床使用率等指标与同级别定点医疗机构的平均值和本医疗机构前三年的平均值进行考核，根据各定点医疗机构的考核结果，结合服务人群及能力建设情况，分别确定-2%至4%的浮动增长率。居民医保继续不设增幅。

二、2019年度年终决算原则

1.对因服务能力提升、公共卫生应急（流感爆发等）以及规模体系建设等原因引起医疗服务量发生较大变化的定点医疗机构，根据其服务人数的增加值进行年终决算总额的调整。

2.根据各定点医疗机构2019年度开展的新技术、新项目情况，合理增加年终决算总额。

3.对社区卫生服务中心（站）因提供长处方服务，《慢病用药优选目录》内药品费用较2018年度合理增加的费用，不列入年终决算总额。

4.对各定点医疗机构2019年度门诊次均费用、门诊人头人次比、百门诊人数住院率、住院人均费用、平均住院日、病床使用率等指标结合服务人数进行考核，分别与同级别定点医疗机构的平均值和本医疗机构前三年的平均值进行比较，严格控制超指标医疗费用的不合理增长，科学确定各定点医疗机构年终决算总额的调整额度。

5.建立日常稽核与年终决算挂钩机制，定期通报日常稽核情况，并将稽核情况与年终决算总额的调整直接挂钩；建立医疗保障、卫生健康、市场监管等多部门联合考核机制，并将考核结果与年终决算时门诊及住院次均费用指标计算挂钩；完善和加强对医保定点医疗机构的监督管理，提高医保管理服务水平，建立费用激励和约束机制，鼓励定点医疗机构提升内部管理质量。
