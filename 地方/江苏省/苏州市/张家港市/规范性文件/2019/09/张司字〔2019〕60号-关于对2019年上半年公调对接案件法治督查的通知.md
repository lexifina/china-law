# 关于对2019年上半年公调对接案件法治督查的通知

为了更好地推进公调对接工作，充分发挥公调对接在维护社会稳定中的积极作用，市司法局将联合市公安局对2019年上半年度公调对接案件进行法治督查。

现通知如下：

一、督查日程

9月16日至18日 杨舍警署辖区各派出所

9月19日至20日 金港警署辖区各派出所

9月23日至24日 乐余警署辖区各派出所

9月25日        塘桥警署辖区各派出所

9月26日        凤凰警署辖区各派出所

9月27日        锦丰警署辖区各派出所

二、督查组成员

市司法局  人民参与与促进法治科

市公安局  指挥中心

各司法所（办）

三、督查内容

1.规范化制作人民调解卷宗情况。

2.人民调解个案补贴申报、发放情况。

3.人民调解小助手平台录入情况。

四、督查形式

通过召开座谈会，查阅人民调解卷宗、台账的形式开展督查。

五、工作要求

1.本次督查是对各公调对接组织上半年度工作的全面评价和调解员工作能力的全面检验。督查结果将作为市司法局评选优秀调解组织、优秀调解员等有关活动的主要依据。

2.各司法所（办）应高度重视此次督查工作，高标准高要求的负责协助、指导各公调对接组织做好迎检准备工作。
