# 市政府关于同意塘桥镇“云筑”地名命名的批复

张政复〔2019〕73号

来源：市政府发布时间：2019-09-05 15:08:00访问量：字体【大中小】

塘桥镇人民政府：

你镇《关于塘桥镇“云筑”地名命名的请示》（塘政发〔2019〕37号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将位于你镇浏泾塘以东、北环路以南、维达路以西、富民路以北范围内新建的住宅区命名为“云筑”。地名标志汉语拼音拼写形式：YUN ZHU。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。
