# 市政府关于同意塘桥镇部分桥梁地名命名的批复

塘桥镇人民政府：

你镇《关于塘桥镇部分桥梁命名的请示》（塘政发〔2019〕41号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意对你镇申报的2座桥梁予以命名。具体批复如下：

1．同意将你镇位于南苑东路向东延伸段规划道路，锡张高速（S19）东侧，跨越黄泗浦大塘的桥梁命名为“西塘岸桥”。地名标志汉语拼音拼写形式：XITANGAN QIAO。

2．同意将你镇位于南苑东路向东延伸段规划道路，西环路西侧，跨越三干河的桥梁命名为“和平桥”。地名标志汉语拼音拼写形式：HEPING QIAO。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2019年9月25日
