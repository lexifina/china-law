# 关于调整市科学技术局领导工作分工的通知

局机关各科室，生产力促进中心、科技人才服务中心：

因人事变动，经局党组会议研究决定，现将局领导工作分工调整如下：

赵瑜：党组书记、局长，主持市科技局全面工作。

俞萍：党组成员、副局长，协助分管党的建设、组织人事、财务工作，负责绩效考核、文明创建、科技宣传、政务公开、法治建设、市级科技计划、信息化、保密、双拥、老干部及群团、机关事务管理方面的工作，分管办公室(党建科)。

朱晨阳：党组成员、副局长，负责高新技术产业化、农业农村科技进步、社会事业科技发展、科技对口支援、科技金融方面的工作，分管高新技术与社会发展科。

张天若：党组成员、副局长，负责科技合作、成果转化、技术转移体系建设、长三角一体化、科技行业协会管理及科技镇长团方面的工作，分管科技合作与成果转化科。

孙东亮：副局长，负责科技人才、科技人才活动周筹备、创新展示中心、创新创业梦工厂方面的工作，分管科技人才与外国专家科、生产力促进中心、技术市场。

宓灏文：党组成员、副局长，负责创新型县(市)、高新区建设、创新例会、科技载体、科技服务、科技安全生产方面的工作，分管区域创新与载体建设科、科技人才服务中心。

特此通知。
