# 市人力资源和社会保障局关于发布《张家港市2019—2020年度重点产业紧缺专业需求目录》的通知

各有关单位：

为深入推进人才优先发展战略和创新驱动发展战略，加强全市重点产业紧缺人才队伍建设，引导紧缺人才向支柱产业和重点新兴产业集聚，提升我市人才资源竞争优势，编制了《张家港市2019—2020年度重点产业紧缺专业需求目录》（以下简称《目录》），经市人才办主任会议审定，现予以发布。有关事项说明如下：

1．《目录》覆盖我市发展规划中布局定位的主导产业和重点产业，包括：新能源、新材料、高端装备制造、电子信息（半导体）、冶金、化工、机电等15个产业领域，共110个岗位。

2．本次《目录》引入了“紧缺程度”，根据不同产业专业和岗位需求情况划分为1~4四个等级，其中1级为一般紧缺，一年内计划招募到岗，4级为急缺，需尽快招募到岗。“紧缺程度”的引入将进一步指导我市企业引进产业急缺人才。

3．《目录》中涉及的相关专业、岗位、紧缺程度等信息将用于落实人才礼遇相关待遇：“人才礼遇分类认定”以及“人才礼遇薪酬补贴申请”，具体要求以实际通知为准。

希望各单位继续重视优秀人才的引进和培育工作，不断提升服务水平，进一步优化人才发展环境，为港城经济发展提供人才支撑和智力保障。
