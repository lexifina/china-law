# 关于调整职工基本医疗保险个人账户购买商业健康保险产品的通知

各有关单位：

根据苏州市医疗保障局及审计相关工作要求，严禁扩大职工医保个人账户购买“返本型”商业健康保险，对部分个人账户购买商业健康保险产品进行调整替换，现予以公布，请各单位做好对照和解释工作。

保重疾（100种）、特定疾病（50种）、身故或全残以及保费豁免。

1、重疾保障：(1)若被保险人因遭受意外伤害被确诊初次发生本合同约定的重大疾病（无论一种或多种，下同），或在本合同生效或最后一次复效（以较迟者为准）之日起180 日后因意外伤害以外的原因被确诊初次发生本合同约定的重大疾病，我们按本合同基本保险金额给付重大疾病保险金，本合同终止。

(2)若被保险人在本合同生效或最后一次复效（以较迟者为准）之日起180日内因意外伤害以外的原因被确诊初次发生本合同约定的重大疾病，我们按您根据本合同约定已支付的保险费总额给付重大疾病保险金，本合同终止。

2、特定疾病保障：若被保险人因遭受意外伤害被确诊初次发生本合同约定的特定疾病，或在本合同生效或最后一次复效（以较迟者为准）之日起180 日后因意外伤害以外的原因被确诊初次发生本合同约定的特定疾病，保险人按基本保额的20%给付特定疾病额外给付保险金，特定疾病额外给付保险金给付以3次为限，每种特定疾病仅限给付1次；

3、身故或全残保障：若被保险人身故或全残，保险人按基本保额给付身故保险金或全残保险金（180日内非意外原因或未成年人，给付已支付的保险费总额）；

4、保险费豁免：若被保险人首次符合特定疾病额外给付保险金给付条件，除给付特定疾病额外给付保险金外，自被保险人被确诊初次发生合同约定的特定疾病后的首个保险费约定支付日起，我们每年于保险费约定支付日豁免本合同当期应支付的保险费，直至本合同终止。

一般医疗保险金

被保险人因遭受意外伤害或在疾病观察期后因患疾病，在指定医疗机构接受治疗的，依约给付一般医疗保险金；

重大疾病医疗保险金

被保险人因遭受意外伤害被确诊初次发生合同约定的重大疾病(无论一种或多种)，或在疾病观察期后因意外伤害以外的原因首次发病并被确诊初次发生合同约定的重大疾病，在指定医疗机构接受治疗的，首先按照前款约定给付一般医疗保险金，当累计给付金额达到基本保险金额后，依约给付重大疾病医疗保险金；

重大疾病保险金

被保险人因遭受意外伤害被确诊初次发生合同约定的重大疾病(无论一种或多种)，或在疾病观察期后因意外伤害以外的原因首次发病并被确诊初次发生合同约定的重大疾病，按合同约定的重大疾病保险金额给付重大疾病保险金。
