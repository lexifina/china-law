# 关于下达2019年第三批基本公共卫生服务项目经费的通知

各镇(区)财政所、社区卫生服务中心：

现将省财政厅、省卫健委《关于下达2019年基本公共卫生服务补助资金的通知》(苏财社〔2019〕64号)下达的基本公共卫生服务项目经费783万元下达你们，列2019年度“医疗卫生---公共卫生---基本公共卫生服务”支出。

请各镇(区)等额安排镇级配套基本公共卫生经费，并按规定专账管理，专款专用。

附件：2019年第三批基本公共卫生服务项目经费表

张家港市卫生健康委员会

2019年11月5日
