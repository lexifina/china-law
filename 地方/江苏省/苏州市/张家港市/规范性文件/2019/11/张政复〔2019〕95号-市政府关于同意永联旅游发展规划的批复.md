# 市政府关于同意永联旅游发展规划的批复

南丰镇政府：

你镇上报的《关于报批永联旅游发展规划的请示》（南政请〔2019〕11号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《永联旅游发展规划》。规划范围为永联村及周边区域和核心区域两级。规划年限为2016—2025年，其中近期为2016—2020年，中远期为2021—2025年。

二、要加强与城市总体规划、土地利用规划、南丰镇总体规划等相关规划的衔接、融合，严格控制建设用地规模，优化建设用地结构和布局，加大存量建设用地挖潜力度，促进各项建设集约节约用地，提高土地使用效率。

三、要贯彻落实“一年布局、两年成形、三年见效”的创建节奏，注重特色风情打造，充分挖掘江南乡村文化、农耕文化、沙洲文化，整合区域资源，发挥“旅游+”作用，不断提升服务水平，努力打造江南田园风情浓郁、游客体验独特、公共配套完善、运营管理有效的旅游风情小镇。

四、要完善公共服务设施，完善建设小镇客厅、旅游住宿设施、餐饮设施、商业服务设施、给排水和污水、公厕设施以及信息网络等基础配套设施建设。

五、经市政府批准的《永联旅游发展规划》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2019年11月6日
