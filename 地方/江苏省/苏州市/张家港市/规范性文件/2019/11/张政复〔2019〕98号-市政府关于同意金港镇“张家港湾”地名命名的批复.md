# 市政府关于同意金港镇“张家港湾”地名命名的批复

张政复〔2019〕98号

来源：市政府发布时间：2019-11-10 16:38:00访问量：字体【大中小】

金港镇人民政府：

你镇《关于命名“张家港湾”的请示》（金政请〔2019〕11号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意将位于你镇福南水道东入口侧江堤以东、长江水面（德积）以南、张皋路（俗称）以西、德积东新路以北及沿线堤岸至张家港河口的区域范围命名为“张家港湾”。地名标志汉语拼音拼写形式：ZHANGJIAGANG WAN。

请按照《地名标志》（GB17733—2008）国家标准，及时做好地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2019年11月10日
