# 关于印发《张家港市养老从业人员入职奖励管理细则（试行）》的通知

各镇（区）民政办、财政所：

现将《张家港市养老从业人员入职奖励管理细则（试行）》印发给你们，请认真贯彻执行。

张家港市民政局

张家港市财政局

2019年11月27日

（此件公开发布）

张家港市养老从业人员入职奖励管理细则（试行）

为吸引更多优秀人才从事养老服务工作，进一步加强我市养老从业人员队伍建设，提升全市养老服务水平。根据《江苏省养老服务条例》《苏州市居家养老服务条例》《苏州市关于全面放开养老服务市场提升养老服务质量实施意见的通知》和《苏州市养老从业队伍培训和入职奖励管理办法》(苏政民老〔2019〕10号)等法规文件精神，制定本细则。

一、发放对象

获得国家教育主管部门认可的高等院校、中等职业技术学校颁发的毕业证书后，在我市同一养老服务机构中连续从事养老服务工作年限满5周年的、且继续在我市从事养老服务工作、与养老服务机构签订劳动合同或协议，并缴纳社会保险的人员均可申请入职奖励。并符合以下要求：

1.养老服务机构，指在我市依法登记并经市民政局备案的养老机构，以及在我市依法登记主要从事养老服务的企业、社会组织。养老服务机构营业执照（登记证书）的经营范围（业务范围）需载有养老服务内容。

2.入职奖励对象不含机关事业单位在编人员和编外人员(市镇两级财政资金保障人员），以及养老服务企业和社会组织的法人和股东。

3.公办养老机构社会化运营后，原财政资金保障的养老服务从业人员继续留任的，原工作年限不累计。工作年限以运营单位为其缴纳社保日期为准。

二、奖励标准

中专学历3万元，大学专科学历4万元，大学本科学历5万元，研究生学历6万元。非全日制毕业生的奖补比例按照全日制的90%进行奖补。申请人在申请入职奖励前，先后获得国家不同层级学历证书的，入职奖励实行就高不就低原则，不重复奖励。

三、申报流程

1.申请。申请人通过所在单位自愿申报，于每年8月31日前，由所在单位按要求集中向市民政局申请。

2.受理。市民政局在每年9月底前，对受理的相关材料进行审核。

3.公示。市民政局核实后，将拟奖励名单和金额等相关信息在用人单位和当地网站公示7天。

4.批准。公示无异议，经市民政局批准备案。

四、申报材料

1.养老服务机构应提交营业执照（登记证书）；

2.申请人应提交《张家港市养老从业人员入职奖励申请表》、身份证复印件、学历原件及复印件、高等教育学历认证报告原件、与所在养老服务机构签订的劳动合同复印件、社会保险缴纳证明、获得的职业资格证书原件及复印件（选择项）。

五、经费发放

1.入职奖励分3年申请，获批后按每年30%、30%、40%发放。奖励金额拨付给用人单位后应及时全额发放给申请人。

2.申请人工作已满8周年的，按标准一次性拨付。不满8周年离开养老服务行业的，入职奖励未发放部分不再予以发放。

3.申请人在享受入职奖励期间提升学历，提供原件及复印件、高等教育学历认证报告原件，剩余年度奖励可按对应新学历的标准发放。申请人入职奖励发放结束后，不再因其学历变化另外给予入职奖励。

4.满5周年后，又在不同养老服务机构工作，服务时间由从事过的养老服务机构出具证明，并附劳动合同、社保证明和岗位工作职责，经民政局盖章确认，作为发放入职奖励的依据。

5.申请人在申请入职奖励期间，已达退休年龄，取消剩余入职奖励发放。

6.凡提供虚假材料的个人和单位，虚报冒领入职奖励的，一经发现，停发个人特岗补贴、入职奖励、单位运营补贴和本单位其他人员的入职奖励，并纳入征信系统。

7.入职奖励经费由福彩公益金承担。

六、其他

本细则自下发之日起试行。
