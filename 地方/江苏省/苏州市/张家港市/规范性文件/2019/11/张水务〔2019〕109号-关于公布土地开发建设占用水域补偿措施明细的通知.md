# 关于公布土地开发建设占用水域补偿措施明细的通知

各镇政府，冶金工业园、高新技术产业开发区、常阴沙现代农业示范园区、双山香山旅游度假区管委会，市自然资源和规划局，市城投集团，高铁新城投资发展有限公司：

根据《江苏省建设项目占用水域管理办法》，为加强水域管理和保护，进一步规范土地开发建设占用水域行为，在土地开发前，由各镇（区）及相关单位统筹考虑本行政区域内水域占补平衡。现将各镇（区）及相关单位土地开发建设占用水域计划补偿的情况公布如下：

2019年1月至10月，土地出让环节全市共占用水域186398平方米，各镇（区）及相关部门承诺通过拓宽、新开等方式补偿水域286664平方米，其中承诺在2019年完成新增水域面积247324平方米。

根据《苏州市河道管理条例》，对于补偿工作不到位的镇（区）及相关部门，我局将无权同意占用水域面积的地块出让。为防止我市现有水域面积衰减，且不影响后续土地开发建设，请各区镇及相关单位按照承诺及时落实，并将落实情况于11月30日前反馈至我局规建科，联系人：夏国菁，联系电话：58186063。

张家港市水务局

2019年11月14日
