# 市人力资源和社会保障局市财政局关于落实东西部扶贫劳务协作有关政策的实施意见

各镇（区）、各有关单位：

为深入贯彻落实人社部、财政部《关于进一步加大就业扶贫政策支持力度着力提高劳务组织化程度的通知》（人社部发〔2018〕46号）和省人社厅《关于进一步做好东西部扶贫劳务协作工作的通知》（苏人社函〔2018〕410号）、《关于落实东西部扶贫劳务协作有关政策的实施意见（试行）》（苏人保就〔2018〕29号）等文件有关精神，调动各方积极性，落实劳务协作各项工作及任务，结合我市实际，提出如下实施意见：

一、实施受援地贫困劳动力社会保险补贴政策。对吸纳来我市实现稳定就业（单位吸纳就业）的东西部扶贫协作张家港受援地认定的建档立卡贫困劳动力，参照我市各类用人单位吸纳就业困难人员社会保险补贴政策，在相应期限内单位为其缴纳的社会保险费可享受全额补贴。补贴时间最长不超过3年。

二、实施企业吸纳受援地贫困劳动力就业贴息贷款政策。将符合条件的小微企业吸纳张家港受援地认定的建档立卡贫困劳动力就业，纳入我市小微企业吸纳就业贴息贷款政策范围，按照《关于印发〈张家港市创业担保贷款实施细则〉的通知》（张银〔2018〕4号）、《关于做好张家港市富民创业担保贷款管理工作的通知》（张财企〔2019〕1号）有关规定执行。

上述两项政策执行期限截止2021年12月31日。

三、实施职业介绍补贴政策。对成功介绍东西部扶贫协作张家港受援地认定的建档立卡贫困劳动力在我市就业的人力资源服务机构，成功介绍用人单位与之签订1年及以上期限劳动合同并缴纳6个月及以上社会保险，按照每成功推荐就业一人1500元标准给予职业介绍补贴。具体按照《关于印发〈张家港市职业介绍补贴实施办法〉的通知》（张人社发〔2019〕32号）执行。

四、实施免费培训和就业服务政策。对有就业愿望的来张东西部扶贫协作张家港受援地认定的建档立卡贫困劳动力，按照我市外来工免费培训政策，给予免费的首次职业培训。对有就业愿望的贫困劳动力，按照精准服务的要求，摸清每个贫困劳动力的基本情况和就业意愿，提供免费的职业指导、就业援助等公共就业服务，广泛动员人力资源服务机构、社会组织参与就业扶贫。

五、其他

（一）本意见所需资金由财政部门统筹安排。

（二）本意见由市人力资源和社会保障局负责解释，自下发之日起执行。
