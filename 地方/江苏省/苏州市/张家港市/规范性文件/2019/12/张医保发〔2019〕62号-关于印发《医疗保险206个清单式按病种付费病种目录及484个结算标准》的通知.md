# 关于印发《医疗保险206个清单式按病种付费病种目录及484个结算标准》的通知

各定点医疗机构：

为全面落实医药卫生体制改革重点工作任务，进一步深化医保支付方式改革，提高按病种付费基金支出占比，提升医保基金使用效益。根据临床路径和诊疗规范明确、并发症和合并症相对较少、诊疗技术成熟、医疗质量可控、医疗安全等原则进行筛选，并结合国家临床2.0版疾病诊断编码（ICD－10）和手术操作编码(ICD-9-CM3)，经全市相关医疗专家研究，将按病种付费病种目录扩至206个，并结合临床路径对按病种付费结算标准行清单式管理，在调整完善现行80个按病种付费结算标准基础上，制定了484个结算标准，现予印发。

附件：1.医疗保险清单式按病种付费病种目录和结算标准的说明

附件1

医疗保险清单式按病种付费病种目录和结算标准的说明

1.清单式按病种付费的病种目录和手术编码是以国家临床2.0版疾病诊断编码（ICD－10）和手术操作编码(ICD-9-CM3)为依据。

2.清单式按病种付费手术类疾病是同时提取第一诊断编码和手术操作编码为审核依据，非手术类疾病是提取第一诊断编码为审核依据。

3.手术类疾病按病种付费完成率：三级医院≥80%、二级医院≥85%、一级医院≥90%；非手术类疾病按病种付费完成率：三级医院≥25%、二级医院≥30%、一级医院≥35%。

4.医保局将组织每年不少于4次专项检查，如查实医疗机构部分医务人员在按病种付费执行过程中故意规避，将扣除相应医疗费用，医保基金考核分每次扣0.5分。

5.以按病种付费结算的病种总费用不纳入年终5%考核留存款计算范围。
