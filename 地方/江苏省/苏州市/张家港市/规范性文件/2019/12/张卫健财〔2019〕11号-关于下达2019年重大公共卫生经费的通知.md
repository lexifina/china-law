# 关于下达2019年重大公共卫生经费的通知

各镇(区)财政所、社区卫生服务中心：

根据《关于印发〈张家港市农村妇女宫颈癌和乳腺癌检查项目实施方案(行)〉的通知(张卫监控(2010)87号)及《张家港市妇女免费增补叶酸预防神经管缺陷项目实施方案》(张卫监控〔2010〕11号)精神，市财政局、卫健委对各镇农村妇女两癌检查人数及免费检测情况进行了核对，现下达各镇2018年重大公共卫生经费，列2017年度“医疗卫生——公共卫生——重大公共卫生服务”支出。

请各镇(区)、各单位按照规定，专款专用，并及时、足额安排镇级配套经费
