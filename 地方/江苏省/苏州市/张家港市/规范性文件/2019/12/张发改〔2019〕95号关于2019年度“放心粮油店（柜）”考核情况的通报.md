# 张发改〔2019〕95号关于2019年度“放心粮油店（柜）”考核情况的通报

各镇政府、常阴沙现代农业示范园区：

根据市政府办公室《关于推进放心粮油工程建设的实施意见》（张政办〔2017〕45号）文件精神，市发改委联合市场监督管理局对各粮油供应店（柜）进行了年度考核评比工作，“润众粮油供应店”等十家粮油供应店（柜）被评为2019年度优秀“放心粮油店（柜）”。现将考核评比情况通报如下：

一、考核基本情况

2019年，我市放心粮油工程建设在各镇（区）领导的积极支持和各创建单位的大力配合下，顺利完成了放心粮油店（柜）年度创建任务。各镇（区）都能按要求加强日常管理，加快放心粮油柜的推进，并及时落实奖励资金；各创建单位积极参与放心粮油工程建设，经营理念明确，运作规范，质量保证，服务到位，较好地彰显了“放心粮油店（柜）”示范引领作用，继续推进了放心粮油工程建设。

二、主要存在问题

1.部分粮油供应店经营业绩仍然不行，没有起到粮油店作用。

2.部分粮油供应店（柜）没有很好地执行相关规定，仍然存在台账资料不齐全、环境卫生条件差、明码标价和亮证经营不规范等现象。

三、相关要求

1.各镇（区）对2019年被评为“合格”等次以上的粮油供应店（柜），要继续根据相关文件精神落实好配套奖励资金。

2.各镇（区）对经营规模不大、品种单一、环境卫生差的粮油供应店，可以挑选一些大型超市设立放心粮油店（柜），保质保量落实创建任务。
