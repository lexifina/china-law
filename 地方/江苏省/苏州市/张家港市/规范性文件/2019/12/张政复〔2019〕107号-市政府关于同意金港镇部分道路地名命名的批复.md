# 市政府关于同意金港镇部分道路地名命名的批复

金港镇人民政府：

你镇《关于金港镇部分道路命名的请示》（金政请〔2019〕17号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意对你镇申报的6条现有未命名道路予以命名。具体批复如下：

1．同意将你镇位于天台南路东侧，南起滩上路、北至天福路的道路命名为“和爱弄”。地名标志汉语拼音拼写形式：HEAI LONG。

2．同意将你镇位于长江西路北侧，南起长江西路、北至巫山港东侧江堤的道路命名为“渡江路”。地名标志汉语拼音拼写形式：DUJIANG LU。

3．同意将你镇位于严子港西侧，南起长江东路、北至东新路的道路命名为“长江北路”。地名标志汉语拼音拼写形式：CHANGJIANG

BEILU。

4．同意将你镇位于护严河北侧，东起千禧路北路、西至东华能源股份有限公司的道路命名为“火通港路”。地名标志汉语拼音拼写形式：HUOTONGGANG

LU。

5．同意将你镇位于幸福小区北侧，东起滨江路、西至长江西村4组34幢东侧道路的道路命名为“鑫苑路”。地名标志汉语拼音拼写形式：XINYUAN LU。

6．同意将你镇位于新塍幼儿园南侧，东起塍德小区31幢南侧围墙、西至新塍路的道路命名为“新学路”。地名标志汉语拼音拼写形式：XINXUE LU。

请按照《地名 标志》（GB17733—2008）国家标准，及时做好道路标志牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2019年12月5日
