# 市政府关于同意张家港市综合交通规划（2012—2030）（2019年修改）的批复

张政复〔2019〕110号

来源：市政府发布时间：2019-12-17 18:12:00访问量：字体【大中小】

市自然资源和规划局：

你们上报的《关于报批张家港市综合交通规划（2012—2030）（2019年修改）的请示》（张资规发〔2019〕174号）收悉。经研究，现批复如下：

一、原则同意《张家港市综合交通规划（2012—2030）》（2019年修改）。规划范围为张家港市行政区域范围。规划期限为至2030年，其中近期规划至2025年，远期规划至2030年。

二、要加强与城市总体规划、土地利用规划等相关规划的衔接、融合，做好与周边城市在过江通道、轨道交通、快速路网方面的衔接，合理配置交通资源，统筹重大交通基础设施建设。

三、经市政府批准的《张家港市综合交通规划（2012—2030）》（2019年修改）是指导我市综合交通规划建设的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府
