# 市政府关于同意南丰镇部分道路地名命名、调整、注销的批复

南丰镇人民政府：

你镇《关于南丰镇部分道路申请命名、调整、注销的请示》（南政请〔2019〕14号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意对你镇申报的2条道路予以命名、2条道路予以延伸、1条道路地名予以注销。具体批复如下：

一、道路命名

1．同意将你镇位于江苏永钢集团有限公司北侧，东起妙丰公路、西至永琪路向北延伸段的道路命名为“永辉路”。地名标志汉语拼音拼写形式：YONGHUI LU。

2．同意将你镇位于南丰小学东侧，南起南丰东路、北至南丰大道的道路命名为“兴丰路”。地名标志汉语拼音拼写形式：XINGFENG LU。

二、道路延伸

1．同意将你镇原“钢村路”（南起永南河、北至永琪路）向北延伸至永丰村50#桥，延伸后的“钢村路”南起永南河、北至永丰村50#桥；地名标志汉语拼音拼写形式：GANGCUN LU。

2．同意将你镇原“振兴南路”（南起建工大道、北至南丰东路）向南延伸至永南河，延伸后的“振兴南路”南起永南河、北至南丰东路；地名标志汉语拼音拼写形式：ZHENXING NANLU。

三、道路地名注销

同意将你镇“永颐路”（南起永南河、北至永钢大道）指称道路地名注销。

请按照《地名 标志》（GB 17733—2008）国家标准，及时做好道路标志牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2019年12月18日
