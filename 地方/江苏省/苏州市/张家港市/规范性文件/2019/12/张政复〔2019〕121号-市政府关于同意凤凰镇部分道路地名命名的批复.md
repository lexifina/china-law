# 市政府关于同意凤凰镇部分道路地名命名的批复

凤凰镇人民政府：

你镇《关于对凤凰镇部分道路进行命名的请示》（凤政请〔2019〕23号）收悉。根据《张家港市地名管理办法》（张政发规〔2015〕2号）及有关法律法规规定，经研究，同意对你镇申报的3条道路予以命名。具体批复如下：

1．同意将你镇位于凤凰大道北侧，东起新横河、西至济富路的道路命名为“创兴路”。地名标志汉语拼音拼写形式：CHUANGXING LU。

2．同意将你镇位于凤凰生活广场西侧，南起凤凰镇金谷路、北至望湖路的道路命名为“小墩路”。地名标志汉语拼音拼写形式：XIAODUN LU。

3．同意将你镇位于三干河东侧，南起西妙路、北至凤凰镇镇北路的道路命名为“京庄路”。地名标志汉语拼音拼写形式：JINGZHUANG LU。

请按照《地名 标志》（GB 17733—2008）国家标准，及时做好道路标志牌、门号牌等地名标志牌的制作、设置工作，规范地名管理，方便群众日常工作和生活。

此复。

张家港市人民政府

2019年12月23日
