# 市政府关于同意张家港市乐余镇建新区控制性详细规划的批复

乐余镇政府：

你镇上报的《乐余镇人民政府关于报批〈张家港市乐余镇建新区控制性详细规划〉的请示》（乐政发〔2019〕66号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《张家港市乐余镇建新区控制性详细规划》。规划范围：东至五干河，南至港丰公路，西至沪通铁路—市铁路专用线，北至乐丰路—五干河，规划面积317.56公顷。

二、要加强与城市总体规划、土地利用规划、乐余镇总体规划等相关规划的有机衔接、融合，深化规划地块发展定位和功能布局研究，协调处理好规划区域与周边区域的关系，统筹安排基础设施和公共服务设施建设，保障土地科学、合理与集约利用。

三、经市政府批准的《张家港市乐余镇建新区控制性详细规划》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2019年12月18日
