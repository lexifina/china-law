# 关于成立苏州线上教育张家港分中心工作领导小组的通知

各镇区教卫文体办（综合办），各中小学，各直属单位：

为统筹推进苏州线上教育张家港分中心建设的各项工作，全面深化平台应用，进一步发展更多基于互联网的教育服务新模式，促进优质教育资源共建共享，根据苏州市教育局线上教育工作的会议要求，经研究，决定成立苏州线上教育张家港分中心工作领导小组，组成如下：

一、领导小组组成人员

组  长：杨志刚 市委教育工委书记、教育局局长

副组长：王柳军 教育局副局长

朱治国 教育局副局长

成  员：徐  健 教育局发财科科长

丁新忠 教育局基教科科长

吴新建 教师发展中心主任

孙  贤 教育技术装备室主任

二、职责分工

发财科：负责落实项目建设、日常运维等经费；

基教科：负责研制平台应用管理办法，统筹协调平台推广、宣传、培训等工作；

教师发展中心：负责建设区域名师资源团队及组织开展课程开发、资源制作、直播组织等；

教育技术装备室：负责项目招标采购、平台部署、账号采集及平台运维、网络信息安全等。

张家港市教育局

2019年12月2日
