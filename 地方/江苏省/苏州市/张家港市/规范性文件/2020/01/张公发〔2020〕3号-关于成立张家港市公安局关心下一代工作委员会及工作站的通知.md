# 关于成立张家港市公安局关心下一代工作委员会及工作站的通知

各警署、各派出所、直属各单位、机关各部门：

为深入学习贯彻习近平新时代中国特色社会主义思想和总书记关于关心下一代工作的一系列重要指示，推动我局关心下一代工作的深入开展，按照省市关工委和省厅、苏州市局关工委的部署要求，市局经研究决定，成立张家港市公安局关心下一代工作委员会。成员如下：

关心下一代工作委员会下设办公室，办公室与政治处合署，负责关工委日常工作，各成员单位按照职责分工开展工作。

同时，在全市户籍派出所成立关心下一代工作站。各关爱工作站站长由派出所分管政工工作的领导担任，副站长由一名退休老同志担任，成员由从事该工作的民警担任，按照关爱站工作职责和任务开展工作。
