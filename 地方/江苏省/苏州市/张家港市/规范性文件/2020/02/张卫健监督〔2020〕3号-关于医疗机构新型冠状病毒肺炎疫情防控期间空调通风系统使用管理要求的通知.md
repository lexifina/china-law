# 关于医疗机构新型冠状病毒肺炎疫情防控期间空调通风系统使用管理要求的通知

各医疗机构：

为有效应对新型冠状病毒肺炎疫情，切断新型冠状病毒通过空调通风系统传播，预防和控制感染的发生，现将医疗机构疫情防控期间空调通风系统的使用管理要求通知如下：

一、在疫情防控期间，原则上应暂停使用集中空调通风系统。疫情结束后，重新开启前应由清洗消毒的专业机构对集中空调通风系统清洗消毒或部件更换一次。

二、在疫情防控期间，必须开启集中空调通风系统的，集中空调通风系统应当具备采用全新风方式运行，或装有空气净化消毒装置(纳米或高强度紫外线灯等)并有效运行，或风机盘管加新风的空调系统并确保各房间独立通风等三项条件之一的，方可继续运行。同时，应当加强对集中空调通风系统的清洗消毒，必须增加房间每天换气频次和空调清洗消毒频次，每周对运行的集中空调系统的开放式冷却塔、过滤网、过滤器、净化器、风口、空气处理机组、表冷器、加热(湿)器、冷凝水盘等设备或部件进行清洗消毒或者更换。否则，坚决予以关闭。

三、在疫情防控期间，要加强对独立分体空调、取暖器等空气调温、净化设备的清洗消毒管理，必须增加房间每天换气频次和空调清洗消毒频次，每周对过滤网、过滤器、冷热交换器(片)、导风片等设备或部件进行清洗消毒或者更换。

四、各医疗机构要健全空调通风系统使用管理制度和管理网络，明确责任领导，落实专(兼)职管理人员，掌握本单位空调通风系统基本情况，建立空调通风系统卫生管理档案，认真做好空调通风系统清洗、消毒记录台账。

五、各医疗机构要高度重视，必须落实空调通风系统使用管理主体责任，严格执行相关规定，确保不发生使用空调通风系统导致疫情传播事件。
