# 张资规发（2020）51号关于印发《张家港市房屋建筑面积预测成果管理（暂行）规定》的通知

各有关单位：

现将《张家港市房屋建筑面积预测成果管理（暂行）规定》印发给你们，请遵照执行。

张家港市自然资源和规划局

2020年2月27日

（此件公开发布）

张家港市房屋建筑面积预测成果管理(暂行)规定

根据《国务院办公厅关于全面开展工程建设项目审批制度改革的实施意见》（国办发[2019]11号）、《江苏省人民政府办公厅关于印发江苏省工程建设项目审批制度改革实施方案的通知》（苏政办发[2019]53号）及《关于执行〈江苏省城市规划管理技术规定—苏州市实施细则之一“指标核定规则”（2018年版）〉的通知》（苏规管[2018]1号）等文件精神，结合我市实际情况，我局现对建设工程项目规划许可办理和商品房预售面积预测成果进行规范，具体规定如下：

一、实行建设项目审批阶段的“联合测绘”制度

将原规划许可阶段、房产预售阶段的预测绘工作进行有机整合。

1.建设单位在项目规划方案审批前，即可委托有测绘资质的单位按相关规范对建设项目的建筑总面积和容积率面积进行预测绘，并出具初步成果报告。

2.工程建设项目在规划许可证取得之前，受托的测绘单位按照规划、房产等测量的技术标准和规范要求，一次性出具联合测绘成果报告。

二、成果内容要求和采用技术规范

1.测绘成果报告内应准确反映各幢房屋的套（间）、层、幢的建筑面积和用途，包括计容面积、不计容面积等内容，并满足规划许可、商品房预售的需求，成果数据应满足入库标准。

2.所有提交的面积预测成果图形文件应采用AutoCAD2004版本dwg格式，其他成果采用Word2007或Excel2007格式。房产预测采用的测绘软件（系统）应当经省级以上相关部门测评认证。

3.容积率计算执行《江苏省城市规划管理技术规定—苏州市实施细则之一“指标核定规则”（2018年版）》。细则未尽部分可按照《房屋面积测算技术规程》中的相关规定执行。

4.建筑面积计算执行国家标准《房产测量规范》GB/T17986及江苏省工程建设标准《房屋面积测算技术规程》DGJ32/TJ131

-2011。房屋用途应根据通过规划审核的图纸确定，同时符合不动产登记对房屋用途的相关要求。

三、成果审核流程

市自然资源和规划局建设规划管理科和不动产登记中心分别对容积率计算面积和房屋建筑面积预测成果进行审核，审核合格后的预测成果方可作为房屋规划许可、预售、备案的依据。

四、保税区规划建设局、经开区建设局、冶金工业园规划建设局和凤凰镇建设局可参照执行。

五、本规定自2020年3月1日起施行。
