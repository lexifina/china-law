# 市政府关于张家港市河湖和水利工程管理范围划定工作的公告

河湖是水资源的重要载体，加强河湖管理，对于保障防洪、供水、生态安全，促进经济社会可持续发展具有重要意义。开展河湖和水利工程管理范围划定工作，是保证河湖功能和水利工程效益充分发挥的重要手段，是践行绿色发展理念，推进生态文明建设的重要举措。

根据水利部《关于开展河湖管理范围和水利工程管理与保护范围划定工作的通知》（水建管〔2014〕285号）、省政府办公厅《关于开展河湖和水利工程管理范围划定工作的通知》（苏政办发〔2015〕76号）要求，我市于2015年开展河湖和水利工程管理范围划定工作。2016年1月，我市成立了河湖和水利工程管理范围划定工作领导小组（张水发〔2016〕1号），张家港市水务局为划定工作牵头单位。2016年6月，《张家港市河湖和水利工程管理范围划定实施方案》通过苏州市水务局符合性审查。2016年7月，张家港市人民政府以《张家港市河湖和水利工程管理范围划定实施方案》（张政复〔2016〕62号）批准实施方案。2016年10月，张家港市水务局完成划定工作项目公开招标，中标单位为江苏省工程勘测研究院有限责任公司。

划定工作的实施对象包括：

一、  骨干河道27条；

1. 区域性河道3条：张家港、十一圩港、走马塘。

2. 重要跨县河道2条：东横河、盐铁塘。

3. 重要县域河道22条：朝东圩港、十字港、五节桥港、天生港、三丈浦、西旸塘、一干河、三干河、四干河、五干河、六干河、七干河、奚浦塘、新市河、北中心河、永南河、新沙河、南横套、太字圩港、常沙河、农场河、华妙河。

二、市县管湖泊1个：暨阳湖。

三、水利工程39座；

1. 堤防2处：长江堤防、双山洲堤。

2. 沿江中型闸13座：张家港节制闸、五节桥泵闸工程、十字港闸、太字圩港节制闸、段山港节制闸、朝东圩港水利枢纽、一干河水利枢纽、十一圩闸、走马塘江边枢纽、三干河水利枢纽、五干河节制闸、六干河节制闸、渡泾港泵闸工程。

3. 沿江小型闸8个：双山北闸枢纽、双山南闸枢纽、护漕港节制闸、常通港节制闸、十三圩节制闸、四干河节制闸、农场河节制闸、常沙河节制闸。

4. 内河节制闸8个：东横河水利枢纽、东横河西节制闸、新沙河南端控制工程、朝东圩港节制闸、乐余北中心河节制闸、南横套节制闸、七干河西闸、三干河南闸。

5. 内河套闸8个：后塍套闸、福前套闸、锦丰套闸、东莱东套闸、东莱西套闸、鹿苑套闸、西旸套闸、杨舍套闸。

2017年8月，划定工作通过江苏省水利厅组织的省级内业审核。2017年10月，划定工作通过苏州市水务局组织的县级技术预验收。2017年11月，张家港市河湖和水利工程管理范围划定工作完成。2019年11月，划定工作通过张家港市人民政府组织的县级正式验收。

张家港市划定成果为67个对象，划定成果范围线总长878.47千米，管理范围界桩点4829个，告示牌862块。
