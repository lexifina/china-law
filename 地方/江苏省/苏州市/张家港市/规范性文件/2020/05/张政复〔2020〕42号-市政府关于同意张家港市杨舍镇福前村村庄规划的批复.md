# 市政府关于同意张家港市杨舍镇福前村村庄规划的批复

杨舍镇政府：

你镇上报的《关于报批〈张家港市杨舍镇福前村村庄规划〉的请示》（杨政请〔2020〕7号）收悉。经研究，现批复如下：

一、原则同意你镇上报的《张家港市杨舍镇福前村村庄规划》。规划范围为福前村辖区范围，规划面积2.16平方公里。

二、要加强与城市总体规划及土地利用规划等相关规划的有机衔接、融合，坚持保护耕地、集约利用土地，提高土地利用效率；要从农村实际出发，尊重村民意愿，体现地方和农村特色，以葡萄种植和高效丰产农业为主导，发展现代化、田园式、农旅结合的现代新农村，优化村庄生产、生活环境，提高村庄发展和建设整体水平。

三、经市政府批准的《张家港市杨舍镇福前村村庄规划》是指导该区域建设和管理的重要依据。要严格执行规划，切实维护规划的严肃性和权威性。

此复。

张家港市人民政府

2020年5月3日
