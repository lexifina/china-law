# 关于评聘黄磊等同志为辅警兼职教员的决定

各警署、各派出所、直属各单位、机关各部门：

为进一步提升辅警培训工作规范化、科学化、制度化水平，努力打造一支政治强、业务精、作风硬、形象好的警务辅助人员队伍，有力推动全市公安机关辅警培训工作持续健康发展，根据《江苏省公安机关警务辅助人员培训管理办法（试行）》和《苏州市公安局关于规范和加强警务辅助人员培训工作的指导意见》等规定，市局决定：评聘黄磊等12名同志为辅警兼职教员，聘期二年，自2021年6月起至2023年5月止。

黄　磊   巡特警大队

桑晓舟   巡特警大队

常铭宇   保税区（金港）警署

马东鑫   冶金工业园（锦丰）警署

朱　烨   交警大队杨舍中队

杨树波   城北派出所

王洪江   塘市派出所

夏　斌   城西派出所

王熠中   政治处

韦亚新   东莱派出所

姚益丰   西张派出所

陆文龙   德积派出所

希望被评聘为辅警兼职教员的同志们珍惜荣誉、发扬成绩、再接再厉，积极投身警务辅助人员教育培训工作，用实际行动为提升全市公安辅警队伍整体素质和综合能力作出更大贡献！

张家港市公安局

2021年6月17日
