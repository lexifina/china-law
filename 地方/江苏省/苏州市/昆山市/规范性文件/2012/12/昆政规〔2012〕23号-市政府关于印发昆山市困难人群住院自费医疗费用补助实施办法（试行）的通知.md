# 市政府关于印发昆山市困难人群住院自费医疗费用补助实施办法（试行）的通知

昆山开发区、昆山高新区、花桥经济开发区、旅游度假区管委会，各镇人民政府，市各委办局，各直属单位：

《昆山市困难人群住院自费医疗费用补助实施办法（试行）》业经市政府第11次常务会议审议通过，现印发给你们，请认真贯彻执行。

昆山市人民政府

2012年12月27日

昆山市困难人群住院自费医疗费用补助

实施办法（试行）

根据《关于进一步促进低收入农户增收改善收入群体结构的意见》（昆委〔2012〕41号），为切实保障困难群众的基本生活，加大困难群众的医疗保障力度，特制定昆山市困难人群住院自费医疗费用补助实施办法。

一、适用范围

参加我市基本医疗保险，按照《昆山市社会医疗救助办法》（昆政办发〔2008〕121号）享受社会医疗实时救助的5类本市户籍困难人群，即：经民政部门确定的低保人员、低保边缘人员、三无人员、五保人员和经市总工会确定的特困职工。

二、住院自费医疗费用补助标准

（一）困难人群年度内发生的住院自费（含目录内药品和诊疗项目费用的个人先付比例部分，下同）医疗费用，按以下标准累计分段补助，上不封顶：2万元以下的部分，补助50%；2万元及以上至10万元以下部分，补助60%；10万元及以上部分，补助70%。

（二）下列情形之一所发生的医疗费用，不列入补助范围：

1．门诊、急诊；

2．未经医保部门批准，在非定点医疗机构住院；

3．在零售药店购药；

4．使用超出《中华人民共和国药典》范围以外的药品；

5．各类器官、组织移植的器官源及组织源；

6．人工器官和体内置放材料，超过社会医疗保险限量限价规定；

7．住院期间发生的特需床位费、自请护工费及伙食费等服务项目类费用；

8．超过国家、省市物价部门规定对社会医疗保险标准收费价格；

9．中断保险期间以及当年度户籍转入我市之前或转出我市之后的医疗费用。

三、资金来源

补助资金由市级财政预算安排，福利彩票公益金、关爱帮扶基金共同承担。

四、操作流程

市社保中心每年1月份根据社保系统数据，统计困难人群实际发生住院自费医疗费用。补助资金与社会医疗年度救助资金合并发放。

五、执行时间

本通知从2013年1月1日起执行。
