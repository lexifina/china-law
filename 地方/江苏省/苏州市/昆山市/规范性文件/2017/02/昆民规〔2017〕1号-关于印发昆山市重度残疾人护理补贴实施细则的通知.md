# 关于印发昆山市重度残疾人护理补贴实施细则的通知

各区镇、中心城区各城市管理办事处：

现将《昆山市重度残疾人护理补贴实施细则》印发给你们，请认真贯彻落实。

昆山市民政局 昆山市财政局

昆山市残疾人联合会

2017年1月24日

昆山市重度残疾人护理补贴实施细则

根据国务院《关于全面建立困难残疾人生活补贴和重度残疾人护理补贴制度的意见》、《省政府关于完善困难残疾人生活补贴和重度残疾人护理补贴制度的意见》（苏政发〔2016〕15号）、《关于做好困难残疾人生活补贴和重度残疾人护理补贴发放管理工作的通知》（苏民福〔2016〕13号）和《市政府印发关于完善困难残疾人生活补贴和重度残疾人护理补贴制度意见的通知》（苏府〔2016〕162号）精神，结合我市实际，制定本细则。

一、补贴对象

昆山市户籍，并持有本市残联核发的第二代《中华人民共和国残疾人证》，残疾等级评定为一级、二级，且需要长期照护（是指因残疾产生的特殊护理消费和照护服务支出持续6个月以上时间）的重度残疾人。

二、补贴标准

符合条件的重度残疾人的护理补贴，城乡统一按120元/月·人的标准发放。低保与低保边缘重病困难对象救助家庭中16～60周岁生活不能自理或自理困难，享受居家托养、日间托养、全日制托养等服务的一、二级智力、肢体、精神、视力重度残疾人，其护理补贴按原有标准、形式执行。

三、补贴形式

重度残疾人护理补贴采取政府购买家庭或社会组织服务形式发放。主要有两种类型，残疾人可自由选择：

1.向残疾人家庭购买服务。由政府向重度残疾人亲属购买服务，亲属直接为残疾人提供服务。重度残疾人户口所在区镇、城市管理办事处与残疾人亲属签订服务协议，明确服务标准和服务内容，主要有：根据残疾人自理能力和服务需求，为其提供护理、洗衣、做饭、整理卫生、居室保洁、衣服烫熨、陪同看病、取药、代为购物、代为办理社会事务等。

2.向社会服务机构购买服务。由政府向社会服务机构购买服务，符合条件的重度残疾人与社会服务机构签订服务协议，明确服务标准和服务内容，主要有：根据残疾人自理能力和服务需求，为其提供护理、洗衣、做饭、整理卫生、居室保洁、衣服烫熨、陪同看病、取药、代为购物、代为办理社会事务等。

四、办理流程

1.自愿申请。重度残疾人护理补贴由残疾人向户籍所在区镇人民政府、城市管理办事处社会救助服务窗口提交书面申请。残疾人的法定监护人，法定赡养、抚养、扶养义务人，所在村民（居民）委员会或其他委托人可以代为办理申请事宜。申请人按《昆山市重度残疾人护理补贴申领须知》（附件1）提交第二代中华人民共和国残疾人证、身份证、户口簿、《昆山市残疾人重度护理补贴申领诚信承诺书》（附件2）等材料，并填写《昆山市重度残疾人护理补贴申请审批表》(附件3)。

2.受理审核。各区镇、城市管理办事处建立“一门受理、协同办理”机制，依托社会救助受理服务窗口，向社会公开重度残疾人护理补贴申领须知、制式申请材料等信息，方便申请人知悉办理事宜，对重度残疾人护理补贴申请进行初审。初审合格后，提出审核意见，同时，在申请人居住村（社区）公示栏进行5天公示（格式见附件4）。重度残疾人选择向社会服务机构购买服务的，经区镇、城市管理办事处民政审批符合条件的，由重度残疾人或法定监护人与社会服务机构签订，随材料一并报送市民政局审批。

3.按时发放。重度残疾人护理补贴采取社会化形式按季度发放，各区镇、城市管理办事处于每季度首月10日前上报市民政局《昆山市重度残疾人护理补贴发放情况明细表》（附件5），于每季度首月月底前打卡发放。补贴资格审定合格的残疾人自递交申请当月计发补贴。购买家庭服务的通过金融机构转账存入残疾人本人账户，购买社会服务的通过金融机构转账至护理服务机构账户。防止和杜绝冒领、重复领取、克扣现象。非经本人或监护人同意，任何人不得代为保管账户存折。

4.做到定期复核。采取残疾人主动申报和发放部门定期抽查相结合的方式，建立重度残疾人护理补贴定期复核制度，实行残疾人重度残疾人护理补贴应补尽补、应退则退的动态管理。定期复核内容包括申请人资格条件是否发生变化、补贴是否及时足额发放到位等。

五、有下列情形之一的，不享受护理补贴

1.符合残疾人护理补贴条件，又符合老年、因公致残、离休等福利性护理补贴（津贴），可择高申领其中一类护理补贴（津贴），不重复享受。

2.领取工伤保险生活护理费或纳入特困人员供养的残疾人不享受残疾人护理补贴。

六、资金来源

重度残疾人护理补贴经费由市财政统筹解决。

七、相关要求

1.密切配合。各有关部门要相互支持，密切配合，各司其职，各负其责。各区镇、城市管理办事处民政办（科室）做好补贴对象的资格审核；各级残联协助民政做好资格审核工作；市民政负责做好补贴对象审批及经费发放工作；市财政部门负责落实补贴资金，加强资金使用的管理和监督。

2.加强政策宣传。要及时组织有关部门及工作人员学习培训，全面掌握重度残疾人护理补贴制度精神和内容。要充分考虑残疾人获取信息的特殊要求和实际困难，广泛利用各种媒介宣传完善重度残疾人护理补贴制度重要意义，采用灵活多样形式进行宣传解读，确保残疾人及其家属知晓重度残疾人护理补贴制度内容，了解基本申领程序和要求。要利用各种服务平台及窗口做好重度残疾人护理补贴政策解释工作，协助残疾人便捷办理相关手续。

3.规范运作。各区镇、城市管理办事处要按照有关规定，认真审核补贴对象，按照档案管理相关规定及时做好相关资料的存档和留存工作。财政、民政部门和残联组织要充分运用已建立的信息系统，实现信息资源共享和补贴工作的动态管理。每年6月、12月底前，各区镇、城市管理办事处民政办（科室）要认真核准本区补贴资金发放情况，并及时填报《昆山市重度残疾人护理补贴发放统计表》（附件6），上报市民政局。

附件1

昆山市重度残疾人护理补贴申领须知

一、申领重度残疾人护理补贴范围

残疾等级一、二级，且需要长期照护的重度残疾人（长期照护是指因残疾产生的特殊护理消费和照护服务支出持续6个月以上时间）。

二、相关政策规定

既符合重度残疾人护理补贴条件，又符合老年、因公致残、离休等福利性生活补贴（津贴）、护理补贴（津贴）条件的残疾人，可择高申领其中一类护理补贴（津贴），不重复享受。享受孤儿基本生活保障政策的残疾儿童可享受重度残疾人护理补贴。领取工伤保险生活护理费或纳入特困人员供养的残疾人不享受重度残疾人护理补贴。重度残疾人护理补贴不计入城乡最低生活保障家庭的收入。

三、申领重度残疾人护理补贴应提供的证明材料

1.第二代中华人民共和国残疾人证原件及复印件1张；

2.户口簿原件、户主和本人页复印件1张；

3.身份证（未办理身份证的儿童可不提供）原件及复印件1张；

4.近期免冠彩色二寸照片2张；

5.昆山市重度残疾人护理补贴申领诚信承诺书

6.昆山市重度残疾人护理补贴申请审批表

7.开户银行名称、银行卡原件及复印件1张。
