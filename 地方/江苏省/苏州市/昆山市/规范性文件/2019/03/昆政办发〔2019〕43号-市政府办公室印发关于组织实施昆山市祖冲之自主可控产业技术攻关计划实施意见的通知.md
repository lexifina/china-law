# 市政府办公室印发关于组织实施昆山市祖冲之自主可控产业技术攻关计划实施意见的通知

昆政办发〔2019〕43号

昆山开发区、昆山高新区、花桥经济开发区、旅游度假区管委会，各镇人民政府，各城市管理办事处，市各委办局，各直属单位：

《关于组织实施昆山市祖冲之自主可控产业技术攻关计划的实施意见》业经市政府第30次常务会议讨论通过，现印发给你们，请认真贯彻执行。

昆山市人民政府办公室

2019年3月19日

（此件公开发布）

关于组织实施昆山市祖冲之自主可控

产业技术攻关计划的实施意见

为进一步营造国家一流产业科创中心建设的浓厚氛围，瞄准自主可控发力点，点燃人才科创主引擎，不断激发企业自主创新 热情和积极性，提升高端产业核心竞争力，经研究，决定组织实施昆山市祖冲之自主可控产业技术攻关计划，并制定如下实施意见。

一、指导思想

深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，以全力打造具有国际影响力的国家一流产业科创中心为目标，以18项三年提升工程为抓手，立足人才科创，立足自主可控，立足企业主体，大力实施昆山市祖冲之自主可控产业技术攻关计划，进一步围绕产业链部署创新链，支持四大高端产业在攻克技术难关、破解关键瓶颈、掌握核心技术上持续用劲，推动昆山在高质量发展中实现 “全新一跃” 。

二、主要目标

以推进工业企业转型创新发展为主要任务，聚焦光电、半导体、小核酸及生物医药、智能制造等四大高端产业，组织实施昆山市祖冲之自主可控产业技术攻关计划，每年面向全球集中发布“需求清单” 、征集 “供给清单” ，通过高校院所技术转移、国际先进技术导入、军民融合技术双向转化、大企业大科学工程协作分工等路径，着力实施千项产学研项目，攻克百项 “卡脖子” 技术难关，形成十项国际领先水平技术项目，加快培育自主创新、自主可控的 “热带雨林” ，真正让企业真实需求、院所有效供给“显山露水” ，助力企业对接研发需求 “最初一公里” ，打通成果转化 “最后一公里” 。

三、基本原则

1. 坚持市场化导向。充分发挥市场对创新资源配置的决定性作用，加快推动四大高端产业在提升关键技术控制力、产业集群带动力、产业链条整合力、信息化引领力、标准主导力上寻求全新突破，着力构建以企业为主体、市场为导向、产学研深度融合的技术创新体系。

2. 坚持前瞻性布局。把握新一轮科技革命和产业变革趋势，强化战略谋划和前瞻部署，加强技术攻关、力争率先突破、勇攀科技高峰、赢得战略主动，鼓励引导科技研发前沿化、高端化、产业化，全面推动产业链和创新链 “双向融合” ，加快实现 “一体多翼” 的产业格局和多点突破的创新格局。

3. 坚持国际化视野。强化开放创新模式，发挥工研院等创新纽带作用，借助长三角一体化上升为国家战略机遇，深入对接上海科创中心建设，主动对接美国、以色列、日本等创新先进地区以及俄罗斯、白俄罗斯等 “一带一路” 沿线国家，在全球范围集聚创新资源，以国际化视野领跑创新转型。

四、重点任务

1. 明确产业技术攻关主体。以规上工业企业、高新技术企业、领军人才、“专精特新” 企业等为主体，借力现有创新载体、科技镇长团、科技服务机构、校友会等资源，梳理我市具备重大科研攻关能力、拥有自主可控技术的企业清单。

2. 梳理产业技术需求清单。对产业技术攻关主体，逐一开展“面对面” 辅导、“肩并肩” 走访、“实打实” 对接，精准梳理制约我市四大高端产业发展的重大核心技术和关键共性技术，努力做到 “企业需求快速知道、科技服务快速到位、技术攻关快速解决” ，描绘全市产业技术攻关需求全景图。

3. 建立技术需求发布平台。进一步整合创新信息资源，建设“祖冲之自主可控产业技术攻关在线” 平台，面向全球范围发布攻关需求清单，鼓励国内外高校、科研机构、行业社团组织等技术供给方主动揭榜应征，提供解决方案。

4. 加快协同攻关技术瓶颈。整合全市科创资源，持续推进 “千企千校产业科创合作万里行” 活动，充分发挥工研院创新纽带作用和首席科学家（顾问）团队智库作用，借力科技镇长团、产业技术创新联盟优质资源，围绕卡脖子的技术难题，着力推动企业与高校、科研院所创新要素优化整合，实现精准合作、长期合作、协同攻关、技术突破。

5. 组织开展项目评审奖励。攻关计划项目按现有政策在立项并获得科技等财政资金支持的基础上，每年在已实施完成的项目中，根据企业创新投入、技术水平、经济效益、财政贡献等要素，遴选一批具有突破性、原创性、引领性的攻关成果，分金π、银π、铜π三个层次予以表彰和奖励。其中，金π项目1—3个，奖励100万元；银π项目3—5个，每个奖励80万元；铜π项目5—8个，每个奖励50万元；鼓励奖项目10个，每个奖励20万元。

五、保障措施

1. 加强攻关计划组织领导。在昆山产业科创中心建设领导小组下设立自主可控产业关键技术攻关工作组，由市政府分管副市长担任工作组组长，定期会商、协调技术攻关计划实施中的重大问题，统筹调配各类创新资源。

2. 落实项目政策资金保障。紧盯产业前沿和市场需求，大力实施普惠性支持政策，不断加大财政资金对技术攻关项目的支持力度，着力推进全市经济高质量发展。

3. 加大重大攻关成果宣传。充分释放 “祖冲之自主可控产业技术攻关在线” 平台辐射功能，通过报刊、杂志、广播、电视和微博、微信等媒体，大力宣传人才科创政策，帮助更多企业了解政策、用好政策，营造支持自主可控产业技术攻关的良好社会氛围。
