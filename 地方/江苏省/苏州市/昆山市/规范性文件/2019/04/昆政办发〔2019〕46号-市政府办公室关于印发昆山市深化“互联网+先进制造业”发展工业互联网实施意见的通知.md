# 市政府办公室关于印发昆山市深化“互联网+先进制造业”发展工业互联网实施意见的通知

昆政办发〔2019〕46号

昆山开发区、昆山高新区、花桥经济开发区、旅游度假区管委会，各镇人民政府，各城市管理办事处，市各委办局，各直属单位：

《昆山市深化 “互联网+先进制造业” 发展工业互联网实施意见》业经市政府第30次常务会议讨论通过，现印发给你们，请认真贯彻执行。

昆山市人民政府办公室

2019年3月22日

（此件公开发布）

昆山市深化 “互联网+先进制造业”

发展工业互联网实施意见

为贯彻落实国务院《关于深化 “互联网+先进制造业” 发展工业互联网的指导意见》（国发〔2017〕50号）、省政府《关于深化“互联网+先进制造业” 发展工业互联网的实施意见》（苏政发〔2018〕98号）和苏州市政府《市政府关于深化 “互联网+先进制造业” 发展工业互联网的实施意见》（苏府〔2018〕101号）精神，按照市委市政府《加快创新转型推进经济高质量发展三年提升工程实施方案（2018—2020年）》（昆委〔2018〕27号）的总体要求，大力发展实体经济，加快创新转型，推进制造大市向制造强市转变，促进工业经济高质量发展，特制订本实施意见。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻党的十九大关于 “推动互联网、大数据、人工智能和实体经济深度融合” 的战略部署，以创建国家级工业互联网平台和应用示范区为目标，以智能制造为两化深度融合的主要抓手，以全面构建工业互联网生态体系为主攻方向，建立信息基础设施升级改造、中小微企业上云、大中型企业工业互联网平台建设和应用、智能制造、标杆打造等梯度推进工作体系，全力推动工业互联网在全市重点制造业领域的创新应用，加快提升全市工业互联网发展水平，全力打造具有国际竞争力的先进制造业集群。

二、工作目标

2019年，5G网络在重点产业园区实现试商用。新增1000家信息技术基础设施与管理系统上云企业，创建30家省星级 “上云” 企业；培育工业APP200个，入选省级工业互联网服务资源池企业10家，创建1家省级工业互联网示范标杆工厂，1个省级 “互联网+先进制造业” 特色产业基地；开展智能制造诊断300家，实施智能制造项目300项，创建省级以上智能示范车间（工厂）15个。

到2020年，企业上云广泛普及，实现6000家工业企业信息技术基础设施与管理系统上云，创建100家省星级上云企业；工业互联网平台建设取得新成效，培育工业APP500个，工业互联网平台30个，入选省级工业互联网服务资源池企业20家，创建2个省级工业互联网示范平台，打造3家省级工业互联网标杆工厂，昆山开发区和昆山高新区均入围省级 “互联网+先进制造业”特色产业基地；智能制造取得新突破，开展智能制造诊断400家，实施智能制造项目600项，创建省级以上智能示范车间（工厂）80个。

三、重点工作

1. 推动工业网络升级。实施工业互联网基础设施升级改造工程。面向企业工业互联网应用需求，优化升级骨干网络，打造低时延、高可靠、广覆盖的工业网络。支持工业企业开展内网改造，以IPv6、工业以太网、工业无线等新型技术和设备改造生产现场网络和系统。布局5G网络建设。协调各电信运营商加快推进5G在重点产业园区的网络技术试验及局部试商用，重点在机器人产业园、光电产业园、大数据产业园等园区开展5G网络部署，并组织部分机器人、光电和大数据企业开展5G网络试用。协调各电信运营商实施网络提速降费，降低企业互联网专线和上云成本（市工信局，各区镇，各电信运营商）

2. 开展企业上云活动。组织实施企业上云三年行动计划。组织各电信运营商以及华为、阿里等龙头云平台企业集中开展 “企业上云” 行动计划宣传推介活动，通过中小企业信息化券等形式支持企业信息技术基础设施与管理系统上云，每年新增上云企业1000家以上。推动企业设备上云。支持巨立电梯、金蛋科技等企业加强平台化服务能力建设，组织树根互联、紫光云数等国内龙头工业互联网平台企业开展对接活动，支持企业通过设备上云开展在线监测分析和大数据服务。组织开展星级上云企业评定工作，每年创建省星级上云企业30家以上，其中四星以上企业超5家，对入选企业予以财政支持。（市工信局、财政局，各区镇，各电信运营商）

3. 培育工业互联网平台。加快培育工业APP。开展工业APP综合提供商的征集和向上推荐工作，支持工业APP综合提供商加入国内大型工业互联网平台，每年培育工业APP200个以上。支持企业建立工业互联网平台。加快设备、能源、电梯等行业性工业互联网平台建设步伐，支持研华科技、友达光电等龙头企业建立完善企业级工业互联网平台，开展工业互联网解决方案服务商、数据采集服务商的征集和培育扶持工作，鼓励星云智能装备、同日工业自动化、鲲鹏智能科技等骨干企业向平台化服务化转型。支持平台企业加入苏州市级以上工业互联网服务资源池，与龙头工业互联网平台开展业务合作，开拓省内外市场，带动本市工业企业上云。对获评省级以上各类工业互联网平台和服务型制造企业予以政策支持。（市工信局）

4. 开展智能制造服务。全面开展智能制造诊断活动。组织中软国际等智能制造诊断服务商在各区镇广泛开展诊断服务对接活动。探讨与台湾电电公会合作模式，制定台资企业智能制造服务专案，为全市台资企业开展智能制造诊断和实施服务，推动台资企业加快自动化智能化改造步伐。每年参与智能制造诊断企业达到200家以上，对参与企业予以财政支持。全面开展智能制造服务对接活动。充分发挥机器人及成套装备创新中心和机器人行业协会的平台服务作用，组织本市及国内机器人及智能制造骨干企业定期举办智能制造服务对接活动，形成常态化对接机制。每年推动300家以上企业开展自动化智能化改造。（市工信局〔重点产业发展促进中心〕，市委台办，各区镇）

5. 实施示范引领工程。全面开展智能示范工厂（车间）创建工作。强化智能示范创建企业的辅导培育工作，加大智能示范工厂（车间）创建工作力度，力争每年新增省级以上智能示范工厂（车间）15家以上。全力打造工业互联网标杆工厂。组织实施江苏省工业互联网创新发展 “365” 工程，聚焦汽车零部件、光电、半导体、高端装备等重点行业骨干企业，与华为公司等合作开展工业互联网标杆工厂建设，到2020年入选省级工业互联网应用标杆工厂3家以上。加大工业互联网示范园区建设力度，以昆山开发区、昆山高新区为主要载体，提升园区工业互联网支撑能力，提高工业互联网平台建设应用和信息基础设施建设水平，打造省级 “互联网+先进制造业” 特色产业基地。（市工信局〔重点产业发展促进中心〕，各区镇）

6. 构建工业互联网协同服务体系。全面贯彻落实《长三角地区一体化发展三年行动计划（2018—2020年）》，引进国内外领先的工业互联网创新资源，鼓励工业互联网龙头企业在昆山设立分支机构，共同打造使能中心、协同研发、咨询诊断、试点示范、大数据应用、交流合作等工业互联网公共服务体系。鼓励建设工业互联网 “双创” 平台，吸引优秀的工业互联网服务企业进驻。深化与华为和中软国际在智能制造领域的合作，结合昆山实际，重点推进智能制造诊断、示范工厂打造、公共技术平台建设等工作，加快推动智能制造示范区建设。（市工信局〔重点产业发展促进中心〕）

7. 打造工业互联网特色产业和基地。以花桥大数据产业园为主要载体，发展云计算、大数据、人工智能、区块链等相关支撑产业。加快引进中科院等国内外著名高校科研院所，设立大数据智能等领域的研究机构，支持基于平台采集的设备联网实时数据和供应链企业数据等工业大数据的开发利用。利用我市大力发展半导体产业的政策优势，支持企业发展工业互联网芯片（能讯、创通等）、传感器（双桥传感器等）、远程数据采集模块（研华科技等）、智能测控模块、智能联网装备等核心硬件产品的技术研发和产业化。积极培育工业互联网产品制造、平台服务、工业软件等领域骨干企业，建设具有昆山特色的工业互联网技术产业体系，形成工业互联网产业基地和产业群。（市工信局〔重点产业发展促进中心〕，各区镇）

四、保障措施

1．加强组织协调。市工信局牵头建立全市发展工业互联网工作协调机制，负责全市工业互联网相关工作和任务安排，督促检查重点目标任务落实情况，会同市转型办加强督查考核。各区镇要发挥桥梁纽带作用，将发展工业互联网作为建设制造强市的重点工作之一，深入了解掌握企业 “互联网+” 的实际需求，积极动员组织企业参与各项对接交流活动，确保各项任务落实到位。

2．加大政策支持。切实落实市委市政府《关于加快创新转型推进经济高质量发展财政扶持若干意见》，调整完善《关于加快昆山市机器人及智能制造产业发展的若干政策意见》，加强对企业上云、工业软件应用、两化融合、工业互联网平台建设、智能使能技术平台、试点示范创建等的财政支持，充分调动企业和相关组织参与推动我市企业上云用云、发展工业互联网的积极性。

3．营造良好氛围。市工信局要强化示范引领，积极组织工业互联网领域优势资源举办覆盖全市各区镇的智能制造诊断、企业上云、工业互联网平台应用、智能化改造、网络安全等大型对接交流活动。协调成立工业互联网产业联盟，组织骨干培育企业举办工业互联网平台搭建、智能示范工厂（车间）创建等各类小型沙龙，为培育企业 “开小灶” 。加大财政政策和示范企业宣传力度，编印智能制造和工业互联网优秀解决方案、示范企业典型案例宣传册，利用各种网络媒体、重大活动、各类专题会议和现场会进行宣传和推广应用，营造促进工业互联网发展的良好氛围。
