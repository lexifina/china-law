# 市政府关于公布昆山市行政规范性文件制定主体清单的通知

昆政发〔2019〕37号

昆山开发区、昆山高新区、花桥经济开发区、旅游度假区管委会，各镇人民政府，各城市管理办事处，市各委办局，各直属单位：

根据《国务院办公厅关于全面推行行政规范性文件合法性审核机制的指导意见》《省政府办公厅关于全面推行行政规范性文件合法性审核机制的实施意见》《苏州市行政规范性文件制定和监督管理规定》等有关要求，建立行政规范性文件制定主体资格制度。现将《昆山市行政规范性文件制定主体清单》予以公布。

昆山市人民政府
