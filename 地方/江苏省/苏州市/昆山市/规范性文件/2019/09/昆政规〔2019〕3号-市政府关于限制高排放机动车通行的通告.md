# 市政府关于限制高排放机动车通行的通告

昆政规〔2019〕3号

为进一步加强我市大气污染防治，提升空气质量，有效减少机动车尾气污染，根据《中华人民共和国大气污染防治法》《江苏省大气污染防治条例》《江苏省机动车排气污染防治条例》《打赢蓝天保卫战三年行动计划》《江苏省打赢蓝天保卫战三年行动计划实施方案》《苏州市打赢蓝天保卫战三年行动计划实施方案》等规定，结合《苏州市人民政府关于限制高排放机动车通行的通告》《苏州市人民政府关于国Ⅲ及以下排放标准柴油货车通行管理的通告》，经2019年7月20日市政府第37 次常务会议审议通过，市政府决定限制高排放机动车通行，通告如下：

一、本通告所称高排放机动车是指：

（一）注册登记满15年，装用点燃式发动机（使用汽油燃料），排放标准为国Ⅰ、国Ⅱ标准的小、微型汽油车；

（二）按照车辆结构应当由农业机械管理部门核发牌、证的变型拖拉机及拖拉机运输机组（根据《苏州市人民政府关于限制高排放机动车通行的通告》，2018年12月1日起，已禁止变型拖拉机及拖拉机运输机组在全市道路通行）；

（三）国Ⅲ及以下排放标准柴油货车，即排放标准为国Ⅲ标准和低于国Ⅲ标准以柴油作为动力的货车和专项作业车；

二、中环内禁止高排放机动车进入区域（附图）

（一）全天禁止高排放机动车进入区域（红色区域）：中环北线以南、中环东线以西、中环南线—长江路—沪宁铁路以北、中环西线以东的区域，不包括中环地面道路、长江路的创业路以南路段。

（二）7时—21时禁止高排放机动车进入区域（蓝色区域）：沪宁铁路以南、中环东线以西、外泾河路—玫瑰路以北、青阳港以东的区域，不包括昆山综保区及外泾河路、玫瑰路、保通路。

（三）中环以内除上述区域外，允许正常行驶。

三、昆山市域内原货车限行政策不变。针对国Ⅲ及以下排放标准柴油货车申请进入中环限行区域的，公安机关交通管理部门将不予办理道路通行证；国Ⅲ及以下排放标准柴油货车已取得中环限行区域2019年道路通行证的，自期满后不再换发中环限行区域的道路通行证。

四、公安机关交通管理部门将按照本通告规定的限行区域设置交通标志，驾驶人应当按照交通标志通行。公安机关交通管理部门可以在上述限制通行区域设置高排放机动车自动识别系统。

五、违反本通告的，由公安机关交通管理部门按照违反禁令标志予以处罚。

六、本通告自2019年9月26日起施行。市政府此前发布的文件与本通告不一致的，按照本通告的规定执行。
