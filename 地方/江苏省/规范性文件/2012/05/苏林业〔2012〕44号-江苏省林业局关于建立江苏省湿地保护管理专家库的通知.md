# 江苏省林业局关于建立江苏省湿地保护管理专家库的通知

各市林业局：

为提高全省湿地保护管理决策水平，促进湿地保护管理科学化、规范化，充分发挥专家在湿地保护管理工作中的决策支撑作用，决定建立江苏省湿地保护管理专家库。在各有关单位推荐基础上，经严格审核，决定聘用薛建辉等47位专家为首批江苏省湿地保护管理专家库成员（名单见附件）。专家库专家对全省湿地保护管理规划编制、政策法规制订、湿地保护名录确定等湿地保护管理工作提供咨询服务和技术支持。全省湿地自然保护区、湿地公园、湿地保护小区建设审查评估专家应根据相关要求从发布的专家库中随机抽取。

附件：江苏省湿地保护管理专家库成员名单
