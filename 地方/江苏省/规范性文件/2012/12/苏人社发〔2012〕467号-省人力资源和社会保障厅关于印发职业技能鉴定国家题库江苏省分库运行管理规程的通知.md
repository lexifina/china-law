# 省人力资源和社会保障厅关于印发职业技能鉴定国家题库江苏省分库运行管理规程的通知

各市人力资源和社会保障局，昆山、泰兴、沭阳县（市）人力资源和社会保障局：

为规范我省职业技能鉴定题库运行管理，加强安全保密工作，根据人力资源和社会保障部《关于印发职业技能鉴定国家题库安全保密工作规程（暂行）的通知》（人社鉴发[2010]2号）、《关于开展职业技能鉴定题库地市级分库试点机构评估工作的函》（人社厅函[2012]300号）精神，我厅对《职业技能鉴定国家题库江苏省分库运行管理规程》（苏劳社鉴[2003]11号）进行了修订，现印发给你们。请结合实际，认真贯彻执行，执行中如遇到问题及时报我厅职业技能鉴定中心。我厅将于2013年第2季度对各市级分库运行情况进行专项检查，具体要求另行通知。

江苏省人力资源和社会保障厅

2012年12月4日
