# 省人力资源社会保障厅省财政厅关于职业年金启动投资运营前个人账户记账利率和投资收益率有关事项的通知

各设区市、县（市）人力资源和社会保障局、财政局，各中央驻苏单位：

根据《人力资源社会保障部办公厅 财政部办公厅关于职业年金启动投资运营前个人账户记账利率和投资收益率有关事项的通知》（人社厅发﹝2019﹞3号）精神，现结合我省实际，就职业年金启动投资运营前记账部分记账利率和实账积累部分投资收益率等有关事项通知如下：

一、2014年10月1日至2018年12月31日，机关事业单位职业年金个人账户中记账部分按5%年记账利率计算记账利息。

二、2014年10月1日至2018年12月31日，机关事业单位职业年金个人账户中实账积累部分按5%年投资收益率计算投资收益。

三、上述两项之和与已经归集的职业年金存款利息差额部分所需资金由同级财政给予保障。中央驻苏单位的5%年记账利息和5%的投资收益所需资金由各单位承担。

四、2019年3月底前，按规定应当归集而没有归集的，应计入个人账户的利息和投资收益全额由参保单位承担。

江苏省人力资源和社会保障厅

江苏省财政厅
