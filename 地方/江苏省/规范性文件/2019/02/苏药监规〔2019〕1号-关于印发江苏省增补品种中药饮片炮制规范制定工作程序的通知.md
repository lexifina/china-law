# 关于印发江苏省增补品种中药饮片炮制规范制定工作程序的通知

各设区市市场监督管理局，昆山、泰兴、沭阳县（市）市场监督管理局：

为规范我省增补品种中药饮片炮制规范制定工作，根据《中华人民共和国药品管理法》《国家药品监督管理局关于发布省级中药饮片炮制规范修订的技术指导原则的通告（2018年第16号）》有关规定，我局起草了《江苏省增补品种中药饮片炮制规范制定工作程序》（附件），现予印发。
