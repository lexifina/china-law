# 省国资委转发国务院国资委办公厅《关于做好2019年国有企业招收高校毕业生工作有关事项的通知》的通知

各省属企业，各设区市国资委：

为贯彻落实《国务院关于印发“十三五”促进就业规划的通知》（国发〔2017〕10号）和《国务院关于做好当前和今后一个时期促进就业工作的若干意见》（国发〔2018〕39号）精神，积极做好2019年国有企业招收普通高等学校毕业生（以下简称高校毕业生）工作，国务院国资委办公厅印发了《关于做好2019年国有企业招收高校毕业生工作有关事项的通知》，现转发给你们。请认真对照文件要求，充分认识做好招收高校毕业生工作的重要意义，切实加强对2019年高校毕业生招收工作的组织领导，建立健全招聘工作管理制度，努力营造公开公平公正的就业环境。各单位要进一步明确目标，强化责任，采取有力措施，全面推进招收高校毕业生工作。

请各省属企业和设区市国资委分别组织填写《省属企业2019年招收高校毕业生情况统计表》和《各设区市国资委监管企业2019年招收高校毕业生情况统计表》，于9月20日前报省国资委。
