# 连云港市住房和城乡建设局关于加强我市住宅阳台排水管理工作的通知

（连建总〔2019〕321号）

各有关单位：

为进一步改善城市水环境，从源头上杜绝住宅阳台洗衣机等污水通过雨水管直接流入自然水体污染环境现象，实现雨污分流，提高城市生态环境质量，现就加强我市住宅阳台排水管理工作通知如下：

一、新建、改建住宅的阳台应单独设置阳台污水收集系统，并采取防臭措施后排入室外污水收集系统。

二、施工图设计审查机构、监理单位、质量监督机构和排水管理部门应将住宅阳台污水收集系统的要求纳入到审查、监理、质监和竣工验收备案等管理工作中。

三、住宅小区的物业管理单位应以适当的方式告知业主，并根据物业服务合同做好住宅阳台污水收集系统的管理和维护。

本通知自发布之日起实施。

连云港市住房和城乡建设局

2019年8月2日
