# 连云港市赣榆区促进重点工业项目招商引资若干政策指导意见（试行）

（赣政发〔2018〕57号）

各镇人民政府，区各委办局，区各直属单位：

为全面贯彻落实市、区“高质发展、后发先至”动员大会精神，加快实施“工业立区、产业强区”战略，以优惠的政策、优良的服务，鼓励和吸引更多规模体量大、科技含量高的优质工业项目落户我区，根据《市政府关于扩大对外开放加大招商引资力度的实施意见》（连政发〔2017〕48号）文件精神，特制定本指导意见。

一、支持范围

本指导意见支持项目是指新引进的符合国家产业政策、环保安全要求以及我区产业导向，固定资产投资（包括土地购置及相关税费支出、厂房及办公楼建设支出、设备购置支出、配套设施投资支出等，下同）过5000万元或800万美元的装备制造、电子信息、新能源、新材料、新医药等重点工业项目。

二、扶持政策

（一）投资奖励

1.项目受益财政根据项目类型和对本地区经济贡献度，可给予新引进项目一定额度的投资奖励，用于企业研发、信息化建设等，按会计年度兑现。

2.项目按照约定序时投产，年亩均税收达到5万元-10万元的，受益财政可给予相当于项目当年度对地方经济收入贡献实绩不超过50%额度的奖励，时限3-5年；年亩均税收达到10万元的，受益财政可给予相当于项目当年度对地方经济收入贡献实绩不超过70%额度的奖励，时限3-5年。

（二）设备补贴

1.项目受益财政根据项目类型和对本地区经济贡献度，可给予新引进项目一定额度的设备补贴，用于技术改造、设备升级等，按会计年度兑现。

2.项目按照约定序时投产，自投产之日起3年内，年亩均税收达到5万元-10万元的，受益财政可按其生产性设备实际投入的3%额度给予一次性补贴；年亩均税收达到10万元的，受益财政可按其生产性设备实际投入的5%额度给予一次性补贴。

3.对达到奖励条件的项目，设备补贴可一次性或在前3年内分期兑现到位，具体由项目双方协商约定。

4.受益财政每年给予项目设备补贴与投资奖励的总额，不得超过项目当年度对地方经济收入贡献实绩。

（三）基建奖励

1.对新引进的重点工业项目，允许实行弹性出让、先租后让等工业用地供应方式。

2.在项目用地上，受益财政根据项目类型和对本地区经济贡献度，可给予购地新建项目一定额度的扶持，用于项目基础设施配套等，按会计年度兑现。

3.项目按照约定序时投产，自投产之日起，年亩均税收达到5万元-10万元的，受益财政可给予每亩不超过5万元的奖励；年亩均税收达到10万元的，受益财政可给予每亩不超过10万元的奖励。

4.基建奖励可在项目投产后分期兑现或提前预支，具体由项目双方协商约定。

（四）厂房补贴

1.以租赁的形式取得我区标准厂房使用权的新引进项目，按照约定序时投产，且投产后年亩均税收达到5万元的，受益财政可给予一定年限减免租金补贴。

2.对新建厂房或购买我区标准厂房的新引进项目，按照约定序时投产，且投产后年亩均税收达到5万元的，受益财政可给予一定额度厂房补贴。原则上，单个项目新建或购买厂房面积不低于5000平方米。

3.补贴资金由区、镇（园区）共同承担。其中，区级财政对项目固定资产实际投资达到5000万元、1亿元的，分别给予项目载体单位50万元、100万元的奖励，主要用于项目建设的厂房补贴；各镇（园区）根据自身情况，安排配套资金。

（五）产业引导

对固定资产投资5亿元以上的高新技术产业项目，可给予代购土地、代建厂房和股权投资等扶持政策。具体内容，参照有关法律、法规及政策规定，由项目双方协商约定。

（六）服务保障

对固定资产投资10亿元以上的重大项目，成立由区级领导、招引单位主要负责人、驻企帮办员组成的专项服务组，提供“一对一”“一条龙”的管家式服务，负责代办、协调项目审批和建设过程中的所有手续和问题。

三、其他

1.对重大项目（固定资产投资5亿元以上），或科技含量较高的项目，或大公司、大集团、跨国公司投资项目，以及其他对赣榆经济发展具有重要意义的项目，在投资奖励、土地供应和各项费用收取等方面，按照更加灵活、更加优惠的原则，实行“一事一议”政策。

2.本指导意见涉及的固定资产投资、生产性设备投入等兑现依据以合法有效的票据或有资质单位出据的审计评估报告为准。

3．本指导意见与赣榆区已颁布的其他相关产业扶持政策同步执行。同一项目同时符合其他扶持奖励政策规定的，按照从高不重复的原则予以支持。

4.本指导意见所指新引进项目，是指购地新建或购买厂房新上工业项目，包含已落户企业投资新建与现有行业不同的项目，不含已落户企业扩建、技改项目。

5.各镇（园区）可根据本指导意见，结合自身实际，自行制定出台引进项目招商引资优惠政策，对农业和服务业等项目，也可参照执行。

6.本指导意见由赣榆区重点工业项目招商引资与扶持奖励评审领导小组办公室负责解释，自发文之日起试行。区级原有招商引资优惠政策同时废止。

7.今年以来至发文之日前，对符合支持范围和认定条件的招商引资落地项目，各镇（园区）可视项目推进情况，参照本意见执行。
