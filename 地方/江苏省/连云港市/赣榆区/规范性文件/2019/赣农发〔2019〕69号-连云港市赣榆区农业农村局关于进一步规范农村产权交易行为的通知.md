# 连云港市赣榆区农业农村局关于进一步规范农村产权交易行为的通知

（赣农发〔2019〕69号）

各镇农村经济服务中心：

农村集体产权交易工作事关集体利益维护、基层社会和谐稳定。为规范农村产权交易行为，完善农村产权交易程序，根据《赣榆区农村产权交易管理办法（试行）》（赣委办发〔2015〕55号）要求，结合实际工作，现就进一步规范我区农村产权交易行为，作出如下补充规定。

一、明确交易项目

根据苏农经〔2017〕11号文件农村产权交易项目“应进必进”的要求，各镇、村凡需要进行农村产权交易的，在履行村、镇相关手续后，必须到区或镇农村产权交易机构进行信息登记，由区、镇农村产权交易机构统一发布信息，按规定程序组织交易。

二、严格交易范围

根据我区农村产权交易工作实际情况，10万元以上项目（农户土地承包经营权、农村养殖水面使用权、海域使用权除外）原则上在区农村产权交易中心报名登记并现场交易，50万元以上项目（农户土地承包经营权、农村养殖水面使用权、海域使用权除外）必须在区农村产权交易中心报名登记和现场交易。

三、严格交易方式和程序

1.各镇村需要交易的项目，在完成村两委会讨论、村民代表会通过后报镇政府核准，镇政府核准通过后的项目由镇农村产权交易服务中心安排专人对申请项目进行现场勘查并填写勘查报告，经过现场勘查后进行平台登记并提交区交易中心审核（重大项目需有专业评估公司评估报告）。项目登记需提交材料包括：村民代表会议记录、项目现场勘察表，房屋建设类项目须提供国土部门出具的建设用地证明；资金来源为财政拨款的工程类项目须同时提供发改委立项证明或项目主管部门批复、资金来源证明、工程量清单、施工图纸、招标文件；资金来源为村集体自筹的20万元以上项目须提供工程量清单、招标文件。经区交易中心审核通过后的项目，由镇农村产权交易服务中心生成交易公告并报区农村产权交易中心审核，审核通过后由镇发布交易公告（交易平台网络公告与项目所在村公告栏张贴公告同步进行），公告内容包括：项目概况、报名起止时间、报名地点、交易时间、交易地点、交易方式、报名费及保证金缴纳、报名条件（要注明接受个人报名还是企业报名）等，公告时间不得低于七天,公告应注明交易方式以及当意向承包方数量不足以进行公开招标活动时应采用何种方式交易的情况。

2.交易公告发布后，在公告期内，镇农村产权交易服务中心接受意向受让方报名并进行资质审查，接受报名时间不得低于五天。工程类招标项目，如对报名人有资质要求，报名人报名时须提供以下材料：（1）企业营业执照副本复印件加盖公章；（2）企业资质证书复印件加盖公章；（3）安全生产许可证复印件加盖公章；（4）注册建造师资格证复印件加盖公章；（5）注册建造师安全生产考核合格证复印件加盖公章；（6）法定代表人或代理人身份证原件及复印件；（7）授权委托书；（8）项目经理与资质公司签订的劳动合同及近三个月的社会保险缴纳明细证明（社保证明必须由社保部门出具并加盖印章）；（9）外省企业进驻本省资质审验材料。区、镇农村产权交易中心接到报名人报名材料后要及时进行报名登记、上传相关附件并提交区交易中心审核。

3.农村产权交易可以采取协议转让、拍卖、招投标等方式，也可以采取法律、法规、规章规定的其他方式。交易现场由区或镇农村产权交易机构主持，交易双方到场并有村民代表等相关人员参与监督。

4.为保证项目交易后能够正常实施，区交易中心建立信用管理体系，参照赣信用办〔2018〕5号文件，项目成交后，如果因为转让方原因，导致项目不能正常实施，区将会把转让方纳入不诚信名单，一年内限制该转让方通过平台交易。受让方出现串标、中标后弃标导致项目不能正常实施等违规行为的，企业法人将会降低信用等级，自然人将被纳入失信名单，半年内不能参与平台交易。

四、投标保证金的收取与退回

为保证交易正常开展，交易项目收取的投标保证金全部缴纳至区农村产权交易中心专有账户，待交易结果公示期满后，由镇交易服务中心提供材料至区交易中心财务人员，由区交易中心财务人员统一退回保证金，保证金的退回要准确及时，镇提交退回保证金的材料包括：项目名称、报名人姓名、退款账号、是否是中标人、交易鉴证费收取金额、保证金退回金额等。

五、交易档案资料的整理归档

交易档案资料的整理要完整规范，各镇须于每月10日前将上月所有交易项目的档案资料整理齐全并报区交易中心一份存档备查。档案资料装订内容包括：项目登记前的村民代表会议记录、交易申请报告、现场勘察表等材料、登记审批表（特殊项目包括项目评估报告、招标文件、清单、图纸等）、交易公告、报名材料、开标材料、交易成交公告、合同等。档案资料按照平台交易流程整理，分项目装订成册。

六、实施责任追究

1.镇农村集体资产管理部门及农村集体经济组织成员、工作人员有下列情形之一的，应当追究责任：

（1）根据村民代表大会的决议应该进入区镇农村产权交易机构交易的产权，规定应进场交易而未进场交易或规避进场交易的；

（2）违反规定将必须进场交易的项目化整为零或以其他方式规避招标的；

（3）不按规定履行事前核准、备案、告知手续的；

（4）交易公告中有关获取交易文件的时间和办法的规定明显不合理的；提供虚假的公告、证明材料，或者公告含有欺诈内容的；

（5）在交易活动中索取、收受贿赂的；

（6）对发现的违规交易行为不及时报告或放任纵容的；

（7）在交易过程中有借工作之便参与违规交易、不当干预正常评标活动、收受贿赂等违纪违法行为的；

（8）泄露依法应当保密的与交易有关的情况或者资料的；

（9）利用交易平台为相关单位、个人提供虚假交易手续。

2.投标方在投标过程中采取不正当手段获取招标信息的、投标人之间相互串通排挤其他投标人的，应当追究责任。

3.招标方不按规定履行职责的、无故不与中标方签订合同的，应当追究责任。

4.对以上应当追究责任的行为，移交纪检监察机关，由纪检监察机关依法依规进行追究。

其他未尽事宜按《赣榆区农村集体资产监督责任追究办法（试行）》规定执行。
