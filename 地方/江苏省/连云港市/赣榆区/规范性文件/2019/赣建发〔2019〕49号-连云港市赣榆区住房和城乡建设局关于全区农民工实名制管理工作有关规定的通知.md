# 连云港市赣榆区住房和城乡建设局关于全区农民工实名制管理工作有关规定的通知

（赣建发〔2019〕49号）

各施工企业、建设单位，各有关单位：

为进一步贯彻落实《建筑工人实名制管理办法（试行）》、《江苏省政府办公厅关于全面治理拖欠农民工工资问题的实施意见》（苏政办发〔2016〕85号）文件精神，保障农民工合法权益，防范拖欠农民工工资行为的发生。现就全区农民工实名制管理工作有关规定的通知如下：

一、施工企业应在新项目缴纳农民工工资保证金并核发施工许可证前到局清欠办申请办理农民工实名制管理登记手续；在工程项目所在地银行开设农民工工资专用账户并为农民工办理工资卡；应当设立劳资专管员，并报局清欠办备案；劳资专管员应定期通过实名制平台的考勤信息生成农民工工资表。

二、建设单位在按照施工合同约定拨付工程进度款时，应将进度款的20%资金存入施工企业开设的农民工工资专用账户中；应发工资高于进度款20%的，则按照实际工资数额存入工资专用账户。若在工程主体完成之前合同未约定进度款的项目，建设单位应在工程开工之前向农民工工资专用账户存入工程合同价款1%的专用款，用于专项支付农民工工资。

三、区预售资金监管中心应在拨付工程进度款时优先将农民工工资费用拨付到农民工工资专用账户。

四、管理银行应按照实名制平台生成的农民工工资表，按月足额转入农民工的个人账户。

五、局清欠办应对农民工工资表等信息数据进行核对，确保实名制平台内数据真实完整。

六、对于建设单位和施工企业在落实“四项制度”中的失信行为。我局将采取约谈相关负责人、暂停建设相关手续、暂停商品房销售、暂停拨付预售资金、限制融资贷款、追缴或加倍追缴农民工工资保证金、记不良行为、扣信用分、在“信用中国”网站发布、限制本地市场准入；对于涉嫌“拒不支付劳动报酬”罪的企业和个人，移交公安、人社、司法部门，依据《劳动法》、《刑法》等相关法规查处；对于恶意讨薪的劳务班组及其负责人,将逐级上报市和省清出全市或全省建筑市场。

七、本通知自印发之日起施行，由区住建局负责解释。

连云港市赣榆区住房和城乡建设局
