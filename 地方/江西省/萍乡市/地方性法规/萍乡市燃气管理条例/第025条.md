# 第二十五条

燃气用户应当遵守法律、法规的规定和安全用气规则，不得有下列行为：

初装管道燃气用户未经燃气经营者验收合格自行开通点火；

使用不合格或者使用年限已届满的燃气燃烧器具、连接管等；

将安装有燃气设施的场所改为卧室、浴室等违反安全用气规定的场所；

在同一室内同时使用其他燃料；

将管道燃气设施砌入墙体或者采取可能影响管道燃气设施安全的其他方式遮盖、隐蔽管道燃气设施；

加热、摔砸、倒卧、曝晒气瓶或者改换气瓶检验标志、权属标志、钢印、漆色；

排放气瓶内燃气、残液；

改变燃气用途或者转供燃气；

擅自安装、改装、拆除户内燃气设施和燃气计量装置；

使用明火检查泄漏。

非居民用户应当遵守燃气安全管理制度，操作人员、管理人员应当接受安全生产教育和培训。
