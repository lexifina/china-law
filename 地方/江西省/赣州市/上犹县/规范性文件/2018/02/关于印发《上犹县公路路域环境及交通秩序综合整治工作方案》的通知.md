# 关于印发《上犹县公路路域环境及交通秩序综合整治工作方案》的通知

各乡（镇）人民政府，县政府有关部门，县属、驻县有关单位：

《上犹县公路路域环境及交通秩序综合整治工作方案》已经县政府研究同意，现印发给你们，请结合实际，认真抓好贯彻落实。

2018年1月12日

上犹县公路路域环境及交通秩序

综合整治工作方案

为贯彻落实省委、省政府关于建设国家生态文明试验区、打造美丽中国“江西样板”和建设优美城乡环境的战略部署，进一步提高我县公路通行能力和服务水平，营造安全有序、文明和谐的交通环境，根据《江西省人民政府办公厅关于转发省交通运输厅省公安厅全省公路路域环境及交通秩序综合整治工作方案的通知》（赣府厅字〔2017〕129号）等有关文件精神，现就开展全县公路路域环境及交通秩序综合整治工作制定如下方案。

一、整治范围及目标

整治范围为我县所有公路，整治重点为高速公路、普通国省道。包括我县境内高速公路G76厦蓉高速、国道G357（黄埠—中稍）、省道S547(东山镇—江西坳)、省道S221（东山—社溪）等国省道公路、高速公路、连接线及县乡道路。我县境内高速公路G76厦蓉高速作为此次环境整治示范路。

（一）路域环境整治。范围包括公路用地、公路建筑控制区以及建筑控制区以外可视范围。努力实现公路沿线路域环境“八个无”目标（交通标志前后500米无广告、无违法建筑物和地面构筑物、无违法搭接道口和占地挖掘公路、无违法跨越和穿越公路的设施、无违法非公路标志、无路基路肩边坡非法种植物、无摆摊设点和打谷晒场、无公路用地范围内堆积物），营造畅安舒美的公路交通环境。

（二）公路通行秩序整治。范围包括所有我县公路行驶的客货运车辆（重点是3轴及3轴以上货运车辆和大型客车），通过加大对客货运车辆违法超限超载超速超员行为的查处力度，有效遏制违法超限超载超速客货运车辆、非法改装货运车辆绕行低等公路，逃避治超站点检查的行为，发挥高速公路、普通国省干线公路和农村公路不同的运输功能作用，营造畅通高效、安全绿色的公路交通环境。

二、整治内容

（一）公路基础设施整治。严格按照各等级公路基础设施工程技术标准和规范，全面排查和整治公路路基、路面、排水系统、防护工程、桥梁、隧道、交通安全设施、环境保护设施、通信监控设施和隧道通风、照明、消防、逃生设施等方面存在的不足，保障其处于良好的技术状态和安全保障水平。（责任单位：县交运局、公安局、环保局、公路管理局、高速路政办）

（二）公路路面环境整治。依法取缔各类违法占道经营、占道晒粮、沿路串卖、马路市场，整治违法占路经营、摆摊设点等行为，清除各类占道堆积物。对公路两侧的建筑材料、砂石等散装货物集散地和建设工地进行清理规范，做好防护措施，防止造成公路污染。（责任单位：县交运局、城管局、市场和质量监管局、城建局、矿管局、水利局、公路管理局、各乡镇政府）

（三）公路沿线标志标线和交通安全设施整治。开展路域范围内道路交通标志标线和穿越公路行人过街设施使用情况排查，对存在安全隐患的要重新设计并整改。完善和规范公路标志设置，增设地域自然、人文景观、公路服务设施和宣传交通安全文明等行业统一标志标牌，优化美化公路出行人文环境。对影响公路安全畅通及违法标识标牌必须拆除。（责任单位：县交运局、交管大队、城建局、城管局、公路管理局、高速路政办、各乡镇政府）

（四）交叉路口整治。平交道口及接入口设置要规范，平交道口要保证视距良好，间距合理，无遮挡视线的障碍物，干线要设置警示标志和道口标柱，支路要设置减速让行或停车让行标志，明确主路优先通行权。干线公路之间、干线公路与其他县道的交叉道口要设置指路标志。要在乡道道口处设置减速带。公路沿线各施工单位及各企业要负责做好开设道口的硬化和卫生保洁工作。（责任单位：县交运局、城建局、交管大队、公路管理局、各乡镇政府）

（五）公路绿化景观整治。对公路绿化带和分隔带，要因地制宜，突出绿化特色，坚持人工造景与自然景观相结合，坚持“栽、管、护”相统一，进一步优化完善设置。高速公路要以打造昌铜高速公司路绿色生态百里画廊为示范，努力打造全国绿色高速公路“江西样板”。普通公路要以助力美丽生态江西建设为重点，及时清除病死树木，加强对绿化带的管护，达到“树种多样、四季常青、花草成片、层次分明”的效果。（责任单位：县交运局、城建局、城管局、公路管理局、高速路政办、各乡镇政府）

（六）过乡镇村庄路段整治。公路过乡镇、过村庄路段要严格按照有关规划和管理要求，综合治理公路两侧新建集贸市场、厂矿企业、学校、住宅等，做到路宅分离、建设规范。加大街道景观环境整治力度，进行必要的亮化、绿化和美化。（责任单位：县交运局、城管局、城建局、公路管理局、各乡镇政府）

（七）公路建筑控制区整治。对各等级公路、公路用地、桥下地面及公路建筑控制区内的违法建筑、违章搭建、违法地面构筑物依法全面拆除，全面整治修复公路排水系统。查处和清理公路两侧、桥梁上下游、公路隧道上方和洞口外等安全保护区内的违法采矿、采石、取土、采砂以及其他违法作业行为，规范公路沿线加水站和修理厂。（责任单位：县交运局、城建局、城管局、矿管局、公路管理局、各乡镇政府）

（八）公路通行秩序整治。全面排查公路桥梁技术状况，确定现行荷载标准，在合适地点设置荷载标准标识牌和通行指示牌，深入开展客货运车辆超限超速超员治理工作，坚持以固定治超为依托，在重点区域、重点路段、重点时段开展流动治超，利用移动检测设备进行检查，建设货车超限超载动态自动监测系统，努力提升科技治超水平。根据道路等级和行车安全要求，分车型设定相应行驶限速标准。在合适地点设置客货车辆行驶速度标识牌，加强公安交警路面执法，大力整治客货车辆超速行为。（责任单位：县交运局、公安局、城管局、治超办、公路管理局、各乡镇政府）

三、时间安排

本次整治工作从2018年1月开始至2018年12月底结束，分三个阶段进行。

（一）调查摸底阶段（2018年1月）。各责任单位结合实际，组织动员部署，细化分解任务。根据本方案确定的整治内容和工作标准进行全面调查摸底，找出当前存在问题和不足，对影响安全行车和公路环境的各类设施登记造册，制定整治工作计划，落实工作职责和时间节点。

（二）集中治理阶段（2018年2月至11月）。各责任单位针对前阶段调查摸底情况、日常监督检查中所发现的问题，全面启动整治工作，采取多部门联动方式，集中治理公路路域环境及交通秩序。整治工作要合法合规，因地制宜，注重成效。要及时总结经验，不断推动整治工作深入开展。

（三）总结提高阶段（2018年12月）。各责任单位要认真总结经验，梳理存在的问题和不足，进一步完善相关制度和措施，巩固整治行动成果，建立健全公路路域环境及通行秩序整治的长效机制，大力提升公路管理的法制化、规范化水平。

四、工作要求

（一）加强组织领导。成立公路路域环境及交通秩序综合整治工作领导小组，由县政府主要领导任组长，县政府分管交通、公安的领导任副组长，县交运局、交管大队、城建局、城管局、市场和质量监管局、国土局、矿管局、水利局、公路管理局、治超办、高速路政办和各乡（镇）政府主要负责人为成员。

（二）加强部门联动。各责任单位要主动靠前、积极作为，其他单位要大力支持、密切配合，形成信息共享、情况互通、齐抓共管的工作合力。各公路沿线乡（镇）政府和行业管理部门要建立工作协调和情况会商机制，对公路建筑控制区违法建筑物重难点问题组织相关职能部门联合行动，依法依规及时处置。

（三）强化舆论引导。充分发挥广播、电视、报刊、网络、微信等媒体的舆论引导作用，大力宣传公路路域环境及通行秩序整治工作的现实意义，进一步增强工作紧迫感。注重典型整合的宣传曝光，接受社会监督，扩大公众参与面，创造全社会关心、公路路域环境及通行秩序整治工作的良好局面。

（四）加强监督检查。各责任单位要加强内部监督检查，及时总结经验做法和工作体会，同时表扬先进、鞭策后进，形成比学赶超氛围，保证环境整治工作任务落实到每个人。对治理工作组织实施不到位、岗位工作落实不到位、治理成效不明显的部门，将对相关责任人进行责任追究。
