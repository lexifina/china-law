# 关于印发《上犹县2018年度产业扶贫到户奖补实施办法》的通知

各乡（镇）人民政府，县政府各部门，县属、驻县各单位:

经县政府研究同意，现将《上犹县2018年度产业扶贫到户奖补实施办法》印发给你们，请认真贯彻执行。

2018年3月29日

上犹县2018年度产业扶贫到户奖补

实施办法

为进一步激励广大建档立卡贫困户发展产业，深入推进产业扶贫，帮助更多贫困户尽早尽快脱贫致富，结合2017年产业扶贫到户奖补项目实施情况，特制定本办法。

一、农业产业扶贫到户奖补项目内容（详见附表）

每户贫困户每项农业产业项目每年只能申报一次，且每户贫困户当年享受的奖补资金总额不得超过5000元。

二、农业产业扶贫奖补的程序

1.贫困户根据家庭实际情况自主选择产业发展类型，合理确定家庭主导产业。

2.产业项目实施完成后，由结对帮扶干部协助贫困户填写《上犹县产业扶贫项目申请、验收、审核表》。

3.结对帮扶干部、第一书记或驻村工作队员、村“两委”干部共同对贫困户当年新发展实施的产业扶贫项目进行现场验收。

4.各乡（镇）成立产业扶贫项目验收工作领导小组，由该领导小组审核后发回贫困户所在村进行公示，公示时间不得少于7天。

5.产业扶贫项目验收并公示无误后，乡（镇）每半月汇总向县城投公司申报资金，资金拨入乡（镇）精准扶贫专户后，乡（镇）财政所及时将奖补到户资金通过“一卡通”发放给贫困户。

6.各乡（镇）每月汇总产业扶贫项目奖补明细，报送至农业和粮食局备存。同时，乡（镇）负责做好现场验收合影照片（帮扶干部、贫困户、发展产业）、村内公示照片、验收审核发放表等资料归档工作。

三、重点发展蔬菜、生态鱼、光伏等见效快、覆盖面广、符合我县实际的相关产业，确保产业扶贫全覆盖。光伏发电装机容量3千瓦以上，供电部门验收并网发电，一次性奖补6000元；装机容量5千瓦以上，供电部门验收并网发电，一次性奖补10000元。

四、各级把关验收签字的干部要切实履行监管责任，严格按照文件要求执行，严禁套取、骗取产业到户奖补资金。违者由纪检监察部门予以严肃查处，追回套取、骗取的奖补资金，并追究相关人员责任。

五、本办法自印发之日起执行。《上犹县人民政府办公室印发〈上犹县关于开展产业帮扶推进精准扶贫的实施办法〉的通知》（上府办发〔2015〕36号），《上犹县人民政府办公室印发《关于的补充规定》的通知》（上府办发〔2016〕50号），《上犹县2017年度产业扶贫到户奖补实施办法》（上府办发〔2017〕11号）停止执行，本办法另有规定的除外。
