# 关于分解落实2019年县《政府工作报告》主要目标任务的通知

各乡（镇）人民政府，县政府各部门，县属、驻县各单位：

2019年县《政府工作报告》已经县十八届人大四次会议审议通过。为确保全面实现县《政府工作报告》提出的2019年我县经济社会发展奋斗目标和主要任务，经县政府研究同意，现将县《政府工作报告》2019年主要目标任务分解表印发给你们，请按照以下要求，认真组织实施，确保各项工作落实到位、目标任务顺利完成。

一要高度重视。各乡（镇）、有关部门（单位）要严格按照责任分工，把落实目标任务作为履行工作职责、转变工作作风、提高服务质量的一件大事来抓。各牵头单位、责任单位主要领导要负总责，分管领导要具体抓，制定贯彻落实的具体措施，确保责任落实到位。

二要狠抓落实。各牵头单位要紧紧围绕目标任务，充分发挥牵头抓总作用，常态化协调推进所牵头的各项工作；各责任单位要自觉落实牵头单位分配的工作任务，积极主动配合，共同推动目标任务的完成。

三要强化督查。县政府督查室要加大督查力度，采取定期检查、不定期抽查和明查暗访等方式，对目标任务完成情况进行督查，并通报目标任务落实情况。各责任单位要分别于2019年6月20日、12月20日前，将所负责工作落实情况上报至各牵头单位，由各牵头单位梳理汇总后再以书面形式上报至县政府督查室（电子稿发送至shangyou99@163.com）。
