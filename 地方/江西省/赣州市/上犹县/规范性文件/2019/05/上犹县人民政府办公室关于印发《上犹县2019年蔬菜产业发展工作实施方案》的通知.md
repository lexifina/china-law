# 上犹县人民政府办公室关于印发《上犹县2019年蔬菜产业发展工作实施方案》的通知

各乡（镇）人民政府，县政府有关部门，县属、驻县有关单位：

经县政府同意，现将《上犹县2019年蔬菜产业发展工作实施方案》印发给你们，请认真抓好贯彻落实。

2019年5月29日

上犹县2019年蔬菜产业发展工作实施方案

为加快推进乡村振兴发展战略，深化农业供给侧结构性改革，加速全县现代农业发展进程，根据市委、市政府关于蔬菜产业发展的工作部署和发展定位，坚持巩固与发展并重、质量与效益并举，以品种品质品牌为重点，以绿色发展为导向，着力推动全县蔬菜产业高质量发展。现结合实际，特制定本方案。

一、工作思路

按照“产业兴旺、生态宜居、乡风文明、治理有效、生活富裕”的总方针，坚持农业农村优先发展，以科技为先导，大力推广蔬菜产业发展新品种、新技术和新模式，提升产业科技水平，推动全县蔬菜产业由粗放种植向规模化、标准化、集约化转变，全面提升全县蔬菜产业发展水平。

二、工作目标

（一）扩大产业规模。坚持适度规模、经济适用原则，年内以上太线沿线乡（镇）为重点，新（扩）建设施蔬菜产业面积2500亩以上，实现全县蔬菜累计播种面积达7.6万亩以上。

（二）培育经营主体。鼓励和支持规模设施蔬菜种植，大力培育蔬菜产业龙头企业、种植大户（能手）、家庭农场等经营主体14家以上（每个乡镇1家以上）。

（三）实现带农富民。通过鼓励和引导，充分发挥各类经营主体的示范带动作用，引导更多农户尤其是贫困户通过自主发展、反租倒包、订单生产、入股分红等方式直接或间接发展蔬菜产业生产。

三、工作重点

（一）建设规模基地

1.选址要求：各乡（镇）项目选址遵循“地势平坦、交通便利、沙质土壤、排灌便利”的原则，单个基地要相对集中连片50亩以上。

2.时序要求：以乡镇为单位，4月份完成蔬菜基地选址工作；5月份完成土地流转（基地土地流转须10年以上）及土地平整工作；6月份落实经营主体并启动大棚建设；力争10月份开始投入生产经营。

3.建设标准：

（1）标准大棚（单体大棚）

①主体规格：棚体高度不低于3m，肩高不低于2m，棚宽在8m以上。

②主要材质：拱管外径不小于25mm，壁厚不小于1.5mm；拱管间距不大于1.5m。棚顶及纵向两侧各一根外径不小于25mm、壁厚不小于1.5mm拉杆。棚头棚尾两侧各一根外径不小于25mm、壁厚不小于1.5mm斜交式拉杆。所有钢材需为全新热镀锌钢管，材料及焊接点必须做防锈处理。所有覆盖棚膜材料质量不低于国标GB/T10003-2008无滴10-15丝 PO膜、8-10丝EVA膜等蔬菜专用膜。

③配套设施：棚内开窗，并配备抗风钢丝绳、内膜悬挂设备。

④其他：验收过程中发现一年内都未覆盖棚膜、钢材生锈、大棚未明确编号的，不予验收。对建设标准稍高于标准大棚，但未达到高标准大棚建设标准的，按标准大棚奖补标准执行。

（2）连栋大棚

①主体规格：棚体高度不低于3.8m，肩高不低于2.5m，并用专用卡具连接，形成装配式连栋大棚。要求大棚四周采用砖体（混凝土）圈梁稳固，圈梁壁宽不小于100mm，高不小于300mm；或连地钢管底部浇筑外径不小于200mm的水泥柱进行稳固。

②主要材质：所有钢材为全新热浸镀锌钢管。立柱方管外径不小于60×40mm或50×50mm，圆管外径不小于60mm，壁厚不小于2.0mm；柱距不大于4m。肩管方管外径不小于40×40mm，圆管外径不小于47mm，壁厚不小于1.8mm。拱管圆管外径不小于32mm，壁厚不小于1.5mm。所有覆盖棚膜材料质量不低于国标GB/T10003-2008无滴10-15丝 PO膜、8-10丝EVA膜等蔬菜专用膜。

③配套设施：棚内开窗，并配备水肥一体化设施、内膜悬挂设备。

④其他：验收过程中发现偷工减料、大棚未明确编号的，不予验收。对建设标准高于连栋大棚，配套开窗、水肥一体化设施，具备通风、保温、遮阳、降温等功能的其他类型大棚，申报主体在提供完整造价证明材料后，可按“一事一议”验收标准收执行。

（3）新增田头冷库：新增库容50立方米以上。

（4）新建采后商品化处理场地：购置包装设备，实现100%产品分等分级和包装标识，推行净菜上市、建立溯源体系。

（二）创新发展方式

1.建设方式多样：主要采取以下五种方式同步实施：

（1）规模相对集中连片300亩以上的重大项目，县人民政府按照“一事一议”扶持建设；

（2）规模相对集中连片50亩以上社会资本投资建设的，县级按照有关标准奖补；

（3）政府采取招投标程序投资建设，由企业（大户）承建承租的，相关设施归村集体所有，发展村级集体经济；

（4）政府采取招投标程序投资建设，由农户（贫困户）租赁种植的，相关设施归村集体所有；

（5）农户（贫困户）自主建设小规模蔬菜基地，政府按标准奖补建设。（建设标准及补助标准按照年度产业扶贫奖补到户文件执行）

2.推广“七统一分”发展模式：积极探索“统一规划设计、统一搭建大棚、统一配套设施、统一政策扶持、统一种植品种、统一技术指导、统一产品销售、实行分户经营管理”模式，因地制宜制定符合本地的发展模式。

（三）强化科技支撑

1.推广实用技术：大力引进推广钢架大棚设施栽培、无土栽培、水肥一体化和互联网应用等农业尖端技术。推广连体双拱双膜钢架大棚和标准化单体钢架大棚，增加达到避雨、遮阳、降温、保温、增温、通风、防虫的“七大”功能，推广早春、越夏、秋延、越冬蔬菜栽培技术，确保一年四季能够安全种植和全年供应蔬菜。

2.优化种植品牌：加快蔬菜新品种引进、示范和推广，大力发展培育优良蔬菜品种，推广应用喷滴灌、杀虫灯、小型耕作机械等配套设施。

3.加强技术合作：加强与高校、蔬菜科研单位合作，加强与先进的蔬菜主产区的技术联系，坚持“请进来、派出去”，通过课堂培训与基地实训相结合的方式，加强蔬菜生产技术培训和服务指导，年内组织蔬菜生产技术集中培训2期以上。

（四）创建产品品牌

1.确保产品安全。强化蔬菜投入品监管力度，指导蔬菜基地全面建立生产和销售台账，坚决杜绝使用禁限用农药、安全间隔期未满即采等行为。强化投入品管控和监督抽检，对农残超标的蔬菜生产经营主体，年内申报奖补时实行一票否决。鼓励蔬菜生产经营主体积极申报“三品一标”。

2.注册地域商标。坚持品牌兴菜、绿色发展，应用“赣南蔬菜”品牌认定及评价标准，大力推进标准化生产。积极引导蔬菜基地建立质量追溯体系，着力扩大可追溯蔬菜产品的覆盖范围。发挥我县富硒土壤资源，建设一批富硒绿色蔬菜产业基地，打造“上犹富硒蔬菜”品牌。

（五）畅通市场渠道

1.结合蔬菜产业区域布局，规范县级农贸市场经营，完善县城、乡（镇）农贸市场体系。鼓励推进蔬菜生产经营企业在农产品交易中心、农贸市场设立蔬菜专营直销店。

2.鼓励现有运输、联运、快递企业拓展蔬菜服务项目，引导社会力量从事蔬菜配送、连锁经营、电子商务等业务，发展一批蔬菜购销经纪人队伍。

3.加强与广州、深圳、厦门等目标市场的交流合作，发展对口供应蔬菜基地，建立互利合作产销关系。引导企业、学校、酒店、社区居民与蔬菜生产基地、合作社、企业开展直供直销店，实现生产与销售相对接。

4.以规模蔬菜基地和集散市场为依托，推进蔬菜产品编码管理、包装仓储。加快各类保鲜、冷藏、冷冻、预冷等冷链物流设施建设，逐步推进蔬菜分级分拣及包装处理。

四、扶持政策

1.扶持基地建设：对社会资本投资按要求建设的相对集中连片50亩以上的蔬菜大棚（棚内面积按540平方米折算为1亩），按照标准大棚12000元/亩（含市级补助）、连栋大棚20000元/亩（含市级补助）的标准予以奖补；对新建田头冷库按照200元/立方米的标准进行奖补，每个基地的最高奖补资金不超过30万元；对新建采后商品化处理场地的，给予一次性5万元奖补；对列为县级重点蔬菜产业基地的，按照“一事一议”进行扶持。

2.扶持基础设施：一方面县级整合节水灌溉、农田、水利项目等予以扶持，改善水电路渠和地力条件，提高设施蔬菜基地标准化水平。另一方面县级对社会投资项目按照2000元/亩标准补助，用于设施蔬菜基地土地平整、道路、水沟等基础设施建设扶持。政府投资建设项目的同时要做好土地平整、道路、水沟等基础设施建设。

3.扶持品牌创建：积极提升产品品质，创建产品品牌，申报“三品一标”认证，对新获取无公害农产品、绿色食品、有机食品、地理标志农产品认证的，分别予以一次性1000元、3000元、3000元和5000元的补助。

4.扶持土地流转：根据各乡（镇）年度任务数，按照700元/亩的标准预拨给县农业农村局、各乡（镇）用于土地流转和工作经费（其中县农业农村局蔬菜办工作经费50元/亩），由县农业农村局、乡（镇）按程序申报拨付，年终结算对多余资金进行扣除。

五、保障措施

（一）强化组织领导。成立由县政府县长任组长，分管副县长任副组长，农业农村局、组织部、财政局、发改委、审计局、自然资源局、生态环境局、水利局等部门主要负责人及各乡（镇）主要负责人为成员的上犹县蔬菜产业发展工作领导小组。领导小组办公室设在县农业农村局，由县农业农村局局长兼任办公室主任，负责制定考核办法，分解年度任务，落实产业发展、基地建设、项目验收、资金奖补等事项；把蔬菜产业发展列入现代农业攻坚战重要考核项目，加大评分权重。各相关乡（镇）是当地蔬菜产业发展的责任主体，乡（镇）长作为第一责任人，要强化工作调度，并负责具体组织实施。

（二）强化部门配合。建立完善“蔬菜基地建在哪里，配套设施及服务就跟到那里”的机制，由县农业农村局牵头推进，结合高标准农田项目，设计建设一批标准菜田，县水利局负责排灌设施建设，县住建局负责严抓大棚质量，自然资源局负责调配设施农用地，通信部门负责协调杆线迁移工作等，气象部门负责建立蔬菜专项风险预警机制，各乡（镇）负责做好土地流转及矛盾纠纷调处工作。

（三）强化资金保障。县财政从整合涉农资金中安排1500万元用于政府投资建设高标准设施蔬菜基地；另外县本级安排资金5000万元用于对社会投资项目进行奖补或政府投资建设高标准设施蔬菜基地。

（四）强化招商引资。各乡（镇）、部门（单位）要以巩固脱贫成效工作为契机，广泛宣传蔬菜产业发展的各项扶持政策，引导农户尤其是贫困户、企业、外出创业人员、合作社等积极参与蔬菜产业发展，同时做好技术服务和扶持政策的申报工作；并围绕蔬菜产业发展，通过以商招商、专业队伍招商等形式，加强与上犹在外知名企业家和相关产业著名专业技术人才的跟踪对接，力争实现招商引资和招才引智“双赢”效果。
