# 上犹县人民政府办公室关于印发《上犹县高考中考及小学质量监测奖励方案（试行）》的通知

各乡（镇）人民政府，县政府有关部门，县属、驻县有关单位：

经县政府研究同意，现将《上犹县高考中考及小学质量监测奖励方案（试行）》印发给你们，请认真抓好贯彻落实。

2019年6月6日

上犹县高考中考及小学质量监测

奖励方案（试行）

为进一步激发广大教师和教育工作者的工作热情，推动我县教学质量稳步提升，促进教育事业快速发展，结合我县实际，特制定本方案。

一、高考上线奖励

（一）一本上线奖励

1.上犹中学以前三年高考一本上线人数的平均数为目标数，达到或超过目标数，按每人4000元的标准奖励学校；低于目标数10%以内，按每人3000元的标准奖励学校；低于目标数超过10%，按每人1000元的标准奖励学校。

2.上犹中专、上犹三中一本每上线1人，按每人4000元的标准奖励学校。

（二）二本上线奖励

1.上犹中学以前三年高考二本以上上线人数的平均数（含体艺生）为目标数，达到或超过目标数，按每人800元的标准奖励学校。若低于目标数10%，按每人500元的标准奖励学校。若低于目标数超过10%，按每人300元的标准奖励学校。（一本、二本奖励不重复计算）

2.上犹中专、上犹三中以前三年高考二本以上上线人数的平均数（含体艺生）为目标数，达到或超过目标数，按每人800元的标准奖励学校。若低于目标数，按每人500元的标准奖励学校。（一本、二本奖励不重复计算）

二、录取优质高校奖励

1.录取清华大学、北京大学：每录取1人奖励20万元，其中奖励生源学校10万元，奖励考生所在班级任课教师5万元，奖励考生5万元。

2.录取北京体育大学、中央美术学院、中央音乐学院：每录取1人奖励2万元，其中奖励生源学校1万元，奖励考生1万元。

3.录取42所“双一流”大学：每录取1人奖励0.6万元，其中奖励生源学校0.3万元，奖励考生0.3万元。若录取总人数超过33人，超过人数按每生1万元给予奖励，其中奖励生源学校0.7万元，奖励考生0.3万元（超过人数不重复奖励）。本项奖励与考取清华大学、北京大学、北京体育大学、中央美术学院、中央音乐学院的奖项不重复计算。

三、人口万人比奖励

1.如高考二本以上上线人数人口万人比（含体艺生）列全市第7名，分别奖励县教科体局5万元、学校15万元，在全市排名每前进1名，增加奖励4万元，其中奖励县教科体局1万元，学校3万元，累进累加；每退1名减少奖励4万元，其中减少县教科体局1万元，减少学校3万元，累退累减。如在全市排名列11名（含11名）后，则取消此奖项。

2.此项奖金分配办法：实际奖金÷全县二本以上上线人数×各校二本以上上线人数。

四、高考尖优生奖励（分文、理科）

1.考生高考成绩列全市第1名，奖励考生5万元，奖励生源学校10万元；

2.考生高考成绩列全市第2名，奖励考生3万元，奖励生源学校8万元；

3.考生高考成绩列全市第3-5名，奖励考生2万元，奖励生源学校每生5万元；

4.考生高考成绩列全市第6-10名，奖励考生0.5万元，奖励生源学校每生1万元。

五、中考奖励

1.中考质量奖励：设立中考质量奖，奖金30万元，按《上犹县中考教学质量奖励方案》执行。

2.稳定优质生源奖励：对中考成绩全县排名前30名且留在县内中学就读的考生给予奖励。

（1）前10名的考生各奖励1万元，并奖励生源学校每生0.5万元；

（2）第11至20名的考生各奖励0.6万元，并奖励生源学校每生0.3万元；

（3）第21至30名的考生各奖励0.3万元，并奖励生源学校每生0.1万元。

六、小学质量监测奖励

设立小学质量监测奖，奖金20万元，按《上犹县小学质量监测奖励方案》执行。

七、其它事项

1.在每年8月，由县委、县政府召开高考表彰大会，对全县优秀教师进行表彰奖励；由县财政在每年8月初预拨各项奖励资金的80%，剩余部分在10月底拨付到位。

2.奖励资金由学校制定分配方案，可直接到班到人。

3.本方案从2019年开始执行，解释权归上犹县教育科技体育局。

上犹县人民政府办公室 2019年6月6日印发
