# 关于做好我县2019年度电动汽车充电基础设施建设有关工作的通知

各乡（镇）人民政府，县政府有关部门，县属、驻县有关单位：

为切实加快推进我县电动汽车充电基础设施建设，促进我县新能源汽车推广应用，现就做好我县2019年度电动汽车充电基础设施建设有关工作通知如下：

一、目标任务

到2019年底，全县建成公用和专用充电设施165根以上（具体见附件1），满足全县各类电动汽车的充电需求，初步形成统一开放的充电服务市场。

二、工作要点

（一）明确项目投资主体。新能源汽车充电桩建设项目投资主体按建设类别确定。其中，任务类项目由县犹江实业公司当业主；鼓励类项目由停车位所有单位自行决定投资和运营主体。

（二）积极建设示范项目。积极探索“示范小区与单位”“示范公交”“大型文体场馆示范”等充电基础设施建设与运营模式试点示范，加快推进陡水停车场、梅水新建旅游接待中心及县城公共停车场充电设施建设。

（三）分类推进项目建设。1.任务类项目：社会停车场、安置点、公共社会活动区域等市政工程充电基础设施，由县犹江实业公司负责建设，县城管局配合推进，在2019年8月底前完成；旅游集散地、大型酒店等充电基础设施，由县犹江实业公司负责建设，县文广新旅局配合推进，在2019年9月底前完成。2.鼓励类项目：乡（镇）院内、学校、加油站、工业园企业等场所充电基础设施建设，由停车位所有单位负责推进，县发改委、财政局、工信局、教科体局、住建局、自然资源局、卫健委、商务局、工业园区管委会、犹江实业公司、供电公司、石油公司等单位配合推进。

三、保障措施

（一）加强协同配合。建立由县发改委牵头、相关部门配合的协同推进机制，统筹协调和督促落实全县电动汽车充电基础设施建设工作。各相关部门（单位）要切实承担起统筹推进充电基础设施建设的主体责任，强化协同配合，按照职责分工，抓好组织实施。每月26日前，县公安局交管大队负责将新能源电动汽车保有数量报县发改委，县供电公司负责将居民个人自用充电设施报装用电名单报县发改委。

（二）加快审批进度。相关部门要缩短充电基础设施建设审批时间，加快办理手续。居民个人自用充电设施，无需向县供电公司申请用电包装手续，需新装用电或扩容时，可直接向县供电公司申请用电报装手续；非居民个人充电设施，由产权单位或委托建设单位向县发改委备案（审批），县供电公司申请用电报装手续。县供电公司要制定充电设施报装业务办理指南，明确各类充电设施的电力报装流程。另外，对未做电动汽车充电桩规划及建设充电设施的房地产项目，县自然资源局、住建局不予审批及验收。

（三）加强配套电网支撑。县供电公司要根据充电基础设施建设需求，合理提高用电设计标准，修改完善相关标准规范，加强充电基础设施配套电网建设与改造，满足充电基础设施运营需求；要尽量缩短并网距离，为充电桩建设运营企业节省并网投资，原则上并网距离不得超过1公里。县供电公司必须在项目主体建设完成前，建设完善电网配套工程，不能因并网问题影响充电基础设施项目建设进度。

（四）积极争取补贴补助。县财政局、发改委要积极落实电动汽车充电基础设施中央和省、市财政支持政策，配合充电基础设施建设单位（企业）申报电动汽车充电基础设施省级和市级补贴资金，并加大力度争取中央和省、市资金支持符合条件的充电基础设施建设项目。补助资金按照“谁投资补给谁”的原则执行。2019年度鼓励类项目中，各乡（镇）在本乡（镇）政府院内建设30KW以上直流桩的，由县财政给予2万/根的奖励补贴。

（五）加大督查考核力度。各责任单位要安排专人负责，认真填写《上犹县电动汽车充电基础设施建设情况进度表》（附件3），并于每月26日前将进度表报县发改委（邮箱：syfgw2018@163.com），再由县发改委根据每月进展情况汇编项目进度专报报送县委、县政府。县政府办督查室、发改委要加强督促检查，对充电基础设施建设进展情况进行不定期督查，并将督查结果纳入单位年度考核。
