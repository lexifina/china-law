# 关于进一步加强规范性文件和重大行政执法行为备案工作的通知

各乡（镇）人民政府，县政府各部门，县属、驻县有关单位：

根据《江西省规范性文件备案办法》（省政府令第119号）、市推进法治政府建设工作领导小组办公室《关于进一步加强规范性文件和重大行政执法行为备案工作的通知》（赣市法府建办字〔2019〕2号）要求，为切实加强我县规范性文件和重大行政执法行为备案工作，促进该项工作制度化，现将有关事项通知如下：

一、提高认识，切实增强规范性文件和重大行政执法行为备案工作的自觉性

开展规范性文件和重大行政执法行为备案工作，是加强行政执法监督的重要形式，是维护社会主义法制统一的重要手段，对于提高行政机关依法行政水平、促进严格规范公正文明执法、加快推进法治政府建设、优化经济和社会发展环境具有重要意义。各乡（镇）、各部门（单位）要高度重视，进一步加强组织领导，压实工作责任，坚持“有件必备、有备必审、有错必纠”的原则，严格按照有关要求做好规范性文件和重大行政执法行为备案工作。

二、明确要求，切实增强规范性文件和重大行政执法行为备案工作的规范性

（一）明晰备案范围

1.规范性文件备案范围。本通知所称规范性文件，是指由行政机关或者经法律、法规授权的具有管理公共事务职能的组织依照法定权限、程序制定并公开发布，涉及公民、法人和其他组织权利义务，具有普遍约束力，在一定期限内反复适用的公文。符合上述定义的规范性文件均属于备案范围。

2.重大行政执法行为备案范围。行政许可方面包括作出行政许可决定，可能影响社会稳定或者引发群体性事件的；实施行政许可应当听证的。行政处罚方面包括各级人民政府作出的；责令停产停业的；吊销许可证或者执照的；对公民处1万元以上、对法人或者其他组织处10万元以上的罚款或者没收相当于该数额违法所得的。行政强制方面包括各级人民政府作出的；强制拆除对公民、法人或者其他组织的生产、生活有重大影响的建筑物、构筑物或者设施的。

（二）规范备案程序

1.备案和审查机关。以县政府及其办公室名义制定的规范性文件，报送同级人大及市政府备案，由县政府办负责分别报送至县人大监察司法和备案审查工作委员会、县司法局，再由县司法局负责报送至市司法局进行备案审查；以县政府名义作出的重大行政执法行为，报送市政府备案，由具体实施部门负责报送至县司法局，再由县司法局负责报送至市司法局进行备案审查。

县司法局负责对各乡（镇）政府、各部门（单位）制定的规范性文件和作出的重大行政执法行为进行备案审查。

2.报送备案期限。规范性文件应当自公布之日起10日内报送备案；重大行政执法行为自作出之日起10日内报送备案。

3.报送备案材料。规范性文件报备资料包括备案呈报表（见附件1）、规范性文件文本和说明，并按照规定的格式装订成册，一式2份。重大行政执法行为报备资料包括重大行政执法行为备案报告（见附件2）、重大行政执法决定书及主要案件资料，必要时需提交行政执法案卷；经听证程序作出的，应一并报送听证笔录复印件。

（三）严格审查处理

1.审查期限。备案审查机关应当自收到规范性文件和重大行政执法行为备案报告之日起20日内完成备案审查工作。

2.审查内容

（1）规范性文件审查内容。是否同法律、法规、规章相抵触；是否超越权限设定行政处罚、行政收费、行政许可、行政强制措施、减免税等事项；是否同上级行政决定、命令相抵触；不同规范性文件对同一事项的规定是否一致。备案审查机关审查行政规范性文件时，认为需要制定机关说明情况的，制定机关应当在规定期限内予以说明；需要其他机关提出意见的，其他机关应当及时回复。

（2）重大行政执法行为审查内容。备案审查机关对报送备案的重大行政执法行为的合法性、适当性进行审查，重点审查重大行政执法行为的主体、程序是否合法，事实、证据是否确凿，适用法律是否正确，运用行政裁量权是否适当。备案审查不影响重大行政执法行为的执行。备案审查机关备案审查时，认为必要的，可以调阅行政执法案卷等相关材料，有关行政执法部门应当予以协助。

3.审查处理

（1）规范性文件审查处理

①经审查，发现行政规范性文件同法律、法规、规章相抵触，或者超越权限设定行政处罚、行政收费、行政许可、行政强制措施、减免税等事项，或者同上级政府其他规范性文件相抵触的，先由备案审查机关书面建议制定机关在规定期限内自行纠正；制定机关逾期不纠正的，备案审查机关应当提出处理意见，报请本级政府作出予以撤销或者限期纠正的书面决定。

②行政规范性文件制定机关应当自接到备案审查机关的书面建议或者县政府限期纠正的书面决定之日起30日内，将纠正情况报送备案审查机关。制定机关重新制定或者修改的行政规范性文件，应当按照本规定要求重新报送备案。

③备案审查机关审查规范性文件时，认为需要有关机关提出意见的，有关机关应当在规定期限内回复；需要制定机关说明情况的，制定机关应当在规定期限内予以说明。

（2）重大行政执法行为审查处理。备案审查机关对报备的重大行政执法行为，经审查发现有违法或者不当的，应当提出《行政执法监督建议书》（见附件3），要求限期自行纠正、撤销或者重新作出行政执法决定。重大行政执法行为作出机关应当在接到备案审查机关的《行政执法监督建议书》之日起20日内，将处理结果报送备案审查机关。作出机关逾期不改正的，由备案审查机关提请本级人民政府作出《行政执法监督决定书》（见附件4），责令纠正或者撤销。

三、强化举措，切实增强规范性文件和重大行政执法行为备案工作实效性

（一）明确责任。各乡（镇）、各部门要高度重视，落实责任，指定专人负责规范性文件和重大行政执法行为的报备工作。

（二）加强监督。司法行政部门作为备案审查机关，要加强对行政规范性文件和重大行政执法行为备案工作的督促指导，对行政执法机关长期无备案件、应备不备、拖延报备、审查发现重大问题等情况提醒整改，逾期未整改的，视情况依据《江西省行政执法监督条例》处理。

（三）强化考核。将规范性文件和重大行政执法行为报备情况、整改情况纳入年度法治政府建设考评，并强化考评结果的运用。各乡（镇）、各部门于每年12月15日前将本年度开展规范性文件和重大行政执法行为备案工作情况说明报送至县司法局，如没有出台规范性文件、没有作出重大行政执法行为的，也要实行“零报告”，报送情况作为年度法治政府考评依据。
