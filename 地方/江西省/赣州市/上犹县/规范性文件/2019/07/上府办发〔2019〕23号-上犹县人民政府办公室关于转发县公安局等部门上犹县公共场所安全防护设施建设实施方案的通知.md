# 上犹县人民政府办公室关于转发县公安局等部门上犹县公共场所安全防护设施建设实施方案的通知

上府办发〔2019〕23号

上犹县人民政府办公室

关于转发县公安局等部门上犹县公共场所

安全防护设施建设实施方案的通知

各乡（镇）人民政府，县政府各部门，县属、驻县各单位：

县公安局、县住建局、县交运局、县应急管理局《上犹县公共场所安全防护设施建设实施方案》已经县政府研究同意，现转发给你们，请认真贯彻执行。

2019年7月2日

上犹县公共场所安全防护设施建设实施方案

县公安局 县住建局 县交运局 县应急管理局

为切实维护人民群众的生命财产安全，根据《江西省人民政府办公厅关于转发省公安厅等部门江西省公共场所安全防护设施建设意见的通知》(赣府厅字〔2018〕129号)和《赣州市人民政府办公室关于转发市公安局等部门赣州市公共场所安全防护实施建设实施方案的通知》(赣市府办字〔2019〕36号)文件要求，依据《城市道路交通设施设计规范》(GB50688-2011)、《城市道路交通标志和标线设置规范》(GB51038-2015)、《城市桥梁设计规苑》(CJJ11-2011)、《安全防范工程技术规范》(GB50348)等规范、标准，结合我县实际，制定本实施方案。

一、目标任务

在城市建设中同步规划、同步建设、同步使用公共场所安全防护设施，力争2019年内完成中心城区公共场所安全防护设施建设；2020年内完成全县公共场所安全防护设施建设，切实提升防范能力。

二、建设范围及标准要求

安全防护设施建设的重点目标和部位：

（一）党政机关、医院、学校门前及周边；

（二）中心广场、开放式休闲场所、繁华商业区、农贸市场等人员密集场所；

（三）码头、客运站等旅客出入口及周边；

（四）过江跨湖的城市桥梁、交通枢纽、高落差的临崖临水道路；

（五）城市公交站台、加油(气)站。

建设标准、要求:按照《江西省人民政府办公厅关于转发省公安厅等部门关于江西省公共场所安全防护设施建设意见的通知》(赣府厅字〔2018〕129号)和《赣州市人民政府办公室关于转发市公安局等部门赣州市公共场所安全防护实施建设实施方案的通知》(赣市府办字〔2019〕36号)文件要求执行。

三、责任分工

(一)党政机关门前及周边:由县机关事务管理局负责县行政中心安全防护设施建设；其他党政机关由所在单位负责安全防护设施建设。

(二)医院门前及周边:由县卫健委负责组织，各医院负责本医院及周边安全防护设施建设。

(三)学校门前及周边:由县教科体局负责组织，各学校幼儿园负责本校及周边安全防护设施建设。

(四)中心广场、开放式休闲场所等人员密集场所:由县城管局负责组织安全防护设施建设。

(五)繁华商业区、农贸市场等人员密集场所:大型商场、大型市场由县商务局负责组织安全防护设施建设；农贸市场由县城管局（市场管理中心）负责组织安全防护设施建设；其他繁华商业区按照“谁主管、谁负责”的原则组织建设。

(六)码头、客运站、公交站台等旅客出入口及周边:由县交运局负责组织安全防护设施建设。

(七)过江跨湖的桥梁、交通枢纽、高落差的临崖临水道路：结合交通安全工作分工，城区范围内的过江跨湖的城市桥梁由县城管局负责组织安全防护设施建设；城区范围之外过江跨湖的桥梁、交通枢纽、高落差的临崖临水道路，国省道由县公路管理局负责组织安全防护设施建设，农村公路由县交运局负责组织安全防护设施建设。

(八)加油站:由县商务局负责组织安全防护设施建设。

(九)加气站:由县住建局负责组织民用加气站安全防护设施建设。

(十)交通标志:由县公安局交管大队负责统筹规划建设。

(十一)交通标线、减速带:城区内由县公安局交管大队负责统筹规划建设；城区外道路由所属路权单位负责统筹规划建设。

(十二)公共场所安全防护设施建设经费:各有关(建设经营)责任单位和县财政部门按照原经费保障渠道解决。

四、实施步骤

(一)动员部署阶段(5月20日至6月14日）。县反恐办牵头召开工作协调部署会，制定《上犹县公共场所安全防护设施建设实施方案》。有关部门（单位）根据《实施方案》制定具体任务分工，建立工作机制。

(ニ)调查摸底阶段(6月15日至6月25日)。依据《江西省公共场所安全防护设施建设意见》和《赣州市公共场所安全防护实施建设实施方案》，各有关部门（单位）对所管辖公共场所安全防护设施建设情况进行摸底、统计、估算，摸清已建、拟建、在建以及需要新建、升级改造项目的底数和预算资金，并登记造册，于6月25日前报县反恐办。

(三)实施建设阶段(2019年7月至2020年12月）。按照“轻重缓急”原则分两步实施，第一步:2019年重点完成过江跨湖的城市桥梁、城区中心广场、城区中小学和幼儿园等重点公共场所安全防护设施建设；第二步:2020年完成全县公共场所安全防护设施建设。

(四)检查验收阶段(2019年12月、2020年12月)。2019年12月，按照“4+1联合督导、验收”模式，县公安局、县住建局、县交运局、县应急管理局会同各业务主管(监管)职能部门对2019年建设、升级改造的安全防护设施进行检查验收；2020年12月，对全县所有公共场所安全防护设施进行检查验收。

五、工作要求

(一)提高认识，加强领导。各有关单位要立足于应对复杂情况、强化底线思维、加强事前预防，成立由县公安局（县反恐办）、县住建局、县交运局、县应急管理局、县财政局、县教科体局、县卫健委、县城管局、县商务局、县机关事务管理局为成员单位的领导小组，办公室设在县公安局(县反恐办)，负责督促和指导有关单位建设责任落实和竣工验收，协调解决建设中遇到的困难和问题。各有关单位明确一名联络员于6月25日前报县公安局。

(二)统筹推进，分步实施。各有关单位要认真检视公共场所安全防护设施投入不足、覆盖范不全面、建设滞后等问题，对公共场所安全防护设施建设情况进行全面摸底，科学规划、统筹推进。要区分情况分步实施，对拟建、在建项目要同步建设安全防护设施；对没有安全防护设施的，要列出建设计划;对于设施老旧、不符合标准的，要予以更换和升级改造。

(三)明确责任，狠抓落实。按照“谁主管、谁负责，谁经营、谁负责”的原则，明确安全防护施建设、维护、监管工作责任。各有关部门要制定具体分工方案，细化分解任务，明确责任领导、责任人稳步推进建设工作，确保任务如期完成。

(四)完善制度，强化监管。建立问责问效制度，对于因设施建设不到位，未能有效防范驾车冲撞暴力极端侵害事件造成严重后果的，予以严肃问责。各有关部门每月10日前将工作开展情况书面材料（含工作文件、会议纪要等有关图文材料）报至县反恐办(联系人:黄祥贵；邮箱：635276550@qq.com；电话:[电话略])。县反恐办要加强统筹协调，会同县住建局、县交运局、县应急管理局适时对有关单位开展督导、抽查、暗访，及时将发现的重大问题通报有关单位。
