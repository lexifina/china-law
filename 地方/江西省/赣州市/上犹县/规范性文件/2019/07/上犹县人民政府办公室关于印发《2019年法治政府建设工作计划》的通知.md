# 上犹县人民政府办公室关于印发《2019年法治政府建设工作计划》的通知

各股、室：

《2019年法治政府建设工作计划》已经办公室主任会议研究，现印发给你们，请认真贯彻落实。

2019年7月12日

2019年法治政府建设工作计划

为深入推进依法行政，加快建设法治政府，坚持以习近平新时代中国特色社会主义思想为指导，紧扣县委、县政府工作大局，对标对表、补齐短板，着力整体提升办公室法治能力和依法行政水平，为全面推进我县“同城发展，绿色赶超”提供坚实的法治保障，现按照省、市、县有关文件精神，结合办公室工作实际，特制定本工作计划。

一、进一步压减行政许可事项。在承接落实好国务院、省、市已经取消、下放和调整行政审批事项基础上，对现有行政许可事项进行全面清理，由办公室政务服务管理股牵头组织各有关部门清理各类变相审批和许可，对部门变相设置审批的违规行为进行专项整治。

二、加快推进政务服务标准化建设。根据全县机构改革后部门“三定”方案职责规定，由办公室行政审批制度改革股督促有关部门全面梳理完善部门权责清单，做好行政权力责任清单、行政许可事项目录清单和行政审批中介服务事项目录清单动态调整工作，编制全省标准统一的行政权力事项目录清单，编制公共服务事项清单，并督促部门在门户网站或江西政务服务网及时更新动态信息。同步梳理各部门依申请事项清单，力争做到审批事项应减尽减。

三、大力推进政务服务事项网上办理。由办公室政务服务管理股牵头，按照上级部署统筹推进一体化在线政务服务平台建设，力争在2019年底前实现县级政务服务事项网上可办率不低于80%。不断拓展“互联网+政务服务”，推进“赣州通”平台建设及“一证通办”，12月底前完成“赣服通”上犹分厅建设，实现20个以上本地事项“掌上办理”。

四、全面推进政务公开。紧紧围绕“五型”政府建设和公众关切，加大公开解读回应力度，由办公室新闻信息股负责，以“公开为原则，不公开为例外”，将政府工作全面公开，打造透明政府，接受群众的监督。创新公开方式，善于使用新媒体手段，进一步发挥政务微博、微信、自媒体等社交网络和即时通讯工具的积极作用，善于用老百姓喜闻乐见的方式，灵活传递政务信息，增强政务公开的影响力和舆论引导力。

五、严格落实重大行政决策制度。进一步强化制度建设，明确领导职责、工作职责、决策机制、依法行政等，涉及人事任免、考核奖惩、财务预决算以及其他需要办公室领导班子集体决策的重大事项，由班子会议讨论和决定。

六、积极落实政府法律顾问制度。始终把完善法律顾问制度视为推进依法行政工作和加强自身建设的重要推动力量。充分发挥政府法律顾问的作用，提高其参与面，进一步提高依法行政系统决策能力、管理能力、服务能力和风险防范能力。

七、落实领导干部学法工作。采取集中学习与自学相结合的方式，坚持把抓好定期学法制度作为推进法治政府建设的关键。利用每周三“集中学习日”，由秘书股统筹安排，定期培训《中华人民共和国公务员法》、《政府信息公开条例》等内容，结合“不忘初心、牢记使命”主题教育，深入学习宣传党内法规，深入学习贯彻习近平新时代中国特色社会主义思想，切实增强领导干部依法行政的意识和能力，不断提高依法行政工作水平和自身法治素养。

八、突出“创建文明城市”相关法律法规政策宣传教育。围绕我县创建省级文明城市工作目标，以加强法治宣传教育工作为载体，推动全县法治环境创建工作。结合我办创文工作实际，在包干片区重点宣传涉及法治环境创建的政策、法律法规，为创建省级文明城市营造良好的法治环境。

九、大力开展法治文化活动。支持和引导法治文化作品的创作传播，结合精准扶贫工作在东山镇伏坳村和黄埠镇合溪村经常性地开展送法下乡活动，把法律送到农村和农村群众手中。继续组织参加全省“百万网民学法律”网络法律知识系列竞赛活动，扩大竞赛活动的参与度。

十、推进法治文化阵地建设。落实机关单位法治宣传文化窗建设，以法治文化为引领，深化“法律六进”活动，完善“法律六进”工作标准，建立健全长效机制，推动“法律六进”活动增强文化底蕴，形成浓厚的文化氛围。

十一、加强法治舆论宣传。结合法律法规颁布实施日、重大事件等时间节点，开展各项法律法规宣传活动（如“12·4”国家宪法日系列宣传活动）。充分利用电子显示屏、微信、微博等新媒体技术加强普法宣传，普及法律知识，传播法治精神，服务好法治上犹建设。

十二、加强法治宣传教育队伍建设。把建设一支高素质的法治宣传教育队伍作为落实我办“七五”普法规划的重要基础，着力推动普法讲师团、普法志愿者队伍建设，善借外脑外力推进普法工作。深入实施“七五”普法规划，推进农村“法律明白人”培养工程，确保为办公室所帮扶的贫困村每个村民小组至少培养1名“法律明白人”骨干。健全普法联络员制度，加强对法治宣传教育工作者的教育培训，提高新形势下做好法治宣传教育工作的能力。

各有关股（室）要强化法治政府建设工作的紧迫感和责任感，细化措施办法，及时研究解决法治政府建设工作中存在的重点、难点问题，切实提高行政效能，确保各项任务落到实处取得实效，推动办公室法治政府建设工作实现新发展。
