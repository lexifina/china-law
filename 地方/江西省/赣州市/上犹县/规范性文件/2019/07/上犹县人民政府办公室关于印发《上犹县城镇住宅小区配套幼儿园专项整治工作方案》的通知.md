# 上犹县人民政府办公室关于印发《上犹县城镇住宅小区配套幼儿园专项整治工作方案》的通知

各乡（镇）人民政府，县政府有关部门，县属、驻县有关单位： 《上犹县城镇住宅小区配套幼儿园专项整治工作方案》已经县政府研究同意，现印发给你们，请结合实际认真抓好贯彻落实。

2019年7月24日

上犹县城镇住宅小区配套幼儿园专项整治工作实施方案

为贯彻落实《中共中央、国务院关于学前教育深化改革规范发展的若干意见》，根据《江西省城镇小区配套幼儿园专项治理工作方案》和《赣州市城镇住宅小区配套幼儿园专项整治工作方案》等文件精神，为切实解决小区配套幼儿园应配建未配建、应移交未移交、应举办未举办等问题，结合我县实际，特制定本实施方案。 一、整治目标 凡是住宅小区规划已配套建成的幼儿园，原则上于2019年9月底前全部收回，一律办成公办幼儿园或普惠性民办幼儿园；凡是已规划幼儿园但还未配建的住宅小区，均需补建、改建或新建小区幼儿园，原则上于2019年12月底前完成相关建设规划，2020年12月底前完成项目竣工验收。 二、整治范围 整治范围为全县城镇住宅小区配套幼儿园。住宅小区配套幼儿园是指城区及重点城镇规划区范围内住宅小区（含政府投融资建设的保障性住房或安置房（含棚户区改造））按规划要求配套建设的幼儿园。教育行政管理部门外的其它政府机关和国有事业单位已举办的配套幼儿园，以及村民集体组织建设的配套幼儿园，不在本次收回整治范围之内。 三、工作任务和整治措施 （一）关于规划工作 规划部门在组织编制控制性详细规划时，要严格遵循《中华人民共和国城乡规划法》和《城市居住区规划设计标准》（GB50180－2018），老城区（棚户区）改造、新城开发和居住区建设、易地扶贫搬迁均应将配套建设幼儿园纳入公共管理和公共服务设施建设规划。要按照《幼儿园建设标准》（建标175-2016）的要求，单个小区1200户及以上的必须在小区配套建设幼儿园，1200户以下的小区或居民区采取统筹合建的方式配套建设幼儿园，原则上按每1200户建设一所规模不低于6个班的幼儿园。 1.未规划配套幼儿园的住宅小区 （1）对现有住宅小区已达到配建规模标准但没有规划配套幼儿园的，通过补建、改建、就近新建、置换、购置等方式予以解决，规划部门要在摸底排查的基础作出相关规划。 （2）对在建且达到配建规模标准但没有规划配套幼儿园的住宅小区，要及时制定补救措施，责令限期整改，按规划设计标准落实配建。 （3）对已规划配套幼儿园但规划不足的住宅小区，要通过依法调整规划、扩增配建幼儿园规模予以解决。 （4）对规模未达到配建幼儿园标准的住宅小区，要结合学前教育整体规划布局，在周边区域统筹安排配建公办园或普惠性民办园，满足适龄儿童入园需求。 （牵头单位：县自然资源局，责任单位：县住建局、县教科体局） 2.已规划配套幼儿园但建设不到位的住宅小区 （1）对有完整配建规划但未按要求开工建设的，对开发建设单位进行约谈，并责令限期按标准完成配套幼儿园建设。如项目尚未全部开发完毕，开发单位须在本方案发布之日起启动配套幼儿园建设，并在2020年12月底之前竣工验收。相关职能部门在办理开发单位后续开发项目总图审批、建筑单体审查、初步设计审查、国土指标核算前，应征求县教育部门有关配套幼儿园建设情况的审查意见。如项目全部开发完毕，但开发单位在我县有新开发项目的，参照项目尚未全部开发完毕的办法办理；如项目全部开发完毕，但开发单位无法继续配建幼儿园，由县自然资源局、住建局等主管部门按照有关规定，依法进行处理。 （2）对不按规划方案建设，缩减建设规模的，督促开发建设单位通过改扩建、补建等方式予以解决；对在幼儿园建设用地上进行其他项目建设的，依法依规予以处置。 （3）对已建成但尚未竣工验收或目前在建的住宅小区，如配套幼儿园建设存在不建、缓建、缩建、停建和建而不交等问题的，不得办理项目竣工验收。 （4）城镇住宅小区配套幼儿园属于公共服务设施，未经批准，不得擅自拆改或闲置，严禁出租、出售、转让、抵押等方式改变用途，对已挪作他用的要采取有效措施予以收回。 （5）对违反规划要求和建设条件，且不按时落实整改要求的开发建设单位，相关部门要将其纳入黑名单，依法依规实施联合惩戒。 （牵头单位：县住建局，责任单位：县自然资源局、县教科体局） （二）关于移交工作 （1）凡政府投融资建设的保障性住房或安置房(含棚户区改造)小区配套幼儿园及其它产权系政府所有的小区配套幼儿园，均须于2019年6月底前办理完移交手续，无偿移交县教科体局。若已出租，在租赁期内，由产权所有单位办成公办性质的幼儿园，待租赁期满后，无偿移交县教科体局。 （2）凡土地招拍挂时明确需配建公办幼儿园或建设时免收开发建设单位配套幼儿园土地出让金的小区配套幼儿园，均须无偿移交县教科体局。 （牵头单位：县教科体局，责任单位：县财政局、县自然资源局、县住建局、县城投公司） （三）关于举办工作 1.规范小区配套幼儿园使用。小区配套幼儿园移交县教科体局后，由县教科体局根据县域学前教育布局规划优先办成公办园或委托办成普惠性民办园，不得办成营利性幼儿园。在全县公办幼儿占比达到50%以前，需将2018年4月以后建设的城镇小区配套幼儿园移交办成公办园。办成公办园的，由县编制部门按程序做好事业单位法人登记和教师配备等工作；委托办成普惠性民办园的，县教科体局做好对相关机构资质、管理能力、卫生安全及保教质量等方面的审核工作，签订的委托举办协议有效期原则上不得超过10年，并要约定收费价格。同时，县民政局要完善相关登记手续，县财政局要明确补助标准。 2.配套幼儿园应与配套小区同步投入使用。对已交未用的，由县教科体局负责在2019年9月投入使用。对已出租或已出让的配套幼儿园，收回后可优先由原承租方或受让方在原合同约定期限内继续举办，但须按照普惠性质办园，并与县教科体局签订委托办园协议。 （牵头单位：县教科体局，责任单位：县财政局、县编办、县人社局、县民政局） 三、整治步骤 城镇住宅小区配套幼儿园专项整治工作分为三个阶段进行： 第一阶段：部门联动，全面摸排。 对全县范围内小区按照相关标准进行摸底排查，分两个步骤进行：一是由县自然资源局、县住建局负责梳理所有楼盘规划、竣工验收、办证、档案等环节，建好台账。二是由县教科体局负责根据台账情况进行现场核实。对规划、配建、移交、使用不到位等情况，分别列出清单、建立台帐。 牵头单位：县教科体局 配合单位：县自然资源局、住建局 完成时限：2019年 5月底前 第二阶段：分类整治，按期移交 按照“一事一议”“一园一案”的原则，制定针对性整治措施，逐一进行整治。 1.已经建成、需办理移交手续的小区配套幼儿园。 牵头单位：县住建局 配合单位：县财政局、教科体局、城投公司。 完成时限：2019年7月底前 2.需要回收、置换、购置的配套幼儿园。 牵头单位：县住建局 配合单位：县财政局、教科体局、城投公司。 完成时限：2019年9月底前 3.需补建、改建、新建的小区配套幼儿园。 牵头单位：县住建局 配合单位：县发改委、自然资源局、财政局、教科体局、城投公司。 完成时限：2019年12月底前完成相关建设规划，2020年12月底前完成项目竣工验收。 4.收回后举办成公办或民办普惠性幼儿园。 牵头单位：县教科体局 配合单位：县财政局、编办、人社局、住建局 第三阶段：总结上报，建立机制 对小区配套幼儿园整改工作进行全面总结，整理相关档案资料，按期上报。制定完善我县城镇住宅小区幼儿园规划建设和管理办法，建立部门联动长效机制。 牵头单位：县教科体局 配合单位：所有成员单位 完成时限：2020年12月底。 四、工作要求 （一）加强领导，建立协调机制。成立由县政府分管教育工作副县长任组长，县教科体局、县住建局、县自然资源局、县财政局、县发改委、县编办、县人社局、县公安局、县消防救援大队、县司法局、县税务局、县城投公司、县供电公司、各乡（镇）政府负责人为成员的城镇住宅小区配套幼儿园专项整治工作领导小组。领导小组办公室设在县教科体局，由县教科体局主要负责人兼任办公室主任，县住建局、县自然资源局分管负责人兼任办公室副主任，负责统筹协调城镇住宅小区配套幼儿园专项整治工作。 （二）明确分工，部门通力合作。各部门要按照职责分工以及小区配套幼儿园规划、设计、建设、验收、移交、登记等各个环节的工作要求，联合集中办公，形成工作合力，切实把摸底排查、全面整改、专项督查等各项工作落到实处。（部门具体职责详见附件）。 （三）强化措施，开辟绿色通道。收回的配套幼儿园，税费按照相关法律法规、政策规定的优惠政策执行；在用水用电用气方面，按居民用水用电用气价格收费；在物业管理上作为自管物业；在产权登记方面，县教科体局提交与开发单位签订的移交确认书和产权登记申请报告后，不动产权登记部门在15日内将配套幼儿园登记在县教科体局名下；在组织机构和编制方面，县编制部门要及时办理公办幼儿园统一社会信用代码证。 （四）加强宣传，及时报送情况。加大专项治理工作的宣传力度，积极通过网络、电视、广播、报纸等多种媒体，及时宣传治理工作开展情况，定期公布整改成效，形成有利于推进城镇小区配套幼儿园治理工作的舆论氛围。 （五）强化保障，加大监督管理。畅通群众反映意见渠道，设立并公布监督举报电话和信箱，对没有依规依标配建并移交造成学前教育资源严重不足或配套建设幼儿园资源流失的失职渎职行为和违法违纪案件，依法依规严肃追究责任；对城镇住宅小区配套幼儿园情况瞒报漏报的，严肃追究相关人员责任。 附件：上犹县城镇住宅小区配套幼儿园专项整治工作领导小组成员单位职责分工。 附件 上犹县城镇住宅小区配套幼儿园专项整治 工作领导小组成员单位职责分工 一、县住建局：负责全县城镇小区配套幼儿园摸底排查工作；加强对城镇小区配套幼儿园的建筑设计、施工建设、验收、移交的监管落实；协调做好全县住宅小区配套幼儿园的收回和移交工作；指导和督促各相关部门做好住宅小区配套幼儿园的回收、移交和补建等工作。 二、县教科体局：配合做好全县城镇小区配套幼儿园摸底排查以及幼儿园规划、建设、验收、移交等各环节工作；与开发单位签订移交确认书，向产权登记部门申请产权登记等；已移交的幼儿园开办工作。 三、县自然资源局：负责核实全县住宅小区配套幼儿园规划及用地情况，具体包括配建幼儿园开发小区名单、配套幼儿园具体位置、用地面积、建筑面积、土地取得方式等；负责督促未建设的配套幼儿园与首期住宅同步规划建设、同步登记，收回已建成配套幼儿园土地使用权并重新办理划拨用地手续。协调做好全县住宅小区配套幼儿园的收回和移交工作；指导和督促各相关部门做好住宅小区配套幼儿园回收、移交和补建等工作。 四、县财政局：负责核查国有资产中的幼儿园房产，并督促相关部门做好属国有资产的幼儿园房产移交、回收等工作；指导和督促各相关部门做好住宅小区配套幼儿园回收工作。 五、县卫健委：负责督促配套幼儿园与同期住宅同步进行卫生健康验收。 六、县城投公司：配合做好代建项目中已建成小区配套幼儿园的移交工作；做好在建返迁房配套幼儿园的规划、设计和施工，补足配齐返迁房配套幼儿园。 七、县发改委：参与小区配套幼儿园项目规划布局，对需补建、改建、新建的项目按程序及时办理审批、核准或备案手续。 八、县消防救援大队：负责对小区配套幼儿园和同期住宅同步进行消防验收。 九、县编办：按程序做好小区配套幼儿园移交涉及的机构编制工作；根据办园性质，依法办理事业单位法人登记，核定教师编制，办理公办幼儿园统一社会信用代码证。 十、县人社局：做好公办幼儿园人员的社会保险基金的安全监管、工资审核与分配、福利和津补贴管理、人事制度改革、人员离退休政策以及劳动、人事争议调解仲裁等与本部门相关的各项工作，确保幼儿园正常运转。 十一、县司法局：负责指导依法收回小区配套幼儿园工作。 十二、县税务局：负责办理税收征免手续，落实相关税收优惠政策。 十三、县供电公司：负责支持配套幼儿园移交后实行独立用电。 上犹县人民政府办公室 2019年7月24日印发
