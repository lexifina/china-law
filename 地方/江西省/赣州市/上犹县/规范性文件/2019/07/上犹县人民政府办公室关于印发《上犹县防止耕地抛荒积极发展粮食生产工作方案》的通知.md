# 上犹县人民政府办公室关于印发《上犹县防止耕地抛荒积极发展粮食生产工作方案》的通知

各乡（镇）人民政府，县政府有关部门：

为切实加强耕地保护，防止耕地抛荒，进一步夯实粮食生产基础，确保全年粮食生产稳定，现将《上犹县防止耕地抛荒积极发展粮食生产工作方案》印发给你们，请结合工作实际，抓好目标任务落实，确保完成全年秋粮扩种任务。

2019年7月2日

上犹县防止耕地抛荒积极发展粮食生产工作方案

为切实加强耕地保护，坚守耕地红线，防止耕地抛荒，稳定我县粮食生产，根据《江西省人民政府办公厅关于切实抓好秋粮生产确保全年粮食生产稳定的通知》（赣府厅明〔2019〕50号）、《江西省农业农村厅、江西省财政厅的通知》（赣农字〔2019〕42号）等文件精神和农业农村厅厅长胡汉平同志在全省防止耕地抛荒稳定发展粮食生产视频会议上的讲话精神，结合我县实际，特制定本工作方案。

一、指导思想

全面贯彻落实党的十九大精神和中央、省委一号文件精神，以习近平总书记视察江西重要讲话精神为统领，坚守“谷物基本自给、口粮绝对安全”底线，深入实施“藏粮于地、藏粮于技”战略，切实加强耕地保护，坚决守住耕地红线，确保耕地不抛荒，大力提高耕地质量，夯实粮食生产基础，发挥粮食生产优势，坚持绿色优质导向，进一步巩固粮食主产区地位，不断增加绿色优质粮食供给。

二、基本原则

（一）坚持口粮为主。始终坚持优势区域种植优质品种的原则，对于灌溉条件和水源较好区域，不遗余力种水稻，确保宜种尽种；对于易旱易涝区域，或已出现因灌溉不便、水源不足而抛荒耕地，积极发展节水抗旱水稻、玉米或红薯等粮食作物，作为水稻生产的有效补充。

（二）坚持规模推进。各乡（镇）要根据实际情况，针对已出现抛荒的耕地，或今年没有种植计划的耕地，规范有序开展耕地集中流转，或以代耕代种形式，将分散的耕地统一发包到大户种植，形成规模种植效益。

（三）坚持订单种植。加强产销衔接，以销定产，确保能种能收。选择优质高产品种，组织种植户与加工企业对接，推进订单种植和收购。对未与加工企业签订订单的节水抗旱水稻种植户，提前做好与政策性粮食收购库点对接，在启动托市收购后，确保节水抗旱水稻按政策价格敞开收购。

（四）坚持农民自愿。始终坚持以农民为主体，充分尊重农民意愿，不搞强迫命令。通过降低耕地田租、产销对接、适当扶持等方式，提高粮食种植效益。探索建立防止耕地抛荒的政策框架，激发农民发展粮食的积极性。

三、目标任务

面积目标：11100亩。其中节水抗旱稻500亩，玉米600亩，红薯10000亩。

四、耕地范围和补贴标准

（一）耕地范围：一年以上（含一年）未种或当年没有种植计划的耕地，或有一定灌溉条件和水源但又不能满足水稻稳产要求的旱地。同时，在中稻种植适宜地区积极推广再生稻种植。

（二）补贴标准：按照“谁种植、补贴谁”的原则，按112元/亩进行补贴，重点用于购买种子、化肥等生产性资料补贴，以及开展耕种收服务和种植区域四至信息填报等补贴。

六、保障措施

（一）加强组织领导。成立县防止耕地抛荒积极发展粮食生产工作领导小组，由县政府分管领导为组长，县财政局、县农业农村局和各乡（镇）主要负责同志为成员。各乡（镇）要强化组织领导，细分工作、严格把关，确保防止耕地抛荒发展粮食生产工作落到实处。

（二）加强技术指导。成立县防止耕地抛荒积极发展粮食生产技术专家组，由农技站、土肥站、植保站和种子站等相关技术人员组成，组织开展有针对性的技术指导服务。各乡镇要紧密与专家组对接、加强沟通，抓好技术到户到田，依靠科技提高单产水平。

（三）紧扣时间节点。6月15日前，完成节水抗旱稻、玉米、红薯等播种面积落实；7-9月开展田间技术指导，加强田间管理确保稳产高产；9-11月份，开展面积和产量调查；11月，进行总结评估。

（四）做好调查统计。适时开展工作督导，推动资金、技术、生产服务等措施落实，确保完成目标任务。配合江西调查总队开展面积和产量统计，通过卫星遥感技术、无人机调查等方式实时跟踪节水抗旱水稻、玉米和红薯等种植，对种植面积和产量进行调查统计，各乡镇要密切配合，确保工作顺利进行。

（五）强化考核激励。将防止耕地抛荒发展粮食生产列入年度农业农村工作考核，对未完成粮食目标面积和产量的乡（镇），将按考核要求进行问责。
