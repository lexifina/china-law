# 上犹县人民政府办公室关于印发《上犹县“十四五”规划编制工作方案》的通知

各乡（镇）人民政府，县政府有关部门，县属、驻县有关单位：

《上犹县“十四五”规划编制工作方案》已经县政府研究同意，现印发给你们，请认真贯彻执行。

2019年8月2日

上犹县“十四五”规划编制工作方案

“十四五”规划是我国开启全面建设社会主义现代化国家新征程的第一个五年规划，也是我县全面建成小康社会之后、着力建设革命老区高质量发展示范区承上启下的五年规划。为贯彻落实省、市“十四五”规划编制工作要求，高质量做好我县“十四五”规划编制工作，特制定本工作方案。

一、指导思想和编制原则

（一）指导思想

坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻党的十九大和十九届二中、三中全会精神，全面贯彻落实习近平总书记视察江西和赣州时的重要讲话精神，坚持稳中求进工作总基调，坚持新发展理念，坚持高质量跨越式发展首要战略，坚持以供给侧结构性改革为主线，把握时代特征，强化战略思维，统一规划体系，提高规划质量，更好发挥发展规划的战略导向作用，为着力实施“同城发展、绿色赶超”主战略，推动全县高质量跨越式发展提供可靠的规划保障和科学的政策指引。

（二）编制原则

1.坚持上位要求与下位需求相衔接。要围绕全面建设社会主义现代化国家的目标要求，准确把握发展阶段特征，加强对未来五年甚至更长远的发展谋划，增强规划宏观性、战略性、指导性。同时，要立足“同城发展、绿色赶超”主战略，突出规划的针对性和可操作性，确保提出的目标和举措能够顺应发展趋势、引领发展方向。

2.坚持全面规划和突出重点相协调。既要全面统筹经济社会各领域各方面，推动全县整体发展，又要适应所处发展阶段的特殊需求，突出重点领域和薄弱环节，整合资源，集中攻关。

3.坚持目标导向与问题导向相统一。围绕全面建设社会主义现代化国家的目标要求，真正明晰并严格执行工作路线图、时间表和任务书，又聚焦经济社会发展的突出矛盾和重大问题，明确破解难题的途径和方法，不断地解决前进中遇到的各种困难和问题，在不断克服困难、解决问题中向着既定目标迈进。

4.坚持政府主导与社会参与相结合。既要发挥好政府部门编制规划的主导作用，又要坚持开门编制规划，充分听取和吸纳社会公众、专家学者、代表委员等各方面的意见建议，增强规划编制的科学性、民主性，提高规划工作的透明度和社会参与度。

二、主要任务和责任分工

围绕建立全县“十四五”规划体系，协调组织和统筹推进县发展规划（国民经济和社会发展规划纲要）、专项规划、国土空间规划编制工作。

（一）编制总体规划。即上犹县国民经济和社会发展“十四五”规划纲要，重点明确全县“十四五”时期国民经济和社会发展的指导思想、发展目标、主要任务、发展重点和政策措施。总体规划是编制本级和下级各类规划以及制定有关政策和年度计划的重要依据，其它规划必须符合总体规划的要求。〔县发改委牵头，各乡（镇）人民政府、县政府有关部门配合〕

（二）编制专项规划。围绕细化和落实总体规划对特定领域提出的战略任务，在关系国民经济和社会发展全局且需要政府发挥作用的市场失灵领域编制一批县级“十四五”专项规划，作为审批核准重大项目、安排政府投资和财政支出预算的重要依据。县发改委会同县政府有关部门研究提出编制目录清单（待国家、省、市编制目录清单确定后研究提出），报县政府审定后实施。在编或已出台的规划期到“十四五”末的专项规划，可作为“十四五”专项规划的组成部分。县政府有关部门根据需要，在总体规划和专项规划基础上编制的行业规划，报县发改委备案。〔县相关部门负责，县发改委综合协调〕

（三）编制国土空间规划。县级国土空间规划以全县空间治理和空间结构优化为主要内容，细化落实市总体规划提出的国土空间开发保护要求，聚焦空间开发强度管控和主要控制线落地，并以此为载体统筹协调各类空间管控手段。县自然资源局会同县发改委研究提出编制目录清单，报县政府审定后实施。〔县自然资源局牵头，各乡（镇）人民政府、县政府有关部门配合〕

三、工作阶段和时间安排

参照国家、省和市的总体安排，县总体规划编制工作分为前期研究、形成纲要框架、起草和征求意见、论证报批四个阶段。

（一）前期研究阶段（2019年7月至2020年2月）

1.开展课题研究。由县“十四五”规划编制工作领导小组组织对事关经济社会发展的全局性、前瞻性、关键性、深层次重大问题进行深入研究、集中攻关。县政府有关部门应结合基本思路研究和专项规划、国土空间规划编制，另行组织开展课题研究。

2.提出重大事项。县政府有关部门和各乡（镇）研究提出纳入国家、省、市、县“十四五”规划基本思路的重点内容，由县发改委汇总，并衔接好市发改委。

3.起草规划基本思路。各乡（镇）和县政府各部门从本地、本行业、本领域实际出发，就“十四五”时期重大目标、重大任务、重大项目和重大政策等开展调研，研究提出本地、本行业（领域）“十四五”规划基本思路，2019年11月上旬报县发改委。县发改委汇总并与市里衔接后，研究提出我县“十四五”规划基本思路。

（二）形成纲要框架阶段（2020年3月至县委“十四五”规划建议出台前）

1.开展建言献策。通过县内主流新闻媒体开设活动专栏等方式开展建言献策活动，征询社会公众意见建议。

2.研究论证重大工程项目。围绕补短板、强弱项、提质量，县政府有关部门研究提出一批新时代重大标志性工程和重点民生项目。

3.起草县“十四五”规划纲要框架。在规划基本思路的基础上，研究起草“十四五”规划纲要框架。

（三）起草和征求意见阶段（县委“十四五”规划建议出台后至2020年12月）

1.起草纲要草案。根据县委“十四五”规划建议，对纲要框架进行完善充实，形成规划纲要草案。

2.征求各乡（镇）、县直各部门（单位）意见。全面广泛征求各乡（镇）、县直各部门（单位）意见建议。

3. 征询人大代表、政协委员意见。广泛征求各阶层人大代表、各界别政协委员意见。

4.修改完善。充分吸纳各方面意见，并与国家、省和市规划纲要草案衔接后，对规划纲要进行修改完善。

（四）论证报批阶段（2020年12月至2021年全县“两会”召开）

1.组织专家开展咨询论证。召开县“十四五”规划咨询委员会会议，对规划纲要草案进行论证。

2.报请县委、县政府研究审议全县“十四五”规划纲要草案。

3.按照县委、县政府审议意见修改完善后，经与市发改委衔接，提请县人大审议规划纲要草案。

县“十四五”专项规划、国土空间规划原则上与规划纲要同步部署、同步研究、同步编制，2021年6月前全部出台。

四、保障措施

（一）加强组织领导。县政府成立上犹县“十四五”规划编制工作领导小组，由县政府县长任组长，县政府常务副县长任常务副组长，县政府办主任和县发改委主任任副组长，各乡（镇）政府主要负责同志、县直有关部门主要负责同志为成员。领导小组办公室设在县发改委（办公室主任由县发改委主任兼任），具体负责领导小组的日常工作。

（二）明确责任分工。县“十四五”规划编制工作领导小组负责统筹协调推进“十四五”规划编制工作，研究确定重大事项。规划领导小组办公室具体负责总体规划编制工作，统筹专项规划编制工作。县直有关部门是县级专项规划、国土空间规划编制的责任主体，在规划编制过程中，要细化落实县总体规划对重点领域和空间治理发展战略、重点任务、重大举措等要求，切实强化专项规划的支撑作用和国土空间规划的基础作用。各部门要制定相应的规划编制工作实施方案，落实工作机构、工作人员，组织配备知识结构合理、业务水平高、责任心强的规划编制队伍。

（三）组建专家队伍。由县“十四五”规划编制工作领导小组办公室牵头组织，邀请县内外知名专家、学者组成全县“十四五”规划咨询委员会，为规划编制提供咨询、论证等智力支持。要注重发挥在我县挂职领导的作用，为我县“十四五”重大项目、重大政策研究论证和争取，重大课题研究和规划编制等发挥积极作用。

（四）落实规划经费。县“十四五”规划（含专项规划、国土空间规划）编制和课题研究等工作所需经费，由规划领导小组办公室统筹安排；各部门自行编制的规划经费在各部门预算经费中统筹安排。
