# 关于做好当前消防安全工作的通知

各乡（镇）人民政府，县政府有关部门，县属、驻县有关单位：

根据市政府办《关于进一步加强当前火灾防控工作的通知》（赣市府办字〔2019〕51号）文件精神，全市范围内将开展为期3个月的消防安全专项治理。为贯彻落实文件精神，全面消除火灾防控盲区，实现消防监管全覆盖，有效防范和坚决遏制亡人火灾事故发生，结合当前正值季节交替、天干物燥的特点，现就我县做好当前消防安全工作通知如下：

一、全面落实消防安全监管，广泛开展消防安全宣传

各乡（镇）、各有关部门（单位）要根据《消防安全责任制实施办法》和《江西省消防条例》等有关规定，严格落实消防安全监管责任，深入开展消防安全隐患排查，重点查处使用易燃可燃材料装修、防火分隔不到位、疏散通道不畅通、存放易燃易爆品、电动自行车违规停放充电等突出隐患。要充分用好每日消防“巡更”、车载喇叭、微博微信等方式扎实开展消防安全知识宣传，并广泛发动政府专职消防、村居委会、派出所等基层网格力量，以走街串巷、进店入户、上门入户、进村入户等形式深入到群众中宣传消防安全知识。

各乡（镇）要按照“属地管理”原则，组织乡（镇）干部、网格员和村（居）工作人员，上街入户开展消防安全检查及消防宣传。特别是要针对制衣小作坊等失控漏管区域，组织联合排查整治，凡不符合要求的场所一律依法关停。

各行业主管部门要履行对各自行业领域的监管职责，扎实开展消防安全隐患排查整治。

县消防救援大队要履行对二级消防安全重点单位的监管职责，并指导各乡（镇）和有关部门开展消防监督检查工作。

各公安派出所要履行对三级消防安全重点单位、“九小场所”、群租房的监管职责，要对居民住宅区的物业服务企业进行日常消防监督检查和公共区域消防设施维护管理进行检查。

二、严格落实安全防控措施，切实整改消防安全隐患

各乡(镇)、各有关部门（单位）要因地制宜、因情施策，严格落实消防安全防控措施，切实推动消防安全隐患整改，特别是要将清理违规住人、全面推行安装NB-IoT智能独立烟感、配备灭火器、打通逃生通道、开展实操实训等“五项硬举措”贯穿到火灾隐患排查整治的始终。同时，要充分用好信用惩戒、约谈警示、挂牌督办、媒体曝光、社会公示、通报函告、依法惩处等手段，强力推进火灾隐患整改和消防安全举措落实。一要督促家具制衣等行业认真落实“1241”防控措施，即：建立一个微型消防站，开展违规住人和车间粉尘“两项清理”，落实配备一台机动泵、建设一个蓄水池、配备一定数量的灭火器材、开展一次电气线路改造“四项措施”，组织一次全员培训。二要督促合用场所认真落实“4+1” 防控措施，即：物理隔断、打通逃生通道、安装NB-IoT智能独立烟感和简易喷淋、配备灭火器以及开展一次全员培训。三要督促沿街店面和住宅小区认真落实“3+1”防控措施，即：发放一份消防宣传资料、配备两具以上灭火器、安装NB-IoT智能独立烟感以及开展一次实操实训。

三、牢固夯实消防安全基础，健全消防安全长效机制

各乡（镇）要加大乡（镇）政府专职消防队建设支持力度，配齐配强专职人员和救援装备。各有关部门（单位）要督促分管行业单位配齐灭火器材装备、建立微型消防站，强化自身应急处置能力。县消防救援大队要强化值班备勤、熟悉演练和实战练兵力度，加强对乡（镇）政府专职消防队、城区小型消防站的督促指导，确保消防救援队伍随时拉得出、冲得上、打得赢；要持续推进“一警六员”实操实训，组织开展现场实战演练，切实提升群众“见火不慌、抬手就打”的能力。县政府督查室将适时联合有关部门（单位）对各项工作落实情况开展督查，并将督查情况进行通报。对因消防安全责任不落实、火灾防控措施不到位，致使发生有影响和亡人火灾事故的，依法依规追究有关人员责任；发生较大以上火灾事故的，依法从严追究火灾事故责任人和有关单位责任。
