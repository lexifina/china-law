# 关于做好村级光伏扶贫电站收益管理和分配工作的通知

各乡（镇）人民政府，县政府有关部门，县属、驻县有关单位：

根据《村级光伏扶贫电站收益分配管理办法》（国开办发〔2017〕61号）和《上犹县村级光伏扶贫电站收益分配管理办法》（上府办发〔2018〕90号）等文件精神，为进一步明确村级光伏扶贫电站收益的拨付与分配工作，提高村级光伏扶贫电站带贫益贫效果，现就有关事项通知如下：

一、进一步规范上网电费和发电补贴的拨付管理

村级光伏扶贫电站收益包括上网电费和发电补贴两部分，由县供电公司、县优能置业有限公司和相关乡（镇）分工负责做好资金拨付工作。其中：

1.上网电费。由县供电公司按月拨付各个村级光伏扶贫电站的上网电费，并同步向所在乡（镇）提供上网电费清单；乡（镇）人民政府应及时将上网电费清单提供给相关村委会，并督促指导村委会核对发电量，做好资金入账等账务工作。

2.发电补贴。县供电公司应积极协调市供电公司将发电补贴拨至县优能置业有限公司，并及时提供各个村级光伏扶贫电站发电补贴明细表。县优能置业有限公司在收到发电补贴的7个工作日内，根据发电补贴明细表分拨至各个村的对应账户，并同步通知所在乡（镇）人民政府查收。各相关乡（镇）人民政府应及时将发电补贴明细表提供给相关村委会，并督促指导村委会做好资金核对入账等账务工作。

二、进一步加强村级光伏扶贫电站收益分配管理

1.统建电站收益。万油年、中稍、花园等光伏扶贫电站收益（包括上网电费和发电补贴），在优先满足本村大病、大灾、失能、弱能等兜底保障贫困群众的资产收益后，各村可按照带贫益贫的原则，统筹安排用于本村急需解决或群众反映强烈的道路、水利、环境整治、产业发展等扶贫项目建设。对计划安排的扶贫项目，各乡（镇）及相关村要严格按照《上犹县财政扶贫和移民资金使用管理办法》（上精扶字〔2016〕44号）文件要求，逐级申报和审批后实施。

2.自建电站收益。各村在本村自建的光伏扶贫电站的收益使用范围按《上犹县村级光伏扶贫电站收益分配管理办法》（上府办发〔2018〕90号）第五条执行。

三、进一步明确村级光伏扶贫电站运维管理

1.运维责任。县优能置业有限公司负责全县所有村级光伏扶贫电站的运维管理和信息监测，及时组织专业人员清除电站运行故障，确保电站运行正常。各乡（镇）要加强对辖区内村级光伏扶贫电站的日常监管，明确分管领导和具体负责人员，各村要指定具体负责人员做好在本村建成的光伏扶贫电站的日常运维，及时发现和排除发电异常及不安全隐患，确保正常发电。

2.运维费用。县优能置业有限公司按财编〔2019〕222号审核意见明确的标准（0.06元/度电），计提基本运维费用，先从中稍光伏扶贫电站的发电收益中列支；遇有大额支出的基础设施建设费用或设备更换费用，按照“一事一议”原则报县政府审批后实施。
