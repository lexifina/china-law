# 关于切实做好今年早稻收购工作的通知

各乡（镇）人民政府，县政府有关部门，县属、驻县有关单位:

根据全省2020年早稻收购工作电视电话会议精神及省发改委、省粮食和物资储备局、省财政厅、省农业农村厅、中储粮江西分公司、农发行江西分行《关于切实做好2020年早稻收购工作的通知》(赣发改粮食〔2020〕541号)要求，为切实抓好今年我县早稻收购工作，现就有关事项通知如下:

一、充分认识做好今年早稻收购工作的重要意义

今年在疫情防控常态化背景下，抓好今年早稻收购工作，对于保护农民种粮积极性、保持粮食市场平稳运行、促进经济社会稳定发展具有特殊重要意义。同时，也是严格落实粮食安全省长责任制，做好“六稳”工作、落实“六保”任务，推动我县粮食产业经济健康可持续发展的具体要求。全县各乡（镇）、有关部门，要切实提高政治站位，认真落实国家粮食收购政策，牢牢守住不出现农民“卖粮难”的底线，坚决扛稳我县粮食安全重任。

二、及时启动政策性粮食收购，严格执行国家粮食收购政策

按照国家发展改革委等部门联合印发的《小麦和稻谷最低价执行预案》(国粮发〔2018〕99号)、《关于完善稻谷最低收购价有关政策的通知》(国粮粮〔2020〕41号)和《关于切实做好2020年夏季粮油收购工作的通知》(国粮粮〔2020〕107号)要求，明确政策主要内容。

1.早稻最低价收购执行起止时间:经中储粮集团江西分公司等批准后，由县粮食流通中心及时通知各乡（镇）。

2.早稻最低价粮收购的库点:县粮食储备库（油石塘角村）。

3.早稻最低价粮收购价格(到库价) : 121 元/50公斤。

4.早稻最低价粮收购的等级标准和质量要求。按国家规定的三等粮质量标准执行，即:早稻收购水份小于或等于13.5%、杂质小于或等于1%、黄粒米小于或等于1%、出糙率大于或等于75%。既不得随意放宽收购标准，收购不符合质量标准的粮食；也不得拒收农民交售达标粮食，切实维护政策性粮食收购的严肃性。

5.严格按照国家最低收购价政策。执行政策到位，不打折扣，应收尽收、确保不发生“卖粮难”现象。

三、大力拓宽市场销售渠道，提高种粮农户效益

各乡（镇）要积极引导种粮农户，特别是种植大户、农业合作社拓宽市场销售路子，实现早稻增产增效。 一是要帮助引导种粮农户将收获的原粮(稻谷)，通过就地加工转化实现好的种粮经济效益。二是深化产销合作，通过粮食加工企业、粮食经营企业或粮食经纪人，将粮食销售到广东、福建等市场需求量大的区域，提高销售价格，增加种粮效益。三是通过农户自产自销方式增加早稻的经济效益。县粮食流通等部门要充分调动粮食加工企业等收购多元主体积极性,多措并举组织好市场化粮食收购，充分尊重种粮农户的售粮意向，使种粮农户实现好的粮食经济效益。

四、加强粮食产后服务，切实提高为农服务水平

各乡(镇)、有关部门要认真履职尽责，进一步增强为农服务意识，创新为农服务举措，提高为农服务水平。一是县农业农村局、县粮食流通服务中心以及下属所、站、库(点)要深入村、组指导农户做好新粮的整理、晾晒，宣传家庭储粮知识，促进粮食提级进档。二是县粮食产后服务中心、各乡(镇)要积极发挥作用，为农户提供早稻杂质清理、湿谷烘干等服务，切实帮助本地种粮农户解决实际问题。三是粮食部门要抓好优质服务，有序收购。收购库（点）要有休息场所、防暑药品和茶水等。四是积极做好粮食市场信息服务。各乡(镇)、有关部门要充分利用好信息平台，主动发布早稻收购数量进度和市场价格信息，完成好统计工作任务，为种粮农民售粮和粮食经营企业提供信息服务。五是各收购库(点)要做到“价格上榜、 标准上墙、样品上台”，让农户售“明白粮”“放心粮”。同时，还要充分利用中储粮预约收购APP、省粮食和储备局“赣粮通”平台，提升粮食购销自助化、便捷化水平。

五、加强收购工作监督检查，维护好正常的收购秩序

有关部门要各司其职，进一步加强我县早稻收购工作的监督检查，维护好正常的收购秩序。督促粮食收购企业严格遵守国家粮食收购政策和“五要五不要”守则。粮食、市场监管等部门要推行“双随机、一公开”抽查方式，加强明查暗访，发挥媒体监督和12325全国粮食流通监管热线作用，坚决查处“克扣斤两”“压级压价”“打白条”等损害农民利益和“以次充好”“先收后转”“转圈粮”等损害国家利益的违法违规行为。要强化粮食收购工作各环节的安全生产主体责任，维护好粮食收购现场秩序，坚决防范重特大事故发生，确保人民群众生命和财产安全。对工作落实不力，造成不良社会影响的单位和个人要严肃追责。要加强舆情监测与分析，主动及时回应社会和媒体关切，积极做好处置工作和化解风险，为今年早稻收购工作营造良好的社会氛围。

六、加强粮食收购工作的组织领导，明确部门责任

成立上犹县粮食收购工作协调小组，组长由县政府分管领导担任；副组长由县粮食流通服务中心主任担任；成员由县政府办公室、县委宣传部、县农业农村局、县粮食流通服务中心、县发改委、县财政局、县市监局、县农发行等部门的分管领导组成。要切实明确部门、乡（镇）职责。

1.县粮食流通服务中心:牵头负责全县的粮食收购工作；全面做好粮食收购前的仓容、资金和工作人员、收购器材等准备工作；负责制定全县粮食收购工作预案；及时向上级申请并启动我县早稻最低价收购预案；积极主动当好政府参谋，并严格按国家粮食政策做好粮食收购工作。

2.县发改委：做好县内粮食收购市场价格采集和监测，积极协调有关部门做好粮食最低价收购启动申报工作。

3.县农业农村局：牵头做好全县早稻产量的摸底工作；协助做好粮食收购政策的宣传工作。

4.金融部门:县农发行要积极做好粮食收购资金筹措供应，确保收购粮款的及时结算。各相关银行要确保粮食收购资金足额发放，及时办理农户粮款转账业务，服务基层和群众，不得出现向售粮农民“打白条”现象。

5.县财政局：做好政策粮食费用补贴保障，牵头对超标粮收购处置的损失进行认定。

6.县市监局：加强对县内粮食收购市场的监管工作，对扰乱粮食收购市场秩序、坑农害农等不法行为，做到坚决查处、绝不姑息。

7.县宣传部门：积极做好粮食收购政策宣传；加大对种粮大户、水稻专业合作社等种粮主体新型种粮技术、农机奖补等政策的宣传力度，进一步浓厚全县大力发展粮食生产的氛围。

8.各乡（镇）人民政府：负责做好本乡（镇）粮食收购计划的摸底、汇总、上报工作；做好国家粮食收购政策的宣传引导；积极做好本乡（镇）种粮农户，特别是种植大户、农民合作社对稻谷的烘干、销售、加工和市场推广等工作，确保农民种的粮食卖得出、卖得好。
