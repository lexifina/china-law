# 信丰县人民政府办公室关于印发《信丰县全日制普通高等院校退役大学生士兵优待安置办法》的通知

各乡（镇）人民政府，县政府有关部门，县直、驻县有关单位：

《信丰县全日制普通高等院校退役大学生士兵优待安置办法》业经2018年4月20县政府第18次常务会议研究通过，现印发给你们，请遵照执行。

2018年6月3日

信丰县全日制普通高等院校退役大学生士兵优待

安置办法

为缓解高校毕业生就业压力，提高我县大学生应征入伍的积极性，对信丰籍的全日制普通高等院校退役大学毕业生士兵实行优待安置，现结合我县实际，制定本安置办法。

一、安置对象及条件

（一）安置对象

优待安置对象为经县征兵领导小组批准入伍的信丰籍退役全日制普通高等院校大专及以上学历毕业生。

（二）安置条件

1. 拥护中国共产党的领导，遵守宪法和法律。

2. 具有良好的政治素质，品行端正。

3. 无违法违纪行为，在校就读和部队服役期间未受纪律处分。

4. 身体健康，适应岗位工作要求。

5. 符合招聘事业单位工作人员有关规定。

6. 在各级公务员、事业单位招考中因严重违纪被取消考试资格，在禁考期间的，不予安置。

二、安置办法

采取统一考试、公平竞争、择优聘用的方式进行安置。在本县事业单位面向社会公开招聘工作人员时，每年从全县招聘岗位计划中拿出5-10%的岗位，用于招聘信丰籍普通高校全日制大专及以上学历的退役大学生士兵；同等条件下，优先聘用退役大学生士兵。

三、安置要求

退役大学生士兵一经聘用，应服从工作安排，按时到接收单位报到上班，认真履职，并按规定与单位签订聘用合同，聘用单位与其约定最低5年服务年限，工作满5年以上方可调离本县。
