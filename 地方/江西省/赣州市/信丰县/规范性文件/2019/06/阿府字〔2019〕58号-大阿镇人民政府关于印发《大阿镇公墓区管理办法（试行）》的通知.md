# 大阿镇人民政府关于印发《大阿镇公墓区管理办法（试行）》的通知

各村（居）委员会、相关站所：

经研究同意，现将《大阿镇公墓区管理办法（试行）》印发给你们，请认真贯彻执行。

2019年6月12日

大阿镇公墓区管理办法（试行）

为加强公墓区管理，保护土地资源和生态环境，规范引导健康文明的丧葬活动，制订本办法。

一、公墓区应成立公墓管理理事会。公墓区所有权归政府所有，授权理事会管理。理事会成员由选举产生，负责对公墓的日常维护管理工作及理事会章程的制定工作。

二、实行殡葬改革。进入公墓安葬骨灰，必须事先到公墓管理理事会办理相关手续，由公墓管理人员安排墓位，交清费用后，方可进入墓区安放。

三、严格规范相关费用收取。公墓为公益性墓地，为减轻群众负担，原则上每个墓位不得超过3000元。因公墓新立，为吸引人气引导更多人员选择在墓区安葬，允许其他乡镇逝者在公墓安葬，可适当收取管理维护费用，具体标准以公墓管理理事会核定。对“三沿六区”坟墓搬迁进入公墓区的，免除墓穴费用并按照“谁先捡‘精’、谁先选安置坟墓”原则选择坟墓安置地。

四、资金代管。在理事会未能完成相关手续无法在银行开设专户前，允许公墓理事会委托公墓区所在村委会代管收取的费用，资金缴入相关村村级账户。代管资金的使用需凭理事会相关人员签字后的开支说明出账。

五、严格规范资金管理。必须严格按照理事会章程使用收取的墓穴费用及其他维护管理费用等资金。资金可用于日常维护及节日管理、适当发放管理人员补贴、对在墓区使用初期（半年内）对引导进入墓区安葬的人员进行奖励和计提10%作为村集体收入，其余资金须用于公益事业。

六、安放骨灰必须服从公墓管理人员的管理，不得擅自安葬，不得改建、扩建坟墓。

七、严格落实防火措施。提倡文明祭祀，鲜花祭祀，禁止燃放烟花爆竹、冥纸冥币等祭祀用品，禁止挂放气球，不得乱扔烟头,确保墓区林区安全。如因火烛、燃放烟花爆竹、烟头等引起火灾，按有关规定追究责任。

八、爱护公墓区环境卫生及绿化等基础设施。祭祀物、塑料袋、死者遗物等祭祀后必须收回放焚烧坑内焚烧，不得放在墓前，确保公墓内环境卫生。爱护墓区内的绿化及基础设施，如有损坏，照价赔偿，车辆进入墓区必须按序停放。
