# 信丰县人民政府办公室关于印发《新增商贸流通企业申报工作财政资金奖励办法》的通知

各乡（镇）人民政府，县政府各部门，县直、驻县各单位：

经11月24日县政府第48次常务会议同意，现将《新增商贸流通企业申报工作财政资金奖励办法》印发给你们，请认真贯彻落实。

2019年12月13日

新增商贸流通企业申报工作财政资金奖励办法

为切实做好我县限额以上消费品零售额统计工作，根据市政府办公厅《关于加强限额以上消费品零售额统计工作的通知》（赣市府办字〔2017〕215号）和市商务局《关于进一步做好2018年全市社会消费品零售额统计督报工作的通知》（赣市商务运字〔2018〕11号）、《关于进一步做好2019年全市社会消费品零售额统计督报工作的通知》（赣市商务运字〔2019〕9号）的文件精神，进一步调动我县商贸流通企业和统计人员申报数据的积极性，提高商贸统计工作的科学性、准确性和及时性，鼓励支持商贸流通企业依法统计，应统尽统，履行统计责任和义务，特制定本办法。

一、奖励对象

1. 新增限额以上批发、零售、住宿餐饮企业及其相关负责人、统计人员。

2. 当年销售额增长20%以上的限额以上商贸企业。

二、奖励标准

1. 对新增限额以上批发、零售、住宿餐饮企业给予一次性奖励5万元（不含省、市奖励）

2. 对当年销售额增长20%以上且增幅全县排名前10位的限上企业，每户奖励0.5万元。

三、经费来源及发放

1. 由县财政安排资金给予奖励；

2. 由县商务局、县统计局共同审核企业统计数据，并向县政府提出奖励申请报告，经县财政审核奖励申请报告，县政府批复后，将奖励资金拨付到县商务局财务账户。

3. 由县商务局发放到各奖励企业账户。

本办法自印发之日起实施，由县商务局负责解释。
