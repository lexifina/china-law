# 大余县人民政府关于严禁在规划区内抢栽抢种的通告

为确保全县重点工程项目建设顺利实施，有效遏制和严厉打击趁机在规划区内抢栽抢种等违法违规行为，维护社会公平正义和正常的征地拆迁秩序，根据《中华人民共和国土地管理法》《中华人民共和国城乡规划法》和《自然资源部关于完善征地补偿安置制度的指导意见》等相关规定，现就有关事项通告如下：

一、本通告所指规划区内抢栽抢种，是指县人民政府征地通知、公告及本通告下达之日起，在城乡规划区、旅游规划区、工业园规划区以及其他地区的重点工程项目建设用地范围内，被征地单位或个人以骗取征地拆迁补偿款为目的，在征地拆迁范围内抢栽抢种各种农作物、林果苗木花卉及其他地上附着物的违法违规行为。

二、在规划区内，未经批准任何单位和个人不得擅自改变土地用途，不得擅自改变耕地、林地现状，禁止栽种各种农作物、林果苗木花卉及其他地上附着物，依法依规经县人民政府批复同意的除外。

三、在规划区内，反季节、超密度等明显违反生长规律移栽各种农作物、林果苗木花卉及其他地上附着物，恶意突击移栽各种农作物、林果苗木花卉及其他地上附着物等行为，将依法按抢栽抢种论处。

四、在规划区内，按照产业发展规划发展林果苗木花卉产业的，经营者应拟定种植方案向村（居）委会、乡镇政府申报，经林业、国土、农粮等相关单位审核，符合规定的由县人民政府批复同意后，按审定的种植方案栽种；未经批准不得擅自栽种，否则将依法按抢栽抢种论处。

五、凡在规划区内抢栽抢种的各种农作物、林果苗木花卉及其他地上附着物一律不予补偿。

六、以抢栽抢种等违法违规行为骗取征地拆迁补偿费的，将依法没收非法所得；构成犯罪的，依法移交司法机关追究刑事责任；抗拒阻挠国家工作人员依法清除抢栽抢种者，依法予以治安处罚；构成犯罪的，依法移交司法机关追究刑事责任。

七、国家工作人员和村（居）干部参与抢栽抢种、抗拒阻挠依法清除抢栽抢种等违法违规行为的，依法依纪依规严肃处理和问责。

八、各乡镇人民政府、项目业主单位要切实加强宣传和日常巡查，依法依规及时制止抢栽抢种等违法违规行为。

九、广大干部群众应当自觉维护正常的征地拆迁秩序，自觉抵制、检举抢栽抢种等违法违规行为，积极支持重点工程项目建设；主动发挥监督作用，如有发现上述违法违规行为，任何单位和个人均有权向有关部门举报(举报电话：0797-8717110)。

十、本通告自发布之日起施行，之前发布与本通告有冲突的，以本通告为准。
