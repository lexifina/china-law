# 余府办发〔2019〕3号大余县人民政府办公室关于印发大余县现役军人立功受奖奖励办法的通知

各乡镇人民政府，县政府各部门，县直、驻县各单位：

《大余县现役军人立功受奖奖励办法》已经2019年5月10日县政府41次常务会议审议通过，现印发给你们，请认真遵照执行。

大余县人民政府办公室

2019年6月11日

大余县现役军人立功受奖奖励办法

为深入开展拥军优属活动，奖励现役军人立功受奖行为，激励其安心服役，建功立业，为国防建设多作贡献，特制定本办法。

一、奖励对象

大余籍在部队获得荣誉称号或立功受奖的现役军人。

二、奖励依据

以所在部队发出的喜报和立功通知书为依据，驻县部队由入伍所在地予以奖励。

三、奖励标准

（一）荣获中央军委授予荣誉称号者给予60000元人民币奖励；

（二）荣获战区级单位荣誉称号者给予30000元人民币奖励；

（三）荣立一等功者给予奖励20000元人民币奖励；

（四）荣立二等功者给予奖励10000元人民币奖励；

（五）荣立三等功者给予奖励5000元人民币奖励。

对年度内多次获得荣誉称号、立功受奖的，按年度最高荣誉给予一次性奖励。

四、奖励办法

获得中央军委授予荣誉称号、战区级单位荣誉称号者、荣立一等功者，由县政府和县人武部领导、县退役军人事务局和户籍所在乡镇政府主要领导负责上门走访慰问；荣立二、三等功者，由县人武部、县退役军人事务局和户籍所在乡镇政府相关领导负责上门走访慰问。

（一）对授予荣誉称号和荣立一、二等功的现役军人，由县委宣传部、县广电新闻中心协调赣南日报、赣州电视台、大余县电视台等新闻媒体进行宣传报道，必要时组织到部队慰问采访。

（二）对荣立三等功现役军人，户籍所在地乡镇政府在办公楼信息公开栏张贴立功受奖喜报，户籍所在地行政村利用广播通告宣扬。

（三）在县退役军人事务局微信公众号设立“大余籍儿女建功军营光荣榜”专栏，刊登立功受奖军人名单和先进事迹。

五、奖励经费

奖励经费纳入县本级财政预算安排，由县财政每年安排10万元奖励专项资金，每年由各乡镇政府根据实际受奖人员上报县退役军人事务局，县退役军人事务局根据各乡镇实际上报奖励资金汇总后，向县财政局提出拨款申请，县财政按程序审核批准后奖励资金直接拨付到县退役军人事务局。

六、人民武装警察和预备役人员立功受奖参照本办法执行。

七、本办法从2019年8月1日开始执行。

抄送：县委办，县人大办，县政协办，县纪委办，县人武部政工科，

县委有关部门，县法院，县检察院，各人民团体。
