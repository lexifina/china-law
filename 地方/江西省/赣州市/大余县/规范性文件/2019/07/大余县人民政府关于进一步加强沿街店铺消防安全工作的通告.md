# 大余县人民政府关于进一步加强沿街店铺消防安全工作的通告

为吸取广东中山“6.26”五金店铺等火灾事故教训，进一步加强沿街店铺消防安全工作，坚决遏制火灾事故发生，保障居民群众生命和财产安全，根据《中华人民共和国消防法》《江西省消防条例》等法律法规规定，结合《赣州市人民政府办公厅关于进一步加强消防安全治理工作的通知》（赣市府办字〔2019〕1号）精神，现将有关事项通告如下：

一、沿街店铺各业主应切实提高消防安全意识，主动履行消防安全主体责任，严格遵守消防法律法规规定，自觉做好消防安全管理工作。

二、积极组织、参加消防安全知识学习培训，所有人员会报火警、会扑救初起火灾、会自救逃生、会组织人员疏散。

三、所有人员严禁在店铺内住宿。

四、不得违规经营、储存易燃、易爆物品和危险化学品。

五、严禁将商品、货物、手推车等摆放于安全出口，占用疏散通道。

六、每日关铺前须断开电源总开关，商铺用电开关及其他开关、插座须保持完好；发现损坏，须及时予以维修更换。

七、严禁在店铺内乱接乱拉电线，电表箱下不可堆放杂物；电动车不允许在店内和安全出口处充电；确需充电应放置安全区域，充电后务必及时收回插座、电源设备或将室内插头拔掉。

八、店铺内须安装独立式感烟报警器；一旦发生火灾第一时间发出警报，引导人员灭火、疏散逃生。

九、每个店铺内除大门出口外，须另行设置一个以上逃生出口，确保遇到火灾能安全疏散；店铺窗户可作逃生通道，且不能设置栅栏等阻碍逃生设施，有条件的可设置单独的疏散出口。

十、每个店铺内必须配置两具以上4KG干粉灭火器，设置在明显和便于取用的地方，周围不准堆放物品和杂物；店铺使用者应掌握消防器材的操作使用和维护方法。

十一、店铺存在火灾隐患且无法短时间内完成整改的，应当自行停业整改，确保消防安全。

十二、本通告自发布之日起施行。

特此通告。

大余县人民政府
