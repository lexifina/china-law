# 关于进一步加强校园食品安全工作的通知

各乡镇人民政府，县政府有关部门，县属、驻县有关单位：

为贯彻落实全国、全省校园食品安全工作电视电话会议精神和市食安委成员（扩大）会议精神，切实做好我县校园食品安全工作，根据教育部、市场监管总局和卫生健康委《学校食品安全与营养健康管理规定》和赣州市食品安全委员会办公室《关于进一步加强校园食品安全工作的通知》（赣市食安字〔2019〕8号）文件精神，结合我县实际，现将有关事项通知如下：

一、立即开展校园食品安全专项排查整治

各乡镇、各相关部门要结合近期国家、省、市关于学校食品安全要求和3.15晚会曝光的“辣条”食品安全问题，全面开展校园及周边食品安全隐患排查整治工作，将校园及周边200米范围作为食品安全严管区，校内及校园周边同步排查，确保排查整治覆盖面达到l00%。把学校营养餐集中供餐单位和校园周边商店、零售摊点作为排查整治的重中之重，对3.15晚会曝光的河南省兰考县宁远食品有限公司、河南省尉氏县欧飞食品有限公司、湖南省平江县钧力食品有限公司、湖南省平江县味泉食品有限公司等企业生产的“辣条”及相关食品，一律下架封存、停止销售，做好详细记录并通报生产企业所在地的市场监管部门，等待生产企业进行产品召回；对其他生产企业的“五毛食品”，如发现超过保质期、已腐败变质、标签标识不规范、“三无”、产品名称和包装不符合要求、检验不合格等问题食品，责令经营主体停止销售并下架，做好详细记录并通报生产企业所在地的市场监管部门；对排查的各类校园食品安全风险隐患，要建立清单，落实跟踪整改措施，逐项整改，务求实效，务必于4月底前完成隐患排查整治工作；对发现的学校食堂、校园周边食品安全违法行为实行“零容忍”，从严处罚违法行为，涉嫌犯罪的一律移送公安机关。

二、严格落实食品安全管理责任

(一)强化乡镇属地管理责任。各乡镇要严格按照“党政同责、一岗双责、齐抓共管、失职追责”要求，将校园食品安全工作列入党委政府重要议事日程，纳入年度重点工作安排，切实担起《中华人民共和国食品安全法》等有关法律法规赋予的法定职责，统一组织领导、协调调度本辖区校园食品安全监督管理工作。要制定实施校园食品安全专项规划，推进校园食品安全治理能力和保障水平逐年提升。要及时听取辖区内校园食品安全工作汇报，每年专题研究校园食品安全工作不少于2次，对贯彻落实上级党委政府关于校园食品安全工作的重大部署提出具体举措，推动解决影响本辖区校园食品安全的重点问题。要安排专人负责校园食品安全工作，做好本乡镇内校园周边食品小作坊、小餐饮、小食杂店和食品小摊贩的安全隐患排查整治、信息报告、宣传教育等工作。

（二）强化学校主体责任。各学校必须建立食品安全责任体系，强化校（园）长第一责任人责任，切实落实学校食品卫生安全校（园）长负责制。要建立校（园）长为组长、分管校（园）长及相关责任人员为成员的学校食品安全管理工作组织机构，建立健全校园食品安全管理制度，落实各项食品安全管理措施，落实好自查责任，强化日常管理，定期排查风险隐患。要规范学校食堂管理，义务教育阶段学校实行自主经营，坚持公益性原则，不以营利为目的，并由县教科体局具体负责在7月底前排查整治到位。其它阶段学校对外承包的食堂必须以招投标方式公开选择依法获得食品经营许可、能承担食品安全责任、社会信誉良好的餐饮服务单位或者符合条件的餐饮管理单位，依法签订经营合同，确保供餐安全。招标的核心侧重于企业的服务能力和管理水平，同时要研究制定负面清单，采取“扣分制”方式进行量化考核，严格监管，并明确年度考核不合格的退出机制。要严格执行从业人员健康体检、食品留样和购物索证索票等制度。对食堂硬件差的要加大投入，迅速整改落实到位。严格食品经营许可管理，各中小学校、幼儿园食堂食品经营许可证持证率必须达到100%。积极推行“洁厨亮灶”，到今年底，全县学校食堂“洁厨亮灶”比例达80%以上。严格落实省教育厅关于食品原料采购“十不准”，经营管理“十必须”要求，杜绝假冒伪劣食品、未经检疫的肉类进入校园，食堂采购要建立台帐。要建立校长等学校相关负责人及教师陪餐制度，有条件的学校应当建立家长陪餐制度，健全学校负责人、教师、学生、家长和社会监督机制。

（三）强化部门监督责任。教科体部门要切实履行管理主体责任，督促学校、幼儿园落实校（园）长第一责任人责任，加强学校食堂硬件改造，健全食品安全管理制度，加强学生和教职员工的食品安全教育；市场监管部门要切实履行食品监管责任，督促学校食堂严格执行食品安全管理制度和操作规程，加大校园及其周边食品经营者和针对学生制售食品的监督检查力度，依法查处违反食品安全法律法规行为；卫生健康部门要加强学校食源性疾病监测，强化饮用水安全监督，消除水源安全风险。一旦发生食品安全事件，要立即组织流行病学调查并对现场进行卫生学处理；城管部门要加大监管力度，依据《江西省食品小作坊小餐饮小食杂店小摊贩管理条例》规定，清理整治校门外道路两侧100米范围内的食品小摊贩，严禁食品流动摊贩。各有关部门要建立健全信息通报、风险排查、联合整治、应急处置等制度，齐抓共管，形成合力，确保校园食品安全。

（四）强化应急处置和责任追究。各乡镇、各相关部门要加强学校食品安全事件应急处置能力建设，指导学校建立学校食品安全事故处置方案，积极开展应急演练；要进一步强化部门协同配合，优化学校食物中毒事件调查处置流程，一旦发生突发事件，要及时、准确查清事故性质和原因；要加强食品安全舆情监测，及时回应家长和学生关切，防范恶意炒作；要提高舆情事件应急水平，迅速研判，及时处置，精准发声。要强化学校食品安全事故责任追究，对于因学校食品安全监督管理责任不落实、不到位导致发生食物中毒事故，或对事故应急处置不力的，要依法依规严肃问责。

三、不断强化食品安全宣传教育

（一）开展形式多样的学校宣传教育活动。各中小学校、幼儿园要通过手抄报、黑板报、宣传栏、展板、手机报、班会等形式，营造浓厚的宣传教育氛围。特别是要将食品安全教育纳入课程，普及食品安全防范知识，教育学生不购买“三无”食品和“五毛食品”，养成良好饮食卫生习惯，降低“病从口入”的风险，增强学生食品安全自我保护意识与能力。一旦发现食品颜色、气味、口味等感官性状异常，应立即停止食用，及时向陪餐老师报告。

（二）开展食品安全宣传“小手拉大手”活动。开展“致全县中小学、幼儿园学生及家长的一封信”活动，将食品安全教育由孩子辐射到每一个家庭。通过孩子来提升家长的食品安全意识，提醒每个家庭在食品买卖、加工活动中注意食品安全，努力达到“教育一个学生，辐射一个家庭，影响整个社会”的食品安全教育效果。

四、强化食品安全督促检查

县教科体局、县市场监管局、县卫健委、县城管局等部门要建立校园食品安全联动督查机制，定期或不定期组成检查组，采取不打招呼、不发通知、不听汇报、不看材料、直奔学校、直赴现场的方式，督促检查学校及周边食品经营户食品安全管理和食品安全责任履行情况。对工作不重视，责任不落实，措施不到位的单位或个人，县政府将进行通报，对情节严重的将依法追究相关人员责任。
