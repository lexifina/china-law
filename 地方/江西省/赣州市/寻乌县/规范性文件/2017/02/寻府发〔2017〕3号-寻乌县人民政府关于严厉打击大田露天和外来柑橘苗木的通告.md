# 寻乌县人民政府关于严厉打击大田露天和外来柑橘苗木的通告

寻府发〔2017〕3号

健康、安全的柑橘苗木是柑橘产业可持续发展的根本保证，是柑橘丰产的基础。开春以来，部分果农急于求成，盲目调苗现象有所抬头，给产业有序恢复埋下重大安全隐患。为巩固柑橘黄龙病防控成果，防范不健康苗木流入我县，成为柑橘黄龙病的新病源。经研究决定，对大田露天育苗和外来柑橘苗木进行专项打击行动，现将有关事项通告如下：

一、严格禁止未按《柑橘无病毒苗木繁育技术规程》（NY/T973—2006）要求生产；砧木、接穗来源不明；苗木生产过程没有网棚保护；出圃前没有进行危险性病虫害检测的大田露天育苗和外来柑橘苗木。

二、柑橘无病毒苗木生产实行定点繁育，定点育苗点由赣州市果业局组织专家评估确定，任何组织或个人未经审批不得从事柑橘苗木生产。

三、根据《中华人民共和国植物检疫条例》第七、八、十条规定，凡种子、苗木和其他繁殖材料，不论是否列入应施检疫的植物、植物产品名单和运往何地，在调运之前，都必须经过检疫，经检疫未发现植物检疫对象的，发给《植物检疫证书》。未取得《植物检疫证书》的外来柑橘苗木一律依法采取封存、没收及销毁等措施处理。

四、根据《中华人民共和国植物检疫条例》第十八条规定，未依照规定办理植物检疫证书或者在报检过程中弄虚作假，引起疫情扩散的，由司法机关依法追究当事人的刑事责任。

五、各乡（镇）人民政府要切实履行属地管理职责，摸清辖区内大田露天育苗和外来苗木调运情况，及时如实向上汇报，并主动配合相关部门依法查处。

六、由县农粮局牵头，县市场和质量监督管理、果业、公安等部门组成联合执法队伍，在全县范围开展柑橘大田露天苗木清理、市场检查及调运监管工作，坚决杜绝未经检验检疫、来历不明的柑橘苗木流入我县。

七、广大群众要树立防范意识，自觉做到不繁育、不调入、不种植来历不明的柑橘苗木，避免来之不易的柑橘黄龙病防控成果毁于一旦。
