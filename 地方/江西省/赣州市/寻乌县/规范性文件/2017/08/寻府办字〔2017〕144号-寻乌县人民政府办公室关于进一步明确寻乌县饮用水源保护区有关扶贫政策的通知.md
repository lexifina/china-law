# 寻乌县人民政府办公室关于进一步明确寻乌县饮用水源保护区有关扶贫政策的通知

三标乡人民政府，县政府有关部门，县属、驻县有关部门：

根据《江西省人民政府关于寻乌县城市生活饮用水地表水源保护区范围划定的通知》（赣府字〔2017〕57号）、《寻乌县“十三五”脱贫攻坚规划》和《寻乌县易地搬迁脱贫攻坚实施方案》（寻办字〔2016〕35号）等文件精神，三标乡东江源村、图岭村和长安村的新告路小组、黎洋尾小组、龙岗塘小组、蓑衣塘小组、新屋小组梅子坝自然村已划入饮用水源保护区整村整组生态搬迁区域。为进一步明确饮用水源保护区的移民搬迁及相关扶贫政策，经2017年8月10日县政府第24次常务会议研究，现将有关事项通知如下：

一、明确易地移民搬迁政策

寻乌县饮用水源保护区易地移民搬迁工作，总体上依照《中共寻乌县委办公室 寻乌县人民政府办公室关于印发寻乌县易地搬迁脱贫攻坚实施方案>》（寻办字〔2016〕35号）政策执行，具体明确以下三个方面：

（一）补助标准

建档立卡贫困人口每人补助2万元，同步搬迁的非贫困人口每人补助8000元。

（二）安置方式

根据群众意愿，对饮用水源保护区的移民搬迁实行“进城安置为主、就近安置为辅”方式安置。

1．进城进园安置。鼓励移民户选择在进城安置点和进园安置点购房安置。

2．就近集中安置。饮用水源保护区不审批非农建设用地手续。在饮用水源保护区外，可以规划建设乡级集中安置点，实行就近安置。

二、明确相关扶贫政策

为确保饮用水源保护区贫困群众实现“收入过线”和“两不愁三保障”目标，且不与促进生态移民搬迁相冲突，饮用水源保护区相关扶贫政策明确如下：

（一）关于教育扶贫政策

除在红线区域内不安排教育基建项目外，其它教育扶贫政策参照《寻乌县教育扶贫工程实施方案》文件执行。

（二）关于就业扶贫政策

除在红线区域内不新建扶贫车间、扶贫企业（可用原有建筑设立符合环保要求的扶贫车间、扶贫企业）外，其它就业扶贫政策参照《寻乌县就业扶贫专项实施方案》文件执行。

（三）关于产业扶贫政策

禁止在饮用水源保护区内开展不符合国家污染物排放标准要求的种植、养殖等生产经营活动。禁止在饮用水源保护区开发果园、旱地，破坏生态，除养蜂外，其它种、养项目不列入奖补，不享受柑橘扶贫等相关产业扶贫政策。

（四）关于健康扶贫政策

除不安排村卫生室建设项目外，建档立卡贫困人口可以享受相关医疗扶贫政策。

（五）关于金融扶贫政策

建档立卡贫困人口可以享受金融扶贫政策。

（六）关于兜底扶贫政策

符合条件的对象可以享受兜底保障扶贫相关政策。

（七）关于安居扶贫政策

鼓励饮用水源保护区群众实施生态移民搬迁。在规划红线区域内不安排新建住房项目、不安排住房维修加固项目、不安排保障建设房项目。

（八）关于基础设施扶贫政策

在饮用水源保护区所在村组不安排基础设施项目。不准新建、扩建向水体排放污染物的基础设施建设项目。改建项目必须消减污染物排放量。

（九）关于生态扶贫政策

在饮用水源保护区不安排林木砍伐指标。建档立卡贫困户可以享受生态扶贫政策。

（十）关于光伏扶贫政策

可以享受光伏扶贫政策。

（十一）关于电商扶贫政策

可以享受电商扶贫政策。
