# 关于调整我县农村客运基本运价的通知

寻乌县汽车客货站：

你站报来《关于要求调整我县农村客运基本运价的请示》收悉。根据《江西省发展改革委江西省交通运输厅关于进一步加强道路客运价格管理的通知》（赣发改价调[2018]906号）文件要求，寻乌县价格认证中心进行了成本调查，召开了“寻乌县农村客运基本运价调整意见征集会”。并报请寻乌县人民政府经2019年1月14日县政府第60次常务会议研究，同意对我县农村道路客运基本运价从0.24元/人·公里调整为0.29元/人·公里。

寻乌县发展改革委　　　　寻乌县交通运输局

2019年3月15日
