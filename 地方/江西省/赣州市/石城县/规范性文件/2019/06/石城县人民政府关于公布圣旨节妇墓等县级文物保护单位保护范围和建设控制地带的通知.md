# 石城县人民政府关于公布圣旨节妇墓等县级文物保护单位保护范围和建设控制地带的通知

各乡（镇）人民政府，县政府各部门，县直、驻县各单位：

经研究，现将圣旨节妇墓等13处县级文物保护单位的保护范围和建设控制地带予以公布（详见附件）。

各乡镇、部门和单位应严格按照《中华人民共和国文物保护法》《中华人民共和国文物保护法实施条例》《江西省文物保护条例》规定，坚持“保护为主、抢救第一、合理利用、加强管理”方针，切实做好文物保护利用和管理工作。
