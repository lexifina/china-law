# 石城县人民政府办公室关于印发石城县2019年“放管服”改革工作要点的通知

各乡（镇）人民政府，县政府各部门，县直、驻县各单位：

经县政府同意，现将《石城县2019年“放管服”改革工作要点》印发给你们，请结合实际抓好贯彻落实。

石城县人民政府办公室

2019年7月26日

（此件主动公开）

石城县2019年“放管服”改革工作要点

为认真贯彻落实党中央、国务院“放管服”改革决策部署，进一步深化重点领域和关键环节改革攻坚，深入推进“五型”政府建设，努力营造“四最”发展环境，根据《赣州市人民政府办公室关于印发2019年“放管服”改革工作要点的通知》（赣市府办字〔2019〕32号）精神，结合县情实际，制定本工作要点。

一、推进政务服务网上办理

（一）加快一体化在线政务服务平台建设。

按照省、市部署，统筹推进县乡村三级政务服务网上平台建设，力争实现县乡两级政务服务事项网上可办率不低于80%。〔牵头单位：县行管委, 县工信局；责任单位：各乡镇人民政府，有关部门和单位；完成时限：按省、市统一部署序时推进〕

（二）推进与市级政务数据交换及“四库一平台”建设对接工作。

涉及企业和群众网上办事的政务数据归集率达90%以上。〔牵头单位：县工信局，县行管委；责任单位：各乡镇人民政府，有关部门和单位；完成时限：按市统一部署序时推进〕

（三）推进“赣州通”平台建设。

2019年9月底前完成“赣服通”县分厅建设，第一批实现20个以上本地事项“掌上办理”；县本级高频事项掌上可办率达到70%。〔牵头单位：县行管委，县工信局；责任单位：各乡镇、部门和单位；完成时限：2019年12月底前〕

（四）推进“一证通办”“全城通办”。

通过整合资源、优化方式，实现一张身份证或统一社会信用代码通办大部分政务事项，梳理公布第一批“全城通办”事项清单，清单内事项可实现跨区办理。〔牵头单位：县行管委、县工信局、县公安局；责任单位：有关部门和单位，各乡镇人民政府；完成时限：2019年12月底前〕

（五）完善社会保障“一卡通”。

根据省、市统一部署，推动养老保险、医疗保险等跨地区联网办理，实现养老保险关系转移接续业务网上办理和顺畅衔接。〔牵头单位：县人社局、县医保局；责任单位：各乡镇、部门和单位；完成时限：2019年12月底前〕

（六）建设12345政府服务热线平台。

严格按照有关要求和规定时间推进12345政府服务热线平台建设，不断强化运行管理、健全完善转办督办机制，确保2019年9月底前热线平台正式运行，年底前热线系统接通率、一次办结率、群众评价满意率等指标达98%以上。结合延时错时预约服务，实现预约办事只需拨打“12345”号码或登录“12345”网络平台。〔牵头单位：县行管委；完成时限：2019年9月底前〕

二、推进政务服务重点改革

（七）全面推广“一窗受理”服务改革。

进一步完善县综合性政务大厅集中服务模式。年底前，县政务服务大厅“一窗”受理率达到90%以上。乡镇直接面向群众办理的社保、医保、民政、计生、农民建房审批等事项全部进驻便民服务中心，并尽可能采取“前台综合受理、后台分类审批、综合窗口出件”模式。有条件的乡镇，除班子成员外，其余人员全部进驻便民服务中心办公。〔牵头单位：县政府办、县行管委；责任单位：各乡镇人民政府，有关部门和单位；完成时限：2019年12月底前〕实现权责清单同“三定”规定有机衔接；同步梳理各部门依申请事项清单，审批事项应减尽减。〔牵头单位：县政府办、县委编办、县行管委；责任单位：有关部门和单位；完成时限：2019年12月底前〕

（八）积极开展相对集中行政许可权改革。

根据省市统一部署，深化相对集中行政许可权改革试点，实行“一枚印章管审批”，建立“审管分离”审批模式和工作运行机制。〔牵头单位：县行管委、县政务服务管理办、县委编办；责任单位：有关部门和单位；完成时限：按省、市统一部署安排序时推进〕

（九）开展“一链办理”改革。

全面梳理优化办事全流程，编制“一链办理”事项目录清单和办事指南，变过去企业和群众到不同部门“办几件事”为全链条办理“一件事”。2019年底前，县本级10项以上多部门事项实现“一链办理”。〔牵头单位：县行管委；责任单位：有关部门和单位；完成时限：2019年12月底前〕

（十）扩大“最多一次办结”改革。

着力推进网上办、邮寄办，鼓励为企业群众提供免费邮寄服务，将更多事项纳入“最多一次办结”清单。除有明确特殊要求的外，凡是法律法规没有规定必须到现场办理的事项一律要做到企业和群众办事可以“一次不跑”，凡法律法规明确要求必须到现场办理的事项要想方设法做到“只跑一次”。到2019年底，县本级“最多跑一次”事项占比提高到90%以上，“一次不用跑”“就近办”事项提高到50%以上。对已公布的“一次不跑”“只跑一次”事项要真正兑现承诺并实现高质量办理。〔牵头单位：县行管委、县政务服务管理办；责任单位：有关部门和单位，各乡镇人民政府；完成时限：2019年12月底前〕

（十一）探索“标准地+承诺制”改革。

建设用地带着建设规划、能耗、环境、投资强度等一系列标准进行出让，企业拿地后通过“一窗受理”，一次提交材料即可开工，建成投产后按照法定条件和既定标准进行验收。2019年年底前，35%以上的新增工业用地实现标准地供应。〔牵头单位：县工业园区管委会，县自然资源局；责任单位：县工信局、县发改委，有关部门和单位；完成时限：2019年12月底前〕

（十二）全面推开“证照分离”改革。

对所有涉企经营许可事项实行“证照分离”改革，让企业更便捷拿到营业执照并正常运营，切实解决“准入不准营”的问题。2019年底前制定全覆盖全流程的事项清单，清单之外事项一律不得作为限制企业经营的依据。按照直接取消审批、审批改为备案、实行告知承诺、优化准入服务等四种方式逐一制定具体管理措施，让企业和群众明明白白办事。〔牵头单位：县市场监管局；责任单位：有关部门和单位；完成时限：2019年12月底前〕

三、着力提升政务服务水平

（十三）加大“三集中三到位”力度。

根据机构改革后部门“三定”规定调整，全面梳理完善部门权责清单。2019年年底前，除对场地有特殊要求的事项外，依申请类事项“应进必进”县行政服务中心，实现一门办理。推行一站式办理水电气过户联办业务，不断提升有线电视、通信、公积金、银行、公交、医院、学校等民生领域服务水平。〔牵头单位：县政务服务管理办、县行管委；责任单位：有关部门和单位；完成时限：2019年12月底前〕

（十四）强化对企业的服务。

优化企业开办服务，进一步推行企业开办“一窗办”集成服务，实现企业开办时间压缩至5个工作日内完成。推行企业投资项目“保姆制”代办服务，对重点产业项目实行“一对一”全程跟踪服务。〔牵头单位：县市场监管局、县行管委、县发改委；责任单位：县工信局，县工业园区管委会，有关部门和单位；完成时限：2019年12月底前〕

（十五）优化完善错时延时服务。

以办成事为原则，从接件、办件到出件，全链条开展错时延时服务，加大错时延时服务的人力、物力的保障力度，将更多与群众生产生活密切相关的事项纳入错时延时服务。〔牵头单位：县行管委；责任单位：有关部门和单位，各乡镇人民政府；完成时限：2019年12月底前〕

（十六）完善基层综合便民服务平台功能。

制定出台规范乡镇便民服务中心和村（居）代办点建设标准文件，明确乡镇、村便民服务中心（站）的名称、场所、标识、进驻部门、办理事项、运行模式，推动更多事情就近办。〔牵头单位：县政务服务管理办；责任单位：县行管委，有关部门和单位，各乡镇人民政府；完成时限：2019年12月底前〕

（十七）积极推行自助服务。

2019年底前，县行政服务中心大厅设置自助服务专区，并在商场、银行、车站和村（居）委会等场所积极推行设置自助设备，方便企业群众就近办事。同时开发和采购一批网上办事自助设备向基层延伸。〔牵头单位：县行管委；责任单位：县政务服务管理办，有关部门和单位，各乡镇人民政府；完成时限：2019年12月底前〕

（十八）提升规范中介服务。

按照上级有关规定，坚持必需、简便的原则，对中介服务事项进行全面清理，取消调整一批中介服务事项，防止行政审批对中介服务过度依赖。积极推行中介机构联合体，同一事项涉及多类中介服务的，由一家中介机构联合相关中介机构，打包提供多类中介服务，变多个中介报告为一份“综合报告”。县“行政审批中介服务超市”向民营企业开放，降低企业中介成本。〔牵头单位：县行管委、县发改委；完成时限：2019年9月底前〕

（十九）深化“减证便民”行动。

对无法律法规明确要求提供的材料进行清除；对部门间可相互提供的材料或通过数据共享、上网可查验的材料进行精简；对确需保留的证明，对外公布清单并严格加强管理，清单之外，不得索要证明，企业和群众提供的证明材料减少60%以上。〔牵头单位：县司法局；责任单位：有关部门和单位，各乡镇人民政府；完成时限：2019年12月底前〕

抄送：县委各部门，县纪委监委办公室，县人大常委会办公室，

县政协办公室，县人武部，县法院，县检察院，群众团体。

石城县人民政府办公室秘书科 2019年7月26日印发
