# 石城县人民政府关于公布石城县行政规范性文件制定主体清单的通知

各乡（镇）人民政府，县政府各部门，县直各单位：

根据《江西省司法厅关于编制行政规范性文件制定主体清单的通知》(赣司法审字〔2019〕1号)精神，为进一步明确行政规范性文件制定主体，切实做好全县行政规范性文件制定、备案、监督和管理工作，结合我县机构改革和部门工作实际，编制了《石城县行政规范性文件制定主体清单》，现予以公布。

各乡镇、部门和单位应严格遵循规范性文件制定程序，按照有关要求做好各项工作；清单中公布的乡镇、部门和单位可以依法制定行政规范性文件，未列入清单的均不得自行制定行政规范性文件。
