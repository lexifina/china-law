# 关于印发石城县环评审批提质增效改革实施方案的通知

各乡（镇）人民政府，县政府各部门，县直、驻县各单位：

经县政府同意，现将《石城县环评审批提质增效改革实施方案》印发给你们，请按照工作要求，认真贯彻执行。

石城县人民政府办公室

2019

年9月16日

（此件主动公开）

石城县环评审批提质增效改革实施方案

为深入推进环评审批提质增效，根据省委十四届六次、七次全会精神，按照《中共江西省委  江西省人民政府关于加强作风建设优化发展环境的意见》（赣发〔2018〕24号）、《江西省生态环境厅关于印发〈江西省环评审批提质增效改革指导意见〉的通知》（赣环发〔2019〕1号）、《赣州市生态环境局关于落实江西省环评审批提质增效改革指导意见切实加强环评管理的通知》（赣市环发〔2019〕56号）有关要求，依据相关法律法规和政策规定，结合县情实际，制定本方案。

一、总体要求

以习近平新时代中国特色社会主义思想为指导，按照深化“放管服”改革部署要求，加强规划环评与项目环评联动，分区分类实施建设项目环境准入政策，进一步减少审批事项、简化审批程序、优化审批流程、提高审批效率；进一步强化事中事后监管，不断提升生态环境保护能力，促进产业布局更为优化、县域经济社会健康协调可持续发展。

二、工作重点

（一）合理分区，优化产业布局

坚持问题导向，强化生态环境保护对促产业升级、优营商环境的正向拉动作用，推进建设项目环境影响评价审批制度改革。以“三线一单”为基础，结合县环境保护规划和环境功能区划的要求，将全县划分为工业准入优先区、城市人居功能区、农产品主产区、特殊环境敏感区等4个区域，分别实行不同的建设项目环境准入政策，优化项目准入，引导工业项目向园区集聚，实现产业集聚发展、污染集中控制，保障人居环境和粮食生产安全，构筑良好生态屏障。

（二）宽严相济，实行分类准入

针对全县不同区域的主体功能和环境承载力，实行分类环境准入，探索建立基于不同区域的建设项目环境准入负面清单制度。按照“三线一单”划分的“一般管控单元、重点管控单元、优先保护单元”原则，对于环境容量相对宽裕区域，在确保主体功能和环境质量的前提下，引导项目集聚发展, 实现环境容量高效利用；对于优先保护单元等环境问题相对敏感的管控区域，实行严格的环境准入政策，控制污染物新增量。

（三）简政放权，优化环评管理

优化建设项目分类管理，改进完善管理办法，切实提高行政效能，认真履行管理职责，依据《江西省免于环境影响评价管理建设项目目录（试行）》，取消、合并部分环评审批事项。对未列入国家建设项目环境影响评价分类管理名录（除环境影响或环境风险较大的新兴产业外）采取豁免审批，对污染排放强度低、环境影响程度小、仅需填写环境影响登记表的建设项目实行网上备案，落实“一次不跑”要求；对国家规定需要保密的项目，仍采用纸质备案方式。取消竣工环保验收行政许可，建设项目竣工后，由建设单位依据《建设项目竣工环境保护验收暂行办法》开展自主验收。推动项目环评和规划环评联动，对按要求完成了规划环评的区域，符合规划环评要求和环境准入标准的项目，可以简化环境影响评价文件。

三、分类施策

（一）工业准入优先区

主体功能区划重点开发区域中省级以上开发区，要以实现环境资源优化配置为目标，引导工业项目向园区集聚，科学高效利用环境容量，推动产业转型升级。

1.取消部分审批事项。对建设项目环境影响评价豁免管理名录内的所有项目，不需办理环评手续。

2.简化部分审批程序。依据原环保部《建设项目环境影响评价分类管理名录》规定，对填报环境影响登记表的项目，按照建设项目环境影响登记表备案管理工作要求，环评文件由审批制改为备案制。

3.探索实行项目环评承诺备案制。对位于已完成规划环评审批的工业园区内且符合主体产业定位（国家法律另有规定的项目除外）、属县本级审批应编制环境影响报告书（表）的建设项目，建设单位按要求填报及提交相关承诺材料，完成受理后，当场制作建设项目环境影响告知承诺制审批批复。

4.严控部分重污染项目。严格燃煤火电项目审批，不予审批化工、冶金、钢铁、铁合金、生物发酵制药、制浆造纸、制革及毛皮鞣制、印染等行业单纯新建和单纯扩大产能的项目；不予审批新增重金属污染物排放量的相应项目（符合省、市重大产业布局的项目除外）。

（二）城市人居功能区

主体功能区划重点开发区域中县城区、各乡镇建成区，以及规划区中以居住、商贸、文教科研、旅游为主的特色小镇等区域，要以保障人居环境安全为目标，坚持重污染项目“只出不进”，严格控制工业开发活动，着力解决大气、水和噪声污染等城市突出环境问题，不断提升人居环境质量。

1.取消部分审批事项。对免于环境影响评价管理建设项目目录中的城市交通设施、城市基础设施、社会事业与服务业等三类项目，不需办理环评手续。

2.简化部分审批程序。依据原环保部《建设项目环境影响评价分类管理名录》规定，对填报环境影响登记表的项目，按照建设项目环境影响登记表备案管理工作要求，环评文件由审批制改为备案制；对应编制环境影响报告表的城市基础设施、交通设施、房地产、社会事业与服务业的项目，简化审批程序，通过受理审查的即报即受理。

3.严控重污染项目。不予审批《工业项目分类清单》中三类工业项目和排放重金属、持久性有机污染物、挥发性有机污染物等影响人居环境安全的二类工业项目及产生噪声、废水等纯工业项目。

4.从严掌握准入标准。其他与生产生活相关的建设项目清洁生产水平应达到国内先进水平，废水须进入区域集中式污水处理厂处理，废气、噪声等污染物排放必须执行相应功能区的环境质量标准和排放标准。

（三）农产品主产区

除产业开发区和县城建成区、建制乡镇以外区域，要以保障农产品供给安全为目标，严格控制工业开发活动，支持因地制宜发展农产品加工业，防止不合理工业开发对农业生产环境的不良影响。原则上不允许有污染的项目向农村转移，对有规定要求进园区的项目从其规定。

1.取消部分审批事项。对免于环境影响评价管理建设项目目录中的水利、农林牧渔、农副食品加工、交通设施、社会事业与服务业等五类项目，不需办理环评手续。

2.简化部分审批程序。依据原环保部《建设项目环境影响评价分类管理名录》规定，对填报环境影响登记表的农副产品加工、餐饮娱乐、手工业等项目，按照建设项目环境影响登记表备案管理工作要求，环评文件由审批制改为备案制，即报即受理。

3.严控重污染项目。不予审批《工业项目分类清单》中三类工业的新建项目和涉及重金属、持久性有机污染物排放等影响粮食生产安全的二类工业新建项目（矿产资源点状开发项目和符合省、市重大产业布局的项目除外）。

4.严控部分重污染项目。不予审批屠宰、酿造、含发酵工艺的粮食加工等废水排放量大且废水无法进入集中式污水处理厂处理或无法达标排放的项目。

（四）特殊环境敏感区

各级各类自然保护地及生态保护红线，作为特殊环境敏感区，要以确保区域生态安全为目标，实施强制性保护，严守生态红线。

1.从严审批建设项目。在特殊环境敏感区内，不予审批任何有污染物排放或造成生态破坏的建设项目；除文化自然遗产保护、森林防火、应急救援、环境保护和生态以及必要的旅游、交通、电网、通讯、防洪、管道等基础设施外，原则上不予审批其他基础设施工程（国家另有规定的从其规定）。

2.严格保护饮用水源。在饮用水水源一级保护区内，不予审批与供水设施和保护水源无关的建设项目；在饮用水水源二级保护区内，不予审批排放污染物的建设项目。

四、保障措施

（一）减少审批前置

对选址符合土地利用规划和城乡规划等区域控制性规划的项目，其国土、规划、文物、林业等部门的审批意见不作为环评文件受理前置条件。对涉及法定保护区域的项目，在符合法律法规规定的前提下，主管部门意见不作为环评审批的前置条件。

（二）优化总量管理

对已有重点污染物排放总量指标、不增加排放量的项目，环评审批取消污染物排放总量确认手续；对需增加主要污染物排放量的，简化确认手续，总量确认文件由业主提供替代为生态环境部门内部核查。

（三）推进网上审批

积极推进环境管理信息化建设，推行建设项目环境影响评价和竣工环保验收网上审批系统，逐步实现网上受理、办结，提升网上办事服务能力，缩短审批时限，提高审批服务效率。

（四）完善规划环评和项目环评联动机制

对未通过规划环评的园区，不得受理入区建设项目的环评文件；对纳入规划的建设项目，在规划环境影响报告书经有审查权的环保部门审查通过后，符合主体功能和主要产业的建设项目，其环评文件内容可适当简化。

（五）健全同步机制

园区污水集中处理、固体废物处理（处置）、集中供热、集中供气、风险应急等设施，应与园区同步规划，同步建设，实现污染集中控制，提高环境容量利用效率；建立完善入区项目审批与环保基础设施联动机制，对污水集中处理设施、集中供热、固体废物处理（处置）等设施建设严重滞后的园区，暂缓审批其新增相应污染物排放的三类工业项目。

（六）强化监督管理

健全建设项目全过程监管长效机制，负责审批环评文件的生态环境部门应与建设项目相应部门建立联动管理、协调和信息共享机制，落实监管职责；对实施备案管理的环境影响登记表项目，生态环境部门要加强监督检查，督促项目在建设及运营过程中遵守环境保护法律法规和标准，防止出现环境违法问题,定期检查环评审批和备案情况，确保准入标准不降低，监管力度不放松；进一步加强对建设项目执行“三同时”制度的事中事后监管，确保各项环评要求落实到位；加强环境影响评价中介市场、中介机构的监督管理，确保环境影响评价文件质量。

五、附则

（一）本方案所涉国家、省产业政策和环境管理要求发生变化的，则按照新规定执行。

（二）本方案所列四种类型分区尚未涵盖的区域，参照农产品主产区的环境准入政策执行。
