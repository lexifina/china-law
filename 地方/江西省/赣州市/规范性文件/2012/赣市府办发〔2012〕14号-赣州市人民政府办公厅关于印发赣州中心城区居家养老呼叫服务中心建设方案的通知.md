# 赣州市人民政府办公厅关于印发赣州中心城区居家养老呼叫服务中心建设方案的通知

赣市府办发〔2012〕14号

赣州市人民政府办公厅关于印发

赣州中心城区居家养老呼叫服务中心建设方案的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

《赣州中心城区居家养老呼叫服务中心建设方案》已经市政府研究同意，现印发给你们，请认真贯彻实施。

二○一二年五月四日

赣州中心城区居家养老呼叫服务中心建设方案

为推进社区居家养老服务工作，加快居家养老服务信息化建设，力争把“赣州中心城区居家养老呼叫服务中心”建设成为布局合理、设施完善、功能齐全、服务周到、深受老年人喜爱的“没有围墙”的养老院，结合我市实际，制定本方案。

一、工作目标

通过建设呼叫服务中心，使居家老年人只要通过一部电话（一键通）和一个网络平台，就能享受到配餐送餐、保洁清扫、医疗陪护、日间照料、休闲娱乐、精神慰藉、紧急救助等方便快捷的各项居家养老服务，达到构建社区居家养老“15分钟”服务圈的目标。

二、建设模式

按照低成本、广覆盖、高效率的原则，实行“政府授权、企业建设、市场运作、政策扶持、社会参与、部门监管”的建设模式。

三、建设规模

根据经济实力、场地设施、经营管理等资质条件，通过调研考察，确定赣州添立市民幸福促进中心（民办非企业单位）承建赣州中心城区居家养老呼叫服务中心，并负责招募各类企业加盟开展居家养老各项服务。赣州中心城区居家养老呼叫服务中心建设地址选在章贡区大公路2号赣州添立养生院内，使用面积1200平方米，估算投资600万元，2012年计划呼叫服务中心内设50个呼叫电话座席。居家养老服务范围为章贡区和赣州开发区的城区居家老年人，并逐步将南康市和赣县的城区居家老年人纳入赣州中心城区居家养老呼叫服务中心的服务范围。

四、功能设置

赣州中心城区居家养老呼叫服务中心由网络通信平台、老人接待中心、呼叫指挥中心、加盟服务企业管理中心组成一套完整的服务系统，实现老年人各类需求的快捷响应、专业服务和过程监督。

（一）网络通信平台。1.呼叫终端。即电话（或一键通），具备通话和紧急呼叫功能，居家老人可通过终端随时方便快捷地进行服务呼叫；2.呼叫接收平台。24小时接收呼叫，根据需求安排加盟企业进行服务，并对服务时间、服务质量及时跟踪；3.服务监督平台。居家养老业务主管部门和社区可对每次服务进行查询、回访和评价，并对服务中存在的问题提出整改意见。

（二）老人接待中心。负责建立老年人信息库、扩大用户量和收集服务需求，开展老年人心理咨询和法律咨询、法律援助以及为老服务志愿者注册管理等服务。

（三）呼叫指挥中心。以信息技术为平台，老年人通过电话请求服务，呼叫指挥中心向加盟企业派出工单，组织加盟企业服务老人，负责汇总老人需求数量及服务结果，并对软件进行维护升级。

（四）加盟服务企业管理中心。负责考察确定服务加盟企业、建立企业信息库以及服务人员的备案管理，协调落实各种为老政策、确定服务项目标准价格和政府购买服务补贴的结算。

五、组织实施

赣州中心城区居家养老呼叫服务中心建设的责任主体是赣州市民政局，赣州市老龄办具体负责组织实施，民政、老龄部门共同负责协调呼叫服务中心的建设运营和有关优惠政策的落实，以及对居家养老服务质量进行监管。赣州添立市民幸福促进中心负责呼叫服务中心的投资建设和居家养老服务的市场化运营，中心建设包括场地选址、硬件设施、通信网络、软件平台等，服务运营包括建立老年人信息库、招募企业加盟并建立企业信息库、开展各项居家养老服务以及对服务人员和加盟企业进行管理等。

六、时间安排

第一阶段：2011年底，拟定建设方案，做好项目建设的报批等前期工作。

第二阶段：2012年1—4月份，完成硬件设施、通信网络、软件平台等“一平台三中心”建设。

第三阶段：2012年5-7月份，建立老年人信息库、招募企业加盟、发放终端设备，开展居家养老呼叫服务试运营。

第四阶段：2012年8-10月份，呼叫服务中心全面竣工，正式投入使用。

七、保障措施

（一）加强组织领导。成立由赣州市政府分管副秘书长担任组长，市民政局局长担任常务副组长，市民政局分管副局长、市老龄办主任、市财政局和章贡区政府分管领导担任副组长的赣州中心城区居家养老呼叫服务中心建设工作领导小组，成员由市民政局、市财政局、市老龄办相关科室负责人和章贡区相关部门负责人组成。章贡区政府要积极配合抓好呼叫服务中心的建设。章贡区、赣州开发区各街道要成立由街道办主任任组长的居家养老服务工作小组，成员由分管副主任、民政所长（老龄工作负责人）、社区居委会主任组成，主要负责对辖区居家养老服务对象开展入户调查、受理申请、审核、登记造册，评审和发放重点对象居家养老购买服务补贴，宣传、指导和管理居家养老服务工作等。

（二）加大资金投入。赣州中心城区居家养老呼叫服务中心建设投资由赣州添立市民幸福促进中心负责承担。赣州市政府对建成后的呼叫服务中心给予一定额度（按投资总额的25-30%比例）的一次性建设补助。章贡区政府、赣州开发区管委会对辖区内下列城区居家重点老年人对象，即60岁以上生活难以自理的“三无”老人、重点优抚对象、市级以上劳动模范、因病因残的特困老年人（低保对象），发给每人每月不低于50元的居家养老服务券，分类给予政府购买补贴（具体补贴标准由当地政府确定），老年人凭券选择呼叫服务中心明码标价的服务项目。

（三）落实优惠政策。居家养老呼叫服务中心建设是一项社会福利事业，也是一个系统工程。为保证其持续运营、老人长期受益，各有关部门要密切协作，形成合力，按照各自职责积极开展工作，并根据省、市人民政府关于加快养老服务事业发展的意见规定，落实好居家养老呼叫服务中心建设用地、设施用房和税费减免等优惠政策。

（四）建立评估机构。建立赣州中心城区居家养老服务评估工作小组，市政府分管副秘书长担任组长，市民政局局长担任常务副组长，市民政局分管副局长、市老龄办主任、市财政局和章贡区政府分管领导担任副组长，成员由市民政局、市财政局、市老龄办相关科室负责人和章贡区相关部门负责人组成，主要职责是对居家养老服务质量进行监督评价。对服务质量差、群众意见大的服务企业，评估小组责成其限期整改。

各县（市）参照本方案制定符合本地实际的居家养老呼叫服务中心实施方案。
