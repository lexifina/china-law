# 赣州市人民政府办公厅关于深入推进粮食稳产增产十大行动切实抓好2012年粮食生产工作的实施意见

赣市府办发〔2012〕19号

赣州市人民政府办公厅关于

深入推进粮食稳产增产十大行动切实抓好

2012年粮食生产工作的实施意见

各县（市、区）人民政府，市政府有关部门，市属、驻市有关单位：

为认真贯彻落实中央、省委1号文件及全国、全省农业工作会议精神，进一步推动我市粮食生产稳步发展，根据省政府办公厅《关于深入推进粮食稳产增产十大行动确保2012年完成410亿斤目标的实施意见》（赣府厅发〔2012〕18号），结合我市实际，现就贯彻落实粮食稳产增产十大行动，切实抓好2012年粮食生产工作，提出如下实施意见。

一、指导思想

认真贯彻落实中央、省委1号文件及全国、全省农业工作会议精神，牢牢把握赣南苏区振兴发展重大战略机遇，全面落实各项强农惠农富农政策，提高农民种粮积极性，以稳定粮食播种面积为基础，以科技进步为着力点，大力实施粮食稳产增产技术措施，主攻粮食单产，增加粮食总量，确保粮食安全，保护和提高粮食综合生产能力，进一步推动粮食生产的发展。

二、目标任务

通过粮食稳产增产十大行动，2012年全市粮食播种面积稳定在805万亩左右，粮食总产达290万吨，其中水稻播种面积740万亩左右，稻谷总产280万吨以上。各地粮食播种面积和粮食产量指导性目标详见附件。

三、实施内容

（一）政策支持行动。将中央预拨的各项粮食补贴资金，及时足额兑现到户，严格补贴发放程序，加强督促检查，确保政策落实不走样、给农民的实惠不缩水；进一步加大农机购置补贴力度，利用购机补贴政策导向不断优化农机装备结构；严格落实国家粮食最低收购价政策，保护好农民种粮积极性；继续实行种粮大户补贴。大力实施水稻政策性保险，积极改善农村金融服务，加大对种粮大户、农机大户、专业合作组织和粮食加工龙头企业的信贷支持；紧紧围绕粮食生产能力建设，积极谋划项目，争取更多的资金支持。

（二）粮田建设行动。根据《关于整合资金建设高标准农田的指导意见》（赣府发〔2011〕19号）文件精神，进一步加快所有涉及农田水利基础设施建设项目资金的整合力度，按照全市高标准农田建设统一规划，科学规范，加强协调，确保建设任务按时完成。加快2011年度粮田建设项目建设进度，科学安排好在建田间工程，确保2011年整合资金粮田建设项目如期完工，不误农时，早日见效。

（三）科技促进行动。加大集中育秧示范推广力度，重点推广早稻塑盘集中育秧技术。大力推广超级稻及其配套高产高效栽培技术，力争全年超级稻应用面积达200万亩以上。大力推广抛秧等轻简栽培技术，力争全年抛秧应用面积达500万亩以上。继续深入开展“多用一斤种，增收百斤粮”技术推广活动，确保水稻种植密度。大力开展基层农技人员能力提升培训，增强基层农技人员科学种粮技术服务能力和指导水平。

（四）高产创建行动。规划建设15个水稻万亩高产创建示范片以及信丰嘉定镇、兴国高兴镇2个水稻高产创建整乡制推进的地方积极探索高产创建新模式、新方式和新机制，带动更多农户参与高产创建示范活动，努力促进水稻大面积均衡增产，切实推动我市高产创建再上新水平。

（五）良种推广行动。建立健全现代种业科技创新体系，加快培育和引进一批水稻新品种。大力推进水稻新品种展示示范，加快新品种推广应用。积极做好新品种区试，广泛宣传和推介主导品种，提高良种推广服务能力。力争新品种年更换率20%以上，良种覆盖率95%以上。

（六）配方施肥行动。通过深化“示范乡”创建、狠抓“配方肥”下地、落实“示范片”到村、举办“培训班”进田、强化“建议卡”上墙、推进“触摸屏”进店、开展“施肥预告”服务等关键性措施，全面推进测土配方施肥行动。全市推广测土配方施肥技术面积685万亩以上，其中配方肥施用面积20%以上。深入推进有机质提升行动，推广秸秆腐熟还田面积60万亩，种植绿肥面积110万亩。力争肥料利用率提高3个百分点。

（七）统防统治行动。积极扶持专业防治组织，引导专业防治组织逐步实现运作市场化、管理制度化、人员专业化、技术标准化、作业规范化、装备现代化和服务优质化，提高专业防治效果和服务水平。鼓励开展全程承包服务和跨区作业，每县至少扶持发展一个全程承包服务面积不少于500亩的标准化专业防治组织，专业防治承包服务面积力争增长20%。大力推广非化学防治和科学用药等绿色植保农药减量技术，减少化学农药用量。每个县建立绿色植保农药减量示范区1个，面积不少于500亩。力争高效安全对路农药使用面积达到50%以上，生物农药使用面积增长10%，化学农药用量减少10%以上。

（八）农机应用行动。继续开展“推进机插秧、创建高产县”活动，以水稻工厂化育秧示范为重点，大力推广水稻机械化育插技术，不断扩大机插秧面积，力争全市机插面积64万亩，机插率达8.8%。积极做好“百万农机闹春耕”、“农机双抢大会战”和“农机化秋收冬种”等关键农时农机服务活动。精心组织农机跨区作业，推进跨区作业由机收向机播、机耕、植保等领域扩展，不断扩大作业范围，提高作业效益。逐步实施农机专业合作社的税费减免、信贷支持、机库棚建设等扶持措施，促进农机专业合作社的稳定发展。

（九）防灾减灾行动。加强农业气象灾害监测预警，全力做好主要农时季节农业气象灾害趋势分析，及时制定防灾减灾应急预案，适时启动应急响应，做到主动避灾、科学防灾、有效减灾。加强病虫灾害的监测预警和防治指导，完善公共植保体系建设，落实乡镇植保员制度，做到监测系统、预报准确、发布及时、指导科学、宣传到位。切实做好灾情调度和灾害损失评估等工作。开展以增施叶面肥为主要措施的水稻防早衰工程。积极向上争取农业防灾减灾稳产增产关键技术良法补助，不断提高防灾减灾技术落实到位率。

（十）农资整治行动。进一步加强农资市场调控，搞好良种、化肥、农药、秧盘、柴油等农业生产资料的调配、储运及供应，优化电力调度，确保粮食生产物资供应和用电需要。加强对农资产品和经营主体的资质审查，坚决取缔无证生产经营农资的单位和个人，强化对农资批发市场、专业市场、集散地和经营门店的日常监管。抓住春耕备耕、双抢、冬种等重要农事季节，加大对种子、肥料、农药、农机具等农资产品质量和价格的监管，坚决打击哄抬农资价格和制售假冒伪劣农资的违法行为，切实维护好农资市场秩序。启动农业综合执法标准化建设，增加执法经费投入，改善执法装备和条件，深入推进农业综合执法，积极推行“检打联动”，确保农资合格率整体上升1个百分点，促进全市粮食生产健康发展。

四、工作措施

（一）加强组织领导，健全工作机制。各级政府要把粮食稳产增产十大行动放在突出位置，摆上重要议事日程，做到主要领导负总责，分管领导具体抓。科学制订工作方案，明确工作职责，强化工作措施，把粮食生产指导性目标任务逐级分解落实到乡村和田块。将十大行动按内容分别落实到相关职能部门，精心组织，周密安排，凝聚多方智慧和力量，齐心协力推进十大行动。建立健全督导检查制度，在关键农时季节，及时开展工作督导，帮助基层解决实际困难，推动各项措施落实。

（二）加强政策扶持，提升服务水平。各地要切实加大对发展粮食生产的扶持力度，出台更多的优惠扶持政策。加快基层农业技术推广体系改革步伐，创新农技推广方式，积极开展“农业科技促进年”活动，不断提升科技服务水平。推进土地承包经营权流转规范化服务试点，积极引导土地承包经营权有序流转，发展多种形式的粮食生产适度规模经营。扶持和引导与粮食生产有关的合作组织，积极参与粮食稳产增产十大行动，提升专业化服务能力。加大对粮食加工龙头企业扶持力度，大力发展粮食精深加工，积极创建粮食产品品牌，提高粮食产品市场竞争力。

（三）加强宣传示范，营造良好氛围。各地要加强示范基地建设，精心选好示范点，落实示范责任，做到主要领导挂帅，技术干部驻点，确保示范一片成功一片，示范带动大面积平衡增产。充分发挥新闻媒体的舆论导向作用，坚持多渠道、立体式、高密度地宣传发动，及时总结和宣传好经验、好做法、好成效，以点带面，形成典型示范效应，使活动深入农村、贴近农户、扎根田间，为深入推进粮食稳产增产十大行动营造良好的社会舆论氛围。
