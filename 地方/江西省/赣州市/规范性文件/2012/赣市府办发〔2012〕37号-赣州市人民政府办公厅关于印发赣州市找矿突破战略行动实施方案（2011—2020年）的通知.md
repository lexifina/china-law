# 赣州市人民政府办公厅关于印发赣州市找矿突破战略行动实施方案（2011—2020年）的通知

赣市府办发〔2012〕37号

赣州市人民政府办公厅

关于印发赣州市找矿突破战略行动实施方案

（2011—2020年）的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

经市政府同意，现将《赣州市找矿突破战略行动实施方案（2011—2020年）》印发给你们，请结合实际，认真贯彻执行。

2012年10月1日

赣州市找矿突破战略行动实施方案

（2011—2020年）

为贯彻落实省政府办公厅《关于印发江西省找矿突破战略行动实施方案（2011—2020年）的通知》（赣府厅发〔2012〕27号）精神，结合我市实际，提出我市找矿突破战略行动实施方案：

一、指导思想

坚持以科学发展观为统领，贯彻落实节约资源与保护环境的基本国策，遵循地质工作规律和市场经济规律，以实现地质找矿重大突破为核心，全面推行“公益先行、商业跟进、基金衔接、整装勘查、快速突破”地质找矿新机制，着力打造以市场需求为导向、以政府宏观调控为手段的多元投资制度平台，利用好各方资金，做好规划，促进矿产资源勘查开发，努力实现地质找矿重大突破，为促进我市经济社会可持续发展提供强有力的矿产资源保障。

二、基本原则

（一）近期重点突破与长远可持续发展相结合。在开发条件好、找矿潜力大的地区和资源潜力较大的老矿山周边和深部，统筹部署安排，集中优势力量实现找矿突破，提高资源保障能力。同时，着眼长远，持续加大基础性地质工作及找矿潜力研究，形成一批后备普查基地。

（二）加大财政投入与拉动社会资金投入相结合。明确各类地质找矿投入定位。加大财政对有望取得重大突破区域的勘查前期投入，努力降低商业性矿产勘查风险；同时充分发挥市场配置资源的基础性作用，鼓励、支持和引导社会资本投入地质找矿工作，积极构建多元投资、多方合作、协调有序、快速推进的制度平台，加快实现地质找矿重大突破。

（三）开辟新的资源基地与拓展老的资源基地相结合。积极开展重要成矿区带的矿产资源远景调查和成矿远景预测，提供新的矿产地，开辟新的矿产资源基地；同时充分依靠科技支撑，全面推进深部和老矿山外围找矿，大力实施“攻深找盲”战略，努力缓解现有大中型矿山的资源危机，提高资源供给能力，缓解资源紧缺瓶颈。

（四）实现地质找矿突破与提高资源利用效率相结合。扎实开展“紧缺和优势矿产资源保障工程”，努力实现地质找矿的重大突破，大幅新增矿产资源的可采储量。同时大力实施矿产资源综合利用示范工程，加强资源综合利用的科技攻关，解决利用资源及低品位资源利用的技术难题，用经济和技术手段提高矿产资源综合利用水平，积极发展绿色矿业，显著提高矿产资源综合利用效率。

（五）实现找矿突破目标与赣南苏区振兴发展相结合。抓住国家支持赣南苏区振兴发展的有利时机，用好《国务院关于支持赣南等原中央苏区振兴发展的若干意见》（国发〔2012〕21号）相关政策措施，积极向上争取中央地质勘查资金和财政专项资金找矿项目，努力实现地质找矿重大突破，促进赣州经济加快发展、转型发展、跨越发展。

三、工作目标

（一）总体目标：保障赣州市钨、稀土、萤石、铀等优势矿种的优势地位，兼顾金、银、铜、铅锌、钼、锂、水泥灰岩等紧缺和重要矿种。在2012—2020年期间，新增资源储量分别达到：钨50万吨，稀土100万吨，铀X万吨，萤石2000万吨，金50吨，银1000吨，铜20万吨，铅锌30万吨，钼100万吨，锂5万吨，水泥灰岩2亿吨。我市优势矿产资源保障得到进一步加强。

（二）阶段目标：

1.用3年左右的时间，实现地质找矿的新进展。区域成矿地质规律研究和成矿模式研究获得新认识，地质矿产调查评价取得新的重要新成果，力争形成或提升3—7处大型矿产勘查开发基地，新增一批主要矿产的资源储量：钨10万吨，稀土20万吨，铀×万吨，萤石500万吨，钼20万吨，铜5万吨，铅锌10万吨，金10吨，银300吨，锂1万吨，水泥灰岩5000万吨。

2.用5年左右的时间，实现紧缺和优势矿产勘查重大突破。形成或提升8—10处大型矿产勘查开发基地，新增一批主要矿产的资源储量：钨20万吨，稀土50万吨，铀×万吨，萤石1000万吨，钼50万吨，铜10万吨，铅锌20万吨，金20吨，银600吨，锂3万吨，水泥灰岩1亿吨。

3.用8—10年的时间，重塑矿产勘查开发新格局。形成或提升15—20处大型矿产勘查开发基地，新增主要矿产的资源储量达到总体目标，我市优势矿种地位进一步加强，紧缺矿种和资源枯竭矿山的接续资源得以保障。矿产勘查开发形成良性循环，地质找矿工作健康有序发展，多元化投入的格局基本形成，勘查队伍的技术水平明显提升。

四、主要任务

（一）基础地质调查与研究。根据《江西省找矿突破战略行动实施方案（2011—2020年）》,优先安排雩山—九连山成矿带、赣县大埠—于都小东坑（钨稀土多金属）、龙南—定南（稀土）、桃山（铀多金属）、于都银坑—宁都青塘（银铅锌多金属）、崇义鹿井、全南黄洞—龙源坝(铀多金属)等6个重点突破区，以及中南武夷山铀钽铌铜钼多金属成矿亚带寻乌河草坑（铀铜多金属）重点突破区的1：5万区域矿产调查，各地勘单位要积极立项，争取国家资金和各类专项资金开展基础地质调查、矿产资源潜力评价和地质科研工作，进一步提高基础地质工作程度，为矿产勘查工作夯实基础。

（二）重要矿产资源勘查。

钨矿：主攻以石英脉型为主，兼顾云英岩型、矽卡岩型的钨矿资源调查评价（勘查）工作。选择在赣县—于都钨矿勘查区、崇余犹钨矿勘查区、定南岿美山钨矿勘查区、兴国张家地钨矿勘查区、全南网城岗—大吉山钨矿勘查区等作为突破区。前期初步优选崇义淘锡坑—高坌、崇义八仙脑—茅坪、崇义宝山钨多金属区、于都小东坑—罗仙岽钨多金属区、赣县合龙等地作为重点工作区，首先开展崇义淘锡坑外围钨矿调查评价、赣县罗仙岽—龙潭下钨矿远景调查，加大现有钨矿探矿权地质勘查工作；中后期对调查评价有利地段开展重点勘查或整合矿业权整装勘查，加强钨矿调查评价项目申报，以中央资金为主，带动现有钨矿探矿权的国有企业资金投入实现钨矿找矿突破。钨矿勘查主要由省地勘、省有色系统完成。

稀土矿：主攻中重稀土矿，兼顾轻稀土矿。主要在稀土国家规划矿区、稀土储备试点矿区和其它稀土远景区开展稀土调查评价和勘查工作。2012年完成现有矿山储量核实工作，开展赣县谢公坑、信丰县东坑—安远铜锣窝、定南县龙塘3个中央基金普查项目和省地勘基金稀土普查项目。计划2013年启动龙南、安远、信丰及赣县的5个（中）重稀土规划矿区以及稀土储备试点矿区调查评价工作；2015年安排全南、定南、寻乌、信丰和赣县5个中轻稀土规划矿区调查评价；其它远景区的勘查工作安排在2017年开展。由省地勘系统承担，负责取得中央资金项目，并实现稀土矿找矿突破。

萤石矿：主攻矿床类型为内生热液充填或交代型。以基础较好的兴国远景区为重点，兼顾全南—龙南远景区、宁都—石城远景区、瑞金—会昌等其他远景区，优选城岗—良村矿田，江背矿田、兴国古龙岗—宁都黄陂矿田、全南青龙山—寨头矿田、石城丰山矿田、崇义中坑口—金鸡岭矿田作为重点工作区。积极争取国家地质调查评价、中央和省地质勘查基金等资金支持，依托现有萤石探矿权、采矿权，引导商业性资金投入，加大资源勘查，实现萤石找矿目标突破。

铀矿：主攻火山岩型与花岗岩型，兼顾炭硅泥岩型及其它类型。主要在已知矿集区、矿田的深部及外围找铀。加强桃山、河草坑、全南黄洞—龙源坝、崇义鹿井、信丰隘高等重点铀矿区的铀矿普查；扩大桃山花岗岩型、河草坑火山岩型等铀矿田的储量规模。同时，开展其他铀多金属矿找矿远景区预查普查。2012年实施信丰县安西镇四个脑地区铀—金矿普查等4个中央地勘基金项目和省地勘基金项目。由省核工业系统地勘单位负责。

金银矿：主攻矿床类型为破碎带蚀变岩型和石英脉型。重点突破于都银坑—宁都青塘银铅锌多金属成矿区、兴国留龙—瑞金陈坑和上犹营前—崇义金坑钨锡金成矿区。以于都、兴国、瑞金、崇义、南康、信丰、赣县现有金银矿探矿权、采矿权为主，加强矿山生产勘探和探矿权勘查投入，实现金银矿找矿突破。

铜矿：主攻隐爆角砾岩型，兼顾破碎蚀变岩型。主攻地区为会昌红山、于都银坑地区。以会昌、于都等铜多金属矿探矿权为主，以崇余犹铜多金属矿探矿权为辅，加大勘查力度，寻求共伴生铜找矿突破，实现找矿目标。

地热：主要实施对流型地热远景带的勘查评价，包括上犹五指峰—营前—油石、石城、安远虎岗—孔田、会昌—瑞金、全南大庄—南迳、龙南夹湖—汤湖、定南岭背、寻乌、宁都石上—湛田、宁都肖田等地热远景区带勘查评价。近期完成会昌车心、龙南汤湖、寻乌南桥、寻乌河角等地热勘查工作。同时开展赣州中新生代盆地区域地热远景调查，推动洁净环保地热资源利用和休闲旅游业发展，促进我市能源结构改善与低碳经济发展。

铅锌：主攻类型为中低温岩浆热液型和破碎带蚀变岩型，重点工作地区为于都银坑地区。以现有商业性探矿权地质勘查为主，加强成矿规律的研究，尽早实现找矿目标。

钼矿：主攻斑岩型为主，兼顾石英脉型钼矿。主攻地区为安远县园岭寨、寻乌丹溪—桂竹帽地区、赣县大埠岩体周边、兴国雷公嶂一带、崇余犹地区。加快安远园岭寨和寻乌丹溪—桂竹帽等地斑岩型钼矿探矿权勘查，加大对赣县、兴国、崇余犹地区共伴生石英脉型钼矿探矿资金投入，缩短勘查周期，实现找矿突破。

锂矿：主攻类型为伟晶岩型，以宁都河源地区为重点开展普查，以现有矿业权人为主体，在采矿权证内及其深边部以及省地勘基金项目进行锂矿找矿突破。

黑滑石矿：以沉积岩型为主要矿床，重点在于都小坌—长洛一带。以综合研究为主，辅以工程验证，开展调查评价，实现找矿目标。

水泥用灰岩矿：以海相沉积型为主要矿床类型，重点选区为信丰丫叉桥、瑞金市云石山—猫子寨、瑞金沙洲坝—洁源、会昌鹅公岽、于都金鸡山、崇义宝山、崇义半坑。鼓励以资源整合以及公开出让矿业权等方式，加大石灰岩资源勘查，查明资源储量，为我市水泥企业提供资源保障。

（三）大中型老矿山深边部找矿。2012年实施下垄钨矿左拔矿区接替资源勘查项目，2013年开始陆续向国家申报取得画眉坳钨矿区、盘古山钨矿区、漂塘钨矿区、西华山钨矿区、岿美山钨矿区、大吉山钨矿区、铁山垅钨矿区等大中型老矿山开展深边部综合勘查和综合评价项目。力争为老矿山提交8万吨钨资源储量。有色地勘单位要积极争取中央财政的专项资金，与市内国有大中型矿山企业配套资金相结合，以稳定和增强现有大中型矿山产能为目标，按照“探边摸底，攻新找盲”的思路，在大中型老矿山深部和外围寻找新储量，缓解老矿山资源危机，延长大中型老矿山服务年限，并利用共生钨矿的其它探矿权勘查形成一批老矿山接续资源基地。

（四）矿产资源节约与综合利用。构建矿产资源节约与综合利用监督管理的长效机制，在矿产资源开发的全过程，坚持“开源与节流并举、开发与保护并重”的方针，建立健全管理制度和相关技术标准。推广先进技术和管理制度，激励矿业企业科技创新和人才培养，加快科技成果转化，实现难利用资源开发利用的规模化和产业化，不断提高矿产资源节约与综合利用水平。加快矿产资源开发利用方式的转变，发展矿产资源领域循环经济，建设资源节约型、环境友好型绿色矿山。

1.提高矿产资源开发利用水平。提高矿产资源开采回采率、选矿回收率，减少储量消耗和矿山废弃物排放。钨矿开采回采率平均保持90%以上，选矿回收率平均保持在85%以上。煤矿开采回采率平均保持在83%以上。同时开展低品位矿开发利用研究，推广应用选矿新技术和新工艺。

2.加强矿产资源综合利用。建立赣南钨矿资源综合利用基地和赣州稀土资源综合利用示范基地，基地建设规划期为2012—2015年；尾砂综合资源回收等项目远期规划期为2016—2020年。2013年申报大余、崇义等地方钨矿资源综合利用示范基地。用示范基地建设来加快推动我市资源开发利用水平的整体提高、矿业发展方式的转变和矿业结构调整。加强低品位、共伴生矿产资源的综合勘查、综合评价与综合利用。市、县（市）矿产资源管理部门要加强示范基地项目实施监管，确保示范基地取得实效。

3.促进矿产资源领域循环经济发展。坚持“再勘查、减量化、再利用、资源化”和“低开采、高利用、低排放”的原则，以资源节约型、清洁生产型、利废环保型为重点，加强矿山固体废弃物、废水、尾矿资源和废旧金属利用，实施矿产资源领域循环经济示范工程。促进有利于节约资源、保护环境的资源开发利用与矿山发展模式，推进绿色矿山建设。2012年申报12个国家级及省级绿色矿山试点。开展赣南稀土矿尾矿综合利用与开发治理示范工程。

五、组织与保障

（一）加强组织领导。成立赣州市找矿突破战略行动工作领导小组，由市政府分管领导任组长，市政府分管副秘书长、市矿管局局长任副组长，市矿管局、市发改委、市财政局、市国土资源局、市林业局、市水利局、市公安局、市安监局、市环保局、市科技局、赣南地质调查大队、江西有色地质勘查二队、二六四大队为成员单位。领导小组负责找矿突破战略行动的统一领导、宣传动员、各阶段工作的检查落实，及协调解决地质勘查过程中遇到的问题和困难。领导小组办公室设在市矿管局，负责找矿突破日常工作、组织协调项目申报、实施和质量保证。各县（市、区）人民政府要成立相应的工作领导小组及办公室，组织开展找矿突破战略行动工作。

（二）落实工作责任。市矿管局作为找矿突破战略行动的第一责任人，负责牵头实施全市找矿突破战略行动；市发改委要加强找矿突破战略产业政策指导；市财政局负责协助保障找矿突破战略行动有关经费落实；市国土资源局、市林业局负责协调解决地质勘查工作野外施工过程中遇到的土地使用、山林权属等问题；市安监局、市环保局负责协调处理矿产资源勘查开发中的安全和环保问题；市公安局、市水利局负责协调解决矿产资源勘查开发中的火工产品、河道水利设施问题；市科技局负责协调技术成果评选推荐问题；各地勘单位负责技术力量保障。各县（市、区）、乡（镇）人民政府、市直有关单位要加大宣传，营造全社会了解、重视和支持找矿突破的良好社会氛围。要及时掌握各类勘查项目进展情况，加大打击违法违规矿业行为，维护矿业权人合法权益。

（三）完善矿业权管理。科学编制矿业权设置方案，有序布局出让矿业权。协助省国土资源厅做好对探矿权出让实行分区分类管理。低风险矿种（二类矿种）一律采取拍卖或挂牌的方式公开出让矿业权，无风险矿种（三类矿种）一律采用拍卖的方式公开出让采矿权。经批准采用协议方式出让矿业权的，价格比照同类产品市场价格。所有矿业权出让必须进场公开公示，接受社会监督。逐步推行重点突破区探矿权合同制管理。加强重点突破区主攻矿种的探矿权转让管理，优先考虑以矿业开发为主导的国内知名企业、综合实力较强的国有地勘单位和省内大中型矿山企业及相邻矿山企业与甲级资质地勘单位组成的利益共同体。坚持政府引导和市场运作相结合的原则，加强对矿业权的整合，将整装勘查区内主矿种的矿业权整合纳入到新一轮矿产资源整合工作范围；对圈而不探或勘查矿种与勘查许可证颁发矿种不一致的探矿权进行清理整顿；对整装勘查区内零星分散、非主矿种的采矿权扩界加以限制，通过合并、重组、收购等方式对设置不够科学合理的矿业权进行整合。

（四）发挥主体作用。要充分发挥地勘单位实施找矿突破战略行动主力军作用，在找矿突破战略行动过程中，各地勘单位要成立领导小组，负责保障项目取得和落实、人员配置到位、项目成果质量等，充分调动本单位找矿突破战略行动的主动性。各级政府作为找矿突破战略组织实施主体，要大力支持地勘单位提升队伍整体素质和科技创新能力，确实解决地勘单位在编制、人员经费等方面问题，为找矿突破战略行动实施提供技术支持和智力保障。要鼓励和帮助地勘单位建立找矿突破管理机制，全力支持地勘单位争取各类基金项目或社会资金勘查项目，多方位筹集资金开展地质勘查，多方式合作进行地质找矿。

（五）加强矿业权市场建设。加强探矿权出让总量控制，调节供需平衡，引导市场价格，促进矿业权市场的持续健康发展。进一步加强矿业权有形市场建设，全面推进矿业权网上交易管理。建立矿业权信息发布、查询和公开交易制度，规范矿业权网上交易行为。促进资本和技术的合作。鼓励和支持地勘单位向“探采一体化”模式转变。建立中介服务信誉评估体系和中介行业自律、责任追究制度，加强对中介机构和从业人员的监督管理。加强对矿业权招标、拍卖、挂牌的监督检查，对矿业权交易过程中出现的违法违纪行为依法依规予以查处，提高对矿业权市场的监督管理水平。

（六）争取各类资金支持。积极争取中央财政专项资金、国土资源大调查资金等财政资金的支持力度，加快重要成矿区带的公益性、基础性、战略性调查工作，提高基础地质研究程度；协助大中型矿山及地勘单位积极申报老矿山找矿项目，大力实施矿山密集区深部战略性勘查工作和资源危机矿山接替资源勘查工作；协助地勘单位积极争取中央和省地质勘查基金项目，加大重要矿产勘查力度。同时，进一步调动和发挥社会资金进入商业性勘查领域的积极性和主动性，引导和拉动社会各类资金进入矿产资源勘查领域，努力形成矿产勘查多元化投入机制。

（七）加强考核联动。逐步形成“政府主导、部门联动”工作机制，建立找矿突破考核制度，将找矿突破战略行动实施工作纳入对县（市、区）政府、市相关单位工作考核体系，对工作成效突出的予以奖励，对工作不力的给予通报批评。市直相关单位要加强配合，各负其责，相互协作，形成合力，有效推动我市找矿突破战略行动的实施。
