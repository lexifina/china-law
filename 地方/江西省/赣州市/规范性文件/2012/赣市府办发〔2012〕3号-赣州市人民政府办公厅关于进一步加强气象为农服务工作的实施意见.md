# 赣州市人民政府办公厅关于进一步加强气象为农服务工作的实施意见

赣市府办发〔2012〕3号

赣州市人民政府办公厅

关于进一步加强气象为农服务工作的实施意见

各县（市、区）人民政府，市政府有关部门，市属、驻市有关单位：

为贯彻落实《关于加强农业气象服务体系和农村气象灾害防御体系建设的意见》(赣府厅发〔2011〕66号)文件精神，充分发挥气象服务在“三农”工作中的基础保障作用，切实做好我市农村防灾减灾工作，经市政府同意，现就进一步加强气象为农服务工作提出如下实施意见：

一、充分认识加强气象为农服务工作的重要性

我市是全省气象灾害最严重的地区之一。多年来，在市委、市政府的高度重视下，经过各级、各部门的共同努力，我市气象防灾减灾工作取得了显著成效，但农业农村气象灾害防御能力依然薄弱。受全球气候变化加剧的影响，当前极端天气日益增多，气象条件不确定性更为复杂，而随着农村经济社会发展，农业生产、农村发展、农民生活则对气象服务提出了更高的要求，需求也更迫切。因此，加强新形势下气象为农服务工作，对提高农村防灾减灾能力、保障广大农民生命财产安全、确保农村经济社会的可持续发展具有重大意义。

二、明确气象为农服务的指导思想、原则和目标

（一）指导思想：以科学发展观为指导，围绕农村改革发展的总体要求，统筹集约各种有效资源，以提升农业气象灾害监测预警能力、农业气候资源开发能力、农业应对气候变化能力和农村气象灾害防御能力为重点，全力推进“两个体系”建设，切实发挥气象为农服务的职能和作用，为全市农村经济社会的可持续发展提供气象保障。

（二）基本原则：按照公共气象服务城乡均等化发展的要求，遵循“政府领导、财政保障，部门合作，气象主办，大户辐射、农户参与，统筹规划、突出重点，整合资源、信息共享”的原则，结合各地需求，立足现有基础，科学合理布局，强化薄弱环节，完善网络系统，延长服务链条，积极推进农村气象技术装备和其他防灾减灾基础设施建设。

（三）工作目标：用5年的时间，在全市范围内建立适应农业产业化发展要求的农业气象观测网络系统，构建结构科学、布局合理、功能先进的市、县、乡、村四级农业气象服务体系；完善适合我市实际的农村应急减灾组织体系，建立覆盖面广的农村气象预警信息发布网络，构建市、县、乡、村、户五级有效联动的农村气象灾害防御体系。实现防御规划到县（市、区）， 组织机构、自动观测、精细预报、气象信息服务站到乡（镇），应急预案、风险调查、科普宣传、气象信息员、预警信息发布到村。力争农业气象灾害预报准确率达到75%以上，农村灾害性天气预警信息能提前15—30分钟以上发出；气象为农服务信息能够覆盖100%的农民专业合作组织和85％以上的农户；农民专业合作组织对气象服务的满意度达到90％以上，农户对气象服务的满意度达到80％以上；95％以上的农民专业合作组织和80％以上的农户能够科学地使用气象为农服务信息。

三、深入推进气象为农服务体系建设

（一）加强专业化的农业气象监测预报技术系统建设。在保持现有农业气象观测站网格局基本稳定的前提下，以充分满足地方需求、代表区域农业特色和兼顾平衡分布为原则，结合各地现代农业示范区建设，安装必要的农业气象观测仪器，开展农田小气候观测，提高脐橙、生猪、蔬菜、花卉苗木、油茶、工业原料林等产业和特色产业的气象监测服务能力；开发农用天气、土壤墒情与灌溉量、特色农作物产量等预报技术，建立满足需求的农业气象指标体系和服务系统。加强农业气象灾害立体化监测与诊断，建立完善农业气象灾害监测与诊断系统和农业气象灾害指标体系，逐步发展重大农业气象灾害的立体化实时监测、诊断分析和预报、预警与评估业务。

(二)加强保障粮食安全的气象服务。加强粮食生产气象条件、农田土壤墒情、作物长势等农业动态监测与评价，开展气候变化对农业种植结构、粮食生产影响评估和适应性分析，强化粮食作物产量预报、年景预报、农事活动天气预报和农作物病虫害预报，确保粮食生产“灾年少减产、平年能增产、丰年多增产”。

（三）加强农民专业合作组织气象服务工作。健全农民专业合作组织气象服务联系卡制度，开展需求调查和服务反馈。以农民专业合作组织为对象，围绕脐橙、生猪、蔬菜、花卉苗木、油茶、工业原料林等主导产业及烟叶、黄鸡、水产、食用菌等特色产业，以产前、产中、产后各环节的气象服务需求为指导，整合已有的气象服务信息资源、农业气候区划产品和技术、信息传播资源和气候可行性论性技术，设计并制作针对性强、需求广、通俗易用的服务产品，并通过手机、广播、电视、电子显示屏、高音喇叭、报刊、互联网等渠道进行发布，确保农民专业合作组织能够及时收到气象服务信息，并通过农民专业合作组织将气象服务信息辐射到每个农户。

（四）加强农业抗旱防雹减灾人工影响天气服务工作。在全市农经作物主产区（含粮食、脐橙、烟叶、蔬菜、花卉等）、大型水库集水区建设人影示范工程，加强赣州飞机人影作业基地建设，形成地空立体化作业体系，提高农业增雨抗旱、防雹减灾、水库增蓄等作业能力。建立地空相结合的人影监测网、统一协调的指挥体系和功能先进的人影指挥中心，不断提高人工影响天气的作业指挥水平和能力。加强队伍和作业机制建设，建设一支管理规范、业务精通、作业服务能力强的人影为农服务专业化队伍，适时在农业易旱区、农村缺水区、现代农经作物区、林区开展抗旱、防雹、水库增蓄等作业。

（五）加强乡（镇）、村级综合气象信息服务化站（网）建设。结合“信息入村”工程，按照“有固定场所、有信息设备、有信息员、有定期活动、有管理制度、有长效机制”的标准，加强乡（镇）和村级气象信息化站（网）建设。依托新农村建设网，建设市、县两级农村用户气象服务信息平台；整合农粮、林业、水利等多部门、多学科专家队伍，组建农业专家联盟，以及由专业技术骨干、种养能手和种养大户等组成的农民专家队伍，完善信息资源、网络和共享平台，开展信息互动业务。

（六）加强农业气象服务技术创新工作。加快促进农业气象科研成果的应用转化，针对设施农业、特色农业、精细农业、订单农业、创汇农业、绿色农业、高效农业集中科技攻关，大力开发适合“一乡一品、一县一业”的农业气象适用技术。合理开发利用农业气候资源，加强农村风能、太阳能等清洁能源的普查和区划。组织开展精细化的农业气候区划和农业气象灾害风险区划，大力推进政策性农业保险和脐橙、烟叶保险气象服务工作。

四、大力加强气象为农服务防御体系建设

（一）加强农村气象灾害监测预警预报能力建设。建设和完善农村气象灾害综合监测预警系统，继续推进全市乡(镇)、村中小尺度灾害性天气监测站网建设，2015年前实现每个乡（镇）至少建设1套多要素区域气象观测站。重点加强中小河流、山区丘陵暴雨(尤其是病险水库、山塘、尾矿坝所在地区暴雨)和地质灾害易发、频发区的自动气象站建设，着重在气象灾害关键区域和敏感区布设雷电监测仪，切实增强对突发气象灾害的监测预警能力。加快乡村精细化气象预报系统建设，完善短时临近预报预警服务体系，提高农村灾害性天气气候的预报预警水平。

（二）加强农村气象灾害预警信息发布网络建设。建立综合性、多方式的农村气象灾害预警发布网络，力争至少有一种方式能将预警信息送达农村的每一个村点。县级建立气象部门和乡（镇）、行政村、中小学校的双向预警信息传递机制，完善手机短信和电话气象信息发布系统，利用手机短信、电子显示屏、高音喇叭、楼宇电视、公交移动电视、宣传车、电台和电视台等多种媒介及时发布气象灾害预警信息。乡（镇）要建立通知到村的双向预警信息传递机制，村级要建立通知到户的预警信息传递机制。

（三）加强农村气象灾害防御机制和应急减灾组织体系建设。县级编制出台气象灾害防御规划，组织开展精细化气象灾害区划和普查工作，建立气象灾害多因子综合风险评估和气候可行性论证、气象灾害防御明白卡发放、气象灾害隐患排查和气象灾情调查上报等制度。完善各级政府统一领导、综合协调，相关部门各负其责、有效联动的农村应急减灾组织体系。建立预案到村、责任到人的农村气象灾害应急处置体系，实现县乡有气象分管领导、乡乡有气象协理员、村村有气象信息员。组织抓好乡（镇）气象协理员和农村气象信息员队伍建设，加强气象协理员（信息员）队伍业务培训和管理。结合全国综合减灾示范社区等活动，在乡（镇）开展气象灾害应急准备认证工作。

五、切实强化气象为农服务各项保障措施

（一）加强组织领导。各县（市、区）政府要高度重视“两个体系”建设，并作为农村公共服务体系建设的重要组成部分，纳入当地经济社会发展规划，认真组织实施，强化监督检查，确保取得实效，根据省要求，从2012年起将气象灾害防御工作纳入政府绩效考核。发改、财政、国土、农粮、林业、水利、民政、教育、科技、气象、文广、通信等部门要加强协调配合，推进信息共建共享，共同做好综合服务，形成“两个体系”建设的整体合力。

（二）加强科技创新。各地、各有关部门要加强对农业气象灾害监测、预报、预警、评估及综合防御技术的研究，加强农业气象关键技术研发、试验示范和成果转化应用，为“两个体系”建设提供坚实的科技支撑。

（三）加强宣传引导。各地、各有关部门要通过电视、广播、报纸、网络等媒体，加大对“两个体系”建设重要意义、政策措施以及新进展、新经验的宣传，为“两个体系”建设营造良好的舆论氛围。大力开展农村气象防灾减灾科普宣教示范活动，在县级综合科普馆增设气象防灾减灾展区，在气象信息服务站（点）设立气象科普宣传栏，广泛宣传气象防灾减灾科普知识。同时，充分利用农村数字电影和科普大篷车，开展防灾减灾知识和技能宣传，提高群众防灾减灾意识和自救互救能力，最大程度地减轻气象灾害损失。
