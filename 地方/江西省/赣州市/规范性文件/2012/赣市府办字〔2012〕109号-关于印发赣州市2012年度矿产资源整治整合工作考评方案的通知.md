# 关于印发赣州市2012年度矿产资源整治整合工作考评方案的通知

赣市府办字〔2012〕109号

关于印发赣州市2012年度矿产资源整治整合

工作考评方案的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

《赣州市2012年度矿产资源整治整合工作考评方案》已经市政府研究同意，现印发给你们，请认真抓好落实。

二○一二年五月二十八日

赣州市2012年度矿产资源整治整合工作考评方案

为切实做好我市矿产资源整治和整合工作，保障矿业经济尤其是稀土、钨、萤石产业经济持续健康发展，根据有关法律法规和中央、省关于做好矿产资源整治和整合工作的要求，特制定本考评方案。

一、考评对象

各县（市、区）人民政府、市整顿和规范矿产资源开发秩序工作领导小组成员单位。

二、考评依据

（一）《国务院关于全面整顿和规范矿产资源开发秩序的通知》（国发〔2005〕28号）。

（二）《国务院办公厅转发国土资源部等部门对矿产资源开发进行整合意见的通知》（国办发〔2006〕108号）。

（三）省政府办公厅《关于印发赣州市稀土整治工作方案的通知》（赣府厅字〔2011〕28号）。

（四）市政府《关于印发赣州市稀土整治工作分工表的通知》（赣市府发〔2011〕182号）。

三、考评内容

考评内容包括积极组织开展矿产资源开发秩序整治、积极稳妥推进矿产资源整合、建立健全组织保障体系和组织领导、宣传教育、依法履行相关职责、参与配合整治整合情况等（详见附件）。

四、考评程序及步骤

（一）自查自评。各县（市、区）、市整顿和规范矿产资源开发秩序工作领导小组成员单位分别对照年度考评内容，逐项进行自查自评，并认真填写自评结果和先进单位、先进个人推荐表。

（二）组织考评。市整顿和规范矿产资源开发秩序工作领导小组办公室组织考评组，根据考评细则和各县（市、区）自查自评情况逐项评定，同时结合各县（市、区）、市整顿和规范矿产资源开发秩序工作领导小组成员单位日常工作的开展及成效进行综合考评，形成考评汇总材料，并提出先进单位和先进个人建议名单，报市整顿和规范矿产资源开发秩序工作领导小组审定。

（三）表彰奖励。对经审定的先进单位和先进个人由市政府进行表彰。并给予先进单位和先进个人各3万元、1000元奖励。奖励资金从省财政下拨的稀土整治专项经费或市级矿产资源扶持发展基金中列支。

五、奖项名额分配

（一）市矿产资源整治整合工作先进单位，县（市、区）政府评选6个，市整顿和规范矿产资源开发秩序工作领导小组成员单位评选6个。

（二）市矿产资源整治整合工作先进个人，各县（市、区）2名，市整顿和规范矿产资源开发秩序工作领导小组成员单位及领导小组办公室各1名。

六、其他要求

自查自评工作在下年的元月31日前完成。2011年度考评工作参照本考评方案执行，并在5月30日前完成（电话：8271551，传真：8271171）。
