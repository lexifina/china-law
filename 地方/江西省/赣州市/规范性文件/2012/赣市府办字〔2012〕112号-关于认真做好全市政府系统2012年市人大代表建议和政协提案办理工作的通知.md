# 关于认真做好全市政府系统2012年市人大代表建议和政协提案办理工作的通知

赣市府办字〔2012〕112号

关于认真做好全市政府系统2012年

市人大代表建议和政协提案办理工作的通知

有关县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

市四届人大二次会议和市政协四届二次会议提出并交市政府系统办理的人大代表建议、政协提案总计518件，其中人大代表建议269件、政协提案249件。为切实做好今年的办理工作，现就有关事项通知如下：

一、精心安排部署。各承办单位要进一步深化对办理工作重要性的认识，切实加强组织领导，把建议提案办理工作列入重要议事日程，精心谋划，周密部署，保证办理工作扎实有效推进。各承办单位在收到建议提案后（已于5月21日交办各承办单位），应认真核对内容，对建议提案不属于本单位职责范围，需要调整承办单位的，应在规定时间内向分管领导汇报并向市人大常委会选任联工委或市政协提案委及市政府督查室书面说明理由，经同意后退回，不得拖压搁置和自行转办。

二、确保办理质量。各承办单位主要负责人是建议提案办理工作第一责任人，要切实加强对办理工作的领导，健全和完善建议提案办理责任制，坚持实行“主要负责人负总责，分管负责人具体负责，办公室协调督办，承办处室办理落实”的分级负责制，促进办理工作的规范化、制度化，保证每一件建议提案都能落到实处。要加强沟通联系和密切协作，主办单位要切实负起牵头责任，协办单位要积极参与，共同协商制定办理方案。

三、严格办理时限。要根据国家法律法规政策和有关规定，严格按照建议提案办理的程序要求，做好办理工作。所有的人大代表建议政协提案从交办开始3个月内完成，即所有建议提案在今年8月底前必须办结回复。协办单位应当在交办之日起2个月内（即7月底前）将办理意见函告主办单位。

四、切实做好答复和征求意见工作。各承办单位要按统一格式行文答复代表、委员，并附《征询意见表》征求代表、委员意见，答复件及协办件均须抄送市政府督查室和市人大常委会选任联工委或市政协提案委。

五、认真处理代表和委员的反馈意见。要把“办理及时不及时、答复认真不认真、落实到位不到位、代表满意不满意”作为衡量办理工作的标准。代表委员对办理结果不满意的，有关承办单位要采取措施，加强与代表委员的沟通，认真向代表委员解释答复，进一步加大办理力度，并在1个月内再次答复代表委员，提高办理工作的办结率和满意率。

六、做好建议提案办理的总结工作。建议、提案办理工作结束后，要认真总结经验、查摆不足，树立典型，不断提高办理工作水平。办理工作书面总结请于9月10日前报送市政府督查室和市人大常委会选任联工委或市政协提案委。
