# 关于纠正在电力销售中以“路灯费”等名义加价乱收费行为的通知

赣市府办字〔2012〕114号

关于纠正在电力销售中以“路灯费”

等名义加价乱收费行为的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

近些年来，随着城镇规模的扩大和亮化、美化工程的实施，我市部分县（市、区）不同程度地存在违反规定，在电力销售中以“路灯费”和各种附加费等名义加价乱收费现象，加重了企业和人民群众的负担，社会反映比较强烈。根据《中华人民共和国价格法》、《中华人民共和国电力法》，以及国家计委、国家经贸委、财政部、监察部、审计署、国务院纠风办《关于整顿电价秩序坚决制止乱加价乱收费行为的通知》（计价格〔1998〕2212号）精神，经市政府同意，现就纠正在电力销售中以“路灯费”等名义加价乱收费行为有关事项通知如下：

一、充分认识纠正电力销售中乱收费行为的重要意义。纠正电力销售中的乱收费行为事关改革、发展和稳定的大局，事关企业和人民群众的切身利益，事关创业、宜居、平安、生态、幸福赣州建设。各县（市、区）人民政府要统一思想，高度重视，切实增强对纠正电力消费中加价乱收费工作重要性和紧迫性的认识，采取有力措施，加强电价管理，停止乱加价、乱收费行为，切实减轻企业和人民群众负担，为促进我市经济和社会事业又好又快发展创造一个良好的价格环境。

二、严格落实责任。各县（市、区）人民政府要对纠正电力销售中的加价乱收费行为负总责，督促供电部门纠正以“路灯费”等名义违规提高电力用户销售电价的行为，纠正工作务必在6月15日前全部到位。对纠正不力，有令不行、有禁不止，造成不良影响的，要追究相关责任单位和责任人的责任。

三、加强督促检查。纠正电力销售中的加价乱收费行为工作的督查和验收，由市政府纠风办牵头，市物价局、市监察局、赣州供电责任有限公司配合。请各县（市、区）人民政府于7月底前将纠正电力销售中加价乱收费行为的工作情况，书面报市政府纠风办。

二○一二年六月二日
