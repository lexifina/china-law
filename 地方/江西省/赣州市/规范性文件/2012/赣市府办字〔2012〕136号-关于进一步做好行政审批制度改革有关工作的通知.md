# 关于进一步做好行政审批制度改革有关工作的通知

赣市府办字〔2012〕136号

关于进一步做好行政审批制度改革有关工作的通知

市政府各部门，市属、驻市各单位：

按照国务院和省政府的统一部署，近年来我市积极开展行政审批制度改革，全市行政审批事项大幅减少，行政审批行为逐步规范，行政效率明显提高，取得阶段性成效。但对照人民群众的期望和效能政府建设的要求，我市目前行政审批制度和行政审批工作仍然存在一些不容忽视的问题。为进一步推进全市行政审批制度改革，现将有关事项通知如下：

一、进一步梳理审批事项，优化工作流程

各部门（单位）要认真对照赣州市人民政府《关于进一步精简市级行政审批事项的决定》（赣市府发〔2009〕29号）和《关于精简市级非行政许可审批项目的决定》（赣市府发〔2012〕15号）中确定保留的行政许可和非行政许可审批事项，进一步梳理审批流程，精简规范办理要件和程序，缩短审批办理时限。

一是要严格按照《中华人民共和国行政许可法》的要求，重新审查其事项名称、设立依据、办理条件、申报材料、审批程序、法定时限、承诺时限、收费依据和标准，并通过政府门户网站、部门网站、服务中心网站、行政服务中心大厅显示屏、行政服务中心设置的触摸查询机以及窗口放置的服务指南予以全面公开，全方位接受监督。此项工作2012年8月底前完成。

二是要着力减少部门要件前置交叉。在认真兑现2009年承诺的办理时限的同时，根据审批内容尽量压缩审批项目办结时限，对不能进一步缩短办理时限的，相关部门要逐项作出说明。此项工作2012年7月底前完成。

三是要对保留的行政许可和非行政许可事项。进一步规范审批流程，绘制流程图（样表见附件），优化后的流程图务求准确、全面，要涵盖从受理到办结的全过程，尤其是内部运转审批环节。各部门（单位）保留的行政许可和非行政许可事项流程图请于2012年7月底前报市行政服务中心管理办行政服务监管科。

二、推进“两集中”、“两到位”改革

各部门（单位）要认真落实中办发〔2011〕22号文件精神，进一步强化市行政服务中心“一个窗口受理、一站式审批、一条龙服务、一个窗口收费”的载体功能，加大办理相对集中行政审批项目工作力度。各部门（单位）要依法将承担的行政审批、与广大群众密切相关的便民服务审批项目和行政事业性收费职能进行归并，全部纳入市行政服务中心窗口统一办理；市直各相关单位已建审批科室必须成建制进驻行政服务中心；行政审批科室挂靠其他科室的，应进行调整，改为其他科室挂靠行政审批科室，并成建制进驻行政服务中心；对因单位内部审批职能复杂，难以归并至一个科室的应建立单位内部行政审批工作小组，由分管领导负责，实行“部门内部并联审批制度”，审批科长负责受理审核和内部协调工作，并进驻行政服务中心实行“一个窗口”对外；对因场地、技术限制等原因暂时不能进驻中心的，纳入各类专业性服务大厅办理，由市行政服务中心实行统一指导和监管，条件成熟后适时入驻中心；对行政审批服务事项少的部门，在市行政服务中心联合设立“综合受理窗口”管理，以实现真正意义上的行政审批“两集中”、“两到位”。

各部门（单位）制定的“内部并联审批”工作制度请于2012年7月底前报市行政服务中心管理办行政服务监管科备案。

三、建立 “并联审批”工作机制

要按照协调服务、分类牵头、部门参与、效能监察的原则，对涉及两个部门以上审批的行政许可项目，建立“并联审批”工作机制。市行政服务中心管理机构负责“并联审批”的综合协调和服务工作；市城乡规划建设局、市发改委、市工信委、市工商局、市城管局等部门分别负责房屋建设、重大产业、工业服务、企业注册登记和市政工程等项目“并联审批”的牵头工作；相关部门参与涉及管理项目的联审联办、联合踏勘和联合验收工作。各级效能办负责并联审批效能制度建设，对各相关部门工作作风、办事效率进行监督。各部门（单位）实施“并联审批”工作应明确责任人，牵头部门由分管领导参加，参与部门由业务科室负责人或指定专业人员参加，并充分授权到位。要落实“并联审批”服务举措，规范组织工作和操作程序，对审批职能部门实行超时默认和超期默许制，对失职部门实行责任追究。

各牵头部门（单位）请于2012年7月底前制定并联审批工作实施方案报市行政审批制度改革工作领导小组办公室，经市政府审定后公布实施。

四、进一步规范网上审批和电子监察系统运行工作

各部门（单位）保留的行政许可和非行政许可事项必须全部纳入全省统一的网上审批系统进行办理，接受电子监察。包括因客观原因在各分中心办理和经市政府同意不进驻市行政服务中心窗口办理的事项，也必须使用全省统一的网上审批系统进行办理。此项工作在2012年8月底前完成。

要杜绝部分纳入、部分体外循环的情况，所有行政许可和非行政许可事项办理的业务台帐必须与在全省统一的网上审批系统中办理的时间、流程、结果一致，绝不允许先办理后一次性录入。所有行政许可和非行政许可事项必须严格按照承诺的时间进行办结。

五、强化行政审批责任监督制约机制

各部门（单位）要遵循有权必有责、用权受监督、侵权要赔偿、违法要追究的原则，完善行政审批责任监督制约机制，进一步强化对入驻行政服务中心的部门和单位的审批机构和审批人员、审批行为的监督。要坚持“法治、服务、责任”的行政理念，依法监督入驻行政服务中心各部门（单位）现有行政审批权力运行流程，使行政审批权力运行通过信息网络技术得到固化和整合。要完善行政审批责任追究制度，对各部门（单位）已入驻行政服务中心的审批项目，无正当理由仍采取体外循环、“只挂号，不看病”以及超越权限、超时不办、违反程序、勒卡刁难等行为给市民和投资者造成损失的，由行政监察机关严肃追究部门和单位主要领导以及办事人员的责任，确保行政审批权力始终在“阳光”下运行。

做好行政审批制度改革工作是加快政府职能转变，严格依法行政，提高行政审批效率的重要举措。各部门（单位）要高度重视，精心部署，严格按照安排的时间节点，有力有序推动工作任务落实。各部门（单位）填报的材料，务必于各时间节点前以书面（加盖单位公章）和电子版两种形式上报。
