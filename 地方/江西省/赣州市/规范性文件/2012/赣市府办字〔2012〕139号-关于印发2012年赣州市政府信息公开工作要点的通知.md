# 关于印发2012年赣州市政府信息公开工作要点的通知

赣市府办字〔2012〕139号

关于印发2012年赣州市政府

信息公开工作要点的通知

各县（市、区）人民政府，赣州开发区管委会，市政府各部门，市属、驻市有关单位：

《2012年赣州市政府信息公开工作要点》已经市政府同意，现印发给你们，请认真贯彻落实。

二○一二年七月二十日

（此件主动公开）

2012年赣州市政府信息公开工作要点

自2008年《中华人民共和国政府信息公开条例》（以下简称《条例》）施行以来，我市各级各部门认真贯彻落实，围绕建设法治政府、责任政府、服务政府、效能政府、廉洁政府的目标，按照上级和市委、市政府对政府信息公开的工作要求，深入开展政府信息公开工作，公开渠道和载体不断拓展，工作制度不断完善，广大人民群众的知情权、参与权、表达权和监督权得到有效保障，政府信息公开工作取得明显成效。当前和今后一段时间，各县（市、区）、各部门要紧紧围绕市委、市政府中心工作和赣南苏区振兴发展大局，着眼于提高政府工作透明度，着眼于增强政府执行力和公信力，着眼于保障人民群众合法权益，着眼于促进社会和谐稳定，进一步加强《条例》的贯彻落实，扎实推进重点领域信息公开，推动全市政府信息公开工作不断取得新成效。根据《江西省人民政府办公厅关于印发2012年江西省政府信息公开工作要点的通知》（赣府厅字〔2012〕115号）要求，结合我市实际，现就2012年政府信息公开工作要点安排如下：

一、推进财政预决算、“三公”经费和行政经费公开。一是推进财政总预算和总决算的公开。按照上报市人大审查通过的财政总预算和总决算的有关要求，公开财政总预算和总决算。二是报送市人大审查部门预算的部门和单位，要按照省财政的有关规定和部署，公开部门预算和决算。三是推进“三公”经费和行政经费公开。按照省政府的要求，在省财政的统一指导下公开“三公”经费。同时，稳步推进市政府各部门行政经费公开。四是指导督促县（市、区）政府及其部门公开预算和决算，加快“三公”经费公开步伐。（牵头单位：市财政局）

二、推进保障性住房信息公开。及时向社会公布保障性住房建设和管理的政策、措施、办法。公开保障性住房建设年度计划、项目开工和竣工情况，保障性住房项目名称、建设地址、建设方式、建设总套数、建设进度、项目总投资、项目建设和设计、施工、监理单位名称和责任人，以及保障性住房分配规则、分配对象、分配房源、分配程序、分配过程、分配结果、退出情况、投诉举报电话等信息。保障性住房建设和管理的政策、措施、办法出台前，应当遵循决策民主、程序公开、结果公开的要求，通过网络等形式进行公示，以征求群众意见。办法出台后，必须在规定时间内及时在政府网站公布。（牵头单位：市房管局）

三、推进食品安全信息公开。加强食品安全日常监管方面政府信息公开，依法公开各食品安全监管部门生产经营餐饮服务的行政许可情况、专项检查治理的进度及成果、违法生产经营行为查处情况、日常检测抽检结果及食品安全诚信体系建设情况等信息，及时公开食品安全政策法规、标准和食品安全科普知识等信息。积极推进食品安全风险监测评估和风险预警信息公开，及时向公众公开区域性食品安全风险监测结果、食品安全风险预警公告、食品安全监测抽检结果、食品安全事件处置等信息。稳妥做好食品安全舆情监测处置工作，对人民群众广泛关注的食品安全热点问题，快速响应，正确引导社会舆论。（牵头单位：市食安办、市卫生局）

四、推进环境保护信息公开。加强环境质量监测信息公开。及时准确公开18个县（市、区）和赣州开发区城市空气环境质量、全市主要河流国控断面水质监测信息、环境统计和环境调查等相关信息。按照应急预案信息发布的相关规定，及时公布重大突发环境事件处理情况等相关信息。抓好污水处理设施、主要污染物排放总量指标分配及落实情况、城市环境综合整治定量考核结果、环境监察执法情况等相关信息公开。推进项目环评、行业环保核查、上市公司环保核查等信息的公开。加大赣南苏区振兴发展环保重大政策项目等相关信息的公开力度。（牵头单位：市环保局）

五、推进招投标信息公开。国有资金占控股或者主导地位依法必须进行招标的项目，其招投标信息、投标单位及从业人员信用信息等有关政府信息，要及时向社会公开。参照《赣州市政府投资重点建设项目双公示制度管理暂行办法》，对有关建设项目实行“双公示”。按照《中华人民共和国招标投标法实施条例》等要求，结合全省开展的工程建设领域项目信息公开和诚信体系建设工作，着力推进招投标全过程信息公开。强化违法违规行为处理情况的信息公开，对在我市范围内发现的招投标违法违规行为及处理情况、违法违规企业名单全面公开，对不依法履行公开职责的责任人员依法给予处分。（牵头单位：市发改委）

六、推进生产安全事故信息公开。加强生产安全事故应对处置信息公开，及时准确发布政府采取的事故处置举措、风险预警、抢险救援进展等信息。认真做好事故调查处理信息公开工作，除依法应当保密的内容外，主动公开事故调查报告。对公众提出的事故信息公开申请，应在规定时限内认真答复。（牵头单位：市安监局）

七、推进征地拆迁信息公开。征地拆迁项目，各县（市、区）人民政府、赣州开发区管委会在征地补偿安置方案依法报批前，应当遵循决策民主、程序公开、结果公开的要求，严格履行公告、告知、论证、听取意见等程序，以提高征地信息的透明度。征地征收补偿安置方案批准后，要及时发布征地公告，认真做好征地、征收补偿安置信息公开工作，全面公布征收补偿安置方案，补偿安置标准、措施和补偿安置的结果等各环节的信息。坚决查处不依法公开征地拆迁信息和在信息公开工作中弄虚作假行为。（牵头单位：市房管局、市国土局）

八、推进价格和收费信息公开。政府指导价、政府定价的商品和服务价格，以及行政事业性收费标准调整时，要主动公开调整原因、标准、执行期限等，需听证的应及时公开听证信息。执行政府指导价、政府定价的经营服务性收费，要完善目录公开、明码标价、收费公示等相关制度。加强对垄断行业和公共企事业单位价格行为的监管，依法完善信息公开制度。行政事业性收费单位必须及时公开收费文件依据、收费项目、收费范围、收费标准等，对取消的收费项目及调减后的收费标准必须及时主动公开。要加大对价格和行政性事业单位收费违法违规行为及处理情况的信息公开力度，及时公布查处结果。（牵头单位：市发改委、市财政局）

九、进一步拓宽政府信息公开渠道。各地、各部门要坚持方便群众知情、便于监督的原则，加强政府网站管理，充分发挥政府网站信息公开第一平台作用。要创新载体、充分利用政府公报、新闻发布会、报刊杂志、广播、电视、公开栏、电子显示屏、宣传手册等多平台，多形式向社会公开政府信息，积极探索通过网络论坛、微博、手机短信等即时发布政府信息，进一步拓宽政府信息公开渠道。各县（市、区）要在行政服务中心、档案馆、公共图书馆设置政府信息查阅场所，各部门也应根据需要设立相应的场所、设施，方便群众查阅政府信息。

十、加强社会反映评估和舆情引导工作。一些社会关注度高、涉及面广的政府信息，如食品安全信息、环境保护信息等，公开前，要对公开后的社会反映进行预判，做好应对预案；公开后，要跟踪舆情，主动引导。对易于引发炒作的事件和信息，要及时发布正面信息，正确引导舆论。

十一、严格落实政府信息发布审查制度。要按照《国务院办公厅关于进一步做好政府信息公开保密审查工作的通知》（国办发〔2010〕57号）精神，坚持“先审查、后公开”和“一事一审”的原则，按照“谁审核、谁签字、谁负责”的要求，规范保密审查程序，落实保密审查制度，切实做好公开信息的保密审查，严禁公开涉密信息。

十二、认真做好依申请公开工作。各地、各部门要严格按照《条例》和《国务院办公厅关于做好政府信息依申请公开工作的意见》（国办发〔2010〕5号）精神，明确“一事一申请”原则，进一步改进依申请公开政府信息服务。规范申请受理和答复工作流程，安排专人定时查收群众网上和其他渠道的公开申请，及时处理依申请公开。在受理依申请公开政府信息过程中，若申请公开的信息是需要社会广泛知晓的，应在答复申请人的同时，通过有关渠道主动公开该信息，以减少对同一政府信息的一再申请，节约行政成本，提高工作效率。对于申请事项不属于政府信息公开工作范畴或无法按申请提供政府信息的，应主动与申请人沟通，尽量取得申请人的理解。在答复申请时，要依法有据、严谨规范、慎重稳妥。

十三、推进政府信息公开年度报告公开。各地、各部门在每年3月31日前必须向社会及时公开上年度政府信息公开年度报告。要提高年度报告编制质量，做到格式规范、内容全面、数据准确、分析到位。要规范年度报告编制和公开，严格按要求编制年度报告内容，及时在政府网站“政府信息公开专栏”二级子栏目上公开年度报告。

十四、加强机构和队伍建设。政府信息公开工作责任重大，各地各部门要进一步加强工作机构和队伍建设，从实际出发，建立健全政府信息公开工作机构，配强配齐工作队伍，明确工作职能，落实工作责任和经费保障。要建立政府信息公开业务培训制度，每年有针对性地开展业务培训，不断提高政府信息公开工作人员的业务能力和水平。

各县（市、区）、各部门要充分认识推进政府信息公开工作的重要意义，围绕政府信息公开工作常态化、制度化、规范化开展的工作目标，切实加强组织领导，明确责任，周密部署，将政府信息公开工作纳入年度目标考核，强化日常督促检查，扎实做好政府信息公开各项工作。市政府有关部门要按照上述工作安排和任务分工，对涉及本部门的工作进一步分解细化，抓紧制订具体措施，加强工作指导，认真抓好落实。涉及多个部门的工作，牵头部门要切实负起责任，加强组织协调，其他部门要密切配合。各牵头部门要于2012年10月30日前将相关工作进展情况报送市政府办公厅。市政府办公厅将对政府信息公开工作的落实情况适时进行督查。
