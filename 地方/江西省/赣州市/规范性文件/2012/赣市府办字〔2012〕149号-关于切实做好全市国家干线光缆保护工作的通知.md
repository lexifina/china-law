# 关于切实做好全市国家干线光缆保护工作的通知

赣市府办字〔2012〕149号

关于切实做好全市国家干线光缆保护工作的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

通信光缆线路是国家通信网的重要组成部分，担负着党、政、军的重要通信任务，属于国家的信息基础设施，是国家信息的命脉。近年来，因冬修水利、农田改造、市政施工、工业园基础设施建设等施工造成国家干线光缆破坏的事故时有发生，给党、政、军及人民群众的通信安全带来严重影响。下半年，党的十八大将召开，各地冬修水利、农田改造、地方基础设施建设随即进入高峰期，为确保光缆线路安全畅通，现就有关事项通知如下：

一、各级政府、各有关部门要充分认识保障国家干线光缆安全畅通，对促进经济社会发展和巩固国防的重要意义，切实增强保护国家干线光缆安全意识，认真履行保护国家通信设施和公用电信设施的职责义务。

二、在党的十八大期间和冬修水利、农田改造、地方基础设施建设时，各有关部门要加强对施工单位的现场管控，特别是对可能威胁到国家干线光缆安全的建设工程，必须事先与国家干线光缆维护部门（赣州市电信传输局，电话118114）取得联系，在国家干线光缆维护部门人员现场指导下采取必要的安全防护措施后方可施工。

三、各建设单位在干线光缆安全范围内施工时，要加强对施工人员特别是挖机手的安全教育，坚决杜绝人为损害光缆线路的事故发生。对由于施工管理不到位、未经光缆维护部门同意，擅自施工导致通信阻断事故的，要严肃追究有关人员的责任。

四、国家干线光缆主管部门要进一步强化责任意识，对有影响干线光缆安全的建设施工，主动向当地政府、建设部门介绍干线光缆路由情况，在接到各乡镇、村委会及沿线施工单位的开工通知后，必须积极配合施工单位施工，及时标明干线光缆具体位置，并协助其做好相应的保护工作。

五、对于护线管理、施工管理不到位，以及因违章作业、无现场指导作业等原因造成国家光缆线路破坏的重大故障、安全事故，将依法追究相关人员和单位负责人的责任。

二○一二年八月十三日
