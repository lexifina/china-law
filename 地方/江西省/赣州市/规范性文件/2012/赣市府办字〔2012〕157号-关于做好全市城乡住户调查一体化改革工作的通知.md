# 关于做好全市城乡住户调查一体化改革工作的通知

赣市府办字〔2012〕157号

关于做好全市城乡住户调查一体化

改革工作的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

为更加真实准确全面地反映城乡居民收入状况，根据国家统计局《全国城乡住户调查一体化改革总体方案》（国统字〔2012〕22号）和省政府办公厅《关于做好全省城乡住户调查一体化改革工作的通知》（赣府厅字〔2012〕101号）的要求，现就做好全市城乡住户调查一体化改革工作有关事项通知如下：

一、充分认识城乡住户调查一体化改革的重要意义

城乡住户调查是准确及时了解居民家庭收入、消费及其生活状况，客观监测居民收入分配格局和不同收入层次居民生活质量的重要民生统计调查。多年来，受城乡二元结构的制约，我市住户调查一直分城乡独立开展，且城镇住户调查只在章贡区和信丰县开展，城乡居民的收支水平和结构等统计数据不完整、不可比，更无法提供和发布全体居民收支数据，难以精确测算全体居民内部的收入差距和支出结构。开展城乡住户调查一体化改革，有利于准确完整地提供市、县两级全体居民收支、消费、住房及家庭就业等信息，及时监测农民工、贫困人口等群体的生活状况；有利于客观反映我市城乡之间、地区之间和不同群体之间的收入差距及其变化，为促进城乡统筹发展提供真实、可靠、有效的依据；有利于真实检验我市实施的一系列重大发展战略所取得的成果以及给人民群众带来的实惠，更好地保障和改善民生。各县（市、区）要提高认识，积极作为，确保城乡住户调查一体化改革的各项工作顺利开展。

二、积极稳妥推进城乡住户调查一体化改革

（一）坚持一体化改革目标。各县（市、区）全面建立城乡一体的住户调查体系，统一城镇居民和农村居民收支指标，从2013年起分县（市、区）统计全体居民可支配收入、城镇居民可支配收入、农村居民可支配收入等相关数据，并满足全市汇总需要，提高住户调查能力和数据质量。

（二）建立规范的调查制度。将农村居民人均纯收入改为农村居民人均可支配收入，设置农村、城镇和全体居民可支配收入指标，建立城乡可比、以可支配收入指标为核心的居民收支指标体系。按照统一的方法，对包括农民工在内的所有居民进行分层随机抽样，选取调查户，实现所有地域和人群不交叉、全覆盖，确保对省、市、县（市、区）有充分的代表性。采用统一问卷和记账格式，对包括农民工在内的所有居民实施常住地调查，直接采集原始数据。充分应用现代信息技术，以住户电子记账和调查人员手持电子终端的方式直接采集数据，并通过互联网直接报送国家统计局数据中心，实现各级统计机构按照权限共享数据，减轻调查对象的负担，促进调查对象的参与。在发布城乡居民收支水平、结构及变化数据的基础上，按年度发布全体居民和不同收入层次居民的收支水平、结构及变化数据。按季度发布现金收支水平、结构及变化等数据。

（三）分步实施，扎实推进。根据全国城乡住户调查一体化改革总体方案要求，城乡住户调查一体化改革分为准备阶段和实施阶段。

1．准备阶段（2012年底前）。主要任务是调查试点，建立调查制度，抽选对分市、县（市、区）有充分代表性的住户调查样本，组织开展摸底调查，选聘辅助调查员，抽选落实调查户，组织培训各级调查人员。

2．实施阶段（2013年起）。主要任务是在全市范围内组织实施住户生活状况调查，发布全市和分县（市、区）居民收支数据。居民可支配收入指标将列为政府目标考核并按季通报。

三、加强和改进市县住户调查工作

（一）加强组织领导。城乡住户调查一体化改革工作，不仅工作难度大、技术要求高，而且政策性强、影响面广。各县（市、区）要高度重视，加强组织领导，将推进城乡住户调查一体化改革工作列入议事日程，成立以政府分管领导为组长的城乡住户调查一体化改革工作领导小组，研究制定工作方案，及时解决工作中出现的问题，确保改革顺利推进。

（二）强化工作职责。按照国家统计局江西调查总队和省统计局确定的工作管理模式，我市的市县住户调查工作由国家统计局赣州调查队负责牵头，会同市统计局共同管理。已设立国家调查队的县（市、区），住户调查工作由县级国家调查队直接组织实施,未设国家调查队的县（市、区），由县（市、区）统计局负责组织实施。

（三）强化经费保障。各地要根据当地的工资标准和调查户数，确定辅调员和记账户的补贴，并列入财政预算，及时足额拨付。

（四）严格数据质量控制。数据质量是住户调查工作的生命，也是衡量城乡住户调查一体化改革成败的关键所在。各地统计调查部门要切实履行职责，坚持独立调查、独立上报，做好调查数据的审核评估，规范数据管理与发布，严禁弄虚作假，确保调查质量。
