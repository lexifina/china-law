# 赣州市人民政府办公厅关于成立赣州市尿毒症免费血透救治工作协调小组的通知

赣市府办字〔2012〕165号

赣州市人民政府办公厅关于成立

赣州市尿毒症免费血透救治工作协调小组的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

为做好全市尿毒症免费血透救治工作，经研究，决定成立赣州市尿毒症免费血透救治工作协调小组。成员名单如下：

组　长：孙黎明　 市政府副市长

副组长：邝先元　 市政府副秘书长

廖　伟　 市卫生局局长

成　员：黄敬平　 市政府纠风办主任

李国生　 市委宣传部副部长

陈玉英　 市财政局副局长

钟华锋　 市发改委纪检组长

刘　洪　 市人力资源和社会保障局党组成员、医保局局长

衡京南　 市民政局副调研员

赖卫国　 市卫生局副局长

协调小组下设办公室，设在市卫生局，赖卫国同志兼任办公室主任。

2012年9月1日
