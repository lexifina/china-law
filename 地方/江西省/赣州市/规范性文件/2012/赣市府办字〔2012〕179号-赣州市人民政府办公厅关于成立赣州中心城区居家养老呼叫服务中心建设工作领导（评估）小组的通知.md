# 赣州市人民政府办公厅关于成立赣州中心城区居家养老呼叫服务中心建设工作领导（评估）小组的通知

赣市府办字〔2012〕179号

赣州市人民政府办公厅

关于成立赣州中心城区居家养老呼叫服务中心建设

工作领导（评估）小组的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

为加强赣州中心城区居家养老呼叫服务中心建设工作的组织领导和服务评估工作，经市政府同意，成立赣州中心城区居家养老呼叫服务中心建设工作领导（评估）小组。其组成人员如下：

组　长：陈晓春　市委常委、市政府副市长

副组长：刘树明　市政府副秘书长

李桂生　市民政局局长

成　员：戴华松　市民政局副局长

史方现　市老龄办主任

陈玉英　市财政局副局长

宋怡萍　章贡区委常委、区政府副区长

领导（评估）小组下设办公室，办公室设在市老龄办，史方现同志兼任办公室主任。

2012年9月17日
