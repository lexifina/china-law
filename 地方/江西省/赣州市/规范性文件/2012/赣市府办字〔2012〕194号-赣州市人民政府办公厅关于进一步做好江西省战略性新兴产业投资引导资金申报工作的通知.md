# 赣州市人民政府办公厅关于进一步做好江西省战略性新兴产业投资引导资金申报工作的通知

赣市府办字〔2012〕194号

赣州市人民政府办公厅

关于进一步做好江西省战略性新兴产业

投资引导资金申报工作的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

为贯彻落实省人民政府办公厅《关于印发江西省战略性新兴产业投资引导资金管理暂行办法的通知》（赣府厅发〔2012〕16号）精神，进一步做好我市申报江西省战略性新兴产业投资引导资金有关工作，现将有关事项通知如下：

一、申报范围

符合《江西省十大战略性新兴产业发展规划》、《战略性新兴产业延伸产业链发展规划》、《江西省十大战略性新兴产业科技创新规划》、《战略性新兴产业重大技术引进和创新项目指南》，重点是《2012年江西省战略性新兴产业重大项目申报指南》所确定的光伏、风能核能及节能、半导体及绿色照明、金属新材料、非金属新材料、航空制造、新能源汽车及动力电池、生物和新医药、绿色食品、文化及创意等十个产业的项目。

二、申报程序

成立赣州市组织申报江西省战略性新兴产业投资引导资金项目办公室（以下简称市申报办），市工信委、市财政局、市发改委、市科技局为成员单位，办公室设在市工信委。

（一）各地遴选项目。各县（市、区）工信局、财政局、发改委、科技局，赣州开发区发展规划局，共同组织选定当地项目。

（二）各地上报表格。各地以县（市、区）人民政府，赣州开发区管委会名义正式行文将《江西省战略性新兴产业重大项目申报汇总表》、《江西省战略性新兴产业重大项目情况表》上报市申报办，由市申报办汇总后报市政府。各地上报时间为：以省里要求各设区市上报的截止时间为基准，至少提前七个工作日上报市申报办。

（三）组织审核项目。由市政府分管领导组织市申报办各成员单位及有关专家对各地上报的项目进行评审，确定我市需要上报的项目。

（四）上报项目表格。市政府确定需要上报的项目后，由市申报办起草上报文件，市政府审定后上报省战略性新兴产业投资引导资金管理委员会办公室。

（五）编写上报材料。经省战略性新兴产业投资引导资金管理委员会办公室初步审查通过的项目，项目业主单位按编写提纲要求编写项目资金申请报告，并以县（市、区）人民政府、赣州开发区管委会名义行文上报市申报办。经市申报办审核确认后，草拟上报文件，报市政府审定并报省战略性新兴产业投资引导资金管理委员会办公室。

（六）监管考核。省战略性新兴产业投资引导资金下达后，市申报办各成员单位按照赣府厅发〔2012〕16号文件要求对项目资金有关情况进行监管考核，并将情况及时报市申报办汇总后上报市政府。

三、工作要求

（一）各地要高度重视，按照项目申报的有关要求，认真选择对地方经济发展具有重要带动作用的战略性新兴产业项目作为申报对象，对上报的材料进行认真审核把关，及时上报申报材料。

（二）市申报办负责我市申报江西省战略性新兴产业投资引导资金项目的组织协调及有关申报的具体工作。

（三）市申报办各成员单位负责指导、督促其下属对口单位，做好符合条件项目的申报工作；同时负责与省对口部门对接汇报，从申报、评审至最后省政府审定项目进行全程跟踪落实；对获得省引导资金支持的项目，各自履行监督、检查、管理服务等工作。

2012年10月22日
