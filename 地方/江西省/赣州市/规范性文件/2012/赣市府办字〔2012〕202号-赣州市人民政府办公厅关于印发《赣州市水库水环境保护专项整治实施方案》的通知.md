# 赣州市人民政府办公厅关于印发《赣州市水库水环境保护专项整治实施方案》的通知

赣市府办字〔2012〕202号

赣州市人民政府办公厅

关于印发《赣州市水库水环境保护专项

整治实施方案》的通知

各县（市、区）人民政府、赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

经市政府同意，现将《赣州市水库水环境保护专项整治实施方案》印发给你们，请认真抓好贯彻落实。

2012年11月2日

赣州市水库水环境保护专项整治实施方案

目前，全市有大中小型各类水库1千余座，在防洪、灌溉、供水、养殖中发挥了重要作用。近年来，随着水库养殖业的迅速发展，在各类水库库区内，存在网箱养殖及利用畜禽粪便、饲料、化肥养鱼等危害水库水环境行为，水库水环境污染问题日益突出。为加强全市大中小型水库及水库周边地区（水库周边地区为水库饮用水源二级保护区）生态环境资源的保护，确保水库水环境安全，制定本实施方案。

一、目标任务

通过水库水环境保护专项整治行动，规范水库养殖，饮用水源地水库全部退出承包养殖和取消网箱养鱼，水质达到水域功能Ⅲ类标准，非饮用水源地水库禁止肥水养鱼，进一步改善生态环境，有效治理和保护水库水环境，清除水库及其水库周边地区污染源，水库的水质全面达到《地表水环境质量标准》（GB3838—2002）水域功能区标准。

二、组织领导机构

市政府成立水库水环境保护专项整治领导小组（以下简称市领导小组），分管副市长任组长，分管副秘书长任副组长，市水利局、市环保局、市农粮局、市林业局、市卫生局、市国土资源局、市公安局、市发改委、市财政局、市工商局、赣州供电公司为成员单位，市领导小组下设办公室，由市水利局分管领导任办公室主任。市领导小组负责全市水库水环境保护专项整治活动的组织、领导和协调工作。各县（市、区）要相应成立组织机构协调本地开展专项整治工作。

三、成员单位职责分工

市环保局：负责水源保护区、水库周边地区范围内排污企业许可审批；加大水质水环境污染监测力度，完善排污企业的申报登记制度；严格执法，对违反环境保护法规造成水源污染的企业实施处罚，从严要求库区新建企业和养殖场，对达不到排放标准的，不发放相关许可证件。

市农粮局：负责抓好水源保护区、水库周边地区范围内生态农业建设及农业面源污染状况调查，联合相关部门依法取缔水源地养殖承包合同，推广无公害生产，指导农民科学种田，合理施用化肥、农药，减少农业面源污染。

市水利局：负责加强水源保护区、水库周边地区范围内沿线排污口设置的管理，加大库区内执法力度，依法打击、处置非法养殖行为，确保生产、生活用水安全。

市工商局：负责依法查处水源保护区、水库周边地区范围内的个体户、企业违反工商管理法律法规的经营行为，对影响水质且未按要求取得前置审批许可的项目一律不予核准；对被政府或有关部门责令关闭的企业，依法注销或吊销其营业执照。

赣州供电公司：负责对水源保护区、水库周边地区范围内的用电管理，配合当地政府，对依法关闭的企业采取限电、停电、断电等有效措施。

市公安局：加强对水源保护区、水库周边地区范围内治安秩序的管理，打击破坏水库水质违法犯罪活动。

市财政局：统筹安排必要的工作经费，保障工作顺利进行。

市发改委：严格执行产业政策，对水源保护区、水库周边地区范围内建设项目审批立项严格把关，杜绝产生新的污染。

市国土资源局：负责水源保护区、水库周边地区范围内国土资源的监督管理；严把保护区内新增建设用地的审核、审批关，对造成水质污染的用地坚决不予办理用地手续；配合相关部门对水库集雨区范围内的用地进行调查摸底，对造成污染又没有办理用地手续的地面建筑物，由当地国土资源行政主管部门依法申请法院强制拆除。

市卫生局：负责饮用水水源的卫生防疫指导工作，对饮用水水源的水质进行定期检测，枯水期和丰水期各检测一次，为行政执法提供依据。

市林业局：负责指导水库周边地区范围内水源涵养林建设与管理。加强森林资源保护，打击乱砍滥伐林木和乱征滥占林地等违法犯罪行为。指导水库集雨区范围内耕地的退耕还林和绿化的落实与管理。

四、实施步骤

（一）动员部署阶段（2012年10月26日-- 11 月10日）

各县（市、区）要结合本地实际，制定专项整治活动的具体实施方案，明确整治要求、整治重点、整治任务和保障措施，及时动员部署。同时，组织好专项整治活动的宣传工作，向水库承包养殖户、企业主、水库周边群众广泛宣传水库水质保护的政策和措施，广泛动员，争取社会各界对水库水环境专项整治工作的支持。各县(市、区)人民政府要在2012年11月30日前将专项整治工作方案和责任单位实施方案上报市领导小组办公室（联系人刘军，电话8196440）。

（二）排查梳理阶段（2012年11月11日-- 2013年3月10日）

各县（市、区）要组织环保、水利、农粮等部门对辖区内的所有水库逐座进行水环境质量检查，重点对库区周边污染企业、养殖场以及利用畜禽粪便、饲料、肥料养鱼等污染水源的情况进行排查，确保不漏一点死角，不留一片空白，不存一处盲点。要对排查的水库建立水库养殖档案，按照清查一座，整治一座的目标任务要求，周密安排，跟踪落实。同时，根据排查情况进行认真梳理、分类登记、汇总（见附表），将排查结果于2013年3月10前报市领导小组办公室。

（三）集中整治阶段（2013年3月11日--2013年11月30日）

各县（市、区）应根据排查情况，有针对性地组织专项执法整治行动。

1．集中对库区周边排污企业进行治理，对不符合产业政策、无职能部门许可、污染重、效益差且无力治理的企业，要实施关停并转措施，并制定严格的执行时间表。

2．清理饮用水源地库区的承包养殖和网箱养鱼。各县（市、区）要在专项整治结束前，完成承包养殖全部退出和网箱养鱼全部取消。

3．开展水库水质监测，各地要委托资质单位进行按季监测，并将监测结果定期公布。

4．清理整治在水库校核水位或历史最高水位线以下的滩地和岸坡堆放、存储废物及其他污染物；打击向水库排放超过国家综合排放标准的废水、倾倒畜禽废渣以及在库区从事滥伐林木、乱征滥占林地、毒鱼、炸鱼、电力捕鱼等行为。

5．加强水库水环境管理机构，适时制定出台水库水环境的管理细则或办法，建立水库水环境管理长效机制。

（四）总结考核阶段（2013年12月1日--12月30日）

整治活动结束后，市领导小组组织有关部门对整治工作进行考核，并对整治活动效果及存在问题进行全面总结，向全市通报。各县（市、区）要建立严格的水库水质保护长效机制，对整治活动进行回头看，总结经验，查遗补漏，巩固成果，并于2013年12月20日前将总结和汇总表报市领导小组办公室。

五、工作要求

（一）加强组织领导。各县（市、区）、各责任单位要高度重视此次专项整治活动，成立专项整治工作小组，根据本单位的工作职责，制定具体实施方案。各责任单位要主动开展工作，密切配合，互相支持。市领导小组办公室定期组织召开成员单位联席会议，及时跟踪专项整治工作进度，协调解决专项整治过程中存在的问题。

（二）严格整治措施。各县（市、区）要强化整治力度，依法依规开展整治活动，对重点污染企业和污染源进行重点整改，对重大的水库水环境违法案件实行挂牌督办，对超标排污的单位予以严惩，并责令其限期治理。在规定时间内仍不能实现达标的，坚决予以取缔或关停。对超标严重的要媒体上通报，对达不到限期治理要求的，实行“三停”（停水、停电、停贷）。

（三）加强宣传引导。通过电台、电视、报刊等媒体，广泛宣传水库水环境保护的法律法规知识，及时报道水库水环境专项整治情况，公布举报电话，动员广大群众关心、支持和监督水库水环境整治发挥舆论监督作用，构建良好的执法氛围。

（四）落实工作责任。要认真贯彻专项整治方案要求，把水库水环境整治专项行动作为推动各级政府落实科学发展观、建设生态赣州的重要手段。各县（市、区）、各责任单位要健全水库水环境专项整治工作责任制和问责制，形成“一级抓一级、层层抓落实”的强有力工作格局，要按照职责分工，各负其责、各司其能、加强配合，采取扎实有效的措施，确保各项工作落到实处、取得实效。整治期间，因组织不力，措施不落实，导致辖区水库水环境监管混乱，水库水环境质量仍得不到有效解决的，将按有关规定，追究相关人

员责任。
