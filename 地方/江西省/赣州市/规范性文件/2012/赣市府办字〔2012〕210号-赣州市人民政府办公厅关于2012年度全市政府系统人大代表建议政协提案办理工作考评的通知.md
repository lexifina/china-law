# 赣州市人民政府办公厅关于2012年度全市政府系统人大代表建议政协提案办理工作考评的通知

赣市府办字〔2012〕210号

赣州市人民政府办公厅

关于2012年度全市政府系统人大代表建议

政协提案办理工作考评的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

为认真总结经验，寻找差距，全面提升我市政府系统办理工作水平，根据人大代表建议政协提案办理相关文件要求，经市政府办公厅研究，并报市领导同意，决定对全市政府系统2012年度办理人大代表建议、政协提案工作进行考评，现将有关事项通知如下：

一、考评对象

各县（市、区）人民政府，赣州开发区管委会；2012年办理市人大代表建议、市政协提案总数在5件以上的市政府有关部门或市属、驻市有关单位。参与了政府系统2012年度人大代表建议政协提案办理工作的人员。

二、考评内容

（一）2012年办理人大代表建议、政协提案工作的有关原始材料（含登记簿、拟办意见、领导审签意见、答复件、征询意见反馈表、简报等）。

（二）2012年办理工作总结材料（包括基本情况、主要做法、问题和建议等）。

（三）人大代表建议、政协提案二次办理工作情况。

三、考评方式

（一）自评。各县（市、区）人民政府和市直各参评单位要对今年的人大代表建议、政协提案办理工作进行认真总结、自评。要在自评总结和相关材料上加盖本单位公章，于2012年12月5日前报市政府督查室，联系电话：8391324。

（二）初评。市政府督查室对有关单位今年办理的市人大代表建议、政协提案答复件或报送件（各县（市、区）人民政府、赣州开发区管委会只需报送考评表、先进个人推荐表和总结材料）逐件审查，并结合自评总结材料和抽查掌握情况，根据考核标准综合打分，提出初评意见。

（三）审定。市政府督查室结合初评情况，进一步征求市人大选举任免联络委员会和市政协提案委员会的意见，报市政府审定。在各县（市、区）人民政府、赣州开发区管委会中评选出6个办理工作先进县（市、区）；在市政府有关部门、市属、驻市有关单位中评选出10个办理工作先进单位；在所有参评单位中评选出20名先进个人予以表彰。

四、相关要求

（一）各承办单位要高度重视，按要求及时报送材料，并实事求是开展自评，对弄虚作假的自评材料，一经核实，立即取消评先资格。

（二）各承办单位要把本单位人大代表建议、政协提案办理工作的所有资料，逐件清点，分门别类，立卷归档。

（三）市政府督查室要适时开展抽查，确保掌握的情况真实、准确。
