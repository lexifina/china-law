# 关于印发《2012年市政府常务会议学法安排》的通知

赣市府办字〔2012〕21号

关于印发《2012年市政府常务会议

学法安排》的通知

市政府各部门，市属、驻市有关单位：

经市政府同意，现将《2012年市政府常务会议学法安排》印发给你们，请认真抓好落实。

各有关部门（单位）要根据本安排，尽快落实主讲人员（原则上为主讲单位的主要领导），并提前准备好相关的学习材料（包括辅导发言材料、法律法规单行本各60份），于当次常务会议召开前送市政府法制办。
