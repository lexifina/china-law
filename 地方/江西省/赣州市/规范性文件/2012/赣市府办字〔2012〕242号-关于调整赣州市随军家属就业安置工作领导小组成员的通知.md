# 关于调整赣州市随军家属就业安置工作领导小组成员的通知

赣市府办字〔2012〕242号

关于调整赣州市随军家属

就业安置工作领导小组成员的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

鉴于人事变动，经研究，决定将赣州市随军家属安置工作领导小组成员调整如下：

组　长：陈晓春　　市委常委、市政府副市长

副组长：张福东　　赣州军分区政治部主任

刘树明　　市政府副秘书长

陈庐生　　市委编办主任

孔德然　　市委组织部副部长、市人社局局长、党组书记

李桂生　　市民政局局长

成　员：段先顺　　市委编办副主任

梁　卫　　市民政局副局长

廖慧明　　市人社局纪检组长

吴玉明　　市人社局党组成员、就业局局长

陈玉英　　市财政局副局长

邹凤阳　　市工商局副局长

李日胜　　市国税局副局长

钟圣生　　市地税局纪检组长

李振明　　赣州军分区政治部科长

领导小组办公室设在市双拥办，李桂生同志兼任办公室主任，梁卫、廖慧明、段先顺、李振明等同志为办公室副主任。

2012年12月28日
