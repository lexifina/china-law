# 关于下达2012年全市金融机构小额担保贷款计划任务的通知

赣市府办字〔2012〕25号

关于下达2012年全市金融机构小额担保贷款

计划任务的通知

中国农业发展银行赣州市分行，各国有商业银行赣州市分行，中国邮政储蓄银行赣州市分行，江西省农信联社赣州办事处，赣州银行：

为认真贯彻《关于转发的通知》（南银发〔2008〕212号）精神，经市政府同意，现将2012年全市金融机构小额担保贷款计划下达给你们，具体为：中国农业发展银行赣州市分行发放1000 万元；中国工商银行赣州市分行发放800万元；中国农业银行赣州市分行发放1000万元；中国银行赣州市分行发放800万元；中国建设银行赣州市分行发放800万元；中国邮政储蓄银行赣州市分行发放12100万元；江西省农信联社赣州办事处发放39000万元；赣州银行发放 4500万元。全市金融机构发放小额担保贷款总计为6亿元。请各金融机构在2012年3月10日前将任务细化、分解落实到基层。

小额担保贷款工作是贯彻落实中央和省委、省政府关于进一步加强就业再就业工作的重要举措，对推进全民创业，促进我市经济发展和社会稳定具有重要意义。市委、市政府已将此项工作列入“民生工程”和各级党委、政府领导政绩考核的主要内容之一。各金融机构要进一步落实小额担保贷款政策，创新小额担保贷款工作模式，提高小额担保贷款额度和扩大贷款范围。要加快小额担保贷款发放和回收工作力度，不断增强小额担保贷款发放的主动性、自觉性，确保小额担保贷款“放得出、用得好、收得回”，为支持就业创业和推动地方经济发展作出新的贡献。

二○一二年三月二日
