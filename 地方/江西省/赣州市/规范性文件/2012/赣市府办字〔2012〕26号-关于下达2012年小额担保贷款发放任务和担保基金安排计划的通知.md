# 关于下达2012年小额担保贷款发放任务和担保基金安排计划的通知

赣市府办字〔2012〕26号

关于下达2012年小额担保贷款发放任务

和担保基金安排计划的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

为认真贯彻《关于转发的通知》（南银发〔2008〕212号）精神，做好2012年小额担保贷款发放工作，经市政府同意，现将2012年各县（市、区）小额贷款发放任务和担保基金安排计划下达给你们，请认真抓好贯彻落实。

小额担保贷款是国家促进各类人员就业创业的一项重要扶持政策，对于促进我市就业再就业，带动地方经济社会发展具有重要的意义。各级政府要高度重视，采取有效措施，及时将目标任务分解落实到位。人力资源和社会保障、财政和金融主管部门要加强协调配合，认真贯彻各项就业创业扶持政策，加大小额担保贷款工作的督查督办力度。各金融机构要简化手续，积极为各类创业人员提供信贷支持，确保圆满完成2012年全市小额担保贷款工作任务。
