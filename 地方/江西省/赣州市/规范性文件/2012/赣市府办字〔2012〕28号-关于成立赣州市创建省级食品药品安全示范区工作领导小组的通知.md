# 关于成立赣州市创建省级食品药品安全示范区工作领导小组的通知

赣市府办字〔2012〕28号

关于成立赣州市创建省级食品药品安全示范区

工作领导小组的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

为加强对创建省级食品药品安全示范区工作的统筹协调，经市政府研究，决定成立赣州市创建省级食品药品安全示范区工作领导小组。其组成人员名单如下：

组　长：孙黎明　 市政府副市长

副组长：邝先元　 市政府副秘书长

邓正华   市食品药品监督管理局局长

成  员：曾李安   市食品药品监督管理局副局长

曾凡生   市农粮局副局长

陈晓春   市质监局副局长

江文科   市工商局副局长

喻声萍   市商务局副局长

唐赣珍   市卫生局调研员

陈玉英   市财政局副局长

刘昌明   市教育局副局长

段先顺   市委编办副主任

尹良耀   市公安局副调研员

领导小组办公室设在市食品药品监督管理局，负责创建日常工作，邓正华同志兼任办公室主任，曾李安同志兼任办公室副主任。

二○一二年三月五日
