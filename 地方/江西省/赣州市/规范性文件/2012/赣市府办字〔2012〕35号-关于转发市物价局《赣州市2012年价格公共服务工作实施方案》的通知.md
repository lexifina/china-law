# 关于转发市物价局《赣州市2012年价格公共服务工作实施方案》的通知

赣市府办字〔2012〕35号

关于转发市物价局《赣州市2012年价格公共

服务工作实施方案》的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属有关单位：

经市政府研究同意，现将市物价局《赣州市2012年价格公共服务工作实施方案》转发给你们，请抓好贯彻落实。

二○一二年三月二十日

赣州市2012年价格公共服务工作实施方案

为使我市2012年价格公共服务工作持续有效地开展，根据江西省发展和改革委员会《二○一二年价格公共服务工作意见》（赣发改价检字〔2012〕18号）文件精神，结合我市实际，制定本方案。

一、工作目标

继续深入开展价格公共服务工作，拓宽服务领域，丰富服务内容，创新工作方法，不断巩固和扩大已开展的价格公共服务“七进”（进农户、进企业、进景区、进医院、进社区、进学校、 进商场）活动成果，突出价格公共服务“进银行”和“再进商场”工作重点，全面提升12358价格咨询投诉系统的服务质量，大力推进价格诚信建设，为实现赣州加快发展、转型发展提供良好的价格环境。

二、工作内容

（一）巩固和扩大价格公共服务“七进”成果，切实做好六项工作

1．进一步发挥乡镇便民服务中心、价费监督站和价格服务岗作用，继续为农民提供价格政策法规和涉农信息服务。

2．继续清理和公示涉企收费，为企业发展增添后劲。

3．规范景区价费公示和价格行为，维护景区价格秩序。

4．完善社区价格政策宣传和物业收费公示栏，保障社区居民的知情权和监督权，促进社区和谐建设。

5．落实二级以上规模医院医药价格公示查询制度、收费一日清单和出院病人医药费签字认可制度，推进医院价格诚信建设。

6．落实教育收费公示制度，规范学校收费行为。

（二）开展价格公共服务“进银行”活动

价格公共服务“进银行”的服务对象是城乡居民群众。主要工作有：

1．县（市、区）价格主管部门与辖区内人民银行、银监会建立价格公共服务联系制度，争取商业银行主管部门的理解和支持。

2．做好银行收费公示工作，按照全省统一的银行收费公示格式，促使各银行营业网点在醒目位置进行公示，提高银行收费透明度。

3．建立与辖区内各商业银行的联系制度，明确服务范围、内容、方式以及服务责任单位和责任人。3月底前，将联系情况书面上报市价格公共服务工作领导小组办公室（设市物价局）。

（三）开展价格公共服务“再进商场”活动

价格公共服务“再进商场”的服务对象仍然是广大的消费者。主要工作有：

1．继续做好辖区内各类主要商场、超市的明码标价工作，尤其要规范降价、折扣类商品的价格标示。

2．做好大型家电类商场、超市“明码实价”工作，各县（市、区）年内至少要培育一个家电“明码实价”示范店。

3．设置好商场、超市12358价格举报电话公示牌，为顾客价格维权提供方便。

4．积极帮助和引导商场、超市参加价格诚信单位创建评选活动。

三、工作要求

（一）加强组织领导。各县（市、区）要进一步加强对价格公共服务工作的领导，及时调整充实价格公共服务工作领导小组，为价格公共服务工作的顺利开展，提供坚强的组织保障。

（二）加强宣传造势。各县（市、区）要加大价格公共服务工作的宣传力度，让社会各界知晓价格公共服务的意义、目的、内容和要求，营造居民积极参与、社会多方配合的价格公共服务良好氛围。

（三）加强部门协调。各县（市、区）价格主管部门要充分发挥职能作用，加强与各有关部门的沟通和协调，形成工作合力。

（四）加强制度建设。要着眼长远、立足长效、着力于创新，建立价格公共服务情况通报、定期联系、追踪调度、考核评价等制度，完善工作长效机制，使价格公共服务工作制度化、经常化。

（五）加大经费投入。各地财政要确保价格公共服务工作必需经费，为价格公共服务深入持久、卓有成效地开展提供必要的保障。

（六）加强督促检查。各县（市、区）价格公共服务领导小组，要结合本地实际，制定具体工作方案，细化工作内容，落实工作职责，加强工作调度和经常性的督促检查，使价格公共服务真正成为政府的惠民工程。
