# 关于调整市政府应急管理专家组成员的通知

赣市府办字〔2012〕36号

关于调整市政府应急管理专家组成员的通知

各县（市、区）人民政府，赣州开发区管委会，市政府各部门，市属、驻市各单位：

自2008年12月22日市政府应急管理专家组成立以来，专家组成员在决策建议、专业咨询、理论指导和技术支持上发挥了重要作用，为全市突发事件处置和应急管理顺利开展做了大量卓有成效的工作。为进一步发挥专家在突发事件处置中的指导和参谋作用，健全和完善科学决策机制，提高我市应急管理工作水平，根据《赣州市应急管理专家组工作规则》有关规定和工作需要，在市应急委专项指挥部和市直、驻市有关部门推荐并广泛征求意见的基础上，市应急委对市政府应急管理专家组进行了调整和充实。调整后的市政府应急管理专家组组长由市政府应急办负责人兼任，专家组秘书处设市政府办公厅应急管理处；专家组成员共28名，其中自然灾害类5名，事故灾难类9名，公共卫生类5名，社会安全类5名，综合管理类4名，由市政府颁发聘书，聘期3年。经市政府领导同意，现将调整后的市政府应急管理专家组成员名单通知如下。
