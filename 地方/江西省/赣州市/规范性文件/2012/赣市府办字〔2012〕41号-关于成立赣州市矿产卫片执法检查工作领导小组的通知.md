# 关于成立赣州市矿产卫片执法检查工作领导小组的通知

赣市府办字〔2012〕41号

关于成立赣州市矿产卫片执法检查工作

领导小组的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

根据国土资源部《关于开展2011年度土地矿产卫片执法检查工作的通知》(国土资发〔2012〕15号)文件精神，为认真做好我市矿产卫片执法检查工作，进一步加强组织领导，经研究，决定成立市矿产卫片执法检查领导小组。领导小组成员名单如下：

组 长：刘建萍 市政府副市长

副组长：薛有长 市政府副秘书长

李国清 市矿管局局长

成 员：吴才茂 市监察局副局长

徐新丰 市矿管局副局长

罗志欣 市国土资源局执法监察支队支队长

钟大洪 市林业局副局长

尹良耀 市公安局副调研员

领导小组下设办公室，办公室设在赣州市矿产资源管理局，由徐新丰同志兼任办公室主任。

二○一二年三月二十四日
