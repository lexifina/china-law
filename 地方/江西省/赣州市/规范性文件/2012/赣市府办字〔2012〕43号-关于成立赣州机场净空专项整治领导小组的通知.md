# 关于成立赣州机场净空专项整治领导小组的通知

赣市府办字〔2012〕43号

关于成立赣州机场净空专项整治领导小组的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

为贯彻落实《中华人民共和国民用航空法》、《民用机场管理条例》和《民用机场运行安全管理规定》等有关净空保护规定，开展机场净空专项整治工作，确保赣州机场净空条件良好，经研究，决定成立赣州机场净空专项整治领导小组。领导小组组成人员名单如下：

组 长：刘建萍　市政府副市长

副组长：薛有长 市政府副秘书长

张福胜 赣州机场分公司总经理

成 员：陈建生 市交通运输局副局长

廖光斌 市城乡规划建设局总规划师

蒙在煌 市城市管理局副局长

邓晓楠 南康市政府副市长

邹焕铁 南康市凤岗镇党委书记

黄万林 南康市唐江镇党委书记

领导小组办公室设在赣州机场分公司，由机场管理部经理李小明同志兼任办公室主任。

二○一二年三月二十六日
