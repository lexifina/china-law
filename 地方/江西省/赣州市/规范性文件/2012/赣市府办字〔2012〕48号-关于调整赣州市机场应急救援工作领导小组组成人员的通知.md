# 关于调整赣州市机场应急救援工作领导小组组成人员的通知

赣市府办字〔2012〕48号

关于调整赣州市机场应急救援工作

领导小组组成人员的通知

章贡区、南康市人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

副组长：薛有长 市政府副秘书长

张福胜 赣州机场分公司总经理

成 员：黄 鹏 市政府应急办常务副主任、市政府新

闻发言人

董 杰 市公安局副局长

袁丰生 市民政局副局长

章广麟 市交通运输局副调研员

赖卫国 市卫生局副局长

黎德周 市安监局副局长

肖惠文 市武警支队副支队长

王栋梁 市消防支队参谋长

曾明荣 市国防动员委员会综合办公室秘书

领导小组办公室设在赣州机场分公司，由张福胜同志兼任办公室主任。
