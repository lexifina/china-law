# 关于赣州市青少年权益保护委员会更名及调整组成人员的通知

赣市府办字〔2012〕4号

关于赣州市青少年权益保护委员会更名

及调整组成人员的通知

各县（市、区）人民政府，赣州开发区管委会，市政府各部门，市属、驻市各单位：

为贯彻实施《江西省未成年人保护条例》，进一步加强未成年人保护工作，经市政府研究，决定将赣州市青少年权益保护委员会更名为赣州市未成年人保护委员会，并调整补充部分成员单位。现将更名、调整补充后的赣州市未成年人保护委员会成员名单通知如下：
