# 关于印发赣州市2012年现代物流产业发展工作要点的通知

赣市府办字〔2012〕60号

关于印发赣州市2012年现代物流产业

发展工作要点的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

经市政府研究，现将《赣州市2012年现代物流产业发展工作要点》印发给你们，请结合实际，认真贯彻执行。

二○一二年四月二十一日

赣州市2012年现代物流产业发展工作要点

2012年是落实“十二五”规划的关键一年，我市现代物流工作总的指导思想是：坚持以科学发展观为指导，全面贯彻市第四次党代会精神，以赣南苏区振兴发展为契机，以加快物流基础设施和信息平台建设、完善物流政策平台和体制机制建设为重点，促进现代物流产业快速、健康、可持续发展，使物流产业成为赣州经济社会发展新的增长点，推动赣州经济社会加快发展、转型发展，为实现赣粤闽湘四省通衢的区域性物流中心奠定基础。

一、进一步完善物流政策平台建设，营造物流产业快速健康发展软环境。根据《关于加快建设赣州市区域性物流中心的实施意见》的精神，配套出台相关实施细则，扶持和规范全市物流产业发展。进一步完善物流发展体制、机制建设，通过成立专门机构以及建立相关的考核、评审制度，使全市物流管理专业化、常态化。

二、进一步加快物流载体建设，基本形成全市物流配套设施网络。全市物流载体建设总体参照工业园区的建设模式进行。加快赣州综合物流园区返迁房建设、水电路等基础设施建设，主体一期工程全面竣工；中心城区六大物流节点完成控制性详细规划编制工作。除空港物流中心外，其余5个物流节点开工建设；各县（市、区）完成县级物流中心项目备案和控制性详细规划编制等工作，并全面开工建设。

三、进一步扶持物流企业发展，初步形成较为完善的物流企业体系。各县（市、区）重点扶持1-2家货运代理企业上规模，引进1-2家具有现代物流意识和现代物流技术的企业，特别是物流信息咨询机构、物流规划研究机构等技术水平较高的物流企业；全市推举1-2家实力雄厚、管理规范的物流企业，参加全国AA级物流企业评选，打造赣州物流品牌；建立物流企业信誉评定机制，引导和规范中小物流企业的运营，使全市物流企业格局进一步优化，初步形成较为完善的物流企业体系。

四、进一步推进物流信息平台建设，初步形成赣州物流信息网络。以赣州综合物流园区的信息中心为载体，全面启动赣州物流公共信息平台建设，完成物流信息平台的监控中心、资讯中心和交易中心三大模块建设，并投入使用。

五、推进专业物流的发展，形成赣州专业物流优势。完成南康家具物流中心、赣州开发区粮食物流中心建设，发展专业化、信息化的第三方物流；加快推进会昌盐业物流中心建设。

六、加强全市物流统计工作，初步建立全市物流统计指标体系。建立覆盖全市的物流调查统计数据库，不断加强全市物流统计工作。参与物流调查统计的工业企业、商贸企业和物流企业每月上报一次相关数据；各县（市、区）安排专门人员每个月上报一次相关物流统计数据。各地统计上报情况将作为年度考核的依据。

七、抓好物流标准化试点工作，推进物流新技术、标准化的推广应用。在规模以上物流企业推广GPS、EDI电子数据交换等先进技术，各县（市、区）在上半年至少抓好一个试点企业，并在下半年将试点的成功经验进行推广。

八、推进物流宣传交流平台建设，形成良好的宣传舆论氛围。充分发挥赣南日报社、赣州电视台、赣州广播电台和赣州现代物流网的传媒效应，加大对物流产业的宣传力度；继续办好《赣州物流新视界》和《赣州物流简报》，及时发布和传递物流产业发展信息，加强对物流项目和重点企业的经验总结，发挥其在全市物流发展中的引领作用，各县（市、区）每个月至少有一条信息发表。

九、加强物流人才培训，提升全市物流专业化水平。由市物流办牵头举办一期物流统计专业知识培训，各县（市、区）至少举办一次物流基础知识讲座或者培训。由各级物流协会牵头，年内举办一期物流师资格考前培训，培养一批在岗物流师。

十、加强物流协会建设，充分发挥物流协会作用。发挥行业协会服务企业的作用，参与行业调查、统计、咨询等工作；优化赣州物流资源配置，推进赣州现代物流产业发展；积极与地方政府部门联系，大力支持地方企业发展。
