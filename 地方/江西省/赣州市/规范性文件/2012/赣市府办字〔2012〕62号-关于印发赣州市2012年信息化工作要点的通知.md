# 关于印发赣州市2012年信息化工作要点的通知

赣市府办字〔2012〕62号

关于印发赣州市2012年信息化工作要点的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

为指导和推进全市信息化建设工作，经市政府同意，现将《赣州市2012年信息化工作要点》印发给你们，请认真贯彻落实。

二○一二年四月二十七日

赣州市2012年信息化工作要点

2012年我市信息化工作的总体思路是：以科学发展为主题，以加快发展方式转变为主线，牢固树立“发展为先、生态为重、创新为魂、民生为本”的理念，深入推进工业化和信息化融合，加快电子政务建设，扎实推进社会各领域信息化，有效提升信息化应用水平，促进全市经济和社会各项事业又好又快发展。

一、完善基础设施建设

（一）加快宽带网络光纤化升级。通过建设覆盖全市各县（市、区），集IP化、宽带化、融合化为一体的城市光纤宽带网络，逐步实现“百兆到户、千兆进楼、百万兆出口”的网络能力，互联网接入速率城区20M，行政村8M。

（二）推进无线城市建设。加大TD网络基础设施投资力度，做好TD基站、机房、管道建设，TD信号覆盖到每个乡镇。铺设以TD/LTE为主干，以WLAN为辅助的无线宽带，提供覆盖全市19个县（市、区）的无线宽带服务。

二、大力推进“两化”融合

（三）加强“两化”融合项目建设。围绕促进经济发展方式转变、促进产业结构优化升级这一主线，在稀土、钨、氟盐化工、电子、食品、机械等重点产业中，组织实施具有示范推广意义的信息化与工业化融合项目，推进研发设计、过程控制、企业管理、物流市场、人力资源开发、新兴产业和技术改造等环节两化深度融合。

（四）开展企业信息化主题活动。组织协调电信、移动等通信运营商，深入实施“信息化入园”工程、“万家数字企业建设”活动、企业信息化“千百万工程”等主题活动，突出企业主体地位，积极引导企业利用通信运营商搭建的信息化服务与应用平台，开展信息化应用，提高企业信息化水平。

（五）推动电子商务应用。鼓励骨干企业建立电子商务平台，引导中小企业广泛开展电子商务应用，拓展B2B、B2C等模式在工业企业的应用，推广在线交易、电子支付及物流的一体化集成，提升企业采购和营销效率。

（六）推进物联网产业发展。以项目为抓手，以试点、示范为引导，加快培育推动物联网应用和产业化，并积极争取国家物联网产业发展基金支持。

三、积极推进电子政务

（七）进一步完善电子政务统一网络平台。按照全省统一IP地址的改造技术规范标准，全面完成全市电子政务网乡乡通工程，为各级政务部门开展面向乡镇的业务应用提供网络服务。启动建设电子政务涉密内网升级改造工程，满足政务部门涉密业务系统传输需要。

（八）建立完善共享数据统一交换平台。依托全市电子政务网，建立完善我市共享数据统一交换平台并推广应用，实现跨部门、多业务、异构系统和异构数据库之间的数据交换与共享。

（九）加快推进网上办公。推广和利用市电子政务统一应用平台进行网上办公和公文传输，对接入各单位使用网上办公系统的情况，列入机关效能考核。加快各县（市、区）网上办公和公文传输系统建设，逐步实现与市级电子政务统一应用平台的对接。

（十）强化政府门户网站建设。对赣州市人民政府门户网站进行改版，在5月中上旬上线运行，建立涵盖市政府部门网站的政府网站群，加大政务资源整合力度，深化政务公开、网上办事、在线访谈、网络问政等功能，拓宽公众参与渠道，着力打造对外一站式公共服务平台。加强网站内容保障工作，进一步明确各地各部门相关栏目内容上传、更新和维护任务，定期进行检查和通报，确保网站内容的丰富和及时更新。开展政府网站绩效评估工作，提升市政府部门网站和县（市、区）政府门户网站建设水平。

（十一）推动科技反腐水平提升。建设公共资源网上交易系统，推广电子化招投标，以信息化推动公共资源交易规范化、程序化、公开化；探索建设“云监察”综合平台，对行政权力运行及公共服务情况进行实时、同步、全程电子监察。依托电子政务内网，建设纪检监察综合办公信息管理系统和办案信息管理系统。

（十二）完善财税信息化建设。继续做好财政应用支撑平台的修改完善工作，实现与人民银行的联网；推进综合治税平台建设，完成基础数据的收集和填报，用信息化手段有效提高税收征管质量与效率。做好金税三期工程广域网项目实施后续工作，保障网络安全运行。

四、加快推进“数字赣州”建设

（十三）启动“数字赣州地理空间框架”项目建设。按照市政府与省测绘局签订的合作协议，开展“数字赣州地理空间框架”项目建设，建立全市统一的基础地理信息数据库和地理信息公共平台。

（十四）加快中心城区“数字化城管”项目建设。完成项目软件开发及硬件采购，明确城市部件权属，完成网络及机房建设，争取在2012年正式上线运行，提高城市管理信息化水平。

（十五）建设“赣州市房地产信息系统改造升级”项目。实现部、省、市、县住房信息系统联网及县（市、区）一体化管理，构建全市统一的房地产管理综合信息系统和基础数据管理平台，实现“以图管房，以房管档，图、文、档一体化”的新型管理模式。

（十六）开展“警用地理信息基础应用平台（PGIS）”项目建设。建设PGIS基础平台，并基于基础平台推进各项应用系统建设，更好地服务于公安指挥调度工作。

（十七）启动“金土工程”二期建设。建设国土资源“一张图”工程，完成市级数据中心和安全体系建设，利用二调成果建立国土资源“一张图”本底数据库，深化“一张图”在国土资源全流程的应用，逐步实现“以数管地”到“以图管地”的转变。

五、协调推进社会各领域信息化

（十八）继续推进“金保工程”二期建设。逐步实现社会保障“一卡通”，融合人力资源和社会保障两大业务，打造基础设施、业务经办、公共服务和管理决策四大平台，不断深化人力资源和社会保障信息化。

（十九）完善交通信息监控平台的建设。在现有中心城区公交、出租车实时监控基础上，逐步将危货车辆、客运车辆、货运车辆纳入监控平台管理，进一步拓展和丰富监控平台使用功能，提高对交通突发事件的防范能力和应变能力。

（二十）建设综合防灾减灾应急指挥中心。通过视频会议系统建设，实现全市各县（市、区）民政系统综合防灾减灾应急指挥中心与省、市应急指挥中心互联。

（二十一）实施“阳光医药”项目建设。按照全省统一部署，加强医药卫生系统信息化建设，完善业务应用系统，建立对医药采购、流转等环节的电子监察。

（二十二）加快档案系统信息化建设。实施数字档案馆建设，开展馆藏档案数据录入工作，应用信息技术对数字档案信息进行采集、加工、存储、管理和网上查询服务。有效整合、共享数字档案资源，市、县两级接入全省政务网档案资料查阅平台。

（二十三）积极实施“金统工程”项目建设。按照国家统计局“统筹考虑、统一规划、分期建设、分步实施”的规划要求，以企业一套表改革入手，建设基本单位名录库、企业一套表制度、数据采集处理软件系统和联网直报系统等“四大工程”项目；建立省、市、县政府统计部门联网视频会议系统。

六、扎实推进农村和农业信息化

（二十四）完善农村综合信息服务体系。推进乡镇农业服务中心和农村综合信息服务站建设，充实电脑网络、光盘影像、报刊资料等基础手段，配备兼职信息员，开展信息查询、咨询和培训服务。

（二十五）完善农业综合信息网站。以“赣州农网”和“赣州农业和粮食网”为载体，建立全市农业信息发布系统，提升信息收集、整理和发布水平，丰富信息资源，加强交流互动，提高信息服务效果。

（二十六）建立“赣南脐橙灾害监测信息发布绿色通道”。建设脐橙预警短信发布系统，整合农口资源，将冻害天气预警、水利灾害、病虫灾害等预警信息纳入该系统，建立“赣南脐橙灾害监测信息发布绿色通道”，保障赣南脐橙产业发展。

（二十七）建立特色农产品信息化服务体系。围绕脐橙、蜜柚、板鸭等我市优势农产品，积极发展电子商务，建立跨区域、专业化的特色网站和交易网络，形成以批发市场、物流调度中心、商品集散地为依托的特色农产品电子商务服务体系。

七、加强信息安全保障

（二十八）落实《政府信息系统安全检查办法》，开展信息安全检查，按照“谁主管谁负责、谁运行谁负责、谁使用谁负责”的原则，搞好安全隐患排查和整改，健全管理制度，加强防范措施，提升信息安全防范能力。

（二十九）完善电子政务网网络和信息安全管理机制，建立健全各种管理制度，完善电子政务网信息安全应急预案，保障电子政务网安全稳定运行。

（三十）开展网络安全评估、检测工作，组织专业评测机构对电子政务网运行状况进行检测和安全评估，并根据检测和评估结果进行网络改造，提高政务网络的稳定性和安全性。

八、加大信息化推进措施

（三十一）建立健全信息化政策体系。积极借鉴先进城市的经验做法，结合本地实际，制订或修订完善我市信息化建设和项目管理、政府网站建设与管理、信息资源开发利用与共享等方面的管理办法或实施细则，推进和保障信息化建设。

（三十二）加大信息化建设投入。各级财政安排信息化专项资金，引导和支持全局性、基础性、示范性、带动性和公益性的信息化项目建设。努力争取国家、省各类信息化建设与应用试点和政策扶持，采取以奖代补、招商引资等方式促进重大信息化项目建设。

（三十三）强化信息化专业队伍。加强市、县二级信息化系统队伍建设，建立专业技术机构，增加专业技术人员编制，保障政府门户网站、电子政务网络、应用系统、信息网络安全等电子政务建设与应用工作的有效开展。加强信息化技术人才培养和引进，开展党政领导干部、机关工作人员信息化学习培训，举办信息化讲座，加强信息化典型宣传，提高全社会信息化意识。
