# 关于印发赣州市2012年现代农业产业园区建设实施方案的通知

赣市府办字〔2012〕65号

关于印发赣州市2012年现代农业产业园区

建设实施方案的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

经市政府同意，现将《赣州市2012年现代农业产业园区建设实施方案》印发给你们，请认真组织实施。

二○一二年五月四日

赣州市2012年现代农业产业园区建设实施方案

为进一步推进我市现代农业发展，转变农业增长方式，发挥现代农业产业园区示范带动作用，加快农业现代化建设步伐，根据《赣州市2012—2016年现代农业产业园区建设工作方案》，特制定本实施方案。

一、目标任务

以赣南苏区振兴发展为契机，围绕脐橙、生猪、花卉苗木、蔬菜、油茶、工业原料林等六大农业主导产业及区域优势特色产业，2012年全面启动现代农业产业园区建设，各县（市、区）要根据实际，集中力量抓好一个以上现代农业产业园区或现代农业园区，市级重点抓好瑞金、信丰两个脐橙产业园区。

二、基本原则

（一）坚持统筹规划、分步推进。园区建设要与自然资源、产业基础、重大项目、区域发展和统筹城乡发展等综合考虑，统筹规划、分步实施。

（二）坚持政府引导、市场运作。园区建设要按照“项目集合、资金集中、要素集聚、效益集显”的要求，强化政府扶持资金的引领作用，引进工业园区建设先进理念，建立多渠道投融资机制和多元化投资格局，营造良好的投资环境。

（三）坚持保护耕地，尊重农民意愿。园区建设必须严格保护耕地，不得改变土地性质和用途，严禁各种圈地和滥占耕地行为。充分尊重农民意愿，按照依法自愿有偿，开展土地承包经营权流转，引导发展适度规模经营，维护农民合法权益。

（四）坚持园区自我发展，增强带动能力。园区要通过机制创新、技术创新，提升产业发展水平，增强自我发展能力。积极发挥园区示范推动作用，应用现代农业科技，辐射带动园区周边地区发展高效农业，带动培育市场竞争主体，推动现代农业全面发展。

三、进度安排

园区建设采取基础设施边建设、入园企业边引进、对外招商边进行、入园企业边施工的办法进行，园区新引进企业于引进后的次年投产。（瑞金、信丰脐橙产业园区建设进度按照〈赣南（瑞金、信丰）脐橙产业园建设2012年工作方案〉执行。）

（一）2012年5月底前，完成园区选址、用地规模的规划调整，启动园区规划工作。

（二）2012年6月底前，完成园区详细规划，制定园区建设方案，完成园区项目建设立项、土地报批等申报工作。制定企业入园原则、总体要求、优惠政策、主要入园企业类别等，编制完成入园企业及招商指南。启动基础设施建设工作。

（三）2012年8月底前，完成园区主要基础设施建设，入园企业开工建设。

四、保障措施

（一）科学编制园区建设规划。各县（市、区）要按照“适度超前，整体规划，分步推进，突出特色，错位发展”的要求，迅速制定园区规划，园区的选址、定位要与农业主导产业发展规划相结合、与区域特色产业发展规划相结合、与统筹城乡发展规划相结合、与新农村建设规划相结合、与经济社会发展规划相结合。规划编制要坚持风格的独特性、经营的规模性、功能的多样性，因地制宜地划分标准化种植、养殖、加工、物流及休闲观光等功能分区，科学设计建设周期，合理划分建设阶段，全方位、多层次地丰富园区建设内容。

（二）加快园区基础设施建设。充分利用优势资源，加快园区内产业与现有基础设施对接，促进基础设施利用效益的最大化，提升园区项目承载能力。加快园区基础设施建设速度，市、县相关职能部门要各司其职，结合实际，系统安排，加强配合，逐步完善配套设施，合力推进园区基础设施建设。

（三）加强园区招商引资工作。紧紧围绕园区建设规划、产业定位和优势资源，精心包装农业招商项目，通过“走出去，请进来”的方式，运用推介会、以商招商、网络招商等形式，全方位开展招商引资引企。积极引导民间资本和金融资本进入园区建设领域，着力引进一批有实力、有潜力的龙头企业入园。

（四）强化政策支持。认真落实促进现代农业发展的政策措施，建立健全促进园区建设的政策体系。各县（市、区）要制定扶持园区建设的政策措施，加大财政资金投入力度，在用地、用水、用电等方面给予优惠，在品牌创建、产业发展等方面给予奖励，充分调动各方面参与园区建设的积极性。按照“目标统一、渠道不变、有效整合、管理有序”的要求，以县为单位，整合发改委、财政、科技等部门相关涉农资金及扶贫、农业、林业、农业综合开发、水保、水利、农机等部门相关项目资金统筹用于园区内项目建设。要密切与各商业银行、政策性银行的合作关系，安排产业发展专项贷款，逐步提高信贷规模；加强银企合作，促进银企对接，切实解决园区企业的融资困难。

（五）加强组织领导。市政府由分管副市长负责、市农办牵头，相关成员单位参与，定期会商，合力推进，协调解决建设中存在的问题，保障园区建设有序进行。各县（市、区）也要建立协调机制，推进园区加快发展。

（六）强化督查考核。各县（市、区）及市直有关部门要定期调度园区建设进度，市农办负责对全市现代农业（产业）园区建设情况进行考核,对如期完成年度目标任务的给予表彰奖励，对未完成年度目标任务的给予通报批评。
