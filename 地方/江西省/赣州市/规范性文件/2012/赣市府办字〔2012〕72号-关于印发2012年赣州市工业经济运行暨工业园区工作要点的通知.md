# 关于印发2012年赣州市工业经济运行暨工业园区工作要点的通知

赣市府办字〔2012〕72号

关于印发2012年赣州市工业经济运行

暨工业园区工作要点的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

《2012年赣州市工业经济运行暨工业园区工作要点》已经2012年4月22日市工业及工业优势产业集群培植工作领导小组会议审议通过，现印发给你们，请认真贯彻执行。

二○一二年五月十一日

2012年全市工业经济运行暨工业园区工作要点

2012年是实现未来五年发展目标的起步之年，为全面贯彻落实市第四次党代会和市第四届人大一次会议精神，加快推进“三个三”产业集群和工业园区建设，保持全市工业经济平稳快速增长，全面实现年度各项目标任务，意义重大。

一、工作思路

紧紧围绕市委、市政府确定的年度工业经济和工业园区发展目标，以推进“三个三”产业集群建设为契机，以工业园区为平台，牢牢把握全市工业经济运行及各主导产业的特点和趋势，强化工业经济运行监测、调度、分析、预警，强化工业园区基础、配套、服务设施建设，做强产业龙头，做大经济总量，推进产业集聚，促进全市工业经济又好又快发展。

二、发展目标

（一）工业经济预期目标

1．全市工业经济预期目标。规模以上工业增加值510亿元，增长18%；主营业务收入2300亿元，增长30%；利税总额260亿元，增长30%。

2．县（市、区）预期目标。（见附件1）

（二）工业园区发展目标

1．实现工业增加值500亿元，增长18%；

2．主营业务收入突破2000亿元，达到2300亿元，增长39%；

3．上缴税收达到80亿元，增长24.6%；

4．从业人员达到30万人；

5．主营业务收入过百亿元工业园区力争达到8个；

6．新增投产企业300家，其中新增规模以上企业100家；

7．投资亿元以上的开工在建项目100个，新增主营业务收入过亿元的企业60户，新增税收超千万的企业40户；

8．22个特色产业主要经济指标占全市工业园区主要经济指标的50%以上。

各工业园区指导性目标任务见附件2。

三、主要工作任务

（一）工业经济运行方面

1．建立健全工业监测预测和分析信息直报工作机制。一是认真做好网上数据直报工作。根据省工信委的要求，认真组织重点企业和重点园区做好工业经济运行监测管理系统的数据网上直报工作，建立工作制度，抓好工作落实，确保各填报单位如期保质完成各类信息数据的填报工作。二是加强工业运行预测分析。及时采集各单位网上填报的各类信息数据，全面客观分析预测工业运行情况，及时为领导提供高质量的月度工业运行数据信息。三是建立工业统计预报制度。各县（市、区）在每月28日前报送本地区规模以上工业当月及累计产值、主营业务收入和利税总额预计完成情况。四是不断夯实工业统计基础。各县（市、区）要以工业一套表统计改革和网上直报工作为契机，进一步加强基础数据库建设，建立涵盖各行业、各园区、各县（市、区）、各重点企业的基础数据库、资料库。

2．进一步加强工业运行调度力度。一是坚持工业运行调度分析例会制度。原则上每月组织召开一次全市工业经济运行调度会议，加强市、县信息沟通和工作协调。二是加强工业运行调研分析。针对各阶段工业运行情况，要有针对性地组织开展各类工业调研活动，认真分析工业运行中出现的热点和难点问题，为领导决策提供准确依据。三是不断创新工作方式。针对新形势下工业运行工作中出现的各类问题，要善于学习，大胆创新，积极谋求工业运行调度工作的新思路、新方法。

3．进一步加强对重点企业协调服务。一是逐步建立和完善重点企业领导挂点帮扶制度。通过领导挂点帮扶，部门合力推动，不断提高扶优扶强工作质量，积极为企业发展营造良好环境。二是明确重点企业协调服务工作机制。列入市重点调度的企业（见附件3），可随时向各级工信委（局）反映企业发展中存在的困难和问题，对需市政府综合协调解决的重大问题，由市工信委负责上报市政府，组织召开企业现场办公会议或专题协调会议研究解决；对需市有关单位和部门解决的，由市工信委转送给各相关单位进行解决，并进行跟踪落实；对需县（市、区）协调解决的问题，各县（市、区）要认真加以协调解决，市工信委负责对解决情况进行跟踪落实。同时，各县（市、区）、赣州开发区也要相应完善重点企业协调服务制度，加强对本区域内重点企业的帮扶，切实提高企业服务水平和质量。

4．进一步加强运行监测预警体系建设。一是拓展经济运行监测分析的广度和深度。加强与有关部门之间沟通协调，在全市逐步构建包括产业、金融、税务、电力、投资等各方面在内的运行监测分析格局。有针对性地分行业、分企业、分县市对各个监测层次按不同情况分类调度，密切关注企业订单、库存、资金、用工、用电、物流、新增长点等指标的动态情况，实现精细化调度。二是建立健全产品价格监测预警机制。提高全市主要工业品价格的监测面和调度频率，分析价格走势及对工业运行的影响，对价格跌幅超过一定程度的产品及时预警。三是抓好对重点监测服务对象的调度扶持。进一步强化对优势产业、重点企业、重点园区、重点县（市、区）、省级产业基地的监测调度，加强指导协调。

5．进一步加强运行协调保障体系建设。一是强化生产要素保障。加强引导企业节能降耗、节约用电，保障工业用电需求；积极探索银企合作融资方式，努力缓解企业融资难状况；加强运输协调力度，切实保障重点企业运输要求。二是做好生产综合协调服务。采取召开会议、现场调研等多种方式，加强对倾向性、苗头性问题和热点难点问题的调查研究，及时提出有针对性的政策措施建议，协调解决企业生产经营中的实际问题。三是引导企业开拓市场。进一步摸清企业市场订单、产销库存情况，针对不同情况进行分类指导，积极帮助企业拓宽销售渠道，提高工业品产销衔接水平。

6．进一步加强省级产业基地培育体系建设。一是积极引导和支持各县（市、区）加快省级产业基地的培育建设工作，着力解决好省级产业基地申报和建设过程中的困难问题，全年力争新增省级产业基地2-3个。二是大力促进产业升级。在省级产业基地中优选出一批产业集聚、企业集群、主业突出、特色鲜明的基地进行重点扶持，并配合省工信委组织条件成熟的基地申报国家级新型工业化产业示范基地。

7．进一步加强工业考核体系建设。科学合理编制2012年工业经济运行调控目标，将目标任务逐季度、逐县（市、区）、逐行业分解落实，明确责任，明确要求，加强目标调控管理，实行月度排序、季度通报、年度考核、动态督查制度。

各县（市、区）、赣州开发区每月28日前预测预报本地区的当月工业生产情况；市重点企业（名单见附件3）每月填报《2012年赣州市重点企业调度月报表》（见附件4），由各县（市、区）和赣州开发区负责通知企业填报，收集汇总后于次月10日前报市工信委经济运行科。（联系电话：8391187，电子信箱：gxwjjk @ganzhou.gov.cn）

（二）工业园区建设方面

1．打造四型园区。一是打造特色园区。实施差异化发展战略，根据不同区域经济发展的基础和特点，引导和突出特色产业园区规划建设，努力抢占产业发展制高点，推动产业转型升级，形成层次递进、特色鲜明、产业聚集、跨越发展的产业新格局，实现特色产业园区间的错位发展。重点推动22个特色产业园（基地）建设，每个县（市、区）集中人力、财力培育形成1个特色产业，特色产业主营业务收入占园区全部主营业务收入的比重超50%。二是打造生态园区。编制建设国家生态工业示范园区总体规划，并对生态示范工业园区建设的各项目标进行分解，对园区进行生态化改造，尽快达到生态工业园区建设规划的各项目标要求。按全省三年建成工业园区污水处理设施的目标，有步骤地完成我市工业园区污水处理设施建设任务。争取信丰工业园、南康工业园、瑞金经济开发区纳入省级生态园区试点，力争兴国经济开发区、大余工业园通过省级生态工业园验收。三是打造数字园区。加快园区工业和信息化的融合，提高园区信息化水平，实现省、市园区办与各工业园区的信息直通，建立园区基本情况数据库、园区项目数据库和园区投产企业基本情况数据库，并对园区基本情况、项目建设情况和企业运行情况进行动态管理。四是打造规模园区。按照五年内形成1个主营业务收入超1000亿、2个超500亿、5个超300亿园区的目标，到2012年底，赣州开发区主营业务收入要突破600亿元，赣县经济开发区突破200亿元，龙南经济技术开发区、于都工业园、沙河工业园、南康工业园分别达到150亿元，兴国经济开发区突破100亿元，其他园区力争突破60亿元并再用2-3年迈入百亿元园区的行列。在突出做大园区经济总量的前提下，注重园区的效益提升，特别要提高园区的投资强度。

2．破解三个节点。一是破解资金问题。充分运用现代金融工具，加快推进与银行业金融机构合作实施的“银园保”项目，加快推进中小微企业金融服务“入园进企”活动，切实破解园区企业、项目建设融资难的问题。二是破解用地问题。包装好大项目挤进省调度项目的“笼子”，使用省级预留指标。对超亿元以上的大项目要争取发改部门的指导，列入省重大项目调度名单，并跟踪项目进展情况；对战略性新兴产业项目要进行好包装，争取工信部门战略性新兴产业项目省预留指标；积极申报特色产业基地，争取基地建设用地指标。三是破解项目审批问题。推动建立园区项目报批“绿色通道”，凡是涉及规划、国土、安全评估、建设项目水资源论证、环境评估等工作，属县（市）级评估的，园区主要领导一定要亲自协调解决，争取用最短的时间完成；审批权限在市级以上部门的，安排专人跟踪落实，搞好服务。

3．强化保障措施

（1）用好两个调控手段。一是用好1000万左右的奖励扶持资金。每年向上争取的园区特色产业扶持资金、生态园区试点补助资金和市政府对园区经济总量上台阶奖励等三块总额1000万左右资金，对22个特色产业园区（基地）规划中发展好的产业进行重点扶持，对园区生态建设好的进行重点支持，以资金奖励扶持的手段引导园区转型发展。二是用好1000亩用地指标。市政府每年奖励市先进园区1000亩工业用地指标，要充分用好这1000亩用地指标指挥棒的作用，科学设置考评办法，加大园区引进重大特色产业项目的权重，让当年引进亿元以上特色产业项目，并当年开工的园区得到用地方面的支持，以用地指标奖励的手段引导园区加快发展。

（2）出台政策文件支持。争取尽快出台《关于加快全市工业园区发展的若干意见》，从理顺园区机制、完善职能、落实责任、优化环境、产业发展和加强领导等六个方面推进园区发展，同时进一步充实和完善相配套的文件，使园区建设得到多方面的支持。

（3）编制特色产业发展规划。加快园区特色产业规划工作，突出科学性、前瞻性、战略性和可持续性，着重发挥比较优势，注重环境容量，科学确定总体布局、产业导向、功能区块、生态环保和基础设施建设。全市工业园区、小企业创业基地特色产业规划要在2012年6月底前编制完成，并统一组织验收，对未完成产业规划的园区调整出市特色产业基地布局规划。

（4）推动特色产业大项目建设。通过加快建设大项目，带动产业结构大调整，培育骨干大企业，强化投入大支撑，推动技术大升级，提升工业园区的经济发展水平和核心竞争力。着力点放在政策措施的引导和支持上。一是确保大项目的用地需求。用地指标向大项目倾斜，在达到规定投资密度的前提下，大项目的用地指标计划由市协调安排或由市向省争取。二是支持大项目多渠道融资，深入开展以大项目为主体的银企合作活动，保证对大项目信贷支持的连贯性。三是帮助大项目争取国家和省有关技术改造、成果转化、科技创新等方面的资金扶持。四是对总投资亿元以上的大项目，实行一事一议的办法，给予更大幅度的优惠和奖励。五是对重点项目从谋划包装、立项审批到开工建设全程跟踪，落实一位领导、一套人马、一抓到底，并把推进项目按期开工、竣工作为园区重要考核内容，促进项目尽快投产。

（5）加快特色产业聚集。各园区要将优惠政策向特色产业倾斜，在推进产业集聚总体思路下设计吸引外资、外企的政策，有针对性地吸引具备产业带动优势和有产业关联效应或配套协作功能的项目进入工业园区；发挥产业存量资源优势，以产业关联度招商引资，通过产业链招商，着力引进大项目，按照“大项目—产业链—产业集群—制造业基地”的发展思路，充分发挥龙头企业的规模和技术优势，将其生产经营领域向上下游的产业延伸，培育自己的产业链条和产业体系，努力构建现代产业集群体系，积聚雄厚的产业基础；实施“腾笼换鸟”，把同类企业聚集到同一区域，把不符合本园区产业规划的企业调整出本园区功能区，并把与本园区特色产业关联度不高的企业作相应调整，腾出空间发展本园区特色产业的配套企业。

（6）推进园区配套建设。一是着力解决园区公共交通问题。各园区要协调公交部门千方百计增加公交线路，解决园区企业员工交通不便问题；二是加强基础设施建设。继续抓好水、电、路和公用设施的配套建设，不断完善综合配套服务功能，提高园区承载和配套能力；三是加强公共服务设施建设。改变园区生活服务设施与休闲娱乐配套设施发展滞后的现状，充分配合园区现代化、都市化的生活、教育、文化需求，加快园区经济和社会协调发展；四是增 加配套服务能力。努力解决园区企业员工子女就学问题，统一调控和安排就读学校，保障外来务工人员子女就读的稳定性。
