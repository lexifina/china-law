# 关于成立赣州市农村义务教育学生营养改善计划实施领导小组的通知

赣市府办字〔2012〕78号

关于成立赣州市农村义务教育

学生营养改善计划实施领导小组的通知

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

为进一步加强我市农村义务教育学生营养改善工作组织领导，经市政府研究，决定成立赣州市农村义务教育学生营养改善计划实施领导小组。组成人员名单如下：

组  长：陈晓春  市委常委、市政府副市长

杨雍谨  市委教育工委书记

成  员：张秀峰  市委宣传部副部长

领导小组下设办公室，办公室设在市教育局，负责推进农村义务教育学生营养改善计划实施的日常工作，蓝赟同志兼任办公室主任，余振柳同志兼任办公室副主任。
