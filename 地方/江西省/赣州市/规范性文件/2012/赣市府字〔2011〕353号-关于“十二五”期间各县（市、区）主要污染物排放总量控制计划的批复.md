# 关于“十二五”期间各县（市、区）主要污染物排放总量控制计划的批复

赣市府字〔2011〕353号

关于“十二五”期间各县（市、区）主要污染物排放

总量控制计划的批复

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

市环保局《关于审定“十二五”期间各县（市、区）主要污染物排放总量控制计划的请示》（赣市环文〔2011〕58号）收悉。现批复如下：

一、原则同意《“十二五”期间各县（市、区）主要污染物排放总量控制计划》（以下简称《计划》）。

二、化学需氧量、氨氮、二氧化硫和氮氧化物排放总量控制指标是国家确定的约束性指标，也是《赣州市国民经济和社会发展第十二个五年规划纲要》确定的约束性指标。到2015年底，全市化学需氧量和氨氮排放总量（含工业、生活、农业）分别比2010年减少6.8%（其中工业和生活排放量减少7.8%）、10.8%（其中工业加生活排放量减少11.0%）；二氧化硫和氮氧化物排放总量分别比2010年减少2.0%（其中火电排放量减少36.1%）、10.2%（其中火电、水泥、机动车排放量分别减少67.1%、27.3%、7.4%）。为确保排放总量控制目标的实现，现将这四项指标分解到各地（见附件），各县（市、区）人民政府及赣州开发区管委会必须严格执行，不得突破。

三、各县（市、区）及赣州开发区要将《计划》确定的主要污染物排放总量控制目标纳入本地经济社会发展“十二五”规划和年度计划，分解落实到有关行业和排污单位。要认真贯彻落实国家产业政策，坚决遏制高耗能、高排放、低产出项目投资增长，把住产业源头关，加快产业结构优化升级，切实转变经济发展方式。要落实工程措施和资金，狠抓重点领域、重点行业和重点企业减排，大力实施增量控制工程、机动车污染减排工程、火电等行业脱硫脱硝工程、污水处理厂减排工程和畜禽养殖污染减排工程。要加强环境监管执法，加大对各种违法排污行业的监督查处力度。要继续推进污染减排统计监测考核体系建设，加强对重点污染源的在线监控管理，构建农业源减排管理体系，强化机动车污染减排能力建设，确保实现计划目标。

四、市政府各有关部门要根据职能分工，加强指导和督促检查，密切跟踪《计划》执行情况。市发改委、市工信委、市规划建设局、市农粮局、市公安局等部门要对口分解、落实好任务。市环保局要牵头制订科学合理的考核指标体系，加强对《计划》完成情况的检查和考核，有关情况及时向市政府报告并向社会公布。
