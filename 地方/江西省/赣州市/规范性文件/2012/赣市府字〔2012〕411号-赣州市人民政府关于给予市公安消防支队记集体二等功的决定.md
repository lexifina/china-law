# 赣州市人民政府关于给予市公安消防支队记集体二等功的决定

赣市府字〔2012〕411号

赣州市人民政府

关于给予市公安消防支队记集体二等功的决定

各县（市、区）人民政府，赣州开发区管委会，市政府各部门，市属、驻市各单位：

近年来，在市委、市政府和公安机关的坚强领导下，市公安消防支队深入贯彻落实科学发展观，牢记全心全意为人民服务的根本宗旨，秉承和发扬苏区精神，紧紧围绕消防监督、火灾扑救和应急救援等中心工作，忠诚履职，顽强拼搏，奋勇当先，与时俱进，为建设创业、宜居、平安、生态、幸福赣州提供了坚强有力的消防安全保障。据统计，自2002年以来，全市消防部队共接警出动2万余次，扑救火灾9千余起，参加抢险救援1万余次，营救人员1.8万余人，保护国家和人民财产价值20多亿元；成功处置了2008年赣州冰灾、汶川震灾，大余县“7.3”、定南县“5.7”洪灾，信丰县“12.12”高层建筑火灾，赣州开发区“10.13”公交车被洪水围困等重大救援任务；圆满完成了北京奥运会、广州亚运会、第七届全国城市运动会、中国赣州国际脐橙节、党的十八大等重大活动消防安全保卫任务，取得了自赣州消防建队62年来全市未发生重特大火灾的显著成绩。市公安消防支队先后被公安部消防局表彰为“全国‘三基’工程建设先进单位”，被省委、省政府表彰为“全省抗冰救灾先进集体”，被市委、市政府、赣州军分区记集体二等功一次，是全省消防部队中唯一连续十年被评为“全省先进支队”的消防部队。2011年6月，市公安消防支队党委还被公安部表彰为“全国公安现役部队先进基层党组织”。

为表彰先进、树立典型，弘扬正气、鼓舞士气，根据《中华人民共和国消防法》第一章第七条关于“对在消防工作中有突出贡献的单位和个人，应当按照国家有关规定给予表彰奖励”的规定，市政府决定，给予市公安消防支队记集体二等功。

希望市公安消防支队和全市消防官兵珍惜荣誉，戒骄戒躁，再接再厉，再创佳绩。同时，号召全市各部门、各单位及广大干部职工以先进为榜样，深入贯彻落实党的十八大精神，立足本职，开拓进取，勤奋工作，为加快赣南苏区振兴发展作出新的更大贡献。

2012年12月12日
