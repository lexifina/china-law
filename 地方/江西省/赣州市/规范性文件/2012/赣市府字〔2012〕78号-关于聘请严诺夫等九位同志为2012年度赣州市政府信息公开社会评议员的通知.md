# 关于聘请严诺夫等九位同志为2012年度赣州市政府信息公开社会评议员的通知

赣市府字〔2012〕78号

关于聘请严诺夫等九位同志

为2012年度赣州市政府信息公开社会评议员的通知

各县（市、区）人民政府，赣州开发区管委会，市政府各部门，市属、驻市各单位：

鉴于2011年度社会评议员聘任期届满，为继续做好我市政府信息公开社会评议工作，根据《赣州市政府信息公开社会评议制度（试行）》的规定，经市政府研究同意，决定聘请严诺夫等九位同志（名单附后）为2012年度赣州市政府信息公开社会评议员，聘期一年。各级政府行政机关要积极支持和配合政府信息公开社会评议员的工作，认真和虚心接受社会各界的监督，切实提高政府信息公开的质量和水平。
