# 关于2012年1-2月全市工业运行情况的通报

赣市府字〔2012〕96号

关于2012年1-2月全市工业运行情况的通报

各县（市、区）人民政府，赣州开发区管委会，市政府有关部门，市属、驻市有关单位：

今年以来，在市委、市政府的正确领导下，全市工业战线围绕 “三个三”产业发展目标，加快推进工业转型升级，强化运行调度服务，全力做好工业统计一套表改革，全市工业运行总体平稳，主要指标保持了快速增长的势头。现将1-2月份全市工业运行情况通报如下：

一、基本情况

1-2月份，全市规模以上工业企业完成工业增加值72.22亿元，同比增长17.1%，较上年同期提高1.41个百分点，列全省第四位，较上年末前移三位；工业产品销售率达到100.55%；实现主营业务收入286.6亿元，同比增长36.4%；利税总额27.84亿元，同比增长55.2%，其中，利润总额14.82亿元，同比增长41.5%，税金总额13.02亿元，同比增长74.5%。

二、主要特点

（一）“三个三”产业平稳增长。十大主导产业中，从主营业务收入看，稀土、生物制药、氟盐化工和电子电器四大产业增长在50%以上，其中，生物制药增长最快，达到79.5%，氟盐化工和电子电器业的增速超过60%；从利税来看，稀土、生物制药和电子电器三大产业利税增幅在70%以上，其中，稀土产业增幅最大，达到1.4倍，生物制药产业也达到1.26倍；从利润来看，稀土、电子电器和食品三大产业利润增幅在50%以上，其中，稀土产业效益最为突出，达到1.01倍。从总体上看，稀土产业延续了上年强劲增长，电子电器、生物制药和氟盐化工三大产业年初发展势头较好。

（二）轻工业快速增长。轻工业完成工业增加值19.79亿元，同比增长21.52%，高于全市4.42个百分点；实现主营业务收入77.61亿元，同比增长36%；利税总额5.29亿元，同比增长48.3%；重工业完成工业增加值52.43亿元，同比增长15.33%，实现主营业务收入208.99亿元，同比增长36.6%，利税总额22.54亿元，同比增长57%。

（三）部分县（市、区）快速增长。全市共有8个县（市、区）规模以上工业增加值增速在20%以上，其中，瑞金市高达44.62%，赣州开发区和会昌县在30%以上；共有5个县（市、区）主营业务收入增速在50%以上，其中，崇义县达到65.9%，安远县和石城县也在60%以上；共有6个县（区）利税增幅在80%以上，其中，安远县高达5.37倍，赣县和全南县也在2倍以上。

（四）规模企业户数大幅增加。通过市、县各相关部门的共同努力，去年年报新入规企业81户，至二月底全市规模以上工业企业户数达到843户，较上年底（781户）增加62户。

三、存在的主要问题

（一）县域经济发展不平衡。受稀土分离企业停产和钨市场需求下降等因素影响，稀土分离企业和钨矿山产量下降，造成部分稀土加工县和钨矿资源县主要指标下降较大。全市共有8个县（区）增加值增速在10%以下，其中，大余、上犹、安远和定南等4个县同比下降；共有5个县的主营业务收入增速不足10%，其中，定南和全南2个县同比下降；共有7个县（市）利税增幅不到10%，其中，信丰、大余、定南和瑞金4个县（市）同比下降。

（二）中央、省属企业、国有及国有控股企业和中型企业发展偏缓。中央、省属企业工业增加值同比下降6.49%，主营业务收入同比增长1.7%，利税同比下降30.1%；国有企业工业增加值同比增长1.67%，主营业务收入同比下降2.9%；国有控股企业工业增加值同比增长9.24%，主营业务收入同比增长19.7%，利税同比下降9.3%；中型企业主营业务收入同比增长26.7%，利税同比增长21%。主要原因是国有钨矿和部分稀土分离企业产量下降较大所致。

（三）水泥和钢铁产业效益下滑明显。受市场因素和全省高耗能企业执行差别电价政策等影响，1-2月份，全市工业累计用电量7.56亿千瓦时，同比下降16.28％；非金属矿物制品业主营业务收入同比增长18%，利税同比下降34.1%；黑色金属冶炼及压延加工业主营业务收入同比增长10.8%，利税同比下降17.5%。

虽然1-2月全市工业经济保持了较快的发展态势，但工业增加值、主营业务收入和利税仅完成省下达一季度目标的64.5%、56.6%和49.6%，完成目标任务的压力较大。为此，各地、各部门务必进一步加大工作力度，抓好工业运行调度，切实帮助企业解决生产经营困难，力争实现一季度开门红。
