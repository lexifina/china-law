# 关于做好《赣州年鉴》2014卷编纂工作的通知

赣市府办字〔2014〕32号

赣州市人民政府办公厅

关于做好《赣州年鉴》2014卷编纂工作的通知

各县（市、区）人民政府，赣州开发区管委会，市政府各部门，市属、驻市各单位：

《赣州年鉴》是由赣州市人民政府主办、赣州市地方志办公室承编，按年度连续出版，全面记述赣州自然、政治、经济、文化、社会等方面情况的年度资料性文献，是国内外了解赣州、研究赣州、投资赣州的权威性资料工具书和科学性公共信息资源，具有存史、资政、育人的重要功能。为做好《赣州年鉴》2014卷编纂工作，确保年鉴按时出版，现就有关事项通知如下：

一、编纂内容和要求

（一）撰稿内容

《赣州年鉴》2014卷主要记述2013年度全市经济社会发展新成绩、新情况、新经验及各行业涌现出的先进人物、先进集体。年鉴采用分类编纂法，设类目、分目、条目三个层次，条目为年鉴内容的基本记述实体。各县（市、区）、市直、驻市各单位为年鉴主体撰稿记述单位，撰稿记述内容包括大事记，条目，人物、荣誉录三部分。

1．大事记。站在全市的角度记述2013年度内各地、各单位全面推进深化改革和苏区振兴发展进程中发生的大事、要事、新事、特事，按时间顺序，采用编年体和纪事本末体相结合的方式进行记述。

2．条目。条目撰写包括综合性和单一性两类。拟定综合性条目时，各地、各单位对2013年度发展变化的总体情况和主要特点进行概述，以保持年鉴资料逐年记载的系统性、连续性；拟定单一性条目时，各地、各单位应从年度工作的发展轨迹中筛选，找出确有价值的事件立目记述，一事一条，可适当运用表格和图片的形式反映，并配文字说明。条目总字数控制在3000字左右（不含大事记、人物及荣誉录部分）。

3．人物、荣誉录。即获省部级以上表彰的先进集体、先进个人和当年获正高级职称资格的人员，其中获得省以上劳模及国家部委与人社部联合表彰的系统模范人物需提供人物简介。

（二）撰稿要求

1．观点正确、资料翔实、重点突出、文约事丰。符合年鉴文体，述而不论，寓观点于记述之中。做到既不遗漏基本情况，又突出工作特色，确保资料全面、真实、准确。

2．严格遵守保密规定。各撰稿单位领导要对本单位稿件内容认真审定、严格把关，做到涉密内容不报，防止失泄密事件发生。

二、彩页征集

彩页图片是年鉴的重要组成部分，能全面记载和直观展现赣州的历史形象。各县（市、区）、各单位要大力支持年鉴彩页图片的征集入编工作，提供高质量的彩页图片，生动形象、图文并茂地展示各自风采以及赣州全面推进深化改革和苏区振兴发展取得的重大成果。

三、其他事项

各撰稿单位要切实加强领导，增强全局意识，明确分管领导，选派熟悉情况、具有较强文字能力的同志负责撰写。撰稿人员要增强责任意识，全面把握年度工作情况，按时保质完成年鉴文字稿撰写和图片征集入编任务。文字稿截稿时间为3月31日，要求纸质稿一式3份（署撰稿人和审稿人姓名，加盖公章），并附电子版和2013年度工作总结。彩页图片征集截稿时间为4月30日。联系地点：市地方志办公室秘书科（市政中心1号楼10楼东北11027室）；电子信箱：gzsdfzb@163.com ；电话：8391596（传真）、8391595、8391591。
