# 关于印发赣州市2014年法治政府建设工作要点的通知

赣市府办字〔2014〕37号

赣州市人民政府办公厅

关于印发赣州市2014年法治政府建设工作要点的通知

各县（市、区）人民政府，赣州开发区管委会，市政府各部门，市属、驻市各单位：

《赣州市2014年法治政府建设工作要点》已经市政府同意，现印发给你们，请认真贯彻落实。

2014年3月20日

（此件主动公开）

赣州市2014年法治政府建设工作要点

2014年，全市法治政府建设工作要按照党的十八大、十八届三中全会精神以及省委、市委贯彻落实三中全会《决定》的要求，紧紧围绕苏区振兴发展工作大局，切实转变政府职能，深化行政体制改革，创新行政管理方式，增强政府公信力和执行力，为实现全市经济又好又快发展和社会和谐稳定营造良好法治环境。本年度要重点抓好以下工作：

一、着力提高干部队伍运用法治思维和法治方式的能力

（一）落实领导干部学法制度。采取政府常务会、部门办公会议会前学法，举办法制讲座等多种方式，重点学习规范政府共同行为的法律法规特别是新颁布的法律法规，带动干部职工学法用法，年内集中学法不得少于4次。（县〈市、区〉政府，市政府各部门负责）

（二）组织依法行政知识培训。将依法行政知识纳入市委党校主体班次培训内容并组织专题研讨。各县（市、区）政府每年至少举办2期领导干部依法行政专题研讨班，学习依法行政理论，集中研讨制约本地依法行政工作的重点难点问题，增强领导干部的法治理念、法治思维。（县〈市、区〉政府，市政府法制办负责）

（三）加强公务员的普法教育。公务员每年学习法律知识不少于40学时，学法情况和考试成绩应记入档案，作为公务员考核、任职、定级、晋升的重要依据。（县〈市、区〉政府，市政府各部门负责）

（四）提高行政执法人员的法律素质。继续在全市行政执法部门开展“行政执法人员素质提高年”活动。加强行政执法人员综合法律知识和更新知识培训，采取不定期抽查等方式检验培训效果，对测试不合格者限期补考，补考仍不合格者建议离岗培训。（县〈市、区〉政府，市直各行政执法部门负责）

二、坚持依法科学民主决策，确保政府的各项决策和施政行为在宪法和法律的轨道上运行

（五）提高决策的公众参与度。凡是与群众切身利益密切相关的重大行政决策事项，决策机关应当通过政府网站、报纸、广播、电视等媒体公布重大行政决策方案草案，征求社会公众的意见，时间一般不少于20个工作日。（县〈市、区〉政府，市政府各部门负责）

（六）加大决策合法性审查力度。政府法制机构要从决策事项是否属于政府法定权限，决策内容是否合法等方面认真做好决策合法性审查工作。必要时，可邀请相关专家进行合法性论证。（县〈市、区〉政府，市政府各部门负责）

（七）积极开展决策风险评估。涉及征地拆迁、农民负担、国有企业改制、环境影响、社会保障、公益事业等方面的重大工程项目建设、重大政策制定以及其他对社会稳定有较大影响的重大行政决策事项，决策前都要进行社会稳定风险评估，风险评估结果作为决策的重要依据。（县〈市、区〉政府，市政府各部门负责）

（八）普遍推行法律顾问制度。加强市政府已有法律顾问队伍建设，使其在经济和社会发展事务中发挥更大作用。推动乡（镇）、县（市、区）政府、国有企业以及市、县有需要的政府部门、事业单位建立法律顾问制度。（县〈市、区〉政府，市政府各部门负责）

三、努力改进规范性文件制定及后续实施工作，建立适应发展需要的制度保障机制

（九）改进制定规范性文件调研方法。制定规范性文件调研要更加深入基层、深入实际，采取开放包容的心态，兼听各方意见、多听逆耳之言，找准事关改革发展大局的重点难点问题，全面系统研究，科学合理设计。加快已列入江西省2014年立法项目的《江西省稀土管理办法》和《江西省赣南脐橙保护办法》的调研、完善和报批工作。（市、县〈市、区〉政府法制办，市县〈市、区〉政府有关部门负责）

（十）做好规范性文件实施工作。规范性文件制定出台后，政府法制机构要督促指导执行部门制定宣传、培训、评估等具体实施方案，提高规范性文件的实施效果。（市、县〈市、区〉政府法制办，市县〈市、区〉政府有关部门负责）

（十一）加强规范性文件备案审查。政府法制机构对内容违法或者超越权限、违反法定程序制定的规范性文件，要及时通知制定机关在法定期限内作出处理；逾期不处理的，报请本级政府责令改正或者依法予以撤销，并向社会公布。（市、县〈市、区〉政府法制办，市县〈市、区〉政府有关部门负责）

四、加强行政执法监督，促进严格规范公正文明执法，树立和维护政府良好形象

（十二）深化行政执法体制改革。继续推进相对集中行政处罚权工作；推进跨部门、跨行业综合执法，避免交叉执法、多层执法、多头执法；完善执法程序，进一步规范执法自由裁量权；加强对行政执法的监督，促进公正文明执法，惩处趋利执法、粗暴执法、“钓鱼”执法。（县〈市、区〉政府，市直各行政执法部门负责）

（十三）深化行政审批制度改革。按照党的十八届三中全会《关于全面深化改革若干重大问题的决定》要求，进一步简政放权。对市场机制能有效调节的经济活动，一律取消审批；能够下放的经济社会事项，一律下放到县（市、区）管理。及时衔接落实好上级下放我市的各项行政审批项目，对保留的行政审批项目一律列入政府目录清单向社会公布，规范管理，提高效率；对下放的行政审批项目加强后续监管。（县〈市、区〉政府，市政府有关部门负责）

（十四）推行行政执法权力清单制度。对行政执法权力进行全面梳理，编制行政执法权力目录，明确行政执法权力名称、执法依据、执法主体、执法对象、执法内容、执法方式、执法程序和监督办法，加强对行政执法权力的管理，严格规范行政执法行为。（县〈市、区〉政府，市直各行政执法部门负责）

（十五）实行行政执法信息公开制度。制定行政执法信息公开办法，除涉及国家秘密、商业秘密和个人隐私的外，并经研究批准，行政执法信息必须在网站、行政服务大厅或窗口全面公开，重点公开行政执法权力目录、自由裁量权基准、行政执法结果、投诉举报方式和行政救济途径，自觉接受社会监督。（县〈市、区〉政府，市直各行政执法部门负责）

（十六）推行网上行政执法。加快建设执法办案系统与监督系统，逐步实现执法办案的网上流程管理、网上审批、网上监督和网上考评，对执法办案全过程实行动态实时监督。（县〈市、区〉政府，市直各行政执法部门负责）

（十七）加大重点领域执法监督力度。加强对执法频率高、与群众关系密切的有关重点行政执法部门的监督，年内围绕优化企业发展环境组织开展一次执法监督检查。（县〈市、区〉政府，市监察局，市政府法制办，市政府有关部门负责）

（十八）严格实行行政执法过错问责。畅通群众投诉举报渠道，认真受理群众反映的问题。明确行政执法监督的责任，加强行政执法内部监督，对行政执法失职渎职、弄虚作假、以权谋私等违反有关规定的行为，严肃追究直接责任人员和有关领导的责任；涉嫌犯罪的移交司法机关依法处理。（县〈市、区〉政府，市监察局，市政府法制办，市政府有关部门负责）

五、依法化解矛盾纠纷，实现定纷止争，维护社会稳定

（十九）提高行政复议公信力。加快推进市本级行政复议委员会试点工作，尽快组建赣州市行政复议委员会，吸收专家学者参与案件审理，保障行政复议独立公正，消除群众对行政复议公正性的疑虑，提高行政复议案件审理的透明度和公信力。推动县（市、区）政府创造条件逐步设立行政复议委员会。继续推进行政复议规范化建设，不断提高行政复议水平，让人民群众在每一起案件处理中都感受到公平正义。（县〈市、区〉政府，市政府法制办负责）

（二十）依法积极推进行政调解工作。注重把矛盾纠纷化解在基层，解决在萌芽状态。完善行政调解工作配套制度和推进措施，行政调解任务较重的部门应设立行政调解室、接待室，有条件的地方建立行政调解中心。注重行政调解与司法调解、人民调解的衔接，有效整合调解资源，提高行政调解工作效率。（县〈市、区〉政府，市政府法制办，市政府有关部门负责）

六、加快申报较大的市，力争我市在国务院重启审批后尽早成为获批城市

（二十一）加快申报“较大的市”。落实党的十八届三中全会《关于全面深化改革若干重大问题的决定》和国务院《关于支持赣南等原中央苏区振兴发展的若干意见》精神，加强与全国人大法工委、国务院法制办等部门的联系汇报和沟通协调，做好申报的各项工作，争取早日享有地方立法权。（市政府法制办、市人大内司委负责）

七、努力提高依法行政保障水平，确保各项工作有效落实

（二十二）强化组织领导。县（市、区）政府常务会议每半年听取一次依法行政工作汇报，政府及其部门推进依法行政工作领导小组定期召开成员单位负责人会议，研究依法行政工作重要事项，确保完成市政府确定的阶段性工作目标和各项具体工作任务。

（二十三）加强法制机构队伍建设。县（市、区）政府应当根据法治政府建设的需要，配齐、配强政府法制机构队伍，使政府法制机构规格、人员编制与其承担的职责和工作任务相适应。各县（市、区）要重视乡镇特别是中心镇政府的法制建设，加强工作力量配备，并落实专人负责法制工作。

（二十四）营造良好法治氛围。各地、各部门要通过报刊、广播、电视、网络等平台，采取各种形式广泛深入开展依法行政宣传教育，弘扬社会主义法治理念，努力营造学法、尊法、守法和依法办事的良好社会氛围。

各县（市、区）政府、市政府各部门要按照本工作要点，结合实际，及时制定年度工作计划，并于2014年4月上旬，报市推进依法行政工作领导小组办公室。
