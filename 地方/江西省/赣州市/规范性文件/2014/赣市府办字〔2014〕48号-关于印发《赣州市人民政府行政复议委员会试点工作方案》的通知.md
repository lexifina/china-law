# 关于印发《赣州市人民政府行政复议委员会试点工作方案》的通知

赣市府办字〔2014〕48号

赣州市人民政府办公厅

关于印发《赣州市人民政府行政复议委员会

试点工作方案》的通知

各县（市、区）人民政府，赣州开发区管委会，市政府各部门，市属、驻市有关单位：

《赣州市人民政府行政复议委员会试点工作方案》已经市政府同意，现印发给你们，请认真组织实施。

2014年4月15日

（此件主动公开）

赣州市人民政府行政复议委员会试点工作方案

为贯彻落实十八届三中全会精神，进一步改革行政复议体制，健全行政复议案件审理机制，提高行政复议工作公信力，发挥行政复议在解决行政争议、建设法治政府、构建和谐社会中的作用，根据《中共中央关于全面深化改革若干重大问题的决定》、国务院法制办《关于进一步加强行政复议工作规范化建设的实施意见》、省政府法制办《关于做好行政复议委员会试点有关工作的通知》及省推进依法行政工作领导小组办公室《关于开展行政复议委员会试点工作的函》的有关要求，结合实际，现就市本级开展行政复议委员会试点工作，制定本方案。

一、指导思想

坚持以邓小平理论、“三个代表”重要思想、科学发展观为指导，以完善、改革行政复议体制机制、提高行政复议案件办理质量和效率为目标，围绕行政复议职责范围、组织形式、运行机制、工作规则等内容，有效集中现有分散的行政复议资源，开展相对集中行政复议权工作，创新行政复议案件审理机制，强化政府依法解决行政争议的能力，进一步提高行政复议制度的公信力，为建设创业、宜居、平安、生态、幸福赣州创造良好的法治环境。

二、试点内容

（一）功能定位

赣州市人民政府行政复议委员会，是市政府授权负责审议行政复议案件、指导全市行政复议工作的议决机构。其宗旨是通过创新案件审查方式和方法，最大限度地化解行政争议、保证办案质量、提高复议决定公信力、保障当事人合法权益、维护社会和谐稳定。

（二）组织形式

按照国务院法制办和省人民政府法制办关于行政复议委员会试点工作的要求，组建赣州市人民政府行政复议委员会及其办公室。

1．行政复议委员会由主任、副主任、常任委员、非常任委员组成。主任由市政府分管法制工作的副市长担任；副主任由市政府负责协调法制工作的副秘书长和市政府法制办主任担任；常任委员由市政府法制办分管行政复议工作的领导、行政复议委员会办公室专职副主任及行政复议科工作人员担任；非常任委员30名，由经遴选的精通法律事务的行政执法机关工作人员、专家学者、政协委员等人员担任，任期为3年。

行政复议委员会的主要职责是：贯彻落实上级和市政府有关行政复议工作的决定、决议精神，研究行政复议工作的体制、机制及制度建设等重要问题；审议决定行政复议案件；负责对全市行政复议、行政应诉、行政赔偿工作进行监督检查与协调指导。

2．行政复议委员会下设办公室，与市政府法制办公室合署办公，对外挂“赣州市人民政府行政复议委员会办公室”牌子。市政府法制办公室主任兼任市行政复议委员会办公室主任，另设一名专职副主任主持行政复议委员会办公室的日常工作。

行政复议委员会办公室的主要职责是：具体负责市行政复议委员会的日常事务，承担行政复议案件受理、审理、行政复议决定起草、法律文书送达等工作，办理行政复议委员会交办的其他工作。

（三）运行机制

行政复议委员会对行政复议案件采取“统一受理、统一审查、统一决定”的运作方式。

1．统一受理。行政复议委员会办公室负责行政复议申请的立案受理工作，依法受理行政管理相对人不服县（市、区）政府、市政府各部门、市政府部门下设的独立执法部门（二级法人）的具体行政行为提起的行政复议申请。市政府各部门不再受理行政复议案件，对县（市、区）政府部门作出的具体行政行为不服而提起的行政复议申请，由所在的县（市、区）政府受理。对中央垂管部门行政复议案件的受理，仍按照国家现有法律规定执行。

2．统一审查。行政复议案件立案受理后，行政复议委员会办公室根据案件实际情况，组成案件审查组，负责案件的承办工作，通过调查、听证、现场勘验、研究讨论、表决等方式审理案件，形成行政复议案件审结报告。

3．统一决定。行政复议决定统一以市政府名义作出，行政复议决定书加盖“赣州市人民政府行政复议专用章”。

（四）保障措施

1．人员保障。行政复议委员会办公室具体机构和人员编制由市政府法制办参照市中级人民法院行政庭的人员编制情况按照程序向市委编办申请报批。

2．经费保障。试点筹备工作所需经费经市政府批准后，由市财政一次性安排解决；工作步入正轨后，根据工作需要，将行政复议工作经费列入财政预算。

3．场所保障。根据办公用房管理规定和实际需要增配办公、案件审理场所。

4．车辆保障。在公务用车改革时统筹考虑。

三、工作步骤

（一）准备阶段（2014年4月底前）

根据国家、省关于开展行政复议委员会试点、相对集中行政复议权的要求，拟定试点工作方案，呈报市政府审批。

（二）筹办阶段（2014年7月底前）

根据市政府批准的试点工作方案，确定行政复议委员会组成人员及办公场所，制定行政复议委员会工作规则等配套工作制度，完善受理审查的各种法律文书，做好试点运行的各项筹备工作。开展行政复议委员会专题宣传活动。

（三）启动阶段（2014年8月底前）

召开第一次全体委员会议，正式启动“统一受理、统一审查、统一决定”的行政复议委员会试点工作运作方式，并在运作中不断总结完善。
