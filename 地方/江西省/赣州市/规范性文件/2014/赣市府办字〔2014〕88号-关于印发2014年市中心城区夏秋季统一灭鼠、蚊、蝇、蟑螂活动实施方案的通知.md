# 关于印发2014年市中心城区夏秋季统一灭鼠、蚊、蝇、蟑螂活动实施方案的通知

赣市府办字〔2014〕88号

赣州市人民政府办公厅

关于印发2014年市中心城区夏秋季统一

灭鼠、蚊、蝇、蟑螂活动实施方案的通知

章贡区人民政府，赣州经济技术开发区管委会，市政府各部门，市属、驻市各单位：

经市政府研究同意，现将《2014年市中心城区夏秋季统一灭鼠、蚊、蝇、蟑螂活动实施方案》印发给你们，请结合各自工作，认真组织实施。

2014年8月28日

（此件主动公开）

2014年市中心城区夏秋季

统一灭鼠、蚊、蝇、蟑螂活动实施方案

为进一步巩固省级卫生城市创建成果，迎接省爱卫会对我市省级卫生城市的复审，有效遏制夏秋季老鼠、蚊子、苍蝇、蟑螂的危害，保障人民身体健康，根据《江西省爱国卫生工作条例》，决定组织开展2014年市中心城区夏秋季统一灭鼠、蚊、蝇、蟑螂活动，特制定本实施方案。

一、工作目标

通过本次活动，确保市中心城区的老鼠、蚊子、苍蝇、蟑螂密度控制在省级卫生城市标准范围。市中心城区各单位、街道及社区的鼠、蚊、蝇、蟑螂密度明显降低。

二、实施范围

本次活动在章贡区、赣州经济技术开发区所辖城区范围内全面开展。章贡区、赣州经济技术开发区的乡镇参照本通知要求，结合当地实际制定方案组织实施。

三、组织领导与责任分工

本次活动在市政府统一领导下，由市爱卫会具体组织实施。坚持“属地管理，块块为主，条条保证，条块结合”的原则。章贡区政府、赣州经济技术开发区管委会、市直各部门、市属（驻市）各单位依照职责管辖范围，做好辖区内本部门、本单位、本行业的灭鼠、蚊、蝇、蟑螂活动。具体责任分工如下：

市爱卫会：负责病媒生物防治专业队伍的培训、技术指导和监督，负责公共场所（公共绿地、下水道、河堤、公园）的灭鼠、蚊、蝇、蟑螂活动开展。

章贡区政府、赣州经济技术开发区管委会：按照属地管理的原则，以街道办事处、居委会为主体，负责辖区内的驻片机关团体、企事业单位、居民住宅区居民户的灭鼠、蚊、蝇、蟑螂活动的组织开展。

市城管局：负责组织中心城区环境卫生综合整治，垃圾中转站、垃圾池、垃圾填埋场的灭鼠、蚊、蝇、蟑螂活动的开展，及安装下水道口“五防”设施。

市卫生局、市食品药品监督管理局：负责餐饮单位和公共场所及“六小”行业单位灭鼠、蚊、蝇、蟑螂活动的监督检查工作，并负责城区鼠、蚊、蝇、蟑螂密度的日常监测和评价工作，对工作不到位的单位进行督查整改。

市城乡规划建设局：负责建筑工地、待建工地和停建工地的灭鼠、蚊、蝇、蟑螂活动的组织开展。

市质量技术监督局：负责食品生产加工企业的灭鼠、蚊、蝇、蟑螂活动的组织开展。

市工商局：负责超市、食品商店、街道门店的灭鼠、蚊、蝇、蟑螂活动的组织开展。

市商务局：负责农贸市场灭鼠、蚊、蝇、蟑螂活动的开展。

市房管局：负责各物业小区的灭鼠、蚊、蝇、蟑活动的开展。

市交通运输局、南铁赣州车务段、赣州机场分公司：负责汽车站、火车站及机场所辖地域的灭鼠、蚊、蝇、蟑螂活动的组织开展。

四、活动时间和主题

本次活动时间为10月8日-10月30日。

活动主题为：讲卫生、除四害、防疾病。

五、实施步骤

本次活动分为制定方案、宣传发动、环境整治、完善设施、药物分发、药物投放和消杀、检查验收等七个阶段进行。

（一）制定方案（10月8日-10月12日）

章贡区、赣州经济技术开发区及市直各部门、市属（驻市）各单位根据总体方案要求，结合本行业、本单位实际制定具体活动方案。

（二）宣传发动（10月13日-10月15日）

市、区两级充分利用广播、电视、报纸、墙报、标语宣传单等多种形式，广泛宣传发动群众，大造灭鼠、蚊、蝇、蟑螂声势，宣传灭鼠、蚊、蝇、蟑螂知识，使此次活动家喻户晓，人人皆知。

（三）环境整治（10月15日-10月20日）

由市城管局牵头，章贡区、赣州经济技术开发区、市直各部门要分别组织所辖地居委会和单位开展环境卫生综合整治，全面铲除城区卫生死角，清除城区鼠、蚊、蝇、蟑螂孳生地。健全和落实清扫保洁制度，建立规范的生活垃圾清运工作制度，认真做到日产日清，建立长效管理机制。

（四）完善设施（10月21日-10月22日）

全市各重点行业、窗口单位（农贸市场、粮库、饭店宾馆、医院、学校、影剧院、幼儿园、饮食店、食品加工厂、屠宰厂、酿造厂、港口、车站、机场等）要严格按照国家标准要求，建设和完善防蝇、防蚊、防鼠设施（即纱窗、纱门、门帘、风幕机、灭蝇灯等）。

（五）药物分发（10月23日-10月24日）

章贡区、赣州经济技术开发区按属地管理的原则，统一订购消杀药物并具体组织分发至辖区内单位和居民用户。

（六）药物投放和消杀（10月25日-10月27日）

1．全市烟熏灭蚊、蝇、蟑螂和投放蟑螂粉、饵剂统一时间为10月25日晚7时。

2．全市投放鼠药统一行动时间为10月25日-10月27日晚6时。

3．公共场所（市中心城区内公园、公共绿化地、河堤、下水道等）的灭鼠、蚊、蝇、蟑螂工作由市爱卫办组织专业消杀队伍按照统一时间分片进行布放毒饵盒和消杀。市直各部门、各单位对本部门、本单位的内外环境、办公场所、家属区等进行统一布放毒饵盒和消杀。

（七）检查验收（10月28日-10月30日）

1．自查整改：10月28日至29日，章贡区政府、赣州经济技术开发区，市直各部门、市属（驻市）各单位分别按照“条条”和“块块”对灭鼠、蚊、蝇、蟑螂活动进行自查，对不合格的单位、居民区及门点及时组织整改。

2．检查验收：10月30日，由市、区爱卫会组织督查和监测人员对此次灭鼠、蚊、蝇、蟑螂活动进行检查、监测和验收。

六、活动经费和药物供应

为确保活动效果，此次活动使用的灭鼠、蚊、蝇、蟑螂药物由市、区两级爱卫会按照全国爱卫会推荐和指定的药品目录统一购买。公共场所的灭鼠、蚊、蝇、蟑螂所需经费由市财政解决；城区各居民住户的灭鼠、蚊、蝇、蟑螂所需经费由各区财政解决；各机关、学校、企事业单位、物业管理部门、农贸市场和个体工商户的灭鼠、蚊、蝇、蟑螂经费按照“谁受益，谁出钱”的原则，由受益单位和个人自行解决。

为确保灭鼠、蚊、蝇、蟑螂效果、药物质量和用药安全，此次活动药物要严格执行“五统一”（即统一部署、统一购置、统一价格、统一时间、统一投放）。严禁任何单位和个人擅自购买或加工毒饵；杜绝使用违禁、剧毒药物和伪劣药物。

七、工作要求

（一）切实加强领导。灭鼠、蚊、蝇、蟑螂活动是一项社会性、群众性很强的工作，涉及千家万户，关系到我市能否巩固省级卫生城市的成果。各部门各单位要切实加强领导，高度重视，实行层级负责制，认真按照活动方案要求和职责分工，服从辖区爱卫办的统一组织领导，确保活动达到预期效果。

（二）坚持环境治理和化学药物防治并重的综合防治措施。在做好药物投放和消杀的同时，要认真做好环境卫生综合整治，彻底清除鼠、蚊、蝇、蟑螂孳生地，同时，要及时完善防蚊、蝇、蟑螂、鼠设施的建设。

（三）消杀药物投放要做到“五统一”（统一部署、统一培训、统一药物、统一时间、统一投放）和“四不漏”（不漏单位、不漏居民户、不漏外环境、不漏门点）。

（四）加强对专（兼）职人员的管理。各部门、各单位要做好消杀人员的技术培训，确定其职责，并定期检查，保证消杀质量和效果。

（五）各地、各单位要做好灭鼠、蚊、蝇、蟑螂的安全宣传和教育工作，不得委托无资质的单位和个人开展灭鼠、蚊、蝇、蟑螂工作，防止人、畜、禽中毒。

（六）工商、商务、房产、交通、卫生、药监、质监、建设部门要加大对食品行业、农贸市场、物业小区、车站、机场、码头等窗口单位及建筑工地的灭鼠、蚊、蝇、蟑螂工作的监督管理力度，认真督促各餐饮、食品生产销售单位消杀和防鼠、蚊、蝇、蟑螂设施到位工作，确保鼠蚊蝇蟑密度达标，对鼠蚊蝇蟑密度超标又不开展消杀的“六小”行业单位、农贸市场及建筑工地坚决依法处罚。

（七）加强监督检查。市、区两级爱卫办要按照省级卫生城市标准，对各部门、各单位、各居民户的灭鼠、蚊、蝇、蟑螂活动进行督查，对行动不力、不达标的单位给予通报。

（八）为检查这次灭鼠、蚊、蝇、蟑螂活动效果，由赣州市疾控中心、章贡区和开发区疾控中心分别按国家《四害密度监测技术规范》要求，负责完成公共场所和辖区内重点单位的灭鼠、蚊、蝇、蟑螂活动前后的鼠蚊蝇蟑密度监测工作，并于2014年11月15日前将监测结果报市爱卫办。
