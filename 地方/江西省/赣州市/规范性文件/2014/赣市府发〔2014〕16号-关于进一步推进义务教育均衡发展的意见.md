# 关于进一步推进义务教育均衡发展的意见

赣市府发〔2014〕16号

赣州市人民政府

关于进一步推进义务教育均衡发展的意见

各县（市、区）人民政府，赣州经济技术开发区管委会，市政府有关部门，市属、驻市有关单位：

为贯彻落实《国务院关于深入推进义务教育均衡发展的意见》（国发〔2012〕48号）等文件精神，切实保障适龄儿童少年平等接受义务教育，进一步推进全市义务教育均衡发展，现提出如下意见。

一、指导思想和目标任务

（一）指导思想。以邓小平理论、“三个代表”重要思想和科学发展观为指导，全面贯彻党的十八大、十八届三中全会精神，坚持把立德树人作为教育的根本任务，以提高教育质量为核心，以大力提高农村地区和薄弱学校义务教育水平为重心，以促进县域内义务教育均衡发展为重点，进一步完善农村义务教育保障机制，科学、均衡配置经费、设施、设备、教师等办学资源，努力办好每一所学校、教好每一个学生，整体提高义务教育发展水平，推进全市义务教育均衡、协调、可持续发展。

（二）目标任务。坚持以县为主、因地制宜、统筹配置资源、软件硬件并重的原则，紧紧抓住增加教育投入、改善办学条件、优化师资队伍、提高教育质量四个关键环节，努力缩小城乡之间、校际之间的差距和不同群体之间接受义务教育的差异。全市义务教育阶段学校基本达到省定办学条件标准，基本消除薄弱学校和“大班额”现象；所有县（市、区）实现区域内义务教育基本均衡。具体目标任务是：2014年，章贡区（含赣州经济技术开发区）率先实现县域内义务教育基本均衡，全市基本均衡率达到5.56％；2016年，南康区、崇义县、大余县3个县（区）实现县域内义务教育基本均衡，全市基本均衡率达到22.22％；2018年，上犹县、赣县、瑞金市、宁都县、定南县、安远县、寻乌县、龙南县、信丰县、兴国县10个县（市）实现县域内义务教育基本均衡，全市基本均衡率达到77.78％；2020年，会昌县、石城县、于都县、全南县4个县实现县域内义务教育基本均衡，全市基本均衡率达到100％。

二、着力改善办学条件，缩小校际办学差距

（三）完善义务教育经费保障机制。进一步完善各级政府分项目、按比例分担义务教育经费的保障机制，提高保障水平。各县（市、区）政府要确保义务教育经费“三个增长”，把义务教育经费全面纳入财政保障范围。全面落实义务教育免费政策，根据中央的统一部署相应提高义务教育阶段生均公用经费标准。

（四）加大薄弱学校改造力度。各县（市、区）要按照义务教育标准化办学标准，对辖区内所有义务教育阶段学校的办学条件进行核定；对没有达到基本要求的薄弱学校，制定改造规划，明确任务和时限，集中财力加快改造，努力使区域内所有义务教育阶段学校的办学条件尽早达标。要充分发挥优质学校的辐射、带动作用，积极探索实践“强校+弱校”、“名校+分校、新校”等集约化办学模式，整合教育资源，实现优质教育资源共享，促进城区优质学校支持带动薄弱学校全覆盖，提高薄弱学校管理水平和教育质量。

（五）继续优化调整中小学布局。各县（市、区）要根据当地城镇化发展和人口变动等情况，科学合理地制定学校布局整体规划。中小学布局调整要与薄弱学校改造、中小学标准化建设统筹规划实施。按照相对集中、就近入学的原则，对生源不足的学校有计划进行撤并，被撤并学校资产由教育行政部门统一安排使用。加强县城、乡镇中心小学和初中建设，推动城镇教育园区建设，在边远山区、库区和交通不便的农村地区保留、加强必要的小学和教学点。规范学校布局调整的程序，避免因布局调整引发新的矛盾。

（六）加快改善农村学校办学条件。以改善农村教育为重点，统筹城乡教育资源，努力让每个适龄儿童少年都能享受良好的教育。各县（市、区）要切实做好中小学校舍安全和校舍维修改造工程，教师周转房、限价商品房和公共租赁住房建设工程，农村初中校舍改造工程，农村寄宿制学校建设工程，农村义务教育薄弱学校改造计划和标准化建设工程等项目建设工作，统筹安排建设资金，积极推进义务教育标准化建设，办好必要的教学点。同时，加强学校教育教学设施设备和活动场地建设，为推进义务教育均衡发展奠定坚实的物质基础。

（七）加强城镇中小学校建设。各县（市、区）要按照加快推进新型城镇化的要求，遵循人民群众的普遍愿望和需求，把中小学建设纳入城镇建设总体规划，并注意留出发展空间。各级城乡规划行政主管部门要会同教育行政部门按照《城市居住区规划设计规范（GB50180—93）》规定，编制教育网点布局专项规划，明确中小学数量、规模及选址，确保新建、改建居民区的规划与新建、改扩建中小学校的规划同步编制和实施。各级财政要安排专项资金，推动解决中小学“大班额”问题。

三、强化教师队伍建设，促进师资力量均衡配置

（八）落实教师培训经费。各县（市、区）要按照属地管理的原则，依法保障教师培训经费的落实。各中小学校要按照“农村学校年度公用经费预算总额5％的标准和教职工年度标准工资（不含绩效工资）总额1.5％的标准安排教师培训经费”的要求，统筹安排好教师培训经费，确保足额到位、专款专用。

（九）合理配备教师资源。各县（市、区）要对义务教育学校合理定编，科学设岗，满足义务教育均衡发展对师资的需要。在编制总额内，对中小学教师实行动态管理，根据农村中小学网点布局及学科结构情况，配备教师资源，确保农村教学网点按照每班1.5名教师的编制标准配备教师。建立完善教师增补机制。严格执行城乡中小学统一岗位结构比例的规定，认真解决好农村学校英语、音乐、体育、美术、地理、生物、信息技术等专业教师缺乏的结构性缺编问题。

（十）完善教师和校长交流轮岗制度。各县（市、区）要建立完善公办中小学教师和校长定期交流和轮岗制度、城镇中小学教师到农村中小学任教服务、农村中小学教师到城镇中小学跟班学习制度和区域内骨干教师巡回授课、紧缺学科教师流动教学制度，广泛开展“送教下乡”活动，推动校长和教师在城乡之间、校际之间的合理流动，鼓励优秀校长和骨干教师到农村学校和薄弱学校任职、任教。

（十一）加强农村教师队伍建设和管理。继续组织实施“国培计划”、“省培计划”，为农村中小学培养高素质教师。大力加强县级教师培训机构建设。实施优质学校与薄弱学校的团队交流，积极组织联片教研和集体备课。发挥远程教育和培训基地的功效，全面提高农村中小学教师素质。实施“中小学校长培训计划”。

（十二）加强师德师风建设。完善师德档案管理，严格师德考核制度，健全教育、宣传与考核、奖惩相结合的师德建设工作机制，开展丰富多彩的师德教育活动，使广大教师自觉加强职业道德修养，模范履行《中小学教师行为规范》和教师职业道德“七项严禁”。建设一支品德高尚、爱岗敬业、无私奉献的教师队伍。

四、深化教育综合改革，全面提高义务教育质量

（十三）进一步规范学校办学行为。各县（市、区）要依法保障义务教育适龄儿童少年在户籍所在地公办学校就近免试入学。各地不得以任何名义改变或变相改变公办学校的性质。要建立健全义务教育学校重点监测制度，减轻学生课业负担。不得将义务教育阶段学校分为重点、非重点学校；学校不得分设重点、非重点班，不得擅自举办各种名目的实验班，不得违规组织学生集体补课。加强校风、教风、学风建设，强化学校内部管理。加强义务教育学籍管理。

（十四）加强和改进中小学德育工作。坚持育人为本，德育为先，以培育和践行社会主义核心价值观引领中小学德育工作并融入中小学教育的全过程，认真抓好“三爱”教育和“三节”教育，突出诚信教育。加强德育工作队伍建设。加强对学生课余活动的引导和管理，倡导和组织学生积极参加各种有益的生产劳动和公益活动。各类公益性的文化、体育场所和设施向学生免费或优惠开放。充分发挥青少年校外活动场所的作用，促进学生全面发展。

（十五）深化义务教育课程改革。严格按照国家课程计划开齐开足课程，全面实施学校体育三年行动计划和《国家学生体质健康标准》，加强学校体育、艺术教育和校园文化建设，促进学生德智体美全面发展。进一步深化义务教育课程改革，切实把党的教育方针和社会主义核心价值观细化、实化、具体化到课标、教材以及考试评价中。积极推行招生制度改革，坚持义务教育免试入学，积极推进初高中学业水平考试考核综合素质评价改革，完善小学、初中学生综合素质评定办法，建立体现素质教育要求的义务教育教学质量评估体系，定期对学校实施素质教育进行检查和督导，全面提高义务教育办学质量。

（十六）提升中小学校信息化水平。把全面推进中小学教育信息化作为促进义务教育均衡发展的重要战略举措，不断提高教育信息化的普及水平和应用水平。加大现代教育信息技术硬件投入，启动教育云示范工程，建设覆盖全市学校、分布合理、安全有效的市级教育管理公共服务平台和教育资源公共服务平台，实现宽带网络校校通、优质资源班班通、网络学校空间人人通。充分运用信息化的教育手段和方式，不断扩大优质教育资源覆盖面，实现优质教育资源共享，有效促进教育质量的提高。

（十七）保障特殊群体平等接受义务教育。将残疾儿童少年义务教育纳入义务教育总体发展规划，加快特殊教育学校建设，完善特殊教育体系，启动《特殊教育提升计划（2014-2016）》，依法保障残疾儿童少年接受义务教育权利。认真做好进城务工人员随迁子女接受义务教育工作，坚持以流入地政府及公办中小学为主保障进城务工人员随迁子女与当地学生平等接受义务教育。健全农村留守儿童关爱服务体系，建立由政府统筹、相关部门和农村基层组织齐抓共管的工作机制。建立完善多形式资助家庭经济困难学生的就学制度，确保学生不因贫困而失学。

五、加强组织领导，确保义务教育均衡发展顺利推进

（十八）加强组织领导。市政府成立推进义务教育均衡发展领导小组，领导小组办公室设在市教育局，负责义务教育均衡发展具体实施和组织协调工作。各县（市、区）要建立完善推进义务教育均衡发展的组织协调机制，把推进义务教育均衡发展作为“一把手”工程，将推进本地区义务教育均衡发展作为一项重要任务，纳入当地经济社会发展总体规划，列入经济社会发展目标考核内容。建立各级党政领导班子成员定点联系学校制度，及时帮助解决实际问题。实行政府向同级人大报告、向政协通报教育工作制度。

（十九）建立完善督导评估制度。进一步完善推进义务教育均衡发展督导评估制度及督导评估指标体系，市政府教育督导室定期对各县（市、区）义务教育均衡发展状况进行评估，并将评估结果作为评价当地教育工作的重要指标，同时列为县（市、区）主要领导和教育行政部门干部政绩考核的重要内容和进行表彰奖励的重要依据。各县（市、区）要建立和完善义务教育均衡发展监测制度，定期对辖区内义务教育城乡、校际间的差距进行监测和分析，并以适当方式予以公布，接受社会监督。

各县（市、区）要根据省、市实施县域义务教育均衡发展意见，制定本地实施意见，完善相关政策和配套措施，确保实现县域义务教育均衡发展规划所确定的目标任务全面完成。

2014年8月1日
