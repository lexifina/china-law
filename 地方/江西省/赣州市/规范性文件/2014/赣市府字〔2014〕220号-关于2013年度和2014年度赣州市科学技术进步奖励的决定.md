# 关于2013年度和2014年度赣州市科学技术进步奖励的决定

赣市府字〔2014〕220号

赣州市人民政府关于2013年度和2014年度

赣州市科学技术进步奖励的决定

各县（市、区）人民政府，赣州经济技术开发区管委会，龙南经济技术开发区管委会，市政府各部门，市属、驻市各单位：

为全面贯彻党的十八大和十八届三中全会精神，大力实施创新驱动发展战略，调动和激发科技人员创新创业的积极性和创造性，根据《赣州市科学技术进步奖励实施办法》，经赣州市科学技术进步奖励委员会评审，市政府研究决定:

授予“系列风力发电机专用磁钢”成果为2013年度赣州市科学技术进步奖一等奖。

授予“无润滑二氧化碳压缩机关键技术的研制与应用”等9项成果为2013年度赣州市科学技术进步奖二等奖。

授予“浓香油茶籽油的技术研究与应用”等14项成果为2013年度赣州市科学技术进步奖三等奖。

授予“稀土强化梯度结构硬质合金球齿制备技术”等3项成果为2014年度赣州市科学技术进步奖一等奖。

授予“无润滑混合制冷剂压缩机”等6项成果为2014年度赣州市科学技术进步奖二等奖。

授予“黄谷绿地贴（铺地锦竹草）开发”等12项成果为2014年度赣州市科学技术进步奖三等奖。

希望获奖单位和个人珍惜荣誉，再接再厉，再创佳绩。全市科技工作者要向获奖者学习，坚持科学精神，弘扬求实作风，勇于探索创新，为提高我市科技进步和自主创新能力，促进赣南苏区振兴发展作出更大贡献。
