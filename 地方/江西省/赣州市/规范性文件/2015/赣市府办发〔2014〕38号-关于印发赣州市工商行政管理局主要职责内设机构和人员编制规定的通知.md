# 关于印发赣州市工商行政管理局主要职责内设机构和人员编制规定的通知

赣市府办发〔2014〕38号

赣州市人民政府办公厅

关于印发赣州市工商行政管理局主要职责

内设机构和人员编制规定的通知

各县（市、区）人民政府，赣州经济技术开发区管委会，龙南经济技术开发区管委会，市政府各部门, 市属、驻市各单位：

《赣州市工商行政管理局主要职责内设机构和人员编制规定》经市机构编制委员会审定，市政府批准，现予印发。

2014年12月28日

(此件主动公开)

赣州市工商行政管理局

主要职责内设机构和人员编制规定

根据《江西省机构编制委员会办公室江西省工商行政管理局关于赣州市工商行政管理系统机构编制下划移交的通知》（赣编办发〔2014〕40号）和《中共赣州市委、赣州市人民政府关于印发赣州市人民政府职能转变和机构改革实施方案>的通知》（赣市字〔2014〕35号），将赣州市工商行政管理局由省以下垂直管理调整为市政府工作部门。

一、职责调整

（一）划出和取消的职责。

1．将流通环节食品安全监督管理职责划转市食品药品监督管理局。

2．取消企业年度检验制度，改为企业年度报告公示制度。

（二）增加和承接的职责。

1．增加企业信用信息公示系统建设和管理职责。

2．承接省工商行政管理局下放设区市工商局外国企业常驻代表机构登记、事业单位广告经营资格审批、外商投资广告企业设立分支机构审批、外商投资广告企业项目审批等职责。

（三）加强的职责。

1．加强新兴市场主体监管，强化网络商品交易行为和中介机构监管。

2．加强和完善工商行政执法职责，完善协同监管机制，建立健全部门间信息沟通共享、信用信息披露和案件协查移送机制，提高协同监管执法能力，构建市场监管长效机制。

3．建立市场主体信息公示系统，建立完善信用约束机制，促进社会诚信体系建设。

4. 加强投诉举报受理工作。统一受理、分派、督办、回复全市涉及经营活动和消费活动的各类投诉、举报、申诉和咨询，建立健全投诉、举报集中受理、快速响应、精细管理、依法处置工作机制。

二、主要职责

（一）贯彻实施国家和省、市有关工商行政管理法律、法规、规章，拟订相关规划、政策并监督实施；负责本市市场监督管理和行政执法工作。

（二）依法实施各类市场主体的注册登记；负责中心城区注册资本200万元以上的私营有限责任公司、市本级内资企业、股份有限公司、全市外商投资企业以及外国（地区）企业常驻代表机构等市场主体的登记注册和监督管理；负责指导全市各类企业、个体工商户、农民专业合作社和从事经营活动的单位、个人等市场主体的登记注册管理；按职责分工承担并指导依法查处取缔无照经营工作。

（三）依法规范和维护各类市场经营秩序，负责监督管理市场交易行为和网络商品交易行为及有关服务的行为。

（四）依法监督管理流通领域商品质量；组织开展有关服务领域消费维权工作，按分工查处假冒伪劣等违法行为；负责消费者投诉、举报的处理和网络体系建设等工作，保护经营者、消费者合法权益。

（五）拟定有关反垄断、反不正当竞争、直销监督管理和禁止传销的规章制度及具体措施、办法；承担有关反垄断执法、监督管理直销企业和直销员及其直销活动工作；承担协调相关方面开展打击传销联合行动工作。

（六）依法查处不正当竞争、商业贿赂、走私贩私、违法直销和传销以及法律法规规定由设区市工商局查处的其他经济违法案件；监督、协调和指导全市公平交易执法工作。

（七）依法监督管理经纪人、经纪机构及经纪活动。

（八）依法实施合同行政监督管理；依法查处合同欺诈等违法行为。指导全市工商系统监督管理拍卖行为及动产抵押登记工作；

（九）依法办理相关广告登记；负责广告活动监督管理工作，组织查处违法广告。

（十）组织实施商标监督管理工作，依法保护商标专用权和查处商标侵权行为；组织实施特殊标志、官方标志的保护工作；推荐江西省著名商标；承担赣州市知名商标认定委员会日常工作。

（十一）负责市场主体信用信息公示体系建设工作，开展市场主体信用信息公示，开展或组织市场主体公示信息抽查工作；负责并指导全市注册登记的市场主体的经营异常名录管理工作；为政府决策和社会公众提供信息服务。

（十二）负责市委、市政府交办的其他事项。

三、内设机构

根据上述职责，市工商行政管理局内设8个职能科（室）。

（一）办公室

负责机关文电、会务、机要、档案、史志、督查督办等机关日常运转工作；负责重要文稿起草和调研工作；负责政务公开、宣传报道、舆情处置、安全保密、信访等工作；负责市人大代表建议、市政协委员提案办理工作。

（二）法规科

组织起草工商行政管理地方性法规草案及规章草案；负责有关规范性文件合法性审核工作；负责行政处罚案件核审、听证工作，承办相关行政复议、行政诉讼应诉和行政赔偿等工作；组织、协调、参与工商行政管理法律、法规、规章宣传和普法教育工作；负责行政执法监督检查工作。

（三）计划财务科

研究拟订财务、审计管理的规章制度；组织实施各项财务管理制度；编制、上报经费预算及决算方案；研究拟订本级机关财务资产、资金管理、基本建设、经济责任、政府采购等管理工作的审计规章制度并组织实施。

（四）人事教育科

负责局机关和所属单位的机构编制、人事管理、队伍建设、教育培训、外事、离退休人员的管理和服务等工作。

（五）市场秩序规范监督管理科（增挂网络商品交易监督管理科牌子）

拟订规范市场秩序的具体措施、办法并组织实施；承担规范维护各类市场经营秩序，组织实施市场专项治理工作；组织指导商品交易市场信用分类管理工作；负责网络商品交易及有关服务行为的监督管理工作；负责合同行政监督管理；指导动产抵押登记；承担经纪人和拍卖行为的指导管理工作；查处合同欺诈、不公平格式条款等违法行为。

（六）广告监督管理科

拟订市本级广告业发展规划，推动广告业发展；依法办理相关广告登记；负责监督管理广告活动，指导监测各类媒介广告发布，查处虚假广告等违法行为。

（七）个体私营经济监督管理科

调查研究个体、私营经济发展与管理情况，拟订监督管理的具体措施、办法并组织实施；指导全市个体工商户、私营企业、农民专业合作社的注册登记工作；组织指导全市个体工商户信用分类管理工作；指导全市个体私营经济协会的工作；按照职责分工承担市本级和指导全市工商系统开展查处取缔无照经营工作。

（八）投诉举报科

承担消费和经营领域各类方式（包括电话、信函、网络、来人等）投诉、举报受理工作；负责工商行政管理职责范围内上级机关交办、其他有关机关移送、业务科（室、局）履职中发现的案源线索以及投诉举报案源线索的收集、分类管理，提出案件分派、查办意见，并将案件办结信息反馈给交办、移交的部门或者实名投诉举报的人员。

机关党委。负责机关和直属单位的党群工作。

纪检组（监察室）。为市纪委（监察局）的派驻机构。

四、人员编制

市工商行政管理局机关行政编制51名（含纪检监察编制2名）。其中领导职数：局长1名、副局长4名，纪检组长1名；正科级10名(含机关党委副书记、监察室主任各1名)，副科级8名。

五、其他事项

（一）市工商行政管理局下设5个正科级直属机构。

1．市工商行政管理局企业注册监督管理局更名为市工商行政管理局企业注册局（增挂市工商行政管理局外商投资企业注册局），行政编制12名，其中领导职数1正2副。

主要职责：拟订全市各类市场主体注册登记管理的具体措施和办法；组织指导全市各类市场主体注册登记工作；承担职责范围内的内资、外资企业注册登记工作；核定冠市名的企业名称；承担全市各类市场主体注册登记基础信息库的建立、维护和内资、外资企业注册登记信息的分析、公开工作。

2．市工商行政管理局外商投资企业注册监督管理局更名为市工商行政管理局企业监督管理局，行政编制8名，其中领导职数1正2副。

主要职责：负责承担市本级注册登记的内资、外资企业的日常监督管理工作；负责市本级注册登记的内外资企业年度报告公示制度的监督落实；负责全市市场主体信息公示系统的建设和管理工作；组织实施全市市场主体信息公示工作；负责对市场主体公示信息情况进行抽查；依法依规确定企业经营异常名录以及严重违法企业名单；负责涉及市本级注册登记企业落实市委、市政府重大工作部署的督促推进工作。

3．市工商行政管理局公平交易局（增挂市工商行政管理局执法支队和市工商行政管理局打击传销办公室牌子），行政编制12名，其中领导职数1正2副。

主要职责：拟订有关反垄断、反不正当竞争、直销监督管理和禁止传销的具体措施、办法；承担有关反垄断执法、监督管理直销企业和直销员及其直销活动工作；查处市场中的不正当竞争、商业贿赂、违法直销和传销及其他经济违法案件；承担协调相关方面开展打击传销联合行动工作。

4．市工商行政管理局商标监督管理局，行政编制4名，其中领导职数1正1副。

主要职责：拟订商标监督管理的具体措施和办法；组织实施对商标使用的监督管理；组织推荐全省著名商标，认定市知名商标；负责商标使用许可合同和商标印制的监管工作。

5．市工商行政管理局消费者权益保护局，行政编制8名，其中领导职数1正2副。

主要职责：拟订保护消费者权益的具体措施、办法；承担流通领域商品质量监督管理工作；开展有关服务领域消费维权工作；查处假冒伪劣等违法行为；承担指导消费者咨询、申诉、举报受理、处理和网络体系建设工作。

（二）赣州经济技术开发区工商行政管理局，为市工商行政管理局下属正科级行政机构。

1. 赣州经济技术开发区工商行政管理局机关，行政编制8名，其中领导职数1正2副。

2. 赣州经济技术开发区工商行政管理局直属行政机构。

（1）赣州经济技术开发区工商行政管理局企业注册监督管理局，副科级，行政编制8名，其中领导职数1正2副；

（2）赣州经济技术开发区工商行政管理局公平交易局，副科级，行政编制6名，其中领导职数1正1副；

（3）赣州经济技术开发区工商行政管理局消费者权益保护局，股级，行政编制3名，其中领导职数1名。

3. 赣州经济技术开发区工商行政管理局基层分局（派出机构），均为副科级。

（1）黄金岭分局，行政编制8名，其中领导职数1正2副；

（2）蟠龙分局，行政编制8名，其中领导职数1正2副；

（3）湖边分局，行政编制9名，其中领导职数1正2副；

（4）潭口分局，行政编制8名，其中领导职数1正2副。

4. 赣州经济技术开发区工商行政管理局下属全额拨款事业单位，均为股级。

（1）赣州经济技术开发区工商行政管理局个体私营经济协会办公室，人员编制4名；

（2）赣州经济技术开发区工商行政管理局消费者协会办公室，人员编制3名；

（3）赣州经济技术开发区工商行政管理局信息中心，人员编制5名。

（三）市工商行政管理局下属7个正科级全额拨款事业单位。

1.市工商行政管理局机关后勤服务中心，人员编制18名，其中领导职数1正2副。承担市局机关车辆、食堂、会务、基建维修、办公用品采购以及楼院资产、节能、绿化管理等后勤保障和服务工作。

2.市工商行政管理局个体私营经济协会办公室，人员编制3名，其中领导职数1名。承担宣传贯彻个体私营经济工作的法律法规和政策；向政府和有关部门反映个私经济发展状况，提出建议；协助政府和有关部门做好对个体户、私营企业管理，加强行业自律；维护个体户、私营企业合法权益；负责个体户、私营企业素质教育和培训以及表彰、学习、教育活动。

3.市工商行政管理局消费者协会办公室，人员编制4名，其中领导职数1正1副。负责处理消协日常事务；开展消费教育、引导和法律法规宣传活动；受理消费者投诉并调解；组织或参与商品和服务质量检查、收集和反馈信息，配合有关单位积极开展打击制售假冒伪劣商品的违法违章活动。

4.市工商行政管理局商标协会办公室，人员编制3名，其中领导职数1名。负责宣传、贯彻国家有关商标的法律、法规和政策，指导会员的商标行为自律；指导会员争创知名商标、著名商标、驰名商标并提供服务；组织有关商标工作的经验交流、学术讨论、业务培训和考察；向政府有关方面提供商标信息，提出工作建议。

5.市工商行政管理局广告协会办公室，人员编制3名，其中领导职数1名。负责指导广告行业协会工作，为广告行业建设与发展提供服务、反映诉求、规范行为。

6.市工商行政管理局信息中心更名为市工商行政管理局信息档案中心，人员编制17名，其中领导职数1正2副。负责组织实施全市工商系统信息化建设；负责市局机关信息化网络安全运行和维护；负责网络舆情监控、政府信息公开内容的上传工作；负责市本级注册登记企业档案的管理工作；依照有关规定对外提供档案资料查询服务。

7.市工商行政管理局培训中心，人员编制6名，其中领导职数1名。负责全市工商系统干部职工的工商法律法规培训、业务技能培训、执法办案培训等相关培训工作；负责企业涉及工商业务的相关培训。

六、附则

本规定由市机构编制委员会办公室负责解释，其调整由赣州市机构编制委员会办公室按规定程序办理。
