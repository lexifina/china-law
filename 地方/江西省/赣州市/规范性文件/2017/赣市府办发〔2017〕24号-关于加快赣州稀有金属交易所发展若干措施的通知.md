# 关于加快赣州稀有金属交易所发展若干措施的通知

赣市府办发〔2017〕24号

赣州市人民政府办公厅

印发关于加快赣州稀有金属交易所

发展若干措施的通知

各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区和赣州蓉江新区管委会，市政府各部门，市属、驻市各单位：

《关于加快赣州稀有金属交易所发展的若干措施》已经市政府同意，现印发给你们，请抓好贯彻落实。

2017年5月2日

（此件主动公开）

关于加快赣州

稀有金属交易所发展的若干措施

为加快赣州稀有金属交易所（以下简称“稀交所”）发展，更好地发挥价格发现和指引功能，巩固和提升我市稀土、钨产业的辐射力和影响力，推动稀土、钨产业健康、持续、快速发展，特制定以下扶持奖励政策措施。

一、根据《关于赣州市执行西部大开发税收政策问题的通知》（财税〔2013〕4号）规定，若稀交所开展的业务属于《国家产业结构调整指导目录》鼓励类产业，可享受减按15%征收企业所得税的税收优惠。

二、引导稀土、钨企业通过稀交所平台进行交易，对首次年交易额突破5亿元、10亿元、20亿元的本地企业，由市财政分别给予2万元、5万元、10万元资金奖励。

三、支持稀交所在合法合规的前提下进行交易产品和管理模式创新。交易额突破50亿元以上，给予稀交所500万元奖励，奖励奖金由市财政负担。

四、自2017年起两年内，市财政每年补贴稀交所场地租赁及运营费100万元。

五、支持稀交所加快矿产品仓储建设。稀交所交易额达到3000亿元以上时，在仓储建设用地需求等方面给予优先保证。

六、自稀交所开业运营起，企业高管人员缴纳的薪资个人所得税，第1年按市财政实得部分100%奖励，第2年按市财政实得部分90%奖励，第3年按市财政实得部分80%奖励，第4年、第5年按市财政实得部分50%奖励。奖励资金由市财政负担。

七、对稀交所引进的专业团队工作人员，工作满两周年以上的，除享受稀交所董事会给予的各项待遇外，经市委人才工作领导小组审定符合《关于大力引进高层次人才的若干意见》（赣市才发〔2013〕2号）规定的高层次人才，还可享受我市有关人才引进方面给予的住房、配偶就业、子女入学等方面的优惠政策。

八、本措施自印发之日起施行。
