# 关于建立固定资产投资调度联席会议制度的通知

赣市府办字〔2017〕115号

赣州市人民政府办公厅关于建立

固定资产投资调度联席会议制度的通知

各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区和赣州蓉江新区管委会，市政府有关部门，市属、驻市有关单位：

为加强固定资产投资运行分析，强化固定资产投资统计，形成上下联动、部门协作的固定资产投资调度工作机制，促进投资稳定增长，经市政府同意，决定建立赣州市固定资产投资调度联席会议制度（以下简称联席会议）。现就有关事项通知如下：

一、联席会议主要职能

（一）研究审议固定资产投资年度计划。

（二）研究完善扩大合理有效投资、促进投资增长的政策措施。

（三）加强固定资产投资项目调度，推进重大项目统计入库。

（四）研究解决固定资产投资工作中存在的重大问题。

（五）指导、督促、检查固定资产投资政策措施的落实。

（六）完成市政府交办的其他工作。

二、联席会议成员单位及职责分工

联席会议由市发改委、市统计局、市工信委、市城乡建设局、市房管局、市交通运输局、市水利局、市环保局、市商务局、市国资委、市国土局、市重点办、市财政局、市金融工作局、市中小企业管理局、市国税局、人民银行赣州市中心支行等部门和单位组成。市发改委、市统计局为牵头单位，据工作需要，经联席会议研究确定，可增加成员单位。

联席会议由市发改委主要负责同志担任召集人，市发改委、市统计局分管负责同志担任副召集人，其他成员单位有关负责同志为联席会议成员。联席会议成员因工作变动需要调整的，由所在单位提出，联席会议确定。联席会议办公室设在市发改委，承担联席会议日常工作。联席会议设联络员，由各成员单位有关科室负责同志担任。

联席会议成员单位及职责分工如下：

市发改委：牵头组织召开固定资产投资调度部门联席会议；负责组织协调全市固定资产投资项目信息共享和入库统计责任制工作；负责将全市审批、核准、备案的计划总投资500万元及以上项目信息按月抄送市统计局；负责督促项目单位主动与项目所在地统计部门联系，建立固定资产投资统计报送关系。

市统计局：负责组织实施固定资产投资统计调查制度，全面掌握投资动态和项目进展情况，对数据进行质量检查评估；按照各部门提供的相关信息和联系方式，督促县级统计部门及时与项目单位联系，布置新开工项目入库申报、固定资产投资、房地产开发等报表，对统计人员进行业务培训；负责向联席会议成员单位提供固定资产投资统计数据。

市工信委：负责将全市审批、核准、备案的计划总投资500万元及以上工业项目和工业技改项目信息按月抄送市统计局；负责调度推进全市重大工业项目建设，分析研究工业投资运行情况，并将项目建设进展情况、工业投资运行情况抄送市发改委、市统计局；负责督促全市重大工业项目入库资料（项目批文、施工合同和现场照片，下同）的收集、及时入库统计和数据上报。

市城乡建设局：负责将权限许可范围内办理的施工许可证项目信息按月抄送市统计局；负责调度推进市中心城区重大城建项目建设，并将项目建设情况抄送市发改委；负责督促中心城区城建项目入库资料的收集、及时入库统计和数据上报；负责督促符合条件的建筑业企业的入库入统工作；协助统计部门做好建筑业企业联网直报数据的上报，协助做好建筑业总产值增速与投资增速的评估。

市房管局：负责将全市房地产企业和项目预售许可信息按月报送市统计局；负责督促全市房地产企业和项目入库资料的收集、及时入库统计和数据上报；负责每月后3日前将全市分县（市、区），分企业、分项目的商品房销售网签汇总数据报送市统计局。

市交通运输局：负责将全市新开工交通运输业项目信息按月抄送市统计局；负责调度推进全市重大交通项目建设，分析研究交通基础设施投资运行情况，并将项目建设进展情况、交通基础设施投资运行情况抄送市发改委；负责督促交通运输业投资项目入库资料的收集、及时入库统计和数据上报。

市水利局：负责将全市新开工水利建设项目信息按月抄送市统计局；负责调度推进全市重大水利项目建设，分析研究水利基础设施投资运行情况，并将项目建设进展情况、水利基础设施投资运行情况抄送市发改委；负责督促水利项目入库资料的收集、及时入库统计和数据上报。

市环保局：负责将已办理的环评批复项目信息按月抄送市统计局；负责调度推进全市重大环保项目建设，并将项目建设进展情况抄送市发改委；负责督促环保项目入库资料的收集、及时入库统计和数据上报。

市商务局：负责将市本级招商引资落户项目的单位名称、项目名称、投资额、产品或行业、生产能力、联系方式等资料按月抄送市统计局；负责调度推进全市招商引资工作，并将招商引资工作情况抄送市发改委；负责督促商贸流通企业投资项目入库资料的收集、及时入库统计和数据上报。

市国资委：负责将市属国有企业投资项目（除城建、交通、水利外）信息按月抄送市统计局；负责调度推进市属国有企业重大项目建设，并将项目建设进展情况抄送市发改委；负责督促市属国有企业投资项目入库资料的收集、及时入库统计及数据上报。

市国土局：负责将中心城区已办理用地审批项目的信息按月抄送统计部门；负责梳理全市工业、房地产、基础设施等项目用地情况，按月抄送市发改委、市统计局。

市重点办：负责调度推进市级重点项目建设，并按月将重点项目建设进展情况抄送市发改委、市统计局；负责督促市级重点项目及时入库统计及数据上报。

市财政局：负责调度全市PPP项目实施情况、全市政府出资产业发展基金运行情况及财园信贷通、小微信贷通、创业信贷通服务运行情况，并将有关情况抄送市发改委、市统计局。

市金融工作局：负责分析研判全市经济金融工作形势，调度全市“产业扶贫信贷通”服务运行情况，调度推进全市企业上市工作，并将有关情况抄送市发改委。

市中小企业管理局：负责分析研判全市民营（非公）经济运行情况和民营企业、中小企业投融资情况，并将有关情况抄送市发改委。

市国税局：负责按月将上月建筑业增值税和房地产增值税及其增幅表报送市统计局。

人民银行赣州市中心支行：负责每月将上月分县（市、区）金融机构中长期贷款余额及增速、固定资产中长期贷款、建筑业贷款和房地产业贷款及其增速情况报送市发改委、市统计局。

教育、卫生计生、林业、农粮、扶贫移民、民政、供电等部门负责调度推进本单位及下属单位重大项目建设，组织和督促项目单位按时上报项目报表，并督促本系统投资项目入库资料的收集、及时入库统计和数据上报。

三、联席会议工作规则

（一）联席会议根据工作需要定期或不定期召开全体会议，通报全市投资运行情况，分析研判投资形势，研究投资运行困难及问题，提出下一步工作对策及建议。联席会议以会议情况通报的方式，明确固定资产投资调度的下一步工作，印发有关方面并抄报市政府。

（二）市发改委要切实做好联席会议各项工作，各成员单位要密切配合、相互支持、形成合力，认真落实联席会议议定事项，充分发挥联席会议作用，形成高效运行的长效工作机制，推动固定资产投资调度联席会议制度平稳有效实施。

（三）联席会议成员单位联络员应于每月10日前将有关情况抄送各相关部门，全力推动项目入库统计工作。

（四）市统计局要按月形成固定资产投资分析报告，市发改委要根据联席会议研究讨论情况定期形成固定资产投资运行综述报告，专报市政府并通报联席会议成员单位。

（五）各县（市、区）要参照市里的做法，认真研究制定固定资产投资调度工作机制，加大项目入库统计工作力度，全面加强投资运行分析及形势研判，确保投资保持较快增长态势，为经济平稳运行提供有力支撑。
