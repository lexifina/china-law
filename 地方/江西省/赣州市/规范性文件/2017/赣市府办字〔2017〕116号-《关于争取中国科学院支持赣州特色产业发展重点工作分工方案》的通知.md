# 《关于争取中国科学院支持赣州特色产业发展重点工作分工方案》的通知

赣市府办字〔2017〕116号

赣州市人民政府办公厅印发

《关于争取中国科学院支持赣州特色产业

发展重点工作分工方案》的通知

章贡区、赣县区、定南县人民政府，赣州经济技术开发区管委会，市政府有关部门，市属、驻市有关单位：

《关于争取中国科学院支持赣州特色产业发展重点工作分工方案》已经市政府同意，现印发给你们。

各有关部门和单位要加强领导，明确责任，各司其职。要按照《关于争取中国科学院支持赣州特色产业发展重点工作分工方案》要求，对涉及本部门和单位的工作进一步分解细化，制定具体措施。牵头单位（排序第一的为牵头单位）要加强组织协调，切实发挥牵头抓总的作用；责任单位要密切配合，主动对接，积极跟进，形成工作合力，确保各项目标任务不折不扣地落到实处。要抓紧做好向中国科学院的汇报沟通衔接，争取获得中国科学院最大限度的支持。赣南科学院要及时掌握各部门和单位的对接情况，加强信息沟通。

2017年7月10日

（此件主动公开）

关于争取中国科学院

支持赣州特色产业发展重点工作分工方案

一、推进赣州稀土钨产业发展

1.争取中科院支持我市组建以江西理工大学为核心，由政府引导、高校科研院所牵头、企业出资共同参与的江西省新材料开发与应用研究院，并给予人才、技术、项目方面的支持。（责任单位：市工信委、市科技局、江西理工大学、市财政局、赣南科学院、市国资委）

2.争取中科院与我市合作在“中国稀金谷”投资新建1-2个稀土、钨新材料及应用产业大项目。（责任单位：市国资委、赣县区政府、赣南科学院、赣州稀土集团）

3.争取中科院支持赣州稀土集团国家离子型稀土资源高效开发利用工程技术研究中心建设，深化中科院与工程中心产学研合作、人才交流和技术对接，促进科研成果转化。（责任单位：市国资委、赣州稀土集团、市科技局、市人社局、市委人才办、赣南科学院、江西理工大学、赣州有色冶金研究所）

4.争取中科院有关院所落户“中国稀金谷”。（责任单位：市科技局、市国资委、赣州高新区管委会、市工信委、赣南科学院）

5.推进赣州稀土集团与中科院海西研究院“离子型稀土矿清洁分离与高值利用技术的研究与产业化”、江西省钨与稀土产品质量监督检验中心与中科院金属研究所“新型稀土掺杂结构材料”、“高纯稀土金属合金”等项目建设。（责任单位：市国资委、赣州稀土集团、江西省钨与稀土产品质量监督检验中心、市科技局）

6.争取中科院在钨和稀土方面的科技成果产业化优先在赣州高新区钨和稀土企业实现转化。（责任单位：赣州高新区管委会、市科技局）

7.争取中科院与我市合作建立中试基地以及技术中心等创新服务平台，与相关企业共建重点实验室、科技企业孵化器、研发中心、工程技术中心、院士工作站，博士后科研工作站等平台，将钨和稀土新材料及其应用项目布局到我市。（责任单位：市科技局、市科协、市人社局、市工信委、市商务局）

8.推进中科院海西研究院与江西理工大学、赣州高新区合作共建中科院海西研究院赣州稀有金属研究中心。（责任单位：市科技局、江西理工大学、赣州高新区管委会、赣州稀土集团）

二、推进赣州新能源汽车产业发展

9.争取中科院所属院（校）帮助我市新能源汽车、电子信息等主导产业企业解决电池隔膜、电机及驱动控制器等关键技术难题，争取设立中科院赣州新能源汽车研究所。（责任单位：市工信委、市商务局、赣州经济技术开发区管委会、市科技局）

三、推进赣州电子信息产业发展

10.争取中科院在我市设立中科院赣州电子信息产业研究所。（责任单位：市商务局、赣州经济技术开发区管委会、市科技局、市工信委、市科协）

四、推进赣州建设“青峰药谷”

11.争取中科院相关研究院所与赣南医学院、青峰药业“天然药物与中药注射剂国家重点实验室”开展合作，支持在赣州青峰药谷共建医药研发平台。（责任单位：章贡区政府、赣南医学院、市科技局、市食品药品监督管理局、市卫计委）

12.加快推进青峰药业创新天然药物与中药注射剂国家重点实验室建设。对接中科院整合科研成果，特别是上海药物研究所等院所较为成熟的新药研发成果，优先在赣州青峰药谷医药企业实现转化。（责任单位：章贡区政府、市科技局）

13.争取中科院推荐其投资或控股的高科技医药企业入驻青峰药谷。（责任单位：章贡区政府、市国资委）

五、积极开展柑橘黄龙病防控技术攻关

14.推动中科院与我市就柑橘黄龙病防控技术开展科技项目联合申报、立项和试验研究，并就科技成果的转化应用进行合作。（责任单位：市果业局、市科技局、国家脐橙工程技术研究中心、赣南科学院）

15.争取中科院动植物所、武汉病毒所等相关研究院所与国家脐橙工程技术研究中心、赣州市柑桔研究所的合作，加强对柑橘黄龙病的防控调研。（责任单位：市果业局、国家脐橙工程技术研究中心、赣南科学院、市科技局）

六、推动人才双向交流

16.争取由中科院牵头或参与在我市成立新能源汽车、电子信息行业协会，定期举办行业类院、校、企合作论坛，帮助引进管理类人才和高技能人才。（责任单位：市工信委、市人社局、市教育局、市委人才办）

17.争取中科院所属院（校）按照专业培养特色重点与我市新能源汽车、电子信息产业重点企业合作，有针对性地互建技能人才实训基地。（责任单位：市人社局、市工信委、市委人才办、市科协、市招商服务中心）

18.争取中科院所属院（校）通过具体的项目作为载体与我市新能源汽车、电子信息等产业企业进行产学研合作。院（校）企双方互派人员到对方任教，院（校）提供科研成果和技术支撑，企业为院（校）提供项目和实习场所。（责任单位：市科技局、市教育局、市委人才办、市人社局、市工信委）

19.开展双向挂职交流。争取中科院专家人才来我市挂职锻炼或考察指导，围绕我市“两城两谷一带”产业发展及人才智力需求，选派一批优秀人才来我市挂职或专题调研、授课，指导攻克关键技术。同时接纳我市新能源汽车、电子信息、柑橘脐橙等专业技术人才到中科院进修。（责任单位：市委人才办、市人社局、市工信委、市科技局、赣南科学院、国家脐橙工程技术研究中心、市果业局）

20.“柔性引进”中科院专家。争取中科院“钨和稀土新材料”、新能源汽车、电子信息等相关产业的专家采取顾问、项目合作、技术入股、联合设立研发机构等多种灵活方式落户我市企业，支持企业的升级发展。（责任单位：市科协、市委人才办、市人社局）

七、围绕赣州特色产业部署科技专项

21.推进定南县人民政府与中科院宁波材料技术与工程研究所“派遣科技联络员服务当地企业技术难题”等产学研项目实施。（责任单位：定南县政府、市科技局）

22.加强与“中科院科技服务网络计划”、“战略性先导科技专项”等科技专项的对接，有针对性地选择优势企业作为中科院战略研讨、专家咨询和联合攻关的试验田和发展地，开展深度合作和联合攻关，推动稀土钨等产业升级发展。（责任单位：赣南科学院、市科技局、赣州高新区管委会）
