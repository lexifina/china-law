# 关于赣市府办发〔2016〕19号文件的补充通知

赣市府办字〔2017〕175号

赣州市人民政府办公厅

关于赣市府办发〔2016〕19号文件

的补充通知

各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区和赣州蓉江新区管委会，市政府各部门，市属、驻市各单位：

2016年7月14日，市政府办公厅下发了《关于印发〈关于加强政府投资房建市政工程建设项目招标投标工作的若干规定（试行）〉的通知》（赣市府办发〔2016〕19号，以下简称《若干规定》）。为更好地执行《若干规定》，进一步规范招标投标秩序，经市政府研究，决定对《若干规定》有关条款进行修改，现将有关事项通知如下：

一、《若干规定》第二条第二款“市本级政府投资的上述房建市政工程建设项目，适用于本规定”修改为“市本级政府投资的上述房建市政工程建设项目，适用于本规定。县（市、区）政府投资的房建市政工程建设项目可参照执行”。

二、《若干规定》第十一条“投标人数量应确定15至25家，具体数量由招标人在招标公告中明确”修改为“投标人数量确定为30家，并在招标公告中明确”，第十一条相应修改为“投标人数量的确定。采用A、B、C级信用承包商库进行施工招标的项目，投标人数量确定为30家，并在招标公告中明确。项目招标时，如投标报名人数不足30家，则不进行抽取，全部入围投标人；如投标报名人数超过30家，则按以下规定采用随机抽取的办法确定投标人：

第一次抽取投标人：在A级库中随机抽取投标人总数的60%，即18家；

第二次抽取投标人：在B级库中随机抽取投标人总数的25%，即8家；

第三次抽取投标人：在C级库中随机抽取投标人总数的15%，即4家。

投标人数量确定后，如A库企业报名人数不足约定的入围投标人数量时，则A库不再进行抽取，全部作为入围投标人，A库剩余入围投标人名额按60%的比例补充到B库、按40%的比例补充到C库；如B库企业人数（含补充后）不足抽取数量时，则B库不再进行抽取，全部作为入围投标人，B库剩余入围投标人名额直接补充到C级；如C库企业中符合条件的投标人数量（含补充后）不足时，则入围投标人数量自然减少。各级库中投标人名额数量按比例计算后四舍五入取整数，如小数点后面均为五时，则补充到高一级库。入围投标人确定后，在入围投标人中随机抽取15名正式投标人进行资格审查，经资格审查认定为不合格的，招标人应当在入围投标人中随机抽取并补足15名正式投标人数量”。

三、本通知自下发之日起施行，《若干规定》规定的其他内容不变。

2017年9月27日
