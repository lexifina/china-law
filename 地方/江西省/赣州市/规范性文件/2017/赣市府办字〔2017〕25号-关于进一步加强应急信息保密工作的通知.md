# 关于进一步加强应急信息保密工作的通知

赣市府办字〔2017〕25号

赣州市人民政府办公厅

关于进一步加强应急信息保密工作的通知

各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区和赣州蓉江新区管委会，市政府各部门，市属、驻市各单位：

为加强应急信息管理，根据《保密法》《中华人民共和国突发事件应对法》《江西省突发事件应对条例》及相关法律法规规定，现就加强应急信息保密工作通知如下。

一、高度重视。突发事件具有突发性、社会性、难于预见性和敏感性，极易引起社会关注，一旦传播失实容易造成负面影响，各地、各部门要高度重视突发事件等应急信息的保密工作。要严格按照《保密法》《中华人民共和国突发事件应对法》《江西省突发事件应对条例》和相关保密规定，加强应急信息保密工作。

二、加强管理。对涉密的信息，要严格按照密级文件进行管理，做好收发、登记、传递、保管、清退、销毁等工作，确定专人负责保管，不得私自存放密级文件。对未定密级的信息，包含市政府办公厅（应急办）通过手机平台、邮箱、OA系统、传真、短信等各种途径通报的应急信息、领导批示等，要按照内部文件进行管理，不得转发、外传、公开，不得在社交媒体上发布。

二、明确责任。各地、各部门要加强对保密工作的领导，严格落实各项保密工作制度，教育、督促本单位工作人员严格执行各项保密规定，严防内部信息外泄和失泄密事件发生。要按照“谁主管谁负责，谁泄露谁负责”的原则，对应急信息外泄或涉密信息外泄人员和单位严肃追责。
