# 关于印发《赣州市“城乡环境整治年”活动实施方案》的通知

赣市府办字〔2017〕31号

赣州市人民政府办公厅

关于印发《赣州市“城乡环境整治年”

活动实施方案》的通知

各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区、蓉江新区管委会，市政府各部门，市属、驻市各单位：

经市政府研究同意，现将《赣州市“城乡环境整治年”活动实施方案》印发给你们，请认真抓好贯彻落实。

2017年2月25日

（此件主动公开）

赣州市“城乡环境整治年”活动实施方案

2017年是全市“城乡环境整治年”。为切实加大全市城乡环境整治力度，进一步改善城乡人居环境，根据省城乡环境整治相关文件精神，结合赣州实际，制定本方案。

一、总体目标

围绕打造“干净整洁、秩序井然、通行顺畅、环境优美、和谐宜居”城乡环境，以整治“脏、乱、堵”问题为突破口，突出重点、统筹推进，综合治理、长效管理，全面开展城乡环境整治行动，推动全市城乡人居环境明显改善，为成功创建“全国文明城市”，“打好攻坚战、同步奔小康”提供良好的环境保障。

二、城镇市容环境整治重点任务

（一）环境卫生整治

1．加强城区街巷、江河水域、堤岸、绿地、重点部位、居民小区清扫保洁。推进环卫作业精细化管理，推行政府向社会购买环卫作业服务，做到清扫到位、保洁及时、生活垃圾日产日清。每月开展一次全民卫生日活动，集中整治城中村、城乡结合部、居民小区卫生死角，清理积存垃圾。（责任单位：市城管局（排序第一的为牵头单位，下同）、市水利局、市房管局、市交通运输局、市爱卫办、赣州机场分公司、南昌铁路局赣州车务段，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

2．强化工业污水和生活污水排放监管。依法严查重惩企业超标排放、偷排偷放等环境违法行为。查处沿街餐饮店、洗车店等场所沿街排放污水问题，督促业主及时整改到位。加快生活污水收集管网建设，新区建设和棚改项目全部实现雨污分离。加强污水收集管网维护，确保设施完好率达95%以上。（责任单位：市环保局、市发改委、市城管局、市城乡建设局、市公安局、市市政公用集团，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

3．强化扬尘油烟污染治理。城区建筑工地全部落实防尘、降尘措施，实行流散物体密闭化运输管理，执行车辆驶出建筑工地冲洗制度。推行机械化湿式清扫作业方式，科学实施洒水降尘，抑制道路扬尘。取缔露天烧烤，加强餐饮行业油烟排放监管，防止油烟直排。落实城区暂未利用土地围挡措施，清理种菜、畜禽养殖等行为。（责任单位：市城管局、市城乡建设局、市公安局、市工商局、市环保局、市国土资源局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

（二）市容市貌整治

4．强化户外广告、店招牌匾整治。规范户外广告设置，清理各类不规范广告，及时更新修复破损、缺损广告，取缔落地小广告牌，清理“牛皮癣”小广告，严肃打击小广告违法活动。在街巷、居民小区适当位置规范设置信息张贴栏，实行合法合规信息集中张贴。规范新设、重修店面招牌匾设置，实现临街店招牌匾整齐、协调、美观。（责任单位：市城管局、市公安局、市房管局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

5．强化临街标牌、设施、立面整治。清理临街乱搭乱披乱挂物品，修复清洗破损、污损临街立面，保持立面干净整洁。规范沿街指引、提示标牌，做到整洁完好。清理违规设置的商亭、报刊亭、岗亭等设施，依法许可经营的，实行统一喷涂标识。（责任单位：市城管局、市公安局、市邮政管理局、赣州电信分公司、赣州供电公司，相关业主单位，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

6．强化园林景观管护。加强园林绿地管养、公园广场设施维护，强化城市公共建筑亮化改造提升和设施维修管养，打造舒心宜人休闲环境。（责任单位：市城管局、市城乡建设局，相关业主单位，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

（三）市容秩序整治

7．整治占道经营行为。取缔主次干道、重要区域、公共场所摆摊设点、店外经营等占道行为。坚持疏堵结合，规范摊点疏导区管理，做到规范有序。（责任单位：市城管局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

8．整治占道作业、堆放、晾晒行为。规范占道开挖、占道施工、顶管作业等行为，查处乱扔乱倒垃圾、乱堆杂物、车窗抛物等行为，清理沿街晾晒衣物行为。（责任单位：市城管局、市公安局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

9．整治违法建设行为。重点管控农民返迁安置房、城乡结合部等重点区域，做到早发现、早制止、早拆除，实现违法建筑零增长。（责任单位：市城管局、市国土资源局、市城乡规划局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

10．规范燃放烟花爆竹行为。在城区适当区域设置烟花爆竹集中燃放点，引导市民在指定地点燃放。城区逐步限制出售、燃放烟花爆竹，减少环境污染和噪音扰民。（责任单位：市城管局、市公安局、市工商局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

（四）交通秩序整治

11．整治交通违法行为。整治机动车、两（三）轮车、行人交通违法行为，提升城市文明形象，保障交通安全畅通。（责任单位：市公安局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

12．规范停车秩序。在具备条件的道路上施划停车泊位线，引导机动车、两轮车有序停放，依法查处车辆乱停乱放、占人行道停放和车辆占公交站台区临时停靠行为，取缔私设停车泊位、圈占公共停车泊位等行为。（责任单位：市公安局、市城管局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

13．规范交通运营秩序。规范出租车、公交车、客运车营运秩序，做到不拒载、不甩站、不绕行、不宰客。打击非法营运车辆，维护客运秩序。（责任单位：市交通运输局、市公安局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

（五）市政公用设施整治

14．加强市政设施维修保养。及时修复车行道、人行道、路灯、排水沟、井盖等市政设施，修复、更新破损路名牌，新建贯通道路同步完善交通标线、信号灯、路灯、绿化等基础设施。（责任单位：市城管局、市城乡建设局、市财政局、市城投公司、市民政局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

（六）城区出入口和国道、省道环境整治

15．城区出入口环境整治。合理规划、设计和建设城市出入口道路，设置标识、雕塑等景观，推进景观建设和亮化工程。整治城市出入口道路两侧乱搭建、乱堆放行为。（责任单位：市城管局、市城乡规划局、市城乡建设局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

16．国道、省道环境整治。做好辖区国道、省道清扫保洁，清除占路堆放杂物、沙石、占路施工作业等行为，清理违章广告牌、横幅标语。做好国、省道治超工作。（责任单位：市交通运输局、市公安局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

（七）圩镇环境秩序整治

17．圩镇环境卫生整治。落实集镇清扫保洁人员，每日清扫，做到道路、集市干净、无卫生死角，生活垃圾日产日清，垃圾收集点无积存垃圾。（责任单位：各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

18．圩镇市容秩序整治。城市管理执法向圩镇延伸，落实管理人员，整治圩镇以路为市、占道摆摊设点、杂物乱堆乱放、车辆乱停乱放和乱搭乱建、乱披乱挂行为，保持圩镇秩序良好，通行顺畅。（责任单位：各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

19．圩镇公用设施整治。加大圩镇道路、沟渠、路灯等公用设施管护力度，及时修复破损道路和公用设施，做到路平、沟通、灯亮。（责任单位：各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

三、农村环境整治重点任务

（一）深入推进农村生活垃圾专项治理。推进城市环卫职能向农村延伸，建立由县级城管环卫部门统一管理负责的城乡环卫一体化工作体系。落实“户分类、村收集、镇转运、县处理”四级运行机制，加强垃圾收集转运和终端处理设施建设，推行农村环卫第三方治理和保洁员全职化。按照农村户籍人口不低于50元/年/人要求落实运行经费，按照不低于农村户籍人口3‰要求安排保洁人员。加强乡风文明教育，提高卫生保洁意识。2017年，全市农村生活垃圾处理率高于90%，所有县（市、区）申报农村生活垃圾专项治理省级考核验收。（责任单位：市委农工部、市城管局、市文明办、市城乡建设局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

（二）推进农村“空心房”整治。加大农村“空心房”拆除力度，实现拆除到位、清理到位、复垦到位。加大对祠堂、众厅、围屋、古建筑群等维修力度，保护传统村落，保留农村文脉。（责任单位：市国土资源局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

（三）开展农村民房庭院整治。以房前屋后干净、院内院外整齐为目标，实现农村民房院落洁化、硬化、绿化、美化，2017年新农村建设点整治率达到80%以上。（责任单位：市新村办，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

（四）加强农村建房管理。严格落实“一户一宅”政策，规范农民建房行为，坚持遏止乱搭乱建现象，集中整治农村“两违”。严格镇村规划实施管理，引导农民依规划建房，严厉查处违反规划的用地和建设行为。（责任单位：市城乡规划局、市国土资源局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

（五）推进交通沿线村点建筑立面整治提升。结合推进“整洁美丽，和谐宜居”新农村建设，对铁路、高速公路、国省道公路沿线及农村旅游公路沿线村点建筑进行立面整治和提升改造，重点对干道沿线可视范围内的残墙断壁、墙体广告、“赤膊墙”进行整治，引导有条件农户对房屋坡顶进行加固和改造，打造风格相对统一、体现客家特色的建筑风景线。（责任单位：市新村办、市城乡规划局，各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区管委会，蓉江新区管委会）

四、时间安排

“城乡环境整治年”活动分三个阶段实施：

（一）宣传动员阶段（2017年2月1日-2月28日）。一是组织召开全市“城乡环境整治年”动员大会；二是各责任单位认真制定具体实施方案，于2月28日前分别报送市市容环境专项治理工作指挥部办公室和市委农工部；三是新闻媒体开辟“城乡环境整治年”活动专题专栏，各责任单位开展形式多样的宣传活动，营造浓厚氛围。

（二）全面整治阶段（2017年3月1日-11月30日）。各责任单位对照整治任务，采取切实有效措施，逐项推进治理，确保工作成效。

（三）巩固提升阶段（2017年12月1日-12月31日）。市城市市容环境专项治理工作指挥部、市委农工部对任务完成情况进行检查验收，查缺补漏，督促整改，确保整治任务圆满完成。

五、工作要求

（一）加强组织领导。城市市容环境整治工作由市城市市容环境专项治理指挥部牵头组织实施；农村环境整治工作由市委农工部（市农办）牵头组织实施。各责任单位主要负责人是落实“城乡环境整治年”活动的第一责任人，要亲自抓、负总责；分管负责人是具体责任人，要具体抓、抓具体。各县（市、区）要落实属地责任，充分调动群众参与，认真组织实施好本地城乡环境整治活动。

（二）加强部门联动。各责任单位要认真履职、主动靠前，其他单位要大力支持、积极配合，形成密切合作、齐抓共管的工作合力。市直、驻市各单位要积极参与城乡环境综合整治，认真抓好环境卫生责任区的整治工作。市、县两级财政部门要加强经费保障，确保整治工作顺利推进。各新闻单位要加强宣传报道，为“城乡环境整治年”活动营造良好氛围。

（三）加强监督检查。各责任单位要将“城乡环境整治年”活动任务逐项明确责任人，高标准抓好落实。市市容环境专项治理工作指挥部和市委农工部要加强监督检查，及时通报整治情况。对工作成效明显的地方和单位，给予表彰和奖励；对工作落实不到位、进展严重滞后的，按照市委、市政府改作风、提效率“一个意见两个办法”进行问责处理。

（四）建立长效机制。各责任单位既要立足当前，下决心、下力气解决一批群众反应强烈的突出环境问题，又要着眼长远抓，好建章立制，在城乡环境综合整治的组织管理、责任落实、激励保障、举报监督、督查问责等方面建立长效机制，实现由突击整治向常态治理转变。
