# 关于印发《赣州市人民政府2017年立法工作计划》的通知

赣市府办字〔2017〕35号

赣州市人民政府办公厅关于印发

《赣州市人民政府2017年立法工作计划》的通知

各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区和赣州蓉江新区管委会，市政府各部门，市属、驻市各单位：

《赣州市人民政府2017年立法工作计划》已经市政府同意，现印发给你们，请认真遵照执行。

政府立法是一项重要的行政决策活动，是推进依法行政、建设法治政府的重要基础。起草单位要严格按照《赣州市人民政府制定规章和拟订地方性法规草案程序规定》，扎实做好相关立法工作。一要强化组织领导。起草单位要成立由主要负责人任组长的起草小组，落实起草人员，制定工作方案，严格按照时间要求向市政府报送送审稿。二要加强调查研究。坚持问题导向开展立法调研，全面了解立法事项的现状、重点难点和突出问题，形成调研报告，提出对策建议，积极学习借鉴外地的好经验、好做法。三要确保起草质量。坚持“不抵触、有特色、可操作”的立法原则，广泛征求意见，充分论证协调，着力解决好立法所涉及的重点、难点和热点问题，提高立法的科学性、针对性和操作性。

市政府法制办要切实做好立法工作计划的组织实施工作，督促指导起草单位抓紧开展相关工作，加强调查研究，依法协调立法工作中出现的问题，对草案送审稿要严格把关，进一步提高法规规章草案审查修改质量，确保完成市政府2017年立法工作任务。
