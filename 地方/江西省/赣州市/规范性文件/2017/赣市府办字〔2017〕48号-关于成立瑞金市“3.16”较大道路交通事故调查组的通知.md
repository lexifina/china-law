# 关于成立瑞金市“3.16”较大道路交通事故调查组的通知

赣市府办字〔2017〕48号

赣州市政府办公厅

关于成立瑞金市“3.16”较大道路交通

事故调查组的通知

瑞金市人民政府，市公安局、市监察局、市安监局、市交通运输局、市总工会：

2017年3月16日15时40分许,赣AC0360大货车与赣F81H78轻型普通货车在319国道414KM+900M（瑞金市大柏地乡路段）相撞，造成3人经抢救无效死亡。

根据《中华人民共和国道路交通安全法》、《生产安全事故调查和处理条例》等法律法规规定，经市政府研究，决定成立瑞金市“3.16”较大道路交通事故调查组。现将有关事项通知如下：

一、调查组由市公安局牵头，成员由市公安局、市监察局、市安监局、市交通运输局、市总工会、瑞金市人民政府等单位派人组成，并邀请市检察院派员参加。

二、调查组要严格按照“四不放过”原则，查明事故发生经过、原因及直接经济损失情况，认定事故性质，提出对事故责任单位和责任人的处理建议，总结事故教训，提出防范、整改措施，并按规定将事故调查报告提交市政府。

2017年3月17日

（此件主动公开）
