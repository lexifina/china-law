# 关于全面开展市直经营性国有资产自查申报工作的通知

赣市府办字〔2017〕53号

赣州市人民政府办公厅

关于全面开展市直经营性国有资产

自查申报工作的通知

市政府各部门，市属各单位：

为进一步盘活市直单位经营性国有资产，做大做强市属国有企业，推动我市国资国企深化改革上新台阶，经市政府研究同意，决定进一步推进市直经营性国有资产集中统一监管，组织市直行政事业单位全面自查申报所属经营性国有资产。现就有关事项通知如下：

一、进一步明确纳入集中统一监管的市直经营性国有资产范围

市直单位除办公必需的国有资产外，所属尚未脱钩移交的其他各类国有资产，均纳入市直经营性国有资产集中统一监管范围。

（一）市直单位经营性国有资产：包括市直单位开办的宾馆、酒楼、招待所、培训中心，以及对外出租的经营性用房、其他闲置房产、未进行房改的公有住宅、可经营性土地等国有资产。

（二）除地方金融和国家政策性因素不宜集中统一监管的企业外，市直单位以国有资金兴办的各类企业、咨询服务部（中心）等各种经济实体，以及投入到各类经济实体中的国有股权和在各类经济实体中所拥有的国有债权。

（三）市直单位所属公共服务类基础设施、风景名胜区等非经营性国有资产，如广场、公园、城市道路、公共停车场、景区等资产。

二、市直各单位对所属经营性国有资产进行全面自查申报

市直各行政事业单位要根据经营性国有资产集中统一监管的要求，以及本通知明确的经营性国有资产范围，认真组织对本单位经营性国有资产的全面自查、资产统计和申报工作。

（一）各单位要结合已脱钩移交的经营性国有资产情况，对本单位所属国有资产进行全面清查，对于自查后确无应交未交的经营性国有资产的，统一由主管部门向市直企事业单位改革攻坚领导小组办公室（设在市国资委）进行零填报，并加盖主管部门和法人代表印章。

（二）各单位对清理出来尚未脱钩移交的经营性国有资产，要按财务账面数认真填报《市直行政事业单位尚未脱钩移交经营性国有资产自查申报表》（附件1）、《市直行政事业单位尚未脱钩移交国有企业（股权）自查申报表》（附件2）和《市直行政事业单位非经营性国有资产自查申报表》（附件3），在2017年3月31日前报市直企事业单位改革攻坚领导小组办公室统计汇总（市国资委产权管理科，联系电话：8196681）。

（三）市直企事业单位改革攻坚领导小组办公室要根据各单位自查申报的经营性国有资产情况，及时牵头组织市直有关部门和赣州市国有资产投资集团等监管企业与经营性国有资产主管部门对接，核实资产情况，签订移接交协议，于2017年4月15日前完成脱钩移交手续。

三、对脱钩移交的市属经营性国有资产实行分类监管

市属经营性国有资产全部与原主管部门脱钩，移交至市国资委实行集中统一监管。市国资委要根据资产状况和市属国有经济布局结构调整规划，对市属经营性国有资产实行分类监管。

（一）对市直单位脱钩移交的经营性国有资产，由市国资委暂授权赣州市国有资产投资集团管理运营。

（二）对市直单位脱钩移交的国有企业（股权），除市政府授权市国资委直接监管的企业外，其他国有企业（股权）由市国资委根据市属国有经济布局结构调整规划和所监管企业发展定位，分别授权不同的所监管企业进行管理。

（三）对市直单位脱钩移交的非经营性国有资产，由市国资委根据资产性质和所监管企业发展定位，分别授权对应的所监管企业运营管理。

四、严肃工作纪律

（一）市直单位及所属企业要严格按照本通知明确的经营性国有资产范围，认真对本单位资产进行全面自查，如实填报尚未脱钩移交的经营性国有资产，不得瞒报漏报，不得抽逃、隐匿资金，不得擅自划拨、转移、出卖资产，不得突击花钱、私分财物，不得突击进人、突击提拔。

（二）市直企事业单位改革攻坚领导小组办公室要牵头组织市直有关部门开展督导检查，对各单位自查清理、资产统计、移交落实等情况进行督查，及时督促整改发现的问题。对瞒报信息、漏报资产、抽逃资金或疏于监管，导致国有资产流失涉嫌违纪的，移交纪检监察部门按照有关规定追究责任；涉嫌犯罪的，依法移送司法机关处理。对应交未移交经营性国有资产的，要倒查责任，严肃追究单位负责人和直接责任人的责任，视情节轻重，给予党纪、政纪处分。
