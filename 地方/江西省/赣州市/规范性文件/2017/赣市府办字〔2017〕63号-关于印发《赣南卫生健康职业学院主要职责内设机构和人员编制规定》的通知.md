# 关于印发《赣南卫生健康职业学院主要职责内设机构和人员编制规定》的通知

赣市府办字〔2017〕63号

赣州市人民政府办公厅

关于印发《赣南卫生健康职业学院主要职责

内设机构和人员编制规定》的通知

各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区和赣州蓉江新区管委会，市政府各部门，市属、驻市各单位：

《赣南卫生健康职业学院主要职责内设机构和人员编制规定》经市机构编制委员会审定，市政府批准，现予印发。

2017年4月1日

（此件主动公开）

赣南卫生健康职业学院主要职责

内设机构和人员编制规定

根据《江西省人民政府关于同意设立赣南卫生健康职业学院的批复》（赣府字〔2016〕25号）、《江西省机构编制委员会办公室关于赣南卫生健康职业学院级别的批复》（赣编办文〔2016〕69号）和《赣州市机构编制委员会关于设立赣南卫生健康职业学院的通知》（赣市编〔2016〕58号）精神，赣南卫生健康职业学院为赣州市卫生和计划生育委员会管理的正处级全额拨款事业单位，与赣州卫生学校合署办公，实行“两个机构、一套人马”；学院实行党委领导下的院长负责制。

一、主要职责

贯彻执行国家有关法律法规，依法办学，负责学院教育教学的管理；承担全日制高职学历教育，培养全日制高职学历层次的医药卫生健康高技能应用型人才；承担医药卫生健康类专业成人高等专科学历教育和医药卫生健康行业技术培训等非学历教育。

二、内设机构

（一）党政管理机构（11个）

1.党政办公室（外事办公室）

负责学院党委、行政综合性事务和学校重要事务、重大活动的统筹协调、组织实施，及档案、保密、信访、信息、外事、计划生育管理、对外交流等工作。

2.组织宣传统战部

负责全校性的思想政治教育学习、法制教育、校园文化建设、精神文明建设、对内对外宣传、校园门户网站及微信公众号等对外宣传媒介管理等工作。负责学院党委组织、统战、老干工作，具体负责党员发展、教育、培训和管理工作，干部的日常考核和管理工作，退休党支部和离退休人员管理、联系。

3.人事处

负责学院机构设置与调整、人员编制的管理、岗位设置、人才队伍建设规划、专业职务评聘、人事档案管理、工资审批核算等工作。

4.教育督导处

负责对学校教学活动和教学行为实施监督检查。具体负责教学质量监控，全校教学秩序及各教学环节督查，督促各教学机构组织开展教学自查自评工作，多渠道收集教学质量信息、组织课堂教学质量反馈测评。

5.招生就业处（校企合作处）

负责学院招生、实习、就业工作。具体负责学院的招生宣传与录取，就业指导与服务，学生实习安排、实践教学质量监控及实践基地建设，开展校校、校院、校企合作等工作。

6.后勤管理服务处

负责学院后勤保障服务工作。具体负责学院基础设施建设与维修，资产购置与管理，饮食服务与食品安全管理，校园环境卫生保洁、绿化、美化等物业督查管理，校医院启用前医务所日常管理以及学院医疗保健等工作。

7.科研处（高教研究室、学报编辑部）

负责学院高等职业教育及医疗卫生健康工作的开展与交流，科研项目的申报、管理、服务及学报编辑，搜集、处理并传递国内外教学改革信息等工作。

8.计划财务处

负责组织制定和实施学院经费预、决算方案，各项经费日常核算、管理，校内招投标组织，一卡通卡务管理等工作。

9.教务处

负责全院教学工作的宏观调控与整体性管理。具体负责人才培养目标和培养方案的总体设计、制定和调整；学科与专业申报、建设，组织实施全校性的教学改革，进行教学运行的日常管理和质量监控，开展教学改革立项、教学奖励和教学质量的评估工作、校外教学点教学评估以及实验室建设规划、课务及考务管理、学科竞赛管理与服务、教材建设与发放等工作。

10.学生工作处

负责全院学生工作的宏观调控与整体性管理。具体负责制定与实施学生工作规划计划，学生思想政治教育及日常管理，学生安全教育和心理健康咨询，班主任队伍建设，学籍管理、学生资助、学生保险办理及理赔服务、学生国防军事训练及学生宿舍管理等工作。

11.保卫处（人民武装部）

负责校园保卫、消防、维稳、社会治安综合治理，法制和安全教育，国防军事教育及征兵等工作。

（二）教学教辅、科研等机构

参照《江西省机构编制委员会关于省属高校机构管理有关事项的通知》（赣编发〔2016〕5号）有关规定，由赣南卫生健康职业学院根据学院教学科研任务、学科建设需求自主设置教学教辅、科研等机构，不定机构级别和领导职数，由市委编办备案管理：

1.教学机构（8个）：护理系、药学系、医学技术系、临床医学系、健康服务与管理系、医学基础部、人文社科部（思政部）、继续教育部。

2.教辅机构（2个）：图书馆、信息中心。

3.直属机构（1个）：附属医院。

三、人员编制

赣南卫生健康职业学院人员编制与赣州卫生学校共用，仍为282名全额拨款事业编制，不单独核定人员编制。其中，赣南卫生健康职业学院、赣州卫生学校领导职数配备：党委书记1名、院长（校长）1名，均为正处级；纪委书记1名、副院长（副校长）4名、工会主席1名，均为副处级。党政管理机构科级领导职数33名，其中正科级13名（含工会副主席、团委书记各1名）。8个教学机构基层党组织均配正、副书记各1名。

四、其他事项

赣州卫生学校原有职责不变。

五、附则

本规定由赣州市机构编制委员会办公室负责解释，其调整由赣州市机构编制委员会办公室按规定程序办理。
