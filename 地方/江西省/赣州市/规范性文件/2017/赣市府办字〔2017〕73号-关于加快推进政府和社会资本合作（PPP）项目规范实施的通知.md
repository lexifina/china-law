# 关于加快推进政府和社会资本合作（PPP）项目规范实施的通知

赣市府办字〔2017〕73号

赣州市人民政府办公厅

关于加快推进政府和社会资本合作

（PPP）项目规范实施的通知

各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区和赣州蓉江新区管委会，市政府各部门，市属各单位：

为贯彻落实市委全面深化改革领导小组第八次全体（扩会议精神，加快推进政府和社会资本合作（PPP）项目规范实施，现将有关事项通知如下：

一、提高思想认识

积极应用PPP模式，大力推动PPP项目落地，是破解项目资金难题、加快项目建设的重要举措，对于促投资、稳增长、打好“六大攻坚战”具有重要意义。各地、各部门要坚持问题和市场导向，进一步放宽投资准入，大胆使用PPP模式，务求在项目落地实施上取得突破。

二、明确工作目标

2017年，全市计划实施PPP项目56个（见附件），总投资555亿元。其中，市本级项目9个，总投资168.15亿元；县（市、区）项目47个，总投资386.85亿元。各地在规范实施好已有项目的基础上，年内至少新增2个PPP项目，市本级和各县（市、区）2017年PPP项目财政支出责任要达到一般公共预算支出的5%以上。

三、强化工作措施

（一）统筹安排PPP奖补资金。继续安排市级PPP奖补资金3000万元，对新建项目按投资规模给予奖励，对融资平台存量项目转型为PPP项目的，按项目转型实际化解地方政府存量债务规模给予奖励。各地要建立PPP项目奖补机制，安排专项资金用于PPP项目奖补。

（二）研究设立PPP引导基金。市、县两级逐步统筹适度规模的资金作为劣后资金，按照一定的杠杆比例募集金融和社会资本，共同设立PPP引导基金，为PPP项目提供资金支持，提高PPP项目融资的可获得性。

（三）争取中国PPP基金合作支持。加强与中国政企合作投资基金（中国PPP基金）对接，组织召开项目对接会，推荐我市投资额较大、质量较高的PPP项目，争取中国PPP基金支持。

（四）推进相关领域强制应用PPP模式。在垃圾处理、污水处理等公共服务领域，各地新建项目原则上采用PPP模式实施；在其他有现金流、具备运营条件的项目原则上实施PPP模式识别论证，鼓励尝试运用PPP模式，注重项目运营，提高公共服务质量。

（五）进一步优化操作流程。发展改革部门在PPP项目审批、核准或备案等方面要与财政部门PPP操作流程中项目方案编制、评估论证、审核审批等有效衔接，建立部门间PPP协同管理和联审机制，明确管理职责，进一步提高工作效率。

（六）加强业务培训。每个季度分行业分领域开展一次专题培训和研讨活动，适时组织外出考察学习，提高对PPP项目管理实施的能力和水平。

（七）建立PPP项目财政支出责任统计分析制度。各地、各有关部门每年7月向市财政局报送PPP项目财政支出责任统计表，严格监控PPP项目支出责任，防范控制财政风险，实现PPP可持续发展。

（八）加强PPP项目财政管理。行业主管部门在完成PPP项目识别后，20个工作日内完成物有所值评价报告、PPP实施方案、财政承受能力论证报告的编制工作并报批。财政部门在收到行业主管部门报送的物有所值评价报告、财政承受能力论证报告后，10个工作日内组织专家进行评审并出具批复意见。为保证PPP项目全生命周期规范实施、高效运营，各级财政部门要会同相关部门，统筹安排财政资金、国有资产等各类公共资产和资源与社会资本开展平等互惠的PPP项目合作，切实履行项目识别论证、政府采购、预算收支与绩效管理、资产负债管理、信息披露与监督检查等职责。

（九）建立PPP咨询服务机构库和评审专家库。积极发挥第三方专业机构作用，向社会公开征集PPP咨询服务机构和评审专家，建立咨询机构库和评审专家库，提高PPP项目发起、实施的质量与效率，并视情况对入库机构和专家进行动态调整。

（十）建立PPP顾问制度。针对我市PPP人才缺乏实际，鼓励各地通过政府购买服务方式引进智力支撑，聘请专业化团队帮助开展PPP项目总体规划、开展项目咨询论证、方案设计和法律咨询等工作。

（十一）完善管理机制。各地、各部门要切实加强PPP项目的组织领导，加强力量，健全机构，保证各项工作有序开展。建立健全推广PPP模式的政策和制度保障，协调解决项目实施过程中的问题，推进项目规范高效实施。

（十二）落实主体责任。各地、各部门要切实承担起推进PPP工作的主体责任，主要负责同志要亲自抓、亲自管，压实责任，确保工作实效。项目实施机构要全面履行牵头职责，主动作为，履职尽责。市政府将PPP项目落地情况纳入科学发展综合考评。市财政局每季度对全市PPP项目进行调度和通报。
