# 关于加强当前春耕生产工作的通知

赣市府办字〔2017〕79号

赣州市人民政府办公厅

关于加强当前春耕生产工作的通知

各县（市、区）人民政府，赣州经济技术开发区、赣州蓉江新区管委会，市政府有关部门，市属、驻市有关单位：

当前已进入春耕生产大忙时节。为认真做好今年春耕生产工作，现将有关工作通知如下：

一、大力宣传惠农政策。充分利用广播、电视、报纸、网络、短信等多种有效途径，深入宣传党和国家一系列强农惠农富农政策，特别是耕地地力保护补贴、粮食适度规模经营补贴、农机购置补贴、最低收购价、市县扶持蔬菜产业发展等政策，做到家喻户晓，深入人心。要认真落实各项强农惠农政策，细化工作方案，规范操作程序，强化资金管理，确保政策落实不走样，给农民的实惠不缩水，充分调动农民群众和农业企业发展春季农业生产的积极性、主动性。

二、积极推进土地流转。通过各种手段和方式，充分利用确权登记颁证成果，积极落实“三权分置”政策，保障农民合法权益。整合涉农资金加大对基本农田建设的投入力度，完善奖补机制，对集中连片流转土地发展适度规模经营的农业主体，符合条件的优先安排涉农项目和适当补助。坚持改革创新，鼓励探索股份合作、联耕联种等土地流转新模式，大力引导扶持村级组织集中流转土地发展适度规模经营，破解流转难题。进一步建立完善县、乡、村三级农村土地流转服务体系，提升信息发布、价格评估、土地鉴定、合同管理服务水平。

三、全面落实春耕面积。围绕“稳粮、优供、增效”的总体要求，把落实面积作为春耕生产的首要任务，及早把粮食面积层层分解落实下去，重点是抓好早稻面积落实，确保春播和全年粮食生产面积稳定，为全年粮食生产打好基础。要抓好种植结构调整工作，优化耕作模式，积极推广优质稻、有机稻、再生稻等优质优价品种，大力发展蔬菜、食用菌、刺葡萄等高效经济作物。

四、提升科技服务水平。大力推广农业新品种、新技术、新机具、新工艺、新模式，提高春季农业生产科技水平。要聚集整合农业科研、教学、推广等力量，大力开展春季农业技术培训，积极开展送科技下乡活动。要做好春管、春耕、春播所需机械的调配、维修、保养工作，提高作业质量。要统筹安排好新品种展示、测土配方施肥、病虫害统防统治等技术项目，深入推进粮食绿色高产高效创建工作，加快高标准蔬菜基地建设，创办一批高水平、高质量的示范样板。

五、强化农资市场监管。做好农机具、种子、化肥、农药、农膜、柴油等生产资料的调剂、调运、储备和供应工作，保障当前农业生产的需要。要对农药、肥料、种子等重点农资产品价格实行动态监测，并采取有效措施防止价格过快上涨。要组织公安、工商、质监、农粮、物价等部门，集中开展“农资打假”等专项治理行动，规范市场秩序，严厉打击制假售假和坑农害农行为，杜绝假冒伪劣农资流入市场，为农业生产的顺利开展营造良好的市场环境。

六、注重农业防灾减灾。积极做好农业防灾减灾工作，制定防灾预案，落实应对措施。农粮、气象、水利等相关部门要加强沟通会商，密切关注天气变化，及早发布预警信息，科学研判灾害可能带来的影响，提前做好种子、种苗、化肥、柴油、农药等各项救灾物资准备。要加强对重大农作物病虫害监测预警，及时掌握病虫害发生动态，准确预报发生趋势。落实灾害应急应对工作，对突发灾害适时启动应急响应，组派救灾工作组和专家指导组，深入灾区开展工作，帮助灾区搞好生产恢复，根据灾害情况、影响程度、作物种类、生育时期，制定相应的救灾方案，加强分类指导，主动避灾、科学抗灾、积极救灾，最大限度减少灾害损失。

七、切实强化组织领导。把春耕生产作为当前农业工作中的重要任务，建立主要领导亲自抓、分管领导具体抓、相关部门抓落实的工作机制，推动各项工作早安排、早动员、早落实，坚决打好春耕生产第一仗。要进一步增强大局意识、责任意识、服务意识，认真履行好工作职责，加大工作力度，落实工作责任。要深入春耕生产第一线，加强检查督导，科学决策，靠前指挥，帮助农民、企业解决生产中的困难和问题。

2017年4月20日
