# 关于支持龙南全南定南园区一体化发展的若干意见

赣市府发〔2017〕14号

赣州市人民政府关于支持龙南全南定南

园区一体化发展的若干意见

各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区和赣州蓉江新区管委会，市政府各部门，市属、驻市各单位：

为推动龙南、全南、定南（以下简称“三南”）一体化发展，打造赣州南部重要增长板块，根据《国务院办公厅关于促进开发区改革和创新发展的若干意见》（国办发〔2017〕7号）精神，现提出如下意见。

一、总体要求

（一）基本思路。由国家专项资金、市本级财政、“三南”共同出资和引进外来资金，采取市场化运作，组建运营公司，统一实施征地拆迁、“三通一平”以及配套基础设施建设，在“三南快线”沿线、“京九”铁路沿线建设“三南”承接加工贸易转移示范地产业园（以下简称“三南”示范园）。创新管理模式，将全南工业园、定南工业园、“三南”示范园纳入龙南经济技术开发区（以下简称龙南经开区）管理，推动品牌共用、政策共享、规划共编、园区共建、数据并表，构建龙南经开区“一区四园”发展新格局。

（二）发展目标。“三南”示范园一年拉开框架、两年完善配套、三年初具规模。“三南”加工贸易产业主营业务收入在2016年基础上实现三年翻番。到2020年，龙南经开区经济实力大幅提升，核心竞争力明显增强，工业增加值、主营业务收入、利税总额在全省国家级经开区中排位前移、位居前列，电子信息首位产业在全省比重提升。

二、着力创新体制机制

（三）创新管理体制机制。深化行政审批制度改革，赋予“三南”更加灵活的管理权限，在“三南”有条件承接的前提下，将市级经济管理、企业投资、行政管理和行政执法权限依法授权或委托“三南”行使；对确需市相关主管部门审核转报省级审批事项，实行即时办理。加强统计业务指导，创新“一区四园”统计方法。

（四）改革人事管理体制。创新选人用人机制，在征得上级组织人事部门同意后，赋予“一区四园”对外公开招聘事业编制干部和选调科级及以下机关工作人员的权限。支持“一区四园”开展以全员聘任制和薪酬绩效激励制为主要内容的人事制度改革。探索建立干部差异化绩效考核制度和末位淘汰制度，畅通“一区四园”身份对等人员能进能出的双向渠道和职级晋升渠道。

（五）完善财税管理体制。建立“三南”示范园财税分享机制，按照三个县招商企业纳税比、基础设施出资比进行核定。原龙南经开区和全南、定南工业园区财税独立运行。从2018年起，凡由龙南经开区新引进并在其区域范围内设立的各类纳税人（除银行、保险、证券等金融业外），在龙南经开区范围内中央、省投资的基础设施建设项目所缴税费，由项目所在地税务机关进行征收。龙南经开区区域范围内所有土地出让收入归属龙南经开区。

（六）创新投融资体制。鼓励设立“三南”产业发展基金，加大“一区四园”建设和产业发展投入。推动设立赣粤产业合作基金，赣粤产业合作项目向“一区四园”倾斜集中。推动政策性银行和开发性金融机构加大对“一区四园”信贷支持力度。优化完善产业投融资体制机制，推进“一区四园”加快形成“基金+基地”的产业发展载体建设新模式。支持龙南经开区建投公司依照国家有关规定，上市和发行中期票据、短期融资券等债券产品筹集资金。

（七）推进试点示范。争取将国家级新区、自贸区、深圳前海经济特区等先行先试优惠政策复制到“一区四园”。争取龙南县、全南县、定南县享受省直管县相关政策，争取将国家和省级层面试点示范优先在“三南”布局。争取省政府将“三南”列入“多规合一”试点县。支持“一区四园”开展产城融合和园区循环化改造试点，探索行政区与功能区融合发展的体制机制。支持“一区四园”创建国家生态工业示范园区和申报国家级园区循环化改造试点园区。

三、着力加快园区发展

（八）支持园区基础设施建设。争取将“一区四园”上缴的新增建设用地有偿使用费、森林植被恢复费省、市两级分成部分，按规定用途通过安排专项支出的形式，用于支持“一区四园”基础设施建设。支持鼓励单位、集体或个人在“一区四园”投资兴建标准厂房。对符合条件的标准厂房项目，在申报省级专项补助的基础上，市县财政给予配套补助。对投资建好的标准厂房，因招商等原因造成无法投入生产且无其他经营收入的，按规定减免房产税、城镇土地使用税。

（九）鼓励企业入驻。对入驻“三南”示范园的电子信息产业项目，总投资1亿元及以上且在两年内竣工投产的，由受益财政按其项目设备投资额的3%以内给予一次性补助，单个项目最高补助额不超过300万元；总投资3亿元及以上且在两年内竣工投产的，在受益财政补助的基础上，市财政再适当给予一次性补助；对新引进的世界500强企业由受益财政给予一次性开办补助。“三南”示范园内标准化厂房建设和入驻企业应缴的政府定价管理的涉企经营服务性收费，一律按下限执行。对入驻“一区四园”的企业，缴纳房产税、城镇土地使用税确有困难的，由企业提出申请，经批准后，可按规定予以减免。帮助龙南经开区争取比照适用国家自主创新示范区在股权奖励、转股增本、技术转让等方面的个人所得税优惠政策。

（十）支持企业技术创新。支持“一区四园”重点企业增加对关键、核心技术研发的投入，不断提高研发经费占销售收入的比重；搭建产学研对接平台，组织企业参加高校产学研和对外科技合作考察、科技创新论坛等活动。重点支持企业与高校、科研院所共建省级高新技术重点实验室、工程技术研究中心等产业技术创新平台。推动与工信部电子第五研究所合作，设立国家级“三南”电子信息产品检验检测中心。鼓励“一区四园”内重点企业购买用于重点工艺流程和环节改造关键设备，对符合条件的企业视同技术改造予以资金支持。

（十一）支持企业挂牌上市。对“一区四园”内企业挂牌上市给予奖励，在省财政奖励基础上，对在境内主板、中小板、创业板上市的企业，每户由市县财政各奖励 500万元；对在境外上市并符合条件的企业，每户由市县财政各奖励100万元；对在“新三板”成功挂牌的企业，每户由市财政奖励120万元，县级财政给予配套奖励。

（十二）推进一体化招商。创新招商引资方式，建立“一区四园”联动招商工作机制，统一招商政策，统一宣传口径，推进“一区四园”一体化招商。健全与粤港台产业对接合作机制，探索在“一区四园”设立跨省（区）产业合作区，打造“飞地经济”。

（十三）加快“三南快线”建设。把“三南快线”作为推进“三南”产城融合、构建龙南经开区“一区四园”发展新格局的重大项目，统一建设标准，由“三南”共同出资，市财政给予补助，推动“三南快线”尽快全线贯通。

四、着力强化保障措施

（十四）加大资金支持。由市财政筹集1亿元，“三南”各出资1亿元，推动设立产业发展基金，通过股权投资、债权投资、风险投资等方式支持“三南”示范园建设。“三南”示范园新增财力由市本级和“三南”按一定比例予以分成。省下达的承接加工贸易转移事项资金优先向“三南”示范园倾斜。争取省财政新增地方政府债券和置换债券资金，新增债券资金向“一区四园”倾斜。加大市级资金奖励倾斜力度，对“一区四园”内年纳税额首次突破5000万元、1亿元的工业企业，市财政分别给予100万元、200万元的一次性奖励；对新认定的国家级、省级企业技术研究中心，由市财政分别给予30万元、20万元一次性奖励；对被国家工商总局新认定为地理标志证明（集体）商标、中国驰名商标的产品，由市财政给予每件10万元的一次性奖励；对被认定为江西省著名商标、江西省名牌产品的由受益财政给予5万元的一次性奖励。对新认定的高新技术企业，由市级财政对其给予研发投入的20%、最高不超过10万元的一次性奖励。对“一区四园”企业进口的高端设备和先进技术，在国家、省给予贴息补助的基础上，市财政按照上级进口贴息金额1：1的比例予以配套。

（十五）强化用地保障。每年倾斜下达“三南”用地计划，其中单列“一区四园”用地计划；对符合条件的重大项目，列入省重大项目调度，使用省级预留计划指标，做到应保尽保。“一区四园”耕地占补平衡以县域自行平衡为主，资源匮乏确实无法完成土地开发补充耕地任务的，在市域范围内统筹予以解决。鼓励企业推行工业用地“长期租赁、先租后让、租让结合”供应方式，缓解企业一次性支付土地出让金的资金压力。鼓励现有用地提高土地利用率，在符合规划、不改变用途的前提下，对现有工业用地通过厂房加层、厂区改造、内部用地整理等途径提高土地利用率，对增加容积率的，不再增收土地价款。经依法批准后，鼓励划拨土地上的工业厂房、仓库等用于养老、流通、服务、旅游、文化创意等行业发展，在一定时间内可继续以划拨方式使用土地，暂不变更土地使用性质。支持“一区四园”调区扩区。

（十六）强化人才支撑。支持“一区四园”建立健全人才培养、引进、使用、流动、评价等制度，鼓励高等院校、科研院所和金融机构人才到“一区四园”挂职锻炼，支持高等院校、科研机构和企业实行创新人才双向流动。支持“一区四园”加大高端领军人才和高层次人才引进力度，鼓励企业引进国外智力和外国专家。

（十七）加强组织领导。建立市县两级推进“一区四园”建设联席会议制度。市级联席会议由市政府主要领导召集，市商务局具体承办，研究解决“一区四园”建设重大问题，在前期起步阶段原则上每月召开一次，正常运转后每半年召开一次。县级联席会议由龙南经开区党工委书记召集，龙南经开区具体承办，可根据需要即时召开。在龙南经开区设立“一区四园”建设工作县级指挥部。市政府督查室将支持“一区四园”建设工作列入重点督查内容，加强督查督办，确保各项政策措施落到实处。

市直、驻市各部门（单位）要根据本意见于2017年6月中旬前制定具体实施细则，最大限度支持帮助“一区四园”创新发展、转型升级。

2017年5月25日
