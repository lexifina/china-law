# 关于印发《2017年40件民生实事安排意见》的通知

赣市府发〔2017〕3号

赣州市人民政府

关于印发《2017年40件民生实事

安排意见》的通知

各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区和赣州蓉江新区管委会，市政府各部门，市属、驻市各单位：

现将《2017年40件民生实事安排意见》印发给你们，请认真遵照执行。

2017年1月17日

（此件主动公开）

2017年40件民生实事安排意见

一、群众生产生活

1.提升中心城区“菜篮子”工程。统筹安排资金6.02亿元，在中心城区新增50亩以上规模蔬菜基地8000亩；新（改）建社区蔬菜便利店20家；新（改）建水西西出入口等6个农贸市场；加快推进水西蔬菜批发市场一期工程建设。〔责任单位：市农粮局、市商务局、章贡区人民政府〕

2.实施中心城区景观提升改造工程。统筹安排资金2.16亿元（2017年完成1.41亿元），完成章江右岸市民公园（南河大桥至西津门）建设；对章江两岸（武龙大桥至北门段）及八镜台、郁孤台、古城墙夜景亮化提升改造；对赣州东、赣州北高速出入口进行道路扩宽、绿地景观提升改造；完成西津门－龟角尾木栈桥建设。〔责任单位：市城管局〕

3.加快中心城区快速路网建设。统筹安排资金110亿元（2017年完成26.41亿元），建设文明大道、迎宾大道、赣南大道、东江源大道及创业路等快速路；实施红旗大道东延（沙河段）项目；打通栎木坑路、宝福院路、东坡路、广电路、储运路、廉泉路，改造广电路与黄屋坪路交叉路口、贡竺路与红旗大道东延路口。〔责任单位：赣州城投集团、章贡区人民政府、赣州经济技术开发区管委会、市城乡建设局、市城乡规划局、市城管局〕

4.加快中心城区公共停车场建设。统筹安排资金8.55亿元（2017年完成1.68亿元)，开工建设人民巷停车场、梅关大道与全南路交汇处停车场；建设油山路及金辉路公交首末站、章贡王路公交换乘枢纽；新建中心城区公交候车亭60座；新增公交线路6条（含微公交3条）。〔责任单位：市政公用集团、市城乡建设局、市城乡规划局、市交通局、市公交总公司、市城管局〕；为符合条件的65周岁以上老年人提供免费乘坐公交车。〔责任单位：市公交总公司、市老龄办、各县（市、区）人民政府〕

5.实施中心城区公共自行车项目建设。统筹安排资金2090万元，投放1000辆公共自行车，建设40个自行车租赁点。〔责任单位：市城管局、市公交总公司〕

6.建设智能交通指挥系统。统筹安排资金6000万元，实施智能交通项目，在中心城区无交通信号灯路口安装交通信号灯及监控设备，提升交通管理科技信息化水平。〔责任单位：市公安局、章贡区人民政府、赣州经济技术开发区管委会〕

7.实施历史文化街区及百街小巷提升改造工程。统筹安排资金28.42亿元（2017年完成5.5亿元），对新赣南路、阳明路等街区进行改造；对中心城区的老旧小区及街巷开展道路硬化、排水排污管道改造及公共设施维护等环境综合整治提升。〔责任单位：赣州城投集团、市文广新局、市城乡规划局、章贡区人民政府〕

8.实施市容市貌提升工程。统筹安排资金1.3亿元，对健康路、厚德路、青年路、大公路、环城路、红环路等6条道路进行立面改造；对新老城区144条人行道进行整治。〔责任单位：市城管局、章贡区人民政府〕

9.实施惠民小游园、小广场工程。统筹安排资金3000万元，完成羊婆巷、赣纺等7个小游园、小广场项目建设。〔责任单位：章贡区人民政府〕

10.加快推进垃圾处理场建设。统筹安排资金9.39亿元（2017年完成3.48亿元），加快赣州市生活垃圾焚烧发电厂、赣州市垃圾处理转运中心和赣州市餐厨废弃物资源化利用和无害化处理中心项目建设；完成赣州市水上环卫码头项目建设。〔责任单位：市城管局、章贡区人民政府〕

11.推进净空、净水、净土工程。统筹安排资金1090万元，深化大气污染、水污染、土壤污染治理，空气质量优良率高于全省平均值，地表水主要监测断面水质达标率稳定在90%以上，土壤重金属污染势头有效遏制；对中心城区章江河段河道的淤积物进行清理。〔责任单位：市环保局、市水利局、市政公用集团、市城管局、市水保局、市城乡建设局、市工信委、市农粮局、各县（市、区）人民政府〕

12.加快环保基础设施建设。统筹安排资金5.64亿元（2017年完成5.19亿元），新建赣州市生活污水处理厂污泥处置中心、赣州市工业固体废弃物处置中心、赣州市医疗废物集中处置中心。〔责任单位：章贡区人民政府、信丰县人民政府、赣县区人民政府、市环保局、市卫计委〕

13.实施农村路桥提升改造工程。统筹安排资金30.3亿元，完成县道、乡村道路、通25户以上自然村公路提升改造1200公里；改造危桥120座。〔责任单位：市交通局、各县（市、区）人民政府〕

14.实施上犹江引水工程一期暨龙华水厂工程建设。统筹安排资金8.62亿元（2017年完成1.2亿元），实施上犹江引水工程一期暨龙华水厂工程建设,改善中心城区居民饮用水质量。〔责任单位：市政公用集团、市环保局、市水利局、市城乡规划局、市城乡建设局、南康区人民政府〕

15.完善电网基础设施建设。统筹安排资金21.3亿元，实施农网升级改造、整乡整镇配电网建设改造、村村通动力电、城网中低压、中心村农网建设改造升级等配电网项目建设；年内建成投运南康稍江220千伏、兴国高兴110千伏输变电工程；开工建设赣州西500千伏、于都葛坳220千伏、新能源汽车城赤湖110千伏等输变电工程。〔责任单位：赣州供电公司、各县（市、区）人民政府、赣州经济技术开发区管委会〕

16.实施大广高速南康南互通工程。统筹安排资金4.46亿元（2017年完成2.1亿元），加快大广高速南康南互通连接线SL33（第二期）工程建设；对105国道天马山大道交叉口至SL33交叉口进行改扩建。〔责任单位：南康区人民政府〕

17.实施电动汽车充电基础设施项目建设。统筹安排资金3100万元，建设直流快充桩20根，交流慢充桩88根，在7对14个高速公路服务区建设直流快充桩56根。〔责任单位：市发改委、赣州供电公司、市机关事务管理局〕

二、社会保障和社会救助

18.扩大社会保险覆盖面。统筹安排资金98.86亿元，加大社会保险征缴扩面力度，年内城乡居民社会养老保险参保人数达403万人；城镇企业职工养老保险参保人数达95万人；机关事业单位养老保险参保人数达22万人。〔责任单位：市人社局、各县（市、区）人民政府〕

19.加快社会养老服务体系建设。统筹安排资金8.16亿元（2017年完成3.87亿元），新（改、扩）建福利院、光荣院、敬老院、民办养老机构60所，新（改、扩）建章贡区7个社区（村）居家养老服务中心；新建农村老年人颐养之家20个，新增养老床位4000张；推进章贡区翡翠谷养老基地建设。〔责任单位：市民政局、市老龄办、各县（市、区）人民政府〕

20.建设赣州市精神卫生社会福利院。统筹安排资金5000万元（2017年完成2000万元），加快推进赣州市精神卫生社会福利院项目建设。〔责任单位：市民政局、市卫计委、市国土局、章贡区人民政府〕

21.加强对弱势群体援助。统筹安排资金7484万元，为1275名在康复机构训练的贫困残疾儿童（少年）提供康复补贴；为300名贫困肢体残疾人安装假肢；为300名肢体残疾人适配矫形器；为4200名贫困残疾人配发各类辅助器具；为1255名残疾儿童提供学前教育资助；为1000户贫困残疾人家庭进行无障碍改造；建设赣州市残疾人康复托养中心。〔责任单位：市残联、各县（市、区）人民政府〕

三、医疗保障

22.实施健康保障工程。统筹安排资金3317万元，对九种重大疾病和贫困家庭艾滋病机会性感染患者实施免费救治；对贫困地区儿童提供营养改善和地中海贫血免费筛查；在全市二级、三级医疗机构按总床位的5%左右设置扶贫病房（床），五保、低保和建档立卡贫困人口入住后享受健康扶贫政策。〔责任单位：市卫计委、各县（市、区）人民政府〕

23.实施医保“一站式”服务。统筹资金10.28亿元，实现全市城乡贫困人口四道医疗保障线“一卡通”同步结算；实现全市城乡居民基本医疗保险和大病保险“一卡通”。〔责任单位：市人社局、市民政局、市卫计委、市扶贫和移民办、各县（市、区）人民政府〕

24.推进赣州市人民医院新院建设。统筹安排资金7210万元，完成赣州市人民医院新院建设并全面投入运营使用。〔责任单位：市卫计委〕

25.建设赣州市妇幼保健院新院。统筹安排资金8.64亿元（2017年完成8000万元），加快推进赣州市妇幼保健院新院建设。〔责任单位：市卫计委、市城乡规划局、市城乡建设局、赣州经济技术开发区管委会〕

26.推进赣州市儿童医院建设。统筹安排资金3.3亿元（2017年完成6500万元），加快推进赣州市儿童医院建设。〔责任单位：南康区人民政府、市卫计委〕

27.加快县级公立医院建设。统筹安排资金18.19亿元（2017年完成8.4亿元），新建兴国县人民医院、会昌县人民医院、于都县人民医院贡江新院。〔责任单位：兴国县人民政府、会昌县人民政府、于都县人民政府、市卫计委〕

28.新建新能源科技城医院。统筹安排资金7400万元（2017年完成3000万元），在科技城按二级综合医院标准新建1所区级综合医院。〔责任单位：赣州经济技术开发区管委会〕

29.加强食品安全检测。统筹安排资金3500万元（2017年完成1300万元），完成龙南、瑞金食品药品检验检测中心建设；新建安远县食品检验检测所；推行农产品生产基地例行监测工作，开展8万批次以上农产品安全快速检测。〔责任单位：市食品药品监督管理局、市农粮局、龙南县人民政府、瑞金市人民政府、安远县人民政府〕

四、教育文体事业

30.加大对家庭经济困难学生的资助力度。统筹安排资金2.47亿元，对义务教育阶段家庭经济困难寄宿生补助生活费；对家庭经济困难的幼儿园、普通高中、中职学校及高考考入大学的学生进行资助；对全市1.5万名普通高中建档立卡家庭经济困难和残疾学生免除学杂费。〔责任单位：市教育局〕

31.加快中心城区义务教育学校建设。统筹安排资金8.74亿元（2017年完成5.19亿元），开工建设厚德路小学章江路校区、阳明小学、文清路小学梅江路校区、西津路小学唐江路校区；扩建杨梅小学、黄金小学、车头小学；建设赣州经济技术开发区金岭学校、黄金中学分校、科技城学校（九年制）；建设南康区东山中心小学；建设蓉江新区高校园区管理处中心小学；建设赣县思源学校（二期）、城关七小。〔责任单位：章贡区人民政府、赣州经济技术开发区管委会、南康区人民政府、赣县区人民政府、赣州蓉江新区管委会、市教育局〕

32.改善城乡义务教育基本办学条件。统筹安排资金2.17亿元，完成113所薄弱学校的改造，新（改、扩）建校舍面积12万平方米。〔责任单位：市教育局、各县（市、区）人民政府〕

33.加快城乡公办幼儿园建设。统筹安排资金 1亿元，城区新（改、扩）建公办幼儿园13所；新（改、扩）建村级公办幼儿园151所。〔责任单位：市教育局、各县（市、区）人民政府〕

34.加快赣南职业技术学院建设。统筹安排资金11亿元（2017年完成5亿元），加快推进赣南职业技术学院项目建设。〔责任单位：赣州城投集团、市教育局〕

35.建设赣州市综合文化艺术馆。统筹安排资金7.88亿元（2017年完成1亿元），推进赣州市综合文化艺术馆项目建设。〔责任单位：赣州城投集团、市文广新局〕

36.推进公共文化服务标准化、均等化建设试点工作。统筹安排资金17.38亿元（2017年完成4.38亿元），完成全市5个试点县、260个示范单位标准化建设；以保护非物质文化遗产为核心，加快国家级客家文化（赣南）生态保护实验区建设。〔责任单位：市文广新局、各县（市、区）人民政府〕

37.加快市民休闲健身公园建设。统筹安排资金1.25亿元（2017年完成8420万元），推进杨仙岭人文健身公园基础设施、杨梅渡公园二期、赣州公园二期建设；对飞龙岛进行保护利用；新建叶坪路公园。〔责任单位：市城管局、章贡区人民政府〕

38.加强体育设施建设。统筹安排资金9338万元（2017年完成4638万元），新建南康体育公园体育场；新建乡（镇）、村（社区）体育健身设施60个。〔责任单位：各县（市、区）人民政府、市体育局〕

五、住房保障

39.加快扶贫移民搬迁。统筹安排资金20.92亿元，完成易地扶贫搬迁5万人，其中建档立卡贫困人口搬迁3.4万人。〔责任单位：市扶贫和移民办、市发改委〕

40.实施保障性安居工程。统筹安排资金108.77亿元（2017年完成65.33亿元），完成城市棚户区改造24685户；国有垦区危旧房改造137户；国有林场危旧房改造147户。〔责任单位：市房管局、市农粮局、市林业局、各县（市、区）人民政府〕

抄送：市委各部门，市纪委办公室，市人大常委会办公厅，市政协办公厅，赣州军分区，市中级法院，市检察院，群众团体，新闻单位。
