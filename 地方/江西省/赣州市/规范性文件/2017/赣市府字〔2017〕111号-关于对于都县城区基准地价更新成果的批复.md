# 关于对于都县城区基准地价更新成果的批复

赣市府字〔2017〕111号

赣州市人民政府

关于对于都县城区基准地价更新成果的批复

于都县人民政府：

你县《关于请求批准于都县城区基准地价更新成果的请示》（于府文〔2017〕28号）收悉。经市政府研究，同意你县2017年城区基准地价更新成果，请按规定抓紧公布实施。同时，要根据经济社会发展情况，定期修编城区基准地价，合理配置土地资源，节约集约利用土地，促进经济社会又好又快发展。

特此批复。
