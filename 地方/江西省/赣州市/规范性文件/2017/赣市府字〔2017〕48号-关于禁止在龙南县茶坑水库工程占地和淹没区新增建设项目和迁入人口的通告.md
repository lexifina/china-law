# 关于禁止在龙南县茶坑水库工程占地和淹没区新增建设项目和迁入人口的通告

赣市府字〔2017〕48号

赣州市人民政府

关于禁止在龙南县茶坑水库工程占地和淹没区新增建设项目和迁入人口的通告

茶坑水库位于龙南县南部的临塘乡塘口村茶坑片区，距龙南县城约23千米，水库坝址位于桃江二级支流、渥江一级支流石门河中游，水库正常蓄水位为黄海高程297.5米，总库容为2220万立方米，是一座以承担城乡供水为单一任务的中型水库。为切实做好茶坑水库建设征地补偿和移民安置工作，确保茶坑水库前期工作顺利进行，避免重复建设，根据《大中型水利水电工程建设征地补偿和移民安置条例》（国务院令第471号）第七条的有关规定，经省人民政府同意，现将有关事项通告如下：

一、工程占地和淹没区范围

（一）枢纽工程占地区为：临塘乡塘口村茶坑片区枢纽工程建设征地红线范围内的区域。

（二）水库淹没区为：东起下蕉陂，西至高陂头，南起龙仔头，北至上屋。范围包括黄海高程297.5米以下区域以及黄海高程297.5米以上受相应水库洪水回水、风浪等淹没影响的区域（林地按正常蓄水位黄海高程297.5米以下，耕园地相应五年一遇洪水回水淹没处理范围，居民点、专项相应二十年一遇洪水回水淹没处理范围）。

具体范围可参见茶坑水库工程占地和淹没区示意图(附后)。

二、自本通告发布之日起，禁止任何单位、组织和个人在茶坑水库工程占地和淹没区新建项目和迁入人口。违反上述规定而造成茶坑水库工程占地和淹没区新增的项目资产和人口，一律不予补偿。

三、本通告由江西省扶贫和移民办公室、赣州市人民政府负责督促检查，龙南县人民政府负责组织实施。龙南县人民政府要积极支持茶坑水库建设，为工程建设创造良好环境。要认真做好群众的思想工作，教育干部群众正确处理国家利益、集体利益和个人利益的关系，正确处理长远利益和眼前利益的关系，正确处理全局利益和局部利益的关系，顾全大局，确保移民安置工作顺利进行。

四、本通告从发布之日起执行。

特此通告。

2017年3月10日
