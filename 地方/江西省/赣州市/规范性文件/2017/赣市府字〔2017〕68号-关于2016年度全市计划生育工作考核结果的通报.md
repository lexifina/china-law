# 关于2016年度全市计划生育工作考核结果的通报

赣市府字〔2017〕68号

赣州市人民政府

关于2016年度全市计划生育工作

考核结果的通报

各县（市、区）人民政府，赣州、龙南、瑞金经济技术开发区和赣州蓉江新区管委会，市政府各部门，市属、驻市各单位：

2016年，在市委、市政府的坚强领导下，各地坚持计划生育基本国策不动摇，稳妥实施全面两孩政策，全面提升服务管理水平，确保了年度计划生育目标任务圆满完成，有效促进了人口均衡发展。为鼓励先进，推动工作，经综合考核评估，市政府决定，将2016年度全市计划生育工作考核结果通报如下：

一、综合先进县（市、区）（8个）

（一）一等奖(1个)

寻乌县

（二）二等奖(3个)

全南县、龙南县、石城县

（三）三等奖(4个)

信丰县、上犹县、南康区、崇义县

二、综合先进乡（镇、街道）（50个）

石城县小松镇
