# 关于做好2018年蔬菜产业发展工作的意见

赣市府办发〔2017〕74号

赣州市人民政府办公厅

关于做好2018年蔬菜产业发展工作的意见

各县（市、区）人民政府，市政府有关部门，市属、驻市有关单位：

2018年是我市蔬菜产业全面推进、规范发展、提档升级的关键一年。为深入贯彻落实全省现代农业发展暨产业扶贫现场推进大会精神和市委市政府乘势而上加快蔬菜产业发展的部署，促进农业结构调整，助推产业扶贫，现就做好2018年蔬菜产业发展工作提出如下意见：

一、明确年度目标任务

（一）咬定“把蔬菜打造成农业支柱富民产业，把赣州打造成江南重要的蔬菜集散地”定位，发挥龙头带动作用，以品种引领、品质提升、品牌打造为主攻方向，统筹规划布局，重点在乡（镇）村建设一批生产规模适度、紧密联结菜农的大棚设施蔬菜基地，发挥辐射带动和示范引领作用，推动产业规模扩张、结构优化、质量提档、效益提升。

（二）全年新（扩）建规模蔬菜基地钢架大棚10万亩，力争全市蔬菜基地面积达25万亩，其中钢架大棚面积达到15万亩，产业总产值达到85亿元。坚持因地制宜、适度规模，原则上每个乡镇新（扩）建蔬菜大棚200亩以上。通过引导农民自主发展、返租倒包、订单生产、入股分红等方式，覆盖带动20万户以上的农户发展蔬菜产业。

二、遵循规划布局推进

（一）应用《赣州市蔬菜产业发展规划（2017—2025）》成果，制定逐年推进计划，合理布局年度发展地块，落实经营主体。鼓励返乡创业农民采取直接投资、股份合作、订单农业等形式，发展适度规模蔬菜基地。

（二）加强蔬菜良种繁育基地和集约化育苗基地建设，提高优良种苗供应能力。坚持“一村一品”发展思路，引导农民群众相对连片种植，主推2—3个主导品种，按专业化要求发展蔬菜生产。注重引进种苗繁育、全程植保、蔬菜加工、冷链物流等服务型企业，推动蔬菜全产业链发展。

三、建设大棚设施基地

（一）选择地势平坦、交通便利、沙质土壤、排灌便利、水位较低的地块发展设施蔬菜基地，地处偏远、立地条件较差的乡镇因地制宜发展大棚种植。

（二）完善农村土地经营权流转机制，促进农村土地向蔬菜规模基地、合作社、家庭农场和大户集中。坚持高标准农田建设与设施蔬菜基地建设紧密结合、同步设计，改善水电路渠和地力条件，提升设施蔬菜基地标准化水平。

（三）注重经济实用原则，适应种植茬口调整和越冬越夏生产要求，鼓励发展冬保暖、夏遮阳生产型经济大棚。合理调控茬口安排，发展瓜果类、茄果类和特色叶类等有比较效益的蔬菜种植。引导现有基地巩固提升，带动周边农户种植，形成蔬菜专业村组。

四、构建新型经营方式

（一）发挥企业经营型蔬菜基地龙头带动作用，推广企业提供种苗、技术、农资和产品回购，农户负责种植并按产量、品质获得收益等模式，推动种植技术、经营模式、市场信息向乡镇、村延伸辐射，输入现代生产要素和经营模式，带动千家万户发展大棚蔬菜。

（二）加快培育专业大户、家庭农场、合作社等新型蔬菜生产主体。鼓励工商资本投资兴建蔬菜大棚设施，采取出租方式交由专业大户、家庭农场经营。在乡镇、蔬菜专业村（组）培育组建蔬菜合作社，通过土地、资金、技术、品牌等入股或采取合同制、订单制、委托制、代理制等方式，促进龙头企业、合作社与农户间由带动向合作转变，让更多的收益留给蔬菜种植户。

（三）落实“五个一”产业扶贫机制，推广“蔬菜企业+合作社+贫困户”、“433”（钢架大棚40%基地示范经营，30%返租给种植能手，30%无偿租给贫困户种植）等产业扶贫模式，带动贫困户要素入股、就业务工、订单生产。通过“一对一”结对措施，精准推送生产技术、市场行情，推进蔬菜产业精准扶贫。

五、普及推广先进技术

（一）以蔬菜专家团为依托，围绕品种和大棚开展技术攻关，加强蔬菜基地巡回技术指导。推广吊蔓栽培、长茬栽培、深浅根轮作、绿色防控、土壤改良等技术，以及水肥一体、生物调节等机械化装备，提升蔬菜基地种植效益。

（二）加快推进高效种植示范基地建设，每个县（市、区）提升或新建1—2个推广新品种、新技术，辐射带动全县的高效种植示范基地，年内形成3个以上蔬菜品种种植技术规程，引导专业化种植、标准化生产。

（三）大力开展蔬菜技术人员和专业菜农培训，加快蔬菜新技术推广应用，提升基层一线蔬菜种植水平。依托“两中心一基地”，分现场参观、实训教学、现场诊断、远程指导四个阶段，全年培训县乡干部、种植能手2000人次以上。

六、完善产业服务体系

（一）加快构建县、乡、村三级技术服务网络，充实和配强技术力量，强化田间地头指导服务。鼓励政府购买服务引进专业人才，引导本地种菜能手示范带动，加快培养一支本地化蔬菜技术队伍。

（二）加快培育社会化服务组织，推进市场信息、种植技术、生产资料等公共服务。创新蔬菜农资供销方式，构建植保服务平台，推进社会化专业植保服务。搭建学员互助和技术交流平台，推进各类主体分享种植经验，合理安排生产茬口。

（三）强化病虫害测报预警，在“两中心一基地”建立物联网系统，构建“蔬菜病虫害远程诊断和咨询服务体系”，在每个县选取3—5个规模基地，布点汇集病虫害数据信息，及时预警、科学预防。

七、实施产业品牌战略

（一）实施蔬菜质量安全提升计划，加强安全监管体系建设，督促规模基地制定生产流程，规范生产档案、过程监控和销售台账，逐步建立质量追溯制度。充实加强乡镇农产品检测中心，做好蔬菜基地质量安全检测工作。

（二）实施“三品一标”奖补政策，引导各类蔬菜经营主体开展基地认定、产品认证，打造生态原产地保护产品、中国农业名牌产品，推进标准化生产、商标化销售。鼓励发展方便净菜和蔬菜加工业。

（三）引入良好农业规范、HACCP认证，提升出口竞争优势，建设一批面向东南沿海、港澳蔬菜供应及出口蔬菜基地，带动提升产业发展水平。

八、搞活市场流通

（一）完善“1+3”蔬菜产业体系，加快建设中农批赣州国际农产品交易中心，布局建设一批产地批发市场，改造提升一批农贸市场，补充发展一批社区便利店。

（二）大力培育市场主体，推广生产、供销、信用“三位一体”综合合作模式，发展壮大购销经纪人队伍。支持运输、联运、快递企业拓展服务项目，扶持工商企业及社会力量从事蔬菜配送、连锁经营、电子商务等业务。

（三）用好国内国际两个市场，重点瞄准广州、深圳、厦门、港澳和其他国内高端市场，加强对接与交流合作，建立互利合作产销关系。依托赣州港构建对外物流通道，对接国际贸易平台，扩大高端品质蔬菜出口。

九、加大政策支持力度

（一）市财政继续预算安排资金，对新（扩）建100亩及以上蔬菜钢架大棚进行奖补，补助标准按赣市府办字〔2017〕24号文件执行，跨年度分两次验收奖补到位。冬暖式保温大棚按高标准大棚补助标准进行奖补。2017年新发展并通过验收的基地，继续按原奖补政策执行第二批奖补。各地要及时宣传扶持政策，设立蔬菜产业发展资金，对百亩以下基地钢架大棚、喷滴灌设施、预冷设施、露地基础设施和土地流转等进行奖补，及时组织验收并兑现政策。

（二）全力推进“财政惠农信贷通”、“小微信贷通”和“产业扶贫信贷通”政策落实，以财政资金撬动金融资金、带动社会资金，共同支持蔬菜产业发展。有条件的县（市、区）要成立蔬菜产业融资平台，探索组建蔬菜产业投资集团，应用现代融资方式解决资金投入问题。

十、切实加强组织领导

（一）各地要把发展蔬菜产业摆上产业结构调整、现代农业发展、农民脱贫增收的重要位置，抓紧分解年度任务，提早落实种植地块，提前做好土地流转等前期工作。要加强工作力量，切实解决人员和经费等问题，强化工作调度。

（二）把蔬菜产业发展列入现代农业攻坚战重要考核内容，加强督促检查，每季度对县（市、区）工作进度进行通报。各地要对乡镇工作落实情况加强调度，促进此项工作落到实处。
