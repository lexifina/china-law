# 关于印发赣州市专利质量提升特色主题国家知识产权试点城市工作方案的通知

赣市府办字〔2017〕217号

赣州市人民政府办公厅关于

印发赣州市专利质量提升特色主题国家知识产权试点城市工作方案的通知

各县（市、区）人民政府，市政府各部门，市属、驻市各单位：

经市政府同意，现将《赣州市专利质量提升特色主题国家知识产权试点城市工作方案》印发给你们，请结合实际认真组织实施。

2017年12月28日

（此件主动公开）

赣州市专利质量提升特色主题国家知识

产权试点城市工作方案

为进一步提高我市知识产权创造、运用、保护、管理能力与水平，充分发挥知识产权对经济社会发展的助推器作用，确保我市国家知识产权试点城市建设取得实效，根据《国务院关于新形势下加快知识产权强国建设的若干意见》（国发〔2015〕71号）及《加快推进知识产权强市建设工作方案（试行）》（国知发管字〔2015〕59号）文件要求，结合我市实际，制定本工作方案。

一、工作目标

（一）总体目标

全面贯彻落实国家、省关于知识产权战略的决策部署，坚持以专利质量提升支撑城市创新发展为主线，以加强知识产权保护和运用为主题，以知识产权强市、强县、强企建设为抓手，进一步建立健全与我市经济、社会发展相适应的知识产权创造、运用、保护、管理体系；构建有利于知识产权创造和运用的政企联动、上下协作的工作新机制，扩大培育一批拥有自主知识产权、知名品牌和具备核心竞争力的优势企业；营造尊重、保护知识产权的良好法治、经济环境，建成名列省内前茅的专利质量显著提升的知识产权强市。

（二）具体目标

1．知识产权创造能力得到加强。专利质量显著提升，到2019年，发明专利申请比例、发明专利授权量大幅增长，全市有效发明专利增长50%，万人发明专利拥有量超1件，职务专利拥有量占全市专利总量的比重达50%，专利授权量达1.5万件。大力实施商标战略，更加注重国际、国内商标注册；更加注重作品和软件著作权登记、植物新品种授权；在主要产业领域形成一批高价值专利、高知名度品牌。

2．知识产权实施效果明显提高。不断提高专利技术产业化实施率，专利产品产值占工业产品产值的比重、自主品牌企业增加值占地区生产总值比重不断增加，高新技术产业产值占规模以上工业产值比重达到40%，重点支持依靠专利技术实施，实现产品产值上亿元的高新技术企业，知识产权试点、示范企业50家以上。

3．知识产权保护力度逐步加大。组建市专利侵权判定专家库，积极争取设立中国（赣州·稀土稀有金属）知识产权保护中心，开展相关部门联动执法和专项维权行动，严肃查处假冒专利、假冒商标、侵权盗版等行为，依法维护知识产权权利人的合法权益。

4．全社会知识产权意识普遍增强。加大对知识产权工作的宣传力度，每年组织4次以上知识产权培训活动，组织实施中小学学校开展知识产权教育，充分利用电视、报纸、网络等新闻媒体宣传知识产权，提高全社会知识产权认知度。加强知识产权工程师培训和引进，形成一批复合型知识产权管理人才，满足企业不断增长的知识产权发展需求。

5．完善知识产权服务体系。加强知识产权中介服务机构支持、管理，试点期间重点培育壮大1—2家知识产权服务机构，1—2家知识产权（专利）孵化中心；建立健全重大项目专利审查机制，探索开展产业专利导航，建立知识产权保护预警机制，增强企业保护知识产权的能力。

二、工作任务

（一）推进自主知识产权创造

1．提高企业知识产权创造能力。推进企业建立工程（技术）研究中心、企业中心，加强研发机构建设的培育工作。充分发挥政府各类专项资金导向作用，围绕我市支柱产业和高新技术企业，支持企业加强专利技术信息利用，挖掘企业专利与实施企业专利技术的行业布局，引导企业加大科技投入，努力创造一批具有自主知识产权的核心技术。（责任单位：市科技局、市发改委、市工信委、市财政局）

2．推进知识产权园区建设。通过开展知识产权试点示范园区、试点示范企业培育，规范园区、企业知识产权制度建设。鼓励和支持工业园区开展省级知识产权试点园区、示范园区建设工程，形成具有区域特色的知识产权工作体系、服务体系和保护体系。（责任单位：市科技局、市工信委）

3．组织实施知识产权富民强县示范县建设工程。总结“十二五”期间知识产权富民强县专项实施经验，进一步加大市知识产权富民强县示范县建设专项实施力度，不断加强市、县（市、区）知识产权人员配备和机构建设，强化知识产权工作机制，建立健全管理制度。指导、督促有条件的县（市、区）制定本级知识产权战略行动计划或实施意见，推进知识产权战略在广大基层的落地实施。（责任单位：市科技局、市委编办）

4．组织实施知识产权管理规范国家标准推广工程。积极推动企业高校、科研机构开展知识产权管理规范国家标准工作。大力贯彻实施《企业知识产权管理规范》国家标准，将贯彻《企业知识产权管理规范》作为高新技术企业培育工作的重要内容，引导企业挖掘创新潜能，提升运用知识产权制度的能力，力争到“十三五”末全市申请“贯标”企业累计达40家以上，通过认证的企业达30家以上。选取1—2所市内高校（院所）开展高校、科研机构知识产权管理规范国家标准试点工作，引导和提升市内高校（院所）的知识产权管理能力。通过企事业单位的“贯标”工作，推动企业、高校、科研院所成立知识产权管理部门，配备专门人员，制定管理制度，明确管理职责，逐步实现知识产权管理工作的规范化、标准化，打造一批知识产权强企、强校和强所。（责任单位：市科技局、市工信委、市教育局、江西理工大学、赣南师范大学）

5．培育高价值专利。将高价值知识产权创造和拥有情况作为科技立项的重要内容，形成推动高价值知识产权创造的鲜明导向。通过实施高价值专利培育计划，加强企业研发全过程中的专利信息利用、预警分析、申请管理，努力实现高新技术企业、规上企业有效发明专利全覆盖。（责任单位：市科技局、市工信委）

6．鼓励企业创建自主商标品牌。加大对企业、农民专业合作社商标注册的力度，提升市场主体自主商标拥有率。扶持拥有驰（著）名商标的企业做大做强，发挥商标品牌优势，提高综合竞争力。引导和支持农业组织、农业企业注册农产品商标、地理标志，重点培育一批如“赣南脐橙”、“赣南油茶”、“南安板鸭”等具有赣州特色农林产品商标品牌，农产品商标品牌，形成一批市场覆盖面广、影响力大、经济价值高的高知名度商标。（责任单位：市工商局、市质监局、市农粮局、市林业局、市工信委）

（二）促进知识产权运用

1．强化企业知识产权管理标准化建设。推行企业知识产权管理规范国家标准，引导企业建立健全知识产权管理制度，推动企业将知识产权管理融入研发、生产、销售的全过程。支持知识产权服务机构面向中小企业开展集中管理、委托管理服务，加快提升中小企业知识产权管理水平。（责任单位：市科技局、工信委）

2．推动企业实施知识产权战略。深入实施企业知识产权战略推进计划，支持通过“贯标”认证的企业研究制定知识产权战略规划，将知识产权战略纳入经营发展战略，实现创新水平、技术装备层次、规模效益的全面提档升级。支持知识产权服务机构为企业提供知识产权战略策划、信息分析、纠纷应对等服务，提高企业知识产权战略实施能力。加大指导和服务工作力度，发挥企业知识产权工程师作用，推动企业尽快熟悉并积极运用知识产权规则应对国内外竞争挑战。（责任单位：市科技局、市工信委）

3．打造知识产权密集型企业。实施知识产权密集型企业培育计划，遴选一些具有较强创新实力、较大品牌优势、良好发展潜质的企业，优先支持建有工程（技术）研究中心等研发机构的企业实施科技项目，努力集聚高层次知识产权人才和团队，创造引领产业发展的知识产权成果，造就拥有核心知识产权和自主品牌的知识产权密集型企业。（责任单位：市科技局、市发改委、市工信委）

4．启动专利导航工作。启动钨产业专利导航项目，以钨产业专利导航项目为起头，逐步建立稀土产业、新能源汽车及其应用等特色产业专利信息资源分析和运用，将专利信息分析与产业运行决策深度融合，专利创造与产业创新高度匹配。积极开展专利导航工作试点，以专利导航优化专利创造，进一步完善以市场需求为导向、以专利运用为目的的专利创造体系。（责任单位：市科技局、市工信委）

5．拓展知识产权投融资渠道。建立健全多元化、多渠道的知识产权投融资体系。鼓励银行金融机构开展知识产权质押融资，支持拥有自主知识产权的企业通过资本市场直接融资。（责任单位：市科技局、市财政局、赣州银监分局、市金融工作局）

6．实施中小学知识产权教育试点工作。通过打造一批示范学校，让青少年从小形成尊重知识、崇尚创新、保护知识产权的意识，并充分发挥中小学知识产权教育的辐射带动作用，形成“教育一个学生，影响一个家庭，带动整个社会”的局面，增强全社会的知识产权意识，营造“大众创业、万众创新”的良好社会氛围，加快实施创新驱动发展战略，有力推动国家知识产权试点示范城市建设。（责任单位：市教育、市科技局）

（三）加强知识产权保护

1．加强知识产权执法队伍建设。优化行政执法资源配置，组织专利、商标、版权、软件著作等知识产权执法队伍培训，提高行政执法人员的服务能力和执法效能。（责任单位：市科技局、市工商局、市文广新局、市质监局、市农粮局、市林业局、市公安局）

2．加大知识产权行政执法与保护力度。坚决打击侵权假冒专利、商标、版权的违法犯罪行为，加大对恶意侵权、重复侵权等案件的打击力度。结合各种专项行动，重点对与人民生活密切相关商品的商标的侵权和专利的假冒行为依法进行严厉打击。建立知识产权侵权违法档案，将假冒专利、假冒商标、侵权盗版等信息录入国家企业信用公示系统（江西）归集与企业或个人名下。推行知识产权执法信息公开，及时向社会发布案件投诉和处理情况。（责任单位：市商务局、市科技局、市工商局、市文广新局、市质监局、市农粮局、市林业局、市公安局）

3．强化知识产权司法保护。加强知识产权行政主管部门和公安机关的沟通与合作，形成联合执法协调机制，依法加大对侵权案件的查处打击力度，推进行政执法与刑事司法的衔接，努力形成知识产权保护合力。（责任单位：市公安局、市检察院、市科技局、市工商局、市文广新局、市质监局、市农粮局、市林业局）

（四）强化知识产权管理

1．健全知识产权服务体系。培育和引进服务质量优、信誉好、水平高、实力强的知识产权代理机构，组织知识产权管理人员参加各项专业知识培训，组建知识产权服务小分队,深入企业提供上门服务，为企业出谋划策、排忧解难。（责任单位：市科技局、市工商局、市文广新局、市质监局、市农粮局、市林业局、市公安局、市工信委）

2．充分发挥维权平台作用。加强“12330”知识产权维权援助与举报投诉制度建设，及时处理解决本市知识产权举报投诉问题，向社会公众提供知识产权申请、管理、维权和转化等相关服务。（责任单位：市科技局、市工商局、市文广新局、市质监局、市农粮局、市林业局、市公安局）

（五）提高全社会知识产权意识

1．广泛开展知识产权宣传普及活动。结合“3·15消费者权益日”、“4·26世界知识产权日”等宣传活动，重点开展知识产权法律法规宣传，不断提高全社会知识产权意识，营造知识产权保护的社会氛围。（责任单位：市科技局、市工商局、市文广新局、市质监局、市农粮局、市林业局、市公安局）

2．开展“知识产权进企业、进机关、进学校、进社区”活动。鼓励有条件的学校开展知识产权课程，组织开展青少年创新发明竞赛活动。（责任单位：市教育局、市科技局、市工商局、市文广新局、市质监局、市农粮局、市林业局）

3．强化企业制度建设。加强对技术创新型企业技术秘密保护工作的宣传与指导，引导企业建立健全技术秘密管理制度。（责任单位：市科技局、市工信委）

三、保障措施

（一）加强组织保障。成立由市政府分管领导任组长，科技、财政、发改、统计、工信、工商、文广等相关部门为成员的国家知识产权试点城市推进工作领导小组，负责研究制定推动我市创建国家知识产权试点城市的重大政策措施，协调解决创建工作中遇到的重大问题。领导小组下设办公室，设在市科技局。

（二）加大政策支持。加强产业、科技、人才等政策与知识产权政策的衔接，把是否拥有自主知识产权作为各种政策支持的前置条件；突出发明专利、PCT专利申请、运用为导向，着力保护自主知识产权，根据全市专利工作情况，完善专利奖励补助政策；支持企业争创名牌产品、驰名商标、著名商标，促进企业提高品牌知名度。

（三）加大经费投入。统筹用好科技创新券专项资金，采取事前引导企业需求、事后兑现创新券方式，支持知识产权密集型企业专利创造，提升专利质量，支持知识产权优势示范企业培育、贯彻企业知识产权管理规范，以及企业专利维权，产业专利导航、专利权转让、专利实施许可并实施转化；引导企业设立知识产权专项经费，特别是知识产权示范企业、知识产权贯标企业要设立专项知识产权工作经费，用于知识产权的申请、维持、保护、宣传培训以及转化实施等。

（四）严格目标考核。将知识产权重点工作纳入市委、市政府对县（市、区）科学发展综合考核内容，相关部门把知识产权工作作为对县（市、区）专项工作目标责任制考核，通过考核促进知识产权各项工作的全面落实，推进知识产权强县工程建设；把知识产权工作作为企业高企申报、复核、项目申报的关键指标，同时对全市建有工程（技术）研究中心、企业中心的企业进行运行绩效评估考核，把知识产权工作作为权重较大的考核内容，进一步促进企业提高知识产权作用意识。

（五）加强典型示范。在知识产权强市工程建设过程中，大力培育、宣传知识产权典型，对知识产权典型单位予以表彰奖励，对好的做法予以推广，充分发挥典型示范效应，促进全市知识产权事业有序发展。
