# 关于切实做好夏季安全生产重点工作的通知

赣市府办字〔2018〕64号

赣州市人民政府办公厅

关于切实做好夏季安全生产重点工作的通知

各县（市、区）人民政府，市政府有关部门，市属、驻市有关单位:

夏季是高温、雷电、暴雨、强风等自然灾害多发的季节，也是各类安全生产事故的易发、高发期。为认真贯彻落实国家、省、市关于加强安全生产工作的决策部署，进一步筑牢安全发展根基，做好夏季安全生产工作，严防各类安全生产事故发生，现就有关事项通知如下：

一、强化红线意识，高度重视夏季安全生产工作

各地、各有关部门和单位要认真贯彻习近平总书记、李克强总理等中央领导同志关于安全生产的重要指示批示精神，坚守安全红线，强化忧患意识、风险意识和责任意识，认真分析研判当前安全生产面临的风险因素，深刻汲取近期各类安全事故的教训，高度重视季节因素对安全生产工作造成的不利影响，切实把夏季安全生产工作摆到重要位置，抓实抓细抓好。各县（市、区）安委会、十二个市安全生产专业委员会牵头部门主要负责同志近期要专题研究部署安全生产工作，做到把忧患放在心中，把责任扛在肩上，确保安全生产各项要求传达到位、任务部署到位、隐患排查到位。要组织力量对辖区重点行业领域、重点单位和重点部位进行检查督查，坚决遏制各类重、特大事故发生，确保全市安全生产形势持续平稳。

二、认真排查隐患，切实强化安全生产源头治理

各地、各有关部门和单位要按照“全覆盖、零容忍、严执法、重实效”总要求，坚持问题导向，迅速组织开展安全生产执法检查，扎实抓好安全生产隐患排查，做到关口前移、横向到边、纵向到底，严厉打击、整治各类非法违法、违规违章行为。要结合全市正在开展的安全生产十大专项整治等行动，对重点行业、重点领域、重点单位、重点部位认真梳理分类排查，坚决把事故隐患找到查清并消灭在萌芽状态。要依法运用行政处罚、责令停产、暂扣吊销证件、查封扣押等法律赋予的权力，确保安全隐患得到彻底整治。

三、突出重点领域，不断加大安全监管力度

各地、各有关部门和单位要结合本辖区、本行业和高温季节安全生产特点，在前期十大专项整治扫雷行动的基础上，聚焦重点行业领域，进一步加大安全监管力度，扎实开展专项治理排查，严厉打击各类非法违法生产经营建设行为。

（一）工矿企业安全监管方面。非煤矿山方面，要加强重点部位和场所的安全监控，实施24小时不间断巡查，制定落实防滑坡、防中暑事故的具体措施。危险化学品和烟花爆竹方面，要针对气温升高易造成危险化学品挥发、泄漏和爆燃，加强对危险化学品重大危险源的监控以及危险化学品生产、储运设施的检查，落实危险化学品装置和管道防爆、防雷电、防泄漏措施。要加强对现场直接作业环节的安全监管，严格执行施工动火、有限空间作业、高空作业、临时用电、重物吊装、危化品仓储、危化品装卸运输、检修施工等方面的安全管理制度。要督促烟花爆竹批发企业严格落实烟花爆竹仓库通风散热、防火、防雷、防静电、防水、防潮等安全防范措施。冶金、机械等行业方面，要加强通风管道、阀门降温等设备的检测，加强锅炉等压力容器、仪器仪表等计量设备的检查和维修，确保安全运行。

（二）道路（水上）交通方面。要重点整治疲劳驾驶、超载、超速违法行为，加大“两客一危”车辆、校车、渣土车等交通运输企业、重点路段的路检路查，严防超员超速、疲劳驾驶和无证无照经营等严重违法违规行为。加强对危化品运输车辆的监督检查，督促经营单位落实防火、防爆、防泄漏措施，确保安全。

（三）建筑施工方面。要突出抓好夏季高温及汛期建设工程重点项目、重点部位的安全管理，着重抓好深基坑、高支模、建筑起重机械和脚手架等重点部位汛期防雷电、防风、防坍塌工作。夏季高温期间，要督促用人单位调整作业和休息时间，采取“做两头、歇中间”的方法，避免疲劳作业，日最高气温达到40℃以上，停止室外露天作业；日最高气温达到37℃以上、40℃以下时，室外露天作业时间累计不得超过6小时。要督促生产经营单位改善劳动条件，减轻劳动强度，高温作业场所要采取有效的通风、散热、降温措施，对年龄大、身体素质差、不适应高温作业的人员要及时调换岗位，配备防暑设施、防护用品和急救药品，确保劳动者身体健康和作业安全。

（四）消防安全方面。要加强对宾馆饭店、商场超市、集贸市场、网吧歌厅、养老机构、学校食堂等人员密集场所的消防安全检查，大力宣传消防安全知识，督促生产经营单位认真落实突发事件应急预案以及人员控制和疏导措施，加强用火、用电、用油、用气的防火安全管理，及时发现和消除火灾隐患，严防高温天气下各类火灾事故的发生。要突出对住人地下室、群租房、快递仓储、汗蒸场所、电瓶车集中充电点的检查巡查和相关人员的安全教育。要认真开展电气火灾防范检查，在电气火灾多发场所推广安装电气火灾监控系统。对检查中发现的火灾隐患和消防安全违法行为，依法采取罚款、拘留、“三停”、封查等手段，督促整改落实到位。

（五）城镇燃气方面。要加强对城镇液化天然气站、供应站等燃气供应场站管理制度落实和隐患排查治理情况的检查，加强燃气管道施工现场的管理，落实燃气管道设施定期巡查、维护。要结合夏季高温特点，针对当前燃气爆燃事故多发的实际，立即组织开展全市餐饮场所和民用燃气使用拉网式安全大检查，强化常态化安全监管，及时消除事故隐患。坚决杜绝危及燃气管道安全的野蛮施工行为，加强对各类餐饮店、宾馆、门面房、出租房等场所使用瓶装燃气的检查管理。

（六）校园安全及防淹溺方面。要加强校园安全宣传教育，学校在组织或举办学生夏令营、旅游、游泳等户外活动时，事前必须对教师和学生进行防中暑、防中毒、防溺水、防雷击等事故的安全常识教育，落实安全措施，防止各类交通等意外事故的发生。各县（市、区）要组织对辖区内的天然河道、湖泊、水塘、景观休闲水域等易发生淹溺事故的场所进行检查，增设安全警示标识标牌。要督促各中小学校采取开展防溺水警示教育、发送提示短信等各种方式，加强对学生的暑期安全教育宣传和管理。

城管、旅游、工商、商务、民政等行业监管部门也要加强安全监管，深入排查治理事故隐患，全面落实安全生产措施，确保行业企业（场所）生产安全。

四、加强值班值守，着力提升应急处置水平

各地、各有关部门和单位要认真做好夏季安全生产应急值守工作，重点行业、部门要实行24小时值班和领导带班制度。要进一步完善应急预案，加强应急演练，做好应急组织机构、救援队伍、装备、物资等应急资源的落实。要密切关注高温、雷电、强风、暴雨等极端天气情况，根据有关部门发布的预警信息，提前督促指导有关单位做好高温、强风、强降雨等自然灾害可能引发各类生产安全事故的防范应对工作，做到早预警、早准备、早防范。要跟踪掌握安全生产动态，一旦发生事故，确保信息畅通、反应迅速、指挥有力、处置有效，将事故损失降到最低。
