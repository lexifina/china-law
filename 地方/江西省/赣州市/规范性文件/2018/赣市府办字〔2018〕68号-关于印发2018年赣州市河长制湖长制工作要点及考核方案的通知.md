# 关于印发2018年赣州市河长制湖长制工作要点及考核方案的通知

赣市府办字〔2018〕68号

赣州市人民政府办公厅关于印发

2018年赣州市河长制湖长制工作要点及

考核方案的通知

各县（市、区）人民政府，市政府各部门，市属、驻市各单位：

经市政府同意，现将《2018年赣州市河长制湖长制工作要点》《2018年赣州市河长制湖长制考核方案》印发给你们，请结合实际认真贯彻执行。

2018年5月26日

（此件主动公开）

2018年赣州市河长制湖长制工作要点

为全面贯彻落实《江西省全面推行河长制工作方案（修订）》《关于以流域生态综合治理为抓手打造河长制升级版的指导意见》，促进我市河长制湖长制取得实效，按照《赣州市全面推行河长制工作方案（修订）》确定的总体思路、工作任务及要求，现制定如下工作要点。

一、巩固成果，提升河长制工作实效

1. 完善“四个到位”。进一步健全河长制组织体系、责任体系、制度体系、监督检查和考核评估。进一步完善村级巡查员、专管员、保洁员设置。完善河长制公示牌设置。结合实际，完善“河长+警长”、生态检察室等组织体系。各级河长出现人员变动的，及时调整并向社会公布名单。〔牵头单位：市河长办，各县（市、区）政府〕

2. 强化督察督办。严格执行河长制工作督察制度、河长制工作督办制度，在分级、销号、滚动管理问题清单的基础上，加强督察督办，推动问题有效解决。对省级、市级河长巡河督导发现的问题实行一县（市、区）一单、跟踪督办，监督考核。〔牵头单位：市河长办；配合单位：市工信委、市城乡建设局、市农粮局、市水利局、市环保局、市林业局、市交通运输局、赣州港航分局、市委农工部，各县（市、区）政府〕

3. 总结推广综合执法。总结经验，鼓励各地进一步探索推进河湖和生态环境综合执法。〔牵头单位：市水利局、市政府法制办、市委编办、市公安局、市林业局；配合单位：市环保局、市国土资源局、市矿管局、市农粮局、市城乡建设局、市城管局、市交通运输局、赣州港航分局等，各县（市、区）政府〕

4. 推进河长制法制化、标准化建设。进一步规范河长制工作，从机构设置、人员配备、配套资金及基础工作等方面，规范和加强基层河长办能力建设。〔牵头单位：市河长办、市政府法制办；配合单位：市委编办、市财政局、市水利局，各县（市、区）政府〕

5. 全面推行自然资源资产离任审计。选择1个县（市、区）开展领导干部自然资源资产离任审计工作，各县（市、区）审计部门至少审计1个乡（镇）。〔牵头单位：市审计局，各县（市、区）政府〕

6. 落实“一河一策”。抓好“一河一策”的实施，“一河一策”方案需报经同级人民政府批准，将保护治理措施项目化、清单化。完善“一河一档”。〔牵头单位：市河长办；配合单位：市工信委、市城乡建设局、市农粮局、市水利局、市环保局、市林业局、市交通运输局、赣州港航分局、市委农工部，各县（市、区）政府〕

7. 加快推进河长制信息化建设。确保市、县两级河长制信息平台建设在今年9月底上线运行。〔牵头单位：市河长办；配合单位：市工信委、市城乡建设局、市农粮局、市水利局、市环保局、市林业局、市交通运输局、赣州港航分局、市委农工部，各县（市、区）政府〕

8. 深化河长制培训、宣传和教育。开展多种形式的河长制宣教活动，完善志愿者服务机制。结合实际设立民间河长、企业河长等。进一步增强领导干部的责任意识、社会公众的参与意识。强化中小学生的河湖保护及涉水安全意识。〔牵头单位：市委宣传部、市教育局、市河长办；配合单位：市工信委、市城乡建设局、市农粮局、市水利局、市环保局、市林业局、市交通运输局、赣州港航分局、市委农工部，各县（市、区）政府〕

二、对标中央、省要求，落实湖长制重点任务

9. 制订湖长制工作方案，落实任务分工。2018年6月底前，市级出台《关于在湖泊实施湖长制的工作方案》。各县（市、区）结合实际，细化目标任务，落实责任分工，明确进度安排，强化保障措施，将实施湖长制纳入全面推行河长制工作体系。7月底前出台县级《关于在湖泊实施湖长制的工作方案》。〔牵头单位：市河长办，各相关县（市、区）政府〕

10. 健全湖长制组织体系。逐个湖泊明确湖长，落实属地管理责任。已经设立河长的湖泊，按要求抓紧完善湖长体系，名称统一为湖长；尚未设立湖长的湖泊，尽快建立湖长体系。市、县（市、区）及时向社会公布湖长名单，规范湖长制公示牌设置。〔牵头单位：市河长办，各相关县（市、区）政府〕

11. 完善湖长制相关法规和制度建设。认真学习宣传和贯彻执行《江西省湖泊保护条例》。各级探索实施“一湖一法”，将湖长制工作纳入已出台的河长制相关制度执行，根据实际情况针对性地制定湖长制相关制度。〔牵头单位：市政府法制办、市水利局、市河长办；配合单位：各有关市级责任单位；各县（市、区）政府〕

12. 建立“一湖一档”，制定“一湖一策”。调查摸清全部湖泊（含常年水面面积1平方公里以下湖泊）的基本情况，编制湖泊名录，建立“一湖一档”，科学制定“一湖一策”方案，提出问题清单、目标清单、任务清单、措施清单和责任清单。〔牵头单位：市河长办；配合单位：各有关市级责任单位，各县（市、区）政府〕

三、水岸联动，切实落实“管治保”措施

13. 继续实施流域生态综合治理。继续推进流域生态综合治理工程建设，打造一批示范河流或河段。2018年，市、县两级加快推进2017年确定的试点流域综合治理项目，有条件的地方扩大实施范围。〔牵头单位：市水利局、市发改委；配合单位：各有关市级责任单位；各县（市、区）政府〕

14. 继续推进水质不达标河湖治理。进一步落实治理方案，加强跟踪督导，实行销号管理。加强各地水环境质量年度考核评价。〔牵头单位：市环保局；配合单位：市发改委、市工信委、市国土资源局、市矿管局、市交通运输局、赣州港航分局、市城乡建设局、市城管局、市农粮局、市水利局，各县（市、区）政府）〕

15. 继续推进劣V类水治理工作。2018年3月底前印发消灭劣V类水市级河长令、挂图作战工作计划及工作地图， 4月底前完成消灭劣V类水市级专项督察，5—7月通过省级考核验收。〔牵头单位：市河长办、市环保局；配合单位：市发改委、市工信委、市国土资源局、市矿管局、市交通运输局、赣州港航分局、市委农工部、市城乡建设局、市城管局、市农粮局、市水利局、赣州稀土公司、市科技局；各县（市、区）政府〕

16. 持续加强工矿企业及工业聚集区水污染防治。逐步完善工业聚集区污水集中处理设施（含管网）建设，完善在线监测。〔牵头单位：市工信委；配合单位：市发改委、市环保局、市科技局；各县（市、区）政府〕

17. 持续强化城镇生活污水治理。进一步加强城镇生活污水处理设施和配套管网建设，提升污水处理率；各县（市、区）生活污水处理厂产生的污泥基本实现无害化（资源化）处理处置。〔牵头单位：市城乡建设局；配合单位：市环保局、市发改委，各县（市、区）政府〕

18. 持续推动畜禽养殖污染控制。科学指导限养区和可养区内畜禽养殖场，配套建设粪污处理利用设施。加强监督管理，防止禁养区内已关闭或搬迁的畜禽养殖场复养。〔牵头单位：市农粮局；配合单位：市环保局，各县（市、区）政府〕

19. 持续推进农业化肥、农药减量化治理。继续推进农作物病虫专业化统防统治与绿色防控融合示范，推广生物农药和高效低残留化学农药安全科学使用技术，大力推广应用现代高效植保机械，实施农药经营许可和限用农药定点经营。大力推广测土配方施肥技术，大力恢复绿肥生产，推进水肥一体化技术应用。〔牵头单位：市农粮局；配合单位：市环保局，各县（市、区）政府〕

20. 持续加大农村生活垃圾及生活污水整治。完善城乡环卫一体化体制，大力推行城乡环卫“全域一体化”第三方治理。开展农村生活垃圾分类试点，开展农村生活污水治理。〔牵头单位：市委农工部、市城乡建设局、市城管局、市环保局，各县（市、区）政府〕

21. 持续加强船舶港口污染防治。推进港口船舶污染物接收、转运和处置设施建设，加强危险品船的进出港、作业审批和监管，加大船舶污染专项整治和执法检查力度，推进船舶结构调整，积极推进液化天然气（LNG）等清洁能源在水运行业中的应用，加强港口码头垃圾、废水及作业扬尘整治。〔牵头单位：市交通运输局、赣州港航分局；配合单位：市环保局、市水利局、市农粮局，各县（市、区）政府〕

2018年赣州市河长制湖长制考核方案

根据《赣州市河长制工作考核问责办法》和《2018年赣州市河长制湖长制工作要点》，经充分征求各县（市、区）以及河长制市级责任单位意见，制定本考核方案。

一、考核组织及时间安排

（一）考核组织

考核分自评与市级考核。各县（市、区）（含省直管县）按要求组织开展自评工作，在规定时间内上报自评结果，并做好市级考核的各项准备工作。市级考核按照职责分工，由市级责任单位分别负责。

（二）时间安排

1.2018年12月上旬前，县（市、区）完成自评工作，将自评报告报市河长办公室、市级有关责任单位。

2. 2018年12月底前，市河长办公室、市级有关责任单位对县（市、区）（含省直管县）自评结果进行复核，并完成市本级自评工作。各县（市、区）（含省直管县）考评材料，按照负责考核的市级责任单位的通知要求分别报送。

3. 2019年1月上旬前，市级责任单位完成年终考核工作，并将有关结果统一交市河长办公室。

4. 2019年1月底前，市河长办公室统计并汇总考核结果。

5. 2019年2月底前，公布考核结果，并报送市有关部门。

二、考核评分方法

市级考核满分105分，结合赣州水利和水土保持工作实际，市级考核增加了河流治理成效（3分）和加大对河流弃土、弃渣违法行为查处力度（2分）两个考核项目，比省级考核100分增加了5分。

具体考核评分细则和任务分工另行印发。

（一）各县（市、区）上报考核自评结果作为市级考核评分的依据和参考。

（二）最终得分为市级对县（市、区）的考评分。

（三）考核中所列部门为负责考核部门，考核指标中有多个部门共同负责的，第一位的为牵头单位。各市级责任单位在年终考核前要认真开展好对县（市、区）（含省直管县）自评结果复核工作，并积极与省直对口部门对接，确保全市河长制工作年终考核顺利完成。

三、考核结果运用

（一）考核等次分为优秀、合格、不合格三类，按得分高低进行排序。考核得分按百分制，得分90分及以上的评定为优秀，60分至89分评定为合格，60分以下评定为不合格。

取得优秀等次的县（市、区）可获得2至4名优秀河长推荐权。

（二）考核结果纳入县（市、区）科学发展综合考核评价体系。

（三）考核结果纳入生态补偿机制。
