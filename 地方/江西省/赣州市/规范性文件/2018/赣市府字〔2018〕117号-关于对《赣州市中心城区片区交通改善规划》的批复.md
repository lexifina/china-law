# 关于对《赣州市中心城区片区交通改善规划》的批复

赣市府字〔2018〕117号

赣州市人民政府

关于对《赣州市中心城区片区

交通改善规划》的批复

市城乡规划局：

报来《关于呈报审批赣州市中心城区片区交通改善规划>的请示》（赣市规文〔2018〕47号）收悉。经研究，原则同意《赣州市中心城区片区交通改善规划》（以下简称《规划》）。

改善中心城区交通状况是建设省域副中心的重要基础保障，也是提升市民获得感的重要民生实事。市城乡规划局、市城乡建设局、市城市管理局、市交通运输局、市公安局交警支队、章贡区人民政府、南康区人民政府、赣县区人民政府、赣州经济技术开发区管委会、赣州蓉江新区管委会等相关部门和单位要结合实际，认真抓好《规划》的组织实施，要扎实推进《规划》相关项目的实施，市城乡规划局要加强对《规划》实施的指导监督和检查工作。各有关部门和单位要通力合作，齐心协力维护好中心城区交通秩序。

附件：《赣州市中心城区片区交通改善规划》

2018年9月14日
