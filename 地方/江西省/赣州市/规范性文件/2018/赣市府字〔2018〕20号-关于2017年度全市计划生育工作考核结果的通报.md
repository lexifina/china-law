# 关于2017年度全市计划生育工作考核结果的通报

赣市府字〔2018〕20号

赣州市人民政府

关于2017年度全市计划生育工作

考核结果的通报

各县（市、区）人民政府，市政府各部门，市属、驻市各单位：

2017年，在市委、市政府的正确领导下，全市各地坚持计划生育基本国策不动摇，深入实施全面两孩政策，扎实推进计划生育服务管理改革，确保了年度目标任务的圆满完成，有效促进了全市人口均衡发展。为鼓励先进、推动工作，经综合考核评估，市政府决定，将2017年度全市计划生育工作考核结果通报如下：

一、综合先进县（市、区）（8个）

（一）一等奖(1个)

崇义县

（二）二等奖(3个)

寻乌县、石城县、上犹县

（三）三等奖(4个)

兴国县、大余县、瑞金市、龙南县

二、创新奖县（市、区）（4个）

宁都县、安远县、章贡区、赣县区

三、综合先进乡（镇、街道）（50个）

（一）一等奖（10个）

赣州经开区湖边镇、上犹县寺下镇、南康区镜坝镇、大余县左拨镇、安远县孔田镇、寻乌县丹溪乡、于都县罗江乡、瑞金市壬田镇、会昌县白鹅乡、石城县琴江镇

（二）二等奖（15个）

章贡区赣江街道办事处、赣县区阳埠乡、崇义县横水镇、大余县黄龙镇、信丰县铁石口镇、龙南县汶龙镇、全南县社迳乡、定南县鹅公镇、寻乌县南桥镇、于都县黄麟乡、兴国县高兴镇、瑞金市泽覃乡、会昌县麻州镇、石城县小松镇、宁都县固村镇

（三）三等奖（25个）

章贡区东外街道办事处、赣县区五云镇、赣县区梅林镇、上犹县黄埠镇、上犹县油石乡、崇义县聂都乡、南康区龙回乡、南康区赤土乡、大余县樟斗镇、信丰县西牛镇、信丰县小江镇、龙南县渡江镇、龙南县黄沙管委会、全南县城厢镇、定南县龙塘镇、安远县高云山乡、安远县鹤仔镇、于都县贡江镇、兴国县长冈乡、兴国县埠头乡、瑞金市沙洲坝镇、会昌县站塘乡、石城县丰山乡、宁都县洛口镇、宁都县大沽乡
