# 关于2017年度县（区）政府食品安全工作评议考核情况的通报

赣市府字〔2018〕32号

赣州市人民政府

关于2017年度县（区）政府食品安全工作

评议考核情况的通报

各县（市、区）人民政府，市政府有关部门，市属、驻市有关单位：

2017年，全市各地各有关部门按照“实施食品安全战略，让人民吃得放心”总体要求，以创建国家食品安全示范城市为总抓手，着力补短板、建机制、抓长效，严防、严管、严控食品安全风险，食品安全形势持续稳中向好，全市未发生较大或较大以上食品安全事故、未发生区域性和系统性食品安全风险，有效保障了人民群众生命健康安全，为打好攻坚战、同步奔小康营造了良好的食品安全环境。

根据《赣州市食品安全工作评议考核办法》要求，市食安办会同市食安委相关成员单位，对各县（市、区）政府、赣州经济技术开发区和蓉江新区管委会2017年食品安全工作进行了评议考核。经市食安委审定，考核综合得分排名前7位的赣州经济技术开发区、大余县、于都县、章贡区、寻乌县、安远县、上犹县，考核结果为优秀等级；宁都县、全南县、龙南县、定南县、信丰县、赣县区、石城县、崇义县、南康区、蓉江新区、兴国县、会昌县，考核结果为合格等级。瑞金市考核结果已上报省食安办，由省里审定通报。

食品安全是全面建成小康社会的重要标志。希望考核结果为优秀等级的县（区）再接再厉，继续加大食品安全工作力度，着力提高监管效能，为全市发挥示范作用。各地各有关部门要把保障食品安全作为重大政治任务来抓，认真实施食品安全战略，强力推进国家食品安全示范城市创建工作，切实提高食品安全监管水平和能力，坚持最严谨的标准、最严格的监管、最严厉的处罚、最严肃的问责，守护人民群众“舌尖上的安全”。

2018年3月26日
