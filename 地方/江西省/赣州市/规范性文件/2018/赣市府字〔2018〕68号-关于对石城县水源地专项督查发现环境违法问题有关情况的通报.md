# 关于对石城县水源地专项督查发现环境违法问题有关情况的通报

赣市府字〔2018〕68号

赣州市人民政府

关于对石城县水源地专项督查发现环境

违法问题有关情况的通报

各县（市、区）人民政府，市政府各部门，市属、驻市各单位：

5月31日，生态环境部在官方网站公布了集中式饮用水水源地环境保护专项第一轮督查（简称“水源地专项督查”）第五批环境违法问题，并指出我市石城县自来水厂取水口（琴江）水源地一级保护区存在“两侧约有2000米水利部门建设的排水渠，用于两侧农田灌溉，一条引流河水，一条混有生活污水，灌溉农田后经出水口排入一级保护区内”的问题。

饮用水水源保护是重大民生问题，与老百姓生活息息相关。市委、市政府高度重视饮用水水源保护工作，多次进行强调部署，但还有个别地方重视不够，工作落实不力。特别是石城县水源地一级保护区环境违法问题被生态环境部曝光，充分暴露出石城县主要领导对饮用水水源保护工作重视不够、督查不严；分管领导责任意识不强，工作落实不力，作风漂浮。经市政府研究，决定对石城县水源地专项督查发现环境违法问题予以通报批评，责成石城县人民政府向赣州市人民政府作出深刻的书面检查。

开展集中式饮用水水源地环境保护专项行动，是贯彻落实党的十九大关于坚决打好污染防治攻坚战的具体举措，是加快解决饮用水水源地突出环境问题的重要抓手。各地各部门要切实提高站位，增强“四个意识”，始终坚持以人民为中心的发展思想，扎实做好饮用水水源地环境保护工作；要坚决抓好整改，特别是石城县要立行立改，在最短的时间内将曝光问题整改到位，其他县（市、区）要坚持问题导向，举一反三，全面开展自查整改，确保不出问题；要压紧压实责任，环保部门要发挥牵头抓总、综合协调、调度指导作用，各县（市、区）政府要履行主体责任，各有关部门要履职尽责、密切配合，加大环境违法行为查处力度，建立健全饮用水水源地环境保护长效机制，确保全市饮用水水源地环境安全，让老百姓喝上放心干净的饮用水。

2018年6月4日
