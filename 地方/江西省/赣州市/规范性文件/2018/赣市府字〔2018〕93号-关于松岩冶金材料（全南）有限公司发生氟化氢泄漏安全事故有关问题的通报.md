# 关于松岩冶金材料（全南）有限公司发生氟化氢泄漏安全事故有关问题的通报

赣市府字〔2018〕93号

赣州市人民政府关于

松岩冶金材料（全南）有限公司发生氟化氢

泄漏安全事故有关问题的通报

各县（市、区）人民政府，市政府各部门，市属、驻市各单位：

2018年5月15日10时38分，松岩冶金材料（全南）有限公司（以下简称“松岩公司”）在检修氟化氢储罐液位计时，因操作不当引起少量氟化氢泄漏，造成1人受伤。这起事故发生在省安委会在我市开展安全生产巡查期间，且全市正在开展危险化学品安全综合治理和安全专项整治行动，造成极为不利影响。

为帮助企业认真查找事故中存在的问题，深刻吸取教训，5月22日，市安委办向松岩公司下达《关于对松岩冶金材料（全南）有限公司进行安全生产约谈的通知》（赣市安办字〔2018〕31号），决定对松岩公司董事长、总经理等进行安全生产约谈。

5月28日，市安委办组织召开约谈会，松岩公司董事长、总经理没有按照通知要求到会,也未到市安委办说明情况，仅派常务副总经理、安全环保部负责人和安全顾问参会。

5月29日，市安委办根据约谈内容，下发会议纪要，指出了松岩公司“5·15”事故暴露的五个安全生产问题，同时提出了五个方面的整改要求。

7月2日至3日，市安委办组织人员及专家深入现场，对松岩公司整改落实情况进行实地核查，发现该公司仍存在以下安全生产问题，构成重大生产安全事故隐患：一是未经批准，擅自恢复生产。二是擅自改变安全设施设计。松岩公司在现有的氟盐生产厂区范围内，未经变更设计审查,擅自建设采用四氟铝酸钾为原料生产电子级无水氟化氢的新工艺试验基地。三是对约谈会议纪要指出的五个安全生产问题不仅没有整改落实到位，同时还存在其他七个安全生产问题。

7月3日，全南县安监局下达了现场处理决定书（〈全〉安监现决〔2018〕1号）责令松岩公司停产整改。7月5日，市安委办向全南县政府下达了《重大生产安全事故隐患挂牌督办通知书》，要求全南县政府督促企业切实加强整改落实，未经市安监局组织核查合格，不得恢复生产。目前，该企业已停产整顿。

松岩公司“5·15”事故发生后，思想认识不到位，安全主体责任不落实，重生产轻安全，对安全隐患排查治理不彻底，“扫雷”行动流于形式，安全风险管控不到位，对重大危险源管理不严，对安全隐患整改的措施不扎实。同时也暴露出全南县政府对企业安全生产工作要求不严，督促企业加强安全隐患整改的态度不坚决、措施不得力。经市政府研究决定，给予全南县政府通报批评。

全市各地各部门要认真学习领会习近平总书记关于安全生产重要思想，树牢安全发展理念，既要发展、更要安全，以更大的决心、更强的力度、更硬的措施，从根本上彻底消除安全隐患，防范遏制安全事故的发生。

一要认真吸取教训、举一反三，进一步增强安全责任意识，进一步严格落实党政领导责任、部门监管责任、企业主体责任，扎实做好安全生产各项工作，切实做到对人民群众负责。

二要认真组织开展好安全生产十大专项整治行动，抓好隐患排查整治，常抓常管、常态长效，从严从实推进安全生产工作。要针对当前高温、汛期特点，狠抓危险化学品、矿山、道路与水上交通、消防、防汛减灾等重点行业领域的隐患排查整治，加强各类易燃易爆品生产、流通、储存等环节的监管，建好台账、健全机制，挂牌督导、对账销号，坚决防范遏制各类安全事故的发生，切实做到守土有责、守土尽责、守土负责，确保人民群众生命财产安全。

三要严格落实高温、汛期值班制度和领导带班等有关制度，严格执行高温、汛期24小时应急值守制度，一旦发生重大险情或安全生产事故，要及时组织抢险，做到快速响应、科学施救，并按有关规定立即上报，严禁迟报、漏报和瞒报。对于玩忽职守、疏于管理、责任不落实、措施不到位和抢险不及时、不科学造成事故的，对相关责任人和责任单位，要严肃追究责任。

2018年7月18日
