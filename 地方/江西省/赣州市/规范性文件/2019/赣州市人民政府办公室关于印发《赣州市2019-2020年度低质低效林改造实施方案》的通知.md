# 赣州市人民政府办公室关于印发《赣州市2019-2020年度低质低效林改造实施方案》的通知

各县（市、区）人民政府，市政府有关部门，市属、驻市有关单位：

经市政府同意，现将《赣州市2019-2020年度低质低效林改造实施方案》印发给你们，请结合实际抓好贯彻落实。

2019年11月8日

赣州市2019-2020年度低质低效林改造实施方案

为贯彻落实市委、市政府10年改造1000万亩低质低效林决策部署，高质量推进生态文明建设，根据全市低质低效林改造（以下简称“低改”）规划，结合《江西省人民政府关于在重点区域开展森林美化彩化珍贵化建设的意见》，现就2019-2020年度低改工作制定如下实施方案。

一、总体要求

以习近平生态文明思想为指导，深入贯彻落实习近平总书记视察江西和赣州时的重要讲话精神，围绕持续精准提升森林质量和效益，坚持政府主导、社会参与，因地制宜、分类施策，造管结合、科学改造，突出重点、循序渐进原则，紧扣重点区域森林质量提升和生态宜居乡村绿化美化建设，全面推进低质低效林改造，为筑牢我国南方地区重要生态屏障，建设革命老区高质量发展示范区奠定良好的生态基础。

二、目标任务和改造重点

（一）目标任务。2019-2020年度，全市计划完成低改任务110万亩（含重点区域建设任务2.45万亩，高铁沿线低改任务4.28万亩），其中：更替改造11.63万亩、补植改造24.87万亩、抚育改造29.55万亩、封育改造43.95万亩（见附件1）。通过实施改造，逐步优化树种结构，提升林分质量，增强森林对火灾和病虫害的抵抗能力，达到改善森林景观，提高森林生态效益、社会效益和经济效益目标。

（二）改造重点。2019-2020年度低质低效林改造的重点是境内昌赣、赣深等高铁沿线低质低效林和疏林地、火烧迹地、废弃矿山等生态脆弱、亟需恢复区域，其低效林地全部纳入今冬明春低改范围，做到应改尽改（见附件3）。同时，进一步巩固厦蓉、赣兴、大广、宁定、泉南等高速公路和京九、赣韶铁路沿线的低改效果，持续做好饮用水源地，城镇、村庄和重点景区周边低改工作。

三、工作步骤和时间安排

（一）调查摸底和制定方案（2019年5-8月）。按照年度改造任务，组织各地开展调查摸底，重点摸清高铁沿线拟改造的低质低效林基本情况，并结合《江西省赣州市低质低效林改造规划》，落实分解各县（市、区）今冬明春低改任务。各地结合实际制定年度实施方案，把改造任务落实到山头地块。

（二）编制作业设计（2019年9-10月）。各县（市、区）根据本地实施方案，以小班为单位编制改造技术作业设计，确定改造方式、栽植树种、苗木规格和数量、主要技术措施和投资预算。

（三）动员部署和组织实施（2019年11月-2020年9月）。召开低改工作会议，总结上年度低改工作，对2019-2020年度低改工作进行全面动员部署。各地根据本地低改年度实施方案及作业设计，落实配套项目资金，履行好相关程序，选好施工队伍，落实质量保障措施，按工作进度要求抓实抓好整地造林等各阶段改造工作。

（四）检查验收和绩效评估（2020年10-11月）。各阶段任务完成后，各地对照年度低改考评方案开展项目自查验收，对本地低改工作进行全面自评，并上报自查验收成果资料至市低改办。市低改办根据县级自查验收成果，委托第三方中介机构或组织专业技术人员进行核查，开展量化考评和绩效评估，考评结果报市政府。

四、工作措施

（一）分类实施改造。将松材线虫病灾害林和火烧迹地全部纳入改造范围。对疫情发生严重的马尾松林，优先进行块状更替改造；对疫情较轻的，在清除疫木的同时进行补植改造或抚育改造。对遭受其他病虫害的林分和受冻害的桉树林尽快更替改造；对土壤瘠薄林木生长不良、林下植被稀少的林地，特别是生态功能弱的马尾松低效林实施补植改造。对密度过大、林木分化严重、生长量明显下降的林地实施抚育改造。对郁闭度小于0.5的低质低效林或有望培育成乔木的灌木林地，且立地条件及天然更新条件较好、通过封山育林可以达到较好改造效果的实施封育改造。

（二）提高造林质量。合理选择整地方式，开挖标准穴坑并回填表土，禁止全垦整地破坏已有植被。针对不同生态区域土壤条件，采取科学施肥技术。严格按照工程项目建设规定，推行针叶与阔叶树种混交，逐步增加阔叶树比例。要以本地阔叶树种为主，提高良种壮苗使用率，优先使用本地保障性苗圃繁育的乡土阔叶树种，严格引种管理，减少长距离调运种苗，禁止大规模引种造林。

（三）鼓励群众参与。注重低改生态效益与经济效益相结合，在生态优先的前提下，充分考虑林农的经济利益，鼓励群众积极参与。支持林农按个人意愿种植南酸枣、杨梅、板栗等具有较高生态价值，又有较好经济效益的树种，或种植樟、楠、栎、栲、青冈、锥等珍贵树种，充分调动群众在承包林地上实施低改的积极性和主动性，在保护与改善生态的同时，促进农民增收。

（四）加强基地建设。各地要在高铁、铁路、高速公路等主要通道沿线集中精力高标准打造低改重点路段，着力提升生态效果。各县（市、区）政府主要领导和分管领导分别建设一个面积不少于300亩的低改基地，各县（市、区）林业部门主要领导、乡（镇）主要领导分别建设一个面积不少于200亩的低改基地（见附件2）。低改基地的改造方式为补植改造或更替改造，并按照省森林“四化”建设要求，提高整地、垦穴、苗木和施肥标准。

（五）注重造管结合。加强对低改新造林和幼林抚育管护工作，建立管护机制，落实管护主体，实行“造管一体”。低改新造林要做到连续抚育三年，科学选择除草松土、扩穴培蔸、施肥修枝等技术措施，确保新栽树木的成活率。要充分发挥生态护林员作用，整合护林员队伍，加大对低改小班的巡山管护力度，严防人畜破坏、森林火灾的发生，巩固改造成果。加大高速公路、高铁等主要通道沿线乱砍滥伐等违法犯罪行为查处力度，加强森林防火和林业有害生物监测防治，确保森林资源安全。

（六）创新经营机制。积极鼓励引导社会主体参与低改工作，在依法自愿有偿的基础上,支持各类主体采取承包、租赁、入股、合作等形式流转集体林地实施低改。将低改与脱贫攻坚相结合，用好扶贫和低改项目资金，优先安排贫困村、贫困户林地改造，支持鼓励具有出资、筹资能力，能够组织承担造林绿化项目的企业、林业大户和集体经济组织等建立扶贫造林合作社参与低改项目建设。对吸纳建档立卡贫困人口参与造林整地和抚育管护等工作达到50%以上的合作社，同等条件下优先安排工程任务。支持国有林场依托技术优势，组建以林业职工为主的营林专业队伍，依法依规流转周边集体林地实施低改和场外造林。鼓励有条件的地方对主要通道沿线、县城周边、饮用水源地等重要生态区域开展政府赎买或置换，在赎买的林地统一实施低改。

五、有关要求

（一）强化领导责任。各地各部门要切实提高政治站位，始终站在生态文明建设的高度切实抓好低改，各级党政主要领导要亲自部署、精心组织、实地督导，从政策制定、工作部署、资金保障等各个环节抓好落实。县、乡政府主要负责同志为第一责任人，切实担负起低改的主体责任，细化项目任务，强化组织实施，做好群众工作，解决低改用地，确保年度低改工作有序推进。市低改领导小组成员单位要结合部门职能,履行好工作职责，形成分工合作、协调联动的生态修复合力。财政部门负责统筹资金，加大对低改的支持；交通运输部门和铁路部门分别负责高速公路隔离栅栏内、高铁、铁路地界内的绿化提升工作，并为高铁、铁路、高速公路沿线两侧的低改提供施工便利；林业、果业、自然资源等部门要加强对油茶、果业、矿产资源开发的监管，落实生态开发措施；水保部门要加强主要通道沿线水土保持工作。

（二）强化资金保障。充分发挥政府主导作用，加大财政资金投入力度，市本级财政统筹安排1亿元资金用于低改。各地要加大资金投入，统筹生态建设项目资金、财政涉林扶贫项目资金用于低改，并按照每亩改造任务不低于200元的标准落实县级配套资金。纳入国家重点防护林、省级低改等涉及生态建设项目的，不得整合项目资金用于其他工作。建立多元化的低改资金投入机制，积极争取国家重点防护林建设、森林抚育补贴、省级低改等项目资金，鼓励、引导和吸引社会资金投入低改建设。

（三）强化绩效管理。将低改工作纳入高质量发展考评的重要内容，从作业设计、苗木质量、施工质量、任务完成及基地建设等方面开展绩效评价。结合年度任务，对低改工作实施分类考评，并重点考评高铁沿线低改实施成效。考评得分靠前的县（市、区），由市政府评为全市低改工作先进单位，予以通报表彰。将2018-2019年度检查验收不合格面积任务纳入本年度整改考核内容（见附件4），要采取有力措施及时抓好整改工作。对各地前三年低改新造林开展“回头看”，进一步总结经验教训，抓好整改落实。同时，在重点时间和关键节点，采取以暗访为主的真督实查，不发通知、不打招呼、不听汇报、直奔山头地块，坚持重实绩、轻痕迹，简化工作程序，减少材料和报表数量，确保年度低改工作取得实效。
