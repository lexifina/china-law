# 关于印发赣州市中心城区2019年国有建设用地供应计划的通知

赣市府办字〔2019〕28号

赣州市人民政府办公室关于印发

赣州市中心城区2019年国有建设用地

供应计划的通知

章贡区、南康区、赣县区人民政府，赣州经济技术开发区、赣州蓉江新区管委会，市政府各部门，市属、驻市各单位：

经市政府研究同意，现将《赣州市中心城区2019年国有建设用地供应计划》印发给你们，请认真遵照执行。

2019年4月12日

（此件主动公开）

赣州市中心城区2019年国有建设用地供应计划

为深入贯彻党的十九大、十九届二中、三中全会和习近平新时代中国特色社会主义思想，统一行使所有国土空间用途管制职责，充分保障中心城区经济社会持续稳步健康发展用地需求，依据原国土资源部《关于印发国有建设用地供应计划编制规范（试行）的通知》（国土资字〔2010〕117号），结合中心城区实际，制定本计划。

一、计划指标

（一）供应总量。中心城区2019年国有建设用地计划供应总量控制在46440.33亩以内，其中利用新增建设用地控制在39817.33亩以内，利用存量建设用地6623亩。

（二）供应结构。供应总量按用途分：商服用地2380.25亩，住宅用地12637.5亩（含保障性住房用地3044.44亩），工矿仓储用地15861.03亩，公共管理与公共服务用地6699.52亩，交通运输用地7419.51亩，其他类用地1442.53亩。

二、政策导向

（一）坚持主攻工业不动摇，高质量保障“六大攻坚战”用地需求。根据市委、市政府“主攻工业、三年再翻番”的工作目标，坚定不移打好“主攻工业”攻坚战，全力保障“两城两谷一带”重大工业项目用地需求，加大标准厂房土地供应力度，补齐园区基础设施短板，引导具有较大影响力、较强综合实力的企业落户中心城区重大产业平台，为产业发展提供坚实保障；加快促进现代服务业发展，加大文化旅游、特色产业用地供应力度；加大基础设施建设用地保障力度，重点保障学校、公园绿地、医疗卫生、城市道路等民生项目用地需求，强化发展支撑。

（二）统筹区域用地布局，纵深推进省域副中心城市建设。根据市委、市政府加快推进中心城区五区联动一体化发展要求，推动章贡区、赣州经开区、蓉江新区、南康区、赣县区“五大功能区”之间差异化和互补发展，高标准规划建设蓉江新区、高铁新区、三江六岸旅游区、赣州国际陆港，统筹规划布局重大项目建设，加快推进区域性城市道路、供水、供电、排污、垃圾处理等基础设施建设，实现互联互通和共建共享。

（三）强化房地产市场调控，进一步加大住宅用地供应。不折不扣按照党中央“房住不炒”定位，加强中心城区房地产调控力度，合理组织中心城区各区域住宅用地供应的结构和时序，实现“稳地价、稳房价、稳预期”成效，有效防控房地产领域风险，加快新型城镇化良性发展。

（四）促进土地资源节约集约利用。大力推进土地利用计划“增存挂钩”，严格控制建设用地总量，统筹利用存量和新增建设用地；加快推进“亩均论英雄”、“标准地+承诺制”改革试点工作，促进土地等资源要素向优强企业集聚；严把工业项目用地准入，加大多层标准厂房项目用地供应量；不断深化土地出让制度改革，鼓励工业、旅游及公共服务等项目用地采取长期租赁、先租后让、租让结合方式供应。

（五）严格土地供应程序。依据《赣州市人民政府办公室关于印发推进市中心城区五区一体化实施方案的通知》（赣市府办发〔2019〕1号），南康区项目用地储备和土地供应纳入市级统筹，由市政府统一审批；赣县区在过渡期内,国土资源管理按照《关于调整赣县区管理体制的意见》（赣市发〔2016〕24号）文件执行，年度土地储备和土地供应计划纳入中心城区管理。

三、保障措施

（一）加强组织领导，落实工作责任。健全完善由市政府主导，市自然资源局牵头，相关职能部门和各区政府共同参与的土地供应工作机制，协同做好项目审批、规划设计、供地方案编制等各项土地供应前期准备工作，抓紧组织实施土地征收和补偿安置，加快征地拆迁、清场腾地、清算交地进程和融资抵押宗地的抵押注销工作。土地供应计划一经公布，所涉单位、部门必须采取切实有效措施保障计划的顺利实施。

（二）健全工作机制，加强计划执行。建立土地供应计划执行情况动态跟踪管理制度，定期与相关职能部门沟通协调，及时解决计划实施中存在的问题，切实提高土地储备和供应的效率和质量。确需要调整计划地块的，依据计划执行和土地供需情况，在充分征求意见的基础上，在总量控制范围内做好计划调剂工作。

（三）把握实施节奏，稳定市场预期。在计划实施过程中，要突出重点、强化服务、保障需求，对年度重大项目用地、保障性住房用地、民生项目用地等提前介入；合理分析市场需求，科学研判市场形势，统筹安排商品住房项目供应时序，合理掌握供应节奏；确保土地市场健康平稳运行，为奋力推进高质量跨越式发展提供有力的土地要素保障。
