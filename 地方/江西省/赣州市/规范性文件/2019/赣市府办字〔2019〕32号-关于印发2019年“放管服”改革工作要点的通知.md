# 关于印发2019年“放管服”改革工作要点的通知

赣市府办字〔2019〕32号

赣州市人民政府办公室关于印发

2019年“放管服”改革工作要点的通知

各县（市、区）人民政府，市政府各部门，市属、驻市有关单位：

经市政府同意，现将《2019年“放管服”改革工作要点》印发给你们，请结合实际抓好贯彻落实。

2019年4月28日

（此件主动公开）

2019年“放管服”改革工作要点

为认真贯彻落实党中央、国务院有关“放管服”改革决策部署，进一步深化重点领域和关键环节改革攻坚，深入推进“五型”政府建设，努力营造“四最”发展环境，结合工作实际，制定本工作要点。

一、推进政务服务网上办理

1.加快一体化在线政务服务平台建设。按照上级部署，统筹推进市县乡村四级政务服务网上平台建设，努力提升网上办事比例。2019年底前，市县两级政务服务事项网上可办率不低于80%。〔牵头部门：市行政审批局，市大数据发展管理局，各县（市、区）人民政府；完成时限：2019年底前〕

2.推进系统整合和数据共享。2019年6月底前，打通与“放管服”改革相适应的已建业务系统，推进政务数据交换共享，全面完成“四库一平台”建设，涉及企业和群众网上办事的政务数据归集率达100%。〔牵头部门：市大数据发展管理局，市行政审批局，各县（市、区）人民政府；完成时限：2019年6月底前〕

3.推进“赣州通”平台建设。2019年5月底，完成“赣服通”分厅——“赣州通”建设并正式上线，第一批实现50个以上本地事项“掌上办理”；2019年12月底前，各县（区、市）完成“赣服通”分厅建设，第一批实现20个以上本地事项“掌上办理”；市县两级高频事项掌上可办率分别达到50%和70%。〔牵头部门：市大数据发展管理局，市行政审批局，各县（市、区）人民政府；完成时限：2019年12月底前〕

4.推进“一证通办”“全城通办”。2019年6月底前实现一张身份证或统一社会信用代码通办大部分政务事项。2019年8月底前梳理公布第一批“全城通办”事项清单，清单内事项可实现跨区办理。〔牵头部门：市行政审批局，市大数据发展管理局等相关单位，各县（市、区）人民政府；完成时限：2019年12月底前〕

5.完善社会保障“一卡通”。根据省里统一部署，推动养老保险、医疗保险等跨地区联网办理。2019年实现养老保险关系转移接续业务网上办理和顺畅衔接。〔牵头部门：市人社局、市医保局，各县（市、区）人民政府；完成时限：2019年12月底前〕

6.建设12345政府服务热线平台。2019年8月底前热线正式运营，强化运行管理和转办督办机制，年底前热线系统接通率、一次办结率、群众评价满意率等指标数据达98%以上。结合延时错时预约服务，实现预约办事只需拨打“12345”号码或登录“12345”网络平台。〔牵头部门：市行政审批局；完成时限：2019年8月底前〕

二、推进政务服务重点改革

7.全面推广“一窗受理”服务改革。完善各级综合性政务大厅集中服务模式。2019年底前，县级政务服务大厅“一窗”受理率达到90%以上。乡镇（街道）直接面向群众办理的社保、医保、民政、计生、农民建房审批等事项要全部进驻便民服务中心，并尽可能采取“前台综合受理、后台分类审批、综合窗口出件”模式。有条件的乡镇（街道），除班子成员外，其余人员全部进驻便民服务中心办公。〔牵头部门：市行政审批局，各县（市、区）人民政府；完成时限：2019年12月底前〕实现权责清单同“三定”规定有机衔接。同步梳理各部门依申请事项清单，审批事项应减尽减。〔牵头部门：市行政审批局，市直各相关单位，各县（市、区）人民政府；完成时限：2019年12月底前〕

8.开展“一链办理”改革。全面梳理优化办事全流程，编制“一链办理”事项目录清单和办事指南，变过去企业和群众到不同部门“办几件事”为全链条办理“一件事”。2019年底前，市县两级分别要实现5项、10项以上多部门 “一链办理”事项。〔牵头部门：市行政审批局等相关单位，各县（市、区）人民政府；完成时限：2019年12月底前〕

9.扩大“最多一次办结”改革。着力推进网上办、邮寄办，鼓励各地为企业群众提供免费邮寄服务，将更多事项纳入“最多一次办结”清单。除有明确特殊要求的外，凡是法律法规没有规定必须到现场办理的事项一律要做到企业和群众办事可以“一次不跑”，凡法律法规明确要求必须到现场办理的事项要想方设法做到“只跑一次”。市县两级“最多跑一次”事项占比提高到90%以上，“一次不用跑”“就近办”事项提高到50%以上。对已公布的“一次不跑”“只跑一次”事项要真正兑现承诺并实现高质量办理。〔牵头部门：市行政审批局等相关单位，各县（市、区）人民政府；完成时限：2019年12月底前〕

10.推行“六多合一”改革。创新“六多合一”集成审批模式（多证合一、多规合一、多介合一、多评合一、多审合一、多测合一），实施“四个联合”改革（联合图审、联合测绘、联合踏勘、联合竣工验收），政府投资项目、企业投资项目的审批时间再压减20%以上。〔牵头部门：市住建局、市自然资源局、市行政审批局及相关行业部门，各县（市、区）人民政府；完成时限：2019年12月底前〕

11.推行“区域评估”改革。省级以上经开区、高新区等重点区域新批工业用地按照“区域评估”制度供地比例不得少于35%，切实压缩工业投资项目审批时间20%以上。〔牵头部门：市发改委、市自然资源局、市生态环境局、市工信局、市水利局、市住房和城乡建设局、市科技局、市税务局、市市场监管局、市气象局；完成时限：2019年12月底前〕

12.探索“标准地+承诺制”改革。建设用地带着建设规划、能耗、环境、投资强度等一系列标准进行出让，企业拿地后通过“一窗受理”，一次提交材料即可开工，建成投产后按照法定条件和既定标准进行验收。2019年年底前，35%以上的新增工业用地实现标准地供应。〔牵头部门：市发改委、市自然资源局，各县（市、区）人民政府；完成时限：2019年6月底前〕

13.全面推开“证照分离”改革。对所有涉企经营许可事项实行“证照分离”改革，让企业更便捷拿到营业执照并正常运营，切实解决“准入不准营”的问题。2019年底前制定全覆盖全流程的事项清单，清单之外事项一律不得作为限制企业经营的依据。按照直接取消审批、审批改为备案、实行告知承诺、优化准入服务等四种方式逐一制定具体管理措施，让企业和群众明明白白办事。〔牵头部门：市市场监管局，各县（市、区）人民政府；完成时限：2019年12月底前〕

三、着力提升政务服务水平

14.加大“三集中三到位”力度。根据机构改革后部门“三定”规定调整，全面梳理完善部门权责清单。2019年年底前，除对场地有特殊要求的事项外，依申请类事项“应进必进”各级政务服务中心，实现一门办理。推行一站式办理水电气过户联办业务，不断提升有线电视、通信、公积金、银行、公交、医院、学校等民生领域服务水平。〔牵头部门：市行政审批局，各县（市、区）人民政府；完成时限：2019年12月底前〕

15.强化对企业的服务。优化企业开办服务。在市本级开展企业开办全程网上办“零见面”改革试点，在县（市、区）推行企业开办“一窗办”集成服务，实现常态化企业开办时间压缩至2个工作日内完成。实行企业名称自主申报。在蓉江新区和各经开区、高新区、开发区实行商事登记住所托管制度。推行企业投资项目“保姆制”代办服务。在市、县两级设立企业投资审批代办中心，对重点产业项目实行“一对一”全程跟踪服务。〔牵头部门：市市场监管局、市行政审批局、市发改委，各县（市、区）人民政府；完成时限：2019年12月底前〕

16.优化完善错时延时服务。以办成事为原则，从接件、办件到出件，全链条开展错时延时服务，加大错时延时服务的人力、物力的保障力度，将更多与群众生产生活密切相关的事项纳入错时延时服务。〔牵头部门：市行政审批局等相关单位，各县（市、区）人民政府；完成时限：2019年12月底前〕

17.完善基层综合便民服务平台功能。制定出台规范乡村两级便民服务中心和村（居）代办点建设标准文件，明确乡镇、村便民服务中心（站）的名称、场所、标识、进驻部门、办理事项、运行模式，推动更多事情就近办。〔牵头部门：市行政审批局，各县（市、区）人民政府；完成时限：2019年12月底前〕

18.积极推行自助服务。2019年底前，各地政务服务大厅要设置自助服务专区，并积极推行在商场、银行、车站和村（居）委会等场所设置自助设备，方便企业群众就近办事。同时开发和采购一批网上办事自助设备向基层延伸。〔牵头部门：市行政审批局，市大数据发展管理局，各县（市、区）人民政府；完成时限：2019年12月底前〕

19.提升规范中介服务。按照必需、简便的原则，对中介服务事项进行全面清理，取消调整一批中介服务事项，防止行政审批对中介服务过度依赖。积极推行中介机构联合体，同一事项涉及多类中介服务的，由一家中介机构联合相关中介机构，打包提供多类中介服务，变多个中介报告为一份“综合报告”。市县“行政审批中介服务超市”向民营企业开放，降低企业中介成本。〔牵头部门：市发改委、市行政审批局，各县（市、区）人民政府；完成时限：2019年6月底前〕

20.深化“减证便民”行动。对无法律法规明确要求提供的材料进行清除；对部门间可相互提供的材料或通过数据共享、上网可查验的材料进行精简；对确需保留的证明，对外公布清单并严格加强管理，清单之外，不得索要证明，企业和群众到政府办事提供的证明材料减少60%以上。〔牵头部门：市司法局、市行政审批局，各县（市、区）人民政府；完成时限：2019年8月底前〕
