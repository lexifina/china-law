# 关于印发赣州市进一步激发商贸消费潜力促进商贸消费升级三年行动方案（2019-2021年）的通知

《赣州市进一步激发商贸消费潜力促进商贸消费升级三年行动方案（2019-2021年）》已经市政府同意，现印发给你们，请结合实际，认真抓好贯彻落实。

赣州市进一步激发商贸消费潜力促进

商贸消费升级三年行动方案（2019-2021年）

为贯彻落实党中央、国务院和省委、省政府有关促进消费升级的决策部署，进一步提升消费水平，释放消费潜力，加快培育形成经济发展新供给新动力，增强消费对经济发展的基础性作用，结合赣州实际，制定本行动方案。

一、总体目标

全面推动商贸消费升级三年行动，力争实现“一年大突破、两年大提升、三年大跨越”。

一年大突破。城乡消费基础设施得到改善，消费理念有所提升，消费主体逐步扩大，新型消费热点不断涌现，消费氛围日渐浓厚，商贸领域消费统计体系初步建立，商贸流通业转型升级步伐加快，实现“质”的突破。

两年大提升。消费环境进一步优化，便民消费服务网络不断完善，消费水平和质量显著提高。特色商业街、商业综合体、星级酒店等商业基础设施量质齐升，红色旅游市场份额明显提升。到2020年，全市社会消费品零售总额力争突破1000亿元。

三年大跨越。城市消费商圈不断繁荣壮大，现代化商贸流通市场体系基本建立，规模和质量与省域副中心城市相匹配的消费市场全面建成。到2021年，全市社会消费品零售总额突破1100亿元，网络零售突破500亿元，餐饮业营业额突破190亿元，限额以上商贸企业突破900家。

二、主要工作

(一）加强商贸消费领域基础设施建设

1.建设高品位特色商业街区。以高品位、高标准为建设要求，着力打造一批特色鲜明、业态多元、人流物流集中的现代化特色商业街区。重点打造文清路商业街、中联商城步行街、郁孤台历史文化街区、赣县梅林古镇商业街、石城客家风情街、上犹拾乐汤街等。每个县（市、区）至少要新建改造一条特色商业街。

2.建设大型商业综合体。提升步步高新天地、华润万象城、九方等商业综合体功能与品质，力争在我市成立独立法人机构，成为限上企业，做大销售总量。引进京东、苏宁、万达等国内一流企业建设大型商业综合体项目。推进高铁站前商务中心建设，杉杉奥特莱斯购物广场、第五大道王府井购物中心、会昌铜锣湾壹然广场、大余奥园广场等商业综合体尽快开业运营。每个县（市、区）至少新建1个商业综合体。

3.引进国内外知名连锁品牌酒店。加大旅游基础设施建设力度，中心城区建成五星级酒店5家以上，每个县（市、区）建成四星级以上酒店3家以上，五星级酒店1家以上。充分利用2020年全省旅游产业发展大会在我市召开的契机，做大旅游消费市场。

4.完善便民服务设施。在中心城区打造10分钟便民生活服务圈，确保新建社区商业和综合服务设施面积占比不低于10%。引进全国知名连锁便利店，支持本土社区蔬菜便利店发展。中心城区新建社区便利店100家，新建改造农贸市场30个以上。

（二）做大做强商贸主体

1.培育壮大商贸龙头企业。落实政府采购支持中小企业发展政策，支持我市商贸企业做大做强。支持赣州国光、坚强百货等年销售额、增速达到一定标准的限上企业做大做强。培育打造一批十亿级、百亿级商品市场。实施实体零售企业创新转型示范工程，对经营模式先进，线上线下融合发展，创新业绩显著且具有重要示范和引领作用的实体零售创新转型示范企业给予扶持。每个县（市、区）至少引进和培育一个大型商贸流通龙头企业。

2.引进国内外“名店”“名企”。实施大型商贸流通企业引进计划，引进山姆会员店等国内外知名零售企业。吸引大型实体零售和网络零售龙头企业在我市设立法人公司或结算中心，对市外迁入并达到总部企业认定标准的，按照“一企一策”给予综合支持。

（三）提升赣品品质服务供给

1.做强赣州农产品品牌。提高农产品质量安全水平，增加绿色优质农产品供给。着力打造赣南脐橙、赣南茶油、南康甜柚、寻乌蜜桔、会昌橘柚、南安板鸭、石城白莲等公共品牌和区域品牌。充分开发利用富硒土地资源，推广发展好脐橙、蔬菜、大米等富硒农产品，切实打造好富硒农产品品牌。实施老字号振兴工程，培育扶持一批发展潜力大、竞争能力强的老字号品牌。

2.做强南康家具品牌。支持南康家居特色小镇建设，持续举办中国（赣州）家具博览会，推动南康家具品牌崛起。支持汇明、蓝天木业、富龙皇冠、千多多、兴隆芳华、文华家瑞、李氏王朝等南康家具品牌打造成为国内知名家具品牌，提升南康家具品牌价值。引导企业通过“互联网+”发展国内市场，稳定开行赣欧（亚）班列，支持企业拓展海外市场。

3.做强于都服装品牌。推动于都服装行业高质量发展，开启服装行业新长征，将于都县打造成为中国品牌服装制造名城。支持赢智尚、初语、播、梦之屋、可可贝拉、榭家、播妍等本土品牌打造成为国内知名品牌，鼓励企业发展私人定制、网红推广、柔性智造等各种业态。

（四）加大“海品”进口，扩大“名品”供给

1.加大国内外知名品牌和全国各地特色产品供给，组织市内重点消费品采购商参加境内外活动，扩大日用消费品进口。加快特殊商品指定进境口岸布局和发展，推动赣州综保区和赣州国际陆港“港区联动”，支持其建立进口商品展示直销中心，丰富进口商品供给。引入蔻驰、阿玛尼、资生堂、天梭、浪琴等国际高端品牌，推进名品入店，满足中高端消费需求。

2.实施进口商品交易便利化工程。推进实体零售企业与跨境电商进口企业开展进口商品采购供应链合作，设立形式多样的跨境电商线下体验店。推进中国跨境电子商务综合试验区创建，重点推进跨境电商产业园、跨境电商产业带建设，鼓励跨境电商进口企业在综合试验区设立进口母仓、区域总仓。

（五）丰富新兴业态热点

1.繁荣夜间消费市场。培育有影响力的特色夜生活街区和大型文化娱乐中心区，扩大夜消费、丰富夜生活、繁荣夜经济。提质优化“外滩1号娱乐城”，打造市级高品质夜间消费街区，鼓励发展24小时不打烊餐饮店、便利店、娱乐场所。

2.做旺应季消费。围绕季节性消费热点和重要节假日，采取政府引导、市场运作的方式，开展聚人气促消费活动，发展节会经济。办好中国赣州国际脐橙节、中国（赣州）家具博览会等重大活动，积极举办美食节、展销会、文化旅游节等活动，做到“月月有活动，季季有节会”。

3.提升餐饮消费。打造客家大院、鹭溪客家菜、上客天下等赣南美食旗舰店，支持渔湾里等美食街建设。积极培育“绿色饭店”“智慧餐厅”“无人餐厅”等新的业态模式。打造具有赣南客家菜特色的名宴、名菜、名小吃，支持红色文化餐饮发展，持续举办赣南客家美食节，繁荣餐饮消费市场。

（六）完善商贸流通网络

1.深入实施“互联网+商贸流通”行动。全力推进“赣品网上行”，推动电子商务与特色产业融合发展，与快递物流协同发展。推动生活服务业在线化，完善社区智能快件箱等末端服务设施，中心城区住宅小区智能快件箱覆盖率达到85%以上，县城住宅小区覆盖率达到70%以上。

2.提高商贸物流配送效率。发展城乡高效配送，完善城乡配送网络，打造一批一级配送基地，推进智慧物流平台建设。依托全国首个无人机物流配送试点项目，探索建立无人机物流运行平台。推进赣州明品福冷链物流中心、赣州港龙泰食品链加工产业园等冷链物流项目建设，推动互联网与冷链物流行业融合发展。

3.优化综合物流运输。充分依托指定口岸功能优势，做大临港经济产业，加快进境肉类指定口岸正常运营，做好整车进口口岸建设。开展进境粮食、水果、钻石等指定口岸和国际快件海关监管中心的研究论证和申报工作。发展港口现代物流，构建国内大型物流区域集散中心。

4.提升乡村商贸流通基础设施建设。实施乡村商贸振兴工程，发挥好乡村自然资源和人文资源优势，提升乡镇商贸集聚水平，重点建设龙南虔心小镇、江口果蔬小镇、会昌和君教育小镇、寻乌南桥青龙岩小镇等一批工贸型、农贸型、电商型和商旅文型特色商贸小镇。

三、保障措施

（一）强化组织领导。成立赣州市促进商贸消费升级工作领导小组，市商务局、市财政局、市发改委、市农业农村局、市文广新旅局、市城管局、市体育局、市统计局、市工信局、市市场监管局、市自然资源局、市住建局、市交通运输局、市邮政管理局、市公安局为成员单位，领导小组负责统筹协调推进各项工作，领导小组办公室设在市商务局，负责日常协调、督查、考核工作。

（二）落实推进机制。加大财政支持力度，统筹安排相关资金，引导商贸市场健康发展。建立促消费工作协调推进机制，市直有关部门要各司其职，密切配合，切实负起责任，根据本方案抓紧落实工作举措，形成齐抓共管工作合力。各县（市、区）要高度重视，建立主要负责同志任组长的工作推动机制，落实消费升级主体责任，结合本地实际，按照项目化、工程化的要求制定具体的三年行动实施方案，于2019年7月底前报市商务局备案。

（三）强化规划引领。坚持规划先行，以高质量商业网点规划为引领，推动建立和完善与我市城市经济发展相适应，布局结构合理、功能齐全、竞争有序的现代商业网点网络和商品市场体系。

（四）加强宣传引导。通过新闻媒体加强对推动供给侧结构性改革、消费升级以及商贸流通创新的宣传报道，营造良好舆论环境。建立信息反馈机制，不断发现总结好的经验、好的做法在全市推广。

（五）严格考核奖惩。建立“月调度、季分析、半年总结、年度考核”工作机制，完善考核指标体系，建立具有量化指标、明确标准的促进消费体系。加强对重点工作任务跟踪，定期通报工作推进和完成情况，对工作落实不力、行动计划推进缓慢的单位和部门进行通报约谈。
