# 赣州市人民政府办公室关于建立定期梳理集中破解制约高质量跨越式发展突出困难问题长效机制的通知

赣市府办字〔2019〕50号

赣州市人民政府办公室关于建立

定期梳理集中破解制约高质量跨越式发展

突出困难问题长效机制的通知

各县(市、区）人民政府，市政府各部门，市属、驻市各单位：

为贯彻落实省政府办公厅《关于建立定期梳理集中破解制约高质量跨越式发展突出困难问题长效机制的通知》（赣府厅字〔2019〕64号）精神，现就建立全市定期梳理集中破解制约高质量跨越式发展突出困难问题长效机制有关事项通知如下：

一、重点领域

聚焦建设革命老区高质量发展示范区，重点梳理和集中破解加快推进新旧动能转换、产业转型升级、重大项目落地、重大基础设施建设、重点企业帮扶、开发区改革创新、功能性平台建设、扩大高水平开放、促进区域协调发展、民生工程以及其他关系本地区、本部门发展的全局性、关键性问题。

二、工作流程

（一）问题收集。各地、各部门围绕重点领域，每半年集中开展一次问题梳理和摸排，也可根据工作需要就某个领域或某项重点工作及时进行梳理摸排。对梳理和摸排出的问题，各地、各部门要先行对其必要性、可行性和前期工作、基础条件等进行分析研究和论证，认真筛选，按轻重缓急、解决层面等进行分类整理。

（二）问题上报。按照分级负责原则，对通过本地、本部门研究论证，认为可行的事项，各地、各部门每年分两批次，分别于3月15日前和9月15日前统一上报市政府（市政府办公室政策法规科，联系电话：8392217）。上报事项原则上应纳入本地、本部门当年工作计划。其中，对需争取国家、省级层面支持协调解决的困难问题，由市政府汇总、审核后报送省政府。

（三）问题交办。对各地、各部门报送的困难问题，市政府办公室负责牵头抓总，由市政府办公室相关业务科室按照职能分工和问题类型，进行审核把关。对符合要求的，建立工作任务清单，明确问题来源、主要内容、办理层级、牵头领导、责任部门、责任人员和办结时限等，及时予以交办。对不符合要求的，及时退回并说明理由。

（四）问题协调。明确相关市政府副秘书长担任协调负责人，负责抓好对口部门事项的协调落实。责任部门要对每个困难问题，因情施策、逐一研究，制定具体解决方案和措施。对解决难度较大的困难问题，视情逐级报请市政府分管领导或主要领导协调解决；对需争取国家、省级层面帮助解决的，要主动加强与国家部委、省直厅局沟通汇报，需请市政府领导出面的及时报告。

（五）问题跟踪。按照“谁负责、谁反馈”原则，坚持每月一调度、一季一汇总、半年一小结，以销号管理方式，抓好困难问题解决。责任部门应及时向问题提出单位及时反馈办结情况；对因国家和省政策限制或有关条件暂不成熟等客观原因一时难以解决的，要做好充分说明和耐心解释工作，并共同研究谋划，为今后推进相关工作创造条件。市政府办公室将加强困难问题办理情况的跟踪落实，每年1月和7月上旬，定期将相关困难问题办理情况通报各地、各部门。对破解困难问题成效突出的单位和个人，市政府将通令嘉奖并优先推荐申报省政府及时奖励；对推诿扯皮、弄虚作假导致问题久拖不决造成不良影响的，一经查实严肃追责问责。

三、工作要求

（一）高度重视。各地、各部门要把梳理解决制约高质量跨越式发展困难问题，作为深化“五型”政府建设、开展好“不忘初心、牢记使命”主题教育的重要举措，列入本地、本部门重要议事日程，安排专人具体负责，主要领导亲自研究、亲自部署、亲自推动困难问题解决。

（二）凝聚合力。要完善工作机制，建立定期收集机制，加强上下级之间、部门之间的沟通衔接，互通信息，凝聚合力，推动困难问题及时发现、及时交办、及时解决、及时反馈。对需国家、省级层面解决的重大事项，要充分发挥国家部委对口支援等政策优势，市县联动，共同争取。

（三）加强宣传。要充分利用传统媒体和新兴媒体，加强宣传引导，强化正向激励，宣传报道各地、各部门在推动困难问题解决过程中的良好风貌，全面展现全市“五型”政府建设的新成效，让“不为不办找理由、只为办好想办法”成为全市政府系统干部的鲜明标签。
