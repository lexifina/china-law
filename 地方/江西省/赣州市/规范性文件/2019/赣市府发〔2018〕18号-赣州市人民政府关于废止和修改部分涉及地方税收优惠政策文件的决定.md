# 赣州市人民政府关于废止和修改部分涉及地方税收优惠政策文件的决定

赣市府发〔2018〕18号

赣州市人民政府关于废止和修改部分涉及

地方税收优惠政策文件的决定

各县（市、区）人民政府，市政府各部门，市属、驻市各单位：

为进一步优化我市经济社会发展环境，市政府对涉及地方税收优惠政策的文件进行了全面清理。经研究，决定废止《赣州市人民政府办公厅关于印发赣州市扶持铜铝有色金属产业发展若干政策的通知》(赣市府办发〔2016〕36号)、《赣州市人民政府办公厅关于印发赣州市扶持食品产业发展若干政策的通知》(赣市府办发〔2016〕35号)等2件文件，修改《赣州市人民政府印发关于促进经济平稳健康发展的若干政策措施的通知》(赣市府发〔2017〕20号)等11件涉及地方税收优惠政策文件。

本决定自公布之日起施行。

附件：废止和修改涉及地方税收优惠政策文件目录和内容

2018年12月21日

（此件主动公开）

二、财税优惠　3．落实税收优惠政策。……新办企业开业之日起三年内，按其缴纳的企业所得税地方留成部分的50%的标准由受益财政通过支出渠道安排资金进行奖励；对年纳税500万元以上，且同比增长20%的企业，由受益财政给予一次性奖励。

二、财税优惠　3．落实税收优惠政策。……新办企业开业之日起三年内，由受益财政根据企业对地方经济的贡献情况给予一定的奖励；对主营业务收入增长20%以上且对地方经济贡献突出的成长型企业，由受益财政给予一次性奖励。
