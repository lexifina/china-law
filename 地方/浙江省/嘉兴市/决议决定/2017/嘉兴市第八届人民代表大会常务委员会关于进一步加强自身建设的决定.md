# 嘉兴市第八届人民代表大会常务委员会关于进一步加强自身建设的决定

嘉兴人大网 发布日期：2017-08-11

嘉兴市八届人大常委会任期的五年，是我市高水平全面建成小康社会、奋勇当标尖的关键时期和决胜阶段。为坚持和完善人民代表大会制度，进一步增强依法履职能力，更好地发挥地方国家权力机关的作用，推进我市经济社会发展和民主法治建设，现就加强新一届市人大常委会自身建设，作出如下决定：

一、强化政治建设，做到对党忠诚永葆初心

1．坚定正确政治方向。要高举中国特色社会主义伟大旗帜，以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入贯彻习近平总书记系列重要讲话精神，坚定不移走中国特色社会主义道路。要牢固树立政治意识、大局意识、核心意识、看齐意识，坚决同以习近平同志为核心的党中央保持高度一致，坚定维护以习近平同志为核心的党中央的权威，在思想上拥护核心、政治上维护核心、行动上紧跟核心。要带头讲政治、讲党性，严格遵守政治纪律和政治规矩，认真贯彻执行党的路线方针政策，自觉把党的领导贯穿于人大工作全过程，落实到依法履职各方面。

2．坚决贯彻市委决策。要进一步坚持和完善向市委请示报告制度，定期向市委报告常委会工作，及时向市委请示报告立法、监督、重大事项决定、人事任免等工作中的重大问题，维护市委总揽全局的领导核心地位，并积极通过人大法定程序与履职实践，保证党委的决策部署转化为全市人民的共同意志和自觉行动。特别要认真贯彻落实市第八次党代会作出的决策部署，以及打造勇立潮头红船铁军的总体要求，在勇当高水平全面建成小康社会的标尖、全力打造具有国际化品质的现代化网络型田园城市进程中，积极发挥人大的功能与作用，贡献更多人大的智慧与力量。

3．坚持依法履职行权。要始终坚持党的领导、人民当家作主、依法治国的有机统一，严格按照宪法和法律法规，以更高标准、更严要求、更实举措，统筹推进人大立法、监督、决定、任免、代表各项工作。要积极配合国家监察体制改革，合力推动试点工作取得成效。要正确处理监督与支持的关系，依法加强对市“一府两院”的工作监督和法律监督，寓支持于监督之中，在监督中体现支持，在支持中实施监督。

二、强化思想建设，做到增强自信走在前列

4．增强人大制度自信。要充分认识人民代表大会制度是符合中国国情和实际、体现社会主义国家性质、保证人民当家作主、保障实现中华民族伟大复兴的根本政治制度，切实增强中国特色社会主义道路自信、理论自信、制度自信、文化自信，坚决消除在人民代表大会制度、人大作用发挥等方面存在的认识误区，始终不渝地把人民代表大会制度坚持好、完善好、发展好，不断丰富人民代表大会制度在嘉兴实践的地方特色和时代特色。

5．增强思想理论武装。要坚持把加强学习作为履行职责的重要基础，以深入学习中国特色社会主义理论体系为主题，以深入学习人民代表大会制度基本理论和相关法律法规为重点，以及时掌握人大制度和人大工作的研究前沿为切入，全面加强学习，有效提升履职站位、夯实履职基础。要牢固树立终身学习的理念，面对新常态新要求，坚持勤学善思，拓展学习方式，进一步完善常委会理论中心组学习、读书会、法制讲座等学习制度，不断完善知识结构、充实知识储备、拓展工作视野。要注重把学习成果转化为依法履职的本领，紧密结合经济社会发展和人大工作实际，研究新情况、解决新问题、把握新规律、总结新经验。

6．增强调查研究能力。调查研究是推进决策科学化、民主化的基本环节。要紧紧围绕省、市重点工作部署，以及市人大常委会年度监督工作计划和年度立法计划等内容，有针对性地开展调查研究，广泛听取各方意见，形成高质量的调研报告，为党委决策、人大履职提供参考。市人大常委会组成人员要带头深入基层听民意、深入实际察民情、深入代表集民愿、深入群众暖民心，始终为改革发展稳定服务，为社会民生福祉呼吁，为解决难点问题用劲。

三、强化制度建设，做到科学决策依法履职

7．严格遵守议事规则。要认真贯彻民主集中制，严格遵循集体领导、民主集中、会议决定的原则，按照市人大常委会有关议事规则，通过会议的形式，由集体行使职权。要在充分发扬民主的基础上，集中多数人的意见，作出决议决定。要健全并落实市人大常委会领导分工负责制，充分发挥常委会组成人员的主观能动性，做到各司其职、各尽其责。对集体讨论决定的事项，市人大常委会组成人员要带头严格执行、坚决维护并督促落实。

8．建立健全工作制度。要加强对人大工作规律和工作特点的研究，及时总结经验，把成功的做法适时制度化。要坚持依法治国、依制管理统筹推进、一体建设，依据地方组织法、代表法、监督法等有关法律法规的规定，建立健全立法、监督、决定、任免、代表工作和自身建设等方面的各项制度，细化工作流程，完善工作机制，不断提升人大工作制度化、规范化水平。要提升制度执行力，市人大常委会组成人员要真正敬畏制度、自觉维护制度、带头落实制度。

9．积极推进制度创新。要在宪法和法律框架内，处理好继承与发展、规范与创新的关系，坚持从实际出发，积极推进人大常委会工作的机制和制度创新。要积极探索人大工作的新思路、新途径、新措施，深化拓展专题询问、满意度测评、部门工作评议等工作举措，深入推进“两站一平台”建设，有序实施政府民生实事票决制，推进项目建设，回应群众关切，使人大工作体现时代性、把握规律性、富于创造性。

四、强化作风建设，做到干事担当不辱使命

10．始终保持进取状态。要保持“一线”状态，坚持“一线”标准，发挥“一线”作用。要牢牢把握人大工作定位、特点和要求，紧紧围绕中央和省、市委的重大决策部署和全市中心工作，积极有效地履行法定职责，认真审议有关议案和各项报告，保证宪法和法律在本市行政区域得到正确实施。要模范遵守宪法、法律、法规和市人大及其常委会通过的决议决定。要增强责任意识、强化使命担当，勤奋敬业、倾心履职，重实情、讲实话、求实效。常委会组成人员要自觉履行法定义务，按时出席会议，提前做好会议审议准备工作，带头参加闭会期间的代表活动。

11．密切联系代表群众。要认真践行群众路线，畅通社情民意反映和表达渠道，尊重和发挥代表主体作用，支持和保证人大代表依法履行职责。要坚持和完善市人大常委会组成人员联系代表、代表联系群众做法，通过广泛联系，使常委会作出的决定决议、提出的审议意见，更加符合改革发展要求，符合客观实际，符合群众意愿。要深化完善市人大常委会领导领衔督办制度，改进代表议案建议办理工作，切实提升办理质量和办结率。要深化代表述职评议，健全代表履职评价办法，促进代表依法积极履职。

12．有效激发队伍活力。要密切上下协同，认真贯彻落实上级人大部署要求，加强对县（市、区）人大的联系指导，深入推进镇（街道）人大规范化建设，形成上下联动，汇聚工作合力。要推进作用发挥，充分发挥专工委的组织作用和专业优势，依托专工委推进落实常委会的重点任务。要强化机关建设，以营造奋发向上、学习创新、团结和谐良好氛围为目标，以提升干部队伍整体素质能力为重点，进一步强化执行力、提升创新力、增强公信力，全面加强人大机关自身建设，为常委会依法履职提供服务和保障。

五、强化廉政建设，做到保持本色干净自律

13．全面落实主体责任。要按照全面从严治党要求，认真落实市人大常委会党组党风廉政建设主体责任和领导干部“一岗双责”，坚持严字当头、实字托底，以上率下、把牢关键，坚决贯彻落实中央和省、市委关于加强反腐倡廉建设的决策部署和各项规定，带头落实中央八项规定精神，严格执行《关于新形势下党内政治生活的若干准则》和《中国共产党党内监督条例》，切实增强党内政治生活的政治性、时代性、原则性和战斗性，以身作则、挺纪在前、严于律己，维护团结统一、保持先进纯洁，不断增强拒腐防变和抵御风险的能力。

14．自觉接受各方监督。要牢固树立国家权力机关对人民负责、受人民监督的意识，始终按照法定权限和法定程序履行职责。要坚持秉公用权、为民用权、阳光用权，始终保持昂扬向上的履职热情和清正廉洁的政治本色。要坚持和完善监督公开制度，加强和改进人大宣传工作，依法及时向社会公开，增强常委会工作的公开性和透明度，使工作始终处于人大代表、人民群众和社会各界的有效监督之下。

15．持续加强自身修养。要树立正确的世界观、人生观、价值观，带头践行社会主义核心价值观，自觉遵守社会公德、职业道德、家庭美德，讲党性、重品行、做表率。要在人民赋予的权力面前、在市场经济各种利益诱惑面前，始终保持头脑清醒、思想纯洁和政治定力，耐得住寂寞，守得住清贫，经得起考验，以实际行动维护人大及其常委会的良好形象。
