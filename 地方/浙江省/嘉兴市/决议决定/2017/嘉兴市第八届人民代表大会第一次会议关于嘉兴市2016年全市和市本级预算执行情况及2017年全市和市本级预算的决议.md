# 嘉兴市第八届人民代表大会第一次会议关于嘉兴市2016年全市和市本级预算执行情况及2017年全市和市本级预算的决议

嘉兴人大网 发布日期：2017-04-26

嘉兴市第八届人民代表大会第一次会议经过审查，并根据嘉兴市第八届人民代表大会第一次会议计划预算审查委员会关于预算的审查报告，决定批准嘉兴市人民政府提出的2017年嘉兴市市本级预算,同意嘉兴市财政局受市人民政府委托所提交的《关于嘉兴市2016年全市和市本级预算执行情况及2017年全市和市本级预算草案的报告》。
