# 嘉兴市第八届人民代表大会第一次会议关于嘉兴市2016年国民经济和社会发展计划执行情况及2017年国民经济和社会发展计划的决议

嘉兴人大网 发布日期：2017-04-26

嘉兴市第八届人民代表大会第一次会议经过审查，并根据嘉兴市第八届人民代表大会第一次会议计划预算审查委员会关于计划的审查报告，决定批准嘉兴市人民政府提出的嘉兴市2017年国民经济和社会发展计划，批准嘉兴市发展和改革委员会受市人民政府委托所提交的《关于嘉兴市2016年国民经济和社会发展计划执行情况及2017年国民经济和社会发展计划草案的报告》。
