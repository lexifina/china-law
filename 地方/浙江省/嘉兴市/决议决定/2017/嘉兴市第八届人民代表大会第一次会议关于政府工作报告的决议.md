# 嘉兴市第八届人民代表大会第一次会议关于政府工作报告的决议

嘉兴人大网 发布日期：2017-04-26

嘉兴市第八届人民代表大会第一次会议听取和审议了胡海峰市长代表市人民政府所作的《政府工作报告》。会议认为，过去五年，市政府坚持把发展作为第一要务，紧紧依靠和团结全市人民，克难奋进、开拓创新，较好地完成了市七届人大历次会议确定的主要目标任务，全市经济社会发展迈上了一个新台阶。报告对2016年和过去五年工作的总结是实事求是的，提出的2017年和今后五年工作目标和主要任务，符合中央和省委、省政府的战略部署，符合市第八次党代会的精神，符合嘉兴的实际，是积极可行的。会议决定批准胡海峰市长所作的报告。

会议强调，今后五年是嘉兴经济社会转型发展的关键时期，也是高水平全面建成小康社会的决胜阶段。全市上下必须高举中国特色社会主义伟大旗帜，以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入贯彻习近平总书记系列重要讲话精神，牢固树立以人民为中心的发展思想，积极践行新发展理念，适应把握引领经济发展新常态，重点围绕“高质量、均衡性”，突出创新驱动，放大平台载体优势，加快推动新旧动能接续转换和产业改造升级；突出内外联动，放大改革集群和接沪联杭优势，提升经济发展的活力和市场化国际化水平；突出全域统筹，放大城乡区域协同优势，全面提高城市承载力和竞争力；突出绿色低碳，放大“三五共治”联动优势，着力打造江南水乡名典范；突出民生优先，放大公共服务供给优势，不断增强人民群众获得感，全力打造具有国际化品质的现代化网络型田园城市。

会议指出，2017年是新一届政府履职的第一年。市政府要深入贯彻党的十八大和十八届三中、四中、五中、六中全会和中央、省经济工作会议精神，坚持稳中求进工作总基调，以提高发展质量和效益为中心，注重供需两端发力，保持经济平稳运行；振兴实体经济，加快产业结构调整；深化改革开放，释放体制机制红利；推进城乡区域统筹发展，提升城市品质；狠抓环境治理和净化，打造“美丽嘉兴”；强化发展惠民，保障和改善民生；加强自身建设，提高政府履职水平。

会议号召，全市人民要紧密团结在以习近平同志为核心的党中央周围，在中共嘉兴市委的正确领导下，不忘初心、继续前进、勇立潮头、勇当标尖，以优异成绩迎接党的十九大胜利召开，奋力谱写高水平全面建成小康社会的崭新篇章！
