# 嘉兴市第八届人民代表大会第四次会议关于将嘉兴市第八届人民代表大会内务司法委员会更名为嘉兴市第八届人民代表大会监察和司法委员会的决定

嘉兴人大网 发布日期：2019-01-19

（2019年1月16日嘉兴市第八届人民代表大会

第 四 次 会 议 通 过）

根据《中华人民共和国地方各级人民代表大会和地方各级人民政府组织法》的有关规定和《嘉兴市机构改革方案》，嘉兴市第八届人民代表大会第四次会议决定：将嘉兴市第八届人民代表大会内务司法委员会更名为嘉兴市第八届人民代表大会监察和司法委员会。

嘉兴市第八届人民代表大会内务司法委员会组成人员职务终止。
