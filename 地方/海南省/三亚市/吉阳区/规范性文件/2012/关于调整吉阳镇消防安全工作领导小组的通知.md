# 关于调整吉阳镇消防安全工作领导小组的通知

各村（居）委会、各机关单位：

因工作、人事变动，经镇委、镇政府同意，现将吉阳镇消防安全工作领导小组成员调整如下：

副 组 长：陈德勇（镇委副书记、镇长）

凌秀东（镇委副书记、武装部部长）

成    员：吴邦平（吉阳派出所所长）

吴淑群（荔枝沟派出所所长）

李  陈（亚龙湾派出所所长）

王文正（安游边防派出所所长）

熊  彬（红沙边防派出所所长）

李才进（吉阳工商所所长）

陈  娇（荔枝沟工商所所长）

各村（居）委会书记、主任

领导小组下设办公室，设在镇消防安全办公室，主任由凌秀东兼任。办公室主要负责具体整治工作的组织、协调、落实以及各种材料的收集、起草和上传下达工作。

三亚市吉阳镇人民政府

二一二年七月五日
