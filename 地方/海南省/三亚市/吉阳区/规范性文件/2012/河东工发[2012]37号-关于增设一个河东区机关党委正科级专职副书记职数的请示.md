# 关于增设一个河东区机关党委正科级专职副书记职数的请示

关于增设一个河东区机关党委正科级

专职副书记职数的请示

市编委：

我区目前党组织设置有区工委1个，机关党委1个，党总支部3个，党支部47个，党员1511人。其中机关党委下辖党总支部2个，党支部17个，党员408人。机关党委设置书记1名（区工委副书记兼任）、副书记1名（兼职）、委员5名（兼职）。

我区机关党委下辖的支部包括机关、环卫局、绿地所、学校、老干部、军转自主择业干部，单位多、党员多、党员的统计、党费的收缴、开展党员活动等党员管理工作难度大，需要配置专职机关党委副书记进行管理。而我区机关党委虽然已设置机构，但成员都是兼职的，没有专职人员，造成机关党委工作难以打开局面。为了促进基层党组织建设，加强我区机关党委工作，请贵委增设河东区机关党委1个正科级专职副书记职数。

妥否，请批示

2012年5月4日
