# 关于成立河东区流动人口服务中心筹备组的通知

各科室（中心、局）、居（村）委会：

为做好河东区流动人口服务中心前期的准备工作，经区工委会议研究，成立河东区流动人口服务中心筹备组。

组 长：刘跃忠（区工委副书记）

副组长：莫壮丽（区管委副主任）

陈 锐（区工委调研员）

成 员：刘文杰、吉才芬、蔡利、姜平

领导小组下设办公室，办公室主任刘文杰兼任。

中共河东区工作委员会

2012年4月5日 （此件主动公开）
