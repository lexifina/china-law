# 三亚市人民政府办公室关于设立区镇食品安全委员会及其办公室的通知

三亚市人民政府办公室

关于设立区镇食品安全委员会及其办公室的通知

各镇人民政府，河东区管委会，河西区管委会，市政府直属各单位：

根据《海南省人民政府关于省级以下食品药品监督管理体制改革的意见》（琼府〔2013〕79号）和《海南省食品安全委员会办公室关于在乡镇政府、街道办事处设立食品安全委员会及其办公室的通知》（琼食安办〔2014〕37号）有关在乡镇、街道设立食品安全委员会的精神，为进一步完善我市区、镇食品安全监管体制，落实属地政府对辖区食品安全负总责的职责，推动食品安全监管关口前移、重心下移。现就在各镇人民政府、两区管委会设立食品安全委员会及其办公室的有关事项通知如下：

一、两区管委会、各镇人民政府要设立食品安全委员会，履行食品安全综合协调、监督指导和考核评价等职能。可由区、镇食品药品监管所承担食品安全委员会具体工作，加挂“××区（镇）食品安全委员会办公室”牌子。

二、各区、镇食品安全委员会主任、副主任分别由区管委会、镇政府主要负责人、分管负责人兼任。区、镇食品安全委员会办公室主任可由区、镇食品药品监管所所长兼任。

三、以上工作于2014年10月中旬完成，由市食品安全委员会对设立具体工作进行督察指导并将完成情况上报市政府。

三亚市人民政府办公室

2014年8月1日
