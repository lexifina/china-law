# 三亚市人民政府办公室关于印发三亚市继续整治旅游市场突出问题工作方案的通知

三亚市人民政府办公室

关于印发三亚市继续整治旅游市场突出问题

工作方案的通知

各镇人民政府，各区管委会，市政府直属各单位：

《三亚市继续整治旅游市场突出问题工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2014年8月4日

（此件主动公开）

三亚市继续整治旅游市场突出问题

工作方案

为做好我市旅游旺季接待服务工作，解决旅游旺季存在的各类突出问题，自2013年国庆黄金周结束以来，我市开展了旅游旺季突出问题综合整治工作，针对涉海涉水旅游、旅游交通、旅游经营、旅游住宿、旅游环境、旅游餐饮、旅游安全7个方面60项突出问题进行全面整治。经过大力整治，一些突出问题已经整治完成并取得了良好的效果，一些问题建立了长效机制，但也有部分问题仍未得到有效解决，需要继续进行整治。

根据《中共三亚市委办公室三亚市人民政府办公室关于印发三亚市开展深化改革年科学管理年和问题整改主题月活动实施方案的通知》（三办字〔2014〕17号）要求，按照我省深化改革年、科学管理年相关工作部署，为了进一步深入整治我市旅游市场存在的突出问题，深化我市正在开展的旅游产业结构调整和旅游市场整治专项活动，市假日办对需要继续进行整治的问题以及在整治过程中新发现的问题进行了梳理。市政府决定自2014年7月至10月，继续全力整治我市旅游市场存在的突出问题，现根据工作实际，制定本方案。

一、总体目标

进一步统一思想，提高认识，理清各单位在旅游市场管理中的职责，系统解决当前我市旅游市场存在的各类突出问题，进一步做好我市旅游市场接待服务工作，为我市2014年下半年旅游旺季接待服务工作营造良好的环境，实现“安全、秩序、质量、效益”四统一的假日旅游工作目标。同时建立长效管理机制，实施精细化管理，切实提高我市旅游管理水平，提升旅游服务质量。

二、工作任务

围绕总体目标，全面落实责任制，层层分解任务，制定解决旅游市场突出问题的任务分解方案，把各项工作任务落到实处，继续着力解决我市旅游市场在涉海涉水旅游、旅游交通、旅游经营、旅游住宿、旅游环境、旅游餐饮、旅游安全七个方面存在的突出问题，并建立良好的旅游市场秩序（详见附件，继续整治问题36项，新增问题24项，共计60项）。

三、工作步骤

此项工作从2014年7月15日至10月31日。

（一）大力整治解决问题阶段（2014年7月15日至8月31日）

各单位以维护我市旅游市场秩序、提升服务质量为目标，全面落实《责任分解表》的各项工作任务。

（二）总结提升巩固成果阶段（2014年9月1日至2014年9月30日）

1．各牵头单位要对解决各类问题的具体工作情况进行全面、深入地分析总结，总结经验，查找不足，检验工作成效，并于2014年10月1日前形成书面总结报市假日办，由市假日办汇总整理后报市政府。

2．市政府召开总结大会，验收工作成果，总结工作经验，部署旅游旺季工作。

（三）建立长效机制阶段（2014年10月1日至10月31日）

1.涉海旅游方面。建立明确的海上旅游监管机制，切实保障游客安全，严厉打击利用渔船等非营运船只招徕游客出海旅游等非法经营行为，加强摸排，持续打击非法经营者。

2.旅游交通方面。建立良好的沟通协作机制和应急处置预案，科学调配运力，提升交通畅通率及便捷性。

3.旅游经营及旅游住宿方面。进一步贯彻落实《旅游法》的相关规定，严格市场准入制度；健全景区景点管理机制；推进导游体制管理改革；不断完善旅游法规和行业标准，提升旅游服务质量。

4.旅游环境方面。严厉打击“两抢一盗”现象；打击街边散发虚假小广告、乱摆乱放等不文明行为；建设自驾车露营地；充分发挥新闻媒体的作用，广泛宣传丰富多彩的假日旅游休闲活动，倡导旅游接待单位诚信经营、文明服务、细微服务、优质服务，引导游客文明旅游、健康旅游、绿色旅游、理性消费。进一步完善突发事件新闻发布制度和新闻发言人制度，及时、准确、全面地发布相关公共服务信息，主动接受新闻媒体和社会监督。不断提高我市旅游服务质量和水平，为游客提供良好的旅游体验，着力提高游客满意度。为游客和市民营造安全、祥和的旅游环境。

5.旅游餐饮方面。加强餐饮食品质量检查，不断完善餐饮行业标准，进一步排除食品安全隐患。

6.旅游安全方面。做好交通集散地、住宿餐饮娱乐设施、旅游景区及相关旅游设施设备的日常安全检查工作，确保游客人身安全。

四、相关要求

（一）建立工作责任制。各责任市领导、牵头单位、配合单位要明确各自分工，加强协作，联合执法，形成责任市领导负总责，牵头单位具体负责，配合单位全力支持配合的联动机制。

（二）制定工作方案。各牵头单位要针对每一项工作制定切实可行的工作方案，细化任务措施，层层分解，级级落实，明确工作目标和责任分工，确保每一个问题都有人负责、有人跟踪、有人协调、有人推进。牵头单位是各项任务的主要责任主体，负责抓好各个突出问题的解决；各配合单位在各自的职能范围内，配合牵头单位抓好各项任务的落实。

（三）加强行政督查。各牵头单位要做好督查、汇报工作，每月15日和30日将前半个月整治工作推进情况和计划开展的工作报市假日办汇总（2014年7月15日至10月31日），市假日办以简报形式报市政府督查议案室。市假日办负责做好解决各类问题的统筹、协调、服务等工作，并对问题的解决情况进行全面监督、检查，对久拖未决的问题进行重点督办，确保各类问题都有处理结果。市监察局、市政府督查议案室负责对本责任分解方案的落实情况进行监督检查。

（四）做好媒体宣传工作。各单位要充分发挥新闻媒体的作用，通过中央和地方媒体联动、集中报道与日常报道相结合的方式，广泛宣传本单位所开展的旅游市场整治活动，并及时、准确、全面地发布相关信息，主动接受新闻媒体和社会监督。
