# 三亚市人民政府办公室关于印发三亚市2014年农业机械购置补贴项目实施方案的通知

三亚市人民政府办公室

关于印发三亚市2014年农业机械购置补贴项目实施方案的通知

各镇人民政府，各区管委会，市各有关单位：

《三亚市2014年农业机械购置补贴项目实施方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2014年8月26日

（此件主动公开）

三亚市2014年农业机械购置补贴项目实施方案

根据《海南省农业厅海南省财政厅关于印发2014年农机购置补贴项目实施方案和补贴额一览表的通知》（琼农字〔2014〕55号）精神，为做好我市2014年农业机械购置补贴工作，进一步促进我市农业机械化又好又快发展，结合我市农业实际，制定本实施方案。

一、总体要求

以加快发展热带现代农业和增加农民收入为中心，以转变农机化发展方式为主线，以调整优化农机装备结构、提升农机化作业水平、增强农业综合生产能力为主要任务，加快推进主要农作物关键环节机械化。注重阳光操作，加强农机购置补贴实施监管和廉政风险防范，进一步推进补贴惠民政策执行公平公开。优先扶持水稻、瓜果菜机械化作业机具和粮食烘干设备，以及喷滴灌节水和冷藏设备，推动瓜果菜、南繁育种、畜牧业、水产、林业、农产品加工业机械化发展。

三、实施范围及资金控制规模

（一）实施范围：全市各区镇（含地方农场、林场）。

（二）资金规模：2014年我市第一批农机购置补贴规模为1520万元。其中，中央财政专项补贴资金600万元、省级资金70万元、市配套财政专项补贴资金850万元（含工作经费）。

四、补贴机具类型及补贴标准

（一）补贴机具种类

根据海南省确定的补贴机具种类范围和我市农业生产实际需要，我市2014年补贴机具设备为耕整地机械、种植施肥机械、田间管理机械、收获机械、收获后处理机械、农产品初加工机械、排灌机械、畜牧水产养殖机械、动力机械、农田基本建设机械、设施农业设备和冷藏设备、其他机械等12大类41个小类116个品目的补贴农机具及设备（详见附件1）。

（二）补贴标准

中央、省和市级财政农机购置补贴资金实行定额补贴，即同一种类、同一档次的农业机械在本省行政区域内实行统一的补贴标准。2014年农机购置补贴非通用类农机产品定额补贴不得超过本省近三年的市场平均销售价格的30%，一般机具单机最高补贴额原则上不超过5万元。各种类型补贴机具单机补贴额参见附件1。

为使补贴政策惠及更多农民，2014年以个人名义申请购买补贴机具（含建设喷滴灌节水设备、简易冷库设备），年内每户享受补贴资金原则上不超过20万元；以从事农机作业的农业生产经营组织和农民专业合作社名义申请购买补贴机具（含建设喷滴灌节水设备、简易冷库设备），年内每家享受补贴资金原则上不超过80万元；以从事农机作业的农业生产经营组织或农民专业合作社名义承包或建设的喷滴灌设施农业基地、简易冷库、种养基地等，申请农机购置补贴时须以从事农机作业的农业生产经营组织或农民专业合作社名义申请，不得以农户个人名义申请或按照农户个人享受最高补贴额标准分散办理补贴资金结算。申请同一类型补贴机具5台（部）以上的，申请人须提供补贴机具作业面积（或种养面积、加工能力、冷库库容）合同等证明材料，市农机局对材料的真实性认真进行审查。

为加大水稻和瓜菜生产从育秧（育苗）、播插（移栽）和烘干等全程机械化机具补贴力度，在中央资金补贴的基础上，允许地方配套资金实行累加补贴，但省、市两级累加资金不得重复（即省或市两级补贴资金选择其一）。安排设施农业机械设备补贴资金额原则上不超过本市农机购置补贴资金总额的三分之一。

根据我市农业生产需要，增加推广的适用农机具、累加补贴机具及额度标准为：

1.增加推广的适用农机具

（1）智能畜禽养殖器TW=XQ002型2750元/台（7克）；

（2）农用捕虫器GM950型186元/台；

（3）井关瓜菜移栽机械（2行）24000元/台；

（4）水稻育秧硬盘、瓜菜育苗硬盘、花卉穴盘和托盘，额度为50%，主要补贴农民专业合作社和从事农机作业的农业生产经营组织。

2.累加补贴机具额度

（1）累加补贴额度为42%：多功能电动撒肥机，其中中央财政资金补贴30%，市地方资金补贴12%。

（2）累加补贴额度为45%：主要为大棚耕地机（20-40马力）、粮食烘干机（1-5t），其中中央财政资金补贴30%，地方资金补贴15%。

（3）累加补贴额度为48%，畜牧水产养殖机械（主要补贴合作社），其中中央财政资金补贴30%，地方资金补贴18%。

（4）累加补贴额度为50%：主要为山区适用的先进小型4-15匹马力的（微耕机、耕整机、田园管理机、中耕机、开沟机、起垄机、手扶拖拉机）、小型水稻收割机（0.5≤喂入量≤0.8）和植保机械、太阳能灭虫灯、乘坐式割草机、割灌机、稻麦脱粒机，其中中央财政资金补贴30%，地方资金补贴20%。

（5）累加补贴额度为50%：主要为水稻育秧机插秧机、

瓜菜育苗机械、简易冷库，其中中央财政资金补贴30%，地方资金补贴20%，主要补贴农民专业合作社和从事农机作业的农业生产经营组织。

五、补贴对象和经销商的确定

（一）补贴对象。享受农机购置补贴的对象为全市的农牧渔民、农场（林场）职工、农民专业合作社和从事农机作业的农业生产经营组织。

允许补贴对象在海南省域内跨市县自主选择经销商购买补贴机具。补贴对象购买补贴机具后，拥有机具的所有权。

（二）经销商的确定及管理。农机购置补贴产品经销商由农机生产企业自主提出，报省农业厅汇总后统一公布（海南省农业厅信息网、三亚市农业局信息网、三亚市农机局信息网上有关农机购置补贴资料公布），供农民等补贴对象自主选择。

经销商要严格遵守《海南省农机购置补贴产品经销商管理暂行办法》（琼农字〔2012〕112号）等农机购置补贴政策各项规定，不得擅自提高补贴机具销售价格或降低补贴机具配置标准。要在经营服务场所醒目位置公布补贴机具配置和最高销售价格等相关内容，销售补贴机具时按照《全国农机购置补贴管理软件系统》操作要求录入购机人相关信息，开具海南省税务部门规定的合法发票，及时做好购机农户信息、工程建设合同、验收报告、照片等材料收集归档以及督促补贴机具生产企业通过农机购置补贴系统确认补贴机具等各项工作。市农机局和生产补贴机具的农机企业要加强对经销商的监督管理，发现违反农机购置补贴政策规定的要及时严肃处理。

六、申请农机购置补贴程序及补贴资金的兑付方式

2014年继续实行“全价购机、定额补贴、县级结算、直补到卡”的农机购置补贴资金兑付方式。

操作流程是：申请和确认→购机→验机（验收）→结算。

1.申请和确认。申请人凭身份证等身份有效证明（证件）向所在地的村委会、镇（区）农机管理部门提出申请，如实填写《海南省（三亚市）2014年农业机械购置补贴申请表》一式3份（附件2），审核作意见（领导签名、盖公章），送市农机局对申请人的资格条件等进行审查确认。市农机局按购机申请人购机的先后顺序，补贴资金指标先到先办、用完资金为止的方式办理。

2.购机。申请人凭《海南省（三亚市）2014年农机购置补贴申请表》（附件2）在规定的时间内向补贴机具经销商全价购买补贴机具（申请人与经销商签订喷滴灌节水设备、冷库工程建设合同等），经销商通过全国农机购置补贴管理软件系统采集申请人身份证等身份证明、人机合影并上传至省农机局。（附件2中的联系电话、身份证号码不得在软件系统中填写，注意以适当方式保存。）

3.验机（验收）。申请人应当于购机后20日内向市农机局提出验机申请，市农机局组织人员验机。喷滴灌节水设备、冷库等的验收由市农机局牵头，组织农业、财政等部门参加验收，并主动接受纪检监察、审计等部门监督。（详见附件4）

4.结算。经验机（验收）程序后，市农机局分期分批进行公示，再统一造表送市财政局审定，市财政局对报送的材料进行审查，并按确定的拨付方式在10个工作日内将补贴资金全额兑付到购机农民一卡（折）通账户或从事农机作业的农业生产经营组织、农民专业合作社账号。完成补贴机具结算后，市农机局及时做好农机购置补贴资料文件的归档。

申请设施农业机械设备购置建设补贴，除了执行本实施方案规定的操作程序外，还应当按照海南省农业厅《关于做好2010年设施农业机械设备购置补贴工作的通知》（琼农字〔2010〕74号）及其补充通知（琼农办〔2010〕59号）、《关于做好2011年简易保鲜冷藏设备购置建设补贴工作的通知》（琼农字〔2011〕98号）等有关规定办理。

七、农机购置补贴项目实施时间安排

2014 8月中旬，市农机局组织召开全市农机购置补贴工作会议，对农机购置补贴工作有关人员进行具体操作培训，并组织实施。农机购置补贴资金使用期限截至2014年12月30日。

八、其他要求

（一）加强领导，密切配合。市农机购置补贴工作领导小组要对补贴政策实施情况进行监管。农机购置补贴重要工作事项，经工作领导小组研究确定，并报省农业厅审核备案后实施。市农机局、市财政局要建立工作协调机制，完善农机购置补贴工作考核，注重工作绩效。

（二）规范操作，严格管理。通过全国农机购置补贴管理软件系统办理所有补贴操作手续，全面深入推进农机购置补贴信息网络化管理，实现与财政、纪检监察、审计等部门信息共享。市农机局要公平公正确定补贴对象，不得优亲厚友，不得违反规定人为设置购机条件；要按照规定组织完成补贴机具验收和编号喷印等项工作（喷滴灌节水设备、冷库等建设由经销商按统一规格、标准制作标志牌），并将购机者和补贴机具拍照存档以备检查。享受补贴的拖拉机、联合收割机须依法办理牌证；要认真贯彻《海南省农业厅关于加强农机购置补贴服务窗口建设的通知》（琼农办〔2013〕151号）精神，统一实施农机购置补贴窗口一站式服务；每月底将本市当月享受农机购置补贴的农户信息汇总表报省农机化管理局备案。

（三）公开信息，接受监督。要按照《海南省农业厅办公室关于做好农机购置补贴政策信息公开工作的通知》（琼农办〔2011〕101号）要求，把农机购置补贴政策实施情况列入政务公开和政务服务目录，及时分类整理、积极主动公开农机购置补贴实施方案、补贴额一览表、支持推广目录、补贴经销商名单、操作程序、举报电话、资金规模等内容，有关文件应向社会公开相关信息。要将农机购置补贴政策信息公开到村。每月30日定时、定点（农机网站或信息公开栏等）公布本市补贴资金执行进度和申请购机农户不涉及个人隐私部分信息（参见附件5），在年度补贴工作结束后，要以公告的形式将享受补贴的农户信息（参见附件6）和本市农机购置补贴政策落实情况报告在市人民政府网站或农业（农机）部门网站（页）上公布。享受补贴的农户信息包括：姓名，所购机具型号、单价、数量、产销企业、补贴额等；农机购置补贴政策落实情况报告包括：补贴机具种类、数量、受益农户数、补贴资金（含中央财政和地方财政）使用情况、取得的成效、主要做法和经验体会等内容。

市农机局要按规定设置信息公开固定网址或开通固定专栏。农机购置补贴信息公开固定网址或开通固定专栏的网址链接要主动提交上级农机主管部门统一对外发布，确保通过网址链接有效查询信息公开情况。

（四）严肃纪律，加强监管。市农机、市财政部门要切实把国务院“三个严禁”和农业部“四个禁止”、“八个不得”等要求落到实处。市农机、市财政部门积极配合省农机、省财政主管部门开展专项检查和重点抽查，严查套取补贴资金、乱收费等违规行为。要落实监督检查责任制，实行“谁核查、谁签字、谁负责”的责任追究制。市财政部门要按照《财政部关于切实加强农机购置补贴政策实施监管工作的通知》（财农〔2011〕17号）要求，主动参与农机购置补贴政策具体实施工作，积极会同农机等部门按照不低于购机农民10%的比例，对农民购机后实际在用情况进行抽查核实。生产企业应加强对经销商的管理，2014年12月25日前将全年销售核实情况（附件3：《海南省2014农机购置补贴机具供货核实表》）报送海南省农机化管理局。要严格按照有关补贴产品生产及经销企业监督管理有关规定，加强对补贴产品产销企业的监督管理，对参与违法违规操作的经销商，及时列入黑名单并予公布，被列入黑名单的经销商及其法定代表人永久不得参与补贴产品经销活动；对参与违法违规操作的生产企业要及时取消其补贴产品补贴资格，非法侵占补贴资金应足额退回财政部门；对违法违规性质恶劣的生产或经销企业，建议工商部门吊销其营业执照。涉嫌违法的，依照有关规定移交司法机关处理。

（五）落实职责，保障经费。市农机局要按照规定的程序和步骤认真做好调查摸底、标准测算、方案制定、动员部署、培训指导、信息公开等工作，确保农机购置补贴顺利实施。要在补贴申请、审核与审批、公示与核实、监管与督查、档案管理等方面，建立“谁办理、谁负责，谁核实、谁负责”的责任追究制度。市农机局主要负责政策宣传、补贴对象的确定、购机情况和补贴资金核实、公示、档案登记汇总及项目监管等，积极主动会同财政部门及时做好补贴资金兑现拨付工作。市农机局和经销商要加强和规范有关农机购置补贴档案的管理，并确保5年内能够随时查阅，购机人（申请人）的信息等发生变化时要及时变更。

为保证农机购置补贴政策顺利实施，市财政部门应保证必要的项目组织管理经费。市农机局农机购置补贴组织管理工作经费应占中央和地方财政补贴资金规模的3%―5%，主要用于政策宣传、建档、公示、监督检查、验机(验收)劳务等组织管理方面的支出。严禁挤占挪用中央财政补贴资金用于工作经费。

（六）加强宣传，搞好服务。各村委会、各镇（区）农机管理部门要高度重视，齐心协力，积极配合市农机局做好农机购置补贴宣传、初审、公示和参加检查验收等工作。市农机局要充分利用广播、电视、报纸、信息网络等媒体大力宣传，让广大农民了解购机补贴政策、程序等信息，积极做好农民、合作组织、企业的宣传引导、咨询解答工作，及时结算补贴资金，做到每月结算不少于一次，协调经销商做好补贴机具的供货工作。要统一印制农机购置补贴政策告知书，并宣传到村委会，并做到购机人手一份，防止电信诈骗案件发生。要加强补贴机具的质量监督，及时了解补贴机具的质量状况、企业承诺落实情况和购机者的反映，督促企业做好售后服务工作。市农机局投诉电话（88272798），及时调查处理购机者的投诉，保护好购机者的合法权益。要继续做好农机购置补贴信息报送工作，及时做好全年农机购置补贴项目执行情况总结，并于12月30日前，将全年农机购置补贴项目（包括地方财政安排的补贴）实施情况总结报告报送省农机化管理局。
