# 三亚市人民政府办公室关于成立空间管制规划编制工作领导小组的通知

三亚市人民政府办公室

关于成立空间管制规划编制工作领导小组的

通 知

各镇人民政府，各区管委会，市政府直属各单位：

《空间管制规划》的编制是今年市委市政府确定的61项改革事项之一，该规划是依托城市总体规划而进行的专项规划，涉及面广，包含对国土、海洋渔业、林业等多个部门规划的衔接，为加快推进规划编制基础资料收集，更好地衔接和落实各部门规划，我市决定成立《空间管制规划》编制工作领导小组，其组成人员及职责分工如下：

一、领导小组成员

组 长： 陈小亚 市政府副市长

副 组 长： 韦迪伟 市政府副秘书长

黄海雄 市规划局局长

成 员： 马育红 市发展改革委副主任

陈海兴 市财政局副局长

何海英 市国土环境资源局副局长

李恩祥 市海洋渔业局副局长

冯建东 市水务局副局长

陆仁彬 市林业局副局长

鲁正兰 市交通运输局副局长

领导小组下设办公室，负责领导小组日常工作，办公室设在市规划局，办公室主任由市规划局局长黄海雄担任，办公室副主任由市规划局副局长常成云担任。

二、主要职责

（一）领导小组主要职责

1.讨论确定规划编制单位、经费，对规划方案等重大事项进行审查。

2.协调和处理规划编制工作中存在的重大问题。

（二）领导小组办公室主要职责

1.负责领导小组各项审议会议的组织工作，包括会议记录和决议草案的起草，以及会议档案的整理和保存工作。

2.负责各部门的协调和联系工作，实现各部门规划的有效衔接。

3.负责与规划编制单位衔接，做好方案的编制、汇报、批前公示、批后公布及处理公众意见。

规划编制工作结束后，该机构自行撤销。
