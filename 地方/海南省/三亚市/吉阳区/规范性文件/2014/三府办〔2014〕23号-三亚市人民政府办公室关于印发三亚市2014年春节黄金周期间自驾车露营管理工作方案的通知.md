# 三亚市人民政府办公室关于印发三亚市2014年春节黄金周期间自驾车露营管理工作方案的通知

三亚市人民政府办公室

关于印发三亚市2014年春节黄金周期间

自驾车露营管理工作方案的通知

市政府直属各单位：

《三亚市2014年春节黄金周期间自驾车露营管理工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2014年1月21日

（此件主动公开）

三亚市2014年春节黄金周期间自驾车

露营管理工作方案

一、指导思想

为加强2014年春节黄金周期间我市自驾车露营管理工作，在总结2012年国庆和2013年春节黄金周两次自驾车露营管理工作经验的基础上，进一步创新管理模式，逐步采取由政府主导向政府引导、市场化运作模式的转变，即市政府不统一设置自驾车临时露营地，采取指导企业自主建设和经营管理露营地，政府相关部门负责做好申报审批、指导检查、舆论宣传、政策扶持等配套服务管理工作，科学应对自驾车露营旅游管理这一新课题。

二、组织领导

成立三亚市2014年春节黄金周期间自驾车露营管理工作领导小组，人员组成如下：

组　 长：许振凌　市政府副市长

副 组 长：何世刚　市政府副秘书长

周　俊　市政府副秘书长

周乃武　市综合行政执法局局长

成员单位：市综合行政执法局、市旅游委、市委外宣办、市公安局、市公安消防局、市园林环卫管理局、市财政局、市工商行政管理局、三亚地方税务局、市物价局、三亚海螺姑娘创意文化园有限公司。其中市综合行政执法局为牵头单位，其他成员单位为配合单位。

领导小组下设办公室，地点设在市综合行政执法局，办公室主任由市综合行政执法局局长周乃武兼任，联系电话：88595012。

三、露营地选址

2014年春节黄金周，我市仅在吉阳大道219号三亚海螺姑娘创意文化园内设置1处房车临时露营地，该露营地原则上仅用于接待房车，其他自驾车辆采取其他方式疏导分流。营地建设和经营管理的主体为三亚海螺姑娘创意文化园有限公司，园区总面积约35000㎡，露营地面积约20000㎡（长200m,宽100m），可接待大型房车约35辆，以下简称为“三亚海螺姑娘房车露营地”。

四、工作安排

市综合行政执法局：负责2014年春节黄金周期间全市自驾车露营管理工作的牵头组织；负责会同市旅游委，全程指导三亚海螺姑娘房车露营地参照《三亚市自驾车旅游露营地建设与服务规范》（DB46/T250-2013）进行建设和经营管理；负责查处自驾车乱停乱放和破坏市容环境的行为，会同市公安交警、园林环卫等部门开展自驾车专项检查执法工作。

市旅游委：负责会同市委外宣办开展舆论引导工作，为到三亚的自驾车游客提供多样化的旅游和住宿方式选择，多渠道分流自驾车露营游客；负责会同市综合行政执法局，全程指导三亚海螺姑娘房车露营地进行建设和经营管理；负责在露营地设立旅游宣传资料发放点，为游客提供景点景区介绍、一日游和宾馆酒店预定、旅游温馨提示等旅游宣传资料；当露营地发生旅游投诉事件时，及时介入处理，平息事态发展，营造和谐旅游环境。

市委外宣办：负责会同市旅游委开展舆论引导工作；春节前期，会同市旅游、综合执法等部门，利用网络、报纸等媒体，开展文明旅游宣传工作，营造文明旅游氛围；负责全程加强舆情监控，组织相关部门做好舆情应对工作。

市公安局：负责将三亚海螺姑娘房车露营地列入春节黄金周期间治安管理工作目标，加强露营地及周边路面的巡逻防控工作，防止“两抢一盗”及其他治安案件的发生；当露营地发生治安纠纷及案件时，快速出警，依法处理；市公安交警部门负责查处自驾车违反道路交通安全的行为，会同市综合行政执法、园林环卫等部门开展自驾车专项检查执法工作。

市公安消防局：负责将三亚海螺姑娘房车露营地列入春节黄金周期间消防安全管理工作目标，对露营地进行消防安全检查，及时消除消防安全隐患；当露营地发生火灾和其他事故时，快速出警,有效处置险情，确保游客人身财产安全。

市园林环卫管理局：负责教育劝阻自驾车在绿地和广场等公共区域乱停乱放的行为，会同市综合行政执法、公安交警等部门开展自驾车专项检查执法工作。

市财政局：负责审核和拨付露营管理工作相关经费。

市工商行政管理局、市地方税务局、市物价局：负责依法审批三亚海螺姑娘房车露营地露营收费相关申请，完备收费程序，确保露营收费合法。具体为：工商行政管理部门负责审批企业营业执照增加相应经营范围、物价部门负责进行收费价格备案和价格公示、地税部门负责核发服务性定额发票。

三亚海螺姑娘房车露营地：根据市政府相关部门的指导，参照《三亚市自驾车旅游露营地建设与服务规范》，自主建设和经营管理房车露营地，为房车游客提供水、电、卫生保洁、安全管理等基本服务，按照规定收取费用并办理相关手续。

五、工作要求

（一）高度重视，精心组织。今年春节黄金周我市自驾车露营管理模式的调整转变，是市政府在总结评估以往自驾车露营管理模式利弊的基础上，进一步转变政府职能和适应市场经济要求的重要举措。各责任单位要切实做到思想认识到位、组织保障到位、行动措施到位和责任落实到位，根据职能和分工，切实做好春节黄金周期间自驾车露营管理各项服务保障工作。

（二）加强协作，密切配合。各责任单位要站在全市高度，加强沟通、密切协作。牵头单位要精心布置和组织开展工作，主动与各配合单位沟通协商；各配合单位要积极配合牵头单位开展工作，形成工作合力，共同完成任务。

（三）积极探索，不断创新。要不断总结完善我市自驾车露营管理工作的经验做法，积极研究探索，创新管理模式，进一步适应市场发展需求和推动旅游业转型升级，实现自驾车露营旅游产业的健康持续发展，促进三亚国际旅游城建设。
