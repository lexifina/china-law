# 三亚市人民政府办公室关于印发三亚市开展重点项目“集中解决问题月”活动工作方案的通知

三亚市人民政府办公室

关于印发三亚市开展重点项目“集中解决问题月”

活动工作方案的通知

各镇人民政府，各区管委会，市政府直属各单位：

《三亚市开展重点项目“集中解决问题月”活动工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2014年9月10日

（此件主动公开）

三亚市开展重点项目“集中解决问题月”

活动工作方案

根据《海南省人民政府办公厅关于开展重点项目建设“集中解决问题月”活动的通知》（琼府办〔2014〕129号）（以下简称《通知》）精神，为进一步加快推进我市重点项目建设，确保我市重点项目2014年度投资计划圆满完成，按照省政府关于开展“集中解决问题月”活动的工作部署，特制定本方案。

一、目标任务

按照省政府工作部署，以更加开阔的视野、更加有效的措施、更加扎实的作风、更大的工作力度，深入开展重点项目建设“集中解决问题月”活动，以钉钉子精神协调解决项目存在问题。按照“竣工项目抓投产，续建项目抓进度，前期项目抓开工，储备项目抓落地”的工作思路，全力推进重点项目建设。

二、组织机构

成立三亚市深入开展重点项目“集中解决问题月”活动领导小组。

组 长：王 勇 市委副书记、市政府市长

常务副组长：吴岩峻 市委副书记、市政府常务副市长

副 组 长：各重点项目责任领导

成 员：市政府秘书长、副秘书长，市委宣传部、市委督查室、市政府督查议案室、市金融办、市政府政务服务中心、市发展改革委、市财政局、市审计局、市规划局、市国土环境资源局、市住房城乡建设局、市海洋与渔业局、市林业局、市交通运输局、市公安局、市综合行政执法局、市水务局、市科技工业信息化局、市教育局、市文化广电出版体育局、市土地储备中心、吉阳镇、凤凰镇、海棠湾镇、崖城镇、天涯镇、育才镇、河东区管委会、河西区管委会、海棠湾管委会、创意产业园管委会等单位负责人。

领导小组下设办公室，办公室设在市发展改革委，张利同志任办公室主任，负责日常协调工作。

三、组织实施

（一）集中排查阶段（9月3日至9月10日）

梳理排查重点项目存在问题。由市发展改革委梳理、汇总重点项目业主报送项目存在问题，于9月6日前上报市政府。对存在问题的重点项目由项目责任领导带队深入项目一线，对分工责任项目进行走访，会同项目业主逐一对项目存在问题进行确认和分析。对存在的问题，能够现场协调解决的，当场予以解决。对难以现场解决的难点问题，及时带回研究解决。责任单位负责将现场解决问题情况及需带回研究解决问题的情况（现场解决问题需明确责任单位及时间节点，带回研究解决问题需提出解决问题措施建议），于9月10前报送至市发展改革委，由市发展改革委汇总后上报市政府。

（二）研究部署阶段（9月11日至12日）

市政府组织“集中解决问题月”活动专题会议，集中研究解决项目现场带回来的项目存在问题。解决问题要找准原因，逐个提出解决方案和针对性的措施，并明确时间节点，限时限期处理。对于需要省级部门解决的问题，提出处理意见建议，集中上报省政府专题研究。

（三）解决落实阶段（9月13日至28日）

1.各有关部门要充分发挥职能作用，按照解决项目存在问题的责任分解，指派分管领导负责，安排得力干部主动上门，尽快予以协调解决。对于涉及多个部门的问题，由项目责任单位牵头，加强与各相关单位沟通，确保问题得到及时解决。

2.市政府督查议案室负责跟踪督办责任领导现场解决问题部分议定的事项；市委督查室负责跟踪督办市政府“集中解决问题月”活动专题会研究项目问题部分议定的事项。要及时掌握问题解决情况，特别是重点加强对久拖未解决问题的督办，确保每个问题都有处理结果，并将督办情况上报市政府。

3.项目责任单位需分别于9月12日、27日前将所负责的重点项目存在问题协调解决情况报送市发展改革委，由市发展改革委汇总后上报市政府，并将省重点项目解决问题情况报送省发展改革委。

四、工作要求

（一）贯彻落实省政府重点项目建设“集中解决问题月”活动。各部门要坚决按照《通知》精神，高度重视，把准问题、精心组织，根据各自职责制定具体的问题解决方案，方案实施过程中要明确任务，强化措施，狠抓落实，以一刻也不放松、一天也不耽误的精神，确保各项解决措施落到实处。

（二）集中精力协调解决重点项目存在的问题。各有关部门要进一步加大重点项目的协调解决力度和问责力度，针对重点项目存在的突出问题，尤其是第一轮全省重点项目专项检查中的有关问题，要实行每日研究解决一项问题、每周召开一次协调会、每半月进行一次总结，采取切实措施，逐项抓紧落实整改、协调解决，为迎接省政府第二轮专项检查做好充分准备。

（三）加大督促检查力度。市发展改革委要分别于9月13、28日前将重点项目存在问题协调解决情况上报市政府。市督查部门要加大督促检查力度，及时跟踪重点项目存在问题解决情况。认真制定督查方案，专门对此次开展重点项目建设“集中解决问题月”活动情况进行督查、抽查，随时跟踪掌握活动开展和协调解决实际问题的情况。

（四）做好宣传报道工作。市宣传部门要围绕重点项目建设，精心策划宣传内容，创新宣传方式，多角度、多层次、多形式组织宣传报道重点项目建设“集中解决问题月”活动。要充分发挥好网络、广播、电视、报刊等新闻媒体的宣传作用，以新闻、专题、专栏、专访等方式，宣传协调解决问题的先进典型，营造以项目为重点、项目为先，人人关心项目建设、人人支持项目建设的良好环境。
