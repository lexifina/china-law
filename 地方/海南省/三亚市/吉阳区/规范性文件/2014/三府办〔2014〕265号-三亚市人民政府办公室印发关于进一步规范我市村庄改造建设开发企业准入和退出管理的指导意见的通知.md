# 三亚市人民政府办公室印发关于进一步规范我市村庄改造建设开发企业准入和退出管理的指导意见的通知

三亚市人民政府办公室印发

关于进一步规范我市村庄改造建设开发企业

准入和退出管理的指导意见的通知

各区筹备组，各管委会，市政府直属各单位:

为进一步规范我市村庄改造的市场运作，加强开发企业的准入和退出管理，确保我市村庄改造建设工作有序稳步推进，根据《三亚市人民政府办公室关于印发三亚市城边村改造建设和环境改善工作指导意见的通知》（三府办〔2010〕171号）、《三亚市人民政府关于规范三亚市城边村改造建设和环境改善项目土地利用管理工作的指导意见》（三府〔2012〕221号）、《三亚市人民政府办公室关于城边村改造建设和环境改善工作补充指导意见的通知》（三府办〔2012〕333号）和《三亚市人民政府办公关于印发三亚市城中村和城边村改造实施方案》（三府办〔2013〕305号），特制定本指导意见。

一、村庄改造意向开发企业的准入条件

（一）具备独立的法人资格，有健全的组织机构和各项管理制度。属省外企业的，需承诺获得开发权后在我市注册独立的全资子公司作为项目公司；

（二）近三年没有违法和严重违规记录；

（三）具有实施村庄改造的资金实力（企业资本金不得低于项目总投资估算的30%），具备与该区域规划改造方案相符的建设或开发资质条件；

（四）中国500强企业、上市公司、大型国有企业、对三亚市城乡建设和公益事业有突出贡献的企业、具备城中村和城边村改造开发或“美丽乡村”建设经验的企业，符合以上条件且在经验技术、投融资等方面比较有优势的，可作为优先条件；

（五）法律、法规另有规定的，从其规定。

二、村庄改造意向开发企业的准入程序

（一）意向开发企业备案。凡符合准入条件且有意向参与三亚市村庄改造建设的企业，应向区政府提出申请，并出具企业资质、资金、融资担保、已开发项目情况等相关证明材料，由区政府审查通过报市城中村和城边村改造建设工作领导小组办公室备案后，对意向企业出具备案通知书。

(二)采取公开招商方式确定开发企业。区政府按市城中村和城边村改造建设工作领导小组下达的计划，以行政村或几个自然村为单位，明确改造范围和规划条件，经村（居）民会议2/3以上成员或者2/3以上村民代表同意并出具委托书，进行公开招商。已备案的意向企业依据村庄综合改造的规划条件和政策，出具企业资本金证明（不得低于项目总投资估算的30%）、编制概念性规划方案和安置补偿方案(包括产业引导和村民长期收益规划设置)响应招商。区政府设定评分标准和评定方式，经市政府批准组织专家和村（居）民代表参与评定，公开确定开发企业后，报市城中村和城边村改造建设工作领导小组办公室备案。

（三）签订项目开发协议书。确定开发企业后，区政府应与涉及改造用地村（居）委会（村民小组）、开发企业签订三方开发协议书，协议书中应约定建设进度和投资时序，设定项目投资保障金（不低于总投资概算的30%），确定共管账户及管理模式，明确企业退出条件。项目开发协议书签订后，区政府报市城中村和城边村改造建设工作领导小组办公室备案，并作出企业准入批复。

三、村庄改造开发企业的退出机制

区政府依照法律、法规和相关政策，在开发协议书中明确开发企业的退出条款，切实加强对项目开发建设的监督和管理。

（一）本指导意见下发后，新取得开发权的企业存在以下情形之一的，区政府、村（居）委会（村民小组）应责令其退出项目开发。

1．企业在取得开发权后，未按照招商方案的时间要求或在3个月内未签订项目开发协议书的；外省企业在取得开发权后，在6个月内未按承诺在我市注册独立的控股子公司作为项目公司的；

2．签订项目开发协议书后，在12个月内未按土地利用总体规划、城乡规划和产业发展规划要求以及安置标准和有关技术规定编制完成修建性详细规划方案和建筑方案的；

3．企业未按批准的村庄改造项目建设工程规划许可进行建设的；

4．企业未按“先安置后开发”的原则动工建设的；

5．修建性详细规划方案和建筑方案获批后，未按照协议书规定进度节点完成建设和投资额度的，即两年内应完成安置区的建设并累计投资达到总投资额的25%以上。

（二）本指导意见下发前，市政府已批准村庄改造试点项目（附件）开发企业的退出条件，参照三府办〔2012〕333号文件执行。

1.对村庄建设规划方案获批的城边村改造试点项目，开发企

业应制定实施方案，明确项目推进时间节点，保证项目修建性详细规划方案和建筑方案获批后两年内完成基础设施和安置区建设。对未按要求推进的开发企业，区政府、村（居）委会（村民小组）应责令其退出，并按开发企业准入程序重新确定开发企业。

2.对村庄建设规划方案尚未获批的村庄改造试点，应在2014年12月底前按土地利用总体规划、城乡规划和产业发展规划要求以及安置标准和有关技术规定编制完成修建性详细规划和建筑方案。在规定期限内，未能完成上述工作的，区政府、村（居）委会（村小组）应责令开发企业退出。在保持市政府批准的各区村庄改造试点数量不变前提下，可按准入程序重新确定开发企业或变更村庄改造试点。

对符合退出条件的村庄改造开发企业，村庄所在区政府、村（居）委会（村民小组）应在2015年1月20日前以书面通知或公告形式责令其退出试点项目建设，并报市城中村和城边村改造建设工作领导小组办公室备案。退出的开发企业，两年内不得参与村庄改造项目建设。

四、各部门职责分工

（一）区政府要按程序制定辖区村庄改造规划（规划条件）和年度实施计划，主导做好改造村庄的宣传发动、房屋丈量、边界确认、投资概算、拆迁安置、编制改造实施方案等工作。

区政府负责辖区内村庄改造开发企业准入和退出的管理工作；严格审查意向开发企业的准入条件，对村庄改造工作实施全过程进行考量，严格执行退出条件的要求。

（二）市城中村和城边村改造建设工作领导小组办公室负责

村庄综合改造工作全过程指导、监督和协调。

（三）市法制办和市发改委负责对区政府拟签订项目开发协议书等相关合同内容进行审查。

（四）市国土、规划、住建、综合执法等职能部门应加大支持力度，帮助开发企业和村委会（村民小组）依法加快办理土地、规划、建设、房产等有关手续，加强违章建筑管控和拆迁工作。

五、本《通知》由市城中村和城边村改造建设工作领导小组负责解释，联系电话：88986176。
