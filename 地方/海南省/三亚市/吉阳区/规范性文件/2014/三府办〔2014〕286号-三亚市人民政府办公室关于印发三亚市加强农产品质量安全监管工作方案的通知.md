# 三亚市人民政府办公室关于印发三亚市加强农产品质量安全监管工作方案的通知

三亚市人民政府办公室

关于印发三亚市加强农产品质量安全监管

工作方案的通知

各区筹备组，育才生态区管委会，市各相关单位:

《三亚市加强农产品质量安全监管工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2014年10月28日

（此件主动公开）

三亚市加强农产品质量安全监管工作方案

为深入贯彻落实《海南省政府办公厅关于加强农产品质量安全监管工作的通知》（琼府办〔2014〕68号）精神，切实维护人民群众身体健康和生命安全，结合我市实际，特制订本方案。

一、指导思想

以党的十八大精神为指导，全面贯彻落实《食品安全法》、《农产品质量安全法》等法律法规，围绕监管体系建设、投入品监管、标准化生产、检验检测、质量安全执法和长效机制建设，全面落实农产品质量安全全程监管工作，巩固和提升我市农产品质量安全水平，促进农业产业健康、可持续发展，确保不发生重大农产品质量安全事件，切实维护人民群众“舌尖上的安全”。

二、工作目标

围绕努力确保不发生重大农产品质量安全事件总目标，着力构建和完善市、区（农场）、村三级农产品质量安全监管体系，建立健全相关责任制度和监管制度；强化执法、监测体系建设，推进质量监管和农技服务进村入户下田头；继续深化农产品质量安全专项整治，消除风险隐患；大力推进农业标准化建设，确保全市农产品农药残留检测合格率达到98％以上，畜产品检测合格率达到99％以上，水产品检测合格率达到97％以上。

三、工作重点

（一）进一步落实监管责任。

1.落实属地管理责任。要落实区、农场对农产品质量安全负总责和属地管理的责任，加强组织领导和工作协调，把农产品质量安全监管纳入重要议事日程，在规划制定、力量配备、条件保障等方面加大支持力度。要将农产品质量安全监管纳入绩效考核范围，特别是要建立农产品质量安全监管协同机制，将农产品质量安全监管重点落实到生产基地、收购、贮运、加工和流通环节。要用最严谨的标准、最严格的监管、最严厉的处罚、最严肃的问责，确保环境安全、产品安全、产业安全。（责任单位：各区筹备组、育才生态区管委会，各国营农场）

2.落实部门监管责任。按照省政府机构改革和职能转变的工作要求，统筹建立农产品质量安全和食品药品监管工作衔接机制，健全部门间联合协作机制，努力构建“横到边、纵到底”的农产品质量安全全程监管网络。农业部门负责种植业、畜牧业食用农产品进入批发、零售市场或生产加工企业前的质量安全监管，负责兽药、饲料、饲料添加剂和职责范围内的农药、肥料等其他农业投入品的质量及使用的监督管理，负责畜禽屠宰环节、生鲜乳收购环节质量安全监督管理；海洋渔业部门负责食用水产品进入批发、零售市场或生产加工企业前的质量安全监管；食品药品监管部门负责食用农产品（含水产品）进入市场或加工企业后的监管；粮食部门负责粮食收购、储存、运输、出库环节的监管；出入境检验检疫部门负责农产品进出口环节的监管工作。国土、环保、农业等部门要组织开展产地污染状况普查、监测和治理，把好生产环境安全关。（责任单位：市农业局、市海洋渔业局、市食品药品监管局、市国土环境资源局、市粮食局、三亚出入境检验检疫局）

3. 落实网格化岗位责任。按照冬季瓜菜质量安全网格化监管工作要求，各监管单位要落实监管人员，划分责任区，明确监管职责和范围，落实监管责任书，确保各监管对象、各环节、各节点都有具体负责人。各网格化岗位责任人要认真履行监管工作职责，抓好本区域内的农业投入品使用监督、农产品质量安全监测、基地农产品准出检测，督促指导农产品生产的档案建立，开展农产品质量安全检查、矛盾纠纷调处、事故应急处置等工作，切实担负起农产品从生产环节到进入批发、零售市场或生产加工企业前的质量安全监管职责。（牵头单位：市农业局；责任单位：各区筹备组、育才生态区管委会，各国营农场）

4.落实生产经营者主体责任。强化“农产品生产者第一责任人”的责任，各区政府及相关部门要采取行之有效的办法，将责任落实到每个生产单位和农户，各生产主体要主动接受农产品质量安全监督管理，积极配合相关执法检查工作的开展，自觉加强农产品质量控制。农业品生产企业和农民专业合作组织要如实建立基地农产品生产档案，开展农产品质量自律性检测。对于不严格落实农产品质量安全管理要求的生产经营主体，一律不得享受扶持、奖励等优惠政策。对农产品生产违法违规行为予以严厉打击。（牵头单位：市农业局、市海洋渔业局；责任单位：各区筹备组、育才生态区管委会，各国营农场；配合单位：市食品药品监管局、三亚市工商行政管理局、市粮食局）

（二）进一步强化质量监管

1.强化质量安全监管。督促农产品生产者到正规农资店购买农资并科学施用。严格执行农药、兽药使用安全间隔期（休药期）和生产档案记录等制度，推广物理防治、生物防治等农业综合防治技术，鼓励开展病虫害专业化统防统治。强化生产者安全用药意识，督促和指导生产者科学合理使用农药，严格执行农药使用安全间隔期规定。探索建立农产品收贮运主体和贮运设施设备备案登记管理制度，建立健全收、贮、运环节的进货查验、查验记录、自查自检和无害化处理等制度。加强对畜禽养殖、屠宰等环节防疫条件的审核和整顿，健全病死畜禽无害化处理的长效机制。加强畜禽屠宰执法，严厉打击私屠滥宰等违法违规行为。推行农产品质量安全信息化管理，建立以组织机构代码实名制为基础，以物品编码管理为溯源手段的农产品质量安全监管和追溯信息平台，并与农产品进入市场或加工企业后的追溯平台对接，实现从农田到餐桌的全程有效监管。（牵头单位：市农业局、市海洋渔业局；责任单位：各区筹备组、育才生态区管委会，各国营农场；配合单位：市财政局、市科技工业信息化局、市商务局、市公安局、三亚市工商行政管理局、市食品药品监管局、市粮食局）

2.推行农产品产地准出和市场准入。实施农产品产地准出制度，各区、农场要以企业基地、合作社、村委会和其他农产品生产主体为依托，督促和引导农产品生产企业、农民专业合作组织、重点农产品生产基地开展产品质量自律性检测或委托检测，严把农产品基地准出关口。以“三品一标”（无公害农产品、绿色食品、有机食品和地理标志农产品）认证企业以及新型农业经营主体为重点，力争2-3年内，在全市80％以上“三品一标”认证企业以及注册登记的新型农业经营主体建立起主要食用农产品产地准出制度。推行农产品市场准入制度，加强农产品市场准入管理。食品药品监管部门要严格落实市场开办方的食品安全监管责任，指导生产经营者做好索票索证，依法监督生产经营者履行进货查验、查验记录等义务；制定市场主体农产品质量安全检测室规范和标准，推动市场开办者建设农产品质量安全检测室，落实农产品入市前检测主体责任，力争2-3年内，在主要农产品批发市场、配送中心、超市和农贸市场建立起主要食用农产品市场准入制度。建立健全农产品产地准出与市场准入有效衔接机制。农业、渔业部门要加强产地检测和畜禽、水产品产地检疫，督促农产品生产经营者加强生产标准化管理和关键点控制，落实农产品入市前检测主体责任，把好农产品质量安全关。（牵头单位:市食品药品监管局、市农业局、市海洋渔业局；责任单位: 各区筹备组、育才生态区管委会、各国营农场；配合单位：三亚市工商行政管理局、市公安局、市科技工业信息化局、市粮食局）

3.强化农业投入品监管。建立农业投入品经销台账制度、质量安全承诺制度，规范农业投入品经营。统筹推进农药、肥料、种子、兽药、饲料和饲料添加剂等投入品生产经营监管，提高准入门槛，畅通经营渠道。深入开展专项整治，加强农业综合执法，努力提高农业投入品质量整体水平。到2015年，全市90％以上的农业投入品经营企业要落实农业投入品经营诚信档案和购销台账，95％以上的农药经营门店要落实农药实名购买制度。建立农业投入品质量追溯、“黑名单”等制度，对问题企业严格落实行业退出和禁入机制。（牵头单位：市农业局、三亚工商行政管理局；责任单位：各区筹备组、育才生态区管委会，各国营农场；配合单位：市公安局、市科技工业信息化局、市商务局、市供销社）

4.加强产地环境安全监管。开展农产品产地环境质量监测与保护，实施农产品产地安全生产区域管理。在主要农产品生产区域设定产地环境监测点，开展定期定点监测，掌握产地环境质量变化动态，加强对农业面源污染监测与管理，推行农业生产废弃物、污染物的集中无害化处理，防止造成农产品产地环境污染，积极推进农产品产地环境污染的治理修复工作。（牵头单位：市农业局、市海洋渔业局、市国土环境资源局、市水务局；责任单位：各区筹备组、育才生态区管委会、各国营农场）

（三 ）进一步推进标准化生产

1.健全农业产地标准。各区筹备组、各国营农场及相关部门要强化规划指导，加快制定完善农业标准化发展规划，力争用3-5年时间，建立起以整治田块、改良土壤、建设灌排设施、整修田间道路、完善农田防护与生态环境保持、配套农田输配电设施、加强农业科技服务、强化后续管护为主要建设内容的高标准农田基础设施建设标准体系。要集中连片建设高标准农田，配套完善水、电、路设施，改善耕作条件，提高优质耕地比重。（牵头单位：市发展改革委、市财政局、市农业局、市国土环境资源局；责任单位：各区筹备组、育才生态区管委会，各国营农场；配合单位：市水务局）

2.加快标准化推广。坚持绿色生产理念，各区、农场和相关部门要将农业标准化作为发展现代农业的重要举措，大力推进农业标准化生产建设；积极建立以优势农产品、“菜篮子”产品、“三品一标”产品为主的农产品生产标准体系，以农产品采收、保鲜、运输、粗加工等环节为主的农产品收贮运标准体系，实现农业产业升级、农民增收和农产品质量安全水平提升。到2015年，种养大户、家庭农场、专业合作社、农业产业化龙头企业等新型经营主体要率先实现农业标准化生产经营。要按照“选好一个项目、支持一个主体、执行一套标准、形成一片示范，带动一个龙头、创立一个品牌、致富一方百姓”的模式，深入推进“菜篮子”标准化生产示范基地和出口农产品质量安全示范区建设。（牵头单位：市农业局、市海洋渔业局、三亚出入境检验检疫局；责任单位：各区筹备组、育才生态区管委会，各国营农场）

3.加强品牌建设。要将农业标准化、规模化与品牌化有机结合起来，努力打造一批具有区域优势的优质品牌农产品。鼓励和支持农产品生产企业、农民专业合作组织、大户积极开展无公害农产品产地认定和“三品一标”农产品质量认证，不断壮大认证农产品生产规模。强化对无公害农产品、绿色食品、有机农产品、地理标志农产品的证后监管，对获得认证的农产品品牌以及品牌企业，要给予资金支持和政策扶持。要加大农产品品牌宣传推广力度，扩大品牌农产品的影响力和市场占有率；坚决打击假冒行为，营造良好的“三品一标”农产品认证、生产、经营、消费氛围。（牵头单位：市农业局、市海洋渔业局；责任单位：各区筹备组、育才生态区管委会，各国营农场；配合单位：市财政局、三亚市工商行政管理局）

（四）进一步提升监管能力

1.完善体系建设。按照有机构、有职能、有人员、有办公场所、有检测设备、有工作经费的工作要求，继续抓好基层农产品质量安全监管体系建设，根据工作实际需要，加强各区、国营农场农产品质量安全监管检测人员配备，提高工资待遇，切实解决其后顾之忧，加强村级农产品质量监管员队伍建设和管理，充分发挥现有村级农产品质量监管员的作用，夯实田间生产的监管基础。进一步加强机制建设，实现监管、检测以及执法体系的协调高效运转。（牵头单位：市发展改革委、市财政局、市农业局；责任单位：各区筹备组、育才生态区管委会，各国营农场）

2.加强能力建设。制定政策措施，加大投入，加强检测机构建设，加快检测机构资质认证和考核，提高检测机构检测能力，规范检测行为。要抓好市、区、村三级监管、检测和执法人员培训。加大监管执法、监测预警、质量追溯等管理信息现代化的投入力度，强化监管信息收集、汇总、分析和发布。（责任单位：各区筹备组、育才生态区管委会，各国营农场，市农业局、市海洋渔业局、市食品药品监管局）

3.强化风险防控。要加强农产品质量安全风险监测、评估和监督检查，排查各类风险隐患，提高风险防范、监测预警和应急处置能力。各区筹备组、各国营农场要认真制定和实施本辖区的风险监测方案，扩大监测品种和监测范围，对本辖区主要农产品、水产品、“菜篮子”产品和农田土壤环境质量进行常态化风险监测，及时发现和防范各类系统性风险。要制定和完善农产品质量安全应急预案，组织农产品质量安全应急队伍，开展形式多样的预案演练，提高应对和处置农业各类风险的能力。（牵头单位：市农业局、市海洋渔业局；责任单位：各区筹备组、育才生态区管委会，各国营农场；配合单位：市食品药品监管局、市国土环境资源局）

四、保障措施

（一）加强组织领导。各区、农场要成立农产品质量安全监管工作领导小组和农产品质量安全事故应急指挥机构，组织协调农产品质量安全监管与事故的应急处置工作，统筹农产品质量安全监管工作衔接机制，细化部门职责，明确农产品质量安全监管各环节工作分工，避免出现监管职责不清、重复监管和监管盲区，形成监管合力。要努力强化区（场）、村、组级农产品质量安全监管人员履行职责意识与能力，扎实推进各项工作的落实。（牵头单位：市农业局、市海洋渔业局、市食品药品监管局；责任单位：各区筹备组、育才生态区管委会，各国营农场）

（二）健全投入机制。建立健全市、区两级投入保障机制，将农产品质量安全监管、检测、执法和农业标准化等工作经费纳入各级财政预算，切实加大财政投入力度，尽快配齐必要的检验检测、执法取证、样品采集、农业标准化、质量追溯、信息化管理等设施设备，保证必要的培训经费。加大市、区农产品质量安全监管、检测机构的设施设备投入和资金支持，完善与履行职责相适应的工作条件。（牵头单位：市财政局；责任单位：各区筹备组、育才生态区管委会，各国营农场；配合单位：市农业局、市海洋渔业局、市食品药品监管局）

（三）完善考核机制。各区筹备组、各国营农场要切实将农产品质量安全主要指标以及资金投入、体制机制建设等重要内容纳入绩效考核范围。农业、海洋渔业、食品药品监管等部门要加大工作完成情况的督查督办力度，适时组织开展专项督查活动。（牵头单位：市农业局；责任单位：各区筹备组、育才生态区管委会，各国营农场；配合单位：市财政局、市海洋渔业局、市食品药品监管局）

（四）强化责任追究制。各区筹备组、各国营农场要认真落实《中华人民共和国农产品质量安全法》，强化农产品质量安全监管工作的组织领导。各有关部门要各司其职，各负其责，相互配合，形成农产品质量安全监管合力，共同推动农产品质量安全监管工作有效开展。依法强化农产品生产者和企业农产品质量安全第一责任人的职责，将农产品质量安全监管责任落实到每个生产单位和农户。进一步建立和完善农产品质量安全责任制和问责制，把责任分解到单位，分解到责任人。因监管不力而发生重大农产品安全事件的，对所涉及到的相关负责人和责任人，依照有关法律法规和党纪政纪严肃处理。（牵头单位：市监察局；责任单位：各区筹备组、育才生态区管委会，各国营农场；配合单位：市农业局、市海洋渔业局、市食品药品监管局）
