# 三亚市人民政府办公室关于印发三亚市2014年水稻生产机械插秧作业补贴实施方案的通知

三亚市人民政府办公室

关于印发三亚市2014年水稻生产机械插秧

作业补贴实施方案的通知

各镇人民政府，各区管委会，市政府直属各单位：

《三亚市2014年水稻生产机械插秧作业补贴实施方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2014年3月4日

（此件主动公开）

三亚市2014年水稻生产机械插秧作业

补贴实施方案

为了贯彻落实2014年中央一号《关于全面深化农村改革加快推进农业现代化的若干意见》文件精神，切实保障我市粮食安全生产，推进我市水稻生产全程机械化进程，鼓励农民使用先进机械育插秧技术，改变传统的劳动生产方式，提高我市水稻机械化生产作业水平，制定本实施方案。

一、指导思想

以全面深化农村改革加快推进农业现代化发展战略为指导，紧紧围绕农业节本增效、粮食增产、农民增收为中心目标，增强农业综合生产能力，提高农业机械化作业水平，加大水稻生产机械插秧作业过程补贴力度，调动农民使用先进机械化育插秧技术的积极性，促进农业现代化发展和我市水稻生产全程机械进程，保障我市粮食安全。

三、工作内容

（一）补贴对象

补贴对象为三亚市户籍的农民、市地方农场（林场）职工、直接从事农业生产经营组织、取得当地工商行政管理部门登记的农民专业合作社。

（二）补贴标准

为推进现代农业发展生产方式转变，提高农业机械化作业水平，农民使用机械育秧、插秧机械作业，补贴标准为：机械育秧每亩补贴30元、机械插秧每亩补贴80元。在申请机械育插秧补贴田亩超过计划指标时，按照先后顺序，先到先得，补完为止。

（三）申报程序

1．农户（村民小组）与合作社签订作业合同，面积基本连片。

2．作业完成后，农户（村民小组）与合作社在插秧地点现场验收，填报《水稻生产机械插秧作业补贴资金申请表》（附件2）一式三份，双方确认作业面积、农户在插秧地点拍照存档，签名盖章。

3．合作社将双方确认的《水稻生产机械插秧作业补贴资金申请表》送村委会审核作意见盖章后，再将《水稻生产机械插秧作业补贴资金申请表》（纸质、电子表和田间插秧照片）一并报送市农机局报账、存档备案。

（四）公示及补贴方式

合作社将村委会核实盖章后的《水稻生产机械插秧作业补贴资金申请表》送市农机局审核，并公示七天无异议后，采取直补方式，将机械育秧、插秧机械作业补贴资金直接划拨给农机作业服务组织。

（五）奖励标准

为鼓励农民专业合作社或农业生产经营服务组织，提高机插秧作业者的积极性，将年度机插秧作业面积奖励标准分为3个标档：

1．经营服务面积1000亩以上（含1000亩），每亩奖励5元。

2．经营服务面积5000亩以上（含5000亩）每亩奖励7元。

3．经营服务面积10000亩以上（含10000亩）每亩奖励10元。补贴、奖励资金从市财政年度预算安排中列支。

四、有关要求

（一）加强项目组织领导

各镇政府、区管委会要重视水稻生产机械插秧作业补贴项目工作，要安排专人负责，积极配合市农机局做好机械插秧宣传示范推广工作。一是各镇要组织召开各村委会负责人会议传达《三亚市2014年水稻生产机械插秧作业补贴实施方案》精神，同时利用村委会墙报宣传水稻生产机械育插秧补贴惠民政策，切实把惠民补贴政策宣传到村落实到户。二是各镇政府把任务分解到各村委会，村委会在把任务落实各村民小组，村民小组根据生产任务组织农户连片签订机械插秧作业合同。三是各村委会要积极配合合作社机械育秧、插秧作业面积的审核工作。四是市农机局在工作领导小组的领导下组织实施，协调农机作业服务组织开展农机作业及监督管理，跟踪做好水稻生产机械插秧作业面积的核实和做好项目实施档案管理。

（二）明确工作责任

明确任务指标。根据各镇每年水稻生产实际，全市每年水稻机插秧计划指标为29800亩，其中海棠湾镇2800亩、吉阳镇4000亩、凤凰镇6500亩、天涯镇3500亩、崖城镇10500亩、育才镇2500亩。

（三）强化补贴资金使用管理

各镇政府要严格按照补贴对象和相关要求，切实把好审核关，对于申报补贴资金中弄虚作假、虚报作业面积、套用财政资金等违规行为，追回补贴资金，情节严重的追究有关部门及相关人员的责任。市农机局要加强补贴资金使用与管理，做到专款专用，不得挤占和挪用。
