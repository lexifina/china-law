# 三亚市人民政府办公室关于印发三亚市2014年扶贫工作实施方案的通知

三亚市人民政府办公室

关于印发三亚市2014年扶贫工作实施方案的通知

各镇人民政府，市政府各有关单位：

《三亚市2014年扶贫工作实施方案》已经市政府同意，现印发给你们，请认真贯彻执行。

三亚市人民政府办公室

2014年3月27日

（此件主动公开）

三亚市2014年扶贫工作实施方案

为全面贯彻落实我市五年扶贫开发规划（2012—2016年），按照中央和省扶贫工作会议精神要求，巩固和发展扶贫成果，挖掘扶贫资源，整合各类扶贫力量，促进贫困地区经济健康持续发展和农民持续增收，现结合我市实际，制定本方案。

一、指导思想

以科学发展观为指导，认真贯彻党的十八大精神，按照市六届人大四次会议要求，结合省扶贫开发工作会议提出的农村扶贫开发工作的意见、目标、任务和要求，以“政府主导、科学规划、城乡统筹、创新机制、精准开发式扶贫”为方针，按照“连片开发、整体推进、规划到村、扶贫到户”的原则，以“贫困农民增收、稳定解决温饱、尽快脱贫致富”为目标，以培育贫困地区特色优势产业、改善贫困农民生产生活条件、提升贫困农民自我发展能力、提高劳动力素质为重点，整合资金，加大力度，强化措施，加快贫困地区农民脱贫致富步伐，为建设更加卓越和谐的三亚增光添彩。

二、工作目标

按照市政府提出的农民人均年纯收入3000元的新扶贫标准，实施以“整村推进”为重点的贫困村基础设施建设，扩大产业化扶贫覆盖面，开展扶贫对象培训等工作，实现全市3545贫困人口脱贫。

三、工作任务

（一）基础设施类

1.硬板化村道。

（1）在崖城镇长山村至三更村、吉阳镇三郎村至罗蓬村修建村道3.2公里，解决4个村1700人交通难问题。（责任单位：市交通运输局，协办单位：崖城镇、吉阳镇）

（2）在育才镇那受村、明善村修建村道4.7公里，解决2个村3000人交通难问题。（责任单位：市农工委，协办单位：育才镇）

（3）在育才镇青法村委会一组、那会村委会福来组修建村道1.9公里，解决2个村395人交通难问题。（责任单位：育才镇，协办单位：青法村、那会村）

（4）在崖城镇三公里村委会修建村道20公里，解决1个村1600人交通难问题。（责任单位：崖城镇，协办单位：三公里村）

2.修建桥梁。在凤凰镇抱前、台楼、立新、扎南村委会、崖城镇抱古村委会修建桥梁11座共334.88米，解决5个村农民交通难问题。（责任单位：市交通运输局，协办单位：凤凰镇、崖城镇）

3.人畜饮水。在凤凰镇扎南村委会加跃、南进、加油村民小组引进山泉水及配套消毒设备，解决1个村200户930人畜饮水不安全问题。（责任单位：市水务局，协办单位：凤凰镇）

4.生产用水。

（1）在育才镇龙密、马脚、雅林村委会开展水渠改造工程，解决3个村1302.78亩生产用水问题。（责任单位：育才镇，协办单位：龙密村、马脚村、雅林村）

（2）在凤凰镇抱前村委会三翁至三孟修建沟渠1.3公里，解决1个村300亩田地生产用水问题。（责任单位：凤凰镇，协办单位：抱前村）

5.住房保障。完成育才镇、崖城镇农村危房改造605户，解决2个镇贫困村605户2600人住房难问题。（责任单位：市住建局，协办单位：育才镇、崖城镇）

6.电力保障。在育才镇明善村委会三、四组台区开展改造工程，抱安村委会抱安一组#2台区开展新建工程，崖城镇抱古村委会抱古四组、三更村委会上中下村、三公里村委会台区开展改造工程，解决5个贫困村农户用电电压低问题。（责任单位：三亚供电局，协办单位：育才镇、崖城镇）

（二）经济发展类

1.农业种植。

（1）在吉阳镇罗蓬、大茅田洋建立占地面积200-500亩的无机农业种植点，扶持1个镇贫困农户发展农业生产。（责任单位：吉阳镇，协办单位：罗蓬村、大茅村）

（2）在育才镇、凤凰镇、崖城镇、吉阳镇、天涯镇种植牛大力120亩、橡胶900亩、槟榔540亩、菠萝蜜550亩、豆角种子2778亩，扶持5个镇贫困农户发展热带经济作物和瓜菜产业。（责任单位：市农业局，协办单位：育才镇、凤凰镇、崖城镇、吉阳镇、天涯镇）

2.农业生产资料。为育才镇、凤凰镇、崖城镇、吉阳镇、天涯镇贫困农户提供复合肥83吨，扶持5个镇贫困农户发展农业生产。（责任单位：市农业局，协办单位：育才镇、凤凰镇、崖城镇、吉阳镇、天涯镇）

3.农业养殖。

（1）在育才镇贫困村养猪78头，扶持贫困农户发展养殖业。（责任单位：育才镇，协办单位：育才镇各村委会）

（2）在天涯镇贫困村养猪278头、养鹅1750只、养鸡3500只，扶持贫困农户发展养殖业。（责任单位：天涯镇，协办单位：天涯镇各村委会）

（3）为育才镇、凤凰镇、崖城镇、吉阳镇、天涯镇贫困农户提供猪苗4000头、鹅苗10000只、阉鸡苗25000只，扶持5个镇贫困农户发展养殖业。（责任单位：市农业局，协办单位：育才镇、凤凰镇、崖城镇、吉阳镇、天涯镇）

4.林业生态经济兼用林。在南丁村、立新村、扎南村、抱龙村、台楼村、抱安村、马脚村、明善村、那会村、好甘岭种植生态经济兼用林6095亩，扶持10个村发展林业经济。（责任单位：市林业局，协办单位：育才镇、凤凰镇、吉阳镇）

5.村庄绿化。在凤凰镇、吉阳镇绿化宝岛村庄面积300亩，提高2个镇村庄绿化和农民增收的双重效益。（责任单位：市林业局，协办单位：凤凰镇、吉阳镇）

（三）社会服务类

1.校舍建设。

（1）在凤凰镇抱龙村抱龙小学新建综合楼1050平方米和室外建设，崖城镇抱古村抱古小学新建综合楼2000平方米，改善2个村学校办学条件。（责任单位：市教育局，协办单位：凤凰镇、崖城镇）

（2）在育才镇、凤凰镇、崖城镇实行农村义务教育阶段寄宿生生活费补助，资助人数1732人，解决14个村1732名小学生在校生活问题。（责任单位：市教育局，协办单位：育才镇、凤凰镇、崖城镇）

2.卫生室建设。在17个贫困村的20个卫生室购买20套基本医疗设备，提高20个村卫生室标准化建设水平。（责任单位：市卫生局，协办单位：育才镇、崖城镇、凤凰镇、吉阳镇）

3.农村医疗保险。

（1）完成19个贫困村3545人的医疗保险，解决医疗保障问题。（责任单位：市社保局，协办单位：育才镇、凤凰镇、崖城镇、吉阳镇）

（2）完成19个贫困村1700人代交医疗保险，解决医疗保障问题。（责任单位：市民政局，协办单位：育才镇、凤凰镇、崖城镇、吉阳镇）

4.农村养老保险。完成19个贫困村10272人养老保险，解决养老问题。（责任单位：市农保局，协办单位：育才镇、凤凰镇、崖城镇、吉阳镇）

5.农村低保。将19个贫困村符合条件的1700人纳入低保，解决低保问题。（责任单位：市民政局，协办单位：育才镇、凤凰镇、崖城镇、吉阳镇）

6.文化设施。在崖城镇抱古村委会抱古四组、白河二组、三组、五组新建篮球场4个，丰富1个村500人业余文化生活。（责任单位：市农工委，协办单位：崖城镇）

7.环卫管理。在凤凰、崖城、吉阳镇建设5座垃圾转运站，改善村镇环境卫生状况。（责任单位：市园林环卫局，协办单位：凤凰镇、崖城镇、吉阳镇）

（四）技能培训类。

1.卫生员培训。对育才镇、凤凰镇、吉阳镇、崖城镇17个贫困村的20名乡村医生进行基本药物、抗菌药物使用、中医适宜技术等培训，提高20名乡村医生的理论和实践水平。（责任单位：市卫生局，协办单位：育才镇、凤凰镇、崖城镇、吉阳镇）

2.劳动力转移就业培训。在凤凰镇5个贫困村培训173人次、吉阳镇罗蓬村培训51人次、崖城镇3个贫困村培训153人次，育才镇10个贫困村培训303人次，提高19个贫困村680人次就业竞争力，促进农村劳动力转移就业。（责任单位：市人力资源开发局，协办单位：育才镇、凤凰镇、吉阳镇、崖城镇）

3.扶贫干部学习培训和贫困村农民实用技术培训。

（1）在育才镇举办贫困农民农业实用技术培训，提高贫困农民382人次农业实用技术水平。（责任单位：育才镇，协办单位：育才镇各村委）

（2）在吉阳镇举办贫困农民农业实用技术培训，提高贫困农民500人次农业实用技术水平。（责任单位：吉阳镇，协办单位：吉阳镇各村委）

（3）在天涯镇举办贫困农民农业实用技术培训，提高贫困农民500人次农业实用技术水平。（责任单位：天涯镇，协办单位：天涯镇各村委）

（4）组织负责扶贫工作的各级干部学习培训和举办贫困农民农业实用技术培训500人次，提高扶贫系统干部扶贫开发管理水平和贫困农民农业实用技术水平。（责任单位：市农业局，协办单位：育才镇、凤凰镇、崖城镇、吉阳镇、天涯镇）

四、保证措施

（一）加强领导，落实责任。各单位要高度重视扶贫工作，把扶贫工作作为全面落实科学发展、构建卓越和谐三亚的一项重要任务，列入议事日程，主要领导要亲自抓，分管领导具体抓，切实加强组织领导。责任单位和协办单位要明确主体责任和从属责任，密切配合、各司其责、形成合力，为今年的扶贫开发工作提供强大的组织保障和内在动力。

（二）创新机制，精准帮扶。各单位要探讨建立驻村工作队（组）制度。可分期分批安排，确保每个贫困村都有驻村工作队（组），每个贫困户都有帮扶责任人。把驻村入户扶贫作为培养锻

炼干部特别是青年干部的重要渠道。深入分析致贫原因，逐村逐户制定帮扶措施，集中力量予以扶持，切实做到扶真贫、真扶贫，确保在规定时间内达到稳定脱贫目标。

（三）明确任务，认真组织。各单位要按照责任分解的任务，深入实际，全面细致掌握情况，责任单位要与协办单位相互沟通研究，制定可行性的工作方案，组织力量，按计划分步骤强力推进，确保任务顺利实施，落到实处。

（四）强化措施，狠抓落实。各单位要按照市政府提出的“六个一”工作责任制度，即按“一个项目、一个分管领导、一个责任单位、一个工作班子、一个倒排工期计划、一竿子抓到底”的模式，做到领导到位、责任到位、资金到位、组织实施到位，保证按时按质按量完成计划任务。

（五）监督管理，考核达标。市政府要把全年的扶贫工作纳入责任单位年度为民办实事、办好事的工作内容，坚持公开、公平、公正的原则，加强扶贫项目、资金管理，建立健全扶贫项目公告公示制度、招投标制度、大宗物资设备集中采购制度，建立工程监理制度、项目竣工验收制度、审计制度、资金报账制度等。各单位要保证工作经费，扶贫办在预算内专项扶贫经费中安排5%工作经费用于扶贫项目有序运作、管理和监督，审计、监察部门按要求进行督查，年终进行考核，对工作任务达标的单位予以表彰，对措施不力、进展缓慢的单位予以通报问责,确保我市扶贫工作取得实效。
