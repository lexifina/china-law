# 关于印发吉阳镇2014年元旦、春节期间

安全生产工作部署的通知

各村（居）委会、各有关单位：

经镇委、镇政府同意，现将《吉阳镇2014年元旦、春节期间安全生产工作部署》印发给你们，请认真贯彻执行。

三亚市吉阳镇人民政府

2013年12月26日

（此件主动公开）

吉阳镇2014年元旦、春节期间

安全生产工作部署

2014年元旦、春节即将来临，这个阶段是我镇的旅游度假旺季，是人流、物流、车流的高峰期，也是生产安全事故的易发期、多发期。为进一步贯彻落实习近平总书记关于安全生产的一系列重要指示精神，按照“全覆盖、零容忍、严执法、重实效”的总要求，继续开展安全生产大检查、大排查、大整治行动。要突出消防、道路交通、建筑施工等重点行业领域，突出学校、医院、车站、景区等人员密集场所，突出反复发生、长期未得到根治的重点问题开展检查，严防重特大安全事故的发生。

一、加强组织领导，充分认识做好节日期间安全生产工作的重要意义

安全生产工作关系国家安危和人民生命财产安全，事关社会安定稳定，安全责任重于泰山，做好安全生产工作，严防重特大事故发生，是践行科学发展观的具体体现。为了营造节日期间安定稳定的社会环境，各村党支部书记、村委会主任及有关单位负责人要以对人民群众生命财产高度负责的态度，从讲政治、保稳定、促发展的大局出发，把安全生产工作当做当前的头等大事来抓。对元旦、春节期间的安全生产工作要做到有部署、有检查、有落实，坚决遏制群死群伤重特大安全生产事故的发生，确保我镇的安全稳定和社会经济的健康发展，让全镇人民群众过一个欢乐、祥和、平安、喜庆的节日。

二、突出重点，强化措施，切实加大安全监管力度

各村委会、镇各单位要针对元旦、春节期间安全生产特点，切实采取措施，抓好安全监管，严防各类事故发生。要按照“条块结合、分级负责、属地监管”的原则，认真组织开展节日期间的安全大检查。严厉查处和打击安全生产领域的各类违法违规行为，对排查出的事故隐患要采取有效措施立即进行治理。

（一）安全生产方面

1、各村（居）委会、各有关单位要加强对本辖区的烟花爆竹进行监管，重点打击非法运输、非法销售、违规存放、违规燃放等违法行为，对无证无照经营的一律给予取缔，镇政府也相应成立工作组，由镇辖区派出所、工商所、综合执法大队和各村（居）委会协助，同时各村委要加强巡查，做到及时发现，及时上报，及时打击。

2、为确保节日期间我镇辖区内的高铁安全运行，镇政府要求在高铁周边禁止燃放孔明灯，发现违法行为将现场进行打击，造成影响高铁或引发安全事故的要追究相关人员法律责任。因此我镇各村（居）委会在元旦、春节期间务必做到“三到位”，即“宣传到位、落实到位、处置到位”。

3、加强对危险化学品的管理，重点是对销售瓶装汽油的打击力度，重点区域是各村（居）委会的各小商铺零售点，各村（居）委会认真做好调查摸底和集中打击工作，并及时将情况上报到镇政府。

4、各村（居）委会、各有关单位要认真对本单位的隐患排查，做到对本辖区重点区域安全隐患情况明，有专人负责，及时落实整改措施。

5、元旦、春节期间是酒后驾车事故频发的高峰时段，各村（居）委会及有关单位要加大宣传力度，严禁酒后驾驶，确保交通安全，防止事故发生。

6、做好信息上报工作。对“四不”（不排查、不上报、不整改、不监管）行为的单位和部门而引发的安全事故的，将按安全生产事故“四不放过”（即事故原因未查清不放过，职工和事故责任人受不到教育不放过，事故隐患不整改不放过，事故责任不处理不放过）的原则和属地管理原则将依法追究相关人员的责任。

（二）消防安全方面

1、各派出所要加强对人员密集场所如家庭旅馆、网吧、“三合一”、“多合一”场所进行监管，重点检查网吧、家庭旅馆、废品收购站等场所，发现问题立即整改，防止火灾发生。

2、各村（居）委会要加强对本村易引发火灾的重点部位进行隐患排查，对排查出的隐患要及时进行整改，及时做好上报工作。

3、各村（居）委会及有关单位要积极做好消防安全宣传教育工作，增强群众消防安全观念。

（三）食品安全方面

1、重点是农贸市场销售的熟食卫生和生猪屠宰问题，农贸市场管理处和工商所要加大监管力度，确保节日期间食品安全。

2、卫生院、工商所要重点对我镇范围内接待团圆饭、年夜饭团队用餐及集体聚餐等餐饮的酒店、餐馆和海鲜店的食品安全监管，严格执行索证和进货台帐制度，入库有验收记录；食品库房不与非食品混放，无超过保质期或腐败变质食品，冷藏设施正常运转；厨房内外环境整洁，有防绳、防鼠、防尘设施，加工用设施、设备工具干净；食品加工及餐饮具消毒保洁符合要求；从业人员持有健康证明上岗，及时消除食品安全隐患防止发生食品中毒事件。工商所要对各餐饮店的价格进行监管，实行明码标价，防止宰客现象的发生。

3、各村（居）委会要加强对元旦、春节期间村民集体聚餐实行监管，按我镇下发的聚餐申报制度做好台帐登记，实行农村宴席厨师备案管理和卫生管理制度，全面推行农村宴席申报备案管理制度，一次就餐在100人以上宴席必须申报备案，各村（居）委会要联合卫生院、工商所加强对聚餐的食品、场所等进行卫生检查，确保农村集体聚餐食品安全。

三、工作要求

（一）提高认识。各单位要清醒认识我镇当前安全生产的严峻形势，客服盲目乐观和麻痹松懈思想，把思想认识统一到认真贯彻落实习近平总书记关于加强安全生产的一系列重要指示精神和镇政府的部署上来，扎实抓好安全生产工作。

（二）认真排查。各单位要在上次集中开展安全生产大检查的基础上，再次开展安全生产大检查活动，认真查找安全生产管理上的薄弱环节，认真查找各类事故隐患，认真查处各种安全生产违法行为。

（三）重在落实。各单位对排查出来的安全隐患，按照“五落实”的要求抓好整治工作；对屡教不改、整改不力的要按“四个一律”的要求严肃处理。

（四）加强值守。元旦、春节期间，各单位要安排好值班，并且要有领导在岗带班。要做好应急准备，突发事件要及时报告并采取有效措施妥善处置。

（五）认真总结。各单位要对安全生产检查中形成的好经验、好做法，要及时总结提炼固化为规章制度，建立健全隐患排查整改长效机制。
