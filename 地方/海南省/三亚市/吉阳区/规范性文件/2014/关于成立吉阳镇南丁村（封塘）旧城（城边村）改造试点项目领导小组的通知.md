# 关于成立吉阳镇南丁村（封塘）旧城（城边村）改造试点项目领导小组的通知

关于成立吉阳镇南丁村（封塘）旧城

（城边村）改造试点项目领导小组的通知

镇各办公室（中心）、南丁村委会、可金公司：

根据《三亚市2014年城中村城边村和新农村综合改造建设工作方案》（三办发〔2014〕12号）的文件精神，为加快我镇南丁村城边村改造项目的进程，努力实现建成全省城乡一体化先行示范区的任务目标，现成立吉阳镇南丁村（封塘）旧城（城边村）改造试点项目领导小组，成员名单如下：

组 长：陈德勇（镇委副书记，镇长）

副组长：谭秋桂（亚龙湾纪工委书记）

胡旭东（镇委委员，镇人大副主席）

严志海（三亚可德金投资开发有限公司总经理）

组 员：张劲涛、邢福雄、陈明荣、高进南、董学才、谭开清、符国文、高亚平及可金公司前期部人员。

领导小组下设“三亚城边村改造项目南丁（封塘）”前期指挥部。

指挥长：谭秋桂

副指挥长：胡旭东、邢福雄、陈明荣、高进南

办公室主任：李强

办公室副主任：顾智毅

指挥部成员由村委会、公司相关人员组成。

三亚市吉阳镇人民政府

2014年5月4日
