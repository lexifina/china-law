# 三亚市吉阳区人民政府关于印发三亚市吉阳区实施征地工作暂行办法的通知

三亚市吉阳区人民政府

关于印发三亚市吉阳区实施征地工作

暂行办法的通知

区政府直属各单位、各村（居）委会：

现将《三亚市吉阳区实施征地工作暂行办法》发给你们，请结合实际，认真组织实施。

三亚市吉阳区人民政府

2015年4月20日

（此件主动公开）

三亚市吉阳区实施征地工作暂行办法

为了加强我区征地工作的管理，明确征地工作流程和各部门分工，根据《三亚市集体土地征收补偿安置管理规定》、《三亚市征地工作经费管理暂行办法》、《征地工作小组有关工作经费使用处理的指导性意见》和《三亚市市直机关差旅费管理办法》等有关规定，结合我区实际，制定本办法。

一、适用范围

凡在我区行政区域内实施征收农民集体所有的土地（以下简称“征地”），适用本办法。

本办法所称征地工作，是指市政府下发项目征地调查通知后，由我区组织实施项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作。

区各责任单位（部、委、办、局、中心）应根据本办法的工作要求，认真贯彻落实相关征地工作。

二、征地工作流程

征地工作流程是实施征地工作的指导。征地工作流程主要包括编制征地告知书、落实放线及拍照、编制安置补偿方案、编制项目实施方案、清点丈量及测量等方面。

（一）编制征地告知书：项目调查通知下发后，应编制征地告知书，在被征地村（居）委会和项目征地范围内张贴告知。告知书的编制和张贴由区项目推进服务中心负责。

（二）落实放线及拍摄：征地工作开展前，为明确项目征地涉及土地面积、房屋、青苗及地上附着物等情况，应根据项目用地红线坐标等，落实放线工作。放线时，应拍摄项目现状，作为打击抢建抢种的依据。放线后，区项目推进服务中心应组织区城管局人员确认征地范围。放线及拍摄工作由区项目推进服务中心负责，各责任单位及测量单位配合。

（三）编制安置补偿方案：征地补偿标准应按市政府最新标准执行，如项目需编制补偿安置方案，应在市政府最新安置补偿规定的基础上进行编制，由区政府报市政府批准实施。安置补偿方案编制工作由区项目推进服务中心负责，各责任单位配合。

（四）编制实施方案：为确保项目征地工作的有序开展，应编制项目征地工作实施方案，明确项目征地工作人员职责：

1.成立项目领导小组，全面负责组织实施项目征地工作。领导小组组长应由被征地村（居）委会联系点领导兼任，成员应由驻点单位工作人员和被征地村（居）委会组成。征地项目由各被征地村（居）委会驻点领导和单位负责，不随驻点领导或单位人员工作调整而调整；

2.项目领导小组根据需要下设项目征地办公室，负责项目征地具体事务。办公室主任应由被征地村（居）委会驻点单位领导兼任；

3.项目领导小组或征地办公室应成立征地工作组，负责项目征地的土地、青苗、房屋及其它地上附着物的清点丈量、制表、作价补偿等工作。区项目推进服务中心派出工作人员负责业务指导及补偿审核工作。

编制实施方案由区项目推进服务中心牵头，各责任单位配合。

（五）宣传及解释、调查和动迁：项目征地工作组成立后，应在被征地村（居）委会召开项目征地动员会，将项目范围、补偿及安置等情况进行宣传及解释。

项目征地工作组应协同被征地村（居）委会对拟征收房屋的权属、人员户籍及分户等情况进行调查摸底，由被征地村（居）委会对调查结果初步审核，并在村（居）委会公示7天无异议后，送区征地项目分户审查组进行审核。如无异议，按程序落实补偿；如有异议，未能确定的出具审查意见报区政府常务会议讨论确定。

调查结果确定后，项目征地工作组要积极与被拆迁户沟通，做好被拆迁户的思想动迁工作。遇到阻力情况，要有迎难而上的精神，从多方面考虑去解决问题。

宣传及解释、调查和动迁由项目征地工作组负责。

（六）清点丈量及测量：被拆迁户同意动迁的，应及时做好清点丈量和测量工作。清点丈量及测量主要包含房屋、附着物及青苗等清点丈量和土地测量。房屋、附着物及青苗等清点丈量应严格按规定进行；土地测量应做好各村委会、各村民小组和各被征地户之间的土地权属分界工作。涉及到各宗地补偿及青苗补偿实行按亩包干补偿的情况，应统一使用测量仪器进行测量，并出具宗地图。

为规范清点丈量及测量工作，清点丈量之前，应对被征房屋采取统一编号，明确征收房屋数量。同时，应对被征房屋全面测量，出具项目房屋测绘图，图上应标明被征收房屋占地面积、层数及编号。清点丈量登记造册后三个工作日内登记本原件须交区项目推进服务中心制表组保管，同时复印两份交征地工作组使用。宗地测量时应对宗地控制点实地打桩定点，以便下步校核。清点丈量及测量工作由区项目推进服务中心负责，各责任单位及测量单位配合。

（七）结果核对：完成清点丈量及测量工作后，征地工作组应将登记及测量结果复印件发放给被征地户进行核对，如有错漏，应及时更正。错漏较小，由原清点丈量登记人员及参与核实人员签名确认，后联系区项目推进服务中心制表组更正登记表原件及复印件；错漏较大，须由项目责任单位和项目推进服务中心领导到现场确认后方可更正。

（八）制表、审表、公示及补偿：区项目推进服务中心制表组根据登记及测量结果，利用征地补偿系统，严格按市政府最新补偿标准制定补偿表。

补偿表应交区项目推进服务中心审表组审核，审核主要内容为登记表数据应与补偿表数据一致、各项套用补偿标准应符合规定、被征房屋编号和层数应与房屋宗地图一致、被征房屋面积应与房屋宗地图数据基本一致及宗地补偿面积及青苗补偿面积不应超出征地总面积等。如审核发现数据错误、标准不一致等不符合规定的情况，应及时通知项目征地工作组核实，确定有误的，须进行更正。

项目征地工作组应将补偿情况（含被拆迁户的户籍、分户情况、房屋编号、房屋面积、补偿金额等）在被征地村（居）委会和项目范围内公示七天。

补偿结果公示无异议的，由征地工作组按规定落实补偿。

（九）档案管理：完成被征地户补偿后，应在3个工作日内将补偿表等相关资料移交区项目推进服务中心档案组归档，保证征地资料的安全保管和高效利用。

（十）项目审计：完成征地工作后，应及时落实项目审计工作。如项目特殊，可同步审计。项目审计工作由区项目推进服务中心负责送审。

三、明确征地工作分工

市政府下发项目征地调查通知后，由区项目推进服务中心负责编制征地告知书、落实放线及拍照、编制安置补偿方案、编制项目实施方案、申请征地费用等前期工作，区各责任单位配合区项目推进服务中心推进前期工作。

项目征地实施方案下发后，由征地工作组（即各被征地村（居）委会驻点领导和单位人员）负责项目的宣传解释、调查、动迁等实施推进工作，区项目推进服务中心配合做好清点丈量、测量、制表、审表、公示、补偿等工作。

四、征地补偿审批程序

征地工作补偿包括补偿表、协议书、五联单和报销支付凭证。

（一）补偿统计表的审批程序：一是制表人：1人，由区项目推进服务中心制表人员签名；二是清点勘丈人签名：至少两人，由清点丈量登记人员签名（其中至少有1人是区在职在编人员）；三是审表人：1人或多人，由区项目推进服务中心审表人员签名；四是征地小组领导：由项目征地小组领导签名。

（二）协议书的审批程序：一是分管领导：由项目分管领导签名；二是征地单位：由区项目推进服务中心领导签名，并加盖区项目推进服务中心印章。

（三）五联单的审批程序：一是制表人：1人，由区项目推进服务中心人员签名；二是参加调查人员签名：至少两人，由清点丈量及登记人员签名（其中至少有1人是区在职在编人员）；三是审表人：1人或多人，由区项目推进服务中心审表人员签名；四是征地小组领导：由项目征地小组领导签名；五是征地拆迁负责单位责任领导签名：由项目责任单位领导签名；六是区项目推进服务中心领导签名：由区项目推进服务中心领导签名，并加盖区项目推进服务中心印章。

（四）报销支付凭证的审批程序：一是经办人：由实际办理人员或领导指定的人员签名；二是验证人：由项目责任单位领导签名；三是备注：由区项目推进服务中心审核人员审核签名；四是领导审批：由区项目推进服务中心负责领导签名并盖章。

五、征地工作经费使用和审批

（一）征地工作经费使用

项目征地工作经费包含一般征地工作经费和不可预见费。征地工作经费主要用于两大方面：一是日常支出费用，包含征地工作误餐费、外勤补助、办公费、交通费、车辆油料和维修费、聘用人员工资等；二是不可预见补偿支出费用，包含征地工作不可预见特殊问题和相关历史遗留问题解决经费等。

征地工作经费用于推进项目征地工作，由区项目推进服务中心统筹安排，各项目责任单位提出资金使用计划。

项目征地工作人员误餐费标准为50元/人/餐；油料费以征地工作组为单位，每月控制在2000-3000元/辆之内，凭油料费发票报销；在职在编人员的外勤补助按照70元/人/天，临时聘用工作人员（含因征地工作需要，临时配合工作人员）的外勤补助按照80元/人/天，外出考勤由各项目责任单位负责，外勤天数以实际出勤天数为准，且每人每月外勤补助不得超过2000元。

（二）征地工作经费的审批

被征地村（居）委会申请征地工作经费和单笔不可预见补偿支出费用3万元以下（含3万元）由各项目征地工作组与区项目推进服务中心召开吉阳区项目推进专题会议确定； 3万元以上10万元以下（含10万元）由项目分管领导召开吉阳区项目推进专题会议确定；10万元以上的由区政府常务会议确定。

六、其他事项

（一）自本办法下达之日起，区各责任单位、各项目征地工作人员要严格按照本办法要求实施征地工作。区纪检、监察部门不定时、不定点的督查项目征地工作，对违反法定程序实施征地或者不按国家和本办法的规定进行征地补偿安置的，依法追究主要负责人和相关人员的法律责任。征地工作人员玩忽职守，滥用职权，徇私舞弊，依法给予行政处分；构成犯罪的，依法追究法律责任。

（二）本办法由区项目推进服务中心负责解释。
