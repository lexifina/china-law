# 三亚市吉阳区人民政府关于吉阳区狗岭路免费公共停车场停止使用的通告

三亚市吉阳区人民政府

关于吉阳区狗岭路免费公共停车场

停止使用的通告

因市重点项目建设需要，三亚市吉阳区狗岭路免费公共停车场（三亚市中医院旁靠近狗岭路方向），将于2017年11月28日晚24：00停止使用。停止使用后，停放于狗岭路免费公共停车场内的各类车辆自行驶离停车场，如因个人原因未能及时将车辆驶离，交管部门将采取强制拖车措施，对于交管部门采取的拖车措施及由此可能产生的车辆损坏及费用支出，将由车主自行承担责任。为此给市民带来的不便，敬请谅解！

特此通告

三亚市吉阳区人民政府
