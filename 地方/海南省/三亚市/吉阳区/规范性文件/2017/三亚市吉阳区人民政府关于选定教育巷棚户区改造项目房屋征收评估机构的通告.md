# 三亚市吉阳区人民政府关于选定教育巷棚户区改造项目房屋征收评估机构的通告

三亚市吉阳区人民政府

关于选定教育巷棚户区改造项目房屋征收

评估机构的通告

项目被征收人：

根据《国有土地上房屋征收与补偿条例》（国务院令第590号）、《国有土地上房屋征收评估办法》（建房〔2011〕77号）和《三亚市棚户区改造房屋征收补偿安置暂行办法》（三府〔2015〕112号）等有关规定，为做好教育巷棚户区改造项目征收范围内房屋征收评估工作，区政府从在我市备案的房地产价格评估机构中选取了16家机构（名单附后），请按照以下程序从中选定1家房地产价格评估机构：

一、协商选定

由港门村社区居委会于2017年11月20日18时前将被征收人自行协商选择结果书面报区住房和城乡建设局。具体协商方式，可由被征收人自行协商出一致意见后，联名签署书面选定意见或共同委托代表向当地社区居委会提交书面选定意见。

协商选定的评估机构，应经半数以上项目被征收人同意。

二、多数决定

在2017年11月20日18时前，协商未能选定评估机构的，由港门村社区居委会在改造区域入户调查的办公地点设置投票点收集被征收人选票，每户一票，按少数服从多数的原则根据最终统计票数结果选定评估机构，投票时间为2017年11月21日至2017年11月23日。

一户多投，按废票处理；规定时间内未投，视为自愿弃权。

三、随机选定

若通过多数决定仍未能选定评估机构，我区将在三亚市公证处全程参与和监督下，采取随机抽签方式，从报名参加抽签的评估机构中抽签选定项目房屋征收评估机构。具体时间、地点另行通知。

房地产价格评估机构确定后，我区将在征收范围内进行公告。
