# 三亚市人民政府办公室关于印发三亚市2017年知识产权宣传周活动实施方案的通知

三亚市人民政府办公室

关于印发三亚市2017年知识产权宣传周

活动实施方案的通知

各区人民政府，各管委会，市政府直属各单位:

《三亚市2017年知识产权宣传周活动实施方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年4月19日

（此件主动公开）

三亚市2017年知识产权宣传周活动实施方案

为加强知识产权宣传普及，提升全社会的知识产权意识，结合庆祝第17个世界知识产权日，根据海南省知识产权战略实施工作联席会议办公室统一部署和我市实际，制定本方案。

一、指导思想

贯彻落实党的十八大、十八届三中、四中、五中、六中全会精神，紧紧围绕统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，广泛宣传国家、省关于知识产权工作的决策部署及相关扶持政策，特别是宣传《国务院关于新形势下加快知识产权强国建设的若干意见》、《深入实施国家知识产权战略行动计划(2014-2020年)》、《“十三五”国家知识产权保护和运用规划》和《海南省人民政府关于新形势下加快知识产权强省建设的实施意见》等重要政策落实情况，全面展示我市在推进知识产权强市建设的重大进展和工作成就，突出反映深化知识产权领域改革、加强知识产权保护运用对于创新驱动发展、大众创业万众创新的支撑作用，向社会公众普及知识产权知识，大力推进以“尊重知识、崇尚创新、诚信守法”为核心的知识产权文化建设，为加快知识产权强市建设营造良好氛围。

二、活动时间

2017年4月20日-26日

三、活动主题

创新发展，竞争未来。
