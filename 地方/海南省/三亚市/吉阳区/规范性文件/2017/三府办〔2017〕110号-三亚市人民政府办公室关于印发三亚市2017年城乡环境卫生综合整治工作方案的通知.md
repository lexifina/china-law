# 三亚市人民政府办公室关于印发三亚市2017年城乡环境卫生综合整治工作方案的通知

三亚市人民政府办公室

关于印发三亚市2017年城乡环境卫生综合整治工作方案的通知

各区人民政府，各管委会，市各有关单位：

《三亚市2017年城乡环境卫生综合整治工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年4月15日

（此件主动公开）

三亚市2017年城乡环境卫生综合整治工作方案

为了贯彻落实省政府工作部署，扎实推进我市城乡环境整治及创文巩卫工作取得的新成效，全面加强和改进城市管理及乡村环境治理工作，努力营造整洁、有序、规范的城乡环境卫生面貌，提升城市的国际化水平，根据《海南省2017年城乡环境综合整治工作方案》，结合我市实际，制定本工作方案。

一、指导思想

以科学发展观为指导，以建设美丽三亚、提升城市国际化水平，改善人居环境质量为主要目标，坚持“政府主导、全民参与、属地负责、统筹兼顾”的工作原则，努力创建环境优美、干净整洁、舒适宜居、文明向上的国际性热带滨海旅游城市。

二、组织领导

成立2017年三亚市城乡环境综合整治工作领导小组，负责组织、指导、协调开展城乡环境综合整治工作。其组成人员如下：

三、整治工作目标

在我市已经开展 “创文巩卫”的基础上，大力组织动员城乡环境卫生整治工作，通过开展垃圾杂物清理，病媒生物防治及摊点乱摆、车辆乱放治理、广告乱贴、污水乱排、工地乱象等城乡脏乱差问题的整治，创建整洁有序、生态文明的热带滨海旅游城市，通过改善城乡环境容貌，进一步激发城乡发展活力，提高城乡管理水平，为建设国际性热带滨海旅游城市打下坚实基础。

四、整治内容及任务分工

（一）深入开展“清洁城区”活动

各单位要充分利用我市开展创文巩卫的契机，定时组织辖区居民开展环境整治活动，全面清理辖区积存垃圾、杂物，共同研究解决辖区环境卫生脏乱差问题。对城区主次干道、繁华地区和重点部位要增加清扫作业班次，推行精细化环卫保洁模式，着力提高城区道路机械化清扫率及清扫水平，确保城区机械化清扫率达到50%以上。（牵头单位：市园林环卫局、市爱卫办，责任单位：各区人民政府、育才生态区管委会）

（二）落实“门前三包”责任制

“门前三包”制度是群众参与城市管理的有效模式，推行“门前三包”制度是保证城市环境卫生干净整洁、市容市貌井然有序的主要手段，市综合行政执法局、市园林环卫局要督促各区政府、各管委会尽快完成门前三包牌的制定工作，实现“门前三包”制度的全覆盖，加强监督检查，注重实效。（牵头单位：市综合执法局、市园林环卫局，责任单位：各区人民政府、育才生态区管委会）

（三）加强建筑垃圾管理工作

当前，建筑垃圾占用土地空间及乱堆放问题已成为城市管理的一大难题，亟待加强管理。市园林环卫局要加快建筑垃圾综合利用厂的建设工作，各区政府、各管委会要尽快完善建筑垃圾常态化管理机制，加快建筑垃圾临时堆放点的选址建设，排查建筑垃圾堆放数量，对拆迁产生的建筑垃圾要做到随拆随清；要加紧完善建筑垃圾进行收集转运及科学化管理体系建设，确保建筑垃圾得到妥善处置。（牵头单位：市园林环卫局、市住房城乡建设局，责任单位：各区人民政府、育才生态区管委会）

（四）推进和加强农贸市场改造及管理

1.做好农贸市场规划建设。市商务局、市国资委要督促项目业主尽快完成全市33座农贸市场的升级改造工作，确保农贸市场按时完工投入使用。（牵头单位：市商务局，责任单位：各区人民政府、育才生态区管委会、市国资委）

2.加强农贸市场管理工作。各区人民政府、育才生态区管委会要督促市场管理单位与市场经营者签订环境卫生保洁责任书，管理单位要加强对市场布局划行规市的指导工作，监督市场经营者依照责任书约定事项进行逐项落实，做到整洁有序，管理规范；加强市场周边环境卫生的监督指导工作，属地人民政府要做好农贸市场周边垃圾清运工作。（责任单位：各区人民政府、育才生态区管委会）

（五）加强市政设施建设与维护

要全面加强城区公厕、公交车站点、健身器材、果皮箱、垃圾转运站、沿街路灯等市政设施管理维护工作，确保各类市政设施正常使用，符合使用管理标准。（责任单位：市住房城乡建设局、市园林环卫局、市交通运输局、市文化广电出版体育局、各区人民政府、育才生态区管委会）

（六）强化建设工地整治

市住房城乡建设局要加强对建筑工地的监督检查工作，各建筑工地应按要求设置全封闭围挡墙，内部主要道路必须进行硬化处理，土方应采取覆盖、固化或绿化等措施，防止黄土露天，按要求做好工地内卫生管理；对进出建设工地的车辆应加强管理，从工地现场驶出的车辆须按要求进行冲洗，防止车辆带泥上路污染路面，建筑工地要设有泥浆沉淀池，防止污水直接进入河道；载重的各类工程车上路前须进行覆盖处理，避免建筑材料散落污染路面；市公安交警部门对无牌无证、假牌假证、报废、套牌运输建筑材料、渣土的工程车依法进行查处；综合行政执法、住建部门负责对满载、超载建筑材料导致建筑材料沿途撒漏路面及带泥上路的车辆及乱倒建筑废弃物的行为进行查处。（责任单位：市住房城乡建设局、市综合行政执法局、市公安局交警支队、各区人民政府、育才生态区管委会）

（七）继续推进城市“双修”工作

市园林环卫局、市住房城乡建设局、市林业局、市规划局等单位要按照2017年三亚市“双修”项目推进工作要求，倒排工期，加快项目建设；试点推进海绵城市建设，将海绵设施建设融入市政建设内容。按照“300米见绿、500米见园”的理念，持续推进城区园林绿化建设；加强园林绿化管理，对缺株、缺损的花草树木进行补缺、补损，提高城市绿化覆盖率。（责任单位：市住房城乡建设局、市园林环卫局、市林业局、市规划局）

（八）推进农村环境整治工作

1.加强农村存量垃圾清理，全面做好国家十部委农村生活垃圾治理考核准备工作。各区及育才生态区管委会务必下力气开展清理活动，主要领导要进一步增强做好农村垃圾治理工作的大局意识，把农村垃圾治理作为一项主要工作内容；全面排查清理，组织人力物力全面清理村庄公共区域、田园、河道杂物等存量垃圾；指导基层村委会修订、完善“村规民约”，建立日常保洁、巡查制度；采取与村民签订“门前三包”责任书等方式，明确村民对自家庭院、房前屋后的保洁义务，做好日常保洁工作，使村庄“脏乱差”现象得到根本改善。（牵头单位：市园林环卫局、市爱卫办，责任单位：各区人民政府、育才生态区管委会）

2.加强农业废弃物清理工作。热带高效农业是我市的一大招牌，但近年来出现的农业垃圾污染问题给我们敲响了警钟。农业垃圾种类繁多，主要有农药瓶、农药袋、肥料袋、塑料膜各种农产品包装物等，且有从点源向面原扩散的趋势。市农业局、市生态环保局要指导各区政府、各管委会加强对农业污染源的清理工作，特别要加强对农户及南繁育种单位的宣传工作，确保各种农业污染物的清除率在90%以上，做到田园洁净，农业生产安全，农产品质量达标。（牵头单位：市农业局、市生态环保局，责任单位：各区人民政府、育才生态区管委会）

3.推进农村污水整治工程。市生态环保局要加快推进农村（城郊村）污水整治工程，加大农村污水治理经费的投入力度，制定农村污水处理设施建设方案；因地制宜，采用多种处理工艺开展农村污水治理工作，优先推进水源保护地、环境敏感区域、规模较大的规划布点村庄和新建村庄生产生活污水治理工作。（牵头单位：市水务局，配合单位：各区人民政府、育才生态区管委会、市生态环保局）

4.加强村庄美化、绿化、亮化建设。各区政府、各管委会要进一步加强村庄的美化、绿化工作，重点抓好村庄道路、水边及公共活动场地的美化、绿化建设；实施边远乡村亮化工程，确保村村通电，保证农村道路亮化率。通过美丽乡村建设，逐步完善农村基础设施，提高农村公共服务保障能力，改善人居环境。（牵头单位：市住房城乡建设局、市园林环卫局、市林业局、三亚供电局，责任单位：各区人民政府、育才生态区管委会）

（九）实施“清洁水体”工程

继续推进河湖整治工程，重点推进三亚河污染及近海海域环境整治工程，巩固先前整治成果；实施宁远河、藤桥河等重点河段综合整治，充分发挥落实河长监督制度，整治河段沿岸乱排、乱倒行为，确保重点河段水体环境质量。（牵头单位：市水务局、市海洋渔业局、市生态环保局，责任单位：各区人民政府、育才生态区管委会）

（十）开展专项整治行动

1.开展户外广告整治行动。组织开展各类广告专项整治行动，检查高铁、高速公路、国省道、城市主次干道沿线及繁华商业区车站、码头的广告设置情况，对过期、废旧、残缺、违章或影响市容环境的广告予以拆除，对违规设置的各类广告（含小广告）予以坚决清除，对不符合要求的各类广告坚决不予审批。（责任单位：市综合执法局、三亚公路局、市交通运输局）

2.开展交通环境整治行动。规范机动车辆停放行为，加大车辆乱停乱放、乱掉头、逆行等交通违章行为；规范电动车管理工作，指导市民按规定停放电动车，引导市民文明出行，对普遍存在的行人横穿马路、翻越栏杆等不文明行为开展综合整治；推进城区停车场建设，规范停车场管理；市交通运输局、三亚公路局要加大对高速公路、国道、省道沿线的卫生保洁工作，确保各高速路口、机场、码头加油站等出入口卫生干净整洁；做好水上船舶管理工作，引导渔民、游客科学收集各类垃圾，杜绝随意丢弃垃圾行为。（责任单位：市公安局交警支队、市交通运输局、市海洋渔业局、三亚公路局、市住房城乡建设局、各区人民政府、育才生态区管委会）

3.加强景点景区环境整治。全面整治景点、景区环境，提高服务质量；推进旅游公厕建设，加强公厕管理服务。加强景区内部管理，确保垃圾日产日清、无垃圾死角；进一步加强涉海旅游活动管理。（责任单位：市旅游委、市园林环卫局、市海洋渔业局，配合单位：各区人民政府、育才生态区管委会）

4.加强对各类户外体育活动的管理工作。户外露营活动应严格遵守相关规定，务必做到“人走无痕“，保持露营活动结束后露营点卫生干净整洁。（牵头单位：市文化广电出版体育局，配合单位：各区人民政府、育才生态区管委会、市旅游委）

5.开展博鳌论坛年会周边环境整治行动。全力以赴做好年会环境卫生保障工作，加强东环高铁、东线高速公路沿线，凤凰机场出口周边及沿线的卫生保洁及美化、绿化、亮化、花化工作，加强加油站、车站等沿线窗口单位的公厕保洁工作，确保年会期间保洁质量。（责任单位：市园林环卫局、市综合行政执法局、市交通运输局、三亚公路局、吉阳区人民政府、海棠区人民政府、天涯区人民政府）

五、实施步骤

（一）宣传发动阶段（3月10日―3月20日）

各相关单位要在创文巩卫的基础上，全面推进2017年城乡环境卫生整治工作取得新成效。各区政府、各管委会、市各有关单位要做好宣传发动工作，营造良好的社会舆论环境。

（二）集中整治阶段（3月20日―11月30日）。各责任单位要根据排查发现的问题，及时组织开展城乡脏、乱、差整治活动，要有专门的整改方案，明确完成时限、目标及责任人，层层抓落实。市、区两级职能部门要加强整治工作的监督指导工作，并将整改工作列入干部年度考核内容。

（三）总结整改阶段（12月1日―12月31日）。年终，市城乡环境综合整治工作领导小组将对全市各单位开展城乡环境整治情况开展集中检查，对在整治工作不作为，职责履行不到位的将启动问责机制。

六、保障措施

（一）统一认识，加强领导。各单位要从思想上高度重视，把加强和改善城乡环境卫生工作作为提升我市城市形象和创文巩卫工作的重要内容。各级领导要增强大局意识、看齐意识，成立组织机构，做到主要领导亲自挂帅，分管领导专抓专管，认真履行岗位职责，全面组织开展城乡环境卫生自查、整改工作。

（二）明确分工，落实责任。全市相关单位要按照本工作方案的要求，制定出具体的工作方案，明确责任领导、责任人和完成时限，一级抓一级，层层抓落实，为国家卫生城市复查提供坚强保障。

（三）讲究实效，重在落实。各单位要发扬正抓实干精神，注重成效，对短时间内尚不能整改的责任事项，要研究制定整改工作计划，开展专项整改。
