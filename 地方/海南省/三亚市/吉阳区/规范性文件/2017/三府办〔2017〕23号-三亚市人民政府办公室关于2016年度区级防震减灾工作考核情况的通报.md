# 三亚市人民政府办公室关于2016年度区级防震减灾工作考核情况的通报

三亚市人民政府办公室

关于2016年度区级防震减灾工作考核情况的通报

各区人民政府，育才生态区管理委员会：

根据《三亚市人民政府办公室关于印发三亚市2016年度区级防震减灾工作考核的通知》（三府办〔2016〕405号）要求，市政府组织区级防震减灾工作考核组于2017年1月5日至1月6日对各区人民政府和育才生态区管理委员会2016年度防震减灾工作完成情况进行了综合考评。经市政府同意，现将考核情况通报如下：

一、2016年度考核评定结果

经考核，我市2016年度区级防震减灾工作先进单位：（空缺）；合格单位按得分高低排名如下：

1.海棠区人民政府

2.育才生态区管理委员会

3.崖州区人民政府

4.吉阳区人民政府

5.天涯区人民政府

二、2016年度各区、育才生态区管委会防震减灾主要工作任务完成情况

（一）防震减灾保障工作情况。

按照市政府的工作部署，各区和育才生态区管委会均能完善机构建设，成立防震减灾工作领导小组，明确防震减灾分管领导以及防震减灾工作机构和工作人员；均将防震减灾经费纳入财政预算，但除了崖州区和育才生态区管委会外，其他各区防震减灾工作经费均未达到省政府要求的人均1.8元的标准。

（二）地震监测工作情况。

各区和育才生态区管委会已制定和完善群测群防工作管理制度，行政村换届选举后，均能及时调整落实群测群防联络员，编制更新人员名录并组织开展至少一次群测群防知识培训；已建立地震宏观异常落实制度和至少一个地震宏观观测点，并有专人担任宏观观测员；已按时协助足额发放群测群防联络员补助。

（三）震害防御工作情况。

1.创建防震减灾综合示范社区（村）情况。仅有海棠区、吉阳区根据《三亚市人民政府办公室关于印发三亚市区级防震减灾年度考核工作方案的通知》（三府办〔2016〕77号）通知要求，创建市级防震减灾综合示范社区并开展活动，其中海棠区江林村通过省级部门验收获评省级防震减灾综合示范社区（村）；其余区和育才生态区管委会均无创建防震减灾综合示范社区（村）。

2.防震减灾科普示范学校创建情况。各区和育才生态区管委会均已创建市级防震减灾科普示范学校，其中吉阳区市第十小学、天涯区水蛟小学通过省级部门验收获评省级防震减灾科普示范学校。

（四）应急救援工作情况

各区和育才生态区管委会均能按照《中华人民共和国防震减灾法》的要求，结合《三亚市地震应急预案》和自身实际编制地震应急预案，并要求区直属各单位以及辖区内人员密集场所和易发生次生灾害的生产经营单位开展地震应急预案编制备案工作，但除海棠区外，其余区和育才生态区管委会地震应急预案备案率均未达到100%；均按要求组织、指导辖区内中小学校进行地震应急疏散演练活动，但除海棠区组织开展地震应急综合演练、社区地震应急演练、医院地震应急演练外，其余区和育才生态区管委会均未开展；均按要求成立地震应急志愿者队伍；均未开展地震应急避难场所建设工作。

（五）防震减灾宣传教育工作情况

各区和育才生态区管委会均能利用“5・12”汶川地震纪念日、科技活动月、“7.28”唐山地震纪念日等契机，认真开展防震减灾知识“进学校、进社区、进机关、进企事业单位、进农村”活动，利用宣传栏、发放地震科普宣传册等方式大力宣传防震减灾科普知识，社会公众的防震减灾意识得到进一步提高，但除海棠区外，其余区和育才生态区管委会开展防震减灾宣传活动次数不够，社区、学校覆盖率低，未达到市政府考核标准要求。

三、存在的主要问题

一是防震减灾组织领导有待加强。各区和育才生态区管委会未召开防震减灾联席会议专题研究防震减灾年度工作；对防震减灾纳入市政府单项目标考核认识不深，相关职能部门的防震减灾职责不明确，协调协作不够，尚未形成部门合力；不按要求报送考核材料。

二是防震减灾综合示范创建工作力度不够。各区和育才生态区管委会尚未对辖区内社区（村）、学校开展详细调研，也没有将创建工作经费纳入防震减灾专项工作经费，创建工作推动缓慢。目前，除海棠区、吉阳区外，其余区和育才生态区管委会2016年防震减灾综合示范社区（村）创建工作内容尚处空白。

三是地震应急管理体系有待完善。各区和育才生态区管委会的地震应急预案编制流于形式，缺乏动态管理，实用性和可操作性不强；地震应急演练组织工作不到位，地震应急演练单一，缺乏多部门的综合性演练，无演练方案和演练总结。尚无地震应急避难场所建设规划立项，目前全市仅有市地震局管理的红树林地震应急避难场所。

四、下一步工作要求

防震减灾事关人民生命财产安全，事关国民经济发展与社会和谐稳定。各区和育才生态区管委会要牢固树立“宁可千日不震，不可一日不防”的意识，切实增强做好防震减灾工作责任感和紧迫感，按照年度防震减灾重点工作任务的要求，切实加强防震减灾工作的领导，正确全面履行政府防震减灾管理职责，建立防震减灾工作目标管理责任制；尽快完善防震减灾部门的机构建设，解决工作经费不足等突出问题；继续开展地震安全综合示范社区（村）和防震减灾科普示范学校的创建工作，完善地震应急预案体系，加强志愿者队伍和学校、医院等人员密集场所的地震应急演练，加快开展地震应急避难场所建设。

三亚市人民政府办公室
