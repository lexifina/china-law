# 三亚市人民政府办公室关于调整三亚市投资项目在线审批监管平台应用领导协调小组的通知

三亚市人民政府办公室

关于调整三亚市投资项目在线审批监管平台应用领导协调小组的通知

各区人民政府，各管委会，市各相关单位：

因人事变动和工作需要，市政府决定调整三亚市投资项目在线审批监管平台应用工作领导协调小组。现将领导协调小组成员名单通知如下。

组　长：鲍　剑（市委常委、常务副市长）

副组长：李武军（市政府副秘书长）

张　利（市发展改革委主任）

林日雄（市统计局副局长）

领导协调小组下设办公室，办公室设在市发展改革委，办公室主任由市发展改革委主任张利担任。领导协调小组办公室不定期组织召开部门协调工作会议，对投资项目在线审批监管平台应用情况进行通报、总结，协调解决有关问题。

领导协调小组各成员单位应建立本单位工作责任人制度，明确责任领导和工作联络人，积极开展相关工作。

三亚市人民政府办公室

2017年1月26日
