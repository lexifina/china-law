# 三亚市人民政府办公室关于印发三亚市农村低保对象特困人员教育医疗住房保障和产业扶持实施方案的通知

三亚市人民政府办公室

关于印发三亚市农村低保对象特困人员

教育医疗住房保障和产业扶持实施方案的通知

各区人民政府，各管委会，市政府直属各单位：

《三亚市农村低保对象、特困人员教育医疗住房保障和产业扶持实施方案》已经七届市政府第15次常务会议审议通过，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年9月27日

（此件主动公开）

三亚市农村低保对象、特困人员

教育医疗住房保障和产业扶持实施方案

为了实现农村最低生活保障制度与扶贫开发政策的有效衔接，切实做好农村低保对象、特困人员教育、医疗、住房保障和产业扶持工作，确保农村贫困人口如期脱贫，根据《海南省人民政府办公厅关于印发海南省做好农村最低生活保障制度与扶贫开发政策有效衔接实施方案的通知》（琼府办〔2016〕314号）和《海南省人民政府办公厅关于印发海南省农村低保对象特困人员教育医疗住房保障和产业扶持实施办法的通知》（琼府办〔2017〕112号）的规定，结合我市实际，制定本方案。

一、指导思想

全面贯彻落实党的十八大和十八届三中、四中、五中、六中全会以及习近平总书记系列重要讲话精神，按照省委、省政府和市委、市政府关于做好困难群众基本生活保障工作的有关要求，结合市扶贫攻坚开发政策，充分发挥各项帮扶政策的保障作用，解决农村低保对象、特困人员在教育、医疗、住房保障和产业发展等方面的实际困难。

二、基本原则

（一）坚持人员双向纳入、政策无缝衔接的原则。对未纳入建档立卡贫困户范围的我市农村户籍的低保对象、特困人员在教育、医疗、住房保障等方面享受与建档立卡贫困户相同的政策待遇；有劳动能力且有脱贫意愿的农村低保对象享受与建档立卡贫困户相当的产业扶持政策待遇。

（二）坚持高效便捷、公开公正原则。优化救助流程，简化救助程序，加快信息建设，畅通居民参与渠道，加大信息公开力度，做到审核审批过程公开透明，审批结果公平公正，使贫困人口及时得到有效保障。

（三）坚持资源统筹、分类管理的原则。统筹各类救助和扶贫资源，将政府各项社会救助与扶贫开发政策相结合，形成脱贫攻坚合力，实现对农村低保对象、特困人员的全面扶持。

三、工作目标

加强部门协作，完善政策措施，健全工作机制，将符合条件的农村低保对象、特困人员的教育、医疗、住房保障和产业扶持政策落实到位，确保农村贫困人口如期脱贫。

四、内容标准

（一）农村低保家庭学生、特困供养学生按照建档立卡贫困户家庭学生同等标准享受各项教育补助政策。

1.学前教育：补助标准为每位学生每年4000元。

2.义务教育阶段：在实施义务教育阶段学生免学杂费、课本费、作业本费、住宿费的政策基础上：

小学：补助标准为每位学生每年3200元（其中，伙食费补贴2800元，校服费春秋两套150元，交通费50元，学习资料费200元）。

3.普通高中教育：在实施免学费、住宿费、课本费、作业本费的政策基础上，再给予补助每位学生每年4000元。

4.中等职业教育：在实施免学费、住宿费、课本费的政策基础上，再给予补助每位学生每年5500元。

5.高等教育（含高职）：普通高等学校学生补助标准为每位学生每年8000元，其中，学费补助5000元，生活费补助2000元，交通费补助1000元；高等职业学校学生补助标准为每位学生每年3000元，其中，生活费补助2000元，交通费补助1000元。

6.市制定的建档立卡贫困户家庭学生其他教育补助政策，亦适用于农村低保家庭学生、特困供养学生。

（二）农村低保对象、特困人员按照建档立卡贫困户同等标准享受各项医疗保障待遇。

1.提高普通门诊报销比例。患者在市内定点基层医疗机构门诊就诊，报销比例提高5%，从50%提高至55%。

2.提高慢性病特殊病种门诊报销比例。患有30种慢性病（病种参照《三亚市人民政府关于印发三亚市创新健康扶贫工程实施方案的通知》（三府〔2016〕337号）文件规定执行）特殊病种的患者门诊报销按住院标准提高比例，在省内医保定点医疗机构门诊就诊，报销比例提高5%，其中：一级医院从90%提高至95%，二级医院从75%提高至80%，三级医院从65%提高至70%。

3.提高住院患者报销比例。患者在省内医保定点医疗机构住院治疗，报销比例提高5%，其中：一级医院从90%提高至95%，二级医院从75%提高至80%，三级医院从65%提高至70%。

4.提高地中海贫血患者城乡居民基本医疗保险补偿水平，将排铁治疗药物纳入报销范围，将重症地贫患者造血干细胞移植纳入重大疾病种类范围，实行按病种付费，并提高报销比例，其中，二级医院报销比例为85%，三级医院报销比例为80%。

5.降低大病保险起付线。患者在定点医疗机构住院医疗报销不设起付线；大病保险起付线由8000元降至4000元，最高报销22万元。

6.农村低保对象、特困人员在基本医疗保险定点医疗机构发生的日常门诊、特殊病种门诊医疗费用和住院医疗费用，经基本医疗保险、城乡居民大病保险、其他补充医疗保险等支付后，个人仍无力支付的剩余医疗费用，按医疗救助标准报销后，再从市慈善救助基金中予以全部解决，并享受“先治疗后付费、住院免交押金、一站式结算”等优惠服务。

7.市制定的建档立卡贫困户其他医疗保障政策，亦适用于农村低保对象、特困人员。

（三）农村低保对象、特困人员在危房评定标准、补助标准、危房改造面积标准、危改质量安全标准等方面享受与建档立卡贫困户同等待遇。

1.符合农村危房改造条件的农村低保对象、特困人员，住建部门核定为D级危房改造的每户补助4.5万元，核定为C级危房改造的每户补助2.2万元。

2.对农村低保对象、特困人员自筹资金和投工投料能力极弱的，可以通过建设集体公租房、利用闲置农房和集体公房置换、提高补助资金额度等方式予以兜底解决。

3.市制定的建档立卡贫困户其他住房保障政策，亦适用于农村低保对象、特困人员。

（四）有劳动能力且有脱贫意愿的农村低保对象享受与建档立卡贫困户相当的产业扶贫政策。

1.根据农村低保对象劳动力、承包土地、生产技能等情况，按每人每年1600元的标准（根据市扶贫办每年调整标准适时调整）开展产业帮扶工作，由各区人民政府、育才生态区管委会统筹安排。各职能部门要在科技、就业、电商、旅游、光伏、金融、生态补偿、农业种植养殖、文化和体育等方面，按建档立卡贫困户相当的产业扶贫政策予以扶持。

2.市制定的建档立卡贫困户其他产业扶持政策，亦适用于农村低保对象。

五、步骤方法

（一）教育保障。

1.做好收集审核工作。各区人民政府、育才生态区管委会由民政部门牵头，教育部门配合，分秋季、春季两个学期，组织工作人员对农村低保家庭学生、特困供养学生的教育情况进行摸底排查，负责收集和审核相关材料，编制《农村低保家庭学生、特困供养学生教育资金补助表》等台账，并进行三级公示（村小组、村委会、区政府），公示无异议后，由各区人民政府、育才生态区管委会的民政部门将名单和所需资金形成书面报告，秋季学期在每年9月30日前，春季学期在每年3月15日前，以区政府（管委会）名义报送市民政局，由市民政局对各单位上报的名单和所需资金进行汇总。

2.做好信息核定工作。市教育局根据市民政局提供的名单，通过信息比对、查验学籍信息等多种方式，对农村低保家庭学生、特困供养学生受教育信息进行逐一核对，于每年10月30日前完成秋季学期核验工作，每年4月15日前完成春季学期核验工作。

3.做好资金发放工作。市教育局制定完善教育保障资金发放工作规程，根据核定的名单，分秋季、春季两个学期向市财政局提出用款申请，市财政局将用款计划下达市教育局，市教育局通过“一卡通”发放到农村低保家庭学生和特困供养学生或其监护人手中。并将发放名单和资金分别于每年6月20日和11月20日前抄送市民政局，由市民政局统一上报省民政厅。

（二）医疗保障。

1.落实先诊疗后付费，实行“一站式”结算绿色通道服务工作。全市定点医疗机构为救助患者住院、门诊治疗提供绿色通道，优先安排住院、门诊治疗，医疗机构先垫付政策范围内医疗费用。市人力资源和社会保障局、市卫计委、市扶贫办、市民政局等部门应积极与基本医疗保险定点医疗机构协调，实施“一站式”即时结算。

2.全额资助参加城乡居民基本医疗保险。各区人民政府、育才生态区管委会的民政部门，应于城乡居民基本医疗保险征缴工作开始前，将本辖区内农村低保对象、特困人员名单提供给负责的征缴机构。并做好参保动员工作，确保人费对应、足额参保、及时参保。

（三）住房保障。

1.做好收集审核工作。各区人民政府、育才生态区管委会由民政部门牵头，住建部门配合，组织工作人员对农村低保对象、特困人员的住房情况进行摸底排查，并对其住房进行危房级别鉴定，初步筛选出符合农村危房改造条件的对象，负责收集和审核相关材料，编制《农村低保家庭、特困人员住房保障资金补贴表》等台账，并进行三级公示（村小组、村委会、区政府），公示无异议后，由各区人民政府、育才生态区管委会的民政部门将名单和所需资金形成书面报告，在每年4月30日前以区政府（管委会）名义报市民政局，由市民政局对各单位上报的名单和所需资金进行汇总。

2.做好危房改造的认定工作。市住房和城乡建设局根据市民政局提供的名单，转发到各区人民政府、育才生态区管委会的住建部门，并督促住建部门组织专业技术人员逐户逐屋精准识别，核定农村低保对象、特困人员房屋的安全状况和危房改造意愿。5月底前按照危房改造相关程序，完成建立完善危房改造档案工作。

3.做好资金发放工作。市住房和城乡建设局根据确定最终改造对象的贫困类型，按照改造施工进度，做好资金分配方案并向市财政局提出拨款申请，拨付给各区人民政府、育才生态区管委会。由各区人民政府、育才生态区管委会的住建部门根据实际情况，按照施工进度或竣工验收合格后，通过“一卡通”或根据实际情况把补助资金拨付到符合改造条件的农村低保对象、特困人员手中，并将拨款名单和拨款资料归档抄送给民政部门。由各区人民政府、育才生态区管委会的民政部门分别于每年6月20日和11月20日前上报市民政局，由市民政局统一上报省民政厅。

（四）产业扶持。

1.做好收集审核工作。各区人民政府、育才生态区管委会由民政部门牵头，人社、农业部门配合，组织工作人员对农村低保对象进行摸底调查，逐户摸清农村低保对象中劳动力人数、劳动力就业状况、就业需求、产业扶持等详细信息，编制《三亚市农村低保家庭产业扶持资金补贴表》等台账，同时对有劳动能力且有脱贫意愿的农村低保对象所需帮扶资金进行测算，制订产业扶持计划，以区政府（管委会）名义形成书面报告于每年的5月底前报市民政局，由市民政局对各单位上报名单和所需资金进行汇总，报市财政局审核。

2.做好产业扶持工作。各区人民政府、育才生态区管委会根据农村低保对象在劳动力、承包土地、生产技能等方面的实际情况，将帮扶工作纳入本区的扶贫工作计划，因地制宜，统筹使用帮扶专项资金，开展产业帮扶工作。在旅游、农业种植养殖、光伏、电商、金融、就业、科技、文化和体育等方面，各职能部门要结合扶贫开发政策，将有劳动能力且有脱贫意愿的农村低保对象纳入帮扶范围，参照建档立卡贫困户相当的产业扶贫政策开展产业帮扶工作。

3.做好资金统筹使用工作。各区人民政府、育才生态区管委会根据本区的扶贫工作计划，向市财政局提出用款申请，市财政局将用款计划下达各区人民政府、育才生态区管委会，由各区（管委会）按照实际情况把资金补贴到有劳动能力且有脱贫意愿的农村低保对象手中，并将产业扶持名单和资金使用情况分别于每年6月20日和11月20日前抄送市民政局，由市民政局统一上报省民政厅。

六、资金筹措

农村低保对象、特困人员的教育、医疗、住房保障和产业扶持所需资金，由市政府优先从历年结余的低保专项资金、盘活困难群众基本生活救助补助资金等存量资金中安排。确有缺口的，从省级和市财政专项扶贫资金中安排。

七、发放方式

教育、医疗、住房和产业扶持资金，由市财政局分别将所需资金划拨到市教育局、市卫计委、市民政局、市住房和城乡建设局、各区人民政府、育才生态区管委会等单位，由各单位严格按照财经程序拨付到位。

八、工作要求

（一）加强组织领导。成立农村低保对象特困人员教育医疗住房保障和产业扶持工作领导小组，组长由分管民政工作的副市长担任，成员由市民政局、市教育局、市卫计委、市农业局（市扶贫办）、市住房和城乡建设局、市旅游委、市人力资源和社会保障局、市财政局、市科技工业信息局、市文化广电出版体育局、市交通运输局、市水务局、市园林环卫局、市生态环境局、市规划局、市林业局、市金融办、市商务会展局、市供销社、三亚供电局、各区人民政府、育才生态区管委会等负责扶贫工作的单位组成。领导小组下设办公室在市民政局。领导小组负责研究制定农村最低生活保障对象、特困人员“三保障”和产业扶持工作重要事项和重大工作决策，领导小组办公室负责组织实施、统筹协调和督促检查，确保各项工作落实到实际行动上，落实到具体工作中。各区人民政府、育才生态区管委会是“三保障”和产业扶持工作的责任主体，应充分发挥组织领导作用，确保有关制度和政策得到有效落实。

（二）加强队伍建设。各区人民政府、育才生态区管委会要结合扶贫开发工作，加强帮扶队伍建设，要选派综合素质好、熟悉农村工作、事业心强的干部担任帮扶责任人，跟踪服务、推动落实。

（三）建立帮扶台账。各区人民政府、育才生态区管委会要对农村最低生活保障对象、特困人员的教育、医疗、住房保障和产业扶持情况，逐户建立帮扶台账，要严格按照一户一册标准印发《农村低保对象、特困人员“三保障”和产业扶持帮扶手册》，并发放到农村低保对象、特困人员手中。组织帮扶联系人做好帮扶手册的填写工作，如实、规范记录农村低保对象、特困人员获得各项帮扶情况。

（四）加强信息共享。市民政局、市教育局、市卫计委、市农业局、市扶贫办、市住房和城乡建设局、市人力资源社会保障局、市财政局等单位要建立健全信息沟通，使农村低保对象、特困人员教育、医疗、住房保障和产业扶持信息系统与本单位信息系统互联互通、相互衔接，建立的信息系统应当数据真实、清晰完整，进行动态管理。各职能部门之间加强协作，做到互通信息，实现信息共享。

（五）加强政策宣传。各区人民政府、育才生态区管委会和相关职能部门要加大对农村低保对象、特困人员的教育医疗住房保障和产业扶持政策宣传力度，要充分利用村（居）委会政务公开栏、村庄、主次干道沿线醒目的位置宣传帮扶政策，并通过广播、电视、微信平台、网络、报刊等媒体进行广泛宣传，提高救助政策的透明度，接受社会监督。

（六）强化监督检查。农村低保对象、特困人员“三保障”和产业扶持工作列入社会救助绩效考核，建立问责机制，成立以民政为牵头单位，组织、审计、财政、住建、人社、教育、卫计等部门为配合单位的监督检查小组，加强对各区人民政府、育才生态区管委会开展的帮扶工作进行监督检查。由市民政局根据各单位按月报送的工作进展情况形成督查通报，联合市政府督查议案室印发，由市委督查室、市政府督查议案室共同督查落实，确保督查指导工作取得成效。
