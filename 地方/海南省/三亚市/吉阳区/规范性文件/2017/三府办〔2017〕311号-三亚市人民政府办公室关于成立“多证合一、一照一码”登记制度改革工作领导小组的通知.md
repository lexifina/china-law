# 三亚市人民政府办公室关于成立“多证合一、一照一码”登记制度改革工作领导小组的通知

三亚市人民政府办公室

关于成立“多证合一、一照一码”

登记制度改革工作领导小组的通知

各区人民政府，各管委会，市政府直属各单位：

为深入贯彻落实《海南省人民政府办公厅关于加快推进“多证合一、一照一码”登记制度改革的实施意见》（琼府办〔2017〕135号），经市政府同意，决定成立三亚市“多证合一、一照一码”登记制度改革工作领导小组，具体组成人员及职责分工如下：

领导小组下设办公室设在市工商行政管理局，由市工商行政管理局副局长林尤才兼任办公室主任，市政府政务服务中心副主任吴清蓉、市工商行政管理局登记改革办主任黄熠娜任办公室副主任。领导小组成员单位各派1名人员担任办公室成员。

二、主要职责

（一）领导小组职责

1.贯彻落实中央和中共海南省委、海南省人民政府关于推进“多证合一、一照一码”登记制度改革的重要指示精神，统筹推进全市“多证合一、一照一码”登记制度改革工作，协调解决工作中遇到的问题，提出工作目标，落实好各项任务分工，确保改革目标实现。

2.协调有关部门做好全市登记改革工作部署与安排，研究、解决人员、经费保障等工作问题。

3.根据工作目标，进行宏观指导、督促检查和考核。

4.研究、讨论和决定登记制度改革工作的其他事项。

（二）领导小组办公室职责

1.组织研究、制定全市“多证合一、一照一码”登记制度改革重大政策和运行机制，拟订工作计划并组织实施，负责组织协调、政策解读、工作落实和对外宣传工作。

2.统筹、指导、协调全市登记制度改革工作，承担改革推进协调例会具体工作及工作开展的相关统计分析。

3.组织开展工作督查。

4.负责做好市委、市政府交办的其他重点工作。

三、工作要求

（一）领导小组各成员单位要按照各自职责和整合任务，主动作为，积极研究相关配套政策措施，认真落实解决证照整合后遇到的数据衔接问题。

（二）领导小组办公室要及时向各成员单位通报有关情况；各成员单位要互通信息、密切配合、相互支持、形成合力。
