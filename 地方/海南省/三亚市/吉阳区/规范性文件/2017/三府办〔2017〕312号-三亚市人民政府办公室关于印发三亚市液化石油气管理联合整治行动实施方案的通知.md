# 三亚市人民政府办公室关于印发三亚市液化石油气管理联合整治行动实施方案的通知

三亚市人民政府办公室

关于印发三亚市液化石油气管理联合整治行动实施方案的通知

各区人民政府，各管委会，市政府直属各单位：

《三亚市液化石油气管理联合整治行动实施方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年9月30日

（此件主动公开）

三亚市燃气管理联合整治行动实施方案

为进一步加强我市燃气管理，构建起部门联合执法机制，加大对违法违规行为的处罚力度，杜绝燃气安全事故，结合我市实际，制定本方案。

一、整治的目的

通过建立起多部门联合执法机制，开展联合整治行动，从根本上解决过去燃气管理方面各部门各自为战、缺乏联动的问题，以达到齐抓共管、标本兼治的效果，在年底前取得明显成效，基本实现常态化管理。

三、任务目标

通过拉网式排查整治，严厉查处一批燃气管理方面的典型违法违规行为，取缔非法经营的燃气经营场所、燃气储存场所、燃气使用场所，清理拆除燃气设施保护范围内的违法建（构）筑物，保护燃气设施安全，进一步规范燃气经营单位的经营行为，消除燃气管理方面的安全隐患，有效杜绝燃气安全事故发生。

四、时间安排

（一）摸底排查阶段（2017年9月）。各区人民政府、管委会和相关职能部门根据职责分工，开展摸底排查，建立问题台账，并责令当事人立即整改；同时，对存在严重安全隐患的，按照“边排查、边处罚、边整改”的原则进行处理。

（二）集中整治阶段（2017年10月至12月）。各区人民政府、管委会和相关职能部门根据排查出的问题台账，组织力量，对当事人自行整改情况进行“回头看”，对整改不到位的依法进行处罚，并采取有效措施消除安全隐患。领导小组办公室结合市民投诉举报和媒体曝光，每月组织开展全市性的联合整治行动。

（三）常态管理阶段（2018年起）。各区人民政府、管委会和相关职能部门各司其职，共同做好燃气管理工作，形成执法合力。市、区综合执法部门不定期协调相关单位开展联合整治行动，严查违法违规行为。

五、整治内容

根据《城镇燃气管理条例》和《海南省燃气管理条例》的有关规定，开展拉网式排查整治，依法查处违法违规行为。

（一）查处无证照经营的场所。包括燃气经营场所，储存燃气场所，燃气设施经营场所，在经营活动中使用燃气的场所（如餐饮店）等。

（二）查处违规使用燃气设施行为。包括把燃气管道作为负重支架或接地引线，擅自安装、改装、拆除燃气设施和燃气计量装置，进行危害室内燃气设施安全的装饰、装修等活动，燃气燃烧器具的安装、维修不符合国家有关标准，擅自操作公用燃气阀门，加热、摔砸、倒卧、曝晒燃气气瓶，改换燃气气瓶检验标志、漆色，倾倒燃气残液，盗用燃气，改变燃气用途或转供燃气，用燃气气瓶相互转充等。

（三）查处危害燃气设施行为。包括在燃气设施保护范围内擅自进行焊接、烘烤、爆破、取土等作业，动用明火，倾倒、排放腐蚀性物质，放置易燃易爆物品，种植植物，未采取安全保护措施从事敷设管道、打桩、顶进、挖掘、钻探等活动，建设占压地下燃气管线的建筑物、构筑物或其他设施，侵占、损毁、擅自拆除、移动燃气设施，擅自改动市政燃气设施，损毁、覆盖、涂改、擅自拆除或移动燃气设施安全警示标志，在管道设施上牵挂电线、绳索或晾晒衣物，建设工程未采取安全保护措施等。

（四）查处燃气经营者违规经营行为。包括不按照燃气经营许可证的规定从事燃气经营活动，在不具备安全条件的场所使用、储存燃气，未设立售后服务站点，未配备经考核合格的燃气燃烧器具安装、维修人员，拒绝向市政燃气管网覆盖范围内符合用气条件的单位或个人供气，倒卖、抵押、出租、出借、转让、涂改燃气经营许可证，未履行必要告知义务擅自停止供气、调整供气量，未经审批擅自停业或歇业，未向燃气用户持续、稳定、安全供应符合国家质量标准的燃气，未对燃气用户的燃气设施定期进行安全检查，擅自为过期未检测气瓶或不合格气瓶充装燃气，未按规定设置燃气设施防腐、绝缘、防雷、降压、隔离等保护装置和安全警示标志，未定期对燃气设施进行巡查、检测、维修和维护，未采取措施及时消除燃气安全事故隐患等。

六、职责分工

（一）市综合行政执法局：负责对各区的整治工作进行指导、培训、检查、督促，牵头组织开展全市性的联合整治行动。

（二）各区人民政府、管委会：负责辖区范围内的整治工作，组织开展区一级联合执法行动。

（三）市住房和城乡建设局：负责协调燃气经营单位派出技术人员协助各区人民政府、管委会和市综合行政执法局开展整治工作，督促燃气经营单位对经营场所及周边、燃气管道沿线、用户屋内燃气管道及燃气设施等方面定期进行检查，并将检查情况报各区人民政府、管委会和市综合行政执法局。

（四）市安全生产监督管理局：负责配合各区人民政府、管委会和市综合行政执法局开展整治工作，参加市级联合执法行动。

（五）三亚质量技术监督局：负责对气瓶等设施进行检查，配合各区人民政府、管委会和市综合行政执法局开展整治工作，参加市级联合执法行动。

（六）市工商行政管理局：负责依法查处无营业执照的经营场所，配合各区人民政府、管委会和市综合行政执法局开展整治工作，参加市级联合执法行动。

（七）市公安局：负责对构成犯罪的行为依法追究刑事责任，依法处置阻挠执法及暴力抗法事件，配合各区人民政府、管委会和市综合行政执法局开展整治工作，参加市级联合执法行动。

（八）市公安消防支队：负责对燃气经营场所、储存燃气场所、使用燃气场所的消防状况进行检查，配合各区人民政府、管委会和市综合行政执法局开展整治工作，参加市级联合执法行动。

七、工作要求

（一）加强组织领导。各单位要高度重视，提高认识，加强液化石油气管理工作的组织领导，制定细化性实施方案，按照“边排查、边处罚、边整改”的原则开展整治行动，坚持有问题必整改、整改不到位就处罚、情节严重的边罚边改，确保问题全部整改到位。

（二）加强执法协作。各单位要树立“全市一盘棋”的观念，积极主动地配合市、区综合执法部门开展整治工作，相关部门要派出技术人员，确保整治行动顺利开展。

（三）加强信息报送。各单位要根据管理职责开展整治工作，每月5日前将整治情况报送领导小组办公室。相关职能部门排查发现的问题要及时函送属地区人民政府、管委会。市住房和城乡建设局要督促燃气经营单位建立定期检查报告制度，每月将检查情况报送各区人民政府、管委会和市综合行政执法局。
