# 三亚市人民政府办公室关于印发三亚市2017年度农田水利基本建设实施方案的通知

三亚市人民政府办公室

关于印发三亚市2017年度农田水利

基本建设实施方案的通知

各区人民政府，育才生态区管委会，市各有关单位：

《三亚市2017年度农田水利基本建设实施方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年10月18日

（此件主动公开）

三亚市2017年度农田水利基本建设实施方案

为深入贯彻落实党中央、国务院关于大规模推进农田水利建设的决策部署，加快创新和完善体制机制，组织发动社会各方力量，持之以恒地开展冬春农田水利基本建设，为三亚经济社会发展良好开局提供有力的水利支撑。按照省水务厅的统一部署，结合当前水利工作实际及今冬明春农业生产用水情况，制订我市今冬明春农田水利基本建设实施方案。

一、指导思想

坚持以十八届六中全会精神为指导，牢固树立新发展理念，积极践行中央新时期水利工作方针，进一步加强组织领导，创新体制机制，增加资金投入，强化规划统筹，规范建设管理，重视运行管理，以病险水库除险加固、中小型水库配套设施完善、排沟整治、农田综合整治、农村饮水安全等工程建设为重点，通过政府的强力推动，受益农户和社会力量积极参与，有组织、有计划地开展农田水利基本建设，巩固农业基础，为促进农业增产、农民增收、农村发展夯实物质基础。

二、目标任务

实施完成高标准田洋整治工程5宗；渠道防渗改造4宗，新增防渗渠道47条，长73公里，受益面积7.61万亩；病险水库加固1宗；农村饮水安全工程3宗；水毁工程修复50宗等。

改善灌溉面积5.94万亩，改善排涝面积0.87万亩，新增节水灌溉面积3.16万亩（渠道防渗），改造中低产田0.9万亩，解决不安全饮水受益人数74528人。计划完成投资98056万元，其中：中央投资7886万元，省投资924万元，市财政投资80433万元，区投资8813万元。计划完成工程量：土方231.1万方，石方39.33万方，砼66.57万方。

三、工作重点

（一）抓好高标准农田整治，改善农业基础设施条件

为提高农业综合生产能力，提升抵御自然灾害能力，改善农业基础设施条件，促进农业生产和农村经济结构调整，各区（育才生态区）要按照《三亚市人民政府办公室关于印发三亚市小型农田水利设施工程管护实施方案的通知》（三府办〔2017〕224号）的要求，作好辖区内小型农田水利设施工程管护工作。今年重点抓好5宗高标准农田整治项目：崖州区郎芒田洋高标准农田项目、海棠区落根田洋高标准农田项目、吉阳区新村田洋高标准农田项目、崖州区白超田洋高标准农田项目、崖州区水南田洋高标准农田项目；5宗渠道建设工程：赤田水库灌溉渡槽维修改造工程、大隆西干渠改迁工程、高园水库—大茅水连通工程、高峰渠道工程、育才渠道工程；3宗河道及排沟建设工程：三亚市三亚东河生态修复工程（溪泽三桥—东环高铁段）、落根排沟清淤工程、中和河道综合整治工程。

（二）加强水库维护工作，确保水库安全度汛

为充分发挥水库防洪蓄水效益，各工管单位应继续加强我市大中型水库设备维修养护和大坝管理，各区（育才生态区）应继续加强我市小型水库管护，确保我市水库运行安全，保障下游人民的生命财产安全及灌溉用水。今年重点完成1宗病险水库加固工程：茅彭水库除险加固工程；4宗水库配套工程：区间水库溢洪道改造及防洪公路工程、汤他水库放水涵及溢洪道应急加固工程、水源池水库弧形闸门启闭机及启闭机室更新改造工程、石姆隆水库溢洪道尾端工程。

（三）加快农村饮水安全工程建设，确保农民生活用水

农村饮水安全是我市统筹城乡发展，实现城乡公共服务均等化的一项重要民生工程。我市农村饮水安全工作应继续坚持“建管并重”的原则，既要继续加大投资和建设力度，完成农村饮水安全工程建设任务，更要积极推进建立起符合三亚实际的、良性的农村饮水安全工作管理体制机制，保障我市农村饮水安全工程长效运行。今年重点建设3宗饮水安全工程：2017年三亚市农村饮水安全工程、北部山区饮水安全工程以及红塘、槟榔等村饮水安全工程。

各区（育才生态区）要作好农村饮水安全工程建后管护工作，将辖区内农村饮水安全工程委托海南天涯水业（集团）公司统一管理，实现抄表到户，确保农村饮水安全工程长效运行。

（四）加快水毁工程修复，确保水利设施正常发挥

尽快完成水毁工程的修复任务，保证今冬明春生产用水，各区（育才生态区）要抓紧水毁工程的修复及面上渠道维修。今年我市计划修复水毁工程50处，其中：崖州区15处，天涯区12处，吉阳区9处，海棠区9处，育才生态区5处。

四、任务分解

（一）市水务局及各工管单位

实施或完成吉阳区新村田洋高标准农田项目、三亚东河生态修复工程（溪泽三桥—东环高铁段）、赤田水库灌溉渡槽维修改造工程、大隆西干渠改迁工程、区间水库溢洪道改造及防洪公路工程、茅彭水库除险加固工程、高园水库—大茅水连通工程、汤他水库放水涵及溢洪道应急加固工程、水源池水库弧形闸门启闭机及启闭机室更新改造工程、北部山区饮水安全工程（原水工程）等工程建设任务。

（二）市农综办

完成崖州区郎芒田洋高标准农田项目、海棠区落根田洋高标准农田项目等工程建设任务。

（三）吉阳区

完成吉阳区小型水库及其以下水库配套设施工程、水毁修复工程等建设任务。

（四）海棠区

完成石姆隆水库溢洪道尾端工程、落根排沟清淤工程及水毁修复工程等建设任务。

（五）天涯区

完成高峰渠道工程、中和河道综合整治工程、红塘、槟榔等村饮水安全工程及水毁修复工程等建设任务。

（六）崖州区

完成崖州区白超田洋高标准农田项目、崖州区水南田洋高标准农田项目及水毁修复工程等建设任务。

（七）育才生态区

完成育才渠道改造工程及育才渠道水毁工程等建设任务。

五、时间安排

（一）2017年9月至10月，制定全市农田水利基本建设实施方案，宣传发动；

（二）2017年10月至12月，全面掀起农田水利基本建设高潮；

（三）2018年1月中旬，组织全市农田水利基本建设检查评比。

六、主要措施

（一）科学筹划  注重实效

各区（育才生态区）要认真总结近几年农田水利基本建设工作经验，本着因地制宜、突出重点、讲求效益的原则，科学规划、统筹安排，制定好本辖区农田水利基本建设实施方案。方案中要重点突出效益好、见效快的“民生水利”项目。在全面维修现有水利设施的基础上，加大渠道防渗配套的力度，完成病险水库除险加固,不断提高农业抗灾和减灾能力。要统筹安排农田水利基本建设和冬种的时间，做到冬修冬种两不误。

（二）加大投入  多方筹资

积极探索创新农田水利基本建设投入机制，各区（育才生态区）可采取“四个一点”的办法，即中央、省和市财政扶持一点、区财政配套一点、社会赞助一点、受益农户出一点，多渠道、多层次、多方面筹集资金。要建立起中央、地方和农户投资投劳相结合的有效投入机制。各区（育才生态区）要把农田水利基本建设资金列入财政预算，落实农田水利基本建设资金。同时，要利用好有关政策，合理有效地整合农业综合开发、扶贫、土地复垦等各种涉农资金用于农田水利基本建设。各区（育才生态区）应采取有效措施，确保农田水利基本建设资金足额按时到位。

（三）正确引导  发动群众

农田水利基本建设是农业增产、农民增收的基础性工作，农民群众是最大的受益者，同时也是投入的主体之一，要正确理解减轻农民负担和发动农民自愿投工投劳改善自己生产条件的政策。在组织形式上要改变用行政命令的手段强迫农民出工的方式，通过政策推动、改革促动、效益驱动等形式，引导广大农民投工投劳，发动广大农民群众积极投身于农田水利基本建设热潮之中。

（四）深入指导  确保质量

各区（育才生态区）要加强工程项目的前期工作，搞好规划设计；强化建设管理，认真执行项目法人负责制、招标投标制、工程监理制、项目合同制和竣工验收制。要组织工程技术人员深入工程建设第一线，加强施工指导，确保工程施工质量。工程完工后，要按照有关规定，及时组织验收。

（五）加强领导  落实责任

为了加强对全市农田水利基本建设工作的领导，市政府成立农田水利基本建设指挥部，由市政府李劲松副市长任总指挥，市水务局局长马育红任副总指挥。下设办公室，设在市水务局，负责农田水利基本建设日常工作。各区（育才生态区）也要成立农田水利基本建设工作领导机构,加强组织领导，落实责任，做到主要领导亲自抓，分管领导具体抓，各级领导共同抓，把农田水利基本建设作为实践科学发展观和推进农村改革发展的大事来抓，将农田水利基本建设纳入今冬明春农村工作重点来抓，确保全面完成今冬明春农田水利基本建设任务。

同时，采取多种形式宣传农田水利基本建设的重要意义，营造农田水利基本建设的良好氛围，以优异成绩迎接全省农田水利基本建设检查评比，市政府将继续对2017年度农田水利基本建设先进区进行表彰。

（一）海棠区：由市水务局规划建设科负责，赤田水库管理处协助（电话：88678531）；

（二）吉阳区：由市水务局农村水利科负责，半岭水库管理处协助（电话：88273224）；

（三）天涯区：由市三防办公室负责，汤他水库管理处协助（电话：88678535）；

（四）崖州区：由大隆水利工程管理局负责（电话：88650311）；

（五）育才生态区：由城市水务科负责，水源池水库管理处协助（电话：88205594）；

各区（育才生态区）要抓紧与市水务局各科室及包点单位联系，做好农田水利基本建设项目的前期工作，按时、按质、按量完成今年农田水利基本建设任务。每周以书面形式向市农田水利基本建设指挥部办公室汇报工作进展情况，以便编制全市农田水利基本建设简报，并做好汇总上报。（地址：市水务局农村水利科，联系电话：88678534、88678530）
