# 三亚市人民政府办公室关于三亚市漳波河水环境综合整治工程（225国道～西线高速公路桥）项目土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市漳波河水环境综合整治工程

（225国道～西线高速公路桥）项目

土地调查有关事项的通知

崖州区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对漳波河水环境综合整治工程（225国道～西线高速公路桥）项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于崖州区辖区内，用地调查面积约201107平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见三亚市水务局出具的三亚市漳波河水环境综合整治工程（225国道～西线高速公路桥）征地范围平面布置图（已在三亚市规划局审核出具的项目用地红线范围内扣除基本农田占用部分）。土地权属（海南平面坐标系）情况为崖州区临高、乾隆、保平、港门、港一和港二（原详查资料）村委会集体土地共约148205平方米，国家所有土地约28230平方米，临高小学和保平小学国有土地共约5936平方米，三亚意源养殖有限公司国有土地约7258 平方米，海南三亚电业公司国有土地约1平方米，海南海控燃料化学控股有限公司国有土地约118平方米，保港镇政府（原详查资料）土地约178平方米；土地利用现状（西安80坐标系）为农用地约149552平方米（其中水田约2701平方米、旱地约26291平方米、其他园地约8906平方米、其他草地约876平方米、坑塘水面约2278平方米、设施农用地约108499平方米），建设用地约40538平方米（其中河流水面约23829平方米、建制镇约 8925平方米、村庄约6102平方米、采矿用地约1288平方米、风景名胜及特殊用地约394平方米）；该项目用地在土地利用总体规划调整完善（西安80坐标系）中规划为城镇用地约13220平方米、公路用地约1807平方米、旱地约6178平方米、河流水面约22749平方米、坑塘水面约1070平方米、农村居民点用地约3533平方米、设施农用地约105968平方米、园地约35566平方米。该项目为水环境整治工程，不列入农用地转用及征收报批计划。具体征地范围以市水务局与崖州区政府现场实际勘测确认为准，现既有河流水面不列入该项目土地调查范围。

二、为做好该项土地调查工作，由崖州区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土资源局负责征收集体土地范围内征地业务指导工作；市住房城乡建设局负责收回国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行；收回国有土地征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、根据2010年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，崖州区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认工作。

五、为进一步做好被征地农民养老保险工作，崖州区政府应根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅 2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神办理。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
