# 三亚市人民政府办公室关于成立三亚市推进农业水价综合改革工作领导小组的通知

三亚市人民政府办公室

关于成立三亚市推进农业水价综合改革

工作领导小组的通知

各区人民政府，育才生态区管委会，市各有关单位：

根据《海南省人民政府办公厅关于印发海南省推进农业水价综合改革实施方案的通知》（琼府办〔2017〕49号）和《海南省物价局海南省财政局海南省水务厅海南省农业厅转发国家发展改革委财政部水利部农业部国土资源部关于扎实推进农业水价综合改革的通知》（琼价价管〔2017〕420号）文件精神和市领导指示精神，为有序推进我市农业水价综合改革工作，加强组织领导，完善改革机制，细化目标任务，市政府作为全市农业水价综合改革的责任主体，成立由常务副市长任组长，分管副市长任副组长，市发改、财政、水务、农业、各区（育才生态区）等相关职能部门负责人为成员的市农业水价综合改革领导小组，负责相关工作的统筹协调和组织推进。小组成员如下：

领导小组下设办公室，负责农业水价综合改革工作协调和领导小组日常工作。办公室设在市水务局，办公室主任由马育红兼任，副主任由谢志军（市水务局副局长）和朱鹏雄兼任。相关部门明确责任分工，细化落实责任，切实履行职责，强化协调配合，通力合作，形成合力，协同推进改革。价格主管部门牵头制定农业水价综合改革实施方案，负责做好成本监审、水价制定等工作；财政部门负责整合相关资金，统筹落实工程建设和改革经费；水行政主管部门牵头实施农业水价综合改革，提出农业水价综合改革年度实施计划，负责农田水利工程建设配套改造，完善用水计量设施，推进水利工程管理体制改革，开展农业水定额管理工作，会同财政、价格、农业等部门研究建立农业用水精准补贴和节水奖励机制，指导水费收支管理；农业部门负责农业节水措施推广应用，调整农业结构，加强农业用水需求管理，调查统计不同用水类型用水数量；其他有关部门要按照各自职能做好相关工作。

领导小组组成人员因工作（职务）变动不再担任成员的，由继任者自动接任或所在部门指派人员担任。
