# 三亚市人民政府办公室关于印发三亚市参加2017年中国（海南）国际热带农产品冬季交易会工作方案的通知

三亚市人民政府办公室

关于印发三亚市参加2017年中国（海南）国际

热带农产品冬季交易会工作方案的通知

各区人民政府，育才生态区管委会，市各有关单位：

《三亚市参加2017年中国（海南）国际热带农产品冬季交易会工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年11月23日

（此件主动公开）

三亚市参加2017年中国（海南）

国际热带农产品冬季交易会工作方案

根据海南省人民政府办公厅《关于印发2017年中国（海南）国际热带农产品冬季交易会筹备工作方案的通知》（琼府办函〔2017〕413号）文件精神，省政府决定在2017年12月12日至15日在海南国际会展中心举办2017年中国（海南）国际热带农产品冬季交易会。为了切实展示我市热带高效农业风采和扶贫成效，确保2017年冬交会的各项筹备工作真正落到实处，特制定本方案。

一、主题、宗旨和原则

为全面贯彻党的十八大、十九大和省第七次党代会精神，落实省委、省政府的重大决策部署，推动农业供给侧结构性改革，打造热带特色高效农业王牌，本届冬交会我市秉承以“共创农业新机遇，争当建设美好新海南排头兵”为主题；以“展示发展成果、加强交流合作、促进商贸流通”为宗旨；以“创新、绿色、节俭、高效”为办会原则，通过突出宣传我市优越的生态环境和资源优势，充分展示我市热带特色农业发展成果、精准扶贫成果，促进我市优质农产品对外交易、农业交流合作共建共赢和一、二、三产业衔接融合，带动农民增收、农业提质增效。

二、组织机构

（一）三亚市代表团

团  长：吴岩峻（市政府市长）

副团长：李劲松（市政府副市长）

参会工作人员由“冬交会”筹备工作领导小组根据需要从有关单位抽调。

三、重点工作内容及任务

（一）邀请客商、落实订单

时间：11月2日—11月30日

工作内容：市农业部门要及时组织各区（育才生态区）农业部门和农业龙头企业、农业专业合作组织赴内地考察市场，落实订单，做好产销衔接工作。落实客商邀请工作，重点邀请我市农产品主销地的收购商、市场负责人、农产品流通质量安全主管部门负责人。

牵头单位：市农业局，配合单位：各区政府、育才生态区管委会

（二）布展筹备工作

时间：11月2日—12月11日

工作内容：

1.展馆：对三亚展馆进行设计和建设，展馆设计与建设要坚持“简约、明快、实用”的原则，展示我市热带果蔬、林产品、水产品、畜禽产品、花卉产品、热作产品、休闲农业、品牌和包装及“互联网+农业”等，充分突出我市热带特色现代农业发展成果、精准扶贫成果。并按要求将布展设计平面图和效果图送省筹备办公室审定。

2.展品：参展展品包括热带水果、冬季瓜菜、南繁产品、畜禽产品、林业产品、海产品和加工品等特色农产品。参展产品以省级以上品牌产品为主，要具有包装和品牌；采取各区（育才生态区）推荐或企业、合作社自荐相结合的方式报名。

参展的水果和瓜菜（鲜活畜禽产品除外）必须由市现代农业检验检测预警防控中心通过定量检测合格（送检样品与参展产品必须出自同一生产者和同一生产基地），并张贴可追溯的二维码标识；参展加工品必须是质量合格，通过相关认证的产品。林产品和花卉产品由市林业局负责，水产品由市海洋渔业局负责，最后参展企业、合作社名单，由市农业局根据参展需要统筹考虑确定。

牵头单位：市农业局，配合单位：各区政府、育才生态区管委会

（三）参加开幕式

我市代表团全体成员参加12月12日上午9:00在海口市海南国际会展中心前广场举行的主会场开幕式。

市农业局负责代表团参加开幕式的总协调和组织工作，各区（育才生态区）具体负责组织本辖区内参展人员按时参加。

牵头单位：市农业局，配合单位：领导小组各成员单位

（四）省外农业项目招商和农产品产销订单对接活动

11月中下旬，由市农业局组织各区（育才生态区）农业部门和部分企业全国重点城市开展大型农产品批发市场开展农业项目招商和瓜果菜等农产品产销订单对接活动。

牵头单位：市农业局，配合单位：各区政府、育才生态区管委会

（五）组织参加冬交会系列活动

时间：12月11日—12月15日

工作内容：参加海南品牌农产品推介会、海南农产品网上交易暨专业采购团签约仪式、农业品牌高端论坛、“家乡的味道，我为品牌农产品代言”推介公益活动暨海南十佳公共区域品牌农产品评选发布和海南农产品十大运销商评选颁奖活动、互联网+共享农庄研讨会、乡村振兴与农产品区域公用品牌建设高端论坛、全国农产品加工业区域经济合作交流座谈会、农业投资项目招商（含市县）推介会、全国供销社系统合作高峰论坛暨农业招商项目推介、“央视看冬交会”美丽海南乡村行和“一带一路”中外新闻媒体记者聚焦冬交会活动等。组织邀请我市农产品主销地的收购商、市场负责人、农产品流通质量安全主管部门负责人考察我市农业生产基地、三亚品牌农业展示中心等。

牵头单位：市农业局，配合单位：各区政府、育才生态区管委会、市供销合作社

四、经费来源

由市农业局从年初冬交会项目预算经费中列支（其中省外农业项目招商和农产品产销订单对接活动由市农业局农产品网络运转经费中列支）。

五、工作要求

（一）加强领导。各责任单位要统一思想、高度重视，充分认识到办好冬交会对推动我市农业供给侧结构性改革和促进农民增收的积极意见和作用。切实把思想和行动统一，加强组织领导，明确工作任务，细化落实责任，协调相关部门和企业，抓好各项工作的落实，确保筹备工作顺利完成。

（二）做好宣传。一是组织驻三亚媒体对“冬交会”进行全程采访报道，营造氛围，扩大影响。“冬交会”期间，创新采用专题报道、系列报道、专题采访等多形式、多渠道开展宣传。二是要编印宣传资料，制作三亚热带高效农业专题片，全方位介绍三亚丰富的热带农业资源、优美的旅游景观、良好的投资环境和独特的品牌农副产品等。三是要开展网上宣传，在网络、微信、直播等信息平台上推介三亚农业，扩大宣传力度，为促进我市农产品的线上线下交易营造氛围和创造良好条件。

（三）抓好促销。市各相关单位要积极主动组织企业与产销大户开展市场调研，根据我市冬季农产品上市时间早的特点，及早组织相关企业代表到销地市场开展产销对接、订单洽谈等活动，确保会展期间的订单贸易和项目招商取得新突破。

（四）精选展品。认真筛选展品，突出我市特色和精品立市的战略要求，实行参展销售农产品的严格准入制度，认真审查各参展企业的资质和参展展品的质量，坚决杜绝“三无”产品、证照不全企业等不安全产品企业参会参展，以高质量、严要求、全方位展示三亚精品“三农”形象。

（五）搞好总结。“冬交会”是全国知名的农业会展平台，是展示三亚“三农”的重要窗口。因此，各单位要以高度负责的态度认真抓好落实，策划好、包装好农业招商项目，确保责任、分工、人员、经费和措施“五到位”。会后要认真进行总结，找出不足，以便在今后的“冬交会”取得更好的成效。
