# 三亚市人民政府办公室关于贯彻落实“一市（县）两校一园”优质教育资源引进工作实施意见的通知

三亚市人民政府办公室

关于贯彻落实“一市（县）两校一园”优质教育

资源引进工作实施意见的通知

各区人民政府，各管委会，市政府各有关单位：

根据《海南省人民政府关于开展“一市（县）两校一园”优质教育资源引进工作的实施意见》（琼府〔2017〕52号）的文件精神，为进一步集聚国内优质教育资源，带动我市基础教育的创新发展，不断提高老百姓日益增长的优质教育需求，促进国内优质教育资源与我市教育合作项目的发展，现结合我市实际，就贯彻落实“一市（县）两校一园”优质教育资源引进工作通知如下。

一、 总体要求和工作目标

（一）总体要求。以促进义务教育均衡发展为基本出发点和落脚点，聚焦完善教育布局规划，优化教育资源配置，扎实推进优质教育资源引进工程。通过引进一批高层次的优秀校长、教师和管理团队，为三亚基础教育植入“优质基因”，辐射带动教育内涵发展，逐步缩小区域、城乡、校际差距，为建设经济繁荣、社会文明、生态宜居、人民幸福的美好新三亚提供人才支撑和智力支持。

（二）工作目标。切实落实《三亚幸福民生行动方案（2017-2021年）》中引进合作办学行动计划，在“十三五”期间，我市引进北京人大附中、上海外国语大学、北大附中、南京师范大学等国内优质教育资源创建4所以上优质学校，引进西南大学、海南中学、江苏阶梯教育集团等优质资源托管我市至少3所公立学校及幼儿园。引进的优质教育资源经过3-5年的合作办学，其中：普通高中（或完全中学）达到“省一级学校”办学水平，九年一贯制学校（或完全小学）达到“省级规范化学校”办学水平，幼儿园达到“省级示范园”办学水平。

二、优质教育资源引进的对象、内容和办学机制

（一）引进对象。全国著名的综合性大学、师范大学及附属学校，教育发达省市排名靠前、知名度高、群众口碑好的中学、小学和幼儿园。

（二）办学机制。发挥市场机制作用，积极探索公办、民办、混合制等多种形式，采取“独立办学”（省外名校在海南独立办学）、“整体托管”（将我市原有学校或新建学校、幼儿园整体委托省外名校管理）等多种办学方式。鼓励社会资本通过引进优质教育资源举办优质学校（幼儿园）。引进的优质教育机构要创新体制机制和管理运行模式，建立健全现代学校制度，形成政府引导、社会参与的多元办学格局。

（三）引进内容。引进的省外优质教育资源主要包括省外名校的品牌、先进管理理念和优秀管理团队等优质教育教学资源。在合作学校的领导班子中，省外名校委派的优秀校长、副校长人数不少于3名，并引进一定数量的中层管理干部和学科骨干教师等。

（四）辐射示范。引进省外优质教育资源举办的中小学（幼儿园）作为我市基础教育的示范基地和校长、教师培养、培训基地，在队伍建设、学校管理、教育教学实施、教育评价等方面发挥辐射、示范作用，带动我市中小学校（幼儿园）共同发展。合作办学的学校领导班子成员中也要有我市干部。

三、政策支持

（一）用地支持。市规划局、市国土资源局对引进的优质教育资源新办学校应给予支持。市规划局应将项目用地纳入我市总体规划，市国土资源局应在用地报批、土地供应及土地确权上给予支持，优先保障新增建设用地指标，根据国家有关用地标准，核定教育设施用地规模，切实落实国家、海南省及我市节约集约用地要求；对认定为非营利性教育设施用地且符合国家、海南省及我市划拨用地范围的，按照相关规定办理划拨供地手续。

（二）资金补助。引进优质教育资源所需经费主要由市财政承担。按省政府工作部署，省财政从2016年秋季学期起按最高1300万对我市引进工作进行奖补，我市每引进优质教育资源建成1所中学（含办学规模在1200人以上的普通初中、普通高中、完全中学和九年一贯制学校等）、一所小学（办学规模在800人以上）省财政一次性各奖补500万元，建成1所幼儿园（学位在360个以上）奖补300万元，上述奖补资金补助范围不包括对口帮扶的办学模式，市、区财政按照省奖补资金的比例再予以配套，奖补资金主要统筹用于解决名校品牌使用费、引进的优秀管理团队和骨干教师待遇及我市教育事业发展，三亚教育基金会可根据合作办学项目发展需求，给予一定的经费扶持。

（三）编制保障。市编制部门、市教育部门根据我市中小学教职工编制标准和合作学校的实际规模，在省下达我市中小学教职工总编制内合理调剂，核定公办合作学校的教职工编制。

（四）配套服务。各相关部门应为合作办学在规划报建、费用减免等方面给予政策倾斜，并开绿色通道，确保加快推进各项前期工作。我市鼓励为引进的合作学校无偿代建校园基础设施，实施“交钥匙工程”，积极创造条件在留住好校长、好教师上下功夫，为引进的优秀管理团队和骨干教师在配偶就业、子女入学升学、购房或房屋租赁、落户等方面提供配套服务，落实相应的引进人才待遇。市教育局可根据实际，将合作举办的公办优质高中学校上报省教育行政部门申请列入我市重点高中学校同一批次招生，为合作举办的公办高中学校连续3年每年每所学校申请安排50个招生计划，通过省中等学校招生考试面向全省招生。

（五）自主办学。各相关部门按职能分工配合市教育局按现代学校制度要求，制定相关政策，依法赋予校长（园长）在人事管理、财务管理、设备设施管理、教育教学管理方面的办学自主权，特别是在校园规划设计、校园文化建设、教师招聘等方面，要充分听取并尊重引进优质校长和派遣校长（园长）意见，积极支持学校独立开展各项教育活动，减少过多的行政干预。

（六）特别扶持。引进的省外优质教育资源品牌效应明显、对海南省或我市具有特别重大意义的学校，可实行“一事一议”或“一校一议”，予以特别支持。市（区）财政可根据财力实际，在柔性人才引进方面给予引进的公办性质的学校一定的财政经费支持，需要政府购买服务的，按购买服务方式办理。

四、保障措施

（一）加强组织领导

各区人民政府、各部门要提高认识，高度重视、以务实严格的态度千方百计把这件造福三亚老百姓的好事做实办好。要按照互惠互利的原则，加强顶层设计、认真研究长效机制，确保引进的优质教育资源真正发挥作用，让教育改革发展成果惠及更多老百姓。

各部门根据各自的职能分工，负责省外优质教育资源引进工作的宏观指导，提供政策和经费支持。市教育局牵头负责全市引进工作的统筹实施；市编办负责涉及编制相关政策的指导工作；市财政局负责对我市引进优质教育资源奖补资金的落实；市人力资源社会保障局、市教育局负责引进人才的专业技术资格认定和社保衔接；市公安局负责按政策规定为引进人才落户我市提高服务和指导；市国土资源局对合作办学新建学校、幼儿园用地划拨进行指导支持。各部门要配合市政府按各自职能分工落实好具体工作，把优质教育资源引进工程列为本单位重点工作之一。

（二）加强监督管理和考核评估

市教育局要加强对我市合作办学行为的监督，规范合作的中小学（幼儿园）在招生、编班、收费、执行课程方案、遵守作息时间等方面的办学行为。

（三）加大宣传推介

市教育局要配合市政府加大引进优质教育资源工作的宣传力度，采取多种渠道宣传推介引进工作，吸引全国优质高等学校、中小学校和幼儿园前来洽谈合作，培育先进典型，全面提升我市教育发展水平。

三亚市人民政府办公室
