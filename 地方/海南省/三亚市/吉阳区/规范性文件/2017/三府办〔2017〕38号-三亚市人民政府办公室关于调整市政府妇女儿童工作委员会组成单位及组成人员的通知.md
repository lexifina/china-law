# 三亚市人民政府办公室关于调整市政府妇女儿童工作委员会组成单位及组成人员的通知

三亚市人民政府办公室

关于调整市政府妇女儿童工作委员会组成单位

及组成人员的通知

各区人民政府，各管委会，市各有关单位：

根据工作需要和机构、人员变动情况，市政府决定调整市政府妇女儿童工作委员会组成单位及组成人员。具体如下：

一、市政府妇儿工委成员单位

市政府妇儿工委成员单位由原来的37个调整变更为36个。原“市国土环境资源局”替换为市生态环境保护局；原“省盐务局三亚盐务分局”替换为市食品药品监督管理局；原“市卫生局”和“市人口和计划生育委员会”替换为市卫生和计划生育委员会。其他成员单位不变。
