# 三亚市人民政府办公室关于印发海南省五指山至保亭至海棠湾高速公路项目三亚市境内征地拆迁工作方案

三亚市人民政府办公室

关于印发海南省五指山至保亭至海棠湾高速

公路项目三亚市境内征地拆迁工作方案

各区人民政府，市各有关单位：

为确保海南省五指山至保亭至海棠湾高速公路项目我市境内的征地拆迁工作顺利进行，充分发挥各部门的主观能动性与积极性，落实责任，明确目标，维护被征地群众的合法权益，结合我市实际，制定本方案。

一、指导思想与工作原则

按照省级统筹，市政府负责实施的原则，本次征地工作由省政府统一组织协调，三亚市政府具体负责实施，各有关部门按各自职能配合开展工作。征地工作应做到责任明晰、任务明确、督查到位、按时完成，并自觉接受各有关职能部门、群众及社会舆论监督。

二、征地范围

根据海南省五指山至保亭至海棠湾高速公路用地设计图件资料，三亚市境内项目用地范围由两部分组成：

（一）永久用地部分

1．海南省五指山至保亭至海棠湾高速公路新建公路全长55.865公里，征地面积共计6067.99亩，其中三亚市境内主线长度12.505公里，征地面积1397.465亩。

2．改移道路、沟渠、涵洞顺接用地以及有可能发生的扩补征地部分，根据实际用地需要确定。

（二）临时用地部分

1．大型临时用地：拌合站、取弃土场、制梁场等为大型临时用地。

2．小型临时用地：施工便道、堆料场、工棚等为小型临时用地。

临时用地采用租赁方式有偿使用。

永久用地征地面积及临时用地面积以勘测定界图的数据为准。

三、组织机构

成立海南省五指山至保亭至海棠湾高速公路项目三亚市境内征地拆迁工作小组。

组 长：鲍 剑 市委常委、市政府常务副市长

常务副组长：张兆腾 市政府副市长、市公安局局长

工作小组下设办公室，负责对外联络和上传下达，综合协调各部门开展工作，由海棠区委书记刘冲兼任办公室主任。

四、具体分工

为顺利推进征地拆迁工作，各部门具体职责分工如下：

（一）市交通运输局负责与省交通运输厅对接，提供征地图、征地包干合同文本，并协调及时拨付征地拆迁款；配合省交通运输厅编制用地、用林相关报批材料，跟踪服务各项征地拆迁工作。

（二）市国土资源局负责与省国土资源厅对接，指导和督促用地单位按规定组织用地报批材料，做好用地报批工作；督促和指导征地拆迁的结算和土地使用权证发放工作。

（三）海棠区政府与勘测定界单位对接，做好项目勘测定界工作；并负责组织实施项目征地、拆迁、补偿工作。

（四）市规划局负责与省规划委员会对接，负责做好总体规划调整工作。

（五）市林业局负责与省林业厅对接，做好项目使用林地的报批和审批工作，优先保证建设使用林地指标和林木采伐指标需求，按时按量完成林地征地拆迁和林木采伐工作。

（六）市生态环境保护局负责与省生态环境保护厅对接，做好项目环保手续。

（七）市财政局负责做好征地拆迁补偿款及时拨付工作。

（八）市公安局负责做好征地维稳工作。

五、工作要求

（一）征地拆迁工作小组各成员部门要强化职责分工，通力合作，在3个月时间内依法按时完成征地工作，不得影响项目施工建设。

（二）各成员部门要创造性地开展工作，积极协作，解决征地中出现的问题。

（三）要主动对接，保证信息及时畅通，有问题及时请示汇报相关领导，以有效组织各项工作。

（四）各成员部门提前计划，高效组织服务工作。
