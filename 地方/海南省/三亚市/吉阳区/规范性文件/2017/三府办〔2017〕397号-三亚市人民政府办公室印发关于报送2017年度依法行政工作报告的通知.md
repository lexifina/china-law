# 三亚市人民政府办公室印发关于报送2017年度依法行政工作报告的通知

三亚市人民政府办公室印发

关于报送2017年度依法行政工作报告的通知

各区人民政府，市政府直属各单位：

为做好我市2017年度依法行政考核工作，根据《三亚市人民政府依法行政指标考核办法》（三府〔2010〕8号）的相关要求，请各单位紧紧围绕本单位提高依法行政意识和能力、行政执法成效、行政执法人员培训、行政执法投诉与处理以及落实行政执法责任制等五个方面内容进行全面总结并填写《2017年度行政行为卷宗目录统计报表》；市监察部门还应对廉政机制建设和行政过错责任追究情况进行总结，形成书面材料，于2017年12月30日前随同电子文档报送市法制办。（联系人：杨晓蕾；联系电话：88278075；邮箱：syfzb604@163.com；传真：88283532）

附件：2017年度行政行为卷宗目录统计报表
