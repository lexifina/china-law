# 三亚市人民政府办公室关于印发三亚市整治违法建筑三年攻坚行动2017年工作计划的通知

三亚市人民政府办公室

关于印发三亚市整治违法建筑三年攻坚行动2017年工作计划的通知

各区人民政府，各管委会，市政府直属各单位：

《三亚市整治违法建筑三年攻坚行动2017年工作计划》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年3月5日

（此件主动公开）

三亚市整治违法建筑三年攻坚行动2017年工作计划

为深入推进整治违法建筑攻坚行动，扫除我市“建设精品城市，打造美丽三亚”的发展障碍，结合我市实际，制定本计划。

一、任务目标

（一）拆违工作目标

全市违建台账存量仍有160万平方米（其中天涯区79万，吉阳区40万，海棠区23万，崖州区18万），在此基础上，确定全市今年的拆违任务目标为至少200万平方米。

1．各区任务分解

各区今年的拆违任务分别为：天涯区94万平方米，吉阳区60万平方米，海棠区28万平方米，崖州区18万平方米。

2．全年进度安排

根据我市实际，确定4至9月为集中拆违阶段，具体拆违进度安排如下：

（1）1—3月，全市计划拆违至少25万平方米，其中天涯区12万平方米，吉阳区8万平方米，海棠区3万平方米，崖州区2万平方米。

（2）1—6月，全市计划拆违至少100万平方米，其中天涯区47万平方米，吉阳区30万平方米，海棠区14万平方米，崖州区9万平方米。

（3）1—9月，全市计划拆违至少175万平方米，其中天涯区82万平方米，吉阳区52万平方米，海棠区15万平方米，崖州区16万平方米。

（4）1—12月，全市计划拆违至少200万平方米，其中天涯区94万平方米，吉阳区60万平方米，海棠区28万平方米，崖州区18万平方米。

3．拆违重点领域

（1）根据我市整治违法建筑专项行动的工作部署，今年要完成海坡、月川、东岸、西瓜、芒果、临春、榕根、江林、龙海等棚改区的拆违工作，完成重点项目用地内、主要交通干道沿线、特色产业小镇和美丽乡村范围内以及农用地、林地、山体、河道、海岸带、水源保护区等区域的违建整治工作。

（2）根据《三亚市城市建成区违法建设专项治理工作实施方案》的工作部署，继续推进建成区违法建筑整治工作，全年查处建成区存量违法建筑的比例不低于50%。

（二）控违工作目标

对新增违建实施“零容忍”。通过深入开展“两普查、两规划、一报建”工作和落实属地网格化管理，对新增违建要做到早发现、早制止、早处置，实现全年新增违建零增长。

（三）创建“无违建”示范点工作目标

根据《三亚市“无违建”示范点创建活动实施方案》的工作部署，今年要全面铺开“无违建社区（村庄）”创建工作，全年通过“无违建社区（村庄）”验收的社区（村庄）比例要达到30%，即至少43个。具体分解到各区的任务为：天涯区13个，吉阳区11个，崖州区9个，海棠区7个，育才生态区3个。

二、工作措施

（一）进一步加大部门联合执法力度

各区政府、管委会和相关职能部门要认真履行《三亚市违法建筑管控办法》规定的职责，加强执法协作，在整治违法建筑工作中形成执法合力。其中，规划、住建、国土部门要指导和协助各区推进“两普查、两规划、一报建”工作，重点解决村民因历史原因无法报建的问题。规划、住建、国土、林业、水务等部门要在职责范围内开展巡查，发现违法建设行为要及时移送属地区政府、管委会查处。公安机关要积极配合各区开展拆违行动，及时处置阻挠执法人员正常执法、暴力抗法等事件，并依法查处销售违法建筑、在互联网散播谣言等行为。各区政府、管委会在打击违法建筑工作中需要对违法建筑实施停水、停电、停气或注销相关证照的，相关单位要积极予以配合。

（二）进一步加强对新增违建的管控

1．加强居（村）民建房管理。各区要推进“两普查、两规划、一报建”工作，按照合法、规范、便民的原则完善居（村）民建房管理办法，加大政策宣传力度，落实依法建房报建奖励，提高村民依法建房的积极性。

2．加强对新建房屋的巡查报告。各区要在社区（村庄）安排规划协管员，引导居（村）民依法报建，并对新建房屋进行巡查，及时向区城管局举报疑似新增违建。

3．加强对新增违建的“打早打小”。各区要组建新增违建快速处置队伍，对新增违建及时制止并实施分类处置。新增违建符合引导报建条件的，引导其报建补办手续；不符合报建条件的，依法实施拆除。

（三）按照时间节点开展“无违建”示范点创建工作

1．3月初，市打违办要起草三亚市2017年度创建“无违建”示范点工作计划，作为我市今年全面铺开“无违建”示范点创建活动的指导性文件。

2．3月底前，各区（含育才生态区）要制定本年度“无违建”示范点创建工作实施方案，按至少30%的比例确定“无违建社区（村庄）”创建点名单，并召开动员会。

3．10月底前，各区（含育才生态区）要按照创建标准开展“无违建”示范点创建工作，消减完“无违建社区（村庄）”创建点的存量违建，实现创建点新增违建零增长，并广泛开展宣传，将“无违建”示范点创建工作写入村规民约或社区居民公约，让创建点的居（村）民普遍知晓“无违建”示范点创建工作。

4．11月底前，各区（含育才生态区）要对照《海南省“无违建村（社区）”定性考评表》和《海南省“无违建村（社区）”定量考评表》，对“无违建社区（村庄）”创建点进行考核验收。

5．12月底前，市打违办要对“无违建社区（村庄）”创建点进行复核，并将复核结果报市政府审议。市政府审议通过后，向各区反馈并报省整违办备案。

（四）完善整治违法建筑的相关制度

1．数据核实方面。3月初，市打违办要制定核实拆违数据实施方案，对各区的拆违数据每周核实一次，每月通报一次。年底对各区拆违台账、违建案件和拆违合同进行全面核对，保证拆违数据的准确性。

2．考核及问责方面。3月底前，市综合行政执法局要对《三亚市违法建筑管控办法》进行修改，调整办法中对各区管控新增违建方面的问责标准。4月底前，市打违办要依据《三亚市整治违法建筑绩效工作考核与奖惩规定》，制定2017年度整治违法建筑工作考核实施方案。

3．建筑垃圾处置方面，市园林环卫部门要加快推进建筑废弃物综合利用厂项目，力争2017年上半年开工建设，2017年底前建成并投入使用。6月底前，市园林环卫部门要起草我市建筑废弃物处置办法，规范我市建筑废弃物的收运和综合利用。各区6月底前要完成建筑垃圾临时堆放点的建设工作，及时将拆违产生的建筑垃圾运往临时堆放点存放。

（五）加强执法队伍的教育管理

1．市综合行政执法局牵头，在全市综合行政执法系统继续开展“强基础、树形象、转作风”活动。市综合行政执法局组织全市综合执法人员开展一至两次集中培训活动，各区自行组织开展一至两次培训活动。通过培训，进一步增强整治违法建筑队伍的依法行政观念，提升执法人员的执法办案能力。

2．各区、市综合行政执法局要进一步加强综合执法队伍的党风廉政建设，不定期开展警示教育活动，对照综合执法“六条禁令”查摆问题，杜绝吃拿卡要、野蛮执法等恶习，在执法工作中做到“骂不还口、打不还手”。

3．市综合行政执法局要加大对各区办案工作的指导力度，组织开展全市法制员培训活动，加强对违法建设案件的审核把关。3月份前要制定违法建设案件检查实施方案，每季度抽查一次，指导和督促各区进一步规范办案工作。

（六）做好拆违过程中的风险防范和物品处置工作

各区在拆违前要做好风险评估，制定应急预案，提前化解矛盾纠纷，及时处置突发事件。对违建内有人员居住和物品存放的，要依法做好清点登记，全程摄像取证，及时将物品移送物主并签字确认；无法将物品移送物主或物主拒绝认领的，应进行公证，妥善保管，通知物主限期领取，逾期无人认领的依法进行处置。

三、工作要求

（一）各区（含育才生态区）和相关职能部门要根据本计划制定本单位细化性实施方案，加强组织领导，细化分解任务，明确工作措施，保障工作经费，扎实推进整治违法建筑工作。

（二）市打违办要对全市整治违法建筑工作进行跟踪督查，定期通报督查情况；对拆违进度缓慢、新增违建管控不力的单位，进行督办并报市政府。

（三）各区要根据全市拆违进度安排，提前安排每月的拆违计划，并将计划报市打违办；市打违办汇总后函送市财政部门，作为各区申请拆违经费的依据。
