# 三亚市人民政府办公室关于废止增加容积率补交地价款评估时间节点有关问题的通知

三亚市人民政府办公室

关于废止增加容积率补交地价款评估

时间节点有关问题的通知

各区人民政府，各管委会，市各有关单位：

2013年4月8日，国土资源部出台了《关于发布〈国有建设用地使用权出让地价评估技术规范（试行）〉的通知》（国土资厅发〔2013〕20号）规定：“在评估需补缴地价款时，评估期日应以国土资源主管部门同意补缴地价时为准”。

结合近年来审计署、专员办等多个部门对土地出让金的检查反馈情况，为遵从国家相关规定，强化补缴地价款评估管理，并考虑存在已参照《三亚市人民政府办公室关于印发增加容积率补交地价款评估时间节点有关问题的通知》（三府办〔2012〕323号）评估但尚未向市国土资源局申请补缴地价款企业的实际情况，市政府决定从2017年10月1日起废止《三亚市人民政府办公室关于印发增加容积率补交地价款评估时间节点有关问题的通知》（三府办〔2012〕323号）。

今后补缴地价款的地价评估应严格遵循国土资源部出台的《国有建设用地使用权出让地价评估技术规范（试行）》（国土资厅发〔2013〕20号）有关规定实施。

三亚市人民政府办公室
