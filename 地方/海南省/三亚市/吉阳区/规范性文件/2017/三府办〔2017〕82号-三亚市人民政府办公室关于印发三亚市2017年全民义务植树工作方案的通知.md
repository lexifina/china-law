# 三亚市人民政府办公室关于印发三亚市2017年全民义务植树工作方案的通知

三亚市人民政府办公室

关于印发三亚市2017年全民义务植树

工作方案的通知

各区人民政府，各管委会，市各有关单位：

《三亚市2017年全民义务植树工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年3月22日

（此件主动公开）

三亚市2017年全民义务植树工作方案

1981年12月13日，五届全国人大四次会议做出《关于开展全民义务植树运动的决议》，决议指出，凡是条件具备的地方，年满11岁的中华人民共和国公民，除老弱病残者外，因地制宜，每人每年义务植树3棵至5棵。这是我国林业事业史上的一场壮举，到今年已有36个年头。值此“十三五”规划第二年，为响应习近平总书记“我们既要绿水青山，也要金山银山。宁要绿水青山，不要金山银山，而且绿水青山就是金山银山。”的讲话精神，加速推进我市2017年“双修”工作，按照省林业厅义务植树活动的安排，结合我市造林实际情况，制定本市2017年全民义务植树工作方案。

一、2017年全民义务植树活动主题

开展全民义务植树，永葆三亚绿水青山。

二、工作目标

2017年全市义务植树活动计划植树202000株。

三、时间安排

全民义务植树活动分四个阶段，第一阶段1-3月份地块落实阶段，第二阶段4-6月份，为宣传活动阶段；第三阶段7-10月份，为植树造林阶段；第四阶段11月份，为检查验收阶段。

（一）第一阶段完成目标：1-3月份为规划设计和落实地块阶段。主要工作：各单位根据本区域实际情况制定方案，落实造林地块。

（二）第二阶段完成目标：4-6月份为宣传活动和造林准备阶段。主要工作:全市政府各机关、各民主团体、企事业单位、学校、部队等开展多种形式的义务植树宣传教育活动，大力弘扬爱绿、护绿、植绿、兴绿的良好风尚，增强广大人民群众建设绿化宝岛行动的积极性和主动性，共建宝岛秀美山川。同时结合绿化宝岛行动、退果还林以及各类生态修复建设项目，做好育苗、整地等造林前各项准备工作，有条件地区可争取早造林。

（三）第三阶段完成目标：7-10月份我市雨季到来之际，各单位要抓住雨季这一造林有利时机，组织本区域内全体适龄公民掀起植树高潮。

（四）第四阶段完成目标：11月份结合我市全年造林验收工作，对全市义务植树成果进行验收，检查评比，表彰先进，对不完成任务的单位进行通报批评。

四、任务安排

各区政府（管委会）绿化任务是202000株，种植树种为小叶榄仁、雨树、风铃木、火焰木、羊蹄甲、孔雀豆、盆架子、琼崖海棠、大叶相思、木麻黄、果树、吊瓜木、三角梅、黄心榕、朱蕉、槟榔和椰子等。其他机关单位想要参加义务植树活动可与所在区政府（管委会）联系。

五、植树地点

各区政府（管委会）可根据本区域实际情况自行安排植树点，可选择各自区域内的道路、水边及新农村建设点、本区域公共绿地、公用广场等。

六、具体要求

（一）各区政府（管委会）要将任务细化，下达到属地各企业、小区、宾馆、自然村、生产队等，将任务与单位领导考核挂钩，建立责任制。

（二）种植苗木品种由各单位根据本区域具体情况确定。

（三）各单位要结合“双修”工作和文明生态村建设，充分发挥农村土地资源丰富的特点，组织群众在水边、村边、路边和荒山荒地植树，美化绿化我市的新农村。

（四）绿化方式采取庭院绿化为主，在本区域范围内，充分利用现有空间，采取乔、灌、草相结合的方式，进行立体式绿化，努力创建“花园式单位”和“庭院绿化达标单位”。

（五）种植技术

1.树穴规格为：

（1）大树规格70厘米（边宽）×70厘米（深）×60厘米（底宽），株行距5×5（米）；

（2）小树规格40厘米（边宽）×40厘米（深）×30厘米（底宽），株行距均为3×2（米）。

2.大树胸径为6-10厘米，袋装良种壮苗，要求土球完整。种植设计为大树每亩20-30株，小树苗高80厘米以上，每亩111株-167株，混交组团种植。

3.种植下苗前，要先回填表土；下苗时，要剥掉营养袋，扶正，回表土分层压实，做好积水窝，浇足定根水。种植前尽量避免树苗土球散破，以免影响所栽种树的成活和生长。

（六）植树所需苗木、工具和经费由各区政府（管委会）自行解决，植树地点建议充分考虑文明生态村建设，并与我市“双修”工作相结合。

七、保障措施

（一）成立领导机构，加强组织领导

义务植树是我市实现“生态更加宜人”目标的一项重要措施，各单位、各部门主要领导要亲自挂帅抓落实，要把义务植树作为一项重要工作抓，做到有计划、有部署、有措施、有行动，切实抓出实效。为此，市政府成立工作总指挥部，总指挥由市政府副市长李劲松担任，副总指挥由市林业局局长陈斌担任 ，市绿委办负责总指挥部的具体协调和组织工作。各单位要成立相应的领导机构，加强领导，精心组织，统一部署开展行动。

（二）拓宽渠道，制定行动方案，开展形式多样的全民义务植树活动。

各单位要结合本地区的实际，以建设绿化生态城市、美化新农村为重点，拓宽渠道，制定绿化行动方案，开展形式多样的全民义务植树活动。一是大力推进生态修复建设；二是大力推进“身边增绿”；三是大力推进送苗下乡活动；四是大力推进古树名木保护管理；五是大力推进“纪念林”建设。要按照海绵城市建设的要求，创造性地推进全民义务植树运动的深入开展。

各单位在全民义务植树过程中，要创新工作机制，拓展全民义务植树方式方法，使全民义务植树形成多主体、多层次，多形式的格局。要广泛地在校园、部队，医院、厂矿、旅游区等，加强绿化建设，营造“党员林”、“政协委员林”、“民主党派林”、“青年林”、“三八林”、“双拥林”、“入学林”、“毕业林”等纪念林，开展形式多样的“弘扬生态文明、共建绿色家园”活动，打造人与自然和谐发展。市教育局要组织在市学校，积极参与绿化校园活动，检查评比出市级“绿色生态校园”学校。市文明办要结合全市文明生态村建设，评比达标文明生态村。

（三）广泛宣传发动，城乡联动掀高潮

各区政府（管委会）和责任单位要充分利用广播、电视、报纸、横幅、标语、宣传车等多种形式，开展丰富多彩的绿化宣传活动，广泛宣传全国人大《关于开展全民义务植树运动的决议》，宣传义务植树的法定性、全民性、义务性和公益性意义。要充分利用植树节、世界湿地日、森林日、环境日等纪念日，开展有特色的专题宣传，为绿化大行动营造良好的舆论氛围。市工作总指挥部要组织力量、认真指导各单位开展绿化大行动，并做好新闻媒体的跟踪报道工作。

（四）措施到位，确保全民义务植树活动取得成效。

各单位要早部署、早准备、早抓落实。一是制定活动方案，明确工作目标，并建立奖惩制度，实行责任制管理。二是落实专项经费，广辟资金渠道，实行政府投资与全社会共同参与的方式造林。三是搞好苗圃建设，备足苗、备好苗，为义务植树活动提供种苗支持。四是开展技术指导。五是做好统计和建档，准确掌握义务植树的状况与成效。六是落实检查指导，建立检查验收制度，切实落实造林后的管护，保证义务植树真正取得成效。各单位在种植时要严把质量关，保证种植成活率达85％以上。未成活的要及时补苗。全部植树任务务必于10月底前完成，并由市林业局组织验收。

各区政府（管委会）于每月25日前将本单位义务植树的开展情况报市绿委办（联系人：林媛；联系电话：88689160）统计。
