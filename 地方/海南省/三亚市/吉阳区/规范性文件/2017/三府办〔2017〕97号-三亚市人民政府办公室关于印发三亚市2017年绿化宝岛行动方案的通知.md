# 三亚市人民政府办公室关于印发三亚市2017年绿化宝岛行动方案的通知

三亚市人民政府办公室关于

印发三亚市2017年绿化宝岛行动方案的通知

各区人民政府，育才生态区管委会，市政府直属各单位:

《三亚市2017年绿化宝岛行动方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年4月10日

（此件主动公开）

三亚市2017年绿化宝岛行动方案

为贯彻落实省委、省政府关于继续实施绿化宝岛行动，不断提高重点生态修复成效，加快生态文明建设的战略部署，推动我市“双修、双城”工作，以增加“绿量”、提升“绿质”为主题，构建“显山、露水、见林、透气”的生态格局，结合林业生态修复与湿地保护专项行动和我市的实际，制定本方案。

一、指导思想

以十八大和习近平总书记考察海南时的重要讲话精神为指导，以实现我市景观更加优美、“生态更加宜人”为目标，促进我市社会、经济、生态和谐发展。

二、基本原则

（一）坚持生态效益优先，兼顾景观提升的原则；

（二）坚持政府主导，部门联动，全民参与的原则；

（三）坚持因地制宜，注重实效的原则；

（四）统一部署、分区实施、稳步推进的原则。

三、计划指标及主要任务

2017年省下达我市计划造林绿化指标1300亩，其中，指令性计划800亩，指导性计划500亩。义务植树指标20万株。

2017年我市绿化宝岛行动的主要任务有：

（一）完成省下达的1300亩造林绿化任务；

（二）对历年的造林成果进行重点管护；

（三）组织机关及团体植树，推进全民义务植树；

（四）推进高标准农田防护林网建设。

四、建设内容

（一）造林指标任务

2017年省下达我市计划造林绿化指标1300亩，其中，指令性计划800亩，指导性计划500亩，下达各区、育才生态区，按三亚市2017年造林绿化任务计划表实施完成。同时分解下达绿化宝岛市财政资金130万元，补贴各区、育才生态区造林费用。（详见附表一、五）

（二）历年造林成果养护

三亚市历年绿化宝岛行动各区、育才生态区造林绿化成果共计59669.9亩，2017年绿化宝岛市财政资金依据成果面积,分解下达160万元，由各区、育才生态区，按行政管辖范围和造林成果保存实际组织重点养护。（详见附表二、五）

养护工作按以下规程实施：

1.除草割藤：砍除植株为圆心半径0.5m内影响生长的杂草及藤蔓，除草时间根据各造林地上的灌木杂草的情况，不影响苗木正常生长为原则。

2.修枝培土：对倒伏的苗木扶正、培土，将大苗2米以下的干枯枝、病虫枝、交叉枝、密生枝等修剪并清理干净，使苗木主枝条上的侧枝条分布均匀，方向合理。

3.浇水：为了利于水分渗透，浇水前应先松土，根部松土深5-6厘米，其它部位松土深10-15厘米，松土时切勿损伤根皮，并在苗木周围挖设半径0.5m的蓄水圈，做到及时、适时浇水，以保证水分充足。

4.施肥：通过沟施或浇灌等方式对苗木进行追肥，即在苗木下开挖7-10cm深施肥后盖土或结合灌水的办法进行施肥，大苗施肥1kg/株，小苗施肥0.02kg/株，以保证生长具备充足养分。

5.管护：安排养护人员定期巡查，防止人畜破坏，对枯死和遭到破坏的植株及时进行补植和更换，管护期为一年。

主要责任单位为各区、育才生态区，负责组织实施和管理，市林业局负责指导、督促。

（三）机关、团体植树和义务植树

2017年安排60万元经费组织市级领导、各机关团体、企（事）业单位及社会团体举行大型植树造林活动；安排40万元给各区、育才生态区组织义务植树，吉阳区、天涯区、海棠区、崖州区、育才生态区各4万株植树任务，各8万元苗木经费。

主要责任单位为市林业局、各区及育才生态区，负责苗木采购、组织实施等。

（四）高标准农田防护林网建设

按照《三亚市高标准农田建设规划实施方案》（三府〔2017〕178号文），2017年计划安排169.57万元，用于崖州区郎茫田洋等高标准农田防护林网建设。由崖州区、海棠区按照三亚市政府印发的《三亚市高标准农田建设规划实施方案》要求和标准组织建设，建设成果纳入年度绿化宝岛造林绿化任务。

主要责任单位为崖州区、海棠区，负责组织实施和管理，市林业局负责指导、督促。

五、资金安排

2017年绿化宝岛行动市财政预算资金600万元，计划安排如下（详见附表四、五）：

（一）造林指标任务补贴经费130万元；

（二）历年造林成果重点养护经费160万元；

（三）机关及团体植树经费60万元；

（四）义务植树经费40万元；

（五）高标准农田防护林网建设169.57万元；

（六）成果验收工作经费10.43万元；

（七）工作人员经费30.00万元。

2017年绿化宝岛行动市财政资金由市财政局按资金安排表一次性下达各区及育才生态区。（详见附表五）

六、时间安排

（一）制定方案（2017年2月―4月）

市林业局落实全市实施方案，各责任单位要对各自的历年造林成果进行核实，制定方案，细化任务指标。

（二）造林准备（2017年5月―6月）

各责任单位确定好造林和养护地块，根据下达资金与任务组织实施；做好机耕、整地工作，准备好充足的苗木以及相关物质。

（三）造林施工（2017年7月―10月）

各责任单位安排落实造林与成果养护施工，严把造林“六关”（良种壮苗、起苗运苗、分级修剪、整地挖坑、栽植浇水、管护抚育），落实养护责任，确保造林成活率（保存率）在85%以上。补植要选择好苗壮苗，就近调苗，确保造林成功。

（四）检查验收（2017年11月―12月）

绿化宝岛行动建设成果验收采用分级验收的制度实施，施工完成后由各责任单位自查并上报，由市林业局组织市级检查验收，统计造林成果并报省林业厅，迎接省厅造林绿化检查验收。

七、保障措施

（一）加强领导，明确责任

各区、育才生态区要高度重视，加强领导，落实责任，强化措施。尽快制定工作方案，精心组织，周密部署，早计划，早安排，早行动。要把责任措施落实到具体部门和具体责任人，形成以上率下、上下联动、齐抓共管的工作格局，确保年度造林绿化任务顺利完成。

（二）强化宣传，合力推进

充分发挥广播、电视、报纸、网络等媒体的宣传作用，采取标语、宣传栏等多种方式，广泛宣传绿化宝岛行动建设成果，以及保护成果的重要性，营造声势、激发热情，形成全民护绿护林的意识，鼓励社会各界积极护林、管林、爱林、养林。

（三）科学管理，突出重点

建立完善的质量管理制度，严格按照项目要求和管理程序操作。严格执行国家和行业造林绿化标准，认真抓好苗木、造林和养护质量；严格管护责任，造管并举，强化保护，确保造林一片、成活一片、保存一片；委托有资质的单位进行设计、施工、监理和验收，确保造林质量，加强苗木质量监督，禁用病苗、劣苗造林。市林业局作为主要牵头单位，要派驻技术力量，监督各责任单位，对苗木质量、造林施工和检查验收严格把关。

（四）及时反馈，规范档案

加强工程进度管理，确保工程监理制度，做好工程信息反馈工作，及时反馈工程进度及工程质量，准确掌握工程进展情况。各责任单位要确定专人，负责每月15号前向市林业局营林与花卉科报送进度。对于历年档案信息，要做好分类管理工作，确保每项工程、每棵树、每分钱都有据可依、有档可查。

（五）严格检查，兑现奖惩

要加强植树造林工作的专项督查，搞好检查验收。对造林绿化工作组织不力，质量不高，整地不合格、苗木不达标、进度慢、造林成活率（保存率）达不到要求的，要给予通报批评并追究有关责任人的责任。要把造林绿化工作纳入当年目标考评，考评结果将作为市委、市政府对各区、育才生态区及部门年终考核的重要指标和重要依据。
