# 关于三亚市SY2016-027号拟征收土地有关事项的告知书

三亚市吉阳区人民政府

关于三亚市SY2016-027号拟征收土地

有关事项的告知书

三亚市吉阳区海罗村委会：

因我市的城市建设需要，市政府以《关于河东区海罗村149.8亩用地土地调查有关事项的通知》（三府办〔2014〕125号）文拟征收三亚市吉阳区海罗村委会集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区海罗村，用地面积为5.6695公顷（涉及水田1.6326公顷、有林地0.6874公顷、园地0.9029公顷、设施农用地0.2530公顷、农村道路0.0165公顷、村庄2.1771公顷）。

二、拟征收土地的项目用途为艺术传媒用地（占50%）、设施旅馆业用地（占30%）和其他商务设施用地（占20%）。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出据确认意见。

特此告知。

（此件主动公开）

三亚市吉阳区人民政府
