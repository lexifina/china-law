# 关于三亚市SY2017-061号拟征收土地有关事项的告知书（抱坡35.6299公顷）

三亚市吉阳区人民政府

关于三亚市SY2017-061号拟征收土地

有关事项的告知书

三亚市吉阳区抱坡村委会：

因我市的城市建设需要，市政府以《关于吉阳区抱坡新城片区棚户区改造项目土地调查有关事项的通知》（三府办〔2017〕235号）文拟征收吉阳区抱坡村委会集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区抱坡新城片区，用地面积为35.6299公顷（涉及其他农用地0.0078公顷、建设用地35.6221公顷）。

二、拟征收土地的项目用途为商服用地、公共管理与公共服务用地、住宅用地等。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出据确认意见。

特此告知。

三亚市吉阳区人民政府

2017年10月17日
