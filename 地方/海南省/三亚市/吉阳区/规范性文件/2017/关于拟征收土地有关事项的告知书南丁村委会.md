# 关于拟征收土地有关事项的告知书南丁村委会

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

南丁村委会：

因我市的城市建设需要，市政府以《关于三亚市荔枝沟水质净化二厂工程项目土地调查有关事项的通知》（三府办〔2017〕211号）文拟征收我区南丁村委会部分集体土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约 4.2524公顷（其中水田约3.3815亩、旱地约0.1894公顷、可调整其他园地约0.0016公顷、其他林地约0.2243公顷、城市约0.086公顷、村庄约0.3696公顷）。

二、拟征收土地的用地性质为公共管理与公共服务用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知

三亚市吉阳区人民政府

2017年7月31日
