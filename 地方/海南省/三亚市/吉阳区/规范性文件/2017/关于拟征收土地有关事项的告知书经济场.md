# 关于拟征收土地有关事项的告知书经济场

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区经济场：

因我市的城市建设需要，市政府以《关于三亚市高新片区控规A11-3地块部分用地土地调查有关事项的通知》（三府办〔2016〕348号文）拟征收吉阳区经济场、苗圃场集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市高新片区控规A11-3地块，用地面积为0.9149公顷（均为其他农用地）。

二、拟征收土地的用地性质：一类工业用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2017年9月1日
