# 关于拟征收土地有关事项的告知书(三亚东河生态修复工程（溪泽三桥—东环高铁段）项目)

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

东岸村委会、海罗村委会、临春居委会、荔枝沟居委会、榕根居委会：

因我市的城市建设需要，市政府以《关于三亚东河生态修复工程（溪泽三桥—东环高铁段）项目土地调查有关事项的通知》（三府办〔2017〕243号）文拟征收我区东岸村委会、海罗村委会、临春居委会、荔枝沟居委会、榕根居委会部分集体土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约 165549平方米，其中土地权属情况为东岸、海罗、临春和荔枝沟村委会集体土地共约150000平方米，榕根社区居委会土地约14221平方米，临春居委会与海罗村委会共有土地约510平方米，广州铁路集团海南铁路总公司（已收回）国有土地约818平方米，详见项目土地权属示意图。

二、拟征收土地的用地性质为生态防护绿地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知

三亚市吉阳区人民政府

2017年8月28日
