# 关于拟征收土地有关事项的告知书（三亚市南新横二路工程项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

南丁村委会、海南省国营南新农场、三亚南新投资有限公司、海南亚龙木业有限责任公司、原三亚椰林书苑海垦地产有限责任公司：

因我市的城市建设需要，市政府以《关于三亚市南新横二路（落笔洞—同心路段）工程项目土地调查有关事项的通知》（三府办〔2017〕252号）文拟征收我区南丁村委会部分集体土地及我区辖区内部分国有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约 19455平方米（其中南丁村约4851平方米、南新农场约3504平方米、三亚南新投资有限公司约1884平方米、海南亚龙木业有限责任公司约7440平方米、原三亚椰林书苑海垦地产有限责任公司约1776平方米）。

二、拟征收土地的用地性质为市政道路用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知

三亚市吉阳区人民政府

2017年9月29日
