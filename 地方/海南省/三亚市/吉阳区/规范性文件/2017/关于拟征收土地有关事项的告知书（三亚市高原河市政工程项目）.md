# 关于拟征收土地有关事项的告知书（三亚市高原河市政工程项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

干沟村委会、海南省第二燃料公司、海南瑞泽新型建材股份有限公司：

因我市的城市建设需要，市政府以《关于三亚市高原河市政工程项目土地调查有关事项的通知》（三府办〔2017〕283号）文拟征收我区干沟村委会部分集体土地及我区辖区内部分国有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约 6600平方米（其中干沟村约2321平方米、海南省第二燃料公司约3969平方米、海南瑞泽新型建材股份有限公司约310平方米）。

二、拟征收土地的用地性质为市政道路用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知

三亚市吉阳区人民政府

2017年9月29日
