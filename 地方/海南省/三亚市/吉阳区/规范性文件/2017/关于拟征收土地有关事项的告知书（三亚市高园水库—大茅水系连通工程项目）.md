# 关于拟征收土地有关事项的告知书（三亚市高园水库—大茅水系连通工程项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

干沟村委会、榆红村委会、红土坎村委会、三亚市土地储备开发中心：

因我市的城市建设需要，市政府以《关于三亚市高园水库—大茅水系连通工程项目土地调查有关事项的通知》（三府办〔2017〕291号）文拟征收我区干沟、榆红和红土坎村委会部分集体土地及我区辖区内部分国有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约 2.8523公顷（其中干沟村约0.5261公顷、榆红村约0.1857公顷、红土坎村约1.0214公顷、国家约0.7027公顷、三亚市土地储备开发中心约0.4164公顷）。

二、拟征收土地的用地性质为水利设施用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知

三亚市吉阳区人民政府

2017年11月2日
