# 关于拟征收土地有关事项的告知书（关于三亚市“君和君泰”项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

荔枝沟居委会、海南省国营南新农场、三亚富斯实业有限公司、三亚椰林书苑海垦地产有限责任公司：

因我市的城市建设需要，市政府以《关于三亚市“君和君泰”项目二期周边市政道路工程项目土地调查有关事项的通知》（三府办〔2017〕117号）文拟征收我区荔枝沟居委会部分集体土地及我区辖区内部分国有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约 25445平方米（其中荔枝沟居委会约767平方米、海南省国营南新农场约7平方米、三亚富斯实业有限公司约3平方米、三亚椰林书苑海垦地产有限责任公司约18121平方米、原三亚南新富斯复合肥发展有限公司（已收回）约69平方米、原三亚椰林书苑海垦地产有限责任公司（已收回）约6479平方米。

二、拟征收土地的用地性质为市政道路用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知
