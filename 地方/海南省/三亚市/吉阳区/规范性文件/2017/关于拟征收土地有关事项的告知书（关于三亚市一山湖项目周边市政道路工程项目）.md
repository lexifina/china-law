# 关于拟征收土地有关事项的告知书（关于三亚市一山湖项目周边市政道路工程项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

国营南新农场、三亚保力房地产投资开发有限公司、三亚联合实业有限公司：

因我市的城市建设需要，市政府以《关于三亚市一山湖项目周边市政道路工程项目土地调查有关事项的通知》（三府办〔2017〕116号）文拟征收我区辖区内部分国有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约 1.2472公顷，其中南新农场约0.2260公顷、三亚保力房地产投资开发有限公司约0.0237公顷、三亚联合实业有限公司约0.7029公顷、原三亚宝迪投资有限公司(已收回）约0.2946公顷。

二、拟征收土地的用地性质为市政道路用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知

三亚市吉阳区人民政府

2017年10月19日
