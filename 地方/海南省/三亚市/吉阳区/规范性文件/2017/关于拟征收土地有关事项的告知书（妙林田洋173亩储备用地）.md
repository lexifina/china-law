# 关于拟征收土地有关事项的告知书（妙林田洋173亩储备用地）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区月川社区居民委员会：

因我市的城市建设需要，市政府以《三亚市人民政府办公室关于做好妙林田洋173亩土地征收拆迁调查工作有关问题的通知》（三府办〔2007〕237号）文、《三亚市人民政府办公室关于妙林田洋部分储备用地土地调查有关问题的通知》（三府办〔2010〕206 号）文、《三亚市人民政府办公室关于槟榔河两侧约8669平方米土地纳入储备用地土地调查有关事项的通知》（三府办〔2014〕251 号）文拟征收村委会农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于月川片区控规YC3-19-3、YC3-23-1、YC3-24-5、YC3-25-7地块，用地面积为0.2548公顷（涉及耕地 0.0521公顷、其他农用地0.0005公顷、建设用地0.2022公顷）。

二、拟征收土地的用地性质为商业用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出据确认意见。

特此告知。

（此件主动公开）

三亚吉阳区人民政府

2017年9月8日
