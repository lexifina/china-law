# 关于拟征收土地有关事项的告知书(抱坡)

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区抱坡村民委员会：

因我市的城市建设需要，市政府以《关于榕根社区居委会预留集体经济发展项目用地土地调查有关事项的通知》（三府办〔2012〕285号）文拟征收三亚市吉阳区抱坡村民委员会农民集体部分土地，现将拟征收土地的有关事项告知如下：

一、拟征收土地位于三亚城市职业学院南侧地块，用地面积为2.2349公顷（涉及可调整果园2.1934公顷、其他农用地0.0312公顷，建设用地0.0103公顷）。

二、拟征收土地的用地性质为商服用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出据确认意见。

特此告知。

三亚市吉阳区人民政府

2017年6月12日
