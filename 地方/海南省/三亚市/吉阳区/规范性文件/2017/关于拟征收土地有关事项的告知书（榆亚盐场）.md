# 关于拟征收土地有关事项的告知书(榆亚盐场)

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

榆亚盐场：

因我市的城市建设需要，市政府以《关于亚龙湾第二通道（一期）工程项目土地调查有关事项的通知》（三府办〔2017〕144号）文拟征收贵单位部分国有土地，现将拟征收的土地有关事项告知如下：

一、拟征收贵单位土地位于吉阳区辖区内，用地面积约 33999平方米，详见用地红线图和权属图。

二、拟征收土地的用地性质为道路用地。

三、拟征收土地、房屋及地上附着物的补偿标准参照《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行。

四、自本告知下达之日起，拟征收土地范围内禁止抢种青苗和抢建附着物；凡属抢种青苗及抢建附着物，一律不予补偿。

特此告知

三亚市吉阳区人民政府

2017年6月9日
