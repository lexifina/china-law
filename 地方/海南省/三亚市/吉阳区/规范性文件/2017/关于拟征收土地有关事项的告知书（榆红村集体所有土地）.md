# 关于拟征收土地有关事项的告知书(榆红村集体所有土地)

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区榆红村民委员会：

因我市的城市建设需要，市政府以《关于扩大残疾人托养服务中心用地项目土地调查有关事项的通知》（三府办〔2016〕312号文）拟征收吉阳区榆红村集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳镇镇区控规D-22地块内，用地面积为1.2061公顷（其他农用地0.0129公顷和建设用地1.1932公顷）。

二、拟征收土地的用地性质：特殊医疗用地

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出据确认意见。

特此告知

（此件主动公开）
