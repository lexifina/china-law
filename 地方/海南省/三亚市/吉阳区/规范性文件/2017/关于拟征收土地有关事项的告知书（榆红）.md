# 关于拟征收土地有关事项的告知书(榆红)

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

榆红村委会：

因我市的城市建设需要，市政府以《关于三亚市榆红村委会集体预留用地土地调查有关事项的通知》（三府办〔2017〕175号）文拟征收我区榆红村委会部分集体土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内（榆亚大道西侧控规D-16、D-19地块内），起点位于工业南路，终点至吉阳大道，用地面积约 0.9708公顷（涉及村庄0.9708公顷）。

二、拟征收土地的用地性质为城镇用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知

三亚市吉阳区人民政府

2017年8月25日
