# 关于拟征收土地有关事项的告知书（海南农垦亚龙置业）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

海南农垦亚龙置业有限责任公司：

因我市的城市建设需要，市政府以《关于热带海洋学院周边规划市政道路工程项目土地调查有关事项的通知》（三府办〔2017〕51号）文拟征收贵司部分国有土地，现将拟征收的土地有关事项告知如下：

一、拟征收贵司土地位于吉阳区辖区内，用地面积约 19417.7654平方米（其中荔枝沟纵一路约11886.9639平方米，荔枝沟纵二路约7530.8015平方米），具体详见用地红线图和权属图。

二、拟征收土地的用地性质为市政道路用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、自本告知下达之日起，拟征收土地范围内禁止抢种青苗和抢建附着物；凡属抢种青苗及抢建附着物，一律不予补偿。

特此告知

三亚市吉阳区人民政府
