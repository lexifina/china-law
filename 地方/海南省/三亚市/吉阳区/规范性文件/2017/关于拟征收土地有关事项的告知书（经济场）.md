# 关于拟征收土地有关事项的告知书（经济场）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

经济场：

因我市的城市建设需要，市政府以《关于三亚市高新技术产业园控制性详细规划B3-1地块部分用地土地调查有关事项的通知》（三府办〔2017〕191号）文拟征收我区经济场部分集体土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约 0.3198公顷（其中果园约0.0015公顷、其他园地约0.2887公顷、村庄约0.0296公顷）。

二、拟征收土地的用地性质为图书展览设施用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知

三亚市吉阳区人民政府

2017年8月25日
