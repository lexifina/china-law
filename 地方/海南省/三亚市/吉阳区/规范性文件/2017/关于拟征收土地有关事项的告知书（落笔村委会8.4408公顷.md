# 关于拟征收土地有关事项的告知书(落笔村委会8.4408公顷

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区落笔村委会：

因我市的城市建设需要，市政府以《关于三亚半岭温泉建设项目用地土地调查有关事项的通知》（三府办〔2010〕372号）拟征收三亚市吉阳区落笔村委会集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市半岭温泉旅游区控规BL-04-04、BL-04-08、BL-04-11、BL-04-12地块，用地面积为8.4408公顷（涉及果园3.5987公顷、其他园地1.5862公顷、灌木林地0.9548公顷、沟渠0.0795公顷、农村道路0.1056公顷和村庄2.1160公顷）。

二、拟征收土地的项目用途：其中BL-04-04、BL-04-08、BL-04-11为居住用地，

BL-04-12为度假商业综合用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出据确认意见。

特此告知

三亚市吉阳区人民政府

2017年 6月12日
