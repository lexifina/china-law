# 关于印发海洋学院三亚校区新增用地和三环路荔枝沟段项目安置补偿方案的通知

吉阳府〔2017〕168号

三亚市吉阳区人民政府

关于印发海洋学院三亚校区新增用地和三环路荔枝沟段项目安置补偿方案的通知

各相关单位：

为推进海洋学院三亚校区新增用地和三环路荔枝沟段项目建设，妥善解决项目范围内南新农场和亚龙置业公司职工的补偿安置问题，特制订《海洋学院三亚校区新增用地和三环路荔枝沟段项目安置补偿方案》。现印发给你们，请认真贯彻执行。

三亚市吉阳区人民政府

2017年6月29日

（此件主动公开）

海洋学院三亚校区新增用地和三环路

荔枝沟段项目安置补偿方案

为推进海洋学院三亚校区新增用地和三环路荔枝沟段项目建设，妥善解决项目范围内南新农场和亚龙置业公司职工的补偿安置问题，根据《中华人民共和国土地管理法》、《中华人民共和国城市房地产管理法》、《中华人民共和国城乡规划法》、《中华人民共和国物权法》、《国有土地上房屋征收与补偿条例》（国务院590号令）、《国有土地上房屋征收评估办法》、《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）和《三亚市棚户区改造房屋征收补偿安置暂行办法》等法律法规和国家、省、市有关安置补偿政策的规定，结合项目的具体情况，特制定本方案。

一、征收范围（四至范围）及基本情况

海洋学院三亚校区新增用地四至范围：东至落笔洞路，南至富斯化肥厂，西至双大地产，北至高速公路，具体范围四至及坐标以项目规划红线的实际勘测定界为准。征收南新农场国有土地面积约 311.32亩（属南新农场三队承包地）。项目涉及南新农场职工及相关人员约200户，房屋约12万平方米，具体数据以实际测量为准。

三环路荔枝沟段项目四至范围：东至南丁村田地，南至亚龙木业厂区，西至富斯公司综合楼，北至亚龙木业宿舍区，具体范围四至及坐标以项目规划红线的实际勘测定界为准。征收海南农垦亚龙置业有限责任公司（以下简称亚龙置业公司）土地面积约 10.55亩，性质为国有工业划拨用地。征收亚龙置业公司1栋6层宿舍楼，共有住房48套，每套50.38平方米（不含公摊面积），总建筑面积约2418平方米，具体数据以实际测量为准。

二、指导思想及基本原则

以科学发展观为指导，以维护广大人民群众的根本利益为宗旨，以加快推进项目建设为目标，坚持公开、公平、公正，依法征收补偿，依法拆迁安置，先安置补偿，后拆迁的原则，达到和谐拆迁，满意安置。

三、征收主体

征收人：三亚市人民政府

实施单位：三亚市吉阳区人民政府

四、南新农场三队补偿安置及保障安置对象和房屋权属的认定

根据项目实际情况，南新农场三队补偿安置对象包括农场三队正式职工和农场三队离退休职工，保障安置对象包括农场三队辞职辞退职工和农场三队职工子女，具体如下:

（一）农场三队正式职工。在本案方案发布时，户籍关系在南新农场三队，与南新农场仍存续着合法有效的劳动关系并仍履行着职工义务的人员，且在南新农场三队从事生产和经营活动。

（二）农场三队离退休职工。原属南新农场三队职工，因达到法定退休年龄或因疾病丧失劳动能力等情况已办理离退休，在本方案发布之日前在项目范围内有相对独立房屋的人员。

（三）农场三队辞职辞退职工。原属南新农场三队职工，因各种原因已与农场终止、解除劳动合同或者被辞退、除名等，在本方案发布之日前在项目范围内有相对独立房屋的人员。

（四）农场三队职工子女。即农场三队正式职工、离退休职工或辞职辞退职工的子女，在本方案发布之日前在项目范围内有相对独立房屋的人员。

（五）农场其他特殊情形人员。即不属于本方案规定的南新农场三队补偿安置及安置保障对象，但属南新农场正式职工、离退休职工或职工子女等农场相关人员。

南新农场补偿安置及保障安置对象和房屋权属的认定由南新农场按规定核定后报吉阳区政府，吉阳区根据核定结果按本方案标准予以补偿。农场其他特殊情形人员及其房屋权属的认定由南新农场按规定核定后报吉阳区政府另行研究确定。

五、亚龙置业宿舍楼产权和面积的认定

（一）被征收房屋产权认定：被征收人具有改造项目范围内被征收房屋有效产权证书、产权证明或其它合法手续的认定为房屋合法产权人。

如被征收人没有取得房屋所有权，但有其持有占有该房屋的合法手续，并在其本人签订征收补偿协议前取得了其可以有效取得房屋权属的全部手续后，可以认定其为房屋的合法产权人。

（二）被征收房屋的建筑面积与套内面积的认定：被征收房屋的建筑面积和套内面积，以被征收人房屋产权证上记载的面积为准。没有房屋产权证的，以规划部门批准的面积为准。（安置房的建筑面积和套内面积的认定同样按照本款执行）

六、房屋征收安置补偿标准

（一）南新农场三队正式职工和离退休职工居住房屋的安置补偿标准

1.现有居住房屋按照框架结构每平方米1350元、混合结构每平方米1100元的标准作价进行货币补偿。

2.每栋房屋建筑面积不超过270平方米，按被搬迁房屋作价补偿金额的100%给予搬迁奖励。每栋房屋建筑面积超过270平方米的部分，按被搬迁房屋作价补偿金额的30%给予搬迁奖励。

3.房屋装饰、青苗及其它附着物等补偿标准参照《三亚市集体土地征收补偿安置管理规定的通知》（三府〔2013〕43号）规定另行补偿。

4.未享受过职工安置房或保障性住房的农场正式职工和离退休职工，可按下述方式进行产权调换：

（1）如家庭人口2人（含2人）以上的，可享受120平方米商品房作为安置房；

（2）如家庭人口仅1人的，可享受60平方米商品房作为安置房。

被征收房屋的产权调换比例参照《三亚市棚户区改造房屋征收补偿安置暂行办法》第九条实施。

（二）南新农场三队辞职辞退职工和职工子女居住房屋的保障安置标准

1.现有居住房屋按照框架结构每平方米1350元、混合结构每平方米1100元的标准作价进行货币补偿。

2.每栋房屋建筑面积不超过270平方米，按被搬迁房屋作价补偿金额的100%给予搬迁奖励。每栋房屋建筑面积超过270平方米的部分，按被搬迁房屋作价补偿金额的30%给予搬迁奖励。

3.房屋装饰、青苗及其它附着物等补偿标准参照《三亚市集体土地征收补偿安置管理规定的通知》（三府〔2013〕43号）规定另行补偿。

4.符合以下各项条件的南新农场辞职辞退职工或职工子女，如家庭人口2人（含）以上的，可按安置房建安成本价格申购120平方米的安置房；如家庭人口仅1人的，可按安置房建安成本价格申购60平方米的安置房：

（1）家庭主要成员至少有一人具有三亚市市区非农业户籍3年以上，且均在本市范围内实际居住或工作；

（2）家庭无其他住房或另外住房人均建筑面积低于18平方米（含18平方米）；

（3）家庭未享受过政策性住房；

（4）申购安置房应当以家庭为单位。未婚或离异满一年不带子女的被征收人可以单独进行申购，但年龄须在35周岁（含35岁）以上。

（三）南新农场非居住房屋和外来人员房屋的征收补偿标准

在南新农场范围内没有合法的房屋（含取得合法权属的房屋，或取得合法建设手续的房屋）、且户籍也不在南新农场的外来人员的房屋和非居住房屋，依照“一户一栋”的原则，按以下标准补偿：

被拆迁人主动配合登记丈量，且在规定时间签订征收补偿协议并主动腾空房屋配合拆迁的，被拆房屋（包括框架、混合、砖木结构房屋）按每平方米800元标准给予被拆迁户补偿（每户以525平方米为最高标准，剩余部分不予补偿），且房屋装饰部分也不再另行补偿。

（四）亚龙置业公司宿舍楼的安置补偿标准

对被征收房屋，采取货币补偿、产权调换两种方式进行补偿，具体补偿方式由被征收人自行选定。

1.货币补偿方式

被征收人选择货币补偿的，按照评估机构依法评估确定的被征收房屋市场评估价格的进行补偿，再给予其被征收房屋市场评估价格20%的奖励。

（五）安置房建设

由市政府在改造项目范围内安排约100亩用地作为安置房建设用地，根据统一规划、统一设计、统一建设和统一安置的原则，建设标准符合国家有关规定。具体户型和面积以市规划部门批准的安置房建设方案为准。

1.钢筋混凝土框架结构；

2.外墙涂料（以规划局批准为准）；

3.入户大门为防盗门；

4.门窗为铝合金或PVC塑钢玻璃门窗；

5.室内地面为高级地砖；

6.各户室内强、弱电全部暗装到位；

7.每户独立水、电、气表；

8.各户室内全部为简装；

9.配置灯具照明、卫浴厨具等设备。

（六）安置房屋差额面积结算

1.农场三队正式职工和离退休职工差额面积结算

（1）被征收人选定的安置房面积小于其应得安置房面积的，差额部分按框架结构每平方米2700元、混合结构每平方2200元的标准结清差价；

（2）被征收人选定的安置房面积大于其应得安置房屋面积的，超出的安置房屋面积按以下方式结算：

超出面积在15平方米以内（含15平方米）的部分，按安置房建安成本价格结清差价；超出面积在15平方米以上（不含15平方米）部分，按照安置房屋的市场评估价格结清差价。

2.亚龙置业公司宿舍楼差额面积结算

（1）被征收人选定的安置房面积小于其应得安置房面积的，未安置面积按照被征收房屋市场价格的120%给予补偿。

（2）被征收人选定的安置房面积大于其应得安置房屋面积的部分，超出的安置房屋面积按以下方式结算：

超出面积在15平方米以内（含15平方米）的部分，按安置房建安成本价格结清差价；超出面积在15平方米以上（不含15平方米）部分，按照安置房屋的市场评估价格结清差价。

(七)被征收房屋评估方式

1.评估机构的选定

评估机构由被征收人推选出的代表协商选定。协商不成的，由房屋征收实施单位组织被征收人代表从已在三亚市备案的评估机构库中随机抽取。被征收房屋的价格评估基准日可以选定评估机构之日为准。

被征收人或房屋征收实施单位对评估结果有异议的，应当自收到评估报告之日起10日内，向评估机构申请复核；被征收人或房屋征收实施单位对评估机构的复核结果有异议的，应当自收到复核结果之日起10日内，向三亚市房地产价格评估专家委员会申请鉴定。

2.评估方式

选定的评估机构依照《国有土地上房屋征收评估办法》（建房〔2011〕77号）等相关法律法规对被征收房屋进行价值评估，并出具评估报告。评估结果在项目范围内进行公示。

七、搬迁补助、临时过渡安置费用

（一）搬迁补助费

以被征收人（外来人员除外）现有居住房屋的建筑面积（不包括简易结构房屋、铁皮棚等）为基数，按照每平方米18元的标准给予搬迁补助费（单次搬迁最低不少于3000元）。

被征收人未享受房屋安置的，一次性结清搬迁补助费；被征收人享受房屋安置的，按两次发放搬迁补助费。

（二）临时过渡安置费

被征收人享受房屋安置的，临时过渡安置费发放标准为每人每月租房补贴1000元，生活补贴500元。自被征收人签订征收补偿安置协议并腾空房屋之日起，先按18个月向被征收人一次性计发，期满后再每半年发放一次，直至被征收人取得安置房为止。

八、其他补偿及要求

（一）亚龙置业公司宿舍楼装饰、其他附着物等补偿可参照三府〔2013〕43号文件规定执行。

（二）项目范围内的南新农场土地、其他附着物及青苗等补偿标准按照三府〔2013〕43号文件规定执行，青苗包干补偿标准可按三府办〔2011〕208号文件规定执行。

（三）国有工业用地补偿按照国家、省征收国有工业用地土地的有关规定执行。

（四）南新农场居住房屋和非居住房屋的界定以征地调查通知下发后现场调查时间为准。

（五）在本方案下发之日前一年离异的家庭按一个家庭计。

九、保障措施

（一）在规定的搬迁期限内，被征收人因个人不合理原因拒不搬迁的，由吉阳区政府报市相关部门按程序办理拆迁手续后，予以强拆。

（二）执法部门对征收范围内的抢建、抢种及违章建筑依法予以打击。

（三）参与补偿、安置相关的工作人员，必须严格执行有关法律、法规、政策和本《方案》的规定，接受社会监督。对玩忽职守、滥用职权、徇私舞弊的，由其所在单位或上级主管机关给予处分。构成犯罪的，由司法机关依法追究刑事责任。

（四）对影响项目推进正常工作秩序，干扰、围攻、殴打工作人员执行公务的，由公安机关依照《中华人民共和国治安管理处罚法》进行处罚。构成犯罪的，依法追究刑事责任。

十、附则

（一）本方案自批准发布之日起施行。

（二）本方案中未尽事宜，或在项目房屋征收补偿安置过程中需对本方案的有关内容进行调整的，由征收实施单位会议讨论确定。

（三）本方案由吉阳区人民政府负责解释。
