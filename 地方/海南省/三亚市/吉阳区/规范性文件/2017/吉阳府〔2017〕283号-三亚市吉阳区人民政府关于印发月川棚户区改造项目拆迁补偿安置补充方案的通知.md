# 三亚市吉阳区人民政府关于印发月川棚户区改造项目拆迁补偿安置补充方案的通知

吉阳府〔2017〕283号

三亚市吉阳区人民政府

关于印发月川棚户区改造项目拆迁补偿安置

补充方案的通知

各有关单位：

《月川棚户区改造项目拆迁补偿安置补充方案》已经区委、区政府审议通过，并经市住建局备案登记，现印发给你们，请遵照执行。

三亚市吉阳区人民政府

2017年9月12日

（此件主动公开）

月川棚户区改造项目拆迁补偿安置补充方案

为确保月川棚户区改造项目顺利推进，根据《三亚市人民政府关于印发月川棚户区改造项目拆迁补偿安置方案的通知》（三府〔2016〕79号）的有关规定，结合月川村实际，现制定项目拆迁补偿安置补充方案如下：

一、安置对象的认定

在《三亚市人民政府关于印发月川棚户区改造项目拆迁补偿安置方案的通知》（三府〔2016〕79号）规定的安置对象认定基础上，将符合下列条件并在2017年12月31日前签订征收补偿协议并搬迁腾空房屋的人员列入安置范围：

（一）参照三亚市人民政府2016年第394期市长办公会议纪要精神，结合月川村实际，无月川居委会户籍，在征收范围内有自有独立住房，且同时符合下列条件的人员：

1.具有三亚市户籍；

2.持有月川居委会出具的土地来源证明；

3.在三亚市内未享受过福利分房（含经济适用房、单位分房、集资房、房改房等），且在月川村以外未享受宅基地分配、拆迁安置或福利分红；

4.房屋为框架结构或混合结构，且房屋面积大于60平方米（含60平方米）。

（二）参照三亚市人民政府2016年第394期市长办公会议纪要精神，结合月川村实际，无月川居委会户籍，在征收范围内有自有独立住房，且同时符合下列条件的人员：

1.具有三亚市户籍；

2.持有月川居委会出具的土地来源证明；

3.在三亚市内未享受过福利分房（含经济适用房、单位分房、集资房、房改房等），且在月川村以外未享受宅基地分配、拆迁安置或福利分红；

4.房屋为框架结构或混合结构，且房屋面积小于60平方米。

二、安置补偿标准

（一）本补充方案确定的第（一）类安置人员，按照“一证一户”的原则，现有房屋在120平方米以上的，每户安置居住面积120平方米；现有房屋在60平方米以上120平方米以下的，按其现有房屋实际面积1:1安置居住面积。如被征收人选择货币补偿，安置房屋的货币补偿标准为每平方米6400元。

（二）本补充方案确定的第（二）类安置人员，不给予安置房实物，按照现有房屋实际面积、每平方米6400元的标准给予货币补偿。装修按房屋建筑面积给予每平方米500元的补偿。

三、现有房屋的拆迁补偿

（一）本补充方案确定的第（一）类安置人员，其在月川村的现有房屋按以下标准给予补偿：

（1）现有房屋面积在525平方米以内（含525平方米）部分的补偿标准：

扣除安置房屋面积后剩余部分按框架结构每平方米1350元、混合结构每平方米1100元给予补偿。装修按房屋建筑面积给予每平方米500元的补偿。如现居住房屋有土地证和房产证等相关手续，其房屋装修按市场评估价格作价补偿。

（2）现有房屋面积在525平方米以上、1000平方米以内（含1000平方米）部分，按每平方米550元的标准给予补助，在规定时间内签订征收补偿协议并腾空房屋的，再给予每平方米250元的搬迁补贴。

（3）现有房屋面积在1000平方米以上的部分不予补偿。

（二）本补充方案确定的第（二）类安置人员，其在月川村的现有房屋不再予以补偿。

（三）符合《三亚市人民政府关于印发月川棚户区改造项目拆迁补偿安置方案的通知》（三府〔2016〕79号）规定的（一）、（二）、（三）、（五）、（六）类安置条件和本补充方案规定的安置条件，但在三亚市内享受过福利分房（含经济适用房、单位分房、集资房、房改房等）的人员，以及户籍已迁出月川居委会、在嫁入地享受土地承包、集体分红、拆迁补偿安置等待遇的外嫁女，其在月川村的现有房屋按以下标准给予补偿：

（1）现有房屋面积在525平方米以内（含525平方米）的部分，按框架结构每平方米1350元、混合结构每平方米1100元标准补偿。装修按房屋建筑面积给予每平方米500元的补偿。

（2）现有房屋面积在525平方米以上1000平方米以内（含1000平方米）的部分，按每平方米550元的标准给予补助，在规定时间内签订征收补偿协议并腾空房屋的，再给予每平方米250元的搬迁补贴。

（3）现有房屋面积在1000平方米以上的部分不予补偿。

四、分户原则

（一）原则上一本户口簿为一户。安置对象家庭成员符合下列条件的，可予以分户：

1.在政府征地决定发布之日前已结婚并办理婚姻登记手续的，可予以分户。

2.在政府征地决定发布之日前离婚满一年的，可予以分户。

3.自政府征地决定发布之日止，达到法定结婚年龄的未婚人员，可予以分户。

4.丧偶人员可予以分户。

（二）其他特殊情形需进行分户的，由月川居委会提出初步意见，项目推进工作领导小组复核后，报吉阳区棚户区改造工作议事小组审核确定。

五、其他事项

（一）《三亚市人民政府关于印发月川棚户区改造项目拆迁补偿安置方案的通知》（三府〔2016〕79号）规定的（一）～（五）类安置对象，其货币补偿标准由每平方米1.5万元调整为每平方米1.6万元；在2017年12月31日前签订征收补偿协议并搬迁腾空房屋的，可再上浮15%（即每平方米1.84万元）。

（二）项目范围内的坟墓迁移补偿标准为2.4万元/座，迁移地点由市政府和区政府统筹安排。

（三）单次搬迁补助费由每户3000元调整为3600元；临时过渡安置费中的租房补贴由每户每月3000元调整为4000元。

（四）对《三亚市人民政府关于印发月川棚户区改造项目拆迁补偿安置方案的通知》（三府〔2016〕79号）规定的第（六）类和本补充方案确定的安置对象，临时过渡安置费中的生活补贴标准为每户每月500元。

（五）《三亚市人民政府关于印发月川棚户区改造项目拆迁补偿安置方案的通知》（三府〔2016〕79号）规定的第（六）类安置对象现有房屋的补偿标准，参照本补充方案第三条第（一）款执行。

（六）出具土地来源证明的流程为：月川居委会召集2/3以上居民代表会议讨论，半数以上与会代表讨论通过后公示7日，在公示期内无异议的，由居委会出具土地来源证明。

（七）其他补偿标准，按照《三亚市人民政府关于印发月川棚户区改造项目拆迁补偿安置方案的通知》（三府〔2016〕79号）有关规定执行。

（八）本方案与《三亚市人民政府关于印发月川棚户区改造项目拆迁补偿安置方案的通知》（三府〔2016〕79号）不相一致之处，以本方案为准。

三亚市吉阳区人民政府办公室
