# 关于印发同心家园红沙小区周边规划市政道路（红沙片区规划八路）项目房屋征收补偿

吉阳府〔2017〕344号

三亚市吉阳区人民政府

关于印发同心家园红沙小区周边规划市政道路（红沙片区规划八路）项目房屋征收补偿

安置方案的通知

红沙居委会，各相关单位：

根据《三亚市人民政府办公室关于同心家园红沙小区周边规划市政道路（红沙片区规划八路）项目用地土地调查有关事项的通知》（三府办〔2015〕348号）精神，为加快推进同心家园红沙小区周边规划市政道路（红沙片区规划八路）项目征收补偿安置工作，根据《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）、《三亚市人民政府关于印发三亚市征收集体土地青苗补偿费和征地经费包干管理暂行办法的通知》（三府〔2011〕208号）和《国有土地上房屋征收与补偿条例》（国务院590号令）等相关规定，结合项目征地实际，特制订《同心家园红沙小区周边规划市政道路（红沙片区规划八路）项目房屋征收补偿安置方案》，现印发给你们，请认真贯彻执行。

三亚市吉阳区人民政府

2017年10月11日

（此件主动公开）

同心家园红沙小区周边规划市政道路（红沙

片区规划八路）项目房屋征收

补偿安置方案

为加快推进同心家园红沙小区周边规划市政道路（红沙片区规划八路）项目征收补偿安置工作，现根据《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）、《三亚市人民政府关于印发三亚市征收集体土地青苗补偿费和征地经费包干管理暂行办法的通知》（三府〔2011〕208号）和《国有土地上房屋征收与补偿条例》（国务院590号令）等相关规定，结合项目征地实际，制定该项目征收补偿安置方案。

一、被征收户分类和认定

（一）被征收户分类

综合项目实际，将项目涉及被征收户分为符合安置补偿人员和其他情形人员两类，具体如下：

1.符合安置补偿人员：在本方案发布之日前在项目范围内有相对独立房屋，且具有原红沙社区居委会出具的宅基地销售合同和宅基地安排证明书的人员。

2.其他情形人员：在本方案发布之日前在项目范围内有相对独立房屋的，但不属于符合安置补偿人员以外的其他人员。

（二）被征收户认定

被征收户认定由红沙居委会和征地工作组共同确认；如属其他情形人员需列入安置的，由被征收户提出申请，经红沙社区居委会和征地工作组调查审核后，报吉阳区政府审议确定。

二、房屋征收安置补偿标准

（一）符合安置补偿人员的安置补偿标准

符合安置补偿人员采用货币补偿、货币补偿和产权调换相结合的两种安置补偿方式，具体由被征收人自行选定。

1.货币补偿标准

（1）现有居住房屋按照框架结构每平方米1250元、混合结构每平方米1050元的标准补偿。

（2）现有居住房屋270平方米的部分，按房屋补偿金额的100%给予奖励补偿；超出现居住房屋270平方米以外的部分，按房屋补偿金额的30%给予奖励补偿。

（3）房屋装饰、青苗及其它附着物等补偿标准参照《三亚市集体土地征收补偿安置管理规定的通知》（三府〔2013〕43号）规定另行补偿。

（4）搬迁补助以被征收人（外来人员除外）现有居住房屋的建筑面积（不包括简易结构房屋、铁皮棚等）为基数，按照每平方米18元的标准给予搬迁补助费（单次搬迁最低不少于3000元）。

（5）临时过渡安置期为6个月，按每栋每月6000元的标准一次性发放。

2.货币补偿和产权调换相结合

（1）每栋可申请置换1套安置房（具体面积以实际分配安置房为准），安置房拟从市保障性住房房源中予以解决。

（2）现有居住房屋置换后剩余房屋面积按照框架结构每平方米1250元、混合结构每平方米1050元的标准补偿。

（3）现居住房屋属270平方米（含270平方米）的部分，按扣除置换面积后剩余房屋面积补偿金额的100％给予奖励补偿；超出现居住房屋270平方米以外的部分，按房屋补偿金额的30%给予奖励补偿。

（4）房屋装饰、青苗及其它附着物等补偿标准参照《三亚市集体土地征收补偿安置管理规定的通知》（三府〔2013〕43号）规定另行补偿。

（5）搬迁补助以被征收人现有居住房屋的建筑面积（不包括简易结构房屋、铁皮棚等）为基数，按照每平方米18元的标准给予搬迁补助费（单次搬迁最低不少于3000元）。

（6）临时过渡安置期为6个月，按每栋每月6000元的标准一次性发放。

（二）其他情形人员的补偿标准

（1）现有居住房屋按照框架结构每平方米1250元、混合结构每平方米1050元的标准补偿。

（2）房屋装饰、青苗及其它附着物等补偿标准参照《三亚市集体土地征收补偿安置管理规定的通知》（三府〔2013〕43号）规定另行补偿。

（3）搬迁补助按每栋3000元的标准给予一次性搬迁补助。

（4）临时过渡安置费按每栋每月6000元的标准一次性发放，临时过渡安置期为6个月。

（三）被征收户自行将其居住房屋改为经营性用房且同时符合下列条件的，按照本方案发布前一年的月平均营业额8%的标准给予停产、停业补偿，补偿期限6个月。营业额以税务部门核准的纳税申报为准。

（1）持有土地、房屋权属证书或相关证明；

（2）持有工商执照且正在营业中。

以上材料被征收户应在确认清点丈量数据后5个工作日提供给项目征地工作组，由项目征地工作组审核通过后制表补偿；逾期未提供的，视为放弃补偿。

三、土地征收补偿

（一）征收集体土地补偿标准按三府〔2013〕43号文件执行。

（二）收回国有土地补偿标准按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、附则

（一）本方案自批准发布之日起施行。

（二）本方案中未尽事宜，或在项目房屋征收补偿安置过程中需对本方案的有关内容进行调整的，由吉阳区政府会议讨论确定。

（三）本方案由吉阳区人民政府负责解释。

三亚市吉阳区人民政府办公室
