# 关于印发三亚市吉阳区教育巷片区棚户区改造项目征收补偿安置方案的通知

吉阳府〔2017〕363号

三亚市吉阳区人民政府

关于印发三亚市吉阳区教育巷片区

棚户区改造项目征收补偿安置方案的通知

区各有关单位：

《三亚市吉阳区教育巷片区棚户区改造项目征收补偿安置方案》已经区委、区政府审议通过，现印发给你们，请遵照执行。

附件：关于港门村教育巷片区棚户区改造项目征收补偿安置

方案征求意见情况的说明

三亚市吉阳区人民政府

2017年10月19日

（此件主动公开）

三亚市吉阳区教育巷片区

棚户区改造项目征收补偿安置方案

为优化城市环境，提升三亚市整体形象和品位，改善吉阳区教育巷片区居民的居住条件，保障片区改造工作顺利进行，根据国家、省、市有关文件规定，结合改造片区实际情况，制定本方案。

一、征收范围及基本情况

教育巷片区棚户区改造征收四至范围：东至临春河路；西至山水云天公寓；南至市委大院边界；北至市二小边界，改造地块总面积约31.19亩，具体范围四至坐标及面积以项目规划红线的实际勘测定界为准。

改造区域需征收三亚市电视台等六家单位职工宿舍，征收房屋建筑面积约3.72万平方米，户数约349户，最终数据以实际测量核定为准。

二、指导思想

坚持以科学发展观为指导，围绕国际性热带滨海旅游城市、国际旅游岛建设的战略目标，加快推进城市国际化进程，完善城市基础设施，改善城市面貌和居民居住条件及生活环境，提升城市品位、价值和形象，维护被征收单位、被征收人的合法权益，在依法征收的基础上，做到和谐征收。

三、征收主体和法律依据

（一）征收主体

1. 征收人：三亚市吉阳区人民政府。

2. 征收实施单位：三亚市吉阳区住房和城乡建设局。

3. 被征收人：项目范围内需要征收的房屋及其他建筑物、地上附着物的合法产权人。

（二）法律依据

1.《中华人民共和国土地管理法》（2004年8月28日公布实施）；

2.《中华人民共和国城乡规划法》（2008年1月1日起实施）；

3.《国有土地上房屋征收评估办法》(建房〔2011〕77号)；

4.《国有土地上房屋征收与补偿条例》（国务院令第590号）；

5.《三亚市集体土地征收补偿安置管理规定（2013年修订）》 （三府〔2013〕43号）；

6.《三亚市棚户区改造房屋征收补偿安置暂行办法》（三府 〔2015〕112号）。

四、征收补偿安置原则

（一）坚持“公开、公平、公正”和“依法和谐征收”原则。

（二）坚持“先补偿后搬迁”原则。

（三）坚持以人为本，让利于民，保障被征收户的合法利益。

（四）坚持依法征收和坚持打击违法、违章建筑相结合原则。

五、被征收房屋的认定

（一）房屋征收范围内住宅房屋、非住宅房屋的认定，按照房屋所有权证记载的用途确定。房屋所有权证没有记载用途的，按照规划部门批准的用途确定。

（二）被征收房屋建筑面积和套内面积的认定：

1.被征收房屋建筑面积和套内面积的认定，按照房屋所有权证记载的建筑面积和套内面积确定。房屋所有权证没有记载的，按照有资质测绘机构的测绘结果确定。

2.房屋征收范围内已按照房改政策出售的公房、集资房、房改房等，尚未取得房屋所有权证的，按照购房合同（或协议）记载的建筑面积和套内面积核实确定。购房合同（或协议）没有记载的，按照有资质测绘机构的测绘结果确定。

3.被征收人房屋没有所有权证书，但持有土地证或合法土地来源证明的，按以下方法认定安置面积：

（1）有合法报建手续的，按照批准的房屋面积认定安置面积；

（2）没有报建手续的，对现有房屋（占地面积不超出土地证或合法土地来源确定的面积）四层半（含四层半）以下部分，可予认定为安置面积。

（三）超出批建部分、或既没有房屋产权证又没有相关合法手续的房屋，按以下标准给予补助：

1.1000平方米以内部分，按照框架结构每平方米1350元、混合结构每平方米1100元的标准给予建安材料费补助。装修按房屋建筑面积每平方米500元标准给予补助。

2.1000平方米以上部分不予补助。

（四）未超过批准期限的临时建筑，可按批准使用的剩余期限予以适当的货币补偿;已超过批准期限的临时建筑不予补偿，应自行拆除。

六、征收补偿

征收补偿方式分为货币补偿、产权调换、货币补偿和产权调换相结合三种，具体补偿方式由被征收人自行选定。

（一）货币补偿

1.征收住宅房屋，被征收人选择货币补偿的，按照安置房屋的市场评估价格进行补偿。

2.征收非住宅房屋，被征收人选择货币补偿的，按照安置房屋的市场评估价格进行补偿；造成停产、停业的，给予6个月的补偿，补偿标准以房屋征收公告前一年的月平均营业额（以税务部门核准的纳税申报为准）的8%计算。

3.被征收人自行将临街的底层住宅改变为商业经营用房且同时符合下列条件的，除按照住宅房屋给予货币补偿外，再按照安置房屋市场评估价值的50%给予货币补偿：

（1）持有房屋权属证书或其他合法手续；

（2）持有工商执照并正在营业中；

（3）被征收前连续3年以上（含3年）依法纳税。

（二）产权调换

1.征收住宅房屋，被征收人选择产权调换的，在不改变国有土地使用权取得方式的情况下，按照被征收房屋套内面积调换安置房套内面积并结算，调换比例如下：

2.非住宅房屋仅可选择货币补偿，不作产权调换。

3.被征收人自行将临路（街）的底层住宅改变为商业经营用房且同时符合下列条件的，对该底层住宅部分，除按照住宅房屋进行产权调换外，再按照安置房屋市场评估价值的50%给予货币补偿：

（1）持有房屋权属证书或其他合法手续；

（2）持有工商执照并正在营业中；

（3）被征收前连续3年以上（含3年）依法纳税。

（三）货币补偿与产权调换相结合

被征收人选择货币补偿与产权调换相结合补偿方式的，按照上述第（一）、（二）款有关规定执行。

（四）产权调换房屋差额面积结算和其它费用

1.产权调换房屋套内面积差额在5㎡以内（含5㎡）的，按安置房的建安成本价格结清差价；套内面积差额超出5㎡的，按相关部门审定的安置房市场价格结清差价。超选安置房套内面积部分最大不能超过15㎡。

2.被征收人应得安置房屋面积对应的相关税费由征收人承担；超出部分面积所产生的契税、印花税、维修基金、办证手续费等费用，由被征收人在办理安置房交付使用前一次性缴清。

3.安置房屋为天然气入户，如被征收房屋在征收前未安装天然气管道，被征收人在办理安置房入户手续时须缴纳天然气管道入户初装费，具体缴费标准以天然气公司确定的价格为准。

4.被征收的房屋已依法取得房屋所有权证的，换发安置房屋所有权证所需费用由征收人承担；被征收房屋未依法取得房屋所有权证的，征收人协助被征收人办理房屋所有权证，换发安置房屋所有权证所需费用由被征收人承担；被征收房屋土地性质为划拨，安置房需办理为出让地的，由被征收人补交土地出让金；换发安置房屋所有权证时安置房屋维修基金由被征收人承担。

（五）被征收房屋的评估

1.评估机构的选定

房地产价格评估机构由被征收人协商选定（应经半数以上被征收人同意）；协商不成的，由房屋征收实施单位组织被征收人代表从已在三亚市备案的评估机构库中随机抽取。被征收房屋价值评估时间节点为房屋征收决定公告之日。

2.评估方式

选定的评估机构依照相关法律法规，被征收房屋、装修等进行价值评估，并出具评估报告。评估结果应视情况在改造项目范围内进行公示。

被征收人或房屋征收实施单位对评估结果有异议的，应当自收到评估报告之日起10日内，向评估机构申请复核；被征收人或房屋征收实施单位对评估机构的复核结果有异议的，应当自收到复核结果之日起10日内，向三亚市房地产价格评估专家委员会申请鉴定。

（六）房屋装修及其它地上附着物补偿

1.被征收人选择产权调换、货币补偿和产权调换相结合的补偿方式，被征收房屋的装修按照市场评估价格给予补偿。

2.其它地上附着物按市场评估价格补偿。

3.树木、青苗的补偿标准，采取评估方式补偿，或参照《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）执行。如市政府出台最新文件规定的，按最新文件规定执行。违法抢种的树木、青苗一律不给予补偿。

4.被征收房屋的空调、电话、有线电视（数字电视）、太阳能热水器等迁移补助费用，参照《三亚市集体土地上征收补偿安置管理规定（2013年修订）》（三府〔2013〕43号）文件规定执行。政府如出台新的文件规定，从其规定。

（七）公共部分的征收补偿

改造区域扣除被征收人所有房屋以外的公共部分建筑，按照市场评估价格予以回收补偿。

七、临时过渡安置和搬迁补助

（一）临时过渡安置

1.被征收人产权调换、货币补偿和产权调换相结合补偿方式的，向被征收人发放临时过渡费由其自行过渡安置。发放标准具体如下：

（1）被征收房屋套内面积在100平方米以下的（含100平方米），按4000元/户/月的标准发放临时过渡安置费。

（2）被征收房屋套内面积在100-200平方米以内的（含200平方米），按6000元/户/月的标准发放临时过渡安置费。

（3）被征收房屋套内面积在200-300平方米以内的（含300平方米），按8000元/户/月的标准发放临时过渡安置费。

（4）被征收房屋套内面积在300平方米以上的，按10000元/户/月的标准发放临时过渡安置费。

2.临时过渡安置费发放时间从被征收人签订征收补偿安置协议并腾空居住房屋之日起计算。先按18个月向被征收人一次性计发，期满后再每半年发放一次，直至被征收人分配安置房现房为止。

（二）搬迁补助

以被征收房屋的套内面积（不包含简易结构房屋、铁皮棚、临时建筑和外来人员房屋）为基数，按照每平方米20元的标准给予搬迁补助费。按上述方式计算不足3000元的，按3000元计算。

被征收人选择货币补偿方式的，在签署征收补偿安置协议后按一次搬迁，一次性结清搬迁补助费；被征收人选择产权调换（含货币补偿和产权调换相结合）的，在签署征收补偿安置协议后按两次搬迁，一次性结清搬迁补助费。

十、搬迁奖励

积极配合进行清点、丈量和登记，按规定时间内签订房屋征收补偿安置协议，同时，在签订房屋征收补偿安置协议时间内搬迁腾空房屋的被征收人给予奖励，具体奖励情况如下：

（一） 被征收人在本项目征收决定公告之日起45日内（含45日）签订房屋征收补偿安置协议并搬迁腾空房屋的，一次性给予人民币8万元/户的奖励。

（二） 被征收人在本项目征收决定公告之日起45日后至65日内（含65日）签订房屋征收补偿安置协议并搬迁腾空房屋的，一次性给予人民币5万元/户的奖励。

（三） 被征收人在本项目征收决定公告之日起65日后至90日内（含90日）签订房屋征收补偿安置协议并搬迁腾空房屋的，一次性给予人民币2万元/户的奖励。

（四） 被征收人在本项目征收决定公告之日起超过90日签订房屋征收补偿安置协议和搬迁的，不给予任何货币奖励。

九、安置房建设和分配

（一）安置房建设

1.安置房选址在本改造项目范围内。

2.安置房按照国家城市居民住宅楼建设标准统一规划，统一设计，统一建设。户型面积以市规划局、市住房和城乡建设局审批确定的为准。安置房交房时的装修标准为简装。

3.安置房图纸设计及施工情况随时接受被征收人监督，以确保安置房建设进度及质量。

（二）安置房分配

1.安置房分配工作由房屋征收实施部门负责组织实施，公证处给予业务指导和见证。

2.按照被征收人签订的征收补偿安置协议时间顺序确定选房顺序；同一日签订征收补偿安置协议的，采取抽签方式确定选房顺序。

3.安置房分配工作开始前，房屋征收实施部门应采取电话通知、张贴告示、登报公告等方式，提前通知被征收人选房时间、地点和其它有关事项。

十、房屋征收拆除

按照《三亚市人民政府关于印发三亚市棚户区改造房屋征收拆除工作若干意见的通知》（三府〔2016〕266号）和三亚市人民政府有关规定执行。

十一、福利保障

（一）被征收人家庭人均收入低于最低生活保障的特困户、低保户、五保户和《三亚市城镇最低收入家庭廉租住房管理办法》规定的廉租住房保障对象（以区人民政府、区民政部门、区人事社保部门、辖区社区、辖区派出所共同出具证明证实，户口为三亚地区且在本棚改项目征收区域内）及廉租住房保障对象，依法将纳入最低生活保障，可直接向市相关部门申请租赁住房补贴或者公租房实物配租。

（二）从被征收人安置入住之年起，被征收人的子女可以选择继续就读原学校，也可以选择转学就读，需要转学就读的，市、区政府教育部门应当依据其新迁住址划定的招生范围免费依法办理相关手续。

（三）被征收人中的零就业家庭成员、抚养未成年子女的单亲家庭成员和享受最低生活保障待遇的人员，在法定劳动年龄内、有劳动能力和就业愿望的，由市、区政府人事社保部门给予核发《失业登记证》，纳入再就业政策扶持范围。

（四）被征收人在法定劳动年龄内持有《失业登记证》或属于城镇登记失业人员的，市、区政府人事社保部门应当给予免费职业技能培训和就业再就业税费减免等。

（五）实行财政补贴或扶持的各类社会公益性岗位，应当优先安排被征收户中持有《失业登记证》的零就业家庭成员及就业困难人员就业。

十二、强制搬迁

征收人与被征收人在签约期限内（以房屋征收决定公告为准）达不成补偿协议，或者被征收房屋所有权人不明确的，由吉阳区人民政府作出补偿决定，依法送达被征收人并予以公告。

被征收人在法定期限内不申请行政复议或者不提起行政诉讼，在补偿决定规定的期限内又不搬迁的，由吉阳区人民政府依法申请人民法院强制执行。

十三、附则

（一）本方案中的 “户”按下列原则确定：被征收房屋有房屋所有权证书的，按照“一证一户”原则确定；已按照房改政策出售的公房、集资房、房改房等，尚未取得房屋所有权证的，按 “一合同（协议）一户”的原则确定；没有房屋所有权证书，按照“一栋一户”的原则确定。

（二）本方案中“四层半”的含义：“四层”是指地上建筑四层总面积；“半层”是指地上四层平均每层面积的一半（计算方法：半层面积=地上四层总面积×1/4×50%）（含本数）。

（三）本方案中未尽事宜，按照《国有土地上房屋征收与补偿条例》及省、市有关规定，由征收实施单位与被征收人协商解决。

（四）本方案由三亚市吉阳区人民政府负责解释。

（五）本方案自公布之日起施行。
