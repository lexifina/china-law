# 关于印发三亚市吉阳区大东海鹿鸣小区棚户区改造项目征收补偿安置方案的通知

吉阳府〔2017〕364号

签发人：张华文

三亚市吉阳区人民政府

关于印发三亚市吉阳区大东海鹿鸣小区

棚户区改造项目征收补偿安置方案的通知

区各有关单位：

《三亚市吉阳区大东海鹿鸣小区棚户区改造项目征收补偿安置方案》已经区委、区政府审议通过，现印发给你们，请遵照执行。

附件：关于吉阳区大东海鹿鸣小区棚户区改造项目征收补偿

安置方案征求意见情况的说明

三亚市吉阳区人民政府

2017年10月19日

（此件主动公开）

三亚市吉阳区大东海鹿鸣小区

棚户区改造项目征收补偿安置方案

为改善大东海鹿鸣小区周边环境，消除片区楼房“老、旧、危”现象，改善片区居民的居住条件，提升三亚市整体形象和品位，保障片区改造工作顺利进行，根据国家、省、市有关文件规定，结合改造片区实际情况，制定本方案。

一、征收范围（四至范围）和基本情况

四至范围：东至海花路，南至宝宏大酒店地界，西至鹿岭路，北至夏威夷大酒店，具体范围四至及坐标以项目规划红线的实际勘测定界为准。征收范围土地面积约35.53亩，性质为国有出让地。需征收房屋户数90户，总建筑面积约34236平方米，具体数据以实际测量为准。

二、指导思想及基本原则

以科学发展观为指导，以维护广大人民群众的根本利益为宗旨，以加快推进片区危旧房改造为目标，坚持公开、公平、公正，依法征收补偿，依法拆迁安置，先安置补偿，后拆迁的原则，达到和谐拆迁，满意安置。

三、征收主体

（一）征收主体

征收人：三亚市吉阳区人民政府。

征收实施单位：三亚市吉阳区住房和城乡建设局。

（二）法律依据

1.《中华人民共和国土地管理法》（2004年8月28日公布实施）；

2.《中华人民共和国城乡规划法》（2008年1月1日起实施）；

3.《国有土地上房屋征收评估办法》(建房〔2011〕77号)；

4.《国有土地上房屋征收与补偿条例》（国务院令第590号）；

5.《三亚市集体土地征收补偿安置管理规定（2013年修订）》 （三府〔2013〕43号）；

6.《三亚市棚户区改造房屋征收补偿安置暂行办法》（三府 〔2015〕112号）。

四、被征收人和被征收房屋的认定

（一）被征收人：具有改造项目范围内被征收房屋及其他建筑物、地上附着物有效产权证书、产权证明或其它合法手续的合法产权人。

被征收人没有房屋所有权但有其占有该房屋的合法手续的，必须由本人在签订征收补偿协议前完善个人房屋产权过渡等相关手续。

（二）被征收房屋：改造项目范围内具有有效产权证书、产权证明或合法手续的房屋及其它建筑物。

（三）住宅与非住宅的认定：改造项目范围内住宅与非住宅房屋的认定，按照房屋产权证上登记的用途确定。没有房屋产权证明或房屋产权证上没有明确登记用途的，按照规划部门批准的用途确定。

（四）被征收房屋建筑面积和套内面积的认定：被征收房屋的建筑面积和套内面积，以被征收人房屋产权证上登记的面积为准；没有房屋产权证的，以规划部门批准的面积为准；房屋产权证或规划审批文件上均未标明建筑面积和套内面积的，以有资质测绘机构测量并经被征收人认可的面积为准（安置房的建筑面积和套内面积的认定同样参照本款执行）。

五、超出批建部分或无合法手续房屋的处理方式

改造范围内超出批建部分、或既没有房屋产权证又没有相关合法手续的房屋，按以下标准给予补助：

（一）1000平方米以内部分，按照框架结构每平方米1350元、混合结构每平方米1100元的标准给予建安材料费补助。装修按房屋建筑面积每平方米500元标准给予补助。

（二）1000平方米以上部分不予补助。

六、临时建筑的处理方式

（一）未超过批准期限的临时建筑，按照批准使用的剩余期限给予适当的货币补偿；

（二）未取得批准或已超过批准期限的临时建筑不予补偿，应自行拆除。

七、征收补偿安置

对被征收房屋，采取货币补偿、产权调换、货币补偿和产权调换相结合三种方式进行补偿，具体补偿方式由被征收人自行选定。

（一）货币补偿

1.征收住宅房屋，被征收人选择货币补偿的，按照评估机构依法评估确定的被征收房屋市场评估价格进行补偿，再给予其被征收房屋市场评估价格20%的奖励。

2.征收非住宅房屋，被征收人选择货币补偿的，按照评估机构依法评估确定的被征收房屋市场评估价格进行补偿，再给予其被征收房屋市场评估价格20%的奖励；造成停产、停业的，给予6个月的补偿，补偿标准以房屋征收公告前一年的月平均营业额（以税务部门核准的纳税申报为准）的8%计算。

3.被征收人自行将临街的底层住宅改变为商业经营用房且同时符合下列条件的，除按照住宅房屋给予货币补偿外，再按照该底层住宅部分市场评估价格增加50%给予货币补偿。

（1）持有房屋权属证书或其他合法手续；

（2）持有工商执照并正在营业中；

（3）被征收前连续3年以上（含3年）依法纳税。

（二）产权调换

被征收人选择产权调换的，在不改变国有土地使用权取得方式的情况下，按以下标准置换：

1.公寓住宅

根据《三亚市棚户区改造房屋征收补偿安置暂行办法》（三府〔2015〕112号）的有关规定，按照被征收房屋的套内面积置换安置房屋（套内面积）。置换比例如下：

3.非住宅房屋

（1）按照被征收房屋的建筑面积调换非住宅房屋，调换比例参照住宅房屋补偿标准执行；造成停产、停业的，给予6个月的补偿，补偿标准以房屋征收公告前一年的月平均营业额（以税务部门核准的纳税申报为准）的8%计算。

（2）被征收人自行将临街的底层住宅改变为商业经营用房且同时符合下列条件的，对该底层住宅部分，除按照住宅房屋进行产权调换外，再给予被征收人该底层住宅部分市场评估价格50%的货币补偿：

①持有房屋权属证书或其他合法手续；

②持有工商执照并正在营业中；

③被征收前连续3年以上（含3年）依法纳税。

（三）货币补偿与产权调换相结合

被征收人选择货币补偿与产权调换相结合补偿方式的，按照上述第（一）、（二）款有关规定执行。

（四）产权调换房屋差额面积结算

1.产权调换房屋套内面积差额在5㎡以内（含5㎡）的，按安置房的建安成本价格结清差价；套内面积差额超出5㎡的，按相关部门审定的安置房市场价格结清差价。超选安置房套内面积部分最大不能超过15㎡。

2.被征收人应得安置房屋面积对应的相关税费由征收人承担；超出部分面积所产生的契税、印花税、维修基金、办证手续费等费用，由被征收人在办理安置房交付使用前一次性缴清。

3.安置房屋为天然气入户，如被征收房屋在征收前未安装天然气管道，被征收人在办理安置房入户手续时须缴纳天然气管道入户初装费，具体缴费标准以天然气公司确定的价格为准。

（五）房屋装修及其它补偿

1.被征收人选择产权置换、货币补偿和产权调换相结合的补偿方式，被征收房屋的装修按照市场评估价格给予补偿。

2.其它地上附着物按市场评估价格补偿。

3.树木、青苗的补偿标准，采取评估方式补偿，或参照《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）执行。如市政府出台最新文件规定的，按最新文件规定执行。违法抢种的树木、青苗一律不给予补偿。

4.空调、电话、有线电视（数字电视）、太阳能热水器等迁移补助费用，参照《三亚市集体土地上征收补偿安置管理规定（2013年修订）》（三府〔2013〕43号）文件执行。

（六）公共部分的征收补偿

改造区域扣除被征收人所有的土地房屋以外的公共部分，按照市场评估价格予以回收补偿。补偿资金由所有被征收人协商分配。

八、被征收房屋的评估

（一）评估机构的选定

评估机构由被征收人协商选定（应经半数以上被征收人同意）。协商不成的，由房屋征收实施单位组织被征收人代表从已在三亚市备案的评估机构库中随机抽取。被征收房屋的价格评估时间节点为房屋征收决定公告之日。

（二）评估方式

选定的评估机构依照相关法律法规，分别对项目范围内公寓住宅、别墅、商业房屋等进行价值评估，并出具评估报告。评估结果应视情况在改造项目范围内进行公示。

被征收人或房屋征收实施单位对评估结果有异议的，应当自收到评估报告之日起10日内，向评估机构申请复核；被征收人或房屋征收实施单位对评估机构的复核结果有异议的，应当自收到复核结果之日起10日内，向三亚市房地产价格评估专家委员会申请鉴定。

九、搬迁补助和临时过渡安置费用

（一）搬迁补助费：以本方案第四条第（四）款确定的被征收房屋的建筑面积（不包括简易结构房屋、铁皮棚等）为基数，按照每平方米20元的标准给予搬迁补助费。按上述方式计算不足3000元的，按3000元计算。

被征收人选择货币补偿方式的，在签署征收补偿安置协议后按一次搬迁、一次性结清搬迁补助费；被征收人选择产权调换（含货币补偿和产权调换相结合）的，在签署征收补偿安置协议后按两次搬迁、一次性结清搬迁补助费。

（二）临时过渡安置费：

1.被征收人选择产权调换、货币补偿和产权调换相结合补偿方式的，向被征收人发放临时过渡费由其自行过渡安置。发放标准具体如下：

（1）被征收房屋套内面积在100平方米以下的（含100平方米），按4000元/户/月的标准发放临时过渡安置费。

（2）被征收房屋套内面积在100-200平方米（含200平方米）的，按6000元/户/月的标准发放临时过渡安置费。

（3）被征收房屋套内面积在200-300平方米（含300平方米）的，按8000元/户/月的标准发放临时过渡安置费。

（4）被征收房屋套内面积在300平方米以上的，按10000元/户/月的标准发放临时过渡安置费。

2.临时过渡安置费发放时间从被征收人签订征收补偿安置协议并腾空居住房屋之日起计算。先按18个月向被征收人一次性计发，期满后再每半年发放一次，直至被征收人分配安置房现房为止。

十、安置房建设

（一）安置房选址在本改造项目范围内。

（二）安置房按照国家城市居民住宅楼建设标准统一规划，统一设计，统一建设。户型面积以市规划局、市住房和城乡建设局审批确定的为准。安置房交房时的装修标准为简装。

（三）安置房图纸设计及施工情况随时接受被征收人监督，以确保安置房建设进度及质量。

十一、安置房分配

（一）安置房分配工作由房屋征收实施单位负责组织实施，公证处给予业务指导和见证。

（二）按照被征收人签订的征收补偿安置协议时间顺序确定选房顺序；同一日签订征收补偿安置协议的，采取抽签方式确定选房顺序。

（三）安置房分配工作开始前，房屋征收实施单位应采取电话通知、张贴告示、登报公告等方式，提前通知被征收人选房时间、地点和其它有关事项。

十二、奖励

积极配合进行清点、丈量和登记，在规定时间内签订房屋征收补偿安置协议，同时，在签订房屋征收补偿安置协议规定时间内搬迁腾空房屋的被征收人给予奖励，具体奖励情况如下：

（一） 被征收人在本项目征收决定公告之日起45日内（含45日）签订房屋征收补偿安置协议并搬迁腾空房屋的，一次性给予人民币8万元/户的奖励。

（二） 被征收人在本项目征收决定公告之日起45日至65日内（含65日）签订房屋征收补偿安置协议并搬迁腾空房屋的，一次性给予人民币5万元/户的奖励。

（三） 被征收人在本项目征收决定公告之日起65日至90日内（含90日）签订房屋征收补偿安置协议并搬迁腾空房屋的，一次性给予人民币2万元/户的奖励。

（四） 被征收人在本项目征收决定公告之日起超过90日签订房屋征收补偿安置协议和搬迁的，不给予任何货币奖励。

十三、房屋征收拆除

按照《三亚市人民政府关于印发三亚市棚户区改造房屋征收拆除工作若干意见的通知》（三府〔2016〕266号）和三亚市人民政府有关规定执行。

十四、保障措施

（一）征收人与被征收人在规定期限内达不成补偿协议，或被征收房屋所有权人不明确的，由房屋征收实施单位报吉阳区人民政府作出补偿决定，依法送达被征收人并予以公告。

接到补偿决定后，被征收人在法定期限内不申请行政复议或者不提起行政诉讼，在补偿决定规定的期限内又不搬迁的，由作出房屋征收决定的吉阳区人民政府依法申请人民法院强制执行。

（二）对征收范围内的抢建、抢种行为以及违法建筑，执法部门将依法予以打击。

（三）房屋征收实施单位参与征收补偿安置工作的人员，必须严格执行有关法律、法规、政策和本《方案》的规定，接受社会监督。对玩忽职守、滥用职权、徇私舞弊的，由其所在单位或上级主管机关给予处分。构成犯罪的，由司法机关依法追究刑事责任。

（四）对被征收人干扰、阻挠工作推进，围攻、殴打工作人员的，由公安机关依照《中华人民共和国治安管理处罚法》进行处罚。构成犯罪的，依法追究刑事责任。

十五、附则

（一）本方案中未尽事宜，按照《国有土地上房屋征收与补偿条例》（国务院590号令）、参照《三亚市集体土地上征收补偿安置管理规定（2013年修订）》（三府〔2013〕43号）其他有关规定，由征收实施单位与被征收人协商解决。

（二）本方案由吉阳区人民政府负责解释。
