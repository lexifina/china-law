# 关于印发三亚有轨电车示范线工程项目车辆段（含部分道路）用地土地征收补偿安置方案的通知

吉阳府〔2017〕376号

三亚市吉阳区人民政府

关于印发三亚有轨电车示范线工程项目

车辆段（含部分道路）用地土地征收补偿

安置方案的通知

抱坡村委会，各相关单位：

为做好三亚有轨电车示范线工程项目车辆段（含部分道路）用地的征收补偿工作。根据《三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）和《三亚市人民政府关于印发三亚市棚户区改造房屋征收补偿安置暂行办法的通知》（三府〔2015〕112号），结合三亚有轨电车示范线工程项目车辆段（含部分道路）用地区域内的实际情况，特制定《三亚有轨电车示范线工程项目车辆段（含部分道路）用地土地征收补偿安置方案》。现印发给你们，请认真贯彻执行。

三亚市吉阳区人民政府

2017年10月30日

（此件主动公开）

三亚有轨电车示范线工程项目车辆段（含部分道路）用地土地征收补偿安置方案

为做好三亚有轨电车示范线工程项目车辆段（含部分道路）的征收工作，根据《中华人民共和国土地管理法》、《中华人民共和国城乡规划法》、《中华人民共和国物权法》、《国有土地上房屋征收评估办法》（建房〔2011〕77号）、《城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）、《国有土地上房屋征收与补偿条例》（国务院令第590号）、《三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）和《三亚市人民政府关于印发三亚市棚户区改造房屋征收补偿安置暂行办法的通知》（三府〔2015〕112号）等法律、法规及参照三亚市政府有关规定，结合三亚有轨电车示范线工程项目车辆段（含部分道路）用地区域内的实际情况，制定本方案。

一、征收土地及地上建筑物基本情况

（一）土地征收情况

1.国有土地征收情况：收回国有土地约53998平方米，其中：三亚海润实业投资有限公司国有土地约11203平方米，粤海铁路有限责任公司国有土地约7367平方米，三亚市工业区开发建设管理委员会国有土地约12185平方米，国家所有23243平方米。

2.集体土地征收情况：征收抱坡村集体土地17706平方米。

（二）地上建筑物基本情况

1.国有土地上建筑物征收情况：涉及海润实业公司房屋3栋约439平方米；三亚市工业区开发建设管理委员会土地上合丰纸业有限公司厂房约7342平方米；粤海铁路公司砖混结构约380平方米。

2.集体土地上建筑物征收情况：涉及抱坡村土地上厂房约7633平方米。

二、指导思想和基本原则

坚持以科学发展观为指导，围绕国际性热带滨海旅游城市、国际旅游岛建设的战略目标，改善城市面貌，提升城市品位、价值和形象，维护被征收人的合法权益，在依法征收的基础上，坚持公开、公平、公正、依法、和谐征收。

三、土地补偿标准

国有土地补偿按《城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）、《国有土地上房屋征收与补偿条例》（国务院令第590号）和《国有土地上房屋征收评估办法》（建房〔2011〕77号）等相关规定，采取评估的方式给予补偿。

集体土地补偿按照《三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）文件规定执行。

四、树木和青苗等补偿标准

国有土地上涉及的树木、青苗补偿原则上执行《国有土地上房屋征收评估办法》（建房〔2011〕77号）的规定，采取评估的方式给予补偿，或参照《三亚市征收集体土地青苗补偿费和征地经费包干管理暂行办法》（三府〔2011〕208号）、《三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）规定进行补偿。对于项目启动后，违法抢种的树木，青苗一律不给予补偿。

集体土地上树木和青苗补偿按照《三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）和《三亚市征收集体土地青苗补偿费和征地经费包干管理暂行办法》（三府〔2011〕208号）文件规定，采取“就高不就低”方式进行补偿。

五、房屋装饰、地上附着物、机械设备及设备搬迁等补偿标准

国有土地上房屋装饰、地上附着物、机械设备及设备搬迁等补偿按《国有土地上房屋征收评估办法》（建房〔2011〕77号）的规定，采取评估的方式给予补偿；或参照《三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）有关规定进行补偿。涉及机械设备、材料等搬迁及搬迁损失无法评估确定价值的，可由征地工作组与被征收人共同协商搬迁补偿费，报区政府研究确定。

集体土地上房屋装饰、地上附着物等补偿按照《三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）规定执行。机械设备等特殊附着物补偿参照《国有土地上房屋征收评估办法》（建房〔2011〕77号）的规定，采取评估的方式给予补偿。涉及机械设备、材料等搬迁及搬迁损失无法评估确定价值的，可由征地工作组与被征收人共同协商搬迁及搬迁损失补偿费，报区政府研究确定。

六、房屋等建筑物补偿标准

（一）国有土地上房屋征收补偿标准

框架、混合及厂房等房屋补偿采取货币补偿，按《国有土地上房屋征收与补偿条例》（国务院令第590号）和《国有土地上房屋征收评估办法》（建房〔2011〕77号）等相关规定进行评估补偿；或参照《三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）有关规定进行补偿。

（二）集体土地上房屋征收补偿标准

集体土地上房屋补偿按照《三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）规定执行。

厂房等无补偿标准房屋参照《国有土地上房屋征收评估办法》（建房〔2011〕77号）的规定，采取评估的方式给予补偿。

七、评估机构选定和评估价格确认

（一）评估机构的选定

评估机构由被征收人推选出的代表协商选定。协商不成的，由征收实施单位组织被征收人代表从已在三亚市备案的评估机构库中随机抽取。被征收土地、房屋和附着物等价格评估时间节点为委托评估调查之日。

（二）评估价格鉴定和认证

评估价格出具后，被征收人或征收实施单位对评估结果有异议的，应当自收到评估报告之日起10日内，向评估机构申请复核；被征收人或征收实施单位对评估机构的复核结果有异议的，应当自收到复核结果之日起10日内，向三亚市房地产价格评估专家委员会申请鉴定或向三亚市价格认证中心申请价格认证。

（三）评估价格确认

评估价格鉴定或认证后，报由区政府会议确认后补偿。

八、其他补偿

（一）搬迁补助费：

以被征收人现有居住房屋或厂房的建筑面积为基数，按照每平方米18元的标准给予搬迁补助费（单次搬迁最低不少于3000元）。

（二）停产停业补偿：

被征收人属经营性用房且同时符合下列条件的，按照本方案发布前一年的月平均营业额8%的标准给予停产、停业补偿，补偿期限6个月。营业额以税务部门核准的纳税申报为准。

1、持有土地、房屋权属证书或相关证明；

2、持有工商执照且正在营业中。

以上材料被征收户应清点丈量工作完成后十日内提供给征地工作组，由工作组审核通过后制表补偿；逾期未提供的，视为放弃补偿。

九、保障措施

（一）在规定的搬迁期限内，被征收人因个人不合理原因拒不搬迁的，由吉阳区政府报市相关部门按程序办理拆迁手续后，予以强拆。

（二）执法部门对征收范围内的抢建、抢种及违章建筑依法予以打击。

（三）参与补偿、安置相关的工作人员，必须严格执行有关法律、法规、政策和本《方案》的规定，接受社会监督。对玩忽职守、滥用职权、徇私舞弊的，由其所在单位或上级主管机关给予处分。构成犯罪的，由司法机关依法追究刑事责任。

（四）对影响项目推进正常工作秩序，干扰、围攻、殴打工作人员执行公务的，由公安机关依照《中华人民共和国治安管理处罚法》进行处罚。构成犯罪的，依法追究刑事责任。

十、附则

（一）本方案自批准发布之日起施行。

（二）本方案中未尽事宜，或在项目征收补偿过程中需对本方案的有关内容进行调整的，由征收实施单位会议讨论确定。

（三）本方案由吉阳区人民政府负责解释。

三亚市吉阳区人民政府办公室
