# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书《关于“三亚市奥林匹克国际生态体育公园”-A线道路工程项目》

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

大茅村委会：

因我市的城市建设需要，市政府以《关于“三亚市奥林匹克国际生态体育公园”-A线道路工程项目土地调查有关事项的通知》（三府办〔2017〕385号）文拟征收我区大茅村委会部分集体土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约 0.7271公顷，其中土地所有权均属大茅村委会。

二、拟征收土地的用地性质为道路用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如对上述拟征收土地有关事项有异议，自本告知书下达之日起15天内以书面形式向我区申请听证。

特此告知

三亚市吉阳区人民政府
