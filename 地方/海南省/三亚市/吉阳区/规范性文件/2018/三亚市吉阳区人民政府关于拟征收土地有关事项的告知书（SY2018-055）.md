# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（SY2018-055）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区博后村委会：

因我市的城市建设需要，市政府以《关于亚龙湾旅游度假区博后村约127亩用地土地调查有关事项的通知》（三府办〔2018〕236号）等文拟征收三亚市吉阳区博后村委会农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区玫瑰谷，用地面积为8.4978公顷，涉及水田5.7861公顷、农村道路0.3497公顷、沟渠0.1994公顷、设施农用地2.1626公顷。

二、拟征收土地的规划性质为旅游建设用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出出具确认意见。

特此告知。

三亚市吉阳区人民政府

2018年8月31日
