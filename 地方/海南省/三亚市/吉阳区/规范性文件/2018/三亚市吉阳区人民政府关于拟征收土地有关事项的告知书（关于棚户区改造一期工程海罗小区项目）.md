# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（关于棚户区改造一期工程海罗小区项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

海罗村委会：

因我市的城市建设需要，市政府以《关于棚户区改造一期工程海罗小区项目土地调查有关事项的通知》（三府办〔2015〕76号）文拟征收我区海罗村委会部分集体土地及我区辖区内部分用地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约 6.8101公顷，其中土地权属情况均为海罗村委会。

二、拟征收土地的用地性质为建设用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如对上述拟征收土地有关事项有异议，自本告知书下达之日起15天内以书面形式向我区申请听证。

特此告知

三亚市吉阳区人民政府
