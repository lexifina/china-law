# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（干沟村委会预留用地道路出入口用地）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚保力房地产投资开发有限公司：

因我市的城市建设需要，市政府以《关于三亚市吉阳区干沟村委会预留用地道路出入口用地土地调查有关事项的通知》（三府办〔2018〕241号）文拟收回我区辖区内部分国有土地，现将拟收回的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约640平方米，其中土地权属均为三亚保力房地产投资开发有限公司。

二、拟征收土地的用地性质为道路用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，自本告知书下达之日起15天内以书面形式向我区申请听证。

特此告知

三亚市吉阳区人民政府
