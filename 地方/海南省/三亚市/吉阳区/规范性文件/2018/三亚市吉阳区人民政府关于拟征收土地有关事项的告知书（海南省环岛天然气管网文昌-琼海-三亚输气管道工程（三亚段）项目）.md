# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（海南省环岛天然气管网文昌-琼海-三亚输气管道工程（三亚段）项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

大茅村委会、罗蓬村委会、红花村委会、落笔村委会、南新农场、三亚市落笔洞野生动植物园有限公司、各有关单位：

因我市的城市建设需要，市政府以《关于海南省环岛天然气管网文昌-琼海-三亚输气管道工程（三亚段）项目土地调查有关事项的通知》（三府办〔2018〕209号）文拟征收我区大茅村委会、罗蓬村委会、红花村委会、落笔村委会部分集体土地及收回我区辖区内部分国有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地涉及海棠区、吉阳区、天涯区和崖州区，用地面积约2120.865亩，包括永久性建设用地、50年长期租赁用地和临时用地。其中吉阳区用地面积约471.83亩，土地权属为大茅村38.45亩，罗蓬村45.46亩，红花村60亩，落笔村75亩，南新农场3.81亩，三亚市落笔洞野生动植物园有限公司57.14亩，部队8亩、市政府182.23亩，国家1.74亩（最终面积以实际勘测面积为准）。

二、拟征收土地的用地性质为公用设施用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，自本告知书下达之日起15天内以书面形式向我区申请听证。
