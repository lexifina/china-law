# 三亚市人民政府办公室关于印发三亚市职业技能培训行动计划（2018—2021年）的通知

三亚市人民政府办公室

关于印发三亚市职业技能培训行动计划

（2018—2021年）的通知

各区人民政府，各管委会，市政府直属各单位：

《三亚市职业技能培训行动计划（2018—2021年）》已经七届市委第71次常委会和七届市政府第22次常务会议审议同意，现印发给你们，请认真贯彻执行。

三亚市人民政府办公室

2018年6月5日

（此件主动公开）

三亚市职业技能培训行动计划

（2018—2021年）

为落实《中共三亚市委 三亚市人民政府关于推动〈建设世界级滨海旅游城市行动方案〉和〈幸福民生行动计划（2017—2021年）〉落实的通知》（三发〔2018〕6号），加强技能培训，提升就业创业能力，促进居民增收，制定三亚市职业技能培训行动计划。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九大精神，紧紧围绕“一支柱两支撑”的产业发展战略，大规模开展技能培训，激励更多劳动者走技能就业、技能成才、技能致富之路，培育新型技能型劳动大军，为打造幸福三亚、促进居民增收提供人才支撑。

二、主要任务

根据《三亚市幸福民生行动计划（2017—2021年）》要求，2017—2021年五年内培训农村劳动力15000人，培训下岗失业人员2500人。其中，每年开展农村劳动力职业技能培训3000人，下岗失业人员职业技能培训500人。

同时，进一步扩大培训范围，积极开展行业技能培训，每年培训不少于5400人。其中，市科技工业信息化局科技培训3000人，市农业局新型职业农民培育200人，市商务会展局牵头家庭服务行业培训200人、电子商务行业培训500人，市民政局养老服务行业培训200人，市旅游委旅游服务人才培训500人，市文化广电出版体育局文体行业培训300人，市住房城乡建设局建筑领域行业培训300人，市卫生和计划生育委员会医疗健康行业培训200人。

三、落实措施

为扩大技能培训人群和技能培训科目，主要开展两个方面的培训，一是职业技能培训，二是行业技能培训。职业技能培训是指组织实施人社部公布的81项技能人员职业资格目录清单内的职业技能培训，培训合格后可申请职业资格许可和认定。行业技能培训是指根据行业标准及岗位需求，由行业部门合理设置培训工种，教学内容，培训课时，开展灵活多样的培训，培训工种属于职业资格目录清单内，可申请职业资格许可和认定，目录清单外的严禁组织实施职业资格许可和认定。

（一）职业技能培训

结合我市技能人才战略部署要求，按照人社部公布的81项技能人员职业资格目录清单内容，依照国家职业技能标准，大力培养适应产业发展的技能人才，全面提高劳动者职业技能水平，服务我市经济发展。

1．重点群体职业技能培训。对贫困家庭劳动力、城镇登记失业人员、农村转移就业劳动者、毕业年度高校毕业生、城乡未继续升学的应届初高中毕业生、棚户区改造居民、被征地拆迁农民等重点群体开展职业技能培训。培训工作要结合实际，根据培训对象特点，开展针对性培训。对从未参加过职业技能培训的贫困家庭劳动力、棚户区改造居民、被征地拆迁农民等群体，可结合培训需求及就业创业意愿，主要开展以专项能力、初级技能和创业培训为主的职业技能培训。对已掌握一定职业技能的，可根据其职业技能提升需求或转移就业需要，开展中级以上或其他工种的职业技能培训。培训内容要突出实际操作技能训练，并结合实际增加劳动法律法规、权益保护、求职技巧、市民文明行为规范、劳动安全等知识，着力提升技能技术水平、转移就业和创业能力，促进重点群体高效就业，稳定就业，自主创业。（责任单位：各区人民政府、育才生态区管理委员会、市人力资源社会保障局。）

2．企业职工岗位职业技能提升培训。引导用人单位建立和完善职工培训制度，适应产业升级和技术进步，针对岗位需求和职工特点，开展多层次、多样化培训。通过在岗培训、脱产培训、业务研修、技能竞赛等措施，提升在职职工适应新技术、新产业、新业态的学习能力、创新能力和发展能力。（责任单位：市人力资源社会保障局、市财政局、市国资委、市总工会。）

3．城乡居民职业技能培训。遵循培训需求与就业岗位匹配的原则，结合我市产业发展要求，依据人力资源市场岗位需求分析，鼓励和引导全市城乡劳动者参加技能培训，提升职业技能水平。定时公开职业技能培训信息和就业岗位信息，引导城乡居民根据自身实际和就业需求积极参加职业技能培训，提高培训的针对性和实用性，调动市民参加培训的积极性。（责任单位：市人力资源社会保障局、市财政局、市各有关单位。）

（二）行业技能培训

以提升就业能力为核心，以实现稳定就业为目标，结合我市产业行业发展及企业岗位要求，合理设置培训科目，开展与岗位相匹配的定向式、定岗式职业技能培训和就业技能培训，突出培训的针对性、实效性。

1．科技信息行业培训工程。围绕新兴科技产业及信息产业发展，在科技创新、科技进步，信息化建设等方面，开展各类科技与信息化培训，提高城乡居民科技应用水平。（责任单位：市科技工业信息化局。）

2．热带现代农业培训工程。围绕新农村建设需要，实施农技人才培养工程，大规模开展农村实用人才培训，组织开展生产型、经营型、技能型、服务型农村实用人才培训。（责任单位：市农业局。）

3．家政服务行业培训工程。结合我市家政服务需求，对有意愿从事家政服务行业的劳动者开展保洁、月嫂、家电维修、育婴员、保育员等技能服务或职业技能培训。（责任单位：市商务会展局、三亚质量技术监督局、市妇联。）

4．养老服务行业培训工程。依托符合条件的养老培训机构或企业，对有意愿从事养老服务行业的劳动者开展就业服务技能培训，对养老服务企业、机构在岗的养老护理工作人员开展岗位技能提升培训，对有意愿或已在养老服务行业创业的劳动者开展创业培训。（责任单位：市民政局。）

5．电子商务行业培训工程。依托各类职业培训机构及电子商务企业等资源，采取政策引导，公益性和市场化相结合的方式，有针对性地开展电子商务技能培训。（责任单位：市商务会展局、市科技工业信息化局。）

6．旅游服务行业培训工程。实施旅游人才素质提升工程，对有意在旅游服务业就业的人员开展旅游英语、餐厅服务、景区讲解、民宿经营管理等旅游服务技能培训。对旅游行业在岗人员开展经营管理人才、岗位技能提升培训，提高从业人员技能水平和职业素质。（责任单位：市旅游委。）

7．文化体育行业培训工程。结合我市文化产业发展，组织开展黎锦、黎陶等文化传承技能技艺培训。组织开展体育产业、体育服务从业人员职业技能培训，重点培育体育产业发展急需和从事高危险性体育活动的技能人才，如游泳、潜水等职业技能培训，提高从业人员技能水平和职业素质，促进体育事业和体育产业发展。（责任单位：市文化广电出版体育局 。）

8．建筑领域行业培训工程。组织建筑安装领域从业人员开展建筑安装施工、电梯安装维修、空调安装维修等职业技能培训，提升建筑施工安装技术水平。（责任单位：市住房城乡建设局、三亚质量技术监督局。）

9．医疗健康行业培训工程。结合我市医疗卫生事业发展的要求，开展健康咨询、医疗保健、护理服务等技能服务培训，提高从业人员服务水平。（责任单位：市卫生和计划生育委员会。）

10．新业态专项培训工程。结合我市产业发展和新兴业态，紧跟时代发展趋势，适时组织开展灵活多样的职业培训，服务三亚市新兴产业和新兴业态的发展。（责任单位：市各有关单位。）

（三）加强培训监管

1．加强技能培训机构建设。一是发挥三亚市内各大院校的基础作用，利用师资、实训场地以及设备资源优势，提供各类技能培训服务。二是发挥民办职业培训机构的积极作用，结合三亚市产业发展及企业岗位需求，指导培训机构有针对性的设置培训科目，优化教学课程，提升培训质量。三是支持各大院校、职业培训机构与企业合作，广泛开展订单、定向和定岗培训。四是支持和鼓励省内外优质的办学机构参与我市技能培训工作。五是突出企业培训主体作用，鼓励和支持有条件的企业利用自身资源建立技能大师工作室，自主开展在岗职工培训，高技能人才培养。开展企业新型学徒制试点工作。六是加快推进公共实训基地建设及高技能人才培训基地建设，提供公共实训及高技能人才培养服务工作。（责任单位：市教育局、市教育工委、市人力资源社会保障局、市民政局、市财政局、市国资委、市总工会。）

2．强化培训质量监督。一是完善承担政府培训任务的培训机构管理措施，严格师资、设备、场地和培训教学经验等基本条件，规范和引导社会力量开展培训服务。二是加强培训过程的监督，落实开班申请、过程检查和结业审核三项制度。三是建立动态管理机制，对培训质量低劣尤其是存在骗取、套取培训资金的培训机构，取消其培训资格，追回被骗取、套取的补贴资金。四是探索建立第三方监督机制，委托有资质的社会中介组织对培训机构的培训质量及资金使用情况进行评估。（责任单位：市人力资源社会保障局、市各有关单位。）

（四）提供就业服务

1．利用“就业援助月”、“春风行动”、“民营企业招聘周”等公共就业服务专项活动，积极搭建供需平台，结合农村劳动力就业意愿和培训后掌握的岗位技能，有针对性筛选企业需求岗位，深入基层开展就业专场招聘会，为农村劳动力提供就业岗位，职业介绍，创业服务，政策宣传等就业服务，把公共就业服务送到区、社区、村、家庭中去，切实促进农村劳动力转移就业。（责任单位：市人力资源社会保障局、市科技工业信息化局、共青团三亚市委、市总工会、市妇联、各区人民政府、育才生态区管理委员会。）

2．建立完善村（居）人力资源服务平台。各区人民政府、育才生态区管理委员会要加强基层就业服务队伍建设，明确专人负责就业创业工作，加强就业创业政策业务培训，为城乡劳动者提供优质高效的就业创业服务。要加强就业岗位信息的宣传，村（居）委会要开设就业信息专栏，把就业创业政策，就业岗位信息送到村（居）委会和村（居）民家中，全方位、常态化、有效性的提供就业服务。（责任单位：各区人民政府、育才生态区管理委员会。）

3．整合人力资源市场供求平台。充分发挥职业介绍机构、劳务派遣机构、职业培训机构的作用，多渠道提供人力资源服务。鼓励和支持省内外优质的人力资源服务机构在我市设立分支机构，多渠道开展就业服务。对免费介绍农村劳动力和城镇登记失业人员到企业就业的经营性人力资源服务机构，符合条件的，按照《海南省就业补助资金管理办法》，给予一次性职业介绍补贴。（责任单位：市人力资源社会保障局、各区人民政府、育才生态区管理委员会、市财政局。）

四、资金扶持

（一）落实就业补助资金职业培训补贴政策。根据就业补助资金职业培训补贴的有关规定，对贫困家庭成员（指建档立卡贫困家庭、城乡低保家庭、城镇零就业家庭，下同）、毕业学年和毕业年度高校毕业生（含技师学院高级工班、预备技师班和特殊教育院校职业教育类毕业生，下同）、城乡未继续升学的应届初高中毕业生、农村转移就业劳动者、城镇登记失业人员、随军家属（经军队师（旅）级以上政治工作部门批准并办理了随军手续的现役军人配偶，下同）、退役大学毕业生士兵（海南籍或入伍地为海南的退役大学生毕业生士兵，下同）（以下简称重点人员），自费参加职业技能培训，培训后取得职业资格证书、专项能力证书或创业培训合格证书，可依据相关规定给予一定标准的职业培训补贴，补贴资金从就业补助资金中支出。（责任单位：市人力资源社会保障局、市财政局。）

（二）落实失业保险基金技能提升补贴政策。根据失业保险基金技能培训补贴的有关规定，对符合条件的企业在职职工参加职业技能培训且取得职业资格证书或职业技能等级证书的，按照初级（五级）补贴800元，中级（四级）补贴1300元，高级（三级）补贴1800元。补贴资金从失业保险基金中支出。（责任单位：市人力资源社会保障局、市财政局。）

（三）建立城乡居民职业技能培训补贴政策。为激励广大市民积极参加职业技能培训，提高职业技能水平，为市民高质量就业创造条件，对无法享受就业补助资金、失业保险基金给予的职业培训补贴和技能提升补贴的劳动年龄段内的三亚市户籍市民，自费参加职业技能培训，取得初级、中级和高级职业资格证书的，参照失业保险基金技能提升补贴标准，按照初级（五级）补贴800元，中级（四级）补贴1300元，高级（三级）补贴1800元。补贴资金从市财政一般预算中支出。（责任单位：市人力资源社会保障局、市财政局。）

（四）完善职业技能培训生活补贴政策。为鼓励生活困难人员积极参加培训，提高职业技能水平和就业创业质量，对贫困家庭成员（指建档立卡贫困家庭、城乡低保家庭、城镇零就业家庭）、农村转移就业劳动者，城镇登记失业人员参加职业技能培训的，给予培训生活补贴。生活补贴标准按每人每天50元计算，以实际参加的培训时间为准，最高不得超过650元。补贴资金从市财政一般预算中支出。（责任单位：市人力资源社会保障局、市财政局。）

（五）建立区级财政资金支持培训就业政策。各区人民政府（育才生态区管理委员会）要加大区级财政对就业培训工作的支持力度，制定完善配套的职业培训和就业扶持政策，多渠道实施技能培训，鼓励外出就业，全面促进居民增收。（责任单位：各区人民政府、育才生态区管理委员会。）

（六）建立行业技能培训支持政策。行业培训是职业技能培训的重要组成部分，各级财政要给予资金支持，为行业培训提供必要的条件。要加强培训资金的监管，保障培训资金安全有效使用。（责任单位：各行业主管部门、市财政局。）

五、组织保障

（一）加强组织领导。建立由市人民政府统筹领导，市人力资源部门牵头协调，各相关部门共同参与的职业技能培训联动机制和共商机制。市人力资源社会保障局负责制订职业技能培训计划、业务指导、监督检查；市科技工业信息化局负责科技培训；农业部门负责农业生产技能培训；商务部门负责牵头家政服务、电子商务等技能培训；民政部门负责养老护理服务等技能培训； 旅游部门负责牵头旅游行业、酒店服务等技能培训；文化部门负责文化传承、体育指导等技能培训；住建部门负责施工建设、房屋安装等技能培训；卫计部门负责医疗健康等技能培训；市交通、海洋、水务、园林、安监、质监等部门要积极指导本行业加强技能培训工作；各级工会、共青团、妇联等组织要在各自职责范围内开展技能培训；财政部门负责按照政府批准的计划落实资金安排；宣传部门负责职业技能培训、就业创业、居民增收的宣传工作。各区（育才生态区管理委员会）负责区级职业技能培训工作，确保政策落实到位。各区（育才生态区管理委员会）、市各有关部门要充分认识职业技能培训工作的重要意义，摆上重要位置，各司其职，密切配合，共同推进。

（二）做好政策宣传。宣传部门要利用各类新闻媒体，广泛宣传职业技能培训的重要意义和政策措施，鼓励引导市民积极参加职业技能培训，提高职业技能水平，为广大市民就业创业创造条件。

（三）抓好措施落实。各区（育才生态区管理委员会）、市各有关部门要结合实际，研究制定具体的工作计划和措施，确保各项工作落到实处。各单位每年3月初要将年度技能培训工作计划报市人力资源社会保障局，由市人力资源社会保障局汇总报市政府，列入单位绩效考核内容。
