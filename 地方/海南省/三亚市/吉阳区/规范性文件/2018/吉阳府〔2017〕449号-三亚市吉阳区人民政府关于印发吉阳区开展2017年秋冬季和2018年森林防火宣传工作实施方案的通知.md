# 三亚市吉阳区人民政府关于印发吉阳区开展2017年秋冬季和2018年森林防火宣传工作实施方案的通知

吉阳府〔2017〕449号

三亚市吉阳区人民政府

关于印发吉阳区开展2017年秋冬季和2018年森林防火宣传工作实施方案的通知

区各相关部门、村（居）委会：

《吉阳区开展2017年秋冬季和2018年森林防火宣传工作实施方案》已经区政府同意，现印发给你们，请认真组织实施。

三亚市吉阳区人民政府

2017年12月21日

（此件主动公开）

吉阳区开展2017年秋冬季和2018年森林

防火宣传工作实施方案

为进一步加强森林防火宣传工作，切实提高全民森林防火意识，最大限度地预防森林火灾的发生，做到“森林防火、人人有责”。结合我区森林防火实际，组织开展森林防火宣传月活动，特制定本方案。

一、指导思想

为全面贯彻落实党的十九大精神，以习近平新时代中国特色社会主义思想为指导，以树立和践行绿水青山就是金山银山为理念，紧紧围绕建设国际旅游岛、建设生态文明、构建和谐社会为主题，以确保人民生命财产和森林资源安全、社会稳定为中心，坚持“预防为主、积极消灭”的森林防火工作方针，严格执行《森林防火条例》和《海南省森林防火条例》，全面贯彻落实国务院、国家森林防火指挥部和省、市有关森林防火工作要求，始终把森林防火宣传工作贯穿森林防火工作的全过程，坚持以人为本，突出宣传重点，创新宣传方式，深入组织开展多渠道、多样式、多角度、大力度的森林防火宣传工作。

二、领导机构

成立吉阳区森林防火宣传工作领导小组。

组 长：蔡曜泽（区人民政府副区长）

副组长：梁 浩（区农林局局长）

成 员：彭海光（区农林局副局长）

何志林（区农林局科员）

高 宁（区农林局职员）

蒲向武（区农林局护林员）

领导小组下设办公室，办公室设在区农林局，梁浩兼任办公室主任，办公室组成人员从护林员队伍中抽调，具体负责森林防火宣传的一切日常事务工作。

三、任务目标

通过开展森林防火宣传，提高全社会参与森林防火工作的积极性和主动性，做到森林防火全民参与，通过全方位、深层次的宣传，使森林防火各项法律法规、制度深入民心，提高林区群众规范、安全用火意识，确保不发生重大以上森林火灾和人员伤亡事故，努力开创森林防火宣传工作的新局面。

四、宣传内容

《中华人民共和国森林法》、国务院颁布的《森林防火条例》、省政府颁布的《海南经济特区林地管理条例》以及森林防火 “四个一律”、“四不放过”等法律法规、制度规定，预防和扑救森林火灾的基本常识，处罚违章用火及森林火灾典型案例警示宣传。

五、宣传任务

（一）超前谋划，深入宣传。各村（居）委会要结合当地实际，尽快召开一次森林防火工作会议，安排部署森林防火工作。区森林防火部门组织好一次森林防火实战演练，检验森林防火指挥员、森林消防专业队员应急实战能力。按照三亚市宣传设施的标准，及时刷新防火宣传墙（牌），开设森林防火宣传栏，在林内重点路口设置大型森林防火宣传墙，营造森林防火浓厚氛围。

（二）集中时间，大力宣传。区森林防火部门要充分利用宣传月活动，至少组织1辆防火宣传车，不间断深入到森林防火重点街道、社区、农村和森林景点、林地耕作点等进行巡回宣传。组织护林员、社会志愿者进村入户进行宣传教育，重点宣传野外火源管理的相关规定，转变传统的烧荒、烧田坎等用火习惯，同时积极倡导通过鲜花、诗赋、信函、植树等文明环保的祭扫形式，减少火灾隐患。

（三）抓住典型，反复宣传。区森林防火部门对发生的重大森林火灾或有较大影响的森林火灾，及时制作成典型案例进行宣传，主动与新闻媒体配合，通过广播电视台制作播出森林防火公益广告和森林防火警示教育片等方式，警示教育群众安全用火，严防森林火灾发生。

（四）创新形式，重点宣传。一是教育部门组织林区中小学校上一堂防火课，教育学生不上山玩火、不在野外点火，发现火情要及时报告教师、学校、森林防火巡护人员或拨打火灾报警电话（119）等。二是区森林防火部门要利用互联网等现代手段，在相关网站设立森林防火专题窗口，与林区居民、旅行社进行有效互动。三是组织青年志愿者服务队，安排志愿者走上街头、风景区入口散发传单，进行森林防火知识宣传，并组织到林区边缘清理林下易燃物等活动，充分发挥志愿者作用。

六、工作要求

（一）加强领导，科学筹划。各村（居）委会要高度重视森林防火宣传教育工作，主要领导亲自部署，分管领导亲自组织，认真谋划部署，科学组织实施，使森林防火宣传教育工作贯穿于森林防火工作的始终，达到经常化、规范化、制度化。

（二）精心组织，制定方案。各村（居）委会要结合实际，认真制定切实可行的森林防火宣传工作方案，明确工作重点，细化工作措施，落实工作任务，把握宣传的政策、时机和节奏，分工负责、分级实施。

（三）勇于创新，注重实效。要充分利用电子屏幕、户外视频、手机短信，借助微博等新兴媒介，广泛宣传，充分调动广大人民群众参与森林消防宣传的积极性，努力扩大覆盖面和社会效果。

（四）督导检查，狠抓落实。区森林防火部门要切实加强森林防火宣传工作的督导检查，定期对宣传月活动各项内容的开展情况进行检查，及时查漏补缺，确保宣传活动取得实效。
