# 三亚市吉阳区人民政府关于对吉阳区下洋田第二片区棚户区改造项目征收补偿安置方案补充说明的通知

吉阳府〔2018〕42号

三亚市吉阳区人民政府

关于对吉阳区下洋田第二片区棚户区改造项目

征收补偿安置方案补充说明的通知

区各有关单位：

《三亚市吉阳区人民政府关于印发三亚市吉阳区下洋田第二片区棚户区改造项目征收补偿安置方案的通知》（吉阳府〔2017〕365号）下发后，在文件贯彻落实中陆续收到一些情况反映，经区政府研究，现对该文件做如下补充说明：

一、文件中第五条第一款“货币补偿”，以被征收房屋的合法建筑面积为基数，按照安置房屋的市场评估价值补偿。即：货币补偿额=被征收房屋合法建筑面积×安置房市场评估单价。

二、文件中第五条第三款“货币补偿与产权调换相结合”，产权调换部分，已被征收房屋的合法套内面积调换安置房屋（套内面积）；货币补偿部分，以征收房屋的合法套内面积扣减产权调换部分后剩余套内面积为基数，按照安置房屋的市场评估价值补偿。即：货币补偿额=被征收房屋扣减产权调换部分后剩余合法套内面积×安置房市场评估单价。

三、文件中第七条第二款“临时过渡安置费”，以被征收房屋的合法套内面积作为确定临时过渡安置费的发放标准。
