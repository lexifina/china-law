# 三亚市吉阳区人民政府关于对2018年省政协七届一次会议第0199号建议的会办意见

吉阳府函〔2018〕468号

三亚市吉阳区人民政府

关于对2018年省政协七届一次会议

第0199号建议的会办意见

市公安局交警支队：

张先云委员在政协海南省第七届委员会第一次会议提出的第0199号“关于加强共享单车停放管理的建议”收悉，现将我区会办情况答复如下：

一、我区已建成368个网格路段，每个网格至少配备4名网格员参与管理。网格员由城市管理执法人员、交警执法人员、环卫清扫保洁员等部门人员组成，在同一网格内履行各自的职能，形成管理合力，最大程度地营造整洁有序的市容市貌。

二、自共享单车进驻我区以来，我区根据共享单车“随骑随停”的停放特点，加强对其乱停乱放的管控，积极引导群众文明停放，并针对群众停放习惯，科学合理规划单车停放区。今年以来，我区共规范引导共享单车停放3000余辆次，在榆亚路、迎宾路、凤凰路等主次干道，共规划非机动车泊位10689个，基本上做到了“一车一位”。

三亚市吉阳区人民政府
