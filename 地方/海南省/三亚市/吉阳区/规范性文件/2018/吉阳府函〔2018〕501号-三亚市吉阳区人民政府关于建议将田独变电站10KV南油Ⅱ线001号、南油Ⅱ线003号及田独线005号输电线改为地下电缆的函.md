# 三亚市吉阳区人民政府关于建议将田独变电站10KV南油Ⅱ线001号、南油Ⅱ线003号及田独线005号输电线改为地下电缆的函

吉阳府函〔2018〕501号

三亚市吉阳区人民政府

关于建议将田独变电站10KV南油Ⅱ线001号、南油Ⅱ线003号及田独线005号输电线

改为地下电缆的函

海南电网有限责任公司三亚供电局：

根据三亚市吉阳区第二届人民代表大会第五次会议建议《关于将高空高压输电线路改为地下电缆的建议》（第16号），吉阳区红土坎村人大代表向我区提出贵局在红土坎村安装的10KV南油Ⅱ线001号、南油Ⅱ线003号及田独线005号高压电缆距地高度约为5米，横跨红土坎村8户村民楼房上空，距离村民房屋顶极近，极易引发用电安全问题，影响村民的居住安全，而且因高压电的存在导致因人口增加的村民无法改造住房，造成现居住环境堪忧，群众反映强烈。为解决群众居住、用电安全问题及人大代表的意见，及时为民解忧，现请贵局充分考虑我区提出的建议：

将10KV南油Ⅱ线001号、南油Ⅱ线003号及田独线005高压线改为铺设地下的电缆，并请贵局于7月10日前将研究意见反馈至我区。

此函

附件：《关于将高空高压输电线路改为地下电缆的建议》（第

16号）
