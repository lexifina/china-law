# 三亚市吉阳区人民政府关于对政协三亚市第七届委员会第三次会议第339号提案的会办意见

吉阳府函〔2018〕513号

三亚市吉阳区人民政府

关于对政协三亚市第七届委员会第三次

会议第339号提案的会办意见

市林业局：

李毅委员提出的“关于建设南丁山市民森林休闲公园的提案”收悉。根据要求，由我区协助贵单位办理此提案，经研究，现提出涉及我区工作的答复意见。

一、我区支持建设南丁山市民森林休闲公园，在规范建设中，要本着“生态、便民、求实、发展”的原则，坚持走“节约型、生态型、功能完善型”的发展道路，不断满足人民对美好生活的向往，丰富广大群众健康休闲的内涵，实现全民共享生态文明建设的绿色福利。

二、建设公园涉及的相关报建手续及赔偿问题应严格按照相关法律法规执行。

以上意见供答复委员时参考。

三亚市吉阳区人民政府

2018年6月26日
