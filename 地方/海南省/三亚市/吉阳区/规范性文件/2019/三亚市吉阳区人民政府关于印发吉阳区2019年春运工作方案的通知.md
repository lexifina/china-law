# 三亚市吉阳区人民政府关于印发吉阳区2019年春运工作方案的通知

三亚市吉阳区人民政府

关于印发吉阳区2019年春运工作方案的通知

亚龙湾管委会，三亚市火车站，各相关单位：

《吉阳区2019年春运工作方案》已经区政府同意，现印发给你们，请认真贯彻落实。

三亚市吉阳区人民政府

2019年1月31日

（此件主动公开）

吉阳区2019年春运工作方案

2019年春运工作从1月21日开始至3月1日结束，共计40天。根据《海南省2019年春运工作总体方案》《2019年三亚市春运工作方案》要求，为全力做好我区2019年春运有关工作，满足广大人民群众出行需要，确保春运期间我区安全形势稳定，现结合我区实际，特制定2019年吉阳区春运安全工作方案。

一、春运工作的重要意义

春运工作事关国计民生和社会稳定，事关群众切身利益，是一项重要的民生工程。做好春运交通保障工作，是解决人民群众最关心、最直接、最现实的利益问题，是推动我区科学发展的重要举措。春运期间，我区处于旅游高峰期，人流、车流、物流徒增，运输矛盾突出，春运工作任务复杂艰巨、影响范围广、涉及部门多，各单位领导要深化认识、高度重视、集中力量、周密谋划、加强协调，遵循“以人为主、安全第一、以客为主、优质服务”原则，牢固树立“四个意识”，坚决做到“两个维护”，认真抓好春运安全工作。各单位要对春运工作所需的人力、物力、经费等予以重点保证，同时要尽最大努力为春运一线干部职工提供良好的工作和生活条件，保证他们能全身心投入春运工作。

三、落实工作责任

区委宣传部：负责全区春运宣传工作，协调新闻媒体对春运进行采访报道，营造良好的春运舆论氛围。

区委政法委：负责全区春运组织协调，承担区政府和春运领导小组交办日常工作，协调公安和交警维护亚龙湾区域、三亚火车站秩序，确保春运期间全区安全顺畅完成任务。

区交通运输和安全生产监督局：协调春运工作有关运力问题，协调做好运力投放保障工作，确保春运安全有序畅通。负责协调落实区有关部门安全生产责任制，加强交通安全事故和责任督查，及时统计报送道路、公交、出租车运输信息。

亚龙湾管委会：制定春节期间亚龙湾交通疏导方案，配合吉阳交警大队做好春节期间亚龙湾交通疏导工作，加强亚龙湾内停车场的管理。

三亚火车站：制定三亚火车站和亚龙湾火车站春运保障方案，确保春运期间两个火车站的安全顺畅，配合吉阳公安分局做好春运期间安全保障工作。

市公安局吉阳分局：做好三亚火车站、亚龙湾火车站春运期间的安全保障工作及周边地区安全隐患排查工作。

市交警支队吉阳大队：负责道路运输交通安全秩序管理，加大源头和路面交通安全管控，严格落实反超载、反超限、反超速措施，严禁驾驶证记满12分的驾驶人参加春运，严肃查处无证驾驶、酒后驾驶、疲劳驾驶、超速超载行驶等违章行为，协调优化高速公路封闭办法，落实应急职责。加大道路主干线交通事故多发和易堵路段以及亚龙湾、三亚火车站、大东海景区等重点场所道路的指挥疏导力度。

区城市管理局：负责做好对三轮车、摩托车非法营运违法行为的行政处罚；加大对亚龙湾、大东海、三亚火车站等重点场所附近道路小摊小贩的整治力度。

区旅游文体局：负责旅游客流组织，积极与运输部门和企业衔接，配合做好客流的运输组织工作，配合协调做好旅客滞留的住宿安置工作。

区财政局：负责落实春运应急工作经费保障。

区卫生和计生局：负责加强对春运有关场所和工具的卫生监督与指导，有效预防监控各类传染病的传播，发生突发事件时及时协调提供卫生救护支持。

区海洋渔业水务局：负责沿海海域的水上安全监督、海上搜救协调和水上安全通信管理等监督、应急和保障工作。

四、强化安全监管

（一）全面落实安全生产责任。各单位要始终坚持“安全第一、预防为主、综合治理”的方针，严格落实春运安全生产的各项要求，切实强化运输安全“党政同责、一岗双责、齐抓共管、失职追责”的总体要求。相关单位狠抓企业主体责任和部门监管及各级领导责任落实，建立一级抓一级、层层抓落实的安全责任体系，严格落实春运安全生产各项要求，把安全生产责任落实到岗位、落实到人员、落实到具体环节，坚决遏制重特大事故发生。

（二）全面排査安全隐患。春运开始前，各成员单位根据职责分工加强对亚龙湾、大东海、三亚火车站等重点部位场所的准备工作开展督查。结合国家和省市的相关检查督查，分别组织开展春运安全大检查，对运输企业、运输设备、管理制度、从业人员、服务质量等方面隐患和缺陷全面开展排查，严禁技术状况不达标的设施设备及运输装备投入运营，严禁逾期未检验、未报废的客运车辆和未审验、未换证的客运车辆和记满12分的营运驾驶人参加春运。对重大隐患要建立台账，逐级挂牌督办，严格整治，限期整改，确保各项安全措施落实到位。

（三）狠抓春运治安管理。公安分局要对线路及周边地区存在的影响社会治安秩序的突出问题开展针对性清理整治，要认真做好反恐防暴各项准备，强化对治安复杂地区的巡逻和控制，最大限度的把警力投入到亚龙湾、大东海、三亚火车站等重点部位，配合市运管部门打击亚龙湾、大东海、三亚火车站等重点区域拉客仔，切实加大社会治安秩序维护和掌控力度。

五、完善应急措施

各单位要根据实际和可能出现如大面积旅客滞留、交通事故、群体性事件等突发情况，制定和完善责任主体明确、可操作性强的春运应急预案，形成准备充分、反应快速、应对准确、处置果断的应急机制。

要做好应急物资准备工作。有关部门要做好各类应急车辆、应急食物、应急药品、应急油料等物资的准备工作，在事故多发路段，提前备好应急物资、大型清障设备，组织好应急队伍，保证能及时调用，快速恢复交通通行条件。一旦发生突发事件，要立即启动相应级别的应急预案，有关部门领导要第一事件抵达现场，采取有力举措及时、有效地控制事态发展，降低事件造成的影响，尤其要做好应对出现旅客大面积滞留的疏导安置工作。道路发生旅客、车辆大面积滞留拥堵或发生突发事件时，交通、交警部门领导要第一时间到现场处置。区春运领导小组成员必要时到现场处置，区春运办做好指挥协调工作。

六、夯实春运保障基础

（一）建立信息共享协作机制。各单位要密切配合，相互协作。区政府和市运管处要建立沟通渠道，相互通报客流量、运力较大变化、调整的情况，及时采取联动对应措施。运输部门之间要建立协作机制，最大限度地发挥综合运输能力。公安和交通运输部门要建立保障道路畅通的联动机制，做好春运期间高速公路防拥堵报畅通预案，发生恶劣天气时加强车辆疏导，采取措施尽量减少道路封闭，保证道路通行。相邻地区之间要建立联动机制，信息互通，措施联动，保证干线公路通畅。

（二）维护道路安全畅通。交警部门要会同交通运输部门加强路网运行监测和交通秩序维护，加大道路主干线交通事故多发和易堵路段以及亚龙湾、大东海、三亚火车站等重点场所附近道路的指挥疏导力度，及时处理交通事故和突发事件；严肃查处超速、超员、超载、疲劳驾驶等各类交通违法行为，保障春运道路安全畅通。

（三）加强医疗卫生防控。卫生部门要加强春运期间重点传染病风险评估监测，及时通报重点传染病风险隐患。

七、提升服务水平

（一）加大宣传引导力度。相关部门要通过各种新闻媒介，及时发布春运有关的政策措施、运力调整和安排等重要信息，让广大旅客及时了解春运相关情况。要充分发挥媒体监督作用，积极关注媒体报道反映的问题，努力加以改进，对群众反映较为强烈的热点问题，要及时回应，做好解释，让人民群众更加理解和支持春运工作。广泛宣传春运一线干部职工无私奉献、辛勤工作的先进事迹，弘扬爱岗敬业的精神，营造良好的舆论氛围，促进春运工作顺利开展。

（二）加强春运值班执勤。值班室、值班领导、当班人员的通讯设备必须保持24小时在线，确保信息畅通、及时处置问题。对于旅客大面积滞留、车辆拥堵及其他紧急情况，春运工作有关领导要第一时间到现场处置，公安交警、安全生产等部门要按相关规定处置问题。

八、总结工作

春运结束后，各部门和有关单位要对春运工作进行总结，于3月6日前将总结材料报区春运办。
