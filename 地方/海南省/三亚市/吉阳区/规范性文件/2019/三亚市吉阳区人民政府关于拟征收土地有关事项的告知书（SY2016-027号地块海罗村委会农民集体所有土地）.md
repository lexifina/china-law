# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书(SY2016-027号地块海罗村委会农民集体所有土地）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区海罗村委会：

因我市的城市建设需要，市政府以《关于河东区海罗村149.8亩用地土地调查有关事项的通知》（三府办〔2014〕125号）文拟征收三亚市吉阳区海罗村委会农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区海罗村辖区内，用地面积为5.6695公顷，其中：村庄0.9999公顷、果园1.5424公顷、农村道路0.0303公顷、设施农用地0.2629公顷、水田1.6951公顷、有林地1.1389公顷。

二、拟征收土地的用地性质为艺术传媒用地、旅馆用地、其他商务设施用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你村委会对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出据确认意见。

特此告知。

三亚市吉阳区人民政府

2019年1月23日
