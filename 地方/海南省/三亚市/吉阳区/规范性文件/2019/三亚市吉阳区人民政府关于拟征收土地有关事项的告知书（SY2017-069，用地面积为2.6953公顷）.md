# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（SY2017-069，用地面积为2.6953公顷）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区海罗村委会：

因我市的城市建设需要，市政府以《关于河东区海罗村内166亩用地土地调查有关事项的通知》（三府办〔2014〕57号）等文拟征收三亚市吉阳区海罗村委会集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市丰兴隆控规B-12-2地块，用地面积为2.6953公顷。

二、拟征收土地的规划性质为二类居住兼容旅馆业用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2019年10月18日
