# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（SY2018-070，用地面积为0.5351公顷）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区苗圃场：

因我市的城市建设需要，市政府以《关于田独高新技术产业园报社东路北段延伸建设项目用地土地调查有关问题的通知》（三府办〔2011〕8号）等文拟征收三亚市吉阳区苗圃场农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区报社东路，用地面积为0.5351公顷。

二、拟征收土地的用地性质为城市道路用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你单位对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2019年9月24日
