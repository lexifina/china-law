# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（SY2018-074号、用地面积为2.5448公顷、主送经济场）2019无文号280

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区经济场：

根据市政府《关于吉阳区高新技术产业园高新大道西北侧72474平方米储备用地土地调查通知有关事项的通知》（三府办〔2015〕26号），政府拟征收三亚市吉阳区农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区内，用地面积为2.5448公顷，涉及果园2.4772公顷、农村道路0.0676公顷。

二、拟征收土地的用地性质为一类工业用地、规划路及防护绿地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你单位对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2019年7月3日
