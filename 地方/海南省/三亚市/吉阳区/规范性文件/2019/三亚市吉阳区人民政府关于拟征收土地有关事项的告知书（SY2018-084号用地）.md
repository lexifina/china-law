# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（SY2018-084号用地）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区抱坡村委会：

因我市的城市建设需要，市政府以《关于三亚市吉阳区抱坡新城片区棚户区改造项目土地调查有关事项的通知》（三府办〔2017〕235号）等文拟征收三亚市吉阳区抱坡村委会集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区，用地面积为7.3625公顷，涉及水田4.7907公顷、旱地0.7381公顷、可调整有林地0.2131公顷、其他园地0.5665公顷、农村道路0.2475公顷、坑塘水面0.2505公顷、设施农用地0.1076公顷、建制镇0.0091公顷、村庄 0.3067公顷、河流水面0.1327公顷。

二、拟征收土地的规划性质为体育场馆用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出据确认意见。

特此告知。

三亚市吉阳区人民政府

2019年4月9日
