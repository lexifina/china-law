# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（SY2019-001号用地）

2019无文号125

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区新村居委会：

因我市的城市建设需要，市政府以《关于高新技术产业园控规C2-1-2地块用地土地调查有关事项的通知》（三府办〔2013〕340号）等文拟征收三亚市吉阳区新村居委会集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市高新技术产业园C2-1-2地块，用地面积为0.2118公顷，涉及水田0.0032公顷、其他园地0.0580公顷、村庄0.1122公顷 、坑塘水面0.0384公顷。

二、拟征收土地的规划性质为行政办公用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出据确认意见。

特此告知。

三亚市吉阳区人民政府

2019年4月2日
