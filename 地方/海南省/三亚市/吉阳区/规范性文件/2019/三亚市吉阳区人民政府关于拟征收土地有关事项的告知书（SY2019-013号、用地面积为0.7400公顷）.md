# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（SY2019-013号、用地面积为0.7400公顷）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区大茅村委员会：

因我市的城市建设需要，市政府以《“三亚市奥林匹克国际生态体育公园”A线道路工程项目土地调查有关事项的通知》（三府办〔2017〕385号）等文拟征收三亚市吉阳区大茅村委员会农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区内，用地面积为0.7400公顷。

二、拟征收土地的用地性质为规划路。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你单位对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2019年7月30日
