# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（SY2019-015号用地）

2019无文号127

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区东岸村委会：

因我市的城市建设需要，市政府以《关于三亚市东岸村棚户区改造项目土地调查有关事项的通知》（三府办〔2016〕222号）等文拟征收三亚市吉阳区东岸村委员会农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区，用地面积为3.1477公顷，均为建设用地。

二、拟征收土地的用地性质为东岸总部经济区。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出据确认意见。

特此告知。

三亚市吉阳区人民政府

2019年4月2日
