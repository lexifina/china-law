# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（SY2019-032号用地）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区新村社区：

因我市的城市建设需要，市政府以《关于三亚市高新技术产业园控制性详细规划A4-2地块用地土地调查有关事项的通知》（三府办〔2014〕297号）等文拟征收三亚市吉阳区新村社区农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市高新技术产业园控规A4-2地块内，用地面积为1.0329公顷，涉及果园1.0307公顷、公路用地0.0022公顷。

二、拟征收土地的用地性质为特殊用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你社区对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出据确认意见。

特此告知。

三亚市吉阳区人民政府

2019年4月25日
