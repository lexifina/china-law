# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（SY2019-106，用地面积为0.6260公顷）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区新村社区居民委员会：

因我市的城市建设需要，市政府以《关于海榆东线（国道G223）亚龙湾至吉阳转盘公路改造工程项目土地调查有关事项的通知》（三府办〔2017〕143号）等文拟征收三亚市吉阳区新村农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区内，用地面积为0.6260公顷。

二、拟征收土地的用地性质为公路用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2019年10月14日
