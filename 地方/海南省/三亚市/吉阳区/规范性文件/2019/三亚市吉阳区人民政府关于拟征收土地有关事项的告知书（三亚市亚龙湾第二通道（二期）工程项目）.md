# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（三亚市亚龙湾第二通道（二期）工程项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

干沟村委会，榆红村委会，海罗村委会，临春居委会，三亚南新实业集团有限公司（南新农场），三亚警备区，三亚军分区后勤部营房科（榆红医院门诊），广州军区房地产管理局三亚房地产管理处：

因我市的城市建设需要，市政府以《关于三亚市亚龙湾第二通道（二期）工程项目土地调查有关事项的通知》（三府办〔2019〕188号）文拟征收我区干沟、榆红、海罗村委会和临春社区部分集体土地及我区辖区内部分国有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约8.7934公顷，其中土地权属情况为榆红村委会约2.9806公顷、临春居委会约0.8293公顷、海罗村委会约0.0982公顷、干沟与海罗村待处理地约1.2775公顷、干沟与榆红村约0.7837公顷、南新农场约1.6797公顷、三亚警备区约0.0023公顷、三亚军分区后勤部营房科（榆红医院门诊）约1.0058公顷、广州军区房地产管理局三亚房地产管理处约0.1363公顷。

二、拟征收土地的用地性质为公路用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩

余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，自本告知书下达之日起15天内以书面形式向我区申请听证。

三亚市吉阳区人民政府

2019年10月11日
