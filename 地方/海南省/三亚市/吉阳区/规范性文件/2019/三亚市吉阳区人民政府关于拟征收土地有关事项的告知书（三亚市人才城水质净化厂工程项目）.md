# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（三亚市人才城水质净化厂工程项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

田独村委会：

因我市的城市建设需要，市政府以《关于三亚市人才城水质净化厂工程项目土地调查有关事项的通知》（三府办〔2019〕64号）拟征收我区田独村委会部分集体土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约1.5488公顷（其中水田约1.0155公顷、其他园地约0.1177公顷、公路用地约0.4156公顷）。

二、拟征收土地的用地性质为公共管理和公共服务用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2019年5月6日
