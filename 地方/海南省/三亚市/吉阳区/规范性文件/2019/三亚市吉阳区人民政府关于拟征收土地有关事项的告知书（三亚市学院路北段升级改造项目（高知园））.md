# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（三亚市学院路北段升级改造项目（高知园））

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

海南落笔洞投资有限公司：

因我市的城市建设需要，市政府以《关于三亚市学院路北段升级改造项目（高知园）土地调查有关事项的通知》（三府办〔2019〕20号）文拟征收我区三亚市热带植物园、中国热带植物园、植物园部分国有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区辖区内，用地面积约4079平方米。其土地权属情况为三亚市热带植物园国有土地约3795平方米、中国热带植物园国有土地约99平方米和植物园国有土地约185平方米。

二、拟征收土地的用地性质为市政道路建设用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，自本告知书下达之日起15天内以书面形式向我区申请听证。

特此告知。

三亚市吉阳区人民政府

2019年3月17日
