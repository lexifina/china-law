# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（三亚市抱坡片区市政道路一期工程项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

抱坡村委会，东岸村委会，三亚南新实业集团有限公司（原南新农场），师部农场，三亚警备区，三亚水泥厂：

因我市的城市建设需要，市政府以《关于三亚市抱坡片区市政道路一期工程项目土地调查有关事项的通知》（三府办〔2019〕206号）文拟征收我区抱坡村委会、东岸村委会部分集体土地及我区辖区内部分国有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区抱坡片区内，用地面积约1.2215公顷，其中土地权属情况为抱坡村委会约0.5885公顷、东岸村委会约0.0904公顷、南新农场约0.1230公顷、师部农场约0.1237公顷、三亚警备区约0.2852公顷、三亚水泥厂约0.0107公顷。

二、拟征收土地的用地性质为公路用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，自本告知书下达之日起15天内以书面形式向我区申请听证。

三亚市吉阳区人民政府

2019年11月19日
