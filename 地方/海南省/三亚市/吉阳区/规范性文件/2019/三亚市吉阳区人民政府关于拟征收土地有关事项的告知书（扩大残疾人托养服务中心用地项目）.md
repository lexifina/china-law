# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（扩大残疾人托养服务中心用地项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区榆红村委会：

因我市的城市建设需要，市政府以《关于扩大残疾人托养服务中心用地项目土地调查有关事项的通知》（三府办〔2016〕312号）等文拟征收三亚市吉阳区榆红村委员会农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区控规D-22规划单元内，用地面积为1.2044公顷，涉及有林地0.0116公顷、建制镇0.0296公顷、村庄1.0494公顷、风景名胜及特殊用地0.1138公顷。

二、拟征收土地的用地性质为特殊医疗用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2019年2月21日
