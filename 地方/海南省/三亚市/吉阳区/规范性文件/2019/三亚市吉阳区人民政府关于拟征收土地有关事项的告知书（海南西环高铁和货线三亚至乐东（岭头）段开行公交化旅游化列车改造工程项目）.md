# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（海南西环高铁和货线三亚至乐东（岭头）段开行公交化旅游化列车改造工程项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

抱坡村委会：

因我市的城市建设需要，市政府以《关于利用海南西环高铁和货线三亚至乐东（岭头）段开行公交化旅游化列车改造工程项目土地调查有关事项的通知》（三府办〔2019〕180号）文拟征收我区抱坡村委会部分集体土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于天涯区、崖州区和吉阳区内，涉及吉阳区用地面积约0.4549公顷，土地权属情况为抱坡村委会。

二、拟征收土地的用地性质为城镇建设用地、风景名胜设施用地和公路用地等。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，自本告知书下达之日起15天内以书面形式向我区申请听证。

三亚市吉阳区人民政府

2019年10月30日
