# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（海南西环高铁和货运三亚至乐东（岭头）段开行公交化旅游化列车改造工程项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区抱坡村委会：

因我市的城市建设需要，市政府以《关于利用海南西环高铁和货运三亚至乐东（岭头）段开行公交化旅游化列车改造工程项目土地调查有关事项的通知》（三府办〔2019〕180号）文拟征收三亚市吉阳区抱坡村委会农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区，用地面积为0.4565公顷，均为建设用地。

二、拟征收土地的用地性质为交通运输用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2019年11月29日
