# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（荔枝沟居委会预留集体经济发展用地项目）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

海罗村委会、东岸村委会、临春居委会、荔枝沟居委会、南新农场：

因我市的城市建设需要，市政府以《关于吉阳镇荔枝沟居委会预留集体经济发展用地土地调查有关事项的通知》（三府办〔2013〕151号）文拟征收我区海罗村委会、东岸村委会、临春居委会、荔枝沟居委会部分集体土地及收回我区辖区内部分国有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地分别位于迎宾大道南侧和高铁路桥与三亚学院路交汇处东侧，用地面积约41815.71平方米（合约62.7235亩）,其土地权属情况详见权属示意图。

二、拟征收土地的用地性质为预留发展用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，自本告知书下达之日起15天内以书面形式向我区申请听证。

特此告知

三亚市吉阳区人民政府

2019年1月25日
