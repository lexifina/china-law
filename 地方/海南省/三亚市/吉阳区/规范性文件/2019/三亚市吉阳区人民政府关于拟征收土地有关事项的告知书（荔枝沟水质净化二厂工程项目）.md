# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（荔枝沟水质净化二厂工程项目）

2019无文号69

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区南丁村委会：

因我市的城市建设需要，市政府以《关于三亚市荔枝沟水质净化二厂工程项目用地土地调查有关问题的通知》（三府办〔2017〕211号）文拟征收三亚市吉阳区南丁村委会农村集体所有土地，作为荔枝沟水质净化二厂建设用地。现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区荔枝沟片区控规LZG5-5-7地块，用地面积为4.2524公顷，其中：水田约3.3815公顷、旱地约0.1894公顷、可调整其他园地约0.0016公顷、其他林地约0.2243公顷，城市0.086公顷，村庄0.3696公顷。

二、拟征收土地的用地性质为公共管理和公共服务用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2019年2月15日
