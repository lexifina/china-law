# 三亚市吉阳区人民政府关于智能化电力保护测控监视装置系统建设项目用地土地搬迁通知（智能化电力保护测控监视装置系统建设项目）

搬迁通知

各相关单位及个人：

根据《三亚市人民政府办公室关于智能化电力保护测控监视装置系统建设项目用地土地调查有关问题的通知》（三府办〔2011〕28号）文件精神，我区已完成智能化电力保护测控监视装置系统建设项目用地范围内土地、房屋及其他附着物的补偿工作。该项目位于高新技术产业园区内，四至范围：东至三亚雷声船舶维修公司、西至海南中本水产食品有限公司、南至吉阳大道、北至高新大道（具体的征地拆迁范围四至及坐标详见用地勘测定界图）。为确保项目建设工作有序推进，相关权利主体拟对该地块上所有附着物依法进行清理，请你单位（个人）接到本通知之日起7日内自行搬迁完毕，逾期未完成搬迁，相关权利主体将依法强制清理，由此造成的不利后果均由你单位（个人）自行承担。
