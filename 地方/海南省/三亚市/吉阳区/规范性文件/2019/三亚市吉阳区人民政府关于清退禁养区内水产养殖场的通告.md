# 三亚市吉阳区人民政府关于清退禁养区内水产养殖场的通告

三亚市吉阳区人民政府

关于清退禁养区内水产养殖场的通告

根据《海南省生态保护红线管理规定》《海南经济特区海岸带保护与开发管理实施细则》《三亚市海岸带保护规定》和《三亚市养殖水域滩涂规划（2018-2030年）》等相关文件要求，榆林港周边离海200米以内的海岸带，属于Ⅱ生态保护红线区和禁止养殖区。为贯彻落实中央第四环境保护督察组督察反馈意见的整改工作，进一步强化我区海洋生态环境保护，并根据《海南省农业农村厅关于印发海南省2019-2020年水产养殖整治工作实施方案的通知》（琼农字〔2019〕75号）《三亚市人民政府办公室关于印发三亚市海水养殖综合治理工作方案的通知》（三府办〔2019〕32号）要求，现对清退禁养区内水产养殖场通告如下：

一、严禁在榆林港周边离海200米以内的海岸带或其他禁养区内新增水产养殖设施。

二、严禁向位于禁养区内水产养殖场投放任何水产品幼苗。

三、本区辖区内的各禁养区内水产养殖场业主均须主动配合我区开展涉及本人所有养殖场的清退工作。

特此通告。

三亚市吉阳区人民政府

2019年6月28日
