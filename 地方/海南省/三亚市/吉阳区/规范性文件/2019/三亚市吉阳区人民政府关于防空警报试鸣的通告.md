# 三亚市吉阳区人民政府关于防空警报试鸣的通告

三亚市吉阳区人民政府

关于防空警报试鸣的通告

根据《中华人民共和国人民防空法》《中共海南省委 海南省政府 海南军区关于加强人民防空工作的决定》，今年10月29日（星期二）上午09:00至11:00，我市将进行防空警报试鸣。届时，全市防空警报器和三亚市电视台、三亚市广播电视台天涯之声（104.6兆赫）将同时分别通过图像、语音向广大群众发出“预先警报”“空袭警报”和“解除警报”三种防空警报信号，各种信号重复2次。望广大市民听（看）到防空警报信号时，注意分辨，不要惊慌，照常工作和生活。现将防空警报的信号通告如下表：
