# 三亚市吉阳区人民政府关于限期选择房屋征收补偿安置方式的通知（覃国崖）（第二版、此件为准）

三亚市吉阳区人民政府

关于限期选择房屋征收补偿安置方式的通知

覃国崖：

根据三亚市人民政府印发的《下洋田安置区项目房屋征收决定》（三府〔2014〕183号），我区作为房屋征收实施单位，负责对下洋田安置区项目用地范围内的房屋及地上附属物实施征收。您位于三亚市吉阳区二环路下洋田安置区B型安置楼501房处于项目征收范围内，房屋建筑面积为124.48平方米，土地房屋权证号为：三土房（2003）字第2094号。根据《国有土地上房屋征收与补偿条例》（国务院590号令）有关规定，三亚市住房和城乡建设局按照程序对您的被征收房屋和安置房屋进行了评估，您位于吉阳区凤凰路下洋田安置区B型安置楼501房的市场评估单价为11228元/㎡，安置房屋的市场评估单价为16292元/㎡。

根据《国有土地上房屋征收与补偿条例》（国务院590号令）、《下洋田安置区拆迁安置补偿方案》（三住建〔2013〕933号）等相关规定，请您在2019年7月15日前就以下两种补偿安置方式作出书面选择，逾期不选择的，视为您默认选择第一种补偿安置方式（即货币补偿方式）。届时，我区将据此报市政府作出征

收补偿决定。

一、货币补偿方式

由我区向您支付下列补偿费用：

（一）被征收房屋的市场评估价值1397661.44元（被征收房屋建筑面积124.48㎡×市场评估单价11228元/㎡)；

（二）房屋室内装修补偿38435.55元（因覃国崖不配合评估机构对其被征收房屋装修进行评估，暂以下洋田安置区B型安置楼同等户型8户被征收人的房屋装修补偿均值进行补偿，待具备评估条件后再予以评估，实行多退少补）；

（三）搬迁补助费3000元。

以上三项合计1439096.99元。

二、产权调换方式

由我区按以下标准对您的被征收房屋实施补偿：

（一）搬迁补助费3000元、被征收房屋室内装修费38435.55元（因您不配合评估机构对其被征收房屋装修进行评估，暂以下洋田安置区B型安置楼同等户型8户被征收人的房屋装修补偿均值进行补偿，待具备评估条件后再予以评估，实行多退少补），以上两项合计41435.55元。

（二）临时过渡安置方式为向您发放临时过渡费，由您自行过渡安置。临时过渡期暂定12个月，自搬迁之日起，按2400元/月的标准向您一次性发放12个月的临时过渡费共计28800元。过渡期满后仍未交付安置房屋的，按照《下洋田安置区拆迁安置补偿方案》有关规定继续向您发放临时过渡费，至安置房屋交付您的次月起停止支付临时过渡费。

（三）市政府向您提供的产权调换房为期房，位于下洋田安置区旧城改造项目征收范围内，房号为15栋14层02户型，建筑面积为150.22平米。按照建筑面积1:1的标准进行产权调换后，安置房屋建筑面积超出被征收房屋建筑面积25.74㎡，您需交纳353896.08元（5㎡×3200元/㎡+（25.74-5）×16292元/㎡）的差额面积房价。

（四）第一、第二项与第三项相抵后，您还需交纳产权调换房屋面积差价283660.53元（交款时间以通知为准）。

三亚市吉阳区人民政府
