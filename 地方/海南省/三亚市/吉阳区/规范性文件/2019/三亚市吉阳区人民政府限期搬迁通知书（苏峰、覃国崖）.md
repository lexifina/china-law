# 三亚市吉阳区人民政府限期搬迁通知书（苏峰、覃国崖）

限期搬迁通知书

苏峰、覃国崖：

下洋田安置区旧城改造项目于2014年11月8日启动，截至目前，仅剩你们2户被征收人尚未与我区签订《房屋征收补偿协议》。近期，我区委托海南汇国建筑工程检测有限公司对你们2人居住的下洋田安置区1号楼和下洋田安置区2号楼房屋安全性进行了鉴定，鉴定结果显示两栋房屋均为Dsu级危房。为维护公共安全及保护你们的生命财产安全，根据《突发事件应对法》第三条、第五条、第四十八条、第六十六条、第六十七条和《城市危险房屋管理规定》第五条、第九条、第十六条、第十七条之规定，限你们在2019年10月20日前自行搬离出两栋危房并清空房屋内全部物品，逾期不搬离的，视为你们放弃对该房屋及室内全部物品的所有权和处置权。我区将依法采取相应的行政强制措施，届时你们须承担因此产生的行政及民事责任。

特此通知。

三亚市吉阳区人民政府

2019年10月10日
