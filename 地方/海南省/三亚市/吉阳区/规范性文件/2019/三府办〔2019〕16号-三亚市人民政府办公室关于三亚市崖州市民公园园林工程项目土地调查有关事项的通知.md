# 三亚市人民政府办公室关于三亚市崖州市民公园园林工程项目土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市崖州市民公园园林工程项目土地

调查有关事项的通知

崖州区人民政府，市各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对崖州市民公园园林工程项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于崖州区辖区内，用地调查面积约58035 平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市规划委审核出具的崖州市民公园拟用地红线图。土地权属（海南平面坐标系）情况为：崖州区城东村集体土地约49661平方米、崖州区水南村集体土地约570平方米、崖州区政府土地约7117平方米、南滨农场国有土地约687平方米；土地利用现状（2000国家大地坐标系）为农用地约15649平方米（其中水田约5237平方米、旱地约1679平方米、其他园地约1809平方米、坑塘水面约6924平方米）、建设用地约42434平方米（其中建制镇约167平方米、采矿用地约42267平方米）；该项目用地在土地利用总体规划2014年调整完善（2000国家大地坐标系）中规划为城镇用地约35454平方米、坑塘水面约16平方米、公路用地约22576平方米、旱地约6平方米、园地约32平方米；该项目用地在《三亚市总体规划（空间类2015-2030）》（市多规合一，2016年经省政府常务会审议通过）中规划为城镇建设用地和公路用地。上述用地涉及的约6916平方米耕地在办理农用地转用时，从我市耕地占补平衡指标中统筹安排。待完成占补平衡任务后，由崖州区政府按要求提供用地报批材料，市国土资源局将其列入当年新增建设用地指标并办理农转用及征收报批手续。崖州区政府、各相关职能部门一定要提高依法用地意识，新的项目决不能产生违法用地。

二、为做好该项土地调查工作，由崖州区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土资源局负责对征收集体土地范围内征地业务指导工作；市住房城乡建设局负责对收回国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地及收回农场国有土地的征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行；收回其他国有土地的征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）等规定执行。

四、根据2010年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，崖州区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认，向市国土资源局出具履行征地前告知等程序的证明及土地权属确认意见（附件1）。待有权限的人民政府批准征地后，征收土地公告和征地补偿安置方案公告可同步进行。

五、为进一步做好被征地农民养老保险工作，根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神，应在本通知下发后10个工作日内对项目征收农用地和享受缴费补贴人数等情况进行调查，组织村（居）小组填写《征地项目被征地农民基本情况调查表》（附件2），经村（居）委会、崖州区政府逐级审核后，由崖州区政府汇总填写《征地项目被征地农民基本情况乡镇调查汇总表》（附件3），并将上述两种表格报送市国土资源局。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
