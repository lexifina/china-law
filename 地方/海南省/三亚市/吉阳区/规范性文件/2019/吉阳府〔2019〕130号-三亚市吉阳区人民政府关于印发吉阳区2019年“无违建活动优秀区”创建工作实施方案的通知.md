# 三亚市吉阳区人民政府关于印发吉阳区2019年“无违建活动优秀区”创建工作实施方案的通知

三亚市吉阳区人民政府

关于印发吉阳区2019年“无违建活动优秀区”创建工作实施方案的通知

区各相关单位，各村（居）委会：

《吉阳区2019年“无违建活动优秀区”创建工作实施方案》已经区委、区政府同意，现印发给你们，请认真贯彻落实。

三亚市吉阳区人民政府

2019年7月24日

（此件主动公开）

吉阳区2019年“无违建活动优秀区”

创建工作实施方案

为落实省、市“无违建”工作部署，深入整治违法建筑，巩固整违成果，依据《关于印发2019年“无违建”示范点创建活动工作计划的通知》（三打违〔2019〕5号），结合我区实际，制定本方案。

一、任务目标

成功创建“无违建活动优秀区”

二、时间安排

2020年2-3月，迎接市打违办对“无违建活动优秀区”创建点的考核。

以上构成人员工作变动时，由对应的新任职人员自然递补，不再发文调整。

四、责任分工

（一）区委政法委：负责强制拆除行动的风险评估和维稳工作。

（二）区委宣传部：负责创建“无违建活动优秀区”行动的媒体宣传报道工作。

（三）区农业农村局：负责对挖山毁林建房、非法占用农用地建房等行为进行巡查管护，发现挖山毁林建房、非法占用农用地建房等行为立即报区综合行政执法局依法查处。

（四）区财政局：负责为“无违建活动优秀区”创建工作提供经费保障。

（五）区司法局：负责为“无违建活动优秀区”创建工作提供司法保障，指导法制宣传教育，普及法律常识。

（六）区综合行政执法局：负责对各社区（村庄）的存量违建消减情况、新增违建管控情况、村（居）民建房管理情况进行督查。

（七）区住房和城乡建设局：负责深入开展房屋普查工作，要求已实行物业管理的小区积极配合各社区（村庄）开展“无违建”示范点创建活动，指导和协助区综合行政执法局完善村（居）民建房管理机制。

（八）区海洋水务局：负责对非法占用河道、海岸线、水源保护区等建房行为进行巡查监管。依法需要给予行政处罚的，应当及时将有关线索通报区综合行政执法局进行查处。

（九）吉阳国土分局：负责对违法建筑非法占用使用土地情况进行监管，利用卫星遥感影像资源为违法建筑排查提供基础数据参考，指导和协助区综合行政执法局解决“一户多宅”等问题及完善村（居）民建房管理机制，并依据职责及时回复征询意见事项，出具审查认定意见。

（十）吉阳规划分局：负责指导和协助相关单位完善村（居）民建房管理机制。

（十一）市公安局吉阳分局：负责协助开展“无违建活动优秀区”创建活动，对整治违法建筑工作中发生的阻挠执法、暴力抗法等行为依法进行查处。

（十二）各局、中心及各村（居）委会：驻点干部及村（居）委会干部提前做好宣传工作，监督辖区村（居）民的建房行为，并及时向领导小组办公室反馈，积极配合做好“无违建活动优秀区”创建活动。

五、“无违建活动优秀区”创建标准

（一）区所辖90%以上的社区（村）建成“无违建社区（村）”，创建成功后保持新增违建“零增长”

考核方式：查阅资料、实地查看。

迎检资料：

1.辖区“无违建社区（行政村）”的验收表。（责任单位：区综合行政执法局）

2.2018至2019年期间新增违建统计表。（责任单位：区综合行政执法局）

（二）区政府或管委会所在地的社区（村）建成“无违建社区（村）”

考核方式：查阅资料。

迎检资料：区政府或管委会所在地的社区（村）的“无违建”验收表。（责任单位：区综合行政执法局）

（三）辖区范围内无因整违工作引发的重大群体性事件和安全事故

考核方式：查阅资料。

迎检资料：区安监部门出具的证明材料。（责任单位：区应急管理局）

（四）构建了全覆盖、网格化的违法建筑防控和整治工作机制

考核方式：查阅资料。

迎检资料：

1.区一级网格化包干制度及网格化管理人员名单。〔责任单位：区综合行政执法局、各村（居）委会〕

2.2019年所有村（居）的巡查记录，每日要巡查，必须手写，每页加盖村（居）委会公章。〔责任单位：各村（居）委会〕

3.2019年区执法局的巡查记录，每日要巡查，必须手写，每页加盖区执法局公章。（责任单位：区综合行政执法局）

4.区一级的违建监督举报机制，投诉电话、举报信箱，以及2019年违建投诉案件清单（包括市12345热线交办、区投诉平台受理等渠道受理的案件），已办结的要提供佐证材料。〔责任单位：区综合行政执法局、各村（居）委会〕

5.区一级的违建管控督查问责机制，督办单、督查通报等有效证明开展了督查的资料，以及有效证明落实了责任追究的资料。〔责任单位：区综合行政执法局、各村（居）委会〕

6.区成立快速处置新增违建队伍的文件，规定打早打小措施的文件，2019年打早打小台账及档案。（责任单位：区综合行政执法局）

（五）有健全的规划

考核方式：查阅资料。

迎检资料：

1.区土地利用规划，区土地管理部门出具书面盖章说明。（责任单位：吉阳规划分局、吉阳国土分局、区住建局）

2.区城乡建设规划，区规划管理部门出具书面盖章说明。（责任单位：吉阳规划分局、吉阳国土分局、区住建局）

3.区所辖社区（村庄）规划编制情况，区规划管理部门出具书面盖章说明。（责任单位：吉阳规划分局、吉阳国土分局、区住建局）

4.各社区（村庄）规划，区规划管理部门出具书面盖章说明。（责任单位：吉阳规划分局、吉阳国土分局、区住建局）

5.2019年查处违反规划建设行为的清单。（责任单位：区综合行政执法局、吉阳规划分局、吉阳国土分局、区住建局）

（六）成立创建工作领导机构

考核方式：查阅资料。

迎检资料：出台成立区政府、管委会主要领导为组长的“无违建活动优秀区”创建工作领导机构的文件。分值4分，有文件得分，否则不得分。（责任单位：区综合行政执法局）

（七）经常性研究部署创建工作

考核方式：查阅资料。

迎检资料：区政府、管委会部署研究“无违建”创建活动的会议纪要（至少4份）。分值4分，每提供一份会议纪要得1分。（责任单位：区委办、区政府办、区综合行政执法局）

（八）制定创建工作方案

考核方式：查阅资料。

迎检资料：“无违建活动优秀区”创建工作方案，明确创建工作目标、任务和措施。分值4分，有文件得分，否则不得分。（责任单位：区综合行政执法局）

（九）召开创建工作动员部署会议

考核方式：查阅资料。

迎检资料：区政府、管委会召开“无违建活动优秀区”创建工作动员部署会议的佐证材料（美篇、图片说明均可）。分值4分，有材料得分，否则不得分。（责任单位：区委宣传部、区委办、区政府办、区综合行政执法局）

（十）层层分解落实工作任务

考核方式：查阅资料。

迎检资料：将“无违建活动优秀区”创建工作任务层层分解落实到村（居）委会的文件。分值4分，有文件得分，否则不得分。（责任单位：区综合行政执法局）

（十一）落实创建工作经费

考核方式：查阅资料。

迎检资料：区统一保障创建工作经费的相关文件或财政资金支出凭证。分值4分，有文件得分，否则不得分。（责任单位：区财政局）

（十二）出台相关配套政策

考核方式：查阅资料。

迎检资料：区一级违建举报奖励、农村宅基地管理、村（居）民建房报建审批等配套政策（至少3个）。分值15分，提供一份文件得5分。〔责任单位：区综合行政执法局、吉阳规划分局、吉阳国土分局、区住建局、各村（居）委会〕

（十三）多渠道、多层次开展宣传工作

考核方式：查阅资料、走访群众。

迎检资料：

1.通过宣传栏、标语、横幅、海报、宣传手册、宣讲等方式宣传“无违建”工作的有关政策、法规和文件精神的视频、相片、文件资料等佐证材料。分值4分，采取1种宣传方式得1分。〔责任单位：区委宣传部、区综合行政执法局、各村（居）委会〕

2.通过新闻媒体宣传报道的佐证材料。分值4分，报道1次得1分。（责任单位：区委宣传部）

3.随机走访10名群众，进行问卷调查了解情况。分值4分，知晓率90%以上（不含90%）得4分，知晓率70%以上（不含70%）得3分，否则不得分。

（十四）完成存量违建的分类处置

考核方式：查阅资料、实地查看。

迎检资料：

1.存量“两违”台账，无存量“两违”的由区执法局书面盖章说明。立案的违建需提供结案报告；补办手续的违建需提供相关报建手续；拆除的违建需提供拆除记录（有结案报告的无须提供），放入“两违”档案中。“两违”图斑应分类处置完成，列为拆除方式处置的必须拆除完毕，列为暂缓拆除的必须走完程序。（责任单位：区综合行政执法局、吉阳规划分局、吉阳国土分局、区住建局）

2.“一违一档”。档案内的相关材料要齐全，能够充分证明已进行了分类处置。（责任单位：区综合行政执法局）

分值15分，全面完成得15分，完成90%以上（含90%）得12分，完成80%以上（含80%）得9分，完成70%以上（含70%）得6分，完成60%以上（含60%）得3分，完成60%以下不得分。

（十五）有效制止并处置新增违建

考核方式：查阅资料、实地查看。

迎检资料：

1.新增“两违”台账，无新增“两违”（即2017年9月22日之后建设的违法建筑）的由区执法局书面盖章说明。立案的违建需提供结案报告；补办手续的违建需提供相关报建手续；拆除的违建需提供拆除记录（有结案报告的无须提供）。新增“两违”原则上不能作暂缓拆除处置。（责任单位：区综合行政执法局、吉阳规划分局、吉阳国土分局、区住建局）

2.“一违一档”。档案内的相关材料要齐全，能够充分证明已进行了分类处置。（责任单位：区综合行政执法局）

分值10分，结合投诉举报，实地随机核查5处疑似新增违建，确认一起扣2分，扣完为止。

（十六）科学做好拆后土地平整和规划利用工作

考核方式：查阅资料、实地查看。

迎检资料：2019年拆违台账。（责任单位：区综合行政执法局）

分值15分，其中土地平整10分，土地利用5分。随机抽查5处拆违点，全部平整得10分，4处已平整得8分，3处已平整得6分，2处及以下不得分；4处及以上土地已利用得5分，3处土地已利用得4分，2处土地已利用得3分，1处及以下不得分。

（十七）妥善办结违法建筑投诉举报件

考核方式：查阅资料、实地查看、电话回访。

迎检资料：2019年违法建筑投诉举报件受理台账，已办结的要提供佐证材料。（责任单位：区综合行政执法局、区应急联动中心）

分值10分，随机抽查10个举报件，随机电话回访至少5个投诉人，办结9宗及以上得10分，办结8宗得8分，办结7宗得6分，办结6宗及以下不得分。

六、工作要求

（一）加强组织领导。创建“无违建活动优秀区”是我区年度“两违”整治任务之一，各职能部门要高度重视，认真对待，主要领导要下沉一线，靠前指挥，经常性研究部署工作。分管领导要经常深入社区（行政村）检查创建工作，研究解决遇到的问题，协调保障工作经费，确保创建活动扎实开展。

（二）建立例会制度。区主要领导或分管领导要定期召集各相关单位听取创建工作进展情况及迎检资料准备情况的汇报，协调解决存在问题，部署下一步的工作。此外，各相关单位也要定期召开创建工作会议，研究部署各自负责的工作内容，促进创建工作向前发展。

（三）组织学习培训。区打违办要将培训学习列入年度工作计划中，采取“课堂教学与现场实践相结合”的方式，定期组织对业务骨干进行轮训，通过“传、帮、带”的模式，加快提高工作人员业务水平。同时，各相关单位要组织开展本单位的学习培训活动，确保每个工作人员都熟悉创建标准及自身职责，规范准备迎检材料。

（四）持续跟踪督查。各相关单位要根据创建工作和迎检资料的分工，建立工作进度跟踪督查机制，每月将更新的工作开展和资料准备进度，报区打违办，由区打违办汇总上报市打违办。区打违办要对各单位创建工作情况进行督查，对未完成任务、工作开展不力、进度严重滞后的单位进行通报，并追究相关人员的责任。
