# 三亚市吉阳区人民政府关于印发海南省公路交通扶贫六大工程三亚市旅游资源路工程项目补偿安置方案的通知

吉阳府〔2019〕162号

三亚市吉阳区人民政府

关于印发海南省公路交通扶贫六大工程

三亚市旅游资源路工程项目补偿安置方案的通知

各有关单位：

《海南省公路交通扶贫六大工程三亚市旅游资源路工程项目补偿安置方案》已经区政府二届第61期常务会议审议同意，现印发给你们，请认真贯彻执行。

三亚市吉阳区人民政府

2019年9月24日

（此件主动公开）

海南省公路交通扶贫六大工程

三亚市旅游资源路工程项目补偿安置方案

根据市政府《关于三亚市交通运输局关于下达海南省农村公路交通扶贫六大工程三亚市旅游资源路工程项目用地土地调查的请示》的批示及三亚市自然资源和规划局（原三亚市国土资源局）《关于下达海南省农村公路交通扶贫六大工程三亚市旅游资源路工程项目用地土地调查事宜的复函》（三土资用〔2017〕383号）文件精神，市交通局拟占用我区落笔村委会部分集体土地及南新农场部分国有土地作为三亚市旅游资源路工程项目用地。为做好项目征地补偿安置工作，结合《三亚市人民政府关于印发<三亚市集体土地征收补偿安置管理规定（2013年修订）>的通知》（三府〔2013〕43号）、《三亚市人民政府关于印发<三亚市征收集体土地青苗补偿费和征地经费包干管理暂行办法>的通知》（三府〔2011〕208号）和《三亚市人民政府办公室关于做好用地征收补偿有关工作的通知》（三府办〔2019〕8号）等相关规定和项目实际，我区制定了该项目征地补偿安置方案，具体如下：

一、项目占用土地范围及基本情况

项目涉及我区落笔村委会部分集体土地及我辖区内南新农场部分国有土地，具体面积及四至范围详见项目用地红线图，主要涉及占用落笔村委会村民和南新农场居民的房屋，房屋共5栋，总建筑面积约715平方米（最终数据以实际丈量核实数据为准）。

二、指导思想

坚持以习近平新时代中国特色社会主义思想为指导，建设海南自由贸易试验区和中国特色社会主义贸易港，改善城市面貌，提升城市品位、价值和形象，维护被搬迁人的合法权益，在依法征用补偿基础上，做到和谐拆迁。

三、基本原则

（一）坚持“公平、公正、公开”的补偿原则。

（二）坚持保护合法建筑和打击违法建筑相结合的原则。

（三）以人为本，让利于民，保障被搬迁人的合法权益。

四、房屋征收补偿标准

（一）本方案发布前被搬迁户为具有落笔村委会户籍或属南新农场户籍人员且在落笔村或南新农场常住的人员的补偿标准

1.现有居住房屋按照框架结构每平方米1250元、混合结构每平方米1050元的标准作价进行货币补偿。

2.每栋房屋建筑面积不超过270平方米，按被搬迁房屋作价补偿金额的100%给予奖励。每栋房屋建筑面积超过270平方米的部分，按被搬迁房屋作价补偿金额的30%给予奖励。

3.房屋装饰、青苗及其它附着物等补偿标准参照三府〔2013〕43号文件规定另行补偿。青苗补偿可根据三府〔2011〕208号文件规定采取按亩包干补偿。

4.搬迁补助按每户3000元的标准给予一次性搬迁补助。

5.临时过渡安置补助费按三府〔2013〕43号文件400元/人/月标准执行，过渡费发放期为12个月。

（二）外来人员房屋的征收补偿标准

在项目范围内没有合法手续的房屋（合法手续房屋为取得合法权属的房屋，或取得合法建设手续的房屋）且户籍也不在落笔村委会、南新农场的外来人员的房屋，如被拆迁人主动配合登记丈量，且在规定时间签订征收补偿协议并主动腾空房屋配合拆迁的，被拆房屋（包括框架、混合、砖木结构房屋）按每平方米800元标准（搬迁奖励：550元/平方米，搬迁补贴250元/平方米）给予被拆迁人，且房屋及房屋装饰部分不再另行补偿。

（三）其他符合安置条件且需产权置换安置的被征收户或属其他情形的被搬迁户，补偿安置标准按三府〔2013〕43号文件规定执行或上报区政府研究确定。

五、土地征收补偿标准

征收各村（居）委会集体土地补偿按三府〔2013〕43号文件标准执行，收回南新农场国有土地参照三府〔2013〕43号文件标准执行。

六、附则

（一）本方案自批准发布之日起施行。

（二）本方案中未尽事宜，或在项目征收补偿过程中需对本方案的有关内容进行调整的，由区政府会议讨论确定。

（三）本方案由吉阳区人民政府负责解释。

三亚市吉阳区人民政府办公室
