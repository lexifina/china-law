# 三亚市吉阳区人民政府关于印发三亚东河生态修复工程（溪泽三桥—东环高铁段）项目补偿安置方案的通知

吉阳府〔2019〕163号

三亚市吉阳区人民政府

关于印发三亚东河生态修复工程（溪泽

三桥—东环高铁段）项目补偿安置方案的通知

各有关单位：

《三亚东河生态修复工程（溪泽三桥—东环高铁段）项目补偿安置方案》已经区政府二届第61期常务会议审议同意，现印发给你们，请认真贯彻执行。

三亚市吉阳区人民政府

2019年9月24日

（此件主动公开）

三亚东河生态修复工程

（溪泽三桥—东环高铁段）项目补偿安置方案

根据《三亚市人民政府办公室关于三亚东河生态修复工程（溪泽三桥—东环高铁段）项目土地调查有关事项的通知》（三府办〔2017〕143号）精神，市政府拟征收我区东岸村委会、海罗村委会、临春居委会、荔枝沟居委会部分集体土地及收回我辖区内部分国有土地作为三亚东河生态修复工程（溪泽三桥—东环高铁段）项目用地。为做好项目征地补偿安置工作，结合《三亚市人民政府关于印发<三亚市集体土地征收补偿安置管理规定（2013年修订）>的通知》（三府〔2013〕43号）《三亚市人民政府关于印发<三亚市征收集体土地青苗补偿费和征地经费包干管理暂行办法>的通知》（三府〔2011〕208号）和《三亚市人民政府办公室关于做好用地征收补偿有关工作的通知》（三府办〔2019〕8号）等相关规定和项目实际，我区制定了该项目征地补偿安置方案，具体如下：

一、征收范围及基本情况

项目涉及我区东岸村委会、海罗村委会、临春居委会、荔枝沟居委会部分集体土地及我辖区内部分国有土地，面积约248.31亩，具体面积及四至范围详见项目征地红线图，主要涉及征收海罗村委会和荔枝沟居委会村（居）民房屋及部分外来户房屋，房屋共34栋，总建筑面积约1.3万平方米（最终数据以实际丈量核实数据为准）。

二、指导思想

坚持以习近平新时代中国特色社会主义思想为指导，建设海南自由贸易试验区和中国特色社会主义贸易港，改善城市面貌，提升城市品位、价值和形象，维护被征收人的合法权益，在依法征收的基础上，做到和谐征收。

三、基本原则

（一）坚持“公平、公正、公开”的征收补偿原则。

（二）坚持保护合法建筑和打击违法建筑相结合的原则。

（三）以人为本，让利于民，保障被征收单位和被征收人的合法权益。

四、房屋征收补偿标准

（一）被征收户为海罗村、荔枝沟社区集体经济组织成员或本方案发布前具有海罗村、荔枝沟社区户籍且在海罗村、荔枝沟社区常住的人员的补偿标准

1.现有居住房屋按照框架结构每平方米1250元、混合结构每平方米1050元的标准作价进行货币补偿。

2.每栋房屋建筑面积不超过270平方米，按被搬迁房屋作价补偿金额的100%给予奖励。每栋房屋建筑面积超过270平方米的部分，按被搬迁房屋作价补偿金额的30%给予奖励。

3.房屋装饰、青苗及其它附着物等补偿标准参照三府〔2013〕43号文件规定另行补偿。青苗补偿可根据三府〔2011〕208号文件规定采取按亩包干补偿。

4.搬迁补助按每户3000元的标准给予一次性搬迁补助。

5.临时过渡安置补助费按三府〔2013〕43号文件400元/人/月标准执行，过渡费发放期为12个月。

（二）外来人员房屋的征收补偿标准

在项目范围内没有合法手续的房屋（合法手续房屋为取得合法权属的房屋，或取得合法建设手续的房屋）且户籍也不在海罗村、荔枝沟社区的外来人员的房屋，如被拆迁人主动配合登记丈量，且在规定时间签订征收补偿协议并主动腾空房屋配合拆迁的，被拆房屋（包括框架、混合、砖木结构房屋）按每平方米800元标准（搬迁奖励：550元/平方米，搬迁补贴250元/平方米）给予被拆迁人，且房屋及房屋装饰部分不再另行补偿。

（三）被征收户属其他情形的，补偿安置标准按三府〔2013〕43号文件规定执行或上报区政府研究确定。

五、特殊苗木的补偿

项目涉及征收三府〔2013〕43号文件中无补偿标准的特殊苗木可委托有资质的估价机构进行评估，评估补偿价格经吉阳区人民政府批准确认后执行。

六、土地征收补偿标准

征收各村（居）委会集体土地补偿按三府〔2013〕43号文件标准执行。

七、附则

（一）本方案自批准发布之日起施行。

（二）本方案中未尽事宜，或在项目征收补偿过程中需对本方案的有关内容进行调整的，由区政府会议讨论确定。

（三）本方案由吉阳区人民政府负责解释。
