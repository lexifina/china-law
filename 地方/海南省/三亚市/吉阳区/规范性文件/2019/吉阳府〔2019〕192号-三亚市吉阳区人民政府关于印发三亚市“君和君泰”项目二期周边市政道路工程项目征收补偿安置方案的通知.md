# 三亚市吉阳区人民政府关于印发三亚市“君和君泰”项目二期周边市政道路工程项目征收补偿安置方案的通知

吉阳府〔2019〕192号

三亚市吉阳区人民政府

关于印发三亚市“君和君泰”项目二期周边

市政道路工程项目征收补偿安置方案的通知

各相关单位：

《三亚市“君和君泰”项目二期周边市政道路工程项目征收补偿安置方案》已经区政府二届第71期常务会议审议同意，现印发给你们，请认真贯彻执行。

三亚市吉阳区人民政府

2019年11月12日

（此件主动公开）

三亚市“君和君泰”项目二期周边市政道路

工程项目征收补偿安置方案

为切实做好三亚市“君和君泰”项目二期周边市政道路项目（以下简称“本项目”）征地搬迁补偿安置工作，保障项目建设顺利推进，维护被征收人的合法权益，根据《中华人民共和国土地管理法》《中华人民共和国城乡规划法》《国有土地上房屋征收与补偿条例》《海南经济特区土地管理条例（2018修正）》《三亚市人民政府关于印发<三亚市集体土地征收补偿安置管理规定（2013年修订）>的通知》（三府〔2013〕43号）等文件精神，结合当地具体实际情况，制定本方案。

一、征收范围

本项目征地范围位于三亚市荔枝沟片区，北邻绕城高速公路，南靠东线高铁，东接落笔洞路。土地权属涉及荔枝沟居委会集体土地和三亚椰林书苑海垦地产有限责任公司国有土地（含已收回的该司国有土地）。征收各权属单位的土地面积以市政府征地调查通知的面积为准。征地范围内房屋及其他地上附着物以实际测量核定为准。

二、指导思想及基本原则

以习近平新时代中国特色社会主义思想为指导，围绕高标准高质量建设海南自由贸易试验区和中国特色自由贸易港为战略目标，坚持“公开、公平、公正”的征收补偿原则，以坚持保护合法建筑和打击违法建筑相结合的原则，以人为本，保障被征收人的合法权益。

三、征收主体

征收人：三亚市人民政府

实施单位：三亚市吉阳区人民政府

四、征收集体土地上房屋及其他附着物补偿标准

（一）具有荔枝沟居委会户籍的原籍居民和具有合法土地来源证明人员（以证明记载的权益人为准）认定为被征收人。

（二）被征收人家庭未享受过政策性住房（含保障性住房、职工安置房、集资房、房改房等）、宅基地分配和其他项目拆迁安置的，被征收人可选择货币方式或安置房安置和货币补偿相结合方式进行补偿；被征收人家庭已享受过政策性住房（含保障性住房、职工安置房、集资房、房改房等）、宅基地分配和其他项目拆迁安置的，被征收房屋仅按货币方式进行补偿。

（三）补偿方式

1.货币补偿

（1）被征收人家庭成员符合以下条件的，可予以分户进行货币补偿和奖励：成年子女已结婚的；年龄30岁以上（含30岁），未婚且已分家单独居住的。

（2）每户现有居住房屋建筑面积270平方米以内（含270平方米）的部分，按照框架结构每平方米1350元、混合结构每平方米1100元的标准补偿且给予补偿金额的100%搬迁奖励；被征收人现有居住房屋建筑面积超出270平方米的部分，按照框架结构每平方米1350元、混合结构每平方米1100元的标准补偿且给予补偿金额的30%搬迁奖励。

（3）房屋装修、青苗及其他附着物参照《三亚市人民政府关于印发<三亚市集体土地征收补偿安置管理规定（2013年修订）>的通知》（三府〔2013〕43号）相关标准执行；征收青苗补偿实行包干的，可参照《三亚市人民政府关于印发<三亚市征收集体土地青苗补偿费和征地经费包干管理暂行办法>的通知》（三府〔2011〕208号）标准执行。

2.安置房安置和货币补偿相结合

（1）如家庭人口2人（含2人）以上的，可置换建筑面积120平方米安置房；如家庭人口仅1人的，可置换建筑面积60平方米安置房。具体面积以实际分配安置房面积为准。

（2）被征收人现有房屋建筑面积270平方米以内（含270平方米）的部分，在扣除实际分配安置房面积后剩余部分按照框架结构每平方米1350元、混合结构每平方米1100元的标准补偿且给予补偿金额的100%搬迁奖励；被征收人现有房屋建筑面积270平方米以上的部分，按照框架结构每平方米1350元、混合结构每平方米1100元的标准补偿且给予补偿金额的30%搬迁奖励。

（3）现有房屋建筑面积不足以置换安置房面积的，不足部分由被征收人按相关职能部门核定的安置房综合建设成本价购买补足。

（4）房屋装修、青苗及其它附着物等补偿标准参照《三亚市人民政府关于印发<三亚市集体土地征收补偿安置管理规定（2013年修订）>的通知》（三府〔2013〕43号）规定另行补偿；征收青苗补偿实行包干的，可参照《三亚市人民政府关于印发三亚市征收集体土地青苗补偿费和征地经费包干管理暂行办法的通知》（三府〔2011〕208号）标准执行。

五、征收国有土地上（已收回）房屋及其他附着物补偿标准

（一）具有合法房屋所有权证或缴纳相关费用经原南新农场办理的私建公助住宅权属证明的房屋，房屋产权人（即被征收人）可选择货币方式补偿，也可以选择房屋产权调换方式进行补偿：

1.货币补偿

被征收人选择货币补偿的，被征收房屋按照房屋征收公告发布之日被征收房屋市场评估价值进行补偿。

在规定时间内（自本方案批准发布之日起10日内）被征收人共同协商确定一家具有资质的房地产价格评估机构；协商不成的，由征地实施单位从市住房城乡建设主管部门已备案的具有相应资质的房地产价格评估机构储备库中采取随机抽取确定。

选定的评估机构依照相关法律法规，对被征收房屋、装修等附着物进行价值评估，并出具评估报告。

被征收人或房屋征收实施单位对评估结果有异议的，应当自收到评估报告之日起10日内，向评估机构申请复核；被征收人或房屋征收实施单位对评估机构的复核结果有异议的，应当自收到复核结果之日起10日内，向三亚市房地产价格评估专家委员会申请鉴定，最终评估结果以专家委员会鉴定结果为准。

2.产权调换

被征收人选择产权置换的，在不改变国有土地使用权取得方式的情况下，按照被征收房屋建筑面积置换安置房屋建筑面积比例进行调换，调换比例如下：

按上述产权调换比例计算，应置换的安置房建筑面积大于实际分配的安置房建筑面积的，差额部分按照被征收房屋市场评估价格进行结算。

应置换的安置房建筑面积不足实际分配的安置房建筑面积的，差额部分在5平方米以内（含5平方米），按安置房综合建设成本结算；差额部分超出5平方米的（最大不超过15平方米），按照安置房市场评估价格进行结算。

被征收房屋换发安置房房屋所有权证所需费用由被征收人承担。

（二）国有和集体企业单位职工为解决生活生产困难自建但未办理产权证明的房屋。

部分国有和集体企业职工在单位用地范围内为解决生活生产困难自建但未经市政府或南新农场有关部门办理合法产权证明的房屋，仅按以下标准进行货币补偿：

1.现有住房按框架结构每平方米1350元、混合结构每平方米1100元标准实行货币补偿。

2.房屋装修、青苗及其他附着物补偿标准参照《三亚市人民政府关于印发<三亚市集体土地征收补偿安置管理规定（2013年修订）>的通知》（三府〔2013〕43号）相关标准执行。

（三）其他特殊情形人员

其他特殊情形人员确需纳入补偿的，由本人申请，经所属村（居）委会或相关单位初审，项目征地工作小组复核后，上报区政府研究确定。

六、安置房源及分配

（一）安置房源优先从同心家园22期、南新农场安居工程等相关保障房中给予安排，具体房源以市政府批复为准。

（二）安置房分配

符合安置房安置的被征收人按照正式签订的补偿安置协议书时间先后顺序确定选房顺序。同一日签订协议的，采取抽签的方式确定选房顺序（包括安置房朝向、楼层、户型等）。

七、搬迁补助费和临时过渡安置费

（一）搬迁补助费

以被征收人现有住房的建筑面积（仅包括混合、框架结构）为基数，按照每平方米18元的标准发放搬迁补助费，单次搬迁最低不少于3000元。符合条件的被征收人选择产权调换的，按两次发放搬迁补助费。

（二）临时过渡安置费

依据本方案分配安置房的被征收人，以被征收人家庭为单位（不含分户的成员）发放临时过渡费。临时过渡费发放标准为每人每月租房补贴1000.00元、生活补贴500.00元。自被征收人签订征收补偿安置协议书并腾空房屋之日起一次性发放18个月临时过渡费，期满后每半年发放一次，直至被征收人取得安置房。

八、保障措施

（一）自本方案批准发布之日起3个月内，被征收人因个人不合理原因拒不配合办理补偿和搬迁的，或者被征收房屋所有权人不明确的，由吉阳区人民政府做出补偿决定予以公告，并依法申请法院强制执行。

（二）执法部门依法对征收范围内的抢建、抢种及违章建筑依法予以打击；对未登记的建筑进行调查、认定和处理，经执法部门认定为违法建筑和超过批准期限的临时建筑，不予补偿。

（三）参与补偿、安置相关的工作人员，必须严格执行有关法律、法规、政策和本《方案》的规定，接受社会监督。对玩忽职守、滥用职权、徇私舞弊的，由其所在单位或上级主管机关给予处分。构成犯罪的，由司法机关依法追究刑事责任。

（四）对通过恶意串通、故意阻挠等方式影响市政道路项目推进正常工作秩序，干扰、围攻、殴打工作人员执行公务的，由公安机关依照《中华人民共和国治安管理处罚法》进行处罚。对涉嫌黑恶势力的，移送由市扫黑办处理，构成犯罪的，依法追究刑事责任。

九、附则

（一）本方案自批准发布之日起施行。

（二）本方案中未尽事宜，或在项目房屋征收补偿安置过程中需对本方案的有关内容进行调整的，由吉阳区人民政府审议确定。

（三）本方案由吉阳区人民政府负责解释。
