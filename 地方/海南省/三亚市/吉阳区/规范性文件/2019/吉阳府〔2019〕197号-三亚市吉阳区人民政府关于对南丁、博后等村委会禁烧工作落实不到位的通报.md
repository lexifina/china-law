# 三亚市吉阳区人民政府关于对南丁、博后等村委会禁烧工作落实不到位的通报

吉阳府〔2019〕197号

三亚市吉阳区人民政府

关于对南丁、博后等村委会禁烧工作

落实不到位的通报

区各相关单位，各村（居）委会：

市环境保护督察整改工作领导小组于11月5日通报我区南丁村（高速公路旁）存在焚烧秸秆、垃圾行为，并根据《三亚市秸秆、垃圾禁烧工作方案》对吉阳区政府予以通报批评。

南丁村地处交通干道周边，是禁烧工作敏感区域，也是辖区内的重点监管范围。发生的大面积秸秆焚烧行为，对我市形象影响较坏，给区里工作造成被动局面，也从根本上暴露了村委会对禁烧工作思想松懈、麻痹大意，工作落实不到位的问题。

为加强和巩固秸秆、垃圾禁烧管理工作，我区有针对性地开展辖区内田洋、高速公路、铁路沿线等重点路段的清查工作。根据省市领导通报、市里不定期检查和我区自查发现，今年以来，我区南丁村、博后村、六盘村、大茅村、落笔村和中廖村等村委会和新村居委会均被发现存在露天焚烧秸秆的现象，现予以通报批评。

各村（居）委会和包点单位要认真吸取教训，加大秸秆垃圾禁烧宣传力度，做好一家一户的禁烧宣传教育，加强日常巡查，积极配合秸秆清运工作，疏堵结合，排除隐患，把问题解决在萌芽阶段，确保完成年度禁烧目标，维护优良空气质量。

三亚市吉阳区人民政府

2019年11月15日
