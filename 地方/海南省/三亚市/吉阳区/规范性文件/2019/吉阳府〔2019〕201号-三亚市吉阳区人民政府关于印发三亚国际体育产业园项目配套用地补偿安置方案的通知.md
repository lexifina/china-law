# 三亚市吉阳区人民政府关于印发三亚国际体育产业园项目配套用地补偿安置方案的通知

三亚市吉阳区人民政府

关于印发三亚国际体育产业园项目配套用地

补偿安置方案的通知

各有关单位：

《三亚国际体育产业园项目配套用地补偿安置方案》已经区政府二届第72次常务会议审议同意，现印发给你们，请认真贯彻执行。

三亚市吉阳区人民政府

2019年11月21日

（此件主动公开）

三亚国际体育产业园项目配套用地

补偿安置方案

根据《三亚市人民政府办公室关于三亚国际体育产业园项目配套用地土地调查有关事项的通知》（三府办〔2017〕143号）及三亚市人民政府《关于征收三亚市SY2019-057号用地12.9706公顷集体土地的通告》（三府〔2019〕200号）精神，市政府拟征收我区抱坡村委会部分集体土地及收回我辖区内部分国有土地作为三亚国际体育产业园项目配套用地。为做好项目征地补偿安置工作，结合《三亚市人民政府关于印发〈三亚市集体土地征收补偿安置管理规定（2013年修订）〉的通知》（三府〔2013〕43号）、《三亚市人民政府关于印发〈三亚市征收集体土地青苗补偿费和征地经费包干管理暂行办法〉的通知》（三府〔2011〕208号）和《三亚市人民政府办公室关于做好用地征收补偿有关工作的通知》（三府办〔2019〕8号）等相关规定和项目实际，我区制定了该项目征地补偿安置方案，具体如下：

一、征收范围及基本情况

我区抱坡村委会部分集体土地及我辖区内部分国有土地，面积约141亩，征收范围以项目征地红线图为准。

二、指导思想

坚持以习近平新时代中国特色社会主义思想为指导，全力推进海南自由贸易港建设，改善城市面貌，提升城市品位、价值和形象，维护被征收人的合法权益，在依法征收的基础上，做到和谐征收。

三、基本原则

（一）坚持“公平、公正、公开”的征收补偿原则。

（二）坚持保护合法建筑和打击违法建筑相结合的原则。

（三）以人为本，让利于民，保障被征收单位和被征收人的合法权益。

四、房屋征收补偿标准

（一）框架结构按照1,250.00元/㎡的标准进行货币补偿。

（二）混合结构按照1,050.00元/㎡的标准进行货币补偿。

（三）砖木结构按照750.00元/㎡的标准进行货币补偿。

（四）简易结构红砖墙体、铁皮顶或石棉瓦顶按照350.00元/㎡的标准进行货币补偿；红砖墙体、油毡顶按照300.00元/㎡的标准进行货币补偿；空心砖墙体、铁皮顶或石棉瓦顶按照280.00元/㎡的标准进行货币补偿；红砖墙体、油毡顶按照200.00元/㎡的标准进行货币补偿；木板、铁皮、竹编等材料墙，油毡顶按照80.00元/㎡的标准进行货币补偿。

五、房屋装修及附着物补偿标准

房屋装饰及其他附着物等补偿标准参照《三亚市人民政府关于印发〈三亚市集体土地征收补偿安置管理规定（2013年修订）〉的通知》（三府〔2013〕43号）规定另行补偿。

六、青苗补偿标准

青苗补偿可根据《三亚市人民政府关于印发〈三亚市征收集体土地青苗补偿费和征地经费包干管理暂行办法〉的通知》（三府〔2011〕208号）规定采取按亩包干补偿，或按照《三亚市人民政府关于印发〈三亚市集体土地征收补偿安置管理规定（2013年修订）〉的通知》（三府〔2013〕43号）规定补偿。

七、土地征收补偿标准

被征收抱坡村委会集体土地补偿按《三亚市人民政府关于印发〈三亚市集体土地征收补偿安置管理规定（2013年修订）〉的通知》（三府〔2013〕43号）标准执行。

八、自《三亚市人民政府办公室关于三亚国际体育产业园项目配套用地土地调查有关事项的通知》（三府办〔2017〕143号）发布之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。

九、附则

（一）本方案自批准发布之日起施行。

（二）本方案中未尽事宜，或在项目征收补偿过程中需对本方案的有关内容进行调整的，由区政府会议讨论确定。

（三）本方案由吉阳区人民政府负责解释。
