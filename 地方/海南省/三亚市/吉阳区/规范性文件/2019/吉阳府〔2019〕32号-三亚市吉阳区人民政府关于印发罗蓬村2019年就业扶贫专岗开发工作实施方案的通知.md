# 三亚市吉阳区人民政府关于印发罗蓬村2019年就业扶贫专岗开发工作实施方案的通知

三亚市吉阳区人民政府

关于印发罗蓬村2019年就业扶贫专岗开发

工作实施方案的通知

罗蓬村委会：

为贯彻落实《海南省人力资源和社会保障厅印发<关于开发就业扶贫公益专岗的指导意见>的通知》（琼人社发〔2018〕503号）文件精神，充分利用就业扶贫公益专岗，有效帮扶建档立卡贫困户实现就业，结合我区实际，制定本实施方案。

一、开发对象

就业扶贫公益专岗作为一种特殊就业帮扶形式，罗蓬村委会要合理开发，用于安排符合条件、有劳动能力的建档立卡贫困家庭劳动力就业，重点帮扶安置“零就业”建档立卡户家庭劳动力。

二、开发原则及岗位期限

就业扶贫公益专岗人员管理按照属地管理原则，落实“谁开发、谁管理、谁负责”工作责任，坚持“公正、公平、公开”基本原则，实行实岗实名制登记，确定上岗人员名单，并进行公开公示，自觉接受群众的评议监督。就业扶贫公益专岗人选经公示无异议后，由罗蓬村委会与其签订《就业扶贫公益专岗服务协议》，及时安排上岗，服务期限一般不低于1年，最长不超过3年。

三、开发岗位数量及待遇

罗蓬村委会要对本辖区建档立卡户家庭劳动力全面摸底排查，了解本村内就业扶贫公益专岗开发需求，掌握群众就业能力和就业意愿，准确对接岗位类型、岗位数量、岗位文件，完成开发计划。

截至目前，2019年罗蓬村委会因需上报开发的就业扶贫公益专岗为19人次，3月份工作应全面开展，掌握群众就业能力和就业意愿，收齐符合条件群众的资料；6月份工作进展过半，至少安排10人上岗；9月份工作进度达到80%，至少累计安排16人上岗；12月份工作进度达到100%，完成19人上岗的目标。

就业扶贫公益专岗人员的岗位补贴按不低于三亚市当地最低工资标准执行（基本工资定为1600元/月/人），另按每月工作考核发放绩效700元/月/人。

罗蓬村委会要统一为就业扶贫公益专岗人员购买一定额度的商业意外伤害保险。购买商业意外伤害保险不得高于20元/月/人，资金从就业补助资金中列支。已经参加城乡居民养老保险和医疗保险的就业扶贫公益专岗人员，服务期间不再为其缴纳从业人员社会保险。

开发需求上报及工作计划下达后，因建档立卡户家庭劳动力需要增加开发岗位的，区人社局将上报市人社局根据实际情况给予追加计划。

四、开发管理

罗蓬村委会要加强就业扶贫公益专岗考核管理，明确岗位职责，落实绩效考勤制度，绩效考核与岗位补贴挂钩，确保“有岗有人有事做”，防止虚设岗位，变相发钱，服务期间应进行年度考核，考核不合格的，不再续订服务协议。区人社局要落实监督职责，督促指导罗蓬村落实岗位管理。

五、做好开发工作衔接

为进一步加强贫困劳动力公益性岗位管理，罗蓬村委会应于3月10日前，将原有安置贫困劳动力家庭的公益性岗位转化为就业扶贫公益专岗，转化后享受岗位补贴年限累计计算，岗位补贴标准原则上不低于原实发到手的工资待遇，并与新开发的就业扶贫公益专岗岗位补贴一致。

1.甲方应每周定期安排乙方本周服务内容，并记录本周服务事项完成情况，完成服务事项的应按规定支付服务补贴。甲方做好日常安全管理和教育工作，不安排乙方从事危险服务事项。

2.乙方按甲方要求提供服务，遇恶劣天气或危险场所应中断服务事项，并及时将发现的问题报告甲方，由甲方作出合理安排。

乙方在道路上服务时，应悬挂醒目标志、及时避让车辆，不得违规操作。

第六条 纠纷处理

因履行本服务协议发生的争议，双方本着合理合法、互谅互让的原则协商处理，协商不成的，可以向调解组织申请调解或向人民法院起诉。
