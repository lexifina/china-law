# 三亚市吉阳区人民政府关于印发2019年森林防火宣传工作方案的通知

三亚市吉阳区人民政府

关于印发2019年森林防火宣传工作方案的通知

区各村（居）委会：

为切实做好我区2019年森林防火宣传教育工作，提高公众的森林防火意识和法制观念，我区制定了《吉阳区2019年森林防火宣传工作方案》，现印发给你们，请结合实际，认真组织实施。

三亚市吉阳区人民政府

2019年3月25日

（此件主动公开）

吉阳区2019年森林防火宣传工作方案

为了切实做好我区2019年森林防火宣传教育工作，提高公众的森林防火意识和法制观念，普及森林防火常识，最大限度减少森林火灾发生，减少森林火灾损失，确保人民群众生命财产和森林资源安全，维护好青山绿水，按照省森防办要求及我市森林防火工作实际，特制定本方案。

一、指导思想

以党的十九大精神为指引，紧紧围绕建设国际旅游岛、建设生态文明、构建和谐社会、做好生态修复工作的主题，全面贯彻落实省森林防火指挥部和市委、市政府的重大安排部署及有关森林防火工作要求，认真贯彻“预防为主、积极消灭”的森林防火工作方针，严格执行《森林防火条例》和《海南省森林防火条例》等条例，充分发挥新闻媒体作用，利用现代信息手段，开展全方位、多渠道的森林防火宣传工作，努力营造“森林防火、人人有责”的森林防火氛围，确保全区森林资源安全，推进生态文明建设。

二、总体目标

森林防火宣传活动形式多样、突出主题，努力营造“森林防火、人人有责”的浓厚氛围，全面提高社会公众的森林防火意识，最大限度减少森林火灾的发生，为维护我区森林资源安全、确保“城市双修”和促进国际旅游岛建设又快又好地发展提供有力保障。

三、领导机构

成立吉阳区森林防火宣传工作领导小组，区人民政府副区长陈练任组长，区农业农村局局长任副组长，区委宣传部、区委政法委、区发展和改革委员会、区旅游和文化广电体育局、区生态环境局、区财政局、区教育局、区卫生健康委员会、区医疗保障局、区综合行政执法局、区民政局、区海洋水务局、区住房和城乡建设局、区应急管理局、吉阳消防大队、市公安局吉阳分局、各村（居）委会等主要负责人为成员。领导小组成员工作发生变动时，由对应的新任人员自然替换，履行其职责，不再另行发文。

领导小组下设办公室，办公室设在区农业农村局，办公室主任由区农业农村局局长兼任，办公室具体负责森林防火宣传的一切日常事务工作，统筹各村（居）委会组织开展工作。

四、宣传内容

（一）重点宣传《森林法》《森林防火条例》《海南省森林防火条例》等森林防火法律、法规，提高全社会森林防火的法律意识

加大学习教育力度，并结合自身实际，积极地开展《海南省森林防火条例》等森林防火法规的宣传工作，重点通过广播、电视、报刊、电影下乡等传统媒体和微博、论坛、手机短信等新媒介进行宣传，并设置宣传栏（警示牌）、印发宣传单（册）、张贴宣传标语、举办培训班、开展知识竞赛等各种形式，进一步明确各级政府和森林、林木、林地经营单位及个人应尽的义务与责任，不断提高依法行政、依法治火工作水平。

（二）积极开展森林防火宣传月活动

在高森林火险期, 要集中开展森林防火宣传月活动。3月份是全省森林防火宣传月，5月12日是国家第9个“防灾减灾日”。各单位要通过举办森林防火专题讲座、森林防火知识竞赛等活动，宣传森林火灾的危害性、危险性和突发性，切实提高林区群众的森林防火意识和安全意识。动员社会力量开展形式多样的森林防火宣传活动，扩大森林防火宣传辐射面，提高社会公众参与森林防火工作的积极性和主动性。

（三）深入开展森林防火巡回宣讲和“进村入户”宣传教育活动

组织森林防火宣传教育流动宣讲队，定期深入到林区及村落送法普法、专题培训、设立咨询点等。一是宣传普及野外用火的有关规定，以及林区用火审批流程，切实做到未经批准不用火，防范措施不到位不用火；二是宣传森林防火法律法规、预防与扑救以及安全避险等知识，着力提高全民森林防火意识；森林防火重点区域，要集中开展“进村入户”宣传教育，采取区各部门包村、村包组、组包户的组织形式，做到森林防火知识家喻户晓、人人皆知，真正形成依法治火、群防群治的良好氛围。

（四）广泛发动，开展“十个一”宣传

1.发布一个森林防火令，森林防火重点区域的各村（居）、农（林）场要根据森林火险等级变化，及时发布森林防火令，划定森林高火险区，规定森林高火险期。

2.签订一份森林防火目标责任书，各村（居）、农（林）场要及时与各社区、居委会、工作区负责人签订森林防火目标责任书，明确防火区域、宣传目标等，层层包干，责任到人，确保不留死角。

3.发送一张森林防火一封信，重点讲清森林防火的重要性，森林火灾的危害，预防森林火灾的基本要求和扑救火灾的基本常识。

4.召开一次森林防火社区居民大会，以社区或居委会为单位，在清明节前专门召开森林防火大会，强调野外用火管理，提高森林防火意识。

5.给学生讲一堂森林防火课，山区和临近林区中小学校，要普及性地上一次森林防火课，教育学生不在野外玩火，制止、举报野外违法用火，并以“小手拉大手”形式感化家长，实现森林防火群防群治。

6.开通一段时间的森林防火广播，在防火期内，防火区每个社区都要实行一天三广播，反复向居民宣传森林防火知识和安全遇险规范。

7.出动一辆森林防火宣传车，森林防火重点区域，要以各村（居）、农（林）场为单位，至少开通一辆森林防火宣传车，配注防火标语，配带高音喇叭，走街串户巡回宣传。

8.粘贴一批森林防火标语，要在交通要道、街区、进山路口，风景名胜区等重点位置，刷写或更新一批配目的森林防火警示标语。

9.印刷一批带有森林防火警示标志的门票，在“五一”黄金周到来之前，在森林旅游区要印刷一批有森林防火提示语的门票，提高游人防火意识。

10.编制一批森林防火知识读本，组织开展森林防火基本知识宣传活动，真正使森林防火家喻户晓，人人皆知。

（五）抓住关键，开展集中宣传

要围绕森林防火关键时段、关键部位和关键人群、有针对性地组织开展集中宣传教育。

1.关键时段：在森林高火险期（12月-次年5月）、旅游高峰期（“五一”和“十一”），野外用火多发期（春耕、秋收农忙季节、传统的烧荒、烧桔杆和炼山造林）、传统节日的危险期（清明、冬至等）等关键时段，要组织进行集中宣传。

2.关键部位：在重要设施、国有林场、自然保护区、森林旅游景区、封山育林区、海防林区、高速公路两旁等关键部位、要组织进行重点宣传。

3.关键人群：对痴呆傻人员、中小学生、进入林区旅游和从事经营活动的人员，要组织进行有针对性的宣传。

（六）在中小学校深化开展森林防火宣传教育活动

为增强中小学生森林火灾应对防范能力，各级森林防火部门要积极主动协调教育部门，将森林防火知识学习纳入年度教育计划，深入开展森林防火知识进校园“五个一”活动，即林区每所中小学校每学期由专人上一堂森林防火知识课、出一期图文并茂的森林防火知识板报、组织一次森林防火知识竞赛、印发一封《致学生家长的森林防火公开信》、发放一张森林防火温馨提示卡，形成教育一个孩子，带动一个家庭，影响全社会的良好局面。

（七）深入开展监管单位和重点部位的宣传工作

在春节、清明、冬至等重要时段，扫墓、上坟祭祀、燃放爆竹等活动大幅增多，野外火源管理难度加大，各级民政部门要积极倡导文明祭扫，教育群众移风易俗、破除迷信，用植树、送花等有益于保护生态环境的文明方式祭奠，广泛宣传因不文明祭祀引发森林火灾的典型案例，切实提高广大群众的森林防火意识。各级森林防火部门要协调旅游部门加强对游客的森林防火宣传教育，在景区入口、景点和沿线重点部位、宾馆（饭店）及各类服务网点等均要设置规范性防火宣传牌或防火标志，导游讲解要有森林防火内容。

（八）大力开展森林防火警示教育和先进典型宣传活动

大力宣传森林火灾典型案例，发挥它的警示教育作用。同时宣传森林防火工作中涌现出来的先进人物、先进个人、先进经验。各级森林防火部门要结合本地森林火灾典型案例，开展“追忆历史、警示后人”防灾减灾相关的警示教育宣传活动，制作播出森林防火警示教育片，唤起社会各界对森林防火工作的高度关注。各单位在及时报道打击查处野外违法用火行为、公布辖区内森林火灾案件查处、责任者追究、肇事者处理等情况的同时，还要积极挖掘、整理出一批森林防火先进集体、先进个人事迹，在电视、广播、网络等媒体上进行广泛宣传报道。

（九）积极开展日常时段的普遍宣传

要定期组织森林、林木、林地经营单位及个人进行专项森林防火知识培训；督促有关部门在主要交通要道、铁路、电力、电信线路沿线等森林防火危险地段，设置更新森林防火宣传牌（碑）；组织区（居委会）、村开设森林防火宣传栏；在各林区主要进山路口、旅游景区、自然保护区和森林公园等重点区域设置通俗易懂的森林防火宣传标语等，做到“时时讲宣传，处处是宣传”，大力普及森林防火知识。

五、工作要求

（一）高度重视，加强领导。要引起高度重视，牢固树立底线，建立健全森林防火宣传教育工作的领导机制和工作机制。要把宣传工作作为全年森林防火工作的一项重要内容来抓，切实加强组织领导，强化责任、落实到人、统一安排部署、明确责任划分、加强协调保障，形成立体式、全覆盖的宣传格局。

（二）认真组织，落实措施。要科学分析火险形势，根据实际情况，周密制定森林防火宣传工作方案，明确工作重点，细化工作措施，落实工作任务，把握宣传的政策、时机和节奏，在全社会营造“森林防火、人人有责”的浓厚氛围。

（三）加强协调、注重实效。各级防火部门要积极协调和沟通相关单位，运用多种手段、多种形式开展森林防火宣传教育工作。要坚持日常宣传与集中宣传相结合、媒体宣传与社会宣传相结合。

（四）认真总结，及时反馈。要认真总结，对宣传活动开展好的单位和个人予以上报表扬和奖励，对工作不扎实、走过场的要通报批评。要及时编发森林防火简报，推介各地宣传活动组织开展情况，将一些好的经验和做法要及时上报市防火办公室，以便在全市范围内进行报道推广。要充分利用主要媒体加强宣传报道，及时做好森林防火动态信息的收集、整理和上报工作。
