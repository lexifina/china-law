# 三亚市吉阳区人民政府关于对三亚市七届人大第五次会议第46号建议的会办意见

吉阳府函〔2019〕390号

三亚市吉阳区人民政府

关于对三亚市七届人大第五次会议第46号

建议的会办意见

市农业农村局：

韦良聪代表在市七届人大五次会议上提出的“关于农村五网设施建设的建议”收悉。根据要求，由我区协助贵局办理此建议，经研究，并与韦良聪代表沟通，现提出涉及我区工作的答复意见。

我区各职能部门正就五网设施建设开展实地调研，结合我区各行政村实际情况提出可行性意见，现我区正在筹备编制吉阳区五网基础设施建设专项规划。

以上意见，请你们在正式答复代表时参考。
