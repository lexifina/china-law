# 三亚市吉阳区人民政府对政协三亚市第七届委员会第四次会议第431号提案的会办意见

吉阳府函〔2019〕402号

三亚市吉阳区人民政府

对政协三亚市第七届委员会第四次会议

第431号提案的会办意见

市民族事务局：

市政协民宗委提出的《关于推进三亚“三月三”民族文化广场游览园建设的建议》提案收悉。根据要求，由我单位协助贵局办理此提案，经研究，现提出涉及我单位工作的答复意见。

该项目于2019年3月12日在海南省投资项目在线监管平台备案，关于项目的方案和选址等问题此前我区多次与项目业主沟通，并召开会议讨论，我区已在会上提出了指导性意见。

三亚市吉阳区人民政府

2019年7月1日
