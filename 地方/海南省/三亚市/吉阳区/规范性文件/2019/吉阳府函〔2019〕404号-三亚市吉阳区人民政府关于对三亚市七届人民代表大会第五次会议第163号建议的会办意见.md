# 三亚市吉阳区人民政府关于对三亚市七届人民代表大会第五次会议第163号建议的会办意见

吉阳府函〔2019〕404号

三亚市吉阳区人民政府

关于对三亚市七届人民代表大会第五次会议

第163号建议的会办意见

市住房和城乡建设局：

李洁代表在市七届人大五次会议上提出的“关于解决北部山区农村建筑垃圾收运的建议”收悉。根据要求，由我区协助贵局办理此建议，经研究，并与李洁代表沟通，现提出涉及我区工作的答复意见：

为加强建筑垃圾管理，推进我市建筑垃圾废弃物综合利用，三亚市政府于2017年11月5号发布了《三亚市建筑废弃物综合利用管理办法》（三府〔2017〕307号），该办法中对建筑废弃物处置许可、建筑废弃物运输管理、建筑废弃物综合利用处置管理、处罚条款等已经有了明确的规定。该办法对各区建筑废弃物处置已经形成政策性的指导，适用于我区北部山区建筑垃圾处理。

以上意见，请你们在正式答复代表时参考。
