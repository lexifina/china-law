# 三亚市吉阳区人民政府关于对三亚市七届人民代表大会第五次会议第167号建议的会办意见

吉阳府函〔2019〕405号

三亚市吉阳区人民政府

关于对三亚市七届人民代表大会第五次会议

第167号建议的会办意见

市住房和城乡建设局：

刘海龙代表在市七届人大五次会议上提出的“关于推行垃圾分类管理的建议”收悉。根据要求，由我区协助贵局办理此建议，在与刘海龙代表沟通的基础上，结合我区实际工作，现提出涉及我区工作的答复意见：

我区一直以来高度重视垃圾分类管理工作，各项工作逐步展开，具体如下：

一、推进试点单位垃圾分类工作。2015年我区在龙坡村、干沟村实施垃圾分类试点工作。

二、构建美丽乡村垃圾分类体系。2018年开始，结合我区美丽乡村建设，我区先后在中廖村、博后村、安罗村建设智慧垃圾屋，实施垃圾分类收集。

三、推进全区垃圾分类收集硬件设施建设。推动垃圾分类工作，硬件配备是取得成效的关键。2018年，我区计划在全区范围内建设95座四分类智慧垃圾屋，2019年底可全部建成并投入

使用。

四、拟计划推进全区中小学校园垃圾分类工作。垃圾分类是一个体系工程，应该从早从小培养。通过培养中小学生“保护环境，从我做起”意识，促使学生良好的垃圾分类习惯，进而影响推进家庭、社区，可以长效推进全区垃圾分类工作。目前，我区已制定全区中小学校园垃圾分类方案，下一步强力推进校园垃圾分类工作。

五、支持各街道、社区、农村开展垃圾分类。从2015年起，我区每年安排经费，购置分类垃圾桶免费发放到社区、农村居民户使用，目前已经发放了四个批次的分类垃圾桶，起到了一定的宣传作用。

下步我区将重点开展以下工作：

一、垃圾分类立法先行。只有推动垃圾分类立法工作，垃圾分类才有法可依，有章可循。

二、建立分类运输体系。按照市政府的四分类标准，调整清运车，建立可回收垃圾、有害垃圾、易腐垃圾、其他垃圾收运车辆体系，做到分类运输，分类处理。

三、推动垃圾分类外包工作。引入国内一些优秀的垃圾分类专业公司，建立覆盖全区的垃圾分类及再生资源回收利用体系，从宣传动员、设备投放、指导监督、垃圾处理等方面，建立健全辖区垃圾分类各项工作。

四、强化监督考核，成立垃圾分类工作领导小组，开展监督检查，建立督办制度，敦促问题整改。

以上意见，请你们在正式答复代表时参考。
