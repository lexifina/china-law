# 三亚市吉阳区人民政府对三亚市七届人大第五次会议第22号建议的会办意见

吉阳府函〔2019〕411号

三亚市吉阳区人民政府

关于对三亚市七届人大第五次会议

第22号建议的会办意见

市教育局：

赵日升代表在市七届人大五次会议上提出的“关于提高三亚市教育系统临聘非教学人员工作待遇的建议”收悉。根据要求，由我区协助贵局办理此建议，经研究，并与赵日升代表沟通，现提出涉及我区工作的答复意见。

我区教育系统始终将安保工作、卫生工作摆在重中之重的位置。在区委、区政府的大力支持下，吉阳区各公办学校的安保工作均按各单位需求统一购买社会专业服务，保安员工资标准为5.4万元含社保每年，超过三亚地区最低工资待遇标准；关于卫生工作，吉阳教育系统以“义务教育均衡发展”“创文巩卫”为契机，依据校情落实各项卫生指标，我区教育局根据学校申请，解决学校卫生经费不足问题。

以上意见，请你们在正式答复代表时参考。

三亚市吉阳区人民政府
