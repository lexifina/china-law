# 三亚市吉阳区人民政府对政协三亚市第七届委员会第四次会议第380号提案的会办意见

吉阳府函〔2019〕413号

三亚市吉阳区人民政府

关于对政协三亚市第七届委员会第四次会议

第380号提案的会办意见

三亚市自然资源和规划局：

林晓委员提出的“关于村（居）委会集体预留用地问题”的提案收悉。根据要求，由我区协助贵局办理此提案，现提出涉及我区工作的答复意见。

土地是衡量一个地区经济发展的根本，是农民生产、生活的保障，是促进社会经济的可持续发展的关键性问题。随着三亚市城市建设发展，为落实党中央、国务院将海南全面建设自由贸易区（港）的定位需要，市政府先后大量征收农民集体土地，使农民集体经济收入、乡村振兴战略受到极大的制约。林晓委员在政协三亚市第七届委员会第四次会议第380号提案提出几点建议，我们深有感触。

集体预留用地对失地农民而言，是造福于现在和将来子孙后代幸福生活的大事。吉阳区是一个拥有38个村（居）委会的行政区，自三亚市实施征收农民集体土地二十多年以来，少数村（居）委会充分利用本村集体经济安置留用地将集体经济盘活，

保障了被征收农民长远生计，统筹城乡发展，促进了新农村建设及社会发展和谐稳定。根据林晓委员提出的“村（居）委会集体留用地应遵循‘先预留后征用’的原则”，目前我市尚无相关政策性文件予以支撑。目前，对集体预留用地的审批和开发使用主要存在以下问题：

一、留用地选址难

留用地在本村经济组织集体土地选址，应符合《海南省征地安置留用地管理办法》（琼府办〔2012〕97号）的相关规定。以实际情况出发，寻找符合产业发展地块，经三分之二村民成员或三分之二村民代表同意选址。后市政府因有其他因素或城市发展需要，留用地发展建设规模规划设计跟不上周边项目设计规模的需要，需另行选址。

人民政府、各职能部门应形成网络机制，帮助解决失地农民异地选址难的问题。做到敢于担当，为失地农民今后生产、生活、保障经济发展，创建良好的工作机制和社会环境。

二、留用地从审批到使用的过程时间长

留用地的开发建设模式，根据留用地的地理位置不同建设模式的起点和要求不同。特别是在城市主城区的留用地，要体现三亚的特色，按自由贸易区（港）建设的高标准、严要求的地标性风格建设。同时办理留用地的开发使用，由于土地在办理农转用、用地指标申请难，导致留用地办理时间过长。

基于以上情况，建议：留用地的开发建设应由政府引导，并提供相应的工作信息平台，缩短、简化留用地的相关程序，优先考虑失地农民。

以上意见，请贵局在正式答复代表时参考。
