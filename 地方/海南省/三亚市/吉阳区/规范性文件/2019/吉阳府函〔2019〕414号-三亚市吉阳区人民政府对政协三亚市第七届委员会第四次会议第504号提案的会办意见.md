# 三亚市吉阳区人民政府对政协三亚市第七届委员会第四次会议第504号提案的会办意见

吉阳府函〔2019〕414号

三亚市吉阳区人民政府

对政协三亚市第七届委员会第四次会议

第504号提案的会办意见

市旅游和文化广电体育局：

张蕾委员提出的“关于开展城市社区体育活动，打造15分钟社区健身圈的提案”收悉。根据要求，由我区协助贵局办理此提案，经研究，现提出涉及我区工作的答复意见。

根据《国务院关于印发全民健身计划（2016-2020年）的通知》（国发〔2016〕37号）《海南省人民政府关于印发海南省全民健身实施计划（2016-2020年）的通知》（琼府〔2016〕12号）和《三亚市人民政府关于印发三亚市全民健身实施计划（2016-2020年）的通知》（三府〔2017〕138号）精神，结合我区实际制订了《吉阳区全民健身实施计划（2016-2020年）》，2017至2018年我区新建、改造、修缮12个球场，面积约6076平方米，采购了562件套健身器材安装至辖区内各村（社区），体育场地人均面积达到了1.83平方米，有效缓解了我区健身场地落后健身设施不足的情况。根据国家相关规定商业小区内的体育设施由开发商自行配套，也可供附近居民使用。目前临春岭森林公园、月川湿地公园、红树林生态公园、东岸湿地公园、白鹭公园、丰兴隆生态公园丰兴隆生态健康步道、临春河公园、鹿回头滨河

公园等场所体育设施均较为完善，属于免费向公众开放的市属公园。对此，吉阳辖区内的体育健身资源较为丰富。

目前存在的困难：

一、部分村（社区）没有新建或新增体育健身设施的场地。

二、体育投入经费有限。

下一步我区将逐步完善体育设施管理制度，做好做强体育管理工作，提高体育公共服务水平，积极协调相关部门在国家法定节假日，向公众逐步开放吉阳辖区内的各中小学体育资源。

以上意见，请你们在正式答复代表时参考。
