# 三亚市吉阳区人民政府对政协三亚市第七届委员会第四次会议第479号提案的会办意见

吉阳府函〔2019〕415号

三亚市吉阳区人民政府

对政协三亚市第七届委员会第四次会议

第479号提案的会办意见

三亚市交通运输局：

周士钧委员提出的“关于打造2.0版公共自行车系统，推动三亚交通治理”的提案收悉。根据要求，由我区协助你们办理此提案，经研究，现提出涉及我区工作的答复意见。

根据周士钧委员提出的打造2.0版公共自行车系统，推动三亚交通治理的建议，我区认为该提案可行，我区将积极配合贵局做好提案的落实。

以上意见，请你们在正式答复委员时参考。

三亚市吉阳区人民政府

2019年7月4日
