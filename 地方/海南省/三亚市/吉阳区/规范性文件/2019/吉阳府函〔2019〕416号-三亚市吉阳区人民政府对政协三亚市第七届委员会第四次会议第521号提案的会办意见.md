# 三亚市吉阳区人民政府对政协三亚市第七届委员会第四次会议第521号提案的会办意见

吉阳府函〔2019〕416号

三亚市吉阳区人民政府

对政协三亚市第七届委员会第四次会议

第521号提案的会办意见

三亚市交通运输局：

欧颖代表提出的关于“保护农村公路路产路权行为的建议”的提案收悉。根据要求，由我区协助你们办理此提案，经研究，现提出涉及我区工作的答复意见。

根据欧颖委员提出的关于“保护农村公路路产路权行为的建议”我区认为该提案非常好，我区将积极配合市交通局做好工作。

并提出以下意见：

一、大力宣传农村公路路产路的有关政策法规。各属地村委会积极参与其中，发现有破坏路产路权的行为，及时向区交通运输局反映或举报。

二、建议村民利用12345热线或微信，向市政府热线投诉，多种渠道保护农村公路路产路权。

以上意见，请你们在正式答复委员时参考。

三亚市吉阳区人民政府
