# 三亚市吉阳区人民政府对政协三亚市第七届委员会四次会议第376号提案的会办意见

吉阳府函〔2019〕419号

三亚市吉阳区人民政府

对政协三亚市第七届委员会四次会议

第376号提案的会办意见

市农业农村局：

台盟三亚市委会提出的“关于借鉴台湾经验，以乡村旅游推动我市乡村振兴”的提案收悉。根据要求，由我区协助贵局办理此提案，经研究，现提出涉及我区工作的答复意见。

一、逐步完善美丽乡村配套设施

改造旅游标识导视系统，制作景区、景点导览牌39套、交通指引牌7套、景点名牌、景点介绍牌43套、宣传公告牌42套、特色农产品展示牌111套等中廖村旅游设施路牌。文体设施投入建设方面：中廖村、大茅村、海罗村、田独村、春光社区、罗蓬村、同心家园五期等13处配置健身设施201件；建设榆红村二组篮球场、荔枝沟派出所三人制篮球场；建设干沟、落笔、新红、新村、大茅村5个文体活动室；修缮田独“万人坑”纪念碑并整治周边环境。旅游厕所建设方面：在中廖村建设2座旅游厕所，目前已投入使用。

二、开展全域旅游美丽乡村旅游扶贫培训

共组织全域旅游美丽乡村旅游扶贫培训8场，带领村民实地

考察槟榔谷扶贫街进行现场教学，分享村民在美丽乡村建设中可

借鉴的经验，提高村民建设美丽乡村意识。

三、成立吉阳区民宿行业协会

吉阳区民宿行业协会已于2019年4月正式成立，旨在整合优质的区域民宿资源，规范民宿行业经营管理，尤其是引导乡村民宿发展走向专业化、制度化、规范化道路。

四、引进优质企业开展美丽乡村建设

我区先后在中廖村、大茅村、博后村、红花村引入如华侨城集团、远洋集团等优质企业，采取企业与农民合作的方式，带动和促进村民脱贫致富。

以上意见，请你们在正式答复代表时参考。

三亚市吉阳区人民政府
