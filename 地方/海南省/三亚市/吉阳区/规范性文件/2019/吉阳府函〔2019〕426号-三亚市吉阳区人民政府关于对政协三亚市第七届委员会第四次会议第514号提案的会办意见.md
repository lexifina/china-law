# 三亚市吉阳区人民政府关于对政协三亚市第七届委员会第四次会议第514号提案的会办意见

吉阳府函〔2019〕426号

三亚市吉阳区人民政府

关于对政协三亚市第七届委员会第四次会议

第514号提案的会办意见

市住建局：

曾启宏委员提出的“关于解决我市乡村教师保障性住房建议”的提案收悉。根据要求，由我单位协助你们办理此提案，经研究，现提出涉及我单位工作的答复意见。

建议贵局在我市保障性住房的统筹规划、建设及分配过程中，充分考虑乡村教师住房保障问题，以解决乡村教师的实际困难，进一步稳定乡村学校师资队伍。我区将发挥属地职能，积极配合贵局做好保障性住房建设、分配相关工作。

三亚市吉阳区人民政府

2019年7月5日
