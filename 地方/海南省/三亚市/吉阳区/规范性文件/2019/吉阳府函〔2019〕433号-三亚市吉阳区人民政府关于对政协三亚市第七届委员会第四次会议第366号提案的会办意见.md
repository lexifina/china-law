# 三亚市吉阳区人民政府关于对政协三亚市第七届委员会第四次会议第366号提案的会办意见

吉阳府函〔2019〕433号

三亚市吉阳区人民政府

关于对政协三亚市第七届委员会第四次会议

第366号提案的会办意见

市农业农村局：

郭森委员提出的“关于推进美丽乡村建设，治理利用我市农村闲置房的建议”的提案收悉。根据要求，由我区协助贵局办理此提案，经研究，现提出涉及我区工作的答复意见。

我区美丽乡村项目不对农村闲置房屋进行改造，主要是对农村基础设施、雨污水管道铺设、强弱电管线下地和环境整治等基础设施进行改造。

以上意见，请你们在正式答复代表时参考。

三亚市吉阳区人民政府
