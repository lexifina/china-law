# 三亚市吉阳区人民政府关于对政协三亚市第七届委员会第四次会议第463号提案的会办意见

吉阳府函〔2019〕445号

三亚市吉阳区人民政府

关于对政协三亚市第七届委员会第四次会议

第463号提案的会办意见

市农业农村局：

九三学社三亚市委会提出的“关于用文化‘引擎’推动三亚乡村振兴的建议”收悉。根据要求，由我区协助贵局办理此提案，经研究，现提出涉及我区工作的答复意见：

九三学社三亚市委会关于以文化“引擎”推动三亚乡村振兴提案中的四条建议：一是重建文化自信，为乡村振兴奠定“根基”。二是留下乡村记忆，为乡村振兴搭建“骨架”。三是突出地域特色，为乡村振兴涂抹“亮色”。四是利用网络科技，为乡村振兴安装翅膀。这些建议都非常好，对我区乡村振兴有着一定的指导意义。乡村振兴是一个系统工作，而乡村的文化振兴是乡村振兴的灵魂，对做好乡村振兴工作起到基础性作用。

目前，我区正在积极开展乡村振兴工作，我们会把乡村文化振兴放在重要的位置，注重培养乡土文化意识，凝聚村民的精神力量，培育人情味浓厚、邻里互助、诚实互信、集体意志强的乡村文化。同时加强对本土文化遗产保护，突出地域特色，支持差

异化布局，以“一村一韵，一村一乡愁、一村一特色”的要求，将本土文化元素融入旅游产品中，做好乡土文化和旅游的融合。

三亚市吉阳区人民政府
