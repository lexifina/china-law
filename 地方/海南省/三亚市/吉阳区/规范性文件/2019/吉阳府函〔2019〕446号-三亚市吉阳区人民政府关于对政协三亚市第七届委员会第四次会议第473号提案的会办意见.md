# 三亚市吉阳区人民政府关于对政协三亚市第七届委员会第四次会议第473号提案的会办意见

吉阳府函〔2019〕446号

三亚市吉阳区人民政府

关于对政协三亚市第七届委员会第四次会议

第473号提案的会办意见

市公安局：

农工委三亚市委会提出的“关于外来人口管理问题的建议”提案收悉。根据要求，由我区协助贵局办理此提案，经研究，现提出涉及我单位工作的答复意见。

一、关于改善外来人口居住条件的问题

针对《提案》第二条第（一）项“改善外来人口居住条件”，为进一步解决外来人口居住问题，建议由辖区派出所、村（社区）配合做好外来人口及出租房的申请、批准、登记等工作。

二、关于外来人口接受职业培训的问题

（一）根据《海南省人民政府印发<海南省关于当前和今后一个时期进一步促进就业工作的若干措施>的通知》（琼府〔2018〕56号）文件第八条措施内容，2019年1月1日至2020年12月31日，参加失业保险1年以上的企业在职职工取得职业资格证书（职业技能等级证书）或专业技术职业资格证书的，可申请技术技能提升补贴。取得初级（五级）、中级（四级）和高级（三级）职业资格证书（职业技能等级证书）或专业技术职业资格证书的，补贴标准分别为800元、1300元和1800元。

（二）外来人口符合以上条件参加职业培训取得职业资格证书的，可向参保地人力资源社会保障部门申请，所需资金由失业保险基金列支。补贴申请时间为2019年1月1日至2020年12月31日。

（三）不符合第一项条件的外来人口，暂无相关政策支持参加职业培训。

三、关于解决外来人口子女上学的问题

依据《海南省教育厅关于做好中小学招生入学工作的通知》《三亚市义务教育阶段免试就近入学工作实施方案》等相关文件要求，我区对辖区内外来务工随迁子女实施就近入学、电脑派位原则，安排入学。截至目前，已连续两年安排外来务工随迁子女1400余人。2019年我区继续实行外来务工随迁子女摇号入学政策，具体方案已在“吉阳教育”公众号向社会发布，最大化保障外来务工随迁子女入学权益。

四、关于提供外来人口医疗健康服务的问题

为了提高外来人口归属感，提供外来人口医疗健康服务方面，我区已落实诸多措施。2016年5月印发的《关于发放吉阳区孕产妇健康管理对象孕检补助的通知》已明确外来人口在吉阳区辖区内已连续住满6个月及以上、或居住不满6个月但有长期居住趋向的法定内怀孕的孕产妇（需提供租房合同等相关证明材料），于孕早期12周内，孕中期第16-20周、21-24周，孕晚期第28-36周、37-40周，可在居住地卫生院各进行1次免费孕检，并获得补助（整个孕期共计可享受5次免费孕检并获得共计500元的补助）。

目前，我区正在全力推进基层医疗机构标准化建设，南丁、红花、中廖、博后、榆红等村级健康服务室均完成财评和网上公开招标，即将开工建设；博后村健康服务室目前已经动土开工；南新第四作业区已经确定选址。一村一室标准化建设将极大丰富我区的医疗资源，居住在我区内的本地居民和外来人口都将同等的享受更多医疗健康服务。

三亚市吉阳区人民政府
