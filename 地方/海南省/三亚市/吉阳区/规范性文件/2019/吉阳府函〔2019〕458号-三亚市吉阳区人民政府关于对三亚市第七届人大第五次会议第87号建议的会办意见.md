# 三亚市吉阳区人民政府关于对三亚市第七届人大第五次会议第87号建议的会办意见

吉阳府函〔2019〕458号

三亚市吉阳区人民政府

关于对三亚市第七届人大第五次会议

第87号建议的会办意见

三亚市交通运输局：

王树清代表在市第七届人大第五次会议上提出的“关于在同心家园五期建设大型立体停车场的建议”收悉。根据要求，由我区协助你们办理此建议，经研究，并与王树清代表沟通，现提出涉及我区工作的答复意见。

由于王树清代表在提案中未提供拟建设立体停车场的选址或用地坐标，在不影响规划强制实施内容及近期启动项目建设的前提条件下，选址位置用地性质不占用道路用地等，建议征得相关职能部门同意后办理相关审批手续，我区原则给予支持，积极配合贵局做好提案的落实。

以上意见，请你们在正式答复代表时参考。

三亚市吉阳区人民政府

2019年7月17日
