# 三亚市吉阳区人民政府关于对三亚市第七届人大第五次会议第188号建议的会办意见

吉阳府函〔2019〕474号

三亚市吉阳区人民政府

关于对三亚市第七届人大第五次会议

第188号建议的会办意见

三亚市交通运输局：

洪漫宁代表在市第七届人大第五次会议上提出的“关于在荔枝沟同心路周边建设立体停车楼的建议”收悉。根据要求，由我区协助你们办理此建议，经研究，并与洪漫宁代表沟通，现提出涉及我区工作的答复意见。

一、根据洪漫宁代表提出关于在同心路周边建设立体停车楼和撤销同心路路面停车位规划的建议，经核查：该用地占地面积10亩，土地利用总体规划为城镇用地；土地利用现状为城市；该用地未办理土地确权登记。目前，贵局正在开展《三亚市中心城区立体停车楼近期建设规划》编制工作，建议由贵局结合荔枝沟同心路周边停车情况，在规划中统筹考虑,在不影响规划强制实施内容及近期启动项目建设的前提条件下，选址位置用地性质不占用道路用地等，征得相关职能部门同意后办理相关审批手续。

二、关于设置相关交通指示灯的建议，市交警支队已在同心路与荔枝沟交叉口设置了移动红绿灯，并进行了交通组织渠化，以此保障道路交通安全有序。

三、迎宾路与同心路交汇处的护栏不宜打开。原因如下：

（一）迎宾路学院路T字路口与迎宾路落笔洞路T字路口，两个路口相邻相近，打开护栏增设路口会增加车流冲突点，造成新的交通问题；

（二）同心路区域常住人口密集，迎宾路与同心路交汇处设有斑马线供行人过街，此处打开护栏，行人过街安全将得不到保障，市交警支队下一步工作将对该处进行交通组织优化，确保行人过街安全。

以上意见，请你们在正式答复代表时参考。
