# 三亚市吉阳区人民政府关于对市第七届人大第五次会议第153号建议的会办意见

吉阳府函〔2019〕493号

三亚市吉阳区人民政府

关于对市第七届人大第五次会议

第153号建议的会办意见

三亚市住房和城乡建设局：

方晓龙代表在市第七届人大第五次会议上提出的“关于政府对物业公司完善监管工作的建议”收悉。根据要求，由我单位协助你们办理此建议，经研究，现提出涉及我单位工作的答复意见。

我单位将各区域划分成立工作巡查小组，不定期对小区巡查物业服务情况，主要巡查目的：一、对未达到服务标准且管理失职的物业企业，我单位将对此下达限期整改通知书，并核查后续整改情况；二、对小区物业存在违法侵占、违规建筑的问题，我单位将联合执法部门强制执法拆除；三、对迟迟未配合整改的物业公司，将联合物业管理协会将该物业公司列入企业黑名单。

以上意见，请你们在正式答复代表时参考。

三亚市吉阳区人民政府
