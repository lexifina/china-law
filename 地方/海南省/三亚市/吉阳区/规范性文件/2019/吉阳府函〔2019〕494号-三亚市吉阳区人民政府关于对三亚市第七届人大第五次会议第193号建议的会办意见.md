# 三亚市吉阳区人民政府关于对三亚市第七届人大第五次会议第193号建议的会办意见

吉阳府函〔2019〕494号

三亚市吉阳区人民政府

关于对三亚市第七届人大第五次会议

第193号建议的会办意见

市应急管理局：

欧阳细金代表在市七届人大五次会议上提出的“关于编写三亚市风险隐患清单保障公共安全的建议”收悉。根据要求，由我区协助你们办理此建议，经研究，现提出涉及我区工作的答复意见。

一是在加大公共安全教育力度，增强居民安全意识方面：积极开展全民安全宣传教育和培训工作，加大公共安全教育力度。通过积极开展安全生产月活动、举办安全生产知识及应急救护培训班、组织开展应急演练活动及技能竞赛等活动，从而不断增强居民安全意识。二是在防范城市公共安全风险隐患方面：全面落实安全监管和隐患排查治理工作，有针对性的对非煤矿山、危险化学品、烟花爆竹、道路交通、建筑施工、人员密集场所、涉海涉水等各类重点企业及经营场所进行安全监管和排查整治，防患于未然，有效遏制各类事故的发生；通过集中开展电动自行车消防安全综合治理、大型商业综合体消防安全专项整治、城乡电力设施安全隐患专项排查整治等专项整治活动，有效降低城市公共安全风险。三是城市网格化管理方面：结合我区实际，认真制定

《吉阳区安全生产网格化管理工作实施方案》，合理划分网格、明确工作任务、落实监管责任、健全基层安全监管网络和完善安全生产责任体系，全面提升安全生产事故防控水平，努力减少一般事故，坚决遏制较大以上事故，为我区打造“宜居城区”提供坚强的安全保障。四是在风险管控方面：积极与各级职能部门沟通、协调和衔接，整合现有安全管控系统，实现信息与资源的有效整合，充分发挥风险协同管控作用的最大化。

以上意见，请你们在正式答复代表时参考。
