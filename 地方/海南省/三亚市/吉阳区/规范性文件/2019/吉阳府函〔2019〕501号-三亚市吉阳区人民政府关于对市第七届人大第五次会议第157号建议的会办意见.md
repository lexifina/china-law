# 三亚市吉阳区人民政府关于对市第七届人大第五次会议第157号建议的会办意见

吉阳府函〔2019〕501号

三亚市吉阳区人民政府

关于对市第七届人大第五次会议

第157号建议的会办意见

三亚市住房和城乡建设局：

杜斌代表在市第七届人大第五次会议上提出的“关于加强对三不管小区管理的建议”收悉。根据要求，由我单位协助你们办理此建议，经研究，现提出涉及我单位工作的答复意见。

目前我区已完成辖区“三无”小区摸排工作，计划选取下洋田人大宿舍楼、荔枝沟原政府宿舍楼、吉阳区政府宿舍、3个小区所作为试点开展整治工作，主要内容有：一、指导该类住宅小区成立业主委员会；二、协助选聘物业管理企业，通过公开招标形式引入正规物业企业对小区实行专业化长效管理机制；三、协助修缮“三无”小区原有硬件配套设施、园区环境，确保该类小区达到“四保”标准。下一步，我区将在试点工作基础上，分批次推进辖区“三无”小区改造工作。

以上意见，请你们在正式答复代表时参考。

三亚市吉阳区人民政府
