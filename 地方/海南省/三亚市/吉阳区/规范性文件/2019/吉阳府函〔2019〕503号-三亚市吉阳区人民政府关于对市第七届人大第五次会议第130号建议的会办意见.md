# 三亚市吉阳区人民政府关于对市第七届人大第五次会议第130号建议的会办意见

吉阳府函〔2019〕503号

三亚市吉阳区人民政府

关于对市第七届人大第五次会议

第130号建议的会办意见

三亚市住房和城乡建设局：

张海林代表在市第七届人大第五次会议上提出的“关于加强城市垃圾资源化利用管理的建议”收悉。根据要求，由我单位协助你们办理此建议，经研究，现提出涉及我单位工作的答复意见。

一、《三亚市建筑废弃物综合利用管理办法》对建筑废弃物处置许可、建筑废弃物运输管理、建筑废弃物综合利用处置管理、处罚条款等已经有了明确的规定。

二、在棚改建筑垃圾处理方面，我区严格按照《三亚市建筑废弃物综合利用管理办法》，要求各棚改项目房屋拆除实施单位将建筑垃圾运往三亚市建筑废弃物综合利用厂。目前，东岸棚改项目建筑垃圾清运工作已完成，无新的建筑垃圾产生。月川、临春、海罗、抱坡等棚户区改造项目的建筑垃圾清运工作正在有序推进中。下一步我区将按市、区有关建筑垃圾管理规定，认真督促相关责任企业做好棚改项目建筑垃圾清运工作。

三、在乡村生活垃圾处理方面，我区已经建立了完整的清扫保洁清运体系，乡村环境卫生管理工作取得了良好的成效。乡村垃圾分类工作也在开展，目前已经在博后、中廖、龙坡、干沟等

乡村开展垃圾分类试点工作，下一步将在全区农村逐步推广。

以上意见，请你们在正式答复代表时参考。

三亚市吉阳区人民政府
