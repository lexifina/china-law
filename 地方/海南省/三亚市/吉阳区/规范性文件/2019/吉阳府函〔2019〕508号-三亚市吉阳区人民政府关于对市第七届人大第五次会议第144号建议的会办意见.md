# 三亚市吉阳区人民政府关于对市第七届人大第五次会议第144号建议的会办意见

吉阳府函〔2019〕508号

三亚市吉阳区人民政府

关于对市第七届人大第五次会议

第144号建议的会办意见

市自然资源和规划局：

周进管代表在市第七届人大第五次会议提出的“关于建设海南自贸区、自贸港的城市化建设征地的建议”收悉。根据要求，由我单位协助你们办理此建议，经研究，现提出涉及我单位工作的答复意见。

根据三亚市经济社会发展需要，2017年市政府将抱坡村整村纳入棚户区改造计划。抱坡村委会坚决支持市政府的决策，积极配合抱坡村棚户区改造项目，尤其是三横路（抱坡段）市政道路、市文化中心、市体育中心等项目用地征收补偿工作，为我市发展做出了很大贡献。因抱坡村民绝大多数以土地为生，为避免村民失地后缺乏有效的谋生手段和稳定的收入来源引发诸多社会问题，根据《海南省征地安置留用地管理办法》（琼府办〔2012〕97号）第五条、第六条和《三亚市集体建设用地开发利用管理暂行办法（2014年修订）》（三府〔2014〕103号）第十二条之规定，抱坡村棚户区改造项目实际需征收抱坡村集体土地3350亩，按照市政府确定的5%的比例计算，应给抱坡村安排集体预留用地167.5亩，供抱坡村集体建设租赁住房、仓储物流、购物餐饮

等经营性产业。目前，抱坡棚改预留建设用地选址已基本确定，但该地块土地性质变更工作尚未完成，建议贵局按省、市有关程序，加快办理抱坡村集体预留用地划拨手续，同时给予考虑置换榕根、东岸已办证的预留用地造成两个村集体经济损失及补偿的问题，让村民得到长期的可持续的利益保障。

以上意见，请你们在正式答复代表时参考。

三亚市吉阳区人民政府
