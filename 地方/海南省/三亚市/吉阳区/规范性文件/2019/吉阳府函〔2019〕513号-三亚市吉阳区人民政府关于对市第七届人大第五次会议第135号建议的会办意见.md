# 三亚市吉阳区人民政府关于对市第七届人大第五次会议第135号建议的会办意见

吉阳府函〔2019〕513号

三亚市吉阳区人民政府

关于对市第七届人大第五次会议

第135号建议的会办意见

三亚市住房和城乡建设局：

洪漫宁代表在市第七届人大第五次会议上提出的“关于落实建筑废弃物处理工作的建议”收悉。根据要求，由我单位协助你们办理此建议，经研究，现提出涉及我单位工作的答复意见。

一、《三亚市建筑废弃物综合利用管理办法》对建筑废弃物处置许可、建筑废弃物运输管理、建筑废弃物综合利用处置管理、处罚条款等已经有了明确的规定。

二、我区棚改、拆违建筑垃圾清运责任单位多次反映，市政府指定的建筑垃圾消纳场所（瑞泽建筑垃圾处理厂）容纳量有限，日消耗量不足，影响建筑垃圾清运工作进度，建议对瑞泽建筑垃圾处理厂进行升级改造。

三、建议贵局在瑞泽建筑垃圾处理厂周边选址设立建筑垃圾堆放点，缓解该厂对建筑垃圾的日产日消压力，同时从顶层设计上进一步完善，明确职责、分工、标准，推动我市建筑垃圾资源化利用管理。

以上意见，请你们在正式答复代表时参考。

三亚市吉阳区人民政府

2019年8月2日
