# 三亚市吉阳区人民政府关于对市第七届人大第五次会议第175号建议的会办意见

吉阳府函〔2019〕529号

三亚市吉阳区人民政府

关于对市第七届人大第五次会议

第175号建议的会办意见

市住建局：

王芳代表在市七届人大第五次会议上提出的“关于推广‘气代柴薪’工程，提升我市城乡气网基础建设的建议”收悉。根据要求，由我区协助你们办理此建议，经研究，并与王芳代表沟通，现提出涉及我区工作的答复意见。

根据三亚长丰天然气公司的反馈，目前三亚市燃气管网建设工作为全市布局，尚未按区域制定工作方案、实行分区管理。有关燃气管网建设计划应由市住建部门与燃气公司对接。

以上意见，请你们在正式答复代表时参考。

三亚市吉阳区人民政府

2019年8月8日
