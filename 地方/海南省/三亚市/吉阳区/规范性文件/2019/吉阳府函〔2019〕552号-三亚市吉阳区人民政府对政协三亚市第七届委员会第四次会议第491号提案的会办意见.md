# 三亚市吉阳区人民政府对政协三亚市第七届委员会第四次会议第491号提案的会办意见

吉阳府函〔2019〕552号

三亚市吉阳区人民政府

对政协三亚市第七届委员会第四次会议

第491号提案的会办意见

三亚市住房和城乡建设局：

民盟三亚市委会提出《关于对三亚市行道树木进行修剪的建议》的提案收悉。根据要求，由我单位协助贵单位办理此提案，经研究，现提出涉及我区工作的答复意见。

一、科学制定修剪方案

我区严格按照《三亚市园林绿化植物修剪技术规范》（三园环〔2007〕64号）制定和执行行道树的修剪方案。同时把日常养护修剪和防风修剪相结合，在修剪过程中遵循“一知、二看、三剪、四拿、五处理”的程序。行道树一般统一保留净空高度3M，修剪的树形以伞形为主，修剪时一般是剪去树木的病枝、残枝、下垂枝、霸王枝、重叠枝、不雅观枝、疏通过于集中密实的营养消耗枝条。高大乔木则要剪掉与架空电线相接触的枝条，遇到遮挡指示牌或红绿灯尽量在保持树形整体效果时提高净空或修剪通透，增加其通透度。截至目前为止我区修剪行道树品种有雨树、椰子树、小叶榕、高杆蒲葵、中东海枣、小叶榄仁、印度紫檀等共计约2万多株，基本完成总量的60%修剪工作。迎宾路、凤凰路、鹿回头路等路段基本完成，其它各主干道仍然按计

划在修剪中，预计2个月内可以完成全部修剪工作。

二、加强专业技术培训

7月份我区园林绿地所安排所骨干管理人员及外包单位骨干人员参加了三亚市住房和城乡建设局举办的园林树木修剪培训班，共计100多人次。

以上意见，请你们在正式答复代表时参考。
