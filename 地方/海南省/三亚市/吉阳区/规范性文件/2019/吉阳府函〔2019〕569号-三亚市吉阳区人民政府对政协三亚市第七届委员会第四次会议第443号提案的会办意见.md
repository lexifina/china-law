# 三亚市吉阳区人民政府对政协三亚市第七届委员会第四次会议第443号提案的会办意见

吉阳府函〔2019〕569号

三亚市吉阳区人民政府

对政协三亚市第七届委员会第四次会议

第443号提案的会办意见

三亚市住房和城乡建设局：

孙斌委员提出的“关于打造三亚城市文化公园的提案”收悉。根据要求，由我区协助你们办理此提案。经研究，由于建设生态湿地公园，需因地制宜，根据提案中提到的文化公园无法提供相关材料，现将吉阳湿地公园建设依据报送作为参考。

吉阳湿地公园建设应为周边居民提供多样化的休闲场所和活动场地，全方位打造多层次和立体式的景观空间，注重艺术性和具有时代感的体现和融合，兼顾生态保护与节能减排的精品湿地公园。

一、项目建设不仅符合三亚市经济与社会发展需要和政策要求，还符合三亚市总体规划要求。

二、项目建设完善该区域的公共配套设施，提高片区的绿化率，有利于美化城市生态环境，提升城市形象，改善投资环境。

三、项目建设规模确定适宜，选址合理，设计方案成熟可行，工程技术可靠，建设条件优越，公共配套设施完善，为开发建设奠定了良好的基础。

四、项目建设资金来源有保障，且综合效益高。

五、项目是一项利国利民的民心工程，是吉阳区乃至三亚市经济建设、旅游业发展的需要。

三亚市吉阳区人民政府
