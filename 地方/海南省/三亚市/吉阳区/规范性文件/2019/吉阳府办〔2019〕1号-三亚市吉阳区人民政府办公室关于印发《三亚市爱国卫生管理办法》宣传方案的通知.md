# 三亚市吉阳区人民政府办公室关于印发《三亚市爱国卫生管理办法》宣传方案的通知

三亚市吉阳区人民政府办公室

关于印发《三亚市爱国卫生管理办法》宣传方案的通知

区各有关单位，各村（居）委会：

根据市政府办《关于印发三亚市爱国卫生管理办法宣传方案的通知》（三府办〔2018〕346号）要求，结合我区实际，制定了《三亚市爱国卫生管理办法》宣传方案，现印发给你们，请认真组织实施。

三亚市吉阳区人民政府办公室

2019年1月2日

（此件主动公开）

《三亚市爱国卫生管理办法》宣传方案

《三亚市爱国卫生管理办法》（以下简称《办法》），已经市人大常委会通过、省人大批准，自2019年1月1日起正式实施。为做好《办法》的宣传、贯彻实施，助力“创文巩卫”工作，提高我区爱国卫生工作水平，提升居民的幸福感、获得感，促进社会经济协调发展，根据市政府办印发的《关于印发三亚市爱国卫生管理办法宣传方案的通知》（三府办〔2018〕346号），并结合我区实际，制定本宣传方案。

一、宣传组织领导

成立区宣传工作领导小组，具体负责《办法》的宣传、解读工作。

组 长：蔡曜泽（区人民政府副区长）

副组长：陈小鹤（区卫计局局长）

雷历轮（区委宣传部副部长）

组 员：区司法局、区法制办、区爱卫办各1名分管领导。

二、宣传内容

《三亚市爱国卫生管理办法》

三、宣传时间

2019年1月至6月

四、宣传任务及分工

（一）发放宣传资料

2018年12月29日前，统一将《办法》宣传资料发放到区爱卫会成员单位、各村（居）委会。区司法局利用宣传车下村（居）委会、田间地头进行广播宣传，为期半个月。（责任单位：区爱卫办、区司法局）

（二）开设宣传专栏

利用“创文巩卫，建设美丽三亚”网络版面和区爱卫会各成员单位行业微信公众号，不间断宣讲、解读《办法》。（责任单位：区委宣传部、区爱卫会各成员单位）

（三）组织培训讲解

2019年1月份，组织对辖区内网格员进行《办法》学习培训。各职能部门按照谁执法谁普法的要求对行业进行普法。（责任单位：区司法局、区法制办、区爱卫办、区爱卫会各成员单位）

（四）营造宣传氛围

各单位利用电子屏播放宣传标语，各村（居）委会统一设置固定的《办法》宣传栏，营造浓烈的宣传氛围。〔责任单位：区爱卫会各成员单位、各村（居）委会〕

（五）开展系列宣讲

1.结合“4.13”讲话周年纪念活动，紧扣“爱国卫生活动月”主题展开宣讲。2019年4月份，利用“4.13”讲话周年纪念活动和“爱国卫生活动月”契机集中开展1次《办法》普法宣传，定点定员发放宣传资料。（责任单位：区司法局、区爱卫办、区法制办）

2.结合“创文巩卫”督查现场解读、宣讲。利用“创文巩卫”督查时机，现场执法、宣传解读，提高群众对《办法》的知晓率。（责任单位：区创文巩卫办）

（六）规范行业执法

结合《三亚市爱国卫生管理办法》等法律法规内容，各相关执法单位要开展执法知识培训，集中学习，熟练掌握条款内容，规范执法。（责任单位：区城管局、区卫计局、区旅游文体局、区交安局、区农林局、区海水局、区环保局、区工商局、区各食药监所、吉阳国土分局、市公安局吉阳分局）

（七）开展考评工作

2019年6月份，由区爱卫办组织《办法》学习、实施考评工作，并将考评结果予以通报。（责任单位：区法制办、区爱卫办）

五、宣传工作要求

（一）加强组织领导。各单位领导要高度重视，切实将宣传贯彻《办法》工作列入重要议事日程，全面部署，精心组织，确保宣传工作领导到位，落实到位。

（二）强化监督考评。按照责任分工，区司法局、区法制办、区爱卫办要组织对宣传贯彻《办法》情况进行专项督查，并对工作开展不力的单位予以指导。各相关单位要及时收集、整理学法守法用法情况。

（三）认真梳理总结。各单位要做到宣传学习有计划、分步骤落实，用法执法要吃深吃透。《办法》宣传既要讲究形式，更要注重结果，要对宣传覆盖范围、普法人数、宣传效果等情况及时总结，并于每月月底前将本月《办法》宣传活动开展情况报区爱卫办，确保《办法》的真正落地、生根、见效。
