# 三亚市吉阳区人民政府办公室关于印发三亚市吉阳区2019年自然资源卫片执法工作实施方案的通知

三亚市吉阳区人民政府办公室

关于印发三亚市吉阳区2019年自然资源卫片执法工作实施方案的通知

各相关单位：

为维护自然资源开发利用和保护秩序，做好吉阳区2019年自然资源卫片执法工作，《三亚市吉阳区2019年自然资源卫片执法工作实施方案》已经区政府同意，现印发给你们，请认真组织实施。

三亚市吉阳区人民政府办公室

2019年7月11日

（此件主动公开）

三亚市吉阳区2019年自然资源卫片

执法工作实施方案

为进一步维护自然资源开发利用和保护秩序，全面贯彻《自然资源部办公厅关于开展2019年卫片执法工作的通知》（自然资办发〔2019〕26号）和《海南省自然资源和规划厅关于开展海南省2019年卫片执法工作的通知》（琼自然资察〔2019〕1号）及《三亚市人民政府办公室关于印发三亚市2019年自然资源卫片执法工作实施方案的通知》（三府办〔2019〕99号）要求，做好吉阳区2019年自然资源卫片执法工作，结合实际，制定本工作方案。

一、指导思想及重要意义

三亚市吉阳区自然资源卫片执法工作要以习近平生态文明思想和习近平总书记关于自然资源管理的重要论述为指导，要“像保护眼睛一样保护生态环境，像对待生命一样对待生态环境”，始终坚持绿水青山就是金山银山，坚持“源头严防、过程严管、后果严惩”，坚持“用最严格制度最严密法治保护生态环境”，坚持严格规范公正文明执法，严肃惩治自然资源违法行为，严守生态红线、永久基本农田红线和城镇开发边界。

抓好三亚市吉阳区卫片执法工作是落实习近平总书记关于自然资源管理的重要论述的基本要求，是为三亚市自由贸易区（港）创造良好营商环境的必要条件，是事关三亚市年度新增开发利用自然资源约束性指标的增减和长远发展的大事。

二、执法对象

2019年吉阳区自然资源卫片执法工作的对象包括市自然资源和规划局下发的2018年度发现的土地、矿产卫片执法图斑和2019年发现的土地、矿产卫片执法图斑。

三、主要任务

（一）认真核查卫片执法图斑，及时发现、制止、报告违法行为

对市自然资源和规划局下发的三亚市吉阳区2018年度发现的土地、矿产卫片执法图斑和2019年发现的土地、矿产卫片执法图斑，进行内外业核查，及时发现、制止、报告各类自然资源及城乡规划违法行为。

（二）严肃查处整改违法行为

切实加大执法力度，把吉阳区自然资源违法行为查处整改落实结果作为衡量卫片执法工作成效的第一标准。对吉阳区各类自然资源及城乡规划违法行为，须依法依规严肃查处。坚持既查事也查人，既查违法事实也要查决策过程。依法该立案的坚决立案，该拆除的坚决拆除，该没收的坚决没收，该移送的坚决移送。对违反党纪政纪的，坚决并及时移送纪检监察机关；对涉嫌犯罪的，坚决并及时移送公安、检察机关。对生态环境造成影响的，应开展环境恢复治理和复耕复绿，并消除安全隐患。违法行为未依法处理到位的，通报给相关部门不得办理相关行政许可。对属于其他执法部门职责范围的，要及时移交并做好记录。同时要突出重点，采取联合查处方式，严厉打击违法行为。对于违法主体，可将其违法行为纳入社会信用体系。对违法性质恶劣、造成严重后果的单位或个人，要列入“黑名单”。发现涉黑涉恶线索，及时报告市扫黑办及时查处。

（三）落实主体责任、严肃约谈问责

严格按照自然资源和城乡规划法律法规的规定，对违法占用永久基本农田和自然保护地面积5亩以上或一般耕地10亩以上的，将即时开展警示约谈或启动问责。对违法严重单位和个人，由区政府批转区委监察委开展警示约谈、启动问责，督促有关单位和个人落实依法依规使用自然资源。

（四）建立健全长效机制

结合国家自然资源卫片执法工作新政策和新要求，按照三亚市跨领域综合行政执法改革工作要求，推进执法下沉到各村（居）委会，同时建立健全整治违反自然资源和城乡规划法律法规的行为网格化管理工作机制，实行党委负责制落实村（居）委会日常监管和查处整改责任，实现吉阳区自然资源违法行为“零增长”，管控更加高效。

四、组织机构及职责分工

为加强组织领导，决定成立三亚市吉阳区2019年自然资源卫片执法工作领导小组，负责自然资源卫片执法工作的统筹安排以及重大事项处置的审议工作，并建立联席会议制度，共同推进违反自然资源和城乡规划法律法规行为的查处整改工作。领导小组成员因工作和职务变动不再担任成员的，由继任者接替。

（二）各成员单位职责分工

1.吉阳国土资源管理分局牵头负责组织开展吉阳区2019年自然资源卫片执法工作，具体职责如下：

（1）领取市自然资源和规划局下发的吉阳区2019年（年度+季度）卫片执法图斑，将内外业核查数据结果上报市自然资源和规划局。

（2）做好各成员单位卫片工作数据的汇总、上报工作，与区综合行政执法局共同指导、并督查各成员单位按照职责分工落实违法图斑核查、立案处罚、拆除、复耕复绿等分类整改情况，逐个图斑建立整改档案。

（3）将填报卫片信息系统的查处整改数据和卫片执法查处整改情况报市自然资源和规划局。

（4）开展吉阳区2019年自然资源卫片执法工作进行全方位、多形式、多层次宣传培训活动。

（5）负责与市自然资源和规划局对接和沟通，牵头做好迎接国家级、省级、市级对吉阳区卫片执法工作的抽查、督导、验收工作。

2.区综合行政执法局按照职责要求，与吉阳国土资源管理分局共同做好吉阳区2019年自然资源卫片执法工作。具体职责如下：

（1）与吉阳国土资源管理分局共同指导并督查各成员单位按照职责分工落实违法图斑查处整改。

（2）坚持依法该立案的坚决立案，该拆除的坚决拆除，该没收的坚决没收，该移送的坚决移送。

3.区财政局负责落实三亚市吉阳区2019年自然资源卫片执法工作后勤保障工作，将自然资源卫片执法工作所需工作经费纳入年度财政预算，做好区卫片执法工作经费保障工作。

4.区发展和改革委员会负责核查涉嫌违反自然资源或城乡规划法律法规的违法项目的备案，配合区卫片执法工作的整改。

5.区生态环境局负责核查涉嫌违反自然资源或城乡规划法律法规的违法项目的环评审批，配合区卫片执法工作的整改。

6.区住房和城乡建设局不得对涉嫌违反自然资源或城乡规划法律法规的违法项目进行审批同意,同时应加快推进负责的公共基础项目用地手续的办理，配合做好区卫片执法工作的整改。

7.区农业农村局应加强农业生产项目、南繁项目及其配套附属设施用地指导，对符合设施农用地手续图斑及时办理设施农用地备案手续，配合做好区卫片执法工作的整改，对拆除的违法图斑及时实施复耕复绿。

8.市公安局吉阳分局负责对非法买卖自然资源以及其他涉嫌犯罪的自然资源违法行为组织查处，依法追究违法当事人的刑事责任；对妨碍、阻扰、围攻、殴打有关部门执法人员的违法当事人应及时出警并依法查处。

9.南新农场公司负责加强农场土地的属地监管，引导场地内项目建设及职工依法依规使用自然资源，配合区政府对卫片执法图斑的外业核查及分类查处整改拆除工作。

10.各村（居）委会实行书记负责制。书记作为村委会第一责任人，要率先垂范，充分发挥基层党支部的战斗堡垒作用，绝不能知情不报、默认、暗中支持、置若罔闻，任由破坏耕地等自然资源现象的发生，必须积极履行党员干部保护自然资源的职责，做到及时发现、制止、报告违反自然资源和城乡规划法律法规的行为，极力配合并支持吉阳区2019年卫片执法的核查、整改、拆除及复耕复绿工作。

五、工作步骤

（一）初核梳理卫片执法图斑（2019年4月至12月）

根据市自然资源和规划局下发的图斑，进行内外业核查、梳理，并上报。

（二）图斑查处整改（2019年4月至12月）

1.根据国家卫片政策要求及法律法规的规定负责组织开展辖区内卫片执法图斑的外业核查、调查、制止、立案处罚、拆除等分类查处整改。须在2019年5月30日前完成对2018年度卫片执法图斑立案查处和拆除等分类查处整改工作；2019年6月30日前完成对2019年第一和第二季度卫片执法图斑立案查处和拆除等分类查处整改工作；在2019年9月30日前完成对2019年第三季度卫片执法图斑立案查处和拆除等分类查处整改工作；在2019年12月30日前完成对2019年第四季度卫片执法图斑立案查处和拆除等分类查处整改工作。

2.其他成员单位根据《三亚市吉阳区2019年自然资源卫片执法工作实施方案》明确的职责分工主动履行职责。

3.吉阳国土资源管理分局和区综合行政执法局共同指导并督促各成员单位按照职责分工落实违法图斑查处整改。

（三）迎接督导和抽查（2019年5月至12月）

自然资源部、国家自然资源督察广州局、省自然资源和规划厅、省国土资源监察总队将根据卫片执法工作部署，在2019年5月至12月期间不定期的开展随机抽查、督导、成果审核。各成员单位要通力配合，严格按照本方案时间节点和查处整改工作要求落实整改工作，做好实地督导、抽查检查、督察的各项准备工作。

（四）迎接验收（2019年6月、2020年1月）

按照卫片执法工作部署，2019年6月，省自然资源和规划厅组织相关部门对三亚市2018年度的卫片执法工作进行验收。2020年1月，省自然资源和规划厅组织相关部门对三亚市2019年卫片执法工作进行验收。

1.吉阳国土资源管理分局负责将辖区内卫片执法图斑分类查处整改情况填入卫片执法系统，按照一个图斑一宗整改档案的原则建立图斑整改档案。

2.各成员单位将涉及卫片执法系统的分类查处整改数据和情况及时报送吉阳区2019年自然资源卫片执法工作领导小组办公室汇总，经吉阳区2019年自然资源卫片执法工作领导小组审核后，报市自然资源和规划局。

（五）成果上报

在2019年6月20日前向市自然资源和规划局上报2018年度卫片执法查处整改情况；在2020年1月20日前，向市自然资源和规划局报送2019年卫片执法图斑查处整改情况。

卫片执法工作中发现的军用土地图斑，要填写《军用土地登记表》，以机要件单独上报（一式三份）市自然资源和规划局。

六、工作要求

自然资源卫片执法工作是自上而下主动开展监管自然资源依法依规使用的专项工作，事关三亚自由贸易区（港）推进的一项重要任务。各有关职能单位、各村（居）委会要树立“党中央精神、国家立场、权责对等、严起来”的理念，正确处理好政治与业务、权力和责任、当前与长远、前任与后任、局部与全局等关系、严字当头，敢于较真、敢于碰硬、敢于担当，采取强有力措施抓好落实。

（一）提高政治站位，发挥党委组织领导作用。各成员单位要严密组织领导，高度重视、提高政治站位、主动作为、形成统一战线、做好人员、经费、装备等保障工作。

（二）加大宣传，形成浓厚的舆论氛围。要充分运用报纸、电视、电台、网络等新闻媒体对自然资源卫片执法工作进行全方位、多形式、多层次的正面宣传。

（三）创新工作方式，形成合力。各成员单位要创新工作方式，将自然资源卫片执法工作与吉阳区深化生态环境六大专项整治工作行动相结合、与整治违法建筑三年攻坚行动相结合，形成合力，让管控更高效，查处更严格。

（四）严密政治纪律，严肃开展约谈问责。突出“后果严惩”，落实“严起来”要求，坚持源头严防、过程严管、后果严惩，要更加严格查处违法案件，要既查事也查人，既查违法事实也查决策过程。一要将坚持刀刃向内原则，对玩忽职守、瞒案不报、压案不查或者弄虚作假的单位和个人，将依法依纪律严肃处理。二要开展约谈。违法严重的各职能单位、村（居）委会，要进行警示约谈，督促整改落实。三要严肃问责。

（五）坚持新增违法实行零容忍。对于新增违法行为实行零容忍，2019年新发现自然资源违法行为，追究当事人的直接责任、党政领导干部责任，该问责的严肃问责。对于历史遗留问题，建立问题台账，积极稳妥推进解决。

（六）严肃查处整改违法行为。切实加大执法力度，把自然资源违法行为查处整改落实结果作为衡量卫片执法工作成效的第一标准。要通过卫片执法信息系统及时更新填报查处情况、行政处罚（行政处理，下同）落实情况以及整改落实结果，直至消除违法状态。已经通过拆除、复耕、毁闭等方式消除违法状态的，要上传现场照片；已经完善审批手续的，要填报审批文件文号、批准时间等相关信息。

（七）严格按照时间节点完成各项工作任务。各成员单位要克服困难，切实提高政治站位、主动作为，严格按照时间节点完成调查、立案处罚、拆除复耕、补办相关手续等工作任务。
