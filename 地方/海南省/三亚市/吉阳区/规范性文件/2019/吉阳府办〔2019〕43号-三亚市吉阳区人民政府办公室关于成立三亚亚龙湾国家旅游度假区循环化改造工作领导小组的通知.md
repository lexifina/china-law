# 三亚市吉阳区人民政府办公室关于成立三亚亚龙湾国家旅游度假区循环化改造工作领导小组的通知

三亚市吉阳区人民政府办公室

关于成立三亚亚龙湾国家旅游度假区

循环化改造工作领导小组的通知

区政府直属各单位，各相关单位：

《三亚亚龙湾国家旅游度假区循环化改造工作领导小组机构设置方案》已经区政府同意，现印发给你们，请认真贯彻执行。

三亚市吉阳区人民政府办公室

2019年12月18日

（此件主动公开）

三亚亚龙湾国家旅游度假区

循环化改造工作领导小组机构设置方案

按照省工信厅《关于印发海南省推进园区循环化改造工作方案的通知》（琼工信节〔2018〕123号）等相关文件要求，启动三亚亚龙湾国家旅游度假区循环化改造实施方案的编制工作，为了推动三亚亚龙湾国家旅游度假区循环化改造工作进展，制定本方案。

领导小组成员如有工作岗位变动，由接任者自动递补，不再另行发文调整。

三亚亚龙湾国家旅游度假区循环化改造工作领导小组主要职责为：负责三亚亚龙湾国家旅游度假区循环化改造工作的决策、指导和监督。

（二）三亚亚龙湾国家旅游度假区循环化改造工作领导小组办公室

领导小组下设办公室（设在亚龙湾综合服务中心），办公室主任由黄国梁兼任，办公室副主任由亚龙湾综合服务中心副主任莫壮岳兼任，工作人员由成员单位抽调组成。

三亚亚龙湾国家旅游度假区循环化改造工作领导小组办公室主要职责为：负责日常协调工作，完成领导小组交办工作。

二、具体工作任务

（一）领导小组办公室配合节能减排主管部门加强节能减排管理工作，按职能职责及有关要求落实有关措施。

（二）领导小组办公室配合环保主管部门不断加大环境保护监督管理力度，杜绝偷排现象，保证所有现役污染治理设施正常运行，各类污染物稳定达标排放。

（三）三亚亚龙湾国家旅游度假区循环化改造实施方案获批复实施后，领导小组办公室配合循环化改造主管部门定期对各主要企业循环化改造工作履职情况进行评价考核，考核结果上报领导小组，并予以通报。结合亚龙湾工作实际情况，采取适当的奖励或处罚措施。

三亚市吉阳区人民政府办公室
