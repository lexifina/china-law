# 三亚市吉阳区人民政府办公室关于启用“三亚市吉阳区人民政府办公室”印章的函

三亚市吉阳区人民政府办公室

关于启用“三亚市吉阳区人民政府办公室”

印章的函

区各相关单位：

根据《中共三亚市吉阳区委办公室 三亚市吉阳区人民政府办公室 关于印发<三亚市吉阳区机构改革实施方案>的通知》（吉委办发〔2019〕12号）文件精神，我办决定自2019年3月15日起启用“三亚市吉阳区人民政府办公室”新印章，同时停止使用旧的印章。
