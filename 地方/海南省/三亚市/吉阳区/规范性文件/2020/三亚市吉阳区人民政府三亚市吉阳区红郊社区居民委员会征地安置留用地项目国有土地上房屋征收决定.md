# 三亚市吉阳区人民政府三亚市吉阳区红郊社区居民委员会征地安置留用地项目国有土地上房屋征收决定

三亚市吉阳区人民政府

三亚市吉阳区红郊社区居民委员会征地

安置留用地项目国有土地上房屋征收决定

根据三亚市土地利用总体规划，城市规划和项目建设需要，依照《国有土地上房屋征收与补偿条例》（国务院令第590号）《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）以及三亚市人民政府《关于同意将原红沙B-007地块（现为控规HS02-07地块）3.924亩土地安排作为吉阳区红郊社区居民委员会征地安置留用地的批复》（三府函〔2020〕57号）等规定，决定收回原红沙B-007地块（现为控规HS02-07地块）3.924亩土地作为吉阳区红郊社区居民委员会安置留用地，对征收范围内的房屋与地上附作物等予以征收补偿，保障被征收人的合法权益。征收范围内的单位和个人应当积极配合做好征收补偿工作。

一、项目名称

吉阳区红郊社区居民委员会征地安置留用地项目

二、征收范围

项目四至范围：东至天涯水业地界，南至榆亚路地界，西至荔枝山庄地界，北至红郊居委会（荔枝山庄租用）地界，具体范

围四至及坐标以项目规划红线的实际勘测定界为准。征收面积3.924亩，具体数据以实际测量为准。

三、征收人

三亚市吉阳区人民政府

四、征收实施单位

三亚市吉阳区项目推进服务中心

五、征收期限

从2020年7月31日始至2020年10月27日

六、行政复议和行政诉讼权利

被征收人如不服本决定，可在本决定书送达之日起60日内向三亚市人民政府申请行政复议，或者6个月内向三亚市中级人民法院提起行政诉讼。

七、其他事项

（一）征收工作实施期间，在征收范围内不得实施新建、扩建、改建房屋、改变房屋及土地用途的行为；违反规定实施的，不予补偿。

（二）征收补偿依据及补偿标准根据《国有土地上房屋征收与补偿条例》（国务院令第590号）《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）以及参照三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定（2013年修订>的通知》（三府〔2013〕43号）等相关规定执行。

（三）征收实施单位与被征收人在征收补偿签约期限内达不成补偿协议或被征收的房屋权利人不明确的，由征收实施单位报请征收人按照国有土地上房屋征收补偿的有关规定作出补偿决定，并在征收范围内予以公告。被征收人在补偿决定规定期限内仍不搬迁的，征收人将依法申请人民法院强制执行。

（四）任何组织和个人对本次征收补偿工作中违反《国有土地上房屋征收与补偿条例》等规定的行为，都有权向有关部门举报。

三亚市吉阳区人民政府
