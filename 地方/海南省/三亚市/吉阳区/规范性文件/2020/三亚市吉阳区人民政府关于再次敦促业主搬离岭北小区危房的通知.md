# 三亚市吉阳区人民政府关于再次敦促业主搬离岭北小区危房的通知

三亚市吉阳区人民政府

关于再次敦促业主搬离岭北小区危房的通知

岭北小区全体业主：

岭北小区7栋房屋已被检测机构鉴定为D级危房且无修缮价值。近期，部分业主反映小区房屋墙体渗水、天花板水泥块脱落等情况加剧，之前我区已多次要求小区业主尽快搬离危房，但仍有部分业主不予配合，坚持居住在危房中。为维护小区业主的人身财产安全，我区再次敦促小区全体业主尽快搬离危房，另觅住所。

下一步，我区将尽快出台岭北小区危房改造方案，协调市相关职能部门确定安置房源，加快启动小区危房改造工作。

三亚市吉阳区人民政府

2020年1月9日
