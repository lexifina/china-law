# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（SY2019--120号用地、用地面积为0.8001公顷）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区田独村民委员会：

为实施我市城市规划和市政公用项目建设需要，市政府以《关于三亚市人才城水质净化厂工程项目土地调查有关事项的通知》（三府办〔2019〕64号）文拟征收三亚市吉阳区田独村民委员会农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市吉阳区，用地面积为0.8001公顷（土地现状为：水田、其他园地）。

二、拟征收土地的用地性质为公用工程用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如对上述拟征收土地有关事项有异议，我区将在30天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2020年6月28日
