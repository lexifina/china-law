# 三亚市吉阳区人民政府关于对市第七届政协第六次会议第722号提案的会办意见

吉阳府函〔2020〕258号

三亚市吉阳区人民政府

关于对市第七届政协第六次会议第722号

提案的会办意见

市生态环境局：

李松海委员提出的关于加强海洋白色污染防治建议的提案收悉。根据要求，由我区协助贵局办理此提案，经研究，现提出涉及我区工作的答复意见如下：

针对李海松委员提出的建议，我区拟制了《吉阳区海岸线垃圾污染专项治理实施方案》《“人人齐参与、海洋需要您”保护海洋环境宣传活动策划方案》。并依照方案与三亚海警局吉阳工作站建立联合工作机制，加强对海上非军事、非渔业船舶垃圾海上排放的监督管理。

下一步，我区将根据方案严抓落实，建立吉阳区海洋环保教育基地，组织志愿者、市民、游客开展沙滩垃圾清捡活动等，将方案内容一一落在实处，保证质量，不走过场。

附件：1.吉阳区海岸线垃圾污染专项治理实施方案

2. “人人齐参与 海洋需要您”保护海洋环境宣传活动策划方案

3.三亚市吉阳区生态环境局三亚海警局吉阳海警工作站关于加强海洋生态环境联合治理协作办法

三亚市吉阳区人民政府
