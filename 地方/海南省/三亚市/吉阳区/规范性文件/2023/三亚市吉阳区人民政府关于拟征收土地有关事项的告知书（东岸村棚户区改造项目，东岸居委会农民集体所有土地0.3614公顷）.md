# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（东岸村棚户区改造项目，东岸居委会农民集体所有土地0.3614公顷）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

吉阳区东岸社区居民委员会：

根据三亚市总体规划和项目建设需要，市政府以《关于三亚市东岸村棚户区改造项目土地调查有关事项的通知》（三府办〔2016〕222号）等文件拟征收三亚市吉阳区东岸居委会农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区内，用地面积为0.3614公顷（土地利用现状为城市）。

二、拟征收土地用地规划性质为二类居住用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如对上述拟征收土地有关事项有异议，我区将在30天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2023年9月7日
