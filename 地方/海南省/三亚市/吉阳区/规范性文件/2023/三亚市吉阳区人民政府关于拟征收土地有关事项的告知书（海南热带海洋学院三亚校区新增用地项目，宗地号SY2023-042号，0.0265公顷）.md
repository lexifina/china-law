# 三亚市吉阳区人民政府关于拟征收土地有关事项的告知书（海南热带海洋学院三亚校区新增用地项目，宗地号SY2023-042号，0.0265公顷）

三亚市吉阳区人民政府

关于拟征收土地有关事项的告知书

三亚市吉阳区落笔村委会：

根据三亚市总体规划和项目建设需要，市政府以《关于海南热带海洋学院三亚校区新增用地土地调查有关事项的通知》（三府办〔2016〕10号）等文件拟征收三亚市吉阳区落笔村委会农民集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于吉阳区内，用地面积为0.0265公顷（土地利用现状为水田、其他草地、村庄）。

二、拟征收土地用地规划性质为二类居住用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如对上述拟征收土地有关事项有异议，我区将在30天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市吉阳区人民政府

2023年7月6日
