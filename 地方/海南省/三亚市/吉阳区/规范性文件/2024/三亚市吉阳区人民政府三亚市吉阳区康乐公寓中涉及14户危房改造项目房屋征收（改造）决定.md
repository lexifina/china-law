# 三亚市吉阳区人民政府三亚市吉阳区康乐公寓中涉及14户危房改造项目房屋征收（改造）决定

三亚市吉阳区人民政府

三亚市吉阳区康乐公寓中涉及14户危房改造项目房屋征收（改造）决定

为做好吉阳区康乐公寓危房改造工作，消除安全隐患，改善人民群众的居住条件，提升城市形象，根据国家、省市有关文件规定，结合改造区域实际，决定对康乐公寓国有土地上涉及李龙华、史云升、乔晓贞、龙小春、李桂华、李红光、王仲恒、王让伟、王景祥、李星霏、陈冠霖、李佰华、韩晓坤的14户房屋及其附着物实施危房征收（改造）并对权利人进行安置，涉及的国有土地使用权同时收回。

一、项目名称

三亚市吉阳区康乐公寓中涉及14户危房改造项目

三、实施主体

三亚市吉阳区人民政府

四、改造工作实施部门

三亚市吉阳区住房和城乡建设局

五、补偿安置标准

《三亚市吉阳区康乐公寓中涉及14户危房改造项目补偿安置方案》

六、征收（改造）期限

自本决定书发布之日起7日内

七、行政复议和行政诉讼权利

被改造房屋权利人如不服本决定，可在本决定送达60日内向三亚市人民政府申请行政复议，或者在6个月内向三亚市中级人民法院提起行政诉讼。

八、其他事项

（一）本决定规定的14户不适用《三亚市吉阳区康乐公寓D级危房改造项目补偿安置方案》（吉阳府〔2023〕131号）。

（二）危房改造工作实施期间，在危房改造范围内不得实施新建、扩建、改建房屋、改变房屋及用途的行为；违反规定实施的，不予补偿。

（三）危房改造项目安置补偿依据及标准参照《国有土地上房屋征收与补偿条例》（国务院第590号令）等相关规定执行。

（四）房屋改造工作实施部门与被改造房屋权利人达不成补偿协议或被改造房屋权利人不明确的，由房屋改造实施部门报请实施主体按照危房改造方案作出补偿决定，并在改造范围内予以公告。被改造房屋权利人在补偿决定规定期限内不搬迁的，实施主体将依法申请人民法院强制执行。

（五）任何组织和个人对本次危房改造项目补偿安置工作违反《国有土地上房屋征收与补偿条例》《城市危险房屋管理规定》等规定的行为，都有权向有关部门举报。
