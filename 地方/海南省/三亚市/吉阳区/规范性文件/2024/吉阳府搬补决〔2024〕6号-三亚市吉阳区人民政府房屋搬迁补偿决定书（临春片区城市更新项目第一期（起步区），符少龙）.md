# 三亚市吉阳区人民政府房屋搬迁补偿决定书（临春片区城市更新项目第一期（起步区），符少龙）

三亚市吉阳区人民政府

房屋搬迁补偿决定书

搬迁人：三亚市吉阳区人民政府，住所地：三亚市吉阳区迎宾路483号，法定代表人：杨鸿钧，职务：区长。

被搬迁人：符少龙，男，黎族，1977年10月4日出生（公民身份证号：4602xxxxxxxxxx5333），现居住临春三组二路一巷。

因实施三亚市临春片区城市更新项目第一期（起步区）工作需要，依据《三亚市吉阳区人民政府关于印发三亚临春片区城市更新项目实施方案的通知》（吉阳府〔2023〕75号）、《三亚市吉阳区人民政府关于印发三亚临春片区城市更新搬迁补偿安置方案的通知》（吉阳府〔2023〕76号）、《三亚市吉阳区人民政府关于临春片区城市更新项目第一期（起步区）搬迁公告》等规定，三亚市吉阳区人民政府对三亚临春片区城市更新项目第一期（起步区）用地范围内的房屋及地上附着物实施搬迁补偿。

经核查：被搬迁房屋位于三亚市吉阳区临春社区居民委员会临春三组二路一巷，总共1栋，房屋结构为框架结构，片区号为24，房屋总建筑面积为162.55平方米，房屋面积丈量号为2­312，权属人为符少龙，家庭人口为4人。在签约期限内，搬迁人与被

搬迁人已多次协商，被搬迁人仍未签订搬迁补偿安置协议。

为保证临春片区城市更新项目第一期（起步区）的顺利推进，保障被搬迁人的合法权益，根据《三亚市吉阳区人民政府关于印发三亚临春片区城市更新搬迁补偿安置方案的通知》（吉阳府〔2023〕76号）等相关规定作出补偿决定如下：

一、对位于海南省三亚市吉阳区临春社区居民委员会临春三组二路一巷框架结构，总建筑面积为162.55平方米的房屋实施搬迁。

二、被搬迁人符少龙可在货币补偿、回迁安置、货币补偿和回迁安置三种补偿方式中选择一种进行补偿：

（一）货币补偿方式

由搬迁人向被搬迁人支付下列补偿费用：

1.被搬迁人为《三亚市吉阳区人民政府关于印发三亚临春片区城市更新搬迁补偿安置方案的通知》（吉阳府〔2023〕76号）规定的第1类安置对象，人口为4人，应得安置房屋建筑面积240平方米，按就地安置安置房市场评估价20070元/平方米（划拨地）给予一次性货币补偿，补偿金额为4816800元。

2.被搬迁人现有居住房屋面积扣除240平方米安置房屋面积后，对剩余现有居住房屋面积，按以下标准予以补偿：

被搬迁人现有居住房屋面积为162.55平方米，房屋结构为框架结构。被搬迁人现有居住房屋面积在525平方米以内（含525平方米）部分扣除其安置房屋面积后剩余面积为框架结构房屋0平方米，补偿标准为每平方米1350元且给予100%奖励补偿，补偿金额0元；装修部分按被搬迁人现有居住房屋建筑面积162.55平方米、每平方米800元给予补偿，补偿金额130040元。

现有居住房屋面积在525平方米以上、1000平方米以内（含1000平方米）部分为 / 平方米，补助标准为每平方米550元，补助金额为 / 元；1000平方米以上部分不予补偿。

附着物及青苗部分补偿36000.2元。

3.被搬迁人搬迁补助

被搬迁人自愿选择货币补偿方式进行房屋搬迁补偿安置，搬迁人支付给被搬迁人3600元的一次性搬迁补助。

4.以上1—3项补偿金额合计4986440.2元。

5.若被搬迁人在本决定书规定的期限内签订补偿协议并腾空房屋的，房屋面积在525平方米以上1000平方米以内（含1000平方米）部分为 / 平方米，给予每平方米250元的搬迁补贴，补贴金额为 / 元。

6.集体经营性产业用房

被搬迁人属于第1类安置对象，人口为4人，安排人均10平方米（商业、旅馆、商务办公）或人均25平方米（租赁住宅）的临春社区居民委员会产业经营性用房，产权归临春社区居民委员会集体经济组织所有，被搬迁人参与收益分成。

（二）回迁安置方式

1.被搬迁人为《三亚市吉阳区人民政府关于印发三亚临春片区城市更新搬迁补偿安置方案的通知》（吉阳府〔2023〕76号）规定的第1类安置对象，人口为4人，应得安置房屋建筑面积为60平方米/人，给予安置240面积的房屋（其中就地安置面积每户最高面积不超过120平方米，超出面积选择异地安置）。

2.被搬迁人现有居住房屋面积扣除240平方米安置房屋面积后，剩余现有居住房屋面积，按以下标准补偿：

被搬迁人现有居住房屋面积为162.55平方米，房屋结构为框架结构。被搬迁人现有居住房屋面积在525平方米以内（含525平方米）部分扣除其安置房屋面积后剩余面积为框架结构房屋0平方米，补偿标准为每平方米1350元且给予100%奖励补偿，补偿金额0元；装修部分按被搬迁人现有居住房屋建筑面积162.55平方米、每平方米800元给予补偿，补偿金额130040元。

现有居住房屋面积在525平方米以上、1000平方米以内（含1000平方米）部分为 / 平方米，补助标准为每平方米550元，补助金额为 / 元；1000平方米以上部分不予补偿。

附着物及青苗部分补偿36000.2元。

3.搬迁补助和临时过渡安置费

被搬迁人选择回迁安置方式进行房屋搬迁补偿安置，搬迁人支付给被搬迁人每户7200元（含搬迁和回迁）的一次性搬迁补助；被搬迁人家庭人口计4人，其中 / 人选择回迁安置方式，搬迁人支付给被搬迁人每户每月租房补贴4000元、每人每月生活补贴500元，由被搬迁人自行过渡。临时过渡期限，自被搬迁人腾空房屋当月起算至安置房交付当月止。

4.若被搬迁人在本决定书规定的期限内签订补偿协议并腾空房屋的，房屋面积在550平方米以上1000平方米以下部分为 / 平方米，给予每平方米250元的搬迁补贴，补贴金额为 / 元。

5.集体经营性产业用房

被搬迁人属于第1类安置对象，人口为4人，安排人均10平方米（商业、旅馆、商务办公）或人均25平方米（租赁住宅）的临春社区居民委员会产业经营性用房，产权归临春社区居民委员会集体经济组织所有，被搬迁人参与收益分成。

（三）货币补偿和回迁安置相结合

被搬迁人选择货币补偿和回迁安置相结合的安置补偿方式的，参照上述货币补偿和回迁安置的标准进行补偿。

三、限被搬迁人在本决定书送达之日起7日内与搬迁人（联系地址：三亚临春片区城市更新项目领导小组办公室311号，联系人：蒲兵，联系电话：0898­88236433）办理房屋搬迁补偿手续和移交手续，签订搬迁安置补偿协议，搬离并腾空位于三亚市吉阳区临春社区居民委员会临春三组二路一巷房屋。

四、被搬迁人未在上述期限内签订搬迁补偿安置协议的，在复议或诉讼期限内仍可自行选定补偿决定中的一种安置补偿方式，若复议或诉讼期满后被搬迁人仍未选择的，搬迁人将按有利于被搬迁人的第二种回迁安置补偿方式进行安置补偿，并将相应补偿款项提存到公证处或城市更新项目专户。

五、被搬迁人如不服本决定，可在本决定送达之日起六十日内向三亚市人民政府申请行政复议，或者在本决定书送达之日起六个月内可以选择向三亚市中级人民法院提起行政诉讼。
