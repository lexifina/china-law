# 三亚市人民政府办公室关于建立三亚市数字化城市管理工作联席会议制度的通知

三亚市人民政府办公室

关于建立三亚市数字化城市管理工作

联席会议制度的通知

各镇人民政府，各区管委会，市各相关单位:

为整合全市城市管理资源，形成齐抓共管、协同配合的“大城管”格局，有效建立监督、指挥、处置三方的协同机制，提高数字化城市管理水平，确保数字化城市管理工作顺利实施，经市政府研究，决定建立三亚市数字化城市管理工作联席会议制度。

二、联席会议主要职责

三亚市数字化城市管理工作联席会议是市政府数字化城市管理工作的协调议事机构，在市政府的领导下，负责组织、统筹、协调全市的城市管理工作，其主要职责是：

（一）分析研究和通报阶段性城市管理工作情况，总结交流城市管理工作经验，布置阶段性城市管理工作；

（二）对责任归属未完全明确或有争议的事件进行明确，进一步规范管理流程、结案标准和考评方法，完善城管工作制度；

（三）协商解决数字城管工作中，通过群众举报的热、难点问题，以及属于多部门联合执法的问题，形成标准工作流程和合理评价标准，或提出意见和建议供市委、市政府决策参考；

（四）及时协调处理涉及城市管理的突发事件，做好突发事件的预防、应急和事后处理工作；

（五）协商解决数字城管的其他事项。

三、联席会议议事规则

会议应贯彻落实国家、省市有关城市管理工作的精神和方针政策，由联席会议召集人或副召集人主持召开。

（一）数字化城市管理工作联席会议议事职责范围内的事项，由市数字化城管监控中心向市政府提出议题。议题经会议召集人同意后，召开联席会议，就议题内容进行研究并作出工作决定。

（二）涉及城市管理的事项，联席会议其它成员单位可向市政府提出议题，议题经联席会议召集人同意后，召开联席会议，市政府可根据工作需要，直接决定议题。

（三）联席会议的工作意见，属重大事项的，经联席会议召集人同意后，报市政府常务会议决定；属成员单位职权范围内的，有关成员单位依照法定职权和规定的办事程序办理。

（四）各联席会议成员单位要按照本单位职责分工，主动研究涉及数字城管工作的有关问题，认真落实联席会议布置的工作任务，在符合法规、政策的前提下，按照责任分工，主要领导要亲自抓，分管领导要具体抓，按照时限要求抓好落实。

（五）各成员之间要加强和创新部门联动工作机制，定期公布相关服务资源，涉及城市管理的各项政策和规定，要及时上报、整合到市数字化城市管理大平台中。同时畅通信息渠道，相互配合，相互支持，形成合力，充分发挥联席会议的作用。
