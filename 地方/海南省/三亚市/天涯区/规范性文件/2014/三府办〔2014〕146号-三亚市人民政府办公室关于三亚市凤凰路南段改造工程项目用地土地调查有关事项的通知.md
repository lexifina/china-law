# 三亚市人民政府办公室关于三亚市凤凰路南段改造工程项目用地土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市凤凰路南段改造工程项目用地土地调查有关事项的通知

河东区管委会，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，拟征收河东区月川村、东岸村、临春村部分土地和收回河东区辖区内部分国有土地作为凤凰路南段改造工程项目用地。为做好该项土地调查工作，现就有关事项通知如下：

一、该宗项目起点于榆亚路口，终点至金鸡岭路，用地面积365159.5平方米（约547.7393亩）。土地权属为河东区河东办事处（原详查资料）38901平方米、国有土地75747平方米、月川居委会74655平方米、三亚市食品冷冻厂86平方米、三亚林场（原详查资料）137平方米、榆亚盐场118576平方米、初秀华36平方米、河东区东岸村321平方米、三亚市食品供应公司180平方米、榆亚盐场（已收回）9917平方米、河东区月川与金鸡岭农场争议6713平方米、部队2697平方米（海南平面坐标系）。土地利用总体规划为建设用地365244平方米、非建设用地132平方米（西安80坐标系）。具体的征地范围四至及坐标详见用地勘测定界图。

二、根据《中华人民共和国土地管理法》第二条第四款“国家为公共利益的需要可以依法对土地实行征收或征用并给予补偿”的规定，为做好该宗用地拟征收及收回土地的调查工作，由河东区负责组织实施该项目用地上的青苗清点、地上附着物和土地面积丈量等土地补偿审核及土地补偿工作；市国土环境资源局负责对该宗用地范围内的土地权属确认及业务指导工作。在调查工作中，拟征收及收回土地范围内的单位或个人，不得以任何理由进行阻挠。

三、拟调查土地补偿标准按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、根据《国土资源部关于进一步做好征地管理工作的通知》（国土资发〔2010〕96号）第四条规定，河东区应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认，向市国土环境资源局出具履行征地前告知等程序的证明及土地权属确认意见。待有权限的人民政府批准征地后，征收土地公告和征地补偿安置方案公告可同步进行。

五、为了进一步做好被征地农民养老保险工作，根据省人力资源和社会保障厅、省财政厅和省国土环境资源厅《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号），河东区应在本通知下发后10个工作日内对项目拟征收农用地和享受缴费补贴人数等情况进行调查，组织村（居）小组填写《征地项目被征地农民基本情况调查表》，经村（居）委会、河东区管委会逐级审核后，由河东区管委会汇总填写《征地项目被征地农民基本情况乡镇调查汇总表》，并将上述两种表格报送市国土环境资源局。

六、自本通知下达之日起，在拟调查范围内的土地一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
