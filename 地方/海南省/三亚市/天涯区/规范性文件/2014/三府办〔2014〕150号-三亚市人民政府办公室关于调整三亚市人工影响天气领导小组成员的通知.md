# 三亚市人民政府办公室关于调整三亚市人工影响天气领导小组成员的通知

三亚市人民政府办公室

关于调整三亚市人工影响天气领导小组成员的通知

各镇人民政府，各区管委会，市政府直属各单位：

为加强全市人工影响天气工作的组织工作，结合各职能部门人事变动情况，市政府决定对三亚市人工影响天气领导小组成员进行调整。调整后的领导小组组成人员如下：

组 长：周高明（市政府副市长）

副组长：曹 兵（市政府副秘书长）

柯维耀（市气象局局长）

成 员：李劲松（市农业局局长）

（市水务局局长）

章华忠（市海洋与渔业局局长）

张 利（市发展和改革委员会主任）

孙 宁（市林业局局长）

徐 冰（市公安局副局长）

郑先吉（市民政局党组成员、双拥办主任）

领导小组下设办公室，办公室设在市气象局，办公室主任由市气象局副局长黄海智同志兼任。各成员单位按照本单位职能，具体落实领导小组的工作部署和有关要求。

三亚市人民政府办公室

2014年6月18日

（此件主动公开）
