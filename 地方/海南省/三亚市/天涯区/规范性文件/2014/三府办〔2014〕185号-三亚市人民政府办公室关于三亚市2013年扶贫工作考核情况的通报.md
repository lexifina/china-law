# 三亚市人民政府办公室关于三亚市2013年扶贫工作考核情况的通报

三亚市人民政府办公室

关于三亚市2013年扶贫工作考核情况的通报

各镇人民政府，市政府各有关单位：

根据三亚市人民政府办公室《关于印发三亚市2013年扶贫工作实施方案的通知》（三府办〔2013〕90号）要求和市领导指示精神，为做好2013年扶贫工作考核，全面掌握我市2013年度扶贫工作完成情况，查找问题，总结经验，推动工作，市农业局组成了扶贫工作考核小组对各责任单位进行了考核。现将考核情况通报如下：

一、2013年度扶贫项目及资金计划情况

2013年度，我市共投入扶贫专项和整合资金10908.036万元（其中：部门预算8792.801万元，镇级预算2115.235万元），实施项目有四大类别：一是基础设施类实施项目6个，资金4953.92万元（其中：部门预算3874.92万元，镇级预算1079万元）；二是经济发展类实施项目5个，资金1599.279万元（其中：部门预算786.044万元，镇级预算813.235万元）；三是社会服务类实施项目7个，资金4222.437万元（其中：部门预算4022.437万元，镇级预算200万元）；四是技能培训类实施项目2个，资金132.4万元（其中：部门预算109.4万元，镇级预算23万元）。

三、主要成效

2013年，市委、市政府高度重视扶贫开发工作，把扶贫开发的成效作为考核乡镇党政主要责任人和部门负责人政绩的重要依据。各单位认真落实责任，分工明确，通力合作，从资金、项目、技术、信息等各方面重点向贫困地区、贫困农户倾斜；乡镇负起了属地管理的职责，制定了具体的扶贫开发实施方案，明确了减贫目标、扶贫措施和脱贫时间；加强了贫困地区农村基层组织建设，为新阶段扶贫开发任务的完成提供可靠的基层组织保障。在广大干部的共同努力下，取得了显著的成绩。主要体现在以下八大方面：

（一）扶贫资金整合力度加大。2013年，我市整合各部门涉农扶贫资金10908.036万元集中用于贫困村扶贫开发建设，同比往年资金投入力度不断增加，着力了解决制约贫困村发展的基础设施、经济发展、社会事业和贫困农户技能培训等方面的问题，实现了我市贫困人口早日脱贫致富的目标。

（二）贫困人口明显减少。按照《三亚市五年扶贫规划（2012―2016年）》的安排，2013年我市各部门齐心协力，加快贫困地区建设，综合经济实力整体提升，贫困人口由15291人减少到11340人，减少了3951人，为促进三亚建成小康社会创造了有利条件。

（三）贫困群众收入明显增加。2013年，农民人均纯收入9795元，同比去年增长11%。贫困群众的经济收入明显增加，贫困群众的生产生活条件明显改善，为促进三亚城乡统筹发展，缩小城乡差距提供了有力保障。

（四）贫困观念思想明显转变。“扶贫先扶智，治贫先治愚、治穷先治懒”。在广大干部的共同努力下，通过实施生产技能培训、创业培训和雨露计划等方面的教育引导工作，推动贫困群众“等、靠、要”的落后思想转变，促进了贫困群众积极脱贫的意识和自我发展的能力。

（五）产业结构进一步优化。通过扶持橡胶、槟榔、豆角等热带作物和瓜菜种子种苗及肥料，扶持林业经济建设等，贫困地区共种植热带经济作物和瓜菜等7千多亩，扶持养猪5千多头、蜜蜂4百多箱、“三鸟”5万多只等畜禽，初步形成了一批热带特色优势产业，为贫困农户稳定增收奠定了基础。

（六）基础设施进一步改善。新建改建贫困村道路8.7公里、桥梁4座，解决了5235人的交通难问题；修建饮水工程8宗，解决了1916人畜饮水困难；整治生产用水渠道7.8公里，完成危房改造564户，改造220户配变过载及台区电压低等问题，新建户用沼气池800个，为保护贫困地区生态环境和节能减排进一步巩固了基础，切实解决了贫困群众交通难、饮水难等生产生活问题。

（七）社会事业稳步发展。新建改建校舍约3715平方米，贫困村小学危房改造基本完成；新建改建卫生室2间、文化室5间、多功能厅6个，改善看贫困地区的卫生医疗条件和文化娱乐条件；农村垃圾分类搜集、运营，设备采购（垃圾车、箱、桶）一批；解决了19个贫困村35751人医疗、26846人养老、1924人低保问题，贫困地区社会事业发展有了明显进步。

（八）致富能力不断提高。举办劳动力转移就业培训908人次，为贫困村农民转移就业创造了较好条件。同时还加强农业技术培训，举办各类实用技术培训班，培训贫困村农民3130人次，进一步增强了群众的致富能力。

四、存在问题

（一）个别项目及资金尚未实施完成。基础设施类：凤凰镇由于一条渠道初步设计不合理，需重新设计，致使完成项目及资金87%；社会服务类：市卫生局由于在育才镇、凤凰镇建设村卫生室选址难度大，目前尚未开展，致使完成项目及资金50%；技能培训类：吉阳镇培训工作计划15万元，由于制定计划未把握好任务量，尚有10万元培训任务没有完成，致使完成项目及资金33%。

（二）项目已实施完成，但资金尚未全额拨付。育才镇由于等待审计结算，致使基础设施类完成项目100%，资金拨付74%；经济发展类完成项目100%，拨付资金70%；社会服务类完成项目100%，拨付资金82%。

五、有关建议

（一）加快项目建设进度，实现资金全额拨付。

（二）将尚未完成的项目及资金列入2014年扶贫项目继续抓好实施工作。
