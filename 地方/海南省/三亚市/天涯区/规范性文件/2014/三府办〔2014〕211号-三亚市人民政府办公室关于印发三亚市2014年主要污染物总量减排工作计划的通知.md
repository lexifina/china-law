# 三亚市人民政府办公室关于印发三亚市2014年主要污染物总量减排工作计划的通知

三亚市人民政府办公室

关于印发三亚市2014年主要污染物

总量减排工作计划的通知

各镇人民政府，各区管委会，市各有关单位：

为顺利推进2014年主要污染物总量减排工作，确保完成我市2014年减排工作任务，结合我市实际情况，特制定本工作计划。

一、指导思想

以邓小平理论和“三个代表”重要思想为指导，坚持科学发展观，以改善环境质量、维护生态安全、保障国际旅游岛建设为目标；以总量减排为抓手，加快推进各减排项目建设进度，推动产业结构调整和经济发展方式的转变，完成2014年主要污染物总量减排任务。

二、减排目标

完成海南省下达的2014年主要污染物排放总量控制目标。

三、2014年工作任务

（一）加快推进红沙污水处理厂氨氮升级改造工程项目、新城水质净化厂项目、创意产业基地南区污水处理厂项目建设及配套管网建设，确保上述三个项目在2014年投入试运行。加强环境执法监察，督促现有污水处理设施运营单位加强管理，确保所有污染治理设施和在线监测设施正常运转，确保现有污水处理厂稳定排放达标率97%。加快推进片区管网建设和中水回用管网建设，确保片区污水集中收集并得到处理、红沙污水处理厂2014年内形成中水回用能力。

（二）继续规范污水处理厂污泥处置工作。建立污泥管理和转移联单制度，实施污泥生产、运输、贮存处理、处置全过程管理。

（三）全面完成规模化畜禽养殖场及养殖小区污染治理工程,推进畜禽养殖业废弃物综合利用。生猪规模化养殖场推广“雨污分流+干清粪（资源综合利用）+厌氧+好氧”养殖废弃物处理方法；奶牛规模化养殖场推广“雨污分流+干清粪+干粪生产有机肥+厌氧+好氧处理”养殖废弃物处理方法；蛋鸡规模化养殖场推广“雨污分流+干清粪+资源综合利用”养殖废弃物处理方法。提高畜禽养殖规模化养殖率，推进农村养殖小区建设，按照海南省“十二五”主要污染物总量减排工作责任书的要求完成猪、蛋鸡和肉鸡的规模化养殖率和规模化治理率。

（四）加快推进垃圾渗滤液处理设施改扩建工程建设，在改扩建后的渗滤液处理设施投入运行前，未经处理的渗滤液必须妥善储存，不得直接外排或超标外排，确保环境安全。

（五）推进余热利用、严格控制新建煤电、造纸、制糖、钢铁、水泥、玻璃等污染严重的项目、严格限制污染物排放超过省政府下达总量指标的新、改、扩建项目建设；实行部门联动，协同把好立项、审批、用地、施工、登记、供电等项目准入关。

（六）大力发展深海养殖，集约发展近海养殖和淡水养殖。

（七）严格机动车环境准入。新车注册登记和省外转入车辆与全国同步执行国家第IV阶段机动车污染排放标准，对污染物排放达不到机动车污染排放标准的新车与转入车辆，不予办理注册登记或转入手续。重点对营运车辆选型实行排放达标环保审核监督。

（八）强化机动车环保定期检验，全面开展环保标志发放工作。严格按照国家和省发布的测量方法对机动车排放污染物定期检测，及时公开检测程序和获得审批的检测收费标准。全面开展环保标志发放工作，将机动车排气污染物检测情况纳入机动车定期检测合格标志核发审核内容，对于检测合格的机动车核发相应的环保标志，公安部门对当年未取得环保标志的车辆，不得通过年审。

（九）明确划定“黄标车”限行区域、限行时段，严格执行“黄标车”限行区域、限行时段等限行规定，禁止检验不合格车辆上路行驶。

（十）推进车用燃油标准升级和质量监管。积极协调相关部门和石油企业，提升车用油品质量，加强成品油的经营许可管理，严格落实国IV车用汽柴油标准，确保2014年度内全部供应国IV标准车用汽柴油。

（十一）完善黄标车淘汰补贴优惠政策，研究制定机动车油品使用价格优惠地方配套经济政策并推动实施。进一步落实规模化养殖场和养殖小区鼓励政策。完善污水处理费征收和使用管理经济政策。

（十二）按照减排统计、监测、考核三大体系的要求。落实减排统计、监测工作，开展年度和“十二五”末重点企业减排任务完成情况的考核。具体任务分解详见附件。

四、几点要求

（一）高度重视，认真部署2014年减排工作。2014年我市要全面完成“十二五”各个减排项目，减排压力大，各相关单位要高度重视、认真部署各项减排工作，确保完成“十二五”各项减排工作。

（二）加强组织领导，按时上报减排工作情况。各相关单位要提高工作的责任感和紧迫感，建立减排工作问责制，在计划的时间内完成各项指标；要认真履行监管职责，加强对相关企业的监管，按时按要求上报减排工作情况。

（三）加强宣传，提高全民减排意识。采取多种方式广泛宣传减排的重要性、紧迫性，提高全社会的减排意识。
