# 三亚市人民政府办公室关于印发三亚市2014年度农田水利基本建设实施方案的通知

三亚市人民政府办公室

关于印发三亚市2014年度农田水利

基本建设实施方案的通知

各区筹备组，育才生态区管委会，市各相关单位：

《三亚市2014年度农田水利基本建设实施方案》已经市政府同意，现印发给你们，请认真贯彻执行。

三亚市人民政府办公室

2014年10月29日

（此件主动公开）

三亚市2014年度农田水利基本建设实施方案

按照省水务厅的统一部署,为做好我市今冬明春农田水利基本建设工作，结合我市当前水利工作实际及今冬明春农业生产用水情况，特制订本方案。

一、指导思想

坚持以十八届四中全会精神为指导，以病险水库除险加固、大中型水库配套设施完善、排沟整治、农田综合整治、农村饮水安全、污水排放处理等工程建设为重点，通过政府的强力推动，受益农户和社会力量积极参与，有组织、有计划地开展农田水利基本建设，巩固农业基础，为促进农业增产、农民增收、农村发展夯实物质基础。

二、目标任务

实施完成渠道防渗改造34宗，新增防渗渠道52条，长60.3公里(其中主要干支渠32条长47.7公里,田间渠道20条长12公里)；田洋整治3宗，受益面积0.29万亩；大中型水库配套设施改造工程2宗、病险水库加固11宗、拦水坝及防洪堤改造加固2宗；河道整治3宗；田洋排沟整治3宗，长10.3km；饮水安全工程2宗，解决22个村委会135个自然村6831户55937人的饮水安全问题；水毁工程修复38宗；污水排放处理工程1宗以及其他水土保持及水电站改造等工程6宗。

新增灌溉面积0.4万亩，改善灌溉面积4.7万亩，改造中低产田0.7万亩，高标准整治农田0.29万亩，年新增节水41.2万方。计划完成投资35437.3万元（其中：中央投资1933万元，省投资9028万元，市财政投资20414.2万元，区投资3712.2万元）。计划完成工程量：土方78.7万方，石方1.3万方，砼12.3万方。

三、工作重点

(一)抓好田洋综合整治，改善农业基础设施条件。

为提高农业综合生产能力，提升抵御自然灾害能力，改善农业基础设施条件，促进农业生产和农村经济结构调整，同时增加农民收入，重点抓好3宗田洋水利综合整治、9宗渠道防渗改造工程和3宗田洋排沟整治工程。3宗田洋水利综合整治即：马脚村委会那上、那马、那通田洋综合整治工程，那受村委会那头、保月、永介田洋综合整治工程和青法村委会豪轮田洋整治工程；9宗渠道防渗改造工程即：三亚市大隆灌区西干渠与支渠连接段工程、宁远河北干渠维修加固工程、中廖村委会芭蕉村排灌沟工程、上抱坡村排灌沟工程、大茅村委会里二村排灌沟工程、鄱园村排灌沟工程、塔岭大村水库放水口到那亲田洋灌溉渠道工程、布山水库主干渠布甫支渠灌溉渠道改造工程、那会村委会那泡支渠工程；3宗田洋排沟整治工程即：海棠湾落根田洋排水工程、大茅村里一、里二村田洋排水沟工程和过岭六六田洋排洪沟改造工程。

(二)推进水库除险加固及设施配套建设，保障农业灌溉用水安全。

为确保我市水库运行安全，保障下游人民的生命财产安全及灌溉用水，重点完成2宗大中型水库配套设施改造加固和11宗病险水库加固。2宗大中型水库配套设施改造工程即：市水源池水库工程管理处防洪物资仓库工程、汤他防洪物资仓库工程。11宗病险水库加固即：榕树水库除险加固工程、道宁水库除险加固工程、五一水库除险加固工程、台楼水库除险加固工程、三清本水库除险加固工程、草头水库除险加固工程、文针水库除险加固工程、高村水库除险加固工程、黄猄水库除险加固工程、尖岭水库除险加固工程、双本水库除险加固工程。

(三)加快农村饮水安全工程，确保农民生活用水。

为保障农村饮水安全，解决22个村委会135个自然村6831户55937人的饮水安全问题，重点完成2宗饮水安全工程，即：2014年农村饮水安全工程(包括水务局建设任务、海南天涯水业（集团）公司建设任务及海棠区、天涯区、吉阳区、崖州区建设任务)和三亚市吉阳中廖、大茅供水主管道工程。

按照《三亚市人民政府关于印发三亚市农村饮水安全工程建设实施方案的通知》（三府〔2013〕号156号，以下简称《三亚市农村饮水安全工程实施方案》）的要求，各区及各受益村委会要对实施农村饮水安全项目的自然村进行宣传教育，让受益农户积极参与农村饮水安全工作，解决建设用地等问题，并自筹资金安装入户管网。村内管由区或受益村委会负责自筹资金解决。

(四)开展河道整治，保障排涝畅通。

为保证我市河道等泄水通道的畅通，减少洪灾损失，促进我市农村生态环境的改善，为新农村建设、群众安居乐业、社会繁荣稳定提供良好的基础，重点实施3宗河道整治及2宗拦水坝、防洪堤改造加固。3宗河道整治即：三亚市宁远河防洪整治工程、三亚东河防洪整治工程（抱坡溪段）、吉阳大茅河整治工程。2宗拦水坝、防洪堤改造加固即：乌岸坝改造修复工程和三亚东河儋州桥至海螺村防潮堤左岸堤防工程（市政海螺80号地块河堤）。

(五)推进污水工程建设，助力新农村建设。

为净化我市农村人居环境，保障新农村建设，使群众安居乐业、社会繁荣稳定,省级财政2014年安排9000万元，市级财政配套3211.91万元,重点实施三亚湾新城水质净化厂。

(六)修复水毁工程，确保各项水利设施正常发挥作用。

今年我市各区需修复水毁工程38处，为尽快完成水毁工程的修复任务，保证今冬明春生产用水，各区要抓紧水毁工程的修复及面上渠道维修。

四、任务分解

(一)市水务局

完成《三亚市农村饮水安全工程实施方案》要求的2014年农村饮水安全工程市水务局建设任务、11宗病险水库加固、2宗渠道防渗改造工程、2宗大中型水库配套设施改造工程、2宗拦水坝、防洪堤改造加固、2宗饮水安全工程、3宗河道整治项目和三亚市吉阳中廖、大茅供水主管道工程、海棠湾落根田洋排水工程、三亚湾新城水质净化厂项目、三亚市抱古水库小流域水土保持综合治理工程、河道防洪治导线控制点界桩工程、全市水利工程水毁维修及紧急防护处理项目、汤他三级电站危房改造工程、汤他水库35KV供电线路安全改造工程。

(二)市农综办

完善田洋管护规章制度，定期对其进行考核，考核合格后按月发放补助，补助以负责田洋管养工作量的大小进行安排。

(三)海南天涯水业（集团）公司

完成《三亚市农村饮水安全工程实施方案》要求的2014年农村饮水安全工程海南天涯水业（集团）公司建设任务。

(四)天涯区

完成《三亚市农村饮水安全工程实施方案》要求的2014年农村饮水安全工程天涯区建设任务、过岭打钟村灌溉渠道改造工程、过岭土农村灌溉渠道改造工程等20宗渠道改造工程和大村水库防洪公路改造工程及其他水毁修复10处。

(五)吉阳区

完成《三亚市农村饮水安全工程实施方案》要求的2014年农村饮水安全工程吉阳区建设任务、大茅村里一、里二村田洋排水沟工程、中廖村委会芭蕉村排灌沟工程、大茅村委会里二村排灌沟工程、上抱坡村排灌沟工程、鄱园村排灌沟工程及其他水毁修复8处。

(六)海棠区

完成《三亚市农村饮水安全工程实施方案》要求的2014年农村饮水安全工程海棠区建设任务和龙山渠道维修工程、龙楼村沟渠水毁修复工程及其他水毁修复8处。

(七)崖州区

完成《三亚市农村饮水安全工程实施方案》要求的2014年农村饮水安全工程崖州区建设任务，解决7个村委会44个自然村2697户16979人的饮水安全问题，另完成其他水毁修复6处。

(八)育才生态区管委会

完成马脚村委会那上、那马、那通田洋综合整治工程、那受村委会那头、保月、永介田洋综合整治工程、青法村委会豪轮田洋整治工程和那会村委会那泡支渠工程、马脚村委会那供一队水渠工程等7宗渠道改造工程以及其他水毁修复5处。

五、时间安排

（一）2014年10月，制定全市农田水利基本建设实施方案和召开全市农田水利基本建设动员大会；

（二）2014年11月至12月，全面掀起冬修水利高潮；

（三）2015年1月中旬，组织全市农田水利基本建设检查评比。

六、主要措施

(一)科学筹划，注重实效。

各区要认真总结近几年农田水利基本建设工作经验，本着因地制宜，突出重点，讲求效益的原则，科学规划、统筹安排，制定好本辖区农田水利基本建设实施方案。方案中要重点突出效益好、见效快的“民生水利”项目。在全面维修现有水利设施的基础上，加大渠道防渗配套的力度、完成病险水库加固工程,不断提高农业抗灾和减灾能力。要统筹安排农田水利基本建设和冬种的时间，做到冬修冬种两不误。

(二)加大投入，多方筹资。

积极探索创新农田水利基本建设投入机制，各区可采取“四个一点”的办法，即中央、省和市财政扶持一点、区财政配套一点、社会赞助一点、受益农户出一点，多渠道、多层次、多方面筹集资金。要建立起中央、地方和农户投资投劳相结合的有效投入机制。各区要把农田水利基本建设资金列入财政预算，落实农田水利建设资金。同时，要利用好有关政策，合理有效地整合农业综合开发、扶贫、土地复垦等各种涉农资金用于农田水利建设。各区应采取有效措施，确保农田水利建设资金足额按时到位。

(三)正确引导，发动群众。

农田水利基本建设是农业增产、农民增收的基础性工作，农民群众是最大的受益者，同时也是投入的主体之一，要正确理解减轻农民负担和发动农民自愿投工投劳改善自己生产条件的政策。一是区和村委会要引导群众配合农田基本建设，负责解决阻工问题，创造更好的施工环境，特别要解决好农田基本建设占地问题，村委会干部要及时向群众说明项目建设的重要性和要求，尽量用集体用地进行项目占地调剂，确实需要补偿的要按合理的标准进行补偿，并创新补偿新机制，建立健全市、区和村委会三级分担补偿机制。二是要发动群众积极参与冬修水利。各区要给每个村委会安排冬修水利任务，并由各村委会组织实施。对不能按时完成任务的村委会，各区要指定施工并从村委会工作经费中扣回工程费用，并对村委会书记和主任进行通报。

(四)深入指导，确保质量。

各区要加强工程项目的前期工作，搞好规划设计；强化建设管理，认真执行项目法人负责制、招标投标制、工程监理制、项目合同制和竣工验收制。要组织工程技术人员深入工程建设第一线，加强施工指导，确保工程施工质量。工程完工后，要按照有关规定，及时组织验收。

(五)加强领导，落实责任。

为了加强对全市冬修工作的领导，市政府成立冬修水利指挥部，由市政府周高明副市长任总指挥，市政府副秘书长曹兵、市水务局局长何世刚任副总指挥。下设办公室，设在市水务局，负责冬修水利日常工作。各区也要成立冬修工作领导机构,加强组织领导，落实责任，做到主要领导亲自抓，分管领导具体抓，各级领导共同抓，把农田水利基本建设作为实践科学发展观和推进农村改革发展的大事来抓，将农田水利基本建设纳入今冬明春农村工作重点来抓，确保全面完成今冬明春农田水利基本建设任务。

同时，采取多种形式宣传农田水利基本建设的重要意义，营造农田水利基本建设的良好氛围，以优异成绩迎接全省农田水利基本建设检查评比，市政府将继续对2014年度农田水利基本建设先进区进行表彰。
