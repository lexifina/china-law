# 三亚市天涯区人民政府关于征收三亚市海坡片区（西瓜村、芒果村）棚户区集体土地的通告

三亚市天涯区人民政府

关于征收三亚市海坡片区（西瓜村、芒果村）

棚户区集体土地的通告

根据三亚市土地利用总体规划、城市规划和项目建设需要，市政府下发《关于三亚市海坡片区（西瓜村、芒果村)棚户区改造项目土地调查有关事项的通知》（三府办〔2017〕210号）文的要求，经市政府同意批准征收天涯区海坡、羊栏村委会的部分集体土地 98.3552公顷（合约1475.328亩），现将有关事项通告如下：

一、被征收土地规划性质:

三亚市海坡片区（西瓜村、芒果村）棚户区集体土地规划性质为建设用地及农用地。

二、被征收土地四至范围：

被征收地块用地位于天涯区海坡、羊栏村委会棚户区（具体以勘测定界图为准）。

三、被征收土地权属单位及面积：

天涯区海坡、羊栏村委会的部分集体土地98.3552公顷（合约1475.328亩）。

（二）地上附着物补偿标准和青苗补偿标准：

按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定（2013年修订）>的通知》（三府〔2013〕43号）及《三亚市人民政府关于印发三亚市征收集体土地青苗补偿费和征地经费包干管理暂行办法>的通知》（三府[2011]208号）规定的补偿标准执行。

五、农业人员安置：

（一）根据三亚市人民政府有关征地补偿标准规定，一次性拨付土地安置补助费。

（二）被征地农民社会养老保险和就业保障，按《海南省人民政府关于印发被征地农民参加社会养老保险办法的通知》（琼府[2013]21号）及《海南省人民政府办公厅关于印发海南省征地安置预留用地管理办法的通知》（琼府办[2012]97号）的有关规定办理。

六、被征收土地四至范围内的土地所有权人、使用权人在通告规定期限内，持土地权属证书或其他有关证明材料，到指定的地点办理征地补偿登记。

凡从天涯区政府现场调查之日起，抢栽、抢种青苗和抢建地上附着物的不予办理补偿登记。
