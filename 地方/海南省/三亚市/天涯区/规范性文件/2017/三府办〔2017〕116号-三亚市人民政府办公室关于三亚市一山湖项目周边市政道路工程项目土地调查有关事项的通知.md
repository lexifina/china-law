# 三亚市人民政府办公室关于三亚市一山湖项目周边市政道路工程项目土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市一山湖项目周边市政道路工程项目土地调查有关事项的通知

吉阳区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对一山湖项目周边市政道路工程项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于吉阳区辖区内，用地调查面积约12472平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市规划局出具的三亚市一山湖项目周边市政道路工程项目用地红线图。土地权属（海南平面坐标系）情况为海南省国营南新农场国有土地约2260平方米、三亚保力房地产投资开发有限公司国有土地约237平方米、三亚联合实业有限公司国有土地约7029平方米、原三亚宝迪投资有限公司（已收回）国有土地约 2946平方米；土地利用现状（西安80坐标系）为果园约2125平方米、建设用地约10354平方米（其中村庄约135平方米、风景名胜及特殊用地约10219平方米）；该项目用地在土地利用总体规划调整完善（西安80坐标系）中规划为园地约5平方米、城镇用地约46平方米、公路用地约12428平方米。上述用地待市住房城乡建设局按要求提供用地报批材料后，市国土资源局将其列入当年新增建设用地指标并办理农转用及征收报批手续。

二、为做好该项土地调查工作，由吉阳区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土资源局负责收回农场国有土地范围内征地业务指导工作；市住房城乡建设局负责收回其他国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）、《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）、《国有土地上房屋征收与补偿条例》（国务院令第590号）和《三亚市人民政府办公室关于妥善处理农垦无缝转让用地被公共基础设施占用补偿问题的通知》（三府办〔2016〕270号）规定执行。

四、根据2010 年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，吉阳区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认工作。

五、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
