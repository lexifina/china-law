# 三亚市人民政府办公室关于天涯区布甫安置区中和河道治理工程项目土地调查有关事项的通知

三亚市人民政府办公室

关于天涯区布甫安置区中和河道治理工程项目土地调查有关事项的通知

天涯区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对天涯区布甫安置区中和河道治理工程项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于天涯区布甫安置区内，用地调查面积约122626平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市规划局出具的担油河（中和河）水域及两侧用地界址图、天涯镇总规部分水域及农林用地界址图。土地所有权属（海南平面坐标系）情况为天涯区布甫村委会集体土地约70916平方米、天涯区红塘村委会集体土地约19990平方米、国家所有土地约27530平方米、市政府国有土地约28平方米、三亚红棠湾国际高尔夫俱乐部有限公司国有土地约2404平方米、三亚长丰海洋天然气供气有限公司国有土地约96平方米、海南铁路总公司国有土地约852平方米、粤海铁路有限责任公司国有土地约810平方米；土地利用现状（西安80坐标系）为农用地约97580平方米（其中水田约15292平方米、旱地约8097平方米、果园约140平方米、可调整其他园地约15884平方米、其他园地约3444平方米、有林地约17818平方米、灌木林地约10470平方米、坑塘水面约26435平方米）、建设用地约23087平方米（其中铁路用地约1605平方米、公路用地约1898平方米、建制镇约9708平方米、村庄约986平方米、风景名胜及特殊用地约8890平方米）、沿海滩涂约1954平方米；该项目用地在土地利用总体规划调整完善（西安80坐标系）中规划为公路用地约6979平方米、农村居民点用地约22平方米、园地约29184平方米、坑塘水面约307平方米、城镇用地约4平方米、旱地约6092平方米、林地约21662平方米、水工建筑用地约6878平方米、水田约8908平方米、河流水面约23542平方米、滩涂约10711平方米、自然保留地约2578平方米、铁路用地约2523平方米、风景名胜设施用地约3235平方米。该项目用地规划性质为水系、农林用地、园地、公园绿地，不列入农用地转用及征收报批计划，具体征地范围以天涯区政府现场实际测量确认为准。

二、为做好该项土地调查工作，由天涯区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土资源局负责征收集体土地范围内征地业务指导工作；市住房城乡建设局负责收回国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行；收回国有土地征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、根据2010年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，天涯区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认工作。

五、为进一步做好被征地农民养老保险工作，天涯区政府应根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅 2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神办理。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
