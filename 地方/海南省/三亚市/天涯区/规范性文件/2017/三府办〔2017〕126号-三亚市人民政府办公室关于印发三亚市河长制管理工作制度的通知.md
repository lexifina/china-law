# 三亚市人民政府办公室关于印发三亚市河长制管理工作制度的通知

三亚市人民政府办公室

关于印发三亚市河长制管理工作制度的通知

各区人民政府，育才生态区管委会，市各相关单位：

《三亚市河长制管理工作制度》已经七届市政府第8次常务会议同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年4月19日

（此件主动公开）

三亚市河长制管理工作制度

为进一步推进“河长制”管理工作，强化河长的管理、治理、保护等工作职责,完善河湖的长效管理机制，达到“河畅、水清、景美、岸绿”的目标，持续改善全市水环境质量，特制定三亚市河长制管理工作制度，本制度适用于列入《三亚市全面推行河长制工作方案》范围内的所有河湖。

一、巡查制度

进一步加强河湖管理，促进长效巡查检查工作机制落到实处，确保河长、河段长履职到位。

（一）巡查范围：

列入《三亚市全面推行河长制工作方案》中的河湖及河湖管理范围。

（二）巡查频率：

河长、河段长要加大对包干河湖的巡查力度，监管河湖污染等情况。区级河长巡查每周不少于1次，村级河段长每天最少巡查1次。除日常巡查外，河长可以结合相关工作联系河湖实际情况进行不定期巡查。河长要督促各相关部门定期检查河湖周边情况，对发现的问题进行及时处理。河湖保洁员应每天进行检查，当天产生的垃圾当天清理，发现问题及时报告。

（三）巡查内容：

1.河湖截污纳管、日常保洁是否到位。

2.工业企业、在建施工项目、禽兽养殖、居民生活污水等是否存在偷排、漏排及超标排放等行为。

3.是否存在各类污水直排口、涉水违建（构）筑物、弃土弃渣、工业废物和危险废物等。

4.生活垃圾、建筑垃圾、种植垃圾等各类垃圾是否有效收集处理。

5.河湖整治工程质量进展情况。

6.河湖两岸20米范围内的各类堆积物及水面非法围栏、船屋等违章建筑。

7.河湖管理保护范围是否存在未经批准擅自占挖现象。

（四）巡查处置。河长、河段长在巡查中发现问题的处置：

1.处置权限属于河段长，马上进行处置。

2.处置权限属于相关部门，河段长应第一时间报告河长，同时通报相关部门，由河长督促相关部门进行查处。

3.若发现责任部门对问题查处不力的，河段长应第一时间报告河长，由河长安排区政府（管委会）督查部门，以督办函形式通知相关部门在规定的时间内予以处理，并进行跟踪落实，督促反馈结果，确保落实整改到位。

4.河段长发现问题要及时妥善处理并向上级报告；特别是发现重大污染事故或污染隐患的，河段长要第一时间向河长报告，由河长督促有关部门查处。

（五）巡查记录：

河段长每次巡查要做好记录工作（含文字、照片或视频等信息），把巡查中发现的问题与处置情况，准确详细的记录在《河段长工作日记》中。

二、投诉举报受理制度

鼓励社会公众积极参与河湖管理，举报河湖水环境污染等违法行为，及时发现、控制和消除水污染安全隐患，严厉打击污染环境违法犯罪行为。统一监督举报平台为“12345”政府服务热线，公众可通过拨打该热线或关注热线公众号进行相关投诉。

（一）一旦所负责的河湖被投诉举报或媒体曝光，相关巡查人员必须及时受理，河段长或河长必须及时到现场，听取举报人和群众意见，做好记录和登记，同时进行实地探勘调查，并及时交办有关部门立即处理。不能现场立即处理的，要以督办函形式转交相关部门在规定的时间内予以查处。对于需要综合性治理、工作量较大的问题，须在受理的当日起3个工作日内提出整改方案并反馈，10个工作日内整改到位或开始实质性实施整改计划和措施。抓好跟踪落实和情况反馈，做到件件受理、事事回应，确保整改到位。

（二）鼓励实名举报下列违法行为：

1.单位或个人偷排、直排废水;

2.随意倾倒混凝土块、渣土等建筑垃圾;

3.违反规定设置排污口或私设暗管排污;

4.河湖周边禁养区内的规模化畜禽养殖场;

5.河湖周边存在涉水违法建（构）筑物;

6.河岸垃圾乱堆放，未有效集中处置。

（三）任何单位或个人通过电话举报或来人举报等方式，需同时提供被举报河湖的名称、地址（或违法事实发生地）、违法行为发生时间、基本违法事实（或违规现象），必要时应配合河长及有关人员调查取证或提供相关的证据材料。

（四）对实名举报的问题，河长对投诉举报做到件件受理、事事回应。由被举报河湖的河长牵头有关部门进行核查，事件处理的结果要及时反馈给举报人，并向社会公开。

（五）区级河长办应建立健全投诉举报档案，包括记录、立案和查处情况等。工作人员必须严格执行保密制度，未经举报人同意，任何单位和个人不得将其姓名、身份、居住地及举报情况对外公布或者泄露给被举报单位和其他人员，否则按有关规定严肃查处。

（六）举报人应对举报内容的真实性负责。不得借举报之名故意捏造事实诬告、陷害他人，否则，要承担相应的法律责任。

（七）举报问题经查实后，根据其对河长制工作或水污染治理工作的贡献程度，可按规定对举报人予以金额不等的奖励。

三、重点项目协调推进制度

河长、河段长应明确工作责任、牵头制定包干河湖属地河段“一河一策”治理方案，及时协调解决在河湖防洪建设、河湖污染整治、河湖日常清淤疏浚、河湖保洁、河湖沿岸违法搭建物拆除等改善河湖水环境的重点项目推进中遇到的困难和问题，主动研究解决重点难点问题，确保重点项目顺利推进。

（一）重点项目协调指的是河长会同职能部门解决重点难点问题，确保重点项目顺利推进。

（二）重点项目协调由区级河长办收集梳理重点项目推进过程中遇到的困难与问题，由河长召集各相关职能部门会商，区级河长办负责督促落实。

（三）与会人员：

河长、河段长、相关职能部门单位、所在村居委会的干部和群众代表、其他相关人员。

（四）会议内容：

河长听取相关汇报和建议意见后针对存在的困难和问题进行协调，相关职能部门单位就所遇到问题提出建议，以推进重点项目工程为目标，各相关部门形成合力，攻坚克难。区级河长办做好会议记录，会后根据会议协调结果做好与各相关单位的衔接工作，跟踪落实，定期向河长汇报工作进展，并做好会议纪要备案。

（五）河长要切实履行协调督促的职责，协调各职能部门单位发挥应有作用，建立健全重点项目联络员制度。区级河长办必须对所辖河湖每个重点项目做好日常联系沟通工作，全程跟踪，紧抓落实。重点项目协调推进会，原则上每月应不少于1次。

（六）区级河长办牵头组织开展重点项目督查活动。通过现场察看、汇报座谈、查阅资料等方式，对各重点项目难题协调推进情况和问题落实整改等情况进行定期或不定期的督查，及时向河长汇报项目督查情况，推进重点项目建设。

四、信息公示制度

各区政府（管委会）应结合“河长制”管理工作的具体情况，做好“河长制”工作的新闻报道和信息报送工作，重大事项应在三亚电视台、三亚日报等媒体上公布。

为使公众了解河长制的情况，应在河湖（段）岸上醒目位置设立规范的“河长”公示牌，公示牌应包括河流名称、河湖长度、河长姓名及职务、联系部门、工作职责目标及任务、举报电话等信息。信息内容应准确，一旦人员调整，应在5个工作日内将“河长”调整到位。“河长”明确后，在5个工作日内，由区级河长办将“河长”公示牌的相关信息更新到位。

五、河长例会和报告制度

各区政府（管委会）要制定河长例会和定期报告等制度。

（一）河长例会指的是河长为专门研究所辖河湖的水环境、水生态的存在问题及治理措施而定期召开的会议。

（二）河长例会由河长召集，原则上每月最少召开一次，具体情况根据河湖整治工作的实际需要确定。区级河长办要做好会议各项准备，督促检查上次会议决议的落实情况。一事一议，急事急办，特殊事情临时召开河长会议讨论决定。

（三）与会人员：

河长、河段长、相关职能部门单位、所在村居委会的干部和群众代表、其他相关人员。

（四）会议内容：

会议由河长主持，通报日常巡查、投诉举报及处置情况，研究协调河湖的治理和保护中出现的问题，部署落实河湖的治理和保护工作计划和具体措施。区级河长办做好会议记录，根据会议决策出具会议纪要、工作联系单，送交各相关单位做好衔接工作，严抓落实。

（五）河长应于每月底前5个工作日内向市河长制管理工作领导小组提交工作报告，主要内容包括：上月工作进展、存在问题和本月工作计划、上次例会所提问题落实情况等，工程项目要明确时间节点，责任到人。

六、监督检查工作制度

（一）监督检查的对象

各区级的河长、河段长和各相关成员单位。

（二）监督检查的领导机制

监督检查工作在三亚市河长制管理工作领导小组的统一领导和组织协调下进行，每季度督查一次。

（三）监督检查的主要内容

1.河长制工作落实情况。河长制是否全覆盖，河长制的机构建设是否健全，河长制常态化工作机制是否建立，河长制工作资料台账是否齐全，对举报的问题是否处理并反馈举报人，河湖的管理是否逐步规范，河湖整治工作是否有力推进，河湖的水质和生态环境是否逐步改善等。

2.各相关单位工作开展情况。各相关单位是否协助河长做好河湖治理的相关工作。已建立的河长办是否做好治河的政策支持工作，是否做好治河信息、报表的及时上报工作。

3.上级单位督查发现的问题整改落实情况。对省、市督查中发现的问题，媒体报道的问题是否及时整改落实。

（四）监督检查的方法

主要采取到各单位实地抽查河湖整治情况、查阅河长制工作资料台账、听取汇报、综合评定等环节。

（五）监督检查结果的使用

1.督促整改。市督查组对河长制督查中发现的问题，提出整改意见，明确整改期限，督促整改工作。并将每个季度监督检查情况汇总作为各区“河长制”工作年终考核分数。

2.及时通报。每次的河长制工作督查及考核情况，市督查组将以通报形式报市委市政府主要领导、分管领导。

3.严格考核。每次的河长制工作督查及考核结果，将计入河长制工作年度考核的综合评分。

七、考核奖惩制度

“河长制”的河长、相关部门负责人、村级河段长承担的“河长制”落实情况将列入市、区两级政府（管委会）对其年度考核的工作中。具体按照河长制管理工作考核办法等相关文件进行考核。对推进河长制工作成效优秀的河长、责任单位予以通报表彰；对落实河长制不力的河长、河段长、相关部门负责人将由市政府采取全市通报等形式进行问责。河长、相关部门负责人、村级河段长履职情况的考核结果将作为党政领导干部年度考核评价的重要参考。
