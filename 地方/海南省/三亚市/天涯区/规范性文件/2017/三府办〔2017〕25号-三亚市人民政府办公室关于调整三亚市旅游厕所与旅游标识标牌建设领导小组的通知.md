# 三亚市人民政府办公室关于调整三亚市旅游厕所与旅游标识标牌建设领导小组的通知

三亚市人民政府办公室

关于调整三亚市旅游厕所与旅游标识标牌

建设领导小组的通知

各区人民政府，各管委会，市政府直属各单位：

因人事变动和工作需要，市政府决定调整三亚市旅游厕所与旅游标识标牌建设领导小组（以下简称领导小组），现将有关事项通知如下：

组 长：鲍 剑（市委常委、常务副市长）

副组长：李武军（市政府副秘书长）

樊 木（市旅游委主任）

文开平（三亚质量技术监督局局长）

黎 俊（市园林环卫局副局长）

成 员：张 利（市发展改革委主任）

张红艳（市精神文明办主任）

王 瑜（市财政局局长）

吴海钰（市商务局局长）

陈文军（市农业局局长）

唐国梁（市外事侨务办公室主任）

吴海峰（市交通运输局党组书记）

刘关山（市林业局党组书记）

张华文（吉阳区人民政府区长）

陈向奋（天涯区人民政府区长）

冯 强（崖州区人民政府区长）

海 斌（海棠区人民政府常务副区长）

周月霞（育才生态区管委会主任）

领导小组负责研究和协调解决我市旅游厕所与标识标牌建设和管理中的有关问题；提出全市旅游厕所与旅游标识标牌建设规划意见；推动全市旅游厕所与旅游标识标牌建设按计划进行；确定全市旅游厕所与旅游标识标牌管理的措施和办法；向省旅厕标办、国家旅游局、省政府报送全市旅游厕所与旅游标识标牌建设的有关信息。

领导小组下设办公室，设在市旅游委，负责承担领导小组日常工作。办公室主任由市旅游委主任樊木兼任。

三亚市人民政府办公室

2017年1月26日
