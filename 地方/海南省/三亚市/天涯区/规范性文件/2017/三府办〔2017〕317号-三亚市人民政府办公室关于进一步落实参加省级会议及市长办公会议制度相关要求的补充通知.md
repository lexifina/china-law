# 三亚市人民政府办公室关于进一步落实参加省级会议及市长办公会议制度相关要求的补充通知

三亚市人民政府办公室

关于进一步落实参加省级会议及市长办公会议制度相关要求的补充通知

各区人民政府，各管委会，市政府直属各单位：

为进一步提高会议效率，根据《三亚市人民政府市长办公会议制度》和《三亚市人民政府市长现场办公会议制度》规定，现将规范各区人民政府、市政府直属各单位参加会议的准备和落实工作相关要求补充通知如下：

一、参加省级会议相关要求。省政府或省直部门召开的需要我市多部门参加的会议，会前牵头部门要组织相关部门负责人召开协调会，对会议内容进行研究，沟通一致后再到省里参会；到省里参会的人员应当是参加协调会人员，如因特殊情况调整人员参加会议，参会人员必须了解市里协调会精神。会后应及时将会议精神和相关要求报告本单位主要负责人，重要的会议应报告分管市领导。若省级会议涉及应由市政府或我市未参会单位主导的事项，参会单位应于会后主动将会议内容书面报告市政府或该事项主导单位。

二、市长办公会相关要求。各单位按会议通知要求安排人员参会。若明确要求部门（区政府）副职以上领导参加的，原则上要按要求派员参会，如有特殊情况无法安排副职以上领导参会，则需提交本单位负责人签字的书面请假并经会议主持人同意后方可派员参会。各部门（区政府）参会人员要熟悉情况并提前与本单位主要负责人沟通，做好会上汇报的准备工作。会后要及时将会议精神向本单位主要负责人汇报，按照会议要求认真抓好落实。涉及各区、各工委书记参加会议的，按市委相关要求执行。

三、市长现场办公会相关要求。各单位按照会议通知要求派员参会，调研点的责任单位对点内调研工作负总责，按要求安排参会人员，认真做好调研准备，现场汇报人员要熟悉情况，汇报内容简明扼要。现场可根据需要提前准备展板、扩音器等设施设备，以提高会议效率。未经同意，禁止现场人员拍照、录像、上传网络等行为。

请各部门认真领会工作要求，如果因未遵守上述要求而出现工作纰漏的，市政府办公室将视情况予以通报批评。
