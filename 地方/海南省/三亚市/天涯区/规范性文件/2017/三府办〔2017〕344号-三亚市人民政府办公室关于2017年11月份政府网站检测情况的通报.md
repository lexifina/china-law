# 三亚市人民政府办公室关于2017年11月份政府网站检测情况的通报

三亚市人民政府办公室

关于2017年11月份政府网站检测情况的通报

各相关单位：

为进一步做好全国政府网站信息内容建设有关工作，有效解决政府网站“不及时、不准确、不回应、不实用”等问题，维护政府公信力，市政府办公室2017年11月1日至11月16日对全市纳入普查范围的网站进行了检测。现将有关情况通报如下：

一、总体情况

此次对我市正在运行的22个政府部门网站进行了检测，共有20个网站达标，2个网站未达标。其中达标网站得分在90分以上的有8个，得分在80-89分区间的有8个，得分在70-79分区间的有1个，得分在60-69分区间的有3个。

未达标的2个网站分别是“三亚市农业局”因“单项否决”指标中存在“网站不更新”情况，被判定为未达标；“三亚旅游官方政务网”因“单项否决”指标中“栏目不更新”情况，被判定为未达标。

二、主要问题

（一）网站仍存在信息更新不及时现象。此次检测的22个网站在监测时间点前2周内有13个网站存在栏目应更新未更新情况。其中“三亚市审计局”“三亚市卫生信息网”“三亚市卫生监督所”“三亚旅游官方政务网”“三亚市人力资源和社会保障局”“三亚市综合行政执法网”“三亚市林业局”等网站存在多个应更新未更新栏目。

（二）网站存在不可用链接。在监测时间点前2周内，“三亚市卫生信息网”网站首页存在无效链接4个，其他页面无效链接10个；“三亚市农业局”首页存在无效链接3个。

（三）网站安全防护水平较低。“三亚市农业局”“三亚旅游官方政务网”“三亚市海洋与渔业局”等网站安全防护系统脆弱，甚至缺乏防病毒、防篡改、防攻击等基本防护措施，应用系统存在风险漏洞且未及时修复，易被黑客攻击，数据信息存在严重安全隐患。

三、下一步工作要求

（一）各部门要加强对政府网站建设和管理工作的领导，针对普查发现的问题举一反三，进一步查漏补缺，加大对本部门网站的检查力度，巩固普查成效，避免出现整改不彻底、问题反弹等情况，扎实推动各级政府网站持续健康发展。

（二）根据《中华人民共和国政府信息公开条例》，在推进政府信息公开工作中需加强对公民个人隐私的保护。请各部门全面排查本部门政府网站及市级门户网站政府信息公开专栏已公开的信息中是否包含公民身份证、详细居住地址及联系方式和法律法规规定不得对外公开的信息。重点针对专项资金管理和分配、人事招考录用、保障性住房分配、农村危房改造、棚户区改造、扶贫救济等方面信息；各部门行政权力运行结果信息；各部门公开的依申请公开办理结果信息等三类信息进行排查。在确保应公开信息予以公开的同时，对公民身份证件、居住地址及联系方式等予以删除、遮挡或隐藏。建议身份证号遮挡方式为：46000119******0111，手机号遮挡方式为：130****0111。

（三）本次检测未达标网站的“三亚市农业局”“三亚旅游官方政务网”要采取有力措施进行整改，并于2017年11月28日前将整改情况书面报送市政府新闻信息领导小组办公室（市政府一办105室）。
