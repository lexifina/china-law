# 三亚市人民政府办公室关于三亚市月川生态绿道工程项目二期用地土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市月川生态绿道工程项目二期用地

土地调查有关事项的通知

吉阳区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对月川生态绿道工程项目二期用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目位于吉阳区月川片区，用地调查面积约154800平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市规划局审核出具的三亚市月川控规部分规划绿地及水域用地红线图。土地权属（海南平面坐标系）情况为：吉阳区月川村委会集体土地约17150平方米、国家所有土地约62008平方米、部队土地共约36221平方米、李忠标等10户个人土地共约574 平方米、市土地储备中心等6家机关单位国有土地共约11501平方米、三亚兰海水城旅业投资有限公司等10家公司国有土地共约27344平方米；土地利用现状（西安80坐标系）为农用地约17987平方米（其中有林地约11685平方米、灌木林地约6302平方米），建设用地约124158平方米（其中城市约119753平方米、建制镇约4405平方米），河流水面约12749平方米；该项目用地在土地利用总体规划调整完善（西安80坐标系）中规划为城镇用地约19630平方米、河流水面约10039平方米、水工建筑用地约20190平方米、林地约16196平方米、滩涂约23213平方米、园地约65628平方米。该项目为生态防护绿地，不列入农用地转用及征收报批计划。具体征地范围以市园林管理局与吉阳区政府现场实际勘测确认为准，现既有绿化带不列入该项目征地调查范围。

二、为做好该项土地调查工作，由吉阳区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土资源局负责征收集体土地范围内征地业务指导工作；市住房城乡建设局负责收回国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地及收回部队国有土地征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行；收回部队国有土地外的其他国有土地征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、根据2010年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，吉阳区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认工作。

五、为进一步做好被征地农民养老保险工作，吉阳区政府应根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神办理。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
