# 三亚市人民政府办公室关于三亚市实行汛期水库领导责任制和抗旱行政责任制的通知

三亚市人民政府办公室

关于三亚市实行汛期水库领导责任制和抗旱行政责任制的通知

各区人民政府，育才生态区管委会，市政府直属各单位：

为做好我市2017年水库防汛和全市抗旱工作，经市政府同意，现对大隆、赤田、水源池、福万、汤他、半岭、抱古等7宗大、中型水库实行汛期领导责任制和三亚市抗旱行政责任制。具体责任人如下：

大隆水库防汛行政责任人为市委副书记、市长吴岩峻；

赤田水库防汛行政责任人为市委常委、常务副市长鲍剑；

汤他水库防汛行政责任人为市政府副市长许振凌；

水源池水库防汛行政责任人为市政府副市长陈晓昆；

福万水库防汛行政责任人为市政府副市长蓝文全；

半岭水库防汛行政责任人为市政府副市长何世刚；

抱古水库防汛行政责任人为市政府副市长王铁明。

三亚市抗旱行政责任人为市政府副市长李劲松。

三亚市人民政府办公室

2017年2月24日
