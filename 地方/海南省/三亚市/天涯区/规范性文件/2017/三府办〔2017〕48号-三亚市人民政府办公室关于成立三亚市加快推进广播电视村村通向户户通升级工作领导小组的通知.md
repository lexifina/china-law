# 三亚市人民政府办公室关于成立三亚市加快推进广播电视村村通向户户通升级工作领导小组的通知

三亚市人民政府办公室

关于成立三亚市加快推进广播电视

村村通向户户通升级工作领导小组的通知

各区人民政府，各管委会，市政府直属各单位：

为加快推进我市广播电视村村通向户户通升级工作，市政府决定成立三亚市加快推进广播电视村村通向户户通升级工作领导小组。领导小组成员名单如下：

组 长：许振凌（市政府副市长）

副组长：丁 （市政府副秘书长）

陈震（市文化广电出版体育局局长）

华 斌（三亚广播电视台副台长）

成 员：张福豪（市发展改革委副主任）

史晓辉（市财政局调研员）

曾 文（市文化广电出版体育局调研员）

林 岳（市科技工业信息化局总工程师）

赵小南（三亚广播电视台副台长）

李开明（海棠区人民政府副区长）

陈 玮（吉阳区人民政府常务副区长）

吴小琳（天涯区人民政府副区长）

林 辉（崖州区人民政府副区长）

贾 鹏（育才生态区管委会副主任）

赵清波（三亚无线电监管站站长）

谢哲华（中国有线电视网络有限公司三亚分公司经理助理）

领导小组下设办公室，办公室设在市文化广电出版体育局，办公室主任由陈震兼任，办公室副主任由曾文兼任，办公室人员根据工作需要从各成员单位抽调组成。

三亚市人民政府办公室

2017年3月2日
