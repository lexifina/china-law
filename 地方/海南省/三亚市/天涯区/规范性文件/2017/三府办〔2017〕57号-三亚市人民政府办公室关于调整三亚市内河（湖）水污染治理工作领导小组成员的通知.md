# 三亚市人民政府办公室关于调整三亚市内河（湖）水污染治理工作领导小组成员的通知

三亚市人民政府办公室

关于调整三亚市内河（湖）水污染治理工作领导小组成员的通知

各区人民政府，育才生态区管委会，市各有关单位：

因人事变动和工作需要，现对三亚市城镇内河（湖）水污染治理工作领导小组成员进行调整。调整后组成人员如下:

组 长：吴岩峻（市委副书记、市人民政府市长）

副组长：李劲松（市人民政府副市长）

成 员：张华文（吉阳区人民政府区长）

陈向奋（天涯区人民政府区长）

冯 强（崖州区人民政府区长）

李开明（海棠区人民政府副区长）

周月霞（育才生态区管委会主任）

季端荣（市生态环境保护局局长）

马育红（市水务局局长）

陈文军（市农业局局长）

王 瑜（市财政局局长）

张 利（市发展和改革委员会主任）

吴清江（市海洋与渔业局党组书记）

刘关山（市林业局党组书记）

黎 俊（市园林环卫管理局局长）

吴海峰（市交通运输局局长）

王宏宁（市综合行政执法局局长）

蔡海宝（市科技工业信息化局副局长）

领导小组统筹领导全市城镇内河（湖）水污染治理专项工作，制定全市水环境治理行动方案和各部门专项治理方案，制定综合执法、巡查督导、挂牌督办、分级约谈、信息公开等专项工作制度和考核办法，建立水污染治理行政执法与司法衔接配合机制，指导各区、育才生态区实施专项治理，组织日常监督检查，协调解决治理过程中出现的难点和重点问题。

领导小组下设办公室，办公室设在市生态环境保护局，具体负责全市城镇内河（湖）水污染综合治理工作协调、检查督导和日常工作。

各区人民政府、育才生态区管委会成立相应的内河（湖）水污染治理工作领导小组，严格按照属地管理原则和法定生态环境和资源保护责任义务，切实落实各区人民政府、育才生态区管委会的主体责任。

三亚市人民政府办公室

2017年3月6日
