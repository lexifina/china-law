# 三亚市人民政府办公室关于印发三亚市迎接国家农村生活垃圾治理考核验收工作方案的通知

三亚市人民政府办公室

关于印发三亚市迎接国家农村生活垃圾治理

考核验收工作方案的通知

各区人民政府，各管委会，市各有关单位：

《三亚市迎接国家农村生活垃圾治理考核验收工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年3月9日

（此件主动公开）

三亚市迎接国家农村生活垃圾治理

考核验收工作方案

为迎接今年5月国家农村生活垃圾治理考核验收工作，确保我市顺利通过国家验收，根据《海南省城乡环境综合整治领导小组办公室关于深入开展农村生活垃圾治理工作的通知》（以下简称《通知》）要求，结合我市实际，特制定本方案。

一、工作目标

根据考核验收的“五有”（有设施设备、有治理技术、有保洁队伍、有监管制度、有资金保障）标准，按照“政府主导、全民参与、场镇统筹、属地管理”要求，以《通知》中明确的近期农村生活垃圾治理目标和十项任务为重点，全面推进我市农村垃圾处理，引导农民形成日常性的卫生清扫保洁习惯，用有效的工作机制推动农村垃圾的收集处理，营造干净、整洁、优美的农村环境,建设美丽乡村，以崭新的面貌顺利通过国家对我市农村生活垃圾治理考核验收工作。

二、组织领导

成立三亚市迎接国家农村垃圾治理考核验收工作领导小组，负责组织、指导、协调我市迎接国家农村垃圾治理考核验收的各项工作。其组成人员如下：

三、工作内容

（一） 完善设施设备

根据《三亚市农村生活垃圾清扫保洁实施方案》以及《通知》要求配齐各类垃圾运输车辆、钩臂箱、公用垃圾桶等；垃圾收集点、垃圾转运站的建设要进一步完善；行政村生活垃圾要100%得到收集转运和处理；生活垃圾焚烧发电厂三期要顺利推进。

（二）做到农村垃圾无害化处理

各区政府、育才生态区管委会、各国营农场要根据实际开展垃圾分类回收和垃圾定点定时收集工作。垃圾分类减量和资源回收后，外运处理类垃圾全部进入生活垃圾焚烧发电厂或填埋场进行无害化处理。

（三）强化农村保洁队伍建设

督促中标企业按《三亚市农村生活垃圾清扫保洁实施方案》和《通知》要求，加强对清扫保洁队伍的管理，配齐配足保洁人员，建立保洁人员花名册和台帐，按时足量发放保洁人员工资,保持队伍相对稳定。

（四）建立健全农村垃圾治理监管制度

建立市、区、村三级组织领导体系和考核机制。市区制定检查监督相关制度和方案，建立微信、信息或广播电视等多种形式的监督制度并有相应的奖惩措施；各村要通过村规民约、门前三包责任书等形式对村民进行制约，提高村民参与生活垃圾治理的自觉性。

（五）建立长效的资金保障机制

各区政府、育才生态区管委会要在市财政预算安排的农村垃圾清扫保洁经费的基础上，因地制宜，通过财政补助、社会帮扶、村镇自筹、村民适当缴费等方式筹集运行应急维护资金，使农村生活垃圾治理经费得到保障。

四、工作安排

（一）层层部署，全面动员（2017年3月15日前）

市迎接国家农村垃圾治理考核验收工作领导小组组织召开动员会，安排部署农村垃圾治理验收相关工作。各区政府、各国营农场要认真组织相关人员认真学习领会《通知》有关要求及《海南省农村生活垃圾治理考核验收办法》等相关内容，认真部署迎检工作。

（二）制定计划，成立机构（2017年3月15日-20日）

各区政府、育才生态区管委会、各国营农场，要切实加强组织领导，成立迎检工作小组，明确工作任务和时间节点，落实具体工作部门和人员，制定具体工作计划。组织机构人员名单和工作计划于2017年3月20日上午12时前报送市迎接国家农村垃圾治理考核验收工作领导小组（设在市园林环卫管理局）。

（三）逐项查摆，全面整改（2017年3月20日-4月30日）

各区政府、育才生态区管委会、各国营农场，要根据验收重点内容，对照《通知》中明确的近期农村生活垃圾治理目标和十项任务，逐项逐村进行查摆，边查边改，全面摸清家底，排查问题，形成问题整改台账。4月30日前务必将所有问题整改完毕，并将工作总结上报市迎接国家农村垃圾治理考核验收工作领导小组（设在市园林环卫管理局）。市、区要在4月上旬组成检查组对各受检单位进行中期的检查验收。

五、工作要求

（一）高度重视，认真组织

本次迎检工作，内容多、要求严、标准高，各单位要高度重视，各区的区长为第一责任人，要把迎接国家农村垃圾治理考核验收的每一项指标任务要落实到部门、落实到人，做的组织到位、领导到位、措施到位、责任到位。

（二）加强宣传，营造氛围

要充分利用黑板报、标语、广播、散发宣传单等形式，向群众进行广泛宣传，动员广大村民积极参与到农村垃圾治理工作，在村周边书写宣传标语，营造浓厚的迎检氛围。

（三）强化监督，责任追究

市迎接国家农村垃圾治理考核验收工作领导小组将采取定期查、重点查、随机查等多种方式开展检查监督。对工作中有突出表现的单位和个人予以通报表扬，对检查中发现的工作效率低下、责任不明确、标准不掌握、整改不及时并造成不良影响的单位和个人，单位要向市政府写出书面报告，同时要追究单位领导和相关责任人的责任。

（四）沟通协调，形成合力

各区政府、育才生态区管委会、各国营农场、市各相关部门，要按照各自职责分工及相关要求开展工作。对涉及多个部门的问题，要有大局意识，积极沟通，密切配合，形成强大的工作合力，杜绝推诿、扯皮现象发生。
