# 三亚市人民政府办公室关于成立三亚市创建公交都市工作领导小组的通知

三亚市人民政府办公室关于成立

三亚市创建公交都市工作领导小组的通知

各区人民政府，各管委会，市政府各有关单位：

为贯彻落实国家城市公共交通优先发展战略，提高城市公共交通服务水平，满足人民群众基本出行需要，根据《交通运输部办公厅关于全面推进公交都市建设等有关事项的通知》（交办运〔2016〕157号），经研究，我市决定成立三亚市创建公交都市工作领导小组，其组成人员如下：

领导小组主要负责创建公交都市工作的决策、协调和指导，定期组织召开创建公交都市工作会议。领导小组办公室设在市交通运输局，办公室主任由吴海峰兼任，办公室工作人员从各成员单位协调组成。办公室负责领导小组日常协调沟通等工作，主要承担三亚市公交都市建设实施方案的编制，对创建公交都市工作进行跟踪和督查，加强市相关职能单位的协调联系，定期向领导小组汇报创建公交都市工作进展情况，负责领导小组交办的其他工作。

各区人民政府，各管委会，市政府各有关单位要高度重视三亚市创建公交都市工作，加强组织领导，全力配合市交通运输局做好公交都市申报和创建工作，全面推进三亚市城市公共交通又好又快发展。
