# 三亚市天涯区人民政府关于三亚市中投悦府项目房屋征收决定的公告

三亚市天涯区人民政府

关于三亚市中投悦府项目房屋征收决定的公告

天府〔2017〕224号

因实施三亚市中投悦府项目需要，依照《国有土地上房屋征收与补偿条例》（国务院第590号令）的规定，决定征收三亚市中投悦府项目范围内的国有土地上的所有房屋。

一、征收项目名称

三亚市中投悦府项目

二、征收范围

三亚市中级人民法院职工楼及周边区域，东至消防路与中级人民法院办公楼用地边界交汇处，西至市公安局宿舍区东侧道路中线，东西长120米；南至政法路，北至三亚公安边防支队用地边线，南北长80米。总共70户，其中，两户独栋居民户。用地面积约12亩，需拆除房屋建筑面积约7384平方米。上述房屋被依法征收的，国有土地使用权同时收回。

三、征收主体

三亚市天涯区人民政府

四、房屋征收实施单位

三亚市天涯区住房和城乡建设局

五、征收签约期限

征收签约期限：2017年8月7日—2017年11月7日

六、房屋征收补偿方案：详见附件1

七、行政复议和行政诉讼权利

征收范围内的被征收人对本征收决定不服的，可以在征收决定书发布之日起60日内依法申请行政复议，也可以自征收决定发布之日起6个月内依法向人民法院提起行政诉讼。

八、其他事项

（一）征收实施期间，在征收范围内不得新建、扩建、改建房屋和改变房屋及土地用途的行为；违反规定实施的，不予补偿。

（二）房屋征收部门与被征收人在征收补偿签约期限内达不成补偿协议或被征收房屋所有权人不明确的，由本府按照征收补偿方案和有关规定作出补偿决定。被征收人在法定期限内不申请行政复议或者不提起行政诉讼，在补偿决定规定的期限内又不搬迁的，本府将依法申请人民法院强制执行。

（三）任何组织和个人对本次征收和补偿工作中违反《国有土地上房屋征收与补偿条例》的行为，都有权向有关部门举报。
