# 三亚市天涯区人民政府关于三亚湾“阳光海岸”片区棚户区改造项目不列入征收对象的公告

三亚市天涯区人民政府

关于三亚湾“阳光海岸”片区棚户区改造项目 不列入征收对象的公告

天府〔2017〕238号

各被征收人：

三亚湾“阳光海岸”片区棚户区改造项目已全面进入签约阶段，为尽快完成本项目房屋征收工作，保障被征收人的补偿安置权益。根据《三亚湾“阳光海岸”片区棚户区改造项目房屋征收决定的公告》《三亚湾“阳光海岸”片区棚户区改造征收补偿安置方案》的相关规定，现将不列入本项目征收对象的单位、小区、酒店公告如下：

不列入“阳光海岸”片区棚户区改造项目征收对象的名单:长城花园、望海花园小区、金海湾花园、金色港湾、步行街、东宏花园、昌达海景花园、天泽海韵酒店、仙居府酒店、胜意大酒店、海悦台、盛世新弟小区、昌达雅华香榭小区、水晶蓝湾小区、洛克铂金港湾、莲花公寓。

三亚市天涯区人民政府

2017年8月17日
