# 三亚市天涯区人民政府关于印发三亚湾“阳光海岸”片区棚户区改造项目征收补偿安置补充方案的通知

天府〔2017〕251号

三亚市天涯区人民政府

关于印发三亚湾“阳光海岸”片区棚户区改造 项目征收补偿安置补充方案的通知

区政府直属各单位，各居（村）委会，各有关单位：

《三亚湾“阳光海岸”片区棚户区改造项目征收补偿安置补充方案》已经天涯区二届区委常委第47次（扩大）会议、天涯区政府二届第30期政府常务会议审议通过，并经市住建局备案登记，现印发给你们，请遵照执行。

三亚市天涯区人民政府

2017年8月28日

（此件主动公开）

三亚湾“阳光海岸”片区棚户区改造项目

征收补偿安置补充方案

为进一步做好三亚湾“阳光海岸”片区棚户区改造征收补偿安置工作，根据《国有土地上房屋征收与补偿条例》（国务院令590号）、《三亚市棚户区改造房屋征收补偿安置暂行办法》（三府〔2015〕112号）等法律法规及规定，现在结合三亚湾“阳光海岸”片区棚户区改造征收项目实施过程中的实际情况，制定《三亚湾“阳光海岸”片区棚户区改造征收补偿安置方案》补充方案。

一、被征收房屋的认定

在《三亚湾“阳光海岸”片区棚户区征收补偿安置方案》第五条“被征收房屋的认定”基础上，补充以下内容。

被征收人有土地房屋所有权证书的，但登记的房屋面积发生拆改变动的，被征收房屋建筑面积的认定，作如下处理：

（一）拆改变动不超过原土地使用权及房屋建筑登记面积的，按照拆改变动后房屋实际面积确定。

（二）拆改变动超出原房屋建筑登记面积，但没有超过土地使用权登记面积的，按以下情况分别处理：

1．原房屋登记超过四层半（含四层半）的，在原房屋基础上进行拆改变动后，按原房屋所有权证记载的建筑面积予以认定并进行补偿；如拆改变动后的建筑物楼层超出原建筑物楼层的，增加房屋建筑面积在500㎡以内（含500㎡）的，按照800元/㎡予以补偿；超出500㎡以上部分，不予补偿。

2．原房屋登记面积没有超过四层半（含四层半）的，在原房屋基础上进行拆改，拆改后被征收房屋四层半（含四层半）以下部分，可予认定并进行补偿；超出四层半500㎡以内（含500㎡）部分，按照800元/㎡予以补偿；超出四层半500㎡以上部分，不予补偿。

3．没有拆改原房屋，但在登记的土地使用权范围内另行建造房屋的，或在原房屋基础上加宽面积的，按照《三亚湾“阳光海岸”片区棚户区征收补偿安置方案》第五条第三款的规定执行，即被征收人没有土地房屋所有权证书，但持有土地证、合法土地来源证明或社区出具的土地历史来源取得证明的被征收房屋四层半（含四层半）以下部分，可予认定并进行补偿；超出四层半500㎡（含500㎡）以内部分，可按800元/㎡予补偿；超出四层半500㎡以上部分，不予补偿。

4．将原房屋全部或部分拆除后，在原有土地上建造一栋及以上栋数房屋的，按照《三亚湾“阳光海岸”片区棚户区征收补偿安置方案》第五条第三款的规定执行，即被征收人没有土地房屋所有权证书，但持有土地证、合法土地来源证明或社区出具的土地历史来源取得证明的被征收房屋四层半（含四层半）以下部分，可予认定并进行补偿；超出四层半500㎡（含500㎡）以内部分，可按800元/㎡予补偿；超出四层半500㎡以上部分，不予补偿。

二、安置房建设地点

为更好的安置被征收人，在原方案基础上增加下列安置区作为异地安置区，且选择异地安置的，享受被征收房屋套内面积10%的奖励，具体如下：

山林君悦安置区、东岸安置区、抱坡新城安置区。

三、搬迁奖励

对于积极配合阳光海岸棚改项目的被征收人，在原方案基础上将搬迁奖励的条件调整为，按规定时间内签订房屋征收补偿安置协议，并在收到征收补偿款后七天内搬迁腾空房屋的给予搬迁奖励。具体如下：

（一）被征收人在本项目征收决定书公告之日起45日内（含45日）即2017年6月23日前（含当天）签订（或预签）房屋征收补偿安置协议的，并在收到征收补偿款后七天内搬迁腾空房屋的，一次性给予8万元/户的奖励。

（二）被征收人在本项目征收决定书公告之日起45日后至65日内（含65日）即2017年7月13日前（含当天）签订（或预签）房屋征收补偿安置协议的，并在收到征收补偿款后七天内搬迁腾空房屋的，一次性给予5万元/户的奖励。

（三）被征收人在本项目征收决定书公告之日起65日后即2017年7月14日及以后签订房屋征收补偿安置协议的，不给予任何货币奖励。

抄送：区委办，区人大办，区委各部门，各人民团体。
