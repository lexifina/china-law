# 关于海坡村委会西瓜村、芒果村棚户区改造项目范围内国有土地上房屋征收决定的公告

三亚市天涯区人民政府

关于海坡村委会西瓜村、芒果村棚户区改造项目范围内国有土地上

房屋征收决定的公告

天府〔2017〕267号

因实施海坡村委会西瓜村、芒果村棚户区改造项目需要，依照《国有土地上房屋征收与补偿条例》（国务院第590号令）的规定，决定征收海坡村委会西瓜村、芒果村棚户区改造项目范围内的国有土地上的所有房屋及附着物。

一、征收项目名称

海坡村委会西瓜村、芒果村棚户区改造项目

二、征收范围

项目四至范围：北至海榆西线规划主干道（含道路红线）、南至海坡人工河、西至椰林路、东至机场用地范围内的国有土地（具体范围四至坐标以项目规划红线的实际勘测定界为准,西瓜、芒果村国有土地发证情况详见附表）。项目总占地面积约132.6亩，总户数约15户（总占地面积及总户数以实际确认的数量为准）。上述房屋被依法征收的，国有土地使用权同时收回。

三、征收主体

三亚市天涯区人民政府

四、房屋征收实施单位

三亚市天涯区住房和城乡建设局

五、征收签约期限

征收签约期限：2017年8月28日——2017年11月28日

六、房屋征收补偿方案：（详见附件1）

七、行政复议和行政诉讼权利

征收范围内的被征收人对本征收决定不服的，可以在征收决定书发布之日起60日内依法申请行政复议，也可以自征收决定发布之日起6个月内依法向人民法院提起行政诉讼。

八、其他事项

（一）征收实施期间，在征收范围内不得新建、扩建、改建房屋和改变房屋及土地用途的行为；违反规定实施的，不予补偿。

（二）房屋征收部门与被征收人在征收补偿签约期限内达不成补偿协议或被征收房屋所有权人不明确的，由本府按照征收补偿方案和有关规定作出补偿决定。被征收人在法定期限内不申请行政复议或者不提起行政诉讼，在补偿决定规定的期限内又不搬迁的，本府将依法申请人民法院强制执行。

（三）任何组织和个人对本次征收和补偿工作中违反《国有土地上房屋征收与补偿条例》的行为，都有权向有关部门举报。
