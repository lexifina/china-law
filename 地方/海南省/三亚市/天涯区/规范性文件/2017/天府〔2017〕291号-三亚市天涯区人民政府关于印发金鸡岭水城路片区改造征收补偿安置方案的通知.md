# 三亚市天涯区人民政府关于印发金鸡岭水城路片区改造征收补偿安置方案的通知

天府〔2017〕291号

三亚市天涯区人民政府

关于印发金鸡岭水城路片区改造征收补偿安置方案的通知

区政府直属各单位，各居（村）委会，各有关单位：

《三亚市金鸡岭水城路片区改造征收补偿安置方案》已经天涯区二届区委常委第41次（扩大）会议、天涯区政府二届第1期政府常务会议审议通过，并经市住建局备案登记，现印发给你们，请遵照执行。

三亚市天涯区人民政府

2017年9月22日

（此件主动公开）

三亚市金鸡岭水城路片区改造征收

补偿安置方案

为改善三亚市金鸡岭水城路片区居民的居住环境，提升城市形象，加快推进该片区改造工作顺利进行，根据《中华人民共和国土地管理法》、《中华人民共和国城乡规划法》、《中华人民共和国物权法》、《国有土地上房屋征收评估办法》、《国有土地上房屋征收与补偿条例》（国务院令第590号）、《三亚市棚户区改造房屋征收补偿安置暂行办法》（三府〔2015〕112号）等规定，结合水城路片区范围内的实际情况，制定本方案。

一、征收范围及基本情况

三亚市金鸡岭水城路片区改造项目规划红线范围：北至中国人民解放军92810部队用地，南至月川社区居委会用地，西至水城路，东至金鸡岭社区居委会用地，总用地面积约12580.42平方米（合计18.87亩）。项目改造区域涉及总住户约46户，总人口约208人，总征收建筑面积约21055.82平方米（实际用地面积以测量为准）。

二、指导思想

坚持以科学发展观为指导，围绕国际性热带滨旅游城市、国际旅游岛建设的战略目标，改善城市面貌，提升城市品味、价值和形象，维护被征收人的合法权益，在依法征收的基础上，做到和谐征收。

三、征收主体

1．征收人：三亚市天涯区人民政府。

2．实施单位：三亚市天涯区住房和城乡建设局。

3．被征收人：项目范围内需要征收的房屋及其他建筑物、地上附着物的合法产权人。

四、征收补偿安置原则

（一）坚持“公开、公平、公正”、“依法和谐征收”原则。

（二）坚持“先补偿后搬迁”原则。

（三）坚持以人为本，让利于民，保障被征收户的合法利益。

（四）坚持依法征收和坚持打击违法、违章建筑相结合原则。

五、被征收房屋认定

（一）房屋征收范围内住宅范围、非住宅房屋的认定，按照房屋所有权证记载的用途确定。房屋所有权证没有记载用途，按照规划部门批准的用途确定。

（二）被征收房屋(含地下室）建筑面积的认定，按照房屋所有权证记载的建筑面积确定。房屋征收范围内已按照房改政策出售的房改房、公房以及经济适用房、单位集资房等福利住房，且尚未取得房屋所有权证的和其他不能确定房屋建筑面积的，建筑面积按照有资质测绘机构的测绘结果确定。

（三）被征收人没有房屋所有权证书，但持有土地证、合法土地来源证明或社区出具的土地历史来源取得证明的被征收房屋四层半（含四层半）以下部分，可予认定并进行补偿；超出四层半1000㎡（含1000㎡）以内部分，可按800元/㎡予补偿；超出四层半1000㎡以上部分，不予补偿。

（四）被征收人没有房屋所有权证书，也没有土地证、没有合法土地来源证明或社区出具的土地历史来源取得证明的被征收房屋，可按建筑物建成时间作如下处理：

1．1990年4月1日《中华人民共和国城市规划法》施行之前建成的，地面房屋四层半以内（含四层半）的部分按如下情况补偿：

（1）被征收人在三亚市内没有取得政府划拨土地或者没有享受其他优惠房屋政策的，按第六条的补偿标准予以补偿；

（2）被征收人在三亚市内取得政府划拨土地的，或者取得政策性保障住房的，按框架结构每平方米1350元、混合结构每平方米1100元且给予100%奖励的标准补偿。

地面房屋四层半以上的部分，在1000平方米以内的，给予800元/平方米的补偿，1000平方米以上的部分，不予补偿。

2．建成时间在1990年4月1日《中华人民共和国城市规划法》施行之后，2008年6月12日《中共三亚市委 三亚市人民政府关于坚决打击违法建设行为的决定》（三发〔2008〕3号）施行之前的被征收房屋四层半（含四层半）以下部分，可予以认定，可按政府房屋征收公告发布之日的建安成本价给予补偿；超出四层半1000㎡（含1000㎡）以内部分，可按800元/㎡予补偿；超出四层半1000㎡以上部分，不予补偿。

3．2008年6月12日《中共三亚市委 三亚市人民政府关于坚决打击违法建设行为的决定》（三发〔2008〕3号）施行之后建成的，不予补偿，应自行拆除。

被征收人房屋建成时间原则上按照以下程序认定：由社区居委会对本社区房屋建成时间进行调查和登记，经社区居民代表会议2/3以上居民代表人数讨论表决通过后公示7日，在公示期内无异议的，给予认定。

4．未超过批准期限的临时建筑，可按批准使用的剩余期限予以适当的货币补偿。

5．已超过批准期限的临时建筑不予补偿，应自行拆除。

六、补偿方式及标准

征收补偿方式分为货币补偿、产权置换、产权置换与货币补偿相结合三种方式，由被征收人自主选择，鼓励选择货币补偿方式。

（一）货币补偿标准

被征收人选择货币补偿的，可选择按安置房屋的市场评估价值补偿或按每平方米1.5万元的标准进行货币补偿。

（二）产权置换补偿标准

（三）房屋装修及地面附着物补偿标准

被征收房屋装修及地上附着物按市场评估价值补偿；树木青苗的补偿标准，参照《三亚市集体土地征收补偿安置管理规定（2013年修订）》（三府〔2013〕43号）执行或按市政府出台的最新文件、规定执行。

七、临时过渡及其它补偿

（一）临时过渡方案

1．被征收人可选择政府提供的临时过渡房屋，地点在金鸡岭花园新村小区，不再给予临时过渡安置补助；也可自行解决过渡安置，按3000元/月/户标准给予临时过渡费。临时过渡安置期以被征收人签订征收补偿安置协议、并腾空居住房屋之日起计算，一般为18个月（1年半），被征收人选择金盾小区6号或9号楼安置的，过渡安置期为6个月（半年）。

2．临时过渡安置期满后，被征收人仍未得到妥善安置的，从过渡安置期满后第一个月起，继续按3000元/月/户标准发放临时过渡费，直到妥善安置为止。

3．已做出单一货币补偿的被征收人不再享受临时过渡安置补偿。

4．临时过渡安置期一般不超过1年半（18个月）。

（二）搬迁补助费3000元/户

（三）其它费

1．空调迁移补助费：300元/部。

2．电话迁移补助费：200元/部。

3．有线电视、数字电视迁移补助费：400元/户。

4．太阳能热水器设备迁移补助费：800元/部。

5．水表迁移补助费：500元/户。

6．电表迁移补助费：600元/户。

7．天然气迁移补助费：2500元/户。

8．被征收的房屋已依法取得房产证的，换发安置房房产证所需费用由征收人承担；被征收的房屋未依法取得房产证的，换发安置房房产证所需费用由被征收人承担。

八、安置房地点

选择产权调换的安置房位于金鸡岭四组棚户区改造项目安置小区内。

九、保障政策

（一）被征收人的家庭人均收入低于最低生活保障的特困户、低保户、五保户（以区人民政府、区民政部门、区人事社保部门、辖区社区、辖区派出所共同出具证明证实，户口为三亚本地且在改造区域内）及廉租住房保障对象，依法将纳入最低生活保障，可直接向市相关部门申请租赁住房补贴或者公租房实物配租。

（二）从被征收人安置入住之年起，被征收人的子女可以选择继续就读原学校，也可以选择转学就读，需要转学就读的，市、区政府教育部门应当依据其新迁住址划定的招生范围免费依法办理相关手续。

（三）被征收人中的零就业家庭成员、抚养未成年子女的单亲家庭成员和享受最低生活保障待遇的人员，在法定劳动年龄内、有劳动能力和就业愿望的，由市、区政府人事社保部门给予核发《失业登记证》，纳入再就业政策扶持范围。

（四）被征收人在法定劳动年龄内持有《失业登记证》或属于城镇登记失业人员的，市、区政府人事社保部门应当给予免费职业技能培训和就业再就业税费减免等。

（五）实行财政补贴或扶持的各类社会公益性岗位，应当优先安排被征收人中持有《失业登记证》的零就业家庭成员及就业困难人员就业。

十、附则

（一）本方案中未尽事宜，按照《国有土地上房屋征收与补偿条例》及省、市有关规定，由征收实施单位与被征收人协商解决。

（二）本征收补偿安置方案由天涯区政府负责解释。

（三）本方案自公布之日起施行。

抄送：区委办，区人大办，区委各部门，各人民团体。
