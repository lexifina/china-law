# 三亚市天涯区人民政府办公室关于做好2018年度城乡居民基本医疗保险费征收工作的通知

天府办〔2017〕92号

三亚市天涯区人民政府办公室

关于做好2018年度城乡居民基本医疗保险费征收工作的通知

区委各部门、区政府直属各单位，各村（居）委会：

根据《海南省地方税务局 海南省人力资源和社会保障厅 海南省农村信用社联合社关于做好2018年度城镇居民基本医疗保险费征缴工作的通知》（琼地税发〔2017〕79号）文件有关规定，为做好我区2018年度城乡居民基本医疗保险费征收工作，现就有关问题通知如下：

一、征收任务和征收时间

我区2018年度城乡居民基本医疗保险费征收任务为 136000人（见附件《天涯区2018年度城乡居民基本医疗保险费征收工作任务分解表》），征收时间为2017年10月10日至12月20日。

二、城乡居民基本医疗保险征缴范围

（一）具有本市户籍，未纳入城镇从业人员基本医疗保险制度覆盖范围内的城乡居民（含农垦居民）；

（二）本市学籍的大中小学校、幼儿园在校（园）生；

（三）经市政府批准，参加城镇从业人员基本医疗保险确有困难的关闭破产企业退休人员和困难企业职工；

（四）已办理本市居住证且在户籍地非参保的非本市户籍居民和在本市暂住满一年及以上，且在户籍地非参保的外来务工人员（男未满60周岁，女未满55周岁）。

三、城乡居民基本医疗保险征缴标准

（一）2018年度参加城乡居民基本医疗保险的个人缴费标准统一为每人每年180元；

（二）建档立卡贫困户、重度残疾人、低保对象、低收入家庭60周岁以上老年人和未成年人、无城镇职工基本医疗保险的优抚对象等六类人员参保所需个人缴费部分由财政全额补助；非重度残疾人所需个人缴费部分由财政补助50%；

（三）被征收土地农民所需的个人缴费部分，因累计征地失去70%及以上农用地的，市财政每年按缴费标准全额代缴；因累计征地失去50%及以上不足70%的，市财政每年按缴费标准的50%代缴。市财政代缴参保费的期限最长为20年。

四、城乡居民基本医疗保险征缴办法

（一）本市户籍人员参保缴费

1．新参保人员，持本人身份证或户口簿到所辖村（居）委会进行参保登记后，刷卡缴费；

2．已有缴费记录的缴费人，可直接到村（居）委会刷卡缴费或到农商银行ATM、CRS机上自助缴费，或在海南农信的手机银行、微信银行、网上银行等渠道缴费；

3．低保对象、优抚对象、重度残疾人和低收入家庭60周岁以上老人，必须到所辖村（居）委会办理参保核定登记手续，未办理参保核定登记的，不能享受居民基本医疗保险待遇。

（二）非本市户籍人员参保缴费

需填写《三亚市外来务工人员参加城乡居民基本医疗保险申报核定表》，还需由现住地村（居）委会在《申报核定表》上加具证明意见和盖章确认。该表可向现住村（居）委会或各区社保部门领取。

五、工作要求

（一）加强组织领导。区人社局、包点单位、村（居）委会要把城乡居民基本医疗保险费征收工作作为一项重要工作来抓，形成主要领导亲自抓，分管领导具体抓，业务部门具体负责的工作格局。要分解任务，落实责任，全力推进，确保圆满完成征缴任务。

（二）加强政策宣传。区人社局要加大城乡居民基本医疗保险政策的宣传力度，做到城乡居民基本医疗保险政策深入人心，家喻户晓。要让城乡居民了解基本医疗保险的作用和参加医疗保险的好处，自觉自愿参保缴费。

（三）发挥职能作用。区人社局要深入各村（居）委会检查指导工作，协调解决有关问题并定期通报工作进展情况；各包点单位要深入包点社区发动、督促居民参保缴费工作；区政府督查室要加大督查力度，定期或不定期通报有关情况。区人社局、督查室、包点单位、各村（居）委会要充分发挥职能作用，互相配合，扎实推进居民参保缴费工作，确保按时完成我区城乡居民基本医疗保险参保缴费工作任务。
