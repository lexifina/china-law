# 三亚市人民政府办公室关于印发2018年三亚市落实省政府“菜十条”及“菜篮子”市长负责制工作方案的通知

三亚市人民政府办公室

关于印发2018年三亚市落实省政府“菜十条”及“菜篮子”市长负责制工作方案的通知

各区人民政府，育才生态区管委会，市各有关单位：

《2018年三亚市落实省政府“菜十条”及“菜篮子”市长负责制工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2018年4月21日

（此件主动公开）

2018年三亚市落实省政府“菜十条”及

“菜篮子”市长负责制工作方案

根据省政府“菜十条”和《海南省“菜篮子”市县长负责制考核办法》（琼府办〔2017〕123号）要求，依据《三亚市“菜篮子”保供稳价2018年—2020年行动计划》（三府〔2018〕6号）和《三亚市平价蔬菜产销联盟方案》（三府办〔2017〕336号），以及市委、市政府有关“菜篮子”工程建设及保供稳价工作一系列指示精神，为进一步提高我市“菜篮子”基地生产能力、市场供应能力、价格调控能力、应急保障能力、质量安全水平，提高市民对“菜篮子”工程建设的满意程度，特制定三亚市落实2018年省政府“菜十条”及 “菜篮子”市长负责制工作方案如下：

一、总体思路

贯彻落实省委、省政府和市委、市政府“菜篮子”工作的决策部署，全面落实市长负责制，坚持民生为重，坚持市场化运作和财政适当扶持，以完善“淡季、旺季、台风、春节”四个时段保供稳价模式为目标，以引导市场价格机制合理形成为落脚点，以扩大平价网点、构建产销对接机制、健全应急调控及保障体系、提升管理水平、提高质量安全为抓手，推动“菜篮子”工程建设步入生产能力稳定提升、产销衔接顺畅、质量安全可靠、市场竞争充分、价格波动可控、应急保障完备的可持续发展轨道。

二、主要任务及责任区分

（一）落实“菜篮子”区长负责制

一是各区政府（育才生态区管委会）对本行政区内的“菜篮子”工作负总责，将“菜篮子”工作列入议事日程，统筹规划“菜篮子”工程项目建设，建立“菜篮子”价格应急调控保障体系。二是成立区稳定“菜篮子”价格领导小组，下设办公室并配备工作人员，负责辖区内“菜篮子”工程保供稳价及社区平价网点建设,力争年内新建1个公益性平价市场或自由交易区，加大“菜篮子”保供稳价工作力度。三是将“菜篮子”建设资金纳入区政府年度财政预算。[牵头单位：各区政府、育才生态区管委会，配合单位：市发展改革委（市稳价办）、市政府督查室、市农业局、市商务会展局、市财政局]

（二）加强骨干调控蔬菜基地建设

一是集中财力扩大常年蔬菜应急调控基地建设面积。由市农业局牵头，各区政府（育才生态区管委会）配合，2018年市政府常年蔬菜应急调控基地总面积扩大到1000亩（其中：高标准的本地叶菜应急保障基地300亩），具体扶持政策由市农业部门和区政府制定。二是扶持引进适合本地种植的蔬菜品种，扶持改良种植技术创新、集约化育苗、标准化生产以及病虫害防治、质量安全检测等项目，并在天涯区建设1个豆苗、花生苗、蘑菇等工厂化生产试点基地，丰富保基本蔬菜供应品种。三是积极探索在岛内外蔬菜主产区建立总面积2000亩“异地蔬菜直供及应急保障基地”，重点保障我市特殊时段叶菜供应，市财政出资购买4台移动式蔬菜真空预冷机，同时进一步完善异地蔬菜调配扶持机制。四是建立常年蔬菜基地调整的占补平衡和补偿机制，稳定1.85万亩常年蔬菜种植面积保有量，其中，崖州区保有量为3300亩，天涯区保有量为6200亩，吉阳区保有量为5100亩，海棠区保有量为2300亩，育才生态区管委会保有量为1600亩。[牵头单位：各区政府、育才生态区管委会、市农业局，配合单位：市发展改革委（市稳价办）、市商务会展局、市财政局]

（三）加强畜禽养殖基地建设

一是发展规模化、标准化、产业化、品牌化、生态化健康养殖，增加养殖量，提高自给能力。二是加大对“龙头企业+托养”等带动农户畜牧养殖项目的扶持力度，建立农民增收长效机制。三是加强畜禽养殖数据库建设，积极搭建“畜禽养殖+精准扶贫+互联网电商”产销对接平台，推行定制畜牧业。四是扶持建设1个生猪应急调控保障基地，探索建立扶贫户生猪滞销处置扶持机制。年出栏总数:生猪26万头以上、肉牛1万头以上、肉羊5.5万只以上、家禽335万只以上；年存栏：蛋鸡27万只以上、奶牛400头以上。[牵头单位：各区政府、育才生态区管委会、市畜牧兽医局，配合单位：市财政局、市发展改革委（市稳价办）、市国土资源局、市规划委]

（四）加强“菜篮子”流通应急调控及保障体系建设

一是由市发展改革委（市稳价办）牵头，市双拥办、市商务会展局、市国土资源局、市规划委、相关驻军单位配合，探索我省首个“菜篮子军民融合”试点项目，市政府在“菜篮子”南海维权应急保障储备库建设方面予以扶持。二是在传统农贸市场周边区域开设“菜篮子配送服务站”，参照“保基本蔬菜应急投放点”做法予以扶持;按照5%的面积指标，继续在传统农贸市场或在人口密度大的区域开设18个保基本蔬菜应急投放点。三是结合旧城改造，在保障性住房小区（或棚改安置区）提前规划配置“菜篮子”平价网点，并将“菜篮子”平价专区建设纳入商铺招商的前置条件。四是优化平价网点布点与结构，继续扶持在大（中）型生活超市、保障性住房小区、人口密集小区开设保基本蔬菜平价专营区，提高平价网点覆盖面。五是完成海润路（七彩阳光）、原田独粮站等2个市政府公益性平价市场和大东海社区平价专营区（移动货仓）建设。六是开展农贸市场猪肉肉品公益性摊位和猪肉公益性铺面项目试点，逐步形成猪肉肉品价格调控能力。七是委托市信投公司，完成“三亚市‘菜篮子’信息化管理系统”建设，提升平价网点管理水平。八是在平价网点（或集中设置的专业冷库中心）扶持设置总面积1000平方米应急投放冷库。九是继续扶持平价蔬菜配送车辆（总数达18台），并配发“车辆入市区24小时通行证”。[牵头单位：市发展改革委（市稳价办）、各区政府、育才生态区管委会，配合单位：市商务会展局、市农业局、市国资委、市国土资源局、市规划委、市公安局、市食品药品监管局、市工商行政管理局、市综合执法局、市科技工业信息化局、市双拥办、三亚城投公司]

（五）落实社会救助和保障标准与物价上涨挂钩联动机制

根据《海南省人民政府关于进一步完善社会救助和保障标准与物价上涨挂钩联动机制的通知》（琼府〔2016〕114号）精神，落实优抚对象、低保对象、特困人员、领取失业保险金人员、全日制在校大中专（含技校）学生等五类群体发放价格临时补贴机制的同时，结合三亚实际，2018年将我市建档立卡贫困户学生和公办农村义务教育阶段的寄宿学生纳入价格临时补贴范围。[牵头单位：市发展改革委（市物价局），配合单位：市民政局、市教育局、市人力资源社会保障局、市扶贫办]

（六）做好居民消费价格总指数（CPI）信息运用和市场价格监测预警工作

一是相关部门应加强对居民消费价格总水平（CPI）变动情况研究与应用，按照“供给侧”改革要求，做好涉及调控物价的民生业态培育、供给与监管，促进市场充分竞争，保持物价总体稳定。二是密切关注粮油肉禽蛋菜等生活必需品的市场供应和价格变化，加强价格形势研判，做好价格监测预警，及时处置。[牵头单位：国家统计局三亚市调查队、市发展改革委（市稳价办），配合单位：市统计局、市商务会展局、市农业局]

（七）加强食品安全监管和市场价格监督检查

加强肉类和蔬菜等“菜篮子”质量安全追溯体系建设和食品安全监管。一是由市商务会展局牵头，实现批发市场、农贸市场、配送中心的农残检测室配备率达100%。二是由市农业局牵头，进一步完善本地农产品质量安全追溯体系。三是由市食品药品监管局牵头，加强流通环节食品安全监管，并指导市政府蔬菜应急调控配送中心和新鸿港批发市场完成农残检测室建设，市财政在场地租金、设施配备、人员配备等方面予以扶持。四是市食品药品监管局牵头，建立健全质量安全会商机制，综合施策，全面监管。五是创新农贸市场明码标价方式，加强提醒告诫，打击哄抬物价和跟风涨价行为。[牵头单位：各区政府、育才生态区管委会、市食品药品监管局、市农业局、市商务会展局，配合单位：市发展改革委（市稳价办）、市公安局、市工商行政管理局、市财政局]

（八）建立“菜篮子”保供稳价工作激励机制

一是建立平价网点等级评定及退出机制。由市发展改革委（市稳价办）牵头，与有资质的第三方评估机构合作，探索建立平价网点等级评定及退出机制，并将评定结果向社会公布。二是建立“菜篮子”工程建设工作表彰制度。结合平价网点建设成效以及“菜篮子”产品价格调控效果，建立“菜篮子”工作先进单位和个人表彰制度。[牵头单位：市发展改革委（市稳价办）、市政府督查室；配合单位：各区政府、育才生态区管委会、市农业局、市商务会展局、市财政局]

三、保障措施

（一）明确任务，各尽其责。各相关单位要根据“菜篮子”价格调控的总体要求，结合各自职责，做好工作调研，制定年度工作计划，明确责任分工、完成任务的时间节点、标准和要求，逐项抓好工作落实。各区政府（育才生态区管委会）要结合辖区内“菜篮子”项目发展与培育现状，高度重视对“菜篮子”价格调控项目建设与投入，通过市场资源的合理配置、有效供给，促进市场充分竞争，保持物价总体稳定。

（二）深入一线调研，加强跟踪督办。各相关单位分管领导要深入一线调研，摸清实情，根据“问题导向”制定专项落实方案，加强跟踪督办，解决“最后一公里问题”，确保“菜篮子”价格调控工作抓出成效。

（三）完善部门联动机制，提高工作效能。进一步完善工作机制，加强沟通协调，加大“菜篮子”工作暗访力度，依法依规加强市场整治，积极牵头组织部门联动、联合执法，提高工作效能。

（四）加强舆情引导，营造良好氛围。要积极与本地主流媒体协调，加强正面引导，及时发布“菜篮子”价格调控措施和成效；要创新工作方法，利用价格信息大数据引导生产、供应和消费；要严肃查处捏造、散布虚假价格信息行为，努力营造“菜篮子”保供稳价的良好社会环境。
