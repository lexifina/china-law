# 三亚市人民政府办公室关于2018年第四次政府网站检测情况的通报

三亚市人民政府办公室

关于2018年第四次政府网站检测情况的通报

各相关单位：

根据《国务院办公厅秘书局关于做好政府网站季度抽查工作的通知》（国办秘函〔2016〕48号）要求和《国务院办公厅关于开展第一次全国政府网站普查的通知》（国办发〔2015〕15号）确定的检查标准，2018年11月1日—11月14日，市政府办公室对全市纳入普查范围的网站进行了检测。现将有关情况通报如下：

一、总体情况

（一）网站检测情况。此次对我市正在运行的20个政府部门网站进行了检测，合格率为85%。其中得分在90分以上的有“三亚市旅游发展委员会”“三亚市人民政府政务服务中心”“三亚市生态环境保护局”“三亚市海洋与渔业局”“三亚市财政局”5个网站，得分在80-89分区间的有5个网站，得分在70-79分区间的有6个网站，得分在60-69分区间的有1个网站。

未达标的3个网站情况分别是：“三亚市林业局”网站因“单项否决”指标中存在“栏目未更新”情况，被判定为未达标；“三亚市综合执法局”“三亚市卫生和计划生育委员会”网站因“信息更新情况”累计扣分超过40分，被判定为未达标。

（二）政务公开暨政府网站第三方评估反馈问题整改情况。2018年7月至10月，省政务公开协调小组办公室先后转发了4期《2018年全省政务公开暨政府网站第三方评估情况》，评估反馈问题整改涉及我市共337条。为做好反馈问题整改工作，我市高度重视，截至目前，已完成整改279条，整改完成率83%。三亚市林业局未按规定将政务公开暨政府网站第三方评估反馈问题整改情况报送至市政府办公室。

（三）办理网站纠错留言情况。2018年8月—2018年11月，网民通过“我为政府网站找错”平台反映我市政府网站问题11条,大部分网站主办单位都能够及时对留言进行核实、处理和反馈,留言办结率为90%。

二、主要问题

（一）网站管理不到位。“三亚市林业局”网站集约至三亚市政府网站统一平台后，原网站“hisy.forestry.gov.cn”未按《三亚市政府网站集约化建设方案》进行关停注销。

（二）网站存在空白栏目。“三亚市林业局”“三亚市卫生和计划生育委员会”“三亚市综合行政执法局”网站分别存在3个以上空白栏目。

（三）网站内容保障不到位。三亚市林业局”网站10月至11月仅发布2条信息，“三亚市卫生和计划生育委员会”首页存在4个应更新未更新栏目，图片新闻栏目更新至2017年11月7日。

（四）网站互动渠道不顺畅。部分网站“首页-互动-政务咨询”栏目1年内无有效留言。

三、下一步工作要求

各单位要落实政府网站主办单位域名管理责任，根据《国务院办公厅关于加强政府网站域名管理的通知》（国办函〔2018〕55号）要求，对本单位及内设机构持有的域名进行全面梳理，清理注销不合规的域名、网站已关停但仍未注销的域名，以及被用于非政府网站的域名。

各政府网站主办单位要高度重视政府网站管理工作,建立健全信息发布审核和用户信息保护制度，畅通公众网络问政渠道，切实为群众咨询问题、建言献策提供便利。

本次检测中存在问题的“三亚市林业局”“三亚市卫生和计划生育委员会”“三亚市综合行政执法局”网站要采取有力措施进行整改，并于2018年11月26日前将整改情况报市政府办公室。
