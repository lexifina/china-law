# 关于三亚市天涯区南海渔村精品街区改造项目房屋拆迁补偿安置方案征求公众意见及修改情况的通知

三亚市天涯区人民政府

关于三亚市天涯区南海渔村精品街区改造项目房屋拆迁补偿安置方案征求公众意见及修改

情况的通知

根据《国有土地上房屋征收与补偿条例》（国务院令第590号）和《三亚市棚户区改造房屋征收补偿安置暂行办法》（三府〔2015〕112号）等规定，三亚市天涯区人民政府于2018年2月5日在三亚市天涯区南海渔村精品街区改造项目房屋征收（拆迁）范围内发布了《三亚市天涯区人民政府关于征求〈三亚市天涯区南海渔村精品街区改造项目房屋拆迁补偿安置方案〉意见的公告》，公布了《三亚市天涯区南海渔村精品街区改造项目房屋拆迁补偿安置方案》（征求意见稿），期限为2018年2月5日至2018年3月20日。

现将修改后的《三亚市天涯区南海渔村精品街区改造项目房屋拆迁补偿安置方案》（修改稿）公布，具体内容附后。
