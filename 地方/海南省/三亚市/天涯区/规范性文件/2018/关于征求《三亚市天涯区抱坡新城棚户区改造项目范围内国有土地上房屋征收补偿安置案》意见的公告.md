# 关于征求《三亚市天涯区抱坡新城棚户区改造项目范围内国有土地上房屋征收补偿安置案》意见的公告

三亚市天涯区人民政府

关于征求《三亚市天涯区抱坡新城棚户区改造

项目范围内国有土地上房屋征收补偿安置案》

意见的公告

根据《国有土地上房屋征收与补偿条例》（国务院令第590号）和《三亚市棚户区改造房屋征收补偿安置暂行办法》（三府〔2015〕112号）等规定，《三亚市天涯区抱坡新城棚户区改造项目范围内国有土地上房屋征收补偿安置方案》（以下简称《方案》）经组织有关部门反复论证并拟定。为进一步扩大公众参与，保障公众的知情权、参与权和建议权，现将《方案》在征收现场全文公布，公开征求征收范围内公众意见。

征求意见期限：2018年5月28日—2018年6月28日。

被征收人若认为《方案》不符合《国有土地上房屋征收与补偿条例》和《三亚市棚户区改造房屋征收补偿安置暂行办法》等有关规定的，请在征求意见期限内，通过以下3种形式向三亚市天涯区棚改办提出，并附本人身份证复印件、土地房屋权属证明复印件（电子邮件形式为扫描件）和联系方式。

1．电子邮件形式：意见反馈的电子邮箱：519172556@qq.com

2．邮寄形式（以邮戳日期为准,并在信封上注明：“三亚市天涯区抱坡新城棚户区改造项目范围内国有土地上房屋征收补偿安置方案征求意见”字样）：

邮寄地址：三亚市天涯区人民政府，邮编：572000，联系人：唐玲美，联系电话：88911336。

3．书面形式：地址：三亚市天涯区棚户区改造工作领导小组办公室，联系人：蔡小智，联系电话：88911086。
