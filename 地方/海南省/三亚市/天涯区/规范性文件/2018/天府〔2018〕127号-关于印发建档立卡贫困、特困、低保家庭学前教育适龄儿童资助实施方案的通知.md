# 关于印发建档立卡贫困、特困、低保家庭学前教育适龄儿童资助实施方案的通知

天府〔2018〕127号

三亚市天涯区人民政府

关于印发建档立卡贫困、特困、低保家庭

学前教育适龄儿童资助实施方案的通知

区政府直属各单位、各村（居）委会、各学校（含幼儿园）：

现将《建档立卡贫困、特困、低保家庭学前教育适龄儿童资助实施方案》印发给你们，请各单位遵照执行。

三亚市天涯区人民政府

2018年4月21日

（此件主动公开）

建档立卡贫困、特困、低保家庭学前教育适龄儿童资助实施方案

为贯彻中央扶贫开发工作会议精神，落实《中共中央 国务院关于打赢脱贫攻坚战的决定》《中共海南省委 海南省人民政府关于打赢脱贫攻坚战的实施意见》《海南省教育精神扶贫行动计划（2016-2020年）》《海南省人民政府办公厅关于建立义务教育阶段建档立卡家庭经济困难学生基本生活保障制度的通知》和《三亚市关于建档立卡家庭经济困难学生资助实施方案》，出台建档立卡家庭贫困、特困、低保学前教育适龄儿童特惠政策，打好教育精准扶贫攻坚战，特制定本实施方案。

一、指导思想

全面落实以党的十八大、十九大以及中央扶贫开发工作会议精神为指导，按照中央、省、市有关扶贫攻坚工作会议部署和要求，坚持“治贫先治愈，扶贫先找智”的扶贫攻坚工作方针，切实做好精准帮扶、精准资助工作，保障每一个建档立卡贫困、特困、低保家庭学前教育适龄儿童都能接受公平有质量的教育，顺利完成学前教育阶段。

二、工作目标

建立完善合理的资助体系，确保我区建档立卡贫困、特困、低保家庭学前教育适龄儿童“全上学、全资助、上好学”的目标，对全区建档立卡贫困、特困、低保学前教育学生的保教费、伙食费、住宿费达到全免。实现精准扶贫全覆盖和基本托底，从根本上阻断因学致贫和贫困代际传递。

三、资助对象

按照“定点帮扶，不落一户；困难资助，不落一生”的要求，对我区所有建档立卡贫困、特困、低保家庭适龄儿童学前教育阶段全程资助。

四、资助标准

在市财政资助每生每年4000元的基础上（未享受市级资助的由区财政补贴），按服务区域公办幼儿园收费标准（保教费、伙食费、住宿费）追加资助。

（一）高峰片区：天涯区抱前幼儿园4200元/年，追加每生每年200元。

（二）天涯片区：天涯区红塘幼儿园5550元/年，追加每生每年¥1,550元。

（三）凤凰片区：天涯区新联幼儿园5900元/年，追加每生每年¥1,900元。

（四）市区范围：三亚市第一幼儿园5600元/年，追加每生每年¥1,600元。

随着幼儿园收费标准变化增长追加。

五、方法及步骤

（一）区扶贫办、民宗局提供的建档立卡贫困、特困、低保学前教育阶段适龄儿童名单（提供时间：分别每年2月15日前和8月20日前），名单报至区教科局。

（二）区教科局督促和协调入园情况，达到全部入园（幼儿园签定入园确认表）。

六、资金来源和发放方式

资金主要由市财政局按标准补助，不足部分由区财政统筹予以追加，并通过财政惠民资金“一卡通”发放到学生或其监护人个人账户。

七、实施时间

从2018年9月起开始实施。

八、工作要求

（一）加强组织领导，明确工作职责

区教育、扶贫、民政和财政等部门要密切配合，明确补助内容、补助标准及审核发放程序，及时做好资助资金落实工作。

（二）强化资金管理，及时下达资金

区教育、扶贫、民政、财政等部门要切实加强资助资金管理，足额安排资金，确保资金及时发放、专款专用。各有关部门要加强对资助资金使用情况的监督检查，防止挤占挪用、弄虚作假套取资助资金行为的发生。

（三）加大宣传力度，营造良好氛围

区教育、扶贫、民政、财政部门和幼儿园要加强舆论宣传工作，通过新闻媒体、入户宣传、街头板报等多种形式，广泛宣传我区建档立卡贫困、特困、低保家庭学生补助政策，为政策实施营造良好的舆论氛围，使党和政府的这项惠民利民政策家喻户晓、深入人心。
