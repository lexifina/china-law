# 三亚市天涯区人民政府关于印发三亚湾“阳光海岸”片区棚户区改造征收补偿安置补充方案（二）的通知

天府〔2018〕266号

三亚市天涯区人民政府

关于印发三亚湾“阳光海岸”片区棚户区改造

征收补偿安置补充方案（二）的通知

区政府直属各单位，各居（村）委会，各有关单位：

《三亚湾“阳光海岸”片区棚户区改造征收补偿安置补充方案（二）》已经天涯区二届区委常委第105次（扩大）会议、天涯区政府二届第76次政府常务会议审议通过，并经市住建局备案登记，现印发给你们，请遵照执行。

三亚市天涯区人民政府

2018年8月1日

（此件主动公开）

三亚湾“阳光海岸”片区棚户区改造征收补偿

安置补充方案（二）

为进一步做好三亚湾“阳光海岸”片区棚户区改造征收补偿安置工作，根据《国有土地上房屋征收与补偿条例》（国务院令590号）、《三亚市棚户区改造房屋征收补偿安置暂行办法》（三府〔2015〕112号）等法律法规及规定，现在结合三亚湾“阳光海岸”片区棚户区改造征收项目实施过程中的实际情况，制定本补充方案（二）。

一、三亚湾“阳光海岸”片区棚户区改造二期项目

三亚湾“阳光海岸”片区棚户区改造二期项目定于2018年8月1日正式启动。

二、二期项目具体范围为：“阳光海岸”项目区域中除港务局至光明路片区以及胜利路北段以外的区域。

三、安置房建设地点

三亚湾“阳光海岸”片区棚户区改造项目安置区为市食品厂安置区，市原武装部安置区，东岸安置区，海坡安置区二期，西瓜村、芒果村安置区二期，金鸡岭四组片区安置区。

其中，东岸安置区，海坡安置区二期，西瓜村、芒果村安置区二期三个安置区为异地安置。选择异地安置的，享受被征收房屋产权置换套内面积10%的奖励。

四、搬迁奖励

积极配合清点、丈量、登记、评估等工作，在规定时间内签订房屋征收补偿安置协议，并在收到征收补偿款后七天内搬迁腾空房屋的被征收人给予奖励。具体签约时间及奖励情况如下：

（一）被征收人在本项目补充方案（二）公告前，或公告之日起45日内（含45日）即2018年9月14日前（含当天）签订（或预签）房屋征收补偿安置协议的，一次性给予8万元/户的奖励。

（二）被征收人在本项目补充方案（二）公告之日起45日后至65日内（含65日）即2018年10月4日前（含当天）签订（或预签）房屋征收补偿安置协议的，一次性给予5万元/户的奖励。

（三）被征收人在本项目补充方案（二）公告之日起65日后即2018年10月4日后签订房屋征收补偿安置协议和搬迁的，不给予任何货币奖励。

五、附则

本补充方案（二）与《三亚湾“阳光海岸”片区棚户区改造征收补偿安置方案》（天府〔2017〕117号）、《三亚湾“阳光海岸”片区棚户区改造征收补偿安置补充方案》（天府〔2017〕117号）不一致的，以补充方案（二）为准。

抄送：区委办，区人大办，区委各部门，各人民团体。

三亚市天涯区人民政府办公室 2018年8月1日印发
