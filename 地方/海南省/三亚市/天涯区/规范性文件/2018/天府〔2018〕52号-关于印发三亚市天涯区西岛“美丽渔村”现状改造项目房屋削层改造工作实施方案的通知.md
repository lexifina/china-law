# 关于印发三亚市天涯区西岛“美丽渔村”现状改造项目房屋削层改造工作实施方案的通知

天府〔2018〕52号

三亚市天涯区人民政府

关于印发三亚市天涯区西岛“美丽渔村”现状

改造项目房屋削层改造工作实施方案的通知

区各相关单位：

经区委、区政府同意，现将《三亚市天涯区西岛“美丽渔村”现状改造项目房屋削层改造工作实施方案》印发给你们，请遵照执行。

三亚市天涯区人民政府

2018年2月11日

（此件主动公开）

三亚市天涯区西岛“美丽渔村”现状改造项目 房屋削层改造工作实施方案

一、指导思想

为了完善西岛基础设施，改善渔村面貌和居民居住条件及生活环境，提升渔村品位、价值和形象，打造渔村文化风情小镇，盘整现状民居建筑，保留已有权属建筑，全面提升渔村景观环境，维护被改造对象的合法权益，结合西岛渔村区域范围内的实际情况，制定本方案。

二、改造范围及基本情况

三亚市天涯区西岛社区辖区范围内的所有超过三层的13栋楼房，总占地面积3259.29平方米，需改造削层面积5910.85平方米（最终以实际测绘面积为准）。

由区委政法委负责对削层房屋进行风险评估，由区住建局负责房屋削层前后的检测等工作，由区规划分局牵头，区住建局、区国土分局配合做好被削层拆除房屋备案工作，由区城管局负责涉及违章、违法建筑拆除等工作，由区法制办负责整项拆除工作的法律解释等工作，由区旅游文体局负责相关协调工作，由区项目推进服务中心负责指导西岛社区做好拆除房屋的制表赔偿等工作，由区应急联动中心、西岛社区居委会负责政策解释、发动宣传、以及组织村民拆除等工作，西岛社区负责做好制表补助相关工作，由西岛景区负责协调好进出岛交通问题。

领导小组下设办公室在区住建局，办公室主任由冯焕彬同志兼任，负责综合协调等工作，工作人员从各相关部门抽调，项目建设过程中遇到本方案未明确的问题，由领导小组召开工作会议研究确定。

四、补助原则

按照本项目现状改造规划设计及建设要求，需要对改造区域内所有房屋及建筑附着物三层以下（含三层）部分予以保留并进行立面改造，三层以上部分进行削层拆除，按照相关优惠政策规定，由改造实施单位负责对同意参与立面改造并签订补助协议的被改造对象该部分房屋按相关规定办理房屋备案手续，相关办理费用由改造实施单位承担。

（一）未取得合法手续房屋。配合改造单位对房屋三层以上部分削层拆除后，由改造单位对三层以下部分按相关规定负责办理房屋备案手续，超出三层500㎡（含500㎡）以内部分，按1000元/㎡予以货币补助，超出三层500㎡以上部分，不予以补助。

（二）对需削层处理房屋，经被改造房屋产权人确认后，由区住建局委托具有相应资质的检测机构进行检测并出具检测报告，根据检测报告确定适合进行削层改造的房屋并牵头组织拆除需削层部分房屋，房屋削层并进行立面改造后，经检测，原本适合进行削层改造的房屋因改造单位的原因导致出现漏水、墙体裂缝等质量原因的，由改造单位负责解决，检测费用由改造实施单位承担。

（三）自削层改造公告发布之日起，改造单位组织相关部门对被削层、立面改造的房屋进行审查，并按相关法律规定进行处理。被改造房屋产权人在削层改造公告发布之日起10日内积极配合改造单位进行房屋削层改造的，由改造单位给予签约奖励。被改造房屋被依法认定为违法建筑的，按照相关规定处理，不予补助。

五、临时过渡及其它补助

（一）临时过渡安置费

临时过渡安置由被改造对象自行解决，按照3600元/户/月的标准一次性发放3个月的临时过渡费给被改造对象（临时过渡安置期以被改造对象签订改造补助安置协议并腾空居住房屋之日起计算）。

（二）搬迁补助费

搬迁补助费标准为6000元/户一次性结清。

（三）其它费

1. 空调迁移补助费：300元/部。

2. 电话迁移补助费：200元/部。

3. 有线电视、数字电视迁移补助费：400元/户。

4. 太阳能热水器设备迁移补助费：800元/部。

5. 水表迁移补助费：500元/户。

6. 电表迁移补助费：600元/户。

7. 天然气迁移补助费：2500元/户。

8. 签约奖励：削层拆除改造公告发布10日内与改造单位进行签订房屋削层改造协议的被改造对象，给予奖励8万元/户。

六、附则

（一）本方案中的“户”按下列原则确定：被改造房屋有房屋所有权证书的，按照“一证一户”原则确定；没有房屋所有权证书，按照“一栋一户”的原则确定；行政事业单位、国有和集体企业的房改房、公房、经济适用房和单位集资房等福利住房，按 “一协议一户”的原则确定。

（二）本方案中“三层”的含义：是指地上建筑三层总面积。

（三）本方案中未尽事宜，或在房屋改造削层过程中需对本方案的有关内容进行调整的，由三亚市天涯区人民政府会议研究确定。

（四）本房屋改造削层工作实施方案由三亚市天涯区人民政府负责解释。

（五）本方案自公布之日起施行。

三亚市天涯区人民政府办公室
