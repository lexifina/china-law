# 三亚市天涯区人民政府办公室关于成立三亚市天涯区农民工工作领导小组的通知

天府办〔2018〕95号

三亚市天涯区人民政府办公室

关于成立三亚市天涯区农民工工作领导小组的通知

区各相关单位：

为保障和维护我区农民工权益，进一步做好为农民工的服务工作，促进社会和谐稳定，根据《三亚市人民政府办公室关于成立三亚市农民工工作领导小组的通知》（三府办〔2016〕206号）文件精神，结合我区实际情况，决定成立三亚市天涯区农民工工作领导小组。现将有关事项通知如下：

二、领导小组主要职责

领导小组负责组织拟订和审议全区农民工工作的重大政策、措施，组织推动农民工工作，督促检查全区各单位相关农民工政策落实和任务完成情况，统筹协调解决政策落实过程中的重点难点问题。

领导小组下设办公室，办公室设在区人社局，郭宏伟同志兼任办公室主任，负责领导小组日常工作开展。
