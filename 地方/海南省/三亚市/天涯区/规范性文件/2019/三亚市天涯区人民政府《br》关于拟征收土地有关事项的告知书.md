# 三亚市天涯区人民政府<br>关于拟征收土地有关事项的告知书

三亚市天涯区人民政府

关于拟征收土地有关事项的告知书

三亚市天涯区桶井村委会：

根据三亚市凤凰机场支管网配套污水改造项目海新路北段道路工程建设需要，市政府以《三亚市凤凰机场支管网配套污水改造项目海新路北段道路工程土地调查有关事项的通知》（三府办〔2019〕148号）文拟征收三亚市天涯区桶井村委会集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市天涯区桶井村辖区内，用地面积为23.74亩。

二、拟征收土地的项目用途为三亚市凤凰机场支管网配套污水改造项目海新路北段道路。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出具确认意见。

特此告知。

三亚市天涯区人民政府

2019年10月5日
