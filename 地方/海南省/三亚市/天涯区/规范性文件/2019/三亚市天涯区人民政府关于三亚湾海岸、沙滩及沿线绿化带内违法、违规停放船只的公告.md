# 三亚市天涯区人民政府关于三亚湾海岸、沙滩及沿线绿化带内违法、违规停放船只的公告

三亚市天涯区人民政府

关于三亚湾海岸、沙滩及沿线绿化带内违法、违规停放船只的公告

根据《中华人民共和国渔业法》、中华人民共和国建设部《城市绿线管理办法》（中华人民共和国建设部令第112号）、《三亚市天涯区人民政府关于加强三亚湾区域管理的二十五条通告》等法律、法规及相关规范性文件的规定，现就三亚湾海岸、沙滩及沿线绿化带内违法、违规停放船只公告如下：

一、三亚湾沿岸沙滩、绿化带内严禁摆放任何船只。

二、停放于三亚湾沿岸沙滩、绿化带内的证照齐全的船只，限于2019年8月5日前，按船舶登记证书及船籍港管理要求，停泊到证书上明确的船籍港或自行驶离三亚湾区域。

三、对于“三无”（指无船名船号、无船舶证书、无船籍港）船只，限于2019年8月5日之前，其所有人将属于自己船只自行驶（拖）离三亚湾区域（含三亚湾海域、沙滩和海岸沿线绿化带）。

四、2019年8月5日以后，对仍违法、违规停放于三亚湾沿岸沙滩、绿化带内，未按本公告要求处理的船只，三亚市天涯区人民政府将依法责成相关执法部门对违法、违规停放的船只进行拖离和清理。

特此公告。

三亚市天涯区人民政府
