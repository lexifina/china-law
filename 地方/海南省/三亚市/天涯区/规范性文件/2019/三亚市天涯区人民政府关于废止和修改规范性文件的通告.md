# 三亚市天涯区人民政府关于废止和修改规范性文件的通告

三亚市天涯区人民政府

关于废止和修改规范性文件的通告

区政府直属各单位、各村（居）委会:

根据《三亚市人民政府办公室关于认真做好规范性文件清理工作的通知》（三府办〔2019〕81号）、《三亚市人民政府办公室关于对各区行政规范性文件清理的意见》（三府办〔2019〕163号）和《海南省行政规范性文件制定与备案规定》（海南省人民政府第285号令）的要求， 我区对2015年-2018年制定实施的8件规范性文件进行了清理，决定废止《天涯区三亚河生态环境常态化管控办法》1件规范性文件（具体见附件1），修改《天涯区畜禽养殖污染防治管理暂行办法》等7 件规范性文件（具体见附件2），现予公布。废止的1件行政规范性文件，自本通告公布之日起停止执行。修改的7件行政规范性文件，请各责任单位根据本通告做相应修正后重新公布。
