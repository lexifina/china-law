# 三亚市天涯区人民政府关于征求《三亚市第一农贸市场改造项目征收补偿安置方案》意见的公告

三亚市天涯区人民政府

关于征求《三亚市第一农贸市场改造项目征收补偿安置方案》意见的公告

根据《国有土地上房屋征收与补偿条例》（国务院令第590号）和《三亚市棚户区改造房屋征收补偿安置暂行办法》（三府〔2015〕112号）等规定，《三亚市第一农贸市场改造项目征收补偿安置方案》（以下简称《方案》）经组织有关部门反复论证并拟定。为进一步扩大公众参与，保障公众的知情权、参与权和建议权，现将《方案》在征收现场全文公布，公开征求征收范围内公众意见。

征求意见期限：2019年12月13日—2020年1月12日。

被征收人若认为《方案》不符合《国有土地上房屋征收与补偿条例》和《三亚市棚户区改造房屋征收补偿安置暂行办法》等有关规定的，请在征求意见期限内，通过以下3种形式向三亚市天涯区棚改办提出，并附上本人身份证复印件、土地房屋权属证明复印件（电子邮件形式为扫描件）和联系方式。
