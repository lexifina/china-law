# 三亚市天涯区人民政府关于拟征收土地有关事项的告知书

三亚市天涯区人民政府

关于拟征收土地有关事项的告知书

三亚市天涯区梅村村委会：

因我市的城市建设需要，市政府以《关于三亚凤凰机场站坪扩建工程用地征收土地调查有关问题的通知》（三府办〔2007〕26号）文拟征收天涯区梅村村委会集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于三亚市天涯区梅村村委会，用地面积为9.8479公顷，涉及农用地4.1493公顷、建设用地5.6425公顷、未利用地0.0561公顷。

二、拟征收土地的项目用途为机场用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我区将在15天内举行听证会；如无异议，请出据确认意见。

特此告知。

三亚市天涯区人民政府

2019年11月14日
