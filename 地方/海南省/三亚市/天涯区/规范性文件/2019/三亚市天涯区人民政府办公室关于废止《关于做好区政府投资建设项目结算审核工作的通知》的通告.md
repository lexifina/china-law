# 三亚市天涯区人民政府办公室关于废止《关于做好区政府投资建设项目结算审核工作的通知》的通告

三亚市天涯区人民政府办公室

关于废止《关于做好区政府投资建设项目结算审核工作的通知》的通告

区各相关单位、各村（居）委会：

根据国务院办公厅《关于聚焦企业关切进一步推动优化营商环境政策落实的通知》（国办发〔2018〕104号）以及财政部《关于促进政府采购公平竞争优化营商环境的通知》（财库〔2019〕38号）文件要求，我办决定对《关于做好区政府投资建设项目结算审核工作的通知》（天府办〔2015〕76号）文予以废止，自本通告公布之日起停止执行。

附件：三亚市天涯区政府废止的规范性文件名录

三亚市天涯区人民政府办公室
