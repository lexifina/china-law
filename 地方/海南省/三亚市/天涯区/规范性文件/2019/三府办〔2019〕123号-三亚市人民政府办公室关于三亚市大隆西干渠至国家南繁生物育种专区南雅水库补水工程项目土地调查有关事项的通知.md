# 三亚市人民政府办公室关于三亚市大隆西干渠至国家南繁生物育种专区南雅水库补水工程项目土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市大隆西干渠至国家南繁生物育种专区南雅水库补水工程项目

土地调查有关事项的通知

崖州区人民政府，市政府各有关单位：

根据三亚市总体规划和项目建设需要，经市政府同意，对三亚市大隆西干渠至国家南繁生物育种专区南雅水库补水工程项目用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于三亚市崖州区，用地调查面积约4511平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见三亚市城市总规中部分生产防护绿地、农用地及生态用地、公共绿地及山体等用地红线图。土地权属（海南平面坐标系）情况为崖州区北岭村委会集体土地约4001平方米、海南农垦南繁产业集团有限公司国有土地约506平方米、市政府国有土地约4平方米；土地利用现状（2000国家大地坐标系）为农用地约4507平方米（其中旱地约375平方米、果园约4061平方米、其他园地约70平方米、人工牧草地约1平方米）、村庄约7平方米；该项目用地在《三亚市总体规划（空间类2015-2030）》（市多规合一）中规划为基本农田、Ⅳ级保护林地和园地。该项目用地保留原规划用地性质不变，按农业附属设施用地方式使用土地，不列入我市农用地转用及征收报批计划。

二、为做好该项土地调查工作，由崖州区人民政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市自然资源和规划局负责对征收集体土地范围内征地业务进行指导；市住房和城乡建设局负责对国有土地上的房屋征收与补偿工作进行指导。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地和收回农场国有土地的征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行；收回其他国有土地的征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）等规定执行。

四、根据2010年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，崖州区人民政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认工作。

五、为进一步做好被征地农民养老保险工作，崖州区人民政府应根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神办理。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。崖州区人民政府、各相关职能部门一定要提高依法用地意识，决不能产生新的违法用地。
