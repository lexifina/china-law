# 三亚市人民政府办公室关于对各区行政规范性文件清理的意见

三亚市人民政府办公室

关于对各区行政规范性文件清理的意见

各区人民政府：

根据国务院《全面推进依法行政实施纲要》（国发〔2004〕10号）“建立和完善行政法规、规章修改、废止的工作制度和规章、规范性文件的定期清理制度”和《关于加强市县政府依法行政的决定》（国发〔2008〕17号）“市县政府及其部门每隔两年要进行一次规范性文件清理工作”的规定。区一级政府本应主动清理2019年1月1日前对外公布的行政规范性文件，并按照《海南省行政规范性文件制定与备案规定》（海南省人民政府第285号令）的规定对外公布清理结果。

此次市政府以2019年“废改立”工作为契机，一并对各区政府对外发布的16个行政规范性文件作出初步清理意见，请你单位结合实际进一步完善后报市司法局备案并对外公布。
