# 三亚市人民政府办公室关于三亚市抱坡片区市政道路一期工程项目土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市抱坡片区市政道路一期工程项目

土地调查有关事项的通知

吉阳区人民政府，市政府各有关单位：

根据三亚市总体规划和项目建设需要，经市政府同意，对抱坡片区市政道路一期工程项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于吉阳区抱坡片区内，用地调查面积约12215平方米（海南平面坐标系），具体土地调查范围四至及坐标详见三亚市抱坡片区市政道路一期工程用地红线图。土地权属（海南平面坐标系）情况为吉阳区抱坡村委会集体土地约5885平方米、吉阳区东岸村委会集体土地约904平方米、南新农场国有土地约1230平方米、师部农场国有土地约1237平方米、三亚警备区国有土地约2852平方米、三亚水泥厂国有土地约107平方米；土地利用现状（2000国家大地坐标系）为农用地约11846平方米（其中水田约6735平方米、旱地约2273平方米、果园约2139平方米、坑塘水面约184平方米、设施农用地约515平方米）、建设用地约376平方米（其中公路用地约9平方米、建制镇约362平方米、风景名胜及特殊用地约5平方米）；该项目用地已纳入《三亚市总体规划（空间类2015年-2030年）》（市“多规合一”2019年动态调整版）中，规划用地性质均为公路用地。上述用地涉及的约9008平方米耕地在办理农用地转用时，从我市耕地占补平衡指标中统筹安排。待完成占补平衡任务后，由市住房和城乡建设局按要求提供用地报批材料，市自然资源和规划局将其列入当年新增建设用地指标并办理农转用及征收报批手续。

二、为做好该项土地调查工作，由吉阳区人民政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市自然资源和规划局负责对集体土地范围内的征地工作进行指导；市住房和城乡建设局负责对国有土地上的房屋征收与补偿工作进行指导。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地和收回农场、部队国有土地的征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行。收回其他国有土地的征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）等规定执行。

四、根据2010年6月26日原国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，吉阳区人民政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认，向市自然资源和规划局出具履行征地前告知等程序的证明及土地权属确认意见（附件1）。待市政府批准征地后，征收土地公告和征地补偿安置方案公告可同步进行。

五、为进一步做好被征地农民养老保险工作，根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神，应在本通知下发后10个工作日内对项目征收农用地和享受缴费补贴人数等情况进行调查，组织村（居）小组填写《征地项目被征地农民基本情况调查表》（附件2），经村（居）委会、吉阳区人民政府逐级审核后，由吉阳区人民政府汇总填写《征地项目被征地农民基本情况乡镇调查汇总表》（附件3），并将上述两种表格报送市自然资源和规划局。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。吉阳区人民政府、各相关职能部门一定要提高依法用地意识，新的项目决不能产生违法用地。
