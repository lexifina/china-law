# 三亚市天涯区人民政府关于对2018年度优秀公务员给予三等功和嘉奖的决定

天府〔2019〕124号

三亚市天涯区人民政府

关于对2018年度优秀公务员给予三等功和嘉奖的决定

区政府直属各单位：

根据《公务员奖励规定（试行）》《海南省公务员考核实施办法（试行）》和《中共三亚市天涯区委组织部 三亚市天涯区人力资源和社会保障局关于做好2018年区属机关事业单位科员及以下工作人员年度考核工作的通知》（天人社〔2019〕10号）的精神，决定对张林等4名同志记三等功，江小全等15名同志给予嘉奖。

希望受表彰的同志戒骄戒躁，再接再厉，再创佳绩。同时，号召全区广大干部向先进同志学习，开拓创新，锐意进取，为建设“美丽天涯”而不懈奋斗。
