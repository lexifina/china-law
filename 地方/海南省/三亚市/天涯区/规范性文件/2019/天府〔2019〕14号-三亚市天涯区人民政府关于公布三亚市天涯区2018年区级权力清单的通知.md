# 三亚市天涯区人民政府关于公布三亚市天涯区2018年区级权力清单的通知

天府〔2019〕14号

三亚市天涯区人民政府

关于公布三亚市天涯区2018年区级权力清单的通知

区政府直属各单位：

为深化行政体制改革，进一步转变政府职能，推进行政权力规范公开透明运行，按照《海南省人民政府办公厅关于在全省各市县人民政府开展职权清理推行权力清单制度的通知》（琼府办〔2015〕162号）、《三亚市人民政府办公室关于印发三亚市推行权力清单和责任清单制度实施方案的通知》（三府办〔2015〕357号）要求，我区组织开展了区政府各职能部门以及有关单位的行政权力清理工作。根据“行政权力进清单、法无授权不可为”的原则，经全面清理规范，编制了《三亚市天涯区2018年区级权力清单》并经区人民政府常务会第101次会议审议通过，现予以公布，接受社会监督。

区级权力清单具有刚性约束力，区级各部门必须严格执行，切实做到“清单之外无权力”。区级权力清单实行动态管理，根据法律、法规的颁布、修订、废止以及部门职能变化，及时调整完善。区级权力清单的调整，由权力行使单位提出，经区政务服务中心组织审核后报区政府审定。

附件：三亚市天涯区2018年区级权力清单
