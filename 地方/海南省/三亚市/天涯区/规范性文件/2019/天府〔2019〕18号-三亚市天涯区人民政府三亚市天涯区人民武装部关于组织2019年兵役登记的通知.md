# 三亚市天涯区人民政府三亚市天涯区人民武装部关于组织2019年兵役登记的通知

天府〔2019〕18号

三亚市天涯区人民政府

三亚市天涯区人民武装部

关于组织2019年兵役登记的通知

各居（村）委会：

根据国防部征兵办《关于做好2019年征兵准备工作的通知》和年度征兵工作安排，今年兵役登记工作于1月10日全面展开，为确保按时保质完成兵役登记任务，现将有关事项明确如下：

一、登记对象

辖区内截止2019年12月31日前满18周岁的男性适龄公民（含在本区范围内全日制普通高等学校就读的大学生）。2019年12月31日以前年满17周岁未满18周岁的男性高中（含中专、职高、技校）毕业生，本人自愿应征的，也可进行兵役登记。大学文化程度24周岁前，高中文化程度22周岁前，初中文化程度20周岁前的适龄男性公民未登记的要进行补登。

二、登记时间

2019年1月10日至6月30日

三、登记地点

各村（社区）便民服务站设置兵役登记站和登记负责人（由各民兵营长兼任），接收本辖区内所有适龄男性公民网上兵役登记表，并提供网上登记、报名和打印表格等服务。三亚航空旅游职业学院学生，由学院征兵工作站负责组织登记；普通高中、中等职业学校（中专、职高、技校）学生和其他社会青年，由常住户口地乡镇（街道）武装部会同所在学校、企业事业单位组织登记。

四、登记流程

（一）网上注册信息。登录“全国征兵网”，网址：https://

www.gfbzb.gov.cn,点击“兵役登记”选项，进行实名注册并真实、完整填写个人基本信息。

（二）打印表格。信息填写完整后，打印《男性公民兵役登记表》。

（三）现场确认。青年本人持打印的表格，携带身份证（户口簿）、毕业证（学历证明）、2张近期1寸免冠红底证件照到兵役登记站现场确认。

（四）初检初审得出结论。各村（社区）兵役登记站、高校征兵工作站对参加兵役登记的适龄男性公民进行初检初审，并依法作出应征、缓征、免征和不得征集的结论，填写《兵役登记证》，并报区武装部军事科审核。

（五）发放《兵役登记证》。各村（社区）兵役登记站、高校征兵工作站将区武装部审核盖章的《兵役登记表》发给登记青年。《兵役登记证》作为有关部门查验适龄男性公民履行兵役义务情况的依据。

五、法律责任

参加兵役登记是法律赋予每个适龄男性公民应尽的光荣义务和神圣责任，适龄青年应自觉按时进行兵役登记或查验。根据《中华人民共和国兵役法》《征兵工作条例》规定，男性适龄公民拒绝、逃避兵役登记的，机关、团体、企事业单位阻挠公民履行兵役登记或有妨碍兵役工作行为的，由当地人民政府征兵办公室按照有关条款予以处罚，构成犯罪的依法追究刑事责任。2016年5月30日，国务院出台的《关于建立完善守信联合激励和失信联合惩戒制度加快推进社会诚信建设的指导意见》明确规定“对拒不履行国防义务，拒绝、逃避兵役……”的，要进行联合惩戒。随着兵役法规制度和联合惩戒机制逐步完善，今后适龄男性公民不按要求参加兵役登记的，将面临以法律惩处：不能参加公务员、事业单位和国有（国有控股）企业等单位招聘，不能出国（境），不能办理高校入学、复学手续，不能办理银行贷款，不能乘坐飞机、高铁、入住星级以上宾馆等高消费行为，所在单位作为违法失信记录计入个人档案等。
