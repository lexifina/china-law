# 三亚市天涯区人民政府关于印发三亚市天涯区海坡村委会西瓜村、芒果村棚户区改造项目征收补偿安置补充方案的通知

天府〔2019〕231号

三亚市天涯区人民政府

关于印发三亚市天涯区海坡村委会

西瓜村、芒果村棚户区改造项目征收补偿安置补充方案的通知

区政府直属各单位，各居（村）委会，各有关单位：

《三亚市天涯区海坡村委会西瓜村、芒果村棚户区改造项目征收补偿安置补充方案（修订稿）》已经天涯区二届区委常委会第175次（扩大）会议、二届区政府第124次政府常务会议审议通过，并经市住建局备案登记，现印发给你们，请遵照执行。

三亚市天涯区人民政府

2019年11月1日

（此件主动公开）

三亚市天涯区海坡村委会西瓜村、芒果村

棚户区改造项目征收补偿安置补充方案

为做好天涯区海坡村委会西瓜村、芒果村棚户区改造项目征收补偿安置工作，确保海坡村委会西瓜村、芒果村棚户区改造项目顺利推进，根据《三亚市天涯区海坡村委会西瓜村、芒果村棚户区改造项目征收补偿安置方案》（天府〔2017〕254号）有关规定，结合海坡村委会西瓜村、芒果村、羊栏村委会、羊新社区居委会实际，为确保被征收人的合法权益，现修订项目征收补偿安置补充方案如下：

一、关于第（六）类安置对象的上门女婿和入嫁媳妇

在《三亚市天涯区海坡村委会西瓜村、芒果村棚户区改造项目征收补偿安置方案》（天府〔2017〕254号）发布之日前办理婚姻登记手续，且在本方案发布之日前1年内因夫妻投靠办理居住登记（暂住证），在方案发布后落户在海坡村委会西瓜村、芒果村，羊栏村委会、羊新社区居委会，并生活在海坡村委会西瓜村、芒果村，羊栏村委会、羊新社区居委会的人员，可认定为第（六）类安置对象。

二、关于未婚人员的分户原则

《三亚市天涯区海坡村委会西瓜村、芒果村棚户区改造项目征收补偿安置方案》（天府〔2017〕254号）发布之日止，达到法定结婚年龄的人员，可予分户。

三、关于安置对象的说明

对第（一）类、第（二）类、第（三）类、第（四）类、第（六）类安置对象，在《三亚市天涯区海坡村委会西瓜村、芒果村棚户区改造项目征收补偿安置方案》（天府〔2017〕254号）发布之日起10个月内出生的婴儿，经海坡村委会、羊栏村委会、羊新社区居委会核实后，即可按照其父母的类型及补偿标准进行补偿，不再以怀孕时间作为认定条件。

在《三亚市天涯区海坡村委会西瓜村、芒果村棚户区改造项目征收补偿安置方案》（天府〔2017〕254号）发布之日10个月后出生的婴儿，不认定为安置对象。

四、附则

（一）本补充方案自公布之日起实施。2018年1月5日公布的《三亚市天涯区人民政府关于印发三亚市天涯区海坡村委会西瓜村、芒果村棚户区改造项目征收补偿安置补充方案的通知》（天府〔2018〕6号）同时作废。

（二）本补充方案与《三亚市天涯区海坡村委会西瓜村、芒果村棚户区改造项目征收补偿安置方案》（天府〔2017〕254号）不一致的，以本补充方案为准。

三亚市天涯区人民政府办公室 2019年11月1日印发
