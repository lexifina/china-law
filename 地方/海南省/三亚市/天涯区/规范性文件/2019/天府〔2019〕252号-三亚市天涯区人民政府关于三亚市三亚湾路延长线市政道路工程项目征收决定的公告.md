# 三亚市天涯区人民政府关于三亚市三亚湾路延长线市政道路工程项目征收决定的公告

三亚市天涯区人民政府

关于三亚市三亚湾路延长线市政道路工程项目

征收决定的公告

天府〔2019〕252号

因实施三亚市三亚湾路延长线市政道路工程项目需要，依照《国有土地上房屋征收与补偿条例》（国务院第590号令）、《中华人民共和国土地管理法》的规定，决定征收三亚市三亚湾路延长线市政道路工程项目范围内合法的国有出让土地、房屋及其他建筑物、地上附着物。

一、征收项目名称

三亚市三亚湾路延长线市政道路工程项目

二、征收范围

三亚市天涯区三亚湾路延长线市政道路工程规划红线范围：西至滨海别墅中段，东至胜利路，北起光明街，南至建港路。规划红线宽20米～24米，全长约1.52公里，项目总占地面积约45亩，征收国有出让土地、房屋及建筑附属物总建筑面积约5.3万平方米，共约26户，涉及光明社区、和平社区、新建社区、榆港社区等4个社区居委会。上述房屋被依法征收的，国有土地使用权同时收回。具体征收范围以实际征收红线图为准（详见附件2）。

三、征收主体

三亚市天涯区人民政府

四、征收实施单位

三亚市天涯区项目推进服务中心

五、征收签约期限

自本决定发布之日起至2020年1月22日止

六、征收补偿方案：详见附件1

七、行政复议和行政诉讼权利

征收范围内的被征收人对本征收决定不服的，可以在征收决定书发布之日起60日内依法申请行政复议，也可以自征收决定发布之日起6个月内依法向人民法院提起行政诉讼。

八、其他事项

（一）征收实施期间，在征收范围内不得新建、扩建、改建房屋和改变房屋及土地用途的行为；违反规定实施的，不予补偿。

（二）征收部门与被征收人在征收补偿签约期限内达不成补偿协议或被征收国有出让土地、房屋及其他建筑物、地上附着物的合法产权人不明确的，由本府按照征收补偿方案和有关规定作出补偿决定。被征收人在法定期限内不申请行政复议或者不提起行政诉讼，在补偿决定规定的期限内又不搬迁的，本府将依法申请人民法院强制执行。

（三）任何组织和个人对本次征收和补偿工作中违反《国有土地上房屋征收与补偿条例》《中华人民共和国土地管理法》的行为，都有权向有关部门举报。
