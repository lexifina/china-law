# 三亚市天涯区人民政府关于转发2019年海南省语言文字工作要点的通知

天府〔2019〕50号

三亚市天涯区人民政府

关于转发2019年海南省语言文字工作要点的通 知

区各党政机关、事业单位、村（居）委会、中小学校（幼儿园）：
