# 三亚市天涯区人民政府关于公布三亚市天涯区“马上办、网上办、就近办、一次办”事项清单的通知

天府〔2019〕55号

三亚市天涯区人民政府

关于公布三亚市天涯区“马上办、网上办、就近办、一次办”事项清单的通知

区政府直属各单位：

根据《三亚市行政审批制度改革工作领导小组办公室关于全面梳理“马上办、网上办、就近办、一次办、集中办”事项清单的通知》（三审改办函〔2018〕59号）要求，我区将面向企业和群众的审批服务事项进行了梳理。根据“便民、高效、廉洁、规范”的原则编制出《三亚市天涯区“马上办、网上办、就近办、一次办”事项清单》（以下简称“四办”事项清单），并经区人民政府常务会审议通过，现予以公布。

区级“四办”事项清单公布后，区级各相关部门要随着权责清单的调整对“四办”事项清单实行动态化调整，按照“成熟一批、公布一批”的原则定期进行更新完善，进一步促进审批服务流程的优化再造，畅通办事渠道，切实增强政府公信力和执行力，促进服务型政府建设。
