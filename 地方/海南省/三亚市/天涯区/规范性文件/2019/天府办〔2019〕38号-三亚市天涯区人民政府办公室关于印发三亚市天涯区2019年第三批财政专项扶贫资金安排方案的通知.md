# 三亚市天涯区人民政府办公室关于印发三亚市天涯区2019年第三批财政专项扶贫资金安排方案的通知

天府办〔2019〕38号

三亚市天涯区人民政府办公室

关于印发三亚市天涯区2019年第三批财政

专项扶贫资金安排方案的通知

区各相关单位：

《三亚市天涯区2019年第三批财政专项扶贫资金安排方案》已经区政府常务会议第2届121期审议通过，现印发给你们，请认真组织实施。

三亚市天涯区人民政府办公室

2019年7月29日

（此件主动公开）

三亚市天涯区2019年第三批财政专项扶贫

资金安排方案

根据省级脱贫攻坚专项扶贫资金的使用要求，为了用活、用好、用足上级财政扶贫专项资金，结合我区建档立卡贫困户实际情况，现就上级下达我区财政专项扶贫资金使用进行安排，制定本方案。

一、安排的资金来源

根据三亚市财政局《关于下达2019年中央及省级财政专项扶贫资金（第二批）的通知》（三财农〔2019〕75号）文件，下达我区2019年第三批财政专项扶贫资金（发展资金）310万元。

二、资金使用方向和原则

依据“精准扶贫、效益优先、程序规范、资金安全”的使用原则，坚持投向准确、重点突出，充分发挥龙头企业的带头作用，突出产业扶贫功效。确保资金使用与建档立卡结果相衔接，发展资金主要用于产业项目、公共服务设施等项目。确保专款专用，不得用于与脱贫攻坚无关的支出。

三、资金安排及使用内容

（一）天涯区黑土村哈密瓜种植产业扶贫项目（二期）。计划安排中央财政专项扶贫资金165万元，用于天涯区黑土村哈密瓜种植产业扶贫项目（二期），具体由区农业农村局和区城投公司负责落实，不足部分可由区财政安排。

（二）三亚市天涯区扎南幼儿园建设工程项目。计划安排中央财政专项扶贫资金95万元，用于三亚市天涯区扎南幼儿园建设工程项目，具体由区教育局和区城投公司负责落实。不足部分可由区财政安排。

（三）天涯区抱龙村卫生室标准化建设项目。计划安排中央财政专项扶贫资金50万元，用于天涯区抱龙村卫生室标准化建设项目，具体由区卫健委负责落实，不足部分可由区财政安排。

四、加强管理和档案建设

各职能单位要认真履行职责，按照中央及省市的财政专项扶贫资金管理办法有关规定，加强资金项目的管理和监督，做好资金使用和项目实施的监督检查工作，确保年度项目按时按质按量完成。同时，要对项目实施的各个环节资料要及时收集，确保项目归档资料能准确地反映项目建设的全过程。

五、相关要求

（一）资金的管理使用要严格按照国家、省、市出台的扶贫资金管理办法等有关规定执行。

（二）由牵头单位组织相关部门对项目验收（产业奖励扶持项目除外），区财政、发改、审计等职能部门负责对资金使用监督、审计、效益评估等相关工作。

（三）项目进度和资金支出情况，项目业主单位要安排专人负责，每周五上午12点前报区扶贫工作办公室（联系人：蒲志伊，电话:88913235），便于掌握项目建设情况。

三亚市天涯区人民政府办公室 2019年7月29日印发
