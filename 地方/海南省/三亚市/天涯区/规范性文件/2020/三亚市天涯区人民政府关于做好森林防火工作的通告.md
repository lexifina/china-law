# 三亚市天涯区人民政府关于做好森林防火工作的通告

三亚市天涯区人民政府

关于做好森林防火工作的通告

为有效预防和遏制森林火灾发生，确保天涯区森林资源和人民群众生命财产安全，根据《中华人民共和国森林法》《森林防火条例》《海南省森林防火条例》等法律法规，结合我区实际情况，现就森林防火有关事宜通告如下：

一、每年的3月1日至5月31日为森林防火高火险期。

二、生态公益林区、风景旅游区、海防林区、重点封山育林区、水库周围以及村级以上公路周围100米内为我区森林防火重点区域，全年禁止一切野外用火。对未经批准擅自在规定范围内野外用火的行为，由公安机关依照《中华人民共和国治安管理处罚法》的规定给予行政处罚。情节和危害后果严重，按《海南省森林防火条例》有关规定严肃查处；构成犯罪的，由司法机关依法追究刑事责任。

三、任何单位和个人不得携带火源火种、易燃易爆物品及其他易引起森林火灾的物品进入林区；森林防火重点区域禁止吸烟、野炊、烧荒等，严禁毁林烧荒、砍山烧山、烧山驱兽、乱烧垃圾及其他生产性用火，违者按《海南省森林防火条例》有关规定严肃查处。

四、森林火灾扑救应当以专业扑火队伍和半专业扑火队伍为主，严禁无实战经验的干部担任火场指挥，不得动员未经训练的人员、老弱病残人员、中小学生、妇女进入火场参加扑打明火，坚决杜绝人员伤亡事故发生。

五、凡本区人员以及进入本行政区域的人员，必须自觉执行防火规定。对违反以上规定的单位和个人，根据《森林防火条例》和《海南省森林防火条例》的有关规定，进行严肃处理；造成火情火险的依法从严处置，涉嫌犯罪的移交司法机关依法追究刑事责任。

六、任何单位和个人发现违规用火行为和森林火灾应立即报告，森林火情报警电话：119；三亚市森林防火指挥部值班电话：88689110；天涯区应急联动指挥中心值班电话：88880110。

七、本通告自发布之日起实施。

三亚市天涯区人民政府
