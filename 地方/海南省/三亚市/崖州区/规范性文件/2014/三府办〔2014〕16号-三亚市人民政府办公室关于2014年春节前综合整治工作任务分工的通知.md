# 三亚市人民政府办公室关于2014年春节前综合整治工作任务分工的通知

三亚市人民政府办公室

关于2014年春节前综合整治工作任务分工的通知

各区管委会，各镇人民政府，市政府直属各单位：

为规范我市旅游市场秩序，改善市容市貌，提升城市管理水平，市政府决定成立河东区、河西区、吉阳镇、凤凰镇、天涯镇、崖城镇六个综合整治工作组和水果店（摊）、三亚湾、非法潜水三个专项整治工作组，从2014年1月16日开始，利用10天时间对我市旅游服务、道路交通、市容市貌等方面存在的问题进行集中整治，并作为春节应急组，及时处理2014年春节期间城市管理和旅游服务方面出现的投诉及问题。各综合整治工作组、专项整治工作组任务分工和人员构成如下：

一、综合整治工作组

由相关区管委会（镇政府）牵头，市公安局、市综合行政执法局、市工商行政管理局、市物价局、三亚质量技术监督局、市住房城乡建设局、市交通运输局、市海洋与渔业局、市园林环卫局等单位积极配合。

（一）主要任务

一是要加强旅游市场秩序整治，对辖区内的海鲜排挡、珠宝购物点等旅游服务场所进行排查，发现问题及时整改。二是要加强道路交通整治，坚决查处车辆乱停乱放、农用车及拖拉机进入城区行驶、电动车不走非机动车道等交通违法行为，及时查扣违法车辆。河东区、河西区管委会按照市政府通告要求尽快启动临时占道停车收费工作，对不在规定区域内停车或不配合停车收费工作的车辆和驾驶员由市公安局交警支队依法查处。三是要加强市容市貌整治，坚决拆除违规广告牌、商业道旗广告，加快施工遮挡围墙整治和美化，对道路两侧绿化树木进行补植、养护。四是要加强南山、天涯海角、亚龙湾等重点旅游区域整治，查处非法广告牌匾、沿途卖香、海上游天涯、沙滩乱搭乱建、非法潜水等违法行为。

二、专项整治工作组

（一）水果店（摊）专项整治工作组

由市工商行政管理局牵头，市公安局、市综合执法局、市物价局、三亚质量技术监督局、属地区管委会（镇政府）等单位积极配合。

1.主要任务

对全市范围内的水果店（摊）进行地毯式排查，坚决取缔无照经营，存在问题的要限时整改，整改不到位的禁止营业。严格落实明码标价，规范标价管理，涉嫌价格欺诈的依法严厉打击。加强计量检查，排查各水果店使用的电子称，严防缺斤少两，维护消费者合法权益。

（二）三亚湾沙滩专项整治工作组

市综合执法局牵头，市公安局、市海洋与渔业局、市园林环卫局、市工商行政管理局、市食品药品监督管理局属地区管委会（镇政府）等单位积极配合。

（三）非法潜水专项整治工作组

由市海洋渔业局牵头，市交通运输局、三亚海事局、市工商行政管理局、市文化广电出版体育局、市旅游委、市公安局、三亚公安边防支队、武警海警二支队等单位积极配合。

1.主要任务

加大海上巡查、执法力度，依法查处非法潜水组织人员，查扣非法潜水器材并及时组织公开销毁，严厉打击暴力抗法行为，切实改善我市海上旅游环境。完善执法处罚机制，形成全市处罚非法潜水行为的规范管理机制。
