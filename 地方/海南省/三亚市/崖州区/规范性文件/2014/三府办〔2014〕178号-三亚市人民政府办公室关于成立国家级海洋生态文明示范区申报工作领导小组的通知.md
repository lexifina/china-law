# 三亚市人民政府办公室关于成立国家级海洋生态文明示范区申报工作领导小组的通知

三亚市人民政府办公室

关于成立国家级海洋生态文明示范区申报工作领导小组的通知

各镇人民政府，各区管委会，市政府直属各单位:

为提升我市海洋生态文明建设水平，实现我市提出的“海洋强市”建设战略，落实2014年我市确定的创建国家级海洋生态文明示范区申报工作，市政府批准成立国家级海洋生态文明示范区申报工作领导小组，现将领导小组名单通知如下：

组 长：王 勇（市政府市长）

常务副组长：周高明（市政府副市长）

副 组 长：文中童（市政府副秘书长）

张 利（市发展改革委主任）

章华忠（市海洋渔业局局长）

成 员：陈海兴（市财政局副局长）

李建军（市国土环境资源局调研员）

冯祝昌（市旅游委副调研员）

陈光发（市文化广电出版体育局副局长）

陈 斌（市统计局副调研员）

钟 声（市科技工业信息化局副局长）

段德玉（市海洋渔业局副局长）

领导小组负责组织、协调、实施国家级海洋生态文明示范区申报与建设等工作；负责经费保障、方案审定和申报工作。领导小组下设办公室，办公室设在市海洋渔业局，由章华忠兼任办公室主任，段德玉任副主任，办公室成员由市发展改革委、市财政局、市国土环境资源局、市旅游委、市统计局、市科技工业信息化局、市文化广电出版体育局、市海洋渔业局各安排一名工作人员组成。

三亚市人民政府办公室

2014年7月2日
