# 三亚市人民政府办公室关于三亚市大隆灌区西干渠与支渠连接段工程项目用地土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市大隆灌区西干渠与支渠连接段工程

项目用地土地调查有关事项的通知

崖城镇人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，拟征收崖城镇三公里村委会、港门村委会、北岭村委会、城西村委会、保平村委会、盐灶村委会、海棠村委会、崖城村委会、乾隆村委会、临高村委会、凤岭村委会部分集体土地及收回崖城镇辖区内部分国有土地作为大隆灌区西干渠与支渠连接段工程项目用地。为做好该项土地调查工作，现就有关事项通知如下：

一、该宗项目用位于崖城镇辖区内，用地面积约23706平方米，其中永久用地面积约11380平方米、临时用地面积约12326平方米。该宗土地为农田灌溉设施农地，土地利用总体规划中均为非建设用地；土地所有权属情况：崖城镇三公里村委会集体土地约1204平方米、港门村委会集体土地约611平方米、北岭村委会集体土地约563平方米、城西村委会集体土地约7235平方米、保平村委会集体土地约2448平方米、盐灶村委会集体土地约2583平方米、海棠村委会集体土地约1882平方米、崖城村委会集体土地约125平方米、乾隆村委会集体土地约695平方米、临高村委会集体土地约57平方米、凤岭村委会集体土地约4776平方米、崖城中学国有土地约965平方米、崖城镇沟渠用地（未发证）约183平方米。具体征地拆迁范围四至及坐标详见用地勘测定界图。

二、根据《中华人民共和国土地管理法》第二条第四款“国家为公共利益的需要可以依法对土地实行征收或征用并给予补偿”和第五十八条第一款“国家为公共利益的需要使用土地的可依法收回国有土地使用权，并给土地使用权人适当补偿”的规定。为做好该宗用地拟征收土地的调查工作，由崖城镇负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土环境资源局负责对拟征收土地范围进行土地权属确认及业务指导工作。在调查工作中，拟征收土地范围内的单位或个人，不得以任何理由进行阻挠。

三、拟调查征收土地补偿标准按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行；拟收回土地补偿标准按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行；临时用地补偿标准建议参照新建海南西环铁路二期征地临时用地补偿标准执行。

四、根据国土资源部于2010年6月26日下发的《关于进一步做好征地管理工作的通知》第四条规定，崖城镇应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认，向市国土环境资源局出具履行征地前告知等程序的证明及土地权属确认意见。待有权限的人民政府批准征地后，征收土地公告和征地补偿安置方案公告可同步进行。

五、为了进一步做好被征地农民养老保险工作，根据省人力资源与社会保障厅、省财政厅和省国土环境资源厅《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号），崖城镇人民政府应在本通知下发后10个工作日内对项目拟征收农用地和享受缴费补贴人数等情况进行调查，组织村（居）小组填写《征地项目被征地农民基本情况调查表》，经村（居）委会、崖城镇人民政府逐级审核后，由崖城镇人民政府汇总填写《征地项目被征地农民基本情况乡镇调查汇总表》，并将上述两种表格报送市国土环境资源局。

六、自本通知下达之日起，在拟调查范围内的土地一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
