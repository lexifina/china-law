# 三亚市人民政府办公室关于加强我市秋冬季大气污染防治工作的通知

三亚市人民政府办公室

关于加强我市秋冬季大气污染防治工作的通知

各区筹备组，各管委会，市政府有关单位:

随着秋冬季的到来，在下沉干冷空气作用下，气象条件不利于空气污染物稀释、扩散和清除。同时，秋冬季又是我市旅游度假旺季，旅游度假人口和活动、机动车流量等大量增加，加大了我市大气污染物的排放。为强化秋冬季我市大气污染防治工作，有效控制大气污染物的排放，保障人民群众的身体健康，保持环境空气质量优良，现就有关要求通知如下：

一、高度重视大气污染防治工作。良好的空气质量是三亚发展的生命线，也是三亚创建一流国际旅游度假城市的重要条件。秋冬季是我市旅游度假的黄金期，同时受气象条件的影响也是环境空气质量承受压力最大的季节。全市各单位要高度重视秋冬季大气污染防治工作，认真按照《三亚市2014年大气污染防治实施计划》（三府办〔2014〕145号）、《三亚市大气重污染应急预案》（三府办〔2014〕152号）等文件要求，加强组织领导，采取有力措施，加强协同合作，落实工作责任，积极做好大气污染防治工作。

二、严格控制建筑施工和道路扬尘污染。市住房城乡建设局牵头，按照《三亚市人民政府办公室关于做好建筑工地扬尘污染整治工作的通知》（三府办〔2014〕36号）要求，强化房屋建筑和市政工程施工扬尘污染防治工作，督促各工地落实全封闭围挡、堆土覆盖、洒水压尘、使用高效洗轮机和防尘墩、料堆密闭、道路裸地硬化等扬尘控制措施。市园林环卫局要推行道路机械化清扫等低尘作业方式，强化道路洒水降尘措施，增加市区主干道的保洁及洒水频次，加强管理，减少道路扬尘污染。

三、加强机动车污染防治工作。市国土环境资源局继续做好机动车环保标志核发工作，加强在用机动车尾气检测机构的监督检查，开展机动车道路检测工作。市公安局要落实“黄标车”、无标车限行制度，查处“黄标车”、无标车在限行区域上路行驶的行为，严查行驶中冒黑（浓）烟的车辆；加强市区内各主要道路交通繁忙路段的交通疏导工作，保障交通畅通。

四、加强油烟、烟尘等污染物无组织排放的监督管理。市综合行政执法局牵头，加强对露天烧烤、露天焚烧垃圾杂物等产生大量油烟、烟尘排放行为的监督管理，严格查处餐饮服务业违法排放油烟污染环境行为。各区筹备组、育才生态保护区管委会以及各国营农场要严格要求，禁止焚烧秸秆行为发生，切实防止大气面源污染。市国土环境资源局要加快推进加油站、油罐车、储油库油气回收治理工作，确保2014年底前完成油气回收治理。

五、加强环境空气质量监测和分析工作。市国土环境资源局、市气象局要加强环境空气质量监测和大气气象监测，建立完善的会商机制，做好环境空气质量趋势分析和研判工作，按规定做好环境空气质量监测信息发布工作。

六、强化责任落实。各牵头单位要严格按照要求制定工作方案，明确具体措施，把责任落到实处，认真做好大气污染防治工作。请各责任单位于10月20日前将秋冬季大气污染防治工作实施方案送市国土环境资源局（联系电话：污染防治科 88250386）。

市国土环境资源局要加强对大气污染防治工作的统一监督，对各责任单位落实大气污染防治工作情况进行核查，于2015年3月将秋冬季大气污染防治工作落实情况报告市政府。

三亚市人民政府办公室
