# 三亚市人民政府办公室关于启用吉阳区人民政府等印章的通知

三亚市人民政府办公室

关于启用吉阳区人民政府等印章的通知

各区筹备组，各管委会，市政府直属各单位：

国务院《关于同意海南省调整三亚市部分行政区划的批复》（国函〔2014〕14号）批复同意调整三亚市部分行政区划，设立“三亚市海棠区、三亚市吉阳区、三亚市天涯区、三亚市崖州区”四个区。经市政府批准，从2015年1月1日起，各区启用“三亚市海棠区人民政府”、“三亚市吉阳区人民政府”、“三亚市天涯区人民政府”、“三亚市崖州区人民政府”印章，同时废止“三亚市河东区管理委员会”、“三亚市河西区管理委员会”、“三亚市吉阳镇人民政府”、“三亚市凤凰镇人民政府”、“三亚市天涯镇人民政府”、“三亚市海棠湾镇人民政府”、“三亚市崖城镇人民政府”、“三亚市育才镇人民政府”和“三亚市海棠区筹备组”、“三亚市吉阳区筹备组”、“三亚市天涯区筹备组”、“三亚市崖州区筹备组”印章，交市政府保密室封存。
