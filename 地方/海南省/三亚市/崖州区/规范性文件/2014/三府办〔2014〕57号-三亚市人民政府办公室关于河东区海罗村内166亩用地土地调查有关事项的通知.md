# 三亚市人民政府办公室关于河东区海罗村内166亩用地土地调查有关事项的通知

三亚市人民政府办公室

关于河东区海罗村内166亩用地

土地调查有关事项的通知

河东区管委会，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，拟征收河东区海罗村部分集体土地和收回河东区辖区内部分国有土地作为储备用地。现就有关事项通知如下：

一、该宗用地位于河东区海罗村辖区内，用地面积约110766.21平方米（合约166亩）。其四至范围为：东至海罗村内规划路，南至海罗村内规划路，西至原80号储备用地，北至规划河道。土地权属为河东区海罗村110147平方米、榆亚盐场619平方米（海南平面坐标系），土地利用总体规划为建设用地58080平方米、有条件建设区52752平方米（西安80坐标系）。具体调查范围四至及坐标详见海螺166亩备用地储备图。

二、为做好该宗用地拟征收及收回土地的调查工作，由河东区负责组织实施该项目用地上的青苗清点、地上附着物和土地面积丈量等土地补偿审核及土地补偿工作；市国土环境资源局负责对该宗用地范围内的土地权属确认及业务指导工作。在调查工作中，拟征收及收回土地范围内的单位或个人，不得以任何理由进行阻挠。

三、该宗用地补偿标准按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定（2013年修订）的通知》（三府〔2013〕43号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、根据《国土资源部关于进一步做好征地管理工作的通知》（国土资发〔2010〕96号）第四条规定，河东区应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认，向市国土环境资源局出具履行征地前告知等程序的证明及土地权属确认意见。待有权限的人民政府批准征地后，征收土地公告和征地补偿安置方案公告可同步进行。

五、自本通知下达之日起，在拟征收及收回范围内的土地禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
