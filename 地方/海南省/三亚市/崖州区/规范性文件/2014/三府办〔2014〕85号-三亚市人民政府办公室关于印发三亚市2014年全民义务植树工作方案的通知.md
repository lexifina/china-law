# 三亚市人民政府办公室关于印发三亚市2014年全民义务植树工作方案的通知

三亚市人民政府办公室

关于印发三亚市2014年全民义务植树

工作方案的通知

各镇人民政府，各区管委会，市各有关单位：

《三亚市2014年全民义务植树工作方案》已经市政府同意，现印发给你们，请各相关单位严格执行，落实责任。

三亚市人民政府办公室

2014年3月31日

（此件主动公开）

三亚市2014年全民义务植树工作方案

根据省林业厅“大力植树造林，建设绿色宝岛”义务植树活动的安排，结合我市造林实际情况，制定本市2014年全民义务植树工作方案。

一、2014年全民义务植树活动的主题：拥抱春天，播种绿色。

二、时间安排：活动分三个阶段，第一阶段3-4月份，为宣传发动阶段；第二阶段7-8月份，为植树造林阶段；第三阶段10月份，为检查验收阶段。

三、工作目标：

（一）第一阶段完成目标：3-4月份为宣传发动和造林准备阶段。组织市政府各机关、各民主团体、企事业单位、学校、部队等单位，开展多种形式的义务植树宣传教育活动，大力弘扬爱绿、护绿、植绿、兴绿的良好风尚，激发广大群众建设绿色宝岛的积极性和主动性，持续掀起义务植树、共建宝岛秀美山川热潮，推动我省国际旅游岛建设。

（二）第二阶段完成目标：7-8月份是我市雨水较多的时期，各单位要抓住这一植树有利时机，组织本区域内全体适龄公民掀起义务植树高潮。

全市义务植树活动计划植树520000株，其中市各单位植树2500株，各区镇、宾馆、酒店和企事业单位植树517500株。各系统植树任务安排如下：

1.市各单位绿化任务

市各单位种植树种以景观林为主，任务是2500株，树种主要有小叶榄仁、重阳木、椰子等本地乡土树种，种植苗木由市林业局负责。参加人员为市四套班子领导和驻三亚部队、市直机关干部和职工等。

2.各区镇、企事业单位、宾馆、酒店绿化任务

各区镇、企事业单位、宾馆、酒店绿化任务是517500株，地点自定，种植树种为小叶榄仁、长叶马府油、雨树、孔雀豆、盆架子、琼崖海棠、大叶相思、木麻黄、果树、吊瓜木和椰子等，种植苗木由各单位负责。区镇单位要结合造林和社会主义新农村建设，充分发挥农村土地资源丰富的特点，组织群众在水边、村边、路边绿化植树，美化绿化我市的新农村。三亚企事业单位、宾馆、酒店等绿化方式采取庭院绿化为主，在本区域范围内，充分利用现有空间，采取乔、灌、草相结合的方式，进行立体式绿化，努力创建“花园式单位”和“庭院绿化达标单位”。

（三）第三阶段完成目标：10月份结合我市全年造林验收工作，对全市义务植树成果进行验收，检查评比，表彰先进，对未完成任务的单位进行通报批评。

四、植树地点

1.市直机关植树地点待定。

2.企事业单位、宾馆、酒店绿化地点在各自单位内自行安排。

3.各区镇植树地点在各区镇道路、水边及新农村建设点。

五、具体要求

树穴规格为：(1)大树规格70厘米(边宽)×70厘米(深)×60厘米(底宽)，株行距5×6(米)；(2)小树规格40厘米(边宽)×40厘米(深)×30厘米(底宽)，株行距均为2×2(米)。

大树胸径为6—10厘米，袋装良种壮苗，要求土球完整。种植设计为大树每亩20—30株，小树每亩167株-222株，混交组团种植。

下苗前要先回填表土15厘米；下苗时，要剥掉营养袋、扶正、回填表土分层压实、做好积水窝、浇足定根水。种植前尽量避免树苗土球散破，提高树苗的成活率。

各单位应认真按造林技术要求种植。

六、保障措施

（一）成立领导机构，加强组织领导

义务植树是国际旅游岛建设的一项重要措施，各单位、各部门主要领导要亲自挂帅抓落实，要把义务植树作为一项重要工作来抓，做到有计划、有部署、有措施、有行动，切实抓出实效。市政府成立工作总指挥部，总指挥由市政府副市长周高明担任，副总指挥由市政府副秘书长文中童、市林业局局长孙宁和市园林环卫管理局局长蓝文全担任，市绿委办负责协调和组织工作。各区镇要成立相应的领导机构，加强领导，精心组织，统一部署开展行动。

各单位在义务植树行动结束后，及时将相关材料报市绿化委员会办公室（传真：88689002），市绿委办将组织检查组对各责任单位进行检查验收，并把检查情况报市政府。

（二）拓宽渠道，制定行动方案，开展形式多样的全民义务植树活动

今年是我国开展全民义务植树运动33周年，各单位要结合我市实际，以建设绿化生态城市、美化新农村为重点，拓宽渠道，制定绿化行动方案，开展形式多样的全民义务植树活动。要按照海南国际旅游岛建设的要求，创造性地推进全民义务植树运动的深入开展：一是大力推进生态屏障建设；二是大力推进“身边增绿”；三是大力加强中幼林抚育；四是大力推进古树名木保护管理；五是大力推进“纪念林”建设。

各单位在全民义务植树过程中，要创新工作机制，拓展全民义务植树方式方法，使全民义务植树形成多主体、多层次，多形式的格局。要广泛地在校园、军营、医院、旅游区等地点开展绿化建设，营造“党员林”、“青年林”、“三八林”、“八一林”、“入学林”、“毕业林”等纪念林，开展形式多样的“弘扬生态文明、共建绿色家园”活动，促进人与自然和谐发展。市教育局要组织学校，积极开展绿化校园活动，检查评比出市级“绿色生态校园”学校和申报省级“绿色生态校园”学校。

市绿委办要组织力量对各单位开展义务植树活动及时进行指导，加强督促检查，并做好协调保障工作。

（三）广泛宣传发动，城乡联动掀高潮

1.各区镇、各新闻媒体要充分利用广播、电视、报纸、横幅、标语、宣传车等多种形式，开展丰富多彩的绿化宣传活动，广泛宣传《中共中央、国务院关于加快林业发展的决定》；宣传全国人大《关于开展全民义务植树运动的决议》；宣传义务植树的法定性、全民性、义务性和公益性意义，为义务植树行动营造良好的舆论氛围。

2.要充分利用世界湿地日、森林日、环境日和“国际森林年”等纪念日，开展有特色的专题宣传教育，不断增强广大市民，特别是党员、团员、军人、学生、妇女等爱绿、护绿、植绿、兴绿的自觉性，形成我为宝岛添新绿的良好社会风尚。

（四）措施到位，确保全民义务植树活动取得成效

各单位要早部署、早准备、早抓落实。一是制定活动方案，明确工作目标，并建立奖惩制度，实行责任制管理；二是落实专项经费，广辟资金渠道，实行政府投资与全社会共同参与的方式造林；三是搞好苗圃建设，备足苗、备好苗，为义务植树活动提供种苗支持；四是开展技术指导，为义务植树提供技术保障；五是做好统计和建档，准确掌握义务植树的状况与成效；六是加强督促检查指导，建立检查验收制度，切实落实造林后的管护，保证义务植树真正取得成效。

为此，市林业局在制定全民义务植树方案之后，同时在《三亚日报》、《人民网》、《三亚门户网》等多家媒体发布消息：在今年3-8月份雨水充沛季节，市林业局免费提供树苗给市民在自家庭院栽种。目前，树苗的品种主要有花梨、沉香、檀香三种，市民如有需求，可凭本人身份证到市林业科学研究院领取3-5株树苗。联系人：蔡主任，联系电话：18608923300。

各单位在种植时要严把质量关，保证种植成活率达90％以上，未成活的要及时补苗。未按规定完成分配植树任务的单位，将按《国务院关于全民义务植树实施办法》追究责任。全部植树任务务必于10月底前完成，届时由市绿委办组织验收。
