# 三亚市人民政府办公室关于印发第八届泛珠三角区域合作与发展论坛暨经贸洽谈会三亚市综合招商推介活动方案的通知

三亚市人民政府办公室关于印发

第八届泛珠三角区域合作与发展论坛暨经贸洽谈会

三亚市综合招商推介活动方案的通知

各镇人民政府，各区管委会，市各有关单位：

《第八届泛珠三角区域合作与发展论坛暨经贸洽谈会三亚市综合招商推介活动方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2012年7月12日

（此件主动公开）

第八届泛珠三角区域合作与发展论坛暨经贸洽谈会

三亚市综合招商推介活动方案

第八届泛珠三角区域合作与发展论坛暨经贸洽谈会（简称“泛珠大会”定于2012年10月底在我省举办。根据省政府《第八届泛珠三角区域合作与发展论坛暨经贸洽谈会筹委会办公室关于印发<第八届泛珠三角区域合作与发展论坛暨经贸洽谈会我省招商引资工作方案>的通知》（泛珠筹委办〔2012〕1号）精神，特制定本活动方案。

一、活动宗旨

充分利用我省承办第八届“泛珠大会”的平台，围绕我市国际旅游岛建设及“十二五”国民经济和社会发展规划要求，宣传三亚、推介三亚，开展招商引资推介活动，力争促成重点项目签约，推动我市经济社会又好又快发展。

二、活动名称

第八届泛珠三角区域合作与发展论坛暨经贸洽谈会三亚市综合招商推介会。
