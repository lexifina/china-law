# 三亚市人民政府办公室关于社会信用体系建设督查的通知

三亚市人民政府办公室

关于社会信用体系建设督查的通知

市各有关单位：

为全面贯彻落实国务院《社会信用体系建设规划纲要（2014－2020）》、《海南省社会信用体系建设“十三五”规划》及市政府相关文件精神，进一步加快我市社会信用体系建设工作，争创国家信用建设示范城市，创建全国文明城市，全面掌握我市社会信用体系建设工作进展情况，根据市信用体系建设联席会议工作要求，市信用办建立定期督查通报机制。市信用办将每月定期收集各单位工作开展情况并汇总上报，以督查通报形式进行通报，对社会信用体系建设工作落实不力、进展缓慢的单位进行通报批评和约谈提供依据。现市信用办调整了《三亚市社会信用体系建设工作进展表》格式和内容，请你单位从5月开始按下表要求填写工作进展，于每月底前报市信用办。

联系人：符元瀚，电话：88756452

电子邮箱：xinyongsanya@163.com

备注

一、信用信息共享平台建设情况

1、市信用办填报全市统一的公共信用信息平台建设进展情况。2、具有区域、行业（领域）信息平台的单位填报信息平台整合信用信息的情况、整合范围、数量

提供网址和信用信息公开情况

二、信用制度建设情况

各单位填报，列出已印发文件标题、文号，说明根据文件开展的工作情况，后附文件内容全文

第一次填报可填报近年来已出台的相关制度文件，总体工作情况，以后每月不重复填报，只填报当月工作进展（下同）

三、四大领域诚信建设（政务诚信、商务诚信、社会诚信、司法公信等四大领域诚信建设）进展情况

各单位填报，列出在政务诚信、商务诚信、社会诚信、司法公信建设方面印发的文件、文号，说明根据文件开展的工作情况，后附文件内容全文

四、建立完善守信联合激励和失信联合惩戒机制进展情况

各单位填报，列出守信联合激励、失信联合惩戒具体机制、合作备忘录、与相关部门工作协同等情况，列出联合惩戒的具体事件、数量。后附相关文件内容全文

五、部际联合奖惩合作备忘录落实情况

已印发的部际联合奖惩合作备忘录牵头部门（发起部门）填报，其他部门填报响应、配合情况

市政府已印发20个部际联合奖惩备忘录

六、“红黑名单”制度制定及实施情况

各单位填报，提供“红黑名单”制度内容，公布的诚信“红名单”和失信“黑名单”具体名单和公布出处

七、信用服务市场发展进展情况

市信用办填报引进信用服务机构情况，各单位填报在行政管理、行政服务中使用信用记录、信用报告情况

八、诚信宣传教育进展情况

各单位填报，报送开展的具体活动，提供活动方案、宣传内容、宣传图片等宣传资料

九、完善工作推进机制情况

各单位填报

第一次填报工作推进机制情况，以后每月填报调整情况

十、统一社会信用代码工作进展情况

由市工商局、市编办、市民政局填报工作进度，完成百分比

十一、“双公示”进展情况

由市政务中心、具有行政许可、行政处罚的单位填报

第一次填报“双公示”工作开展以来总体情况，以后每月只填报当月公示情况及公示数量

十二、报送典型案例

各单位填报，每个单位每月至少报一个诚信典型案例、一个失信典型案例，全年诚信、失信典型案例各不少于12个

十三、创建国家信用建设示范城市进展情况

由市信用办填报
