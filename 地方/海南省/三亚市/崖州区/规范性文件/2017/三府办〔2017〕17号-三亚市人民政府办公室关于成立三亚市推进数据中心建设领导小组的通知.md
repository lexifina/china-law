# 三亚市人民政府办公室关于成立三亚市推进数据中心建设领导小组的通知

三亚市人民政府办公室

关于成立三亚市推进数据中心建设领导小组的通知

各区人民政府，各管委会，市政府直属各单位：

为推进我市数据中心建设，降低我市信息化建设投资成本，提高信息化项目建设效益，促进政府信息资源整合、共享和交换，利用集约化、虚拟化和云计算等技术，助力智慧三亚建设，市政府决定成立三亚市推进数据中心建设领导小组。现将有关事项通知如下：

领导小组下设办公室，办公室设在市科技工业信息化局，由周俊兼任办公室主任,办公室成员由市科技工业信息化局副局长张腾、蔡海宝，市科技工业信息化局副调研员胡静，市科技工业信息化局信息化科科长冯学江、市党政综合网络信息中心负责人吴开唐组成。

二、领导小组及办公室职责

（一）领导小组主要职责：研究全市大数据产业发展重大战略、重大项目和重大政策措施，研究全市有关大数据产业发展全局性、方向性的重大事项和重大问题，全面统筹、指导和推进数据中心建设工作，听取大数据产业发展及云数据中心建设工作汇报，研究阶段性工作计划、工作措施。

（二）领导小组办公室主要职责：负责领导小组日常工作，统筹推进全市大数据产业发展、数据中心建设及管理工作，制定数据中心建设、服务及购买云服务标准，贯彻落实领导小组会议议定事项，组织实施大数据产业及云计算发展战略、项目、政策措施及《三亚市推进智慧城市建设十三五行动计划》等相关规划；统筹协调政务信息资源共享、开放开发；管理三亚大数据资源及应用开发，组织开展大数据及云计算培训、交流、研讨等活动，完成领导小组交办的其他任务。

领导小组各成员单位主要职责：按照领导小组统一安排部署，牵头抓好本系统、本领域大数据发展及系统迁移、接口对接等工作，并承担以下工作职责：

市监察局主要负责监督数据中心项目建设过程中招投标、合同履行、工程变更、资金使用、财务管理及决算审计等重要环节的廉政情况；

市发展改革委主要负责宏观经济数据库建设，为其他政务应用系统提供基础数据服务；

市财政局主要负责落实数据中心建设及大数据产业发展等信息化发展专项资金预算；

市审计局主要负责数据中心及大数据产业发展中的项目跟踪审计工作，提高项目绩效；

市政务服务中心主要负责政务大数据建设及共享，为其他政务应用系统提供基础数据服务；
