# 三亚市人民政府办公室关于大力宣传三亚市区至南山景区开通海上巴士和旅游火车的通知

三亚市人民政府办公室

关于大力宣传三亚市区至南山景区开通

海上巴士和旅游火车的通知

各区人民政府，各管委会，市各有关单位：

近日我市开通了市区至南山景区的海上巴士和旅游火车，为广大市民和游客的出行增添了新的线路，根据市政府要求，请各单位鼓励干部职工和亲友选择新的出行方式，体验新的旅游产品，并广泛宣传。线路具体内容如下：

一、海上巴士。1月25日，“海琨号”高速客轮在鹿回头公共码头起航，标志着三亚市海上巴士正式开通。线路途经天涯海角、南山景区，全程票价90元，运行时间约50分钟。登船地点：鹿回头游艇公共码头（三亚市民游客中心对面）；咨询电话：13876580350、13976189027、15103077376。

“海琨号”高速客船可运载人数为350人，运营航速每小时30节，每天执行两次航行任务，在每天早上9时和下午1时准点在鹿回头公共码头起航，航程分为两段，在鹿回头公共码头至天涯海角景区单程票价60元，天涯海角景区至南山景区的单程票价为50元，鹿回头公共码头至南山景区的单程票价为90元。市民和游客可在鹿回头公共码头售票点购船票和景区门票，返程时也可在景区购买船票。

二、旅游火车。南山北站是旅游铁路新增建车站，开通运营后，三亚至南山北站间开行快速客运列车5对，单程票价为14.5元。（登车地点：三亚市火车站、南山北站，咨询电话：0898-31520482）。具体票价和列车时刻如下：
