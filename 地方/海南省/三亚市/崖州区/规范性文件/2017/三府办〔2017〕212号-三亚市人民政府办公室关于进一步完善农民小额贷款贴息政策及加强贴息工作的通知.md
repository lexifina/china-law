# 三亚市人民政府办公室关于进一步完善农民小额贷款贴息政策及加强贴息工作的通知

三亚市人民政府办公室

关于进一步完善农民小额贷款贴息政策

及加强贴息工作的通知

各区人民政府，育才生态区管委会，市各有关单位：

自2013年以来，省委、省政府已连续5年将农民小额贷款贴息工作列入为民办实事十大事项。《三亚市人民政府办公室关于进一步推进农民小额贷款贴息工作的实施意见》（三府办〔2014〕100号，以下简称《实施意见》）执行3年来，累计发放贷款7.216亿元，扶持农户、涉农企业1.98万人次，贴息奖补3906.21万元，为我市农业发展做出了重要贡献。为充分发挥农民小额贷款贴息在我市扶贫攻坚战中的助推作用，解决贴息政策执行过程中存在的问题，更好推动我市农民小额贷款贴息工作顺利开展，确保贴息资金的安全高效使用，根据《海南省人民政府办公厅关于进一步完善农民小额贷款贴息政策的通知》（琼府办〔2017〕103号），结合我市实际，现将有关事项通知如下。

一、完善贴息政策

（一）贴息政策进一步向贫困户倾斜

1.对金融机构发放给贫困户（指2014年底以来建档立卡贫困户，下同）5万元以下、3年以内、免抵押免担保、执行基准利率（指中国人民银行同期同档次基准利率，下同）的小额贷款，按照实际贷款期限每年给予全额贴息。

2.对金融机构发放给贫困户5年以内、执行基准利率的自建住房贷款，按照实际贷款期限每年给予全额贴息。

3.对金融机构按照基准利率发放给贫困户贷款的风险补偿比率提高至2%，贷款奖励金比率提高至2%。

（二）进一步扩大贴息对象范围

将《实施意见》第二条第一款第一项“贴息对象：在三亚市辖区内从事农业生产的海南省户籍的农民（含个体农民、地方农场职工、林业职工、农垦职工和渔民，以下简称农民）、农村妇女和在三亚市工商部门注册登记的农民专业合作社、为本地‘三农’服务的我市涉农企业。”修改为“贴息对象：拥有海南省农业户口的居民或属地在乡村的家庭户口的居民（含地方农场职工、林业职工、农垦职工和农民），农村妇女和在三亚市工商部门注册登记的农民专业合作社、为本地‘三农’服务的我市涉农企业。”

二、加强贴息工作

（一）规范贫困户贷款的贴息奖补流程

1.贴息方式为每年贴息，对于贷款期限超过1年的，在借款人每年正常偿还利息后，按年贴息的方式予以贴息，贷款到期全部还本付息后，再对剩余期限部分进行贴息。

2.对于符合贴息条件的贫困户贷款，由各金融机构编制发放符合贴息条件的贫困户贷款清单（见附件1），于每季度结束后5个工作日内报送市金融办和市财政局备案。

3.各经办金融机构原则上要于每年正常偿还利息后10个工作日内，将符合贴息条件的贫困户贷款贴息资金发到借款人账户，兑付贴息的同时要通过短信提醒借款人。按季度编制金融机构已贴息贫困户贷款清单（见附件2），并于每月结束后10个工作日内报送市金融办、市财政局和相关职能部门备案。

4.各经办金融机构在每季度结束后5个工作日内将符合贴息条件贫困户贷款的风险补偿和奖励金申请清单（见附件3）及贫困户贷款风险补偿和奖励金补助金申请总表（见附件4）报市金融办。市金融办在每季度结束后10个工作日内审核经办金融机构申请的贫困户贷款奖补，并将审核结果报市财政局申请资金。市财政局在3个工作日审核后，将贫困户贷款的风险补偿和奖励金、补助金拨付经办金融机构。

（二）加大宣传力度

1.加大贫困户贷款宣传力度。各区（生态区）要动员村“两委”，联合涉农金融机构，加大对贫困户的贴息政策和信用意识的宣传和教育培训，对贫困户的培训要做到进村入户、户户到位。

2.按时报送农民小额贷款贴息宣传工作总结。各区（生态区）、各职能部门要主动承担责任，明确农民小额贷款贴息宣传工作负责人，宣传发动的形式灵活多样，要通过树立农民小额贷款发展生产、致富典型，让农民切身体会到农民小额贷款带来的实惠，带动农民踊跃贷款。各涉农金融机构对贫困户的宣传培训要加大力度，保质保量。各区（生态区）、各职能部门、各涉农金融机构应于每年12月份前3个工作日内将农民小额贷款贴息宣传工作总结报送市金融办汇总。各单位宣传工作安排见附件5。

（三）开展专项检查

由市金融办牵头，联合我市农民小额贷款贴息工作领导小组成员单位，采取聘请中介机构的方式，定期对贴息工作开展专项检查。制定具体的检查方案（包括检查内容、检查方式、检查时间、实施步骤、检查人员及相关要求），检查整改结束后出具检查报告（包括整体情况、发现的问题、整改情况等）并及时报告给市政府、省政府金融办。

（四）提高贴息工作及时性

1.贴息情况报送方面，各经办金融机构要在每月15日前将上月已贴息农民小额贷款清单及兑付凭证、上月三亚市省市两级财政资金使用划分表、农民小额贷款贴息资金使用情况表报送至市金融办汇总。

2.奖补申报方面，各经办金融机构要在每季度结束后10个工作日内报送申请奖补的相关材料。

3.奖补审核方面，市金融办要在每季度结束后15个工作日内审核经办金融机构申请的奖补，并将审核结果汇总报市财政局申请资金。

4.奖补拨付方面，市财政局在3个工作日审核后，将奖补拨付经办金融机构。

三、其他说明

1.非贫困户的农民小额贷款贴息流程仍按照《三亚市人民政府办公室关于做好2015年农民小额贷款贴息工作的通知》（三府办〔2015〕87号）执行。

2.本通知自印发之日起执行。《实施意见》的有关政策和规定继续执行，与本通知不一致的，以本通知为准。
