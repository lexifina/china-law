# 三亚市人民政府办公室关于2017年6月份政府网站检测情况的通报

三亚市人民政府办公室

关于2017年6月份政府网站检测情况的通报

各相关单位：

为进一步做好我市政府网站信息内容建设有关工作，根据《国务院办公厅秘书局关于做好政府网站季度抽查工作的通知》(国办秘函〔2016〕48号)要求和《国务院办公厅关于开展第一次全国政府网站普查的通知》(国办发〔2015〕15号)确定的检查标准，2017年6月17日至6月26日，市政府办公室对全市纳入普查范围的网站进行了检测。现将有关情况通报如下：

一、总体情况

此次对我市正在运行的31个政府相关部门网站进行了检测，共有24个网站达标，6个网站未达标，1个网站因网络IP异常未列入检测。其中达标网站得分在90分以上的有3个，得分在80-89分区间的有8个，得分在70-79分区间的有12个，得分在60-69分区间的有1个，合格率为80%。

未达标的6个网站原因分别是：“三亚市卫生信息网”、“三亚市图书馆”因“单项否决”指标中“网站不更新”情况，被判定为未达标；“三亚市公安局”、“三亚市教育局”、“三亚市人力资源和社会保障局”因“单项否决”指标中“栏目不更新”情况，被判定为未达标；“三亚市文化广电出版体育局”网站因“网站可用性”、“信息更新情况”、“互动回应情况”三项指标累计扣分超过40分，被判定为未达标。

“三亚市考试中心”网站因网络IP出现异常无法打开网页，需对网站进行维护，已申请临时下线，此次检测未将其纳入。网站上线后将重新纳入政府网站检测。

二、主要问题

（一）网站栏目应更新未更新。此次检测的30个网站中有23个网站出现栏目应更新未更新情况。其中比较严重的有“三亚市教育局”网站存在6个应更新未更新栏目；“三亚市公安局”和“三亚市文化广电出版体育局”分别存在5个应更新未更新栏目。

（二）网站存在空白栏目。此次检测的30个网站中有10个网站存在空白栏目。其中2个网站存在突出问题，分别是“三亚市公安局”存在8个空白栏目；“三亚市人力资源和社会保障局”存在6个空白栏目。

（三）网站信息更新数量未达标。此次检测的30个网站中有15个网站存在信息更新数量未达标现象。其中包括：“三亚市图书馆”、“三亚市卫生信息网”2个网站在监测2周内，首页栏目无信息更新；“三亚市卫生监督所”、“三亚市质量技术监督局”、“三亚市统计信息网”、“三亚市公共就业服务网”、“三亚市创意新城”、“三亚市消防网”、“三亚市南繁科学技术研究院”、“三亚市社会保险事业局”、“三亚市发展和改革委员会”、“海南三亚国家农业科技园区”、“三亚市教育局”、“三亚市人力资源和社会保障局”、“三亚市文化广电出版体育局”13个网站在监测2周内，首页栏目信息更新数量少于10条。

三、下一步工作要求

（一）全市纳入政府网站普查范围的单位要切实履行网站主管责任，进一步完善常态化内容发布机制，坚持问题为导向，推进政府网站持续健康发展。

（二）此次检测未达标的“三亚市卫生信息网”、“三亚市人力资源和社会保障局”、“三亚市公安局”、“三亚市文化广电出版体育局”、“三亚市教育局”、“三亚市图书馆”网站要采取有力措施，全面核查相关情况及时完成整改，并于2017年7月20日将整改情况报市政府新闻信息领导小组办公室（市政府一办105室）。

（三）全市纳入政府网站普查范围的网站改版升级应确保正常运行的情况下进行。如无法确保正常运行，请提前向市政府新闻信息领导小组办公室申请临时下线，并在全国政府网站信息报送系统提交下线申请（临时下线每年不得超过1次，下线时间不得超过30天）。
