# 三亚市人民政府办公室关于三亚市吉阳区临春片区棚户区改造项目土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市吉阳区临春片区棚户区改造项目

土地调查有关事项的通知

吉阳区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对临春片区棚户区改造项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于吉阳区辖区内，用地调查面积约1320364平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市规划局出具的临春改造片区（含棚户区改造）土地调查规划红线图。土地权属（海南平面坐标系）情况为：吉阳区临春社区居委会集体土地约1103714平方米、三亚林场国有土地约152平方米、榆亚盐场国有土地约5467方米、国家所有土地约189447平方米、三亚市中医院国有土地约9平方米、临春小学国有土地约7226平方米、三亚（首都机场）投资开发有限公司国有土地约108平方米、海南电网公司三亚供电局国有土地约11平方米、三亚三特索道有限公司（收回注销）国有土地约4271平方米、部队土地约9960平方米。土地利用现状（西安80坐标系）为农用地约549309平方米（其中水田约109445平方米、旱地约143714平方米、果园约149928平方米、有林地约67845平方米、灌木林地约28561平方米、其他林地约19323平方米、坑塘水面约15856平方米、设施农用地约14637平方米）；建设用地约771834平方米（其中公路用地约4293平方米、城市约717848平方米、建制镇约2289平方米、村庄约44370平方米、风景名胜及特殊用地约3034平方米）。该项目用地在土地利用总体规划调整完善（西安80坐标系）中规划为城镇用地约879787平方米、公路用地约11537平方米、林地约87033平方米、特殊用地约8042平方米、园地约334742平方米。上述用地已由市规划局统筹纳入“多规合一”的技术路线蓝图中，正按程序上报。根据海南省国土资源厅对棚改项目用地的审批要求，新增农用地不列入棚改项目征收及农转用报批范围。待市规划局落实用地控制性详细规划指标后，市国土资源局从我市耕地占补平衡指标中统筹安排约253159平方米的耕地占补平衡任务，并将其列入当年新增建设用地指标办理农转用及征收报批手续。

二、为做好该项土地调查工作，由吉阳区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土资源局负责对、征收集体土地范围内征地业务指导工作；市住房城乡建设局负责对收回国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地及收回盐场、林场国有土地征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行；收回盐场、林场国有土地外的其他国有土地征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、根据2010年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，吉阳区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认，向市国土资源局出具履行征地前告知等程序的证明及土地权属确认意见（附件1）。待有权限的人民政府批准征地后，征收土地公告和征地补偿安置方案公告可同步进行。

五、为进一步做好被征地农民养老保险工作，根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神，应在本通知下发后10个工作日内对项目征收农用地和享受缴费补贴人数等情况进行调查，组织村（居）小组填写《征地项目被征地农民基本情况调查表》（附件2），经村（居）委会、吉阳区政府逐级审核后，由吉阳区政府汇总填写《征地项目被征地农民基本情况乡镇调查汇总表》（附件3），并将上述两种表格报送市国土资源局。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负
