# 三亚市人民政府办公室关于2017年7月份政府网站检测情况的通报

三亚市人民政府办公室

关于2017年7月份政府网站检测情况的通报

各相关单位：

为进一步做好我市政府网站信息内容建设有关工作，根据《国务院办公厅秘书局关于做好政府网站季度抽查工作的通知》（国办秘函〔2016〕48号）要求和《国务院办公厅关于开展第一次全国政府网站普查的通知》（国办发〔2015〕15号）确定的检查标准，2017年7月12日至7月24日，市政府办公室对全市纳入普查范围的网站进行了检测。现将有关情况通报如下：

一、总体情况

此次对我市正在运行的31个政府相关部门网站进行了检测，共有28个网站达标，2个网站未达标，1个网站因网络IP异常未列入检测。其中达标网站得分在90分以上的有10个，得分在80-89分区间的有7个，得分在70-79分区间的有8个，得分在60-69分区间的有3个，合格率为90%。

未达标的2个网站原因分别是：“三亚市图书馆”因“单项否决”指标中“网站不更新”情况，被判定为未达标；“三亚市农业局”网站因“网站可用性”“信息更新情况”“互动回应情况”三项指标累计扣分超过40分，被判定为未达标。

“三亚市考试中心”网站因网络IP出现异常无法打开网页，需对网站进行维护，已申请临时下线，此次检测未将其纳入。网站上线后将重新纳入政府网站检测。

二、主要问题

（一）网站内容保障不到位。此次检测的30个网站中有9个网站存在信息更新数量未达标现象。其中包括：“三亚市图书馆”在监测时间点前2周内，首页栏目无信息更新；“三亚市公共就业服务网”“三亚市卫生监督所”“三亚市财政局”“三亚市交通运输局”“三亚市创意新城”“三亚市卫生信息网”“海南三亚国家农业科技园区”“三亚市农业局”8个网站在监测时间点前2周内，首页栏目信息更新数量少于10条。

（二）网站栏目不更新问题依然存在。此次检测的30个网站中有16个网站出现栏目应更新未更新情况。其中比较严重的有“三亚旅游官方政务网”存在6个应更新未更新栏目；“三亚市农业局”和“三亚市教育局”分别存在5个应更新未更新栏目。

（三）网站办事服务功能亟待完善。此次检测的30个网站中有7个网站存在办事指南要素类别缺失的情况。例如“三亚市交通运输局”办事指南中“网络预约出租汽车驾驶员证报名事项”缺失设定依据、办理地点、办理时间、联系电话等4个要素。

三、下一步工作要求

（一）全市纳入政府网站普查范围的单位要切实履行网站主管责任，进一步完善常态化内容发布机制，坚持问题为导向，推进政府网站持续健康发展。

（二）全市纳入政府网站普查范围的网站要定期对网站办事服务的信息准确性、功能实用性进行核验，服务事项取消或办理条件发生变化的，要及时调整更新相关信息。

（三）此次检测未达标的“三亚市图书馆”“三亚市农业局”网站要采取有力措施，全面核查相关情况及时完成整改，并于2017年8月7日前将整改情况报市政府新闻信息领导小组办公室（市政府一办105室）。

三亚市人民政府办公室
