# 三亚市人民政府办公室关于调整三亚市交通基础设施扶贫攻坚战农村公路建设领导小组的通知

三亚市人民政府办公室

关于调整三亚市交通基础设施

扶贫攻坚战农村公路建设领导小组的通知

各区人民政府，各管委会，市政府直属各单位：

因人事变动和工作需要，市政府决定调整三亚市交通基础设施扶贫攻坚战农村公路建设领导小组，统筹协调我市交通基础设施扶贫农村公路建设工作，具体如下：

三亚市交通基础设施扶贫攻坚战农村公路建设领导小组办公室设在市交通运输局，办公室主任由市交通运输局党组书记吴海峰兼任。

二、工作职责分工

（一）市交通运输局作为项目建设单位，负责做好我市交通基础设施扶贫农村公路建设工作。

（二）市发展改革委负责协调省级补助资金并筹措落实市级建设资金。

（三）市财政局负责对资金拨付进行监督指导，落实财政性资金。

（四）市审计局、市国土资源局、市规划局、市水务局、市林业局、市生态环境保护局等部门负责按照职责分工做好行业指导和保障工作。

（五）各区政府、管委会，各农场负责做好各自辖区内的公路建设用地协调和保障工作。

（六）中国农业发展银行三亚分行负责按照资金需求保障贷款资金及时足额到位。
