# 三亚市人民政府办公室关于开展2017年度政府投资项目稽察工作的通知

三亚市人民政府办公室

关于开展2017年度政府投资项目稽察工作的通知

各区人民政府、市政府直属各单位：

根据《国家重大建设项目稽察办法》（国办发〔2000〕54号 国家计委2000年6号令）、《海南省重大建设项目稽察办法》（琼府办〔2001〕7号）等文件精神，为进一步加强和规范全市政府投资项目监管，保证工程质量和资金安全，充分发挥中央投资项目对我市经济的带动作用，经市政府同意，我市将开展2017年度政府投资项目稽察工作，现将有关事项通知如下：

一、指导思想

2017年，我市重大项目稽察工作以规范项目管理为目的，以保障资金安全和工程质量为核心，以强化监管为手段，指导和推动项目规范建设，进一步促进政府投资项目管理水平全面提升。

二、稽察范围和重点

稽察范围为2016年中央预算内投资项目，包括基础设施项目、双修双城项目、民生项目及其他项目等。

2017年稽察中央预算内投资项目有8个，具体项目详见附件1：三亚市2017年度政府投资稽察项目计划表。

三、稽察内容

（一）建设项目审批情况；

（二）招投标情况；

（三）合同签订及财务支付情况；

（四）概算执行情况；

（五）资金使用管理情况；

（六）工程质量及进度情况；

（七）投资计划执行情况等。

四、稽察方法和步骤

（一）自查阶段（2017年8—9月）

请市各有关部门（单位）对列入稽察的项目进行自查，并做好稽察前的准备工作，自查报告及稽察工作表于2017年9月30日前报市发展改革委，同时对列入稽察计划的项目，项目业主须每月2号前向市发展改革委报送项目进展情况月报表。（附电子文档）。

自查报告应包括所有列入本计划的项目，每个项目应包括：（1）项目基本情况（总投资及来源、建设内容和标准、建设或代建单位、开竣工时间、目前形象进度）；（2）各项前期手续办理情况（项目所有审批文件）；（3）招投标情况（招投标方案核准情况和执行情况）;（4）合同签订及财务支付情况；（5）概算执行情况（有无设计变更情况）；（6）资金使用管理情况（有无挪用建设资金的现象；有无随意更改批准的建设内容和标准）;（7）投资计划执行情况等。

（二）集中稽察（2017年10月）

根据各项目业主提交的自查资料情况，集中进行审查,并根据审查发现的问题进入建设项目现场进行核实、查验。现场检查期间，各项目业主单位应根据稽察组检查要求，积极配合做好现场检查准备。稽察组根据稽察中发现的问题，提出整改意见报市政府。根据市政府反馈意见，下发整改通知或通报，明确整改责任、整改要求和整改时限。

（三）整改阶段（2017年11月）

被稽察单位接到整改通知后，应当认真按照通知要求进行整改，切实解决好存在的问题，并在整改期限内报送整改报告至市发展改革委。稽察组将实时跟踪各项目整改情况，并进行复查，对个别不按时整改、性质恶劣、问题严重的项目，将给予通报。对存在严重违规违纪或重大违法行为的，将上报市政府，并按程序将相关资料移送有关部门进行处理。

（四）总结阶段（2017年12月）

在稽察和整改的基础上，市发展改革委对项目稽察工作进行认真总结，并将稽察总结报告上报市人民政府。

五、稽察组织

市发展改革委负责我市项目稽察工作。成立年度三亚市政府投资项目稽察组，组长由市发展改革委分管领导担任，成员由市发展改革委、市财政局、市法制办和各项目主管部门组成。市财政局、市法制办相对固定一名工作人员参与稽察工作，人员名单报市发展改革委，1名项目主管部门工作人员（市住房和城乡建设局、市水务局、）根据项目所属行业分管情况参与稽察工作（请各单位将人员名单于2017年9月30日前报市发展改革委）。

六、工作要求

（一）提高思想认识，增强稽察意识。政府投资项目各项目业主单位要确实提高对项目稽察工作重要性与必要性的认识，认识到稽察的根本目的是发现问题、解决问题、促进规范，保证工程质量和资金安全，提高投资效益。特别是列入2017年重点稽察的项目单位，要严格按照稽察工作要求，认真准备，积极主动开展自查，并配合稽察组工作，不得拒绝、隐匿、瞒报、伪报及无故拖延向稽察组报送稽察所需的相关资料。

（二）落实责任，强化稽察整改工作。稽察整改是稽察工作的关键，是突显稽察成效的主要抓手，对稽察出的问题，各单位要进行认真整改，稽察组将对整改情况进行复核，确保稽察成效。

（三）严格稽察工作纪律。稽察组成员应坚持清正廉洁、秉公办事、实事求是的原则，严格按照国家及省市有关政策、法律、法规、规章开展稽察工作，一律不得接受被稽察单位的任何馈赠、报酬，不得参加被稽察单位安排的宴请、娱乐等活动，稽察过程中要客观公正、实事求是记录和反映项目的情况和问题，确保稽察工作的公正性、客观性、有效性。
