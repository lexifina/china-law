# 三亚市人民政府办公室关于印发《三亚市危险化学品重大危险源和高风险点监管任务分解表》等的通知

三亚市人民政府办公室

关于印发《三亚市危险化学品重大危险源

和高风险点监管任务分解表》等的通知

各区人民政府、育才生态区管委会、市各有关单位:

为进一步明确责任，切实加强危险化学品重大危险源和高风险点安全监管，遏制重特大事故发生，市安委办近期对我市危险化学品重大危险源和高风险点进行了摸排，并编制了《三亚市危险化学品重大危险源和高风险点监管任务分解表》、《三亚市危险化学品重大危险源和高风险点分布统计表》、《三亚市重大危险源基本特征表》等3个表格，对危险化学品重大危险源和高风险点进行了责任分工。经市政府同意，现印发给你们，请认真贯彻执行。

附件：1.三亚市危险化学品重大危险源和高风险点监管责任分解表

2.三亚市危险化学品重大危险源基本特征表

3.三亚市危险化学品重大危险源和高风险点分布统计信息表

三亚市人民政府办公室

2017年8月7日
