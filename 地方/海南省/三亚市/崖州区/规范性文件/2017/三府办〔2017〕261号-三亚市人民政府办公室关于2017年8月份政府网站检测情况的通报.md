# 三亚市人民政府办公室关于2017年8月份政府网站检测情况的通报

三亚市人民政府办公室

关于2017年8月份政府网站检测情况的通报

各相关单位：

根据《国务院办公厅秘书局关于做好政府网站季度抽查工作的通知》（国办秘函〔2016〕48号）要求和《国务院办公厅关于开展第一次全国政府网站普查的通知》（国办发〔2015〕15号）确定的检查标准，市政府办公室2017年8月1日至8月15日对全市纳入普查范围的网站进行了检测。现将有关情况通报如下：

一、总体情况

此次对我市正在运行的31个政府部门网站进行了检测（新增“三亚市审计局”1个网站；关停“中国国家海岸三亚海棠湾”1个网站），共有29个网站达标，2个网站未达标。总体合格率93.5% ，比上月提高了3.5个百分点。其中达标网站得分在90分以上的有11个，得分在80-89分区间的有7个，得分在70-79分区间的有11个，得分在60-69分区间的有1个，得分低于60分的有1个。

未达标的2个网站分别是“三亚市审计局”因“单项否决”指标中存在“栏目不更新”情况，被判定为未达标；“三亚市消防网”因“单项否决”指标中“首页栏目未更新”情况，被判定为未达标。

二、主要问题

（一）网站栏目未更新问题依然突出。此次检测的31个网站在监测时间点前2周内有21个网站存在栏目应更新未更新情况。其中“三亚市审计局”“三亚市物价局”“三亚市林业局”网站存在多个应更新未更新栏目。

（二）网站常态化监管有待提高。“三亚市审计局”“三亚市公安局”等5个网站在监测时间点内存在多个空白栏目。

（三）网站出现无效链接或栏目附件无法下载等现象。在监测时间点前2周内，“三亚市农业局”网站首页存在无效链接5个，其他页面无效链接2个；“三亚市教育局”在“服务实用情况”指标中存在首页栏目附件无法下载4个。另有14个网站首页及其他页面存在无效链接情况。

三、下一步工作要求

（一）全市纳入政府网站普查范围的单位要对网站信息数据进行科学分类、及时更新，对信息数据无力持续更新或维护的栏目要进行优化整合。

（二）全市纳入政府网站普查范围的单位均要在首页添加“我为政府网站找错”监督举报平台入口，规范网站名称和域名，加强链接管理，严禁刊登商业广告。

（三）全市纳入政府网站普查范围的单位要进一步完善政府网站信息发布、解读回应和互动交流功能。

从2017年9月起，将把上述要求纳入政府网站检测内容。此次检测未达标的“三亚市消防局”“三亚市审计局”网站要采取有力措施进行整改，全面核查相关情况及时完成整改，并于2017年8月25日前书面报送市政府新闻信息领导小组办公室（市政府一办105室）。
