# 三亚市人民政府办公室印发关于加强规范性文件备案登记管理的通知

三亚市人民政府办公室

印发关于加强规范性文件备案

登记管理的通知

各区人民政府，育才生态区管委会，市政府直属各单位：

为贯彻落实《国务院关于加强市县政府依法行政的决定》和《国务院关于加强法治政府建设的意见》，加强和改进制度建设，依据《海南省规范性文件制定与备案登记规定》，结合我市实际，现就规范性文件的备案登记工作通知如下：

一、备案登记的范围、期限

本通知所称规范性文件是指在我市行政区域内，除市政府规范性文件外，各区人民政府、育才生态区管委会，市政府各部门和法律、法规授权具有公共管理职能的组织依据法定职权制定的涉及或影响不特定公民、法人和其他组织权利义务的可以反复适用、具有普遍约束力的行政公文。上述规范性文件需在发布之日起10个工作日内，报市人民政府法制办公室机构备案登记。

下列情形，不在备案登记范围：

（一）行政机关和法律、法规授权具有公共管理职能的组织规范内部工作制度、工作程序和职责分工、表彰奖励、责任追究、人事任免、转发上级文件以及对具体行政行为作出决定等事项制定的文件；

（二）实行垂直领导的行政机关制定的文件。

二、报送备案登记应提供的材料

（一）报送备案登记的报告（附件1需套红头盖章）；

（二）规范性文件文本及电子版（附件2电子版发送至市法制办邮箱abc88272247@sina.com）；

（三）制定机关的法律审核确认书（附件3需套红头盖章）；

（四）起草说明（附件4）

（五）制定规范性文件的依据文本和其他相关材料。

三、备案登记的办理

市法制办公室通过传真（号码：88283532）受理规范性文件备案登记，各区法制办、市政府直属各部门法规科或办公室按照报送备案登记应提供的材料负责报送工作。

市法制办公室应当自收到报送的材料之日起3个工作日内完成备案登记，并按照下列规定办理：

（一）提交的备案材料齐全、符合规定形式的，应当统一登记编号，并将登记的情况及编号书面通知制定机关；

（二）提交的备案材料不齐全、不符合规定形式的，暂缓备案登记。

暂缓备案登记的，由市法制办公室通知报送单位补充或者重新报送备案登记材料；补充或者重新报送备案登记材料符合规定的，予以备案登记。不具备制定规范性文件主体资格的机构制定的规范性文件，市法制办公室不予备案登记。

四、未备案规范性文件清理

请各区法制办、市政府直属各部门法规科或办公室对已发布的规范性文件开展一次集中清理，未向法制办公室备案登记的，应在一个月内清理完毕，重新向社会公布实施，并在公布之日起10日内，严格按照本《通知》中报送备案登记应提供的材料，向市法制办公室备案登记。

未按本通知要求办理备案登记的规范性文件，市法制办公室可提请市政府予以撤销。

五、考核通报

各区、市政府直属各部门规范性文件备案登记工作将纳入年度依法行政考核指标体系，定期考核并通报。

本《通知》实施后，请各区、市政府直属各部门制发规范性文件时，应严格按照备案登记要求，进一步做好规范性文件的备案登记工作，确保各区、市政府直属各部门制定规范性文件的规范化程度稳步提高，规范性文件质量明显提升。
