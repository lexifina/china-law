# 三亚市人民政府办公室关于天涯区凤凰机场至羊栏排洪沟工程项目土地调查有关事项的通知

三亚市人民政府办公室

关于天涯区凤凰机场至羊栏排洪沟工程项目

土地调查有关事项的通知

天涯区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对天涯区凤凰机场至羊栏排洪沟工程项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于天涯区辖区内，用地调查面积约114615平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市规划局出具的凤凰镇镇区控规部分绿地及水域用地红线图和城市总规部分园地、基本农田和防护绿地用地红线图。土地所有权均属天涯区水蛟和羊栏村委会；土地利用现状（西安80坐标系）为农用地约84461平方米（其中水田约63779平方米、旱地约11129平方米、有林地约243平方米、设施农用地约9310平方米）、建设用地约30227平方米（其中公路用地约339平方米、河流水面约7668平方米、建制镇约21211平方米、村庄约981平方米、采矿用地约28平方米）；该项目用地在土地利用总体规划调整完善（西安80坐标系）中规划为城镇用地约616平方米、公路用地约67平方米、旱地约11101平方米、河流水面约4166平方米、设施农用地约5640平方米、水田约34078平方米、铁用地约248平方米、园地约58772平方米。该排洪沟建设工程为农业土地整治项目，不列入农用地转用及征收报批计划。

二、为做好该项土地调查工作，由天涯区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、农业土地整治项目用地的补偿工作按2015年第169期三亚市人民政府市长办公会议纪要第三项议题的议定精神执行。

四、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
