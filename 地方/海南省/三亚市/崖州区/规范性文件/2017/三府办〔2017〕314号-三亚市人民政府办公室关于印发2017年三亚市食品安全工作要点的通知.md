# 三亚市人民政府办公室关于印发2017年三亚市食品安全工作要点的通知

三亚市人民政府办公室

关于印发2017年三亚市食品安全

工作要点的通知

各区人民政府，各管委会，市政府直属各单位：

《2017年三亚市食品安全工作要点》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年9月30日

（此件主动公开）

2017年三亚市食品安全工作要点

根据《海南省人民政府办公厅关于印发2017年海南省食品安全工作要点的通知》(琼府办〔2017〕121号)和《海南省人民政府办公厅关于印发海南省食品药品安全“十三五”规划的通知》(琼府办〔2016〕323号)精神，制订我市2017年食品安全工作要点如下：

一、为民办实事重点事项

解决以前由于投入不够造成的历史欠账，补齐基础性短板，让公众切实感受到食品安全水平的提高。

（一）清除未派驻检验检疫人员的生猪屠宰场(点)。改造生猪屠宰场(点)，提高生猪和猪肉运输能力，使经过检验检疫的猪肉供应覆盖辖区所有村居。坚决关闭未配备检验检疫人员的生猪屠宰场(点)，防止未经检验检疫猪肉和病死猪肉流入市场。(责任单位：市农业局，各区人民政府)

（二）建设病死猪无害化处理设施。贯彻《海南省人民政府办公厅关于印发海南省建立病死畜禽无害化处理机制实施方案的通知》(琼府办〔2015〕83号)，落实病死畜禽无害化处理项目建设用地、项目环评和项目建设资金等，促进病死畜禽无害化处理项目早日建成。(责任单位：市农业局，各区人民政府)

（三）解决“无根豆芽”问题。将豆芽生产纳入“菜篮子”工程给予补贴，支持利用恒温设备生产豆芽的生产企业或作坊，为市场提供不添加“无根水”“无根素”的合格豆芽。(责任单位：市发展改革委、市食品药品监督管理局，各区人民政府;配合单位：市农业局、市商务会展局)

（四）实施食品生产加工小作坊集中生产。根据本地食品加工作坊的主要品种，参照海口市豆腐、米粉集中生产的模式，建立食品生产加工作坊集中区域。(责任单位：市食品药品监督管理局、相关区人民政府，配合单位：市规划局、市发展改革委、市商务会展局、市财政局、市生态环境局、市工商行政管理局、三亚质量技术监督局、市国土资源局、市住房城乡建设局)

（五）实施小摊贩、小餐饮集中经营。各区建立食品小摊贩、小餐饮集中经营区域或小餐饮一条街。(责任单位：各区人民政府，配合单位：市综合行政执法局、市发展改革委、市商务会展局、市财政局、市规划局、市生态环境局、市食品药品监督管理局、三亚工商行政管理局、三亚质量技术监督局、市国土资源局、市住房城乡建设局)

（六）改造升级农贸市场。对城区“脏、乱、差”的农贸市场改造升级，改造后的城区农贸市场熟食专间、食品安全检测室等设施建设达标率达到50%以上。(责任单位：市商务会展局;配合单位：各区人民政府，市食品药品监督管理局)

（七）改造升级学校食堂。加大对学校食堂的投入，使硬件不达标（面积可适当降低标准）的学校食堂比2016年减少30%。(责任单位：市教育局;配合单位：各区人民政府，市食品药品监督管理局)

（八）推行病虫害、动物疫病统防统治专业化服务，扶持培育经营性服务组织。(责任单位：市农业局，各区人民政府;配合单位：三亚质量技术监督局、市财政局)

二、整治突出问题，打击食品安全违法犯罪行为

针对食品安全突出问题，采取多轮次、全覆盖、拉网式的排查整治，切实消除一批问题，杜绝“整治年年搞，问题年年在”的现象。

（九）打击销售使用禁限用农药兽药的违法行为。加强农药兽药安全间隔期、休药期管理。健全农药兽药定点经营、实名购买制度。反复开展全覆盖、拉网式明查暗访的禁限用农药兽药专项整治，查处销售、使用禁限用农药兽药的违法行为。(责任单位：市农业局、市海洋渔业局;配合单位：各区人民政府)

（十）解决人用药用于畜禽的问题。严查重罚药店不凭处方销售抗生素的行为，防止药店将人用抗生素销售给农户用于畜禽防治疾病。(责任单位：市食品药品监督管理局、市农业局，各区人民政府)

（十一）提高畜禽水产品的质量安全水平。集中治理农药兽药残留超标突出问题。开展科学种养技术培训，指导农户依法科学合理使用农药、兽药、饲料和饲料添加剂。严厉打击畜禽水产品中违规使用抗生素以及非法使用“瘦肉精”、硝基呋喃、孔雀石绿等禁用化合物的行为，清理违法违规销售兽药和禁用化合物的网站，严惩违法生产经营者，曝光典型案例。(责任单位：市农业局、市海洋渔业局、市食品药品监督管理局，各区人民政府)

（十二）严查严打食品生产加工“黑窝点”。将提供食品生产、批发“黑窝点”信息，纳入网格员、综合治安员的工作职责。公安部门对行政监管部门移送的食品安全违法犯罪案件快侦快办，提高立案率，实现从严、从快打击。对失职渎职的监管部门人员给予最严厉的问责。(责任单位：各区人民政府，市综治办;配合单位：市公安局、市监察局)

（十三）清除不达标食品生产加工小作坊。落实食品生产加工小作坊生产技术规范，对不愿意按规范要求改造的小作坊实行强制退出。(责任单位：市食品药品监督管理局，各区人民政府)

（十四）防止已被基本清除的食品安全突出问题“死灰复燃”。继续反复拉网排查使用甲醛、双氧水浸泡食物，在米粉、面条中添加硼砂和防腐剂，在火锅中添加罂粟壳，用工业松香、沥青拔畜禽毛，销售走私冻肉制品等违法违规行为。(责任单位：市食品药品监督管理局;配合单位：市公安局)

（十五）进一步提高桶装饮用水等“必需品”的安全水平。保持高压态势，继续降低桶装饮用水、集中消毒餐饮具的不合格率。(责任单位：市食品药品监督管理局)

（十六）清除说明书、标签和广告违规的保健食品。依法严查保健食品在说明书、标签标识、广告中进行虚假宣传、夸大功效的欺诈行为，对违规宣传的保健食品责令下架。(责任单位：市食品药品监督管理局、市工商行政管理局)

（十七）打击篡改食品保质期、翻新过期食品的违法行为。(责任单位：市食品药品监督管理局)

（十八）加强食品相关产品生产企业监管，规范标识标注。进一步加大对食品相关产品的执法打假力度。(责任单位：三亚质量技术监督局)

（十九）解决米、面、油等日常消费量大的食品存在的突出问题，重点在批发环节开展排查、整治行动。(责任单位：市食品药品监督管理局，配合单位：市粮食局)

（二十）规范网络销售食品行为。排查网络食品经营者许可证，严查持过期、借用、编造、伪造许可证经营和超范围经营行为。(责任单位：市食品药品监督管理局)

（二十一）对食品仓储和冷链运输开展专项整治，查处不按标示温度条件存放、运输食品的行为。(责任单位：市食品药品监督管理局)

（二十二）落实国家加快发展冷链物流保障食品安全促进消费升级的意见。(责任单位：市交通运输局;配合单位：市发展改革委、市农业局、市海洋渔业局、市商务会展hh局、市卫生计生委、三亚质量技术监督局、市食品药品监督管理局)

（二十三）深入开展农村食品安全治理，重点排查整治农村及城乡结合部突出的食品安全风险隐患，针对性强化长效机制建设。(责任单位：市食品药品监督管理局、市农业局、市工商行政管理局，各区人民政府)

（二十四）加强农村集体聚餐管理。完善农村集体聚餐管理措施，由各区政府督促每个村（居）确定至少1名食品安全信息员负责收集和上报本村（居）的农村集体聚餐信息，食品安全监管部门接到报告后按照规定进行现场指导。（责任单位：各区人民政府，市食品药品监督管理局）

（二十五）开展食用农产品批发市场专项治理，督促食用农产品批发市场开办者落实食品安全管理责任，全面摸清农产品一级批发市场进岛蔬菜质量安全底数。(责任单位：市食品药品监督管理局)

（二十六）加强学校食品安全管理。落实学校和幼儿园负责人食品安全第一责任，对发生食品安全事件的学校、幼儿园负责人，取消评优评先资格、扣减绩效工资、解除聘用。探索推行学校食堂“家长监督委员会制度”。严查学校内部及周边经营“三无”食品等违法违规行为，校园周边200米范围内无食品摊贩经营区域及“三无”食品出售。开展学生食品安全教育。(责任单位：市教育局、市食品药品监督管理局、市综合行政执法局，各区人民政府)

（二十七）巩固国家卫生城市食品安全环节成果。建立常态化监管机制，将监督食品生产经营者是否符合国家卫生城市标准纳入网格管理员职责，开展日常巡查，保持长抓常管，及时消灭存在问题。（责任单位：市食品药品监督管理局，各区人民政府）

（二十八）对列入《进口食品境外生产企业注册实施目录》内食品的境外生产企业严格开展注册核查工作。（责任单位：三亚出入境检验检疫局）

（二十九）加大对重点敏感食品走私的打击力度。(责任单位：三亚海关)

（三十）开展进出口食品安全领域质量安全风险排查。落实进口食品进出口商备案制度，对进出口食品安全领域的重点产品、重点企业、重点环节和重点区域开展排查整治，提升进出口食品质量安全水平。进一步强化国境口岸食品安全监管，加强国际通行交通工具食品及饮用水供应单位的监督力度，提升供给质量，防范口岸食品安全事件的发生。加强进出口农产品和饲料安全监管，开展风险监控。(责任单位：三亚出入境检验检疫局)

（三十一）启动农用地土壤污染状况调查。建立全市土壤环境重点监管企业名单，并向社会公布。(责任单位：市生态环境局)

（三十二）开展耕地质量保护与提升行动，推进农业面源污染防治攻坚行动。(责任单位：市农业局；配合单位：各区人民政府)

（三十三）落实国务院关于加强粮食重金属污染治理的各项措施，指导中轻度污染耕地安全利用以及重度污染耕地食用农产品禁止生产区域划定，处理好调整种植结构和保护农民利益的关系。(责任单位：市农业局、市发展改革委、市财政局、三亚粮食局，各区人民政府)

三、完善监管体系，提升食品安全监管能力

不断完善食品安全监管法律法规，加强食品安全监管基础建设，提升监管能力，适应新监管形势的需要。

（三十四）落实“十三五”国家食品安全规划及海南省食品药品安全“十三五”规划，将规划实施情况纳入对各区政府的考评内容。(责任单位：市食安委、市食安委各成员单位，各区人民政府)

（三十五）加强食品安全法治教育。各级食品安全监管人员、各类食品生产经营单位负责人、主要从业人员全年接受不少于40小时的食品安全集中培训。完善食品安全行政执法程序，加强行政处罚法律适用的指导。(责任单位：市食安委有关成员单位，各区人民政府)

（三十六）完善食品安全监管地方法规和制度。贯彻落实《海南省食品生产加工小作坊监督管理办法》《海南省食品摊贩监督管理办法》，制定完善《三亚市食品安全委员会工作规则》，根据修改完善后的《海南省市县经济社会发展主要指标考核办法》修改完善我市的主要指标考核办法。(责任单位：市食安委、市食品药品监督管理局、市统计局，各区人民政府)

（三十七）采取切实有效措施加强各级食安办建设，充实各级食安办人员和经费保障，提升食品安全综合协调能力。（责任单位：市食安委、各区人民政府、市食品药品监督管理局）

（三十八）促进食品安全风险监测上台阶。组织落实国家、省食品安全风险监测计划，加大风险监测评估力度。完善风险交流和形势会商工作机制。推进部门间风险监测、评估和监督抽检信息共享，用好互联网、大数据，加强风险监测结果通报与会商研判。(责任单位：市卫生计生委、市食安办;配合单位：市农业局、市海洋渔业局、市食品药品监督管理局、三亚质量技术监督局、三亚粮食局)

（三十九）开展农渔产品质量安全风险隐患摸底排查，加强风险监测、评估和监督抽检，公布抽检信息。(责任单位：市农业局、市海洋渔业局)

（四十）推进风险分级制度落地，在风险分级基础上加强日常监督检查，贯彻“双随机、一公开”原则，通过彻查隐患、抽检“亮项”、处罚到人、公开信息，曝光所有违法违规企业，倒逼生产经营者落实主体责任。加大专项检查和飞行检查力度，推行检查表格化、抽检制度化、责任网格化，落实日常检查和监督抽检两个责任。(责任单位：市食品药品监督管理局)

（四十一）建设食品安全追溯体系。推进肉类、蔬菜追溯体系建设，指导大型食品生产企业建立追溯体系。(责任单位：市商务会展局、市农业局、市食品药品监督管理局)

（四十二）贯彻实施食品工业企业诚信管理体系国家标准，推动和鼓励食品工业企业开展诚信管理体系评价。(责任单位：市科技工业信息化局)

（四十三）开展风险预警交流，及时发布食品安全抽检信息、风险警示或消费提示。探索开展大型食品企业风险交流，完善重要信息直报制度和直报网络，加强食品安全舆情监测预警，完善三亚市食品安全突发事件应急预案。(责任单位：市食安办、市食安委有关成员单位)

（四十四）加强食品安全基层监管力量和基础设施建设。加强基层食品安全和农产品质量安全监管机构与技术队伍能力建设，推动实现业务用房、执法车辆、执法装备配备标准化，保障各级食品安全监管所需经费，特别是检验检测经费。解决基层食药监管所的办公用房、执法执勤车辆不足的问题。(责任单位：市财政局、市发展改革委、市食品药品监督管理局、市农业局、市海洋渔业局、三亚粮食局，各区人民政府)

（四十五）强化各级公安机关食品药品犯罪专业侦查力量。(责任单位：市公安局)

（四十六）建立健全食品安全信用档案并依法及时向社会公布，加强对食品生产经营失信者的联合惩戒。(责任单位：市食安委各成员单位；配合单位：市金融办)

（四十七）市疾控中心食品安全风险监测设备达标率达到国家规定的配置标准。(责任单位：市卫生计生委)

（四十八）推动我市粮食质量检验监测体系建设，保障粮食质量安全。进一步加强粮食质量安全属地管理责任，建立健全我市粮食质量检验机构，落实人员编制，配备检验监测设备，或配合将市级粮食检验监测能力建设纳入省级食品检验监测体系建设，确保全市政策性粮食质量安全。(责任单位：市粮食局；配合单位：市食品药品监督管理局)

（四十九）建立食品安全工作绩效与履职评定、奖励惩处挂钩制度。(责任单位：市食品药品监督管理局、市农业局、市海洋渔业局、市公安局、市卫生计生委、市教育局，各区人民政府)

四、实施食品安全示范、样板工程

以示范、样板工程引领食品安全发展方向，鼓励各级政府、企业加大投入力度，为公众打造更有安全保障的食品消费环境，为市场提供更优质食品。

（五十）深入实施农业标准化战略，突出优质、安全和绿色导向，严格无公害农产品、绿色食品、有机农产品和农产品地理标志(“三品一标”)认证，围绕市场需求调整农产品种养结构。(责任单位：市农业局、三亚质量技术监督局)

（五十一）实施国际标准认证工程。在大型食品生产企业、连锁超市、五星级酒店推行HACCP认证体系，引导一批企业通过认证。(责任单位：市食品药品监督管理局)

（五十二）创建省级食品安全示范学校食堂。落实好即将出台的《海南省学校食堂食品安全标准化(示范)建设现场检查评定标准(试行)》，配合省级部门建立学校食品安全管理检查员队伍及规范复核、监督整改、审核验收等工作程序。深入推进三亚市省级食品安全示范学校食堂创建工作。(责任单位：市食品药品监督管理局、市教育局;配合单位：各区人民政府)

（五十三）大力开展餐饮服务食品安全示范街/区、示范店创建，不断提升我市餐饮服务行业食品安全水平。（市食品药品监督管理局）

（五十四）开展实施餐厨废弃油脂治理工程试点工作。以集体食堂和大中型以上餐饮单位为重点，推行安装油水隔离池、油水分离器等设施，完善餐厨废弃物的集中收集、资源化利用和无害化处理措施，严防“地沟油”流向餐桌。(责任单位：市园林环卫局、市综合行政执法局、市食品药品监督管理局、市教育局、市商务会展局、市工商行政管理局；配合单位：各区人民政府)

（五十五）配合省级部门实施“透明厨房”和“透明车间”工程。在学校食堂、旅游团队接待酒店和食品生产车间安装监控视频，并连接到有线电视机顶盒、智能手机上，让学生家长和消费者通过高清电视机和手机收看制作现场实况，督促生产经营单位提升食品安全水平和餐饮业质量安全水平。选择一个条件较好的区作为试点，实现学校食堂“透明厨房”全覆盖。(责任单位：市食品药品监督管理局、市教育局，各区人民政府)

（五十六）实施“放心粮油”工程。整合利用现有粮食行业及社会资源，培育扶持一批“放心粮油”企业和产品，在具备条件的地方规范认定、建设一批“放心粮油”配送中心，在中心城区和四个区管辖范围规范认定、建设一批“放心粮油”示范店和经销点，初步建成规范化、网络化、标准化、信息化程度较高的“放心粮油”供应网络，逐步形成覆盖城乡、连接产销、设施完善、服务规范的“放心粮油”供应体系。(责任单位：市粮食局；配合单位：各区人民政府)

（五十七）启动放心食品工程。推出一批“放心豆芽”“放心米粉”“放心冻肉”等放心食品和放心企业。(责任单位：市食品药品监督管理局)

（五十八）推进进口食品安全放心工程。严防不合格进口婴幼儿配方乳粉、肉类、食用油、酒类等食品从三亚口岸入境。(责任单位：三亚出入境检验检疫局)

（五十九）打造食品加工产业集群，引导食品加工企业向主产区、优势产区、产业园区集中，加大技术改造支持力度，促进食品工业增品种、提品质、创品牌。 (责任单位：市科技工业信息化局、市发展改革委，各区人民政府)

（六十）推广“生产基地+中央厨房+餐饮门店”“生产基地+加工企业+商超销售”等产销模式。 (责任单位：市农业局、市食品药品监督管理局，各区人民政府)

（六十一）按照2017年出口食品企业“逐一帮扶”行动计划，开展好“同线同标同质”工程等相关工作。（责任单位：三亚出入境检验检疫局)

（六十二）推广食品安全责任保险，鼓励食品生产经营企业投保食品安全责任险。(责任单位：市食品药品监督管理局，中国平安保险公司三亚分公司)

（六十三）强化食品安全科普网点建设，推进食品安全科普工作队伍建设和示范创建。(责任单位：市科协)

以上工作由市食安办联合市级有关部门对各项工作完成情况进行考核。
