# 三亚市人民政府办公室关于三亚市绕城高速及互通绿化彩化工程项目土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市绕城高速及互通绿化彩化工程项目土地调查有关事项的通知

各区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对绕城高速及互通绿化彩化工程项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目起点于吉阳区迎宾互通立交，终点至崖城互通立交，用地调查面积约279022平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市住房城乡建设局出具的三亚市绕城高速及互通绿化彩化工程项目用地红线图（已在市规划局审核出具的用地红线范围内扣除市交通运输局已征部分用地）。土地权属（海南平面坐标系）情况为：吉阳区中廖、南丁村委会集体土地共约10957平方米，崖州区临高、南山村委会集体土地共约18050平方米，天涯区妙林、新联、桶井、梅村、槟榔、水蛟、塔岭、布甫、文门、红塘、过岭、黑土村委会集体土地共约117858平方米，海棠区三灶、庄大、林新、湾坡村委会集体土地共约17356平方米，国家所有土地约1187平方米，三亚市公安局戒毒康复农场、南新农场、南滨农场、荔枝沟农场及三亚林场国有土地共约87188平方米，三亚警备区部队国有土地约2665平方米，三亚市人民政府及原田独镇政府国有土地共约10403平方米，三亚市林业科学研究所、三亚长丰海洋天然气供气有限公司等7家单位国有土地共约13363平方米；土地利用现状（西安80坐标系）为农用地约199491平方米（其中水田约39851平方米、旱地约19448平方米、果园约25409平方米、可调整果园约568平方米、其他园地约20836平方米、可调整其他园地约137平方米、有林地约57730平方米、可调整有林地约2251平方米、灌木林地约30792平方米、其他草地约1216平方米、坑塘水面约1136平方米、设施农用地约117平方米），建设用地约74544平方米（其中铁路用地约9498平方米、公路用地约12945平方米、水库水面约366平方米、水工建筑用地约723平方米、建制镇约11326平方米、村庄约11135平方米、采矿用地约7257平方米、风景名胜及特殊用地约21294平方米），未利用地约5166平方米（其中河流水面约189平方米、沿海滩涂约6平方米、裸地约4971平方米）；该项目用地在土地利用总体规划2014年调整完善（西安80坐标系）中规划为城镇用地约3668平方米、公路用地约16169平方米、旱地约10528平方米、河流水面约2平方米、坑塘水面约455平方米、林地约103103平方米、农村居民点用地约14494平方米、水工建筑用地约723平方米、水田约28010平方米、滩涂约6平方米、铁路用地约3453平方米、园地约97637平方米、自然保留地约955平方米。该项目为绿化彩化景观带工程，不列入农用地转用及征收报批计划。具体征地范围以市住房城乡建设局与各区政府现场实际勘测确认为准，现既有绿化带不列入该项目征地调查范围。

二、为做好该项土地调查工作，由各区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土资源局负责征收集体土地范围内征地业务指导工作；市住房城乡建设局负责收回国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地及收回部队、农场、林场国有土地征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行；收回部队、农场、林场国有土地外的其他国有土地征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、根据2010年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，各区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认工作。

五、为进一步做好被征地农民养老保险工作，各区政府应根据省人力资源社会保障厅、省财政厅和原省国土环境资源厅 2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神办理。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
