# 三亚市人民政府办公室关于印发三亚市河长制工作督察制度的通知

三亚市人民政府办公室

关于印发三亚市河长制工作督察制度的通知

各区人民政府，育才生态区管委会，市各有关单位：

《三亚市河长制工作督察制度》已经市政府第16次常务会议审议通过，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年10月26日

（此件主动公开）

三亚市河长制工作督察制度

第一条 督察目的

为贯彻落实《中共三亚市委办公室、三亚市人民政府办公室关于全面推进河长制工作方案的通知》（三办发〔2017〕15号），加强河长制工作督察，落实工作职责，提升工作效率，现结合《海南省河长制工作督查制度》，特制定本制度。

第二条 督察适用范围

本制度适用于全面推行河长制工作实施情况市级督察。

第三条 督察总体要求

坚持实事求是、统筹协调、分工负责的原则，全面开展河长制工作市级督察，及时掌握市河长制成员单位全面推行河长制工作进展情况，指导、督促区级河长办公室健全工作机制、明确工作责任，并按照时间节点、工作目标和工作要求落实河长制工作任务。

第四条 督察主体及对象

（一）河长督察。市级总河长、河长对市河长制成员单位、区级河长履行河长制工作情况进行督察；对市河长办公室不能有效督察的重大事项进行督察。

（二）河长办公室督察。市河长办公室牵头组织各相关部门对各区河长制工作落实情况进行督察，或受市级河长委托对市河长制成员单位开展河长制工作情况进行督察。

（三）责任单位督察。市河长制成员单位按照职责分工负责组织实施，开展对下级部门全面推行河长制、落实河湖管理保护职责情况进行督察。

第五条 督察主要内容

（一）河湖分级名录确定情况。各区（育才生态区）根据河湖自然属性、行政区域情况以及对经济社会发展、生态环境影响的重要性等，确定需由各区（育才生态区）负责同志担任河长的河湖名录情况，村（居）委会干部分级担任河段长的河湖名录情况。

（二）工作方案制定和实施情况。各区（育才生态区）全面推行河长制工作方案制定、阶段目标设定、任务细化、工作进展等实施情况。

（三）组织体系建设情况。包括区、村河长体系建立情况，总河长、河长、河段长的设置情况，区河长办公室设立及工作人员落实情况；河湖管理保护、执法监督主体、人员、设备和经费落实情况；以市场化、专业化、社会化为方向，培育环境治理、维修养护、河道保洁等市场主体情况；河长公示牌的竖立及监督电话的畅通情况等。

（四）制度建立和执行情况。各区（育才生态区）河长会议制度、信息共享和信息报送制度、工作督察制度、考核问责与激励制度、验收制度等制度的建立和执行情况。

（五）河长制主要任务实施情况。市河长制成员单位有关水资源保护、水域岸线管理保护、水污染防治、水环境治理、水生态修复、执法监管等主要任务实施情况；信息公开、宣传引导、经验交流等工作开展情况。

（六）整改落实情况。各级部门检查、督导发现的问题以及媒体曝光、公众反映强烈的问题的整改落实情况。

（七）市总河长会议、河长会议和成员单位联席会议决议（决定）落实情况。

（八）其它需要督察的事项。具体督察内容可根据督察检查各区（育才生态区）河湖管理和保护的实际情况有所侧重。

第六条 市河长办公室在市委、市政府督察机构的领导下，负责统筹协调河长制督察工作。市河长制成员单位按照职责分工做好督察工作。

第七条 督察工作可以根据督察任务需要，采取联合督察和专项督察的方式。联合督察由市河长办公室负责牵头，相关成员单位参加，负责督察河长制工作整体推进情况和重大事项落实情况；专项督察由市河长制成员单位组织，对职责范围内的事项进行专项督察。督察采取听取情况汇报、交流座谈、查阅相关文件与资料、实地查看现场等措施。

第八条 督察任务采用“督察函”书面形式下发，责任单位“督察函”由该单位负责人签发，报市河长办公室备案；河长办公室“督察函”由市河长办公室负责人签发；市级总河长、河长“督察函”由总河长、河长签发，由市委督查室或市政府督查议案室负责督促落实。

第九条 联合督察和专项督察在督察结束后5个工作日内，向市河长办公室提交督察报告，由市河长办公室将督察发现的问题及相关意见分别按一地一单的方式反馈至有关单位，并分别抄报市总河长、河长和相关成员单位负责人。

第十条 被督察责任单位要及时向市河长办公室书面反馈问题处理及整改情况。对督察意见不重视、不落实整改要求的，由市级河长对部门及相关责任人进行约谈。

第十一条 督察单位应当对督察事项登记造册，统一编号。督察任务完成后，及时将督察事项原件、领导批示、整改和处理情况、督察报告等资料立卷归档，以备核查。

第十二条 本制度由三亚市河长办公室负责解释。

第十三条 本制度自印发之日起实施。
