# 三亚市人民政府办公室关于成立三亚市教育体制改革领导小组的通知

三亚市人民政府办公室

关于成立三亚市教育体制改革领导小组

的通知

各区人民政府，育才生态区管委会，市政府各有关单位：

为进一步推进我市教育体制机制改革，市政府决定成立教育体制改革领导小组，明确领导小组职责。现将组成人员名单和职责通知如下：

二、工作职责

领导小组下设办公室，办公室设在市教育局，办公室主任由吴萍局长兼任，办公室负责在领导小组的领导下开展相关协调工作。领导小组负责研究部署、指导实施全市教育体制改革的重大方针政策和措施，统筹协调解决全市教育体制改革发展中的重大问题，构建有利于全市教育事业科学发展的体制机制，指导和督促全市教育体制改革重大试点项目的科学实施，协调和指导全市民办教育改革发展和全市考试招生制度改革。
