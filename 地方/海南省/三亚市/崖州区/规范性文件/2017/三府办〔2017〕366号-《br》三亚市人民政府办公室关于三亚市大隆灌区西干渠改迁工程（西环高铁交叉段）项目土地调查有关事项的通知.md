# <br>三亚市人民政府办公室关于三亚市大隆灌区西干渠改迁工程（西环高铁交叉段）项目土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市大隆灌区西干渠改迁工程（西环高铁交叉段）项目土地调查有关事项的通知

崖州区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对三亚市大隆灌区西干渠改迁工程（西环高铁交叉段）项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于崖州区辖区内，用地调查面积约6042平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见三亚市水利水电勘测设计院出具的三亚市大隆灌区西干渠改迁工程（西环高铁交叉段）项目征地图。土地权属（海南平面坐标系）情况为崖州区长山村委会集体土地约5983平方米、梅东村委会集体土地约59平方米；土地利用现状（西安80坐标系）为农用地约5945平方米（其中水田约1479平方米、旱地约4205 平方米、可调整果园约172平方米、可调整其他园地约64平方米、坑塘水面约25平方米），建设用地约102平方米（其中铁路用地约68平方米、村庄约34平方米）；该项目用地在土地利用总体规划2014年调整完善（西安80坐标系）中规划为旱地约4205平方米、坑塘水面约25平方米、林地约167平方米、农村居民点用地约34平方米、水田约1479平方米、铁路用地约23平方米、园地约115平方米。该灌溉工程为农业土地整治项目，不列入农用地转用及征收报批计划。

二、为做好该项土地调查工作，由崖州区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、农业土地整治项目用地的补偿工作按2015年第169期三亚市人民政府市长办公会议纪要第三项议题的议定精神执行。

四、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
