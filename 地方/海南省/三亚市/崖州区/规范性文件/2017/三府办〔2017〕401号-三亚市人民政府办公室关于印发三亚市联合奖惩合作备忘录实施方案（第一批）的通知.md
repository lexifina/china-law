# 三亚市人民政府办公室关于印发三亚市联合奖惩合作备忘录实施方案（第一批）的通知

三亚市人民政府办公室

关于印发三亚市联合奖惩合作备忘录实施方案（第一批）的通知

各区人民政府,育才生态区管委会,市各有关单位：

现将《三亚市联合奖惩合作备忘录实施方案（第一批）》印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年12月14日

（此件主动公开）

三亚市联合奖惩合作备忘录实施方案（第一批）

为加强社会信用体系建设工作，国家发展改革委牵头，联合相关部门和单位以签订合作备忘录的形式加强联合奖惩工作。自2014年以来，已签订了28个合作备忘录，其中4个联合激励备忘录，24个联合惩戒备忘录，分别明确了联合奖惩对象、发起部门、配合部门，奖惩措施和实施要求，今后还将陆续签订。为贯彻落实部委签订的合作备忘录，加大联合奖惩工作力度，现提出以下实施方案。

一、 实施备忘录奖惩措施市级部门配置。

市金融办（市信用办）负责将部际联合奖惩备忘录配置到市公共信用信息共享平台联合奖惩模块，相应的奖惩措施对接市级相应部门，由部门在行政审批、行政服务中实施，实现联合奖惩系统自动化处理。

配置原则，备忘录的奖惩措施能够明确对应部门的，配置到对应部门，没有对应部门的暂不配置，奖惩措施与部门对应关系不明确的，暂不配置。配置工作将分批进行，首批配置6个备忘录。

市级各部门要密切关注各备忘录发起部委、配合部委对备忘录的调整情况，对修改的内容要及时报告市金融办（市信用办），市金融办（市信用办）要对备忘录更新、修改的内容重新配置到市公共信用信息联合奖惩系统。

二、通过市政务服务中心政务审批系统实施奖惩

市公共信用信息平台将与市政务服务中心行政审批系统进行联合奖惩数据对接，将备忘录的奖惩措施信息推送到审批系统，进入市政务服务中心审批大厅的部门在行政审批和服务过程中，根据系统自动提示的信息查看具体奖惩措施内容，实施相应的激励和惩戒，并将结果按要求填报反馈至市公共信用信息平台。没有进入市政务服务中心审批大厅的部门，在行政审批和服务过程中，应通过市公共信用信息平台查询审批对象的信用信息状况，对照备忘录中本部门应采取的奖惩措施实施相应奖惩，并将实施结果反馈至市公共信用信息共享平台。

三、加强政务审批信息化建设工作

根据行政审批制度改革和政务信息整合的相关要求，我市没有使用政务审批系统进行政务审批的单位，要加强信息化建设，尽早使用政务审批系统开展行政审批、行政服务工作，有利于更好地推进信用联合奖惩措施的实施。

四、加强协作配合

市政务服务中心、市金融办要加强协作和配合，做好系统技术对接，确保每个备忘录的联合惩戒措施配置到位、实施顺畅、反馈及时、系统运行安全。各单位要按照信用“红黑名单”报送的要求，及时将本单位产生的信用“红黑名单”共享到市公共信用信息共享平台；要加强本单位内部的协调配合，制定实施细则和操作流程，确保各项奖惩措施的落实。要与市金融办、市政务服务中心密切合作，协调解决联合奖惩合作备忘录（第一批）实施过程中的具体问题。
