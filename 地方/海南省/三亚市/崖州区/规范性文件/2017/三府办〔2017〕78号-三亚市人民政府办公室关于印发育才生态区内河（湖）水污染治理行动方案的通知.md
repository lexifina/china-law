# 三亚市人民政府办公室关于印发育才生态区内河（湖）水污染治理行动方案的通知

三亚市人民政府办公室

关于印发育才生态区内河（湖）水污染治理

行动方案的通知

育才生态区管委会，市政府各有关单位：

《育才生态区内河（湖）水污染治理行动方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年3月22日

（此件主动公开）

育才生态区内河（湖）水污染治理行动方案

国务院《水污染防治行动计划》提出，“系统推进水污染防治、水生态保护和水资源管理”，“到2020年，全国水环境质量得到阶段性改善”。《海南省城镇内河（湖）水污染治理三年行动方案》提出，“到2018年，全省城镇内河及流经城镇河段消除劣V类水体，力争达到Ⅳ类及以上水质，内湖消除劣V类水体，实现城镇建成区基本消除黑臭水体”。《三亚市城镇内河（湖）水污染治理三年行动方案》提出,“到2018年，我市内河及流经我市河段消除劣Ⅴ类水体，力争达到Ⅳ类及以上水质，内湖全面消除劣Ⅴ类水体，实现我市建成区消除黑臭水体”。

为加大水污染治理力度，持续改善水环境质量，加快实现国家、省、市确定的内河（湖）水质管理目标，根据《海南省城镇内河（湖）水污染治理三年行动方案》《三亚市城镇内河（湖）水污染治理三年行动方案》精神，结合育才生态区实际，制定本行动方案。

一、总体要求

紧紧围绕“建设精品城市、打造幸福三亚”的工作主题，以改善水环境质量为核心，强化“源头控制、水陆统筹、标本兼治、综合治理”，系统实施本辖区水污染综合整治，全力打造“水清、水美、水畅”的水生态环境，为全面建设生态三亚提供强有力的水环境保障。

二、治理范围

对立才河的水污染问题进行综合治理。

三、工作目标

对内河（湖）水污染实施综合治污，到2018年，治理范围内的水体要消除劣Ⅴ类水体，达到Ⅳ类及以上水质，全面消除黑臭水体，水生态、水环境得到有效保护，水生态系统功能基本恢复，水环境质量总体改善明显，建成基本完备的水环境监管体系。

四、存在问题

经排查，立才河及那马山塘存在的主要水污染问题如下：

（一）污水排河。污水排河口18处，排放污水量估算约1670吨/天。主要是陆域居民生活污水、经营单位生产污水直排河道，是污染水体的主要来源。

（二）养殖污染。共2处，其中：养猪场1处，猪存栏约500头；养殖水塘1处，面积约30亩。养殖排污处理设施缺失，养殖废水直接或通过沟渠等途径排入河道，对水体造成严重危害。

（三）侵占河道。共6处，沿河建筑、生活垃圾共约370；成片水生杂草及藻类共约5000。沿河堆放建筑垃圾、生活、沟渠、生产垃圾，对河流造成渗透污染；水生植物挤占河道，滞缓流水，使河流富营养化，影响水生态循环系统。

（四）农村污水。辖区有37个自然村2027户居民的污水排放未得到有效处理，大量污水排入河道水系，成为主要的水污染源。

五、主要任务

（一）加强排污口整治。

加快整治污水排放口，杜绝污水直排河道，从源头上消除入河污染源，确保河湖水质稳定达标。

采取建设一体化污水处理站或人工湿地、截污纳管、封堵管口等方式治理居民生活污水排放口。（责任单位：育才生态区管委会、市水务局）。对于项目或生产经营单位的排污口，通过严格执法查处的措施予以整治。（责任单位：市生态环境保护局、育才生态区管委会）

（二）加强农业农村污染防治。

1.整治养殖污染。划定畜禽养殖禁、限养区，明确畜禽养殖区、限养区、禁养区范围，合理优化养殖布局。（责任单位：市农业局）。严禁养殖污水及粪污通过各种途径排入河道，依法取缔非法的畜禽养殖场及水产养殖场。新建、改建、扩建规模化畜禽养殖场要实施雨污分流、粪便污水资源化利用，配套建设粪便污水贮存、处理、利用设施。（责任单位：育才生态区管委会、市生态环境保护局）

2.控制种植面源污染。全面推广低毒、低残留农药，开展农作物病虫害绿色防控和统防统治。实行测土配方施肥，推广精准施肥技术和机具。落实高标准农田建设，建设生态沟渠、污水净化塘、地表径流集蓄池等设施，净化农田排水及地表径流，严禁农田退水直接排放地表水体。推进农家肥、畜禽粪便等有机肥料资源的综合利用。（责任单位：育才生态区管委会）

3.加快农村生活污水处理设施建设。结合美丽乡村建设和生态文明村镇建设，因地制宜地统筹推进辖区37个自然村的污水处理设施建设。对可纳入城镇污水收集管网的村庄，将其生活污水纳入城区污水收集管网进行统一处理；对不能纳入城镇污水收集管网的村庄，生活污水量大且易于统一收集的，建设雨污分流收集管网，采用污水治理厂（站）、一体化处理设施、集中式人工湿地等方式集中处理；对居住相对分散，生活污水难以统一收集的村庄，采用分散式人工湿地、氧化塘、稳定塘等方式分散处理。对原有处理设施存在进水口有缺陷、动力设施受损、管网破损、污水池内无水或水量较少等问题，采取设施（设备）维修或更换、管网修复、配套管网建设等措施恢复污水收集系统和湿地处理系统正常功能。（责任单位：市水务局、育才生态区管委会）

4.强化农村环境卫生综合整治。结合“巩卫创文”工作，大力开展河道、田洋、村庄等农村环境卫生整治，及时清理河道、沟渠、农田沿线的垃圾、淤泥、杂物及水生杂草。完善农村生活垃圾收运处理系统，推进垃圾“日产日清”，提高垃圾处理能力，确保日常保洁机制有效运转，禁止倾倒垃圾入河。（责任单位：育才生态区管委会）

（三）加强城镇生活污水治理。

1.加快污水处理厂（站）建设。根据本区经济社会发展要求，因地制宜建设污水处理厂（站），有效解决人口聚集区生活污水集中处理问题，切实提升生态区污水处理能力。（责任单位：市水务局）

2.加强管网配套及泵站建设。加快市政污水管道及污水提升泵站建设，实施雨污分流改造，切实提升全区污水收集能力，实现建成区范围内的污水应收尽收，接入污水处理厂（站）进行处理并达标排放。（责任单位：市住房城乡建设局）

（四）加强河道生态治理。

1.加大水环境治理。深入开展海棠区黑臭水体整治，2017年实现辖区全面消除黑臭；2018年实现辖区“内河湖治理监测断面”达到水质目标要求。在全面控源截污的基础上，近远措施结合，主要通过内源污染和生态修复等措施开展水体水环境综合治理，最终重建水体良性生态系统，使河段水质达标并实现长治久清。一是岸带修复，主要针对已有硬化河岸，通过恢复岸线和水体的自然净化功能，强化水体污染治理效果。二是生态净化，实现有效去除水体中有机物、氮、磷等污染物的目标，在综合考虑水质净化、景观提升与植物的气候适应性的基础上，采用人工湿地、生态浮岛、水生植物种植等方式。三是人工增氧，用于整治后水体水质的保持，主要采取跌水、喷泉、射流以及其他各类曝气形式有效提升水体的溶解氧水平，同时辅助提升水体流动性能。四是根据不同水体特点采用活水循环、清水补给、旁路治理等措施，其中：活水循环用于城市缓流河道水体或坑塘区域，主要通过设置提升泵站、水系合理连通等方式，实现水体流动；清水补给主要通过利用城市再生水、城市雨洪水、清洁地表水等作为城市水体的补充水源，增加水体的流动性和环境容量，充分发挥海绵城市建设作用，强化城市降雨径流的滞蓄和净化作用；旁路治理主要用于无法完全实现全面截污的重度黑臭水体、或无外源补水的封闭水体的水质净化，通过采取在水体周边区域设置适宜的污水处理设施，从污染最严重区段抽取河水，经处理净化后，排放至另一端，实现水体的净化和循环流动。（责任单位：市水务局、市生态环境保护局、育才生态区管委会）

2.大力开展河道治理。对问题河道进行清淤、疏浚、水环境治理的同时，实施两岸堤防建设及海绵化改造，对沿线的绿道系统、绿化、截污治污、运动休闲设施等生态建设，提升河道防洪、生态、景观等综合功能。（责任单位：育才生态区管委会、市水务局）

3.推进河湖水生态保护。严格保护大隆水库饮用水水源地保护区，保障辖区生态系统功能安全，促进自然生态系统良性循环。（责任单位：育才生态区管委会、市林业局、市生态环境保护局、市水务局）

（五）加强水环境监管，严惩违法排污。

1.严厉打击环境违法行为。严肃查处建设项目环境影响评价领域未批先建、边批边建、久试不验等违法违规行为，重点打击在建项目违规排放废水，以及单位、个人私设暗管或利用渗井、渗坑排放、倾倒污染物的行为；深入打击不正常使用水污染物治理设施，或者未经批准拆除、闲置水污染物治理设施等环境违法行为。（责任单位：市生态环境保护局）

2.落实排污排水许可制度。依法核发排污、排水许可证。严格排污许可管理，排污单位应依法申领排污许可证并按照规定排放污染物。将污染物排放种类、浓度、总量、排放去向等纳入许可证管理范围，禁止无证排污或不按许可证规定排污；强化污染源现场环境监察，将企业持证排污情况纳入日常现场监察内容。

（责任单位：市生态环境保护局、育才生态区管委会）。城镇排水设施覆盖范围内的排水用户应按照要求申请排水许可证，将符合标准的污水排入城镇排水设施，禁止无证排水或不按许可规定排水。对车辆清洗点、车辆修理厂、餐饮服务、垃圾收集点和中转站、豆制品等食品加工点落实污染预处理设施建设与完善，严禁将污水排入雨水管网。（责任单位：市住房城乡建设局、育才生态区管委会）

3.严管占用河道违规违法行为。严厉打击破坏河道、侵占河道、倾倒河道垃圾的违法行为，依法拆除沿河违章建筑物、构筑物，全面清除违规侵占河道、妨碍流水的各类市政设施和施工围堰，真正做到让绿于民、让路于民、让景于民。（责任单位：育才生态区管委会）

4.完善水环境水质监测体系。加大水质监测力度，及时、准确地掌握辖区水体水环境质量现状及变化情况，为水污染治理提供科学依据。（责任单位：市生态环境保护局）

注：以上责任单位中排第一位的为牵头单位。

六、保障措施

（一）强化组织领导。建立以育才生态区管委会主要负责人为组长的内河（湖）治理工作机构，制定落实辖区“一河（湖）一案”水污染防治方案，落实环境保护监管“一岗双责”，抓好任务分解、责任落实，组织辖区水污染治理工作，确保按时完成河流断面达标治理任务。

（二）严格落实“河长制”。建立水污染监管全覆盖的“河（段）长制”管理体系。河长要落实工作责任，督导下级河段长和相关部门履行职责，协调河流保护与经济社会发展的矛盾、上下游之间的纠纷，牵头组织整治非法排污、面源污染、采砂、侵占河道等突出问题，确保辖区河湖健康安全。组织开展辖区黑臭水体、养殖排污、管网排查、农村污水等污染源现状调查，深入查找各类水污染问题，针对性地研究制定并组织实施水污染治理工作。健全河道网格巡查、信息报告、应急处置、督查督办、考核激励等工作机制，建立河（湖）水体水污染防治长效机制。

（三）强化督导落实。辖区河长、育才生态区管委会督查部门要定期督促检查水污染防治计划的实施。育才生态区管委会要建立水污染问题日常巡查工作机制，落实本辖区水污染问题的巡查督办以及问责、通报制度。市政府督查议案室联合市水务局、市生态环境保护局以及育才生态区管委会相关部门组成督查组，定期督导落实水污染治理工作，督察和巩固治污成效。督查组办公室设在三亚市水务局。育才生态区管委会及相关市级责任单位每月将内河（湖）治理工作进展情况报送督查组办公室，由市政府督查议案室按月通报督查情况。

（四）强化资金保障。各级财政要加大对水污染治理工作的经费投入、项目投资。市发改部门要积极推行水污染治理项目的PPP投资模式，保障治污项目的顺利实施。

（五）强化协调联动。辖区流域上下游各乡村之间和市、管委会各部门之间要加强协调配合，对重要水污染问题实施联合监测、联合执法、应急联动、信息共享。

（六）强化社会监督。育才生态区管委会要健全举报制度，支持公众监督、举报污染水环境行为。积极响应“12345”政府热线投诉机制，各单位要限期处置群众举报投诉的环境问题。加强舆论引导监督和水环境法规宣传，提升人民群众的水环境保护意识和责任意识。
