# 三亚市人民政府办公室关于三亚市北部山区饮水安全工程（原水工程）临时租地补偿标准的通知

三亚市人民政府办公室

关于三亚市北部山区饮水安全工程（原水工程）临时租地补偿标准的通知

天涯区人民政府：

三亚市北部山区饮水安全工程（原水工程）是解决天涯区北部山区、育才生态区居民长期饮用不合格地下水，支持该区域发展生态新农村，实现农旅产业一体，达到省政府扶贫攻坚计划提出的农村自来水化的目标要求，实施精确扶贫，全面建成小康社会的重要农村基础设施。为确保该工程按时保持顺利完成，现就有关问题通知如下：

一、该项目土地调查有关事项按《三亚市人民政府办公室关于三亚市北部山区饮水安全工程（原水工程）项目土地调查有关事项的通知》（三府〔2016〕332号）有关规定执行。

二、该项目总占地面积279.01亩，其中永久220.69亩（含河床61.84亩），临时58.32亩，临时征地租金按1.2万元/亩年的标准予以补偿两年，青苗补偿按5万元/亩的标准予以包干属地区政府补偿，地面建筑物等补偿标准按《三亚市人民政府关于印发〈三亚市集体土地征收补偿安置管理规定（2013年修订）〉的通知》（三府〔2013〕43号）有关规定执行。

三、各有关单位要做好群众思想工作，教育群众顾全大局，服从工程建设需要，积极配合做好各项工作。

三亚市人民政府办公室

2017年4月10日
