# 三亚市人民政府办公室关于印发成立海南省环岛旅游公路陵水土福湾至三亚海棠湾通道工程推进小组的通知

三亚市人民政府办公室

关于印发成立海南省环岛旅游公路陵水土福湾至三亚海棠湾通道工程推进小组的通知

各区人民政府，育才生态区管委会，市政府直属各单位：

为加快推进海南省环岛旅游公路陵水土福湾至三亚海棠湾通道工程项目建设，明晰责任、明确任务，根据《三亚市人民政府市长办公会议纪要》（第129期）精神，决定成立海南省环岛旅游公路陵水土福湾至三亚海棠湾通道工程推进小组。

工程推进小组下设办公室，负责对外联络和上传下达，综合协调各部门开展工作，由市交通运输局局长吴海峰兼任办公室主任。

二、工作目标

陵水土福湾至三亚海棠湾通道工程作为海南省环岛旅游公路的重要组成部分，项目的建设对加强我市与陵水、保亭、五指山等周边市县旅游交通的互联互通、完善“大三亚旅游经济圈”路网结构、带动区域经济发展具有重大意义。各部门要有高度的历史责任感、创新思维和理念，各负其责、勇于担当、主动作为、交叉跟进，促使项目早日建成。

三、工作要求

1．工作小组各成员部门要强化职责分工，通力合作，依法按时完成各项工作，不得影响项目推进。

2．各成员部门要创造性地开展工作，积极协作，解决工程推进过程中出现的各项问题。

3．要主动对接，保证信息及时畅通，有问题及时请示汇报相关领导，以有效组织各项工作。

4．各成员部门提前计划，高效组织服务工作。
