# 三亚市人民政府办公室关于印发2018年三亚市引进“银发精英”教育人才工作实施方案的通知

三亚市人民政府办公室

关于印发2018年三亚市引进“银发精英”

教育人才工作实施方案的通知

各区人民政府，育才生态区管委会，市政府各有关单位：

《2018年三亚市引进“银发精英”教育人才工作实施方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2018年8月22日

（此件主动公开）

2018年三亚市引进“银发精英”教育人才

工作实施方案

为深入贯彻落实习近平总书记在庆祝海南建省办经济特区30周年大会上的重要讲话和《中共中央国务院关于支持海南全面深化改革开放的指导意见》（中发〔2018〕12号）精神，按照《百万人才进海南行动计划（2018-2025年）》要求，根据《海南省教育厅关于〈利用“候鸟型”教育人才提升海南省基础教育质量试点工作方案（试行）〉的通知》《中共三亚市委办公室 三亚市人民政府办公室关于印发三亚市加强和改进“候鸟型”人才工作实施方案的通知》《三亚市落实“百万人才进海南行动计划”实施方案（2018-2025年）》和三亚市“双十行动”教育提升工程确定的工作任务，结合我市实际，制定本方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实习近平总书记在庆祝海南建省办经济特区30周年大会上的重要讲话和《中共中央 国务院关于支持海南全面深化改革开放的指导意见》精神，按照省、市第七次党代会总体部署，围绕海南全岛建设自由贸易试验区，逐步探索、稳步推进中国特色自由贸易港建设，营造全社会关心教育、支持教育的良好氛围，以用好“银发精英”教育人才为抓手，吸引“银发精英”教育人才为我市教育发展贡献才智、经验和力量，通过示范引领作用，打造一支师德高尚、业务过硬、乐于奉献的教师队伍。

二、工作目标

2018-2020年期间，是实施百万人才进海南的大好时机，实施“银发精英”汇聚计划，主动对接国内发达省市教育机构，采用退休返聘等方式吸引大师级人才及其他高层次人才到三亚支教，并对汇聚我省的“银发精英” 教育人才进行充分挖掘， 建立我市“银发精英”教育人才信息库，引进一批相对稳定的专家顾问团队或素质优良，乐于奉献的“银发精英”退休教师、教育专家。通过试点，逐步积累利用“银发精英”教育人才提高教育质量的经验和范例，待时机成熟后向全市中小学校铺开。

2018年拟引进12名退休教师及1个顾问团，其中海南中学三亚学校3名（语文、历史、物理各1名）、市第四中学3名（语文、数学、英语各1名）、西南大学三亚中学3名（语文、数学、化学各1名）、市第一中学3名（语文、数学、英语各1名）。顾问团以“专家顾问团”形式组建，由10人组成，其中区域教育管理专家1人（团长）、研训专家1人，德育专家1人，艺体专家1人、学科专家6人（语文、数学、英语、物理、化学、历史专业优先考虑），主要负责市直属学校的教育教学指导工作。

三、引进程序

（一）人才招募 在南方人才网、海南省“候鸟”教育人才信息网、市政府、市教育局网站和三亚日报等宣传渠道上发布信息，向社会公开发布公告或通过省教育学会推荐，建立健全“银发精英”教育人才信息资源库，招募优秀“银发精英”教育人才。

（二）审查和面试 市教育局委托专家对“银发精英”教育人才进行资格审查和面试，符合条件的人员在市教育局网站公示5个工作日，公示无异议者，由市教育局统一组织体检。经综合考量后由三亚市引进“银发精英”教育人才提升教育质量工作领导小组确定聘用人选。引进人才应聘时应保证所提交的信息资料真实有效，如发现弄虚作假者，一经核实立即取消应聘资格。

（三）签订聘用合同 学校与确定聘用的“银发精英”教育人才签订聘用合同，实行一学期一签。岗位职责、工作时间和劳动报酬等事项依照本方案及相关的规定执行。

四、资格条件

（一）应聘人员应具备的基本条件

1.原则上年龄不超过65周岁，身体健康，品德高尚，思维敏捷，无不良记录，能胜任本职工作。

2.有多年一线教育教学经历，经验丰富，威望较高，成果得到社会认可，在一定范围内得到有效推广。

3.具备副高级教师（含）以上专业技术资格。

（二）除以上基本条件外，下列岗位还应满足如下相应要求

1.研训专家：曾在市县级以上（含市县）教育教学研究培训部门有不少于5年的管理经历，有较突出业绩的教学专家；

2.德育专家：曾在市县级以上（含市县）优质学校从事学校德育管理工作，有成功的实践案例的优秀德育管理干部或教研员；

3.艺体专家：曾在市县级以上（含市县）优质学校从事学校艺体教育工作，有成功实践案例的优秀教师或教研员。

五、工作时间和内容

（一）退休教师

聘用到各学校的“银发精英”退休教师必须满足一学期全职工作的要求（其中试用期1个月），无正当理由，不得随意变更。

主要工作内容：

1.引进先进教育理念和管理方法，协助学校建立稳定的教育教学秩序，优化学校的文化环境，推动学生学业水平的提高。

2.根据学校实际情况安排工作，以师徒结对方式指导青年教师，参加并指导学校的教研和集体备课活动，并通过集体备课、举办讲座、开设公开课等多种形式，帮助当地教师提高教学水平、业务能力。

3.结合中、高考实际，提出有效的指导意见和建议，协助做好学生的心理辅导工作。

4.配合市教育研究培训院开展教研培训、送教下乡或定点帮扶工作。

5.工作方式：退休教师必须在一线工作，示范培养一个班级。

（二）顾问团队

“银发精英”教育人才顾问团队每个学期工作期限至少为3个月（含）以上（其中试用期1个月），无正当理由，不得随意变更。

主要工作内容：

1.引进先进教育理念和管理方法，协助学校建立稳定的教育教学秩序，优化学校的文化环境，推动学生学业水平的提高。

2.工作方式：至少4名专家组成一个顾问小组，分别以1-2所学校为基地，顾问团统筹主要工作，通过实地调研，结合基础教育质量监测结果，制定质量提升方案，经市教育局同意后，指导工作实施。

六、福利待遇

（一）工资待遇参照我市正（副）高级退休教师测评工资标准执行，其中：正高级职称 12000 元/月（试用期11000元/月）;副高级职称 10000 元/月（试用期9000元/月）。

（二）对有住房需求的“银发精英”教育人才，市政府通过安排人才周转房或公租房的形式予以解决；确因周转房或公租房紧缺，市政府不能提供或本人自愿不使用的，可以以货币形式享受住房补贴。1. 正高级职称，住房补贴标准为4000元/月；2. 副高级职称，住房补贴标准为3000元/月。

（三）市内交通、工作误餐等方面执行本地政策, 异地就医结算按人社部相关规定执行。被聘用人员连续服务时间超过3个月的，夫妻双方每年往返一次机票按经济舱标准实报实销。

（四）用人单位要为“银发精英”教育人才创造良好的工作和生活条件，建立规范的劳务关系，明确双方的权力、责任及其他需要约定的事项，鼓励用人单位结合实际为“银发精英”人才购买医疗、意外伤害等保险，充分保障“银发精英”人才在服务期间的合法权益。

七、考核和监督

（一）“银发精英”教育人才的人事关系、档案、户籍、社保等关系保留在原单位，我市对当地人事、教育行政部门评定的专业技术资格予以认可。

（二）“银发精英”教育人才在我市教育系统工作期间应按照合同履行职责、自觉遵守法律法规、服从学校的管理，遵守教师职业道德规范和校纪校规，尽职尽责，主动做好各项工作，充分利用先进的教学理念、教学方法和丰富的教学经验，帮助当地教师提高教学水平和业务能力。

（三）对不服从领导，不认真履行工作职责的要严肃批评，情节严重者报教育行政主管部门审定后予以解聘，列入不良信用记录，其工作经历不予认可。

（四）个人身体原因不能坚持工作或请假超过十五天的，需经教育行政主管部门同意，严禁顶替、挂名等弄虚作假行为。一经核实，将追究相关领导及责任人员的责任。

（二）明确责任分工

市委组织部负责政策指导；市人力资源社会保障局负责对拟聘用退休教师专业资格进行确认；市财政局负责保障“银发精英”教育人才工作经费及将聘用退休教师所需经费列入年度预算予以保障；市住房城乡建设局负责提供相关周转房或公租房；市教育局牵头负责聘用工作的组织实施，做好综合协调工作，制定年度聘用计划。各职能部门要高度重视，密切配合，在人力、物力和财力等方面提供支持，形成合力，为引进的“银发精英”教育人才开通绿色通道。

各区政府（育才生态区管委会）可根据各区实际情况，结合相关职能部门意见，制定各区聘用计划，自行引进“银发精英”教育人才并保障相应费用。

（三）定期组织交流

建立导向明确、激励约束并重的评价标准和跟踪督导机制，实施动态监测，每学期结束之后由市教育局对引进的“银发精英”人才的教育教学工作进行评价，并组织召开由试点单位和相关部门参与的“银发精英”人才工作评价交流会，及时反馈评价结果和工作中存在的问题及相关建议。
