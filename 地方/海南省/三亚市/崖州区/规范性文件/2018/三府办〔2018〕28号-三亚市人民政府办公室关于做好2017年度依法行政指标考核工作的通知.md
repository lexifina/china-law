# 三亚市人民政府办公室关于做好2017年度依法行政指标考核工作的通知

三亚市人民政府办公室

关于做好2017年度依法行政指标考核工作的通知

各区人民政府，育才生态区管委会，市政府直属各部门：

根据《三亚市人民政府依法行政考核办法》（三府〔2010〕8号）的要求，为做好我市2017年度依法行政考核工作，更好地迎接省政府依法行政考核工作组的考核，现就关于开展我市2017年度依法行政指标考核工作的相关事项通知如下：

一、考核对象

吉阳区、天涯区、崖州区、海棠区、育才生态区管委会、市科技工业信息化局、市人力资源和社会保障局、市民政局、市民族宗教事务委员会、市文化广电出版体育局、市卫生和计划生育委、市教育局、市财政局、市审计局、市统计局、市商务会展局、市公安局、市公安局交警支队、市安全生产监督管理局、市发展改革委、市交通运输局、市农业局、市林业局、市水务局、市住房城乡建设局、市园林环卫局、市综合行政执法局、市国土资源局、市生态环境保护局、市海洋与渔业局、市旅游委、市规划委。

二、考核组组成人员

组 长：鲍 剑（市委常委、市政府常务副市长）

副组长：李武军（市政府副秘书长）

关 平（市法制办主任）

成 员：林日雄（市统计局副局长）

吴清蓉（市政务中心副主任）

市依法行政指标考核工作领导小组办公室设在市法制办，具体负责依法行政考核的组织、协调工作。办公室成员分别从市法制办、市统计局、市政务中心等依法行政考核领导小组的成员单位中抽调。

三、考核内容

具体的考核指标详见附件1《三亚市政府直属部门2017年度依法行政考核指标自评表》和附件2《2017年度各区政府、管委会依法行政考核自评表》。

四、考核方式

本次考核主要采取审阅年度报告、听取工作汇报、查阅案卷和文件资料并评分。

五、考核步骤

（一）第一阶段：自查自评阶段（2018年1月31日至2018年2月9日）。被考核对象要认真围绕考核内容开展自查自评工作。

（二）第二阶段：考核评议阶段（2018年2月10日至2018年2月14日）。市依法行政考核领导小组办公室组织考核组，对被考核对象进行考评。

（三）第三阶段：综合评定阶段（2018年2月22日至2018年2月28日）。市依法行政考核领导小组办公室将考核情况进行综合评价，并报市依法行政领导小组审定。

六、有关要求

（一）高度重视，加强领导。各区人民政府、市直属各行政执法单位要高度重视，切实加强自查自评工作的组织领导，要认真总结2017年度依法行政工作取得的成效，反思存在的问题，并以考核为契机，进一步提升依法行政的能力和水平。

（二）精心组织，严格要求。各区人民政府，市政府直属各部门要紧密结合自身实际，认真对照法定职责，深入做好自查自评，按照本通知要求的时间向市政府报送有关自查自评材料。要主动配合做好考核工作，认真审核报送的考核材料和有关数据，确保真实准确。

（三）各单位请于2018年2月9日前将本单位2017年度依法行政自查自评报告、指标考核表、行政执法案件统计表、行政执法人员行政执法评议考核表以及与依法行政考核有关的材料报市法制办（联系人：黄德福，联系电话：88278075）。
