# 三亚市人民政府办公室关于2018年第一次政府网站检测情况的通报

三亚市人民政府办公室

关于2018年第一次政府网站检测情况的通报

各相关单位：

根据《国务院办公厅秘书局关于做好政府网站季度抽查工作的通知》（国办秘函〔2016〕48号）要求和《国务院办公厅关于开展第一次全国政府网站普查的通知》（国办发〔2015〕15号）确定的检查标准，2018年3月1日—3月21日，市政府办公室对全市纳入普查范围的网站进行了检测。现将有关情况通报如下：

一、总体情况

（一）网站检测情况。此次对我市正在运行的21个政府部门网站进行了检测，合格率为100%。其中网站得分在90分以上的有3个，得分在80-89分区间的有8个，得分在70-79分区间的有6个，得分在60-69分区间的有4个。

（二）办理网站纠错留言情况。2018年1月1日至2018年3月21日，网民通过“我为政府网站找错”平台反映我市政府网站问题9条，留言按期办结率达100%。

（三）政府网站工作年度报表公开情况。按照《国务院办公厅关于做好政府网站年度报表发布工作的通知》（国办函〔2018〕12号）要求，大部分政府网站主管单位按规范、按时限公开了《政府网站工作年度报表》，截至2018年1月31日，全市公开率为85.7%。

二、主要问题

此次网站检测从检查结果看，总体情况较好，没有不合格网站，但少数单位存在政府信息公开专栏内容保障不到位、网站安全防护水平较低等问题。

（一）网站安全防护水平较低。“三亚市农业局”网站安全防护系统脆弱，缺乏防篡改、防病毒、防攻击、防瘫痪、防劫持、防泄密能力。网站未建立安全监测预警和应急处置机制，易因错误解析指向、DNS发生故障或遭受攻击、网站程序被篡改等原因导致网站无法访问。

（二）政府信息公开专栏内容保障不到位。抽查发现，政府信息公开专栏内“三亚市综合行政执法局”“三亚市科技工业信息化局”多个栏目长期不更新；“三亚市发展和改革委员会”“三亚市财政局”“三亚市监察委员会”“三亚市国土资源局”“三亚市交通运输局”“三亚市商务会展局”未按要求公开《政府信息公开年度报告》。

（三）部分单位机构概况信息未公开。“海棠区人民政府”“崖州区人民政府”“三亚市现代服务业产业园管理委员会”“育才生态区管理委员会”均未在政府信息公开专栏内公开机构职能、领导班子、内设机构、下属单位等信息。

三、下一步工作要求

（一）各单位要认真落实《海南省人民政府办公厅关于印发海南省政府网站管理办法的通知》（琼府办〔2017〕191号）相关要求，完善信息发布板块中概况信息、机构职能、负责人信息（包括姓名、照片、简历、主管或分管工作等）、政策文件、国务院信息转载、海南省要闻转载、政务动态、数据发布、数据开放等栏目。

（二）各单位要对照《海南省政府网站集约化建设审定表》，于2018年3月31日前完成迁移网站的数据迁移、域名及标识码注销等工作，严格杜绝“假整合”和随意下线。市政府办公室将通过全国政府网站信息报送系统对相关网站的整合迁移情况进行检查，检查结果将列入下一季度政府网站检测内容。

（三）各单位要高度重视政府信息公开工作，按照《政府信息公开条例》相关规定，进一步强化政府信息公开内容保障工作机制，避免栏目长期不更新、空白栏目等现象出现。

（四）请以上未按要求公开本单位政府信息公开年度报告和机构概况（机构职能、领导班子、内设机构、下属单位）的单位，于2018年3月27日前按要求上传相关信息。
