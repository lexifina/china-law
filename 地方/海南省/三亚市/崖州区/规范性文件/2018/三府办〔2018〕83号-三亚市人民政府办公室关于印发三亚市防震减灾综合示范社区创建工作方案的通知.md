# 三亚市人民政府办公室关于印发三亚市防震减灾综合示范社区创建工作方案的通知

三亚市人民政府办公室

关于印发三亚市防震减灾综合示范社区

创建工作方案的通知

各区人民政府，育才生态区管委会，市地震局：

《三亚市防震减灾综合示范社区创建工作方案》已经市政府同意，现印发给你们，请结合实际，认真抓好落实。

附件：三亚市防震减灾综合示范社区创建工作方案

三亚市人民政府办公室

2018年4月12日

（此件主动公开）

三亚市防震减灾综合示范社区创建工作方案

社区是社会管理的基本单元，是落实防震减灾各项措施的基层实施主体。根据《中国地震局关于印发地震安全示范社区管理暂行办法的通知》（中震防发〔2012〕33号）精神以及《三亚市“十三五”防震减灾规划》（三府办〔2016〕323号）的部署要求，决定在全市范围内开展防震减灾综合示范社区创建工作。方案如下：

一、指导思想

以党的十九大精神为指导，坚持预防为主的方针，充分发挥各级政府的主导作用，广泛动员社会力量参与创建工作，全面提升社区应对地震灾害的综合防御能力，为建设“美丽三亚”夯实防震减灾基础。

二、目标任务

作为《三亚市“十三五”防震减灾规划》重点项目，全市每年至少创建1个省级防震减灾综合示范社区，各区每年至少创建1个市级防震减灾综合示范社区。

三、创建标准

（一）工作保障。

1.成立防震减灾综合示范社区创建工作领导小组负责创建工作，全面组织开展防震减灾综合示范创建活动。

2.制定防震减灾综合示范社区创建工作方案。

3.制定符合社区实际、体现社区特色、切实可行的防震减灾示范创建工作计划。

4.有工作经费支持。

5.建立月报制度，定期上报创建工作进度。

6.建立信息网站公开制度，定期公开创建工作进度。

（二）基本消除地震安全隐患。

1.加强对新建民居的监督指导，开展对社区建筑物的抗震性能排查，力争社区内80%的建筑物基本采取符合当地地震烈度的抗震构造措施。

2.对辖区内可能因地震引起次生灾害的危险源、风险点建档，并采取有效措施清除，如清除不了，应建立定期排查和预警报告制度。

（三）防震减灾宣传。

1.社区结合现有资源组建一支防震减灾宣传队伍。

2.社区居民要做到家家户户都有防震减灾知识小册子。

3.利用社区现有公共活动场所或设施（图书馆、宣传栏、橱窗等）设置固定的防震减灾科普宣传栏，并定期更新防震减灾知识。

4.社区结合3.1《防震减灾法》颁布实施日、5.12全国防灾减灾日、7.28唐山大地震纪念日、国际减灾日等时机，采取设咨询点、发放宣传资料、播放电影、举办讲座等多种形式，每年举办至少2次以“地震基本知识、防震避险常识、自救互救技能”为主要内容的宣传教育活动，要求社区居民广泛参与。

（四）地震应急准备。

1.编制社区地震应急预案，每年开展地震应急疏散演练不少于1次。

2.利用绿地、广场和其他空地，以及达到抗震设防要求的场、馆，规划建设社区应急避险安置场所，划定紧急疏散通道，设置规范醒目的疏散路线图和指示标识牌。

3.有固定的物资储备室配备必要的应急物资，包括救援工具、帐篷、灭火器、话筒、照明设备、应急药品、矿泉水等。

4.建立社区居民联络卡制度。双面卡片包含家庭人员、性别、年龄、联系电话以及社区书记、主任和网格长的联系电话等信息。

5.家庭配备地震应急包（内含干粮、雨衣、手电、哨子、火柴、收音机、药品、绷带等），储备必要的逃生工具。

6.组建一支地震应急救援社区志愿者队伍，并定期开展培训和训练。

7.建立社区与邻近商场、商店的应急物资供应联动机制。

8.建立社区与周边医疗服务站的应急医疗救护联动机制。

9.建立社区与邻近公安机构的应急安全救助联动机制。

（五）群测群防工作。

1.配备一名防震减灾联络员。

2.建立联络员制度。联络员要定期与市、区防震减灾主管部门保持工作联系，平时履行日常工作职责，当遇有震情时，认真开展震情、灾情的搜集整理和上报等工作。

（六）档案管理。

建立包括文字、音像等档案信息在内的规范齐全、方便查阅的防震减灾工作档案，包括社区房屋建筑抗震设防情况、志愿者队伍、应急避难场所、地震应急预案、社区居民情况等内容。

四、进度安排

（一）制定方案。各区人民政府、育才生态区管委会结合当地实际，制定切实可行的实施方案。

（二）组织实施。各区人民政府、育才生态区管委会按实施方案组织实施，并于每年下半年，组织自评审核和推荐申报市级防震减灾综合示范社区。

五、申报与认定

（一）申报资格。

凡具备开展防震减灾综合示范社区创建活动条件的，均具有申报市级防震减灾综合示范社区的资格。

(二）申报条件。

按照本实施意见开展创建活动，并已达到标准要求的，均可申报。

（三）申报材料。

1.创建工作总结（内容包括社区的基本情况、创建活动中开展的主要工作和取得的成效等）；

2.三亚市防震减灾综合示范社区申报表（见附件）；

3.证明符合申报条件的有关材料（含文件、音像等资料）。

（四）申报程序。

每年10月底前，各区防震减灾主管部门负责对本行政区域内社区申报材料的核实，在确保材料的真实性和准确性后，作出推荐意见报市抗震救灾指挥部办公室（市地震局）。

(五）认定与命名

市抗震救灾指挥部负责对申报社区进行建成验收，对通过认定的社区进行命名及颁发“三亚市防震减灾综合示范社区”牌匾，视其条件推荐申报海南省或国家地震安全示范社区。防震减灾综合示范社区每年认定一次。挂牌后，每两年复核一次，经复核不合格的，撤销其称号并摘牌。

六、工作要求

（一）加强领导，齐抓共管。各区政府、育才生态区管委会要加强对防震减灾综合示范社区创建的组织领导，各级各部门要各司其职，密切配合，形成合力，确保示范创建的软、硬条件成熟。区防震减灾主管部门为防震减灾综合示范社区创建工作的第一责任单位，负责防震减灾综合示范社区创建的跟踪督导、沟通协调、初检验收等工作；社区居委会为防震减灾综合示范社区创建工作的具体实施主体，负责组织实施防震减灾综合示范社区的创建、资料收集汇总和申报等。

（二）广泛宣传，营造氛围。防震减灾综合示范社区创建需要社会各方面的支持和参与，各地要加大宣传力度，宣传创建防震减灾综合示范社区的重要意义，做到家喻户晓，充分调动各方参与创建的积极性，确保创建工作有序推进。

（三）加大投入，经费保障。创建防震减灾综合示范社区对推动全市防震减灾工作具有战略意义，所需经费应按照《三亚市“十三五”防震减灾规划》（三府办〔2016〕323号）安排纳入当地财政年度预算予以保证。

（四）防震减灾综合示范村的创建参照本实施意见执行。
