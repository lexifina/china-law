# 三亚市崖州区人民政府关于印发贯彻落实过“紧日子”要求压减一般性支出有关事项方案的通知

三亚市崖州区人民政府

关于印发贯彻落实过“紧日子”要求

压减一般性支出有关事项方案的通知

区各相关单位:

《关于贯彻落实过“紧日子”要求压减一般性支出有关事项的方案》已经区政府同意,现印发给你们,请认真贯彻执行。

三亚市崖州区人民政府

2019年5月22日

(此件主动公开)

关于贯彻落实过“紧日子”要求

压减一般性支出有关事项的方案

为贯彻落实党中央、国务院过“紧日子”要求,根据《中共海南省委办公厅海南省人民政府办公厅关于贯彻落实过“紧日子”要求压减一般性支出有关事项的通知》(琼厅〔2019〕26号)文件要求,结合我区实际,制定以下实施方案。

一、总体目标

为贯彻落实党中央、国务院过“紧日子”要求,根据《中共海南省委办公厅海南省人民政府办公厅关于贯彻落实过“紧日子”要求压减一般性支出有关事项的通知》(琼厅〔2019〕26号),切实做好压减一般性支出有关事项,确保实现压减目标。

二、任务分工及职责

(一)进一步压减一般性支出。全区各预算单位在年初预算压减基础上进一步加大压减力度,本次一般性支出按压减比例5.5%进行压减,压减的资金用于重点支出。(牵头单位:区财政局,配合单位:区直各预算单位,完成时限:2019年5月底前)

(二)进一步压减“三公”经费支出。在2019年各预算单位“三公”经费年初预算限额的基础上,本次分别按照3.5%的比例压减“三公”经费支出,压减范围为公务接待费、因公出国(境)费、公务用车运行维护和购置费。(牵头单位:区财政局,配合单位:区直各预算单位,完成时限:2019年5月底前)

(三)强化公务接待经费管理。按照文件规定,严格遵守公务接待标准、接待事项范围、接待人员数量,确保实现压减目标。(牵头单位:区政府办、区委办,配合单位:区直各预算单位,完成时限:2019年5月底前)

(四)严格因公出国(境)管理。严格遵守文件规定,从严控制因公出国(境)人员数量、出国天数等方式减少因公出国(境)经费支出,确保实现压减目标。(牵头单位:区人社局,配合单位:区直各预算单位,完成时限:2019年5月底前)

(五)细化公务用车管理。通过规范车辆维修标准、提高车辆使用效率、合理控制购车等方式减少公务用车运行和购置成本,确保实现压减目标。(牵头单位:区发展改革委,配合单位:区直各预算单位,完成时限:2019年5月底前)

(六)严格预算执行。年度预算执行,原则上不追加临时预算。全区各级预算单位一律不予追加办公、会议、培训、维修维护、公务接待、因公出国(境)、公务用车运行维护和购置等一般性支出预算,不得调剂现有项目预算用于增加一般性支出。(牵头单位:区财政局,配合单位:区直各预算单位,完成时限:长期)

(七)提高资金使用效率。加大存量资金盘活力度,由区财政部门牵头,区级各预算单位负责,对包括实有账户在内的各项存量资金清理工作、对没有及时支出的资金定期进行盘活,长期沉淀资金一律由区财政部门收回,统筹用于重点支出。(牵头单位:区财政局,配合单位:区直各预算单位,完成时限:2019年5月底前)

三、工作要求

(一)高度重视,精心组织。压减一般性支出是党中央、国务院的重要决策部署,区直属各预算单位请务必要高度重视,树立过“紧日子”思想,认真抓好贯彻落实。

(二)务实高效,确保质量。各单位参照本实施方案严格落实到位,积极发挥财政资金效益,对于压减比例低于5.5%的单位,我单位将在预算调整中直接压减,并在下一年度预算安排中减少安排一般性经费。

(三)领导负责,专人跟踪。压减一般性支出是党中央、国务院的重要决策部署,各单位一把手要扛起责任担当,并派专人跟踪,及时上报各单位工作落实情况。
