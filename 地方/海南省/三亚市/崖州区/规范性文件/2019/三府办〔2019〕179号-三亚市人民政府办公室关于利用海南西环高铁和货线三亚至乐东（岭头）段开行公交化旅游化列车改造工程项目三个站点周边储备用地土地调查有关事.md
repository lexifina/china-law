# 三亚市人民政府办公室关于利用海南西环高铁和货线三亚至乐东（岭头）段开行公交化旅游化列车改造工程项目三个站点周边储备用地土地调查有关事项的通知

三亚市人民政府办公室

关于利用海南西环高铁和货线三亚至乐东

（岭头）段开行公交化旅游化列车改造

工程项目三个站点周边储备用地

土地调查有关事项的通知

天涯区人民政府，崖州区人民政府，市政府各有关单位：

根据三亚市总体规划和项目建设需要，经市政府同意，对利用海南西环高铁和货线三亚至乐东（岭头）段开行公交化旅游化列车改造工程项目三个站点周边储备用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于天涯区和崖州区内，包含天涯海角站、红塘湾站和科技城站三个站点周边的储备用地，用地调查面积共约955393平方米（海南平面坐标系）。

（一）天涯海角站周边储备用地的用地调查面积约316435平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见利用海南西环高铁和货线三亚至乐东（岭头）段开行公交化旅游化改造项目三亚天涯海角站拟用地红线图。土地权属（海南平面坐标系）情况为天涯区文门村、马岭村和黑土村委会集体土地共约309255平方米，国家土地约516平方米，三亚城市投资建设有限公司国有土地约5477平方米，三亚市天涯镇中心学校国有土地约13平方米，三亚长丰海洋天然气供气有限公司国有土地约378平方米，粤海铁路有限责任公司国有土地约796平方米；土地利用现状（2000国家大地坐标系）为农用地约261964平方米（其中水田约101661平方米、旱地约87625平方米、果园约48365平方米、有林地约16102平方米、坑塘水面约1881平方米、设施农用地约6330平方米），建设用地约36150平方米（其中铁路用地约117平方米、公路用地约6042平方米、建制镇约4345平方米、村庄约4261平方米、采矿用地约10564平方米、风景名胜及特殊用地约10821平方米），其他草地约18552平方米；上述用地在《三亚市总体规划（空间类2015-2030）》（市“多规合一”）中规划性质为城镇建设用地、公路用地、其他设施用地、一般耕地、园地、林地等，涉及规划调整的由市自然资源和规划局纳入调整完善。

（二）红塘湾站周边储备用地的用地调查面积约148849平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见利用海南西环高铁和货线三亚至乐东（岭头）段开行公交化旅游化改造项目三亚红塘湾站拟用地红线图。土地权属（海南平面坐标系）情况为天涯区布甫村委会集体土地约103678平方米，天涯区红塘村委会集体土地约45171平方米；土地利用现状（2000国家大地坐标系）为农用地约147018平方米（其中水田约121022平方米、旱地约3386平方米、其他园地约1272平方米、有林地约5886平方米、农村道路约4934平方米、坑塘水面约10518平方米），建设用地约1943平方米（其中公路用地约407平方米、建制镇约968平方米、村庄约568平方米）；上述用地在《三亚市总体规划（空间类2015-2030）》（市“多规合一”）中规划性质为其他设施用地、公路用地、园地、林地等，涉及规划调整的由市自然资源和规划局纳入调整完善。

（三）科技城站周边储备用地的用地调查面积约490109平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见利用海南西环高铁和货线三亚至乐东（岭头）段开行公交化旅游化改造项目三亚科技城站拟用地红线图。土地权属（海南平面坐标系）情况为崖州区南山村、水南村和城东村委会集体土地共约155901平方米，三亚南滨投资有限公司（南滨农场）国有土地约327763平方米，海南农垦南繁产业集团有限公司国有土地约208平方米，国营南滨农场中学国有土地约831平方米，海南铁路总公司国有土地约5381平方米，粤海铁路有限责任公司国有土地约25平方米；土地利用现状（2000国家大地坐标系）为农用地约473470平方米（其中水田约128365平方米、旱地约152760平方米、果园约183739平方米、农村道路约5161平方米、设施农用地约3445平方米），建设用地约16858平方米（其中铁路用地约953平方米、建制镇约2829平方米、村庄约13076平方米）；上述用地在《三亚市总体规划（空间类2015-2030）》（市“多规合一”）中规划性质为城镇建设用地、公路用地、一般耕地、园地、林地等，涉及规划调整的由市自然资源和规划局纳入调整完善。

上述用地涉及的耕地在办理农用地转用时，从我市耕地占补平衡指标中统筹安排。待完成占补平衡任务后，由市交通运输局按要求提供用地报批材料，市自然资源和规划局将其列入当年新增建设用地指标并办理农转用及征收报批手续。

二、为做好该项土地调查工作，由天涯区政府和崖州区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市自然资源和规划局负责对集体土地范围内的征地工作进行指导；市住房和城乡建设局负责对国有土地上的房屋征收与补偿工作进行指导。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地和收回国营农场土地的征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行。收回其他国有土地的征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）等规定执行。

四、根据2010年6月26日原国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，天涯区政府和崖州区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认，向市自然资源和规划局出具履行征地前告知等程序的证明及土地权属确认意见（附件1）。待市政府批准征地后，征收土地公告和征地补偿安置方案公告可同步进行。

五、为进一步做好被征地农民养老保险工作，根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神，应在本通知下发后10个工作日内对项目征收农用地和享受缴费补贴人数等情况进行调查，组织村（居）小组填写《征地项目被征地农民基本情况调查表》（附件2），经村（居）委会、天涯区政府和崖州区政府逐级审核后，由天涯区政府和崖州区政府汇总填写《征地项目被征地农民基本情况乡镇调查汇总表》（附件3），并将上述两种表格报送市自然资源和规划局。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。天涯区政府、崖州区政府及各相关职能部门一定要提高依法用地意识，新的项目决不能产生违法用地。
