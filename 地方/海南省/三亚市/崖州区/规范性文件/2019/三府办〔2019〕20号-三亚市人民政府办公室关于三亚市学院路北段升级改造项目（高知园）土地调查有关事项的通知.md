# 三亚市人民政府办公室关于三亚市学院路北段升级改造项目（高知园）土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市学院路北段升级改造项目（高知园）土地调查有关事项的通知

吉阳区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对学院路北段升级改造项目（高知园）部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于吉阳区辖区内，用地调查面积约4079平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市住房城乡建设局出具的用地红线图（已在市规划委审核出具的用地红线范围内扣除已征收的用地及不符合我市多规合一成果的用地）。土地权属（海南平面坐标系）情况为：三亚市热带植物园国有土地约3795平方米、中国热带植物园国有土地约99平方米、植物园国有土地约185平方米；土地利用现状（2000国家大地坐标系）为农用地约3764平方米（其中旱地约244平方米、其他园地约3520平方米）、建设用地约316平方米（其中公路用地约150平方米、城市约63平方米、村庄约103平方米）；该项目用地在土地利用总体规划2014年调整完善（2000国家大地坐标系）中规划为园地约1平方米、公路用地约4079平方米；该项目用地在《三亚市总体规划（空间类2015-2030）》（市多规合一，2016年经省政府常务会审议通过）中均规划为公路用地。上述用地涉及的约244平方米耕地在办理农用地转用时，从我市耕地占补平衡指标中统筹安排。待完成占补平衡任务后，由吉阳区政府按要求提供《收回国有土地补偿协议书》等材料后，市国土资源局将按程序办理用地收回及农转用手续。吉阳区政府、各相关职能部门一定要提高依法用地意识，新的项目决不能产生违法用地。

二、为做好该项土地调查工作，由吉阳区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市住房城乡建设局、市国土资源局负责收回国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、收回国有土地的补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）、《国有土地上房屋征收与补偿条例》（国务院令第590号）等相关规定执行。

四、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
