# 三亚市人民政府办公室关于印发加快推动连锁便利店发展实施方案的通知

三亚市人民政府办公室

关于印发加快推动连锁便利店发展

实施方案的通知

各区人民政府，育才生态区管委会，市各有关单位：

《加快推动连锁便利店发展实施方案》已经七届市政府第77次常务会议审议通过，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2019年12月11日

（此件主动公开）

加快推动连锁便利店发展实施方案

便利店是以满足人民群众日常生活消费需求为主要目的的便民服务业态，对扩大消费、改善民生、促进就业、提高城市品质具有重要意义，优化连锁便利店营商环境，提高生活性服务业品质，加快国际旅游消费中心建设，制定本方案。

一、指导思想和工作原则

全面贯彻党的十九大精神，以习近平新时代中国特色社会主义思想为指导，深入学习贯彻习近平总书记“4.13”重要讲话、中央12号文件和《中国（海南）自由贸易试验区总体方案》精神，坚持积极促进与依法规范并重，不断满足人民群众日益增长的美好生活需要，为建设世界级滨海旅游城市和国际旅游消费中心提供有力支撑。

二、总体目标

通过实施本方案，本市连锁便利店营商环境得到明显改善，进一步扩大连锁便利店的数量和覆盖率。到2021年，连锁便利店数量达到200家左右，其中中心城区达到100家以上，基本实现中心城区社区、产业园区、重点景区、总部经济和中央商务区全覆盖，24小时便利店占比60%以上，实现空间布局更加合理，服务种类更加丰富，服务品质和水平进一步提升，市民游客生活消费更便利、更舒心、更放心。

三、主要任务

（一）优化拓展发展空间。各区政府、各管委会、市各有关部门要按照“十五分钟生活圈”的要求和基本便民商业配置比例，统筹利用城市空间，优先布局连锁便利店等生活性服务业网点。支持各区政府、各管委会、村（居）委会、各产权单位开放所属公共服务单位的空间资源，在学校、商业楼宇、度假酒店、公园、体育场馆、会展设施、停车（楼）场、汽车站、动车站、码头、地下空间等引入品牌连锁便利店等便民服务网点。（责任单位：市商务局、市住房城乡建设局、市委军民融合发展委员会办公室、各区人民政府、各管委会）

（二）加大扶持和招引工作。市商务局制定便利店发展规划，优先引进知名连锁便利店品牌尤其是知名外资品牌。加大对本地优质连锁便利店民营企业的扶持力度，鼓励国有企业通过合资、入股、铺面参股等方式建立便利店企业，有序引导企业升级管理，诚信经营，公平竞争，不断改进便民服务质量。对产值和税收达到总部企业标准的连锁便利店区域总店或结算中心，依照省市相关规定进行总部企业认定，落实相应扶持奖励政策。（责任单位：市商务局、市国资委、市供销合作社）

（三）加大资金、土地支持力度。支持连锁便利店企业新开店铺、新建或改造中央厨房、鲜食工厂等加工配送中心；鼓励连锁便利店应用物联网、大数据、云计算、人脸识别、智能结算等技术，开发和升级管理信息系统，提升供应链和销售端协同能力，加快线上线下融合发展，积极发展周边快速配送业务，提高运营效率。支持便利店企业使用新能源物流配送车辆，加大对连锁便利店企业门店节能改造项目的支持力度，鼓励企业更新使用节能设备设施和可降解包装材料，推动绿色环保流通体系建设。（责任单位：市商务局、市财政局、市科技工业信息化局、各区人民政府、各管委会）

（四）实行“一区一照”登记。市商务局根据连锁便利店的业态标准和经营服务规范，提出“一区一照”试点企业名录。连锁便利店企业在本市登记注册后可作为“总店”对所有分店进行统一管理。新设立分店时，“总店”向市市场监督管理部门提交合法有效的经营场所证明文件进行备案，可不再办理分店营业执照。企业应将“总店”的营业执照副本及分店的食品经营许可证置于该经营场所醒目位置。对试点企业实行动态管理，试点企业名录每季度更新一次。试点企业应签署诚信经营承诺书，加强内部管理，履行相关法律责任和义务。对检查发现问题的企业，约谈并责令其整改或取消其试点资格。（责任单位：市商务局、市市场监督管理局、各区人民政府、各管委会）

（五）创新许可监管模式。简化食品经营许可审批流程，实行“承诺审批制”的审批模式。连锁便利店企业可凭营业执照办理各分店食品经营许可，统一向市市场监督管理部门申请，提交备案文件及所要求的申报材料，并由该企业实际负责人签署经营许可承诺书，经市市场监督管理部门核对真实无误，即可发放食品经营许可证。连锁便利店申请食品制售类项目时，应设置食品处理区。允许连锁便利店内设立简易就餐区。（责任单位：市市场监督管理局、各区政府、各管委会）

（六）丰富搭载便民服务。依法支持对于连锁便利店开设洗衣代收、代收代缴公共事业费、快递代收等便民服务项目。推进便利店搭载零售图书、音像制品及报刊等业务。对搭载限价便民早餐或平价蔬菜零售等便民服务和开展扶贫产品销售的连锁便利店，自门店正式营业之日起，连续3年给予每月每平方米30元的财政租金补贴，每月最高补贴不超过1500元。（责任单位：市商务局、市委宣传部、市市场监督管理局、市发展改革委、各区人民政府、各管委会）

（七）从严把控商品质量。加强便利店所售商品质量监督管理，依法查处商品质量违法行为，督促经营者履行商品质量义务，保护消费者合法权益。落实“双随机、一公开”制度，建立随机抽查事项清单和“双随机”抽查机制，积极引导便利店做好年报信息公示，探索建立跨部门联合检查机制。（责任单位：市市场监督管理局、市商务局、各区人民政府、各管委会）

（八）加强信用管理。采取守信激励和失信惩戒措施，促使市场主体强化主体责任，在安全生产、质量管理、营销宣传、售后服务、信息公示等各方面切实履行法定义务，对失信企业开展联合惩戒。引导连锁便利店企业主动接受社会监督，充分发挥行业协会等社会组织的作用，开展行业规范宣传，倡导行业自律。（责任单位：市商务局、市市场监督管理局、各区人民政府、各管委会）

（九）落实企业主体责任。引导连锁便利店企业加强内部管理，积极落实食品安全等主体责任。总部应对各门店实行统一配送，对各门店的经营行为进行统一管理，按照要求进行巡查和自检，各门店应保留总部的配送记录、巡查记录等资料备查。（责任单位：市商务局、市市场监督管理局、各区人民政府、各管委会）

四、工作要求

（一）明确实施范围。本方案所提的连锁便利店企业，是指实行“统一品牌、统一标准、统一管理、统一采购、统一配送”的运营管理模式，并在本市行政区域内已有5个或以上直营门店的连锁便利店。进入“一区一照”登记的试点企业，应在本市行政区域内已有10个或以上直营门店。

（二）部门协同推动。建立促进连锁便利店发展的部门协调机制，统筹推进各项工作任务。市商务局、市市场监督管理局、市财政局、市应急管理局、各区政府、各管委会要按照职责，做好顶层设计，分工负责，从机制层面推进连锁便利店营商环境的改善。

（三）加强宣传引导。通过多种途径、采取多种方式宣传连锁便利店等便民服务的发展情况，宣传典型经验和做法，鼓励连锁便利店企业开发APP、微信公众号、小程序等平台，方便消费者知晓便利店位置和服务内容，营造良好氛围和舆论监督环境。
