# 三亚市人民政府办公室关于进一步做好政府公报工作的通知

三亚市人民政府办公室

关于进一步做好政府公报工作的通知

各区人民政府，育才生态区管委会，市政府直属各部门：

政府公报是发布政府行政法规、规章和政令的权威载体，是推行政务公开、推进法治政府建设的重要平台。按照《海南省人民政府办公厅关于进一步做好政府公报工作的通知》（琼办发〔2018〕35号）要求，现就做好《三亚市人民政府公报》（以下简称《公报》）有关事项通知如下：

一、刊登要求。《公报》是由市政府办公室主办的全市公开发行的月刊，主要刊登市政府、市政府办公室制发的主动公开文件以及市政府有关部门出台的主动公开文件和重要政策解读。有关部门应于每月第一个工作周，将本部门上个月制发的主动公开文件和重要政策解读报送市政府办公室，供《公报》刊登。各区政府可结合实际探索创办政府公报，市政府有关部门不办政府公报。

二、信息化建设。在三亚市政府门户网站首页设立政府公报专栏，提供政府公报电子版目录导航和内容检索等服务。将公报发行版在三亚政务上发布，电子版与纸质版同步发行，清样定稿后先行发布电子版。积极配合上级有关部门不断完善政府公报数据库，同时充分利用电子签名、电子水印等防护手段，确保电子版不被篡改。

三、发行管理。通过网址、微信、微博等方式发布公报，以便社会公众查阅。《公报》纸质版的发行主要面向基层、面向群众、面向窗口单位，应当覆盖本地区档案馆、公共图书馆、书店、政务（行政）服务大厅、车站、码头、主要旅游景区景点等。《公报》纸质版实行免费赠阅。

各区政府、育才生态区管委会、市政府有关部门要安排专人负责、主动配合做好《公报》的发行管理工作，负责收集社会群众对《公报》发行的意见和建议，提供受赠单位名称、地址和需要《公报》数量及时报市政府办公室（联系电话：88272364），确保《公报》纸质版及时准确无误地投递到位。

四、组织领导。市政府办公室是《公报》的主办部门。成立由市政府秘书长、市政府办公室主任为组长，分管《公报》编辑工作的领导为副组长的《公报》编辑领导小组，领导小组编辑部设在市政府办公室文秘科，编辑部具体负责《公报》的内容收集、排版、校对、印刷和发行等工作。市政府办公室将继续加强《公报》发行的督促检查。
