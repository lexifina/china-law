# 三亚市人民政府办公室关于印发“三亚记忆”老照片征集活动方案的通知

三亚市人民政府办公室关于印发

“三亚记忆”老照片征集活动方案的通知

各区人民政府（育才生态区管委会），市各有关单位：

现将《“三亚记忆”老照片征集活动方案》印发你们，请按要求认真组织实施。

三亚市人民政府办公室

2019年7月11日

（此件主动公开）

“三亚记忆”老照片征集活动方案

为挖掘我市人文资源，追忆城乡原貌，发挥档案真实记录社会活动，反映人类发展进步的特殊作用。根据《三亚市庆祝中华人民共和国成立70周年活动实施方案》的通知精神，特制定本方案。

一、征集目的

以习近平新时代中国特色社会主义思想为指导，围绕庆祝中华人民共和国成立70周年，回顾过往岁月，总结历史经验，展望美好未来，鼓舞和激励全市人民爱党、爱国、爱三亚的热情，在建设海南自由贸易试验区、中国特色自由贸易港伟大进程中凝聚强大的精神力量。

二、征集对象及内容

（一）征集对象

面向全市征集，持有三亚（崖州或崖县）老照片的个人或单位、市内外摄影爱好者及摄影协会团体均可参加。

（二）征集内容

各界人士收藏或拍摄的，清末（崖州）；民国、中华人民共和国成立前后（崖县）；撤县设市、升格地级市、撤镇设区以及近30年来三亚从一个小渔村蝶变成为国际知名旅游城市的历史变迁，反映三亚市在政治、经济、社会、文化、民俗等各个领域发展变化的各类老照片。具体包括：

1、反映三亚经济社会发展及重要事件、重要会议、重要活动、重大工程建设的照片。

2、反映党和国家各级领导人到三亚视察工作和生活的照片。3、反映历史文化名人在三亚工作和生活的照片。

4、反映具有历史文化价值的三亚纪实性老照片，包括民俗风情、民间工艺、不同时期旧街貌、旧村镇、旧民居、老字号商店的照片以及同一区域前后变化的照片。

5、建设、生产、生活场景以及路、桥、车站等，并能反映百姓衣着、饮食、居住、出行、文化、教育、劳动、宗教、休闲等变迁的个人照、家庭照、生活照、工作照、单位景物照、生产照、活动照、集体照等老照片。

（三）其他事项

1、照片黑白彩色不限，尺寸大小不限，内容真实，每张照片附上相应的详细文字说明（注明照片事由、时间、地点、人物姓名、背景等，同时说明照片是原件还是翻拍、扫描件，文末须注明拍摄者或收藏者的真实姓名、身份简介、地址、邮编、电话，以便联系）。

2、不得加LOGO、水印、修饰性边框等其他任何东西修饰照片；增加或删减影像内容等影响作品真实性的照片不予参选。若发生侵犯他人著作权、肖像权、名誉权等行为及由此产生的一切法律责任，由照片提供者自行承担。

3、征集到的老照片均及时翻拍、扫描处理后归还提供者。持有者也可自行扫描、翻拍提供电子文档至指定邮箱，文件存为JPEG格式，大小不小于3M。若遇特殊情况需保留原件的，由活动组织方与提供者协商。对征集到的老照片，活动组织方拥有使用权，图片使用时标明收藏、提供或拍摄者姓名。

4、本次征集活动解释权归属市档案局。

三、征集方式

作品初选入围后，由评审委员会对作品进行甄别、鉴定，评选获奖作品。

四、奖励办法

为了激励广大市民踊跃参与“三亚记忆”老照片征集活动，本次活动设立一等奖1名，二等奖2名，三等奖3名，优秀奖10名。其中，一等奖10000元；二等奖8000元；三等奖6000元；优秀奖1000元。

五、征集活动起止时间：即日起至2019年8月31日(以征集电子邮件收到或实体照片送达时间为准)。
