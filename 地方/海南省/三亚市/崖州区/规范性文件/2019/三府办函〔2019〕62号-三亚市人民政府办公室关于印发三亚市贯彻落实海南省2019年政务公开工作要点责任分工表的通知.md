# 三亚市人民政府办公室关于印发三亚市贯彻落实海南省2019年政务公开工作要点责任分工表的通知

三亚市人民政府办公室

关于印发三亚市贯彻落实海南省2019年

政务公开工作要点责任分工表的通知

各区人民政府，育才生态区管委会，市政府各有关单位：

为贯彻落实好海南省2019年政务公开工作要点，认真做好我市2019年政务公开工作，经市政府同意，现将《三亚市贯彻落实海南省2019年政务公开工作要点责任分工表》印发给你们，并将有关事项通知如下，请结合实际认真贯彻执行。

一、围绕中心，服务大局，全面推进政务公开工作

各责任单位要高度重视政务公开工作，加强对新形势下全面推进政务公开工作重要性的认识，严格落实党中央、国务院和省委、省政府关于政务公开工作的各项决策部署。紧紧围绕市委、市政府中心工作，以提升政务公开质量为主线，确保政务公开工作落地见效。深化重点领域信息公开，深入推进决策和执行公开，完善政务公开体制机制，以公开稳预期、强监督、促落实、优服务，进一步提高政府治理和政务服务水平，切实提升人民群众获得感和满意度，为三亚打造海南自由贸易试验区和中国特色自由贸易港建设新标杆、争当海南全面深化改革开放排头兵发挥积极作用。

二、建立制度，狠抓落实，着力提升政务公开工作

各责任单位要根据政务公开的新要求、新任务，结合工作实际，进一步理顺和完善工作机制，及时制定完善相关配套制度。将《中华人民共和国政府信息公开条例》（国务院令第711号）等国务院、省政府信息公开工作相关文件纳入学习培训计划，不断增强干部职工的公开意识和履职能力，提高政务公开工作质量和效率。组织开展形式多样的《条例》宣传普及活动，加强政策解读和回应关切，引导社会公众参与，营造良好氛围。全面开展主动公开基本目录编制工作，推进基层政务公开标准化规范化建设。涉及机构改革调整的政府部门，要依法公开本单位新的机构职能等信息，及时更新主动公开范围目录。

三、优化服务，加强建设，有序开展政务公开工作

各责任单位要加大主动公开力度，规范依申请公开程序，加强信息公开审查，明确审查程序和责任，对拟公开的政府信息加强沟通确认，防止公开的信息失实失信。加强政务公开平台的整合建设和资源优化，推进政府网站与政务新媒体协同联动、融合发展。进一步加强政府信息资源的规范化、标准化、信息化管理，做到有领导统筹、有部门负责、有专人承办，实行一套人马、一个流程、一个载体管理的工作机制，实现政府网站和政务新媒体整体发声、信息同源、分发同时、资源同享、服务同根，运行维护更加高效、规范、有序、便捷。各责任单位要指定一名分管领导和具体承办人员（即统筹负责本单位政务公开、政府网站和政务新媒体管理工作的分管领导和工作人员），填写《三亚市政府系统政务公开工作人员名单》，于2019年7月31日18:00前上报至市政府办公室信息公开科。

四、夯实责任，强化督查，切实规范政务公开工作

各责任单位要严格对照责任分工表要求，坚持创新理念，加强协作配合，形成工作合力，逐项抓好工作落实。牵头单位要加强组织统筹，积极推进各项工作有序开展；具体责任单位要根据各自职能，积极抓好责任落实。各责任单位要将2019年政务公开工作要点落实完成情况于2020年1月10日前报市政府，并纳入政府信息公开工作年度报告，向社会公开。市政府将严格落实把政务公开纳入政务绩效考核体系且分值权重不低于4％的要求，采取网上核查、实地调查和组织第三方评估等方式，对完成工作任务情况进行检查，并通报结果。联系人：全思思，联系电话：88989623，电子邮箱：sanyashixinwen@163.com
