# 三亚市人民政府办公室关于2019年第三季度政府网站与政务新媒体检查情况的通报

三亚市人民政府办公室

关于2019年第三季度政府网站与政务新媒体

检查情况的通报

各区人民政府、各管委会，市政府各相关单位：

为做好全市政府网站与政务新媒体管理工作，根据《国务院办公厅关于印发政府网站发展指引的通知》（国办发〔2017〕47号）和《海南省政府网站管理办法》相关要求，市政府办公室组织开展了2019年第三季度全市政府网站与政务新媒体检查工作。现将有关情况通报如下：

一、总体情况

2019年9月20日至26日，按照《国务院办公厅秘书局关于印发政府网站与政务新媒体检查指标、监管工作年度考核指标的通知》（国办秘函〔2019〕19号）确定的检查标准，市政府办公室对全市处于正常运行状态的19个单位政府网站和56个政务新媒体进行了检查。

2019年7月1日至9月12日，网民通过“我为政府网站找错”平台反映全市政府网站问题9条，有关网站主管单位均进行了办理和反馈，办结率为100％。

二、主要问题

（一）网站信息更新不及时。“三亚市自然资源和规划局”网站首页的政策文件、政策解读、回应关切等栏目更新不及时。

（二）网站标识不规范。“三亚市卫生健康委员会”网站缺少公安机关备案标识，党政机关标识基本信息长期未更新。“三亚市教育局”网站公安备案号基本信息未更新。

（三）信息内容审核把关不严。“三亚市综合行政执法局”“三亚市人力资源和社会保障局”网站信息发布未严格落实内容发布审核制度，存在文字错漏等问题。

（四）政务新媒体管理不到位。“三亚防汛”微信公众号未向市政府办公室进行备案并纳入日常监管，存在漏报现象，且长期不更新；“三亚农业”微信公众号监测时间点前2周内无更新；“三亚社保”微信公众号存在无法访问栏目；

三、下一步工作要求

（一）落实网络意识形态责任制。各单位要严格内容发布审核制度，坚持分级分类审核、先审后发，明确审核主体、审核流程，严把政治关、法律关、政策关、保密关、文字关。规范转载发布工作，原则上只转载党委和政府网站以及有关主管部门确定的稿源单位发布的信息，不得擅自发布代表个人观点、意见及情绪的言论，不得刊登商业广告或链接商业广告页面。

（二）规范政务新媒体的开设整合。各单位要按照《三亚市人民政府办公室关于进一步加强政务新媒体管理工作的通知》（三府办函〔2019〕76号）要求，对问题比较突出、确实无力维护的政务新媒体予以关停，对分散的或功能相近的政务新媒体进行整合，将保留的政务新媒体向本级政府办公室进行备案。

（三）强化重点民生领域信息公开。各单位要按照《海南省人民政府办公厅关于印发海南省政务公开基本目录(2019年版)的通知》（琼府办函〔2019〕215号）和《三亚市人民政府办公室关于印发三亚市贯彻落实海南省2019年政务公开工作要点责任分工表的通知》（三府办函〔2019〕62号）要求，做好就业、教育、医疗、养老、征地、公共文化等领域的信息公开工作，并根据本单位职责开设相应的重点领域信息公开专栏。

对此次抽查通报的政府网站和政务新媒体，各有关单位要积极采取措施，全面核查、严肃追责，及时完成整改，并于2019年10月13日前将整改情况报市政府办公室。
