# 中共三亚市崖州区委办公室三亚市崖州区人民政府办公室<br>关于印发三亚市崖州区区属国有企业管理暂行实施意见的通知

中共三亚市崖州区委办公室三亚市崖州区人民政府办公室

关于印发三亚市崖州区区属国有企业管理暂行实施意见的通知

区各相关单位:

《三亚市崖州区区属国有企业管理暂行实施意见》已经区委、区政府同意,现印发给你们,请认真组织实施。

中共三亚市崖州区委办公室三亚市崖州区人民政府办公室

2019年8月13日

(此件主动公开)

三亚市崖州区区属国有企业管理暂行实施意见

第一章总则

第一条为了加强我区国有企业监督管理,理顺管理关系,规范企业运行,增强企业竞争能力,促进我区国有企业良性发展,确保国有资产保值增值,根据《中华人民共和国公司法》、《中华人民共和国企业国有资产法》、《企业国有资产监督管理暂行条例》(中华人民共和国国务院令第378号)等相关法律法规和文件规定,结合我区实际,制定本实施意见。

第二条本实施意见适用于三亚市崖州区区属国有企业,包括区属国有独资企业、国有独资公司、国有控股公司、国有实际控制企业(以下简称区属国有企业)及其子企业。

第三条按照“国有资产国家所有,各级政府分级监管,授权经营”的原则,三亚市崖州区人民政府(以下简称区政府)依照“权利、责任和义务相统一,管人、管事和管资产相结合”的管理体制,代表国家对国有企业履行出资人职责,享有出资人权益。

三亚市崖州区国有资产监督管理机构目前为区财政局,区财政局根据区政府授权,代表区政府对区属国有企业履行出资人职责,对全区国有企业实施监督管理。

第二章管理体制

第四条区财政局作为区属国有企业的监管部门,负责对区属国有企业资产、人员以及重要事项的管理,通过开展统计监测、财务预决算、重要人事任免、业绩考核、薪酬分配、审核审批重大事项等工作,加强对区属国有企业的监管。

第五条区属国有企业实行重大事项报告制度。重大事项分为审批事项和备案事项。

审批事项是指依照有关法律、法规以及企业章程的规定,由区财政局审批或区财政局审核后报区政府审批的事项。审批事项须经区财政局审核批准并书面回复后方可实施。

备案事项为告知事项,对区属国有企业上报的备案事项,区财政局有权进行复核和要求纠正。

第六条以下事项为审批事项:

(一)制定与修改企业章程。

(二)企业合并、分立、解散、申请破产、增加或减少注册资本、改制、上市。

(三)国有资产租赁与转让。

(四)重大投资。

(五)重大融资。

(六)重要资产评估。因改制、资产转让、解散、破产、债转股等所发生的资产评估。

(七)利润分配方案、财务预决算方案、职工年度薪酬分配方案。

(八)对外担保、对外捐赠及商业赞助。

(九)企业负责人出国出境。

(十)企业聘任财务部门负责人及子公司负责人。

(十一)其他应当请示审批的事项。

第七条以下事项为备案事项:

(一)企业年度生产经营计划、年度工作总结报告。

(二)采用的会计政策发生重大更改,涉及资产核算方法发生重要变化。

(三)不属于请示项目的其他资产评估。

(四)向子企业委派股权代表,派出监事。

(五)企业重要人员持有股份(票)情况。企业董事、监事、经营者持有的本企业及其控(参)股企业股份(票)。

(六)发生生产安全事故、自然灾害造成人员伤亡,以及重大财产损失;涉及企业重大权益的法律诉讼案件以及职工集体上访等。

(七)企业发生重大法律诉讼仲裁、国有股权被人民法院司法冻结,或企业重要工作人员涉嫌刑事犯罪。

(八)企业负责人因被采取人身强制措施或者健康等原因不能履行职责。

(九)企业负责人离开本市三天以上。

(十)其他需要备案的事项。

第八条涉及区属国有企业合并、分立、解散、申请破产、增加或减少注册资本、重要国有资产租赁与转让、改制、上市等重要事项以及企业负责人出境出国,应报区人民政府批准。

第三章人员管理

第九条区属国有企业领导人包括董事长、副董事长、总经理、财务总监、副总经理等职务。

第十条区属国有企业领导人一般为5名,下属子公司设总经理1名,副总经理2名。

第十一条区属国有企业领导人实行任期制,每届任期三年。

第十二条坚持党管干部与依法管理、管资产与管人管事相结合的原则。

区属国有企业董事长、副董事长、总经理、财务总监、副总经理由区委管理。董事长、副董事长由公司依据公司章程确定的办法选举产生。总经理、财务总监、副总经理建议人选可以采取公开招聘或推荐的方式产生,参照《党政领导干部选拔任用工作条例》进行任免。任免结果报区委组织部、区财政局备案。

第十三条区属国有企业其他副职负责人以及国有企业下属子公司总经理,由区财政局征求相关部门单位意见后提出人选建议,经区政府研究同意并按照干部管理权限和法定程序予以任免。

第十四条除职工监事外的其他监事由区财政局委派,监事会主席根据公司章程在监事会成员中选举产生。财务总监由区财政局委派。

第十五条区属国有企业应根据自身发展情况,建立“总额控制、因需设岗、能进能出、优胜劣汰”的用工制度,每年根据岗位或工作所需实行优胜劣汰,优化企业人员构成。

第十六条区属国有企业新招聘的人员,原则上应为企业业务所需的专业人才。企业招聘人员应拟定招聘计划和方案,报经区财政局审查备案后,由企业面向社会公开招聘,并将新招录人员的档案资料报区财政局备案。

第十七条区属国有企业设党组织书记,一般由董事长兼任,或由领导班子成员中的党员兼任;可根据需要设党组织副书记,由总经理或其他副职负责人员中的党员兼任。

区属国有企业必须坚持党的领导,把加强党的建设和完善公司治理有机统一起来,在日常工作中注重党员教育管理、干部管理等工作,强化党的思想建设、精神文明建设、企业文化建设和宣传工作。区财政局负责指导和监督区属国有企业的思想政治工作和党建工作,协助企业党组织深入开展党风廉政建设工作,不定期对企业的党建工作进行督促检查。

第四章薪酬管理

第十八条区属国有企业全面实行工资总额预算管理,企业工资总额预算方案、内部薪酬分配方案及绩效考核方案由企业按照本实施意见规定编制,并报区财政局审定。

第十九条区属国有企业领导人薪酬结构由基本年薪、绩效年薪、任期激励收入三部分组成。其他人员的薪酬结构由基本年薪和绩效年薪组成。

(一)基本年薪是指企业人员的年度基本收入。企业人员的基本年薪根据上年度三亚市国有单位在岗职工平均工资水平确定,原则上每年核一次,并根据各岗位职责和承担风险等因素,合理确定薪酬倍数,董事长、总经理、财务总监和副职负责人的薪酬倍数最高分别不超过5倍、4倍、3.5倍、3倍,其他人员的薪酬倍数最高不超过2.5倍。

(二)绩效年薪是指与企业人员年度综合绩效考核评价结果相联系的收入,根据年度综合绩效考核评价结果在基本年薪的30%以内确定。

(三)任期激励收入是指与企业领导人任期综合绩效考核评价结果相联系的收入,任期激励收入在任期内年薪总水平的30%以内确定。

第二十条企业人员的薪酬按照核定的薪酬方案支付。基本年薪按月支付;绩效年薪按照先考核后兑现的原则,年度综合绩效考核结束后一次性兑现,原则上于次年上半年支付;任期激励收入实行延期支付办法,任期综合考核结束后,分两年(第一年按60%、第二年按40%的比例)发放。

第五章财务管理

第二十一条区属国有企业实行财务收支预决算制度。区属国有企业年初按照规定的口径和要求,根据企业的经营发展计划,科学编制年度财务预算,经区财政局批复后严格执行。年终应全面真实做好财务决算,并对运行质量进行科学分析和评价。

第二十二条区属国有企业应当依照法律、行政法规和财政部门的规章,并结合本企业实际情况,制定财务管理制度和企业会计核算办法,并报区财政局备案。企业内部财务管理制度原则上应包括以下内容:

(一)财务预算管理制度;

(二)资本金管理制度;

(三)货币资金及往来户结算管理制度;

(四)设备等资产购置和管理制度;

(五)在建工程管理制度;

(六)费用支出管理制度;

(七)部门负责人离任审计制度。

第二十三条区属国有企业应当在年度终了时,编制年度财务决算报表经会计师事务所审计后,报区财政局备案。

第二十四条区属国有企业法定代表人发生变动时,应当对其进行财务审计和经济责任审计。

第二十五条区属国有企业应当按照《中华人民共和国企业国有资产法》的相关规定,建立健全国有资本经营预算制度,对取得的国有资本收入及其支出实行预算管理。

第二十六条区属国有企业的国有资本收益应当按规定上缴财政。为扶持和激励区属国有企业的健康稳定持续发展,新设立的区属国有企业自成立之日起5年内可暂不上缴应交利润,用于企业转增国家资本或者国有资本公积。

第六章资产管理

第二十七条区属国有企业应建立健全实物形态资产的价值构成情况、产权情况、使用情况、经营情况和抵押情况等管理台帐,做到家底清楚,帐、卡、实相符。

第二十八条区属国有企业利用国有资产进行抵押担保,应当报区财政局审批。其中:为非本企业抵押担保的,应报区人民政府批准。

第二十九条区属国有企业资产处置和资产租赁应遵循“阳光交易”原则,按规定的程序进行公开交易。区属国有企业对外公开出租资产应向区财政局和交易机构提供招租方案和租金底价确定方案。

第七章采购管理

第三十条区属国有企业采购货物、服务和工程建设类项目,属于我区政府采购目录的应当纳入政府采购,同时按照我区政府采购管理的相关规定执行。

第三十一条区属国有企业应根据经营管理需要制定当年采购项目计划,纳入年初财务预算,并报区财政局备案。

第三十二条采购申报程序。区属国有企业根据年初采购预算,填写《采购计划申请表》报区财政局备案。

第八章监督管理

第三十三条加强区属国有企业监事会监督职能。建立健全企业监事会工作制度,规范监事会运行机制,加强监事会在企业运行、重大事项决策等方面的监督。

第三十四条加强对区属国有企业经济审计监督工作。每年对区属国有企业经营和财务状况进行一次专项审计,定期、不定期实施区属国有企业资产负债损益审计以及企业法人经济责任审计。

第三十五条加强区属国有企业日常监管。区财政局以及相关部门要按照各自职能,通过监测、监督检查、规范等方式加强区属国有企业的日常管理。

第三十六条加强区属国有企业负责人履职考核监管。建立企业负责人业绩考核与薪酬分配和任职挂钩的激励和约束机制,实行年度和任期履职考核,将区属国有企业负责人履职结果与任职管理和薪酬待遇全面结合,加强履职监管。

第三十七条严肃责任追究。对在经营管理中违反管理规定的以及造成企业重大损失或国有资产流失事项,视其情节轻重给予企业负责人及相关责任人通报批评、考核不合格、经济处罚、降职、解聘等处理,并按相关规定承担相应的经济和法律责任。

第九章附则

第三十八条本实施意见未明确的其他关于区属国有企业管理方面的内容,按《中华人民共和国公司法》、《中华人民共和国企业国有资产法》《企业国有资产监督管理暂行条例》等相关法律法规和文件规定执行。

第三十九条本办法由区财政局负责解释。

第四十条本办法自印发之日起执行。
