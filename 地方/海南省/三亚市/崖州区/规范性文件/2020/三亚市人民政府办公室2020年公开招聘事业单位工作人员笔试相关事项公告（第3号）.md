# 三亚市人民政府办公室2020年公开招聘事业单位工作人员笔试相关事项公告（第3号）

三亚市人民政府办公室

2020年公开招聘事业单位工作人员笔试相关事项公告

（第3号）

三亚市人民政府办公室2020年公开招聘事业单位工作人员报名工作结束，已于5月21日对资格初审合格人员进行了公告，现将笔试相关事项公告如下：

一、资格初审合格进入笔试人员名单（见附件1）

二、笔试时间：2020年9月12日（周六）上午09：00-11:00

三、笔试地点：海南省三亚市（具体详见笔试准考证）

四、打印准考证时间：2020年9月10日下午16:00至9月12日上午8:00

请资格初审合格人员在规定时间内登录本人报名时预留的电子邮箱，下载打印笔试准考证。未在规定时间内打印笔试准考证的考生，视为自动放弃考试，所造成的后果由考生自负。

五、注意事项

（一）受疫情影响，请各位考生认真阅读附件2《笔试防疫指南》，按要求落实防疫工作。进入考场的考生需佩戴口罩、测量体温，体温正常（低于但不包括37.3℃）、出示健康码为绿色、出示个人14天内行动轨迹（手机查询）并提交《防疫承诺书》的考生可进入考场参加考试。如因个人问题无法提供上述材料，影响参加考试的，后果由个人承担。进入考场后，按要求将手机关机，放在指定位置集中保管。

（二）考生须凭笔试准考证和有效身份证（丢失身份证或身份证失效者，须及时到公安部门补办临时身份证）参加考试，二者缺一不可，否则取消考试资格。

（三）请各位考生提前30分钟到场。开考30分钟后不允许进场，中途不得提前交卷，考试结束方可离开考场。

（四）答题卡一律用2B铅笔填涂作答，其它内容用黑色水笔或签字笔作答。请考生自带2B铅笔、橡皮、黑色水笔或签字笔。

（五）不得携带任何书本资料、手机及电子通讯设备进入考场。

咨询电话：0898-88365655

咨询时间：工作日上午8:00-12:00，下午15:00-18:00
