# 三亚市人民政府办公室关于印发《三亚市推进项目建设红黄绿亮牌督办机制（试行）》的通知

三亚市人民政府办公室

关于印发《三亚市推进项目建设

红黄绿亮牌督办机制（试行）》的通知

各区人民政府，各管委会，市各有关单位：

《三亚市推进项目建设红黄绿亮牌督办机制（试行）》已经市政府同意，现印发给你们，请认真组织实施。各区、各部门在执行过程中如有意见或建议，请及时反馈市发展和改革委员会，以便进一步修改完善。

三亚市人民政府办公室

2020年9月15日

（联系人：李晓宇，联系电话：88298895）

（此件主动公开）

三亚市推进项目建设红黄绿亮牌督办机制（试行）

为贯彻落实推进全省高质量高标准投资现场观摩会精神，督促项目加快开工、满负荷建设、超计划投资和尽量提前完工，层层传导推进项目的压力和责任，确保完成全年投资计划，根据《海南省关于进一步采取超常规举措确保完成全年经济目标的实施意见》，结合我市实际，特制定推进项目建设红黄绿亮牌督办机制（试行）。

一、亮牌项目范围

（一）《中共三亚市委办公室三亚市人民政府办公室关于印发三亚市2020年固定资产投资项目计划的通知》（三办发〔2020〕17号）所列的建设项目。

（二）《中共三亚市委办公室三亚市人民政府办公室关于印发三亚市2020年重点项目“六个一”责任分解表》（三办发〔2020〕55号）所列的建设项目。

（三）年度计划外新增的总投资500万元以上的建设项目。

二、实施亮牌主体

（一）市政府各部门、市属企事业单位作为项目业主单位的政府投资项目和年度计划投资额1亿元以上（含1亿元）的社会投资项目，由三亚市投资工作领导小组办公室（市发展和改革委员会）发文通报亮牌。

（二）区政府各部门、区属企事业单位作为项目业主单位的政府投资项目和年度计划投资额1亿元以下的社会投资项目，由各区政府发文通报亮牌。

三、亮牌规则

（一）三亚市投资工作领导小组和各区政府从2020年9月起，每月根据市统计部门核定的各建设项目年初至上个月月底投资完成数进行亮牌。

（二）建设项目年初至上个月月底投资完成数超过或等于计划投资额序时进度的，亮绿牌；低于计划投资额序时进度50%以内的（含50%），亮黄牌；低于计划投资额序时进度50%以上的，亮红牌。

（三）竣工、续建项目的序时进度从2020年1月份开始计算，新开工项目的序时进度从计划开工的月份开始计算。

（四）建设项目被亮黄牌或红牌后，投资序时进度符合本条第二项的，由红牌转黄牌、绿牌或由黄牌转绿牌。

（五）对各区（含育才生态区）全社会固定资产投资任务完成数单独亮牌。未完成全社会固定资产投资月度下达任务数的亮黄牌，连续两个月未完成全社会固定资产投资月度下达任务数的亮红牌。

四、约谈要求

（一）政府投资项目被亮黄牌的，由项目业主单位主要负责人约谈分管项目领导；连续两次被亮黄牌的，由分管副市长约谈项目业主单位主要负责人，市政府各部门、市属企事业单位的下属单位作为项目业主单位的，约谈市政府各部门、市属企事业单位的主要负责人。

（二）政府投资项目被亮红牌的，由分管市领导约谈项目业主单位主要负责人，市政府各部门的下属单位作为项目业主单位的，约谈市政府各部门、市属企事业单位的主要负责人；连续两次被亮红牌的，由市长约谈市政府各部门、市属企事业单位的主要负责人。

（三）社会投资项目被亮黄牌的，由三亚市投资工作领导小组办公室约谈项目业主单位主要负责人；连续两次被亮黄牌的，由分管副市长约谈项目业主单位主要负责人。

（四）社会投资项目被亮红牌的，由分管副市长约谈项目业主单位主要负责人；连续两次被亮红牌的，由市长约谈项目业主单位主要负责人；连续三次被亮红牌的，推送媒体曝光，涉嫌构成《海南省闲置土地认定和处置规定》第二条规定的闲置土地的，由市自然资源和规划局在30日内开展调查核实，依法处置。

（五）各区未完成全社会固定资产投资月度下达任务数被亮黄牌的，由三亚市投资工作领导小组办公室通报批评；被亮红牌的，由市长约谈区长。

（六）各区按照上述原则对由区政府发文通报亮牌的项目实施约谈和督办。

五、其他

（一）各区、各单位可根据本机制制定本单位推进项目建设红黄绿亮牌督办措施，层层传导压力和责任。

（二）本机制由市发展和改革委员会负责解释。

（三）本机制自2020年9月15日开始实施。
