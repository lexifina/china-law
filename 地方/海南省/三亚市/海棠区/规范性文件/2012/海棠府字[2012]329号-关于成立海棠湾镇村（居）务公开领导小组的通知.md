# 关于成立海棠湾镇村（居）务公开领导小组的通知

三亚市海棠湾镇人民政府文件

海棠府字[2012]329号

海棠湾镇人民政府

关于成立海棠湾镇村（居）务公开领导

小组的通知

各村（居）委会、各相关单位：

为切实加强海棠湾镇村（居）务公开工作的组织领导，进一步推进我镇村（居）务公开工作。经镇委研究，现成立海棠湾镇村（居）务公开领导小组，成员如下：

组 长：陈治邦（海棠湾工委副书记、镇委书记、镇人大主席）

副组长：刘 冲（海棠湾管委副主任、镇委副书记、镇长）

刘 莉（镇委委员、镇委专职副书记）

钟 路（镇委委员、纪委书记）

彭伟然（镇委委员、常务副镇长）

苏文茹（镇政府副镇长）

罗丕智（镇政府挂职副镇长）

林云春（海棠湾财政所所长）

成 员：朱博阳（镇党政办主任）

黄启鸣（镇社会事务办主任、分房办主任）

孙方来（海棠湾“三资”委托代理服务中心主任）

占道魁（海棠湾镇社会事务办民政助理）

领导小组下设办公室，办公室设在社会事务办，主任由罗丕智同志兼任，副主任由黄启鸣同志兼任，工作人员从党政办、社会事务办人员中抽调，负责村务公开日常实施工作。

特此通知。

海棠湾镇人民政府

2012年10月23日
