# 关于进一步加强瓜菜质量检测工作的通知

三亚市海棠湾镇人民政府文件

海棠府字[2012]361号

海棠湾镇人民政府

关于进一步加强瓜菜质量检测工作的

通 知

海棠湾镇各瓜菜收购商：

根据市委市政府的要求，为进一步做好我镇冬春瓜菜质量安全保障工作，确保出岛瓜菜100%检测、100%合格和100%凭证，维护我镇冬季瓜菜品牌声誉，我镇将进一步加强瓜菜质量检测工作，现将有关事项通知如下：

1、从2012年12月6日起，我镇瓜菜检测站将对全镇的瓜菜收购档口进行瓜菜随机抽样检测，希望各瓜菜收购商积极配合，对拒不配合采样的档口我镇将联合海棠湾镇工商所对其进行取缔。

2、过往车辆的瓜菜检测合格后发证放行，如检测出不合格的瓜菜则扣下并将瓜菜存放在低温储存室（费用由镇政府承担），直至瓜菜复检合格后方可发证放行，对多次抽检不合格的档口将进行处罚。

特此通知。

海棠湾镇人民政府

2012年12月5日

（此件主动公开）

海棠湾镇党政办公室 2012年12月5日印发
