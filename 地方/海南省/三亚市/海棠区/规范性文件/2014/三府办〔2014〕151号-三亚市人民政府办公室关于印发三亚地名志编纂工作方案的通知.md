# 三亚市人民政府办公室关于印发三亚地名志编纂工作方案的通知

三亚市人民政府办公室

关于印发三亚地名志编纂工作方案的通知

各镇人民政府，各区管委会，市政府直属各单位：

《三亚地名志编纂工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2014年6月18日

（此件主动公开）

三亚地名志编纂工作方案

一、指导思想

坚持以科学发展观重要思想为指导，以党的群众路线教育实践活动为牵引，以精细化为目标，全力做好三亚地名志编纂工作。在实施过程中，做到任务分工明确，确保全面系统收集整理三亚社会、人文、工业、农业、林业、渔业、海洋、水文等方面的地名信息资料。充分挖掘和传承三亚历史地名文化，展示三亚人民在1919.6平方公里土地上辛勤劳动、进行革命和建设的宏伟业绩，特别是1984年撤县设市、1987年升格为地级市后，三亚所取得的巨大成就和变化。

二、组织领导

为推进《三亚地名志》编纂工作顺利开展，成立《三亚地名志》编纂工作领导小组，其组成如下：

《三亚地名志》编纂工作领导小组办公室设在市民政局区划地名科，主要负责《三亚地名志》编纂工作的具体组织、协调、实施。联系人：文彩珍，联系电话：88279962，13876586599，电子邮箱：sanyadmk@163.com。

三、工作安排

2014年12月底前完成《三亚地名志》的编纂出版工作。分三个阶段实施：

（一）动员部署阶段（2014年6月20日—6月27日）

2014年6月下旬，由市民政局组织召集各镇、区和三亚学院等单位相关人员，召开《三亚地名志》编纂工作动员部署及编纂业务培训会，布置编纂工作任务和开展业务培训学习。

（二）组织实施阶段（2014年7月1日—11月30日）

1．2014年7月1日—7月30日，组织对三亚的各类地名进行分类采集，收集历史照片或音像资料等其他多媒体资料；

2．2014年8月1日—8月31日，组织全体编纂工作人员，按章节、分类别集中撰写和进行资料遴选、图片剪辑合成等；

3．2014年9月1日—10月31日，组织集中校对和专家组审稿，完成终审和封面、插图设计等工作；

4．2014年12月底前按要求完成出版发行工作。

（三）总结阶段（2014年12月中旬）

由编纂工作领导小组办公室组织召开总结表彰会，对在编纂工作中表现突出的工作人员或专家学者给予表彰。

四、任务分工

（一）市民政局：总体负责牵头组织《三亚地名志》的编纂、校对、会审、出版等系列工作，负责联系协调各成员单位共同开展相关工作。

（二）市史志办：负责协助市民政局组织本土专家学者对《三亚地名志》书稿进行审核把关，提供编纂所需历史图片资料。

（三）其他市直单位和省垂直双管单位：根据编纂工作要求，提供相关数据资料，配合《三亚地名志》编纂、出版发行等工作。

（四）各镇、区：选派专员下乡开展调研、采访工作，负责本辖区地名、人文、社情等具体收集、调研、撰写工作。

（五）三亚学院：根据协议，按照《三亚地名志》编纂领导小组办公室要求，组织团队按“编纂细则”规范要求开展实地调查、采访等外业和资料汇编、史志撰写等内业工作。

五、工作要求

（一）严格标准，确保精准，突出特色

《三亚地名志》是三亚有史以来第一次系统编纂的首部地方志，编纂完成后，将填补三亚地方志的空白。因此，具体参加撰写编纂工作的人员要严格按照“三亚地名志编纂细则”所规范的目录、框架结构去收集资料和撰写。按现行的行政区划体系，把本市范围之内重要地名的历史沿革、地名含义及重大事件、重要人物记载清楚，确保精准；系统收集、整理资料，集中组织撰写，聘请专家审稿，确保资料完整详实、篇幅适当、语言文字规范、地方特色突出。

（二）实事求是调研，系统规范编纂

由于《三亚地名志》编纂工作是一项内容涵盖广泛、科学严谨的系统工程，要求内容必须真实，不能弄虚作假，更不能杜撰数据资料。以三亚现有的行政区划为界，按照“三亚市地名管理办法”界定的地名范畴，提供三亚所辖各类地名的标准名称，准确表述地名的汉语拼音、地理位置、地名含义和演变、历史沿革及其自然地理、社会历史和经济文化状况等地理实体特征及相关信息。《三亚地名志》编纂必须以“三亚地名志目录”和“三亚地名志编纂细则”为基准，深入挖掘三亚地名历史文化，使地名工作为三亚的社会发展作出更大的贡献。

（三）加强沟通联系，密切协同配合

各成员单位要严格按照工作方案保质保量完成工作任务，工作中要注重沟通、密切配合。为方便工作联络，请各镇、区和市史志办及三亚学院等单位将参加编纂工作的人员姓名、职务、手机号码于2014年6月25日报三亚地名志编纂工作领导小组办公室，以便协调配合开展工作。各镇、区和三亚学院编纂的稿件统一用电子文档报送《三亚地名志》编纂工作领导小组办公室。

（四）提高思想认识，形成编纂合力

《三亚地名志》编纂工作是一项全新的系统工程，是一项文化建设工程，意义重大。各成员单位要从思想上高度重视，从组织上严格把关，指定专人负责本辖区和本单位的编纂组织工作，并选派政治觉悟高、文字功底好的人员参加具体调研编纂工作，同时要在人力、财力、物力上给予充分保障。
