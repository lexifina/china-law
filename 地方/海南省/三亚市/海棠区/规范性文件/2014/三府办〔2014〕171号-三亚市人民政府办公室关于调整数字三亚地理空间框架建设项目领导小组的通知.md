# 三亚市人民政府办公室关于调整数字三亚地理空间框架建设项目领导小组的通知

三亚市人民政府办公室

关于调整数字三亚地理空间框架建设项目

领导小组的通知

各镇人民政府，各区管委会，市政府各有关单位：

因人事变动和工作需要，市政府决定调整数字三亚地理空间框架建设项目领导小组，调整后的组成人员如下：

数字三亚地理空间框架建设项目领导小组主要职责：负责项目建设的组织领导工作，协调解决项目建设中的重大困难和问题;审定项目建设总体设计方案、总体进度计划;审定项目建设、运营、维护、更新、推广等方面的相关规范和政策措施;监督、检查项目进度、推广应用、资金落实等工作；负责项目验收相关工作。

数字三亚地理空间框架建设项目领导小组下设办公室，办公室设在市国土环境资源局（市测绘地理信息局）。办公室主任由程春满局长担任，办公室副主任由何海英副局长和市国土环境资源信息中心（市地理信息中心）叶璐主任担任。办公室具体职责：负责项目筹划、招标、运作等工作；指导总体设计方案、实施方案；协调、指导项目的组织实施、质量管理、安全生产等工作；拟订项目建设、运营、维护、更新、推广的相关规范和政策措施；监督、指导项目经费预算和决算的编制，监督、指导项目年度预算的执行；完成项目领导小组交办的其他工作。办公室下设协调组和技术组。
