# 三亚市人民政府办公室关于成立三亚市低空领域管理改革和促进通用航空产业发展工作领导小组的通知

三亚市人民政府办公室

关于成立三亚市低空领域管理改革和促进

通用航空产业发展工作领导小组的通知

各镇人民政府，各区管委会，市政府直属各单位：

为配合海口分区低空领域改革试点工作，促进三亚通用航空产业发展，市政府决定成立三亚市低空领域管理改革和促进通用航空产业发展工作领导小组，现将有关事项通知如下：

一、领导小组成员

领导小组下设办公室，负责领导小组日常工作，办公室设在民航三亚空管站，何世刚兼任办公室主任，市发展改革委张途晟、民航三亚空管站冼志强任副主任。

二、主要职责

（一）领导小组主要职责

1.配合海口分区低空领域空域管理改革试点工作领导小组做好涉及三亚的低空空域管理改革试点工作，积极向省政府、部队、民航部门争取政策支持。

2.研究三亚市通用航空产业发展政策，协调通用航空资源支持三亚经济发展和抢险救灾工作。

3.合理规划通用航空基地布局，协调解决通用航空项目建设和企业发展中存在的重大问题。

（二）领导小组办公室主要职责

1.承担领导小组的日常工作，协调处理低空领域管理改革和通用航空产业发展工作推进中的具体事务。

2.做好领导小组成员单位间的沟通协调工作，建立快捷有效的管理运行和部门合作机制，督查落实领导小组议定事项。
