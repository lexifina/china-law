# 三亚市人民政府办公室关于认真做好2014年春运工作的通知

三亚市人民政府办公室

关于认真做好2014年春运工作的通知

市政府直属各单位：

2014年春运工作从1月16日开始至2月24日结束，共计40天。为深入贯彻落实党的十八大、十八届三中全会精神和省委、省政府的工作部署，努力做好2014年春运有关工作，满足广大人民群众的出行需要，实现和谐春运的目标，现将春运工作有关事项通知如下：

一、提高认识，强化春运紧迫感和责任感

春运工作涉及广大人民群众的切身利益，是一项重要的民生工程。做好春运工作，是解决人民群众最关心、最直接、最现实的利益问题，是推进我市科学发展的重要举措。春运期间，我市返乡流、探亲流、旅客流叠加，人流、车流、物流激增，运输矛盾突出，春运工作任务复杂艰巨、影响范围广、涉及部门多，各单位要高度重视，集中力量，周密谋划，加强协调，扎实抓好各项工作落实，对春运工作所需的人力、物力、经费等予以重点保证，同时要尽最大努力为春运一线干部职工提供良好的工作和生活条件，保证一线干部职工能全身心投入春运工作。

二、加强领导，建立健全组织机构

各单位要按照“以人为本、安全为先、科学组织、和谐春运”的指导原则，加强组织领导，完善协调机制，扎实做好春运各项工作。

市春运工作领导小组组长由市委副书记、市政府常务副市长、海棠湾工委书记吴岩峻担任，成员由市有关单位分管负责人组成，领导小组办公室（以下简称“市春运办”）设在市交通运输局，具体负责全市春运的日常综合协调工作，办公室主任由市交通运输局局长李维担任。市春运办实行24小时值班制，值班地点：市交通运输局六楼运管处投诉受理中心，值班电话：88667803。

各单位要相应成立春运工作领导小组，具体负责春运工作的组织协调，处理春运重大问题和突发事件，保障春运工作安全有序开展。市春运办实行信息日报制度，各单位每天上午9时前分别将前一天的春运情况，道路、水路、公交、出租车运输情况，铁路运输情况，航空运输情况报市春运办。旅客大面积滞留、发生春运交通安全事故等重大紧急情况即发即报。

三、齐抓共管，强化安全监管

各单位要始终坚持“安全第一、预防为主”的方针，严格落实春运安全生产的各项要求，切实强化运输安全“一岗双责”和企业主体责任，加强安全监管，重视隐患排查，突出事故预防，强化应急值守，切实保障旅客的人身和财产安全。

各有关单位要强化对铁路道口、港口、水上渡口、镇客渡船的管理，加强对重点桥梁、隧道和重点路段的检查养护，加大对农村民俗节日、庙会等的交通组织和安全监管力度，防止各类事故发生。交通运输和公安部门在春运期间要组织开展各类运输设备的安全排查，及时清除安全隐患；加强路面巡查和严厉打击非法营运车辆，严格落实反超载、反超限、反超速措施，严肃查处无证驾驶、酒后驾驶、疲劳驾驶、超速超载行驶等违法行为，严禁非客运车辆参加春运；加强车站、码头现场监督管理，所有参加春运车辆都必须按规定进站(场)经营，严禁超载超限车出站。各运输企业要强化春运期间各种运输工具的维修和检查，严禁任何不符合安全要求的设施设备投入春运；强化对司乘人员、经营者的安全教育，凡是不符合要求的司乘人员一律不得参加春运；切实做好危险品的查禁工作，严禁旅客携带易燃、易爆及其他危险品乘坐交通工具。民航部门要加强营运飞机安全监管，提高航班正常率；加强空域协调，进一步做好净空区域安全及宣传工作，确保飞行安全。海事部门要加大船舶的安全监管力度，同时将海上旅游船列入监管重点，并加强海上应急搜救。

四、科学安排，优化运力配置

各有关单位要根据今年春运客流特点，加强客流预测分析，科学调配运力，优化运输组织，保证运力充足、调度有序。要增强应急预案的针对性，合理储备应急运力。要及时疏散春节期间的积压旅客，确保旅客走得安全、及时、便捷、有序。

道路运输部门要准备充足运力，加大长途正班车发班密度，并根据客流变化，及时增调机动运力，缩短发车间隔，适时开行省际和市县间直达客运班线，避免高峰期旅客“压站”。同时要组织包车运力，满足团体旅客出行需求；要制定接驳运输试点方案，并加强监督管理，严格组织实施，稳步推进长途客运车辆凌晨2至5点接驳运输试点工作；要加强农村客运的组织管理，特别要做好农村赶集和大型集会时的运力保障；要加强二级以上客运站的联网售票管理和宣传工作，及时检查维护售票设备及网络，班线联网售票系统正常运行，保证广大旅客正常使用和顺利购票。

民航部门要密切关注天气和航班运行情况，做好热点航线的加机和包机工作。要细化服务保障和应急处置预案，调剂大型客机保障运力，发生大面积航班延误时，要及时启动应急处置预案。

铁路部门要抓好东环铁路客货运输，兼顾短途沿线区间群众乘车需求，做好高峰客流期间增开直通临客的准备工作，用好用足运力。

水运部门要根据区间和短途客流变化情况，及时安排加班运力，科学增加客船定额，避免出现旅客“压港”问题。发生旅客大面积滞留时，要及时启动应急处置预案。

城市公共交通部门要加强组织调度，重点做好火车站、汽车站、码头、机场等旅客集中地点的运力调度工作。要通过增投运力、加密班次、延长运营时间等有效措施，最大限度地方便旅客中转换乘，及时疏运节日期间参加重大节庆活动的市民群体。

在做好旅客运输的同时，要统筹兼顾，合理安排，组织好重点生产、生活物资运输，保障市场供应和价格稳定，确保工农业生产和居民生活平稳有序。

五、突出重点，完善应急措施

各单位要根据本单位实际和可能出现的突发情况，制定和完善责任主体明确、可操作性强的春运应急预案，形成准备充分、反应快速、应对准确、处置果断的应急机制。一旦发生突发事件，要立即启动相应级别的应急预案，有关部门领导要第一时间抵达现场，采取有力举措及时、有效地控制事态发展，降低事件造成的影响。尤其要做好应对因航班延误、港口停航等原因出现旅客大面积滞留的疏导安置工作。市民航办要提前组织协调机场、市旅游委做好机场旅客滞留的食宿安排工作。机场旅客大面积滞留或发生突发事件时，市民航办领导要第一时间到现场处置；道路、港口发生旅客、车辆大面积滞留拥堵或发生突发事件时，市交通运输局领导要第一时间到现场处置。市春运领导小组成员必要时到现场处置，市春运办做好指挥协调工作。

各单位要密切配合，相互协作。市政府和相关运输部门要建立沟通渠道，相互通报客流量、运力较大变化、调整的情况，及时采取联动对应措施。运输部门之间要建立协作机制，最大限度地发挥综合运输能力。公安和交通运输部门要建立保障道路畅通的联动机制，做好春运期间高速公路防拥堵保畅通预案，发生恶劣天气时加强车辆疏导，采取措施尽量减少道路封闭，保证道路通行。相邻地区之间要建立联动机制，信息互通，措施联动，保证干线公路通畅。气象部门要做好春运期间中短期和恶劣天气的预测预报工作，及时向市春运办等部门提供有关信息。

六、以人为本，提升服务质量

各有关单位和各运输企业要牢固树立和落实“以人为本”的服务理念，采取切实有效措施，努力提高服务质量和服务水平，营造文明、温馨、和谐的出行环境。

要虚心听取群众诉求，用心服务，为旅客出行创造良好的环境和条件，对因气候、交通环境变化导致发班延误的，要耐心解释、周到服务、并采取有效措施妥善处理。要落实各项客运服务标准，提升服务效能和质量，保持站容站貌和车（船）容车（船）貌整洁，维护客运站秩序，机场、客运站、码头在客流高峰期要增派服务人员，为旅客提供周到热情服务，对老幼病残孕等特殊旅客给予重点照顾。客运站（码头）要采取增设售票窗口、延长售票时间及预售（订）票、联网售票和组织送票服务等措施，方便旅客购票，在客流高峰期增派服务人员，引导旅客购票、乘车（船），耐心解答旅客提出的各种问题，为有困难的旅客提供帮助，夜晚有旅客滞留时，要开放候车室并提供必要服务。凡是发生严重服务质量事件，特别是粗暴待客、侵犯旅客合法权益、造成不良社会影响的，要严肃追究相关单位和责任人的责任。

春运期间，各单位要积极引导宣传春运好经验、好做法和先进典型事迹，及时发布运力、客流、售票、旅客服务、公路通行、天气等信息。宣传部门、媒体单位要安排好春运采访报道，营造良好的舆论氛围，促进春运工作顺利开展。

春运结束后，各部门和有关单位要对春运工作进行总结，于2月25日前将总结材料报市春运办。
