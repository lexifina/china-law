# 三亚市人民政府办公室关于印发三亚市2014年土地矿产卫片执法监督检查工作方案的通知

三亚市人民政府办公室

关于印发三亚市2014年土地矿产卫片

执法监督检查工作方案的通知

各镇人民政府，各区管委会，市政府直属各单位：

《三亚市2014年土地矿产卫片执法监督检查工作方案》已经市政府同意，现印发给你们，请认真贯彻执行。

三亚市人民政府办公室

2014年9月4日

（此件主动公开）

三亚市2014年土地矿产卫片执法

监督检查工作方案

为做好三亚市2014年土地矿产卫片执法检查工作，纠正土地违法违规行为，加强和规范土地与矿产资源管理，按照国土资源部和海南省国土环境资源厅的工作部署，结合三亚市实际，制定本工作方案。

一、主要任务

通过开展2014年土地矿产卫片执法监督检查工作，发现、制止和查处违法用地、违法勘查开采矿产资源行为；对违法用地、违法勘查开采矿产资源严重的辖区主要负责人进行警示约谈，督促依法依规管地用地、管矿用矿；依据《违反土地管理规定行为处分办法》（监察部、人力资源和社会保障部、国土资源部令第15号，以下简称15号令），对违法用地严重地的辖区主要负责人和其他负有责任的人员实施问责。

二、组织机构及职责分工

（一）组织机构

为加强组织领导，决定成立市土地矿产卫片执法监督检查工作领导小组，由市政府副市长陈小亚担任组长，市政府副秘书长韦迪伟、市国土环境资源局局长程春满担任副组长，市国土环境资源局、市综合行政执法局、市公安局、市财政局、市人力资源和社会保障局、市发展和改革委员会、市住房和城乡建设局、市交通运输局、市科技工业信息化局、各辖区等部门分管负责人担任领导小组成员。市领导小组成员办公室设在市国土环境资源局，办公室主任由市国土环境资源局副局长高富宅担任，副主任由市国土环境资源监察支队支队长陈武卫担任，各成员单位按照各自职能，细化工作职责，积极协助，定期召开联席会议，并分别确定1名人员负责联络工作。联络人员名单报至市国土环境资源监察支队，电话：88756806。

（二）职责分工

市政府负责对有关部门移送的违法违规用地、违法勘查开采矿产资源等案件中涉及公职人员不作为、乱作为和其他渎职行为的，依法提出处理意见。对政府及其派出机构、相关职能部门和单位及其工作人员违反法律法规规定，违法颁发有关许可证照、违规办理核准事项和不履行有关协助义务的，要依法追究相关责任人的责任。对违法用地严重地区的辖区主要负责人进行警示约谈，并依据15号令实施问责。

市国土环境资源局负责具体组织开展三亚市土地矿产卫片执法监督检查工作，查处土地矿产违法案件，并依法将违法用地行为涉及违法建筑移交市综合执法局拆除，同时对查处过程中发现涉嫌刑事犯罪的，依法移送公安机关处理；按要求及时审核和报送有关数据；提请市政府开展警示约谈和问责。

市综合行政执法局负责城镇规划范围内违法建设的巡查、监控、调查取证、查处以及拆除等工作；对发现违法建筑涉及的违法用地，应在查处违法建筑后告知国土部门对违法用地行为依法查处。

市公安局负责对涉嫌犯罪的土地违法行为和违法勘查采矿行为组织查处，依法追究违法当事人的刑事责任，及时出警对妨碍、阻扰、围攻、殴打有关部门执法人员的违法当事人依法查处。

各辖区按照属地管理原则，充分发挥辖区政府、社区居委会、村委会的基层前沿作用，协助配合成员单位开展工作，并按照职责巡查、制止本辖区违法用地行为和违法勘查采矿行为，及时向市领导小组办公室报告。

市财政局负责落实三亚市土地矿产卫片执法监督检查工作的后勤保障工作，将专项行动所需工作经费纳入年度财政预算，以确保三亚市土地矿产卫片执法监督检查工作顺利开展。

市人力资源和社会保障局、市发展和改革委员会、市住房和城乡建设局、市交通运输局、市科技工业信息化局等部门按照各自职责，协同做好土地矿产卫片执法监督检查工作，配合对未取得合法用地、勘查开采手续的建设项目进行查处并监督落实整改。

三、工作安排

（一）自查整改阶段（2014年5月至7月）

5月至6月，结合三亚市2013年度土地变更调查工作，发现并积极查处整改违法用地行为；对省国土环境资源厅下发三亚市的2014年矿产卫片执法检查工作图件数据组织实地核查、整改和查处工作，并做好开展2014年土地矿产违法执法检查工作的各项准备工作。7月，对省国土环境资源厅下发三亚市的2014年土地卫片执法检查工作图件数据，逐一组织实地核查、判定图斑性质，开展查处和整改工作。

（二）监督检查阶段（2014年7月至8月）

按照国土资源部、省国土环境资源厅的工作部署，及时向省国土环境资源厅报送初步数据成果，迎接省国土环境资源厅对三亚市组织实地核查、查处和整改工作的监督检查。

（三）验收总结阶段（2014年8月至9月）

及时向省国土环境资源厅报送最终数据成果，做好2014年度土地矿产卫片执法监督检查工作的总结工作，按照国土资源部和省国土环境资源厅的要求进行整改纠正。

四、工作要求

（一）加大宣传，统一思想

各有关部门要充分利用报纸、电视、电台、网络等新闻媒体全方位、多形式、多层次的宣传教育，正确舆论导向；保持对违法用地、违法勘查开采矿产资源行为的高压打击态势，做到查处一案，处理一人，教育一片。

（二）加强协作，形成合力

为做好三亚市2014年土地矿产卫片执法监督检查的各项工作任务，各部门必须高度重视，在市政府领导下明确分工，落实责任，精心组织开展土地矿产卫片执法监督检查工作，形成工作合力，做到机构、人员、经费三落实。

（三）严肃查处违法行为

土地矿产卫片执法监督检查工作，市国土环境资源局要按照国土资源部和省国土环境资源厅的统一要求正确掌握相关政策和技术要求，严格执行各项政策标准，结合年度土地变更调查、国土资源“一张图”统一监管平台等认真开展核查工作，对发现的违法用地、违法勘查开采矿产资源行为，要严格把关、依法查处，认真落实整改工作。对检查中发现的违法行为，未依法处理的一律不得办理相关审批手续，要坚持既查事、又查人的原则，对违反党纪政纪的，要及时向监察局提出处分建议；对涉嫌犯罪的，要依法移送司法机关。

（四）确保各类数据真实、准确

市国土环境资源局要切实采取有效措施，逐级落实责任，确保上报的各类数据真实、准确。2014年土地矿产卫片执法监督检查工作的各类表格，填表人必须签名，并对填报内容的真实性、准确性负直接责任；各级领导要认真审查，严格把关，审核签字，并对填报内容的真实性、准确性负领导责任。数据上报须经市土地矿产卫片执法监督检查工作领导小组组长审核签字。

（五）按时完成各项工作任务

土地矿产卫片执法监督检查工作中，各部门要严格按照本方案的时间节点和工作要求按时完成各项工作任务，及时上报土地矿产卫片执法监督检查工作情况报告和相关数据，做好国土资源部的阶段性监督检查和年末验收工作。
