# 三亚市人民政府办公室关于印发三亚市大隆水库库区移民村整村推进扶贫工作方案的通知

三亚市人民政府办公室

关于印发三亚市大隆水库库区移民村整村推进

扶贫工作方案的通知

各区筹备组，各管委会，市各有关单位:

《三亚市大隆水库库区移民村整村推进扶贫工作方案》已经六届市政府第29次常务会议通过，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2014年9月25日

（此件主动公开）

三亚市大隆水库库区移民村整村推进扶贫工作方案

为切实解决天涯区布甫移民村生产生活困难的问题，促进三亚社会的和谐发展，特制定本工作方案。

一、指导思想

认真贯彻落实党的群众路线教育实践活动市政府党组专题民主生活会上提出的关于“重视解决库区移民生产、生活问题”的整改工作要求，立行立改，以整村推进扶贫为抓手，从农业发展、生态保育、社会事务、环境整治等四个方面着力解决大隆水库天涯区布甫移民村的生产生活困难等问题，确保移民生产生活水平高于全市平均水平，促进三亚社会和谐发展。

二、天涯区布甫移民村现状及存在问题

全村农户133户共702人，生产用地面积511亩，人均耕地0.72亩。目前该村存在以下主要问题：

（一）移民回迁问题。由于当时对移民原先在库区宁远河上游北岸种植的橡胶、槟榔等经济作物因未被淹没而未给予补偿，移民认为属于自有财产，有权继续经营管理，加上现居住地生产生活条件相对困难，近些年来除老弱人员外大部分村民又长途往返原居住地，从事原先种植的经济作物的生产管理等。

（二）移民就学就医困难问题。由于移民回流，部分移民子女也分散在天涯、育才求学，交通等生活成本增大，移民就医比较困难，特别是移民经常摆渡库区宁远河上游存在严重的交通安全隐患，影响库区生态环境保护。

（三）移民增收困难问题。该村责任田土质为沙壤土，不保水且肥力较差，不宜种植水稻，迫切需要改良土壤。同时，该村509亩安置生产用地已承包给有关农业企业却长期闲置，未发挥产业带动和解决移民就业作用，移民缺乏就业技能和农业生产技术方面的培训，收入渠道不宽，增收困难。

（四）移民户籍管理问题。大部分村民未把户口迁至天涯区，造成天涯、育才属地管理不顺畅，移民办事不便。

（五）移民社会保障问题。部分村民未参加农村养老保险，缺乏养老保障。

（六）移民环境基础落后问题。村容村貌和基础设施条件较差，人居环境有待改善，人畜饮水主要靠机井抽取地下水至蓄水池饮用，人畜安全饮水有困难。

三、整村推进扶贫的主要任务

（一）发展特色农业，促进移民增收。

1.大力发展兰花产业。天涯区布甫村按照1800元/亩的标准以118.43亩土地入股三亚柏盈热带兰花产业有限公司，联合进行建设兰花种植、加工、研发等农业综合开发产业项目，所得的土地承包金全部安排给布甫村作为集体经济收入，并由村集体进行统一分配，并带动40―80名农民就业，增加移民收入。市财政局按我市兰花产业发展的补贴办法给予相应的扶持。（责任单位：市林业局、市财政局、天涯区。）

2.积极推进冬季瓜菜生产。通过进一步补充完善布甫移民村与三亚好运通农业科技有限公司（以下简称“好运通公司”）签订的农业用地租赁合同，充分发挥509亩已租赁农用地的使用价值，适当提高好运通公司所租用的土地租金标准，提高移民土地收益。同时，为进一步改变农用地闲置状况，市农业局负责在加强地力保育改良土壤的基础上，发放豆角等种子种苗，帮助布甫村移民种植冬季瓜菜509亩，并扶持肥料等农用物资和加强农产品质量监管。市南繁技术研究院、市农业技术服务推广中心负责加强种植技术培训指导、病虫害防治工作。市科技工业信息化局负责配套10盏太阳能灭虫灯。市财政局农综办负责修缮水利渠，解决瓜菜生产灌溉用水问题（责任单位：市农业局、市科技工业信息化局、市财政局农综办、市南繁技术研究院、市热带农业科学研究院、市农业技术服务推广中心、天涯区）

3.适当扶持畜牧养殖产业。由市畜牧兽医局牵头，天涯区配合，根据移民关于发展畜牧养殖的实际需求，在布甫移民村附近规划建设15亩的集中式养猪场并配套沼气设施，以购猪补贴的方式扶持有养猪意愿的移民发展畜牧养殖产业（先期扶持养猪400头）。（责任单位：市畜牧兽医局、市财政局、天涯区）

（二）实行生态补偿，维护移民权益。

据育才生态区管委会初步调查统计，涉及大隆水库宁远河上游北岸种植经济作物的村民小组共有9个(含原那会、那抗、那练村民小组)共379户1864人，种植经济作物地块有1680块共19322.3亩，以种植橡胶（15393.7亩,占79.7%）、槟榔(3264.4亩,占16.9%)为主。为保护这一重要的水源林保护区和抱龙国家天然林保护工程林区，市林业局、育才生态区管委会等有关单位要加强协作，在进一步核实经济作物种植情况的基础上，研究拟定大隆水库生态养护补偿办法，对在北岸已种植经济作物的移民实行适当的生态养护补偿，并关闭取缔临时渡口，解决渡口的安全隐患问题，并对北岸地区实行封山育林，禁止移民再返回原居住地，严格保护当地生态环境。（责任单位：市林业局、市水务局、市财政局、市安全监管局、市交通运输局、三亚海事局、育才生态区管委会）

（三）提高生活补贴，改善移民生活。

在原有发放给大隆水库移民个人的后期扶持资金（每人每年600元分四个季度按时直接打进农户个人在农村信用合作社开通的“一卡通”账户，从2006年开始扶持20年）的基础上，市水务局牵头负责进一步核定应纳入扶持范围的天涯区布甫移民村村民，市财政局按照每人每月50元的标准从2015年1月起再发放生活补贴（共持续发放11年），进一步改善大隆水库库区移民生活条件，对其他库区移民村的有关补助办法可以参照上述办法另行制定。（责任单位：市水务局、市财政局、天涯区、育才生态区管委会）

（四）强化齐抓共管，力解移民困难。

1.加快户籍转移，理顺属地管理。建立户籍转移办理联合工作组，做好移民信息核实、思想教育等方面工作，公安部门具体负责，统一把移民户籍从育才镇转移至天涯镇，进一步理顺户籍管理等相关问题。（责任单位:天涯区、市公安局）

2.落实社会保障，力争应保尽保。按照全市统一标准，一是广泛动员符合条件村民全部参加农村养老保险。二是研究解决移民医疗救助问题，对患大病、重病、长期慢性病或重度残疾移民，要加大医疗援助力度。三是积极开展移民生活救助工作，把人均家庭生活标准低于当年最低生活标准的困难移民户全部纳入低保范围，做到应保尽保。（责任单位：天涯区、市人力资源和社会保障局、市卫生局、市民政局）

3.促进就近入学，解决教育难题。根据移民子女就学在育才生态区管委会的实际情况，在充分尊重移民意愿的基础上，尽可能动员移民将子女全部转移到天涯中小学校就近就地入学，并解决学生的寄宿、交通问题，确保其平等受教育的权利。（责任单位：市教育局、天涯区）

4.加强技能培训，促进就业增收。各有关单位要充分整合各类培训资源，加强对移民的兰花种植、瓜菜种植等农业技术培训（300人次）和转移就业培训（200人次），促进移民转变就业观念，掌握一种或多种农业技术和就业技能，增强移民的自我发展能力和就业竞争力。要为移民提供更多的就业岗位、资金、技术、经营场所等有关方面的支持，并采取各项措施努力推进库区移民实现自主创业自我就业，每年安排一定数量的具有劳动能力和创业意愿的移民青年到市南繁技术研究院进行技能学习培训。（责任单位：市人力资源和社会保障局、市农业局、市南繁技术研究院）

5.推进基础建设，整治村容村貌。一是加快推进村生活区太阳能路灯（5套）建设、村庄绿化（每户20株菠萝蜜树苗共2660株），移民住房改造、排污及围墙等基础设施建设，创造良好生活环境；二是加强自来水入户工程建设及后续的运行管理，改变该村移民依靠抽取地下水生活的状况，保证人畜饮水安全；三是加强环境卫生整治，配齐配全保洁员和卫生清理设备，规划建设垃圾池和转运设施，建立环境整治长效机制，确保村容村貌整洁有序。（责任单位：市委农工委、市林业局、市水务局、市农业局、天涯区）

四、工作要求

（一）加强领导，密切协作，积极主动开展工作。成立由分管农业副市长为组长，各责任单位为成员的三亚市大隆水库库区移民村整村推进扶贫工作领导小组，各责任单位要将此项工作列入重要议事日程，认真按照方案安排的工作任务组织实施，并加强组织协调，形成整体合力，按期完成任务。同时，有关单位要加强库区水上交通安全管理和生态环境保护，多措并举杜绝安全事故隐患，确保人民生命财产安全。

（二）加强督查，明确进度，确保任务顺利完成。市政府就此项工作加强督查督办，要求从方案印发的月份开始，各责任单位每月28日前向市政府督查议案室报送工作情况，主要报告工作进度、存在问题、建议措施等，市政府督查议案室汇总整理后于下月初上报市政府。各责任单位完成工作情况将纳入市政府年度工作考核内容进行考核，无故未按期完成任务的将实行问责。
