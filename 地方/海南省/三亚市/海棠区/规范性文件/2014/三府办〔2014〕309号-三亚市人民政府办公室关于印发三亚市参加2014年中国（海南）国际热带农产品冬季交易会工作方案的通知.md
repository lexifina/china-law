# 三亚市人民政府办公室关于印发三亚市参加2014年中国（海南）国际热带农产品冬季交易会工作方案的通知

三亚市人民政府办公室

关于印发三亚市参加2014年中国（海南）国际热带

农产品冬季交易会工作方案的通知

各区筹备组，各管委会，市政府各相关单位：

《三亚市参加2014年中国（海南）国际热带农产品冬季交易会工作方案》已经市政府同意，现印发给你们，请认真贯彻执行。

三亚市人民政府办公室

2014年11月26日

（此件主动公开）

三亚市参加2014年中国（海南）

国际热带农产品冬季交易会工作方案

2014年中国（海南）国际热带农产品冬季交易会（以下简称“冬交会”），将于2014年12月12日至15日在海南（海口）国际会展中心举行。按照省委、省政府的统一部署和具体要求，做到早安排、早策划、早布置、早落实，确保2014年冬交会的各项筹备工作真正落到实处，特制定本方案。

一、主题和原则

本届冬交会我市以“质量塑造农业品牌，电商促进市场营销”为主题，坚持“改革、创新、务实、节俭、高效”的办会原则，突出宣传我市优越的生态环境和资源优势，充分展示我市热带特色农业发展成果，推动我市农业向品牌化、产业化、市场化、网络化发展，加强与内地市场及客商的联系和沟通，促进我市农副产品与内地市场的衔接，促进我市农业增效和农民增收。

二、组织机构

（一）三亚市代表团

团长：吴岩峻（市委副书记、市政府代市长）

副团长：岳进（市委常委、市政府常务副市长）

成员：相关职能部门领导，各区筹备组负责人，龙头企业代表，种植大户代表，农民专业合作组织代表，受邀请的省外客商，销地市场检测负责人和农产品质量安全信息主管部门负责人，三亚市参加“冬交会”工作人员。

筹备领导小组下设办公室，办公室主任由市农业局李劲松局长担任，具体负责全面工作，办公室设在市农业局，内设5个工作小组：

1．会务组：由市农业局冯永杰副局长负责，负责工作组日常工作；负责参会人员的确定、邀请、联络协调，会议日程和会务安排，各种证件、礼袋的发放，经费预算方案的拟订、订单、签约，总结撰写等材料工作。

2.招商组：由市农业局曲环副局长负责，负责项目的策划、包装和推介；负责落实订单、招揽客商和交易情况统计等工作。

3．宣传组：由市农业局董朝周副局长负责，负责宣传报道和新闻发布工作，组织新闻单位跟踪采访报道；负责产品简介材料的编印和宣传品的制作发放和网上宣传等。

4．接待组：由市农业局董朝周副局长负责，负责与会人员的接送、报到，住宿安排和会后活动的组织，代表团和被邀客商等驻会人员的车辆安排和生活管理。

5．布展组：由市农业局冯永杰副局长负责，负责布展设计，组织展品参展。

参会工作人员由“冬交会”筹备工作领导小组根据需要从有关单位抽调。

三、重点工作内容及任务分解

（一）邀请客商、落实订单

时间：9月23日—12月11日

工作内容：市农业部门要组织各区农业部门和农业龙头企业、农业专业合作组织赴内地考察市场，寻找订单，认真研究客商邀请对象，切实把对三亚农产品市场开拓能够发挥作用以及能够拿到实实在在订单的客商邀请到三亚来，保证高质量的客商和订单。今年要邀请一些大型采购团、联盟成员和网络销售人员。长沙、武汉、广州等地市场检测负责人和农产品质量安全信息主管部门负责人。（责任单位：市农业局）

（二）布展筹备工作

时间：10月8日—12月11日

工作内容：

活植株：主要突出我市将要推出的新的农产品。要提早做好活植株的培育工作。（责任单位：市农业局）

展品：冬季瓜菜、热带水果、畜禽产品由各区推荐或生产企业（合作社）自荐，市农业局审核后参展，所有展品要具有包装和品牌，水果和瓜菜必须由市现代农业检验检测预警防控中心通过定量检测合格后方能参展。林产品和花卉产品由市林业局负责提供，水产品由市海洋渔业局负责提供。

展馆：对三亚展馆设计方案进行征集，展馆要坚持“简约、明快、实用”的原则。展示我市热带果蔬、林产品、水产品、畜禽产品、花卉产品、热作产品、休闲农业、品牌和包装及现代电子商务等，充分突出我市热带特色现代农业发展成果和标准化种植园区建设。于10月28日前设计出我市布展设计平面图和效果图送省筹备办公室审定。（责任单位：市农业局）

12月11日所有工作人员、参展单位、展示产品全部到位。（责任单位：市农业局）

（三）参加开幕式

我市代表团全体成员参加12月12日上午9:00在海南国际会展中心前广场举行的主会场开幕式。

市农业局负责组织代表团全体成员参加开幕式，各区负责组织本辖区内参会人员参加开幕式。

（四）组织参加冬交会系列活动

时间：12月11日—12月15日

工作内容：参加采购团现场洽谈和订单签约活动，组织生产商、电商、物流商“三商”现场洽谈对接活动，参加农业高新技术成果推介转让会、海南休闲农业高峰论坛、热带农业海上丝绸之路战略研讨会和品牌农业系列宣传等活动。召开三亚市驻省外20个农产品流通办事处主任工作会议，组织全国各地客商召开产销座谈会、参观我市农业基地等。（责任单位：市农业局）

四、工作要求

（一）加强领导。各责任单位必须加强组织领导，明确工作任务，落实责任，明确分工，协调相关部门和企业，抓好各项工作的落实。

（二）落实经费。经费安排。市农业局要按照年初预算安排落实相关经费，确保筹备工作顺利展开。

（三）做好宣传。一是组织驻三亚媒体记者，对“冬交会”的全程进行采访报道，营造气氛，扩大影响。“冬交会”期间，要采用专题报道、系列报道、专访等多样形式开展宣传。二是要编印宣传资料，组织有关人员编写《三亚农业》等宣传资料，制作三亚热带高效农业多媒体专题片，全方位介绍三亚丰富的热带农业资源、优美的旅游景观、良好的投资环境和独特的农副产品等。三是要开展网上宣传和贸易。从10月份开始，在市农业信息平台上推出介绍三亚农业的基本情况，介绍三亚龙头企业和种植运销大户，多途径地扩大宣传，部分产品实现网上贸易。

（四）抓好促销。市各相关部门要主动积极组织企业与产销大户进行市场调研，根据我市冬季农产品上市时间早的特点，及早组织相关企业代表到销地市场开展产销对接、订单洽谈等活动，确保会展期间的订单贸易和项目招商取得新突破。

（五）精选展品。认真筛选展品，突出我市的特色和实施精品立市的战略，高质量、严要求，杜绝“无证”产品等参展，打造三亚无公害农产品精品，主要包括冬季瓜菜、热带花卉、热带水果和农产品加工品等。

（六）搞好总结。本次“冬交会”任务重、规模大、规格高。因此，各单位要以高度负责的态度认真抓好抓实，会后要认真进行总结，找出不足，以便在今后的“冬交会”中把活动办得更好。
