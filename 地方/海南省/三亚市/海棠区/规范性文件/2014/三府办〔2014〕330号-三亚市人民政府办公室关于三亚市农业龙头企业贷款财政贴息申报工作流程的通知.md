# 三亚市人民政府办公室关于三亚市农业龙头企业贷款财政贴息申报工作流程的通知

三亚市人民政府办公室

关于三亚市农业龙头企业贷款财政贴息申报工作流程的通知

市财政局，市金融办，市农业局，市林业局，市海洋与渔业局：

根据《三亚市人民政府关于印发三亚市农业龙头企业贷款财政贴息扶持资金管理办法的通知》（三府﹝2014﹞135号）要求，为做好我市农业龙头企业贷款财政贴息申报、审核和发放工作，经市政府同意，现将我市农业龙头企业申报贷款财政贴息工作流程及相应审批表格规范通知如下：

一、每年7月进行当年度上半年贴息申报审核，次年1月进行前年度下半年贴息申报审核。

二、市农业局、市林业局、市海洋与渔业局在当年7月及次年1月最初5个工作日内通知辖下龙头企业申报贴息，申请贴息的龙头企业填写《三亚市农业龙头企业贷款贴息申请表》（见附件1）并按照主管部门要求提供相关材料。

三、市农业局、市林业局、市海洋与渔业局在10个工作日内完成申报贴息材料的审核，填写《三亚市农业龙头企业贷款贴息企业名册》（见附件2）加盖公章及龙头企业相关贴息资料（贴息申请表、三府﹝2014﹞135号文件申报所需材料的复印件）送市金融办。

四、市金融办在收齐农业、林业、海洋渔业等部门审核资料后在5个工作日内填写《三亚市农业龙头企业贷款贴息汇总表》(见附件3)、出具审核报告（农业、林业、海洋渔业等部门的审核材料作附件）报市财政局。

五、市财政局审核确认后在5个工作日内发放贴息。

六、每年9月初，市农业局、市林业局、市海洋与渔业局根据本行业龙头企业生产经营情况，拟定下一年度贷款资金需求送市金融办，由市金融办汇总后，向市财政局报送贴息资金需求预算计划，由市财政局列入下一年度预算内统筹安排。

七、市农业局、市林业局、市海洋与渔业局未按时通知龙头企业申报贴息或农业龙头企业未按时申报贴息材料的，视为放弃贷款贴息要求，事后不予补报。

附件：1.三亚市农业龙头企业贷款贴息申请表

2.三亚市农业龙头企业贷款贴息企业名册

3.三亚市农业龙头企业贷款贴息汇总表
