# 三亚市人民政府办公室关于印发三亚市2014年金融改革创新实施意见的通知

三亚市人民政府办公室

关于印发三亚市2014年金融改革

创新实施意见的通知

各镇人民政府，各区管委会，市政府各有关单位：

《三亚市2014年金融改革创新实施意见》已经市政府同意，现印发给你们，请认真贯彻执行。

三亚市人民政府办公室

2014年4月8日

（此件主动公开）

三亚市2014年金融改革创新实施意见

2014年是全面贯彻落实党的十八届三中全会精神的开局之年，也是实施“十二五”规划承前启后的关键一年，更是我市金融改革创新发展的重要一年。根据《海南省人民政府办公厅关于印发海南省2014年金融改革创新指导意见的通知》（琼府办〔2014〕22号）精神，结合我市实际，现就我市2014年金融改革创新工作提出如下实施意见：

一、指导思想

按照党的十八届三中全会及中央和省、市经济工作会议精神，深入贯彻落实科学发展观，认真执行国家经济金融政策，坚持服务实体经济、坚持改革创新，继续优化金融对重要产业、重点企业和重大项目的服务，加大对“三农”和小微企业等薄弱领域的金融支持，全面提升金融服务国际旅游岛建设的能力和水平。

二、总体目标

力争信贷投放平稳较快增长，直接融资渠道不断拓宽，保险保障与投资功能有效发挥，金融服务体系继续完善，金融改革持续深化，金融创新开放有序推进，金融发展环境进一步优化，金融服务国际旅游岛建设能力显著增强。金融业各项指标继续保持较快增长，金融业增加值争取达到48亿元左右，占全市GDP比重达到11%左右，占第三产业增加值比重达到17%左右。贷款余额同比增速11%左右，新增贷款70亿元左右，贷款余额达到683亿元，存款余额同比增速11%左右，新增存款103亿元左右，存款余额达到1033亿元，保险公司保费收入达到10亿元以上，保费收入增速达到18%左右。

三、主要任务

（一）加快金融服务体系建设。一是做好跟踪落实和服务，推进光大财险总部落户，争取中信银行三亚分行设立，完成西安中盈基金公司、海南中度实业公司设立的基金落户工作，根据我市撤镇设区工作，支持和引导产业基金落户三亚，完善各区金融服务网点布局。二是协助海棠湾企业绿都园区、国际金融产业聚集区、财经论坛永久会址和阳光金融广场的开发建设，发挥优惠政策的吸引作用，引导金融企业进驻海棠湾现代服务业试验区。三是加大招商力度，变企业上门提出合作条件为主动上门有针对性的引进企业，争取吸引效益好、知名度高的金融机构在三亚设立分支机构。四是积极引导民间资本发起设立基金管理公司、小额贷款公司、担保公司等地方民营金融组织。（市金融办、市海棠湾管委会、三亚银监分局负责）

（二）增加有效信贷投放。一是根据全市经济发展需求和产业政策导向，盘活存量，用好增量，加强人民银行窗口指导和行业对接，把握信贷投放总量、结构和节奏，保持信贷规模适度增长，引导银行业优化信贷结构，支持银行开发海洋经济方向的信贷市场，加大对支柱产业、新兴产业、现代服务业以及重点项目的信贷支持力度,扩大信贷规模。二是鼓励金融机构加强对三农、小微企业以及就业、助学、扶贫等薄弱环节的金融支持。三是完善金融运行分析工作机制，定期召开金融运行分析会议，提升政策贯彻实施的指导性，积极引导金融机构领会货币政策意图，正确把握好实施稳健货币政策的力度，结合经济发展特点，合理调整信贷结构，促进经济稳步发展。（人行三亚市中心支行负责）

（三）推动多层次资本市场建设。一是以新股发行体制改革为导向，加大上市资源培育，形成一批发展良好的企业后备资源，支持符合条件的企业加大上市、“新三板”挂牌工作推进力度。争取新大兴公司今年申报首发材料、“新三板”有突破。二是发展金融要素交易市场。积极鼓励市中小企业信用担保公司设立海南金融资产交易中心，解决我省非上市公司债券交易与融资问题，盘活企业存量资产，拓宽投融资渠道。三是支持基金、信托、金融租赁等新业态发展，鼓励资本参与企业并购重组和上市，以资本为纽带整合热带旅游资源，促进产业结构调整升级，引导民间资金进入省、市重大项目建设和优质企业等实体经济领域。（市金融办负责）

（四）促进保险业健康快速发展。一是督促阳光人寿保险公司总部落实协议约定，加大对三亚的业务拓展，争取尽早设立业务发展机构，通过培育保险主体、创新保险品种推动总部企业发展。二是完善农业保险试点工作机制，加强农业保险基层服务站点建设，积极稳妥开展农业保险试点。三是鼓励保险机构创新保险品种，开发符合我市高端旅游发展的保险产品。（市金融办、市财政局负责）

（五）务实推进金融改革与创新开放。一是加快离岸金融业务试点工作研究，为市政府决策提供可行参考意见，力争试点工作在我市取得突破。二是创新金融支持海洋经济、三农经济和小微企业模式，探索建立农村土地承包经营权、海洋权益抵押贷款登记制度，拓宽“三农”有效抵押资产。三是大力推动金融机构开展产品与服务创新，鼓励民生银行、国家开发银行探索开展贷款新模式，开发新的信贷市场，鼓励三亚农商银行等涉农金融机构利用森林资源开发林权抵押贷款业务。四是继续加强农户征信系统建设，完成农户信贷和经济信息采集入库任务，拓展涉农金融网点联网，发挥系统信用导向作用。五是改进外币兑换方式，促进辖区外币兑换便利化。（市金融办、市农业局、市海洋与渔业局、人行三亚市中心支行、三亚银监分局负责）

（六）大力发展普惠金融。一是大力发展新型农村金融。鼓励金融机构提高对中小微企业和“三农”支持力度，力争实现“两个不低于”目标。引导村镇银行、小额贷款公司拓宽“三农”资金来源，支持信用担保机构不断壮大，鼓励更多的资金进入小额贷款、担保领域，加强对农业、服务业、商贸、高科技等行业的中小微企业、个体工商户的金融服务。二是加强中小微企业、涉农企业与政府、银行、担保企业间的联系和信息沟通。三是进一步改善三亚农村地区支付服务环境，鼓励银行业收单机构积极发展助农取款服务点，选取瓜果蔬菜集散地推广银行卡及非现金支付方式的应用。继续推动三亚刷卡无障碍城市建设，拓展金融IC卡在旅游、农业等领域的使用。四是发挥财政资金引导作用，调整和完善农民小额贷款贴息政策，继续推进农民小额贷款贴息工作，扩大政策惠及面。市财政全年安排400万元财政资金用于贴息，撬动全市发放50万元以下农民小额贷款和100万以下农民专业合作社贷款24853万元以上，其中10万元以下农民小额贷款和100万以下农民专业合作社贷款5762万元以上。（市财政局、市金融办、人行三亚市中心支行、三亚银监分局、三亚农商银行、农业银行三亚分行、邮储银行三亚分行负责）

四、保障措施

（一）创新工作联动机制，切实加强组织领导。一是要与金融监管部门保持良好的沟通与合作，形成合力，加强对金融工作的指导与服务，协调解决金融机构在发展中出现的问题，争取在我市开展金融领域改革创新试点工作。二是各相关单位要从经济社会发展全局和战略的高度重视金融业发展，切实加强组织领导和协调服务，不断优化发展环境，形成支持金融业发展的整体合力，为把金融业打造成为我市支柱产业创造良好条件。（人行三亚市中心支行、三亚银监分局、市发改委、市财政局、市金融办按职责分工负责）

（二）健全支持政策体系，用好用足政策。一是不断完善我市优惠政策，鼓励金融机构适度竞争发展，增强金融业的集聚和辐射带动能力。二是要强化部门协作，认真督促已出台金融业发展支持政策落实到位，探索建立对金融机构支持地方发展的激励机制，最大限度地发挥政策支持经济金融发展的作用。（市财政局、市金融办负责）

（三）防范金融风险，优化金融生态环境。一是加强风险防范体系建设，健全金融业综合统计和分析，建立多层次、全覆盖、高效率的金融风险预警机制，加强对地方政府融资平台、房地产、影子银行、民间金融等重点领域的监测分析，大力整治非法集资等非法金融活动，严厉打击金融犯罪，排查化解各类风险隐患，严守不发生系统性、区域性金融风险的底限，维护我市金融稳定。二是加强与省金融办等省级部门、银证保等监管部门、金融机构和外部的沟通联系，宣传三亚的区位优势和政策，争取更多的金融机构了解三亚、支持三亚。（人行三亚市中心支行、三亚银监分局、市公安局、市金融办按职责分工负责）
