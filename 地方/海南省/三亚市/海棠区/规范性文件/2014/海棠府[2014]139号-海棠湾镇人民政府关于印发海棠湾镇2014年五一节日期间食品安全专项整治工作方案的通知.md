# 海棠湾镇人民政府关于印发海棠湾镇2014年五一节日期间食品安全专项整治工作方案的通知

三亚市海棠湾镇人民政府文件

海棠府[2014]139号

海棠湾镇人民政府

关于印发海棠湾镇2014年五一节日期间

食品安全专项整治工作方案的通知

各村（居）委会、各部门：

《海棠湾镇2014年五一节日期间食品安全专项整治工作方案》经镇政府同意，现予以印发，请认真组织实施。

特此通知。

海棠湾镇人民政府

2014年4月30日

（此件主动公开）

海棠湾镇2014年五一节日期间食品

安全专项整治工作方案

为了保障我镇五一期间食品安全，确保人民群众身体健康和生命安全，严防发生重大食品安全事故，经镇政府同意，决定开展五一期间食品安全专项整治行动。具体实施方案如下：

一、组织领导

为切实做好我镇五一期间食品专项检查工作，指导协调节日市场专项整治工作，镇政府成立节日市场专项整治领导小组。领导小组成员如下：

组 长：严连勇（海棠湾工委副书记、镇委副书记、镇长）

副组长：黄 锐（镇人大副主席）

成 员：谭小强（海棠湾工商所所长）

赵辉城（藤桥派出所所长）

方 伦（林旺派出所所长）

陈孝强（市执法局海棠湾执法分局局长）

黎运雄（镇农业服务中心主任）

关心光（林旺中心卫生院院长）

黄满忠（藤桥卫生院院长）

程方虎（镇食安办主任）

各村（居）委会书记

二、工作目标和整治重点

（一）严把节日市场准入关，大力打击无证生产经营行为，严厉查处无QS认证食品、不合格食品以及假冒伪劣食品等违法行为，针对节假日特点，加大重点品种、重点区域、重要环节、重要时段的食品安全专项整治，防止食品安全事故的发生，切实保障人民群众节日饮食安全。

（二）对辖区内学校食堂、建筑工地食堂、农家乐、海鲜渔排、旅游景区等人员集中餐饮场所及农贸市场、饮食摊点、食品加工小作坊等重点场所开展全面检查、专项整治和联合执法检查。

（三）突出节日消费量大、消费者申诉举报多以及群众日常生活必需的食品，突出乳制品、粮食制品、肉制品、食用油等重点品种，突出农村、城乡结合部、城市社区、旅游景区及车站码头等重点区域，以商场、超市、批发市场、集贸市场、食品店为重点场所，有针对性地集中开展专项执法检查，严厉打击销售不符合食品安全标准食品，特别是有毒有害食品的违法犯罪行为。

（四）认真做好群体性聚餐监管，特别是农村5桌以上集体聚餐监管工作，防止群体性食物中毒事件的发生。

（五）加强组织领导，采取切实有效措施，把食品安全属地监管责任制落到实处。坚持重大事项报告制度，及时果断妥善处置食品安全突发问题，确保节日食品消费安全。

三、整治责任分工

（一） 加强对农产品安全知识的宣传力度，配合市农业局加强对蔬菜、水果、水产品等农兽药和禁用药物残留监测，加大监督力度，严把“瘦肉精”的使用和水产品甲醛超标问题。（责任单位：农业服务中心、工商所）

（二）重点查处无食品流通许可证、无工商营业执照的非法生产经营行为，加强对农贸市场、批发市场、超市和个体商店的监督检查，检查进货索证查验、购销登记台账制度的落实情况，检查是否存在销售无QS认证食品、假冒伪劣食品、过期食品，加强对节日期间海鲜排档的监管，杜绝欺客宰客事件发生。（责任单位：工商所、派出所、食安办）

（三）加强对旅游景点、学校、幼儿园和建筑工地等集体用餐单位的监管，加强对各类小食店的监管，严厉查处无餐饮服务许可证、无工商营业执照的非法生产经营行为，严禁“地沟油”和一次性筷子的使用，防止食物中毒事故发生。（责任单位：食安办、餐饮监管站、工商所）

（四）打击生猪私屠滥宰，依法取缔非法生产加工窝点，规范生猪屠宰的管理，加强对定点屠宰厂的监管，坚决查处销售“注水肉”和“病害肉”及其产品的违法违规行为，落实进货索票索证制度，确保商贩进货渠道及销售的产品符合安全要求。（责任单位：工商所、执法分局、派出所）

（五）农村地区食品安全的监管

严厉打击各种利用节假日期间制售假冒伪劣食品和过期霉变、有毒有害食品的行为，防止不合格食品在城市形成打击高压态势后向农村市场转移的情况发生。加强农村集体聚餐活动的备案管理和监督指导，保证群众用餐安全。（责任单位：镇食安办、工商、卫生院、各村委会）

四、工作要求

（一）要高度重视，加强领导，确保节日食品安全。各成员单位要把加强节日期间食品安全工作当做目前的重点工作，结合各自部门实际，制定专项检查工作计划，明确工作目标，完善工作措施，切实防止重大食品安全事故的发生。

（二）严厉查处制售假冒伪劣食品的违法行为。对节日食品市场存在的问题必须做到早发现、早治理、早规范。在整治行动中发现问题要及时处理，限期整改，涉嫌违法违规行为的，要由相关部门依法处罚，构成犯罪的，及时移交司法机关处理。

（三）建立食品安全投诉举报制度。凡食品安全的投诉，要快速反应，特别是因食品质量而发生中毒事故的要在第一时间赶到现场，及时上报情况，控制事态蔓延，将影响和损失降到最小程度，同时要查清事故的原因，并及时向上级报告。

（四）严格落实责任制。各部门要严格按照职责分工，责任到人，做到认识到位，检查到位，处理到位，对因工作不力出现问题的，要追究单位主管人员和相关人员责任。要加强值班，落实责任，切实做好应急准备。要认真落实节日期间值班制度，保证举报投诉电话畅通。对群众举报投诉的食品安全事

件，要认真受理，及时应对。

（五）各部门要加强联系，密切配合。在镇食品安全领导小组统一领导下，加强沟通，整合部门资源，提高执法水平，落实食品安全监督管理制度。行动期间要加强信息沟通和反馈，及时将整治情况报送镇食安办。镇食安办负责做好此次整治行动的信息收集、整理，并及时上报市食安办。

海棠湾镇党政办公室 2014年 5月8日印发
