# 海棠湾镇人民政府关于印发海棠湾镇2014年食品安全工作实施方案的通知

海棠湾镇人民政府

关于印发海棠湾镇2014年食品安全工作

实施方案的通知

各村（居）委会、各部门：

《海棠湾镇2014年食品安全工作实施方案》经镇政府同意，现予以印发，请认真组织实施。

特此通知。

海棠湾镇人民政府

2014年4月30日

（此件主动公开）

海棠湾镇2014年食品安全工作实施方案

为进一步做好我镇2014年食品安全监管工作，消除食品安全隐患，维护人民群众饮食安全和身体健康，确保我镇无食品安全事故发生，根据市政府有关工作要求，结合本镇实际，制定实施方案如下：

一、工作目标

2014年食品安全工作的主要目标是在市委、市政府的正确领导下，大力践行科学监管理念，落实监管责任，坚持标本兼治、着力治本，继续深化食品安全治理整顿，加大严惩重处力度，切实解决影响人民群众食品安全的突出问题，坚决遏制食品安全违法行为多发态势；进一步完善食品安全监管体制和制度，努力消除监管盲区、死角，健全食品安全监管长效机制；加强食品安全监管力量，努力提高食品安全监管能力，促进食品安全水平不断提高。

二、主要工作

（一）加强宣传教育和培训学习。一是认真抓好食品安全重要政策措施的宣传教育工作。深入开展“食品安全周”宣传教育活动，加强食品安全法制宣传、诚信自律宣传和科学常识普及，提高食品生产经营者的守法意识，提高消费者对食品安全风险的科学认知水平。二是加大食品安全宣传培训力度。要加强对村级食品安全信息员和乡村厨师有关农村集体聚餐申报工作的培训，使农村集体聚餐申报工作走向规范化。对镇区酒类经营者进行有关法律法规的培训，让经营者懂法守法。三是充分发挥社会和媒体监督作用。鼓励群众投诉举报，支持新闻媒体开展舆论监督，及时公布根据群众投诉举报和媒体监督查处的食品安全违法行为信息。曝光典型案件，揭露不法分子危害群众健康的恶劣行径。

（二）加强日常监管。各职能部门要按照各自分工加强对辖区内食品源头、生产加工、流通和消费环节的日常监管。加强对农村集体聚餐食品安全管理、餐饮卫生监督管理，把日常监管落实到实处，建立食品安全良好秩序。

（三）开展食品安全专项整治工作。以继续深入开展食品安全专项整治为切入点，针对问题多发场所、单位和监管薄弱领域以及重点品种，治隐患、抓反复、防反弹，将专项整理工作引向深入，确保节日和日常生活的食品安全，确保人民健康和社会稳定。一是加大对农产品生产环节的整治力度，抓好农产品污染源治理。深入开展农药残留、禽畜产品违禁药物滥用，水产品药物残留专项整治，推广使用低残高效农药、兽药和无污染添加剂，规范种植、养殖行为。二是加强对食品生产和加工环节的整治。突出抓好重点品种、重点区域、重点企业的整治。严厉查处粮、肉、蔬菜、奶制品、豆制品、水产品、酒、饮料、儿童食品和保健品等的制假、售假行为和食品生产加工过程中滥用食品添加剂和使用非食品原料的违法行为，重点打击分散在自然村、监管薄弱和长期存在的食品销售点，取缔无证生产的小作坊。三是加大对食品流通环节的整治。开展包装食品安全专项执法检查，重点对饮料、酒、奶制品、儿童食品、保健食品、豆制品、调味品、食用油等包装食品质量监测力度。四是抓好对消费环节的食品安全管理。进一步扩大学校、幼儿园食堂和餐饮业的监管，以控制食物中毒为重点，加强对餐馆、学校、幼儿园和建筑工地食堂的监督管理，建立食堂中毒责任追究制度，开展联合监督检查，降低食物中毒风险；开展对学校周边饮食店、小餐饮店的专项整治，取缔无证经营，消除卫生安全隐患。加大对海鲜、排档的整治力度，使海鲜、排档餐饮服务单位经营更加规范化。五是开展畜禽屠宰专项整治。加强对活禽、生猪屠宰检疫，严惩出售和屠宰病死畜禽的行为。严厉打击私屠滥宰和屠宰过程中注水或注入其他物质的违法犯罪行为。严把市场准入关，依法依规清理整顿我镇生猪定点屠宰厂（场）。加强对畜禽屠宰场所的监督检查，督促屠宰企业落实进场查验、来源和产品流向登记、肉品品质检验、问题产品召回、病害动物及产品无害化处理等制度。坚决查处加工、出售未经肉品品质检验或经肉品品质检验不合格的肉品等行为。

（四）加强村级队伍建设。加强村级食品安全信息员队伍建设，形成完整的食品安全网络，同时加强食品安全信息员思想教育和业务培训，提高监管责任意识和业务水平，确保食品安全综合监管取得实效。

（五）建立健全食品安全事故应急处置预案。食品安全事件敏感度高，社会关注度大，影响深刻。为此我们必须高度重视食品安全应急工作，从环节、品种、区域等方面严把食品安全关。在重点环节上，严把种植、生产加工、市场流通、餐饮服务等关口。加强与群众日常生活密切相关的米、面、油、肉、蛋、奶、菜、果等食品监管；在重点区域上，切实加大对分散

在社区、乡村的各类食品批发市场、集贸市场、小加工作坊的监管力度，确保食品“从农田到餐桌”的全程监管。建立健全食品安全事故应急救援体系，完善应急预案，畅通信息渠道，不断提高我镇食品安全事故的处置能力。

三、工作要求

（一）提高思想认识。做好食品安全工作是落实科学发展观，维护广大人民群众根本利益的必然要求，是保障群众健康安全，维护社会和谐稳定的现实需要，是提高食品行业综合素质、促进行业健康发展的重要举措。各村（居）委会、各部门要进一步提高思想认识，切实增强使命感、紧迫感，全力以赴、开拓创新、真抓实干，努力完成全年食品安全工作任务。

（二）明确工作责任。各村（居）委会、各部门要进一步落实食品安全工作责任，结合实际制定具体实施方案，明确完成时限和考核指标，做到目标明确，职责到位，工作到位，确保各项工作取得实效。

（三）加强协调配合。各村（居）委会、各部门要加强食品安全工作协调，努力形成上下联动、部门联动、区域联动的食品安全工作机制；密切关注食品安全新动态、新情况，及时协商解决问题；加强信息沟通，建立生产企业与监管部门信息直报渠道和信息报告制度。

海棠湾镇党政办公室 2014年 5月8日印发
