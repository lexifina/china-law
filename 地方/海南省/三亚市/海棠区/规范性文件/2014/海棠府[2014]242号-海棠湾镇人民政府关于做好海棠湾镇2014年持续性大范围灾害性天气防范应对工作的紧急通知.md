# 海棠湾镇人民政府关于做好海棠湾镇2014年持续性大范围灾害性天气防范应对工作的紧急通知

三亚市海棠湾镇人民政府文件

海棠府[2014]242号

海棠湾镇人民政府

关于做好海棠湾镇2014年持续性大范围灾害性天气防范应对工作的紧急通知

各村（居）委会及相关单位：

当前已经进入主汛期，暴雨、台风等持续性大范围灾害性天气增多。2014年7月18日今年第9号台风“威马逊”(超强台风级)已在海南省文昌市翁田镇沿海登陆，造成人民群众生命财产严重伤害与损失。我镇前一阶段汛期安全生产工作中还存在一些突出问题，主要是：安排部署不得力、工作开展不扎实、隐患排查治理不彻底，防范措施落实不到位；预测预警和应急联动机制不健全、应急预案不完善、应急准备工作不充分等，汛期安全生产工作亟待进一步加强。

为认真贯彻落实中央领导同志重要批示精神及省、市有关汛期安全生产文件精神，进一步加强汛期安全生产工作，切实防范因灾害性天气引发生产安全事故，经镇政府同意，现就有关要求紧急通知如下，请认真抓好落实。

一、进一步加强组织领导，对汛期安全生产工作进行再部署、再落实

各村（居）委会和相关单位要进一步强化红线意识和底线思维，充分认识做好汛期安全生产工作的极端重要性，深入查找分析前一阶段汛期安全生产工作中存在的问题和薄弱环节，结合主汛期天气气候特点，对汛期安全生产工作进行再部署、再检查、再落实。各村（居）委会及相关单位要成立汛期安全生产应急小组，进一步加强领导，严格落实责任，强化防范措施，狠抓工作落实，切实把汛期安全生产各项工作抓紧抓实抓好。

为切实做好我镇汛期安全生产工作，我镇立足于防大汛，救大灾，克服麻痹思想和厌战情绪，增强责任感和紧迫感，成立海棠湾镇汛期安全生产工作领导小组，成员如下：

领导小组办公室设在镇安全生产办，负责汛期安全生产工作的综合协调，督促检查有关单位的各项防范措施的落 实，办公室主任由全建国兼任。

二、突出重点行业领域，进一步加大隐患排查治理和安全专项整治力度

各村（居）委会及有关单位要在前期全面排查的基础上，突出危旧房屋及建筑施工工地、交通运输、水库、水上交通、涉海旅游、铁炉港等重点行业领域和重点对象，特别是事故易发的重点场所、要害部位、关键环节，进一步加大隐患排查治理力度，反复拉网排查，坚决消除各类安全隐患，切实做到防患于未然。

我镇地势低，水库多，汛期易受藤桥河和各水库的影响，

因此加强对各水库安全检查尤为重要，各村（居）委会要高度重视，要对水库排泄设施、安全超高和坝体稳定性的检查，做到早检查、早发现、早准备、早防范，该加固的要早加固，要确保汛期洪水能及时排得出去,同时保证水库下游群众的生命财产安全，要严格落实汛期24小时专人值守监控制度和安全防范措施，坚决防止溃坝事故发生。

根据我镇地质环境条件，北山、海丰等村在强降雨的作用下，易造成积水、沉降、塌陷、山体滑坡等地质灾害，这些村要加强群测群防网络建设，明确检测责任人，埋设警示牌，发放防灾避灾明白卡，对群测群防人员进行培训教育，充分发挥群测群防在地质灾害防治工作中的基础作用，对地质灾害隐患区要进行定期或不定期的检查和巡查，尤其是连续或集中降雨期间和降雨后，国土所要对各村地质灾害防治工作进行督导和检查，重点检查隐患点检测责任人，防灾避难措施，值班到岗等落实情况，发现问题，及时解决。

三、加强监测监控，切实做好应急管理工作

各村（居）委会及相关单位要切实加强汛期应急值守工作，严格落实领导干部到岗带班和重要岗位24小时值班值守制度，发现险情要立即启动应急响应，及时处置、准确上报。要严格落实预测、预报、预警制度，切实提高事故预防能力；要认真分析我镇气象地理环境及主要灾害风险，密切跟踪暴雨、台风、高温、雷电等灾害性天气过程和洪水、泥石流、山体滑坡等自然灾害灾情变化，及时采取有效防范措施；要进一步完善预警预报手段，充分利用微博、微信、政府网站、手机短信平台等及时发布预警信息，确保险情、灾害信息第一时间通知到有关部门、企业和人员。

在此基础上，要进一步完善汛期自然灾害引发生产安全事故的各项应急预案，加强预案的培训和演练，强化各村（居）委会及企业应急预案与镇政府应急预案的有效衔接，切实增强预案的科学性、针对性和有效性。要对各类应急物资储备情况进行复查，统筹各方资源，及时补充必要的物资装备，建立完善紧急调配机制，切实做好各项应急保障工作。要组织各类安全生产应急队伍保持战备状态，确保一旦发生突发险情或事故，能得到及时、有力、有效处置，把损失减少到最低限度。要积极探索采取多种有效方式，加大安全知识的宣传教育工作力度，普及汛期安全防范和应急避险知识，增强社会公众尤其是从业人员自我保护和自救互救能力，有效防止或减轻灾害损失。
