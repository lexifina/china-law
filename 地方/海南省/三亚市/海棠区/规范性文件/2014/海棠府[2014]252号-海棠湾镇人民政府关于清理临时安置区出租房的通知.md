# 海棠湾镇人民政府关于清理临时安置区出租房的通知

三亚市海棠湾镇人民政府文件

海棠府[2014]252号

海棠湾镇人民政府

关于清理临时安置区出租房的通知

各相关村委会及住户：

江林、庄大、青田、猪场临时安置区是镇委镇政府专门用来安置被拆迁户的临时居住小区。近期以来，一些临时安置户未经同意，擅自将临时安置房出租给外来人员居住，个别外来租住人员甚至在临时安置区进行焊接作业，严重影响临时安置区的生活秩序，也带来了严重的安全隐患。为加强临时安置区的管理，镇政府决定对临时安置区内的出租房进行清理。现将有关事项通知如下：

一、凡将临时安置区的出租房屋给外来人员居住的，自本通知下发之日起，一律停止出租，外来租住人员必须在本通知下发之日起10日内自行搬离。如果安置户本人不需要居住的，由安置办收回所分配的安置房，另行安排给其他安置户居住。

二、未在限定时间内搬离的，物业公司不再供水、供电以及提供相关的物业服务，并由相关部门采取措施强制搬离。

特此通知。

海棠湾镇人民政府

2014年8月21日

(此件主动公开)

海棠湾镇党政办公室 2014年 8月22日印发
