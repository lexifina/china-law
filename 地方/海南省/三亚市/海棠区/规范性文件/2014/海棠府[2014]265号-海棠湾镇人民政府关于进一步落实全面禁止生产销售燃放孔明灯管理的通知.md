# 海棠湾镇人民政府关于进一步落实全面禁止生产销售燃放孔明灯管理的通知

三亚市海棠湾镇人民政府文件

海棠府[2014]265号

海棠湾镇人民政府

关于进一步落实全面禁止生产销售燃放

孔明灯管理的通知

各村（居）委会及相关单位：

8月份以来，全省发生多起因燃放孔明灯影响东环高铁运行安全，导致动车组列车晚点事故。为消除孔明灯燃放造成飞机飞行、高铁运行、电力设施、通信设施、油气库（站）及森林防火安全的威胁，认真贯彻落实三亚市安全生产委员会办公室《关于进一步落实全面禁止生产销售燃放孔明灯管理的通知（三安委办201449号）文件精神，切实做好我镇2014年全面禁止生产销售燃放孔明灯管理工作，增强人民群众对燃放孔明灯危害的安全意识，最大限度预防和减少因燃放孔明灯造成的安全事故及其损失。结合我镇实际，现就进一步落实全面禁止生产、销售、燃放孔明灯管理工作通知如下：

一、加强巡查，及时消除隐患

各村（居）委会及相关单位要成立巡查小组，要将巡查责任落实到人，村干部要强化特殊节日期间的蹲点检查，“三合一”管理员配合巡查小组加强对本辖区巡查，及时劝阻村民制作、燃放孔明灯行为，加强巡查海棠广场，及时劝阻、禁止村民及游客燃放孔明灯行为。各单位加强联防联控，严厉打击整顿经营性单位生产销售孔明灯行为，对不听劝阻，恶意扰乱社会治安的要采取强制措施，严厉查处，对存在可燃物、易引发火灾的部位要及时落实防范措施，消除安全隐患，对吊挂在电力设施、通信设施、建筑设施等的孔明灯要及时清理，防止引发重大安全生产事故。林业站护林员近期要加强林区巡防值守，对在林区销售和燃放孔明灯的行为要及时制止和查处，严防孔明灯燃放引发森林火灾事故。

二、加强宣传教育，提高安全意识。

各村（居）委会及相关单位要加强安全宣传教育，广泛宣传燃放孔明灯的危害，在人员密集场所和重要片区醒目张贴相关公告、标语，制作横幅、设置宣传栏等，提高群众对燃放孔明灯危害性的认识，引导群众转变观念，积极鼓励群众举报生产、销售和燃放孔明灯行为，发动群众共同参与整治，严防辖区内发生孔明灯燃放事故，从而进一步落实在全镇全面禁止生产、销售、燃放孔明灯管理工作，让民俗让步于安全。

特此通知。

海棠湾镇人民政府
