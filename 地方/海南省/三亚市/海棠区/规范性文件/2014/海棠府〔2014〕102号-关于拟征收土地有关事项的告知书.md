# 关于拟征收土地有关事项的告知书

三亚市海棠湾镇人民政府文件

海棠府〔2014〕102号

关于拟征收土地有关事项的告知书

（宗地号： ）

海棠湾镇洪李村委会：

因我市的城市建设需要，市政府以三府办〔2014〕71号文拟征收海棠湾镇洪李村委会部分集体所有土地，现将拟征收的土地有关事项告知如下：

一、拟征收土地位于海棠湾仲田水库周边，用地面积为30.9075公顷（涉及耕地0公顷、其他农用地30.0093公顷、建设用地0.8982公顷），其中洪李村委会集体土地1.9440公顷。

二、拟征收土地的项目用途为旅游建设用地。

三、拟征收土地补偿标准按市政府规定的补偿标准执行，剩余劳动力的安置途径以货币方式安置。

四、如你对上述拟征收土地有关事项有异议，我镇将在15天内举行听证会；如无异议，请出据确认意见。

特此告知。

海棠湾镇人民政府

2014年4月8日

（此件主动公开）
