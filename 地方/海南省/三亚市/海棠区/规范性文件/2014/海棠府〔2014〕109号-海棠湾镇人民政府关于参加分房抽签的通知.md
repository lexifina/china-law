# 海棠湾镇人民政府关于参加分房抽签的通知

三亚市海棠湾镇人民政府文件

海棠府〔2014〕109号

海棠湾镇人民政府

关于参加分房抽签的通知

龙江村委会：

龙江村委会自行安置户分户名单已经过镇村两级反复公示，为加快海棠湾镇村民的安置进度，现就分房抽签有关事项通知如下：

一、2014年4月24日（星期四）上午9时，在龙江安置区举行分房顺序号抽签活动。

二、2014年4月25日（星期五）上午9时，在龙江安置区举行房号抽签活动。

现请你村委会通知相关安置户户主携带本人身份证或户口簿，届时务必及时到场参加以上抽签活动。凡无正当理由而拒不参加此次抽签活动的安置户，我镇将取消其临时过渡补助费和本次安置资格，留待全镇其他农户安置完成后再另行安排。

海棠湾镇人民政府

2014年4月23日

（此件主动公开）

海棠湾镇党政办公室 2014年 4月23日印发
