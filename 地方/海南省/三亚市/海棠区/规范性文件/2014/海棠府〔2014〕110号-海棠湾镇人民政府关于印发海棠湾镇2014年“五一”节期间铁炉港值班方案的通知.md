# 海棠湾镇人民政府关于印发海棠湾镇2014年“五一”节期间铁炉港值班方案的通知

海棠府〔2014〕110号

海棠湾镇人民政府

关于印发海棠湾镇2014年“五一”节期间

铁炉港值班方案的通知

各村（居）委会、各部门：

《海棠湾镇2014年“五一”节期间铁炉港值班方案》经镇政府同意，现予以印发，请认真组织实施。

特此通知。

海棠湾镇人民政府

2014年4月23日

（此件主动公开）

海棠湾镇2014年“五一”节期间铁炉港值班方案

为迎接“五一”小长假的到来，根据全市安全生产工作会议要求，我镇安全生产工作紧紧“安全第一，预防为主，综合治理”的原则，对我镇铁炉港从事海上旅游业进行监管，现结合我镇实际情况特制定以下值班方案：

一、指导思想

以科学发展观为指导，通过全面开展海上动力平台安全隐患整治，突出“预防为主、加强监管、落实责任”重点，进一步落实主体责任和监管责任，严厉打击非法违法建设、生产、经营行为，彻底排查治理事故隐患，认真解决安全管理上存在的突出问题和薄弱环节，有效防范安全生产事故。

二、组织机构

成立海棠湾镇海上旅游业安全监管工作领导小组。

组　长：严连勇　海棠湾工委副书记、镇委副书记、镇长

副组长：黎杰市　公安局海棠湾分局局长

翁裕育　镇委委员、武装部长

陈孝强　市执法局海棠湾分局局长

成　员：李正庄　后海边防派出所教导员

黄启鸣　镇党政办主任

全建国　镇安全生产办主任

谭小强　海棠湾工商所所长

梁振富　藤海居委会书记

领导小组下设办公室，办公室设在镇安全生产办，负责海上旅游监管的综合协调，督促检查有关单位各项检查措施落实的情况，办公室主任由全建国兼任，联系电话：13876668667。成员由黄学壮、黄宏敏组成。

三、监管内容及重点

在我镇辖区铁炉港内海及铁炉港外海附近海域，存在未经有关行政主管部门批准，擅自使用动力平台或无动力平台从事海上旅游活动，包括拉运送客人到内海或外海潜水、钓鱼、观光、用餐等，存在严重安全隐患。为了确保我镇生产安全，按照《中华人民共和国安全生产法》属地管理原则，现由镇政府安全生产办牵头，组织工商所、执法分局、后海边防派出所及藤海居委会等各有关单位，对存在安全隐患的动力平台或无动力平台进行安全专项监管。

四、值班时间

本次海上动力平台安全隐患监管时间自2014年5月1日开始至2014年5月4日结束。（具体值班安排见附表）

五、工作要求

（一）“五一”假日期间，值班人员要认真执行值班工作，做好工作衔接，保证通讯联络畅通，及时做好海上动力平台安全隐患监管工作。

（二）做好应急工作准备，一旦发生海上安全危险突发事故，值班人员要及时采取措施，果断处理，绝不允许瞒报、迟报、漏报安全事故，延误事故处理。

（三）值班人员要按时上下班，按时签到，并将当天的值班情况和安全隐患处理情况登记清楚。并于当天上报镇安全生产办，镇安全生产办汇总后上报镇安委会，遇有重大情况由镇安委会及时上报市安委会。
