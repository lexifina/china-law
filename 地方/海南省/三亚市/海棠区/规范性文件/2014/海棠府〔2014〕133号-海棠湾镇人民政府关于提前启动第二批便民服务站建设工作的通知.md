# 海棠湾镇人民政府关于提前启动第二批便民服务站建设工作的通知

三亚市海棠湾镇人民政府文件

海棠府〔2014〕133号

海棠湾镇人民政府

关于提前启动第二批便民服务站建设工作

的通知

各有关部门、各村委会：

便民服务站建设是一项“民生工程”，该项工作已列为2014年市政府工作报告责任事项，是各区镇必须认真落实的工作任务。根据市委、市政府有关文件精神，市政务服务中心要求我镇于5月1日前全面启动便民服务站建设事宜，并于6月15日前全面建成22个村（居）委会便民服务站，实现所有社区居（村）委会便民服务站全覆盖。

为保障此项工作顺利实施、按时间节点完成，我镇决定提前启动升昌村委会、营头村委会等12个村委会便民服务站的建设工作，请各村委会按照《海棠湾镇便民服务站建设工作方案》的要求认真组织实施，按时完成便民服务站的建设工作。

特此通知。

附件：1、《海棠湾镇人民政府关于印发海棠湾镇便民服务站建设工作方案的通知》海棠府[2014]62号。
