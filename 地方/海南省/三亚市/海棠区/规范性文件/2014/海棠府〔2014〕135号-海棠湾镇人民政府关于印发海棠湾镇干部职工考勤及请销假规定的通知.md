# 海棠湾镇人民政府关于印发海棠湾镇干部职工考勤及请销假规定的通知

海棠府〔2014〕135号

海棠湾镇人民政府

关于印发海棠湾镇干部职工考勤及

请销假规定的通知

各相关部门：

《海棠湾镇干部职工考勤及请销假规定》已经镇政府同意，现予以印发，请遵照执行。

海棠湾镇人民政府

2014年5月5日

（此件主动公开）

海棠湾镇干部职工考勤及请销假规定

为切实转变机关作风，严肃工作纪律，提高工作效率和服务质量，确保海棠湾镇各项工作的高效运转，特制定本规定。

一、考勤规定

（一）考勤登记

干部职工和各部门临聘工作人员上下班实行指纹打卡和登记确认相结合的考勤制度。不参与征地的坐班人员一律执行指纹打卡；参加征地的工作人员采用指纹打卡与考勤登记相结合方式，外出征地未进行打卡登记的时段，以征地组为单位，如实填写在职在编和临时聘用人员的考勤情况，报征地组分管领导审核后，于每月15日、30日前报党政办公室备案。

（二）时间规定

1、上午8：00至12：00时，下午15：00至18:00，坐班制工作人员每天打卡四次。上午上班打卡时间为7:30-8:00，下午上班打卡时间为14:20-15:00，上班迟到10分钟以上者记迟到，下班提前10分钟以上者记早退。凡不按时打卡超过一小时或迟到、早退合计3次分别记缺勤半天。

2、征地组人员每天上午8点前打卡一次（根据征地项目分别在藤桥、林旺打卡）。

3、工作人员因公务未能按时打卡的，填写《工作人员因公外出漏打卡情况说明》（附件1），经分管领导审核后交党政办备案，否则按迟到、早退或缺勤旷工处理。经审批同意，外出开会、参加培训学习的，当事人将相关文件批示材料送党政办备案，按出勤计。

（三）出勤抽查。各部门负责人是负责监督本部门干部职工出勤的第一责任人，部门人员无故缺勤情况较多、影响工作落实的，将对部门负责人进行约谈，约谈后没有效果的，将进行岗位调整。镇纪检部门要定期对各部门出勤情况进行抽查核实，杜绝冒名、替名打卡，如弄虚作假情况一经查实将对相关人员进行处理。

二、请销假规定

（一）探亲、婚假、公休、产假等国家法律法规规定的假期，按国家规定的天数予以安排。事假、病假等无相关规定和时间的假期，由申请人提供相关证明后视工作实际合理安排。事假原则上每月不超过2天。

（二）会议请假。凡经相关领导批准召开的会议，参会者因公务或因私不能参加的，应报告会议主持人同意，因私需提交书面请假条报批后送党政办备案。不提交请假条的，视为缺席，在全镇范围通报批评。

（三）临时事务性请假。上班时间不得擅自离岗，因公务需要到其他单位联系工作、开会或下村的，必须向所在部门负责人报告。凡无故离开岗位，所在部门负责人不知其去向超过一小时以上者，按缺勤半天处理。

（四）审批权限。请假1天以内的，由所在部门负责人审批；1天至3天的，由所在部门负责人提出意见，报分管领导审批；3天（含3天）以上的，由所在部门负责人提出意见、组织干事按规定核对请假时间，报分管领导、组织员、分管组织人事领导审核后，呈报镇委、镇政府主要领导批准（月请假累计满3天的按此程序审批）。

（五）请销假备案管理。凡请假超过1天（含1天），均按照审批程序批准后报党政办备案，由党政办对照打卡或考勤登记表记录进行统计管理。《海棠湾镇请假单》（附件2）由党政办专人负责编号管理，由请假人到党政办申请领取，并按程序审批后送回党政办存档。请假单经审批后不送回党政办备案存档的，一律按缺勤旷工处理。假期结束后，请假人须及时到党政办进行销假。

（六）驻镇双管部门工作人员请销假以垂直管理部门审批为主，部门负责人请假的，需及时报告镇主要领导，同时将请假审批材料送党政办备案。

（七）村（居）书记、主任请销假参照本规定执行。

三、公示监督

由镇党政办结合考勤记录、请销假、公务外出等情况统计核对后，于每月15日、30日在公开栏进行公布，接受群众监督。

四、惩处

严格根据《中华人民共和国公务员法》、《行政机关公务员处分条例》、《事业单位工作人员处分暂行规定》等法律法规和省市相关规定对干部职工进行管理，出勤情况作为年度考核评选的基本条件。每月迟到、早退累计达到6次（含6次）以上者由镇纪检部门给予诫勉谈话，每月累计旷工三天者，给予点名批评，每年累计旷工10天者，年终考核不得评为称职，旷工或者无正当理由逾期不归连续超过15天，或者一年内累计超过30天的，按照相关法律法规予以辞退。对违反法律法规其他情形的将按程序进行严肃处理。

五、本规定自2014年5月12日起执行。

海棠湾镇党政办公室 2014年 5月7日印发
