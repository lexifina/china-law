# 关于调整海棠湾镇历史遗留项目处理工作领导小组办公室成员的通知

三亚市海棠湾镇人民政府文件

海棠府〔2014〕168号

海棠湾镇人民政府

关于调整海棠湾镇历史遗留项目处理工作

领导小组办公室成员的通知

各相关部门：

经镇领导班子会议研究决定，调整海棠湾镇历史遗留项目处理工作领导小组办公室成员，主任由钟路同志担任，副主任由苏文茹、陈帮武、林云春同志担任，办公室成员由各部门（科室）负责人组成。办公室负责领导小组日常组织协调工作。

特此通知。

海棠湾镇人民政府

2014年6月4日
