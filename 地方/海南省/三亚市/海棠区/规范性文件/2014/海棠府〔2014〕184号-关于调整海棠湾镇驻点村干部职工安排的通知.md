# 关于调整海棠湾镇驻点村干部职工安排的通知

三亚市海棠湾镇人民政府文件

海棠府〔2014〕184号

海棠湾镇人民政府

关于调整海棠湾镇驻点村干部职工安排的

通知

各有关单位：

由于我镇人事关系变动，驻点村干部职工作相应调整，现将调整后的《海棠湾镇驻点村干部职工安排表》印发给你们，各村驻点干部职工实行轮流值班制度，值班时间内不得离开镇区范围，以便及时联系处理驻点村群众反映的问题。

海棠湾镇人民政府

2014年6月9日

（此件主动公开）

海棠湾镇党政办公室 2014年 6月11日印发
