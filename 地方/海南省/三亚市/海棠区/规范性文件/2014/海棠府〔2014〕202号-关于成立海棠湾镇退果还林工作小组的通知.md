# 关于成立海棠湾镇退果还林工作小组的通知

三亚市海棠湾镇人民政府文件

海棠府〔2014〕202号

海棠湾镇人民政府

关于成立海棠湾镇退果还林工作小组的

通 知

各有关单位、部门：

根据《三亚市林业局关于印发三亚市林业局2014年退果还林工作方案的通知》（三林〔2014〕109号）文件精神，为了加强退果还林工作的组织领导和协调，确保此项工作的顺利开展，镇政府决定成立海棠湾镇退果还林工作小组，其组成人员如下：

组 长：严连勇 （海棠湾工委副书记、镇委副书记、镇长）

副组长：彭伟然 （镇委委员、常务副镇长）

成 员：黎运雄 （农业服务中心主任）

黄启鸣 （党政办主任）

林云春 （财政所所长）

唐曙光 （林业站站长）

冯琼珍 （园林技术员）

蓝文良 （湾坡村书记）

周其川 （湾坡村主任、副书记）

领导小组下设办公室，办公室设在镇林业站，办公室主任由唐曙光站长兼任，办公室负责组织协调退果还林各项工作、以及汇报此次工作的各项事宜。

海棠湾镇人民政府

2014年6月27日

（此件主动公开）

抄送：市林业局

海棠湾镇党政办公室 2014年 6月30日印发
