# 三亚市海棠湾镇人民政府关于拟征收湾坡村部分集体土地的公告

三亚市海棠湾镇人民政府文件

海棠府〔2014〕75号

三亚市海棠湾镇人民政府

关于拟征收湾坡村部分集体土地的

公 告

海棠府〔2014〕75号

根据三亚市人民政府办公室《关于海棠湾C2、C3片区温泉疗养度假设施用地及海榆东线防护绿地用地土地调查有关问题的通知》（三府办〔2011〕65号）的要求。我镇将组织实施对该项目建设用地内的湾坡村委会部分集体土地及农户青苗、地上附着物进行丈量清点，以及补偿有关工作。拟征收及收回土地补偿标准按《三亚市集体土地征收补偿安置管理规定（2013年修订）》（三府〔2013〕43号）、《三亚市政府关于印发<三亚市征收集体土地青苗补偿费和征地经费包干管理暂行办法>的通知》（三府〔2011〕208号）文件执行。地块四至以用地勘测定界图为准。

本公告发布之日起，各相关部门停止办理勘测定界图范围内有关工商营业执照登记、土地及房屋权属变更、转移登记、新建建设项目的审批、征地范围内土地及地上物的转承包、租赁和经营合同等续签及登记等事宜。对违反本公告有关规定的相关责任人，依法追究相关责任。

本公告发布后，抢搭抢建的建筑物、抢栽抢种的附着物一律不予补偿。
