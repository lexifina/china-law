# 三亚市海棠区筹备组关于印发海棠区领导带班值班制度的通知

三亚市海棠区筹备组文件

海棠筹〔2014〕18号

三亚市海棠区筹备组

关于印发海棠区领导带班值班制度的通知

各部门：

《海棠区领导带班值班制度》已经海棠区筹备组同意，现印发给你们，请认真组织实施。

特此通知。

三亚市海棠区筹备组

2014年10月20日

（此件主动公开）

海棠区领导带班值班制度

为进一步加强作风建设,根据《海棠区开展深入整治庸懒散奢贪“不干事、不担事”突出问题专项工作实施方案》的要求,特制定本制度。

一、实行领导带班制度

每天安排5名干部职工轮流值班（区筹备组领导和原镇班子领导各1名、中层干部1名、普通干部职工2名）。

值班电话：88811015，传真88810777。

二、值班主要职责

（一）值班领导职责：统筹日常值班工作，及时了解工作动态，协助处理突发事件，并及时向相关领导和部门报告值班期间重大事项。

（二）值班工作人员职责：日常值班、填写值班日志、信息处理、情况反馈、协助处理重特大突发事件、领导批示件办理及领导交办的有关工作。

三、值班要求

（一）实行24小时值班制度，确保随时对各种情况和信息作出快速反应。由党政办将值班表进行公示，并每日电话、短信提醒当日值班人员。换班或请人代班须经带班领导同意并报党政办备案。值班领导和值班干部要坚守岗位，保持手机24小时畅通，不得离开本辖区。

（二）值班工作要求当日处理完毕，并做好交接班工作。

（三）遇重大突发事件，值班员要立即向值班领导报告，并作出应急处理，值班领导应及时向相关领导和部门报告，并根据领导指示，第一时间赶赴现场协助处理。

（四）值班人员因缺岗造成工作失误的，视情节轻重给予通报批评。

（五）党政办于每月25日前，将下月值班表进行公示。

附件：海棠区筹备组成员带班值班安排表

海棠区筹备组办公室 2014年 10月20日印发
