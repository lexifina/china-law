# 三亚市海棠区筹备组关于印发海棠区文明大行动第三阶段工作方案的通知

三亚市海棠区筹备组文件

关于印发海棠区文明大行动第三阶段工作方案的通知

各村（居）委会及相关单位：

《海棠区文明大行动第三阶段工作方案》已经海棠区筹备组同意，现印发给你们，请认真组织实施。

特此通知。

三亚市海棠区筹备组

2014年10月21日

（此件主动公开）

海棠区文明大行动第三阶段工作方案

2014年是海南文明大行动的总结之年。为了进一步提高我区居民的文明素质和城乡文明程度，塑造国际休闲度假区海棠湾的良好形象，根据《三亚文明大行动第三阶段工作方案》要求，我区决定从2014年9月至12月，组织实施海棠区文明大行动第三阶段工作。现结合实际，制定方案如下。

一、工作目标

（一）形成礼让有序的公共场合秩序。居民文明行为规范知晓率达到90%；居民自觉遵守行为规范，恪守社会公德，公共场所安静文明、无大声喧哗、污言秽语、嬉戏吵闹、禁烟场所吸烟现象，公共设施无损毁现象；机关工作作风明显改进，窗口行业职业道德水平明显提高；公共文明的长效机制初步建立，居民文明素养不断提高。

（二）形成整洁有序的公共环境。城乡建设布局合理、设施配套完善，环境优美整洁；卫生环境宣传教育深入开展，健康卫生知识知晓率达到90%；爱国卫生运动深入开展，居民自觉讲卫生、护环境，公共场所无乱吐乱扔、乱涂乱画现象，居民对城乡环境满意率在80%以上；门前责任制度落实到位，主要街道、车站和农贸市场等经营场所卫生状况良好，无占道经营、散发小广告、乱贴乱画、乱设广告牌和单位铭牌现象。

（三）形成安全有序的交通秩序。城乡交通安全设施和管理平台完善；交通法制知识普及率达到90%，公民安全意识和法制观念普遍增强；车辆行人自觉遵守交通信号、各行其道，行人乱闯乱行、攀越护栏以及机动车抢行、压黄线、乱变线、乱停靠等违章行为明显减少；交通守法率达标，区域主干道的机动车守法率≥98%、非机动车守法率≥85%，恶性交通事故发生率明显降低。交通执法更加规范，管理更加科学。

（四）形成和谐有序的旅游秩序。旅游企业努力提升服务质量，投诉处理机制健全，游客满意度不断提高；景点（区）公共服务设施完善，道路标识规范齐备；旅游文明素质教育活动深入开展，游客旅游素质显著提升，自觉维护旅游秩序；管理机制更加完善，导游服务“行前宣传教育、行中督促提醒、行后总结反馈”的目标实现率达到100%，旅游行业整体素质明显提升。

（五）形成文明诚信的经营秩序。文明诚信教育实现企业经营者和从业人员全覆盖，恪守诚信、公平合理、文明待客、卫生整洁等理念成为业界共识；信用体系建设步伐加快，社会管理和监督职能不断强化，服务行业投诉明显减少，处理合理高效。公民对行业风气的满意度在85%以上。

二、组织领导

为加强海棠区文明大行动的组织领导和协调工作，特成立海棠区文明大行动领导小组，名单如下:

组 长：张华文（海棠区筹备组成员）

副组长：罗启亮（原任海棠湾镇宣传委员）

叶凯中（海棠湾管委会旅游发展局局长）

成员由市政管理局、旅游发展局、综合执法大队、党政办、纪检办、司法所、综治办、社会事务办、农业服务中心、便民服务中心、工会、科教办、妇联、团委、各中小学、各卫生院、各派出所、工商所、各村（居）委会等部门、单位负责人组成。

领导小组下设办公室，负责指导协调、服务保障和材料收集等日常工作，主任由党政办主任黄启鸣兼任，成员从相关部门抽调。办公室设在党政办，联系电话：88811015，传真：88810777。

三、重点任务

各单位、各部门要根据《海棠区文明大行动任务分解表》（见附件）责任分工，认真完成各项任务，重点抓好以下工作：

（一）整治城区脏乱差堵。一是治脏。积极发动群众，整治环境卫生，重点整治背街小巷、社区环境和农贸市场、餐饮店、宾馆酒店等地方，整治乱吐槟榔水的行为。二是治乱。重点治理“乱倒垃圾、乱搭乱建、乱贴挂广告、乱摆设摊点、乱停放车辆、乱挖马路、乱占道工作、乱倒污水、乱排放废气”等九乱现象。三是治差。重点整治区容区貌，维护修善公共设施，加强对区内主要街道沿街建筑物的规范管理。四是治堵。重点整治电动车、摩托车闯红灯，机动车随意变道、掉头、乱停乱放等交通乱象，整治骑电动车、摩托车不戴头盔、行人随意横穿马路等不文明行为；完善交通标志，严查交通违章行为。

（二）整治农村环境卫生。一是完善农村环卫基础设施，加快海棠区垃圾收集中转站建设，加强道路保洁和农贸市场的管理。二是配备农村保洁员，配合市相关部门建立村清、区运、市处理的“三级”垃圾收集清运管理体系。三是开展“四边三大”行动（屋边、路边、水边、田边垃圾大清扫、大清理、大清运），清理各类积存垃圾。四是做好农村道路及两旁环卫保洁工作，将农村公路沿线两侧的垃圾收运纳入环卫工作范围。五是开展移风易俗，反对陈规陋习、封建迷信、大操大办，提倡科学、节俭、文明健康的生活方式。

（三）开展“四大创建活动”。一是开展文明交通行业创建。配合市相关部门开展“文明交通伴我行，我为三亚添光彩”主题创建活动，强化安全有序的交通意识，严格抵制“六大危险驾驶行为”，集中解决车辆行人不遵守交通法规、交通道路拥堵，事故隐患多等突出问题。在公交车、出租车公司推出一批文明公交、出租车公司，文明公交路线，文明司乘人员，提升交通行业服务质量和服务水平。二是开展诚信市场主体创建。以“诚实守信、文明经商”为主题，在工商行业开展争当诚信商家活动，着力推进价格守信商家体系建设，倡导经营者依法经营、诚信经营、文明经营。完善文明诚信监管平台。在海棠区打造一批海鲜排档、景区景点、旅游购物诚信示范点。三是开展文明旅游行业创建。以“文明和旅游同行”为主题，以“优美环境，优良秩序，优质服务”为目标，在全区旅游企业开展文明创建活动，规范和优化旅游市场秩序，打击黑社，黑导、黑车等非法经营和欺客宰客行为;推进旅游标准化工作，完善旅游产品和服务质量标准，完善服务流程，提升服务水平。四是开展文明村（社区）创建。在全区村（社区）开展“创建文明村（社区），建设美好家园”活动，切实把文明村（社区）创建作为基层开展文明大行动的重要载体，坚持硬件和软件建设并重，把健全村（社区）组织、完善村（社区）服务、发展村（社区）文化、美化村（社区）环境、加强村（社区）治安等工作落到实处;深入开展科教、文体、法律、卫生“四进”村（社区）活动，提升村（社区）文明程度和居民文明素质；建立完善村（社区）志愿服务队伍和管理制度，开展志愿服务活动，健全对老年人、残疾人、优抚对象和困难群体的服务网络；广泛开展文明街道、文明家庭等群众性创建活动，营造文明祥和的村（社区）环境。

（四）抓好文明礼仪学习宣传活动。一是做好文明礼仪的宣传，通过电视、广播、报纸、墙报、小品、宣传栏等多种形式营造学礼、知礼、重礼、守礼的良好社会氛围。二是开展文明礼仪的学习活动，以《国际旅游岛公民手册》《海南省礼仪知识读本》、《我爱三亚――做文明有礼的三亚人》为主要教材，组织知识宣讲、培训讲座、情景模拟、文艺活动等方式，广泛开展生活礼仪、社交礼仪、公共礼仪、公务礼仪等活动。三是深化党政机关、窗口行业、中小学生等重点人群和行业的文明礼仪教育，加强外来务工人员的交通法制和文明卫生教育，营造讲文明、知礼仪、懂礼貌的社会氛围。

四、实施步骤

（一）动员教育、查摆问题阶段（9月29日――10月15日）。

各部门、单位要做好动员、部署工作，做到人人知晓、全民参与，迅速掀起海棠区文明大行动的热潮。相关部门、单位要认真梳理各自存在的突出问题和薄弱环节，建立问题台账，并制定具体的实施计划和整改措施。

（二）狠抓落实、对照整改阶段（10月16日――11月30日）。

各部门、单位要紧密结合当前进行的党的群众路线教育实践活动、环境卫生综合治理等工作，扎实推进文明大行动。积极配合市督察组开展的每月督查和测评工作，相关部门要做好自查工作，并根据督察组的指导和存在的问题狠抓落实，对存在的问题进行对照整改；要借鉴创卫的成功经验，组织测评，表扬先进，批评后进。从10月份起，坚持每月测评一次，测评结果张榜公布，促进各项整改活动的有效落实。

（三）迎接省、市测评阶段（12月1日――12月31日）。

区文明大行动领导小组办公室要收集和编制各类创建工作资料，组织开展模拟测评；各相关部门、单位要根据测评体系查漏补缺，抓好整改；相关部门要配合省、市测评组做好实地考察和问卷调查工作。

五、工作要求

（一）进一步明确责任。各部门、单位要根方案要求和《任务分析表》，理清本部门、单位工作任务，建立工作台账，提出具体措施，要明确责任人、明确工作任务、明确完成时间，做到事事有人抓。

（二）注意材料收集。各部门、单位在工作中注意材料收集，活动的方案、照片（视频）、报道等材料，要按要求归类报送。

（三）做好舆论监督。组织三亚日报社、三亚广播电视台开展系列专题报道，重点对不文明现象进行曝光，对整改不力的单位进行曝光，不断扩大宣传声势，有力推动工作深入开展。
