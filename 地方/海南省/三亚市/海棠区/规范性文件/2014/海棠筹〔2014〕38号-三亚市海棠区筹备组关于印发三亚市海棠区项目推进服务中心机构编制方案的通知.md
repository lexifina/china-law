# 三亚市海棠区筹备组关于印发三亚市海棠区项目推进服务中心机构编制方案的通知

三亚市海棠区筹备组文件

海棠筹〔2014〕38号

三亚市海棠区筹备组

关于印发三亚市海棠区项目推进服务中心

机构编制方案的通知

区机关各部门，区直各单位：

《三亚市海棠区项目推进服务中心机构编制方案》经区筹备组批准，现印发给你们，请认真遵照执行。

三亚市海棠区筹备组

2014年11月3日

（此件主动公开）

三亚市海棠区项目推进服务中心

机构编制方案

一、单位名称

三亚市海棠区项目推进服务中心。中文域名名称为：“三亚市海棠区项目推进服务中心・公益”。

二、隶属关系

三亚市海棠区项目推进服务中心为隶属区人民政府的正科级事业单位。

三、工作任务和职责范围

受区政府委托承担本区非经营性重点项目的协调、服务和督查推进工作；协调本区范围内各村（居）委会、村（居）小组配合区政府做好征地工作；负责本区范围内拟征土地的征地方面相关具体事务工作；承办区委、区政府及上级部门交办的工作。

四、内部机构设置

三亚市海棠区项目推进服务中心不设内部职能机构。

五、人员编制和经费渠道

（一）编制数额和经费渠道

核定三亚市海棠区项目推进服务中心财政全额预算管理事业编制5名。

（二）岗位结构

1. 单位领导职数2名（正职1名，副职1名）。

2. 其他管理岗位3名。

抄报：市人大、市编委办

海棠区筹备组办公室 2014年 11月3日印发
