# 三亚市海棠区筹备组关于印发三亚市海棠区交通运输和安全生产监管局主要职责内设机构和人员编制规定的通知

三亚市海棠区筹备组文件

海棠筹〔2014〕47号

三亚市海棠区筹备组

关于印发三亚市海棠区交通运输和安全生产监管局主要职责内设机构和人员编制规定的通知

区机关各部门，区直各单位：

《三亚市海棠区交通运输和安全生产监管局主要职责内设机构和人员编制规定》经区筹备组批准，现印发给你们，请认真遵照执行。

三亚市海棠区筹备组

2014年11月3日

（此件主动公开）

三亚市海棠区交通运输和安全生产监管局

机构编制方案

一、单位名称

三亚市海棠区交通运输和安全生产监管局，中文域名名称为：“三亚市海棠区交通运输和安全生产监管局・政务”。

二、工作任务和职责范围

（一）贯彻执行中央及省、市有关安全生产和交通运输工作的方针、政策；依法拟定并组织实施本区安全生产工作和交通运输行业发展的规划和措施；参与拟定物流业发展规划并监督实施。

（二）指导协调本区安全生产与交通运输工作，分析和预测安全生产与交通运输工作形势，发布安全生产信息，协调解决安全生产中的重大问题。

（三）承担安全生产综合监督管理责任和本区公路运输经营市场监管责任。负责本区农村公路和行业监督管理；负责城乡客运及有关设施规划和管理工作；负责本区机动车维修经营、停车场、洗车店的行业管理；维护公路交通运输行业和城市客运行业的平等竞争秩序。

（四）承担本区公路建设市场监管责任。负责本区重点公路建设和工程质量、安全生产监督管理工作；负责本区公路、水路和交通运输设施的监督管理。

（五）统筹本区安全生产大检查和专项督察工作，监督检查重大危险源监控和重大事故隐患排查治理工作，查处安全生产违法行为。指导协调、监督检查区级有关部门安全生产工作，监督考核并通报安全生产控制指标执行情况。

（六）统筹本区安全生产应急救援工作，调查处理生产安全事故，综合管理安全事故和安全生产行政执法统计分析工作。按规定组织协调重点物资运输和紧急客货运输。

（七）负责本区烟花爆竹零售许可工作。

（八）负责职业危害申报、备案、审核、验收工作；组织作业场所职业健康监督检查，查处职业危害违法行为。

（九）负责本区安全生产宣传教育工作，组织特种作业人员从业资格考核，以及生产经营单位主要负责人、安全管理人员的培训工作；负责维修、营运车辆综合性能检测、机动车驾驶员培训机构和驾驶员培训管理工作。

（十）负责监督检查职责范围内本区建设项目的安全设施以及职业卫生防护设施与主体工程同时设计、同时施工、同时投入使用。

（十一）负责劳动防护用品和高温天气劳动保护监督管理工作；负责本区公路基础设施的建设、管理和维护，组织实施重点公路建设项目。

（十二）指导、协调本区安全生产检测检验、安全评价、安全资讯和安全新技术的推广工作。指导本区交通运输信息化建设，负责交通运输行业统计和信息引导。

（十三）负责受理有关安全生产群众举报、来信来访；负责安全生产行政复议和行政应诉工作。

（十四）承办区委、区政府及上级部门交办的工作。

三、内设机构

三亚市海棠区交通运输和安全生产监管局不设内设职能机构。

四、人员编制

核定三亚市海棠区交通运输和安全生产监管局行政编制为5名。其中：局长1名，副局长1名。

海棠区筹备组办公室 2014年 11月3日印发
