# 三亚市海棠区人民政府关于印发三亚市海棠区协助南田农场开展精准脱贫攻坚工作实施方案的通知

三亚市海棠区人民政府

关于印发三亚市海棠区协助南田农场开展精准脱贫攻坚工作实施方案的通知

各有关单位、部门:

《三亚市海棠区协助南田农场开展精准脱贫攻坚工作实施方案》已经区政府同意,现印发给你们,请各相关单位认真组织实施。

特此通知。

三亚市海棠区人民政府

2016年10月19日

（此件主动公开）

三亚市海棠区协助南田农场开展精准脱贫攻坚工作实施方案

为贯彻落实2015年中央、省市扶贫开发工作会议精神和三亚市扶贫工作要求和部署，协助南田农场抓好贫困户民生工作，加快精准扶贫、精准脱贫，完成精准脱贫攻坚总体目标任务，现结合我区实际，制定本工作方案。

一、指导思想

以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入贯彻习近平总书记系列重要讲话精神，准确把握深刻领会中央扶贫工作会议精神，全面贯彻落实市委市政府精准脱贫工作部署，树立全市扶贫一盘棋的大局意识，发扬三亚先行区实干精神，以服务和改善百姓民生为宗旨，求真务实，勇于担当，切实做到“一对一、点对点、人对人、企业对贫困村”的精准扶贫、精准脱贫，优质高效完成南田农场20户贫困户、1户低保户的脱贫工作任务，坚决打赢精准脱贫攻坚战，力争“一年脱贫攻坚，两年巩固提升，两年全面提升”。

二、目标任务

根据三亚市2016年开展精准脱贫攻坚工作的要求和部署，我区会同南田农场按照“十项基本标准”，全力开展南田农场20户贫困户、1户低保户的“一对一”的精准扶贫，精准脱贫工作（详见南田农场精准扶贫任务分解表）。其中该表前13户由海棠区牵头负责（含低保户），其余8户贫困户由我区各职能单位配合南田农场开展扶贫工作，2016年底全部完成21户脱贫任务。

三、加强组织领导

为全面做好海棠区脱贫攻坚工作，加强领导，成立海棠区精准脱贫攻坚工作领导小组，领导小组成员名单如下：

组 长：陈 明 区委副书记、区长

副组长：蔡克勤 副区长

成 员：钟向能 区农林局局长

杨军建 区委办主任、区农工委主任

罗启亮 区民政局局长

吴永恺 区卫生和计生局局长

苏文茹 区人力资源和社会保障局局长

陈小冬 区教育科技局局长

曹立伟 区住房与城市建设局局长

领导小组下设办公室，在海棠区农林局，蔡克勤兼任办公室主任，钟向能任办公室副主任，具体负责领导小组日常事务，收集和汇报信息,办公室联系电话：88810217。

四、责任分工

各责任单位组成调研组，由区农林局牵头，扎实调研，做好贫困户的调查摸底工作，了解贫困户的生产生活状况及具体致贫原因，把调查情况,整改措施的意见和建议，上报给海棠区精准脱贫攻坚工作领导小组办公室，并协调各职能部门落实帮扶。实施帮扶中要做到一户一本台账、一户一个脱贫计划、一户一套帮扶措施，确保实施精准扶贫、精准脱贫。

（一）培育特色产业。区农林局帮助贫困农户掌握1至2项实用技术；企业出资扶持（市残联也计划资助，此项由民政局对接），形成大规模的种植、养殖、林下经济、花卉苗木培育、设施农业等增收项目。（责任单位：区农林局、区民政局、复星集团、天津房地产发展股份有限公司）

（二）提供医疗帮助。针对往年因病致贫，不符合政府职能部门救助政策的贫困户，企业给予适当的救济；针对贫困户在办理低保和落户中，需要医疗诊断和进行亲子鉴定的，由企业出资，区卫生和计生局协调医疗机构，办理诊断、鉴定证明。（责任单位：区卫生和计生局、恒大集团、三亚蜈支洲岛度假中心、中国交通建设集团有限公司、铁汉生态环境股份有限公司、中国保利集团公司、复星集团、三邦友）

（三）改善住房条件。掌握贫困户的住房条件，由企业出资帮助部分贫困户进行房屋修缮和危房改造，切实解决贫困户的住房安全问题，保障贫困户的住房条件。（责任单位：区住房与城市建设局、区民政局、恒大集团、三亚蜈支洲岛度假中心、中国交通建设集团有限公司、铁汉生态环境股份有限公司、天津房地产发展股份有限公司）

（四）保障文化教育。了解贫困户子女教育情况，使贫困户家庭子女的九年义务教育巩固率达93%以上，保障学生就近上学；企业资助贫困户子女义务教育期间的生活费用。（责任单位：区教育科技局、中国保利集团公司、三亚蜈支洲岛度假中心、复星集团、好汉坡酒店）

（五）引导就业创业。了解贫困户家庭的就业情况，引导贫困户家庭成员就业创业，通过就业创业推动脱贫。（责任单位：区人力资源和社会保障局）

（六）社会保障兜底脱贫。按照“保基本、兜底线、促公平、可持续”的基本原则，对建档立卡贫困户，按照国家相关政策，由政府兜底脱贫，做到应保尽保。对贫困老年人，按规定发放基本养老金和高龄生活补贴；对生活困难残疾人，发放残疾人专项补贴。对符合条件的“特困人员”、孤寡老人等贫困群众，全部纳入最低生活保障和“特困人员”供养范围。（牵头单位：区民政局）

五、工作要求

（一）提高认识。全区各职能部门要以高度的责任感，充分认识到精准扶贫工作的重要性、复杂性和艰巨性，将此项工作列入重要议事日程，做好组织协调和落实，认真做好脱贫结对工作，确保精准脱贫工作不走样。

（二）明确责任分工。区各职能部门要切实履行好精准扶贫攻坚主体责任，将工作任务细化分解到人。要深入了解贫困户的情况，切实将各项帮扶项目扶持到根本上。对于在精准脱贫工作不作为的相关责任人要严格追究责任。

（三）加强宣传。在全区大力宣传中央省市精准脱贫战略部署和扶贫开发政策，要求全区上下树立大局观念，积极参与到精准脱贫攻坚工作上来，要充分利用网络等媒体工具，大力宣传精准脱贫工作的重大意义和工作成效，鼓励辖区内企业和广大市民积极参与，着力营造全社会支持和参与扶贫工作的浓厚氛围。

（四）经费保障。为确保精准脱贫攻坚工作顺利实施，区政府安排专项工作经费以及工作车辆用于开展精准脱贫攻坚工作。
