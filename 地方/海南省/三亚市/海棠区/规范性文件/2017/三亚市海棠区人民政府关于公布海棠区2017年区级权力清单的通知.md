# 三亚市海棠区人民政府关于公布海棠区2017年区级权力清单的通知

三亚市海棠区人民政府

关于公布海棠区2017年区级权力清单的通知

区各有关单位：

根据《三亚市人民政府办公室（三府办﹝2015﹞357号）》要求，以建设“有限、有为、有效”的法治政府和服务型政府为目标，按照职权法定、简政放权、权责一致、公开透明、便民高效、问题导向的原则编制汇总的《三亚市海棠区2017年区级权力清单》已经二届区政府第32期常务会议审议通过，现予以公布。

区级权力清单具有刚性约束力，各相关部门必须严格执行，切实做到“政府权力进清单、清单之外无权力”，不得擅自变更权力，并严格执行“法定权责必须为、法无授权不可为”落实责任主体。区级权力清单实行动态管理，根据法律、法规的颁布、修改、废止以及部门职能变化，及时调整完善。区级权力清单的调整，由权力行使单位提出，经区编办、区法制办、区政务服务中心联合审核后报区政府审定。《三亚市海棠区2017年区级权力清单》在三亚市政府门户网站上公布，接受人民群众监督。
