# 三亚市海棠区人民政府关于印发海棠区2017年财政扶贫资金安排方案的通知

三亚市海棠区人民政府

关于印发海棠区2017年财政扶贫资金安排方案的通知

各单位：

《海棠区2017年财政扶贫资金安排方案》已经区政府同意，现印发给你们，请认真贯彻执行。

三亚市海棠区人民政府

2017年4月25日

（此件主动公开）

海棠区2017年财政扶贫资金安排方案

为贯彻落实好2017年省市扶贫开发工作会议精神和工作部署，全面落实“一年脱贫攻坚，两年巩固提升，两年全面提高”的工作要求。根据《海南省人民政府办公厅关于印发海南省财政专项扶贫资金管理暂行办法的通知》（琼府办[2016]324号）的文件精神，结合市政府安排财政扶贫资金和我区扶贫工作实际，特制订如下方案：

一、 安排的资金来源

根据《三亚市财政局关于下达2017年财政扶贫资金的通知》（三财农[2017]14号）资金安排，市财政拨付我区2017年度财政扶贫资金139万元，区本级资金20万元主要用于发展种养殖产业扶贫、进行基础设施建设、扶贫培训、工作经费等。

二、 资金用途及使用原则

按照“精准扶贫、精准脱贫”的原则，结合我区扶贫工作实际，编制资金使用的项目计划（以实际支出为准），资金主要用于扶持我区南田居建档立卡贫困人口脱贫成效。

三、资金安排及建设内容

市级安排资金139万元，区本级资金20万元，共计159万元，具体建设内容如下。

（一）产业发展类投入104万元，主要用于根据地域特色发展效益高、惠及贫困户广的特色产业扶持项目，我区拟将采取政府+企业+贫困户模式，将财政产业扶贫资金委托海垦果业集团管理，贫困户定期取得固定分红。

（二）基础设施类投入20万元，主要用于房屋修缮等基础设施建设。

（三）扶贫培训类投入5万元，主要用于开展扶贫方面的种养殖类技术培训、工作培训等扶贫类培训，印刷培训教材，租赁培训场地等。

（四）工作开展经费10万元，主要用于入户调查、扶贫项目的监督管理、规划编制、项目评估、检查验收、档案管理、工作宣传、项目公告公示、培训考察、报账管理、会议经费、资料印刷费、油料费、工作用车租赁费、聘用工作人员等开支。

四、资金的管理使用

区财政、审计、纪检部门加强资金管理监督，资金使用部门须严格按照《海南省人民政府办公厅关于印发海南省财政专项扶贫资金管理暂行办法的通知》（琼府办[2016]324号）和《海南省人民政府办公厅关于印发海南省扶贫项目管理暂行办法的通知》（琼府办[2015]165号）等有关规定执行。
