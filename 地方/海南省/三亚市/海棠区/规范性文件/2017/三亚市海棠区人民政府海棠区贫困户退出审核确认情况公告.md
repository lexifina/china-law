# 三亚市海棠区人民政府海棠区贫困户退出审核确认情况公告

三亚市海棠区人民政府

贫困户退出审核确认情况公告

根据《三亚市建立贫困退出机制的实施方案》要求，我区对南田居上报的应退出贫困户20户56人进行了审核，同意将杨桂英等20户56人全部脱贫退出，现予以公告（名单附后）。如有异议，请从公告日起7日内向区人民政府提出意见。

监督电话：88810217

三亚市海棠区人民政府
