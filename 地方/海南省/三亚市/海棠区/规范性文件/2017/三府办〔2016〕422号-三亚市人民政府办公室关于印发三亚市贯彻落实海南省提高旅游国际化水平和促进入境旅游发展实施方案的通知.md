# 三亚市人民政府办公室关于印发三亚市贯彻落实海南省提高旅游国际化水平和促进入境旅游发展实施方案的通知

三亚市人民政府办公室

关于印发三亚市贯彻落实海南省提高旅游

国际化水平和促进入境旅游发展实施方案的通知

各区人民政府，各管委会，市政府直属各单位：

《三亚市贯彻落实海南省提高旅游国际化水平和促进入境旅游发展实施方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2016年12月31日

（此件主动公开）

三亚市贯彻落实海南省提高

旅游国际化水平和促进入境旅游发展实施方案

为进一步贯彻落实《国务院关于推进海南国际旅游岛建设发展的若干意见》（国发〔2009〕44号）的相关政策，推进《海南省人民政府关于印发海南省提高旅游国际化水平和促进入境旅游发展实施方案的通知》（琼府〔2016〕2号）的有关工作要求，大力提高我市旅游国际化水平，推进我市入境旅游发展，结合我市实际情况，制定本方案。

一、指导思想

贯彻落实《海南省人民政府关于印发海南省提高旅游国际化水平和促进入境旅游发展实施方案的通知》（琼府〔2016〕2号）的任务要求，利用我市的区位及资源优势，按照国际通行的旅游服务标准，推进旅游产业的转型升级，不断扩大对外开放，推动我市入境旅游市场的发展，把三亚建设成国际化热带滨海旅游精品城市和国际经济合作和文化交流的重要平台。

二、工作目标

打造世界一流的滨海休闲度假旅游目的地，进一步优化旅游要素配置，完善旅游基础设施和服务设施，规范旅游市场，大力提升旅游管理、营销、服务和产品开发的国际化水平，力争2016年实现入境游客增长6%以上，2018年实现入境游客增长8%以上；2020年实现入境游客增长10%以上，接待入境游客达60万人次以上。

三、工作措施

（一）完善旅游综合配套，提高整体服务质量，营造旅游国际环境。

1．提高城市管理水平和社会文明程度，按照国际标准增加公共标识，完善社会治安、医疗救助等功能，大力整治城市环境卫生。引导市民维护环境卫生，遵守公共秩序，保护生态环境，尊重游客权利，为游客提供宾至如归的良好条件。（牵头单位：各区政府；配合单位：市公安交警支队、市综合行政执法局、市园林环卫局、三亚质量技术监督局）

2．改善交通环境。按照中高端入境游客出游需求，实现机场、港口码头、火车站、城市公交与旅游区域交通的无缝对接。加快旅游车辆配置向市场化过渡，提高旅游车供给个性化订制，提高对入境游客的交通服务水平。（牵头单位：市交通运输局；配合单位：市旅游委、各区政府）

3．提高外币兑换的便利性，大幅增设货币兑换点。提高入境游客享受购物退免税政策的便利性，推动设立具备支付功能的离岛免税网上购物平台，争取在机场设立退税办理点。（牵头单位：市政府金融办；配合单位：国家外汇管理局三亚市中心支局、市财政局、三亚海关、凤凰机场）

4．提高旅游全要素的信息化水平，深入推进智慧旅游建设。完善旅游标识、旅游咨询等服务体系，全面提高旅游元素的国际化信息水平。推行主要旅游区域旅游公共服务场所wifi全覆盖。（牵头单位：市科技工业信息化局；配合单位：各区政府、市旅游委、市通信管理局、中国移动三亚分公司、中国电信三亚分公司、中国联通三亚分公司）

5．深度挖掘我市滨海和海岛、历史、民俗、民族等本土文化资源，增强境外游客文化体验。（牵头单位：市文化广电出版体育局；配合单位：市旅游委、市规划局、各区政府）

6．完善在机场、码头、车站、旅游酒店景区、旅游小镇、精品乡村旅游点及其他公共场所设立规范的汉英标识标牌，全面提高外语服务水平和标准，着力提高旅游从业人员外语水平，加强旅游英语100句的推广，推进国际语言环境建设。（牵头单位：市旅游委；配合单位：三亚质量技术监督局、市人力资源和社会保障局、市教育局、市综合行政执法局、各区政府、各大院校）。

7．允许我市旅游企业聘请一定数量的外籍人员担任高级管理人员和中层员工。（牵头单位：市人力资源和社会保障局；配合单位：市旅游委）

（二）对我市重点旅游景区、旅游点进行旅游国际化改造。

8．提高现有旅游产品的国际化水平，对我市主要度假区和核心旅游供应链进行国际化改造。加大适合境外游客旅游产品的开发力度。（牵头单位：相关区政府；配合单位：市旅游委、市发展改革委）

9．参照国内入境旅游发达城市及世界知名岛屿旅游目的地发展的经验和做法，对海棠湾“国家海岸”休闲度假区、凤凰岛邮轮母港的旅游设施、配套设施进行国际化改造，力争到2018年达到国际通行标准。到2020年，全市范围内的旅游设施、配套设施与国际通行标准接轨。（牵头单位：海棠、天涯区政府；配合单位：市发展改革委、市旅游委、市交通运输局、现代服务业产业园管委会、三亚凤凰岛邮轮港）

（三）针对国际市场需求，加快旅游产品的转型升级。

10．做大做强邮轮游艇旅游。加快我市邮轮母港和游艇码头等公共设施建设，创新符合国际惯例的通关模式和口岸监管协调机制。培育邮轮游艇市场，完善邮轮游艇扶持政策，加大邮轮游艇旅游的宣传推广，大力提高邮轮游客的数量。（牵头单位：市海防口岸局；配合单位：市发展改革委、市交通运输局、市旅游委、三亚海关、市外事侨务办公室、市财政局）

11．针对境外游客需求，打造海洋旅游、森林旅游、民族文化旅游、中医理疗游、房车露营游等旅游产品。细分境外市场，针对境外高端商务、家庭休闲、探亲访友、婚庆、会展、游学修学等群体，推出不同的专项产品。（牵头单位：市旅游委；配合单位：市商务局、市文化广电出版体育局、市林业局、市海洋渔业局、市卫生局、市农业局、市海防口岸局、各区政府、市教育局、各大院校）

12．结合资源和市场条件，打造一批能体现三亚特色、吸引境外游客、提升三亚国际旅游形象的品牌旅游节庆活动。（牵头单位：市旅游委；配合单位：市文化广电出版体育局）

13．加强旅游与体育赛事融合，筹划举办更多能吸引国际游客的国际体育赛事。（牵头单位：市文化广电出版体育局；配合单位：市旅游委、各区政府）

（四）加大航空补贴力度，优化航空补贴。

14．进一步加大航空补贴力度。继续加大对境外航线补贴的资金规模，严格按照《海南省整合和调整有关民航客运财政补贴政策条款实施办法》予以落实。（牵头单位：市财政局；配合单位：市旅游委、市海洋口岸局、凤凰机场、各航空公司驻三亚办事处）

15．整合航空补贴资金。推进省、市两级共同负担补贴金额，提升资金运用效率，放大资金使用效益，优化和平衡航班进港时刻，延长境外游客在我市停留时间。（牵头单位：市财政局；配合单位：市旅游委、市海防口岸局、凤凰机场、各航空公司驻三亚办事处）

（五）抓紧优化26国免签政策，全力争取全球免签政策。

16．以实现“全球免签”（即对与我国建交国家的公民个人来琼旅游免签证，并准其从国内享有72小时过境免签政策的城市中转来琼）为最终目标，加强基础设施建设，完善服务管理措施，提高队伍管控能力，尽早达到全球免签政策所需要的软硬件条件。（牵头单位：市公安局；配合单位：市旅游委、市外事侨务办公室）

（六）加大对外开放力度，提升海南国际旅游岛和三亚国际旅游城的形象。

17．每年对重点客源国家或客源市场组织几次大型的综合性促销活动，包括招商推介、旅游促销、房地产促销、文化展示、国际教育交流、境外媒体宣传等。（牵头单位：市旅游委；配合单位：市委外宣办、市商务局、市文化广电出版体育局、市住房城乡建设局、市教育局、市外事侨务办公室、各区政府）

18．切实加大我市的对外开放力度。积极参与国家各部委在国际上开展的推介等活动，加大请进来和走出去促销的力度。（牵头单位：市外事侨务办公室；配合单位：市旅游委、市商务局、各区政府）

19．大力发展国际会展旅游，加强国际会展品牌和国际会展企业的引进，加快会展基础设施建设和会展人才培养，积极发挥国际会展对我市入境旅游的拉动作用。加强我市现有会展环境、品牌会展的促销，吸引国际品牌经销商、专业买家来我市参展，特别是加强有我市直达航线国家和地区的会展营销。（牵头单位：市商务局；配合单位：市旅游委、各区政府）

20．提高餐饮业服务水平和国际化程度。鼓励餐饮企业开展转型升级，利用信息技术，打造“互联网+餐饮”，不断丰富经营模式，提升服务质量；吸引国际餐饮品牌入驻我市，提高三亚餐饮业的国际化水平。（牵头单位：市商务局；配合单位：市科技工业信息化局、市旅游委、各区政府）

（七）创新、扩大旅游营销体系。

21．加强三亚国际旅游城的整体形象设计。从宣传口号、媒体形象到文明理念、文明礼仪、服务标准、服务形象展示等对我市旅游整体形象进行创新、包装、宣传推广。（牵头单位：市旅游委；配合单位：市各有关部门、各区政府）

22．开展互联网营销。通过猫途鹰等国际著名旅游网站、重点客源国家和地区的主流旅游网站、脸书、推特等社交平台和三亚旅游资讯网的英、俄、韩、日、德五个外语网页，全方位推介我市的旅游形象、产品。（责任单位：市旅游委；配合单位：各区政府）

23．大力开展整合营销。我市出境公务团队增加宣传推广三亚旅游的工作内容，对“请进来”的国际客商和各类国际会议、国际培训也要积极开展旅游宣传促销。（牵头单位：市旅游委；配合单位：市商务局、市外事侨务办公室等有关单位）

24．加强与国际友城、华人华侨社团、国际旅游组织、境外旅游推广部门的交流合作，建立跨国界、跨地区的旅游营销网络，开展“一程多站”联合促销。（牵头单位：市旅游委；配合单位：市外事侨务办、各区政府）

25．加大“请进来”力度，组织邀请台湾、香港、俄罗斯、韩国等重点客源地的旅行商和媒体来我市考察踩线、拍摄，设计新的旅游线路，加大三亚旅游在境外的宣传力度。（牵头单位：市旅游委；配合单位：各区政府）

26．加强与大集团、大平台的跨界合作，与国内的大型旅游集团公司、跨国企业、大型航空公司、大型银行、大型影院进行合作营销。（牵头单位：市旅游委；配合单位：各区政府）

（八）加大旅游促销经费的投入，在境外设立营销机构。

27．加大旅游促销经费的投入。加强与俄罗斯、韩国、日本、东南亚等重要客源国、客源地区的知名媒体合作，在我市海外客源市场积极投放形象推介广告。全面开展网络营销，更加积极有效地实施走出去、请进来等促销力度。对入境旅游的开发进行奖励和支持，从2017年起市财政对旅游宣传促销经费每年递增1500万元，到2020年达到1.1亿元。加强对旅游促销资金使用情况的绩效考评，建立旅游促销资金与旅游产业发展综合绩效相挂钩的联动机制。（牵头单位：市财政局；配合单位：市旅游委）

28．在境外设立旅游推广分支机构。落实《国务院关于推进海南国际旅游岛建设发展的若干意见》中赋予海南在海外主要旅游客源地设立旅游推介分支机构的政策，加强与我国有关部门在境外重点客源城市的外驻机构、当地航空公司、主要组团社的合作，设立我市的境外旅游推广办事处，对客源市场开展市场调研、媒体公关和新闻宣传，联络旅行商开展专项促销、展会促销等，同时利用在当地举行的重大国际性旅游促销活动积极促销三亚旅游。（牵头单位：市旅游委；配合单位：市财政局）

（九）出台支持奖励旅游企业政策。

29．制定入境旅游奖励办法，充分发挥旅游企业市场主体作用，对本市企业赴境外参展、组织推介会、请进来促销和其它营销创新项目予以资金支持。对境外组团社、邮轮旅游经营企业、会展企业、酒店等企业根据开拓入境旅游业绩进行资金奖励。市财政每年列专项补贴奖励资金1500万元。（牵头单位：市旅游委；配合单位：市财政局）

（十）规范旅游市场秩序，提高旅游服务水平。

30．加大市场监管力度，严厉打击欺客宰客行为，维护三亚旅游对外形象，为境内外游客提供安全、舒心的旅游环境。进一步完善现有的旅游市场联合执法机制，积极探索旅游市场监管体制机制改革，逐步实现联合执法向综合执法的过渡。（牵头单位：市旅游委；配合单位：市工商行政管理局、市公安局、市交通运输局、市物价局、市国家税务局、各区政府）

31．提升旅游服务水平，强化旅游标准化建设。完善市级旅游标准化技术委员会组织机构和地方旅游标准体系。强化旅游企业质量主体地位，实施旅游服务质量标杆单位创建和旅游服务质量对比提升活动。编制《三亚市旅游质量发展纲要》，提升全行业的旅游质量观，提升旅游服务质量宏观指导水平。（牵头单位：市旅游委；配合单位：三亚质量技术监督局、各区政府）

四、工作要求

（一）提高思想认识，抓好任务落实。提高旅游国际化水平和促进入境旅游发展对全面提升我市国际化旅游精品城市建设水平、打造世界一流的滨海休闲度假旅游目的地和国际经济合作及文化交流平台至关重要，全市各有关单位要进一步增强责任心、使命感，切实提高思想认识，聚焦任务要求，加强组织领导，确保工作任务按期完成。

（二）坚持问题导向，务求工作实效。全市各有关单位要对照实施方案及任务分解表，对责任事项进行认真梳理，找准存在问题，研究方法路径，制定解决措施，确保各项工作落到实处。

（三）明确职责分工，加强督查督办。实施方案对相关工作进行了责任分解，明确了牵头单位和配合单位。全市各有关单位要依据实施方案及任务分解表确定的工作任务和时间进度，进一步细化工作方案，明确具体工作任务、责任人和推进时间表，确保责任事项按计划推进落实。各牵头单位对所牵头的责任事项的落实负总责，配合单位要严格按照分工要求，积极参与、密切配合，共同完成责任事项涉及的各项任务。市政府督查室加强工作定期督办。
