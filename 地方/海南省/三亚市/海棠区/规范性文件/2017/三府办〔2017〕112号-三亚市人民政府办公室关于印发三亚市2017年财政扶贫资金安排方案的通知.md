# 三亚市人民政府办公室关于印发三亚市2017年财政扶贫资金安排方案的通知

三亚市人民政府办公室关于印发

三亚市2017年财政扶贫资金安排方案的通知

各区人民政府，育才生态区管委会，市各相关单位:

《三亚市2017年财政扶贫资金安排方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年4月19日

（此件主动公开）

三亚市2017年财政扶贫资金安排方案

为贯彻落实好2017年全省扶贫开发工作会议精神，按照市委、市政府有关扶贫开发的工作部署，全面落实“一年扶贫攻坚，两年巩固提升，两年全面提高”的工作要求。根据《海南省人民政府办公厅关于印发海南省财政专项扶贫资金管理暂行办法的通知》（琼府办〔2016〕324号）的文件精神，结合我市扶贫工作实际及各区（育才生态区）扶贫项目资金需求，特制定如下方案：

一、安排的资金来源

将市财政安排的2017年度财政扶贫资金预算2500万元，统筹安排下拨至天涯区、崖州区、吉阳区、海棠区、育才生态区及市有关单位，主要用于发展种养殖产业扶贫、进行基础设施建设、电商扶贫及扶贫培训等。

二、资金用途及使用原则

按照“精准扶贫、精准脱贫”的原则，结合本地区扶贫工作实际，编制资金使用的项目计划，资金主要用于扶持我市建档立卡贫困人口、巩固提升已脱贫人口及已脱贫行政村的脱贫成效。截至2017年3月22日统计，我市2014年至2017年建档立卡贫困人口（含已脱贫）为2255户10067人，其中7户19人为我市新增贫困人口，35户95人为原农垦城镇户籍贫困人口。

根据《三亚市财政局关于批复2017年本级部门预算的通知》（三财〔2017〕90号）的文件精神，市财政安排2017年度财政扶贫资金预算2500万元，拟分配至产业发展类、基础设施类、电商扶贫、扶贫培训等4大类，力争到2017年底实现贫困人口如期脱贫退出，已脱贫人口全面巩固提升，已摘帽出列贫困村经济社会全面协调发展，生产生活条件明显改善。各类资金分配情况如下：

（一）产业发展类投入1820.48万元，主要用于各区（育才生态区）根据地域特色发展效益高、惠及贫困户广的特色产业扶贫项目。

（二）基础设施类投入379.52万元，主要用于房屋修缮、发展光伏扶贫等基础设施建设。

（三）扶贫培训类投入50万元，主要用于在全市各区（育才生态区）开展扶贫方面的种养殖类技术培训、工作培训等扶贫类培训，印刷培训教材，租赁培训场地等。

（四）电商类投入100万元，主要用于通过发展电商、举办农产品销售大集等各类促进扶贫农产品销售的活动。

（五）工作开展经费150万元，主要用于入户调查、扶贫项目的监督管理、规划编制、项目评估、检查验收、档案管理、工作宣传、项目公告公示、培训考察、报账管理、会议经费、资料印刷费、油料费、工作用车租赁费、聘用工作人员等开支。

根据文件要求及财政预算扶贫资金的使用要求，坚持以巩固提升脱贫成效为重点，结合我市各区（育才生态区）区位优势、产业基础及贫困户巩固提升的需求，采取多种扶持方式，精准扶持到户，统筹安排2017年度市级财政专项扶贫资金2500万元。

三、资金分配及建设内容

根据《海南省人民政府办公厅关于印发海南省财政专项扶贫资金管理暂行办法的通知》（琼府办〔2016〕324号）文件，以及各区（育才生态区）扶贫工作项目资金需求，今年我市将按照产业帮扶未脱贫人口2万元/人的标准，巩固提升已脱贫人口1600元/人的标准及扶贫工作需要，向各区（育才生态区）拨付扶贫专项资金。具体安排如下：

（一）育才生态区：分配资金938.88万元。主要用于巩固提升已脱贫建档立卡贫困人口1012户4627人和已脱贫出列行政村的脱贫成效，帮扶立才居居委会5户14人实现脱贫出列。其中，发展产业扶贫类项目计划投入768.32万元，基础设施类计划投入140.56万元，扶贫培训计划投入5万元，工作经费25万元。

（二）天涯区：分配资金568.24万元。主要用于完成2016年新增5户12人的如期脱贫、巩固提升已脱贫建档立卡贫困人口613户2783人和已脱贫出列行政村的脱贫成效、帮扶南岛居居委会5户11人实现脱贫出列。其中，发展产业扶贫类项目计划投入491.28万元，基础设施类计划投入56.96万元，扶贫培训计划投入5万元，工作经费15万元。

（三）崖州区：分配资金483.68万元。主要用于完成2016年新增2户7人的如期脱贫、巩固提升已脱贫建档立卡贫困人口501户2198人和已脱贫出列行政村的脱贫成效、帮扶南滨居居委会5户18人实现脱贫出列。其中，发展产业扶贫类项目计划投入401.68万元，基础设施类计划投入62万元，扶贫培训计划投入5万元，工作经费15万元。

（四）吉阳区：分配资金65.2万元。主要用于巩固提升已脱贫建档立卡贫困人口87户345人。其中，发展产业扶贫类项目计划投入55.2万元，扶贫培训计划投入5万元，工作经费5万元。

（五）海棠区：分配资金139万元。主要用于帮扶南田居居委会20户52人实现脱贫出列。其中，发展产业扶贫类项目计划投入104万元，基础设施类计划投入20万元，扶贫培训计划投入5万元，工作经费10万元。

（六）市农业局（市扶贫开发办）：分配资金295万元。其中，基础设施类计划投入100万元，电商扶贫类计划投入100万元，扶贫培训计划投入25万元，工作经费70万元。

（七）市南繁科学技术研究院：分配工作经费10万元，主要用于建立基层农技服务站点，便于贫困户在生产过程中遇到的种植类的技术问题时，能够及时联系专家，第一时间给予解决。

安排到各区（育才生态区）、各单位的扶贫资金，各区（育才生态区）、各单位可结合工作实际自行适当调整，有较大资金需求的项目可另向市扶贫开发办申报，市扶贫开发办研究后视情况呈报市政府审议。各区（育才生态区）、各单位应根据扶贫工作实际制定具体的资金使用方案，并配套本区、本单位的扶贫资金，加快资金使用进度。

四、资金的管理使用

此项资金，请严格按照《海南省人民政府办公厅关于印发海南省财政专项扶贫资金管理暂行办法的通知》（琼府办〔2016〕324号）和《海南省人民政府办公厅关于印发海南省扶贫项目管理暂行办法的通知》（琼府办〔2015〕165号）等有关规定执行。要求各区（育才生态区）结合本区的实际情况，认真研究制定相应的资金使用方案，并于4月28日前报市扶贫开发办备案。
