# 三亚市人民政府办公室关于印发三亚市河长制管理工作考核办法的通知

三亚市人民政府办公室关于

印发三亚市河长制管理工作考核办法的通知

各区人民政府，育才生态区管委会，市各有关单位：

《三亚市河长制管理工作考核办法》已经七届市政府第8次常务会议同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年4月19日

（此件主动公开）

三亚市河长制管理工作考核办法

为推进全市河湖环境综合整治，进一步改善水环境，加强对各区政府、育才生态区管委会河湖水环境的河长制（以下简称河长制）管理工作的考核，特制定本办法。

一、考核范围

列入《三亚市全面推行河长制工作方案》中的河湖及其它城市黑臭水体均在本办法考核范围内，共分为以下二类：

（一）《三亚市全面推行河长制工作方案》中规定的河长制管理的河湖。

（二）其它城市黑臭水体，该项应由各区政府（管委会）自行列入本区政府（管委会）河长制实施方案。

二、考核方式

各区政府（管委会）河长制管理工作的考核包括部门督查和年度考核二种方式。

（一）部门督查

部门督查采取定期督查考核的方式，督查组由市水务局、市生态环境保护局、市园林环卫局、市住房城乡建设局、市综合执法局等相关部门人员组成，负责各区政府（管委会）河长制的部门督查考核工作，并将各个季度督查考核的结果汇总上报市河长制管理工作领导小组。

督查考核的时间为每个季度的最后一个月，督查组根据各相关部门的职责和工作实际，通过现场检查与台账核查，确定各自负责考核指标的督查考核方法，并依据《三亚市河长制管理工作考核评分表》（见附件3）对单条河道相关指标进行打分，各区政府（管委会）所管辖的所有河道得分的算术平均值即为该区政府（管委会）河长制管理工作季度督查考核的最终得分。

（二）年度考核

年度考核由三亚市河长制管理工作领导小组负责组织，考核组的组长由市河长制管理工作领导小组确定，考核组成员由市河长办的各相关部门的人员组成，考核时间为下一个年度的1月底前。

每年12月底前，各区政府（管委会）应对照考核内容对本年度河长制工作情况进行自查，并按照《河长制工作自查报告编制大纲》（见附件2），形成自查报告，于12月底前以正式文件报三亚市河长制管理工作领导小组，并抄送市河长办组成部门。

考核组在审核各区政府（管委会）的河长制管理工作自查报告的基础上，综合分析各相关部门定期对各区政府（管委会）河长制工作进行季度督查考核的情况，并在每个区政府（管委会）管辖的河道中抽查2－3条河道，现场打分确定被抽查的河道年底考核得分。检查各区的河长制工作完成情况并得出综合考核得分，通过计算确定各区河长制工作年度考核的综合得分。

（三）考核结果通报

由市政府对河长制工作的部门督查、年度考核等情况向全市进行通报。

三、考核内容及评分

各区政府（管委会）河长制考核及评分共分为部门季度督查和市领导小组年度考核两种情况，从单条河道考核、综合考核两个方面进行考核。河道季度督查考核分数按百分制计算，年底河道抽查分数按百分制计算，区政府（管委会）综合考核分数按总分20分计算，年终考核总分按百分制计算。

（一）部门季度督查考核内容及评分

部门季度督查考核内容主要是对所管辖的河道进行考核，主要包括水质目标、管理机制、水环境整治工作及河道管护等四个方面。水质目标考核指标主要由市生态环境保护局负责考核打分；管理机制考核指标主要由市水务局、市生态环境保护局负责考核打分；整治工作考核指标主要由市水务局、市住房城乡建设局负责考核打分；河道管护工作中考核指标主要由市园林环卫局、水务局、市住房城乡建设局负责考核打分。单条河道的具体考核内容为：

1.水质目标，得分制，总计30分，包括：水质情况、水体感官情况。

2.管理机制，得分制，总计25分，包括：组织机构及制度建立、河道整治日常跟踪情况、定期监测及上报信息、河道周边环境监管。

3.整治工作，得分制，总计25分，包括：整治方案的制定与论证、控源截污工程推进和完成情况，河道堤防的建设、河道清淤疏浚、河流水质净化工程的推进和完成情况，河岸生态景观工程推进和完成情况。

4.河道管护工作，得分制，总计20分，包括：河道保洁管护制度的建立、河道保洁情况、河道附属设施管护及河道运行安全情况。

部门督查考核总分=所有河道的季度督查考核分数的算术平均值

（二）对区政府（管委会）的综合考核内容及评分

综合考核是对区政府（管委会）河长制工作的全面完成情况及取得的社会效果的评价。区政府（管委会）综合考核分数为总分20分，下列情况每发生一例扣一分，群众举报或投诉的污染事件未及时处理、群众举报或投诉的侵占河道事件未及时处理、河湖淹溺事件、上级领导检查发现辖区内黑臭水体情况、媒体报道辖区内黑臭水体情况、媒体报道辖区内污水直排河道情况、媒体报道黑臭水体未纳入河长制管理情况。

（三）年度考核内容及评分

各区政府（管委会）河长制管理工作年度考核得分按照考核内容和评分中综合考核方法确定，根据辖区内每一条河道考核得分、现场抽查河道考核情况得分、综合考核得分等进行测算。

年终考核总分=（所有河道季度督查考核的平均分数*50%+所有年底抽查河道的平均分数*50%）*80%+区政府（管委会）综合考核分数。

四、考核等次

对单条河道考核、区政府（管委会）河长制工作综合考核结果均划分考核等次。考核结果分优（考核分数80分以上，含80分，下同）、良（考核分数70分以上，80分以下）、中（考核分数60分以上，70分以下）、差（考核分数60分以下，未通过考核）。

五、考核结果应用

加强对河长制年度考核结果的应用，以进一步推动河道综合整治工作的开展。对考核结果为优、良的单位及个人进行表彰奖励，对水环境河长制管理工作未通过考核、河道环境综合整治推进不力的单位及个人进行问责，并向社会公布。
