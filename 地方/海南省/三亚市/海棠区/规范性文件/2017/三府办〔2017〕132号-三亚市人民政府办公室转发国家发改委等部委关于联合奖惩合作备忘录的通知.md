# 三亚市人民政府办公室转发国家发改委等部委关于联合奖惩合作备忘录的通知

三亚市人民政府办公室

转发国家发改委等部委关于联合奖惩

合作备忘录的通知

市社会信用体系建设联席会议成员单位，各有关部门：

加快社会信用体系建设是党中央、国务院的战略决策，党的十八大、十八届三中、四中、五中、六中全会，中央全面深化改革领导小组会议，国务院都做出了一系列的工作部署，密集出台了与社会信用体系建设密切相关的改革文件。2015年以来，社会信用体系建设部际联席会议牵头部门、各成员单位密集签订了20个联合奖惩合作备忘录，其中：3个联合激励备忘录、17个联合惩戒合作备忘录，现转发给你们，并提出以下要求。

一、部际联合奖惩合作备忘录是由国家发改委、人民银行牵头（简称部际牵头部门）印发，由具体行业（领域）部委发起（简称部际发起部门），其他部委响应（简称部际响应部门）的对守信激励、失信惩戒的一种方式，多部门约定了联合奖惩对象、范围、措施和信息共享、实施方式的合作具体办法。部际发起部门是具体行业（领域）联合奖惩的牵头部门，与部际响应部门相互协调、共同配合负责该行业（领域）联合奖惩合作备忘录的组织实施、协调沟通工作。部际联合奖惩合作备忘录已通过部际牵头部门、发起部门、响应部门下发到我市各单位。

二、发起部门的市级单位（简称市级发起部门）要主动承担责任，牵头负责做好本行业（领域）联合奖惩合作备忘录在市级层面的落实工作，牵头协调相关部门（简称市级响应部门）采取签署市级联合奖惩合作备忘录，建立联合奖惩机制、协调沟通机制、信息共享机制等多种方式，兑现部际联合奖惩合作备忘录各项奖惩措施，使守信者得到激励和支持，失信者“一处失信、处处受限”，加快推进我市联合奖惩工作。

三、市级发起部门要牵头建立行业（领域）信用信息系统，建立信用信息共享工作机制，梳理联合奖惩合作备忘录中联合奖惩具体措施，与响应部门做好对接，按要求把联合奖惩事项推送给响应部门，由响应部门实施联合奖惩。响应部门要主动承接联合奖惩事项，在本行业（领域）的行政管理、行政服务中必须查询联合奖惩事项，对行政管理、行政服务相对人实施联合奖惩。

四、市级发起部门、响应部门要在行政管理、行政服务中详细记录联合奖惩的响应情况，重点记录典型案例，如实反映联合奖惩的实施情况并每月定期向发起部门报告。发起部门汇总联合惩戒的实施情况，每月定期向市信用办（市金融办）报告。

五、市级发起部门、响应部门在落实部际联合奖惩合作备忘录过程中，要积极向上级主管部门汇报情况，争取上级主管部门指导和培训，交流、学习同行业（领域）其他城市的先进经验，加强与市信用办沟通协调，共同努力把联合奖惩合作备忘录在我市落到实处。

六、由于部际联合奖惩合作备忘录内容较多，请发起部门、响应部门在市信用办（金融办）邮箱自行下载，在贯彻落实过程中遇到具体问题可及时与市信用办联系。下载邮箱：syjrbxiazai@163.com（密码：88756452），联系人：符元瀚，联系电话：88756957。
