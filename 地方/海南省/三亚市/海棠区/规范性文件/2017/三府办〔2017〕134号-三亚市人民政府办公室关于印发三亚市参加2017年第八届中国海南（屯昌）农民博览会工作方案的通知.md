# 三亚市人民政府办公室关于印发三亚市参加2017年第八届中国海南（屯昌）农民博览会工作方案的通知

三亚市人民政府办公室

关于印发三亚市参加2017年第八届

中国海南（屯昌）农民博览会工作方案的通知

各区人民政府，育才生态区管委会，市各相关单位:

《三亚市参加2017年第八届中国海南（屯昌）农民博览会工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年5月2日

（此件主动公开）

三亚市参加2017年第八届

中国海南（屯昌）农民博览会工作方案

根据《海南省人民政府办公厅关于印发2017年第八届中国海南（屯昌）农民博览会总体筹备方案的通知》（琼府办〔2017〕63号）精神，2017年第八届中国海南（屯昌）农民博览会（以下简称农博会），将于2017年5月19日至21日在屯昌县举行。按照省政府的统一部署和具体要求，做到早策划、早布署、早落实，为确保2017年农博会的各项筹备工作真正落到实处，特制定本方案。

一、活动主题、原则和宗旨

本届农博会以“循环、标准、农业+”的参会主题，坚持“节俭、创新、务实、服务”的参会原则，突出宣传我市优越的生态环境和资源优势，充分展示我市热带特色农业发展、精准扶贫成果。着力加强农业供给侧结构性改革，推动我市农业转型升级，打造绿色、有机、安全的农产品品牌，引导我市农民以市场为导向，加快调整种养结构，发展多种形式适度规模经营，充分利用农业产业扶贫资源，扎实推进农业精准扶贫各项措施落地生根，统筹推进美丽乡村和特色小镇的建设，努力走出我市特色现代农业发展之路，促进农民增收，带动农民脱贫致富。

二、组织机构

（一）代表团

团　长：李劲松　　（市政府副市长）

副团长：陈文军　　（市农业局局长、市扶贫办主任）

成　员：市农业局、市商务局、市林业局、市海洋与渔业局、市科技工业信息化局、市供销合作社等职能部门分管领导，各区政府、育才生态区管委会分管领导，龙头企业、农民专业合作组织、种养大户代表、贫困户代表，三亚市参加农博会工作人员。

（二）筹备工作领导小组

组　长：陈文军　　（市农业局局长、市扶贫办主任）

副组长：冯永杰　　（市农业局副局长）

工作领导小组下设办公室在市农业局，办公室主任由冯永杰同志担任，办公室负责筹备参加农博会的日常工作；负责参会人员的确定、邀请、联络协调，会议日程和会务安排等工作。

参会工作人员由农博会筹备工作领导小组根据需要从有关单位抽调。

三、重点工作内容及任务分解

（一）组织参展

市农业部门要协同各区农业部门组织辖区农业龙头企业、农业专业合作、种养大户、扶贫企业、贫困户参加此次农博会，主要突出展示我市的优势瓜菜产品、热带水果、畜禽产品、海产品、林业产品和加工品等特色农产品。

1.申报方式：

（1）由各区推荐，生产企业、合作社、种养大户、扶贫企业、贫困户自荐，并由市农业局审核后组织参展；

（2）根据参展需要，由市农业局直接指定相关企业、合作社、种养大户、扶贫企业、贫困户参展。

2.申报时间：

各区、参展的企业、合作社、种养大户、扶贫企业、贫困户于5月5日前报送参展名单、参展产品等相关资料，各区和市相关职能部门于5月10日前报送参加人员名单，报至市农业局种植业科。联系人：赵小飞，联系电话：88672505，邮箱：synyjzzyk@163.com。

3.参展要求：

（1）所有展品要具有包装和品牌；

（2）参展水果和瓜菜（鲜活畜禽产品除外）需在5月16日前送市现代农业检验检测预警防控中心进行定量检测合格后方能参展（送检样品与参展产品必须出自同一生产者和同一生产基地）；

（3）布展工作需在5月18日中午前完成。

（二）参加开幕式

我市参会代表团成员，参加5月19日在屯昌县农博城举行的农博会开幕式和巡馆活动。

市农业局负责组织代表团全体成员参加开幕式，各区具体负责组织本辖区内参会人员参加开幕式。

（三）组织参加农博会系列活动

时间：2015年5月19日—21日

参加农博会组委会组织的系列活动，进驻市县展馆展示展销我市特色品牌农产品、我市农业精准扶贫成效，组织参加第三届海南省农产品擂台赛评比活动、农产品产销对接及采购项目签约仪式、海南生态循环农业标准化建设论坛、海南“农产品网上行”电子商务优质资源推进会暨电商扶贫经验交流会、美食评比及体验等活动。

四、工作要求

（一）加强领导

各责任单位必须加强组织领导，明确工作任务，落实责任，分工协作，确保参展产品品质和质量安全,积极协调相关企业、合作社、种养大户、扶贫企业和贫困户代表参会，抓好各项工作的落实。

（二）做好宣传

1.多方宣传、联合发动符合参展的企业、合作社、种养大户、扶贫企业和贫困户参会；

2.组织驻三亚媒体记者，对农博会宣传报道。

（三）精选展品

认真筛选展品，突出我市的特色和实施精品立市的战略，高质量、严要求，杜绝“无证”产品参展，展示三亚精品农业形象。

（四）抓好促销

市各相关部门要主动积极组织企业与产销大户进行市场营销，利用好农博会平台积极开展产销对接、订单洽谈等活动，确保会展期间的订单贸易和项目招商取得新突破。

（五）做好保障

农博会是我省夏季的重要农业展会，对展示我市农产品品牌，提升农产品质量安全，促进产销对接意义重大。因此，各成员单位要以高度负责的态度认真抓好抓实，确保责任、分工、人员、经费和措施“五到位”。会后要认真进行总结，找出不足，以便在今后参加类似展会活动时办得更好。
