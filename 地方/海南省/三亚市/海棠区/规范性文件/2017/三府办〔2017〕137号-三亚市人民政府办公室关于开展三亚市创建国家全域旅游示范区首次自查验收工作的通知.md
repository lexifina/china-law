# 三亚市人民政府办公室关于开展三亚市创建国家全域旅游示范区首次自查验收工作的通知

三亚市人民政府办公室

关于开展三亚市创建国家

全域旅游示范区首次自查验收工作的通知

市各相关单位：

为认真贯彻国家旅游局《关于开展“国家全域旅游示范区”创建工作的通知》（旅发〔2015〕182号）文件精神和市委、市政府关于加快推进全域旅游的工作要求，根据《海南省创建国家全域旅游示范区认定标准》（以下简称标准），我市将在今年5月组织开展全域旅游示范区首次自查验收工作。具体要求如下：

一、抓紧落实全域旅游《三亚市全域旅游发展规划（2016―2020）》、《三亚市创建国家全域旅游示范区工作方案及实施计划（2016―2020）》及《三亚市创建国家全域旅游示范区2017年迎检验收重点推进工作方案》中的各项工作。

二、对照《标准》中《海南省各市县创建国家全域旅游示范区验收评分表》以及附件中的责任分工开展自查验收工作，结合验收指标下的考核明细，汇编评分表内的相应材料，形成自查验收报告，于2017年5月25日前将电子版报送至市创建国家全域旅游示范区领导小组办公室（电子邮箱：3531351641@qq.com，联系人：孙欢，联系方式：88272318）。

附件：对标《海南省各市县创建国家全域旅游示范区验收评分表》自查验收分工表

三亚市人民政府办公室
