# 三亚市人民政府办公室关于调整三亚市政府新闻信息领导小组的通知

三亚市人民政府办公室

关于调整三亚市政府新闻信息领导小组的通知

各科室：

因人事变动和工作需要，市政府决定调整三亚市政府新闻信息领导小组。现将市政府新闻信息领导小组成员通知如下：

组　长：吴岩峻 （市委副书记、市长）

副组长：鲍　剑 （市委常委、常务副市长）

陈　明 （市政府秘书长）

组成人员：市政府各副秘书长、市政府研究室主任、市政府督查室主任、市科技工业信息化局局长。

领导小组成员如发生职务调整或变动，则由接任其职务者自然替补。领导小组下设办公室，挂靠市政府办公室，由市政府研究室主任陈潇兼任办公室主任。

领导小组办公室将紧密结合市政府工作主要目标和重点任务，在办好“中国三亚”政府门户网站的同时，运用市政府官方微博、微信公众号在新媒体上充分反映市政府重要会议、活动和决策内容，及时准确发布政府信息，开展交流互动，倾听公众意见，回应社会关切，接受社会监督，使新媒体成为公众和其他媒体获取市政府信息的第一来源、互动交流的重要渠道。

三亚市人民政府办公室

2017年5月5日

（此件主动公开）
