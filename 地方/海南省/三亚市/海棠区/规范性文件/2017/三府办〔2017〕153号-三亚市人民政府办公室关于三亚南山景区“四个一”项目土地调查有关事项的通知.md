# 三亚市人民政府办公室关于三亚南山景区“四个一”项目土地调查有关事项的通知

三亚市人民政府办公室

关于三亚南山景区“四个一”项目土地调查

有关事项的通知

崖州区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对南山景区“四个一”项目用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于崖州南山景区内，包含一期和二期两部分工程，其中：

一期项目用地面积约762443平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市规划局出具的三亚南山景区“四个一”项目一期约1143.65亩用地界址图。土地权属（海南平面坐标系）情况为崖州区南山村委会集体土地约503832平方米、国家所有（原详查资料）土地约3818平方米、三亚市人民政府国有土地约34071平方米、海南南山文化旅游开发有限公司国有土地约212717平方米、三亚南山观音苑建设发展有限公司国有土地约4676平方米、中国石油化工股份有限公司海南石油分公司国有土地约234平方米、三亚长丰海洋天然气供气有限公司国有土地约3095平方米；土地利用现状（西安80坐标系）为农用地约418377平方米（其中水田约141791平方米、旱地约197440平方米、果园约3058平方米、其他园地约12685平方米、有林地约19444平方米、灌木林地约40073平方米、坑塘水面约3533平方米、设施农用地约353平方米）、建设用地约344671平方米（其中建制镇约1216平方米、村庄约127755平方米、风景名胜及特殊用地约215700平方米）；该项目用地在土地利用总体规划调整完善（西安80坐标系）中规划为风景名胜设施用地约311227平方米、公路用地约57434平方米、旱地约128623平方米、林地约9943平方米、农村居民点用地约12242平方米、水田约79566平方米、园地约164015平方米。

二期项目用地面积约316150平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市规划局出具的三亚南山景区“四个一”项目二期约474.22亩用地界址图。土地权属（海南平面坐标系）情况为崖州区南山村委会集体土地约314239平方米、三亚市人民政府国有土地约17平方米、海南南山文化旅游开发有限公司国有土地约704平方米、海南南山公用工程有限公司国有土地约1190平方米；土地利用现状（西安80坐标系）为农用地约297172平方米（其中水田约107799平方米、旱地约137403平方米、有林地约35289平方米、灌木林地约6555平方米、坑塘水面约9814平方米、设施农用地约312平方米）建设用地约19235平方米、（其中建制镇约1586平方米、村庄约17649平方米）；该项目用地在土地利用总体规划调整完善（西安80坐标系）中规划为风景名胜设施用地约15548平方米、公路用地约14217平方米、旱地约122635平方米、坑塘水面约4598平方米、林地约14991平方米、水田约97106平方米、园地约47312平方米。

上述用地涉及的约584433平方米耕地在办理农用地转用时，从我市耕地占补平衡指标中统筹安排。待完成占补平衡任务后，由项目业主按要求提供用地报批材料，市国土资源局将其列入当年新增建设用地指标并办理农转用及征收报批手续。土地权属涉及海南南山文化旅游开发有限公司、三亚南山观音苑建设发展有限公司和海南南山公用工程有限公司的项目用地不列入征地补偿范围。具体征地范围以崖州区政府现场实际测量确认为准。

二、为做好该项土地调查工作，由崖州区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土资源局负责征收集体土地范围内征地业务指导工作；市住房城乡建设局负责收回国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行；收回国有土地征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、根据2010年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，崖州区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认，向市国土资源局出具履行征地前告知等程序的证明及土地权属确认意见（附件1）。待有权限的人民政府批准征地后，征收土地公告和征地补偿安置方案公告可同步进行。

五、为进一步做好被征地农民养老保险工作，根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神，应在本通知下发后10个工作日内对项目征收农用地和享受缴费补贴人数等情况进行调查，组织村（居）小组填写《征地项目被征地农民基本情况调查表》（附件2)，经村（居）委会、崖州区政府逐级审核后，由崖州区政府汇总填写《征地项目被征地农民基本情况乡镇调查汇总表》（附件3)，并将上述两种表格报送市国土资源局。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。

七、因该项目用地规划调整，原市政府办公室印发的《关于三亚市南山旅游设施项目土地调查有关事项的通知》（三府办〔2017〕30号）文废止，涉及该项目用地的土地调查工作以本通知为准。
