# 三亚市人民政府办公室关于调整三亚市邮轮旅游推进工作领导小组的通知

三亚市人民政府办公室

关于调整三亚市邮轮旅游推进工作领导小组的通知

各区人民政府，各管委会，市政府直属各单位：

由于人事变动及工作需要，市政府决定调整三亚市邮轮旅游推进工作领导小组，具体组成人员及职责如下：

一、组织领导

组 长：鲍 剑 市委常委、常务副市长

副 组 长：李武军 市政府副秘书长

成 员：吴海峰 市交通运输局局长

张 利 市发展和改革委主任

王 瑜 市财政局局长

樊 木 市旅游发展委员会主任

黄海雄 市规划局局长

黎觉行 市住房和城乡建设局局长

左正和 市海防与口岸局局长

吴清江 市海洋与渔业局局长

高富宅 市国土资源局局长

陈宗琦 市公安局副局长

曾宪云 三亚凤凰岛国际邮轮港发展有限公司董事长

蔡建民 三亚凤凰岛国际邮轮港发展有限公司总经理

领导小组下设办公室，办公室设在市交通运输局，主任由市交通运输局局长吴海峰兼任。

二、责任分工

（一）市交通运输局：负责领导小组日常工作，统筹三亚市邮轮产业发展中相关问题的推进工作。负责协调各部门积极配合、共同推进邮轮港建设。

（二）市发展和改革委员会：负责研究国家和海南省关于21世纪海上丝绸之路发展规划，将三亚凤凰岛国际邮轮港规划建设成为海上丝绸之路重要站点和邮轮始发港；报海南省发展改革委请求国家有关部门批准三亚凤凰岛国际邮轮港区为自由贸易区；制定支持邮轮产业发展的相关配套政策。

（三）市财政局：负责落实有关支持邮轮旅游发展的财政和税收优惠政策；

（四）市旅游发展委员会：进一步完善《三亚市邮轮旅游发展专项规划》、《三亚市邮轮母港产业园总体规划》的编制和实施工作；负责研究开发和营销邮轮旅游产品，吸引远洋海域旅游航线邮轮访问三亚；积极寻求与国际邮轮公司合作，开辟区域性、近洋型国际航线旅游和地区性航线旅游；协调中资企业中有实力、有经验的国际旅行社经营邮轮旅游；负责中国邮轮（三亚邮轮港产业园）旅游发展实验区申报工作。

（五）市规划局：负责指导和支持邮轮港项目完成规划审批和修编工作。

（六）市住房和城乡建设局：负责第二座跨海大桥和邻近凤凰岛入口的交通畅通工程等市政配套设施规划建设。

（七）市海防与口岸局：协调海关及相关联检单位，研究在凤凰岛邮轮母港设立临港保税仓，向国际邮轮供应保税燃油和酒店用品，离入境购物；梳理相关政策条款，并向国家争取优惠口岸政策支持我市邮轮产业发展；落实临时联检楼口岸设施设备采购；协调做好国际邮轮旅游的口岸综合保障工作。

（八）市公安局：负责协调上级公安部门批准三亚口岸出入境更加便捷的签证政策，如“过境免签”政策等；加强与南海周边国家和地区政府出入境部门沟通协调，实现邮轮旅游相互通关便利化。

（九）市海洋与渔业局：负责二期工程海洋生态修复填海工程的竣工验收。

（十）市国土资源局:负责二期工程码头和口岸设施用地划拨及商业用地出让，及土地证办理；解决邮轮码头、口岸设施用地划拨。

（十一）三亚凤凰岛国际邮轮港发展有限公司：扩大邮轮旅游的经济腹地，以国际化规模和标准规划完成三亚市邮轮母港项目的综合开发建设，建成一批附属商业、餐饮、旅游、休闲、娱乐以及航运文化等综合服务配套设施；按照《全国沿海邮轮港口布局规划方案》要求，以邮轮母港引领、始发港为主体，加快推进邮轮港二期工程建设，完善航站楼等码头配套设施设备，构建能力充分、功能健全、服务优质、安全便捷的邮轮港口体系；充分利用“亚洲邮轮专案”和“21世纪海上丝绸之路邮轮旅游发展联盟”等合作平台，进一步加强了与东盟邮轮港口（城市）间的交流与合作，发展东盟邮轮旅游航线；研究制定开辟邮轮始发港或母港航线实施方案；协调与远洋海域航线的相关邮轮公司的合作，努力把三亚凤凰岛邮轮港打造成为远洋海域航线邮轮“必停港”。
