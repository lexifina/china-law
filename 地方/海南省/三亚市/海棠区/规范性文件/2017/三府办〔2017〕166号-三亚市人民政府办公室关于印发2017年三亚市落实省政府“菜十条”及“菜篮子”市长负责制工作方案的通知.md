# 三亚市人民政府办公室关于印发2017年三亚市落实省政府“菜十条”及“菜篮子”市长负责制工作方案的通知

三亚市人民政府办公室

关于印发2017年三亚市落实省政府“菜十条”及“菜篮子”市长负责制工作方案的通知

各区人民政府，育才生态区管委会，市各有关单位：

《2017年三亚市落实省政府“菜十条”及“菜篮子”市长负责制工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年6月1日

（此件主动公开）

2017年三亚市落实省政府“菜十条”及

“菜篮子”市长负责制工作方案

根据省政府“菜十条”、市政府“菜26条”要求，进一步提高我市“菜篮子”基地生产能力、市场供应能力、调控能力和质量安全水平，有效保障 “菜篮子”产品生产供应、质量安全和价格平稳，提高市民对“菜篮子”工程建设的满意程度，特制定三亚市落实省政府“菜十条”及“菜篮子”市长负责制工作方案如下：

一、总体思路

贯彻落实省委、省政府和市委、市政府“菜篮子”工作的决策部署，全面落实市长负责制，坚持民生为重，坚持市场化运作和财政适当扶持，以完善“淡季、旺季、台风、春节”四个时段保供稳价模式为目标，以引导市场价格机制合理形成为出发点，以扩大平价网点、构建产销对接机制、提升管理水平、提高质量安全为抓手，推动“菜篮子”工程建设步入生产稳定发展、产销衔接顺畅、质量安全可靠、市场竞争充分、价格波动可控的可持续发展轨道。

二、主要任务及责任区分

（一）加强骨干调控基地建设

1. 制定骨干调控基地标准和支持政策，对承担我市副食品供应、调控任务的种养殖调控基地进行认定，通过认定的，给予财政扶持。（牵头单位：市农业局，配合单位：各区政府、市稳价办、市商务局、市财政局）

2. 稳定1.85万亩蔬菜种植面积保有量，抓好5000亩常年蔬菜示范基地建设，建设总面积约800亩“产销一体化”市政府瓜菜应急调控试点基地；进一步改善常年蔬菜基地生产条件，重点扶持“产销一体化”市政府瓜菜应急调控试点基地的地力保育和“水肥一体化项目”建设；进一步加强产销对接，优化常年蔬菜基地生产补贴，落实应急供给保障，开展自产自销补贴试点，逐步建立“以产量定补”的种植扶持机制；建立菜地调整的占补平衡和补偿机制；扶持集约化育苗、标准化生产以及病虫害防治、质量检测、品种改良等。（牵头单位：市农业局，配合单位：各区政府、市稳价办、市商务局、市财政局、市国土资源局、市规划局）

3. 采取有效措施保住现在的养殖规模，对较大的生猪养殖场进行标准化升级改造，扶持基地企业标准化饲养、品种改良、疫病防疫、粪污综合利用和无害化处理等项目；以天涯区政府台楼村等贫困村黑猪养殖户为试点，逐步搭建保基本猪肉品种产销对接机制；开展特色蔬菜种植以及鸡、鸭、鹅、牛、羊等健康养殖，扶持搭建产销对接平台。（牵头单位：市畜牧兽医局，配合单位：各区政府、市稳价办、市商务局、市财政局、市食品药品监管局、市国土资源局、市规划局）

4. 整合惠农资金，市财政重点加大对应急调控骨干基地扶持；各区政府要相应安排“菜篮子”工程建设专项扶持资金，并列入区级财政年度预算。（牵头单位：市财政局及各区政府，配合单位：市稳价办、市商务局、市农业局）

5. 吸引社会资金参与“菜篮子”产品产销对接基地建设，鼓励银行金融机构加大对带动农户多、有潜力的龙头企业的信贷支持力度，继续推进和完善“菜篮子”保险产品，积极引导“菜篮子”生产企业和农户投保，对保费给予适当的财政补贴。（牵头单位：市农业局，市稳价办，配合单位：各区政府、市财政局、市商务局、市农业局、市金融办）

（二）优化“菜篮子”产品流通体系建设

1. 推进海南南部公益性综合批发市场（120亩）项目建设；按照国内一流现代化批发市场建设标准，由蔬菜联盟成员租赁场地自行投资建设，市政府在供土地政策、环境保护、信息化项目方面予以适当支持。公益性要求：（1）铺面档口租金实行统一政府定价；（2）蔬菜、猪肉等主要“菜篮子”产品批发实行统一控价；（3）企业按照实际交易面积20%比例作为免费自由交易区，提供给政府职能部门支配。（牵头单位：市商务局、吉阳区政府、市稳价办，配合单位：市国土资源局、市规划局、市财政局、市农业局、市食品药品监管局、市工商行政管理局、市综合执法局）

2. 按照“先见效，后扶持”思路，鼓励有潜力平价蔬菜产销联盟企业（以下简称：联盟成员）向上、下游延伸产业链，做大规模，创出品牌。（牵头单位：市稳价办，配合单位：各区政府、市商务局、市农业局、市工商行政管理局）

3. 搭建产销对接平台，扶持发展订单农业，与岛内外副食品生产基地建立合作互惠机制。（牵头单位：市商务局，配合单位：各区政府、市稳价办、市农业局、市财政局）

（三）完善调控保障体系（牵头单位：市稳价办，配合单位：各区政府、市商务局、市农业局、市国资委、市财政局、市科技工业信息化局、市食品药品监管局、市工商行政管理局、市综合执法局、市公安局）

1. 公益性平价市场。完成解放路三路、海螺一路、机场社区等3个投入运营的公益性平价市场软硬件提升；完成未名湖、原田独粮站、海润路等3个公益性平价市场建设；结合棚户区改造，由吉阳区、天涯区政府牵头，推进榆林片区、南边海片区、金鸡岭片区、羊栏片区、海坡片区、红塘湾片区、东岸片区、月川片区等8个公益性平价市场、早餐经营点等便民服务区及停车场选址与立项工作；公益性平价市场在经营模式上，蔬菜、猪肉等涉及民生的主要“菜篮子”产品采取集中规模化经营，产销对接，合理调控价格；其余商品合理定价，自主经营。

2. 农贸市场公益性摊位（铺面）。按照5%的农贸市场面积指标要求，继续在现有农贸市场开设公益性摊位（铺面）。年内在14个农贸市场开设总数110个公益性摊位和300平方米公益性铺面。

3. 保基本品种社区平价专营店。优化保基本品种社区平价专营店财政扶持政策，继续在保障性住房小区、农贸市场周边区域、主城区人口密集小区开设保基本品种社区平价专营店。年内计划保基本品种社区平价专营店总数达25个。

4. 保基本蔬菜平价专营区。合理调整保基本蔬菜平价专营区销量补贴政策，继续在大型超市开设保基本蔬菜平价专营区。年内计划保基本蔬菜平价专营区总数达25个。

5. 提升平价网点管理水平。启动平价网点、配送中心标准化创建工作，对海螺一路、解放三路公益性平价市场进行升级改造；扶持联盟成员加大对平价网点“硬件”、“软件”投入；开发“三亚平价蔬菜调控点信息化结算和监管（价格监测）系统”，用大数据引导生产与供应。

6. 扩大保基本品种。在15个市政府保基本蔬菜品种的基础上，从现有公益性平价市场、保基本品种社区平价专营店试点，将猪肉、蘑菇、豆腐、鸡蛋等“菜篮子”产品纳入保基本品种。

7. 建设应急调控冷库。常年租赁或自建（购买移动式）约400冷库，用于联盟成员保基本蔬菜应急储备，市财政按照40%租金或购价予以补贴。

8. 扶持联盟成员购置（租赁）配送车辆，配发“车辆入市区24小时通行证”。

（四）加强食品安全监管

1. 扶持批发市场、农贸市场、超市、生鲜专卖店、蔬菜配送中心等建设自检机构，在市政府平价蔬菜应急调控配送中心建设一个公益性商品质量检测室，建立检验检测资源共享和信息互联互通机制。（牵头单位：市食品药品监管局、市稳价办，配合单位：各区政府、市农业局、市商务局、市财政局）

2. 严格执行国家和省公布实施的有关“菜篮子”商品质量标准，完善“菜篮子”商品市场准入措施。（牵头单位：市食品药品监管局、市农业局，配合单位：各区政府、市稳价办、市商务局、市财政局）

3. 在市级生猪养殖基地、定点屠宰厂建设运行监控追溯系统，主城区的农贸市场、大型超市、专营店等零售终端推行溯源式电子秤和追溯系统，在市级挂牌认定基地建立蔬菜追溯信息采集系统，逐步形成全程质量追溯体系。（牵头单位：市食品药品监管局、市农业局，配合单位：各区政府、市稳价办、市商务局、市财政局）

（五）落实社会救助和保障标准与物价上涨挂钩联动机制

依照《海南省人民政府关于进一步完善社会救助和保障标准与物价上涨挂钩联动机制的通知》（琼府〔2016〕114号）精神，按照补贴机制启动或中止条件，落实物价补贴联动机制。（牵头单位：市稳价办，配合单位：市民政局、市教育局、市人力资源社会保障局）

（六）建立“菜篮子”区长负责制目标管理考核机制

实行“菜篮子”区长负责制，各区政府要把“菜篮子”工作列入政府办公会议事日程，年内建设1-2个公益性平价市场和2个保基本品种社区平价专营店。市稳价办（市发改委）将依照《海南省基本蔬菜品种价格区间调控管理办法》规定和要求，对辖区内农贸市场省政府确定的10种常见蔬菜（小白菜、上海青、圆白菜、地瓜叶、菜心、生菜、白萝卜、茄子、空心菜、土豆）实施基本蔬菜品种价格区间调控管理，并建立通报制度，纳入“菜篮子”区长负责制年度考核。（牵头单位：市稳价办，配合单位：各区政府、市商务局、市财政局、市农业局）

三、保障措施

（一）明确分工，落实部门责任。依据省政府“菜十条”、《2016年三亚市“菜篮子”工程建设及保供稳价工作责任分解方案》（三府办〔2016〕98号）、《三亚市平价蔬菜产销联盟方案》（三府办〔2016〕302号）要求和市政府有关“菜篮子”工作部署，各司其责，密切配合，推进各项工作。

（二）属地管理，落实区政府责任。各区政府要建立和完善行政首长“菜篮子”工作负责制，加大人、财、物的投入，做到“三纳入”、“四到位”：即纳入政府绩效考评的重要内容、纳入经济社会发展总体规划、纳入财政预算安排重点项目，机构、人员、资金、责任到位，将“菜篮子”工作纳入各区政府行政首长负责制的考评内容。

（三）加强督促检查，严格责任追究。实行“菜篮子”工作问责制，将各区、各有关部门落实“菜篮子”工作情况纳入综合考核评价的内容，实行定期通报成效制度，对不重视“菜篮子”工作而引发“重大舆情”或影响社会稳定的，追究有关部门或区政府负责人的领导责任。

（四）引导舆论宣传，营造良好氛围。加强新闻媒体的正面宣传引导工作，加强价格资讯的权威发布，正确引导消费者理性消费，严肃查处捏造、散布虚假价格信息行为，努力营造和谐稳定的社会环境。
