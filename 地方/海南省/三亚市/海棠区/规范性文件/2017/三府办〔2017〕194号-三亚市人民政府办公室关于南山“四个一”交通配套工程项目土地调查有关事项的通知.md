# 三亚市人民政府办公室关于南山“四个一”交通配套工程项目土地调查有关事项的通知

三亚市人民政府办公室

关于南山“四个一”交通配套工程项目土地

调查有关事项的通知

天涯区人民政府、吉阳区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对南山“四个一”交通配套工程项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于天涯区和崖州区辖区内，用地调查面积约319455平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市规划局出具的南山“四个一”交通配套工程项目拟用地界址图。土地权属（海南平面坐标系）情况为天涯区塔岭村委会集体土地约85481平方米、崖州区南山村委会集体土地约149940平方米、南滨农场国有土地约41514平方米、三亚林场国有土地约5275平方米、（原详查资料）国家土地约16666平方米、市政府土地约907平方米、三亚长丰海洋天然气供气有限公司国有土地约6447平方米、中国石油化工股份有限公司海南石油分公司国有土地约305平方米、海南省公路管理局三亚公路局国有土地约935平方米、粤海铁路有限责任公司国有土地约11984平方米；土地利用现状（西安80坐标系）为农用地约206584平方米（其中水田约51735平方米、旱地约63544平方米、可调整果园约3634平方米、果园约6354平方米、其他园地约10404平方米、可调整有林地约2254平方米、有林地约17709平方米、灌木林地约39576平方米、其他草地约6814平方米、农村道路约267平方米、坑塘水面约4293平方米）建设用地约110798平方米，（其中铁路用地约4185平方米、公路用地约13348平方米、建制镇约5911平方米、村庄约74240平方米、采矿用地约1229平方米、风景名胜及特殊用地约11885平方米），裸地约2330平方米；该项目用地在土地利用总体规划调整完善（西安80坐标系）中规划为城镇用地约1102平方米、风景名胜设施用地约 16284平方米、公路用地约149500平方米、旱地约6744平方米、坑塘水面约952平方米、林地约18216平方米、农村居民点用地约27356平方米、水田约11183平方米、铁路用地约28987平方米、园地约56889平方米、自然保留地约2500平方米。市规划局说明：项目用地统筹纳入“多规合一”的技术路线蓝图中，正按程序上报。上述用地涉及的约121167平方米耕地在办理农用地转用时，从我市耕地占补平衡指标中统筹安排。待完成占补平衡任务后，由市交通运输局按要求提供用地报批材料，市国土资源局将其列入当年新增建设用地指标并办理农转用及征收报批手续。

二、为做好该项土地调查工作，由天涯区政府和崖州区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土资源局负责征收集体土地范围内征地业务指导工作；市住房城乡建设局负责收回国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地及收回农场、林场国有土地征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）（三府〔2013〕43号）》规定执行；收回农场、林场国有土地外的其他国有土地征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、根据2010年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，天涯区政府和崖州区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认，向市国土资源局出具履行征地前告知等程序的证明及土地权属确认意见（附件1）。待有权限的人民政府批准征地后，征收土地公告和征地补偿安置方案公告可同步进行。

五、为进一步做好被征地农民养老保险工作，根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神，应在本通知下发后10个工作日内对项目征收农用地和享受缴费补贴人数等情况进行调查，组织村（居）小组填写《征地项目被征地农民基本情况调查表》（附件2），经村（居）委会、天涯区政府和崖州区政府逐级审核后，由天涯区政府和崖州区政府汇总填写《征地项目被征地农民基本情况乡镇调查汇总表》（附件 3），并将上述两种表格报送市国土资源局。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
