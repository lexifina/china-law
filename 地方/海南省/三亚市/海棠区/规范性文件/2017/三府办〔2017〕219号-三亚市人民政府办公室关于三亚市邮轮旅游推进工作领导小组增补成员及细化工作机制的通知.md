# 三亚市人民政府办公室关于三亚市邮轮旅游推进工作领导小组增补成员及细化工作机制的通知

三亚市人民政府办公室

关于三亚市邮轮旅游推进工作领导小组

增补成员及细化工作机制的通知

二、领导小组办公室

三亚市邮轮旅游推进工作领导小组下设办公室（设在市交通运输局），成员组成和工作职责如下：

主  任：吴海峰。

副主任：唐彪、黄海雄、左正和。

办公室成员：陈凤祥、段德玉、朱文灼、王雪颜、高中贵、何大哲、朱莉、叶凯中、郑聪辉、陈浩净、陈宗琦。

工作职责：负责凤凰岛邮轮母港项目推进过程中的日常工作，协调工作组和有关部门解决相关问题，完成领导小组交办的各项工作。

三、工作组设置、工作职责及成员单位职责分工

为高效推动凤凰岛邮轮母港项目的综合开发建设，加快推进我市邮轮旅游发展，三亚市邮轮旅游推进工作领导小组办公室下设3个工作组：基建组、规划组、政策组。各组组成单位和工作职责如下：

（一）基建组

组    长：陈凤祥  市交通运输局副局长。

成员单位：市交通运输局（牵头单位）、市海洋与渔业局、市住房和城乡建设局、市海防口岸局、市国土资源局、市审计局。

工作职责：负责推进邮轮港及其市政配套设施建设。

职责分工如下：

市交通运输局：全面统筹凤凰岛二期工程整岛验收推进工作，负责推进凤凰岛二期工程3、4号泊位码头竣工验收。

市海洋与渔业局：负责协调省海洋与渔业厅完成凤凰岛二期填海项目竣工海域使用验收、海洋环境保护设施竣工验收工作。

市住房城乡建设局：负责第二座跨海大桥和邻近凤凰岛入口的交通畅通工程等市政配套设施建设。

市海防与口岸局：落实临时联检楼口岸设施设备采购。

市国土资源局：根据城市规划，依法办理海域使用权证换发国有土地使用权证手续，包括二期工程码头和口岸设施用地划拨及商业用地出让等。

市审计局：负责落实凤凰岛二期项目成本核定。

（二）规划组

组    长：高中贵  市规划局副局长。

成员单位：市规划局（牵头单位）、市多规办、市交通运输局、市旅游发展委员会。

工作职责：负责邮轮港及邮轮产业规划编制工作。

职责分工如下：

市规划局：负责组织邮轮港项目规划编制和报批工作。负责研究凤凰岛一期规划调整问题；负责协调《三亚市城市规划（2011－2020）》凤凰岛局部修改；负责编制凤凰岛二期规划研究；开展凤凰岛邮轮港交通体系规划研究；指导相关规划编制和报批工作。

市多规办：协调将凤凰岛二期填海用地纳入《三亚市总体规划（空间类2015－2030）》。

市交通运输局：负责将凤凰岛邮轮港建设申报入省“十三五”码头建设规划。

市旅游委：进一步完善《三亚市邮轮母港产业园总体规划》的编制和实施工作；负责中国国际邮轮（三亚）旅游发展实验区申报工作。

（三）政策组

组    长：左正和  市海防与口岸局局长。

成员单位：市海防与口岸局（牵头单位）、市发展改革委员会、市旅游发展委员会、市交通运输局、市财政局、市公安局。

工作职责：负责研究、落实邮轮旅游相关配套政策；研究“一船两港”、“邮轮产权登记”、“游艇使用权登记”等一系列创新制度。

职责分工如下：

市海防与口岸局（牵头单位）：梳理相关政策条款，并向国家争取优惠口岸政策支持我市邮轮产业发展；协调海关及相关联检单位，研究在凤凰岛邮轮母港设立临港保税仓，向国际邮轮供应保税燃油和酒店用品，离入境购物；协调做好国际邮轮旅游的口岸综合保障工作。

市发展改革委：负责研究国家和海南省关于21世纪海上丝绸之路发展规划，将三亚凤凰岛国际邮轮港纳入市打造21世纪海上丝绸之路战略支点行动的重要内容；配合省发展改革委编制三亚凤凰岛国际邮轮港自由贸易区方案并跟踪报批工作；配合行业主管部门制定支持邮轮产业发展的相关配套政策。

市旅游委：负责研究开发和营销邮轮旅游产品，吸引远洋海域旅游航线邮轮访问三亚；积极寻求与国际邮轮公司合作，开辟区域性、近洋型国际旅游航线和地区性旅游航线；协调中资企业中有实力、有经验的国际旅行社服务我市邮轮旅游；负责中国邮轮（三亚邮轮港产业园）旅游发展实验区申报工作。

市交通运输局：负责邮轮航线审批问题的政策推进工作。

市财政局：负责落实有关支持邮轮旅游发展的财政和税收优惠政策。

市公安局：负责协调上级公安部门批准三亚口岸出入境更加便捷的签证政策，积极协调给予我市更加宽松优惠的外国人来琼旅游的政策，实现邮轮旅游相互通关便利化。

三亚凤凰岛国际邮轮港发展有限公司：派员参与三个组（基建组、规划组、政策组）的工作。

四、工作机制及会议机制

（一）工作机制

各组成员单位必须严格遵守以下工作机制：

1．主动作为，强化协作。在邮轮旅游推进工作领导小组的带领下，各成员单位按照职责分工主动作为，积极协调对口上级部门适应新业态发展需求，扎实工作，加强沟通，通力协作。

2．求是务实，注重实效。各组的成员单位必须选派1—2名业务骨干专门对接具体工作分工，并定时把工作进展情况（详见附件：《三亚市邮轮旅游推进工作责任事项分解表》）反馈到三亚市邮轮旅游推进工作领导小组办公室（市交通运输局）。各成员单位应以求实务实，积极推进的态度，注重工作实效，杜绝庸懒散，强化紧迫感。

（二）会议机制

1．三亚市邮轮旅游推进工作领导小组形成月例会制度。办公室每月将各组的成员单位工作进展情况、存在问题汇总后，上报市政府，由领导小组组长主持召开邮轮旅游推进工作例会。

2．三个工作组（基建组、规划组、政策组）成员单位依照职责分工开展工作，各组组长负责汇总各成员单位的工作落实情况，解决工作开展的存在问题，并形成意见后上报办公室。
