# 三亚市人民政府办公室关于三亚东河生态修复工程（溪泽三桥-东环高铁段）项目土地调查有关事项的通知

三亚市人民政府办公室

关于三亚东河生态修复工程（溪泽三桥-东环高铁段）项目土地调查

有关事项的通知

吉阳区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对东河生态修复工程（溪泽三桥-东环高铁段）项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于吉阳区辖区内，用地调查面积约165549平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见三亚市规划局出具的总规部分绿地、园地及水域、月川控规部分绿地和水域用地红线图。土地权属（海南平面坐标系）情况为吉阳区东岸、海罗、临春和荔枝沟村委会集体土地共约150000平方米，榕根社区居委会土地约14221平方米，临春居委会与海罗村委会共有土地约510平方米，广州铁路集团海南铁路总公司（已收回）国有土地约818平方米；土地利用现状（西安80坐标系）为农用地约117155平方米（其中水田约88971平方米、其他园地约1320平方米、可调整其他林地约6391平方米、其他林地约5846平方米、坑塘水面约14413平方米、设施农用地约214平方米），建设用地约48491平方米（其中公路用地约213平方米、城市约6950平方米、建制镇约19664平方米、村庄约8606平方米、采矿用地约13058平方米）、沿海滩涂约1954平方米；该项目用地在土地利用总体规划调整完善（西安80坐标系）中规划为城镇用地约2368平方米、公路用地约1087平方米、河流水面约83平方米、坑塘水面约9985平方米、水工建筑用地约435平方米、滩涂约24715平方米、园地约126973平方米。该项目为河道生态修复工程，不列入农用地转用及征收报批计划，具体征地范围以市水务局与吉阳区政府现场实际勘测确认为准，现既有河流水面不列入该项目征地调查范围。

二、为做好该项土地调查工作，由吉阳区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土资源局负责征收集体土地范围内征地业务指导工作；市住房城乡建设局负责收回国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行；收回国有土地征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、根据2010年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，吉阳区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认工作。

五、为进一步做好被征地农民养老保险工作，吉阳区政府应根据省人力资源社会保障厅、省财政厅和原省国土环境资源厅 2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神办理。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
