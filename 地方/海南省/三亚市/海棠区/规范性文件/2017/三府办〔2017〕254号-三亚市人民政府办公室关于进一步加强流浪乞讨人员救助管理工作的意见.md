# 三亚市人民政府办公室关于进一步加强流浪乞讨人员救助管理工作的意见

三亚市人民政府办公室

关于进一步加强流浪乞讨人员

救助管理工作的意见

各区人民政府，各管委会，市政府直属各单位：

为进一步加强流浪乞讨人员救助管理工作,根据国务院《城市生活无着的流浪乞讨人员救助管理办法》（国务院第381号令）、民政部《城市生活无着的流浪乞讨人员管理办法实施细则》（民政部第24号令）、《海南省人民政府关于认真做好城市生活无着的流浪乞讨人员救助管理工作的通知》（琼府〔2003〕71号），创新社会管理模式，形成流浪乞讨人员救助管理的长效机制，经七届市政府第11次常务会议审议同意，结合我市实际,提出以下意见:

一、创新城市管理模式,建立综合管理长效机制

以公安、综合执法部门的街面执法权为基础,民政的兜底救助职能为依托和支撑，联合卫生计生、交通等其它有关部门,把流浪乞讨人员的救助管理工作纳入城市管理范畴，提升城市治理能力现代化水平,并逐步形成“公安+城管+民政+卫生计生+交通等”相融合的城市综合管理体制。对于发现的流浪乞讨人员,辖区公安机关负责进行教育、告知、引导或护送其到市救助管理站,对违法犯罪行为依法打击,协助查找流浪乞讨人员的个人信息。辖区综合行政执法部门在执行公务过程中,对流浪乞讨人员应当告知、引导或护送其向市救助管理站求助,对违反城市管理法律法规的行为进行教育、制止、纠正。辖区民政部门负责对符合救助条件的受助人员做好救助管理工作。市公安局、市综合行政执法局、市民政局、市卫生计生委、市交通运输局等有关单位做好各区、各管委会业务部门的监督指导工作，形成流浪乞讨人员救助管理工作定期检查、督导的长效机制。

二、管理关口前移,实行首见责任制

（一）管理关口前移,落实首见责任制。对三亚市卫生、容貌、秩序存在严重影响的流浪乞讨人员救助管理工作纳入城市管理和社会综合治理工作的重要内容。依照《三亚市“门前三包”责任制试行办法》的规定,落实“门前三包”责任制。

（二）住宅小区、商铺、市场、机场、车站、建筑工地、公路、桥梁、风景名胜景区等经营管理单位,机关、团体、部队、学校、医院以及其他企事业单位为“门前三包”责任人，如发现流浪乞讨人员在其“门前三包”范围内进行乞讨,可主动询问其基本信息,对需要救助的流浪乞讨人员应告知其可接受救助及求助途径,并及时告知市救助管理站（24小时值班电话:0898—88384179）。对不提供基本信息、不愿接受救助的流浪乞讨人员,可予以劝离。对影响市容市貌、妨碍正常生产生活秩序的流浪乞讨人员,报辖区综合行政执法部门综合治理;对有强讨硬要、妨碍交通秩序或有涉嫌违法犯罪行为的流浪乞讨人员,及时向110报警,由辖区公安机关依法调查处理。

三、分类管理,明确职责

（一）市民政部门对由于贫困、疾病、残疾等导致生活无着的流浪乞讨人员,因失业、受骗、走失等因素造成临时困难和愿意接受帮助的流浪乞讨人员,由市民政部门对其进行救助;对在本市流浪乞讨的无法定监护人在场且愿意接受救助的未成年人,由市民政部门设立的未成年人救助机构进行救助;对在本市流浪乞讨的老年人、重度残疾人和其他愿意接受救助且符合救助条件的人员,由民政部门设立的市救助管理站负责救助。市公安和综合行政执法部门经过综合治理护送引导至市救助管理站的流浪乞讨人员（若为危重病人直接送到定点医院开通绿色通道先行救治），市救助管理站接收并加强救助管理工作。市救助管理站加强内部管理，严格按照流浪乞讨人员救助管理工作相关的规范性文件进行规范管理，严禁出现辱骂、殴打、虐待被救助人的情形。市救助管理站通过购买服务等方式优先安排女性工作者到救助一线工作，提升救助工作的亲和力和救助服务质量。

（二）市综合行政执法部门对辖区内，在城市市区交通主干道、主城区街面、机关、学校、旅游景点等区域乞讨的；横躺竖卧、衣着不整、乱丢垃圾故意破坏城市环境、用扩音器唱歌乞讨造成噪声扰民等影响市容环境的；以及其他有损市容环境卫生流浪乞讨行为的；责令其改正、劝离、纠正或引导其去救助管理站求助,拒不改正或拒绝离开的,依照城市管理法律法规予以综合处置。对流浪乞讨人员采取自残行为或有可能危害他人行为进行乞讨时,辖区综合行政执法部门对其进行制止、劝导,如在劝导中流浪乞讨人员有过激行为的,及时拨打110通知辖区公安部门对其采取约束性保护措施。

（三）市公安机关对在本市流浪乞讨人员中涉嫌违法犯罪的,依法调查处理。对于强索强讨,寻衅滋事,扰乱社会公共秩序的;假借乞讨方式,从事偷窃、骗取、抢夺、敲诈公私财物行为的;拐卖或者收买被拐卖的儿童,拐骗、租借儿童,压榨少年儿童乞讨牟利的;胁迫、利用未成年人、残疾人、老年人进行流浪乞讨牟利的；组织、参与带有黑社会性质的乞讨团伙等违法犯罪行为的；拒绝、阻碍公安、城管执法人员执行公务活动的；使用暴力、威胁手段,构成犯罪的，由辖区公安部门按照《治安管理处罚法》、《中华人民共和国刑法》等法律法规进行处置。对在十字路口、交通要道拦截车辆、强讨硬要的流浪乞讨行为,由辖区公安交警部门依据《道路交通安全法》、《治安管理处罚法》等法律法规,依法处置。流浪乞讨人员中的吸毒人员的戒毒工作,由市公安部门负责依法处置。对流浪乞讨人员进行身份甄别,分类进行救助管理。身份甄别由流浪乞讨地公安派出所负责。市公安部门负责协助查找核对流浪乞讨人员的个人信息。

（四）市卫生计生部门对流浪乞讨人员中危重病人、传染病人安排到指定医院进行治疗。在医院救助的危重流浪乞讨病人，已经治疗达到出院标准，由医院出具出院证明；患者同意接受救助的，市救助管理站按照相关程序负责接收；对赖在医院不出院或者在医院无理取闹、扰乱正常医疗秩序的流浪乞讨人员，由辖区公安派出所依法处置；公安、城管或市民发现危重流浪乞讨患者，及时拨打120送到医院救治。市卫生计生部门责令医院开通绿色通道，先救人后办手续；市卫生计生部门负责鉴定在本市流浪乞讨的疑似精神病人，如被鉴定为精神病患者，由市公安部门负责核实信息，确认为“三无”精神病患者的直接护送至定点医疗机构进行救治，市民政部门（市救助管理站）在定点医疗机构接收后给予签字确认，负责承担“三无”精神病人的治疗、生活费用。

（五）市交通运输部门协调车站开通绿色通道，对市救助管理站提出为受助人及护送特殊困难救助人员返乡的工作人员及时办理专用车票或乘车凭证，并在进站、乘车时，积极协调车站给予协助并提供必要的便利。

（六）市残联协助市救助管理站做好聋哑流浪乞讨人员的手语翻译以及查验残疾人有关证件工作，指导市救助管理站安装残疾人设施设备。

（七）各区政府、育才生态区管委会要落实属地管理责任，负责辖区内流浪乞讨人员救助管理工作。对辖区流浪乞讨人员做好告知、引导等救助工作，对自愿接受救助的护送其到市救助管理站接受救助。落实网格化管理，依托社区网格化管理的优势，确保流浪乞讨人员及时发现、及时劝导、及时救助。建立社区网格员与辖区各有关部门、救助管理机构的互通互联机制。督促、指导辖区村（居）委会做好大街小巷流浪乞讨人员的救助管理工作，村（居）委会网格员或相关工作人员对于发现的流浪乞讨人员应主动询问，对自愿接受救助的直接联系辖区民政部门或者市救助管理站（24小时值班话:0898—88384179），对不愿意接受救助且故意影响市容市貌或有其它违法犯罪嫌疑的直接报辖区公安、城管部门处置。

四、加强组织领导，健全工作机制

成立三亚市流浪乞讨人员救助管理工作领导小组，由市政府分管副市长任组长，市政府分管副秘书长、市民政局局长任副组长，市民政局、市公安局、市综合行政执法局、市卫生计生委、市交通运输局、各区政府分管副区长、育才生态区管委会分管领导为成员，领导小组下设办公室在市民政局。市流浪乞讨人员救助管理工作领导小组每年至少召开1次以上联席会议,主要研究解决工作中遇到的困难和问题。领导小组办公室及时收集各成员单位履行职责的工作情况，提请三亚市流浪乞讨人员救助管理工作领导小组进行通报。

各区政府、育才生态区管委会要明确自身属地管理主体责任，做好辖区内的流浪乞讨人员救助管理工作，参照市里的组织机构成立区级流浪乞讨人员救助管理工作领导小组。在每年春冬时季和重大节假日、国家和省市重大活动以及重要会议期间,适时组织开展多部门联合巡查救助行动。

五、工作要求

（一）加强管理，落实责任。流浪乞讨人员救助管理工作实行属地管理。各区政府、育才生态区管委会切实加强救助管理工作。市流浪乞讨人员救助管理工作领导小组对各区政府、育才生态区管委会进行定期、不定期检查通报，发现存在流浪乞讨人员救助管理不到位,工作不作为、乱作为、慢作为情况的,及时通报批评；造成不良后果的，根据有关规定通报纪检部门对直接责任人进行责任追究。

（二）加强协作，密切配合。各部门之间加强信息互通，及时通报救助管理工作相关信息。接到群众反映的线索根据职责分工及时行动，迅速处置，处置结果通过信息或者简报形式报送市流浪乞讨人员救助管理工作领导小组办公室。按照主动发现情况、部门协同联合的工作思路抓实流浪乞讨人员救助管理工作。

（三）加强宣传，广泛参与。市委宣传部门、区委宣传部门和新闻媒体负责协同民政等部门做好流浪乞讨救助管理的政策及工作情况的宣传。引导市民对流浪乞讨人员理性救助,使职业乞讨逐利的空间逐步缩小,最终使好吃懒做的职业乞讨人员弃讨改行,自食其力。引导慈善人士和社会资金投放给真正需要救助的对象。鼓励、支持社会组织、志愿者积极参与流浪乞讨人员救助管理工作。发动热心群众和志愿者提供流浪乞讨人员线索，多措并举做好流浪乞讨人员救助管理工作。

三亚市人民政府办公室
