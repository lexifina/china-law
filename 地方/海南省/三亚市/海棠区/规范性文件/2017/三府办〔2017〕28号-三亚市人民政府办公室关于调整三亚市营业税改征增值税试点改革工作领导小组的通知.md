# 三亚市人民政府办公室关于调整三亚市营业税改征增值税试点改革工作领导小组的通知

三亚市人民政府办公室

关于调整三亚市营业税改征增值税试点改革

工作领导小组的通知

各区人民政府，各管委会，市政府直属各单位：

因人事变动和工作需要，市政府决定成立三亚市营业税改征增值税试点改革工作领导小组，具体如下：

一、三亚市营业税改征增值税试点改革工作领导小组及办公室

组 长：鲍 剑（市委常委、常务副市长）

副组长：李武军（市政府副秘书长）

王 瑜（市财政局局长）

赵文晓（市地方税务局局长）

何云高（市国家税务局局长）

成 员：陈浩净（市财政局预算管理局局长）

黄晓新（市地方税务局副局长）

冯天弟（市国家税务局副局长）

其他成员由市金融办、市科技工业信息化局、市文化广电出版体育局、市交通运输局、市商务局、市统计局、市工商行政管理局、市住房城乡建设局、市国土资源局、人民银行三亚市中心支行等单位主要负责人及市委宣传部、市公安局等部门分管负责人担任。

三亚市营业税改征增值税试点改革工作领导小组办公室设在市财政局。办公室主任由王瑜兼任，副主任由陈浩净、黄晓新、冯天弟兼任。成员由其他成员单位相关处室负责人组成。

二、部门职责分工

（一）市财政局

牵头开展“营改增”试点工作，加强与税务部门、行业主管部门的沟通，协调各方开展工作，汇总相关信息，及时向领导小组汇报试点改革工作进展情况，为税务部门开展工作提供必要的支持和保障。

（二）市地方税务局

将试点纳税人户籍及相关征管数据在规定时间内完整、准确移交市国家税务局，做好税制转换前营业税征收和清缴欠税工作，研究完善附加税种的征管流程。

（三）市国家税务局

组织实施“营改增”试点的各项征管工作，具体包括做好试点纳税人户籍及相关征管数据接收工作，完善税控系统、制定征管措施、开展企业培训，为纳税人提供高效、便利的办税环境和条件。

（四）市委宣传部

负责组织有关新闻媒体，分阶段、分步骤、有计划地开展“营改增”试点改革相关宣传工作，关注舆情，正确引导社会舆论。

（五）市统计局

负责收集相关宏观经济数据和信息，测算、分析试点改革对我市宏观经济的影响并提供相关报告等。

（六）市公安局

负责保障试点改革的平稳推进，协助市国税、地税部门抓好税收征管工作，严厉查处试点改革中相关违法案件等。

（七）市金融办、市工商行政管理局及其他成员单位

配合税务部门推进试点改革工作，跟踪试点情况，研究全面“营改增”对相关行业发展的影响，反映纳税人在试点中存在的问题。

三亚市人民政府办公室
