# 三亚市人民政府办公室关于三亚市高园水库-大茅水系连通工程项目土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市高园水库-大茅水系连通工程项目土地调查有关事项的通知

吉阳区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对高园水库-大茅水系连通工程项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于吉阳区辖区内，用地调查面积约28523平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市规划局出具的高园水库-大茅水系连通工程用地界址图。土地权属（海南平面坐标系）情况为：吉阳区干沟、榆红和红土坎村委会集体土地共约17332平方米，国家所有土地约7027平方米，三亚市土地储备开发中心国有土地约4164平方米；土地利用现状（西安80坐标系）为农用地约18639平方米（其中水田约11209平方米、旱地约2524平方米、有林地约3597平方米、其他草地约299平方米、坑塘水面约1010平方米）、建设用地约9900平方米（其中村庄约1077平方米、采矿用地约8823平方米）；该项目用地在土地利用总体规划调整完善（西安80坐标系）中规划为城镇用地约451平方米、公路用地约33平方米、旱地约2272平方米、坑塘水面约281平方米、林地约3315平方米、水工建筑用地约925平方米、水田约11204平方米、滩涂约1631平方米、园地约8427平方米。该水系连通工程为农业土地整治项目，不列入农用地转用及征收报批计划。

二、为做好该项土地调查工作，由吉阳区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、农业土地整治项目用地的补偿工作按2015年第169期三亚市人民政府市长办公会议纪要第三项议题的议定精神执行。

四、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
