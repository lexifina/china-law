# 三亚市人民政府办公室关于印发2017海南亲水运动季（三亚）活动工作方案的通知

三亚市人民政府办公室

关于印发2017海南亲水运动季（三亚）

活动工作方案的通知

各区人民政府，各管委会，市政府直属各单位：

《2017海南亲水运动季（三亚）活动工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年9月21日

（此件主动公开）

2017海南亲水运动季（三亚）活动工作方案

根据《海南省人民政府办公厅关于印发2017海南亲水运动季活动工作方案的通知》（琼府办函〔2017〕262号）要求，结合我市全民健身事业发展需要，为扩大亲水运动在三亚的普及推广，引导体育旅游消费，推动体育与旅游、教育的深度融合，确保“2017海南亲水运动季（三亚）活动”在我市顺利开展，特制定本方案。

一、活动原则

（一）积极创新。在活动形式、组织方式、多方联动等方面，探索独具三亚特色、有全国影响力和民众口碑度的活动创新，进一步夯实体育旅游的发展基础。

（二）跨界融合。在活动策划、组织、实施的各个阶段，加强保障，推动体育、旅游、教育的深度融合。

（三）塑造品牌。各项目的设立、包装、推广、实施，均紧密围绕“海南亲水运动季”品牌打造展开，突出动感、时尚、健康元素。

（四）服务游客。以外地游客及青少年群体为重点，努力提高活动的参与度和口碑度，服务并带动游客及青少年参与互动。

二、活动主题

推动亲水运动深入开展，掀起体育旅游和全民健身的新高潮。

三、活动时间：2017年7月8日至2018年1月8日。

四、活动地点：三亚市

五、活动规模

在亲水运动季中实现目标人群广泛参与，其中本市民众5万人次，外省游客15万人次，重点覆盖青少年人群。

六、活动目标

打造三亚水上运动天堂，拉动旅游人数新增长、推动全民健身和体育旅游的融合发展。

七、活动内容

（一）重点项目。

根据各地资源特色和优势定位，策划组织亲水运动项目活动，以及重点亲水运动赛事、游客参与活动等。

（二）互动项目。

1.观赏类：在拥有亲水运动训练场地及设施的场所，定期开放针对市民及游客的观赏类活动。

2.体验类：市场性质的亲水运动景区、酒店等运营机构，在运动季期间，为游客提供优惠折扣和特别项目。

3.培训类：在拥有亲水运动设施及场地，根据市场需求，策划和开展一系列时长不同、层次不同的运动训练营。以及在活动期间组织专业教练及工作人员，深入全市中小学、社区、街道，针对性开展面向学生群体的亲水运动推广普及和体验培训活动。

八、举办单位

（一）主办单位：国家体育总局、海南省人民政府

（二）三亚市承办单位：三亚市人民政府

（三）三亚市协办单位：三亚市文化广电出版体育局

具备相应条件获得活动参与资格的相关运动协会及俱乐部、各相关旅游企业。

九、组织机构

（一）组织委员会。

主 任：许振凌（市人民政府副市长）

副主任：王克宏（市人民政府副秘书长）

委 员：刘 兰（市委宣传部副部长）

陈震旻（市文化广电出版体育局局长）

樊 木（市旅游发展委员会主任）

吴 萍（市教育局局长）

成员：市委宣传部、市旅游发展委员会、市文化广电出版体育局、市公安局、市教育局、市财政局、市卫计委、市海洋与渔业局、市综合行政执法局、市安全生产监督管理局、三亚海事局、共青团三亚市委、市文化体育发展中心。

组织委员会下设办公室在市文化广电出版体育局，由市文化广电出版体育局副局长韩建平任办公室主任。

（二）组委会成员单位职责分工。

1.市文化广电出版体育局：负责制定活动方案；统筹协调市内各相关部门和各区为活动提供整体保障和服务。

2.市委宣传部：制定活动宣传工作方案；协调有关新闻媒体单位做好活动的宣传报道工作，接待协调好有关媒体记者等相关事宜。

3.市公安局：制定有关活动安保工作方案；做好领导、嘉宾、活动场地和住地周边的安全保卫工作；做好其他有关活动的道路交通保障工作；根据活动需求抽调1台消防车待命。

4.市旅游发展委员会：负责组织旅游企业、协会参与活动，积极吸引国内外游客参与活动；提出具体游客组织、推广方案；根据整体项目时间及地点整合旅行社、景区资源推出亲水旅游季产品包。

5.市财政局：负责为市级各部门开展活动提供经费保障。

6.市教育局：负责各活动的校园宣传推广工作，组织学生积极参与。配合组委会组织各种校园培训活动，协调做好课时安排。

7.市卫计委：制定有关医疗救护方案；根据活动需要安排1辆救护车及必要的医护人员在指定的位置待命。

8.共青团三亚市委：负责青少年群体的组织推广及志愿者服务。

9.市海洋与渔业局：负责活动水域使用协调，活动水域障碍物的清理工作。

10.三亚海事局：制定海上安全保障方案和应急保障方案；负责水上交通安全监督管理，根据申请发布航行通（警）告。

11.市综合行政执法局：支持活动氛围营造工作，协调和审批活动主会场搭建、宣传广告悬挂和张贴工作。

12.市安全生产监督管理局：对活动场所进行质量安全监督检查，确保安全工作的落实。

13.市文化体育发展中心：负责做好赛事活动的沟通与协调推进及相关文书工作；负责策划组织活动期间本地特色文化体育活动；执行组委会交办的其他工作任务。

14.各相关运动协会及俱乐部、各相关旅游企业：负责按照活动总体安排具体承担本单位所从事业务相关项目的落实工作。

十、宣传推广

（一）市内宣传。本地路牌广告、酒店、报纸、电视台、政府网站及自媒体等，提供相关版面和宣传资源，整体纳入统一管理，专项用以发布亲水运动季的相关宣传内容。

（二）岛外宣传。用合作、资源交换及统一采购等多种形式，整合全国性优质媒介资源，用于面向游客市场的亲水运动季推广工作。

十一、工作要求

（一）加强组织领导。

1.活动组委会充分发挥内外联动作用，突出协调保障推进各项工作，建立有效工作机制，确保活动有序开展。

2.组委会各成员单位要成立工作小组，由单位分管负责人担任组长，抽调专人负责落实本单位各项工作，定期开展考核，抓落实、抓进度、抓成效，切实把2017海南亲水运动季（三亚）活动组织工作落到实处。

（二）调动社会参与。

各成员单位积极推动社会参与，为积极参与活动的企业创造良好的政策环境，借助2017海南亲水运动季（三亚）活动举办的契机，切实提高我市亲水运动产业发展水平，丰富我市亲水旅游产品内涵，打造我市体育旅游品牌。

（三）加强宣传推广。

宣传工作是本次活动的重要目标之一，结合2017海南亲水运动季（三亚）活动，充分利用各种媒体宣传本次活动，扩大活动的社会影响力，将活动打造成三亚国际旅游目的地的地标性的新名片。
