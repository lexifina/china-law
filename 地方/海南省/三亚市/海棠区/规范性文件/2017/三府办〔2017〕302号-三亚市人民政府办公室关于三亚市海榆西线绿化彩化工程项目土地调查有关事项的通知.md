# 三亚市人民政府办公室关于三亚市海榆西线绿化彩化工程项目土地调查有关事项的通知

三亚市人民政府办公室

关于三亚市海榆西线绿化彩化工程项目土地

调查有关事项的通知

天涯区人民政府，崖州区人民政府，市政府各有关单位：

根据三亚市土地利用总体规划、城市规划和项目建设需要，经市政府同意，对海榆西线绿化彩化工程项目部分用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目起点于海榆西线大兵桥，终点至崖城互通立交，用地调查面积约554390平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见市住房城乡建设局出具的海榆西路红线图（已在市规划局审核出具的用地红线范围内扣除现既有道路）。土地权属（海南平面坐标系）情况为：天涯区塔岭、红塘、桶井、大兵（羊栏）、布甫、马岭、黑土村委会和崖州区南山村委会集体土地共约379190平方米，南滨农场、三亚林场国有土地共约40909平方米，国家所有土地约53798平方米，部队国有土地约1406平方米，三亚市人民政府、天涯区（原天涯镇）政府土地共约4785平方米，红塘小学、天涯中学（未发证）土地共约3330平方米，三亚市天涯海角旅游发展有限公司等13家公司国有土地共约70974平方米；土地利用现状（西安80坐标系）为农用地约304001平方米（其中水田约72391平方米、旱地约60852平方米、果园约33833平方米、可调整果园约2861平方米、其他园地约9405平方米、有林地约83744平方米、灌木林地约23665平方米、其他草地约9876平方米、农村道路约715平方米、坑塘水面约5483平方米、设施农用地约1176平方米），建设用地约260370平方米（其中铁路用地约24273平方米、公路用地约20369平方米、河流水面约1049平方米、建制镇约18876平方米、村庄约115629平方米、采矿用地约4308平方米、风景名胜及特殊用地约75866平方米），裸地约522平方米；该项目用地在土地利用总体规划调整完善（西安80坐标系）中规划为城镇用地约22191平方米、风景名胜设施用地约63896平方米、公路用地约227406平方米、旱地约12319平方米、河流水面约51平方米、坑塘水面约2904平方米、林地约46608平方米、农村居民点用地约23455平方米、设施农用地约48平方米、水田约15111平方米、铁路用地约33335平方米、园地约107490平方米。该项目为绿化彩化景观带工程，不列入农用地转用及征收报批计划。具体征地范围以市住房城乡建设局与天涯区政府、崖州区政府现场实际勘测确认为准，现既有绿化带不列入该项目征地调查范围。

二、为做好该项土地调查工作，由天涯区政府和崖州区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土资源局负责征收集体土地范围内征地业务指导工作；市住房城乡建设局负责收回国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地及收回部队、农场、林场国有土地征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行；收回部队、农场、林场国有土地外的其他国有土地征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、根据2010年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，天涯区政府和崖州区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认，向市国土资源局出具履行征地前告知等程序的证明及土地权属确认意见（附件1）。待有权限的人民政府批准征地后，征收土地公告和征地补偿安置方案公告可同步进行。

五、为进一步做好被征地农民养老保险工作，根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神，应在本通知下发后10个工作日内对项目征收农用地和享受缴费补贴人数等情况进行调查，组织村（居）小组填写《征地项目被征地农民基本情况调查表》（附件2），经村（居）委会、天涯区政府和崖州区政府逐级审核后，由天涯区政府和崖州区政府汇总填写《征地项目被征地农民基本情况乡镇调查汇总表》（附件 3），并将上述两种表格报送市国土资源局。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
