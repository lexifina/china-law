# 三亚市人民政府办公室关于印发市公共信用信息平台报送信用“红黑名单”信息的通知

三亚市人民政府办公室

关于印发市公共信用信息平台报送信用

“红黑名单”信息的通知

各区人民政府，育才生态区管委会，市各有关单位：

我市公共信用信息共享平台框架已基本搭建成型，为建立信用信息对接机制，归集信用信息数据，完善信息共享、联合惩戒机制，现就联席会议成员单位信用“红黑名单”信息报送工作通知如下。

一、报送信用“红黑名单”信息的依据

（一）《国务院关于建立完善守信联合激励和失信联合惩戒制度加快推进社会诚信建设的指导意见》（国发〔2016〕33号）。

（二）《三亚市人民政府关于印发三亚市信用“红黑名单”发布和联合奖惩制度实施办法的通知》（三府〔2017〕214号）。

（三）各行业、部门印发和执行的行业、部门信用“红黑名单”管理制度。

（四）根据有关要求，以下信用“红黑名单”信息必须向市公共信用信息共享平台报送。

1.市中级人民法院负责发布的失信被执行人信息；

2.市委宣传部负责发布的各项荣誉守信“红名单”；

3.市公安局负责发布的道路交通违法失信“黑名单”；

4.市工商局负责发布的企业信用“红黑名单”；

5.市司法局负责发布的法律服务机构、法律服务人员信用“红黑名单”；

6.市食品药品监管局负责发布的食品、药品安全管理，经营主体和执业人员信用“红黑名单”；

7.市环保局负责发布的环境保护参与主体信用“红黑名单”；

8.市质监局负责发布的生产企业产品质量信用“红黑名单”；

9.市安监局负责发布的生产、经营主体安全生产信用“红黑名单”；

10.市消防局负责发布的生产、经营主体消防安全信用“红黑名单”；

11.市国税局负责发布的企业纳税情况信用“红黑名单”；

12.市地税局负责发布的企业纳税情况信用“红黑名单”；

13.市教育局负责发布的教育事业参与主体、教师信用“红黑名单”；

14.市科工信局负责发布的科学技术、工业与节能、信息化、知识产权和专利、节能降耗等参与主体信用“红黑名单”；

15.市人社局负责发布的企业劳动保障、公务员信用“红黑名单”；

16.市住建局负责发布的房地产、建筑市场、中介机构等信用“红黑名单”；

17.市交通局负责发布的交通运输经营主体、管理对象，交通工程建设领域信用“红黑名单”；

18.市农业局负责发布的农产品、种子、农药、肥料质量管理和生产经营主体信用“红黑名单”；

19.市旅游委负责发布的旅游景区景点、酒店、旅行社、导游信用“红黑名单”；

20.市发改委（市物价局）负责发布的价格管理信用“红黑名单”；

21.市商务会展局负责发布的批发零售、商贸物流和会展服务业信用“红黑名单”；

22.三亚海关负责发布的进出口企业信用“红黑名单”；

23.人民银行、三亚银监分局、市金融办负责发布的金融行业信用“红黑名单”；

24.市财政局负责发布的财政性资金管理使用、政府采购领域信用“红黑名单”；

25.市政务中心负责发布的招投标信用“红黑名单”；

26.市网信办负责发布的电子商务领域信用“红黑名单”；

27.市卫计委负责发布的医疗卫生、计划生育领域信用“红黑名单”；

28.市民政局负责发布的社会保障领域信用“红黑名单”；

29.市文体局负责发布的文化体育领域信用“红黑名单”；

30.市总工会负责发布的劳动模范、“五一”劳动奖章获得者诚信“红名单”；

31.团市委负责发布的优秀青年志愿者诚信“红名单”；

32.市妇联负责发布的妇女三·八红旗手诚信“红名单”；

33.联席会议成员负责发布其他行业、领域的信用“红黑名单”。

二、报送信用“红黑名单”信息的时间要求

（一）请各行业、部门于10月30日前把今年以来确定和公开的信用“红黑名单”重新进行复核，按照报送指南，一次性全部向市公共信用信息共享平台报送。

（二）今后产生的信用“红黑名单”，各行业、部门要在确定和公开的7天内向市公共信用信息共享平台报送。

三、报送信用“红黑名单”信息指南

信用“红黑名单”与“双公示”信息报送方式相同。

步骤1：确认自已的电脑终端是否连接到电子政务外网或互联网。

步骤2：联席会议成员单位在“信用三亚”网站（http://xysy.sanya.gov.cn/）“法人服务”栏目下，点击“信息报送”。也可直接输入http://xysy.sanya.gov.cn/CreditGovDepSystem/a/login

点击“开始报送”。

看到如下登录“政府应用系统”界面，输入用户名及密码。

步骤3：进入“信息报送”后看到如下内容：

红黑名单报送栏目下有法人红黑名单和自然人红黑名单；上报前需确认上报信息数据属于哪种类型的信息，在相对应的信息报送窗口进行数据报送。

步骤4：选择“模板下载”，将上报数据按照模板格式填入模板，保存到本地。

将模板下载到本地，使用office打开进行填写。

填写模板时，每一列填写说明都在模版中做出了相应的说明：

步骤5：批量导入数据，点击“批量导入”：

弹出“导入数据”页面，再点击“浏览”按钮，选择已保存在本地的报送数据，进行导入：

导入成功后，系统显示如图：

导入失败会有失败提示：

点击失败原因，打开可以查看详细信息：

注：现有模板无法满足上报内容时，需联系三亚市社会信用体系建设联席会议办公室（市金融办），技术人员将在3个工作日内根据需求新增或调整模板。

四、报送信用“红黑名单”信息账号与密码

（一）联席会议各成员单位已分配登录账号，提供了初始密码（密码要及时修改），各成员单位要建立三亚市公共信用信息共享平台账号管理、使用，信用信息报送、查询内部管理制度，专人负责管理账号和密码，信息报送、查询。

（二）如确需增加平台登录账号请填写三亚市公共信用信息共享平台登录账号开通申请表(点击下载)并加盖公章，传真或邮箱发至三亚市金融工作办公室进行账号注册申请。
