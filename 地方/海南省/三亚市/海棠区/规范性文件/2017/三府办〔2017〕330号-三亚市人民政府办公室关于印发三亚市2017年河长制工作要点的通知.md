# 三亚市人民政府办公室关于印发三亚市2017年河长制工作要点的通知

三亚市人民政府办公室

关于印发三亚市2017年河长制工作要点的通知

各区人民政府，育才生态区管委会，市各有关单位：

《三亚市2017年河长制工作要点》已经七届市政府第16次常务会议审议通过，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年10月26日

（此件主动公开）

三亚市2017年河长制工作要点

为贯彻落实《海南省2017年河长制工作要点》（琼河办〔2017〕2号）精神，结合《三亚市全面推行河长制工作方案》《三亚市水污染防治行动计划实施方案》《三亚市城镇内河（湖）水污染治理三年行动方案》《三亚市黑臭水体整治工作方案》《三亚市2017年城镇内河（湖）水污染专项整治工作实施方案》等要求，特制定三亚市2017年河长制工作要点。

一、健全河长制组织体系

（一）2017年5月底前，成立市级河长制领导小组和市级河长办公室；9月底前，建立市级河长制工作会议制度、信息共享制度、督察制度。（责任单位：市水务局、市生态环境保护局，配合单位：市法制办。）

（二）2017年8月底前，落实河湖分级名录调查确认、设立河长制公示牌、“一河一策”和“一河一档”等河长制工作经费，确保河长制年度工作任务按时完成。（责任单位：市水务局，配合单位：市财政局、市生态环境保护局。）

（三）按规定程序推动落实各级河长办人员编制，确保市、区两级河长办公室有专职人员负责河长办公室的具体工作，保障河长制工作顺利实施。（责任单位：市水务局、市生态环境保护局，配合单位：市编办、各区政府、育才生态区管委会。）

（四）2017年7月底前，各区政府（育才生态区管委会）成立河长制领导小组和河长制办公室；10月底前，建立区级河长制工作会议制度、信息共享制度、督察制度等工作制度。（牵头单位：市水务局、市生态环境保护局，责任单位：各区政府、育才生态区管委会。）

（五）2017年12月底前，全市所有河湖落实河长制，建立市、区级河长体系，市、区分别在政府网站或主要媒体公布相关河湖河长名单；设立反映河湖问题的投诉举报平台，公布举报电话。（牵头单位：市水务局，配合单位：12345政府服务热线管理办公室，责任单位：各区政府、育才生态区管委会。）

二、完善工作机制

（一）2017年7月底前，各区政府（育才生态区管委会）出台河长制工作方案，明确河长制工作目标、主要任务、组织形式和保障措施。（责任单位：各区政府、育才生态区管委会。）

（二）2017年12月底前，所有河湖岸边显著位置均要竖立河长制公示牌，标明河长姓名、职责、整治目标和监督电话等内容，接受公众监督。（责任单位：市水务局，各区政府，育才生态区管委会。）

（三）2017年10月底前，举办市级河长制培训工作，组织指导我市规范推行河长制工作。（责任单位：市水务局。）

（四）根据《关于深化行政执法体制改革推进市县综合行政执法指导意见》（琼府〔2017〕19号），建立健全覆盖河湖保护管理工作的跨领域综合行政执法机制。（牵头单位：市编办，责任单位：市法制办、市综合执法局。）

三、开展河湖调查摸底

（一）2017年6月前，通过开展河湖基本信息调查复核，全部确认所有河湖名录。2017年12月31日前，完成全市河湖调查摸底工作，为全面启动一河一策、一湖一策提供支撑。（牵头单位：市水务局，责任单位：各区政府、育才生态区管委会。）

（二）开展河湖水质、沿线排污企业、河湖排污口情况调查，并建立台账档案，其中：河湖水质、沿线排污企业调查由市生态环境保护局牵头，河湖排污口调查由市水务局牵头。（配合单位：市住房城乡建设局、市农业局、市海洋渔业局、市科技工业信息化局、市综合执法局，责任单位：各区政府、育才生态区管委会。）

（三）全面调查农业面源污染情况，并建立台账档案。（牵头单位：市农业局，配合单位：市生态环境保护局；责任单位：各区人民政府、育才生态区管委会。）

（四）全面调查全市河湖沿线500米以内的畜禽养殖情况，并建立台账档案。（牵头单位：市农业局，责任单位：各区政府、育才生态区管委会。）

（五）严禁河湖非法采砂行为，并建立台账档案。（牵头单位：市水务局，配合单位：市国土资源局、市交通运输局、市综合执法局、市公安局，责任单位：各区政府、育才生态区管委会。）

（六）全面调查河湖乱占乱建、河流乱围乱堵行为，并建立台账档案。（牵头单位：市水务局，配合单位：市综合执法局、市国土资源局，责任单位：各区政府、育才生态区管委会。）

（七）全面调查河流和水库沿岸绿化及湿地等情况，并建立台账档案。（牵头单位：市林业局，配合单位：市水务局、市园林环卫局、市住房城乡建设局、市国土资源局，责任单位：各区政府、育才生态区管委会。）

（八）全面调查市政雨水排放口排污情况，并建立台账档案。（牵头单位：市住房城乡建设局，配合单位：市生态环境保护局、市水务局，责任单位：各区政府、育才生态区管委会。）

四、实施河湖管理突出问题整治

（一）落实最严格水资源管理制度。实行水资源消耗总量和强度双控行动，切实做到以水定需、量水而行、因水制宜。抓紧推进节能减排工程实施，加快落后用水装置和设备的淘汰步伐，推动产业结构的优化调整。推进农业水价综合改革，加快试点灌区供水计量设施建设，推进小型农田水利工程管理体制改革，明晰农田水利设施产权，探索建立水权制度和建立健全农业水价形成机制。推行城镇居民阶梯水价和非居民用水超定额累进加价制度。严格水功能区监管，根据水功能区划确定的河流水域纳污容量和限制排污总量，落实污染物达标排放要求。2017年，全市用水总量控制在3.454亿立方米以内。（牵头单位：市水务局，配合单位：市发展改革委、市生态环境保护局、市科技工业信息化局、市财政局，责任单位：各区政府、育才生态区管委会。）

（二）开展农业面源污染治理。发展绿色农业和有机农业,减少农业面源污染。鼓励农民增施有机肥、物肥、缓释肥，推行测土配方施肥技术，研究制定农药、化肥使用种类目录和使用技术指南，提高废弃物的综合利用水平，降低农药、化肥、农膜污染的影响。大力推广深耕深施，结合节水灌溉，减少肥料流失。推进规模化畜禽养殖场和养殖小区的畜禽粪便处理利用设施建设。制定实施我市畜禽养殖发展规划和污染防治规划,划定养殖禁养区、限养区和适养区。2017年，化肥施用总量增幅控制在5%以内，依法逐步关闭或搬迁禁养区内所有的畜禽养殖场和养殖专业户。重点推进无疫区建设、畜禽废弃物综合利用措施、农业投入品田间农业废弃物回收利用措施、化肥农药减量增效措施、重大植物疫情监测防控措施等工作。（牵头单位：市农业局，配合单位：市发展改革委、市生态环境保护局、市国土资源局，责任单位：各区政府、育才生态区管委会。）

（三）加强工矿企业水污染防治。制定“三亚市十小企业清查清单”和实施计划，全面整顿燃煤小锅炉，严格控制建成区新建燃煤锅炉，实施环保综合提升工程，严格控制各区政府（育才生态区管委会）新建燃煤锅炉。（牵头单位：市生态环境保护局，配合单位：市发展改革委、市科技工业信息化局、市国土资源局、市农业局，责任单位：各区政府、育才生态区管委会。）

（四）控制水产养殖污染。制定辖区渔业养殖废水排海监测实施方案，加强对养殖废水排污口的排查和水质监测，严格查处未达标排放养殖废水的行为。加强水产品药残检测，严厉打击违法违规养殖用药行为。制定促进现代渔业发展的意见，推动水产养殖向集约化、标准化、产业化及生态化方向发展。（牵头单位：市海洋渔业局，配合单位：市生态环境保护局、市林业局，责任单位：各区政府、育才生态区管委会。）

（五）强化黑臭水体和城镇生活污水治理。全面推进城镇内河（湖）污染水体的综合治理。2017年年底前，列入内河（湖）水污染治理三年行动方案的11条河（湖）全面开工建设，8个断面要达到水质目标，水质达标率提升到40%。（牵头单位：市生态环境保护局，配合单位：市发展改革委、市财政局，责任单位：市水务局、市住房城乡建设局、各区政府、育才生态区管委会。）

全面推进城市黑臭水体整治工作。2017年年底前，全市黑臭水体消除率提升到70%。加快推进红沙污水处理厂二厂工程、荔枝沟水质净化厂二厂工程、红塘湾污水处理厂工程建设，因地制宜建设了一批移动污水处理站。全面推进污泥处置设施建设，禁止处理处置不达标污泥进入耕地，取缔非法污泥堆放点。城镇污泥无害化不低于75%。（责任单位：市水务局、各区政府、育才生态区管委会，配合单位：市生态环境保护局、市发展改革委、市财政局。）

制定城市污水管网建设和改造实施计划，加快大茅河水系污水排放拦截工程、回新村排污沟整治工程等污水管网新建、改造和污水提升泵站建设，提升污水收集和处理能力。加快推进污水管网建设，2017年要完成76.5公里污水管网建设。（责任单位：市住房城乡建设局、各区政府、育才生态区管委会，配合单位：市水务局、市发展改革委、市财政局。）

2017年年底前，全市产业园区应按规定建成污水集中处理设施，逾期未完成的，一律暂停审批和核准增加水污染物排放的建设项目，并依照有关规定撤销其园区资格。（牵头单位：市生态环境保护局、市科工委，配合单位：市水务局、市住房城乡建设局，责任单位：各区政府、育才生态区管委会。）

（六）加大农村生活垃圾及生活污水整治。深入推进特色风情小镇和美丽乡村建设，统筹农村改水改厕，加快完善农村基础设施，推动绿化、美化、彩化、亮化，实施农村环境连片整治。（责任单位：各区政府、育才生态区管委会，配合单位：市生态环境保护局、市财政局。）

加大农村生活垃圾整治。统筹农村垃圾处理，加快完善环卫基础设施，推动绿化、美化、彩化，实施农村环境连片整治。加快推进各区政府（育才生态区管委会）垃圾转运站、农村垃圾收集点建设，探索开展农村垃圾分类收集，实施垃圾源头减量试点，实施城乡非正规垃圾堆放点排查整治，加快推进垃圾焚烧发电项目建设。2017年5月底前，农村生活垃圾治理率达到92%以上，通过国家考核验收。（牵头单位：市园林环卫局，配合单位：市生态环境保护局、市财政局，责任单位：各区政府、育才生态区管委会。）

统筹农村饮水安全，全面开展农村生活污水治理，编制实施农村生活污水治理规划，采取截污纳管、建设一体化处理设施等措施，采用PPP模式对全市491个自然村的生活污水进行治理。2017年6月底前，完成农村生活污水治理规划编制。（牵头单位：市水务局，配合单位：市生态环境保护局、市财政局，责任单位：各区政府、育才生态区管委会。）

（七）加强侵占河湖水域整治和河道采砂管理工作。严厉打击侵占水域岸线行为，加大对沿河违法建设和占用河道非法行为的治理力度，依法拆除沿河违章建筑物、构筑物，全面清除违规侵占河道、妨碍流水的各类市政设施和施工围堰。（牵头单位：市综合执法局，配合单位：市水务局、市国土资源局、市公安局、市交通运输局，责任单位：各区政府，育才生态区管委会。）

加强河道管理，开展河道综合治理工程，维护河道生态安全。加大联合执法力度，落实河道巡查制度，集中开展以严厉打击非法采砂为目标的专项整治活动，坚决打击偷采、盗采等行为，遏制非法采砂行为。（牵头单位：市水务局，配合单位：市综合执法局、市国土资源局、市公安局、市交通运输局，责任单位：各区政府，育才生态区管委会。）

（八）开展非法设置入河湖排污口专项整治。加强入河排污口的监督管理，严格按照有关要求，认真抓好入河排污口设置审查、监督检查、档案台账管理等工作。2017年7月底前完成台账档案管理工作，并全面开展监督检查工作；2017年9月底前补办完善入河排污口设置论证报告（或对水功能区影响的分析报告）的相关审批手续；2017年12月底前，全市规模以上（指日排放废污水量300吨或年排放量10万吨，下同）入河排污口监测覆盖率不低于80％，规模以下入河排污口监测覆盖率不低于50％。（牵头单位：市水务局，配合单位：市生态环境保护局，责任单位：各区政府、育才生态区管委会。）

（九）严厉打击水环境违法行为。重点打击企业直排、私设暗管或利用渗井、渗坑偷排废水行为，以及不正常使用水污染处理设施，或者未经批准拆除、闲置水污染处理设施、超标排污管等水环境违法行为；构成犯罪的,要依法追究刑事责任。对于废水或废弃物排放不符合要求的养殖场（畜禽养殖、水产养殖），限期整改，达标排放，整改不到位的，依法关停；对于非法养殖场坚决实行取缔清拆。（牵头单位：市生态环境保护局，配合单位：市水务局、市农业局、市海洋渔业局、市住房城乡建设局、市公安局，责任单位：各区政府，育才生态区管委会。)

五、加大宣传力度

（一）宣传“河长制”新举措、新做法和保护河湖生态环境重大决策和部署。开展专项整治行动的跟踪宣传，营造声势，促进整治效果。（牵头单位：市委宣传部，责任单位：市水务局、市生态环境保护局、各区政府、育才生态区管委会。）

（二）立足提升全社会生态文明意识，凝聚生态文明建设共识与合力。（牵头单位：市委宣传部，责任单位：市水务局、市生态环境保护局、各区政府、育才生态区管委会。）

（三）加强生态文明教育，组织中小学校开展河湖保护管理教育，增强中小学生的河湖保护及涉水安全意识。（牵头单位：市委宣传部，配合单位：市水务局、市生态环境保护局，责任单位：市教育局、各区政府、育才生态区管委会。）

六、加强督察考核

（一）开展河长制工作督察。根据工作需要，采取联合督察或专项督查方式，对全市河湖分级名录确认、工作方案制定、组织体系建设、制度建立、主要任务实施、问题整改等进行督察。（牵头单位：市水务局、市生态环境保护局，配合单位：市委督查室、市政府督查议案室、市农业局、市科技工业信息化局、市林业局、市海洋渔业局、市住房城乡建设局、市综合执法局，责任单位：各区政府、育才生态区管委会。）

（二）严格目标任务考核。将全面推行河长制工作纳入最严格水资源管理制度考核和水污染防治行动计划实施情况考核。考核结果向社会公布，并作为地方党政领导干部综合考核评价的重要依据。（牵头单位：市水务局、市生态环境保护局，配合单位：市委督查室、市政府督查议案室，责任单位：各区政府、育才生态区管委会。）

（三）实施问责制度。对未通过年度考核的，要约谈区政府（育才生态区管委会）及其相关部门有关负责人，提出整改意见，予以督促。对突出水环境问题治理工作执行不力或限期治理不达标的具体责任单位和责任人要进行问责。（牵头单位：市水务局、市生态环境保护局，配合单位：市委督查室、市政府督查议案室，责任单位：各区政府、育才生态区管委会。）

七、工作要求

（一）落实工作职责。各牵头单位负责监督指导、督促各责任单位落实工作要点责任事项。各责任单位要按照工作要点和时间节点的要求，加快推进各项工作任务。各配合单位做好本职河长制工作的同时，要积极支持各牵头单位、责任单位完成各项任务，合力推动全市河长制更好、更快地发展。以上牵头单位中，排在第一位的单位负责日常牵头组织、协调推进相关工作。

（二）加强信息报送。各单位要安排联络员负责信息报送工作，于每工作日下午4:50前通过微信（三亚市河长制工作群）将工作动态报送市河长办公室，每月28日前上报负责事项的落实情况（含完成情况、存在问题及原因、下一步工作措施等内容），2017年12月15日前将全年本单位所负责事项的落实情况报送市河长办公室（纸质版及电子版，注明联系人及联系电话）。市河长办联系人:文世舜（88657671，13876895686），邮箱:syhzb2017@163.com。
