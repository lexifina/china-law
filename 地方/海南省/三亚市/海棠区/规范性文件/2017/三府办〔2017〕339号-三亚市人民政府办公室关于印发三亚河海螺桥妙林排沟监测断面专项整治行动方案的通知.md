# 三亚市人民政府办公室关于印发三亚河海螺桥妙林排沟监测断面专项整治行动方案的通知

三亚市人民政府办公室

关于印发三亚河海螺桥妙林排沟监测断面

专项整治行动方案的通知

各区人民政府，育才生态区管委会，市各有关单位：

《三亚河海螺桥妙林排沟监测断面专项整治行动方案》已经市政府同意。现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年10月30日

（此件主动公开）

三亚河海螺桥妙林排沟监测断面

专项整治行动方案

根据《海南省城镇内河（湖）水污染治理三年行动方案》《三亚市城镇内河（湖）水污染治理三年行动方案》精神，为加大水污染治理力度，确保三亚河海螺溪、妙林排沟监测断面稳定达标，特制定本行动方案。

一、工作目标

通过持续深入治理，着力解决三亚河海螺桥、妙林排沟河段影响断面水质的水污染问题，在2017年12月底前实现治理范围内的水体稳定达标在地表水Ⅲ类。

二、存在问题及整治措施

今年以来，三亚东河海螺桥监测断面水质为地表水Ⅴ类，未达到地表水Ⅲ类的管理目标；三亚妙林排沟监测断面自2016年下半年以来水质一直稳定达标于地表水Ⅲ类，但2017年7月降为地表水Ⅳ类，水质达标不稳定。

上述2个水体存在的主要水污染问题及整治措施如下：

（一）三亚东河海螺桥监测断面

1.污水排河。污水排放口共有12处，主要因为雨污分流不完善导致雨污混排进入河道，估算排放量约7500吨/天。

整治措施:

（1）荔枝沟二桥上游左岸戒毒所污水提升泵站偶尔因停电、垃圾堵塞等原因停止运行，导致污水通过泵站溢流口排河，需加强泵站监管，杜绝污水排河；荔枝沟二桥上游右岸雨水排放口，雨水排放的时候会将截污纳管的生活污水带入河道，需完善荔枝沟路市政雨污分流管网；荔枝沟二桥下游左岸排洪渠口，学院路与汕头村周边区域雨水汇经排洪渠排入河道，需杜绝生活污水混入排河；海螺桥头上游右岸排放口污水排河，应予以有效整治，杜绝污水排河；海螺桥下游100米右岸污水排河，应予以有效整治，杜绝污水排河；（责任单位：市住房城乡建设局）海螺中桥上游左岸50米排放口污水来源为上游海螺村、南新农场二队，生活污水通过灌溉渠排入河道，该处建有污水提升泵站，但目前处于溢流状态，需采取有效措施，杜绝污水排河；（责任单位：市住房城乡建设局；配合单位：吉阳区政府）迎宾桥头下游右岸市政污水检查井有大量污水从市政污水检查井溢流入河，应对污水溢流问题进行整治；海螺中桥下游800米右岸雨水排放口排放污水，应予以有效整治，杜绝污水排河；海螺桥上游300米右岸排放口污水排河，应予以有效整治，杜绝污水排河。（责任单位：市住房城乡建设局、市水务局）

（2）海螺中桥下游850米左岸排放口污水来源为海螺村居民生活污水通过沟渠排入河道，该处虽建有移动式污水处理站，但目前处理能力不足，需改造移动式污水处理系统，增设泵站解决污水处理能力不足问题；设置浮岛、水上加强净化系统、增加曝气、微生物活化系统、生物基及仿生水草系统等，进一步核减水环境污染物指标，持续改善三亚河水环境。（责任单位：市水务局）

（3）荔枝沟水质净化厂排放口污水来源为荔枝沟水质净化厂经处理后达标排放的中水。由于该中水排放量大，且水质磷含量仍较高，水质净化厂应采取降低中水磷含量的有效措施，提升河道水质。（责任单位：市水务局）

（4）在各村庄的入河排污口安装临时生活污水处理设施，主要有：对该断面影响较大的南丁村、封塘村、海螺村。（责任单位：市水务局）

（5）荔枝沟二桥下游右岸雨水排放口污水来源为荔枝沟自来水厂生产尾水，通过市政雨水排放口排入河道，需检测水质是否达标排放，如确定违法排放污水，应予查处，杜绝生产尾水超标排入河道。（责任单位：市生态环境保护局）

2.垃圾占河。三亚东河荔枝沟二桥至溪泽三桥段共有各类垃圾2处，分别是：海螺西路海螺桥下游50米左岸，沿河岸堆放大量动物毛发垃圾，面积约180平方米；海螺桥上游500米河道内有大量生活垃圾、枯树枝等未清理。

整治措施：吉阳区政府应组织清理影响海螺桥断面水质的沿河堆放的各类垃圾，防止垃圾被雨水冲入河道而造成二次污染。（责任单位：吉阳区政府）

3.农业面源污染。海螺桥上游南丁田洋种植面积约1210亩，沿河种植区长期过量施用农药、化肥，使其残留物沉积土壤，并随降雨、农田作业翻耕时流入河内，影响河道水质。

整治措施：加强南丁田洋的农药、化肥施用技术指导，推广低毒、低残留农药。对农药、化肥的包装瓶、包装袋等物品统一收集处理，严禁丢弃于田间地头或河道内。结合现有农田灌溉沟渠，建设生态沟渠、污水净化塘、地表径流集蓄池等设施，净化农田排水及地表径流，严禁农田退水直接排放地表水体。（责任单位：吉阳区政府；配合单位：市农业局）

（二）妙林排沟监测断面

1.污水排河。妙林排沟周边的妙林村、白鸡村、新联村、下大恶坝村等村庄存在居民生活污水通过田洋沟渠排河。

整治措施：

（1）对于农村生活污水对该断面影响较大的共7个自然村：妙林村（妙山村、六乡村、鹅仔村、林家村）、水蛟村（白鸡村、上下乙村、水足村），其中妙林村（妙山村、六乡村）、水蛟村（白鸡村、下乙村）4个自然村属我市棚改拆迁范围，没有纳入农村生活污水治理工程范围内，妙林村（鹅仔村、林家村）、水蛟村（水足村）3个自然村计划列入第二批实施计划中。针对没有纳入农村污水治理的村庄，可在村庄的入河排污口安装临时生活污水处理设施予以临时解决污水排河问题。（牵头单位：市水务局；配合单位：天涯区政府）

（2）针对妙林村三亚凤凰旺达实木家具厂、三亚展华幼儿园等2家单位将生活污水排入灌溉沟渠，汇入妙林排沟，污染河道水体问题，需通过执法等措施进行整治，杜绝污水排河。（牵头单位：天涯区政府，配合单位：市生态环境保护局、市水务局）

（3）对于项目或生产经营单位的排污行为，通过严格执法查处的措施予以整治。（责任单位：市生态环境保护局，配合单位：市水务局、市住房城乡建设局、天涯区政府）

2.养殖污染。养猪场3处，猪存栏约30头，青蛙养殖1处。天涯区白鸡村、妙林村家庭式零星养殖排污处理设施缺失，养殖废水通过沟渠排入湿地水塘后通过灌溉沟渠排入河道，对水体造成危害。

整治措施：区政府负责取缔、拆除妙林排沟及上游河道沿岸禁养区内的畜禽养殖场，严禁在排沟内从事养鸭、养牛等养殖放牧行为。（责任单位：天涯区政府）

3.农业面源污染。妙林排沟存在农业灌溉尾水回流排河口12处，其中存在排水的10处，排放水量估算约15000吨/天。妙林田洋种植面积约有4600多亩，沿河种植区长期过量施用农药、化肥，使其残留物沉积土壤，并随降雨、农田作业翻耕时流入河内，影响河道水质。特别是，妙林排沟灌溉尾水回流入河口，农田灌溉退水及农业种植翻耕导致废水直接或间接排入排洪沟，今年7月此类行为突出，对当月妙林排沟断面突发超标构成严重影响。

整治措施：加强妙林田洋的农药、化肥施用技术指导，推广低毒、低残留农药。对农药、化肥的包装瓶、包装袋等物品统一收集处理，严禁丢弃于田间地头或河道内。结合现有农田灌溉沟渠，建设生态沟渠、污水净化塘、地表径流集蓄池等设施，净化农田排水及地表径流，严禁农田退水直接排放地表水体。（责任单位：天涯区政府；配合单位：市农业局）

4、生态补水及水环境治理。增加妙林排沟生态来水，保障河流生态流量，增加水环境治理措施，持续改善水环境。

整治措施：落实妙林排沟生态来水补给方案，将汤他水库下游木棉坝农业灌溉用水部分分流补充至妙林排沟，补充生态基流，促进水流通；设置浮岛、水上加强净化系统、增加曝气、微生物活化系统、生物基及仿生水草系统等，进一步核减水环境污染物指标，持续改善妙林排沟水环境。（责任单位：市水务局）。

三、工作要求

（一）高度重视。妙林监测断面水质是国家考核断面，海螺桥为省级考核断面。2016年下半年至2017年6月稳定达标于Ⅲ类水质，2017年7月份从Ⅲ类变为Ⅳ类，影响了我省考核结果。海螺桥断面2017年上半年以来水质监测结果显示，水质为Ⅴ类，未达到Ⅲ类水质目标。天涯区人民政府、吉阳区政府、各责任部门要高度重视所面临的严峻形势，要对整治任务进行细化和分解，对标解决影响断面水质的各类水污染问题。

（二）加强协作和信息报送。各单位要对工作发现的情况和信息及时共享，加强部门之间的联动机制，形成合力，并自9月起，每周五前将整治工作进展情况报送市水务局，市水务局对整治情况进行汇总后上报市政府。

（三）巡查督察督办。整治工作开展期间，市水务局组成巡查小组，定期巡查整治工作进展情况，及时通报和督促各责任单位落实整治工作。
