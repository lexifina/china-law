# 三亚市人民政府办公室关于印发三亚市工程车辆污染路面联合整治行动实施方案的通知

三亚市人民政府办公室

关于印发三亚市工程车辆污染路面联合整治

行动实施方案的通知

各区人民政府，各管委会，市政府直属各单位：

《三亚市工程车辆污染路面联合整治行动实施方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年11月1日

（此件主动公开）

三亚市工程车辆污染路面联合整治行动

实施方案

为进一步加强对工程车辆污染路面行为的整治，营造整洁、美观的道路环境，结合我市实际，制定本方案。

一、组织领导

为加强组织领导，成立三亚市工程车辆污染路面整治工作领导小组。

领导小组下设办公室，设在市综合行政执法局，市综合行政执法局副局长李清云兼任办公室主任。

二、时间安排

整治行动时间为2017年11月1日至2018年2月28日，分为两个阶段：

（一）集中整治阶段。时间为2017年11月1日至2018年1月31日。各单位联合行动，集中整治污染路面及超限超载的工程车辆，查处违法违规行为，通过严管重罚规范工程车辆的管理，确保上路的工程车辆符合标准。

（二）巩固提高阶段。时间为2018年2月1日至2018年2月28日。建立属地常态化管理机制，加强对上路工程车辆的日常监管，巩固整治成果，营造整洁、美观的道路环境迎接春节黄金周。

三、整治内容

（一）联合整治上路的工程车辆

各区组织区城管局和区公安交警大队联合行动，日间和夜间各安排一支队伍共同上路执法，采取监控重点工地、巡查主要道路、设卡检查等方式，加大对上路的工程车辆的检查力度，依法查处带泥上路、沙土遗撒、车体未覆盖、超限超载等违法违规行为。市综合行政执法局联合市公安局交警支队开展机动整治，加强执法协作，在市区主要道路设卡检查，严查工程车辆违法违规行为。

（二）规范施工工地和工程车辆的管理

市住房城乡建设局通知所有施工工地将工程车辆名单送市综合行政执法局、市公安局交警支队和区城管局备案，并加强对所有在建工地的检查，对工地出入口未硬化和未设置冲洗设备的责令工地限期整改，逾期未整改到位的要依法查处。各区政府、市住房城乡建设局和市园林环卫管理局要严格要求所负责的项目工地高标准管理工程车辆，做到上路前要冲洗干净，要覆盖好车体，不超限超载。

四、职责分工

（一）市综合行政执法局：负责对整治工作开展情况进行督查、督办，联合市公安局交警支队开展机动整治行动，依法查处工程车辆带泥上路、沙土遗撒、车体未覆盖等行为。

（二）各区政府、育才生态区管委会：负责片区整治工作，依法查处工程车辆带泥上路、沙土遗撒、车体未覆盖等行为，并做好所负责项目工地的工程车辆管理。

（三）市公安局：负责联合各区政府、市综合行政执法局开展整治行动，依法查处工程车辆超限超载行为。

（四）市住房城乡建设局：负责对在建工地进行检查和执法，并做好所负责项目工地的工程车辆管理，配合各单位开展整治行动。

（五）市园林环卫管理局：做好所负责项目工地的工程车辆管理，配合各单位开展整治行动。

五、工作要求

（一）加强组织领导。各单位要高度重视，将整治工作部署到位，安排一名分管领导具体负责工作，尽快组建执法队伍。各区政府要结合片区实际，主动联合市公安局交警支队共同上路执法，并组织区住房城乡建设局、区城管局加强对辖区在建工地的检查和执法。

（二）加大处罚力度。各执法部门要依法行政，对违法违规的工程车辆作暂扣处理并立案处罚。对造成路面污染的，要责令其清洗路面，对不积极采取措施消除路面污染的要从重处罚。

（三）做好信息报送。各单位要根据职责开展整治工作，每日下午18时前将整治情况报送领导小组办公室（联系人：吴玉立，联系电话：88595026）。领导小组办公室每日汇总整治情况报分管市领导。
