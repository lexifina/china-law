# 三亚市人民政府办公室关于印发《三亚市开展2017年度半年土地卫片执法监察工作方案》的通知

三亚市人民政府办公室

关于印发《三亚市开展2017年度半年土地卫片执法监察工作方案》的通知

各区人民政府，育才生态区管委会，市各有关单位:

《三亚市开展2017年度半年土地卫片执法监察工作方案》已经市政府同意，现印发给你们，请认真贯彻执行。

三亚市人民政府办公室

2017年11月14日

（此件主动公开）

三亚市开展2017年度半年土地卫片执法监察工作方案

为全面贯彻落实国家关于切实强化日常执法监管，及时发现和查处违法行为，推动执法监管“重心下移、关口前移”的工作要求，做好三亚市2017年度上半年土地卫片执法监察工作，结合实际，拟定本工作方案。

一、主要任务

通过开展半年土地卫片监察，实现“天上拍、地上巡”的立体防控措施，及时发现，及时处置违法行为，拆除未经规划报建的新增建筑物或构筑物，切实做好三亚市违法建筑管控和保护三亚市宝贵的国土资源，提前主动介入国家2017年度卫片执法监督和土地例行督察工作。

二、执法监察对象

本次执法监察的对象为2017年度上半年高清疑似违法卫片图斑。2017年共采集变化图斑11635个。按照国家关于勾选疑似违法图斑的政策要求和依托“图形（GIS）和数据库（MIS）”一体化的地籍管理信息系统，经对采集的卫片11635个图斑进行叠加分析，共分析出疑似违法图斑1470个。其中崖州区268个，天涯区452个，吉阳区337个，海棠区312个、育才管委会101个。

三、职责分工

市国土资源局负责具体组织开展三亚市2017年半年土卫片执法监察工作。依托“图形（GIS）和数据库（MIS）”一体化的地籍管理信息系统，将用地审批信息与对采集的卫片图斑进行叠加分析，形成疑似违法图斑；按照国家卫片执法政策的要求根据土地管理法律法规，对违法占地行为严格依法查处，对查处过程中发现涉嫌刑事犯罪的，依法移送公安机关处理；对属于违法用地涉及违法建设图斑，根据《三亚市土地执法共同责任制实施办法》、《三亚市违法建筑管控办法》的相关规定，将未经规划报建的新增建筑物或构筑物上报市政府批转各责任单位落实整改；及时掌握各区图斑查处整改进展情况，视情在市政府主导下牵头组织召开全市卫片工作整改推进会；在市政府部署下，会同市政府督查室对各区违法图斑拆除复垦复耕工作进行市级督导；按照市政府的部署和要求将各责任单位查处整改情况汇总上报市政府；依据半年土地卫片图斑整体情况，对全市土地违法形势进行分析并将情况上报市政府，促进全市土地管理秩序不断好转。

各区政府（或育才生态区管委会）应切实贯彻《三亚市土地执法共同责任制实施办法》、《三亚市违法建筑管控办法》的有关规定，落实属地监管职责，充分发挥区政府、社区居委会、村委会的基层前沿作用，负责本辖区范围内对卫片图斑逐一开展外业核查，对违法占地建设的项目责令停工、查封施工现场、查处以及拆除复垦复绿工作；对符合设施农用地手续的图斑督促用地单位或个人办理设施农用地备案手续；核实农村建房图斑是否符合一户一宅。按照市政府的部署和要求，将查处整改情况汇总函报市国土资源局（邹海梅，联系电话88217326）。

市综合执法局按照职责，负责组织育才生态区管委会行政区范围内违法占地建设的巡查、防控、责令停工、查封施工现场、查处及拆除等工作；负责协调指导各区政府（管委会）依法做好防控和查处违法建筑相关工作。

市财政局负责落实三亚市2017年度半年度卫片执法监察工作的后勤保障工作，将半年卫片执法监察工作专项行动所需工作经费纳入年度财政预算，确保工作顺利开展。

市规划局在进行项目规划报建审批时应核实项目用地是否合法，不得对涉嫌违法用地的项目审批办理。

市住房城乡建设局在进行建设项目审批时应核实项目用地是否合法，不得对涉嫌违法用地的项目审批同意。

市公安局负责对非法买卖土地以及其他涉嫌犯罪的土地违法行为和违法勘查采矿行为组织查处，依法追究违法当事人的刑事责任；对妨碍、阻扰、围攻、殴打有关部门执法人员的违法当事人应及时出警并依法查处。

市林业局应加强对占用林地建设的监督检查，依法严格核准建设项目占用林地，并依法对非法占用林地的违法行为进行查处整改。

海南神泉集团有限公司、海南省国营南新农场、海南海垦南繁集团产业股份有限公司和海南农垦投资控股集团立才农场有限公司负责加强各农场土地的属地监管，引导场地内项目建设及职工依法用地，对卫片图斑涉及的符合农场职工建房政策的职工建房及符合设施农用地补办手续图斑依法完善用地手续。

四、工作安排

（一）数据处理下发阶段（2017年11月5日前）。

2017年11月5日前，市国土资源局对采集的半年度图斑依托“图形（GIS）和数据库（MIS）”一体化的地籍管理信息系统，将用地审批信息与对采集的卫片图斑进行叠加分析，形成疑似违法图斑。逐图斑勾勒出卫片影像，并将疑似违法片图斑及卫星影像下发至各区政府（或育才生态区管委会）。

（二）自查整改阶段（2017年11月6至11月30日）。

2017年11月6至11月30日，各责任单位要严格按照本方案的时间节点和工作要求按时对疑似违法片图斑开展外业实地核查和查处整改，并将查处整改情况函告市国土资源局。

（三）查处整改情况上报阶段（2017年12月1至12月10日）。

市国土资源局汇总各责任单位查处整改情况，并在在2017年12月10日前将有关情况形成报告报市政府。

五、工作要求

（一）加大宣传，统一思想。

各责任单位要充分利用报纸、电视、电台、网络等新闻媒体进行全方位、多形式、多层次的宣传教育，正确舆论导向；保持对违法行为高压打击姿态。

（二）齐抓共管，合力做好卫片执法监察工作。

为做好三亚市2017年度上半年卫片执法监察的各项工作任务，各成员单位应在市领导小组的领导下明确分工，按照《三亚市土地执法共同责任制实施办法》和《三亚市违法建筑管控办法》要求，各司其职，积极协助，通力配合，定期召开联席会议，落实责任到人，形成工作合力，做到机构、人员、经费三落实，切实履行部门职责，确保有效完成卫片执法监察工作。

（三）严格依法规范公正查处整改违法行为

各成员单位要按照有关法律法规及规章的要求，依法严肃查处违法行为。坚持既查事、又查人的原则，做到应收缴的罚没款收缴到位，应没收的建筑物和其他设施没收到位，应拆除的建筑物和其他设施拆除到位，责任人责任追究到位，对涉嫌犯罪的，要依法移送司法机关。

（四）加强日常执法监管，努力转变监管方式。

要切实强化日常执法监管，及时发现并查处整改违法行为，努力将违法违规行为“发现在初始，解决在萌芽”。
