# 三亚市人民政府办公室关于印发三亚市内河（湖）水污染治理检查整治工作方案的通知

三亚市人民政府办公室

关于印发三亚市内河（湖）水污染治理检查

整治工作方案的通知

各区人民政府，育才生态区管委会，市各有关单位：

《三亚市内河（湖）水污染治理检查整治工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年11月23日

（此件主动公开）

三亚市内河（湖）水污染治理检查整治工作方案

为扎实推进生态文明建设，严格落实河长制，根据《中共三亚市委关于进一步加强生态文明建设工作实施方案》《三亚市全面推行河长制工作方案》及有关水污染治理文件要求，结合工作实际，制定三亚市内河（湖）水污染治理检查整治工作方案如下：

一、指导思想

全面贯彻党的十九大精神，深入落实省委、市委关于进一步加强生态文明建设的工作要求，坚持生态立市，坚持河长制，坚持问题导向，加快治理内河湖水污染突出问题，不断提升和巩固水生态安全，进一步夯实三亚生态文明基础，在全省生态文明建设中争当先锋。

二、整治目标

加快实施内河（湖）水污染，落实综合治污措施和长效治理机制，2017年12月30日前，各治理水体水质有明显提升；到2018年年底前，11条治理河流18个监测断面力争达到Ⅳ类及以上水质，全面实现水质管理目标。

三、主要问题

今年10月份11条内河湖18个内河（湖）断面达标数为12个，达标率为66.7%，内河湖水质持续向好，但仍存在以下主要问题，对内河湖水环境根本改善构成严重影响。

（一）水污染问题依然突出。11条内河湖剩余135处水污染“硬骨头”问题需下大力气整治，包括：排污口96个，垃圾侵占河道13处，养殖排污15处，农业面源8处，船舶污染3处。其中，三亚河108处排污口已完成整治58个，剩余50个排污口尚需整治。（市住房城乡建设局负责43个，市水务局负责4个，天涯区政府负责3个）

（二）水质达标有波动。个别断面水体达标不稳定，容易出现反弹，如妙林断面、桃源河断面出现达标与超标交叉的情况；海螺断面常年不达标。

（三）污水处理设施建设滞后，污水收集处理能力不足。原天涯镇、崖城镇、藤桥镇等老镇区市政污水管网建设滞后，已建成的红塘湾、崖城、海棠湾污水处理厂进厂污水不足，污水厂负荷率低。受雨污分流管道建设滞后、电力供应不稳定以及个别污水处理厂容量不足的限制，主城区一些排水口及泵站溢流口出现溢流现象。

（四）海水考核达标有难度。采用海水类考核标准治理感潮河段水体，治理技术不成熟，治理难度大，国内尚未成功案例。

四、治理措施

（一）加强排污口整治

1.在市政污水管网覆盖区域或者市政污水管网可延伸区域，采取截污纳管、管口封堵等方式治理排污口。（责任单位：市住房城乡建设局）

2.对于项目或生产经营单位的排污口，通过严格执法查处的措施予以整治。（责任单位：市生态环境局）

3.对于市政污水管网未覆盖的农村生活污水排放口，通过建设一体化污水处理设备、人工湿地等措施予以集中整治。（责任单位：市水务局、各区政府、育才生态区管委会）

（二）加强河道生态治理

1.围绕18个水质监测断面，以及妙林国控断面、海螺省控断面开展水环境治理，落实综合治理措施，对白鹭公园小桥、山水国际内湖、三亚东河临春桥及潮见桥、三亚西河月川桥、三亚大桥、青梅港、烧旗沟、白水溪、鸭仔塘、腊尾山塘、大茅水、盐灶溪、藤桥西河等断面水体进行水环境治理，同时积极探索海水类监测断面达标治理措施。（责任单位：市水务局、市生态环境局、各区政府）

按照《三亚河海螺桥妙林排沟监测断面专项整治行动方案》（三府办〔2017〕339号）要求，逐项落实整治措施，加快治理妙林国控断面、海螺省控断面水体。（责任单位：市水务局、市住房城乡建设局、市生态环境局、天涯区政府、吉阳区政府）

东岸、抱坡溪两个湿地公园要同步实施水环境治理措施，净化水体，提升水质。（责任单位：市园林环卫局）

2.全力推进河道综合整治和水系连通工程建设。加快三亚东河、漳波河综合治理工程，实施三亚河口清淤疏浚工程，提升水环境容量和水质安全。加快建设海坡内河水系连通工程、大茅水～高原水库连通工程、西水中调工程建设，贯通河流生态通道，改善水系生态环境。（责任单位：市水务局）

（三）完善污水收集处理系统

1.加快污水处理厂建设与改造。加快建设红沙污水处理二厂、荔枝沟水质净化二厂、红塘湾水质净化厂、亚龙湾污水处理二厂工程、国际旅游岛人才城污水处理厂等污水设施工程；实施新城水质净化厂提标改造工程、三亚学院污水处理站改造工程，进一步提升水质标准。（责任单位：市水务局）

2.加快市政污水管道及污水提升泵站建设，实施白水溪、荔枝沟路、学院路等路段干、支管网配套工程，建成一批污水提升泵站，提高污水收集率，实现雨污分流。（责任单位：市住房城乡建设局）

加快实施崖城老镇污水处理厂截污并网工程。（责任单位：崖州区政府）

加快实施吉阳高新产业园截污并网工程。（责任单位：市科工委）

（四）大力治理农村农业面源污染

1.依法取缔、拆除违法排污的畜禽养殖设施，指导养殖户按照减排模式的要求建设污染治理设施。（责任单位：各区政府、育才生态区管委会）

2.对农药、化肥使用严格管理，对农药、化肥的包装瓶、包装袋等物品统一收集处理，严禁丢弃于田间地头或河道内。（牵头单位：市农业局，责任单位：各区政府、育才生态区管委会）

3.加强农村生活污水收集处理，统筹采取分散处理、就近处理或集中处理等方式，通过截污纳管、建设一体化处理设施等措施，采用PPP模式对491个自然村的生活污水进行治理。（责任单位：市水务局、市委农工委、各区政府、育才生态区管委会）

4.整治农村环境卫生，落实农村垃圾“日产日清”，及时清除沿河建筑及生活垃圾。（责任单位：各区政府、育才生态区管委会）

（五）加强污染监管，严惩违法排污

1.依法严厉查处企事业单位、建设或经营项目、建设工地非法排污、超标排污的行为。（责任单位：市生态环境局）

2.加强管理建筑工地，防治施工废水及工人生活废水，杜绝直排入河。严禁将污水排入雨水管网，并根据《城镇排水与污水处理条例》的规定，依法查处市政排水设施覆盖地区的污水乱接乱排行为。（责任单位：市住房城乡建设局）

3.严厉打击破坏河道、侵占河道、倾倒河道垃圾的违法行为，依法拆除河岸、河内的违章建筑物、构筑物。（牵头单位：市综合执法局，责任单位：各区政府、育才生态区管委会）

（六）防控船舶、港口污染

1.加强河流出海口各类船舶的监督管理，清理整顿“三无船舶”，严厉查处船舶废弃物、废污水、油污直排水体的行为。（责任单位：各区政府、市海洋渔业局、市交通运输局、三亚海事局）

2.完善港口区域污水管网、垃圾转运服务体系，港口、码头接收的含油污水、化学品洗舱水要进行无害化处理，避免造成二次污染。（责任单位：各区政府、市交通运输局）

（七）加强水质监测体系建设

加大、加密水质监测，落实主要河流“一周一测”措施，及时、准确地掌握水体水环境质量现状及变化情况，为水污染治理提供科学依据。（责任单位：市生态环境局）

五、工作要求

（一）加强组织领导。各区政府、育才生态区管委会、市政府各有关单位要进一步增强责任意识，把内河湖水污染治理作为生态文明建设重要工作来抓牢抓实，主要领导要亲自抓，精心组织，强力推进，确保全面完成治污工作任务。

（二）构建长效机制。河长制工作和内河湖水污染治理工作要紧密结合起来，市水务局、市生态环境局要整合资源，统一排查台账和督查通报，聚焦发力、合力推进水污染治理工作。市水务局牵头组织推进河长制，强化河长制在内河湖水污染治理工作中的抓手作用。市河长办要抓紧落实督查督办、情况通报等河长制督察制度，协调督促各级河长、各责任单位落实治理任务。各区（育才生态区）河长办公室要紧盯辖区治污问题，督促落实属地治理责任。创建微信工作群，动态推进水污染治理各项工作，各区（育才生态区）、各单位内河湖水污染整治工作情况要及时反映在工作群内，并于每月25日前向市河长办书面报送相关治理情况。

（三）加强监督考核。对于落实治污责任不力的河长及相关责任人、责任部门，采取通报批评、行政问责、河长约谈等多种形式进行问责。

（四）强化社会监督。加大媒体宣传力度，充分发挥12345、12301市民投诉统一平台的作用，鼓励公众举报、反映河湖污染问题，扩大社会监督影响面。各区（育才生态区）要积极创建“民间河长”“企业河长”“巡河志愿者”等群体，进一步强化河湖管护合力。
