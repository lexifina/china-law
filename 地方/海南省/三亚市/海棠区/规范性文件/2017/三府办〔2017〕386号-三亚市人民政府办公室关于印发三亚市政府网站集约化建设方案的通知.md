# 三亚市人民政府办公室关于印发三亚市政府网站集约化建设方案的通知

三亚市人民政府办公室

关于印发三亚市政府网站集约化建设方案的通知

各区人民政府,各管委会,市政府各有关单位:

《三亚市政府网站集约化建设方案》已经市政府同意,现印发给你们,请认真组织实施。

三亚市人民政府办公室

2017年12月5日

(此件主动公开)

三亚市政府网站集约化建设方案

为贯彻落实《海南省人民政府办公厅关于推进政府网站集约化建设的通知》(琼府办函〔2017〕263号)要求,进一步推进我市政府网站集约化建设,优化网站结构布局,规范政府网站管理,提升运行维护及信息安全保障水平,结合我市实际,制定本工作方案。

一、工作目标

以“三亚市人民政府网站集约化平台”为中心,推进各区、市直各部门政府网站集约化建设,对政府网站功能进行整合迁移,建设政府网站群,并实行统一运维管理。通过资源整合和平台集约,推动政府网站管理水平提升和改革创新,增强政府网站政务公开能力、公共服务能力、信息共享能力、技术支撑能力和安全保障能力。

二、基本原则

按照国务院办公厅、省政府办公厅关于政府网站集约化建设相关要求和绩效评估标准,全市政府网站集约化建设工作遵循“统筹规划、分级负责、分层推进、整合共享、保障安全”的原则,关停一批、规范一批、升级一批。市政府办公室负责编制全市政府网站集约化建设方案并指导实施,各区、各部门办公室负责本辖区、本单位网站集约化建设具体工作。

三、集约化建设的范围

本方案中需集约化建设的政府网站,主要指市、区政府及其部门、承担行政职能的事业单位,依托国际互联网开办的网站,包括:

(一)已纳入全国政府网站普查范围的政府网站。

(二)已经建站,但未纳入全国政府网站普查范围的政府网站。

(三)尚未建站,但建站后需纳入全国政府网站普查范围的政府网站。

(四)其他需要集约化建设的政府网站。

四、总体要求

(一)各区基层网站。

各区直属部门、街道办事处及以下单位,原则上不单独建设网站,已建成的必须于2018年3月底前,关停并集约至本区政府门户网站,完成数据迁移,以栏目或频道的形式呈现。因特殊原因确需保留的网站,经本级政府同意后,报市政府办公室审核。

(二)各区政府门户网站。

各区政府门户网站原则上应于2018年3月底前集约至“三亚市人民政府网站”统一平台,并完成数据迁移。

(三)市直各单位网站。

市直各单位原则上每个单位只保留1个政府网站。尚未集约至“三亚市人民政府网站”统一平台的,必须于2018年3月底前完成集约,并完成数据迁移。因特殊原因不能集约的政府网站,需提交书面申请,报市政府办公室审核。

五、工作安排

(一)关停一批。我市在全国政府网站信息报送系统共有29个政府网站,本次需注销关停政府网站11个,保留政府网站18个(其中保留市政府门户网站1个,保留市直部门网站17个)。拟关停的政府网站主办单位通过全国政府网站信息报送系统(http://pucha.kaipuyun.cn)申请网站永久关停,经逐级审核批准后,原网站要在首页显著位置悬挂迁移公告信息,随后向管理部门注销注册标识、证书信息(如ICP备案编号、党政机关网站标识、公安机关备案标识等)和域名。拟关停的政府网站要同步正常维护至数据迁移结束,网站完成迁移后,相关政府门户网站或部门网站要发布公告,说明被整合迁移网站内容去向,有关公告信息原则上至少保留30天。因特殊原因需要单独保留的网站,由其建设、管理单位向市政府办公室申请同意后,由市政府办公室统一向省政府办公厅申请。(市政府办公室、拟关停网站主办单位负责,2017年12月底前完成)

(二)规范一批。拟保留的政府网站其名称和域名需规范。网站名称以本部门机构名称命名。已有名称不符合要求的,要尽快调整,或在已有名称显示区域加注规范名称。政府网站要在头部标识区域显著展示网站全称。

市政府各部门网站要使用三亚市人民政府门户网站的下级域名,其结构应为“○○○.sanya.gov.cn”,其中○○○为本部门名称拼音或英文对应的字符串。如三亚市统计局域名为tjj.sanya.gov.cn。

政府网站不宜注册多个域名,已有域名不符合要求的,要逐步注销。网站栏目和内容页的网址原则上使用“○○○.sanya.gov.cn/.../...”形式。新开设的政府网站及栏目、内容页域名要按照本方案要求设置,原有域名不符合要求的要逐步调整规范。

市政府各部门政府网站名称或域名修改完成后,需在全国政府网站信息报送系统(http://pucha.kaipuyun.cn)“基本信息修改”功能中修改网站名称或域名等基本信息。(市政府办公室、各部门、市科技工业信息化局负责,2017年12月底前完成)

(三)升级一批。市政府办公室和各部门按照国办《政府网站发展指引》,结合三亚实际,对三亚市人民政府门户网站和各部门网站进行规划和设计,确保政务公开有窗口、互动交流有渠道、便民服务有载体。页面设计应简洁、大方、明了,方便社会公众查阅、浏览。(市政府办公室、市科技工业信息化局、各部门负责,2018年3月底前完成)

(四)统一政府网站集约化平台。市科技工业信息化局梳理网站集约和迁移操作流程,制订《政务网站生成平台建站、迁移流程指引》,指导各区、市直各部门网站集约至“三亚市人民政府网站群”统一平台,并对各单位网站管理人员进行业务培训。各区、各部门根据《政务网站生成平台建站、迁移流程指引》,组织专门团队对本区政府门户网站、本部门网站向“三亚市人民政府网站群”统一平台集约,按时完成改版和数据迁移。(市科技工业信息化局、尚未集约的各区、各部门负责,2018年3月底前完成)

(五)修订《三亚市政府网站管理办法》。根据集约化建设情况和统一运维需求,修订《三亚市政府网站管理办法》,明确网站建设各主体单位责任,进一步规范我市政府网站的建设、运行、管理和维护。(市政府办公室负责,2018年3月底前完成)

六、工作要求

(一)落实工作责任。市政府办公室负责政府网站集约化建设工作的组织、统筹协调、部署推进。各区、各部门要专人专责,按照时间进度全力推进,狠抓落实。各区、各部门,包括网站已关停的部门依然要承担上级网站子站、栏目、频道的运维职能,及时准确地做好相关信息发布、政策解读、热点回应、互动交流、便民服务等工作。

(二)强化网站管理。各区、各部门作为网站的主办单位开设和关停网站,必须严格按照国家有关政府网站建设指引要求,按程序逐级申请。未经审批,严禁擅自开办和关停网站。

各区、各部门要进一步强化网络安全意识,严防失密、泄密和安全事件发生。

(三)加强监督考核。市政府办公室将对全市政府网站集约化进展情况进行督促检查,对于行动迟缓、拖延推诿,未按统一时限要求完成工作任务的单位,将予以通报批评。相关工作落实情况纳入全市政府网站年度绩效考核。
