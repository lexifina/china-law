# 三亚市人民政府办公室关于印发三亚市关于进一步促进金融业发展的实施意见的通知

三亚市人民政府办公室

关于印发三亚市关于进一步促进金融业

发展的实施意见的通知

各区人民政府，各管委会，市各有关单位：

《三亚市关于进一步促进金融业发展的实施意见》已经七届市政府第18次常务会议审议通过，现印发给你们，请认真遵照执行。

三亚市人民政府办公室

2017年12月5日

（此件主动公开）

三亚市关于进一步促进金融业发展的实施意见

为全面贯彻党的十八大、十八届历次全会和十九大精神，全国、全省金融工作会议精神，以及省委、市委开展“深入学习贯彻习近平总书记视察海南时的重要讲话精神建设美好新海南”百日大研讨大行动工作要求，进一步促进我市金融业稳定、健康、创新发展，结合我市实际，提出如下意见。

一、进一步明确发展目标

（一）指导思想。认真执行国家经济金融政策，坚持服务实体经济、防范风险、改革创新，以金融组织体系建设为抓手，完善金融市场主体，发展普惠金融服务，优化金融生态环境，深化金融改革创新，提升金融业服务水平和能力，为我市建设国际化热带滨海旅游精品城市、争当建设美好新海南排头兵提供强有力的金融支持。

（二）发展定位。立足国际旅游岛建设、“一带一路”倡议支点城市、南海开发建设战略机遇，发挥我市区位优势、生态优势，增强金融要素集聚能力，提升金融资源配置效率，提升金融业竞争力，努力把我市建设成为海南金融业发展副中心，金融改革的先行区、金融生态的优质区、金融运行的安全区。

（三）总体目标。到“十三五”末，基本建成各类金融机构健全、金融产品丰富、创新能力较强、服务功能完善、具有较强影响力的现代金融业服务体系。力争全市金融业增加值占地区生产总值比重达到13%左右，占服务业增加值比重达到20%左右，把金融业发展成为我市重要的支柱产业。

二、加快发展市场主体

（四）大力发展地方法人金融机构。支持地方法人金融机构做大做强，鼓励阳光人寿保险公司加大对我市的贡献力度，推动三亚农商银行在“新三板”挂牌和跨区域经营；支持国企整合资源，发起设立金融控股集团公司，壮大地方金融机构实力；支持三亚市中小企业小额贷款公司股份制改造，支持惠民村镇银行增资扩股，扶持崖城众树资金互助社更好地服务三农和精准扶贫；积极引进有实力和影响力的金融机构和企业到我市设立法人机构。（责任单位：市金融办、三亚银监分局）

（五）大力发展新型金融机构。支持企业发起设立金融租赁（融资租赁）公司、担保公司，带动游艇产业、水上飞机、船舶制造、海洋工程行业发展。积极发展金融中介和新兴业态，引进私募股权投资企业，发展资产评估、资信评级、证券咨询机构，引导发展金融软件、数据处理、服务网络等金融辅助产业。探索发展互联网支付、电子商务结算等互联网金融。（责任单位：市金融办）

（六）鼓励金融业聚集发展。利用我市棚户区改造契机，完善金融业用地规划，保障金融业发展用地，建设金融聚集区。鼓励金融集团、总部机构到我市发展金融聚集区，拓展金融业发展新空间，树立我市金融业聚集发展新品牌。（责任单位：市金融办、市规划局、市国土局、市住房城乡建设局、三亚银监分局）

三、积极拓展融资渠道

（七）发挥银行的主体作用。发挥开发性金融、政策性金融和重点银行机构的作用，贯彻执行中央货币政策，运用货币政策工具，不断改善信贷结构。充分利用开发性政策性银行的中长期融资优势，提升商业性信贷资金投放总量、结构和节奏，争取尽可能多的政策性信贷资金，进一步加大“双修”、南海资源开发、棚户区改造、“一支柱两支撑”重点产业项目的中长期信贷支持。（责任单位：人民银行三亚市中支、三亚银监分局）

（八）推动融资模式创新。发挥市场对资源配置的决定性作用和更好地发挥政府的作用，建立政府引导、政企分开、社会参与、市场运作的投融资体制。提高财政资金的使用效率，发挥政府资金作用，设立重点产业引导基金，引导更多社会资金投入战略性新兴产业和基础设施建设，缓解地方政府建设资金的不足，促进经济结构调整和产业转型升级。（责任单位：市财政局）

（九）发展多层次资本市场。扩大企业直接融资规模，继续按照“培育一批、辅导一批、改制一批、上市一批”的总体要求和工作思路，采取境内与境外，主板、中小板、创业板与区域股权市场并举的方针，积极推动符合产业政策、有规模、效益好的优势企业上市融资，对具有三亚重点产业特色的企业纳入上市后备资源库并给予重点培育。对有条件的企业，充分利用债券、各类证券化产品等进行融资，提升全市金融产品运用的多样性和广泛性。对拟上市企业（含新三板、区域性股权交易市场挂牌企业）在规范重组过程中，涉及办理房屋土地等类不动产权登记、产权交易、土地房屋测绘的，相关部门提供快捷服务，费用按最低标准收取。（责任单位：市金融办、市发展改革委、市国土局、市住房城乡建设局）

四、加快金融改革创新

（十）务实推进金融业创新开放。充分利用战略机遇和区位优势, 积极参与跨境金融创新和金融交流合作,充分利用博鳌亚洲论坛、三亚财经国际论坛、亚洲金融合作联盟、亚太金融研究院等高端平合开展合作交流活动, 促进资金、人才、信息、业务等资源的相互流动，努力提升金融服务现代化和国际化水平。在全省统筹下积极探索离岸金融试点工作，争取离岸金融业务落地。支持金融机构“走出去”，鼓励我市金融机构到外地设立分支机构、拓展业务。（责任单位：市金融办、人民银行三亚市中支、三亚银监分局）

（十一）创新绿色金融。将生态文明理念融入金融产业，提升绿色金融的战略地位，加大宣传和推广力度，加强金融政策和产业政策的协调配合，严格控制“三高一低”企业资金服务，推动金融机构将环境评估纳入流程，在投融资行为中注重对生态环境的保护，引导各类金融机构创新绿色金融产品和服务，通过信贷、保险、上市、理财、担保等多种金融工具积极发展绿色金融。（责任单位：市金融办、人民银行三亚市中支、三亚银监分局）

（十二）推动三权抵押贷款创新。积极争取探索建立和规范农村产权流转交易市场，增强农村资产流动性，完善与农村金融服务及创新相关的农村产权确权、登记、评估、交易等中介服务，缓解农村金融供给不足。（责任单位：市农业局、市金融办、市国土局、三亚银监分局）

（十三）促进保险业健康快速发展。鼓励保险公司产品创新，丰富市场内涵，不断扩大保险覆盖面，提高保险服务的深度和密度，满足不同层次消费需求。加强与保险公司合作，搭建保险资金运用对接平台，引导保险资金投向康养不动产、健康医疗产业、基础设施建设项目等。支持保险中介市场发展，提升专业化服务水平，加强行业自律。（责任单位：市金融办、市保险业协会）

五、努力发展普惠金融

（十四）加强农村金融服务。继续实施农民小额贷款贴息和精准扶贫政策，简化贴息流程，提高贴息效率，加强贴息政策宣传，进一步调动三农发展积极性，实现农民增收。合理运用支农再贷款、再贴现工具，对涉农票据、农村企业以及涉农贷款占比高的金融机构优先办理票据再贴现。运用精准扶贫贷款风险补偿机制，大力发放扶贫小额贷款，推广“银行+企业+贫困户”放贷模式，支持贫困户发展绿色生态种养业、经济林产业、森林旅游、休闲农业、传统手工业、乡村旅游、农村电商等特色产业，实现产业脱贫。（责任单位：市金融办、人民银行三亚市中支、三亚银监分局）

（十五）加强小微金融服务。设立和运用小微企业风险补偿专项资金,对接银行服务小微企业的信贷产品，优选小微企业群体，分担银行风险，扩大银行放贷倍数，扶持小微企业发展，有效化解小微企业融资难、融资贵问题。（责任单位：市科技工业信息化局、三亚银监分局）

（十六）推动消费、支付便利化服务。建立金融服务民生工作协调机制，支持在景区景点、公交出租、商场超市、教育医疗等领域普及应用手机支付等非现金支付方式，为市民游客创造快捷、便利、安全的支付环境，方便群众生活。推动银行收单机构在商户中推广外卡受理。（责任单位：人民银行三亚市中支、市金融办、三亚银监分局、市旅游委、市交通局、市商务会展局、市教育局、市卫计委）

六、营造良好金融发展环境

（十七）完善金融发展扶持政策。建立财政资金竞争性定存机制，充分考虑银行机构对我市经济社会发展的贡献度，积极引导银行机构服务济社会发展；完善《三亚市促进金融业发展扶持奖励办法》，加大对创新工作的奖励力度，建立金融创新专项评选办法，奖励在创新工作方面表现突出的金融机构；对金融监管部门推动金融机构加大对实体经济和重点项目支持力度的，在评先评优、通报表扬等方面给予倾斜。（责任单位：市金融办、市财政局）

（十八）优化政务服务环境。大力强化优质服务意识，简化行政审批手续和程序，切实降低金融机构的经营成本，为金融机构设立，办理抵押、登记、税务、工商等服务提供便捷、高效的政务配套服务。（责任单位：市政务服务中心、市国土局、市住房城乡建设局、市国税局、市地税局、市工商局）

（十九）优化金融发展舆论环境。加强与新闻媒体沟通，坚持正确的舆论导向，营造我市金融业发展的良好舆论环境。开展金融知识进企业、进社区、进家庭等公众金融教育活动，面向社会公众普及金融知识，营造关心、支持金融业的社会氛围。加强与省金融办等省级部门、人民银行海口中支等监管部门、金融机构和外部的沟通联系，宣传三亚的区位优势和政策，争取更多的金融机构了解三亚、服务三亚。（责任单位：市金融办、人民银行三亚市中支、三亚银监分局、市委宣传部）

（二十）搭建政银企信息对接平台。加强对接服务平台建设，巩固政银企对接机制、部门与行业协会对接机制，定期组织召开政府、企业与银行、担保公司融资对接会,搭建多层次合作交流平台。探索建立小微企业金融服务中心，集中金融产品和资讯、会计、法律、资产评估等中介服务，为小微企业发展提供融资政策咨询、融资受理、配套服务的长效综合服务平台。（责任单位：市金融办、人民银行三亚市中支、三亚银监分局）

（二十一）加强社会信用体系建设。加强社会信用体系规划、制度建设工作，建设和运行市级公共信用信息共享平台，建立信用信息互通共享、联合惩戒、信用应用等工作机制，不断推动政务诚信、商务诚信、社会诚信和司法公信建设，积极创建社会信用体系建设示范城市，为金融业发展提供良好社会信用环境。（责任单位：市金融办、人民银行三亚市中支、市发展改革委、市科技工业信息化局、三亚银监分局）

七、切实防范金融风险

（二十二）加强风险防范体系建设。建立健全部门数据交换、金融信息共享运行机制，加强综合统计，做好金融业发展动态分析和研判。加强对地方政府融资平台、房地产、影子银行、民间金融等重点领域的监测，大力整治非法集资等非法金融活动，严厉打击金融犯罪，排查化解各类风险隐患，严守不发生系统性、区域性金融风险的底线，维护我市金融稳定。（责任单位：市金融办、市公安局、人民银行三亚市中支、三亚银监分局、市发展改革委、市财政局、市统计局）

（二十三）加强地方金融监管。搭建央行、金融监管部门、金融办、发改、财政、统计、公安等职能部门参与的经济运行、金融风险、财政风险会商制度，健全金融稳定和打击处置非法集资、非法金融、洗钱犯罪工作协调机制，拓展监管合作领域和范围，加快构建跨行业、多层次、全覆盖、高效金融风险防范处置工作体系，合力引导金融业健康发展，净化金融市场，防止恶性竞争，保持金融稳定。（责任单位：市金融办、人民银行三亚市中支、三亚银监分局、市发展改革委、市财政局、市统计局、市公安局）

八、建立金融业发展保障机制

（二十四）建立金融业发展协调机制。加强金融业组织领导、协调服务和行政效能，完善金融办工作职能，充实人员队伍，提高服务能力，适应金融改革创新、稳定发展要求。密切省市互动、一办一行一局配合，务实解决金融发展难题。（责任单位：市金融办、人民银行三亚市中支、三亚银监分局）

（二十五）加强金融业人才队伍建设。大力引进金融业高级技术和管理人才，鼓励政府部门与监管部门、金融机构开展双向挂职交流。按照《海南省公安机关推进户籍制度改革实施细则（试行）》《三亚市引进人才办法（试行）》的相关规定开展人才引进工作，化解人才落户、安居、子女教育问题。完善人才培养机制，引导海南热带海洋学院、三亚学院等高校调整学科、专业设置，增强经济、金融专业人才培养能力，为金融业发展培养实用人才，提升金融行业人才综合素质。（责任单位：市人社局、市公安局、市住房城乡建设局、市教育局、三亚银监分局）
