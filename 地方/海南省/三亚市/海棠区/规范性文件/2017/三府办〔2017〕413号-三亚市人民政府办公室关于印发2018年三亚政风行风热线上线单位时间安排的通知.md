# 三亚市人民政府办公室关于印发2018年三亚政风行风热线上线单位时间安排的通知

三亚市人民政府办公室

关于印发2018年三亚政风行风热线上线

单位时间安排的通知

各区人民政府，育才生态区管委会，各有关单位：

为了继续推动我市政风行风建设，根据市领导指示，《三亚政风行风热线》的直播栏目（播出频道：FM104.6天涯之声；播出时间：每周四下午15:00-16:00），将继续开播，各参与单位“一把手”要积极参与并主动做好播前、播中、播后的各项工作，高度重视群众的意见和建议，积极解决群众关注的“创文巩卫”、精准扶贫等热点难点问题，架起政府和群众之间的公开对话桥梁，为加快国际化热带滨海旅游精品城市建设做出贡献。

附件：2018年《政风行风热线》上线单位时间安排

三亚市人民政府办公室

2017年12月28日
