# 三亚市人民政府办公室关于海南省五指山至保亭至海棠湾高速公路项目三亚段土地调查有关事项的通知

三亚市人民政府办公室

关于海南省五指山至保亭至海棠湾高速公路

项目三亚段土地调查有关事项的通知

海棠区人民政府，市政府各有关单位：

根据新建海南省五指山至保亭至海棠湾高速公路项目的用地需要，经市政府同意，对海南省五指山至保亭至海棠湾高速公路项目三亚段用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于海棠区辖区内，用地调查面积约1001309平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见省征地办提供的海南省五指山至保亭至海棠湾高速公路（三亚段）公路征地拆迁图。土地权属（海南平面坐标系）情况为海棠区东溪村和藤桥村委会集体土地共约200901平方米、海南省国营三道和南田农场国有土地共约399363平方米、市政府土地约66763平方米、海南神泉集团有限公司等4家公司国有土地共约334280平方米；土地利用现状（西安80坐标系）为农用地约834880平方米（其中沟渠约1864平方米、灌木林地约3056平方米、果园约218600平方米、旱地约121764平方米、可调整果园约120253平方米、可调整坑塘水面约504平方米、可调整有林地约2158平方米、坑塘水面约13047平方米、农村道路约32702平方米、其他园地约145065平方米、人工牧草地约37450平方米、设施农用地约498平方米、水田约133756平方米、有林地约4163平方米），建设用地约134468平方米（其中采矿用地约426平方米、村庄约750平方米、公路用地约87150平方米、建制镇约44982平方米、铁路用地约1160平方米），未利用地约32390平方米（其中其他草地约2182平方米、河流水面约12492平方米、裸地约180平方米、内陆滩涂约17536平方米）；该项目用地在土地利用总体规划2014年调整完善（西安80坐标系）中规划为城镇用地约597平方米、风景名胜设施用地约11517平方米、公路用地约49537平方米、旱地约174054平方米、河流水面约10823平方米、坑塘水面约12831平方米、林地约15019平方米、农村居民点用地约973平方米、设施农用地约100平方米、水工建筑用地约9184平方米、水田约126977平方米、滩涂约26265平方米、铁路用地约1490平方米、园地约562373平方米。上述不符合我市土地利用总体规划的部分用地建议由省规划委统筹纳入我省“多规合一”成果蓝图并按程序上报国务院审批。上述用地涉及的约378435平方米耕地在办理农用地转用时，由省政府统筹安排耕地占补平衡指标。待完成占补平衡任务后，由海棠区政府按要求提供用地报批材料，市国土资源局将其列入当年新增建设用地指标并办理农转用及征收报批手续。

二、为做好该项土地调查工作，由海棠区政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市国土资源局负责征收集体土地范围内征地业务指导工作；市住房城乡建设局负责收回国有土地范围内征地业务指导工作。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地及收回农场国有土地征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行。收回农场国有土地外的其他国有土地征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）规定执行。

四、根据2010年6月26日国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，海棠区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认，向市国土资源局出具履行征地前告知等程序的证明及土地权属确认意见（附件1）。待有权限的人民政府批准征地后，征收土地公告和征地补偿安置方案公告可同步进行。

五、为进一步做好被征地农民养老保险工作，根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神，应在本通知下发后10个工作日内对项目征收农用地和享受缴费补贴人数等情况进行调查，组织村（居）小组填写《征地项目被征地农民基本情况调查表》（附件2），经村（居）委会、海棠区政府逐级审核后，由海棠区政府汇总填写《征地项目被征地农民基本情况乡镇调查汇总表》（附件3），并将上述两种表格报送市国土资源局。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。
