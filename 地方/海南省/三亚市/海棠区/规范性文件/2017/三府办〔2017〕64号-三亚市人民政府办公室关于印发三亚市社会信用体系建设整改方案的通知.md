# 三亚市人民政府办公室关于印发三亚市社会信用体系建设整改方案的通知

三亚市人民政府办公室

关于印发三亚市社会信用体系建设

整改方案的通知

市社会信用体系建设联席会议各成员单位：

去年底，国家发改委会同中央网信办、银监会、证监会等组成联合督查组，对我市社会信用体系建设工作进行了督查，肯定了我市在社会信用体系建设工作中的成绩，同时也指出了我市工作中的不足，提出了整改意见。根据市政府对《关于2016年度社会信用体系建设督查工作情况报告》的批示精神，为改进工作，切实加强我市社会信用体系建设，现将《三亚市社会信用体系建设整改方案》印发给你们，请认真组织实施。

三亚市人民政府办公室

2017年3月11日

（此件主动公开）

三亚市社会信用体系建设整改方案

根据国家发改委社会信用体系建设督查意见和市政府批示精神，结合我市信用体系建设实际，制定以下整改措施。

一、工作目标

加快落实国务院、省政府关于加快建设社会信用体系的规划部署，围绕热带滨海旅游精品城市建设和我市国民经济社会发展“十三五”规划纲要，结合旅游、高新技术、热带高效农业等支柱、支撑产业的发展，全面推进政务诚信、商务诚信、社会诚信和司法公信建设，以信用制度建设为核心，以信用信息共享和平台建设为抓手，发挥信用管理机制作用，不断完善我市社会信用体系，促进“诚信三亚”建设，提高全社会诚信意识和诚信水平，营造诚实守信的经济社会环境。

二、责任分工

（一）调整完善我市社会信用体系建设联席会议制度，加强统筹协调我市社会信用体系建设工作。（责任单位：市金融办、人民银行三亚市中心支行，配合部门：市发改委，市科工信局。完成时间：2017年1月底前）

（二）充实市联席会议办公室，配备工作人员，承担好社会信用体系建设日常工作。加强全市公共信用信息的归集、整合、加工、处理及相关服务工作。（责任单位：市金融办，配合部门：人民银行三亚市中心支行、市信息管理中心。完成时间：2017年3月底前）

（三）申报全国社会信用体系建设示范城市。通过全国社会信用体系示范城市建设，统筹我市社会信用体系建设工作，强化责任落实，倒逼各行业信用机制改革，用2年左右时间，初步建设与我市国际化热带滨海旅游精品城市相适应的社会信用体系。（责任单位：市联席会议办公室，配合单位：市发改委、市科工信局、人行三亚市中心支行。完成时间：2017年2月底前）

（四）加强信用体系规划建设工作。聘请信用信息服务中介机构参与，市联席会议办公室尽快制定三亚市社会信用体系建设工作计划并启动实施，重点制定企业信用监管、联合惩戒等配套制度，推进行业信用建设，健全企业和个人信用信息，发挥信用体系建设在经济社会发展中的重要作用。（责任单位：市联席会议办公室，配合单位：市发改委、市科工信局、人行三亚市中心支行。完成时间：2017年6月底前）

（五）加快信用信息交换平台建设。按照信用建设标准化有关要求，尽快制订信用信息数据标准、交换共享规则和接口技术规范，在现有电子政务平台基础上，建设和运行全市信用信息交换平台，建设“信用三亚”网。（责任单位：市联席会议办公室，配合单位：市发改委、市科工信局、人行三亚市中心支行。完成时间：2017年6月底前）

（六）对出现不良信用事件的行业和部门，要快速反应，有针对性地进行整改并及时向媒体通报。加强行业管理，重点提高旅游、工商、环保、价格、执法、建设、国土、人社、司法、金融、食品药品、卫生等行业信用，降低不良信用事件出现率。（责任单位：市信用体系建设联席会议成员单位，重点是市旅游委、市工商局、市环保局、市发改委（物价局）、市执法局、市住建局、市国土局、市人社局、市公安局、市检察院、市中级人民法院、三亚银监分局、市食品药品监管局、市卫生局、市林业局、市海洋渔业局。完成时间：长期）

（七）加强信用制度建设，要尽快完善信用体系相关制度。（责任单位：市信用体系建设联席会议成员单位，重点是电子商务领域、交通运输领域、生产领域、税务领域、中介会展广告统计领域、文化体育教育科研及其他领域、知识产权领域、法院检察院公信、公共安全领域公信等9个未在网上监测到信用制度公布的领域。完成时间：2017年4月底前）

（八）做好与全国城市信用状况监测平台沟通工作，及时通报我市社会信用体系建设工作情况。（责任单位：市联席会议办公室。完成时间：长期）

（九）在市级门户网站开通统一社会信用代码公示栏目，公示统一社会信用代码工作进展情况。（责任单位：市科工信局、市工商局、市编办、市民政局。栏目开通时间：2017年3月底前，统一社会信用代码工作进展情况公示时间：2017年4月开始）

（十）制定“红黑名单”制度，对守信企业给予激励，对失信企业开展联合惩戒，4月起每月向联席会议办公室报送守信激励和失信惩戒的典型案例（责任单位：市社会信用体系建设联席会议成员单位。完成时间：2017年3月底前）

三、督查督办

市社会信用体系建设联席会议成员单位要高度重视社会信用体系建设工作，要指定分管领导，指定专门科室和人员负责整改工作，市金融办、人行三亚市中心支行要按照时间节点进行督查督办，工作推进缓慢、未落实或落实不到位的，由市政府督查室进行通报。（责任单位：市联席会议办公室，配合单位：市政府督查室。完成时间：长期）
