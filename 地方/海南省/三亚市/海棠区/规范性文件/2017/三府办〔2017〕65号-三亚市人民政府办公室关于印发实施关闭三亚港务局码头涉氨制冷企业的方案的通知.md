# 三亚市人民政府办公室关于印发实施关闭三亚港务局码头涉氨制冷企业的方案的通知

三亚市人民政府办公室

关于印发实施关闭三亚港务局码头涉氨

制冷企业的方案的通知

天涯区政府，市各有关单位:

《实施关闭三亚港务局码头涉氨制冷企业的方案》已经市政府同意，现印发给你们，请认真贯彻执行。

三亚市人民政府办公室

2017年3月10日

（此件主动公开）

实施关闭三亚港务局码头涉氨制冷企业的方案

为及时妥善处置三亚港务局码头涉氨制冷企业环保和安全隐患问题，制定本方案：

一、基本情况

三亚港务局码头涉氨制冷企业由于历史原因，存在无规划审批、无规范设计、设施设备严重老化、维护保养不及时、安全管理薄弱等诸多安全隐患问题。近年来，根据《国务院安委会关于深入开展涉氨制冷企业液氨使用专项治理的通知》（安委〔2013〕6号）要求，市安全监管局牵头组织了多次专项治理，先后关闭了13家不符合安全生产条件的涉氨制冷企业。目前仍存在8家，其中三亚海洋制冰厂和腾达制冰厂等2家企业仍在继续生产，三亚福隆冰冻厂等6家已经停业但未抽离液氨，这些企业违规继续生产，影响了我市渔港搬迁的工作部署，特别是存在的安全隐患，严重危及人民的生命财产安全。

二、工作目标

坚持安全第一，依据国家的有关规定，全面检查评估其安全生产状况，责令不具备安全生产条件的企业停止生产经营活动，安全转移处置危险源（液氨），完成三亚港治理及安全隐患整治工作。

三、任务分工及时限

（一）三亚质量技术监督局、市武警消防支队等相关单位要开展一次现场检查，对照相应的法律法规、技术标准，向企业下达相应的执法文书。不符合安全要求的，责令其停止使用相应的设施设备。（3月10日前完成）。

（二）市安全监管局邀请国家级权威专家，进行现场检查评估，出具安全评估报告。（3月17日前完成）。

（三）市安全监管局牵头，结合有关职能部门意见，进一步开展沟通协调工作，促使企业自行关闭处置危险源（液氨），同时形成专题报告提交市政府。如果企业不配合处置危险源（液氨），则采取停水停电等强制性措施，予以关闭或取缔。（4月28日前完成）。

（四）由市安全监管局牵头，协调相关部门制定强制性关闭及抽取液氨的现场处置方案，确保执行过程的安全平稳。

（五）市供电、供水部门要全力支持和落实市安全监管局对不具备安全生产条件企业做出的有关停电停水决定。

（六）市海洋渔业局要履行行业监管的职责，全力支持和配合有关部门采取的行政强制措施，加强涉氨制冷企业的安全监督检查。

四、工作要求

（一）各相关职能部门要切实履行职责，依法依规从严实施现场检查。

（二）加强联动和协调，及时向市安全监管局报送相关执法信息。

（三）及时协调解决各种困难和问题，确保危险源处置过程中的安全。
