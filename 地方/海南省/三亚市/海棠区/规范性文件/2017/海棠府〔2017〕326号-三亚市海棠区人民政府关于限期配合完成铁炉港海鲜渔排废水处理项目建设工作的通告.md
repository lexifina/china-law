# 三亚市海棠区人民政府关于限期配合完成铁炉港海鲜渔排废水处理项目建设工作的通告

三亚市海棠区人民政府

关于限期配合完成铁炉港海鲜渔排废水处理项目建设工作的通告

多年来，由于经营活动过于频繁，铁炉港非法占海海鲜鱼排存在各类生活垃圾、污水和餐饮废弃物直接倾倒、排放入海现象，导致该区域海水出现不同程度污染和水质下降。今年以来，随着中央环保督察力度不断加强，彻底解决铁炉港渔排污染问题已提到重要议事日程，列入到环境污染整治责任事项中。为解决污水乱排问题，改善铁炉港水域生态环境，促进区域经济的可持续发展，区人民政府投入200万元启动实施了铁炉港海鲜渔排废水处理项目，将各海鲜渔排产生的污水进行收集处理后达标排放。

项目建设工作实施以来，由于非法占海海鲜渔排经营户环保意识不强，主动配合意识不高，致使项目建设进展过于缓慢。为了加快推进项目建设，确保海鲜渔排餐饮废水及生活污水达标排放，有效保护铁炉港海域生态环境，现要求各非法占海海鲜渔排经营户于本通告发布之日起至2018年2月10日前配合施工单位完成海鲜渔排废水处理项目建设，如因非法占海海鲜渔排经营户配合不力导致项目无法按期完工的，区人民政府将依法予以强制拆除。同时，通告发布之日起，严禁任何海鲜渔排未经批准擅自改建扩建，一经发现，区政府将依法予以强制拆除。

特此通告。

三亚市海棠区人民政府
