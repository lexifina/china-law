# 三亚市海棠区人民政府关于开展铁炉港渔排养殖退养还海工作的通告

三亚市海棠区人民政府

关于开展铁炉港渔排养殖退养还海工作的通告

根据《中华人民共和国环境保护法》《中华人民共和国海洋环境保护法》《中华人民共和国海域使用管理法》《中华人民共和国渔业法》等法律法规规定，为保护铁炉港海域生态环境,充分合理利用铁炉港海域资源，促进渔业、航运、旅游等功能的协调发展,海棠区人民政府决定对铁炉港养殖渔排实施全面退养。现将有关事项通告如下：

一、本次实施退养的范围指铁炉港海域内所有从事渔业养殖的渔排，具体以海棠区人民政府于2016年5-8月组织普查、丈量和统计确认的养殖龙口、工作平台、居住棚等海上设施为准。

二、各养殖户在通告发布之日起6个月内，即2018年6月20日前全面完成退养还海工作。在通告规定期限内鲜活水产品由各养殖户自行处理后自行拆除养殖渔排；至通告时间届满尚未完成退养还海的，区人民政府将按非法养殖依法予以强制拆除，由此产生的一切损失由养殖户自行负担。对无理取闹制造事端者，由公安机关依照《中华人民共和国治安管理处罚法》的规定处罚；构成犯罪的，依法追究刑事责任。

特此通告。
