# 三亚市海棠区人民政府关于印发《三亚市海棠区政府投资建设项目开展预算评审和决（结）算审计规定》的通知

三亚市海棠区人民政府

关于印发《三亚市海棠区政府投资建设项目开展预算评审和决（结）算审计规定》的通知

各相关单位、村（居）委会：

根据二届区政府第18次常务会议要求，为加强我区政府投资建设项目的全面监督，促进项目业主单位自觉规范管理，保障工程质量，提高投资效益，现将修定后的《三亚市海棠区政府投资建设项目开展预算评审和决（结）算审计规定》印发给你们，请遵照执行。

三亚市海棠区人民政府

2017年4月7日

（此件主动公开）

关于政府投资建设项目开展预算评审和

决（结）算审计的规定

为加强我区政府投资建设项目的全面监督，促进项目业主单位自觉规范管理，保障工程质量，提高投资效益。结合我区政府投资项目的实际，对我区政府投资项目开展预算评审和决（结）算审计做如下规定：

一、不论工程造价大小，原则上都必须由单位领导班子审定或报送区财政局预算评审后方可实施。

二、投资额5万元以下（不含5万元）的项目，工程量清单报价经单位领导班子审定后按合同包干价执行。

三、投资额5万元以上（含5万元）到20万元以下（不含20万元）的项目，预算由业主单位自行编制并经单位领导班子审定，决（结）算编制后由具有资质的社会中介机构审计并报单位领导班子审定。

四、投资额20万元以上（含20万元）的项目，除送区财政局进行预算评审外，还必须送区审计局进行决（结）算审计，工程造价以最终审定金额为准。

五、涉及面较广或影响较大的项目，经区领导批示，亦需进行预算评审和决（结）算审计。

六、以区政府、区筹备组及原镇政府名义出台的文件，有定额标准的，按定额标准执行，可不进行预算评审和结算。

七、区财政局和区审计局开展预算评审和决（结）算审计工作所需经费，分别由区财政局和区审计局负担。

八、本规定出台之前20万元以下（不含20万元）的项目已实施预算评审，但还没申请决（结）算审计的，可不再报送区审计局进行决（结）算审计而按本规定执行。

九、执行过程中具体问题，由区财政局和区审计局共同解释。

十、本规定自印发之日起执行。
