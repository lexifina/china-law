# 三亚市人民政府办公室关于《三亚市政府性债务管理暂行办法》等28件市政府规范性文件限期修改或重新制定的通知

三亚市人民政府办公室

关于《三亚市政府性债务管理暂行办法》等28件市政府规范性文件限期修改或重新制定的通知

各相关单位：

经七届市政府第21次常务会议审议通过，决定《三亚市政府性债务管理暂行办法》等28件市政府规范性文件限期修改或重新制定（详见附件）。请各单位按照《三亚市人民政府规范性文件制定程序办法》要求在2018年11月前提交市政府审议。

附件：限期修改或重新制定的28件市政府规范性文件
