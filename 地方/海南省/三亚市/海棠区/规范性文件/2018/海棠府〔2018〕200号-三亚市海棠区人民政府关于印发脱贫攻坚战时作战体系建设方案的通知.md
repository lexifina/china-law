# 三亚市海棠区人民政府关于印发脱贫攻坚战时作战体系建设方案的通知

三亚市海棠区人民政府

关于印发脱贫攻坚战时作战体系建设方案的通知

各有关单位:

《海棠区脱贫攻坚战时作战体系建设方案的通知》已经区政府同意，现印发给你们，请认真贯彻执行。

三亚市海棠区人民政府

2018年6月8日

（此件主动公开）

海棠区脱贫攻坚战时作战体系建设方案

为贯彻中央关于“省负总责、市县抓落实、乡镇扑下身子”的要求，落实刘赐贵书记一系列批示指示精神，切实打通脱贫攻坚“最后一公里”，有力解决基层扶贫工作职责不清、力量分散、落实不到位等突出问题，坚决打赢打好脱贫攻坚战，现就进一步完善区包村脱贫攻坚工作机制制订方案如下：

一、作战时间

2018年6月1日至脱贫攻坚期结束

二、作战体系

1.建立区、村干部扑下身子抓脱贫攻坚的战斗体系。在区成立打赢脱贫攻坚战指挥部的基础上，进一步明晰、压实“区直机关单位包村”的工作机制，以行政村、自然村为单位，划定脱贫攻坚作战区城，设立类似军事管理的基层三级战斗队，包村单位领导、第一书记、村两委干部、帮扶责任人、村民小组组长等各方面力量全部编入战斗队伍，形成分工明确、责任清晰、各方力量有效整合、攻坚压力传导到位的工作格局。

2.在区设立脱贫攻坚大队。由蔡克勤副区长任大队长，农林局钟向能任副大队长。大队长全权负责组织统筹区范围内的扶贫力量，解决遇到的重大困难和问题，完成脱贫攻坚各项具体任务；副大队长负责具体实施各项任务，协调行政村和自然村各战斗队共同作战，检查指导区域内中队、小队工作，并负责提供后勤保障和抓好日常管理工作。脱贫攻坚大队的主要职责：一是宣传贯彻执行上级有关脱贫攻坚工作的方针、政策和措施。二是抓好贫困户建档立卡工作，做好抗贫监测、统计工作。三是拟定我区精准扶贫工作实施方案，组织实施我区精准扶贫工作。四是抓好扶贫项目的申报和实施，加强扶贫资金的管理，监督、检查扶贫资金使用情况。五是动员组织社会力量参与扶贫，协调做好帮扶工作。六是负责其他脱贫攻坚有关工作。在区农林局设立大队部，安排固定的1间办公室，挂三亚市海棠区脱贫攻坚大队的牌子，配备相应办公设备，并设有公章。从区机关抽调4名左右精干人员作大队部工作人员。大队配备2名专职信息员，负责扶贫开发信息系统各项信息数据的采集、录入、更新、维护工作，完善精准识别、精准管理、精准帮扶、精准退出等方面的资料，扎实做好建档立卡档案与扶贫信息系统数据的精准比对衔接，并负责信息报送。

3.在行政村（含南田居）设立脱贫攻坚中队。区包点行政村的区领导对所包行政村的扶贫工作负总责，作为第一责任人，每周至少有两天在行政村办公。中队长由包村（居）主要单位领导（包村的部委局办领导）担任，第一书记和村支书记副中队长。中队长负责行政村脱贫攻坚全面工作，统一管理、组织行政村范围内帮扶责任人、村支两委干部、村民小组长，统筹安排行政村扶贫资源和力量，承担全面责任。第一书记主要负责抓精准帮扶措施的制定和落实（如没有第一书记，则有村党支部书记负责）。村党支部书记主要负责精准识别、精准退出、动态管理和群众的思想政治工作。帮扶责任人承担落实贫困户的帮扶责任。脱贫攻坚中队的主要职责：一是宣传贯彻执行上级脱贫攻坚有关方针、政策和措施。二是负责行政村贫困户的精准识别、精准管理、精准帮扶、精准退出。三是负责协调解决好行政村贫困户“两不愁三保障”问题。四是负责全村贫困人口动态监测管理和扶贫开发与农村低保制度的衔接工作。五是协助上级有关单位做好定点帮扶工作。六是负责行政村脱贫攻坚各项信息数据的采集、录入、更新、维护工作。七是负责编制实施行政村脱贫攻坚规划和实施方案。在行政村设立中队部，安排固定的1间办公室，挂脱贫攻坚中队的牌子，配备相应办公设备，从帮扶单位和村两委分别抽调1人作中队部工作人员。每个中队配备1名专职信息员，负责信息工作。

4.在自然村（组）设立脱贫攻坚小队。根据自然村（组）的实际情况，可在包含多个小组的自然村设一个小队，包含多个自然村的小组设一个小队。由行政村指派一名两委干部任小队长，村民小组长任副小队长。小队长统一组织统筹村（组）范围内的所有扶贫力量，统筹村（组）所有贫困户帮扶工作，全面了解贫困户的详细情况，提出有针对性的帮扶措施，把各项扶贫政策落实到每一个贫困户、每一个贫困人口，承担全面责任。副小队长协助小队长工作，承担各项具体任务，做好群众思想工作。脱贫攻坚小队的主要职责：一是宣传贯彻执行上级脱贫攻坚有关方针、政策和措施。二是负责自然村贫困户的精准识别、精准管理、精准帮扶、精准退出。三是负责落实好贫困户“两不愁三保障”帮扶措施。四是做好扶贫手册的准确登记填写，及时反馈贫困户家庭有关动态信息。五是负责做好贫困户的沟通和宣传教育工作。

三、工作制度

5.建立战斗队工作清单制度。大队、中队、小队要把脱贫攻坚的常规工作、整改工作等进行统筹安排，根据工作目标、任务、要求、时限等，制定年、季度、月、周、日工作常规工作清单，使全体战斗队员知道整个队伍和自己每天、每周、每月、每季度、每年必须干什么、怎么干。对国家考核反馈问题、复查问题、排查问题建立问题清单和整改时间表，完成一项销号一项。

6.实行战斗队工作例会制度。大队、中队实行每周工作例会制度，由大队长、中队长召集，主要听取汇报本周工作情况及存在问题的汇报，收集社情民意，研究布置下一步的工作，研究解决存在的问题和困难。例会要做好会议记录。小队每周召开一次碰头会。

7.实行常态化的信息采集、核对、录入、更新管理制度。根据农户有关信息的动态变化情况，随时采取核对录入更新；每月进行一次定期信息动态汇总更新。要借鉴贵州、江西等地做法，推行贫困户信息二维码标识。不能推行二维码标识的，也要丰富更新所有贫困户门牌有关信息。各中队、小队要及时把动态信息反馈到大队，由大队汇总后反馈到市扶贫办，使信息保持一致。

四、管理要求

8.实行标准化规范化管理。脱贫攻坚战斗队要做到有组织机构、工作人员、办公场所、工作经费、规章制度，大队和中队统一配备一台电脑、一部打印机、一个文件柜、一部固定电话、一个信息公示栏。工作经费由区统一安排，办公场所由区村安排。脱贫攻坚大队长必须每周至少有2天时间到大队部办公，中队长全日制在行政村办公。驻村干部必须与贫困户同吃、同住、同劳动、同学习，按时交伙食费。大队、中队、小队必须制定工作制度、工作流程，大队工作程序和流程由市里统一制定，中队、小队工作制度和流程由大队制定。

9.利用信息化手段加强组织管理。拓展脱贫致富电视夜校“钉钉群”的功能，把副大队长、中队长全部纳入“钉钉群”，由区委组织部统一管理。副大队长、中队长要每天通过“钉钉群”上传当天所做的工作、成效、存在问题及工作建议等。副大队长、中队长利用“钉钉群”进行指挥、跟踪、监督，成员之间也可以利用微信群交流讨论工作，取长补短。确保人在岗、心在位、事在办。

10.建立奖惩机制。大队、中队、小队，每月对区域范围内的队员进行一次量化评比，评比的具体办法由区农林局制定。对工作成效突出、群众满意度高的单位和个人，列入红榜通报表扬，并给予适当的资金奖励。对工作落后、群众满意度低的列入黑榜通报批评。对工作不力，精准识别、精准帮扶、精准退出等方面问题较多的中队、小队，由大队长蔡克勤约谈各级队长。各级队长在日常工作中，要即时帮助工作落后、问题解决不力的队员及时整改。对责任心不强、工作不到位的个人和帮扶单位，各级队长要及时把情况反馈给区农林局，由区农林局在核实情况后报大队长进行约谈，对问题严重的，要按程序进行严肃问责。村党支部要发挥好战斗堡垒作用，驻村第一书记、帮扶责任人要当好脱贫攻坚先锋队。村级组织、包村单位和战斗队成员要充分认识脱贫攻坚工作的极端重要性和形势的严峻性，进一步提高政治站位，把全部精力投入脱贫攻坚战主战场，卧薪尝胆、背水一战，坚决打赢脱贫攻坚这场输不起的战争。
