# 三亚市海棠区人民政府关于赤田水库饮用水水源保护区治理管理工作2017年第四季度进展情况的通报

三亚市海棠区人民政府

关于赤田水库饮用水水源保护区治理管理工作2017年第四季度进展情况的通报

各相关单位：

根据《三亚市海棠区人民政府关于印发三亚市海棠区饮用水水源保护区治理管理工作方案的通知》（海棠府〔2016〕334号）要求，区环境保护局组织区海水、城管、农林、项目推进中心等职能部门于2017年12月27日对赤田水库开展了实地督查工作，现将治理管理工作进展情况和督查情况通报如下：

一、治理管理工作进展情况

（一）加强农业面源污染治理。一是在赤田水库管理处和南田居高也队安置区设立了两幅农业面源污染防治宣传栏，并安排专人对赤田水库饮用水源地保护区农业面源污染整治进行宣传，张贴和下发《农业面源污染防治技术》《土壤修复技术》《秸秆综合利用技术》等资料。二是开展农资包装废弃物回收整治工作。按照《海棠区2017年农资废弃物统一回收集中无害化处置实施方案》，委托三亚海棠湾罗美昌再生资源回收站负责对饮用水水源保护区内芒果地、槟榔地约350亩的经济林，每半月进行一次农资包装废弃物统一回收工作。第四季度对赤田水库饮用水源地保护区的经济林开展了8次统一回收工作，共收集农资废弃物约6吨。

（二）加强居民生活污水治理。对二级保护区集中居住的继光队和高也队建设生态集中型人工湿地，将生活污水生态处理，达标排放。目前，已完成继光队项目施工图设计，并报市水务局审核通过，经基本建设程序报财政预算评审后总投资189万元，现已进场协调征地和管道铺设相关工作；高也队居民生活污水治理项目已列入我区第一批6个自然村农村生活污水治理工作。

（三）逐步推进居民点退出一级保护区工作。制定《关于印发赤田水库一级保护区房屋等饮用水水源安全隐患拆迁工作方案的通知》（海棠府办[2017]45号），并认真开展相关工作，目前，已完成133块地块的丈量，合计668.2亩，涉及的房屋为3700.03平方米，正按程序进行办理。

（四）建立巡查制度打击违建。建立巡查机制，加大对赤田水库区内违建的巡查力度，与赤田水库管理处紧密配合，对违建行为严厉打击，发现一起，依法查处一起。第四季度经排查发现新增违法建筑地基一处，执法人员立即下发责令改正违法行为通知书，责令当事人自行整改。

（五）建立长效机制确保环境卫生整洁。一是加强库区陆域垃圾清理。赤田水库边区设有可供村（居）民使用的生活垃圾收集点，有保洁公司每日清运垃圾，本季度共清运垃圾约270吨，减少生活垃圾对饮用水水源地的污染。二是定期清理隔离网。水政监察人员定期清理隔离网上各类植物和周边的生活垃圾，确保库区环境卫生整洁。

二、督察情况

从总体情况看，饮用水水源保护区治理管理工作进展顺利，但仍存在工作落实不力，推进缓慢的情况。

（一）区农林局：二级保护区内居民饲养生猪和放养家禽情况未得到有效解决，仍存在生猪粪便直排的行为，禁养措施落实不力。

（二）区海水局：在继光队和高也队居民集中居住地现场未发现建设单位进驻，人工湿地建设进展缓慢。

（三）区城管局：继光队和高也队集中居住地垃圾收集点简陋，未建设规范的垃圾收集设施。

（四）区项目推进服务中心：退出一级保护区的征地、补偿、拆迁等工作未有实质性的进展。

三、工作要求

（一）各责任单位要高度重视饮用水水源保护区的治理管理工作，对存在问题抓紧进行整改，不能走过场，工作切实落到实处。

（二）各责任单位要相互配合，形成合力，采取最有力的措施，确保完成治理管理工作。

（三）各责任单位要认真做好信息统计和阶段性总结的报送工作，确保信息报送及时、准确。
