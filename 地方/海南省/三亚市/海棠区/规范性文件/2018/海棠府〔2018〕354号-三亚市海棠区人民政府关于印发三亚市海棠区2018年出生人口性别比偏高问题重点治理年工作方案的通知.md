# 三亚市海棠区人民政府关于印发三亚市海棠区2018年出生人口性别比偏高问题重点治理年工作方案的通知

三亚市海棠区人民政府

关于印发三亚市海棠区2018年出生人口性别比偏高问题重点治理年工作方案的通知

各有关单位：

《三亚市海棠区2018年出生人口性别比偏高问题重点治理年工作方案》已经区政府同意，现印发给你们，请认真贯彻执行。

三亚市海棠区人民政府

2018年10月18日

（此件主动公开）

三亚市海棠区2018年出生人口性别比偏高问题重点治理年工作方案

为进一步做好我区2018年综合治理出生人口性别比偏高工作，根据《三亚市2018年出生人口性别比偏高问题重点治理年工作方案》（三人口领导小组办〔2018〕4号）的通知精神，结合我区实际，特制定本工作方案。

ー、工作目标

坚持落实“高层倡导、政府主导、卫生计生牵头、部门联动、联合执法、责任约谈、重奖重罚、综合治理、考核评估”的工作机制，提倡实行“责任捆绑，同奖同罚”责任机制，充分调动相关职能部门工作积极性。对工作相对落后的重点地区和单位要开展重点约谈，进一步推动相关机制和制度落实。要采取明查暗访，积极开展依法打击“非医学需要的胎儿性别鉴定和选择性别的人工终止妊娠行为”（下称“两非”）及采血鉴定胎儿性别活动，查处一批案件，打击违法行为，始终保持打击“两非”的高压态势。通过重点治理活动，进一步强化对孕妇的跟踪管理服务，强化对B超机、人工终止妊娠手术和终止妊娠药物的各个环节规范管理，促进全区出生人口性别比稳步逐年下降，完成省下达的年度工作目标。

二、工作内容

（一）加强目标管理，开展重点约谈。继续加大综合治理出

生人口性别比偏高问题工作力度，对主要职能单位提倡实行“责任捆绑、同奖同罚”制度：对重点地区和单位开展重点约谈强化预警预报和过程管理。

（二）增强宣传倡导，提升教育效果。深入开展“关爱女孩

行动”；集中开展法律法规、医德医风和预防“两非”教育活动，形成良好社会风气，促进社会性别平等。

（三）提高孕情服务管理水平。加强乡村计划生育管理服务

队伍建设，提高基层工作人员的工作能力。规范使用《孕情全程

管理和服务情况表》，提高孕情掌握率。加强对重点地区、重点

人群、重点环节的管理，摸清服务底数，规范服务流程，细化服

务内容，防止孕情不明原因消失。对孕情不明原因消失的，要及时查处，追根溯源，严厉打击“两非”违法行为。

（四）完善医疗保健、人口计生服务机构、药品批发零售企业的日常管理制度。组织对当地各类医疗保健机构、人口计生服

务机构、药品批发和零售企业进行全面清查，对管理中存在问题

的限期整改，尤其要督促其进一步完善B超使用管理制度、终止

妊娠药物销售和使用管理制度、终止妊娠手术审批制度，更加有

效地防止“两非”违法行为发生。创新监管办法与措施，注重重

点环节的监管。高度重视查处采血鉴定胎儿性别行为，从源头上

遏制“两非”违法行为发生。

（五）联合执法，严厉打击“两非”。实行卫生计生、公安、食品药品监督三部门打击“两非”责任捆绑，发挥三部门联合执法作用，进一步明确职能部门职责分工，落实工作责任。开展常态化专项联合执法检查，切实对辖区内的医疗机构、药品批零企事业单位定期或不定期进行常态化专项执法检查。加大暗访力度，要组织专门人员，定期或不定期对医疗机构、药品商店进行暗访，对获得有价值的“两非”线索及时上报有关部门查处。建立健全打击“两非”联动机制，由卫生计生行政部门牵头，联合快速查处“两非”案件，及时进行媒体曝光，保持打击“两非”的高压态势。

四、职责分工

市公安局海棠分局：负责组织本部门相关单位和人员参加整治“两非”专项行动；发挥职能优势，积极参与案件查处专案组联合查处“两非”案件，对线索明确的涉嫌“两非”行为的案件，会同相关部门联合取证，联合办案，为查处“两非”典型案例提供支持配合；依法严厉打击非法行医、溺弃女婴和“两非”等违法犯罪行为。

区卫计局：负责本次专项整治活动的组织、协调和监督工作；会同公安、食药监等部门联合查处“两非”案件，加强对各级医疗保健机构的管理，依法对发生“两非”行为的医疗保健机构及有关责任人进行严肃处理；设立有奖举报电话，实行举报核实有奖制度；协调建立综合治理出生人口性别比部门协调机制；加强对计生服务机构的孕情管理；督促各医疗机构启用“妊娠实时通”机制；向本级政府和上级主管部门报告工作进展情况；组织开展宣传活动，及时向社会发布相关信息。

市食品药品监督管理局海棠湾所：负责至本部门相关单位和人员参加整治“两非”专项行动；会同案件查处专案组联合查处“两非”案件；负责对药品批发和零售企业、个体经营户终止妊娠药物的销售管理情况开展专项检查和清理整治，严厉查处非法经营销售终止妊娠药物等行动；加强对终止妊娠药品销售、使用单位的监管，对终止妊娠药品和促排卵药品实行严格的处方管理，建立终止妊娠药品购销台账，确保药品使用规范；依据有关规定对违规违纪单位及有关责任人进行严厉处理。

卫生院（医院）：全面开展相关从业人员的发至教育和职业道德教育培训；严格落实14周以上孕妇B超检查实名制登记、双人开机、双人在场检查、双人签名的工作制度。对14周以上孕妇进行B超检查必须2名医务人员在场，实名制登记；严格执行终止妊娠药品专人专帐专柜管理制度，做好终止妊娠药品出入库、存放及使用的登记工作，严禁滥用药物、私下引产现象的发生；严格执行《三亚市基层医疗机构早期人工终止妊娠手术审批制度》，按规定查验相关证明才能开展人流、药流手术。

社会办医疗机构：制定本机构打击“两非”专项行动方案，机构法定代表人为第一责任人，每周对妇产科、B超科（室）的检查不低于2次;未取得《母婴保健技术服务执业许可证》的医疗单位，严禁开展上环、取环、人工终止妊娠手术等计划生育技术服务项目;本机构医务人员相关法律法规的学习，完善内部管理制度，层层签订责任书、承诺书，净化就医环境。

五、时间安排

2018年10月起，区打击“两非”专项行动领导小组将开展为期3个月的重点治理活动，并以宣传教育、孕情管理、打击“两非”、制度建设等为主题开展工作，促使出生人口性别比趋于正常。

六、工作要求

（一）强化组织领导。各单位务必高度重视综合治理出生人口性别比偏高问题工作，真正做到“一把手亲自抓、负总责”。要把目标管理责任制和“一票否决”用好用足，调动各方面积极性，切实组织好重点治理年的各项工作。

（二）注重工作实效。要紧紧围绕稳步降低出生人口性别比工作目标，结合本地实际，制定切实可行、目标明确的工作计划和实施方案，扎实工作，力争实现出生人口性别比工作任务下降达标。
