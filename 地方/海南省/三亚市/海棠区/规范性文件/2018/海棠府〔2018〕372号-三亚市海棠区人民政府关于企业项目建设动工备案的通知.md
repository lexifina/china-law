# 三亚市海棠区人民政府关于企业项目建设动工备案的通知

三亚市海棠区人民政府

关于企业项目建设动工备案的通知

区各相关单位、各企业：

根据省委省政府和国家自然督察广州局2018年土地例行督察，指出海棠区企业项目建设违法面积占比大，违法占地有超红线范围建设、临时用地未批先建、施工便道占用耕地等问题。为建设生态文明城市，服务海南岛自由贸易试验区和中国特色自由贸易港建设，加强土地资源保护，提高城市空间发展，和谐推进海棠区开发建设，同时降低违法占地成本，减少企业违法投入损失。自2018年11月1日起，海棠区内所有企业新建项目施工前，须在海棠区进行施工备案，施工备案办理流程通知如下：

一、备案范围

海棠区范围内所有新建项目。

二、提交材料

依法取得不动产权证书、建设用地坐标图、施工建设基本情况书面说明（含施工便道、临时工棚等用地使用情况）、根据施工用地情况需要提供的其他材料。

三、备案办理流程

土地使用建设主体持相关材料提交至海棠国土分局，并填报《海棠区项目施工前用地审核备案表》→海棠国土分局5个工作日内审核施工土地相关材料，审核土地办理手续、土地性质等相关信息是否符合建设，将审核情况填报《海棠区项目施工前用地审核备案表》，并作出意见→报区住建局备案→反馈申请备案主体单位。

四、项目施工前用地审核备案须知

（一）项目施工前用地审核备案目的，是为避免违法占用使用土地问题，给予正确的用地指导，保障项目建设临时用地的合法使用，减少违法投资成本，促进项目建设。

（二）土地必须经依法批准、合法使用，已取得用地手续的，严禁超红线范围建设；临时用地、施工便道选址，应避开占用农用地、耕地，严禁占用基本农田。

（三）各企业须按照通知要求开展施工前备案，对施工建设前未备案的企业，在土地动态巡查或国家土地矿产卫片执法检查过程中发现的违法行为，一律予以拆除整改，并约谈违法主体责任人。

特此通知。

附件：《海棠区项目施工前用地审核备案表》
