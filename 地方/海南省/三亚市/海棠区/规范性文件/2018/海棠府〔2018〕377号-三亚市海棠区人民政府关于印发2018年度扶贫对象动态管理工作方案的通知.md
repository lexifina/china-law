# 三亚市海棠区人民政府关于印发2018年度扶贫对象动态管理工作方案的通知

三亚市海棠区人民政府

关于印发海棠区2018年度扶贫对象动态管理工作方案的通知

各相关单位::

《海棠区2018年度扶贫对象动态管理工作方案》已经区政府同意，现印发给你们，请认真贯彻执行。

三亚市海棠区人民政府

2018年11月1日

（此件主动公开）

2018年度扶贫对象动态管理工作方案

为做好我区2018年度扶贫对象动态管理工作，根据市指挥部《关于印发三亚市2018年扶贫对象动态管理工作方案的通知》（三脱贫指办〔2018〕19号）文件要求，结合我区实际情况，制定本工作方案。

一、工作目标

坚持精准扶贫、精准脱贫，切实做到扶贫对象动态管理，确保应纳尽纳、应退则退、应扶尽扶，高质量完成2018年脱贫攻坚扶贫开发工作任务。

二、工作任务

（一）贫困人口动态管理

1.新增贫困人口

各村（居）委会、帮扶责任单位要将所有符合现行我省农村贫困标准，但仍“应纳未纳，应扶未扶，应保未保”和未实现“两不愁三保障”的贫困人口，经农户申请、村民民主评议、“两公示、一比对、一公告”等识别程序核查核实后，全部纳入建档立卡管理，做到“应纳尽纳、应扶尽扶，应保尽保”。严禁设定贫困人口识别纳入规模，切实做到不漏一人、不落一户。对新纳入人员要及时明确帮扶责任人，制定帮扶措施并落实到位。

2.贫困家庭成员的自然变更

为掌握脱贫户基本情况，区帮扶责任人需进村入户采集我区2017年脱贫户家庭成员的增加（新生、嫁入、迁入等）、自然减少（死亡、迁出等人口信息），并在三亚市开发系统内完成人员增加、减少人员操作。

（二）关于扶贫对象信息采集和录入

1.脱贫户的基础信息更新。

2.脱贫户的措施信息采集和录入三亚市开发系统。

三、进度安排

（一）组织部署阶段

根据今年“大排查”掌握的情况，重点关注农村低保特困户三保障未解决人员、2017年脱贫退出人员、农村户口未实现“两不愁三保障”和意见较大的边缘群众等重点人群。

（二）动态调整和信息采集

10月1日至11日为动态调整和信息采集开展时间。我区各帮扶责任人要按照时间节点有序完成以下工作：

1.10月17日至10月24日。南田居20户脱贫户的各帮扶责任人要组织开展进村入户动态调整，严格履行脱贫户返贫纳入程序，同时22个村（居）委会也要组织开展进村入户动态调整，对有提出申请纳入贫困户的农村户口人员随时受理，严格履行贫困户的识别和纳入等各项程序。

农户家庭收入计算周期为2017年10月1日至2018年9月30日。低保金、养老金计入脱贫收入。

2.10月25日至11月8日，各帮扶责任人完成我区南田居扶贫对象各类信息采集和更新，主要采集录入发生变化的信息。

脱贫户信息采集，使用《脱贫户情况调查表》，脱贫户家庭成员自然变更的信息采集，使用《贫困户家庭成员自然增加情况表》和《贫困户家庭成员自然减少情况表》，新识别贫困户信息采集，使用《新识别贫困户信息采集表》采集所有基础信息入户核实信息并采集本年度发生变化的基础信息。在校生状况指标今年在采集时，要对去年“在校生状况”进行核准和采集。

3.11月8日至10日，完成所采集扶贫对象各类信息的核验，及时查漏补缺，确保所采集信息准确无误。

（三）数据录入

11月10日前，各帮扶责任人在完成动态调整和信息采集工作和22个村（居）委会完成新增贫困人口的识别后，要将动态管理工作完成情况书面报送至区扶贫办。区扶贫办将汇总我区动态管理工作完成情况向市扶贫办报告并申请开放系统功能权限。

11月10日至28日，各帮扶责任人要及时组织人员开展数据录入三亚市系统。

11月28日至30日，完成录入数据核对，保证信息录入质量。

11月30日24时前，各帮扶责任人务必完成全部数据录入工作。

（四）开展工作总结

2019年1月1日至4日，我区帮扶责任人需对2018年度动态管理工作进行总结，形成报告并上报区扶贫办。

1月5日至7日，区扶贫办汇总各帮扶责任人上报的动态工作总结，形成我区2018年度动态管理工作总结上报市扶贫办。

（五）完善扶贫手册及做好档案材料归档工作

各帮扶责任人要及时完成扶贫手册的填写和脱贫户信息采集工作。

四、工作要求

（一）加强组织领导

各帮扶责任单位要切实把思想和行动统一到中央和省、市的决策部署上来，主要领导要亲自抓，分管领导具体抓落实工作任务。各村（居）委会要高度重视此次贫困人口动态调整工作，落实工作人员，建好信息员队伍。

（二）改进工作作风

各村（居）委会对扶贫对象动态调整要深入细致地开展工作，耐心做群众工作，解决群众反映任何问题。

（三）确保工作进度

2018年度扶贫对象动态管理工作从10月上旬开始，11月30日前完成信息数据录入工作。各村（居）委会要严格按照规定的贫困识别和退出程序，坚持公开、公平、透明的原则，识别程序要规范，不得走过场；要动员包括贫困户在内的广大农民群众积极参与贫困识别和退出工作。

(四) 确保工作质量

要确保扶贫对象动态管理和信息采集工作质量。区扶贫办、各帮扶责任单位要切实采取有力措施，对此次动态管理信息采集和录入的数据质量严格审核把关。增强数据录入人员责任意识，对录入时发现的疑似问题数据要能较真碰硬。
