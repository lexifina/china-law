# 三亚市海棠区人民政府关于印发《海棠区2018年行政审批及管理服务事项目录》的通知

三亚市海棠区人民政府

关于印发《海棠区2018年行政审批及管理服务事项目录》的通知

区各相关单位：

根据《三亚市人民政府关于印发三亚市行政审批事项目录管理办法的通知》（三府〔2016〕23号）要求，按照依法合理、从严管控、动态调整、便民公开的原则编制汇总《海棠区2018年行政审批及管理服务事项目录》，已经二届区政府第41期常务会议审议通过，现予以印发。

各职能部门要持续推进“放管服”改革，认真落实国务院深入推进审批服务便民化的有关要求，进一步优化内部审批服务流程，减少审查环节，缩短办理时间，提高办件效率。着力打造“宽进、快办、严管、便民、公开”的审批服务模式，不断优化办事创业和营商环境，切实增强政府公信力和执行力。
