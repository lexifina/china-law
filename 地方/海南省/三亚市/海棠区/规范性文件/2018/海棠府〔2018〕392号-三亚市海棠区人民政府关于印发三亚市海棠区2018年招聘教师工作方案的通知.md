# 三亚市海棠区人民政府关于印发三亚市海棠区2018年招聘教师工作方案的通知

三亚市海棠区人民政府

关于印发三亚市海棠区2018年招聘教师

工作方案的通知

各相关单位：

《三亚市海棠区2018年招聘教师工作方案》经区政府同意，现印发给你们，请认真遵照执行。

三亚市海棠区人民政府

2018年6月25日

（此件主动公开）

三亚市海棠区2018年招聘教师工作方案

为加快海棠区义务教育发展均衡进程，顺利通过2018年义务教育均衡省级评估及国家认定，根据中小学校教育教学工作需要，面向社会公开招聘非事业编制中小学教师，特制定本方案。

一、招聘原则

按照“公平、公正、公开”的原则招聘，坚持“严格把关、双向选择”。

二、领导机构

为做好招聘工作，成立海棠区教师招聘工作领导小组。

组 长：海 斌（海棠区委常委、常务副区长）

副组长：秦朝文（海棠区委副调研员）

陈小冬（海棠区教育科技局局长）

成 员: 林云春（海棠区财政局副局长）

李 伟（海棠区人力资源和社会保障局副局长）

黄运清（海棠区教育科技局党组成员）

刘少峙（海棠区人力资源和社会保障局科员）

吉文权（海棠区教育科技局工作人员）

领导小组下设办公室，办公室设在海棠区教育科技局，陈小冬同志兼任办公室主任，负责教师招聘具体工作。

三、招聘对象及岗位（66名）

（一）全省中学退休教师（6名）

中学语文2名、数学1名、物理1名、政治1名、历史1名,共6名（详见附件1）。

（二）中小学临聘教师（60名）

1.中学语文3名、数学1名、英语2名、音乐1名、化学2名、物理2名、历史3名、政治1名，共15名（详见附件1）。

2.小学语文6名、数学9名、英语6名、体育9名、美术9名、音乐5名，信息技术1人，共45名（详见附件1）。

四、招聘条件

（一）中学退休教师

1.思想政治素质好，爱岗敬业，师德高尚，事业心和责任感强，教育教学能力强，能运用先进的课改理念，在教育教学中起示范、引领作用，具有本省户籍的退休教师。

2.身心健康，无重大疾病，能承担一定的教学任务。男应聘者年龄在63周岁以下（1955年8月31日之后出生）；女应聘者年龄在58周岁以下（1960年8月31日之后出生）。

3.应具备专科以上（含专科）学历，初级中学教师资格及以上，副高级以上（含副高级）职称。

4.市县级以上骨干教师、学科带头人，在当地和本学科教学有一定影响的优先聘任。

（二）中小学临聘教师

1.具有中华人民共和国国籍。

2.政治思想品德端正，无违法违纪记录。

3.热爱教育事业，为人师表，具有良好身体素质和心理素质，口齿清楚。

4.能吃苦耐劳，爱岗敬业，遵守教师职业道德，服从组织工作分配。

5.具有正常履行职责的身体条件;

6.学历及专业条件：报考中学临聘教师职位的，须具备报考职位相应专业本科及以上学历;报考小学临聘教师职位的，须具备报考职位相应专业大专及以上学历。

7.教师资格：报考中学临聘教师职位的，须具有初中及以上等级的教师资格证书，报考小学临聘教师职位的，须具有小学及以上等级的教师资格证书。

8.普通话要求：报考语文学科普通话等级必须具有二级甲等及以上证书;报考其他学科普通话等级必须具有二级乙等及以上证书。

9.年龄限35周岁(含35岁)以下的人员(即1983年8月31日后出生)。

（三）有下列情形之一的不受理应聘

1.受过刑事处罚、劳动教养、少年管教的。

2.曾受过记过以上处分，或受警告处分尚未解除的。

3.曾被辞退或开除公职的。

4.道德败坏，因不良行为受过公安机关处理的。

5.其它原因不适合从事教师岗位工作的。

五、工资待遇

（一）中学退休教师

1.工资5500元/月，住宿、交通补贴1000元/月。

2.购买聘期内意外保险。

3.实行两年一聘，与本校教职工享受同样节假日。

（二）中小学临聘教师

1.中学教师工资3900元/月，工资标准包含个人承担的“五险一金”，单位按规定比例缴交各项社会保险、住房公积金等。

2.小学教师工资3700元/月，工资标准包含个人承担的“五险一金”，单位按规定比例缴交各项社会保险、住房公积金等。

六、工作要求

（一）教师招聘工作由区教科局组织实施，统筹处理减少或取消岗位、公布笔试和面试成绩等招聘工作。

（二）区人社局负责对招聘工作进行指导、监督和管理，保证招聘工作的实效。

（三）对违反公开招聘纪律的工作人员，视情节轻重进行批评教育、调离招聘工作岗位或给予处分；对违反公开招聘纪律的其他相关人员，按照有关规定追究责任。

（四）招聘过程中如出现某学科招聘岗位无人员报考或报考人数不足，可将该学科招聘岗位调整到其他学科。

（五）区财政局负责保障招聘工作及聘用教师经费。
