# 三亚市海棠区人民政府关于印发2017年脱贫攻坚“送温暖”活动方案的通知

三亚市海棠区人民政府

关于印发海棠区2017年脱贫攻坚“送温暖”

活动方案的通知

各相关单位：

《海棠区2017年脱贫攻坚“送温暖”活动方案》已经区政府同意，现予以印发，请认真贯彻执行。

特此通知。

三亚市海棠区人民政府

2018年1月9日

（此件主动公开)

海棠区2017年脱贫攻坚“送温暖”活动方案

为夯实精准扶贫工作成效，进一步密切党群干群关系，值2018年春节即将来临之际，根据《三亚市扶贫开发领导小组关于开展2017年脱贫攻坚“送温暖”活动的通知（三扶发〔2017〕15号）》精神，我区决定开展扶贫“送温暖”活动，并制定工作方案如下。

一、指导思想

以习近平总书记十九大报告和脱贫攻坚系列讲话精神为统领，深入贯彻落实党中央、国务院和省市关于坚决打赢脱贫攻坚战的决策部署，以高度的政治责任感，精心组织开展“送温暖”活动，着力解决好贫困人口的实际困难，把以习近平同志为核心的党中央的关怀和温暖送到贫困群众的心坎上，以解民忧、暖民心的实际行动践行到精准扶贫工作中，提高群众满意度，夯实我区脱贫成效。

二、活动时间

活动时间为2017年12月29日至2018年2月14 日。

三、活动对象

南田居建档立卡的贫困人口。

四、资金预算

（一）按照每户500-700元/户的标准（可根据家庭人口情况适当调整），市级下拨2万元用于购置米、油、御寒衣被等相关慰问品。

（二）各职能部门、各定点帮扶单位相关工作经费由各部门自行安排。

（三）各帮扶单位可充分发动社会爱心企业，募集资金开展“送温暖”活动。

五、活动内容

（一）送帮扶。入户深入摸底了解南田居建档立卡的贫困人口的生活状况，为群众解决生产、生活中的困难等，让他们切实感受到党和政府的关心。如为家庭条件困难、缺少御寒衣被的贫困户发放衣被等御寒物品，确保贫困户能够顺利的度过寒冬；开展“两节”慰问活动，送米、油等慰问品。入户时，结合“两讲”、“两教育”，宣传党的扶贫政策，增强群众对党和政府工作的信心，激发“我要脱贫”、“我要致富”的内生动力，为全面致富奔小康吃下一颗定心丸。不断提高满意度，为制定2018年扶贫工作计划奠定基础。（牵头单位：区农林局）

（二）送健康。针对“送温暖”对象开展送义诊、送医、送药活动，普及健康知识，大力宣传疾病预防控制知识，提高贫困群众的知晓度。（牵头单位：区卫计局）

（三）送就业。举办“就业扶贫”专场招聘会，为有工作能力的贫困人口提供就业机会，并配套就业技能培训，并推荐贫困人口到景区、商业贸易、旅游酒店等行业就业。（牵头单位：区人力资源社会保障局）

（四）送文化。以文艺演出、公益电影放映、送图书、送体育器材等形式，丰富群众业余文化生活。组织各家媒体深入贫困户，收集整理群众身边的励志故事、脱贫致富典型、树立榜样，传播正能量，引导群众克服“等、靠、要”的消极思想，增强靠自身努力，加上政府帮扶就能够脱贫致富奔小康的信心和决心。（牵头单位：区委宣传部）

（五）送教育。解决好建档立卡贫困子女、生活较困难家庭孩子上学的现实问题，为贫困家庭的子女送书籍、送资料，在学习和技能提升上给予帮助。（牵头单位：区教科局）

（六）送技术。组织科技人员入村入户，开展技术指导，及时解决困难群众在冬季生产中遇到的问题。举办实用的种养殖培训，提高生产技术水平。（牵头单位：区农林局）

（七）其他。各单位可发挥自身优势，积极创新，开展其他各种形式新颖、带动性强、影响范围广的送温暖活动。

六、工作要求

（一）强化指导，狠抓落实。区农林局要统筹安排好此次“送温暖”活动，及时为各相关单位提供贫困户名单等必要的基本信息，确保各单位及时、顺利开展“送温暖”活动。

（二）因户制宜，优化措施。各单位要入户深入摸底了解建档立卡的贫困人口及家庭较困难的农户的生活状况，根据实际情况调整“送温暖”活动措施，为群众解决生产、生活中的困难，让他们切实感受到党和政府的关心。

各职能单位要根据分工和职责，制定本部门的“送温暖”活动方案，进一步做实做细“送温暖”。

（三）专人负责，信息互通。各单位要指定专人负责“送温暖”活动的落实，并指定专人联系，建立顺畅的沟通关系，确保“温暖”送得及时、送得到位、送得入心、送得满意。

（四）严肃纪律，提高满意度。在开展“送温暖”活动中，各单位、各位领导干部、工作人员要严格遵守相关规定，提升群众满意度。
