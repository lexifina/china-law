# 三亚市海棠区人民政府关于赤田水库饮用水水源保护区治理管理工作2018年第一季度进展情况的通报

三亚市海棠区人民政府

关于赤田水库饮用水水源保护区治理管理工作2018年第一季度进展情况的通报

各相关单位：

根据《三亚市海棠区人民政府关于印发三亚市海棠区饮用水水源保护区治理管理工作方案的通知》（海棠府〔2016〕334号）要求，区环境保护局组织区海水、城管、农林、项目推进中心等职能部门于2018年3月28日对赤田水库开展了实地督查工作，现将治理管理工作进展情况和督查情况通报如下：

一、治理工作开展情况

（一）加强农业面源污染治理。在赤田水库管理处和南田居高也队安置区设立了两幅农业面源污染防治宣传栏，并安排专人对赤田水库饮用水源地保护区农业面源污染整治进行宣传，张贴和下发《致农民朋友的一封信》、《海南经济特区禁止生产运输存储销售使用的农药品种名录》等资料。

（二）加强居民生活污水治理。对二级保护区集中居住的继光队、老丰收队和高也队建设生态集中型人工湿地，将生活污水生态处理，达标排放。

1.启动南田农场老丰收队和高也队居民生活污水治理

该项目已纳入全市农村污水治理第一批实施计划，由市水务局作为项目业主，区政府配合推进，预计2018年上旬开工建设。

2.加快推进南田农场继光队居民生活污水治理项目

该项目已于去年底动工，村内主导管网敷设已基本完成，因项目涉及占地部分未能及时有效解决，导致项目无法如期推进，现在抓紧协调难念农场方解决项目占地问题。待项目占地问题解决后，抓紧时间推进项目建设并投入使用。

（三）逐步推进居民点退出一级保护区工作。制定《关于印发赤田水库一级保护区房屋等饮用水水源安全隐患拆迁工作方案的通知》（海棠府办〔2017〕45号），并认真开展相关工作，目前，已完成133块地块的丈量，合计668.2亩，涉及的房屋为3700.03平方米，正按程序进行办理。

（四）建立巡查制度依法打击各类违法行为。建立巡查机制，加大对赤田水库区内各类违法行为的巡查力度，与赤田水库管理处紧密配合，对违法行为严厉打击，发现一起，依法查处一起。

本季度开展水源保护巡查共234次，出动巡逻艇156艘次，巡查人员932人次，发现影响水源安全行为21宗，二级保护区违法建房行为4宗（属保亭地界，均已报保亭县三道国土环境资源管理中心所）。

2018年1月25日，我区执法队员巡查至南田农场东风分厂西村队水源一级保护区内，发现村民私自搭建一处铁皮棚，现场立即控制停工，并下发相关法律文书，于2018年1月26日依法依规对其强制拆除，拆除面积121平方米。

2018年3月初，接举报，南田农场在赤田水库二级保护区内喷洒橡胶化学药品。我区立即组织人员进行查处，南田农场为管理橡胶树喷洒硫磺粉。执法人员按《海南省饮用水水源保护条例》相关条款依法责令南田农场改正违法行为。

（五）建立长效机制确保环境卫生整洁。一是加强库区陆域垃圾清理。在南田居水源水源保护区内共设置垃圾投放点5个，带盖垃圾桶20个，外包环卫公司配备1辆垃圾压缩车，并投入15人负责南田居饮用水源保护区内环境卫生清扫保洁工作，其中管理人员1个，保洁人员14人。每日清运垃圾，本季度共清运垃圾约270吨，减少生活垃圾对饮用水水源地的污染。二是加强库区水域垃圾清理。运用船只、浮台水上收集托运上岸装车进行清运水浮莲，目前清理库区水浮莲及垃圾73车次共430多吨。三是定期清理隔离网。水政监察人员定期清理隔离网上各类植物和周边的生活垃圾，确保库区环境卫生整洁。

二、督察情况

从总体情况看，饮用水水源保护区治理管理工作进展顺利，但仍存在工作落实不力，推进缓慢的情况。

（一）区农林局：二级保护区内居民饲养生猪和放养家禽情况未得到有效解决，仍存在生猪粪便直排的行为，禁养措施落实不力。

（二）区海水局：在继光队居民集中居住地现场未发现建设单位进驻，人工湿地建设进展缓慢。

（三）区城管局：继光队和高也队集中居住地垃圾收集点简陋，未建设规范的垃圾收集设施。

（四）区项目推进中心：退出一级保护区的征地、补偿、拆迁等工作未有实质性的进展。

三、工作要求

（一）各责任单位要高度重视饮用水水源保护区的治理管理工作，对存在问题抓紧进行整改，不能走过场，工作切实落到实处。

（二）各责任单位要相互配合，形成合力，采取最有力的措施，确保完成治理管理工作。

（三）各责任单位要认真做好信息统计和阶段性总结的报送工作，确保信息报送及时、准确。
