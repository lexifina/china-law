# 三亚市海棠区人民政府关于印发三亚市海棠区2018年财政专项扶贫资金安排方案的通知

三亚市海棠区人民政府

关于印发三亚市海棠区2018年财政专项

扶贫资金安排方案的通知

各有关单位：

《三亚市海棠区2018年财政专项扶贫资金安排方案》已经区政府同意，现予以印发，请认真贯彻执行。

特此通知。

三亚市海棠区人民政府

2018年4月9日

（此件主动公开）

三亚市海棠区2018年财政专项扶贫资金安排方案

为贯彻落实党的十九大精神和全国经济工作会议、全国农村工作会议、省农村工作会议精神、市扶贫开发领导小组要求，统筹推进我区2018年脱贫攻坚工作，根据区脱贫攻坚领导小组指示，现将我区2018年财政扶贫资金安排如下：

一、资金来源

三亚市人民政府印发《三亚市2018年财政专项扶贫资金安排方案》（三府办〔2018〕33号）、市财政局《关于下达2018年财政专项扶贫资金的通知》（三财农〔2018〕11号）文件下达我区2018年第一批省级财政专项扶贫资金（发展资金）20万元（农垦资金）；市财政局安排2018年度市级财政专项扶贫资金16.46万元；不足部分由区政府或帮扶企业出资。

二、使用范围

依据“精准、规范、安全、有效”的原则，财政专项扶贫资金使用向扎实推进精准施策、聚焦脱贫攻坚、开展扶贫领域腐败和作风问题专项治理、扶贫与扶志扶智相结合、强化驻村帮扶、完善大扶贫格局、做好宣传培训等7项重点工作倾斜。

三、资金安排及建设内容

省级资金20万元，市级资金16.46万元，区政府视情调整或协调企业安排资金，具体安排如下。

（一）光伏扶贫安排23.9万元。根据《三亚市2017年脱贫攻坚工作方案》（三发办〔2017〕11号）要求，在全市推行光伏特色产业扶贫，特将省级财政专项扶贫资金（发展资金）20万元，市级产业扶贫资金3.9万元，不足部分由区政府或帮扶企业出资,用于南田居黎亚光、杨海文、蒲亚娘、罗大海、符开清、黄月民、王国恩、罗亚珍、林子敬、林金玉10户巩固提升户建设光伏发电站。

（二）产业发展类投入5.06万元。主要用于根据地域特色发展效益高、惠及贫困户的特色产业扶持项目，我区拟采取先种后补、先养后补的方式鼓励南田居脱贫户发展种养产业，提高巩固提升户的“造血”功能。产业扶贫资金原则上按每人1600元标准投入，可根据实际情况作适当调整（部分无产业巩固提升户的产业扶贫资金向有产业、产业量大的巩固提升户倾斜）。

（三）扶贫培训类投入7万元。主要用于开展扶贫方面的种养殖类技术培训、工作培训等扶贫类培训，印刷培训教材，租赁培训场地等。

（四）工作开展经费0.5万元。主要用于入户调查、扶贫项目的监督管理、规划编制、项目评估、检查验收、档案管理、项目公告公示、培训考察、报账管理、会议经费、资料印刷费。

四、资金的管理使用

区财政、审计、纪检部门加强资金管理监督，资金使用部门须严格按照《海南省人民政府办公厅关于印发海南省财政专项扶贫资金管理暂行办法的通知》（琼府办〔2016〕324号）、《海南省人民政府办公厅关于印发海南省扶贫项目管理暂行办法的通知》（琼府办〔2015〕165号）、《海南省扶贫物资政府采购实施暂行办法》（琼府办〔2016〕182号）和市、区有关扶贫资金管理办法等有关规定执行。
