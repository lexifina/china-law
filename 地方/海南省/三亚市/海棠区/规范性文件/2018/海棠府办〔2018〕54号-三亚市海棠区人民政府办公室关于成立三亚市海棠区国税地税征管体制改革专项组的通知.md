# 三亚市海棠区人民政府办公室关于成立三亚市海棠区国税地税征管体制改革专项组的通知

三亚市海棠区人民政府办公室

关于成立三亚市海棠区国税地税征管体制改革专项组的通知

区各有关单位：

为加强我区国税地税征管体制改革的组织协调工作，确保我区国地税征管体制改革任务顺利落实，成立三亚市海棠区国税地税征管体制改革专项组，办公室设立在区财政局，由区财政局局长担任办公室主任，日常工作人员从三亚市国家税务局第二分局、区地方税务局局和区财政局中抽调。三亚市海棠区国税地税征管体制改革专项组主要负责研究贯彻落实中央关于国税地税征管体制改革工作中存在的问题，指导、推动国税地税征管体制改革各项工作，组成人员如下：

组 长： 孙 耿 区委副书记、区长

副组长：海 斌 区委常委、常务副区长
