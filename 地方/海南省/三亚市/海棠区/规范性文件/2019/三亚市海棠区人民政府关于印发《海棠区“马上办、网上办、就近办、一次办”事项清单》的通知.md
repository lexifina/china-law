# 三亚市海棠区人民政府关于印发《海棠区“马上办、网上办、就近办、一次办”事项清单》的通知

三亚市海棠区人民政府

关于印发《海棠区“马上办、网上办、就近办、一次办”事项清单》的通知

区各相关单位：

为进一步深化“互联网+政务服务”，推进我区政务服务“一网、一门、一次”改革工作，根据《三亚市行政审批制度改革工作领导小组办公室关于修改完善“马上办、网上办、就近办、一次办”事项清单的通知》（三审改办〔2019〕6号）要求，按照依法合理、从严管控、动态调整、便民公开的原则编制汇总《海棠区“马上办、网上办、就近办、一次办”事项清单》（以下简称“四办”清单）,已经二届区政府第45期常务会议审议通过，现予以印发。

为扎实推动“放管服”改革，进一步提高政府服务效率和透明度，方便企业和群众办事创业。各职能单位要强化责任，严格落实“四办”清单要求，着力提升办事的质量和精准度，坚持服务便民利民，更好满足企业和群众需求；加强“四办”清单管理要求，“四办”清单实行动态管理，根据法律、法规的颁布、修订、废止以及机构和职能变化等情况，需调整完善的报至区政务服务中心予以调整。
