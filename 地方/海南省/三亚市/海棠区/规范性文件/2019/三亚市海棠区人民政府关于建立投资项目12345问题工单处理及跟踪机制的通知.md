# 三亚市海棠区人民政府关于建立投资项目12345问题工单处理及跟踪机制的通知

三亚市海棠区人民政府

关于建立投资项目12345问题工单

处理及跟踪机制的通知

区直属各单位、驻区各单位、各投资项目业主：

为切实改善营商环境，有效提升政府投资项目服务效能，更好地解决企业最关心、最直接、最现实的利益问题，现参照“12345”市政府服务热线管理办法，制定海棠区投资项目“12345”问题工单处理及跟踪机制如下：

一、工作目标

以提高投资项目服务保障水平和畅通企业诉求渠道为目标，按照“整合资源、减少层级、快速处置”的思路，通过“政府搭台、部门联动、各级参与”的方式，开通海棠区投资项目12345问题工单处理及跟踪热线，具体实现“一号对外、统一受理、多级联动、统一监管”，着力打造优质高效的综合性投资项目服务平台，广泛受理企业诉求，做到及时交办、及时调查、及时处理、及时回复，确保事事有回音、件件有落实。

二、工作任务

（一）区发展和改革委员会项目投资服务中心设置“海棠区投资项目服务热线办公室”（以下简称“投资热线办”），并开通项目投资服务热线，通过热线电话（08983-8888033）、传真（0898-38888035）及电子邮箱（httz12345@126.com）收集投资项目企业诉求，并根据各单位职能分派工单；

（二）各相关单位对项目投资服务中心的派单要在12小时内接收，并在办理时限内完成调查、核实、处理、回复等工作，同时将调查情况和办理结果书面报送投资热线办。对不属于本单位职责范围的工单，应在1个工作日内退回，并注明退回理由、依据、建议、回退人及联系方式；

（三）办理时限要求，咨询类诉求在2个工作日内、求助或建议类诉求在5个工作日内回复，涉及工程建设及征地拆迁事项，根据诉求处理工作量并在征求分管区领导意见后，呈报区主要领导确认后实施；

（四）对涉及多个部门的事项，一是由投资热线办对诉求进行拆解，在明确责任单位后派送工单；二是指定牵头单位和相关责任单位后派送工单解决；

（五）针对企业反映但不能解决的突出问题（未办理延期手续，经投资热线办提醒后，超办理时限2个工作日以上的问题），投资热线办需整理资料，专题呈报区人民政府研究解决；

（六）热线中影响面广、解决难度大的事项，确因办理时限不足的，经部门分管区领导（海棠湾开发公司向市现代服务业产业园管委会）签字同意，可以向投资热线办申请延期；

（七）未按照规定时限办结的事项，投资热线办通过电话、传真、微信等形式进行催办；针对领导批示件及重大紧急问题，实行重点催办；对催办后仍超期2个工作日仍未处理的，将相关资料报送区委办、区政府办督办落实，情节严重的交由区纪委处理；

（八）归档工作由区投资热线办负责。

三、工作要求

（一）加强领导。成立以区长为组长，常务副区长为副组长，相关单位主要负责人为成员的区人民政府投资项目服务热线工作领导小组，建立区人民政府周调度会议，定期召开调度会、联席会议和专题会议，及时研究和解决工作中遇到的困难和问题，保质保量完成投资服务热线各项工作。各相关单位要高度重视、真抓实干、齐抓共管、形成合力，自觉把思想和行动统一到区委、区人民政府的决策部署上来，切实加强领导、明确责任、强化措施，按要求抓好相关工作落实；

（二）宣传发动。相关单位要根据热线工作推进情况，有计划、有步骤地制定宣传方案，充分发挥新闻媒体的作用，多渠道、多层次宣传投资服务热线，努力营造良好的宣传氛围，使热线家喻户晓、人人皆知；

（三）强化督查。投资热线办要采取日常检查、定期督查、重点抽查、工作完成周报、月报等方式，对各相关单位工作情况进行督促检查。对不按工作要求和完成时限开展工作的责任单位，将严格考核，并在全区范围内通报。
