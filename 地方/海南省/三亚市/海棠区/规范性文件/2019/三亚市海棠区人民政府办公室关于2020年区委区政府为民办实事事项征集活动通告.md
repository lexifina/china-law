# 三亚市海棠区人民政府办公室关于2020年区委区政府为民办实事事项征集活动通告

三亚市海棠区人民政府办公室

关于2020年区委区政府为民办实事事项征集活动通告

为坚持在发展中保障和改善民生，解决人民群众最急需、最昐望、反映最强烈的民生问题，不断提高人民群众的生活质量，落实幸福民生行动计划，不断满足人民日益增长的美好生活需要，让民生改革成果惠及海棠区人民。2020年区委、区政府将继续实施为民办实事工程。为进一步提高社会各界参与度，更广泛地吸收群众意见，使民生工作更加符合人民群众的愿望和要求，使区委、区政府为民办实事决策更加民主化、科学化，特向全社会公开征集2020年为民办实事事项的建议和意见现将征集有关事项通告如下：

一、征集时间

2019年11月25日至2019年11月29日

二、征集内容

符合三亚海棠区实际，是群众关心和急需解决的问题，覆盖面和受益面比较广，包括但不限于脱贫攻坚、教育、医疗、社会保障、居民就业、住房保障、菜篮子建设、交通出行、文化体育建设和乡村振兴等方面，原则可以在一年内完成的项目。

三、征集方式

请登录三亚市人民政府门户网站(网址htp:/www.sanya. gov.cn)，点击三亚市海棠区政府浏览通告，将您最急需、最昐望的民生事项或建议发送至邮箱：htqysgk@163.com。

真诚期待广大群众积极建言献策，我们将认真研究吸收您的意见和建议，让为民办实事工程更好地惠及千家万户。

三亚市海棠区人民政府办公室

2019年11月25日
