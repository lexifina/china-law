# 三亚市人民政府办公室关于省道S314天新线天涯至新宁坡段改建工程（三亚段）新增用地土地调查有关事项的通知

三亚市人民政府办公室关于

省道S314天新线天涯至新宁坡段改建工程

（三亚段）新增用地土地调查有关事项的通知

天涯区人民政府，崖州区人民政府，育才生态区管委会，市政府各有关单位：

根据省道S314天新线天涯至新宁坡段改建工程的建设需要，经市政府同意，对省道S314天新线天涯至新宁坡段改建工程（三亚段）新增用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于天涯区、崖州区、育才生态区内，用地调查面积约325461平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见省交通运输厅提供的省道S314天新线天涯至新宁坡段改建工程两阶段施工图。土地权属（海南平面坐标系）情况为天涯区文门村、马岭村和黑土村委会集体土地共约56509平方米，崖州区明善村委会集体土地约9929平方米，育才生态区雅亮村、青法村、马亮村和马脚村委会集体土地共约36789平方米，海南省农垦集团有限公司、保国农场和立才农场国有土地共约113608平方米，保国农场占用明善村和青法村土地共约1768平方米，国家土地约1774平方米，市政府土地约29126平方米，力村水库和大隆水库土地约9388平方米，光彩小学国有土地约318平方米，三亚城市投资建设有限公司等4家公司国有土地共约66251平方米；土地利用现状（2000国家大地坐标系）为农用地约288481平方米（其中水田约19019平方米、旱地约10243平方米、果园约24349平方米、其他园地约171053平方米、有林地约5345平方米、灌木林地约57446平方米、其他林地约178平方米、坑塘水面约848平方米），建设用地约27933平方米（其中铁路用地约349平方米、公路用地约2441平方米、建制镇约2505平方米、村庄约20476平方米、风景名胜及特殊用地约2162平方米），未利用地约9321平方米（其中其他草地约9068平方米、河流水面约66平方米、裸地约187平方米）；该项目大部分用地已纳入《三亚市总体规划（空间类2015-2030）》（市“多规合一”动态维护版）中规划为公路用地，涉及的小部分基本农田、林地等用地调整正在按程序上报。上述用地涉及的约29262平方米耕地在办理农用地转用时，从我市耕地占补平衡指标中统筹安排。待完成占补平衡任务后，由省交通运输厅按要求提供用地报批材料，市自然资源和规划局将其列入当年新增建设用地指标并办理农转用及征收报批手续。

二、为做好该项土地调查工作，由天涯区政府、崖州区政府和育才生态区管委会按照属地管理的原则负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市自然资源和规划局负责对征收集体土地范围内的征地工作进行指导；市住房和城乡建设局负责对国有土地上的房屋征收与补偿工作进行指导。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、征收集体土地及收回农场国有土地的征地补偿测算工作按《三亚市人民政府关于印发三亚市集体土地征收补偿安置管理规定的通知（2013年修订）》（三府〔2013〕43号）规定执行。收回农场国有土地外的其他国有土地的征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）等规定执行。

四、根据2010年6月26日原国土资源部下发的《关于进一步做好征地管理工作的通知》第四条规定，辖区政府应履行征地前告知、确认和听证程序并完成土地权属、地类、面积等确认，向市自然资源和规划局出具履行征地前告知等程序的证明及土地权属确认意见（附件1）。待省政府批准征地后，征收土地公告和征地补偿安置方案公告可同步进行。

五、为进一步做好被征地农民养老保险工作，根据省人力资源和社会保障厅、省财政厅和原省国土环境资源厅2013年10月15日颁发的《关于印发海南省被征地农民参加社会养老保险业务操作规程（试行）的通知》（琼人社发〔2013〕302号）精神，应在本通知下发后10个工作日内对项目征收农用地和享受缴费补贴人数等情况进行调查，组织村（居）小组填写《征地项目被征地农民基本情况调查表》（附件2），经村（居）委会、辖区政府逐级审核后，由辖区政府汇总填写《征地项目被征地农民基本情况乡镇调查汇总表》（附件3），并将上述两种表格报送市自然资源和规划局。

六、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。天涯区政府、崖州区政府、育才生态区管委会、各相关职能部门一定要提高依法用地意识，决不能产生新的违法用地。
