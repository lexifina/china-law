# 三亚市人民政府办公室关于印发三亚市2019年春节黄金周期间城市供水安全保障工作方案的通知

三亚市人民政府办公室

关于印发三亚市2019年春节黄金周期间

城市供水安全保障工作方案的通知

各区人民政府，育才生态区管委会，市各有关单位：

《三亚市2019年春节黄金周期间城市供水安全保障工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2019年1月28日

（此件主动公开）

三亚市2019年春节黄金周期间城市供水

安全保障工作方案

为确保我市2019年春节黄金周期间供水安全，按照市委市政府的工作部署和要求，结合三亚市供水实际情况，制定本方案。

一、工作原则

按照“供水应急工作实行‘常备不懈、预防为主、全市互动、全力抢救、保障供水’的指导方针”，本着“统一指挥、统一调度、按级负责、各司其职、团结协作，保障重点和局部利益服从全局利益，一般工作服从应急工作的原则，保证应急供水工作实施过程的严肃性和权威性”的工作原则，加强对城市供水安全的监管力度，督促各供水企业、原水水库管理责任单位、各相关责任单位落实城市供水安全责任制，及时发现和解决城市供水安全的突发问题，进一步提升城市供水系统应急处置能力，健全城市供水安全保障机制，切实做好春节黄金周期间供水安全保障工作。

二、组织领导

为加强2019年春节黄金周期间供水安全保障工作领导，成立三亚市供水安全保障工作领导小组，全面负责我市2019年春节黄金周期间的供水安全保障工作。其组成人员如下：

三、供水保障内容

（一）在2019年春节黄金周到来之前，主要做好以下几方面工作：

1.各相关职能单位要根据《三亚市城市供水应急管理规定》，按照各自的职责制定本单位的《2019年春节黄金周期间城市供水安全保障工作方案》，并且制定各种突发情况下的应急预案。

2.在2019年春节黄金周到来之前走访重点保障单位，特别是亚龙湾片区、亚龙湾火车站、三亚火车站、凤凰机场等重点保障区域，排除供水安全隐患，加强及重点区域水质检测，确保供水安全。（责任单位：海南天涯水业集团有限公司、三亚中法供水有限公司、海棠区政府、亚龙湾管委会、亚龙湾开发股份有限公司）

3.在2019年春节黄金周到来之前，海棠区政府要牵头联合三亚中法供水有限公司、赤田水库做好青田水厂原水管线、赤田农灌渠的巡查、维护等工作，务必确保2019年青田水厂供水安全。（三亚中法供水有限公司、海棠区政府、赤田水库）

4.在2019年春节黄金周到来之前完成供水厂及配套供水系统设备的检查维修保养工作，同时备足相关的备品、备件，监督亚龙湾火车站做好储水设备配套建设，确保春节期间各供水厂安全运行。（责任单位：海南天涯水业集团有限公司、三亚中法供水有限公司，市水务局）

5.供水调度工作要统一到保障全市供水安全的高度，互相协调服从，确保供水安全。（责任单位：海南天涯水业集团有限公司、三亚中法供水有限公司）

6.制定各种突发情况下应急抢修方案，贮备抢修需要的物资、材料，建立抢修队伍，确保因水压调整造成的爆管现象，抢修8小时内完成。（责任单位：海南天涯水业集团有限公司、三亚中法供水有限公司、亚龙湾开发股份有限公司）

（二）在2019年春节黄金周期间，主要做好以下几方面工作：

1.指导监督各水厂安全运行，确保城镇供水安全

加强监督指导各供水企业和原水水库做好2019年春节黄金周期间供水设施的检查和维护，确保各水厂正常安全运行。（责任单位：市水务局）

2.水源安全防护

加强城市供水水源大隆水库、赤田水库、福万-水源池水库和半岭水库的巡查管理工作，确保原水水质安全。（责任单位：各原水水库管理责任单位）

3.供水设施安全保障

（1）原水管道。对原水输水管道进行24小时巡查，及时处理输水管偷、漏水点，对发现的安全隐患要及时整改，确保24小时连续不间断供水以及水质、水量、水压符合国家有关技术规范标准，防止停水事故发生。（责任单位：海南天涯水业集团有限公司、三亚中法供水有限公司、各原水水库管理责任单位）

（2）供水管道。负责全市供水设施的巡查维护，特别是针对薄弱环节，实行重点巡查维护，负责在应急状态下对突发的供水进行维护和爆管抢修，对全市小区内供水管道抢修进行指导和辅助。（责任单位：海南天涯水业集团有限公司、三亚中法供水有限公司）。

4.水质监测督查

（1）原水水质。加强对原水水质的保护，对水源保护区进行24小时巡逻，防止水污染事件发生。（责任单位：各原水水库管理责任单位）

（2）供水水质。负责监测原水供水管道、自来水出厂水、管网水以及重点用户水质，并对水质污染提出预测和对策。（责任单位：市水务局、海南天涯水业集团有限公司、三亚中法供水有限公司）。

（3）水质检测频率。增加水质检测频率。（责任单位：海南天涯水业集团有限公司、三亚中法供水有限公司）

（4）水质监督监测。监督监测2019年春节黄金周期间各水厂出水水质、管网末梢水等。（责任单位：市水务局）

5.供水调度

由领导小组办公室负责，海南天涯水业集团有限公司、三亚中法供水有限公司、亚龙湾开发股份有限公司配合，对全市供水水量进行调度，保证亚龙湾、大东海、南山、天涯海角等重要活动和旅游区、城区主要居民生活区、部队驻地、凤凰机场等重点地区和重要区域用水。（责任单位：市水务局、海南天涯水业集团有限公司、三亚中法供水有限公司、亚龙湾管委会、亚龙湾开发股份有限公司）。

6.供电保障

三亚供电局在2019年春节黄金周期间要为各供水厂提供正常供电保障，如确实需要进行常规维修以及配合其他工作进行停电时，应尽量考虑减少跟供水有关的停电计划，并提前24小时告知供水企业及供水相关责任单位做好准备工作，确保各水厂供电安全，同时各供水厂要准备好应急发电设施。（责任单位：三亚供电局、海南天涯水业集团有限公司、三亚中法供水有限公司、亚龙湾开发股份有限公司）

7.应急送水

在突发停水情况下，各供水企业及时报告领导小组办公室，负责协调联系市园林环卫局和市消防支队落实送水车，合理调配水车等车辆为突发停水区域或其他需送水区域送水，市园林环卫局和市消防支队配合实施应急送水工作。（责任单位：市水务局、市园林环卫局、市消防支队、海南天涯水业集团有限公司、三亚中法供水有限公司、亚龙湾开发股份有限公司）

五、应急措施

当发生重大供水设施事故或水质污染等突发供水安全事件，造成部分城区管网无水压及部分地区没水供应，修复时间24小时以上时，有关单位必须启动本单位应急供水安全预案并采取以下应对措施：

（一）突发供水安全事故报告制度

1.各原水水库管理单位、供水企业、亚龙湾开发股份有限公司必须在30分钟内将事故情况向领导小组办公室报告，同时由领导小组办公室报市委、市政府值班室和市安全生产监督管理局。

2.各原水供应单位、供水企业、亚龙湾开发股份有限公司在6小时内形成书面报告，报送领导小组办公室，再由领导小组办公室书面报送给市委、市政府值班室和市安全生产监督管理局。

3.报告应包括以下内容：（详见附表）

（1）报告单位、签发人和报告时间；

（2）造成事故的单位及发生的事件、地点；

（3）造成事故的原因、经过、影响范围；

（4）应对事故采取的抢修措施；

（5）需要有关部门和单位协助事故抢救处理的有关事宜。

（二）安全供水领导小组在接到报告后，指挥和督促相关单位采取相应的应急措施。

1.集中力量组织抢修，尽快恢复供水设施。

2.确保原水供应，以满足水厂供应自来水。

3.领导小组办公室报市应急指挥部批准，对全市管网和阀门进行调控，实行分区分时分量供水。

4.领导小组办公室协调应急送水小组，指定装水地点，向重大保障区域供水，向重点用水单位调配用水车辆。

5.恢复自来水供应时，根据供水经营范围，各供水企业应对管网水质进行检测，合格后恢复对外供水，加大对城市管道的巡视，逐步实现正常供水，保障安全恢复供水。

（三）专业抢修车辆、设备、机具保障措施

1.各供水企业应配备足抢修物资、机械设备、机具、车辆等，确保在应对突发事件时抢修物资的供应。紧急情况下抢修所需的物资、器材、车辆可在全市范围内调用，按“先处置、后结算”的要求进行抢修、救助，所发生的费用在抢修完毕后按相关规定处理。

2.各供水企业成立供水抢险工作队，队员均应配备相应的空气呼吸器、防毒面具等装备，确保抢险过程中人员的安全。抢修过程中必需的管线图、抢修通讯录机及其他抢险机具等必须配备齐全，保证完好有效。机具必须经常维修，并存放在抢修工程车上。

六、工作总结

各职能单位应于2019年春节黄金周结束后24小时内向领导小组提交工作总结，领导小组办公室汇总后，及时上报市政府及相关部门。
