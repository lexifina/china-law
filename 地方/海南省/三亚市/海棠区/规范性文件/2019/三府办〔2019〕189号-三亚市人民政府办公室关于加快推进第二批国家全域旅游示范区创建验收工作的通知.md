# 三亚市人民政府办公室关于加快推进第二批国家全域旅游示范区创建验收工作的通知

三亚市人民政府办公室

关于加快推进第二批国家全域旅游

示范区创建验收工作的通知

各区人民政府：

根据文化和旅游部《关于公示首批国家全域旅游示范区名单的公告》，我市吉阳区成功入选首批国家全域旅游示范区名单。为顺利通过第二批国家全域旅游示范区验收，根据省旅游和文化广电体育厅关于第二批国家全域旅游示范区创建第三方评估初步反馈意见，以及市委、市政府关于加快我市全域旅游创建工作相关部署，现将《三亚市迎接第二批国家全域旅游示范区验收需加强的创建任务清单》印发给你们，请各区党政主要领导高度重视、亲自谋划，加快推进解决创建任务中存在的各项问题，每月30日前将进展情况报市创建国家全域旅游示范区领导小组办公室（市旅游文化广电体育局）。

附件：三亚市迎接第二批国家全域旅游示范区验收需加强的创建任务清单

三亚市人民政府办公室

2019年9月26日
