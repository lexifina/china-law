# 三亚市人民政府办公室关于印发三亚市培育引进上市公司三年行动计划——白鹭计划（2019-2021年）的通知

三亚市人民政府办公室

关于印发三亚市培育引进上市公司

三年行动计划——白鹭计划（2019-2021年）的通知

各区人民政府，各管委会，市政府直属各单位:

《三亚市培育引进上市公司三年行动计划——白鹭计划（2019-2021年）》已经七届市委常委会第139次会议、七届市政府第72次常务会议审议通过，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2019年11月29日

（此件主动公开）

三亚市培育引进上市公司三年行动计划

——白鹭计划（2019-2021年）

为深入贯彻落实习近平总书记“413”重要讲话和中央12号文件精神，加快海南自贸区（港）建设，高标准高质量推动三亚金融业发展，实施上市公司集聚，夯实三亚市金融业发展基础，制定本计划。

一、总体思路

坚持政府引导、市场化运作、专业化服务，加大扶持、培育和引进力度，充分利用资本市场资源，做大资本市场规模，补齐资本市场短板。

二、主要目标

到2021年底，全市境内外上市、挂牌公司达到10家，重点培育企业达到30家。

三、适用对象

本市已上市、挂牌企业，本市拟上市、挂牌企业，有意向迁址落户本市的上市企业。为三亚市培育引进上市公司提供服务的中介服务机构。

四、扶持已上市企业提质增效

（一）支持上市公司募资发展

1.鼓励上市公司充分利用增发、配股、公司债等资本市场工具募集资金，吸引战略投资者和财务投资人，降低企业负债率和股票质押率，降低财务风险。加大上市公司募资后所投项目的落地服务力度，落实好相关配套服务工作。

2.对增发、配股、发债等募资成功的上市企业，按照到位资金的0.5%给予奖励，最高补贴金额不超过100万元。对于募资后所投项目落地本市的给予一次性奖励50万元，并全力做好落地服务工作。

（二）支持上市公司开展并购重组

1.发挥上市公司资源整合能力，鼓励各类并购基金、私募股权基金、证券中介机构、国有龙头企业参与，兼并重组市内相关企业，以资本、产业优势盘活存量有效资产。

2.支持本市有实力的企业参与上市公司并购重组，鼓励银行机构积极开展并购贷款、银团贷款，为并购重组提供融资支持。

3.对上市公司并购重组项目按到位资金0.5%给予奖励，最高补贴金额不超过100万元。

五、培育本地企业上市

（一）加强对拟上市企业的培育引导

1.制定完善上市企业后备资源库管理办法，实行“分类管理、区别对待、因企施策”，加强入库企业的指导服务，突出抓好重点拟上市、挂牌企业的培育工作。根据企业不同特点和上市、挂牌进程，采取分层次、分行业、分梯队办法对上市企业后备资源库进行定期更新，优化完善管理和服务。对有潜力入库的企业进行股份制改造、融资及挂牌专项辅导，建立规范的现代企业制度，培育壮大后备上市梯队。

2.深入开展宣传发动、培训辅导活动，邀请境内外证券交易所、全国中小企业股份转让系统有限公司及中介机构的专家来我市进行授课和辅导，传播资本市场理论知识、政策动态、运作技巧和典型案例，增强企业对接多层次资本市场的意识、动力和能力。

（二）对于企业上市给予奖励

1.对在沪深交易所（含创业板、科创板）首次公开发行股票并上市的三亚市注册企业，市级财政奖励1500万元，该奖励分阶段拨付：对完成企业股份制改造，报海南证监局办理辅导备案手续的，奖励400万元；对经中国证监会受理申请材料的，奖励500万元；对获得中国证监会核准，并在沪深交易所成功发行的，奖励600万元。鼓励企业注册所在区参照市本级标准进行奖励，奖励标准由各区自行制定。

2.对市内企业按规定异地“买壳”或“借壳”上市，将注册地迁回本市的，市级财政给予一次性奖励1500万元，迁入上市公司享受奖励后10年内将注册地迁出我市的，要求退还此项奖励。对企业在境外证券交易所公开发行股票并上市的，给予一次性奖励1000万元。对在全国中小企业股份转让系统挂牌的企业，给予一次性奖励150万元；对在区域性股权交易中心交易板挂牌的企业，给予一次性奖励30万元。

企业获得的财政奖励资金，应部分用于奖励对企业上市做出特殊贡献的高级管理人员和团队骨干人员。

六、引进上市公司迁入三亚

对于符合三亚市总体战略定位和产业发展方向的已上市企业，以开放姿态欢迎迁入三亚。突出抓好拟上市、挂牌企业的引进工作。

（一）采取产业政策扶持、招商政策配合的方式，通过运用市场化的基金、纾困等模式，解决有意向迁入我市的已上市、重点拟上市企业的实际问题。具体可采取“一事一议”的办法，参考《海南省总部企业认定管理办法》中对于总部企业的认定标准，结合《三亚市促进总部经济发展暂行办法》在开办补助、经营贡献奖励、管理人员奖励、办公用房租购补贴及企业用地等方面提供政策保障。

（二）对上市公司注册地迁入我市的，给予一次性奖励1500万元，迁入上市公司享受奖励后10年内将注册地迁出我市的，要求退还此项奖励。

七、研究成立上市公司培育引进发展基金

研究成立由三亚市政府（三亚发展控股有限公司实际运作）和省内外金融控股集团或产业集团（一至两家）合作的发展基金，通过股债结合的方式直接投资或投资其他基金、项目进行放大，撬动社会资本。采取定向纾困、并购基金搭建等方式解决企业流动性问题及企业发展面临的资金问题。

八、鼓励中介服务机构开展业务

鼓励证券公司、信托公司等金融机构和会计师事务所、律师事务所、信用评级机构等中介服务机构为我市引入上市资源，对协助我市引入上市公司和优质企业的、辅导引入企业上市或服务市内企业借壳上市后将注册地迁入我市的，给予一次性奖励100万元。

九、保障措施

（一）加强组织领导

1.建立三亚市资本市场工作领导小组。领导小组以市委书记、市长为组长，分管金融的副市长为副组长，各产业负责部门主要领导为成员，办公室设在市金融发展局，分管金融的副市长兼任办公室主任。

2.由领导小组统筹协调全市企业上市、挂牌、质量提升和吸收引进工作。完善工作组织机构，建立健全推进机制，制定年度推进计划，建立股改清单和上市、挂牌、引进清单，明确目标任务，分解落实责任。

（二）建立工作推进责任制

每家挂牌企业要明确1名市领导负责，1个行业牵头单位工作班子跟踪服务，1个企业内部上市工作组具体实施，1个企业上市工作方案。随时掌握和推动企业上市进程，研究解决企业上市的具体问题，督促中介机构提高辅导工作质量，全面解决存在问题，为企业提供全方位、全过程服务。

（三）加强协调沟通

领导小组成员单位要高度重视，成员单位之间要加强协作，推动资源倾斜，对符合上市条件的企业进行集中培育、辅导和推荐，促进做大做强。加强与监管部门、交易所、中介服务机构的联系与互动，为企业提供政策、服务等配套支持。
