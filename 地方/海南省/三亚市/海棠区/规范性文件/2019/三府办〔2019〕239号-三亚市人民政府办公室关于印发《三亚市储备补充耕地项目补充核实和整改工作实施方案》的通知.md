# 三亚市人民政府办公室关于印发《三亚市储备补充耕地项目补充核实和整改工作实施方案》的通知

三亚市人民政府办公室

关于印发《三亚市储备补充耕地项目补充核实

和整改工作实施方案》的通知

各区人民政府，市政府各有关单位：

《三亚市储备补充耕地项目补充核实和整改工作实施方案》已经市政府同意，现印发给你们，请认真组织实施。

附件：三亚市储备补充耕地项目补充核实和整改工作实施方案

三亚市人民政府办公室

2019年12月10日

（此件主动公开）

三亚市储备补充耕地项目补充核实和

整改工作实施方案

为切实加强我市补充耕地项目管理，根据省自然资源和规划厅下发《关于抓紧完成储备补充耕地项目补充核实和整改工作的通知》（琼自然资函〔2019〕2480号）文件要求，我市本次储备补充耕地核查不合格（或疑似存在问题）项目共9个（三亚市天涯区红塘村耕地开垦项目、三亚市南滨农场南新立新队耕地开垦项目、三亚市吉阳镇中廖村土地开发整理项目、三亚市南滨农场土地开发整理项目（一期）、三亚市崖州区梅东村耕地开垦项目、三亚市南田农场耕地开垦项目、三亚市南滨农场红星金鸡队耕地开垦项目、三亚市天涯区华丽村耕地开垦项目、三亚市天涯区布甫村耕地开垦项目），为了确保三亚市储备补充耕地项目补充核实和整改工作的顺利开展，结合下达我市需要整改的9个补充耕地项目问题清单，分析梳理项目具体情况，制定本方案。

一、整改内容及步骤

（一）制定工作方案（2019年10月21日至11月8日）

市自然资源和规划局利用土地利用及影像数据开展本次储备补充耕地项目的实地补充核实，并制定相关工作方案并征求相关单位意见。

（二）项目整改工作（2019年11月9日至12月10日）

对整改清单中9个项目存在的问题进行分类整改：

1.对“有管护协议无管护资金、后期管护不力”等问题，由市土地整理中心将后期管护资金纳入年度部门预算，按年度统计并报请市财政批准，并先上传申报、安排资金等相关文件作为整改资料，待资金下达后由市土地整理中心拨付给区政府或项目设施接管单位，以便落实后期管护工作。

2.对于项目区内补充耕地地块目前利用状况是种植木瓜、火龙果、芒果等果树的问题，结合三亚市第三次国土调查数据进行实地核查，确属无法整改的，按照实际面积填写上报，由自然资源部判断是否核减新增耕地指标。

3.对于项目区内存在工程设施损毁、补充耕地地块撂荒及其他需要工程性整改的项目，由于整改工作时间紧、任务重、要求高，由市土地整理中心报市自然资源和规划局批准后组织实施，并由市自然资源和规划局组织整改验收工作。

（三）整改上报工作（2019年12月11日至12月15日）

由市自然资源和规划局收集整理整改验收的有关资料数据，通过有关软件上报省自然资源和规划厅审核，并配合省自然资源和规划厅上报自然资源部复核的工作。

（四）建立长效机制（2019年12月以后）

由市土地整理中心将后期管护资金纳入年度部门预算，按每年度统计并报请市财政局批准，待资金下达后按时拨付给各区政府或项目设施接管单位落实项目后期管护工作。各区政府或项目设施接管单位负责管理每年下拨的管护资金，专款专用，切实落实管护责任，确保补充耕地不撂荒不改变土地类别。

二、任务分工

本项整改工作时间紧、任务重、要求高，各相关单位要高度重视，共同推进整改工作，确保本市补充耕地数量真实、质量可靠，避免因整改不过关扣除我市新增耕地指标，对我市建设项目用地报批等工作造成严重影响。

市自然资源和规划局作为整改工作主管部门，负责牵头落实各项整改工作，负责组织整改验收及上报工作。

市财政局负责落实整改需要工程资金及各项目后期管护资金。

市农业农村局负责工程性整改项目的立项等前期审批工作。

各区政府配合整改项目的协调工作。落实管护责任，指导各项目所在区域集体经济组织、国营农场做好新增耕地的耕作。

三、整改资金来源

对于项目区内存在工程设施损毁、补充耕地地块撂荒及其他本次需要工程性整改复耕的项目，整改资金从2019年国土空间生态修复专项资金或市自然资源和规划局土地出让金业务费中列支。

后期管护资金由市财政局结合年度部门预算统筹安排。
