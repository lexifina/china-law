# 三亚市人民政府办公室关于印发三亚市12345政府服务热线聘请热线社会监督员工作实施方案的通知

三亚市人民政府办公室

关于印发三亚市12345政府服务热线聘请热线

社会监督员工作实施方案的通知

各区人民政府，各管委会，市政府直属各单位：

《三亚市12345政府服务热线聘请热线社会监督员工作实施方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2019年11月27日

（此件主动公开）

三亚市12345政府服务热线

聘请热线社会监督员工作实施方案

为充分发挥社会各界人士对12345政府服务热线工作的监督作用，提升12345政府服务热线为民服务水平和质量，从而提高政府热线工作作风，树立政府良好形象，特制定本方案。

一、指导思想

根据李克强总理在全国深化“放管服”改革转变政府职能电视电话会议上的重要讲话中强调“要以人民为中心和落实监管责任，要扎实做好资源整合、队伍磨合、技能提升等工作，培养‘一专多能’的监管人员，提升监管能力和水平”的讲话精神，同时，为贯彻落实省委七届六次全会和省委书记刘赐贵在会上的讲话精神，按照《海南省人民政府政务服务热线12345平台建设管理实施方案的通知》（琼政务办〔2019〕3号）相关文件要求，并结合全市主题教育活动的整改要求和参照其他城市政府热线的先进管理经验，计划聘请社会各界人士担任热线社会监督员，与12345政府服务热线工作人员一起，化解群众反映的热点、难点、焦点问题，从而促进12345政府服务热线和各热线成员单位更好地树立为民服务意识，打造市民群众满意的政府服务平台。

二、工作内容

（一）聘请对象

聘请热线社会监督员人选，来自社会各界，主要有市级人大代表、市级政协委员、区级人大代表、各协会成员代表、社会团体代表、旅游界代表、企业代表、律师代表、媒体记者代表、退休老干部代表、社区代表、医护人员代表、教职工代表及社会热心人士或自荐人员代表等。

（二）聘请条件

热线社会监督员应关心12345政府服务热线工作，热心社会公益事业，具有强烈的社会公德心、责任感，坚持原则，公道正派；具有一定的政策、法规知识和口头、文字表达能力，工作经验较丰富，善于发现和提出问题；具有较好的政治素质，做到廉洁自律，保守秘密，认真遵守有关规章制度；具有较强的监督意识和辨别是非能力，有一定的时间和精力参与监督活动；能密切联系群众，敢于反映情况和提出批评意见。

（三）热线监督员管理职责

1.工作职责。热线社会监督员按照实事求是、客观公正、提升效能的原则，积极履行职责，积极参与市12345政府服务热线服务管理工作，其工作职责主要是：

（1）通过拨打12345政府服务热线和12301旅游服务热线，监测热线的接通情况、话务员的值班状态、话务质量和派单水平，查找热线服务与管理中存在的问题；

（2）了解、收集群众对12345政府服务热线工作的意见和建议，反映人民群众日常生产、生活中遇到的咨询、投诉、求助、建议等方面的问题；

（3）监督各区、各部门、各单位在处理12345政府服务热线事项工作中存在的失职和不作为行为；

（4）监督12345政府服务热线工作人员在服务态度、办事效率等方面存在的问题；

（5）听取12345政府服务热线通话录音，查找话务员通话服务过程中存在的问题；

（6）参与12345政府服务热线热线疑难办件的督办和第三方评价；

（7）为12345政府服务热线热线提出改进和提高工作水平的意见建议；

（8）积极参加12345政府服务热线组织的社会活动。

2.组织管理。热线社会监督员每两年招募一届，每届200人。通过单位组织推荐、社会各界人员自荐等方式产生，具体产生方式是：

（1）市人大常委会办公室负责推荐市级人大代表10人；

（2）市政协办负责推荐政协委员代表10人；

（3）各区人大常委会办公室负责推荐区级人大代表各5人；

（4）市民政局负责推荐社会团体代表10人；

（5）市国资委负责推荐企业代表10人；

（6）市司法局负责推荐律师代表10人；

（7）市教育局负责推荐教职工代表15人；

（8）市卫生健康委负责推荐医护人员代表15人；

（9）市委老干局负责推荐退休老干部代表5人；

（10）市商务局负责推荐会展协会代表5人；

（11）市交通运输局负责推荐市交通协会代表5人；

（12）市旅游和文化广电体育局负责推荐旅游界代表和旅游协会代表30人；

（13）各区人民政府、育才生态区管委会负责推荐社区代表25人；

（14）三亚传媒影视集团有限公司负责推荐媒体记者代表10人；

（15）市热线办负责推荐社会热心人士或自荐人员代表25人。

市热线办负责热线社会监督员的人选名单审核并负责发放聘用证书；负责对热线社会监督员进行整体管理、协调热线社会监督员分组和工作任务的分派；负责热线社会监督员工作成果的统计、整理和提交。

3.费用补贴。由市热线办根据《三亚市城市管理举报投诉奖惩办法》对其发放适量的话费奖励等补贴，补贴金额经市热线办测算后列入本年度热线办奖励经费中进行列支。

三、工作步骤

（一）准备部署阶段（2019年11月底前）。市热线办根据聘请热线社会监督员的相关工作部署，制定具体实施方案，与各相关部门联系协商，确认各相关单位推荐聘任热线社会监督员名单。

（二）动员推进阶段（2019年12月中旬）。召开热线社会监督员的聘任动员大会，经市政府审查后，颁发聘用证书，明确热线社会监督员的权利和义务，确保热线社会监督员聘任取得明显成效。

（三）全力推进阶段（2019年12月底前）。为提高热线社会监督员的服务水平，推动热线服务品质再上新台阶，针对电话沟通技巧、综合业务、案例分析等内容对聘任热线社会监督员进行讲授及培训，并协调分派热线社会监督员的工作任务。

（四）全面实施阶段（2020年1月开始）。热线社会监督员定期或不定期进驻热线，协助热线开展工作。充分发挥热线社会监督员的监督作用，开辟12345政府服务热线“绿色通道”和搭建“连心桥”的平台，从而推动群众反映问题的有效解决，助力海南自由贸易区（港）建设。

四、工作要求

（一）精心组织。聘请社会各界代表作为热线监督员，是提升12345政府服务热线为民服务水平，树立政府良好形象，加强社会监督的重要举措。各相关部门要高度重视，加强领导，专人负责，明确责任人，按照工作方案要求，有组织有计划地开展推荐活动。将真正符合条件并热心于社会监督工作的人员推荐到热线监督员队伍中来。

（二）加强宣传。市热线办要在媒体上对选聘“热线社会监督员”活动广为宣传，使社会广泛知晓、自愿、主动参与“热线社会监督员”活动，扩大热线社会监督员参加范围。

（三）严格审核。各相关部门要按照热线社会监督员的条件把好审核关，组织推荐活动要公开、公正、透明、有序，确保所推荐的热线社会监督员主客观条件符合选聘的要求，能够积极履行职责，真正发挥好社会监督的作用。

（四）规范管理。市热线办要建立和妥善保管热线社会监督员档案资料，做到日常工作信息、人员档案管理规范化。同时，要加强对热线社会监督员履行监督职责的管理，督促其主动监督，行为规范，达到预期的目的。
