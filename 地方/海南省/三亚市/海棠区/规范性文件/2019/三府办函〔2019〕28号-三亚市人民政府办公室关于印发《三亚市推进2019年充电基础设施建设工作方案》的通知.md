# 三亚市人民政府办公室关于印发《三亚市推进2019年充电基础设施建设工作方案》的通知

三亚市人民政府办公室

关于印发《三亚市推进2019年充电基础设施建设工作方案》的通知

各区人民政府，各管委会，市政府直属各单位：

《三亚市推进2019年充电基础设施建设工作方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府办公室

2019年5月15日

（此件主动公开）

三亚市推进2019年充电基础设施建设

工作方案

为贯彻落实2019年海南省政府工作报告明确提出的“建设充电桩4万个以上”和《海南省发展和改革委员会关于印发海南省2019年充电基础设施建设任务分解目标的通知》的工作要求，加快推进我市充电基础设施建设，确保我市2019年充电基础设施建设任务的完成，结合我市实际，特制定本方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实十九大及习近平总书记在庆祝海南建省办经济特区30周年大会上的重要讲话和《中共中央国务院关于支持海南全面深化改革开放的指导意见》精神，以创建国家生态文明试验区为根本目的，以促进清洁能源汽车推广应用为出发点，以提升充电保障能力为行动目标，全面贯彻落实省委、省政府关于推进清洁能源汽车发展的决策部署，科学规划我市充电基础设施建设，全力加快推进我市电动汽车充电基础设施建设，为推进清洁能源汽车全域化的实现提供好基础保障。

二、建设原则

（一）适度超前，有序建设。根据电动汽车应用特点与技术迭代趋势，紧扣电动汽车推广应用需求，建立政府有关部门与相关企业各司其职、各尽所能、群策群力、合作共赢的系统推进机制，适度超前建设，站在更高的起点上推进三亚充电基础设施发展。

（二）依托市场，政府引导。充分发挥市场主导作用，政府积极引导社会资本投资充电基础设施建设。鼓励企业结合“互联网+”，创新商业合作和服务模式，创造更多经济社会效益，实现可持续发展。

（三）统筹规划，科学布局。秉承“专（自）用为主、公用为辅、快充（充换电）站为补充”的原则，构建以住宅小区停车位、单位停车场、公交及出租车场站、环卫及物流车站点等配建的专用充换电基础设施为主体，以城市公共建筑物停车场、社会公共停车场、临时停车位、加油站等配建的公共充电基础设施为辅助，以城市建成区充换电站和公路沿线充换电站为补充，打造适度超前、布局合理、功能完善的充电基础设施体系。

三、建设目标

2019年充电基础设施建设目标为8108个/枪/接口，其中公共桩目标为1018个/枪/接口，在此基础上，尽量增加充电基础设施建设数量，以满足电动汽车不断增长的充电需求。

四、工作任务

鉴于2019年充电基础设施建设时间紧，任务重，结合当前我市充电基础设施推进工作的实际，2019年我市充电基础设施建设主要以新建住宅小区、大型商场、超市、酒店等场所配建充电基础设施为主，同时结合既有场地（包括已建、在建住宅小区、各类停车场、公共机构办公区停车场等）情况实施充电基础设施建设。并完成5个符合规划要求的独立占地的集中式充（换）电站建设。

（一）完成5个独立占地的集中式充（换）电站布点规划意见，并落实具体土地。（责任单位：市自然资源和规划局）

（二）推进住宅小区充电基础设施建设。住宅小区新增充电基础设施6900个，其中充电桩300个，充电接口6600个。（责任单位：市住房和城乡建设局；配合单位：市自然资源和规划局、三亚供电局）

（三）推进公共机构充电基础设施建设。各市级党政机构、事业单位、团体组织内部停车场新增充电基础设施108个。（责任单位：市公共机构节能办公室；配合单位：三亚供电局、相关公共机构）

（四）推进各公共停车场及各类交通场站充电基础设施建设。各公共停车场及各类公交场站新增充电基础设施130个。（责任单位：市交通运输局；配合单位：三亚城市投资建设有限公司、三亚供电局）

（五）推进各类文体场馆、旅游景区、景点、宾馆酒店等停车场充电基础设施建设。各类文体场馆、旅游景区、景点、宾馆酒店新增充电基础设施100个。（责任单位：市旅游和文化广电体育局；配合单位：三亚供电局）

（六）推进各大型商场、超市等停车场充电基础设施建设。各大型商场、超市新增充电基础设施50个。（责任单位：市商务局；配合单位：三亚供电局）

（七）推进各类公共教育机构内部停车场充电基础设施建设。各类公共教育机构新增充电基础设施20个。（责任单位：市教育局；配合单位：三亚供电局）

（八）推进各类医疗机构停车场充电基础设施建设。各类医疗机构新增充电基础设施40个。（责任单位：市卫生健康委员会；配合单位：三亚供电局）

（九）推进全市国有企业停车场充电基础设施建设。全市国有企业停车场新增充电基础设施20个。（责任单位：市国有资产监督管理委员会；配合单位：三亚供电局）

（十）推进各社会救助机构充电基础设施建设。各社会救助机构新增充电基础设施20个。（责任单位：市民政局；配合单位：各区人民政府、育才生态区管委会、三亚供电局）

（十一）在其负责管理和建设的项目停车场新增充电基础设施20个。（责任单位：三亚城市投资建设有限公司；配合单位：三亚供电局）

（十二）推进各区充电基础设施建设。区级各部门办公区停车场、区政府及所属各部门管理的各类停车场、美丽乡村项目停车场等新建充电基础设施700个，其中吉阳区250个；天涯区250个；海棠区100个；崖州区80个；育才生态区20个。(责任单位：各区人民政府、育才生态区管委会；配合单位：三亚供电局)

（十三）全力推进集中式充（换）电站建设。

1.对经规划好的5个集中式充（换）电站，由责任单位拟定具体实施方案、明确好建设规模、投资方式等报市政府审定后实施；（责任单位：市交通运输局；配合单位：各区人民政府、育才生态区管委会、市财政局、市自然资源和规划局、市住房和城乡建设局、市生态环境局、市综合行政执法局、三亚供电局）

2.加大力度协调推进企业自建的集中式充（换）电站项目建设。（责任单位：各区人民政府、育才生态区管委会；配合单位：三亚供电局）

五、工作要求

（一）高度重视，按时完成。2019年充电基础设施建设任务已写入省政府工作报告，是政府对社会的庄严承诺，各责任单位要提高政治觉悟，充分认识到完成今年工作任务的重要性，盯紧目标，勇于担当，主动作为，全力以赴推进我市充电基础设施建设，必须确保任务目标的按时完成。

（二）推动政策有效落实。各相关单位要严格按照《海南省电动汽车充电基础设施建设运营管理暂行办法》、《海南省居住（小）区、建筑物、停车场配套充电设施建设管理暂行规定》《三亚市电动汽车充电基础设施管理暂行办法》规定，结合各自行业分管职责，督促新建、在建及既有项目停车场落实配建及改造任务，同时鼓励有条件的单位将充电设施向社会公众开放。

（三）营造良好的舆论环境。各相关单位要在各自分管行业领域通过多种形式，加强充电基础设施发展趋势、政策宣传，营造好良好的舆论氛围，让社会各界全面了解充电基础设施，吸引更多社会资本参与充电基础设施的建设运营，全面推进我市充电基础设施建设。

（四）建立月报制度。为及时掌握各单位推进充电基础设施建设情况，各责任单位必须于每月25日之前将各自推进充电基础设施建设情况报市发展和发改委员会（联系电话：88278768），由市发展和改革委员会汇总后报送市推进充电基础设施建设工作领导小组。
