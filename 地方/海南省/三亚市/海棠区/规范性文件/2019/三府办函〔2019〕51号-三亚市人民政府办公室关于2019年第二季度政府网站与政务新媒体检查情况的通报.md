# 三亚市人民政府办公室关于2019年第二季度政府网站与政务新媒体检查情况的通报

三亚市人民政府办公室

关于2019年第二季度政府网站与政务新媒体检查情况的通报

各相关单位：

根据国务院办公厅出台的《政府网站与政务新媒体检查指标》和《政府网站与政务新媒体监管工作年度考核指标》，市政府办公室组织开展了2019年第二季度全市政府网站与政务新媒体检查。现将有关情况通报如下：

一、总体情况

（一）政务新媒体摸底调查情况。2019年5月17日，市政府办公室印发《关于进一步做好政府网站与政务新媒体管理工作的通知》，在全市范围内开展政务新媒体基本情况摸底调查工作。据调查，各区、各部门共开设政务新媒体账号或应用共7类46个。

（二）网站检测情况。2019年6月1日至24日，按照《政府网站与政务新媒体检查指标》，市政府办公室对全市处于正常运行状态的18个政府网站和32个部门信息公开专栏进行了检查，发现存在突出问题的网站2个，存在突出问题的部门信息公开专栏6个。

（三）机构改革期间政府网站调整优化工作情况。因政府机构改革，三亚市旅游和文化广电体育局开通新的政府网站（lwj.sanya.gov.cn），并关停注销原三亚文化广电出版体育局网站（wtj.sanya.gov.cn）和原三亚市旅游发展委员会网站（tour.sanya.gov.cn）。三亚市自然资源和规划局关停注销原三亚市规划委员会网站（ghj.sanya.gov.cn）和三亚市海洋与渔业局网站（dof.sanya.gov.cn），三亚市自然资源和规划局因未完成党政机关网站标识申请和公安机关备案，目前未在全国政府网站信息填报系统中提交网站基本信息。

二、主要问题

（一）网站内容保障不到位。市卫生健康委员会网站存在多个应更新未更新栏目，市住房和城乡建设局网站存在多个空白栏目，市民政局、市民族事务局等单位信息公开专栏多个栏目长期不更新。

（二）未发布政府信息公开指南。市自然资源和规划局、市商务局、市司法局、市公安局等单位未按要求发布本单位政府信息公开指南。

（三）政务新媒体管理不到位。部分单位政务新媒体在监测时间点前2周内无更新，互动回应性差，不能提供有效互动功能，关注度低，群众体验感不足，有待进一步优化整合。

三、下一步工作要求

（一）持续做好政府网站管理工作。各单位要按照《政府网站发展指引》和《海南省政府网站管理办法》的要求抓好政府网站常态化监管工作，严格信息发布审核机制，加强值班读网，对存在问题的栏目及时落实整改，确保政府网站管理无死角、问题不反弹。

（二）调整政府信息公开基本目录。各单位要按照《海南省政务公开基本目录(2019年版)》于2019年7月10日前完成目录配置、栏目或专栏建设工作，并及时调整对应信息，做好内容保障工作。

（三）规范清理政务新媒体。请各单位对问题比较突出、确实无力维护的政务新媒体予以关停，对分散的或功能相近的政务新媒体实施整合，推进政务新媒体健康有序发展。

（四）加强政务新媒体常态监管。市政府办公室将加强对政务新媒体的常态化监管，按季度组织检查，及时通报问题，督促检查落实。

此次检查中发现存在突出问题的单位要积极采取有力措施及时整改，全面核查，并于2019年7月10日前将整改情况报市政府办公室。

附件：检查发现存在突出问题的政府部门名单
