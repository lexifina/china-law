# 市海棠区人民政府关于印发《海棠区农村人居环境整治清洁家园活动日工作方案》的通知

三亚市海棠区人民政府

关于印发《海棠区农村人居环境整治清洁家园活动日工作方案》的通知

各相关单位：

《海棠区农村人居环境整治清洁家园活动日工作方案》已经区政府同意，现印发给你们，请认真贯彻执行。

特此通知。

三亚市海棠区人民政府

2019年4月11日

关于农村人居环境整治清洁家园活动日的方案

为深入贯彻落实习近平总书记关于改善农村人居环境的重要指示精神，大力实施乡村振兴战略，不断改善我区农村人居环境，促进农村社会文明和谐，实现全面建成小康社会目标，现结合我区“创文巩卫”工作部署，制定本方案。

一、指导思想

坚持以习近平新时代中国特色社会主义思想为指导，以改善农村人居环境质量为目标，坚持“规划先行、示范引导，因地制宜、分类指导、量力而行、循序渐进，城乡统筹、突出特色，建管并重、长效运行”的工作原则，牢固树立新发展理念，加快实施乡村振兴战略，动员各方力量，整合各种资源，强化各项措施，补齐农村人居环境突出短板，力争在推动人与自然和谐发展、满足人民美好生活需要等方面走在全省前列，在海南自由贸易试验区和中国特色自由贸易港建设中打造标杆。

二、活动时间

2019年4月12日上午9点

三、活动人员

区三套班子领导、各局（委、办、中心）主要领导两人

四、活动地点

风塘村委会

五、各村（居）委会

各村（居）委会书记组织人员在村委会负责开展卫生大扫除

六、活动内容

集中开展环境卫生大扫除。重点做好楼道、停车棚、储藏间、卫生间等地方的卫生大扫除工作，对所有物品逐一搬运清扫。清除鼠迹、蟑迹，堵塞鼠洞；清除积水、垃圾污迹，清除卫生死角。要彻底清扫垃圾和杂物，对果皮箱、垃圾箱等进行清洗，保持整洁卫生。

七、活动要求

各单位要高度重视，认真组织实施。要严格按照“巩卫”工作行业管理责任、属地管理责任、网格管理责任和“门前三包”责任，严密组织，加强沟通协调，无缝对接，突出重点。各村（居）委会要对活动开展情况及时进行总结，在开展纪念“4·13”讲话一周年，农村人居环境整治清洁家园活动中将活动现场图片及时上传海棠区人居环境整治工作群，并于4月12日下午 17:00前将活动总结和图片一同报送区农业农村局，将电子版一并发至邮箱：htqnlj88810217@163.com。
