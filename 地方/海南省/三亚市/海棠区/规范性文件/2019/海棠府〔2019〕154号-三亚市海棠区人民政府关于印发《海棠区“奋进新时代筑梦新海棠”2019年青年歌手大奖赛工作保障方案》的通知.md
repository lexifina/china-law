# 三亚市海棠区人民政府关于印发《海棠区“奋进新时代筑梦新海棠”2019年青年歌手大奖赛工作保障方案》的通知

三亚市海棠区人民政府

关于印发《海棠区“奋进新时代 筑梦新海棠”2019年青年歌手大奖赛工作保障方案》的通知

各相关单位:

为展现海棠区青年的奋发进取的精神风貌，进一步凝聚广大青年的智慧和力量，助力海南自由贸易试验区(港）建设,由中共三亚市海棠区委宣传部指导、三亚市海棠区旅游和文化广电体育局主办的海棠区“奋进新时代 筑梦新海棠”2019年青年歌手大奖赛计划于2019年5月22日19:30在三亚海昌梦幻海洋不夜城举行，为确保赛事活动顺利进行，请各相关单位认真落实保障方案（见附件），并于5月21日12:00前将对接联络员回执表报送至区旅文局邮箱haitangbaywtj@163.com。

特此通知。
