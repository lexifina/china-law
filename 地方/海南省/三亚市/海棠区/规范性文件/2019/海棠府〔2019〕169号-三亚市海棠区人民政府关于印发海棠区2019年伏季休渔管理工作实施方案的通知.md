# 三亚市海棠区人民政府关于印发海棠区2019年伏季休渔管理工作实施方案的通知

三亚市海棠区人民政府

关于印发海棠区2019年伏季休渔管理工作实施方案的通知

区各相关单位：

《2019年伏季休渔管理工作实施方案》已经区政府同意，现印发给你们，请认真贯彻执行。

三亚市海棠区人民政府

2019年5月24日

海棠区2019年伏季休渔管理工作实施方案

为切实做好我区2019年海洋伏季休渔管理工作，确保海洋伏季休渔制度的顺利实施，根据《农业农村部关于印发<“中国渔政亮剑2019”系列专项执法行动方案>的通知》（农渔发〔2019〕8号）、《海南省2019年海洋伏季休渔管理工作实施方案》和《三亚市2019年海洋伏季休渔管理工作实施方案》的文件要求及海洋休渔管理的有关规定，结合我区实际情况，制定本方案。

一、休渔时间、海域和范围

休渔时间：5月1日12:00至8月16日12:00

休渔海域：海棠区所辖海域

休渔范围：本辖区和外籍在本区内休渔的除钓具外的所有作业类型捕捞渔船以及为捕捞渔船配套服务的捕捞辅助船。

二、休渔管理目标

贯彻落实《中华人民共和国渔业法》《中国水生生物资源养护行动纲要》以及生态文明建设要求，保护海洋渔业资源，促进海洋渔业可持续、稳定、健康发展，通过加强领导、广泛宣传、严格管理，做到“船进港、证集中、网封存、人上岸”，确保休渔渔船全部按时进港休渔；切实做好“防火、防盗、防台”工作，确保渔船安全渡休；加强监督管理，确保休渔渔船无违规事件发生；关心休渔渔民生活，确保渔区社会安全稳定，为海棠区的经济发展、社会稳定创造良好的环境。

三、组织领导

为加强休渔管理工作的组织领导，保证休渔管理工作顺利开展，海棠区政府成立伏季休渔专项工作领导小组。

组　长：杨 硕（副区长）

副组长：吉家佩（区农业农村局局长）

成员由区农业农村局、区综合行政执法局、区市场监督管理、区应急管理局、公安（边防派出所）、海警、藤海社区、区渔业大队等部门人员组成。

领导小组下设办公室，区农业农村局何宗鹏副局长任办公室主任，办公室设在区农业农村局，负责伏季休渔的组织协调、指导督促工作，成员由办公室人员组成。藤海社区和渔业大队成立伏季休渔工作小组，负责本单位伏季休渔的具体工作。

四、休渔相关要求

（一）所有休渔渔船原则上应回到渔船船籍港所在地的港口、码头停泊，休渔期间不得擅自离港或改变停泊地点。要严格执行船籍休渔制度，严禁渔船跨省异地休渔。因修船、避风等特殊情况需在省内跨地区、跨县域休渔的，必须经船籍港和停泊港所在地渔业主管部门协商确认，由停泊港所在地渔业部门履行监管职责，并报市渔政渔港监督管理处备案，且渔船离港必须全时开启北斗设备。

（二）在休渔期间，休渔渔船的渔具应捆扎、封存于船舱等固定位置，或搬离渔船进库存放；需修理的渔具，应在修理完比后立即封存或进库存放。

（三）在休渔期间，不允许将其他作业类型变更为钓具；刺钓渔船进行钓具作业时，不得携带刺网作业相关网具及设备。

（四）所有休渔渔船不得携带渔具进入休渔海域。

（五）除维持日常生活需要外，休渔渔船在伏休期间不得擅自加水、加冰、加油。

（六）渔业辅助船同步休渔，伏休期间不得为休渔渔船提供收购、运输、补给等后勤服务。

（七）伏季休渔期间租用渔船开展渔业资源调查工作的，必须符合《农业部渔业渔政管理局关于规范伏季休渔期间租赁渔船开展资源调查工作的通知》（农渔资环函〔2018〕53号）要求，资源调查项目必须属于国家重点支持的科研调查范畴。

五、休渔工作措施

（一）加强宣传引导，营造良好氛围。使用悬挂宣传横幅、张贴标语、派发宣传资料等宣传工具在铁炉港内、藤海社区、营头村委会（渔业大队）等地宣传休渔政策，增强渔民群众参与休渔的自觉性。充分利用网络、手机、微信等宣传手段，让更多的人了解、支持和配合休渔工作。成立渔业工作微信群，方便渔业工作的开展。

（二）强化日常监督，掌握渔船动态。一是对区内休渔渔船分类登记造册，将休渔渔船的船名号张榜公布在相应的港口、码头，便于群众监督；统筹安排，划定休渔渔船停泊区，组织渔船就近停泊，保障渔船停泊有序和航道畅通登记并上报未能回港停泊船只，检查登记有特殊情况不能回本辖区渔港停泊的外籍渔船。二是驻点监管。成立休渔工作小组，常驻重点休渔港口，实行划片包干，分工负责，对零星分散的休渔渔船停泊点，指定专人实施有效监控。三是组织港口巡查。根据伏休监管前、中、后三个阶段的不同特点，组织阶段性的港口检查，定期清点渔船，密切关注港口渔船动态。四是强化渔港安全监管。联合后海边防派出所、消防安全部门，加强港内日常消防安全监督，及时发现港内消防安全隐患，加大消防安全的宣传和培训力度，避免麻痹松懈思想。联合后海边防派出所、消防部门，采取有效措施做好渔船的防火、防盗、防台工作。

（三）突出监管重点。加强海上和港口的执法检查，严厉打击违反休渔规定，集中打击“三无”船舶和电、炸、毒等非法捕鱼行为，集中整治渔船船号标识遮挡问题，定期检查海上渔船有无擅自将拖网作业临时更改为刺网或钓具作业，有无携带双重、或多重刺网作业情况，禁止渔民使用任何方式从事灯光捕鱼作业，检查休渔渔船是否擅自转移停泊点和加冰、加油等渔需物资。

（四）处罚措施。对违反休渔规定的渔船，将没收渔获物、渔具，同时暂扣捕捞许可证和处5万元人民币以下罚款，对违反休渔规定作业，电鱼、毒鱼、炸鱼作业，套牌或用假船名作业，暴力抗法的渔船，除接受上级渔业执法部门的处罚外，一律扣除当年油价补贴。

（五）休渔相关工作。利用休渔期间，联合船检部门做好年度船检，不定期组织执法检查，检查渔船证件、职务船员持证、渔船安全设施配备，对存在安全隐患的及时进行整改，确保休渔渔船安全渡休。

五、工作要求

“伏季休渔”是一项综合、系统的社会工程，要把休渔工作作为一项政府行为认真组织实施。主要负责人加强组织领导，密切配合，结合实际情况狠抓实干，落实各项工作，通过广泛宣传教育，增强渔区人民群众爱护渔业资源、保护环境资源的意识，集中精力、突出重点，结合实际，扎实抓好伏季休渔期间的各项管理工作，要加强检查督促，落实安全责任制，为海棠区休渔划上圆满的句号。
