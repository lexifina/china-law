# 三亚市海棠区人民政府关于秸秆、垃圾禁烧工作情况的通报

三亚市海棠区人民政府

关于秸秆、垃圾禁烧工作情况的通报

各相关单位、各村（居）委会：

为切实做好空气质量保障工作，深入推进“秸秆、垃圾禁烧”方案实施，坚决杜绝各类露天焚烧现象发生，安排部署秸秆、垃圾禁烧专项巡查行动，不间断地巡回督导检查。5月25日至6月30日，发现9处着火点,依据《中共三亚市委办公室 三亚市人民政府关于印发<三亚市秸秆、垃圾禁烧工作方案>的通知》（三办发〔2018〕83号）、《中共三亚市海棠区委办公室 三亚市海棠区人民政府关于印发海棠区秸秆、垃圾禁烧工作方案的通知》（海棠办发〔2019〕8号），决定对着火点所在地给予全区通报批评。

一、检查、巡查情况

（一）6月4日，南田居第1东风网格农田焚烧秸秆，居委会安排工作人员扑灭。

（二）6月10日，南田居第4西村网格田地焚烧垃圾，居委会安排农户扑灭。

（三）6月13日，营头村田地焚烧垃圾，村委会安排工作人员扑灭。

（四）6月18日，南田居第1 东风网格农田焚烧秸秆，居委会安排农户扑灭。

（五）6月20日，南田居第1 东风网格农田焚烧秸秆，居委会安排工作人员扑灭，执法局工作人员到现场核实处理。

（六）6月21日，海棠广场保利瑰丽酒店附近有焚烧情况，无法核实归属地

（七）6月22日，铁炉村农田焚烧秸秆，村委会工作人员和执法局工作人员联合119消防员扑灭。

（八）6月23日，铁炉村农户焚烧垃圾，村委会安排工作人员扑灭。

（九）6月26日，椰林村农田焚烧垃圾，执法局工作人员督促村民扑灭。

二、建议

（一）各村（居）委会要将禁烧工作的各项措施、责任落实到位，加强检查。由于工作责任制不落实、工作措施落实不到位等原因造成焚烧现象的，要严格追究相关人员的责任。

（二）各相关单位和村（居）委会要高度重视，认真落实秸秆、垃圾禁烧的工作部署。

（三）根据《三亚市秸秆、垃圾禁烧工作领导小组办公室关于做好秸秆、垃圾禁烧工作的函》（三环防〔2018〕265 号）精神及区领导批示，区综合行政执法局加强巡查，对焚烧秸秆、垃圾的当事人按照相关规定进行查处及将堆放点、垃圾点的垃圾进行日产日清；区农业农村局、各村（居）委会做好禁烧宣传、堆放点的设置及收集；区住房和城乡建设局加强建设项目垃圾焚烧的监管，其他各相关部门按职责做好秸秆、垃圾禁烧工作。
