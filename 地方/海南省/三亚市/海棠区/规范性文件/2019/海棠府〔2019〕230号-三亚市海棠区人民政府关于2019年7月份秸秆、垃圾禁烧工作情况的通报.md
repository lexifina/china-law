# 三亚市海棠区人民政府关于2019年7月份秸秆、垃圾禁烧工作情况的通报

三亚市海棠区人民政府

关于2019年7月份秸秆、垃圾禁烧工作情况的通报

各相关单位、各村（居）委会：

近段时间，中央第三生态环境督察组下沉我市开展环保督察，我区启动海棠区秸秆、垃圾禁烧工作管理应急预案，安排部署秸秆、垃圾禁烧专项巡查行动，各片区网格员实时监督巡查。经统计，我区在2019年7月份发现处理秸秆、垃圾焚烧现象共3起,疑似火情6起。

7、8月份是海南的农忙季节，是村民焚烧秸秆的高发时期。一是各相关单位和村（居）委会要高度重视，认真落实秸秆、垃圾禁烧的工作部署，加大秸秆、垃圾禁烧入户宣传和巡查监管力度，从源头上避免焚烧秸秆、垃圾的行为；二是要将防控工作的各项措施、责任落实到位，加强检查，确保全区“不烧一把火，不冒一处烟”；三是要做好秸秆、垃圾的收集和清运工作。由于工作责任制不落实、工作措施落实不到位等原因造成严重火情的，要严格追究相关人员的责任。

附件：2019年1月至7月各村（居）委会焚烧秸秆、垃圾汇总表

三亚市海棠区人民政府

2019年8月1日
