# 三亚市海棠区人民政府关于办理IC公交卡的通知

三亚市海棠区人民政府

关于办理IC公交卡的通知

各村（居）委会：

2019年9月1日原三亚一卡通运营系统将关停，为满足广大居民刷卡乘坐公交的需要，我区将为广大居民集中更新办理一批IC公交卡，请各村（居）委会对本村需要办理IC卡的居民进行一次全面统计，并将人员名单和身份证号码上报区住房和城乡建设局交通办公室（218房），办理时间为2019年8月12日—2019年9月10日，逾期不予办理。

三亚市海棠区人民政府

2019年8月13日

（此件主动公开）
