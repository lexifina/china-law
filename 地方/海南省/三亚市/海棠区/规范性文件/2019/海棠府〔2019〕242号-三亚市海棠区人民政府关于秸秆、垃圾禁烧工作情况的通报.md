# 三亚市海棠区人民政府关于秸秆、垃圾禁烧工作情况的通报

三亚市海棠区人民政府

关于秸秆、垃圾禁烧工作情况的通报

各相关单位、各村（居）委会：

近段时间，中央第三生态环境督察组下沉我市开展环保督察，我区启动海棠区秸秆、垃圾禁烧工作管理应急预案，安排部署秸秆、垃圾禁烧专项巡查行动，实时巡回监督检查。7月30日至8月11日，发现8处着火点,依据《中共三亚市委办公室 三亚市人民政府关于印发<三亚市秸秆、垃圾禁烧工作方案>的通知》（三办发〔2018〕83号）、《中共三亚市海棠区委办公室 三亚市海棠区人民政府关于印发海棠区秸秆、垃圾禁烧工作方案的通知》（海棠办发〔2019〕8号），现对巡查情况予以通报。

一、检查、巡查情况

（一）8月6日，龙楼村第2网格农田焚烧秸秆。

（二）8月7日，南田居第8网格农户焚烧垃圾。

（三）8月8日，龙楼村第2网格农田焚烧秸秆。

（四）8月9日，南田居第5网格农户焚烧垃圾。

（五）8月9日，龙海村第2网格居民焚烧垃圾。

（六）8月10日，南田居第10网格公路旁焚烧垃圾。

（七）8月10日，龙楼村第2网格农田焚烧秸秆。

（八）8月11日，龙楼村第2网格农田焚烧秸秆。

二、更正说明

因上次通报中着火点属地交叉错乱，导致7月23日、7月25日、7月29日火点属地核实有误，经再次核实后火点属地分别归属为：龙楼村第2网格、无法核实、龙楼村龙楼岭芒果地。

三、工作要求

（一）近段时间在秸秆、垃圾禁烧工作中南田居、龙楼村焚烧现象高发，尤其是龙楼村第2网格在本周内焚烧现象高达4起。龙楼村第1、2网格位处于高铁桥附近，属于重点监管路段。望南田居民委员会、龙楼村主要负责人、网格员要引起高度重视，加强巡查、监管力度，对于工作中存在的问题做出相应解决措施。

（二）中央环保督察期间，各村（居）委会要高度重视中央生态环境保护督察，做好禁烧工作。在焚烧现象高发的时间段安排专人实时巡查、处理焚烧情况。

（三）八月份是农忙时期，村民焚烧秸秆现象高发，秸秆堆放于田地里存在焚烧隐患，区农业农村局应做好秸秆堆放点的合理设置，将堆放点的秸秆及时清运。区综合行政执法局加强巡查，对焚烧秸秆的当事人按照相关规定进行查处。其他各相关部门按职责做好秸秆、垃圾禁烧工作。

（四）各相关工作人员要认真负责，不互相推脱工作，主动发现问题、解决问题，切实把管控工作落到实处，认真落实秸秆、垃圾禁烧的工作部署。
