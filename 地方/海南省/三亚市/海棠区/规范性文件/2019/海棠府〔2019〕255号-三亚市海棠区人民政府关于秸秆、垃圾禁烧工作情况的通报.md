# 三亚市海棠区人民政府关于秸秆、垃圾禁烧工作情况的通报

三亚市海棠区人民政府

关于秸秆、垃圾禁烧工作情况的通报

各相关单位、各村（居）委会：

为切实做好空气质量保障工作，深入推进“秸秆、垃圾禁烧”方案实施，坚决杜绝各类露天焚烧现象发生，安排部署秸秆、垃圾禁烧专项巡查行动，实时巡回监督检查。8月17日至8月23日，发现5处着火点。依据《中共三亚市委办公室 三亚市人民政府关于印发<三亚市秸秆、垃圾禁烧工作方案>的通知》（三办发〔2018〕83号）、《中共三亚市海棠区委办公室 三亚市海棠区人民政府关于印发海棠区秸秆、垃圾禁烧工作方案的通知》（海棠办发〔2019〕8号），现对巡查情况予以通报。

一、检查、巡查情况

（一）8月17日，藤桥村第二网格四组芒果地焚烧垃圾。

（二）8月18日，三亚林场树林焚烧。

（三）8月19日，营头村前进路芒果地焚烧垃圾。

（四）8月22日，龙海村芒果地焚烧垃圾。

（五）8月23日，仲田水库附近焚烧垃圾，无法核实属地。

二、工作要求

（一）8月18日，在海昌梦幻不夜城对面的海防林树林自燃，焚烧面积较大，由庄大联防员和119消防员现场扑灭火情。8月21日，由区生态环境局牵头，区农业农村局、庄大村联防员和网格员、三灶村网格员配合到现场核实，经查实此处林地归属三亚林场，由区农业农村局监管。针对此次情况，望三亚林场和区农业农村局引起高度重视，加强对海防林的巡查、监管力度。

（二）8月23日，仲田水库附近焚烧垃圾，无法核实着火点。8月27日由区生态环境局牵头，区综合行政执法局配合到现场核实，查明该地无归属单位，焚烧垃圾的居民属于北山村村民、居住在仲田水库附近，该地周围未设置垃圾堆放点、垃圾无人清运。针对此次情况，望北山村村委会加强对本村村民的教育，区海洋水务局加强对水库范围的管控，区综合行政执法局在仲田水库附近设置垃圾堆放点，对产生的垃圾日常日清。

（三）各相关工作人员要认真负责，不互相推脱工作，主动发现问题、解决问题，切实把管控工作落到实处，认真落实秸秆、垃圾禁烧的工作部署。

（四）根据《三亚市秸秆、垃圾禁烧工作领导小组办公室关于做好秸秆、垃圾禁烧工作的函》（三环防〔2018〕265号）精神及区领导批示，区综合行政执法局加强巡查，对焚烧秸秆、垃圾的当事人按照相关规定进行查处，并将堆放点、垃圾点的垃圾进行日产日清；区农业农村局、各村（居）委会做好禁烧宣传、堆放点的设置及收集；区住建局加强建设项目垃圾焚烧的监管，其他各相关部门按职责做好秸秆、垃圾禁烧工作。
