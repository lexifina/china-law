# 三亚市海棠区人民政府关于2019年8月份秸秆、垃圾禁烧工作情况的通报

三亚市海棠区人民政府

关于2019年8月份秸秆、垃圾禁烧工作情况的通报

各相关单位、各村（居）委会：

本月中央第三生态环境督察组下沉我市开展环保督察工作，世界顶级科学家三亚论坛在我区召开。我区启动海棠区秸秆、垃圾禁烧工作管理应急预案，安排部署秸秆、垃圾禁烧专项巡查行动，各片区网格员实时监督巡查，区生态环境局安排工作人员轮流值班查看秸秆焚烧预警监控平台，发现焚烧情况后第一时间通知相关单位进行处理。经统计，我区在2019年8月份发现处理秸秆、垃圾焚烧现象共20起，其中焚烧秸秆9起，焚烧垃圾11起。

统计数据显示下午18:00-20:00是村民焚烧秸秆、垃圾的高发时间段，各相关单位和村（居）委会应在这时间段内加强巡查，高度重视，特别是高铁桥附近的网格点要加大巡查力度，认真落实秸秆、垃圾禁烧的工作部署。加强秸秆、垃圾禁烧入户宣传和巡查监管和查处力度，从源头上避免焚烧秸秆、垃圾行为，要将防控工作的各项措施、责任落实到位，加强检查，确保全区“不烧一把火，不冒一处烟”。同时也要做好秸秆、垃圾的收集和清运工作，由于工作责任制不落实、工作措施落实不到位等原因造成严重火情的，要严格追究相关人员的责任。

附件：2019年1月至8月各村（居）委会焚烧秸秆、垃圾汇总表

三亚市海棠区人民政府
