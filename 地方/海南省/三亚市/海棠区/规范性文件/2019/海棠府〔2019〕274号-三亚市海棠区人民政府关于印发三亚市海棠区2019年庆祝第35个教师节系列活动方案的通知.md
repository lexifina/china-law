# 三亚市海棠区人民政府关于印发三亚市海棠区2019年庆祝第35个教师节系列活动方案的通知

三亚市海棠区人民政府

关于印发三亚市海棠区2019年庆祝第35个教师节系列活动方案的通知

区各相关单位：

《三亚市海棠区2019年庆祝第35个教师节系列活动方案》已经区政府同意，现印发给你们，请遵照执行。

三亚市海棠区人民政府

2019年9月18日

（此件主动公开）

三亚市海棠区2019年庆祝第35个教师节系列活动方案

为隆重庆祝我国第35个教师节，集中展现我区广大教师爱岗敬业、立德树人的精神风貌，弘扬尊师重教社会风尚，激励广大教师和教育工作者不忘初心、牢记使命，教书育人，为人师表，开拓创新，无私奉献，推动我区教育事业全面发展，我区决定于9月8日-20日开展海棠区庆祝第35个教师节系列活动。为做好此次教师节庆祝工作，特制定本活动方案。

一、活动主题

以“庆祝新中国七十华诞，弘扬新时代尊师风尚”为主题，激励广大教师以模范先进为榜样，振奋精神、扎实工作，为办好人民满意的教育作出新贡献；大力宣传人民教师教书育人的光荣事迹，展现新时期人民教师良好的精神风貌，努力营造尊重知识、尊重人才、尊重教师和关心教育、理解教育、支持教育的良好社会氛围。

为做好庆祝我国第35个教师节活动，特成立工作领导小组。

三、活动内容

（一）召开2019年庆祝第35个教师节暨表彰先进大会

我区拟定于2019年9月9日16:00（具体时间另行通知），在南田世纪大礼堂召开庆祝第35个教师节文艺表演暨表彰先进大会，热烈庆祝我国第35个教师节及对今年我区教育系统获表彰的先进单位、优秀个人进行表彰。

（二）开展主题宣传教育活动

区委宣传部、区总工会、团区委及区教育局要以“庆祝新中国七十华诞，弘扬新时代尊师风尚”为主题，大力宣传我区教育改革发展成果，展现我区先进教育工作者积极向上、奋力拼搏的精神风貌，营造尊重知识、尊重人才、尊重教师和关心教育、理解教育、支持教育的良好社会氛围。

（三）开展先进集体和先进个人宣传活动

在教师节前后，区委宣传部、区总工会、团区委、区教育局及各中小学校（幼儿园）通过报纸、公众号、校园网、校园广播、短信平台、宣传橱窗、张贴标语及微信、微博等形式对我区教育系统先进集体和教师队伍中先进典型人物进行立体式的宣传推介。

（四）组织走访慰问教师活动

教师节期间，由区教育局牵头、各相关单位配合，走访慰问教师，认真贯彻落实《教师法》，关心教师的工作、生活、学习，为教师办实事，办好事，切实帮助教师解决工作、学习和生活中的实际困难，征求对教学改革意见，共商教育发展大计。

（五）召开教师节座谈会

区教育局牵头，区财政局、区人社局等相关单位配合，组织先进学校校长，优秀教育工作者、优秀班主任、优秀教师代表和退休教师代表座谈会，认真听取广大教师对我区教育发展的意见和建议，促进我区教育事业发展。同时，倾听广大教师的心声，从解决教师的实际问题入手，主动采取措施，努力提高教师待遇，积极解决广大教师工作、生活等方面遇到的实际困难，积极开展为贫困教师送温暖等活动，切实解决教师的后顾之忧。

（六）开展庆祝教师节征文比赛

面向全区中小学生、教师、家长开展“感念恩师•老师，我想对你说”“不忘初心•我的教师梦”主题征文比赛，引导学生尊重教师、感念师恩，形成尊师重教的社会风尚，同时促进广大教师在教书育人岗位做出新的更大贡献，在全社会进一步营造尊师重教的浓厚氛围。

（七）开展社区尊师重教活动

各村（居委会）要开展以“尊师重教”为主题的社区活动，以走访学校、慰问教师、举办座谈会等形式，进一步加强社区与学校的联系，努力营造全社会尊重知识、尊重人才、尊重教师和关心教育、理解教育、支持教育的良好氛围，

（八）组织观看教师题材优秀影片

各学校自行组织教师观看《一生只为一事来》《我是班主任》等教师题材优秀影片，引导教育广大教职工爱岗敬业，无私奉献，勇于担当，不断提高教职工的思想觉悟，立德树人，促进师德师风建设，做无愧于新时代的“四有”好老师。

（九）启动实施“不忘初心、牢记使命”师德师风建设提升工程

在新学年启动实施“不忘初心、牢记使命”师德师风建设提升工程，既强化师德正面感召，引导广大教师争做“四有”好老师，又开展查处违反师德行为“亮剑”行动，对师德问题“零容忍”，营造风清气正的育人环境。同时，区教育局及相关单位、学校、幼儿园要积极为教师办实事、解难事，落实强师惠师政策，真心关爱教师，弘扬新时代尊师风尚。

四、经费保障

活动经费从2019年海棠区教育局本级预算“教师节活动”经费中支出。

五、活动要求

（一）加强领导，组织到位。此次活动时间紧，任务重，要求高，为确保各项庆祝活动达到预期效果，区教育局要成立教育系统庆祝第35个教师节活动领导小组，负责庆祝活动的组织协调工作；及时与有关部门沟通协调，努力争取各方面支持，使各级领导和广大社会了解教育、关心教育、支持教育；制订具体活动方案，组织形式多样、丰富多彩的庆祝活动，在教师节前夕掀起喜迎教师节、庆祝教师节的热潮。

（二）统筹安排，积极参与。庆祝活动要突出时代性、社会性和参与性。各单位要统筹安排，密切联系学校，主动倾听教师呼声，解决教师的实际困难，切实增强庆祝活动的影响力。

（三）思想重视，积极配合。各单位要高度重视并配合区教育局开展庆祝活动。庆祝大会当天，交警部门负责维持会场及周边交通秩序，保证会议当日交通畅通，公安部门负责做好会议安保工作；区委宣传部要积极联系新闻媒体，深入各校跟踪报道教师的先进事迹。

（四）广泛宣传，营造氛围。教师节期间，各学校要通过校园网、短信平台、宣传橱窗、张贴标语及微信、微博等形式，多方位介绍我区教育发展和改革的重要成果，多角度展示我区教师优秀群体形象和课堂教学改革成果，进一步鼓舞士气，营造良好氛围。
