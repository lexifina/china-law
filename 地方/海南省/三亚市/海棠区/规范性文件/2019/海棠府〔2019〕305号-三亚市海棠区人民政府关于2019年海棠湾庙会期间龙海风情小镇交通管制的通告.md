# 三亚市海棠区人民政府关于2019年海棠湾庙会期间龙海风情小镇交通管制的通告

三亚市海棠区人民政府

关于2019年海棠湾庙会期间龙海风情小镇 交通管制的通告

广大市民游客、商家：

由海棠区人民政府主办的2019年海棠湾庙会将于2019年10月12日9:30—22:00在龙海风情小镇内举办。

为保障庙会活动顺利开展，活动期间小镇内海棠二十八路、龙海七路、龙海八路街道禁止各类机动车辆通行及停放。请广大市民游客、商家积极配合，并于2019年10月11日20:00前,将所使用的各类车辆机动车辆驶离活动区域停放至龙海风情小镇内非活动区域或活动临时停车场（附图）。

由此带来的不便，恳请给予理解和支持。

特此通告。

三亚市海棠区人民政府

2019年10月10日
