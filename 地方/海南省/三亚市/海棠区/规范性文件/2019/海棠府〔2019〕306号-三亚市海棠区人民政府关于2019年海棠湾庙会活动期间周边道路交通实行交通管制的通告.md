# 三亚市海棠区人民政府关于2019年海棠湾庙会活动期间周边道路交通实行交通管制的通告

三亚市海棠区人民政府

关于2019年海棠湾庙会活动期间周边道路交通实行交通管制的通告

广大市民游客：

2019海棠湾庙会活动将于10月12日9:30-22:00在龙海风情小镇举办。为确保庙会活动期间的道路交通安全和交通秩序，根据《中华人民共和国道路交通安全法》的有关规定，三亚市公安局交通警察支队海棠大队将对龙海风情小镇周边的龙海路、G223国道部分路段及龙海风情小镇海棠二十八路、龙海七路、龙海八路等路段实行交通管制，具体交通管制设置如下：

一、停车场设置和管制停车场设置

（一）1号停车场：设置在靠近国道G223（即：区政府旁侧门路段），设为电动摩托车停车位，供小镇内居民、商家和周边游客停放。

（二）2号停车场：设置在龙海风情小镇东门右侧（即：消防支队海棠大队旁），设50个停车位，6:00-18:00时段提供学生家长接送学生车辆停放，18:00-22:00用于VIP车辆停放。

（三）3号停车场：设置在龙海风情小镇西门右侧，设10辆大巴车停车位，500辆普通车辆停车位，供市民游客停放。

（四）龙海风情小镇非活动区域可根据现场实际进行停放，配合交警部门指挥和指导。

二、停车场管制

10月11日20:00前，禁止一切车辆在2号、3号停车场停放，原已停放在以上位置的车辆一律自行驶离，未按规定驶离的车辆，交警部门将予以拖离并按照《道路交通安全法》相关规定予以处罚。

三、交通管制

（一）国道G223交通管制

10月11日20:00-10月12日22:00，对国道G223（新居民路路段）龙海风情小镇北门至海棠区政府路口路段实行交通管制，禁止一切车辆在此通行。

（二）龙海路交通管制

10月11日20:00-10月12日22:00对龙海路（消防支队海棠大队路段）实行交通管制，除VIP车辆及学生家长接送车辆等相关工作车辆外，禁止一切车辆进入该路段通行。

（三）龙海风情小镇内部交通管制

10月11日20:00-10月12日22:00，对龙海风情小镇内部的龙海六路（龙海小学旁路段）、龙海七路北段与海棠十七路交叉口及龙海八路（南侧、北侧出入口）等路段实施交通管制，禁止一切车辆在此通行。

（四）龙海路、国道G223龙海风情小镇路段交通限行

10月11日20:00-10月12日22:00，限制2吨以上货运车辆从龙海路、国道G223龙海风情小镇路段通行。

交警提醒：违反本通告交通管制和限行措施的，将依照《道路交通安全法》相关规定予以处罚，对不服从交通警察指挥或阻碍交通警察依法履行职务的，将依法追究当事人相关法律责任。

三亚市海棠区人民政府
