# 三亚市海棠区人民政府关于秸秆、垃圾禁烧工作情况的通报

三亚市海棠区人民政府

关于秸秆、垃圾禁烧工作情况的通报

各相关单位、各村（居）委会：

为切实做好空气质量保障工作，深入推进“秸秆、垃圾禁烧”方案的实施，坚决杜绝各类露天焚烧现象发生，安排部署秸秆、垃圾禁烧专项巡查行动，实时巡回监督检查。9月28日至10月4日，发现3处着火点,依据《中共三亚市委办公室 三亚市人民政府办公室关于印发<三亚市秸秆、垃圾禁烧工作方案>的通知》（三办发〔2018〕83号）、《中共三亚市海棠区委办公室 三亚市海棠区人民政府办公室关于印发海棠区秸秆、垃圾禁烧工作方案的通知》（海棠办发〔2019〕8号），现对巡查情况予以通报。

一、检查、巡查情况

（一）9月28日，龙楼村焚烧秸秆，执法局工作人员扑灭。

（二）9月28日，藤桥村焚烧秸秆，执法局工作人员扑灭。

（三）10月4日，湾坡村水稻公园焚烧秸秆，村委会安排工作人员扑灭。

二、工作要求

（一）各相关工作人员要认真负责，不互相推脱工作，主动发现问题、解决问题，切实把管控工作落到实处，认真落实秸秆、垃圾禁烧的工作部署。

（二）各村（居）委会要将禁烧工作的各项措施、责任落实到位，加强检查。由于工作责任制不落实、工作措施落实不到位等原因造成焚烧现象的，要严格追究相关人员的责任。

（三）根据《三亚市秸秆、垃圾禁烧工作领导小组办公室关于做好秸秆、垃圾禁烧工作的函》（三环防〔2018〕265 号）文件精神及区领导批示，区综合行政执法局要加强巡查，按照相关规定对焚烧秸秆、垃圾的当事人进行查处，同时将堆放点、垃圾点的垃圾进行日产日清；区农业农村局、各村（居）委会要做好禁烧宣传、堆放点的设置及收集；区住建局要加强建设项目垃圾焚烧的监管，其他各相关部门按职责做好秸秆、垃圾禁烧工作。
