# 三亚市海棠区人民政府关于2019年11月份大气污染防治工作情况的通报

三亚市海棠区人民政府

关于2019年11月份大气污染防治工作情况的通报

各相关单位、各村（居）委会：

根据《三亚市海棠区人民政府办公室关于印发海棠区秸秆、垃圾禁烧工作方案的通知》（海棠办发〔2019〕8号）、《三亚市大气污染防治工作领导小组办公室关于印发三亚市打赢蓝天保卫战2019年工作要点和任务分解的通知》（三环函〔2019〕367号）、《三亚市大气污染防治工作领导小组办公室关于加强城市扬尘管理工作的函》（三环函〔2019〕448号）等文件要求及秋冬季的气候特点，我区安排部署秸秆、垃圾禁烧专项巡查行动，实时巡回监督检查。并组织相关职能部门于2019年11月25日对城市扬尘污染防治工作开展情况进行检查，现将本月秸秆、垃圾禁烧和城市扬尘检查情况通报如下：

一、总体情况

（一）做好秸秆、垃圾禁烧工作

根据区政府工作要求和区主要领导指示，我区在2019年11月份开展秸秆、垃圾禁烧工作，安排部署秸秆、垃圾禁烧专项巡查行动，各片区网格员实时监督巡查，区生态环境局安排工作人员值班查看秸秆焚烧预警监控平台，发现焚烧情况后第一时间协调相关单位进行处理。

（二）做好扬尘防治工作

1.严控道路扬尘污染

（1）强化道路降尘措施。为做好我区道路洒水降尘工作，每天早、晚两次用高压清洗车进行机械化洒水降尘作业，同时加强对重点路段洒水降尘作业次数，强化道路冲洗、洒水、降尘、吸尘，进一步提升环境卫生质量，达到路见本色，路牙及收水口无垃圾等。本月共出动805车次，对主要道路进行冲洗、除尘，用水8601吨。

（2）加强道路保洁作业。在落实清扫保洁人员“五定责任制”（定岗、定人、定时间、定地段、定责任）的基础上，按时清扫、保洁，生活垃圾日产日清。配备机械化清扫设备，对城区主干道实行机械化清扫作业，清扫作业时开启喷水降尘设备，采取湿法作业，降低道路扬尘对空气的污染。本月共清理生活及园林垃圾6861吨。

（3）加强道路巡查力度。加大路面巡查频次，严防突发道路污染案件发生。

2.严控建筑工地扬尘污染

加强对建筑工地和混凝土公司的监管，督促建筑工地做好围挡和出入口清洁工作，把建筑工地和混凝土公司纳入“门前三包”范围。根据建筑扬尘治理管理制度和工程技术规程，在建筑工地管理中落实施工现场管理“六必须”、“六不准”，即必须湿法作业、必须打围作业、必须硬化道路、必须设置冲洗设施、必须配齐洁保人员、必须定时清扫施工现场；不准车辆带泥出门、不准运渣车辆冒顶装载、不准高空抛洒建渣、不准现场搅拌混凝土、不准场地积水、不准现场焚烧废弃物，有效遏制建筑扬尘污染。本月日常巡查工地、混凝土搅拌站共出动 45人次，检查15家施工单位。

二、巡查问题情况

（一）秸秆、垃圾禁烧问题

经统计，我区在2019年11月份发现处理秸秆、垃圾焚烧现象共6起，其中焚烧秸秆3起，焚烧垃圾3起：

1.11月3日龙楼村焚烧秸秆，区综合行政执法局工作人员现场扑灭。

2.11月7日龙海村焚烧垃圾，区综合行政执法局工作人员现场核实。

3.11月7日东溪村焚烧垃圾，区综合行政执法局工作人员现场核实。

4.11月16日青田村小学对面100米田地焚烧秸秆，区综合行政执法局工作人员现场核实。

5.11月16日青田村水厂对面200米田地焚烧秸秆，村委会工作人员现场核实。

6.11月16日铁炉村峰鑫搅拌站对面焚烧垃圾，区综合行政执法局工作人员现场核实。

（二）扬尘污染防治问题

1.经检查的五家建筑工地都未完全落实“六个100％”措施，主要存在以下问题：

（1）三亚海棠湾太平国际医疗康养项目工程进出口未设置冲洗装置，带泥上路；施工道路无硬化；渣土覆盖不规范；黄土裸露无覆盖。

（2）天房海棠墅项目工程生活垃圾和厨余垃圾乱堆乱放；施工道路积土过多；渣土堆覆盖不规范（绿网网目过大）；渣土堆无围挡、无覆盖；场内未设置洒水、喷淋装置。

（3）保利C+国际博览中心项目工程施工道路积土；装修垃圾无围挡、无覆盖；渣土覆盖不规范；场内未设置洒水、喷淋装置。

（4）海棠湾恒大国际医院（F-3-2地块）主体及配套建设工程生活垃圾乱堆乱放；施工道路未做降尘处理。

（5）三亚国美酒店项目工程渣土无围挡、无覆盖；施工道路积土。

2.上期整改情况

针对上期检查中发现的问题，我办抽取3家工地进行回头看检查。

（1）三亚国美酒店工程项目渣土无围挡、无覆盖，施工道路积土。上期建筑垃圾无围挡、无覆盖等问题已整改。

（2）天房海棠墅项目工程生活垃圾乱堆乱放，无围挡、无覆盖；施工道路积土过多；渣土堆无围挡、无覆盖或渣土堆覆盖不规范（滤网网目过大），无喷淋设施等问题均未整改。

（3）三亚海棠湾恒大国际医院（F-3-2地块）工程项目生活垃圾乱堆乱放，施工道路未做降尘处理等问题均未整改。

三、工作要求

（一）禁烧工作要求

1.应急状态下，启动《海棠区秸秆、垃圾禁烧工作管理应急预案》。下发应急启动指令，统筹指挥全区应急工作，部署应急响应范围内网格片长、网格长和网格员的工作。区应急联动中心负责转办和协调相关投诉、举报信息的办理工作，并及时反馈处理结果。启动应急预案时，各相关工作人员要按照各自职责分工，到指定的位置，开展监控管控工作，确保特殊时段在重点区域无焚烧现象。建立海棠区秸秆、垃圾禁烧工作群，及时沟通信息，联络和反馈工作，实现高效巡查与管控。构建预防为主、防灭结合、快速反应的管理与应急处理机制。

2.统计数据显示：下午18:00-20:00是村民焚烧秸秆、垃圾的高发时间段。各相关单位和村（居）委会要高度重视，在该时间段内加强巡查，特别是高铁桥附近的网格点要加大巡查力度，认真落实秸秆、垃圾禁烧的工作部署。

3.加强秸秆、垃圾禁烧入户宣传和巡查监管及查处力度，从源头上避免焚烧秸秆、垃圾行为，要将防控工作的各项措施、责任落实到位，加强检查，确保全区“不烧一把火，不冒一处烟”。

4.做好秸秆、垃圾的收集和清运工作，由于工作责任制不落实、工作措施落实不到位等原因造成严重火情的，要严格追究相关人员的责任。

（二）扬尘防治要求

1.加强对建设项目的监管，按照《三亚市大气污染防治工作领导小组办公室关于印发三亚市打赢蓝天保卫战2019年工作要点和任务分解的通知》（三环函〔2019〕367号）的要求，监督项目在建工地建设单位、施工单位、监理单位确实履行防尘治理责任，加强对全区的建设项目施工工地检查，发现扬尘问题及时督促相关责任单位整改。

2.加强对道路扬尘的执法检查力度，对违反规定的运输车辆及企业依法进行查处，加强道路清扫、洒水降尘的管理工作，针对季节特点对扬尘进行治理。

3.加强对建设项目建筑垃圾、生活垃圾乱堆乱放，不及时清运、焚烧垃圾等问题的查处。
