# 三亚市海棠区人民政府关于印发三亚市海棠区2019年财政专项扶贫资金安排方案的通知

三亚市海棠区人民政府

关于印发三亚市海棠区2019年财政专项扶贫资金安排方案的通知

各有关单位：

《三亚市海棠区2019年财政专项扶贫资金安排方案》已经区政府同意，现予以印发，请认真贯彻执行。

特此通知。

三亚市海棠区人民政府

2019年3月21日

（此件主动公开）

三亚市海棠区2019年财政专项扶贫资金

安排方案

为贯彻落实党的十九大精神和全国经济工作会议、全国农村工作会议、省农村工作会议精神、市扶贫办指示，统筹推进我区2019年脱贫攻坚工作，根据区脱贫攻坚领导小组要求，现将我区2019年财政扶贫资金安排如下：

一、资金来源

根据三亚市财政局《关于下达2018年市级财政专项扶贫资金的通知》（三财农〔2019〕20号）文件下达我区2019年市级财政专项扶贫资金10万元。

二、使用范围

依据“精准、规范、安全、有效”的原则，财政专项扶贫资金使用向扎实推进精准施策、聚焦脱贫攻坚、开展扶贫领域腐败和作风问题专项治理、扶贫与扶志扶智相结合、强化驻村帮扶、完善大扶贫格局、做好宣传培训等重点工作。

三、资金安排及建设内容

（一）产业发展类投入8万元。主要用于根据地域特色发展效益高、惠及贫困户广的特色产业扶持项目，鼓励南田居脱贫户发展种养产业，提高巩固提升户的“造血”功能。产业扶贫资金原则上按每人1600元标准投入，可根据实际情况作适当调整（部分无产业巩固提升户的产业扶贫资金向有产业、产业量大的巩固提升户倾斜）。

（二）扶贫培训类投入2万元。主要用于开展扶贫方面的种养殖类技术培训、工作培训等扶贫类培训，印刷培训教材，租赁培训场地等。

四、资金的管理使用

区财政、审计、纪检部门加强资金管理监督，资金使用部门须严格按照《海南省人民政府办公厅关于印发海南省财政专项扶贫资金管理暂行办法的通知》（琼府办〔2016〕324号）、《海南省人民政府办公厅关于印发海南省扶贫项目管理暂行办法的通知》（琼府办〔2015〕165号）、《海南省扶贫物资政府采购实施暂行办法》（琼府办〔2016〕182号）和市、区有关扶贫资金管理办法等有关规定执行。
