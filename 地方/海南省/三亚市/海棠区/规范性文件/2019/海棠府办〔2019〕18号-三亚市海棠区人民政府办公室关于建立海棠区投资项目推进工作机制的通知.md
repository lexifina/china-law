# 三亚市海棠区人民政府办公室关于建立海棠区投资项目推进工作机制的通知

三亚市海棠区人民政府办公室

关于建立海棠区投资项目推进工作机制的通知

区直属各单位、驻区各单位、各投资项目业主：

为改善辖区营商环境，及时解决项目投资存在问题，加快推进项目建设，确保投资任务保质保量按时完成，现制定本工作机制。

一、强化项目主体责任机制

严格落实项目法人责任制，项目业主单位应主动协调、积极推动项目加快实施。针对区级层面的问题，需及时报请区项目责任领导协调解决。

二、建立周项目调度协调机制

建立区人民政府周调度机制，每周召开一次调度会。海棠区委副书记、区政府区长孙耿同志担任总召集人，海棠区委常委、常务副区长海斌同志担任召集人，成员为区直属及驻区各相关单位。经总召集人、召集人委托，海棠区人民政府各副区长可以组织召开周调度会。调度会参加单位根据需要进行确定。

区人民政府周调度机制办公室设在区发展和改革委员会（联系人：朱玉萍、林竹，电话：0898-38888033、传真：0898-38888035、电子邮箱：httz12345@126.com），负责收集项目存在问题、拟定会议方案、准备协调会议材料，跟踪、定期通报问题解决情况等。

三、实行分层级协调机制

（一）区人民政府。每周召开项目调度协调会，协调需区人民政府层面统筹解决事项。

（二）区发改委。负责梳理汇总项目业主解决不了的问题及项目单位提出问题事项，征求部门意见或组织会议协调。难以协调解决的，分类呈报区人民政府专题研究。

（三）项目推进相关单位。根据职能分工，及时解决项目推进存在问题；督促各投资项目业主，加快开展相关工作，确保投资项目又快又好建设。

区人民政府分管领导按照责任分工，督促项目推进并召集相关部门研究解决相关问题。需协调中央、省、市相关部门的，由分管区领导实时对接处理。

四、建立适时联系机制

（一）建立微信群，完善联系方式。区发改委牵头建立联系人微信工作群，由区三套班子、政协联络组领导指定的联系人，区委办、区政府办、区旅游文体局、区生态环境局、区农业农村局、区财政局、区教育局、区卫健委、区民政局、区住建局、区海洋水务局、区项目推进服务中心、海棠国土分局、海棠规划分局、海棠湾开发公司等指定的专人组成。

（二）建立投资项目12345问题工单处理及跟踪机制。一是建立问题处理工单制度，明确责任主体和办理时限；二是根据项目工作开展，针对项目推进存在问题进行分项目、分种类、分责任实施单位，编制问题处理工单落实情况汇总表；三是建立项目推进存在问题通报制度，确保项目存在问题不解决不收工。

五、建立周报月报机制

各单位、项目业主每周五向区人民政府周调度机制办公室报送相关情况。其中：区项目推进服务中心提供征地拆迁完成情况；区委办公室、区政府办公室提供各级领导有关项目推进调研、会议、文件批示及相关要求等情况；政府投资项目业主、省市重点投资等项目单位提供项目存在问题和解决进展情况；各项目推进责任单位，根据区人民政府周调度机制办公室派送问题处理工单事项，提供存在问题解决进展情况。

区发改委综合项目推进和存在问题解决情况，每周一18：00前将上一周工作进展情况编制简报，报区三套班子领导、政协联络组、市现代服务业产业园管委会领导班子，并抄送各相关单位。

区发改委每月通报上个月的投资完成情况和项目推进情况。未按时落实存在问题的，由区委办公室、区政府办公室进行督办处理。
