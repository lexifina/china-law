# 三亚市海棠区人民政府办公室关于开设区级部门信息公开专栏的通知

三亚市海棠区人民政府办公室

关于开设区级部门信息公开专栏的通知

区政府各部门：

为进一步加强和规范我区政府部门机构信息公开工作，根据市政府办公室《关于做好机构信息公开工作的通知》精神，原则上各部门均需开设信息公开专栏，并按照《中华人民共和国政府信息公开条例》（国务院令711号）及《海南省2019年政务公开要点》要求，及时公开本部门的脱密信息。请参照《区政府部门政府信息公开基本目录（参考）》，在7月12日18：00前以正式文件上报本部门信息公开拟开设目录、负责人员名单及联系方式至我办，由我办统计后向市政府办申请开设。如不需开设，也请以正式文件向我办说明原因。

附件：区政府部门政府信息公开基本目录（参考）

三亚市海棠区人民政府办公室
