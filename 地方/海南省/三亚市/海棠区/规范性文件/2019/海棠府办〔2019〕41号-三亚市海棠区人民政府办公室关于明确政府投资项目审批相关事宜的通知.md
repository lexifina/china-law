# 三亚市海棠区人民政府办公室关于明确政府投资项目审批相关事宜的通知

三亚市海棠区人民政府办公室

关于明确政府投资项目审批相关事宜的通知

各相关单位：

根据《政府投资条例》（国务院令第712号）、《必须招标的工程项目规定》（国家发改委第16号令）（以下简称“政府投资条例”）、《三亚市人民政府关于印发三亚市政府投资项目管理规定的通知》（三府〔2013〕112号）（以下简称“政府投资项目管理规定”）、《三亚市人民政府关于印发政府投资建设项目设计变更管理规定的通知》（三府〔2018〕104号）（以下简称“项目设计变更管理规定”）等文件精神，为优化审批流程，提高投资项目推进速度，特明确政府投资项目审批相关事宜如下：

一、根据《政府投资条例》第二条、第九条相关内容，明确需立项、可研、初步设计概算审批的项目为“使用各级政府财政预算，投资新建、扩建、改建、技术改造等进行房建、设备采购安装、水利、交通、能源、园林绿化、城市亮化、五网基础设施等固定资产投资建设项目”。

二、根据《政府投资条例》精神，结合投资项目招投标管控，总投资小于400万元（不含400万元）的固定资产投资项目，建设资金已经落实，或区政府已确认启动，其相应资金安排及启动文件（含会议纪要）视为项目立项批复，项目业主持以上文件，根据相关行业主管部门要求，直接开展后续手续办理工作，并在确保资金已落实情况下开工建设。

三、根据《项目设计变更管理规定》第三条内容，政府投资建设项目设计变更批复，是指项目业主在已批复的施工图设计基础上（在投资主管部门具体体现为项目初步设计批复），因《项目设计变更管理规定》第七条所列原因，需对原设计批复进行变更的，应按《项目设计变更管理规定》流程进行审批。根据《政府投资条例》第十三条第三款内容，针对总投资小于500万元而前期未办理初步设计批复的项目，由项目业主在不超过原有资金安排、不减小规模、不降低使用功能及质量基础上，自行组织调整，并按财政部门要求组织财评。针对超过原有资金安排的项目，应按建设资金追加相关程序办理。

三亚市海棠区人民政府办公室
