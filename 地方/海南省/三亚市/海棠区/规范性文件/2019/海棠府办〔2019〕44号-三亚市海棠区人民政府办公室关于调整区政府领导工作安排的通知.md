# 三亚市海棠区人民政府办公室关于调整区政府领导工作安排的通知

三亚市海棠区人民政府办公室

关于调整区政府领导工作安排的通知

区政府各单位，各村（居）委会：

因区政府领导人事变动及工作需要，根据二届区政府党组第43次会议议定，现将调整的区政府领导工作安排通知如下：

海斌副区长 负责项目推进服务等方面工作；

分管区项目推进服务中心工作。

王蓓副区长 负责自由贸易港制度建设、外事、海防等方面工作；

分管区政府办公室（区外事办公室、区海防办公室）、区推进自由贸易港建设办公室工作。

杨清安副调研员 协助区长分管区卫生健康委员会（区爱国卫生运动委员会办公室）、区商务和金融发展局（区口岸办公室、区会展局、区投资促进局）、区医疗保障局、区信息化服务中心、区档案管理中心工作。

其他区政府领导工作安排按海棠府办〔2019〕14号文件执行。

三亚市海棠区人民政府办公室

2019年10月21日
