# 三亚市人民政府办公室关于印发成立三亚市尘肺病防治攻坚行动工作领导小组的通知

三亚市人民政府办公室

关于印发成立三亚市尘肺病防治攻坚行动

工作领导小组的通知

市各相关单位：

为加强我市尘肺病防治工作的组织领导和统筹协调，提高我市尘肺病防治能力，促进职业健康工作发展，经市政府同意，决定成立三亚市尘肺病防治攻坚行动工作领导小组。现将有关事项通知如下：

一、主要职责

贯彻落实省委、省政府和市委、市政府关于尘肺病防治攻坚行动的重大决策部署；统筹协调解决全市尘肺病防治工作重点、难点问题；研究审议尘肺病防治各项措施；督促检查尘肺病防治工作有关法律法规和政策措施的落实情况、各区政府、育才生态区管委会和各部门任务完成情况；完成市委、市政府交办的其他事项。

三、其他事项

（一）领导小组办公室设在市卫生健康委员会，承担领导小组日常工作。办公室主任由市卫生健康委员会副主任郑通勤同志兼任，办公室成员由领导小组成员单位有关分管负责同志担任。领导小组成员因工作和职务变动不再担任成员的，由继任者接替，不再另行发文。

（二）领导小组及办公室不刻制印章，不对外正式行文，全市尘肺病防治攻坚行动任务完成后自动撤销。

（三）各区政府、育才生态区管委会要成立相应尘肺病防治攻坚行动推进机构，加强尘肺病防治工作的组织领导，切实提高尘肺病防治能力。
