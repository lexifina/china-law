# 三亚市人民政府办公室关于印发《三亚市“无废城市”建设试点宣传方案》的通知

三亚市人民政府办公室

关于印发《三亚市“无废城市”建设试点宣传

方案》的通知

各区人民政府，育才生态区管委会，市各有关单位:

《三亚市“无废城市”建设试点宣传方案》已经市政府同意，现印发给你们，请认真贯彻执行。

三亚市人民政府办公室

2020年5月12日

（此件主动公开）

三亚市“无废城市”建设试点宣传方案

“无废城市”建设试点是三亚市深入贯彻习近平生态文明思想和全国生态环境保护大会精神，认真落实党中央、国务院固体废物管理战略部署的重要举措，是建设生态文明示范区、中国特色自由贸易港的重要抓手，是促进城市固体废物精细化管理的有效平台，也是推动形成绿色生活和消费方式，促进城市生活垃圾源头减量、构建生态文明的旅游文化和打造“无废城市”建设宣传窗口城市的具体行动。本着“面向公众，面向基层，注重创新、注重实效”的原则，本方案将充分利用各类宣传渠道，通过平面海报、户外广告、新媒体产品传播、市民线上线下活动等多元化方式，搭建全媒体立体传播框架，充分呈现新时代三亚在固体废物环境管理等方面的新成绩和新面貌，切实提高“无废城市”建设的群众参与度和满意度。同时，发挥各级部门优势，构筑起以各职能部门为横轴，各级政府机构为纵轴的矩阵式宣传体系，在全市营造三亚“无废城市”建设的氛围，全面发动社会各界助力“无废城市”建设试点取得圆满成功。

一、宣传目标

聚焦“无废城市”主题，对照“无废城市”建设试点任务清单，逐条解读，逐条策划，做好针对性宣传报道，一是展示三亚在创新“无废城市”建设过程的阶段性成效、典型案例、新举措、新亮点等；二是全面提高公众对“无废城市”建设工作的知晓率、支持率、参与率和满意率；三是创建“无废”旅游文化，打造“无废城市”建设的宣传窗口城市。

二、宣传时间

“无废城市”建设试点期间。

三、宣传内容

（一）实施方案宣传。围绕三亚市“无废城市”建设试点工作任务，广泛宣传“无废城市”建设内涵、工作目标、工作任务，传达党中央、国务院，省委、省政府，市委、市政府关于“无废城市”建设的重要指示精神和有关重要工作部署。

（二）基础性材料宣传。印刷“无废城市”建设宣传科普手册、海报、宣传标语，推广宣传短片。在市政府政务服务中心电子屏幕滚动宣传标语，明显区域摆放宣传册、宣传画报。在机场、码头、车站、景区的电子屏幕、灯箱播放宣传画面、宣传短片，利用宣传板张贴宣传海报，在明显区域发放三亚“无废城市”建设游客指南等宣传册。在各社区、学校、酒店、商场、文化广场等场所发放“无废城市”建设市民指导手册等宣传册，张贴宣传标语、宣传画报，播放宣传短片。在公交车等移动载体播放宣传短片。在公交车、出租车等车身悬挂宣传标语。在全市主要交通干道、公交车亭、人行天桥、旅游景点等地方，充分利用电子显示屏、LED屏等媒介，不定时播放宣传标语、宣传短片；利用灯箱广告、建筑围档、道路隔离带等载体悬挂宣传海报，大力营造三亚“无废城市”建设试点工作的氛围，提高群众知晓率和支持率，动员全社会以实际行动参与创建工作。

（三）酒店宣传。酒店大厅摆放“无废城市”建设游客指南手册，并通过酒店广告牌、客房电视界面等，播放宣传标语；推动智能无纸化入住、不主动提供一次性洗漱用品、使用全生物降解塑料制品等举措，倡导“无废城市”建设试点和绿色行动；餐饮区域，摆放“光盘行动”“垃圾分类”等标语，倡导餐饮垃圾高质回收；开展生活垃圾分类、废物再利用等环保主题活动。组织开展专题培训和评定嘉奖活动，将“无废城市”建设内涵、举措融入酒店企业文化和实际行动。

（四）旅游景区宣传。在旅游景区张贴宣传标语、宣传海报，发放“无废城市”建设游客指南，播放宣传片。组织开展专题培训，将“无废城市”建设内涵，生活垃圾分类、禁塑等“无废”举措融入景区建设发展规划。总结景区“无废”理念和举措，融入导游解说词，倡导游客树立环保理念。面向游客打造“无废城市”建设场景，开展寓教于乐的多形式环保教育宣传活动。

（五）商场宣传。在三亚免税店等大型商场，张贴宣传标语、宣传海报，发放“无废城市”建设游客指南。结合商场减少过度包装，禁止销售和使用列入禁止名录的一次性不可降解塑料袋、塑料餐具，提供可重复使用的环保购物袋，优先使用绿色快递包装等举措，强化绿色消费引导。

（六）学校、社区宣传。在学校、社区张贴宣传标语、宣传海报，发放宣传册。将生活垃圾分类、废物再利用、禁止销售和使用一次性不可降解塑料制品等“无废”理念融入教学计划和教师培训内容，组织废物减量和再利用创意评选、环保设施开放、趣味环保知识竞赛、“无废”课堂等专题活动。组织开展生活垃圾分类等“无废城市”理念进社区活动。

（七）会展、赛事宣传。在大型会展、赛事中播放宣传片，张贴海报，增加“无废”主题宣传活动，大型会展、赛事等活动需落实生活垃圾分类、禁止使用列入禁止名录的一次性不可降解塑料袋、塑料餐具等“无废”举措。

（八）手机短信宣传。充分利用短信平台，在重要节点向全市和入岛游客手机发送1条“无废城市”创建宣传标语，使手机成为“无废城市”创建的快捷通道。

（九）政府官网宣传。各相关单位结合自身“无废城市”建设试点工作实际，在官网、公众号等平台及时宣传“无废城市”创建工作动态和成效、亮点等，组织开展“无废城市”宣传月活动，全年应不少于3篇工作动态。

（十）媒体宣传。邀请环境保护杂志社、海南在线、三亚日报等电视、电台、报纸媒体跟踪报道，通过媒体专栏、新媒体、自媒体平台等方式扩大宣传。

四、责任分工

（一）市生态环境局：全面统筹策划“无废城市”创建宣传工作，推动各相关单位开展宣传，定期收集各职能部门“无废城市”建设情况，上报“无废城市”建设进展、数据和典型案例，开展一批形式多样、内容丰富的主题宣传活动，通过媒体专栏、新媒体平台等方式扩大宣传，构建国际交流对话平台，举办“无废城市”国际论坛或培训活动。

（二）市住房城乡建设局：牵头推进生活垃圾分类进机关、进社区、进校园等工作，宣传生活垃圾减量、垃圾分类回收等市民参与“无废城市”创建的行为，印制系列宣传海报，增加“无废城市”建设主题，在各社区等公示栏张贴，并在小区、企事业单位、公共文化场所等区域进行精准传播。牵头推进建筑废物宣传进工地等工作，宣传绿色建筑设计、装配式建筑应用、建筑废物治理等内容，推动建筑废物高质资源化利用。牵头推进循环经济产业园的工业旅游示范、生活垃圾环保教育基地等创建及宣传工作。

（三）市旅游和文化广电体育局：会同市交通运输局、市商务局打造从机场到码头、到景区、到酒店、到商场的“无废城市”建设第一印象区，通过广告标语、宣传册、多媒体等，多语言、多途径、广泛宣传“无废城市”建设的内涵、创新举措、行为准则等，提高“无废城市”的社会知晓度和参与度。面向市民、游客的“微信公众号”中增加“无废城市”相关内容和绿色行为的环保币奖励。将“无废城市”建设试点内容和要求纳入全市旅游标准化学习培训。牵头推进“无废旅游景区”“无废酒店”的创建及宣传工作。

（四）市农业农村局：牵头推进农业废弃物治理宣传进农村、进农田等工作，打造一批绿色无公害生态农业示范基地，做好农用地膜、农药包装物回收管理，总结农业废弃物收运处置体系等方面的经验做法。推进休闲农业旅游项目建设，引导公众践行简约适度、绿色低碳的生活方式。

（五）市商务局：牵头推进再生资源宣传进废品回收站、再生资源利用企业等工作；推进绿色商场的创建和宣传工作；推进再生资源环保教育基地建设。

（六）市教育局：牵头创建绿色校园，开展环保教育进课堂活动，将生活垃圾分类、废物再利用等“无废”理念融入教学计划、展览、知识竞赛等，定期组织环保教育基地参观学习，培养学生对“无废城市”建设的认同感和参与感。

（七）各区政府、育才生态区管委会：统筹推进辖区“无废城市”建设工作，具体承担市直各单位宣传海报、宣传短片等进街道、进社区工作，支持开展无废社区、无废旅游景区的宣传引导。

（八）其他部门：按照实施方案的任务分工，细化工作安排，落实责任部门，明确工作责任人员，开展特色宣传。

五、工作要求

（一）明确责任人

各责任单位安排一名责任人全程跟进宣传工作，按时报送宣传工作情况，开展宣传效果调查，及时总结经验，提高宣传工作效果。

（二）紧密协调配合

各有关单位要按照分工，密切配合，切实抓好各自领域的宣传和组织工作。充分运用多种宣传载体和形式，积极开展喜闻乐见的宣传活动，争取社会公众广泛认同和支持，共同参与和推动三亚“无废城市”建设试点工作。

（三）保障工作经费

各责任单位要安排工作经费，用于三亚“无废城市”建设试点工作的宣传，积极调动并充分利用社会力量。要注重宣传方式、载体、内容的创新与优化，注重日常动态宣传与集中重点宣传的结合，力求宣传工作取得实效。
