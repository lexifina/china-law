# 三亚市发展和改革委员会2012年党风廉政建设和反腐败工作实施方案

为贯彻落实十七届中央纪委七次全会、省纪委五届七次全会、市纪委六届二次全会精神，根据《三亚市2012年党风廉政建设和反腐败工作实施意见》（三办发[2012]17号）精神，结合工作职责，特制定我委2012年党风廉政建设和反腐败工作实施方案。

一、加强反腐倡廉教育，筑牢党员干部拒腐防变的思想基础

（一）深入开展党风党纪教育。组织广大党员干部认真学习中共中央国务院新修订的《关于实行党风廉政建设责任制的规定》以及中共中央办公厅、国务院办公厅《关于领导干部报告个人有关事项的规定》和《关于对配偶子女均已移居国（境）外的国家工作人员加强管理的暂行规定》等法规，深刻领会精神实质，熟悉掌握具体内容，认真抓好贯彻落实。

（二）大力加强反腐倡廉宣传教育。结合发改工作特点，按照岗位类别，有针对性地开展好警示教育、示范教育、岗位廉政教育，引导党员干部加强思想道德修养。继续抓好《廉政准则》的学习和贯彻执行，严格遵守“八个禁止五十二个不准”的规定，加强对《廉政准则》执行情况的督导检查。

二、建立健全规章制度，加强对权力运行的监督制约

（一）坚持反腐倡廉教育制度。坚持和完善党组中心组学习，主要负责同志定期讲廉政党课等制度；建立健全党性定期分析、反腐倡廉专题民主生活会等制度；完善示范教育、警示教育、岗位廉政教育等制度。

（二）建立党风廉政建设责任制。坚持和完善反腐败领导体制和工作机制。领导班子按照责任分工，一把手负总责，对重要工作和重大问题亲自部署、过问、协调和督办，领导班子其他成员要抓好自己职责范围内的反腐倡廉建设。适时召开专题工作会议，及时掌握落实情况，切实解决突出问题。坚持执行《党风廉政建设责任书》制度，把党风廉政建设与业务工作共同部署、落实、督促、考核，并把检查考核结果作为对干部职工奖励惩处、选拔任用的重要依据。

（三）完善权力运行监督机制。全面实行党务公开、政务公开。认真执行党政领导干部选拔任用工作有关规定，进一步匡正选人用人风气。继续抓好“三重一大”规定的落实，进一步界定细化“三重一大”事项范围，明确运行程序及监督和责任追究办法，保证决策的科学化、民主化。

（四）健全机关效能建设制度。认真落实机关效能建设相关制度，促进岗位责任制、服务承诺制、限时办结制、责任追究制的落实，特别要加大治理庸懒散力度，以治庸提能力、以治懒增效率、以治散正风气。完善绩效评估的指标体系和方法，强化结果的运用，发挥绩效管理的导向作用。加大领导干部问责力度，加强对党员干部履职情况的监督检查，使领导干部真正理解权力就是责任、干部就是公仆、领导就是服务。

（五）坚持政务公开制度。做到政务、政策、办事程序和办事结果公开。重点公开人民群众普遍关心、涉及人民群众切身利益的各类事项。拓宽群众参与党风廉政建设和反腐败工作的渠道，增加透明度，促进“阳光作业”。

三、认真履行工作职责，坚决落实《实施意见》所部署的任务

认真贯彻执行《建立健全惩治和预防腐败体系2008-2012年工作规划》和《三亚市2012年党风廉政建设和反腐败工作实施意见》部署的工作任务，结合我委工作实际，坚持“标本兼治、综合治理、惩防并举、注重预防”的工作方针，将《实施意见》中我委牵头的4项、协办的12项工作任务分解到各责任领导和责任科室，使反腐倡廉工作任务落实到实处。

（一）加强对重大政策措施和项目建设情况的监督检查。重点检查加快开发建设、产业振兴等重大政策措施和重大项目建设的实施情况，促进“科学规划年”和“项目建设年”活动顺利开展。

（二）从严控制党政机关办公楼等楼堂馆所建设。严格审批程序和建设标准，严格控制房屋面积和工程造价，严禁违规改变房屋使用性质，严肃查处各种违规建设行为。

（三）做好深化投资体制改革工作。进一步完善和落实企业投资核准制度，防止项目审批中的腐败行为。健全完善政府投资项目后评价与公示制度，提高项目决策科学化、民主化水平。

（四）深化公务用车问题专项治理。认真执行党政机关公务用车配备使用管理办法，严格配备标准，完善和落实编制管理、购置审批、经费预算管理等制度，坚决减少公车总量。抓好对违规车辆的纠正处理，把领导干部调离时违反规定随带车辆列入专项治理范围。加强日常监管，执行公车集中统一管理、回单位存放和节假日封存等制度。

（五）深入推进工程建设领域突出问题专项治理。着立解决招标投标等公共资源交易中存在的突出问题，推进全市公共资源交易市场建设。着力解决工程项目建设实施管理中存在的突出问题，严肃查办工程建设领域违法违规案件。

（六）深化和巩固“小金库”专项治理成果。加强法规制度建设、强化监督检查、堵塞财政财务和资产管理漏洞，推进治理工作制度化、规范化、常态化。

（七）配合职能部门做好反腐倡廉工作。配合市农业局加强对“三农”工作情况的监督检查；配合市纪委、市监察局加强对保障和改善民生政策落实情况的监督检查；配合市国土环境资源局做好纠正违法违规征地问题；配合市住房和城乡建设局加强房屋拆迁行为监管和加大保障性住房建设监管力度；配合市财政局严格规范各项资金管理使用和深化财税管理体制改革；配合市卫生局纠正医药购销和医疗服务中的不正之风；配合市纪委建立健全防治利益冲突制度；配合市纪委、市监察局继续治理领导干部在住房方面的不廉洁问题。
