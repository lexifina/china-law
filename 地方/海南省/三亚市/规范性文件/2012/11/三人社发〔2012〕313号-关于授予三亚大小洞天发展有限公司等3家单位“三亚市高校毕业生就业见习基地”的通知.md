# 关于授予三亚大小洞天发展有限公司等3家单位“三亚市高校毕业生就业见习基地”的通知

各有关单位：

根据市人力资源和社会保障局和市财政局联合下发的《关于切实做好2011年我市高校毕业生就业见习工作的通知》（三人社发［2011］174号）精神，结合用人单位实际情况及其提供申报就业见习基地的材料，经我局审核通过，现授予三亚大小洞天发展有限公司、三亚天域实业有限公司天域度假酒店、三亚亚龙湾开发股份有限公司亚龙湾凯莱仙人掌度假酒店3家单位“三亚市高校毕业生就业见习基地”，请以上单位按有关规定做好我市高校毕业生就业见习工作。

三亚市人力资源和社会保障局

2012年10月24日
