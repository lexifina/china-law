# 三亚市农业局关于做好当前灾后恢复生产工作的紧急通知

河东区、各镇人民政府、有关单位：

今年第23号强台风“山神”于10月27日从我市近海擦过，带来了10-12级大风和长时间强降雨。我市农业损失重大，水稻、冬季瓜菜、香蕉、芒果等农作物受到严重影响。预计受灾面积达到180913亩，为切实减轻灾害损失，迅速恢复农业生产，各相关单位要结合本地实际，抓紧落实各项抗灾救灾措施，迅速组织抗灾服务队伍，分赴灾区一线开展指导灾后恢复农业生产工作。为做好当前灾后恢复生产工作，力争将损失减少到最低限度，全面完成今冬明春生产任务，现将有关事项紧急通知如下：

一、迅速组织力量强排田间积水。各区镇尤其是崖城、凤凰等受灾严重的地方，要立即组织力量对受淹的稻田、瓜菜地等田块进行深挖沟排水，用抽水机排水，及时排掉田间积水，缩短作物受浸时间。

二、立即组织抢收晚季水稻。我市现有水稻，正值黄熟期，必须集中力量排水，并组织机械、人力进行抢收，有条件的采取烘干等措施，确保颗粒收仓。

三、冬季瓜菜要抢补种。各区镇尤其是崖城、凤凰重灾区，要坚持“能保则保、不保改种”的原则，及时组织农民开展查苗补苗，对于受灾不严重的瓜菜及时扶正植株、清洗植株叶片上的污泥、中耕、松土、培土等，加强田间管理，使其尽快恢复生长；对于因淹水时间过长而绝收的作物要抓紧开展改种、补种，建议绝收香蕉园改种一季冬季瓜菜。

四、热带水果等作物要抢管理。当前，正值冬种的关键时期，各区镇要切实加强灾后农作物管理，要做好瓜菜、香蕉、芒果等作物修剪及清理杂枝、病虫害防控、花期调控等工作，科学喷施药物，严格土壤消毒，防止病害发生蔓延，促进农作物生长。瓜菜要注意角斑病、青枯病、灰霉病等防治，芒果要注意炭疽病、细菌性黑斑病、白粉病等防治。

五、要及时抢修大棚等农业设施。各区镇要广泛发动群众尽快抓紧抢修直接影响瓜菜、水果等生产的农田设施，对水毁的大棚、农机具、水利渠道等农业生产和服务设施进行抢修，对倒塌损坏的畜禽棚舍等设施，要抓紧进行修缮和加固。

六、要组织瓜菜种子和育苗。各镇政府要尽快组织瓜菜种子，特别是豆角、苦瓜、茄子等种子供应农户，并组织专业育苗单位，安排资金，统一育苗，保证灾后群众所需种苗。

七、要注意畜禽的灾后防疫。畜牧局要组织调度消毒药品，对灾后的养殖场、屠宰场及畜栏禽舍进行严格消毒，组织力量开展动物免疫注射工作，对受灾病死的畜禽进行强制性的无害化处理同时，要加强动物检疫和屠宰场检疫工作，防止死亡畜禽和带病动物及产品进入消费市场。各级农技推广部门要加强重大农作物病虫害预报、防治工作，确保大灾之后无大疫。

三亚市农业局

2012年10月28日
