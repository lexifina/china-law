# 三亚市农业局关于报送青瓜嫁接苗需求计划的紧急通知

各镇政府、河东区管委会：

今年第23号强台风“山神”于10月27日从我市近海擦过，带来了10-12级大风和长时间强降雨。我市农业损失重大，其中冬季瓜菜受到严重影响，为切实减轻灾害损失，扶持补种冬季瓜菜，市政府补贴的青瓜嫁接苗（品种：博美5号）将在15-20天后开始出苗，原市场价1元/株，现政府每株补贴80%，售价0.2元/株（由农户负担），全市共供应140万株。请你单位于10月31日下午5：30之前将青瓜嫁接苗需求计划（需求量、供苗时间等，如还需其他种苗也一并上报。）报至我局种植业与市场信息科，逾期不报，视为无需求。

联系电话（传真）：88272632

联系人：郑文虎

附件：嫁接苗需求计划表

三亚市农业局
