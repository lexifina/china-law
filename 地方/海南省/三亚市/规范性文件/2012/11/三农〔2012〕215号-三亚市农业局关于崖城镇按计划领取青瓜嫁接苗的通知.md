# 三亚市农业局关于崖城镇按计划领取青瓜嫁接苗的通知

崖城镇人民政府：

根据《三亚市农业局关于报送青瓜嫁接苗需求计划的紧急通知》（三农〔2012〕196号），按照各镇报送需求计划，分配你镇青瓜嫁接苗（品种：博美5号）30万株。工作要求如下：

一、领取时间：11月15日至11月27日，每日上午

8:00-12:00，下午14:00-17:00。

二、领取地点：崖城良种厂。领取地点负责人：[姓名略]。

三、请你镇统筹安排需求情况，引导做好领取工作。

四、领取程序：以村委会为单位开具领取证明，农户携带村委会证明、身份证、现金（补贴后价格0.2元/株）自行前往领取。

联系单位：三亚市优质蔬菜开发中心。

联系人：张德文。

附件：1.领取日期、领取地点及日供应量

2.崖城镇村委会领取证明

三亚市农业局
