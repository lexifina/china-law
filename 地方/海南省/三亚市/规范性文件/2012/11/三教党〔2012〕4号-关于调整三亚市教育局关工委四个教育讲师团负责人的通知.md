# 关于调整三亚市教育局关工委四个教育讲师团负责人的通知

三教党〔2012〕4号

中职学校、各中学、中心学校、直属学校、民办学校及幼儿园：

为扎实深入推动爱国主义教育、法制教育、科技活动和家庭教育，经研究，决定调整三亚市教育局关工委爱国主义、法制、科技、家庭教育四个讲师团。调整后各团团长为：

爱国教育讲师团团长：占达龙

法制教育讲师团团长：高士博

科技教育讲师团团长：张文昭

家庭教育讲师团团长：张文昭

中共三亚市教育局党组

2012年11月6日
