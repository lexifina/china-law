# 转发省教育工委省教育厅党组关于全省教育系统学习贯彻党的十八大精神的通知

三教党〔2012〕5号

局机关各科室，进修学校，中职学校，各中小学，民办学校，幼儿园：

现将省委教育工委、省教育厅党组《关于全省教育系统学习贯彻党的十八大精神的通知》（琼教工委〔2012〕47号）转发给你们。各单位要把学习贯彻党的十八大精神作为当前和今后一段时期的重要政治任务来抓，按省教育工委、省教育厅党组、市教育局党组的要求，切实把党的十八大精神传达好、学习好、宣传好、贯彻好。

各单位于12月6日前，将学习传达贯彻党的十八大精神情况报局机关党委。

中共三亚市教育局党组

2012年11月30日

三亚市教育局办公室

2012年11月30日印发
