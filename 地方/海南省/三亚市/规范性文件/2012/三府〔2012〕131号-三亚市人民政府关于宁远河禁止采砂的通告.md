# 三亚市人民政府关于宁远河禁止采砂的通告

三亚市人民政府

关于宁远河禁止采砂的通告

三府〔2012〕131号

我市宁远河因过量开采，严重影响河势稳定及堤防安全。为维护宁远河的河势稳定，确保河道行洪安全及人民群众生命财产安全，促进经济社会可持续发展。依据《中华人民共和国水法》、《中华人民共和国水土保持法》、《中华人民共和国防洪法》、《中华人民共和国河道管理条例》和《海南经济特区水条例》等法律法规的有关规定，现将我市禁止在宁远河管理范围内非法采砂事宜通告如下：

一、禁止在宁远河大隆水库以下至出海口河段内非法采砂、挖石、取土。

二、凡在该河段内非法采砂作业的采（运）砂船只和采砂设备必须全部撤离，清理堆砂场并恢复原状；禁止非法采（运）砂船只和采砂设备在该河段管理范围内停泊、存放。

三、逾期不撤离的非法采（运）砂船只和采砂设备，将依法强制扣押、拆除采（运）砂船只和采砂设备、没收违法所得，并处罚款。

四、凡拒绝、阻碍执法人员依法执行公务的，依照《中华人民共和国治安管理处罚法》予以处罚；构成犯罪的，依法追究刑事责任。

五、公民如发现在该河段管理范围内有非法采砂行为的，可向三亚市水务局举报，举报电话：88264353。

六、此通告自发布之日起施行。

特此通告。

三亚市人民政府

2012年7月30日
