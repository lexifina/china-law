# 三亚市人民政府关于严禁在三亚海域违规建造和设置海上移动平台的通告

三亚市人民政府

关于严禁在三亚海域违规建造和设置

海上移动平台的通告

三府〔2012〕195号

近期在我市三亚湾等海域内，个别企业和个人非法占用海域建造和设置海上移动平台从事海上住宿、垂钓、餐饮、娱乐等经营活动，严重违反了三亚市海洋功能区划且存在较大的安全隐患。根据《中华人民共和国海域使用管理法》、《中华人民共和国海上交通安全法》等相关规定，特通告如下：

一、严禁非法占用海域建造和设置海上移动平台，危害海上交通安全。

二、自本通告发布之日起60天内，非法占用海域建造和设置的海上移动平台必须自行清除，正在非法建造的海上移动平台应立即停止建造并自行清除。

三、在规定期限内未自行清除或离开三亚海域的海上移动平台，市政府将组织相关部门依法强制清除。

四、本通告自发布之日起执行。

三亚市人民政府

2012年10月10日
