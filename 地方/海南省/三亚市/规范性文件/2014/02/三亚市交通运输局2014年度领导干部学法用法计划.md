# 三亚市交通运输局2014年度领导干部学法用法计划

为贯彻依法治国方略，推进法治政府部门建设进程，进一步培养和增强我局领导干部依法决策、依法行政、依法管理水平，特制定三亚市交通运输局2014年机关及事业单位领导干部学法用法工作计划如下：

一、指导思想

以邓小平理论和“三个代表”重要思想为指导，认真贯彻党的十八大精神，全面落实科学发展观，推进依法行政工作，加强对各级领导干部的法制教育，不断提高领导干部依法决策、依法行政、依法管理、依法办事的能力，培养和造就高素质的干部队伍，不断提高法治化管理水平，为构建平安和谐的交通运输环境提供强有力的法律保证。

二、工作目标

领导干部要牢固树立社会主义法治观念，坚持依法行政，维护法律的尊严和权威；强化领导干部依法履职和尽职尽责意识；逐步实现领导干部由提高法律意识向提高法律素质的转变；由注重依靠行政手段管理向注重运用法律手段管理的转变；不断提高领导干部学法的计划性、系统性和针对性，推进领导干部学法的规范化、制度化建设，使领导干部学法用法工作深入健康发展。

三、学习对象

交通运输局领导干部和各科室、各事业单位主要负责人。

四、时限、方法要求

（一）学习时间

领导干部全年学法不少于40学时。

（二）学习方法

集中学习与自学相结合。法规宣传科在局党组领导下具体负责本年度领导干部集中学法的组织工作，并在专门的学法笔记本上作集中学法记录。领导干部个人要自觉结合工作需要，开展法律法规自学活动。个人自学要在个人学法笔记本上作学法记录。

五、学习内容

1.《政府信息公开条例》；

2.《道路运输条例》、《道路旅客运输及客运站管理规定》、《道路货物运输及站场管理规定》、《国内水路运输管理条例》、《公路安全保护条例》、《机动车维修管理规定》、《机动车驾驶员培训管理规定》；

3.《信访条例》；

4.《行政许可法》、《行政处罚法》、《行政强制法》《行政复议法》、《国家赔偿法》；

5.《海南国际旅游岛建设发展条例》；

6.我国《刑法》中有关职务犯罪的规定及与反腐倡廉有关的法律知识；

7.《海南省行政执法过错责任追究暂行办法》。
