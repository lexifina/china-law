# 三亚市农业局关于加强我市冬季瓜菜质量安全田间监管工作的通知

河东区管委会、各镇人民政府、各国营农场：

为落实中央农村工作会议和我市“双冬”工作会议精神，进一步实施网格化监管机制，实现监管关口前移到生产田间地块，充分发挥安监员的作用，确保上市冬季瓜菜质量安全，现就全市冬季瓜菜质量安全田间监管工作事项通知如下：

一、加强田间网格化工作的组织领导

（一）加强网格化领导小组机构。为充分发挥网格化监管组织作用，在成立农业局网格化工作领导小组和办公室的同时，加设冬季瓜菜质量安全网格化应急处理中心，主任由张磊（农业技术推广服务中心副主任）担任，人员由邢增通、何志林、邢增汤组成。

（二）各区镇、国营农场落实网格责任人员。为加强瓜菜田头监管和安监员管理，各区镇、国营农场、村、农场联队都要确定一名干部做为片区网格化管理人员，做到每一网格的每一个层级都有专人监管。

（三）设立安监员责任片区组长。在镇、国营农场设立安监员责任片区组长，负责安监员的管理和日常工作。安监员责任片区组长的设立，由区、镇（国营农场）领导与农业局网格责任领导协商确定。安监员组长名单报送时间为1月15日前报农业局安监科（联系人：何志林，联系电话：88266290）。

二、加强安监员的田头监管工作

（一）明确安监员工作时间

从2014年1月至6月，安监员工作时间为每天上午8:00―12:00，下午15:00―18:00，河东区、各镇、国营农场与农业局网格化责任领导可根据工作情况有计划地安排各组的安监员轮休，但不得影响工作的正常开展。

（二）落实安监员主要工作任务

1.基础数据调查统计

（1）网格责任田块冬种瓜菜信息统计

为全面掌握我市河东区、各镇、国营农场田块冬种瓜菜信息，做好瓜菜田头质量监管工作，安监员要对责任田块冬种信息进行及时、有效的统计。需要统计的信息是：种植户基本信息（姓名、村组、电话）、种植品种信息（品种、生产地点、面积、种植与预计上市时间）（见附表1）。

（2）农户冬种瓜菜常用农药调查统计

为较好地掌握农户在冬季瓜菜生产中常用的农药（杀虫剂），加强对田间农药使用的监管，安监员必须对责任田块主要瓜菜品种（豇豆、四季豆、苦瓜、青瓜、茄子等）常用的农药（杀虫剂）进行调查统计（见附表2）。

对以上两数据信息（表格）的调查统计，责任片区的区镇（国营农场）、村（国营农场作业区）、组（农场联队）干部要积极支持，全力配合安监员抓落实。

2.网格责任田块抽检

（1）日常定性抽检

安监员在网格责任田块瓜菜上市后，必须每天开展定性抽检工作。瓜菜上市高峰期，每天至少抽检10个样（含10个样），非高峰期，每天抽检5―9个样（含9个样）。抽检结果要填入《农产品质量安全监督管理员工作日记簿》和田头检测卡，将田头检测卡挂在农户瓜菜种植地块里。抽检结果还要由安监员组长报镇信息员汇总报送农业局安监科。

（2）配合定量抽检

按照市农业局检测中心要求，安监员抽取指定田块瓜菜样品。

①对安监员日常定性抽检结果有问题的样品进行定量复检。

复检：市检测中心对安监员日常定性抽检结果不合格（呈阳性）的样品复检，安监员按要求提取样品，交区、镇政府、国营农场安排专门人员送样，市检测中心联系人：吉训东。

奖励：定量复检核实不合格的（检出含违禁农药或常规农药超标），对安监员给予物质奖励（一户即一个样品奖励20元人民币）。

②市检测中心对崖城、海棠湾两个区域检测站检测结果有问题的实行追溯抽检或对重点镇（农场）重点田洋（块）重点品种不定期的进行定量抽检工作，区、镇政府、国营农场要给于支持，安监员要积极配合。

3.信息报送

为保证网格化工作信息畅通，河东区、各镇、国营农场要安排一名信息员，专门负责本单位瓜菜质量安全监管信息的报送工作。信息员名单与安监员组长名单一同报送。

（1）信息报送内容和时间：《网格责任田块冬种信息统计表》和《农户冬种瓜菜常用农药调查统计表》，从1月至6月，每周五下午下班前，由安监员组长报河东区、镇政府、国营农场的信息员汇总后报农业局安监科。《安监员田头定性抽检结果统计表》从1月至6月，每天下午下班前，以同样途径报农业局安监科。

（2）报送方式和具体要求：以电子表格网上报送，安监科邮箱为synyaj88266290@163.com。信息员和安监员要对所报送的信息注意加强保密工作，保管好原始资料备查，泄露工作秘密的按属地管理原则和有关保密工作规定问责。

4.工作考核

基础数据调查统计、网格责任田块抽检、信息报送工作作为安监员当前的主要工作，纳入年度考核指标，考核办法另外行文。

三、加强田头检测室建设

在规模田洋建设田头检测室，是充分发挥安监员田头监管作用，实现监管关口前移的重要途径。各镇（国营农场）可根据本单位的财力情况安排资金组织实施，农业局给于指导。

四、加强安监员队伍建设与管理

我市农产品质量安全监督管理员（简称安监员）实行双重管理，工作上受属地单位领导，业务上由农业局指导，是一支重要的农产品质量安全监管工作力量，战斗在第一线，属地单位要给予重视，工作上要支持，生活上要关心，财力上要倾斜，以此更好地推动我市的农产品质量安全监管工作的顺利开展，充分发挥安监员的作用。
