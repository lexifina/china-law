# 三亚市交通运输局转发交通运输部安委办关于加强推进企业安全生产标准化达标考评工作的通知

三交运〔2014〕89号

三亚市交通运输局转发

交通运输部安委办关于加强推进

企业安全生产标准化达标考评工作的通知
