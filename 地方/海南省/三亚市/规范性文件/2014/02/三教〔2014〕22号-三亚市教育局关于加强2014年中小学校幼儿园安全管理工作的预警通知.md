# 三亚市教育局关于加强2014年中小学校幼儿园安全管理工作的预警通知

三教〔2014〕22号

局机关各科室，各中小学校和幼儿园：

2013年期间，我市发生几起学生安全伤亡事故，给学生家庭造成极大不幸，学生安全工作管理现状不容乐观。2014年春季开学在即，为进一步明确安全责任，有条不紊地开展学校（含幼儿园，下同）安全管理工作，确保我市师生生命财产安全，维护正常的教育教学秩序，现就2014年中小学校幼儿园安全管理工作提出以下预警通知，请认真贯彻落实。

一、加强学生游泳安全教育，严防溺水事故发生。学生放学、双休日、节假日是溺水事故的高发期，学校要特别加强与家长的沟通和联系，增强家长监护意识，指导家长采取有效保护措施，加强对孩子进行教育与监管，避免发生青少年儿童溺水事故的发生。加强与镇（街道）、村（居）委会的联系，形成全社会共同监管学生安全的良好氛围，共同做好预防学生溺水工作。

二、强化交通安全教育和校车管理。一要加强对学生的教育。明确要求学生自觉遵守道路交通规则，坚决拒绝乘坐超载、拼装及无证无牌等非法运营车辆和拖拉机、载货车、三轮车等非客运车辆。通过多种形式对学生开展交通安全教育，增强学生的交通安全意识和自我保护能力，有效防止交通事故的发生；二要加强校车管理。认真落实国家、省、市有关校车安全管理工作文件精神，健全和完善校车和驾驶员安全管理制度，建立校车和驾驶人员安全管理台账，确保接送各环节的安全；严禁使用报废车、拼装车、农用机动车接送学生，严禁车辆超速、超载行驶，确保学生交通安全。

三、组织开展消防、地震专题讲座与演练。要加强与公安消防、防震等相关部门联系，制定应急预案，定期开展消防、地震演练和专题讲座，增强师生的安全意识，让孩子们进一步熟悉遇到紧急事故时疏散路线，提高自救和自我防护能力，做好各项演练的原始资料存档工作。学校应至少每半年组织一次有学生参加的演练，并结合实际不断完善预案。学校每学年至少应举办一次消防、防震安全专题讲座，开设教育栏目，对学生进行法律法规、防火防震知识、自救知识和案例教育。

四、定期排查安全隐患，营造良好校园环境。要根据《三亚市教育局关于建立各类学校幼儿园安全隐患每周自查制度的通知》（三教〔2013〕20号）要求，本着“以人为本，安全第一、预防为主”的原则，有针对性地对电路、消防、校车、食品卫生、危险易发场所等进行排查，更要特别注意对学校杂物堆放、卫生死角和易燃物品的排查，发现隐患及时排除，并将排查台账存档备案。同时，要明确事故预警方式、转移路线，加强保障，确保发生危险事故时不出现人员伤亡。要加强汛期安全教育，确保学生上下学道路交通安全。有建筑工地的学校，要加强对校内建筑工地安全管理，落实各项防范措施，施工现场必须进行隔离、限制通行，要设置醒目安全警示标牌，及时排查和整治校园施工造成的安全隐患。

五、建立学校安全工作管理台账。根据《三亚市教育局关于印发三亚市中小学幼儿园安全工作档案立卷与管理暂行规定的通知》（三教基〔2014〕6号）精神，学校安全档案是学校安全教育与管理工作真实具体的原始性记录，是研究处理问题、开展工作、领导决策以及实施学校安全工作目标考核、追究事故责任的重要依据。各学校要梳理安全工作台账，修订、完善各类安全工作管理制度，清理日常工作台账，做好安全工作的总结。学校幼儿园将安全信息周报制度（见三教基〔2012〕42号）由“每周一报”改为“每月一报”，幼儿园要落实每日人数“一日二报”制度（见三教民基〔2012〕11号）。

六、警钟长鸣，切实开展安全教育。要结合当日学校情况、学生情况、天气情况及各地学生安全事故案例等等，坚持开展“每天两个五分钟”安全教育，并通过广播、板报、横幅标语等形式对学生开展安全教育，同时，进行交通出行、食品、消防、活动玩耍、中毒、外来侵害等安全事故的防范与自护自救教育。

七、落实学生上下学时间和点名制度。班主任一旦发现学生在未请假的情况下缺课，要第一时间通知家长，掌握缺课学生的动向。各校要通过家访、校讯通、短信、电话等形式同家长取得联系，提醒家长做好子女的安全监管。同时，向家长明确其子女返校报到时间和安全注意事项，确保子女平安往返学校。学生在校时间内发生安全事故，学校要负全部责任，并追究相关责任人的责任。

八、明确分工，严究责任。各学校要成立落实预警通知的行动领导小组，明确责任分工，强化学校安全工作责任意识，一旦发生突发事件，要在第一时间报告教育主管部门，立即启动应急预案，及时有效地开展处置工作。我局各科室要按照分管领导分片包点的安排，积极到各分片学校进行督促检查指导，每月至少2次。同时，我局将建立问责制度，对未落实或落实不到位、拖延懈怠、措施不力的，将严究学校责任，并追究相关人员责任。

请各学校迅速将本预警通知精神传达给本校所有教职工，认真抓好工作，并在2014年12月10日前形成年度安全管理工作书面总结材料（纸质材料，加盖单位公章）报我局相关科室：中小学校（含民办，中心学校负责汇总本辖区完小情况）报至局基教科；幼儿园报至局民教办。
