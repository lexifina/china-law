# 三亚市教育局转发三亚市人民政府办公室关于做好2014年无偿献血工作的通知

三教体〔2014〕3号

中职学校，各中小学校、幼儿园：

为进一步提高我市教职工“无偿献血,拯救生命”的社会责任感和道德情操，确保我市采供血淡季期和突发事件发生时有充足的血液供应，保障临床用血和人民群众生命安全。现将《三亚市人民政府办公室关于做好2014年无偿献血工作的通知》（三府办201450号）转发给你们，请各学校加大宣传力度，积极发动本校教职工自愿参与献血，并把自愿献血的人员名单报送到市教育局体卫艺科，以便安排时间集中采集。（联系人：杨标，电话：88657855，QQ邮箱：2677920694@qq.com）

三亚市教育局

2014年3月5日
