# 三亚市交通运输局关于申请迎宾路上“红土坎”站更名为“南枫禅墅”的回复

三交运函〔2014〕318号

三亚市交通运输局

关于申请迎宾路上“红土坎”站更名为

“南枫禅墅”的回复

三亚集远房地产开发有限公司：

你公司《申请将迎宾路“红土坎”公交车站名更改为“南枫禅墅”》的来文收悉。我局已组织人员到现场察看，并先后征求了吉阳镇政府和民政局的意见。根据国务院《地名管理条例》、《海南省地名管理办法》和《三亚市公共交通客运管理规定》等文件的规定，经研究，不同意将迎宾路上“红土坎”站更名为“南枫禅墅”。

附件：三民函〔2014〕42号《三亚市交通运输局关于征求迎宾路荔仙园路口、红土坎公交站名更名意见函

的回复》

三亚市交通运输局

2014年4月24日
