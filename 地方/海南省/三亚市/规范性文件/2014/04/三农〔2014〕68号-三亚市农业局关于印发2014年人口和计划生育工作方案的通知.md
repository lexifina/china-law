# 三亚市农业局关于印发2014年人口和计划生育工作方案的通知

局机关各科室、下属各单位：

根据《中共中央国务院关于全面加强人口和计划生育工作统筹解决人口问题的决定》文件精神，为切实抓好我局系统计划生育工作，确保全年计划生育工作顺利完成，现结合我局实际，制定了《三亚市农业局2014年人口和计划生育工作方案》，现印发给你们，请按照工作方案要求严格落实。

三亚市农业局

2014年4月14日

（此件主动公开）

三亚市农业局2014年人口和计划生育工作方案

为切实抓好我局系统计划生育工作，确保全年计划生育工作顺利完成。现结合我局实际，特制定本工作方案。

一、指导思想

坚持以邓小平理论和“三个代表”重要思想为指导，深入学习贯彻党的十八届三中全会精神，坚持不懈地用科学发展观统领人口和计划生育工作，全面落实《中共中央国务院关于全面加强人口和计划生育工作统筹解决人口问题的决定》，结合实际，紧紧围绕全面建设小康社会和加快建设社会主义新农村的目标任务，不断提高人口计生依法行政能力和水平，维护我局干部职工的合法权益，为构建社会主义和谐社会营造良好的氛围。

二、目标任务

(一)切实加强组织领导，进一步健全领导机构，“一把手”负总责，分管领导亲自抓，专(兼)职计生管理人员具体抓的工作格局。计划生育工作作为单位、个人年终实绩考核的一项重要内容。

(二)协助有关部门做好农村妇女的农业科学技术培训工作，提高农民妇女的劳动技能。支持和鼓励农村妇女参加农业产业发展建设活动，充分发挥农村妇女在发展农业和农村经济中的作用。把贫困妇女儿童、独生子女户、二女(少数民族三女)结扎户的扶贫开发纳入规划，保障享有同等扶贫机会。无偿提供农业法律法规援助，保护农村妇女儿童的合法权益。

(三)抓好本单位职工及家属的计划生育管理工作，做到符合法定生育率100%。

(四)抓好本单位的流动人口计划生育工作，并落实双向通报制度。流动人口计划生育管理服务率达100%以上。

(五)配合市计生部门继续开展关爱女孩活动，倡导男女平等，提高女孩和女孩家庭的社会地位，进一步转变干部职工的婚育观念。

(六)配合计生部门开展优生优育、避孕节育、妇科病普查、咨询义诊活动。

(七)配合计生部门做好本部门的人口信息档案管理，负责收集本部门年度实施妇女儿童发展纲要、规划的情况和检测统计的有关数据。

领导小组下设办公室，办公室设在局办公室，由妇委会韩艳主任兼任办公室主任。根据全局人口和计划生育工作需要，领导小组办公室可随时抽调局机关、各下属单位相关工作人员参与各项工作，各科室、下属各单位要给予支持。

领导小组各副组长负责督导所分管的科室及相关下属单位或所在单位开展相关人口和计划生育工作，开展活动的有关信息资料要及时向领导小组办公室报送。

我局开展人口与计划生育的综合性工作由曲环副组长负责，并指导领导小组办公室开展日常具体工作，协调有关活动事项。

四、工作职责和要求

1. 分管领导职责：负责分管领域人口和计划生育工作的全面开展，督促计生工作，规范人员管理，建立规章制度，完成市下达的各项指标任务。

2. 专(兼)职计生员职责：协助、配合辖区的计划生育部门做好本单位与下属单位干部职工、家属和租(借)住本单位辖区范围内的其他人员的计划生育工作。每月做好本单位及下属单位人口档案、人口信息变动情况的调查和通报。

3. 科室工作职责：负责对农村独生子女领证户、二女(少数民族三女)结扎家庭在沼气建设、扶贫工作、农业生产项目中保障享有同等扶持权益，并指导完成各项工作任务。

4. 办公室工作职责：负责与各科室、下属单位签订《2014年人口和计划生育责任书》，并督促各项目标任务的开展。按季度对本单位及下属单位的计生管理工作进行检查，并形成书面材料报送市人口和计划生育管理部门。

五、工作措施

1. 建立健全目标管理制度，把计生工作纳入年度机关人员和下属单位目标管理考核内容。出现问题坚决一票否决。真正形成一级抓一级，层层抓落实的工作格局。

2. 坚持做好计划生育的宣传工作，办好计划生育专栏，在单位办公区、宿舍区，张贴宣传计划生育标语，大力宣传计划生育知识及相关政策法规。

3. 强化计划生育利益导向机制，保障干部职工应享有的权利。严格按照计划生育政策规定，落实本单位及下属单位干部职工计划生育优惠政策，在坚决落实上级有关部门奖励政策的基础上，对本单位及下属单位独生子女给予适当奖励。

4. 各相关科室及下属单位在农业生产项目、扶贫工作、沼气建设、阳光培训等农业产业发展建设活动中，保障农村独生子女户、二女(少数民族三女)结扎户、贫困妇女儿童享有同等扶持机会。无偿提供农业法律法规援助，保护农村妇女儿童的合法权益。

5. 严格处罚制度，杜绝计划外生育。加大对农业局系统内超生子女管理力度，发现一例上报一例，并配合计生部门做好处罚管理工作。

6. 做好季度、年度计划生育自查和检查工作，进一步落实计划生育的各项政策和法规，以优质服务为重点，切实完成上级部门交给的各项任务。
