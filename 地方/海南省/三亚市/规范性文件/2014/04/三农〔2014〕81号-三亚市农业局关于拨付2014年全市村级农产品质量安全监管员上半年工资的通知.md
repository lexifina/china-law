# 三亚市农业局关于拨付2014年全市村级农产品质量安全监管员上半年工资的通知

河东区管委会、各镇人民政府、各国营农场：

为了稳定全市村级安监员队伍，切实解决春节期间安监人员的生活保障问题，在市分管领导的多次强调下，我局经咨询财政部门并经过财政部门同意，决定从农业局基本帐户中借拨全市218名安监员1至3月的工资和5项保险金，共1179162元（每人3个月的工资3600元，五项保险1809元），现财政预算资金已下达。根据当前安监工作实际情况，我局决定拨付上半年安监员工资，经费共2358324元，其中1179162元补还到我局基本户，余额按各区、镇、国营农场安监员人数拨付（见附表）。河东区、各镇、农场要确保做到专款专用，及时把工资发放到安监员手中，及时为安监员交纳5项保险，解决其后顾之忧。

附件：全市安监员2014年第二季度工资和一项保险经费表
