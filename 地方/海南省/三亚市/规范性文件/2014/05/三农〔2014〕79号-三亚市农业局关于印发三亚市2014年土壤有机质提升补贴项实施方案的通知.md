# 三亚市农业局关于印发三亚市2014年土壤有机质提升补贴项实施方案的通知

关于印发三亚市2014年土壤有机质提升补贴项目实施方案的通知

各镇人民政府，局下属相关单位：

《三亚市2014年土壤有机质提升补贴项目实施方案》已经我局局务会议讨论通过，现印发给你们，请认真组织实施。

三亚市农业局

2014年4月24号

（此件主动公开）

三亚市2014年土壤有机质提升补贴项目实施方案

土壤有机质提升补贴项目是农业部项目，主要采用秸秆还田技术，通过腐熟剂的使用，改善土壤的物化特性，提升土壤有机质含量。为规范土壤有机质提升补贴项目管理，提高资金使用效率，科学、客观、公正评价土壤有机质提升补贴项目实施效果，加大土壤改良、地力培肥技术推广力度，根据《中央财政农业推广与服务补助资金管理办法》以及土壤有机质提升补贴项目管理要求，结合三亚农业实际，制定本方案。

一、目标任务

按照省土肥站安排，2014年三亚市计划实施秸秆还田面积10万亩，发放腐熟剂217.39吨，使用作物为水稻、瓜菜、水果和其他经济作物等。计划推广各镇秸秆还田面积6.2万亩，发放腐熟剂140吨，企业生产基地推广和示范区建设面积3.8万亩，发放腐熟剂77.39吨。具体计划安排见表1。

二、技术措施

（一）秸秆平铺翻埋还田腐熟技术

将上茬作物秸秆粉碎为10-15厘米后均匀撒在田间，切忌成堆。腐熟剂按2公斤/亩的用量与适量泥土或底肥拌匀，撒施到秸秆上。同时每亩加施农家粪肥100-200公斤或尿素5公斤调节碳氮比。施腐熟剂施肥后立即用灭茬旋耕机进行灭茬，将秸秆翻埋入土，深度10-15厘米。将作物秸秆翻埋入耕层土壤后即可开始灌水，开始时不可灌大水冲，避免将腐熟剂中的菌种冲走影响腐熟效果；灌深水7-10厘米深。后茬为旱地的，在将作物秸秆翻埋入耕层土壤后即可开始平整土地，然后播种或移栽幼苗，田间含水量以50％为宜，否则在翻埋后及时灌水。

（二）秸秆覆盖还田腐熟技术

将收获后的作物秸秆均匀地平铺在田面，切忌成堆。亩用2公斤腐熟剂与适量细土并加5公斤尿素混合均匀后撒在秸秆上，用木棍或其他工具敲打秸秆以便腐熟剂和种子掉到秸秆下面与泥土接触，同时浇适量水。

（三）秸秆沟埋还田腐熟技术

在田间挖40厘米宽，30厘米深的沟，长度根据需要确定，将秸秆铺进沟中。按每亩施2公斤腐熟剂配施5公斤尿素调节碳氮比，撒入秸秆表层，轻拍秸秆，使菌种抖落到秸秆下。浇水使水满沟即可，雨季可不浇水。

（四）秸秆就地沤腐熟还田技术

作物收获后，将秸秆收集于田间地头、场院等空地上。按照每1000公斤秸秆用秸秆腐熟剂2公斤的用量，加入尿素5公斤，钙镁磷肥3公斤混均匀。将收获后的作物秸秆按照15-20厘米厚一层铺放，均匀泼入腐熟剂，逐层堆放，堆高以高出田面1.2米左右为宜。可适当使用覆盖膜，缩短腐熟时间，使用时应注意膜内温度，过高时应掀开覆盖膜通风降温。

三、经费安排

根据项目要求，本项目推广以物质补贴的方式进行，即对使用秸秆还田技术的农户每亩发放腐熟剂2公斤，所需尿素由农户自行解决。因省土肥站目前未安排工作经费，项目所需工作经费4万元从市农技中心年度预算“2014年三亚市改善土壤耕地地力补贴项目”经费中开支，主要用于农技中心在腐熟剂运送和发放，技术培训指导，监督检查，效果评价等方面的费用。

四、时间安排

2014年4月：制定并印发实施方案。

2014年4-12月；组织实施，其中生产企业和示范区建设由市农业局负责组织实施，镇政府配合；安排下达的各镇推广实施面积由各镇政府负责组织实施，农业局指导检查。各镇农业服务中心要按计划做好腐熟剂的接收和组织发放工作，同时统计农户领取腐熟剂登记表（原件）报送市农业技术推广服务中心种子（土肥能源）站。

2015年1月：总结验收，成效评价。

五、保障措施

（一）加强领导，精心组织

成立以市农业局李劲松局长为组长，农技中心罗宏伟主任为副组长的项目实施领导小组，负责项目的组织实施，领导小组下设办公室于市农技中心种子（土肥能源）站（88270116），负责具体落实工作。各区镇也要相应成立领导机构，落实属地责任，保障工作经费，明确专人负责项目各项具体工作，做到上下对接，形成网络，共同推进。市农技中心统筹安排并指导检查，各镇农业服务中心负责腐熟剂发放、农户登记、技术指导及资料统计上报等工作。

（二）广泛宣传，加强培训

通过开展科技下乡，播放广播、电视或现场讲解咨询等形式，广泛开展秸秆还田腐熟技术专题、专刊宣传活动，大力宣传推广秸秆还田腐熟技术的意义与作用，让全市形成共识，充分调动了基层农业技术部门和农民参与积极性。

（三）树立样板，示范推广

建立秸秆还田试验点、示范区，以试验带动示范，以示范促进推广，提升我市耕地土壤有机质含量，促进我市耕地土壤的可持续发展。抓好秸秆还田示范区建设，充分发挥示范区的示范带动作用，带动全市广大农民群众积极推广秸秆还田技术。

（四）热心服务，确保实效

市镇两级农技服务部门要设立热线服务电话，方便群众咨询，发现问题，解决问题，落实项目技术规程，确保项目质量。项目实施后，由市农业局组织开展效果评价。
