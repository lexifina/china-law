# 三亚市教育局转发海南省教育厅关于做好2014年学校突发公共卫生事件防控工作的通知

海南省教育厅关于做好2014年学校

突发公共卫生事件防控工作的通知

三教体〔2014〕11号

各中职学校、中小学校和幼儿园：

为进一步加强我市中职学校、中小学校和幼儿园（以下简称学校）突发公共卫生事件预防控制工作，有效防范传染病疫情，保障师生身体健康。现将《海南省教育厅关于做好2014年学校突发公共卫生事件防控工作的通知》（琼教体201425号）转发给你们，请各学校按照通知要求，认真做好传染病防控工作，并于5月10日前将《海南省学校突发公共卫生事件信息报送负责人、联络员回执表》报送局体卫艺科。

三亚市教育局

2014年4月29日
