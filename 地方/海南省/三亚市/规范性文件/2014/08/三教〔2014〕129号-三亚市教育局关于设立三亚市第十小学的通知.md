# 三亚市教育局关于设立三亚市第十小学的通知

三教〔2014〕129 号

局机关各科室，各中小学：

由于国防建设的需要，安由片区的安由、六道、内村、罗郁四个村的村民将全部集中搬迁到福海苑安置区，我局已将安由小学、六道小学、内村小学、罗郁小学四所学校撤销整合到福海苑安置区配套学校，设立一所新小学。根据《三亚市机构编制委员会关于设立三亚市第十小学的批复》（三编字〔2014〕14号）精神，决定撤销三亚市安由小学、三亚市吉阳镇六道小学、三亚市吉阳镇内村小学、三亚市吉阳镇罗郁小学四所小学，设立三亚市第十小学。

三亚市教育局

2014年8月28日
