# 三亚市农业局关于印发三亚市2014年重大农作物病虫害统防统治补助项目实施方案的通知

三农〔2014〕207号

三亚市农业局关于印发三亚市2014年

重大农作物病虫害统防统治补助

项目实施方案的通知

各镇人民政府：

现将《三亚市2014年重大农作物病虫害统防统治补助项目实施方案》印发给你们，请认真组织实施。

三亚市农业局

2014年9月16日

（此件主动公开）

三亚市2014年重大农作物病虫害统防统治补助项目实施方案

为切实做好2014年重大农作物病虫害防控工作，将水稻病虫害、农区蝗虫的危害程度降到最低程度，减少农业生产损失，促进农民增收，根据海南省农业厅、海南省财政厅《关于印发海南省重大农作物病虫害统防统治补助项目实施方案的通知》（琼农字〔2014〕90号）精神，结合我市实际，制定本方案。

一、指导思想

贯彻落实“预防为主、综合防治”的植保方针和“公共植保、绿色植保”的理念，通过创新机制、规范管理和提高组织化程度，重点防治水稻稻飞虱、稻纵卷叶螟、稻瘟病、南方水稻黑条矮缩病、白叶枯病、纹枯病、三化螟和农区蝗虫，大力推进专业化统防统治和综合防治模式，实行整片、整村推进，带动区域性联防联控和群防群控，有效预防控制病虫害蔓延，保障农业安全生产。

二、计划防治面积及补助资金安排

根据省农业厅、省财政厅资金安排，我市水稻病虫防治补贴资金35万元，按每亩补助10元，全市计划推广水稻病虫害防治面积3.5万亩。安排农区蝗虫防治补贴资金10万元，按每亩补助5元，全市计划推广农区蝗虫防治面积2万亩。根据各镇水稻种植面积、病虫害发生情况和农区蝗虫发生情况，具体安排2014年水稻病虫害防治、农区蝗虫防治计划。（详见表1）。

三、补助对象和标准

（一）补助对象。实施病虫害防治的种植农民和专业化统防统治服务组织。统防统治服务组织包括农民专业合作社、专业协会、专业服务公司、基层农技服务组织、植物流动医院、农业科技110等。

（二）补助标准。水稻病虫害防治每亩补助10元，农区蝗虫防治每亩补助5元。补助资金主要对病虫害源头区和重发区实施统防统治、应急防治的药剂和施药作业进行补助。

四、补助形式和规程

根据我市目前水稻病虫害和蝗虫发生形势，拟采取物化补助的形式。

1.防治资金主要用于购买防治药剂，根据我市目前水稻病虫害发生形势，按规定组织采购，供货企业要有经营资质并有正规进货渠道，确保及时足量供应农药。

2.审核服务组织资质。实施项目的统防统治服务组织必须向市农技中心植保站提交由工商或民政注册部门注册的登记证、法人资格证和相关证明，接受植保站监督与指导。

3.确认作业面积。统防统治服务组织应根据当地病虫害发生情况和植物保护机构的指导意见，科学制定病虫害防治方案，按照“集中连片，整村整镇推进”的原则，细划防治任务，确认作业面积。

4.市农技中心组织各镇将药剂分发给统防统治服务组织或有防治能力的农民。

五、组织实施

（一）加强组织领导。为了加强实施工作的组织领导，成立重大农作病虫害防治工作领导小组，建立病虫害观测点，深入调查分析病虫害发生趋势，研究防治策略和措施。

（二）大力推进统防统治。2014年重大农作物病虫害统防统治补助资金重点支持具有推广统防统治能力的服务组织或有防治能力的农民，市农技部门要按照关于“支持开展农作病虫专业化统防统治”的有关要求，大力发展病虫害统防统治服务组织，引导具有防治技术的服务组织或有防治能力的农民积极承包防治面积，调动社会力量开展统防统治工作。市农技、农机等部门要切实做好病虫情报提供、药剂推荐、机械维护保养、安全用药等技术指导服务。

（三）加大宣传力度。大力宣传提供统防统治的好处和重要意义，充分调动社会各种统防统治服务组织和农民参与统防统治的积极性，及时推广成功的典型模式和经验，按质按量按成2014年重大农作物病虫害统防统治补助项目实施计划。

（四）加强补助资金管理。市财政、农业部门要密切配合，加强监督指导，加强项目资金的监管，严防挤占、挪用补助资金，按照规定实行招标采购，坚决杜绝违规违纪行为，一旦发现，严肃处理。
