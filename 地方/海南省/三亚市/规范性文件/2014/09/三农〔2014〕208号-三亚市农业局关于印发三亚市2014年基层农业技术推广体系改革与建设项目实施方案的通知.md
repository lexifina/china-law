# 三亚市农业局关于印发三亚市2014年基层农业技术推广体系改革与建设项目实施方案的通知

三农〔2014〕208号

三亚市农业局关于印发

三亚市2014年基层农业技术推广体系改革与

建设项目实施方案的通知

各镇人民政府、河东区管委会、各相关单位：

现将《三亚市2014年基层农业技术推广体系改革与建设项目实施方案》印发给你们，请认真组织落实。

三亚市农业局

2014年9月16日

（此件主动公开）

三亚市2014年基层农业技术推广体系改革与

建设项目实施方案

一、基本情况

（一）自然气候条件、人口及农业农村经济状况

三亚市位于海南省南部，全市2区6镇，92个行政村，4个国营农场，总人口57.25万人，其中农村人口27.20万人。陆地面积1918.37平方公里，耕地面积18.24万亩。农业以粮食、冬季瓜菜、热带水果为主。2013年全市农业总产值76.76亿元，农民人均纯收入9752元。水稻等粮食作物种植面积18.79万亩，总产量6.79万吨；冬季瓜菜种植面积18..5万亩，总产量54.5万吨；芒果、香蕉等热作水果种植面积25.77万亩，总产量34.54万吨。

（二）农技推广机构专业技术力量情况

目前，全市有市级农技推广机构5个，81人，有高级职称6人，中级职称36人，初级职称42人。其中市农业技术推广服务中心技术人员29人，有农技推广研究员1人，高级农艺师2人，农艺师20人，助理农艺师8人；市热作技术推广服务中心6人，有高级农艺师1人、农艺师3人、助理农艺师1人。区镇农业服务中心7个，农技人员213人。

（三）基层推广体系改革与建设情况

根据海南省政府《关于在全省开展农村综合改革的通知》（琼府〔2008〕79号）精神，市政府将各区镇涉农单位综合设置为农业服务中心，7个区镇共核定编制213人，平均每个区镇30人左右，人员工资经费为财政预算管理。根据三亚市机构编制委员会《关于调整各镇事业单位机构编制有关问题的通知》（三编字〔2013〕37号）精神，区镇农业服务中心为副科级事业单位，落实法人主体地位，行政上隶属镇政府管理，业务上接受市相关工作部门的指导和监督。内设农业技术推广站、畜牧兽医站、农产品质量安全监管站。同时逐步健全村级农业技术推广队伍，每个行政村选配1名农民技术员，逐步建立起市、镇、村三级一体化的农技推广服务网络。

通过基层农技机构改革，完善创新运行机制，实现有制度管人、管事，建立起农技推广机构长效运行管理制度。一是实行人员聘用制；二是全面推行农技推广责任制，明确农技人员服务区域，服务内容；三是建立考评制度，开展年度考核。同时，积极创新农业科技培训和农业科技入户方式，推行农技人员包村联户制度，逐步形成了农技人员抓科技示范户，科技示范户带动普通农户的科技入户模式和机制，积极创新农业科技推广方式，推行面上咨询培训与点上示范指导相结合的推广方式，建立起适应农民需求的反馈机制，加强新技术的推广。

二、项目实施年度目标

1.通过项目实施，促进我市构建职能明确，机构完善，队伍精干，保障有力，运转高效的基层农技推广服务体系；完善人员聘用制度、农技推广责任制度、绩效考评制度、多元化推广服务机制等基层农技人员管理机制；疏通“专家-试验示范基地-农技推广人员-科技示范户-辐射带动户”的农业科技成果转化应用快速通道；建立市、镇、村农业科技试验示范网络，建立健全运行高效，服务到位、支撑有力、农民满意的基层农技推广机构，切实提升基层农技推广服务能力，为科技兴农、绿色崛起作积极贡献，推动全市农技推广工作走上一个新的台阶。

2.实行专家技术负责制，围绕水稻、瓜菜、热作水果等主导产业，确定省级和市级专家20名，81名农技人员（其中：水稻33人、瓜菜150人、热作水果60人）。搞好主导品种和主推技术的筛选推广，使主导品种和主推技术入户率和到位率达到90%以上，示范户示范作物单产增长10%以上。不断加大农业科技示范户的培育力度，全市培育农业科技示范户243户，带动周边2430户辐射户采用主导品种和主推技术。

3.加强农业科技示范基地建设，全市建立示范基地3-4个。

4.加强农技人员知识更新培训，全市集中培训农技人员81名，全年培训农业科技示范户243户，发放技术资料1万份，技术咨询指导农民1万人次。

5.丰富推广手段与方法，建设农民田间学校1个，依托农业科技网络书屋、3G技术农技推广服务平台，充分利用现代信息技术提高推广服务效能。

三、实施内容

（一）深入推进基层农技推广体系改革和建设

1.继续搞好区镇农业技术推广机构改革。

区镇涉农单位综合成立农业服务中心，主要负责农业、林业、水利、渔业、畜牧业生产技术的推广、指导和服务、农产品检验检测等职能，核定编制和实行财政预算管理，人、财、物权归属区镇管理，业务技术接受市农技推广机构指导。进一步提高工作效率和服务质量，逐步完善市、镇、村三级一体化的农技推广服务网络，特别是农业技术推广、动植物疫病防控、农产品质量安全监管三大公共服务机构。

2.优化市级农技推广机构。

市级农技推广机构，是国家农技推广体系中的重要一环，起到了重要的枢纽和桥梁作用，是镇村农技推广的坚强后盾，只能加强，不能削弱，要落实中央有关要求，明确公益性职能任务，要不断改善条件，保障经费，优化结构，稳定队伍。

3.进一步健全农技推广工作机制

（1）实行农技人员聘用制度。实行全员聘用制，采取由政府人事部门公开招聘、竞聘上岗，择优聘用等方式，招录选择德才兼备、品学兼优的高等院校毕业生和有真才实学的专业技术人员进入农技推广队伍，逐步实行农技推广资格准入，在不断提升服务质量的同时，使农技推广机构的政治和经济地位得到提高。

（2）建立农技人员工作考评制度。实行市级业务主管部门、镇政府、服务对象共同参与的考评机制，把农技推广人员进村入户，为农民服务的业绩作为考核的主要内容，将考核结果与农技人员的岗位工资补贴、绩效工资、晋职晋级、聘任、评先进优秀、业务培训等挂钩，逐步建立公平、公正、公开的管理激励机制。

（3）推行农技推广责任制。建立岗位责任制，明确每个农技人员的工作内容、服务对象，量化工作指标和任务要求，进行任务公解，划分包片，实行层层负责制，责任落实到人，做到任务明确，奖惩分明。实行工作任务公开制。全面推行工作日志公示和考勤制度，把每个农技人员的下乡记录和服务情况张贴公示，强化群众监督。

（4）加强技术培训，提高服务技能。要有计划地对农技人员进行技术培训，根据不同需求，有目的地开展农技人员知识更新培训，不断提高基层农技人员的业务素质和服务能力，使其职称资格名副其实。分批次选派81名基层骨干农技人员，到国家或省级农业技术培训基地进行5天以上的学习培训。

（二）确定主导产业，加快主导品种和主推技术的推广应用

1.主导产业

根据我市自然地理和气候条件，土地资源状况，示范主导产业是水稻，冬季瓜菜、热作水果。

2.主导品种

（1）水稻：博优225、特优138、金博优168、福龙两优3381、海秀占9号、桂农占、特优009、神农（稻）326、特优248、II优629等10个水稻优质品种。

（2）冬季瓜菜：艳红朝天椒，湘研13号辣椒，千禧番茄，津绿18号和津优1号、12号黄瓜，翠柳苦瓜，热研二号油绿苦瓜，琼2号苦瓜，华赣-宝冠、琼豇三号、夏宝2号豇豆等12个瓜菜品种。

（3）热作水果：无胶菠萝蜜、金煌芒、台农1号芒、贵妃芒、热研73397橡胶、文椰2号、文椰3号等7个热作品种。

3.主推技术

（1）综合技术：耕地地力保育技术，热作水果间种套养技术，病虫害绿色防控技术，农区灭鼠技术，作物药物拌种技术，测土配方施肥技术，作物水肥一体化技术等7项技术。

（2）水稻：水稻集约化机械化生产关键技术、水稻拌种防治稻飞虱预防水稻病毒病技术、水稻病虫害绿色防控集成技术、水稻“三控”施肥技术、稻鸭共育等5项技术。

（3）冬季瓜菜：健康瓜菜育苗技术、瓜菜根结线虫防治技术、豇豆病虫害绿色防控集成技术等3项技术。

（4）热作水果：芒果产期调节催花技术，芒果花量调控技术，无胶菠萝蜜丰产栽培技术，槟榔黄化病综合防控技术、芒果安全生产和采收技术、芒果园生态绿化生产技术等6项技术。

（三）培育农业科技示范户

围绕水稻、冬季瓜菜、热作水果等主导产业，结合各地的自然条件和生产特色，在全市7个区镇92个行政村中择优选用243名农民作为科技示范户（其中：水稻33户、瓜菜150户、热作水果60户），这些示范户应具有：农业生产规模较大，种植面积较大，种植水平较高，勤劳朴实、乐于助人，道德品质好，肯钻研农业技术，在农户中有影响力，能够示范带动其他农户，辐射周边群众，促进农业科技进村入户等的条件，至少创办1间农民田间学校。

（四）建设试验示范基地

根据我市各地土地等资源优势、地理气候条件、农民生产习惯和产业品种特色，依托农业合作社和龙头企业，在农业科研院所指导下，在全市建立3-4个农业科技示范基地，集试验、示范、展示、推广、培训于一体，组织科技示范户观摩学习，既要作为主推品种、主推技术的试验、示范、展示、推广基地，又要作为省农广校等培训机构的实训基地。

（五）加强培训，提高基层农技人员素质

1.培训任务：每年挑选81名骨干农技人员进行培训。

2.培训方式：开展委托培训和属地培训，重点通过组织农技人员参加农业部和省级农业部门举办的培训班和市级集中办班及现场培训方式，时间5天以上，分期分批分类开展培训，促进农技人员知识更新，提高业务素质和服务能力。

3.培训内容：主要包括重点推广的水稻、冬季瓜菜、热作水果等新品种、新技术、新模式、病虫害防治、地力保育、农产品质量安全、农技推广理论与方法、农业公共信息服务及农业有关政策、法律、法规。

四、进度安排

从2014年6月至2015年6月，分三个实施阶段。

1.筹备阶段（2014年6月）

成立基层农技推广体系与建设项目领导小组和技术指导小组；制定项目实施方案，确认技术指导单位；遴选技术指导专家、技术指导员、科技示范户、辐射带动户、示范基地、基层农技人员特岗计划岗位；召开基层农技推广体系改革与建设项目动员大会；组织科技下乡等宣传活动。

2.任务落实和指导服务阶段（2014年7月-2015年5月）

2014年7月：选定20名省、市级技术指导专家、81名技术指导员、243个示范户，3-4个示范基地，落实示范品种与示范技术；制定技术示范和技术指导方案，编写技术资料，聘请专家对技术指导员进行技术培训。开展主导产业入户现场，培训和入户指导服务，举办科技示范户培训工作，组织发放物资化肥补贴，开展工作督查。

2014年8月-9月：邀请专家对农技人员进行培训及组织农技人员骨干进行异地培训5天以上，开展示范户技术培训和技术指导服务，重点抓好2014年冬种瓜菜筛选品种、培育壮苗、地膜覆盖技术及前期病虫害防治工作。

2014年10月-2015年5月：对示范户进行主推技术和主导品种培训，重点抓好示范户和示范基地的农作物田间管理、测土配方施肥、地力保育、病虫害综合防治、农田灭鼠、无公害瓜菜栽培技术、合理安全使用农药、农产品质量安全检验检测工作，在各个田洋各个基地有技术人员专人负责基础上，分期分批组织专家组到各镇深入田间地头了解生产情况，分析问题，接受咨询，进行会诊和实地指导服务。

3.检查验收阶段（2015年6月）

组织专家及指导员进行对照检查，互相交流，测产验收、搜集、整理资料，做好项目实施总结工作，迎接验收。

五、项目实施主要参与单位任务分工

主要参与单位：中国热带农业科学院、省农技中心、省农科院、市南繁科学技术研究院等作为专家协作单位，主要负责农技人员培训和项目建设指导工作。

市农业局为农业行政主管部门，主要负责项目的审核、检查、督导工作。

市农业技术推广服务中心和市热作技术推广服务中心作为主要技术指导实施单位，主要负责农技人员、科技示范户、试验示范基地的人员培训、技术指导等。制定全市农技推广计划、技术实施方案，制作技术指导员胸牌和手册、农业科技示范户门牌和手册、农业科技试验示范基地的标牌、主导产业分布及包村联户服务图，农技推广制度（责任、考评、培训等）上墙，编印主导品种与主推技术明白纸等。

六、经费使用计划和配套安排

2014年中央项目安排资金80万元，计划市配套资金10万元。中央项目资金安排如下：

1.农业技术推广服务补助不高于总经费的35%。主要用于：基层农技人员进村入户开展技术服务（服务示范户入户率达100%，出勤100天以上）的交通、通讯、误餐等补助，不超过总经费的25%；完成农技推广重大任务（主推品种、主推技术的覆盖率达60%以上）的绩效奖励，不超过总经费的5%；技术资料印刷、制度建设、档案管理及工作考评等管理费，不超过总经费的5%。

2.农业科技示范补助不低于总经费的35%。主要用于：农业科技示范户（种植面积5亩以上）采用新品种、新技术的种子、种畜禽、水产苗种以及购买农（兽）药、化肥、饲料等物化技术补贴，不低于总经费的15%；农业科技试验示范基地（种植面积50亩以上）建设开展新品种、新技术试验示范所需要的农（兽）药、化肥、饲料、种子、试验设施等物资及组织开展产学研等展示活动补贴，不超过总经费的12%；与农业科研教学单位组织开展产学研等展示活动补贴，不超过总经费的5%，采用农业科技网络书屋、3G技术等现代化手段开展农科推广服务的补贴，不超过总经费的3%。

3.农技人员能力建设补助不高于总经费的30%。主要用于：基层农业技术人员参加异地研修、集中培训和现场实训、开展继续教育等教材、场地、差旅、食宿、交通等培训费用，不低于总经费的20%；开展基层农技人员特岗计划试点，大学生到乡镇从事农业技术推广服务工作补助（每个特岗补助5000元以上），不低于总经费的10%。

4.市财政年度预算申请安排农业实用技术指导培训服务经费10万元，可用于全市市、镇、村三级农技员和科技示范户的农业科技培训和技术指导服务。

七、保障措施

（一）成立项目领导机构

为确保基层农技推广体系改革与建设项目顺利开展，成立三亚市基层农技推广体系改革及建设项目工作领导小组，其组成人员为：

领导小组下设办公室在市农业技术推广服务中心，具体负责日常工作，办公室主任由市农技中心罗宏伟主任兼任。各区镇要成立相应的组织机构，认真组织实施工作。

（二）加强宣传引导

“基层农技推广体系改革与建设项目工程”是落实农业部、省农业厅进一步创新管理体制、健全推广机构、提高队伍素质、完善运行机制、强化条件建设的重要内容，是大面积推广高产栽培技术模式、将新品种和新技术的潜在生产力转化为现实生产力、进行高产现场示范展示的重要载体和媒介。

该项目要通过典型示范的带动作用，带动全市农民掀起学科技、用科技的热潮，提升我市农业的综合生产能力，实现农业增产、农民增收的目的，我们要充分利用各种媒体，如广播、电视、报纸、网络等，加大项目的宣传力度，把政府承担的任务、农业各项政策法规及给农民带来的实惠，在服务过程中广泛宣传到群众中去，同时及时宣传项目实施中的典型经验、好做法，相互借鉴，使项目真正深入民心，做到实处，体现政府对群众的关怀。

（三）强化示范带动

科技示范户和示范基地大力推行“三统一”、“三到位”。“三统一”即统一良种、统一培训、统一技术；“三到位”即宣传发动到位、技术培训到位、技术指导到位，结合“农业科技入户工程、新型农民培训工程”，办好技术培训班，印发相关技术资料，以新品种新技术推广为载体，促进我市基层农技推广体系的改革与建设。

在技术上为科技示范户提供全程技术服务，国家实施的各项惠农政策及时向农民宣传，提高广大科技示范户参加培训、搞好试验、示范、带动的积极性，达到以点带面，为科技入户创造良好的环境，形成广大农民竞相学科技、用科技的氛围，促进科学技术的推广普及，提高科技的到田率，推动科技入户工作深入持久地开展下去。

（四）加强绩效考核制度

制定项目管理办法和资金管理办法，完善绩效考核机制，农技人员实行包片责任制，任务落实到人，示范包片到户，引导科技示范农户严格按照技术规程进行栽植管理，力保技术入户率和到位率达到90%以上。要把农技推广体系改革与建设进度、科技示范户培育、农业科技示范基地建设、农技人员培训以及农民的满意度、技术入户率和到位率、农业产业发展等作为绩效考评的重要指标，建立补贴经费与工作考评挂钩的机制，技术员的补贴经费要与技术员下乡和绩效考评挂钩，对于优秀的技术员要给予表扬和奖励。

（五）加强检查督促

在项目建设过程中的各关键环节，加强检查指导和监管，协调相关部门解决有关具体问题，确保工作落实和技术到位。农技人员的工作职责、考勤制度、考核办法要做到制度上墙，并通过多种形式向社会公布，接受服务区域内广大农民的监督。

（六）加强档案信息管理

加强档案信息管理，建立农技人员及其培训、示范基地、科技示范户档案，实行网络化管理，网上填报省、市专家组、示范基地、农技人员、科技示范户、基层农技人员特岗计划岗位的基本情况，做到各阶级、各产业的档案信息齐全、完善，并把档案信息管理工作纳入项目考核考评内容。
