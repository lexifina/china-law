# 三亚市农业局关于公布2014年认定的市级农民专业合作社示范社的通知

三农〔2014〕215号

三亚市农业局

关于公布2014年认定

的市级农民专业合作社示范社的通知

各镇人民政府、各区管委会，各农民专业合作社：

为进一步贯彻落实《中华人民共和国农民专业合作社法》和《海南经济特区农民专业合作社条例》，根据中共海南省委办公厅、海南省人民政府办公厅《关于进一步推进农民专业合作社发展的若干意见》和三亚市人民政府办公室《关于进一步推进农民专业合作社发展的实施意见》精神，按照《三亚市农业局关于开展申报农民专业合作社市级示范社工作的通知》（三农〔2013〕179号）要求，市农业局开展了2014年度市级示范社申报认定工作，经各区（镇）初审推荐,以及市农业局工作组审核和认定，现将10家新认定的市级农民专业合作社示范社予以公布。

希望新认定的市级示范社再接再厉，在规范化建设和促进农业增效、农民增收取得更好的成绩，为提升我市农民专业合作社发展水平和市场竞争力作出积极贡献。

附件：10家新认定的市级示范社名单

三亚市农业局

2014年9月22日
