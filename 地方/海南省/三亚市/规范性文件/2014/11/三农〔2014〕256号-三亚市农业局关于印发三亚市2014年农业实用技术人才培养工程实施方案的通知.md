# 三亚市农业局关于印发三亚市2014年农业实用技术人才培养工程实施方案的通知

三亚市2014年农业实用技术人才培养工程

实施方案的通知

局各相关单位：

现将《三亚市2014年农业实用技术人才培养工程实施方案》印发给你们，请认真组织落实。

三亚市农业局

2014年11月13日

（此件主动公开）

2014年三亚市农业实用技术人才培养工程实施方案

一、指导思想

为我市粮食作物、冬季瓜菜、热作水果、畜禽养殖、农业机械、良种良苗、检验检测等农业主要行业搭建促进农业科技人才和农村实用人才发展的平台，积极为农业实用技术人才提供服务，加快优秀农业科技人才和农村实用人才的成长，全面提升我市农业人才的创新能力和队伍整体水平。

二、工作目标

围绕我市粮食作物、冬季瓜菜、热作水果、畜禽养殖、农业机械、检验检测、良种良苗等农业主要行业，拟各确定1名水平较高的指导老师，对从全市选拔的6名优秀农业科技人才和18名农村实用人才进行重点培养，形成农业科技人才与农村实用人才的共同培养，相互对应，以点带面，带动全市农业农村人才发展，同时通过对合作社、企业优秀人才和农村技术突出人才的吸收和培养，引导农民专业合作组织、涉农企业参与农技推广服务，构建新型农技推广服务体系。

三、实施单位

畜牧局，农技中心，热科院，农机局，热作中心，检测中心。

四、实施时间

2014年9月-2015年8月。

五、实施内容

农业实用技术人才培养工程计划根据不同专业行业设立培养站，确定指导老师，拟在全市范围内的农技部门、种养大户、技术能手、农民满意农技员、农机员、安监员等一批学科技、素质高、能力强的农技人员中，挑选24名优秀农业科技人才和农村实用人才进行重点培养。包括以下培养内容：一是重点培养人才加强学习培训，有计划地选送赴省内外进行中短期培训考察1次以上，并鼓励积极参加专业职称再教育培训和职称评定。二是以项目培养人才，围绕我市粮食、瓜菜、热作水果、畜牧、农机等农业生产发展需求，通过与农户、合作社、企业共建共同开展农业项目，实现科技人才的吸收和培养，并提高农民的农业实用技能。三是创建生产示范基地培养人才，搭建农业企业与农业技术人才的交流平台，鼓励与高等院校、科研院所、合作社、龙头企业共建生产示范基地5个，每个生产示范基地建设面积50亩以上，作为重大项目的实施基地和农业农村人才培养基地，以基地的示范效应推动新品种新技术的推广应用。五是每个培养对象全年开展学习交流活动不少于5次，活动包括学习培训、技术指导、技术交流座谈会、专业技术竞赛、参观考察、基地创建示范等内容。

六、工作计划

2014年9-10月：各单位确定培养站工作负责人和指导老师，挑选重点培养对象。

2014年11月-2015年8月：各单位制定培养计划，组织培养对象参加省市级的培训，组织培养对象到生产基地参观实践，组织培养对象开展交流研讨会，组织培养对象实施农技推广服务工作和开展农产品质量检测等。

2015年9月：指导培养对象撰写学术论文；各培养单位和培养对象完成工作总结；指导帮助培养对象申报职称和总结成果等。

七、工作措施

1．成立领导小组，加强领导。成立领导小组，组长由农业局局长担任，副组长由农业局分管人才工作的副局长担任，办公室设在市农业技术推广服务中心，由张斌担任主任，成员由各相关单位负责人组成。

2．成立培养站，选拔培养对象。根据我市农业发展现状，以及不同农业专业特性，成立农技实用技术推广、热作实用技术推广、农业机械、畜牧养殖、农产品质量检测、良种良苗等6个培养站，每个培养站计划安排工作经费2.5万元，培养对象主要是农技人员或素质水平较高的农民、技术能手、行业带头人等，通过个人申报和业务部门的初步审查，由培养站负责人、主管部门审核批准，需要自身发展欲望强、水平素质较高、主动性强，有坚定的职业理想和职业信念，热心于农业农技事业作为培养对象。培养站和培养对象之间应互相认同、互相信任，能够团结协作，服从分配，建立良好的发展合作基础。

3．建立培养对象档案，确立培养目标。培养站结合不同培养对象的个性特点，对他们提出具体的发展方向和要求，使培养对象的科技水平和能力得到全面提升。每位培养对象要在培养站指导老师的指导和帮助之下，定出自己在培养周期内的发展规划，确立自己的发展目标，并建立个人培养记录档案，每月要有学习记录、有总结，年终要有成果。

4．实施月交流制度，加强沟通联系。各培养站争取每月进行一次座谈会等交流活动，主要采取培训、研讨、观摩等形式的活动展示阶段性培养和发展成果。活动有记录，有总结，形成文字图片资料归档。

5．加强学习，提高科技素养和水平。培养站指导老师在自身积极工作的同时，要带动培养对象自觉学习，力争每位对象都能快速成长。培养站督促并鼓励培养对象从事农业科技学习、研究和推广工作，指导有条件的对象积极撰写论文。同时，创造条件组织开展人才的继续教育和培训工作，鼓励他们评取职称，参与新品种新技术的试验示范工作。

6．加强信息报送。各个培养站要将开展活动情况及时整理出信息报送农业实用技术人才培养工作办公室，汇编成三亚市农业实用技术人才培养工作文集。鼓励培养对象独立撰写农业科技发展动态、推广成果等文章，争取在省市农业相关网站和报刊上发表。同时，充分利用三亚政府网、农业信息网、农信通、三亚晨报等平台积极宣传农业实用技术人才培养工程成效。

7．抓好自我管理、自我评价工作。制定培养站的管理制度，年度末对培养站工作、对培养对象的发展进行梳理提炼，总结经验，反思不足。对培养对象进行年度评估和考核，对表现突出的成员进行奖励，对达不到培养目标的对象督促改进，争取共同进步。

八、经费安排

2014年农业实用技术人才培养工程经费共15万元，主要用于培养对象省内外专业技术培训，包括人才的选拔、培训资料的编制印刷、培训专家补助、职业再教育培训以及农业科技学习考察、学习交流活动经费、示范基地建设扶持、新品种新技术推广示范等。建设农技推广、热作技术、畜牧养殖、农用机械、农产品质量检测和良种良苗等6个农业实用技术人才培养站，每个培养站计划安排工作经费2.5万元，共培养24名农业实用技术人才，平均每个人才培养经费6250元。具体各单位安排经费为：畜牧局2.5万元；农技中心2.5万元；热作中心2.5万元；农机局2.5万元；检测中心2.5万元；热科院2.5万元。

九、项目管理

1．实施单位要严格按照本方案要求编制具体实施方案，设定具体的目标任务，报市农业局审批同意后方可实施，项目实施前要与农业局签订协议。在项目实施过程中要建立严格的财务管理制度，确保专款专用，取得实效。

2．实施单位要与培养对象加强联系，积极为农业实用技术人才提供服务，尽力解决他们工作和生活上的困难。其中各实施单位原则上确定1名优秀农业科技人才和3名农村实用人才，重点培养的优秀农业科技人才要主动带领农村实用人才，实现共同成长。

3．实施单位要及时上报相关人才工作信息，项目完成后须上报工作总结和资金使用情况。

4．市农业局负责项目实施的监督和管理工作，经检查达不到任务目标的，撤销该培养站，取消来年经费支持。
