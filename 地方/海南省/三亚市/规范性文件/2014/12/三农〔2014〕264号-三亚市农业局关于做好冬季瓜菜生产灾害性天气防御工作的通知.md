# 三亚市农业局关于做好冬季瓜菜生产灾害性天气防御工作的通知

各区筹备组、育才生态管理委员会：

根据气象部门预测，从12月1日起我市出现一轮持续降雨过程，并伴有5-7度的降温，对冬季瓜菜生产将造成一定影响，为切实做好冬季瓜菜产销和质量工作，现将有关事项通知如下：

一、及时做好病虫害防治。由于雨水影响，田间湿度大，各种病虫害易于发生流行，特别是疫病、灰霉病、角斑病、青枯病等，晴天后要及时组织农业技术人员下到田间地头指导瓜菜生产和种植户科学使用农药，防止病虫害蔓延。

二、加强冬季瓜菜的防寒保暖工作，可采取薄膜、遮风网和稻草覆盖等措施抵挡寒流的侵袭。严重的情况下也可以喷施保暖的药剂，如多保功、磷酸二氢钾等，防止种苗或幼苗损失。

三、对于尚未移栽的瓜菜幼苗，要组织人力及时将其转移到温暖避风的高处，避免受淹，减少冬季瓜菜生产的损失。

四、待天气转晴表土稍干后要及时中耕培土、增施有机肥，增加土壤透气性，提高植株对水分和养分的吸收能力，增强瓜菜抵抗力，促使瓜菜尽快恢复生长。

各区要高度重视，充分发挥属地农业技术人员的作用，加强瓜菜防寒、防病工作的指导，采取有效的防御措施，努力降低灾害影响，确保瓜菜增效、农民增收。

三亚市农业局

2014年12月3日
