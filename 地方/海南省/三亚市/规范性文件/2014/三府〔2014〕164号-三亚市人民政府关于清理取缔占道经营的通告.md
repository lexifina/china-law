# 三亚市人民政府关于清理取缔占道经营的通告

三亚市人民政府

关于清理取缔占道经营的通告

三府〔2014〕164号

为进一步提高我市城市管理水平，创造优美、整治、有序的城市环境，创建国际旅游岛良好旅游城市和文明城市形象，根据国务院《城市市容和环境卫生管理条例》、《海南省城乡容貌和环境卫生管理条例》、《城市道路管理条例》和《海南省城市市政设施管理条例》等有关规定，现就清理取缔市区占道经营有关事项通告如下：

一、严禁任何时段占用市区道路、广场、街道及其他公共设施从事经营活动。

市区内所有占道经营的烧烤点、早餐夜市排档、手提肩挑、

推车兜售水果、杂货、槟榔等流动商贩必须在本通告发布之日起自行停止占道经营活动。

二、沿街店面必须在店内归店经营，不得在店外占道摆卖、堆放销售商品；从事餐饮的经营户不得出店设桌、摆放炉灶；车辆清洗、维修、装饰行业不得占道作业；加工、焊接及修理行业不得出店占道施工。

三、禁止在市区范围内设置沙场售卖沙子，已设置沙场售卖沙子的经营者必须在本通告发布之日起20日内予以搬离完毕。

四、禁止人力三轮车进入市区拉客载货。

五、全市临街的企、事业单位、餐饮酒店、超市等服务行业应当配合做好“门前三包”责任制工作，杜绝门前摆摊设点和乱停放车辆，并自行设置好停车位，规范车辆停放。

六、对违反本通告的，由市综合行政执法局或联合有关部门依法采取强制措施，一律予以取缔，并按照有关法律法规进行处罚。对侮辱、殴打执法人员或者阻挠执法人员依法执行公务的，由公安部门依照《中华人民共和国治安管理处罚法》的规定处罚；构成犯罪的，依法追究刑事责任。

七、本通告自发布之日起施行，原《三亚市人民政府关于清理取缔占道经营的通告》（三府〔2010〕148号）同时废止。

三亚市人民政府

2014年10月10日
