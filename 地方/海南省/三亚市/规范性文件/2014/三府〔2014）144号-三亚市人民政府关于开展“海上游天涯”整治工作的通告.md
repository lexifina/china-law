# 三亚市人民政府关于开展“海上游天涯”整治工作的通告

三亚市人民政府

关于开展“海上游天涯”整治工作的通告

三府〔2014）144号

为进一步加强“海上游天涯”整治工作，巩固我市前阶段的整治成果，维护我市旅游市场秩序，保障广大游客的生命财产安全，根据《中华人民共和国海上交通安全法》、《中华人民共和国海洋法》等相关法律法规的规定，现就“海上游天涯”整治工作的有关事项通告如下：

一、天涯海角景区内外的各类船只，没有合法有效的证件，不得在景区内外从事“海上游天涯”的经营活动。

二、市海洋与渔业局、市旅游委、市交通运输局、三亚海事局、市公安局、天涯镇人民政府、天涯边防派出所、天涯海角景区要相互协作，密切配合，严厉打击景区内外非法营运的“三无船舶”。

三、对以暴力、威胁的方法阻碍国家机关工作人员依法执行公务，构成犯罪的，公安部门要依照《中华人民共和国刑法》第二百七十七条之规定，依法予以查处。

四、本通告自发布之日起实施。

三亚市人民政府

2014年9月15日
