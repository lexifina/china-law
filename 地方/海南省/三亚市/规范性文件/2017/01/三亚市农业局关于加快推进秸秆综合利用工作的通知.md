# 三亚市农业局关于加快推进秸秆综合利用工作的通知

育才生态区管委会，各区农林局：

根据我市农业生产实际，结合我市“创文巩卫”精神，为进一步加快推进秸秆综合利用工作，确保秸秆综合利用率达100%，现将有关事宜通知如下：

一、加强组织领导，落实任务责任。各区要加强对秸秆综合利用工作领导，明确目标任务，强化主体责任，明确分工、责任到人，构建政府主导、部门联动、农民参与的工作格局。

二、广泛宣传，加强培训。各区要通过开展科技下乡，播放广播、电视或现场讲解咨询等形式，广泛开展秸秆综合利用技术专题、专刊宣传活动，大力宣传推广秸秆利用技术的意义与作用，让全市形成共识，充分调动农民积极性。

三、提高秸秆农用水平。各地要按照种养结合、农业优先的原则，进一步加大秸秆还田力度，利用秸秆腐熟剂进行机耕翻埋还田，有条件的地区可开展秸秆-牲畜养殖-能源化利用-沼肥还田、秸秆-沼气-沼肥还田等循环利用，推动区域秸秆全量利用。

三亚市农业局

2017年1月9日
