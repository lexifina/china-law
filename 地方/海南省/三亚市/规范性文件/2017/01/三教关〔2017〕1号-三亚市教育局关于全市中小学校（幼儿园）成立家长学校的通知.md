# 三亚市教育局关于全市中小学校（幼儿园）成立家长学校的通知

各区教科局、市教育局直属学校（幼儿园）：

为进一步加快全市家庭教育现代化建设步伐，帮助家长更新家庭教育观念，改进家庭教育方法，提高家庭教育实效。根据国家、省有关文件的精神，经研究决定在全市各中小学校、幼儿园成立家长学校。现将有关要求通知如下：

一、提高认识，充分认识成立家长学校的重要意义

家长学校是宣传正确家庭教育思想、普及科学家庭教育知识的主要场所，是中小学、幼儿园开展家庭教育工作的有效途径，是联系学校、家庭、社会并促进形成三结合教育体系的桥梁。办好家长学校对提升家长自身素质，加强社会主义核心价值观的树立，构建和谐社会，实现中国梦，培养社会主义事业建设者和接班人具有十分重要的意义。各单位要紧紧围绕加强和改进未成年人思想道德建设这个中心，以中小学、幼儿园学生家长及其抚养人为主要对象，开展丰富多彩的家庭教育活动，大力宣传科学家庭教育理念和方法，引导广大家长增强责任意识，提高自身素质，培养教育好下一代。

二、明确目标，扎实开展家长学校设置与管理工作

家长学校以中小学、幼儿园学生家长及其抚养人为主要对象，以普及家庭教育科学知识、交流家庭交易经验方法、推广家庭教育科研成果、提高家长素质和家庭教育水平为目的，通过面授、函授、广播、网络交流等教学形式，努力为广大家长服务，为促进青少年健康成长服务。

各单位、各部门要把家长学校建设作为当前教育工作的重点，制定制度、强化措施、落实人员和场所，保证在2017年春季开学后科学规范地设置起来，并有序开展后续工作。家长学校的教学形式要灵活多样，教学内容要坚持系统性、科学性、针对性和实用性。教学方法坚持讲授与研讨、交流相结合，提倡现代教学手段的运用，同时积极开展生动活泼的辅助性家庭教育活动。家长学校的老师可由学校领导、教师、社会上有关方面的专家学者及有教子经验的家长担任。教师要带头学习钻研家庭教育理论，掌握家庭教育的信息。要通过培训、科研、考察、实验等活动，不断提高教师的政治素质和业务水平。使家庭教育的教学内容更加贴近社会、学校和家长。

各家长学校要建立学校章程、考勤、考核制度和教学计划等，使家长学校工作有序进行。

三、加强领导，健全组织

各学校、幼儿园应为家长学校的设置和工作开展提供必要的办公场所和办公条件。家长学校教育属于成人继续教育，不收任何学费。家长学校的经费来源主要依靠主办学校统筹兼顾，亦可争取社会各界支持。

为保证此项工作的顺利开展，市教育局成立家长学校领导小组，领导小组下设办公室，办公室设在关工委。负责对全市家长学校的管理、指导、评估、组织师资培训、学习考察、专题讲座、开展家庭教育咨询及其其它日常工作。各单位也要成立家长学校组织机构，校长由原学校的校长（园长）担任、副校长及委员由中层干部、教师代表和家长代表组成家长学校委员会，共同参与指导家长学校工作的开展。工作中要注意原始材料的积累，加强研究，培育典型、总结经验，促进此项工作的扎实开展和有效推进。
