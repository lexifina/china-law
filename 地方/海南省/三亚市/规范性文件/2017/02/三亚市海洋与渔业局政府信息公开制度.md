# 三亚市海洋与渔业局政府信息公开制度

为了对我局政务工作实施有效监督，使政务公开工作顺利开展，进一步改进工作作风，切实提高办事效率，增强工作透明度，有效抑制各种腐败现象，维护政府威信，树立良好形象，根据市委、市政府的有关规定、要求，结合我局实际特制定本制度。

一、承办科室和职责

政务公开的监督检查工作坚持市委、市政府的统一领导和部署，由局办公室具体负责，各科室按要求及时报送公开内容。办公室依据有关政务公开的各项制度、要求，按照各科室具体工作内容、时限、要求，对政务公开工作实施全过程、全方位的监督检查，各科室均应严格遵守制度，并及时提供报送市政府公开的相关材料内容。

二、公开范围及内容

凡一切运用公开权力直接为群众服务的科室对职责范围内的公开事务，除涉及党和国家机密以外，都要采取适当方式向干部群众和社会公开事权、财权、人权，包括办事依据、职责、条件、程序、标准时限和结果等，接受群众监督。

具体内容有：

（一）对内公开内容：

1、年度工作计划，工作目标及完成情况；

2、事关全局的重大决策过程及出台的政策；

3、年度财政预决算及执行情况，包括话费、接待费、车辆管理费的开支情况；

4、人事任免、人员招聘、专业技术人员的职称评定、考核等次、评优评先等；

5、重大基本建设、工程项目情况；

6、行政审批项目、程序的执行情况；

7、直接影响公民、法人或其他组织权益的行政执法事项；

8、干部职工关心的其他重要事项。

（二）对外公开内容

1、行政事业性收费和罚款、年审、办证等情况；

2、科室职责、包括部门职责、内设机构职责、部门领导分工和工作人员职责；

3、办事依据，包括所遵循的法律、法规、政策、决议决定、指标和罚款收费的基础及标准；

4、办事条件，包括办事对象如申请年审、办证等所应具备的基本条件及必备的文书资料；

5、办事程序，包括办事的过程、顺序等；

6、办事时限，即办理某一事项所需的最长时间承诺；

7、办事纪律，包括在办事过程中必须遵循的纪律规定和违章、违纪处罚办法等；

9、监督投诉，对外公开监督机构、监督制度及监督渠道、电话等内容。

三、公开形式

1、以上公开内容采用公示栏张贴、上网络公示以及其它公共媒体等形式予以公开，接受干部群众的监督。

2、政务公开结合实际采取固定内容和活动内容相结合的方式进行，定期公开与不定期公开相结合，事前公开、与事中、事后公开相结合。

四、公开程序

1、政务公开由办公室按照确定的公开内容向各科室搜集，整理、汇总后，经单位负责人同意后或予以对内公开，或按要求及时报送有关部门予以对外公开。

2、每次公开后，由办公室负责收集干部、群众的意见、建议，提交领导研究处理，处理结果及时公布。

3、每次公开的资料要明确专人管理、检查监督，归档备查。

五、责任追究

对不按规定的内容、时间、程序、形式进行公开，或者公开内容失实的科室或个人，视其情节，给予通报批评，诫勉处理；对拒不公开的，造成恶劣影响的给予党纪政纪处分。
