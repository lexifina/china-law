# 三亚市交通运输局关于增加乐天城公交站点的通知

市公共交通集团有限公司：

目前，乐天城港湾式公交候车亭已建设完毕，并交付使用。为了方便附近市民和游客乘车，经研究，在“强制戒毒所”和“市仔村”2个公交站点之间增加“乐天城”公交站点，请你公司必须于2017年1月16日前完成对公交站牌、线路信息的刷新工作。同时，做好7路、30路、37路、38路等4条公交线路运营车辆腰牌和报站器数据的更新工作，待以上工作完成后，按照新增站点信息运营。

三亚市交通运输局

2017年1月10日
