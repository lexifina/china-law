# 三亚市卫生和计划生育委员会关于印发三亚市2016-2017年人体生物监测实施方案的通知

各区卫计局:

2016年国家人体生物监测项目正式开始启动实施,三亚市成为全国152个监测点之一,根据《海南省人体生物监测技术方案》文件精神,我委制定《三亚市2016-2017年人体生物监测实施方案》,现印发给你们,请各相关单位认真落实。

三亚市卫生和计划生育委员会

2017年2月16日

(此件主动公开)

三亚市2016-2017年人体生物监测实施方案

2016年国家人体生物监测项目启动实施,全国152个监测点,三亚市做为海南省2个监测点之一,根据《海南省人体生物监测技术方案》的要求,按照我市实际,制定本方案:

一、监测目的

人体生物样本(血、尿、母乳、牙齿、头发等可反映人体的健康状况、营养状况和环境化学物质的累积暴露情况。通过对人体生物样本中环境化学物质及其代谢物的检测分析,可获取个体及群体暴露环境化学物质的类别、数量、负荷水平及变化趋势等的基础数据。长期系统地开展环境化学物质人群暴露监测,掌握我国人群环境暴露特点和变化反应的规律,对评估环境污染物的健康风险及暴露途径,为政府制定环境污染防控政策和干预措施提供科学依据。

二、监测地区及人群

按照三亚市行政规划区,由中国疾病预防控制中心抽样,我市为2个居委会、1个村委会共3个监测点。分别为吉阳区的港门村居委、鹿回头居委会及南丁村委会。每个监测点按随机抽取3岁~、6岁~、12岁~、19岁~、40岁~、60~79岁共6层,每1层按单纯随机抽样原则抽取男女样本各4人共8人,6层共48人(6×8=48)进行问卷调查、体检及生物样品采集。

每个监测点抽取48名常住居民,监测总样本量共计144人(3个监测点×48人=144人)。

三、监测内容和方法

(一)监测点基础资料收集

1.监测点的人口学资料,如行政区划、总人口数、人口年龄结构、城镇人口数、出生率、死亡率、主要死因排序、预期寿命等。

2.监测点的一般经济学资料,如城镇化率、国民生产总值、就业率、产业结构、行业结构、教育经费、人均收入、人均支出水平等。

(二)调查单元基础资料收集

1.人口学资料,如总人口数、人口年龄结构、性别结构等。

2.医疗保健与社会福利情况,如所在乡镇卫生院/社区卫生服务中心总数、该地区卫生技术人员数、该地区福利院数、该地区敬老院等。

3.污染源情况,如辖区内集中式污染处理设施、工业污染源农业污染源等。

(三)现场问卷调查

对抽样人群进行现场问卷调查,通过《家庭居住环境问卷》、《个人健康和生活习惯问卷》、收集调查对象的家庭基本信息、经济收入和生活环境中环境化学物的暴露情况;收集调查对象个人基本信息、疾病史、家族史、职业史、生活习惯等。

(四)健康体检

主要项目包括一般检查,如体重、身高、腰围、体质指数等,以及专项检查,如甲状腺、淋巴节、扁桃体等。

(六)血液样本处理

6岁及以上调查对象,抗凝全血4ml现场检测血常规后,剩余按每份1ml分装,全程冷链运送至中国疾病预防中心环境所生物样本库。

非抗凝全血现场分离血清,至实验室先分装0.8ml,用于临床生化检测;其余每份0.5ml分装,与用于DNA提取的血液凝固层一起,全程冷链运送至中国疾病预防中心环境所生物样本库。

6岁以下儿童:抗凝全血现场检测血常规后,取1.5ml离心分离血浆后用于生化检测。剩余样本至实验室按每份1ml分装,与离心后的凝固层一起,全程冷链运送至中国疾病预防中心环境所生物样本库。

2.尿液样本处理

尿液采集后,现场应用“苦味酸分光光度法”进行尿肌酐和尿常规测定,然后至实验室根据检测需求选择不同材质容器分装(用于多环芳烃检测的尿样应采用无菌容器分装),每份5ml或10ml。全程冷链运送至中国疾病预防中心环境所生物样本库

(七)生物样本临床常规项目和生化项目检测

血、尿的临床常规检测应在样本采集后2个小时内完成,应在现场采样后即刻检测,检测仪器为全自动血常规、尿常规分析仪。生化检测统一由全自动生化分析仪完成,所用仪器需通过相关质控部门的检验或认证,并在有效期内。血、尿临床检测的主要指标如下:

1.血、尿常规。

实验室常规检测项目确定,如血常规:白细胞计数(*109/L)、中性粒细胞百分比(%)等。

尿常规:尿比重(SG)、尿酸碱度(pH)、尿白细胞(LEU)、尿潜血(BLD)、尿蛋白质(PRO)、尿糖(GLU)、亚硝酸盐(NIT)、尿酮体(KET)等。以上由南新农场医院负责。

2.血生化全项。

各地可根据当地临床检测实验室常规检测项目确定,如血液生化检测项目:血清丙氨酸氨基转移酶测定(ALT)、血清直接胆红素测定、血清天门冬氨酰基转移酶测定(AST)、血清间接胆红素测定、血清γ--谷氨酰基转移酶测定、血清前白蛋白测定、血清碱性磷酸酶、ALT/AST、血清总蛋白测定、血清总胆固醇测定等。以上由南新农场医院负责。

(八)人体内暴露水平检测。生物样本检测由中国疾病预防控制中心负责组织。

(九)按国家人体生物监测体检项目

由南新农场医院负责。

四、数据管理

(一)数据录入与报送

各监测点现场调查数据通过计算机辅助面访程序(CAPI)直接录入并上报数据管理系统。

(二)数据审核

省疾控部门负责将中国疾控预防控制中心环境所的审核意见传达至各监测点,并负责给环境所反馈各监测点对数据审核意见的解答和数据修订的结果。

(三)数据管理要求

本项目产生的所有数据由中国疾病预防控制中心环境所统一管理,相关数据与各地实施单位间进行共享。未经批准,各级数据保管单位不得擅自公开数据结果,或将部门保管数据提供给与本项目工作无关的单位和个人使用。

五、质量控制

参与人员具有现场调查经验或经过培训方可上岗;参与

单位设备齐全、检验室有相应资质与专业技术人员;并对南新农场医院资质及各项检测工作进行质量控制。建立完善的计算机网络系和档案管理系统及严格、健全的保密制度。

六、组织实施与职责分工

(一)市卫生行政部门

负责监测工作的组织协调与管理、协调落实配套资金。组织疾控中心成立现场监测工作组;制定工作方案,协调与督促各相关单位按各自职能落实各项监测工作。吉阳区卫计局负责做好本辖区各监测点调查户与调查对象宣传动员工作,协助疾控中心做好抽样辖区居委会和行政村人口资料填报,并协助完成各项监测调查工作。协调南新农场医院做好被调查人员的体检及现场血样检测项目。

(二)市疾控中心

拟定监测工作方案,建立专项工作队伍,完成监测调查工具设备采购与准备工作;组织开展现场问卷调查;血样分装、贮藏及运输任务;完成监测数据的录入、整理与上报工作及时向调查对象反馈检测结果。

(三)南新农场医院

组织体检队伍负责被调查人员的体检、采血及部分检测

项目,协助疾控中心做好结果反馈工作。
