# 关于印发《2017年党风廉政建设主要任务》的通知

局机关各科室、各下属单位及各国土资源管理分局：

《2017年党风廉政建设主要任务》已经局党组同意，现印发你们，请结合本单位实际，认真制定2017年党风廉政建设工作计划，并密切配合抓好我局2017年党风廉政建设主要任务的贯彻落实，深入推进我局党风廉政建设再上一个新台阶。

中共三亚市国土资源局党组

2017年2月23日

（此件主动公开）

2017年党风廉政建设主要任务

2017年是党的十九大召开之年，是全面贯彻落实党的十八大和十八届六中全会精神的重要一年，也是深入推进我局党风廉政建设再上新台阶的关键一年。今年党风廉政建设的总体要求是：认真学习贯彻习近平总书记系列重要讲话精神，全面落实党的十八届六中全会、十八届中央纪委七次全会精神，坚决维护以习近平同志为核心的党中央权威。严肃党内政治生活，加强党内监督，推进标本兼治，持之以恒纠正“四风”，保持惩治腐败高压态势，严肃查处群众身边的“微腐败”，加大对不作为、不担当的问责力度。严格执行监督执纪工作规则，强化监督执纪问责，推动全面从严治党向纵深发展，努力营造忠诚干净担当的政治生态。

一、深入学习贯彻十八届中纪委七次、省纪委六届七次和市纪委七届二次全会精神，强化党内党外监督

深入学习贯彻落实习近平总书记系列重要讲话和党的十八届六中全会精神，是我局当前和今后一个时期首要的政治任务。在今年，要组织局党组成员和党员干部学习十八届中央纪委七次全会和习近平的重要讲话精神、学习省纪委六届七次全会和市纪委第七届二次全会精神，确保中央、省、市及省厅重大决策部署贯彻落实。局纪检组要履行好党内监督职责，创新纪检监察工作方式。为加强我局纪检监察力量和提高我局党风廉政建设水平，局纪检组要到海口局就纪检监察的机构设置、工作职能和党风廉政建设经验做法等进行调研学习，组建好我局的纪检监察科（室），用他山之石推动我局的党风廉政建设。为提高局纪检联络员队伍抓党风廉政建设的能力，局纪检组要积极协调参加市纪委和省纪委派驻国土厅纪检组组织的有关培训，夯实我局内部监督力量的基础。为发挥好社会监督作用，在局机关、下属单位、各分局、登记中心及审批办设立和完善投诉举报意见箱，召集我局社会监督员开会布置今年社会监督的工作重点和要求，提高社会监督工作的积极性和有效性。坚决纠正打折扣、搞变通、自行其是，消极应对、落实不力，“吃拿卡要拖”等行为。只有把党内监督和社会监督有机结合起来，才能推进我局党风廉政建设工作在2017年再上一个新台阶。

二、认真履行党风廉政建设主体责任，强化执纪“四种形态”和问责

局党组是党风廉政建设的领导者、执行者、推动者，要时刻把党风廉政建设主体责任抓在手上、扛在肩上，与国土资源管理工作同部署、同落实、同检查、同考核，全力推进党风廉政建设和反腐败工作。局党组成员要带头执行廉洁从政相关规定，做廉洁自律的表率，自觉接受组织和群众的监督。为此，适时召开2017党风廉政建设和反腐败工作部署大会，签订2017年党风廉政建设责任书。针对市纪委巡查和问责的重点（党的领导弱化、党的建设缺失、从严治党责任落实不到位、对维护党的政治纪律和政治规矩失责、贯彻中央八项规定精神不力、不作为乱作为等），组织科以上的党员干部学习市纪委转发的《海南省委贯彻〈中国共产党问责条例〉实施办法》，对照检查我局和个人还存在哪方面的问题，哪方面还需要整改提高。通过自查自纠，提高执行党的政治纪律、政治规矩、组织纪律的自觉性。同时，有效运用监督执纪“四种形态”，在加强我局党员干部队伍的日常管理监督上下功夫，牢固树立责任意识、廉洁意识，不断推进管党治党从宽松软走向严紧硬，推动我局党组主体责任有效落实。

三、扎实抓好党风廉政教育，强化批评和自我批评

要结合“两学一做”学习教育，扎实抓好党风廉政教育。在上半年，局党组书记、局党组成员要给全局党员干部讲廉政党课，增强党员干部的廉洁自律意识；组织一到两次勤政、廉政先进典型示范教育活动，牢固树立向先进典型看齐意识，增强自我净化、自我完善、自我提高能力。在下半年，将邀请省内专家给全局党员干部讲党风廉政风险防控课，适时组织开展一到两次反面典型警示教育活动，做到警钟长鸣，增强全局党员干部队伍的拒腐防变能力。在全局经常开展提醒谈话活动，发现问题及时提醒，使咬耳朵、扯袖子，红红脸、出出汗成为常态。把批评和自我批评贯穿到全局工作生活中，并形成一种新常态。让全体党员干部自觉遵守党纪党规，自觉抵制“四风”；让严格贯彻执行中央八项规定精神，深化风纪作律建设，不断改进工作作风在我局生根开花结果。

四、继续发挥队伍思想形势分析研判机制作用，强化治本抓源意识

我局去年建立的队伍思想形势分析研判机制，为我局2016年的党风廉政建设发挥了不可或缺的积极作用。今年将继续坚持队伍思想形势分析研判机制，不断完善我局党员干部职工队伍管理的长效机制。紧密结合本单位的实际检查落实中央八项规定和省市二十条规定精神措施的执行情况，对不适应实际情况的制度措施加以修订，对需要马上建立的制度抓紧制定。针对我局聘用人员多，管理无制度的问题，纪检组要会同办公室和相关部门制定出台我局聘用人员管理规定，不断完善规章制度，不断巩固深化作风纪律建设的成果。同时局党组要认真落实习近平总书记“把权力关进制度的笼子里”的讲话要求，立足于建立“提前防范、主动防范”的长效工作机制。加强对纪检联络员队伍的培训，不断提高他们抓党风廉政建设的工作能力；加大对重点环节的监管力度，着力强化内部风险控制；加强对权力运行的监督和制约，让权力在阳光下运行，从源头上防治腐败。

五、全面推进我局党风政风行风建设，强化为人民服务的宗旨

在2016年党风政风行风建设社会评价市纪委反馈意见函中，排名相较2015年有所进步，但与为人民服务的宗旨还相差较远。为此，2017年将以2016年党风政风行风建设社会评价市纪委反馈意见建议的整改方案为抓手，对局机关、下属单位、各分局进行全面督促检查。抓工作纪律，养成良好的工作作风；抓服务质量，养成良好的为人民服务态度；抓办事效率，养成良好的马上就办精神。促进我局党风政风行风建设在2017年再上一个新台阶。

三亚市国土资源局

2017年党风廉政建设主要工作一览表

季度

主要工作

第一季度

1.召开局党组专题会议，研究部署2017年党风廉政建设和反腐败工作，明确2017年党风廉政建设主要任务，制定我局《2017年党风廉政建设和反腐败工作实施方案》。

2.召开我局2017年党风廉政建设和反腐败工作部署大会，组织签订《2017年党风廉政建设责任书》。

3.组织局党组成员学习习近平中纪委七次全会重要讲话精神；组织科以上干部学习市纪委转发的《中共海南省纪委关于运用监督执纪“四种形态”的指导意见》、《海南省贯彻〈中国共产党问责条例〉实施办法》。

4.为加强聘用人员管理，完善《三亚市国土资源局聘用人员管理办法》，报局党组同意后印发实施。

5.为抓好市纪委反馈意见的整改落实，根据我局《2016年党风政风行风建设社会评价市纪委反馈意见建议的整改方案》，对局机关、下属单位、各分局进行一次全面督促检查，并讲评整改情况；为加强社会监督，设立、更新局机关及下属单位、分局的投诉举报意见箱。

6.到海口局就纪检监察的机构设置、工作职能和党风廉政建设等情况进行调研学习，组建好我局纪检监察科（室），用他山之石推动我局的党风廉政建设。

7.对我局第一季度党风廉政建设、“两个责任”落实情况和全局干部职工队伍思想形势进行分析，深入查找问题和隐患，有针对性的抓好整改落实。

8.报送局党组成员第一季度开展谈话提醒工作情况；及时传达学习上级纪委和省厅有关文件、通报，完成上级部署的党风廉政建设和反腐败其他重要工作。

第二季度

1.第一季度未完成的工作顺延到第二季度。

2.为增强党员干部廉洁意识，局党组书记局长给全体党员干部上一堂党风廉政课；组织开展一到两次先进典型示范教育活动，发挥好先进典型的示范引领作用。

3.为促进我局党风政风行风建设水平提升，根据我局整改方案，进行第二次全面督促检查讲评，并对2017年党风政风行风社会评价活动进行部署，提出相关要求。

4. 对我局上半年党风廉政建设和“两个责任”落实情况进行半年总结，对下半年工作进行部署。对第二季度全局系统干部职工队伍思想形势进行分析，排查苗头和隐患，及时解决存在问题。

5.报送局党组成员第二季度开展谈话提醒工作情况；及时传达学习上级纪委和省厅有关文件、通报，完成上级部署的党风廉政建设和反腐败其他重要工作。

第三季度

1.为提升党员干部的拒腐防变能力，邀请专家来我局讲一次有关廉政风险防控的党课；组织开展一到两次反面典型案例警示教育，督促党员干部做到警钟长鸣，筑牢廉洁自律的思想防线。

2.为提高我局纪检联络员的工作能力，积极协调我局纪检联络员参加市纪委和省纪委派驻国土厅纪检组组织的培训。

3.及时向市纪委上报我局2017年党风政风行风社会评价活动的有关材料，做好有关准备工作。

4.对我局第三季度党风廉政建设、“两个责任”落实情况和全局系统干部职工队伍思想形势进行分析，排查苗头和隐患，抓好相关问题的整改落实。

5.报送局党组成员第三季度开展谈话提醒工作情况；及时传达学习上级纪委和省厅有关文件、通报，完成上级部署的党风廉政建设和反腐败其他重要工作。

第四季度

1.组织我局干部队伍开展述职述廉，并按要求上报上级部门。

2.向省纪委派驻国土厅纪检组、省厅党组和市纪委书面报告2017年度党风廉政建设主体责任和监督责任的落实情况。

3.根据2017年党风政风行风社会评价活动中市纪委反馈意见，制定整改方案，抓好整改落实。

4.报送局党组成员第四季度开展谈话提醒工作情况；及时传达学习上级纪委和省厅有关文件、通报，完成上级部署的党风廉政建设和反腐败其他重要工作。
