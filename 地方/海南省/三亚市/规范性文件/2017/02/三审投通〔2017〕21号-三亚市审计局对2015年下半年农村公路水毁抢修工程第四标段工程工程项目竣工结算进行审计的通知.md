# 三亚市审计局对2015年下半年农村公路水毁抢修工程第四标段工程工程项目竣工结算进行审计的通知

市水务局：

根据《中华人民共和国审计法》第二十二条规定，我局决定派出审计组，自2017年1月23日起，对你单位负责建设的2015年下半年农村公路水毁抢修工程第四标段工程竣工结算进行审计，必要时将追溯到相关年度或者将对与项目直接有关的设计、施工、监理、供货等单位取得项目资金的真实性、合法性进行调查，并通知相关单位。请予积极配合，并提供有关资料（包括电子数据资料）和必要的工作条件。

审计组组长：翁娇金

组 员：郑茹方（兼职廉政监督员）

林鸿利（北京华信今朝国际工程咨询有限公司）

附件：三亚市审计局关于审计纪律的规定

三亚市审计局

2017年1月18日
