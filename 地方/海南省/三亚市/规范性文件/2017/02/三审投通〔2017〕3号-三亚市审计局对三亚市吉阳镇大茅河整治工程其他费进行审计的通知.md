# 三亚市审计局对三亚市吉阳镇大茅河整治工程其他费进行审计的通知

三审投通〔2017〕3号

三亚市审计局

对三亚市吉阳镇大茅河整治工程

其他费进行审计的通知

市水务局：

根据《中华人民共和国审计法》第二十二条的规定，我局决定派出审计组，自2017年1月12日起，对你单位负责建设的三亚市吉阳镇大茅河整治工程其他费进行审计，必要时将追溯到相关年度或者将对与项目直接有关的代建、施工、设计、监理、供货等单位取得项目资金的真实性、合法性进行调查，并通知相关单位。请予积极配合，并提供有关资料（包括电子数据资料）和必要的工作条件。

审计组组长：钟祥严

组 员：张春香（兼职廉政监督员）

附件：三亚市审计局关于审计纪律的规定

三亚市审计局

2017年1月10日

（此件主动公开）
