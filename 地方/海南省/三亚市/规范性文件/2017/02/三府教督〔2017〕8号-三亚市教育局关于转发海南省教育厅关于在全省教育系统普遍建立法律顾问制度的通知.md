# 三亚市教育局关于转发海南省教育厅关于在全省教育系统普遍建立法律顾问制度的通知

海南省教育厅关于在全省教育系统

普遍建立法律顾问制度的通知

各区教科局、市教育局机关及事业科室、市教育局直属学校（幼儿园）：

为全面推进我市教育系统依法治教，促进教育治理体系和治理能力的现代化，根据教育部《依法治教实施纲要（2016-2020年）》及《海南省依法治教实施规划（2016-2020年）》要求，海南省教育厅将在全省教育系统普遍建立法律顾问制度，现将《海南省教育厅关于在全省教育系统普遍建立法律顾问制度的通知》（琼教法〔2017〕8号）转发给你们，请依照文件精神认真贯彻落实。市教育局负责局机关和直属学校的法律顾问配备，各区教科局负责区属学校的法律顾问配备。请各区教科局在2017年底前要配备法律顾问，在2018年底前，推动落实属地普通中小学和幼儿园普遍配备法律顾问，实现全市教育系统法律顾问制度全覆盖，全面建成我市教育系统法律顾问制度体系。

海南省教育厅将根据（琼教法〔2017〕8号）关于建立法律顾问制度的时间表和具体要求，对各地各校的相关工作开展检查。各区各学校工作推进情况请及时报送市政府教育督导室。联系人：张燕雄，电话：88657896，电子邮箱：88213055@163.com。
