# 三亚市教育局转发海南省教育厅关于印发海南省中小学老师违反职业道德行为处理实施细则（试行）的通知

三亚市教育局转发海南省教育厅关于印发

海南省中小学老师违反职业道德行为

处理实施细则（试行）的通知

各区教科局、市教育局直属学校（幼儿园）：

现将《海南省教育厅关于印发海南省中小学老师违反职业道德行为处理实施细则（试行）的通知》（琼教师〔2017〕16号）转发给你们，各区各直属学校要高度重视，组织教师深入学习贯彻落实。同时要加强对教师的管理，实施过程遇到的情况和问题，要及时报告我局。

三亚市教育局

2017年2月8日
