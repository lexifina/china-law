# 三亚市林业局关于三亚市海棠湾湾坡片区危旧房改造（安居工程）项目办理林地审核的通告

为做好三亚市海棠湾湾坡片区危旧房改造（安居工程）项目办理林地审核和林业相关手续工作，根据2015年2月15日国家林业局令第35号下发的《建设项目使用林地审核审批管理办法》第十一条“县级人民政府林业主管部门对建设项目拟使用的林地，应当在林地所在地的村（组）或者林场范围内将拟使用林地用途、范围、面积等内容进行公示，公示期不少于5个工作日。”及有关法律法规规定。现将有关情况通告如下：

一、项目名称：三亚市海棠湾湾坡片区危旧房改造（安居工程）项目

二、用途：湾坡片区危旧房改造建设用地。

三、项目用地范围：该项目位于三亚市海棠区湾坡片区区域。所使用林地面积在《三亚市林地保护利用规划（2010-2020年）》规划内的Ⅲ级林地面积2.9459公顷、Ⅳ级林地面积0.8186，规划外林地（已核发林权证）面积1.0930公顷。具体详见：海棠湾湾坡片区危旧房改造（安居工程）项目用地红线图。

四、通告期限：5个工作日（2017年2月8日至2017年2月14日）。
