# 三亚市交通运输局关于临时调整途经胜利路段（光明街至新风街）公交线路的通告

关于临时调整途经胜利路段（光明街至新风街）

公交线路的通告

由于胜利路地下综合管廊建设施工需要，市公安局交通警察支队将于2017年2月27日至8月27日期间对胜利路段（光明街至新风街）实施交通管制，为方便市民和游客乘坐公交车，决定对途经上述路段的公交线路作如下临时调整：

一、3路公交线路往半岭温泉方向由原行驶胜利路（步行街口）至新风街调整为：光明街―解放路―新风街，往蓝色果岭方向行驶路线不变；

二、9路公交线路往崖州古越方向由原行驶胜利路（步行街口）至新风街调整为：光明街―解放路―新风街，往凤凰岛方向行驶路线不变；

三、11路公交线路往同心家园五期方向由原行驶胜利路（步行街口）至新风街调整为：光明街―解放路―新风街，往凤凰岛方向行驶路线不变；

四、15路公交线路往海底世界方向由原行驶胜利路（步行街口）至新风街调整为：光明街―解放路―新风街，往火车站方向行驶路线不变；

五、19路公交线路往凤凰岛方向由原行驶胜利路（步行街口）至新风街调整为：光明街―解放路―新风街，往安游方向行驶路线不变；

六、23路公交线路往南田农场方向由原行驶胜利路（步行街口）至老铁路调整为：光明街―解放路―新风街―老铁路，往凤凰岛方向行驶路线不变；

七、25路公交线路往海底世界方向由原行驶胜利路（步行街口）至新风街调整为：光明街―解放路―新风街，往大小洞天方向行驶路线不变；

八、26路公交线路往天涯海角方向由原行驶胜利路（步行街口）至老铁路调整为：光明街―解放路―新风街―老铁路，往蓝色果岭方向行驶路线不变；

九、28路公交线路往蜈支洲岛方向由原行驶胜利路（步行街口）至新风街调整为：光明街―解放路―新风街，往凤凰岛方向行驶路线不变；

十、42路公交线路往客运西站方向由原行驶胜利路（步行街口）、新风街至解放路调整为：光明街―解放路，往凤凰岛方向行驶路线不变；

十一、49路公交线路往槟榔河温泉方向由原行驶胜利路（步行街口）、新风街至解放路调整为：光明街―解放路，往凤凰岛方向行驶路线不变；

十二、56路公交线路往火车站方向由原行驶胜利路（步行街口）至老铁路调整为：光明街―解放路―新风街―老铁路，往实验中学方向行驶路线不变；

十三、57路公交线路往南滨农场方向由原行驶解放路、光明街、胜利路（步行街口）至老铁路调整为：新风街―老铁路，往城市乐园方向行驶路线不变；

十四、58路公交线路往崖州中心渔港方向由原行驶胜利路（步行街口）、新风街至解放路调整为：光明街―解放路，往南边海方向行驶路线不变。

临时交通管制解除后公交线路将恢复原行驶路线，对交通管制期间公交线路临时调整带来的不便，请广大市民和游客给予理解和支持。

三亚市交通运输局

2017年2月23日
