# 三亚市交通运输局关于配合做好2016年度公交成本与收入规制成本监审工作的通知

三亚市公共交通集团有限公司、三亚海棠湾公共交通有限公司：

根据《三亚市城市公交成本与收入规制实施办法（试行）》办法要求，目前市财政局已选定中介监审机构，将对你公司2016年度公交成本与收入进行监审。请你公司积极配合中介监审机构做好成本监审工作。

特此通知

三亚市交通运输局

2017年3月14日
