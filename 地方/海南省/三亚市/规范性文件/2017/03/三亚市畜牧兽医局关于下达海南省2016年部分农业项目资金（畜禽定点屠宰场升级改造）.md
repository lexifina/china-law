# 三亚市畜牧兽医局关于下达海南省2016年部分农业项目资金（畜禽定点屠宰场升级改造）

三亚益民肉联实业有限公司：

根据《海南省财政厅关于下达2016年部分农业项目资金（第二批）的通知》（琼财农〔2016〕680号）和《海南省农业厅关于印发开展服务农业投资百日大行动工作方案的通知》（琼农字〔2016〕135号）等文件精神，结合项目审核、公示、专家评审结果和项目批复，安排你单位2016年部分农业项目资金50万元，专项用于畜禽定点屠宰场升级改造项目，建设肉牛屠宰车间、分割车间、待宰间和存栏间。请依照国家相关项目管理规定、批复的建设规模及内容和项目协议要求，规范项目工作程序和财务管理，专项核算，专款专用。根据项目实施进度，现将2016年部分农业项目资金（畜禽定点屠宰场升级改造）第二批25万元下达给你单位，要发挥好财政资金应有效益，进一步提升屠宰加工能力，保障“菜篮子”肉品供应，建立相关管理制度，完善各项工作措施，收集、整理、归档有关资料。
