# 关于成立三亚市交通运输局普法依法治理工作领导小组的通知

局机关各科室，各事业单位，重点项目组：

为加强我市交通运输普法依法治理工作领导，不断推动法治宣传教育和依法治理工作，经研究，决定成立三亚市交通运输局普法依法治理工作领导小组。现将有关事项通知如下：

一、主要职责：

研究贯彻推进法治宣传教育和依法治理工作的重要会议精神和具体落实意见；组织制定普法依法治理工作规划、计划，并负责监督落实；听取领导小组办公室关于法治宣传教育和依法治理工作年度执行情况的汇报，安排部署年度重点工作；讨论决定普法依法治理工作中的重要事项，解决存在的问题。

二、组成人员

组 长：吴海峰 局党组书记、局长

副组长：陈凤祥 局党组成员、副局长

刘万祥 局党组成员、副局长

唐和良 局党组成员、道路运输管理处处长

朱光泽 局副调研员

袁泽华 局副调研员

聂汉桥 局副调研员

王 强 局副调研员

成 员：机关各科室、各事业单位及重点项目组负责人

三、工作机构：

局普法工作领导小组办公室设在法规监察科。局党组成员、副局长刘万祥兼任主任；局法规监察科科长张鹏任副主任；各科室、单位有关负责人组成办公室成员。具体承担的职责是：及时向局普法工作领导小组报告普法依法治理工作；根据三亚市普法依法治理领导小组办公室部署，组织实施交通运输“七五”普法依法治理工作规划、拟定年度工作计划或工作要点；分解细化普法依法治理工作任务；组织开展法治宣传教育活动；承办局普法工作领导小组交办的其它工作任务。
