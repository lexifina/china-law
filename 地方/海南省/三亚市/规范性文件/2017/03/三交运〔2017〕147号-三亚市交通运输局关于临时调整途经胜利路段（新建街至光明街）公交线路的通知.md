# 三亚市交通运输局关于临时调整途经胜利路段（新建街至光明街）公交线路的通知

三交运〔2017〕147号

三亚市交通运输局

关于临时调整途经胜利路段（新建街至光明街）

公交线路的通知

各相关公交企业：

由于胜利路地下综合管廊建设施工需要，三亚市公安局交通警察支队将于2017年3月23日起对胜利路段（新建街至光明街）实施交通管制，双向禁止机动车通行。经研究，决定对途经上述路段的公交线路作如下临时调整：

一、3路公交线路往半岭温泉方向由原行驶榆亚路―建港路―胜利路―光明街―解放路―新风街―河西路调整为：榆亚路―解放路―新风街―河西路；往蓝色果岭方向由原行驶光明街―胜利路―建港路―榆亚路调整为：光明街―解放路―榆亚路。

二、12路公交线路往市政府方向由原行驶三亚湾路―光明街―胜利路―建港路―榆亚路调整为：三亚湾路―光明街―解放路―榆亚路；往火车站方向行驶路线不变。

三、19路公交线路往安游方向由原行驶光明街―胜利路―建港路―榆亚路调整为：光明街―解放路―榆亚路；往凤凰岛方向由原行驶榆亚路―建港路―胜利路―光明街―解放路调整为榆亚路―解放路。

四、56路公交线路往火车站方向由原行驶榆亚路―建港路―胜利路―光明街―解放路―新风街―老铁路调整为：榆亚路―河西路―新风街―老铁路；往实验中学方向行驶路线不变。

五、58路公交线路往崖州中心渔港方向由原行驶榆亚路―建港路―胜利路―光明街―解放路调整为：榆亚路―解放路；往南边海方向由解放路―新风街―三亚湾路―光明街―胜利路―建港路―榆亚路调整为：解放路―榆亚路。

各相关公交企业务必确保上述公交线路按照临时调整确定的路线行驶，停靠相应路段的公交站点，并做好公交车辆腰牌和报站器的更新工作，三亚市公共交通集团有限公司于2017年3月23日前完成公交站牌线路信息的刷新工作。
