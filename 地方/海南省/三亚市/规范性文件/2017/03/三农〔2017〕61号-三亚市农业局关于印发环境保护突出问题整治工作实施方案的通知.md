# 三亚市农业局关于印发环境保护突出问题整治工作实施方案的通知

各区政府、育才生态区管委会，局机关各科室、各下属单位：

根据市政府关于《印发开展环境保护突出问题整治工作实施方案的通知》（三府办〔2017〕47号）文件精神，为进一步解决我市农业环境保护突出问题，推进“创文巩卫”、“美丽乡村”建设，特制定并印发《三亚市农业局环境保护突出问题整治工作实施方案》，请认真贯彻执行。
