# 三亚市农业局关于贯彻执行琼农生态〔2017〕2号文件做好农村沼气安全生产工作的通知

育才生态区管委会，各区农林局：

为营造安全稳定的社会环境氛围，迎接2017年博鳌亚洲论坛年会和省第七次党代会的胜利召开，海南省农业生态与资源保护总站下发《关于做好2017年博鳌亚洲论坛年会和省第七次党代会期间农村沼气安全生产工作的通知》（琼农生态〔2017〕2号），现将文件转发给你们。

各单位要认真领会文件精神，牢固树立安全生产永远在路上的观念，继续深入开展沼气生产安全隐患大排查，切实做好我市沼气安全生产工作。请于4月30日前将工作落实情况（纸质版盖公章）报市农业局科教科，电子版发市农业局科教科邮箱。
