# 三亚市农业局关于2016年农产品质量安全监管责任书考核的通知

各区人民政府、育才生态区管委会，各国营农场：

根据《三亚市人民政府办公室关于印发三亚市2016年农产品质量安全监管责任书考核方案的通知》（三府办〔2017〕43号）精神，市政府对各单位2016年农产品质量安全监管工作情况进行考核。考核工作由市考核领导小组办公室具体负责，即由市农业局牵头，市海洋渔业局、市畜牧兽医局参加（考核组人员名单见附件1）。时间定在2017年3月27日-31日（具体时间安排见附件2），请各单位按照市政府考核方案做好迎考准备。
