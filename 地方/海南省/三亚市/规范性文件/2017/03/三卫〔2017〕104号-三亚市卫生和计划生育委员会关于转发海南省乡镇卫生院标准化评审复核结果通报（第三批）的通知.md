# 三亚市卫生和计划生育委员会关于转发海南省乡镇卫生院标准化评审复核结果通报（第三批）的通知

三卫〔2017〕104号

三亚市卫生和计划生育委员会

关于转发海南省乡镇卫生院标准化评审

复核结果通报（第三批）的通知

各区卫生和计生局，育才卫生院：

现将《海南省卫生和计划生育委员会关于海南省乡镇卫生院标准化评审复核结果的通报（第三批）》（琼卫基层〔2017〕5号）转发给你们，为做好2017年度省级标准化乡镇卫生院复评工作，就有关事项通知如下：

一、请各单位认真分析2016年度评审复核结果，充分将评审结果运用到卫生院的管理工作中。各受评卫生院要根据评审专家组评估反馈意见，逐条逐项分解细化到科室，对复核中存在的问题，要制定针对性措施进行整改。

二、省级标准化乡镇卫生院复评结果是政府医改工作考核指标之一。各单位要继续开展卫生院标准化建设工作，并于2017年6月9日前将本年度参加复评的卫生院报送到市卫计委基层指导科，以便于开展本年度省级标准化乡镇卫生院复评工作。

附件：1.海南省卫生和计划生育委员会关于海南省乡镇卫生院标准化评审复核结果的通报（第三批）

2.海南省标准化乡镇卫生院评估标准（试行）
