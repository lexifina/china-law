# 三亚市教育局转发海南省教育厅关于印发2017年海南省初中毕业生学业水平考试物理和化学实验操作技能考查方案的通知

各区教科局，市教育局直属各中学：

现将《海南省教育厅关于印发<2017年海南省初中毕业生学业水平考试物理和化学实验操作技能考查方案>的通知》（琼教中招〔2017〕6号）转发给你们，现结合我市实际提出如下要求：

一、考查时间

我市各中学物理和化学实验操作技能考查安排在4月20日-4月30日，不得提前或延后。请各校于4月15日前将本校安排考查的具体时间报市中招办。各校在进行物理和化学实验操作技能考查过程中，市中招办将与各区教科局一起，根据情况对各校考查操作情况进行检查。

二、考查结果上报时间和方法

考查结束后，将考查结果连同考生综合素质评价结果一起报市中招办。发送电子版时要将文件名改为“学校名称+上报内容”。

三、考查结果上报格式

以Excel格式上报，上报格式如下：

XX中学物理化学实验操作及综合素质评价结果一栏表

序号

准考证号

姓名

性别

物理等级

化学等级

综合素质评价等级
