# 三亚市教育局关于组织征订2017年度《心系下一代》的通知

各区教科局、育才生态区社会事务局，市直属各学校（幼儿园）：

《心系下一代》杂志是教育部关工委会刊，是教育系统关工委工作的指导性刊物。该刊是传达上级精神的重要平台、交流工作经验的互动阵地、“五老”工作者的良师益友、关工委事业的宣传窗口。服务对象为各地教育关工委、各类学校关工委，广大关心下一代工作的老同志、社区教育工作者和青少年德育工作者。

《心系下一代》为双月刊，逢单月20日出版。杂志每期10元，全年6期共60元。

请各区教科局、育才生态区社会事务局、市直属学校（幼儿园），根据实际情况征订，各区还要组织动员所属学校征订。

特别提示：

1.根据教育部关工委教关委函〔2010〕20号文，单位可以用关工委的工作经费订阅。

2.各单位可采取集体订阅或个人订阅的形式，杂志由邮局直接寄送到单位或个人。
