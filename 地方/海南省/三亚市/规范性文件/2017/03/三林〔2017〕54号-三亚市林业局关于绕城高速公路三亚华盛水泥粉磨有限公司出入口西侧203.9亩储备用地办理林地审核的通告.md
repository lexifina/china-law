# 三亚市林业局关于绕城高速公路三亚华盛水泥粉磨有限公司出入口西侧203.9亩储备用地办理林地审核的通告

三林〔2017〕54号

三亚市林业局

关于绕城高速公路三亚华盛水泥粉磨有限公司出入口西侧203.9亩储备用地

办理林地审核的通告

为做好绕城高速公路三亚华盛水泥粉磨有限公司出入口西侧203.9亩储备用地项目办理林地审核和林业相关手续工作，根据2015年2月15日国家林业局令第35号下发的《建设项目使用林地审核审批管理办法》第十一条“县级人民政府林业主管部门对建设项目拟使用的林地，应当在林地所在地的村（组）或者林场范围内将拟使用林地用途、范围、面积等内容进行公示，公示期不少于5个工作日。”及有关法律法规规定。现将有关情况通告如下：

一、项目名称：绕城高速公路三亚华盛水泥粉磨有限公司出入口西侧203.9亩储备用地

二、用途：储备用地，拟为科研建设用地。

三、项目用地范围：该项目位于三亚市吉阳区荔枝沟抱坡岭绕城高速公路三亚华盛水泥粉磨有限公司出入口西侧。所使用林地面积占《三亚市林地保护利用规划（2010-2020年）》规划外林地（已核发林权证）面积4.9613公顷。具体详见：抱坡岭水泥厂勘测定界图。

四、通告期限：5个工作日（2017年3月9日至2017年3月15日）。
