# 三亚市林业局关于三亚市吉阳区三娘村公墓项目（二期工程）办理林地审核的通告

关于三亚市吉阳区三娘村公墓项目

（二期工程）办理林地审核的通告

为做好三亚市吉阳区三娘村公墓项目（二期工程）办理林地审核和林业相关手续工作，根据2015年2月15日国家林业局令第35号下发的《建设项目使用林地审核审批管理办法》第十一条“县级人民政府林业主管部门对建设项目拟使用的林地，应当在林地所在地的村（组）或者林场范围内将拟使用林地用途、范围、面积等内容进行公示，公示期不少于5个工作日。”及有关法律法规规定。现将有关情况通告如下：

一、项目名称：三亚市吉阳区三娘村公墓项目（二期工程）

二、用途：三娘村公墓建设用地。

三、项目用地范围：该项目位于三亚市吉阳区三娘村东侧坡地区域。所使用林地面积占《三亚市林地保护利用规划（2010-2020年）》规划内的林地面积11.8138公顷，规划外已核发林权证面积0.0005公顷。具体详见：吉阳区三娘村公墓二期用地界址图。

四、通告期限：5个工作日（2017年3月16日至2017年3月22日）。
