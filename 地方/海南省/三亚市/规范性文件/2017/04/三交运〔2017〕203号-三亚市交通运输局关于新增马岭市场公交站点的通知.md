# 三亚市交通运输局关于新增马岭市场公交站点的通知

新国线集团（海南）运输有限公司三亚分公司、三亚怡兰公共交通有限公司：

为合理设置公交站点，方便市民和游客乘坐公交车，经研究，决定在G225国道“天涯派出所”和“天涯邮政”公交站点之间增加“马岭市场”公交站点。请你公司务必做好所属16路和25路公交车辆的腰牌及报站器的更新工作，自2017年4月15日起按照新增的停靠站点提供运营服务。三亚市公共交通集团有限公司负责在上述公交站点设立临时公交站牌，并于2017年4月15日前完成公交站牌线路信息的刷新工作。

三亚市交通运输局

2017年4月12日
