# 三亚市交通运输局关于新增云港创业基地和南繁研发中心公交站点的通知

三交运〔2017〕214号

三亚市交通运输局

关于新增云港创业基地和南繁研发中心

公交站点的通知

各相关公交企业：

为合理设置公交站点，保障三亚高新技术产业园区工作人员便捷出行，经研究，决定在吉阳大道“海螺姑娘园”和“逸夫中学”公交站点之间增加“云港创业基地”公交站点，“亚龙湾火车站”和“京润珍珠馆”公交站点之间增加“南繁研发中心”公交站点，将“军坡村”公交站点更名为“和泓假日阳光”。

本月28日开始，18路公交线路的公交车停靠南繁研发中心公交站点；9路、20路、33路等3条公交线路的公交车停靠和泓假日阳光、云港创业基地公交站点；34路、35路公交线路的公交车停靠和泓假日阳光、云港创业基地和南繁研发中心公交站点。请各相关公交企业务必做好所属公交车辆的腰牌及报站器的更新工作。三亚市公共交通集团有限公司负责在“云港创业基地”和“南繁研发中心”公交站点设立建设临时公交站牌，并于2017年4月24日前完成公交站牌线路信息的刷新工作。

三亚市交通运输局

2017年4月21日
