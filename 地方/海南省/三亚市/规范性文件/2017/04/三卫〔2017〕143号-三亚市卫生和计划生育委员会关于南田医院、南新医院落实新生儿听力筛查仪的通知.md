# 三亚市卫生和计划生育委员会关于南田医院、南新医院落实新生儿听力筛查仪的通知

三卫〔2017〕143号

三亚市卫生和计划生育委员会

关于南田医院、南新医院落实新生儿听力

筛查仪的通知

吉阳区卫计局、海棠区卫计局：

新生儿遗传代谢性疾病与新生儿听力筛查是2017年省、市政府为民办实事的民生项目，南田医院和南新医院是目前我市年分娩量超过400人的三个基层卫生单位中的两个。其中南新医院两项筛查工作均已开展，但因筛查仪故障原因，该院从去年年底至今新生儿听力筛查工作已停止；另外，南田医院目前仅开展新生儿遗传代谢性疾病筛查，新生儿听力筛查因自行采购的听力筛查仪型号不符合开展新生儿听力筛查所要求的技术参数标准，造成新生儿听力筛查工作无法开展。这两家单位年分娩量较大，如不解决听力筛查仪的问题，势必影响我市新生儿听力筛查总体工作的实施。为推动全市新生儿听力筛查工作顺利开展，更好的完成省市政府的工作目标任务，请吉阳区卫计局和海棠区卫计局督促南新医院和南田医院尽快按要求解决新生儿听力筛查仪配置的问题，确保筛查工作顺利开展。

三亚市卫生和计划生育委员会

2017年4月12日

（此件主动公开）

抄送:各区卫计局，委直属各医疗卫生单位，省第三人民医院，

解放军425医院，育才卫生院。

三亚市卫生和计划生育委员会公室 2017年4月12日印发
