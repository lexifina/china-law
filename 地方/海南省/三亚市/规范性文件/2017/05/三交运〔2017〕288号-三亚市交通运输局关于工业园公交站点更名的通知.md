# 三亚市交通运输局关于工业园公交站点更名的通知

各相关公交企业：

原海润路椰子林工业园已撤消，为了方便市民、游客乘坐公交车，经研究，决定将“工业园”公交站点更名为“汇润花园”。三亚泰和旅游交通发展有限公司要做好途径31路公交线路运营车辆腰牌和报站器数据的更新，三亚市公共交通集团有限公司于2017年5月30日前完成公交站牌线路信息的刷新工作。

特此通知

三亚市交通运输局

2017年5月24日
