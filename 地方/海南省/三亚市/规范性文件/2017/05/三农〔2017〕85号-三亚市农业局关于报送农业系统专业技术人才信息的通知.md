# 三亚市农业局关于报送农业系统专业技术人才信息的通知

各下属事业单位，局机关农产品质量安全监管科、农业科技教育科：

为清晰、直观、较为详细的了解全市农业技术人才现状、为今后制定相关政策、人才培养和深化职称制度改革工作提供依据、指导我市基层农业技术服务体系建设工作，请各单位统计相关专业技术人员信息并报农业局科教科，由科教科汇总后建立农业系统专业技术人才信息库。

各单位务必高度重视，安排专人负责并积极配合，主动开展工作，并于5月19日下午下班前报至科教科邮箱。

附件：1.农产品质量安全监督员信息表

2.畜牧兽医员信息表

3.农业技术推广员信息表

4.沼气技术员信息表

5.农业机械化技术员信息表

6.农业系统专业技术人才信息表

三亚市农业局
