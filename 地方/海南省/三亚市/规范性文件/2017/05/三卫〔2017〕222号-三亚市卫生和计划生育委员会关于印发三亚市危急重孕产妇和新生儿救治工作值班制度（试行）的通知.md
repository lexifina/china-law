# 三亚市卫生和计划生育委员会关于印发三亚市危急重孕产妇和新生儿救治工作值班制度（试行）的通知

三卫〔2017〕222号

三亚市卫生和计划生育委员会

关于印发三亚市危急重孕产妇和新生儿救治

工作值班制度（试行）的通知

各区卫计局、委直属各医疗卫生单位：

现将《三亚市危急重孕产妇和新生儿救治工作值班制度（试行）》印发给你们，请认真执行。

三亚市卫生和计划生育委员会

2017年5月17日

三亚市危急重孕产妇和新生儿救治工作

值班制度（试行）

为保障三亚市危急重孕产妇和新生儿救治工作顺利开展，规范危急重孕产妇和新生儿日常救治工作，建立高效、有序的危急重孕产妇和新生儿救治、转诊协调机制，制定本值班制度。

一、 值班方式

值班方式为微信平台值班和电话值班，不设固定值班场所。

（一）微信平台值班。成立三亚市危急重孕产妇和新生

儿救治工作领导小组，并下设办公室，办公室设在卫计委妇幼健康科，郑通勤副主任为主任，蓝碧科长为副主任。同时设立“三亚市产科重症”和“三亚市新生儿重症” 微信工作群；“三亚市产科重症”微信群要求全市各级医疗保健机构的妇产科主任加入，“三亚市新生儿重症”微信群要求全市各级设有儿科的主任加入。

（二）电话值班。我市产儿科重症救治中心设在农垦三亚医院，并设立24小时行政值班电话，危重孕产妇救治24小时值班电话：38225783 38225784 ；危重新生儿救治24小时值班电话：38225855。

二、值班安排

救治办公室负责全面指挥、领导与协调值班工作；救治办副主任协助做好值班具体管理工作。

微信平台值班，由省第三人民医院妇产科和新生儿科值班专家担任，具体负责在线或现场指导全市诊疗单位做好危急重孕产妇和新生儿救治工作，并根据情况做出转诊决定。

电话值班由省第三人民医院救治中心安排医院相关人员担任，负责微信平台的危急重孕产妇和新生儿信息受理、协调联络工作，包括提醒值班专家及时指导救治，受理值班专家反馈报告，联系跟踪危重病人，向救治办公室报告、收集和分析病例信息等。

三、 值班流程

（一）全市各级各类医疗卫生单位首诊医生发现危急重孕产妇和新生儿应及时向科室负责人报告，并组织本院专家进行会诊、制定治疗方案；如本单位无条件救治的危急重孕产妇和新生儿，要及时向救治中心转诊，争取抢救时间，如不便于转诊需要专家会诊和提供技术支援的，由领导及时向本市危急重孕产妇和新生儿救治工作领导小组办公室报告，由办公室协调专家进行会诊和指导治疗，待条件允许后及时转诊；在救治期间，需要市级专家组成员提供技术指导的，由治疗科室负责人将危急重孕产妇和新生儿相关信息放至“三亚市产科重症”和“三亚市新生儿重症”微信平台，发出援助信息。

（二）“三亚市产科重症”和“三亚市新生儿重症”微信平台值班专家对上传的危急重孕产妇和新生儿相关信息进行分析，在线指导，必要时救治办公室派专家到场指导救治；需转诊的病人，由值班专家做出决定并协调安排；对严重复杂病例，由值班专家提出，专家组组长组织相关专家会诊；值班专家遇协调困难的，应及时上报救治办公室，办公室根据具体情况协调领导小组成员单位予以解决。

（三）值班人员要关注“三亚市产科重症”和“三亚市新生儿重症” 微信平台，及时收集各医疗卫生单位上传的危重孕产妇和新生儿信息，及时协调和指导救治工作，特殊情况要及时向救治办公室报告。

四、相关要求

（一）救治中心要认真安排好孕产妇和新生儿专家值班工作，以月为单位进行安排，并报备救治办公室备案。

（二）值班专家和电话值班人员要遵守值班纪律，及时查看“三亚市产科重症”和“三亚市新生儿重症”微信平台信息，保持值班电话通畅，以免耽误危重孕产妇和新生儿的救治。

（三）经专家评估决定转诊的危急重孕产妇和新生儿，原则转诊至省第三人民医院，由省第三人民医院安排专人专车接诊，或通过120派车。如省第三人民医院没有床位接收时，由值班专家报救治办公室协调转诊至其他医疗卫生单位。

（四）需要专家到基层会诊、现场指导救治，由专家所在的单位安排车辆，产生的差旅费、会诊费由专家所在的单位解决，不得由病人支付。

（五）省血液中心三亚分中心要优先保障危急重孕产妇和新生儿救治临床用血，共同做好危重孕产妇和新生儿救治工作。

（六）各区卫计局、育才管委会要按本通知要求，相应制定本辖区危急重孕产妇和新生儿救治值班制度并组织实施。
