# 三亚市林业局关于亚龙湾第二通道（一期）工程项目办理林地审核的通告

为做好亚龙湾第二通道（一期）工程项目办理林地审核和林业相关手续工作，根据2015年2月15日国家林业局令第35号下发的《建设项目使用林地审核审批管理办法》第十一条“县级人民政府林业主管部门对建设项目拟使用的林地，应当在林地所在地的村（组）或者林场范围内将拟使用林地用途、范围、面积等内容进行公示，公示期不少于5个工作日。”及有关法律法规规定。现将有关情况通告如下：

一、项目名称：亚龙湾第二通道（一期）工程项目

二、用途：市政道路建设 。

三、项目用地范围：该项目位于三亚市吉阳区，东起亚龙湾博后南路，经大安岭、安游路、榆林湾至榆亚路一线区域。所使用林地面积占《三亚市林地保护利用规划（2010-2020年）》规划内的林地面积22.3072公顷，规划外林地（已核发林权证）面积0.0163公顷，规划外生态公益林面积0.0823公顷。具体详见：亚龙湾第二通道拟用地界址图。

四、通告期限：5个工作日（2017年5月9日至2017年5月15日）。
