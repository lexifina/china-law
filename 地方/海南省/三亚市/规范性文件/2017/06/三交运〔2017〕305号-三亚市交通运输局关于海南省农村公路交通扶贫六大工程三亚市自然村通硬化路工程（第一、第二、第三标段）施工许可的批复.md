# 三亚市交通运输局关于海南省农村公路交通扶贫六大工程三亚市自然村通硬化路工程（第一、第二、第三标段）施工许可的批复

三交运〔2017〕305号

三亚市交通运输局

关于海南省农村公路交通扶贫六大工程三亚市自然村通硬化路工程（第一、第二、第三标段）

施工许可的批复

市交通运输局交通基础设施扶贫攻坚战农村公路建设指挥部：

你单位《关于海南省农村公路交通扶贫六大工程三亚市自然村通硬化路工程（第一、第二、第三标段）施工许可审批的请示》（三交农建〔2017〕004号）收悉。根据《中华人民共和国公路法》第25条规定、交通部《关于进一步加强公路工程施工许可管理工作的通知》（2007年）第2条规定“公路建设项目施工许可由县级以上地方人民政府交通主管部门批准”等依据，经研究，现批复如下：

一、你单位负责实施的海南省农村公路交通扶贫六大工程三亚市自然村通硬化路工程（第一、第二、第三标段）已按规定完成了各项前期审批及施工招投标工作，程序符合交通部和省交通厅有关规定的要求，同意以上项目准予施工。

二、由于该部分项目属于省、市政府督查的为民办实事事项，因此你单位必须精心组织施工建设，严格控制成本、保证工程质量和施工安全，确保海南省农村公路交通扶贫六大工程三亚市自然村通硬化路工程（第一、第二、第三标段）按规范要求，按时按质按量完成建设任务。

三亚市交通运输局

2017年6月1日
