# 三亚市教育局关于印发2017年暑假期间安全教育致家长的一封信的通知

各区教科局、市教育局直属学校（幼儿园）：

暑假将至，为进一步加强暑假期间学生安全教育，现将《2017年暑假期间安全教育致家长的一封信》印发给你们，请各单位高度重视，加强领导，组织人员在暑假前及时将此信印发到每位学生家长手中，共同做好学生的安全工作，同时，做好回执单备存工作，各区学校（幼儿园）由区教科局通知，育才生态区各完小由中心学校负责通知。

在暑假放假期间，各校（园）务必要加强安全管理工作，排查校（园）内及周边安全隐患，建立健全台账，确保万无一失。

联系人：刘玲，联系电话：88657827。

三亚市教育局

2017年6月22日

（此件主动公开）

2017年暑假期间安全教育致家长的一封信

尊敬的学生家长：

光阴荏苒，转眼间，暑假将至。首先，感谢您对学校工作的理解、支持与配合！为了让您的孩子度过一个“安全、文明、健康、充实、愉快”的假期，我们诚挚地希望您配合学校，认真履行监护人的职责，教育和督促孩子做好以下十条暑假期间安全防范和自主学习等教育工作:

一、根据省教育厅通知安排，我市小学从2017年7月1日、中学从2017年7月8日开始放暑假，中小学下学期报名注册时间为2017年8月30-31日，正式上课时间为9月1日。普通高中三年级可提前两周开学。

二、教育孩子遵守交通规则，防止交通事故发生。请教育孩子遵守交通法规，严禁在路上追逐打闹，不乘坐报废车、无牌无照车、超员车、拉客摩托车和农用车等非客运车辆。未满12周岁的学生不准骑自行车上马路，禁止未成年孩子驾驶电动车、摩托车和其他机动车辆，尤其是严禁学生飚车、赛车等危险行为。

三、加强防溺水安全教育，牢固树立孩子安全意识。向孩子说明私自外出游泳的危险性及可能导致的严重后果，对孩子进行游泳遇险时的自救、逃生常识以及施救和报警方式的教育。教育孩子不要在海、河、溪流、水库、池塘、建筑工地的积水洼地等不安全水域游泳，不能私自或擅自结伴外出游泳或到游戏池游泳，如发现其他同学私自外出游泳或到水边游玩，要及时制止，并向家长或老师报告。

四、加强汛期安全教育，防止意外事故发生。向孩子说明台风、雷击、洪水、滑坡等自然灾害的特点及存在的危险，教育孩子不到危险区域玩耍逗留，在雷雨等恶劣天气情况下要尽量留在家中或其他安全场所。

五、加强使用玩具枪等物品的安全教育。不能让孩子购买具有杀伤力的玩具枪、牙签弩等物品，如发现孩子自行购买，要及时制止孩子使用。

六、教育孩子防火、防电、防煤气中毒。不让未成年人独自使用燃气，使用电器、煤气做饭时最好有家长的监护和指导；不要让孩子乱动、乱拆电线、插座和电器设备，遇到火警时及时拨打119报警。

七、提醒孩子远离存在安全隐患的危险区。尽量避免带孩子前往人群拥挤的场所，叮嘱孩子不要私自前往人群聚集处，不要私自进入工程建筑施工现场，不要靠近电线杆、塌方、塔吊或工地围墙，不要强行私自经过滑坡险道、危房和危墙，要绕道而行。

八、教育孩子合理饮食，养成良好的卫生习惯。要注意饮食卫生，不暴饮、暴食，不吃腐烂变质的食物，不买“三无”食品，做到不抽烟、不喝酒。生活有规律，按时起居，多锻炼，预防疾病侵染，提高身体素质。

九、提高孩子自我防护意识，防诈骗、防伤害。与陌生人打交道时，要提高警惕，谨防上当受骗。遇有紧急情况，要见义巧为，善用智慧取胜，避免力敌不过反而危害自身现象的发生。出门前必须和家长打招呼，并按时回家，不得在未告知家长的情况下私自外出、在外住宿和远游。要注意暑假往返学校途中人身和财物安全，不参与非法传销活动，不参与非法宗教活动，不参与赌博和其他违法活动等。

十、教育孩子远离网吧，合理利用网络。要妥善安排每天的时间，不沉迷于网络游戏，注意身心健康；要文明上网，讲求网络道德，不查看、下载和传播色情、淫秽等不良信息，不登录不健康的网站。

十一、培养孩子的责任心、勤俭节约的良好品德。假期里要安排孩子做一些力所能及的家务劳动和公益活动，增强劳动观念，提倡勤俭节约、不乱花钱，学会计划每天的生活；增强礼仪、礼节、礼貌意识，不断提高自身道德修养。

祝您和家人身体健康、万事如意！
