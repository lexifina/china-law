# 三亚市林业局关于海榆东线（国道G223）亚龙湾至吉阳转盘公路改造工程项目办理林地审核的通告

关于海榆东线（国道G223）亚龙湾至吉阳转盘

公路改造工程项目办理林地审核的通告

为做好海榆东线（国道G223）亚龙湾至吉阳转盘公路改造工程项目办理林地审核和林业相关手续工作，根据2015年2月15日国家林业局令第35号下发的《建设项目使用林地审核审批管理办法》第十一条“县级人民政府林业主管部门对建设项目拟使用的林地，应当在林地所在地的村（组）或者林场范围内将拟使用林地用途、范围、面积等内容进行公示，公示期不少于5个工作日。”及有关法律法规规定。现将有关情况通告如下：

一、项目名称：海榆东线（国道G223）亚龙湾至吉阳转盘公路改造工程项目

二、用途：市政道路扩宽建设用地。

三、项目用地范围：该项目位于三亚市吉阳区现状国道G223（亚龙湾路口至吉阳转盘段）区域。所使用林地面积占《三亚市林地保护利用规划（2010-2020年）》规划内的林地面积4.3419公顷。具体详见：海榆东线（国道G223）亚龙湾至吉阳转盘公路改造工程规划红线图。

四、通告期限：5个工作日（2017年6月6日至2017年6月12日）。
