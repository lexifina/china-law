# 三亚市林业局关于南山旅游基础设施项目--一镇、一中心、一道办理林地审核的通告

关于南山旅游基础设施项目--一镇、

一中心、一道办理林地审核的通告

为做好南山旅游基础设施项目--一镇、一中心、一道办理林地审核和林业相关手续工作，根据2015年2月15日国家林业局令第35号下发的《建设项目使用林地审核审批管理办法》第十一条“县级人民政府林业主管部门对建设项目拟使用的林地，应当在林地所在地的村（组）或者林场范围内将拟使用林地用途、范围、面积等内容进行公示，公示期不少于5个工作日。”及有关法律法规规定。现将有关情况通告如下：

一、项目名称：南山旅游基础设施项目--一镇、一中心、一道

二、用途：南山景区基础设施建设用地。

三、项目用地范围：该项目位于三亚市南山风景区内区域。所使用林地面积18.2491公顷，其中占《三亚市林地保护利用规划（2010-2020年）》规划内的林地面积18.2197公顷，规划外生态公益林面积0.0294公顷。具体详见：南山旅游基础设施项目-一镇一中心一道红线图。

四、通告期限：5个工作日（2017年6月8日至2017年6月14日）。
