# 三亚市交通运输局关于临时调整途经月川桥公交线路的通知

三亚市公共交通集团有限公司、三亚海棠湾公共交通有限公司：

由于月川桥两侧桥拱支撑柱维修需要，三亚市公安局交通警察支队将于2017年6月29日23时起至2017年8月30日零时对月川桥实行单向交通管制，禁止车辆由解放路往河东路方向通行（迎宾路月川桥西往东方向）；仅允许车辆由河东路往解放路方向通行（迎宾路月川桥东往西方向）。经研究，决定对途经上述路段的公交线路作如下临时调整：

一、6路公交线路往港务局方向由原行驶友谊路―解放路―迎宾路―河东路调整为：友谊路―解放路―金鸡岭街―河东路；往天涯海角方向行驶路线不变。

二、23路公交线路往南田农场方向由原行驶老铁路―迎宾路调整为：老铁路―外贸路―金鸡岭街―河东路―迎宾路；往凤凰岛方向行驶路线不变。

三、27路公交线路往亚龙湾方向由原行驶三亚湾路―迎宾路调整为：三亚湾路―金鸡岭街―河东路―迎宾路；往凤凰机场方向行驶路线不变。

四、35路公交线路往海棠湾免税广场方向由原行驶河东路―金鸡岭街―解放路―迎宾路调整为：河东路―迎宾路；往火车站方向行驶路线不变。

五、49路公交线路往槟榔河温泉方向由原行驶解放路―迎宾路调整为：解放路―新风街―河东路―迎宾路；往凤凰岛方向行驶路线不变。

六、54路公交线路往火车站方向由原行驶解放路―迎宾路―河东路―金鸡岭街调整为：解放路―金鸡岭街；往鹿回头风景区方向行驶路线不变。

请你公司务必确保上述公交线路按照临时调整确定的路线行驶，停靠相应路段的公交站点，并做好公交车辆腰牌和报站器的更新工作，三亚市公共交通集团有限公司于2017年7月8日前完成公交站牌线路信息的刷新和在公交站牌上公示工作。

特此通知。

三亚市交通运输局

2017年7月6日
