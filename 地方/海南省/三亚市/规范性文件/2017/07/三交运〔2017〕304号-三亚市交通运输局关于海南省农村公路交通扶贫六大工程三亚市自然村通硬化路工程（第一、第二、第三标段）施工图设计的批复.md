# 三亚市交通运输局关于海南省农村公路交通扶贫六大工程三亚市自然村通硬化路工程（第一、第二、第三标段）施工图设计的批复

三交运〔2017〕304号

三亚市交通运输局

关于海南省农村公路交通扶贫六大工程三亚市自然村通硬化路工程（第一、第二、第三标段）

施工图设计的批复

市交通运输局交通基础设施扶贫攻坚战农村公路建设指挥部：

你单位《关于海南省农村公路交通扶贫六大工程三亚市自然村通硬化路工程（第一、第二、第三标段）施工图设计审批的请示》（三交农建〔2017〕003号）收悉。根据市发改委《关于对海南省农村公路交通扶贫六大工程三亚市自然村通硬化路工程项目初步设计及概算的批复》（三发改产〔2017〕128号）确定的建设规模、技术标准、总投资，并结合施工图审查专家组意见，现批复如下：

一、海南省农村公路交通扶贫六大工程三亚市自然村通硬化路工程（第一、第二、第三标段）施工图设计文件基本符合《公路工程技术标准》（JTG B01-2003）和《公路工程基本建设项目设计文件编制办法》规定的要求，原则同意该项目施工图设计文件交付使用。

二、建设标准与规模

该项目共四条公路，道路建设总长10.833km。道路参照四级公路技术等级建设，设计行车速度20km/h，路基宽度分别为4.1m、5.1m，路面宽度分别为3.5m、4.5m。其中：

1.梅东村委会梅东村至岭落水库公路全长2.631km。

2.抱龙村委会扎浩村至扎套村公路全长3.150km。

3.南滨农场赤草管区公路全长3.922km。

4.梅东村委会昌仔园公路全长1.130km。

三、原则同意设计单位编制的施工图预算，并控制在概算范围内。

四、请你单位严格按照批准的施工图设计文件执行，未经批准不得擅自修改。确需修改变更部分，应严格执行《公路工程设计变更管理办法》。较大、重大变更必须按照规定和程序进行报批，未经审批的设计变更不得擅自实施。

五、请施工、监理单位认真做好项目实施的各项准备工作，确保按期开工顺利实施。

特此批复

三亚市交通运输局

2017年6月1日
