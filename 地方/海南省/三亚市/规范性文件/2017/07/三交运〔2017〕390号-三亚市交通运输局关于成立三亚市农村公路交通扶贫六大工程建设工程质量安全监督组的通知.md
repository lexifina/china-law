# 三亚市交通运输局关于成立三亚市农村公路交通扶贫六大工程建设工程质量安全监督组的通知

三交运〔2017〕390号

三亚市交通运输局

关于成立三亚市农村公路交通扶贫六大工程

建设工程质量安全监督组的通知

局机关各科室、事业单位、三亚市农村公路交通六大工程各参建单位：

为切实加强由我局负责实施的我市农村公路交通扶贫六大工程建设工程质量安全监督工作，保证工程质量及安全，提高投资效益，根据《海南省农村公路六大工程领导小组办公室关于农村公路六大工程质量安全精度监督管理有关要求的通知》（琼六大工程办〔2017〕16号）精神，结合我局质量安全管理的相关实际情况，经研究决定成立三亚市农村公路建设工程质量安全监督组。

一、组成人员

组 长：何子晔（高级工程师）

组 员：王会文（中级工程师）

王海丰（中级工程师）

周 容（道路与铁道工程硕士）

潘惠芬（助理工程师）

廖永辉（专职安全员）

三亚市农村公路建设工程质量安全监督小组办公室设在三亚市交通运输局公路科。

二、工作职责

根据《中华人民共和国公路法》、《建设工程质量管理条例》、《建设工程安全生产管理条例》、《公路工程质量监督规定》等有关法律、法规、规章、技术标准和规范执行我市农村公路交通扶贫六大工程建设工程质量安全监督，专门负责我市农村公路交通扶贫六大工程的质量安全监督检查工作，并委托具有相应公路水运工程试验检测资格的检测机构承担工程交（竣）工验收前的质量检测或质量鉴定工作。

三、监督程序

（一）农村公路建设工程质量安全监督受理

监督组在收到建设单位递交的《工程质量安全监督申请》和相关材料后，在15天内完成申请资料审查工作。对审查符合报监条件的农村公路项目签发质量安全监督通知，明确项目监督小组。

（二）过程中间监督检查

监督组根据工程特点和进度安排，以抽查方式对工程质量安全进行监督。整个过程主要检查有关责任主体的质量安全管理行为、施工工艺及现场安全、工程实体质量及原材料检测，包括外业检查和内业资料审查。重点是质量薄弱环节，涉及工程结构安全性、耐久性，主要使用功能的重要指标和关键部位。根据对质量安全状况判定的需要，进行验证性试验检测。

（三）竣（交）工质量监督检查

监督组在农村公路建设项目竣（交）工检测环节对项目单位、分部工程进行工程实体检测、外观检查和内业资料审查，并按标准对项目质量进行鉴定评分，综合评价公路工程项目质量状况，判定工程项目质量等级。评价工程质量是否符合技术标准、规范及设计要求，是否存在安全隐患，为整个项目工程质量鉴定提供基础资料和评定依据。涉及中间交工工程质量检测和合同段工程质量检测两方面内容。

（四）参建单位工作综合评价

监督组根据项目法人或建设单位提交的设计、监理、施工初步评价后，参照项目监督过程的有关文件进行审核，提出审核意见，并形成《参建单位工作综合评价报告》报送交通运输主管部门，同时抄送项目法人或建设单位。
