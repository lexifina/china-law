# 三亚市卫生和计划生育委员会关于2017年上半年妇幼卫生工作督导和考核的通知

各区卫生计生局、委各医疗卫生单位、育才生态区社会事务局：

根据我市2017年妇幼卫生工作计划安排，为全面了解和评估我市上半年各级各类医疗卫生单位妇幼卫生工作执行和落实情况，以更好地推进我市妇幼卫生工作顺利开展，我委定于2017年7月20―8月8日对全市各级各类医疗卫生单位2017年上半年妇幼卫生工作执行情况进行督导和考核。现就有关事项通知如下：

一、督导时间和行程安排

对各单位督导的具体日期由督导组根据工作安排另行通知。

二、督导人员和车辆安排

督导和考核人员从市妇幼保健院抽调，车辆由市妇幼保健院负责安排。

三、督导内容和方法

（一）方法：查看工作台帐、抽查相关个案材料、工作任务完成情况、随机抽查服务对象和查看服务的真实性等。

（二）考核内容：按2017年三亚市妇幼卫生工作考核标准和2017年基本公共卫生服务项目孕产妇和0-6岁儿童健康管理项目工作考核标准进行。

四、要求

（一）各区卫计局、各级各类医疗卫生单位对本次督导和考核工作应给予重视，并认真做好相关准备工作。

（二）基层卫生单位由分管的副院长（副主任）或站长向考核组汇报上半年工作情况，时间限10分钟。

（三）各医疗单位要向考核组提交一份本单位2017年上半年妇幼卫生工作总结。

（四）督导结束后将督导中存在问题向被督导单位反馈，并汇总上报市卫计委；上半年考核成绩的40%纳入年终考核成绩。

三亚市卫生和计划生育委员会

2017年7月20日
