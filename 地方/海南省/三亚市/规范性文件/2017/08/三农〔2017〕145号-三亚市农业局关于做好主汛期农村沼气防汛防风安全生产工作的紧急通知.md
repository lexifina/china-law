# 三亚市农业局关于做好主汛期农村沼气防汛防风安全生产工作的紧急通知

育才生态区管委会，各区农林局：

我市已进入主汛期，根据市防汛防风防旱指挥部办公室、市安全生产委员会办公室相关文件精神，当前台风“桑卡”已逼近我市，将带来强风强降雨，为尽量降低台风灾害给我市农村沼气造成的损失，特发此紧急通知。

各单位务必高度重视，做好主汛期、台风来临前的农村沼气安全检查工作，安排技工认真排查各类型沼气池存在的安全隐患，强化农村户用沼气池安全使用及管理，对辖区内的大中型沼气综合利用项目工程，相关责任单位要加强监管，认真做好防汛防风工作。

各单位要成立沼气应急处理工作组，落实责任，保障安全。如发生沼气突发紧急情况，请妥善处理并及时上报市农业局。
