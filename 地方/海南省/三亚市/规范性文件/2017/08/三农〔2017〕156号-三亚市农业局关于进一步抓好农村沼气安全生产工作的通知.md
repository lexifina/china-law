# 三亚市农业局关于进一步抓好农村沼气安全生产工作的通知

育才生态区管委会，各区农林局：

当前，农村安全工作十分重要，特别是农村沼气安全生产丝毫不能松懈，为进一步抓好农村沼气安全生产，结合在全省开展的农村安全隐患整治工作，现将《海南省农业厅办公室关于做好农村沼气安全生产工作的通知》（琼农办〔2017〕50号）转发给你们。

请各单位高度重视，以抓铁有痕、踏石留印的作风，认真落实沼气安全工作的各项制度，扎实做好日常安全巡查、技术指导、季度检查和宣传培训等工作，发现问题及时整改，把隐患消除在萌芽状态，并做好各项材料的规范管理和存档。请严格按照要求，认真填写好附件表格，并将沼气安全生产管护工作报表加盖单位公章，于每个季度最后一个月的10号前报送我局，以便我局汇总后上报省农业生态与资源保护总站。

我们将不定期对各单位开展的安全生产工作情况进行检查抽查，并结合相关表格报送情况进行通报。
