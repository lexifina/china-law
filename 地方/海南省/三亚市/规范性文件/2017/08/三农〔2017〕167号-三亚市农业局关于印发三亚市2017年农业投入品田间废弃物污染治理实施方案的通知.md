# 三亚市农业局关于印发三亚市2017年农业投入品田间废弃物污染治理实施方案的通知

各区人民政府，育才生态区管委会，局各相关单位：

为做好2017年农业投入品田间废弃物污染治理工作，保护农业生态环境，我局制定了《三亚市2017年农业投入品田间废弃物污染治理实施方案》，经局务会议审议通过，现印发给你们，请认真组织实施。

三亚市农业局

2017年7月15日

（此件主动公开）

三亚市2017年农业投入品田间废弃物污染治理实施方案

为贯彻落实中央1号文件、海南省农产品质量安全条例等文件精神，保护耕地土壤质量，改善农村生态环境质量，建设美丽和谐乡村，发展低碳生态农业，深入推进农业面源污染治理工作，积极发展生态循环农业，结合我市“双修双城”、美丽乡村建设及生态环境保护六大行动等工作，制定本实施方案。

一、指导思想

坚持以科学发展观为指导，以“生态修复、美丽乡村”建设为目标，以“统一回收、集中处置”为模式，按照“市、区、村三级结构”的管理原则，探索建立“政府扶持引导、企业市场运作、农户自觉参与”的回收利用机制，逐步建立农业投入品田间废弃物污染治理的长效机制和网络体系，保障农产品产地安全和农产品质量安全，改善农村农田生态环境。

二、组织机构

为加强对农业投入品田间废弃物污染治理的领导，市政府成立工作领导小组。

组 长：陈文军 市农业局局长

副组长：柯用春 市南繁科学技术研究院院长

曲 环 市农业局副局长

陈 伟 市畜牧兽医局局长

成 员：各区农林局、育才生态区管委会经济发展局负责人，市畜牧兽医局、市农业技术推广服务中心、市热作技术推广服务中心，农业局科教科负责人。

领导小组办公室设在市农业局科教科，由农业局曲环副局长兼任主任，成员由局科教科、市畜牧兽医局、市农业技术推广服务中心、市热作技术推广服务中心等相关科室和下属单位组成，负责统筹处理农业面源污染综合治理日常工作。

三、目标任务

全市各区（生态区）结合当地实际采取多种模式开展农业投入品田间废弃物污染治理，建立健全集中回收处置网络，对全市各田洋、果园、瓜菜种植基地等范围内农业生产产生的，丧失原有利用价值或者虽未丧失利用价值而被抛弃或者遗弃的，对土壤、水体、大气可产生有害影响的农药、化肥、农膜、育苗盘、滴喷管带等农资废弃物（包括瓶、桶、罐、袋、膜、盘、管等）进行集中回收和无害化处理。计划到2020年，基本实现大面积田洋农业投入品废弃物回收利用，回收率达85%以上，回收后的无害化处置率100%。

四、回收模式

（一）建立村级废弃物代收点

建立村级废弃物代收点，区（生态区）农业部门协同各村建立农资废弃物代收点，安排专人负责，做好回收管理工作。代收点负责有偿回收农资废弃物，进行初步分拣、包装和隔离防止废弃物的二次污染功能。回收标准为（暂定）：农药瓶（袋）、管带、棚膜、塑料桶等2元/公斤，农膜、育苗盘、粘虫板、纸箱、肥料袋、金属包装、其他农资塑料瓶（袋）等1.5元/公斤，玻璃瓶包装0.5元/个，具体由各区（管委会）根据实际情况确定。代收点要设立回收台账，详细记录回收日期、数量、类型等信息。回收的废弃物要暂存于专用场所，不得与其它废弃物混合存放。暂存场所应当采取防雨淋、防渗漏等措施。初步分拣后由具有废弃物处理资质公司或回收利用公司将废弃物运走。区（生态区）农业部门应牵头相关部门定期对代收点回收情况进行验收，根据实际验收结果返还代收费用。为充分调动代收点工作积极性，可根据代收点绩效考核评分进行适当奖励，奖励标准为实际产生的代收费用的10-20%。

（二）采取政府购买公共服务的模式

各区（生态区）农业部门根据实际情况，通过招投标的模式，委托有专业资质的企业进行统一回收，统一处置。各区（生态区）农业部门牵头相关单位对其回收进行监管和阶段性验收。各村村级指定负责人负责加强田间农资废弃物回收工作监管和巡查，检验回收工作完成质量。

（三）依托农资店进行强制性有偿回收

各区（生态区）联合有关执法部门协调农资店作为有偿回收点，要求农资店做好销售记录，根据销售记录以补贴的方式强制回收，销多少，回收多少的原则。政府给农资店相应的补贴，做到多收多补。农资店回收点要设立回收台账，详细记录回收日期、数量、类型等信息。回收的废弃物要暂存于专用场所，不得与其它废弃物混合存放。初步分拣后由具有废弃物处理资质公司或回收利用公司将废弃物运走。区（生态区）农业部门应牵头相关部门定期对农资店回收点回收情况进行检查验收，根据实际验收结果返还有偿回收补贴费用。

（四）发动种植基地自觉回收

加大宣传力度，在农业生产集中区域、农业生产组织较规范的标准化果园或瓜菜种植基地按平均5亩1个的标准发放安装废弃物回收桶，按照谁生产谁负责、谁使用谁交回的原则，要求种植大户等农业生产者自觉在田间回收生产过程中产生的农资包装废弃物，待达到一定数量后交至代收点或通知回收机构进行统一清理和集中处置。

五、处置方式

各种集中回收模式要在临时存放点完成废弃物的初步分拣与装车打包，根据回收废弃物量定期或不定期联系专业废弃物处置公司进行集中无害化处理，转运应当采取安全防护和防污染防治措施。环保等部门要确定具有相关资质的处理机构对农资废弃物进行无害化处理，防止污染环境。

六、实施进度

实施时间从2017年8月至2018年8月。

2017年8月-9月：制定实施方案，宣传培训并发动农户参与。

2017年9月-2018年7月：全面组织实施。

2018年8月：检查考核验收。

七、保障措施

（一）加强组织领导，落实工作责任

农业投入品田间废弃物污染治理工作履行属地责任，领导小组统一组织协调各项工作。

1.市农业局研究制定农业投入品田间废弃物污染治理的实施方案，提供技术指导，组织监督验收，开展宣传培训和成效推广。

2.各区农林局，育才生态区经济发展局，成立工作机构，安排专人负责，落实专项资金。广泛宣传发动，引导农户参与，结合当地实际制定本辖区的实施方案并组织实施，接受市农业部门的检查指导。

（二）扩大宣传指导，营造舆论氛围

充分发挥村级农技员、安监员、防疫员等基层农技推广队伍作用，进村入户，深入田间地头发放技术宣传资料，通过手机、电视、广播、新闻、报纸、横幅、宣传车、标识牌等形式营造舆论氛围，加强对农资废弃物田间乱丢乱弃危害性和安全处理重要性的宣传，提高全民对随意丢弃废弃物危害性的认识，有效发动和引导农户自觉开展废弃物回收，使广大群众积极参与到农资废弃物回收工作。同时，把废弃物回收工作与财政支农扶持工作相结合，对主动参与的农户优先给予扶持。

（三）规范日常管理，确保正常运行

各区（生态区）要加强领导，精心组织，相关部门要按照方案要求，切实履行本区（生态区）农资废弃物回收和处置责任，根据本地实际选择合适的模式建立回收网络，安排专人负责废弃物收集点日常管理工作，做好废弃物的收集、分类、存放、转运等全过程管理及存放点环境保护工作。禁止废品回收站或无回收农资废弃物资质的机构回收农投废弃物，防止造成再次污染。同时，废弃物回收工作要与农产品质量安全监管工作紧密结合，把种植生产过程中的农药的使用和监管互联互通。或与田间秸秆收运工作相结合共同实施。

（四）落实资金保障，强化监督考核

市财政统筹安排资金，加强农资废弃物统一回收和集中无害化处置工作所需资金保障。各区（生态区）要履行属地责任，落实专项资金，纳入年度预算。各区（生态区）应出台农资废弃物无害化处置制度、工作职责和回收流程，加强对各村农资废弃物回收和处置工作的指导。建立健全工作督查考核制度，加强对属地部门和回收网络的督查考核，对工作成绩显著的单位和个人给予表彰奖励，对工作不得力、监管不到位的进行批评问责。
