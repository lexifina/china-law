# 三亚市农业局关于三亚市2017年农作物病虫害绿色防控实施方案的通知

各区农林局，育才生态区经济发展局，局各有关下属单位：

实施病虫害绿色防控可有效保障农产品质量安全和农业生态环境安全，针对我市冬季瓜菜和热作水果病虫害发生和防治情况，我局制定《三亚市2017年农作物病虫害绿色防控实施方案》，现印发给你们，请认真组织实施。

三亚市农业局

2017年8月17日

（此件主动公开）

三亚市2017年农作物病虫害绿色防控实施方案

三亚市位于热带地区，农作物病虫害发生种类多、为害重，给农业生产造成严重影响。实施病虫害绿色防控能有效地控制病虫为害，降低化学农药使用，提高农产品质量，是保护农业生态环境、保障农产品质量安全的有效途径。结合我市农业生产实际，特制定本方案。

一、指导思想

树立“科学植保、绿色植保、公共植保”的现代植保理念，坚持“预防为主，综合防治”的植保方针，遵循“政府扶持，市、区、村共建，企业（合作社）组织，农民参与”的原则，采取“以点带面，整片推进”的战略，落实绿色防控综合技术，保障农产品质量安全。

二、目标任务

项目总投入资金150万元，实施面积1.1万亩，主要在全市的冬季瓜菜、热作水果上示范推广绿色防控技术，根据不同作物病虫发生特点采取不同的技术措施。一是冬季瓜菜、热作水果示范区1000亩，由市农技中心负责建立。示范区以灭虫灯诱杀、粘虫板诱杀和生物防控技术等为主，应用区以粘虫板诱杀技术为主。二是冬季瓜菜推广应用区10000亩，由各区组织实施。推广应用区以粘虫板诱杀技术为主。

通过优化集成推广应用绿色防控技术，力争实现实施区域内病虫害的防效达85%以上，农残检测合格率98%以上，化学农药使用量减少20%以上。

三、组织机构

为了加强对各项工作开展实施的组织领导，成立农作物病虫害绿色防控工作领导小组。

四、实施模式

采取“市、区、村”三级共建，以企业和合作社为主要载体，结合农业标准化示范园区建设，形成“政府扶持、企业组织、农民实施”的三方互动模式。

五、实施内容

（一）广泛开展宣传

利用各类宣传媒体，通过现场展示等形式，开展以“实施绿色防控、保障农产品质量安全”为主题的宣传，营造良好的氛围，提升社会大众对绿色防控的认知。

（二）加强技术培训

通过举办培训班、召开现场会、田头技术指导等形式，结合农业科技网络书屋、基层农技推广服务云平台、农业人才工作站等项目建设，传授绿色防控知识，培养一批技术骨干。

（三）发布病虫信息

依托市区域病虫监测站和各区基层监测点，以文件、短信、信息栏等形式，及时发布病虫预测预报信息，指导农户开展有效防治。

（四）实施统防统治

采用委托或招标方式，依托现有的企业和合作社的防治队伍，开展病虫害专业化统防统治。市农业部门对示范区病虫害统防统治工作，予以适当的补贴。

（五）主推实用技术

主推杀虫灯诱杀技术、信息素诱杀技术、粘虫板诱杀技术、生物防控技术、果园生草技术、农业防控技术等。

六、资金安排

全市计划投入资金150万元，从市农业局年度预算生物农药示范和物理防治推广经费中列支，主要用于绿色防控物资采购、工作宣传等，其中各区（生态区）根据工作任务安排经费共7万元（详见表1和表2）。

七、实施进度

实施时间从2017年6月至2018年5月。

2017年6-7月：各区（生态区）根据市总体方案制定各区（生态区）具体实施方案和技术方案，开会部署，宣传培训并发动农户参与。

2017年8-10月：指导各区农业部门采购绿色防控物资采购工作。

2017年11月-2018年4月：全面实施、落实各项技术方案。

2018年5月：效果调查评估，组织项目验收评价。

八、保障措施

（一）加强组织领导

各区政府（生态区）和职能部门要高度重视，落实属地责任，层层抓落实，主要负责人要亲自抓，具体负责人要直接抓，各区（生态区）、居（村）委会负责组织农民参与实施。

（二）落实工作责任

农作物病虫害绿色防控工作领导小组统一组织协调各项工作。

市农业部门研究制定农作物病虫害绿色防控的实施方案和技术方案，指导监督绿色防控工作，协助资金落实，提供技术支持，开展宣传培训和成效推广，组织开展项目验收评价。

市财政部门负责专项资金的安排下达与监督管理，建立健全专项资金的管理机制，协助开展项目验收。

区政府（生态区）负责组织实施本区域内冬季瓜菜绿色防控的推广应用，落实配套资金，制定实施方案，明确实施田洋，落实到户，开展防控物资采购和发放，并协助市农业局进行项目验收。

企业、合作社、居（村）委会全力发动并组织农户参与，通过居（村）委会干部、农民技术员和质量安监员等指导和监督农户具体实施。

（三）实现技术支撑

各区（生态区）农业部门技术人员负责本辖区示范区和应用区的技术方案组织实施，市农技中心组成专家组分片监督落实和技术指导。

（四）保障资金投入

积极争取省级农业部门的资金和物资扶持，市、区（生态区）要逐渐加大资金投入力度，通过示范带动，鼓励和引导社会资本进入绿色防控领域，完善投入机制，提升发展能力。

（五）做好试验示范

实施“五个一”行动，即核心示范区设立统一的示范展示牌，明确不少于一名技术指导，实施一套技术方案，推介一批绿色防控产品，落实一批扶持政策，确保示范成功，推动绿色防控工作的全面开展。

（六）加强信息报送

冬季瓜菜生产季节，各区（生态区）农业部门根据本区域内农业生产和项目实施进度向市领导小组办公室报送项目信息，项目结束后及时上报工作总结。领导小组办公室负责情况登记、分析、汇总。
