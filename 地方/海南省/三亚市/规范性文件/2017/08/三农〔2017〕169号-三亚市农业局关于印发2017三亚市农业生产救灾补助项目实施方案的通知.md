# 三亚市农业局关于印发2017三亚市农业生产救灾补助项目实施方案的通知

各区农林局，育才生态区经济发展局：

为有效预防控制水稻暴发性、迁飞性、流行性病虫害，降低水稻病害、减少农业有害生物灾害，促进农民增收，根据海南省农业厅、海南省财政厅关于印发2017年海南省农业生产救灾补助实施方案的通知》（琼农字〔2017〕86号）精神，结合我市实际，特制定《2017三亚市农业生产救灾补助项目实施方案》，现印发经你们，请认真贯彻执行。

三亚市农业局

2017年8月17日

（此件主动公开）

2017三亚市农业生产救灾补助项目

实施方案

为有效预防控制水稻暴发性、迁飞性、流行性病虫害，降低水稻病害、减少农业有害生物灾害，促进农民增收，《根据海南省农业厅、海南省财政厅关于印发2017年海南省农业生产救灾补助实施方案的通知》（琼农字〔2017〕86号）精神，结合我市晚造水稻生产实际情况，特制定本实施方案。

一、指导思想和目标

贯彻落实“预防为主，综合防治”的植保方针和“科学植保、公共植保、绿色植保”的理念，通过创新机制、规范管理和提高组织化程度，重点开展水稻稻飞虱、稻纵卷叶螟、三化螟、稻瘟病、南方水稻黑条矮缩病毒病、细菌性条斑病、纹枯病等水稻病虫害防控（具体根据当地发生情况而定），大力推进专业化统防统治和综合防治，实行整片、整村推进，带动区域性联防联控和群防群控，有效预防控制病虫害蔓延，保障农业安全生产。

通过项目实施，有效控制水稻病虫害发生蔓延，使为害损失控制在5%以内。

二、资金来源和防治计划面积

项目资金总额30万，来源：2017年海南省农业生产救灾补助资金，防治水稻面积1.5万亩次。

根据当前各区（生态区）上报水稻种植面积及实地调查，结合常年病虫害发生特点，防治田洋计划安排在天涯区、吉阳区和育才生态区管委会等地（详见表1），具体防治可根据全市水稻病虫害的实际发生情况进行面积调整。

三、资金使用范围

根据《财政部 农业部关于印发〈中央财政农业生产防灾减灾资金管理办法〉的通知》（财农〔2013〕3号）规定，补助资金主要用于水稻主要病虫害防治所需物资材料补助，包括购买药剂、药械、燃油及生物防治、综合防治、生态控制技术应用费、技术指导费、作业费等。选择施药防治的原则上不高于20元/亩次（一次用药兼防多种有害生物时，凡针对不同对象自行加入相应防治农药混配防治的，要分别统计防治面积，如采用甲维盐、春雷霉素混配农药防治稻纵卷叶螟和细菌性条斑病，要分别统计防治面积，同时防治一亩的实际统计面积为2亩次。）

四、资金补助对象

补助对象为实施病虫害防治作业的统防统治服务组织和农民。统防统治服务组织队伍包括农民专业合作社、专业协会、专业服务公司、基层农技服务组织、植物流动医院等。

五、补助方式和实施规程

（一）补助方式：采取施药防治补助

1．由三亚市农业技术推广服务中心与统防统治服务组织签订水稻病虫害飞防协议。

2.协议签订后，再由统防统治服务组织与实施防治田洋所属村委会签订工作协议，确定防治面积。防治结束后，由三亚市农业技术推广服务中心、村委会和飞防公司三方共同验收确认面积。同时由市农技中心邀请第三方随机抽查验收防治效果，收集相关防治确认材料，经面积和防治效果通过验收的，市农技中心根据防治面积拨付相应防治费用。

（二）实施流程

调查水稻生产情况，制定项目实施方案 三家以上（含三家）统防统治服务组织询价 上会讨论，择优选定统防统治服务组织，并公示确认 市农技中心和统防统治服务组织签订防治合同 确定防治点面积，进行公示，统防统治服务组织与实施防治作业点所属村委会签订协议 防治面积和防治效果验收，出具验收报告 农技中心根据项目实施进度拨付进度款。

六、项目进度安排

（一）2017年7月中下旬－8月上旬：调查了解全市晚稻生产情况，根据海南省农业厅、财政厅《关于印发2017年海南省农业生产救灾补助项目实施方案的通知》（琼农字〔2017〕86号）精神，制订《2017年三亚市农业生产救灾补助项目实施方案》。

（二）2017年8月中上旬：遴选确定统防统治服务组织，根据水稻生产和常年田间病虫害发生特点，确定防治田洋、防治面积与防治时间，统防统治服务组织根据病虫害发生情况科学配药，确保防治效果。

（三）2017年8月中下旬―12月下旬：根据田洋病虫害发生情况和最佳防治时期，分别开展统防统治，并对防治面积进行确认和组织第三方专家对防治效果评价。项目完成后，根据项目实施具体情况进行总结，材料整理归档。

七、保障措施

（一）加强组织领导，明确工作责任

成立2017年三亚市农业生产（水稻）救灾补助项目工作领导小组，组长由市农业局局长、市扶贫开发办主任陈文军兼任；副组长由市农业局党组成员、市农技中心主任邢精华兼任；成员由各区农林局局长、育才生态区管委会经济发展局局长以及市农技中心植保植检站和病虫害测报站人员组成。领导小组下设办公室于市农技中心（88268474），负责具体落实工作。各区（生态区）农业部门要落实属地责任，安排专人负责，及时上报水稻种植和病虫害发生情况，协助做好防治面积核实、宣传培训等工作。

（二）大力推进统治和绿色防控

在推进统防统治的同时，大力推广生物防治、物理防治等病虫害绿色防控技术，促进病虫害专业化统防统治和绿色防控的有机融合。

（三）加强资金管理

市财政、农业部门要密切配合，加强项目资金的监管，严防挤占、挪用补助资金，坚决杜绝违法违纪行为。

（四）做好项目总结及材料收集

资金下达后，领导小组办公室每月25日前将项目实施进度、资金开支上报省植物保护总站。项目开展过程中，要做好材料收集归档工作，妥善管理项目资金下达文件、实施方案、购买服务合同、开支发票复印件、工作相处、防治面积等证明材料。项目实施完成后，认真总结，并将项目总结报告报送省农业厅种植业管理处和海南省植物保护总站。
