# 三亚市农业局关于印发三亚市安全生产大检查实施方案的通知

局机关各科室、下属各单位：

为进一步加强我局安全生产行业监管工作，根据《三亚市人民政府办公室关于印发〈三亚市安全生产大检查实施方案〉的通知》（三府办〔2017〕237号）要求，结合实际，制定了《三亚市农业局安全生产大检查实施方案》，现印发给你们，请认真贯彻落实。

三亚市农业局

2017年8月6日

（此件主动公开）

三亚市农业局安全生产大检查实施方案

为进一步加强我市安全生产行业监管工作，严格落实各项安全防范责任和措施，有效防范和坚决遏制重特大事故，为党的十九大胜利召开营造稳定的安全生产环境，根据《三亚市人民政府办公室关于印发〈三亚市安全生产大检查实施方案〉的通知》（三府办〔2017〕237号），结合我局实际，特制定本实施方案。

一、指导思想

认真贯彻落实中央及省、市关于安全生产的一系列重要会议和文件精神，按照国家及省、市关于开展安全生产的一系列工作部署，本着谁主管，谁负责的原则，明确安全生产责任目标，进一步强化安全生产责任，以坚决遏制重特大事故为重点，坚持全面检查与严格执法相结合、企业自查与政府督查相结合、属地负责与部门督导相结合，集中开展安全大检查，已发严惩一批违法违规和不符合安全生产条件的企业，联合惩戒一批严重失信企业，问责曝光一批责任不落实、措施不力的单位和个人，严格落实各项安全防范责任和措施，坚决遏制重特大事故，确保不发生造成较大社会影响的事故，以安全生产的新成效迎接党的十九大胜利召开。

二、组织领导

按照市安委会的工作要求，成立三亚市农业局安全生产大检查领导小组，负责领导、部署、组织全市农业安全生产大检查工作，及时研究解决大检查工作中存在的突出问题。

组 长：冯永杰 市农业局副局长

副组长：董朝周 市农业局副局长

曲 环 市农业局副局长

陈 伟 市畜牧兽医局局长

潘在明 市农业综合执法支队支队长

邢精华 市农业技术推广服务中心主任

成 员：孙虎厚副调研员、范德新副调研员、华世科副调研员，局机关各科室、下属各单位主要负责人。

领导小组下设办公室，负责综合协调、材料上报及相关督办工作，办公室主任由董朝周副局长兼任，副主任由陈太杰同志担任，成员由各科室负责人和各下属单位安全生产负责人组成。

三、检查范围和重点内容

（一）农产品质量安全管理

1.负责冬季瓜菜、常年蔬菜、热作水果生产监管和抽样检测（责任领导：冯永杰，责任部门：农产品质量安全监管科、市现代农业检验检测预警防控中心）

2. 负责重大动物疫病防控，监管畜禽屠宰工作。（责任领导：陈伟，责任部门：市畜牧兽医局、市动物卫生监督所、市动物疾病预防控制中心）

（二）农产品加工安全管理

负责瓜果菜预冷等相关农产品加工企业的安全管理，指导、督促有关企业落实安全生产主体责任。（责任领导：曲环，责任部门：农业企业发展科）

（三）农资安全管理

1.负责农药销售、使用等环节的安全管理和事故防范工作。（责任领导：潘在明，责任部门：市农业综合执法支队）

2.负责兽药饲料销售、使用等环节的安全管理和事故防范工作。（责任领导：陈伟，责任部门：市畜牧兽医局）

（四）沼气安全管理

负责指导、协调、监督农村沼气等农村可再生资源综合开发与利用项目的建设、使用等相关环节的安全管理。（责任领导：曲环，责任部门：农业科技教育科）

（五）农业生产设施、设备安全管理

1.负责农业机械安全使用培训；负责拖拉机、收割机等农业机械的安全监管、隐患排查治理及违法违规行为的查处；根据相关规定，参与道路上设计农业机械交通事故的调查处理。（责任领导：潘在明、周坤、何世剑，责任部门：市农业综合执法支队、市农业机械化管理局、市农业机械技术培训学校）

2.负责设施大棚安全生产指导、监督工作。（责任领导：冯永杰，责任部门：种植业与市场信息科）

3.负责动物实验室安全生产，宠物医院（店）经营安全管理工作（责任领导：陈伟、卢永清，责任部门：市畜牧兽医局、市动物卫生监督所）

（六）种子质量监督检测和植物检疫

负责对全市水稻、瓜菜种子经营市场进行质量监督检查，做好植物检疫和外来生物入侵监控工作。（责任领导：邢精华，责任部门：市农业技术推广服务中心）

四、工作安排

从2017年7月至10月，集中4个月时间开展安全生产大检查。各分管领导、各责任科室和下属单位按各自职责开展安全生产大检查工作，对分管行业的安全生产进行监督、指导和检查。

（一）全面部署，广泛动员，自查自改。（7月）

各分管领导、各责任科室和下属单位要按照大检查部署要求，组织力量对照政府层面检查内容深入开展自查自改。

（二）深入检查、严格执法，集中整治（8月至9月）

1.各责任科室和下属单位要结合实际制定检查表，详细列明检查事项、具体内容和检查标准，在企业自查自改的基础上，组织检查组深入企业开展对表检查，对高危行业领域企业要做好检查全覆盖。

2.对检查发展的每一项违法违规行为，要依法严格落实查封、扣押、停电、停供民用爆炸物品、吊销证照和停产整顿、关闭取缔、上限处罚、追究法律责任“四个一律”执法措施。对涉及多部门或跨地区的重大问题，加强联合执法。

3.对大检查发展的每一项事故隐患，要严格落实整改责任，制定整改措施，立即整改。对重大事故隐患实行挂牌督办，确保整改到位。

4.各责任科室和下属单位将开展大检查情况和执法处罚、集中整治和需要录入安全生产“红黑”名录系统的企业或个人名单等阶段性情况于8月23日前报送市农业局办公室，市农业局办公室于8月25日前汇总报送市安委办。

（三）实地督查，统筹推动，巩固提高（9月至10月）

1.各责任科室和下属单位要将采取突击检查、明察暗访、随机抽查、回头检查、交叉检查等多种方式，深入开展督查检查。突出对安全生产任务重、事故多发的地区、重点行业领域和高风险企业进行重点检查，对停产整顿、关闭取缔企业进行跟踪复查。

2.各责任科室和下属单位要及时分析大检查工作中存在的突出问题，制定并落实整改措施，于9月29日前报送市农业局办公室，市农业局办公室于10月8日前汇总报送市安委办；于10月23日前将大检查总结报市农业局办公室，市农业局办公室于10月25日前报送市安委办。

四、工作要求

（一）加强领导,落实责任。局各科室（办）及下属各单位要落实到责任人,并严按要求抓好责任落实。重点要做好责任分解,使各项工作落实到岗、落实到人,防止走过场和形式主义。

（二）精心组织，制定方案。局各科室（办）及下属各单位要结合自身工作实际，制定具体的安全生产工作方案，方案要明确具体的内容和工作要求。

（三）立足当前,着眼长远。以安全生产大检查为契机,既要加强农业安全生产的宣传，树立安全意识,又要建立农业安全生产的长效机制,促进农业安全生产工作的落实。

（四）认真总结,定期上报。局各科室（办）及下属各单位要对安全生产工作认真总结,掌握工作中存在的不足和问题,结合安全生产暗查抽查工作，及时上报。
