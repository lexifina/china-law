# 三亚市教育局关于公布2017年三亚市普惠性民办幼儿园审定结果的通知

关于公布2017年三亚市普惠性民办幼儿园

审定结果的通知

各区教科局，市教育局直属幼儿园：

根据《海南省普惠民办幼儿园认定及管理办法》《三亚市教育局关于印发<三亚市普惠性民办幼儿园认定及管理暂行办法>的通知》（三教〔2016〕88号）、《三亚市教育局关于开展三亚市普惠性民办幼儿园申报及评估工作的通知》（三教〔2017〕8号）等文件精神，为做好2017年学前教育奖补省级资金分配工作，省教育厅要求尚未开展普惠性幼儿园认定的市县要抓紧开展评审认定，经由各区教科局开展评审认定工作，已于2017年7月30日将普惠性民办幼儿园评定结果报送三亚市教育局基教科，现将已认定的39家普惠性民办幼儿园予以公布（见附件）。
