# 三亚市教育局转发海南省教育厅关于进一步做好2017年普通高中学校招生和新生学籍认定管理工作的通知

三亚市教育局转发海南省教育厅关于

进一步做好2017年普通高中学校招生和

新生学籍认定管理工作的通知

各区教科局，市教育局直属学校：

现将《海南省教育厅关于进一步做好2017年普通高中学校招生和新生学籍认定管理工作的通知》（琼教〔2017〕37号）转发给你们，请你们按通知要求认真落实好高中阶段学校招生工作和学籍管理工作。对于往届遗留的学籍认定问题，省教育厅将进行一次性全面清理，清理截止时间为2017年11月30日。各单位务必于10月30日前将有关问题以正式申请方式报市教育局基础教育科，逾期不再受理，今后也不再受理学籍认定遗留问题。

附件：海南省教育厅关于进一步做好2017年普通高中

学校招生和新生学籍认定管理工作的通知
