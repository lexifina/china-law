# 三亚市林业局关于三亚市北部山区饮水安工程-配水管网工程项目办理临时使用林地审核的通告

关于三亚市北部山区饮水安全工程-配水管网工程项目办理临时使用林地审核的通告

为做好三亚市北部山区饮水安全工程-配水管网工程办理临时使用林地审核和林业相关手续工作，根据2015年2月15日国家林业局令第35号下发的《建设项目使用林地审核审批管理办法》第十一条“县级人民政府林业主管部门对建设项目拟使用的林地，应当在林地所在地的村（组）或者林场范围内将拟使用林地用途、范围、面积等内容进行公示，公示期不少于5个工作日。”及有关法律法规规定。现将有关情况公告如下：

一、项目名称：三亚市北部山区饮水安全工程-配水管网

工程

二、用途：配水管网工程。

三、项目用地范围：该项目用地位于三亚市育才生态区、天涯区北部区域。项目用地土地总面积23.7846公顷，其中临时使用林地面积19.0649公顷，规划林地面积18.4779公顷、规划外公益林地面积5.1817公顷，规划外已核发林权证林地面积为0.4310公顷、规划外经批准退耕还林地0.1310公顷。按林地权属分：立才农场国有2.9418公顷、立才农场南岛片区国有8.2162公顷，育才生态区龙密村委会集体0.2055公顷、育才生态区马脚村委会集体0.3367公顷、育才生态区马亮村委会集体0.2615公顷、育才生态区明善村委会集体1.1872公顷、育才生态区那受村委会集体0.1833公顷、育才生态区青法村委会集体0.9390公顷、育才生态区雅亮村委会集体0.1538公顷、育才生态区雅林村委会集体0.3323公顷、天涯区抱龙村委会集体2.0847公顷、天涯区抱前村委会集体0.3719公顷、天涯区立新村委会集体0.7560公顷、天涯区扎南村委会集体1.0950公顷。详见：北部山区饮水安全工程-净水厂及配水管网部分总平面图。

四、公告期限：5个工作日（2017年6月19日至2017年6月23日）。
