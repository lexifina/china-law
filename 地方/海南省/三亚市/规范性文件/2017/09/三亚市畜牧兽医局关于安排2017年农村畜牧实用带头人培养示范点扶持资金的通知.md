# 三亚市畜牧兽医局关于安排2017年农村畜牧实用带头人培养示范点扶持资金的通知

董恩章、吉立斌、麦胜明、麦科、孙令伟、董新凯、张永才、苏江宏等同志：

根据《三亚市畜牧兽医局2017年农村畜牧使用人才培养项目方案》（以下简称“项目方案”）和《三亚市畜牧兽医局关于开展2017年农村畜牧实用带头人申报工作的通知》（三牧医〔2017〕53号）工作安排，经申报、审核、实地现场考察、综合评审、会议讨论和公示等环节，确定你等8人为我市2017年农村畜牧实用带头人培养对象。为切实提高你等经营或从业养殖基地建设水平，形成更好示范带动效果，根据项目方案要求，现将2017年农村畜牧实用带头人培养示范点扶持资金16万元安排给你们（详见附件）。其中，培养对象为养殖场、农民专业合作社负责人或技术负责人的，扶持资金拨付至培养对象所在养殖场或农民专业合作社银行账户；培养对象为养殖大户或家庭农场主且未在工商部门注册备案的，扶持资金可拨付至培养对象个人账户。

示范点扶持资金专项用于你等经营或从业养殖基地建设，具体使用用途可根据你基地情况自行确定，但必须确保扶持资金切实使用在养殖基地示范建设上，不可挪作他用，同时，务必做好资金使用记录，以备有关部门监督检查。
