# 三亚市农业局关于印发三亚市2017年农业面源污染综合治理实施方案的通知

各区人民政府，育才生态区管委会，局各相关单位：

为做好2017年农业面源污染综合治理工作，保护农业生态环境，我局制定了《三亚市2017年农业面源污染综合治理实施方案》，现印发给你们，请认真组织实施。

三亚市农业局

2017年7月15日

（此件主动公开）

三亚市2017年农业面源污染综合治理

实施方案

加强农业面源污染治理，是转变农业发展方式、推进现代农业建设、实现农业可持续发展的重要任务。为贯彻落实农业部关于打好农业面源污染防治攻坚战的实施意见、海南生态循环农业示范省的创建要求，三亚市开展环境保护突出问题整治、大气污染和水污染治理等工作部署，现结合我市农业实际，制定本方案。

一、指导思想

以习近平总书记考察海南时的重要讲话精神为指导，树立绿色、低碳、循环的现代农业发展理念，以促进农业资源持续利用和生态环境持续改善为目标，以“双查双减三利用”为工作重点，通过生态环境保护、农业减量投入、资源循环利用等技术手段，指导全市着力推进农业面源污染综合治理，加快推动农业生产方式转变，不断提升我市农业可持续发展能力。

二、组织机构

为加强对农业面源污染综合治理工作的领导，成立领导小组。

组 长：冯永杰 市农业局副局长

副组长：曲 环 市农业局副局长

柯用春 市南繁科学技术研究院院长

陈 伟 市畜牧兽医局局长

邢精华 市农业技术推广服务中心副主任

成 员：各区政府、育才生态区管委会的分管农业负责人，市畜牧兽医局、市农业技术推广服务中心、市热作技术推广服务中心，农业局科教科负责人。

领导小组办公室设在市农业局农业科技教育科，由农业局曲环副局长兼任主任，成员由市农业局农业科技教育科、市畜牧兽医局、市农业技术推广服务中心、市热作技术推广服务中心等相关科室和下属单位组成，负责统筹处理农业面源污染综合治理日常工作。

三、责任划分

农业面源污染综合治理工作领导小组统一组织协调各项工作。

（一）市农业局研究指导各区（生态区）制定农业面源污染综合治理的实施方案和技术方案，成立专家组，指导监督农业面源污染综合治理工作，争取资金落实，提供技术支持。

（二）区政府（管委会）履行属地责任，保障配套资金，组织实施农业面源污染综合治理各项具体工作，并协助市农业局开展审核验收。居委会应配合区政府（管委会）做好管辖范围内各项农业面源污染综合治理工作。

（三）市畜牧兽医局协助市农业局开展各项工作，重点做好畜禽养殖的污染综合治理的技术指导和项目实施。

（四）市农业技术推广服务中心协助市农业局开展各项工作，重点做好水稻等粮食作物、瓜菜等经济作物的农业面源污染综合治理的技术指导和项目实施。

（五）市热作技术推广服务中心协助市农业局开展各项工作，重点做好热带作物和热带水果等经济作物的农业面源污染综合治理的技术指导和项目实施。

四、目标任务

通过开展“一防双查双减三利用”八项重点工作，基本做到全市规模畜禽养殖合理规划和标准化健康养殖，全面掌握全市农业面源污染情况，力争当年综合治理实现以下目标：推广测土配方施肥技术19万亩，化肥减量保持零增长；绿色统防技术和统防统治应用面积4万亩，化学农药使用量零增长；力争秸秆综合利用率达到80%；争取每个区建立1个农业投入品废弃物回收示范点，辐射全市各主要田洋；提高沼渣沼液的循环利用率。

五、重点工作

重点进行全市养殖业污染防治，深入开展农业面源污染调查和耕地土壤环境调查监测，积极推进测土配方施肥和病虫害绿色统防的减肥减药行动，有效实施秸秆综合利用、农业投入品废弃物回收利用、沼渣沼液循环利用等工作。

（一）养殖业污染防治

全力抓好畜禽养殖区划分，合理划定禁养区、限养区、适养区，全力抓好标准化规模清洁、健康养殖，按照标准化规模养殖小区“五化”标准和健康养殖要求，建设畜禽标准化养殖小区。全力抓好畜禽养殖废弃物无害化处理和资源化利用，推进畜禽规模养殖污染防治、屠宰畜禽粪污治理和绿色生态畜牧业发展。通过建设粪污排放与无害化处理、有机肥生产处理配套设施，积极推行种养结合、生态循环、绿色发展的“畜禽-沼气（渣、液）-果菜”等农业生产模式。（责任单位：市畜牧兽医局，各区（生态区）农业部门）

（二）农业面源污染调查

根据全省农业面源污染调查工作部署，开展全面清查和典型调查，调查内容涵盖种植业与养殖业，其中种植业包括耕地面积、园地面积、主要种植模式名称及种植面积、肥料农药使用情况、地膜使用与回收利用情况等；养殖业主要包括规模养殖单元位置、养殖规模、畜禽种类、养殖数量、清粪方式、粪污处理状况等，以表格填报的形式统计实地调查的结果，根据调查结果建立数据库。（责任单位：市农业技术推广服务中心，市畜牧兽医局，市热作技术推广服务中心，各区（管委会）农业部门）

（三）耕地土壤环境调查监测

继续开展农产品产地土壤重金属污染调查监测，切实摸清我市农产品产地重金属污染底数。根据调查结果，依据农业部农产品产地分级评价方法及技术规范，开展农产品产地分级划定。在分级区划的基础上，开展相应的耕地重金属污染治理修复。（责任单位：市农业技术推广服务中心，各区（生态区）农业部门）。

（四）化肥减量

深入推进测土配方施肥在蔬菜、果树等园艺作物上的应用，依托农业部测土配方施肥项目和省市级耕地地力保育项目，基本实现项目区主要农作物测土配方施肥技术全覆盖，减少化肥用量。积极探索有机养分资源利用有效模式，鼓励增施有机肥，引导农民施用农家肥，着力推广使用商品有机肥，通过施用有机肥，提高土壤有机质含量，促进微生物繁殖，改善土壤理化性状，减少化肥施用量。（责任单位：市农业技术推广服务中心，市热作技术推广服务中心，各区（生态区）农业部门）

（五）农药减量

继续加强病虫监测预警，不断完善全市基层病虫监测体系，按时开展病虫监测和及时上报数据，提高病虫测报的准确率，指导农民安全科学用药。加快绿色防控推进步伐，在全市建立主要作物病虫害绿色防控示范区，重点推广灯诱、性诱、色诱、食诱“四诱”措施，优先选用生物农药或高效低毒低残留农药，偿试开展天敌生物防治。全面推进农作物病虫害统防统治，重点是推广无人植保机飞防，以此推进专业化统防统治与绿色防控融合，把统防统治的组织方式与绿色防控的技术措施集成融合为综合配套的技术服务模式，进行大面积示范推广，减少化学农药用量。（责任单位：市农业技术推广服务中心，市热作技术推广服务中心，各区（生态区）农业部门）

（六）秸秆综合利用

主要推进秸秆肥料化综合利用，不断提升秸秆综合利用水平，通过实施有机质提升、耕地质量保护等项目，重点抓好秸秆机械化还田、腐熟还田、商品化有机肥还田和过腹还田等肥料化综合利用方式，既提高土壤的有机质含量，又能杜绝秸秆焚烧引发的破坏大气环境质量问题。（责任单位：市农业技术推广服务中心，各区（生态区）农业部门）

（七）农业投入品废弃物回收利用

借鉴天涯区槟榔村成功模式，在全市推广健全集中回收处置网络，探索建立“政府扶持引导、企业市场运作、农户自觉参与”的回收利用机制，对重大田洋和果园等范围内农业生产产生的，丧失原有利用价值或者虽未丧失利用价值而被抛弃或者遗弃的，对土壤、水体、大气可产生有害影响的农药包装、化肥包装、农膜、育苗盘、滴喷管带等农业投入品田间废弃物（包括瓶、桶、罐、袋、膜、盘、管等）进行集中回收和无害化处理。（责任单位：各区（生态区）农业部门，市农业技术推广服务中心）

（八）沼渣沼液循环利用

重点推广普及“养殖-沼气-种植”三位一体的种养结合循环农业模式，循环利用畜禽养殖产生的沼渣沼液作为沼肥，可以作为优良的有机肥施用。建立完善沼肥综合利用体制机制，借助沼气技术员这支基层队伍和所配备的抽渣运渣设备，充分利用沼气工程产生的沼肥肥田育田，重点应用于热作水果和蔬菜等经济作物上。（责任单位：市农业局农业科技教育科，各区（生态区）农业部门）

六、保障措施

（一）加强组织领导。市农业局已经成立农业面源污染治理工作领导小组和专家组，各区（生态区）农业部门要争取当地党委、政府的重视和有关部门的支持，建立完善的领导工作机制，形成主要领导亲自抓、分管领导具体抓、各相关部门分工协作、齐抓共管的工作格局。

（二）上下联动推进。结合实施项目的考核评价，建立上下联动、多方协作的工作机制，强化责任、整合力量、加强督查。充分发挥专业合作社、种植（养殖）大户、家庭农场、龙头企业的作用，鼓励开展技术推广、政策宣传、技术培训、服务指导等工作。

（三）加大投入力度。加强与有关部门的沟通合作，整合资源，形成合力，建立以政府为主导、社会共同参与的投入机制。充分整合利用耕地地力保育、农作物病虫害绿色防控、基层农技推广补助、畜禽无害化处理等项目资金，积极引导地方政府和社会各界加大对农业面源污染综合治理工作投入力度。

（四）加强宣传培训。充分利用报纸、广播、电视、新媒体等途径，加强农业面源污染综合治理的科学普及、舆论宣传和技术推广，让社会公众和农民群众认清农业面源污染的来源、本质和危害。大力宣传农业面源污染综合治理工作的重大意义，推广普及化害为利、变废为宝的清洁生产技术和污染防治措施,引导广大农户理解、支持、参与到农业面源污染治理工作。

（五）加强信息报送。实行月报制度，信息报告和专项工作落实情况将作为农业面源污染综合治理考评的重要参考依据使用。各区（生态区）农业部门要把每月工作开展情况于月底30日书面报市领导小组办公室,88275936。领导小组办公室负责情况登记、分析、汇总，并及时报送市有关部门和领导。
