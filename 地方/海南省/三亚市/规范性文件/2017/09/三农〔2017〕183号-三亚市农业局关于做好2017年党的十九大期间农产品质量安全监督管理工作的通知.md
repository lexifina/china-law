# 三亚市农业局关于做好2017年党的十九大期间农产品质量安全监督管理工作的通知

育才生态区管委会，各区农林局：

为确保我市农产品质量安全，保证市民、游客的身体健康和饮食安全，及时消除农产品质量安全隐患，以安全和谐的良好环境迎接党的十九大胜利召开，现就党的十九大期间农产品质量安全监管工作有关事项通知如下：

一、切实加强对党的十九大期间农产品质量安全工作的领导

各单位要充分认识党的十九大期间农产品质量安全工作的重要性和特殊性，要切实加强组织领导，按照市政府与各区签订的责任书和《三亚市冬季瓜菜网格化管理方案》的要求，严格落实网络监管责任和责任追究制，制定详细的监管工作计划和值班表，明确责任与任务，有针对性地开展各项工作，确保党的十九大期间农产品质量安全。

二、严格落实农产品质量安全监管措施

各单位要按照属地管理原则，切实加强党的十九大期间农产品质量安全监督管理工作，严格落实各项工作措施。一是做好瓜菜生产技术指导和服务。要及时组织农技人员进村入户到田，指导农民开展瓜菜生产，指导农民科学合理用药防控病虫害，做到早发现，早防治，防止扩散蔓延。二是强化安监员网格化监管。要充分发挥安监员的作用，妥善安排党的十九大期间的采样送样工作，保证党的十九大期间农产品质量安全监管工作有序开展。三是要针对属地农产品质量安全监管难点、热点问题和薄弱环节，深入排查隐患，严格落实种植养殖环节和农业投入品监管，努力消除食用农产品生产环节和农业投入品监管的空白和盲区，从严查堵农产品质量安全监管漏洞。四是要加大党的十九大期间上市鲜活农产品质量安全监测力度，开展农产品生产基地抽查检测，发现不合格农产品一律不得上市销售并依法处置。同时，对监测中发现的问题要及时反馈、及时追溯源头、及时妥善处理。五是要切实落实凭证出岛制度。各区域检测站要认真组织抽样检测，确保我市出岛瓜菜100%检测，100%凭证出岛。六是要严格执行外来市县瓜菜交易准入制度。对进入我市瓜菜收购交易的外来市县瓜菜，无论是否持有产地农业部门出具的检测报告单，都必须主动配合我市属地检测站做好采样检测工作，对检测出违禁农药的要坚决组织销毁。

三、做好农产品质量安全应急处置工作

要加强农产品质量安全应急管理，不断完善应急机制，确保农产品质量安全应急工作快速、高效、有序开展。要设立举报投诉电话，并严格执行值班制度和工作日报制度，认真受理群众举报投诉，及时组织调查处理。一旦出现农产品质量安全突发事故（件），要快速反应，果断处置，并将有关情况按照规定及时报告。各单位要指定专人负责信息报送工作，建立健全信息收集、编写、报送等工作制度，要保持24小时联络畅通，并把值班电话、值班表上报市农业局。三亚市农业局值班电话：88272023。
