# 三亚市农业局关于印发2017年全国科普日活动方案的通知

局各有关单位：

根据三亚市全民科学素质工作领导小组《关于印发2017年三亚市全国科普日活动实施方案的通知》（三全科组办〔2017〕1号）文件安排，我局结合实际，制定《三亚市农业局2015年全国科普日活动方案》，现印发给你们，请认真组织实施。

各单位要高度重视，精心组织，认真总结科普日的各项活动，形成活动总结。请于10月27日前将活动总结和相关图片等影像资料报送市农业局科教科。

三亚市农业局
