# 对藤加线（南田至爱工队公路）、南田农场爱泉分场至爱华队公路水毁项目进行审计的通知

三审投通〔2017〕107号

三亚市审计局

对藤加线（南田至爱工队公路）、

南田农场爱泉分场至爱华队公路水毁项目

进行审计的通知

市交通运输局：

根据《中华人民共和国审计法》第二十二条的规定，我局决定派出审计组，自2017年9月4日起，对你单位负责建设的藤加线（南田至爱工队公路）、南田农场爱泉分场至爱华队公路水毁项目进行审计，必要时将追溯到相关年度或将对项目直接有关的设计、施工、监理等单位取得项目资金的真实性、合法性进行调查，并通知相关单位。请予积极配合，并提供有关资料（包括电子数据资料）和必要的工作条件。

审计组组长：陈惠琳

审计组成员：谭春华（主审） 邢增宝（兼职廉政监督员）

宋新兵（北京华信今朝国际工程咨询有限公司）

附件：三亚市审计局关于审计纪律的规定

三亚市审计局

2017年8月31日
