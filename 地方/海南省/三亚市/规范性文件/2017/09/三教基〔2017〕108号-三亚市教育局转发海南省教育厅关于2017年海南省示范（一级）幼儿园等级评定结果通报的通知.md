# 三亚市教育局转发海南省教育厅关于2017年海南省示范（一级）幼儿园等级评定结果通报的通知

三亚市教育局转发海南省教育厅关于

2017年海南省示范（一级）幼儿园等级评定

结果通报的通知

各区教科局，市教育局直属幼儿园：

现将《海南省教育厅关于2017年海南省示范（一级）幼儿园等级评定结果的通报》（琼教基〔2017〕146号）转发给你们，请你们按通知精神，认真落实。在提高办园水平的基础上，全面提高保育、教育质量。要继续参照《海南省幼儿园等级评定标准（2015年修订版）》，有计划地推动示范性幼儿园建设，做好幼儿园晋级工作，各区教科局要鼓励本区的优秀幼儿园申报省一级以上幼儿园。

三亚市教育局

2017年9月22日
