# 三亚市林业局关于亚龙湾亚泰酒店项目办理林地审核的通告

为做好亚龙湾亚泰酒店项目办理林地审核和林业相关手续工作，根据2015年2月15日国家林业局令第35号下发的《建设项目使用林地审核审批管理办法》第十一条“县级人民政府林业主管部门对建设项目拟使用的林地，应当在林地所在地的村（组）或者林场范围内将拟使用林地用途、范围、面积等内容进行公示，公示期不少于5个工作日。”及有关法律法规规定。现将有关情况通告如下：

一、项目名称：亚龙湾亚泰酒店项目

二、用途：商业服务用地与精品度假酒店用地。

三、项目用地范围：该项目位于三亚市吉阳区亚龙湾旅游度假区亚龙大道龙塘路区域。所使用林地面积占《三亚市林地保护利用规划（2010-2020年）》规划内的林地面积0.5692公顷。亚龙湾亚泰酒店项目包括B12、G09共二个地块，其中G09地块位于亚泰亚龙湾商业街东侧，龙塘路南侧， B12地块位于亚泰亚龙湾商业街北侧，龙塘路北侧。具体详见：三亚兰海亚龙北部湾区开发有限公司用地红线图。

四、通告期限：5个工作日（2017年9月7日至2017年9月13日）。
