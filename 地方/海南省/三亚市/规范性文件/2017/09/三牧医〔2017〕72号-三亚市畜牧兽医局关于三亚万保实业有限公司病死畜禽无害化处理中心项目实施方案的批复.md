# 三亚市畜牧兽医局关于三亚万保实业有限公司病死畜禽无害化处理中心项目实施方案的批复

三亚万保实业有限公司：

报来《三亚万保实业有限公司建设病死畜禽无害化处理中心实施方案》收悉。根据《海南省财政厅关于下达2016年部分农业项目资金（第二批）的通知》（琼财农〔2016〕680号）、《海南省病死畜禽无害化处理公共服务体系建设规划（2016―2020）》精神，经研究，现批复如下：

一、同意建设三亚万保实业有限公司病死畜禽无害化处理中心项目。项目位于三亚市育才生态区明善村，交通便利，水电通畅，且远离居民、风景名胜、自然保护区及饮用水源保护区，符合环保、防疫要求，可建设病死畜禽无害化处理中心。项目建成后可建立健全三亚病死畜禽无害化处理公共服务体系，大大提高病死畜禽无害化处理能力，对加快推进畜禽养殖废弃物无害化处理和资源化利用，防控重大动物疫病，维护公共卫生安全，促进畜牧业持续稳定健康发展具有十分重要的意义。

二、项目建设规模及内容：主要包括购置无害化处理机1套、专用运输车1辆、监控设备1套、消毒设备2套；新建生产厂房600平方米、控制室30平方米、防疫消毒室20平方米、厂区道路350米、厂房雨污分流120米、蓄水池2座（100立方米）、环保处理污水池1座（50立方米），配套水电及相关设施。

三、项目匡算投资：总投资150万元。其中海南省2016年部分农业项目（病死畜禽无害化体系试点建设项目）资金100万元，专项用于病死畜禽无害化处理中心项目建设，不足部分由企业自筹解决。

四、严格项目管理。严格按照国家有关农业项目管理要求，实施项目建设和强化资金管理，专款专用，严禁挤占挪用项目建设资金，确保资金使用安全有效。

五、完善项目建设条件。要进一步落实项目建设条件，严格按照政府投资项目有关管理规定组织实施。

三亚市畜牧兽医局
