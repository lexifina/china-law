# 三亚市畜牧兽医局关于下达病死畜禽无害化处理体系试点建设项目资金（第一批）的通知

三亚万保实业有限公司：

根据《海南省财政厅关于下达2016年部分农业项目资金（第二批）的通知》（琼财农〔2016〕680号)和《海南省病死畜禽无害化处理公共服务体系建设规划（2016―2020）》精神，结合项目审核、公示和项目批复，安排你单位2016年部分农业项目资金100万元，专项用于病死畜禽无害化处理中心项目，主要购置无害化处理机、专用运输车、监控设备、消毒设备，新建生产厂房、控制室、防疫消毒室、厂区道路、厂房雨污分流、蓄水池、环保处理污水池，配套水电及相关设施等。请依照国家相关项目管理规定、批复的建设规模及内容和项目协议等要求，规范项目工作程序和财务管理，专项核算，专款专用。根据项目实施进度，现将病死畜禽无害化处理体系试点建设项目资金（第一批）90万元下达给你单位，要加快推进项目建设进度，办理好相关项目建设手续，确保实施项目按期按质完成建设，发挥好财政资金应有效益，进一步提升我市病死畜禽无害化处理的能力，实现病害动物的无害化处理与资源化利用。

三亚市畜牧兽医局

2017年9月22日
