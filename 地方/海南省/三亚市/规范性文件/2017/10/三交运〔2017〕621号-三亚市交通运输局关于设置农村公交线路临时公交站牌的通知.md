# 三亚市交通运输局关于设置农村公交线路临时公交站牌的通知

三亚市公共交通集团有限公司：

为完善我市公共交通基础设施建设，要求你公司对全市农村公交线路公交站点进行巡查，在未设立公交站牌且也未列入2016公交候车亭建设计划的农村公交站点设置临时公交站牌，设立的临时公交站牌内明确公交车到站时间表，以便市民游客及当地村民的公交出行。

特此通知。

附件：《三亚市2016年计划建设公交候车亭和站牌情况一览表》

三亚市交通运输局

2017年10月16日
