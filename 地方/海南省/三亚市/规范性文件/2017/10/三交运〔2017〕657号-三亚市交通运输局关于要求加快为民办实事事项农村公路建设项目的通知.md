# 三亚市交通运输局关于要求加快为民办实事事项农村公路建设项目的通知

三交运〔2017〕657号

三亚市交通运输局

关于要求加快为民办实事事项农村公路

建设项目的通知

海南第三建设工程有限公司：

根据海南省交通运输厅关于《关于2017年为民办实事事项农村公路建设进展情况的通报》精神，截至今年9月底，临高县、文昌市、东方市和白沙县已提前完成为民办实事建设任务。你公司作为我市为民办实事农村公路建设项目第三标段抱龙村委会扎浩村至扎套村公路的施工单位，施工进度已明显滞后。尤其在项目实施过程中，存在施工人员、机械不足，施工组织安排不够紧密有序等问题，已严重影响我市为民办实事农村公路建设项目整体进度。

为民办实事事项是省委、省政府向全省人民作出的郑重承诺，鉴于我市为民办实事农村公路建设三个标段中，除了你公司负责的三标段以外，另两个标段已基本完成建设任务，现责令你公司加强重视，抓住现有晴好天气的有利条件，增派施工人员、机械，合理优化施工组织，加班加点，务必在10月底前保质保量完成全部建设任务！

附件：《海南省交通运输厅关于2017年为民办实事事项农村公路建设进展情况的通报》

三亚市交通运输局

2017年10月26日
