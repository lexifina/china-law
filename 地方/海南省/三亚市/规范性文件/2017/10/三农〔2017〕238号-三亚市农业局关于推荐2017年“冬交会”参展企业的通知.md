# 三亚市农业局关于推荐2017年“冬交会”参展企业的通知

育才生态区管委会、市林业局、市海洋与渔业局、市供销社，各区农林局：

为做好2017年冬交会参展企业及产品的选定工作，做到早策划、早安排、早布置、早落实，请你单位积极推荐本部门、本辖区知名农业企业或合作社参展。

参展展品包括热带水果、冬季瓜菜、南繁产品、畜禽产品、林业产品、水产品等，以省级以上品牌产品为主，需有包装和品牌；参展的水果和瓜菜（鲜活畜禽产品除外）必须由市现代农业检验检测预警防控中心定量检测合格（送检样品与参展产品必须出自同一生产者和同一生产基地），并张贴可追溯的二维码标识；参展加工品必须是质量合格，通过相关认证的产品。最后参展企业、合作社名单，由市农业局根据参展需要统筹考虑后公布。

请各单位于10月31日12:00前将《参展单位及展品推荐表》（见附件）报市农业局种植业科。
