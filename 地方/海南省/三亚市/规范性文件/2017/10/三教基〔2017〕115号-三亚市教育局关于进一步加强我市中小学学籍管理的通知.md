# 三亚市教育局关于进一步加强我市中小学学籍管理的通知

各区教科局，市教育局直属各学校：

学籍管理工作是学校和教育行政部门一项重要的日常工作，也是一项基本教育管理制度。为进一步规范和加强我市中小学学籍管理工作，现就有关工作通知如下。

一、充分认识学籍管理工作的重要性和严肃性，确保学籍管理工作正常开展

（一）加强学习，进一步提高学籍管理工作水平和质量。

各校校长、分管副校长，学籍管理员等相关同志要切实加强对《海南省教育厅关于印发<海南省义务教育阶段学校学籍管理实施细则>（修订）和<海南省普通高级中学学籍管理实施细则>（修订)及相关联系表的通知》（琼教〔2015〕13号）和《海南省教育厅关于修订印发<海南省普通高级中学学籍管理实施细则>的通知》（琼教基〔2017〕30号）的学习，要加强对班主任的业务培训，切实发挥班主任队伍的作用，协助有关人员做好学籍管理工作。

（二）创造条件，保障学籍管理系统正常运行。选择责任心强、政治素质好并熟悉电脑操作的同志负责学籍管理工作，并配备专用设备（存储学籍数据的专用计算机和用于拍照佐证材料的数码相机或扫描仪），保障学籍系统顺利运行。

（三）规范学籍档案材料管理。学籍档案资料的存储必须规范、准确，学生建籍花名册、毕业生花名册和学生基本信息表必须入档存放、永久保存。

（四）切实保障学籍管理员待遇。各校应配备专兼职学籍管理员,学籍管理人员要求相对稳定，避免因业务不熟造成学籍管理混乱。各校应合理计算学籍管理员的工作量，提高学籍管理员待遇，在评优评先时应考虑学籍管理员的工作成绩。

（五）严格执行信息保密制度。各校要严格落实《全国中小学生学籍信息管理系统数据导出使用管理规则》，数据导出执行“专人负责，双人操作”制度，学籍数据原则上只能用于与教育相关的管理工作，对违规操作，造成学籍数据泄露的将按规定追究相关人员的责任。

二、严格管理，规范操作，不断提高学籍管理工作水平

(一)新生建籍

1.小学招收年满六周岁的适龄儿童入学,并在每年9月30日前完成全国学籍系统小学一年级新生电子学籍建立工作，在每年11月底前完成新生问题学籍的处理工作，严禁学校为不足龄儿童建立小学学籍。对于隐瞒学校已经在学籍系统注册过一年级学籍，现又注册一年级学籍而造成问题学籍的学生，后果由学生家长负责，教育主管部门将不予处理。

2.初中市内新生学籍根据统一招生（按招生学区统一分配的新生）、自主招生原则办理学籍，初一新生学籍根据学生报到就读名单，由就读学籍管理员导入，待学籍主管部门审批后，学校调取档案和学生分班等工作。

3.高中新生学籍根据市中招办提供的各高中录取名单，由学籍系统市学籍主管部门导入，各高中在学籍系统点击学校录取新生即可录取本校高一学籍，并及时完成高一新生调取档案和学生分班等工作。

4.初中和高中应及时为升学学生更新电子学籍系统中的照片信息。

5.省外小学、初中毕业学籍的初一、高一新生在学籍系统中进行毕业后跨省就读申请。初中新生在每年9月30日前完成全国学籍系统七年级新生录取工作。

(二)补建学籍

由于在校生注册已关闭，若学校非起始年级有遗漏未建学籍或从外地转入而对方学校未建学籍的学生，须填写《提交中央查重的在校生学籍信息注册模板》，由市教育局统一书面请示省厅，待中央查重审核后,会在某个时间段点对点开放学籍系统在校生注册端口，届时方可办理。从今年开始，全市补建学籍每年只报一次，时限在每年11月1日-15日前。

(三)转学

1.学籍管理实行“一人一籍，籍随人走”的原则，学校不得接收未按规定办理转学手续的学生就读。转学手续包括学籍系统外手续、电子学籍系统学籍转接手续。学校不得空挂学生学籍。

2.学生转入、转出只能在寒暑假内和每学期开学第一周内进行（其余时间一律不准转出转入学生）。学校必须督促学生家长及时办理纸质转学手续，并在开学后1个月内办结。并及时完成学籍系统内学生转入申请、转出核办和调取学籍档案工作，转入申请需在学生进校后10个工作日内在学籍系统中完成转入申请。

3.学校学籍管理员每个工作日至少需登录学籍系统1次，及时处理转出核办和调取学籍档案等相关业务。

(四)休学和复学

1.学生因病长期治疗需办理休学的，应由学生本人及其家长提出书面申请，填写《三亚市中小学生休学复学申请表》，提供县级以上（含县级）医疗机构开具的疾病诊断书、住院发票和病历，由学校审核后报教育主管部门审批，并在学籍管理系统中提交休学申请。

2.休学期限一般为一年，休学期满后应及时为学生在学籍系统内办理复学手续，复学手续在开学后1个月内办结。

3.普通中小学学生在义务教育阶段原则上最多休学两次。暑（寒）假生病且在暑（寒）假病愈出院，不予办理休学手续。

(五)学生基础数据变更

学生基础信息（主要指修改姓名、出生年月、民族等个人信息）因误或变更需修改时，学校应要求学生及家长提供户籍信息(户口本、身份证或户籍管理部门出具的证明材料原件和复印件），学校及时在学籍信息管理系统中提出关键数据变更申请并上传佐证材料，由学籍主管部门审核。

(六)学籍注销

1.义务教育阶段学生除因出境定居或意外身亡外，不得以任何理由申请注销学籍。

2.普通高中学生学籍注销按《海南省普通高级中学学籍管理实施细则》执行。学校应及时在学籍系统里申请注销退学学生的学籍，并保存好相关证明材料。

(七)毕业

1.义务教育阶段学生学习期满后，全部在学籍系统中操作毕业。通过市招办的统一录取或办理了正常的学籍变更手续的普通高中学生，在校学习修满三年、参加并全部通过省规定科目的学业水平考试、综合素质评价达到合格的方可准予毕业，未通过学业水平考试的学生给予结业。

2.学校应在每年的7月30日前在学籍系统完成所有毕业年级的毕业结业操作和其他在办业务处理。

(八)规范使用学籍管理材料

全市中小学办理转学、休学、复学及开具毕业生证明等，均应使用统一的各类表格。各学校审批办理学籍变更时，要规范填写各类表格，表格内各栏内容均应填写完整、详备，不得空白。各学校可自行打印各类学籍管理表格。

三、改进方法，强化服务，切实提高学籍管理工作质量

1.各学校要有效利用全国中小学生学籍信息管理系统做好学籍管理工作。各学校要与时俱进，遵循学生发展需求，充分利用各类信息化管理手段，不断提高学籍管理工作信息化水平和工作效率。

2.各学校要本着以生为本、服务家长的理念，切实增强服务意识，加强政策宣传，向家长一次性告知说明相关要求和办事程序，各项手续办理应一步到位，切实为学生和家长提供便利，避免反复折腾、增加成本，努力树立教育工作者的良好形象。

3.市教育局将加强学籍管理工作的监控，并将学籍管理工作纳入学校目标管理考核，并作为年度评优评先的重要依据。
