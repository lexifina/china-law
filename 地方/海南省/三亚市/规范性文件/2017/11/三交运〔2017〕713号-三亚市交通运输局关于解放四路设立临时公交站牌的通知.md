# 三亚市交通运输局关于解放四路设立临时公交站牌的通知

三亚市公共交通集团有限公司：

由于225国道（海榆西线）凤凰路至解放四路段道路改造工程，你公司对解放四路凤凰水城北门、世嘉公寓、回新村、南开寺、双品学校等5个公交站点候车亭进行了拆除。为方便市民和游客乘车，现要求你公司在上述5个公交站点设立临时公交站牌，并于2017年11月18日前完成临时公交站牌线路信息的刷新工作。

三亚市交通运输局

2017年11月17日
