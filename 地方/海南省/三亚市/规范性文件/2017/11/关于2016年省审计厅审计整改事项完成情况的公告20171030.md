# 关于2016年省审计厅审计整改事项完成情况的公告20171030

关于2016年省审计厅审计整改事项

完成情况的公告

根据省审计厅《关于做好2016年度省本级预算执行和其他财政收支审计工作报告披露问题整改工作的通知》（琼审〔2017〕498号）、《审计报告》（琼审资报〔2017〕186号）、海南省国土资源厅《关于印发进一步推动拖欠土地出让金清理处置工作方案的通知》（琼国土资用字〔2017〕75号）的整改要求，我局已对《审计报告》中提到的我市土地出让金及滞纳金应征未征情况进行了全面清理，逐宗制定处置整改方案，并认真整改落实。现我局将上述审计整改事项的完成情况公告如下：

根据海南省审计厅的《审计报告》，我局需整改事项共4宗、应征未征土地出让金和滞纳金共计14285.98万元。审计整改期间，我局完成3宗项目用地土地出让金和滞纳金的追缴工作，共计11130.94万元。分别为：1.海南中海三邦友房地产开发有限责任公司土地出让金（本金）6544万元、土地出让金滞纳金1334.98万元。现已征缴完成土地出让金（本金）6544万元。根据市政府批示意见，该公司在实施分期缓缴土地出让金的过程中，并无过错，不存在违约行为，因此该公司无需缴纳1334.98万元土地出让金滞纳金；2.三亚汇涛置业有限公司土地出让金滞纳金1454.94万元，现已全部追缴完成；3.海南满天星旅业开发有限公司土地出让金（本金）3000万元、土地出让金滞纳金132万元，现已全部追缴完成。

特此公告。

三亚市国土资源局
