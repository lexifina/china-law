# 三亚市交通运输局关于调整49路公交线路的批复

三亚市公共交通集团有限公司：

来文《关于优化49路公交线路至凤凰山居小区的请示》（三公交集〔2017〕94号）收悉。经研究，现批复如下：

一、将49路（槟榔河温泉至凤凰岛）公交线路调整为（鸿森医院至凤凰岛），并增加“凤凰山居”公交站点，调整后停靠站点为：

鸿森医院、凤凰山居、新联小学、槟榔河景区、林家村口、妙林村口、槟榔村口、检察院、凯丰花园、边检站、火车站、边检站、海航学院、综合执法局、第一中学、海韵假日、丹州小区、财政大厦、迎宾花园、月川桥广场、工商银行、明珠广场、人民医院、水利大厦、凤凰岛。

返回时途经站点：凤凰岛、供电公司、汽车总站、人民医院、明珠广场、工商银行、月川桥广场、迎宾花园、财政大厦、丹州小区、海韵假日、第一中学、综合执法局、海航学院、边检站、火车站、边检站、凯丰花园、检察院、槟榔村口、妙林村口、林家村口、槟榔河景区、新联小学、风凰山居、鸿森医院。

二、请你公司务必于2017年11月15日前完成公交车辆腰牌、公交站牌线路信息、报站器数据的刷新工作。待上述工作完成后，自2017年11月15日首班车起严格按照调整后的停靠站点提供运营服务。

三亚市交通运输局

2017年11月10日
