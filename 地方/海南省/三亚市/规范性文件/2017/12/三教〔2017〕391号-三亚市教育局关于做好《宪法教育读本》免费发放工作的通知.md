# 三亚市教育局关于做好《宪法教育读本》免费发放工作的通知

各区教科局、各直属学校：

根据海南省教育厅《关于做好<宪法教育读本>免费发放工作的通知》（琼教法〔2017〕94号）要求，为了进一步强化青少年学生宪法教育，弘扬宪法精神，推动广大青少年学生牢固树立宪法意识，中国法制出版社免费向我省捐赠了一批由其编印出版的《宪法教育读本》（分小学版、初中版、高中版）。现就捐赠读本发放有关事项通知如下：

一、《宪法教育读本》将由法制出版社于今年秋季开学后直接配送各地各校（具体分配数量见《宪法教育读本》分配表），届时由市教育局和出版社工作人员直接将读本交赠与学校。此次发放系公益捐赠性质，相关费用由出版社承担，各单位无须支付其他任何费用。

二、各区教科局和学校要高度重视读本发放工作，指定专人负责接收与分配，及时将读本发放到辖区内中小学，作为学校图书配置和学校开展宪法教育重要学习资料。

附件：《宪法教育读本》分配表
