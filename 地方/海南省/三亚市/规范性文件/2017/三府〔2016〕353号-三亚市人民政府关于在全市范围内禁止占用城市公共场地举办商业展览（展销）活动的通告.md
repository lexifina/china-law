# 三亚市人民政府关于在全市范围内禁止占用城市公共场地举办商业展览（展销）活动的通告

三亚市人民政府

关于在全市范围内禁止占用

城市公共场地举办商业展览（展销）活动的通告

三府〔2016〕353号

为进一步整治城市容貌和环境卫生，创造舒适优美的公共安全环境，根据国务院《大型群众性活动安全管理条例》、《海南省城镇园林绿化条例》、《海南省城乡容貌和环境卫生管理条例》、《海南省城市市政设施管理条例》等相关法规的规定，现将有关事项通告如下。

一、禁止任何单位或个人占用城市道路、桥梁、地下通道以及其他公共场所、城市道路设施、城镇绿地举办商业展览（展销）活动。

二、本通告发布之前已经占用城市公共场地举办商业展览（展销）活动的，应立即停止展览（展销）活动，并自行拆除搭建的建筑物、构筑物。

三、对违反本通告规定的，由城市管理、公安等部门依据各自职能依法责令其进行整改；逾期不整改的，依法对涉案物品、工具实施扣押，并依法对其建筑物、构筑物予以强制拆除。

四、凡拒绝、阻碍执法人员依法执行公务的，依照《中华人民共和国治安管理处罚法》予以处罚；构成犯罪的，依法追究刑事责任。

五、本通告自发布之日起施行。

三亚市人民政府

2016年12月31日
