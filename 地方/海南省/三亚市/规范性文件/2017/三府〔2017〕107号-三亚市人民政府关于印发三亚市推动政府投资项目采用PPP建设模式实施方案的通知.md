# 三亚市人民政府关于印发三亚市推动政府投资项目采用PPP建设模式实施方案的通知

三亚市人民政府

关于印发三亚市推动政府投资项目采用PPP

建设模式实施方案的通知

各区人民政府，各管委会，市政府直属各单位:

《三亚市推动政府投资项目采用PPP建设模式实施方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府

2017年4月15日

（此件主动公开）

三亚市推动政府投资项目采用PPP建设

模式实施方案

为贯彻落实《关于创新重点领域投融资机制鼓励社会投资的指导意见》（国发〔2014〕60号）、《国务院办公厅转发财政部、国家发展改革委、人民银行关于在公共服务领域推广政府和社会资本合作模式指导意见的通知》（国办发〔2015〕42号）、《关于创新重点领域投融资机制鼓励社会投资的实施意见》（琼府〔2015〕120号）文件精神，根据《三亚市推广和运用政府和社会资本合作模式的实施意见》，为大力推进我市政府投资项目采用PPP建设模式的相关工作，结合我市实际，制订方案如下：

领导小组办公室设在市发展改革委，负责落实领导小组议定事宜，负责协调、推进PPP建设相关事项。办公室主任由市发展改革委主任张利兼任。

（二）成立PPP 模式具体推进工作组，负责项目的具体推进实施

1.项目组。由市发展改革委牵头，项目责任单位、市财政局等相关单位配合，组织开展PPP项目识别、项目准备，对列入PPP项目库的项目进行分类打包，及时设立、调整PPP项目库，协调各主管单位加快完成可行性研究报告等前期工作。协调完成项目融资工作，负责跟踪、协调试点项目有序推进。

2.采购组。由市财政局牵头，市发展改革委和相关部门配合，通过公开招标，分别建立咨询机构库、社会资本机构库。牵头制订PPP项目商务谈判基本条件。由市财政局牵头完成PPP项目物有所值评价和财政承受能力论证工作。

3.商务组。由项目责任单位牵头，市发展改革委等相关单位配合，根据项目特点补充完善PPP项目商务谈判条件，并从咨询机构库中选定PPP项目咨询机构。市财政局负责指导各项目实施单位开展社会资本的采购工作，采购方式原则上采用公开招标方式。

4.实施组。由项目责任单位落实，市发展改革委、市规划局、市国土资源局、市生态环境保护局等审批单位配合，及时完成相关审批程序，组织开展项目建设。

二、工作流程和分工

（一）完善PPP项目库，做好项目前期工作

市发展改革委梳理拟采取PPP模式建设的政府投资建设项目，经市相关单位讨论，报市政府审定后向社会公示。市发展改革委会同项目责任单位和市财政局对PPP项目进行分类打包。项目责任单位启动PPP项目的前期工作，完成PPP项目可行性研究论证。

（二）保障项目前期工作经费

市财政局负责安排PPP项目的前期工作经费，确保项目前期工作顺利开展。

（三）建立PPP咨询机构库和PPP社会资本机构库

市财政局牵头，市发展改革委和相关单位配合，商咨询机构、招标代理机构制订招标文件。通过一次公开招标，建立一个10-15个单位的PPP咨询机构库、一个50个单位的PPP社会资本机构库，以节省PPP咨询机构和社会资本的多次招标时间。

（四）编制PPP项目实施方案

由项目责任单位根据项目特点，通过在PPP咨询机构库中比选产生一个PPP实施方案编制机构，委托其开展项目PPP实施方案、物有所值评价和财政承受能力论证的编制。市财政局对物有所值评价和财政承受能力论证进行评定。PPP实施方案应征求市发展改革委、市财政局、市审计局、市规划局、市国土资源局、市生态环境保护局、市国资委等职能部门意见后，项目责任单位报市政府批准。

（五）设立项目公开招标条件

按照下列PPP招标基本条件，项目责任单位根据具体项目特点，进一步确定PPP项目商务条件。

1.项目内部收益率（税前）

（1）政府付费的工程类项目原则上不高于5.8%和5年期以上贷款基准利率上调1个百分点中的较小值。

（2）非工程类项目原则上不高于8.8%和5年期以上贷款基准利率上调4个百分点中的较小值。

（3）使用者付费类项目原则上不高于7.8%和5年期以上贷款基准利率上调4个百分点中的较小值。

（4）可行性缺口补贴类项目应视补贴缺口比例确定，项目内部收益率（税前）介于政府付费类及使用者付费费类之间。

2.工程造价下浮率

（1）园林、信息化类项目原则上不低于8%；

（2）水务、环保类项目原则上不低于8%；

（3）桥梁类项目原则上不低于7%；

（4）道路类项目原则上不低于6%；

（5）建筑类项目原则上不低于5%；

（6）环卫类项目原则上不低于5%；

（7）地下综合管廊项目原则上不低于5%；

（8）农业设施类项目原则上不低于3%；

（9）其他项目原则上不低于4%；

根据项目实际情况，可统筹考虑项目资本金回报率和工程造价下浮率进行综合平衡，确需调整上述指标的，报市政府专题会议审议通过。

3.企业净资产可覆盖项目投资额。

4.具备一级以上工程建筑资质（含联合体的施工方）。

5.PPP项目合作年限不低于10年，政府购买服务项目合作年限不低于5年。

6.社会资本在项目公司中出资比率不低于80%。

7.项目的回报参数、工程造价下浮率等应为公开招标的核心评选依据。

（六）选定社会资本。

项目责任单位组织相关单位，组成评审小组，通过公开招标程序确定社会资本，合格的投标人不得少于3人。根据PPP实施方案及与中标人确定的各项合作条件，报市政府审批后，项目责任单位与确定后的社会资本签订PPP合作协议。

（七）组建项目公司

由市政府授权的市属国有企业作为政府代表出资机构，与引入的社会资本，成立项目公司。市财政局准备一定数额的公司注册资本，并根据项目实施计划安排，分年度提供市政府应出相应比例的项目资本金。必要时，市发展改革委研究通过发行其他债权或基金解决政府出资款。

（八）推进PPP项目实施

项目公司组建后，应继续推进项目前期工作，尽快完成PPP项目的前期手续，以期早日开工建设和运营。市发展改革委负责跟踪、协调PPP项目的有序推进。

行业主管部门审查初步设计方案；市发展改革委负责初步设计和概算审批；项目责任单位根据初步设计方案同步制定项目实施考核机制、绩效评价方案、建设运营监督制度和到期移交标准；市规划局负责核发建设用地规划许可证及建设工程规划许可证；市住房城乡建设局负责核发工程许可证。

（九）办理PPP项目融资工作

在完善PPP项目前期手续的同时，项目公司应及时开展项目融资相关工作，在必要时，市发展改革委予以协调推进。若社会资本按约定比例自行出资，则不需再进行融资。

市发展改革委、市财政局等单位应积极向上级争取，申请PPP项目的相关资金，以减少市财政出资压力和财政负担。

（十）项目建设和运营

项目公司负责项目的建设和运营。项目责任单位负责组织建立、组织工程审计、考核项目建设和运营情况。项目责任单位应做好项目建设、运营过程中的考核、监管。

（十一）项目移交

项目运营期满后，或项目责任单位考核认定社会资本项目实施不合格需终止项目合同后，由项目责任单位与项目公司开展项目移交工作。PPP项目中途终止履行合同时，市审计局介入先行清算审计，项目责任单位在赔付时，应扣除对社会资本的处罚金额。

三、工作要求

（一）加大业务培训力度。市财政局、市发展改革委牵头加大对PPP模式的财政风险管理、融资创新、操作流程及法律风险防范进行系统培训，使更多的业务人员对其了解充分，准确解读，从而更好地满足新的融资模式的需要。

（二）加强督办力度。市政府督查室要加大督查工作力度，制定具体的督查方案，严明督查纪律，提高督查质量，做到严查、勤查、细查，定期通报各整治组、各责任单位的任务完成情况,公布督查结果。对思想不重视、措施不得力、效果不明显、工作走过场、整治进展慢的单位，提请市委、市政府依法追究问责，该通报的公开通报，该查处的及时查处。
