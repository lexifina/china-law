# 三亚市人民政府关于印发三亚市行政事业性收费目录清单和三亚市政府定价和政府指导价经营服务性收费目录清单的通知

三亚市人民政府

关于印发三亚市行政事业性收费目录清单和

三亚市政府定价和政府指导价经营服务性

收费目录清单的通知

各区人民政府，各管委会，市政府直属各单位：

为规范收费行为，接受社会监督，根据《国家发展改革委办公厅关于全面实行收费目录清单制度的通知》（发改办价〔2016〕1415号）规定，我市开展了行政事业性收费、政府定价和政府指导价经营服务性收费清理工作。经清理，我市重新制定了《三亚市行政事业性收费目录清单》和《三亚市政府定价和政府指导价经营服务性收费目录清单》，现印发给你们，请认真遵照执行。

三亚市人民政府《关于印发〈三亚市行政事业性收费项目及标准目录清单和三亚市政府实行政府定价、政府指导价涉企经营服务性收费项目及标准目录清单〉的通知》（三府办〔2015〕268号）同时废止。

附件：1．三亚市行政事业性收费目录清单

2.三亚市政府定价和政府指导价经营服务性收费目录清单

三亚市人民政府

2017年5月7日
