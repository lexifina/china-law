# 三亚市人民政府关于征收三亚市创意新城控规A41-3/1地块3.0439公顷集体土地的通告

三亚市人民政府

关于征收三亚市创意新城控规A41-3/1地块3.0439公顷

集体土地的通告

经海南省人民政府同意，原海南省国土环境资源厅以“琼土环资耕字〔2008〕68号”文批准同意征收崖州区（原崖城镇）大蛋村委会第一、二村民小组及乾隆村村委会第一村民小组3.0439公顷集体土地。根据《中华人民共和国土地管理法》第46条、《中华人民共和国土地管理法实施条例》第25条和《海南经济特区土地管理条例》的有关规定，以及《海南省国土环境资源厅关于进一步做好市县征地信息公开工作有关问题的通知》（琼土环资耕字〔2014〕14号），现将经批准的《征收土地方案》内容和有关事项通告如下：

一、被征收土地规划性质：

A41-3/1地块为商业用地。

二、被征收土地四至范围：

位于崖州区崖洲湾（具体位置详见宗地勘测定界图）。

三、被征收土地权属单位及面积：

崖州区（原崖城镇）大蛋村委会第一、二村民小组及乾隆村村委会第一村民小组集体土地，面积：3.0439公顷。

四、征收补偿标准：

按照原海南省国土环境资源厅《关于三亚市创意新城控规A41-3/1地块农用地转用及土地征收手续的批复》（琼土环资耕字〔2008〕68号）批准的补偿标准对崖州区（原崖城镇）大蛋村委会第一、二村民小组及乾隆村村委会第一村民小组3.0439公顷集体土地进行补偿。

五、农业人员安置：

（一）根据三亚市人民政府有关征地补偿标准规定，一次性拨付土地安置补助费。

（二）被征地农民社会养老保险和就业保障，按《三亚市被征地农民基本养老保险暂行办法》有关规定办理。

六、被征收土地四至范围内的土地所有权人、使用权人在通告规定期限内，持土地权属证书或其他有关证明材料，到指定的地点办理征地补偿登记。

凡从崖州区政府现场调查之日起，抢栽、抢种青苗和抢建地上附着物的不予办理补偿登记。
