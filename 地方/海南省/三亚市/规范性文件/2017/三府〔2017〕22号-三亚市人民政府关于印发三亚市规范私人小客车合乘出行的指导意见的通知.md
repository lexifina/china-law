# 三亚市人民政府关于印发三亚市规范私人小客车合乘出行的指导意见的通知

三亚市人民政府

关于印发三亚市规范

私人小客车合乘出行的指导意见的通知

三府〔2017〕22号

各区人民政府，各管委会，市政府直属各单位：

《三亚市规范私人小客车合乘出行的指导意见》已经七届市政府第2次常务会议审议通过，现印发给你们，请认真组织实施。

三亚市人民政府

2017年1月20日

（此件主动公开）

三亚市规范私人小客车合乘出行的指导意见

为缓解城市交通拥堵，倡导绿色出行，方便社会公众出行，鼓励并规范私人小客车合乘行为，保障合乘各方的合法权益，根据《国务院办公厅关于深化改革推进出租汽车行业健康发展的指导意见》（国办发〔2016〕58号）等法律、法规和规章，结合本市实际情况，提出如下意见。

一、合乘定义

私人小客车合乘，也称拼车、顺风车，是由合乘出行提供者事先发布出行信息，出行线路相同的人选择乘坐合乘出行提供者的小客车、分摊部分出行成本或免费互助的共享出行方式。

合乘各方包括合乘信息服务平台（以下简称合乘平台）、合乘出行提供者和合乘者。合乘平台是指以互联网技术为依托构建服务平台，整合供需信息，提供合乘服务的企业法人。

二、基本原则

私人小客车合乘遵循公益合乘优先、民间互助自愿、维护合法权益、规范合乘行为、严禁非法运营的基本原则，鼓励并促进其健康发展。

三、适用范围

在本市行政区域内提供私人小客车合乘服务的，应遵守本意见。

四、合乘各方要求

（一）合乘平台要求。在本市开展合乘信息服务的合乘平台，应当向市道路运输管理机构备案，提供以下相关材料：

1．企业法人营业执照，属于分支机构的还应当提交营业执照，以及法人、经营地址等相关信息；

2．国务院信息产业主管部门或者省、自治区、直辖市电信管理机构颁发的《互联网信息服务增值电信业务经营许可证》；     3．拟开展合乘信息服务的合乘运营模式、合乘出行提供者和合乘者客户端发布及操作方式说明；

4．合乘车辆、合乘出行提供者管理，合乘投诉和有关纠纷处置等制度文本；

5．注册合乘出行提供者和合乘车辆相关信息。

（二）车辆要求。提供合乘服务的车辆应当符合以下条件：

1．本市注册登记；

2．七座以下非营运小客车；

3．车辆通过年检和环保检测；

4．车辆投保营业性交强险、商业第三者责任险。

（三）合乘出行提供者要求。合乘出行提供者应当符合以下条件：

1．取得相应准驾车型机动车驾驶证并具有1年以上驾驶经历，身体健康；

2．无暴力犯罪记录，无交通肇事犯罪、危险驾驶犯罪记录，无吸毒记录，无饮酒后驾驶记录；

3．自合乘平台注册之日前1年内无驾驶机动车发生5次以上道路交通安全违法行为。

五、合乘行为规范

（一）合乘成本分摊。合乘出行分摊的出行成本仅限于当次合乘出行车辆所消耗的燃料成本等费用，由合乘出行提供者和合乘者按照人数合理平均分摊。合乘平台、合乘出行提供者不得收取时间计费及其他任何费用。车辆燃料成本应按照合乘车辆车型工信部登记的综合工况百公里油耗、燃油（气、电）实时价格、合乘里程以平均公里成本计算。合乘平台可在合乘者分摊的费用中提取一定比例的信息服务费。

（二）合乘平台行为规范。合乘平台提供合乘信息服务的，应遵守以下规范：

1．加强合乘车辆、合乘出行提供者、合乘者的实名注册管理，内容应当包括：合乘出行提供者身份证、驾驶证、手机号码等信息；车辆行驶证及保险状况等信息；合乘者身份证、手机号码等信息。对申请注册的合乘车辆和合乘出行提供者按照本意见的要求予以审核，不符合条件的，不得予以注册提供合乘信息服务。注册合乘出行提供者和车辆如发生违法行为或不符合相关条件的，应当及时注销其注册信息、停止提供合乘信息服务；

2．平台数据库接入本市政府监管平台，按要求实时完整传输合乘数据。合乘数据包括但不限于：合乘出行提供者姓名及手机号码、合乘者姓名及手机号码、车辆号牌、车型、单次合乘行为出发、到达时间及地点，行驶轨迹、出行次数、合乘者支付的合乘费用等；

3．应当完善网络安全管理制度和网络安全防范措施，依法合规采集、使用合乘出行提供者和合乘者的个人信息，不得超越提供合乘业务所必需的范围。严格保护数据安全，除配合公安、交通运输等部门依法行使监督检查权或者刑事侦查权外，合乘平台不得泄露合乘双方的信息，不得侵害用户合法权益和社会公共利益。接受公安、交通运输、通信、网信等部门依法监管，遵守国家网络和信息安全有关规定；

4．实时公布合乘出行提供者信用、车辆登记和车辆保险等信息，并建立和落实投诉快速处理制度；

5．合乘软件应提供在线合乘出行服务协议文本、合乘运作流程、评定信用等级等服务内容。明确合乘出行提供者、合乘者各方权利、义务及责任，具备线上签订协议后方可提供当次合乘出行的功能；

6．合乘软件提供合乘出行提供者客户端预先发布的合乘出行信息，应包括合乘出行提供者身份、车辆型号及号牌、起讫点具体地址、出发时间、合乘线路、手机号码等相关信息，并具备合乘者客户端查询；

7．合乘软件不得设置合乘出行提供者预先查询合乘者需求信息的功能，与合乘者签订合乘协议后方可查询，但应具备合乘者预先查询合乘出行提供者供给信息的功能；

8．乘软件应具备按照单次合乘线路测算燃料等成本费用并预先告知合乘者以及当次合乘成本分摊第三方支付的功能。燃料等成本费用可根据合乘出行提供者注册的车辆型号，按照国家工业和信息化部登记的综合工况百公里油耗、燃油等实时价格和合乘线路里程等参数予以自动测算；

9．合乘软件具备符合本意见关于合乘出行提供者行为规范中合乘次数、成本费用分摊等限定功能，并可实时提供相关部门查询。

（三）合乘出行提供者行为规范。合乘出行提供者通过合乘平台提供合乘出行服务的，应遵守以下规范：

1．在合乘平台进行实名注册，并提供合乘车辆的号牌、车型、年检记录以及保险状况等信息；

2．使用具有本市公安交通管理部门核发的有效机动车号牌且年检合格的车辆，并在合乘平台提前发布出行计划及线路，积极配合相关部门执法检查；

3．分摊部分出行成本的，合乘出行提供者每天可提供不超过四次合乘出行；免费互助合乘的，合乘出行提供者每天提供合乘出行次数不受限制。合乘者的起讫点应在合乘出行提供者经过的路线附近。同一合乘线路可以多人共同合乘；

4．应保持合乘车辆性能及技术状况良好，遵守交通规则，确保合乘者的出行安全。

（四）合乘出行责任。私人小客车合乘不属于道路运输经营活动，为合乘各方自愿的民事行为，相关权利、义务和责任由合乘各方自行约定并承担。

六、合乘出行监督管理

（一）日常管理。市道路运输管理机构受市交通运输主管部门委托负责制订合乘平台和合乘出行提供者、车辆备案的具体流程事项，负责对已备案合乘平台的日常监管，督促已备案平台按照规范要求提供合乘信息服务。负责对合乘平台报备的合乘出行提供者及车辆信息按照上述要求予以校核，对不符合条件的合乘出行提供者、车辆，责成合乘平台依据相关管理制度，在平台系统中予以注销。

市道路运输管理机构应监督合乘平台按照有关要求受理市民热线的有关合乘投诉，对存在不符合管理要求的问题应责成合乘平台予以整改，涉嫌违法行为的移交有关部门立案查处。

（二）执法检查。合乘各方应严格遵守道路交通安全法律法规，共同维护道路交通有序、安全、畅通，并配合执法检查，主动提供合乘相关信息。禁止任何企业和个人以合乘名义开展非法营运，禁止利用合乘名义从事道路运输经营活动。违反者由有关部门依照《中华人民共和国道路运输条例》、《网络预约出租汽车经营服务管理暂行办法》、《巡游出租汽车经营服务管理规定》等有关法律、法规和规章进行查处。

（三）信用管理。本市有关部门应当按照职责建立合乘平台和合乘出行提供者信用记录，并纳入本市公共信用信息服务平台。

七、本指导意见自2017年3月1日起实施。
