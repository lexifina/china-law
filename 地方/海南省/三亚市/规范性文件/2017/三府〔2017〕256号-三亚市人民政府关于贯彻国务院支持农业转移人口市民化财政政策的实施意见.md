# 三亚市人民政府关于贯彻国务院支持农业转移人口市民化财政政策的实施意见

三亚市人民政府

关于贯彻国务院支持农业转移人口市民化

财政政策的实施意见

各区人民政府，各管委会，市政府直属各单位：

为贯彻落实《国务院关于实施支持农业转移人口市民化若干财政政策的通知》（国发〔2016〕44号，以下简称《通知》）、《海南省人民政府关于贯彻国务院支持农业转移人口市民化财政政策的实施意见》（琼府〔2017〕37号，以下简称《实施意见》）精神，促进我市农业转移人口市民化和以人为核心的新型城镇化发展，现提出以下实施意见。

一、总体目标

认真落实中央经济工作会议、中央城镇化工作会议、中央城市工作会议和《通知》、《实施意见》精神，按照“创新机制、扩大覆盖，精准施策、促进均衡，强化激励、推动落户，维护权益、消除顾虑”的原则，提高财政保障能力，提升城市功能和承载能力，支持农业转移人口享受同等基本公共服务，促进有能力在城镇稳定就业和生活的常住人口实现市民化。力争到2018年，建立起权责明晰、激励充分、保障有力的支持农业转移人口市民化的财政政策体系。

二、主要措施

（一）支持农业转移人口享受同等基本公共服务。

1. 支持农业转移人口子女平等享有受教育权利。将农业转移人口及其他常住人口随迁子女义务教育纳入公共财政保障范围。全面落实我省中等职业教育免学费相关政策，对城市和农村户籍中职学生均免除学费。进一步完善普惠性学前教育扶持政策，扩大普惠性学前教育资源，不断满足农业转移人口及其他常住人口随迁子女的教育需求。按在校学生人数及相关标准核定义务教育和职业教育中涉及学生政策的转移支付，统一城乡义务教育经费保障机制，实现“两免一补”资金和生均公用经费基准定额资金随学生流动可携带，增强学生就读学校的可选择性。按规定足额落实义务教育和职业教育中涉及学生政策的资金，保障各项政策落实到位。（责任单位：市财政局、市教育局）

2. 支持完善城乡基本医疗保障制度。逐步推进医疗保险关系转移接续和异地就医结算。实行城乡居民基本医疗保险制度。对于居住证持有人选择参加当地居民基本医疗保险的，个人按当地居民相同标准缴费，财政部门按照当地参保居民同样的标准给予补助。继续实施统一、规范、公开、透明的城乡医疗救助制度。逐步推进基本医疗保险参保跨制度、跨地区转移接续。（责任单位：市人力资源社会保障局、市民政局、市财政局、市卫计委）

3. 支持构建统筹城乡的社会保障体系。实行统一规范的城乡社会保障制度。完善企业职工基本养老保险与居民基本养老保险制度衔接办法，将与企业建立稳定劳动关系或符合条件的灵活就业农业转移人口纳入企业养老保险覆盖范围，实现城乡居民基本养老保险制度一体化，促进农业转移人口有序流动。完善城乡居民基本养老保险补助政策，对60岁以上的参保人发放基础养老金，对60岁以下的缴费人口按相应标准施行补助。加强资金全方位监管，防范和堵塞社会保障资金的“跑冒滴漏”，提高资金使用效益。（责任单位：市人力资源社会保障局、市卫计委、市财政局）

4. 支持将农业转移人口纳入就业服务体系。统筹上级就业专项资金和自有财力，支持进城落户农业转移人口中的失业人员进行失业登记，并免费享受政策咨询、职业介绍等公共就业服务，并按规定享受职业培训、技能鉴定、创业担保贷款及财政贴息等扶持政策。（责任单位：市财政局、市人力资源社会保障局）

5. 支持农业转移人口纳入住房保障体系。按照市场配置资源和政府保障相结合的原则，鼓励农业转移人口通过市场购买或租赁住房，采取多种方式解决农业转移人口居住问题。持有居住证的农业转移人口，在三亚市没有住房，在户口所在地未享受过保障性住房，且申请前在三亚市连续缴纳社保不短于6个月的进城农民可申请承租公共租赁住房。（责任单位：市住房城乡建设局、市财政局）

6. 统筹用好上级农业转移人口市民化奖励资金及奖补转移支付，用于提供基本公共服务，切实将农业转移人口纳入基本公共服务保障范围，使农业转移人口与我市户籍人口享受同等基本公共服务。（责任单位：市财政局、市发展改革委、市公安局、市农业局、市卫计委、市人力资源社会保障局、市教育局、市民政局、各区人民政府、育才生态区管委会）

（二）支持提升城镇综合承载能力，缓解农业转移人口带来的城镇基础设施承载压力。

1. 要将农业转移人口市民化工作纳入我市经济社会发展规划、城乡规划和城市基础设施建设规划。（责任单位：市发展改革委、市规划局、市住房城乡建设局、各区人民政府、育才生态区管委会）

2. 要拓宽城市建设融资渠道，通过申请地方政府债券和有关专项资金等方式筹集建设资金。（责任单位：市财政局、市发展改革委）

3. 积极推广政府和社会资本合作（PPP），吸引社会资本参与城市基础设施建设和运营。（责任单位：市财政局、市发展改革委）

4. 加快推进城市地下综合管廊和海绵城市建设。（责任单位：市发展改革委、市住房城乡建设局、市水务局、市园林环卫局、市林业局、各区人民政府、育才生态区管委会）

5. 支持加快推进特色产业小镇建设，通过产城、产业融合发展带动农民就地就近市民化。（责任单位：市发展改革委、各区人民政府、育才生态区管委会、市委农工委）

6. 积极向省争取在特色产业小镇、城市基础设施建设和运行维护等方面的专项资金。（责任单位：市发展改革委、市财政局）

（三）要多渠道筹集资金，促进农业转移人口有序市民化。

1. 多渠道筹集资金，支持农业转移人口市民化。（责任单位：市财政局、市发展改革委）

2. 支持进城落户农民在城镇居住、创业、投资，促进农业转移人口有序市民化。（责任单位：各区人民政府、育才生态区管委会、市人力资源社会保障局、市金融办、市农业局、市住房城乡建设局）

（四）建立农业转移人口市民化与财力性转移支付挂钩机制。

实行财力性转移支付分配与持有居住证人口挂钩，充分考虑各区人民政府为农业转移人口提供基本公共服务的支出需求，加大对吸纳农业转移人口较多且财力水平较低区的转移支付力度。（责任单位：市财政局）

（五）推动居住证管理全面实施，支持逐步扩大为居住证持有人提供基本公共服务和便利的范围。

1. 要将为居住证持有人提供基本公共服务和便利纳入国民经济和社会发展规划（责任单位：市发展改革委、市公安局、市农业局、市卫计委、市人力资源社会保障局、市教育局、市民政局、各区人民政府、育才生态区管委会）

2. 建立健全为居住证持有人提供基本公共服务和便利的相关制度，逐步扩大公共服务和便利的范围并定期向社会公布，并做好居住证持有人的权益保障、服务和管理工作。（责任单位：市发展改革委、市财政局、市公安局、市农业局、市卫计委、市人力资源社会保障局、市教育局、市民政局、各区人民政府、育才生态区管委会）

3. 要将做好居住证持有人权益保障、服务和管理工作所需经费纳入预算管理。（责任单位：市财政局、各区人民政府）

（六）维护进城落户农民合法权益。

切实维护进城落户农民土地承包权、宅基地使用权、集体收益分配权，消除农民进城落户的后顾之忧，不得将权益退出作为进城落户条件。（责任单位：市农业局、市国土资源局、各区人民政府、育才生态区管委会）

三、有关要求

（一）高度重视，狠抓落实。建立健全支持农业转移人口市民化财政政策是党中央、国务院部署的重点改革任务。各相关部门、各区务必要高度重视，认真研究，尽快部署、狠抓落实。

（二）积极主动，创新机制。市政府直属各部门、各区政府要认真梳理现行的不符合常住人口基本公共服务均等化要求、不利于农业转移人口市民化的政策和管理方式，抓紧修改完善；要不断创新机制，积极探索进一步推动农业转移人口市民化政策措施，并鼓励先行先试。

（三）加强督导，落实责任。要建立支持农业转移人口市民化工作任务分工和落实机制，市政府督查室要在每季度末对相关部门、各区工作进展情况开展督导，确保支持农业转移人口市民化财政政策落实执行到位。

三亚市人民政府
