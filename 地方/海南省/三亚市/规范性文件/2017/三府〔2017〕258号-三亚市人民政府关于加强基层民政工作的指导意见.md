# 三亚市人民政府关于加强基层民政工作的指导意见

三亚市人民政府

关于加强基层民政工作的指导意见

各区人民政府，各管委会，市政府直属各单位：

为进一步加强基层民政工作力量，夯实基层民政工作基础，把党和政府爱民、利民、为民的执政理念落到实处，切实加强社会管理和维护社会稳定，经七届市政府第15次常务会议审议同意，现提出如下指导意见：

一、充分认识基层民政工作在社会建设中的重要意义

基层民政是民政工作的基础，也是社会主义和谐社会建设的保证。做好基层民政工作，对于把党和政府的爱民之心、亲民之义和为民之举落到实处，对于加强社会管理和维护社会稳定，惠及一方百姓具有十分重要的意义。

基层民政能力建设直接关系群众切身利益，关系民政工作全局，关系民政事业长远发展，是极其重要的强基固本工程。加强基层民政队伍建设，是新时期民政事业发展的客观需要，是民政职能不断深化和拓展的必然要求，也是做好基层各项民政工作的基础和保证。随着经济发展加快、社会转型加速和政府职能转变，民政服务对象从特定群体向城乡居民全覆盖，民政职能从专项社会行政事务管理向社会建设各领域拓展，民政功能从兜底保障向依法保障城乡居民社会权益提升，基层民政工作的领域越来越宽，服务内容越来越丰富，任务越来越繁重，社会对基层民政工作的关注度和期望值也越来越高。各区党委、政府，各相关部门要从维护人民群众根本利益、促进三亚社会经济平稳较快发展、维护社会和谐稳定的高度，充分认识做好基层民政工作的重要意义，进一步增强责任感、使命感，全力推进基层民政工作健康发展。

二、总体要求

（一）指导思想。全面贯彻党的十八届六中全会精神和习近平总书记系列重要讲话精神，践行“民政为民、民政爱民”工作理念，更好地发挥基层民政在保障民生、服务社会等方面的前沿阵地和基础平台作用，建立健全工作机制，使服务更加便捷、便民和高效，将头绪繁多的民政政策精准兑现给每个民政服务对象，把党和政府的关怀传送给困难群众。

（二）工作目标。加强基层民政队伍建设，解决好基层民政部门人员配备、经费保障、设施改善、交通工具等现实问题，努力实现基层民政有人办事、有钱办事、有条件办事，做到服务管理机制科学化、队伍专业化、内容标准化、程序规范化、手段信息化，全面提升民政综合服务管理能力和人民群众满意度。

三、工作任务

（一）加强基层民政工作力量。采取政府购买服务的方式，在每个村（居）委会、农场居配备民生联络员。具体为：1.民生联络员的配备数量。原则上，居民数量在3000名（含3000名）以下村（居）、农场居配备民生联络员1名，常住人口数量在3000人（不含3000人）以上的村（居）、农场居配备民生联络员2名。2.民生联络员的选配要求。按照择优录取的原则，要求大专以上文化，热心民政工作和社会公益事业，年龄40岁以下，熟悉本村情况，自然村村干部、本村返乡大学生优先，由各区政府、育才生态区管委会统一招聘。3.民生联络员的使用管理。实行“各区政府、育才生态区管委会聘用，区民政部门管理，村（居）、农场居使用”的管理机制，市民政局定期组织到各区对民生联络员进行业务培训，民生联络员在村（居）委会、农场居的领导下，专职本村民政工作。4.民生联络员的薪酬待遇。结合各区均有招聘政府雇员的实际情况和当地生活水平，建议每月工资待遇不低于其他专干，含“五险一金”，列入区财政预算。5.民生联络员的工作职责。主要职责包括：掌握本村（居）、农场居的低保户、五保户、孤儿、残疾人、优抚对象等享受各类民政救助家庭的基本情况，调查核实家庭收入、掌握各种民政对象信息，实行动态化管理；负责本村（居）、农场居灾情核实和上报；负责本村（居）、农场居残疾人两项补贴、孤儿生活补贴、优抚、殡葬管理、困境未成年人、留守儿童等民政工作。6.建立民生联络员考核制度。为便于管理，提高民生联络员工作积极性，各区政府、育才生态区管委会结合实际，由区民政和民族宗教事务局、育才生态区管委会社会事务局组织对民生联络员进行年度考核。对年度考核不合格的民生联络员，原则上不再续聘。

（二）改善基层民政工作条件。各区政府、育才生态区管委会要为区民政部门安排不少于60平方米的办公用房，区级民政部门的设施配备要达到“九有”标准，即：有电话、有电脑、有打印机、有复印机、有传真机、有办公桌椅、有高拍仪、有影录设备、有档案柜，切实改善基层民政工作条件，提升各区民政管理服务效能。

（三）健全基层服务设施。落实《海南省机构编制委员会办公室关于调整乡镇事业单位机构编制有关问题的通知》（琼编办〔2013〕76号）精神，结合三亚“两级政府、三级管理”的行政管理体系，重点推进村（居）综合服务设施建设，不断完善每个村（居）委会设立的便民服务中心或便民服务站。便民服务中心要以居民需求为导向，推动基本公共服务项目全覆盖，确保涉及民生的各项兜底保障的民政政策进驻每一个便民服务中心。便民服务中心实行“前台一口受理，后台分工协同”。要做到有专人、有牌子、有场所、有制度、有台帐。健全完善便民服务中心的民政工作职责、规章制度及业务工作流程图，将与群众密切相关的民政业务的办理依据、条件、程序、时限、需要提交材料的目录、申请表式样、是否收费、服务承诺等信息在办事场所进行公开，便于群众了解服务内容和流程。各类民政服务对象的档案要做到详实可靠、资料齐全、手续完备、归档合理，切实提高基层民政工作规范化管理程度。在村委会所在自然村或中心村，根据村庄的实际，设立老人日间照料中心（互助老人幸福院）。

（四）落实基层民政工作经费保障。各区要保证基层民政部门开展工作必需的运行经费，按照3万人口以下的区每年不低于15万元，3―5万人口的区不低于20万元，5万人口以上区的不低于25万元的标准，列入区级财政预算，并建立增长机制，保证基层民政工作正常有序开展。市民政部门可采取财政专项资金安排、福利彩票公益金支持等途径，明确政府购买服务经费来源，解决服务能力和自身经费不足的问题。

（五）丰富基层服务设施的服务内容。鼓励便民服务中心或便民服务站开展服务事项全程委托办理，最大限度为居民办事提供方便。率先做好社会救助、优抚安置、养老助残等民政服务和社会服务工作，建立健全“三留守”人员关爱服务机制，重点满足老年人、未成年人、残疾人、困难群体的服务需求。区民政部门要指导村委会制定符合本村实际的村规民约，完善村民自治体系。发扬农村邻里相亲、守望相助的传统美德，引导居民开展志愿互助服务，不断壮大志愿者队伍。建立党组织关爱服务、基本公共服务、志愿互助服务、市场化服务衔接互补、覆盖全体居民的服务体系，逐步提高基层民政服务水平和效能。

（六）建立民政基础数据信息平台。加强各区政府、育才生态区管委会的民政信息化建设，建立民生基础信息数据库，进行统一权限管理和资源管理，实现民政同人社、财政、住建、规划、公安、工商、质监、国税、地税、金融、公积金等有关部门连线，通过互联网，连接基层民生服务平台，覆盖所有村（居）。同时，以民政信息资源整合为目标，全面实现民政业务信息的整合，打破条块壁垒，打造民政管理平台，提高信息报送的质量和效率。

（七）提升基层民政工作人员能力素质。健全培训制度，市民政部门要加强对区、村级民政工作人员的培训，采取走出去请进来、相互观摩检查、以会代训等方式，定期对区、村两级民政工作人员进行轮训，每人每年培训时间不少于5天，培训内容包括岗前培训、业务培训、法治培训、警示教育等，提高基层民政干部的道德素养、业务水平和服务水平。建立对基层民政工作人员的年度考核制度，对成绩突出的予以表彰和奖励，对确实不能胜任工作的，要及时给予调整。

四、工作要求

（一）加强组织领导。基层民政工作的成效，直接带动民政工作机制体制创新，促进民政事业发展大局和社会和谐稳定。各区党委、政府要高度重视，充分发挥区领导牵头的困难群众基本生活保障工作协调机制作用；各区政府、育才生态区管委会相应建立由区委书记或区长牵头，分管民政工作的领导及相关部门负责人参与的体制机制；村一级可以建立由村党组织书记牵头，村“两委”有关成员参与的工作机制，形成区、村两级联动，各方面齐抓共管民政工作的局面。

（二）明确责任分工。民政部门要加强对此项工作的协调、调度和业务指导，并主动与上级有关部门联系协调，争取多方支持；财政部门要保障民政工作经费的落实；各相关部门要积极配合，认真履行相关职能，形成工作合力，切实做到责任到位、政策落实到位、措施保障到位，确保全面完成基层民政工作建设各项任务。

（三）严格督导考核。各区党委、政府要把加强基层民政工作纳入责任目标考核范围，采取跟踪督办、实地督查、重点抽查、督促整改等方式严格督导。市政府把加强基层民政工作能力建设的落实情况作为各区政府民政工作考核的重要内容。对落实有力、成效显著的区进行表扬鼓励，对落实不力的区，有针对性的给予指导、帮助和批评。

三亚市人民政府
