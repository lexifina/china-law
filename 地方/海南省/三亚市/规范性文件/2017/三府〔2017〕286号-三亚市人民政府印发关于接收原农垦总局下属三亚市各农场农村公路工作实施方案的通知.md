# 三亚市人民政府印发关于接收原农垦总局下属三亚市各农场农村公路工作实施方案的通知

三亚市人民政府

印发关于接收原农垦总局下属三亚市各农场

农村公路工作实施方案的通知

各区人民政府，市各有关单位：

《关于接收原农垦总局下属三亚市各农场农村公路工作实施方案》已经市政府同意，现印发给你们，请认真组织实施。

三亚市人民政府

2017年10月20日

（此件主动公开）

关于接收原农垦总局下属三亚市各农场农村公路工作实施方案

为贯彻落实《中共海南省委、海南省人民政府关于推进新一轮海南农垦改革发展的实施意见》（琼发〔2015〕12号）精神，切实做好农场农村公路养护管理工作，实现垦地交通运输服务均等化发展。根据《海南省交通运输厅关于印发推进新一轮海南农垦农村公路改革实施方案的通知》要求，结合我市实际，特制定本实施方案。

一、总体要求

（一）指导思想

全面贯彻落实党的十八大和十八届三中、四中、五中、六中全会精神，贯彻落实市委、市政府关于深化农垦管理体制改革的指导意见，坚持创新、协调、绿色、开发、共享五大发展理念，围绕全面建成小康社会的总体目标，按照我市农垦管理体制改革发展的总体要求，立足实际，统筹区域、城乡交通协调大发展，大力提升农垦交通服务均等化水平，积极稳妥推进农垦农村公路管理体制改革，为改善民生和加强社会建设提供有力支撑。

（二）基本原则

1．依法管理。根据《公路安全管理条例》《海南省公路条例》等相关法律法规，推进农场农村公路养护管理。

2．责权一政。明确农场农村公路相关主体的责权，做到责权对等，责任落实。

3．科学高效。积极开展建立高效管理模式，做到有路必养，保障人民群众的出行需求和出行安全。

4．统筹发展。着力提升农场交通服务水平，统筹农场交通发展。

（三）工作目标

通过属地化管理，使南滨农场、立才农场、南田农场、南新农场农村公路在规划、建设、管理、养护等方面与三亚市地方融为一体，为农场公共服务均等化提供交通运输保障并实现以下目标：

1．交通基础设施网络更加完善。通过多渠道加大农场交通基础设施的投入，建成能力充分、结构合理、衔接顺畅的交通基础设施网络，为支撑农场经济社会持续健康发展提供基础保障。

2．交通运输服务质量有效提高。切实改善农场生产生活条件，提升人民群众出行的便捷性、舒适性和可靠性，不断提高运输组织效率，持续提升运输服务质量。

3．交通运输基本公共服务均等化水平有效提升。完善农场农村公路建、管、养体制机制，实现农场全面建成小康社会交通运输发展目标，大力提升交通运输基本公共服务均等化水平。

二、工作内容

（一）南田农场、南新农场、立才农场、南滨农场农村公路由三亚市人民政府管理，市交通运输主管部门做好对接工作，4个农场移交的农村公路共有408.874公里（具体线路明细详见附表）：有路线编码的路面宽度为3.5米的水泥路面共104条161.993公里；无路线编码的水泥路面宽度为3.5米的共75条101.727公里，路面宽度为2.5米的共有36条33.17公里；无编码的土路面共85条106.92公里；桥梁87座。

（二）农村公路养护管理相关资料移交。农村公路养护管理现有的各类相关资料，包括养护工程资料、路况资料、各类档案等，全部移交市交通运输管理主管部门。

（三）农村公路资金核定。目前，我市农村公路养护资金包括市财政配套和省交通运输厅拨付（省厅直接划拨给市财政），移交后，农村公路养护资金由市交通运输主管部门按实际管养线路里程，根据相关标准和规定编制经费预算。农村公路建设资金纳入市财政年度预算。同时，应争取省交通运输主管部门按相关规定给予资金支持。

（四）农村公路管养方式。我市农村公路养护自采取市场化管理模式以来取得较大成效，有效保证了农村公路养护质量和线路覆盖率，移交后目前仍按原养护模式进行管养。

（五）此次下放移交工作，只移交农村公路的养护管理权限，不涉及人员移交等问题。

（六）固定资产和设备移交。农场农村公路（含土地、房产、设备、设施等），按相关手续移交市交通运输主管部门管理。

（七）农场的乡道、村道规划按照属地管理纳入同级规划，由市交通运输主管部门按《公路安全管理条例》和《海南省公路条例》相关规定编制，符合条件的农场农村公路建设项目纳入市“十三五”农村公路建设规划。

三、保障措施

（一）提高认识，加强领导

农场农村公路改革是市深化农垦管理体制改革的重要组成部分，市交通运输主管部门与省农垦投资控股集团有限公司要积极做好本次改革的协调和保障工作，按照农垦优先的原则，统筹安排好农场农村公路的建设和养护计划，结合交通扶贫攻坚工作，逐步提高农场交通服务质量和水平，实现农场交通运输基本公共服务均等化。建立长效管理机制，落实建设、养护主体，落实建设、管理、养护责任，保障农场农村公路的正常使用，行车安全和长远发展。

（二）稳妥推进，狠抓落实

农场农村公路的移交涉及范围广、里程长，市交通运输主管部门与农场要加强沟通协调，确保在市深化农垦管理体制改革中农场农村公路事权的无缝衔接，确保农场均纳入属地化管理范畴。

（三）多渠道争取建设资金，确保落实到位

结合我市正在开展的海南省农村公路六大工程工作，将农场农村公路按类别纳入本市六大工程项目库，加强与省级交通、财政部门规划的衔接，积极争取各项补助资金支持，多方筹集项目建设资金。同时坚持政府投入在农场农村公路建设中的主体和主导作用，认真落实“四好农村路”建设的新要求，鼓励社会资本进入农场公路建设领域。充分发挥区政府、村委会和村民参与作用，营造“建路、爱路、护路”的良好环境。
