# 三亚市人民政府关于征收海棠湾林旺片区F-02-1等地块集体用地的通告

三亚市人民政府

关于征收海棠湾林旺片区F-02-1等地块

集体用地的通告

经海南省人民政府同意，海南省国土资源厅（原海南省国土环境资源厅）以琼土环资审字〔2011〕151号文批准同意征收海棠区三灶村委会旧村一、二组集体所有土地34.1178公顷。根据《中华人民共和国土地管理法》第46条、《中华人民共和国土地管理法实施条例》第25条和《海南经济特区土地管理条例》的有关规定，及《海南省国土环境资源厅关于进一步做好市县征地信息公开工作有关问题的通知》（琼土环资耕字〔2014〕14号），现将经批准的《征收土地方案》内容和有关事项通告如下：

一、被征收土地规划性质：

F-02-1地块用地规划性质为公园用地、F-02-2地块用地规划性质为一类居住用地、F-02-3地块用地规划性质为绿地、F-02-4 地块用地规划性质为一类居住用地、F-04-1地块用地规划性质为一类居住用地、F-04-2地块用地规划性质为街头绿地用地、F-04-4地块用地规划性质为一类居住用地、F-04-5地块用地规划性质为公园绿地。

二、被征收土地四至范围：

被征收土地位于F-02-1地块、F-02-2地块、F-02-3地块、F-02-4地块、F-04-1地块、F-04-2地块、F-04-4地块、F-04-5地块用地范围内（具体以勘测定界图为准）。

三、被征收土地权属单位及面积：

海棠区三灶村委会旧村一、二组集体土地，面积34.1178公顷。

四、征收补偿标准：

按照《海南省国土环境资源厅关于三亚市海棠湾控规林旺片区F-02-1等地块农用地转用和土地征收手续的批复》（琼土环资审字〔2011〕151号）批准的补偿标准对海棠区三灶村委会旧村一、二组集体土地进行补偿。

五、农业人员安置：

（一）根据三亚市人民政府有关征地补偿标准规定，一次性拨付土地安置补助费。

（二）被征地农民社会养老保险和就业保障，按《三亚市被征地农民基本养老保险暂行办法》有关规定办理。

六、被征收土地四至范围内的土地所有权人、使用权人在通告规定期限内，持土地权属证书或其他有关证明材料，到指定的地点办理征地补偿登记。

凡从海棠区政府现场调查之日起，抢栽、抢种青苗和抢建地上附着物的不予办理补偿登记。
