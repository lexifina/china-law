# 三亚市人民政府关于征收新建海南西环铁路三亚段102.3732公顷集体土地的通告

三亚市人民政府

关于征收新建海南西环铁路三亚段102.3732公顷

集体土地的通告

经国土资源部批准同意，海南省国土资源厅（原海南省国土环境资源厅）以“琼土环资函〔2014〕201号”和“琼土环资函〔2014〕376号”文批准同意征收西环高铁凤凰机场至三亚火车站段20.2685公顷集体土地和西环高铁凤凰机场至梅山段 82.1047公顷集体土地。其中西环高铁凤凰机场至三亚火车站段涉及天涯区水蛟村委会、梅村村委会、桶井村委会、妙林村委会、槟榔村委会集体土地；西环高铁凤凰机场至梅山段涉及天涯区水蛟村委会、梅村村委会、桶井村委会、布甫村委会、过岭村委会、文门村委会、崖州区保平村委会、抱古村委会、城东村委会、城西村委会、凤岭村委会、港门村委会、拱北村委会、临高村委会、梅东村委会、梅西村委会、乾隆村委会、崖城村委会、盐灶村委会、长山村委会、镇海村委会集体土地。根据《中华人民共和国土地管理法》第46条、《中华人民共和国土地管理法实施条例》第25条和《海南经济特区土地管理条例》的有关规定，以及《海南省国土环境资源厅关于进一步做好市县征地信息公开工作有关问题的通知》（琼土环资耕字〔2014〕14号），现将经批准的《征收土地方案》内容和有关事项通告如下：

一、被征收土地规划性质：

西环铁路工程建设用地。

二、被征收土地四至范围：

位于天涯区和崖州区辖区范围内（具体以勘测定界图为准）。

三、被征收土地权属单位及面积：

西环铁路凤凰机场至三亚火车站段涉及天涯区妙林村委会、槟榔村委会、水蛟村委会、梅村村委会、桶井村委会集体土地，面积20.2685公顷。

西环高铁凤凰机场至梅山段涉及天涯区水蛟村委会、梅村村委会、桶井村委会、布甫村委会、过岭村委会、文门村委会，崖州区保平村委会、抱古村委会、城东村委会、城西村委会、凤岭村委会、港门村委会、拱北村委会、临高村委会、梅东村委会、梅西村委会、乾隆村委会、崖城村委会、盐灶村委会、长山村委会、镇海村委会集体用地，面积82.1047公顷。

（三）地上附着物补偿标准和青苗补偿标准：

按《海南省人民政府关于印发海南省征地统一年产值标准和海南省征地青苗及地上附着物补偿标准的通知》（琼府〔2014〕36号）及《三亚市人民政府关于印发〈三亚市集体土地征收补偿安置管理规定（2013修订）〉的通知》（三府〔2013〕43号）规定的补偿标准执行。

五、农业人员安置：

（一）根据三亚市人民政府有关征地补偿标准规定，一次性拨付土地安置补助费。

（二）被征地农民社会养老保险和就业保障，按《海南省人民政府关于印发被征地农民参加社会养老保险办法的通知》（琼府〔2013〕21号）及《海南省人民政府办公厅关于印发海南省征地安置预留用地管理办法的通知》（琼府办〔2012〕97号）有关规定办理。

六、被征收土地四至范围内的土地所有权人、使用权人在通告规定期限内，持土地权属证书或其他有关证明材料，到指定的地点办理征地补偿登记。

凡从天涯区政府、崖州区政府现场调查之日起，抢栽、抢种青苗和抢建地上附着物的不予办理补偿登记。
