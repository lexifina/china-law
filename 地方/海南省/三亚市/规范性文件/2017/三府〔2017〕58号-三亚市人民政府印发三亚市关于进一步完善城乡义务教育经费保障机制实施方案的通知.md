# 三亚市人民政府印发三亚市关于进一步完善城乡义务教育经费保障机制实施方案的通知

三亚市人民政府

印发三亚市关于进一步完善城乡

义务教育经费保障机制实施方案的通知

各区人民政府，各管委会，市各有关单位：

《三亚市关于进一步完善城乡义务教育经费保障机制实施方案》已经七届市政府第5次常务会议审议通过，现印发给你们，请认真组织实施。

三亚市人民政府

2017年3月4日

（此件主动公开）

三亚市关于进一步

完善城乡义务教育经费保障机制实施方案

为贯彻落实《海南省人民政府关于印发海南省进一步完善城乡义务教育经费保障机制实施方案的通知》（琼府〔2016〕55号）精神，进一步调整完善城乡义务教育经费保障机制，建立城乡统一的城乡义务教育经费保障机制，推进城乡义务教育均衡发展，结合我市实际特制定本方案。

一、目标要求

为适应新型城镇化建设和户籍制度改革的新形势，按照深化财税体制改革、教育领域综合改革新要求，统筹设计城乡一体化的义务教育经费保障机制，增强政策的统一性、协调性、前瞻性。继续加大义务教育经费投入，统筹城乡义务教育资源均衡配置，建立城乡统一、重在农村的义务教育经费保障机制，促进城乡义务教育均衡发展。大力推进教育管理信息化，创新义务教育转移支付与学生流动相适应的管理机制，实现相关教育经费可携带，增强学生就读学校的可选择性。

二、主要内容

（一）全面实施城乡义务教育“两免一补”政策。对城乡义务教育学生免除学杂费、免费提供教科书（含学生字典、教辅书、作业本、英语语音教辅设备等，下同），对公办农村义务教育阶段寄宿制学校的寄宿生（含少数民族寄宿班学生，下同）给予补助生活费；公办城市义务教育阶段寄宿制学校和民办义务教育阶段寄宿制学校的寄宿生，只对家庭经济困难学生补助生活费。家庭经济困难寄宿生生活费补助人数由市教育局和区教科局以及市、区财政局根据寄宿生数、寄宿生贫困面、省下达指标数等因素进行分类核定。民办学校学生免除学杂费标准按照市确定的民办义务教育阶段学校生均公用经费标准执行。

（二）全面实施城乡义务教育学校生均公用经费制度。对城乡义务教育学校（含民办学校）按照不低于省规定基准定额的标准补助公用经费，并适当提高寄宿制学校、规模较小学校补助水平。

（三）巩固完善城乡义务教育学校校舍安全保障长效机制。支持城乡公办义务教育学校维修改造、抗震加固、改扩建校舍及其附属设施。

（四）巩固落实城乡义务教育教师工资政策。积极落实教师工资政策，确保我市义务教育教师工资按时足额发放，在分配绩效工资时，要加大对艰苦边远贫困地区和薄弱学校的倾斜力度。

（五）完善公办农村义务教育阶段寄宿制学校（含少数民族寄宿班，下同）聘请厨工经费补助及给寄宿生免费提供床上用品制度。

统一城乡义务教育经费保障机制，实现“两免一补”和生均公用经费资金随学生流动可携带。同时，继续实施全面改善贫困地区义务教育薄弱学校基本办学条件、解决城镇普通中小学大班额问题等重点工程，着力解决城乡义务教育发展中存在的突出问题。

三、分担办法

（一）免费提供教科书、对寄宿生补助生活费、生均公用经费政策所需资金，除中央、省财政负担资金外，剩余资金按市对区财政管理体制规定负担。

（二）农村公办义务教育学校校舍安全保障机制所需资金由中央和省财政按比例共同分担。城市公办义务教育学校校舍安全保障机制、农村公办义务教育阶段学校聘请厨工及免费提供床上用品所需资金，按市对区财政管理体制规定负担。

四、实施步骤

（一）自2016年春季学期起，公办学校按不低于省规定的义务教育学校生均公用经费基准定额补助公用经费，民办学校按省规定的义务教育学校生均公用经费基准定额补助公用经费。2016年我市生均公用经费标准为：公办普通小学每生每年1100元、公办普通初中每生每年1500元；民办普通小学每生每年650元、民办普通初中每生每年850元。在此基础上，对公、民寄宿制学校分别按照寄宿生生均300元和200元标准增加公用经费补助，对农村不足100人的规模较小学校按100人核定公用经费，对特殊教育学校和随班就读残疾学生按每生每年6000元标准补助公用经费。

自2016年起，民办学校按照我市确定的生均公用经费标准免除学生的学杂费，收取住宿费的民办学校，按照财政对寄宿制学校补助公用经费的增加部分，相应减免寄宿生住宿费。同时，取消我市对民办学校的学位补贴政策。

（二）自2017年春季学期起，全面实施城乡义务教育学生“两免一补”政策。继续落实城乡公办义务教育学生“两免一补”政策，继续向民办学校学生免费提供教科书，同时，推行部分教科书循环使用制度；对民办学校家庭经济困难寄宿生给予生活费补助；按照小学年生均20元、初中年生均30元标准免费提供作业本。

自2017年起，按市对区财政管理体制规定的资金分担机制，落实免费提供教科书、寄宿生补助生活费、城乡公办义务教育学校校舍安全保障长效机制、聘请厨工、购置床上用品等所需资金。

（三）以后年度，根据省有关规定以及义务教育发展过程中出现的新情况和新问题，适时完善城乡义务教育经费保障机制相关政策措施，并对相关补助标准进行动态调整。

五、组织保障

（一）加强组织领导，落实工作责任。各区政府、各有关部门要高度重视进一步完善城乡义务教育经费保障机制工作，加强领导，落实责任。严格落实义务教育经费“以县为主”的管理体制及主体责任，合理确定各项补助标准以及家庭经济困难寄宿生贫困面。全市各级教育、财政等有关部门要密切配合，充分发挥职能作用，建立健全城乡义务教育经费保障机制管理制度。

（二）优化教育布局，深化教育改革。各区政府要结合人口流动的规律、趋势和城市发展规划，及时调整完善教育布局，将民办学校纳入本地区教育布局规划，科学合理布局义务教育学校。加快探索建立乡村小规模学校办学机制和管理办法，建设并办好寄宿制学校，慎重稳妥撤并乡村学校，努力消除城镇学校“大班额”，保障当地适龄儿童就近入学。加强义务教育民办学校管理。深化教师人事制度改革，健全城乡教师和校长交流机制，健全义务教育治理体系，加强留守儿童教育关爱。

（三）确保资金落实，强化绩效管理。市财政下达经费后，各区财政、教育部门要及时足额拨付到位。各区政府要加强教育经费的统筹安排，保障规模较小学校正常运转；加强义务教育学校预算管理，细化预算编制，硬化预算执行，强化预算监督。规范义务教育学校财务管理，创新管理理念，将绩效预算贯穿经费使用管理全过程，切实提高经费使用效益。

（四）推进信息公开，强化监督检查。各区政府要加大信息公开力度，将义务教育经费投入情况向同级人民代表大会报告，并向社会公布，接受社会监督。市和区财政、教育、价格、审计、监察等有关部门要齐抓共管，加强对义务教育经费保障机制资金使用管理、学校收费等情况的监督检查；教育部门要加强义务教育基础信息管理工作，确保学生学籍信息、学校基本情况、教师信息等数据真实准确。

（五）加大宣传力度，营造良好氛围。各区和市直有关部门要高度重视统一城乡义务教育经费保障机制的宣传工作，广泛利用各种宣传媒介，采取多种方式，向社会进行深入宣传，使党和政府的惠民政策家喻户晓、深入人心，确保统一城乡义务教育经费保障机制各项工作落实到位。

本方案自2016年春季学期开始实施，凡以往规定与本方案规定不一致的，按本方案规定执行。《三亚市人民政府办公室关于印发三亚市农村义务教育经费保障机制改革实施方案的通知》（三府办〔2007〕150号）同时废止。
