# 三亚市人民政府关于做好高火险期森林防火工作的通告

三亚市人民政府

关于做好高火险期森林防火工作的通告

为加强野外火源管控，有效防止森林火情火灾发生，确保人民群众生命财产及森林资源安全，根据《中华人民共和国森林法》、《海南省森林防火条例》等法律法规等规定，现就全市高火险期的森林防火工作有关事项通告如下：

一、根据《海南省森林防火条例》等规定，每年的3月1日至5月31日为全省森林高火险期。

二、各级人民政府、各森林防火责任单位要认真执行森林防火责任制，全面落实野外火源管理措施，开展违规用火专项治理，及时消除火灾隐患；要充分发挥宣传媒体作用，广泛开展依法治火宣传教育，普及森林防火安全知识。

三、森林高火险期，在森林防火区禁止下列行为：携带火源火种、易燃易爆物品；吸烟、野炊、烧荒、烧秸秆；焚烧垃圾、焚香烧纸；燃放烟花爆竹和孔明灯、使用明火照明；一切农事生产用火。清明节期间，要引导群众用敬献鲜花或网络祭扫代替焚香烧纸、燃放爆竹等方式文明祭祀。

四、各森林防火责任单位要严格执行24小时领导带班、工作人员值班、工作日报、有火必报，确保信息畅通和火情规范有序处置。一旦发生森林火情（灾），迅速出动，科学指挥，安全扑救，确保森林火情火灾在第一时间得到有效处置。扑救森林火情（灾）不得动员老弱病残人员、中小学生、妇女参加扑救，避免扑火人员伤亡事故。

五、任何单位和个人要自觉遵守林区野外用火管理规定，学校和家庭要加强对学生及不具备完全民事行为能力人员的教育和监管，严防因玩火失火引发森林火灾。发现森林火情应立即向当地森林防火部门报告。对违反用火规定的，林业主管部门和森林公安机关将依法进行处罚。森林火警报警电话：119，88689110。

六、本通告自发布之日起施行。
