# 三亚市人民政府关于印发三亚市2017年投资项目“绿色审批通道”实施意见的通知

三亚市人民政府

关于印发三亚市2017年

投资项目“绿色审批通道”实施意见的通知

各区人民政府，各管委会，市政府直属各单位：

《三亚市2017年投资项目“绿色审批通道”实施意见》已经七届市政府第7次常务会议审议通过，现印发给你们，请认真组织实施。

三亚市人民政府

2017年3月30日

（此件主动公开）

三亚市2017年投资项目“绿色审批通道”实施意见

为提高项目审批效率、加快项目前期工作，全力促进我市2017年固定资产投资项目加快推进实施，特制定三亚市2017年投资项目“绿色审批通道”实施意见，具体如下：

一、基本原则

（一）从简从快原则。在国家政策许可范围内，按照特事特办、委托代办、跟踪督办、陪同协办等服务方式，简化手续，从快办理，随到随批。

（二）限时办结原则。受理窗口应实行承诺限时服务。

（三）并联审批原则。受理窗口全过程实行并联审批办法，将串联审批改为并联审批。

（四）超时默许原则。对项目手续齐全有效的审批申请，在承诺时限内没有做出合理解释和书面说明，视为部门默认许可审批事项。

（五）一次性告知原则。受理窗口对审批所涉及的申报材料、审批部门、审批程序、办理时限和收费标准等事项，应一次性告知申报人。

二、适用范围

本绿色审批通道适用于三亚市2017年度省、市重点建设项目，“双修”项目，棚户区改造项目，中央预算内投资、专项建设基金、地方政府新增债券资金等上级资金项目，2017年政府基本建设投资计划明确的其它政府投资项目，以及经市委、市政府决定列入的其它项目。

三、简化审批程序

为确保我市投资项目各项审批审查手续完善齐备，各环节相互衔接，按以下简化程序开展工作：

（一）项目前期审批时限一律不超过2个工作日。

（二）项目业主依照项目基本建设程序，在施工招标前向各审批审查单位进行申报，职能部门不能当时批复的，先出具初审意见，但项目业主应在开工前补办完毕。

（三）市规划委员会会议每月召开一次。项目须经市规划委员会审议的，由市规划局协调、统筹，项目业主配合，抓紧开展相关工作。

（四）社会投资项目在取得土地后，立即开展相关规划设计。通过市规划委员会会议审议的社会投资项目可采取“业主承诺、审批后置”的容缺受理方式，办理项目前期相关手续。

（五）政府投资项目简化审批程序。

1．项目可研、初步设计及概算的评估评审时间和用地预审时间一律不超过10个工作日（含出具评估评审报告），若需召开专家会的，项目业主须派项目分管领导参加，涉及事项当场决定。

2．项目可研审批不再以规划、用地、环评、水保、地震等文件作为前置条件，但项目业主须承诺在项目开工前补办完成；

3．项目立项后可立即启动勘察、设计招标；

4．项目初步设计及概算编制可在可研阶段同步启动。

5．项目施工招标、施工图评审、预算评审可同步开展。

（六）项目业主提前准备施工招标相关材料，初步设计及概算批复后即开展备案工作，但施工图、工程量清单应在施工招标公告期内完成并上传至招投标平台。

项目招标资料基本齐全后，窗口先受理，先办后补;对于招标文件和资料存在问题，一次性告知招标人或招标代理机构，并限时修改和补充相关招投标资料。如招标人或招标代理机构报送的文件，没有明显违法违规问题，先审批，在招投标网上再进行修改。

（七）简化施工许可证审批程序。

1．进入“绿色通道”项目，提前受理，简化审批材料，尽快出具《建设工程施工许可审批表》及一次性告知需补充材料，相关费用的缴纳、办理质量安全报监督等不再作为前置条件，施工图审期限为7个工作日。

2．项目应遵循优先办理、特事特办、主动服务和设1专人负责的原则。各政务审批服务窗口在受理“绿色通道”项目后，应快速启动，对可以立即答复或办理的事项应当场答复、办理。

3．项目只要确保有临时规划许可或审批意见、参建单位中标通知书，其他条件和材料有所欠缺，可先予受理，边办、边补、边改。但在颁发施工许可证前应补齐、改好，达到规定要求。

4．对申请人提供的申报材料，只要符合法定内容、形式，且不需要现场勘验即可下达批文、发给证照的事项，实行“一审一核”或“告知承诺制”，作为即办件办理。对该类事项各部门对审批人员要充分授权，并明确审批责任。

5．项目受理后应主动指导、帮助申请人准备审批资料，书面告知审批过程中的有关情况、问题，办结后应尽快主动通告申请人。

四、工作要求

（一）前期征地拆迁工作要提前准备，项目征地工作资金可根据项目实际及业主要求提前下达。被征用土地所在地的区政府征地主管部门按下达征地调查通知材料清单要求向市土地行政主管部门提交规划红线图、权属示意图等相关材料及征地申请书，市土地行政主管部门应在3个工作日内审核并代市政府拟写征地调查通知。

（二）项目所涉及的业务咨询机构，自收到业务指令或中标通知书发出后，立即开展编制工作，项目业主与编制单位以最短时间约定编制工作期限；除地质勘察外，完善施工图设计等其他事项时间不超过5个日历天。对此，项目业主应在委托合同中予以明确时限和处罚措施。

（三）对项目推进工作中存在延缓、迟误、超时甚至拒不配合行为的单位或个人，将予以通报并追究责任。

（四）涉及审批事项的各行业主管部门要根据本实施意见梳理调整本部门的审批服务流程和事项。

（五）涉及审批手续补办工作的项目，由市政务服务部门负责督促项目业主及时补办相应手续，存在应办而未办审批手续的项目不得擅自开工建设。

（六）各项目单位（部门）应加强项目策划和前期工作，提前做好立项的前期工作，防止项目仓促立项，确保相关工作的顺利、高效推进。

（七）本实施意见适用范围内的项目若涉及调整，则调整后增加的项目也纳入“绿色审批通道”，调整出范围的项目不再按本实施意见执行。

（八）依托“12345”热线开通“三亚市项目‘绿色审批通道’服务专线”为项目提供咨询、投诉服务，市政务中心对项目审批进行全程跟踪督办，并对项目审批情况进行定期通报，督促各相关部门按时限完成审批。

（九）本意见自印发之日起实施，有效期为一年。
