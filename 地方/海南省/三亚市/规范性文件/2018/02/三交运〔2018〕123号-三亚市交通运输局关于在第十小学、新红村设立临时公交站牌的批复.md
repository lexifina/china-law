# 三亚市交通运输局关于在第十小学、新红村设立临时公交站牌的批复

三亚市公共交通集团有限公司：

来文《关于在第十小学、新红村设立临时公交站牌的请示》（三公交集〔2018〕14号）收悉。经研究，现批复如下：

为方便市民游客在新红路路段的第十中学、新红村乘坐公交车，同意由你公司在第十小学、新红村公交站点设立临时公交站牌，并于2018年3月1日前完成对临时公交站牌线路信息的刷新工作。

三亚市交通运输局

2018年2月22日
