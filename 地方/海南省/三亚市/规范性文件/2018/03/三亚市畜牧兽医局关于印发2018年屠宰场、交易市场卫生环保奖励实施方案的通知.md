# 三亚市畜牧兽医局关于印发2018年屠宰场、交易市场卫生环保奖励实施方案的通知

关于印发2018年屠宰场、交易市场卫生环保奖励

实施方案的通知

各畜禽屠宰场、交易市场，各有关单位：

为有效落实市委市政府创文巩卫和创建健康城市健康村建设要求，切实优化畜禽屠宰场、交易市场卫生环境，现将《2018年屠宰场、交易市场卫生环保奖励实施方案》印发给你们，请认真实施。

三亚市畜牧兽医局

2018年3月13日

（此件主动公开）

2018年屠宰场、交易市场卫生环保奖励实施方案

为有效落实市委市政府创文巩卫和创建健康城市健康村建设要求，切实优化畜禽屠宰场、交易市场卫生环境，根据《关于印发〈2018年三亚市爱国卫生工作要点〉的通知》（三爱卫〔2018〕6号）、《关于印发三亚市病媒生物防制效果评估工作方案的通知》（三爱卫〔2018〕15号）等文件精神，结合三亚实际，制定本实施方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，认真贯彻落实《“健康中国2030”规划纲要》《健康海南2030规划纲要》《中共海南省委关于进一步加强生态文明建设谱写美丽中国海南篇章的决定》（琼发〔2017〕25号）精神，以环境治理为重点，加强病媒生物综合防制，有效保障“菜篮子”肉品供应和畜产品质量安全。

二、总体目标

根据《2018年三亚市爱国卫生工作要点》，做好畜禽屠宰场、交易市场排污设施维护和病媒生物防制，保证污水处理设备设施正常运转，污水达标排放或循环利用，病死畜禽及废弃物及时无害化处理，防止病媒生物孽生，确保通过市爱卫办考核。

三、项目资金

2018年市本级财政预算安排屠宰场、交易市场卫生环保奖励资金100万元，主要用于扶持畜禽屠宰场、交易市场按照《三亚市2018年病媒生物防制技术工作方案》要求做好病媒生物防制、环境卫生治理、无害化处理和健康教育宣传等工作。

四、补贴对象

三亚市辖区内具有工商部门颁发的营业执照且正常经营的畜禽屠宰场、交易市场。

五、实施期限

2018年3月—12月。

六、资金安排

各单位根据实际情况做出本年度爱国卫生工作实施方案或计划，详细列出环境卫生治理、无害化处理、病媒生物防制、污染源治理设备设施建设及维护、爱国卫生宣传等各项支出资金预算报市畜牧兽医局审核，经会议讨论确定上半年安排各单位环保奖励资金数额。对工作落实到位、卫生环境良好的单位继续给予支持；工作落实不力、不按要求整改的单位将给予严厉批评，同时不予再安排奖励资金。所有资金安排情况进行公开公示，增加资金使用透明度。

七、工作要求

（一）加强组织领导。市畜牧兽医局具体负责资金拨付的日常工作，抽调市动卫所、疫控中心相关人员成立专项工作组，加强对爱国卫生工作的指导、检查和监督。

（二）加强监督检查。市畜牧局将采取不打招呼、不定时间、不定路线的方式对各单位爱国卫生工作方案执行情况进行检查评估，对发现的问题及时拍照取证并通知企业负责人按要求立即整改。

（三）加大宣传力度。各企业要加大政策宣传力度，充分利用微信工作群、场内宣传栏等方式，积极宣传我市创文巩卫工作部署、健康教育或病媒生物防制等相关知识，提高本行业从业人员的主动参与意识。

（四）加强资金管理。企业要根据各自制定的实施方案和资金预算表，落实项目资金台账登记制度，所有资金支出必须留存有效凭证存档备查。市畜牧兽医局要加强资金监管，确保按要求使用。
