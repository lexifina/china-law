# 三亚市畜牧兽医局关于拨付2018年畜禽屠宰场、交易市场卫生环保奖励资金（第一批）的通知

关于拨付2018年畜禽屠宰场、交易

市场卫生环保奖励资金（第一批）的通知

三亚益民肉联实业有限公司等有关单位：

根据《中华人民共和国环境保护法》、《生猪屠宰管理条例》、《国家卫生城市标准（2014版）》等有关法律法规，为巩固我市国家卫生城市建设成果，提高畜禽屠宰场、交易市场卫生环保水平，保障本行业健康稳定发展，有效保护生态环境，现将2018年生猪屠宰场卫生环保奖励资金81万元安排给你们（详见附表）。请严格按照“巩卫”工作要求做好场内环境卫生整治和污水处理设备设施的维护保养，按时清理污染物并做好无害化处理，保障污水处理系统正常运行，做好病媒生物防制工作。建立相关管理制度，完善各项工作措施，收集、整理、归档有关资料，做到专款专用。
