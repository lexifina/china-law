# 三亚市交通运输局关于城郊法院公交站点更名的回复

三亚市公共交通集团有限公司：

你公司来文《关于更改金鸡岭路“城郊法院”站名的请示》（三公交集〔2018〕28号）收悉。根据《三亚市公交站点设施管理暂行规定》（三府〔2016〕245号）有关公交站点命名的规定，经研究，同意将“城郊法院”公交站点更名为“天涯水业”。你公司要做好途经公交线路运营车辆腰牌和报站器数据的更新，并于2018年4月3日前完成公交站牌线路信息的刷新工作。

三亚市交通运输局

2018年3月28日
