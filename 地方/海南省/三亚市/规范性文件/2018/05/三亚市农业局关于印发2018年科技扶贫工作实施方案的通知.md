# 三亚市农业局关于印发2018年科技扶贫工作实施方案的通知

局机关各科室、下属各单位：

为全面贯彻落实党的十九大精神，坚决打赢脱贫攻坚战，结合我市农业工作实际，我局制定了《三亚市农业局2018年科技扶贫工作实施方案》，现印发给你们。

各单位务必高度重视，安排专人负责，认真贯彻执行。相关负责人要加强对相关信息资料的收集整理，及时形成工作总结报农业局科教科。
