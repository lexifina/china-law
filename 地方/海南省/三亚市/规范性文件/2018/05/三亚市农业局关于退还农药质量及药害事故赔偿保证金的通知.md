# 三亚市农业局关于退还农药质量及药害事故赔偿保证金的通知

三亚市各农药零售经营单位：

根据《海南省工业和信息化厅 海南省财政厅关于公布海南省涉企保证金目录清单的通知》（琼工信企业〔2018〕96号）和《三亚市科技工业信息化局转发<关于公布海南省涉企保证金目录清单的通知>的函》（三科工信函〔2018〕226号）的精神，结合我市农药零售经营实际情况，市农业局决定于2018年5月30日前做好全市农药质量及药害事故赔偿保证金（以下简称保证金）退还工作，退还金额包括保证金本金及利息等各项应当退还的费用，请已缴纳保证金的农药零售经营单位及时到三亚农村商业银行股份有限公司办理相关手续。

一、办理时间

2018年5月18日-30日。

二、办理地点

三亚农村商业银行股份有限公司（市二中对面农商银行）。

三、相关要求

1.退款手续原则上由存单登记的本人亲自到柜台办理，委托他人办理的必须出具公证委托书（可在当地公证处进行公证）。

2.请带上本人身份证、缴款存单、《农药质量及药害事故赔偿保证金账户三方共管协议书》及《三亚市农业局关于退还农药质量及药害事故赔偿保证金的通知》。

3.为避免出现人多拥挤，不能顺利办理退款业务，各区农药零售经营单位尽量按照以下时间前往农商银行办理。

2018年5月21日：天涯区

2018年5月22日：吉阳区、育才生态区

2018年5月23日：海棠区

2018年5月24日：崖州区（原南滨农场、粮所）

2018年5月25日：崖州区

三亚市农业局

2018年5月16日
