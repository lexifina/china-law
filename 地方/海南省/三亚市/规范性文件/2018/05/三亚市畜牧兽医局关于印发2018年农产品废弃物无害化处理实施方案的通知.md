# 三亚市畜牧兽医局关于印发2018年农产品废弃物无害化处理实施方案的通知

关于印发2018年农产品废弃物无害化处理

实施方案的通知

各区农林局，育才生态区经济发展局，各有关单位：

为推进畜禽养殖废弃物资源化利用，抓好畜禽养殖污染防治，发展绿色生态畜牧业，实现畜禽养殖与生态环境全面协调可持续发展。现将制定的《三亚市2018年农产品废弃物无害化处理实施方案》印发给你们，请认真组织实施。

三亚市畜牧兽医局

2018年 5月31日

（此件主动公开）

三亚市2018年农产品废弃物无害化处理实施方案

为推进畜禽养殖废弃物资源化利用，抓好畜禽养殖污染防治，发展绿色生态畜牧业，确保公共卫生、生态环境、养殖生产安全，实现畜禽养殖与生态环境全面协调可持续发展，结合三亚实际，制定本实施方案。

一、指导思想

以习近平新时代中国特色社会主义思想为引领，深入贯彻落实党的十九大精神，围绕乡村振兴战略、产业发展规划和“总量控制、合理布局、防治结合、资源利用、生态环保”总体要求及“创新、协调、绿色、开放、共享”发展理念，按照国务院《畜禽规模养殖污染防治条例》（第643号令） 《国务院办公厅关于加快推进畜禽养殖废弃物资源化利用的意见》等规定，推进畜禽养殖废弃物资源化利用和畜禽养殖区划分及管理，实施畜禽养殖污染防治，促进畜禽养殖废弃物减量化、无害化、资源化和生态化，全面协调可持续发展，建设美丽三亚。

二、实施目标

采用“种养结合、达标排放、集中处理”模式和“雨污分流、固液分离、综合利用、化制降解”工艺，开展粪污专项治理，创建标准化养殖试点，升级改造粪污治理设备设施，着力提升畜禽养殖废弃物资源化利用水平；兼顾环境容量、生态承载力、生态功能等要素，以规模养殖关停搬迁补偿为途径，推进畜禽养殖区划分及管理，严守生态保护红线，发展绿色生态畜牧业，保障“菜篮子”供给，促进牧业增效、农民增收。

三、基本原则

（一）坚持相关责任原则。明确管理部门和企业属地、主体责任，密切通力协作，共同推进畜禽养殖废弃物资源化利用。

（二）坚持分类扶持原则。按照粪污治理不同需求和关停搬迁类型、结构等不同要求，采取不同方式和做法分类扶持。

（三）坚持公开公平原则。强化监管工作机制，规范开展宣传指导检查验收公示等工作，公开公平公正，接受社会监督。

（四）坚持协调发展原则。抓好规模养殖污染综合治理，落实关停搬迁补偿，促进畜禽养殖与生态环境全面协调可持续稳定健康发展。

四、范围和内容

区分规模养殖污染综合治理和关停搬迁补偿等两大类给予扶持，其中规模养殖污染综合治理包括粪污专项治理项目和标准化养殖试点项目。

（一）养殖污染综合治理。重点实施规模畜禽养殖粪污专项治理和标准化养殖试点项目建设。

1．粪污专项治理。

（1）扶持范围。扶持对象主要是三亚市辖区内按照《海南省畜禽养殖污染减排技术导则》《病死及病害动物无害化处理技术规范》等要求开展畜禽养殖废弃物资源化利用项目建设，且符合相关规定的规模畜禽养殖场（户）、农民专业合作社和企业。优先扶持贫困户（脱贫户）和帮扶贫困户的农民专业合作社、养殖场。

（2）实施内容。主要包括粪污卫生环境治理与综合利用、厌氧发酵池示范试点、无害化处理扶持、有机肥生产处理试点、环评审批通过补助等项目，其项目补贴内容与标准、申报审批、竣工验收和资金拨付等项目管理，参照《三亚市农业局关于2016年农产品废弃物无害化处理实施方案的通知》（三农〔2016〕142号）要求具体实施。

2．标准化养殖试点。

（1）扶持范围。主要扶持已取得环保部门环评审批通过或完成环保备案规模畜禽养殖场（户）、农民专业合作社和企业的粪污处理与利用设备设施升级改造，美化绿化改善养殖环境，实施畜禽规模养殖污染防治。每个项目最高安排扶持资金原则上不超过15万元。

（2）实施内容。项目实施单位要按照审批的建设内容，具体组织实施建设，在规定的期限内完成项目建设，并接受有关部门的检查监督。

①申报审批。由实施单位编制项目预算书，申报项目建设内容，并向市畜牧兽医局提出项目建设申请；由市畜牧兽医局负责组织审核，经会议讨论通过，并在农业信息网或政府门户网站上公示，无异议后，签定协议书，同意项目建设，预拨启动资金。

②检查验收。项目竣工后，实施单位向市畜牧兽医局提出竣工验收申请，并提供竣工结算审查报告书、竣工实物照片等相关材料。由市畜牧兽医局牵头会同区农林局（经济发展局）等部门组成联合验收小组进行检查验收，完成现场检查验收报告和拍照存档。验收合格的项目和补贴资金在农业信息网或政府门户网站上公示，无异议后，经会议讨论通过，拨付剩余扶持资金。

③资金拨付。按照项目实施进度，市畜牧兽医局以转账或“一卡通”等形式直接拨付扶持资金，扶持资金不得以现金的形式支付。其中：项目开工启动即预拨扶持资金的30%；项目竣工验收合格，扶持资金拨付至100%。

（二）关停搬迁补偿。

1．扶持范围。三亚市辖区内，处在禁养区、城镇内河（湖）沿岸等重点区域和污染治理不达标且需综合整治关停搬迁的规模畜禽养殖场，系经工商行政管理部门注册登记且在三亚市辖区范围内从事畜禽规模养殖的企业。

2．实施内容。

（1）扶持标准。根据畜禽养殖栏舍、管理房等生产设施实际丈量面积、不同结构类型分类给予补偿。

①混凝土结构：屋面（顶）为钢筋、水泥混凝土；墙体为红砖、空心砖或环保砖，内饰水泥砂浆；地面为水泥地板。按每平方米补贴400元的标准给予补偿。

②铁皮结构：屋面（顶）为铁皮钢架材料；墙体为红砖、空心砖或环保砖，内饰水泥砂浆；地面为水泥地板。按每平方米补贴300元的标准给予补偿。

（2）补偿程序。

①提出申请。由拟关停搬迁单位向所辖区农林局（经济发展局）和市畜牧兽医局提出申请，同意主动关停或搬迁，并承诺将存栏畜禽全部清理完毕，日后不再在原址上继续从事畜禽养殖。

②核实验收。由市畜牧兽医局牵头组织，会同所辖区农林局（经济发展局）等相关部门和人员，对符合关停搬迁补偿条件畜禽养殖场进行现场实地核实丈量，完成现场核实验收报告和实物拍照存档。

ƒ资金发放。对已完成丈量面积和现场核实验收情况，由市畜牧兽医局张榜或网上公示，公示无异议后，签订关停搬迁补偿协议书，经会议讨论后，以转账或“一卡通”的形式发放补偿资金，补偿资金不得以现金的形式支付。

五、项目资金

2018年度本级部门市财政预算资金190万元，其中，规模养殖污染综合治理资金100万元、规模养殖关停搬迁补偿资金90万元。按项目验收公示完成时间先后顺序拨付补贴资金，包括上年已检查验收完成尚未拨付补贴资金的规模养殖污染综合治理和关停搬迁补偿项目。资金使用完成后，市财政不再追加安排项目资金，如资金未使用完成则结余结转下年继续使用。

六、实施期限

2018年4月—12月。

七、保障措施

（一）抓好责任落实。制定方案，明确责任分工，狠抓任务落实。市畜牧兽医局负责本项目的组织实施，包括方案制定、协调审批、组织验收、资金拨付、检查指导等工作；区农林局（经济发展局）协助做好申报审核、检查验收和技术服务等工作，共同推进项目建设顺利完成。

（二）注重科技指导。结合“减量、环保、循环、安全”与资源化综合利用等要求，兼顾环境容量、生态承载力、生态功能等要素，以关停搬迁补偿为途径，加快推进畜禽养殖区划分及管理；主推种养结合生态循环农业发展模式，加强与环保、科研等相关单位紧密协作，做好养殖污染综合治理设备设施升级改造、净化美化绿化工程设计与规划，创建标准化养殖小区试点，培育生态品牌产业，加快推进畜禽养殖废弃物资源化利用等生态循环技术转化应用。

（三）加强资金监管。按照“先建后补，分批核拨”原则，项目申报审批后再实施建设。严格落实财务会计和资金管理制度，资金由市财政局负责安排计划，市畜牧兽医局负责拨付发放，专帐管理，专款专用，并接受市财政等部门的检查监督。

（四）强化项目管理。严格项目的申报、审核、审批、验收、公示、拨付等，杜绝弄虚作假、虚报冒领发生，确保项目建设质量和进度，确保资金使用安全。项目完成后，要保证正常运转和发挥应有作用。市畜牧兽医局、区农林局等部门对项目进行服务、协调、检查、指导和监督。

（五）做好宣传总结。结合实际情况，千方百计推动畜禽养殖废弃物资源化利用，开展广泛性的“畜禽—沼气（渣、液）—果菜”等高效生态循环农业模式的科普宣传和技术培训，不断提高生态环保、质量安全和循环利用发展意识，推行新能源沼气和优质有机肥料广泛使用，加快推进现代畜牧业绿色发展。
