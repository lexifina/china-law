# 三亚市畜牧兽医局关于安排2018年农产品质量体系建设资金的通知

三亚万保实业有限公司等有关单位：

为鼓励养殖业“三品一标”和“五好畜产品”发展，进一步推动畜产品品牌建设，现根据各单位获得品牌称号情况，安排2018年农产品质量体系建设资金55万元给通过无公害农产品、五好畜产品品牌认证的畜牧业养殖企业（详见附表）。请认真按照《农产品质量安全法》的要求，建立畜产品质量安全管理制度，健全质量安全控制体系，制定切实可行的生产操作规程，落实生产记录制度。通过品牌认证的畜产品在其生产过程中，保证落实畜产品质量控制措施，严格执行该产品生产技术规程和质量安全标准，严格按照国家法律法规要求使用投入品和添加物，保障源头畜产品质量安全，确保畜牧业健康稳定发展。

附件：2018年农产品质量体系建设资金安排表

三亚市畜牧兽医局

2018年5月31日
