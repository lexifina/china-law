# 三亚市交通运输局关于临时调整途经市223国道原吉阳环岛至亚龙湾路口路段公交线路的通知

三交运〔2018〕267号

三亚市交通运输局

关于临时调整途经市223国道原吉阳环岛至

亚龙湾路口路段公交线路的通知

三亚市公共交通集团有限公司：

根据市公安局交警支队关于市223国道（原吉阳环岛至亚龙湾路口路段）道路施工交通管制通告的内容，原吉阳环岛至亚龙湾路口路段道路实行全封闭或半封闭施工，将对我市15路、17路、19路、24路、25路等5条公交线路营运造成影响。为方便市民和游客乘坐公交车，决定自5月16日开始对途经上述路段的公交线路作如下临时调整：

一、15路、24路、25路等3条线路：改道经过吉阳大道、田独路，不再经过吉阳小学、安游路口、新红村路口等3个站点，增设民族中学、吉阳市场、乌石村、京润珍珠馆、亚龙湾火车站等5个站点。

二、17路线：去程从三亚火车站至福海苑方向行驶线路和途经站点不变，返程从福海苑至三亚火车站方向改道经过田独路、吉阳大道，不再经过第十小学、新红村、安游路口、吉阳小学等4个站点，增设亚龙湾火车站、京润珍珠馆、乌石村、吉阳市场、民族中学等5个站点。

三、19路线：去程从市民游客中心至安游方向行驶线路和途经站点不变，返程从安游至市民游客中心方向改道至X826县道、田独路、吉阳大道，不再经过安游路口、吉阳小学站点，增设第十小学、福海苑安置区、亚龙湾火车站、京润珍珠馆、乌石村、吉阳市场、民族中学等7个站点。

你公司要做好途经公交线路运营调度及车辆腰牌、报站器数据的更新工作，并于2018年5月15日前完成公交站牌线路信息的刷新工作。

特此通知。

三亚市交通运输局

2018年5月8日
