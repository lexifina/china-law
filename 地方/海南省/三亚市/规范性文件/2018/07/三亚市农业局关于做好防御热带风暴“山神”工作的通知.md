# 三亚市农业局关于做好防御热带风暴“山神”工作的通知

育才生态区管委会，各区农林局：

根据三亚市气象台发布：今年第9号台风“山神”（热带风暴级）, 17时中心位于19.2°N、114.7°E，即在文昌市偏东方向约410公里的海面上，8级。预计，“山神”将以35公里左右的时速向偏西方向移动，强度还将有所加强。为切实做好农业防风工作，现就有关事项通知如下：

一、明确责任，确保安全

各区农林局（管委会）要密切关注当前台风动态，及时指导本区农户、合作社、农业企业做好防御准备，确保人员和财产安全，特别是建档立卡贫困户住房和扶贫产业的安全。主要领导手机要24小时畅通，台风过后要安排专人统计灾情，确保6小时内准确统计上报灾害情况，为领导科学决策提供依据。

二、全面排查，做好防范

要对全区农业生产（含畜牧）进行调查摸底，全面掌握生产情况，做到心中有数。重点做好蔬菜大棚、蔬菜种植基地、沼气池、预冷库和畜禽栏舍等防风防汛工作。采取有效措施及时疏通田间沟渠，低洼菜地应尽快排除田间积水，对成熟的农作物要及时抢收，对畜禽栏舍要进行加固，及时对鸡苗、猪苗等进行转移，尽量减少灾害损失。

三、加强灾后指导，靠前服务

各区农林局（管委会）要在做好防范工作的同时，要提前谋划灾后技术指导和恢复生产工作。充分发挥农技人员的作用，组织好灾后恢复生产。
