# 三亚市教育局关于进一步做好《海南省学校毒品预防教育读本》试点工作的通知

《海南省学校毒品预防教育读本》

试点工作的通知

各区教科局：

时值全国青少年毒品预防教育6.27工程收官之年，为了进一步落实毒品预防教育教材，切实推进我市学校毒品预防教育，根据《海南省教育厅关于进一步做好<海南省学校毒品预防教育读本>试点工作的通知》(琼教体〔2018〕133号)要求，要明确地方财政投入，解决学生用书经费，确保试点试用工作任务顺利完成，促使学校毒品预防教育工作凸显成效。

《海南省学校毒品预防教育读本》小学、初中、高中各一册，市教育局直属学校（含民办）由市教育局专项经费安排，区属学校由各区自行解决。据估算下学期学生免费教科书人数（见下表），请你们争取财政支持，积极筹措经费，确保秋季开学教材供应到位。
