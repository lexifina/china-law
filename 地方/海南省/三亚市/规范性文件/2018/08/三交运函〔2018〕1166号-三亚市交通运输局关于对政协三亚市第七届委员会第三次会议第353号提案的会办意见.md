# 三亚市交通运输局关于对政协三亚市第七届委员会第三次会议第353号提案的会办意见

三交运函〔2018〕1166号

三亚市交通运输局

关于对政协三亚市第七届委员会第三次会议

第353号提案的会办意见

三亚市公安局交通警察支队：

杨雄委员提出的“关于规范三亚市河西路路段交通不文明行为的建议”的提案收悉。根据要求，由我单位协助你们办理此提案，经研究，现提出涉及我单位工作的答复意见。

近年来，三亚市委、市政府高度重视公共交通发展，贯彻落实国家优先发展公共交通战略，创建公交都市示范城市，公共交通取得了长足的进步和发展。正在推动三大转变，即由普速公交向快速公交转变、由单一公交向多样公交转变、由普通公交向特色公交转变。目前三亚市共有公交线路85条，营运车辆1102辆。主城区公交站点500米覆盖率95.2%，行政村通客车率95%，2017年客运量约1.05亿人次，公交线网已覆盖至各区、机场、火车站、学校、医院、大型居民区、购物商城及各景区景点。三亚市已初步形成分工明确、衔接顺畅、运营高效的“快、干、支、微”公交运营网络，公交客运服务基本满足市民游客出行需求。

下步将以公交都市创建为抓手，大力推动三亚市域公共交通体系改革，通过推进场站建设、优化公交线网、做好公交运营组织改造、保障公交路权优先、加快公共交通智能化建设，努力实现主城区内出门500米即可乘坐公共交通，5分钟内换乘，解决社区内最后1公里无公交车到达的问题；同时，加快有轨电车建设、规范管理公共交通运输新业态、拓展海上巴士规模，多措并举，满足市民游客多样化出行需求。

以上意见，请你们在正式答复委员时参考。
