# 三亚市人民政府三亚警备区关于做好三亚市随军家属就业安置工作的实施意见

三亚市人民政府三亚警备区

关于做好三亚市随军家属就业安置工作

的实施意见

各区人民政府和人民武装部，各管委会，市政府直属各单位：

为支持国防和军队建设，做好驻市部队现役军人随军家属的就业安置工作，根据国务院、中央军委《关于批转人力资源社会保障部总参谋部总政治部军人随军家属就业安置办法的通知》（国发〔2013〕42号）和海南省人民政府、海南省军区《关于进一步做好随军家属就业安置工作的实施意见》（琼府〔2014〕25号）及中共三亚市委常委议军会议精神，现结合我市实际，提出如下实施意见：

一、随军家属是指经军队师（旅）以上政治机关按规定批准随军并办理了随军手续的现役军人配偶。

二、随军家属就业安置工作，按照政府主导、市场调节、就近就地、照顾专业对口、发挥个人特长、保障基本生活的原则，实行政府行政调配、帮助推荐安置、劳动力市场调节安置、部队内部自行安置、个人自谋职业以及发放生活补助相结合的安置办法。

三、本市行政区域内的各级国家机关、事业单位、社会团体及各类企业，均有接收安置随军家属就业和配合有关部门做好随军家属就业安置工作的义务和责任。

四、有就业能力和就业愿望的以下随军家属优先安置：烈士、因公牺牲、平时荣立二等功、战时荣立三等功以上奖励或被战区（大军区）级以上表彰、一至四级残疾军人、荣获省级以上拥政爱民模范表彰军人的随军家属。同等条件下，团职以上干部或具有高级技术职称的随军家属应予以优先安置。

五、政府行政调配安置渠道有四种，分别为公务员调动安置、事业单位调配安置、国有企业就业安置和公益性岗位援助安置。

（一）公务员调动安置。随军前为公务员的在职在编人员随军家属，经协调本市缺编的国家机关、社会团体、参公管理事业单位同意接收安置的，市各级人力资源和社会保障及机构编制部门应及时办理调动手续予以安置。

（二）事业单位调配安置。每年安排不少于10名事业单位编制（不含参公管理事业单位）用于指令性安置随军家属就业。随军前为事业单位在职在编人员的随军家属优先安排，其余的从编制外人员的随军家属中通过公开招聘方式择优安排。每年12月底前，市人力资源和社会保障部门根据全市事业单位编制情况，按照人岗相宜原则商市机构编制部门拟定安置岗位方案报市政府核准。

对于随军前为事业单位在职在编人员随军家属的安置，由三亚警备区根据随军家属原工作单位及拟安置单位的性质和岗位性质、学历、专业技术职称等相关情况自主确定调配安置方案报市人力资源和社会保障部门审核。对于需采取公开招聘方式安置的随军家属，由三亚警备区按照我省事业单位公开招聘的相关规定具体实施招聘工作，市人力资源和社会保障部门对其招聘方案予以核准备案并对其招聘工作进行指导、监督和管理，拟聘用人员报市人力资源和社会保障部门审核。市人力资源和社会保障部门制定拟调配安置和公开招聘人员聘用方案报市政府审批。

（三）国有企业就业安置。市国有、国有控股和国有资本占主导地位企业应自觉承担和履行安置随军家属的社会责任，每年在招录新员工时，应按照5%的比例安置随军家属。每年12月底前，市国资委将本年度接收安置随军家属的国有企业岗位及所需资格条件报市人力资源和社会保障部门，市人力资源和社会保障部门拟定安置岗位方案报市政府审定，三亚警备区根据市政府审定的安置岗位方案，按照岗位需求并结合随军家属的经历学历、专业技术职称、个人特长等相关情况自主确定安置方案，市人力资源和社会保障部门审核后报市政府审批。

（四）公益性岗位援助安置。各区人民政府及有关部门会同三亚警备区，积极创造条件提供公益性岗位安置随军家属就业。每年提供的公益性岗位不少于100个，其中各区人民政府提供的均不少于15个、驻军部队提供的不少于40个（各驻军部队公益性岗位安排工作由三亚警备区牵头组织）。每年12月底前，各区政府、三亚警备区将各自需安排就业的公益性岗位报市人力资源和社会保障部门审核认定，三亚警备区按照审定的岗位自主确定安置人员名单报各区人民政府安排上岗，并连同自身安置人员名单报市人力资源和社会保障部门备案。

公益性岗位补贴的对象、岗位工资补贴标准、资金来源渠道及公益性岗位的认定与管理等按有关规定执行。

六、市人民政府行政调配安置命令下发后，各接收单位应在3个月内办理接收手续并安排上岗，不得以任何借口拒绝接收。随军家属应及时办理报到手续到指定单位报到，如无正当理由，逾期不报到或不服从安置的，原则上不再安排就业。

七、各接收单位应依法与随军家属签订劳动合同并足额缴纳各项社会保险费。首次签订劳动合同（聘用合同）的期限原则上不低于3年，并不得违反法律法规和有关规定，随意解除或终止随军家属的劳动关系（聘用关系）。

八、鼓励随军家属积极参加公务员公开招考、事业单位公开招聘实现自主就业。

九、有生产任务的企业，不得随意裁减随军家属。企业在经济性裁员时，在同等条件下应当优先留用随军家属。企业需重新招收人员时，应优先从本单位裁减的随军家属中录用。随军家属因企业生产经营困难等原因被安排待岗的，待岗期间，企业应按规定发给其基本生活费。

十、在部队营区服务网点、家属工厂及公益性岗位就业的随军家属，其档案由市公共就业服务机构保存和管理，在军人退出现役或调动时为其办理调转手续。

十一、随军家属在我市实现就业安置或跟随现役军人转业离开我市的，其社会保险关系转移接续问题，按照国家和我省有关规定执行。

十二、市公共就业服务机构设立随军家属就业服务窗口，为随军家属提供免费就业创业指导、职业介绍、档案保管等公共服务。因企业破产、停产等原因造成随军家属失业下岗的，市公共就业服务机构、各区应当优先推荐再就业。

十三、市公共就业服务机构、各区每年应根据各类用人单位用工需求，举办1至2期的随军家属专场招聘会或开展送岗位进军营活动，推荐帮助随军家属就业。企业在招用人员时，同等条件下优先聘用。

十四、加强职业技能培训，增强随军家属就业竞争能力。市公共就业服务机构每年应为登记失业的随军家属举办各类职业技能培训班和技能鉴定，并按规定申请职业技能培训补贴和一次性职业技能鉴定补贴。三亚警备区要积极组织随军家属参加职业技能培训和技能鉴定。

十五、持就业创业登记证随军家属自主参加职业培训、职业技能鉴定、灵活就业和在公益性岗位就业的，分别享受职业培训补贴、一次性职业技能鉴定补贴、社会保险补贴、公益性岗位补贴。补贴标准、申报材料和资金拨付程序按有关规定执行。就业专项资金管理规定有调整时，随军家属的补贴标准、申报材料和资金拨付程序也相应调整。

十六、鼓励和支持随军家属自主创业。符合条件的随军家属自主创业的，可按规定申请创业小额担保贷款。从事微利项目的，个人申贷可享受最高10万元的创业贷款；对合伙经营的，可申请最高50万元的创业贷款；以联保形式申请的，可享受每户最高6万元，总额度最高18万元的创业贷款；创业小额担保贷款按规定可享受全额财政贴息。

十七、鼓励和支持随军家属自谋职业和灵活就业。从事个体经营的随军家属，自领取税务登记证之日起，3年内免征个人所得税。凡是已经纳入营改增试点范畴，从事个体经营的随军家属，有师以上政治机关出具的可以表明其身份的证明，经税务机关进行审查认定的，自领取税务登记证之日起，其提供的应税服务3年内免征增值税;对为安置随军家属就业而新办的企业，招收随军家属人数占企业总人数60%(含)以上，有军(含)以上政治和后勤机关出具的证明，自领取税务登记证之日起，其提供的应税服务3年内免征增值税。

个体经营是指雇工7人(含7人)以下的个体经营行为，随军家属从事个体经营凡雇工8人(含8人)以上的，无论其领取的营业执照是否注明为个体工商业户，均按照新开办的企业享受有关营业税优惠政策。

十八、给予未就业的随军家属发放生活补助，保障其基本生活，所需资金由市级财政负担。生活补助标准根据我市经济社会发展情况、物价水平适时调整，并报省人民政府审批。

十九、随军家属就业安置工作所需经费，纳入各级财政安排的就业工作经费中统筹使用。

二十、市人力资源和社会保障部门是随军家属就业安置工作的主管部门。各区人民政府和市机构编制、财政、民政、国资委、工商、税务等部门依照各自职能，共同做好随军家属就业安置工作。市双拥办负责随军家属就业安置军地之间的联络工作。

二十一、三亚警备区是驻市部队随军家属就业安置工作的牵头组织单位，应会同市人力资源和社会保障部门做好随军家属安置工作，并有责任和义务教育引导随军家属树立正确的就业观，做好内部安置工作。在进行政府行政调配安置工作时应负起主管部门的职责，制定完善、稳妥的制度措施，做到程序公开，确保公平、公正的安置效果。

二十二、三亚警备区、市人力资源和社会保障部门、市双拥办要各司其职，密切配合，共同建立联合督导的工作机制，及时督办、协调联络、检查指导随军家属就业安置工作，协调解决工作中存在的困难和问题。

二十三、未完成随军家属就业安置任务的单位，当年不得评选为双拥先进单位。

二十四、本意见第五条第二款的规定试行期限为5年，其后视我市实际情况适时调整。

二十五、本意见由市人力资源和社会保障部门负责解释，自发布之日起施行，《三亚市随军家属就业安置暂行规定》（三府〔2007〕202号）同时废止。
