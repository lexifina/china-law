# 三亚市人民政府关于印发三亚市旅游厕所管理与服务规范的通知

三亚市人民政府

关于印发三亚市旅游厕所管理与服务规范的通知

三府〔2018〕135号

各区人民政府，各管委会，市政府直属各单位：

《三亚市旅游厕所管理与服务规范》已经七届市政府第29次常务会议审议通过，现印发给你们，请认真组织实施。

三亚市人民政府

2018年7月12日

（此件主动公开）

前言

随着三亚市创建“国家全域旅游示范区”的大背景下，厕所的管理和服务也摆在了更重要的位置。为进一步推进三亚市旅游厕所管理和服务向标准化、质量化发展，根据中华人民共和国《旅游厕所质量等级的划分与评定》（GB/T18973-2016）的相关内容和要求，结合三亚市实际，《三亚市旅游厕所管理与服务规范》着力解决旅游厕所管理与服务的质量化和标准化问题，旨在建立旅游厕所管理服务的长效机制，为三亚市旅游厕所的管理和服务能形成可操作性和可监督性的量化指标，提升旅游厕所管理和服务的质量。

本标准按照GB/T1.1-2009的规则起草。

本标准由三亚市旅游发展委员会提出。

三亚市旅游厕所管理与服务规范

1．范围

本标准适用于三亚市旅游景区、交通集散点（高速公路服务区、车站、机场、码头等）、乡村旅游点、旅游餐馆、旅游娱乐场所、城市公厕、大型商场（超市）等旅游接待场所的公共厕所。

3．术语和定义

3.1旅游厕所tourismtoilets

指为旅游者和当地居民提供如厕服务的旅游景区景点、交通集散点（高速公路服务区、车站、码头等）、乡村旅游点、旅游餐馆、旅游娱乐场所、城市公厕、大型商场（超市）等旅游接待场所的公共厕所。

4．管理规范

4.1管理人员

旅游厕所应配备专门的管理人员，负责旅游厕所的运营、维护和保洁等管理工作。

4.2管理文件

4.2.1应制定并实施内部管理文件，包括但不仅限于：

a）旅游厕所卫生服务标准，内容应包括清洁频次、清洁方式和清洁程度等；

b）设施设备维护管理规范，内容应包括人员安排、技术要求、维护措施等；

c）上岗人员培训制度，内容应包括服务技能、应急技能、文明礼仪等；

d）服务质量检查、考核与激励制度，内容应包括检查、考核的频次和具体要求及激励措施等；

e）突发事件应急预案，包括停水、停电、紧急报修、维修停用、发生安全事故及治安事件等方面的应急措施；

f）如果是委托第三方公司服务的，应与第三方公司签订服务协议。

4.3管理制度

4.3.1应明确各旅游厕所业主单位所属主管部门的管理范围，将旅游厕所的建设管理纳入各自的考核评估体系。

4.3.2应有卫生监督检查制度，建立健全岗位责任制、服务标准、监督改进措施等。

4.3.3应建立每日保洁服务登记制度，包括开门检查、保洁频率、设施维修及日常检查等。

4.3.4应有粪便处理的方法、验收手续和管理制度。

4.4应急措施

4.4.1应有旅游淡旺季和特殊事件厕所应急管理预案。

4.4.2当如厕人数短时间内聚集时，要有应急措施，保证有序如厕。

4.4.3当遇到恶劣天气、停水停电、管道堵塞等突发事件时，应采取应急保障措施，确保厕所服务连续、正常。

4.5设备使用与维护

4.5.1建立设备定期巡查制度并做好相应记录。

4.5.2应定时巡检、维护厕所设备，保障提供干净卫生、功能正常的厕所设备。

4.5.3设备完好率应不低于90%。

4.5.4大、小便位及附属管件停用比例不大于10%，停用时间应不大于2天。

4.5.5其他配件设施停用比例不大于20%，停用时间应不大于3天。

4.5.6厕所应备有充足的卫生纸、清洁液、消毒剂等耗材。

4.5.7排风、除味设施应定期维护、无故障。

4.5.8厕位门锁应保障功能正常。

4.5.9应急照明设施应定期检查，工作正常。

4.5.10洁手设备应定期维护、无故障，及时补充洗手液和擦手纸。

4.5.11婴儿台应保证安全、牢固可靠，干净无灰，功能正常（仅限于有第三卫生间的厕所）。

4.5.12免费提供手纸的厕位应定时检查，保证手纸架内不缺手纸。

4.5.13废纸桶应及时清扫，避免满溢。

4.5.14定时检查厕位内挂钩是否牢固完好，如损坏应及时更换。

4.5.15定时检查厕位间的隔断板、搁物板，保证完好、清洁、无污损。

4.5.16应保持排水、排污管道无堵塞。

4.5.17无障碍通道应保持畅通，无障碍设施应牢固可靠。

4.5.18标识牌应保障易识别、无残损。

4.6文明如厕宣传

4.6.1旅游厕所公共区域应有文明如厕宣传牌或显示屏，文字规范，宣传内容通俗易懂，安装位置醒目。

4.6.2文明如厕宣传方式宜多样化，体现文化特色和人文关怀。

4.6.3文明如厕宣传内容可分为三种情况：

a）禁止随意丢弃厕纸、乱涂写、乱刻画、乱张贴、随地吐痰、吸烟、乱扔杂物和随地大小便等劝告性提示。

b）节约用水、绿色环保、礼让老弱病残、遵守如厕秩序等公益性提示。

C）禁止在洗手台上冲脚，滨海旅游厕所当众更换衣服等不雅行为。

4.7收费标准

旅游厕所应全部免费开放。

5．服务规范

5.1服务人员

5.1.1应有专门的设备维护、保洁服务人员，负责设施、设备维护和保洁作业。

5.1.2保洁人员应经过岗位培训，考核合格后方可上岗。

5.1.3保洁员应统一着装、佩证上岗、文明用语、礼貌待人。在需要时，应对老弱病残幼等特殊人群提供如厕帮助。

5.1.4对不文明行为要及时劝阻和制止。

5.1.5保洁人员应经常检查厕所内设施的正常使用情况，发现故障，及时报修。

5.1.6保洁人员应遵守工作规章制度、熟悉设备、设施的正确使用方法并按要求填写本岗位的工作记录。

5.2卫生保洁

5.2.1保洁程序

5.2.1.1准备好保洁所需的工具和用具并配制好清洁剂和用品。

5.2.1.2进入卫生间前将清洁工作告示牌放在门口，打开门窗通风。

5.2.1.3收集废弃物、清扫地面垃圾，清倒垃圾篓，换新垃圾袋后放回原位。

5.2.1.4冲刷清洁便器，包括厕位间的配件和附件。

5.2.1.5清洁洗手台、面盆、水龙头和面镜。

5.2.1.6根据定期作业要求擦拭墙面、天花板、排气扇、卫生间门及门框。

5.2.1.7清洁地面，地面较脏的要使用清洁剂。

5.2.1.8补充厕所厕纸、洗手液等卫生用品。

5.2.1.9清洁作业完毕，应环视整个厕所一遍，看是否有遗漏和不彻底之处，如有应及时补做。

5.2.2保洁要求

5.2.2.1在规定的开放时段内应有专人进行保洁与服务。

5.2.2.2根据客流量和厕所的使用频率，规定厕所的保洁频次。

5.2.2.3按保洁程序进行保洁作业，厕所内外环境保持干净整洁。

5.2.2.4使用洁厕粉，应戴胶手套做好劳动保护。

5.2.2.5禁止使用高浓度酸、碱清洁剂和粗糙刷具，以免损坏瓷面。

5.2.2.6所有消毒药和清洁液必须是经卫生行政部门批准并有效卫生许可证的产品。

5.2.2.7擦抹电器，电源开关要用干布擦抹，以防触电。

5.2.3大小便器的保洁

5.2.3.1大小便器内应无积便、无污垢、无堵塞、无滴漏。

5.2.3.2应随时检查冲洗器，保证其完好，功能正常。对未能冲洗干净的便器，应立即人工冲洗并检查冲洗功能是否正常。

5.2.3.3对带有自动更换坐垫纸功能的坐便器，要定期维护，保证功能正常和有足够的坐垫纸。

5.2.4净手设备的保洁

5.2.4.1洗手盆应保证清洁、无污迹、上下水通畅、无毛发、无杂物。

5.2.4.2水龙头光洁、无皂迹，开关有效。

5.2.4.3洗手台面干净无污垢、无积水。

5.2.4.4应定时进行洗手液容器的清洁与消毒，及时补充洗手液。

5.2.4.5干手器应功能正常，表面洁净；擦手纸箱内纸张充足，表面洁净。

5.2.4.6手纸盒内的纸张充足，表面洁净。

5.2.4.7废纸桶应放置于出口处或洗手台旁，及时清理，避免满溢。

5.2.5面镜

应保持镜面清洁，无水渍、无污渍、手印。

5.2.6环境保洁

5.2.6.1室内环境保洁

5.2.6.1.1大门内外保持清洁，无污渍、无尘土、无杂物。

5.2.6.1.2窗玻璃明亮，窗台、窗框、排风机等处无灰尘、无蛛网、无破损。

5.2.6.1.3地面无杂物、无痰迹、无积水，瓷砖无破损、无水渍。

5.2.6.1.4墙面、天花板、墙角无积尘、污渍、蜘蛛网，无乱涂画，墙面应光洁。

5.2.6.1.5大门、门把手、挂衣钩、搁物板等设施应完好、功能正常，表面清洁，无积尘、无污迹。

5.2.6.1.6管路、管件应无污垢、无堵塞、无滴漏。

5.2.6.1.7墩布池、地漏无污渍、无杂物、无臭味。

5.2.6.1.8除臭、通风设备运行良好，无污迹。

5.2.6.1.9照明设备上无污迹、无尘土，开关处无明显手印迹、湿迹。

5.2.6.1.10厕所内的标识牌应干净，无掉漆、无残缺。

5.2.6.2室外环境保洁

5.2.6.2.1厕所周边环境整洁有序，应无垃圾、粪便、污水、杂草等其他杂物，无卫生死角。

5.2.6.2.2厕所建筑外表、门窗定期维护、清洁。

5.2.6.2.3厕所外的标识牌应清晰可见、无污渍、无损坏残缺。

5.2.6.2.4厕所外坡道扶手干净无灰尘。

5.2.6.2.5厕所入口处道路、台阶无积水。

5.2.6.2.6厕所外化粪池、粪井周边场地应无垃圾、粪迹、污水。

5.2.7保洁作业和工具放置。

5.2.7.1保洁作业时宜在入口处设置提示牌。雨天和地面保洁时，应设置防滑标识和设施。

5.2.7.2清洁大小便洁具的拖把、抹布应与清洁其他设施的拖把、抹布区分使用。

5.2.7.3保洁作业完毕后，应将作业工具统一放置在工具间内，摆放整齐，拖把、扫把、抹布晾晒时应置于拖把架上。

5.2.7.4公共厕所内部通道、洗手台不应放置拖把、水桶、抹布、扫把等作业工具和其他影响视觉观瞻及通行的物品。

5.2.7.5厕所入口处道路、台阶无积水。

5.3环境卫生控制指标

旅游厕所环境卫生控制指标应符合下表的规定。

5.4服务时间

服务时间应与厕所开放时间一致或长于开放时间。

6.本规范最终解释权由三亚市旅游发展委员会负责。
