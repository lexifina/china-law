# 三亚市人民政府关于亚龙湾海域禁航及管制的公告

三亚市人民政府

关于亚龙湾海域禁航及管制的公告

为确保博论坛2018鳌亚洲年会的顺利进行，减少安全隐患，亚龙湾海域海上作业渔船、游艇以及沿岸各酒店从事海上娱乐项目在博鳌亚洲论坛2018年会期间实施临时管制，设立警戒区海域并禁航，其它地区无关船只禁止进入亚龙湾海域进行作业和活动，亚龙湾内所有船只必须于2018年4月5日上午8时前集中停靠于红树林保护区青梅湾（瑞吉酒店码头）处集中停靠。

禁航区域为A(北纬18°09′36″，东经109°34′24 ″)、B（北纬18°10′54″，东经109°42′00 ″）、C（北纬18°11′48″，东经109°42′45 ″）、D（北纬17°58′18″，东经109°46′45 ″）、E（北纬17°58′18″，东经109°32′55 ″）五点连线范围的海域。

禁航及管制的时间为2018年4月5日上午08:00开始。

三亚市人民政府
