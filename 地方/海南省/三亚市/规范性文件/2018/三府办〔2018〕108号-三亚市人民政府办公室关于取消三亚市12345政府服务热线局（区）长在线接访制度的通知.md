# 三亚市人民政府办公室关于取消三亚市12345政府服务热线局（区）长在线接访制度的通知

三亚市人民政府办公室

关于取消三亚市12345政府服务热线

局（区）长在线接访制度的通知

各区人民政府，各管委会，市各有关单位：

自2016年7月《三亚市人民政府办公室关于印发三亚市12345政府服务热线局（区）长在线接访工作方案的通知》（三府办〔2016〕230号）印发实行以来，各局（区）长在市12345政府热线恪尽职守，在线接听了大量市民游客的来电咨询投诉，协调督办解决了大量疑难办件，极大地发挥了局（区）长在线解决热线问题的作用，较好地促进了12345政府热线工作的开展。

近期，随着市12345政府服务热线工作体制机制、管理制度、办件处置流程、热线话务员队伍建设等逐步完善和提升，经市人民政府同意，决定自本通知发布之日起取消市12345政府服务热线局（区）长在线接访制度。

特此通知。

三亚市人民政府办公室

2018年4月25日

（此件主动公开）
