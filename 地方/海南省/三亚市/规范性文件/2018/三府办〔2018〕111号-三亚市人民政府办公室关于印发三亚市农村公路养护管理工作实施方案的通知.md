# 三亚市人民政府办公室关于印发三亚市农村公路养护管理工作实施方案的通知

三亚市人民政府办公室

关于印发三亚市农村公路养护管理

工作实施方案的通知

各区人民政府、育才生态区管委会，市各有关单位：

为全面加强我市农村公路养护管理，深化体制和机制改革，切实理顺农村公路养护管理权限，充分发挥和履行好各区在农村公路养护管理中的责任主体作用，进一步提高农村公路养护质量和投资效益，建立符合我市农村公路养护管理工作长效机制，确保放得下、用得好、管得住，提升农村公路的通行保障能力和公共服务水平，为我市美丽乡村建设和构建和谐社会提供强有力的服务保障，根据《中华人民共和国公路法》《公路安全保护条例》《海南省公路条例》等有关精神，结合我市农村公路工作实际，制订本实施方案。

一、农村公路养护管理目标

按照“政府主导、区级负责、养护转型、统筹资金、管理升级、服务提质”的总体思路，建立健全市区级负责、权责统一的农村公路养护管理体系，落实养护管理责任、资金、人员，实现养护管理工作的常态化和规范化，实现“有路必养、养必优良、有路必管、管必到位”的目标。

二、农村公路管理养护范围和总体要求

（一）农村公路管理养护范围

自2018年3月1日起市级下放移交给各区的农村公路（乡道和村道）及桥梁，其中农村公路管养总里程共计1331.025公里，992条，桥梁2660.71米，97座。包括：乡道245.575公里，83条；村道1085.45公里，909条。按照管辖范围属地划分具体如下：

天涯区：乡道53.293公里，11条；村道362.46公里，345条；共计415.753公里，356条。

吉阳区：乡道20.171公里，16条；村道141.865公里，124条；共计162.036公里，140条。

海棠区：乡道49.417公里，29条；村道182.96公里，127条；共计232.377公里，156条。

崖州区：乡道69.412公里，13条；村道191.374公里，146条；共计260.786公里，159条。

育才生态区管委会：乡道53.282公里，14条；村道206.791公里，167条；共计260.073公里，181条。

（二）农村公路养护质量总体要求

按照“安全、完好、整洁、畅通”的通行要求，农村公路管理养护工作应达到：路基边坡稳定、路肩整洁，排水畅通；路面整洁、行车舒适；构造物、桥涵等结构完好；大、中修工程完成较好；沿线设施完善，无侵占、破坏道路现象。具体要求：

好路率指标：乡道、村道列养路线年平均好路率和年末好路率达到省公路局下达的年度养护生产计划的指标。（以MQI值和经常性养护率为主要指标考核）。

路基路面：路容整洁，无坑槽（洞）、松散、波浪拥包、破碎板病害，超期油路面没有明显影响行车的病害，路面整洁无堆积物，路肩边缘顺直、路肩坚实且路肩与路面衔接平顺，路基边坡稳定。护坡、挡墙无坍塌。无因养护问题造成社会负面影响。

桥梁、涵洞等构造物桥梁日常养护：桥涵等构造物维护完好、桥面平整干净、排水畅通，栏杆、伸缩缝无损坏、基础无冲刷淘空，桥头和涵顶无跳车，桥涵桥梁锥坡等砌体无破损，设置桥梁养护工程师岗位并有专职人员。

交通工程和沿线设施：标志、标线、里程碑、百米桩、等附属设施维护良好、完整、洁净，功能发挥正常，复杂路段设立警示桩。

排水设施：边沟、排水沟、截水沟等设施无淤（堵）塞、无损坏，应保持排水畅通，要及时修复砌体边沟损坏部位，保持完好状态。

四、农村公路管理养护责任主体、机构设置和职责分工

农村公路原则上以市、区人民政府（育才生态区管委会）为主负责养护与管理工作，各区人民政府（育才生态区管委会）和交通运输主管部门在农村公路养护管理上具体履行以下职责:

1．市政府负责我市农村公路的行政管理，其管理职能由市交通主管部门履行。主要职责：执行国家有关农村公路发展的政策法规；负责辖区内农村公路的养护管理考评工作及养护工程从业单位资质的初审指导；监督辖区内农村公路养护工程的招标；对农村公路养护工程下达生产计划和养护资金的使用情况以及生产完成情况进行监督检查和业务指导。

2．市交通运输主管部门所属的公路管理机构主要职责：负责县道的养护管理工作；负责加强乡、村道养护的监督管理和技术指导，组织检查、考核农村公路养护计划执行和养护质量；负责省级养护资金拨付使用管理；完善对下级交通运输主管部门和育才生态区管委会（相关职能部门）的养护管理目标考核机制。

3．各区人民政府和育才生态区管委会是所辖区内农村公路管理养护的责任主体，其管理职能由下设区交通运输主管部门和育才生态区管委会（相关职能部门）履行。主要职责是：执行国家有关农村公路养护发展的政策法规，编制农村公路养护建设性计划并组织实施；监督区公路管理机构的管理养护工作，检查农村公路养护质量；筹集和管理农村公路养护资金；负责管辖范围内乡道和村道的路政管理和路产路权保护；组织协调村委会做好农村公路管养工作。

4．区交通运输主管部门所属的公路管理机构的主要职责：按照有关规定履行农村公路养护管理的主体责任，建立符合本地实际的农村公路管理体制，落实农村公路养护工作机构和人员，完善养护管理资金财政预算保障机制。具体承担乡道和村道的日常养护管理工作，建立健全农村公路养护管理工作机制；拟定乡道、村道养护建议计划并按照批准的计划组织实施，组织养护工程的招投标和发包工作，对管养线路养护质量进行检查验收；执行和落实各项养护管理任务，做好本辖区农村公路及其附属设施的保护工作；加强路政管理法规的宣传，制定保护农村公路的乡规民约，提高沿线居民爱路护路意识。

五、农村公路养护管理考核

（一）市交通运输主管部门和公路管理机构应当建立健全农村公路养护质量检查、考核和评定制度，考核评定采取日常检查考评和定期检查、不定期检查考评。

定期检查考评：每半年农村公路养护管理工作检查，由市农村公路养护管理工作领导小组组成检查组对农村公路养护管理半年工作实施一次系统全面的检查，并筛选出最终参加省交通运输厅年检的路线；

不定期检查考评：市有关领导和相关部门平时深入基层对各区和育才生态区管委会农村公路养护管理及年度生产计划的实施情况所进行的检查、抽查、调研，以及平时要求上报的有关材料、报表是否按时、准确等进行考评。其考评结果作为年度考评依据之一；

日常检查考评：市交通运输主管部门及公路管理机构组织工程技术人员每月底对各区和育才生态区管委会养护线路进行检查验收。如连续两个月未完成养护指标任务，且考评结果差的单位由市政府或市交通运输局进行通报。

（二）农村公路检查考核的主要内容既要考核公路养护外业各项指标，又要考核内业规范化管理各项工作，总评实行量化考评，按照百分制进行评分，具体由市交通运输主管部门制订养护质量评定表。其中：养护质量考评得分权重为60％，养护管理考评得分权重为40％。

养护质量考评内容：分路基、绿化、路面、桥涵、安保五个方面，采取评分方式，总分100分；

养护管理考评内容：以各区公路养护机构和育才生态区管委会相关职能部门为考评对象。内容分机构设置、养护管理模式、内业管理等三个方面，采取评分方式，总分100分。

（三）各区人民政府和（育才生态区管委会）必须将农村公路养护管理列入议事日程，纳入年度考核目标，并列入有关责任人考核范围，如年终全省农村公路检查评比结果差的单位，由市交通运输主管部门或者由其向市政府建议将予以全市通报批评。各区交通运输主管部门和育才生态区管委会（相关职能部门）要按照考核内容结合日常考核和年终考核情况，搞好自检评比和综合评定工作。

六、农村公路养护资金管理

1．各区政府、育才生态区管委会应当按照国家有关规定，根据农村公路养护和管理的实际需要，安排必要的公共财政预算，保证农村公路养护管理需要，并随农村公路里程的增加，财政资金应当逐年相应增加。鼓励有条件的区政府（育才生态区管委会）通过自行提高补助标准等方式筹集农村公路养护管理资金。

2．市交通运输主管部门主要负责向省交通运输厅上报年度农村公路列养线路建议计划，并编制养护预算。省交通运输厅下达年度养护经费后，由市交通运输主管部门依据农村公路养护考核验收情况向各区交通主管部门和育才生态区管委会（相关职能部门）拨付养护经费。

3．各区交通运输主管部门和育才生态区管委会（相关职能部门）应按照农村公路养护工程相关技术标准和要求按时完成养护任务和指标，每月对管养线路进行自检自评，符合条件后再向市交通主管部门提出验收报告和申请养护经费。同时，应当统筹使用好上级补助的养护资金，实行独立核算，专款专用，禁止截留、挤占或者挪用，建立健全农村公路养护资金使用管理制度，规范资金的使用和管理，并努力提高养护资金使用效益，并使用情况接受审计、财政等部门的审计和监督检查。

七、农村公路路政管理

路政管理要坚持“管养一体、综合治理、预防为主，依法治路”的原则，认真贯彻执行《中华人民共和国公路法》《公路安全保护条例》《海南省公路条例》《路政管理规定》等有关规定，防止路产路权受非法侵害。

1．我市农村公路县道的路政管理由市交通主管部门所属的公路管理机构按有关规定执行；乡、村道的路政管理由各区所属的交通主管部门和育才生态区管委会（相关职能部门）按有关规定执行，各级交通主管部门和公路管理机构要结合实际，建立健全各项管理制度，加强路政管理队伍建设，提高路政管理人员执法水平，严格管理，维护好路产路权，保障农村公路安全、完好和畅通。

2．各区和育才生态区管委会交通主管部门和公路管理机构做好本辖区农村公路及其附属设施的保护工作。一是采取有效措施管理和保护农村公路，检查、制止各种侵占、损坏公路、公路用地、公路附属设施及其他违反《公路法》规定的行为；二是加强路政管理法规的宣传，制定保护农村公路的乡规民约，提高沿线居民爱路护路意识；三是按有关规定定期进行路况巡查，如发现突发损坏、交通中断或者路产路权案件等影响公路通行情况时，及时按有关规定处理和上报。农村公路发生严重损坏或中断时，各级交通运输主管部门和公路管理机构应当在当地政府的统一领导下，组织及时修复和抢通。难以及时恢复交通的，应当设立醒目的警示标志，并告知绕行路线。

3．各区交通运输主管部门和区公路管理机构应在区政府统一领导下，大力整治农村公路路域环境，加强绿化美化，逐步实现田路分家、路宅分家，努力做到路面整洁无杂物，排水畅通无淤积，打造畅安舒美的农村公路通行环境。

4．加大农村公路治超力度。治超工作是从源头上保护农村公路不被破坏的有力保障。各级交通主管部门要坚持把农村公路治超工作作为全市治超工作的深化和延伸，根据农村公路技术等级，科学设置限载、限高、限宽等固定设施，有效防止超限、超高、超宽、超长标准的车辆在农村公路上行驶。要合理调整治超检测站点布局，在重要农村公路入口处派驻路政执法人员；根据农村公路四通八达的特点，进一步加大流动治超检测力度，重点查处超限车辆绕行农村公路等违规行为，严厉打击严重违法超限超载运输行为。要加强治超监控网络建设，着力扩大农村公路监控覆盖面，消除监管盲区。同时要强化源头监管，对砂石场、石料场和货物集散地等源头地点，推行专人派驻制度，切实将超载超限行为消除在萌芽状态。

5．各区人民政府（育才生态区管委会）应当按照《公路法》《公路安全保护条例》《海南省公路条例》的有关规定组织划定农村公路用地和建筑控制区。农村公路两侧建筑控制区按《公路法》规定界线管理。任何单位和个人不得在控制区内修建建筑物和设置交通以外的其它标志，不得在公路和公路用地范围内摆摊设点，堆放物品，倾倒垃圾，设置障碍，挖沟引水或挖坑取土等。所有涉及农村公路（乡、村道）包括挖掘公路、埋设管线、敷设电缆设施等现由市级交通主管部门审批的事项，自本方案下发之日起全部下放至各区（育才生态区管委会）依法行使审批权限。

6．农村公路行使行政许可、行政处罚、行政强制等职权，其中：县道的职权由市交通主管部门依法实施决定，乡、村道的职权由各区（育才生态区管委会）依法实施决定。
