# 三亚市交通运输局关于周士钧等同志职务名称更改的通知

局机关各科室、各事业单位、三亚市公共交通集团有限公司：

三亚市交通运输局已批复同意三亚广达公共交通有限公司更名为三亚市公共交通集团有限公司，市交通运输局决定：

原三亚广达公共交通有限公司总经理周士钧同志的职务名称，随机构更名更改为三亚市公共交通集团有限公司总经理；

原三亚广达公共交通有限公司副总经理张华叔同志的职务名称，随机构更名更改为三亚市公共交通集团有限公司副总经理；

原三亚广达公共交通有限公司副总经理邢维佳同志的职务名称，随机构更名更改为三亚市公共交通集团有限公司副总经理；

原三亚广达公共交通有限公司副总经理江朝政同志的职务名称，随机构更名更改为三亚市公共交通集团有限公司副总经理。

三亚市交通运输局

2019年1月15日
