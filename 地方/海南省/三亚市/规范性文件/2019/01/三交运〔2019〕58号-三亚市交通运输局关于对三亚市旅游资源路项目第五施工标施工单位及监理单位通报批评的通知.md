# 三亚市交通运输局关于对三亚市旅游资源路项目第五施工标施工单位及监理单位通报批评的通知

三交运〔2019〕58号

三亚市交通运输局

关于对三亚市旅游资源路项目第五施工标

施工单位及监理单位通报批评的通知

六大工程各参建单位：

经2018年12月28日省交通运输厅“四好农村路”综合考评检查、2019年1月15日我局在建项目安全生产大检查发现，三亚市旅游资源路项目第五施工标段工程现场施工质量、安全管理工作存在较多问题，施工管理较为混乱，责令其即时加强整改。但直至1月24日省六大办检查组检查，该标段工程施工安全、质量管控方面仍存在较多问题：

一、该标段沿线施工路段设置的安全警示标牌屈指可数，且未设减速（限速）、导向等可夜间反光的安全警示标志，尤其大部分路中电杆未贴反光条和设置安全警示标志，对道路交通安全影响较大；部分拼宽路段路槽安全防护不规范、不到位，并且不应采用打设钢筋系红绳连结作为简单的安全警戒，裸露的钢筋头也存在一定的安全隐患；部分急弯陡坡路段的临边安全防护缺失或设置的构造及强度不符合安全要求；现场文明施工管控差、不规范，部分路段扬尘污染严重，未安排道路清扫及洒水。

二、施工单位施工内业资料和监理单位平行抽检资料不规范、不完整，缺漏内容较多，尤其是有关工程的试验检测资料不齐全。

三、K57+400—K57+430拼宽段底基层有落叶和少量积土未清扫干净，以及未适当进行洒水湿润，局部级配碎石松散未处理便进行混凝土基层浇筑施工,且未安排试验人员检查混凝土来料坍落度及制作混凝土试件；部分拼宽段已浇筑混凝土基层的横向施工缝未按设计要求埋设传力杆，横纵向施工缝拉杆、传力杆均未按设计要求涂抹沥青；K56+180处小桥1#台搭板底基层未按设计要求铺设级配碎石并碾压密实，并且该搭板留设的胀缝传力杆不符合设计要求；K51+980拼宽段有20m级配碎石底基层未压实并经监理验收，施工单位便擅自进行基层混凝土模板安装施工；K52+800处级配碎石底基层施工工艺不合理，选配的施工机械不得当，未使用平地机拌和及摊铺，且摊铺碾压时未安排洒水车进行适当洒水湿润，致使局部级配碎石层不均匀、不密实、不平整，易造成基层混凝土厚度达不到设计要求；现场测量员未到位，K51+940处路基或级配碎石底基层顶面标高未经测量、控制不力，在底基层上挖槽嵌入混凝土基层模板导致混凝土基层厚度无法满足设计要求。

鉴于三亚市旅游资源路项目第五施工标段工程施工、监理单位落实安全、质量主体责任不到位，给工程带来质量安全隐患。为切实促进现场管理，惩治不良行为，确保工程质量安全，经研究，决定对三亚市旅游资源路项目第五施工标段工程的施工单位（金光道环境建设集团有限公司）和监理单位（河南省育兴建设工程管理有限公司）进行通报批评，并责令受到通报批评的单位要认真吸取教训，开展好自查自纠，深入分析工作中存在的问题和原因，研究制定切实有效的措施，限3日内抓好整改落实并将整改结果以书面形式（含图片资料）上报我局，否则我局将采取进一步管控措施。

农村公路六大工程是省委省政府、市委市政府全面贯彻落实党中央和国务院以人民为中心的发展思想，实施精准扶贫的重要举措，是一项关乎人民群众切身利益的工程。我市农村公路六大工程的其他施工、监理等单位要引以为戒，严格履职、加强管理、文明施工、规范施工，着力将我市农村公路六大工程打造成良心工程、民心工程、德政工程，为海南省自贸区（港）提供重要的交通基础设施保障。

三亚市交通运输局
