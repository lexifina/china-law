# 三亚市交通运输局关于印发三亚市道路运输行业2019年春节黄金周运力保障及优质服务活动工作方案的通知

三交运〔2019〕62号

三亚市交通运输局关于印发

三亚市道路运输行业2019年春节黄金周

运力保障及优质服务活动工作方案的通知

市道路运输管理处、各道路运输企业：

为更好地迎接2019年春节黄金周的到来，做好春节黄金周期间出租车、公交车、班线车运力保障及优质服务工作，营造安全、优质、快捷的道路运输环境，我局结合实际，制定了《三亚市道路运输行业2019年春节黄金周运力保障及优质服务活动工作方案》。现印发给你们，请认真组织实施。

特此通知。

三亚市交通运输局

2019年1月31日

（此件主动公开）

三亚市道路运输行业2019年春节

黄金周运力保障及优质服务活动工作方案

为更好地迎接2019年春节黄金周的到来，做好2019年春节黄金周期间出租车、公交车、班线车运力保障及优质服务工作，营造安全、优质、快捷的道路运输环境，推进我市道路运输行业的健康发展，结合实际，制定本方案。

一、工作目标

为进一步加强道路运输规范化管理，全面提高从业人员的整体素质，提高道路运输运力保障能力，确保春节黄金周市民和游客的交通出行顺畅，提高服务质量，营造安全、优质、快捷的道路运输环境。

三、时间安排

2019年2月3日-2019年2月11日

四、运力保障

（一）保障出租车运力

1.开展日常运力保障

市出租车协会负责做好全市的出租车运力调度和保障工作。将凤凰机场、火车站划为运力监控重点区域，利用GPS监控区域内的出租车总量及空车数量，在区域运力不足时，通过GPS调度平台发送运力不足信息到周边出租车，引导周边出租车前往该区域营运。例如：机场方面，在客流高峰期，当排队车辆少于20辆时，应立即发布信息到周边引导车辆前往运送旅客。

2.保障高峰时段运力

为了确保凤凰机场、火车站各时段运力充足，避免航班、动车密集时段出现旅客滞留现象，要求客流高峰时段由公司分别安排应急运力，参加各时段的保障工作。市出租汽车协会根据客流情况及时做出应急运力调整。具体如下：

（1）机场：各企业分时段储备应急运力

出租车企业根据每日航班到达高峰时段，安排相应的出租车进入凤凰机场作为应急运力，各出租车企业须在所负责的航班到达时间点内部署相应数量的应急车辆，根据现场客流情况进行实际运力调整。（具体安排见附件1）

（2）火车站：各企业分时段储备应急运力

出租车企业根据每日动车到达高峰期，安排相应的出租车进入火车站作为应急运力，各出租车企业须在所负责的动车到达时间点内部署相应数量的应急车辆，根据现场客流情况进行实际运力调整。（具体安排见附件2）

从2019年2月3日起执行至2019年2月11日截止，如遇到特殊情况另行通知。

3．启动应急车队保障

三亚公共交通集团有限公司已组建应急保障车队（100辆），纳入96789平台管理，2月3日至2月11日期间，每天9点至动车班次结束，由三亚公共交通集团有限公司安排30辆应急保障车停放在指定位置待命，一旦待命车辆少于30辆时要及时补充，确保待命车辆不少于30辆。市道路运输管理处根据需求调度车辆到特定区域通过智能化的调度方式实现电话叫车+网络+手机APP等多样形式完成点到点服务，面对面下单，为乘客提供便捷的乘车方式进行运力保障。乘客只能通过微信等电子支付方式完成快捷支付。

（二）建立公交运力保障机制

1.市区公交车运力保障

各经营市区公交线路的企业要科学合理编排公交班次，严格按照规定时间、班次发班，教育驾驶员遵章行驶，严格按照规定上下客；督促各公交企业要确保各公交线路所配置的运力全部投入运营；因特殊情况，造成市区公交车辆无法正常营运，公交运力不能满足市民、游客出行需求时，由三亚公共交通集团有限公司负责调配公交车辆到市区运营。

2.延伸调整公交线路

春节黄金周期间，部分路段、景点游客较多，通过合理调整公交运力、延伸公交线路，来解决市民的出行问题。

3.凤凰机场公交车运力保障

凤凰机场公交运力出现不足时，由三亚公共交通集团有限公司负责调度车辆及时输送客人。

4.火车站区域公交车运力保障

火车站区域公交运力出现不足时，由三亚公共交通集团有限公司负责合理调配公交车辆及时输送乘客，途经火车站的公交线路须保障至火车站最后一班动车乘客到达。

5．旅游景点运力保障

各景区、景点出现运力不足时，由各公交企业对旅游景点实行分点保障，确保不出现游客滞留现象。三亚公共交通集团有限公司负责天涯海角、蜈支洲岛、海棠湾免税店、大小洞天、亚龙湾，无乘客滞留现象；三亚怡兰公共交通有限公司负责南山寺。各公司每天必须提前调配3辆公交车放置到所负责的景点，在交通拥堵时，迅速进行应急保障，避免游客滞留。

6.设立南山寺摆渡点

根据市委市政府的部署，为保障南山寺景区春节期间游客出行顺畅，2月4日至2月10日（即除夕至初六），在崖州区创意产业园设立公交摆渡点，由三亚市公共交通集团有限公司安排60辆公交车辆作为摆渡车辆，另外，由该公司再储备20辆应急保障车。车辆调度由崖城运管所负责，责任人林霖（崖城运管所副所长）。

（三）建立班线运力保障机制

1.建立班线加班应急运力信息库，提前做好应急运力储备。 春节黄金周期间市县际和市县内班线客运加班运力的储备车辆，按照《海南省班车客运加班管理办法（试行）》（琼道运发[2013]195号）要求，建立应急加班班线车辆信息库。需要加班时由三大队组织安排车辆输送旅客。

2.建立班线应急运力调派制度。市县际班线加班严格按照《海南省班车客运加班管理办法（试行）》及《海南省道路运输局关于认真做好2019道路春运工作的通知》（琼道运发{2019}13号）的要求，进行组织管理和调派，由驻站办进行统筹安排。市内农村客运班线出现运力不足时，由三亚公共交通集团有限公司调配车辆进行保障。

五、优质服务活动

（一）公交车、出租车优质服务

为给广大乘客提供“安全、舒适、优质、便捷”的公交、出租车出行环境，营造欢乐、祥和的节日气氛，组织各公交、出租车企业在春节黄金周期间开展优质服务活动（详见附件3），具体如下：

1.车容车貌方面：各企业在节前全面清洗所有参运车辆，确保车辆外观整洁，车厢内干净无异味。

2.文明行车、文明用语：驾驶员行车途中不闲谈、不吸烟、不嚼槟榔、不吃东西、不拨打接听手持电话；司乘人员务必注意待客热情、着装规范、语言文明。

3.公交车厢优质服务活动：春节黄金周期间，公交车上司乘人员必须披挂绶带，积极开展维护乘车秩序、引导乘客为老弱病残孕让座、为乘客解决乘车难等服务。

4.设点开展优质服务活动：各公交、出租车企业抽调人员在凤凰机场、火车站、汽车总站等区域，设点开展为乘客提供乘车咨询、为乘客拦车、为乘客提拿行李等优质服务活动。出租车协会负责印制宣传资料、提供活动桌椅、统一安排活动相关事宜，各企业要保障至少工作人员2名到每个优质服务点开展活动。

（二）汽车站优质服务

各班线车企业要树立“以人为本”的服务理念，为公众提供便捷优质的服务。具体如下：

1.各班线运输企业在春节黄金周前要对所属车辆和车站环境卫生进行一次集中整治，做到车容车貌、车内卫生、站内环境干净整洁，给旅客提供良好的出行环境。

2.客运从业人员要着装整洁、使用文明用语、提供微笑服务，为广大旅客提供优质服务，树立交通行业良好形象。

3.客运站要采取增设售票窗口、延长售票时间、提前预售票、联网售票等多种措施，并及时发布运输动态信息，为旅客购票提供便利条件。

4.各班线企业要在春节黄金周期间实行24小时值班制度，及时配合投诉中心做好旅客投诉处理工作。

六、工作要求

（一）各客运企业要高度重视春节黄金周运力保障工作，确保责任到位、人员到位、措施到位、车辆保障到位，司乘人员要统一着装，佩戴领带。

（二）各公交企业要确保所有公交车辆严格按照规定线路、班次及首末班发车时间运营，不串线、不滞站、不甩站、不拒载，依次进入港湾或站点上下客，若有违反，将严格按照《三亚市公交车企业考核办法》的相关规定进行处罚。

（三）各出租车企业要加强出租车驾驶员的职业道德教育，确保出租车驾驶员在营运中不拒载、不绕路、不欺客、不宰客。若有违反，将严格按照《巡游出租汽车经营服务管理规定》进行处罚。

（四）各执法中队要加强对责任车辆流向的监督，确保责任企业安全正常运营，如出现因监管不到位，造成责任企业不按规定运营，造成区域滞留乘客，视情节轻重，给予处分。
