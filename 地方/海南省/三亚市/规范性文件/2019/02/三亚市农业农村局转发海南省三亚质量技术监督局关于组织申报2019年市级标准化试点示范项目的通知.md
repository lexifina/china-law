# 三亚市农业农村局转发海南省三亚质量技术监督局关于组织申报2019年市级标准化试点示范项目的通知

育才生态区管委会，各区农业农村局，局机关各科室，下属各单位：

现将《海南省三亚质量技术监督局关于组织申报2019年市级标准化试点示范项目的通知》（三质技监〔2019〕14号）转发给你们。

请各单位高度重视，积极组织，认真遴选，安排辖区内符合条件的企业向三亚质监局进行申报。

附件：海南省三亚质量技术监督局关于组织申报2019年市级标准化试点示范项目的通知
