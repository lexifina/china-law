# 三亚市林业局关于三亚吉阳（三亚东）220千伏输变电新建工程项目办理林地审核的通告

关于三亚吉阳（三亚东）220千伏输变电

新建工程项目办理林地审核的通告

为做好三亚吉阳（三亚东）220千伏输变电新建工程项目办理林地审核和林业相关手续工作，根据2015年2月15日国家林业局令第35号下发的《建设项目使用林地审核审批管理办法》第十一条“县级人民政府林业主管部门对建设项目拟使用的林地，应当在林地所在地的村（组）或者林场范围内将拟使用林地用途、范围、面积等内容进行公示，公示期不少于5个工作日。”及有关法律法规规定。现将有关情况公告如下：

一、项目名称：三亚吉阳（三亚东）220千伏输变电新建工程

二、用途：输变电工程，提高供电能力，保障生产生活用电需求。

三、项目用地范围：三亚吉阳（三亚东）220千伏输变电新建工程项目用地位于三亚市吉阳区安罗村至罗蓬村一线区域。根据《三亚市总体规划（空间类2016年版）2015-2030局部图》，项目拟长期使用土地面积1.1610公顷，其中林地面积0.5837公顷；临时使用土地面积1.4609公顷，其中林地面积1.4393公顷。

按林地权属分

拟长期使用林地面积0.5837公顷。其中：国有林地0.5494公顷（三亚市人民政府0.3617公顷、部队0.1008公顷、南新农场0.0869公顷），集体林地面积0.0343公顷（罗蓬村0.0043公顷、中廖村0.03公顷）；拟临时使用林地面积1.4393公顷，其中：国有林地1.4244公顷（三亚市人民政府0.8947公顷、部队0.3402公顷、南新农场0.1895公顷），集体林地面积0.0149公顷（罗蓬村0.0149公顷）。

按林地利用保护等级分

拟长期使用林地面积0.5837公顷。其中：Ⅱ级保护林地0.5396公顷、Ⅳ级保护林地0.0441公顷；拟临时使用林地面积1.4393公顷，其中：Ⅱ级保护林地1.3351公顷、Ⅳ级保护林地0.1042公顷。

详见：1.《三亚市总体规划（空间类2016年版）2015-2030局部图》塔基用地

2.《三亚市总体规划（空间类2016年版）2015-2030局部图》临时施工便道用地

四、公告期限：5个工作日（2019年2月14日至2019年2月20日）。
