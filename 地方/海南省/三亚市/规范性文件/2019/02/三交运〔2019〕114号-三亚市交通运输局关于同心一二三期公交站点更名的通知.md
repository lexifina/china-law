# 三亚市交通运输局关于同心一二三期公交站点更名的通知

三亚市公共交通集团有限公司、三亚海棠湾公共交通有限公司：

根据《三亚市公交站点设施管理暂行规定》（三府〔2016〕245号）有关公交站点命名的规定，经研究，决定将“同心一二三期”公交站点更名为“市妇幼保健院”。你公司要做好途经公交线路运营车辆腰牌和报站器数据的更新，三亚市公共交通集团有限公司于2019年3月7日前完成公交站牌线路信息的刷新工作。

特此通知。

三亚市交通运输局

2019年2月28日
