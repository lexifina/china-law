# 三亚市教育局转发海南省教育厅关于2019年春节元宵动员广大学生、家长禁放烟花爆竹的紧急通知

各区教科局，市教育局机关及事业单位，市教育局直属学校（幼儿园）：

时值岁末年初，2019年春节和寒假（以下简称“两节”）来临，为切实抓好我市教育系统的安全工作，有效防范和坚决遏制意外事故发生，现将《海南省教育厅关于2019年春节元宵动员广大学生、家长禁放烟花爆竹的紧急通知》（琼教办〔2019〕5 号）转发给你们，请按要求贯彻执行，避免意外事故发生，动员广大师生家属带头禁放烟花、爆竹，营造文明、安全、环保的节日氛围。并将执行情况于2019年3月1日后报到三亚市教育局108室张燕雄处，联系电话：88657800。

三亚市教育局

2019年2月3日
