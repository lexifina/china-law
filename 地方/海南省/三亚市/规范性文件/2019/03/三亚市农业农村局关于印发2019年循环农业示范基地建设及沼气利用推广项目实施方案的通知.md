# 三亚市农业农村局关于印发2019年循环农业示范基地建设及沼气利用推广项目实施方案的通知

育才生态区管委会，各区农业农村局：

为加快推进“美丽乡村”建设进程，促进我市农村人居环境持续变好，助力乡村振兴、创建生态循环示范市，2019年继续大力开展生态循环农业项目建设。我局结合实际，特制定《三亚市2019年循环农业示范基地建设及沼气利用推广项目实施方案》。该方案已经局党组会议讨论通过，现予以印发。

请各单位务必高度重视，安排专人负责并积极配合，主动开展工作，并及时将工作进展情况报送我局农业科技教育科。
