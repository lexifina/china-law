# 三亚市交通运输局关于开通定制公交线路相关事宜的通知

三亚市公共交通集团有限公司：

三亚崖州湾科技城管理局筹备组向我局来文《关于申请开通市区至科技城往返定制公交的函》（科技城筹函〔2019〕24号），经研究，现就有关事项通知如下：

一、开通定制公交线路

（一）同心家园五期至崖州湾科技城

1.停靠站点：同心家园五期、荔枝沟水厂、第一中学、海航学院、三亚火车站、崖州湾科技城。

2.线路走向：同心家园五期—海螺西路—迎宾路—落笔洞路—荔枝沟路—凤凰路—育新路—育秀路—火车站—育秀路—育新路—G98高速—G225(崖城互通）—中央大道—新道街—2号路—崖州湾科技城。

3.线路里程：54公里

4.运行用时：单程约75分钟

（二）同心家园四期至崖州湾科技城

1.经停站点：同心家园四期、财政局、丹州小区、第一中学、海航学院、三亚火车站、崖州湾科技城。

2.线路走向：同心家园四期—迎宾路—凤凰路—育新路—育秀路—火车站—育秀路—育新路—G98高速—G225(崖城互通）—中央大道—新道街—2号路—崖州湾科技城

3.线路里程：51公里

4.运行用时：单程66分钟

（三）友谊派出所至崖州湾科技城

1.经停站点：友谊派出所、海月广场、迎宾花园、财政局、丹州小区、第一中学、海航学院、三亚火车站、崖州湾科技城。

2.线路走向：友谊派出所—金鸡岭街—三亚湾路—迎宾路—凤凰路—育新路—育秀路—火车站—育秀路—育新路—G225(崖城互通）—中央大道—新道街—2号路—崖州湾科技城。

3.线路里程：54公里

4.运行用时：77分钟

二、开通日期与运营期限

2019年3月25日开通同心家园五期至崖州湾科技城、同心家园四期至崖州湾科技城、友谊派出所至崖州湾科技城等3条定制公交线路，试运营期限自线路开通之日起为一年，期满后根据市场实际情况由你公司上报我局调整。

三、运力配置

本次开通3条定制公交线路运力配置，暂时由在线运营的公交车辆调配3辆。

四、票价核定

本次开通3条定制公交线路票价标准由你公司参照市区至崖州湾科技城公交线路票价标准核定。

五、优化30路公交线路（增设鲸世界·海洋馆站点）

优化后停靠站点：亚龙湾公交枢纽站、红土坎村、夏日百货、水利大厦、海月广场、绿海田园、国光滨海花园、西岛、天涯海角、天涯邮政、南山寺、云海台、鲸世界·海洋馆、科技管理局、大小洞天。

六、相关要求

1.同心家园五期至崖州湾科技城、同心家园四期至崖州湾科技城、友谊派出所至崖州湾科技城等3条定制公交线路，实行公车公营管理模式，严禁买断产权挂靠经营或发包经营。待三亚市定制公交线路管理办法出台后，严格按照该管理办法执行。请你公司认真做好线路开通前的各项准备工作，确保线路开通工作顺利实施。本次定制公交线路开通和运力投放运营工作中所引发的各类纠纷及经济责任由你公司自行解决和承担。

2.由你公司与三亚崖州湾科技城管理局筹备组相关工作人员对接确定开通同心家园五期至崖州湾科技城、同心家园四期至崖州湾科技城、友谊派出所至崖州湾科技城等3条定制公交线路的发班时间、收班时间、停靠站点的时间。

3.请你公司对优化30路公交线路于2019年3月27日前完成公交车辆腰牌、公交站牌线路信息、报站器数据的刷新工作。待上述工作完成后，自2019年3月27日首班车起严格按照优化后的停靠站点提供运营服务。

特此通知

三亚市交通运输局

2019年3月25日
