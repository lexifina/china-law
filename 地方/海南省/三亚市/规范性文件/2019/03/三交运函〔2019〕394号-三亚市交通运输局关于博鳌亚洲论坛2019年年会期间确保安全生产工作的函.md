# 三亚市交通运输局关于博鳌亚洲论坛2019年年会期间确保安全生产工作的函

三交运函〔2019〕394号

三亚市交通运输局

关于博鳌亚洲论坛2019年年会期间

确保安全生产工作的函

各参建单位:

为保障做好博鳌亚洲论坛2019年年会期间的安全生产工作，请各在建单位严格按照以下要求执行:

一、各参建单位严禁于3月22日起至3月30日止对各工作面进行开挖作业，防止挖断光缆及其它通信设施，确保各电缆、光缆畅通;

二、各参建单位要加大力度整治各涉及红线范围内的环境卫生，要确保干净、整洁，黄土部分要用绿网铺盖;

三、各参建单位要加强安全生产工作，确保博鳌亚洲论坛2019年年会期间安全保障。

此函。
