# 三亚市人口和计划生育领导小组办公室关于下发2019年度社会抚养费征收标准的通知

三人口领导小组办〔2019〕2 号

三亚市人口和计划生育领导小组办公室

关于印发2019年度社会抚养费征收标准的通知

各区人民政府，育才生态区管委会：

为了规范我市征收社会抚养费工作，根据《海南省人口与计划生育条例》有关规定和三亚市统计局提供的2018年度全市城镇常住居民人均可支配收入和农村常住居民人均可支配收入的数据，制定《三亚市2019年度社会抚养费征收标准》，现将该征收标准印发给你们，请遵照执行。

附件：《三亚市2019年度社会抚养费征收标准》
