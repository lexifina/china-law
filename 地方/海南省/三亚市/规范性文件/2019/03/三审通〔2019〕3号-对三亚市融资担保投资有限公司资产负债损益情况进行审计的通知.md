# 对三亚市融资担保投资有限公司资产负债损益情况进行审计的通知

三审通〔2019〕3号

三亚市审计局

关于对三亚市融资担保投资有限公司

资产负债损益情况进行审计的通知

三亚市融资担保投资有限公司:

根据《中华人民共和国审计法》第20条的规定和2019年审计项目计划,我局决定派出审计组,自2019年3月11日起,对你单位资产负债损益情况进行审计,有关审计事项延伸审计至有关单位。请予积极配合,并提供有关资料(包括电子数据资料)和必要的工作条件。

审计组组长:董家宏

组员:邓伶俐(兼廉政监督员)、丁先堂、蔡瑞敏

附件:三亚市审计局关于审计纪律的规定

三亚市审计局

2019年3月7日

(此件主动公开)
