# 关于对三亚市2019年扶贫政策执行和财政扶贫资金使用绩效进行专项审计调查的通知

三审通〔2019〕4号

三亚市审计局

关于对三亚市2019年扶贫政策执行

和财政扶贫资金使用绩效进行专项

审计调查的通知

市各相关单位:

根据《中华人民共和国审计法》第二十七条规定和我市2019年审计项目计划,我局决定派出审计组,自2019年3月13日起,对三亚市2019年扶贫政策执行和财政扶贫资金使用绩效进行专项审计调查,必要时将追溯到相关年度或者延伸调查有关单位。请予以配合,并提供有关资料(包括电子数据资料)和必要的工作条件。

审计组组长:邢福波

组员:黄小建(兼廉政监督员)叶杰文郑岚月

陈华欧黄实旺吴樾炫刘玉兴卓杨帆

陈薇薇郑帮伟

附件:三亚市审计局关于审计纪律的规定
