# 关于对三亚市实施乡村振兴战略产业发展资金安全绩效进行专项审计调查的通知

市各相关单位:

根据《中华人民共和国审计法》第二十七条规定和我市2019年审计项目计划,我局决定派出审计组,自2019年3月18日起,对三亚市实施乡村振兴战略产业发展资金安全绩效进行专项审计调查,必要时将追溯到相关年度或者延伸调查有关单位。请予以配合,并提供有关资料(包括电子数据资料)和必要的工作条件。

审计组组长:黄小建

组员:邢福波(兼廉政监督员)叶杰文郑岚月

陈薇薇郑帮伟
