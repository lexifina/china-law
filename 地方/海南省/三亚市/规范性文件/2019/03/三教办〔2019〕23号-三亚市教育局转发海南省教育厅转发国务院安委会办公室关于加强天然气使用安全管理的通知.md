# 三亚市教育局转发海南省教育厅转发国务院安委会办公室关于加强天然气使用安全管理的通知

各区教育局，市教育局机关及事业单位，市教育局直属学校（幼儿园）：

现将《海南省教育厅转发国务院安委会办公室关于加强天然气使用安全管理的通知》（琼教办〔2019〕1号）转发给你们，并结合海南省安全生产委员会办公室通知精神，提出以下意见，请一并抓好落实：

一、建立和完善安全保障机制。各区各校要提高思想认识，加强组织领导，加大对学校食堂燃气设施设备的投入力度，制定燃气安全使用管理规定，建立健全燃气使用安全责任制和燃气事故应急预案。

二、加强液化石油气使用安全管理。各区各校要加强对学校食堂卫生、燃气安全等方面的监督管理，安排专人负责，定期检查钢瓶、灶具、软管和减压器密封阀等燃气设备，日常检查要建立隐患台账，发现问题，立即解决。

三、加强食堂员工培训和学生安全教育。要加强对食堂员工的燃气安全使用常识教育和安全操作培训。要在宣传栏等醒目位置，张贴燃气爆炸事故图片、安全用气常识等内容，提高学生的燃气安全意识，组织学生开展应急疏散演练，提高学生的应急逃生能力。

四、请按业务分工单抓好落实，并将落实情况 3月5日前汇总局办108室。联系人：张燕雄，联系电话：88657800。

三亚市教育局

2019年2月28日
