# 三亚市交通运输局关于三亚肖旗港客运码头改扩建工程施工图设计的批复

三交运〔2019〕256号

三亚市交通运输局

关于三亚肖旗港客运码头改扩建工程

施工图设计的批复

三亚西岛旅游开发有限公司：

报来的三亚肖旗港客运码头改扩建工程施工图设计审批申请及相关材料收悉。根据交通运输部颁布的《水运工程施工图文件编制规定》（JTS 110-7-2013）并综合黑龙江中北航务勘察设计有限公司出具的《三亚肖旗港客运码头改扩建工程施工图设计文件技术审查咨询报告》及专家评审意见，批复如下：

一、总体评价

（一）根据《港口工程建设管理规定》（交通部令2018年第2号）第二十三条：“对于建设内容简单、投资规模较小的按照备案管理的港口工程建设项目，初步设计和施工图设计可以合并设计，深度应当达到施工图设计要求”。本工程初步设计和施工图设计合并设计，符合规定要求。

（二）本工程施工图设计文件，达到了港口工程施工图设计规定的深度要求，内容较完整，图纸基本齐全，可作为施工依据。

二、工程建设规模

本工程位于三亚湾肖旗港大兵河入海处，工程拟建7座突堤码头，每座突堤码头两侧均布置1个靠船泊位，共14个泊位（其中，高速客船泊位12个，游艇泊位2个）。水工结构包含4座55.3米高桩梁板码头，2座52.3米浮码头，1座32.5米浮码头。配套液压升降桥、活动钢引桥、供水、供电、通信、控制、消防等设施设备。本项目液压升降桥为设备采购，不在本次审查范围内。

三、总平面布置方案

本项目使用原有码头岸线231米，保留西侧端部原泊位1个。在拆除原有的浮码头后，在211米范围内连续布置7座突堤码头（1#~7#码头），每座突堤码头由已建的高桩梁板平台与后方陆域连接。1#~4#突堤码头长57.3米、宽5米，布置8个泊位，以399客位高速客船为设计代表船型，但相邻突堤码头间停泊水域不能同时停靠2艘399客位高速客船。5#、6#突堤码头长54.3米、宽3.3米，布置99客位高速客船泊位4个。7#突堤码头长34.5米、宽3.3米，布置70尺游艇泊位2个。

码头后方已建高桩梁板平台标高为3.7米（采用国家85高程基准，下同），停泊水域底高程为-3.3米，港内航道及回旋水域底高程为-2.8米。

四、水工建筑物

（一）1#~4#突堤码头

1#~4#突堤码头采用高桩梁板结构型式。按可停靠399客位高速客船设计，码头顶高程为3.7米。码头共分2个结构段，分别长26.58米、27.45米，中间隔空3.27米以安装接船平台。27.45米结构段考虑液压升降桥安装布置。码头桩基采用φ700钢管桩，共布置10榀排架，每榀排架布置2根直桩。

（二）5#~7#突堤码头

5#~7#突堤码头采用浮码头结构型式。5#、6#突堤码头按可停靠99客位高速客船设计，7#突堤码头按可停靠70尺游艇设计。浮码头均采用桩基固定方式，定位桩采用φ700钢管桩。主浮桥采用C45细石混凝土浇筑成型，浮桥内部用聚苯乙烯做内模提供浮力。浮码头均由活动钢引桥与后方已建高桩梁板平台连接。

五、游客上下工艺

原则同意本工程游客上下工艺方案。

六、工程预算

本工程预算为1963.53万元，经费来源为企业自筹。

七、其他

（一）请你单位工程建设时严格执行港口工程技术规范及国家有关规范标准，按照批准的施工图设计文件进行施工，做好施工期间安全组织和管理，确保工程建设质量和安全。按照国家安全生产、环境保护“三同时”和交通运输部《公路水运工程安全生产监督管理办法》的要求，严格落实安全、环境保护、消防、节能岸电、污染物接收设施等相关措施。

（二）请你单位按有关规定办理开工前相关手续，具备条件后尽快开工建设。工程建设中，重大施工图设计变更报我局审批。

（三）本批复有效期1年，在有效期内未开工建设，本批复自动失效。

三亚市交通运输局

2019年4月19日
