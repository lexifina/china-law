# 三亚市教育局转发海南省教育厅关于进一步落实在全省教育系统普遍建立法律顾问制度的通知

各区教育局，市直属学校（幼儿园）：

现将《海南省教育厅关于进一步在全省教育系统普遍建立法律顾问制度的通知》（琼教法〔2019〕39号）转发给你们，请各区各校按照文件精神，高度重视，认真贯彻落实，并于4月23日前将本单位现有已聘用的法律顾问花名册，报送市教育督导室。尚未实现法律顾问全覆盖、尚未聘用法律顾问的区教育行政部门和学校，要在2019年6月18日前完成法律顾问聘用工作，并于6月21日前将工作总结及学校的法律顾问花名册报市教育督导室。

联系人：蓝伟仕，联系电话：[电话略]，邮箱：88213055@163.com。

三亚市教育局

2019年4月16日
