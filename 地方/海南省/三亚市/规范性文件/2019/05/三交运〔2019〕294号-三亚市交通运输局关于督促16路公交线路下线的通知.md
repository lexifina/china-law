# 三亚市交通运输局关于督促16路公交线路下线的通知

市道路运输管理处：

根据《三亚市人民政府关于同意重新投放16路公交车辆的批复》（三府函〔2013〕673号）、《三亚市交通运输局关于同意16路68辆公交车辆重新投放的批复》（三交运〔2013〕550号）精神，三亚怡兰公共交通有限公司经营管理的16路（港务局至南山）公交线路，经营权期限将于2019年5月21日届满。从2019年5月21日起，请你处按相关规定督促16路公交线路上经营的公交车下线。

特此通知。

三亚市交通运输局

2019年5月6日
