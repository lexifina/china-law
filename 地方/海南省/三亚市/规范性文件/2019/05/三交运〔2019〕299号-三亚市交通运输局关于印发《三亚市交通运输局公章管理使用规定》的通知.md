# 三亚市交通运输局关于印发《三亚市交通运输局公章管理使用规定》的通知

局机关各科室、局属各事业单位：

为进一步规范公章管理使用，使公章的管理使用更加制度化、规范化，保证公章的权威性、严肃性，确保公章管理使用合法、合规、安全。现将《三亚市交通运输局公章管理使用规定》印发给你们，请按照规定要求，认真贯彻执行。

三亚市交通运输局

2019年5月8日

（此件主动公开）

三亚市交通运输局公章管理使用规定

一、局办公室负责局公章的保管和使用，使用印章须履行登记手续，并由印章管理人认真审阅用印件内容。

二、向上级报送的文件、资料等需要使用公章的，必须经单位主要负责人签字或已授权的其他负责人签字。

三、向平级或下级报送的文件、资料等需要使用公章的，必须经各分管领导签字或分管领导授权办公室主任签字。

四、介绍信、单位证明等需要使用公章的须经办公室主任同意。

五、公章禁止带出办公室外使用。

六、电子公章的使用管理参照本规定执行。

七、本规定自印发之日起实施。
