# 三亚市交通运输局关于优化崖州湾科技城定制公交线路的批复

三亚市公共交通集团有限公司：

来文《关于优化崖州湾科技城定制公交线路的请示》（三公交集〔2019〕75号）收悉。鉴于该三条定制线路实际客流与最初需求客流数量差距较大，为避免公共交通资源浪费，节约线路车辆运营成本，经研究，现批复如下：

一、同意优化“同心家园五期至崖州湾科技城”公交线路。

优化后停靠站点：

同心家园四期、市总工会、同心家园五期北门、同心家园五期南门、君和君泰、崖州湾科技城。

二、同意取消“同心家园四期至崖州湾科技城”和“友谊派出所至崖州湾科技城”两条定制公交线路。

三、你公司于2019年5月20日前完成公交车辆腰牌、公交站牌线路信息、报站器数据的刷新工作。待上述工作完成后，自2019年5月20日首班车起严格按照优化后的停靠站点提供运营服务。

三亚市交通运输局

2019年5月16日
