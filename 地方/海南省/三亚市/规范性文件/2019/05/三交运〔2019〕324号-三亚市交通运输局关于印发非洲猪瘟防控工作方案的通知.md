# 三亚市交通运输局关于印发非洲猪瘟防控工作方案的通知

局机关各科室、各事业单位：

为落实国家、省、市有关非洲猪瘟疫情防控工作会议精神，扎实做好我市非洲猪瘟疫情防控工作，现将《三亚市交通运输局非洲猪瘟防控工作方案》印发给你们，请认真贯彻执行。

三亚市交通运输局

2019年5月16日

（此件主动公开）

三亚市交通运输局

非洲猪瘟防控工作方案

为贯彻落实省政府、市政府非洲猪瘟防控工作会议精神，切实抓好我市非洲猪瘟防控，严防疫情流入我市，根据《三亚市非洲猪瘟防控工作方案》，结合我局工作实际，制定本工作方案。

一、工作目标

毫不动摇坚持“严防死守”“内防外堵”工作方针，全面强化防控手段，防止疫情通过运输途径传播，切实做好交通运输领域非洲猪瘟防控工作，确保社会安定稳定。

二、组织领导

成立三亚市交通运输局非洲猪瘟防控工作领导小组。成员如下：

组  长：陈凤祥  市交通运输局副局长

副组长：王  强  市交通运输局副调研员

成  员：局机关各科室及各事业单位负责人

领导小组办公室设在运管处，负责落实协调、督办、统计非洲猪瘟防控等日常工作。

三、工作措施与内容

（一）全面开展排查工作。对全市交通运输企业进行全面梳理排查，加强生猪运输工具的监督、检查和登记，强化信息交流互通。积极配合市农业农村局，督促道路运输企业、水上运输企业按照有关法律法规规定承运生猪及其产品，禁止从疫区运出生猪及其产品。

（二）加大宣传力度。局机关各科室、各事业单位要加大交通运输行业的非洲猪瘟防控知识宣传力度，增强防控信心，确保行业稳定。

（三）加强行业监督管理力度。局运输服务科要协调铁路运输企业做好检疫、消毒、餐厨剩余物处理等工作，协调市邮政管理局加强邮件快件安全检查。

运管处、港航处要按省、市防控非洲猪瘟疫情的文件精神和工作部署要求，从源头上加强对运输生猪及其产品的管理，禁止运输经检疫的生猪及其制品。确保疫情不通过运输工具进行扩散、传输，确保疫情不通过运输途径进行扩散。

（四）加强交通运输行业执法检查。全面开展非洲猪瘟防控等动物疾病防控工作，加大对辖区运输生猪及其产品的车辆、船舶等运输工具的执法检查力度，一旦发现有病猪、死猪等异常情况，立即报告市农业农村局、公安等相关部门。

（五）做好应急车辆准备工作。运管处做好应急运输车辆储备工作，有需要时做好防疫人员、物资的运输保障工作。

（六）配合相关部门开展联合执法。运管处、地方公路站要根据局非洲猪瘟防控工作领导小组的安排，积极配合市农业农村局、公安局等相关部门，设立临时检查点，将联合执法和非洲猪瘟防控工作有机结合起来，坚决防范和有效遏制非洲猪瘟通过交通运输领域在我市范围内进行传播、扩散。

四、工作要求

（一）提高思想认识。各科室、事业单位要高度重视非洲猪瘟应急防控工作，根据自身职责，做好相关工作，切实落实联防 联控职责，确保各项工作取得实效。

（二）加强组织领导。各科室、事业单位要加强管理，听候调遣，政令畅通，确保非洲猪瘟防控工作得到落实。

（三）强化工作纪律。各科室、事业单位要切实履行做好行业管理职责，加强信息的报送和通报，全力以赴做好非洲猪瘟防控工作，严防因责任落实不到位，工作人员不履行职责导致延误疫情处置不力局面。
