# 三亚市交通运输局关于28路和34路公交线路增加公交站点的通知

三亚市公共交通集团有限公司：

为合理设置公交站点，方便市民和游客乘坐公交车，经研究，有关事项通知如下：

一、28路（凤凰岛至蜈支洲岛）和34路（客运西站至海棠湾免税广场）公交线路增加停靠响土村”和“榆红村”公交站点。

二、请你公司务必做好28路和34路公交车辆的腰牌及报站器的更新工作，自2019年5月29日起按照新增的停靠站点提供运营服务。并于2019年5月29日前完成公交站牌线路信息的刷新工作。

三亚市交通运输局

2019年5月23日
