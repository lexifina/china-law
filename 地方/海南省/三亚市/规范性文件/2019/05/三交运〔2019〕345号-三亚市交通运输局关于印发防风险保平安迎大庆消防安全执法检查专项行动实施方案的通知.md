# 三亚市交通运输局关于印发防风险保平安迎大庆消防安全执法检查专项行动实施方案的通知

三交运〔2019〕345号

三亚市交通运输局

关于印发防风险保平安迎大庆消防安全执法

检查专项行动实施方案的通知

局机关各科室、各事业单位、重点项目组：

根据《三亚市安全生产委员会关于印发“防风险保平安迎大庆”消防安全执法检查专项行动方案的通知》（三安委会〔2019〕3号）文件要求，我局结合工作实际，制定了《三亚市交通运输局防风险保平安迎大庆消防安全执法检查专项行动实施方案》，现印发给你们，请认真贯彻落实。

三亚市交通运输局

2019年5月24日

（此件主动公开）

三亚市交通运输局

防风险保平安迎大庆消防安全执法

检查专项行动实施方案

为全力做好新中国成立70周年消防安全保卫工作，有效防范化解重大安全风险，坚决遏制群死群伤火灾事故。根据《三亚市安全生产委员会关于印发“防风险保平安迎大庆”消防安全执法检查专项行动方案的通知》（三安委会〔2019〕3号）要求，特制定我市交通运输行业实施方案。

一、工作目标

深入贯彻落实习近平总书记关于安全生产和消防安全工作的重要指示精神，坚持以人民为中心的发展思想，按照“属地主导、部门联动”总体原则，突出问题导向，强化底线思维，深入开展消防安全检查工作，全面排查整治火灾隐患，坚决预防和遏制重特大火灾尤其是群死群伤火灾的发生，保障群众人身、财产安全，维护三亚市交通运输行业的平稳发展，确保交通运输行业消防安全形势稳定。

二、实施步骤

根据我市交通运输行业实际情况，此次综合治理自2019年5月份开始至2019年10月完成，分为三个阶段，具体安排如下：

（一）部署阶段（2019年5月31日前）。各单位要结合工作实际，制定实施方案，分解排查任务,明确整治责任，细化工作措施，深化到监管单位进行宣传，召开专门工作会议，对专项整治工作进行全面部署，细化重点检查内容、方法和整治标准，开展针对性治理。

（二）排查阶段（6月1日—10月10日）。各单位要组织力量对监管企业仓储场所进行一次全面排查，摸清底数和隐患情况，认真逐一进行登记造册，完善基本台账。各单位要对曾经发生过火灾和已经发现的隐患的仓储场所作为排查重点。道路运输管理处要对海汽车站物流仓储场所进行全面排查；市港航管理处要对码头的仓储场所进行排查；公路科、运输服务科、项目组、港航处、公路站要对各施工单位的仓储场所进行排查。务必要做到排查到位，做到不漏一处、不漏一个重大隐患，对一时不能整改的，要制定整改期限，坚决完成整改。

（三）总结验收阶段（10月10日—10月18日）。各单位要对专项行动进行全面分析，开展自查自评，剖析问题，总结经验，建立完善长效管理机制，切实提升火灾防控水平。

三、重点检查的范围和内容

(一)重点检查范围

车站、码头等人员密集场所、交通工程施工工地及办公住宿区、交通物流仓储场所、“两客一危”企业、公交车企业、港口危险品企业等。

(二)重点检查内容

1.车站、码头等人员密集场所消防安全设施是否齐全、消防设施性能是否能正常使用;

2.交通工程施工地是否落实电气化火灾防控，消防安全设施及性能是否齐全良好;工地办公区、住宿区是否存在违规使用易燃可燃材料装修;

3.物流仓储场所是否存在使用易燃可燃材料搭建、装修，是否违规存放易燃易爆物品，消防实施是否齐全及性能良好;

4.“两客一危”、公交车企业是否落实营运车辆消防安全检查，及时发现问题隐患，落实整改;

5.港口危化品企业重点检查内容是否按省厅下发《关于印发交通运输行业危险化学品安全专项整治工作实施方案的通知》相关要求落实;

6.检查企业是否明确消防安全责任人、管理人员及其职责;消防应急专职(兼职)处置队伍能否及时有效处置初起火灾，是否按要求开展消防安全培训、演练;是否落实日常消防检查巡查，并如实登记报告;消防应急等预案是否可行实用;

7.检查企业是否开展宣传教育培训活动，活动是否严格落实;员工是否了解消防相关知识，是否会报警、掌握逃生技能等。

四、工作措施

（一）配合约谈培训工作。各单位要积极参加本地及相关部门组织的消防安全培训，督促企业内部落实消防培训工作。积极配合相关部门做好企业主要负责人集中约谈工作，要对港口危险化学品生产经营企业进行一次集体约谈活动，提高企业落实主体责任意识。

（二）组织自查自改。各单位要对照工作重点内容和要求，组织企业开展“三自主两公开一承诺”活动(自主评估火灾风险、自主检查消防安全、自主整改隐患问题，向社会公开本单位消防安全责任人和消防安全管理人员及其消防安全责任，承诺本单位不存在突出风险隐患，或已经针对突出风险隐患落实有效的防范措施，保障消防安全)。要督促行业企业强化“四个能力”建设和加强从业人员“一懂三会”教育。

（三）集中开展隐患排查整治。各单位要结合行业特点和对照检査重点、内容，不断深入电气化火灾隐患综合治理，开展仓储场所、人员密集场所等消防安全治理“回头看”行动，对行业监管单位开展消防安全专项检查，督促落实消防安全标准化管理。

（四）联合执法活动，重点是未落实“三自主两公开一承诺”活动和行业排查中发现的弄虚作假或存在突出风险隐患的企业。积极配合相关单位对严重失信、隐患久拖不决的单位和责任人员纳入消防安全失信“黑名单”，实施联合惩戒。

（五）做好重大活动保卫。各单位要围绕国庆70周年等重大活动和重要节假日，组织开展针对性的节前消防安全检查和错时检查，加强消防安全各项工作，确保我市交通运输行业消防安全。

五、工作要求

（一）加强组织领导。各单位要充分认识消防安全工作的重要性，把它将其列为目前中心工作。切实加强组织领导，周密部署，细化工作分工，狠抓落实。

（二）密切协作配合。各单位要严格落实《海南省消防安全责任制规定》及相关消防安全工作规定，制定本单位工作方案，部署本部门专项行动工作，积极配合相关单位落实各项联动工作，进一步提升防范化解重大安全风险能力。

（三）强化落地成效。此次专项行动将列入2019年度安全生产和消防工作考核内容。各单位要认真组织实施，强化配合协调，落实齐抓共管，全力做好消防安全防范工作，确保消防安全工作取得实效。

（四）落实信息报送。各单位要严格落实请示报告制度，自觉做到有情况及时请示报告，确保消防安全工作有序推进。请各单位于5月31日前制定专项行动方案；6月12日报自查自改情况；6月至9月的每月15日报月小结；8月20日报集中开展隐患排查整治情况；10月10日前报总结。（联系人及电话：罗海林 88667873）
