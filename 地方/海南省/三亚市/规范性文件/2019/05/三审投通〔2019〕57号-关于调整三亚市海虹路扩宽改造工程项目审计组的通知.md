# 关于调整三亚市海虹路扩宽改造工程项目审计组的通知

市住房城乡建设局:

我局已于2016年6月24日出具了三亚市海虹路扩宽改造工程项目《审计通知书》(三审投通〔2016〕120号),并于同年6月29对三亚市海虹路扩宽改造工程项目进行审计,因你单位提供的资料无法满足审计要求,我局于同年8月5日中止该项目审计。现你单位于2018年11月9日来函(三住建函〔2018〕4587号)重新提请该项目审计,根据审计工作需要,我局现对该项目审计组进行调整,调整情况如下:

审计组组长:范华林

审计组成员:邢增宝郑茹方(兼职廉政监督员)

向奕帆冯松龙敏(鹏信工程项目管理顾问有限公司)

附件:三亚市审计局关于审计纪律的规定

三亚市审计局

2019年5月5日
