# 三亚市教育局转发关于进一步推进兼职法治副校长工作的通知

各区教育局，市直属学校（幼儿园）：

现将《海南省教育厅 海南省普法依法治理领导小组办公室关于进一步推进兼职法治副校长工作的通知》（琼教法〔2019〕

40号）转发给你们，请按照文件要求，结合实际，认真贯彻落实,并于5月23日、6月26日、12月16日前分别将1月至4月法治校园工作情况（包括图片、视频等）、自查自纠工作总结和兼职法治副校长花名册、全年法治校园工作总结（包括图片、视频等）报送市人民政府教育督导室。

三亚市教育局

2019年5月20日
