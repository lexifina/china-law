# 三亚市林业局关于海南省环岛管网文昌--琼海--三亚输气管道工程（三亚市）办理临时使用林地审核的通告

三林〔2019〕151号

三亚市林业局

关于海南省环岛管网文昌--琼海--三亚

输气管道工程（三亚市）办理

临时使用林地审核的通告

为做好海南省环岛管网文昌--琼海--三亚输气管道工程（三亚段）办理临时使用林地审核和林业相关手续工作，根据2015年2月15日国家林业局令第35号下发的《建设项目使用林地审核审批管理办法》第十一条“县级人民政府林业主管部门对建设项目拟使用的林地，应当在林地所在地的村（组）或者林场范围内将拟使用林地用途、范围、面积等内容进行公示，公示期不少于5个工作日。”及有关法律法规规定。现将有关情况公告如下：

一、项目名称：海南省环岛管网文昌--琼海--三亚输气管道工程（三亚市）

二、用途：输气管道工程。

三、项目用地范围：该项目位于三亚海棠湾、南田农场、吉阳区、南新农场、天涯区、市林科院、三亚林场、崖州区一线区域，三亚段拟临时使用林地总面积55.8558公顷，活立木蓄积量1572立方米。

按地类分：乔木林地50.5063公顷、疏林地0.7747公顷、宜林地4.5748公顷。

按林地保护等级分：Ⅱ级保护林地18.1411公顷、Ⅳ级保护林地37.7147公顷。

按森林类别分：一般商品林地37.7147公顷、重点商品林地1.3290公顷、地方公益林地2.4522公顷、国家Ⅱ级公益林地14.3599公顷。

按林地类型分：防护林地16.5639公顷、经济林地29.9843公顷、用材林地4.7328公顷、其他林地4.5748公顷。

按林地权属分：国有林地22.3335公顷，具体为：南田农场5.9429公顷、海棠湾区人民政府0.4210公顷、甘什岭省级森林公园3.9658公顷、南新农场7.7199公顷、三亚市林科院1.4685公顷、南滨农场1.6844公顷、三亚林场0.5005公顷；集体林地33.5223公顷，具体为：海棠区4.9870公顷，吉阳区集体林地10.5920公顷，天涯区13.4888公顷，崖州区4.4545公顷。

详见：三亚市总体规划（空间类2016版）2015-2030局部图（海南省环岛天然气管网文昌--琼海--三亚输气管道工程

四、公告期限：5个工作日（2019年5月16日至2019年5月22日）。
