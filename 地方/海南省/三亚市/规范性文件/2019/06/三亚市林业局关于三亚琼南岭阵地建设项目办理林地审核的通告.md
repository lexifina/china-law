# 三亚市林业局关于三亚琼南岭阵地建设项目办理林地审核的通告

为做好三亚琼南岭阵地建设项目办理林地审核和林业相关手续工作,根据2015年2月15日国家林业局令第35号下发的《建设项目使用林地审核审批管理办法》第十一条“县级人民政府林业主管部门对建设项目拟使用的林地,应当在林地所在地的村(组)或者林场范围内将拟使用林地用途、范围、面积等内容进行公示,公示期不少于5个工作日。”及有关法律法规规定。现将有关情况公告如下:

一、项目名称:三亚琼南岭阵地建设项目

二、用途:军事设施,国防阵地建设。

三、项目用地范围:三亚琼南岭阵地建设项目用地位于三亚市琼南岭。根据《三亚市总体规划(空间类2016年版)2015-2030局部图》,项目拟长期使用土地面积0.0602公顷,均为林地。

按森林类别分:均为国家二级公益林地;

按使用林地类型分:均为防护林地;

按林地利用保护等级分:均为Ⅱ级保护林地;

按林地权属分:均为三亚市人民政府国有。

详见:《三亚市总体规划(空间类2016年版)2015-2030局部图》75737部队琼南岭阵地建设用地

四、公告期限:5个工作日(2019年6月20日至2019年6月26日)。

五、联系方式:

联系单位:三亚市林业局

单位地址:三亚市凤凰路临春岭公园

邮政编码:572000
