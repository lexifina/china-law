# 三亚市交通运输局关于新居派出所公交站点更名的批复

三亚市公共交通集团有限公司：

来文《关于新居派出所公交站点更名的请示》（三公交集〔2019〕99号）收悉。经研究，鉴于城市乐园公交首末站已更名为春园公交首末站，为避免给乘客造成误导，现批复如下：

同意取消“城市乐园”公交站点，将“新居派出所”公交站更名为“春园首末站”。请你公司对3路、22路、40路、45路、52路公交车辆头牌、腰牌、尾牌、报站器及公交站牌线路信息进行更新。

三亚市交通运输局

2019年6月25日
