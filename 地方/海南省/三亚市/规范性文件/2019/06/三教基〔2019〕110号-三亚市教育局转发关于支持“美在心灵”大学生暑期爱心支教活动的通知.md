# 三亚市教育局转发关于支持“美在心灵”大学生暑期爱心支教活动的通知

育才生态区管委会教育科技卫健局，育才中心学校：

为继续做好面向少数民族和贫困地区的爱心支教工作，海南省“美在心灵”大学生支教志愿者协会计划于暑假期间即2019年7月—8月在我省18个市县75所乡村中小学开展支教活动，其中我市育才生态区满地可小学、雅亮小学为此次活动支教学校。

现将《海南省教育厅行政办公室关于支持“美在心灵”大学生暑期爱心支教活动的通知》转发给你单位，请你单位予以支持配合，并做好支教过程中的安全教育与管理工作，确保活动安全、顺利、有序开展。

三亚市教育局

2019年6月21日
