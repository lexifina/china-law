# 三亚市林业局关于省道S314天新线天涯至新宁坡段改建工程（三亚段2标拌合站及预制梁场）项目办理临时使用林地审核的通告

为做好省道S314天新线天涯至新宁坡段改建工程（三亚段2标拌合站及预制梁场）项目办理临时使用林地审核和林业相关手续工作，根据2015年2月15日国家林业局令第35号下发的《建设项目使用林地审核审批管理办法》第十一条“县级人民政府林业主管部门对建设项目拟使用的林地，应当在林地所在地的村（组）或者林场范围内将拟使用林地用途、范围、面积等内容进行公示，公示期不少于5个工作日。”及有关法律法规规定。现将有关情况公告如下：

一、项目名称：省道S314天新线天涯至新宁坡段改建工程（三亚段2标拌合站及预制梁场）项目

二、用途：建设省道S314天新线改建工程TXTJ2标段，配套搅拌站、预制梁场。

三、项目用地范围：该项目位于三亚市育才生态区明善村委会，三亚段拟临时使用林地面积1.6167公顷，活立木蓄积量0立方米。

按林地保护等级分：均为Ⅳ级保护林地；

按森林类别分：均为一般商品林地；

按使用林地类型分：均为经济林地；

按现状地类分：均为宜林地。

按林地权属分：均为国有林地（海南省农垦集团有限公司和乐东保国投资有限公司）。

详见：省道S314天新线TXTJ2标搅拌站、预制梁场临时用地勘测定界图

四、公告期限：5个工作日（2019年7月10日至2019年7月16日）。
