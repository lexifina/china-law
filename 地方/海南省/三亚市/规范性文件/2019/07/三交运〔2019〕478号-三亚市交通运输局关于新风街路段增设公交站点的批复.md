# 三亚市交通运输局关于新风街路段增设公交站点的批复

三亚市公共交通集团有限公司：

来文《关于新风街路段增设公交站点的请示》（三公交集团〔2019〕120号）收悉，经研究，现批复如下：

一、根据道路交通安全法实施条例《第六十三条（二）》中规定，交叉路口、铁路道口、急弯路、宽度不足4米的窄路、桥梁、陡坡、隧道以及距离上述地点50米以内的路段，不得停车，为了确保行车安全，不同意新风街临近三亚湾处增设公交站点。

二、“水利大厦”公交站点整体往解放路方向迁移，距离红绿灯十字路口过近，高峰区易造成交通堵塞，存在安全隐患。

三、三亚湾路段临近新风街交叉口20米处原有设置公交站点，新增设公交站点无必要性。

三亚市交通运输局

2019年7月30日
