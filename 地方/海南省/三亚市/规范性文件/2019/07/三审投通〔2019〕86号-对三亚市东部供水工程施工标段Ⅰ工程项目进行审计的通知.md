# 对三亚市东部供水工程施工标段Ⅰ工程项目进行审计的通知

市海棠湾开发建设有限公司:

根据《中华人民共和国审计法》第二十二条的规定,我局决定派出审计组,自2019年7月4日起,对你单位负责建设的三亚市东部供水工程施工标段Ⅰ工程项目进行审计,必要时将追溯到相关年度或者将对与项目直接有关的设计、施工、监理、供货等单位取得项目资金的真实性、合法性进行调查。请予积极配合,并提供有关资料(包括电子数据资料)和必要的工作条件。

审计组组长:牟春丽

审计组成员:翁娇金(兼职廉政监督员)

何永忠、李柏睿(湖南乐为工程造价咨询事务所有限责任公司)

附件:三亚市审计局关于审计纪律的规定

三亚市审计局
