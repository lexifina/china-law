# 对三亚市2015年制种大县财政奖励资金南繁科研育种保护区农田基础设施改造提升项目（南滨农场）进行审计的通知

三审投通〔2019〕89号

三亚市审计局

对三亚市2015年制种大县财政奖励资金

南繁科研育种保护区农田基础设施改造提升

项目(南滨农场)进行审计的通知

市农业农村局:

根据《中华人民共和国审计法》第二十二条的规定,我局决定派出审计组,自2019年7月12日起,对你单位负责建设的三亚市2015年制种大县财政奖励资金南繁科研育种保护区农田基础设施改造提升项目(南滨农场)项目进行审计,必要时将追溯到相关年度或者将对与项目直接有关的设计、施工、监理、供货等单位取得项目资金的真实性、合法性进行调查。请予积极配合,并提供有关资料(包括电子数据资料)和必要的工作条件。

审计组组长:翁娇金

组员:牟春丽(兼职廉政监督员)

邢增智(华诚博远工程咨询有限公司)

附件:三亚市审计局关于审计纪律的规定

三亚市审计局

2019年7月9日
