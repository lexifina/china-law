# 对三亚市天涯中学建设项目预算执行情况进行审计的通知

市教育局:

根据《中华人民共和国审计法》第二十二条的规定和三亚市2019年度审计项目计划,我局决定派出审计组,自2019年7月26日起,对你单位负责建设的三亚市天涯中学建设项目预算执行情况进行审计,必要时将追溯到相关年度或将对项目直接有关的设计、施工、监理、供货等单位取得项目资金的真实性、合法性进行调查。请予积极配合,并提供有关资料(包括电子数据资料)和必要的工作条件。

主审:陈惠琳(兼廉政监督员)
