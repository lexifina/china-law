# 三亚市交通运输局关于开通大东海至南山寺景区旅游观光巴士线路的批复

三交运〔2019〕539号

三亚市交通运输局

关于开通大东海至南山寺景区旅游观光巴士

线路的批复

三亚市公共交通集团有限公司：

来文《关于开通旅游观光巴士线路的请示》三公交集〔2019〕130号收悉。报市政府同意，现批复如下：

一、同意由你公司开通大东海至南山寺景区旅游观光巴士线路。全程约52公里，拟配置10辆12米级纯电动旅游观光双层巴士，服务时间：8:00-20:00，发车间隔约40分钟。

线路走向：大东海旅游公交枢纽中心—东海路—榆亚路—凤凰路—新风街—三亚湾路—胜利路—迎宾路—三亚湾路—御海路—G225国道—南山寺站。

停靠站点：大东海旅游公交枢纽中心、大东海广场站、图书馆站、水利大厦站、凤凰岛站、海月广场（椰梦长廊）站、三亚湾路西段、京海假日酒店、国光滨海花园站、三亚湾假日酒店站、西岛站、天涯海角站、南山寺站。

二、按照《2018年关于印发三亚市公交成本规制补贴实施方案》（三府办〔2018〕260号）的要求，大东海至大小洞天景区旅游观光巴士线路的经营期限自线路开通之日起为6年，并实行“公车公营”。严禁买断产权挂靠经营，发包经营。

三、上述旅游观光巴士线路双层巴士公交车辆投放运营中所引发的各类纠纷及经济责任由市公交集团自行解决和承担。

四、以上旅游观光巴士线路开通后线路收费标准严格按照市价格主管部门审批的价格执行。

三亚市交通运输局

2019年9月11日
