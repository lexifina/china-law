# 三亚市交通运输局关于开通南边海公交首末站至鸿森医院等7条公交线路和取消46路公交线路的批复

三交运〔2019〕553号

三亚市交通运输局

关于开通南边海公交首末站至鸿森医院等

7条公交线路和取消46路公交线路的批复

三亚市公共交通集团有限公司：

来文《关于2019年三亚公交线网优化改革实施方案的请示》（三公交集〔2019〕107号）和《关于开通海棠小学至雅安村、三公里村至大茅村2条公交线路的请示》（三公交集〔2018〕90号）收悉。报市政府同意，现批复如下：

一、同意由你公司开通南边海公交首末站至鸿森医院公交线路，全程约23公里，线路编号：29路，配置15辆8米级纯电动公交车辆。

线路走向：南边海公交首末站—南边海路—榆亚路—凤凰路—春光路—河东路—新风街—解放路—回新路—凤凰路—乡道—鸿森医院。

停靠站点： 南边海公交首末站、南边海社区、南边海市场、下洋田社区、山水国际、市中医院、春光路口、市民百果园、春河小区、丰兴隆、榕根社区、创业大厦、市人民医院、明珠广场、友谊路口、市中心医院、第四中学、金水湾、世嘉公寓、回新村、双品学校、阅海观山、槟榔村口、妙林村口、妙联学校、妙林农贸市场、新联官长村路口、新联小学、凤凰华庭、凤凰山居、鸿森医院。

二、同意由你公司开通三公里村委会至凤上村公交线路。全程约8公里，线路编号：崖州10号，配置2辆纯电动微型公交车辆。

线路走向：三公里村委会—Y081乡道—凤上村。

停靠站点：三公里村委会、坡加村、凤上村。

三、同意由你公司开通红塘村委会至饭粒小组公交线路。全程约6公里，线路编号：天涯4号，配置5辆纯电动微型公交车辆。

线路走向：红塘村委会—乡道—饭粒小组。

停靠站点：红塘村委会、龙万站、头亚站、新村站、布福村站、玉盘站、饭粒小组。

四、同意由你公司开通天涯海角至那会村公交线路。全程约9公里，线路编号：天涯5号，配置8辆纯电动微型公交车辆。

线路走向：天涯海角—G225国道—Y064乡道—那会村。

停靠站点：天涯海角、天涯中学、天涯海上巴士码头、天涯邮政、天涯派出所、布带村、竹株村、布方昌村、布梅村、布山下村、布山上村、那会村。

五、同意由市公交集团开通科技城管理局至科技城管理局公交线路。全程约16公里，线路编号为：崖州11号，配置3辆6米级纯电动公交车辆。

线路走向：科技城管理局—2号路—7号路—G225—崖州区政府（掉头）—G225—振州路—12号路—创意街—中央大道—新道街—2号路—科技城管理局。

停靠站点：科技城管理局、蔬菜集散中心、自来水厂、南山花园、南滨路口、崖城派出所、崖州区政府、崖城派出所、南滨路口、南山花园、自来水厂、蔬菜集散中心、创意产业园路口、百泰药业、逸海郡、寰岛小学、中兴二期、国康医院、海洋科技馆、希尔顿、科技城管理局。

六、同意由你公司开通海棠小学至雅安村公交线路。全程约13.7公里，线路编号：崖州8号，配置4辆5.95至6.6米级纯电动公交车辆。

线路走向：海棠村—乡道—225国道—崖保路—兴滨路—雅安村。

停靠站点：海棠小学、海棠三组路口、保平村、保平村路口、西园三组、西园二组、崖州火车站、城西小学、古城门、水南村口、崖城高级中学、崖州区政府、崖城派出所、南滨路口、南滨中学、南滨小学、椰林水乡小区、南滨东升队路口、雅安村。

七、同意由你公司开通三更村委会至大茅村公交线路。全程约17.6公里，线路编号：崖州9号，配置5辆纯电动微型公交车辆。

线路走向：三更村委会—084乡道—Y081—G225—火车站路—古城北路—古城北路—火车站路—G225—吴泊街—Y072乡道—大茅村。

停靠站点：三更村委会、凤岭小学、凤岭村、扫梳三组、太策村路口、三公里小学、三公里村、盐灶小学、保平村、保平村路口、西园三组、西园二组、崖州火车站、城西小学、古城门、张家园十字路口、拱北村路口、拱北四组、大茅村。

八、同意你公司取消46路（同心家园一二期至同心家园一二期）公交线路，并收回该线路经营权。

九、按照《2018年关于印发三亚市公交成本规制补贴实施方案》（三府办〔2018〕260号）的要求，南边海公交首末站至鸿森医院、三公里村委会至凤上村、红塘村委会至饭粒小组、天涯海角至那会村、科技城管理局至科技城管理局、海棠小学至雅安村、三更村委会至大茅村等7条公交线路的经营期限自线路开通之日起为6年，并实行“公车公营”。严禁买断产权挂靠经营，发包经营。

十、上述7条公交线路公交车辆投放运营和取消公交线路中所引发的各类纠纷及经济责任由市公交集团自行解决和承担。

十一、以上7条公交线路开通后线路收费标准严格按照市价格主管部门审批的价格执行。

三亚市交通运输局

2019年9月19日
