# 三亚市交通运输局关于58路公交线路增加边检站公交站点的通知

三交运〔2019〕557号

三亚市交通运输局

关于58路公交线路增加边检站

公交站点的通知

三亚市公共交通集团有限公司：

为合理设置公交站点，方便学生和家长乘坐公交车，经研究，决定对58路公交线路增加“边检站”公交站点，在周五放学和周日返校时段加大该线路发班密度。请你公司务必做好58路公交车辆的腰牌及报站器的更新工作，自2019年9月26日起按照新增的停靠站点提供运营服务。并于2019年9月26日前完成公交站牌线路信息的刷新工作。

特此通知。

三亚市交通运输局

2019年9月23日
