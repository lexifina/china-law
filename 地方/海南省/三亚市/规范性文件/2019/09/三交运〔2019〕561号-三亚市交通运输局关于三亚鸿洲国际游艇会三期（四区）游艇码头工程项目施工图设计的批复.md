# 三亚市交通运输局关于三亚鸿洲国际游艇会三期(四区)游艇码头工程项目施工图设计的批复

三亚鸿洲国际游艇会有限公司：

报来三亚鸿洲国际游艇会三期（四区）游艇码头工程项目施工图设计及相关材料收悉。根据交通运输部颁布的《水运工程施工图文件编制规定》（JTS 110-7-2013）并综合广东省航运规划设计院有限公司出具的《三亚鸿洲国际游艇会三期（四区）游艇码头工程项目施工图设计文件技术审查咨询报告》及专家审查意见，批复如下：

一、总体评价

（一）根据《港口工程建设管理规定》（交通部令2018年第2号）第二十三条：“对于建设内容简单、投资规模较小的按照备案管理的港口工程建设项目，初步设计和施工图设计可以合并设计，深度应当达到施工图设计要求”。本工程初步设计和施工图设计合并设计，符合规定要求。

（二）安徽省交通勘察设计院有限公司编制的《三亚鸿洲国际游艇会三期（四区）游艇码头工程项目施工图设计》文件，内容较完整，图纸基本齐全，达到了港口工程施工图设计规定的深度要求，可作为施工依据。

二、工程建设规模

本工程位于三亚西河口西岸，与鸿洲国际游艇会码头三期（三区）项目毗邻。本工程新建73个游艇泊位及相应配套设施，其中60英尺泊位15个、70英尺泊位22个、80英尺泊位33个、90英尺泊位2个、165英尺泊位1个。

三、总平面布置方案

本工程紧邻鸿洲国际游艇会码头（三区）泊位南侧布置4榀“丰”字型游艇码头（3F-D、3F-E、3F-F、3F-G榀码头），共73个游艇泊位。本项目主浮桥前沿线位于距离堤岸10米左右的位置，平行于堤岸的主浮桥总长344.844米，其中：3米宽的主浮桥长272.704米，4米宽的主浮桥长72.14米；3F-D榀码头干浮桥长72.45米、宽2.5米，支浮桥9座；3F-E、3F-F榀码头干浮桥长82.5米、宽2.5米，支浮桥10座；3F-G榀码头干浮桥长81.5米、宽4米，支浮桥5座。

3F-D榀码头布置19个游艇泊位，其中60尺泊位5个、70英尺泊位13个、80英尺泊位1个。3F-E榀码头布置游艇泊位21个，其中60英尺泊位4个，70英尺泊位8个、80英尺泊位8个，90英尺泊位1个。3F-F榀码头布置游艇泊位21个，其中60英尺泊位4个、80英尺泊位16个、90英尺泊位1个。3F-G榀码头布置游艇泊位12个，其中60英尺泊位2个、80英尺泊位8个、70英尺泊位1个、165英尺泊位1个。

港内停泊水域、回旋水域布置在泊位前方，内航道和支航道有效宽度为设计船长的1.5倍，浮桥内侧15米宽范围的港池底标高为-3.3米（采用国家85高程基准，下同），中间浮桥水域的港池底标高为-3.6米，浮桥外侧的港池底标高为-3.9米，165尺泊位处的港池底标高为-4.9米。游艇浮码头与陆域间连接布设有2座活动引桥（长10米、宽2米）、2个接岸浮平台（长6.5米、宽6米）。

四、水工建筑物

本项目码头主体采用浮箱结构。码头定位结构采用Φ600PHC混凝土管桩。码头与岸连接采用铝合金活动引桥及接岸浮平台。

五、工程投资

本工程总投资为2216.1万元，建设资金由企业自筹。

六、其他

（一）请你单位工程建设时严格执行港口工程技术规范及国家有关规范标准，按照批准的施工图设计文件进行施工，做好施工期间安全组织和管理，确保工程建设质量和安全。按照国家安全生产、环境保护“三同时”和交通运输部《公路水运工程安全生产监督管理办法》的要求，严格落实安全、环境保护、消防、节能岸电、污染物接收设施等相关措施。

（二）请你单位按有关规定办理开工前相关手续，具备条件后尽快开工建设。工程建设中，重大施工图设计变更报我局审批。

（三）本批复有效期1年，在有效期内未开工建设，本批复自动失效。

三亚市交通运输局
