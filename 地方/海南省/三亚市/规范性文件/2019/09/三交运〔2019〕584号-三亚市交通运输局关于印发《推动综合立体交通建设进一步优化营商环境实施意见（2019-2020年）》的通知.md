# 三亚市交通运输局关于印发《推动综合立体交通建设进一步优化营商环境实施意见（2019-2020年）》的通知

各区人民政府，育才生态区管理委员会，市各有关单位：

根据《三亚市人民政府办公室关于印发三亚市优化营商环境行动计划（2019-2020年）》（三府办〔2019〕117号）的要求，结合我市交通运输工作情况，我局制定了《推动综合立体交通建设进一步优化营商环境实施意见（2019-2020年）》，请贵单位结合工作职责，共同配合推进优化营商环境工作。

特此通知

三亚市交通运输局

2019年9月30日

（此件主动公开）

推动综合立体交通建设进一步优化营商环境实施意见

（2019-2020年）

一、工作目标

城市发展，交通先行。以探索海南自由贸易区(港)建设，优化三亚营商环境为契机，提高三亚基础设施网络化水平，完善综合立体交通建设，高质量高标准建设公路、港口、码头、新机场等基础设施，优化公共交通良好运营环境，更加紧密地融入国家战略，为三亚实现高质量发展、踏上现代化新征程提供有力支撑。

二、主要任务

（一）推动港口规划及服务功能不断完善

1、进一步优化水运工程项目设计审查程序。为深化“放管服”改革，推行制度创新举措，率先在全省实施对简单水运工程项目实行简化设计审查审批程序。即对结构简单、投资小于3000万元的企业投资水运工程项目，可将初步设计、施工图设计合并设计，向我局直接申报水运工程施工图设计审查。到2019年底前，优化水运工程项目设计审查程序。（责任单位：市交通运输局）

2、推动《三亚港总体规划》完成报批。《三亚港总体规划》已编制完成形成报批稿，计划到2020年前《三亚港总体规划》完成报批。经批准实施的《三亚港规划》将促进三亚港形成“一港三区”的总体发展格局，助力南山港开发建设。（责任单位：市交通运输局）

3、提高港口作业效率。加快完善南山港通用散杂货码头功能。开展散杂货码头兼顾集装箱业务能力评估，并根据评估意见完善码头设备设施、管理制度，2019年12月前兼顾集装箱作业常态化运营。完成港口作业效率公示与监测工作。公示集装箱港口装卸、运输、仓储、移（掏）箱等作业时限标准及办理提箱作业时间，便利企业办理当天提箱提货。定期对港口装卸效率开展检测，及时发现装卸效率的瓶颈环节，持续改进服务。（责任单位：市交通运输局、三亚交通投资集团有限公司）

4、申请将三亚港水运口岸南山港扩大开放列入国家口岸开放审理计划。（责任单位：市商务局）

5、完成南山港扩大开放的《可行性研究报告》编制。（责任单位：市商务局）

（二）推进邮轮游艇游船等配套建设

1、推动出台《三亚邮轮港口海上游航线试点实施分工方案》。明确各部门职责分工，稳步推进海上游航线试点工作，积极配合省交通运输厅实施邮轮海上游政策。（责任单位：市旅游和文化广电体育局、市交通运输局）

2、推动三亚邮轮旅游中心、游艇旅游中心、游船旅游中心建设，促进还是旅游及航运业的发展。（责任单位：市旅游和文化广电体育局，市交通运输局）

3、积极推动我市游艇租赁业务试点，待《海南省游艇租赁管理规定》印发实施后，严格按照规定执行，做好我市游艇租赁行业管理工作。（责任单位：市交通运输局）

4、放宽游艇旅游管制，重点扶持游艇行业协会，倡导行业自律；协调各部门做好相关服务保障工作，推动游艇产业发展。（责任单位：市旅游和文化广电体育局、市交通运输局、市商务局）

5、收集海关监管场所及检验检疫场所设立申请相关资料，待国家口岸相关部门批复后再按照三亚海关、三亚海事等相关部门要求，逐步完善海关监管场所及检验检疫场所等特殊监管区域设立。（责任单位：市商务局、三亚交通投资集团有限公司、三亚凤凰机场有限公司、三亚海关）

（三）推动水上交通基础设施建设水平不断提升

1、加快完善邮轮母港建设。推进三亚凤凰岛国际邮轮港二期工程建设，在2个已建15万吨级邮轮泊位的基础上，着力完善2个22.5万吨级邮轮泊位建设。到2020年底，完成凤凰岛邮轮港二期工程4个邮轮泊位全部投入使用。（责任单位：市交通运输局、三亚凤凰岛国际邮轮港发展有限公司）

2、加快水上巴士码头建设。为丰富三亚旅游观光出行方式,补齐水上公共交通短板，以新建或升级改造现有码头的形式，加快建设水上巴士码头。到2020年底，完成新建或改建的5个海上巴士码头，供海上巴士船舶靠泊使用。（责任单位：三亚市交通运输局、三亚旅游文化投资集团有限公司）

（四）推动农村公路建设及村庄道路改造

1、加快完成农村公路六大工程。大力推进自然村通硬化路工程、桥梁建设及危桥改造工程、旅游资源路工程建设。到2019年底，在实现行政村100%具备通公交条件基础上实现具备条件的自然村100%通硬化，全面消灭现有危桥。到2020年，完成旅游资源路工程建设，打通北部山区路网横向连接。(责任单位：三亚市交通运输局）

2、实施农村公路网提质升级建设。坚持适度超前、互联互通、安全高效、智能绿色的原则,加快补齐农村交通运输短板，建设一批乡村旅游路、资源路和产业路。根据《三亚市农村公路网建设规划》（2020-2025年），启动农村公路网升级改造项目前期工作，根据轻重缓急的原则，对我市主要农村公路主干道按照三级公路进行升级改造。（责任单位：三亚市交通运输局、各区人民政府、育才生态区管理委员会、市农业农村局、市住房和城乡建设局、市水务局）

3、开展人居环境整治村庄道路改造。统筹各区、育才生态区开展村庄道路改造建设，完善自然村路网联通，加快推进村庄入户道路建设，加强农村道路硬化建设和生命安全防护。到2019年底实现具备条件的自然村硬化率和美丽乡村村庄道路硬化率分别达95%以上。（责任单位：三亚市交通运输局、各区人民政府、育才生态区管理委员会、市农业农村局、市水务局）

（五）优化推进一批重大交通项目建设

推动三亚新机场建设，构建完善三亚航空网络，拓展国际航线，不断丰富国际旅游产品供给；推进西环货线三亚至乐东段公交化旅游化改造项目、三亚有轨电车示范线工程建设，打造综合性旅游交通出行；推动G98环岛高速公路大三亚段扩容工程项目、五指山至保亭至海棠湾高速公路（三亚段）项目、省道S314天新线天涯至新宁波段改建工程项目、等过境道路建设，促进“大三亚”经济圈交通一体化发展，提升三亚城市对外交通便利水平，社会经济发展水平。推进三横路、亚龙湾第二通道工程、海榆东线（国道223）亚龙湾至吉阳转盘公路改造工程、南山“四个一”交通配套工程、三亚绕城高速凤凰机场互通及连接线工程、国道G225塔岭至海角段改扩建工程项目、海南省环岛旅游公路陵水土福湾至三亚海棠湾通道工程等一批公路、市政道路项目建设，进一步完善三亚市交通路网，带动、促进区域经济发展，缓解交通拥堵问题，改善游客及市民出行条件。（责任单位：市交通运输局、市住房和城乡建设局、各区人民政府、三亚交通投资集团有限公司、三亚机场建设有限公司）

（六）优化公共交通运营环境

以公交都市创建为契机，推动公交场站、候车亭等基础设施建设，提高公交车辆进场率，营造公共交通良好运营环境。新建成红沙公交综合维修保养场及鸿森医院、中心渔港、鹿回头公交首末站，续建吉阳公交综合场站、客运东站项目，对老旧公交候车亭进行更新。实施公交西站综合开发。加快推进智慧停车平台项目建设。继续推动农村自然村“村村通公交”工程，自然村通公交率达到98%，农村地区公交线网覆盖率得到显著提升，农村地区居民公交出行条件得到明显改善。加大力度在公交领域推广应用新能源汽车。（责任单位：市交通运输局）

（七）鼓励中外航空公司新开或加密海南直达全球主要客源地的国际航线

加强机场各项基础设施建设，完成凤凰机场保税区规划选址、方案设计及建设工作。做好凤凰机场保税区申报工作。持续提高机场服务保障能力，持续保障凤凰机场总吞吐量在2000万人次以上，积极推进境外航线的开辟，到2020年底，使经停三亚的境外航线达到49条，境外旅客吞吐量达到100万人次以上。（责任单位：市交通运输局、三亚凤凰机场有限公司）

三、保障措施

（一）健全工作机制

成立三亚市交通运输局优化营商环境工作领导小组，主要负责统筹制定和审议交通运输领域优化营商环境工作的重大政策，贯彻落实省、市有关工作部署，协调解决重点难点问题，研究并推动各项工作任务顺利完成。

（二）制定优化营商环境专项计划

围绕交通运输领域的工作要点，制定并出台推动交通运输领域优化营商环境的实施意见，细化任务，明确时间表，抓好各项工作措施落地实施。

（三）建立工作考评及督办机制

领导小组要建立考评及督办工作小组，对各部门的工作措施进行督办及定期考评，将按照责任到人的考评机制对工作完成情况进行考评，考评情况与绩效考核挂钩。
