# 对特警支队育才中队备勤用房项目进行审计的通知

市公安局:

根据《中华人民共和国审计法》第二十二条的规定,我局决定派出审计组,自2019年9月30日起,对你单位负责建设的特警支队育才中队备勤用房项目进行审计,必要时将追溯到相关年度或者将对与项目直接有关的设计、施工、监理、供货等单位取得项目资金的真实性、合法性进行调查。请予积极配合,并提供有关资料(包括电子数据资料)和必要的工作条件。

审计组组长:郑茹方

审计组成员:范华林(兼职廉政监督员)

黄垂杰吉书丽(海南定宇工程造价咨询有限公司)

附件:三亚市审计局关于审计纪律的规定
