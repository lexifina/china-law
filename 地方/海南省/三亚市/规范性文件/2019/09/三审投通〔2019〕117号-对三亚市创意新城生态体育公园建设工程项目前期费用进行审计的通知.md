# 对三亚市创意新城生态体育公园建设工程项目前期费用进行审计的通知

三亚市创意新城开发建设有限公司:

根据《中华人民共和国审计法》第二十二条的规定,我局决定派出审计组,自2019年月30日起,对你单位负责建设的三亚市创意新城生态体育公园建设工程项目前期费用进行审计,必要时将追溯到相关年度或者将对与项目直接有关的设计、施工、监理、供货等单位取得项目资金的真实性、合法性进行调查。请予积极配合,并提供有关资料(包括电子数据资料)和必要的工作条件。

审计组组长:郑茹芳

审计组组员:廉静(主审)

邢增宝(兼职廉政监督员)

吴晓江(深圳轩明达工程项目管理有限责任公司)

附件:三亚市审计局关于审计纪律的规定

三亚市审计局
