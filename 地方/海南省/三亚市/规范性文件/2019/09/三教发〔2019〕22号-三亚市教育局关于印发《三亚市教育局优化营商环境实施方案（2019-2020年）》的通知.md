# 三亚市教育局关于印发《三亚市教育局优化营商环境实施方案（2019-2020年）》的通知

各区教育局，市教育局机关及下属事业单位：

为深入贯彻落实市委市政府关于优化我市营商环境的决策部署，进一步优化全市营商环境,充分激发市场活力和社会创造力，我局制定了《三亚市教育局优化营商环境实施方案（2019-2020年）》，现印发给你们，请你们认真贯彻落实。

三亚市教育局

2019年9月20日

（此件主动公开）

三亚市教育局

优化营商环境实施方案（2019-2020年）

为共同营造有序、高效、便捷的营商环境，进一步提升我市教育系统公共服务水平，助推我市经济社会发展，根据市政府关于《三亚市优化营商环境行动计划（2019-2020年）》和《三亚市优化营商环境考核评价办法》要求，现结合三亚教育系统工作实际，制定本工作方案。

一、指导思想

以习近平新时代中国特色社会主义思想和党的十九大精神为指导，深入贯彻落实习近平总书记“4·13”重要讲话精神和中央12号文件精神，全面贯彻党的教育方针，不断深化教育综合改革，推动教育营商环境的持续改善优化，促进三亚经济持续健康发展。

二、目标与任务

进一步推进《三亚市幸福民生行动计划教育提升工程（2017-2021年）实施方案》，按照服务自贸区（港）人才建设相关标准，加快推进全市基础教育配套设施建设，规划改扩建、新建一批公办中小学、幼儿园，扩充学校容量，增加有效学位，积极引进优质教育资源，提升师资队伍，缓解学生入学压力，保障人才子女入学，努力办好人民满意的教育。

三、具体措施

（一）加强学校基础建设

新建幼儿园13所，改扩建1所，新增公办幼儿园学位2820个，新建小学3所,新增小学学位6062个，新建中学3所、改扩建中学4所，新增中学学位11763个。（牵头科室：改革与发展规划科）

（二）加强教师队伍建设

1.积极打造工作室。打造“银发精英”教育人才校长工作室、市级中小学卓越教师工作室等品牌。(牵头科室:人事科，配合单位：市教培院)

2.全面提高幼儿园教师质量。完善学前教育培训体系，开展幼儿教师全员培训，优化培训内容，突出师德养成和保教融合。(牵头科室:人事科，配合单位：市教培院）

3.中小学教师“县管校聘”管理改革。全面推动实行中小学教师“县管校聘”管理改革，简化县域内教师交流调配人事手续。深入推进区域内义务教育学校校长、教师轮岗交流，实现交流工作制度化、常态化。(牵头科室:人事科）

4.改革创新中小学教师编制管理。实行教师编制配备和政府购买工勤服务相结合，对寄宿制学校生活教师、中小学校工勤岗位等适合社会力量提供的服务，采用劳务派遣或聘任制等方式解决。(牵头科室:人事科)

5.充实一批专业素质和口语水平高的外语师资到中小学校任教，健全外籍和港澳台籍教师资格认证、服务管理制度。(牵头科室:人事科)

（三）加快引进优质教育资源

深化中小学办学体制改革。按照“一市（县）两校一园”的要求，切实加强与教育发达地区的交流合作，吸引国内外名校和社会力量参与办学，探索联合办学、集团办学、委托管理、片区管理等多种办学形式，增强公办学校的办学活力，提高办学水平和效益。拓宽合作交流模式。进一步拓宽国际教育交流渠道，积极引进国外优质教育资源。(牵头科室:改革与发展规划科)

（四）切实保障人才子女入学

建立健全高层次人才服务保障机制，进一步完善《三亚市高层次人才子女入学保障办法》，义务教育阶段入学由各单位于当年6月份统一向教育局提出入学申请，由市教育局根据各学校学位情况统筹安排在相对优质的学校，高层次人才子女参加中考、高考依据《海南省高层次人才子女入学实施办法（试行）》执行;高层次人才子女转学进入我市将采取“一事一议”统筹安排的原则予以保障，切实为高层次人才子女入学提供便利。（牵头科室：基教科，配合科室：改革与发展规划科）

四、实施步骤

（一）部署阶段（2019 年9月底前）

制定出台《三亚市教育局优化营商环境实施方案（2019-2020年）》，明确工作目标和工作任务，层层分解落实。

（二）推进阶段（2019 年10月－2020年11月）

全面落实行动计划，确保营商环境建设取得明显成效，群众认可度、满意度和项目推进速度明显提升。

（三）总结阶段（2020年11月--2020年12月）

对本次行动进行全面深入总结，客观评价工作成效，对典型经验和成功做法进行推广，形成长效工作机制。

五、工作要求

（一）加强组织领导。成立市教育局优化营商环境工作领导小组，由局长担任组长，由分管领导担任副组长，局机关各科室负责人为小组成员，工作领导小组办公室设在改革与发展规划科，具体负责领导小组日常工作。市教培院、改革与发展规划科、人事科、基础教育科等单位及相关科室为具体承办单位及科室，负责政策规定落实、行政审批和服务事项办理等各项工作，全力推进《实施方案》各项任务的落实。

（二）强化督导问效。要加强督促检查，实行跟踪问效。

及时了解掌握当前进度和存在的问题困难，分析问题根源，找准症结，帮助协调解决，切实为项目建设扫清障，加强结果反馈，真正形成抓落实的体制机制。

（三）营造浓厚氛围。广泛宣传我市教育惠民利民政策，提高人民群众对政策的知晓度，大力宣传报道我市教育系统优化营商环境工作的新进展、新动态以及成功做法和典型经验，营造良好的社会氛围。
