# 三亚市交通运输局关于58路增加公交站点的通知

三亚市公共交通集团有限公司：

为合理设置公交站点，方便市民和游客乘坐公交车，经研究，决定在崖保路上增加“保平村市场”和“南滨路口”公交站点，请你公司务必做好58路公交车辆的腰牌及报站器的更新工作，自2019年11月14日起按照新增的停靠站点提供运营服务。并负责在上述公交站点设立临时公交站牌，并于2019年11月14日前完成公交站牌线路信息的刷新工作。

三亚市交通运输局

2019年11月8日
