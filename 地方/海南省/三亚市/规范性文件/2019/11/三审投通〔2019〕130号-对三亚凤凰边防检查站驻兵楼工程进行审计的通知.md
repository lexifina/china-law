# 对三亚凤凰边防检查站驻兵楼工程进行审计的通知

凤凰出入境边防检查站:

根据《中华人民共和国审计法》第二十二条的规定,我局决定派出审计组,自2019年11月15日起,对你单位负责建设的三亚凤凰边防检查站驻兵楼工程项目结算进行审计,必要时将追溯到相关年度或将对项目直接有关的设计、施工、监理、供货等单位取得项目资金的真实性、合法性进行调查。请予积极配合,并提供有关资料(包括电子数据资料)和必要的工作条件。

审计组组长:郑茹方

审计组成员:邢增宝(主审)

范华林(兼职廉政监督员)

王选勇王川雄(鹏信工程项目管理顾问有限公司)

附件:三亚市审计局关于审计纪律的规定
