# 对三亚市第一中学体育馆项目设计变更预算进行审计的通知

市教育局:

根据《中华人民共和国审计法》第二十二条的规定,我局决定派出审计组,自2019年11月15日起,对你单位负责建设的三亚市第一中学体育馆项目设计变更预算进行审计,必要时将追溯到相关年度或将对项目直接有关的设计、施工、监理、供货等单位取得项目资金的真实性、合法性进行调查。请予积极配合,并提供有关资料(包括电子数据资料)和必要的工作条件。

审计组组长:陈惠琳

审计组成员:廉静(兼职廉政监督员)

陈龙盛运尧

附件:三亚市审计局关于审计纪律的规定
