# 三亚市教育局关于转发《2019年全国中小学图书馆（室）推荐书目》的通知

各区教育局,市直属各中小学校：

现将《2019年全国中小学图书馆（室）推荐书目的通知》

转发给你们，请按照通知要求，认真贯彻落实。中小学图书馆（室）是学校文献信息中心，各中小学校要将《推荐书目》作为图书馆配备图书的主要参考依据，合理配置图书，做好图书阅览、外借和宣传推荐等，充分发挥中小学图书馆（室）的功能和作用。《推荐书目》可从教育部门户网站（http://www.moe.gov.cn/）进行下载。

三亚市教育局

2019年11月19日
