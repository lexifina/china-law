# 三亚市交通运输局关于征订2020年度党报党刊的通知

各事业单位：

《人民日报》、《求是》杂志、《海南日报》、《今日海南》、《三亚日报》和《经济日报》等党报党刊是中央、省委、市委指导工作的重要舆论工具。为切实做好2020年度交通系统党报党刊发行工作，按照市委的要求，现将有关事项通知如下：

一、加强领导，明确责任

各单位要充分认识做好党报党刊征订工作，切实把党报党刊的征订工作作为一项政治任务，高度重视、及时部署。各单位主要领导亲自部署、亲自过问、亲自督办，并指定专人负责做好党报党刊征订的工作，确保2020年度党报党刊征订任务的顺利完成。

二、明确征订任务，落实订阅范围

各单位要认真执行中央、省委和市委关于党报党刊订阅范围的规定，在完成局机关、各事业单位订阅的基础上，分配一定数量给所管辖企业，局机关和事业单位必须订阅《人民日报》、《求是》杂志、《海南日报》、《今日海南》、《三亚日报》和《经济日报》等党报党刊。交通系统各企业，特别是三亚汽车总站要订阅一定数量的《海南日报》和《三亚日报》供旅客阅读。具体任务以“三亚市交通系统2020年党报党刊征订计划分配表”为准。

三、继续实行归口征订

各事业单位要按照局分配的任务征订足够后，再分配到相关企业，分配到相关企业的数量要做好登记，并指派专人负责抓好落实。要做好本单位及企业党报党刊征订的统计工作，并将统计表及征订发票复印件于2019年12月15日前上报局办。
