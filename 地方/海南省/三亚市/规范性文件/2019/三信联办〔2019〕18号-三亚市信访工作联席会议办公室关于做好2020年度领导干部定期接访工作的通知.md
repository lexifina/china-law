# 三亚市信访工作联席会议办公室关于做好2020年度领导干部定期接访工作的通知

三亚市信访工作联席会议办公室

关于做好2020年度领导干部

定期接访工作的通知

各区信访工作联席会议办公室，市信访工作联席会议各成员单位：

为进一步畅通信访渠道，化解信访突出问题，维护社会稳定，根据《信访条例》和《海南省信访工作责任制实施细则》相关规定，以及市信访工作联席会议统一部署，现将2020年度领导干部定期接访工作有关事项通知如下：

一、目标任务

建立健全新时期领导干部接待群众来访长效机制，推进信访工作的制度化、规范化和法制化建设。通过开展领导干部定期接访工作，进一步密切党群、干群关系，转变工作作风，压实工作责任，有效推动解决群众的合理诉求，维护群众的合法利益，减少我市信访存量；进一步加强和改进人民信访工作，充分发挥信访工作“了解民情、集中民智、维护民利、凝聚民心”的重要作用，创新完善决策机制，为我市经济社会持续健康发展，加快推进海南自由贸易区（港）建设作出积极贡献。

二、参加接访领导范围

市委、市人大、市政府、市政协市级领导干部，各区、市信访工作联席会议各成员单位领导。

三、接访时间及形式

根据《海南省信访工作责任制实施细则》关于“省级领导每半年安排一次接访，市厅级领导每季度安排一次接访，县（市、区）领导每月安排一次接访，乡镇（街道）领导实行周轮流接访”的规定，参与接访的领导为各级党政机关领导班子成员。市信访工作联席会议办公室结合群众信访情况，拟定了《2020年三亚市级领导接待群众来访日程表》，统筹安排市级领导干部1-2次定期接访。主要采取轮流到市信访局接访室坐班的形式，接待群众来访，听取群众诉求，其余接访任务可以采取走访下访、包案约访的形式完成。

各区、市信访工作联席会议各成员单位按规定统筹安排本单位领导接访，并向社会公布接访时间和地点。

四、工作要求

（一）切实加强领导。各单位要高度重视，结合“不忘初心、牢记使命”主题教育，把领导干部定期接待群众来访作为一项重要制度抓好抓实。市、区信访联席办要做好统筹协调，领导干部要根据统一安排，在规定的时间到指定的场所接待来访群众，确因工作原因无法参加的，应提前和市信访联席办沟通，及时调整，确保不空岗。

（二）切实解决问题。各级领导干部要紧紧围绕“事要解决、案结事了”的目标，坚决克服形式主义，面对面听取诉求，实打实解决群众问题。要强化责任担当，综合运用法律、政策、经济、行政等手段和教育、调解、疏导等办法，按照“三到位一处理”的工作原则，把群众合理合法的利益诉求解决好。涉及群众信访事项的承办单位要主动配合，认真办理信访事项，定期向接访领导汇报调查处理情况和信访人稳定情况。市信访联席办要会同市信访局及时跟踪督办，确保领导公开接访的信访事项得到及时解决。

（三）加大宣传引导。各区、各部门及市信访局要向社会公布领导干部接访时间、接访人和接访方式，明确职能部门参与接访，最大限度方便群众推动问题解决。对活动开展情况要广泛宣传报道，特别是对一些典型案件的化解，要通过媒体正面报道，发挥媒体弘扬社会正气、通达社情民意、引导社会舆论、疏导公众情绪的积极作用。要切实提升群众知晓率、参与度，引导群众正确表达诉求，树立合理心理预期，营造良好的社会舆论氛围和法治氛围。
