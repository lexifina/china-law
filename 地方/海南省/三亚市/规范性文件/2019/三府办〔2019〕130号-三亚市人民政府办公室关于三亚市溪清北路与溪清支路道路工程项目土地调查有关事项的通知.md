# 三亚市人民政府办公室关于三亚市溪清北路与溪清支路道路工程项目土地调查有关事项的通知

三亚市人民政府办公室关于

三亚市溪清北路与溪清支路道路工程项目

土地调查有关事项的通知

吉阳区人民政府，市政府各有关单位：

根据三亚市总体规划和项目建设需要，经市政府同意，对溪清北路与溪清支路道路工程项目用地进行调查。为做好该项土地调查工作，现就有关事项通知如下：

一、该项目用地位于吉阳区内，用地调查面积约24778平方米（海南平面坐标系），具体的土地调查范围四至及坐标详见三亚市溪清北路与溪清支路道路工程拟用地红线图。土地权属（海南平面坐标系）情况为国家土地约2609平方米、三亚市土地储备开发中心国有土地约13722平方米、海南三亚技工学校国有土地约2549平方米、三亚警备区国有土地约324平方米、三亚华惠房地产开发有限公司等5家公司国有土地共约5574平方米；土地利用现状（2000国家大地坐标系）为农用地约6352平方米（其中水田约3816平方米、坑塘水面约2536平方米）、建设用地约18441平方米（其中城市约14613平方米、风景名胜及特殊用地约3828平方米）；该项目用地在《三亚市总体规划（空间类2015-2030）》（市多规合一）中规划为城市道路用地。上述用地涉及的约3816平方米耕地在办理农用地转用时，从我市耕地占补平衡指标中统筹安排。待完成占补平衡任务后，由三亚市市政维护应急中心按要求提供用地报批材料，市自然资源和规划局将其列入当年新增建设用地指标并办理农转用报批手续。

二、为做好该项土地调查工作，由吉阳区人民政府负责组织实施该项目用地上的清点青苗、丈量地上附着物、丈量土地面积等土地补偿审核以及土地补偿工作；市住房城乡建设局负责对国有土地上的房屋征收与补偿工作进行指导。在调查工作中，土地调查范围内的单位或个人，不得以任何理由进行阻挠。

三、收回国有土地的征地补偿测算工作按《中华人民共和国城镇国有土地使用权出让和转让暂行条例》（国务院令第55号）和《国有土地上房屋征收与补偿条例》（国务院令第590号）等规定执行。

四、自本通知下达之日起，在土地调查范围内一律禁止抢种青苗和抢建附着物。凡突击抢种的青苗和抢建的附着物，一律不予补偿，后果自负。吉阳区人民政府、各相关职能部门一定要提高依法用地意识，决不能产生新的违法用地。
