# 三亚市人民政府办公室关于调整市政府秘书长副秘书长分工的通知

三亚市人民政府办公室

关于调整市政府秘书长副秘书长分工的通知

各区人民政府，各管委会，市政府直属各单位：

根据工作需要，现将市政府秘书长副秘书长分工情况通知如下：

陈明秘书长 协助阿东市长工作，协助处理市政府的日常工作事务，主持市政府办公室（市海防办公室、市信访局、市档案局、市政府研究室）全面工作；

协调市财政局、市审计局、三亚崖州湾科技城管理局工作；

分管市政府驻京联络处、市政府办公室秘书一科、综合科。

协助联系驻市各高校、市妇联、市文联、市社科联、市史志办、三亚海事局、三亚海关、三亚凤凰国际机场工作；
