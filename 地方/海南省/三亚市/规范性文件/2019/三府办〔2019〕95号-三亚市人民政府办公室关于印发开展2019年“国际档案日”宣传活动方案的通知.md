# 三亚市人民政府办公室关于印发开展2019年“国际档案日”宣传活动方案的通知

三亚市人民政府办公室

关于印发开展2019年“国际档案日”

宣传活动方案的通知

各区人民政府，育才生态区管委会，市政府直属各单位：

现将《开展2019年“国际档案日”宣传活动方案》印发给你们，请组织实施。

三亚市人民政府办公室

2019年5月30日

（此件主动公开）

开展2019年“国际档案日”宣传活动方案

今年6月9日是国际档案理事会确定的第12个国际档案日，为深入学习宣传贯彻习近平新时代中国特色社会主义思想，大力营造庆祝新中国成立70周年良好氛围，进一步宣传档案工作在服务全局所发挥的特殊作用，根据国家、省档案局关于开展2019年国际档案日宣传活动的要求，制订本方案。

一、活动主题

以“新中国的记忆”为主题开展宣传活动。

二、活动时间

2019年6月9日至16日。

三、活动内容

（一）围绕主题，结合实际，市政府办公室定于2019年6月11日（周二）上午在三亚明珠广场举办大型宣传活动。通过档板展览、发放纪念物品和宣传资料、组织档案知识有奖问答等形式，向社会广大民众宣传档案工作在服务社会、服务民生等方面取得的突出成绩，充分体现档案“存凭、留史、资政、育人”的特殊作用。

（二）围绕“新中国的记忆”，各区、各单位及社区在公共区域制作宣传栏，营造氛围，进一步传播档案文化知识。

（三）市档案局在三亚市政府网站、微信公众号等平台上推出我市“国际档案日”宣传海报、科普文章、微视频等。各区，各单位在各自的门户网站及微信公众号等公众平台上开展有关“国际档案日”的宣传活动，增强广大民众对档案的认知。

（四）制作档案文创产品及主题宣传材料。各区、各单位根据国家档案局《关于开展2019年国际档案日系列宣传活动的通知》（档发〔2019〕9号），积极征订中国档案报社“2019年国际档案日宣传挂图及环保袋”，中国档案杂志社“2019年国际档案日宣传主题宣传品‘毛泽东手书诗词’折扇”等宣传纪念品。

（五）各区在活动日期间开展档案进村、进社区宣传活动，向居民发放宣传手册和纪念品，宣传档案知识。为加深及巩固市民对《中华人民共和国档案法》的推广及档案的利用，可采用有奖问答等生动多样的形式开展宣传活动。

四、活动要求

（一）各区，各单位要高度重视此次活动，要加强领导，指派专人负责，发动大家积极参与，全力保证此次活动有效开展、顺利实施、圆满完成。

（二）2019年6月11日上午，天涯区、吉阳区、海棠区、崖州区及各单位须安排本单位档案管理人员参加在三亚明珠广场举办的宣传活动。四个区各安排10人参加，其他单位档案管理人员参加（参加活动人员必须在当天上午08:30前到达明珠广场指定位置）。

（三）充分利用网络、微信、报纸、电视等网络平台和新闻媒体，宣传档案功能、扩大档案影响，提高广大民众对档案的认知及档案与人们的密切关系。
