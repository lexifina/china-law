# 三亚市人民政府办公室关于增补档案全宗号的通知

三亚市人民政府办公室

关于增补档案全宗号的通知

各有关单位：

按照《中华人民共和国档案法》的规定，为规范本行政区内机关、团体、企事业单位档案管理，市档案馆已对全市归档单位统一编制档案全宗号，现需对国家税务总局三亚市税务局等新建或重组的9个单位增补档案全宗号，其中：国家税务总局三亚市税务局全宗号为142；市自然资源和规划局全宗号为143；市旅游和文化广电体育局全宗号为144；市金融发展局全宗号为145；市退役军人事务局全宗号为146；市应急管理局全宗号为147；市市场监督管理局全宗号为148；市扶贫工作办公室全宗号为149；市医疗保障局全宗号为150。希望各单位档案工作人员在归档、整理档案中，准确使用档案全宗号。

三亚市人民政府办公室

2019年7月1日
