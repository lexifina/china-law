# 三亚市人民政府关于修改《三亚市人民政府关于印发三亚市海上搜救应急预案的通知》等106件行政规范性文件的决定

三亚市人民政府

关于修改《三亚市人民政府关于印发三亚市

海上搜救应急预案的通知》等106件

行政规范性文件的决定

三府规〔2019〕5号

各区人民政府，各管委会，市政府直属各单位：

经七届市政府第66次常务会议审议通过，决定修改《三亚市人民政府关于印发三亚市海上搜救应急预案的通知》等106件行政规范性文件（具体见附件），本决定自发布之日起施行，请各责任单位根据本决定做相应修正后重新公布。

附件：2019年决定修改的行政规范性文件汇总表（106件）

三亚市人民政府

2019年8月13日
