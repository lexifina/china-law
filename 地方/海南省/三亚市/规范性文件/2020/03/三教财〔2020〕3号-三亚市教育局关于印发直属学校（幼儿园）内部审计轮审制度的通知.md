# 三亚市教育局关于印发直属学校（幼儿园）内部审计轮审制度的通知

市直属学校（幼儿园）：

为建立健全教育内部审计工作制度，充分发挥教育系统内部审计的监督、评价、服务功能，提高学校内部管理水平和经费使用效益，促进我市教育事业更好地持续健康发展，现将《三亚市教育局直属学校（幼儿园）内部审计轮审制度》印发给你们，请认真贯彻执行。

三亚市教育局

2020年2月28日
