# 三亚市教育局转发《海南省普通高中体育与健康、音乐、美术等学科学业水平合格性考试实施办法》的通知

市直属各高中学校：

我省2023年普通高中高三年级体育与健康、音乐、美术三个学科学业水平合格性考试书面考试于4月14日进行，技能测试于4月15日—21日进行，现将《海南省考试局关于印发〈海南省普通高中体育与健康、音乐、美术等学科学业水平合格性考试实施办法〉的通知》转发给你们，请按《通知》要求认真做好备考工作。

高二、高一学生不参加考试。

附件：海南省考试局关于印发《海南省普通高中体育与健康、音乐、美术等学科学业水平合格性考试实施办法》的通知

三亚市教育局
