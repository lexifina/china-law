# 儋州市人力资源和社会保障局关于规范我市公益性岗位人员管理工作的通知

各镇政府、市属各机关事业单位：

近年来，我市根据上级有关就业文件精神，大力开发公益性岗位，既解决了我市下岗职工及困难人员就业问题，又减轻了各机关事业单位工作压力，促进了我市社会经济的发展。但部分用人单位对公益性岗位人员管理工作不到位，存在不安排工作、拖欠工资及社保费等问题。为进一步规范我市公益性岗位管理工作，现就有关问题通知如下：

一、各单位要高度重视公益性岗位管理工作，结合当前整治“庸懒散贪”活动，加强人员管理，未上岗人员要及时安排上岗，长期不在岗人员，要及时报市就业局批准后给予办理解聘手续，停拨公益性岗位工资及社保补贴。

二、各单位要按时足额发放公益性人员工资及缴交各项社会保险费，不在岗人员，不得发放公益性岗位工资及补贴。

三、市就业局要按照“先工资后补贴”的办法，加强公益性岗位经费管理。每月凭用人单位提交的工资发放表及缴交社保费清单拨付公益性岗位工资补贴及社会保险费补贴，不提交工资表及社保费清单的单位，市就业局不得拨付经费。

四、各单位要及时清理不在岗及已到聘用期限还未解聘的公益性岗位人员，并于今年九月底前将名单上报我局就业科及市就业局，不上报的单位，一经查出，将在全市通报，并追究单位领导责任。
