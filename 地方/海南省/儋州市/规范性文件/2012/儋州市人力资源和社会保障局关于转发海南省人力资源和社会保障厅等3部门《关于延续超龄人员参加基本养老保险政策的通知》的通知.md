# 儋州市人力资源和社会保障局关于转发海南省人力资源和社会保障厅等3部门《关于延续超龄人员参加基本养老保险政策的通知》的通知

儋人社发63号

各有关单位：

现将海南省人力资源和社会保障厅、海南省财政厅、海南省地方税务局《关于延续超龄人员参加基本养老保险政策的通知》（琼人社发341号）文转发你们，望各单位在去年做好超龄人员参加基本养老保险工作的基础上，严格掌握政策，广泛宣传，认真抓好落实，妥善做好符合条件的超龄人员参加基本养老保险工作，切实维护群众利益和社会稳定。
