# 儋州市人民政府办公室关于印发儋州市2012年能繁母猪补贴工作方案的通知

儋府办〔2012〕132号

儋州市人民政府办公室关于

印发儋州市2012年能繁母猪补贴

工作方案的通知

各镇政府，国营（地方）农林场，市政府直属有关单位：

《儋州市2012年能繁母猪补贴工作方案》已经市政府同意，现印发给你们，请认真组织实施。

儋州市人民政府办公室

2012年8月31日

（此件主动公开）

儋州市2012年能繁母猪补贴工作方案

为落实好2012年能繁母猪补贴政策，调动养殖场（户）饲养能繁母猪的积极性，促进生猪生产持续健康发展，根据农业部办公厅、财政部办公厅《关于印发2012年能繁母猪饲养补贴实施指导意见的通知》（农办财〔2012〕49号）和省农业厅、省财政厅《关于做好2012年能繁母猪饲养补贴工作的通知》（琼农字〔2012〕78号）文件精神，结合我市实际，特制定本方案。

一、指导思想

认真落实国家惠农政策，扎实做好2012年能繁母猪补贴工作，调动农民养殖母猪积极性，保护母猪生产能力，提高生猪出栏率，稳定生猪生产，保障猪肉市场供应，促进我市养猪业又好又快发展，农民持续增收。

二、补贴对象

市境内（含国营农林场）所有饲养能繁母猪的场（户），包括规模养殖场、养殖户、种猪场和散养户。能繁母猪是指饲养10个月以上并产过一胎仔猪，能继续繁殖仔猪的母猪。

三、补贴标准

按每头100元的标准补贴。

四、项目实施程序

（一）核实和统计。能繁母猪的核实和统计工作，由各镇政府、国营（地方）农林场和市畜牧兽医局分工负责。各镇政府、国营（地方）农林场负责辖区内的散养户和小规模养猪户（50头能繁母猪以下的养殖户）的调查核实和统计工作，市畜牧兽医局负责全市大的规模养猪场（50头能繁母猪以上的规模养殖场）的调查核实和统计工作。此次统计结果将作为2012年能繁母猪补贴发放的依据。

1.调查核实。由各镇政府、国营（地方）农林场和市畜牧兽医局组织队伍对辖区内饲养的能繁母猪进行逐村、 逐户、逐头调查核实，并按照《儋州市2012年能繁母猪核准统计表》的要求，逐项登记、建档。统计核准工作要做到“四见”，即：见猪，调查人员要逐场逐户逐头调查，对于拒绝核查的养殖场（户）或现场核实后再增加能繁母猪的，不得纳入补贴范围；见人，现场调查的母猪数要经母猪养殖户和统计人员共同签字确认；见标，对母猪佩带耳标的畜禽标识实行一猪一号登记造册、建立档案；见榜，每村（场）核准的能繁母猪饲养数量要在村（场）中张榜公示，接受村民监督，数量不实及时更正。

2.汇总上报。经各镇政府、地方国营农（林）场调查核实的《能繁母猪核准统计表》必须经村委会（队）和镇政府（农场）分别审核盖章，并将审核后的《能繁母猪核准统计表》制成电子表格，将《能繁母猪核准统计表》的实体表与电子表格统一上报市畜牧兽医局。市畜牧兽医局负责汇总全市能繁母猪数量，审核无误后，会同市财政局上报省农业厅和省财政厅。

（二）能繁母猪补贴资金发放方式。由市畜牧兽医局负责汇总核实能繁母猪数量和补贴金额，并报市财政局审核，由市财政局通过惠农“一卡通”直接将补贴资金发放给养殖场（户）。注册企业由市财政局根据企业提供的相关企业名称、法人、账户等信息直接拨付。对于没有办理惠农“一卡通”的农户，各镇政府、国营（地方）农林场要及时协调当地财政部门与农村信用社为农户办理惠农“一卡通”。

五、时间安排

2012年8月15日至9月15日为数据统计核实工作阶段，9月20日前将《能繁母猪核准统计表》的实体表与电子表格统一上报市畜牧兽医局，由市畜牧兽医局汇总上报市财政局、省农业厅和省财政厅。11月底前完成补贴资金拨付工作。

六、保障措施

（一）加强组织领导。成立市能繁母猪补贴工作领导小组，其组成人员如下：

组 长：张广英（市政府副市长）

副组长：李昌充（市畜牧局副局长）

罗炜阳（市财政局副局长）

万 俊（市农委纪委书记）

成 员：张学刚（市畜牧局副局长）

王世权（市财政局农财科科长）

领导小组下设办公室在市畜牧兽医局，具体负责能繁母猪补贴工作的监督和指导。办公室主任由李昌充同志兼任，副主任由张学刚同志兼任，办公室工作人员从市财政局、市畜牧兽医局抽调。

（二）加强监督管理。市畜牧兽医局要加强监督检查，杜绝出现虚报、假报以及“特权猪”、“人情猪”等违规行为，领导小组要组织调查核实小组深入农村养殖户和规模饲养场抽样检查、核实，严格按“四见”的要求，做到见猪、见人、见档、见榜。市财政部门要做好资金的管理和发放，确保补贴资金及时、足额发到养殖场（户）。

（三）增强实施公开透明度。市畜牧、财政等部门要加大能繁母猪补贴工作的宣传力度，让广大养殖户和养殖企业充分了解能繁母猪补贴的内容、对象、标准、方式。各镇政府和国营（地方）农林场要将每个村的养殖户或养殖场名单及能繁母猪存栏数量和补贴金额等情况在所在村（场、队）张榜公示，能繁母猪存栏50头以上的规模场要在儋州政务网上公示，接受社会和群众监督，保证能繁母猪补贴规范透明、公开、公正、公平。
