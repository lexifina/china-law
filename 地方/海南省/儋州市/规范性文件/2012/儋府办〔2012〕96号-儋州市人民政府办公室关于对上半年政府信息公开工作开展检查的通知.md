# 儋州市人民政府办公室关于对上半年政府信息公开工作开展检查的通知

儋州市人民政府办公室文件

儋府办〔2012〕96号

儋州市人民政府办公室关于对

上半年政府信息公开工作开展检查的通知

各镇政府，市政府直属各单位：

按照儋府办〔2012〕84号文件要求，决定对今年上半年政府信息公开工作开展专项检查。现将有关事项通知如下：

一、检查对象

各镇政府、市政府直属有关单位。

二、检查内容

按照儋府办〔2012〕84号文件确定的检查内容进行专项检查。

三、检查时间

2012年7月22—30日。

四、检查方式

采取听汇报、查资料、看现场等方式进行。

五、分组安排

（一）第一检查组

组长：钟金亮（市政府政研督查室副主任）

成员：龙继业（市政府政研督查室）

古小东（市信息中心）

检查单位：那大镇、海头镇、雅星镇、南丰镇、白马井镇、市发展和改革委员会、市教育局、市科学技术局、市公安局、市民政局、市食品药品监督管理局。

（二）第二检查组

组长：黄鹄（市效能办副主任）

成员：韩望（市效能办）

王健雄（市效能办）

检查单位：木棠镇、光村镇、东成镇、和庆镇、市旅游局、市司法局、市财政局、市人力资源和社会保障局、市安全生产监督管理局、市文化广电体育局。

（三）第三检查组

组长：何发亮（市政府法制办公室副主任）

成员：黄高清（市政府政研督查室）

王春彩（市信息中心）

检查单位：王五镇、排浦镇、大成镇、新州镇、市监察局、市审计局、市工业和信息化局、市交通运输局、市卫生局、市人口和计划生育委员会。

（四）第四检查组

组长：郭开能（市粮食局副局长）

成员：曾常识（市政府办公室）

李发南（市政府办公室）

检查单位：中和镇、三都镇、峨蔓镇、兰洋镇、市住房和城乡建设局、市统计局、市海洋和渔业局、市农业委员会、市商务局、市国土环境资源局。

六、检查要求

（一）被检单位要按照儋府办〔2012〕84号文件向检查组提交相关材料和表格。

（二）被检查单位要自查并做好便民服务中心、公开栏、网站及下属单位等相关的政府信息公开工作。

（三）各检查组要及时汇总各被检单位的得分情况，于8月5日前将有关材料、表格、打分、需要整改的内容等情况送到市政府政研督查室。市政府办公室对各单位得分情况通报全市。
