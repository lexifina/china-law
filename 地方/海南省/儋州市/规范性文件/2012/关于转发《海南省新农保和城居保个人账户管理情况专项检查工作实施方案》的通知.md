# 关于转发《海南省新农保和城居保个人账户管理情况专项检查工作实施方案》的通知

儋人社发33号

儋州市人力资源和社会保障局

关于转发《海南省新农保和城居保个人账户

管理情况专项检查工作实施方案》的通知

各镇，各国营（地方）农（林）场：

为进一步规范我市新农保和城居保个人账户管理，提升经办管理服务水平，切实维护参保人员合法权益，省人力资源和社会保障厅统一于8月份至9月份在全省开展新农保和城居保个人账户管理情况专项检查。现将《海南省新农保和城居保个人账户管理情况专项检查工作实施方案》（琼人社发259号）转发给你们，请高度重视，认真组织实施，做好新农保专项检查的自查和迎检工作。

附件：海南省新农保和城居保个人账户管理情况专项检查工作实施方案.doc

二〇一二年八月二十二日
