# 儋州市人民政府关于发布儋州市政务服务事项目录的公告

儋州市人民政府关于

发布儋州市政务服务事项目录的公告

儋府〔2014〕77号

2014年我市清理行政审批事项工作已经结束，确定45个单位(含中央、省直属单位)政务服务事项460大项711子项，其中行政审批(含行政许可和非行政许可审批)事项274大项415子项，管理服务事项186大项296子项(详见附件),现予发布，自2014年11月12日起正式实施。

《儋州市政务服务事项目录》发布后，将作为部门行政审批权力清单，按照《海南省行政审批事项目录管理办法》实行目录管理，原已实施的事项名称与此次确定的事项名称不同的，以此次确定的事项名称为准，今后目录之外的事项不再实施审批，否则视为违规审批。

附件：儋州市政务服务事项目录

儋州市人民政府

2014年10月23日
