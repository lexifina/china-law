# 儋州市人民政府儋州市人民武装部关于做好2017年征兵工作的通知

各镇政府，国营（地方）农林场，市政府直属各单位：

为高标准完成我市今夏秋季新兵征集任务，根据全国、省征兵工作会议精神，结合我市实际，现将2017年征兵有关事项通知如下：

一、征集对象和范围

男兵征集对象以高中（含职高、中专、技校）毕业以上文化程度的青年为主，优先征集学历高的青年入伍，优先批准应届毕业生入伍。征集非农业户口的青年，应具备高中毕业以上文化程度；征集农业户口青年，应具备初中毕业以上文化程度，尽量多征集高中毕业以上文化程度青年入伍，减少并逐步取消初中生的征集。征集的女青年，为普通高中应届毕业生和普通高等院校全日制应届毕业生及在校生。大专以上高学历青年，2017年已被普通高等学校录取及正在高校就学的学生应征并且符合条件的，优先批准入伍。

优先征集在海上维权、抢险救灾和灾区恢复重建中表现突出的青年入伍。烈士子女、因公牺牲军人子女、现役军人子女符合条件的，应当优先批准入伍。少数民族居住集中地区应当多征集懂双语言、文化程度较高、有专业特长特别是部队建设需要的优秀少数民族青年入伍。革命老区应当多征集老红军、老复员军人后代入伍。有台湾省籍人口和归侨、侨眷的地区，应当尽可能多征集一些台湾省籍和归侨、侨眷青年入伍。

二、征集年龄和条件

（一）征集年龄。男青年为年满18至22周岁，普通高等学校毕业生可以放宽至24周岁，初中文化程度男青年不超过20周岁。女青年为2017年年满18至22周岁。根据本人自愿，可征集年满17周岁的高中毕业生入伍,起算时间均从1月1日起至12月31日止。

（二）征集条件。政治条件，按照公安部、原总参谋部、原总政治部颁发的《征兵政治考核工作规定》和有关规定执行。体格条件，按照国家卫生计生委、原总参谋部、原总后勤部颁发的《应征公民体格检查标准》和有关规定执行。

三、征集办法和时间

（一）征集办法。适龄青年应当在本人常住户口所在地应征，普通高等学校应届毕业生、大学在校生既可在学校所在地应征，也可以在户口所在地应征，经政治考核、体检合格并符合其他征集条件的，由市人民政府征兵办公室批准入伍。批准的时间，统一填写2017年9月1日，新兵的军龄一律从2017年9月1日起算。

适龄男青年和女青年征集实行网上报名，网名为：全国征兵网，网址为：http//www.gfbzb.gov.cn。

（二）征集时间。2017年1月10日—9月30日，分六个阶段进行。宣传发动：1月10日—7月31日；体格检查：8月1—7日；政治考核：8月8—20日；体格复查：8月21—27日；走访定兵：8月28日—9月9日；新兵起运：9月10—30日。

女青年体检：市征兵办于2017年8月6日组织初检，省征兵办于8月12日组织复检。

四、上站体检任务

根据各基层单位人口基数、适龄青年登记分布情况，确定各单位上站体检男青年任务数，具体任务为：那大镇230人、新州镇75人、白马井镇75人、东成镇65人、木棠镇65人、雅星镇90人、大成镇105人、海头镇55人、王五镇55人、和庆镇35人、南丰镇25人、中和镇40人、峨蔓镇30人、光村镇50人、排浦镇25人、兰洋镇30人，洋浦90人，热科院20人，儋州林场、和庆农场、番加农场、侨植农场、南辰农场各3人，木排热作场、农垦机械厂、鹿母湾林场各2人，共1181人。

五、有关要求

（一）严格落实网上报名应征。要按要求，熟练掌握“全国征兵网”的使用程序方法，进一步抓好登记报名、现场确认、受理咨询举报等工作。2017年12月31日以前年满18周岁的男性公民，应登录“全国征兵网”进行兵役登记，申请当年缓征的可只进行兵役登记，应征报名青年需在7月25日前完成网上应征报名。

（二）深入开展征兵宣传发动。各级领导干部要切实履行职责，实行分片包干、分村负责、责任到人，确保宣传教育、思想发动不流于形式，不走过场。深入乡村集市、田间地头、工厂车间、学校单位，采取多种手段开展宣传发动。做到电视里有影，广播（喇叭）中有声，宣传栏橱窗上有字，主要街道路口有口号、标语，人员集中地设有宣传站点，使宣传发动形象直观、寓教于乐、生动活泼，大力营造征兵工作良好的社会氛围。

（三）密切配合抓好各个环节。征兵工作是政府的一项重要工作，各镇镇长、各企事业单位法人代表是第一责任人，必须高度重视，切实履行职责，在人力、物力、财力上给予保障。卫生部门要按照标准要求，切实搞好应征青年的体检工作，市委宣传部、儋州广播电视台要大力宣传《兵役法》、征兵政策规定及征集条件等，切实做到征兵政策规定家喻户晓，深入人心。市兵役机关、市公安局、市教育局、各公安派出所、学校、村（居）委会要密切配合，共同抓好政考工作，确保政考质量。

（四）坚决杜绝征兵不正之风。各级领导和征兵工作人员要自觉在征兵中深化群众路线主题教育活动成果、落实“三严三实”要求，严格执行和落实军委国防动员部、省军区关于廉洁征兵系列规定，对违反者，一经查实将严肃处理。监督职能部门要充分发挥组织监督、舆论监督和群众监督的作用，认真履行职责，确保征兵工作全程公开、公平、公正。各级要设立举报箱、举报电话，接受社会监督。
