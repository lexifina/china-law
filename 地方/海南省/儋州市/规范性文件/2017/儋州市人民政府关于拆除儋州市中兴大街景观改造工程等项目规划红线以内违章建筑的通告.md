# 儋州市人民政府关于拆除儋州市中兴大街景观改造工程等项目规划红线以内违章建筑的通告

为进一步加强和改进我市城市规划管理，改善和提升那大城区环境质量，市政府决定对那大城区中兴大街、兰洋南路、兰洋北路、龙门路(原交通路）等市政道路进行景观提升改造。改造工期为：2017年2月28日至10月1日。根据《中华人民共和国土地管理法》、《中华人民共和国城乡规划法》（2015年修正）及《海南省查处违法建筑若干规定》等法律法规的规定，市政府决定自2017年4月18日起对那大城区中兴大街（225国道兰优村至云月路，云月路至中兴大街西延线，两院植物园至云月湖度假村），兰洋南路、兰洋北路、龙门路（原交通路）、科学南路、杏园七街等6条市政道路两侧的违法建筑、违章建筑、临时建筑和实体围墙依法实施拆除整治。现将拆除整治具体事项通告如下：

一、拆除时间：自行拆除时段为2017年4月18日至5月2日；依法强制拆除时段自2017年5月3日起。

二、拆除范围：未经市规划部门批准的违法建筑及违章建筑；占压道路红线和地下管线、侵占规划绿地和消防通道的建筑；影响市容观瞻的建筑；超过期限的临时建筑；沿街实体围墙。

三、具体位置：

（一）中兴大街人行道景观改造工程（道路红线宽60米，控规项目退让红线距离为18米，具体范围以批准的项目修建性规划为准）。

1.云月路口（原工业大道）至龙门路口（原交通路）段长度为1759米，人行道外边线外侧各13米。

2.龙门路口（原交通路）至儋耳路口（市中医医院）段长度为439米，人行道外边线外侧各5米。

3.儋耳路口（市中医医院）至解放北路口（荣兴酒店）段长度为905米，人行道外边线外侧各7米。

4.解放北路口（荣兴酒店）至先锋路口（福源酒店）段长度为470米，人行道外边线外侧各10米。

5.先锋路口（福源酒店）至美扶三角绿地段长度为3885米，人行道外边线外侧各13米。

6.市体育中心（大门两侧）段长度为360米，人行道外边线外侧各7米。

7.市体育中心至终点建鹏钢材厂段长度为550米，人行道外边线外侧各13米。

（二）兰洋南路（道路红线宽40米，控规项目退让红线距离为8米，具体范围以批准项目修建性规划为准）：海航新天地酒店至万福东路口（英鸣学校）人行道外边线东、西两侧各2米。

（三）兰洋北路（道路红线宽40米，控规项目退让红线距离为10米，具体范围以批准项目修建性规划为准）：海航新天地酒店至国盛路口（文化广场）人行道外边线外东、西两侧各2米。

（四）龙门路（原交通路，道路红线宽55米，控规项目退让红线距离为10米，具体范围以批准的项目修建性规划为准）：人民西丁字路口至宝岛路口人行道外边线外东、西两侧（西侧3米，东侧8米）。

四、各产权单位和个人在拆除沿街建筑和实体围墙后，由施工单位统一组织绿化。

五、被拆迁人自行或委托拆除时，应注意安全施工，避免发生人身伤亡事故造成财产损失；拆除的建筑物、构造物等存在产权、债务纠纷的，在本公告发布之日后三天内由当事人双方协商解决，达不成一致意见先行折除，清理完毕后，按照当事人双方协商意见或有关部门裁决执行。

六、对未按期自行拆除沿街建筑物、构筑物和实体围墙的，由市政府组织有关部门依法强制拆除。

七、对阻碍行政执法人员执行公务的，由公安机关依照《中华人民共和国治安管理处罚法》予以处罚。涉嫌触犯刑法的，移送司法机关追究刑事责任。

八、那大城区市政道路景观提升工程项目是我市创建国家园林城市的重点项目，是民生工程、民心工程，望各有关单位和产权单位及个人自觉服从我市建设大局，积极主动配合，确保该项目建设顺利进行。

特此通告。

儋州市人民政府
