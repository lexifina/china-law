# 儋州市人民政府办公室关于印发2017年海南儋州全民健身日活动总体工作方案的通知

各镇政府，国营（地方）农林场，市政府直属各单位：

《2017年海南儋州全民健身日活动总体工作方案》已经市政府同意，现印发给你们，请认真组织实施。

儋州市人民政府办公室

2017年8月3日

（此件主动公开）

2017年海南儋州全民健身日活动

总体工作方案

2017年海南儋州全民健身日活动将于8月4—8日在那大城区举行。为明确任务分工，强化责任落实，充分调动各责任单位的积极性，按计划有序推进各项活动的筹备工作，确保活动圆满成功，结合实际，特制定本方案。

一、指导思想

通过举办全民健身日活动，倡导全民运动、幸福儋州；吸引各类运动群体参与，提高市民参与感及幸福指数，促进全民健身国家战略，推动全民健身运动蓬勃发展，提高全民身体素质和健康水平，丰富儋州市民文化体育生活。

二、活动主题

全民健身 幸福儋州
