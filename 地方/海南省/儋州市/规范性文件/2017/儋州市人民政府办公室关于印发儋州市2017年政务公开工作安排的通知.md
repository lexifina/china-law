# 儋州市人民政府办公室关于印发儋州市2017年政务公开工作安排的通知

各镇人民政府，市政府直属各单位：

根据《国务院办公厅关于印发2017年政务公开工作要点的通知》（国发办〔2017〕19号）、《海南省人民政府办公厅关于印发海南省2017年政务公开工作安排的通知》（琼府办〔2017〕62号）要求，现将《儋州市2017年政务公开工作安排》印发给你们，并就抓好工作落实提出如下要求：

一、提高认识，加强组织领导

2017年，我省第七次党代会和我党第十九次全国代表大会

将相继召开，做好政务公开工作，助力稳增长、促改革、调结构、惠民生、防风险，向社会公众展现一个透明、开放、自信的服务型政府，意义十分重大。各镇政府、各部门要切实提高对做好政务公开工作重要性的认识，将其列入重要议事日程，主要负责人亲自抓，分管负责人具体抓，定期研究部署推进工作。政务公开机构要发挥好组织协调、指导推进、监督检查作用，跟进抓好工作落实。要建立健全政务公开工作机制，确保保密审查、主动公开发布、政府网站内容保障、绩效问责等工作机制健康运转。要坚持新发展理念，努力通过新作为取得公开工作新成效，以优异的成绩迎接党的十九大和省第七次党代会胜利召开。

二、细化任务，明确工作责任

各镇政府、各部门要根据职能和公开工作的新要求，按照“部门推进、系统保障、集中展示”的思路，尽快在本部门网站建立相应公开专栏，集中公开本部门和本系统的相关信息。市政府门户网站将建立重点领域信息公开专栏，集中展示各镇政府、各部门年度公开工作任务有关落实情况。市信息中心围绕落实年度政务公开工作任务开设的有关专栏网址，于2017 年5月1日前报送市政府政研督查室。

三、严格制度，强化监督考核

各镇政府、各部门要建立健全督促检查和考评制度，认真抓好年度公开任务落实的跟踪督办，对存在的问题及时提出解决办法，并将政务公开纳入绩效考核体系，无绩效考核体系的政府部门，年内要建立政务公开专项考核机制，推动公开工作落到实处。市政务公开领导小组将坚持每季度检查通报公开任务落实情况， 年底组织开展政务公开第三方评估，并公布评估结果。各镇政府、 各牵头任务部门要在2017年12月31日前向市政务公开领导小组报送本年度政务公开工作落实情况。
