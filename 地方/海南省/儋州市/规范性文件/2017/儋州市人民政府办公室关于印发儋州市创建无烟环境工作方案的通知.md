# 儋州市人民政府办公室关于印发儋州市创建无烟环境工作方案的通知

各镇政府，国营（地方）农林场，市政府直属各单位：

《儋州市创建无烟环境工作方案》已经市政府同意，现印发给你们，请认真组织实施。

儋州市人民政府办公室

2017年11月1日

（此件主动公开）

儋州市创建无烟环境工作方案

为切实做好创建国家卫生城市和健康促进市试点项目工作，控制和减少吸烟造成的危害，提高环境卫生质量，倡导健康生活方式，保障群众健康生活，结合我市实际，特制定本工作方案。

一、工作目标

全市各级党政机关、企事业单位，以及住宿、餐饮、交通、体育、商业等公共场所在2020年12月底前完成全市无烟环境的创建工作。

二、范围及标准

1．机关、团体和企事业单位参照《无烟机关、无烟单位标准》和《无烟办公楼标准》中控烟标准执行；

2．医疗卫生计生机构参照《无烟卫生计生机构标准》中控烟标准执行；

3．学校参照《无烟学校标准》中控烟标准执行；

4．企业参照《无烟企业标准》中控烟标准执行；

5．客运企业参照《无烟企业标准》中控烟标准执行；客运车辆、出租车等参照《无烟出租车标准》中控烟标准执行；客车站室内等候厅、售票厅参照《无烟公共场所场所和工作场所标准》中控烟标准执行；

6．档案馆、图书馆、书店、各类餐馆，商店（场）、超市、邮政、电信、金融、保险等行业对外营业场所，以及影剧院、歌舞厅、理发店、网吧和室内体育公共活动场所等参照《无烟公共场所和工作场所标准》中控烟标准执行；

7．其他办公场所均需按照《无烟办公楼标准》、《无烟公共场所和工作场所标准》中控烟标准执行；

8．其他室内公共场所需按照《无烟公共场所或工作场所标准》中控烟标准执行。

以上标准详见附件。

三、实施步骤

（一）组织发动阶段（2017年9月1日—11月30日）。各创建单位成立组织管理机构，制定本单位及负责范围的无烟环境创建管理制度，评估本单位及负责范围的吸烟和二手烟暴露情况，营造氛围，发布无烟环境创建倡议，培训控烟监督员、劝导员，完善本单位控烟设施。

（二）全面实施阶段（自2017年12月1日开始）。各创建单位结合实际，整合利用资源，全面开展无烟环境创建工作，落实各项措施。

四、职责分工

（一）市文明办负责全市无烟环境创建的统筹、协调及督导检查。

（二）市委宣传部负责组织市级新闻媒体开展控烟宣传工作，在《今日儋州》报设控烟宣传专栏，在儋州广播电视台播放控烟公益广告，加大对全市控烟情况的宣传报道。

（三）市卫生计生委负责全市卫计系统无烟环境创建工作；负责理发店、浴室（洗脚城）、歌舞厅等公共场所的无烟环境创建工作；负责全市各系统、各部门无烟环境创建的技术指导。

（四）市教育局负责全市学校、幼儿园、托儿所的教室、实验室、寝室、活动室和其他未成年人集中活动的场所无烟环境创建工作。

（五）市交通运输局负责全市车站、公共交通工具的无烟环境创建工作。

（六）市食品药品监管局负责全市各类餐饮场所、宾馆的无烟环境创建工作。

（七）市文体局负责全市文化馆、体育场所、图书馆、书店、网吧等文化娱乐场所无烟环境创建工作。

（八）市商务局负责全市商店（场）、超市、邮政、电信、金融、保险等行业对外营业场所无烟环境创建工作。

（九）市工商局负责取缔在公交站台等公共场所设置烟草广告。

（十）市公安局负责依法处理在禁止吸烟场所吸烟且不听劝阻所引发的治安案件。

（十一）各镇、农林场和相关单位负责各自辖区和本单位无烟环境创建工作。

五、工作要求

（一）统一认识，加强领导。开展控烟工作，消除或减少因吸烟造成的危害，营造健康、清洁的社会环境，是全民健康教育和创建国家卫生城市的一项重要内容，也是提高人民群众健康素质、促进健康、提高生活质量、建立健康的行为和生活方式的措施之一。各单位要高度重视，加强组织领导，认真做好无烟单位创建工作，建立健全职责明确、运行良好的控烟工作制度，把控烟工作纳入管理目标和工作考核内容，建立长效工作机制。

（二）强化宣传，营造氛围。无烟单位创建评选关系到广大干部职工的切身利益。各单位要广泛宣传禁烟工作的重要意义，普及烟草危害相关知识。并积极开展吸烟行为干预，降低吸烟率。通过创建无烟单位活动，树立单位干部职工健康为本意识，促进健康行为和健康生活方式的养成。要将无烟单位标准张贴在单位显著位置，保证每个职工都能了解掌握标准要求，形成人人从自身做起，并相互监督的氛围，共建无烟环境，使控烟工作深入人心。

（三）示范引领，强化指导。各级党政机关、学校、医疗卫生单位要积极带头开展无烟单位创建活动，在控烟工作中起到模范带头作用，尤其是医疗卫生单位要做好表率，实行全面禁烟。市卫生计生委负责抓好控烟工作的业务培训、提供材料制作模板、技术指导和监测评估等工作，发挥专业优势，使控烟工作取得实效。

（四）落实标准，完善机制。各部门、单位要按照标准做到全面无烟，建立健全禁烟工作制度、奖惩制度。同时，以“一创五建”工作为契机，探索建立禁烟长效机制，构建社会、单位、家庭三结合的禁烟网络，将禁烟活动由单位逐步延伸到家庭、社会，努力创造优美舒适的工作生活环境。

（五）加强督查，强化落实。各镇和行业主管部门要按照属地管理或行业管理原则，对辖区或所属单位落实控烟进展情况进行检查。市文明办、市卫生计生委以暗访和不定期抽查的方式对有关部门、单位控烟落实情况进行督查，对落实不到位的要责令其限期整改，逾期不整改的将予以全市通报批评，以确保我市实现“一创五建”各项工作目标。

附件1

无烟办公楼标准

一、办公楼内所有场所无人吸烟、无烟味、无烟头。

二、办公楼有符合全面无烟环境成果巩固原则的控烟制度和有效的实施措施。

三、办公楼内无吸烟区域、吸烟室及吸烟工具。

四、办公楼有明确的提示进入无烟办公楼的标识，楼内有明显的禁烟标识，有配合无烟环境成果巩固的宣传。

五、设有控烟监督员，对办公楼内的吸烟行为进行劝阻。

六、所属区域内无烟草制品销售，无烟草广告，无烟草赞助与促销活动。

附件2

无烟公共场所或工作场所标准

一、所有室内场所应做到无人吸烟、无烟味、无烟头。

二、有符合成果巩固全面无烟环境原则的控烟制度和有效的实施措施。

三、室内场所无吸烟区域、吸烟室及吸烟工具。

四、场所入口处有明确的提示进入无烟场所标识，场所内所有区域有明显的禁烟标识，有配合无烟环境成果巩固的宣传。

五、设有控烟监督员，对场所内的吸烟行为进行劝阻。

六、所属区域内无烟草制品销售，无烟草广告，无烟草赞助与促销活动。

附件3

无烟机关、无烟单位标准

一、成立成果巩固无烟单位工作机构，明确职责，指定专人负责，将无烟单位建设工作纳入本单位日常管理。

二、制定成果巩固无烟环境工作计划，建立健全控烟考评奖惩制度，设有控烟监督员，及时制止并劝阻违规吸烟行为。

三、所有室内区域全面禁止吸烟（无人吸烟、无烟蒂、无烟味），建筑物入口处有明确的提示进入无烟场所的标识，楼内有明显的禁烟标识，室内无烟具，室外可设吸烟区。

四、开展多种形式的控烟、戒烟宣传教育和服务，有配合成果巩固无烟环境的宣传内容。

五、单位职工履行劝阻吸烟行为的责任和义务。

六、定期对职工、控烟监督员进行培训。

七、有鼓励和帮助吸烟职工戒烟的措施或活动。

八、单位辖区内禁止销售烟草制品，无烟草广告，无烟草赞助与促销活动。

附件4

无烟卫生计生机构标准

一、成立控烟领导组织，将无烟机构建设纳入本机构发展规划。

（一）本机构有控烟领导小组，职责明确。

（二）各部门有专人负责控烟工作，职责明确。

（三）将控烟工作纳入本机构的工作计划（包括资金保障）。

（四） 本机构领导班子成员带头不吸烟， 吸烟成员带头戒烟。

二、 建立健全控烟考评奖惩制度。

（一）本机构有控烟考评奖惩制度。

（二）有控烟考评奖惩标准。

（三）有控烟考评奖惩记录。

三、所属区域有明显的禁烟标识，室内完全禁烟。

（一）本机构所有建筑物的入口处有清晰明显的禁止吸烟提示。

（二）机构所属管辖区域的等候厅、会议室、厕所、走廊、电梯、楼梯等区域内有明显的禁烟标识。

（三）机构室内场所无人吸烟、无烟味、无烟蒂，达到完全禁烟。严禁工作人员穿工作服在任何场所吸烟。

（四）合理设置室外吸烟区（远离密集人群和必经通道）。

四、设有控烟监督员和巡查员。

（一）机构内设有控烟监督员和巡查员。

（二）对控烟监督员和巡查员进行相关培训，并有培训记录有定期监督、巡查记录。

五、开展多种形式的控烟宣传和教育。

（一）有一定数量和种类的控烟宣传材料。

（二）有大众控烟宣传活动。

六、明确规定全体职工负有劝阻吸烟的责任和义务。

（一）有对职工进行控烟知识培训（包括劝阻技巧等），并培训等记录。

（二）有劝阻工作相关制度。

（三）工作人员发现吸烟者及时劝阻。

七、鼓励和帮助吸烟职工戒烟。

（一）掌握机构所有员工吸烟情况。

（二）对员工提供戒烟帮助。

八、所属区域内禁止销售烟草制品。

机构内无烟草广告，商店、小卖部、食堂不出售烟草制品。

九、医务人员掌握控烟知识、方法和技巧，对吸烟者至少提供简短的劝阻和戒烟指导。

（一）医护人员要了解吸烟的危害和戒烟的益处，相关科室的医生要掌握戒烟方法和技巧。

（二）医生对门诊、住院病人需询问吸烟史，对其中的吸烟者进行简短戒烟干预并有记录。

十、医疗机构在相应科室设戒烟医生和戒烟咨询电话；设有戒烟门诊或在相应科室设戒烟医生，并有工作记录。

附件5

无烟学校标准

一、中等及以下教育机构全面无烟校园标准。

（一）学校所有区域（室内和室外）无人吸烟、无烟味、无烟头。

（二）有符合成果巩固全面无烟环境原则的控烟制度和有效的实施措施。

（三）学校所有场所无吸烟区域、吸烟室及吸烟工具。

（四）学校入口处有明确的提示进入无烟校园的标识，校内有明显禁烟标识，有配合无烟环境成果巩固的宣传。

（五）设有控烟监督员，对学校内的吸烟行为进行劝阻。

（六）学校所属区域无烟草制品销售，无烟草广告，无烟草赞助与促销活动。

（七）学校课程中有吸烟及二手烟危害的相关教学内容。

二、高等教育机构全面无烟校园标准。

（一）学校规定区域内无人吸烟、无烟味、无烟头。

（二）学校教学区（包括教学楼、图书馆、运动场馆等）以及学生宿舍、食堂等生活区的所有室内和室外场所禁止吸烟。

（三）有符合成果巩固全面无烟环境原则的控烟制度和有效的实施措施。

（四）学校所有室内场所无吸烟区域、吸烟室及吸烟工具。

（五）学校入口处有明确的提示进入无烟校园的标识，校内有明显禁烟标识，有配合无烟环境成果巩固的宣传。

（六）设有控烟监督员，对学校内的吸烟行为进行劝阻。

（七）学校所属区域无烟草制品销售，无烟草广告，无烟草赞助与促销活动。

附件6

无烟企业标准

一、室内工作场所无人吸烟、无烟味、无烟头。

二、室内工作场所无吸烟区域、吸烟室及吸烟工具。

三、有工作场所控烟的管理制度和实施措施，员工广泛知晓。

四、工作场所有明显的禁烟标识或有效的提醒，有无烟环境的宣传。

五、有控烟监督员，确保工作场所内无吸烟行为。

附件7

无烟出租车标准

一、出租车内禁止吸烟（无论车内是否有乘客，无论行驶或停车等待，无论车窗是否打开）。

二、出租车公司有符合全面无烟出租车成果巩固原则的控烟制度和有效的实施措施。

三、出租车公司有配合全面无烟出租车的宣传活动。

四、对于乘客吸烟出租车司机要进行劝阻。

五、出租车内醒目处应设有禁烟标识。

六、出租车内外无烟草广告。
