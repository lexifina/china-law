# 儋州市人民政府办公室关于印发儋州市小型农田水利设施调查摸底工作方案的通知

各镇政府，国营（地方）农林场，市政府直属各单位：

《儋州市小型农田水利设施调查摸底工作方案》已经市政府同意，现印发给你们，请认真组织实施。

儋州市人民政府办公室

2017年7月18日

（此件主动公开）

儋州市小型农田水利设施调查摸底工作方案

根椐省水务厅《关于加强小型农田水利设施管护的指导意见》（琼水农水函〔2017〕189号）的要求，结合实际，制定本工作方案。

一、调查摸底范围及内容

（1）调查摸底范围

我市各镇、各农场辖区内的各类小型农田水利设施（不含市管水利设施、农业经营者自建自用水利设施、市农业综合开发办公室管护田洋水利设施），具体包括：

1.大中型灌区末级渠系及配套建筑物；

2.小型灌区（控制灌溉面积1万亩以下）工程渠系及配套建筑物；

3.高效节水灌溉工程的取水、输水设施与配水骨干设施；

4.小型排涝工程（除涝面积3万亩以下的排涝沟道与泵站）；

5.小塘坝（蓄水10万m3以下）；

6.小水闸（过闸流量100 m3/s以下的小（1）与小（2）型水闸）；

7.小泵站（装机功率1000千瓦以下的小（1）与小（2）型灌溉及排水泵站）；

8.灌溉机井。

（2）调查摸底内容

我市各镇、各农场辖区内的各类小型农田水利设施的长度与宗数，具体包括：

1.大中型灌区末级渠系的长度及配套建筑物的宗数；

2.小型灌区工程渠系的长度及配套建筑物的宗数；

3.高效节水灌溉工程的取水、输水设施与配水骨干设施的度度与宗数；

4.小型排涝工程排涝沟道的长度与泵站宗数；

5.小塘坝的宗数及其灌溉渠系的长度；

6.小水闸的宗数；

7.小泵站的宗数；

8.灌溉机井的宗数。

二、职责分工

1.各镇、各农场负责辖区内各类小型农田水利设施调查摸底工作，填报小型农田水利设施调查摸底表；

2.市农业委员会负责汇总、整编小型农田水利设施调查摸底表，技术指导各镇、各农场调查摸底工作；

3.市财政局负责分配拨付调查摸底工作经费。

三、时间步骤

1.2017年7月20日至2017年8月20日，各镇、各农场完成辖区内小型农田水利设施的丈量及清点；

2.2017年8月21日至2017年8月31日，各镇、各农场整编完成辖区内小型农田水利设施调查摸底表并上报市农业委员会；

3.2017年9月1日至2017年9月10日，市农业委员会完成汇总、整编小型农田水利设施调查摸底表。

四、组织机构

为了加强全市小型农田水利设施调查摸底工作，成立儋州市小型农田水利设施调查摸底工作领导小组，其组成人员如下：

组 长：符巨友（市政府副市长）

副组长：钟金亮（市政府副秘书长）

郭博宁（市农业委员会主任）

尹亚峰（市财政局局长）

成 员：王方原（市水务局副局长）

各镇分管农业副镇长

各农场分管农业副场长

领导小组下设办公室在市水务局，主抓小型农田水利设施调查摸底工作。办公室主任由王方原同志兼任，办公室副主任由水务建设与管理科王锡鼎同志担任，成员由农委各科、各水管所抽调组成。

五、保障措施

（一）加强组织领导。各镇、国营（地方）农林场要切实加强小型农田水利设施管护工作的组织领导，指定专人负责，建立协调机制，明确时间节点，精心组织实施。

（二）强化责任落实。市政府加强督查督办，适时开展监督检查，确保任务稳步推进。市水务行政主管部门加强行业指导，督导检查，督促管护人员落实责任。

（三）突出行业指导。市水务行政主管部门要有计划地对各镇、国营（地方）农林场管护主体、管护人员开展技术培训和业务指导。出台规范化、标准化管护技术标准，推行先进的管护经验。

（四）严格监督考核。市水务行政主管部门要建立健全考核制度，制定监督考核办法，开展月检查、季督导、年考评的常态化考核工作。考评结果作为下年度招聘管护人员和奖罚的依据。
