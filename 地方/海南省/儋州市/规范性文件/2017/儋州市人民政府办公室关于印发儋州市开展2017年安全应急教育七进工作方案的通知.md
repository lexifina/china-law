# 儋州市人民政府办公室关于印发儋州市开展2017年安全应急教育七进工作方案的通知

各镇政府，国营（地方）农林场，市政府直属各单位:

《儋州市开展2017年安全应急教育“七进”活动实施方案》已经市政府同意，现印发给你们，请认真贯彻执行。

儋州市人民政府办公室

2017年6月5日

（此件主动公开）

儋州市开展2017年安全应急教育

“七进”活动实施方案

为认真贯彻落实《中华人民共和国安全生产法》、《中华人民共和国突发事件应对法》、《中华人民共和国消防法》、《海南省突发公共事件总体应急预案》、《海南省国民经济和社会发展第十三个五年规划纲要》等法律法规和规定，将安全应急教育宣传“进机关、进企业、进学校、进社区、进农村、进家庭、进场所”（以下简称“七进”）作为提高全民安全素质能力及全社会防范和有效应对安全事件能力的重要基础工作深入持久地开展起来，建立和完善安全应急宣传教育工作的长效机制，构建我市安全社会化工作新格局，结合实际，制订本方案。

一、指导思想

坚持以人为本，以“关注安全、关爱生命”为主线，坚持近期与长远、治标与治本、预防与教育相结合，建立健全安全应急教育宣传工作长效机制，切实加强全市安全教育与应急演练，不断扩大安全生产和应急工作宣传教育覆盖面，营造全社会讲安全、促和谐的良好氛围。

二、工作目标

通过推进安全应急教育“七进”工作，将安全应急教育纳入国民安全教育体系，进一步落实各镇政府、农林场、各部门和社会各界的安全宣传教育工作责任，加强安全应急宣传教育工作，努力营造党政领导重视、部门齐抓共管、群众积极参与的浓厚氛围，切实增强公众安全应急意识，提高全民常识知晓率，深入推进平安儋州建设。

特别是各学校应将安全应急知识纳入学生的素质教育内容，在校生受教育率达到100%；各企业应自觉落实安全应急宣传教育内容，员工受教育率达到100%；各社区应按要求实现社区安全应急宣传教育目标，社区居民受教育率达到70%；全面开展农村安全应急宣传教育工作，农村人口受教育率达到60%以上;普及家庭安全应急宣传教育，家庭受教育率达到60%以上；结合机关单位事务特点，大力开展机关人员安全应急宣传教育工作，特别是加强机关工作人员应急管理和预防应对突发事件能力，使机关工作人员熟悉并掌握相应的安全应急技能率达到100%。

三、组织领导

为推动我市安全应急教育“七进”工作的深入开展，确保各项工作措施得到贯彻落实，市政府成立安全应急教育“七进”工作领导小组，其组成人员如下：

组 长：朱洪武（市政府市长）

常务副组长：林 刚（市政府常务副市长）

副 组 长：肖发宣（市政府副市长）

赵江泽（市政府副市长）

成员由市委宣传部、市直机关工委、市综治办、市发展改革委、市旅游委、市农委（三防办）、市工业和信息化局、市财政局、市教育局、市文化广电出版体育局、市卫生计生委、市公安局、市民政局、市国土局、市生态环保局、市住房城乡建设局、市交通运输局、市商务局、市科技（地震）局、市海洋渔业局、市安全监管局、市城管执法局、市政府应急办、市公安局交警支队、市疾控中心、市食品药品监管局、市机关事务局、市气象局、市工商局、儋州公路局、市人武部、市公安消防支队、儋州公安边防支队、团市委、儋州供电局、中国电信儋州分公司、中国移动儋州分公司、中国联通儋州分公司等相关单位主要负责人或负责常务工作的负责人，以及各镇镇长、农林场场长（董事长）组成。

领导小组下设办公室在市安全监管局（市安委办），主任由詹健炜同志兼任，副主任由市安全监管局副局长谢伟、邓波萱同志担任，工作人员由市安全监管局和市政府应急办抽调人员组成，具体负责安全应急教育“七进”工作的组织、协调、策划、落实、督办以及材料收集等相关工作。

四、工作内容

（一）机关安全应急宣传教育工作（责任单位：市委宣传部、市直工委、市机关事务局、市综治办、市安全监管局、市住房城乡建设局、市工业和信息化局、市民政局、市公安局、市卫生计生委、市地震局、市海洋渔业局、市公安消防支队、市农委、市食品药品监管局等相关单位）。

加强对市直机关安全应急宣传的监督管理，督促各单位结合本部门实际制定并严格执行安全应急管理规定，开展安全应急宣传教育培训, 着力提高各级干部安全应急管理能力，重点开展办公场所防火、防盗、防群体性突发事件、防坠落等安全事故警示教育。

1.各单位成立安全应急组织机构，制定各单位安全应急宣传教育工作计划和实施方案，并严格落实。

2.各单位将安全应急知识纳入干部培训课程，新招聘公务员、参公人员、事业编制人员及聘用人员应经过安全应急知识学习、考试，方可上岗。

3.机关宣传橱窗或宣传栏定期有安全应急内容，定期利用单位广播、闭路电视、电子屏幕等进行安全应急内容提示。

4.机关干部必须掌握“一明四会”知识，即：“明确所在场所的安全重点部位；会报警、会自救互救、会疏散逃生、会处置群体性突发事件”。

（二）企业安全应急宣传教育工作（责任单位：市委宣传部、市安全监管局、市住房城乡建设局、市工业和信息化局、市公安局、市卫生计生委、市地震局、市海洋渔业局、市公安消防支队、市食品药品监管局等相关单位）。

加强对企业的监督指导，使企业单位切实履行各自的安全应急宣传教育职责，落实各项安全制度，推动和引导企业自觉开展多种形式的安全应急宣传教育活动，并结合日常监督检查对员工进行面对面的安全应急宣传教育，培养企业员工的安全应急意识和基本安全应急防范技能。

1.成立安全应急组织机构，建立健全安全应急规章制度和

安全操作规程，配备安全应急宣传教育资料、安全应急演练器

具等。

2.制定安全应急宣传教育、安全应急救援演练方案和培训制度；每年至少组织开展一次员工安全应急培训工作，每年至少开展2次安全应急救援演练；新员工以及具有安全危险性的特殊工种、重点岗位员工上岗前必须进行安全专业培训，培训率达 100%，并持证上岗。

3.企业必须开展经常性的安全应急宣传教育工作，每年要对职工进行一次安全应急知识和安全法律法规考试，保证做到“三懂三会”，即懂本岗位安全危害性、懂基本安全常识、懂预防安全事故措施；会报警、会处置基本安全突发事故、会组织人员疏散。

4.企业建立专职或兼职安全巡查队以及其它形式安全检查队伍，必须定期在企业内部通过开展安全应急演练形式，对员工进行安全应急宣传教育。

5.开展经常性安全应急宣传教育活动。

6.企业内部要开设安全应急宣传专栏、专刊，利用单位广播、闭路电视、电子屏幕、局域网等进行安全应急宣传教育；组织企业员工定期收看安全案例警示教育片，阅读安全应急知识刊物。

（三）学校安全应急宣传教育工作（责任单位：市委宣传部、市教育局、市民政局、市安全监管局、市公安局、市卫生计生委、市地震局、市海洋渔业局、市公安消防支队、市农委、团市委、市食品药品监管局等相关单位）。

各单位共同组织开展青少年安全应急教育活动，督促指导各级各类学校做好以下工作：

1.指导学校成立安全组织机构，建立健全安全工作规章制度，制定开展安全应急宣传教育年度工作计划，将安全教育纳入学生课堂教学内容；学校每学期开展安全应急教育不少于2课时，明确专人负责讲解知识，使全体学生明悉暴恐袭击警示、溺水警示、交通警示、火灾警示、爆炸警示、登高警示、自然灾害警示等安全警示内容，使三年级以上学生会报警求救、会使用灭火器材、会自救逃生。

2.各中小学统一在重点时段、节假日，加强学生安全教育和管控工作，严防学生下水游泳造成溺水死亡事故。

3.指导中小学校每学期至少组织开展一次丰富多彩的安全应急宣传教育（包括组织主题班会、知识竞赛、征文比赛、书画比赛、安全主题夏令营或组织参观消防队、交通事故展示、安全事故展示、参与各类事故及自然灾害逃生自救演习等活动。发动大学生利用假期参与“安全宣传志愿者”行动，义务开展安全应急宣传等）。

4.设立安全应急宣传教育场所，配备图书、挂图、音像制品等安全应急宣传资料，校园内建立固定的安全应急宣传牌（栏）不少于两处，组织开展多种形式的安全应急宣传教育活动。

5.组织开展安全应急“六个一”活动（每年组织一次安全应急知识考试、观看一次安全警示知识教育片、开展一次安全应急技能趣味竞赛运动会、开展一次安全应急板报或手抄报比赛、组织一次模拟安全事故和自然灾害逃生演练）。

6.教育师生员工爱护学校各类安全应急器材和设施，确保完好使用。

（四）社区安全应急宣传教育工作（责任单位：市委宣传部、市民政局、市安全监管局、市公安局、市卫生计生委、市地震局、市海洋渔业局、市公安消防支队、市农委、市食品药品监管局、各镇政府、农林场等相关单位）。

各镇政府，农林场及各社区要进一步加大城市安全应急管理工作力度，督促和指导、派出所、居委会、社区和物业管理等部门落实自身安全责任，因地制宜，拓展社区安全应急建设覆盖面。

1.成立社区安全应急组织机构，建立健全安全应急规章制度和加强安全应急基础档案建设。

2.成立由社区保安人员组成的安全应急巡逻队，每日进行安全巡查；成立由社区离退休人员组成的春防、冬防、大风天等重点安全防范时期安全宣传队，努力消除社区以消防隐患为主的各类安全事故隐患。每半年至少开展一次安全宣传活动。

3. 组织社区居民开展家庭火灾扑救、逃生自救、防抢防盗、自然灾害安全疏散等安全应急演练活动。

4.把安全应急工作纳入创建文明社区工作中，经常性地开展“联百街道、走千村社、进万家庭”和创建“平安文明小区”等活动。

5. 推动辖区内社区建设安全应急宣传活动室一处，设置安全宣传牌和宣传栏不少于两处，配备必要的安全事故应急处置器材（如：防暴器材不少于2套、灭火器不少于10具）、发放安全宣传教育资料、建设各类安全标识展台，定期更新宣传牌和宣传栏的内容；每半年召开安全工作会议，对社区群众开展经常性安全应急教育活动。

（五）农村安全应急宣传教育工作（责任单位：市委宣传部、市安全监管局、市住房城乡建设局、市工业和信息化局、市民政局、市公安局、市卫生计生委、市地震局、市海洋渔业局、市公安消防支队、市农委、市食品药品监管局、各镇政府、农林场等相关单位）。

推动、协助各村做好安全应急宣传工作，研究提出改进和加强农村安全应急工作的意见，为农村安全应急工作提供有力支持。积极推动农村安全应急组织建设并保障工作经费。指导农民群众开展喜闻乐见的安全应急宣传教育活动，培养农民群众的安全应急意识和基本安全应急技能。

1.指导行政村成立村民义务安全应急巡查组织并组织安全应急演练每年不少于一次；制订村民安全公约；组织开展安全应急宣传教育活动；建立安全应急宣传教育制度和活动档案。

2.指导行政村开展安全应急宣传“三个一”活动，即每个行政村配备一个安全应急警示宣传钟，明确一名村干部任安全应急宣传员，每天定时敲一遍钟，提醒村民注意安全防范。

3.指导行政村组织村干部进行安全教育培训。

4.每年利用集市和特殊节日等在人员集中场所组织开展至少一次安全应急宣传活动。

5.每个村要设置固定安全应急宣传牌、宣传栏等。

（六）家庭安全应急宣传教育工作（责任单位：市委宣传部、市安全监管局、市住房城乡建设局、市工业和信息化局、市民政局、市公安局、市卫生计生委、市地震局、市海洋渔业局、市公安消防支队、市农委、市食品药品监管局、各镇政府、农林场等相关单位）。

各镇政府、农林场要在加强各社区、各村（居）委会安全应急管理的基础上，进一步强化家庭安全应急教育，努力提高家庭安全意识，采取多种方式开展安全应急宣传教育，把宣传力度渗透至每个家庭。

1.将安全应急工作宣传纳入“文明家庭”、“五好家庭”等创建工作内容。

2.农村以家庭为单位，成立联防巡逻队，每日进行安全应急巡查；城镇成立由离退休人员组成的春防、冬防、大风天等重点时期安全应急宣传队，每季度至少开展一次安全应急宣传活动。以弱势群体为对象，建立“邻里守望”互助对子。

3.各镇政府要督促下级单位，每年春冬两季组织开展一次家庭安全应急“三个一”活动。即：开展一次安全大检查；开展一次家庭安全应急趣味运动会或知识竞赛；开展一次家庭逃生演习。

4.建立以孤寡老人、智障人、精神病人和农民工等弱势群体为对象的“邻里守望”互助对子。

（七）人员密集场所安全应急宣传教育（责任单位：市委宣传部、市安全监管局、市住房城乡建设局、市工业和信息化局、市民政局、市公安局、市卫生计生委、市商务局、市地震局、市海洋渔业局、市文化广电出版体育局、市公安消防支队、市农委、市食品药品监管局、市工商局等相关单位）。

加强对人员密集场所安全应急宣传的监督管理，督促人员密集场所严格执行安全应急管理规定，开展安全应急宣传教育培训, 重点组织开展以“提示公众所在场所安全逃生路线和紧急出口位置；提示公众所在场所群体突发事件的处置；提示公众所在场所内各种自救互救器材具体放置位置和使用方法”为主要内容的“三提示”主题宣传活动。

1.组织人员密集场所安全应急管理人员、重点岗位人员开

展安全应急教育培训等。

2.定期集中组织人员密集场所从业人员尤其是保安人员开展安全法规和安全应急知识教育，新员工按照有关规定经安全培训合格后方可上岗，每位员工掌握引导疏散顾客逃生的技能。

3．指导向公众开放的人员密集场所通过张贴挂图、放置安全知识刊物、刊播安全公益广告、视频和网络宣传、举办安全应急文化活动等形式，向公众宣传安全应急常识。

4.指导人员密集场所在重点部位、疏散出口的醒目位置设置清晰明示的安全应急警示牌、指示牌等。室内外有大屏幕电子显示屏的，每次开机、待机或切换时要播放安全公益广告，并滚动播放安全应急知识；指导人员密集场所在安全出口配置紧急情况下保障逃生自救需要的简易自救器具和互救器具，并经常检查维护，确保完整好用。

5.指导人员密集场所结合每天的防火巡查、检查，开展安全应急巡查、检查，督促有关单位及时消除安全隐患。

6.指导人员密集场所组织建立义务安全应急组织，经常性开展安全应急技能训练。

五、工作步骤

全市安全应急宣传教育“七进”工作分四个阶段进行：

（一）动员部署阶段（2017年6月1-10日）。各镇政府、农林场、各部门和单位要按照 “七进”工作实施方案，结合单位行业实际，制定安全应急预案与演练等在内的具体工作方案，于6月10日前报市安全应急宣传教育“七进”工作领导小组办公室备案。并及时召开动员会，层层发动，广泛宣传安全应急宣传教育“七进”工作的目的和意义。充分发动新闻媒体营造氛围，不断增强“七进”单位的责任意识和文明意识，营造“安全应急工作靠大家”的浓厚氛围，同时做好“七进”工作的各项前期准备工作。

（二）具体实施阶段（2017年6月11日至11月20日）。各镇政府、农林场、各部门和单位要在安全应急宣传教育“七进”工作领导小组的统一安排部署下，结合辖区及各单位实际，统筹兼顾，科学合理地安排、组织、实施。各单位要在6月份集中开展系列活动。要针对不同类型和层次，培养一批新的“七进”典型并全面推广。市政府将不定期对各单位工作开展情况进行督促指导。

（三）总结验收阶段（2017年11月21-30日）。市政府将对照方案要求对全市安全应急宣传教育“七进”工作进行考核验收。安全应急宣传教育“七进”工作领导小组将组织从关部门抽调骨干人员依据相关规定和标准进行综合性检查验收。

（四）巩固提高阶段（2017年12月至长期）。各镇政府、农林场、各部门和单位要对安全应急宣传教育“七进”工作常抓不懈，形成长效机制，并做好日常管理工作。要定期征求群众意见，召开“七进”典型经验现场交流会，及时解决“七进”单位建设中出现的问题，巩固安全应急宣传教育“七进”工作成果。

六、保障措施

（一）加强组织领导。各镇政府、农林场、各部门和单位要切实加强对“安全教育和应急演练”活动的领导，将其列入重要议程，纳入安全目标责任体系，主要领导亲自抓，分管领导具体抓，相关领导配合抓，明确专门机构和人员负责，按照“谁主管、谁负责”的原则，把责任落实到部门、单位和个人，齐抓共管，形成合力。确保领导到位、措施到位、责任到位。

（二）建立责任追究制。各镇政府、农林场、各部门和单位要在建立健全责任制的基础上，切实抓好责任制和责任追究制的落实。对领导重视不够，责任不到位，安全教育和应急演练不开展，防范措施不落实，导致发生重大安全事故的，要实行“一票否决”。同时，要严格按照事故原因未查清不放过，责任人员未处理不放过，整改措施未落实不放过，有关人员未受教育不放过的“四不放过”原则，进行严肃处理和追究。

（三）迅速动员，组织宣传和演练。各镇政府、农林场、各部门和单位要按照本方案要求，周密部署，认真做好安全教育和应急演练活动的动员工作，并于2017年7月5日前将开展安全应急宣传教育活动及应急演练等相关材料（包括应急预案、方案、图片和总结电子版和纸质版）报送市安全监管局。

（四）强化检查，督促整改。在各镇政府、农林场、各部门和单位在开展安全教育和应急演练的基础上，领导小组将从各单位抽调工作人员，组成若干个联合检查组，深入到各单位开展督导检查，对不开展安全教育和应急演练或开展不认真、应付了事的单位，将严肃问责，并督促整改。

（五）总结和通报。各镇政府、农林场、各部门和单位要积极开展各项安全教育和应急演练，认真总结经验和做法，并于每年年底将安全教育和应急演练总结报送领导小组办公室。领导小组将对全市各镇政府、农林场、各部门和单位开展安全教育和应急演练的情况进行认真研究和总结、通报，确保安全教育和应急演练活动取得实效。

七、工作要求

（一）各单位要充分认识安全应急教育“七进”工作的重要性和迫切性，把安全应急教育“七进”工作作为今年乃至今后一个时期加强基础建设的一项重要工作，扎扎实实开展起来，切实抓出成效。

（二）各单位要成立专门的“七进”工作领导机构，落实专人具体负责，结合实际制定相关的工作计划、量化标准和责任落实制度，积极开展调查研究，将安全应急教育“七进”作为重要的基础工作纳入基层建设和领导绩效考评。要积极推动安全应急教育“七进”工作的长效管理机制，制定有关的工作规划、组织实施办法和对社会单位的考评标准。

（三）认真培养和树立典型。要坚持形式、内容和效果的有机结合，因地制宜，勇于创新。要通过开展安全应急教育“七进”工作，在全社会大力普及安全应急知识，培养树立全民安全意识，提高全社会防范和应对处置各类突发事件能力，最大程度地减少突发事件造成的生命和财产损失。

（四）创新工作举措。结合实际，创新工作方式方法，注重总结推广行之有效的经验和做法。实施过程中遇到的问题要及时研究解决办法，加强信息反馈，争取指导和帮助。
