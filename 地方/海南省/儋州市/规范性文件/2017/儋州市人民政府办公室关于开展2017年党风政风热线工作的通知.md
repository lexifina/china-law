# 儋州市人民政府办公室关于开展2017年党风政风热线工作的通知

各镇政府，国营（地方）农林场，市政府直属各单位：

为做好2017年度全市党风政风热线工作,现就有关事项通知如下：

一、总体要求

以党的十八届历次中央全会和习近平总书记系列重要讲话精神为指导，以“转变作风、狠抓落实”为抓手，以“倾听百姓呼声，接受群众监督，展示部门形象，促进党风政风建设”为宗旨，通过加强领导，精心组织，逐步实现广播、电视、报纸、网络的相互联动，充分发挥群众监督和新闻舆论监督的作用，促进党风政风建设，进一步转变政府职能，优化经济发展环境，推进依法行政、依法办事，提高工作效率，化解社会矛盾，解决群众反映的突出问题，树立部门和行业的良好形象，为儋州营造风清气正、和谐稳定的发展环境。

二、播出方式

（一）播出内容。邀请有关单位的班子成员和重要业务科室负责人上线，就单位工作职责、办事程序、工作重点和亮点、惠民政策内容及资金落实情况等问题进行访谈，宣传相关政策法规，向社会公开本单位的服务承诺，接听听众电话，与听众沟通交流，受理咨询诉求事项；下线后在规定期限内答复解决群众咨询诉求问题。市属媒体对相关单位的上线工作进行跟踪报道。

（二）播出时间。每周星期四上午8:00至9:00，在市广播电视台儋州新闻广播（频率FM100.5兆赫）直播，星期六中午12:00重播。热线电话：23883025、23883035、23883125、23883135。

三、上线安排

2017年度计划播出节目48期，重点安排乡镇和涉及民生、项目建设牵头协办和服务保障等单位上线。具体上线单位及上线时间详见《儋州市2017年党风政风热线节目上线安排表》附件1。

四、工作要求

（一）加强组织领导。各有关部门和单位要充分认识党风政风热线节目对于转变工作作风、促进经济社会健康发展、维护社会和谐稳定等方面的重要意义，把着力解决影响经济发展的问题和实现好、维护好、发展好人民群众的根本利益作为“党风政风热线”节目的方向，认真学习领会党的十八大精神，深入贯彻落实科学发展观，更加贴近社会热点、贴近人民群众，真正为广大群众排忧解难，做到情为民所系、权为民所用、利为民所谋。市政风行风热线节目组各成员单位要认真履行职责，按照分工，切实做好各自的责任工作；市广播电视台要充分发挥牵头承办作用，协调、督促各上线单位做好上线工作；各上线单位要把做好“党风政风热线”工作作为落实“干部清正、政府清廉、政治清明”和中央八项规定的重要措施，高度重视，周密组织，切实把“党风政风热线”节目办成密切党群干群关系、树立部门和行业形象的有效载体。

（二）深入宣传发动。市属各媒体、各上线单位要加大热线工作的宣传力度，市广播电视台要制作热线节目广告，在电视电台滚动播出；市新闻中心、市信息中心要分别在《今日儋州》、儋州政务网提前预告每期上线信息；各上线单位要采取横幅、传单等形式，加强上线宣传；市党风政风热线节目组要加强对群众诉求问题解决情况的跟踪报道工作，进一步扩大热线节目的影响力。

（三）严格执行制度。严格执行上线制度，各单位必须按规定的时间上线，不得掉线。严格执行“一把手”上线制度，无特殊原因单位“一把手”及班子成员、下属单位主要负责人必须上线，确有困难的，需报市纠风办核准。严格执行现场应答制度，凡解答听众提问，严禁推诿，严禁大话压人。严格执行限期答复解决制度，咨询事项必须在下线后5个工作日内答复，诉求问题要求在15个工作日内解决（复杂问题可制定计划，承诺解决时限）。严格执行上线反馈制度，上线情况台账、群众咨询和投诉事项的答复解决情况，必须在1个星期内反馈给市党风政风热线节目组（市直机关办公大楼0512房）。

（四）强化监督问责。市纠风办、市党风政风热线节目组要加大监督检查和督查督办力度，督促上线单位及时做好上线准备，按时上线；要开展回访工作，对咨询投诉问题的答复解决情况进行抽查，及时发现和纠正、处理存在问题。对参与节目态度端正、认真负责、答复解决群众咨询投诉问题及时彻底、社会反映良好的，要正面宣传报道、全市通报表扬；对工作不力、敷衍塞责、消极应付、推诿扯皮、解决问题不及时不彻底、造成不良后果的，要启动问责机制，追究单位主要领导和相关责任人的责任。
