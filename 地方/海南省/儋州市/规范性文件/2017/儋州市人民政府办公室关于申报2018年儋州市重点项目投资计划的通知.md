# 儋州市人民政府办公室关于申报2018年儋州市重点项目投资计划的通知

各镇政府，地方农林场，市政府直属各单位：

为做好2018年市重点项目投资计划编制工作，请各单位立即组织做好2018年市重点项目申报工作。现将有关事项通知如下：

一、申报原则

（一）项目应符合市委市政府重大战略、重大决策、重大发展思路，符合我市“十三五”重点项目规划和七大重点产业项目规划，符合国家和省产业政策。

（二）新建项目须完成主要行政审批手续，原则上批复到可研阶段。如项目核准或备案、规划选址、用地预审等支持性文件。

（三）2017年118个市重点项目的结转项目。

（四）基础设施、水利、民生等政府投资项目，总投资达到1000万元以上。

（五）产业政策鼓励发展的项目，总投资达到5000万元以上；侧重房地产的社会投资项目，总投资要达到1亿元以上。

二、申报分类和方式

（一）申报项目按重点项目和预备重点项目两类申报。

1、重点项目。分为竣工项目、续建项目和新建项目。其中：计划2018年底前竣工投产的项目，申报为2018年竣工项目；2017年已开工在建、2018年底前不能全部竣工投产的项目，申报为2018年续建项目；规划选址、用地预审、核准或备案等主要审批手续已完成，且计划在2018年底前开工建设的项目，申报为2018年新建项目。

2、预备重点项目。对一些重大项目，业主落实或前期工作已明确责任单位，前期工作已启动，预计近两年内具备开工条件的，可申报为2018年预备重点项目。

（二）业主单位填写《儋州市2018年申报市重点项目投资计划表》、项目简介、通讯录并加盖公章，附上有关批复文件（复印件），向市行业主管部门申报项目。市行业主管部门根据有关要求进行汇总、填报市重点项目申请有关材料，附上企业提供的相关材料，报单位主要领导签字后，以书面文件和电子版形式统一报送市发展改革委。

三、申报材料

（一）儋州市2018年申报市重点项目投资计划表（附件1）。

（二）儋州市2018年重点项目通讯录（附件2）。

（三）项目简介。

（四）已完成有关审批手续的提供相关批复文件，有市委、市政府或市级部门有关支持意见的提供相应文件。

四、申报要求

（一）请各单位认真填写《儋州市2018年申报市重点项目投资计划表》，表格内的每一项内容要填写完整，数据要准确。

（二）2018年的年度投资计划和目标进度要经过认真测算，与项目总体目标、建设期内年均的投资强度相衔接。

（三）申报截止时间为2017年10月27日。请各单位按时将项目投资计划表以纸质盖章和电子版形式报送市发展改革委项目管理科（市直机关办公大楼0813室），无申报项目也要盖章上报。电子版发送到邮箱dzzdxm@163.com。联系人：周鲁，电话：23885265。附件电子版自行在儋州政务网通知公告栏下载。
