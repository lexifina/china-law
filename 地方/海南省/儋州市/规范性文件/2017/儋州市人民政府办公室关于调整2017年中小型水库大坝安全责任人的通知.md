# 儋州市人民政府办公室关于调整2017年中小型水库大坝安全责任人的通知

各镇政府，国营（地方）农场，市政府直属有关单位：

因人事变动和工作需要，市政府决定调整2017年度中小型水库大坝安全责任人（详见附件）。各责任人要切实增强安全意识，克服麻痹思想，消除侥幸心里，做好防大汛、抢大险的思想准备，做到一手抓管理，一手抓安全，要经常深入到责任水库检查，狠抓各项安全措施的落实，确保我市水库大坝安全度汛。

附件：儋州市2017年中小型水库大坝安全责任人名单

儋州市人民政府办公室

2017年6月6日

办公室，各水库管养所，各水库安全责任人。
