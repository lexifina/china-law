# 儋州市人民政府关于印发儋州市农村建档立卡贫困户危房改造扶贫贷款实施细则(试行)的通知

儋州市人民政府关于印发

儋州市农村建档立卡贫困户危房改造扶贫贷款实施细则(试行)的通知

儋府〔2017〕5号

各镇政府，国营(地方)农林场，市政府直属各单位：

《儋州市农村建档立卡贫困户危房改造扶贫贷款实施细则(试行)》已经第十四届市政府第127次常务会议(纪要十四届127次〔2016〕29号)通过，现印发给你们，请认真贯彻执行。

儋州市人民政府

2017年1月18日

(此件主动公开)

儋州市农村建档立卡贫困户危房改造

扶贫贷款实施细则(试行)

为全面贯彻落实党中央、国务院和省委、省政府关于农村危房改造的工作部署和要求，结合我市危房存量和农村群众居住的实际情况，特制定本细则。

一、总体要求

根据《儋州市人民政府办公室2016年农村危房改造工作实施方案》(儋府办〔2016〕64号)文件要求，坚持突出重点、扶持到户，政府引导、市场运作，规范程序、防范风险的工作原则，确实发挥金融扶贫、政策扶贫的重要作用，促进精准扶贫，帮助贫困户满足基本居住要求的目的，发挥市农信社杠杆作用，积极开展扶贫担保贷款，确保对有贷款需求的建档立卡贫困户获得贷款，有效解决建档立卡贫困户危房改造资金短缺的问题，推动我市农村危房改造工作。

二、相关部门职责

由各镇政府牵头，市扶贫办、市住建、国土、财政等部门负责建档立卡贫困户危房改造扶贫贷款工作的组织、协调、监督和监测，做好贷款扶持对象的筛选、审核、推荐、资金拨付工作。具体如下：

(一)由镇政府牵头负责建档立卡贫困户危房改造借款人名单的审核、推荐，将拟危房改造面积和应补助资金额度名单审核后，推荐给住建局、国土局核实；

(二)市住建和国土部门收到各镇政府推荐的建档立卡贫困户名单后，负责核实危房改造具备的相关材料，是否符合办理土地使用权证及报建手续情况，并出具相关审批证明，改造后颁发产权证书，办理抵押登记手续。

(三)市扶贫办负责对建档立卡贫困户借款申请人(户主或家庭成员)身份予以核实，报市财政局申请补助资金的拨付；

(四)市财政局负责建档立卡贫困户危房改造补助资金和贴息预拨资金的拨付。

1.市财政局在市农信社开立专项危房改造贴息专户；

2.市财政局将预拨贴息资金列入当年财政预算，并按时足额预拨到贴息专户，如资金资金不足时，应追加额度及时拨付，确保及时足额贴息；

3.市农信社应每月从专项危房改造贴息专户按借款合同产生实际的利息贴息到建档立卡贫困户相应账户，兑付当月利息。

(五)对暂时未能提供办理抵押担保手续的，市扶贫担保公司在建档立卡贫困户危房改造扶贫贷款须承担阶段性责任连带保证担保，待借款人办理土地使用权证及房产证后配合市农信社办理足值、有效的抵押登记后，方可退出相应的连带责任担保。

(六)市农信社在收到市住建和国土部门确认后的名单，简化手续，落实相关借款、担保手续，合理安排扶贫担保贷款投放计划，负责扶贫担保贷款的调查、发放和回收管理工作，同时建立扶贫担保贷款台账，对扶贫担保贷款实行专档保管。

三、贷款发放范围及对象

本细则贷款对象为经各镇政府推荐的建档立卡贫困户，以户为单位申请，并明确一名家庭成员为借款人，认定贫困户的农户明确其一名家庭成员为借款人(户主年龄不符合贷款条件的，可用子女作为申请),填报《儋州市农村危房改造扶贫贷款推荐表》。借款人应为各镇政府建档立卡贫困户，且具有完全民事行为能力的中华人民共和国公民、有资金需求、有还款来源、无不良贷款信誉记录和其他违法行为，年龄加上贷款期限不得超过65周岁。一般农户参照农信社现行贷款规定操作，贷款贴息相关贴息规定执行。

四、贷款投放规定

(一)贷款额度

根据各镇政府推荐符合条件、有贷款需求的建档立卡危房改造贫困户实际建造面积确定具体贷款额度。每户贷款金额最高不超过10万元。

(二)贷款期限

贷款期限视借款人加上贷款期限不得超过65周岁确定，最长不超过8年，具体以签订借款合同为准。

(三)贷款利率

贷款利率按人民银行同档次基准利率标准(浮动利率)执行。

(四)担保方式

建档立卡危房改造贫困户贷款抵押担保方式有：

1.以房屋土地使用权、房屋所有权；

2.土地承包经营权、林权；

3.由镇、村两委干部提供连带保证担保；

4.对暂时未能提供办理抵押担保手续的，市扶贫担保公司在建档立卡贫困户危房改造扶贫贷款须承担阶段性责任连带保证担保；

5.只要承诺在一定时限内办理上述4条抵押担保手续的，可事先发放信用贷款。

(五)还款方式

按月结息，分期还本(8年期贷款，待第5年后分期归还本金)。为营造诚信氛围，信用社鼓励提前还款。

(六)贷款贴息

纳入各镇建档立卡危房改造贫困户名录贫困户的贷款，采取事前贴息，享受政府危房改造扶贫贷款全额贴息，即贷款发放之日至结清之日的全部利息。

(七)贷前培训

儋州市农村信用合作联社在贷款发放前必须对借款人进行不少于8小时的贷前培训，对扶贫担保贷款的相关程序和政策、贷款资金的使用、作为借款人的责任和义务等相关知识进行详细介绍。

五、工作要求

(一)各相关单位要高度重视农户及建档立卡贫困户危房改造扶贫贷款工作，指定专门部门、专人对接，各司其职。开展信息沟通与共享，总结经验，解决问题，形成上下联动、共同推进的工作格局。

(二)各镇、村要加强政策宣传，积极开展金融知识进村入户活动，使广大贫困户知晓农户及建档立卡贫困户危房改造扶贫贷款的相关程序和政策，防止出现“争贷款、随意用、失信用”现象，引导贫困农户正确使用小额信贷资金进行危房改造。

(三)各镇、村应将危房改造扶贫贷款政策向社会公开，公布举报电话，接受社会公众监督。继续坚持和完善村公告公示制度，引导扶贫对象自我监督、自我管理，并加强监督检查，发现问题及时进行整改。

六、本实施细则最终解释权由市政府归口管理部门负责解释。

附     儋州市农村建档立卡危房改造办理流程

各镇政府：牵头负责建档立卡贫困户危房改造借款人名单的推荐；

市住房城乡建设局、市国土资源局：负责核实危房改造具备的相关材料，是否符合办理土地使用权证及报建手续情况，并出具相关审批证明；

市扶贫办：对各镇政府推荐的建档立卡贫困户危房改造名单核实，报财政申请补助资金；

市财政局：负责建档立卡贫困户危房改造补助资金和贴息预拨拨付。市财政局在市农信社开立专项危房改造贴息账户，贴息资金列入当年财政预算，并每年预拨一次。如预拨资金不足，应追加拨付，确保足额贴息；

市扶贫担保公司：在扶贫贷款中承担阶段性连带责任保证担保；

市农信社：收到住建局、国土局确认后的名单，简化手续，落实相关借款、担保手续，合理安排扶贫担保贷款投放计划。
