# 儋州市人民政府办公室关于印发2018年儋州市红火蚁工作方案的通知防控

各镇政府，地方农林场，市政府直属各单位：

《2018年儋州市红火蚁防控工作方案》已经市政府同意，现印发给你们，请认真组织实施。

儋州市人民政府办公室

2018年8月4日

（此件主动公开）

2018年儋州市红火蚁防控工作方案

红火蚁原分布于南美州巴拉那河流域，随着世界经济贸易全球化，红火蚁成为世界性的害虫，是国际检疫对象之一，也是我国新增的国内检疫对象。2012年我市首次发现红火蚁危害，给人们身体健康及农业生产带来严重威胁。为贯彻落实省政府《关于印发海南省红火蚁防控总体方案的通知》（琼府办〔2016〕219号）和省农业厅于2018年7月12日在琼海召开的全省红火蚁防控工作会议精神，切实做好我市红火蚁疫情的调查、监测与防控工作，保障我市农业生产、公共设施、生态环境安全和人民身体健康，特制定本方案。

各镇政府、农林场也要相应成立由主要领导或分管领导任组长的红火蚁防控领导机构。

二、成立技术指导组，加强防控技术指导

为加强红火蚁防控工作的技术指导，成立由海南大学环植学院、省植保植检站、市农林科学院等有关专家组成的红火蚁防控技术指导组，为红火蚁普查、监测和防控工作提供技术保障，负责红火蚁的鉴定和确认，对红火蚁发生的危害进行风险评估，制定红火蚁防控技术措施等。技术指导组专家名单如下：

三、明确工作职责

为红火蚁防控工作顺利进行，市各部门和有关单位按各自职责开展红火蚁防控工作。

（一）市农委负责指导落实全市红火蚁防控各项工作，协助市红火蚁防控小组进行组织、指挥，组织实施花卉苗圃、山地、林地、水库、堤坝、水闸等场所监测及防控。做好花卉、绿化林木等的调运检疫工作，防止红火蚁扩散漫延。

（二）市农林科学院具体负责协助红火蚁防控技术专家组和组织技术力量，为识别、监测及防控提供技术咨询和指导，做好防治诱饵、农药等防控物质的供应与储备，并协调有关部门组织专业队伍对红火蚁发生区进行扑杀工作。

（三）市卫生计生委负责协调和督促市各医疗机构做好被红火蚁蜇伤者的治疗、抢救和病例统计等工作。

（四）市园林局负责组织实施城市道路绿化带、公园、广场草坪等市政绿地红火蚁的调查、监测及防控工作。

（五）市教育局负责组织实施学校内草地、绿化区红火蚁的监测、防控和在校学生防范红火蚁的宣传教育工作。

（六）市住房城乡建设局负责监督指导建设工地责任主体、住宅小区等对红火蚁的调查、监测及防控工作。

（七）市环卫局负责组织实施街道垃圾堆、垃圾场（站、池）及周边红火蚁的调查监测与防控工作。

（八）儋州供电局负责组织实施电力设施范围内红火蚁的调查、监测及防控工作。

（九）市旅游委负责组织实施旅游景区红火蚁的调查、监测及防控工作。

（十）市交通运输局、儋州公路局负责组织实施公路绿化带红火蚁的调查、监测及防控工作。

（十一）市商务局负责督促口岸和码头做好红火蚁的调查、监测及防控。

（十二）各镇、地方农林场负责组织实施各自辖区红火蚁的调查、监测及防控。

（十三）松涛灌区管理分局负责组织实施松涛水库库区、水渠等红火蚁的调查、监测及防控工作。

（十四）市财政局负责及时安排市级红火蚁防控应急经费。

（十五）市宣传部门负责正确引导社会舆论，做好正面宣传，并负责对外宣传材料进行把关。

四、主要任务与措施

（一）举办红火蚁防控技术培训班。由市农林科学院负责举办红火蚁防控技术培训班，培训镇一级技术骨干；各镇负责培训村（居）委会干部、农民骨干，提高群众对红火蚁的识别和防控技术。要加大宣传力度，广泛、深入开展宣传，提高群众防疫意识，使群众自觉采取行动防止扩散。

（二）组织全市普查。市农林科学院统筹组织在全市范围内开展红火蚁发生情况进行全面普查，通过走访询问，实地观察，图片对照等，发现疑似红火蚁疫情，在24小时内送样本给专家组鉴定，确认为红火蚁后立即采取扑杀措施。重点普查闲置荒田、荒地草地、水渠、果园、苗圃、花卉基地、绿化林带、草坪等，特别是注意调查从红火蚁疫区调运带土的种苗，花卉，盆景等，不留死角。充分发挥镇政府、村委会的作用，广泛发动群众参加普查工作。

（三）加强检疫工作。一是对疫区调运进来的货物、交通运输工具等严格检查，发现红火蚁要及时处理，防止扩散传播。二是对发生区内的厂家，企业进行摸底调查，对有大宗货物要外运的单位由专人负责做好产地检疫工作，同时对生产场地、货运交通工具进行灭蚁处理，并在装车前实施检查，防止害蚁随货物外流；三是在红火蚁发生区内实行对外运的种子种苗、花卉、盆栽作物、草坪、农产品等植物产品和介质废弃物品进行检疫，禁止发生区内土壤、垃圾、淤泥、堆肥等外运，防止疫情外传。

（四）快速组织扑杀。对红火蚁发生区域，当地镇政府和市有关职能部门要广泛组织群众开展扑杀工作，采取防控措施，铲除蚁巢。防治方法有毒饵法、药液灌巢法、粉剂灭巢法及二阶段处理法。

（五）落实防控经费。市财政部门要及时安排红火蚁防控经费，主要用于培训、普查、扑杀、封锁等工作。

（六）组织防控物资供给。根据红火蚁发生情况，及时组织红火蚁防控农药、器械等物资支持防控工作，同时做好应急防控的农药、器械等物资储备。

五、工作要求

（一）各部门、各单位主要领导要高度重视红火蚁防控工作，切实做到有分管领导抓，有专人负责，扎实做好红火蚁普查与防控工作。

（二）做好信息报送工作。防控采取属地化管理的原则，原则上由各镇、各部门负责本区域内红火蚁的监测与防治，认真组织开展本辖区内的红火蚁普查监测与防控工作，掌握红火蚁发生密度（每亩蚁巢数量）和发生区域生态环境动态，要指定专人负责信息报送工作。已发生红火蚁危害的镇、农林场及有关单位于每周五上午12点前上报，未发生的单位每月25日前将监测普查情况上报市农林科学院。联系人：市农林科学院植物保护检疫站 袁群雄，邮箱：dzszbz@126.com ，联系电话：13307678953 ，传真：23391316。

（三）广泛发动群众参加红火蚁普查和扑杀工作，充分调动群众的防控积极性；各镇、各单位有关部门应当设立疑似红火蚁举报电话。

（四）市宣传部门要正确引导社会舆论，稳定社会秩序，排除负面影响，避免引起社会恐慌。
