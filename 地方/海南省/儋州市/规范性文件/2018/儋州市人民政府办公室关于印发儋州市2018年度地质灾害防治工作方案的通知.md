# 儋州市人民政府办公室关于印发儋州市2018年度地质灾害防治工作方案的通知

各镇政府，国营（地方）农林场，市政府直属有关单位：

《儋州市2018年度地质灾害防治工作方案》已经市政府同意，现印发给你们，请认真贯彻执行。

儋州市人民政府办公室

2018年5月31日

（此件主动公开）

儋州市2018年度地质灾害防治工作方案

为全面贯彻落实党的十九大精神和习近平总书记“两个坚持、三个转变”防灾减灾理念，切实做好我市2018年度地质灾害防治工作，确保人民群众生产财产安全，根据国务院《地质灾害防治条例》（国务院第394号）、《海南省人民政府关于进一步加强地质灾害防治工作的意见》（琼府〔2012〕47号）、省国土资源厅《关于做好2018年度汛前地质灾害排查工作的通知》（琼国土资储字〔2018〕21号）、《儋州市人民政府关于印发儋州市地质灾害防治规划（2013—2020年）的通知》（儋府〔2014〕8号）等文件精神，结合我市地质灾害实际现状，特制订本方案。

一、指导思想

全面贯彻落实党的十九大精神，以习近平新时代中国特色社会主义思想为指引，牢固树立和落实新发展理念，坚持以人民为中心的发展思想，坚持科学防治、依法防治的方针，将“以人为本”的理念贯穿于地质灾害各个环节，以保护人民群众生命财产安全为根本，进一步强化地质灾害调查评价、监测预警、综合防治和应急处置等“四大体系”建设，强化全社会地质灾害防范意识，努力实现从注重灾害救助向注重灾前预防转变、从应对单一灾种向综合减灾转变、从减少灾害损失向减轻灾害风险转变，全面提高我市地质灾害防治水平。

二、工作目标

加强地质灾害详细调查，进一步查清地质灾害现状，全面监控已查明的地质灾害隐患点，进一步提升监测预警水平，实现地质灾害调查评价、监测预警、综合治理和应急四大体系建设的目标任务，强化地质灾害应急处置能力，提升群测群防水平和基层防灾能力建设，最大限度避免和减少人员伤亡及财产的损失。

三、我市地质灾害现状及主要地灾隐患点的分布

（一）我市地质灾害现状。经过我市多年来的排查、核查和销号,以及截止2018年3月31日完成的汛前地质灾害排查工作，我市现有地质灾害隐患点4处，主要威胁对象为山区部分村庄群众生产财产。地质灾害隐患点分布为：南丰镇、光村镇、峨蔓镇、八一总场。

（二）我市地质灾害特征。我市地质灾害类型主要有崩塌和滑坡两种，规模均为小型。在空间分布上地质灾害大部分发育在山地丘陵地区；多数发生于切割较深、坡度较大、相对高差较大的低山丘陵区；在时间分布上，具有热带气旋、台风带来强降雨引发地质灾害发生的特点。

（三）我市2017年地质灾害概况。2017年我市遭遇“塔拉斯”、“桑卡”、“杜苏芮”、“卡努”等台风以及国庆期间持续受强降雨的影响，各地质灾害隐患点均及时安排监测员做好动态监测，同时安排工作组做好地质防治等工作，严格落实“雨前排查、雨中巡查、雨后复查”及24小时值班值守制度。在开展2017年地质灾害汛后复查工作及2018年汛前地质灾害排查工作时，我市会同省厅检查组和专家对全市20处地质灾害隐患点开展实地考察，一致同意对我市16个地质隐患点（详见附件1）全部销号。2017年度我市无地质灾害事件发生。

（四）我市2018年地质灾害监测重点。

1.2018年我市地质灾害隐患点有4处，直接威胁人口51人，威胁资产60万元，分别是南丰居委会新街区、新盈农场22队、八一石花水洞、峨蔓龙门灯塔（详见附件2），将上述4个主要地质灾害隐患点将作为主要防范对象。（责任单位：南丰镇政府、峨蔓镇政府、海南八一总场有限公司、海南农垦西联农场有限公司、市旅游委、市国土资源局）

2.山区历年切坡暴露面较大处，村村通工程、扩改切坡、石砌、填方路基段和中线高速公路建设段(责任单位：属地镇政府，市交通运输局、儋州公路局、市安监局、市国土资源局)。

3.存在高陡边坡、危岩等地质灾害安全隐患的采石场和采沙场（责任单位：属地镇政府，市安监局、市农委、市国土资源局）。

（五）重点防范期。我市的汛期是每年的4月～11月，重点防范期为6—10月，这期间降雨多、雨量大，容易引发崩塌、滑坡和地面塌陷等地质灾害，是地质灾害高发时期，且发生地质灾害的时间具有不确定性，各镇政府、市直各有关单位务必提高警惕，加强防范，长期做好防治地质灾害的各项准备工作。

四、地质灾害防治措施

（一）加强领导、落实防灾责任。各镇政府是地质灾害防治的责任主体，要高度重视地质灾害防治工作，按照《国务院关于加强地质灾害防治工作的决定》（国发〔2011〕20号）和《海南省人民政府关于进一步加强地质灾害防治工作的意见》（琼府〔2012〕47号），把地质灾害防治工作列入重要议事日程，加强领导，建立以行政一把手负总责为核心的防灾责任制，把防治工作纳入政府绩效、领导任职谈话和年度考核等作为重要的考核或谈话内容，确保防治责任和措施层层落到实处。

1.各镇政府及农（林）场职责：

（1）承担本辖区地质灾害防治工作主体责任，划定危险区域并在危险区域设置警示牌等标志；

（2）及时发放地质灾害防灾“避险明白卡”和“工作明白卡”；

（3）根据市政府公布实施的地质灾害防治方案，加强地质灾害群测群防工作，加强地质灾害点和危险区域的巡查和监测，发现险情时应当及时动员受到地质灾害威胁的居民以及其他人员转移到安全地带，情况紧急时可以采取强制措施组织避灾疏散，同时向市政府及市国土部门报告；

（4）当发生灾情时，应当及时组织有关人员施救，并第一时间向市政府及市国土部门报告，做好灾后安置工作；

（5）日常巡查乡村新建住宅，避免山区群众大面积切坡建房，及人为形成新的地质灾害隐患。

2.市公安局职责：负责组织协调武警、消防等部门在地质灾害发生时，抢救被压埋人员并协助有关部门进行工程抢险。

3.市国土资源局职责：

（1）负责全市地质灾害防治工作的组织、协调、指导和监督；

（2）监督各镇及时将地质灾害危险点的《工作明白卡》和《避险明白卡》发给防灾责任单位、责任人和受地灾威胁的群众手中，把监测和防治任务落实至具体单位和责任人；

（3）协助各镇建立“镇、村（居）、地灾点”三级群测群防网络，指导镇编制《村（居）汛期地质灾害危险区域群众转移预案》；

（4）认真落实地质灾害防治值班制度，与防汛、气象等有关部门保持密切联系，开展地质灾害预报预警；

（5）编制市年度地质灾害防治方案，报市政府批准后公布实施。

4.市民政局职责：负责农村自然灾害救济工作，组织查实、统计和发布灾情，申请管理和分配救灾款物，指导灾区开展生产自救。

5.市财政局职责：负责将我市地质灾害的治理资金列入财政预算，妥善调度资金，按计划进度拨款，确保地质灾害治理工程顺利完成。

6.市住房城乡建设局职责：

（1）严格山地建房的管理，指导住宅、工程建设、学校等关系到人民生命财产安全的建设；

（2）禁止在地质灾害危险区内削坡建房和从事不合理的工程活动；

（3）在地质灾害易发区内进行的工程建设，要严格按规定开展地质灾害危险性评估，严防人为活动引发地质灾害；

（4）编制城市总体规划时，尤其对村庄、集镇、基础设施专项规划时，必须对规划区组织开展地质灾害危险性评估，合理选地、布局，切实避开危险区域。

7.市农委职责：

（1）要对全市境内有可能引发地质灾害的山塘、水库、河道等进行全面检查，及时向市国土资源局通报暴雨、洪水等有关防汛信息；

（2）做好水库等水利设施地质灾害防治工作;

（3）做好我市各水库地质灾害危险性评估备案工作。

8.市交通运输局职责：

（1）做好影响公路交通安全的地质灾害防治工作；

（2）在汛前组织编制所辖范围的年度地质灾害防治方案；

（3）加强工程建设中地质灾害隐患的防治，负责铁路、公路沿线地质灾害隐患点的排查、监测和防治工作。

9.市气象局职责：

（1）及时通报气象监测资料和降雨时空分布等信息；

（2）会同市国土资源局做好地质灾害预报预警工作。

10.市教育局职责：

（1）会同有关部门加强中小学校舍地质灾害隐患的排查，及时地进行治理，做好影响学校师生安全的地质灾害防治工作；

（2）在汛前组织编制所辖范围的年度地质灾害防治方案。

11.儋州广播电视台职责：

（1）利用有线电视及时播放市人民政府防灾工作部署、灾害性气象和地质灾害预报预警信息等；

（2）在汛期，协同市国土资源局加强地质灾害知识宣传片的播放。

12.市安监局职责：联合市国土资源局加强对矿山企业的检查，督促矿山企业严格按操作规定作业，防止地质灾害的发生。

13.市发展改革委职责：加强对地质灾害易发区内的各类建设项目的审批管理。

14.市旅游委职责：会同有关部门做好旅游景区地质灾害的排查、防治、治理工作。

其他部门应按照各自的职责分工做好地质灾害防治工作。

（二）强化巡查监测，完善群测群防体系。地质灾害隐患点所在的村（居、连队）委会主任(队长）、各镇国土资源所为监测责任人，负责本辖区的地灾防治日常工作，如对隐患点进行定期及不定期常态监测等；地灾隐患点所在地镇（场）长和相关单位主要负责人、分管领导为防灾责任人，负责领导本辖区群测群防、对监测和防灾进行业务指导等防治工作。

坚持预防为主、防抗救相结合，防灾责任人和监测责任人需切实加强地质灾害巡查、监测和预警预报工作。严格落实“雨前排查、雨中巡查、雨后复查”制度，不定期开展地质灾害隐患排查和巡回检查，一旦发现灾情、险情，必须第一个到达现场，及时上报情况，并协助镇（场）领指挥抢险救灾。本着“以人为本、群测群防、群专结合”的原则，积极行动，分级负责，各司共职，不断完善群测群防体系。（责任单位：各属地镇政府，各有关农场，市国土资源局）

（三）强化汛期信息报告制度。地质灾害隐患点所在地的各级负责人和监测机构及监测人员，在汛期间要与市地质害防治领导小组（指挥部）及其办公室（市国土资源局）保持高度联系，做好信息报送工作。以保护人民群众生命财产安全为根本，以防范突发地质灾害为重点，以群测群防为主要手段，在汛期要切实抓好本辖区地质灾害的灾情月报、日报、速报和下情上报等报送工作。密切关注气象部门预报的热带气旋（台风）强降雨区域，加强对主要地质灾害隐患点雨前、雨中和雨后定期和不定期监测，对监测资料做好记录、整理和上报，及时准确报送灾情、险情，确保动态信息畅通。（责任单位：各属地镇政府，各有关农场，市国土资源局、市气象局）

（四）恪尽职守，落实相关措施。地质灾害隐患点所在地各级领导和相关责任人、在汛期要恪尽职守，落实领导带班，严格执行24小时值班值守制度，及时掌握地质灾害动态，发现重大险情及时发布疏散命令，组织群众早撤离、早避让，必要时应采取强制措施撤离、疏散群众，并迅速启动相应应急预案，开展抢险救灾工作，必须保障人民群众的生命安全，最大限度避免地质灾害造成的损失。（责任单位：各属地镇政府，各有关农场，市直有关单位）

（五）提高防灾意识，做好防治工作。

1．各级领导和相关单位责任人要进一步提高思想认识和防灾意识，克服麻痹思想，明确工作责任。建立健全党委领导、政府负责、部门协同、公众参与、上下联动的地质灾害新格局。

2．树立大局意识责任意识，充分认识地质灾害防治工作的重要性、复杂性和不确定性，把地质灾害防治工作中存在的意想不到的情况和问题科学地预测得更充分些，把措施和防范工作做更到位更全面。

3．为确保人民群众生命财产安全，增强社会公众的自我保护和主动参与意识，着力提高基层群众识灾避灾、自救互救能力，提升基层防治和临灾处置水平，扎扎实实做好我市2018年地质灾害防治工作。
