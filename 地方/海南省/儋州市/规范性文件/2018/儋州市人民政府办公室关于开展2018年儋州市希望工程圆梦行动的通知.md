# 儋州市人民政府办公室关于开展2018年儋州市希望工程圆梦行动的通知

各镇政府，国营（地方）农林场，市政府直属各单位：

2018年高考即将开始，据统计，我市报名参加2018年普通高考的考生人数达6923人，结合往年情况，我市有470名左右贫困大学新生面临着求学难、难求学的问题。为帮助更多家庭贫困、成绩优异的应届高中毕业生能够圆一个大学梦，切实让广大贫困学子感受党和政府的关怀，继续在全市范围内营造关爱、互助的社会风尚，市政府决定实施“2018年儋州市希望工程圆梦行动”。现将有关活动事项通知如下：

一、活动主题

2018年儋州市希望工程圆梦行动。

二、资助对象

2018年被全国普通高等院校录取的农村贫困家庭及城市低收入家庭应届考生。

三、资助标准

每名大学生的资助标准为3000-5000元。

四、受助者条件

（一）2018年被全国普通高等院校录取的大学本科生（原则上以考上本科A批院校学生为主)；

（二）儋州市户籍，遵纪守法，品学兼优；

（三）父母均为农村或城市低收入群体；

（四）家庭贫困，年收入低于当地平均收入水平；

（五）没有获得其它奖学金或助学金资助。

五、捐款管理

（一）募集捐款。

各单位结合实际情况，本着自愿原则，广泛动员所在单位的干部职工参加捐款活动。个人捐款和单位捐款汇集后，各单位于7月30日前统一交至团市委办公室，由团市委统一组织发放到贫困生手中。

（二）捐款方式。

1.各镇政府、市直属机关结合自身实际，可以是一个单位（或几个单位）结对资助若干个贫困学生，也可以是个人、家庭、团体的形式捐款结对资助贫困学生。

2.捐款全部存入共青团儋州市委员会专门账户（捐款必需注明为资助高考特困生），由团市委向捐款人开具希望工程圆梦行动捐助发票，颁发捐款证书；对有明确资助意向的捐款，将按捐方的要求安排资助，保证专款专用。
