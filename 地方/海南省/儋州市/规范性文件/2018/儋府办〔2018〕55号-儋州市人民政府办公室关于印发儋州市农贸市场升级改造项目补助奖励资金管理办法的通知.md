# 儋州市人民政府办公室关于印发儋州市农贸市场升级改造项目补助奖励资金管理办法的通知

QSF-2018-050007

儋府办〔2018〕55 号

儋州市人民政府办公室关于印发

儋州市农贸市场升级改造项目补助

奖励资金管理办法的通知

各镇人民政府，地方农林场，市政府直属各单位：

《儋州市农贸市场升级改造项目补助奖励资金管理办法》 已 经十二届市委常委会第 68 次会议和十五届市政府第 34 次常务会 议审议通过，现印发给你们，请认真贯彻执行。

儋州市人民政府办公室

2018 年 5 月 11 日

(此件主动公开)

儋州市农贸市场升级改造项目补助

奖励资金管理办法

第一章  总则

第一条  为规范我市农贸市场升级改造项目管理，提高财政 资金使用效益，确实保障农贸市场升级改造项目顺利实施，助力 我市 “一创两建”工作，不把 “脏、乱、差”农贸市场带入小康 社会。根据《海南省城镇农贸市场规划建设管理办法》(省政府 令第 222 号 ) 和《海南省农贸市场升级改造项目管理办法》(琼 商建〔2017〕423 号 ) ( 以下简称《项目管理办法》) 等规定,结 合我市实际，特制定本办法。

第二条  本办法所称农贸市场升级改造项目补助奖励资金 ( 以下简称补助奖励资金)，是指由财政安排用于支持农贸市场 升级改造项目的专项资金。

第二章  补助奖励范围和条件

第三条  补助奖励资金主要用于支持列入省、市农贸市场升 级改造计划，并在原址进行改造、拆(扩)建或迁建的农贸市场。

第四条  申请补助奖励资金的农贸市场，应同时具备下列条件：

( 一 ) 列入农贸市场升级改造计划；

( 二 ) 按《海南省农贸市场设计导则》( 以下简称《导则》) 标准版或基本版、升级版进行设计和实施改造，并经验收合格。

第五条  列入省农贸市场升级改造三年攻坚行动计划( 以下 简称省改造计划) 的项目，补助奖励资金由省级和市级财政按比 例分担。

未列入省改造计划，但根据我市“一创两建”工作需要列入 市农贸市场升级改造计划的项目，补助奖励资金由市财政安排。

第六条  申请补助奖励资金的农贸市场实施升级改造前，由 市场升级改造项目投资方向市商务部门提出书面申请报备，并提 交以下材料：

( 一 ) 农贸市场升级改造项目补助奖励资金申请书；

( 二 ) 按照《导则》要求设计的图纸；

( 三 ) 市场升级改造项目投资方营业执照、法定代表人身份 证复印件 ( 带原件备审核)；

( 四 ) 其他需要提交的材料。

第七条  市商务部门负责审核市场升级改造项目投资方提 交的书面报备材料，重点审核是否符合《导则》设计要求，并予 以确认。

第三章  补助奖励标准

第八条  农贸市场升级改造项目按《项目管理办法》规定的定额标准给予资金补助支持。实际结算造价低于定额标准的，按 实际结算造价给予支持。

补助资金金额按改造档次分类核定。按《导则》标准版进行 设计、改造并验收合格的，按定额标准金额核定补助资金；按《导 则》基本版进行设计、改造并验收合格的，按定额标准下调 10% 核定补助资金；按《导则》升级版进行设计、改造并验收合格的， 按定额标准上调 10%核定补助资金。

第九条  在《项目管理办法》下发前已列入 2017 年市农贸 市场升级改造计划并已启动，且经市委常委会会议和市政府常务会 议审定补助奖励标准的项目，在限定时间内完成升级改造任务 的，对按省定额标准核定的补助资金与按市原定标准核定的补助 奖励资金之间的差额不足部分， 由市财政专项资金给予补助。

第十条  农贸市场升级改造项目按照《导则》设计的，设计 费用从市级农贸市场升级改造补助奖励资金中安排。

第十一条  农贸市场升级改造项目补助奖励面积按实际验 收通过的建设面积计算。

第四章  验收条件和要求

第十二条  申请补助奖励资金的农贸市场实施升级改造完 成后，市场升级改造项目投资方按照省市确定的验收标准进行自 测自评，自测自评合格的农贸市场，由市场升级改造项目投资方 向市商务部门提出达标验收申请，并提交以下申请材料：

( 一 ) 完成改造的项目竣工报告和竣工图纸；

( 二 ) 建设单位出具的竣工结算书；

( 三 ) 监理单位出具的项目质量评估报告；

( 四 ) 设计单位出具的项目检查报告；

( 五 ) 拆 (扩) 建或迁建的农贸市场须提交消防验收合格报 告；

( 六 ) 验收需要提供的其他相关材料。

第十三条  市商务部门会同市财政部门组织验收小组或委 托第三方按验收标准对项目进行验收，并出具书面验收报告。列 入省改造计划的项目，经验收合格的，报省商务厅、省财政厅备 案。

第五章  资金拨付

第十四条  市场升级改造项目投资方凭市商务部门出具的 确认文件，可在项目动工后，向市商务部门申请预拨部分补助资 金，市商务部门可按不超过定额补助资金的 30%核定预拨资金。

第十五条  农贸市场升级改造项目完成后，经验收合格的， 市商务部门应及时拨付剩余补助奖励资金。

第六章  资金管理

第十六条  补助奖励资金要实行专款专用，任何单位不得以任何借口截留、挪用， 以确保农贸市场升级改造项目顺利开展。

第十七条  农贸市场升级改造相关工作经费从市财政安排 的专项资金中按照不超过 4％的比例提取使用。主要用于农贸市 场升级改造项目验收、监理及委托第三方中介机构和聘请专家等 与农贸市场升级改造相关的工作。

第十八条  市场升级改造项目投资方对申请材料的真实性 负责，如有伪造或篡改申请有关资料行为的，一经查实，将取消 补助奖励资金申请资格，已获得补助奖励资金的予以追缴，涉及 违法行为的移交司法机关处理。

第十九条  获得补助奖励资金的农贸市场，自通过验收之日

起，5 年内不得擅自改变原市场交易经营功能。 因特殊情况确需 调整的，须报市商务部门商财政部门批准同意；列入省改造计划 的，报省商务厅、省财政厅备案。未经批准擅自改变交易经营功 能的，市商务、财政部门有权督促整改或追缴相应补助奖励资金。

第七章  附则

第二十条  本办法自印发之日起施行，有效期 3 年。

第二十一条  本办法由市商务局会同市财政局负责解释。
