# 儋州市人民政府关于设立清理拖欠民营企业中小企业账款投诉机制的通告

儋府〔2019〕20号

儋州市人民政府关于设立

清理拖欠民营企业中小企业账款投诉机制的通告

根据省促进中小企业发展工作领导小组办公室《关于做好2019年全省清理拖欠民营企业中小企业账款工作的通知》（琼企促进组办〔2019〕14号）文件要求，为加快推进我市全面清理拖欠民营企业中小企业账款的工作，特设立受理清欠民营中小企业账款投诉机制，现将有关情况通告如下：

投诉地点：儋州市那大镇市直机关办公大楼18楼1804室

投诉举报电话：0898-23330871

举报电子邮箱：hndzsqq@163.com

网络平台：http://www.danzhou.gov.cn

特此通告

儋州市人民政府

2019年4月9日
