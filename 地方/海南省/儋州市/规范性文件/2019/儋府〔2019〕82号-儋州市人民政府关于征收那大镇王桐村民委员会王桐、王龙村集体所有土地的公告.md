# 儋州市人民政府关于征收那大镇王桐村民委员会王桐、王龙村集体所有土地的公告

儋州市人民政府关于征收那大镇

王桐村民委员会王桐、王龙村集体所有土地的公告

儋府〔2019〕82号

我市拟征收那大镇王桐村民委员会王桐、王龙村集体所有土地22.311公顷。按有关规定，现就土地征收的相关事项公告如下：

一、批准机关：海南省自然资源和规划厅；批准文号：琼自然资函〔2019〕3224号；批准日期：2019年12月27日；批准用途：教育用地、公园与绿地、城镇村道路用地、其他商服用地、零售商业用地、商务金融用地及城镇住宅用地。

二、被征收土地所有权人为那大镇王桐村民委员会王桐村、王龙村，地类和面积：农用地5.1984‬公顷，建设用地17.1126‬公顷‬。征收地块四至范围：东至海南西部中心医院，南至松涛东干渠，西至兰洋北路，北至西城国际小区（具体位置详见勘测定界图）。

三、土地征收补偿标准，按《海南省人民政府关于印发海南省征地统一年产值标准和海南省征地青苗及地上附着物补偿标准的通知》（琼府〔2014〕36号）执行。农业人员按照《海南省人民政府关于印发海南省被征地农民参加社会养老保险办法的通知》(琼府〔2013〕21号)给予养老保险缴费补贴。

四、自本公告印发之日起7日内，被征地农村集体经济组织、农民和其他权利人，须持土地权属证书等相关材料到儋州市那大镇人民政府办理征地补偿登记。
