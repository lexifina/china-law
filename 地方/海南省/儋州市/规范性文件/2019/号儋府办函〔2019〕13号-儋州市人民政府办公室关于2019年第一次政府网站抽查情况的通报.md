# 儋州市人民政府办公室关于2019年第一次政府网站抽查情况的通报

3号儋府办函〔2019〕13号

儋州市人民政府办公室关于

2019年第一次政府网站抽查情况的通报

各镇人民政府，市政府直属各单位：

为做好我市政府网站信息内容建设，按照《国务院办公厅关于印发政府网站发展指引的通知》（国发办〔2017〕47号）和《海南省政府网站管理办法》，我办于近期组织开展对市政府网站各个栏目及各单位政府信息公开专栏进行抽查工作，现将抽查情况通报如下：

一、总体情况

通过对我市政府网站各栏目及各单位政府信息公开专栏进行抽查，大部分单位都能按照网站检查指标要求及时公开信息，但是也存在一些单位信息更新不及时的问题。

二、主要存在问题

（一）政府信息公开专栏长期不更新。个别单位政府信息公开专栏长期不更新，如光村镇政府信息公开专栏最近一条信息发布时间为2018年12月19日；木棠镇政府信息公开专栏最近一条信息发布时间为2019年2月2日；市发展和改革委员会信息公开专栏最近一条信息发布时间为2019年2月26日；市科技和工业信息发展局信息公开专栏最近一条信息发布时间为2019年2月22日；市财政局信息公开专栏最近一条信息发布时间为2019年2月22日；市统计局信息公开专栏最近一条信息发布时间为2019年3月26日；市扶贫办信息公开专栏最近一条信息发布时间为2019年2月21日；市城市管理局信息公开专栏最近一条信息发布时间为2019年2月21日。

（二）政务服务单位名称、服务事项信息不更新，办事要素不齐全。如市公安局服务事项“人才引进户口迁移许可”中户口迁移审批表未提供下载，办理人联系方式不完整；市人社局服务事项“退休证发放”中办理材料未说明纸质材料份数规格；市发改委服务事项“工程建设项目招标事项核准”中办理人联系方式空白，依据说明空白。

（三）市机构改革后各单位负责政府网站的分管领导及信息员有变动未及时报备。

三、下一步工作要求

（一）加强政府网站内容保障。各单位是市政府网站内容保障的责任单位，请根据2019年儋州市政府网站栏目责任分工表（见附件2），建立严格的信息采集、审核和发布制度，按照“谁发布，谁负责”原则，分级管理，严格把关，确保所发的信息权威、准确、及时、有效。

（二）提高政务服务实用性。请市政务服务中心牵头，各个单位认真自查，对每个事项办事指南重点要素类别（包括事项名称、设定依据、申请条件、办理材料、办理地点、办理机构、收费标准、办理时间、联系电话、办理流程）具体办事要素如办理材料格式要求原件/复印件，表格下载，办理人联系方式，依据说明等进行补充完整。

（三）机构改革后各单位负责政府网站的分管领导及信息员有变动的，需及时向市党政网络管理中心更新。新成立的单位需开通政府网站政府信息公开专栏，目前尚未开通专栏的单位有市退役军人事务局、市医疗保障局、市土地和房屋征收局，请以上单位及时与市党政网络管理中心联系开通专栏事宜。联系人：羊德娟，电话：23335533。

各单位要对存在的问题对照检查，及时整改。于2019年5月17日前将整改情况通过OA报至市党政网络管理中心。
