# 海口市人民政府关于调整儿童免票线标准的通告

为进一步营造有利于儿童身心健康成长的社会环境，根据我市实际，现就调整儿童免票线标准有关事宜通告如下：

一、本市行政区域内的市内公交车、市属公园、博物馆、陈

列馆、展览馆、科技馆、旅游景点（不含场所内的游乐项目）等场所，儿童免票线标准统一定为1.20米，凡身高在1.20米以下（含1.20米）的儿童进入上述场所实行免票。

二、本通告自2006年6月1日起实施。

海口市人民政府

二00六年四月二十六日
