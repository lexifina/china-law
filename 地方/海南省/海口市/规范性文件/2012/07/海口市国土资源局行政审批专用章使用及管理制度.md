# 海口市国土资源局行政审批专用章使用及管理制度

为加强行政审批专用章管理，规范行政审批行为，严格行政审批纪律，确保行政审批专用章使用的严肃性，避免滥用和乱用，特制定本制度。

一、海口市国土资源局行政审批专用章（以下简称行政审批专用章）的使用应当严格执行局《印章管理规定》。

二、行政审批专用章实行专人保管。

三、行政审批专用章仅限于在行政审批办公室使用，不得异地挪用。

四、行政审批专用章的使用范围：凡经行政审批服务窗口受理的行政审批服务事项，作出准予或不准予行政许可（审批）决定的复函，以及授权由行政审批办公室办理的行政审批服务事项，一律使用“海口市国土资源局行政审批专用章”。

五、使用行政审批专用章须填写《行政审批专用章使用登记表》，做好用章登记。报局领导审批的事项，行政审批办公室负责人确认后，方可用印；由局领导授权的事项，经行政审批办公室负责人签字批准后方可用印。无论何种情况用印，均须经办人签名确认，并将用印材料记录存档。

六、行政审批专用章的使用，接受我局、市政务中心和监察部门的监督。

七、本制度自2012年7月1日起施行。
