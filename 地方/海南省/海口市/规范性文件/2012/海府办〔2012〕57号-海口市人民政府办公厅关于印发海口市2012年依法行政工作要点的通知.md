# 海口市人民政府办公厅关于印发海口市2012年依法行政工作要点的通知

海口市人民政府办公厅文件

海府办〔2012〕57 号

海口市人民政府办公厅 关于印发海口市2012 年依法行政工作要点的通知

各区人民政府，市政府直属各单位：经市政府同意，现将《海口市2012 年依法行政工作要点》印发给你们，请认真贯彻实施。

二0一二年三月十四日

海口市2012 年依法行政工作要点

2012 年全市依法行政工作要以科学发展观为指导，紧紧围绕市委、市政府中心工作和建设法治政府的目标任务，认真贯彻《国务院关于加强法治政府建设的意见》（国发〔2010〕33 号）、《海口市人民政府关于贯彻实施〈国务院加强法治政府建设意见〉的意见》（海府〔2011〕60 号），着力于完善决策机制，提高决策水平，转变政府职能，强化执法监督，规范执法行为，进一步推动全市的依法行政工作，为全市转型发展和建设“宜业、宜居、宜学、宜游”的最精最美省会城市提供强有力的服务与保障。

一、提高行政机关工作人员特别是领导干部依法行政的意识和能力

（一）深入推进领导干部任职前法律知识测试制度。完善领导干部任职前法律知识测试制度，制定领导干部任职前法律知识测试办法，加强对科级领导干部任前法律知识测试情况的监督检查。（牵头单位：市法制局、市人社局、市编办，责任主体：各区政府、市政府各部门）

（二）加大法律知识培训力度。深入开展“六五”普法和创建法治城市活动，将法律知识纳入公务员在线学习内容，切实提高机关工作人员的法律意识。强化对法制工作人员和行政执法人员的岗前培训、日常培训和定期轮训，组织开展依法行政专题培训和考试。各区及市直各部门要高度重视机关工作人员依法行政意识与能力的培养，结合创建法治城市活动，采取自学与集中培训相结合，将法律知识考核、考试纳入年度考核。（牵头单位：市司法局、市法制局、市人社局，责任主体：各区政府、市政府各部门）

（三）落实领导干部学法制度。制定和落实政府常务会议、部门会议学法制度，今年安排2 次以上的领导干部法律讲座，邀请知名法律专家、学者授课。学习情况应当记入《会议纪要》。（牵头单位：市法制局，责任主体：各区政府、市政府各部门）

二、健全科学民主依法决策机制，提高决策水平

（四）完善重大决策机制。制定行政程序规定，完善重大决策制定规则程序，科学界定重大决策的事项范围，坚持把公众参与、专家论证、风险评估、合法性审查和集体讨论决定作为重大决策的必经程序，增强公共决策制定透明度和公众参与度。（牵头单位：市政府办公厅、市法制局，责任主体：各区政府、市政府各部门）

（五）建立行政决策风险评估机制。认真贯彻落实中共中央办公厅《关于建立健全重大决策社会稳定风险评估机制的指导意见（试行）》（中办发〔2012〕2 号），制定我市重大决策社会稳定风险评估制度，对凡是涉及社会稳定大局和群众切身利益的重大政策、项目等决策事项，进行合法性、合理性、可行性和可控性评估，把风险评估结果作为决策的重要依据。（牵头单位：市法制局，责任主体：各区政府、市发改委、市征收办、市国土资源局、市规划局）

（六）建立健全行政决策跟踪反馈和责任追究制度。对社会关注度高的重大决策项目的实施效果及时进行跟踪，及时发现并纠正决策制定和执行过程中存在的问题，以适时调整和改进决策。对违反决策规定、出现重大决策失误、造成重大损失的，要按照谁决策、谁负责的原则严格追究责任。（牵头单位：市监察局，责任主体：各区政府、市政府各部门）

（七）严格落实重大行政事务法核制度。起草海口市政府重大涉法事务、合同（协议）审查规定，明确未经各部门前置审核的重大涉法事务、合同（协议），不得报市政府法制机构审查。理顺政府法律顾问机制，建立市政府法律事务办理人员工作考评、激励约束机制，进一步提高政府法律顾问的服务水平和效率。（牵头单位：市法制局，责任主体：各区政府、市政府各部门）

三、加强和改进制度建设，提高制度建设质量

（八）把握立法重点。以服务和保障海口城市转型与空间布局调整为核心，重点从创新体制机制，构建现代产业体系，强化省会中心城市功能，推动城乡统筹发展，改善和保障民生，加强生态文明建设等方面入手，积极构建具有大特区省会和国际旅游岛中心城市特色，与现实生产力水平相适应的地方制度体系，努力实现系统性、民主性、科学性、包容性和可行性的统一。重点抓好《海口综合保税区管理条例》、《海口国家高新技术产业开发区管理条例》、《海口市三轮车管理暂行规定（修订）》等地方性法规、规章的制定工作，为建设“四宜”最精最美省会城市提供法制保障。（牵头单位：市法制局，责任主体：海口综合保税区、海口高新区、市政府有关部门）

（九）完善立法工作机制。认真做好2012 年制度建设（立法）计划的编制与实施工作，建立健全法规规章立项论证、起草阶段提前介入、审查阶段座谈、听证、论证等制度，提高立法水平。进一步完善委托立法制度和立法后评估制度。（牵头单位：市法制局，责任主体：市政府各部门）

（十）完善规范性文件法核制度。修改《海口市规范性文件制定与备案管理办法》，建立市政府各部门起草的规范性文件由各部门法制机构前置审核制度，严格执行规范性文件有效期制度，逐步实行规范性文件统一登记、统一编号、统一发布制度。（牵头单位：市法制局，责任主体：各区政府、市政府各部门）

（十一）严格落实规范性文件备案审查工作。加大对各区、市政府各部门规范性文件审查备案工作的监督指导力度，建立报备情况定期（半年）通报制度。认真执行规范性文件定期清理制度，完善规范性文件网上电子报备工作，全面实现规范性文件网上电子报备。（牵头单位：市法制局，责任主体：各区政府、市政府各部门）

（十二）加强重点项目实施过程中的制度设计。重点关注我市“十二五”规划中的重大项目、关注民生的市重点项目的配套制度建设，抓好30 万亩良田整治工程、南渡江引（调）水工程项目的制度设计和监督检查，预防和杜绝法律和社会风险。（牵头单位：市法制局，责任主体：市发改委、市监察局、各区政府、市政府有关部门）

四、深入推进行政审批改革，转变政府职能

（十三）服务保障强区扩权工作。认真贯彻落实市委、市政府关于第二轮下放行政权限的实施意见，做好强区扩权工作的贯彻落实。进一步加强组织领导，强化责任，落实经费保障，认真做好下放事权的落实和衔接工作，避免出现承接事权后的监管“缺位”或“不到位”现象，并争取在条件成熟时，再下放一批行政权项。加强监督检查，确保下放权限依法合规，提升行政效能，增强区级发展活力。（牵头单位：市政府办公厅，责任单位：市人社局、市财政局、市监察局、各区政府、海口综合保税区、海口高新区、市政府各部门）

（十四）深入推进行政审批工作。深入推进行政审批改革，优化发展环境，着眼于项目的落地、开工建设和投产运营等环节。进一步减少审批事项和审批环节。进一步优化审批服务流程，创新审批服务方式，建立“首席代表”或“审批办”机制。全面规范、升级、完善现有海口市行政审批服务管理系统，充分利用党政办公集成环境和互联网，推行网上申报，逐步实现网上办理审批、缴费、咨询、办证、监督，切实从体制上把行政审批制度改革推向深入。（牵头单位：市政府服务中心，责任主体：各区政府、市政府各部门）

（十五）全面推进信息和政务公开。要认真贯彻执行《海口市人民政府办公厅关于印发市政府信息依申请公开工作规程等5 项政府信息公开配套制度的通知》（海府办〔2011〕218 号），及时、准确公开政府信息公开目录和指南。创新政务公开方式，大力加强电子政务建设，完善网上便民服务，提高政务公开水平。加强对政务公开工作的监督，建立健全政府信息公开的监督和保障机制，推进办事公开。（牵头单位：市政府督查议案室，配合单位：市监察局、市信息中心，责任主体：各区政府、市政府各部门）

五、坚持严格规范行政执法行为，促进公正文明执法

（十六）严格规范执法程序。各级行政执法主体应建立行政执法程序制度，编制执法流程，明确执行环节和步骤，根据法律法规规章立、改、废情况及时调整、梳理行政执行依据，明确执法职权、机构、岗位、人员和责任，并向社会公布。（牵头单位：市法制局，责任主体：市、区行政执法部门）

（十七）加强行政执法队伍建设。加强行政执法主体的清理，严格执行执法人员持证上岗和资格管理制度。完善行政执法人员资格准入制度，健全行政执法人员资格培训考试操作规范。（牵头单位：市法制局，责任主体：市、区行政执法部门）

六、加强和改进行政监督，提高行政效能

（十八）加强行政执法监督。认真落实《海口市行政执法监督办法》（政府令〔2011 〕第84 号），加强行政执法案卷评查制度，规范行政处罚自由裁量权。强化对城市管理等重点领域和各单位执法工作的监督和指导，围绕全市重点项目开展行政执法监督检查。（牵头单位：市法制局、市监察局、市效能办、市重点办，责任主体：市政府各部门）

（十九）完善行政执法体制机制。探索城市管理、文化市场等领域综合行政执法改革，实现政策制定职能与监督处罚职能相对分开、监督处罚职能与技术检验职能相对分开，建立健全行政执法协调配合机制，构建权责明确、行为规范、监督有效、保障有力的执法体制。（牵头单位：市编办，责任主体：各区政府、市政府有关部门）

（二十）加强机关效能建设。以建设“廉政、勤政、务实、高效”的服务型机关为目标，以机关绩效考评为抓手，坚持教育、制度、考评、监督、创新五管齐下抓效能，加强对市委、市政府重点工作的监督，编制每一位机关工作人员的职位说明书，明确岗位职责和工作流程，完善机关绩效考核目标体系，强化效能责任追究，切实转变机关作风，推进工作落实，提高执行力。（牵头单位：市效能办、市编办，责任主体：各区政府、市政府各部门）

（二十一）创新新闻舆论监督机制。建设全市统一的网络问政平台，建立集信息收集处理、督办反馈、检查考核等内容为一体的网络问政工作机制，推动网络问政制度化。利用市政府门户网站、海口广播电视台、海口晚报等现有资源，依托“椰城纠风热线”、海口市政府服务热线“12345”等平台推进市政府领导和各职能部门领导与公众交流，回应群众关注的社会民生、经济发展等方面的诉求，对群众关心的问题进行监督、督办。（牵头单位：市政府办公厅，责任主体：各区政府、市政府相关部门）

七、化解矛盾纠纷，维护社会稳定

（二十二）进一步完善行政调解制度以及行政调解与人民调解、司法调解相衔接的“大调解”联动机制。完善配套工作制度与措施，充分发挥行政调解在化解行政争议和民事纠纷中的作用。在矛盾纠纷多发部门开展行政调解试点，助力海口和谐稳定发展。（牵头单位：市法制局、市司法局、市信访局，责任主体：各区政府、市政府各部门）

（二十三）创新行政复议工作体制机制。积极推进相对集中行政复议权和行政复议委员会的试点工作，探索建立政府主导、社会参与的行政复议委员会，提高社会公信力。进一步健全行政复议工作制度，贯彻落实行政审判与行政复议互动机制，畅通复议渠道，简化申请手续，努力提高行政复议办案质量和效率。（牵头单位：市编办、市法制局，责任主体：市政府相关部门）

八、落实组织保障，切实加强法治政府建设

（二十四）建立依法行政领导协调机制。各部门、各单位的“一把手”作为本部门、本单位依法行政的第一责任人，加强推进依法行政工作的督促指导、监督检查和舆论宣传，形成强有力的推进依法行政的领导体制和机制。（牵头单位：市政府办公厅，责任主体：各区政府、市政府各部门）

（二十五）加强法制机构和队伍建设。以区政府和市直执法部门为重点，加强法制机构和队伍建设，充分发挥法制机构的组织协调和督查指导作用，提高法制工作人员素质。（牵头单位：市编办、市人社局，责任主体：各区政府、市政府各部门）
