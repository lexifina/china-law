# 海南省工商行政管理局关于公布规范性文件清理结果的公告

琼工商法[2017]11号

为全面推进“放管服”改革，转变政府职能，根据省政府办公厅《关于开展“放管服”改革涉及规章和规范性文件清理工作的通知》（琼府办〔2017〕109号）的部署要求，省工商行政管理局对历年来发布的规范发性文件进行了清理。清理结果已经局长办会会议审议通过，共清理规范性文件184件，其中继续有效75件，失效109件。现将清理结果目录予以公布。

海南省工商行政管理局
