# 海南省市场监督管理局关于印发深化简易注销改革试点实施方案的通知

琼市监办〔2019〕69号

各市县、洋浦经济开发区工商局，三沙市市场监督管理局，省局各局、处(室)、直属单位:

在 2017 年简易注销登记改革的基础上，根据《中国(海南)自由贸易试验区商事登记管理条例》《市场监管总局关于开展进一步完善企业简易注销登记改革试点工作的通知》(国市监注〔2018〕237 号)要求，我局制定了《海南省市场监督管理局深化简易注销改革试点实施方案》。现予以印发，请遵照执行。特此通知。
