# 咸安区人民政府办公室关于《政府工作报告》确定的2017年重点工作及“十件实事”责任分解的通知

咸安政办发〔2017〕1号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁向阳湖现代农业科技示范区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

经区政府研究同意，现将《政府工作报告》确定的2017年重点工作及“十件实事”责任予以细化分解。请各乡镇办场、各部门高度重视，迅速制定具体工作方案，细化目标、强化措施、硬化责任，狠抓落实。

区政府督查室将适时组织力量，加强对《政府工作报告》确定的各项工作责任落实情况的检查和督办，并以《督查通报》等形式通报有关情况。

咸安区人民政府办公室

2017年1月3日

《政府工作报告》确定的2017年

重点工作责任分解

2017年，全区经济社会发展的主要预期目标是：完成地区生产总值232亿元，增长9%左右；完成一般公共预算收入10.62亿元，增长10%；规模工业增加值增长8%；完成全社会固定资产投资278亿元，增长16%；实现社会消费品零售总额129亿元，增长12%左右；完成外贸出口总额7290万美元；城镇常住居民人均可支配收入达到30766元，增长9%；农村常住居民人均可支配收入达到15762元，增长10%；居民消费价格涨幅控制在3.5%以内；城镇登记失业率控制在4.6%以内；完成省定节能减排任务。

（一）在统筹区域发展上发力

全力推动主城区发展。计划筹措及引进资金100亿元，其中：2017年完成有效投资40亿元。扎实做好山水开发保护、基础设施提升、城市经济发展文章，强力推进“一河三山”“一场两馆两中心”、棚户区改造等重点项目建设，加快推进城区骨干道路、地下综合管廊、防洪排涝设施、背街小巷整治等基础设施建设，统筹推进城区商业综合体、特色一条街、公共服务场所等服务设施建设（责任单位：区城投公司、区发改局、区招商局、区住建局、区棚改办（区房屋征收管理局）、区国土局、区交通运输局、区水利局、区文体新局、区卫计局、区委党校、区妇联、区商务局、区环保局、区城管执法局、温泉办事处、浮山办事处、永安办事处）。

全力支持产业园发展。计划筹措及引进资金100亿元，其中：2017年完成有效投资30亿元。以咸安经济开发区为主战场，大力实施扩园、强园、优园工程，力争每年建成面积1平方公里、整理土地1平方公里、储备土地1平方公里。统筹推进咸安商贸物流区、向阳湖现代农业科技示范区及乡镇特色工业园区建设，引导投资强度大、经济效益好、环保意识强的企业入驻园区（责任单位：咸安经济开发区、咸安商贸物流区、向阳湖现代农业科技示范区、区发改局、区招商局、区国土局、区规划分局、区环保局、汀泗桥镇、向阳湖镇、官埠桥镇、贺胜桥镇、双溪桥镇、马桥镇）。

全力服务梓山湖发展。计划筹措及引进资金100亿元，其中：2017年完成有效投资30亿元。积极争取市委、市政府支持，理顺梓山湖新城管理体制和工作机制，全力服务重大基础设施、重点产业项目建设，配合做好招商引资工作（责任单位：梓山湖大健康示范区管委会（筹）、区发改局、区招商局、贺胜桥镇、官埠桥镇）。

全力促进特色镇发展。支持贺胜桥镇抢抓“一站一城”建设机遇，打造中国“一带一路”文化特色街区暨中华（贺胜）鸡汤美食文化特色街区（责任单位：区商务局、区旅游局、区招商局、贺胜桥镇）。支持马桥镇、官埠桥镇、向阳湖镇、横沟桥镇发挥区位优势，打造沿国道省道城镇经济带。支持双溪、高桥、大幕、桂花、汀泗立足资源禀赋，打造沿幕阜山片区绿色经济带（责任单位：相关乡镇）。

（二）在推动工业崛起上发力

优化产业布局。强力推进咸安经济开发区建设。完成高端装备制造基地、生物医药产业园、食品产业园、环保产业园等“七通一平”以及污水收集、处理工程建设，积极引进汽车销售、商贸购物、娱乐休闲、商业综合体等第三产业配套，突出抓好凤凰中心小学、社区医疗卫生服务站、三八河右岸商贸中心建设，推进产城一体建设，力争全年引进项目36个、开工投产项目36个（责任单位：咸安经济开发区、区环保局、区住建局、区经信局、区招商局、区教育局、区卫计局、区商务局）。统筹推进乡镇特色工业园建设。全力支持官埠、贺胜、马桥、汀泗、双溪、向阳湖等乡镇立足现有基础，完善园区功能，扩大园区规模；全力支持永安、浮山、温泉及有条件的乡镇村大力发展“飞地经济”，通过借势借力发展，拓展产业发展空间，增强经济综合实力（责任单位：区经信局、区国土局、区规划分局、相关乡镇办）。

培育支柱产业。制定出台《中国制造2025咸安行动实施方案》，深入实施“支柱产业倍增工程”和“百亿产业提升工程”，落实各项优惠政策，帮助企业减轻负担，帮助企业降低成本，帮助企业破解“融资难、用电难、用地难”问题，培育3个以上纳税过千万元的骨干企业、产值过百亿元的支柱产业，全年新增规模以上工业企业不低于15家（责任单位：区经信局、区财政局、区国税局、区地税局、区政府金融办、咸安经济开发区、区国土局、区招商局、区物价局、区供电公司）。加大招商引资力度，大力开展产业招商、专业招商、平台招商，全年引进各类项目不低于300个、到位资金不低于200亿元（责任单位：区招商局、区政府各有关部门、各乡镇办场）。

强化创新驱动。支持鼓励企业加大技改科研投入力度，推广运用新工艺、新流程、新材料，大力实施新产品开发、新技术研发、新产业萌发专项行动，整体提升现有产业的先进产能比重。支持鼓励企业深化与高等院校、科研院所的合作关系，扶持发展一批重点实验室、研发中心、检验检测机构，积极培育一批创新型企业、高新技术企业、科技型中小企业，促进产学研用深度融合，全年新增高新技术企业5家以上（责任单位：区科技局、区经信局、咸安经济开发区）。支持鼓励企业加强品牌标准建设、商业模式创新，积极研发高终端产品，主动融入“互联网+”时代，拓展市场空间，提升市场份额（责任单位：区科技局、区经信局、区商务局、区工商局、咸安经济开发区、咸安商贸物流区、有关乡镇）。支持鼓励企业参与“一带一路”建设，继续扶持天源纺织、华宁防腐、洪盛模具等龙头企业走出国门，积极参与全球产业链分工，开拓国际市场，扩大开放领域（责任单位：区经信局、区商务局、咸安经济开发区）。支持鼓励“大众创业、万众创新”，加快推进小微企业众创中心、“双创”孵化器基地建设，全年新增各类市场主体2000家（责任单位：区人社局、区科技局、区工商局、咸安经济开发区、温泉办事处、浮山办事处）。

（三）在发展现代农业上发力

创新农业经营模式。坚持以土地流转推动规模化经营，引导农村土地向龙头企业、专业大户、家庭农场、农民专业合作组织等流转，培育新型经营主体，培养新型职业农民，新增市级以上农业产业化龙头企业5家、农民专业合作组织60家（责任单位：区农办、区农业局、区经管局、区工商局）。强力推进加工业发展。发挥龙头企业的示范带动作用，突出楠竹、茶叶、桂花等优势产业发展，加快农产品加工产业园、竹循环产业园建设（责任单位：咸安经济开发区、区农办、区农业局、区林业局）。着力彰显种植业特色。重点打造建国畈、东源畈、双溪村等油菜生产示范区，确保全年油菜种植面积不低于38万亩；巩固扩大杨堡、三桥、湖场、古塘、金桥、樊塘、高赛、熊家湾、奶牛场、坤元第五季等标准化蔬菜基地面积，确保全年蔬菜种植面积不低于10万亩；全力支持雨坛、孙鉴、高峰、万秀、万寿桥、黄荆塘等重点茶叶村建设，确保全年新增茶叶种植面积不低于1万亩（责任单位：区农办、区农业局、相关乡镇办场）。适度控制养殖业规模。科学划分畜牧养殖“禁养区、限养区、适养区”，规划建立水产养殖“自然保护区、野生鱼类繁殖区、生态渔业捕捞区”（责任单位：区畜牧局、区水产局、区环保局、相关乡镇）。

夯实农业发展基础。严格落实耕地保护制度，加强土地开发、整理、复垦力度，加快1万亩高标准基本农田土地整治、1055亩工矿废弃地复垦试点项目建设，保持全区耕地面积49.7万亩、基本农田面积39.5万亩的总量动态平衡（责任单位：区国土局、区农办、区农业局、相关乡镇）。加大涉农项目、涉农资金的整合力度，深入实施中央小农水大幕片区、双石灌区节水配套改造、南川灌区、西湖围垸水毁应急工程等重点项目建设，加快完成15座新出险小型水库除险加固工程建设，全面启动山洪沟鸣泉河治理、山洪灾害监测指挥体系建设以及坡耕地、机耕路、林间道等项目建设。坚持“建管并举”，积极探索农村基础设施监管维护长效机制（责任单位：区农办、区财政局、区经管局、区水利局、区交通运输局、相关乡镇）。

健全农业服务体系。坚持以农民需求开展社会化服务，继续推进农业生产全程社会化服务体系建设，采用集中育秧、统防统治、机耕机种机收等方式，重点打造7个集中育秧基地，逐步把育秧“改分散为集中、改单户为联户、改单个作业为专业化社会化服务”，实行集中化、规模化、链条化服务（责任单位：区农办、区农业局、区农机局、相关乡镇）。坚持以实用技术提升科学化水平，大力推广优良品种、轻简栽培、测土配方施肥、稻虾连作等实用技术，推广普及生物防治、物理防治等环保型无公害作物病虫害防治技术，建立新型生态食物链与生态保护体系（责任单位：区农业局、区水产局）。坚持以农产品安全示范区创建为抓手，健全农产品安全追溯体系，开展农产品精品名牌创建，争创“三品认证”农产品5个，全区拥有国家地理标志不少于5个（责任单位：区农办、区农业局、区工商局、区产品质量检验检测中心）。

强力推进精准扶贫。严格落实各项扶贫政策，加大资金投入力度，提升产业帮扶准度，加快易地搬迁进度，配套完善水、电、路、网等基础设施，不断提升教育培训、政策兜底的保障能力，全面提高医疗报销、大病救助标准，实现贫困户基本医疗保险、基本养老保险参保率“两个100%”，实现贫困群众用水、用电“两个安全”，对照“九有”贫困村出列、“一有二不愁四保障”贫困人口脱贫标准，确保全年8个重点贫困村出列、14709名贫困人口脱贫，全面完成168户易地搬迁任务（责任单位：区扶贫办、区农办、区发改局、区水利局、区交通运输局、区农业局、区教育局、区住建局、区文体新局、区民政局、区人社局、区卫计局、区能源办、区供电公司、区电信公司、各乡镇办场）。

（四）在增强服务功能上发力
