# 区人民政府办公室关于成立区人民政府农民工工作领导小组的通知

咸安政办发〔2017〕2号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁向阳湖现代农业科技示范区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

为进一步加强对农民工工作的组织领导、统筹协调和督办落实，根据《省人民政府关于进一步做好农民工服务工作的实施意见》（鄂政发〔2015〕67号）精神，经区政府研究，决定成立区人民政府农民工工作领导小组。现将有关事项通知如下：

一、主要职责

组织拟定和审议农民工工作的重大政策、措施，组织推动我区农民工工作，督促检查各地各有关部门相关政策落实情况和任务完成情况，统筹协调解决政策落实中的重点难点问题。

三、工作机构

区人民政府农民工工作领导小组办公室设在区人社局，承担领导小组日常工作，刘红玲同志兼任办公室主任。

领导小组成员调整由各成员单位向领导小组办公室提出，报领导小组组长批准。
