# 区人民政府办公室关于成立咸安区全国残疾预防综合试验区创建试点工作领导小组的通知

咸安政办发〔2017〕9号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁向阳湖现代农业科技示范区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

为了贯彻实施《国家残疾预防行动计划（2016－2020年）》,推动我区全国残疾预防综合试验区创建试点工作深入开展，根据《咸宁市残疾预防管理办法》有关规定，经区政府研究，决定成立咸安区全国残疾预防综合试验区创建试点工作领导小组。现将成员名单通知如下：
