# 区人民政府办公室关于印发咸安区“十三五”农村社区建设试点工作方案的通知

咸安政办发〔2017〕18号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

《咸安区“十三五”农村社区建设试点工作方案》已经区人民政府同意，现印发给你们，请认真组织实施。

咸安区人民政府办公室

2017年2月27日

咸安区“十三五”农村社区建设试点工作方案

为贯彻落实《中共中央办公厅、国务院办公厅印发〈关于深入推进农村社区建设试点工作的指导意见〉的通知》（中办发〔2015〕30号）和《省委办公厅、省政府办公厅印发〈关于深入推进农村社区建设试点工作的实施意见〉的通知》（鄂办发〔2015〕54号）、《市委办公室、市政府办公室关于印发〈咸宁市农村社区建设试点“五年行动计划”实施方案〉的通知》（咸办发〔2016〕29号）精神，进一步提高农村社会管理和公共服务水平，促进城乡一体化建设，经区政府同意，现就咸安区“十三五”农村社区建设试点工作制定如下方案。

一、指导思想、基本原则和工作目标

（一）指导思想。以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入贯彻落实习近平总书记系列重要讲话精神，立足于创新农村基层社会治理，坚持村党组织领导、村委会牵头，以全面提高农村居民生产生活质量和文明素养为根本，以完善村民自治机制为首要任务，以促进城乡公共服务均等化、便利化为目标，以满足农村居民生产生活需求为导向，加强农村社区精神文明和生态文明建设，努力把农村社区建设成为管理有序、服务完善、文明祥和的社会生活共同体。

（二）基本原则。坚持以人为本，把服务群众、改善民生作为农村社区建设的出发点和落脚点，不断满足农村居民的物质文化需求。坚持因地制宜，对近郊村、集镇村、偏远村实行分类指导，培养各具特色、功能各异的新型农村社区。坚持整合资源，发挥政府和有关部门职能作用，调动农村各类组织参与社区建设的积极性。坚持突出重点，着力解决农村社区活动场地、体制机制、服务体系建设等问题，不断提高农村社区建设水平。

（三）工作目标。到2020年，打造一批管理有序、服务完善、文明祥和的农村社区建设示范点。全区城中、城郊、建制镇周边和园区附近的村要结合城乡一体化建设率先建成农村社区。咸嘉生态文化城镇带作为全区农村社区建设的试点单位，努力实现农村社区建设全覆盖。力争30%的乡镇办实现农村社区建设全覆盖，每个乡镇办每年农村社区建设试点不少于行政村的5%。农村社区综合信息网络平台覆盖率达100%；乡镇办、村三级联动互补的基本公共服务网络和网格化服务管理平台覆盖率达到50%以上；农村社区公共安全视频监控覆盖率达到100%。

（四）基本类型和模式。“十三五”期间，各乡镇办场要充分发挥政府的主导作用，整合社会和社区资源，积极探索政府引领、企业主建；村企联营、项目推动；镇社联动、村民自治；多方帮扶、社区主建等农村社区建设新举措和新路径，努力打造符合咸安实际的平原发达型、山区贫困型、两型社会型、城郊生态文化型等“四型”农村社区，分类分步开展农村社区建设试点，实现城乡统筹协调发展。

二、主要内容

（一）推进基层自治，完善农村社区治理机制。农村社区建设要在行政村范围内，严禁以“管委会”等机构取代村党组织和村民委员会。建立健全以村党组织为领导核心，村民委员会为主导，农村居民为主体，村务监督委员会、村集体经济组织、驻村单位、群众团体、社会组织共同参与的农村社区治理机制。推进农村基层服务型党组织建设，增强乡镇、村党组织和村民委员会的服务功能。以农村基层党组织建设带动农村自治组织、群众组织、经济社会服务组织建设。加强以村党组织书记为带头人的农村干部队伍建设，把村“两委”班子成员特别是村党组织书记培训纳入整个干部培训规划。依法理清乡镇政府与村民委员会的权责边界，建立农村社区事务清单，促进基层政府与社区自治组织的有效衔接和良性互动。认真贯彻落实《中华人民共和国村民委员会组织法》,完善农村社区建设重大问题的民主决策、民主监督制度，加强村民委员会和村务监督委员会建设。加强城乡社区协商，广泛开展多种形式的农村社区协商，逐步实现基层协商的经常化、规范化、制度化。

（二）推进服务设施建设，健全农村社区服务体系。农村社区综合服务站和党员群众服务中心的建设要根据服务范围适度、服务管理方便、服务功能齐全等原则，社区综合服务中心面积不低于500平方米，医疗服务不低于80－100平方米。提升基层农村公共服务信息化水平，逐步推进“互联网+政务服务”，逐步构建乡（镇）、村三级联动互补的基本公共服务网络。整合农村基层综合服务网、“三万”农村网格化、农村科技网、农村供销网、农村党员活动中心等各种涉农网络资源，推动“互联网+政务服务”和网格化管理信息平台建设。创新全区新型农村社区建设体系，大力发展社区救助服务、医疗卫生服务、文化体育活动服务、人民调解服务、商业网络服务，逐步建立党组织关爱服务、基本公共服务、志愿互助服务、市场化服务衔接互补、覆盖农村全体居民的社区服务体系。试点村统一悬挂“中国社区” 和“党员群众服务中心”标识，不挂农村社区标牌、不刻农村社区印章。

（三）推进服务内容完善，提升农村社区公共服务水平。进一步推进公共服务事项下放到农村社区，制定和完善农村社区公共服务目录和清单。依托社区综合服务中心建立“一站式”服务大厅，积极推进以社区治安、医疗卫生、劳动就业、农业生产、环境保护、社会救助、计划生育、文化体育、科技教育、法律服务为主要内容的政府公共服务进农村社区。以农村居民需求为导向，优先发展与农村居民切身利益密切相关的服务项目。依托农村社区综合服务设施建立信息化服务网点，加强实体办事窗口建设，完善信息“进村入户”功能。推动政务服务事项“一号”申请、“一窗”受理和“一网”通办，简化优化群众办事流程。培育新型业态和服务品牌，引导经营性的服务组织在农村社区开展连锁经营，鼓励企业和邮政、金融、电信、燃气、电力、自来水、供销等公用事业单位在社区设服务点，完善农村社区商业网点和物流布局。结合精准扶贫，加快集体经济发展壮大，完善生产生活类服务。立足当地资源优势，发展各类专业合作经济组织，推进土地流转，采取“公司+农户”的模式，大力推进适度规模经济、特色产业发展。鼓励和引导各类组织、企业和个人兴办居民服务业，满足居民多样化生活需求，为就业困难人员和零就业家庭提供就业岗位。

（四）推进“三社联动”机制，拓宽多元主体参与渠道。构建以政府购买服务为牵引，以社区为平台，以社会组织为载体，以社工为骨干，以满足居民需求为导向的社区治理和服务机制。通过购买服务、直接资助、以奖代补、公益创投等方式，支持社区社会组织参与社区公共事务和公益事业，支持专业化社会服务组织配备和使用社会工作专业人才到农村社区开展服务。鼓励农村基层干部参加全国社会工作者职业考试。探索在社区志愿服务组织中配备社会工作专业人才，建立健全社区社会工作专业人才引领志愿者服务机制。根据农村社区发展特点和居民需求，分类推进社会工作服务，发挥社会工作人员在社区志愿服务中的作用。推动建立农村社区“三留守”服务关爱体系，掌握人员动态信息。大力培育和发展针对社区“三留守”人员的互助类、志愿类社会组织。建立区级以上机关党员干部到农村社区挂职任职、驻点包户制度。建立和完善党代表、人大代表、政协委员联系农村居民、支持农村社区发展机制。鼓励驻村机关、部队、企事业单位支持参与农村社区建设。鼓励支持退伍军人、普通高校和职业院校毕业生及各类优秀人才到农村社区工作。拓宽外出发展人员、退休回乡人员参与农村社区建设渠道。

（五）推进农村法治建设，营造平安稳定农村社区环境。充分利用“送法进农户”“民警进社区任职”“律师进社区”“平安之声”等形式和载体，深入开展农村社区法治宣传教育和平安宣传，打造一批具有地方特色的普法宣传教育阵地和法治建设、平安建设示范社区。完善村民自治章程和村规民约，提高农村社区治理法治化水平。健全依法维权和化解纠纷机制，引导和支持农村群众通过合法途径维权，理性表达合理诉求，从源头上预防和化解社会矛盾，解决社会治安问题。建立“一村一法律顾问”制度，加强对农村居民的法律服务和法律援助。加强和改进农村社会治安综合治理。健全完善“一村一警”制度和农村社区综治工作室，加强村、社区治安视频监控系统建设，加强村、社区专业巡逻队伍、义务巡逻队伍和群防群治队伍建设，着力提高人防、物防、技防水平，不断完善农村立体化社会治安防控体系。

（六）推进农村文化建设，增强农村居民凝聚力。加强农村社区文化设施建设，推进多功能、综合性社区文化活动室和乡镇、中心村文化室建设。发挥广播电视村村通、农村党员干部现代远程教育、农村数字电影工程和农家书屋等重点文化工程的作用，为促进社区居民的全面发展创造必要条件。广泛开展文明村镇、文明社区、和谐社区、文明户等群众性精神文明创建活动，倡导健康、文明的生活方式和良好的社会风尚。实施农民体育健身工程，加快农村社区体育设施建设。积极开展群众喜闻乐见的民俗文化、广场文化、院落文化、家庭文化等文化活动，结合当地实际制定村规民约，发扬优良的社会风俗，潜移默化地增强农民文明素养。树立良好家风、弘扬公序良俗、宣传优良家训，形成健康向上、开放包容、创新进取的社会风尚。支持农村居民兴办演出团体和其他文化团体。在规划建设农村社区时，注重保护乡村自然景观，对具有乡土特色的地形、地貌和较高历史文化价值的古村落予以尊重和保护。发现和培养乡土文化能人、乡贤文化、民族民间文化传承人等各类文化人才,打造一批特色文化品牌。

（七）推进人居环境建设，共建生态美丽乡村。改善农村社区人居环境，强化农村居民节约意识、环保意识和生态意识，形成爱护环境、节约资源的生活习惯、生产方式和良好风气。加快完善农村社区基础设施建设，完善“五通”（通水、通电、通路、通有线电视、通网络）配套工程，完善绿化美化建设。建立健全农村供电、供排水、道路硬化和路灯亮化及交通安全、消防安全、地名标志、通信网络等公用设施的建设、运行、管护和综合利用机制，提高对自然灾害、事故灾难、公共卫生事件、社会安全事件的预防和处置能力。加快改水、改厨、改厕、改圈，改善农村社区卫生条件和河道洁化建设。推广沼气、天然气、风力、太阳能、秸秆制气等再生能源和清洁能源设施建设。发动农村居民和社会力量开展形式多样的农村社区公共空间、公共设施、公共绿化管护行动，积极推进“美丽乡村”和生态文明建设，保持农村社区乡土特色建设和田园风光。

三、工作要求

（一）加强组织领导。根据我区城乡社区建设实际，将咸安区社区建设领导小组和咸安区农村社区建设领导小组“合二为一”，成立咸安区城乡社区建设领导小组，负责对全区城镇社区建设和农村社区建设工作的协调领导。区城乡社区建设领导小组下设办公室，设在区民政局。区城乡社区建设领导小组及办公室要加强区级农村社区建设试点的指导，积极开展农村社区建设课题研究，确保取得科研成果。各地要高度重视农村社区建设工作，切实把建设规划纳入当地国民经济和社会发展总体规划、土地利用规划、村庄规划、社会主义新农村建设规划及美丽乡村建设规划，把建设成效纳入政府目标考核指标体系。各地也要相应成立领导小组和办事机构，认真研究制定农村社区建设的政策措施和实施方案。各级各部门要强化责任意识，按照责任分工，搞好配合协作，形成推进合力。

（二）明确部门责任。建立健全政府领导、民政部门牵头、有关部门协同、社会力量参与的农村社区建设推进机制，形成农村社区建设整体合力。各相关部门要充分发挥职能作用，研究制定本系统参与农村社区建设的政策措施和实施办法，按照各自职责范围，制定推动公共服务职能向农村社区延伸覆盖的政策措施。商务、工商、税务、供销等部门负责落实扶持农村社区商业服务发展的政策措施。工会、共青团、妇联以及残联、老龄委等群团组织，要组织发动各自联系的社会力量积极投身农村社区建设，开展各种类型的社区志愿和互助服务。

（三）落实经费投入。各地要加大对农村社区建设试点工作的投入。整合相关涉农资金，拓宽资金来源渠道，统筹利用好村集体经济收入、政府投入和社会资金，提高资金使用效率。按照分级负担的财政体制，落实农村社区建设试点经费，支持农村社区建设课题研究。按规定合理安排农村社区工作、网格化服务管理工作经费和社区工作人员、网格员报酬。同时，提倡政府机关、企事业单位和城市社区与农村社区建立结对帮扶关系，动员社区内外各类社会组织和个人通过慈善捐赠兴办社区服务项目，努力形成全社会关心、支持、参与农村社区建设的良好氛围。

（四）加强宣传引导。坚持正确的舆论导向，通过开展形式多样、生动活泼的宣传活动，让试点政策和措施家喻户晓。对农村社区建设试点工作，要制定路线图，明确时间节点，加大督促检查力度，层层传导压力，形成目标明确、督查有力、问责严格的责任体系，做到农村社区建设工作有人管、有人促、有人干。
