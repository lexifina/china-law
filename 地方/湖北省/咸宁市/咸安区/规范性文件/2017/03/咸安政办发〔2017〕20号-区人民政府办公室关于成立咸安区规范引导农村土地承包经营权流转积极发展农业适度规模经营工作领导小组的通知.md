# 区人民政府办公室关于成立咸安区规范引导农村土地承包经营权流转积极发展农业适度规模经营工作领导小组的通知

咸安政办发〔2017〕20号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

为了进一步加强对全区规范引导农村土地承包经营权流转，积极发展农业适度规模经营工作的组织领导，经区政府研究，决定成立咸安区规范引导农村土地承包经营权流转积极发展农业适度规模经营工作领导小组。现将成员名单通知如下：
