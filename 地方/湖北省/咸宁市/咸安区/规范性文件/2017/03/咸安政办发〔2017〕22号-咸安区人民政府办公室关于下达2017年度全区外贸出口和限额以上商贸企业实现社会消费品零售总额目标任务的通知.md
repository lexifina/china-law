# 咸安区人民政府办公室关于下达2017年度全区外贸出口和限额以上商贸企业实现社会消费品零售总额目标任务的通知

咸安政办发〔2017〕22号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

为了认真落实省、市商务工作会议的决策部署，坚持“稳中求进”的总基调，以推进供给侧结构性改革为主线，深化创新驱动，加快培育商务发展新动能，着力提升开放型经济水平，推动全区商务经济又好又快发展，经区政府研究，决定对2017年全区外贸出口和限额以上商贸企业实现社会消费品零售总额与限上企业发展工作实行目标责任管理，年终进行考核。

现将2017年商务经济指导性目标任务予以细化分解。各相关单位要切实按照“改革创新、稳中求进”的总体要求，对照目标任务，细化分解责任，强化措施，确保2017年各项目标任务顺利完成。

附件：1.咸安区2017年度外贸出口指导性目标任务分解表

2.咸安区2017年度限额以上商贸企业实现社会消费品零售总额与限上法人企业新增个数指导性目标任务分解表

咸安区人民政府办公室
