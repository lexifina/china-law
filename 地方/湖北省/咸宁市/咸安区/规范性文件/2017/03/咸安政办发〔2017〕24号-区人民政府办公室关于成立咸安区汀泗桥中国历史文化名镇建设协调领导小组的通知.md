# 区人民政府办公室关于成立咸安区汀泗桥中国历史文化名镇建设协调领导小组的通知

咸安政办发〔2017〕24号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

为加强对汀泗桥中国历史文化名镇打造的组织领导，加大建设推进力度，确保项目顺利实施，经区政府研究，决定成立咸安区汀泗桥中国历史文化名镇建设协调领导小组。现将成员名单通知如下：

组　长：盛文军 区　长
