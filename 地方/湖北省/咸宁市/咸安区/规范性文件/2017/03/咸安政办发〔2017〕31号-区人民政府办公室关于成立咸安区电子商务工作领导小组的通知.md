# 区人民政府办公室关于成立咸安区电子商务工作领导小组的通知

咸安政办发〔2017〕31号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

二、成员单位职责分工

区政府办：负责全区电子商务发展工作的宏观指导、综合协调和督查考核。

区政府金融办：负责将电子商务建设纳入全区信用体系建设，协助金融机构修订支持电子商务发展的政策措施，负责指导协助及落实情况督办。相关金融机构创新推出扶持电子商务发展的相关专项信贷产品。

区委宣传部：负责电子商务工作媒体宣传、舆论引导，在电视、网络等区内媒体开辟专栏或专题，及时宣传报道全区电子商务发展最新动态。

区委党校：负责将电子商务培训内容列入每年党员干部培训计划，组织开展党员干部电子商务知识培训活动。

区团委：负责发动全区青年创业者参加电子商务培训和就业创业。

区商务局：负责全区电子商务发展推进工作的日常管理和综合协调，研究制订全区电子商务总体发展规划，提出促进我区电子商务发展的政策建议，协调解决全区电子商务发展重大问题，协同有关部门督促落实区电子商务工作领导小组议定事项，做好电子商务协会的服务和管理工作，承办领导小组交办的其他事项，为区委区政府及领导小组做好决策参谋。

区人社局：负责把电子商务培训纳入全区就业创业培训体系，落实相关培训机构对电商人才培训的政策支持，开展网上创业认定和相关政策的研究制定；负责网上创业再就业创业见习基地建设，落实大学生电子商务就业创业优惠政策。

区编办：负责电商发展服务中心机构编制落实，人才的引进服务。

区发改局：负责将电子商务发展作为全区服务业发展的重点进行推动，参与电子商务产业发展规划和扶持政策的制定，对电子商务重点项目在政策上给予扶持。

区公安局：负责依法打击电子商务经营活动中的违法犯罪行为。

区经信局：负责组织全区规模企业全面参与电子商务应用工作。

区农业局：负责做好本地农副产品网上销售相关工作。

区科技局：负责科技在电子商务领域的推广和应用。

区财政局：负责全区电子商务发展工作相关经费的落实和保障，负责全区电子商务发展扶持政策资金的审核、兑现。

区民政局：负责做好区电子商务协会的许可和监督管理工作。

区国土局：负责电子商务产业园和网商创业园项目的供地保障。

区工商局：负责做好全区电子商务企业（网店）的登记工作，加强对电商企业（网店）的诚信教育和监管。

区统计局：负责做好全区电子商务企业（网店）的登记及从业人员的相关统计培训工作。

区旅游局：负责组织全区涉旅企业参加电子商务培训和应用，做好全区各旅游景点的网上宣传、旅游线路网上推介、网上购票、网上订房等具体项目的宣传和实施。

区供销社：负责组织发动全区供销系统内企业参加电子商务知识培训和应用。利用农村村级综合服务社，做好农村电商工作。

区国税局、区地税局：负责落实促进全区电子商务发展的有关税收优惠政策。

区招商局：负责做好知名电子商务企业来咸安投资落户相关服务工作。

区水产局：负责做好本地特色水产品网上销售相关工作。

区广电局：负责做好全区电子商务的广播电视宣传工作。

区质监分局：负责本地网上销售产品的质量检测及监管工作。

区邮政局：负责全区农村电商三级体系建设运营工作。

区电信公司、区移动公司、区联通公司：负责全区网络信息的应用与管理，做好网络信息平台建设和服务工作。

区交通运输局：负责全区电子商务物流配送点的规划、建设和管理。

区教育局：负责加强电子商务职业教育和专业技术培训，引导全区职业技术学校开设电子商务课程和实习培训。

各乡镇办场：负责做好本地范围内农村电子商务的应用推广工作。

领导小组下设办公室，办公室设在区商务局电子商务发展服务中心，负责全区电子商务发展日常工作的规划、指导、协调、督办、重大政策的决策调研论证、情况综合分析汇总等工作，为区委区政府及领导小组当好参谋，提供决策服务，指导全区电商发展。杨大平同志兼任办公室主任，冷庆生同志兼任办公室常务副主任。
