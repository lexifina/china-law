# 区人民政府办公室关于成立咸安区火炬统计工作领导小组的通知

咸安政办发〔2017〕32号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

2017年2月13日，国务院国函〔2017〕16号文件正式批复咸宁高新区升级为国家高新技术产业开发区。为配合做好咸宁国家高新区火炬统计工作，经区政府研究，决定成立咸安区火炬统计工作领导小组。现将领导小组成员名单及成员单位责任分工通知如下：

二、成员单位工作职责

咸安经济开发区：负责咸安经济开发区“一区六园”及三办（温泉、浮山、永安）区域内统计对象在市高新区的科技部火炬中心网站（http：//tj.ctp.gov.cn）进行网上直报、审核工作；协调相关部门和“一区六园”开展统计数据网上直报和“一区六园”统计月报、季报、年报汇总、审核、上报工作。

“六园”所在镇人民政府：负责组织、督查统计人员对工业园区的企业进行统计数据上报工作。

区科技局：负责提供全区高新技术企业名单及2016年相关数据；负责指导督办“一区六园”所有高新技术企业按办公室要求进行统计数据网上直报和统计月报、季报、年报工作。

区统计局：负责提供“一区六园”和“三办” 2016年统计对象的基础数据（应用高技术进行设计、施工以及技术装备的建筑业企业；符合国家统计局高技术服务业、科技服务业、生产性服务业目录的服务企业；符合国家统计局文化及相关产业目录的企业）；负责提供“一区六园”各统计类型入库企业名单和数据资料报送工作；负责定期组织园区填报企业对象开展培训以及统计数据的对接及审核、汇总工作；负责跟踪“四上企业”动态信息，做好后期统计对象的动态监测工作。

区经信局：负责督办“一区六园”和“三办”规上企业的统计数据网上直报；负责与咸安经济开发区统计办公室进行统计数据的对接；负责组织统计类型企业的进规培育成长工作，及时开展后期统计对象的动态监测工作。

区财政局：负责提供“一区六园”内的财政收入及预算支出数据。

区住建局：负责督办应用高技术进行设计、施工以及技术装备的建筑业企业进行统计数据网上直报（http：//tj.ctp.gov.cn）和统计月报、季报、年报工作；负责与咸安经济开发区统计办公室进行统计数据的对接及审核汇总，并组织开展后期统计对象递增动态监测工作。

区文体新局：负责督办“一区六园”限上文化企业的统计数据网上直报和统计月报、季报、年报工作；负责与咸安经济开发区统计办公室进行统计数据的对接及审核、汇总工作。

区商务局：负责提供“一区六园”和“三办”流通领域中的批零，住餐限上企业资料及进出口统计数据，负责跟踪“限上企业”动态信息，做好后期统计对象的动态监测工作。

区工商局：负责提供“一区六园”内企业注册数量及名单资料。

区旅游局：负责提供“一区六园”和“三办”住宿与餐饮限上企业的名单等相关资料。

三、工作要求

1.提高认识，加强领导。咸宁国家高新区建设推进工作事关省委、省政府，市委、市政府战略部署。做好统计工作事关咸宁高新区争先进位，领导小组成员作为国家高新区建设和统计工作第一责任人，要高度重视火炬统计工作，各相关镇和部门要明确一名分管全面负责，切实抓好此项工作的落实。

2.建立机制，协同配合。各相关镇政府要制定各领域网上直报企业名录库和填报对象联系录，分线、分块、分月组织指导网上直报工作，在原各项经济考核模式不变的基础上抓好科技部火炬中心统计工作。要建立长效工作机制，开发区、统计、科技、经信、住建、财政、文体、商务、工商、旅游等部门要协调配合，形成合力，共同促进统计工作的落实。企业要明确一名统计工作分管负责人和一名具体负责网上数据填报的统计人员，开展网上报送工作。全区上下要做到一级抓一级，层层明确职责，及时圆满完成国家高新区的月报和年报工作。

3.明确要求，精准报送。统计指标是衡量国家高新区发展有效综合考评的依据。各相关单位务必清醒认识科学统计工作的重要性。开发区、统计、科技、经信、财政、住建、文体、商务、工商、旅游等部门要组织本单位业务骨干和入库企业统计员开展《火炬统计调查制度》的学习培训。明确各类统计报表的统计对象、统计范围、指标含义、统计渠道、报送时间及审核办法，确保每月据实上报、及时上报、科学上报，并定期配合做好统计数据的审核汇总工作。

4.压实责任，强化考核。开发区及“六园”所在镇和相关部门主要负责人要对本地区、本部门火炬统计工作负总责，明确一名副职分管，对职权范围内的工作负主要领导责任。要制定对统计人员的考核办法，完善工作机制和办法，把责任压实、要求提实、考核抓实，推动火炬统计工作落地见效。
