# 区人民政府办公室关于调整咸安区“三支一扶”工作领导小组和协调管理办公室成员的通知

咸安政办发〔2017〕33号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

根据人事变动和工作需要，经区政府研究，决定对咸安区“三支一扶”工作领导小组和协调管理办公室成员进行调整。现将调整后的成员名单通知如下：

组 长：郑奇明 常务副区长

副组长：陈 政 区委组织部常务副部长

徐炎良　 区委组织部副部长、区公务员局局长

成 员：周立福　 区公务员局副局长

周 敏　 区财政局副局长

赵 红 　区人社局党组副书记

杨之功　 区卫计局副局长

陈 艳　 区农业局副局长

沈昌亚 　区水利局副局长

余淑均　 区文体新局副局长

王春仙　 区扶贫办副主任

陈剑兰 　团区委副书记

王水兵　 区残联主任科员

协调管理办公室设在区公务员局，周立福同志兼任办公室主任，刘玉霞同志担任办公室副主任，办公室成员包括钱道政、曹梦琦、施超、李庆华、刘小平、张培红、邹琼、陈继红、陈微、柯宗苗、陈琼香。
