# 咸安区人民政府办公室关于进一步做好行政机关和事业单位个人所得税全员全额代扣代缴工作的通知

咸安政办发〔2017〕39号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

为进一步加强个人所得税征收管理，根据《中华人民共和国税收征收管理法》、《中华人民共和国个人所得税法》、《国家税务总局办公厅关于做好个人所得税自行纳税申报和全员全额扣缴明细申报工作的通知》（税总办发〔2016〕15号）和《省地方税务局关于进一步加强行政事业单位个人所得税代扣代缴工作的通知》（鄂地发税〔2015〕67号）精神，结合我区行政事业单位工资发放实际情况，经区政府研究，决定从2017年1月1日起，全区各行政机关、事业单位全面履行个人所得税全员全额代扣代缴义务，并使用个人所得税专用申报系统软件，按月向区地税局进行全员全额明细申报。现就进一步做好行政机关和事业单位（以下简称行政事业单位）个人所得税代扣代缴工作有关事项通知如下：

一、充分认识做好依法扣缴个人所得税工作的重要意义

依法纳税是每个公民应尽的义务，做好个人所得税代扣代缴工作是各扣缴单位的法律责任。行政事业单位作为个人所得税扣缴义务人的重要组成部分，要依法认真履行个人所得税代扣代缴义务，为全区个人所得税代扣代缴工作起到示范带头作用。

二、严格执行政策，全面落实行政事业单位个人所得税代扣代缴工作

（一）扣缴对象。各级党政机关（包括人大、政协、司法机关）、事业单位的所有工作人员。

（二）扣缴义务人和范围。扣缴义务人为各行政机关、事业单位。扣缴范围是指个人因任职或者受雇而取得的工资、薪金、奖金、年终加薪、劳动分红、津贴、补贴以及与任职或者受雇有关的其他所得，包括现金、实物、有价证券和其他形式的经济利益。

（三）扣缴方式。根据我区行政事业单位管理体制实际情况，采取不同的代扣代缴模式：

1.行政事业单位，应将其职工工资津贴、补贴、奖金、年终加薪以及其他应税所得合并计算，由各扣缴单位向主管地税机关申报，并统一向主管地税机关缴纳。

2.行政事业单位下属的二级以及其他单位含企业化管理的事业单位等，由主管机关统一将工资津贴、补贴、奖金、年终加薪以及其他应税所得合并计算，由主管机关统一扣缴，并向主管地税机关统一申报，统一汇总缴纳。如因客观原因不能统一扣缴的，由区地税部门确定扣缴方式。

（四）扣缴管理。根据《中华人民共和国个人所得税法》规定，所有扣缴义务人统一安装《个人所得税代扣代缴系统》软件，按要求做好本单位职工个人所得税扣缴基础信息采集工作，将信息录入（导入）个人所得税扣缴系统，并根据基础信息变化，及时更新系统资料。实行全员全额扣缴申报管理，按月将支付给职工的所得额和免税收入额、允许扣除的所得额等相关扣缴信息录入扣缴系统，通过扣缴系统计算应扣缴的个人所得税税款，于次月十五日之前缴入国库，并向主管地税机关报送《扣缴个人所得税报告表》和《支付个人收入明细表》。

（五）手续费支付。主管地税机关对扣缴义务人所扣缴的税款，按照《中华人民共和国个人所得税法》第十一条规定，付给2%的手续费。由地税机关查处补扣的个人所得税税额，不向扣缴义务人支付手续费。

三、工作要求

（一）切实履行义务，推动工作全面落实。各扣缴义务人要高度重视，切实履行好个人所得税代扣代缴义务，自觉接受主管税务机关检查和评估。对逃避、拒绝履行扣缴义务的，或应扣未扣、应收未收税款的，由区地税部门根据《中华人民共和国税收征收管理法》相关规定予以处罚，并将处理结果及时予以曝光，切实维护良好的税收秩序。

（二）增强服务意识，提升扣缴工作质量。区地税部门要通过区综合治税平台对各单位个人所得税电子明细申报情况进行动态监控，对有疑点的单位要通过风险推送、风险应对、稽查查处的税收征管手段及时介入调查；要建立健全个人所得税代扣代缴制度，完善对行政事业单位代扣代缴工作的服务和管理；要加强税法宣传和业务辅导，做好政策咨询和服务工作，维护扣缴义务人的合法权益。

（三）加强协作配合，构建综合治税环境。区财政、地税部门要加强协作，共同做好个人所得税代扣代缴管理工作。区纪检监察机关对拒不执行代扣代缴义务的单位、党员干部，要按相关党纪、政纪进行处理，涉及违法行为的，移送司法机关。区政府办协调解决个人所得税代扣代缴工作中遇到的新情况、新问题。全区各级行政事业单位要积极配合，支持区地税部门加强对个人所得税的征收管理，切实做好个人所得税代扣代缴工作，着力构建协税护税的良好环境，促进个人所得税代扣代缴工作规范有序、深入扎实开展。
