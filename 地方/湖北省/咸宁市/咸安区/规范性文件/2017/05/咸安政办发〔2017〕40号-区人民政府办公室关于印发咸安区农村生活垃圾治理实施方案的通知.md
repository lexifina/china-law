# 区人民政府办公室关于印发咸安区农村生活垃圾治理实施方案的通知

咸安政办发〔2017〕40号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

《咸安区农村生活垃圾治理实施方案》已经区政府常务会议审议通过，现印发给你们，请认真贯彻实施。

咸安区人民政府办公室

2017年4月28日

咸安区农村生活垃圾治理实施方案

为进一步推进全区农村生活垃圾减量化、资源化、无害化，建立改善农村环境卫生状况和环境面貌的长效机制，根据省住建厅等10部门联合印发的《湖北省全面推进农村垃圾治理工作方案》(鄂建文〔2016〕17号)要求，特制定本实施方案。

一、工作目标

（一）总体目标 。通过有效治理农村生活垃圾、建筑垃圾、农村工业垃圾等,促进农村居民环境卫生意识明显提高，农村环境卫生管理制度不断健全，“户分减、组保洁、村监管、镇集中、区转运”的垃圾保洁清运体系日益完善。到2018年，自然村湾保洁全覆盖和农村生活垃圾无害处理率达95%以上，确保“五有”，即有齐全的设施设备、有成熟的治理模式、有稳定的保洁队伍、有长效的资金保障、有完善的监管制度。

（二）年度目标。2017年，落实村庄保洁队伍，完善管理制度，健全城乡生活垃圾统筹治理体系，完成环卫设施设备配套工作，群众能够积极主动参与农村生活垃圾治理。完成所有垃圾中转站配套设施建设，推进垃圾中转站高效运转，基本实现农村生活垃圾集中处理全覆盖，确保全区95%以上村庄的生活垃圾得到有效治理并通过省级验收。2018年通过国家验收。

二、工作重点

（一）有成熟的治理模式。从五个层面上抓治理：一是户分减。从垃圾产生的源头抓起，积极开展垃圾分类收集工作，推动各类垃圾资源化和减量化。二是组保洁。农户屋内及房前屋后、公共场所达到“四不见”效果（即不见塑料垃圾、不见人畜粪便、不见乱堆乱放、不见污水乱流）。三是村监管。村委会监督保洁员履责，监督清运公司及时清运，监督村湾制定村规民约。四是镇集中。垃圾全部集中到垃圾中转站处理，杜绝乱丢乱扔和随处填埋。五是区转运。区政府统一将乡镇办场垃圾中转站垃圾转运到垃圾发电厂焚烧发电，实现农村生活垃圾无害化处理。

（二）有稳定的保洁队伍。从五个方面建队伍：一是户实行“分类+减量”。每户保证垃圾分类和减量，能沤肥的沤肥，能焚烧的焚烧，能喂家畜的喂家畜，建筑垃圾就近铺路，不能处理的电子、医疗等垃圾放到专门设置的垃圾箱或垃圾池收集。二是湾（组）实行“保洁员+评分员”。按照每100户配1名保洁员标准，推选由有奉献精神、敢于坚持原则、德高望重的人担任保洁员，督促农户做好屋内外卫生清理和垃圾分减，负责做好公共场所垃圾清扫、村规民约执行及村民积分（建立村民环境卫生积分制度）记录。三是村实行“信息员+监督员”。各村成立由村干部、老党员、网格员组成的义务监督队，监督保洁员和保洁公司履责，实行保洁记分制，把积分结果与工资挂钩。四是镇实行“清运员+考核员”。各乡镇办场要组建垃圾清运公司，规划好乡镇垃圾清运路线及钩臂箱合理布点，及时将各村湾垃圾清运到镇垃圾中转站。同时，各乡镇办场要落实2名卫生考核人员，负责对垃圾清运、村湾环境卫生实行监督考核。五是区实行“转运员+监管员”。区财政采取竞争性谈判方式，外包清运公司，负责将乡镇垃圾中转站垃圾转运到垃圾发电厂焚烧发电。

（三）有齐全的设施设备。从五个方面配设备：一是户配垃圾桶。每户配备三个垃圾桶，分为可回收类、不可回收类和专业处理类。二是湾配垃圾收集器具。每个自然村湾配置一个垃圾收集器具。三是镇配清运车。每个乡镇办场要配有垃圾清运车。四是镇建中转站。每个乡镇办场要建有垃圾中转站，完善垃圾中转站配套设施。五是区配转运车。区级要配有转运车，能够及时转运各乡镇办场垃圾中转站垃圾和污水。

（四）有完善的监管制度。从五个方面抓监管：一是户建承诺牌。建立家庭格言，制作环境卫生承诺牌，并用二维码标注，增强农户环保意识，抓习惯养成。二是村组订村规民约。建立切合实际的村规民约、村民评分细则和村民积分制管理细则，抓制度形成。三是建立城乡环卫一体化智慧管理平台。区级建立统一指挥调度监控中心，负责监管各乡镇办场垃圾治理情况，实时监控、及时调度；镇级建立六大管理子系统，即环卫基础设施管理子系统、保洁人员智能监管子系统、作业车辆智能监管子系统、垃圾收集智能监控子系统、场站视频监控子系统和监督考核智能管理子系统。四是建立“五长”责任制。明确分管区长与乡（镇、办、场）长（主任）、局长、村长、组长“五长”主体责任，年初分管区长与乡（镇、办、场）长（主任）、局长，镇长与村长，村长与组长分别逐级签订责任状，一级抓一级，确保责任落实到位。五是建立督查考核机制。采取定期不定期督查考核机制，区级一季一考核、镇级一月一督办、村级一周一巡视、组级一天一检查，并将检查情况以通报形式向外公布。

（五）有足够的资金保障。从五个方面抓保障：一是三万工作队结对帮扶资金，确保每户有垃圾桶。二是乡镇办场自筹，配备配齐配足，确保每个村湾有垃圾收集器具，每个乡镇办场有清运车。同时，各乡镇办场按实际服务户数10元/户•月标准计发工资，各村可按每人每月1块钱的标准收取村民环境卫生费（五保户、贫困户除外），不足部份由乡镇办场财政补齐。三是区级财政按照每村每年3万元标准列入财政预算，通过考评后分季度奖补到乡镇办场统筹用于垃圾治理工作。同时区级财政每年列支专项经费给区美洁保洁公司用于转运垃圾中转站垃圾和下乡督查等，确保“区转运”顺畅。四是区政府筹资建立农村生活垃圾治理数字化智慧管理系统。五是争取市政府支持解决我区农村垃圾到市垃圾发电厂焚烧费用问题。

三、工作要求

（一）加强组织领导。成立农村生活垃圾治理工作专班，由区住建局牵头，负责全区“最洁净村庄”和农村生活垃圾治理工作的考核检查。各乡镇办场要把农村垃圾治理工作纳入重要议事日程和工作考核内容，明确责任，强化措施，在工作部署、人员组织、财力安排上统筹协调，确保目标任务落到实处。各有关部门要根据职能分工，发挥部门优势，整合政策、资金、项目，重点支持农村生活垃圾专项治理工作，形成推进合力。

（二）明确责任主体。各乡镇办场是本区域农村生活垃圾治理的实施主体，要落实专人负责，做好收集转运设施建设和日常运行等工作。各村委会要组织动员村民，修订完善村规民约，做好村民的宣传引导和村庄保洁工作。

（三）深化宣传教育。各相关单位要利用广播、横幅、宣传牌等多种形式，集中宣传农村生活垃圾治理的重要意义和基本常识。及时宣传工作要求和好经验好做法，大力宣传先进典型。村委会要广泛开展“文明卫生农户”“文明卫生村湾”评选活动，引导农民群众增强环境意识和责任意识，进一步养成良好卫生习惯，形成“政府主导、农民参与、社会支持”的良好社会氛围。

（四）强化督查考核。区住建局负责制订“最洁净村庄”评选细则、农村生活垃圾治理考评验收标准，牵头组织每季度检查考核工作，及时通报情况，确保全区农村生活垃圾治理工作扎实有效地推进。同时，积极邀请人大、政协等第三方监督各乡镇办场垃圾治理工作，对治理工作开展不好的单位在报纸或电视上予以曝光，对治理工作开展好的单位给予资金奖励。

（五）完善建管机构。各乡（镇、办、场）、村、组要有管理阵地，要有档案管理记录。乡镇办场阵地设在垃圾中转站，将钩臂箱布点、垃圾清运路线图、工作人员管理网络、管控平台、相关记录及奖惩制度等建章立制，建档上墙，便于督查。
