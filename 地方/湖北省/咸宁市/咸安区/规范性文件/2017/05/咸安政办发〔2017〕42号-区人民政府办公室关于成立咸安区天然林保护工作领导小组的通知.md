# 区人民政府办公室关于成立咸安区天然林保护工作领导小组的通知

咸安政办发〔2017〕42号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

根据中央加强生态环境保护的要求，国家决定扩大天然林保护范围，我区被纳入了非天保区天然林保护范围。为了加强对天然林保护工作的领导，全面完成天然林保护工作，确保生态环境不断改善，经区政府研究，决定成立咸安区天然林保护工作领导小组。现将成员名单通知如下：

组 长：王 宇 副区长

副 组 长：陈 辉 区政府办副主任

刘伍寿 区林业局局长

成 员：包 勇 区编办主任

张 凡 区农办副主任

龚长永 区发改局副局长

陈 晖 区财政局副局长

赵 红 区人社局副局长

胡贤艳 区国土局总工程师

黄扬武 区环保局总工程师

廖国强 区扶贫办副主任

领导小组下设办公室，办公室设在区林业局，刘伍寿同志兼任办公室主任。

咸安区人民政府办公室

2017年5月5日
