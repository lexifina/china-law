# 区人民政府办公室关于调整咸安区整顿卷烟市场工作领导小组成员的通知

咸安政办发〔2017〕44号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

根据人事变动和工作需要，经区政府研究，决定对咸安区整顿卷烟市场工作领导小组成员进行调整。现将调整后的成员名单通知如下：

组 长：吴长勇 区政府党组成员

副组长：钱飞鹏 区政府办主任科员

曾卫海 区烟草专卖局局长

成 员：王 波 区检察院副检察长

余经山 区检察院副检察长

沈芳兰 区人民法院副院长

刘 刚 区公安局纪委书记

王 刚 区交通运输局副局长

漆 刚 区工商局副局长

樊 辉 区质监局副局长

朱春平 区烟草专卖局副局长

夏耀林 区邮政分公司副总经理

杨 耀 市公安局温泉分局副局长

黄晓勇 市工商局温泉分局副局长

任永军 武汉铁路公安处咸宁北车站派出所所长

陈 强 武汉铁路公安处咸宁车站派出所所长

领导小组下设办公室，办公室设在区烟草专卖局，钱飞鹏同志兼任办公室主任，刘刚、朱春平同志兼任办公室副主任，负责全区卷烟市场整顿的日常工作。
