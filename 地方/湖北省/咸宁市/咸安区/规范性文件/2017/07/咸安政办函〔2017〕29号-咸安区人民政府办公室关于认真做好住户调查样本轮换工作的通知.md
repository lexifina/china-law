# 咸安区人民政府办公室关于认真做好住户调查样本轮换工作的通知

咸安政办函〔2017〕29号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

根据国家统计局统一安排，2017年在全国开展住户调查样本轮换工作，同时进行增点扩户。为切实做好我区此轮住户调查样本轮换工作，进一步提高样本代表性和调查数据质量，根据市政府办《关于认真做好住户调查样本轮换工作的通知》（咸政办电〔2017〕49号）等文件精神，经区政府同意，现就有关事项通知如下：

一、深化认识，高度重视

此轮住户调查样本轮换并增点扩户是贯彻落实党中央、国务院关于深化统计管理体制改革、提高统计数据真实性的重要措施，聚焦提高居民收入数据代表性和真实性这个根本，不断提高数据质量，为区委、区政府精准施策、精准扶贫、全面小康监测等提供科学决策依据。今年的样本轮换事关今后五年居民收入以及与之相关的一系列数据的代表性和准确性，尤其是对近几年扶贫脱贫工作考核以及2020年全面实现小康社会的核算至关重要，因此，各乡镇办场和区直相关部门要高度重视，坚持实事求是，科学、规范、有序地推进该项工作，严禁在样本轮换和增点扩户工作过程中发生人为干扰、弄虚作假现象，确保样本轮换流程不走样，获取的调查数据真实、准确。各地、各有关部门要严格按照国家调查方案的要求，按时完成相关工作任务。

二、密切配合，统筹推进

全区住户调查样本轮换工作由区统计局和省统计局咸安经济社会调查队组织实施。此次样本轮换工作涉及面广、时间紧、任务重，有关部门要加强分工协作，密切配合。统计调查部门要严格执行国家样本轮换方案，依法依规开展调查工作；被抽中住户所在乡镇办场、村（社区）要全力支持配合做好样本轮换工作，要安排熟悉当地情况的精干力量全程参与抽中小区（村）的住户普查工作，为下一步抽选正式调查户打好基础。在常规调查中，要配合精选责任心强、能力突出的同志作为所在村（社区）的辅助调查员；被抽中住户的所在单位，要支持配合统计调查部门对抽中户开展调查。

三、明确任务，按时完成

根据国家统计局的统一要求，此轮样本轮换工作分两步进行。第一步，对全区范围内抽中调查小区（村）进行住户普查工作。由调查员绘制调查小区（村）图、编制建筑物清查表和编制住户住宅名录表，最后上门入户调查，摸清小区（村）所有住户的人口、就业、收入、住房等基本情况。我区共需要抽取16个调查小区（村），按每个小区（村）需调查350户左右住户计算，即需对5600多户城乡居民进行一次住户普查工作。此项工作是整个住户收入调查工作的基础，要在7月底前完成并上报国家统计局。8月初，国家统计局将根据各地上报的住户普查资料抽取常规调查样本，并将抽取情况反馈到各地。第二步，落实国家反馈的常规调查样本。根据国家反馈的常规调查样本清单，由调查员逐户上门落实调查户，开展记账业务培训和试记账工作。为提高收入数据的代表性，依照国家和省、市统计调查部门的统一安排，我区本次样本轮换需要将调查样本由原来的110户扩大到160户以上。新样本的常规调查将从2017年12月1日起正式执行。同时，为提高统计调查手段的现代化，按国家统计局的要求，新样本（新调查户）常规调查，需全面推行电子记账工作，其中，城镇居民电子记账率要到90%，农村居民电子记账率要达到70%。

四、成立专班，协同推进

五、强化保障，夯实基础

各乡镇办场、区直有关部门要落实好中央深改组关于加强统计工作的意见和省、市政府相关文件要求，加强对此轮样本轮换工作的领导和统筹协调，按分级负责原则，强化保障。

（一）保障调查力量。要通过各种方式，在现有人员基础上，新增住户调查专岗工作人员2—3名，以弥补增点扩户后调查力量不足的问题，并将新增人员经费纳入财政预算。各乡镇办场也要明确专人协同做好样本轮换和住户调查日常工作的开展，并提供必要的综合保障。

（二）落实调查经费。一是要落实好住户普查专项经费。此次小区（村）住户普查的工作量较大，任务重，区财政要安排配套经费予以支持。二是落实好电子记账需要的电子设备购置费和网络通讯费，确保电子记账的顺利推进。三是落实好新增50多户调查户的记账补贴和辅调员的补贴等常规经费。

（三）完善工作机制。住户调查工作涉及面广，任务繁重，调查户所在的乡镇办场、村和社区要配合统计调查部门做好日常调查工作，解决难入户、不配合记账等问题。区发改局、财政局、农业局、林业局、畜牧局、水局产、国税局、地税局、工商局、人社局、民政局、扶贫办、统计局、工会等部门要与统计调查部门建立定期的信息沟通交流机制，根据相关职责，予以大力支持，从面上掌握居民增收的项目支撑和信息，为数据评估打好基础。
