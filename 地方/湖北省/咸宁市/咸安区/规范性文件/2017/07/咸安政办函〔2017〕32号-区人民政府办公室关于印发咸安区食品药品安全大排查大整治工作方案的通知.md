# 区人民政府办公室关于印发咸安区食品药品安全大排查大整治工作方案的通知

咸安政办函〔2017〕32号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁向阳湖现代农业科技示范区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

强力推进“平安咸安”建设，打造安全稳定的食品药品消费环境，切实保障全区人民饮食用药安全，按照省、市、区关于加强食品药品安全工作的要求和部署，结合咸安实际，特制定方案如下：

一、工作目标

深入贯彻习近平总书记关于加强食品药品安全“四个最严”要求和省委书记“六个严防”指示精神，坚持源头严防、过程严管、风险严控的原则，按照“全覆盖、零容忍”的目标，通过开展全区食品药品安全大排查大整治行动，严厉打击一批违法违规生产经营食品药品行为，着力解决一批人民群众反映强烈的食品药品安全突出问题，整顿规范一批重点食品药品生产经营者，进一步提升我区食品药品安全整体水平。

二、组织领导

成立由副区长何琼珍任组长，区委统战部副部长王琦和区食药监局局长聂选明任副组长，各有关职能部门负责人为成员的食品药品安全大排查大整治工作领导小组。领导小组下设办公室，办公室设在区食药监局，具体负责工作的组织指导和统筹协调，聂选明同志兼任办公室主任。各乡镇办场和有关成员单位也要成立相应组织领导机构，定期召开会议，对食品药品安全大排查大整治工作进行指挥调度。

三、排查整治对象与范围

食品（含保健食品下同）生产经营企业、食品“三小”（小作坊、小餐饮、小摊贩），各类学校（含托幼机构）、养老机构、宗教场所、建筑工地和机关企事业单位食堂，网络订餐单位及配送单位，各类农贸市场；药品、医疗器械生产经营企业；二级及以上公立医疗机构、各类民营医疗机构、乡镇卫生院、社区卫生服务中心、村卫生室、个体诊所；化妆品生产经营企业及使用单位等。

四、排查整治内容与措施

（一）开展食品生产环节排查整治

各乡镇办场和有关职能部门要对辖区内食品生产企业和食品加工小作坊开展全面排查整治。严把原辅材料采购使用、食品添加剂管理、产品标识标注、成品出厂检验等关键环节，重点整治使用非食品原料、超范围超限量使用食品添加剂以及掺杂掺假生产加工食品，保健食品非法生产、非法添加，使用甲醇和工业酒精等非食品原料生产加工白酒，违规采购、使用非食用油料油脂和腐败变质原料生产食用油和加工病死畜禽等违法违规行为。（区食药监局负责）

（二）开展食品流通环节排查整治

各乡镇办场和有关职能部门要对辖区内食品经营企业和农贸市场开展全面排查整治。认真排查食品超市、副食店食品经营许可、经营条件、索证索票、进货查验和从业人员健康证等内容，重点整治农贸市场蔬菜、食用菌、畜禽产品、水产品等“菜篮子”食用农产品农药残留超标、非法添加、制假售假，采购、销售来源不明的“三无”散装白酒，销售无“两章”（动物产品检疫合格验讫印章、肉品品质检验合格验讫印章）、“两证”（动物产品检疫合格证明、肉品品质检验合格证）猪肉，购进、贮存、销售超过保质期、腐败变质、标签标识不规范和被责令下架退市、召回的“五毛食品”等违法违规行为。（区食药监局、区农业局、区畜牧局、区水产局、区商务局负责）

（三）开展餐饮消费环节排查整治

各乡镇办场和有关职能部门要对辖区内餐饮服务单位、各类单位食堂、网络订餐平台和入网餐饮服务提供者开展全面排查整治。以原料采购、生食海产品加工、餐饮具清洗消毒、食品配送、食品添加剂管理和使用、食品留样等为重点环节，深入排查经营许可证件、索证索票、进货查验和从业人员健康证等内容，重点整治未经许可、超许可范围从事餐饮服务，借用、变造、伪造许可证照，非法添加非食用物质、掺假掺杂和滥用食品添加剂等违法违规行为。区食药监局负责宾馆、酒店、早点和小餐饮等餐饮单位及农村集体聚餐、小摊贩备案、网络订餐平台和配送单位排查整治；区教育局负责各类学校（含托幼机构）食堂、学生集体用餐配送单位排查整治；区民政局负责社会福利（光荣）院、农村福利院、民办养老院等养老机构食堂的排查整治；区民宗局负责宗教场所食堂排查整治；区住建局负责建筑工地食堂的排查整治；区城管执法局负责食品小摊贩规点排查整治；区公安局负责涉嫌违法犯罪案件查处工作。

（四）开展药品生产经营环节排查整治

各乡镇办场和有关职能部门要对辖区内药品生产经营企业和医疗机构制剂室开展全面排查整治。一是以原辅料供应商资质审计、处方和工艺执行、原辅料和成品质量控制、物料平衡和偏差处理等关键环节，监督执行药品GMP，以麻醉药品和精神药品等特殊药品、基本药物、含特殊药品复方制剂、冷链药品、中药饮片、终止妊娠药品为重点品种，监督执行药品GSP。从严查处不按注册标准，使用未经批准药用辅料、药包材生产药品和非法渠道购进药品、挂靠走票、货账票证款不一致、计算机系统数据造假等违法违规行为。二是重点检查医疗机构制剂室委托（受托）生产品种，梳理医疗机构制剂配制存在的问题隐患，监督落实《医疗机构制剂配制质量管理规范》。从严查处未经注册、批准配制制剂的违法违规行为。（区食药监局负责）

（五）开展医疗器械生产经营环节排查整治

各乡镇办场和有关职能部门要对辖区内医疗器械生产经营企业开展全面排查整治。生产环节重点排查原料采购及质量控制、供货商资质审核和产品销售出库放行等关键环节，突出对一次性使用采血针、一次性医用防护服、定制式义齿、避孕套、体外诊断试剂等实行全环节质量监管。严格落实产品注册标准要求，实施分类分级监管，对不同产品的关键生产环节进行重点监管。从严查处未经批准、不按标准生产等违法违规行为。经营环节重点排查第三类医疗器械经营企业和穿刺类及骨科植入类、体外诊断试剂等重点品种，从严查处无证经营、超范围经营、未建立验收制度、计算机数据造假等违法违规行为。（区食药监局负责）

（六）开展药品和医疗器械使用环节排查整治

各乡镇办场和有关职能部门要对辖区二级及以上公立医疗机构、各类民营医疗机构、乡镇卫生院、社区卫生服务中心、村卫生室、个体诊所等药品和医疗器械使用单位开展全面排查整治。重点排查药品购进渠道是否合法、验收养护制度是否建立并严格执行、冷藏冷冻药品的仓库储存条件以及冷链药品购进和配送过程是否符合药品储存要求、麻醉药品和精神药品的使用和管理是否规范；医疗器械采购、入库制度是否严格执行，第三类医疗器械合格证及注册证书是否留存，冷藏医疗器械储存及使用管理是否规范，大型医疗器械维修及使用、关键零件更换及技术参数是否与说明书要求一致。重点查处从非法渠道采购、使用药品医疗器械，麻精药品管理不善和流入非法渠道等违法违规行为。（区卫计局、区食药监局负责）

（七）开展化妆品生产经营使用环节排查整治

各乡镇办场和有关职能部门要对辖区内化妆品生产企业、商场（含超市）、批发市场、化妆品专卖店、美容美发场所开展全面排查整治。生产环节重点排查违法添加禁用物质或超量添加限用物质以及化妆品标签标识等，检查企业原料的采购、验收、储存、使用等情况，对化妆品生产企业检查覆盖率要求达到100%。经营使用环节重点排查化妆品标签、标识和使用不符合卫生要求的化妆品，加强对化妆品购货验收相关制度建立执行和所经营的化妆品合法性情况的检查。严厉查处自制无标识或销售违规标识化妆品以及违法宣称“药妆”、“医学护肤品”及宣称医疗作用或暗示疗效的化妆品。（区食药监局负责）

三、排查整治时间与步骤

大排查大整治行动分为三个阶段，从2017年6月上旬开始，至2017年12月中旬结束。

（一）全面排查阶段（6月上旬-7月下旬）。各乡镇办场和有关职能部门要按照排查整治内容全面进行排查，摸清食品药品生产经营安全隐患底数及情况。向食品药品生产经营者宣传排查整治工作的内容，督促企业严格落实主体责任，认真执行自查制度，主动进行自查自纠，形成自查报告，并及时向市、区监管部门上报自查自纠情况。

（二）集中排查整治阶段（8月上旬-11月中旬）。各乡镇办场和有关职能部门要对排查出来的安全隐患，全面进行整治，督促制定切实可行的整改措施进行全面整改，对未进行整改和涉嫌违法犯罪的依法予以查处。

（三）总结提高阶段（11月下旬-12月中旬）。各乡镇办场和有关职能部门要对重点区域和企业隐患整改落实情况进行“回头看”，对已责令停产整顿、关闭取缔的生产经营者逐一复查。全面总结大排查大整治工作情况，研究制定强化食品药品监管长效机制和措施，巩固和扩大大排查大整治工作成果。

四、工作要求

（一）强化责任落实。各乡镇办场和有关职能部门要结合实际制定实施方案，细化责任分工、明确工作要求、落实监管责任。各相关部门要加强沟通协作，建立健全信息通报、定期会商和联查联动机制，形成齐抓共管工作合力，确保各项工作任务落到实处。

（二）强化工作措施。实行拉网式排查，结合安全生产和消防隐患排查，全面排查全区食品、药品、医疗器械生产经营企业。组织飞行检查，以“双随机、一公开”为导向，随机抽取检查员在全区范围内就食品药品重点领域开展飞行检查。实行每周公告制度，加大信息公开力度，常态化公开生产经营者行政许可、行政处罚和信用等级信息，权威发布监督检查信息。每周公告监督抽检信息，实行抽检结果、不合格产品处置“双公开”，倒逼生产经营者落实主体责任。加大曝光力度，畅通投诉举报渠道，充分发挥群众的监督作用；邀请人大代表、政协委员进企业、进厨房进行监督；对存在问题拒不整改的单位加大曝光力度；宣传排查整治行动成果，震慑违法犯罪分子。

（三）严格纪律要求。各乡镇办场和有关职能部门要规范监督检查工作程序，加强检查人员培训和管理，对在监督检查中发现的问题原料和问题产品，要及时送检。涉及敏感信息的，及时上报区食品药品安全委员会办公室，不得擅自对外公布有关结果。发现区域性、行业性质量安全隐患或重大食品药品安全问题的，要及时依法处置并报告区食药监局和区政府，通报相关部门。

（四）强化督导检查。大排查大整治期间，各有关职能部门成立督查组，采取现场督导、明查暗访、交叉检查、召开群众座谈会等形式，适时组织抽查，定期通报各地各部门工作进展情况，对排查整治数据造假和问题突出且排查整治效果不佳、上报不及时的单位进行通报批评。各乡镇办场和有关职能部门每个月上报一次排查整治工作进展情况（见附件），12月5日前向咸安区食品药品安全委员会办公室报送全年排查整治工作总结和《咸安区食品药品安全大排查大整治情况统计表》。
