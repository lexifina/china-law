# 区人民政府办公室关于成立咸安区退役士兵安置和权益保障工作领导小组的通知

咸安政办发〔2017〕47号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

为切实加强我区退役士兵安置和权益保障工作的组织领导、统筹协调和推动落实，经区政府研究，决定成立咸安区退役士兵安置和权益保障工作领导小组。现将成员名单通知如下：

组 长：郑奇明 区委常委、常务副区长

领导小组办公室设在区民政局，王小桥同志兼任办公室主任，负责日常工作。领导小组成员因工作变动需要调整的，由所在单位向领导小组办公室提出，按程序报领导小组组长批准。

领导小组下设工作专班，成员由区编办、区民政局、区财政局、区人社局、区住建局、区教育局，区国资局相关股室负责同志组成。
