# 区人民政府办公室关于公布咸安区区级随机抽查事项清单的通知

咸安政办发〔2017〕51号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁向阳湖现代农业科技示范区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

根据《国务院办公厅关于推广随机抽查规范事中事后监管的通知》（国办发﹝2015﹞58号）和《省政府办公厅关于印发全面推行“双随机、一公开”监管工作的通知》（鄂政办发〔2016〕77号）精神，区政府办组织有关部门对区政府各部门随机抽查事项进行清理，形成了《咸安区区级随机抽查事项清单》，已经区政府常务会议审议通过，现予公布。

各部门要按照《区人民政府办公室关于印发咸安区建立双随机抽查机制加强事中事后监管实施方案的通知》（咸安政办发〔2016〕57号）要求，认真组织实施，切实做好“双随机、一公开”工作。要加强事中事后监管，规范市场执法行为，强化抽查结果运用，推动信息互通共享，提升监管的公平性、规范性和有效性，着力营造公平竞争的市场环境和法治化、便利化的营商环境，更好激发市场活力。区审改办、区政府法制办要加强业务指导，建立动态调整机制，根据法律法规规章修订情况和工作实际对清单进行调整，及时向社会公布。
