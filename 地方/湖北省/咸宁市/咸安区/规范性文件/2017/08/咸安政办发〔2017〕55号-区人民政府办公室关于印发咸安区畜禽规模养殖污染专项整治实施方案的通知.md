# 区人民政府办公室关于印发咸安区畜禽规模养殖污染专项整治实施方案的通知

咸安政办发〔2017〕55号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

《咸安区畜禽规模养殖污染专项整治实施方案》已经区政府常务会议审议通过，现印发给你们，请认真组织实施。

咸安区人民政府办公室

2017年8月15日

咸安区畜禽规模养殖污染

专项整治实施方案

为深入推进畜禽养殖禁养区综合整治，切实保护和改善我区城乡生态环境，根据《中华人民共和国畜牧法》、《中华人民共和国水污染防治法》、《畜禽规模养殖污染防治条例》、《生态文明示范区创建工作方案》等文件精神，结合《咸安区畜禽养殖区域划分方案》和我区畜禽养殖实际，特制定本方案。

一、指导思想

按照“稳定总量，调整结构，保护环境，提高效益”的总体要求，以保障水环境安全和促进畜牧业持续健康发展为目标，坚持生产与生态兼顾、治旧与控新结合，综合运用政策引导和行政执法等手段，调整优化畜禽生产布局，突出重点区域、重点流域环境保护，全面推进禁养区制度落实，建立长效监管机制。

二、整治目标

（一）禁养区整治目标

2017年10月31日前，禁养区内按照《畜禽养殖禁养区划分指南》规定必须关停拆迁的养殖场全部自行关停、转产或搬迁；2017年11月30日前，禁养区内按照《畜禽养殖禁养区划分指南》规定要求建立“零排放”设施的养殖场全部整改升级达标。加强对禁养区的巡查和监管，严防禁养区内出现畜禽养殖“反弹”和“复养”现象。

（二）限养区整治目标

控制养殖规模，不得新建和扩建各类畜禽养殖场（小区），现有畜禽养殖场（小区）必须符合《畜禽规模养殖污染防治条例》要求，2017年11月30日前建设完善配套污染治理设施，达到“雨污分离和零排放”的治理标准，5000头以上规模养殖场必须取得环评报告书批复件，5000头养殖场要进行登记备案。2017年11月底前没有建设完善配套污染治理设施并取得环评手续的，自行关停、转产或搬迁，否则2017年底前一律依法予以强制拆除。

（三）适养区整治目标

在畜禽规模养殖污染综合治理期间，不得新建规模养殖场，全区整治任务完成后，新建、改建和扩建畜禽养殖场（小区）应符合规划要求，执行环境影响评价和“三同时”制度。现有畜禽养殖场必须在2017年12月31日前取得环评手续，落实污染防治措施，排放的污染物必须符合《畜禽养殖业污染物排放标准》要求。

三、整治原则

（一）依法整治，以人为本。加大法制宣传和政策引导力度，引导禁养区内养殖场（小区）和养殖专业户转产、关停、搬迁或配套“零排放”环保设施，鼓励扶持发展生态高效养殖。对违法抗拒、阻挠专项整治的，依法强制执行，严肃查处。

（二）全面清理，突出重点。禁养区内的畜禽养殖场（小区）和养殖专业户要严格按照《畜禽养殖禁养区划分指南》的要求关停和整治到位；对限养区内的养殖场（小区）严格控制新建，对现存的养殖场进行全面提档升级，落实“零排放”措施；对适养区内的养殖场（小区）引导其科学规划，集中建设，综合治理，提档增效。

（三）属地管理，联合整治。各乡镇政府要切实履行属地管理职责，具体负责各自辖区内专项整治工作的组织实施，畜牧兽医、环保等相关职能部门要结合单位职责，从技术和政策法规层面提供支持，全力落实好相关工作。

四、工作措施

（一）加强组织领导。畜禽养殖禁养区专项整治工作时间紧、任务重、涉及面广，为切实加强专项整治工作的组织领导，成立咸安区畜禽养殖禁养区专项整治工作领导小组（详见附件），负责对专项整治工作的统一组织领导，制定专项整治工作目标和具体任务，完善工作制度，督促各乡镇、部门有序推进专项整治工作。各乡镇办也要成立相应的工作机构，并报区畜禽养殖污染防治工作领导小组办公室备案。

（二）明确工作职责

区畜牧兽医局牵头咸安区畜禽养殖专项整治工作，负责督促禁养区内规模养殖场的关停、搬迁、转产，为畜禽养殖场（小区）和养殖专业户搬迁转产提供技术指导和服务，结合区环保部门制订畜禽粪污治理和升级达标方案，负责指导限养区、可养区规模养殖场粪污处理设施改造提升工作。

区环保局负责畜禽养殖污染防治的统一监督管理，依法对养殖场的环境影响评价文件进行审批和备案；对异地搬迁的畜禽养殖场要充分考虑环境容量，执行“三同时”制度；负责督促、指导畜禽养殖场落实污染防治措施，达到“雨污分离和零排放”；对各类养殖环节的环境违法行为及时查处。

区财政局负责筹措和安排畜禽养殖污染专项整治工作相关经费。

区国土局负责对占用基本农田的畜禽养殖场（小区）和养殖专业户进行违法处罚。

区城管执法局负责对城区和乡镇城镇规划区内违法搭建的养殖场（小区）和养殖专业户实施整治、拆除。

区委宣传部负责整治行动的宣传报道，营造舆论氛围，引导养殖场、户自觉配合整治行动。

区公安局负责查处专项整治过程中暴力抗法等违法行为，保障执法行为安全开展。

供电、供水部门负责对拒不执行关停转迁的养殖场（小区）和养殖专业户采取断水断电措施。

区水利局负责提供一级饮水水库保护区红线图，指导乡镇识别禁养区范围。

区旅游局负责提供国家风景名胜区地图，指导乡镇识别禁养区内风景名胜区的核心区和缓冲区。

各乡镇政府负责排查辖区内畜禽养殖品种、规模以及畜禽养殖废弃物的产生、排放和综合利用等情况，定期报区畜禽养殖污染专项整治领导小组办公室；负责组织各自辖区内畜禽养殖禁养区养殖场（户）拆除关停和限养区、适养区专项整治达标工作；负责养殖场、户专项整治落实情况的日常巡查。

为及时了解和掌握各乡镇办场专项整治进展情况，区领导小组办公室将组成督促巡查组，定期或不定期对各乡镇办场专项整治情况进行跟踪督查。各乡镇办场也要认真巡查，防止死灰复燃，对于“反弹”和“复养”现象，发现一个、清查一个。对整治不到位，措施不落实，在规定时间内没有完成整治目标任务的乡镇办场将全区通报批评并限期整改，严重的将追究相关人员及领导责任。

（三）坚持属地管理。按照“谁污染、谁治理”原则，认真落实属地管理责任制。各乡镇政府是畜禽养殖禁养区专项整治工作直接责任单位，政府主要负责人是第一责任人。各乡镇政府要结合实际制订专项整治方案，细化程序、落实人员、明确责任、制定措施，充分发挥乡镇、村基层基础作用，切实把整治任务落实到村、到户。

（四）加大执法力度。全面加强执法监管，将畜禽养殖污染防治纳入日常执法监管范围。对禁养区内拒不执行搬迁或建立“零排放”设施的依法处罚，对环境造成重大污染事故的，移送司法机关处理。对适养区、限养区内污染治理不到位的，环保部门依法责令其限期整改，对拒不开展污染防治的依法实施行政处罚。严格落实环境影响评价制度，环保部门要认真按照《建设项目环境影响评价分类管理名录》的要求，指导和督促新建、改扩建养殖场依法开展环境影响评价，凡新建畜禽规模养殖场必须严格遵循“先批后建”的原则获得所在地乡镇政府、环保、国土和畜牧部门同步审批后方可开工建设。未经相关部门审批私自开工建设的一律依法实施行政处罚，涉及环保敏感区域的强制拆除并不予补偿。

（五）强化资金保障。区政府每年安排一定的财政专项资金用于畜禽规模养殖污染治理防治，区乡两级政府对禁养区内自行按期关停拆迁的养殖场（户）给予奖补，畜禽养殖污染防治工作经费列入区级财政预算。本着“谁投入、谁受益”的原则，鼓励和引导社会力量参与畜禽养殖粪污治理和综合利用设施的投资、建设和运营，建立企业、政府、社会多元化投入和利益分享机制。鼓励和支持小型养殖场实行农牧一体化生产，发展种养结合的生态养殖。区环保、畜牧、农业、发改等相关部门要积极争取项目资金支持畜禽养殖污染治理。

五、工作步骤

（一）调查摸底阶段（2017年2月12日-2017年3月12日）

各乡镇政府按《咸安区畜禽养殖区域划分方案》要求，绘制辖区养殖区域分布图，对辖区内畜禽养殖场进行调查摸底，填报规模养殖场基本信息摸底表和禁养区养殖场调查汇总表，加盖乡镇政府公章后报区畜禽养殖污染专项整治工作领导小组办公室。

（二）宣传发动阶段（2017年3月13日-2017年3月31日）

召开全区畜禽养殖禁养区专项整治行动工作会议，印发《咸安区畜禽规模养殖污染专项整治实施方案》，统一部署专项整治行动。充分利用电视、广播、网络等宣传媒介，通过召开座谈会、印发资料、张贴标语和公告、悬挂横幅等形式，多途径、多渠道宣传国家环保相关法律法规，使广大干部群众特别是畜禽养殖场、户充分认识开展畜禽养殖禁养区专项整治工作的重要性；及时宣传专项整治工作中的先进典型和经验，适时曝光一批反面典型，为全区畜禽养殖污染专项整治工作营造良好舆论氛围。

（三）综合整治阶段（2017年4月1日-2017年10月30日）

根据调查摸底情况，各乡镇政府确定搬迁、关闭或转产的畜禽养殖场名单，联合环保局下达限期搬迁、转产通知书，畜禽养殖场按照通知要求停止养殖并自行拆迁的，区乡两级政府根据养殖场基础设施和建场时间等具体情况，结合评估机构意见给予一定的奖励；对禁养区内到期拒不自行搬迁、转产的养殖场，由区畜禽养殖污染专项整治工作领导小组办公室下达责令关停通知书。到期仍不关停的，由区政府组织环保、公安、国土、畜牧兽医等相关部门和乡镇政府依法实施强制拆除。对禁养区外的养殖场，区环保、畜牧部门督促其建设完善配套治污设施，取得环评手续，到期未能完成的，自行拆除，否则依法实施强制拆除。各乡镇政府对于搬迁的养殖场优先在适养区内安排用地，按照土地管理法律法规的规定，科学选址，简化手续，统筹安排。

（四）总结验收阶段（2017年11月1日-2017年12月31日）

区政府将认真总结畜禽禁养区专项整治行动工作情况，各乡镇政府也要对专项整治工作进行总结，总结材料以书面形式上报区畜禽养殖污染专项整治工作领导小组办公室，由领导小组办公室负责对畜禽养殖污染专项整治行动完成情况进行总结验收，确保整治工作取得实效。
