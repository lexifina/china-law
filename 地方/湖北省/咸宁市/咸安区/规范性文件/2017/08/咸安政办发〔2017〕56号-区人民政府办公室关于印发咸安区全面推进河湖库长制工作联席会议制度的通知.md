# 区人民政府办公室关于印发咸安区全面推进河湖库长制工作联席会议制度的通知

咸安政办发〔2017〕56号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

《咸安区全面推进河湖库长制工作联席会议制度》已经区政府常务会议研究同意，现印发给你们，请认真遵照执行。

咸安区人民政府办公室

2017年8月16日

咸安区全面推进河湖库长制

工作联席会议制度

为切实加强对我区全面推进河湖库长制工作的组织领导和统筹协调，压实工作责任，稳步推进“河湖库长制”各项工作落实，根据《区委办公室、区政府办公室印发〈关于全面推行河湖库长制的实施意见〉的通知》（咸安办发〔2017〕22号）要求，建立咸安区全面推进河湖库长制工作联席会议制度（以下简称联席会议）。

一、主要职责

（一）研究贯彻落实中办、国办《关于全面推行河长制的意见》、《省委办公厅、省政府办公厅印发<关于全面推行河湖长制的实施意见>的通知》（鄂办文〔2017〕3号）和《市委办公室、市政府办公室印发〈关于全面推行河湖库长制的实施意见〉的通知》（咸办文〔2017〕8号）在我区实施的相关措施，为区委、区政府决策提供意见和建议。

（二）制定我区全面推行河湖库长制的实施意见、行动方案、相关制度和考核办法等。

（三）拟定区委、区政府领导担任河湖库长的方案；研究制定区级河湖库长相应河湖库的治理和保护方案。

（四）指导和督促各地开展河湖库长制工作，建立河湖库长制体系，完成相关工作目标。

（五）加强全区推行河湖库长制工作的统筹协调，落实各成员单位有关“河湖库长制”工作职责，及时掌握工作动态，通报工作情况，研究解决重点难点问题，拟定相关政策和措施。

（六）定期对全区区级河湖库长制工作进行考核和通报。

（七）及时向区委、区政府报告全面推行河湖库长制工作的重大问题；承办区委、区政府交办的其他工作事项。

二、成员单位

联席会议由区政府分管副区长担任召集人，区政府办分管副主任和区水利局、区环保局主要负责同志担任副召集人，区委宣传部、区编办、区发改局、区经信局、区公安局、区财政局、区国土局、区环保局、区住建局、区交通运输局、区水利局、区农业局、区卫计局、区林业局、区旅游局、区畜牧局、区水产局、区规划分局有关负责同志为联席会议成员（名单附后）。区水利局、区环保局为牵头单位。

联席会议的日常工作由区级河湖库长制办公室承担。区级河湖库长制办公室设在区水利局，办公室主任由区水利局主要负责同志兼任。

联席会议设联络员，由各成员单位有关科室或单位负责同志担任，负责联席会议日常联络工作及处理相关事宜。

联席会议成员因工作变动需要调整的，由所在单位提出，联席会议确认。

三、工作规则

（一）联席会议原则上每年召开1至2次全体会议，由召集人或副召集人主持。

（二）根据区委、区政府领导指示，成员单位建议或工作需要，可临时召开全体会议、部分成员单位会议。

（三）联席会议召开之前，可召开联络员会议，研究讨论联席会议议题和需要提交会议议定的事项。

（四）联席会议以纪要形式明确会议议定事项，经与会单位同意后印发，重大事项及时报区委、区政府。

四、工作要求

各成员单位要按照全面推行河湖库长制工作的总体要求和部署，切实履行职责，积极参加联席会议，主动研究河湖库长制工作，认真落实联席会议议定事项。要加强沟通，密切配合，相互支持，形成合力，充分发挥联席会议作用，形成高效运行的长效工作机制。

区级河湖库长制办公室要及时向联席会议成员单位通报有关情况，督促落实会议议定事项。
