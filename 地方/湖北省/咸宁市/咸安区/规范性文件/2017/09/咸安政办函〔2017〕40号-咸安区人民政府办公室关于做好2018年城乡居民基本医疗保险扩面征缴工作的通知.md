# 咸安区人民政府办公室关于做好2018年城乡居民基本医疗保险扩面征缴工作的通知

咸安政办函〔2017〕40号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁向阳湖现代农业科技示范区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

为巩固我区城乡居民基本医疗保险（以下简称“居民医保”）发展成果，进一步做好基金征缴与管理，推进我区居民医保工作取得实效，根据《市人民政府办公室关于印发咸宁市城乡居民基本医疗保险实施办法的通知》（咸政办发〔2017〕35号）精神，现将我区2018年城乡居民基本医疗保险扩面征缴工作有关事项通知如下：

一、缴费对象及标准

（一）缴费对象。除职工基本医疗保险应参保人员以外的其他所有城乡居民，均纳入城乡居民医保参保登记覆盖范围，不受户籍限制。城乡居民不能同时办理职工基本医疗保险和城乡居民医保参保登记。

（二）缴费标准。2018年城乡居民基本医疗保险个人缴费标准统一为180元。

参保实行年缴费制，一般居民原则上以家庭为单位参保。按规定享受资助政策的困难人员，参加城乡居民医保所需个人缴费资金，由相应的职能部门负责落实。

二、征缴方式及步骤

即日起启动，2017年11月底前全面完成我区城乡居民医保基金收缴及相关信息上机工作。

（一）率先启动学生的医保征缴工作（2017年9月1日-9月30日）。为避免学生重复参保，在全面启动我区2018年城乡居民医保保费征缴工作前，在校学生、在园（所）幼儿以学校（园、所）为单位集中统一参保登记缴费,由区教育局负责牵头，督促所属学校（幼儿园）落实好学生（幼儿）参保登记缴费工作，确保在规定时间内完成集中参保征缴任务。

（二）全面启动城乡居民的医保征缴工作（2017年10月1日-11月30日）。城镇居民以社区为单位由所在社区负责办理居民个人参保登记和缴费手续，农村居民以家庭为单位由所在村负责办理居民个人参保登记和缴费手续。各乡镇办要承担扩面征缴主体责任，结合各自实际，全面启动2018年城乡居民医保征缴工作，切实把组织参保缴费的责任落到村、社区，把资助参保责任落实到有关部门，确保在规定时间内完成征缴工作任务。

（三）做好划转人员的医保征缴衔接工作（2017年10月1日-11月30日）。温泉办事处、浮山办事处划转的有关人员由区人社局、区地税局负责与市人社局、市地税局沟通衔接，做好2018年保费征缴及待遇接续经办管理工作。

三、相关要求

（一）强化组织领导，分解工作任务。2018年参保缴费工作时间紧、任务重，各乡镇办、各相关单位要高度重视，迅速成立城乡居民医疗保险基金征收工作领导小组，要把征缴工作作为一项重要工作来抓，认真研究，及早启动。各乡镇办要明确工作任务，制定有效措施，周密部署、精心组织，狠抓落实，勤于督办，切实把参保任务分解到村、社区，扎实推进征缴工作。各相关单位要积极配合，密切协作，做好信息核对和确认工作，确保我区2018年征缴工作如期顺利完成。

（二）丰富宣传手段，广泛发展动员。各乡镇办、各相关单位要采取多种宣传形式和手段，切实把征缴工作的意义讲透、政策讲准、内容讲清，加大宣传力度，让广大城乡居民进一步深入了解参保的益处，努力做到早参保、不断保。

（三）重视协调配合，确保信息完整。各乡镇办、各有关部门要严格履行各自的工作职责，加强沟通配合，进一步完善基础信息的收集和登记，确保有关信息完整、真实、准确。

区教育局负责督促所属学校（幼儿园），以学校（幼儿园）为单位集中统一参保登记缴费工作。

区民政局负责认定困难对象，落实特困供养人员、孤儿、最低生活保障家庭成员等困难群众参保个人缴费资助政策，做好医疗救助工作，加强医疗救助与城乡居民医保、大病保险的有效衔接。

区卫计局负责认定严重精神障碍患者、计划生育特殊困难家庭中经核定的特困家庭夫妻及其伤残子女的身份，落实其参保个人缴费资助和特殊待遇补助政策，做好疾病应急救助工作。

区扶贫办负责认定精准扶贫建档立卡贫困人口的身份，落实其参保个人缴费及补充医疗保险人员资助政策，向区人社局、民政局提供精准扶贫建档立卡贫困人口的动态变化基础信息。

区残联组织负责做好丧失劳动能力残疾人的身份确认工作，落实其参保个人缴费资助政策。

区地税局统一负责城乡居民医保个人缴费征收工作，确保核定数据应收尽收。

区人社局负责城乡居民医保的综合管理、政策制定和经办服务工作。

区财政局负责执行基金财务管理制度和会计制度，落实财政补助政策和城乡居民医保工作经费。
