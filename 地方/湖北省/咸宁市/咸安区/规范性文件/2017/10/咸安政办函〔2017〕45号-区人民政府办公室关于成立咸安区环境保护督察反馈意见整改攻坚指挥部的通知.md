# 区人民政府办公室关于成立咸安区环境保护督察反馈意见整改攻坚指挥部的通知

咸安政办函〔2017〕45号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁向阳湖现代农业科技示范区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

为深入推进中央第三环境保护督察组反馈意见的整改落实，做到“精准交办、细化责任、属地负责、限期交账，”坚决打赢督察整改攻坚战，区人民政府决定成立咸安区环境保护督察反馈意见整改攻坚指挥部（以下简称“指挥部”）。现将成员名单通知如下：

指挥部在区环境保护督察反馈意见整改工作领导小组的领导下开展工作，负责督察整改攻坚工作的协调推进，狠抓重点、主攻难点、疏通堵点，统筹推进疑难问题的解决；负责细化整改责任清单，进一步明确整改责任人和完成时限；每月召开督察整改攻坚交账会，持续传导整改压力等。

指挥部下设办公室，办公室主任由区环保局局长陈涛兼任，副主任由区环保局主任科员周常前兼任，工作人员从区环保局等有关单位抽调，负责指挥部日常工作，实行集中办公，统一调度。区委督查室、区政府督查室负责中央环保督察反馈意见整改攻坚工作的日常督查。
