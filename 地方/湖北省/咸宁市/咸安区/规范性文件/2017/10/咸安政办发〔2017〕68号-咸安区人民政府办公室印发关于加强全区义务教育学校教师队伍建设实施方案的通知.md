# 咸安区人民政府办公室印发关于加强全区义务教育学校教师队伍建设实施方案的通知

咸安政办发〔2017〕68号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

《关于加强全区义务教育学校教师队伍建设实施方案》经区政府常务会议审议通过，现印发给你们，请认真组织实施。

咸安区人民政府办公室

2017年10月25日

关于加强全区义务教育学校

教师队伍建设实施方案

根据《省人民政府办公厅关于加强全省乡村教师队伍建设实施办法的通知》（鄂政办发〔2015〕68号）、《省人民政府关于统筹推进县域内城乡义务教育一体化改革发展的实施意见》（鄂政发〔2017〕18号）及《市人民政府办公室印发关于加强全市乡村教师队伍建设实施细则的通知》（咸政办发〔2016〕46号）等文件要求，结合我区实际，特制定本实施方案。

一、加强师德师风建设

（一）加强全区义务教育学校基层党组织建设。在乡镇办中心小学及以上学校完善党组织机构，配备专（兼）职党务干部，加大在全区义务教育学校教师中发展党员的力度。加强教师社会主义核心价值观教育，充分发挥义务教育学校基层党组织战斗堡垒和基层党员先锋模范作用。鼓励支持创作展现新时期优秀教师形象的文学影视作品。

（二）引导教师加强职业修养，模范践行教师职业道德规范。把教师职业理想、职业道德、学术规范以及心理健康教育融入职前培训、准入、职后培训和管理的全过程。严格按照《中小学教师职业道德规范》的要求，以爱国守法、爱岗敬业、关爱学生、教书育人、为人师表和终身学习为重点，持续开展形式多样的校风、教风教育和师德教育活动。树立和宣传教师群体中的先进典型，引导教师加强职业修养，模范践行教师职业道德规范。

（三）建立师德师风建设问责机制。认真贯彻《中小学教师违反职业道德行为处理办法》，严禁公办、在职中小学教师从事有偿补课，严禁体罚或变相体罚学生等违规行为。对教师严重违反师德行为监管不力、拒不处分、拖延处分或推诿隐瞒，造成不良影响或严重后果的，追究学校和教育主管部门主要负责人的责任，并给予相应处分；情节严重的依据《事业单位工作人员处分暂行规定》（人力资源和社会保障部令第18号），给予记过、撤销专业技术职务或者行政职务、开除处分。

（四）严格执行师德考核制度。制定考核办法，加强师德考核，建立师德档案。强化师德考核结果运用，在评选特级教师、优秀教师、骨干教师，晋升教师职务，教师资格定期注册时，实行师德“一票否决”，逐步树立科学合理的教师综合评价导向。

（五）加强师德师风行为的社会监督。建立健全师德年度评议、师德状况定期调查分析等制度。各学校要建立家长委员会或聘请社会监督员制度，构建学校、教师、学生、家长和社会广泛参与的师德监督体系。

二、健全义务教育教师补充机制

（一）贯彻落实好省级新机制教师和农村义务教育学校教师补充制度。农村义务教育学校新进教师，落实省级统筹的乡村义务教育学校教师补充机制，落实“国标、省考、县管、校用”制度，按照“总量平衡、退一补一”原则，由区教育局根据当年教师退休和编制空缺情况，会同区编办提出初步招聘计划，在报经区政府审批后，报省编办核准招录数量，由省教育厅统一组织笔试，区教育局在区公务员局指导下统一组织面试，区纪检监察部门负责监督。区招教师（如农村教学点教师、新建扩建学校补充教师等）按省定原则，实行“一事一议”，在报区人民政府同意后，参照省招模式进行招聘补充。实施教师补充过程中，要严格招聘程序，严明选人标准和纪律，严把教师“入口关”。

（二）建立全区义务教育学校教师调配制度。按照“城区义务教育学校间教师调配、乡镇义务教育学校间教师调配、城区义务教育学校到农村义务教育学校下派支教、农村义务教育学校到城区义务教育学校上派学习和农村义务教育学校调动到城区义务教育学校”等五种调配类别，区教育局每学年末依据新学期生源变化情况、教师自然减员情况初核各学校学科教师需求，并会同区编办提出年度教师岗位调配计划，报区政府审批后执行。农村义务教育学校调动到城区义务教育学校采取区级考试方式实施，由区教育局组织，区公务员局参与指导，区纪委监察局全程监督。

（三）建立教师岗位能进能出制度。全面贯彻落实教师资格定期注册制度，对不能通过教师资格定期注册的教师，给予一年待岗学习期，由教育行政部门组织学习培训，仍不能通过资格注册的，按规定予以解聘。同时，对长期因病不能从事教学工作岗位且无法从事其他教育工作的或即将到龄退休且身体条件较差的教师，应鼓励其办理相关手续，退出编制，并按规定执行相关待遇。

三、加大义务教育学校教师培训力度

（一）建立教师培训经费投入保障机制。根据省政府教师全员培训统筹规划，区政府履行实施主体责任，按义务教育学校公用经费5%列支培训费，保障义务教育学校教师培训经费投入。

（二）加强培训管理，建立完善教师培训证书制度、学分管理制度。到2020年前，完成对全区教师、校长360学时的全员培训。推行教师培训学分登记制度，并与教师资格定期注册等挂钩。

（三）创新培训模式，提高培训质量。深入实施中小学教师“国培计划”、“省培计划”、“区培计划”。整合“乡村紧缺学科教师培训”、“名师送教下乡”、“乡村教师访名校”、“优秀教师出国（境）培训”等项目，着力支持乡村教师提升学科教学能力，培养教学名师。加大农村教师特别是音乐、体育、美术等师资紧缺学科教师培训力度，普遍开展中小学教师信息技术应用能力提升培训。鼓励义务教育学校教师参加在职教育硕士学历提高培训，学费由教师培训经费、学校公用经费和教师个人各承担1/3。

（四）加强教师培训基地建设。建好区中小学教师继续教育培训中心，加强教师培训团队建设。整合区级教师培训资源，加大区外和区内培训统筹力度，实施乡村教师区域内培训、校本研修等。

（五）建立教师下派支教学时奖励机制。城区义务教育学校教师下派农村学校支教，每学年奖励10个培训学时，被通报表彰的另奖励10学时。

（六）探索建立乡村全科教师培养模式。区政府强化与师范院校的合作，根据我区乡村教育实际加强定向培养，重点为村小学和教学点培养全科教师。新入职的非师范专业毕业生和初小、教学点教师，入职前必须参加10-15天的全科教学业务能力培训。

四、提高乡村教师生活待遇

（一）实施乡镇教师工作补贴制度。区教育局按办学条件、交通状况、艰苦程度等情况，合理合规发放乡镇工作补贴。

（二）加快乡村教师周转房建设。将符合条件的乡村教师住房纳入当地住房保障范围，积极整合各级资金补助，增加教师周转房补助经费，切实改善乡村教师住房条件。

（三）提高农村教师生活待遇。农村小学特别是初小、教学点，要积极创造条件（如与学生搭伙、教师拼餐等），为教师提供中餐；各乡镇要积极探索实施乡村教师走教机制，为挂点完小教师走教、联教或特别偏远的初小、教学点教师集中住宿、生活提供方便。

五、拓宽义务教育学校教师专业成长渠道

（一）完善中小学教师专业技术水平评价标准和办法。对乡镇及以下农村学校教师在高级、中级岗位设置上给予适度的政策倾斜。专业技术中高级岗位设置要向乡村学校倾斜，城乡学校教师岗位结构比例要保持总体平衡。

（二）完善中小学教师评选表彰机制。继续做好全国、全省、全市、全区优秀教师和教育系统先进工作者推荐表彰工作，定期开展特级教师、教学名师和教学成果奖评选活动，重点向在农村地区长期从教、贡献突出的教师倾斜。在特级教师、“名师工作室”等评审和遴选工作中，将乡村教师进行单列；对长期坚持在农村边远地区教育一线从教，并作出突出贡献的各类优秀教师、优秀校长参加区级评优直接予以表彰奖励。

（三）规范乡村教师专业技术职务评聘标准。坚持“重师德、重师能、重奉献”的原则，制定符合乡村教师特点的评价标准，不作外语成绩、发表论文等硬性要求，也不要求乡村教师参加全省统一组织的专业水平能力测试。

六、建立义务教育学校教师奖扶机制

（一）切实做好“楚天园丁奖”及咸安“最美乡村教师”的评选表彰和跟踪管理。对在教育教学岗位上做出突出贡献的中小学专任教师予以表彰，重点向基层一线教师倾斜，其中乡村教师比例不低于30%。

（二）建立农村教师教龄津贴奖补机制。对在一、二类乡村学校连续任教达30年、20年、10年以上的教师，区级给予表彰和奖励。

（三）关爱教师身心健康。建立农村教师大病救助机制，设立“咸安区乡村教师关爱基金”，对大病、特困教师提供援助；关注教师心理健康，区直义务教育学校及乡镇办中心学校要建立教师心理健康教育机构，为教师提供相关咨询服务。

（四）建立优秀教师奖励基金。完善区级优秀教师评选表彰制度，建立咸安区名师工作室和省、市、区级名师或学科带头人等优秀师资库，并给予适当奖励。

七、加强城乡教师编制管理

（一）建立健全编制动态管理机制。落实《省编办 省教育厅 省财政厅转发<中编办 教育部 财政部关于统一城乡中小学教职工编制标准的通知>》（鄂编办发〔2016〕22号）精神，按照生师比、班师比和教学工作量相结合的方式核定全区义务教育学校教职工编制。区教育局要定期会同区编制办根据当地生源数量变化、学校布局调整以及深化教育教学改革需求等情况，核定编制总量，实行动态管理。

（二）完善中小学教职工编制总量内按需动态调整机制。进一步完善“以区为主”的教师管理体制，区编办、区公务员局对全区义务教育学校教职工编制管理、岗位设置按事业单位有关政策执行。区教育局在核定编制总量内，每学年根据班额、生源等变化情况，统筹使用、适时动态调整所属学校教职工编制并报区编办备案，盘活编制资源，促进校际间师资均衡配置，从而实现教师“无校籍”管理，让教师从“单位人”向“系统人”转变。

（三）优化农村寄宿制学校和村小、教学点教师配备。适当考虑农村寄宿制学校特殊岗位师资配备，村小学、教学点编制根据实际需要，由区编办按照生师比和班师比、教学量相结合的方式核定，配备齐全，确保开足开齐课程。

（四）规范使用教师编制。加强教师编制使用管理，严禁在有合格教师来源的情况下“有编不补”、长期使用临聘人员；严禁任何部门和单位以任何理由、任何形式占用或变相占用乡村中小学教职工编制。

八、推动城乡教师交流

（一）建立健全城乡教师轮岗交流机制。推进义务教育教师队伍“县管校聘”管理体制改革，区教育局应按照“政策引导、因地制宜、稳步推进”的原则，建立健全教师交流轮岗制度。城区学校之间、乡镇学校之间教师每学年交流人数不低于20人。城镇学校、优质学校与农村学校间每学年教师交流轮岗的比例不低于符合交流条件教师总数的10%，其中骨干教师交流轮岗应不低于交流总数的20%。城区学校新进教师必须先在农村学校任教5年以上，乡镇之间、城区之间的教师二次交流必须在新岗位任教满3年。

（二）构建教师校长任期交流制度。推进城区内学校间教师和农村镇内学校间教师定期交流，重点加大骨干教师和校长的任期轮岗交流力度。教师在同一学校连续任教满6年，原则上应交流到区域内其他同学段学校。校长、副校长在同一所学校连续任满两届后，原则上应交流。校长、副校长在农村学校、薄弱学校连续任职时间可以适当予以延长。

（三）打造城乡学校及教师结对帮扶平台。区域内分层次实施城乡学校结对帮扶、支教活动，加强薄弱学校师资建设。到2020年，城乡学校间帮扶结对50个，结对学校间每年开展不少于4次的双向交流活动；区教育局每年遴选2个支教团体（4人），到农村学校支教两年。区教育局要积极探索通过托管、合作等方式建立学校共同体，推动优质师资团队化交流。

（四）建立有利于校长教师交流轮岗的激励约束机制。将交流轮岗作为校长教师聘用、考核的重要内容，与绩效工资分配、职称评审、职务晋升、评先评优挂钩，并予以倾斜。从2017年起，申报中级教师职务，必须有到农村学校、薄弱学校任教2年以上经历；申报高级教师职务和特级教师，必须有到农村学校、薄弱学校任教1年以上工作经历。在乡村学校任教3年以上（含城镇学校交流、支教教师）、聘期考核合格等次以上的教师，岗位空缺时，同等条件下优先聘用；聘用到中级以上岗位、推荐为区级以上评选表彰的教师，必须有在两所以上学校或在农村学校3年以上任教经历。发挥编制在教师配置上的基础性作用，引导和鼓励教师从超编学校向缺编学校流动，推动教师有序轮岗交流。

九、工作要求

（一）加强组织领导。区政府是强化师资队伍建设工作的责任主体，新增财政预算要把支持农村教师队伍建设作为投入重点之一。区政府成立加强义务教育教师队伍建设领导小组，区长任组长，分管教育的区委、区政府领导任副组长，区教育局、区编办、区公务员局、区财政局、区人社局、区发展改革局、区住房城乡建设局、各乡镇办党委政府等部门负责人为领导小组成员。

（二）加强沟通协调。完善部门沟通协调机制，形成责权明确、分工协作、齐抓共管的工作格局，及时研究解决教师队伍建设中的突出矛盾和重大问题。区教育局要加强对教师队伍建设的统筹规划、指导和管理，制定相关政策和标准。区编办、区公务员局、区财政局、区发改局、区人社局、区住建局等有关部门要在各自职责范围内，积极推进有关工作。

（三）加强督促检查。建立教师队伍建设专项督导制度，区政府办每年在全区开展一次督导检查，重点督导教师管理体制和教师队伍建设等工作。建立督导简报制，推动各项政策措施落实到位。
