# 咸安区人民政府办公室关于进一步规范和改进政务值守和突发事件信息报告工作的通知

咸安政办函〔2017〕60号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

为进一步规范和改进政务值守和突发事件信息报告工作，推动政务值守和信息报告工作水平不断提升，根据《中华人民共和国突发事件应对法》、《湖北省突发事件应对办法》、《省人民政府办公厅关于进一步加强和改进突发事件信息报告工作的通知》（鄂政办发〔2016〕58号）、《省人民政府办公厅关于印发全省政府系统政务值班工作规范的通知》（鄂政办发〔2016〕85号）、《市人民政府办公室关于进一步加强和改进政务值守和突发事件信息报告工作的通知》（咸政办电〔2017〕99号）等规定,经区人民政府研究同意，现将有关事项通知如下:

一、进一步规范政务值守制度

做好新形势下的政务值守工作，保障政令畅通，是有效应对各种新情况新问题、妥善处置各类突发事件、促进经济社会健康安全发展的需要。各地、各部门要充分认识政务值守工作尤其是国家法定节假日期间值守工作的重要性，把做好新形势下的政务值守工作摆到更加重要的位置，强化使命意识和责任意识，切实做到任务到岗、责任到人、管理到位。

（一）坚持24小时值班制度。各地、各部门要坚持24小时专人值班制度，不得由保卫人员代班，不得将值班电话呼叫转移，确保值班电话24小时畅通。值班人员不得迟到、早退，并掌握岗位职责和相关规定、突发事件信息报送要求，熟练操作值班室设施设备，负责当天办理事项资料的收集、整理、归档，并完整填写值班日志，对当天值班情况及重要事项做到“一口清”。各地、各部门要为值班人员配备必要的办公设备和工作环境，切实解决实际困难。

（二）落实领导同志带班制度。在国家法定节假日、重要会议活动和重特大事故应对处置等特殊时期，要落实领导同志带班制度，采取主要负责同志属地带班、负责同志单位坐班和值班员在岗值班的三级值班工作模式，各地、各部门主要负责同志是本地、本部门值班工作的第一责任人，坐班负责同志是主要责任人，值班室当班值班人员是直接责任人，杜绝无人值班或值班脱岗、离岗现象。未经带班领导同意，值班人员不得擅离岗位或私自调班代班，确保政务值守工作正常有序。

（三）执行首接首问责任制度。对上级来文来电或交办的工作，第一个承办公务的值班人员，要负责做好值班记录并跟踪办理。一时无法办结的，要与接班人员做好衔接，确保值班工作无缝对接。值班人员如遇紧急重大情况，要立即报告在岗带班领导，并做好信息汇总和综合协调工作。

二、进一步规范突发事件信息报告机制

突发事件信息报送是应急管理工作的“生命线”，也是做好应急处置工作的前提和基础。随着新媒体迅猛发展和新技术广泛应用，传统的信息获取、传递方式面临严峻挑战，极易给突发事件应对处置工作带来被动，甚至造成重大影响。各地、各部门要切实增强政治意识、大局意识、责任意识，充分认识做好新形势下信息报告工作的重要性，把突发事件信息报告工作做为有效预防和处置突发事件的重要抓手，严格落实行政一把手为第一责任人，分管领导为主要责任人，具体工作人员为直接责任人的责任。

（一）明确信息报告责任主体。根据“统一领导、综合协调、分类管理、分级负责、条块结合、属地管理为主”的应急管理体制，各乡镇办场，区政府组成部门、直属机构和单位是突发事件信息报告的责任主体，负责通过区政府应急办向区人民政府报告突发事件信息。在向党委部门报告的同时，必须同时向区政府应急办报告。

各部门对于上级部门要求报告或核实的突发事件信息，必须在对口报告的同时报告区政府应急办。

（二）提升信息报告的时效性和质量。要采取必要的授权方式，简化信息报告审批程序，减少中间环节，提高信息报告时效。各责任单位在接到突发事件信息后，按照“接报即报、随时续报”的要求，采取一切措施尽快掌握情况，力争15分钟内向区政府应急办电话报告初步情况，45分钟内书面报告（联系电话：0715-8322319；传真：0715-8322688）。对区政府应急办要求核报的信息，有关乡镇办场和部门要迅速核实，电话反馈时间一般不超过15分钟，要求书面反馈的，时间一般不超过45小时。

事发地的责任单位，首报要快，可以快报事实、慎报原因。对于敏感时间、敏感地点和敏感性质的事件，要边核实、边报告，或边处置、边报告，并及时跟踪续报，对突发事件动态情况、应急响应情况、预案执行情况、事件发展趋势、事件处置的新进展、新情况等要及时续报。对区委、区政府领导重要批示的贯彻落实情况要限时反馈。处置结束后，要及时终报，包括事件鉴定结论、处置结果、发生的确定原因和产生影响，处置工作评估和对类似事件防范处置建议等。

突发事件处置现场必须指定一名信息报告联络员，专门负责收集、报告信息。必要时，区政府应急办将建立与处置现场的连线制度，直接与现场指挥员或信息联络员连线了解情况。在事发现场指挥处置的乡镇办场及区直单位负责同志和信息联络员要保持通讯畅通，及时接听区政府应急办电话（0715-8322319），准确报告现场处置情况。

（三）拓宽信息获取渠道和创新信息传递方式。各地、各部门要进一步加强信息网点建设，建立健全信息报告员制度，特别是提升第一时间获取信息的能力，充分发挥信息报告主渠道作用。要创新方式方法，充分利用新技术、新手段，拓宽获取信息源的渠道。加强对微博、微信、网络媒体等互联网信息的监测分析，及时掌握突发事件线索和苗头性、趋势性、敏感性信息，对其中反映的重要情况及时核实，并迅速报告。要充分利用电话、传真、短信、微信、互联网、电子政务内网等手段加快信息传递速度，但涉密信息报告要严格按照相关规定执行。

三、进一步加强应急管理动态信息报送工作

各地、各部门要充分认识做好应急管理动态信息报送工作的重要性，按照市政府关于应急管理动态信息报送工作的部署要求，切实加强组织领导，规范工作程序。原则上，各乡镇办场每月报送应急管理动态信息不少于2篇，具有应急管理工作职责的部门每月报送不少于一篇，约稿信息原则上一周内上报。同时，要严格执行保密规定，稿件内容不得涉密。

报送应急管理动态信息要体现应急管理工作的广度和深度，重点围绕应急管理工作召开的重要会议、重大工作部署，制定出台的有关应急管理工作的重要规划、预案；组织开展的各类应急演练、专题调研、科普宣传和教育培训活动；在防范和处置重特大突发事件方面的典型案例、调查（调研）报告、经验教训总结；加强和改进应急管理工作的典型经验做法以及其他有关应急管理的重要工作动态等方面的内容。

各地、各部门要安排专人负责应急管理工作动态信息的报送工作，要安排政策理论水平高、政治敏锐性强、文字功底扎实的同志担负编稿工作。稿件内容要权威、及时，文字要简洁、准确。消息类稿件要篇幅宜短、精炼，总结类稿件要特点鲜明，经验典型、调查研究类稿件要观点明确、指导性强。

要建立健全稿件专报和分管负责同志审签制度，以方便交流，保障质量。报送稿件应由本单位分管负责同志审签，并注明签发人姓名、编稿人姓名和联系电话，通过电子邮件渠道，发送至区政府应急办（联系人：葛航，联系电话：0715-8322319，电子邮箱：xiananyjb@126.com）。

四、进一步加强督查与责任追究力度

各地、各部门要切实加强组织领导，对本地、本系统政务值守、突发事件信息报送、应急管理动态信息报送工作开展自查整改，重点检查政务值守制度是否健全，值班人员是否在岗，领导带班制度是否落实，突发事件和应急管理动态信息收集和报送渠道是否畅通等，对检查发现的问题，要及时整改到位。真正做到思想重视到位、制度保障到位、工作措施到位、责任落实到位。

区政府督查室、总值班室（应急办）将不定期对各乡镇办场及区直单位的政务值班和突发事件信息报告工作，特别是对国家法定节假日期间应急值守工作进行抽查。对无人值班、值班脱岗、离岗以及迟报、漏报、谎报和瞒报突发事件信息的部门予以通报批评，对造成严重后果的，将依法依规追责问责。
