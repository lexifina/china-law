# 咸安区人民政府办公室关于加快推进2017年重点工作目标任务落实的通知

咸安政办发〔2017〕75号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁向阳湖现代农业科技示范区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

为加快推进上级及区本级决策部署落地生根，推动全区经济社会发展提速、进位、增效，全力以赴完成年度目标任务，结好“硬账”。根据区政府安排部署，区政府督查室对市级对我区考核目标、市《政府工作报告》、省政府月度督查、区政府“十件实事”等重点工作目标任务进行了全面梳理，制定了责任清单，明确了责任领导、责任单位。请各乡镇办场、区直各有关单位抓好工作落实。

一、对标调焦，精准施策。当前已是11月下旬，进入完成年度各项目标任务的冲刺阶段，各乡镇办场、区直各有关单位要对照目标任务，认真细致地开展对照检查，对已完成的目标任务要进行“回头看”，对尚未完成的目标任务要查找症结、分析原因，采取有力措施补齐“短板”，力求我区各项工作有新举措、新成效、新突破，进位争先，圆满完成上级及区本级各项年度目标任务。

二、加强配合，协同推进。各乡镇办场、区直各有关单位要根据责任清单，逐一对目标任务制定切实可行的时间表、路线图；各责任领导要高度重视，对各项任务指标要亲自部署、亲自过问、亲自协调、亲自督办；各牵头单位要切实履行牵头抓总、综合协调的职责，加强与上下左右的联系协调，积极主动地开展工作；各责任单位要根据职责分工，协同推进各项工作的落实。

三、强化督办，严肃问责。区政府督查室在12月中旬将牵头组织一次全区范围的大督查活动，重点督办各乡镇办场、区直各有关单位对清单所涉及目标任务的完成情况进行通报，并作为年度综合考评和领导班子考核的重要依据，对工作进展缓慢、落实不力，推诿扯皮、弄虚作假的，区监察局将加大执纪问责力度，对相关单位及责任人严肃追责问责。
