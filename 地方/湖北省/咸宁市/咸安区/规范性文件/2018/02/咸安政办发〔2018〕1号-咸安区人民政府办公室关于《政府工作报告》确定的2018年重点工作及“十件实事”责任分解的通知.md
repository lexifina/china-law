# 咸安区人民政府办公室关于《政府工作报告》确定的2018年重点工作及“十件实事”责任分解的通知

咸安政办发〔2018〕1号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁向阳湖现代农业科技示范区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

经区政府研究同意，现将2018年《政府工作报告》确定的各项工作和十件实事责任予以细化分解。请各乡镇办场、区直各部门高度重视，迅速制定具体工作方案，进一步细化目标、强化措施、硬化责任，狠抓落实。

区政府办将适时组织力量，加强对各乡镇办场和区直各部门落实《政府工作报告》确定的重要工作责任情况的检查和督办。

咸安区人民政府办公室

2018年1月31日

《政府工作报告》2018年

重点工作责任分解

2018年，全区经济社会发展的主要预期目标是：完成地区生产总值301亿元，增长8.5%；完成固定资产投资312亿元，增长13%；规模工业增加值增长8.5%；实现社会消费品零售总额144.6亿元，增长12%；完成一般公共预算收入12.23亿元，增长10.6%；实现外贸出口7168万美元，增长12%；城镇常住居民人均可支配收入达到 33750元，增长8.5%；农村常住居民人均可支配收入达到16820元，增长9%；居民消费价格涨幅控制在3.5%以内；城镇登记失业率控制在4.5%以内；完成节能减排任务。

一、矢志不渝深化“三抓一优”，着力在扩大有效投资上展现新作为

（一）按下项目建设快捷键

1.设立项目建设及固定资产投资奖励基金，认真组织开展项目集中开工月活动，力争全年推动200个以上重点项目开工建设，80个项目建成投产。（责任单位：区项目办、区发改局、区经信局、咸安经济开发区、咸安商贸物流区、各乡镇办场）

2.在抓好基础设施、民生服务等领域投资的同时，将投资重点转向重大产业发展特别是先进制造业和新兴产业，确保工业投资占固定资产投资比重达到40%以上。（责任单位：区发改局、区经信局、咸安经济开发区、区民政局、区教育局、区水利局、区交通运输局、区招商局）

3.力争香城大道古桂段改造升级、区文体中心尽早开工建设。（责任单位：区经发集团、区交通运输局、区文体新局、浮山办事处、汀泗桥镇、官埠桥镇、向阳湖镇）

4.大力争取中央、省预算内投资，力争更多项目纳入国家、省有关规划计划，确保争资的份额稳中有升。（责任单位：区发改局、区财政局、区交通运输局、区水利局、区林业局、区农业局、区教育局、区科技局、区经信局、区民政局、区商务局、区环保局、区国土局、区旅游委、区人社局、区卫计局、区文体新局、区扶贫办、区司法局）

（二）吹响招商引资冲锋号

5.按照“产城融合”发展理念，加大文旅康养、现代物流、电子商务等现代服务业项目的引进。（责任单位：区招商局、区文体新局、区旅游委、区民政局、区交通运输局、区商务局、咸安商贸物流区）

6.加强异地商会平台建设,运用基金招商、委托招商、重资产招商等新方式，聘请一批“招商大使”“招商顾问”，广开招商信息门路。（责任单位：区招商局、区工商联）

7.提高招商质效，优化后续服务，提高项目履约率、开工率、投产率。（责任单位：区项目办、区招商局、区发改局、区经信局）

8.实行“三链”并举，围绕全产业链、城市功能链、创新创业链开展招商。瞄准“高新、集群”，加大机电制造、生物医药、模具及汽车零配件、装备制造、新材料等产业的招商力度，实现传统优势产业的“强链”和战略性新兴产业的“补链”。力争全年签约项目100个以上、开工项目80个以上，到位资金200亿元，至少引进2家投资10亿元以上工业企业。（责任单位：区项目办、区招商局、区发改局、区经信局、咸安经济开发区、各乡镇办场）

（三）筑牢实体经济硬支撑

9.拓展直接融资和间接融资两大市场，培育上市企业后备资源，协调汉口银行、武汉农商行、华夏银行等商业银行在咸安设立分行，支持咸安村镇银行在乡镇设立支行，满足企业多样化融资需求。（责任单位：区政府金融办、区财政局）

10.深化县域金融和金融创新两大工程，推动企业股份制改造，推广政银保、转期贷、项目贷、招商贷等融资产品。充分发挥贺胜金融小镇溢出效应，扎实开展基金路演活动，助力实体经济发展。（责任单位：区政府金融办、区经信局、区财政局、咸安经济开发区、贺胜桥镇）

11.发挥财政资金“四两拨千斤”撬动作用，设立绿色产业发展奖励基金，做大应急周转资金池，做强湖北咸宁凤凰投资开发有限公司，支持民营经济特别是中小微企业转型发展。（责任单位：区财政局、区经信局、区科技局、区商务局、区旅游委、区林业局、咸安经济开发区、咸安商贸物流区）

12.组织一批企业家外出培训，引进一批专业技术人才，培养一批高素质劳动者。（责任单位：区工商联、区人社局）

13.继续实施“规模企业培育、大企业培育”工程，新增规上企业15家以上。（责任单位：区经信局、区统计局、区工商局、咸安经济开发区、各乡镇办场）

14.把握民营经济发展新阶段，实施突破性发展新民营经济的政策举措，支持建设新民营经济园区和创新街区。（责任单位：区发改局、区经信局、区商务局、区工商局、咸安商贸物流区）

二、培育壮大发展新动能，着力在促进转型升级上展现新作为

（一）强力推进“一区六园”建设

15.继续加大对“一区六园”建设支持力度。支持咸安经济开发区扩园、强园、优园，力争每年建成面积1平方公里、整理土地1平方公里、储备土地1平方公里，实现与向阳湖飞地工业园互连互通。（责任单位：咸安经济开发区、区经信局、区国土局、区规划分局、向阳湖镇、双溪桥镇、马桥镇、官埠桥镇、汀泗桥镇、贺胜桥镇）

16.做好物流产业园前期工作，启动开发区新型产业孵化园建设。（责任单位：咸安经济开发区、区交通运输局）

17.支持贺胜、官埠、向阳湖、汀泗、马桥、双溪乡镇工业园的规划修编、土地报批、基础设施建设，加快形成特色鲜明、优势互补的工业园区。（责任单位：区发改局、区规划分局、区经信局、区国土局、咸安经济开发区、相关乡镇办）

（二）加快发展高新技术产业

18.加强核心关键技术攻关，实施高新技术企业培育行动，培育壮大机电制造、电子信息、生物医药、新材料等特色产业园区。（责任单位：区科技局、区经信局、区食药监局、区环保局）

19.大力支持企业新上一批产业层次高、投资体量大、市场前景好的重大技改项目，推动机电制造、苎麻纺织、现代森工、防腐橡胶等传统产业优化提升，形成产业竞争新优势，确保技改投资占工业投资比重达到30%以上。（责任单位：区经信局、区科技局、咸安经济开发区、各乡镇办场）

20.加快“四新”经济、总部经济发展。（责任单位：区招商局、区发改局、区经信局、区财政局、区商务局、区科技局、咸安经济开发区、咸安商贸物流区）

21.加快传统企业向现代公司制企业转型，规范公司治理结构。鼓励优势企业积极参与兼并重组、资本运作，引导中小企业攀高附强、高位嫁接，促进企业跨越式、裂变式发展。（责任单位：区经信局、区工商局、咸安经济开发区）

（三）全力发展现代农业

22.以创建国家农业可持续发展试验区为抓手，推动农业基础设施标准化、产业发展市场化、生产方式机械化、产品销售信息化，加快推进农业供给侧结构性改革。（责任单位：区农办、区农业局、区农机局、区财政局）

23.围绕“两菜一茶”特色优势产业，培育一批享誉全省的“咸安粮、桂香味”农产品品牌，新增“三品一标”认证产品6个以上，加快咸宁桂花、咸安砖茶、杨堡辣椒、白水畈萝卜等国家地理标志品牌保护和开发，增强农业竞争优势。（责任单位：区农办、区农业局、区林业局、区工商局）

24.设立茶产业发展专项基金，巩固砖茶地位、拓展绿茶市场、扩大红茶消费，促进茶产业做大做强。（责任单位：区农业局、区农办、区财政局、区扶贫办）

25.认真落实粮食安全行政首长责任制，全面铺开粮食生产功能区和油菜籽生产保护区划定工作。（责任单位：区粮食局、区农业局、区国土局、区规划分局）

26.落实藏粮于地、藏粮于技战略，新建1.51万亩、补建2.42万亩高标准农田。（责任单位：区农办、区粮食局）

27.推动农业产业链纵向延伸，推进农业内部融合，突出种植业与畜牧、水产、农产品加工业结合，优化农业种植养殖结构。（责任单位：区农办、区农业局、区畜牧局、区水产局、环保局）

28.推进苎麻纺织服装产业园、森工产业园、竹循环产业园、食品产业园建设，打造农产品加工产业集群。（责任单位：区农办、区农业局、区林业局、区发改局、区经信局、区招商局、咸安经济开发区）

29.推动农业功能横向拓展，大力发展“农业+”，打响观光农业、休闲农业、创意农业、智慧农业、绿色农业等品牌，建设咸安都市休闲农业大观园。（责任单位：区农办、区农业局、区旅游委）

（四）聚力发展全域旅游

30.加快融入“一城十区二十景”，大力发展蓝色水上、绿色生态、红色革命教育、古色历史人文“四色旅游”。（责任单位：区旅游委、区文体新局、有关乡镇办）

31.提档升级大幕东源花谷、桂花刘家桥、马桥建国畈、汀泗黄荆塘、双溪王山下等乡村旅游示范点，打造咸安旅游升级版。（责任单位：区旅游委、大幕乡、桂花镇、汀泗桥镇、双溪桥镇）

32.完善旅游交通基础设施建设，确保幕阜山扶贫公路、S360公路全线贯通通车。（责任单位：区交通运输局、有关乡镇）

33.加快高桥“131军旅小镇+白水畈田园综合体”，向阳湖“西湖情”、浮山康美健康小镇等重点旅游项目建设。（责任单位：区旅游委、高桥镇、向阳湖镇、浮山办事处）

34.开发多元化温泉旅游产品，丰富温泉旅游服务内涵，避免同质化竞争。深入开展省级旅游名镇、名村、名街创建工作。（责任单位：区旅游委、区住建局、各乡镇办）

（五）加快发展商贸服务业

35.做好月星家居、义乌国际、五金机电、三亿茶都等建成市场招商等工作，推动商贸物流区规模化发展，增强综合服务功能和消费吸纳能力。（责任单位：咸安商贸物流区、区招商局、区商务局）

36.加快老城区服务业提档升级，打造服务业发展新环境，培育服务业竞争新优势，推动生产服务加快发展，提升流通服务发展水平，扩大社会服务有效供给。（责任单位：区商务局、区交通运输局）

37.抓好以区电子商务服务中心为龙头、乡镇服务站为骨干、村服务点为基础的三级电商公共服务体系建设。大力推进内贸市场主体提质增量，培育限上商贸企业10家。（责任单位：区商务局、区供销社、区工商局、咸安商贸物流区、各乡镇办）

三、构建多点发力新格局，着力在统筹城乡发展上展现新作为

（一）实施城市更新计划

38.融资20亿元，发行城投债券10亿元，加快老城区旧城更新步伐。（责任单位：区经发集团、区棚改办、温泉办事处、浮山办事处、永安办事处）

39.继续推进棚户区改造，确保全面完成2017年棚改项目，启动新一轮棚改三年行动计划。（责任单位：区棚改办、温泉办事处、浮山办事处、永安办事处）

40.加快推进“一河两岸”整体改造，做美沿岸景观，做活“水文章”，打造防洪安全带、滨河景观带、沿河商务带。（责任单位：区水利局、区棚改办、区经发集团）

41.加快推进怀德路中城路、中心巷路综合改造，加快推进贯穿107国道地下通道建设，提升城区道路通行能力。配合抓好107国道改造和咸宁大道西延伸扩建工程。按照“北拓西展”的空间布局，谋划城市“成长坐标”，加快城市基础设施和路网建设。（责任单位：区住建局、区城管执法局、区规划分局、咸安商贸物流区、永安办事处、浮山办事处）

42.加快宏大农贸市场转型，加强背街小巷治理，建立长效管理机制，巩固创卫成果。（责任单位:永安办事处、区商务局、区工商局、区城管执法局、区创建办）

43.推动城管执法力量下沉，推进智慧城市建设，提高城市精细化管理水平。（责任单位：区城管执法局）

（二）实施城镇升级计划

44.着眼提升城镇综合承载和辐射带动能力，启动新一轮乡镇规划修编工作。（责任单位：区规划分局、区国土局、各相关乡镇）

45.因地制宜做好特色小镇产业、文化、生态、风貌的特色打造，增强特色小镇的竞争力和生命力。发挥政府主导、市场主体作用，创新建设管理运营模式，激发特色小镇发展活力。力争创建国家级特色小镇1个、省级特色小镇2个、市级特色小镇不少于3个。（责任单位：区住建局）

46.启动1101个“五边”村管网收集+微动力污水处理站及小型自然村无动力处理设施建设。加快城乡生活垃圾智能监管平台建设，确保城乡垃圾治理通过国家验收。（责任单位：区住建局）

47.加快天然气入镇入户市场推动工作，先期抓好汀泗桥镇、马桥镇气化乡镇试点工作，力争实现乡镇天然气全覆盖。（责任单位：区住建局）

（三）实施乡村振兴计划

48.建成农村产权交易市场，激发农村生产要素有序流转，整合“助农贷、扶贫贷、楚农贷”，引入湖北省农业信贷担保有限公司，缓解新型农业经营主体融资难、融资贵问题。（责任单位：区经管局、区农办、区政府金融办、各乡镇办）

100.建立执法全过程记录制度，严格规范公正文明执法。自觉接受区人大及其常委会法律监督和工作监督，主动接受区政协民主监督和社会舆论监督，认真办理人大代表建议、政协委员提案。（责任单位：区政府法制办、区政府各部门）

（二）建设诚信政府

101.加强政府采购、招商引资、公共资源交易、政府和社会资本合作等领域的政务诚信建设。建立守信践诺机制，将公务员对职权范围内行政事项、行政服务，进行质量、期限、保障承诺的履行情况，纳入个人绩效考核。对社会关注度高、老百姓反映强烈的政务失信易发多发领域进行重点治理，建立政务失信记录机制，加大对政府部门和公务员失信行为的惩戒和曝光力度。深入开展公务员诚信守法和职业道德建设，开展诚信示范单位创建，以政务诚信引领商务诚信、社会诚信，努力让诚信在全社会蔚然成风。（责任单位：区发改局、区财政局、区政府金融办、区招商局、区政务服务中心、区工商局、区公务员局、区公共资源交易监管局、各乡镇办场）

（三）建设高效政府

102.适应新时代新要求，全面增强改革创新、科学发展、群众工作、驾驭风险等本领，有效破解本领恐慌与能力危机。践行“马上就办、真抓实干”精神，把雷厉风行和久久为功结合起来，以钉钉子精神抓落实，一步一个脚印把政府各项工作推向前进。以“亲自、立即、现在”的作风，在落细落小落实中谋大事、干大事、成大事。实行行政问责制、限时办结制、责任追究制，确保各项决策落到实处、各项事项按时办结。推行“一网覆盖、一次办好”，让群众少跑腿、好办事、不添堵。严厉整治庸政懒政怠政行为，不断提高政府执行力。（责任单位：区监察委、区政务服务中心、区政府各部门）

（四）建设廉洁政府

103.落实全面从严治党主体责任和“一岗双责”，打造风清气正的政治生态。严格执行中央、省、市关于作风建设新要求，坚决抵制新形势下形式主义、官僚主义。完善财政资金支出、工程项目招投标、国有资产管理等领域制度，从源头上预防和遏制腐败。加强行政监察和审计监督，坚决纠正损害群众利益的不正之风。持续正风肃纪，严格责任追究，以零容忍态度惩治腐败。（责任单位：区监察委、区审计局、区政府各部门）

9.筹措资金15亿元，再启动6个棚户区改造项目，全面完成省、市下达的农村危房改造任务。（责任领导：陈伟；责任单位：区棚改办、区住建局、有关乡镇办场）
