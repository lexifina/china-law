# 区人民政府办公室关于印发咸安区斧头湖水生态环境综合治理实施方案的通知

咸安政办发〔2018〕3号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁向阳湖现代农业科技示范区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

《咸安区斧头湖水生态环境综合治理实施方案》已经区政府同意，现印发给你们，请结合实际，认真组织实施。

咸安区人民政府办公室

2018年2月9日

咸安区斧头湖水生态环境

综合治理实施方案

为全面落实全省中央环保督察整改攻坚交账电视电话会议有关精神，强化斧头湖水生态环境综合治理工作，确保按时完成斧头湖部分指标超标问题整改任务，根据《市人民政府办公室关于印发斧头湖水生态环境综合治理实施方案的通知》（咸政办发〔2017〕76号）要求，结合咸安实际，特制定本方案。

一、指导思想

坚持科学治水、依法治水，厘清部门治水责任，创新联动工作机制，健全完善管理体制，持续改善斧头湖水生态环境质量。

二、总体目标

通过实施斧头湖水体及入湖污水治理，力争2018年5月底前斧头湖咸安湖心水质明显改善，确保2020年达到国家地表水Ⅱ类标准并长期稳定达标。

三、治理措施

坚持长效机制与短期措施相结合，多措并举，标本兼治的原则，科学有序开展斧头湖流域水生态环境综合治理工作。

（一）摸清底数，科学制定治理方案

1.根据咸宁市环境保护局关于斧头湖水体、底泥和入湖口处的不同形态磷含量的监测数据，定量分析水质总磷超标的具体原因；配合市局监测斧头湖全流域的含磷废水企业的排放情况，摸清重点含磷废水排放企业名单，进一步详查淦河、三八河、贺胜桥河、王生茂河等入湖河流的排放口情况。（时限：2018年1月底前；责任单位：区环保局）

2.根据斧头湖流域水质监测数据和污染调查情况，结合咸安实际，制定斧头湖水质综合治理方案。（时限要求：2018年1月底前；责任单位：区环保局）

（二）加强城镇生活污水治理

3.完善市政污水管网建设，对淦河（咸安段）两岸排污口进行规范化整治，建成区污水基本实现全收集、全处理。（时限要求：2018年5月底前；责任单位：区住建局、区水利局、咸安经济开发区、区经发集团、相关乡镇）

4.根据咸宁市禁止生产、销售和使用含磷洗涤剂的相关规定，对洗涤剂生产企业、销售市场和使用洗涤剂单位实施监督管理。（时限要求：2018年2月底前。责任单位：区环保局、区工商局、区质监局、咸安经济开发区）

（三）加大工业污染防治力度

5.加快咸安经济开发区污水处理厂建设，提高污水处理厂尾水排放标准，确保总磷、氨氮、化学需氧量等因子排放浓度达到三类水体水质要求。（时限要求：2018年10月底前；责任单位：咸安经济开发区）

6.加快完善咸安经济开发区现有污水处理厂管网建设，提高污水收集率，企业污水实现全收集、全处理。（时限要求：2018年3月底前；责任单位：咸安经济开发区）

（四）实施生态修复工程

7.加快淦河、三八河等流域河流下游生态湿地建设，特别是湖北咸宁向阳湖国家湿地公园建设。（时限要求：2018年5月底前；责任单位：区林业局、区水利局、湖北咸宁向阳湖国家湿地公园管理处）

8.对淦河（咸安段）污染底泥进行疏挖和处置，消减内源污染。（时限要求：2018年5月底前；责任单位：区水利局、区经发集团、相关乡镇）

9.分析斧头湖湖底淤泥污染特性，确定清淤范围，及时疏挖并科学处置污染底泥。（时限要求：2018年5月底前；责任单位：区水利局、向阳湖镇、官埠桥镇、贺胜桥镇、向阳湖奶牛场）

10.开展人工增殖放流工作，充分发挥生物治污作用，改善水质和水域的生态环境。（时限要求：2018年5月底前；责任单位：区水产局、区农业局）

11.推进斧头湖生态修复示范工程。人工促进恢复挺水、浮水、沉水植物，逐步改善水生态，提升水体自身净化能力。严厉打击出售湖内扁担草、挖螺等破坏水生态环境的行为。（时限要求：2018年5月底前；责任单位：区水产局、区水利局、区农业局、向阳湖镇、官埠桥镇、贺胜桥镇、向阳湖奶牛场）

12.开展垃圾打捞工作，清除外来入侵水葫芦。（时限要求：长期坚持；责任单位：区水利局、向阳湖镇、官埠桥镇、贺胜桥镇、向阳湖奶牛场）

（五）加强全流域农业面源污染治理

13.开展斧头湖周边区域围堰养殖清理整顿工作，取缔水质污染养殖场，严厉打击投肥养鱼行为，制定分年度退垸还湖方案。（时限要求：2018年3月底前；责任单位：区水产局、区农业局、向阳湖镇、官埠桥镇、贺胜桥镇、向阳湖奶牛场）

14.积极引导科学施肥，减少农药施放。（时限要求：2018年5月底前；责任单位：区农业局、相关乡镇）

15.开展斧头湖流域（咸安段）规模化养殖整治，规范禁养区畜禽养殖散养行为，督促其他区域规模化养殖项目建设环保设施，确保达标排放。（时限要求：2018年3月底前；责任单位：区畜牧局、区环保局、相关乡镇）

16、根据《关于开展碧水保卫战“迎春行动”的命令》（湖北省河湖长令 第1号）要求，斧头湖各级湖长要亲自抓动员、做部署、定方案，加强组织领导，落实主要任务、加强宣传引导，开展斧头湖保护相关工作，务求取得实效。（时限要求：2018年2月底前；责任人：斧头湖区（县）、乡、村各级湖长）

四、相关要求

（一）强化组织领导。成立区斧头湖水生态环境综合治理工作领导小组，区长担任组长，常务副区长任常务副组长，区政府相关领导任副组长，区政府各相关部门、乡镇办场负责同志为成员。领导小组下设办公室，办公室设在区环保局，区政府办公室副主任兼任办公室主任，区环保局局长任办公室副主任，承担斧头湖水生态环境综合治理日常工作。

（二）形成工作合力。斧头湖水生态环境综合治理工作涉及部门多，工作量大，区政府各相关部门、乡镇办场要把综合治理工作摆在突出位置，明确责任领导，成立工作专班，按照方案要求细化工作措施，制定本地区本部门的治理实施方案，形成强大工作合力。各地、各部门要主动作为，加强协调配合，明确目标，任务，时限、要求，实行销号制，建立健全整治档案，确保各项工作任务有布置、有督促、有落实、有结果。

（三）加强指导督办。区斧头湖水生态环境综合治理工作领导小组要加强组织协调和监督检查，坚持一月一督办、一季度一通报、半年一总结，对工作成绩突出的予以表彰，对工作落后的通报批评，对因工作不力、推诿缺位等导致履职不到位、年度目标任务没有完成的，要严肃追究有关单位和人员的责任。区政府各相关部门、乡镇（办场）每月要向领导小组办公室报送工作进展情况。
