# 区人民政府办公室关于印发咸安区2018年度地质灾害防治方案的通知

咸安政办函〔2018〕16号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安区经济开发区，咸宁向阳湖现代农业科技示范区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

《咸安区2018年度咸安区地质灾害防治方案》已经区政府常务会议审议通过，现印发给你们，请认真贯彻实施。

咸安区人民政府办公室

2018年5月24日

咸安区2018年度地质灾害防治方案

为切实做好2018年度地质灾害防治管理工作，最大限度地避免和减少地质灾害造成的损失，维护人民群众生命财产安全，根据《地质灾害防治条例》、《国务院关于加强地质灾害防治工作的决定》（国发〔2011〕20号）和《湖北省地质环境管理条例》的有关规定，结合我区实际，特制定本年度地质灾害防治方案。

一、2017年全区地质灾害基本情况

2017年，区委区政府对地质灾害防治工作高度重视，国土部门和乡镇办党委政府主动作为，落实地质灾害防范防控措施，实现地质灾害零伤亡。咸安区2017年发生地质灾害18起，均为滑坡，威胁人数375，直接经济损失117万元。全区现有地灾点42处，其中温泉办事处4处，属咸宁高新区国土分局负责。

二、2018年度全区地质灾害预测

根据以往监测数据分析，我区地质灾害诱发因素以降雨为主，其次是工程建设活动。山区公路沿线和城乡建设工程区存在崩塌、滑坡、泥石流和地面塌陷等多种地质灾害隐患，严重威胁交通运输、工农业生产和人民群众生命财产安全。

我区旧城区的部分区域、山区公路和村镇建设未考虑周边地质环境条件，存在选址不当、无排水设施、边坡不合理开挖和加载等问题，极易诱发新的地质灾害。

三、重点防控区

（一）人口密集区。相关部门要加强对永安办事处华容南山、马桥镇马桥村五组的监管，采取相应的工程治理和避让措施，消除地灾隐患威胁，防止人员伤亡。在易地扶贫搬迁过程中，要开展地质灾害危险性评估，防止选址不当造成新的生命财产损失。

（二）风景名胜区。要对咸安区鸣水泉风景区、大幕乡樱花谷樱花大道公路沿线等地质灾害隐患点加强监测。旅游主管部门要组织对旅游从业单位和人员的防灾知识培训，督促景区加强监测，落实治理措施，避免地质灾害造成人员伤亡和财产损失。

（三）地质环境脆弱区。要以“三道两旁”关闭矿山（即桂花片、龙潭片）为重点，落实非煤矿山地质环境复绿工作，积极筹措资金，消除地灾隐患。

四、重点防范期预测（5月-10月）

我区地质灾害大多发生在汛期（5月-10月），当降雨延续时间较长且强度较大时，地质灾害就明显增多，受降雨影响十分明显。全区地质灾害防治以5月至10月作为重点防御期。从今年的天气预测情况来看，3月份以来雨水开始增多，所以今年的地灾防治工作要早安排、早布置。

五、地质灾害防治工作的重点

根据我区地质灾害易发程度分区情况，结合城市规划、交通干线分布状况，地质灾害防治区域为乡、镇、办居民区、交通干线、矿山开采区和城乡建设工地。

六、2018年地质灾害防治目标

今年的地灾防治主要工作目标是“一无一降一升一坚决”，即：全区无因地质灾害造成的群死群伤，人为引发地质灾害比例和造成的损失要显著下降，防范和应对地质灾害能力要明显提升，坚决防止因地质灾害防范防控措施不落实、应急救援预案或者防范救援措施不力造成人身伤亡或直接经济损失的安全事故发生。

七、地质灾害防治措施

（一）加强领导，成立专班，依法落实地质灾害防治责任。区政府已成立咸安区地质灾害抢险救灾指挥部和咸安区地质灾害防治网格化管理工作领导小组。各乡镇办场也要相应成立地质灾害防治网格化管理工作领导小组，编制本辖区地质灾害防治年度方案，确定地质灾害网格人员名单，并报送区国土资源局备查。各乡镇办场要落实地质灾害防治值班制度，对本辖区内地质灾害防治工作负总责。区、乡、村三级落实防灾责任，层层签订地质灾害防治责任状，做到各司其职、各负其责。

（二）加强基层地质灾害防治能力建设。一是实行网格化管理，健全群测群防体系和地质灾害监测预警网络，提高应急能力，实现及时预警、及时撤离受威胁人员。二是要配齐区、乡、村三级网格人员。三是充分利用多种手段加强农村地质灾害防治知识宣传和培训，将监测、预警责任制落实到各乡镇办场、村（居委会）。四是将“防灾明白卡”发放至已查明地灾隐患点受威胁的居民手中，加强居民防灾减灾意识，抓好应急避险演练，提高群众自救互救能力。五是充分发挥技术队伍、专家的作用，推进地质灾害防治科学化、应急专业化，形成群专结合的地质灾害防治模式。六是建立地质灾害“四位一体”网格化管理体系。以乡镇办场为区域，以行政村（居委会）行政边界作为网格，各乡镇办场分管领导为网格责任人，各国土资源所所长为网格管理员，市地质环境监测站专家为网格协管员，行政村（居委会）村长或支部书记为网格专管员，各司其职、各负其责、分片包干、重心下沉，切实做好地质灾害防治工作。

（三）落实地质灾害汛期巡查、值班、灾情快报制度。一是做好排查巡查。坚持雨前排查、雨中巡查、雨后复查，动态监控地质灾害隐患点变化情况。二是全面开展督促检查，落实厂矿企业和各类建设单位的防灾责任。三是做好应急值守和信息报送工作，严格按规定报送和发布地质灾害灾情、险情信息。四是继续推进群测群防体系建设，巩固地质灾害高标准“十有县”建设成果。

（四）应急求助装备、资金、物资准备工作及抢险救灾人员组织工作。根据地质灾害应急处理的需要，区政府有权紧急调集人员，调用物资、交通工具和相关的设施、设备，可以根据实际需要在抢险救灾区域范围内采取交通管制等措施。因救灾需要，临时调用单位和个人物资、设施、设备或者占用其房屋、土地的，事后应当及时归还，无法归还或者造成损失的，由区政府给予相应的补偿。

（五）人员财产撤离、转移路线及医疗救治。各乡镇办场、各单位要预定灾害发生时群众撤离方向。区民政局、区卫计局、区食药监局、区商务局、区公安局等部门应及时设置避难场所和救济物资供应点，妥善安排灾民生活，做好医疗救护、卫生防疫、药品供应、社会治安等工作，交通部门保证地质灾害救灾物资、药物、食品的运送。

（六）狠抓宣传培训，普及地质灾害防治知识。以地质灾害防治“五到位”和“十有县”建设为载体，普及地质灾害防灾知识。利用“4·22地球日”、“5·12防灾减灾日”、“12·4法制宣传日”等活动平台，做好宣传报道；组织对从事地灾管理的人员、农村党员干部、网格人员和监测责任人开展地质灾害知识培训，增强全民防灾意识。

（七）加强部门协作，增强防灾能力。区国土资源局要做好地质灾害防治的组织、协调、指导和监督工作。区发改局、区教育局、区财政局、区住建局、区交通运输局、区水利局、区旅游委、区地震局、区扶贫办等单位和气象部门要按照各自职能职责，做好本领域地质灾害巡（排）查、监测预警、治理和应急处置等工作。

区发改局在审批地质灾害易发区内的工程建设可行性研究报告时，应有地质灾害危险性评估结果。

区教育局负责学校周边地质灾害防治工作，对新建、扩建学校选址要组织开展地质灾害危险性评估；在学校开展地质灾害宣传培训，增强师生避险意识和能力。

区财政局要将地质灾害防治专项资金列入年度财政预算。

区住建局负责在建工程施工区和居民点房前屋后的地质灾害防治工作。在核发乡（镇）村建设规划许可证时，需满足地质灾害防治要求，建设项目尽量避免开挖坡体形成高陡边坡。

区交通运输局在公路建设的同时就要及时清除两旁的地质灾害隐患，做好公路沿线地质灾害防治预案，组织人员开展巡查排查，及时预警预报、应急处置，保障过往车辆和人员安全。

区水利局负责河道及水利设施周边地质灾害防治工作。

区旅游委负责旅游景区（点）的地质灾害防治工作。

区地震局负责提供地质灾害所需的地震资料信息，对与地质灾害有关的地震趋势进行监测预报。

区扶贫办要做好扶贫安置区地质灾害危险性评估和防治工作。

气象部门负责提供气象、雨情的监测和预报预警，配合做好地质灾害气象风险预警工作。
