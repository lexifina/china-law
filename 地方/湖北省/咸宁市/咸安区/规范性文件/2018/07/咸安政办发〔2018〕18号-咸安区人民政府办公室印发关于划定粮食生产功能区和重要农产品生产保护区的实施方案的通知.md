# 咸安区人民政府办公室印发关于划定粮食生产功能区和重要农产品生产保护区的实施方案的通知

咸安政办发〔2018〕18号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁向阳湖现代农业科技示范区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

《关于划定粮食生产功能区和重要农产品生产保护区的实施方案》已经区政府常务会议审议通过，现印发给你们，请结合实际，认真组织实施。

咸安区人民政府办公室

2018年7月2日

关于划定粮食生产功能区和重要农产品生产保护区的实施方案

根据《国务院关于建立粮食生产功能区和重要农产品生产保护区的指导意见》（国发〔2017〕24号）、《省人民政府关于建立粮食生产功能区和重要农产品生产保护区的实施意见》（鄂政发〔2017〕43号）、《关于划定粮食生产功能区和重要农产品生产保护区的通知》（鄂农发〔2017〕31号）精神，结合我区实际,为圆满完成我区粮食生产功能区和重要农产品生产保护区（以下简称“两区”）划定工作任务，特制定方案如下。

一、总体要求

（一）指导思想。认真落实党中央国务院、省委省政府和区委区政府决策部署，牢固树立和贯彻落实创新、协调、绿色、开放、共享的发展理念，深入推进农业供给侧结构性改革，以粮食安全和重要农产品有效供给为目标，以主体功能区规划和优势农产品布局规划为依托，以永久基本农田和农村土地承包经营权确权登记颁证为基础，将“两区”面积落实到具体地块。

（二）基本原则。以提高粮油综合生产能力为核心，以粮油生产持续发展和农民持续增收为根本，遵循“政府主导，部门合作；择优选择，确保重点；严格认定，科学管理”的基本原则，做好“两区”划定工作。

1.政府主导，部门合作。“两区”划定由区政府负总责，统筹协调，区农业局牵头，区发改局、财政局、国土局、经管局等部门和乡镇人民政府共同参与，各负其责。

2.择优选择，确保重点。“两区”划定标准：水土资源条件好，坡度在15度以下的永久基本农田；相对集中连片不低于20亩；农田灌排工程等基础设施比较完善，生态环境良好，灌溉水质符合要求，土壤环境质量符合农用地环境质量标准；未列入退耕还林还草还湖还湿等范围；具有水稻和油菜的种植传统，近三年播种面积基本稳定。优先选择已建成或规划建设的高标准农田进行“两区”划定。不符合农用地环境质量标准的地块不得划入“两区”。

3.严格认定，科学管理。各乡镇政府要根据区政府下达的任务，将“两区”划定面积落实到具体地块。严格保护“两区”范围内耕地，原则上不得占用，确需占用的，应按照等效替代原则异地重新划定，确保数量不减少、质量不降低。相关职能部门定期监测、统计、分析“两区”范围内耕地质量等级、作物种植面积、结构和布局等基本情况。

二、目标任务

（一）“两区”划定面积任务。按照省下达我区68万亩“两区”划定总任务，其中粮食生产功能区（水稻）面积33万亩，重要农产品生产保护区（油菜）面积35万亩（见附表1）。

（二）上图入库建档立卡。将划定的“两区”制成电子地图，整理汇总“两区”划定的电子数据和文档，建立“两区”数据库。做好“两区”划定表册、图件、文本和数据等成果的管理，形成全区“两区”布局一张图。

三、工作步骤

（一）资料收集。主要包括永久基本农田划定成果、土地确权登记成果等相关资料。
