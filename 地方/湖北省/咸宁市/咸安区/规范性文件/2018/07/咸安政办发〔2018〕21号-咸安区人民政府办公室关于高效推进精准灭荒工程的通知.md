# 咸安区人民政府办公室关于高效推进精准灭荒工程的通知

咸安政办发〔2018〕21号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

为高效推进精准灭荒工程，规范工程管理，根据《湖北省精准灭荒工程三年行动方案（2018-2020年）》（鄂政发〔2018〕3号）、《湖北省精准灭荒工程建设技术规范（试行）》（鄂林办造〔2018〕18号）和《湖北省精准灭荒工程检查验收办法（试行）》（鄂林办造〔2018〕27号）及有关规定，结合我区实际，现通知如下：

一、明确精准灭荒工程实施范围

精准灭荒工程，是指经省林业厅核实认定且纳入于2018－2020年省级精准灭荒工程范围的宜林荒山造林工程;工程实施范围，是指由省林业厅采取卫片判读、实地核定后录入全省造林信息系统的地块，不得将农用地、采伐迹地等纳入精准灭荒范畴。

二、明确精准灭荒工程实施原则

（一）政府主导，市场参与。各级政府对辖区内精准灭荒负总责，动员和引导各类市场主体参与精准灭荒。

（二）生态优先，兼顾效益。以绿化荒山、改善生态为主，实现经济效益与生态效益相统一。

（三）因地制宜，科学造林。遵循自然规律，合理选择造林树种、造林方式，科学管护，“成活是硬道理，成林是硬政绩”。

（四）统筹兼顾，协调推进。把精准灭荒与长江防护林工程、森林质量精准提升工程、国家储备林建设工程、林业产业基地建设和林业扶贫攻坚结合起来，整合项目、统筹推进，提高精准灭荒综合效益。

（五）加强监管，确保质量。建立健全检查监督机制、激励约束机制和考评机制，实行动态管理，造林合格一块、验收核减一块，三年实现精准灭荒目标。

三、加强精准灭荒工程组织领导

区政府已成立“五个三重大生态工程”建设领导小组，区长任组长，下设全区精准灭荒工程建设指挥部，分管副区长任指挥长，绿化委员会成员单位负责人为成员，办公室设在区林业局，林业局局长兼任办公室主任，负责协调解决精准灭荒中的重大政策和问题。

各乡镇政府要成立领导机构，落实管理专班，负责实施精准灭荒工程。区政府与乡镇、乡镇与村委会签订精准灭荒责任书，压实主体责任。乡镇政府和村委会负责落实造林主体，引导企业、造林专业队、农村合作社、大户投身精准灭荒工程，与造林主体签订精准灭荒工程合同。

区林业部门要发挥精准灭荒指挥办公室职责，加强统筹协调、督办检查、技术指导、项目争取、工程验收等工作。同时，要做好政策宣传，讲清造林质量、抚育要求、管护责任、验收标准、奖补政策和实施时限、资金兑付程序等，让造林主体知晓政策，掌握标准，规范施工；区发改、财政等部门要完善扶持政策，加大对精准灭荒工程投入；区直各部门要结合精准扶贫工作，参与支持所驻村的精准灭荒工程建设，广泛发动群众开展义务植树和灭荒造林，形成政府主导、部门联动、全社会参与的工作机制。

四、抓好精准灭荒工程实施和检查验收

精准灭荒工程按前期准备、组织施工、区级自查和省级核查四个阶段进行控制和管理。

（一）科学制定精准灭荒工程设计方案。区林业部门负责做好荒山调查、作业设计、上报评审、种苗调配等前期准备工作，科学制定三年精准灭荒实施方案和年度作业设计，为全区开展精准灭荒提供指南。

（二）乡镇政府和村委会负责落实造林主体，组织工程施工。各地根据造林作业设计要求，采取“人工造林”、“补植+封山育林”、“林地清理+封山育林”或“直播”等造林方式，在立地条件较好的缓坡地，以发展经济林速生丰产林为主，在陡山石头山等造林难度大的地块以种植刺槐、南酸枣、栾木、香椿、桂花等耐干旱瘠薄的乡土树种为主，用大苗、容器苗上山造林，提高灭荒造林的成活率。

（三）严格检查验收。年度检查验收主要指标包括初植密度、苗木质量、抚育管理、造林面积、造林成存率（保活率）等。区级自查由区林业局在春季造林和夏秋季抚育完成后，组织专班，按照《湖北省精准灭荒工程检查验收办法（试行）》规定，以乡镇为单位，按小班地块实地验收，上报自查结果。秋季开展省级核查，由省林业厅组织专班，逐块核实精准灭荒小班造林面积、保存率和抚育质量，苗木保存率达到85%以上且抚育林地无杂草为合格面积。省级核查验收结果作为年度考核和造林奖补资金兑付依据。

五、制定奖补政策，加强资金管理

（一）制定精准灭荒奖补政策。省级整合中央和省级资金对精准灭荒工程每亩奖补900元，其中，造林每亩600元，抚育300元（连续3年，每年100元）。区政府将加大资金整合力度，在省级奖补基础上，确定区级奖补政策：对精准灭荒工程造林难度大、抚育成本高的茅草山和石头山，每亩奖补抚育费200元，即后两年抚育管理每年补助100元。具体由各乡镇确定奖补造林地块，区林业局制定方案，区财政局监督，报区政府审批执行。同时，利用金融贷款资金，在连片面积达到500亩以上的宜林荒山修建林区公路，每公里奖补3万元。林区公路建设规划由区林业局结合乡镇制定，报区政府审批执行。

（二）严格执行精准灭荒工程奖补政策兑付程序。奖补资金严格按照“先验收、后公示、再兑现”的程序兑付。精准灭荒工程经省林业厅核查并公布结果无异议后，由乡镇按合格面积落实造林业主和奖补资金，经造林业主签字认可、林业管理站签字认定、乡镇政府审查盖章，统一上报区林业局汇总，并将汇总结果函告财政局后，通过“一卡（折）通”形式将奖补资金直接拨付造林业主。林区公路建设经检查验收合格后，其奖补资金按产业扶贫修路政策，直接拨付实施业主。

（三）加强工程奖补资金管理。建立精准灭荒工程资金专账，实行单独核算，任何单位和个人不得挤占、截留、挪用和克扣奖补资金，严禁弄虚作假、虚报冒领奖补资金。

六、加强督办检查，严格考核

区精准灭荒工程指挥部要按照工程建设的时间节点，对各乡镇进行督办，督进度，查质量，及时解决工程建设中遇到的问题。区政府将精准灭荒工作纳入乡镇年度综合目标绩效考核内容，对推进力度大，任务完成好的乡镇，严格按政策兑现奖补资金，并予以表彰；对推动不力，进度慢、质量差的乡镇，责令限期整改，不能按时完成年度灭荒任务的，由区政府领导约谈乡镇政府主要负责人。

七、建立精准灭荒工程档案

乡镇政府和区林业部门要严格按照国家档案管理的有关规定，及时收集、整理工程建设文件资料，包括各级政府和部门印制的文件、作业设计、造林合同、施工照片、检查验收和资金兑付资料等， 建立健全精准灭荒工程档案，接受各级检查和相关部门的监督管理。
