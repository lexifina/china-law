# 区人民政府办公室关于印发咸安区公证处改革方案的通知

咸安政办发〔2018〕23号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区：

《咸安区公证处改革方案》已经区人民政府同意，现印发给你们，请认真组织实施。

咸安区人民政府办公室

2018年8月10日

咸安区公证处改革方案

根据《中华人民共和国公证法》《中共中央 国务院关于分类推进事业单位改革的指导意见》（中发〔2011〕5号）和《司法部 中央编办 财政部 人力资源社会保障部关于推进公证体制改革机制创新工作的意见》（司发〔2017〕8号）等精神，结合湖北省咸宁市咸安区公证处实际（以下简称咸安区公证处），特制定本方案。

一、指导思想和基本原则

（一）指导思想。认真贯彻党的十九大、十八大和十八届三中、四中、五中、六中全会精神，根据司法部、省司法厅关于公证体制改革的部署要求，因地制宜，积极稳妥推进公证体制改革，探索建立权责分明、运转高效、管理科学的公证管理体制，加快我区公证事业发展，为咸安区经济建设提供优质高效的公证法律服务和保障。

（二）基本原则

1.依法设立，促进发展。严格按照有关法律法规规定，推进公证机构改革，坚持公证处法人地位不变、公证的国家证明效力不变。

2.需求导向，服务群众。坚持以人为本，服务群众，不断满足人民群众日益增长的公证服务需求。突出公证服务的职能特性，不断拓展公证服务领域，充分发挥公证机构的服务、沟通、证明、监督作用。

3.积极稳妥，有序推进。以对公证事业负责、对公证机构和公证人员负责的态度，统筹协调各方利益关系，落实工作责任，确保改革顺利推进。

二、改革内容

（一）机构改革。将咸安区公证处由行政机构调整为事业单位，为独立承担民事责任的自收自支依法纳税的独立法人，坚持公证机构的公益性、非营利性属性，并适时根据国家相关政策进行调整。机构名称为“湖北省咸宁市咸安区公证处”，办公地址为咸安区长安大道93号。

（二）人员编制。核定人员控制数4名，实行备案制，负责改革后咸安区公证处的工作。

（三）改革后的体制。改革后的咸安区公证处由区司法局管理、指导和监督。公证机构在核定的绩效工资总量内自主进行分配，实行绩效工资制，鼓励按劳分配、多劳多得。

（四）人员分流与安置。在充分尊重个人意愿的基础上，按照积极稳妥推进的原则，对原咸安区公证处在编在岗人员，根据个人身份，在改革后的咸安区公证处或者区司法局编制限额内进行安置。

1.具有公务员身份的人员，愿意继续从事公证工作的，经本人书面提出申请，办理事业单位工作人员手续，实行事业单位工资待遇；不愿继续从事公证工作的，转入区司法局工作，具体安置方案由区司法局负责制定。

2.没有公务员身份的人，愿意继续从事公证工作的，由改革后的咸安区公证处聘用为工作人员。

（五）业务管理。改革后的咸安区公证处严格按照《中华人民共和国公证法》的规定办理公证事项。原咸安区公证处办理的公证案件的投诉、复查、诉讼等事项，由区司法局依法负责处理。

（六）资产与财务管理。原咸安区公证处的资产无偿划给改革后的咸安区公证处使用和管理，改革后的咸安区公证处依法独立核算，独立承担民事责任，收费按照《湖北省公证服务收费管理办法》（鄂价工服〔2016〕57号）及《湖北省实行政府定价的公证服务收费标准》（鄂价工服〔2016〕42号）执行。执行事业单位会计制度，接受司法行政、审计、财政、税务部门的监督、检查。按照国家规定建立岗位目标责任制、社会保障机制、法人财产制度和公证赔偿制度等工作机制。

（七）档案移交。原咸安区公证处的公证档案由咸安区公证处负责全部移交区司法局，档案必须整理规范、齐全完整，目录完备对应。尚未使用的公证水印纸移交改革后的咸安区公证处。

（八）社会保障。在本次公证处改革前，原咸安区公证处应按照国家及省、市、区相关政策落实本单位在编在岗人员改革前的各类社会保险、住房公积金等费用及相应待遇，所需经费由区财政按照国家及省、市、区相关政策落实。改革后的咸安区公证处应依法依规为本单位在编在岗人员落实各类社会保险和住房公积金等费用及相应待遇。

（九）公证赔偿基金后备金。咸安区公证处必须按照相关政策要求建立和完善公证赔偿制度，按规定比例逐年提留公证赔偿后备金，并按规定提取、上缴赔偿基金。未按规定落实的，应在改革前及时补缴。

三、实施步骤

2018年9月30日前，按要求完成资产交结、档案移交、人员分流等工作。自2018年11月1日起按改革后的管理体制运行。

四、组织保障

（一）加强组织领导。公证体制改革是司法行政体制改革的重要组成部分，要加强领导、周密部署。此次改革由区委、区政府分管司法行政工作的负责同志牵头。区司法局要统筹改革的各项工作，区编办、区财政局、区人社局、区物价局、区档案局、区税务局等单位要各司其职、密切配合，及时研究解决改革过程中出现的新情况、新问题，确保改革工作顺利推进。

（二）严肃改革纪律。公证体制改革工作政策性强，同时也涉及相关人员的切身利益，相关部门特别是领导干部要把思想统一到区委、区政府的决策上来，认真贯彻执行本方案。改革期间，区司法局要认真做好工作，做到工作不断、队伍不散、人员不乱、国有资产不流失。

（三）切实维护稳定。区司法局要担负起维护社会稳定的责任，确保咸安区公证处干部职工队伍稳定。对因改革政策执行不到位、工作不力、处置不当而引发不稳定事件的，将追究相关人员的责任。
