# 关于成立咸安区政策性粮食库存数量和质量大清查工作领导小组的通知

咸安政办函〔2019〕5号

各乡、镇人民政府，各办事处、场，区政府各部门，咸安经济开发区，咸宁鄂南大竹海生态风景区，咸安商贸物流区，华彬金桂湖低碳经济示范区，向阳湖现代农业科技示范区：

根据《国务院办公厅关于开展全国政策性粮食库存数量和质量大清查的通知》（国办发〔2018〕61号），国家发展改革委、国家粮食和物资储备局等7部门《关于印发全国政策性粮食库存数量和质量大清查实施方案的通知》（发改粮〔2019〕247号）和《咸宁市政策性粮食库存数量和质量大清查工作方案》（咸粮清查办发〔2019〕1号）精神，为做好我区政策性粮食库存数量和质量大清查（以下简称大清查）工作，经区政府研究，决定成立咸安区政策性粮食库存数量和质量大清查工作领导小组。现将有关事项通知如下：

一、领导小组成员名单

组 长: 郑奇明　区委常委、区人民政府常务副区长

常务副组长：吴清平 向阳湖湿地管理处主任

副 组 长: 徐建华　区人民政府办公室副主任

陈清淦 区发改局局长

成 员: 郑盛祥 区发改局副局长

陈　晖 区财政局副局长

吴达明 区农业农村局副局长

黄　洋 区统计局副局长

覃文耀 中国农业发展银行咸宁市咸安区支

行副行长

领导小组下设办公室,办公室设在区发改局,负责全区粮食数量和质量大清查组织协调及日常工作, 陈清淦同志兼任办公室主任。

二、领导小组工作职责

（一）按照国务院、省、市级人民政府的统一部署,组织领导我区政策性粮食库存大清查工作；

（二）制定完善政策性粮食库存大清查工作方案,并组织实施;

（三）将全区具体承储库点2019年3月末粮食库存统计报表数据分解下达到各地,作为检查依据;

（四）按照市政策性粮食数量和质量大清查领导小组办公室制定的督导检查方案要求,全面督导我区纳入清查范围的所有政策性粮食承储企业开展自查自纠,指导督促检查区级政策性粮食数量和质量大清查工作成员单位落实大清查工作；

（五）组织实施我区政策性粮食库存的区级普查、市级复查,确保有仓必到、有粮必查、有账必核、查必彻底;

（六）审核汇总全区检查结果和有关情况,经区政府审核后上报市政策性粮食数量和质量大清查领导小组办公室;

（七）协助国家、省政策性粮食库存大清查工作组开展抽查工作；

（八）直接受理和核查举报案件,并对省、市政策性粮食数量和质量大清查领导小组办公室转办案件进行核查;

（九）完成省、市政策性粮食数量和质量大清查领导小组办公室安排的其他清查工作。
