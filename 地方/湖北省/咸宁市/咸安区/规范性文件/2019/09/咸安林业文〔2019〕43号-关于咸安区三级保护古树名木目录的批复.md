# 关于咸安区三级保护古树名木目录的批复

区林业局：

你局《关于公示咸安区古树名木普查结果的请示》（咸安林业文〔2019〕43号）收悉。经区人民政府研究，现就有关事项批复如下：

一、原则同意你局制定的《咸安区三级保护古树名木目录》，共计2441株三级保护古树名木。

二、请你局会同各乡镇办场、区政府有关部门严格按照《中华人民共和国森林法》《湖北省古树名木保护管理办法》（湖北省人民政府令第336号）等规定，切实做好我区区域内古树名木的名录公布、保护管理等工作。
