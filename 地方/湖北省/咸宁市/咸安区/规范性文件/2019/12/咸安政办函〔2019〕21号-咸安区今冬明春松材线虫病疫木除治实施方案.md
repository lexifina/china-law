# 咸安区今冬明春松材线虫病疫木除治实施方案

为进一步加强全区松材线虫病防控工作，打好疫木除治攻坚战，从根本遏制松材线虫病扩散蔓延，确保全区森林资源和生态安全。现根据全区松材线虫病疫情秋季普查结果情况，特制定如下实施方案。

一、工作目标

以培育健康森林理念为指导思想，贯彻“预防为主、科学防控、依法治理”的原则，按照“当年发生当年拔除”的防控工作要求，以各乡镇为实施单位，因地制宜，全面除治松树病死疫木，有效防止松材线虫病的扩散蔓延，使我区疫情发生面积和枯死木数量逐年双下降。

二、除治时间和范围

（一）时间：2019年11月1日至2020年3月31日

（二）范围：全区所有发生松材线虫病疫区。

三、技术要求

（一）除治采取皆伐或择伐。其中：择伐适用于发病小班及其外围5公里以内松林的疫木除治性清理，自然保护区、重要风景区、特殊用途林及其他需要特别保护的松林，连片发生无法根除疫情的大面积松林，应当采用择伐方式。皆伐适用于于发生面积在100亩以下且当年能够实现无疫情的孤立疫点，皆伐后要及时进行造林。

（二）疫木及枝丫处理。所有伐除的松木及直径超过1厘米的枝条全部运至空旷地进行焚烧或运至定点加工企业——咸安巨宁公司进行高温高压处理，焚烧点需要有工作人员现场监管，确保无隐患、无火情发生，切实做到当天砍伐的疫木当天清理完毕。

（三）伐桩处理。伐桩高度应低于5厘米，去皮后喷药液至伐桩湿透，再加盖塑料薄膜，四周覆土压实。

各地严格按照松材线虫病防治技术除治疫木，达到“五个一”标准，即山上不留一株死树、地上不遗一根枝丫、林内不露一个伐桩、路上不丢一根疫木、房前屋后不见一段松木。

四、施工、验收和奖补政策

（一）施工。松材线虫病疫木清理由各乡镇聘请专业公司实施。

（二）检查验收。除治清理完成后，聘请第三方根据《松材线虫病疫区和疫木管理办法》、《湖北省松材线虫病防治指南》等有关法律、法规要求，在2020年4月1日至5月底进行验收。以各疫区乡镇为验收单位，根据枯死木清理的山头地块进行实地核查，全面核查疫区枯死伐除完成情况，枝丫材清理完成情况和伐桩处理达标情况，对验收不合格者不予验收，并按照要求督促整改，直到合格为止。

（三）奖补政策。各地按疫木除治要求完成施工，经第三方检查验收合格后，区政府按500元/吨进行奖补。各乡镇凭疫木清理除治承包合同、验收结果、枝丫焚烧图片、巨宁公司磅单等结算奖补资金。

五、保障措施

（一）加强组织领导，明确防治责任。各乡镇为责任主体，建立健全由政府领导牵头、各乡镇林业站参加松材线虫病的防治领导机构，把除治任务落到山头地块，确保疫木除治无死角。

（二）加强技术指导，明确监督职责。区检疫站对各乡镇松材线虫病除治质量工作进行技术指导和监督检查，对具有疑似症状的松树进行取样送检，严格按照国家林业局《松材线虫病疫区和疫木管理办法》对疫木安全利用，切实组织好第三方核查验收工作。

（三）建立防治机制，完善资料台帐。各地要及时总结松材线虫病防治经验，建立有效管用的疫木除治机制，及时收集松材线虫病防治资料，完善资料台帐。
