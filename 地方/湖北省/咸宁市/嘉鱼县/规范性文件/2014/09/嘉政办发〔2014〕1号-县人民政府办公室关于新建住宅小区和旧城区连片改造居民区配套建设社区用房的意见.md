# 县人民政府办公室关于新建住宅小区和旧城区连片改造居民区配套建设社区用房的意见

嘉政办发[2014]1号

各镇人民政府，县政府各部门，嘉鱼经济开发区管委会：

为加强社区基础设施建设，现就新建住宅小区和旧城区连片改造居民区配套建设社区用房提出以下意见。

一、新建住宅小区和旧城区连片改造居民区，应按《中共中央办公厅 国务院办公厅关于加强和改进城市社区居民委员会建设工作的意见》（中办发[2010]27号）、《中共湖北省委 湖北省人民政府关于进一步加强社区建设的意见》（鄂发[2011]26号）、《中共咸宁市委办公室、咸宁市人民政府办公室印发关于进一步加快推进社区建设的实施办法（试行）的通知》（咸办发[2012]57号）和《城市居住区规划设计规范》（GB50180-93）的要求，配套建设社区用房，由建设单位在小区建设和旧城改造中同步规划、同步设计、同步建设、同步竣工、无偿提供给社区居委会使用。

二、新建住宅小区（含商住小区）和旧城区连片改造居民区配套建设社区用房的标准为：新建小区总户数在100户—300户的，由开发建设单位按60平方米的标准配建；总户数300户—500户的，按100平方米配建；总户数500户—1000户的，按200平方米配建；总户数1000户以上的，按300平方米配建。若住宅区项目分期建设，应按开发建设总面积核定配建社区用房面积，原则上在第一期工程予以配建。

三、社区用房应规划在小区中心或交通便利位置。一楼应设有出入口，保证出入畅通，方便居民办事。社区配套用房与其他建筑物合建时，应当设置在建筑物的1-3层，有独立出入口，以便进出。按照规划配置的社区服务大厅应设在临路方便居民进出办事的地方。配套建设的社区用房应做到水、电、卫等设施齐全，装有固定电话和宽带网线接口，并按同类普通住宅标准交付。建设单位在设计建设工程方案时，应充分征求和听取所在镇和社区的意见，确保房屋布局和内部设施能够满足社区开展办公服务的需要，并与所在镇人民政府签订无偿提供社区用房协议。

四、城投公司在委托国土资源管理部门招拍挂出让住宅用地前，对需配套建设社区用房的地块，须在委托交易函中明确配建的比例、面积。国土资源部门应按规划执法部门和城投部门的意见，将配套建设社区用房在招拍挂文件中予以明确，并写入《土地出让合同》。

五、规划执法部门在规划设计条件中，对新建住宅区和旧城区连片改造居民区配套建设社区用房的建设规模予以明确，在建设工程设计方案上标明社区用房的位置、面积，并在出具规划红线图中也要作相应的注明。对不符合规定配置要求的方案不予审批。在用地规划许可证和建筑工程规划许可证上注明社区用房面积、位置、房产所有权等信息。无偿配建的社区用房面积不计入项目容积率指标，并实行规费减免。

六、住房和城乡建设部门负责对小区配套建设社区用房的建设和工程质量进行监管。要按照相关技术标准和国家、省、市的有关规定，对社区用房建筑施工图纸进行严格审查，对审查不符合要求的，不予核发《建筑工程施工许可证》。

七、新建住宅区和旧城区连片改造居民区项目竣工后，规划执法部门、国土资源部门、住房和城乡建设部门应当将社区用房配套建设情况纳入项目同步验收，对未按批准方案进行建设的责令改正后再行验收。

八、新建住宅区项目验收合格后，建设单位要及时与各镇签订社区用房无偿移交协议，并按协议交付使用。社区用房无偿提供给各镇和社区使用，产权为项目所在地镇政府。各镇和社区不得将社区用房挪作他用，不得用于出租、经营或转让。

九、商品房销售前，必须将社区用房配套到位，经社区所在地的县民政部门签章同意后方可销售。房管部门在办理商品房预售许可证时，应严格审查建设单位是否按照规划许可的内容配建社区用房，没有按照规划设计要求配建的，不予核发《商品房预售许可证》。在办理房屋所有权初始登记时，应在建设单位房屋所有权证上载明社区用房总面积、房号等基本信息。

十、各镇要全程参与社区用房的规划、建设和验收，对社区用房设计、施工、验收全过程进行跟踪关注，发现问题及时向相关职能部门反映。

十一、民政部门负责对小区配建社区用房的整个流程进行监管，其主要领导参与四大家联席会议关于新建住宅区和旧城区连片改造居民区的规划审批工作。国土、规划执法、住建、房管等部门要将涉及到社区用房的审批发证结果告知县民政部门，便于民政部门统筹协调各方工作。
