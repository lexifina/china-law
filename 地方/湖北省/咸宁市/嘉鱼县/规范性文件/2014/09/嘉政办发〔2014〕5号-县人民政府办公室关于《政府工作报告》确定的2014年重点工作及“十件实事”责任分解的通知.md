# 县人民政府办公室关于《政府工作报告》确定的2014年重点工作及“十件实事”责任分解的通知

嘉政办发[2014]5号

各镇人民政府，县政府各部门，嘉鱼经济开发区管委会：

现将《政府工作报告》确定的2014年重点工作及“十件实事”责任分解到各镇、各部门，请认真贯彻落实，确保各项目标任务圆满完成。

一、坚持强主体、育集群，在工业经济上规模、增质效上求突破

1、深入推动“一区三园”加快发展，推进县经济开发区建设全省低碳经济示范园、畈湖工业园建成省级工业园、石矶头沿江工业园和高铁临港产业园建设省级循环经济园，全县园区建设面积达到30平方公里。（责任单位：开发区、发改局、经信局、环保局、相关镇人民政府）

2、加大创业孵化园建设力度，全年引进企业5-10家。（责任单位：开发区、招商局）

3、大力推进产业集群发展，做实传统产业补链，做优成长产业强链，做好新兴产业建链，加快打造3大“百亿集群”。（责任单位：经信局）

4、推进经济结构调整，激活存量资产，加大县级技术进步扶持资金的投入，抓好高强锰业、华义泰特钢、金嘉木业等企业盘活。（责任单位：开发区、经信局、科技局）

5、积极争取国家节能减排专项资金，淘汰落后产能，抓好节能降耗。（责任单位：发改局、经信局）

6、开发和推广节能技术，强化污水处理设施的运行监管，严厉查处企业偷排、漏排、超标排放等违法行为。（责任单位：发改局、环保局）

二、坚持提速度、加力度，在推进项目建设早投产、早见效上求突破

7、强化项目库建设，确保全年争取项目资金超1.5亿元。（责任单位：发改局）

8、力争全年招商引资到位资金达100亿元，引进投资亿元以上项目30个，引进上市公司3家，中国500强企业1-2家，力争在引进世界500强企业上实现突破。（责任单位：招商局）

9、继续坚持重点项目县级领导包保、现场办公、年终考核等制度，把握时间节点，加快工程进度。（责任单位：各项目建设责任单位、项目办）

三、坚持优结构、强基础，在现代农业促特色、创品牌上求突破

10、加快推进8大现代农业示范区建设，凸显蔬菜和水产在农业中的主导地位，建好“五区十线” 林业生态工程。（责任单位：县委农办、农业局、林业局、水产局、相关镇人民政府）

11、力争全年新增土地流转面积1万亩，新增农民专业合作社30家以上，新增蔬菜规模种植大户60家以上。（责任单位：农业局、经管局）

12、加强农产品质量安全建设，力争新增“三品”认证5个，打造1-2个地方特色品牌。（责任单位：质监局、农业局、工商局）

13、完善营销网络，加大专业市场、冷链物流建设力度，深入推广“嘉鱼蔬菜”贴标上市。（责任单位：县委农办、商务局、工商局）

14、扶持、培育2-3家省市级农业产业化龙头企业，引进6-8家农副产品精深加工企业，农产品加工产值占农业产值比重达到2.6∶1。（责任单位：县委农办）

15、加快农田水利基本建设，推进三湖连江灌区续建配套、子湖除险加固和水利血防项目，抓好长港河、余码河、峡港河和斧头湖、西凉湖治理，实施陆水干流嘉鱼段防洪治理工程，加快簰洲湾堤及其他民堤民垸整险加固等水利项目建设。（责任单位：水利局）

16、认真开展新一轮“三万”活动，改造农村人居环境。（责任单位：县委农办）

17、推进农技服务体系建设，培训农民1.5万人次。（责任单位：农业局、人社局）

四、坚持活市场、增后劲，在推进第三产业更活跃、更繁荣上求突破

18、完善全县旅游开发总规划，组织开展好旅游子规划编制，服务推进三湖海航世界、嘉洲生态城等项目。（责任单位：旅游局）

19、全力支持官桥镇打造“湖北旅游名镇”；大力发展乡村旅游。（责任单位：旅游局、相关镇人民政府）

20、力争全年接待游客达到200万人次，实现旅游综合收入超过10亿元。（责任单位：旅游局）

21、实现外贸出口7000万美元，实际利用外资突破1000万美元。（责任单位：商务局）

22、加快专业市场建设，大力培育现代流通业态，力争引进一批大型商贸集团、商展贸易中心及知名品牌商户进驻。（责任单位：招商局、规划执法局、商务局）

23、深入推进“万村千乡市场工程”，建立和完善双向流通网络，实现社会消费品零售总额48.6亿元。（责任单位：商务局、统计局）

24、尽早开工建设潘家湾港区码头和临江山物流园区综合码头，做好嘉鱼长江大桥临江物流园的招商引资工作。（责任单位：招商局、交通运输局、区经局）

25、提高政府融资平台资本运营能力，做大做强城投公司、中小企业担保公司等平台。（责任单位：金融办、城投公司、担保公司）

26、积极支持农村信用社改制，支持配合股份制银行、村镇银行在辖区设立新机构。（责任单位：金融办、人行、银监办、信用社）

27、深入推进税收征管改革，大力培植财源，优化财政支出结构。（责任单位：财政局、国税局、地税局）

五、坚持抓长远、重基础，在推进城乡建设提品位、更宜居上求突破

28、编制完成城东新区概念规划和小湖片区控制性详细规划；开展城区绿道规划和蜀河湿地带控制规划；加快小湖路、麒麟路、代湾路、三湖连江风景区道路等规划设计，编制老城区沙阳大道、方庄路等部分路段综合整治规划，逐步完善覆盖县城区主次干道的控制性详细规划。完善城区停车场等公共设施规划，科学规划并建设季节性农副产品交易、餐饮等一批专业市场。（责任单位：规划执法局）

29、全力协调好嘉鱼长江大桥及接线高速、武深高速建设，抓好咸潘一级公路、迎宾大道、京珠连接线拓宽等道路建设，完成沿江快速通道工程建设。（责任单位：交通运输局、规划执法局）

30、加大市政基础设施建设力度，积极推进城区排水管网改造、自来水厂扩建工作，启动污水处理厂二期建设，实施城区排污泵站和管网全面对接，建设新街110千伏变电站，改造农村电网。（责任单位：住建局、供电公司）

31、推进潘家湾镇开展“四化同步”试点，安排专项资金改造基础设施，及时跟进潘家湾、鱼岳、陆溪、高铁岭的重点镇申报。（责任单位：县委农办、财政局、潘家湾镇及其他相关镇人民政府）

32、深入推进藕塘村、港东村、八斗角村、下沙口村新农村建设，全面完成官桥村、净堡村、四邑村、界石村新农村二期建设，开展创建国家生态文明示范县活动，着力打造一批“美丽乡村”和“绿色生态示范村”。（责任单位：县委农办、环保局、相关镇人民政府）

33、健全完善创建长效管理机制，延伸开展“文明卫生平安”城镇、社区、机关、学校、企业等创建活动，巩固创建成果；加大对乱摆乱占、乱停乱放等违规行为的整治力度；建立全覆盖清扫、保洁长效管控新模式；落实养护责任，提升城区绿地养护水平；加强规划控制管理，加强对重点区域的巡查，坚持开展“两违”集中整治，加大“两违”打击力度。（责任单位：创建办、规划执法局）

六、坚持察民情、解民忧，在推进社会事业惠民生、更和谐上求突破

34、加大科技投入，积极争创全国科技进步先进县。（责任单位：科技局）

35、深入推进义务教育均衡发展，加快中小学教育技术装备标准化建设，不断改善农村薄弱学校办学条件，支持嘉鱼一中打造省级示范高中。（责任单位：教育局）

36、加快推进县镇村三级卫生计生服务机构及信息化建设，全面巩固完善新农合和基本药物制度，确保全县参合率达到100%。（责任单位：卫计局）

37、加强食品药品监督，规范食品、药械市场秩序。（责任单位：食品药品监督管理局）

38、加快建立覆盖城乡居民的社会保障体系，扎实抓好扩面征缴工作，着力解决失地农民养老保障问题。（责任单位：人社局）

39、提高住房公积金覆盖面，着力解决中低收入职工家庭住房困难问题。（责任单位：市住房公积金嘉鱼办事处、住建局）

40、加快完善城乡最低生活保障、残疾人生活保障、五保户以及优抚对象生活保障等救助制度，逐步提高保障标准。（责任单位：民政局、残联）

41、全面启动全省公共文化服务示范区创建工作，落实全民健身计划，继续开展好嘉鱼第一次全国可移动文物普查和全县非遗搜集整理工作。（责任单位：文体新局）

42、认真做好第三次经济普查工作并抓好成果应用。（责任单位：统计局）

43、开展法治嘉鱼建设，争创省级法治先进县。（责任单位：司法局）

44、依法加强安全生产监管，大力推进安全生产隐患排查治理标准化数字化体系建设，开展平安嘉鱼创建，严厉打击“一霸四强”，不断提升人民群众的安全感、幸福感。（责任单位：安监局、公安局）

45、创新社会管理，坚持抓好信访维稳工作，建立多元化矛盾纠纷排查化解机制，依法处置缠访、闹访和赴省进京非正常上访行为；预防和处理群体性突发事件。（责任单位：维稳办、信访局、公安局）

46、紧紧围绕“三化一融合”标准，着力抓好国防后备力量建设。（责任单位：人武部）

七、务实创新，加快建设法治、服务型政府

47、清理各类行政审批事项，建立本级行政审批事项统一目录，向社会全面公开；规范部门执法行为，规范自由裁量权。（责任单位：法制办、政务服务中心）

48、加快事业单位分类改革，建立事业单位法人治理结构。（责任单位：编办、人社局）

49、严格落实中央八项规定和反对“四风”要求，敢于动真碰硬，树立一批正面典型，查处一批不作为、滥作为和慢作为的反面典型。（责任单位：监察局）

50、全面推行县直预算单位公务卡和现金使用管理办法，加快推进预算绩效管理、投资评估和预决算信息公开、“三公”经费公开。（责任单位：财政局）

2014年县政府“十件实事”责任分解

在县十七届人大会第三次会议上审议通过的《政府工作报告》中，县政府庄严承诺2014年继续为城乡居民办好“十件实事”。这“十件实事”突出反映了人民群众目前最关心、最直接、最现实的利益问题。努力办好“十件实事”，对于提高政府执行力和公信力，促进嘉鱼科学发展、跨越发展具有重要意义。为确保“十件实事”圆满完成，根据县政府要求，县政府办公室对2014年县政府“十件实事”进行了责任分解。请各部门对照分解，落实相关责任，制定工作方案，采取有效措施，狠抓落实，确保“十件实事”圆满完成，向全县人民交一份满意答卷。具体责任分解如下：

一、全年城镇新增就业岗位5200个，城镇失业人员再就业900人，城镇登记失业率控制在3%以内。（责任单位：人社局）

二、解决7900名农村人口安全饮水问题。（责任单位：水利局）

三、投资931万元完成谷洲、护县洲等10个民堤民垸及东西湖围堤加固二期工程。（责任单位：水利局）

四、筹资3200万元在东岳路规划建设“夜市”；投资452万元规划建设2500平方米的北门湖农贸综合市场。（责任单位：规划执法局、商务局）

五、通过“以奖代补”形式，对城区背街小巷实施道路硬化，对下水道进行改造；实施发展大道路灯节能改造升级，主要支街小巷安装路灯，实现城区路灯照明全覆盖。（责任单位：鱼岳镇、供电公司）

六、投资290万元在城区新建垃圾中转站2座、改造旱厕5座。（责任单位：规划执法局）

七、完成省市下达的保障性安居工程建设任务。（责任单位：住建局）

八、投资1200万元改造升级小新堤路；投资3500万元动工建设三湖大道。（责任单位：住建局、旅游局）

九、对全县农村适龄妇女开展“两癌”（宫颈癌、乳腺癌）免费检查。（责任单位：妇联、卫计局）

十、投资560万元提升养老服务水平，实现城镇社区居家养老服务中心全覆盖、农村老年人互助照料活动中心覆盖50%。（责任单位：民政局）
