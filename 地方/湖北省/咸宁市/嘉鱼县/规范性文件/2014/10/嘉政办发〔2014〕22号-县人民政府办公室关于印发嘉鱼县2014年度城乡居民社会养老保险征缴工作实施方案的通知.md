# 县人民政府办公室关于印发嘉鱼县2014年度城乡居民社会养老保险征缴工作实施方案的通知

嘉政办发[2014]22号

各镇人民政府，县政府各部门，嘉鱼经济开发区管委会：

经县人民政府同意，现将《嘉鱼县2014年度城乡居民社会养老保险征缴工作实施方案》印发给你们，请认真组织实施。

嘉鱼县人民政府办公室

2014年4月2日

嘉鱼县2014年度城乡居民社会养老保险征缴

工作实施方案

为做好嘉鱼县2014年度城乡居民社会养老保险征缴工作，以高效、便捷的经办方式服务广大城乡居民，全面提升全县城乡居民社会养老保险适龄人员参保率，特制定如下实施方案：

一、总体要求

采取集中征缴和常态征缴相结合的办法，以集中入户征缴为主，提升征缴工作效率，全面完成2014年度征缴工作任务。

二、工作目标

2014年度城乡居民社会养老保险征缴工作要求全县综合参保率达100%以上，参保缴费总人数100752人。

三、实施步骤

（一）前期准备阶段（4月20日—4月30日）

1、县人社局向各镇、县财政局、县地税局提供征缴对象花名册，并进行数据核定。

2、各镇召开动员大会，下达征缴任务，启动征缴工作；县财政局、地税局根据县居保局提供的征缴信息，确保5月1日前做好征缴票据准备工作。

（二）征缴阶段（5月1日—12月31日）

征缴阶段分为：集中征缴阶段（5月1日—6月30日），常态征缴阶段（1月1日—12月31日）。

1、在各镇主导下，由财政、地税部门按人社部门核定的社会保险费缴费档次及缴费标准统一征收，所征资金以镇为单位归集到各镇财经所专用账户。各镇财经所根据人社部门提供的基础信息，对所征缴的资金对应制作缴费人员缴费明细表，注明镇、村组、姓名、身份证号、参保金额、缴费时段。

2、各镇财经所与县人社局、镇人社服务中心联合将征收资金和缴费明细表核对无误后，以镇为单位，将征缴资金统一划转至城乡居民社会养老保险基金专户。

（三）考核结账阶段（11月1日—11月15日）

县财政局、地税局、人社局组成考核结账专班，对征缴阶段的人、款、票进行多向核对，最终核定各地参保缴费人数、参保资金。

四、职责分工

各镇人民政府是城乡居民社会养老保险征缴工作的责任主体，对本镇征缴工作负总责，确保年度任务如期或提前完成。

县财政、地税部门是城乡居民社会养老保险费的征收主体，财政部门负责农村居民保费征缴工作，地税部门负责城镇居民保费征缴工作。

县人社局负责前期的信息提供和后期的缴费记录及进度统计工作。各镇人社服务中心负责参保缴费人员信息登记。

各镇各有关部门要牢固树立创新意识、效率意识、民本意识，切实做好本年度的征缴工作，全面完成征缴任务。
