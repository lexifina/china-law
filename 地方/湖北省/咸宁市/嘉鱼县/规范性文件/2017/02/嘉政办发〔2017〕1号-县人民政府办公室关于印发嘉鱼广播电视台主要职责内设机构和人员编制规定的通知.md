# 县人民政府办公室关于印发嘉鱼广播电视台主要职责内设机构和人员编制规定的通知

嘉政办发〔2017〕1号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园:

经县人民政府同意，现将《嘉鱼广播电视台主要职责内设机构和人员编制规定》印发给你们，请认真遵照实施。

嘉鱼县人民政府办公室

2017年1月9日

嘉鱼广播电视台主要职责内设机构

和人员编制规定

根据《中共嘉鱼县委、县人民政府关于印发〈嘉鱼县人民政府职能转变和机构改革实施方案〉的通知》（嘉发〔2015〕10号）文件精神，将广播电影电视行政管理职能划归县文体广电新闻出版局后，在原县广播电影电视局基础上组建嘉鱼广播电视台，为县政府直属事业单位，不再保留县广播电影电视局牌子。

一、主要职责

（一）贯彻执行党中央、国务院和省委、省政府关于广播电视宣传工作的路线、方针、政策和国家的法律、法规，把握正确的舆论导向，依法规范广播电视台的职业行为，为县委、县政府工作大局和中心工作服务。

（二）组织拟订并实施广播电视台的发展战略和规划，统一领导筹划广播电视台基本建设项目、事业和产业发展、技术改造及新项目开发工作。

（三）推进技术进步，加快科技创新与改造步伐，努力提升广播电视的科技含量和水平。

（四）负责对广播电视台传输覆盖网络统一规划、统一建设、统一管理，努力扩大县级广播电视对内对外覆盖范围。

（五）加强对广播电视台职工队伍的思想建设和业务建设，有计划地培养各类人才；负责对广播电视台的宣传工作及人、财、物实行统一管理。

（六）积极开展广播电视对外交流与合作。

（七）根据县政府授权，承担广播电视台及所属单位国有资产管理，并负责其保值增值。

（八）完成县委、县政府交办的其他事项。

二、机构设置

根据上述职责，嘉鱼广播电视台设6个内设机构：

1．办公室

协助台领导处理日常工作，综合协调各部室和下属部门的有关工作；负责重要文件的起草和重大问题的调研；负责文秘、档案、信访、综合治理、文明创建、保密、信息、督办、会务、议案提案办理等工作；负责办公用品、劳保福利用品的购置、保管和发放；负责各类综合性行政事务工作；负责外事联络接待工作。

2．总编室

贯彻党的宣传方针、政策；负责制定和落实宣传计划，组织、协调重要新闻、重大活动的宣传报道；协调、组织节目的规划和各频率频道栏目设置、节目审查、编排和资源共享工作；负责收听收视率的分析、汇总工作；研究广播电视宣传工作的改革；参与市广播电视学会的工作。

3．人事股

负责台机关及所属部门干部人事工作；负责人才发展规划的拟订和实施；承担干部队伍建设和管理；承办机构编制、人员调配、绩效考核、工资福利、退休、劳动仲裁、社会保险等管理工作；承办技术工人等级考核、专业技术岗位持证上岗、专业技术职务的审查聘任；研究拟订全台干部职工业务培训教育计划并组织实施；研究和推进台及所属部门内部人事制度和管理体制改革工作；负责精神文明建设和职工政治思想工作；负责党建工作；负责党风党纪教育和廉政建设。

4．财务股

负责计划、财务及统计工作；负责对全台国有资产的保值增值实施监督管理；负责监管各项事业经费和专项经费；研究拟订和完善台及所属部门财务核算体系，负责成本核算工作，实行统一规划、统筹预算、分级管理、分级核算。负责按照相关法律对广播电视台各类对外合同文本进行规范审核及法律事务处理；负责各类经营活动的前期论证、过程监督和事后审计。

5．老干部股

落实退休干部工作方针政策，负责退休、改非、内退人员的服务管理工作。

6．事业技术股

负责产业政策研究、市场调研和开发；负责广播电视台产业规划和组织实施；负责重大项目论证和可行性研究；参与审核工程建设方案及竣工验收；负责全县广播电视技术管理和指导工作；负责全县“户户通”“村村响”的发展和运维；负责事业发展数据统计和汇总上报工作；负责全台的安全生产和消防工作，并拟定有关制度和应急方案并组织实施。

机关党组织 负责机关和直属单位的党群工作。

纪检、监察、工会等机构 按有关规定设置。

三、人员编制和领导职数

嘉鱼广播电视台机关事业编制15名。其中：台长(总编辑)1名，副台长2名，副总编辑1名（副科职）。

四、其他事项

所属事业单位的设置、职责和编制另行规定。

五、附则

本规定由县机构编制委员会办公室负责解释，其调整由县机构编制委员会办公室按规定程序办理。
