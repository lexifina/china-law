# 县人民政府办公室关于印发嘉鱼县产品质量检验检测中心主要职责内设机构和人员编制规定的通知

嘉政办发〔2017〕2号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园:

经县人民政府同意，现将《嘉鱼县产品质量检验检测中心主要职责内设机构和人员编制规定》印发给你们，请认真遵照实施。

嘉鱼县人民政府办公室

2017年1月9日

嘉鱼县产品质量检验检测中心主要职责

内设机构和人员编制规定

根据《湖北省人民政府关于改革完善食品药品监督管理体制的指导意见》(鄂政发〔2013〕36号）、《关于嘉鱼县食品药品监管体制改革部分机构设置的批复》（咸编办发〔2014〕6号)和《中共嘉鱼县委、县人民政府关于印发〈嘉鱼县人民政府职能转变和机构改革实施方案〉的通知》（嘉发〔2015〕10号）等文件精神，结合我县实际，全面整合相关检验检测资源，组建嘉鱼县产品质量检验检测中心，为县政府直属事业单位。

一、主要职责

（一）承担政府相关职能部门和司法部门下达的产品质量风险监测、突发事件等计划任务和仲裁检验；承担食品药品生产许可检验工作。

（二）质量风险预警技术支持服务。为政府部门进行产品质量安全监管提供风险预警的技术支持和信息服务。

（三）利用专业技术和人才优势，为企业和消费者提供食品药品的委托检验、新产品鉴定、型式检验和其它各类型的检验工作，为企业产品研发、中试、定型全过程提供检测和分析、诊断服务，提出质量改进的方案和建议。

（四）承担产品国家标准和行业标准的编制、修订及其实验验证工作；提供标准咨询服务。支持企业技术创新，促进企业产品技术、创新成果标准化、产业化，带动产业标准水平整体提升。

（五）为生产企业提供检测技术知识培训服务。

二、内设机构

根据上述职责，县产品质量检验检测中心设2个股级内设机构：

（一）办公室

负责中心文电、机要、保密、档案、财务、办公自动化、会务、党务、机构编制、组织人事、计划生育、综合治理、信访、接待、政务公开等日常管理和后勤保障工作；负责综合性文稿起草、督办检查、组织调研、综合协调和建议、提案办理等工作；负责组织实施各项财务管理规章制度；负责编制汇总和执行单位财务预决算、工资核算和发放工作；负责检验检测收费管理、票据管理；负责单位经费、基建、国有资产的管理。

（二）综合业务室

负责制订安排全县年度抽检计划及应急检验任务，组织协调中心所属事业单位对抽检数据信息进行定期分析，形成分析报告反馈相关部门；负责中心及所属事业单位检验检测机构认证及各种检验资质的申报工作；负责中心所属事业单位检验检测工作的综合协调；负责样品的抽取、收发、安全管理工作；负责开拓外部检验市场及对外业务联系；负责检验检测委托检验协议的签订；负责建立检验检测信息通报和追溯制度，建立质量安全数据库，为政府部门进行产品质量监管提供风险预警的技术支持和信息服务，定期向社会公布检验检测结果；负责检验检测的内部审核、检验报告的审核、签发，保证各类检验检测的科学性及公正性；负责技术人员的专业学习、培训。

三、人员编制和领导职数

产品质量检验检测中心机关核定事业编制11名。其中：主任1名，副主任2名。

四、其他事项

（一）职责分工

县产品质量检验检测中心接受县食品药品监督管理局、县质量技术监督局、县卫生和计划生育局、县农业局（含水产局、畜牧局）、县粮食局相关业务指导监督；县食品药品监督管理局、县质量技术监督局、县卫生和计划生育局、县农业局（含水产局、畜牧局）、县粮食局要积极争取上级业务主管部门对其在检验业务、项目建设、政策性资金和人才培养等方面的支持。

（二）运行机制

1．公共检验检测由县产品质量检验检测中心依照相关法律法规和工作需要，会同相关职能部门提出年度检验检测计划（根据中心检验批量能力，确定具体送样批量），各相关职能部门及县产品质量检验检测中心按业务流程分别落实。

2．公共检验检测业务流程为：①县政府及各职能部门下达年度产品质量检测计划；②各部门按检测计划提取样品，并送样至中心；③中心按各职能部门检验项目要求，独立、公正、及时实施检验检测，出具并向送检单位发送检验报告；④各部门根据检测报告，履行相应的监管、后处理及信息发布等职责。其它检验检测业务，由中心根据企业、市场和职能部门需要按业务流程落实。

（三）经费核拨

县产品质量检验检测中心日常经费、建设资金、公益性检验检测项目经费和应急检验检测经费纳入财政预算，予以保障。鼓励和支持中心积极开拓市场，对企业委托检验、技术鉴定和仲裁检验等经营性检验检测服务项目，中心可按照国家收费标准收取相应检验检测费用。对相关单位对口上级业务主管部门下拨的与检验检测有关的资金，或以开展检验检测业务为主要内容而争取到的专项资金，根据具体业务量的多少，按照一定的比例，在原单位和中心之间进行分配。

（四）所属事业单位设置

县产品质量检验检测中心下设4个正股级全额拨款事业单位：

1．嘉鱼县食品药品检验检测中心

承担食品药品质量检验检测工作。核定事业编制4名。

2．嘉鱼县农产品检验检测中心（加挂嘉鱼县水产品检验检测中心、嘉鱼县粮食检验检测中心、嘉鱼县畜禽产品检验检测中心牌子）

承担农产品质量检验检测工作。核定事业编制2名。

3．嘉鱼县工业产品检验检测中心

承担各类工业产（商）品、工程建设及建设材料质量等检验检测工作。核定事业编制4名。

4．嘉鱼县产品质量检验检测中心实验室

承担综合类检验检测工作；负责开展检验检测方法、质量技术标准的制（修）订和相关科研工作，提供标准咨询服务；承担新产品鉴定、型式检验和其他各类型的产品检验工作。核定事业编制5名。

五、附则

本规定由县机构编制委员会办公室负责解释，其调整由县机构编制委员会办公室按规定程序办理。
