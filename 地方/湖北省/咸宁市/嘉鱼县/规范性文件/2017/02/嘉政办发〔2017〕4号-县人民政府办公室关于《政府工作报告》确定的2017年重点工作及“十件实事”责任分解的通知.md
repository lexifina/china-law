# 县人民政府办公室关于《政府工作报告》确定的2017年重点工作及“十件实事”责任分解的通知

嘉政办发〔2017〕4号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

现将《政府工作报告》确定的2017年重点工作及“十件实事”责任分解到各镇、各有关部门，请认真贯彻落实。

嘉鱼县人民政府办公室

2017年1月12日

《政府工作报告》确定的2017年

重点工作责任分解

2017年全县经济社会发展的预期目标是：完成地区生产总值256亿元，增幅9%；地方公共财政预算收入10.68亿元，增幅9%；全社会固定资产投资额286亿元，增幅15%；实现社会消费品零售总额62亿元，增幅10.7%；规模以上工业增加值增幅8%；城镇常住居民人均可支配收入28069元，增幅9.5%；农村常住居民人均可支配收入17063元，增幅10.8%；单位二氧化碳排放量下降3.8%；万元GDP综合能耗下降3.4%。

一、增强科学发展的内生力，提升县域经济新动能

实施创新驱动，加快转型升级，以新技术、新模式改造提升传统动能，着力培育经济发展新动能。

（一）推进工业转型升级

1.积极实施工业强基、园区转型、集群发展、品牌强工“四大工程”，改造传统产业，发展新兴产业，壮大骨干企业，盘活困难企业，全力打造十亿级企业、百亿级产业，全年实现工业总产值525亿元。（牵头单位：县发改局；责任单位：县经信局、县招商局、县工商局、县质监局、嘉鱼经济开发区、武汉新港潘湾工业园、各镇人民政府）

2.培优更具支撑力的支柱产业。依托沿江优势，不断完善园区基础，夯实产业发展平台。全力推动纺织、冶金、建材、装备制造等传统产业技术改造升级，支持企业挂牌“新三板”、“四板”，力争全县挂牌企业突破40家。推动传统优势产业迈向百亿产业集群，努力建设沿江产业带。(牵头单位：县经信局；责任单位：县发改局、县招商局、县政府金融办、嘉鱼经济开发区、武汉新港潘湾工业园、各镇人民政府)

3.做大更具竞争力的新兴产业。顺应新技术、新产业发展趋势，大力发展循环经济、先进装备制造、生物医药等产业。推进以华亿通、申邦化纤为代表的循环产业发展，推进以欧维姆缆索、嘉诚汽配为代表的先进装备制造业发展，推进以神农制药、武汉新联大为代表的生物医药产业发展，增强县域经济发展后劲。（牵头单位：县经信局；责任单位：县发改局、县招商局、嘉鱼经济开发区、武汉新港潘湾工业园、各镇人民政府）

4.扶强更具贡献力的骨干企业。全面实施“品牌工业”战略，大力引进行业50强企业落户嘉鱼，全力支持金盛兰冶金、嘉麟杰纺织、稳健全棉时代、雅戈尔汉麻、联乐集团、中能锂电等规模大、实力强的优势企业做大做强，力争培育主营业务收入过10亿元企业13家、过40亿元企业1家，打造一批“企业航母”。（牵头单位：县经信局；责任单位：县发改局、县财政局、县招商局、县政府金融办、县人行、嘉鱼经济开发区、武汉新港潘湾工业园、各镇人民政府）

5.盘活停产半停产困难企业。多途径、多方式、多举措帮扶企业解困。对中马动力、德和模具等破产企业拍卖重组，注入活力；对岐丰管业、永幸管业等停产企业实行招商重启，恢复生产；对嘉能热电、嘉台双美等困难企业采取增资扩股、合并重组等办法助其解困。（牵头单位：县经信局；责任单位：县发改局、县财政局、县招商局、县人行、嘉鱼经济开发区）

（二）推进农业提质增效

6.建强农业生产、加工、质量、经营“四大体系”，发展“一镇一业、一村一品”，整体提升农业效益，积极争创国家级现代农业示范区，力争2017年全县农产品加工园区产值过60亿元，农产品加工产值突破200亿元。（牵头单位：县委农办；责任单位：县农业局、县林业局、县经信局、县水产局、各镇人民政府）

7.强基础补短板。按照“挡得住、排得出、灌得上”的目标，积极筹措资金，加快余码头新泵站建设、三湖连江水库灌区续建配套与节水改造、堵口复堤、涵闸除险加固和中小型泵站维修等水利工程建设。（牵头单位：县水务局；责任单位：县财政局、各镇人民政府）

8.扎实推进农业综合开发、高标准农田、土地整治等农田基本建设，夯实农业发展基础。（牵头单位：县委农办；责任单位：县发改局、县农业局、县水务局、县财政局、县国土资源局、各镇人民政府）

9.强特色优结构。以现代农业示范区建设为抓手，加快现代农业板块建设。在簰洲湾、鱼岳建设绿色优质稻和再生稻示范基地；在新街、潘家湾建设绿色蔬菜示范基地；依托官桥油茶基地，争创全省“十大万亩油茶基地”；在渡普推广小龙虾稻田养殖、池塘网箱养鳝等新型高效水产养殖模式；在陆溪建设富硒蔬菜生产示范基地；在高铁岭建设富硒美国斑点叉尾鮰示范基地。（牵头单位：县委农办；责任单位：县农业局、县林业局、县水产局、各镇人民政府）

10.强标准树品牌。建立健全农产品质量追溯和检测体系，按照绿色农业标准要求生产，打响“簰洲湾香米”、“梅山柑橘”、“山古佬冷鲜鱼”等绿色农产品品牌。大力推进“三品一标”认证，着力培育20个有机食品、100个绿色食品品牌。加大农副产品加工产业园建设，加快培育农产品加工龙头企业，提高蔬菜和水产品深加工水平。力争引进2家投资过10亿元的农字号龙头企业，培育1家年产值过20亿元的农产品加工企业。（牵头单位：县委农办；责任单位：县农业局、县工商局、县招商局、县水产局、县质量检测中心、各镇人民政府）

（三）推进三产快速发展

11.着力构建现代服务业体系，不断培育新的经济增长点。加快发展旅游产业。按照“游嘉鱼、看八组、吃吊锅、采果蔬、泡温泉”的旅游路径，大力发展休闲旅游产业，探索做好“旅游+”的文章。着力建设官桥国家乡村公园、康丰源生态旅游区、武嘉一级路沿线和高铁岭、陆溪果蔬采摘旅游体验区、蜀茶湖公园等旅游项目，跟进三湖连江客天下旅游整体开发项目，促进雨燕航空项目尽快落地实施，推动嘉鱼县旅游市场由景点游览向高端休闲运动发展，由传统观光游向主题度假游转型。（牵头单位：县旅游开发建设作战指挥部；责任单位：县旅游局、县商务局、县招商局、各镇人民政府）

12.加快发展商贸服务业。进一步繁荣传统商业，保护和挖掘“嘉鱼麻糖”、“陆口麻花”等具有嘉鱼特色的传统品牌，扶持传统品牌做大做强。鼓励发展农超、农企、农旅对接等产销衔接模式。改造提升农贸市场。（牵头单位：县商务局；责任单位：县工商局）

13.积极引导文化、旅游、健康等新兴消费。（责任单位：县文体广新局、县旅游局、县民政局）

14.推进医养结合，发展养老服务业。（牵头单位：县民政局；责任单位：县卫计局）

15.大力推动农村电商发展，着力培育1-2家网上交易额过千万元电商企业，积极争创省级电子商务创业孵化示范基地。（责任单位：县商务局）

16.加快发展现代物流业。配套建设大型停车场和综合物流仓储等基础设施，逐步形成物流聚集中心。完善镇物流服务站及村物流服务点建设，逐步形成三级物流网络体系。（牵头单位：县交通局；责任单位：县住建局、县规划执法局、县商务局、各镇人民政府）

17.加快发展金融保险业。综合运用“窗口指导”、银企对接等方式，引导金融机构加大对实体经济扶持力度，不断创新信贷产品，切实做到不断贷、不压贷、不抽贷。（牵头单位：县政府金融办；责任单位：县人行、银监办）

18.加强“三农”政策性保险服务工作。（牵头单位：县委农办；责任单位：各镇人民政府）

二、增强城乡统筹的融合力，营造宜居宜业新环境

巩固基础建设，注重联动发展，突出生态文明建设，全力推进城乡一体化发展，加快建设宜居宜业宜游宜学宜养之城。

（一）坚持强基固本

19.强化基础设施建设，推进嘉鱼长江大桥、武深高速嘉鱼北段建设，新建临江山码头至三环线公路、官朱公路等工程，加快推进陆八舒旅游扶贫公路建设，启动武赤线官桥至石埠塘段、丁家曾至漆家山等一级公路建设，打通贯穿县域的快速通道。建成临江山5号、6号码头。（牵头单位：县交通局；责任单位：县国土资源局、县规划执法局、县水利局、县林业局、各镇人民政府）

20.继续争取国家电网建设资金，加快电力基础设施建设，强化电力保障。（责任单位：县供电公司）

21.继续推动光纤网络建设，建成数字化、双向化广电、移动网络，提升全社会信息化水平。（牵头单位：县经信局；责任单位：县电信公司、县移动公司、县联通公司）

（二）坚持城乡联动

22.推进前期PPP谋划项目落地实施，积极开展三湖大道延伸段、滨湖西路、方庄路等城区道路建设，实施迎宾大道、嘉鱼大道景观工程及北门湖公园、小雅公园建设，规划建设城区停车场，推进殷家坡、牛头山片区棚户区改造。（牵头单位：县住建局、县规划执法局；责任单位：县财政局、县城投公司、县房管局、鱼岳镇人民政府）

23.完成数字化城管指挥系统建设。(责任单位：县规划执法局)

24.启动自来水智慧供水管理平台建设。（责任单位：县住建局)

25.引导村民向农村新社区集中，促进人口就地城镇化。做到各镇都有1-2个新农村建设示范点。（牵头单位：县委农办；责任单位：各镇人民政府）

26.建设1-2个省级森林城镇，争创省级林业生态示范县。（牵头单位：县林业局；责任单位：各镇人民政府）

（三）坚持生态优先

27.严格落实环境影响评价和“三同时”制度，从源头控制污染源的产生。完成全县83个20蒸吨以下燃煤锅炉、251辆黄标车淘汰任务和3个农业面源污染治理项目。（牵头单位：县环保局；责任单位：县公安局、县质监局、县农业局、县畜牧局、各镇人民政府）

28.大力开展长江大保护和“三非三水”治理，加快饮用水源地水质自动监测站建设。（牵头单位：县环保局；责任单位：县公安局、县水务局、县交通局、县国土资源局、县安监局、县住建局、县规划执法局、县农业局、县畜牧局、县水产局、嘉鱼经济开发区、武汉新港潘湾工业园、各镇人民政府）

29.实施畜禽“三区”划分和污染处理。（牵头单位：县畜牧局；责任单位：县农业局、县环保局、县水产局）

30.对危化品企业进行腾退整顿。（牵头单位：县安监局；责任单位：县环保局、潘家湾镇人民政府、武汉新港潘湾工业园）

31.开展城区“禁鞭”工作。（牵头单位：县公安局；责任单位：县安监局、县环保局、县民政局、鱼岳镇人民政府）

32.推进河道湖泊生态修复，拆除西凉湖、斧头湖围网，对大岩湖、蜜泉湖和蜀湖等省管湖泊进行综合整治。（牵头单位：县水产局；责任单位：县水务局、县环保局、县农业局,陆溪、高铁岭、官桥、鱼岳、新街、潘家湾、渡普镇人民政府）

33.深入开展农村环境治理，完善农村保洁长效机制。（牵头单位：县委农办；责任单位：县住建局、各镇人民政府）

34.力促林业碳汇项目签约。（牵头单位：县林业局）

35.创建国家级嘉鱼县珍湖湿地公园。（牵头单位：县旅游开发作战指挥部；责任单位：县旅游局、陆溪镇人民政府）

三、增强改革开放的推动力，释放跨越发展新红利

全力推进改革创新，加大开放开发力度，建立更具活力、效率的体制机制，挖掘社会“双创”潜能，壮大新引擎，释放新红利。

（一）着力推进改革纵深发展

36.深化行政体制改革，清理整顿行政执法队伍，探索建立跨部门、跨行业综合执法机制。积极推进中介组织清理整治工作。（牵头单位：县编办；责任单位：县政府法制办、县政务服务中心、县工商局）

37.深化经济体制改革，充分挖掘市场活力，坚持“非禁即准”、“非禁即入”，完善负面清单，鼓励各类市场主体平等进入清单之外领域。（牵头单位：县发改局；责任单位：县财政局、县人社局、县工商局、县商务局、县科技局、县政务服务中心）

38.推进供给侧结构性改革，重点抓好“三去一降一补”，优化资源配置，提升产能过剩行业的集中度和核心竞争力。（牵头单位：县发改局；责任单位：县经信局、县交通局、县国土资源局、县农业局、县住建局、县商务局、县政务服务中心、县财政局、县国税局、县地税局、县人行）

39.鼓励农民进城务工购房，结合棚户区改造货币化安置、保障性住房及租赁市场发展去库存。（牵头单位：县住建局；责任单位：县房管局）

40.进一步推进结构性减税降费，切实降低企业税费、融资、交易、物流、用能等成本。（责任单位：县财政局、县国税局、县地税局、县商务局、县交通局、县工商局、县供电公司）

（二）着力挖掘社会“双创”潜能

41.扶持大众创业、鼓励万众创新，依托开发区创业孵化园，引进、扶持一批“双创”企业发展壮大，搭建科技投融资平台，帮助企业申报国家中小企业创新基金、产业振兴、转型升级等各类项目资金。开好2017年度产学研合作洽谈会，推动高校科研院所科技成果在我县转化。（牵头单位：县科技局；责任单位：县科协、县人社局、嘉鱼经济开发区、武汉新港潘湾工业园）

42.畅通人才创新创业绿色通道，引进一批高层次人才来嘉鱼发展。（牵头单位：县人社局；责任单位：县人才办、县编办）

43.加大创新型企业家、科技创新带头人引进培育力度，把县经济开发区打造成为全县创业洼地和创新高地。（牵头单位：县经济开发区；责任单位：县科技局、县科协、县经信局）

（三）着力提升对外开放水平
