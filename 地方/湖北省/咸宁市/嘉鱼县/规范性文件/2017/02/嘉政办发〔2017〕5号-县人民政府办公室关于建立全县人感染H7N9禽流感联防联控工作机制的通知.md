# 县人民政府办公室关于建立全县人感染H7N9禽流感联防联控工作机制的通知

嘉政办发〔2017〕5号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

为全面做好我县人感染H7N9禽流感防控工作,保障人生命健康安全，经县政府研究决定，建立全县人感染H7N9禽流感内部联防联控工作机制,并制定《嘉鱼县人感染H7N9禽流感联防联控工作方案》（见附件）。请各级各部门结合实际,按照方案要求,分工负责,密切配合,共同做好防控工作。

附件:嘉鱼县人感染H7N9禽流感联防联控工作方案

嘉鱼县人民政府办公室

2017年1月22日
