# 县人民政府关于2017年造林绿化工作的意见

嘉政发〔2017〕2号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

2017年是巩固绿满嘉鱼行动成果的关键年。为全面落实省市关于生态文明建设的总体部署，扎实推进新一轮绿色嘉鱼建设，现就做好2017年造林绿化工作提出如下意见：

一、 指导思想

以邓小平理论和“三个代表”重要思想和科学发展观为指导，深入贯彻落实习近平总书记关于生态文明建设系列重要讲话精神，着力在生态建设上取得新成就，切实改善人居环境，提升民生福祉；解决森林资源总量不足、质量不高、功能脆弱和美丽乡村建设进一步提档升级等问题，坚持增绿提质、增效并重，超额完成绿满荆楚行动任务，不断把国土绿化推向深入，为建设湖北经济强县、打造临港生态新城提供有力的生态支撑和保障。

二、基本原则

1.坚持生态效益、经济效益和社会效益相统一，以生态效益为优先目标，以经济和社会效益为根本保障；

2.坚持统筹规划与分类指导相结合，因地制宜，分区施策，体现区域特色；

3.坚持政府引导与市场主体相促进，政府补贴与造林业主投入相结合，以造林业主自筹为主；

4.坚持“谁造谁有、合作共有”、“谁投资、谁受益”的政策，鼓励各类市场投资主体参与国土绿化；

5.坚持造林绿化与资源管护相协调，扩大新造林，管好现有林，形成造管一体的良性机制；

6.坚持科技兴林与改革活林相一致，强化国土绿化的科技支撑和改革推动。

三、目标任务

全县完成造林绿化面积20000亩（其中高效油茶林基地5000亩，速生丰产林示范基地5000亩，其他村庄、通道沿江防护林等生态10000亩），新建花卉苗木基地4个，面积350亩；争创省级绿色示范村庄6个、县级绿色示范村庄14个；争创省级森林城镇1-2个。

四、工作重点

按照平原速生丰产林、丘陵木本油料林的布局要求，突出通道绿化、村庄绿化和美丽乡村建设，切实抓好因灾受损林业生产恢复和发展。

五、工作措施

（一）加强组织领导。各镇要把林业开发作为当前农村工作的中心任务，党政主要领导亲自抓，分管领导具体抓。各级领导要带头办好造林示范点，县级领导示范基地要求连片面积300亩以上，镇级领导示范基地要求连片面积150亩以上。林业开发任务逐级分解，落实到人，签订责任状，纳入年终责任制考核。

（二）强化政策扶持。继续采取项目贴、政府奖、部门帮、乡镇拿、业主投的办法，积极筹措造林资金，增强林业开发活力。县政府继续给予绿满造林奖补支持资金700万元（其中湿地公园前期建设费100万元），用于对全县村庄绿化、通道绿化、速生丰产林和木本油料林的奖补。继续将花卉苗木示范区纳入县农业“八大示范区”建设内容，实行以奖代补；继续实行油茶财政专项补贴政策。积极向上争取项目资金，利用林业项目实施，带动林业发展。

（三）创新造林机制。进一步深化林业改革，建立经营主体多元化，促进全县森林资源资产依法、公开、有序流转，保障林业产权公开、公平、公正交易，切实提高林农收入。进一步广开门路，建设林业板块基地，形成“大开放、大开发、大发展”的格局。

（四）坚持科技兴林。各镇和相关职能部门要紧紧围绕林业开发主动做好各项服务工作。县林业局进一步完善全县林业开发规划，林业技术人员要深入林业第一线，到实地指导开发。各镇要迅速对种苗资源进行摸底调查、调剂余缺，确保种苗足额供应和种苗质量。要建立林区森林防火群防联防机制，从重从快打击盗伐林木、毁坏幼林等违法行为，维护造林业主权益，巩固造林成果。

嘉鱼县人民政府
