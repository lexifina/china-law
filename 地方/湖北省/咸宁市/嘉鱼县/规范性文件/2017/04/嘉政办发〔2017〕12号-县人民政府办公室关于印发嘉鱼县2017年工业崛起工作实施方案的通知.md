# 县人民政府办公室关于印发嘉鱼县2017年工业崛起工作实施方案的通知

嘉政办发〔2017〕12号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

经县人民政府同意，现将《嘉鱼县2017年工业崛起工作实施方案》印发给你们，请认真遵照执行。

嘉鱼县人民政府办公室

2017年3月6日

嘉鱼县2017年工业崛起工作实施方案

为进一步加快全县工业经济发展，突出工业在县域经济中的主导地位，推动全县经济社会又好又快发展，县委、县政府将在2017年突出实施“工业崛起”战略，现结合实际，特制定本实施方案。

一、指导思想

深入贯彻十八届五中、六中全会精神，以五大发展理念为指导，坚持“稳中求进”的总基调，积极实施工业强基、园区转型、集群发展、品牌强工“四大工程”，坚持“工业强县”发展战略不动摇，以园区建设为载体，以招商引资和项目建设为抓手，发展壮大冶金、纺织、建材、装备制造四大支柱产业，培育发展特色产业和优势骨干企业，促进工业经济量的扩张和质的提升，努力实现工业经济跨越发展。

二、工作目标任务

计划全年完成工业总产值550亿元，实现工业增加值增长8.2%；力争完成新增规模以上工业企业22家；工业技改投资增幅22%；全年新签约工业项目60个、新开工项目36个、新投产工业项目36个，招商引资工业项目到位资金143亿元；完成工业固定资产投资203亿元，增长19 %，工业固定资产投资占全社会固定资产投资比重达到65%；高新技术企业新增数13个，高新技术产业增加值占GDP比重达到9.5%；工业增值税绝对值1.41亿元，增幅20.2%。

三、工作内容及责任分解

实施工业产业升级工程。改造传统产业，发展新兴产业，壮大骨干企业，全力打造十亿级企业、百亿级产业。深入研究和落实国家和省经济产业政策，加快培育发展绿色新产业，积极实施创新驱动，加快产业转型升级，着力培育经济发展新动能。全力推动高端绿色纺织、特种冶金、新型建材、先进装备制造等产业集聚发展。积极培育以高端缆索、汽车零配件等为主体的先进装备制造；以生物医药、电子信息、循环经济等为主体的战略性新兴产业；以新技术、新模式改造提升传统产能，推动传统优势产业迈向百亿产业。科学调度好全县工业经济运行，做好经济运行要素保障工作，及时协调化解经济发展中的突出问题，努力盘活困难企业。建好规模企业成长项目库，力争培育主营业务收入过10亿元企业13家，过70亿元企业1家，打造一批“企业航母”。努力实现工业增加值同比增长8.2%，力争新增规模以上工业企业22家，工业技改投资增速达22%。（责任单位：县经信局、各镇人民政府、嘉鱼经济开发区、武汉新港潘湾工业园）

实施工业后劲储备工程。依托特色资源优势和已形成的产业基础，组织论证、储备一批工业项目，加大宣传推介力度，创新招商引资方式，拓宽招商引资领域，引进一批产业链长、关联度强、技术含量较高并具有持续发展潜力的项目。突出“引大引强”及行业领先企业，大力引进行业50强企业落户嘉鱼，争取引进一批投资过10亿元大项目形成产业集群的龙头，发挥带动效应。全年工业招商引资落地资金达到143亿元以上，全年引进工业项目60家以上，其中投资过千万元的项目20家以上，过亿元的项目3家以上。（责任单位：县招商局、各镇人民政府、嘉鱼经济开发区、武汉新港潘湾工业园、县直相关单位）

实施工业投资支撑工程。深入研究国家产业政策，引导工业企业投资项目落地，努力实现全县工业固定投资203亿元，同比增长19%。及时帮助工业企业做好工业项目备案、核准等工作，实现我县工业固定资产投资占全社会固定资产投资比重达到65%以上。（责任单位：县发改局、各镇人民政府、嘉鱼经济开发区、武汉新港潘湾工业园）

实施工业科技强工工程。切实抓好全县高新技术产业发展工程、科技企业创业与培育工程、专利倍增工程和科技成果大转化工程，帮助企业做好高新技术企业申报工作，不断提升市场竞争力，力争年内新增高新技术企业13家，高新技术产业增加值占全县GDP的比重达到9.5%以上。（责任单位：县科技局、各镇人民政府、嘉鱼经济开发区、武汉新港潘湾工业园）

实施工业园区转型工程。依托沿江优势，优化“一区四园”布局，明确园区发展定位，加快把经济开发区建成全省低碳经济示范园区，武汉新港潘湾工业园建成省级工业园，高铁临江产业园、嘉安物流园建成省级循环经济园，渡普生态产业园建成省级生态园。多种形式创新产城融合模式，推动嘉鱼产业新城PPP项目实施，加快创业平台和产业孵化园建设。坚持七通一平基础建设，配套完善园区产业发展基础服务工程，夯实产业发展平台。（责任单位：嘉鱼经济开发区、各镇人民政府、武汉新港潘湾工业园）

实施工业质效回馈工程。抓好全县工业企业增值税征缴工作，实现全县工业增值税1.41亿元，同比增长20.2%。（责任单位：县国税局、各镇人民政府、嘉鱼经济开发区、武汉新港潘湾工业园）

四、实施步骤

整个活动分为准备发动、组织实施和检查考评三个阶段：

（一）准备发动阶段（2017年元月—2月）。开展调查摸底，分析测算，科学制定工业经济增长速度及经济效益等指标，制定支持工业崛起的政策意见和具体措施。各有关单位积极发动，分类推动相关工作，共同营造政企同心发力争创工业崛起氛围。

（二）组织实施阶段（2017年2月—12月）。各有关单位要积极行动，围绕发展目标和重点任务，采取有力措施，精心组织实施。县“工业崛起”工作领导小组每季度对全县工业崛起战略开展情况进行督查、评比、小结。

（三）考核验收阶段（2018年元月）。对2017年“工业崛起”实施情况进行考核、验收，总结经验，表彰奖励在工作中作出较大贡献的镇、部门、企业和个人。

五、保障措施

（一）加强领导，形成发展合力。县委、县政府成立“工业崛起”工作领导小组，对工作开展实行统一领导。各镇、各单位要切实加强和改进对工业工作的领导，党政“一把手”要自觉把工作重心转移到工业经济工作上来，根据各自职责，制定相关的工作措施，科学决策，密切配合，做到责任、政策、措施和督查“四个落实”，形成发展工业的强大合力。

（二）创新机制，夯实发展基础。抓住有利机遇，争取有关优惠政策。制定加快绿色产业发展、重点优势骨干企业、中小企业发展扶持办法，为工业经济发展提供政策支持。健全完善项目库，组织论证一批符合国家产业政策的工业项目，为项目引进奠定基础。积极争取土地优惠政策和工业用地指标，保障工业发展用地。探索建立多元化的融资体制，鼓励各类投资主体以各种形式参与建设和经营，建立中小企业信用担保体系，大力推进银企合作对接机制，缓解企业发展的资金制约瓶颈问题。

（三）优化环境，提升服务水平。严格落实招商引资项目“代办制”，建立责任追究办法，进一步简化审批程序，提高服务效率。重点项目实行“一个项目、一套班子、一套方案、一套措施、一抓到底”的县级领导包保，部门、乡镇联动的责任机制。定期召开工业经济分析例会，研究解决工业运行和项目建设中存在的问题，努力营造优质、快捷、高效的服务环境。

（四）建立健全考核机制。建立完善工业发展目标责任考核体系，实施一季度一拉练、年终考评的办法，对为工业发展作出突出贡献的镇、部门、企业以及个人予以表彰;将考评结果与年终综合考评相结合，根据工业发展目标责任考核结果，在年终综合考评中适当采取加减分办法。
