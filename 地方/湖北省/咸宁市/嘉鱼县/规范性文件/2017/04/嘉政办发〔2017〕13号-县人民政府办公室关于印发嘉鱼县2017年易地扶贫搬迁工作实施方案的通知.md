# 县人民政府办公室关于印发嘉鱼县2017年易地扶贫搬迁工作实施方案的通知

嘉政办发〔2017〕13号

各有关镇人民政府，县政府有关部门：

经县人民政府研究同意，现将《嘉鱼县2017年易地扶贫搬迁工作实施方案》印发给你们，请认真遵照实施。

嘉鱼县人民政府办公室

2017年3月7日

嘉鱼县2017年易地扶贫搬迁工作实施方案

根据国家发展改革委、国务院扶贫办、财政部、国土资源部、中国人民银行《关于印发“十三五”时期易地扶贫搬迁工作方案的通知》（发改地区〔2015〕2769号）、《关于印发加快推进全省易地搬迁工作实施方案的通知》（鄂发改地区〔2015〕796号）要求，为加快推进全县易地扶贫搬迁工作，切实解决居住在“一方水土养不起一方人”地方建档立卡贫困户的生存与发展问题，现结合我县实际，制定本方案。

一、主要目标

2017年，易地扶贫搬迁工作目标是：做到“户有所居，人有所养，发展共享，全面小康”，达成“搬得出，稳得住，能致富”的预期目标，促成人口、资源、环境协调发展。

二、项目实施主体

嘉鱼县易地扶贫搬迁工作分别以陆溪镇、高铁岭镇、官桥镇、新街镇、渡普镇人民政府为实施主体。

三、搬迁规模及安置方式

（一）搬迁总规模

2017年，拟搬迁718户2175人，住宅面积53080平方米。

（二）安置方式

采取集中安置和分散安置相结合，以集中安置为主。10户（含）以上为集中安置，集中安置主要以中心村（含农民新村）、城镇、产业园、“五保”集中等方式进行；分散安置主要以分散建房、插花等方式进行安置。

四、主要建设任务

（一）住房建设

1.建设面积和户型。2017年全县安置点安置建房718套计53080平方米。共有六种户型：1人户按25平方米96户、1人户按40平方米17户、2人户按50平方米182户、3人户按75平方米182户、4人户按100平方米115户、5人户及以上按125平方米126户。房屋只建一层，地基按两层设计，以满足建档立卡贫困户稳定脱贫后的续建需要。

2.建房成本。建档立卡贫困户搬迁建房成本原则上按每平方米800元左右掌握，具体价格成本由县住建局负责依据设计情况，进行差异化如实核定，报县易地扶贫搬迁领导小组审定。

3.税费政策。国家税收有减免政策的按政策落实到位，没有减免政策的按最低标准执行，报县政府审定。

4.奖励政策。实施易地扶贫搬迁，建新必须拆旧，旧房拆除的，按人均0.25万元进行奖励，每户最高奖励1万元。

（二）基础设施配套建设

集中安置区红线范围内的征地、地基平整及水、电、路、网等基础设施建设，按照每户3万元把握；分散安置点基础设施配套建设按照每户1.5万元把握，按程序报批，建设资金由县人民政府统筹安排。

（三）配套公共服务设施

学校、卫生室等公共服务设施，由镇政府申请，县教育局、县卫计局根据学校和卫生室布局情况统筹安排，报县易地扶贫搬迁领导小组审核。

（四）土地整治

搬出的宅基地全部进行复垦。

（五）后续帮扶脱贫

通过产业发展、教育培训、临近就业等实现脱贫。

五、资金来源及使用管理

2017年易地扶贫搬迁项目资金来源主要有中央预算内投资、专项建设基金、地方政府债券和融资贷款等。县城投公司下属的嘉鱼县波涛旅游投资开发有限公司（以下简称波涛公司）为我县易地扶贫搬迁融资平台和易地扶贫搬迁资金具体管理单位，统一管理全县各项易地扶贫搬迁资金，设立专户、专帐管理。波涛公司要统筹做好年度计划，及时组织资金到位，根据工程建设进度保证及时、足额到位。

六、配套政策

（一）住房政策

国有土地安置的，按照相关规定办理房屋产权，5年内不能进行交易；集体土地安置的，按照农村宅基地进行登记管理。五保户的房屋产权归村集体所有。落实减免相关税费政策，采取政府主导，代建企业微利建设等措施降低建房成本。

（二）土地政策

严格执行土地利用规划，新增建设用地指标要优先满足贫困地区易地扶贫搬迁建房需求，在安排年度新增建设用地指标时计划单列。镇政府及时组织拆除旧房，复垦旧宅基地、旧村庄。允许城乡建设用地增减挂钩节余指标在省域范围内交易，纯收益部分用于易地扶贫搬迁。贫困户新房产权办理与拆除旧房挂钩，搬进新房后允许有过渡期，但不超过1年。

（三）产业发展扶持政策

充分运用好《嘉鱼县精准扶贫产业扶持实施办法》等有关政策，加大扶持产业发展。引导劳动密集型产业向贫困地区转移，支持企业向产业化、规模化、集群化发展。加强市场建设。在项目、资金上给予倾斜支持，大力发展特色优势产业。

（四）社会保障政策

1.合力改善公共服务。不断完善基础设施，重点推进迁出区和安置区土地整治，加快中低产田改造，开展土地平整，提高耕地质量。推进节水改造和小型农田水利建设。加快通村道路建设，继续推进水电新农村电气化建设和农村电网改造升级。普及信息服务，优先实施村村通有线电视、电话、互联网工程。

2.不断完善社会保障。逐步提高农村最低生活保障和五保供养水平，切实保障没有劳动能力和生活常年困难扶贫对象的基本生活。健全自然灾害应急救助体系，完善受灾群众生活救助政策。加快新型农村社会养老保险制度覆盖进度，支持贫困地区加强社会保障服务体系建设。加快农村养老机构和服务设施建设，解决扶贫对象养老问题。做好安置点规划，制定和完善扶贫对象就业、社会保障和户籍制度改革等政策。

七、保障措施

（一）加强组织领导

各镇成立镇领导、各部门干部参与的镇易地扶贫搬迁工作小组，成立工作专班，提前做好项目前期工作，完成项目的具体实施工作，确保年底完成易迁任务。

（二）落实部门职责

各部门要通力合作，开辟“绿色通道”，全力推进易地扶贫搬迁工程顺利实施。县委农办负责对安置点的产业发展情况进行督导与监督；县发改局负责争取中央预算内易地扶贫搬迁投资计划和专项建设基金，下达当年中央预算内易地扶贫搬迁投资计划，协调解决好实施工程中具体问题；县扶贫办负责精准锁定年度易地搬迁对象，负责脱贫的贫困人口的销号管理；县财政局负责筹措、拨付、监管地方政府债务资金和贷款贴息资金，负责制定并落实《嘉鱼县易地扶贫搬迁资金管理办法》，加强经常性监督；县国土资源局负责保障易地扶贫搬迁工程项目建设用地，安排好用地指标；县教育局负责调整优化学校布局规划，优先安排安置点中小学、幼儿园项目，保障搬迁户子女就近方便入学；县民政局负责社会救助及社区建设管理有关工作，将符合条件的搬迁群众纳入最低生活保障范围；县人社局负责搬迁群众职业技能培训、创业培训和就业指导工作；县住建局和规划执法局负责易地扶贫搬迁安置点项目红线图、户型设计、建筑设计图的送审、工程质量安全监管以及垃圾污水设施的配套等；县公管局负责指导各镇项目招标工作；县交通运输局负责安置区外道路配套建设；县供电公司负责安置区供配电设施建设，做好供电服务；县水务局负责搬迁群众饮水安全及相关水利设施建设；县农业局负责扶持搬迁群众后续产业发展；县林业局负责对易地扶贫搬迁建设中确需占用的林地，优先办理林地手续，支持迁出区退耕还林等生态建设项目，支持迁出区生态修复和林业产业发展；县环保局负责进行易迁项目环境影响登记的备案、审查工作；县卫计局优先安排安置点公共卫生服务体系建设；县城投公司根据年度实施方案计划及时拨付资金；县审计局负责易地扶贫搬迁资金的审计监督；县电信、移动、联通等相关部门要积极支持易地扶贫搬迁工作；相关镇人民政府负责复核村委会申报表格材料，汇总上报搬迁户花名册；针对各搬迁户填报的意愿，结合土地利用总体规划、新农村建设规划、产业发展规划等专项规划，统筹考虑搬迁安置方式、安置地点、搬迁时间、脱贫措施，涉及集中安置的安置区的选址要及时与国土、林业、规划等相关部门衔接，公共服务项目要及时与教育、卫生、文体等部门衔接，形成共识后，制订总体规划方案和分项规划方案，报县易迁办；负责项目的初验，通过后向县易迁办提出验收申请；负责办理搬迁户的入住手续，组织搬迁户入住。

（三）强化督查考核

将各单位推进易地扶贫搬迁工作纳入县政府年度目标绩效考核，强化县政府督查力度，由县易迁办督办落实。严格按照省、市易地扶贫搬迁工作数据统计要求落实“月报告”制度，每月1日，各镇将上个月易地扶贫搬迁工作情况报县易迁办，县易迁办审核汇总后上报，同时通报全县。在此基础上，县易迁办每周督查各安置点建设进度，以文字、图片等形式向县易地扶贫搬迁工作领导小组报告，便于掌握工作动态，及时调度、科学决策。对数据上报不及时、工作进度滞后的单位提出预警通知、约谈提醒；对工作推进不力、未按期完成易地扶贫搬迁工作任务的镇，对其主要负责人进行约谈，并启动问责程序。
