# 县人民政府办公室关于下达2017年度科技创新综合考评指标的通知

嘉政办发〔2017〕14号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

为全面贯彻落实全国“科技三会”、全省科技创新大会和全市科技工作会议精神，深入实施创新驱动发展战略，推进我县县域经济竞进提质，根据《省科技厅关于印发〈2016年湖北省市县科技创新综合考评指标体系〉的函》（鄂科技函办〔2016〕205号）要求，将各项考评指标分解下达到各镇、嘉鱼经济开发区和武汉新港潘湾工业园，请各单位高度重视，及时分解落实，认真组织实施，确保任务圆满完成。

科技创新综合考评指标分配说明

一、高新产值：按照开发区、工业园、各镇所具备的高新技术企业和高新技术备案企业2016年全年总产值的合计数量进行分配。没有高新技术企业的镇，根据该镇规上企业中具备的高新技术产品产值进行合理分配。

二、申请专利数：全县目标任务共300件，按照开发区、工业园、各镇所拥有的规上企业个数占全县规上企业个数的比例进行分配。

三、通过认定的高新技术企业数：全县任务数16个，按照县开发区3个，潘湾工业园5个，镇各1个的任务进行分配。

四、规上企业新产品销售收入：全县目标任务共50亿元，按照开发区、工业园、各镇2016年的规上企业总产值占全县总产值的比例进行分配。

五、引进转化成果数：按照开发区、工业园、各镇所具有的高新技术企业个数进行分配，没有高新技术企业的镇各分配1个。

六、规上企业研发经费：全县目标任务共4亿元，按照开发区、工业园、各镇的规上企业2016年总产值占全县总产值的比例进行分配。

七、规上企业研发人员：全县目标任务共1500人，按照开发区、工业园、各镇所拥有的规上企业个数占全县规上企业个数的比例进行分配。
