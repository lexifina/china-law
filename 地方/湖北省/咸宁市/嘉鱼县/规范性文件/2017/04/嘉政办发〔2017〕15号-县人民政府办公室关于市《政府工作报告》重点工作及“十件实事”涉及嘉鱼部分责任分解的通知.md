# 县人民政府办公室关于市《政府工作报告》重点工作及“十件实事”涉及嘉鱼部分责任分解的通知

嘉政办发〔2017〕15 号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

为贯彻落实《市人民政府办公室关于分解落实<政府工作报告>确定的2017年重点工作及“十件实事”的通知》（咸政办发〔2017〕1号）精神，按照县政府统一部署，现对市《政府工作报告》涉及我县工作进行责任分解（详见附件）。请各责任单位严格按照责任分工，逐条对照，进一步明确目标，压实责任，细化措施，抓好组织实施。

附件：1.2017年市《政府工作报告》重点工作涉及我县部分责任分解

2.2017年市政府“十件实事”责任分解

嘉鱼县人民政府办公室

2017年3月22日

附件1

2017年市《政府工作报告》重点工作

涉及我县部分责任分解

1.全面启动潘家湾港区通用码头等“十三五”重大规划项目，重点抓好武深高速公路嘉鱼北段等重点项目。（责任单位：县交通运输局、新街镇人民政府、潘家湾镇人民政府）

2.完善“1+5+X”协同创新体系，推动企业创新主体建设。（责任单位：县科技局、县经信局、嘉鱼经济开发区、武汉新港潘湾工业园）

3.加大棚户区改造力度，推进租购并举，推动商品房供给结构优化，确保商品住房库存消化周期控制在10个月左右。（责任单位：县住建局、县房管局）

4.加快推进嘉鱼长江大桥等项目建设。（责任单位：县交通运输局、新街镇人民政府、潘家湾镇人民政府）

5.优化物流产业布局、建设一批商业中心、特色商业街、乡镇商贸中心等，打造嘉鱼农产品冷链物流集散中心。（责任单位：县交通运输局、县商务局、县农业局）

6.支持县市区按各自定位突出优势、错位发展、争先进位。（责任单位：县直各单位、各镇人民政府）

7.建设咸嘉生态文化城镇带和幕阜山绿色产业带，推进潘家湾重点镇建设，构成“两带牵引、多点支撑”发展格局。（责任单位：县住建局、新街镇人民政府、潘家湾镇人民政府、渡普镇人民政府）

8.落实国家主体功能区规划，制定实施《咸宁市生态功能区划》，加快构建“两带两河两湖生态屏障”。（责任单位：县发改局、县住建局、县水务局、县水产局、各镇人民政府）

9.落实长江大保护职责，重点推进余码头二站、陆水干流防洪治理、斧头湖西凉湖湖堤加固工程建设，确保“满城净水入江，一江清水东流”。（责任单位：县水务局、县环保局、县交通运输局、县公安局、县国土资源局、各镇人民政府）

10.突出“3+X”产业扶贫，推广“合作社、龙头企业、能人大户、现代服务业+贫困户”四种带动模式，着力增强贫困村和贫困户的自我造血能力。创新搬迁扶贫，推动安居点基础设施建设和脱贫产业培育“双轴并进”，全市易地搬迁8448户、24291人。实施贫困户子女“9+3”免费教育，阻断贫困代际传递。推进健康扶贫，实施农村医疗精准救治“五大工程”，对所有建档立卡贫困人口参加城乡居民医疗保险实行补贴，确保参保率达到100%，为贫困人口购买商业补充医疗保险。推进项目扶贫，坚持项目向贫困村倾斜、资金向贫困村聚拢，着力改善贫困村生产生活条件。开展金融帮扶，建立完善风险补偿金，充分调动银行信贷积极性，着力解决贫困地区农户和企业贷款难问题。开展“三扶一助两促进”活动，激发群众内生动力，促进精神脱贫。确保10万贫困人口脱贫，103个贫困村脱贫出列。（责任单位：县扶贫办、县委农办、县发改局、县教育局、县卫计局、县人社局、县政府金融办、各镇人民政府）

11.完善公共文化服务体系，实施文化精品工程，支持嘉鱼创建省级公共文化服务体系示范区。（责任单位：县文体广新局）

附件2

2017年市政府“十件实事”责任分解

实事一：全市城镇新增就业3.5万人，城镇登记失业率控制在4.5%以内。（责任单位：县人社局、各镇人民政府）

实事二：新开工棚户区改造11219套，基本建成1845套。（责任单位：县住建局、县房管局）

实事三：全市建设食品追溯体系单位或名厨亮灶示范单位600家，市城区建成1个日处理能力约100吨的餐厨垃圾无害化处理场所。（责任单位：县食药监局、各镇人民政府）

实事四：实施交通安全生命防护工程，整治交通安全隐患800处，改造农村危险路段1000公里。（责任单位：县公安局、县交通运输局、各镇人民政府）

实事五：建立机关事业单位与企业职工相同的统帐结合的基本养老保险制度，整合城乡居民基本医疗保险制度。（责任单位：县人社局、县卫计局、各镇人民政府）

实事六：提高全市80岁以上老人高龄补贴标准，80-99岁60元/人月；100岁以上300元/人月。（责任单位：县民政局、各镇人民政府）

实事七：完成三分之一建档立卡贫困户饮水安全问题。（责任单位：县水务局、县扶贫办、各镇人民政府）

实事八：新建村级邮政站所200家。（责任单位：县邮政管理局、各镇人民政府）

实事九：实现农村宽带全覆盖、光纤村村通。（责任单位：县经信局、各镇人民政府）

实事十：完成西凉湖、斧头湖17.4万亩围网围栏拆除。（责任单位：县水产局、官桥镇人民政府、新街镇人民政府、潘家湾镇人民政府、渡普镇人民政府）
