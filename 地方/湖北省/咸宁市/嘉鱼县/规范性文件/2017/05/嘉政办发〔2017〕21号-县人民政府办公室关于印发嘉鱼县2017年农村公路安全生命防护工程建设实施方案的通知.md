# 县人民政府办公室关于印发嘉鱼县2017年农村公路安全生命防护工程建设实施方案的通知

嘉政办发〔2017〕21号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

经县人民政府同意，现将《嘉鱼县2017年农村公路安全生命防护工程建设实施方案》印发给你们，请认真遵照实施。

嘉鱼县人民政府办公室

2017年4月28日

嘉鱼县2017年农村公路安全生命防护工程

建设实施方案

为贯彻落实《省人民政府办公厅关于推进公路安全生命防护“455”工程的实施意见》（鄂政办发〔2017〕11号）、《市人民政府办公室关于印发2017年咸宁市农村公路安全生命防护工程建设实施方案的通知》（咸政办发〔2017〕14号）等文件要求，深化全县农村公路安全隐患治理，推进全县农村公路安全生命防护工程建设，提升农村公路通行安全保障能力，维护人民群众生命财产安全，特制定本方案。

一、指导思想

深入贯彻党的十八大和十八届三中、四中、五中、六中全会精神，认真落实习近平总书记“建好、管好、护好、运营好”农村公路的批示精神和省政府、市政府关于实施公路安全生命防护工程的工作部署，牢固树立以人为本、安全发展理念，坚守发展决不能以牺牲人的生命为代价的红线，以防事故、保安全、保畅通为目标，以治理农村公路安全隐患为抓手，坚持建设、管理、养护、安全并举，不断完善农村公路安全设施，全面提升农村公路安全水平，促进全县农村公路交通安全形势持续稳定发展。

二、基本原则

（一）坚持突出重点、分步实施。着力整治农村公路事故多发易发路段、急弯陡坡、临水临崖等重点路段安全隐患，满足群众安全出行基本需要。

（二）坚持分级管理、分级负责。落实各镇人民政府的主体责任和有关部门的监管责任。

（三）坚持政府主导、社会参与。切实加大公共财政投入力度，同时注重发挥市场机制作用。

三、目标任务

（一）总体目标。按照“先急后缓，先重点、后一般”的建设原则，2017年全县农村公路安全生命防护工程建设总体目标任务是：

1.全县农村公路安全生命防护工程实施里程确保完成217.3公里，力争完成258.4公里；

2.消除道路安全隐患点（路段）100处；

3.农村道路交通安全管理“两站两员”（即在各镇设置交通安全管理站和交通管理员，在全县82个行政村设有交通安全劝导服务站和交通安全协管员）建设覆盖率达到100%。

四、工作安排

（一）准备阶段（3月1日-5日）。成立生命安全防护工程领导小组并制订实施方案。

（二）排查阶段（3月6日-31日）。完成258.4公里农村公路安全隐患排查及相关信息采集，建立台帐资料。

（三）规划设计阶段（4月1日-30日）。完成设计招投标、设计院委托书、一阶段施工设计等工作。

（四）工程实施和验收阶段（5月1日-12月31日）。对生命安全防护工程进行施工及验收。

（五）目标考核阶段（2017年11月）。县政府按照市政府要求组织目标考核并通报有关情况。

五、工作职责

县委宣传部：负责全县农村公路安全生命防护工程建设的宣传报道及典型宣传工作；

县考评办：负责组织制定全县农村公路安全生命防护工程建设目标考核细则，统筹开展相关考核工作；

县政府督查室：负责组织领导小组有关成员单位定期开展专项督查，通报督查结果；

县财政局：负责农村公路安全生命防护工程县级财政资金的统筹落实；

县交通运输局：负责全县农村公路安全生命防护工程硬件建设，组织开展全县农村公路安全生命防护工程的隐患排查，制订2017年度全县农村公路安全生命防护工程建设规划及年度计划，做好全县农村公路安全生命防护工程建设技术指导，参与项目管理与质量监督，争取部省级补助资金落实到位；

县公安局：负责全县农村公路安全生命防护工程相关配套建设，会同县交通运输部门开展隐患排查及治理工作，加强农村公路车辆管理，打击损毁公路设施行为；

县安监局：组织有关单位定期开展农村公路安全生命防护工程建设项目的安全生产检查，查处安全生产违法违规行为。
