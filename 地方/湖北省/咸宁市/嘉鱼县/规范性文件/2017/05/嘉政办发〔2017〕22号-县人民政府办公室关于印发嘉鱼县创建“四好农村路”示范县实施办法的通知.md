# 县人民政府办公室关于印发嘉鱼县创建“四好农村路”示范县实施办法的通知

嘉政办发〔2017〕22号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

经县人民政府同意，现将《嘉鱼县创建“四好农村路”示范县实施办法》印发给你们，请认真组织实施。

嘉鱼县人民政府办公室

2017年4月28日

嘉鱼县创建“四好农村路”示范县实施办法

为积极探索我县农村公路建、管、养、运一体化发展模式，创新农村交通工作思路，推动农村交通运输健康有序发展，根据省交通运输厅《关于印发<湖北省“四好农村路”示范县创建实施方案>的通知》（鄂交农〔2017〕90号）文件精神，现结合我县农村公路实际，制定该实施办法。

一、指导思想

根据省交通运输厅《关于印发<湖北省“四好农村路”示范县创建实施方案>的通知》（鄂交农〔2017〕90号）文件要求，以将创建农村公路“建设好、管理好、养护好、运营好”为目标，牢固树立以人为本、安全发展的理念，不断完善农村公路服务功能，促进农村公路可持续发展。

二、总体要求

创建“四好农村路”，是为了深化我县农村公路管理体制改革，提升农村公路档次，实施农村公路安全生命防护工程、危桥改造，发展农村客运，建设美丽新农村。通过“四好农村路”创建活动，以点带面，全面提高我县农村公路发展水平。

三、创建内容

（一）农村公路建设方面。

1.严格执行省、市有关农村公路建设政策，按期完成省交通运输厅创建“四好农村路”示范县工作任务。在建设的同时将农村公路排水及生命安全防护设施与主体工程同步设计、同步实施。

2.进一步完善农村公路路网结构，加大对非建制村和撤并村的道路建设，使全县各镇、村组的农村公路全部实现路面硬化。

3.加强农村公路建设资金落实和管理。农村公路建设项目实施“八公开”（即农村公路建设计划公开、补助政策公开、招投标公开、施工管理公开、质量监管公开、资金使用公开、工程验收公开、考评结果公开）。规范农村公路建设补助资金管理，严禁超期结转结余、挪用、挤占等违规行为。

（二）农村公路管理方面。

1.建立责权明确的农村公路管养体系。落实农村公路监管责任和主体责任，县农村公路养护管理所负责全县农村公路建设补助资金的争取、质量指导及工程验收，农村公路建设、日常养护由各镇，行政村负责，组建路产路权保护队伍，实行县有路政员、镇有监管员、村有护路员。

2.依法加强农村公路路政管理。依据《公路法》《公路安全保护条例》《路政管理规定》等法律法规，对农村公路实施有效路政管理，使农村路域环境得到有效改善。落实路政巡查制度，对违法开设道口和违章建设、损坏农村公路及公路附属设施等违法案件进行查处，保障农村公路完整、安全、畅通。

3.严格治理车辆超限行为。在农村公路重要节点设立固定治超站点，依法对超限超载运输车辆进行查处，依法打击车辆驾驶人员逃检和绕行的违法行为，开展保护农村公路的宣传活动，形成农村公路保护群防群治的良好局面。

4.加强路政执法队伍建设。开展执法人员和镇、村专兼职护路员的培训，学习农村公路管理和路政执法相关法律法规，提高农村公路管理人员的业务能力和专业素质。

5.开展路域环境治理和“美丽农村路”建设。由镇政府、建制村在公示栏或醒目位置张贴乡规民约、村规民约，组织开展路域环境治理和“美丽农村路”建设活动，保护路域环境。

（三）农村公路养护方面

1.落实农村公路养护责任主体。坚持各镇政府主导，充分履行管理职责，各镇成立农村公路养护权责一致、分工合理的管理机构，县农村公路管理养护所加强业务技术培训，为全县农村管理养护提供保障。

2.加强农村公路养护资金的管理。省级农村公路养护补助专项资金用于农村公路养护工程，县政府确保农村公路配套资金纳入财政预算，县农管所根据养护实际需要，将农村公路养护资金拨付给各镇政府。

3.健全农村公路考核、考评机制。县政府将农村公路养护任务纳入各镇年度综合目标考核。

（四）农村公路运营方面。

1.建立农村客运发展长效机制。县政府编制农村客运发展规划，出台资金扶持政策，由县交通运输局制定农村客运服务质量考评机制。

2.促进农村公路客运一体化发展。有序推进农村客运公交化改造，优先扶持农村客运发展，让通村客车“开得通，留得住”。依托农村客运场站，完善镇与镇、镇到村的农村客运线网络布局，实现农村客运与城市公交有效衔接。

3.探索农村物流运输模式。开展县至镇、沿途行政村的双向货物运输配送服务，提高农村物资运输的时效性和便捷性。鼓励县到镇的客运班车代运邮件和快件，健全小件快运服务体系，降低物流成本。引导运输企业与农村商贸流通企业、供销合作社共同制定运输、配送计划，积极支持农村电子商务与农村物流融合发展。

4.加强农村客运安全管理。落实农村客运安全主体责任，强化对农村客运车辆驾驶员安全教育及培训，提高抢险救灾应急能力。督促农村客运车辆及时更新，提高运输车辆装备水平和安全性能。

四、工作职责

县委宣传部：负责全县创建“四好农村路”示范县的宣传报道及典型宣传工作；

县考评办：负责组织制定创建“四好农村路”示范县建设目标考核细则，统筹开展相关考核工作；

县政府督查室：负责组织领导小组有关成员单位定期开展专项督查，通报督查结果；

县财政局：负责创建“四好农村路”示范县县级财政资励资金的统筹落实；

县交通运输局：负责全县创建“四好农村路”示范县硬件建设，组织开展创建“四好农村路”示范县隐患排查，制订2017年度创建“四好农村路”示范县建设规划及年度计划，做好创建“四好农村路”示范县建设技术指导，参与项目管理与质量监督，争取部省级补助资金落实到位；

县公安局：负责创建“四好农村路”示范县相关配套建设，会同交通运输部门开展隐患排查及治理工作，加强农村公路车辆管理，打击损毁公路设施行为；

县安监局：组织有关单位定期开展创建“四好农村路”示范县建设项目的安全生产检查，查处安全生产违法违规行为。

五、创建“四好农村公路”示范县工作计划

2017年，根据省人民政府创建“四好农村公路示范县”工作有关要求，县政府2017年第7次常务会议已研究同意，计划从今年开始利用三年时间开展我县“四好农村路”示范县创建活动，县交通运输局结合我县农村公路实际情况，在充分调查摸底的基础上，计划创建总里程为93公里的“四好农村路”示范线路,具体线路如下：

（一）武蒲复线（幸福路）起止新街镇晒甲山村、港东村、王家月村、沙湖岭村、余码头村，渡普镇蒲圻湖村、杨家咀村，潘家湾镇龙坎湖村、三湾村、东村村出口，全长约43公里；

（二）簰洲湾镇下沙村至中堡村、陈家坊村出口，全长13公里；

（三）簰洲湾加油站至庄屋岭村，金家洲村、复阳村、新洲村返回，全长16公里；

（四）县汽车客运站至官桥八组，循环至两湖村、丁家曾路段，全长21公里。

“四好农村路”示范线路计划创建总里程为93公里,施工费用约10万元/公里（主要用于窄路面加宽、路肩硬化、安防设施等），总投资930万元，另有20公里农村公路需进行路面改造，路面改造施工费用为40万元/公里，投资金额为800万元。
