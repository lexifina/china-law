# 县人民政府办公室关于印发嘉鱼县燃煤锅炉专项整治工作方案的通知

嘉政办发〔2017〕23号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

经县人民政府同意，现将《嘉鱼县燃煤锅炉专项整治工作方案》印发给你们，请认真遵照执行。

嘉鱼县人民政府办公室

2017年5月4日

嘉鱼县燃煤锅炉专项整治工作方案

实施燃煤锅炉专项整治工作，是我县控制煤炭消费总量、削减大气污染物排放总量和改善环境空气质量的关键举措。为切实推动全县环境空气质量改善工作，促进能源结构调整，结合我县实际，特制定本方案。

一、指导思想

以科学发展观为指导，认真贯彻落实《大气污染防治法》和国家大气环境保护工作的部署和要求。在优化能源结构、保障全县能源供应、控制煤炭消费总量的基础上，大力实施燃煤锅炉集中供热替代或淘汰、清洁能源改造、污染治理改造等项目，着力减少燃煤锅炉污染物排放，切实推动我县环境空气质量改善。

二、工作目标

加快推进“煤改气”“煤改电”、锅炉达标排放改造等工程建设，到2017年6月底前，全县范围内淘汰或改造所有20蒸吨/小时以下的燃煤锅炉。所有在用燃煤锅炉必须满足大气污染物排放标准要求。

三、工作原则

（一）优先使用原则。全县范围内企事业单位，应优先使用天然气等清洁能源。在天然气覆盖范围内，建议改造为天然气锅炉；蒸吨数较小的锅炉，建议替换为蓄热式电锅炉；在不具备上述条件的情况下，锅炉可以考虑燃用成型生物质燃料。所有成型生物质锅炉均需安装尾气处理装置，达到30毫克/立方米的烟尘排放标准（GB13271-2014）；推荐采用太阳能、轻质柴油、成型生物质燃料、电能等多种能源联供的高效联用锅炉。

（二）自愿选择原则。按照自愿的原则，由企事业单位根据天然气管网到达区域的实际情况，自主选择使用天然气、成型生物质燃料或其他清洁能源。

（三）优惠保障原则。清洁能源供应企业应积极参与燃煤锅炉的清洁能源替代工作，在设备配套、开口费和能源价格上要给予用户适当优惠，并在改造完成后为用户提供优质服务，保障能源供给。

（四）强制淘汰原则。所有中小燃煤锅炉必须在规定期限内完成清洁能源替代。超过淘汰期限，仍在继续使用高污染燃料锅炉的，由县环保局依法进行处理。

四、工作任务

（一）积极推进煤炭清洁高效利用。严格落实《商品煤质量管理暂行办法》（国家发改委、环保部等六部委第16号令）和《关于促进煤炭安全绿色开发和清洁高效利用的意见》（国能煤炭〔2014〕571号），积极推广先进的煤炭提质、煤炭洗选加工、高浓度水煤浆和洁净煤燃烧等煤炭清洁化利用技术，提高煤炭使用效率，禁止直接燃用高灰分、高硫分煤炭。推行优质、低排放煤炭产品替代劣质散煤机制，全面禁止劣质散煤的销售。

（二）科学划定禁燃区范围。全县将按要求抓紧划定城市中心区禁燃区并向社会公告。在禁燃区内禁止新建燃煤锅炉，禁燃区外不准新建每小时10蒸吨以下的高污染燃料锅炉，促进不符合规定的燃煤锅炉淘汰。禁燃区内禁止销售、燃用高污染燃料，禁止新建、扩建燃用高污染燃料的设施，禁止燃烧原（散）煤、煤矸石、粉煤、煤泥、煤焦油（重油、渣油）、各种可燃废物和直接燃用非成型的生物质燃料（树木、秸秆、锯木、稻谷、蔗渣等）；禁止燃烧燃料中污染物含量超过国家规定限值的固硫蜂窝型煤、轻柴油、煤油和人工煤气。

（三）严格燃煤锅炉准入标准。城市建设应当统筹规划，在燃煤供热地区推进热电联产和集中供热，在集中供热管网覆盖地区，禁止新建、扩建分散燃煤供热锅炉，已建成的不能达标排放的燃煤锅炉应当限期拆除。城市建成区原则上不得新建10蒸吨/小时及以下的燃煤锅炉。新建工业园区（或产业集聚区）要积极推进集中供热，合理规划布局，建设配备完善的集中供热系统；现有工业园区（或产业集聚区）应积极实施热电联产或集中供热改造，将工业园区（或产业集聚区）工业企业纳入集中供热范围。到2017年底，全县工业园区基本实现集中供热或清洁能源燃料锅炉供热。

（四）大力实施燃煤锅炉清洁能源替代工程。加快集中供热管网建设，大力实施燃煤锅炉改燃工程建设，积极推广应用天然气、电力、成型生物质燃料等清洁能源锅炉。凡供热管网覆盖范围内且热源能够保障供应的区域，原则上现有燃煤锅炉应全部拆除。凡天然气管网覆盖范围内且气源能够保障供应的区域，积极推进燃煤锅炉实施天然气改造工程。凡供热管网、天然气管网覆盖范围以外的区域，可通过建设大型燃煤高效锅炉或背压热电机组实现区域集中供热，或建设LNG储配设施保障区域天然气供应后改用燃气锅炉，或改用电、生物质成型燃料等清洁能源燃料锅炉,或采用洁净煤燃烧技术。

（五）提升在用燃煤锅炉污染治理水平。积极推进在用燃煤锅炉脱硫脱硝除尘等环保设施建设，所有在用65蒸吨/小时以上燃煤锅炉应达到《火电厂大气污染物排放标准》（GB 13223-2011）要求，所有在用65蒸吨/小时及以下燃煤锅炉应全面达到《锅炉大气污染物排放标准》（GB13271-2014）要求，其中，重点城市在用燃煤锅炉应达到特别排放限值要求。20蒸吨/小时及以上燃煤锅炉应安装在线监测装置，并与当地环保部门联网。纳入国家、省级、市级重点监控名单的企业应按照要求建立企业自行监测制度，向县环保局备案，并在环保部门统一组建的平台上公布监测信息。

五、责任分工

县燃煤锅炉专项整治领导小组负责全县燃煤锅炉整治工作的统筹协调；各镇人民政府和园区管委会是实施燃煤锅炉整治的责任主体，要切实加强领导，制定实施方案，制定相关配套政策，保证锅炉淘汰整治任务落实到位；县直相关部门要按照工作部署，各司其职，各负其责，完成燃煤锅炉淘汰整治任务。

县环保局：负责核定改造淘汰高污染燃料锅炉名单，监督并推进实施全县燃煤锅炉的限期淘汰工作。对超过淘汰期限仍在继续使用燃煤锅炉的，依照环保法律法规实行全因子收费，并依法进行处理；负责编制嘉鱼县改造淘汰燃煤锅炉资金申报方案，积极争取上级资金对全县改造淘汰燃煤锅炉工作实行以奖代补。

县发改局：负责新建、改建、扩建投资项目节能评估、审查，严禁新建燃煤锅炉项目；监督集中供热企业履行法定义务和约定义务；协调落实天然气资源，保障天然气供应。

县经信局：会同县环保局做好锅炉改造淘汰、锅炉污染治理工作，负责做好高效锅炉产业化工作。

县财政局：会同有关部门编制全县改造淘汰燃煤锅炉资金申报方案，安排治理资金和以奖代补资金。

县住建局：负责城市燃气行业管理和技术指导工作。协调燃气管道、集中供热管道设施配套建设。

县质监局：负责燃气承压锅炉安装、使用的监管工作，对纳入淘汰计划的锅炉不再办理年审手续。

县规划执法局：负责燃气管道配套线路规划等工作。

县安监局：负责锅炉安全生产监管工作，防止发生安全生产事故。

县工商局：负责对涉及新建锅炉的经营单位或个体工商户在办理工商营业登记时，先行审查相关评价手续，从源头上控制煤烟型污染。

县审计局：负责对燃煤锅炉清洁能源替代专项扶持资金的使用和项目执行情况进行监督。

县供电公司：负责对未完成拆改任务被责令停止使用的燃煤锅炉停止供电。

各镇政府、嘉鱼经济开发区管委会、武汉新港潘湾工业园管委会：负责辖区内高污染燃料锅炉的限期改造淘汰工作。

湖北大秦翔远市政燃气工程有限公司、西安华通新能源股份有限公司潘家湾镇分公司：负责落实天然气供应保障，组织实施淘汰燃煤锅炉工作的配套工程、设施安装及供气工作；积极主动对接燃煤锅炉替代用户，提供优质服务。

六、工作措施

（一）加强领导，统筹协调。成立以县政府分管领导同志为组长，县政府办分管副主任、县发改局主要负责同志为副组长的嘉鱼县燃煤锅炉专项整治领导小组，领导小组下设办公室，办公室设在县发改局，办公室主任由县发改局负责同志担任。成立工作专班，由县发改局、经信局、环保局、质监局等职能部门组成，负责燃煤锅炉整治的各项工作。县燃煤锅炉专项整治领导小组要加大燃煤锅炉专项整治督查督办力度，定期通报进展情况，积极协调解决整治过程中遇到的各种困难和问题，确保整治任务顺利完成。各镇政府、工业园区要加强燃煤锅炉专项整治工作的组织领导，明确责任单位和时间节点，确保按期完成全县燃煤锅炉整治工作。

（二）强化考核，严格督办。各镇、工业园区应制定燃煤锅炉整治专项工作方案，建立燃煤锅炉管理台账，逐台明确淘汰时限，因地制宜、一炉一册，确保按期完成燃煤锅炉淘汰任务。各镇、工业园区每月5日、15日与25日前向县燃煤锅炉专项整治领导小组办公室报送辖区内燃煤锅炉整治工作信息和工作进度，县燃煤锅炉专项整治领导小组办公室将适时对工作完成情况进行通报。对于燃煤锅炉淘汰工作滞后的，由县环委会办公室下达专项督办通知，并视情况报请县政府约谈所属辖区负责人。各镇燃煤锅炉淘汰目标任务完成情况将纳入各镇大气污染防治工作目标任务考核内容。

（三）强化宣传，营造氛围。广泛开展形式多样的燃煤锅炉整治宣传教育，宣扬污染危害及整治要求。引导公众参与，充分利用公众力量对燃煤锅炉大气污染情况予以监督。对于未按要求实施整改或整改不达标的，通过新闻媒体予以曝光，为燃煤锅炉整治营造良好的工作氛围。

（四）政策激励，以奖代补。县燃煤锅炉整治工作开展期间，对改造淘汰高污染燃料锅炉的单位实施以奖代补。奖励标准由县财政局、县环保局另行发文。
