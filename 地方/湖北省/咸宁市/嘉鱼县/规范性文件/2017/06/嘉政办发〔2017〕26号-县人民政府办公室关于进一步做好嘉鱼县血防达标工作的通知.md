# 县人民政府办公室关于进一步做好嘉鱼县血防达标工作的通知

嘉政办发〔2017〕26号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

血吸虫病是严重危害人民身体健康和生命安全、阻碍疫区经济发展和社会进步的重大传染病。经过多年努力，我县血防工作取得了明显成效，2013年全县血吸虫病疫情达到了传播控制标准。但由于我县地理三面环水，长江干堤战线长，洲滩钉螺孳生环境很难得到改善，洲滩禁牧工作未得到全面控制，因此血防工作形势十分严峻。为进一步认真贯彻落实省、市血防工作会议精神，按照省委、省政府确定的“十年送瘟神”三步走战略目标，确保我县今年达到传播阻断标准，现将有关事项通知如下：

一、统一思想认识，强化领导责任

今年是省委、省政府提出“十年送瘟神”第三步走的关键阶段，也是我县血吸虫病疫情达到传播阻断标准的决战年，疫区各镇党委、政府及县血防领导小组成员单位要清醒认识到血防达标工作的重要性、艰巨性和紧迫性，要实行“一把手”亲自抓、负总责，分管领导具体抓的工作责任制；要落实县血防领导小组成员单位对口包保疫区镇、县直单位驻村工作队、镇挂村干部包保疫区村的血防达标责任包保制度（重点疫区镇、村血防工作任务责任分解表见附件），围绕全县疫区以行政村为单位血吸虫病人、畜感染率控制在零以下，无新发病人，无感染性钉螺的目标，狠抓落实，坚定不移，整合资源，整合项目，集中财力和人力，落实科学防治措施，确保达标任务顺利实现。

二、突出工作重点，明确工作责任

今年，省政府在控制传染源淘汰耕牛、洲滩禁牧、人畜查治病、扩大化疗、晚血救治、替代养殖、疫情监测和钉螺控制的查螺、灭螺、兴林抑螺、垸内小型易感环境的改造及重疫区通村公路建设等项目给我县下达了具体任务，特别是淘汰耕牛、洲滩禁牧、查灭螺、查治病工作要求突出，因此我们必须按照省政府任务要求，狠抓重点疫区村淘汰耕牛、洲滩禁牧、查灭螺、查治病等防治工作。县血防领导小组成员单位要经常深入包保的疫区镇督查血防工作,督促落实传染源管控、查灭螺、查治病、急感防控及相关血防工作，年底向县血防领导小组提交书面述职报告；县直单位驻村干部、镇挂村干部要加强协调，密切配合血防部门开展查螺灭螺、查病治病、急感防控等工作，及时掌握防治工作进展情况，在深入现场和协调有关防治工作时要做好书面日志记录，年底上交县血防领导小组。

三、强化督查问责，严格考核奖惩

2017年县政府与各疫区镇、血防领导小组成员单位签订了目标责任书，各镇和成员单位要严格按照县委、县政府要求切实做好疫区血吸虫病的各项防治工作，保证达标顺利过关。为确保各项工作顺利完成，县政府已将血防达标工作列入县政府政务督导内容，纳入年终全县综合目标考评体系。县政府成立督办组，从5月起对全县疫区镇、村血防工作进行督办，一月一通报，对不能按期完成任务的疫区镇、村将给予通报，对影响我县不能达标的镇和对口联系的血防领导小组成员单位启动问责机制追究相关领导的责任。

嘉鱼县人民政府办公室
