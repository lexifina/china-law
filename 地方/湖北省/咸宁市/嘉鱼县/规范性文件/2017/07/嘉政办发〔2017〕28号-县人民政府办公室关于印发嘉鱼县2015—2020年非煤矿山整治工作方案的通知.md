# 县人民政府办公室关于印发嘉鱼县2015—2020年非煤矿山整治工作方案的通知

嘉政办发〔2017〕28号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

经县人民政府同意，现将《嘉鱼县2015—2020年非煤矿山整治工作方案》印发给你们，请认真遵照实施。

2017年6月2日

嘉鱼县2015—2020年非煤矿山整治工作方案

为快速推进“咸宁绿色崛起”战略部署，保障我县非煤矿山2020年底整治目标顺利实现，根据市、县非煤矿山综合整治工作方案、《市人民政府关于加强非煤矿山开发利用管理的意见》（咸政发〔2016〕18号）以及《咸宁市非煤矿山整治领导小组关于全面贯彻落实〈市人民政府关于加强非煤矿山开发利用管理的意见〉的会议纪要》（〔2016〕6号）精神，特制订本方案。

一、我县采矿权基本情况

结合县域实际，全县合理设置了非煤矿山“三区”（即开采区、限采区、禁采区），共设置开采区2个，即蛇屋山金矿区开采区、高铁岭—官桥石灰岩矿区开采区；禁采区3个，即鱼岳镇白云山石灰岩矿区禁采区、石壁山石灰岩矿区禁采区和簰洲—新街粘土矿区禁采区；限采区未设置。

全县采矿权18个（详见附件），其中，开采区内15个、禁采区内3个。按矿种划分：金矿2个，即蛇屋山金矿和虎山金矿；锰矿1个，即金鸡山锰矿；地热1个，即山湖温泉旅游有限公司藕塘湾小蛇屋山地热田；石灰石矿14个（含省国土资源厅颁发采矿许可证的高铁岭杨家山石灰岩矿<采矿权人为葛洲坝嘉鱼水泥有限公司>）。按采矿许可证发证权限划分：省级发证5个；县级发证13个，均为采石场。

按照非煤矿山整治精神，我县已于2015年8月份关停禁采区内的鱼岳镇胡秋阳采石场、孙社清采石场和白云山石料公司采石场等3个采石场。2016年5月份关停开采区内的官桥镇舒桥村采石场。截至目前，全县还保留14个非煤矿山，均在开采区域内。其中，按矿种划分：金矿2个、锰矿1个、地热1个、石灰石矿10个；按采矿许可证发证权限划分：省级发证5个、县级发证9个。10个石灰石矿中，除高铁岭杨家山石灰岩矿年开采规模达到《省人民政府关于进一步加强非煤矿山安全生产工作的意见》（鄂政发〔2015〕53号）规定的年开采规模标准外，其它9个采石场开采规模都未达到30万吨/年。

二、整治工作指导思想

以“三区”规划为基础，以《市人民政府关于加强非煤矿山开发利用管理的意见》（咸政发〔2016〕18号）和《咸宁市人民政府办公室关于全面贯彻落实<市人民政府关于加强非煤矿山开发利用管理的意见>的通知》（咸政办电〔2016〕81号）为依据，分类处理，科学规划，认真落实我县2020年底6个采矿权设置；结合现有保有资源储量、年开采规模、设计服务年限，明确县级颁发采矿许可证的9个石灰石采矿权2020年前后处置意见。整治工作中，坚持政府主导，部门联动，坚决将“联合踏勘、集体会审”落实在全县采矿权日常审批工作中；坚决将“在保护中开发、在开发中保护”的理念落实在矿山生态环境保护与复绿工作中；坚决将“安全第一、预防为主、综合治理”的方针落实在矿山安全生产工作中。通过整治，实现全县采矿权配置合理、矿山生态环境优化、矿山安全生产达标、矿山企业权益得以维护、矿区周边群众利益合理保护、矿产资源开发利用效益最大化。

三、整治矿山对象

根据《咸宁市人民政府办公室关于全面贯彻落实<市人民政府关于加强非煤矿山开发利用管理的意见>的通知》（咸政办电〔2016〕81号）文件精神，本次除山湖温泉旅游有限公司藕塘湾小蛇屋山地热田不参与整治外，其它的13个非煤矿山均参与整治，具体为：

（一）省级颁发采矿许可证矿山（4个）：蛇屋山金矿、虎山金矿、金鸡山锰矿、高铁岭杨家山石灰岩矿；

（二）县级颁发采矿许可证矿山（9个）：百合矿业有限公司九龙山采石场、高铁镇九岭山郑绪松采石场、高铁岭镇金石采石场、高铁岭镇九龙山采石场、嘉鱼春祥矿业有限公司、鑫九龙矿业有限公司杨家山采石场、长坂坡（嘉鱼）钙品有限责任公司米埠采石场、官桥镇廖家梅山石灰岩矿（采矿权人为嘉鱼县永力石材有限责任公司）、官桥镇舒桥村东方红采石场。

四、整治路线

（一）采矿权新设立。

1.设立原则

（1）必须符合《嘉鱼县矿产资源总体规划》，并在我县“三区”规划中的开采区内；

（2）矿区查明资源储量必须满足拟设采矿权开采需求；

（3）必须实行净采矿权出让。新设采矿权出让前，由国土部门提请县政府组织相关部门及矿山所在镇、村民代表和相关利益方，对拟出让采矿权项目涉及的环境评价、安全距离、林地占用、水土保持、征地拆迁等进行论证和风险评估；对拟出让采矿权矿区范围及影响范围内的土地、地面附着物及固定资产的权属，由具有资质的单位完成测量、调查，形成专题报告，权属清晰，无权益纠纷的，意见一致后，才实施出让；

（4）其它相关设立条件。

2.设立指标

根据《咸宁市人民政府办公室关于全面贯彻落实<市人民政府关于加强非煤矿山开发利用管理的意见>的通知》（咸政办电〔2016〕81号）规定，我县新设立石灰石采矿权指标为1个。

3.规划设置区

新设采矿权规划区拟定在高铁岭镇九龙山—碳坡山石灰岩矿区内，主矿种拟定为熔剂用或冶金用石灰岩，矿区总面积约0.33平方公里，资源储量约2750万吨（其中熔剂用或冶金用石灰岩矿约980万吨），规划设置矿区开采范围（西安80坐标系）为：X1：3300926.53，Y1：38481054.10；X2：3300953.90，Y2：38481648.28；X3：3300807.36 ，Y3：38481650.22；X4：3300489.24，Y4 ：38481170.18；X5：3300730.05，Y5：38481169.09；X6：3300732.22，Y6：38481054.10；+146.52至40米。X7：3302272.86，Y7：38481507.01；X8：3302221.75，Y8：38482087.47；X9：3301935.62，Y9：38481962.33；X10：3301857.39，Y10：38481715.76；X11：3301977.89，Y11：38481657.60；X12：3302121.12，Y12：38481441.38；+153.18米至+63米。

4.采矿权出让时间

拟定为2017—2018年度。

（二）现有采矿权保留。

1.保留原则

（1）必须符合《嘉鱼县矿产资源总体规划》，并在我县“三区”规划中的开采区内；

（2）矿区保有资源储量能够满足现有保留的采矿权开采需求；

（3）符合《咸宁市人民政府办公室关于全面贯彻落实<市人民政府关于加强非煤矿山开发利用管理的意见>的通知》（咸政办电〔2016〕81号）文件规定；

（4）现有采矿权保留条件符合国土、安监、环保、水务、林业等相关行业管理部门的规定；

（5）其它相关的保留条件。

2.保留指标

保留现有采矿权5个，即蛇屋山金矿、虎山金矿、高铁岭杨家山石灰岩矿、金鸡山锰矿、鑫九龙矿业有限公司杨家山采石场。其中，高铁岭杨家山石灰岩矿根据葛洲坝嘉鱼水泥有限公司今后水泥规划发展需要，允许矿山扩矿，由相关部门依法依规配置；鑫九龙矿业有限公司杨家山采石场设计年开采规模为20万吨，不符合现行行业准入条件，允许由采矿权人提出变更扩大年开采规模申请，国土、安监部门分别为其重新办理采矿许可证、安全生产许可证。鉴于该矿属我县高铁岭镇临江工业园区石灰石深加工原料供应基地，以及该矿矿区现有保有资源储量满足不了工业园区今后长远发展需求的实际，“十三五”期间，由相关部门依法依规为该矿办理采矿权扩矿手续。

（三）现有采矿权过渡。

1.过渡原则

（1）必须符合《嘉鱼县矿产资源总体规划》；

（2）过渡采矿权矿区资源储量经核实后，矿区保有资源储量还较大；

（3）县域经济发展需要现有采矿权暂时过渡提供部分石灰岩原材料；

（4）其它相关要求。

2.设置指标

拟定过渡采矿权设置指标1个，过渡采矿权定为长坂坡（嘉鱼）钙品有限责任公司米埠采石场。

3.过渡处置方案

长坂坡（嘉鱼）钙品有限责任公司米埠采石场位于官桥镇米埠村，采矿权于2011年11月份依法转让获得，采矿许可证证号：C[身份证号略]2601，批准开采矿种为建筑石料用灰岩、熔剂用石灰岩；批准资源储量为720.5万吨，设计开采规模为25万吨/年，设计服务年限26.5年，应开采至2037年；采矿权价款225.92万元，已分年度缴纳到位；截至2016年7月底保有资源储量664.39万吨。

处置方案：鉴于该矿山保有资源储量数目较大和设计开采规模25万吨/年不符合现行政策要求的实际，允许矿山在2017年先将开采规模25万吨/年变更为100万吨/年，并办理其采矿权变更登记手续，然后在2018年再将其开采规模变更为200万吨/年。该矿原则上开采至2020年底关停，考虑其矿区保有资源储量较大的实际，若该矿山关停时间到期矿区储量仍未开采完毕，根据县域经济发展需要，由县政府视实际情况决定该矿过渡时限。

（四）2020年前现有采矿权逐年关停。

1.关停原则

（1）严格执行咸宁市、嘉鱼县非煤矿山综合整治精神以及《咸宁市人民政府办公室关于全面贯彻落实<市人民政府关于加强非煤矿山开发利用管理的意见>的通知》（咸政办电〔2016〕81号）文件精神；

（2）贯彻落实嘉鱼县人民代表大会常务委员会《嘉鱼县人民政府关于严格控制采石矿山开采的规定》（嘉常发〔2014〕9号）；

（3）其它相关规定。

2.关停指标

2020年前分年度逐步关停采矿权7个，分别为：百合矿业有限公司九龙山采石场、高铁镇九岭山郑绪松采石场、高铁岭镇金石采石场、高铁岭镇九龙山采石场、春祥矿业有限公司、官桥镇廖家梅山石灰岩矿、官桥镇舒桥村东方红采石场。

3.逐年关停处置方案

（1）百合矿业有限公司九龙山采石场

该矿位于高铁岭镇九龙村，采矿权于2009年4月份依法转让获得，采矿许可证证号：C[身份证号略]1553，批准开采矿种为建筑石料用灰岩；批准资源储量为135.5万吨，设计开采规模为10万吨/年，设计服务年限12年，应开采至2021年；采矿权价款30.71万元，已分年度缴纳到位；截至2016年7月底保有资源储量72.11万吨。目前，由于该矿矿区范围较小，现有保有资源储量区域无法按安监部门要求分台阶开采，导致剩余资源储量不能开采。

该矿采矿权获得后，经过一年多时间开采，于2010年底又提出变更矿区范围、增加矿山资源储量和提高产能的申请，县国土资源局依法受理。2011年3月26日，在审查通过后，县国土资源局下达了《关于嘉鱼县百合矿业有限责任公司变更矿区范围的批复》，批复其变更矿区范围后资源储量779.84万吨（其中：原批准资源储量135.5万吨、新增资源储量644.34万吨）。该矿按《批复》要求，编制提交了采矿权变更登记所需的相关报告、方案。因县域经济发展需要，其采矿权矿区范围变更登记手续搁浅。2015年6月，该矿直接上访至省国土资源厅。省国土资源厅高度重视，迅速组织咸宁市、嘉鱼县两级国土资源部门进行会商。最后，省国土资源厅根据《国土资源部办公厅关于矿业权设置方案未编制入库的矿业权项目配号有关问题的函》（国土资厅函〔2012〕229号）：“一、矿业权统一配号系统的监管范围: （四）划定矿区范围的受理日期为2012年1月1日前的采矿权新立及扩大开采范围的项目。申请配号时，在配号系统中补充划定矿区范围的受理日期后，配号系统予以配号。”之规定，要求咸宁市国土资源局迅速督办嘉鱼县国土资源局妥善处理该矿历史遗留问题。2015年9月29日，市国土资源局向嘉鱼县国土资源局下达了《咸宁市国土资源局关于嘉鱼县百合矿业有限责任公司信访件的督办通知》，县国土资源局按要求将《督办通知》呈报县政府，县政府于2015年10月10日召开专题会议予以研究，要求县国土资源局按程序办理该矿采矿权变更登记手续。随后，该矿按照采矿权变更矿区范围相关规定再次完成矿产资源开发利用方案、环评报告、安全预评价报告等技术性专项方案（报告）的编制。

处置方案：根据《国土资源部办公厅关于矿业权设置方案未编制入库的矿业权项目配号有关问题的函》（国土资厅函〔2012〕229号）和《嘉鱼县国土资源局关于嘉鱼县百合矿业有限责任公司变更矿区范围的批复》（2011年3月26日），允许按历史遗留问题处理。在2017年期间，允许该矿扩大开采规模至45万吨/年，采矿权采取协议方式出让，然后在2018年再将该矿开采规模变更为200万吨/年，约定开采至2020年12月底关停，由国土资源部门与该矿签订采矿权出让合同。办理采矿权变更登记手续前，该矿需向当地镇政府作出书面关停承诺。

（2）高铁镇九岭山郑绪松采石场

该矿位于高铁岭镇金盆村，采矿权于2008年12月份依法获得，采矿许可证证号：C[身份证号略]8587，批准开采矿种为建筑用白云岩；批准资源储量为317.31万吨，设计开采规模为20万吨/年，设计服务年限13.76年，应开采至2022年；采矿权价款75.92万元，已分年度缴纳到位；截至2016年7月底，+80米标高以上保有资源储量40.19万吨。

矿山在开采过程中，认为矿区实际开采资源储量与原批准的资源储量存在一定数量差距。2014年上半年，该矿多次向市、县国土部门反映，经原报告编制单位—湖北金楚矿业开发有限公司和湖北省第四地质大队一起查阅其原《地质报告》，发现报告编制前未进行一定的勘查工作，编制单位估算资源储量时未扣除开采范围上部第四系覆盖层和强—中风化层的厚度（约5.03米），该厚度内的废土、废料都已作资源处置给了矿山。2014年10月，湖北省第四地质大队对原批准矿区范围重新进行勘查，形成《湖北省嘉鱼县高铁镇九岭山郑绪松采石场建筑石料用灰岩、白云岩矿产资源储量核实报告（截止2014年10月底）》，查明原批准的矿区范围（垂直开采标高为139—80米）内资源储量为205.38万吨，与原备案的资源储量317.31万吨相差111.93万吨。《核实报告》表明，若与原批准的资源储量（317.31万吨）相符，则在平面范围不变的情况下，最低开采标高需为+52米。市国土资源局对该《核实报告》进行了备案（备案文号：咸土资函〔2014〕95号）。

该矿位于我县嘉陆公路旁，与周边矿山—高铁岭镇金石采石场紧紧相连，而金石采石场最低开采标高至+55米。两矿山陆续关停后，最终形成的开采面落差明显很大，不利于两矿山地质环境恢复治理统一规划，同时因存在一定落差，也可能存在滑坡地质灾害隐患，并且会严重影响嘉陆公路上过往行人的视觉感观。

处置方案：鉴于上述实际，同意该矿将最低开采标高由+80米调至+55米，开采规模从20万吨/年变更为45万吨/年，重新办理采矿权变更登记。矿山开采至2019年12月底关停，办理采矿权变更登记手续前，该矿需向当地镇政府作出书面关停承诺。

六、相关要求

（一）本《方案》确定后，所有开采的矿山必须在我县“三区”规划中的开采区内开采。

（二）本《方案》生效执行后，对2020年前现有采矿权逐年关停的采石矿山，采矿权人必须提交国土资源部门审查备案的《资源储量核实报告》。对《资源储量核实报告》中原批准矿区范围内新查明资源储量（又称“新增资源储量”），国土资源部门要依法依规对该部分资源储量进行采矿权价值评估，重新与采矿权人签订《采矿权出让合同》，督促采矿权人补缴采矿权价款，确保国有资产不流失。对原批准矿区范围内新查明资源储量的矿山，根据《嘉鱼县现有非煤矿山整治计划一览表》，在原规定关停时间不变的情况下进行倒逼，重新扩大其年开采规模。

（三）采矿登记前，采矿权人必须按采矿登记相关规定编制、提交《矿山开发利用与生态复绿方案》《环境影响评价报告》《安全预评价报告》《水土保持方案》等相关技术性方案（报告），并由相关主管部门按要求完成公示或备案（批复）。县国土部门对照《矿山开发利用与生态复绿方案》，严格督促矿山按照批准的矿区范围、生产规模、开采方式等依法依规进行开采。对越界开采、无证采矿、盗采等违法行为，要坚决予以严厉打击；县环保部门要督促矿山落实环保“三同时”制度，按要求上齐和运行污染防治设施，不定期开展矿山环境保护执法检查。对环保不达标的矿山企业，严肃督促整改，规范环保行为；安监、水务、林业等其它职能部门也要认真履职尽责，按照各自的工作职责分工，严格加强全县非煤矿山日常开采行为的监管，发现管辖领域中的违法违规行为及时进行打击。

（四）根据《市人民政府关于加强非煤矿山开发利用管理的意见》（咸政发〔2016〕18号）、《咸宁市非煤矿山整治领导小组关于全面贯彻落实〈市人民政府关于加强非煤矿山开发利用管理的意见〉的会议纪要》（〔2016〕6号）以及嘉鱼县人民代表大会常务委员会审议通过的《嘉鱼县人民政府关于严格控制采石矿山开采的规定》（嘉常发〔2014〕9号）等文件精神，采矿权登记前，由县非煤矿山综合整治工作领导小组召开专题会进行讨论，形成集体决议，无异议后，由矿区所在地镇政府以及县国土、安监、环保、水务、林业等部门按相关规定进行办理，其中，采矿许可证有效期每次为1年，省级颁发采矿许可证的矿山除外。

（五）2020年前现有采矿权逐年关停的采石矿山，承诺关停时间一旦到期，无论矿区初始批准的资源储量或本《方案》执行后核实新增的资源储量是否开采完毕，矿山都必须无条件关停。

（六）全县生产矿山必须按照“边开采、边治理”的原则，开展矿山生态复绿；矿山关停后，立即启动矿山恢复治理，消除地质灾害隐患，整体修复矿区生态环境，归还矿区周边居住群众一个良好的生活环境。
