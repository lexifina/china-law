# 县人民政府办公室关于成立十七个安全生产专业委员会的通知

嘉政办发〔2017〕31号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

根据《中共中央 国务院关于推进安全生产领域改革发展的意见》和《市人民政府办公室关于调整市安全生产委员会组成人员和成立十七个安全生产专业委员会的通知》（咸政办发〔2017〕25号）文件精神，经县人民政府同意，成立17个安全生产专业委员会。现将有关事项通知如下：
