# 县人民政府办公室关于成立嘉鱼县政府性债务管理领导小组的通知

嘉政办发〔2017〕32号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

为加强我县政府性债务管理，规范政府性债务举借、使用偿还再担保行为，防范政府性债务风险，经县人民政府同意，成立嘉鱼县政府性债务管理领导小组（以下简称领导小组）。现将有关事项通知如下：

二、主要职责

贯彻落实上级关于政府性债务管理的决策部署，研究政府性债务管理的方针政策和重大事项，组织推进全县政府性债务管理各项工作，协调解决全县政府性债务管理工作中的有关事项。

三、工作机构及职责

领导小组下设办公室，办公室设在县财政局，尹彬生同志兼任办公室主任，刘飞鸣同志任办公室副主任。领导小组办公室承担领导小组日常工作；研究提出全县政府性债务管理的政策建议，建立健全政府性债务的举债审批、债务预警、偿债渠道、绩效评价、责任追究等监控管理机制；具体负责县本级政府债券的申报、使用、管理和监督偿还等工作；审核、汇总和分析政府性债务报表，指导相关部门政府性债务管理工作。
