# 县人民政府关于公布县级暂保留、调整的行政审批中介服务事项清单的通知

嘉政发〔2017〕10号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

按照国务院和省委、省政府有关清理规范行政审批中介服务精神，县审改办组织县直各部门对县级行政审批中介服务事项进行了清理，形成了《县级暂保留、调整的行政审批中介服务事项清单》，经县政府同意，现印发给你们，并在嘉鱼县人民政府门户等网站上公布。

请县政府各有关部门对照清单内容进一步梳理行政审批中介服务事项，对暂保留的行政审批中介服务，要完善服务规范和标准，营造公平竞争、破除垄断、优胜劣汰的市场机制，对取消和调整的行政审批中介服务，要加快配套改革，加强事中事后监管，切实保障简政放权有关工作落到实处。

附件：《县级暂保留、调整的行政审批中介服务事项清单》
