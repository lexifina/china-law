# 县人民政府关于命名嘉鱼县第五届劳动模范的决定

嘉政发〔2017〕7号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

2013年以来，全县人民在县委、县政府的领导下，坚持以党的十八大和十八届三中、四中、五中、六中全会精神为指导，全面深化改革，勇于开拓创新，积极投身“五个嘉鱼”建设，各行各业涌现了一大批“爱岗敬业、争创一流、艰苦奋斗、勇于创新、淡泊名利、甘于奉献”的劳动模范，他们是全县广大劳动群众的杰出代表。为大力弘扬劳模精神，倡导劳动光荣、知识崇高、人才宝贵、创造伟大的社会风尚，充分发挥先进模范人物的示范引领作用，进一步激发全县职工群众的劳动热情和创造活力，县人民政府决定，命名孔群芳等18名同志为“嘉鱼县第五届劳动模范”。

希望各位劳动模范再接再厉，充分发挥骨干带头作用，在全面建成小康嘉鱼征途中再立新功。全县广大职工群众要以劳动模范为榜样，学习他们胸怀大局、忠于职守、乐于奉献的崇高情怀，学习他们尽职尽责、精益求精、争创一流的敬业精神, 学习他们求真务实、埋头苦干、任劳任怨的优良作风，学习他们充满激情、勇于开拓、敢于担当的创新精神，努力争当推动科学发展的先锋，为建设湖北经济强县、打造临港生态新城，全面建成小康嘉鱼作出新的更大的贡献。
