# 县人民政府办公室关于印发嘉鱼县2017年统筹使用财政专项资金实施方案的通知

嘉政办发〔2017〕36号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

经县人民政府同意，现将《嘉鱼县2017年统筹使用财政专项资金实施方案》印发给你们，请认真遵照实施。

2017年7月6日

嘉鱼县2017年统筹使用财政专项资金实施方案

根据《省人民政府关于创新管理机制统筹使用财政专项资金的指导意见》（鄂政发〔2014〕11号）和《省人民政府办公厅关于创新建立贫困县资金整合机制实施精准扶贫的意见》（鄂政办发〔2015〕63号）要求，为进一步完善机制，推动统筹使用财政资金工作，结合我县实际，特制定本实施方案。

一、指导思想

以党的十八届六中全会和省委十届六次全会精神为指导，以嘉鱼县经济和社会发展“十三五”规划为依据，以主导产业、优势区域和重点项目为平台，以提高财政专项资金使用效益为目标，整合各部门和各渠道的财政专项资金，逐步建立起立项科学、分配规范、使用高效、运行安全的管理机制，实现集中财力办大事，促进全县经济和社会事业持续快速发展。

二、基本原则

统筹使用财政专项资金坚持以下原则：

（一）集中财力，县级统筹。在全县范围内，跨部门、跨年度、跨区域整合资金，打捆项目，高效利用，形成集聚效应。

（二）科学规划，分步实施。选择一批对全县经济和社会发展带动力强的重点项目和重点工作，按照“分类指导、分步推进、突出重点、连片建设”的思路，集中投入，做到投资一项，见效一项。

（三）创新机制，提高效益。建立全县统筹使用财政专项资金项目管理机制，尤其是规划统筹、项目统筹、推进统筹和项目管理机制，确保财政专项资金取得最大效益。

（四）协调配合，职责不变。统筹使用财政专项资金工作由县政府指导，统筹资金领导小组办公室牵头，各部门、各镇实施，形成“资金性质不变、管理责任不变”和协调配合、良性互动的工作机制。

（五）公开透明，强化监管。严格规范统筹使用财政专项资金管理，健全专项资金绩效评价体系，加强对项目工程事前、事中、事后的监督，确保资金安全高效运行。

三、统筹平台

按照以规划为引导，以重点项目为载体，以奖补资金为引领，搭建我县统筹资金使用平台。2017年，全县统筹资金使用平台分为五类：

（一）精准扶贫。围绕县委、县政府关于精准扶贫决胜年实施方案，实现4274人建档立卡贫困人口脱贫销号，陆水村、蒲坼湖村等4个贫困村出列。

（二）高标准农田建设。围绕“藏粮于地、藏粮于技”发展规划，深入开展2017年高标准农田建设任务，继续抓好2016年簰洲湾镇2.02万亩高标准农田集中连片建设任务，全面完成2017年度1.77万亩高标准农田建设目标。

（三）农田水利建设。按照农田水利建设“十三五”规划，重点围绕水毁工程恢复重建，着力提升基本农田抗灾害、抗风险能力，加快三湖连江灌区续建配套与节水改造工程，继续抓好县管流域治理工程，抓好小农水项目建设和灾后重建任务。

（四）现代农业（八大农业示范区）建设。瞄准创建国家级现代农业示范区目标，完善“以奖代补”政策，着力抓好绿色粮食、绿色蔬菜、绿色农业、健康畜牧水产养殖、休闲农业和乡村旅游等产业区建设，推动八大现代农业示范区建设提档升级。

（五）社会民生设施建设。逐步分年开展民生领域和社会发展类基础设施建设，带动社会金融资金，全面改善惠及民生的设施短板。

四、整合规模和投向

（一）整合资金的规模。

2017年共计划整合资金50087万元。主要分为五类：

1.精准扶贫类整合资金 13330万元。整合国土、交通、城建、财政、民政、卫生、扶贫、移民等部门资金实施精准扶贫、精准脱贫。具体包括：中央财政专项扶贫资金714万元，省级财政专项扶贫资金1187万元，县本级安排精准扶贫专项资金4000万元（本级增量15%，存量资金50%），市级财政专项扶贫资金60万元，一事一议项目300万元，中央农村环境连片整治示范资金170万元，中央车辆购置税收入补助地方用于一般公路建设项目资金136万元，中央农村危房改造补助资金413万元，中央专项彩票公益金支持扶贫资金490万元，省级旅游发展基金60万元，易地扶贫搬迁（含政府融资资金）5800万元。

2.高标准农田建设类整合资金 5497万元。整合财政、农发、国土、发改等部门资金，开展高标准农田建设。具体为：中央农业综合开发补助资金1962万元，省级农业综合开发补助资金785万元，发改局资金600万元，高标准基本农田建设补助资金2150万元。

3.农田水利建设类整合资金4800万元。整合小农水、水利发展、水利管护、安全饮水、防汛抗旱等资金加快农田水利建设。具体为：中央财政水利发展资金1700万元，省级财政水利发展资金1600万元，县本级农田水利设施建设专项800万元，县本级农村安全饮水工程200万元，县本级防汛抗旱及堤防维修专项资金500万元。

4.现代农业建设类整合资金6460万元。整合财政、农业、水产、畜牧、林业、扶贫、交通、国土等资金实施“八大农业示范区”建设，着力推进农业供给侧结构性改革项目建设。具体为：中央农业生产发展资金970万元，省级产粮大县奖励资金100万元，省级农业生产发展资金1690万元，一事一议奖补资金900万元，生产救灾恢复救助存量资金1000万元，本级农业示范区建设资金1000万元，本级绿满嘉鱼行动奖补资金500万元，本级新农村建设专项资金300万元。

5.社会民生发展类整合资金20000万元。整合教育、卫生、交通、城建、卫生等部门专项资金带动社会金融资金开展民生领域和社会发展类基础设施建设。具体为：卫计局省市专项资金3000万元，县财政、教育资金3000万元，县城投、交通资金14000万元。

（二）整合资金的投向。

整合资金集中用于五个方面：一是统筹资金用于精准扶贫。围绕“精准扶贫、不落一人”的总体要求，以9个建档立卡贫困村为主战场，坚持开发扶贫和社会保障两轮驱动。在镇提出建档立卡贫困村基础设施及基本公共服务建设要求的前提下，统筹规划，对9个建档立卡贫困村逐步实施整村推进，实现4个村脱贫；以镇为分类施策主体单位，对建档立卡贫困人口进行分类帮扶规划，对无劳动能力的孤寡、病残贫困人口，通过低保政策供养兜底；对因病致贫、因病返贫的，通过医疗救助扶持；对其他的贫困人口，分析致贫原因，因地制宜、因户施策，通过帮助发展产业、开展技能培训、金融扶贫或易地搬迁等方式进行帮扶。二是统筹资金用于高标准农田建设，完善基本农田设施建设，围绕项目区基本农田沟渠路网配套项目。支持高标准农田稻虾共养等综合种养模式，促进全县优势生态产业基地成块连片形成规模，为保障粮食安全和农产品有效供给，提高农业综合生产能力奠定坚实基础。三是统筹资金用于农田水利基本建设。分年逐步对全县农田水利设施进行全面维修改造，以提升抵御防大汛、抗大旱能力。四是统筹资金用于现代农业生产发展。深入推进八大农业示范区建设，壮大示范区规模，完善示范区内沟渠配套、道路硬化、绿化美化等基础设施和绿色防控体系建设。培育和扶持市场主体，加快示范区产业化进程，力争将“八大农业示范区”打造成嘉鱼农业的一张靓丽名片，成为全市乃至全省现代农业发展的亮点和标杆。五是统筹资金用于中医院整体搬迁，新建嘉鱼县第一小学，陆八舒扶贫公路等重点项目，全面改善惠及民生的设施短板。

五、保障措施

（一）加强组织领导。统筹使用财政专项资金是一项关乎我县体制机制创新，加快推进经济社会发展的重要工作，涉及面广，政策性强，目标要求高，工作任务重。各部门、各镇要在县统筹使用财政专项资金领导小组办公室的统一协调下，按照每年年初下发的目标任务认真组织实施，确保既定目标任务不折不扣得到贯彻落实。建立工作协调机制，确保部门职责分工，研究纳入统筹整合使用的具体资金范围，定期或不定期召开会议交流情况，解决工作中遇到的实际问题。

（二）建立健全机制。突出建立县级整合集聚使用的资金分配机制，财政专项资金整合项目实行“六制”管理，即项目规划集中制、项目申报会商制、项目建设公示制、项目资金报账制、项目竣工审计制、项目绩效考核制。经确定的项目在启动前先预拨项目资金的30%；项目达到实施进度后再续拨50%；项目竣工并由县相关部门对项目验收合格后，再拨付剩下的资金。

（三）明确工作责任。整合财政专项资金是一项系统工程，各部门、各镇要明确职责、积极配合，县统筹使用财政专项资金领导小组办公室要加强指导、组织协调；县财政部门要加强监督管理，制订财政专项资金管理的具体办法，确保财政专项资金有序统筹、有章可循；各项目主管部门要超前谋划，建立项目库，加强项目规划的衔接配套，各有关部门要按照统筹财政专项资金要求及时调整完善相关专项规划，实现有效衔接，保障按计划完成统筹任务；项目实施主体对统筹使用的财政专项资金，制订统一的实施方案，明确“资金怎么来、怎么统、怎么用”，明晰资金流向，建立台账，确保资金使用有据可查。全县所有责任单位，应做到优势互补、上下协调，形成合力，确保工作顺利推进。

（四）加强监督检查。县统筹使用财政专项资金领导小组办公室要定期或不定期对整合工作进行督办检查，发现问题及时通报，限期整改，确保工作落到实处。
