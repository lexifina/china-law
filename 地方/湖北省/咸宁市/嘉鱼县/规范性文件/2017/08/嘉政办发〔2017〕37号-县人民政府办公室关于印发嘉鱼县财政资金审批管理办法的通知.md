# 县人民政府办公室关于印发嘉鱼县财政资金审批管理办法的通知

嘉政办发〔2017〕37号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

经县人民政府同意，现将《嘉鱼县财政资金审批管理办法》印发给你们，请认真遵照执行。

2017年7月17日

嘉鱼县财政资金审批管理办法

为加强预算管理，规范财政预算资金审批拨付行为，加快预算执行进度，提高财政资金的使用绩效，根据《中华人民共和国预算法》，特制定本办法。

一、财政资金审批的原则

（一）规范审批的原则。坚持“单位申请、财政会审、政府审批”原则，各项财政资金的安排，按规定权限和程序审批后执行。

（二）绩效优先的原则。财政资金着力保障社会民生领域中重点问题、重大事项的资金需求，服务全县经济社会发展大局，坚持集中财力办大事，力保既定工作任务和绩效目标的实现。

二、 财政资金审批的范围

本办法所称财政资金，一是指经县人民代表大会批准的财政预算资金，包括基本支出（人员支出及公用经费）、项目支出（项目经费、非税收入安排的经费）；二是指上级补助资金（中央、省及市级专项转移支付资金）；三是指二次审批和追加的资金。

三、财政资金审批的程序

（一）县人代会已批准的县级财政预算资金。

1.部门预算支出资金。

经县人民代表大会批准，年初预算已明确到行政事业单位的基本支出、项目经费（非二次审批项目）、非税收入安排的经费，由县财政局按时间进度、收入进度或政策依据直接拨付。

2.二次审批和追加的专项资金。

（1）年初无法细化预算以及项目类的专项经费（含预备费）。由相关职能部门根据项目计划和实施进度,向县政府提出用款申请(含申请拨款事项的具体内容、政策依据、经费预算、支出绩效等)，由分管副县长提出意见并报常务副县长、县长批示，经县财政局据实审核报批（涉及相关职能部门的，由县财政局和相关职能部门共同审核）。

（2）预算外追加经费，预算经县人民代表大会批准后，原则上不得提出追加申请，确需追加的，由用款单位提出申请报县政府，常务副县长、县长每季度集中会签一次。

（3）预算安排明确到项目的结算性支出，涉及对县国税局、地税局、财政局、环保局和各镇等结算支出，由县财政局提出方案，报常务副县长、县长审批。

（二）上级补助资金（含专项转移支付）。

1.一般性转移支付资金中的财力性补助，已纳入年初一般公共预算，不属于审批范畴。

2.应支付到享受对象的社会保障和就业资金、各类涉农补贴等专款。相关职能部门及时将资金安排方案，经分管副县长同意，报常务副县长、县长审批后，县财政局将资金直达享受对象或相关财政专户。

3.除上述两项外的其他上级补助资金。

（1）已确定项目实施部门（单位）及具体支出项目的，由用款单位提出申请，报常务副县长、县长审批。

收归存量的上级补助资金按此程序办理。

（2）未确定具体分配部门（单位）或具体支出项目的，由县财政局商相关职能部门按资金用途，将资金安排计划报常务副县长、县长审批或县政府常务会议确定后报县长、常务副县长审批。

（3）省、市主管部门拨入，并已明确了资金使用单位的上级往来资金，由用款单位提供资金到账依据，县财政局将资金拨付到单位。

四、财政资金的监督管理

（一）基本原则。

权责对等原则。按照谁申请、谁审核、谁使用、谁负主体责任的原则，对项目和数据的真实性、资金使用的合规性、绩效目标科学性和最终结果负责。

统筹使用原则。先用同类上级资金，后用本级资金；本级当年项目结余资金年度终了全部清零。

（二）职能部门监管职责。

所有财政资金的使用单位，必须自觉接受县人大的监督，以及县财政局、审计局的审计和检查。

1.财政部门职责。县财政局承担资金拨付的及时性、资金使用的有效性等方面的责任，定期向县长、常务副县长报告政府预算支出进度，向县政府分管领导报告分管单位上级专项资金的有关情况。

2.资金使用部门职责。项目主管部门及财政资金使用单位承担项目申报与实施的真实性、资金使用的合规性、绩效评价等方面的责任。同时，做好项目建设前期准备工作，及时申请拨付资金，大力推进项目建设进度,充分发挥财政资金绩效。

3.审计部门职责。制订年度审计计划，采取全面检查或重点抽查的方式，加强对财政资金使用的审计监督，不断促进财政资金使用安全、规范、有效。对经监督检查发现违反上述规定的行为，由县纪检监察部门依法依规追究责任。

五、本办法自印发之日起执行。在执行过程中，如本办法与上级出台的相关法律法规不一致，以上级文件为准。本办法由县财政局负责解释。
