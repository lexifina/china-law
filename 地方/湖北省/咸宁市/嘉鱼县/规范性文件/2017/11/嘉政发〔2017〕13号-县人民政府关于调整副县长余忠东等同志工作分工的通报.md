# 县人民政府关于调整副县长余忠东等同志工作分工的通报

嘉政发〔2017〕13号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

根据人事变动和工作需要，现将部分副县长工作分工调整情况通报如下：

副县长 余忠东 负责环境保护、城建、交通、规划、国土资源、商贸流通等方面工作。分管县环保局、住建局、交通运输局、规划执法局、国土资源局、人防办、商务局、粮食局、供销社。县长交办的其他工作。

副县长 范 威 负责教育、文化体育、广播电影电视、卫生计生、科技、对外开放、档案、民族宗教等工作。分管县教育局、科技局、文体广电新闻出版局、广播电视台、卫生和计划生育局、食品药品监督管理局、产品质量检验检测中心、民族宗教局、档案局、外侨办（侨联）；联系县工会、共青团、妇联、残联、工商联、科协、文联。县长交办的其他工作。

2017年9月30日
