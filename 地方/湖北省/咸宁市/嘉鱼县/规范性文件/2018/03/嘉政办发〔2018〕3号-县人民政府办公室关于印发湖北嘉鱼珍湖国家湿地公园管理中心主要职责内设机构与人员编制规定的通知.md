# 县人民政府办公室关于印发湖北嘉鱼珍湖国家湿地公园管理中心主要职责内设机构与人员编制规定的通知

嘉政办发〔2018〕3号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

《湖北嘉鱼珍湖国家湿地公园管理中心主要职责内设机构与人员编制规定》已经县人民政府批准，现予印发。

2018年1月15日

湖北嘉鱼珍湖国家湿地公园

管理中心主要职责内设机构与人员编制规定

根据国家林业局《关于同意天津蓟县州河等134处湿地开展国家湿地公园试点工作的通知》（林湿发〔2016〕193号）、《咸宁市机构编制委员会关于设立湖北嘉鱼珍湖国家湿地公园管理中心的通知》(咸编文〔2017〕159号)和《嘉鱼县机构编制委员会关于设立湖北嘉鱼珍湖国家湿地公园管理中心的批复》（嘉编发〔2017〕42号），设立湖北嘉鱼珍湖国家湿地公园管理中心，为嘉鱼县人民政府管理的副县级公益一类事业单位。

一、主要职责

（一）贯彻执行国家有关湿地保护的法律、法规、规章和方针政策。

（二）负责全县湿地保护工作的组织协调、指导和监督。

（三）负责实施国家湿地公园总体规划；制定湿地公园管理计划和湿地资源保护的各项规章制度并组织实施；协调国家湿地公园与周边村组社区的关系；负责营销、生态旅游开发等事务的管理。

（四）负责争取湿地生态资源保护与恢复项目；组织开展湿地生态保护与恢复建设，充分发挥湿地功能，促进湿地公园规范健康发展。

（五）负责湿地资源调查，协助做好环境监测；组织和协调湿地科研、湿地环境质量评估；开展湿地保护宣传教育活动；参与湿地学术交流与合作、科技咨询。

（六）行使有关湿地法律、法规规定的其它职责。

（七）负责协调相关职能部门对湿地公园内的建设、规划、开发、经营活动进行监管、审批、处罚。

（八）完成上级交办的其他事项。

二、内设机构及职能

根据上述职责，设3个内设机构：

（一）综合管理科。

负责湿地公园的文秘、保密、会务、信息、信访、机关接待、统计、财务、档案管理、资产等后勤管理工作；负责单位的年度计划编制、年度工作计划制定等工作；协助处理日常事务。

（二）湿地保护科。

负责贯彻执行国家有关湿地保护的法律、法规、规章和方针政策；组织落实国家湿地公园总体规划；制定湿地公园管理计划和湿地资源保护的各项规章制度并组织实施；履行有关湿地法律、法规的其他职责；承担湿地公园内生物多样性保护、基础设施维护，生态文明教育基地建设、保护站、观测站管理，日常巡查等工作。

（三）项目管理科。

负责争取湿地生态资源保护与恢复项目；组织开展湿地生态保护与恢复建设，充分发挥湿地功能，促进湿地公园规范健康发展；承担工程管理等工作；负责湿地资源调查，协助做好环境监测；组织和协调湿地科研、湿地环境质量评估；开展湿地保护宣传教育活动；参与湿地学术交流与合作、培训、科技咨询；承担湿地公园内种植业、畜牧业等产业及替代产业发展。

机关党组织 负责机关和直属单位的党群工作。

纪检、监察、工会、离退休干部工作等机构按有关规定设置。

三、人员编制和领导职数

湖北嘉鱼珍湖国家湿地公园管理中心核定全额事业编制11名，其中：设主任1名（副县职），副主任2名（正科职），总工程师1名（正科职），科长3名（副科职），副科长3名（正股职）。人员参照机关管理。

四、附则

本规定由县机构编制委员会办公室负责解释，其调整由县机构编制委员会办公室按规定程序办理。
