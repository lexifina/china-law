# 县人民政府关于调整县政府领导班子部分成员工作分工的通报

嘉政发〔2018〕1号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

根据人事变动和工作需要，现将部分副县长工作分工调整情况通报如下：

副县长 宋昵荔 负责教育、文化体育、广播电影电视、卫生计生、科技、对外开放、档案、民族宗教等工作。分管县教育局、科技局、文体广电新闻出版局、广播电视台、卫生和计划生育局、食品药品监督管理局、产品质量检验检测中心、民族宗教局、档案局、外侨办；联系县工会、共青团、妇联、残联、工商联、侨联、科协、文联。县长交办的其他工作。

副县长 范 威 负责环境保护、城建、规划、国土资源、商贸流通等方面工作。分管县环保局、住建局、规划执法局、国土资源局、人防办、商务局、粮食局、供销社。县长交办的其他工作。

副县长 甘志宝 协助常务副县长处理分管工作。县长交办的其他工作。

副县长 华 红 负责农村、农业、防汛抗旱、民政救济、交通、旅游开发、扶贫开发、移民和新农村建设等工作。分管县农业（蔬菜）局、畜牧兽医局、水务局（防办）、农业综合开发办、综改办、农机局、经管局、林业局、水产局、民政局（老龄办）、交通运输局、旅游委、扶贫办（移民局）；联系县委农办（财经办）、气象局、省市驻嘉农林水单位。县长交办的其他工作。

2018年1月3日
