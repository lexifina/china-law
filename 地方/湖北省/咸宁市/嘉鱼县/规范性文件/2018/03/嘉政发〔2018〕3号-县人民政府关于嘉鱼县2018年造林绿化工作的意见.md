# 县人民政府关于嘉鱼县2018年造林绿化工作的意见

嘉政发〔2018〕3号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园:

2018年是全面贯彻落实党的十九大精神的开局之年，也是全面建成小康社会的关键之年，为持续推进全县造林绿化工作，全力建设生态美丽嘉鱼，根据省、市林业工作统一部署，结合我县实际，特提出如下工作意见。

一、指导思想

以习近平新时代中国特色社会主义思想为引领，以建设生态美丽嘉鱼为核心，以建设森林质量精准提升工程为抓手，提质与增量并举，添绿与增效同步，加快绿色村庄、绿色水岸、绿色矿区、绿色林网建设，全面提升林业生态建设水平，为建设湖北经济强县、打造临港生态新城提供有力的生态支撑和保障。

二、目标任务

全县计划完成造林绿化面积1.6万亩，其中高效经济林面积5880亩，速生丰产林面积6350亩，其他村庄、通道、生态防护林面积3770亩;精准提升森林质量面积2万亩，完成义务植树98万株;创建省级森林城镇1-2个，绿色示范村8个，县级绿色示范村12个;新建花卉苗木基地3个，面积300亩。

三、重点工作

一是精准绿美村庄。以实施乡村振兴战略为契机，加快乡村绿化美化，大力开展绿色示范村创建活动，房前屋后以栽植桂花、香樟、红叶石楠等绿化苗木和经济苗木为主，全面加强乡村原生植物、自然景观、古树名木、小微湿地和野生动物保护，形成森林入村、绕路、依水、围田，建设美丽乡村、森林人家和生态文化村。

二是精准绿化通道。加强对县镇通道两侧可视范围内受损山体的生态修复，打造高质量生态经济型绿色长廊。新建公路做到路修到哪里，绿化跟到哪里，绿化与工程规划、施工和验收同步，按照四季有绿、季季有景、乔灌搭配的要求，全面提升通道绿化水平。

三是精准绿满水岸。加强长江大保护力度，打造长江生态防护林。加快对陆水河、金水河、斧头湖、西凉湖、密泉湖、三湖连江等河流、湖泊沿岸沿线生态修复，重点栽植杨树、垂柳、水杉等乡土树种，做到应绿尽绿，提高水源涵养林质量。

四是抓好矿山复绿。结合全县非煤矿山综合整治，切实做好矿山复绿规划，加快矿山复绿步伐。重点抓好高铁岭、官桥、鱼岳三镇区域内的非煤矿山复绿造林，恢复矿山森林生态。

五是抓好林网建设。对在“绿满嘉鱼”行动中建成的“三镇十网”农田林网进一步修复，补植补造，提档升级。重点抓好簰洲湾、潘家湾两镇区域内的农田林网建设，以栽植杨树、香樟、红叶石楠为主，形成完备的农田林网防护林，构建生态高效农田。

六是抓好项目建设。严格按照林业重点工程技术实施标准，加快林业项目实施。重点抓好油茶林、长防林、血防林项目建设，开展补植补造，提高项目建设水平。加强中幼林抚育管理，大力发展林下经济，大幅度提高林地产出率。

四、主要措施

一是加强领导，形成合力。继续坚持各镇党委、政府主要负责人亲自抓，分管负责人具体抓的造林绿化机制，重点抓好村庄绿化美化。县直部门要各司其职:县国土资源局负责矿山复绿;县水务局负责江河湖沿线沿岸绿化;县交通运输局负责省县镇道路绿化;县林业局负责抓好组织协调、技术指导、种苗供应等工作。各镇、各单位要相互协作，形成强大合力。

二是筹足资金，保障投入。各镇要抓好土地流转，多方筹集绿化资金，引进社会资本，广辟筹资渠道，破解资金难题。县直各部门要继续对联点村绿化进行帮扶。县林业局要积极向上争取项目资金，抓好林业项目实施，推进森林质量精准提升工程。县政府安排专项资金500万元，用于造林绿化工作奖补。

三是科技兴林，提高质量。县林业局要加大林木新品种和实用新技术推广力度，要围绕全县森林质量精准提升工程，深入到造林绿化一线，实地搞好指导服务。各单位要因地制宜选择树种，坚持选用规格高的良种壮苗用于造林绿化，要科学栽植，科学管理，确保成活成材成林。同时要落实森林资源保护与管理责任制，全面提升森林资源管理水平。

四是广泛宣传，营造氛围。要进一步加大宣传力度，切实加强全民绿化意识、生态意识、责任意识。县电视台、嘉鱼网要开辟专栏，宣传政策，树立典型，激发全民参与，营造“爱绿、护绿、养绿”的浓厚氛围。

五是严格考核，扎实推进。县政府将加强对各镇各单位的检查督办，把造林绿化、森林质量精准提升工作纳入各镇、各单位年终绩效考核。组织专班对造林绿化、森林质量精准提升工程进行检查验收。对任务完成好的给予表扬;对措施不到位、年度任务未完成的给予通报批评，并对责任人约谈问责。
