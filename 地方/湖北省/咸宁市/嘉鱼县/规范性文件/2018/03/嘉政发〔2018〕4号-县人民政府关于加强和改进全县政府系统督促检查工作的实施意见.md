# 县人民政府关于加强和改进全县政府系统督促检查工作的实施意见

嘉政发〔2018〕4号

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

为深入贯彻落实《中共湖北省委关于加强新形势下党的督促检查工作的实施意见》（鄂发〔2017〕15号）、《省人民政府关于进一步加强全省政府系统督促检查工作的实施意见》（鄂政发〔2017〕37号）和《市人民政府关于加强和改进全市政府系统督促检查工作的实施意见》（咸政发〔2017〕28号）文件精神，在全县政府系统形成督查的大声势、大行动、大权威、大成效，现就加强和改进全县政府系统督促检查工作提出如下实施意见。

一、总体要求

紧紧围绕县委、县政府中心工作开展督促检查，坚持发展导向、目标导向、问题导向、效果导向，以服务领导决策为宗旨，以推动各项工作落实为目标，按照“规范程序、突出重点、创新方式、注重实效”的工作思路，着力构建政府系统大督查工作格局，推动各项决策部署落实见效。

二、督查重点

当前和今后一个时期，县政府督查工作重点主要有八个方面：

（一）国务院大督查、省政府月度督查及大督查反馈意见的整改落实情况；

（二）“市考”目标（政府部分）、省《政府工作报告》及“十件实事”、市《政府工作报告》涉及嘉鱼部分的完成情况；

（三）县十四届党代会二次会议报告确定的政府工作任务的贯彻落实情况；

（四）县《政府工作报告》及“十件实事”确定目标任务的贯彻落实情况；

（五）县政府全会、县政府党组会、县政府常务会议、重要专题会议议定事项和县政府重要文件的贯彻落实情况；

（六）党中央、国务院、省委、省政府、市委、市政府、县委、县政府领导同志重要批示及交办事项的贯彻落实情况；

（七）政府系统承办人大代表建议和政协提案的办理情况；

（八）基层群众反映强烈的突出问题和新闻媒体、网络舆情关注的热点、焦点问题。

三、督查机制

（一）建立“综合督查”工作机制。建立与县委办公室定期会商机制，在县委办公室的统一协调下，做好政务督查工作。着力构建县政府办公室牵头抓总、政府部门联动的县政府综合督查工作格局，涉及县政府层面的督查均由县政府办公室牵头组织实施，未经授权，县政府各部门不得组织对各镇人民政府、嘉鱼经济开发区、武汉新港潘湾工业园的督查，避免重复督查、交叉督查、多头督查。

（二）建立“领衔督办”工作机制。每年由县政府政务督查室负责对县政府“八个方面”的督查任务进行责任分解，明确责任领导、责任单位，建立任务清单和责任清单。县政府分管领导按照县政府班子成员工作分工安排，领衔督办所分管领域重点工作的落实，县政府督查室负责具体跟踪督办。

（三）建立“项目库”工作机制。每年初，根据县政府主要领导批示精神，对需要重点督办的工作纳入县政府督查项目库，项目库原则上不超过15项。对入库项目由县政府政务督查室统一编号，实施全过程、清单化、动态化管理，“挂号”督办直至“销号”。对于其它阶段性、动态性工作，严格执行由县政府分管领导审核，县政府主要领导批准的追加立项制度。

（四）建立“三结合”工作机制。建立书面督查与现场督查相结合、政府督查与社会监督相结合、传统手段与现代科技相结合的督查机制。完善现场督查方式，在明督明查的基础上，深入一线、直奔基层、直插现场，不发通知、不打招呼、不听汇报，通过掌握第一手资料向县政府提出建设性的意见和建议。探索邀请第三方机构、新闻媒体、专家、人大代表、政协委员等参与政府督查，主动接受社会监督。积极运用互联网、大数据开展督查，建立电子台账，对督查事项实施实时跟踪督查。

四、督查方式

（一）日常督查。对县政府“八个方面”重点督查工作任务，由县政府政务督查室建立督查台账，制定任务分解表和落实路线图，主要采取函件交办、电话催办、上门督办、会议协调等方式实行日常跟踪督办。

（二）专项督查。对于县政府领导交办的时间紧、任务重，临时性的督查事项，由县政府政务督查室按照有关分工适时组织实施。对一些政策性、业务性较强的专项督查活动，可经县政府授权由政府部门具体实施，专项督查方案报县政府督查室备案。

（三）联合督查。每季度，从国务院大督查重点督查事项、省政府月度及大督查重点督查事项、市政府大督查活动项目库及领导交办重点事项中抽取部分事项开展督查。督查活动由县政府政务督查室牵头，会同有关单位制定大督查方案，报请县政府同意后，组成若干督查组，分赴各相关单位实地督查，督查结果集中向县政府常务会议汇报。

五、结果运用

建立“一季一督查、一季一通报、一季一排名、一季一约谈”的工作机制，抓好督查结果运用，增强政务督查工作的权威性和威慑力，形成大督查的强大气场。

（一）督查通报。根据督查情况，县政府办公室对专项督查和联合督查情况在全县范围内进行通报、排名。对工作进展缓慢、落实不力的镇和部门，点名道姓指出具体问题，责成报告原因及改进措施，并将通报内容移交纪检监察机关。日常督查、专项督查、联合督查结果统一由县政府政务督查室按程序通报，其他单位不得以县政府名义下发《督查通报》。

（二）督办整改。对督查中发现的问题由县政府政务督查室建立台账，实行销号管理，并统一由县政府政务督查室下发《督办通知》，督促责任单位明确任务清单、责任清单、时限清单，推进问题整改到位，确保督查事项件件有着落、事事有回音。

（三）表扬激励。对国务院、省政府、市政府、县政府组织的督查工作中单项工作表现突出、落实各项重点工作成效明显的单位和个人，提请县委县政府予以表扬奖励。在每季度县政府组织的大督查活动中，探索建立县政府督查综合排名体系，对综合排名第一的单位在全县范围内进行通报表扬，在县委县政府年终综合考评中予以加分奖励。
