# 县人民政府办公室关于印发嘉鱼县“四好农村路”三年攻坚战实施方案的通知

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

经县人民政府同意，现将《嘉鱼县“四好农村路”三年攻坚战实施方案》印发给你们，请认真抓好落实。

2018年7月18日

嘉鱼县“四好农村路”三年攻坚战实施方案

为认真贯彻落实党的十九大和习近平总书记关于“建好、管好、护好、运营好”农村公路的重要指示精神，服务乡村振兴战略和脱贫攻坚，加快交通强县建设，特制订本实施方案。

一、总体目标

加快推进农村公路提档升级和危桥改造，完善农村公路管养体制机制，提升农村公路通畅水平和安全条件，改善农村公路路域环境，构建路网结构优化、体制机制顺畅、安全保障有力、生态环境优美、运输服务优质的农村交通运输服务体系，促进全县农村公路建管养运协调可持续发展，确保到2020年实现“四好农村路”建设总目标，为实施乡村振兴战略、决胜全面建成小康社会提供坚实的交通保障。

二、重点任务

“四好农村路”三年攻坚战重点实施“六大工程”，具体如下：

（一）实施农村公路提档升级工程。一是按照路面宽度不低于5.5米、路基宽度不低于6.5米的标准，用三年时间对300公里通客运班车的农村公路进行提档升级，2018年要完成100公里提档升级任务。二是推动农村公路向进村入户延伸，到2020年底全面完成20户以上组级公路建设任务。

（二）实施农村公路安全保障工程。进一步加快农村公路安全生命防护“455”工程建设，按照市政府要求，确保“后三年任务今年完成”，我县目标任务分解了472.1公里。在全面排查评定的基础上，用三年时间完成现有通客车的农村公路四、五类危桥改造，推动农村公路危桥比例逐年下降，从源头上消除安全隐患。

（三）实施农村公路管养工程。推进镇村两级农村公路管理机构设置率实现100%，落实机构及人员经费，有效维护农村公路路产路权。督促各镇人民政府落实农村公路养护配套资金，推动各镇将农村公路养护配套资金纳入财政预算并根据农村公路发展建立增长机制，确保“有路必养、养必到位”。

（四）实施美丽农村路创建工程。加强农村公路质量监管，加大奖优罚劣力度。结合乡村振兴战略实施和美丽乡村建设，组织开展农村公路路域环境整治，积极打造“美丽农村路”。总体目标为：全县用三年时间建成300公里“美丽农村路”。按照“畅、安、舒、美”的要求，确保每年建成100公里的“美丽农村路”，力争县有一条示范县道，镇有一条示范乡道，村有一条示范村道。

（五）实施农村公路运输服务提升工程。巩固“村村通客车”成果，大力推进镇村公交化，力争50%以上的县至镇农村客运班线到2020年底实现公交化运营，全面提升农村群众出行服务质量和服务品质。整合部门资源，精准发力，加快推进县、镇、村三级农村物流体系建设。促进农村电商、快递线上线下资源高效整合，畅通农产品进城、工业品下乡双向流通渠道，进一步降低农村物流成本，力争到2020年底全县实现县、镇、村三级物流服务网点全覆盖。

（六）实施“四好农村路”创建工程。按照省、市“四好农村路”创建的考核标准，落实县、镇、村三级组织对农村公路的管理责任，完善监督考核体系和激励机制，为农村公路建设提供政策支持和制度保障。加快推进“四好农村路”创建由县向镇、村延伸，力争每年建成“四好农村路”100公里，到2020年底全县共建成县、乡、村道搭配合理的“四好农村路”300公里。

三、攻坚战工作安排

每年第一季度：县交通运输局组织专班对上一年度“四好农村路”建设项目进行检查验收，并做好市交通运输局“四好农村路”攻坚战工作专班对我县验收情况实地抽查复核的准备工作；

每年第二季度：县交通运输局筛选项目，向市交通运输局做好当年项目申报及项目备案入库工作；

每年第三、四季度：县交通运输局每半个月对辖区内“四好农村路”推进情况进行一次督查，并将督查情况形成正式报告报县人民政府和市交通运输局；县“四好农村路”攻坚战工作专班每月对各镇人民政府“四好农村路”建设工作进度进行一次督办，并将督查结果进行通报。县交通运输局要加强所属行业的“四好农村路”攻坚工作的业务指导和监督检查，定期通报情况，形成争先创优的攻坚氛围，确保全年“四好农村路”建设目标任务圆满完成。

四、具体措施

（一）加强组织领导。为加强全县“四好农村路”三年攻坚战建设工作的组织领导、协调督办、跟踪管理，确保年度目标任务全面完成，成立由县委副书记、县长胡春雷任组长，县委常委、县总工会主席余忠东、副县长罗达、副县长李斌任副组长，各镇镇长和相关职能部门负责人为成员的嘉鱼县“四好农村路”三年攻坚战建设工作领导小组（具体成员名单见附件）。

各单位工作职责：

县委宣传部：负责全县“四好农村路”三年攻坚战建设工作的宣传报道及典型宣传工作；

县考评办：负责组织制定“四好农村路”三年攻坚战建设目标考核细则，将“四好农村路”纳入对各镇的目标责任考核，统筹开展相关考核工作；

县政府督查室：负责组织领导小组有关成员单位定期开展专项督查，通报督查结果；

县财政局：负责“四好农村路”三年攻坚战建设工作县级财政资金的统筹落实；

县交通运输局：负责全县“四好农村路”三年攻坚战建设工作硬件建设，制订2018-2020年度全县“四好农村路”三年攻坚战建设工作规划及年度计划，做好全县“四好农村路”三年攻坚战建设工作技术指导，参与项目管理与质量监督，争取部省级补助资金的落实工作；

县公安局：配合做好农村公路安全生命防护工程建设，会同县交通运输局开展联合治超治限工作，加强农村公路车辆管理，打击损毁公路设施的行为；

县安监局：组织有关单位定期开展“四好农村路”三年攻坚战建设项目的安全生产检查，查处安全生产违法违规行为；

县住建局：按照“畅、安、舒、美”要求，配合做好“四好农村路”路域环境整治工作；

县规划城管局：配合做好“四好农村路”总体规划设计工作；

县林业局：配合做好农村公路绿化工作。

（二）加强资金保障。一是充分利用全省“四好农村路”攻坚战机遇，吃透、用好相关政策，积极向省里争取“四好农村路”建设项目和补助资金。二是加大农村公路建设方面的资金投入力度。三是严防腐败问题的发生。认真贯彻执行国家和省市有关农村公路建设管理的规定。严格按照法定程序和省厅要求开展农村公路项目建设，确保立项、设计、招投标、建设各个环节依法依规。用于农村公路建设的资金,无论是国家奖励资金，还是地方自筹的配套资金,都要严格加强管理,实行专户存储、专款专用，严格落实“三同时”、“八公开”制度。

（三）加强程序管理。认真组织编制年度计划项目清单，履行行业管理职责，加强对规划报批、计划申报、设计批复、施工监理、验收考核等程序的全面管控，落实工程质量责任制。鼓励农村公路提档升级工程多项目打捆招标，降低前期工作成本，提高资金使用效率。

（四）加强考核验收。县交通运输局应于每年11月底前对已实施完成的提档升级工程项目进行验收，将验收合格项目报省交通运输厅审核并报市交通运输局备案。对已创建完成的美丽农村路，由工作专班进行实地信息采集，待通过市交通运输局的验收审核后，定期将符合创建标准的项目报省交通运输厅备案。

（五）创新工作机制。一是探索推进农村公路建、管、养、运新模式。深入探索“四好农村路”建、管、养运有效模式，开展农村公路路域环境整治，争取县、镇、村都建有“美丽乡村路”。二是全面推进“路长制”。建立“路长制”管理制度，健全县、镇、村三级路长体系，全面落实县、镇、村三级组织对农村公路管理的主体责任。
