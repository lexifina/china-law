# 县人民政府办公室关于加快推进官桥农村产业融合发展示范园创建工作的意见

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

为贯彻落实《国务院办公厅关于推进农村一二三产业融合发展的指导意见》（国办发〔2015〕93号）、七部委局《关于印发国家农村产业融合发展示范园创建工作方案的通知》（发改农经﹝2017﹞1451号）、《省人民政府办公厅关于推进农村一二三产业融合发展的实施意见》（鄂政办发〔2017〕1号）精神，加快推进官桥农村产业融合发展示范园创建工作，进一步提升全县农村产业融合发展总体水平，实施乡村振兴，结合我县实际，提出本实施意见。

一、总体要求

（一）指导思想。深入贯彻落实党中央、国务院决策部署，坚持“四个全面”战略布局和发展第一要务，牢固树立创新、协调、绿色、开放、共享的发展理念，以深入推进农业供给侧结构性改革、加快培育农村发展新动能为主线，以完善利益联结机制为核心，以要素集聚和模式创新为动力，坚持走农村产业融合与新型城镇化建设协同推进的道路。以官桥片区产城融合发展为主导，在龙头企业和合作社培育、农产品加工园创新升级、农业资源集约利用、产业链完善、创新投融资机制、完善产业融合服务等方面寻求突破和创新，辐射带动周边区域形成农村一二三产业融合发展新格局，提供可借鉴、易推广的经验和模式，充分发挥示范引领作用，促进农业增效、农民增收、农村繁荣。

（二）工作目标。以产城融合为主要示范方向，全面实施现代农业产业体系构建、培育农业多元化主体、健全产业融合的利益联结机制、创新投融资机制及推进城乡一体化建设等战略，通过“三产”融合示范园的创建，打造嘉鱼县城近郊融合现代生态农业、特色农产品加工业、大健康产业于一体，宜居宜业宜游新型功能区，建成链接城乡的新型城镇化示范项目。

二、重点任务

（一）科学规划，推进产城融合发展。

1.编制“多规合一”城镇规划。按照城镇、国土、产业、经济社会等多规划整合的理念，在上位规划的指导下，结合《官桥农村产业融合发展示范园创建方案》、国家乡村公园总体规划、特色小镇概念性规划、官桥镇旅游总体规划等规划成果，科学编制切实可行的官桥镇总体规划。

2.推进特色小城镇建设。引导农村二三产业向县城、官桥镇及创业园、产业园、孵化园区等集中，带动农产品加工、研发、物流、商业、金融等产业，促进产城融合、产城互动和农业增效。按照宜居宜业宜游的要求，完善城镇功能、配套公共设施，实现农村劳动力转移和就地城镇化发展。

3.优化空间发展布局。结合实际情况优化产业融合发展与城镇、村庄空间布局，合理布局综合政务服务区、种植区、养殖区、加工园区、物流园区，明确各区块功能定位，积极打造布局合理、功能互补、效益双赢的全域体系。结合美丽乡村、田园综合体、国家乡村公园、产业园等一二三产业融合发展新业态、新模式，进一步明确空间管控、产业布局、基础设施等要素。

（二）体现特色，打造现代农业全产业链。

1.构建现代农业产业体系。以农业示范基地为基础，通过农业结构调整促进农业适度规模经营，大力发展高效型、生态型特色农业，围绕油茶、茶叶、水产、花卉苗木、有机果蔬、中药材等特色农产品，与农产品加工企业、精准扶贫脱贫工作进行有效对接，精心打造一批高产、优质、高效、生态、安全的特色农产品生产基地。

2.延伸农业产业链条。坚持高起点、高科技、高附加值的发展方向，积极争取扶持政策和引入战略投资者、科研合作者，以产业化龙头企业为带动，联结专业合作社、家庭农场、专业大户等新型农业经营主体，重点围绕油茶、茶叶、水产、中药材等产业做精做深，推动农业生产、农产品研发加工、物流配送、市场营销等产供销环节紧密连接，延伸产业链，提升附加值。

3.拓展农业多功能。大力推进以服务武汉等周边城市为目标，支持田野国家乡村公园、金色年华、恋江湖、宏佛旅游、沙阳古镇等项目加快推进，形成以生态休闲、观光体验、绿色康养、节庆会展等为特征的乡村旅游集聚区，推进农业与旅游、教育、文化、健康养老等产业深度融合，大力推进产村融合、农旅融合。

（三）多措并举，培育壮大产业融合主体。

1.支持和引进龙头企业示范带动。支持田野集团发挥龙头带动作用，积极招商引进农业产业化龙头企业和品牌，建设标准化、现代化、规模化的农业基地，发展农产品加工流通、电子商务和农业社会化服务，促进“产—加—销”一体化发展，提高产品附加值，打造一批有影响的农业品牌。

2.扶持农村新型经营主体。积极支持种植养殖大户、家庭农场、农民合作社发展成为农村经济的主体，实施规模生产、合作经营和多种经营。各部门要积极向上争取项目和资金，支持示范园区内农民合作社和家庭农场发展。

3.培育新型职业农民。探索以示范、承包、委托经营等方式支持生产经营型职业农民实施适度规模化、专业化生产、经营活动。加大对职业农民的培育，引导和资助专业种植养殖户领办基地，开发新产品。充分发挥职业农民的骨干和示范带动作用，带动更多农村青年、返乡劳动力创业致富。

（四）创新思维，建立互利共赢利益联结机制。

1.加强农民与农业产业更加紧密的利益链接。鼓励龙头企业、新型农村经济组织与农民拓展“租金、股金、酬金”利益分享方式，强化农民在产业融合发展中的参与度。引导龙头企业在平等、互利基础上，与农户、种养大户、家庭农场、农民合作社签订农产品购销合同，发展订单农业，建立种苗、设备、技术、资金全方位合作关系，形成稳定购销关系。

2.鼓励企业与集体经济组织实行股份合作。加快示范园区农村集体产权制度改革进度，推广集体资产、土地入股和财政性支持资金折股到户，与龙头企业、新型集体经济组织进行股份合作经营。抓紧建立县、镇两级农村集体产权交易市场，完善示范园区内农村综合产权流转交易平台建设。

（五）加大投入，搭建产业融合发展综合平台。

1.加大基础设施投入力度。加快陆八舒旅游扶贫公路、G351官桥至石埠塘段、S359朱砂至绿岭段、田野大道建设，支持并启动嘉鱼东农村路网改扩建工程、官桥客运站、舒高线等项目实施。按计划实施官桥片区高标准农田改造项目，积极推进美丽乡村建设和乡村振兴项目建设，加快农产品加工园建设步伐，夯实示范园区产业融合发展基础。

2.搭建示范园区公共服务平台。加快建设官桥镇综合便民服务中心，整合“公益、便民、电子商务、培训体验”四类服务。推动信息进村入户，实现普通农户不出村、新型农业经营主体不出户就可享受到便捷、经济、高效的生产生活信息服务。加快提升农业大数据应用能力，建立农资、农产品全程可追溯系统。采取政府购买、资助、奖励等形式，引导科研机构、行业协会、龙头企业等为示范园提供公共服务。

3.强化人才和科技支撑。支持和引进各类科技人员、大中专毕业生等到示范园区创业；鼓励科研人员到新型农业经营主体任职、兼职或担任技术顾问，完善知识产权入股、参与分红等激励机制；落实“三乡工程”支持政策，返乡创业人员进入园区投资兴业享受招商引资同等优惠和支持；鼓励大专院校、科研院所在示范园区设立、共建产学研、教育教学、实践实训基地。

三、政策措施

（一）加大财政支持力度。加大对农村产业融合发展示范园的投入，从 2018 年起，每年整合资金设立县级农村产业融合发展专项资金，重点扶持省级以上农业产业化龙头企业，奖励新型农村经济组织研发产品、争创品牌（奖补办法另行制定）；加大涉农专项资金投入整合力度，重点向种养大户、家庭农场、专业合作社、农业龙头企业等新型农业经营主体和三产融合发展的示范点倾斜。

（二）加强金融信贷扶持。发展农村普惠金融，鼓励农商行、邮政储蓄银行等驻基层金融机构拓展“三农”业务。设立针对示范园区涉农经营主体的融资风险补偿金，引进和支持园区企业、农业生产经营者开展多渠道、多形式的融资活动。

（三）落实税收优惠政策。强化服务意识，简化申报手续，按照从简、从优、从低原则，灵活把握政策，促进农民合作经济提升发展。落实国家针对农村新型经济组织和农业生产者的税收减免和小微企业税收优惠政策；符合条件的技术转让所得，予以免征或减征企业所得税。

（四）完善土地支持政策。积极争取“增减挂钩”、“占补平衡”政策，开展山水林田湖草综合试点，收益部分用于示范园区基础设施建设和产业发展，落实“特色小镇”叠加区用地优惠政策。鼓励和支持新型农业经营主体在农地农用、耕作层不破坏的前提下，延伸农业产业链，拓展农业多种功能，大力发展农业新型业态，加快促进农业与二三产业融合发展。

四、组织保障

（一）加强组织领导。县委、县政府成立领导小组和工作专班负责示范园创建工作，纳入年度计划，加强产业融合发展规划、政策制定、信息沟通、区域协调和监督指导等工作。

（二）落实相关责任。县直各部门、各单位要强化协调配合，积极争取政策支持示范园创建，官桥镇要强化政府主体责任，梳理产业发展优势和薄弱环节，制定具体工作计划，落实相关工作任务。

（三）强化督办考评。县政府督查室、县项目办要将示范园创建工作纳入全县重点项目内容，对相关任务的落实进行督办、检查，确保创建工作稳步推进。
