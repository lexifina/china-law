# 县人民政府关于对嘉鱼县2018年扫黑除恶专项斗争中有关个人记功的决定

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

自扫黑除恶专项斗争开展以来，我县不断强化“四个意识”，严格落实县委系列决策部署，立足实际、科学谋划，精心组织、迅速行动，在扫黑除恶、打击电信诈骗、打击制售假冒伪劣食品药品、长江大保护、交通道路治超、服务民营企业等专项行动中，涌现出了一批优秀工作者。根据《中华人民共和国公务员法》，经县政府2019年第4次常务会议研究，决定对在嘉鱼县2018年扫黑除恶专项斗争中表现突出的李安庆等28名同志记个人三等功。

希望受到表彰的同志戒骄戒躁，再接再厉，更加努力工作，再创佳绩。全县各镇各部门要学习先进，扎实工作，开拓创新，争创一流，为建设平安嘉鱼作出更大贡献。
