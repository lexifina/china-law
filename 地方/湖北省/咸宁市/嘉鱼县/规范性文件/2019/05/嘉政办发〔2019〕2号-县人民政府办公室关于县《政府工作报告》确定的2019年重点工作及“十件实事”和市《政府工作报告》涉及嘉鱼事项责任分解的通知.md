# 县人民政府办公室关于县《政府工作报告》确定的2019年重点工作及“十件实事”和市《政府工作报告》涉及嘉鱼事项责任分解的通知

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

经县人民政府同意，现将县第十八届人民代表大会第三次会议审议通过的《政府工作报告》确定的2019年重点工作和“十件实事”，以及市《政府工作报告》涉及嘉鱼事项责任分解给你们，请认真贯彻落实，将《政府工作报告》确定的2019年重点工作及“十件实事”和市《政府工作报告》涉及嘉鱼事项纳入本单位年度目标任务，夯实责任体系，狠抓工作落实，确保市、县政府决策全面完成。县政府政务督查室将于4月、7月、10月及2020年1月对各单位贯彻落实情况开展专项督查，对工作进展缓慢、落实不力、推诿扯皮、弄虚作假的单位和相关责任人予以通报，并根据相关规定严肃追责问责。

附件1

县《政府工作报告》确定的2019年重点工作责任分解

2019年经济社会发展预期目标是：“六增一降一控制”。

“六增”：1．地区生产总值增长8.5％。［责任领导：李振、甘志宝；牵头单位：县发改局（粮食局）；责任单位：嘉鱼经济开发区，潘湾工业园，各镇人民政府］

2．规模以上工业增加值增长8.5％。（责任领导：李斌、张建军；牵头单位：县科技和经信局；责任单位：嘉鱼经济开发区，潘湾工业园，各镇人民政府）

3．固定资产投资增长12％左右。［责任领导：李振、甘志宝；牵头单位：县发改局（粮食局）；责任单位：嘉鱼经济开发区，潘湾工业园，各镇人民政府］

4．社会消费品零售总额增长11.5％左右。（责任领导：李斌、张建军；牵头单位：县科技和经信局；责任单位：各镇人民政府）

5．一般公共预算收入增长10％。（责任领导：李振、王纲；牵头单位：县财政局；责任单位：县税务局，嘉鱼经济开发区，潘湾工业园，各镇人民政府）

6．城乡居民人均可支配收入与经济增长同步。［责任领导：李振、甘志宝、华红；牵头单位：县发改局（粮食局）、县农业农村局；责任单位：县统计局，各镇人民政府］

7．“一降”，即万元GDP能耗降幅达到市定目标要求。［责任领导：李振、甘志宝；牵头单位：县发改局（粮食局）；责任单位：嘉鱼经济开发区，潘湾工业园，各镇人民政府］

8．“一控制”，即居民消费价格涨幅控制在4.5％以内。［责任领导：李振、甘志宝；牵头单位：县发改局（粮食局）；责任单位：县市场监督管理局，各镇人民政府］

14．积极争创“湖北省质量强省示范县”。（责任领导：李振；牵头单位：县市场监督管理局）

15．支持元拓铝合金、汉麻科技等企业争创省隐形冠军示范企业。（责任领导：李斌、张建军；牵头单位：县科技和经信局；责任单位：嘉鱼经济开发区，潘湾工业园）
