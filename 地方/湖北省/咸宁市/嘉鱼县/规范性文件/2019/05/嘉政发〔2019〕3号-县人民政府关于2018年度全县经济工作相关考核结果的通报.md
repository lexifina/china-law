# 县人民政府关于2018年度全县经济工作相关考核结果的通报

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园：

根据《市人民政府关于表彰2018年度十强纳税企业等经济发展先进单位和先进个人的决定》（咸政发〔2019〕1号）、《市人民政府办公室关于印发咸宁市金融机构支持经济社会发展考核办法的通知》（咸政办发〔2017〕32号）、《县人民政府办公室关于印发加强招商引资工作实施办法的通知》（嘉政办发〔2017〕33号）、《嘉鱼县人民政府关于进一步推进大众创业万众创新深入发展的实施意见》（嘉政发〔2017〕15号）等文件精神和县政府2019年第5次常务会议精神，现将2018年度全县经济工作相关考核结果通报如下：

一、授予中国人民银行嘉鱼县支行、咸宁银监分局嘉鱼办事处、湖北嘉鱼农村商业银行股份有限公司、中国建设银行嘉鱼县支行、中国农业发展银行嘉鱼县支行“2018年度金融支持嘉鱼经济发展突出贡献奖”。

授予中国邮政储蓄银行嘉鱼县支行、中国农业银行嘉鱼县支行、湖北银行嘉鱼县支行、武汉农村商业银行嘉鱼县支行、中国工商银行嘉鱼县支行、嘉鱼吴江村镇银行、中国银行嘉鱼县支行、中国民生银行嘉鱼小微支行、中国人民财产保险公司嘉鱼支公司、中国人寿保险公司嘉鱼支公司、长江证券股份有限公司嘉鱼发展大道证券营业部“2018年度金融支持嘉鱼经济发展贡献奖”。

二、对在武汉股权托管交易中心挂牌的湖北助民食品股份有限公司、湖北嘉珍生态农业发展股份有限公司、武汉神农春酒业股份有限公司、武汉一力涂料股份有限公司、湖北紫珑涂料科技股份有限公司等5家企业分别奖励人民币20万元。

对在武汉股权托管交易中心挂牌（科技板）的湖北怡和亚太卫生用品有限公司、湖北元拓铝合金模架制造有限公司、湖北海源木业有限责任公司、湖北中诚电气有限公司等4家企业分别奖励人民币5万元。

三、对武汉汉麻生物科技有限公司等45家企业给予嘉鱼县2018年度科技创新项目奖励（见附件1）。

四、对高铁岭镇、官桥镇、潘家湾镇等3家嘉鱼县工业经济发展目标考核优秀单位予以表彰。

五、对鱼岳镇、潘家湾镇、簰洲湾镇、嘉鱼经济开发区等4家嘉鱼县中小企业成长工程优秀单位予以表彰。

六、对汪婷等11位嘉鱼县2018年度工业经济工作优秀个人予以表彰（见附件2）。

七、对新获核准注册“地理标志证明商标”的嘉鱼县高铁岭镇嘉联水产协会、嘉鱼县渡普松康水产协会、嘉鱼县粮食行业协会分别奖励人民币10万元。
