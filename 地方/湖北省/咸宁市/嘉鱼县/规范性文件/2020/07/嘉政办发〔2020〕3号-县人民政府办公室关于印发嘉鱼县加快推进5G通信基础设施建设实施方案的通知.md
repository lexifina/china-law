# 县人民政府办公室关于印发嘉鱼县加快推进5G通信基础设施建设实施方案的通知

各镇人民政府，县政府各部门，嘉鱼经济开发区，武汉新港潘湾工业园:

经县人民政府同意，现将《嘉鱼县加快推进5G通信基础设施建设实施方案》印发给你们，请结合实际，认真贯彻落实。

2020年6月8日

嘉鱼县加快推进5G通信基础设施建设

实施方案

为抢抓5G产业发展新机遇，加快推进5G网络建设，坚持信息基础设施的战略性公共基础设施地位，合理统筹利用城市公共资源，让5G发展成果更好地造福全县人民，更好地服务全县经济社会发展，根据《湖北省电信设施建设与保护办法》(省政府令第406号)、《省人民政府关于印发湖北省5G产业发展行动计划(2019—2021年)的通知》(鄂政发〔2019〕18号)、《市人民政府办公室印发咸宁市关于加快5G通信基础设施建设实施方案的通知》(咸政办发〔2020〕9号)精神，制定本方案。

一、发展目标

2020年，全县力争开通5G基站100座，实现城区热点区域覆盖，开展5G场景示范应用;到2022年底，全县开通5G基站400个，其中改造基站350个，新建基站50个，县城区、镇区5G网络基本实现连续覆盖，5G与相关产业链深度融合，5G对经济高质量发展的赋能作用明显增强，持续壮大对全县数字经济的贡献。

二、重点任务

(一)加快5G网络建设

1.加快全县5G基站规划建设。在中国铁塔股份有限公司咸宁分公司嘉鱼办事处(以下简称“县铁塔公司”)已经完成4G/5G 专项规划的基础上，将5G基站建设规划纳入相关控制性详细规划，将5G基站站址、机房及管线、电力等配套设施纳入基础设施专项规划，将交通干线与重要交通枢纽场所基站纳入建设规划，进一步完善5G基础设施建设发展规划;今后，在编制国土空间、住房建设、交通设施等规划时，同步落实5G基站站址、机房、电源、管道等配建空间，并明确规划、建设与管理要求。将县铁塔公司纳入县规委会，发挥好铁塔公司在5G基站建设中的主导性作用，使5G建设规划科学合理。(责任单位:县自然资源和规划局、县发改局、县科经局、县住建局、县交通运输局、县铁塔公司、各基础电信企业，嘉鱼经济开发区，各镇人民政府)

2.加强公共资源向5G基站建设开放。按照“政府主导、铁塔统筹、开放共享、服务社会”的原则，合力推进5G基础设施共建共享。每年年初，由县铁塔公司统筹县内各基础电信企业5G建设需求，形成需要公开的公共建筑、绿化用地、物业资源等开放清单，经县政府批准后，明确上述公共资源所属产权单位为责任单位。县内各党政机关、事业单位(含学校、医院等)、国有企业等楼宇资源、公共基础设施、各类杆塔资源要全力支持5G基站建设，实现开放共享，禁止任何单位或个人在基站建设和运行维护中违规收取不合理费用。明确县铁塔公司为通信行业共建共享代表，入驻县行政服务中心办事大厅，配合县自然资源和规划、住建部门，加强和规范新改扩建住宅和商业楼宇预留5G宏站、微站、室内分布系统以及受理、办理新建小区、新(翻)建市政道路、综合管网(管廊)、大型工程项目(含工业园区等)配套通信工程等设施的审批服务，实现建筑主体工程与5G通信基础设施同步规划、建设、验收与开通。县住建部门要督促房地产开发企业、物业企业配合做好住宅小区移动通信网络覆盖工作，支持5G基站建设与维护。由县住建局牵头，县政务服务和大数据管理局督办协调，结合实际做好房屋建筑的规划、施工、验收流程优化工作，以加快我县的5G通信基础设施建设。(责任单位:县住建局、县政务服务和大数据管理局、县自然资源和规划局、县铁塔公司，嘉鱼经济开发区，各镇人民政府)

3.快速有序推进5G网络覆盖。按照“先城区热点区域，再主城区，后各镇重点区域”的建设原则，有序推进全县5G网络建设覆盖。加快以5G网络为重点的无线宽带城市建设，推进全县交通干线与重要交通枢纽场所、热点区域5G网络建设，构建连续覆盖的5G网络。(责任单位:县科经局、县自然资源和规划局、县交通运输局、县住建局、县铁塔公司、各基础电信企业，各镇人民政府，嘉鱼经济开发区)

(二)加快发展5G设备生产制造业

加强与武汉东湖高新技术开发区等重点5G产业基地对接，着力引进一批5G设备制造和服务企业，实现重要设备本地生产配套，加快我县5G设备生产制造业发展，提升5G基站电源、光纤光缆、电子元器件、服务器、传输光模块、天线等产品技术水平及产业化能力。(责任单位:县招商和投资促进中心、县科经局，嘉鱼经济开发区，各镇人民政府)

(三)加快5G规模化示范应用

大力推进5G+工业互联网、智慧园区、超高清视频和VR(虚拟现实)/AR(增强型虚拟现实)/MR(混合现实)、远程健康医疗、智慧教育、智慧应急、智慧旅游、智慧环保、智慧农业、智慧物流商贸和北斗位置服务、数字政府等领域的5G应用，带动5G产业发展。(责任单位:县科经局、县教育局、县卫健局、县农业农村局、县交通运输局、县应急管理局、县文化和旅游局、市生态环境局嘉鱼县分局、县政务服务和大数据管理局，各镇人民政府，嘉鱼经济开发区)

三、保障措施

(一)建立协调推进机制

成立县5G通信基础设施建设领导小组(不再另行发文)，由分管副县长为组长，县政府办分管副主任和县科经局局长为副组长，县发改局、县教育局、县科经局、县公安局、县人社局、县自然资源和规划局、市生态环境局嘉鱼县分局、县住建局、县交通运输局、县农业农村局、县文旅局、县卫健局、县应急管理局、县政务服务和大数据管理局、县林业局、县城管执法局、县招商和投资促进中心、嘉鱼经济开发区、县供电公司、县铁塔公司、县电信公司、县移动公司、县联通公司、县楚天视讯公司分管负责同志为成员。领导小组下设办公室，办公地点设在县科技局，由县科经局分管副局长兼任办公室主任，县铁塔公司经理担任常务副主任。领导小组办公室负责全县5G通信基础设施建设工作的日常事务和组织协调工作，采取定期召开联席会议、现场办公调研、下发督办通报等方式，督促推动工作落实。各镇人民政府、嘉鱼经济开发区要建立相应工作机制，落实工作任务，推动5G通信基础设施建设相关工作全面深入开展。(责任单位:县5G通信基础设施建设领导小组成员单位，各镇人民政府，嘉鱼经济开发区)

(二)加强5G用地资源保障

各镇人民政府、嘉鱼经济开发区每年根据县铁塔公司、各基础电信企业申报清单，将需要独立占地的5G基站和网络建设用地需求纳入年度用地计划，合理安排用地，及时办理权证。支持县铁塔公司、各基础电信企业按公用设施用途落实用地，并按照有关规定实施供应。对于移动通信基站等用地面积小、分布点多的用地，可采取配建方式供应土地并依法取得地役权。各镇人民政府及相关部门要为5G基站建设用地申请、报建开辟绿色审批通道，简化审批流程，缩短审批时限。(责任单位:县自然资源和规划局、县城管执法局、县铁塔公司、各基础电信企业，嘉鱼经济开发区，各镇人民政府)

(三)加强5G电力资源保障

县供电公司应简化审批流程，建立基站用电报装绿色通道，提高通信设施用电报装效率。实施5G基站单独用电申请、单独开户报装，同时对存量基站电力增容给予支持。推动存量转供电改为直供电，县铁塔公司、各基础电信企业要摸清全县转供电基站安装位置、被转供电主体等基本情况，与县供电公司对接并提出申请，分类实施。公变供电区域内的改为直供电;专变红线内的，要联合查看现场，具备改直供条件的要改为直供，暂时不具备改直供条件的要逐步解决。对于无法接入直供电的站点，涉及各级党政机关、财政保障运营的事业单位及国有企业，应按照直供电价格支持县铁塔公司、基础电信企业5G基站的运营。(责任单位:县供电公司、县铁塔公司、各基础电信企业，嘉鱼经济开发区，各镇人民政府)

(四)加强5G网络基础设施保护

各镇人民政府要认真贯彻落实《湖北省电信设施建设保护办法》，加大对5G等各类通信网络基础设施安全保护的工作力度。县公安部门要加强对通信网络基础设施的保护，依法惩处危及网络基础设施安全的违法行为，严厉打击盗窃、破坏网络基础设施的犯罪活动，严肃查处野蛮施工破坏网络基础设施的行为。各镇人民政府、嘉鱼经济开发区要将因城市建设、规划调整、市政维修、道路维修新建、开发区厂矿企业新建等需要改动、迁移通信杆路、管道、基站、机房等通信设施产生的迁改搬迁费用纳入整体工程预算，建设单位应按照有关标准予以补偿;造成通信设施损毁的，应予以赔偿。对由于5G建设需要新建管道导致的道路破损，县城市管理执法局要简化审批手续，县铁塔公司、基础电信企业实施后要及时恢复原貌。(责任单位:县公安局、县科经局、县住建局、县城管执法局、县交通运输局、县铁塔公司、各基础电信企业，嘉鱼经济开发区，各镇人民政府)

(五)严格执行5G技术标准及规范

发挥政府引导和各类市场主体作用，调动各方积极性，组织供需对接，推进5G网络和应用协同发展。县住建部门要按照上级相关要求，对新建住宅与商业楼宇预留5G宏站、微站、室内分布系统等设施建设进行监督。县交通运输、公安等部门要探索“多杆合一”智能杆塔建设标准，明确杆塔承重及用电标准，推动多功能杆塔资源合用合建，确保智能杆塔的功能性、安全性、统一性。(责任单位:县住建局、县政务服务和大数据管理局、县交通运输局、县公安局、县铁塔公司，嘉鱼经济开发区，各镇人民政府)

(六)加快5G人才引进培育

大力实施重点人才引进计划，出台配套激励政策，推动创新创业。厚植5G人才培育环境，支持县内高校、科研机构与企业联合精准培养，加强5G人才储备，助力5G产业高质量发展。(责任单位:县委人才办、县教育局、县人社局，嘉鱼经济开发区，各镇人民政府)
