# 县人民政府办公室关于印发崇阳县2019年春运安全工作方案的通知

崇政办发〔2019〕1号

人民政府办公室关于印发

崇阳县2019年春运安全工作方案的通知

乡、镇人民政府，县政府有关部门：

《崇阳县2019年春运安全工作方案》已经县人民政府同意，现印发给你们，请认真组织实施。

2019年1月16日

崇阳县2019年春运安全工作方案

2019年春运从1月21日开始至3月1日结束，为期40天。为切实做好我县春运安全管理工作，确保春运期间交通畅通与和谐有序，让人民群众过一个欢乐祥和的春节，特制定本方案。

一、指导思想与工作目标

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九大和十九届二中、三中全会精神，牢固树立“四个意识”，坚决做到“两个维护”，切实提高政治站位，强化责任担当，继续围绕打造“平安春运、便捷春运、温馨春运、诚信春运”，加强领导、周密安排、合理调度、灵活配置、突出重点，抓安全、保畅通，全力以赴做好春运各项工作，圆满完成2019年春运任务。

春运安全工作目标：确保站、场、港秩序井然，无混乱和群众拥挤骚乱现象，无治安和刑事案件，杜绝重大灾难事故发生；确保各种运输工具在运输途中不发生重大交通事故和火灾事故，杜绝群死群伤事件；旅客候车、出行方便舒适，安全及时，无长时间群体性滞留现象；县内交通与长途运输相适应，客货兼顾，衔接恰当，运作协调；确保旅客走得了、走得好，确保工农业生产、人民生活物资运输需要。

二、组织领导与工作步骤

县春运安全工作领导小组要切实加强2019年全县春运安全工作的组织领导，领导小组由分管交通运输的副县长担任组长，县人武部、县委宣传部、县总工会、团县委、县发改局、县教育局、县公安局（交警大队）、县民政局、县财政局、县人社局、县交通运输局、县旅游局、县城管执法局、县安监局、县物价局、县气象局、县供电公司、县消防救援大队、县武警中队等单位负责人为成员。各乡镇、各有关部门要相应成立工作专班，具体抓好各自负责的春运安全工作。全县春运安全工作分三个阶段进行：

第一阶段：动员准备阶段。从2019年1月15日至1月20日。制定出台春运安全工作方案和相应文件，召开全县春运工作会议

第二阶段：组织实施阶段。从2019年1月21日至3月1日。此期间县经信、安监、公安交警、教育、交通等部门要根据各自的工作职责和春运工作实施方案，采取有效措施，加强春运安全监管，深入开展春运平安集中大行动，强化源头管理，加强春运安全监管，确保春运安全。

第三阶段：总结评比阶段。从2019年3月2日至3月8日。全县春运工作结束后，县春运安全工作领导小组将对全县春运安全管理工作进行总结。

三、工作责任和措施

2019年我县春运安全管理工作主要采取以下措施：

（一）开展交通安全大宣传。春运期间，全县统一开展以春运交通安全为主题的宣传教育活动：在县电视台设置春运安全出行信息专题栏目，定时发布省、市、县境内道路交通信息，提醒广大司乘人员注意选择出行线路，安全行驶；对所有参加春运的司乘人员、船员渡工开展一次交通安全宣传教育和冬季安全行车行船常识教育，以增强安全防范能力；悬挂春运交通安全宣传标语。

（二）合理安排陆路运力，加强春运安全保障。据相关部门预测，今年春运期间，我县旅客流量将达到80多万人次。针对这一特点，全县准备了500多台客车、出租车投入春运，确保全县人民群众的出行需求。要进一步完善恶劣天气与突发公共事件运力保障应急预案，提前做好应急保障准备工作。

（三）开展道路客运车辆大检查。春运前，县交通运输管理部门、公安交警要对全县所有参加春运的客车进行一次全面综合技术性能检测，严禁不合格、安全无保障的客车参加春运，对参加春运的驾驶人进行一次集中排查，严禁驾驶证记满12分的驾驶人参加春运；单程在400公里以上的客车，必须配备两名以上驾驶员；严禁超载、超速和疲劳驾驶，超载、超速的一律按有关规定进行处罚，超载20%以上的，取消其春运资格。

（四）加强客（货）运市场监管。交通运输部门要公布监督举报电话，接受社会监督。要加强运输服务质量投诉，接到举报要坚决予以查处，做到举报一起，查处一起。要严厉查处超载、超速、不按规定线路运营、站外组客、无证营运等违法行为。对无证经营、超范围（类别）经营和“甩”客、“卖”客、“倒”客、“宰”客等侵害乘客合法权益的违章行为，要从严处罚。要加强对出租车的监管，从严查处出租车拒载和未经乘客同意擅自拼载等违章行为。要协助物价部门做好客运票价的监督管理，严禁乱涨价。运政人员在执法时，要做到文明礼貌、规范执法、杜绝乱罚款、乱扣车的行为发生。

（五）开展优质服务，完善应急预案。交通运输部门要牢固树立“以人为本”的服务理念，切实增强服务意识，努力提高服务水平，营造文明、温馨、和谐的出行环境。要通过电视、广播、短信、微信、微博等渠道，及时发布天气变化、班次增减、客票余额等免费信息，方便旅客合理安排出行。要做好运输工具和场站的卫生防疫工作，防控疾病传播。运输企业和客运站要以继续开展“情满旅途”、“务工人员平安返乡”等活动为载体，进一步拓展多种形式的便民服务，落实客运服务标准，增设便民服务点，为旅客候乘提供便利。要在客流高峰期间增派服务人员，引导旅客购票、乘车，解答旅客咨询，为有困难的旅客提供帮助。夜晚有旅客候车时，要开放候车室并提供必要服务，努力提升服务质量和水平。

（六）开展道路安全隐患大排查。交通运输部门要抓好路面管理，做好公路养护维修，保持路面平整畅通。县公安交警部门要对辖区危险路段及存在的安全隐患进行一次全面的清理排查，发现安全隐患，及时上报，督促整改落实。各乡镇对辖区内的乡村道路春运安全管理负主要责任，要加大对乡村道路交通秩序的整治力度，督促驻村干部，发动村组干部利用路熟、人熟的特点，做好宣传，加强通村公路的监管，确保道路安全畅通。

（七）开展交通秩序大整顿。公安交警部门要认真履行职责，确保春运期间交通秩序井然有序。一是集中时间、集中警力，对机动车超速、客车超员、疲劳驾驶、酒后驾驶、无证驾驶、车辆带“病”行驶、车辆违章停放和非机动车辆违规载人等8种严重交通违法行为开展不间断的集中整治行动。特别是针对节日期间农村群众探亲访友活动集中、农村道路短途客运量集中的特点，严查严纠三轮汽车、低速载货汽车和摩托车违规载人的交通违法行为。二是开展无牌无证车辆集中查处行动，大力消除车辆安全隐患。要组织民警深入农村、社区、企业、单位，向群众宣传使用无牌无证、假牌假证、挪用套用号牌机动车的危害性及相关处理规定，加大对各类黑市车辆的查处打击力度。对查扣的车辆，一律统一封存，集中处理，严禁罚款放行。三是加大通行车辆测速管制，以压车速、纠违停。每天上路检查不少于6小时，减少和避免隐形违章事故发生。

（八）加强水上安全监管。县地方海事局要加大对渡口渡船的安全监督检查力度，加强对“四客一危”船舶的监管，严厉打击船舶超载和非法载客等行为，全面排查和整改安全隐患。要掌握大风、雨雪、雾天等气象信息，及时向船舶发出危险天气警告，针对恶劣天气要及时启动应急预案，加强渡口、码头、船员管理，在特别恶劣的天气情况下要采取交通管制等相关安全监管措施。要督促乡镇政府切实履行乡镇船舶安全管理职责，落实事故预防措施，防止船舶事故发生，确保假日水上交通运输安全。

（九）加强学校安全监管，确保学生安全回家、返校。一是加强学校安全教育。具体要求每个学校做到“三个一”，即：每个班主任有一节安全教育教案，开好一个安全专题班会，最少召开一次全校安全教育大会。二是错开放假时间。全县小学、中学、高中放假时间要错开。三是加强放学护队。具体做到“三个一”，即：一名老师护队，一面红旗引路，一条直线行走。四是开展校车集中整治行动。各乡镇人民政府和县教育局、交警部门在学校放假、开学前，对辖区内所有接送学生车辆进行一次联合整治，对驾驶员和学生进行一次交通安全大宣传，严格落实省公安厅“四个严禁”和“五个落实”的要求，并加大检查和处罚力度，确保学生安全回家、返校。五是实行安全包保责任制度。县教育部门要全面落实局长包片、股室包线、学校校长包校的安全包保责任制，确保学生安全。

（十）加强监督检查，严格执行值班制度。县春运办公室要不间断不定时对各乡镇重点路段、渡口、码头进行监督检查，对各主管部门履行工作职责情况进行跟踪监督，牢牢把握春运安全工作环节。同时，严格执行值班制度，向社会公布4部值班电话：县交通运输局带班领导黄斌（手机[电话略]）、叶雄（手机[电话略]），值班电话：3395159、3328777；县交警大队带班领导饶宏武（手机[电话略]），值班电话：3395211；县安监局带班领导曾仲龙（手机[电话略]）值班电话：3390455。
