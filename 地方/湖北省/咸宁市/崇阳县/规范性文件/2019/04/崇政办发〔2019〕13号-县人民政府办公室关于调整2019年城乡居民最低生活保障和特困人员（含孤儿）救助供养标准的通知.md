# 县人民政府办公室关于调整2019年城乡居民最低生活保障和特困人员（含孤儿）救助供养标准的通知

崇政办发〔2019〕13号

县人民政府办公室关于

调整2019年城乡居民最低生活保障和

特困人员（含孤儿）救助供养标准的通知

各乡、镇人民政府，县政府有关部门：

为贯彻落实城乡居民最低生活保障和特困人员（含孤儿）救助供养标准动态调整机制，切实维护困难群众和孤儿基本生活权益，根据《市人民政府办公室关于调整2019年城乡居民最低生活保障和特困人员（含孤儿）救助供养标准的通知》（咸政办发〔2019〕11号）要求，现将我县2019年城乡居民最低生活保障和特困人员（含孤儿）救助供养标准调整如下：

一、城市低保保障标准：580元/人/月

二、农村低保保障标准：5500元/人/年

三、农村特困供养人员供养标准分别为：自理能力完好对象9800元/人/年（含生活费6900元，护理费2900元）；半失能对象11000元/人/年（含生活费6900元，护理费4100元）；全失能对象25074元/人/年（含生活费6900元，护理费18174元）。

城市特困供养人员供养标准分别为：自理能力完好对象13920元/人/年（按城市低保保障标准2倍计算，含生活费9048元，护理费4872元）；半失能对象15120元/人/年（含生活费9048元，护理费6072元）；全失能对象27222元/人/年（含生活费9048元，护理费18174元）。

四、孤儿养育标准为：集中供养22272元/人/年;分散供养1160元/人/月。

新标准从2019年4月1日开始执行。

崇阳县人民政府办公室

2019年4月8日
