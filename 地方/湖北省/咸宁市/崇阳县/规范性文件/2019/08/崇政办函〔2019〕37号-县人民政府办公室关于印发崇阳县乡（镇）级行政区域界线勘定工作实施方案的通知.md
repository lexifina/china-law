# 县人民政府办公室关于印发崇阳县乡（镇）级行政区域界线勘定工作实施方案的通知

崇政办函〔2019〕37号

县人民政府办公室关于印发

崇阳县乡（镇）级行政区域界线勘定

工作实施方案的通知

各乡、镇人民政府，县政府有关部门：

《崇阳县乡（镇）级行政区域界线勘定工作实施方案》已经县人民政府同意，现印发给你们，请认真组织实施。

2019年8月14日

崇阳县乡（镇）级行政区域界线勘定

工作实施方案

根据《省人民政府关于开展乡（镇、街道）级行政区域界线勘定工作的通知》（鄂政函〔2018〕165号）要求，为做好崇阳县乡镇级行政区域界线勘定工作，结合我县实际，制定本实施方案。

一、指导思想

全面提升崇阳县行政区域界线法制化、规范化、精细化管理水平，充分发挥地名普查成果对提升社会治理水平、服务经济发展的重要作用。遵循国家有关行政区域界线勘定的规定，从有利于行政管理、有利于社会稳定、有利于群众生产、有利于资源保护出发，坚持以人为本、顾全大局、实事求是，互谅互让、尊重历史、立足现实的原则，采取先易后难和友好协商解决的方法，有计划、有步骤地实施界线勘定工作。

二、组织实施及范围

乡镇勘界是政府行为。县人民政府成立崇阳县乡（镇）级行政区域界线勘定工作领导小组及办公室。原则上，村级界线核定由所在乡（镇）负责组织实施，乡镇级界线勘定由县政府组织实施。本次勘界范围包括但不限于全县所有乡（镇）级行政区域界线。以勘定乡级界线为主，同时核定村级界线，落地县级界线。

三、目标任务

本次乡镇勘界工作不是重新调整行政区划，而是以乡（镇）行政区域管辖现状为基础，依据有关法律法规和勘界规程规范，充分利用土地调查、地名普查、地理国情普查、林业普查、农村集体土地确权、不动产登记等成果，基于1:10000正射影像图，采用测绘、地理信息、互联网等技术，核实法定线、勘定习惯线、解决争议线。以村级权属界线为基础，经逐一核定后最终形成反映乡（镇）级行政区域界线实际走向的勘界协议书及相关图文图表等成果资料，明确乡（镇）行政区域管辖范围，将全县乡（镇）级行政区域界线法定化，用法律的形式将县级及乡（镇）级行政区域界线固定下来。在此基础上将原有的1:50000线划图上已法定的县级界线落地细化，使县级界线更加清晰明确。

四、实施步骤

按照省政府统一要求，乡镇勘界从2019年1月开始，到2021年12月结束，分三个阶段实施。

（一）前期准备阶段（2019年6月-2019年9月）

具体工作任务：一是成立崇阳县乡（镇）级行政区域界线勘定工作领导小组，并设立办公室；从县自然资源局、县林业局、县农业农村局、县水利局等部门抽调专业勘测技术骨干，组建工作专班。乡镇相应成立工作专班，配备专业技术人员，负责乡镇内部的界线核实确认工作和乡镇之间的界线审核工作。二是制定勘界工作实施方案，并报省、市勘界工作领导小组备案。三是选择合格的第三方测绘技术队伍，对相关勘界人员进行有关业务学习及培训，并建立乡镇勘界通讯联络机制。四是购置必要的勘界办公设备，保证勘界机构正常运行。

（二）勘界实施阶段（2019年10月-2020年9月）

1.草绘界线。首先由勘界办公室收集全县土地调查、林业普查、地名普查、农村集体土地确权、农村土地承包经营权、不动产登记等成果资料；然后由第三方测绘技术单位在省勘界办统一制发的乡镇勘界工作底图上草绘各级界线走向并重点比对，对界线明显切割建筑物、农田、池塘等不符合实际情况的地段逐一进行标注，形成勘界工作底图。

2.核定村级界线。在1:10000影像图上根据农村集体土地确权等资料绘制村级权属界线，由技术人员重点比对界线走向情况，对界线明显切割建筑物、农田、池塘等不符合实际情况的地段进行标注，再由乡镇组织所属行政村人员对界线共同进行核对，核定无误后，双方代表在影像图上签字盖章确认；图上标绘有误的，现场指出并进行标注，确需现场勘界，由第三方测绘技术人员重新实地测绘并在工作地图上标绘。

3.勘定乡级界线。在核定村级界线的基础上，由县勘界办公室组织毗邻乡（镇），根据勘界工作底图，对乡级界线进行确认，并签订界线协议书，绘制协议书附图。具体做好以下工作：

（1）图上核定边界线。双方乡（镇）按照国家和省政府规定的有关划界基础的标准，参照历史习惯线，以国家第二次土地调查图和土地承包经营权证以及有关双方边界争议调处结果等有效材料为基础，在现有最新版的1：10000遥感影像图上草绘出乡（镇）边界线走向，在县勘界办公室的组织协调下，双方进行对图核界，应尽可能做到行政区域界线与自然资源权属相一致。对双方标绘一致的地段，按双方一致的画法确定边界线；对双方标绘虽不一致，但实际管辖却无争议的地段，根据实际的行政区域管辖情况确定边界线；对双方标绘不一致，实际管辖有争议的地段，原则上依照地形图上原有的界线，协商确定边界线，实行行政区域界线与自然资源权属界线分离，允许界内有“插花”，界外有“飞地”；如双方同意调整，应本着互谅互让的原则，能够调整的尽量调整，不能调整的维持现状经营，形成协议书和附图，并标注说明。边界线确定后，双方乡（镇）人民政府领导必须在转绘好的1：10000遥感影像图上签字，并加盖乡（镇）人民政府公章。

（2）实地勘定边界线并设立界桩。由县勘界办统一组织，由第三方测绘技术人员实地进行勘定边界线和埋桩工作。

边界线以山为界时，边界以分水线或山脊线划分；边界线以河流为界时，边界以河流中心线划分；边界线以堤塘、桥梁、沟渠、道路和其他坚固建筑物为界时，边界沿这些永久性地物划分。

除乡（镇）界线与省、县边界衔接处可不埋设界桩外，乡（镇）相邻边界线三交点应埋设界桩；边界线上设立界桩的数量由县勘界办视情况另行确定。边界线命名、编号及界桩勘定埋设，由县勘界领导小组统一组织，按照《湖北省乡（镇、街道）级行政区域界线勘定工作技术规范》（以下简称《规范》）执行。

（3）起草边界线协议书。实地勘界埋桩后，由勘界办和第三方技术人员联合起草协议书，协议书内容主要包括以下内容：边界工作概况、重要问题处理结果、边界线走向和界桩位置说明、边界的维护和管理、协议的其他条款、附图等。协议书中注明边界线走向以双方标绘的地形图为准，不再用文字描述。

（4）有关问题的解决和裁定。对意见不统一的问题要及时调处，不可回避矛盾，久拖不决，使矛盾升级或复杂化。乡（镇）级行政区域界线勘界期间，对有关乡（镇）双方多次协商仍无法勘定的争议界线，由争议双方的乡镇人民政府提交各自的解决方案并附边界线地形图，报县人民政府处理。县人民政府受理后，由县民政局会同有关部门调解；经调解不成的，由县民政局会同有关部门提出解决方案，报县人民政府决定。

4.落地县级界线。将原有的1:50000线划图上法定的县级界线按比例放大至1:10000影像图上，并与核定后的村级界线进行比对，重点比对放大后的县级界线与核定后的村级界线在图上距离偏差较大以及县级界线切割地理实体情况较为明显的部分。由于本县和邻县勘界工作进度及时间安排不一致，县级界线的落地原则上由咸宁市牵头作业单位单方完成后交由对方进行确认，确认无误后，由双方县级人民政府签字盖章确认。

（三）总结上报阶段（2020年10月-2020年12月）

1.成果数据整理。以乡（镇）为单位，由第三方测绘技术单位对勘界成果数据进行整理、入库，成果数据技术要求参照《规范》执行。

2.联合上报审批。协议书以及附图等有关勘界成果经双方乡（镇）人民政府签字盖章后，由县人民政府逐级上报省政府审批。协议书及附图原件，按档案管理办法，由县勘界办公室统一汇总，以乡（镇）为单位整理成册存档，并组织制作乡（镇）行政区划图向社会公布。

3.成果验收。乡镇勘界成果验收由省勘界办统一组织实施，验收办法参照《规范》执行。

4.资料归档。乡镇勘界档案由县勘界办以乡（镇）为单位整理归档，并向市勘界办上报勘界资料电子档。

5.开展和谐平安边界创建活动。各乡（镇）一定要高度重视，在完成勘界的同时要管好界，做到乡（镇）勘界与平安边界创建活动同部署、同开展。

五、经费保障

根据鄂政函〔2018〕165号文件要求，此次勘界经费列入县级财政年度预算。预算经费主要用于购买勘界用地形图和器材装备、边界线的勘察测绘、界桩的制作埋设、勘界资料的整理建档，召开边界争议协调会、技术培训、聘用人员工资，日常办公和车辆费用等。

六、工作要求

（一）高度重视，加强领导，确保勘界工作有序开展

各乡镇、各部门要高度重视乡（镇）勘界工作，将其列入重要议事日程，作为维护社会稳定，构建和谐社会，加强地方经济建设的重要工作来抓。成立由县政府分管副县长任组长，民政、财政、公安、法院、司法、自然资源、水利、农业农村、林业等部门为成员单位的乡（镇）级行政区域界线勘定领导小组，协调解决勘界工作重大问题；领导小组办公室设在县民政局。在人、财、物等方面县政府要给予全力的支持，选配一批政策水平高、事业心强、专业技能精的人员，充实到勘界工作队伍中来，确保乡（镇）级勘界工作的有序开展。

（二）科学安排，周密部署，确保勘界工作如期完成

乡镇勘界工作是一项系统的综合性的工作，时间紧、任务重、政策性强、技术要求高、工作难度大。各乡镇要按照县政府统一部署，科学安排好工作任务，制定好具体的实施方案，统筹兼顾好各项工作，确保乡镇勘界及村级行政管辖区域认定工作稳妥推进，如期完成。

（三）通力合作，密切协同，确保勘界工作正常运转

乡（镇）勘界所涉及的单位部门较多，县民政局要切实负起责任，积极主动做好工作，各单位部门之间、毗邻乡镇及所属村组之间要相互支持，通力合作，密切协同。勘界所涉及到的各类资源权属的归属问题，在处理时各相关部门要派人提供合法依据，共同处理权属纠纷。

（四）依法依规，顾全大局，确保边界地区和谐稳定

在乡镇级界线勘定之前，各地必须维持勘界前边界地区的现状，严禁借勘界之机挑起新的边界争议。已经存在边界争议的地方，各村（居）必须采取有效措施防止事态扩大，任何一方都不得往争议地方破坏自然资源。边界争议的处理必须严格按照《行政区域边界争议处理条例》的有关规定依法进行。严禁聚众闹事、械斗伤人，严禁抢夺、破坏国家、集体和个人财产。对借机制造矛盾、设置障碍、干扰勘界工作正常进行、挑起冲突的，要依照有关法律法规严肃处理；对造成严重后果、构成犯罪的，要移交司法部门依法追究刑事责任。
