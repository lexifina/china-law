# 通城县气象局关于防雷安全公益性检测范围及相关事项的公告

发文日期：

2017年03月20日

为进一步做好防雷减灾工作，贯彻落实上级文件精神，现将我县防雷安全公益性检测范围及相关事项公告如下：

县级国家机关及县直公益类事业单位办公场所、城区义务制教育中小学校、县级公办社会福利机构等纳入我县防雷安全公益性检测范围。上述范围内防雷安全检测由通城县防雷中心负责。

请申请单位经办人携带身份证明、单位统一社会信用代码，下载并填写《防雷公益性检测申请表》，到通城县防雷中心申请。

通城县防雷中心联系电话：0715-4322358。

特此公告。

2017年3月16日
