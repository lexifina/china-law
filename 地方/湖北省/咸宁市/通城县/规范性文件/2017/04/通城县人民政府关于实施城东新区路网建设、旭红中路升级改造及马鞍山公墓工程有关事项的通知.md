# 通城县人民政府关于实施城东新区路网建设、旭红中路升级改造及马鞍山公墓工程有关事项的通知

为保障通城县重点基础设施建设，提高民生服务质量，改善城区交通条件，满足城市经济发展和人民生活质量不断提高的需要，经研究，决定实施通城县城东新区路网建设、旭红中路升级改造及马鞍山公墓三个工程，现将有关事项通知如下：

一、项目概况

1、通城县城东新区路网项目建设“三纵四横“的7条道路，分别为解放东路延伸段、学府路、塘湖路、四庄路、沙堆路、白沙路延伸段、广场南路延伸段，建设总里程13公里，路宽50米，为城市次干道。项目总投资35001.38万元，工期2年。

2、通城县旭红中路项目对全长2200米、宽40米的旭红中路路段进行市政配套工程建设。其中，机动车道为沥青混凝土路面。项目总投资20071.2万元，工期1年。

3、通城县马鞍山公墓项目建设墓穴5万个，集人文景观、园林艺术、追思悼念、骨灰安葬于一体，能满足今后50年左右丧葬需求的新型生态公墓。项目总投资为95014.23万元，工期3年。

二、项目实施单位

由通城县惠普投资开发有限公司作为该项目实施主体，负责项目投融资、实施及管理工作，县财政局、县民政局、县住建局等有关部门配合做好项目监督和实施工作。

三、通城县城东新区路网建设、旭红中路升级改造及马鞍山公墓项目服务资金列入政府采购目录

将通城县城东新区路网建设、旭红中路升级改造及马鞍山公墓项目服务资金列入政府采购目录，同时加快推进项目实施，由县人民政府与通城县惠普投资开发有限公司签订《政府购买服务协议》，以明确购买双方的权利和义务。

四、项目资金安排

本项目资金安排按照与县政府签订的《政府购买服务协议》的相关约定履行。
