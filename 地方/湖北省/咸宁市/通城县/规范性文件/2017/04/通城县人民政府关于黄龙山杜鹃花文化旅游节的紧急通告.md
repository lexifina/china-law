# 通城县人民政府关于黄龙山杜鹃花文化旅游节的紧急通告

发文日期：

2017年04月30日

黄龙山杜鹃花文化旅游节由湖北龙都影业公司举办，于5月1日正式开幕。由于黄龙山坪等林场存在交通路况不好、基础设施不完善等因素，根据县安监局风险评估，存在一定安全隐患，为了维护公共安全，经县委、县政府研究同意，5月1日对进入坪等林场现场的人流量实行总量管控，进入坪等林场风景区的游客人数控制在1000人之内。请参加黄龙山杜鹃花文化旅游节的游客于5月1日早上7：30开始在麦市镇陈塅小学领取《游览证》，凭《游览证》进入主会场，无证者一律禁止进入。

特此通告

通城县人民政府
