# 关于做好2014-2016年度省、市级文明村镇申报推荐工作的通知

各县、市、区文明办，市文明委各成员单位：

近年来，在省委和市委的坚强领导下，全市各地各部门以培育和践行社会主义核心价值观为根本，深入开展群众性精神文明创建活动，城乡文明程度和居民文明素质进一步提升，为促进经济社会持续健康发展，维护社会和谐稳定发挥了重要作用。为充分展示全市文明村镇创建工作的丰硕成果，进一步提高文明村镇创建水平，推动群众性精神文明创建活动深入开展，根据省文明办下发的《关于做好2014-2016年度省级文明村镇申报推荐工作的通知》文件精神和市文明委工作安排，今年将评选表彰2014-2016年度省、市级文明村镇。现将有关事项通知如下：

一、申报条件

1.全市符合省级文明村镇标准的行政村、乡镇，2011-2013年度省级文明社区，均可申报省级文明村镇；符合市级文明村镇标准的行政村、社区、乡镇均可申报市级文明村镇。

2.在申报前一年内发生下列情形之一的村镇，不得申报和推荐：

（1）主要负责人在本单位任职期间出现严重违纪违法行为或被追究刑事责任的。

（2）辖区内发生重大刑事案件、重大群体性上访事件、破坏森林资源重大行政案件；违反国家计划生育政策；发生重大安全生产责任事故、重大食品药品安全事故、重大环境污染事故；发生严重损害村镇声誉形象的恶性事件。

二、申报推荐程序

1.村镇自愿申报。村镇对照省级文明村镇创建标准和申报条件进行自查，自查合格后逐级申报。

2.县（市、区）择优推荐。县（市、区）文明委对照省级文明村镇申报条件和创建标准，对提出申请的村镇进行测评考核，按照市文明办分配名额（见附件1）确定本地推荐申报名单，报经县（市、区）党委、政府同意并在本地公示后，于5月30日前将书面推荐申报材料报市文明委。

三、有关要求

1.加强组织领导。各地各部门要高度重视，把申报推荐省、市级文明村镇工作作为推进精神文明建设，促进经济社会更好更快发展的重要抓手，摆上重要位置，作出周密安排，严格按时间和程序要求，做好自查、申报、推荐工作。要充分运用报纸、电台、电视台和网络、手机等各类媒体，大力宣传文明村镇创建的先进经验，扩大推荐评选活动的社会影响力，激发群众创建热情，使评选表彰过程成为群众了解、支持、参与创建的过程，成为各地各部门学习先进、比学赶帮、促进各项工作全面进步的过程，推动兴起群众性精神文明创建活动的新热潮。

2.坚持群众标准。要强化群众观念、践行群众路线，发动群众创建，依靠群众创建，把推荐评选过程变成为群众多办好事实事的过程。要坚持问题导向，对群众反映强烈的突出问题，敢于负责、敢抓敢管，及时整治、立行立改，推动乡村环境和社会风尚明显好转。要注重工作实效，听取群众意见，了解群众需求，不搞突击迎检，力戒形式主义。要把群众满意作为最高标准，只有获得群众多数支持认可的，才能予以推荐参评。

3.严格审核把关。申报推荐工作要坚持规范程序，统一标准、公开透明、确保质量、好中选优，不搞平衡照顾，真正把那些工作扎实、创建成绩突出、示范作用明显、群众认可度高的村镇推荐出来。要把推荐评选置于社会监督之下，通过问卷调查、民意测评、资格审核、媒体公示等办法，广泛听取有关主管部门和公众意见，使推荐评选过程公开公平，使推荐评选结果得到社会认可。要严格纪律，对于隐瞒事实、弄虚作假的，一经查实，即取消申报资格。

4.及时报送材料。2017年5月30日前，各县（市、区）文明委将《省级文明村镇推荐报告》、《市级文明村镇推荐报告》（2000字以内）、相关单位征求意见和申报表（见附件2、3、4、5）报市文明办，逾期不报的，视为自动弃权。
