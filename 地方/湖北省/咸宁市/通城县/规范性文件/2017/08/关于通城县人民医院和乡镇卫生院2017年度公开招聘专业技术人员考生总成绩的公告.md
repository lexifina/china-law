# 关于通城县人民医院和乡镇卫生院2017年度公开招聘专业技术人员考生总成绩的公告

通城县人民医院和乡镇卫生院2017年度公开招聘专业技术人员面试工作已结束，现将最终核定的各单位招聘岗位共334名考生总成绩予以公告。
