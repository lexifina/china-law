# 关于塘湖镇卫生院中医岗位体检和考核人员实行递补的通知

发文日期：

2017年09月22日

通城县人民医院和乡镇卫生院2017年度公开招聘专业技术人员中塘湖镇卫生院中医岗位已进入体检和考核程序人员因考核不合格，取消聘用资格。根据招聘方案规定，塘湖镇卫生院中医岗位进入体检和考核程序人员可按总成绩排序实行一次性递补，经报县人社部门同意，该岗位总成绩第二名杨武（身份证号: [身份证号略]）进入体检和考核程序。

卫计公开招聘领导小组办公室
