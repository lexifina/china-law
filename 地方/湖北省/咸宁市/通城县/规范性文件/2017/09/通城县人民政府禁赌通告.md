# 通城县人民政府禁赌通告

为严厉打击赌博违法犯罪行为，维护社会治安稳定，净化社会风气，强力推进以“五禁五治五提升”“七禁六治五建设”为核心抓手的“四城同创”和“美丽家园”等创建工作，深化“文明通城、平安通城”建设，积极响应广大市民呼声，根据《中华人民共和国刑法》《中华人民共和国治安管理处罚法》等法律规定，现就禁赌有关事项通告如下：

一、严禁任何单位、个人开设“斗牛”“三公”“炸鸡”“二八杠”等赌博场所，以及利用地下“六合彩”、非法彩票、赌球、“老虎机”、电子游戏机等形式进行的赌博违法犯罪活动。

二、严禁以麻将馆、棋牌室、活动室、茶楼、茶座（含宾馆、酒店、牌场）等为名进行打牌赌博活动，凡有“抽头”（指抽水渔利）或按小时收取服务费、按桌收取台面费等行为的，一律视为为赌博提供条件，对经营者进行治安处罚，构成犯罪的一律立案追究刑事责任。

三、严禁在隽水城区、乡镇街道、公路沿线等人口密集地的临街立面内外或连体的居住地进行任何形式的带彩棋牌活动，一经发现，均按赌博打击处理。

四、对开设赌场、聚众赌博、跨境赌博、经营地下“六合彩”的庄家、组织者、主要参与者、屡教不改的参赌人员，暴力护赌、追逼赌债的黑恶势力，放高利贷、为赌博提供条件的违法犯罪分子，将依法从重予以惩处。

五、对参与赌博、为赌博提供条件或充当保护伞的党员、干部、国家公职人员，除对个人依法进行处罚外，一律按组织程序先予免职，再依据党纪政纪严肃处理。

六、赌博中形成的债权债务不受法律保护，对查获的赌资、赌具等非法财物，以及赌博违法犯罪活动中的违法所得，一律依法没收。

七、自本通告发布后三日内，全县所有以营利为目的的涉赌场所须立即关闭；有涉嫌赌博违法犯罪行为的，主动到公安机关投案自首，争取从宽处理。在规定期限内未关闭、未主动投案自首的，依法从严惩处。

八、各乡镇、县直各部门、各企事业单位为禁赌工作的主体责任单位，凡因禁赌工作不力，导致赌博现象严重或因赌博引发案件、事件的，对该单位主要领导、分管领导和相关责任人进行党纪政纪处理。

九、全县人民要积极参与禁赌工作，发现涉赌线索及时向公安机关检举揭发，查证属实的，对有功人员予以奖励。对拒绝、阻碍和打击报复国家机关工作人员依法执行禁赌工作的，由公安部门依法予以处罚，构成犯罪的，依法追究刑事责任。
