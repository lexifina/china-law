# 县人民政府办公室关于成立石泉小广场项目建设指挥部的通知

发文日期：

2019年02月19日

隽政办函〔2019〕5号

各乡、镇人民政府，县直相关单位：

为加快推进通城县石泉小广场和石泉路道路刷黑及配套工程建设，县人民政府决定成立通城县石泉小广场项目建设指挥部。现将成员名单通知如下：

指 挥 长：侯红辉 县人民政府副县长

常务副指挥长：胡从周 县政协副主席

副 指 挥 长：卢玲璋 县规划执法局局长

成 员：李 旭 县国土资源局副局长

洪卫兵 县住建局副局长

黎江华 隽水镇党委副书记

岳 军 县园林局局长

熊 皓 县政府办公室秘书科科长

刘国富 县交通运输局项目办主任

胡向阳 县规划执法局干部

指挥部下设办公室，负责项目建设日常工作，岳军同志兼任办公室主任，熊皓同志兼任办公室副主任。

通城县人民政府办公室

2019年2月19日
