# 县人民政府办公室关于成立通城万康医院项目建设指挥部的通知

发文日期：

2019年02月26日

隽政办函〔2019〕7号

各乡、镇人民政府，县直相关单位：

为加快对通城万康医院项目建设的组织领导，确保项目早日落地建成，经县人民政府研究，决定成立通城万康医院项目建设指挥部。现将组成人员名单通知如下：

指 挥 长：王 斌 副县长

副指挥长：雷明顺 县卫计局局长

吴雄文 隽水镇镇长

成 员：付子龙 县卫计局副局长

李 旭 县国土资源局副局长

何永辉 县林业局副局长

刘利锋 县发改局副局长

洪卫兵 县住建局副局长

孔 雄 县规划执法局副局长

付和爱 县公安局副局长

赵会良 隽水镇人大主席

徐甫国 县交通运输局总工程师

指挥部下设办公室，办公室设在县卫计局，付子龙同志兼任办公室主任，负责项目建设工作的协调、服务和推动。指挥部成员任职或分工如有调整，由接任工作的同志替补，不另行文通知。

通城县人民政府办公室
