# 县人民政府办公室关于县《政府工作报告》确定的2019年重点工作责任分解的通知

隽政办发〔2019〕1号

各乡、镇人民政府，县政府各部门，通城经济开发区管委会：

现将县《政府工作报告》确定的2019年重点工作责任分解到各乡镇、县直有关单位，请你们对照责任分工，迅速拟定工作计划，细化保障措施，认真抓好落实，确保各项目标任务圆满完成。

通城县人民政府办公室

2019年2月1日

县《政府工作报告》确定的2019年重点工作责任分解

2019年全县经济社会发展的主要目标：地区生产总值增长9%；全社会固定资产投资增长12%（责任单位：县发改局）；地方公共财政预算收入增长9%（责任单位：县财政局）；规模工业增加值增长8.5%（责任单位：县经信局）；社会消费品零售总额增长12.5%；外贸出口增长12%（责任单位：县商务局）；城镇、农村常住居民人均可支配收入增幅与经济增长均保持同步（责任单位：县统计局）。

一、聚力发展加速，在增强综合实力上谋求新发展

（一）坚持投资拉动。制定出台《关于支持民营经济发展的若干意见》，大力支持民营经济发展壮大。持续深化“三抓一优”，巩固发展传统制造产业，重点发展电子信息产业，培育发展中医药产业，不断激发投资潜力与发展活力。（牵头单位：县经信局；责任单位：县发改局、县中医药产业办、县政务服务中心）加快坪山孵化园标准化厂房及配套设施建设，着力打造创业孵化平台。加快土地征收，对企业闲置土地清收回购，对“僵尸企业”、破产企业“腾笼换鸟”，保障新落户项目用地。（牵头单位：通城经济开发区管委会；责任单位：县政府项目办、县国资局、县审计局、县城发集团，隽水镇人民政府、大坪乡人民政府）强化企业上市引导，全力支持平安电工、三赢兴电子、福人药业在主板市场上市。（牵头单位：县政府金融办；责任单位：县经信局、县发改局、县财政局）加快推进中医药产业园、平安新材料产业园、麦市尧家林休闲旅游度假区等一批重点项目建设，确保炳彰科技、永豪电业、铱伦科技等一批项目建成投产（牵头单位：县发改局；责任单位：通城经济开发区管委会，县中医药产业办，隽水镇人民政府、大坪乡人民政府、麦市镇人民政府）力争全年省市县重点项目不少于50个，建成投产项目不少于20个；新增入规企业10家，总数突破100家，规模工业总产值增长6%。（牵头单位：县发改局；责任单位：通城经济开发区管委会、县政府项目办、县经信局、县招商局）

（二）推进“十大改革”。坚持先行先试，承接落实国家、省市改革项目，扎实推进殡葬改革、农民工返乡创业、服务业综合改革等改革试点，努力创造可借鉴、可复制、可推广的改革经验。全力推进县级党政机关机构改革、“放管服”改革、市场监管体制、医疗卫生体制、综合执法体制、城市建管体制、县乡财政体制等重点领域改革，为推动县域经济高质量发展注入新活力（牵头单位：县改革办；责任单位：县委组织部、县殡改办、县人社局、县商务局、县政务服务中心、县工商局、县卫计局、县编办、县住建局、县规划执法局、县财政局）

（三）坚持创新驱动。扎实推进国家知识产权强县工程试点工作，确保省知识产权试点工作顺利通过验收。力争完成专利申报500件；完成科技成果转化10项，完成技术合同成交额6亿元；新增院士专家工作站2个。新增高新技术企业5家，新培育科技型企业15家。加快创新创业平台建设，支持校企合作，积极创建“校企共建产业研发中心”和“工程技术研究中心”。（牵头单位：县科技局；责任单位：通城经济开发区管委会、县人社局、县教育局）

（四）坚持开放合作。大力发展外向型经济，不断深化与加拿大卡灵顿市、广东省普宁市、吉林省梅河口市、湖南省城陵矶新港区交流合作，全力推进内陆地区进口贸易创新示范区建设。（牵头单位：县商务局；责任单位：县发改局）积极发展跨境电子商务，力争新增进出口权企业2家、出口实绩企业2家。（牵头单位：县商务局；责任单位：县招商局、县经信局）持续推进通平修次区域合作示范区建设，力争在重大交通项目争取、精品旅游线路制定等方面取得新突破。（牵头单位：县发改局；责任单位：县旅游委、县交通运输局）积极探索政府与社会资本合作新模式，构建多层次资本市场。（牵头单位：县财政局；责任单位：县政府金融办、县城发集团）全面推行“十大招商方式”，重点引进行业龙头企业和配套项目，新签约亿元以上项目55个以上。（牵头单位：县招商局；责任单位：县直各单位、各乡镇人民政府）

二、聚力脱贫摘帽，在乡村振兴道路上迈出新步伐

（一）坚持全员上阵。打赢脱贫攻坚战是天大的事，没有任何借口可讲，政治使命必须完成。始终把脱贫攻坚作为最大政治任务和第一民生工程来抓，按照“户脱贫、村出列、县摘帽”要求，落实帮扶责任，强化帮扶措施，健全完善“县强指挥部、乡强工作队、村强工作组、户强责任人”的“四级联动”作战指挥体系创新扶贫方式，继续落实好“四员”促扶贫机制，激发贫困群众脱贫的主动性和积极性。（牵头单位：县委组织部、县扶贫办；责任单位：县直各单位、各乡镇人民政府）。进一步健全应急会商机制，强化督查考核力度，加强扶贫领域腐败和作风问题专项治理，以扎实过硬的作风推进脱贫攻坚。（牵头单位：县扶贫办；责任单位：县监委，县委组织部、县委督查室、县政府督查室、县审计局、县信访局）

1.强化精准施策。严格按照“两不愁三保障”标准，严格落实“五个一批”政策措施，既不降低标准，也不吊高胃口，全面提升“三率一度”水平。（牵头单位：县扶贫办；责任单位：县直各单位、各乡镇人民政府）大力推进产业扶贫，着力发展中药材、油茶、有机蔬菜等特色产业，推动工厂进村、车间入户，让贫困户就近就业。（牵头单位：县农业局；责任单位：县中医药产业办、县林业局、县畜牧兽医局、县发改局、县扶贫办、县经信局，各乡镇人民政府）大力推进教育扶贫，确保贫困户子女不因贫困辍学。（牵头单位：县教育局；责任单位：县人社局、县财政局、县扶贫办，各乡镇人民政府）大力推进健康扶贫，严格落实医疗救助“985”标准。（牵头单位：县卫计局、县人社局；责任单位：县民政局、县扶贫办、各有关保险公司）以屋场会为依托，坚持开展“四民”活动，实施一批“八小工程”，把好事实事办到群众的心坎上。（牵头单位：各乡镇人民政府；责任单位：县交通运输局、县水利局、县文体广新局、县林业局、县供电公司）广泛动员社会力量帮扶，大力开展村企结对活动，着力构建“政府+企业+社会”的三位一体大扶贫格局。（牵头单位：县委统战部；责任单位：县委组织部、县农办、县工商联、县经信局、县工商局、县商务局、县扶贫办，各乡镇人民政府）。

2.突出均衡推进。统筹兼顾户脱贫与村出列、贫困户与非贫困户、贫困村与非贫困村，突出均衡发展，确保脱贫不留死角。着力抓好政策引导、教育引导、典型引导，切实将扶贫与扶志、扶智结合起来，充分激发贫困户内生动力。（牵头单位：县扶贫办；责任单位：县直各单位、各乡镇人民政府）从群众最关心、最直接、最现实的利益问题入手，集中力量办好精准扶贫“惠民十件事”，全面推进贫困村道路、电力、通信等“九有”项目建设。（牵头单位：县精准扶贫“惠民十件事”指挥部办公室；责任单位：县委政法委、县公安局、县水利局、县交通运输局、县发改局、县财政局、县农办、县农业局、县林业局、县卫计局、县住建局、县规划执法局、县国土资源局、县审计局、县民政局、县环保局、县文体广新局、县旅游委、县公共资源交易监督管理局、县畜牧兽医局、县供电公司，各乡镇人民政府）研究制定脱贫成果巩固提升考核办法，扎实开展脱贫对象“回头看”工作。2019年，确保剩余贫困人口全部脱贫、剩余贫困村全部出列，全县实现整体摘帽。（牵头单位：县扶贫办；责任单位：县直各单位、各乡镇人民政府）。

3.推进乡村振兴。以农业供给侧结构性改革为主线，推动乡村产业全面振兴。大力发展“两茶一药一猪”现代农产品加工体系，新发展中药材2万亩、油茶2万亩。（牵头单位：县农业局；责任单位：县扶贫办、县农办、县林业局、县中医药产业办、县畜牧兽医局，各乡镇人民政府）贯彻落实“一江一山”市级战略，大力推进幕阜山绿色产业带重点示范段建设，加强沿线环境管控，实施房屋立面改造，推进重点项目建设，积极发展“六大绿色产业”。（牵头单位：县幕阜山绿色产业带指挥部办公室；责任单位：县住建局、县林业局、县交通运输局、县规划执法局、县旅游委、县卫计局、县商务局、县经信局、县环保局，麦市镇人民政府、塘湖镇人民政府、关刀镇人民政府、沙堆镇人民政府、四庄乡人民政府）加快编制《全域旅游发展规划》，深入推进“三乡工程”，积极培育市场主体，大力发展乡村旅游。（牵头单位：县旅游委；责任单位：县农办、县农业局、县经信局）持续抓好13个乡村振兴示范点建设，再启动5个示范点建设，努力把通城打造成为全域旅游的大景区。（牵头单位：县农办；责任单位：县水利局、县国土资源局、县住建局、县交通运输局、县卫计局、县环保局、县农业局、县民政局、县商务局、县林业局、县规划执法局，各乡镇人民政府）大力推进土地“三权分置”改革，加快农村土地流转。（牵头单位：县经管局；责任单位：县国土资源局，各乡镇人民政府）严守耕地保护红线不动摇，划定粮食生产功能区19万亩，积极创建全省“优质粮食”工程示范县。（牵头单位：县国土资源局、县粮食局；责任单位：县农业局，各乡镇人民政府）加快现代农业示范区建设，着力构建以健康养生百草园为核心的“一园六区”发展格局。（牵头单位：县农业局；责任单位：县林业局、县中医药产业办、县畜牧兽医局，各有关乡镇人民政府）。

三、聚力城市提质，在城市转型发展上共建新家园

（一）规划战略引领，以图绘城。坚持全域规划、全域推进，科学谋划城市未来。围绕城乡规划编制体系，不断完善城市总体规划和“多规合一”规划编制。推进“智慧城市”建设，做好综合交通、商业布局、绿地系统等专项规划，完成经济开发区、城西新区、老城区控规编制和重点地段设计。加大规划管控力度，严格“三区四线”管理，坚决做到“建设必审批、违建必拆除”，确保城市建设有序推进。（牵头单位：县规划执法局；责任单位：县交通运输局、县住建局、县商务局、县林业局、县“四城同创”指挥部办公室，通城经济开发区管委会，隽水镇人民政府）

（二）拆迁改造推动，以建靓城。紧紧围绕“城市建设品质提升年”活动，全力推进万雅国际商贸城、金融港总部大楼等重大项目建设，着力实施锡山森林公园、柳堤滨河公园、雁塔广场跨河人行桥等景观工程，完成石泉、白沙等4个城市小游园建设。（牵头单位：县招商局、县城发集团、县规划执法局；责任单位：县住建局、县财政局）完成中心商务城、外贸、湘汉、旭红等片区棚户区改造，拆除面积10万平方米。全面推进白沙新城、元宝佳苑等棚改项目产权调换和实物安置工程建设。（责任单位：各棚户区改造指挥部办公室）加快城市供水管网改造，完成城市污水处理厂、建筑垃圾消纳场、垃圾中转站、城市公厕等环卫设施建设，不断提高城市的承载力。（牵头单位：县住建局、县规划执法局；责任单位：县环卫局、县供水公司）加大老城区改造力度，对中心城区临街房屋立面进行改造，对大街小巷路面实施清障、刷黑、绿化工程建设，不断提升城市形象品位。（责任单位：县住建局、县规划执法局）

（三）治理水平提升，以管护城。坚持以“五禁五治五提升”为抓手，持续推进“四城同创”，全力创建省级卫生城市。强化三道防控屏障，严格执行违建“黑名单”制度，始终保持“两违”整治高压态势。深入开展“全民洁城”活动，落实“门前五包”责任，着力解决城区占地种菜、占道经营、乱停乱放、“牛皮癣”等问题。强化“数字城管”建设，健全城市管理长效机制，积极引入社会力量参与城市经营管理，着力提升城市共建共治水平。（牵头单位：县“四城同创”指挥部办公室；责任单位：县卫计局、县规划执法局、县直各单位）

四、聚力交通升级，在发展空间拓展上构建新格局

（一）优化空间规划布局。坚持把交通建设作为拉动经济增长的先手棋，不断优化县域发展空间格局。完善交通发展规划，着力构建以城区为中心，高速公路、国省道为骨架，各种运输方式布局合理、衔接顺畅的综合交通运输体系。积极推动通修高速早日开工，积极推动武咸城际铁路延伸至通城，积极争取常岳九铁路过境通城；加快实施353国道、106国道改扩建，推进交通基础设施互联互通，努力实现“公铁水空”有效对接，着力打造综合立体交通运输走廊。（牵头单位：县交通运输局；责任单位：县发改局、县规划执法局）
