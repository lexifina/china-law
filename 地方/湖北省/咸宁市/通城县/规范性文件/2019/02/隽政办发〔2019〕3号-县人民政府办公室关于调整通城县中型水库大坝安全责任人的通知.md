# 县人民政府办公室关于调整通城县中型水库大坝安全责任人的通知

发文日期：

2019年02月19日

隽政办发〔2019〕3号

各乡、镇人民政府，县政府各部门，通城经济开发区管委会：

为切实做好我县水库大坝安全工作，确保水库大坝安全运行，经县人民政府同意，现将调整后的2019年通城县中型水库大坝安全责任人名单予以公布。

附件：通城县2019年度中型水库大坝安全责任人名单

通城县人民政府办公室

2019年2月19日
