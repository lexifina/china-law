# 县人民政府办公室关于调整通城县中型水库大坝安全责任人的通知

发文日期：

2020年03月06日

各乡、镇人民政府，县政府各部门，通城经济开发区管委会：

为切实做好我县水库大坝安全工作，确保水库大坝安全运行，经县人民政府同意，现将调整后的2020年通城县中型水库大坝安全责任人名单予以公布。
