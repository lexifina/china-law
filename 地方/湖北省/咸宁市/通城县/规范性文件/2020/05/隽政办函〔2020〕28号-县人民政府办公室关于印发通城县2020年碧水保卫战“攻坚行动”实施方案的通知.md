# 县人民政府办公室关于印发通城县2020年碧水保卫战“攻坚行动”实施方案的通知

各乡、镇人民政府，县政府各部门，通城经济开发区管委会：

《通城县2020年碧水保卫战“攻坚行动”实施方案》已经县人民政府同意，现予印发，请认真组织实施。

通城县人民政府办公室

2020年5月28日

通城县2020年碧水保卫战“攻坚行动”实施方案

为贯彻落实省河湖长4号令，纵深开展河湖长制提档升级行动，深入推进水污染防治，打好碧水保卫战，结合我县实际，特制“攻坚行动”实施方案。

一、总体要求

（一）指导思想。深入贯彻落实习近平生态文明思想、习近平总书记关于生态文明建设及河湖保护的一系列讲话精神，坚持问题导向、目标导向、成效导向，践行“节水优先、空间均衡、系统治理、两手发力”新时期治水方针，聚焦“水质提升、空间管控、小微水体整治、能力建设”四大攻坚行动，扎实挑起重担子，啃下硬骨头，进一步维护河湖生态健康，推进我县经济社会高质量发展。

（二）实施原则。一是突出重点，补齐短板。立足河湖实际，统筹兼顾上下游、左右岸，强化水污染治理、水资源保护、水环境改善、水生态修复，瞄准河湖突出问题，补齐河湖管护治理短板。二是党政负责，部门联动。紧紧围绕党政负责制这一核心，强化政府主导，健全完善河湖治理管护责任体系，建立健全河湖治理管护和执法联动机制，实现部门联动、信息共通共享，形成工作合力。三是强化监督，严格考核。完善严格的河湖管理保护监督考核和责任追究机制，拓宽公众参与渠道，营造全社会关心和保护河湖的良好氛围。

（三）工作目标。至2020年底，基本完成乡镇级水源地清理整治任务，按照饮用水水源地环境保护和治理专项战役要求，开展单一供水县级集中式饮用水水源地备用水源或应急水源建设；推进入河排污口排查整治工作，加强水生态修复，切实改善水质。以城市建成区黑臭水体整治为契机，加快补齐城镇生活污水收集处理短板；落实国家禁渔工作部署，开展水生生物增殖放流，提高水生生物多样性和水体净化调节功能；强化节水行动，年内实现万元GDP用水量、万元工业增加值用水量较2015年（万元GDP用水量180m3，万元工业增加值用水量92m3）下降30％的目标。至2020年底，完成河湖和水利工程划界确权任务；推进河湖“清四乱”常态化、规范化；加强河湖生态部门联动、综合执法。基本完成城区小微水体整治任务，完成60％以上农村小微水体整治任务，建立以河湖长制为核心的长效管护机制。

至2021年底前，基本实现小微水体“三无”（污水无直排、水面无垃圾、水质无黑臭）目标。

紧扣河湖长制提档升级“制度建设年”主题，加强河湖长制法规制度体系建设，进一步促进河湖长履职尽责。建成河湖长制信息管理系统，提高河湖监测管控能力。加强各级河湖长及河湖长制工作人员培训，创新培训方式，切实提高履职能力。强化河湖社会管理服务，广泛开展河湖志愿行动，不断健全完善河湖保护共治机制。

二、主要任务

（一）开展水质提升攻坚行动。

1．严格水功能区监督管理。完善重要河湖水功能区划，核定重要水域纳污能力，确定重要水域限制排污总量，落实污染物达标排放要求，控制重要水功能区限制排污总量；核查排污口污染物入河湖量，制定并实施污染物削减分阶段行动计划；对入河湖排放量已超出水功能区限制排污总量的地区，限制审批新增入河湖排污口；全面摸清排污口并建立台账，开展违法排污行为专项整治，实施排污口达标建设和监测体系建设，加强入河湖排污口日常监管。（牵头单位：市生态环境局通城分局；责任单位：各乡镇人民政府，县水利和湖泊局、县发改局、县科经局、县自然资源和规划局、县住建局、县农业农村局等）

2．实施最严格水资源管理制度和落实双控（水资源消耗总量和强度）行动。将“三条红线”（水资源开发利用控制、用水效率控制和水功能区限制纳污）指标分解到乡镇，强化最严格水资源管理制度考核；加强计划用水和取水许可监管，严格建设项目取水许可管理，对达到或超过取用水总量控制指标的地区，暂停审批建设项目新增取水；严格执行水资源有偿使用制度，有效控制水资源消耗强度。（牵头单位：县水利和湖泊局；责任单位：各乡镇人民政府，市生态环境局通城分局、县发改委、县科经局、县自然资源和规划局、县住建局、县农业农村局、县统计局等）

3．严格饮用水水源地保护。2020　年底前，基本完成“百吨千人”以上供水工程水源保护区划定工作，建立饮用水水源保护长效机制；集中整治饮用水水源保护区内存在的违法问题，2020　年，县城集中式饮用水水源水质达标率达到100％。积极推进城市应急备用水源建设；实施农村饮水安全巩固提升工程，完善水源地风险防控体系，确保城乡饮用水安全。（牵头单位：市生态环境局通城分局、县水利和湖泊局；责任单位：各乡镇人民政府，县财政局、县发改局、县自然资源和规划局、县住建局、县交通运输局、县农业农村局、县卫健局、县公安局、县应急管理局、县科经局、县公共检测中心等）

4．深入推进节水型社会建设。加快中型灌区续建配套与节水改造工程建设，持续开展小型农田水利建设，2020年新增高效节水灌溉面积0.6万亩以上；积极推进重点用水行业水效领跑者引领行动，完善高耗水行业取用水定额标准体系；推进城镇供水管网改造，2020年城市公共供水管网漏失率控制在10％以内；建设节水型企业、机关、社区示范项目，打造节水宣传教育基地。（牵头单位：县水利和湖泊局；责任单位：各乡镇人民政府，县农业农村局、县城发水务集团、县发改局、县科经局、县自然资源和规划局、县机关事务服务中心等）

5．加强城镇生活污水治理。加强城镇污水处理设施建设，加快设施提标升级改造，健全乡镇污水处理厂运行管理机制。2020年实现城镇污水处理设施全覆盖，县城、乡镇污水处理率分别达到85％、75％，县城生活污水处理厂出水排放达到一级A标准。加快推进城市污水处理设施配套管网建设，实施城市雨污分流改造和老旧污水管网改造，完善污水收集管网系统，基本实现建成区污水全收集、全处理。加强城市污水处理厂污泥处理处置，2020年县城污泥无害化处理处置率达到90％。（牵头单位：县住建局；责任单位：各乡镇人民政府，县发改局、县科经局、县财政局、市生态环境局通城分局、县农业农村局、县城发集团等）

6．推进农村生活污水治理。全面加强农村人居环境整治，因地制宜地选择生活污水治理模式，将具备条件的村庄生活污水纳入乡镇污水处理厂集中处理。加强乡镇生态化污水治理设施和监控能力建设，积极创建美丽乡村。（牵头单位：县农业农村局、市生态环境局通城分局；责任单位：各乡镇人民政府、县发改局、县住建局、县卫健局等）

7．防治畜禽养殖污染。按规定完成禁养区、限养区、适养区划定，陆水河及百丈潭饮用水水源一级保护区内基本消除畜禽规模养殖场（小区），二级保护区内基本消除有污染物排放的畜禽规模养殖场（小区）。新建、改建、扩建规模化畜禽养殖场（小区）实施雨污分流、粪便污水资源化利用；现有规模化畜禽养殖场（小区）配套建设粪便污水贮存、处理、利用设施，进行标准化改造。（牵头单位：县农业农村局；责任单位：各乡镇人民政府，市生态环境局通城分局等）

8．加强工业污染防治。完善空间准入、产业准入和环境准入的负面清单管理模式，建立健全准入标准，继续实行化工企业、落后淘汰企业零准入制度，入规企业按行业节水标准实行用水效率控制，用水效率未达标的规上企业逐年下降工业用水百分比。推动重要水域周边化工污染专项整治。（牵头单位：县科经局；责任单位：各乡镇人民政府，市生态环境局通城分局、县发改局、县自然资源和规划局、县住建局、县应急管理局等）

9．实施水环境责任目标管理。完善纳入河湖长制管理河湖的考核断面体系，划定控制单元，确定考核断面的水质保护目标，优化断面监测站点布局和能力建设，加强断面水质水量监测。全面排查考核断面达标情况，对未达到水质目标的控制单元，制定达标方案，明确防治措施及达标时限，并定期向社会公布。（牵头单位：县水利和湖泊局、市生态环境局通城分局；责任单位：各乡镇人民政府等）

10．开展农村水环境综合整治。大力实施乡村振兴战略，结合厕所革命、爱国卫生运动，完善农村垃圾分级负责体系，开展农村宜居水环境建设，深入推进农村环境综合整治，建立完善农村环境基础设施长效运行维护机制，2020年前完成7个示范村（灵官桥、冷塅、大埚、港背、梅港、龙门、坪山）31个整治村（柳峦、石泉、东港、季山、何家、治全、马港、黄鹤、易塅、八燕、春雷、杨田、天门、井堂、九房、南虹、石港、凉亭、望湖、堆山、坪坳、华家、向家、小井、仙姑、柏树、贯青、大界、大坪、大九房、花墩）的人居环境整治任务。（牵头单位：县农业农村局；责任单位：各乡镇人民政府，县水利和湖泊局、市生态环境局通城分局、县财政局、县自然资源和规划局、县住建局、县交通运输局、县卫健局、县城管执法局、县文旅局等）

（二）开展空间管控攻坚行动。

11．划定河湖水系生态空间。依法划定河湖和水利工程管理与保护范围，2020年底前基本完成所有河湖和水利工程划界确权工作。结合全域绿化工作，开展河湖复绿工作，构建生态廊道，2020年底，县管河道及水库管理范围内可绿化面积绿化率达到100％。（牵头单位：县水利和湖泊局、县自然资源和规划局；责任单位：各乡镇人民政府、县林业局等）

12．严格水域岸线管控。大力开展“清四乱”“清固废”（两清）等专项整治行动，对河湖“两清”工作进行回头看，巩固扩大成果，推进河湖“两清”常态化、规范化。严格涉河湖建设项目管理，建立涉河湖建设项目行政许可信息通报和公告制度。探索建立建设项目占用水域、岸线补偿制度，严格禁止建设项目非法占用水域。（牵头单位：县水利和湖泊局、县自然资源和规划局；责任单位：各乡镇人民政府，市生态环境局通城分局、县农业农村局、县住建局、县交通运输局等）

13．加强河道采砂管理。结合全县砂土乱挖乱采乱运（三乱）专项整治工作，采取“政府主导、部门联动、社会共治”的方式，落实河砂审批和监管责任。严格实施河道采砂许可与现场监管，强化日常巡查。建立完善部门执法联动机制，严厉打击非法采砂行为。（牵头单位：县水利和湖泊局；责任单位：各乡镇人民政府，市生态环境局通城分局、县林业局、县公安局、县城管执法局、县应急管理局、县交通运输局、县自然资源和规划局、县城发集团等）

14．持续开展河湖保洁行动。结合农村人居环境整治，采取政府购买服务方式，落实资金，统一购买保洁船、工具、服装等装备，全面开展河湖巡查保洁及日常监管，实现河面无大面积漂浮物、河岸无垃圾、无违法排污口。（牵头单位：县农业农村局；责任单位：各乡镇人民政府，县水利和湖泊局、市生态环境局通城分局、县住建局、县城管执法局等）

（三）开展小微水体整治攻坚行动。

15．设置小微水体河湖长公示牌。在小微水体显著地段设置小微水体“两长两员”（河湖长、河湖警长、保洁员、巡查员）公示牌，公开身份，接受群众监督。（责任单位：各乡镇人民政府）

16．一般小微水体整治。针对存在问题的小微水体，制订《小微水体“一点一策”整治方案》，全面落实污染源查控、生活污水收集处理、排污口整治、农业农村面源污染治理等整治措施，明确问题清单、任务清单、责任清单、责任人、完成时间表，挂图作战，整治完成一宗销号一宗。各乡镇可结合实际，多点合并，制订整治方案。其中城市、农村小微水体整治标准分别由住建部门、农业农村部门牵头会同生态环境等有关部门制定。2020年底前，基本完成城区小微水体整治任务，完成60％以上农村小微水体整治任务，建立以河湖长制为核心的长效管护机制。（牵头单位：各县乡镇人民政府；责任单位：县住建局、县农业农村局、市生态环境局通城分局、县水利和湖泊局）

17．试点村整治。为积累经验、探索路子，结合我县美丽乡村建设及农村人居环境整治工作设置8个试点村（塘湖荻田村、麦市冷塅村、关刀高冲村、四庄清水村、隽水油坊村、五里左港村、北港横冲村、大坪内冲村），先行开展小微水体整治，由县农业农村局牵头，会同县水利和湖泊局负责制定整治方案，乡镇政府主导整治工作。（牵头单位：县农业农村局；责任单位：各乡镇人民政府，县水利和湖泊局）

（四）开展能力建设攻坚行动。

18．开展示范河湖建设。遵循自然规律和节约优先、保护优先、自然恢复为主的方针，全面统筹左右岸、上下游、陆上水上、地表地下、河流湖泊（水库）、水生态水资源、污染防治与生态保护，按照“八有”治理管护机制，创建省级示范河湖（库）3条（个）；以“七个有力”为标杆，创建各具特色的省级示范单位（乡镇）4个；挖掘树立积极投身爱护河的“示范人物”典型（官方河湖长、企业河湖长、民间河湖长、河湖保洁员、河湖志愿者）13个。营造人水和谐的社会氛围，形成全民知水、节水、护水、亲水的良好社会风尚和人水和谐的美好环境，不断提高群众满意度。（牵头单位：县水利和湖泊局；责任单位：各乡镇人民政府，县河湖长制工作领导小组成员单位等）

19．加强河湖行政监管执法。健全涉河建设项目管理、水域和岸线保护、采砂管理、水域占用补偿、岸线有偿使用、河湖资源损害赔偿和责任追究等制度。落实涉水执法权委托授权乡镇制度，建立健全多部门联合执法、重大案件河湖长挂牌督办制度，健全行政执法与刑事司法衔接配合机制。推进河湖警长制工作，探索建立专门的环保警察队伍，有效遏制涉河湖违法犯罪行为。落实河湖管理执法监管责任主体、人员、经费和设备，完善监督考核机制，加强河湖日常巡查。（牵头单位：各乡镇人民政府、县水利和湖泊局；责任单位：县河湖长制工作领导小组成员单位等）

20．提升动态监测监管水平。加强河湖跨界断面、重要水功能区等重点水域的水文、水环境、水生态监测。建立河湖长制管理信息平台，实现河湖长制管理信息化。建立河湖信息共享制度，整合并共享基础数据。加强重点河湖动态监控，确保涉河湖问题及时发现、及时上报、及时处理。建立河湖管理动态监控信息公开制度，对违法违规项目信息及整改情况依法予以公布。（牵头单位：县水利和湖泊局、市生态环境局通城分局；责任单位：各乡镇人民政府，县财政局、县自然资源和规划局、县农业农村局、县水文局等）

21．切实提高履职能力。创新培训方式，加强各级河湖长及河湖长制工作人员培训力度，不断提高各级河湖长及河湖长制工作人员的业务水平与综合素质，提升河湖管理能力，助力河湖长制工作从“有名”到“有实”转变。（牵头单位：县委组织部、县水利和湖泊局；责任单位：各乡镇人民政府，县河湖长制工作领导小组成员单位等）

三、保障措施

（一）强化组织领导。各级各部门要始终坚持以习近平新时代中国特色社会主义思想为指导，大力践行“绿水青山就是金山银山”理念，聚焦管好盛水的“盆”和护好盆中的“水”，把全面推行河湖长制作为五个通城建设的重要内容来抓，切实提高思想认识，加强组织领导。县河湖长制办公室要定期或不定期牵头召集成员单位，研究落实专项行动推进情况和需要协调解决的重点难点问题。县河湖长制工作领导小组成员单位及各乡镇人民政府要主动将河湖“老大难”问题作为自己的“责任田”，既挂帅又出征，认真履行巡河、管河、护河、治河职责。

（二）强化经费投入。要整合部门涉河涉湖项目资金和资源，统筹支持水资源保护、水污染防治、水环境治理、水生态修复、水域岸线管护、河湖管理执法监管和智慧河湖体系建设等工作，确保河湖长制全面推行。县财政要按照部门预算编制规定，落实各级河湖长制工作经费。要积极利用多种融资模式推进河湖环境治理与保护。

（三）强化考核问责。以攻坚行动为契机，建立河湖长制监督考核机制，将河湖管理与保护列入各级党委政府目标责任制，考核结果作为领导班子和领导干部考评的重要依据。县委办公室、县政府办公室、县纪委监委、县河湖长制办公室采取明查、暗访相结合的方法，对成员单位工作落实情况进行监督检查，对主要问题挂牌督办，定期整改。对工作懈怠、拖沓、没有按期完成工作任务的，追究单位主要领导责任，并进行通报批评和曝光。对因失职、渎职导致河湖资源环境遭到严重破坏的，依法依规严肃查处并追究责任。

（四）强化舆论引导。综合运用电视、报刊、广播、标语、“两微一端”、云上通城等新媒体，加大全社会对碧水保卫战攻坚行动的监督力度，发挥媒体舆论引导与监督作用。建立河湖保护信息发布平台，依法公示，畅通公众投诉渠道，保障公众知情权、参与权。增强社会各界河湖保护的责任意识、参与意识，形成全社会关心、支持、参与、监督河湖保护工作的良好氛围。
