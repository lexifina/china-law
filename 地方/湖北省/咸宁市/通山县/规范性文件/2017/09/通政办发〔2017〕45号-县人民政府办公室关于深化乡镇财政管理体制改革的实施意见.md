# 县人民政府办公室关于深化乡镇财政管理体制改革的实施意见

各乡镇人民政府，风景区、开发区、富水湖管委会，富水湖湿地公园管理处，县政府各部门：

为进一步调动各乡镇政府发展经济的积极性，鼓励乡镇培植财源，规范收入征管秩序，严控乡镇政府性债务，促进经济社会持续发展，按照《预算法》有关规定和咸宁市全面深化改革领导小组《关于深化乡镇财政体制改革的指导意见》（咸改组发〔2017〕7号）文件精神，结合我县实际，现就深化乡镇财政管理体制改革提出如下实施意见：

一、基本原则

（一）财权与事权相匹配原则。科学划分县乡支出责任，合理配置县乡财力，实现权责结合、事权与财权相匹配。

（二）保稳定与促发展原则。优先保障乡镇人员工资津贴、公用经费等基本支出，鼓励乡镇招商引资，依法依规经营土地，壮大地方财源，加大对乡镇的财力倾斜力度。

（三）激励与约束相结合原则。建立激励约束机制，调动乡镇依法理财、科学理财积极性，努力增收节支，确保财政收支平衡；严格收入目标考核，进一步加大奖惩力度，提高乡镇政府协税、护税积极性；规范乡镇政府举债行为，确保债务风险可控；强化乡镇对村（社区）的财务管理职能，提高财政运行效率。

二、明确乡镇财政收支范围

（一）收入范围。

1．固定补助收入。指县财政按政策保障纳入县财政预算的乡镇在编人员（含离退休）基本工资、津补贴、改革性补贴、乡镇政府公用经费、农村税费改革转移支付补助收入等。

2．上级专项补助收入。指上级下达的有专项用途的补助收入。

3．奖励性收入。指县财政按体制规定奖励给乡镇的收入任务考核、招商引资、促进发展激励奖补资金等。

4．分成性收入。指县财政按体制规定比例乡镇应分成的税收、土地出让收入等。

5．其他收入。指乡镇依法取得的资产处置、社会捐赠、其他部门拨入的经费等。

（二）支出范围。按照公共财政要求，根据财权与事权相匹配原则，合理划分县乡两级财政负担范围。

1．县级财政负担范围。

基本支出：主要包括乡镇政府、财政所人员工资、津补贴、公用经费、农村税费改革转移支付、村级转移支付。

经济发展、维护稳定支出：主要包括由县级及县级以上政府负担的公共安全、教育、医疗卫生、社会保障、农林水事务、交通运输、文化体育与传媒、科技、国土整治、计划生育、环境保护、城乡社区事务等支出。

2．乡镇财政负担范围。

基本支出：主要包括乡镇政府机关运转、人员奖励性、福利性支出。

经济发展、维护稳定支出：主要包括事关乡镇自身发展需要的镇区基础设施建设、维护、环境治理支出；乡镇负担的综合治理、维稳信访、人民调解、村（社区）管理支出等。

（三）乡镇财政基本支出保障标准。

1．人员经费。县财政按政策保障乡镇在编人员（含离退休）基本工资、津补贴、改革性补贴；村主职干部报酬。

2．公用经费。取消定额标准预算，以保障正常运转为前提，根据细化部门预算的要求，参考乡镇政府工作人员、辖区人口、面积等因素，按高于县直部门平均水平，建立乡镇均衡性公用经费保障机制。

3．村级转移支付。在现有保障标准下，参考辖区人口、面积、地理位置等因素，逐步建立提高村级转移支付补助力度的保障机制，切实保障村级组织正常运转。

三、重塑乡镇协助组织收入职能

（一）完善收入征管考核机制。实行县政府对县级征管部门、县级征管部门对乡镇政府两级考核机制。每年县财税部门合理核定乡镇地方公共财政预算收入任务，各乡镇要认真履行职责，落实乡镇协税、护税责任，配合征管部门，积极组织收入，做到应收尽收，完成情况纳入年度绩效目标考核。

（二）建立考核激励约束机制。乡镇未完成年度收入任务的，年度绩效目标考核不得评先评优，同时按掉收比例扣减公用经费，每掉收1%扣减公用经费1万元。

各乡镇要严格遵守属地管理的原则，严禁县乡之间、乡镇之间转移税款。征管部门和乡镇政府在征缴、核算乡镇税收收入中转移税款的，对乡镇政府按转移税收收入占其税收收入比重扣减公用经费，并追究相关人员责任，且转移的税款全部作为县级收入。税收征管经费由县财政统一结算，乡镇不得支付相关征管经费。

对乡镇组织本辖区范围内的零散耕地占用税、契税及建制镇镇区范围内房屋出租增值税等税收收入，由税务部门委托乡镇代征，入库税款按地方留存部分的60%奖励给乡镇。

县财政每年安排100万元用于奖补协助组织收入突出的乡镇。具体分配方法为：综合考虑完成任务的乡镇公共财政预算收入占全县完成数的比重、税收增幅、任务进度三项因素，按3：3：4权重用加权平均法计算奖励。

四、鼓励乡镇发展经济

（一）激励乡镇招商引资。凡由乡镇全程服务、自主招商落户乡镇的企业项目（不含房地产开发项目）、企业总部、销售结算中心、经营性分支机构，除按《通山县招商引资促进办法》规定发放奖金和工作经费外，企业生产环节年缴增值税、企业所得税达到50万元—100万元、100万元—300万元、300万元以上的企业，每年每户分别按5万元、10万元、20万元给予乡镇奖励；引进的企业总部、销售结算中心、经营性分支机构，视年度纳税情况，给予乡镇适当奖励。

鼓励有项目但无落地条件的乡镇发展“飞地经济”。乡镇全程服务、自主招商引进县工业园区或其他乡镇的项目，除按《通山县招商引资促进办法》规定发放奖金和工作经费外，所产生的税收，“飞出地”、“飞入地”按照3：7的比例计入乡镇收入任务考核。

（二）激励经营土地、盘活资产。县财政设立土地收储调度资金，支持乡镇依法依规经营土地。乡镇集镇开发建设储备所产生的土地出让收入，除按政策计提上交中央、省的各项基金外，全额返还乡镇；占补平衡补大于占产生的新增建设用地指标给予适当奖励，支持乡镇基础设施建设和公共事业发展。

支持乡镇通过股份合作经营、集体自主经营、租赁托管经营等方式，盘活资源资产，资产资源处置和经营收益全额返还乡镇，以壮大乡镇经济实力。

（三）集中投入支持项目建设。按照“乡镇申报、县级统筹、确定重点、集中投入”的工作机制，支持乡镇项目建设。乡镇辖区内的建设项目，以乡镇申报为主，由各乡镇根据全县统一发展规划、年度工作重点，结合自身实际，向县发改局申报项目。县发改局负责项目统筹、协调，县财政局负责统筹整合资金，纳入项目库管理。县委、县政府每年确定2-3个乡镇，集中财力办大事，避免项目重复建设和资金分散。

（四）激励创建特色小镇。根据乡镇经济社会发展实际，综合考虑经济基础、区域特色和重点生态功能区功能定位等因素，针对不同乡镇分类施策。采取以奖代补的方式，重点扶持市级以上特色小镇建设。创建过程中，符合条件的项目，优先享受项目申报、融资贴息、专项资金补助等扶持政策。对获得国家、省、市认定的特色小镇，县财政分别给予200万元、50万元、20万元一次性奖励。

五、强化乡镇财政财务管理

（一）加强财政监督管理。各乡镇要切实落实预算单位主体责任，按程序编制完整规范的财政预算，及时公开预决算、“三公”经费使用情况和资产、债务情况；要积极协调组织辖区内的税收收入，负责征收政府性基金等非税收入；要健全乡镇财政双重管理、协调运行的工作机制，提高乡镇财政履职履责能力；要进一步加强财政结余结转资金管理，提高资金的使用效率；要建立就地就近资金监管机制，严格专项资金监管，提高公共服务能力和业务水平，确保各项民生资金落到实处。

（二）加强乡镇债务管理。各乡镇必须严格执行债务管理相关规定，创新资金投入模式，减少财政性资金投入，优化债务结构，切实防范债务风险。

五、配套措施

（一）解放思想，简政放权。县直各部门要进一步解放思想，在法律、法规许可的前提下，大胆向乡镇简政放权，理顺乡镇人民政府与乡镇站所的关系，坚持放管结合、权责对等、职能清晰、职责明确，尽力破解乡镇“权力虚拟化、职责无限化”等机制瓶颈。

（二）部门协作，加强监督。县财政局、国土局、规划局、国税局、地税局、监察局、审计局等有关部门要按照职责分工，强化部门协作，加强工作指导、政策支持、跟踪评估；县政府督查室督促检查本办法的贯彻落实，并及时向县委县政府报告。

本意见自印发之日起施行，有效期五年，如遇国家财税政策重大调整或其他影响乡镇收支有较大变化的情况，经县政府批准，可作相应的调整。此前出台的有关政策与本意见不一致的，以本意见为准。

2017年9月12日
