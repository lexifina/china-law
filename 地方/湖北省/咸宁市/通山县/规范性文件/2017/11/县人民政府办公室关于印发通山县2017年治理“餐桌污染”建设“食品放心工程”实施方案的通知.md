# 县人民政府办公室关于印发通山县2017年治理“餐桌污染”建设“食品放心工程”实施方案的通知

各乡镇人民政府，风景区、开发区、富水湖管委会，富水湖湿地公园管理处，县政府各部门：

《通山县2017年治理“餐桌污染”建设“食品放心工程”实施方案》已经县人民政府同意，现印发给你们，请认真组织实施。

2017年10月30日

通山县2017年治理“餐桌污染”建设“食品放心工程”实施方案

根据《省人民政府办公厅关于印发湖北省2017年治理“餐桌污染”建设“食品放心工程”工作方案的通知》（鄂政办发〔2017〕31号）、《市人民政府办公室关于印发咸宁市2017年治理“餐桌污染”建设“食品放心工程”实施方案的通知》（咸政办发〔2017〕50号）要求，为进一步强化我县食品安全工作，落实“从农田到餐桌”的全过程监管，切实提高食品安全治理能力和保障水平，特制定本方案。

一、工作目标

（一）提高食用农产品质量安全。食用农产品质量安全监测总体合格率达97.5%以上；蔬菜、水果、食用菌、茶叶农药残留监测合格率达97%以上；畜禽产品兽药残留和“瘦肉精”监测合格率达98.5%以上；生鲜乳和禽蛋产品三聚氰胺监测合格率达100%；水产品药物残留监测合格率达97%以上。

（二）提高粮食产品质量安全。原粮质量安全抽检质量合格率、宜存率、卫生监测合格率均达91%以上。

（三）提高饮用水质量安全。集中式饮用水水源地水质达标率和供水管网末梢水质抽检合格率均达96%以上。

（四）推进食品安全企业标准备案工作，一次性通过率达91%以上；食品污染、有害因素及食源性疾病监测实现行政区域100%覆盖。

（五）加强日常监督检查。食用农产品、食品及食品相关产品获证企业现场监督检查覆盖率和发现问题整改率均达100%。

（六）强化专项监督抽检。食品安全监督抽检覆盖100%行政区域，覆盖100%在产获证食品生产企业、食品安全性项目指标、食品品种和生产经营业态。

（七）从事接触直接入口食品工作的从业人员持有效健康证明的比率达到100%。

（八）城乡食品安全网格化监管覆盖率达到100%。

（九）全县食品安全公众满意度平均达到80%以上。

二、工作任务

（一）加强食用农（畜、水）产品源头治理。

1．加强农产品产地环境保护。落实农产品产地环境监测制度，开展土壤污染普查，推动食用农产品产地环境质量长期定位监测点基本全覆盖。深入开展耕地质量保护与提升行动，推行农业面源污染防治攻坚行动。（责任单位：县环保局、县农业局）

2．强化农业投入品监管。督促指导食用农产品生产企业和农民专业合作经济组织建立并落实农业投入品使用记录制度；加快农资监管信息平台建设与应用，实施农药、兽药（渔药）、肥料全程动态监管，实时掌握农药、兽药（渔药）、肥料流向和使用；严格实行高剧毒农药定点经营、一瓶一码、实名购买、终身追溯制度，大力推进农药经营处方制；严厉打击生产、经营、使用国家禁止生产、经营、使用的农业投入品的违法行为和超范围、超标准、不按安全间隔期（休药期）使用农兽（渔）药的违法行为。（责任单位：县农业局、县水产局、县畜牧局）

3．推进农业标准化生产。推广农业标准化生产技术及食用农产品种植养殖标准化示范区（场）建设；大力推进农产品标准化生产、产业化经营和品牌化发展，大力发展“三品一标”（无公害食用农产品、绿色食品、有机食品和地理标志产品），强化证后抽检监督和标志使用管理；积极推进新型农业经营主体申请新认证“三品”，新登记“地理标志”产品。（责任单位：县农业局、县水产局）

4．加强屠宰行业监管。严格管理生猪屠宰准入，实行屠宰场（厂）“瘦肉精”自检和动监部门检测与屠宰检疫同步，不合格产品一律不得开具检疫合格证出厂（场）销售。（责任单位：县畜牧局）

5．做好粮食质量安全管理。加强粮食收购、储存和政策用粮购销活动各环节的质量安全监管，督促粮食收购者、经营者、承储企业和政策用粮经营企业严格执行相关质量安全制度；定期对粮食收购、储存活动和政策用粮购销中的粮食质量和原粮卫生开展抽查与监测；组织开展收获粮食质量安全监测。（责任单位：县粮食局）

（二）加强饮用水安全监管。

6．加强饮用水及集中式供水管理。加强饮用水水源环境保护，开展饮用水水源保护区规范化建设，对饮用水水源地的水环境定期开展质量监测和监督检查，强化集中式饮用水水源地环境监管，严厉查处危害饮用水源安全的违法行为；建立健全供水水质监测、饮用水卫生监测发布制度，按时发布监测信息；加强农村饮水供水设施建设及保护。（责任单位：各乡镇人民政府，县环保局、县水利局、县住建局、县卫计局）。

（三）强化过程监管。

7．加强食用农产品收贮运环节监管。加强食用农产品在进入市场、加工企业、直供餐饮单位前的收购、贮存、运输等环节质量安全监管，实行产地证明随货同行制度；逐步建立产地食用农产品收购人员、贮存仓库和运输车辆登记备案制度，落实食用农产品购、贮、运台账制度。（责任单位：县农业局）

8．加强食用农产品产地准出与市场准入。督促食用农产品生产企业（含农民合作社、家庭农场、种植养殖大户）严格落实食用农产品产地准出制度；加强对进入市场、加工企业和餐饮环节食用农产品检验（检疫）合格证和产地证明等市场准入证明材料查验工作，推动食用农产品产地准出与市场准入、加工企业准入与餐饮单位直供准入相互对接；建立食用农产品联合执法机制，加大监管巡查力度，强化监督抽检，依法公开监管和抽检信息。（责任单位：县农业局、县食药监局、县商务局）

9．加强寄递渠道食品安全管理。加大寄递企业员工培训力度，提高寄递企业员工辨识假劣食品的能力，严格落实寄递食品查验制度，防止假劣食品流入寄递渠道；积极配合有关部门开展联合执法，强化寄递渠道食品安全监管，对未按要求落实的寄递企业，依法依规严肃追责。（责任单位：县邮政分公司）

（四）加强食品生产经营管理。

10．加强食品生产质量安全监管。督促引导食品生产者履行法定责任和义务，建立健全并严格落实责任管理、进货查验、索证索票、生产经营记录、出厂检验、产品追溯召回、员工健康管理、培训教育等制度；按照“双随机、一公开”原则，通过彻查隐患、抽检“亮项”、处罚到人、公开信息、曝光违法违规企业等方式，倒逼生产经营者落实主体责任。督促强化食品生产过程质量安全控制，严格落实食品添加剂进销货台账记录制度，严厉打击无证生产经营、非法添加非食用物质和滥用食品添加剂等违法行为。（责任单位：县食药监局）

11．规范食品经营行为。推进食品经营许可数据库建设和监管工作信息化建设，实施日常监管“清单式”监管模式，推进食品经营日常监管和执法检查的标准化、规范化建设；督促食品经营者把好食品进货、销售和退市关，落实操作规范等有关制度，落实法定责任和义务；重点加强对食品批发市场、集贸市场、商场、超市、城乡结合部、校园及周边、车站码头、旅游景点等重点区域的监管，加大巡查频率。严厉查处经销以假充真、以劣充优、过期变质、“三无”等假冒伪劣食品的违法违规行为。（责任单位：县食药监局、县工商局、县教育局、县商务局、县住建局、县旅游局）

12．加强餐饮服务环节管理。落实餐饮许可和备案制度，建立日常监管“痕迹化”模式，推进餐饮单位标准化、规范化建设，推行日常监督检查结果公示制度；督促餐饮单位认真落实进货查验、操作管理、卫生防护、人员健康、餐饮具消毒等各项管理措施，要求配备专（兼）职食品安全管理人员，接触直接入口食品从业人员健康证明持证率达100%；继续推进餐饮单位量化分级管理，落实农村集体聚餐备案制度。（责任单位：县食药监局、县卫计局）

13．加强校园及周边食品安全监管。推进学校食堂“明厨亮灶”建设，对学校食堂进行升级改造；建立食品药品监管部门、教育部门、城管执法部门等共同参与的校园及周边食品安全综合治理机制；实行食品安全校长负责制，落实校园食品安全管理的主体责任；校园食品安全纳入校园安全的重要内容，学校校园及周边食品经营者全部纳入监管范围，实行监管全覆盖。（责任单位：县教育局、县食药监局、县城管执法局）

14．提高“三小”治理水平。按照“规范一批，提升一批，淘汰一批”的原则，对“三小”（小作坊、小餐饮、小摊贩，简称“三小”，下同）开展普查摸底，建立“三小”监管档案；推动小作坊持证生产经营，指导小作坊完善生产条件、加强原辅材料管理、规范生产加工过程，增加食品生产加工小作坊检查频次；积极引导小餐饮、小摊贩划行归市，改善条件，探索开展分类备案管理，实施精细化监管。（责任单位：各乡镇人民政府，县食药监局、县城管执法局）

15．加强进口食品安全监管。组织开展进口婴幼儿配方乳粉、食用植物油、大米等重点敏感食品专项检查，依法查处不合格进口食品。（责任单位：县食药监局）

（五）开展示范创建。

16．开展示范创建活动。开展食品安全“明厨亮灶”示范创建，在全县学校（幼儿园）建设80家“明厨亮灶”示范食堂；开展小作坊改造升级，推进5家小作坊改造升级达标；2家“放心肉菜”超市建设；5家食品生产经营单位食品安全追溯体系建设；创建1个省级食品安全示范农贸市场（月亮湾农贸大市场）。（责任单位：县教育局、县商务局、县食药监局）

17．推进信用体系建设。贯彻落实《咸宁市食品药品安全信用等级评定管理办法（试行）》，建立健全食品安全信用档案，完善守信联合激励和失信联合惩戒机制；在食品企业开展“做老实人、办良心企业”活动，切实增强企业主体责任意识和质量风险管理能力。（责任单位：县食品药品安全委员会相关成员单位）

（六）严格风险管理。

18．加强食品安全标准宣贯工作。开展食品安全标准宣传培训、贯彻落实、跟踪评价、工作督导、检查考核等工作，推进食品安全标准工作与监管执法工作的衔接，力争推出一个食品安全地方标准。（责任单位：县卫计局）

19．加强食品风险监测、预警和风险交流。配合开展省级食用农产品质量安全例行风险监测和监督抽查；组织对生物毒素、产地环境污染等重点安全隐患开展专项排查和风险评估；推进食源性疾病监测等重点工作，食品安全风险监测机构的设备平均达标率达90%以上；加强食品安全风险研判，推进信息共享，及时发布消费提示和风险警示；加大食品安全责任保险推广力度。（责任单位：县农业局、县卫计局、县食药监局）

20．加强食品安全监督抽检。科学制定抽检计划，扩大抽检覆盖面，提高问题发现率和不合格产品核查处置率。（责任单位：县农业局、县食药监局）

21．加强追溯体系建设。加强肉类、婴幼儿配方乳粉、蔬菜等重点产品追溯体系建设，推进农产品质量安全追溯管理信息平台建设。（责任单位：县农业局、县水产局、县畜牧局、县食药监局）

（七）加大违法犯罪行为打击力度。

22．严厉打击食品安全违法犯罪。健全“三安联动”监管工作机制，加强行政执法与刑事司法的衔接；完善涉嫌犯罪案件移送、信息通报机制，解决食品安全违法犯罪案件取证难、移送难、入罪难以及检验认定经费、检验结论出具、涉案产品处置等问题；严惩农业投入品非法添加、超范围超限量使用添加剂、滥用农药兽药、制假售假、私屠滥宰等违法行为；加大对虚假违法食品广告的查处力度；建立健全重大违法犯罪案件信息发布制度，保障公众知情权。（责任单位：县食品药品安全委员会相关成员单位）

（八）加强基层能力建设。

23．加强基层基础建设。督促落实“党政同责”“四有两责”，推进基层食品药品监管所标准化、规范化建设；实现基层食品安全监管机构业务用房、执法车辆、执法装备配备标准化；推进县级食品安全检验检测资源整合。（责任单位：各乡镇人民政府，县编办、县发改局、县财政局、县农业局、县食药监局等部门）

24．加强基层监管人员培训。加大监管人员教育培训力度，全面开展大学习、大交流、大培训、大比武、大考核“五大”系列活动，提升食品安全监管执法素质和能力；加强食品药品安全协管员和信息员队伍建设，深化农村、社区食品药品安全网格化管理。（责任单位：县食药监局）

（九）强化食品安全宣传教育。

25．加强食品安全宣传教育和新闻宣传引导。组织开展“食品安全宣传周”系列活动，加大《食品安全法》《湖北省食品安全条例》等法律法规宣贯力度，坚持开展食品安全“六进”（进企业、进机关、进学校、进农村、进社区、进家庭）活动，广泛运用“两微一端”（微信、微博、移动客户端）等新媒体平台，加大食品安全公益、科普宣传力度；关注食品安全舆情动态，完善信息发布制度，及时发布权威信息，曝光违法违规行为。（责任单位：县食品药品安全委员会相关成员单位）

三、工作要求

（一）加强组织领导。食品安全工作作为一项重大的政治任务，各有关单位要高度重视，主要负责同志必须亲自抓，积极落实“党政同责”，做到定责任、定岗位、定人员，确保食品安全各项工作的有序推进。

（二）加强工作统筹。各有关单位要根据本方案的工作目标和任务要求，结合工作实际，制定年度治理“餐桌污染”、建设“食品放心工程”工作实施方案，细化目标，分解任务，实行项目化推进、台账式管理，落实责任单位和人员，明确时间表和保障机制，确保工作任务按计划推进。

（三）严格督查考评。各乡镇、各部门要加强对治理“餐桌污染”、建设“食品放心工程”工作督导，对督查中发现的问题，要及时反映和通报，把督查工作贯穿于全过程。将治理“餐桌污染”、建设“食品放心工程”工作纳入目标责任制考核重要内容，并作为对领导班子和领导干部综合考核评价的重要依据，对不作为、慢作为、乱作为等失职渎职行为，严肃追究责任。
