# 县人民政府办公室关于印发通山县2018年畜禽养殖废弃物资源化利用奖补方案的通知

各乡镇人民政府，风景区、开发区、富水湖管委会，富水湖湿地公园管理处，县政府各部门：

《通山县2018年畜禽养殖废弃物资源化利用奖补方案》已经县人民政府同意，现印发给你们，请认真组织实施。

2018年12月27日

通山县2018年畜禽养殖废弃物资源化利用奖补方案

为贯彻落实《国务院办公厅关于加快推进畜禽养殖废弃物资源化利用的意见》（国办发〔2017〕48号）、《省人民政府办公厅关于印发湖北省畜禽养殖废弃物资源化利用工作方案的通知》（鄂政办发〔2017〕101号）、《市人民政府办公室关于印发咸宁市畜禽养殖废弃物资源化利用工作方案的通知》（咸政办发〔2018〕28号）和咸宁市突出环境问题整治工作指挥部《关于印发<咸宁市畜禽养殖污染防治工作方案>的通知》（咸环指发〔2018〕22号）、《关于印发<咸宁市县乡村三级畜禽养殖污染网格化防控巡查改善畜禽养殖影响人居环境的方案>的通知》（咸环指发〔2018〕27号）等文件精神，加快全县畜禽养殖废弃物资源化利用工作，促进畜禽养殖与生态环境协调发展，特制定本方案。

一、总体思路

按照“政府支持、企业主体、市场化运作”方针，坚持“源头减量、过程控制、末端利用”的治理路径，以资源化利用为基础，采取经济高效适用的处理模式，宜肥则肥，宜气则气，实现畜禽粪污就地就近利用。通过不断改造完善我县畜禽养殖场粪污收集、处理、利用等设施，努力形成农牧结合、种养循环发展的产业格局。

二、主要目标

通过项目的实施，2018年全县畜禽规模养殖场废弃物资源化利用率达80%以上，畜禽规模养殖场粪污处理设施装备配套率达到90%以上。进度安排如下：

2018年8月：成立项目工作领导小组和技术专班，全面启动项目建设，重点完成宣传、培训工作，核定一场一策治理改造方案，制定项目实施方案。

2018年9月—2018年12月：在全县全面推进畜禽养殖废弃物资源化利用工作，督促指导规模养殖场对养殖废弃物收集、处理、利用设施设备进行改造升级。

2018年12月：对完成项目建设内容的企业现场考核验收，对验收合格的给予奖补。

三、支持对象

对2018年12月底以前建成投产，畜禽废弃物处理和资源化利用设施设备运行正常，整改升级到位，实行粪污全收集、全处理，实现资源化利用的规模养殖场进行奖补。应同时具备以下条件：

（一）规模养殖场环保设施运行良好，经环保部门认定，符合环保要求；粪污全收集，全处理，实现资源化利用，且去向档案齐全；

（二）奖补金额以环保基础设施投入为基准，养殖规模与粪污处理设备相配套，设备运行正常，养殖场道路、沟渠硬化程度、场内外环境绿化美化情况较好；

（三）营业执照、环保验收手续、动物防疫条件合格证等证照齐全，本年度无违规排放污染物行为，且未因环境污染被投诉。

四、建设内容

（一）畜禽粪污资源化利用。

畜禽养殖场实行干湿分离、雨污分离。参照畜禽养殖场粪污治理的8种典型模式，各养殖场可因地制宜、因场施策，对设施、设备、生产工艺、技术模式等进行改造。

模式1：干清粪+粪便直接农业利用+污水厌氧+好氧+深度处理模式。规模化畜禽养殖场（小区）采取干清粪、粪便农业利用、污水进行厌氧—好氧—深度处理达标排放，出水全部利用。

模式2：干清粪+粪便生产有机肥+污水厌氧+好氧+深度处理模式。规模化畜禽养殖场（小区）采取干清粪、粪便生产有机肥、污水进行厌氧—好氧深度处理达标排放，出水全部利用，且配备了在线监测或视频监控设备并联网。

模式3：干清粪+粪便生产沼气+污水厌氧+好氧+深度处理模式。规模化畜禽养殖场（小区）建设治污设施，无污水排放口，所生产的废弃物综合利用产品（有机肥、沼渣、沼液及经处理后的污水等）经现场认定完全农田利用。

模式4：干清粪+粪便直接农业利用模式。规模化养殖场（小区）采取干清粪方式，建设废弃物储存设施（粪便堆沤、污水、尿液存储氧化），无污水排放口，粪便、污水/尿液经现场认定完全农业利用。

模式5：干清粪+粪便生产有机肥模式。养殖场（小区）采取干清粪、粪便全部生产有机肥，且无废水排出。

模式6：垫草垫料+垫料农业利用模式。规模化养殖场（小区）垫草垫料铺地养殖畜禽，无污水排放口，垫草垫料堆肥农业利用。

模式7：干清粪+粪便生产沼气模式。规模化养殖场（小区）无污水排放口，采用粪污“厌氧发酵一（发酵后固体物）好氧堆肥工艺”，沼液、沼渣完全农业利用。

模式8：室外发酵床模式。猪舍粪尿经收集后，通过污泥泵输送至发酵床，添加生物菌种，通过翻耙进行好氧厌氧处理，发酵腐熟，生成有机肥，还田利用。

（二）病死畜禽无害化处理。

开展病死畜禽收集体系建设，对全县病死畜禽全收集、全处理、全覆盖。我县已建成县级病死畜禽无害化收集中心，在万头猪场已建设小型冻库，对规模养猪场逐场发放冰柜。收集的病死畜禽运往处理厂进行无害化处理。

五、建设标准

全县规模养殖场建设与养殖废弃物总量相适应的收集、处理、利用设施设备，推广应用发酵饲料、干清粪、异位发酵床等环保养殖技术和生产工艺，建立资源化利用长效机制，做到养殖废弃物全收集、全处理、全利用，零排放、无污染。

（一）规模养殖场规模化建设标准。

1．环评标准。新建的畜禽规模养殖场，必须到县环保局办理环评手续和环保“三同时”验收手续，才能投入生产。各乡镇要严格管控新建非规模养殖场，对已建非规模养殖场要加强督促管理，确保零排放。

2．雨污分流建设标准。雨水沟、污水沟独立建设，雨水经雨水沟外排，不得流入污水沟。污水沟必须防雨防渗漏，切实做到“粪不见天”。

3．干清粪标准。生猪养殖场猪栏是水泥地面的必须采用人工干清粪，猪粪从猪栏经斗车转运到干粪储存池；是漏缝地板的采用刮粪板清粪。蛋鸡养殖场采用皮带传输鸡粪、刮粪板清粪或者人工干清粪。肉牛养殖场采用人工干清粪；肉羊养殖场采用人工干清粪或者刮粪板清粪。

4．畜禽饮水管理标准。蛋鸡场采用防滴漏乳头加减压水箱，或带托盘水嘴，或装PVC漏水收集管。猪场采用碗式饮水器，或采用防喷溅水嘴加装饮水收集装置。

5．生产用水管理标准。不使用水冲粪，不使用水冲圈舍（需清洁消毒除外），不使用冲水降温，养殖水禽不得污染饮用水源。

6．环保饲料标准。使用发酵饲料减少氢气和硫化氢；使用肠道微生物菌剂减少抗生素用量；使用有机饲料添加剂减少重金属残留等。

7．干粪储存池建设标准。干粪储存池容积按照设计生产规模，每头猪单位0.1立方米；每万羽蛋鸡60立方米；每头牛单位1立方米；每头羊单位0.1立方米。干粪储存池必需防渗、防雨、防溢流。

8．粪水（污水）储存池标准。粪水（污水）储存池容积按照设计生产规模，干清粪猪场每头猪单位0.3立方米，不能干清粪的猪场每头猪单位0.4立方米；其它养殖场按照需要建设。粪水（污水）储存池必需防渗、防雨、防溢流。

9．养殖废弃物处理标准。干粪采用堆肥发酵、粪水（污水）采用厌氧发酵、异位发酵床处理，推荐添加发酵菌种对干粪、粪水（污水）进行发酵处理。粪尿还可以混合经沼气池发酵处理，或者加工商品有机肥。

10．异位发酵床建设标准。推荐发酵床宽4米、高1.1米（垫料0.8米）以上、长若干米，按照每存栏1000头猪发酵床容积150立方米、存笼万羽鸡建发酵床容积100立方米计算。发酵床要防渗、防雨、防溢流。

11．环境除臭标准。圈舍内安装普通喷头、电动喷雾加除臭菌种。

12．资源化利用标准。一是肥料化利用。经堆肥、发酵床、厌氧发酵，或有机肥厂加工生产商品有机肥，种植蔬菜、瓜果、玉米、水稻、茶叶、油茶、林木、花卉等农林作物。二是能源化利用。粪尿通过沼气池处理，生产沼气能源化利用，生产沼渣、沼液还田利用。三是就近落实消纳土地。养殖场生产的粪肥在自有土地还田利用，或签订粪肥消纳合同供周边农户还田利用，或与种植合作社、畜禽养殖废弃物社会化服务组织等签订养殖废弃物利用合同。消纳土地面积按照每头生猪0.04亩计算，没有实行干清粪的养殖场按照每头生猪0.2亩计算，蛋鸡按照每万只鸡20亩计算，蛋鸭按照每万只30亩计算，牛按照每头0.1亩计算，羊按照每头0.02亩计算。已经按照标准建设异位发酵床处理养殖废弃物的，消纳土地面积按照每存栏1000头猪15亩，每万羽鸡10亩计算。

（二）病死畜禽无害化收集体系建设标准。

各养殖场将病死畜禽放至场内冻库、冰柜或临时收集点，由通山县禾和动物无害化处理有限公司集中收集统一进行无害化处理。

六、奖补标准

养殖企业粪污资源化收集利用实施由养殖企业负责筹资建设，病死畜禽无害化收集体系由通山县禾和动物无害化处理有限公司筹资建设，省级财政项目资金290万元，对实施了畜禽养殖废弃物资源化利用的规模养殖场实施奖补。项目资金主要用于畜禽规模养殖场建设畜禽养殖废弃物收集、贮存、处理设施和输送管网等。奖补标准如下：

（一）异位发酵床模式：根据发酵床容积测算，每立方米垫料一次性奖补120元。发酵床未启用或垫料厚度低于80厘米的不予以奖补。

（二）粪污全量还田模式：根据贮存池或沼气池容积测算，贮存池每立方米奖补60元，其中水泥封顶的每立方米奖补80元；沼气池100立方米奖补1万元、200立方米奖补1.5万元、300立方米奖补2万元。未启用或存在漏排现象的不予奖补。

（三）粪水达标排放模式：粪水深度处理达标排放，经环保验收合格，并取得排污许可证的大型规模养殖场进行奖补。

（四）以上奖补可叠加，总量封顶。每个规模养殖场三年内只能申请一次奖补，先验收先奖补，项目资金奖补完为止。其中生猪年出栏万头以上，粪水深度处理达标排放的，每个场奖补不超过10万元；年出栏6000头以上的，每个场奖补不超过6万元；年出栏4000头以上的，每个场奖补不超过5万元；年出栏4000头以下500头以上的，每个场奖补不超过4万元。肉牛年出栏50头以上，建有标准化牛舍+沼气池、干粪堆积间的，每个场奖补不超过2万元。肉羊年出栏100只以上，建有标准化羊舍+沼气池+干粪堆积间的，每场奖补不超过1.5万元。肉禽年出栏10000羽以上，蛋禽存笼5000羽以上，建有标准化鸡舍+干粪堆积间+贮存池的，每场奖补不超过1万元。

七、申拨程序

（一）由畜禽规模养殖场业主提交书面申请，经乡（镇）人民政府签字盖章后报县畜牧兽医局审查备案；

（二）县畜牧兽医局会同县环保局、乡（镇）人民政府组成联合检查组入场核查；

（三）根据核查数据，确定奖补标准。公示7个工作日，无异议后，发放奖补资金。
