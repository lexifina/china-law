# 县人民政府关于支持民营经济高质量发展的若干意见

各乡镇人民政府，风景区、开发区、富水湖管委会，富水湖湿地公园管理处，县政府各部门：

为全面贯彻落实习近平新时代中国特色社会主义思想和关于民营经济发展的重要指示精神，毫不动摇鼓励支持引导民营经济发展，坚定不移推动民营企业做强做大，营造民营经济更好发展环境，激发民营企业创新活力，充分发挥民营经济作为推进供给侧结构性改革、推动高质量发展、建设现代化经济体系的重要主体作用，根据省、市有关精神，提出如下意见。

一、着力减轻民营企业税费负担

（一）更大力度落实优惠政策。严格按照国务院、省政府及税务总局要求，全面落实增值税改革、小微企业、科技型初创企业等税收优惠政策，全面落实减轻企业税费负担的各项优惠政策，全面落实降低残疾人就业保障金、地方教育附加优惠政策，实现减税降费政策精准推送、应享尽享，增强市场主体发展活力。

（二）更大力度落实降费措施。严格落实涉企收费“一表制”，坚决做到表外“零收费”。涉企收费坚决按国家和省、市最低下限执行；继续执行阶段性降低养老、失业、工伤等社会保险费率政策，严禁自行组织对企业历史欠费进行集中清缴，符合条件的困难企业，经批准可在一定期限内缓缴社会保险费，缓缴期间免收滞纳金。

（三）更大力度降低用地成本。实行差别化供地政策，优化土地供应结构，降低竞买保证金和调整工业用地出让价最低标准。对民营企业参与城市基础设施、公益性科技和非营利性教育、文化、卫生等社会公益事业项目使用的土地，符合国家划拨用地目录的，按照划拨方式供地。对符合我县优先发展产业目录的民营工业项目，以最高年限出让的，在确定出让底价时，可按照不低于所在地土地等别相对应工业用地出让最低价的70%执行。对一次性缴纳出让金确有困难的民营企业，允许分期缴纳，首次缴纳比例不低于50%，一年内缴清。对固定资产投资1亿元以上的工业企业新增厂房建设用地指标给予优先保障，鼓励工业企业集约用地，对符合规划条件、不改变用途，在原地范围内经县政府同意提高土地利用率和增加容积率不低于1.2的，不再收取土地出让金。民间资本在不改变用地主体、规划条件的前提下，利用存量房产、土地资源发展国家鼓励的新产业、新业态项目的，可实行继续按照原用途和土地权利类型使用土地的过渡期政策，过渡期政策为5年。

二、着力破解民营企业融资难融资贵问题

（四）加大信贷投放力度。对流动资金周转贷款到期后仍有融资需求、又临时存在资金困难的小微企业，银行业金融机构可以提前按新发放贷款要求开展贷款调查和评审，并对审核合格的企业办理续贷。支持商业银行面向优质民营企业推广无还本续贷模式，鼓励金融机构结合企业发展实际创新金融产品，推广首资融资、质押融资、产品融资、数据融资、纳税信用融资、出口退税融资等信贷模式。对暂时遇到困难的企业，银行业金融机构不得盲目抽贷、压贷和断贷。银行业金融机构要完善考核奖励办法，建立和完善容错纠错机制，改进内部业绩考核、评价和激励体系，把银行业绩考核同支持民营经济发展挂钩。

（五）加大融资担保力度。支持担保机构面向民营中小微企业开展融资担保业务，积极争取国家、省、市融资担保基金投入支持，落实国家、省、市融资担保业务降费奖补政策。健全政府性融资担保机构，支持担保机构建立资本金持续补充机制、代偿补偿机制，并逐步建立风险分担资金池；支持农业信贷担保公司扩大业务规模和服务范围；完善“4321”风险分担担保机制，担保费率控制在1%以内，对企业融资提供担保额度可提升至企业资产负债率的60%以内。

（六）加大直接融资力度。加大企业直接融资支持力度，对首次在国内主板、中小板、创业板市场或境外市场上市的企业，县政府给予企业一次性200万元奖励资金。对企业异地“买壳”“借壳”上市后，将上市企业注册地迁回通山县，主要生产经营地点在通山县的，县政府给予企业一次性100万元奖励资金。对上述两种情况的上市企业，县政府根据首次发行股票募集资金1亿元以上，且70%用于本地项目的，县政府给予一次性40万至100万元奖励；上市企业在股票市场和债券市场再融资在3亿元以上，且70%用于本地项目的，县政府给予一次性40万至60万元奖励。对成功在“新三板”挂牌的企业给予一次性100万元奖励，对在区域性股权交易市场（即“四板”）“交易板”“科创版”挂牌的企业分别给予一次性20万元、5万元奖励。支持符合条件的企业发行债券，在债券融资成功后且用于本县新上项目、实施技术改造及新产品开发的，按照融资总额的3‰给予一次性奖励，奖励上限不超过50万元。

三、着力优化民营经济发展环境

（七）创造条件为投资提供便利。深入推进投资审批制度改革，投资项目审批一律接入政务服务网，加快实现“一网通办”。全面推行“证照分离”改革，持续推进证照清理，推行照后减证。进一步压缩企业开办时间。规范优化行政审批中介服务，设立统一的中介机构库，取消没有法定依据的中介服务事项，中介服务实现随机抽选、成果互认。

（八）创造条件解决企业用人需求。落实岗前就业培训、稳岗补贴政策。鼓励开展“县校合作”“校企合作”，与企业共建生产实训基地，培育一批技术过硬、素质优良的通山工匠。支持民营企业引进各类高端人才，对符合条件的给予生活补贴，健全人才入户、子女入学就医等配套政策。对符合用地政策和基建程序要求的员工公寓，享受公租房相应的优惠政策。加强贫困户就业与企业用工对接，实现农村具有劳动能力的建档立卡贫困对象就业增收脱贫。

（九）创造条件优化创业环境。放宽民间投资领域，实行“非禁即入”。完善PPP项目信息公开、公示机制，严格执行公开招标制度，为优质民营企业提供公平、公正的竞争平台。鼓励优质民营企业积极参与我县重大经济项目建设，引导优质民营企业进入农业农村、基础设施、市政公用事业、保障性住房等领域。全面推行“双随机一公开”，切实加强事中事后监管，进一步规范市场经营秩序。加快发展现代物流，创新物流配送模式，降低物流成本。对税收规模达到800万元以上，且连续三年增幅在15%以上的电子制造企业，给予一次性20万元的物流运输补贴。着力完善园区基础设施和生活配套设施，促进产业与城区一体化发展。

四、着力提升民营企业核心竞争力

（十）支持“个转企”“小升规”。个体工商户转型为企业的，允许保留原字号和行业特点；对转型后办理土地、房屋、设备等所有权更名时，投资主体、经营场所、经营范围不变的，免收交易手续费。对新入规的县工业企业，县财政给予1万元奖励；首次入围全省民营实体企业10强、100强和民营企业制造业100强的，分别给予50万元、10万元和5万元奖励；首次入围中国民营实体企业500强或中国制造业500强的，给予100万元奖励。鼓励有条件的民营企业建立产权清晰、权责明确、治理规范、管理科学的现代企业制度。

（十一）支持龙头企业发展壮大。鼓励民营企业通过合资合作、兼并重组、并购收购、资本运作和挂牌上市等扩大规模，提升效益和水平。支持有条件的民营企业主动对接全国民营企业500强、行业龙头企业等，兼并重组，形成大企业大集团。对年主营业务收入达到1亿元以上（以纳税平台数据为准），且连续3年增长率达到15%以上的民营实体企业，给予一次性10万元奖励；对当年新增税收300万元以上、新增就业岗位50人以上且对扶贫开发、社会公益事业做出贡献的民营实体企业，给予一次性10万元奖励。

（十二）支持民营企业转型升级。对接“万企万亿技改工程”，整合资金配套投入，坚持“一企一策”，支持引导重点制造企业对外扩张、实施技改、扩大生产；合理运用易地扶贫搬迁产业配套资金，支持企业建立扶贫车间、扶贫工厂；对投入技术改造的固定资产投资，符合固定资产加速折旧政策的，计提的折旧可计入成本费用在计算企业所得税应纳税所得额时扣除。对获得省级及以上认定的“中国制造2025”试点示范企业，给予一次性50万元奖励；对获得国家和省级认定的“智能制造”和“隐形冠军”的企业，分别给予一次性50万元和30万元奖励。

（十三）支持民营企业技术创新。对小微企业首件发明专利授权的申请费、代理费给予全额补贴。对我县绿色新产业重点技术创新成果产业化项目，获得市级政府或市直职能部门以上认定的，按照不超过企业技术研发投入的10%给予补助，最高补助100万元。对首次获得国家级和省级认定的中小企业创新创业示范基地分别给予10万元和5万元奖励。

五、着力保护民营企业合法权益

（十四）建立领导联系企业工作机制。建立领导干部联系重点民营企业和会商制度，党政主要负责人每年主持召开民营企业家座谈会不少于一次，每半年主持召开民营经济发展形势分析会不少于一次，每季度主持召开现场办公会不少于一次，定期与民营企业家代表集中谈心。大力倡导“三多三少”（即多想怎么做、少想不能做，多讲实际情况、少讲大道理，多指导、少指示）服务理念，推行代办员、项目秘书服务民营企业制度，主动将各级干部推向发展一线。

（十五）畅通民营企业诉求反映渠道。加强中小企业服务体系建设，建立健全统一的“线上+线下”服务网络。畅通企业投诉服务渠道，建设企业投诉服务信息平台，健全企业诉求反映处理机制。加大对企业享受政策的宣传督办落实、投诉受理分办反馈等服务力度。认真履行与民营企业依法签订的合同，严禁以各种理由毁约，杜绝“新官不理旧账”。

（十六）保护企业家人身和财产安全。依法保护民营企业和企业家的财产权、人身权。查办涉企经济案件要依法慎用强制措施和查封、扣押、冻结措施，确需采取查封、扣押、冻结措施的，除依法责令关闭的企业外，在法律法规允许的情况下可为企业预留必要的流动资金和往来账户。严格规范涉案财产处置，依法维护涉案企业和人员的合法权益，最大限度降低对涉案企业生产经营活动产生的不利影响。依法严厉打击侵害企业利益的违法犯罪行为，切实整治企业周边治安环境。加强行政执法监督，规范行政裁量权和处罚制度，凡无法律依据的，一律不得开展执法检查，严防执法扰企。发放企业车辆通行证，开辟民营企业运输绿色通道。

六、着力完善政策执行方式

（十七）完善政策执行机制。加强对支持民营经济发展政策的宣传解读，提高政策知晓率和惠及率。坚持既严格执行政策，又实事求是、区别对待的工作方法，在去产能、去杠杆工作中，对各类所有制企业执行同样标准；安监、环保等领域微观执法和执行政策避免简单化，杜绝“一刀切”“一关了之”“一律不批”。

（十八）严格督办落实机制。将促进民营经济发展情况作为各级领导干部履职尽责管理的重要内容，对排名靠前的乡镇、部门予以通报表扬。每年对各部门至少开展一次落实民营经济发展政策情况督查，对落实政策不力的予以通报批评。对违纪违规行为，不作为、慢作为、乱作为的严肃追责问责，及时曝光典型案例。

（十九）强化工作推进机制。县委、县政府成立支持民营经济高质量发展工作领导小组，领导小组办公室设在县经信局。县经信局要切实履行领导小组办公室的牵头协调职责，县工商联要充分发挥桥梁纽带作用和政府管理民营经济的助手作用，县直有关部门要各司其职，加大支持力度，形成工作合力，确保中央、省、市支持民营经济发展的政策措施落地见效。

本意见自发布之日起正式实施，有效期3年，政策兑现不溯及既往。此前出台的有关政策与本意见不一致的，以本意见为准。近三年我县出台的涉企奖补和优惠政策，有效期内均适用于本县民营企业，奖励性政策不叠加享受。

通山县人民政府

2019年2月2日
