# 县人民政府办公室关于加强国省道、县道、乡道两侧生态人居环境和规划建设管控的通知

各乡镇人民政府，风景区、开发区、富水湖管委会，富水湖湿地公园管理处，县政府各部门：

为进一步加强我县国省道、县道、乡道（以下简称“三道”）两侧生态人居环境和规划建设管控工作，切实解决农村人居环境突出问题，根据《中华人民共和国城乡规划法》《湖北省城乡规划条例》《咸宁市城乡个人住宅规划建设管理办法》（市政府令第41号）等法律法规规定，结合我县实际，现就加强全县“三道”两侧生态人居环境和规划建设管控有关事项通知如下。

一、加强村镇建设管控

（一）科学编制乡村规划。按照《住房城乡建设部关于改革创新全面有效推进乡村规划工作的指导意见》《中共湖北省委 湖北省人民政府关于推进乡村振兴战略实施的意见》要求，县住建局要迅速指导各乡镇依法组织编制乡镇建设规划和村庄建设规划，特别是涉及“三道”两侧范围的建设规划。要坚持从实际出发，推动村镇建设规划与土地利用规划、生态环境保护规划等的有机衔接，实现多规合一和乡村建设规划全覆盖。

（二）认真落实规划审批。县住建局将“三道”两侧范围的建设规划许可委托给相关乡镇人民政府，从2019年3月1日开始，凡“三道”（含核电路、横石至九宫山旅游公路、山口至石门公路、富水湖南岸公路、幕阜山片区旅游公路）两侧建房必须由所在地的城建、国土、林业等专班根据各乡镇规划，报乡（镇）人民政府审批，乡镇人民政府根据《咸宁市村镇个人住宅建设规划设计导则》及《鄂南名居建筑设计图集》进行审核，建房户在取得规划行政许可手续后才可实施建设。鼓励已建成的房屋按照鄂南民居风格进行改造，逐步统一民居建筑风格。今后我县所有建设项目用地布局严控向“三道”两侧可视范围内扩展。鼓励村民利用山地集中连片建房，确需扩大建设范围的，应向公路单边组团式纵深发展，严禁将公路变成新的街道或厂区，严禁新增村庄。“三道”两侧乡镇和村庄及其它集中建设区应尽量减少与旅游公路的平交路口。

（三）强化“三道”建设管控。一是摸清底数。由各乡镇规建办和国土所组成联合调查组，对“三道”两侧100米范围内所有建筑物和生态环境进行影像拍摄和文字登记，并以乡（镇）为单位进行电子存档和纸质版存档。二是划定控制区。原则上国省道、县道两侧200米、乡道两侧50米属建设控制区。同时，国家规定的“两区”（粮食生产功能区、重要农产品生产保护区）范围列入控制区，严禁建设和开发。在控制区内严禁现有建筑物无规划改建、扩建，禁止无规划新增建筑物和地面构筑物。确因建设需要的，须由公路管理机构会同乡镇规建办、国土所集体讨论会商，报乡镇人民政府会审，并报县规划委员会备案，核准立面设计、层高，落实建设规划。三是严格审批制度。严格落实农村个人住宅制度，由各乡镇人民政府按乡镇规划进行审批，建设规划执行由县规划委员会实行监督制度，认真执行《咸宁市城乡个人住宅规划建设管理办法》，切实做到先审批、再建设。自2019年3月1日开始，“三道”两侧凡无规划审批的农村建房（含农村拆旧房建新房）或其它建设，一律停建。严格执行规划审批制，凡不符合规划要求的，由各乡镇对其动员并迅速实行整改。各乡镇人民政府是违建拆除的责任主体，城市规划区内（山口高速路口至李渡路口）的处罚权由县城管执法局执法，其它乡村规划区内的处罚权由各乡镇人民政府依法实施，对违法建设要组织规建办、国土所、派出所等部门实行联合执法，一经发现，依法拆除。历史形成的各类违法建筑物、构建物，由所在地乡镇人民政府负责督促逐步拆除，并予以规范。严禁擅自移动古树名木及拆除改造乡村传统民居、代表性建（构）筑物，切实保护好鄂南山村的特色民居风格。

二、加强工业项目管控

在“三道”两侧1000米可视范围（含幕阜山旅游公路、高速公路、重要水源地、村镇居住地、生态保护区外延1000米范围）内，实行工业项目管控，现有的污染项目进行环保整改，整改后达不到环保要求的依法责令停业、关闭。鼓励新上工业项目进入县经济开发区或乡镇工业园区，建设项目中防治污染的设施，应与主体工程同时设计、同时施工、同时投产使用。

三、加强农业生产管控

各乡镇人民政府负责组织国土所、林业站进行综合巡查管控。一是严守耕地红线，严格控制新增建设用地。积极稳妥推进建设用地增减挂钩工程，清理处置闲置土地，推进工矿废弃地复垦利用；严禁在“三道”两侧可视范围内破坏植被开荒性农业开发；严禁全垦种植；禁止任何单位和个人占用基本农田发展林果和挖塘养鱼。二是禁止毁林造林、炼山整地。严禁天然林商品性开发；严禁在“三道”两侧1000米可视范围内发展养殖业；严格按咸政办发〔2018〕26号文件划定的“禁养区”“限养区”“适养区”范围管控要求，做好畜禽养殖管控工作；杜绝“农用地非农化”现象发生。

四、加强资源开发管控

严禁在“三道”两侧可视范围内挖山取土，取沙制沙或建砂石加工厂，已发证的要加大执法巡查力度，严格落实监管责任。加强对现有非煤矿山的规范管理，严格按市政府有关文件精神该关停的关停，予以保留过渡的，依法依程序做好续证和复工手续，切实加强环保生态监管。禁止“三道”两侧占用耕地、林地、湿地等新建项目。

五、加强生态保护管控

积极推进农村环境综合整治，加强农村环境连片整治，禁止垃圾乱扔、污水乱排、秸杆乱烧等现象，推进农村垃圾入箱入池，秸杆集中收集处理，污水管道有序排放，切实改善农村生产、生活环境。凡“三道”两侧100米可视范围内禁止乱倒垃圾；不得无审批破坏植被；不得建设垃圾堆放场、垃圾填埋场、粪便垃圾处置场。严格控制在“三道”两侧可视范围内实施与景观无关或有损景观的设施建设；凡“三道”两侧1000米范围内重要水源地，严禁商品性砍伐林木。

六、加强政策宣传引导

利用电视、报纸、云上通山及张贴公告和广播宣传车进村入户等方式，将县人民政府关于加强“三道”两侧生态人居环境和规划、建设、管控有关工作意见进行常态化宣传，让政策家喻户晓。对核电路、山口至船埠、幕阜山片区旅游公路重要节点地段，由各乡镇牵头，县规划部门配合，设置规划控制区标识牌。切实制订和出台农村建房集约节约用地政策，鼓励农村建房建筑占地面积控制在110平方米以内。对“三道”两侧建房、规划测量等规费收取，以户为单位实行统一价格，由县政府统筹安排，从工作经费中拨付。凡未经审批无规划乱搭乱建的，依照《中华人民共和国城乡规划法》《湖北省城乡规划条例》等法律法规，给予处罚，并依法拆除。

七、加强巡查监管执法

一是建立健全监管机制。实行县、乡（镇）、村三级联动。县住建局作为城乡规划主管部门，每季度对全县各乡镇开展一次专项规划督察；建立村、乡（镇）、县三级巡查联动和报告制度。县政府成立由县住建（规划）、国土、交通（公路）、环保、林业、水利、公安等部门组成的联合执法大队，落实人员、经费，专人、专职、专管。联合执法大队负责对全县各乡镇进行常态化巡查，并协助各乡镇对违建和破坏生态环境现象进行打击和执法。凡乡村违法建设和破坏山体及生态环境行为，一经发现，及时处理和坚决打击。二是落实监管责任。实行“三级”联动履责机制：县四大家包保乡镇领导对各乡镇实行巡查监管责任包保，各乡镇党政主要负责人是辖区生态环境破坏和农村个人建房监管领导责任人，乡镇驻村包村干部、县住建局分管乡建的负责人和县国土资源局分管执法监察的负责人是巡查监管的具体责任人，各乡镇规建办主任、国土所长和村支书（村主任）是农村个人建房规划监管第一责任人。乡镇规建办和国土、林业部门要在十个工作日内做好建房户的规划联合审批和及时上报乡镇人民政府。要强化巡查，切实做好建设规划的日常监管工作。

县纪委监委要建立村镇违法建设和生态环境破坏问责机制，对违建监管不力、失职、渎职的单位和个人，一经发现，将根据情节轻重分别给予组织处理或纪律处分；涉嫌犯罪的，依法移送司法机关处理。

本通知自印发之日起施行，有效期至2020年12月31日。
