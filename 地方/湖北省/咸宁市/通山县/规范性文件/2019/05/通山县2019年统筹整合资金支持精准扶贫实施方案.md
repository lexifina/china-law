# 通山县2019年统筹整合资金支持精准扶贫实施方案

根据《国务院关于探索建立涉农资金统筹整合长效机制的意见》（国发〔2017〕54号）、《省人民政府办公厅关于创新建立贫困县资金整合机制实施精准扶贫的意见》（鄂政办发〔2015〕63号）、《省人民政府办公厅关于完善财政资金统筹整合长效机制的通知》（鄂政办发〔2018〕11号）和《省财政厅关于进一步推进统筹使用财政资金的指导意见》（鄂财农发〔2017〕25号）文件要求，为深入贯彻落实中央、省、市精准扶贫工作相关精神，进一步加大精准扶贫工作力度，创新财政投入，优化资源配置，切实提高财政专项资金统筹使用效率，集中财力支持巩固精准扶贫、精准脱贫成效，特制定本方案。

一、指导思想

以党的十九大及中央扶贫工作会议精神为指导，牢牢把握精准扶贫、精准脱贫基本方略，认真贯彻落实中央、省、市关于精准扶贫工作的有关文件精神，以提高财政专项资金使用效益为目标，以扶贫攻坚项目建设为主线，以“精准扶贫、不落一人”为总要求，以改善人居环境、培育高效产业、促进农民增收为核心，以精准扶贫、精准脱贫为重点，通过建立政府主导、部门配合、社会参与、制度创新、上下联动的工作机制，整合县直各部门和各渠道的财政专项资金，将有限的财政专项资金整合捆绑使用，为整县推进精准扶贫工作奠定坚实基础。

二、基本原则

（一）统筹规划，科学布局。规划是基础，统筹是关键，以规划引导统筹，以重点项目主导统筹。项目规划要科学合理，切实可行，具有可操作性。

（二）集聚财力，全面统筹。坚持跨部门、跨年度、跨层级统筹，以财政资金统筹为主体，带动金融资金和社会资金统筹，带动各种资源统筹，带动各方面力量统筹，增强统筹功能。

（三）搭建平台，精准发力。坚持用精准扶贫规划为引导，以精准扶贫项目为平台。明晰统筹资金的来源渠道、使用平台、资金额度、项目进度、责任单位等，做到内容明确具体、资金流向清晰、责任分工明确，确保精准扶贫到村到户到人。

（四）注重实效，提高效益。科学界定统筹范围，大力推进统筹资金，完善统筹方式，建立健全县级考核、考评、验收机制，以考核、考评促财政资金统筹，以财政资金统筹促考核、考评制度完善，把资金用到实处，把效益发挥到最好。

（五）公开透明，接受监督。建立健全覆盖资金分配、拨付、使用、监管和绩效评价过程的统筹资金管理制度体系，确保资金使用安全规范。

三、统筹范围

根据《国务院办公厅关于支持贫困县开展统筹整合使用财政涉农资金试点的意见》（国办发〔2016〕22号）、《省人民政府办公厅关于创新建立贫困县资金整合机制实施精准扶贫的意见》（鄂政办发〔2015〕63号）和《省财政厅关于贯彻落实〈省人民政府办公厅关于创新建立贫困县资金整合机制实施精准扶贫的意见〉的通知》（鄂财农发〔2015〕127号）等精神，统筹使用财政专项资金范围：中央层面包括财政专项扶贫资金、水利发展资金、农业生产发展资金、林业改革资金、农业综合开发补助资金、农村综合改革转移支付、新增建设用地土地有偿使用费安排的高标准基本农田建设补助资金、农村环境连片整治示范资金、车辆购置税收入补助地方用于一般公路建设项目资金（支持农村公路部分）、农村危房改造补助资金、农村电网改造升级工程中央基建投资预算、以工代赈示范工程中央基建投资预算、农村饮水安全巩固提升工程中央基建投资预算、规模化大型沼气工程中央基建投资预算、退牧还草中央基建投资预算、水文基础设施中央基建投资预算、种养业循环一体化项目中央基建投资预算、水生态治理中小河流治理等其他水利工程中央基建投资预算、重点区排涝能力建设中央基建投资预算、中央预算内投资用于“三农”建设的其他资金。省级层面包括涉农项目及非农项目、上级安排及本级安排、当年安排及结转资金（跨年度资金）、存量资金及增量资金。用于扶贫开发的财政扶贫、以工代赈、少数民族发展、革命老区等资金；用于农村基础设施的国土整治（结存在县财政国库的、规定年限内的土地整治项目资金、本年省级财政专项转移支付安排的土地整治项目资金、经竣工结算后形成的土地整治项目净结余资金）、农发项目、农田水利、农村“一事一议”奖补、现代农业、农村公路、农村饮水安全、农村电网、村卫生室等建设资金；用于农业生产的农技推广、现代农业生产发展、农民合作社发展、农业生产防灾减灾等资金；用于生态环境建设的绿满荆楚奖补、退耕还林（还草）、天然林保护、造林补贴、经济林工程、农村环境整治等资金；用于农村社会事业发展的教育、卫生、文化等资金，用于民生的农村低保、“五保户”供养、危房改造、扶贫搬迁、惠农补贴新增和集中使用部分、新型农民培训等到村到户资金。

四、统筹规模及使用方向

（一）统筹规模。2019年全县计划统筹整合资金58774万元，主要用于支持巩固精准扶贫、精准脱贫。

（二）资金投向。

1．统筹整合财政专项资金29863万元，用于巩固提升精准扶贫成果，进一步改善贫困村及非贫困村基础设施建设，按照脱贫不脱政策，紧紧围绕落实各项精准脱贫政策，特别是产业扶贫、健康扶贫、教育扶贫、民政兜底等。

2．统筹整合财政专项资金11911万元，用于支持落实中央、省、市、县提出的精准扶贫政策。按照“精准扶贫、不落一人”总体要求，一是对建档立卡深度贫困人口，实施扶贫政策叠加，主要用于购买新农合医疗保险、新农保养老保险、健康扶贫补充保险等政策。二是健立建全贫困农户小额贷款风险补偿资金制度，用于解决建档立卡贫困户贷款风险补偿、易地搬迁项目贴息和贫困户小额信贷贴息；三是继续加大贫困村和非贫困村脱贫攻坚政策落实力度，用于支持深度贫困村及贫困村基础设施建设、产业发展、光伏发电及光伏发电奖补、贫困户相关保险支出、农村互联网和深度贫困村需要解决的基础项目建设及贫困村补助等支出；四是用于支持贫困户小额信贷贴息及银行发放贷款奖励支出。

3．金融资金。撬动银行信贷资金17000万元，用于支持全县贫困户发展产业信贷资金15000万元，二是用于贫困大学生助学贷款2000万元。

五、保障措施

（一）加强领导，落实责任。全县2019年统筹整合资金用于精准扶贫工作由县统筹使用财政专项资金工作领导小组统一负责、统一部署、统筹使用资金。县统筹办加强与各项目主管部门综合协调，指导督办统筹使用资金工作。项目主管部门积极参与资金统筹，做好做实项目规划、项目申报和资金的对接落实。任何单位和部门不得以任何理由抵制和干扰，做到应统尽统。

（二）健全机制，齐抓共管。统筹使用财政专项资金坚持规划引导，明晰资金来源，实施跨部门、跨年度、跨层级统筹。打破条块分割、各自为政的管理模式，建立统一区域规划、统一勘测设计、统一招标采购、统一项目实施、统一检查验收、分头报账的“五统一分”管理机制。各单位要按照统筹使用财政资金规模与投向及时与项目实施地对接，确保整合项目按时间要求推进到位，统筹使用财政资金要全额落实到位。各相关乡镇要与县直单位做好对接，尽快将整合项目落地，抓好项目建设，确保建设成效。

（三）强化监督，严格奖惩。按照“既要整合，又要管理”的要求，建立以绩效审计为重点的综合审计及考评检查制度。县精准扶贫指挥部定期召开协调会、督办会、会商会，研究解决精准扶贫资金统筹工作中的问题困难；县政府督查室对统筹使用财政专项资金重点建设项目分阶段进行督办；县纪委对统筹项目单位的项目进展及资金落实情况按季度进行督查，对推进缓慢、责任不落实的进行问责，并限期整改。县委、县政府把资金统筹额度作为行政绩效管理的重要目标，年终纳入年度绩效目标考核。绩效考核由县精准扶贫指挥部牵头，监察、组织、财政、审计等相关部门参与，形成政府主导、部门联动、各负其责、上下齐抓的良好工作局面。对符合整合要求、纳入整合范围的资金要坚决统筹到位，对完成整合目标任务、使用整合资金效率高的要给予通报表扬，对未完成任务和统筹整合资金使用效率低的要进行通报并问责，对连续两年完不成整合任务目标的停拨单位相关专项资金。
