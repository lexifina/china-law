# 县政务服务和大数据管理局党组关于领导班子成员工作分工的通知

各股室、局属各单位：

根据工作需要，经研究，现将县局领导班子成员工作分工通知如下：

金武春（党组书记、局长）：主持全面工作。

朱早腾（党组成员、副局长）：分管机关、人事、财务、档案、党风廉政建设、综合治理、后勤保障、优化营商环境、公共资源交易监管、全面深化改革、招商引资、重点企业、驻村工作；指导乡镇做好乡（镇）、村（社区）两级便民服务机构建设工作；分管办公室、公共资源交易监管股、驻村工作组。

徐红萍（党组成员、工会主任）：分管政务服务大厅日常管理及督查考核、政务服务管理、政务公开、行政审批制度改革、“一张网”建设、数据信息管理、人大政协提案议案办理、信访维稳、计划生育、党建、文明创建、工会、妇联工作；指导乡镇做好乡（镇）、村（社区）两级便民服务机构建设工作；分管政务服务管理股、大数据管理股。

2019年5月21日
