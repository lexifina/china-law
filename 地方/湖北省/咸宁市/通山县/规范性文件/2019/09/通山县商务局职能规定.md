# 通山县商务局职能规定

主要职责是：

（一）贯彻执行国家对外开放、利用外资和国际经济合作以及国内外贸易发展战略、方针、政策，拟订全县商务工作发展规划以及具体政策措施和实施办法。

（二）负责全县内外贸易商品的物流管理与协调工作，负责推进流通产业结构调整、商贸服务业和社区商业发展，提出促进商贸企业发展的政策建议，推动流通标准化和连锁经营、商业特许经营、物流配送、电子商务等现代流通方式的发展，负责拟订全县商业网点建设规划，并组织实施和报批。

(三)培育和完善现代市场体系，促进城乡市场发展，研究提出引导国内外资金投向市场体系建设的政策，指导大宗产品批发市场规划、商业体系建设工作，推进农村市场体系建设，组织实施农村现代流通网络工程。

(四)组织实施主要消费品的市场调控和重要生产资料流通管理，监测分析市场运行和商品供求状况；负责全县商务运行数据统计及相关信息的收集整理、分析和发布工作。

(五)参与协调全县整顿和规范市场经济秩序工作；指导全县商务领域信用体系建设；负责商务行政执法案件协调和审理工作。

(六)执行国家制定的进出口商品、加工贸易管理办法、进出口管理商品和技术目录以及进出口商品配额招标政策，指导全县进出口业务工作。依法监督全县技术引进、设备进口、国家限制出口技术工作。

(七)指导我县在境内外举办的对外经贸交易会、展销会、洽谈会、博览会及有关涉外经贸活动；负责全县商务系统涉及世贸组织相关事务的研究、指导和服务工作；协助有关部门进行产业损害调查；组织并指导我县企业参与国外对我县出口商品的反倾销、反补贴、保障措施的应诉和相关工作。

(八)指导全县外商投资项目合同、章程及其变更、终止、解散及外商投资企业的进出口工作；按规定权限，审核、核准国家规定的限额以上、限制投资和涉及配额、许可证管理的外商投资企业设立工作；依法监督检查全县外商投资企业执行有关法律法规规章、合同章程的情况并协调解决有关问题，发布外商投资项目，指导全县各类外贸外资外经和投资促进工作。

(九)指导和监督全县对外承包工程、对外劳务合作、设计咨询等业务的管理，指导企业对外经济技术合作与交流，落实本县公民出境就业管理政策，审核境外就业介绍机构资格认定，协助进行监督检查。

(十)承办上级交办的其他事项。
