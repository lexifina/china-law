# 通山县文化和旅游局职能规定

主要职责是：

（一）贯彻上级关于文化、旅游、体育和广播电视工作的路线、方针、政策、法律法规，制定全县文化、旅游、体育和广播电视工作的规范性文件和主要措施，并组织实施和监督检查。

（二）研究拟定全县文化、旅游、体育和广播电视事业的发展战略、总体布局，编制并组织实施文化、旅游、体育和广播电视事业的中长期发展计划和年度计划，指导文化、旅游、体育和广播电视体制改革与创新。

（三）研究拟定全县文化、旅游、体育和广播电视产业政策，组织协调文化、旅游、体育和广播电视产业发展，指导规范全县文化体育设施建设。

（四）指导、管理全县社会文化事业，组织指导文学艺术创作与生产，推动群众文化和高雅艺术发展，挖掘整理民间文化艺术资源，弘扬地方特色文化；指导图书馆、文化馆（站）事业和基层文化建设；拟订全县非物质文化遗产保护规划，组织实施非物质文化遗产保护和优秀民族文化的传承普及工作。

（五）负责指导全县文博事业发展，拟订全县文物普查、保护、抢救、考古、发掘和利用规划，依法管理全县文物事业。

（六）统筹协调全县旅游业发展。组织全县旅游资源的普查、规划、开发和保护工作。指导全县旅游区域、旅游目的地和旅游线路的规划开发。组织全县旅游整体形象对外宣传和重大促销活动，组织、指导重要旅游产品开发。负责旅游经营者的资质审查工作，对服务质量、旅游安全实施管理。

（七）负责规范旅游市场秩序，监督管理服务质量，维护旅游消费者和旅游经营者合法权益。负责规范旅游企业和从业人员的经营和服务行为，指导旅游行业精神文明建设和诚信体系建设，负责旅游安全综合协调和监督管理，组织、协调旅游应急救援工作。

（八）统筹协调全县体育事业发展。组织推行全民健身计划。负责对全县性体育社团进行资格审查和业务指导，管理、指导体育社团开展社会体育活动。组织举办全县性体育竞赛，研究全县竞技体育运动项目布局，指导学校体育、体育竞赛、承办市级以上重要赛事。搞好业余体育训练工作，组队参加市级运动会、年度比赛及其他赛事。组织协调管理全县电脑体育彩票（足球彩票）和即开型体育彩票发行工作，规范销售行为，筹集体育事业发展公益金。

（九）负责审查全县广播电视节目、信息网络视听节目和公共视听载体播放节目的内容和质量。指导、监管广播电视重点基础设施建设。

（十）研究拟定全县文化、旅游、体育和广播电视系统干部职工教育规划和人才培养计划并指导实施，组织文化艺术、旅游、体育和广播电视科技研究应用，推广文化艺术、旅游、体育和广播电视科技成果。

（十一）依法管理文化、旅游、体育和广播电视市场。制定全县文化、旅游、体育和广播电视市场发展规划和有关政策，实施文化、旅游、体育和广播电视经营从业资格准入和退出管理，组织指导文化旅游市场综合执法工作。

（十二）负责全县文艺类产品网上传播前置审批工作，负责对全县网吧等上网服务营业场所实行经营许可证管理，对网络游戏服务进行监管；负责对文艺经营活动（包括对从事演艺活动的民办机构）进行行业监管。

（十三）管理全县对外文化、旅游、体育和广播电视交流联络工作，组织指导文化艺术、旅游、体育和广播电视对外交流活动。

（十四）负责组织、指导、协调全县“扫黄打非”工作，组织查处大案要案。

（十五）完成上级交办的其他任务。
