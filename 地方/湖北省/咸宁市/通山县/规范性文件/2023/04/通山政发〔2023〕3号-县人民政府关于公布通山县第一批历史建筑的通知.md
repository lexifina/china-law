# 县人民政府关于公布通山县第一批历史建筑的通知

各乡镇人民政府，保护区、开发区、风景区管委会，富水湖湿地公园管理处，县政府各部门：

为加强我县历史建筑保护，保留历史记忆、彰显地域特色，促进传统建筑艺术的传承和延续，根据《省住建厅省文旅厅关于进一步加强历史文化街区和历史建筑保护工作的通知》和《湖北省历史文化街区划定标准》《湖北省历史建筑确定标准》精神，现将通山县33处历史建筑名单予以公布。

各乡镇各部门要按照历史建筑保护有关规定，认真研究落实具体措施，切实加强对本辖区内历史建筑的保护、管理和宣传工作。相关职能部门要加强保护管理指导，划定保护范围、设置保护标识、建立相关档案，充分研究发挥历史建筑文化价值。
