# 湖北省人民代表大会常务委员会关于大力推动建设全国构建新发展格局先行区的决定

为深入贯彻党中央决策部署和省第十二次党代会精神，大力推动我省建设全国构建新发展格局先行区，特作出如下决定。

一、深刻认识建设全国构建新发展格局先行区的重大意义

加快构建以国内大循环为主体、国内国际双循环相互促进的新发展格局，是以习近平同志为核心的党中央准确把握国内外大势、着眼我国中长期发展作出的重大战略部署，是重塑我国国际竞争新优势的重要战略抉择。党的十八大以来，习近平总书记先后5次考察湖北，参加十三届全国人大三次会议湖北代表团审议，对湖北工作作出一系列重要指示，为新时代湖北高质量发展把脉定向、指路领航。2022年6月28日，习近平总书记考察湖北，对科技创新、社区治理、疫情防控、经济发展等工作作出新的重要指示，提出新的重要要求，寄予殷切期望。省第十二次党代会认真贯彻落实习近平总书记关于湖北工作的重要讲话和指示批示精神，不折不扣贯彻落实党中央决策部署，立足新发展阶段，完整准确全面贯彻新发展理念，科学谋划湖北未来发展蓝图，提出建设全国构建新发展格局先行区的目标任务。这是湖北落实国家重大战略必须肩负的历史使命，是湖北“建成支点、走在前列、谱写新篇”在新发展阶段的内在要求，是湖北全面推进社会主义现代化建设的重要路径。从经济结构、资源要素、地理区位、发展态势等方面看，湖北完全有基础、有条件、有能力建设全国构建新发展格局先行区。我们要深刻领悟“两个确立”的决定性意义，增强“四个意识”、坚定“四个自信”、做到“两个维护”，不断提高政治判断力、政治领悟力、政治执行力，坚决把思想和行动统一到党中央决策部署和省委工作要求上来，切实增强责任感和使命感，抢抓机遇、开拓进取，加快建设全国构建新发展格局先行区。

二、准确把握建设全国构建新发展格局先行区的总体要求

建设全国构建新发展格局先行区，必须坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大、二十大精神，一丝不苟贯彻落实习近平总书记关于湖北工作的重要讲话和指示批示精神，坚持以人民为中心的发展思想，坚持稳中求进工作总基调，立足新发展阶段，完整准确全面贯彻新发展理念，统筹发展和安全，统筹城乡区域和资源环境协调发展，统筹国内国际两个市场、两种资源，推动高质量发展，促进共同富裕，加快“建成支点、走在前列、谱写新篇”，奋进全面建设社会主义现代化新征程。

今后五年，要围绕建设全国构建新发展格局先行区，统筹衔接我省“十四五”规划，努力实现创新发展迈上新台阶、四化同步取得新进展、改革开放实现新突破、民生福祉达到新水平、治理效能得到新提升、党的建设取得新进步。到本世纪中叶，全面建成富强民主文明和谐美丽的社会主义现代化新湖北，物质文明、政治文明、精神文明、社会文明、生态文明全面提升，经济社会发展主要指标达到发达经济体平均水平，全体人民共同富裕基本实现。

三、全面落实建设全国构建新发展格局先行区的重点任务

建设全国构建新发展格局先行区，必须坚持统筹谋划、长短结合，系统协同、重点突破，努力实现更高质量、更有效率、更加公平、更可持续、更为安全的发展，推动湖北由沿海开放的“后队”转变为新时代内陆发展的“前队”。

坚决守住构建新发展格局的安全底线。坚持总体国家安全观，强化底线思维，增强风险意识，扎实做好防风险、保安全、护稳定、促发展各项工作，高效统筹疫情防控和经济社会发展，抓细抓实常态化疫情防控，坚决守住流域安全、生态和粮食安全、经济安全、社会稳定等底线，确保江河安澜、社会安宁、人民安康。

加快建设现代产业体系。坚持创新驱动发展，以攻克关键核心技术“卡脖子”问题为突破口，推进产学研协同创新，打通从科技强到产业强、经济强的通道，加快推进武汉具有全国影响力的科技创新中心建设，推动全国科技创新高地、制造强国高地、全国数字经济发展高地、全国现代农业基地、全国现代服务业基地建设，加快形成汽车、光电子信息等若干个具有全国辐射力和国际竞争力的骨干产业和产业集群。

打造国内大循环的重要节点和国内国际双循环的重要枢纽。积极融入全国统一大市场，着力扩大有效需求，加快建设综合交通运输体系和全国重要物流枢纽，打造国内大循环的生产节点、流通节点、消费节点，构建国内国际双循环的要素链接、产能链接、市场链接。

推进区域协调发展和新型城镇化。推进长江中游城市群协同发展，大力发展以武鄂黄黄为核心的武汉都市圈，建设襄阳都市圈和宜荆荆都市圈，支持各市州差异化发展、协同发展，实施城市更新行动，加快形成大中小城市协调发展新格局。

大力实施强县工程。加快推进以县城为重要载体的就地城镇化和以县域为单元的城乡统筹发展，加强县城建设，构建一二三产业融合的发展体系，建立统筹县城、乡镇、村庄的三级服务体系，健全政府、社会、村民共建共治共享的治理体系，促进农民增收，缩小城乡差距。

全面深化改革开放。以控制成本为核心优化营商环境，深化重点领域和关键环节改革，内引外联、双向开放，推动改革开放和高质量发展深度融合、高效联动。

加快文化强省建设。增强文化自觉、坚定文化自信，着力构筑精神高地，高质量发展文化事业，打造文化产业增长极，推进荆楚文化创造性转化、创新性发展。

更大力度保障和改善民生。持续增加居民收入，加快发展社会事业，全面建设教育强省，推进疾控体系改革和公共卫生体系建设，兜实兜牢民生底线，夯实共同富裕基础。

大力发展社会主义民主政治。积极发展全过程人民民主，加快建设更高水平的法治湖北，坚决捍卫政治安全，加强国防和后备力量建设，巩固发展生动活泼、安定团结的政治局面。

四、着力推动建设全国构建新发展格局先行区各项部署的有效实施

把党的全面领导贯穿于建设全国构建新发展格局先行区全过程、各领域、各环节，坚决贯彻落实党中央决策部署和省委工作要求，将党的政治优势和人民代表大会制度优势转化为建设全国构建新发展格局先行区的坚强保障。

省人大常委会、设区的市（州）人大及其常委会、自治县人大应当坚持立法决策与改革发展决策相衔接，丰富立法形式，注重急用先行，善于通过“小切口”立法解决实际问题，加快重点领域、新兴领域立法修法，推动区域协同立法，加强规范性文件备案审查，发挥立法的引领推动和规范保障作用。各级人大及其常委会应当综合运用听取和审议工作报告及专项工作报告、执法检查、专题询问、专题调研、适时作出决定等方式，推动建设全国构建新发展格局先行区各项任务落地见效；加强对国民经济和社会发展计划等审查监督，深化预决算、地方政府债务审查监督和国有资产管理情况监督，完善对司法工作的监督。全省各级人大代表应当认真履行代表职务，密切联系群众，提出高质量议案建议，充分发挥参与决策、监督推动、桥梁纽带、模范带头作用，引领和带动全省人民投身建设全国构建新发展格局先行区的实践。

各级人民政府及其部门应当锚定省第十二次党代会确定的全省经济社会发展战略、主要目标和重点任务，完善上下联动、协同高效的实施机制和区域协同发展工作机制，制定落实方案，压实工作责任，健全评价体系，实行清单式推进、项目化管理，创造性落实各项目标任务。认真落实《湖北省流域综合治理和统筹发展规划纲要》，因地制宜编制市（州）、县流域综合治理和统筹发展规划，明确细化负面清单、正面清单和重点任务，确定年度行动计划，并对实施情况定期进行评估。强化政策支持，加大制度创新力度，及时制定、修订、废止有关政府规章和规范性文件，完善财政、金融、科技、人才、资源、环境等保障体系，着力保障重大项目要素供给。强化监督考核，督促各级行政机关及其工作人员依法行使权力、履职尽责，不断提高政府行政效能，推动建设全国构建新发展格局先行区各项部署全面落实。

各级监察委员会应当积极履行法定职责，紧盯党中央决策部署和省委工作要求强化监督问责，坚定不移惩治腐败，推动深化改革、完善制度，规范权力运行，加强法治教育、廉洁教育，一体推进不敢腐、不能腐、不想腐，深化拓展清廉湖北建设，为建设全国构建新发展格局先行区营造良好政治生态和发展环境。

各级人民法院、人民检察院应当坚持服务大局、司法为民、公正司法，依法履行审判职能、检察职责，找准服务保障建设全国构建新发展格局先行区的结合点和着力点，不断提升司法质量、效率和公信力，依法维护国家政治安全、确保社会大局稳定、促进社会公平正义、保障人民安居乐业。

工会、共产主义青年团、妇女联合会等群团组织应当充分发挥自身优势，激发社会各界参与建设全国构建新发展格局先行区的积极性、主动性和创造性。基层群众性自治组织应当发挥自我管理、自我教育、自我服务、自我监督功能，推进自治、法治、德治融合，推动基层治理创新。鼓励和引导企事业单位、社会团体、其他组织等社会力量积极参与建设全国构建新发展格局先行区。各类市场主体应当弘扬企业家精神，着力做强做优做大，充分迸发创新创造创业活力。

坚持以人民为中心的发展思想，走好新时代党的群众路线，尊重人民群众主体地位，丰富和发展全过程人民民主的基层实践，扎实开展“下基层、察民情、解民忧、暖民心”实践活动，广泛开展美好环境与幸福生活共同缔造活动，突出乡村振兴、城市更新、流域综合治理、产业发展、基层治理等重点领域，从群众关心的事和让群众满意的事做起，统筹用好政府、社会、群众多元力量，发动群众决策共谋、发展共建、建设共管、效果共评、成果共享，共同建设美好家园，为建设全国构建新发展格局先行区凝心聚力。

建设全国构建新发展格局先行区，事关全局、事关长远，责任重大、使命光荣。我们要更加紧密地团结在以习近平同志为核心的党中央周围，在省委坚强领导下，认真贯彻落实党的二十大精神，按照省第十二次党代会确定的目标任务，保持闯劲拼劲韧劲，踔厉奋发、笃行不怠，努力建设全国构建新发展格局先行区，加快“建成支点、走在前列、谱写新篇”，为全面建设社会主义现代化国家、实现中华民族伟大复兴的中国梦作出新的更大贡献。

本决定自公布之日起施行。
