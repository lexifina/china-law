# 镇委办公室镇政府办公室关于印发《多宝镇2012年服务企业招工工作方案》的通知

各村民委员会：

现将《多宝镇服务企业招工工作方案》印发给你们，请你们结合本单位实际，认真组织，抓好落实。

中 共 多宝镇委办公室

多宝镇人民政府办公室

二O一二年二月十二日

多宝镇服务企业招工工作方案

为了贯彻落实《关于做好服务企业招工工作的意见》(天办发[2010]27号)精神，服务劳动者本人就业，满足企业用工需求，保障“321产业工程”顺利实施，促进我镇经济又好又快发展，特制定如下工作方案：

一、宣传发动

主题思想：“家门口就业——有家、有业、有爱”。

工作目的：帮助企业排忧解难，引导农村劳动力家门口就业，吸引外出务工人员返乡就业。

在全镇上下充分利用本镇现有的有线电视、村务公开栏及时公布市就业局招工信息，让外出务工人员充分了解天门及天门企业用工和待遇情况。让外出务工人员在家就业，让他们认识到在家打工有家有业更有爱，既能挣钱，又能照顾家人及小孩的学业，让小孩健康成长。

二、调查摸底

(一)以村组为单位组织开展外出务工人员基本摸底工作，填写《乡镇外出务工人员就业状况调查表》，建立乡镇人力资源库，并报市服务企业招工领导小组办公室。

(二)联系在外务工返乡人员到结对企业参观考察，了解企业生产经营、用工岗位、劳动报酬、福利待遇等情况，吸引外出务工人员返乡就业。

三、组织领导

各单位要把为重点企业招工工作为服务全镇工作大局的阶段性重点工作来抓，采取得力措施，努力解决好企业“用工难”的问题，确保招工工作圆满完成。特成立以镇委副书记、镇长程诗舫为组长，镇委副书记、综治办主任蒋永和，镇委组织委员隗旭鹏为副组长，潘晶、谌林海、陈立、韩俊平、李新明、余才明、高翔为成员的领导小组。领导小组下设办公室，办公室设在镇人社服务中心，余才明同志兼任办公室主任。

四、奖惩措施

(一)根据村招工工作完成情况按人头给予奖励：完成任务按实际人数予以奖励。(务工人员在市政府确定的 30家重点企业上班，均可计算奖励人头。所有招工人员必须至少在企业工作满3个月才能给予奖励)。

(二)鼓励本镇在企业的员工“以工招工”，企业员工推荐人员到本市重点企业就业满3个月的，予以奖励。

(三)全镇将对组织积极任务完成的好的村给予表彰奖励；对组织不力，完不成任务的村予以通报批评，并作为2012年经济目标责任状考核结帐的评分依据。
