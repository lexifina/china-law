# 镇委办公室镇政府办公室关于2011年度服务企业招工工作考核结帐的通报

各党总支、支部，村（居）民委员会：

2011年，我镇坚持“企业用工为主、政府促进为辅”的原则，牢固树立“招工就是招商”的意识，按照市委、市政府和市招工工作领导小组有关文件要求和会议精神，强化措施，密切配合，较好的完成了招工工作任务。现将2011年全镇招工工作情况通报如下：

一、基本情况

在整个服务企业招工工作中，大多数村按照镇委、镇政府的统一要求，成立了以村支部书记为组长，相关负责人为成员的工作专班，明确了任务，强化了责任；片总支也加强了领导，组织村组干部发放宣传资料，做好返乡在外务工人员本地就业的宣传引导工作；在全市组织的大型招聘会上和乡镇结对企业招工活动中，各村都安排专人接送应聘者，赖场、沙岭、大兴等村还自费派车接送；雷场、崔王率先组织开展农村劳动力调查，建立外出劳动力资源信息库；三桥、江桥、金场等村精心组织，深入到农户家中为益泰药业、浙江白天鹅等企业招工。

虽然我镇服务企业用工取得了一定成效，但仍存在一些不足和需要改进的地方，离市委、市政府的要求还很远。一是有的村对招工工作宣传不够，不能及时发布招工信息，没有把信息传达给有求职意向的群众手中。二是有的村敷衍塞责，将没有求职意向的人员组织参加市内招聘会。三是有的村对本村劳动力情况不明，不能按结对企业的要求组织人员去应聘。

二、结账奖励措施

2010年10月至2011年12月，市30家重点企业招工82人，按照上岗满3个月以上的考核结帐条件，纳入本次服务企业招工结帐范围的招工人数为43人，按每人100元的金额予以奖励（见附表）。同时，镇政府决定对在2011年度招工工作中领导重视，措施得力，成效较显著的方桥村、居委会、艾垸村、金场村、三桥村、江桥村、沙岭村、雷场村、赖场村、大兴村等10个村予以通报表彰。

三、2012年招工工作要求

1、进一步落实招工措施。各村要做好农村富余劳动力资源调查摸底工作，并做好富余劳动力工种情况的详细了解及登记，以便对企业有针对性的招工。

2、加大招工宣传力度。通过召开各级各类会议等方式，着力宣传工业园区重点企业的用工环境和用工情况；向农村富余劳动力发送宣传材料；配合市工业园区各企业悬挂、张贴招工标语；不定时刊出招工信息和市招工办制定的各种优惠政策。

3、继续实行目标管理，将责任层层落实。2012年我镇与益泰药业、叮当猫服饰结对为对口招工企业，各村要创新招工方式，结合自身实际，勤于联系，因势利导，积极动员返乡打工群众和在家劳动力到结对企业就业，将有就业意向的人员推荐到工业园区30家重点企业就业，每村至少要推荐5人到企业上岗，结帐按责任状的标准铁帐铁结。

服务企业招工工作是为企业排忧解难、服务劳动者就业、服务经济发展的大事，艰巨而光荣。希望各村进一步强化领导，明确责任，积极服务企业发展，为推动全市经济社会又好又快发展做出新的更大的贡献。
