# 黄潭镇关于调整安置帮教工作领导小组成员的通知

各党总支、支部，各村(居)民委员会、镇直单位：

因人事变动和工作需要，镇委、镇政府决定调整黄潭镇安置帮教工作领导小组成员，其组成人员如下：

组　　长：杨永斌

副 组 长：何汉军 吴圣中

成　　员：吴 斌 黄石安 汪 平 李松树

向波涛 刘徐洲 郑少华 张进祥

领导小组下设办公室，办公室设在镇综治办，办公室主任由向波涛同志兼任。

二〇一二年二月二十四日
