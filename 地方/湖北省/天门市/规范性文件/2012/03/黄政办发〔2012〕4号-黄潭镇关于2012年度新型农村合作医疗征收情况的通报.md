# 黄潭镇关于2012年度新型农村合作医疗征收情况的通报

各村（居）民委员会，镇直有关单位：

2011年，各村紧紧围绕镇委、镇政府工作中心，积极主动工作，较好地完成了2012年新型农村合作医疗基金征缴工作。现将具体情况通报如下：

一、基金收取情况

全镇共有50370人参合，共收取新农合基金2377450元，占应参合基金的94%。

二、各村参合情况

参合率达到100%的村有黄潭、窑台、陈当3个村；参合率在95%至99%的村有曾巷、万场、新王、甘岭、曹湾、西庙、新华、敖堤、水府庙、丝网湾、张台、阳台、向张嘴、七屋岭、黄嘴、徐南、姚垸、彭湾、复兴、八湾、直河、危湖等22个村；参合率在90%至94%的村有小木桥、鲁店、徐马湾、杨泗潭、黄茅湖等5个村；参合率在83%至89%的村有罗口、龙嘴、白龙、前河等4个村。

镇委、镇政府号召，全镇各村要向参合率达到100%的黄潭、窑台、陈当等村学习，学习他们扎实的工作作风和抢前争先的精神，积极探索新形势下征收的思路和办法，克难奋进，顽强拼搏，为我镇农村社会稳定和经济发展做出应有的贡献。

二〇一二年二月十日
