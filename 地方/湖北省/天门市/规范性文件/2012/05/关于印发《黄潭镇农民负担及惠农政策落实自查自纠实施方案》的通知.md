# 关于印发《黄潭镇农民负担及惠农政策落实自查自纠实施方案》的通知

各党总支、支部，各村（居）民委员会：

经镇委、镇政府研究，现将《黄潭镇农民负担及惠农政策落实自查自纠实施方案》印发给你们，请结合实际，认真贯彻执行。

二〇一二年四月二日

黄潭镇农民负担及惠农政策落实自查自纠

实 施 方 案

为确保各项强农惠农政策落到实处，切实减轻农民负担，经镇委镇政府研究，决定在全镇范围内开展农民负担和惠农政策落实情况自查自纠工作，村制定如下实施方案。

一、　 工作目标

以突出重点、务求实效为原则，着重对中央、省、市出台和省、市明确列入重点检查的农民负担及惠农政策落实情况进行自查自纠。通过自查自纠，找准农民负担和惠农政策执行过程中存在的主要问题，有针对性地提出整改措施，使农民负担和惠农政策真正落到实处，促进社会和谐与发展。

二、自查内容

各村、各单位近几年来贯彻落实上级农民负担及惠农政策情况。

（一）关于农民负担政策落实情况。

1、《农民负担监督卡》和《供水水费明白卡》是否到户；

2、各类收款票据的填开是否规范；

3、是否存在乱加码和超范围、超标准收费的情况。

（二）关于惠农政策落实情况。

1、上报的各种农作物的补贴面积是否真实、准确，是否存在虚报补贴面积的现象；

2、村组干部是否存在冒领农户的补贴的现象；

3、种植大户（10亩以上）的身份和面积是否真实；

4、村机动地的补贴面积是否落实到租种人，是否存在村组干部冒领村机动地补贴的现象；

5、是否存在“合并户”的情况；

（三）关于农村土地政策落实情况

重点检查农民土地承包、流转等方面存在的突出问题。

三、检查时间和方法步骤

自查自纠工作从2012年4月2日到5月15日结束。共分四个阶段：

（一）动员部署、学习培训阶段（4月2日—4月7日）

召开全镇农民负担和强农惠农政策落实情况自查自纠工作动员大会，对此项工作进行全面部署，下发实施方案。镇、村成立专门的领导小组和工作专班。要组织专班人员进行学习培训，熟悉掌握各项强农惠农政策以及强农惠农资金拨付的程序和管理使用的规定。同时，广泛宣传此次自查自纠工作的重要意义、检查内容、时间、方法步骤及工作要求，切实把自查自纠的各项政策交给广大群众，充分发挥群众参与的积极性。

（二）摸清底数，自查自纠阶段（4月8日—4月28日）

各村、各单位要按照检查的范围和内容进行全面排查摸底，并写出自查报告，于5月1日前报镇领导小组办公室。

（三）交叉检查，督促整改阶段（4月29日—5月9日）

在自查自纠的基础上，镇政府组组织专班人员进行交叉检查，并派出督导组赴相关村进行重点检查，对检查出来的问题要认真提出处理意见，对一般性的问题要及时纠正处理，限期整改到位；对套取、截留、挤占、挪用、贪污、私分惠农资金以及其他违纪违法问题要认真调查，严肃处理；对顶风违纪的，查出问题不及时纠正的，弄虚作假欺骗组织的，一律依纪依法从重处理。涉嫌犯罪的，移送司法机关处理。

（四）总结评估，深化提高阶段（5月10日—5月15日）

各村、各单位要对自查自纠工作情况认真进行总结评估。在总结评估的基础上，镇领导小组办公室派出专班人员督促各村、各单位重点抓好建章建制工作，切实巩固检查成要，建立健全落实农民负担和惠农政策的配套措施，规范和完善强农惠农资金管理、使用和监管机制。

四、工作要求

（一）高度重视，精心组织。

开展强农惠农和农民负担政策落实情况的监督检查是认真贯彻落实中央、省、市农村工作会议精神，扎实推进社会主义新农村建设，进一步密切党和政府与人民群众关系而采取的一项重要举措。各村、各单位要站在讲政治和全局的高度，充分认识开展农民负担及强农惠农政策落实情况自查自纠的重要性和必要性，增强做好这项工作的责任感和使命感，要克服畏难情绪和侥幸过关心理，力戒不求实效的形式主义，切实把这项工作抓紧抓实，抓出明显成效。

（二）加强领导，落实责任。

开展强农惠农和农民负担政策落实工作自查自纠涉及面广，情况复杂，工作难度大，各村、各单位要把这项工作作为一件大事，摆在突出位置，统筹安排，精心组织。要落实责任分工，加强组织协调，认真履行对有关问题的督查整改职责。

（三）讲求实效，落实整改。

此次活动重在发现问题和解决问题，推动党在农村的各项政策落到实处。各村、各单位要紧紧抓住整改这个关键环节，按照“问题解决不放过、整改不到位不通过”的要求，对自查过程中发现和群众反映的问题要认真梳理，逐条整改。

（四）纠建并举，注重预防。

各村、各单位要通过自查自纠，进一步建立和完善各项监管制度。要结合这次自查自纠活动，开展一次党在农村政策的宣传教育活动，增强各级干部的政策观念和大局意识，提高服务“三农”工作的自觉性和主动性。要适应新形势新任务的要求，善于用现代信息技术手段，堵塞漏洞，逐步实现从外部压力向自觉行动转变，从解决突出问题向建立预防机制转变，从集中治理向用制度规范转变。
