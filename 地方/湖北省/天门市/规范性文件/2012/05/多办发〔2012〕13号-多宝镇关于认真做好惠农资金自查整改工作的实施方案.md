# 多宝镇关于认真做好惠农资金自查整改工作的实施方案

为了认真做好我镇惠农资金的自查整改工作，根据省市关于强农惠农资金落实有关文件及市纠风办《关于在全市开展强农惠农政策资金落实情况监督检查的紧急通知》精神，结合我镇实际，制订本实施方案。

一、自查整改的内容

这次自查整改的内容主要是对全镇近两年来农作物良种补贴、粮食直补、农资综合补贴、农业保险费的补贴发放情况以及农民负担是否超过政策规定等。

重点自查和整改在惠农资金发放管理中是否存在虚假申报、虚报冒领、骗取、套取、截留、挤占、挪用补贴资金的问题；全面核查村组机动地申报领取补贴情况，是否存在以机动地虚报冒领补贴款的问题；逐户核实重名农户领取补贴情况，是否存在虚假申报、重复申报、借名申报等问题。

二、工作方法和步骤

自查整改采取“各村自查自纠和镇财政所挂点干部指导督导相结合、强责与追究相结合的办法，确保所有问题都能处理落实，整个工作分三个阶段进行。

1、村自查自纠阶段：

5月2日—5月10日为各村自查自纠阶段，重点做好以下工作。

（1）查大户。以二轮延包确田确地到户的面积为依据，对粮食补贴面积在10亩以上的农户进行核查，凡一户补贴面积超过二轮延包面积的，即是大户。一是因土地转让，经查证属实、且农户双方认可的，作正常合户对待，核查结果要在登记表上注明隶属关系；二是如果合户没经过农户同意的人为合户，要查资金是否跟农户结算，农户是否知晓，凡没有结清楚的，在自查整改期间必须跟农户办好结账手续并通知到户主本人；三是因承包机动地超过10亩的，要核查面积总和是否相符，且要对补贴归属要查承包合同条款以及补贴的去向，对不符合补贴条件的，所得补贴应视其情况处理，收归集体或上缴财政。

（2）查虚列。对于一户多人领取补贴的，要逐户核查，凡经查实属于虚列姓名、面积套取补贴的要退回财政上缴；对为了抵扣上交款，将部分农户的面积折成两块，一块打在农户的卡上，一块通过虚列姓名领取补贴的，要核实好抵扣农户的面积，抵扣年份，补贴金额，如数跟抵扣农户本人结账，并在以后年度纠正这种做法。

（3）查“三重”：对在同一个村或组中出现同姓名、同身份证和姓名和身份证都相同领取补贴的，在排除和纠正填写登记错误的农户后，对一人多个户头领取补贴的要逐一核查，凡超过二轮延包面积的，要查明多出的原因，按上述查大户、查虚列的办法进行处理。

（4）查机动地：全面清查村组机动地承包合同及申领补贴情况，对补贴资金用虚列的办法套取的，无论资金最后的归属在哪里，一律收归财政上缴市里。

（5）如实填写自查表。自查由村统一组织，分小组进行。对各类必须自查自纠的问题要逐一登记，对已经解决的问题要逐一销号，做好记录和说明，然后由村统一填写分类登记和汇总表，并写出书面自查整改说明，各村于5月10日前将自查整改情况和自查整改分类及汇总表报镇党政办公室。

2、挂村干部督导整改阶段(5月11日—5月17日)

挂村干部督导整改分两个阶段进行。一是村自查自纠阶段主要是参加村组干部会，传达会议精神、统一干部思想、强化工作责任、安排部署本村自查自纠工作，二是5月11日—5月17日为核查整改阶段，主要做好以下几个方面的工作。

（1）听取村对工作情况的汇报，对村在自查自纠中没有解决彻底的特别是涉及村组干部本身的问题，督促整改到位。

（2）通过走访、召开会议等形式，了解党员、群众对二轮延包、农民负担、粮食补贴等问题的意见和建议，与村一道，研究解决的办法。

（3）组织搞好公示。指导申报2012年粮食补贴面积核实工作。2012年粮食补贴发放信息情况检查成员要督促各村以组为单位在醒目的位置进行张榜公示，接受群众监督。

（4）对自查上报不实的重点村，镇委组织专班进行抽查。

3、纠正和查处违规违纪行为阶段（5月18日—5月25日）

（1）5月25日前，各村要将在自查中虚列面积、虚报冒领的补贴资金全额退回财政上缴。对折户抵扣、合户抵扣领取补贴资金的，要足额退还给折户抵扣、合户抵扣农户本人。

（2）针对强农惠农补贴资金中存在侵害国家和农民利益的问题，要保持高压的态势，加大问责力度。对自查自纠中能主动说明问题，清退违规违法资金的，可视情节从轻从宽处理；对在检查核实中发现严重违规违纪及党员和群众举报经查属实的问题，要严肃处理直接责任人，涉嫌犯罪的要移送司法机关依法处理。

三、有关要求

1、强化领导。各级都要牢固树立惠农补贴资金是高压线的意识，各级一把手要对此项工作负总责、亲自抓，分管领导要具体抓，镇成立强农惠农资金落实工作领导小组，组长：张华中，副组长：程诗舫、黄孝贤、蒋永和、彭江南；成员：陈靖、隗旭鹏、杨忠德、贺生波、欧阳尚、曾斌安、潘晶、陈立、韩俊平、谌林海、夏祥义。各地要成立相应专班，积极开展工作，所有挂村的机关干部和财政干部要深入实际，与村组干部一道，认真解决过去在惠农补贴资金中出现的问题，对所挂村工作的好坏情况负有连带责任，村组干部更应该积极主动的解决自身问题，所有人员都要集中时间集中精力全心身地投入到工作中去，以高度的政治责任感和使命感抓好此次自查整改工作。

2、完善基础性工作。各地要针对在自查自纠中出现的问题，通过建章建制，完善在二轮延包、惠农资金、农民负担管理的长效机制，确保党的各项政策的落实。

3、加强纪律。要严格按照镇委统一部署，认真组织，抓紧抓落实。对在自查自纠中流于形式、走过场或对发现的问题不按要求进行整改的，一经发现，坚决追究村主要领导和分管领导的纪律责任。
