# 天门市安监局2012年民主评议政风行风工作的实施方案

根据《市纠风办关于2012年全市民主评议政风行风工作的实施方案的通知》文件精神（天办文[2012]29号），为做好政风行风评议工作，现结合实际，制定如下实施方案：

一、指导思想

深入贯彻落实科学发展观，围绕市委、市政府的中心工作，结合深入开展"喜迎十八大，争创新业绩"活动，以"优化经济发展环境，促进天门跨越发展"为主题，坚持"谁主管，谁负责"、"管行业必须管行风"的原则，紧密结合安全监管工作实际，认真解决群众关注的热点和难点问题，推动局机关和工作人员进一步增强服务意识、宗旨意识、勤政廉政意识，进一步转变工作作风，规范执法行为，提高安全监管水平，切实履行安全监管职能，为推动我市经济又好又快发展作出更大贡献。

二、评议范围和内容

评议范围：市安监局各科室及全体工作人员。

政风行风评议的主要内容：

1、转变作风，优化发展环境的情况。是否贯彻落实科学发展观，认真执行市委、市政府重大决策和部署，建立健全促进经济社会发展的制度机制；是否围绕"抓作风、抓环境、抓落实、促跨越"的要求，制定优化经济发展环境的具体措施；是否切实解决影响经济发展环境和市场主体反映强烈的突出问题；是否把加强政风行风建设、优化发展环境列入重要工作日程，及时完善工作措施，狠抓落实，取得新的明显成效。

2、履行职责，严格依法行政的情况。是否实行政务公开和落实公示制、承诺制、首问负责制、失职追究制；是否顺应企业和市场需求，最大限度减少行政许可项目；是否按照"简化程序、缩短时限、减少费用"的要求，制定履行审批、许可、执法等职责的最优工作标准；是否存在乱办班、乱收费、乱罚款、乱摊派等问题；是否存在有法不依，执法不规范、不公正、不文明问题；是否存在利用职权吃拿卡要，拿了好处乱办事等滥用职权问题。

3、反腐倡廉，提升效能和执行力的情况。是否落实党风廉政建设责任制和纠风工作责任制；是否把政风行风建设与经济发展环境建设需求紧密结合；是否履行"一岗双责"，是否以务实、高效、勤政、廉洁为标准，改进工作作风；是否认真纠正不作为、慢作为等影响机关效能和执行力的问题。

4、整改问题，加强自身建设的情况。是否建立健全政风行风考核管理制度；是否加强职业道德、社会公德、家庭美德教育，提高全员整体素质；对市场主体通过"行风热线"举报投诉和政策咨询的问题，是否给予认真解决和及时解答；市场主体的诉求渠道是否畅通，解决诉求问题的整改效果如何，市场主体是否满意等。

三、组织实施

采取"统一组织、分级负责、条块结合、面向社会、群众参与、上下联动"的方法。民主评议工作从4月份开始，10月份结束。具体安排如下：

（一）宣传发动（4月至5月上旬）

1、认真学习领会文件精神，提高思想认识，制定具体实施方案。

2、成立政风行风评议领导小组。政风行风评议成立以局长曹江斌为组长，陈翠玉、何新兵为副组长，喻想成、章国平、金波、白小红、王国宏、田佳凯为成员的领导小组。

3、召开动员大会。召开局机关民主评议政风行风工作会议，邀请行风监督员参加，组织机关干部学习有关文件，对民主评议政风行风工作进行安排布置。

4、通过新闻媒体和"政风行风热线"等活动，宣传安监局的职能，介绍我市安全监管工作情况，公布民主评议政风行风举报电话，并向社会作出"公开承诺"，自觉接受社会监督。

（二）自查自纠阶段（5月中旬至6月底）

1、广泛征求意见。采取走出去、请进来、设意见箱等方式，主动征求行风代表、行风监督员和乡镇、部门意见和建议。

2、认真自查。要针对本单位存在的突出问题，广泛深入开展自查自纠，力戒形式主义，防止走过场。主要负责人要走进"行风热线"直播间，现场受理企业、群众代表的咨询、投诉，接受社会各界和新闻舆论监督。重点开展"五查五看"，即：查执法行为，看是否存在不按法定依据、权限和程序执法的问题；查收费行为，看是否存在违法规定，擅自设立收费项目，提高收费标准，以及乱罚款乱摊派问题；查工作作风，看是否存在办事拖拉，推诿扯皮，效率低下的问题；查群众纪律，看是否存在态度蛮横，耍特权"门难进脸难看，事难办"的问题；查廉洁自律，看是否存在拿卡要等其他违反党风廉政建设规定的问题。

3、搞好自纠，对自查发现的问题和群众反映出来的问题，进行梳理归纳，未评先改，即知即改，边整边改，严肃查处群众举报的各种违纪违规问题，撰写自查自纠报告，于7月初将自查自纠报告报市纠风办和省安监局行评办公室。

（三）集中整改阶段（7月至8月）

1、针对自查自纠和行评督查员等反映出来的问题、意见和建议，制定并落实整改措施。

2、突出的个案问题要及时反馈，并通过一定形式向社会公开，能及时解决的问题要及时解决，暂时解决不了的，要列出整改计划，涉及政策的问题，要作出说明，让广大群众真切感受到我们整改工作的力度和决心。

3、进一步制定、完善相关规章制度，对原有制度不完善的地方要修改完善，制度不健全的要及时健全，并强化政风行风建设的内部监督机制，建立落实政风行风建设制度的保障措施，促进政风行风建设的经常化、制度化、规范化。

（四）集中测评阶段（9月份）

1、中介机构电话抽样调查。提供两年以来的300名服务对象信息，由市行评办开展服务对象满意度调查。

2、社会问卷调查集中测评。

（1）问卷调查对象范围：安全监管的服务对象、市人大代表、市政协委员、党政机关干部、企业法定代表人和职工代表、农民、下岗职工、个体业主、离退休人员等。

（2）问卷调查方法。测评活动采取设立固定测评点，通过随机摇号方式抽选200人，集中参加对参评部门群众满意度的问题调查，现场填写、现场收回。要高度重视测评工作，作好自查自纠的报告和现场质询的解释工作，以良好的工作作风和精神面貌接受代表的测评。

3、"行风热线"考核。根据"行风热线"日常受理的群众投诉，对政风行风办理情况进行量化考核，并于9月30日前将行评考核情况报送省安监局行评办公室。

4、召开集中评议大会。集中评议大会由市纠风工作领导小组主持，邀请市人大、市政府有关领导和市直部门负责人以及参评部门服务对象代表和行评督查员参加，进行面对面评议，市领导进行点评，在评议大会上，要虚心听取社会各界和评议代表的意见，正确对待评议中提出的问题，分析症结所在，拿出解决办法。

（五）总结阶段（10月）

要及时对政风行风评议工作进行认真总结，于10月8日前向市纠风办和省安监局行评办公室报送2012年度民主评议政风行风工作总结。

四、计分方法和评议结果运用

评议计分采用百分制。

参评部门综合评议得分=抽样调查结果×50%+社会问卷调查结果×20%+集中评议结果×15%+"行风热线"考核结果×5%+市"万人评百岗"评议结果×10%。（具体评分细则另行制定）

对综合得分85分（含85分以上的，授予市级"民主评议政风行风优秀单位"称号；综合得分在85分以下，75分（含75分）以上的，授予市级"民主评议政风行风合格单位"称号；综合得分低于75分的，为民主评议政风行风"不合格单位"。评议结果与党风廉政建设责任制及纠风工作责任制考核、文明行业（单位）评选等挂钩，并作为政府目标责任制考核及其主要领导干部工作绩效考核的重要依据。

五、工作要求

1、加强领导，明确工作责任。要把民主评议政风行风工作作为落实党风廉政建设和纠风工作责任制的重要举措和重要手段，周密组织，狠抓落实。主要领导干部要强化政治意识和责任意识，把政风行风评议工作列入本单位的重要议事日程。民主评议政风行风工作领导小组要加强领导，安排专班、落实人员、明确职责、责任到人。还要积极主动地接受社会各界的监督，切实落实民主评议政风行风工作。

2、广泛宣传，营造良好环境。要重视教育发动，着力提高全体机关干部的思想认识，形成人人都是行评对象，人人参与行评工作的良好局面。充分利用各种媒体舆论导向作用，采取多种形式，向社会广泛宣传安全法律法规，宣传安全监管部门的工作职能，展示安监部门诚恳接受监督、听取意见的意愿和诚意，及时报道政风行风评议工作的进展情况，大力宣传和介绍规范执法、优质服务的典型，公开曝光处理违法违纪案件，让社会各界进一步了解和认识安监部门，感受安监部门加强政风行风建设的决心和信心，感受安监部门保护人民生命财产安全的诚意和力度，感受安监部门促进安全发展的措施和行为，达到理解、支持和关心安监工作，为开展政风行风评议工作营造良好的舆论氛围和社会环境。

3、突出重点，着力解决问题。要紧紧抓住影响经济发展和社会稳定的突出问题，紧紧抓住影响安全发展和科学监管的突出问题，统筹兼顾，将政风行风评议工作与业务工作有机地结合起来，与"三抓一促"和创先争优活动有机地结合起来。正确处理民主评议政风行风和依法行政、履行监管职能的关系，正确处理广大人民群众提出的批评建议和严格监管、推进服务的关系。要着力在"查、改"上下功夫，在解决问题上用实功，严肃查处违规违纪行为，坚持做到"四个不放过"，即：对发现的问题不查清原因不放过，整改措施不落实不放过，纠正处理不到位不放过，群众对整改效果不满意不放过，以整改的实际成效取信于民。
