# 石河镇关于进一步加强招商引资工作的意见

为促进我镇经济持续、快速、健康发展，实施项目带动战略，充分调动和发挥全镇招商资源优势，提高招商引资实效，强化各村、各单位的工作责任，结合我镇实际，提出如下意见：

一、指导思想

认真贯彻落实市招商引资工作会议精神，结合石河实际，着力打造坚实的投资硬环境，和谐的投资软环境，营造“全民招商、亲情招商、人文招商、以商招商”的良好氛围，努力实现招商引资工作的新突破。

二、目标任务

完成投资500万元以上工业项目2个，投资1000万元以上项目1个，镇、村（单位）建设项目若干。

项目包括：

（1）当年引进的固定资产投资在500万元以上的工业项目。

（2）当年引进的固定资产在1000万元以上的种养殖项目、农业观光和农家乐项目。

（3）当年引进的固定资产投资在3000万元以上的文化、教育、卫生、旅游项目。

（4）5000万元以上的物流项目和商业项目（不含房地产项目）。

（5）当年的固定资产投资在3000万元以上的工业扩规项目。

（6）用于镇、村（单位）建设的非普惠性政策资金。

三、组织领导

（一）加强领导，为招商引资工作提供坚强的组织保障

一是成立招商引资工作专班。镇成立招商引资工作领导小组，组长杨圣平，副组长黄仁杰、吴太平，相关人员组成工作专班。二是各村、各部门相应组建由一把手负责的招商引资工作专班，构建上下联动，全民参与的招商引资新格局。

四、完善机制

1、营造浓厚的招商引资氛围。全镇各村、各单位、企业和广大干部群众主动参与到由党委、政府统一领导的招商引资工作中，形成镇、村、企、单位联动的工作网络。

2、建立信息报备制度。各村、各单位、企业要广泛联系，及时向镇招商引资领导小组报告招商引资信息，由镇招商引资领导小组统筹安排，积极开展招商活动。各村、各单位和企业每年必须向镇报送2条以上有价值的招商引资信息，镇年中对信息报备工作进行一次通报，年底考核结帐。

3、建立项目跟踪服务制度。对引进的项目，在镇招商引资领导小组统一协调下，组建专门班子，确定专人负责，积极跟踪服务，及时预见和化解各种可能的困难和问题，加快项目推进速度。

4、建立部门协调配合制度。各级各部门要各司其职、各负其责，加强协调配合，积极参与和支持招商引资工作。

5、完善引进项目和资金的相关资料。各村各单位项目和资金引进后，必须第一时间上报镇招商引资领导小组确认有效信息，作为年底结账的依据。凡不上报确认的，年底一律不纳入结账。

6、加强对招商引资工件的督导。镇委、镇政府每季度召开一次招商引资督导会。

五、激励办法

1、建立招商引资重奖制度

（1）新引进项目的固定资产投资额度在500万元——1000万元的，对项目引进人奖励3000元；固定资产投资额度在1000万元——2000万元的，对项目引进人奖励5000元；固定资产投资额度达到市政府奖励标准的，按市政府奖励政策执行。

（2）乡镇规模以上工业企业（指独立法人、一般纳税人，年销售收入超过2000万元，税收过20万元的工业企业），每新增1个给予工作专班3000元的奖励。

（3）乡镇每新增1个上级认定的市级农副产品龙头企业，给予工作专班800元的奖励，村级每新增1个农民专业合作社奖村300元。

（4）各村、各单位要积极向上争取项目和资金，凡争取到项目和资金（普惠性政策性资金除外）用于镇、村（单位）建设的，镇政府年终对有功人员进行一定的奖励：资金达到5万元的奖800元；资金在5万元—15万元的奖1500元；资金在15万元—30万元的奖2500元；资金在30万元以上的实行一事一议，给予重奖。

（5）对争取到的各类非普惠性资金额度的认定，由申报单位提交有关争取政策性资金竞争性的证明和说明材料，以上级部门下达的资金通知文件为依据，财政部门进行认定。

（6）凡招商引税被税务部门认定的，给予引进人实际入库税金的5-10%的奖励。

（7）在争取项目与非普惠性政策资金过程中的相关开支，由镇招商引资领导小组提供依据，镇政府办公室年底统一核定出具证明，可按到位资金的一定比例在村级、单位财务中列支（10万元以下的控制在10%以内，10万元—20万元的控制在8%以内，20万元—50万元的控制在7%以内）。

（8）对在招商引资工作中有突出贡献的单位和个人，由镇委、镇政府予以通报表彰，授予招商引资先进单位和个人荣誉称号。对第一时间提供有价值信息并成功引进项目的个人给予一定的奖励。

六、建立招商引资过错责任追究制度

各村主要负责人和相关镇直单位负责人为服务招商引资和项目工作的第一责任人，要对本村、本单位打造“零耗时”、“无障碍”的招商引资工作机制负责，对损害和破坏投资环境的责任人，镇党委将依据干部管理的有关规定，严格追究责任人的责任。
