# 石河镇政策性“三农”保险实施方案通知

深入贯彻落实科学发展观，以促进我镇农村经济的持续发展和农民收入的稳定增长为目的，切实推进政策性“三农”保险工作，建立健全农业保障体系，促进城乡协调发展，构建农村防灾减灾机制，维护农业生产环节稳定，保障农业和农民收益。

二、组织领导

镇成立政策性“三农”保险工作领导小组。组长：党委副书记、镇长黄仁杰；副组长：党委委员、副镇长汪家祥；成员：万义传、苏世平、徐团元、谭会明、杨学新、杨唐俊、张胜祖、冯小仙、蒋刚兵、肖春舫、肖顺祖。领导小组下设办公室，万义传同志兼任办公室主任。

三、实施内容

（一）水稻保险。保险金额为每亩200元，保险费率7%，每季每亩保费14元，其中：中央财政补贴40%，每亩5.6元；省级财政补贴25%，每亩3.5元；市财政补贴10%，每亩1.4元；农民承担25%，每亩3.5元。（人寿财险公司承办）

（二）棉花保险。保险金额为每亩400元，保险费率7%，每亩保费28元，其中：中央财政补贴40%，每亩11.2元；省级财政补贴25%，每亩7元；市级财政补贴10%，每亩2.8元；农民承担25%，每亩7元。（中华保险公司承办）

（三）能繁母猪保险。保险金额为每头1000元，保险费率6%，每头保费60元，其中：中央财政补贴50%，每头30元；省级财政补贴30%，每头18元；养殖户承担20%，每头12元。（人保财险公司承办）

（四）“两属两户”农房保险。保险金额为每户3000元，保险费率3‰，每户保费9元，其中：省级财政补贴70%，每户6.3元；市财政补贴30%，每户2.7元。（人保财险公司承办）

（五）油菜保险。按省政府出台的相关政策组织实施。

四、工作步骤

（一）宣传发动阶段（5月16日—23日）。

根据实际情况，充分利用电视、广播、报纸、网络等媒体，大力宣传开展政策性“三农”保险的重要意义、方法步骤及相关政策，让党和政府的惠农政策家喻户晓，人人皆知，使广大农民真正了解政策性“三农”保险的重要作用，增强保险和风险防范意识，提高参与“三农”保险的自觉性。

（二）水稻、棉花保险信息收集阶段（5月23日—31日）

安排人力物力，开展信息收集工作，确保农户姓名、身份证号、投保面积、联系方式、“一卡通”账户或其他有效账户、开户银行等承保信息准确、真实、完整。

（三）水稻、棉花保费收取阶段（5月23日—6月3日）。

按保费方案，依法收取农民应承担的保费。

（四）水稻、棉花凭证发放阶段（6月15日—30日）。

将凭证及时无误地送到每个农户手中，确保凭证到户率达到100%。各村在确保依法合规的前提下，对农户收费、凭证发放和信息收集工作可以同步进行。

（五）其他险种的实施（下半年）。

能繁母猪、“两属两户”农房保险到期后按时续保。

五、结账方案

（一）结账时间：5月23日至6月3日，分两期结账。第一期5月23日至5月28日结60%；第二期5月29日至6月3日结100%。

（二）奖励办法：按时完成全额任务的给予奖励

1、基础奖

对村的奖励：1.5万元以上的村奖800元；1--1.5万元的奖600元；5000--10000元的奖400元;5000元以下的奖200元。

对片的奖励：奖励2000元

2、名次奖

对村的奖励：1--10名各奖200元。

对片的奖励：第1、2、3、4名分别奖1000元、800元、600元、500元，在规定时间完成任务的其它工作片奖300元。

（二）奖励办法：按时完成全额任务的给予奖励、基础奖对村的奖励：万元以上的村奖元；万元的奖元；元的奖元元以下的奖元。对片的奖励：奖励元、名次奖对村的奖励：名各奖元。对片的奖励：第、、、名分别奖元、元、元、元，在规定时间完成任务的其它工作片奖元。

六、工作要求

各有关单位要加大保险政策宣传力度，切实做好“三农”保险各项基础工作。保险凭证要落实到户，确保凭证信息准确；要依法收取及时上缴农民应承担的保费；要切实保障投保农户的利益，及时查勘定损，及时逐一赔付到户；不得弄虚作假、虚报投保数量；承保和理赔情况要张榜公布，不得以各种名义虚报、冒领、骗取赔付资金；要按期将“三农”保险的承保、理赔等情况报中国人民财产保险股份有限公司。
