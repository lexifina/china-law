# 关于印发《黄潭镇村庄环境整治实施方案》的通知

各村民委员会：

现将《黄潭镇村庄环境整治实施方案》下发给你们，请认真遵照执行。

二〇一二年四月十六日

黄潭镇村庄环境整治实施方案

为了加强黄潭镇村庄环境整治，建立村庄保洁和垃圾处理长效机制，彻底根治“脏、乱、差”现象，建设社会主义新农村，特制订本实施方案。

一、指导思想

按照加快村庄环境整治的总体要求，以改善农民群众生活环境为着力点，切实解决村庄存在的脏乱问题，不断美化农村人居环境和生态环境，逐步提高广大农民文明素质和生态环境意识，建设靓丽和谐宜居家园。

二、工作目标

到2012年底，村庄环境整治任务全面完成，农村生活条件得到较大改善，基本形成村容洁净、生态良好、空气清新的农村环境。

三、主要任务

村庄环境整治的内容和主要工作：在2-3年内达到的基本要求和最低标准。主要任务是“一清两治三加强”，立足整治，注重长效，重点解决农村脏和乱两大问题。

1、清洁厕所。采取多项形式和综合措施，提高农村厕所的净化水平，消灭蚊蝇虫蛆，逐步改善入厕环境，消除卫生隐患，改善卫生环境。村委会供群众使用的公共厕所，要做到有专人负责，及时保洁，定期清理粪便。结合农村卫生厕所改造工程，达到水冲洁厕。逐步解决村内污水乱排乱倒问题，基本实现污水沟渠排放无溢流。

2、治理垃圾。全面清理村内、村外村庄连接处的积存垃圾、死角垃圾，清除河道、河沟、坑塘内多年积存的垃圾渣土，捡拾村庄周边的白色污染；对简易填埋场要及时覆土，进行绿化，有效降低暴露垃圾的污染；禁止在河道、坑塘倾倒、堆放垃圾，保护地下水源。有计划地建立村收集、镇运送的垃圾处理模式。

3、治理乱堆乱放。主要指清理村内柴草、杂物，清除道路两侧的私搭乱建。全面整理收拾主干道及胡同内乱堆乱放的柴草、杂物、砖瓦，清理房前屋后的堆物堆料，打扫庭院内的卫生，村内做到柴草码放整齐，院内做到物料堆放有序。拆除村内占道的私搭乱建，清理、修整有碍观瞻的坍塌破房、残墙断壁。逐步拆迁居民区内有污染的畜禽圈，妥善安置村外养殖，及时清除村内的粪堆、肥堆。结合村庄开展的植树建绿活动，以绿治脏，以绿挤乱，选择成长快、易管护、适宜当地的植物进行绿化，逐步提高村庄绿化美化水平。

4、加强管理，加强日常维护，加强保洁队伍建设。村内设立专门的环境管护人员，明确卫生清扫、垃圾转运、绿化管护、道路保洁的范围和责任，确保能扫得净、看得住、管理好；结合村规民约的宣传、制定和完善，建立健全村庄环境管理和维护制度。调动全体村民参与村庄整治，自觉遵守环境管理制度，自觉维护村庄环境，确保整治有成效、不反弹。

四、工作步骤

1.宣传发动（2012年4月1日至4月30日）。利用标语、横幅、广播、宣传车等各种形式，深入开展宣传活动，努力倡导文明、健康、卫生的生活方式，引导广大群众自觉整治环境，打造宜居村庄。

2.突击整治（2012年5月1日至8月31日）。以荷沙公路沿线整治为突破口，逐步向全镇各村延伸，以点带面，辐射推开。

3.检查验收（2012年9月1日至9月30日）。组织专班逐村验收。

4.整改落实（2012年10月1日至12月31日）。认真开展回头瞄，对不符合要求的整改。

五、有关要求

1.加强组织领导。镇成立村庄环境整治领导小组，党委副书记、镇长程红安同志为组长，党委委员、副镇长石雷钧同志为副组长，抽调党政办、社会事务办、城建、公安、环卫等相关部门人员集中办公，负责村庄环境整治实施计划制定、目标任务分解、协调指导和检查考核等工作。

2.严格考核标准。通过村庄环境整治，使每个村基本达到以下标准：

①干净。从村外到村内，从道路到庭院，基本达到干净卫生，无暴露垃圾、无污水溢流、无人畜混居、无卫生死角，公共厕所基本清洁卫生。

②整洁。村内无占道的私搭乱建、无残墙断壁，无乱贴乱挂、无乱堆乱放。

③路畅。入村主干道、入组道路平整、畅通，无坑洼、无积水、雨雪天不淤泥，便于群众出行和车辆出入。

④村绿。道路两侧因地制宜植树、种花，村边、路边、沟边、房前屋后绿化美化。

⑤建制。建立环卫长效管理维护机制，有专项的规章制度、有专门的组织领导、有专职保障队伍、有村民参与和监督制度，运行有效、管理到位、群众满意。

3.强化技术支持。相关职能部门要加强对村庄建设指导工作，组织专业技术人员深入村庄实地进行技术指导，大力开展科技、规划、技术下乡活动，切实改善村庄环境。

4.规范运转模式。镇成立环卫二所，负责公路沿线环境卫生，沿线基础设施建设纳入镇市政建设和管理范畴。镇环卫所负责出车，各村环卫工负责上车，村干部负责协调并做好沿线市政设施及工具的维修与管理。其他各村各负其责，做好本辖区村庄环境整治工作。
