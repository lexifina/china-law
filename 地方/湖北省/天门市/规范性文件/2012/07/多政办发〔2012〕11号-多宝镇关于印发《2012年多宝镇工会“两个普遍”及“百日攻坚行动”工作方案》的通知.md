# 多宝镇关于印发《2012年多宝镇工会“两个普遍”及“百日攻坚行动”工作方案》的通知

各企事业单位工会：

《2012年多宝镇工会“两个普遍”及“百日攻坚行动”工作方案》已经镇委、镇政府同意，现印发给你们，请结合实际认真贯彻落实。

多宝镇人民政府办公室

二0一二年七月三日

2012年多宝镇工会“两个普遍”及“百日攻坚行动”工作方案

一、指导思想

全面贯彻落实全总“两个普遍”工作方针，深入开展“广普查、深组建、全覆盖”行动，坚持“发展、巩固、规范、提高”的原则，不断提升建会率和职工入会率，着力提高建会质量，把广大职工切实组织到工会中来，以文化体育活动激活基层工会活力、愉悦职工身心健康，为维护职工合法权益、发挥工会积极效应进一步夯实组织基础。

二、工作目标

通过统一部署、上下联动、集中时间、整体推进的方式，开展建会“百日攻坚行动”，力争8月底完成省布企业法人建立工会组织、发展工会会员目标。全市企业工会实施“工会组织亮牌子、工会主席亮身份”的覆盖面达到60%以上。重点工作目标如下：

1、规模以上工业，限额以上贸易业、餐饮业、住宿业，资质以上建筑业、房地产开发企业法人（简称“三上”企业）工会组建率达到90%以上；

2、全镇企业法人工会组建率达到90%以上；

3、劳务派遣企业法人工会组建率达到90%以上，劳务派遣工入会率达到95%以上，其中，电力、电信、邮政、石油、石化、保险、金融等行业劳务派遣工入会率达到95%以上；

4、建立健全同级工会经费审查委员会和女职工委员会。

三、工作步骤

此次集中行动共分为调查核实、组织实施、总结提高三个阶段进行，具体为：

（一）调查核实阶段（5月中旬）。从实际出发，认真开展调查研究，进行逐家实地核实，做到企业经营情况清、职工人数清、企业地址清、未建会原因清和推进建会情况清并登记在册。同时，进一步做好全总数据库内企业工会组织信息的完善修正工作。

（二）组织实施阶段（5月中旬到6月底）。研究制定本地建会“百日攻坚行动”工作方案，明确工作目标和具体措施，有计划、有步骤地开展工作，针对重点工作目标开展建会“百日攻坚行动”。

（一）调查核实阶段（月中旬）。从实际出发，认真开展调查研究，进行逐家实地核实，做到企业经营情况清、职工人数清、企业地址清、未建会原因清和推进建会情况清并登记在册。同时，进一步做好全总数据库内企业工会组织信息的完善修正工作。（二）组织实施阶段（月中旬到月底）。研究制定本地建会“百日攻坚行动”工作方案，明确工作目标和具体措施，有计划、有步骤地开展工作，针对重点工作目标开展建会“百日攻坚行动”。

（三）总结提高阶段（8月中旬）。进一步查漏补缺，完善提高工会组织全覆盖工作。要认真总结经验，对建会“百日攻坚行动”工作情况进行自查自评，并对建会“百日攻坚行动”措施得力、成效显著的单位和个人给予表彰奖励。

四、工作要求

（一）加强组织领导，形成工作合力。镇成立以党群副书记彭江南为组长，组织委员隗旭鹏为副组长，工会专职主席李松柏和相关部门负责人组成的领导小组，切实推进工会组织全覆盖工作，并积极推动建立党工共建长效机制，把工会组建纳入基层党建工作的重要内容。经发办、劳动保障所等部门要积极配合，形成合力，按照各自职责，切实抓好工作落实。

（二）加强检查指导，确保工作进度。领导小组办公室要组织相关人员深入到相关企业，帮助指导各企业在开展工会组建全覆盖百日攻坚行动中遇到的困难和问题，提出解决问题的办法，督促工作进度，集中力量把重点对象普遍组织到工会组织中来。各单位主要负责人要高度重视，落实专人负责，明确工作职责，做到任务到人，责任到人，切实抓好工会组织全覆盖的基础工作，并建立健全规范的工会工作台帐。及时补充、完善和上报企业、工会组织基础数据。

（三）加强舆论宣传，营造良好氛围。充分利用各种媒体和手段向全社会进行广泛宣传，营造良好的建会环境。要重点加强对企业主的宣传教育，努力形成依法组建工会组织的意识，积极配合镇相关部门开展工会组建工作，确保按时完成任务。

（三）加强舆论宣传，营造良好氛围。充分利用各种媒体和手段向全社会进行广泛宣传，营造良好的建会环境。要重点加强对企业主的宣传教育，努力形成依法组建工会组织的意识，积极配合镇相关部门开展工会组建工作，确保按时完成任务。

（二）加强检查指导，确保工作进度。领导小组办公室要组织相关人员深入到相关企业，帮助指导各企业在开展工会组建全覆盖百日攻坚行动中遇到的困难和问题，提出解决问题的办法，督促工作进度，

（四）开展“双亮”活动，着力推动非公企业工会规范化建设。贯彻落实全总《关于在企业工会实施“工会组织亮牌子、工会主席亮身份”的意见》，所有企业工会，要在企业门面或工会办公地点悬挂与企业名称相对应的企业工会组织牌匾；企业工会主席、副主席要以佩戴胸卡、戴牌上岗、印发联系卡、设置办公桌牌等一种或多种形式亮出身份；工会办公地点、工会主席和副主席办公电话、手机号码等联系方式在企业宣传橱窗、厂务公开栏、会务公开栏、企业网站、职工食堂等一处或多处显眼位置公布。区域(行业)性基层工会联合会、联合基层工会、企业工会所属工会分会、工会小组以及其他工会专兼职工作人员采取适当方式进行“双亮”。
