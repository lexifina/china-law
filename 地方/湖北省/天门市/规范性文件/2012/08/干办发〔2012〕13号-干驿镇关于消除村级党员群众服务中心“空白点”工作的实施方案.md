# 干驿镇关于消除村级党员群众服务中心“空白点”工作的实施方案

各相关村、镇直有关单位：

为切实推进基层组织建设年工作，按照市委统一要求，全镇要集中三个月时间，彻底消除村级党员群众服务中心“空白点”，为了将此项工作落实到位，结合我镇实际，特制定本实施方案。

一、指导思想

以科学发展观为指导，以建设服务型党组织、发挥党组织作用、提升党组织形象为目标，以便民利民为宗旨，以党员群众满意为基本要求，通过整合资源、完善设施、改造升级，着力建设一批满足党员群众生产生活需要、适应科学发展要求，党务、村务、商务、服务、医务“五位一体”的村级党员群众服务中心，力争2012年11月底彻底消除全镇村级党员群众服务中心“空白点”。

二、项目建设内容

1、建设范围：油榨村、夹洲村、苏畈村、小河村、史岭村、禾呈村、陈张村、卢岭村。

2、建设方案：市委组织部统一设计3套图纸，由各村结合本村的实际情况召开村党支部会议、全体党员大会、群众代表会议对选址情况和建设图纸进行选择，经镇党委同意，报市委组织部备案。

3、项目报批：本次所有建设项目必须按照市委常委会会议确定的建设计划，经村党支部申请，镇党委研究同意后，制定建设方案，报市委组织部审批。

三、功能要求和建设标准

新建村级党员群众服务中心在内外功能设置上，必须按照省委组织部《2011年度湖北省党的基层组织建设考核评价项目》和《关于进一步做好党员群众服务中心建设、管理、使用工作的意见》要求，做到“九个有”：有一面国旗、有一面党旗、有一个广播、有一个党务村务公开栏、有一个党员阳光便民服务中心、有一个村民说事室、有一个党员电教室、有一套制度、有一套档案，其中村民说事室、党员电教室等可以统筹利用。村办公楼正面醒目处要预留空间悬挂“党员群众服务中心”字牌。

新建村级党员群众服务中心选址由镇党委政府会同项目所在村现场勘查、共同商定，要坚持方便群众办事的原则，必须建在村民集中居住点和交通便利的地方，要预留一定的活动空间，方便群众开展集体性活动。提倡有条件的村立足当前、着眼长远，适当扩大建筑面积，提高建设标准和配套规格，并一律设置党员群众服务大厅，实行柜台式服务，一站式服务。要尽可能把村卫生室、便民超市与活动场所同步规划建设，使其具有干部值班、党员学习、村民议事、综合服务等多项功能，其中办公室设置一般不超过2间。

四、实施步骤

（1）落实选址和确定筹资方向。7月底以前，各有建设计划的村要组织召开全体党员、群众代表大会，就本村党员群众服务中心建设工作展开讨论，落实党员群众服务中心建设方案，确定选址，明确筹资方向和方法。

（2）向镇党委递交建设申请，填报建设审批表。8月2日以前，按照全体党员、群众代表大会确定的建设方案，向镇党委递交建设党员群众服务中心建设工作的申请，并按照镇党委要求认真填写建设审批表。

（3）确定施工单位。按照市委“统一专业建筑队、统一建筑造价、统一招（议）标、统一施工”的要求，7月底以前，镇党委采取公开招标的方式确定施工队，确保施工队的水平质量和价格合理，做好建设工作的前期准备工作。

（4）实施建设。8月-10月底，由施工单位组织进场施工建设。施工单位要严格按照市委建设图纸及有关要求开展建设，确保建设标准不走样，建设质量不降低。同时，各有关村都要确定一名质量监理人员，加强对建设质量的监管。

（5）配套设施完善和检查验收。11月至月底，各有关村要开展党员群众服务中心的配套设施建设，确保镇党委、市委组织部检查验收合格，验收结果将与奖补资金直接挂钩。

五、组织领导和工作要求

1、成立工作专班。有建设任务的各村要在镇村级党员群众服务中心建设工作领导小组的指导下，组建以村党组织书记为第一责任人的工作专班，做好调查摸底、规划安排、资金筹集和检查督办等事宜，具体落实好建设任务。每个建设项目镇党委将指派一名党委班子成员和一名驻村机关干部全程跟踪督办，落实责任，一包到底。

2、严肃工作纪律。所有新建的村级党员群众服务中心一律实行项目管理。按照村级申报、镇党委研究、市委组织部审批的操作程序，严格项目审批管理。各相关单位要严格履行自身职责，为村级党员群众服务中心建设工作提供帮助，确保建设工作的顺利进行，确保工程质量和施工安全，对影响工程进度或造成重大质量问题、安全事故的，严肃追究相关人员的责任。

3、加强管理利用。村级党员群众服务中心建成后，要按照强化党务、规范村务、优化服务、拓展商务、协调事务“五务合一”的要求，抓好规范管理和综合使用。要实行村干部轮流值班制度，公开值班安排表，每天安排一名村干部值班；利用村级党员群众服务中心定期组织开展“三会一课”、民主评议党员等党内活动；举办各种实用技术、科技文化等知识的教育培训以及开展各种便民服务活动等，切实使党员群众服务中心成为村里开展办公议事、党员活动、教育培训、便民服务、文体娱乐等工作的综合阵地。

附：干驿镇村级党员群众服务包保责任一览表。

中共干驿镇委员会
