# 石河镇2012年秋冬农业开发实施方案

秋冬农业生产，一季关系全年。为了切实抓好2012年秋冬农业生产，全面完成今年各项农业目标任务，奠定明年农业发展的坚实基础，实现农村经济社会可持续发展，按照上级有关文件精神，结合我镇农业生产实际，特制定本实施方案。

一、指导思想

以科学发展观为指导，以市场需求为导向，以农业增产、农民持续增收为目的，以推广农业新品种、新技术、新模式为载体，以开发利用冬闲田为手段，以推进土地规模经营为着力点，抓好粮油高产创建，坚持把秋冬农业开发与资源开发相结合，与培育壮大优势产业相结合，加速畜牧、水产等特色产业的建设步伐。

二、目标任务

种植业：两稳一扩一压减。即稳定小麦、蔬菜种植面积，扩大油菜生产面积，压减冬闲田，力争冬闲田面积在上年基础上压缩30%。秋播计划总面积75524亩，其中油菜面积50000亩，实现总产8000吨；夏粮面积24500亩（其中小麦面积23500亩，马铃薯1000亩），实现总产10000吨；蔬菜面积1024亩，实现总产2000吨；种植莲藕3000亩，总产15000吨。秋冬播机械作业覆盖率提高10个百分点。

畜牧业：大力推进畜禽规模化标准示范场建设，加快发展猪禽生产，突破性发展草食畜禽，推行畜牧业循环经济模式，抢抓秋冬补栏、补笼，力争年底存栏生猪29100头、家禽130万只，肉鸭5万只，年出笼肉鸭10万只，出栏生猪3万头。

水产业：大力建设高标准精养渔池，大力推进泥鳅产业大镇建设。全镇拓展完成“三改一建”3000亩，推广稻鳅共生面积5000亩。

三、工作重点

1、优化区域布局，全面推进高产创建。在东虹、洪山、李咀、蔡岭、诸葛、吴刘、吴垸、花垸等村集中连片种植油菜1万亩，镇重点办好东虹与洪山、李咀与蔡岭两个千亩示范片；在东河、西河、石河、杨岭、姚岭、牌岭等村建立连片万亩高产小麦下水田种植示范片；在唐李、东河、吴刘、段场等镇郊村集中连片发展大棚蔬菜、马铃薯等作物。大力推广高效种植模式。按照区域布局和不同的耕作制度，秋冬播生产中重点推广小麦、油菜下水田种植，实行油—稻，麦—稻连作，油（麦）—棉种植共4万亩；蔬菜生产中重点推广洋葱—生姜—甜玉米，甜玉米—蔬菜，萝卜（白菜）—大豆—花菜（秋黄瓜），大棚早春—延秋菜等种植1000亩，在北汊湖一带发展水生蔬菜3000亩。

2、抓好冬闲田开发。一是积极引导农民按照“两稳一扩”的总体要求实施秋冬种，优先发展油菜、小麦等大宗作物，对不宜种植油、麦等作物的田块扩大绿肥种植面积或冬炕，努力压减冬闲田。二是积极推动土地季节性流转。镇以华丰农业专业合作社为龙头，季节性流转李咀、洪山、蔡岭、诸葛、张巷、石庙、孙冲、姚岭等村土地，发展油菜生产，扩大种植面积，并以此办好天石线开发冬闲田示范带，确保天石线公路两侧1000米示范带内没有冬闲田。

3、强化科技服务。一是全力搞好品种定向。油菜主推华油杂9号、华油杂62、中油杂12、油研10号等；小麦主推襄麦25、襄麦55、鄂麦596等品种，力争全镇秋冬播主导品种覆盖率达到90%以上。二是推进农机与农艺结合。积极组织农机专业化队伍投入秋冬播生产，加快机收、机整、机耕和机播进度，大力推广小麦机械冬播技术，示范油菜机播、机收技术，着力解决生产季节紧、劳动强度大、人工成本高的问题。力争全镇完成油菜机播8000亩、小麦机播1万亩，机械耕整覆盖率达到95%以上，秋冬播机械播种覆盖率达到35%以上。三是大力开展统防统治，积极推广油菜“一促四防”、小麦“一喷三防”、小麦药剂拌种等成熟技术。四是开展秋季农资打假保秋冬播活动。

4、推进畜牧业发展。一是全面开展标准化养殖场创建活动。实施规模化养殖场的粪污综合治理，全面推行粪（便）污（水）分离设施改造，变废为宝实施规模化养殖场粪污的综合利用。二是大力推广标准化养殖模式。继续推广适合中、小规模养殖户及家庭小规模养殖的标准化养殖模式，如生猪标准化“150”模式、“500”模式，力争各新建1个；发展蛋鸡“153”标准化养殖模式，力争新增3家。实施标准化生产，推广“六化”，即：畜禽良种化、养殖设施化、生产规范化、防疫制度化、粪污处理无害化和监管常态化，着力提升标准化生产水平。三是突出抓好肉鸭育肥示范场建设。以武汉德丰公司为主，加速蔡岭肉鸭养殖场建设，带动全镇家庭小规模肉鸭养殖，全面提升养殖效益。四是进一步完善市、乡、村三级防疫冷链体系建设，保证疫苗质量和效果。开展动物疫病秋防，做到免疫目标、防疫密度、出证、档案达到100%；加强动物疫病监测，提高动物疫病的监测水平和预警能力。

5、推进水产业发展。一是以打造水产强镇为重点，突出重点区域，连片开发改造，大力建设现代渔业养殖基地。镇计划招商开发北港湖1000亩、北汊湖1000亩，动员组织村组连片开挖改造鱼池1000亩。新开发规模化连片鱼池要纵横整齐排列，进排水系统、供电线路和交通道路布局合理，要求达到“六化”，即渔池标准化（池形整齐成方，池深3米以上，池坡硬化达标），道路网络化（道路硬化，花草成行，车辆能进能转），排灌分开化（进水、排水系统独立分开，排灌自如）设施机电化（增氧机、投饵机、抽水机“三机”配套），品种特色化（养殖名优品种，亩产一吨鱼，产值2万元），养殖健康化（无公害健康养殖，三项记录齐全）。二是以稻鳅共生为重点，加大泥鳅产业大镇建设力度，计划在杨岭、姚岭、石庙、芦岭等村建稻鳅共生基地5000亩。

四、保障措施

1、加强组织领导

为抓好今年秋冬农业生产，镇成立全镇秋冬农业开发工作领导小组，镇长黄仁杰同志任组长，镇委副书记彭会军、副镇长汪家祥任副组长，党政办、经济发展办、各包片挂点责任人、农技、畜牧中心、财政所等单位负责同志为成员。各村委会主任为第一责任人，搞好组织协调、督导检查工作。

2、搞好指导服务

一是通过建立秋冬农业生产示范样板，召开现场经验交流会等多种形式，树典型、促平衡，营造全镇抓秋冬农业生产的良好氛围。二是开展各类形式的技术培训，抓好种植、农技、畜牧、水产等先进实用新技术、新模式技术推广工作，努力提高秋冬农业生产的科技含量，实现增产增收。三是立足抗灾秋冬播，在种植季节可保前提下，农技中心及时提供技术支持，确保种植业可耕地全覆盖，力求种满种足，水产开发抢时保质量、高标准完成规划任务。

3、加强政策扶持。

（1）规模经营扶持政策，促进产业发展。一是规模经营扶持政策。对符合市产业发展重点，规模流转农民土地，规模种植（养殖）5年以上，每年面积2000亩以上，实行“统一耕整、统防统治、统一收获”达到“五有”标准（有阵地、有流转合同、有专业队伍、有机械设备、有规模的农民专业合作社，一次性奖励资金10万元。二是设施蔬菜走廊扶持政策。设施蔬菜走廊范围内，与龙头企业建立紧密生产合作关系的合作社，并作为龙头企业生产基地，连片新建钢构式塑料大棚50亩以上的，按每亩大棚2000元标准分户奖励。三是畜牧业扶持政策。开展粪污综合治理，对养殖污物深度处理后排放达标的示范场和建设病死畜禽无害化处理的示范场，万头以上的按每个给予40万元项目奖励，3000-5000头的按每个给予20万元项目奖励；对生猪样本调查点新建“150”模式，按每幢2万元标准奖励。 四是水产业扶持政策。对连片新开挖1000亩以上，并达到“六化”要求的现代渔业养殖基地进行扶持，按每亩1000元标准奖励。对连片500亩以上规模的稻鳅共生基地，按每亩200元的标准分户奖励；对连片3000亩以上规模的稻鳅共生基地，按每亩300元的标准分户奖励。

4、加强检查验收。

建立镇村分片包点责任制，将秋冬农业开发完成情况与年终村级干部实绩考核直接挂钩，各村要明确任务，强化责任，细化措施，确保秋冬农业开发任务圆满完成，镇政府将加大检查督导力度，定期通报工作进度和存在的问题，发现问题，及时解决，以此推动全镇秋冬农业开发顺利开展。
