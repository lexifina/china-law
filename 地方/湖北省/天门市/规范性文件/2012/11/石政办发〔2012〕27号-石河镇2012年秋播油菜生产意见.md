# 石河镇2012年秋播油菜生产意见

按照省市关于发挥农业优势资源，立足做大做强油菜产业，促进农业增效和农民增收的指示精神，结合我镇近几年油菜生产状况，提出2012年秋播油菜生产意见。

一、指导思想

以市场需求为导向，以农民增收为目标，优化布局，恢复扩大种植面积；依靠科技，主攻单产，提高品质，严格实施双低油菜保优栽植技术；降本增收，大力推广油菜轻简栽培技术。

二、主要目标

全镇油菜秋播面积5万亩，力争平均单产160公斤，总产8000吨以上，建立2个双低油菜千亩高产示范片，油菜机械直播面积8000亩以上。

三、主要技术措施

（一）大力推广油菜机械直播栽培技术，努力压减冬闲田，扩大油菜种植面积。油菜多功能播种机集开沟分厢、灭茬、除草、施肥、播种于一体，操作简便、工效高，可以解决当前油菜生产与农村劳动力缺乏的矛盾，尤其是在冬闲田较多的地区更是一项稳定和扩大油菜生产面积的有效技术措施，同时油菜机械化生产也是未来油菜生产发展的方向和需要。因此要通过推广油菜机械直播生产技术，实行农机与农艺的有机融合，努力压减与消灭冬闲田，扩大油菜生产面积。

（二）加大良种推广力度。配套高产栽植技术，提高生产，一是加大高产优质双低油菜品种的推广力度，对油菜生产大村、重点区域、地段实行统一供种，提高良种覆盖率；二是进一步落实良种与良法配套栽植技术。通过技术培训、示范样板、高产创建等综合措施，提高高产栽培技术入户到田率，提高单位面积产量，促进农民增产增收。

（三）提高合理密植水平，达到以密补肥、以密补迟、以密控草、以密适机、以密增产的效果。根据本地的气候特点，直播油菜最佳播期为9月下旬到10月上旬，最佳种植密度每亩2.5万株为标准，每提早15天或推迟15天，密度相应减少或增加0.5-1万株/亩，同时根据种植密度每增加或减少1万株/亩，相应可以减少或增加1个纯氮/亩的施用量（以16个纯氮/亩为标准），通过合理密植与施肥技术推广运用，实现高产栽培。移栽油菜最佳播种期9月5-15日，最佳移栽期10月5-15日种植密度6000-7000株/亩为标准。同时可以推广以播代育技术，至10月上旬起，可陆续开始提大苗、留小苗，分期分批移栽，本田最后留苗1万株即可。

（四）重点加强油菜病、虫、渍害的防治技术的推广应用，保障农民增产增收。影响油菜的主要病害是菌核病，在防治上应以农业防治和药剂防治相结合。农业防治：一是轮作换茬；二是深翻土地埋菌核减少传播；三是选用无病植株的种子；四是油菜田要窄厢、深沟，易排水滤渍；五是合理密植，配方施肥，促进油菜健壮生长，减轻病原菌侵染。药剂防治：在油菜初花期和盛花期亩用菌核净100克对水50公斤喷施两次、防治部位主要是植株的中下部。

油菜的主要害虫有蚜虫、菜青虫等，在出苗后开始为害，可用吡虫啉或氯氰菊酯之类药剂防治。

油菜对渍害较为敏感。高标准开好田间“三沟”是油菜抗渍的基础工作。一般沟深15-29cm，沟宽20-25 cm，做到沟沟相通，明水能排，暗水能滤。

油菜田杂草分单子叶和双子叶两种，防治药剂根据草相而定，单子叶杂草用5%的高效盖草灵60—80毫升，双子叶杂草用30%好实多50-60毫升兑水喷施。油菜除草剂不能盲目引进利用，要根据产品说明并在试验的基础上进行，否则会伤苗，或对下茬作物产生不良影响。药剂防治杂草时应在无风的情况下进行，不要让药液飘到其它作物上。

四、主要工作措施

（一）加强行政领导。树立粮油并重的思想，紧紧抓住立足开发冬闲田种油菜这个问题，实行镇村行政领导目标责任制管理，确保油菜种植面积的恢复扩大。

（二）深入开展优质油菜高产创建活动。组织好东虹村和洪山村、李咀村和蔡岭村千亩高产示范，以油菜机械直播技术推广为突破口重点消灭天—石线冬闲田，带动全镇秋播油菜生产。主要工作内容：一是做好统一供种，连片种植。二是做好高产创建的技术培训，让标准化生产技术为高产创建保驾护航。

（三）大力推广油菜生产新技术。一是积极示范推广适应机械化操作，含油量高、抗倒性强的油菜新品种和栽培技术模式，通过配套相应的栽植技术，推动油菜全程机械化生产。二是大力推广油菜轻简节本增效技术，推广油菜免耕直播或套播技术。

（四）实施激励机制。根据市秋播生产意见要求，对秋播措施过硬，油菜计划面积落实得好、相关技术到位率高的村组、镇政府将给予一定的奖励；镇政府将秋播油菜生产工作完成情况纳入村级经济工作结帐。
