# 市安办关于切实做好元旦春节期间安全生产工作的通知

各乡、镇人民政府，各办事处、农场，天门经济开发区，天门工业园，市政府各部门：

2013年元旦春节将至，为确保人民群众度过欢乐祥和的节日，维护我市安全生产的平稳态势，现就做好元旦春节期间安全生产有关工作通知如下：

一、提高认识，切实做好元旦、春节期间安全生产工作

元旦、春节期间，各种公共活动、商贸活动将更加频繁，交通运输更加繁忙，很多单位为了赶任务抢进度，往往加班加点，甚至超能力生产。该时段是安全生产事故的易发期、高发期，安全生产面临严峻考验。因此，各地、各部门要时刻从全局和战略的高度，充分认识做好安全生产工作的极端重要性，要以对人民生命财产安全高度负责的态度，切实增强做好安全生产工作的责任感和紧迫感，坚决克服麻痹松懈思想，进一步加强对安全生产工作的组织领导，落实企业安全生产的主体责任和各相关职能部门的监管责任，建立完善各项安全生产制度。要采取有效措施，加强重点行业领域事故隐患排查治理和监管力度，确保元旦、春节安全生产的稳定态势，为明年的工作开好头、起好步。

二、周密部署，认真开展安全生产大检查

各地、各部门要对元旦、春节期间的安全生产工作精心安排，周密部署，按照"属地管理"的原则，认真组织开展节日前后和节日期间的安全大检查。

检查内容主要包括如下方面：

1、道路交通：要进一步强化安全监管，加强路检路查，严厉打击违章驾驶、超速超载等违法行为，坚决取缔各类非法营运工具，确保道路安全形势稳定；制定应对极端天气交通安全措施，防范冬季大雾、降雪及路面结冰对交通安全的不利影响；进一步抓好客车、危险化学品运输车辆、校车的安全监管和车主、驾驶人的管理，从源头上落实事故预防措施。

2、水上交通：继续抓好渡口渡船防碰撞、防泄漏专项整治，加强乡镇船舶安全监管，坚决打击非法营运和小木船营运等违法行为。

3、公众聚集场所：各地及公安、消防等有关部门要重点加强对学校、车站、医院、商场、市场、歌舞厅、宾馆饭店、小旅社、浴室、网吧等人员密集场所的消防安全检查和整治，严肃查处锁闭、封堵或占用疏散通道、疏散楼梯、安全出口等违法行为，确保疏散通道、安全出口畅通，保证消防设施完好、有效；对不具备安全条件的各类人员密集场所要坚决停产停业整改；元旦、春节期间举办各类大型聚集活动，要按照"谁主办、谁负责"的原则，切实做好安全防范工作，防止群死群伤事故的发生。

4、建筑施工：重点监督检查施工现场的防范措施、施工方案和安全技术措施等制定和落实情况；检查施工现场的大型机械设备、脚手架工程等安全情况。

5、城镇燃气：主要检查天然气、液化气站点、管道、钢瓶的安全检测检验、隐患排查整改、安全措施落实情况。

6、危险化学品：主要检查危险化学品的生产、经营、使用和运输等各个环节是否严格执行有关规定；查验安全设施、设备的检测检验情况；检查安全评价报告中事故隐患整改措施的落实情况和危险化学品储存与包装的情况等。

7、烟花爆竹：主要检查批发公司和零售网点是否存在违法经营、违规储存的情况。

8、其他领域：食品药品监督部门要加强对食品、药品行业的监督检查；教育部门要加强校车、校园和周边环境的安全检查。督促学校与涉校车主签订安全责任书，明确安全责任，严禁使用安全状况达不到要求的车辆上路。督促学校加强安全教育，提高学生自我防护意识和能力；质监部门要加强对锅炉、电梯、起重机械、压力容器等特种设施设备的专项检查，对达不到安全条件的，要责令停产整顿；供电部门要加强电网安全生产检查，加强电网的统一调度，确保电网安全稳定运行；农业部门要加强农业机械安全检测检验工作，防止农机事故发生；气象部门要加强重点单位防雷防静电检查、检验工作。

三、强化监管，把各项安全生产工作落到实处

各地、各部门务必落实各项监管措施，切实承担起职责范围内的监管责任，决不允许出现丝毫的懈怠和疏漏。对麻木不仁、疏于管理、玩忽职守导致出现生产安全事故的，将严肃追究相关责任人的责任。要结合本地、本部门的实际，认真制定检查实施方案，做好节日期间的安全生产工作。各单位自查要做到认真彻底、不留死角，对检查中发现的安全隐患要立即采取有力措施，认真进行整改，及时消除安全隐患。对暂时整改不了又无法确保安全的，一律停产停业整顿。要切实做好事前的安全预防工作，把工作做细做实，确保节日期间不发生安全生产事故。

四、加强应急值守，确保信息畅通

在开展大检查和节日期间，要严格领导带班和干部值班制度，落实具体值班人员，明确职责，及时掌握安全生产动态，对各种突发事故必须严格执行事故报告制度，带班领导和值班人员要保持24小时信息渠道畅通。要加强应急预案管理，一旦发生事故，确保有效救援，减小事故损失，严防事态扩大。值班期间，各地、各部门要将本地本部门安全情况及时上报到市安办（电子信箱：tmajjzwxx@163.com）。
