# 黄潭镇关于加强农村重点项目建设管理的意见（试行）

各村（居）民委员会、镇直各单位：

为了更好地落实上级“一事一议”财政奖补的有关政策，集中财力加强农村重点项目建设，进一步增强农村发展后劲，促进全镇经济社会又好又快发展，根据市纪委、市综改办相关文件精神，结合我镇实际，现就加强农村重点项目建设管理提出如下意见：

一、充分认识实施农村重点项目建设的意义

农村重点项目是推动我镇经济社会发展的重要载体，要充分认识抓好农村重点项目建设工作的重要意义，牢固树立抓项目就是抓发展的意识，切实增强抓好农村重点项目建设的责任感和紧迫感，努力开创重点项目建设的新局面。

二、准确把握农村重点项目建设的主要内容

一是以新农村建设为重点，包括村庄环境整治、节能环保、植树造林、殡葬改革、“三清五改”等生态型、文化型、节能型项目；二是以改善农村基础设施为重点，包括水利、交通、农业开发等改善基础设施建设的项目。

三、精心组织农村重点项目建设的实施

1、强化责任，确保农村重点项目建设工程质量与进度

将全镇农村建设项目纳入重点项目管理，由重点项目建设管理办公室统一组织，从项目的立项、发包、开工、竣工验收以及资金拨付等全部由办公室组织实施，严格执行工程招标投标制、工程质量责任制、竣工验收制等各种制度，切实加强对工程全过程的监管，确保项目资金专款专用，努力把农村重点项目建设工程打造成阳光工程、示范工程。

2、加强项目管理，确保农村重点项目建设顺利实施

（1）关于村级全额自筹资金建设项目的管理

经村民委员会或村公益事业建设理事会议事决定并且全额自筹资金建设的项目，村委会（或村公益事业建设理事会）可以自主施工，但村委会必须将议事的相关资料和签定的施工合同报镇重点项目建设管理办公室备案，工程竣工后由重点项目建设管理办公室组织验收。

（2）关于中央、省、市、镇有资金奖补或投入的农村建设项目的管理

凡中央、省、市、镇有资金奖补或投入的农村建设项目，由镇重点项目建设管理办公室全面协调，负责做好立项申报、工程预算、招投（议）标、施工监督、竣工验收、奖补资金（或工程款）的拨付等工作。

3、加强沟通协调，确保农村重点项目建设全面完成

为确保重点项目有效推进，由重点项目建设管理办公室统一协调解决项目建设过程中的问题，切实加强对项目建设进度的跟踪，及时解决建设过程中遇到的困难，确保重点项目建设顺利完成。

四、加强对农村重点项目建设工作的领导

为确保农村重点项目建设顺利推进，镇委、镇政府决定成立重点项目建设管理领导小组，镇长程红安同志任组长，党委副书记杨永斌、程书鹏等同志任副组长，陈明星、孙刚、石雷钧、张翠、鲁军山、吴义斌、何汉军等同志为成员。领导小组下设办公室，办公室设在财政所，吴义斌同志兼任办公室主任，办公室人员从纪委、农办、通村公路办、民政、城建、土管、财政、水利、林业等部门抽调组成，具体负责重点项目建设的管理。

二〇一二年十一月八日
