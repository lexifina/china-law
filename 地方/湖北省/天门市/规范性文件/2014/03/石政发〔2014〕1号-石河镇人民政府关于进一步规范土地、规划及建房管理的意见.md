# 石河镇人民政府关于进一步规范土地、规划及建房管理的意见

依照《中华人民共和国土地管理法》、《中华人民共和国城乡规划法》、《湖北省城乡规划条例》，为了规范土地、规划及建房管理，遵循土地集约节约、高效利用，规划先行、先税后证的原则，促进我镇经济社会全面协调可持续发展。根据“石政发[2012]5号”文件的精神，经镇委镇政府集体研究制定进一步规范石河镇土地、规划及建房管理的意见。

一、强化规划管理

镇委、镇政府成立由镇党委书记任政委，镇长任主任，分管领导任副主任，城建、土管等职能部门的负责同志为成员的石河镇土地规划建房管理委员会（以下简称规委会），负责全镇的土地、规划及建房管理；各村党支部书记（村委会主任）、镇直单位一把手是第一责任人，负责本辖区的土地、规划及建房管理。

二、明确工作目标

镇规委会要加强全镇土地规划建房工作的领导和管理；各村各单位要增强土地规划建房管理的责任意识和法规意识。全镇所有建设建房用地必须严格符合规划，必须从严管理各类非农建设用地，必须严格实行规委会审批，必须彻底杜绝不按规划建设、未批先建、少批多建、以租代征、骑路建设、非法占用基本农田、擅自开发小产权房，以临时用地为名随意圈占土地等问题。保证全镇土地规划建房合法、有序进行。

三、规范土地建房程序

镇规委会对全镇土地占用、建房情况每月组织一次巡查。原则上每双月27、28日集体研究，集中审批一次。

（一）居民个人符合政策建房的办理程序：

1、备齐以下材料：

（1）本人提出申请；

（2）户主身份证明材料；

（3）村委会初审资料；

（4）村镇规划土地部门审核的资料；

（5）土地使用证明材料。

2、缴纳相关税费。

3、城建、土管部门初审。

4、镇规委会审批。

5、城建、土管部门办证。

（二）连片和整体开发的办理程序：

1、村、单位请示报告；

2、城建、土管部门初审；

3、镇规委会集体研究审批；

4、镇政府向市政府申请用地计划；

5、挂牌招拍；

6、缴纳相关税费；

7、完善相关资料；

8、城建、土管部门办理手续。

四、强化土地建房税费征收

按照先税后费、先费后证的工作流程，实行税费归口入专户。征收标准按石政发[2012]5号文件执行。同时，对农村私人建房严格执行一户一宅的用地政策，确需建房的由村委会按村域规划统筹安排，并报经镇规委会审核、上报国土、规划部门批准后，方可建设，新住宅建成后必须拆除原住宅，原宅基地由村集体依法收回。建房新占土地，村级征收土地补偿费，全镇实行分类定价，指导实施。村级所收费用一律入财政会计中心村级专户，严禁坐收坐支。

五、严明工作纪律

按照先规划后用地、先批后建的程序，实行建房用地经镇规委会集体审核的制度，村、单位无权拍卖、转让土地、处置土地。不按规定办事、擅自降低收费标准，收入不上账，坐收坐支等行为，一经查实，作如下处理：

（一）对收入不上账的冻结村级账户，责令限期补齐；对擅自降低收费标准的，按10—20%予以处罚；对坐收坐支，擅自未批先建的对村支部书记、镇管单位一把手诫勉谈话、停职检查，视情节立案调查处理，垂直单位报其主管部门处理。

（二）情节严重、阻挠执法，构成犯罪的当事人，由司法部门依法追究其刑事责任。

（三）对违规建筑当事人处以建筑工程造价一倍以下罚款。

（四）对违法建筑报请市国土、规划、公路等执法部门依法查封施工现场、强制拆除。

（五）违纪资金一律收缴入镇财政专户。

（六）对土地建房违法违规行为不制止，对土地建房违法违规问题隐瞒不报，压案不查，玩忽职守、徇私舞弊的，要追究相关责任人的领导责任。
