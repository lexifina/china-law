# 关于加强党风建设的通知

各党支部、支部，各村（居）民委员会、镇直各单位：

根据中央八项规定、省委“六条意见”、市委“六条禁令”，现就加强党风建设提出如下要求：

一、从2014年起“三公”经费支出要比2013年有明显下降；

二、大幅度减少非生产性开支，严禁用公款购买烟、酒贺年卡、明信片、年历等物品；严禁用公款送礼（慰问困难群众和走访成功人士除外）；严禁用公款吃喝、旅游和消费娱乐；严禁接受服务对象的吃喝、礼金、有价证券。凡被省、市、镇纪检、财政、审计部门清查发现问题的，一律由个人承担开支金额，并严格按上级精神追责。

三、各单位一把手不管公事、私事外出，必须履行请假手续，必须先报镇党政办备案，备案须注明在家主持全面工作同志的姓名、职务、手机号。各单位一把手不管在家还是外出，手机必须24小时保持畅通。市、镇通知的所有会议必须提前到会，不得迟到、早退、旷会，确有特殊情况需要请假的要提前一天履行请假手续，并报批准。

各单位要认真落实以上要求，切实以良好的党风带政风促民风。

2014年1月27日
