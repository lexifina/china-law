# 关于印发《小板镇2014年政策性“三农”保险工作实施方案》的通知

各村民委员会：

现将《小板镇2014年政策性“三农”保险工作实施方案》印发给你们，请认真组织实施。

中共小板镇委办公室　　 小板镇人民政府办公室

2014年5月19日

小板镇2014年政策性“三农”保险工作实施方案

为了切实做好今年水稻、能繁母猪、奶牛，“两属两户”农房、棉花、油菜保险工作，根据市政府有关文件精神，结合我镇实际，特制定本方案。

一、指导思想

深入贯彻落实科学发展观，以促进我镇农村经济的持续发展和农民收入的稳步增长为目的，切实推进政策性“三农”保险工作，建立健全农业保障体系，促进城乡协调发展，构建农村防灾减灾机制，维护农业生产环节稳定，保障农业和农民收益。

二、组织领导

成立小板镇2014年政策性“三农”保险工作领导小组，切实加强我镇政策性“三农”保险工作的组织、指挥、协调和督导。

组 长：黄祥斌

副组长: 鲁鹏飞 江会军 钟艳平 杨永林

成 员: 吴明洋 张代中 代圣祖 汪新洲 刘 潇

于金平 陈志勇 张艾成 王 伟

办公室设在镇农业办公室，吴明洋同志兼办公室主任

三、实施内容

（一）水稻保险。保险金额为每亩200元，农户每亩承担保费3.5元。

（二）棉花保险。保险金额为每亩400元，农户每亩承担保费7元。

（三）能繁母猪保险。保险金额为每头1000元，农户每头承担12元。

（四）“两属两户”农户保险。保险金额为每户3000元，每户保费9元。

（五）奶牛保险。保险金额为每头6000元，养殖户承担保费72元。

（六）油菜保险。按省政府出台的相关政策组织实施。

四、结账办法

在2014年5月30日以前完成水稻、棉花保险缴费任务的村和片将给予一定的工作经费（明细表附后）。

五、工作步骤

（一）宣传发动阶段（5月上旬）

各片各村根据实际情况，充分利用电视、广播、报纸、网络等媒体，大力宣传开展政策性“三农”保险的重要意义、方法、步骤及相关政策，让党和政府的惠农政策家喻户晓，人人皆知，使广大农民真正了解政策性“三农”保险的重要作用，增强保险和风险防范意识，提高参与“三农”保险的自觉性。

（二）水稻、棉花保险信息收集阶段（5月中旬）

各片各村安排人力物力，开展信息收集工作，确保农户姓名、身份证号、投保面积、联系方式、“一卡通”账户或其他有效账户、开户银行等承保信息准确、真实、完整。

（三）水稻、棉花保费收取阶段（5月下旬）

各片各村按保费方案，依法收取农户应承担的保费。

（四）水稻、棉花凭证发放阶段（6月上旬）

各村将凭证及时无误地送到每个农户手中，确保凭证到户率达到100%，各村在确保依法合规的前提下，对农户收费、凭证发放和信息收集工作可以同步进行。

（五）其他险种的实施（下半年）

能繁母猪、奶牛，“两属两户”农户保险到期后按时续保。

六、工作要求

(一)“三农”保险涉及面广，操作复杂，耗费时间长，各片各村要早谋划，早安排，早行动。要加大保险政策宣传力度，切实做好“三农”保险各项基础工作。要及时将承保和赔款到户情况，在村组以公告方式告知，公示率应达到100%。镇政府将对公示情况不定期进行检查，并适时通报。

（二）设立各村政策性“三农”保险办公室，明确专（兼）职人员和协保员。

（三）建立“三农”保险工作联席会议制度。联席会议领导小组及成员单位负责组织协调全镇政策性“三农”保险工作；宣传发动指导相关部门做好政策性“三农”保险工作；督促政策性“三农”保险工作农户自缴保费的收缴；检查各地政策性“三农”保险工作的情况；督促做好政策性“三农”保险理赔工作的落实。
