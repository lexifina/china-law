# 汪场镇人民政府办公室关于成立汪场镇食品安全领导小组的通知

各村（居）民委员会、镇直各单位：

经研究，镇政府决定成立汪场镇食品安全领导小组，现将组成人员通知如下：

组  长：钟儒彪  镇委副书记、镇长

副组长：敖亚军  党委委员、副镇长

陈春平  党委委员、副镇长

成  员：黄保国  经济发展办主任

杨慧源  综治办副主任

樊  杰  纪委副书记

黄建涛  食品药品监督管理所所长

梅少平  财管所所长

曾玉兵  派出所所长

李向东  工商所所长

石中顺  中心卫生院院长

岳宁汉  中心学校校长

周义荣  村镇建设服务中心主任

镇食品安全领导小组下设办公室，办公室设在食品药品监督管理所，黄建涛同志兼任办公室主任。

2014年7月9日
