# 关于印发《镇机关干部“岗位在村、重在服务、责在连心”工作机制的实施办法》的通知

各党总支、支部，各村（居）民委员会，全体机关干部：

《镇机关干部“岗位在村、重在服务、责在连心”工作机制的实施办法》已经镇委、镇政府研究同意，现印发给你们，请认真贯彻执行。

中共麻洋镇委办公室麻洋镇人民政府办公室

2014年5月20日

镇机关干部“岗位在村、重在服务、责在连心”

工作机制的实施办法

为贯彻落实《关于建立乡镇（街道）干部“岗位在村（社区）、重在服务、责在连心”工作机制的意见》（鄂办发[2013]34号）文件精神，推进全镇机关干部下移工作重心、转变工作作风、改进工作方式、提升服务水平、密切联系群众，结合党的群众路线教育实践活动，制定本实施办法。

一、总体要求

镇机关干部“岗位在村、重在服务、责在连心” 工作机制，是着力解决镇机关干部“身在基层下不了基层”、“面对群众不了解群众”等突出问题，夯实党的执政基础的必然要求；是引导镇机关干部深入群众、了解掌握实情，推进各项工作落实的有力措施；是与基层接地气，转变干部作风，增进与群众感情的客观需要；是回应群众迫切期盼、解决矛盾纠纷和破解发展难题的有效途径。我们要按照“全员参与、真情服务、上下联动、注重实效”的总要求，切实转变工作作风，密切党群干群关系，提高工作办事效率，推进各项工作全面进步。

二、职责任务

机关干部挂村工作重点履行指导、监督、服务职责，主要承担以下任务：

1、确保上情下达，当好政策法规“宣传员”。通过进村入户，及时宣传党的路线、方针、政策及有关法律法规，传达镇委、镇政府重大决策和重要会议精神，引导群众增强发展意识、民主意识和法制观念。

2、深入摸清底数，当好社情民意“调研员”。以上门走访为主要方式，加强与挂点村干部群众的联系，全面掌握挂点村经济社会发展情况、群众生产生活、基层组织建设等方面的情况，收集群众的意见或建议，及时向党委、政府报告。

3、推动科学发展，当好富民强村“参谋员”。要结合挂点村实际，科学拟定挂点村年度工作计划，并上报镇党委、政府审批备案；指导村“两委”理清发展思路，制定发展规划，积极推进村庄环境整治，改善群众生产生活条件，发展壮大村级集体经济。

4、真情服务群众，当好民生保障“服务员”。经常直接联系群众，真情服务群众，帮助排忧解难，为群众提供政策咨询、农合农保、民政计生及市场、技术、信息、就业等服务；及时受理群众要求和委托办理事项，结对帮扶1-2户特殊困难家庭，每年为群众办1-2件实事，以实绩取信于民。

5、维护和谐稳定，当好矛盾纠纷“调解员”。协助建立健全矛盾纠纷排查和群众利益诉求表达机制，做好基层矛盾纠纷排查、调处、化解工作，依法依规解决群众现实困难、合理诉求，协助应对处置各类突发事件，努力将矛盾问题化解在基层。

6、加强组织建设，当好基层党建“指导员”。指导挂点村扎实开展党的群众路线教育实践活动，督促村党员干部履行好工作职责，推进村级党员群众服务活动中心建设标准化、管理规范化、活动经常化，加强服务型基层党组织建设工作，强化挂点村“两委”班子建设和后备干部培养；参加村周碰头会、月例会以及各类重大会议，督促依法依规开展民主议事、民主理财和“三资”管理，实行党务、村务、财务三公开，并指导做好各类资料的收集整理，及时上报信息，为党委决策提供有效依据。

7、推进各项工作，当好落实工作的“督导员”。经常性督办计划生育、农业生产、清洁家园、信访维稳等工作，抓好中心工作的推进落实，按规定时限高质量、高效率完成党委、政府布置的各项工作任务。

三、工作要求

1、工作时间。挂村干部每周下村工作时间不少于2天，其中，每周四为集中下村工作日，如遇村发生重大突发事件应迅即报告，并24小时驻村处置。

2、工作职责。遇集中下村日或推进重点工作时，挂村机关干部由管片领导统一调度，统一安排部署工作任务，无特殊情况，分管领导不得调动挂村干部或布置其他工作占用集中下村日，确保下村工作有效开展。其他下村时间由挂村干部结合工作情况自行安排。挂村干部要认真填写《挂村工作内容及重大事项报告登记表》，每月底由管片领导、村支部书记签字后，交镇党委组织办公室汇总，报镇主要领导阅处并存入干部实绩档案。

3、工作纪律。按年初机关干部分工挂村安排，机关干部挂村一定一年，工作期限内，不得挂名不到岗，不得擅自改换挂点村，挂村干部须在村显目位置公开挂村干部个人基本信息，包括姓名、职务、电话等内容，自觉接受群众监督；挂村期间应严格遵守中央八项规定、省委“六条”意见和市委“六条禁令”，不得增加村级负担；要注重形象，不得参与有损党员干部形象的各类活动。镇党政办、纪委、组织办将对挂村情况进行定期不定期的检查督办、跟踪问效，实时掌握工作动态，及时发现查处问题，并将检查结果作为机关干部实绩考核结账依据。

四、工作考核

挂村工作考核由挂村平时检查通报、挂村干部年度述职述评、群众满意度测评和党委总评四部分组成。

1、挂村干部一年内三次被通报批评的，取消其年度评先资格。

2、挂村干部年度述职述评要与年初报镇党委审定后的挂村年度工作计划相结合，并与挂点村支部书记述职述评同步进行。

3、群众满意度测评由镇党委组成专班，在挂点村随机抽取20户群众进行测评。

4、由管片领导对挂村干部一年来的挂村情况进行评定打分。

对挂村工作成绩突出、表现出色、考核优秀的给予评先评优、表彰鼓励；对工作不力，作风不实，群众反映差的实行诫勉谈话，限期整改，必要时作出相应处理。
