# 石河镇2014年秋冬播生产实施方案

为了切实抓好我镇今年秋冬播生产，夯实农业基础，促进农业增产、农民增收目标的实现，按照《天门市2014年秋冬播生产实施方案》有关文件精神，结合我镇实际，制定如下实施方案

一、指导思想

以粮食生产稳定发展、农民收入持续较快增长为目标，进一步优化区域布局，坚持扩粮稳油、优化结构、强化手段、创新机制，大力推进科技秋播、机械秋播、抗灾秋播，深入开展高产创建，集成组装推广适用技术，努力促进农业增长方式转变，促进农业增产、农民增收。

二、任务目标

以“扩大粮食种植面积，稳定油菜和蔬菜面积，提高单产增总产，优化结构增效益，普及良种提品质，降低成本促增收”为目标任务。今年全镇秋冬播计划面积71418亩。其中：小麦21106亩，实现总产6000吨；马铃薯1000亩，实现总产2000吨；油菜48288亩，实现总产7200吨；蔬菜1024亩。主要作物单产比上年提高3%以上。实现优质品种全覆盖，小麦、油菜播种机械化作业全覆盖。

三、重点工作

（一）稳定粮油生产，加大冬闲田开发力度。积极推广小麦、油菜下水田种植，努力压减或消灭冬闲田。全力做好土地季节性流转工作，支持龙头企业、专业合作社、家庭农场和种植大户参与冬闲田资源开发利用，力争种满种足，扩大小麦种植面积，积极发展马铃薯生产，稳定蔬菜面积，巩固双低优质油菜成果，确保我镇粮油大镇地位。

（二）实施板块基地高产创建，加大区域板块布局力度。要充分发挥市场、技术、资源优势，积极打造区域集中、特色鲜明、规模经营的优势农产品产业带，因地制宜布局秋冬播作物。在东虹、洪山、李咀、蔡岭、诸葛、吴刘、吴垸等村集中连片种植油菜1万亩；在东河、杨岭、姚岭、华丰合作社、牌岭、石庙、唐店、刘方岭等村建立连片万亩高产小麦下水田种植示范片；在华丰合作社建立千亩油—稻—稻种植模式示范片；在唐李、东河、吴刘、段场等集镇近郊村集中连片发展大棚蔬菜、马龄薯等作物。

（三）加大科技秋播力度。一是着力推广主导品种。油菜主导华油杂62、华油杂13号、华油杂12、禾盛油555、中油杂7819、华双5号、浙油28；小麦主导襄麦25、鄂麦596、襄麦55、郑麦9023；马铃薯主导费乌瑞它、中薯3号等品种。力争全镇秋冬播主导品种覆盖率达到95%以上。二是组装配套集成技术。大力推广主导品种+机械直播+化学除草+配方施肥+绿色防控等配套技术，切实抓好小麦药剂拌种、力争实现小麦测土配方施肥、“一喷三防”技术全覆盖。三是提高整地和播种质量。大力推广机耕机整机播技术，提高耕种质量，做到适期、适墒、适量“三适”播种。油菜直播亩播种量0.3公斤左右，确保收获株数达到每亩2-3万株，力争10月20日前播完。小麦亩播种量10公斤左右，基本苗15万左右，力争11月7日立冬前播完；坚持早播稀、迟播密，肥田稀，瘦田密的原则。

（四）加大机械秋播力度。认真组织调配机具，抓好作业供需、天气交通等信息引导，扎实推进农机农艺融合，深入发展农机社会化服务，大力推广应用小麦全程机械化生产，加快油菜机播技术的应用。通过推广机械直播，达到以机省工、以机促密、以机抗灾、以机扩面、以机增效的目的。力争今年小麦、油菜机播面积较上年提高10%以上。

（五）加大抗灾秋播力度。秋冬播期间非旱即雨，极端灾害性天气多，要牢固树立抗灾秋播意识，未雨绸缪，争取秋播工作主动。一是“抢、早、巧”三结合，确保适期播种。针对今年受厄尔尼诺现象影响，在田作物生育期延长的特点，中稻要及时抢收，晚稻看田排水，适时抢收，做到快腾茬、快耕整、快播种。棉花对10月15日前单株平均不足5个桃的田块，及时拔杆腾茬满幅种植，单株成桃8个以上的田块采取套播套栽，确保适期播种。二是“种、墒、机”三协调，确保一播全苗。选用高产优质抗逆性强的品种，适时抢墒、人工造墒播种，提高机播质量，确保一播全苗。三是“防、控、管”三配套，确保稳长健长。落实种子包衣、药剂拌种、土壤处理等技术，加大小麦条锈病、赤霉病、马铃薯晚疫病、油菜菌核病等秋冬播作物病虫害和田间杂草的防控力度，开好“三沟”，清理沟厢，根据苗情、墒情适时化学调控、增施肥料，为作物的生长创造良好环境条件，确保稳长健长，壮苗越冬。

四、保障措施

（一）加强组织领导。镇成立秋冬播生产领导小组，镇委副书记沈骏宇同志任组长，党政办、经济发展办、各片负责人、农技中心负责同志为成员，各村委会主任为本村秋冬播生产第一责任人。多方配合，搞好组织协调、督导落实工作。

（二）加强宣传引导。近期少雨偏旱，极有利于我地小麦、油菜下水田耕种。要大力宣传国家和地方政府有关强农惠民政策，特别是小麦的最低收购价和油菜籽临时收储政策；大力宣传秋冬播生产主导品种、主推技术、主要作法、成功经验、先进典型和实施效果；大力宣传秋冬播生产在稳定促进全年农业生产发展中的重要作用和特殊意义，引导农民抢抓时机与季节，种满种足，高标准、高质量完成今年秋冬播生产任务。

（三）加强服务指导。镇农技中心为今年秋冬播生产技术指导组。农技部门要充分发挥秋冬播生产主力军作用，大力开展农业技术培训，把关键技术指导到户、技术要领传授到人、技术措施落实到田。农机部门要提早培训机手，提早检修机具，提早调配机械。推进农机农艺结合，充分发挥农业机械的作用，提高秋冬播作物整地和播种质量，努力为秋冬生产顺利推进做好服务。
