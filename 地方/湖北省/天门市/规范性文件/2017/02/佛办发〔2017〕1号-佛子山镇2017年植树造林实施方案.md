# 佛子山镇2017年植树造林实施方案

为了切实抓好我镇2017年植树造林工作，进一步扩大和巩固"绿满佛子山行动"成果，对照《湖北省绿色示范乡村建设标准（试行）》和市委办、市政府办《关于天门市2017年植树造林方案》（天政办发〔2017〕2号）文件精神，结合我镇实际，制定本实施方案。

一、指导思想

以党的十八届六中全会精神为指导，继续深化"绿满佛子山行动"，按照规划先行、突出重点、扩充总量、提高质量、政府主导、全民参与的原则，着力推进国土绿化进程，加强林业灾后恢复重建，培育保护森林资源，全面提高林业的综合效益，促进林业生产可持续发展。

二、工作目标

2017年全镇造林绿化总面积为2316亩。其中：完成工程造林1406亩，全民义务植树 910亩。新建绿色示范村2 个。

三、 工作任务

（一）抓好林业重点工程项目建设。

2017年，结合我镇实际情况，通过更新改造和部分荒地造林，完成1406亩工程造林建设任务，确保成活率达到90%以上。

（二）抓好通道生态景观建设。

2017年，我镇将进一步完善九蒋公路的绿化建设，九蒋公路沿线（代河、雷畈、王岭、南巷、坟禁、陈场）要实行高标准绿化，打造绿色长廊，里程达到10千米，绿化面积300亩。"村村通"公路要路修到哪里，树就栽到哪里，宜绿化地段实现全部绿化。

（三）抓好绿化示范乡村建设。

2016年我镇成功申报成为"森林城镇"，2017年将全面开展森林村庄创建活动，把村庄绿化美化和"精准扶贫"等工作紧密结合起来，统一规划，分类指导，稳步推进。以沟、路、渠、堤为框架，高标准、高质量营造和完善农田林网建设，抓好农户房前屋后绿化，大力发展庭院经济，建成绿色示范村2个。

（四）抓好全民义务植树活动。

大力开展 "园林单位"、"绿色学校"、"千村绿"创建活动，营造"廉政林"、"青年林"、"三八林"、"园丁林"等绿化示范工程，有效推动全民义务植树活动的开展，加速国土绿化步伐。2017年完成义务植树面积910亩。

（五）抓好林业灾后恢复重建。

深化和巩固"绿满佛子山"成果，切实抓好现在林木的管理。对因2016年水灾损毁的苗圃地、新造林地、未成林地及近三年来造林地保存率低于50%的造林地块，开展补植补造、病虫害防治、除草追肥等工作，对损毁的林业道路、房屋等基础设施，进行修复或重建。

四、工作措施

1.加强组织领导，强化领导责任。镇委、镇政府成立推进绿满天门行动工作领导小组，朱文祥任第一组长；谭纪刚任组长；李次红、方时雨、汪卫平、陈君兰、谈选平、蒋凡任副组长；谌颖、胡会平、许广平、杨义平、吴燕容为成员。下设领导小组办公室，办公室设在经济发展办。各村要成立相应机构，明确工作任务，切实履行职责，形成主要领导亲自抓，分管领导负责抓，工作专班具体抓，一级抓一级，层层抓落实的工作局面，各村要明确支部书记为第一责任人，建立工作目标责任制，并签订责任状，将"佛子山镇2017年植树造林"工作作为村干部实绩考核的重要内容。

2.加大宣传力度，营造舆论氛围。各村要采取各种形式，广泛宣传、层层动员，统一思想，树身边典型，作正面引导，充分调动干部群众参与造林绿化的积极性，通过捐资、改建、认养等多种形式，开展造林绿化，提高公民义务植树尽责率，形成全社会植绿、护绿、爱绿、兴绿的良好氛围。

3.加大资金投入，实行以奖代补。建立市场化投入为主体，全社会广泛参与的多渠道、多层次、多形式投入机制，鼓励和引导农民投资投劳，自筹解决部分建设资金，建设一批绿色示范基地。对于造林补贴试点项目，补贴标准为200元/亩，完成造林任务后，经市林业局依据造林作业设计、造林补贴合同、造林检查验收等规定进行造林成活率检查验收，达到合同规定要求的，通过一卡通一次性地将补贴资金拨付给造林业主。

4.加强督导检查，严格考核结帐。镇政府年终对植树造林工作进行考核，对达到绿化建设标准并通过验收的给予表彰和奖励，对没有完成目标任务的，给予通报批评，并督促整改到位，对不能如期实现绿化达标目标的，要对村主要负责人进行约谈问责。
