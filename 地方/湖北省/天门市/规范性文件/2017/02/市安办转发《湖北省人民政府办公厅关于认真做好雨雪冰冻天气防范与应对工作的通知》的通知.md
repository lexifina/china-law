# 市安办转发《湖北省人民政府办公厅关于认真做好雨雪冰冻天气防范与应对工作的通知》的通知

各乡镇人民政府，各办事处、农场，天门高新园，天门工业园，市安委会各成员单位：

根据最新气象资料分析，受北方强冷空气影响，预计2月20-22日，我省自北向南将有明显寒潮天气发生。鉴于目前春运还未结束，此次冷空气风力大，降温剧烈，将会对人民群众生产生活带来较大影响。省委省政府领导高度重视，迅速制定下发了有关防范与应对的通知；市委市政府领导也迅速就应对与防范工作进行了批示。为确保人民群众生命财产安全，确保正常生产生活秩序，现将《湖北省人民政府办公厅关于认真做好雨雪冰冻天气防范与应对工作的通知》转发给你们，请各地各单位结合工作实际，迅速研究和落实各项应对措施，加强应急准备，确保社会稳定。
