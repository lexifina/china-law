# 天门市道路运输管理局2017年度道路货物运输车辆审验公告

为规范道路货物运输市场经营秩序，保障道路货物运输安全，根据《中华人民共和国道路运输条例》、《湖北省道路运输条例》、交通运输部《道路货物运输及站场管理规定》、《道路运输管理工作规范》等有关规定，天门市道路运输管理局将组织开展2017年度全市货运车辆审验工作，现将有关情况公告如下：

一、审验范围：凡经天门市道路运输管理局行政许可的道路货物运输车辆均属于此次年度审验范围。包括：货运汽车（含危险品运输车辆）、简易车。

二、 审验时间： 2017年4月5日至2017年7月25日。

三、审验地点：天门市道路运输管理局运政服务大厅3号窗口（天门市南洋大道31号）。

四、审验内容及所需资料：

（一）普通货物运输车辆（普通货运汽车、简易车）

1.审验内容

（1）车辆技术状况；

（2）车辆年检状况

（3）车辆技术档案；

（4）车辆定期维护和检测情况；

（5）车辆结构及尺寸变动情况；

（6）违规违章记录；

（7）从业人员持证情况；

（8）总质量达12吨的重型货运车辆、半挂牵引车安装使用具有行驶记录功能的卫星定位装置，并能在全国道路货运车辆公共监管与服务平台上查询车辆基础信息和实时卫星定位信息；

（9）其他按规定需审验的内容。

2.审验所需资料

（1）《天门市2017年度道路货运车辆审验表》；

（2）《道路运输证》原件及复印件；

（3）车辆《行驶证》原件及复印件；

（4）车主身份证原件及复印件；

（5）驾驶员从业资格证原件及复印件；

（6）车辆检测报告单；

（7）维护签章记录卡；

（8）重型货运车辆、半挂牵引车卫星定位装置的安装证明原件。

（二）危险品运输车辆

1.年度审验内容

（1）车辆技术状况，罐式车辆应提供罐体检验合格证；

（2）车辆技术档案，罐式车辆应标明罐体容积；

（3）车辆定期维护和检测情况；

（4）车辆结构及尺寸变动情况；

（5）违规违章情况；

（6）专用车辆投保危险货物承运人责任险情况；

（7）罐式专用车辆罐体质量检验情况；

（8）必需的应急处理器材和安全防护设施设备的配备情况；

（9）专用车辆的标志灯、标志牌安装情况；

（10）卫星定位装置安装使用情况；

（11）从业人员持证情况；

（12）经营业户信誉考核情况；

（13）其他按规定需审验的内容。

2.审验所需资料

（1）《天门市2017年度道路危货运输车辆审验表》；

（2）《汽车综合性能检测报告》（评定为一级车）；

（3）承运人责任险保险单原件及复印件一份；

（4）《道路运输证》原件及复印件；

（5）车辆行驶证、车辆登记证原件及复印件；

（6）危货驾驶员及押运员从业资格证原件及复印件；

（7）卫星定位装置安装证明原件；

（8）罐体检验合格证原件及复印件；

（9）《天门市2016年度道路运输经营业户情况及信誉考核表》；

（10）维护签章记录卡。

五、组织方式：经营业户将所需资料报市运管局道路货物运输车辆审验工作专班，并由审验工作专班负责做好初审工作，统一到天门市道路运输管理局运政服务大厅办理。

望各经营业户看到此公告后相互转告，在规定时间内完成年度审验工作。年度审验工作结束后，天门市道路运输管理局将集中力量对全市道路货运车辆进行检查，对未进行年度审验的货运车辆，将依据相关法律、法规予以查处。
