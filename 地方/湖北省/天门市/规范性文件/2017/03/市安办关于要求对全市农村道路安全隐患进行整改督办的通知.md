# 市安办关于要求对全市农村道路安全隐患进行整改督办的通知

各乡镇人民政府，各办事处、农场，天门高新园，天门工业园，市安委会有关成员单位：

2016年我市组织开展了农村道路安全隐患排查，共排查出农村道路隐患1618处。为切实将隐患整改到位，始终做到防微杜渐、防患未然，市安办将排查出的隐患按属地进行了责任划分。希望各地严格落实安全生产主体责任，迅速采取措施，及时消除隐患。现将有关事项通知如下：

一、各地、各部门务必高度重视，站在讲政治的高度，对辖区内排查出的道路隐患进行整改治理。一把手要亲自过问，分管领导要具体部署、具体安排，专班负责落实。

二、各地、各部门对道路安全隐患要登记造册，制定整改计划、整改措施。要落实责任，落实资金，明确落实整改治理责任部门、责任单位和责任人，实行责任部门、责任单位和责任人分包点段，确保在2017年11月30日前按要求整改治理完毕。

三、各地治理整改已排查出的道路隐患的同时，要继续组织力量不间断的进行道路隐患排查，做到随时排查，随时治理。

各地、各部门道路安全隐患整治工作完成情况于2017年11月30日前报市安委会办公室，市安委会办公室将适时组织督查，并将督查情况纳入年终责任目标考核中。
