# 石家河镇2017年植树造林实施方案

为了进一步扩大和巩固"绿满天门"行动成果 ，切实抓好我镇2017年植树造林工作。根据天政办发【2017】2号文件精神，结合我镇实际，特制定本实施方案。

一、指导思想

以党的十八届六中全会精神为指导，继续深化"绿满天门"行动，建设市级林业生态镇，按照规划先行、突出重点、扩充总量、提高质量、政府主导、全民参与的原则，着力推进绿化进程，加强林业灾后重建，培育保护森林资源，全面提高林业的综合效益，促进林业可持续发展。

二、工作目标

2017年全镇造林绿化总面积为1140亩。其中完成工程造林任务430亩，全民义务植树730亩，新增绿色示范村6个。

三、工作任务

（一）抓好2017市布我镇造林任务，市布1140亩，其中工程造林470亩，义务植树730亩。

（二）抓好通道生态景观建设，实行属地负责，每个行政村高标准建设一条示范通道，进一步完善重点大道的绿化建设，抓好石段、石钱公路补植，石佛路新栽。着重抓好石家河-夏新、张巷-诸葛、胡垱村、董巷村通村公路绿化，实行绿色通道全覆盖。

（三）抓好绿色示范乡村建设。全镇新建6个生态示范村，力争村庄绿化率达到35%，所有农户庭院绿化，每个自然村落房前屋后栽植果树达15株以上，分散屋居住和20株以上。

（四）抓好全民义务植树。以全民植树活动为形式，大力开展"园林单位"、"绿色学校"、"万户绿"创建活动，营造"廉政林"、"青年林"、"三八林"、"学生林"等示范工程。

（五）抓好林业灾后恢复重建。对去年因灾损毁的林木抓紧补植改种，做好镇重点苗木基地的恢复工作。

四、实施步骤

（一）任务落实阶段（2017年1月20日以前），各村各地要全面做好植树造林的各项准备工作，分解任务，做好林业设计、完善土地流转、订购苗木，筹集造林绿化资金。

（二）植树造林阶段（2017年4月5日以前）抓住春季造林的有利时机，在全镇掀起造林高潮，各村各地要在3月15日以前完成杨树栽植任务。

（三）检查验收阶段（2017年5月11日）镇政府组织专班，对村各地造林绿化情况进行全面检查验收，并将结果通报全镇。

五、工作措施

（一）加强领导，明确责任。镇政府成立石家河镇植树造林指挥部，具体负责领导、指挥、组织、协调造林绿化工作，镇长陈春梅同志任指挥长，镇委副书记汪家祥、组织委员刘雄军任副指挥长，镇农技、村镇服务中心、财政所、国土所、交警中队、水管站、林业等部门领导为指挥部成员，指挥部下设办公室，万义传同志任办公室主任、张晓明同志任办公室副主任。

（二）广泛宣传，注重引导。各村要采取多种形式，大力宣传林业在生态文明建设中的作用，不断提高广大群众的绿化意识和参与热情，努力营造全社会植树、护绿、爱绿、学绿的良好氛围。

（三）创新体制，借力发展。一是要创新造林机制。继续借鉴和推广近年来行之有效的造林模式，大力发展非公有制林业，充分调动专业大户和各地合作社的造林积极性，建立多主体参与、多渠道投入、多形式造林的政策机制。二是要明晰产权，要将林地的所有权和林木的使用权分割开来，让经营者充分享有对林木的所有权、经营权和收益权，真正做到"林有其主"、主有其权、权有其责，则有其利"。

（四）严把质量关，确保成效。本着"适地适树，良种壮苗"的原则，按照造林技术规程的要求，科学规划设计，选择造林树种，规范种苗的采购与供应，全面推行专业队伍造林，扩大先进的实用技术，保证造一片，活一片、成林一片，落实管护责任，实行专人管护，严厉打击破坏损毁林木的违法犯罪行为，切实保护和巩固造林绿化成果。

（五）严格考评，奖惩兑现。镇政府组建考核检查专班，对本年度植树造林情况进行检查验收，并严格奖惩结账。镇政府将继续按市有关奖补政策实行以奖代补，安排专项资金对植树造林先进单位予以奖励。
