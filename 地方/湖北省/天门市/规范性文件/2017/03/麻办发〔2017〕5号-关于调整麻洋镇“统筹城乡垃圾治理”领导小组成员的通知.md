# 关于调整麻洋镇“统筹城乡垃圾治理”领导小组成员的通知

各党总支、支部，各村（居）民委员会，镇直各单位：

根据《2017年小城镇建设管理城乡垃圾统筹治理考核办法》有关规定，为了加强领导，推进全镇城乡生活垃圾的统筹治理，美化城乡环境，镇委、镇政府决定调整城乡垃圾统筹治理领导小组成员，名单如下：

组　长：梁文江 镇委副书记、镇长

副组长：彭志中 镇委副书记、综治办主任

孔维新 镇党委委员、副镇长

成 员：涂先仿 经济发展办主任 兼任农办主任

周洪武 国土所所长

李选成 水管站站长

彭俊鹏 农技服务中心主任

梁可珍 畜牧兽医服务中心主任

彭首庚 村镇建设服务中心主任

彭　觅 村镇建设服务中心工作人员

领导小组下设办公室，办公室设在镇农办，涂先仿同志兼任办公室主任。

中共麻洋镇委办公室　　 麻洋镇人民政府办公室

2017年2月28日
