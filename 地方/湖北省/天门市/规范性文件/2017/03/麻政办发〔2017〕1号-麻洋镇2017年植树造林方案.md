# 麻洋镇2017年植树造林方案

为了切实抓好我镇2017年植树造林工作，进一步扩大和巩固“绿满天门行动”成果，结合我镇实际，特制定本方案。

一、指导思想

以党的十八届六中全会精神为指导，继续深化“绿满天门”行动，建设省级林业生态市，按照规划先行、突出重点、扩充总量、提高质量、政府主导、全民参与的原则，着力推进国土绿化进程，加强林业灾后恢复重建，培育保护森林资源，全面提高林业的综合效益，促进林业生产可持续发展。

二、工作目标

2017年全镇造林绿化总面积为1130亩。其中：完成国家重点工程造林370亩，全民义务植树760亩。新建绿色示范乡村2个。

三、工作任务

（一）抓好林业重点工程项目建设。

以新农渠至七一渠之间、二横渠、三横渠、四横渠等水系周边区域为主，通过更新改造与荒地造林相结合，完成国家重点工程造林370亩，确保造林存活率达到90％以上。

（二）抓好通道生态景观建设。

所有改造升级公路要实行高标准绿化，砍伐路段要全面复林更新，断带缺株路段要补植补造到位，“村村通”公路要路修到哪里，树就栽到哪里，打造通道绿化亮丽景观。

（三）抓好绿色示范乡村建设。

全面开展森林城镇和森林村庄创建活动，把村庄绿化美化和“精准扶贫”等工作紧密结合起来，统一规划，分类指导，稳步推进。以“林农结合”、“林水（塘）结合”、“林路结合”为主要模式，完善农田林网建设。宜林的通组路、机耕路、小沟水渠、塘堰要应绿尽绿。抓好农户房前屋后绿化，大力发展庭院经济，构建“春有花，夏有荫，秋有果，冬有绿”的生态经济型村庄绿化体系。2017年建成绿色示范村2个。

（四）抓好全民义务植树活动。

以城镇公共绿地、农村庭院、房前屋后及四旁植树为主，大力开展“廉政林”、“青年林”、“三八林”、“园丁林”等绿化示范工程建设，按照适龄公民人平3-5株树的要求，组织开展全民义务植树活动。2017年完成全民义务植树面积760亩。

（五）抓好林业灾后恢复重建。

深化和巩固“绿满天门”成果，切实抓好现有林木的管理。对因2016年水灾损毁的苗圃地、新造林地、未成林地及近三年来造林保存率低于50％的造林地块，开展补植补造、树体修剪、病虫害防治、除草追肥等工作，强化林木管护措施；对损毁的林业道路、房屋等基础设施；进行修复或重建。

四、工作措施

（一）加强领导，明确责任。镇委镇政府成立麻洋镇植树造林工作领导小组，具体负责领导、指挥、组织、协调造林绿化工作。按照市政府的统一部署，把植树造林作为当前农村工作的重要工作任务，摆上重要议事日程，层层落实责任，确保领导力量到位、工作部署到位、工作责任到位、监督措施到位。

（二）广泛宣传，注重引导。各村要采取多种形式，大力宣传林业在生态文化建设中的作用，不断提高广大群众的绿化意识和参与热情，努力营造全社会植绿、护绿、爱绿、兴绿的良好氛围。

（三）创新体制，借力发展。一是要创新造林机制。继续借鉴和推广近年来行之有效的造林模式，大力发展非公有制林业，充分调动企业、专业合作社及大户的积极性，建立多主体参与、多渠道投入、多形式造林的政策机制。二是要明晰产权。要将林地的所有权和林木的使用权分割开来，让经营者充分享有对林木的所有权、经营权和收益权，真正做到“林有其主，主有其权，权有其责，责有其利”。

（四）严把质量关，确保成效。本着“适地适树，良种壮苗”的原则，按照造林技术规程的要求，科学规划设计，选择造林树种；规范种苗的采购与供应，全面推行专业队伍造林，推广先进实用的造林技术，保证造一片、活一片、成林一片；落实管护责任制，实行专人爱护，做到林下无杂草丛生，树上无藤蔓缠绕。

（五）统筹兼顾，密切配合。农业、林业、公安等部门要按镇政府的统一部署，强化责任意识和服务意识，顾全大局，密切配合，齐抓共管，使造林绿化同高标准农田建设、水利工程、农田基本建设、农业综合开发、土地整理等相结合，做到同步规划，同步设计，同步施工，同步验收。

（六）加强督导检查，严格考核结帐。纪检部门将加大对绿满麻洋行动的督查力度，对作风涣散、进展不力的要予以曝光，对严重违纪违规行为要进行严肃查处。镇政府年终对绿满麻洋行动成效进行考核，对达到绿化建设标准并通过验收的，给予表彰、奖励，对没有完成目标任务的，进行通报批评，并督促整改到位，对不能如期实现绿化达标目标的，要对其主要负责人进行约谈问责。
