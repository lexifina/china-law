# 麻洋镇2017年爱国卫生月活动实施方案

为切实贯彻《省人民政府关于进一步加强新时期爱国卫生工作的实施意见》，不断改善城乡环境，提高人民健康水平，根据天门市爱国卫生委员会要求，决定在全镇范围内深入开展“清洁家园，灭蚊防病”春季爱国卫生月暨创卫整治活动。现结合我镇实际，制定本方案。

一、活动时间

2017年3月

二、活动内容

（一）爱国卫生宣传活动

1、广泛动员，加强教育宣传。

组织各村各单位学习《意见》及市创卫办、市爱卫办关于开展第29个爱国卫生月活动的相关文件精神，在全镇范围内掀起爱卫运动的学习热潮。利用宣传栏、宣传标语等媒介形式大力宣传新时期爱国卫生运动的重要意义和重点任务，广泛传播卫生健康知识，大力推进全民健康生活方式。

2、组织开展义诊活动。

镇卫生院继续开展与镇福利院的结对帮扶活动，为五保户免费看诊、免费提供诊疗方案。

3、健康巡讲“五进”活动。

镇卫生院开展健康知识“五进”活动，组织“基层健康指导员”深入农村、社区、学校、企业和家庭宣讲健康知识，全面普及健康素养基本知识与技能，提高广大群众的卫生意识，摒弃陋习。大力倡导不吸烟、不喝生水、不吃不洁食品、不随地吐痰、不乱扔垃圾、不随地大小便、不施用未经无害化处理的农家肥等科学文明的健康生活、生产方式。

4、开展全民健身活动。

开展丰富多彩的全民健身活动。利用马跃潭广场的优越健身环境，组织街道、附近村（居）民开展以广场舞、羽毛球、乒乓球、篮球为主的健身活动，倡导健康的生活方式。

（二） 无烟环境创建活动

全面贯彻落实《关于领导干部带头在公共场所禁烟有关事项的通知》和《关于在全市开展无烟机关创建活动的通知》文件精神，加大宣传力度，推进公共场所禁烟，大力倡导工作场所禁烟，全面推动无烟环境创建工程，共建健康的工作环境。

（三） 环境卫生整治活动

1、镇区环境卫生整治。全面整治、提高镇区的环境卫生质量，清理卫生死角，增添环卫设施，建立长效管理机制。重点清除积存垃圾、白色垃圾、乱堆乱放、乱涂乱画。

2、乡村环境卫生整治。结合农村垃圾治理，建立健全农村垃圾收运体系。重点清除房前屋后积存垃圾、白色垃圾、乱堆乱放。

（四）开展除“四害”活动

1、铲除“四害”孳生地。坚持“早部署，早动员，早落实，见实效”的原则，结合环境卫生整治组织机关干部社区居民开展以灭蚊为主题的铲除“四害”孳生地活动。要重点对车站、港口、农贸市场、垃圾中转站、单位院落等区域的环境卫生进行治理，彻底清除卫生死角，消除“四害”孳生场所，清理“四害”尸体、虫卵及活动痕迹，创造良好的卫生防病环境。

2、科学监测密度。根据市疾控中心监测方案要求，配合做好监测工作，并根据疾控中心媒介监测数据、媒介传染病发病情况及风险评估结果，将监测的结果采取科普化的语言告知社会大众。在市爱卫办的指导下，有针对性地采取化学、生物等方法开展灭蚊、灭鼠、灭蟑、灭蝇等活动，确保“四害”密度控制在较低水平，从源头上切断病媒生物传染病传播途径。同时要科学、合理地选用敏感的消杀药物，避免过度用药和滥用药，切实提高防治效果。

3、统一投放药物。根据监测结果，到专业消杀公司购买毒饵站和药物，于2月10日-28日统一投放。

三、工作措施

（一） 广泛动员，全民参与。各级领导干部要率先垂范，以身作则，带领群众积极投入到活动中，在全镇范围内掀起爱国卫生运动的热潮。要通过爱国卫生月活动，提高群众自我管理、自我约束的能力，调动各方面的积极性，改善环境卫生，建立和完善长效管理机制。

（二） 密切配合，各负其责。镇爱卫办要做好爱卫月活动整体协调工作，加强与村镇建设服务中心、卫生院、学校、食品所、社区等爱卫会成员单位的联络沟通，充分发挥各专业队伍在活动中的骨干作用，各负其责，共同开展好城乡环境卫生整治行动，真正形成爱国卫生齐抓共管的工作局面。

（三） 狠抓落实，注重实效。各地、各单位要从实际出发，认真组织，精心部署，扎实开展，注重实效，切实解决群众反映强烈的热点、难点问题，为人民群众营造卫生、舒适的生活环境。镇爱卫办将对活动开展情况进行检查考核并通报。
