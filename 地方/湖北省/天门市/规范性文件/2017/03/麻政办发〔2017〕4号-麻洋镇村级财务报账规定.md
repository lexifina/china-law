# 麻洋镇村级财务报账规定

为了进一步规范农村集体“三资”监管和农村财务管理制度，确保村级财务收支报账有章可循。根据《天门市农村集体经济组织资金、资产、资源监管代理服务工作实施办法》、《天门市村级集体工程建设及资产、资源经营处置管理暂行办法》和有关财务管理规定，参照《天门市村级财务报账工作操作指南》。结合我镇实际特制订麻洋镇村级财务报账规定。

一、 报账前准备

定期报帐。镇政府规定每年每季最后一周，星期三伏岭片，星期四麻洋片，星期五毛湖片各村报帐。当年底会计服务中心专业会计汇总。

编制收支计划。村级年初按照当年收支项目及资金进行编制《XX村XX年度收支计划表》（原收支明细表）；按要求逐级签字后交会计服务中心。明确规定各项收支项目控制范围、标准、额度。超出以上规定的业务，未经追加审批表不得报账。

制定村财务管理细则。该细则的内容是镇财务制度规定以外的入伍镇级初检误工费、花圈鞭、换届选举、“两代会”四项开支内容。该细则村级在年初报账前上交会计服务中心时，必须通过代表会议记录、签名及镇长签字。否则该细则无效，支出不能报帐。

二、收入项目报账规定

村级资金收入，包括村级直接收到的货币资金和财政分配得到的收入资金两种。村级直接收到的货币资金主要有各项经营收入；资产、资源处置、租赁、承包及有偿使用收入；经批准的一事一议筹资；社会单位捐赠款；其他收入及收回债权和代收资金等。财政分配得到的收入资金主要有财政转移支付和各项财政补助、专项资金及通过财政得到的土地征用补偿费、社会单位个人捐款等。

资产资源处置发包收入报账。

①票据使用：湖北省农村集体经济组织统一收据和财政部门监制的财政票据。

②报账附件：必须提交代表签字的会议记录、村级招投标项目申报表、资金缴存进账单、处置承包合同；

③分级签批：标的在1万元以下由“三资”监管代理中心主任签批；标的在1万元以上的，必须由乡镇“三资”监管委员会主任签批；标的在2万元以上的除签批外，必须在乡镇产权交易中心场地实施现场交易。

财政分配收入资金报账。

①票据使用：湖北省农村集体经济组织统一收据或资金分配通知单；

②报账附件：资金来源的有关批文、分配资料或拨款单复印件。

三、生产性支出报账规定

村级生产性支出主要指村级发生的公共事业投资项目，生产生活配套设施。农田水利等基本建设及其维修维护和植树造林、环境改造等支出。

基本建设项目（含采购实物5000元以上的）开支报账

票据使用：必须提供正规的税务建安发票。

报账附件：①村拟定的建设工程项目申报表，大型项目要有上级立项批文；②召开村民会议或村民代表会议记录；③建设工程项目预（决）算报告；④工程验收报告，大型项目还要有工程监理报告；⑤建设工程项目招投标公告，大型项目要有招投标现场影像资料及会议记录；⑥乡镇产权交易中心鉴证的建设项目施工合同。

签批要求：采购标的1万元以下、建设项目10万元以下，中心主任签批处置；前项标的以上的由监管委员会主任签批处置。采购标的2万元以上、建设项目10万元以上，必须在乡镇产权交易中心场地实施现场交易，建设项目200万以上，进入市公共资源交易中心交易。

大额（单项事务开支1000元以上）开支报账

票据使用：必须提供正规的税务发票。

报账附件：①村集体拟定报批的《大额支出事项开支计划审批表》；②召开村两委集体研究和村民代表会的会议记录；③1万元以上的事项，必须提供预算、施工记录、完工验收等资料。

签批要求：1000-2000元的由乡镇挂村干部签批、2001-5000元由中心主任签批、5000元以上的由乡镇“三资”监管委员会主任签批。

小额（1000元以下）零星开支报账

票据使用：①单项事务和对外购买1000元以下实物性支出，提供正规有效的税务发票；②对支付个人的劳务服务支出使用领款单报账；③村内小卖店购买的小件公务用品支出，使用统一规范的《零星小额支付单》报账。

报账附件：提供材料、用品明细码单和务工记录。

3、签批要求：村主任签批。

所有生产性支出原始票据报账要真实合格，要素齐全，符合使用范围，内容清楚、书写清晰、规范。发票要有提供服务的单位和个人签字盖章。自制单据不能由村干部代写，要有领（收）款人签字或盖章。每张报账票据上经手人填写事由并签名，证明人、实物验收人、事项负责人、分管领导、村务监督委员会等审核签批手续齐全。

四、非生产性支出报账规定

非生产性支出主要指村干部工资、办公、差旅等管理费及村民福利和其他支出等开支。采取定项限额包干和定项限额审批两种管理模式。各村应在年初填报非生产性支出预算。而未在年初预算中的即将发生开支事项，应填写《村级非生产性支出追加事项开支限额审批表》经审批后方可开支。

非生产性定项限额包干支出

村干部工资。按镇政府下发的文件标准执行；报账凭证以财所统一规定的工资花名册报账；村级不得以任何名目发放钱物提高待遇；组干部工资发放标准，大村职数2人，小村职数1人，每人1000元。

其他定项限额包干。具体项目标准为：报账员办公费600元/年，旅差费人平300元/年。该项开支使用《村定项限额包干费用分配发放单》报账。

非生产性定项限额审批核销支出

公务活动费。村级公务严格实行“零招待”。村级因招商引资、项目建设和重大村务活动，必须发生招待支出的，按限额标准和程序要求执行。

招商引资、项目建设活动：①限额标准：1000人以下的村每村每年3000元；1000-1500人以下的村每村每年4000元；1500人以上的村每村每年5000元。②程序要求：要事先履行申报审批手续填写《村级村务接待开支申报审批单》实行一事一办、一事一结。每笔报账必须提供进餐消费清单，单据载明接待事由、经手人、证明人、村务监督委员会、村分管财务负责人等签批手续齐全。③票据使用：正规税票。

重大村务活动：①限额标准：如每年镇召开的三级干部会议，以组数和村干部数确定人数，每人不高于70元的标准支出报账；每年镇召开的“七一”代表会议按党员数确定人数，每人不高于70月标准支出报账。②报账附件：参会人员的签字花名册。③票据使用：正规税票。

外出差旅费。村干部因招商引资、建设项目和配合行政公务确需外出的。要事先履行申报审批手续，填写《村级公务外出申报审批表》。实行一事一办、一事一结。

费用标准参照《天门市党政机关差旅费管理实施办法》执行。途中交通费和住宿费按标准凭据报销，无据一律不得报费用；伙食补助按外出市外自然天数每人每天100元凭票报销；城市交通费按在外自然天数每人每天50元补贴。非正常路线费用一律自理。

外出参加会议、培训期间。按照谁举办、谁开支的原则，不得报销会务费、住宿费和伙食补贴。外出天门市外参加活动的，来回路途费用按上述外出标准补贴报账。

③打印费。报账须使用正规有效的税务发票，加盖服务单位和个人印章，并附打印资料明细清单。

④其他费用。如花圈鞭、征兵入伍、换届选举、两代会等费用报账，需召开村干部、村民代表大会讨论通过签字，制定村财务细则规定标准，填写有关审批表，上报镇政府签批交会计服务中心备案后方可开支报账。报账时用规定的有效票据和有关附件报销入账。

五、其他补充规定

（一）原始凭证报账使用范围及要求

原始凭证分收入、支出两类凭证。

收入凭证。必须使用湖北省农村集体经济组织统一收据、财政部门监制的财政票据及税务部门监制的发票才是合格有效的收入凭证。

①湖北省农村集体经济组织统一收据。用于农村集体经济组织之间及其内部成员之间发生的经济收入业务事项。

②财政部门监制的财政票据。用于农村集体经济组织与行政事业、社会团体及其他经济组织和个人发生的非经营性经济收入业务事项。

③税务部门监制的发票。用于农村集体经济组织以营利为目的，向其他单位和个人提供商品或劳务发生的经营性经济收入业务事项。

支出凭证。必须采信财政部门监制的财政票据、税务部门监制的发票及村集体经济组织自制的符合财税制度规定的自制凭证为合格有效支出凭证。

①财政部门监制的财政票据。主要有财政部门监制的行政事业单位非税收费收据和结算凭证。

②税务部门监制的发票。主要有：国税统一发票，包括定额发票、网络发票、手工发票等。地税统一发票，包括定额发票、网络发票等。特种行业发票，有行业部门申请税务部门监制。如电费、车票、银行利息发票等。

③自制凭证。用于对集体经济组织成员个人支付管理费用、村级公务活动支出、农村集体经济组织成员误工费、勤杂人员人工报酬等。其凭证必须采用统一格式的工资补助花名册、零星支出小额支付单、领条等。

原始凭证的填制要求。①原始凭证填制要素必须齐全，书写必须清晰、规范，不得涂改、刮檫、挖补。外来原始凭证金额有错误的，应当由出具单位重开，不得在原始凭证上更正；②原始凭证的金额，大小写必须相符；③同一张凭证填写的笔记应当出自一人之手。

（二）原始凭证报账必备附件

村集体经济组织取得的各项收入入账，要求取得收入的相应批复、文件、合同等资料。如筹资筹劳审批表、资产租赁及资源发包合同、土地出让补偿协议及分配方案等。

经上级有关部门批准的经济事项，必须要有批准文件（或复印件）。

大额生产性支付，必须要有《大额支出审批单》。

投资建设项目支出，必须要有村拟定的建设工程项目申报表，召开村民会议或村民代表会议记录、建设工程项目预（决）算报告、工程验收报告、工程监理报告，建设工程项目招投标公告，招投标现场影像资料及会议记录，建设项目施工合同（大型项目村必须与有资质的合法的建筑公司签订）等相关资料。

各项非生产性支出，必须要有上级组织、财政部门出具的批文。如工资报酬审批通知、年度工作实绩考核结果、项目经费限额包干文件等。

购买实物的原始凭证，必须要有验收证明，同一类业务不同种类的商品必须附明细（如办公用品、办公耗材等）。

上级部门的开支证明、会议通知和经手人自己的记录、说明等佐证材料只能作为报账附件，不能作为报账的原始凭证。

（三）原始凭证的审核流程

原始凭证审核就是要确保原始凭证的真实性、合规性、正确性、完整性和时效性。各层次的审核应在全面审核中注意相对的重点。

村报账员初审。①审核经办人提供的原始凭证是否合规，要素是否齐全。经济业务是否真实发生，并与凭证反映内容相符；②审核票据支出各项目金额是否准确，供货单明细汇总金额和发票金额是否合理；③收支项目和额度是否符合财务收支计划，是否违反有关财务制度和规定；④报账应备附件是否完整、真实；⑤有权要求经办人补充完善相关资料和手续。

中心专业会计复核。①复核原始凭证的真实性、合法性、完整性、规范性、准确性、时效性；②审核原始凭证的要素和报账签审手续是否完备，必备附件是否齐全；③审核经办人签署事由是否详实；④审核报账员分类是否准确；⑤审核原始凭证金额是否相符。

中心分管负责人终审。①进一步审核原始凭证的真实性、合法性、完整性、规范性、准确性、时效性，看有无违反计划、制度、政策法规等问题；②审核各层次签批、审核是否认真、负责、有效。

（四）村级财务报账程序

编制村内年度财务计划和特殊项目开支计划，并报乡镇审批后实施；

报账员在“三资”监管代理中心用《代理资金付款通知单》领取一定数额的备用金备用；

报账员将村内各项货币收入及时、全额缴存“三资”监管代理中心指定账户；

日常大额开支凭《开支计划审批表》到“三资”监管代理中心办理银行结算；

组织当期收支唱票审计，完善签批手续，同时将待报账的收支原始凭证逐笔登记，编制《报账单》一式三份；

报账员将收支原始凭证和《报账单》送达“三资”监管代理中心专业会计审查复核。专业会计复核后在《报账单》上签章，再传递至“三资”监管代理中心分管负责人审计并签章；

报账员凭专业会计和分管负责人签章的《报账单》与“三资”监管代理中心出纳办理结算手续，结算手续完毕时报账员和出纳双方在《报账单》上签章，出纳员留下一份《报账单》；

报账员将收支原始凭证及办完结算手续后的《报账单》一份交专业会计办理会计核算，并协助专业会计做好往来账户的登记核算。报账员留存一份《报账单》作为自己记账和回村进行财务公榜的依据；

定期将村内收支及重大财务事项进行公榜，并做好财务公开后的意见收集、解释及有关问题的处理；

在“三资”监管代理中心的协助下，对本村财务计划执行情况及资产状况，向村委会及村民代表会议报告。
