# 关于调整麻洋镇消防安全委员会人员的通知

各村（居）民委员会、镇直各单位：

因人事变动和工作需要，镇政府决定对镇消防安全委员会人员进行调整，调整后的成员名单如下：

组　长：梁文江　 镇委副书记、镇长

副组长：刘　勇　 镇委委员、副镇长、人武部长

成　员：刘云庭　 安全管理办主任、经济发展办副主任

万　峰　 派出所指导员

彭文雄　 派出所副所长

委员会下设办公室，办公室设在天门市公安局麻洋派出所，负责消防安全委员会的日常工作。

麻洋镇人民政府办公室

2017年3月1日
