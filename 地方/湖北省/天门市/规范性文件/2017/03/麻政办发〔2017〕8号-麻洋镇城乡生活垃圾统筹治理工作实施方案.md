# 麻洋镇城乡生活垃圾统筹治理工作实施方案

为认真贯彻落实住建部提出的“城乡生活垃圾五年专项治理”工作总体目标和省、市安排部署城乡生活垃圾统筹治理工作的有关要求，切实做好麻洋镇城乡生活垃圾统筹治理工作，2017年镇委决定将该项工作纳入村级实绩考核，采取“一月一检查、一年一结帐”的方式进行考核。现结合我镇实际，制定实施方案如下。

一、工作目标

按照“因地施策，量力而行，示范引导，全面推进”的原则，结合我镇实际，统筹治理范围全覆盖，实现 “户分类—组保洁—村收集—镇中转—市处理”的生活垃圾处理模式。

二、工作标准

1、村级标准。每村确定好垃圾集并点（按每1000人1个集并点），每个集并点配备一个钩臂箱，每户自备一个垃圾桶，每80-100户配备一名保洁员，每名保洁员配备一辆板车及相应的保洁工具，负责村庄日常清扫保洁及垃圾分类收集，并运送至村集并点。做到“六净”、“六无”，即：进村道路净、大街小巷净、沟塘堰边净、公共场所净、房前屋后净、村周环境净；无生活垃圾、无建筑垃圾、无抛洒杂物、无乱堆乱放、无乱搭乱建、无乱栽乱种。

2、镇级标准。乡镇建设一座统一规范的垃圾压缩中转站，配备专业钩臂车和钩臂箱，并将集并点垃圾收运至镇中转站，进行压缩处理。

三、运行方式及负担办法

1、镇级负责各村集并点垃圾收运。

2、村级负责辖区内垃圾清扫、收运到指定的垃圾箱内。

3、村级负担保洁员工作服及相关保洁工具购置保养、维修费用。

4、市级财政补贴村保洁员每人每月300元，不足部分由村级负担。

四、组织领导及职责分工

1、组织领导。为加强领导，推进城乡生活垃圾统筹治理工作进程，镇委、镇政府成立城乡生活垃圾统筹治理工作领导小组。镇长梁文江任组长，镇委副书记彭志中、镇委委员、副镇长孔维新任副组长，成员由涂先仿、周洪武、李选成、彭俊鹏、梁可珍、彭觅等同志组成。领导小组下设办公室，办公室设在镇农办，涂先仿同志兼任办公室主任。

2、责任分工。

镇统筹办负责人员组织、设施设备、制度建设等各项工作；负责对村级统筹治理工作搞好指导督导工作；负责对村级开展常态化巡查及量化考评；负责对村级保洁员薪酬的统筹。

村级负责组织培训、引导农民养成垃圾分类与投放的良好习惯；负责组织带领农户定期开展房前屋后、道路沟渠的生活垃圾大清除；负责按每80户-100户配备一名保洁员的标准组建和培训好保洁员队伍；负责配齐配足保洁员的各类保洁工具；负责对保洁员的日常工作进行检查、指导和考核；负责小型保洁工具的修理和置换；负责采取多种形式筹集村庄保洁费用，严禁搭车收费。

五、工作日程

1、宣传发动（1-3月）

制定《麻洋镇城乡生活垃圾统筹治理工作实施方案》，与村签定《2017年村庄环境卫生整治目标责任状》，召开动员大会。开展宣传活动，营造浑厚氛围，要求每村设1个宣传专栏、2条墙面标语、1条横幅标语、2张宣传画、每户一份宣传折页、每个农户一份告知书。

2、积存垃圾清理（3-6月）

全面开展积存垃圾和农户房前屋后大清理、大整治，达到农户杂物码放有序，彻底清除村庄积存垃圾，并持之以恒，常年保洁。

3、农户垃圾容器配置（7月）

各村按一户一小桶，硬性指标配置到位，另提倡按五户一大桶配置垃圾容器。

4、村“三员”履职（1-12月）

督查村“三员”履职，是否到岗到位，维持村庄整洁。

5、筹资筹劳（11-12月）

按要求征收统筹费，保障统筹工作正常运转。

六、考核结帐

镇委、镇政府将城乡生活垃圾统筹治理工作纳入村级年底实绩考核，镇统筹治理办公室制定考评细则及奖补办法，通过“日抽查、月检查、季通报、年总评”的形式，对各村进行综合考核，考评结果在全镇进行通报。镇政府每年设立不低于5万元的专项奖励资金进行奖励结帐，根据考核结果，年终对环境卫生先进单位和个人给予奖励。
