# 黄潭镇关于2017年二月城乡垃圾统筹治理工作情况的通报

各村（居）民委员会：

我镇城乡垃圾统筹治理工作于2015年12月正式启动。一年来，在党委、政府的正确领导下，在全镇广大干群的共同努力下，我镇城乡垃圾治理工作取得了一定的成绩，全镇各村村容村貌、人居环境有了较大改变，群众环保意识有了一定提高，但同时也存在许多问题与不足。2017年2月21日－－23日，镇统筹办对全镇34个村城乡垃圾统筹治理工作进行了巡查，对部分村组、重点区域现状进行实地察看拍照，现将有关情况予以通报。

一、基本情况

自我镇城乡垃圾统筹治理工作启动以来，各村相应开展了相关工作，基本能按照：户入桶—－组归类—－村收集－—镇压缩—－市轻运的模式运转。但各村工作极不平衡，成效并不明显，好坏差距分明，存在问题突出。大部分村能够严格按照市、镇有关工作要求，高度重视，真抓实干，扎实推进，治理工作成效显著，村容村貌大有改观，但少数村工作流于形式，表于面上，领导不抓，群众不理，人员不干，垃圾积存，状况不变，村容依旧，工作停滞不前。

二、存在的突出问题

通过巡查表明，我镇城乡垃圾统筹治理工作还存在着严重问题，不容忽视。

1.宣传发动不够，群众认识不高。这次巡查中，我们发现，有的群众根本不知道城乡垃圾统筹治理这项工作，只知道有人收垃圾，总认为垃圾治理是政府和村组以及保洁员的事，因此，容器随意放，垃圾随手倒等现象严重。如杨泗潭村某农户，自家门前也放置了垃圾桶，房前屋后也清扫得十分整洁，但在巡查时碰见，她准备的垃圾桶装满垃圾后未等保洁员收集，自己随手将一桶垃圾直接倒在了公路边。此外，很大一部分农户直接将垃圾倒在了自家屋后、沟渠、塘边、空地等公共场所。

2.垃圾集并点建设不到位。一是相当一部分村垃圾集并点未硬化；二是垃圾集并点选址不合理，建设标准不达标。三是钩臂箱随意摆放，垃圾难以入箱，影响收集和清运，存在重大安全隐患。

3.农户垃圾容器配备不规范。巡查中发现，农户门前的垃圾容器配备严重缺失，有的农户门前根本没有，有的农户用塑料袋、木桶、纸箱、各类包装箱、废旧家具等装储垃圾，五花八门。既不利于垃圾归并，也影响保洁员的收集清运。

4.积存垃圾清理问题突出。积存垃圾清理是城乡垃圾统筹治理工作重中之重，2016年，镇政府安排各村开展了一次积存垃圾大清理工作，但实际情况表明，我镇的积存垃圾处理工作不全面，不彻底，还存在着相当大的问题。具体表现在：一是沟、路、渠、塘边白色垃圾随处可见；二是房前屋后乱倒乱堆；三是空屋空台无人管理；四是林间空地随意抛洒，部分村组和区域积存严重，到了触目惊心，不可目视的地步。

5.保洁队伍管理不善，各村虽然成立了领导小组和专班，配齐了保洁员，但在日常工作中，存在管理不严格，履职不到位的情况。一是村专管员工作不力，对日常保洁工作的巡查、督促、管理考评不严格；二是保洁员脱岗、替岗、拖岗现象严重，队伍不稳定，甚至少数保洁员占额空岗，“三天打鱼，两天晒网”；三是保洁员服装、工具的购置、配备、维修不及时，影响工作的正常开展；四是对保洁工作标准不高，分工不清，职责不明，工作留有死角，未能全覆盖。

三、考评分类

根据这次的巡查情况，结合2016年的工作实际。镇统筹办对各村目前城乡垃圾统筹治理工作情况进行了分类，旨在提醒，促进工作：

一类六个村：七屋岭、姚垸、徐南、新王、曾巷、张台；

二类二十四个村：直河、八湾、前河、曹湾、危湖、甘岭、复兴、陈当、黄茅湖、彭湾、龙咀、黄潭、万场、窑台、新华、小木桥、白龙、敖堤、鲁店、水府庙、丝网湾、杨泗潭、黄咀、阳台；

三类四个村：西庙、向张咀、罗口、徐马湾。

四、今后工作目标及要求

认真落实省、市有关城乡垃圾统筹治理工作的工作部署和要求，对照《黄潭镇2017年推进城乡垃圾统筹治理工作方案》，查漏补缺，着力整改，强化措施，加大力度，保质保量完成2017年各项工作任务。

1.进一步开展宣传。利用广播、标语、横幅、宣传栏、告农户书等多种形式，加大宣传力度，做到家喻户晓，人人明白，全民动员，全民关心，全民参与，努力提高广大农户的积极性和自觉性。

2.切实加强领导。各村要成立专班，明确分工，落实责任。村一把手要亲自抓，专管员要常年抓，挂组干部及组长要天天抓。同时要建立健全各项规章制度，做好巡查督促、考评结账等工作，真正把城乡垃圾统筹治理工作放在心上，拿在手上，抓在点上。

3.迅速行动，抓好以下几项工作：

（1）高标准建设垃圾集并点。按照《方案标准和要求》，根据各村实际需要，合理布局，建设好垃圾集并点。

（2）开展村庄积存垃圾大清理，环境卫生大整治。各村要高度重视，迅速行动，在3月底以前对全村积存垃圾进行一次大排查、大清理、大整治，做到全面、彻底、不留死角。

（3）迅速启动城乡垃圾统筹治理有偿服务费的征收工作。各村要严格按照市、镇两级工作要求和程序，成立清洁村庄理事会，严格遵守“一事一议”、“四议两公开”及“财务管理”等制度，迅速开展有偿服务收费工作，确保城乡垃圾统筹治理工作的稳定和持续发展。

（4）加强保洁队伍管理。一是对保洁员进行教育培训，明确职责，增强责任心；二是加强日常巡查与监督管理，认真填写巡查日制；三是多方筹资，确保保洁员工资按时发放并逐步提高；四是对脱岗、替岗或因病因事不能胜任的保洁员及时予以更换，确保保洁队伍的稳定性和工作的连续性。

（5）严格按照一户一桶标准配备垃圾容器，取缔代用品，同时配齐保洁员服装、作业工具等用品。

城乡垃圾统筹治理是一项长期而艰巨的任务，任重道远。望各村再鼓干劲、再加压力、再增措施，上下同心，在2017年度取得更好的成绩！

黄潭镇人民政府办公室

2017年3月1日
