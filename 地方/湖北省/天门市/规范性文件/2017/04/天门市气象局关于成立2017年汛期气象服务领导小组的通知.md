# 天门市气象局关于成立2017年汛期气象服务领导小组的通知

市局直属各单位、机关各科室：

为了进一步加强对汛期气象服务工作的领导，切实做好汛期气象服务工作，决定成立2017年天门市气象局汛期气象服务领导小组。领导小组组成及职责分工如下：

一、领导小组组成成员

组 长：汪高明

副组长：成 道 刘望平

成 员：陈光荣 芦洪涛 韩 杳

彭中甫 胡卫国 邵万杰

领导小组下设办公室，挂靠气象台。

二、成员单位职责分工

组长：全面指挥和组织领导全市汛期气象服务。

副组长：协助组长全面指挥和组织全市汛期气象服务工作。

综合管理科：负责汛期气象服务工作安排、组织协调、宣传报道、应急管理、车辆保障、资金调拨、人事调配、政策法规、行业和标准化、行政执法、防雷行政管理工作、思想政治工作、水电等后勤保障及安全保卫工作。

天门市气象台：负责汛期气象服务的综合观测、预报、预警和气候预测等工作；负责农业气象观测及服务工作；开展重大天气过程和灾害性天气的会商与上下游联防；开展气象灾害风险预警和影响评估工作；负责重大天气过程技术总结和汛期气象服务总结；负责国家站装备保障及信息网络运行维护工作。负责国家突发事件预警信息发布系统的运行维护；负责天门气象信息服务网站、官方微信、12121等气象服务工作；承担汛期气象科普宣传工作。承担领导小组办公室的日常工作。

天门市气象服务中心：负责全市区域自动气象站维护保障工作；负责气象服务产品分发递送和影视气象服务工作；负责预报、服务、会商等业务平台日常维护保障工作。

天门市人工影响天气办公室：负责全市人工影响天气管理和作业工作。

天门市防雷中心：负责汛期气象服务技术装备和业务系统的防雷安全；负责专业雷电预警服务；负责雷电灾害调查分析工作。

党组纪检组按照有关规定，加强汛期气象服务执纪问责。
