# 小板镇关于机关干部岗位职责及蹲村的通知

各党支部、各村民委员会：

根据工作需要，经镇委研究决定对机关干部岗位职责进一步予以明确，现通知如下：

一、机关干部岗位职责安排

机关内设三大办公室，即：党政综合办公室、经济发展办公室、社会事务办公室。各办公室职责及人员安排如下：

1、党政综合办公室：承担党委、人大、政府、政协交办的各项日常工作和组织、纪检、宣传、社会管理综合治理、信访维稳 、工青妇、机关管理、应急处理等方面的综合协调工作，督促检查有关工作的落实。

刘 潇：主任、人大秘书、小板片片长。负责党政办公室全面工作，协调和督导各方面工作落实。协助抓好人大日常工作、小板片具体工作。

卢义容：副主任。

张代忠：副主任、综治办副主任。负责政法、社会管理综合治理、信访维稳、网格化管理日常工作。协助抓好烟草和屠宰市场管理日常工作。

喻凤娥：副主任，妇联专职副主席、工会专职副主席。负责妇女儿童、工会、机关事务管理日常工作。

汪新洲：纪委专职副书记。负责纪检监察、财务清理、“三资”管理日常工作。

尹雯璟：组织干事、老干部干事、镇党员群众服务中心主任、大板片片长。负责组织、人事、老干部、党员群众服务中心日常工作，大板片具体工作。

陈　田：信访办主任、罗湖片片长。负责信访办和网格化管理中心日常工作，罗湖片具体工作。

杨丹成：信访办副主任。

喻秀丽：宣传统战干事、统计助理。负责宣传统战和统计具体工作。

谢姜山：党政办秘书、团委专职副书记、通村公路办公室主任、文档助理，协助抓好党政办、共青团、档案管理和通村公路建设具体工作。

2、经济发展办公室：承担工业、农业、水利、林业和第三产业发展规划、招商引资工作，协调与经济发展相关的其他工作。

肖黎刚：主任。负责经济发展办公室工作。

吴明洋：副主任、农办主任。负责农业农村和林业、水利、水产、畜牧、农机、血防、土地流转等日常工作，协调与农业农村相关的其他工作。

敖炎斌：副主任。负责安商服务工作。

熊志军：副主任、统计站长。负责统计站日常工作。

祁 杰：副主任。借调市招商局工作。

梁　攀：招商办主任、安全生产助理、武装部副部长、政协干事、工业园片片长。负责招商引资、安商服务、安全生产、环保、科技、消防、武装、政协、工业园片具体工作。

罗雨山：机关工勤人员。负责机关具体工作。

3、社会事务办公室：承担人口与计划生育、民政、人力资源和社会保障、城镇建设、交通、文化、教育、卫生等工作，协调与社会事务相关的其他工作。

王青平：主任、新农办主任。负责社会事务办、新农村建设日常工作。

杨清元：副主任，村建服务中心主任。负责城建城管日常工作。

范耀刚：副主任、民政办主任、扶贫办主任。负责民政办日常事务工作和精准扶贫具体工作。

曾　密：计生办主任。负责计划生育日常工作。

江会军：小板社区书记。

黄靖宇：小板社区主任。协助社区书记做好社区全面工作。
