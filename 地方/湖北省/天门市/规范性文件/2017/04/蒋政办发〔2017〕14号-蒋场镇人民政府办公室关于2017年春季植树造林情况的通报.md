# 蒋场镇人民政府办公室关于2017年春季植树造林情况的通报

各村（居）民委员会：

4月13号至15号，我镇组织专班对全镇2017年春季植树造林工作进行了检查,现将检查情况通报如下：

一、任务完成情况

2017年春季，全镇共植树69250余株，其中绿化树9250余株，意杨60000余株；新建绿化通道5条，长11800米，村庄绿化3个，宜林地造林400亩；完成道路加宽、路肩土回填3000米；补栽“水毁”通道绿化6条，长21500米，补栽树木1700余株，圆满的完成了市布植树造林任务，营造了全镇植树、管树、护树的良好氛围，促进了我镇林业工作再上新台阶。

二、主要成绩

1.认识高、部署早。全镇上下充分认识植树造林工作的重要性，镇委加重“绿满”工作年终考核权重，专门把“绿满”作为三级干部表彰内容之一。各村都把“绿满蒋场”纳入去冬今春重要工作议事日程，结合小农水建设、重点水利工程建设进行统筹规划，统一部署。入春以来，我镇先后召开植树造林相关会议4次，2月22日全镇在堤湾、柳口村召开了“植树造林、绿满蒋场”现场推进会。特别是柳口村、堤湾村、饶场村、三阳寺村主动谋划，先后召开村委会议、村小组会议，积极组织通道除障，路肩土回填，为通道绿化奠定了良好的基础。

2.行动快、标准高。全镇植树造林工作统一盘棋，2月初，在镇三级干部会议上安排了植树造林工作，明确各村的植树地块、面积、数量、品种，各村统一规划、统一树种、统一栽植。代巷村、中和村、西湖村、官河村等4个村积极落实植树地块，组织树苗、划线定窝，高标准的完成了植树任务。特别是柳口村委全员上阵，雨天抢栽，效果较好。

3.措施硬、管护好。全镇认真落实管护措施，建立植树工作目标责任制，做到镇有专班、村有专管、组有专户。柳口村、齐桥村、孙岭村等3个村积极进行树木套白，杀虫除杂等，官祭口村、齐桥村积极补栽水毁树木对责任林木形成了良好保护。

三、存在的问题

1、宜林地矛盾调解不够。部分村干部没有对宜林地的矛盾进行有效调解，造成部分群众对宜林地造林不理解、不支持，全镇还存有较多闲置宜林地。

2、部分村认识不高，行动迟缓。沙湖村、西燕村等2个村对植树造林工作认识不高，行动迟缓，尚未完成造林任务。

3、树木管护不及时。部分村新植树木还未进行修剪和套白；部分村新栽树木存在被盗被破坏情况，管护不到位，如贺湾村新植树木被损坏严重。

蒋场镇人民政府办公室
