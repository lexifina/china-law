# 马湾镇关于建立健全基本农田保护巡查协管体系的通知

各村民委员会：

保护基本农田是各级政府的共同责任。为了加强基本农田保护工作，切实落实基本农田动态巡查责任，镇政府决定在各村聘请基本农田保护巡查协管员，建立健全基本农田保护巡查协管体系。协管员要根据《土地管理法》和《基本农田保护条例》规定，按照巡查区域每周巡查二次，对发现违法用地或破坏基本农田的行为应予制止，并及时上报国土部门立案查处。同时，镇政府将与巡查协管员签订工作责任状，实行目标管理，定岗定责。对工作优秀人员，镇政府将依据有关文件要求予以奖励结帐。对工作不力的人员，按责任状要求予以惩处。
