# 关于切实加强村干部值班制度的通知

各党总支、支部：

为充分发挥村级党员群众服务中心的功能作用，提高村组织管理和服务水平，切实转变干部工作作风，密切党群干群关系，落实全面从严治党向基层延伸的工作要求，镇委研究决定切实加强村干部值班制度，现将有关事项通知如下：

一、值班对象

全镇所有村"两委"干部。

二、工作要求

1、实行村主职干部坐班，每周不少于5天时间，其他村干部轮流值一天班的值班制度。

2、值班时间一般为：上午 7∶30-11∶30，下午2∶30-5∶30。各村将值班人员姓名、职务、联系电话在村公开栏醒目位置予以公开，方便党员群众联系，接受社会监督。

3、按照"谁受理、谁处置、谁反馈"的原则，建立首问负责制，随时处理村内日常事务，帮助党员群众解决各种问题。对在轮值坐班时间内无法解决或需转交他人办理的事项，由受理人负责跟踪落实，并向当事人反馈办理结果，保证受理事项事事有着落，件件有回音。对不属于村级管理的事项，及时报告村 "两委"主要负责人，协调有关方面予以解决。

4、 严格值班纪律，提高办事效率，维护干部形象。

5、发生紧急重大事件，要及时向镇委、政府报告。

6、认真详细记录当天值班记录，确保痕迹化管理落实到位。

三、工作职责

1、清扫整理，搞好环境，干净卫生接待群众。

2、开门办公，服务群众，处理各类申请诉求。

3、搞好传达，加强联系，协调处理紧急事件。

4。做好记录，注重结果，确保事情落到实处

四、督查办法

1、各村值班督查情况列入年终党建工资考评，与村干部工作报酬、评先、责任追究挂钩。

2、市委组织部、镇委组织办定期或不定期检查各镇村干部轮值坐班的落实情况。并对村干部轮值坐班情况进行督检通报。

五、本值班制度从通知下发之日起实施。

中共多宝镇委办公室
