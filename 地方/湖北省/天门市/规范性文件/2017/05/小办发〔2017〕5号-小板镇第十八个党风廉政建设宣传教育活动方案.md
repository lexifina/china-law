# 小板镇第十八个党风廉政建设宣传教育活动方案

根据市委统一部署，今年5月在全镇开展第十八个党风廉政建设宣传教育月（以下简称“宣教月”）活动。为确保活动顺利开展，取得实效，制定如下方案：

一、活动主题

贯彻六中全会精神  推进全面从严治党。

二、指导思想

深入贯彻落实党的十八届六中全会精神，按照省纪委十届七次全会和市纪委八届二次全会的工作部署，强化“四个意识”，深入开展《关于新形势下党内政治生活的若干准则》《中国共产党党内监督条例》（以下简称《准则》《条例》）学习宣传，严肃党内政治生活，加强党内监督，推进全面从严治党不断向纵深发展，为建设小板“卫星乡镇”营造风清气正的政治生态。

三、活动内容

今年宣教月要重点组织开展好以下几项活动：

（一）开展落实党风廉政建设主体责任宣传活动。学习全市第十八个党风廉政建设宣传教育月活动方案，部署全镇第十八个党风廉政建设宣传教育月活动，营造落实主体责任的浓厚氛围。

（二）开展《准则》《条例》集中学习宣传活动。通过廉政党课、廉政讲堂、专题报告会、中心组学习、会前学习、支部学习等方式，组织党员干部深入学习《中国共产党章程》和《准则》《条例》，真正做到入脑入心。各级党组织都要利用党员固定活动日，举办以学习《准则》《条例》为主题的组织生活会，严肃党内政治生活，加强党内监督。

（三）开展重点领域和关键岗位党员干部廉政教育活动。5月中旬集中对全镇重点领域和关键岗位党员干部进行廉政教育，引导重点领域和关键岗位党员干部树立纪律意识、廉洁自律意识，筑牢拒腐防变的思想道德防线。由镇党委书记对重点领域、关键岗位领导干部进行廉政谈话。组织青年干部参观革命历史纪念馆和彭家垴烈士纪念园。

（四）开展家庭助廉活动。以“树清廉家风，创最美家庭”为主题，组织村及镇直单位主要负责人家属集中观看警示教育片，讲述廉政故事，教育引导领导干部家属增强廉洁意识，当好“廉内助”，筑牢家庭“防腐墙”。

（五）组织《准则》《条例》系列测试活动。以落实党建、党纪知识“随会学、随机考”制度为重点，建立测试题库，创新性地开展手机微信平台党建、党纪知识测试，形成党员干部认真学习、积极参加测试的浓厚氛围。加强对各地各单位开展测试情况的检查通报，确保测试活动全覆盖，无遗满。

（六）集中开展党风廉政警示教育活动。组织一定范围内党员干部阅读典型案件；各地各单位组织党员干部集中观看警示教育片，并进行深入讨论。通过开展多种形式的警示教育活动，特别是注意用好反面教材，用身边事教育身边人，促使党员干部知戒惧、明行止，达到拒腐防变、警钟长鸣的目的。

（七）开展廉政文化创建活动。探索新形势下反腐倡廉教育的有效途径和载体，开展革命传统文化、“陆羽茶廉”文化系列宣传活动。通过开展系列丰富多彩的廉政文化活动，加强廉政文化宣传，提升廉政文化感染力，增强党员干部文化自觉和文化自信，以优良党风带动社风民风。

四、组织领导

为确保宣教月各项活动的顺利开展，成立镇第十八个党风廉政建设宣传月活动领导小组，由镇党委书记黄祥斌任组长，纪委书记刘杰任副组长，党政办、纪委、组织、宣传、政法、妇联等相关人员为成员。领导小组下设办公室，办公室设在镇纪委办公室。

五、有关要求

（一）统一思想，提高认识。抓好党风廉政建设宣传教育是各级党组织的应尽之责。各地各单位党组织要切实履行好主体责任，主要负责人要带头履行好第一责任人责任，认真谋划、组织好宣教月的各项活动。各地各单位宣教月开展活动情况将纳入年底党风廉政建设考核内容。相关单位要发挥职能优势，主动配合，形成合力，确保宣教月活动顺利开展。镇纪委要积极组织协调，加强督办指导，对不认真履责的要严格问责追责。

（二）结合实际，狠抓落实。各地各单位党组织要充分认识开展此次宣教月活动的重要意义，在完成各项规定任务的同时，要围绕主题，结合自身实际，在教育活动的针对性、实效性上下功夫，创造性开展特色鲜明、效果显著的自办活动。

（三）注重总结，加强宣传。各地各单位要对开展宣教月的活动情况，取得成效进行总结，大力推广宣传教育中的好做法、好经验，加强对宣传教育月活动的宣传，注重活动的综合总结。
