# 2017年小板镇秸秆禁烧工作实施方案

为解决露天焚烧污染环境的问题，建设“生态小板”，根据《中华人民共和国大气污染防治法》、国务院《大气污染防治行动计划》和湖北省人民代表大会《关于农作物露天禁烧和综合利用的决定》的要求，制定本实施方案。

一、工作目标

以科学发展观为指导，以建设美丽小板、保护生态环境为目标，按照“属地负责、单位履职”的原则，全面落实禁烧责任，建立长效的管理工作机制，全面禁止露天焚烧农作物、杂草、生活垃圾。

二、实施步骤

（一）宣传发动阶段（4月25日一5月10日）

召开会议进行动员部署，明确任务，落实责任，健全机构，完善制度，建立高效运行机制；采取多种形式，大力宣传禁烧工作的重要意义，形成全社会广泛参与、农民群众自觉遵守的良好氛围。

（二）实施阶段（农作物收割期间）

各村组织专班，深入田间地头进行调查摸底，掌握作物收割时间，逐田块进行登记造册；同时，要加大巡查力度，及时制止和依法查处焚烧行为，收获季节实行24小时不间断巡逻检查。各相关单位要切实履责，依法、依规对焚烧的行为进行查处。

（三）总结验收阶段（农作物收割期后）

在各村自查和总结基础上，镇政府组织考评组分春秋两季对各村和有关单位工作情况进行考评，作为年底实绩考核的依据。

三、工作措施

（一）加强组织领导

成立小板镇禁烧工作指挥部，指挥长由镇长鲁鹏飞同志担任，副指挥长由党委副书记杨建华，纪委书记刘杰、副镇长、组织委员鲁泽会同志担任，成员由镇纪检办、宣传办、小板派出所、财管所、农技站、水管站、中心学校等单位主要负责人和全镇挂点机关干部及各村村委会主任组成。

指挥部下设4个督导组。每个督导组安排2-4名专人和1辆专车（由机关统一调配），对分管片区每天进行巡查督导（具体分组情况见附件1）。督导组设立综合办公室，办公室设在镇党政办，由刘潇同志兼任办公室主任，谢姜山、张涛红同志兼任办公室副主任，具体负责日常工作。

禁烧期间，督导组专班人员每天上午将前一天巡查情况形成巡查记录报综合办公室，下午2:30所有人员在镇机关集中后出发。

镇政府根据实际情况，安排禁烧工作专项经费，保障日常工作支出及各村秸秆集中收集堆放经费。

（二）落实工作责任

禁烧涉及范围广，难度大，各村、各有关单位要齐抓共管、形成合力，确保全面实现禁烧目标。

各行政村：按照"属地管理"的原则，各挂点机关干部为挂点村第一责任人，各村党支部书记、主任为禁烧工作直接责任人；同时，镇政府建立"镇领导包片、机关干部包村、村干部包组、组干部包田块"的长效管理机制。

镇财管所：负责筹措禁烧和综合利用工作经费。

镇派出所：对蓄意焚烧且造成严重后果的，按有关规定对直接责任人处以拘留并罚款，构成犯罪的，依法追究刑事责任。镇社会消防专队要严阵以待，一旦发现危害人民群众生命及财产安全的火灾要及时予以扑灭。

镇农技站：对农机使用进行监督管理，引导、鼓励本地和外地农机手购买、安装粉碎设备，推进农作物机械还田。

镇水管站：负责江河湖渠的巡查，防止农户随意丢弃，阻塞河道。

镇中心学校：负责在中小学开展禁烧的宣传教育活动，开展以“禁烧秸秆，保护环境，建设美丽天门”为主题的“小手牵大手”宣传活动，增强学生环保意识，通过学生影响家长，营造全民参与的禁烧氛围。

镇宣传办公室：负责禁烧及综合利用工作的宣传报道及广播、横幅、宣传车等宣传工作，充分发挥新闻媒体的舆论导向作用。

镇纪检监察办公室：负责对禁烧工作不力的地方、部门及人员进行效能追责。

（三）强化巡查监管

全镇要按照“空间覆盖无空白，职责落实无盲点，监督管理无缝隙”的要求，建立以各片为单位、村（居）为基础、村民小组为网格的管理体系，切实将监管责任落实到单位和个人。

收获季节，镇政府成立专班对各村进行督导，督促村干部加强巡查检查，尤其是重点时段、重点区域要24小时不间断进行巡查，努力实现"不燃一把火，不冒一处烟"的目标。挂点机关干部要与村干部一道对本村重点区域、田块进行巡查，督促本村及时解决禁烧工作中出现的困难和问题。督导组要每天对分管片区进行巡查，发现问题，及时督促整改。综合办公室要不定期通报各村火点情况，并将结果直接报镇党委政府主要领导。

（四）严格奖惩考核

春秋两季的收割期后，综合办公室要组织专班对各村、各单位的禁烧工作进行考核，对成绩突出的单位和个人，予以表扬和奖励。未发生焚烧的，给予该村2000元工作经费；对焚烧的，发现一起，通报一起，处理一起，每焚烧一亩（不足l亩的起火点按l亩计算），减少200元工作经费；对反复出现焚烧现象，或被上级环保部门发现火点与黑斑受到通报的，镇委镇政府将约谈该村主要负责人；对影响较大，累计焚烧面积较多，或因丢弃造成河道堵塞的，或被上级环保部门通报两次以上的，或因焚烧造成环境污染严重、交通堵塞的，由镇纪检监察办公室问责；情节特别严重，造成重大损失的，要依法追究刑事责任。
