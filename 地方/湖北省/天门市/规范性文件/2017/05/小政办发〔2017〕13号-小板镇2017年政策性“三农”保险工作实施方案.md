# 小板镇2017年政策性“三农”保险工作实施方案

为全面落实中央一号文件精神，建立健全全镇农业生产风险保障机制，促进农村经济持续健康发展，根据《省农业厅、省财政厅、省民政厅、省林业厅，湖北保监局关于印发湖北省2017年农业保险的工作实施方案的通知》（鄂农发 [2017]4号）及天政保[2017]2号文件精神，结合我镇实际，特制定本方案。

一、指导思想

以农业保险条例为指针，化解和防范农业风险为目的，以合规经营为重点，以加强监管为手段，以完善服务为抓手，积极稳妥开展2017年农险工作。

二、组织领导

成立小板镇2017年政策性“三农”保险工作领导小组，切实加强我镇政策性“三农”保险工作的组织、指挥、协调和督导。

组 长：鲁鹏飞

副组长：鲁泽会 吴 猛

成 员：吴明洋 张代忠 刘 潇 尹雯璟 陈 田

办公室设在镇农办、吴明洋同志兼办公室主任。

三、实施内容

（一）水稻保险。保险金额为每亩400元，保险费率6%，每季每亩保费24元，其中：中央财政补贴45%，每亩10.8元；省级财政补贴30%，每亩7.2元；农户承担25%，每亩6元。（人保财险公司承办）

（二）能繁母猪保险。保险金额为每头1000元，保险费率6%，每头保费60元，其中：中央财政补贴50%，每头30元；省级财政补贴30%，每头18元；养殖户承担20%，每头12元。（人保财险公司承办）

（三）奶牛保险。保险金额为每头6000元，保险费率6%，每头保费360元，其中：中央财政补贴50%，每头180元；省级财政补贴30%，每头108元；市财政补贴10%，每头36元；养殖户承担10%，每头36元。（人保财险公司承办）

（四）“两属两户”农房保险。保险金额为每户3000元，保险费率3‰，每户保费9元。其中：省级财政补贴70%，每户6.3元；市财政补贴30%，每户2.7元。（人保财险公司承办）

（五）棉花保险。保险金额为每亩400元，保险费率7%，每亩保费28元，其中：中央财政补贴40%，每亩11.2元；省级财政补贴25%，每亩7元；市财政补贴10%，每亩2.8元；农户承担25%，每亩7元。（人保财险公司承办）

四、工作步骤

（一）宣传发动阶段（5月中旬）

各片及涉农部门根据实情情况，充分利用电视、广播、墙报、农户告知单（水稻保险告知单填写并发放到户，农户签字认可）等方式大力宣传开展政策性"三农"保险的重要意义、方法、步骤及相关政策，让党和政府的惠农政策家喻户晓、人人皆知，使广大农民真正了解政策性"三农"保险的重要作用，增强保险和风险防范意识，提高参与"三农"保险的自觉性。

（二）水稻、棉花保险信息收集阶段。（5月25日-6月10日）

各村及涉农部门安排人力物力，开展信息收集工作，确保农户姓名、身份证号、投保面积、联系方式、“一卡通”账户或其他有效账户、开户银行等承保信息准确、真实、完整，镇财管所要做好承保信息的审核，确保工作合规。

（三）水稻、棉花承保公示、保费收取阶段（6月10日之前）

各村按保费方案，对收集的承保信息进行公示，并依法收取农户应承担的保费。各村在确保依法合规的前提下，对信息收集及保费收取工作可以同步进行。

（四）保单、凭证发放阶段

各村及涉农部门将保险承保后的保单、凭证及时无误地送到每个农户手中，确保凭证到户率达到100%。

（五）其他险种的实施（下半年）

能繁母猪、奶牛，“两属两户”农户保险到期后按时续保。

（六）查勘理赔阶段

根据标的物灾害损失情况，及时组织现场查勘，理赔公示、理赔到户工作。

五、工作要求

（一）加强领导，组建专班。各村、居委会及有关部门要充分认识推动政策性“三农”保险工作的重要性、必要性和紧迫性，加强领导，相互协作，共同抓好政策性“三农”保险工作。要按照镇政府的统一要求和部署，组建专班、强化措施，切实抓好政策性"三农"保险工作。

（二）早宣传、早启动。各村各涉农部门要提早充分利用电视、广播、墙报、网络等新闻媒体宣传政策性"三农"保险知识和政策。同时，通过召开村民政策性"三农"保险座谈会、编印张贴墙报、发放宣传资料等方式，深入宣传推广农业保险工作。

（三）履行职责，强力推进。镇涉农部门要协助做好投保品种面积确认，灾情核实、防灾防损工作。镇畜牧兽医部门要协助做好能繁母猪、奶牛的投保数量确认、死亡鉴定、防疫等工作。

（四）积极开展服务转型。承包机构要以实现"农民满意、政府满意、社会满意"为目标，积极推进政策性“三农”保险转型升级。一是转变推动模式。将启动时间由以往的四、五月份提前至1月份，将1月份确定为水稻保险工作推动月，确保基础工作在1月份取得实质进展。二是转变承保模式。按照"大户必保、散户尽保"的原则，20亩以上的种植大户单独承保，借助大户示范带动作用，全力争取散户投保。三是精简操作流程。水稻保险变凭证为告知单，将以往到户宣传、面积核实、入户收费、凭证发放同步进行，实现“四位一体”。种植大户的承保数据以农户签字的告知单为准，粮食直补面积仅投保时作参考依据。强化保费直收，对农户保费主推“直收”方式，主要依靠村级协保员直接上门收取。四是转变理赔模式。转变以往“集中报案、集中协商、集中赔付”的操作模式，变“集中”为“及时”。农户报案后，对明显不需要“二次查勘”的案件，要及时予以赔付，不得拖延。要确保足额赔付，坚持“据实赔付”的原则和“赔款到户”的原则，严禁“打包赔付”和“比例赔付”、严禁通过赔款返还农户保费。要通过转型升级，为农户提供更加优质便捷的保险保障服务，更好地将党的惠农政策落到实处。
