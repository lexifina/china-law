# 汪场镇人民政府办公室关于印发汪场镇植树造林方案的通知

各村(居)民委员会：

根据天政办发（2017）2号文件《关于天门市2017年植树造林方案的通知》的精神，结合我镇实际，制定本方案。

一、总体目标

巩固2015年和2016年绿满天门成果，完成市布230亩工程造林和600亩义务植树造林计划，全面建设绿色乡村示范村，建成汪场、雷场、艾垸绿化景观带，确保全镇绿化面积90%以上。

二、重点工作

1.绿色示范村建设

以汪场、雷场、艾垸、古堤等村为重点，打造花园走廊，汪场至雷场的2千米公路，古堤一组至八组的1800米村级路两旁种植单排景观树，树种以桂花、紫薇、红叶石楠小型树种为主，不影响农田作物的正常生长。各村主要道路、沟渠两旁宜植尽植，不能有空缺 。石潭、崔王、大兴等村要对去年栽植的景观苗木严格管理，确定补植数目，尽早补齐。

2.通道生态景观建设

以去年水毁林带为重点，对三叉沟、渔湖沟、保卫中心渠、革命渠、六三渠等重要渠道全线检查，重新栽植、补植，特别是三叉沟、渔湖沟公路，今后将是我镇居民的一个重要的休闲锻炼路段，要高标准全线绿化。以牛张公路、汪岳路、罗金路为重点，查漏补缺，对去年种植的树木进行普查，缺一棵补一棵，对砍伐地带进行复植。

3.成片造林

各村要对宜林地块进行规划，发动大户、吸引社会资金参与成片造林，对艾垸、雷场等村集中造林片块要积极组织，跟踪服务，落实责任人，高标准造林。

三、主要措施

1.加强领导，强化干部责任。

镇政府成立了以镇党委书记刘娟为组长，各职能部门参与的植树造林领导小组，负责对全镇的绿化工作进行总体规划、指挥、协调、考核，各村支部书记为村植树造林第一责任人，负责本村的绿化规划、植树、管护等。镇政府将与各村签订绿化责任书，明确工作职责，以植树量、绿化率、成活率为考核内容，制定奖惩措施。

2.加大资金投入，建好示范基地。

为调动各村各大户的植树积极性，镇政府将财政奖补资金的30%用于全镇绿化，重点用于绿色示范村的建设，先进村的奖励和林木管护。

3.任务分解到村，片块落实到人。

2月15日前，镇政府将全镇宜林面积和地块全部落实，分解到村，各村要因地制宜，采取多种形式落实植树任务，落实具体管护责任人，做到每一段林都有户主，每一棵树都有责任人。

4.严格补贴程序，保证各方利益。

按照市造林项目“谁造林，补贴谁”的原则，对植树一亩以上的成片林按每亩200元（含苗木费）的标准进行补贴，农户可以自购苗木，抢季节种植，然后申报。各村要对本村今年绿化面积摸好底，造好册，确定户主，统一申报，确认资格，对所有信息及补贴进行公示，阳光操作，接受社会监督。各地植树面积经市检查验收，确认成活后，即对户主发放补贴资金，资金打进惠农卡。

5.加强管护，确保成活。

林木的成活率是检验植树造林成果的唯一标准，不能年年栽树年年光，年年栽在老地方，各村要强化责任，加强管护，与责任人签订管护合同，保证今年林木成活率在90%以上。搞好树体修剪，病虫草害的防治，确保栽一棵，活一棵，栽一片，绿一片，用几年的时间把我镇的绿化率提高到95%以上，把我镇建设成为生态宜居的水乡园林城镇。
