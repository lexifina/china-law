# 关于印发《石家河镇2017年政策性“三农”保险工作实施方案》的通知

各村民委员会、镇直有关单位：

《石家河镇2017年政策性"三农"保险工作实施方案》已经镇政府同意，现印发给你们，请认真组织实施。

石家河镇人民政府办公室

2017年5月9日

石家河镇2017年政策性"三农"保险工作实施方案

为了认真贯彻落实省、市两级人民政府关于开展政策性"三农"保险工作的会议精神，切实做好我镇政策性"三农"保险工作，结合我镇实际，制订如下实施方案。

一、指导思想

深入贯彻落实科学发展观，以促进我镇农村经济的持续发展和农民收入的稳定增长为目的，切实推进政策性"三农"保险工作，建立健全农业保障体系，促进城乡协调发展，构建农村防灾减灾机制，维护农业生产环节稳定，保障农业和农民收益。

二、组织领导

镇成立政策性"三农"保险工作领导小组。组长：党委副书记、镇长陈春梅；副组长：党委副书记汪家祥、组织委员刘雄军；成员：张胜祖、万义传、刘春兵、张晓明、冯小仙、谭柳、苏世平、谭会明、郭璐琳、蒋刚兵、肖春舫、肖顺祖。领导小组下设办公室，刘春兵同志兼任办公室主任。

三、实施内容

（一）水稻保险。保险金额为每亩400元，保险费率6%，每季每亩保费24元，其中：中央财政补贴45%，每亩10。8元；省级财政补贴30%，每亩7.2元；农户承担25%，每亩6元。（人保财险公司承办）

（二）能繁母猪保险。保险金额为每头1000元，保险费率6%，每头保费60元，其中：中央财政补贴50%，每头30元；省级财政补贴30%，每头18元；养殖户承担20%，每头12元。（人保财险公司）

（三）"两属两户"农房保险。保险金额为每户3000元，保险费率30/00，每户保费9元，其中：省级财政补贴70%，每户6.3元；市财政补贴30%，每户2.7元。（人保财险公司承办）

（四）棉花保险。保险金额为每亩400元，保险费率7%，每亩保费28元，其中：中央财政补贴40%，每亩11.2元；省级财政补贴25%，每亩7元；市财政补贴10%，每亩2.8元；农户承担25%，每亩7元。（中华保险公司承办）

（五）油菜保险。保险金额为每亩200元，保险费率5%，每亩保费10元，其中：中央财政补贴40%，每亩4元；省级财政补贴25%，每亩2.5元；市财政补贴10%，每亩1元；农户承担25%，每亩2.5元。（太平洋保险公司承办）

（六）水产养殖保险（试点）。全镇养殖面积在30亩以上的规模养殖户和新型农业经营主体为试点范围。国元农业股份有限公司天门支公司与太平财产保险湖北分公司作为试点承办单位（具体乡镇由市水产局与上述两家公司共同确定），试点面积各5万亩。养殖品种为四大家鱼和小龙虾、河蟹、泥鳅、黄鳝等品种。主险：保险金额为2000元/亩（精养、特种养殖），保险费率4%，每亩保费80元，其中市级财政补贴70%，每亩56元；农户承担30%，24元。保险金额为600元/亩（自然水域半精养），保险费率6%，每亩保费36元，其中市级财政补贴70%，每亩25.2元；农户承担30%，10.8元。投保附加险具体见条款。

四、工作步骤

（一）宣传发动阶段（4月28-5月5日）

各村根据实际情况，充分利用电视、广播、报纸、网络、农户告知单（告知单填写并发放到户，农户签字认可）等方式大力宣传开展政策性"三农"保险的重要意义、方法步骤及相关政策，让党和政府的惠农政策家喻户晓，人人皆知，使广大农民真正了解政策性"三农"保险的重要作用，增强保险和风险防范意识，提高参与政策性"三农"保险的自觉性。

（二）水稻、棉花保险信息收集阶段（4月28-5月10日）

各村安排人力物力，开展信息收集工作，确保农户姓名、身份证号、投保面积、联系方式、"一卡通"账户或其他有效账户、开户银行等承保信息准确、真实、完整，同时乡镇财管所做好承保信息的审核，确保工作合规。

（三）水稻、棉花承保公示、保费收取阶段（5月5日-6月25日）

各村按保费方案，对收集的承保信息进行公示，并依法收取农民应承担的保费。各村在确保依法合规的前提下，对信息收集及保费收取工作可以同步进行。

（四）保单、凭证发放阶段（7月）

各村将保险承保后的保单、凭证及时无误地送到每个农户手中，确保凭证到户率达到100%。

（五）其他险种的实施（下半年）

能繁母猪、奶牛、"两属两户"农户保险到期后按时续保。油菜11月承保。

五、结账方案

（一）结账时间：5月10日至5月20日。

（二）结账办法：按时完成全额任务的给予工作经费。

对村的结账：任务在2万元以上的村发放1000元的工作经费；任务在1--2万元的村发放800元的工作经费；任务在5000--10000元的的村发放600元的工作经费；任务在5000元以下的村发放400元的工作经费。对棉花保险按时完成任务的村发放400元的工作经费。

各片工作经费根据各片任务完成情况由镇统一解决。

六、工作要求

各村要加大保险政策宣传力度，切实做好"三农"保险各项基础工作。保险凭证要落实到户，确保凭证信息准确；要依法收取及时上缴农民应承担的保费；要切实保障投保农户的利益，及时查勘定损，及时逐一赔付到户；不得弄虚作假、虚报投保数量；承保和理赔情况要张榜公布，不得以各种名义虚报、冒领、骗取赔付资金；要按期将"三农"保险的承保、理赔等情况报中国人民财产保险股份有限公司。
