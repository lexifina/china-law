# 关于印发市商务局“法律六进”活动实施方案的通知

市商业资产管理办公室、市市场物业开发管理局、市商务综合执法支队、市电子商务办公室，机关各科室：

为全面贯彻落实市委、市政府《关于印发天门市法治政府建设实施方案》（2016—2020年），推进“七·五”普法、依法治理工作深入开展，根据市普法办《关于在全市组织开展以“培育法治精神，强化法律意识”为主题的“法律六进”活动的通知》要求，结合商务系统实际，特制定《市商务局“法律六进”活动实施方案》。现印发你们，请结合各单位（部门）工作实际，认真贯彻落实。

附：《市商务局“法律六进”活动实施方案》

天门市商务局

2017年6月16日

市商务局“法律六进”活动实施方案

一、工作目标

以邓小平理论、“三个代表”重要思想、科学发展观为指导，认真学习贯彻党的十八届三中、四中、五中、六中全会和习近平总书记关于全面依法治国系列讲话精神，以培育法治精神，强化法律意识为主题，紧紧维绕“绿色引领、创新驱动、缩差争先、拼进十强”发展为主线，深入推进法律进机关、进乡村、进社区、进学校、进企业、进单位的“法律六进”活动。坚持理论联系实际、学用结合原则，推进领导干部和国家工作人员学法用法制度化、规范化，促进法治政府和法治天门建设。

二、主要活动形式和内容

1.坚持领导班子集体学法、年终述法。每周四机关和党组集中学习时，要安排一定的党规党纪和国家法律法规学习内容，并作好记录。领导干部年终述职要把述法作为一项重要内容摆进去。领导干部集体学法用法内容由局学法用法领导小组办公室组织提供。

2.坚持“谁主管谁普法，谁执法谁普法”责任制。各分管领导干部对自己分管的行业和部门的学法用法，要进行积极督导，抓好行业和部门的学法用法落实工作。执法部门要对自己的服务对象耐心普法，形成遇事讲法，执法活动依法，解决问题靠法的良好氛围。市普法办在通知中安排今年12月4日国家宪法日宣传活动的重点是对“谁执法谁普法”责任制落实情况，以展板，宣传册等形式集中展示，执法支队要高度重视，结合自己的工作实际，早谋划，早准备，突出商务特色，体现成果成效，作好文字和图像资料的收集整理，切实组织抓好宪法日宣传活动。其他业务部门也要在日常工作中注意向服务对象宣讲国家政策法规，特别是有关商务法律法规，日积月累，潜移默化。市商业资产办、市物管局，比照成立相应机构，具体负责组织实施本单位“法律六进”活动，并将有关情况及时报局“法律六进”活动领导小组办公室。

3.开展法律专题讲座活动。领导干部每年至少在集中学习活动中讲一次法律课，内容可以是综合性讲座，也可以结合工作实际讲专业性较强的法律法规知识。领导干部专题讲座时间另行提前通知安排，课后讲座影像资料和讲课稿（含给服务对象的普法活动）报局存档备查。

4.结合精准扶贫送法下乡。商务系统的精准扶贫工作队要把普法工作作为一项重要内容来落实。一是要积极宣传国家的精准扶贫政策精神，帮助落实好“五个一批”帮扶措施；二是要围绕社会保障救助、残疾人权益保护、生态环境保护、妇女儿童权益保护、村规民约等，开展送法下乡活动。有关影像资料、讲稿等要报局存档。

5.自觉落实无纸化学法用法及考试工作。商务系统所有工作人员今年都要完成40个学时2400积分的网上学法任务，内容包括《普法视频课件》和《考试复习指南》（2017年）两个部分,方法是登陆“湖北省国家工作人员学法用法及考试平台”（http://www.faxuan.net）。全市无纸化学法用法考试将于今年12月进行，请大家在此之前完成规定学时和内容，作好相关准备。

三、工作安排

6月中旬拟定下发实施方案，成立领导小组，并完成动员部署等相关工作。7月至11月上旬为组织实施阶段，按照学法用法的内容和形式组织落实。11月中下旬至12月为总结验收阶段，局学法用法办组织准备有关迎检资料，做好迎检工作。

四、工作要求

1.加强组织领导。局成立“法律六进”活动领导小组和办公室。党组书记、局长程志雄担任领导小组组长，党组副书记、贸促会会长袁友彬任副组长，彭碧银、匡晓斌、孙爽斌、徐文中、齐娜、王时中、胡朝阳等分管领导为成员。办公室设在贸促会，由田剑雄同志任办公室主任，负责分阶段组织实施“法律六进”工作，负责平时集体学法计划制定、记录整理归档和学法用法书目资料编印下发，负责在线学法用法的指导辅导和考试测试，负责按时向市普法办总结上报各种信息资料和迎检准备工作。

2.加强督导检查。“法律六进”活动是市委、市政府推进“七·五”普法，贯彻落实习近平总书记全面依法治国，建设法治政府的重要举措。各单位、部门要进一步提高认识，以高度地政治责任感和强烈地事业心抓好这项工作。办公室要以明察暗访等各种形式对活动开展情况进行督查检查，将有关情况在系统内通报，并作为今年履职尽责，述职述法的重要依据。

3.注重工作结合。要把“法律六进”活动与年度工作计划相结合，贯穿始终，把工作的出发点和落脚点放在围绕中心、服务大局、惠及民生上，促进商务系统各项工作任务的圆满完成。
