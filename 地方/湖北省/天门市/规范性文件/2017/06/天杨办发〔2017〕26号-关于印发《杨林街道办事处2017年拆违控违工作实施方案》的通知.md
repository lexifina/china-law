# 关于印发《杨林街道办事处2017年拆违控违工作实施方案》的通知

各村（居）民委员会、处直各单位：

为贯彻落实全市拆违控违工作会议精神，进一步改善办事处人居环境，推进美好乡村建设，规范城乡建设管理秩序，提升城镇品位和形象，坚决打击和遏制城乡违法建设行为，根据办事处实际，特制定如下实施方案。

一、指导思想

以《中华人民共和国城乡规划法》、《中华人民共和国行政处罚法》、《城市管理行政执法条例》等法律法规为依据，以自拆和强拆相结合，严厉打击违法建设行为，切实维护《城乡规划法》的严肃性，确保城市规划健康、有序实施。

二、工作目标

围绕“五城同创”建设，按照“统一领导、联合执法，部门协作、村（社区）联动，属地管理、依法行政、突出重点、稳步推进”的原则，着力维护城乡规划的严肃性、政府公信力和社会公平正义，坚决遏制违法建设蔓延势头，严力打击各类违法建设行为。依据《中华人民共和国城乡规划法》有关规定，全面清理、核查杨林街道办事处范围内的存量违法建设，并依法分类处置。同时，进一步巩固完善拆违控违动态巡查力度，依法逐步建立起科学有序的长效管理机制，力争违法建设“零增长”。

三、组织领导

为了加强拆违控违工作领导，确保拆违控违工作顺利开展，由杨林街道办事处和规划执法分局组建拆违指挥部，负责方案制定、前期筹备、组织召开部门协调会，以及现场拆违的总指挥工作。

指 挥 长：钱佳敏

副指挥长：刘国华 黄望阳

成　 员：黄 琳 肖敬宝 甘珍军 张陕兵 彭汉平 蔡明波

四、实施步骤

第一阶段：启动实施阶段（6月10前）

1、召开拆违控违工作会议，传达区拆违控违会议精神，对拆违控违工作进行全面动员部署，并通过印发宣传资料和利用媒体、横幅、标语、橱窗等手段，深入开展社会宣传。同时，充分发挥各村（社区）、各部门以及小区物业管理单位的作用，加强对干部群众的法制宣传和教育，形成拆违控违的强大声势和浓厚氛围。

2、各村（社区）、各部门制定本地、本部门拆违控违工作方案。

3、利用广播电视、网络媒体、简报、专栏等形式，广泛深入地宣传拆违控违工作，提高广大干部群众的法律意识、环境意识、文明意识和参与意识，为拆违控违工作提供强有力的舆论支持。

第二阶段：摸底清查阶段（6月11日—6月30日）

各村（社区）、各部门在杨林街道办事处范围内开展一次违法建设（含构筑物）调查摸底工作，对拆违控违范围内的建筑物（构筑物）注明具体地点、形成时间、面积大小、单位名称和当事人姓名等要素，逐一登记造册，所有违法建设要做到一案一表、信息准确，分村（社区）、住宅小区登记造册；于6月28日前报送至规划执法分局。规划执法分局、规划管理分局要加强业务指导和督促检查，确保数据全面准确。

1、各村（社区）负责本辖区范围内违法建设的摸底调查。

2、规划管理分局牵头，规划执法分局、小区所在村（社区）、各小区物业配合，负责对住宅区的违法建设进行摸底调查。

第三阶段：全面整治阶段（7月1日—11月30日）

规划执法分局要认真分析调查摸底情况，围绕工作重点，明确执法主体，严格依法立案查处，对依法必须拆除的，责令限期拆除。同时各村（社区）、相关部门要组织干部，对违建户上门宣传拆违控违政策，动员自行拆除或整改，自行拆除确有困难的可以实施助拆。逾期不自行拆除的，依法强制拆除。对依法强制执行过程中遭遇暴力抗法及执法人员和相关工作人员遭到打击报复的，由公安机关依法坚决打击，涉及党员和干部的由办事处纪委坚决查处。

第四阶段：巩固提高阶段（12月1日—12月31日）

1、违章建筑拆除（整治）后，规划管理分局指导各村（社区）、小区物业管理单位严格按照总体规划，统一抓好环境整治和绿化、美化工作。

2、按照属地管理的原则，各村（社区）以及小区物业管理单位要切实加强对辖区内居民和农户的日常教育、管理，建立健全一系列规章制度，严控新的违法建设。

3、认真总结工作经验，巩固、扩大成果，建立拆违控违长效管理机制。

五、工作要求

（一）加强领导，落实责任

各村（社区）、各部门要充分认识实施拆违控违工作的重要性、艰巨性、复杂性，统一思想，坚定信心，精心组织，攻坚克难。要根据办事处党委、政府的统一部署，成立相关组织机构，加强组织领导，树立大局意识、建立领导负责制，落实常态管理责任制，实施责任追究，加强沟通配合。

（二）精心组织，严肃纪律

各村（社区）、各部门要根据本实施方案，认真制定本辖区、本部门拆违控违工作的具体实施方案，建立明确的工作责任制度、定期反馈报告制度，将任务、责任、进度分解落实到人，做到分工明确，责任落实。各村（社区）、各部门要切实履行好属地管理原则，加大日常巡查管控力度，坚决管住、管好节日期间违法建设的行为的发生。在查处违法建设过程中，实行严格的问责制度。对在职责范围内必须拆除，拒不履行职责、不作为的单位负责人和直接责任人，办事处纪检、组织等部门要追究行政责任或给予纪律处分。

（三）依法行政，维护稳定

各村（社区）、各部门在拆违控违工作中要坚持原则，严格依法办事，坚决整治和拆除违法建设。在具体实施过程中，要注意工作方法，正确处理好依法行政与维护稳定的关系，特别是对弱势群体、少数确有特殊困难的群众，应落实好各项帮扶救助措施。要做好维护稳定工作预案，对矛盾突出的案件予以妥善处理，防止矛盾激化，确保各项工作到位，杜绝恶性事件的发生。

（四）广泛宣传，深入引导

要充分发挥新闻舆论的导向作用，加大相关法律法规的宣传和教育力度，对典型违法建设案例进行公开曝光。同时，要深入细致地做好思想政治工作，讲清说透违法建设的严重性、危害性，宣传查处违法建设的重要性和必要性，引导和教育广大群众自觉遵纪守法，支持和拥护违法建设的依法查处工作。

（五）长效管理，巩固成果

违法建筑拆除后，要按照“属地管理”、“谁主管、谁负责”的原则，建立目标管理责任体系和长效管理机制，切实巩固拆违控违工作成果，坚决杜绝出现新的违法建设，不断提升市容环境质量和城乡建设管理水平。　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　 天门市人民政府杨林街道办事处办公室
