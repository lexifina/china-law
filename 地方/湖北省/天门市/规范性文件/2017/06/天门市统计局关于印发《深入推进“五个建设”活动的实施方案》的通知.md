# 天门市统计局关于印发《深入推进“五个建设”活动的实施方案》的通知

为贯彻落实全省“学习贯彻十八大、争创发展新业绩”主题实践活动动员会及市委、市政府关于深入推进“五个建设”活动的通知（天文〔2013〕3号）精神，局党组决定，今年继续深入推进“五个建设”活动。现制定实施方案如下：

一、指导思想

以邓小平理论、“三个代表”重要思想和科学发展观为指导，以深入学习贯彻党的十八大精神为主线，以市委、市政府提出的实施“三大战略”、推进“四个跨越”、努力建设开放型“四化”同步发展先行区主题，团结带领机关党员干部真抓实干、竞进提质，为天门科学发展、跨越式发展贡献更大力量。

二、主要目标

——深化学习增信念。通过深化学习、领会实质，进一步增强对中国特色社会主义的信心，坚定道路自信、理论自信和制度自信。着力激发党员干部 创先争优意识和干事创业激情，以饱满的政治热情和昂扬的工作状态，积极投身天门跨越式发展的宏伟实践。

——转变作风树形象。严格贯彻执行中央、省委、市委关于进一步改进干部作风有关文件精神，切实转变作风，树立良好形象，以良好的党风带政风促民风，在全局上下形成艰苦奋斗、求真务实的良好风尚。

——服务群众惠民生。坚持以人为本、执政为民，围绕人民群众最关心最直接最现实的利益问题，动员组织机关干部深入基层联系服务群众，建立健全联系服务群众长效机制，进一步提高人民群众物质文化生活水平。

——优化功能强组织。认真贯彻落实《2013—2017年湖北省党的基层组织建设工作规划》，进一步优化组织功能，增强组织活力，全面加强基层服务型党组织建设，不断提高基层党建工作科学化水平。

——实干创新促跨越。动员全局上下全面实施“三大战略”，稳步推进“四个跨越”，努力争当全省“四化”同步发展先行区，推进县域经济跨越进位。

三、主要内容

（一）深入推进能力素质建设

继续深入推进学习型机关创建和岗位练兵活动，大力加强公务员能力席位建设，增强党员干部危机意识和学习意识。组织党员干部学习电子政务知识，全面推行电子政务。充分利用周四集中学习机会，加强机关干部学习培训。通过参加省级市级各类专题班、研讨班等形式，加强十八大精神的学习培训，加深党员干部对十八大精神实质的认识和理解。

（二）深入推进干部作风建设

紧紧围绕为民务实清廉的目标，切实做好干部转变作风、联系服务群众的工作。继续开展“三万”、“城乡互联、结对共建”、“四访促和谐”等活动，切实做好机关联系基层、干部联系群众的工作。严格落实中央八项规定、省委“六条意见”、省统计局“十五条规定”和天门市委改进干部作风《实施意见》及新的“六条禁令”，开展“刹三风”（抹牌玩乐风、大操大办风、奢侈浪费风）、“解三难”（群众办事难、工作落实难、基层组织建设难）活动。大兴狠抓落实之风，把工作重点转移到抓发展、办实事上来。机关党员干部要带头争做学习型、创新型、服务型、效能型、节约型、廉洁型干部，严格照章办事，推行政务公开，提高办事质效，努力建设行为规范、运转协调、公正透明、廉洁高效的行政机关，树立统计人良好形象。

（三）深入推进发展环境建设

1．切实加强人文环境建设。一是充分利用政府门户网站、统计内网和外网倡导诚实守信、互利互赢的发展理念，大力弘扬侨乡精神、陆羽文化，广泛宣传天门近年来的新变化、新成就，提升天门的人气士气，提升天门的知名度、美誉度，激发广大统计干部热爱天门、建设天门的自豪感和责任感。二是积极参与天门网上“市委书记专属版”互动活动，主动回应网络舆情和网民关心关注的问题。三是结合统计部门的工作实际，开展丰富多彩的“双创”文艺活动。开展“我身边的优秀共产党员”推荐活动，评选和表彰优秀共产党员、优秀公务员等先进典型，在全局营造比、学、赶、超的良好氛围。

2．优化企业发展环境。一是继续执行服务企业“十条禁令”，不向企业收取服务费，不向企业吃拿卡要，维护企业正常生产秩序。二是经常深入重点企业调查研究，了解和向上级领导反映企业生产经营过程中的各种困难和问题，帮助企业排忧解难。三是和重点企业建立联席会议制度，主动为企业提供各类统计信息，向企业宣传党的各项优惠政策，引导企业健康、良性发展。继续开展“五亮”（亮身份、亮职责、亮承诺、亮点评、亮评议）、“五比”（比素质、比干劲、比奉献、比创新、比作风）、“五创”（创一流部门、创一流队伍、创一流服务、创一流业绩、创一流形象）和“三评两促”活动，提高服务意识，提升服务水平。坚持为企业发展提供“绿色通道”和“直通车服务”。

（四）深入推进基层组织建设

继续巩固基层组织建设年活动成果，继续深化“五个基本”建设。一是规范党组织班子和队伍建设。按照《中国共产党章程》的要求，加强两个基层支部建设。党组织班子健全、委员分工明确，团结协调，活动正常，认真参加有关培训。加强休干党支部建设，关心和发挥退休干部党员的作用。加强对工青妇等群众组织的领导。定期研究机关群团工作，完善党建带机关群团建设机制。二是重视发展党内民主。认真落实《中国共产党党员权利保障条例》，建立和完善党内情况通报制度、情况反映制度和重大决策征求意见制度，积极推进党务公开，增强党组织工作的透明度。尊重党员干部的知情权、参与权、监督权，使党员干部在参与单位的民主管理、民主监督中做到先知、先议、先行，激发党员的责任性，体现表率作用。严格执行民主生活会制度，着力提高民主生活会质量。三是加强党风廉政建设。有专人分管，廉政制度健全，注重落实；廉政教育有力，按照《中国共产党章程》和《廉政准则》等规定，对党员特别是党员领导干部实行有效监督；按照有关规定查处违纪案件。四是发展党员工作规范。按照“坚持标准、保证质量、改善结构、慎重发展”的方针，有计划地做好发展党员工作，做到手续完备、程序规范。探索疏通党员出口的有效途径。五是规范党员管理工作。按照《中国共产党章程》和中央的有关规定，安排好党的组织生活，使党员认真履行义务，正确行使党员权利。六是规范思想政治工作。深入细致地、创造性地开展思想政治工作。切实抓好政治理论学习和党课教育，加强社会主义核心价值体系建设，不断以马克思主义中国化的最新理论成果武装党员，提高党员干部的思想政治素质。

（五）深入推进重大项目建设

按照市政府的要求，继续开展重大项目建设活动，积极配合有关部门做好重大项目的入库、申报工作，做到不遗、不漏、不重、不错，严把数据质量关。积极服务招商引资，大力开展招商引资，加大招商引资宣传力度，营造良好的招商氛围。

四、活动步骤

整个活动从2013年3月开始，至12月结束，具体分为宣传发动、推进实施、总结提升三个步骤。

（一）宣传发动（3月5日以前）。召开领导小组会议，成立工作专班，制定活动方案。3月5日以前，召开全局深入推进“五个建设”活动动员大会，进行安排部署。

（二）推进实施（3月5日至11月底）。按照活动总体方案，逐项推进实施。

（三）总结提升（12月）。各科室认真总结活动开展情况和经验做法，形成务实管用、简便易行的制度成果，探索增强内生动力、推动科学发展的长效机制。

五、组织领导

1．加强领导，落实责任。市统计局成立深入推进“五个建设”活动领导小组，党组书记、局长任组长，党组成员、副局长等任副组长，成员由局机关各科室负责人担任。领导小组下设办公室，具体负责全局“五个建设”活动的组织谋划、工作推动、综合协调、检查督办。办公室设在局办公室。

2．统筹结合，精心安排。把开展主题实践活动与推进和服务各项工作结合起来，做好统筹文章。做到紧密联系实际，科学制定方案，周密安排部署，扎实有效推进。使得主题实践活动与各项工作相得益彰，两不误，两促进。

3．加强督导，整体推进。要把主题实践活动纳入各科室年度考评和业务工作考评内容，作为评先评优的重要依据，确保活动取得实效。
