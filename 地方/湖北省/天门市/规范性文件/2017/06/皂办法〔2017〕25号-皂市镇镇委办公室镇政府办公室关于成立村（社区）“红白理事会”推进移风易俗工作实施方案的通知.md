# 皂市镇镇委办公室镇政府办公室关于成立村（社区）“红白理事会”推进移风易俗工作实施方案的通知

各村（社区）党组织、各村（居）民委员会：

《皂市镇成立村（社区）"红白理事会"推进移风易俗工作实施方案》已经镇党委、政府研究同意，现印发给你们，请按照要求认真抓好落实。

中共皂市镇委办公室　　 皂市镇人民政府办公室

2017年6月7日

皂市镇成立村（社区）"红白理事会"推进移风易俗工作实施方案

为遏制农村陋习，树立文明乡风，根据天门市精神文明建设委员会天文明委[2017]5号文件精神要求，在2017年底前，全市行政村普遍建立红白理事会，切实推进移风易俗工作。为确保此项工作在我镇全面推进落实，结合我镇实际，特制定本实施方案。

一、指导思想

深入贯彻落实习近平总书记重要指示精神，坚持以社会主义核心价值观为引领，进一步破除社会陋习、倡树社会新风，推进移风易俗，按照"婚事新办、丧事简办、其它事不办或少办"的原则，狠刹"红白事"大操大办、人情债、攀比炫富等不正之风，达到淳化乡风民俗、减轻群众负担、体现组织温暖、融洽干群关系的目标。

第一组长：程应强

副 组 长：郭银官 高社芳 陆 平 汪爱玲 方同兴

三、时间要求

各村在2017年6月10日前召开党员大会，进行宣传动员，2017年6月30日前成立"红白理事会"，通过"红白理事会"章程，7月10日前完成"红白理事会"备案登记，正式启动实施。

四、实施要点

（一）意义要宣传到位

1、有利于革除婚丧陋俗、倡树文明新风。成立"红白理事会"，大力提倡丧事简办、婚事新办，提倡"礼轻情重"、提倡环保低碳，必将推动农村移风易俗工作不断深化，中华民族优秀传统文化必将得到弘扬和继承。

2、有利于减轻群众负担、抑制奢侈浪费。"红白理事会"明确"红白事"操作规范和标准，重点对办事待客范围、就餐桌数、饭菜烟酒标准、礼金标准进行大幅限制，提倡节俭操办红白喜事，及时制止大操大办行为，有利于减轻群众负担、抑制奢侈浪费。

3、有利于提高社会管理能力、凝聚发展合力。"红白理事会"在村"两委"的指导下参与"红白事"的组织工作，以组织名义操持群众庆典，约束事主节俭办事，既喜庆热闹又移风易俗，体现了基层组织对村民的关怀。更重要的是理事会以"会员之家"的形式让群众自觉参与，在增强群众对村级组织的归属感和认同感的同时，必将提升基层治理能力，凝聚发展合力。

（二）做法要合理可行

1、理事要村民公认。在村党支部的领导下成立 "红白理事会"，可根据本村（社区）人数和实际情况设顾问1名、理事长1名、常务理事1名、理事3至5名。一般建议由村党组织书记担任顾问，村乡贤担任理事长。"红白理事会"要充分尊重当地民俗，开展义务服务活动，不发放任何补助。常务理事一般由其他村干部及退休村干部、在当地威望较高的老党员、老同志、乡贤等组成；理事会成员一般由村两委成员、小组长、村民代表等组成；监事会成员一般由村务监督委员会成员组成。

2、章程要操作可行。红白理事会要严格遵守婚姻、殡葬等方面法规制度，在符合当地风土人情、尊重社情民意的基础上，制定理事会活动章程、办事程序、服务规范、待客及礼金标准、参加人数等移风易俗、减轻群众负担的具体措施。《章程》要细化、操作可行，要明确职责任务、纪律要求、工作制度，特别是要将"红白事"举办规模、宴席标准、设宴桌数、禁止封建迷信等内容，在理事会《章程》中进行细化明确。

3、实施要因地制宜。理事会工作服务流程、活动方式要根据本村民俗因地制宜，不要求"一刀切"。 红白理事会成员的拟选名单、《章程》必须事先广泛征求群众意见，再按照党支部提议、村两委会商议、党员大会审议、村民代表会决议"四议两公开"工作法程序进行产生。

4、经费保障要有力。要确保"红白理事会"有钱开展赠送或慰问等服务活动。经费筹措渠道有以下几种：村组积累、社会捐赠、政府资助、村民自筹等方式。

五、工作要求

1、落实工作责任。明确蹲点机关干部为此项工作的直接责任人，负责所联系村"红白理事会"的成立，并加强组织领导，做好业务指导、工作督促等工作；镇纪委、党政办、宣传办负责对全镇"红白理事会"工作开展情况进行具体指导和监督管理。镇民政办要加大对红白理事会的监管力度，严格控制婚丧事规模和标准。村党组织书记为所在村具体责任人。"红白理事会"的成立和组织工作要通过示范带动、整体铺开的形式在全镇迅速推进，全镇上下要将此项工作作为加强基层组织建设和服务人民群众的一项重要任务抓好落实。

2、强化考核激励。镇党委将把成立"红白理事会"推进移风易俗工作纳入对基层党建工作的考核内容。各村（社区）要将此项工作摆上重要议事日程，进行专题研究、重点部署、积极推进。要加强考核督查，对"红白理事会"作用发挥不好，出现大操大办婚丧嫁娶的村（社区），实行一票否决，不纳入评先评优的评选范围。同时，对大操大办婚丧嫁娶、乱搞封建迷信活动的党员干部，严肃党纪处分。

3、广泛宣传引导。各村（社区）要结合"两学一做"学习教育，充分利用党支部主题活动、"村村响"广播、微信群、户外宣传栏等平台载体，广泛宣传设立"红白理事会"的目的意义，积极宣传勤俭节约的先进典型，曝光大操大办的反面典型，用民间舆论的力量引导群众自我约束、自我管理、自我提高，让文明乡风新观念深入人心。
