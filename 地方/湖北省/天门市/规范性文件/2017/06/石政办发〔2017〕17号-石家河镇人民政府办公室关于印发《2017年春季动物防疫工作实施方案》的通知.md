# 石家河镇人民政府办公室关于印发《2017年春季动物防疫工作实施方案》的通知

为了认真贯彻执行《中华人民共和国动物防疫法》切实抓好我镇动物防疫工作，确保我镇畜牧生产持续稳定发展，根据省、市农村工作会议精神，特制定2017年春季动物防疫工作实施方案。

一、指导思想

以省市动物防疫会议精神为指导，以《动物防疫法为依据》，以"无规定疫病区"和"放心肉工程"建设为动力，以"两瘟两病"防疫工作为重点，以农民增收为目的，坚持预防为主的方针，依法防疫，控制动物疫病，降低发病死亡率，促进我镇畜牧小区建设快速发展。

二、组织领导

组 长：熊胜军

副组长：陈春梅　 汪家祥

成 员：张胜祖　 谭会明　 万义传　 苏世平　 徐团员

余 晨　 刘春兵　 肖家彪

领导小组下设办公室，办公室设在畜牧服务中心，肖家彪任办公室主任。

三、工作任务

1、生猪防疫：重点预防猪瘟、五号病，密度分别达100%。

2、耕牛防疫：重点预防五号病，炭疽和四虫联检，密度分别达到100%、100%、70%。

3、禽类防疫：重点预防鸡新城疫，禽流感，密度分别达到100%。

4、狂犬病、禽霍乱以及其它特种疫苗防疫注射，完成分布任务。

四、时间安排

第一阶段：组织动员，准备阶段

1、3月28日，召开防疫工作动员大会，组建防疫专班，落实领导，落实人员，划定区域，落实任务。

2、3月29日，到市领取春防器械、疫苗、表、证等物品；

第二阶段：防疫实施阶段

1、4月1日至4月12日，用12天时间集中力量，对耕牛口蹄疫进行防疫；

2、4月13至4月24日，用12天时间分散人员，对牲猪猪瘟、口蹄疫进行防疫；

3、4月25日至5月5日，用11天时间，对鸡瘟、禽流感进行防疫；

4、5月6日至5月10日，用5天时间，查漏补注；

5、5月11日至5月20日，用10天时间，以片为单位，由防疫专班统计表格，并整理规范上交镇防治中心。

第三阶段：检查验收阶段

1、5月21日至5月23日，用三天时间镇组织检查验收，并根据验收结果与年初所签责任状要求记分，结算到村、到人；

2、6月上旬接受市春防检查验收。

五、工作要求

1、加强对春防工作的领导

中心领导在防疫期间，深入防疫一线，与防疫人员同吃、同住、同工作，加强检查督促、解决实际问题。

2、加强整体意识和组织纪律

在防疫期间，做到四统一、四不准。

四统一即：统一领导、统一布置、统一时间、统一要求。

四不准即：不准单干、不准酗酒闹事、不准赌博抹牌，不准请假。

3、加强技术操作规程实施

防疫中要做到七个一，五把关，三不打、四不漏。

七个一即：一组一村干部带队，一组一消毒；一畜一针头，一畜一棉球，一猪一卡耳，一畜一登记，一天一领苗，一组一消毒瓶。

五把关即：消毒关、冷藏关、登记关、卡耳关、补注关。

三不打即：病畜和疑似病畜不打，临产母猪不打，未满月仔猪不打（要作好登记补注）。

四不漏：不漏一村、不漏一组、不漏一户、不漏一头。

六、加强检查验收，奖惩结账

防疫结束后，由镇政府和兽医服务中心组织人员逐村抽签检查验收，主要检查各项防疫密度、操作技术、防疫效果、村干部带队、防后群众反应等。其检查结果按年初责任状结算到人。
