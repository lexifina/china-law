# 麻洋镇委办公室麻洋镇政府办公室关于成立麻洋镇农村产业融合发展工作领导小组的通知

各党总支、支部，各村（居）民委员会、镇直各单位：

为贯彻落实今年中央一号文件、《国务院办公厅关于推进农村一二三产业融合发展的指导意见》（国办发〔2015〕93号）和今年省委一号文件、《湖北省人民政府办公厅关于推进农村一二三产业融合发展的实施意见》（鄂政办发〔2017〕1号）等文件精神，加快推进我镇农村产业融合发展，特成立麻洋镇农村产业融合发展工作领导小组，其组成人员如下：

组　长：周　超

副组长：梁文江、彭志中

成　员：胡振宇、黄　锋、孔维新、陈　洋

曹于慧、刘　勇

领导小组下设办公室，孔维新同志兼任办公室主任，彭俊鹏同志任办公室副主任。

中共麻洋镇委办公室　　麻洋镇人民政府办公室

2017年5月12日
