# 黄潭镇成立污水处理厂领导小组的通知

闵卡波　 村镇建设服务中心主任

张开忠　 国土资源所所长

杨建波　 黄潭电工组组长

张进祥　 人社中心主任

向小雅　 水管站站长

江月林　 西庙村党支部书记、主任
