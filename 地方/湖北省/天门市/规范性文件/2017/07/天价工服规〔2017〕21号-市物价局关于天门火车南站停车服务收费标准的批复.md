# 市物价局关于天门火车南站停车服务收费标准的批复

武汉捷泊智能停车有限公司天门分公司：

你公司《关于天门火车站申请停车费调整》收悉。为加强停车场管理，提高停车场资源利用率，合理疏导车辆，方便接送旅客，同时也为提高服务质量。根据《湖北省机动车停放服务收费管理办法》（鄂价工服〔2016〕151号）的相关规定，并结合我局成本调查监审分局《关于天门市火车南站机动车停放保管服务定价成本监审报告》（天价成监〔2017〕1号）。经研究，现就你公司停车服务收费有关问题批复如下：

一、停车服务实行计时收费。车辆进入30分钟内免费。

二、停车服务收费标准：中、小型车辆1小时以内收费4元，每增加1小时加收1元；停车不足1小时按1小时计收；一次停车24小时以内，最高不超过20元。超过24小时另按以上规定标准计时收费。

三、军车、警车等执行公务的车辆，消防车、抢险救灾车、市政工程车、救护车等执行任务的车辆免收停车服务费。

四、实施收费时，应在收费地点公示收费依据、收费标准、投诉电话，接受社会监督。

本批复自2017年7月5日起执行。
