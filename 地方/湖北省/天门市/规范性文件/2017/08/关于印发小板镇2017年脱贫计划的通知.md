# 关于印发小板镇2017年脱贫计划的通知

各村、市驻村工作组：

根据市扶贫攻坚领导小组《关于印发2017年脱贫计划的通知》（天扶组办发〔2017〕48号）要求，我镇2017年脱贫计划调整为贫困人口脱贫269人，贫困村出列1个。为了进一步强化各村扶贫开发主体责任，明晰扶贫攻坚任务，现将2017年脱贫计划以工作组为单位进一步予以明确。

各村、工作组要充分认识脱贫攻坚的长期性、艰巨性、复杂性，认真实施精准扶贫、精准脱贫方略，采取有效措施，加大工作力度，确保完成脱贫计划任务。要进一步压实脱贫攻坚责任，精准帮扶到村到户到人，实现精准脱贫。要加大监督检查力度，防止虚假脱贫、数据脱贫，确保脱贫质量。

专此通知。

中共小板镇委办公室 小板镇人民政府办公室

2017年8月5日
