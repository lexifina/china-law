# 皂市镇人民政府办公室关于印发《皂市镇家庭医生签约服务工作实施方案》的通知

各村、居民委员会，镇直有关单位：

经镇政府研究同意，现将《皂市镇家庭医生签约服务工作实施方案》印发给你们，请认真贯彻落实。

皂市镇人民政府办公室

2017年8月17日

皂市镇家庭医生签约服务工作实施方案

为充分发挥家庭医生"居民健康守护人"作用，助力分级诊疗，根据国务院医改办、国家卫计委等七部门联合印发的《2016年关于推进家庭医生签约服务的指导意见》（国医改办发〔2016〕1号）精神，结合我镇实际，制订本实施方案。

一、工作目标

2017年12月底，家庭医生签约服务覆盖率达到常住人口100%，重点人群签约服务覆盖率达到100%，贫困人口签约服务率达到100%，基本实现家庭医生签约服务全覆盖。

二、基本原则

坚持"五个结合"，即自愿签约与政策引导相结合，门诊签约与上门签约相结合，基础服务与个性化服务相结合，村医服务与团队服务相结合，区域划分与有序竞争相结合。

三、主要内容

（一）服务主体

服务主体为皂市中心卫生院家庭医生团队和乡村医生。

天门市第一人民医院指导医生为家庭医生团队提供技术支持和业务指导、开展人员培训带教，衔接双向转诊等。

皂市中心卫生院负责组建9个家庭医生团队，由临床或全科医生、护士、公共卫生医师等组成，一个团队服务不多于5个村，一个团队不少于4个人，每个团队明确第一责任人。负责签约对象的基本医疗服务、基本公共卫生服务、重大公共卫生服务、计划生育免费服务、健康干预服务等。

乡村医生负责做好签约对象的沟通联络工作，协助团队开展健康教育、宣传，信息收集，基本医疗服务、公共卫生服务等工作。

（二）服务对象

家庭医生签约服务优先覆盖贫困人口、老年人、孕产妇、儿童、残疾人以及高血压、糖尿病、结核病等慢性疾病、严重精神障碍患者等重点人群，在此基础上，逐步扩大签约范围。

（三）服务内容

家庭医生签约服务主要包括基本医疗服务、基本公共卫生服务、重大公共卫生服务、计划生育免费服务、健康干预服务等5个方面。

1、基本医疗服务。家庭医生为签约居民提供常见病、多发病的初级诊治，推行分级诊疗，需要转上级医院诊疗的病人，家庭医生要及时提供转诊服务并履行转诊手续。

2、基本公共卫生服务。家庭医生要以签约居民需求为导向，按照《国家基本公共卫生服务规范》第三版要求，认真落实12类46项基本公共卫生服务项目，以65岁以上老年人、0-6岁儿童、孕产妇、慢性病人、严重精神障碍患者、结核病患者等重点服务对象，实行包户责任制开展健康管理、上门访视、家庭康复指导等服务工作。

3、重大公共卫生服务。家庭医生加强与妇幼保健机构衔接，为签约对象中的孕产妇提供免费预防艾滋病、乙肝、梅毒母婴传播项目；农村妇女宫颈癌、乳腺癌检查项目及增补叶酸预防神经管缺陷等服务。

4、计划生育免费服务。家庭医生加强与妇幼保健机构衔接，为签约对象中的相关人群提供免费婚前医学检查服务、免费孕前优生健康检查服务、免费计划生育手术技术服务、免费发放计划生育药具服务、免费计划生育手术并发症鉴定服务、免费计划生育病残儿医学鉴定服务。

5、健康干预服务。鼓励家庭医生开展以健康管理为主要内容、以主动服务为主要形式的个性化服务，如健康咨询、中医保健、药品代购、康复协助、化验检查等。

（四）服务包设计

1、免费包。适用于所有居民，提供基础的基本医疗、基本公共卫生、重大公共卫生、计划生育免费服务。

2、优惠包。皂市中心卫生院已经结合本单位实际，设计体检优惠项目，优惠幅度20%。优惠项目不受公共卫生签约服务项目限制。

（五）签约方式

在双方充分了解家庭医生签约服务内涵的前提下，家庭医生团队和乡村医生组织辖区居民以户为单位上门服务的形式签订协议，明确签约服务内容、方式，双方的责任、权利、义务等事项。家庭医生应根据辖区居民意向和自身服务能力，合理引导居民进行签约。家庭医生签约服务原则上一年一签，期满后居民可选择续（解）约或另选团队签约。

（六）经费渠道

家庭医生团队为签约对象提供约定的签约服务，根据签约服务人数按年收取签约服务费，由医保基金、公共卫生服务经费、计划生育免费服务项目经费等分担。签约服务中的基本公共卫生服务项目费用从基本公共卫生服务专项经费中列支。

四、实施步骤

（一）筹备阶段（2017年7月底前）。镇政府制定家庭医生签约服务实施方案，召开启动会。皂市中心卫生院确定签约服务包，组建家庭医生团队。

（二）运行阶段（2017年12月底前）。皂市中心卫生院对照实施方案，制定相关工作规范和配套政策。镇工作专班加强工作督导，推进工作落实。

（三）考核阶段（2018年1月底前）。镇政府组织专班对家庭医生团队服务开展情况进行评价考核。

五、组织领导

为确保皂市镇家庭医生签约服务作顺利开展，镇政府成立领导小组，各村（居）委会也要相应成立工作专班。

六、保障措施

（一）加强组织领导。镇政府负责全镇家庭医生签约服务工作相关政策、方案的制定及组织、协调、指导、考核。镇政府要成立专班，实行机关干部分片包村负责制，做好家庭医生签约服务工作的宣传发动、组织实施、监督检查；要将签约服务与精准扶贫工作有机结合，确保贫困户100%签约；要把家庭医生签约服务工作落实情况纳入乡镇机关干部、村干部绩效考核内容。

（二）深入宣传发动。镇政府要采取召开动员会、皂市中心卫生院采取悬挂标语和横幅、各村（居）委会采取开辟专栏、专版等方式对家庭医生签约服务政策进行宣传，镇工作专班对工作进度进行跟踪报道；皂市中心卫生院要采取印发宣传册、展板公示等方式，向居民宣传为其提供签约服务的家庭医生团队人员名单、服务项目、联系方式和监督电话等内容，让签约服务深入人心。

（三）实行医卫结合。皂市中心卫生院配合完善市域医疗共享信息平台，执行医卫结合模式，落实基本医疗、基本公卫等服务,实现健康管理数据与医疗信息以及各医疗卫生机构之间数据互联互通。皂市中心卫生院、村卫生室首诊医生要在接诊时使用居民健康卡查阅服务对象健康信息，及时将电子处方、病历、辅助检查结果导入居民健康档案。入户开展医疗卫生服务或随访时，要在服务中及时记录、补充、更新电子健康档案。对需新建或更新健康档案的按照基本公共卫生服务规范、重大公共卫生服务规范、计划生育免费服务工作规范的要求将服务结果及时录入健康档案，便于家庭医生团队更好的为签约对象提供跟踪连续服务。

（四）严格督导考核。镇政府要对家庭医生签约服务工作严格考核、严格结账。市第一人民医院要加强对家庭医生签约服务工作的指导和督导。建立以签约对象数量与构成、服务质量、健康管理效果、居民满意度、签约居民基层首诊比例等为核心的签约服务评价考核指标体系，定期对签约团队开展考核评价。
