# 石家河镇人民政府办公室关于印发《石家河镇2017年家庭医生签约服务实施方案》的通知

为充分发挥家庭医生"居民健康守护人"作用，助力分级诊疗，根据国务院医改办、国家卫计委等七部门联合印发的《2016年关于推进家庭医生签约服务的指导意见》（国医改办发[2016]1号）精神和市深化医药卫生体制改革领导小组相关要求，结合我镇实际，制定本实施方案。

一、指导思想

按照深化医药卫生体制改革的总体部署，以做实家庭医生与居民签约服务为重点，逐步完善以家庭医生为基础的分级诊疗模式，建立以保障群众身体健康为核心、以家庭医生签约服务为基础、全科服务团队为依托、基层医疗机构为平台、二级医疗卫生机构纵向协作为支撑的三级联动医疗卫生服务体系，为全镇居民提供安全、有效、连续、便捷、价廉的基本医疗和基本公共卫生服务。

二、工作目标

到2017年09月30日，全镇家庭医生签服务覆盖率要达到100%，10月1日起为签约对象提供约定服务。

三、主要内容

（一）服务主体

服务主体为镇卫生院家庭医生团队和村医。我镇属市中医医院牵头的医联体，由市中医医院为家庭医生团队提供技术支持和业务指导、开展人员培训带教，衔接双向转诊等。

我镇卫生院建立了由临床或全科医生、护士、公共卫生医师等组成的7个家庭医生团队，按照每个团队不少于5人，每个团队负责5-6个村（居）的原则，负责签约对象的基本医疗服务、基本公共卫生服务、重大公共卫生服务、计划生育免费服务、健康干预服务等。

村医负责做好签约对象的沟通联络工作，协助团队开展健康教育、宣传、信息收集、基本医疗服务、公共卫生服务等工作。

（二）签约服务对象

家庭医生签约服务面向全镇常住6个月以上户籍或非户籍居民，服务人群可分为三类：

1、重点人群，主要指65岁以上老年人、0-6岁儿童、孕产妇、慢性病人、严重精神病障碍患者、结核病患者等。

2、特殊人群，主要指孤寡老人、残疾人、最低生活保障对象、下岗失业人员、优抚对象等。

3、普通人群，除上述人群之外的一般人群。

（三）服务内容

家庭医生签约服务主要包括基本医疗服务、基本公共卫生服务、重大公共卫生服务、计划生育免费服务、健康干预服务等5个方面。

1、基本医疗服务。家庭医生为签约居民提供常见病、多发病的初级诊治，推行分级诊疗，需要转上级医院诊疗的病人，家庭

医生要及时提供转诊服务并履行转诊手续。

2、基本公共卫生服务。家庭医生要以签约居民需求为导向，按照《国家基本公共卫生服务规范》第三版要求，认真落实12类46项基本公共卫生服务项目，以65岁以上老年人、0-6岁儿童、孕产妇、慢性病人、严重精神病障碍患者、结核病患者等重点服务对象，实行包户责任制开展健康管理、上门访视、家庭康复指导等服务工作。

3、重大公共卫生服务。家庭医生加强与妇幼保健机构衔接，为签约对象中的孕产妇提供免费预防艾滋病、乙肝、梅毒母婴传播项目；农村妇女宫颈癌、乳腺癌检查项目及增补叶酸预防神经管缺陷等服务。

4、计划生育免费服务。家庭医生加强与妇幼保健机构衔接，为签约对象中的相关人群提供免费婚前医学检查服务、免费孕前优生健康检查、免费计划生育手术技术服务、免费发放计划生育药具服务、免费计划生育手术并发症鉴定服务、免费计划生育病残儿医学鉴定服务。

5、健康干预服务。鼓励家庭医生开展以健康管理为主要内容、以主动服务为主要形式的个性化服务，如健康咨询、中医保健、药品代购、康复协助、化验检查等。

（四）服务包设计

1、免费包。适用于所有村（居）民，提供基础的基本医疗、基本公共卫生、重大公共卫生、计划生育免费服务。

2、优惠包。根据我镇实际制定，部分体检项目（彩超、心电图）可以优惠20%左右。

（五）签约服务方式

在村（居）民自觉自愿和充分了解家庭医生签约服务内涵的基础上，家庭医生团队和村医组织辖区村（居）民以户为单位上门服务的形式签订协议，明确签约服务内容、方式，双方的责任、权利、义务等事项。

1、统一签约时间。村（居）民签约以签订签约协议书为标志，应在每年第四季度签订次年的家庭医生签约服务，办妥相关手续。

2、统一签约方式。服务团队以签约医生为代表，与村（居）民签订服务协议。签约村（居）民以家庭为签约单位，以户主或一位可代表户主的家庭成员的书面签约为依据，代表全家签约。

3、统一服务约定。签约有效期内，村（居）民可根据实际情况，向签约基层医疗机构提出解约或变更签约家庭医生或医疗机构申请。签约有效期满后，如村（居）民不提出变更或解约要求，视为自动续约。签约双方确定应承担的责任、权利、义务及其他有关事项等。

四、保障措施

（一）加强组织领导。我镇成立了镇分管领导任组长、卫计办主任和卫生院院长为副组长、镇全体机关干部、卫生院家庭医生团队、所有村支部书记、村医为成员的工作专班，对我镇辖区村（居）分片包干开展家庭医生签约服务工作。

我镇将加大对公共卫生、计划生育工作的监督检查和考核，把家庭医生签约，公共卫生、计划生育免费服务纳入村级和镇机关干部、村支部书记绩效考核内容。

（二）深入宣传发动。在镇区街道、镇机关、村委会、卫生院、村卫生室等地悬挂标语和横幅（医院和各村不少于1条、社区不少于3条横幅）、举办宣传栏、电子屏显示等，对家庭医生签约服务工作进行广泛宣传，将公共卫生服务内容和家庭医生签约服务政策宣传到全镇每村每户，营造全社会知晓公共卫生服务，支持、参与签约服务的良好氛围。

（三）实行医卫结合。市卫计委要完善市域医疗共享信息平台，执行医卫结合模式，落实基本医疗、基本公卫等服务，实现健康管理数据与医疗信息以及各医疗卫生机构之间数据互联互通。镇卫生院、村卫生室首诊医生要在接诊时使用村（居）民健康卡查阅服务对象健康信息，及时将电子处方、病历、辅助检查结果导入村（居）民健康档案。入户开展医疗卫生服务或随访时，要在服务中及时记录、补充、更新电子健康档案。对需新建或更新健康档案的按照基本公共卫生服务规范、重大公共卫生服务规范、计划生育免费服务工作规范的要求将服务结果及时录入健康档案，便于家庭医生团队更好的为签约对象提供跟踪连续服务。

（四）考核机制。市中医医院对我镇家庭医生签约服务工作进行指导和督导，市医改办对镇家庭医生签约服务工作考核、结账，以签约对象数量与构成、服务质量、健康管理效果、居民满意度、签约村（居）民基层首诊比例等为核心的签约服务评价考核指标，定期对签约团队开展考核评价。

石家河镇人民政府
