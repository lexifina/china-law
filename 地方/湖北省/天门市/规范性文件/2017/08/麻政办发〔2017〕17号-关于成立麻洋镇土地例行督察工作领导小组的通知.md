# 关于成立麻洋镇土地例行督察工作领导小组的通知

各村（居）民委员会、镇直有关单位：

经镇政府研究，决定成立麻洋镇土地例行督察工作领导小组。现将组成人员通知如下：

组　长：梁文江 党委副书记、镇长

副组长：彭志中 党委副书记、综治办主任

方华祥 人大专职副主任

成　员：刘永华 纪委副书记

彭国平 镇人社中心主任

平福祥 民政办主任、扶贫办主任

周洪武 天门市资源管理局麻洋管理所所长

彭首庚 村镇建设服务中心主任

领导小组下设办公室，由周洪武同志兼任办公室主任。
