# 关于调整多宝镇食品安全领导小组的通知

各村（居）民委员会、镇直各单位：

因人事变动，经政府研究决定，现将多宝镇食品安全领导小组成员作如下调整：

组 长：石 胜（多宝镇人民政府镇长）

成 员：陈 立（多宝镇人民政府副镇长）

鲁登奇（多宝镇派出所所长）

戴 军（多宝镇农技服务中心主任）

常 青（多宝镇工商所所长）

曹运军（多宝镇中心学校校长）

邹森林（多宝镇卫生院院长）

夏祥成（多宝镇畜牧服务中心主任）

赵华龙（多宝镇食药分局局长）

领导小组办公室设在多宝镇政府，由陈立同志兼办公室主任，赵华龙同志兼任办公室副主任。
