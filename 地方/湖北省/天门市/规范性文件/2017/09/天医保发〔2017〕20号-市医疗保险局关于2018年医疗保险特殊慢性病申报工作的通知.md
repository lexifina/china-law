# 市医疗保险局关于2018年医疗保险特殊慢性病申报工作的通知

各参保对象：

根据《市人民政府关于印发天门市城镇职工基本医疗保险实施办法的通知》（天政规[2017]2号）和《市人民政府关于印发天门市城乡居民基本医疗保险实施办法的通知》（天政规[2017]3号）精神，我局将于近期组织开展2018年特殊慢性病申报鉴定工作，现就有关事项通知如下：

二、申报对象

患有上述疾病的参保职工和城乡居民。

三、申报所需资料

1、二级以上定点医疗机构近三年的住院病历（超过三年需提供近期检查报告等依据）；

2、身份证复印件；

3、社会保障卡复印件。

四、申报时间

2017年10月1日至10月31日（节假日除外），逾期不再受理。

五、申报地点

城镇职工到市医疗保险局申报，城乡居民到辖区乡镇人社中心申报。

六、待遇享受时间

申报资料经专家鉴定合格，经公示无异议的，从2018年1月1日起享受特殊慢性病待遇。

特此通知。
