# 关于印发小板镇2017年中小河流治理实施方案的通知

各村（居）民委员会：

为认真贯彻落实2017年中央1号文件和中央水利工作会议精神，完成国务院《关于切实加强中小河流治理和山洪地质灾害防治的若干意见》指出的中小河流治理目标，全面推进我镇中小河流治理工作，现将《小板镇2017年中小河流治理实施方案》印发给你们，请遵照执行。

小板镇人民政府办公室

2017年9月22日

小板镇2017年中小河流治理实施方案

一、总体要求

中小河流治理工作，坚持科学发展、以人为本、和谐发展的战略思想，积极践行可持续发展的治水思路，贯彻落实中央关于中小河流治理工作的重大部署，按照省委、省政府、市委、市政府提出的明确要求和总体安排，采取有力措施，周密安排，精心组织，深入细致，扎实工作，科学制定具体实施方案，合理配置资源，全力加强前期除障工作力度，全面加快实施进度，尽快发挥减灾效益，为推进工业化、城镇化、农业现代化协调发展，建设魅力小板，打造小板城郊工业强镇提供水利支撑。

二、指导思想和原则

（一）指导思想

以科学发展观为指导，全面贯彻2017年中央一号文件精神和中央水利工作会议精神，按照中央关于中小河流治理工作的总体要求，针对中小河流防洪突出问题，以保障人民群众生命财产安全为根本，以中小河流防洪保安为重点，统筹考虑水资源利用和水生态保护，工程措施和非工程措施相结合，治理与管理并重，提高重点河流和重点河段的防洪减灾能力，保障区域防洪安全和粮食安全、生态安全，促进我镇经济社会的可持续发展。

（二）基本原则

1.坚持以人为本。树立以人为本理念，把保证人民群众生命财产安全放在首位，以保障人民群众增产增收作为全镇中小河流治理的出发点和落脚点。

2.坚持突出重点。以提高重要区域、农田保护区的防洪能力作为重点，优先考虑洪涝灾害频繁发生、对人民生命财产威胁严重急需治理的河流和重点河段。

3.坚持注重实效。根据小板镇经济发展需要，合理确定治理方案，注重治理效果，治理一条、竣工一条、见效一条、销号一条，提高治理整体效益。

4.坚持分级负责。镇政府总体协调，镇农办、水管站具体负责日常事务，所涉中小河流沿线各村民委员会负责除障、矛盾调处。

三、工作任务

本次小板镇中小河流治理涉及7条河流，分别是小板河、梅字眼河、叫湖沟、胜利河、小湖新沟、蒋碑渡河、鱼米河。由两个项目单位进行施工建设，项目建设内容如下：

（一）小板河整治项目

小板桥两边各450米进行干砌块石护岸，从县河往南900米进行重点治理，从900米处到方寺村进行削坡、整形，坡面修缮、涵闸泵站水毁工程维修。

（二）梅字眼河整治项目

主要进行堤防消坡、整形，堤身加培、清淤除障，涵闸、生产桥两座拆除重建。

（三）叫湖沟整治项目

主要进行河道清淤疏浚，新堰滩闸周围护岸。

（四）胜利沟整治项目

主要进行清淤疏浚，胜利沟方门口闸拆除重建。

（五）小湖新沟整治项目

主要进行清淤疏浚，鱼嘴闸维修。

（六）蒋碑渡河整治项目

主要进行干砌块石护岸，削坡、整形，坡面修缮、生产桥建设，天仙公路两边各200米进行护岸。

（七）鱼米河整治项目

主要进行干砌块石护岸，削坡、整形，坡面修缮、清淤疏浚，金彭公路两边各200米进行护岸。

四、具体步骤

（一）宣传发动。召开村书记会议，由各村书记传达会议精神并召开村民代表大会，对中小河流治理工作进行宣传，成立工作专班，明确具体分工职责。（10月21日前）

（二）情况摸底。各村排查沿线树木、坟墓、电杆、通信设施数量。（10月8日前）

五、保障措施

（一）强化组织领导。成立小板镇中小河流治理工作领导小组，组长鲁鹏飞，副组长鲁泽会，成员吴明洋、刘潇、尹雯璟、陈田、梁攀、王伟、罗雨山、杨利军。领导小组下设办公室，办公室主任由吴明洋同志兼任。领导小组全面负责领导和协调我镇中小河流治理工作，研究处理中小河流治理有关重大问题，部署加快中小河流治理的除障检查、新闻宣传等工作。

（二）抓好前期除障工作。中小河流治理涉及防洪、生态环境保护、水资源利用等方面，需要统筹规划、精心设计，特别是要加强方案比选。各村民委员会会后要根据实际情况，做好本村伐树、迁坟、杆线迁移、建筑物拆除等除障工作。
