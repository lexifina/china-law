# 天门市交通运输局关于印发《2017年今冬明春火灾防控工作方案》的通知

局直各单位、机关相关科室：

为切实加强全市交通运输行业冬春火灾防控工作，坚决预防和遏制重特大火灾事故发生，确保行业内火灾防控形势稳定，根据市人民政府关于《天门市2017年今冬明春火灾防控工作方案》（天政办发[2017]58号）文件精神，经局党组研究，决定自11月1日起至2018年全国两会结束，在全市交通运输行业开展今冬明春火灾防控工作。现将《2017年今冬明春火灾防控工作方案》印发给你们，请遵照执行。

天门市交通运输局

2017年11月13日

天门市交通运输局2017年今冬明春火灾防控工作方案

为强化针对性火灾防控措施，维护消防安全形势稳定，经市交通运输局党组同意，决定从11月1日起至2018年全国两会结束，在全市交通运输行业开展今冬明春火灾防控工作。特制定如下工作方案：

一、工作目标

深入贯彻落实党的十九大精神和习近平总书记关于加强公共安全的系列重要讲话要求，结合冬春季节火灾规律和特点，动员交通运输行业各方面力量，深化火灾隐患排查整治，广泛开展消防宣传培训，扎实推进消防基础设施建设，全面做好灭火应急准备工作，有效维护全系统火灾防控形势总体稳定。

二、组织领导

局成立交通运输行业冬春火灾防控工作领导小组，领导小组下设办公室，挂靠局安全科，局党组成员、副局长王刚同志任办公室主任，安全科刘雄波同志任联络员，具体负责行动的组织联系、综合协调、检查督导和考核验收工作。

三、工作任务及措施

（一）主要任务

1.建立消防安全管理制度。

2. 制定和落实消防检查巡查制度。

3.是否配备消防设施设备和安全标志。

4. 是否保证消防设施设备的维护保养完好。

5.是否保障安全出口和消防通道畅通、符合消防要求

6.是否开展消防安全宣传教育和消防演练等防控工作。

（二）工作措施

1. 各单位要组织召开会议，部署开展今冬明春火灾防控工作。

2. 落实"6+1"措施，即开展一次消防安全评估、签订一份消防安全承诺书、维护保养一次消防设施、组织监测一次电气和燃气线路设施、全面清洗一次油烟道、集中培训一次全体员工。

3.领导要带队深入企业、场所，帮助指导和推动自查自改工作，并建立工作台账，确保排查不留盲区，不留死角。同时要坚持"谁主管，谁负责""谁检查，谁负责"的原则，落实整治责任，对排查发现和群众举报的火灾隐患要坚决整治，绝不姑息迁就。

4.在节假日和两会期间，严禁重大火灾隐患单位"带病"生产经营、严禁边生产经营边整改，无法保证安全的，一律予以关停或临时查封，对符合重大火灾隐患判定标准的，要报告局冬春火灾防控工作领导小组实施挂牌督办。

5. 要建立健全预警报警、应急联动、组织指挥机制，明确各部门应急响应集结疏散、组织指挥、协调配合、通信联络等程序和要求，组织开展应急演练，优化应急力量和资源，做好各项应急准备工作和提高应急处置能力。

（三）重点领域防控

1.水上交通防控的重点是：乡镇渡口、渡船、危险品船舶、港口等重点部位和环节的消防安全管理。

2. 道路运输防控的重点是：客运站、"两客一危"车辆、机动车维修车间、农村客运、城市公交、公交集中停车站场和出租车的消防安全。

3.交通工程防控的重点是：施工工地、工区宿舍、临时用电用气、炸药及雷管等危险品的领取、保管和使用等消防隐患排查。

4. 森林防火防控的重点是：公路沿途野外火源、违章用火、防特殊人群的消防联防联动。

四、工作步骤

今冬明春火灾防控工作分三个阶段：

（一）部署发动阶段（2017年11月1日至9日）。各单位要召开专题会议对今冬明春火灾防控工作进行部署和安排，下发方案，明确职责、细化措施，广泛发动、部署到位。各单位今冬明春火灾防控工作方案及动员部署情况于11月24日前请报局安全科。

（二）组织实施阶段（2017年11月9日至全国两会结束）。精心组织实施、定期研判调度，组织联合督查、分析通报问题，从严从细从实抓好工作落实，确保圣诞、元旦、春节、元宵节和全国两会消防安全。

（三）总结考评阶段（全国两会结束后5日内）。各单位要认真总结工作经验，对冬春火灾防控工作情况进行汇总分析，研究制定长效管理措施，巩固行动成果，并将汇总分析总结上报局安全科。

五、工作要求

（一）注重宣传，营造氛围。要充分运用各种媒体，加大对今冬明春火灾防控工作的宣传和舆论监督力度，教育引导单位和群众增强做好消防安全工作的主动性和自觉性。要及时曝光一批重大火灾隐患，剖析典型火灾案例，营造全社会关注、参与隐患整治的浓厚氛围。

（二）强化责任，狠抓落实。各单位要进一步明确交通运输行业管理部门消防安全责任，强化消防安全隐患排查，督促相关单位和企业彻底整治火灾隐患。要联合消防部门建立健全消防安全信息互通、联合执法等工作机制。要严格消防安全问责制，对行动不重视、工作不力、措施不落实、成效不明显的要及时进行通报批评、挂牌督办，为做好冬春火灾防控工作打下坚实基础。

（三）定期督查，强化考评。局冬春火灾防控工作领导小组办公室将定期开展督查，活动结束后进行综合考评，并将各单位在本次冬春火灾防控工作的情况纳入年度安全应急管理工作目标考核。对因工作失职造成火灾责任事故的，要实行责任倒查和逐级追查，严格追究相关单位和个人责任。
