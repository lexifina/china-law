# 干驿镇关于印发镇区部分地名更名与命名的通知

各村（居）民委员会、镇直各单位：

近年来，干驿镇城镇建设取得较快发展，新建和改扩建的道路、街巷、桥梁等地理实体急需命名或更名。为凸显千年古镇的文华传承与建设茶韵书香文华品质之城的需要，在第二次全国地名普查中，我镇按《湖北省地名管理条例》等相关文件规定，对镇区部分地名作了标准化处理，并已获得市政府审批，现将部分更（命）名的地名向社会公布。请各村（居）民委员会、镇直各单位广泛宣传，以利人民群众生产生活需要。

特此通知

干驿镇人民政府办公室

2017年11月6日
