# 麻洋镇2017年今冬明春火灾防控工作方案

为切实加强全镇今冬明春火灾防控工作，坚决预防和遏制重特大尤其是群死群伤火灾事故发生，确保全镇火灾形势稳定，按照上级要求，结合本镇实际，经镇政府同意，决定从11月1日起至2018年全国“两会”结束，在全镇范围集中开展今冬明春火灾防控工作。特制定方案如下：

一、工作目标

深入贯彻落实党的十九大精神和习近平总书记关于加强公共安全的系列行政权讲话要求，由派出所牢头，镇直机关相关部门参与，广泛动员社会力量，结合冬春季节火灾规律和特点，广泛开展消防宣传培训，深化重点区域、场所火灾隐患排查整治，全面做好灭火应急救援准备，强化各项防控措施，有效减少较大火灾，坚持遏制重特大尤其是群死群伤火灾事故，确保元旦、春节、全国“两会”等重大节日、重大活动期间不发生有影响的火灾事故，确保全镇火灾形势稳定。

二、工作重点

全镇今冬明春火灾防控工作要强化“七个方面重点”：一是严格落实《火灾隐患整治相关要求》，突出人员密集场所、易燃易爆危险品企业、较大型综合体等火灾隐患排查整治；二是加大对辖区重大火灾隐患单位整改情况的督办；三是加快镇消防规划修编和镇消火栓等公共消防基础设施建设；四是着力强化消防安全“网格化”、“户籍化”管理以及政府专职消防队伍建设；五是加强重点单位、重要部位消防演练和灭火救援战勤保障工作；六是深化消防宣传和重点岗位、重点人员的业务培训；七是做好重大节日和全国两会期间的消防安全保卫。

三、组织领导

为加强对今冬明春火灾防控工作的领导，镇成立工作领导小组。镇长梁文江任组长，副镇长刘勇、派出所所长黄俊峰任副组长，镇经济发展办公室副主任刘云庭、派出所副所长彭文雄、各单位消防安全负责人为成员。领导小组办公室设在派出所，派出所所长黄俊峰任办公室主任，负责工作统筹调度。

四、工作措施

（一）瞄准“靶心”防大火

重点突出人员密集、易燃易爆、“三合一”、群租房、老旧住宅等易发生大火的场所单位，落实严防严管严控措施。

1.全面排查摸清底数。成立专班按照职责分工，逐个行业、逐个区域、逐个场所开展排查，分别摸清各类场所单位的数量、生产经营规模、建筑消防设施状况及消防安全管理、消防履职尽责等情况，并对各场所单位逐个进行详细登记，建立台帐。

2.逐级落实监管责任。11月10日前，要组织召开火灾高危单位、消防安全重点单位、重点监管“十小场所”法定代表人、消防安全管理人会议，部署今冬明春火灾防控工作，明确要求。按照“管行业必须管安全”的要求，明确相关部门监管责任；指导重点单位开展消防安全评估，签订消防安全承诺书。

3.逐一落实人防物防技防措施。督促人员密集场所单位落实主体责任，落实专职经理人制度，进一步明确消防安全责任人、管理人职责，加强日常巡查制度，及时消防火灾隐患。积极推进老旧住宅、群租房、“三合一”场所设置应急广播、独立式火灾探测报警器、简易喷淋设施，组织居民、员工开展逃生自救演练。加强居民用火用电管理，清理柴草杂物，配备灭火器材，落实重点对象“一对一”盯防帮扶。全国“两会”前，督促各场所单位开展一次建筑消防设施维护保养、一次电气线路检测，保证设施设备完好有效。

4.深入推进消防专项治理。元旦、春节前，派出所、电力、城建等部门要联合开展电气火灾综合检查，在今冬明春火灾防控工作期间，对火灾高危单位、消防安全重点单位和重点监管“十小场所”全部排查不少于一次。要依托网格化管理工作平台，组织基层网格员对小单位、小场所及居（村）民楼院进行全面排查。依法对火灾事故严肃问责。落实重大火灾隐患挂牌制度，开展集中曝光行动，推动火灾隐患的整改。

5.全力做好重大活动重要节日消防安保工作。紧盯全国、全省、全市三级“两会”和圣诞、元旦、春节、元宵节，加强消防安全保卫工作。三级“两会”前，督促各单位落实各项安保措施，实行“实名制”巡防看守。重大活动重要节日期间，要严格安全防范措施，并采取流动巡逻、定点执勤等方式加大管控力度。

（二）夯实基础控小火

1.严格落实消防网格化管理。综治部门要将消防安全网格化管理纳入基础综合服务等管理平台，各企业、单位要建立健全完善消防安全组织，逐级明确消防安全责任人和专职消防管理人员，形成组织健全、责任明确、力量整合、巡查有力的消防管理新机制。全国“两会”前，镇消防安全网格实现规范化管理。派出所要加强对辖区小场所、小单位监督检查，督促村（居）委会、物业管理单位落实消防管理职责，结合治安巡逻、户籍检查、社区警务等工作，组织开展防火检查和消防宣传。

2.开展消防安全村（社区）创建达标验收。派出所要会同综治、民政、城建等部门开展“消防安全社区、村”创建达标验收。全国“两会”前，90%的村（社区）创建达标。冬春火灾防控工作期间，各村（社区）要组织居民集中开展一次火灾警示教育和疏散逃生演练，提高自防自救能力。元旦前，各村要组织居民清楼道、清阳台、清住宅周边，提醒居民出门要关火、关电、关气，防止发生火灾。

3.全力推动消防规划实施。年底前，镇要按照年度任务和有关规划，完成镇消火栓建设任务，镇消火栓完好率达到98%以上。要积极推进政府专职消防队伍建设，按照标准配齐人员、装备器材、个人防护装备等设施，并落实消防专项经费保障。

4.因地制宜开展专项治理。要针对镇区居民住宅、群租房、沿街小门店、福利院、厂房仓库等场所火灾多发的特点，开展专项治理，全力减少火灾总量，有效控制小火亡人。

（三）全力备战谋打赢

1.开展冬季练兵。专职消防队要强化消防单兵基础和应用技能的训练，加大车辆、装备器材熟悉和操作应用训练的力度，组织开展专业培训。

2.强化熟悉演练。政府专职消防队要组织对辖区消防水源进行摸底排查，及时进行维护保养，落实防冻保暧措施。对重点单位以及火灾易发场所区域开展实地熟悉、建立台帐，完善灭火救援数字化预案。每周熟悉演练时间不少于2天。春节前，要对辖区重点单位和节庆活动区至少实地熟悉一遍。

3.深化联勤训练。加强对政府专职消防队的指导，组织开展个人防护、灭火器材等装备操作应用训练，达到“三知四会”灭火救援要求；参加好上级组织的轮训培训，提高执勤管理和初战指挥能力。

4.落实战勤保障。及时补充专职消防队的灭火救援装备器材和保障物资，保障车辆装备时刻处于完整好用状态。春节前，要组织对车辆装备进行一次技术检查，保证人员、装备和车辆防冻防滑措施到位。

（四）强化宣传提素质

1.开展社会化宣传培训。大力部署开展消防宣传进村（社区）活动，全镇评选10个消防宣传示范村。开展消防宣传进学校、推进教材、师资、课时、场所“四到位”，深化消防安全“三提示”和“一懂三会”教育，对全镇村负责人以及重点单位负责人、管理人，组织全部培训一遍。落实消防监督员每周半天开展消防宣传教育工作制度。

2.推进媒体宣传报道。充分利用各类主流媒体和门户网站，开办消防宣传专栏，定期报道火灾防控工作动态，将冬春火灾防控工作纳入近期舆论宣传工作重点。常态化开展消防新闻宣传报道和消防知识宣传，开展1次火灾隐患集中曝光。定期开展主题宣传，公益宣传提示做到经常化。发挥舆论监督作用，适时曝光火灾隐患和消防安全不良行为。发动群众通过“96119”举报火灾隐患，并及时核查处理。

3.抓好重要节点宣传。结合冬季火灾特点，大力宣传普及冬季用火、用电、用气、用油、燃放烟花爆竹等防火常识和逃生自救知识。充分利用社区小喇叭、农村消防广播“村村响”工程，开展消防安全温馨提示、发布安全用火告知，提醒和组织群众广泛开展“四清四关”活动（清屋顶、清庭院、清阳台、清楼道，关门窗、关电源、关燃气、关明火）。对老、弱、寡、残、独等特殊人群提供面对面消防安全服务。大力宣传和提示公众聚集场所火灾预防、逃生自救等知识。

五、工作步骤

今冬明春火灾防控工作分三个阶段：

（一）部署发动阶段（2017年11月1日至9日）。召开专题会议，研究制定工作方案，成立组织机构，对今冬明春火灾防控工作进行部署和安排，建立工作机制，逐级动员安排，落实工作任务，明确工作责任，完善工作措施。

（二）组织实施阶段（2017年11月9日至全国“两会”结束）。按照工作方案，精心组织实施、定期研判调度、组织联合督查、分析通报问题，从严从细从实抓好工作落实，确保圣诞、元旦、春节、元宵节和全国“两会”消防安全。

（三）总结考评阶段（全国“两会”结束后5日内）。领导小组在“两会”结束后，要及时组织对全镇各单位冬春火灾防控工作进行检查，并汇总分析工作情况，认真总结经验做法，研究建立长效工作机制。

六、工作要求

（一）提高认识，强化领导。冬春季节历来是火灾防控的关键时段，风干物燥、气候寒冷，节庆活动多，群众用火用电量大，火灾风险剧增，容易引发大的火灾事故。各企业、单位要结合自身实际，建立健全组织，制定工作方案，抓好工作落实。

（二）明确责任，强化督导。各单位要建立健全领导责任制，分片包干、靠前指挥，蹲点督导、跟踪问效。专项行动期间，镇领导小组将督导检查各单位工作情况，并进行实名通报。对火灾多发、易发单位，要派出帮扶小组协助分析原因，帮助解决问题。

（三）分类排查，重点整治。按照“一件事情接着一件事情办、一年接着一年干”的要求，分行业分系统组织开展火灾隐患排查，全面摸清行业系统消防安全状况，对存在的消防安全问题和火灾隐患，要列出清单和时间表，逐一整治，力争排查整治一个行业系统单位，放心一条线的消防安全。

（四）加强执法，严格查处。在发动单位自查自改的基础上，领导小组要加大监督检查频率，充分利用“查、改、罚、封、停、拘”等执法手段，严厉查处火灾隐患和消防安全违法行为。对重大火灾隐患坚持政府挂牌督办，组织综合施策，确保近短时期内整改到位。对符合失火罪、消防责任事故罪条件的，一律依法立案查处，严格倒查责任落实。加强单位消防监督员、派出所民警业务培训，提高监督能力，规范执法行为。

（五）定期调度，强化考评。冬春火灾防控工作领导小组要分阶段、分重点、分专项开展督导，重点检查各企业、单位、村（社区）冬春火灾防控工作推进落实情况。每月对工作情况进行汇总，活动结束后进行综合考评，并将考评成绩纳入对各单位消防工作考核内容。对成绩突出的，给予表扬奖励；对工作不落实，进展缓慢的，通报批评，并约谈单位负责人；对因工作失职造成火灾责任事故的，要实行责任倒查和逐级追查，严格追究单位和相关人员责任。
