# 关于《中共卢市镇委办公室关于卢市镇建立河湖长制实施方案》的制定说明

中共卢市镇委办公室于2017年4月13日印发了《卢市镇建立河湖长制实施方案》（卢办发〔2017〕30号），现就有关制定情况作以下说明。

一、制定意图

为认真贯彻落实中央“四个全面”战略布局，牢固树立创新、协调、绿色、开放、共享发展理念，维护河道健康生命，推进水生态文明建设。

二、主要内容

落实各项河湖管理措施；河湖环境管理水平全面提升；河湖水质基本达到水环境功能区划要求；基本消除沿河违章建筑、乱堆垃圾、河内违法设障的现象；河湖断面水质、环境面貌明显改善，基本实现“水清、流畅、岸绿、景美”的目标。

三、起草及征求意见情况

卢市镇组成文件起草专班，在认真学习中央、省委、市委有关精神的基础上，广泛征求意见建议，形成文件初稿征求市委组织部意见，再次修改后形成征求意见稿，并下发各村、社区及有关镇直单位征求意见。综合各方意见和建议后，形成送审稿。

四、审议批准情况

2017年4月13日，卢市镇党委会会议审议并通过《卢市镇建立河湖长制实施方案》，同日印发。
