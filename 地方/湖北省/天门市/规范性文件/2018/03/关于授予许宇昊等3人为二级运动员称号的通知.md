# 关于授予许宇昊等3人为二级运动员称号的通知

各有关单位：

根据国家《运动员技术等级管理办法》的规定，按照《运动员技术等级标准》，经审核，公示无异议，现授予许宇昊、徐博烁、李广等3人为二级运动员称号。

附件：2018年许宇昊等3人二级运动员详细情况登记表
