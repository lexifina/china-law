# 天门市审计局对天门市扶贫开发办公室2017年度扶贫政策落实和扶贫资金分配管理使用情况进行审计的公告

根据《中华人民共和国审计法》第十六条的规定和中共天门市纪委印发《全市扶贫领域不正之风和腐败问题专项整治战役工作方案》的通知，市审计局决定派出审计组，自2018年1月8日起，对全市2017年度扶贫政策落实、扶贫资金分配管理使用情况和扶贫项目建设运营等情况进行审计，必要时将追溯到相关年度或者延伸审计有关单位。
