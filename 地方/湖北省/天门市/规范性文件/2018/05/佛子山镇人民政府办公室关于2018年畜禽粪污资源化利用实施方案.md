# 佛子山镇人民政府办公室关于2018年畜禽粪污资源化利用实施方案

为全面贯彻落实国务院《畜禽规模养殖污染防治条例》及《天门市畜禽养殖业污染整治实施方案》（天政办发），[2013]55号）精神，按照天门市第七届人民代表大会第四次会议"关于加强农村养殖业污染治理方案的决议"提出的用三年时间对全市畜禽业的养殖污染治理目标任务，结合我镇的实际情况制定畜禽养殖污染治理整镇推进工作实施方案。

一、组织领导

为认真做好我镇畜禽养殖业污染治理工作，镇成立了畜禽养殖业污染治理工作领导小组

组长：谭纪刚 （党委副书记 镇长）

副组长：谈选平 （党委委员副镇长）

成 员：谌颖、胡会平、周会清、李端华、黄中祥、杨义平、梅才华、李雄斌、李国红、向黎霞

领导小组下设办公室，办公室设在镇经济发展办公室，胡会平同志兼任办公室主任。

二、工作任务

1.落实主体责任 各村民委员会是辖区养殖污染治理工作的第一责任人，要迅速成立畜禽养殖业污染治理领导责任专班，落实好领导班子成员包干蹲点，专班人员包户的督导机制，严格管理责任，明确工作目标。

2.明确养殖场（户），规范养殖行为，增强全体村民及养殖户共同参与监督管理的自觉性和主动性，及时举报养殖污染非法排放的违法行为。

3.加大宣传力度 加强对国务院《畜禽规模养殖业污染防治条例》及省环保畜牧部门《关于贯彻落实畜禽规模养殖污染防治条例的通知》的宣传力度，采用发放公开信，制作信息公开栏，组织村级自治组织议事等形式进行宣传，实施公众监督，做到养殖户知晓率100%。

4. 明确工作重点 以辖区内500头以上规模养殖场粪污治理为重点，按100头3个10立方污水处理池和1个5立方的干粪池的建造标准进行建造，然后再全镇推进100头以上养殖场（户）的粪污治理工作，达到标排放或收集还田。

5.推广循环利用 全面推进种养结合，生态治理等综合利用模式，实行养殖废弃物资源化利用。

三、时间安排

1.动员培训。9月28日召开全镇畜禽养殖污染综合治理工作动员会议和培训会议

2.调查摸底。9月28日至9月30日开展调查摸底，并上交养殖场（户）资料。要求对100头以上的养殖户要认真调查摸底，登记造册，同时要了解养殖户的粪污排放情况。

3.10月8日发放养殖污染限期整改通知书。

4.10月10日动工修建至10月30日完工，经验收合格后并投入使用。

四、考核结账

镇养殖污染治理办公室负责对全镇各村养殖场（户）的养殖污染治理情况进行全程监督考核，11月1日前养殖场（户）按养殖污染治理标准建造粪污处理池完工并投入使用，镇将给予一定的奖励。对在规定期限内未动工或动工未完成的要督促完成，情节严重的移交环保部门进行处理直至养殖场关闭为止。
