# 关于印发《小板镇2018年春季重大动物疫病防控工作实施方案》的通知

各村民委员会：

为切实做好我镇重大动物疫病强制免疫工作，根据市动物疫病防控工作会议精神，现将《小板镇2018年春季重大动物疫病防控工作实施方案》印发给你们，请遵照执行。

小板镇人民政府办公室

2018年4月23日

小板镇2018年春季重大动物疫病防控工作

实 施 方 案

为落实市政府春季动物防控工作会议精神，切实抓好我镇重大动物疫病防治工作，根据市防治重大动物疫病指挥部办公室关于《2018年天门市动物疫病强制免疫的通知》〔2018〕1号文件精神，结合我镇实际，制定本实施方案。

一、指导思想

以党的十九大精神为指导，坚持“预防为主”和“加强领导、密切配合、依靠科学、依法防治、群防群控、果断处置”的防控方针，紧紧围绕"两个努力确保"的防控目标、周密部署、完善控施、统筹安排，切实做好春季重大动物疫病防控工作。

二、免疫主体

饲养动物的单位和个人是强制免疫的主体，依据《动物防疫法》承担强制免疫主体责任，切实履行强制免疫义务，按要求实施免疫接种，做好免疫记录，建立免疫档案，主动采样监测免疫抗体，自觉接受畜牧兽医部门监督检查。

三、组织领导

为切实做好我镇2018年春季重大动物疫病防控工作，镇政府成立春防工作领导小组及防疫工作专班。

四、工作目标与任务

1.基础免疫。在全镇范围内，高致病性禽感、牲畜口蹄疫、猪瘟、高致病性猪蓝耳病、鸡新城疫和小反刍兽疫6种动物疫病实行强制免疫。群体免疫密度常年维持在90%以上，其中应免畜禽免疫密度要达到100%，群体免疫抗体合格率全年保持在80%以上。

2.小反刍兽疫免疫。一要对辖区的所有存栏羊开展小反刍兽疫全面免疫工作，做到应免尽免。及时采样监测免疫抗体，针对抗体水平不合格、种羊、新生及补栏的羊只加强补针，确保免疫抗体效价达标，完成2018年小反刍鲁疫免疫无疫防控工作目标。

3.羊布病监测净化。按照人民政府印发的《天门市羊布鲁氏菌病净化实施（2017年版）》文件要求，持续深入推进羊布病净化工作，做“两覆盖一必须”，采样覆盖所存大小羊场，覆盖所有羊只（幼、孕、病三种羊除外）。经确诊为阳性羊的，必须在7天内补杀并无害化处置到位。在必要的情况下，实行同群扑杀，2018年羊布病阳性率控制在0.5%以下，力争阳性率控制在0.1%以下。

4.动物血防。完成全年疫区村牛羊血吸虫病查治任务，做好有钉螺环境禁收工作，按时上报血防工作报表，做好血防资料整理归档工作。

5.宣传“先打后补”政策。对辖内符合“先打后补”申报条件的养殖场进行政策宣传，动员养殖场自愿申报。并积极指导申报场开展重点动物疫病净化工作，督促按月份批次自主送样监测。已申报的养殖场，不得使用政府采购疫苗，并自觉接受畜牧部门抽样检测和年度评估验收。

6.防控系统信息录入。在2017运用动物疫病防控管理系统平台的基础上，逐步推广平机APP运用，进一步完善畜禽存栏、免疫情况、畜禽标识、空瓶回收等信息，做到数据真实、上报及时、自信完整。2018年疫苗标识台账与免疫档案继续实行双轨制，即电子档案和纸质档案同步记录。

7.免疫报告痕迹化管理。一是对疫苗使用和免疫情况实行月报制度，每月28日上报；二是在春秋两季集中免疫期间，对免疫进展实行周报制度，每周四上报本周免疫进度。

8.统筹做好仔猪服泻病、猪伪犬病、鸭病毒性肝炎，禽霍乱等其他动物疫病的防控指导工作。

五、工作要求

1.落实防控责任。按照“地方各级政府对动物防疫工作负总责，政府主要领导是一负责人，分管领导是主要责任人”的要求，切实落实防控工作责任制和责任追究制。

2.落实防疫队伍。要迅速行动，制定春防工作实施方案，组织防疫队伍，开展岗前培训，落实防疫任务，定好奖惩结账办法。

3.强化示范村建设。巩固"两村五场"示范村（场）建设，率先从示范村（场）开针，30天后再强化免疫一次，确保做到"有样可采，抗体达标"的基本要求。

4.落实羊布病采样。结合秋防集体免疫的时机，同步开展羊场布病采样工作，在10月31日前，务必要完成辖区所有羊场的采样送检任务。

5.严格操作规程。按照“一个操作规程、两个全覆盖、六个不漏”的要求，严格遵守防疫技术操作规程，确保不发生因技术操作不当引发的防疫事故。

6.强化疫情巡查和应急值守。春季是牲畜疫动物疫病的高发期，要重点加强对畜禽规模化养殖场、农贸市场活禽交易摊点、畜禽养殖密集区等重点区域的疫情巡查排查力度，严格执行重大动物疫情逐级报告和疫情举报核查制度，及时规范上报疫情。要加强应急值守，坚持24小时值班和领导带班制度，做到责任明确、人员到位、联络畅通，确保一旦发生疑似重大动物疫情，按“早、快、严、小”原则，果断处置疫情。

六、时间安排

1.物资发放：3月26日之前将首批防疫物资到位。

2.技术培训：3月28日召开全镇春防暨防控技术培训会议，进一步安排部署春防工作。

3.集中免疫：3月29日之前全面开针，4月30日前完成集中免疫任务；5月1日-5月10日组织“回头看”开展补注，完善防疫信息台账。

4.防疫督导：整个春防期间，将组织督导专班分阶段巡回督导。
