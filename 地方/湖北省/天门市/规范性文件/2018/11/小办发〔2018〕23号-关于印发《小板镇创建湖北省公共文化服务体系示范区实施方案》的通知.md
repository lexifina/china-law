# 关于印发《小板镇创建湖北省公共文化服务体系示范区实施方案》的通知

各村（居）、镇直有关单位：

《小板镇创建湖北省公共方案》已经镇委、镇政府研究同意，现印发给你们，请认真贯彻执行。

中共小板镇委办公室 小板镇人民政府办公室

2018年10月28日

小板镇创建湖北省公共文化服务体系

示范区实施方案

为深入贯彻落实党的十九大精神，加快推进小板镇公共文化服务体系建设，根据市委市政府办公室《关于印发天门市创建湖北省公共文化服务体系示范区规划（2018-2020年）的通知》（天办文〔2018〕11号）精神，结合我镇实际，特制定本方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实中央和省、市关于构建现代公共文化服务体系的战略部署，着力保障和改善文化民生，满足人民群众基本文化需求。按照公益性、基本性、均等性、便利性的要求，构建具有小板特色的现代公共文化服务体系，提高公共文化服务水平，为我镇经济社会发展提供强有力的文化支撑。

二、创建基础

小板镇位于天门市郊东南，国土面积62.98平方公里，辖1个社区，16个行政村，总人口3.8万人。

小板镇经济发展较快，2017年完成国地两税收入2414.5万元，完成固定资产投资24.74亿元，规模以上工业总产值达到9.85亿元，完成社会消费品零售总额3.2亿元，农业总产值3.17亿元。小板镇文化底蕴较为丰厚，国家级非物质文化遗产“糖塑”在小板得到较好传承，糖塑艺人较多。小板镇文化基础设施建设较为齐全。17个村（社区）均有较为完善的党员群众服务中心，集合了农家书屋、健身设备等功能场所，9个村建设了百姓大舞台。镇文化站有独立办公楼，各室分布达到市布标准。

三、主要任务

（一）完善公共文化服务设施。按照标准着力提升镇区综合文化服务中心建设水平，使综合文化服务中心（文化站）建筑面积达到300平米以上，设备配置、人员配备、管理服务等标准全面达标。村（社区）综合文化服务中心建设依托村（社区）党员群众服务中心等公共服务场所，面积达到200平方米，建有不低于500平方米的农村文体小广场。村（社区）农家书屋（图书室）拥有2000册以上图书、期刊和音像制品。完善农村广播电视基础设施，完成光缆联网和有线电视网络线路升级改造，实现全镇所有村（社区）广播电视“村村通”。

（二）增强公共文化服务能力。镇区综合文化服务中心每周免费开放时间不少于42小时，每年举办培训不少于10次，组织文体活动不少于12次。村（社区）综合文化服务中心每年组织2次以上文艺演出或群众文体活动。推进农村数字电影放映工程，实现村、社区每月放映1场电影全覆盖，探索免费发放电影券、集中放映等方式，不断提高农民观影质量。推进社区公益电影放映，大力开展科普知识宣传，广泛开展送科技下乡活动。

（三）完善公共数字文化设施。镇、村（社区）综合文化服务中心配备数字文化设施，具备数字文化服务能力。群众可以通过固定上网终端、网络电视、手机等多种方式使用文化共享工程和市级公共文化机构的数字服务资源。

（四）加大公共文化保障力度。

1、经费保障。按照基本公共文化服务标准测算公共文化服务经费，并将文化活动经费纳入财政预算。年度文化投入达到创建标准，人均文化事业费（按照常住人口计算）高于平均水平。

2、人才保障。在上级文化部门指导下合理设置公共文化岗位，优化专业人才队伍结构。村（社区）设置公共文化（体育）服务岗位，村（社区）至少配备1名财政补贴的宣传文化员，文化服务中心工作人员不少于2名。加强人才队伍后备力量的建设和培养，基层文化专兼职人员参加集中培训时间每年不少于5天。

3、制度保障。为确保创建活动顺利开展，建立公共文化服务体系制度。充分发挥理论引领和专家指导的作用，为全镇公共文化服务体系示范区创建工作提供制度保障。

四、打造品牌

进一步发掘小板“糖塑”潜力，对民间老艺人登记造册，加强扶持和保护，培育小板“糖塑”的名气和品牌；依托江台村美丽乡村试点项目，打造乡村文化旅游项目，实现文化与农业农村、生态环境的深度融合。

五、实施步骤

（一）启动建设阶段（2018年5月-9月）。深入调研，摸清现状，对接标准，进一步完善创建规划和实施方案，成立创建工作领导小组，统筹安排全镇创建工作。

（二）全面创建阶段（2018年10月-2019年10月）。按照创建标准、实施方案逐项落实，逐项达标，集中力量推进主要项目开展，着力抓好重点工程建设，推动镇区公共文化服务优质化。

（三）全力迎检阶段（2019年11月-2020年5月）。对公共文化服务体系建设工作进行认真自查总结，迎接市公共文化服务体系建设领导小组办公室检查验收。

六、工作要求

（一）加强组织领导。将创建活动纳入镇党委议事日程，定期研究部署。成立创建湖北省公共文化服务体系示范区领导小组，领导小组各成员要积极参与、支持公共文化服务体系示范区创建工作。领导小组定期召开例会，加强工作沟通协调。

（二）加大宣传力度。要切实提高思想认识，通过标语、横幅、报纸、微信等多种形式进行广泛宣传，形成全社会共同参与和推动示范区创建的良好氛围。

（三）加强监督检查。创建工作领导小组办公室要围绕创建工作的具体要求，加强对创建工作的督查力度，分阶段开展督查，对创建工作不力的村或单位进行通报或其他处理。
