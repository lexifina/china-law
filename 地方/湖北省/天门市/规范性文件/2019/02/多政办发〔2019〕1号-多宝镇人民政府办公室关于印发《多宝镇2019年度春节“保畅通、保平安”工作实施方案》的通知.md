# 多宝镇人民政府办公室关于印发《多宝镇2019年度春节“保畅通、保平安”工作实施方案》的通知

为认真做好春运道路交通安全工作，切实保障春运期间全镇道路安全畅通，为返乡群众创造良好的道路交通环境，结合我镇实际，特制定本实施方案。

一、工作目标

通过加强春节期间道路交通安全工作，确保不发生安全事故；确保镇区不发生交通堵塞，乡村道路不发生长时间、长距离交通拥堵，重要路段、主要路口通行有序畅通。

二、组织领导

2019年多宝镇春节期间道路保畅通、保平安工作在镇委镇政府统一领导下进行，由镇安全生产委员会牵头，镇安监办、多宝派出所、多宝交警大队、多宝工商所、多宝食药分局、村镇建设服务中心、居委会、沿线各村按照各自职能职责开展工作。领导小组名单如下：

第一组长：张 勇

组　 长：石 胜

副 组 长：杨忠德 梁浩然 张达贵 陈 立 潘 晶 武 力 王 涛 韩 蓉 夏 琦

成 　 员：刘克义 韩俊平 张皓玮 易 强 李春花 董日明 鲁登奇 段振华 常 青 赵华龙 敖俊岭

领导小组下设办公室，办公室设在镇安监办，敖俊岭同志兼任办公室主任具体做好组织、协调、督导工作。

三、时间要求

春节期间保畅通、保平安时间为：2019年1月21日—2月19日。专班人员每天早上8点前到镇政府大院集合、签到，统一行动。

四、工作安排

多宝派出所、多宝交警大队、多宝工商所、多宝食药分局、村镇建设服务中心要保证警力、配足人员，确保镇区无堵车，道路通畅；

江汉村、明星村、居委会协助做好镇区电动车、麻木、行人的疏导工作；

边湾村负责多宝二中至小公社路段及人民路口通畅；

风景新村负责小公社桥以东路段通畅；

彭场新村负责彭场街道无堵车，道路通畅；

郑场村负责郑场集市道路通畅；

沈场村负责沈场集市道路通畅；

罗汉村负责汉宜、荷沙线交汇路口畅通；

其它各村负责各自村路段道路秩序；

食药分局、工商所负责镇区各经营摊点的管理；

派出所、交警大队、村镇建设服务中心成立联合执法队对镇区车辆进行统一管理疏导。

各单位(村)将值班表于2019年1月20日前交镇201办公室(需附值班人员联系方式)。

五、工作要求

1.加强组织领导。各责任单位和责任人要严格按照方案要求，进一步细化工作措施，精心安排部署，确保组织到位。带班领导要率先垂范，合理调配警力，靠前指挥，确保岗位、责任、措施和领导“四到位”。

2.加强协调配合。各责任单位和责任人要根据各自职能和工作职责，严格落实各项工作措施，各司其责。同时要向相关单位主动通报情况，加强协调配合，确保不出疏漏。

3.实行责任倒查机制。与相关部门和村签订责任状，严格执行责任状有关要求，实行责任倒查机制。同时，强化执法责任和行政责任追究制，对不认真履行职责、工作不到位，发生公路“三乱”行为的，按照“谁主管、谁负责”、“谁管段、谁负责”的原则，不仅要追究直接责任人的责任，而且要追究相关领导的责任。

4.加强信息收集报送。各单位要强化信息收集反馈工作，遇有重大交通事故、交通堵塞或突发性事件要第一时间上报，不得迟报、漏报、瞒报(联系人：敖俊岭，[电话略])。
