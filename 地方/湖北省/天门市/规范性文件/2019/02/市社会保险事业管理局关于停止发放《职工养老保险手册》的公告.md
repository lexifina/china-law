# 市社会保险事业管理局关于停止发放《职工养老保险手册》的公告

各参保单位和参保人员：

为贯彻落实国家关于“放管服”改革精神，减化办事流程，提高办事效率，经研究决定停发《职工养老保险手册》(以下简称《手册》)，现就有关事宜公告如下：

一、自2019年2月18日起，新参加企业职工基本养老保险的人员，不再发放《手册》。参保人员在税务纳税大厅或社保费代收银行（邮政银行）缴纳职工养老保险费后，我局养老保险信息系统可以自动记录缴费信息，参保人员可在缴费次日后通过本公告第四条所列办法查询缴费情况。

二、2019年2月18日以前参加了企业职工基本养老保险的人员，原发放的《手册》继续有效，参保职工仍可持《手册》办理养老保险相关业务。

三、已持有《手册》的参保人员，2018年6月1日以后在市税务局纳税大厅或邮政银行缴纳了职工养老保险费的，我局养老保险信息系统已经自动记录缴费信息。参保人员可以通过本公告第四条所列办法查询，不需再到我局填写《手册》缴费记录。

四、参保人员缴费信息查询有三种方式：

1、网上查询。参保人可登录“天门人力资源和社会保障网上服务大厅”（http://219.138.246.147/tmwt/index.jhtml）、”关注“天门12333”微信公众号、下载“天门人社APP”等三种方式进行网上自助查询。查询时参保人需使用手机号、社保卡实名注册，注册的帐号可以在网上办事大厅、公众号、APP上通用。采用实名帐号登录后，可在社会保险缴费信息中查询。

2、自助服务终端查询。参保人在缴费后，可持本人社会保障卡就近在全市各乡镇人社中心社会保险服务大厅的社会保障自助服务一体机上查询。

3、市社保办事大厅查询。参保人持本人身份证到市人社局办事服务大厅二楼服务窗口查询。

五、参保人员咨询参保缴费相关业务，可以拨打12333电话服务热线进行咨询。
