# 天门市市场监督管理局《营业执照》采购询价公告

根据《中华人民共和国政府采购法》相关规定，我局现就《营业执照》项目进行询价采购，邀请有相应资质和具有相应供货能力的经营商根据询价文件要求参加本次采购活动，并提供满足要求的货物。采购项目要求如下：

一、项目名称：《营业执照》项目

二、项目内容：《营业执照》项目采购

三、报价人须知：

（一）报价人须符合《中华人民共和国政府采购法》第二十二条规定，必须具备湖北省政府集中采购项目2018年度印刷定点服务协议供应商资格。

（二）报价人报名时须提供本单位载有统一社会信用代码的法人营业执照、法人代表身份证或法人代表授权委托书（提供原件，复印件加盖公章留存）和证明自身资质的证明材料。

（三）报名及询价文件领取：2019年3月29日至4月3日（上午8：00—11：30，下午14：30—17：30），报价人可带相关证件到询价小组领取本项目底价文件，或通过网络传递，获取本项目底价文件。

（四）询价响应文件递交地址： 天门市竟陵办事处陆羽大道西21号 天门市市场监督管理局（原天门市工商局注册分局），可以面送亦可快递方式递交，邮编：431700。

截止（报价）时间：2019年4月3日17:30，逾期或不符合规定的询价响应文件恕不接受。

（五）报价人对每个品目和每种货物仅允许提供一个报价，否则，该报价将视为无效。报价应包括运输、税金等所有费用且总报价不得超过采购预算。

（六）报价人必须按产品规定提供质保。

（七）验收：由采购人组织验收。

（八）付款方式：验收合格后按法定程序付款。

（九）报价人及其代表应遵循政府采购的法律法规及通行规则。
