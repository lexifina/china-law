# 天门市烟草专卖局关于印发2019年天门市烟草专卖局党风廉政建设和反腐败工作要点的通知

各部、所、队，机关各部门：

现将《2019年天门市烟草专卖局党风廉政建设和反腐败工作要点》印发给你们，请结合实际，认真贯彻落实。

天门市烟草专卖局

2019年3月29日

（主动公开）

2019年天门市烟草专卖局党风廉政建设和反腐败工作要点

2019年工作的总体要求是：以习近平新时代中国特色社会主义思想为指导，深入贯彻党的十九大和十九届二中、三中全会精神，贯彻中央纪委三次全会、省纪委十一届三次全会、驻工信部纪检组2019年纪检工作会议、全国烟草行业落实全面从严治党主体责任工作会议、全省烟草商业系统落实全面从严治党主体责任工作会议安排，不忘初心、牢记使命，增强“四个意识”，坚定“四个自信”，坚决做到“两个维护”，坚持稳中求进总基调，以党的政治建设为统领，加强正风肃纪，强化监督执纪，坚决惩治腐败，一体推进不敢腐、不能腐、不想腐的体制机制，建设忠诚干净担当的纪检监察队伍，为市局贯彻落实党的十九大精神和党中央决策部署，以及省市和行业决策部署，实现高质量发展提供坚强保障。

一、坚守政治责任，践行“两个维护”

（一）切实强化理论武装。组织开展学习十九大报告，深入学习习近平新时代中国特色社会主义思想。利用党组理论学习中心组学习、党日学习、“三会一课”、专题培训等方式，利用纪检监察网站、学习强国APP、微信公众号等平台，开展系统学、深入学、经常学、反复学，用以武装头脑、指导实践、推动工作。

（二）切实强化政治建设。把增强“四个意识”，强化“四个自信”，践行“两个维护”作为政治建设的首要任务，始终在思想上政治上行动上同以习近平同志为核心的党中央保持高度一致。维护党的纯洁和团结统一，维护党的纪律和规矩，积极协助党组履行主体责任，主动献计献策，当好参谋助手，围绕纪检监察各项工作任务，认真开展监督检查，及时发现问题纠正偏差。

（三）切实压实“两个责任”。继续抓实主体责任这个“牛鼻子”，监督推进主体责任向基层延伸，严格监督党员干部落实“一岗双责”，加强定期检查和结果通报，综合运用“四种形态”，切实推进管党治党走向严、紧、硬。

（四）切实维护好政治生态。加强党内监督，对坚持党的民主集中制情况开展监督，维护风清气正的政治生态。对党组议事规则情况和民主生活会开展情况进行监督，把党组理论学习中心组学习、“三会一课”，谈心谈话等活动情况纳入日常监督重点，协助党组把班子建设好，把干部管理好，把队伍建设好。

二、坚持治理“四风”，狠抓落实中央八项规定精神

（五）抓住关键抓检查。继续开展党员干部大操大办婚丧喜庆事宜治理、“节日病”治理活动。认真落实上级部署，开展形式主义和官僚主义整治，深入开展不担当、不作为纠治。加大对会议纪律、工作作风的监督检查，着力解决作风漂浮、纪律松懈、担当不力问题。

（六）抓住重点抓检查。把党员干部利用名贵特产资源谋取私利问题以及业务招待、公车管理、津补贴发放、财务报销等业务环节存在的“四风”问题作为监督检查的重点，以钉钉子的精神，一个个抓实，一点点突破，以点带面推动全局。

（七）聚焦难点抓检查。对行业巡视巡察问题整改和专项检查问题整改情况开展“回头看”，对照问题清单、整改清单进行再清理，做到全部整改到位，并防止前整后犯，问题反复。

三、坚持风险防治，切实防范系统性廉洁风险

（八）深化廉政风险防控体系建设。组织各部门开展廉政风险防控，做好风险摸排，及时预警处理，及时化解风险。

（九）加大对重点领域的监督检查。开展物资采购、工程建设、招标投标、选人用人、营销费用等五大领域的专项治理，对市局落实“三重一大”决策制度情况开展监督检查。

（十）加大廉政把关力度。开展党员干部廉政档案管理，完善个人重大事项报备审核抽查工作；开展干部选拔、轮岗交流、评先评优和“两代表一委员”评选工作的廉政审核把关工作，坚决守好廉政审核关口。

（十一）深入开展同级监督。探索和完善纪检组对同级党组的监督，运用好监督方式，提高监督质效。每半年向省局纪检组单独报告主要负责人、班子成员在落实全面从严治党主体责任和履行“一岗双责”的表现。

四、坚持正风肃纪，狠抓作风纪律建设

（十二）加大对会纪会风的有效监督。持续整肃会纪会风，加强对市局会纪会风执行情况的监督，及时通报违反会纪会风的典型行为。

（十三）加大对履职履责的有效监督。加强对党员干部和公职人员履职履责的监督，开展有针对性的专项检查和突击检查，倒逼职、权、责有机统一。

五、坚持铁面执纪，综合用好“四种形态”

（十四）加大“四种形态”中的综合运用，让党员干部守纪于底线前，止步于红线前。

（十五）对于顶风违纪、性质恶劣的典型案件，将继续高压问责，不姑息、不手软。

（十六）严格规范办案纪律和工作程序，坚持落实“一案双查”和“一案两报告”，确保党员干部做到知敬畏、存戒惧、守底线。

六、坚持队伍提升，加强纪检铁军建设

（十七）开展纪检队伍学习培训，深入学习贯彻《中国共产党纪律检查机关监督执纪工作规则》，着力提高执纪工作能力水平。

（十八）突出党性观念和政治建设，强化能力建设，进一步提升纪检队伍工作水平，确保政（十九）加强对纪检干部严格管理，以更严的纪律、更高的要求确保忠诚、干净、担当。
