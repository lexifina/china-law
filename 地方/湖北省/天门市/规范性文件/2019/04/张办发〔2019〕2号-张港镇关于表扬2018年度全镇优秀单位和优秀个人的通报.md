# 张港镇关于表扬2018年度全镇优秀单位和优秀个人的通报

2018年，全镇广大干部群众紧紧围绕镇委镇政府制定的工作目标，埋头苦干，锐意进取，各条战线上都取得了较好的成绩，涌现出了一批优秀单位和优秀个人。经镇委镇政府研究，决定对获得“优秀单位”的狮子桥村等20个单位以及获得“优秀个人”的龚则忠等50名同志予以通报表扬，具体名单如下：

一、优秀单位（20个）

狮子桥村、尹港村、罗高村（原高拐村）、九郡村、熊刘村、顺河新村（原顺河村）、白果树村、蒲潭村、习家口村（原增加村）、天门农商行张港支行、镇水管站、镇农技服务中心、镇堤防管理段、工商分局、镇派出所、镇供电营业所、镇卫生院、张港高级中学、张港中心学校、镇文化服务中心。
