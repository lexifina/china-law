# 石家河镇人民政府办公室关于印发《石家河镇2019年第二次安全生产大检查实施方案》的通知

各村（居）民委员会、镇直有关单位：

现将《石家河镇第二次安全生产大检查实施方案》印发给你们，请认真贯彻执行。

石家河镇人民政府办公室

2019年4月2日

石家河镇2019年度第二次安全生产大检查实施方案

为认真贯彻上级关于加强安全生产工作的决策部署，切实保障人民群众的生命财产安全，镇安委会决定开展2019年度第二次安全生产大检查，现制定实施方案如下：

一、检查时间

2019年4月1日（星期一）至4月4日（星期四）

二、参加人员

第一组

组 长：谢国清

副组长：余 晨 张 伟

成 员：严 盟 派出所干警一名 工商所人员一名

第二组

组 长：陈 璐

副组长：夏齐飞 汪丽群

成 员：徐团元 派出所干警一名 工商所人员一名

第三组

组 长：王菊娥

成 员：张彩虹 张作彬

第四组

组 长：谢红宜

成 员：徐 鑫

第五组

组 长：汪家祥

成 员：徐团元　 派出所干警一名

第六组

组长：郭义松

成员：谷 宇 聂永波 派出所干警一名 村镇建设服务中心工作人员一名

注：每组成员中加粗者为联络员。

三、工作要求

1.各检查组要到被检查企业（单位）认真开展检查，督促企业（单位）建立健全安全生产责任制，深入排查隐患并督促整改，填写好《安全生产检查记录表》，做到一企一表、痕迹管理。

2.检查的具体时间由各组组长确定，组员由联络员负责联络。如需车辆等后勤服务，由党政办统一安排。

3.请各组于4月12日前将检查情况资料（记录表、照片等）交给徐团元主任汇总存档。
