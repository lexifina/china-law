# 石家河镇人民政府办公室关于印发《石家河镇2019年政策性“三农”保险工作实施方案》的通知

各村民委员会、镇直有关单位：

《石家河镇2019年政策性“三农”保险工作实施方案》已经镇政府同意，现印发给你们，请认真组织实施。

石家河镇人民政府办公室

2019年5月6日

石家河镇2019年政策性“三农”保险工作实施方案

为了认真贯彻落实省、市两级人民政府关于开展政策性“三农”保险工作的会议精神，切实做好我镇政策性“三农”保险工作，结合我镇实际，制订如下实施方案。

一、指导思想

以农业保险条例为指针，以化解和防范农业风险为目的，以合规经营为重点，以加强监管为手段，以完善服务为抓手，积极稳妥开展2019年农险工作。

二、组织领导

镇成立政策性“三农”保险工作领导小组。组长：党委副书记、镇长陈璐；副组长：党委副书记汪家祥、纪委书记李玉红、组织委员刘雄军；成员：万义传、刘春兵、徐团元、冯小仙、肖尧、蒋刚兵、张晓明、李京军、田利刚、夏仕君。领导小组下设办公室，刘春兵同志兼任办公室主任。

三、实施内容

（一）水稻基础保险和大灾保险。水稻保险由基础保险和大灾保险组成，基础保险每亩保险金额400元；适度规模经营农户可以投保水稻大灾保险，每亩每季保险金额300元。水稻基础保险，每亩保险金额400元，保险费率6%，每亩保费24元。中央财政承担比例由原45%调整为47.5％，每亩保费11.4元；省级财政承担30％，每亩保费7.2元；农户承担比例由原25%调整为22.5%，每亩保费5.4元。水稻大灾保险面向适度规模经营农户，每亩每季保险金额300元，保险费率6%，每亩保费18元。中央财政承担47.5％，每亩保费8.55元；省级财政承担30％，每亩保费5.4元；农户承担22.5%，每亩保费4.05元。适度规模经营主体指种植水稻的专业大户、家庭农场、农民专业合作社和农业产业化龙头企业。适度规模经营主体投保大灾保险需提供真实有效的土地来源合同或证明。参加大灾保险每亩保险金额最高700元，农户共缴保费9.45元。（人保财险公司承办）

（二）能繁母猪保险。保险金额为每头1000元，保险费率6%，每头保费60元，其中：中央财政补贴50%，每头30元；省级财政补贴30%，每头18元；养殖户承担20%，每头12元。（人保财险公司与国元保险公司承办）

（三）“两属两户”农房保险。保险金额为每户3000元，保险费率3‰，每户保费9元，其中：省级财政补贴70%，每户6.3元；市财政补贴30%，每户2.7元。（人保财险公司承办）

（四）棉花保险。保险金额为每亩400元，保险费率7%，每亩保费28元，其中：中央财政补贴40%，每亩11.2元；省级财政补贴25%，每亩7元；市财政补贴10%，每亩2.8元；农户承担25%，每亩7元。（中华保险公司承办）

（五）小麦基础保险和大灾保险。小麦基础保险面向所有小麦种植主体，每亩保险金额300元，保险费率6%，每亩保费18元。中央财政承担47.5％，每亩保费8.55元；省级财政承担30％，每亩保费5.4元；农户承担22.5%，每亩保费4.05元。小麦大灾保险面向适度规模经营主体，每亩保险金额150元，保险费率6%，每亩保费9元。中央财政承担47.5％，每亩保费4.275元；省级财政承担30％，每亩保费2.7元；农户承担22.5%，每亩保费2.025元。适度规模经营主体指种植小麦的专业大户、家庭农场、农民专业合作社和农业产业化龙头企业。适度规模经营主体投保大灾保险需提供真实有效的土地来源合同或证明。（中华保险公司承办）

（六）油菜保险。保险金额为每亩200元，保险费率5%，每亩保费10元，其中：中央财政补贴40%，每亩4元；省级财政补贴25%，每亩2.5元；市财政补贴10%，每亩1元；农户承担25%，每亩2.5元。（太平洋保险公司承办）

（七）农村小额人身保险。参保对象为出生28天以上、80周岁以下身体健康的农村居民。每人每年保费50元。0-65周岁：一般意外伤害及伤残保险金额20000元，重灾意外伤害及伤残保险金额50000元，疾病身故保险金额500元，意外伤害住院津贴50元/天（最长180天）；66-80周岁：交通意外伤害及伤残保险金额20000元，重灾意外伤害及伤残保险金额50000元，疾病或意外身故保险金额500元，意外伤害住院津贴50元/天（最长180天）。（中国人寿保险公司承办）

四、工作步骤

（一）宣传发动阶段（4月27日—5月5日）

各村根据实际情况，充分利用电视、广播、报纸、网络、农户告知单（告知单填写并发放到户，农户签字认可）等方式大力宣传开展政策性“三农”保险的重要意义、方法步骤及相关政策，让党和政府的惠农政策家喻户晓，人人皆知，使广大农民真正了解政策性“三农”保险的重要作用，增强保险和风险防范意识，提高参与政策性“三农”保险的自觉性。

（二）水稻、棉花保险信息收集阶段（5月6日—5月15日）

各村安排人力物力，开展信息收集工作，确保农户姓名、身份证号、投保面积、联系方式、“一卡通”账户或其他有效账户、开户银行等承保信息准确、真实、完整，同时乡镇财管所做好承保信息的审核，确保工作合规。

（三）水稻、棉花承保公示、保费收取阶段（5月16日—5月31日）

各村按保费方案，对收集的承保信息进行公示，并依法收取农民应承担的保费。各村在确保依法合规的前提下，对信息收集及保费收取工作可以同步进行。

（四）保单、凭证发放阶段（7月）

各村将保险承保后的保单、凭证及时无误地送到每个农户手中，确保凭证到户率达到100%。

（五）其他险种的实施（下半年）

能繁母猪、奶牛、“两属两户”农户保险到期后按时续保。油菜11月承保。

五、结账方案

（一）结账时间：5月31日以前。

（二）结账办法：按时完成全额任务的给予工作经费。

对村的结账：任务在2万元以上的村发放1000元的工作经费；任务在1--2万元的村发放800元的工作经费；任务在5000--10000元的村发放600元的工作经费；任务在5000元以下的村发放400元的工作经费。对棉花保险按时完成任务的村发放400元的工作经费。

各片工作经费根据各片任务完成情况由镇统一解决。

六、工作要求

各村要加大保险政策宣传力度，切实做好“三农”保险各项基础工作。保险凭证要落实到户，确保凭证信息准确；要依法收取及时上缴农民应承担的保费；要切实保障投保农户的利益，及时查勘定损，及时逐一赔付到户；不得弄虚作假、虚报投保数量；承保和理赔情况要张榜公布，不得以各种名义虚报、冒领、骗取赔付资金；要按期将“三农”保险的承保、理赔等情况报中国人民财产保险股份有限公司。
