# 关于加强房地产开发项目管理服务工作的通知

各市、州、直管市、林区住建局（房管局）：

为深入开展全省住建系统"服务企业提质年"活动，进一步优化营商环境，推进房地产供给侧结构性改革，现将加强房地产开发项目管理服务工作通知如下：

一、健全房地产开发项目手册制度。各市（州）要按照《湖北省城市房地产开发经营管理办法》要求，建立健全房地产开发项目手册制度，督促开发企业将开发项目的投资、施工、预（销）售、竣工验收、交付等记录在房地产开发项目手册中，并定期送房地产开发主管部门备案。未按要求落实房地产开发项目手册制度的企业，依据《商品房销售管理办法》《房地产开发企业资质管理规定》有关规定处理。

二、强化房地产开发项目动态管理。各市（州）要组织县（市、区）对辖区内房地产开发企业和开发项目进行全面梳理，4月30日前将《房地产开发投资和重点项目情况表》（附件1）报送省厅。及时跟踪房地产开发项目动态，按照《转发住房城乡建设部关于进一步规范和加强房屋网签备案工作的指导意见》（鄂建文〔2019〕15号），每月3日前通过"湖北省房地产市场监测系统"将《房地产开发项目投资计划表》（附件2）报送省厅。

三、加强房地产开发企业监管服务。各市（州）要建立联系企业制度，加强政策宣传，提升房地产开发项目管理水平；加强市场监管，规范房地产开发企业经营行为。建立部门联动协作机制，按照《省住建厅、省统计局关于做好全省房地产市场统计工作的通知》（鄂建文〔2015〕72号）要求，做好信息共享、联合督办、业务培训，加强部门间统计数据的协同性，提升房地产开发项目相关情况的报送质量。
