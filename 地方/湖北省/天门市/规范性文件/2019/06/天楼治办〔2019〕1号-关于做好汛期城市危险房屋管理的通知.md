# 关于做好汛期城市危险房屋管理的通知

各乡、镇人民政府，各办事处、农场，天门高新园，天门工业园，市政府各部门：

近期我市普降大到暴雨，为确保人民群众生命财产安全，切实做好汛期城市危险房屋管理工作，加强灾害防范应对，现将有关极端天气期间开展老楼危楼排查整治工作事项通知如下：

一、排查工作要求

按照“谁主管谁负责”的原则，各地负责本辖区内城镇房屋的安全排查和隐患整治工作，各行业主管部门负责本行业内各单位房屋的安全排查和隐患整治工作。从即日起，排查整治工作要立即开展，做到迅速、全面、彻底，对发现的问题和隐患及时采取排险解危措施，坚决防止坍塌事故发生，切实保护人民群众生命财产安全。

二、排查的范围和内容

暴雨来临前迅速开展城市危房排查，重点检查辖区内在册危房、易受凤雨荷栽影响的砖木结构房屋、受地质灾害威胁的房屋、地势低洼房屋；接近、达到或超过正常使用年限的老旧房屋。对地基下陷、墙体开裂、倾斜的房屋，尚未治理仍在使用的危险房屋，以及存在安全隐患的公共场所房屋的安全状况要重点关注，安排专人巡查，对排查发现的问题和隐患要密切跟踪，及时采取排险解危措施，建立危险房屋安全隐患清单、整改台账、落实管理责任。

三、抓紧完善应急预案

各地要抓紧制定和完善汛期危房突发事故应急预案，加强气象预报和灾害预警信息监测，对存在洪水、滑坡和泥石流等威胁的要提前采取防范应对措施。做好应急救援物资和人员准备工作，适时组织应急演练。与相关部门建立协调联动工作机制，制定应急排险措施，提高处置房屋安全突发事故的能力，确保将灾害损失降到最低。

四、加强值班值守

各地各部门要严格落实汛期24小时值班和领导带班制度，严防值班脱岗、空岗和其他问题的发生。强化信息报送制度，确保信息畅通，坚决杜绝迟报、谎报、瞒报。遇到紧急情况、重大问题随时报告，灾害发生后，应第一时间将基本情况、原因、应对措施及处置情况等报送。

五、开展督导检查

各地各部门应切实加强对所辖区内汛期城市危险房屋管理工作的督导，全面总结工作开展情况，针对突出问题制定有效措施，建立房屋安全监管长效机制，并于6月28日前将相关情况上报市老楼危楼安全排查整治工作领导小组办公室。
