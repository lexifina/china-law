# 天门市2019年杨树食叶害虫防治实施方案

为了有效控制和应对杨树食叶害虫危害，保护全市生态景观，最大限度地减少病虫害造成的损失，保障我市林业健康持续发展和国土生态安全，依据《森林病虫害防治条例》、《湖北省林业有害生物防治条例》、《国务院办公厅关于进一步加强林业有害生物防治工作的意见》（国办发[2014]26号）等有关要求，结合我市实际，特制定本实施方案。

一、2019年杨树食叶害虫发生趋势预测

杨树是我市的主要造林树种，随着杨树栽植面积迅速增长，生态脆弱性日趋呈现，由此引起的杨树食叶害虫危害日趋加剧。根据预测，我市2019年杨树食叶害虫发生面积8.05万亩。主要种类有杨扇舟蛾、杨小舟蛾、分月扇舟蛾、杨尺蠖、舞毒蛾和杨毒蛾等。全市杨树种植地均有发生，各乡镇皆有分布，局部地区可能爆发成灾。

二、指导思想、基本原则、防治目标

（一）指导思想

按照“预防为主，科学治理，依法监管，强化责任”的方针，根据省政府与市政府签订的《天门市重大林业有害生物防控目标责任书》和《天门市重大林业有害生物灾害应急预案》的要求，依法科学防治，有效降低损失，确保我市杨树资源和森林生态安全。

（二）基本原则

预防为主，适时防治，注重效果；属地管理，依法治理，联防联治；突出重点，分类施策，全面防治。

（三）防治目标

2019年6月至8月期间运用各种防治技术，在全市范围内组织开展1-2次杨树食叶害虫防治，确保国道、省道、县道两侧杨树林带及杨树片林有虫不成灾，杨树食叶害虫危害区杨树叶片保存率达80%以上。

三、防治区域划定

根据杨树生态社会功能不同，将杨树食叶害虫防治划分为重点防治区域、一般防治区域，分别采取不同的防治措施。

（一）重点防治区域：国道、省道、主要河道、重要绿色通道、旅游景区。

（二）一般防治区域：县道、乡道、河道、渠道的两侧林带、杨树片林、农田林网。

防治责任区划分

根据“属地管理”和“谁栽植、谁受益、谁防治”的原则，划分不同责任单位。

（一）汉宜线天门段、荷沙线天门段、分当线天门段、潜杨线天门段、天岳公路等国道、省道两侧林木由交通部门组织防治。

（二）汉江沿线防护林由天门汉江河道管理分局组织防治。

（三）汉北河、皂市河、天门河、天南总干渠等主要河渠防护林由水利部门组织防治。

（四）天仙公路、武荆连接线、天佛公路等重要绿色通道两侧林带由市自然资源和规划局组织防治。

（五）市道、乡道、渠道两侧林带、杨树片林、农田林网由所在乡镇组织林业生产经营者开展防治，确保不出现灾情。

五、工作措施

（一）加强组织领导，强化领导责任

市政府成立杨树食叶害虫防治工作领导小组，分管领导任组长，市自然资源和规划局、市水利和湖泊局、市交通运输局、天门汉江河道管理分局等部门为成员单位。领导小组下设办公室，办公室设在市自然资源和规划局。各地和相关单位也要成立相应机构，明确工作任务，切实履行职责，形成主要领导亲自抓，分管领导负责抓，工作专班具体抓，一级抓一级，层层抓落实的工作局面。各地和相关单位要明确主要负责人为第一责任人，分管负责人为主要负责人。落实领导和包保责任制，全面部署防控工作。市自然资源和规划局负责杨树食叶害虫防治技术指导，做好相关协调工作。

（二）加强虫情监测，做好预测预报

市自然资源和规划局要加强虫情测报工作。要在现有测报点基础上，增加测报点数量和测报频次，配备必要的仪器设备和交通、通信工具，全面提高测报准确率。要建立健全测报会商制度，准确分析虫情动态形势，及时向社会发布杨树食叶害虫预警信息。

（三）加大资金投入，提高防治能力

市政府将林业有害生物监测防治所需资金纳入财政预算，加大对林业有害生物预防防治的基础设施建设，全面提高防控能力，确保应急事件和突发疫情得到及时有效的处置。
