# 天门市烟草专卖局关于印发2019年度法规工作要点的通知

各队、所、部，机关各部门：

现将《天门市烟草专卖局2019年法规工作要点》予以印发，请认真贯彻落实。

天门市烟草专卖局

2019年5月22日

（主动公开）

天门市烟草专卖局2019年法规工作要点

2019年，市局法规工作的总体要求是：以习近平新时代中国特色社会主义思想为指导，深入学习贯彻落实行业法规体改工作会议和全省系统专卖内管法规工作电视电话会议精神，紧紧围绕法治烟草建设中心，深入开展法治宣传教育，全面提升“三个依法”水平，加强法治烟草人才队伍建设，为市局高质量发展提供坚实的法治保障。

一、把握普法工作重点，深入开展法治宣传教育

（一）把握关键少数，落实学法用法要求。把法律法规的学习纳入党组中心组学习计划安排，全年至少组织一次党组中心组集体学法。坚持抓好“无纸化学法用法”的学习活动，确保学时学分、参学率、参考率和通过率达标。强化党内法规学习，不断增强全体人员的法纪意识。

（二）把握主体责任，健全完善普法机制。按照“谁执法谁普法”的工作要求，落实党建、纪检监察、专卖、内管、营销、信息安全等部门和基层部、所的普法工作责任，做到普法工作全覆盖。

（三）把握方式创新，营造浓厚普法氛围。以“3.15”、“12.4”、“法治大讲堂”等活动为抓手，充分利用微信、手机APP等现代传媒手段，不断创新普法的方式方法，拓展宣传途经，丰富普法载体，营造浓厚普法氛围。

二、围绕法治烟草建设中心，不断提升“三个依法”水平

（一）围绕制度建设，全面推进法治烟草建设。建立健全行政执法公示制度、执法全过程记录制度、重大执法决定法制审核制度。认真落实行政规范性文件合法性审核制度。贯彻落实全省系统法律纠纷应对管理办法。

（二）围绕执法监督，全面落实执法主体责任。认真组织开展2019年案卷评查工作，协助做好国家局省局布置的专卖执法案件自查工作，及时发现问题，整改问题，确保案卷质量。开展执法资格审验，严格执法资格管理，认真解决执法人员主体资格问题，从源头防范执治风险。落实“双随机一公开”制度，确保执法公开、公平、公正。

（三）围绕窗口建设，全面优化政务服务。按照“互联网+政务服务”的工作要求，配合专卖部门做好“网上审批”、“证照分离”等工作。认真组织开展“双评议”工作，主动接受群众监督。严格落实烟草专卖行政许可事项限时办结的规定，烟草专卖零售许可事项办结时限在5个工作日以内，其余行政审批事项办结时限8个工作日以内。

（四）围绕合同管理，全面深入维护企业权益。进一步健全完善授权委托管理制度和合同管理制度。强化经济合同的审查管理，充分发挥合同审查的作用，严格把关，最大限度堵塞合同管理漏洞。认真组织开展2019年合同评查工作。

（五）围绕风险防控，全面提升企业良好形象。将法规工作融入业务工作之中，全面加强专卖执法、卷烟营销、广告宣传、劳动用工、合同管理等方面的法律风险防控工作。聚焦公共场所控烟、卷烟零售户自律小组建设、文明吸烟环境建设、新型烟草制品监管等重点、热点问题，提高政策研究和沟通协调能力。严格落实涉诉、涉法案件上报制度，有效避免系统性风险。

三、聚焦人员素质提升，加强法治烟草队伍建设

（一）发挥外聘法律顾问作用。进一步加强外聘法律顾问的管理，健全完善法律顾问协调参与相关事务咨询会商、合同会审、疑难问题会诊工作机制，充分发挥外聘法律顾问参谋、协调、服务作用。

（二）着力加强业务培训。围绕国家和行业立法新成果、新型烟草制品监管、专卖执法、合同管理、涉法纠纷等重点工作开展业务培训。创新课程设置，优化培训方案，增强培训的针对性、时效性、实用性，着力提升全员法律素养和业务能力。

（三）做好“两公”律师证照申请工作。按照国家局实施行业公职律师和公司律师制度的有关部署，做好市局符合申领“两公”律师资格人员的证照申请工作，为法治烟草建设提供人才储备。
