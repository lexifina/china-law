# 天门市蒋场镇农村集体账务流水账公开实施方案

为切实加强我镇农村“三资”管理，全面实施乡村振兴战略，经镇党委政府研究，决定在全镇全面开展农村集体账务流水账公开工作，现制定实施方案如下：

一、工作目标

通过对全镇各村集体账务收支日常流水账目“全覆盖、零隐瞒”的公开公示，全力打造村级“阳光账务”，并以流水账公开为着力点，全面提升我镇农村集体“三资”管理水平，切实保障人民群众的知情权、参与权和监督权、激发人民群众参与村级治理和村级发展建设的热情，提升人民群众的获得感、幸福感。

二、公开范围及形式

以村级账务流水账公开为切入点，做到过程公开、结果公开。

（一）公开内容。覆盖农村集体经济组织所有的经济活动，具体包括账务预决算、财务收支、代收代付、债权债务、资产资源处置、征地补偿费用分配等，以及村民会议或村民代表会议要求公开的事项。村级账务流水公开是指以村级经济活动发生的时间为顺序对村级账务逐笔进行公开公示，解答群众质疑，接受群众监督。

（二）公示时间。

1.村级账务，按年度公开。以会计年度为基准，每年12月下旬进行，预决算在村民会议或村民代表会议讨论通过后，于次年1月份公开，公开时间不得迟于1月20日。

2.村级情况按季公开，每季度的下月20日前进行公开，第四季度可与年度公开事项同步，不得迟于次年1月20日。

3.村民代表会议要求公开的重大事项在发生后的第一时间公开。

4.所有公开事项的公示时间不得少于30日。

（三）公开形式。以村务公开栏公开为主，微信公开为辅的方式进行。

1.各村必须建有规范的村级账务公开栏，有条件的地方可以建立组级公开栏，介于同步公开涉及本组权益的事项。

2.可建立“村级流水账公开”微信群。由村级党组织指定一名村干部为群主，村支部委员、村委会成员、村务监督委员会成员、村民代表以及有意愿加入本群、关心村级账务的党员和群众为群成员。为便于及时了解流水账公开活动的进展情况，迅速推动工作，乡镇分管领导、财政所负责人、专业会计也要加入本群，微信群同步上传村务公开栏流水账公开图片、电子文档。流水账公开内容在微信群公开后，群成员有异议的直接在群上反映，群主负责收集整理群众对公开事项的反馈意见，并及时答复。对不会使用微信的党员、群众、村委会要安排专人负责收集整理他们的意见，并予以回复。镇直单位也要建立微信群，乡镇分管领导、财政所负责人为群成员，及时了解工作动态。

三、实施步骤

（一）宣传发动（2019年6月15日前）。各村（居委会）召开村级流水账公开动员会，成立领导小组，制定实施方案并报镇委组织办，镇财政所备案。各村（居委会）要加大对流水账公开的宣传力度，充分调动基层干部和广大群众参与流水账公开工作的积极性。

（二）业务培训（2019年6月10日前）。召开全镇农村集体流水账公开业务培训会，统一流水账公开微信群。做到有账可公，有账必公，公开及时，条理清晰，通俗易懂。

（三）前期准备（2019年6月30日前）。一是村级全面处理未入账条据，滞留在村级的资金必须全额上缴村级资金代管专户，及时收付，及时入账；二是研究村级资产资源处置、工程建设、征地补偿分配等重大事项的具体实施办法；三是设置标准的村务公开栏；四是建立“村级流水账公开微信群”。

（四）集中公开（2019年7月20日前）。首轮集中公开时间全镇统一为2019年7月20日前，公开内容为2019年元月至6月村级账务收支情况等村级经济活动，在村级村务公开栏和微信群同步公开。以后每季度按要求进行公开。

四、保障措施

（一）加强组织领导。镇委组织办、镇财管所加强对村级账务流水账公开工作的具体指导，镇党委政府负责工作的组织实施，合地要落实本村书记、主任负总责，分管领导具体妥善解决，确保村级账务流水账公开工作稳步推进。

（二）明确责任分工。建立健全镇党委政府统一领导，部门分工协作，群众广泛参与的工作机制。镇党委政府负责村级财务流水账公开工作的指导、督导和考核，乡镇财政所负责按要求及时提供农村流水财公开的资料并保证流水账公开资料的真实性。镇委组织办、镇财管所要及时总结推广工作中成功经验，及时发现并研究解决工作中存在的突出问题保证村级财务流水账公开工作顺利进行。

（三）严格督查考核。镇委组织办，镇财管所督查检查专班，对全镇村级流水账公开的形式、内容以及群众对公开事项存在异议的处理情况进行督查检查，对工作中存在的问题指导全镇各村及时进行整改、形成“三资”规范监管的有效机制。各村（居委会）要对农村集体财务流水账公开情况进行经常性了解，每季度组织一次集中检查，建立工作台帐，各村（居委会）要将此项工作纳入村级目标进行管理，并作为考核农村基层干部政绩的重要内容，进行量化考核。

（四）严格执纪问责。对村级财务流水账公开工作走形式、走过场的，我镇纪检监察部门要严格执纪监督；对工作中违反政策规定、徇私舞弊人行为要及时查处、公开曝光；对存在的问题整改不力，群众的反映较大的，对相关责任人进行严肃追责问责；对挥霍、侵占、挪用、私吞集体财物及其他违法行为的，依法及时处理，情节严重构成犯罪的，移交司法机关机关追究刑事责任。
