# 石家河镇人民政府办公室关于印发《石家河镇2019年厕所革命实施方案》的通知

各村（居）民委员会：

《石家河镇2019年厕所革命实施方案》已经镇政府研究同意，现印发给你们，请认真组织实施。

石家河镇人民政府办公室

2019年7月9日

石家河镇2019年厕所革命实施方案

为认真贯彻落实习近平总书记关于“厕所革命”的重要指示精神，按照《天门市“厕所革命”攻坚行动实施方案的通知》相关要求，结合石家河镇工作实际，特制定石家河镇2019年厕所革命实施方案。

一、指导思想

深入贯彻落实党的十九大精神，以习近平总书记关于“厕所革命”重要指示为指导，牢固树立“小厕所、大文明、小厕所、大民生”理念，扎实推进“厕所革命”，全面完成农户无害化厕所建改任务，全面提升镇区、石家河遗址广场、各村党员服务中心公共厕所服务质量，倡导健康文明生活方式，不断满足人民群众对美好生活的需求。

二、目标任务

1.农户无害化厕所建改4425户；

2.农村公共厕所建改33座；

三、资金保障

根据文件精神及我镇实际，农村无害化厕所改造户补助标准为：一般农户省级补助400元，市级配套400元，共800元，贫困户省级补助500元，市级配套700元，共1200元，其余不足部分由农户解决。镇区公共厕所、遗址广场公厕、农村公共厕所将采取政策支持、社会资助相结合的渠道筹集改厕资金。

四、“厕所革命”工作内容

1.加强统筹规划。农户无害化厕所、农村公共厕所、城镇公共厕所纳入城乡总体规划，合理选点布点、优化建改模式。将2018年工作的刹尾、验收与今年新的目标任务捆绑结账。

2.开展全面建改。采取建改结合、补面提标的方式，采用无害化和资源化处理等先进技术，加快城乡厕所标准化，规范化建设。农户无害化厕所坚持“政府主导、农户主体、因地制宜、一村一策”的原则，结合农村生活环境整治、农村污水治理、农村有机物沤肥利用，推行三格化粪池、双翁漏斗式、三联通式沼气厕所等多种无害化卫生厕所模式。重点加强农村党员（社区）服务中心、学校、集贸市场、公共场所、人口集中的居民点、休闲旅游地、田园综合体等厕所建设。镇区公共厕所将坚持“全面规划、补齐短板、合理布局、方便群众、有利排运、资源化利用”的原则，部门协同推进建设。农村公共厕所达到无害化标准，镇区公共厕所建设标准不低于二类。统筹部分镇区公共厕所按照旅游厕所标准建设。厕所建设大力推行节能、节水、节电等新技术、新工艺、新材料，镇区周边有条件的村污水收集管网要与乡镇污水处理厂联通。

3.强化管理提升。建立长效管护机制，建立社会化的农村厕所管理运营组织，充分利用现有的人员和设备，将粪渣和垃圾收运、污水处理有效结合。

4.倡导文明如厕。结合文明城市、卫生城市、美丽乡村的创建活动，广泛开展公益宣传，推动文明如厕进景区、进社区、进农村、进校园，扩大文明如厕的影响力、带动力。

五、推进步骤

1.继续加强宣传，完善施工形式。通过《致全镇群众的一封公开信》、张贴宣传标语、“村村响”广播、户外公示栏等多种形式，全覆盖加强“厕所革命”宣传，提高知晓率和参与率，让群众了解改厕补助政策和实施步骤，发动群众积极参与改厕工作，营造厕改氛围。通过外出学习考察，召开专题培训会等形式，组织村干部、施工人员进行专题学习，重点普及无害化卫生厕所基本常识、建设标准、技术规范、模式选择等知识，确保厕改管理人员和施工人员掌握技术，规范施工。

2.全面摸底，继续推进。各村要对2018年农户厕所全面调查摸底，整改完善资料，做好验收结账准备。根据2019年建改任务数，完善改厕施工形式，做好2019年开工的各项准备工作。以村为主体，镇“厕所革命”工作办公室指导协调，鼓励各地采取统建与自建相结合的办法，实现农户厕改全覆盖。

3.强化监管，加强调度。镇“厕所革命”工作专班要加强对厕所施工质量的巡查与指导，重点把好“四关”：一是严把材料、产品质量关。要保留好相关厂家资质、产品合格证明等复印件。二是严把施工关。厕所改建必须由经过培训的施工人员或有实力的施工队伍承担，落实工程质量和安全责任制。施工人员或队伍要承担一定期限的保修和返修责任，确保厕所质量和使用寿命。三是严把农户签字关。改厕后，由农户对施工质量进行签字确认，农户不满意的由施工方整改。农户签字后，农户厕改登记表以村为单位存档保管。四是严把资金监管关。任何单位和个人不得截留、挤占和挪用厕改资金，确保专款专用。在申报验收、复核奖补过程中，发现弄虚作假、欺上瞒下、虚报冒领的，一经查实，严肃处理。“厕所革命”建设实行周调度和月通报制度，各村（社区）每周五将厕所建设进度报镇“厕所革命”办公室，镇汇总后上报市“厕所革命”办公室，无特殊情况逾期不报的，进度视为零增长。

4.健全档案，考评验收。各村（社区）要加强厕所建设档案资料管理，对已建成的水冲式无害化卫生厕所，要做好记录、分户登记造册，实行一户一档，建立台账，绝对不允许建假台账、假档案。一经发现，比照资金监管违规处罚标准严肃处理。按照“村级初验、镇级复查、市级核查”的程序，各村（社区）级围绕厕改档案资料是否规范齐全，厕所配套设施是否达到标准，进行自查。自查结束后由村委会向镇“厕所革命”办公室提出申请，镇专班到村进行复查，在镇复查过程中，发现一处旱厕，实行“一票否决”，继续整改。待全镇全面完成后，申请市级核查，确保一次通过核查验收。
