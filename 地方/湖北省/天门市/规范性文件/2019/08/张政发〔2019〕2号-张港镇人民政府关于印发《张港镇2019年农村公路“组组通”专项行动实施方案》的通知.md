# 张港镇人民政府关于印发《张港镇2019年农村公路“组组通”专项行动实施方案》的通知

今年是全面建成小康社会，实现第一个百年奋斗目标的关键之年，为充分发挥交通在脱贫攻坚、乡村振兴等重大战略实施中的先导性、支撑性、基础性作用，不断提升人民群众的获得感、幸福感，镇政府决定在全镇范围内开展农村公路“组组通”专项行动。现结合实际，制定如下实施方案。

一、总体要求

以习近平新时代中国特色社会主义思想为指导，全面贯彻落实中央、省、市关于脱贫攻坚、乡村振兴、美丽乡村建设的有关文件精神，加快推进“四好农村路”建设，全面实现具备条件的20户以上自然村通硬化路任务。

二、工作目标

1.完成市下达今年“组组通”任务。通过省高分遥感影像比对复核，市锁定的19个村20户以上自然村（撤并村）52.7公里通组公路实施硬化建设，全面实现“组组通”。

2.完成市下达今年主要农村公路窄路面加宽提档升级22.68公里。

3.已建成的通村公路路肩未回填的回填到位。

三、质量标准

1.20户以上自然村通组公路建设标准：原则上路基宽6.5米，路面宽4.5米；特殊情况下路基宽5.5米、路面宽3.5米，路面砼厚度不小于18厘米，每300米设一个总长40米，有效长度不小于20米的错车台，路肩两侧各填0.6米宽以上10厘米厚碴石，形成有利错车的硬路肩。

2.农村公路提档升级及窄路面加宽技术标准：路面标准按主干道不低于5.5米以上，次干道不低于4.5米，设计植拉结筋，基层压实厚度不小于30厘米，砼厚度18厘米，加宽后两侧路肩土不小于0.5米，有条件的新建和加宽线路两侧路肩宽度要达到1米。

3.所有砼路面厚度18厘米强度C30，路面施工期间每日必需制作砼试块。

四、补助政策

1.通自然村公路补贴标准：修建4.5米宽通组公路补助24万元/公里，修建3.5米宽通组公路补助17万元/公里。

2.农村公路提档升级及窄路面加宽补助标准：路面加宽到5.5米以上按20万元/公里补助，加宽到4.5—5米按13万元/公里补助。

3.普通公路建设资金补助范围包括路基路面和安保设施，加宽公路原有安保标志必须在项目完工后全部恢复到位，需要增加的要同步增加，安保设施建设严格实行“三同时”制度。

4.对实施快、效果好的村，镇里给予一定奖励。

五、时间要求

1.广泛动员（6月下旬）。为确保群众广泛参与“组组通”公路建设，采取悬挂宣传标语、召开群众会议、走访群众等方式，把政策宣传到群众中去，让群众明白“通组路是群众的生产生活路，是脱贫致富路。”

2.成立村组修路理事会（7月上旬）。在党支部的领导下，由村委会组织召开村民代表大会，选举思想素质好、业务水平高、工作作风实、奉献精神强、群众信得过的党员群众组建修路理事会，由理事会负责对进料源头、施工现场、质量检验等环节实行全程监控。

3.公示工程预算、制定筹资方案、启动工程建设（7月上、中旬）。各村要精打细算，降低成本，要制定详实的筹资方案。同时必须全面落实农村公路建设“八公开”制度，确保工程预算、筹资在阳光下操作。

4.筹措资金（7月-11月）。各村严格按照前期制定的筹资方案，将资金筹措到位，确保工程建设如期完成。

5.工程施工（7月-12月）。各村要加强工程全过程监督，确保工程进度、质量。

六、工作原则

1.要坚定目标不动摇。

2.要严格落实村主体责任和班子成员、机关干部包保责任。（责任见附表）

3.村主导、组自理，要充分发动群众、依靠在外成功人士支持家乡建设。

4.要实行财务公开，接受群众监督。

5.要在成本测算上只做减法，不做加法。

6.要做好耐心细致的工作。
