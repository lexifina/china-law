# 市统计局关于成立巡视整改领导小组和工作专班的通知

各科室、普查中心：

为进一步树牢“四个意识”，践行“两个维护”，深入推进十九届中央脱贫攻坚专项巡视反馈意见整改工作，切实加强巡视整改工作组织领导，根据市委办相关文件精神，市统计局决定成立市统计局巡视整改领导小组和工作专班。现将领导小组和工作专班人员名单通知如下。

组　长：吴慧斌　党组书记

副组长：马军堂　总统计师

成　员：许辉　彭井岗   张峰　贺雯  景依 何珍珍

工作专班：喻方明　兰建设  何练斌

领导小组办公室设在局办公室，承担领导小组日常工作，许辉同志兼任办公室主任，工作专班负责具体扶贫工作。

天门市统计局

2019年2月12日
