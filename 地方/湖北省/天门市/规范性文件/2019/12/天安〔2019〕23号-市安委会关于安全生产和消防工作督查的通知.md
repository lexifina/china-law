# 市安委会关于安全生产和消防工作督查的通知

各乡镇人民政府，各办事处、农场，天门高新园，天门工业园：

元旦春节将至，市安委会将组成七个督察组对各地2019安全生产和消防工作落实情况及2020年元旦春节安全生产和消防工作部署安排情况进行督查，现将有关事项通知如下：

一、督查内容

1、《2019年度乡镇（办、场、园）安全生产工作考核细则》（天安〔2019〕19号）现场督查项目；

2、安全生产集中整治工作开展情况；

3、2020年元旦及春节安全生产工作部署情况。

二、督查方式

督查主要采取下列方式：

（一）检查台账　检查乡镇（办、场、园）现场督查项目相关台账。

（二）实地抽查　每个乡镇（办、场、园）抽查1家重点企业、1家烟花爆竹经营点、1家综合超市、一个村（社区）。

三、督查时间

2020年元月2-3日

四、资料准备

1、现场督查项目的所有台账资料（以天安【2019】19号文件为准）；

2、各地党政主要负责人的书面述职报告；

3、各地应急管理机构设置情况；

4、安全生产集中整治工作实施方案及落实情况。

2019年12月30日

天门市安全生产委员会
