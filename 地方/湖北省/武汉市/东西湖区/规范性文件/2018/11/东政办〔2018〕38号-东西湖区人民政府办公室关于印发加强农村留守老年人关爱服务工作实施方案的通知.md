# 东西湖区人民政府办公室关于印发加强农村留守老年人关爱服务工作实施方案的通知

各街道办事处，区人民政府各相关部门，区直各相关单位：

《加强农村留守老人关爱服务工作实施方案》已经区政府同意，现印发给你们，请认真组织实施。

东西湖区人民政府办公室

2018年11月13日

东西湖区加强农村留守老年人关爱服务工作

实施方案

为进一步加强农村留守老年人关爱服务工作，积极构建养老、孝老、敬老、爱老、助老政策体系和社会环境，根据民政部等9部门《关于加强农村留守老年人关爱服务工作的意见》（民发﹝2017﹞193 号）、省民政厅等9部门《关于印发湖北省加强农村留守老年人关爱服务工作实施方案的通知》（鄂民政发〔2018〕11号）、市民政局8部门《关于做好农村留守老年人关爱服务工作的通知》（武民政〔2018〕33号）精神，结合我区实际，制定本实施方案。

一、指导思想

以习近平新时代中国特色社会主义思想和党的十九大精神为指导，以促进农村留守老年人安享幸福晚年生活为出发点和落脚点，着力完善关爱服务网络，提升关爱服务能力，健全关爱服务体制机制，加快推进农村留守老年人关爱服务体系建设。

二、基本原则

（一）家庭尽责。强化家庭和子女赡养、扶养农村留守老年人的主体责任，督促子女或受委托监护人履行法定义务;加强对家庭监护和委托监护的督促指导，确保农村留守老年人得到妥善监护照料、亲情关爱和家庭温暖。

（二）基层主导。把农村留守老年人关爱服务工作作为各级政府重要工作内容，按照属地管理的原则，由各街道、社区（大队）负责本辖区农村老年人关爱服务工作，民政、公安、司法等有关部门的负责监督指导。

（三）社会参与。充分发挥社区(大队)、老年协会、群团组织、社会组织、专业社会工作者、志愿者等各方面积极作用，建立社会化关爱服务工作机制，形成全社会关爱农村留守老年人的良好氛围。

（四）突出重点。加强资源统筹，以防范留守生活安全风险为重点，以经济困难的高龄、失能留守老年人为重点对象，强化生活照料、精神慰藉、安全监护、权益维护等基本服务，有针对性地开展农村留守老年人关爱服务。

三、保障对象

子女全部离开本区区域范围，外出务工或经商等半年以上、留在农村生活、身边没有赡养人或者是赡养人没有赡养能力的60周岁以上老年人。

四、主要任务

（一）切实保障农村留守老年人基本服务

1. 建立基础台帐。各街道要依托社区（大队）和养老机构、派出所对属地农村留守老年人进行全面排查，准确掌握农村留守老年人的数量规模、经济来源、家庭结构、健康状况、照料情况、存在困难及监护人联系方式等基本信息，报民政部门建档立册，并及时录入武汉市民政局“互联网+民政”综合信息化平台。按照《农村留守老年人基本情况登记表》（附件1）的基本内容，在社区（大队）建立农村留守老年人基础台帐，明确关爱联系人。

2. 开展生活照料服务。各街道要依托农村福利院等农村养老服务机构，为留守老年人提供居住和照料服务。特别是农村福利院在满足农村特困对象集中供养需求的同时，要优先向有需求的农村高龄失能留守老年人提供供养服务；依托农村老年人互助照料中心（服务点），为农村留守老年人提供日间照料、情感交流、文体娱乐、精神慰藉等养老服务。

3. 开展精神慰藉服务。各有关部门、街道要利用“九九”重阳节等重大节日走访慰问农村留守老年人，引导社会各界送温暖献爱心，在全社会营造关爱帮扶农村留守老人的良好氛围。组织社会爱心企业和个人与留守老人结成对子，加强日常联络和走访交流，从物质和精神上让留守老人感受关心关怀。动员农村留守老人积极参加各种形式的文体活动，丰富精神文化生活。

4. 开展安全监护服务。要加强对留守老人的安全防范意识教育，定期开展防诈骗、防盗窃、防事故等安全常识宣传活动，为农村留守老人提供各种法律服务，增强农村留守老人的法制观念和自我保护能力。深入推进“天网”工程建设，建设覆盖农村各个交通路口、重点部位的视频监控系统，提搞技防威慑力。对侵害农村留守老人合法权益的违法犯罪行为，坚持快查快结，从严处理，切实人合法权益，增强留守老人的安全感。

（二）建立农村留守老年人关爱服务体系

1. 落实赡养义务人主体责任。家庭是农村留守老年人赡养和关爱服务的责任主体。子女或其他赡养人要依法履行对老年人经济上供养、生活上照料和精神上慰藉的义务，扶养人要依法履行扶养义务。子女因外出务工等原因不能履行赡养义务的，在尊重老年人意愿的前提下，赡养义务人可与亲属或其他有能力的人签订委托照顾协议并妥善安排老人生活，同时向社区（大队）及时、如实告知去向、联系方式等信息。留守老人子女或其他赡养义务人不依法履行赡养义务或虐待老人，构成违反治安管理行为的要依法给予治安处罚，构成犯罪的要依法追究刑事责任。

2. 落实社区（大队）基础作用。各街道要协调、组织、引导各社区（大队）做好留守老年人关爱服务工作，大力弘扬“孝老敬亲”的传统美德，建立健全农村留守老年人救助保护机制；社区（大队）要明确专人通过电话问候、上门访问等方式定期探访留守老人，及时了解其生活情况；建立探访档案，将存在安全风险和生活留守老年人作为重点帮扶对象，社区(大队）要及时通知并督促其子女和其他家庭成员予以照顾，同时报告街道办事处，实施关爱救助。

3. 充分发挥农村老年协会作用。各街道要进一步加强基层老年协会建设，优先在老年协会工作开展较好的社区（大队）建设农村老年人互助照料活动中心（服务点）。

4. 动员社会力量开展关爱服务。广泛开展关爱农村留守老年人志愿服务，引导志愿者和志愿服务组织与留守老年人结对帮扶。探索建立留守老年人服务清单制度，通过向社会购买服务等形式，开展留守老年人关爱服务。加快孵化培育专业化为老社会服务机构，提升其开展农村留守老年人安全防护、生活照料、紧急援助、康复护理等专业服务的能力，支持其连锁化、品牌化发展。

（三）建立健全农村留守老年人救助保护机制

建立以街道为主体，社区（大队）具体实施，区民政局统筹指导的农村留守老年人定期探访制度。社区（大队）要落实专人通过电话问候、上门访问等方式，了解或评估农村留守老年人生活情况、家庭赡养责任落实情况并及时更新台账，为留守老年人提供相应援助服务，切实防范留守生活安全风险。对独居、失能、贫困、高龄等特殊困难留守老年人要随时跟踪掌握情况并及时实施关爱救助，发现留守老年人外出流浪乞讨、遭受非法侵害、发生危重病情、患有严重精神疾病、面临重大困境等情况时，要及时向社区（大队）、街道或民政部门报告，紧急处置后，由街道依据有关要求和分工实施关爱救助。

五、工作要求

（一）强化部门协作。建立健全政府支持保障、部门协同配合、社区(大队）发挥骨干作用、社会力量广泛参与的农村留守老年人关爱服务工作机制。区民政局牵头做好工作协调，培养壮大农村养老服务和社会工作专业人才队伍，加强农村养老服务设施建设，将农村留守老年人关爱服务体系纳入农村养老服务体系统筹考虑。加大农村留守老年人关爱工作力度，培育和发展老年协会，维护留守老年人合法权益，加强孝亲敬老社会宣传与人口老龄化国情教育。区公安局要依法严厉打击侵害留守老年人合法权益的违法犯罪行为。区司法局要做好法治宣传教育工作，依法为留守老年人提供法律援助服务。区财政局要积极支持农村留守老年人关爱服务工作，完善政府购买服务制度。区人社局要建立健全覆盖城乡居民基本养老保险、基本医疗保险等社会保障公共服务体系，逐步提升社会保障水平。区文体局要依托基层综合性文化服务中心，为农村留守老年人提供丰富多彩的文化服务，丰富老年人精神文化生活。区卫计委要落实基本公共卫生服务项目，为65岁以上农村留守老年人提供健康管理服务，会同民政等部门推进医养结合工作。区扶贫办要落实脱贫攻坚政策，坚持应扶尽扶，精准识别农村贫困人口，将符合条件的农村留守老年人全部纳入建档立卡范围，给予政策扶持，帮助其脱贫增收。

（二）提升保障能力。各街道要加大农村养老服务设施建设，充分发挥农村福利院、老年人互助照料活动中心（服务点）等作用，提升农村养老服务水平。按照年度目标要求，确保2020年农村老年人互助照料活动中心覆盖率达到60%以上。要支持农村卫生服务站为农村留守老年人提供健康管理、基本医疗和长期护理等服务。要支持农村综合性文化服务中心、农村社区综合服务设施、老年学校、党员活动室等公共服务设施建设，面向留守老年人开展服务。

（三）营造良好氛围。各相关部门和街道大力宣扬积极老龄化理念，倡导健康生活理念，开展健康生活知识教育，引导农村留守老年人保持身心健康。加强《中华人民共和国老年人权益保障法》等法律法规宣传，提高子女或其他赡养人守法意识，督促落实赡养义务。加强孝亲敬老传统美德宣传，形成互帮互助、助老爱老的良好风尚，营造全社会正确对待、积极接纳、关心关爱留守老年人的友好环境。

（四）加强督促检查。各相关部门、街道及社区要切实履行在维护留守老年人权益中的基本职责，区政府督查室将定期进行督查并通报情况，对底数不清、风险隐患排查不扎实、突发事件处置不及时、关爱服务流于形式的要进行严肃处理。
