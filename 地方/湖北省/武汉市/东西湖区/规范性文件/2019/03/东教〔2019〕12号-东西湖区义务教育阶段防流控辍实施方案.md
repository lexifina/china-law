# 东西湖区义务教育阶段防流控辍实施方案

进一步贯彻《义务教育法》、《未成年人保护法》等教育法规以及党的教育方针，规范学籍管理，稳定教育教学秩序，确保适龄儿童接受九年义务教育，特制定东西湖区义务教育阶段防流控辍方案，其具体如下：

一、高度重视，强化领导

各义务教育阶段所属中小学建立以校长亲自负责的领导小组，组员由政教主任、各班主任、学籍管理员组成。其要求：

1.每学期开学初要召开专题会议，布置和落实安全学期防流控辍工作计划和管理目标。

2.领导小组成员职责明确，责任到人，学籍管理员每月深入到班级核查学生人数，对15日内未到校学生进行二至三次家访，填报《武汉市东西湖区中小学生家访（劝返）记载表》，同时，将此表上传《全国中小学学生学籍系统》，并于每月20日前报教育局基教科。

3.防流控辍是考核学校的一级管理目标，学校要将辍学率与教师的绩效工资挂钩，并划入教师业务档案，对防流控辍工作突出的工作者，尤其是班主任和学籍管理干部在评先、表彰、晋级时应优先考虑。

二、依法治校、强化引导

学校要认真做好《义务教育法》、《未成年人保护法》等教育法法规的宣传工作，让广大家长、教师和全体学生增强法律意识，提高认识，使防流控辍工作落实到平时的各项教育教学活动之中，防患于未然。

1.进一步健全学校辖区内0—15周岁少年儿童文化登记工作，完善义务教育入学通知书制度。对符合入学条件的适龄少年儿童，学校不得以任何理由将其拒之门外。

2.加强对三类残疾儿童随班就读工作的管理，教师在教育教学上要给予特别关注和爱心，不要歧视“随班就读”学生，建立健全三类残疾儿童档案，如：教案、跟踪分析、作业批改、家访记载等。

3.积极争取当地人民政府对防流控辍工作的支持，对辍学学生查明情况后，不仅要及时向教育行政部门上报，更应当及时向街道办事处报告，取得地方政府的有力支持，并采取得力措施，劝其尽快入学，对于思想顽固的家长或监护人依法追究监护人的法律责任。

三、规范管理，落实目标

1.目标：

①中学辍学率必须控制在1.5%以内，小学辍学率控制在0%以内。

②中学入学率≥99%，小学入学率为100%。

以上为学校管理一级目标，学校要不折不扣地完成，对工作不得力，没有完成目标的学校，予以通报，限期整改。

2.各校学籍管理员按要求认真做好“四率”报表和学籍报审工作，统计报表不得以任何名义弄虚作假，严禁虚报瞒报。基教科对各校的学籍申报工作将进行严格审核，对不符合手续的一律不予办理。

3.严格异动手续

转学：严格执行《中小学生学籍管理办法》等相关政策法规，真正做到“籍随人走”的原则。

休学：学校学籍管理员要从严审批学生休学申请，防止学生假休学真留级。学生休学手续仍按原规定从严审核办理。

四、严肃纪律，强化管理

1.继续加大对义务教育法律法规的宣传力度，建立和完善有效的制约、奖励等机制，依法控辍。

2.建立动态监测机制，精准指导加强重点地区控辍保学工作。完善考核问责机制，不定期进行督导检查，及时通报对控辍保学不重视的街道、学校，严肃追究责任。

3.加强学校发展建设，打造学校特色，构建乐学爱学氛围，吸引学生，留住学生，从源头上抓好“控辍保学”。加强中小学学籍管理；完善学生流动相关续，杜绝学生在流动中流失的情况发生。

4.对表现较差的学生给予更多的关注，一旦出现厌学倾向和辍学苗头，千方百计解决实际困难，将辍学化解于萌。
