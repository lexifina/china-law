# 关于印发《2019年全区普法依法治理工作要点》的通知

区各普法责任单位:

现将《2019年全区普法依法治理工作要点》印发给你们，请结合实际认真贯彻落实。

东西湖区依法治区(普法)领导小组办公室

2019年4月26日

2019年全区普法依法治理工作要点

2019年是新中国成立70周年，是深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神的重要一年，是决胜全面建成小康社会的关键一年。全区普法依法治理工作的总体要求是:坚持以习近平新时代中国特色社会主义思想为指导，坚持以人民为中心的发展思想，深入贯彻落实党的十九大和十九届二中、三中全会、中央全面依法治国委员会第一次、第二次会议精神以及市委全面依法治市委员会第一次会议精神，以落实“谁执法谁普法”普法责任制为抓手，不断创新法治宣传教育方式，加大全民普法力度，弘扬社会主义法治文化，切实增强普法宣传的针对性和实效性，确保“七五”普法规划顺利实施，为平安东西湖、法治东西湖建设营造浓厚法治氛围。

一、强化政治引领，明确新时代普法宣传任务

1.深入学习领会习近平新时代中国特色社会主义思想。进一步提高政治站位，牢固树立“四个意识”，坚定“四个自信”，坚决做到“两个维护”，进一步增强走中国特色社会主义道路的自觉性和坚定性。

2.深入学习宣传习近平总书记关于全面依法治国的重要论述。坚持党对普法依法治理工作的绝对领导，坚持以人民为中心的发展思想，推动各级党委(党组)理论学习中心组开展专题学习，推动习近平总书记关于全面依法治国新理念新思想新战略内化于心、外化于行。

3.深入开展“与宪法同行 让法治生辉”系列活动。创新探索分众化、智能化、可分享、可互动、可体验的宪法宣传模式，用鲜活生动、接地气的语言和事例，采取人民群众喜闻乐见的形式，推进宪法进企业、进乡村、进机关、进学校、进社区、进军营、进网络，使宪法学习宣传教育活动走进日常生活，走进人民群众。大力开展“12·4”国家宪法日和“宪法宣传周”集中宣传。

4.学习宣传以宪法为核心的中国特色社会主义法律体系。组织国家机关深入学习宣传与本部门职责、与人民群众日常生产生活密切相关的法律法规，增强国家工作人员依法履职能力，提高社会公众对相关法律法规的知晓度。加强党章和《中国共产党重大事项请示报告条例》《中国共产党支部工作条例(试行)》等党内法规的学习宣传，增强广大党员党章党规党纪意识。

二、服务中心大局，深入开展法治宣传+主题活动

5.坚持服务大局。围绕庆祝新中国成立70周年、打好“三大攻坚战”，采取送法上门、公益法律体检等形式，全力开展法治宣传活动;围绕扫黑除恶专项斗争，精心组织策划专项法治宣传活动，广泛宣传与扫黑除恶专项斗争有关的法律法规，发挥法治宣传在震慑和预防犯罪、增强全民守法意识方面的作用;围绕世界军人运动会、国家级开发区建设、服务民营经济发展和国家安全开展主题法治宣传活动。

6.坚持服务民生。围绕教育就业、医疗卫生、征地拆迁、食品安全、社会救助、农村留守儿童关爱保护和困境儿童保障等群众关心的热点难点问题，围绕维护社会和谐稳定，利用重要时间节点和新法颁布的时机，分时段明确宣传重点，加大宣传力度，开展有针对性的法治宣传，增强人民群众在法治建设中的获得感、幸福感和安全感。

三、丰富活动载体，切实抓好重点对象学法用法

7.加强国家工作人员学法用法。健全完善领导干部学法用法考核机制，确保党委(党组)理论学习中心组集中学法、国家工作人员日常学法、法治培训、旁听审判等制度有效落实。组织好年度无纸化学法用法考试工作，加强学习情况和考试结果的运用，提升各级领导干部、公务员运用法治思维和法治方式推动发展的能力。

8.加强青少年法治教育。深入落实《青少年法治教育大纲》，进一步明确青少年法治宣传教育的责任、方式和途径，发挥法治教育进课堂主渠道作用，开展模拟法庭、普法微课堂、法治情景剧等形式多样的青少年学法用法实践活动，不断完善学校、家庭、社会“三位一体”的青少年法治宣传教育体系。加强对儿童尤其是农村留守儿童、困境儿童的普法教育，指导各街道(含常青花园社管办)和区直各普法单位通过以案释法、社区普法等形式，深入宣传普及《未成年人保护法》、《预防未成年人犯罪法》等未成年人保护法律法规和政策措施，提高儿童的法制观念、自我保护意识和防范能力，强化全社会保护儿童的法律意识。

9.提升企业经营管理者法治意识。深入推进“法律进企业、进商会、进工商联”活动，利用国家宪法日、知识产权日等载体，深入商会、企业开展法治宣传。对重点企业高级管理人员和关键岗位人员进行专门培训，增强企业管理者和职工法治意识，为企业健康发展营造良好的法治环境。

10.加强特殊利益群体法治宣传。加强政策法规宣传，加大以案释法力度，增强特殊利益群体法治观念，营造自觉守法、办事依法、遇事找法、解决问题用法、化解矛盾靠法的法治氛围，依法定分止争，规范信访秩序，促进和谐稳定。

四、提升品质内涵，促进法治文化创新发展

11.推进法治文化阵地建设。切实加强法治文化广场、主题公园、体验园、体验馆等法治宣传教育园地建设，有效提升社区(大队)法治文化阵地覆盖率。对已命名的省、市级法治文化建设示范点进行提档升级、丰富内涵;充分发挥法治文化阵地在知识普及、观念引导、能力培养方面的作用，力争建成全区乃至全市全省的法治文化阵地示范点。

12.加强法治文化作品创作。积极开展法治征文、法治动漫微电影、法治短视频等形式多样的法治文化作品创作，及时推荐参加全国和全省的评选活动。组织文化机构、文艺团体发挥各自优势，打造法治文化精品，繁荣法治文化创作，实现文化精品共享，着力提升我区法治文化建设水平。

13.深入开展法治文化活动。引导国家机关、学校、企事业单位等结合法律颁布实施日、纪念日、宣传日、特定时间节点等积极组织开展法治文化日、法治文化节活动，展现法治建设成果，宣传法治建设成效，提升广大人民群众的参与度。

五、坚持普治并举，推动法治创建提档升级

14.深入推进多层次多领域依法治理。深化部门、行业和基层组织依法治理，实现依法治理对部门、行业和基层组织的全面覆盖。严格按照法治创建考核评估指标体系要求，组织开展依法治校示范校、“诚信守法企业”等部门、行业、基层组织“法治创建示范点”实践活动，总结创建工作经验，树立创建工作典型，促进各部门、行业、基层组织民主法治建设和法治化管理水平不断提高。

15.推动健全自治、法治、德治相结合的乡村治理体系。充分发挥村(居)法律顾问的作用，方便村(居)民学法用法。实施“法律明白人”培养工程，在社区(村)中培养尊法学法守法用法骨干。结合农村社区(村)实际，特别是贫困农村地区，有针对性地开展法治宣传教育和法治创建活动，增强群众法治观念，提高乡村社会治理的法治化水平。加强对民主法治示范村(社区)创建工作的指导，使民主法治示范村(社区)成为推动基层依法治理实践的示范，成为深化法治社会建设的示范。

六、强化保障举措，推动普法责任制进一步落实

16.健全完善全区法治宣传机制保障。组织区各普法责任单位制定2019年度普法责任清单，明确普法重点内容、对象、目标、措施、完成时限，压实普法责任。按照上级普法依法治理业务指标，进一步完善全区普法依法治理工作核心指标及考评办法。建立完善重点工作督办通报机制和定期评议机制，推动考评工作常态化和规范化。

17.大力推进普法与执法有机融合。深入开展法官、检察官、行政执法人员、律师等以案释法工作，加强法治宣传教育案例征集，充分利用重大热点案(事)件开展普法宣传教育工作，针对农村留守儿童和困境儿童法律保护等热点法律问题进行解读，把热点案件依法处理的过程变成全民普法公开课。

18.积极运用新媒体新技术开展普法宣传。适应新时代新形势新要求，统筹整合媒体资源，不断扩大普法社会影响力。办好“东西湖区普法”微信公众号，加强新媒体普法产品开发，积极运用抖音、斗鱼直播、今日头条等开展普法宣传工作，提升普法宣传的吸引力和趣味性，打造我区立体式的法治宣传教育体系。

19.加强普法宣传队伍建设。选聘优秀法律人才，进一步充实我区“七五”普法宣讲团队伍。各街道、各部门进一步配齐、配强法治宣传专职人员，提升法治宣传服务发展的能力和水平。积极鼓励引导司法和行政执法人员、法律服务工作者、大学生和一些社会组织加入普法志愿者队伍，深入开展法治宣传活动。加强全区法治宣传队伍培训，开展普法经验交流，提高我区法治宣传队伍业务素质。

七、增强担当意识、全面落实区委全面依法治区委员会交办的相关工作

20.认真完成好区委全面依法治区委员会2019年工作要点中的相关工作任务。贯彻落实区委全面依法治区委员会的决定事项和工作部署，确保关于全民守法普法的决策部署不折不扣落到实处。

21.做好区委全面依法治区委员会交办的各项普法依法治理工作任务。抓好各项普法依法治理工作的协调、督促、检查、推动，推进各街道之间、部门之间协调配合，形成合力。进一步健全普法依法治理工作机制。加强普法依法治理工作自身建设，加大普法依法治理自身工作的宣传力度。
