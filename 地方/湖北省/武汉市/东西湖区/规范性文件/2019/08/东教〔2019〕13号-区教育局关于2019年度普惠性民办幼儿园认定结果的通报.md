# 区教育局关于2019年度普惠性民办幼儿园认定结果的通报

为贯彻落实市、区学前教育三年行动，持续扩大普惠性学前教育资源，根据市教育局《关于做好2019年全市普惠性民办幼儿园认定扶持工作的通知》精神和区教育局《关于2019年普惠性民办幼儿园认定扶持工作方案》，区教育局按照要求和程序对2019年普惠性民办幼儿园进行认定。经幼儿园自愿申报，区教育审核，并将结果对社会公示，有92所幼儿园经过公示无异议，认定为普惠性民办幼儿园，名单如下：
