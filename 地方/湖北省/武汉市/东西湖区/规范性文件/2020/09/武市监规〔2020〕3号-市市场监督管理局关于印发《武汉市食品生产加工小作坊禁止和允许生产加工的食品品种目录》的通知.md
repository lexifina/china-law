# 市市场监督管理局关于印发《武汉市食品生产加工小作坊禁止和允许生产加工的食品品种目录》的通知

各区行政审批(政务服务)局、各区市场监督管理局，市局机关各处室、各直属单位:

为进一步加强对食品生产加工小作坊的监督管理，规范食品小作坊生产经营秩序，根据《湖北省食品安全条例》相关要求，结合我市实际，经广泛征求意见及合法性审查等程序，市市场监督管理局修订了《武汉市食品生产加工小作坊禁止和允许生产加工的食品品种目录》，经局长办公会审议通过，现印发给你们，请遵照执行。

本目录自公布之日起30日之后施行，有效期5年。

武汉市市场监督管理局

2020年8月31日
