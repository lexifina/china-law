# 江夏区人民政府征收土地补偿安置方案公告[2019]第27号

江夏区人民政府于2019年5月22日发布[2019]第17号《江夏区人民政府征收土地公告》。江夏区人民政府申报的武汉市江夏区2016年度第57批次（江夏区安山街旺安路道路工程）城市建设用地项目，在2019年5月8日经湖北省人民政府审批，批准文号(鄂政土批[2019]479号)。拟征收江夏区安山街安山社区集体土地1.0606公顷，用地单位为武汉市江夏区人民政府安山街道办事处。土地用途为公路用地，拟以划拨方式供地。依据《中华人民共和国土地管理法》第48条和《中华人民共和国土地管理法实施条例》第25条和国土资源部《征用土地公告办法》(国土资源部令第10号)和《省人民政府关于公布湖北省征地统一年产值标准和区片综合地价的通知》（鄂政发[2014]12号）的规定，于2019年6月6日，就土地补偿费、安置补助费、青苗及地上附着物补偿费等征地补偿事宜作出《征收土地补偿安置方案公告》（[2019]第27号），现将征收土地补偿安置方案和有关事项公告如下：

土地补偿费、安置补助费共计61.3673万元,青苗补偿费1.2973万元，地上附着物补偿费据实补偿；共计62.6646万元。由武汉市江夏区人民政府安山街道办事处支付给江夏区安山街安山社区及社区相关权利人。

五、农业人口的安置：货币安置和社会保险安置。

六、集体经济组织、社区相关权利人对以上补偿安置方案有异议申请听证的，请于2019年7月5日前以书面形式送达江夏区自然资源和规划局，由江夏区自然资源和规划局组织召开补偿安置方案听证会。
