# 江夏区人民政府征收土地补偿安置方案公告[2019]第38号

江夏区人民政府于2019年12月17日发布[2019]第24号《江夏区人民政府征收土地公告》。江夏区人民政府申报的江夏区2019年度第20批次（增减挂钩）城市建设用地（江夏区上海通用大道（黄南公路）延伸段道路及管线工程），在2019年12月5日经湖北省人民政府审批，批准文号(鄂政土批（汉）[2019]66号)。拟征收江夏区金口街旭光村集体土地5.2579公顷，用地单位为武汉市江夏区交通运输局。土地用途为公路用地，拟以划拨方式供地。依据《中华人民共和国土地管理法》第48条和《中华人民共和国土地管理法实施条例》第25条和国土资源部《征用土地公告办法》(国土资源部令第10号)和《省人民政府关于公布实施湖北省征地区片综合地价标准的通知》（鄂政发[2019]22号）的规定，于2020年1月1日，就土地补偿费、安置补助费、青苗和地上附着物补偿费及房屋拆迁等征地补偿事宜作出《征收土地补偿安置方案公告》（[2019]第38号），现将征收土地补偿安置方案及房屋拆迁有关事项公告如下：

四、征地补偿费用的支付对象和支付方式：

土地补偿费、安置补助费共计465.3241万元；青苗补偿费和地上附着物补偿费据实补偿；以上费用合计465.3241万元。由武汉市江夏区交通运输局支付给江夏区金口街旭光村及村相关权利人。

五、农业人口的安置：货币安置和社会保险安置。

六、补偿安置方案及房屋拆迁情况的具体方法：

征地红线范围内涉及征收农村集体土地拆迁房屋14户，用地面积1434.56平方米；建筑面积2161.34平方米。依据《武汉市征用集体所有土地房屋拆迁管理办法》（市人民政府令第148号）的相关规定执行。

七、被拆迁房屋权利人：分别是雷宜波、雷宜军、吴齐付、吴路瑶、王本雷、赵巧枝、雷寿春、雷寿田、吴齐旺、吴齐鹏、吴齐元、赵典彦、彭家旺、彭国忠等14户，以上相关权利人对补偿安置方案及房屋拆迁补偿有异议申请听证的，请于2020年1月30日前以书面形式送达江夏区自然资源和规划局，由江夏区自然资源和规划局组织召开补偿安置方案及房屋拆迁补偿听证会。
