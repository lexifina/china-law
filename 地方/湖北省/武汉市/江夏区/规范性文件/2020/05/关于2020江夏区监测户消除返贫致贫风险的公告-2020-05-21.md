# 关于2020江夏区监测户消除返贫致贫风险的公告

根据湖北省扶贫攻坚领导小组 关于印发〈关于建立防止返贫监测和帮扶机制的实施意见〉的通知》（鄂扶组发〔2020〕13号）文件精神，对收入持续稳定、“两不愁三保障”和饮水安全持续巩固，返贫致贫风险已稳定消除的监测对象取消监测，经村民主评议、街审核，共确定陈传胜等3户11人监测户消除返贫致贫风险。经区扶贫攻坚领导小组同意，现予以公告（名单见附件1），如有异议，请即日起7日内向区政府反馈。

公告时间：2020年5月22日至2020年5月28日

监督电话：027-81568130

附件：2020年江夏区消除返贫致贫风险监测户名单

江夏区扶贫攻坚领导小组办公室

2020年5月21日
