# 江夏区关于第一轮中央环保督察反馈意见（省序号81）销号确认表

填报单位（盖章）：江夏区人民政府

反馈问题

进一步加强生态环境保护队伍和能力建设，强化监管执法

整改目标

高度重视生态环境保护工作，强化政策和资金支持，在编制总量内配强环保执法工作人员，切实加强生态环保能力建设。加强执法队伍装备建设，促进规范执法，提高执法人员素质。

整改措施

1、结合省以下环保机构监测监察执法垂直管理制度改革试点工作，统筹研究提出加强市、区环保部门监管执法等职责及编制、人员配备的具体措施。

2、2018年6月底之前，完成环保机构管理体制调整工作。

3、结合日常机构编制管理，促进环保部门按照中央改革精神优化调整职能，加强监管能力建设，加强环保机构规范化建设。通过核准招录公务员、遴选工作人员，引进专业人才使用编制等方式积极支持环保部门改善人员结构，加强监管执法专业人员队伍建设，提升环保监管执法力量。

整改完成

情况

根据中央环保督察反馈的“进一步加强生态环境保护队伍和能力建设，强化监管执法”问题，区委编办高度重视，迅速行动，立行立改，迅速落实整改事项，具体完成情况如下：

一是坚持用编向环保事业倾斜。根据我区生态环保领域空编情况，通过事业单位招聘、军转安置等多渠道补充事业在编人员。近3年，区环境保护局机关军转安置1人，区环境保护局其他事业机构通过招考、军转、退伍安置等共计补充事业人员8名，其中区环境监察大队补充事业人员6名（公招4人，军转2人）。

二是全方位多渠道优化环保执法领域人员结构。在用编过程中，深入分析现有人员结构及单位用人需求，科学制定人员用编方案，并强化部门沟通，增强部门合力，在招考专业设置、军转安置人员专业匹配等方面下功夫，精准把控，制定好招考、军转安置等方案，切实提升编制使用效率；同时全面配合司法部门做好生态环保领域执法考试资格审查工作，从源头把好执法人员素质关，提高执法队伍整体素质。

三是探索用工新形式，充实环保执法力量。为弥补现有执法人员不足的现状，通过增核编制和政府购买服务岗位，充实生态环保执法力量。为配合环保执法工作有序开展，全面加强全区大气治理工作，提高空气质量，经区编委研究，同意从区城管委划转的10名政府购买服务用岗额度及人员给区环保局，用于区大气办巡查督办工作。

目前，区委编办严格按照生态环境部门机构改革及环境保护机构监测检查执法垂直管理改革要求，严格遵守改革纪律，全面配合做好机构改革人员划转有关工作。
