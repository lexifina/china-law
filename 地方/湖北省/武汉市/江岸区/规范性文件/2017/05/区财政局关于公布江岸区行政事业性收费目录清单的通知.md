# 区财政局关于公布江岸区行政事业性收费目录清单的通知

区直各单位、部门：

为减轻企业负担，促进实体经济发展，根据《省财政厅关于停止征收部分行政事业性收费的通知》（鄂财法发〔2017〕6号）文件精神，从2017年5月1日起，停征绿化补偿费等3项行政事业性收费。

现公布《江岸区行政事业性收费目录清单》（见附件1）、《武汉市考试考务费目录清单》（见附件2）。各执收部门和单位应按照《收费目录》，认真核对本部门和单位执行项目，及时对收费窗口公示内容进行调整。目录清单之外的行政事业性收费，公民、法人和其他组织有权拒绝缴纳。执行中行政事业性收费项目发生变化，财政部门将及时更新。

从文件下发之日起，《收费目录》实行网上信息公开发布制度，发布网站为：江岸区政府门户网站（网址：http://www.jiangan.gov.cn/）。

本通知自2017年5月1日起执行。
