# 关于同意成立中共硚口区荣华街道武胜社区委员会的批复

中共武胜社区支部委员会：

你们报来的《关于成立武胜社区党委的请示》已收悉，经街工委研究同意，现批复如下：

同意成立中共硚口区荣华街道武胜社区委员会，党委委员由严红、杨玲、余正香、龚循帆、曾陶鹏5位同志组成，严红同志任党委书记、杨玲同志任党委副书记。

同意成立中共硚口区荣华街道武胜社区第一网格支部、中共硚口区荣华街道武胜社区第二网格支部、中共硚口区荣华街道武胜社区第三网格支部、中共硚口区荣华街道武胜社区第四网格支部。

特此批复。

中共硚口区委荣华街工作委员会

2018年5月18日
