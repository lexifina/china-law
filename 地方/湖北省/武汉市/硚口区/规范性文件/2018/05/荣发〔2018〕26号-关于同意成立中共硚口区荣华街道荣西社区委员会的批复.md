# 关于同意成立中共硚口区荣华街道荣西社区委员会的批复

中共荣西社区支部委员会：

你们报来的《关于成立荣西社区党委的请示》已收悉，经街工委研究同意，现批复如下：

同意成立中共硚口区荣华街道荣西社区委员会，党委委员由吴芳、张鹤玲、张凤武、张华清、匡志军5位同志组成，吴芳同志任党委书记、张鹤玲同志任党委副书记。

同意成立中共硚口区荣华街道荣西社区第一网格支部、中共硚口区荣华街道荣西社区第二网格支部。

特此批复。

中共硚口区委荣华街工作委员会

2018年5月18日
