# 关于印发《武汉市硚口区建设局控烟工作实施方案》的通知

局属各单位,机关各科室：

《武汉市硚口区建设局控烟工作实施方案》经讨论通过，现印发各单位，请各部门、各科室落实方案要求，推进我局控烟工作。局属各单位应参照本方案制定各自的实施方案来开展控烟工作。

武汉市硚口区建设局

2018年7月27日

硚口区建设局控烟工作实施方案

为全面推进我局控烟工作，控制和减少吸烟危害，提高办公环境卫生质量，保障干部职工身心健康，根据《公共场所卫生管理条例实施细则》（国家卫生计生委令第18号）、《武汉市公共场所禁止吸烟规定》（市人民政府令第166号）和《硚口区公共场所控制吸烟方案》等相关文件精神，结合我局实际，特制定本方案。

一、工作目标

在全局系统各办公场所内，通过开展公共场所控制吸烟行动，打造无烟办公场所，实现全局室内公共场所全面禁烟。在此基础上，倡导文明健康的生活方式，提高干部职工身心健康；加强干部职工作风纪律建设，树立工作人员良好形象；降低吸烟造成的公共危害，进一步改善公共环境卫生质量，助力文明军运、健康武汉、生态硚口建设。

二、组织领导

成立硚口区建设局控烟工作领导小组。

领导小组办公室设在局机关党政办公室，办公室负责组织开展、检查、督导日常控烟工作。区建管管理站、区市政工程总公司要参照局控烟工作方案形成自己的工作方案并加强控烟工作。

三、具体措施

1、明确室内办公场所全面禁烟、公务活动严禁吸烟。

2、要求干部职工自觉控烟，不向他人敬烟。鼓励吸烟职工戒烟。

3、在办公室、传达室、会议室、楼道、食堂、洗手间等场所张贴明显的禁烟标识。办公场所禁止摆放烟灰缸，做到室内无烟具、无烟蒂、无烟味。

4、在室内办公场所，人人有责任有义务对他人的吸烟行为进行主动劝阻和积极引导。

5、对违规吸烟者，及时批评教育，责令整改。对拒不改正者，严肃处理。

6、严禁使用或变相使用公款支付烟草消费开支。

7、积极在项目部、在建工地推进控烟行动。鼓励、倡导工地管理人员和外来务工人员控烟戒烟。

四、有关要求

（一）加强领导，精心组织。发挥控烟工作领导小组作用，认真传达贯彻上级关于控烟工作的决策部署，明确我局任务目标，加强统筹安排，落实责任到人，确保工作推进。领导干部带头垂范，积极倡导控烟，广泛发动干部职工积极参与。设立控烟监督员，进行监督、巡查，开展控烟监督活动。

（二）强化督查，严格考核。将控烟工作列入日常工作，纳入绩效管理。对日常检查结果进行通报，令行禁止，抓好落实，确保成效。鼓励社会参与，欢迎公众监督。

（三）广泛宣教，营造氛围。在全局上下开展控烟宣传教育活动，积极进社区、进工地，通过多种宣传活动普及烟草危害知识，提倡文明健康新风，打造控烟宣传阵地，营造人人参与、人人共建的良好气氛，促进无烟城市建设。

（四）建章立制，长效管理。建立健全禁烟工作制度、监督制度、奖惩制度，实现长效化管理。将控制吸烟工作与绩效管理相结合，与创建文明军运、文明单位、卫生单位相结合，立足长远，久久为功。

附件1：

硚口区建设局控烟考核办法及奖惩制度

一、控烟工作领导小组办公室将不定期组织抽查，重点检查各科室、各部门控烟制度建立与落实情况，把检查发现的问题及时反馈到各部门，并要求及时整改。

二、各部门须认真贯彻控烟制度，认真执行本科的控烟规定，负责所属区域内的控烟工作，发现工作人员及来访者吸烟，及时劝阻，保证控烟区内无吸烟者、无烟头。

三、控烟区实行包干负责，各部门负责范围内发生吸烟现象，负责人负监管失职之责。

四、干部职工不得在控烟区内吸烟，违反者若被督查或举报属实，第一次给予口头警告，第二次给予书面警告，第三次给予通报批评，每年出现三次以上（含三次）违反控烟规定者，取消当年评先评优资格。

五、各部门对其干部职工有教育监督责任，若部门工作人员或来访者在本部门包干负责范围内违反控烟规定，或未及时劝阻吸烟人员的，对部门负责人第一次给予口头警告，第二次给予书面警告，第三次给予通报批评，每年出现三次以上（含三次）违反控烟规定者，取消部门负责人当年评先评优资格。

六、定期组织对局属各单位的工作场所、食堂进行检查，一旦发现控烟工作相关规定的，先对单位予以警告，对于整改不及时的，视情节予以相应处理。

七、对无视禁烟制度，造成重大影响的部门或个人，将按规定进一步追究责任。

八、对戒烟成功的医院员工给予发放证书，加以表彰。

九、本制度从发布之日起执行。

十、本制度由控烟领导小组负责解释。

附件2：

控烟承诺书

全面推进我局控烟工作，控制和减少吸烟危害，提高办公环境卫生质量，保障干部职工身心健康。我决心自今日起，遵守单位控烟的相关规定，摈弃不文明吸烟的行为！为此，我郑重承诺：

1、不在控烟区域内的任何地方抽烟。

2、增强自我控制能力，自觉抵制诱惑，对来访人员互不敬烟。

3、发现在控烟区域吸烟者要及时劝阻。

4、坚决遵守单位有关控烟制度，自觉接受监督、检查。

为了自己和他人的身体健康，为了创造洁净、文明、安全的工作环境，让我们一起努力！
