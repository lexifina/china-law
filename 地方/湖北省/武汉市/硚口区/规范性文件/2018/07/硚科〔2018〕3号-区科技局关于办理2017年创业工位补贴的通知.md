# 区科技局关于办理2017年创业工位补贴的通知

各有关单位：

为贯彻《关于支持百万大学生留汉创业就业的若干政策措施》（武办文﹝2017﹞53号）精神，依据《2018年度区科技研发资金预算安排的请示》，结合硚口区各众创孵化平台的地理位置、场地条件、服务成本及实际租金情况，拟对提供免费创业工位的众创孵化平台通过后补贴方式给予补助，现就办理补贴有关事宜通知如下：

一、补贴标准

补贴标准为200-600元/个·月，补贴时间2017年10月----2018年3月，具体补贴金额按照实际使用创业工位数计算，补贴天数按月计算，不足月则按实际使用天数计算。

二、申报条件

（一）申报主体为硚口区提供免费创业工位的众创孵化平台（区级以上众创空间、孵化器）；

（二）大学生出勤率不低于50%。

三、申报材料

（一）硚口区创业工位补贴申请表（见附件，需盖公章）； （二）《大学生免费创业工位申请表》1份；

（三）大学生免费创业工位通知（第三联）；

(四) 大学生学历学位证明或在读证明复印件1份；

（五）大学生入驻考勤记录；

（六）工商注册证明原件及复印件1份。

四、申报流程

（一）区科技局发布申报通知；

（二）申报主体向区科技局提交申报资料；

（三）区科技局业务科室进行资料审核及现场查核；

（四）区科技局局长办公会审议；

（五）立项拨款。

五、申报时间及地点

（一）受理时限：截止2018年8月15日（星期三）

（二）受理地点和联系方式

受理地点：沿河大道518号硚口区政府0517室

联系人：占曙光
