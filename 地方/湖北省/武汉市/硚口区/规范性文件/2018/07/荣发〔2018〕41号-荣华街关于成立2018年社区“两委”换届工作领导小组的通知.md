# 荣华街关于成立2018年社区“两委”换届工作领导小组的通知

领导小组的主要职责是：在街工委、办事处的领导下，具体负责全街社区“两委”换届工作的谋划部署、组织协调、督促指导，及时研究重要政策措施，加强对关键环节的指导把关，确保换届工作有序推进。

领导小组下设办公室，办公室设在党建办，主任由赵静兼任，王守勇任副主任。
