# 2019年硚口区从业人员健康检查工作方案

根据《关于从业人员健康检查管理与经费保障相关事宜的通知》（武卫生计生通〔2018〕6号）文件要求，为进一步做好2019年全区从业人员免费健康检查工作，特制定此方案。

一、组织领导

为进一步加强组织领导，成立区从业人员健康检查工作领导小组，由成亚平同志任组长，疾控科、法监科、区疾控中心、长丰街、古田街、宗关街、汉水桥街、宝丰街、荣华街社区卫生服务中心负责人为组员，领导小组下设办公室在疾控科办公。

二、从业人员范围

（一）从事接触直接入口食品工作的食品生产经营人员（根据《食品安全法》第四十五条的规定）。

（二）直接从事挤奶工作的人员、生鲜乳收购的人员、乳制品生产人员（根据《乳品质量安全监督管理条例》第十七条、第二十条、第二十八条的规定）。

（三） 药品生产企业、药品经营企业和医疗机构直接接触药品的工作人员（根据《药品管理法》第五十一条的规定）。

（四） 直接从事化妆品生产的人员（根据《化妆品卫生监督条例》第七条的有关规定）。

（五） 消毒产品生产企业直接从事消毒产品生产的操作人员（根据《消毒产品生产企业卫生规范》第四十六条的规定）。

（六） 直接从事供、管水的人员、直接从事供水设施清洗消毒、水质处理器（材料）生产的人员（根据《生活饮用水卫生监督管理办法》第十一条的规定）。

（七） 公共场所直接为顾客服务的人员（根据《公共场所卫生管理条例》第七条的规定）。

三、从业人员健康检查项目

根据相应法律法规，按照全市要求，从业人员健康检查项目包括细菌性痢疾、伤寒和副伤寒、病毒性肝炎（甲型、戊型）、活动性肺结核、化脓性或者渗出性皮肤病等。

四、从业人员健康检查免费机构

为方便从业人员健康检查，按上级工作要求，经市卫计委网站公示，辖区从业人员健康检查免费机构为：古田街社区卫生服务中心、宗关街社区卫生服务中心、长丰街社区卫生服务中心、汉水桥街社区卫生服务中心、宝丰街社区卫生服务中心、荣华街社区卫生服务中心。

五、从业人员健康检查办理流程

从业人员健康检查遵循“就近办理、单位预约、有序体检、集中办证”原则。免费机构只接受在硚口区开办有从业场所的用人单位预约申请，并合理安排健康检查。具体流程为：

（一）预约。用人单位统计本单位健康检查人员名单，填写《预防性健康体检免费服务预约申请表》，携带从业场所资质证明材料（营业执照或统一社会信用代码证书或卫生许可证或食品生产许可证、食品经营许可证等有效证照的复印件，加盖公章），与免费体检机构预约体检时间。

（二） 体检。用人单位组织从业人员按预约时间地点，带齐相关资料到免费机构进行健康检查。免费机构根据预约计划，有序实施健康检查，告知用人单位取证时间。

（三） 领证。用人单位到免费机构获得从业人员健康检查结果，领取《从业人员预防性健康检查合格证》。

小餐饮、食品生产加工小作坊、食品摊贩、农村集体聚餐食品从业人员等零散人员凭营业执照直接预约申请。

六、工作要求

（一）落实工作职责。区疾控中心负责组织专业人员培训和技术指导，法监科负责对免费服务机构加强监管，疾控科负责工作协调和督办检查，各免费服务机构负责切实做好预约、体检和办证服务工作。

（二）加强宣传引导。各免费机构要将从业人员健康检查免费对象、开展机构、办理流程、查询方式等关键信息进行公示，广泛利用各类媒体加强政策宣传，做到用人单位和广大从业人员充分了解，引导免费健康检查服务有序开展。

（三）加强监督检查。领导小组办公室定期组织相关部门对辖区内免费机构进行质量检查和考核评估；对违反有关法规要求和弄虚作假的机构，取消免费健康检查服务资格；对发现骗取财政资金等违法行为的，依法调查、处罚、移送。
