# 硚口区卫生计生委关于进一步做好全区分级诊疗制度建设重点工作的通知

辖区各相关医疗机构、委相关科室：

根据《市卫生计生委关于进一步做好全市分级诊疗制度建设重点工作的通知》（武卫生计生通〔2018〕246号）和湖北省卫生计生委《关于进一步做好全省分级诊疗制度建设重点工作的通知》（鄂卫生计生通〔2018〕63号）精神，结合相关工作要求，为进一步推进全区分级诊疗制度建设，现就做好当前几项重点工作通知如下：

一、总体要求

全面贯彻党的十九大和健康中国战略，以社会公益为导向，以满足人民群众基本医疗服务需求为出发点，遵循医学科学规律，通过推进医联体建设、区域医疗中心建设和基层医疗机构医疗能力建设为抓手，完善运行机制和激励机制，引导优质医疗资源下沉，形成科学有序的分级诊疗格局。

二、目标任务

2019年，硚口区医疗服务体系分工协作机制和医疗综合保障机制进一步完善，合理有序的就医格局基本形成，分级诊疗制度建设逐步推进。

2020年，分级诊疗服务能力全面提升，保障机制逐步健全，基层首诊、双向转诊、急慢分治、上下联动的分级诊疗模式基本形成，分级诊疗有序开展。

三、主要措施

（一）加强统筹规划， 加快推进医联体建设

区卫生计生委要统筹区域内医疗资源，根据医疗服务需求科学规划、布局医联体。要将社会力量举办医疗机构纳入医联体，对于具备条件的社会力量举办医疗机构，也可以牵头组建医联体。

1.网格化布局组建紧密型医联体和区域医共体

区卫生计生委要按照“规划发展、分区包段、防治结合、行业监管”的原则，将辖区按照医疗资源分布情况划分为若干个网格，每个网格由一个医联体或者医共体负责为居民提供一体化、连续性医疗服务。三级医院和康复、护理等慢性病医疗机构可以跨网格提供服务，检验检查、消毒供应、特殊临床专科技术等可以在区域内实现资源共享。建立牵头医院负总责、各级各类医疗机构分工负责、防治康协同机制，逐步形成以健康为中心的服务模式，形成医联体网格化全覆盖，有效防止三级医院“跑马圈地”。鼓励中医医院牵头建设医联体，充分发挥中医药在治未病、疾病治疗和康复中的重要作用。要充分发挥妇幼保健机构预防、保健和诊疗作用，为网格居民提供妇幼健康服务。大力推进医联体内远程医疗服务，完善市－区－街道三级远程医疗服务网络，2020年底前，远程医疗覆盖医联体内基层医疗卫生机构。牵头医院要采取有效措施加强医联体医疗质量管理，区卫生计生委要将对单一医疗机构的医疗质量监管转变为对医联体的医疗质量监管，逐步提升医疗质量和医疗服务同质化水平。

2.重点推进重大疾病和短缺医疗资源专科联盟建设

要充分发挥国家级、省市级医院临床重点专科优势， 调动积极性，重点推进肿瘤、心脑血管、呼吸、感染性疾病、重大传染病等重大疾病，以及儿科、麻醉科、病理科、精神科等短缺医疗资源的专科联盟建设，以专科协作为纽带，强弱项、补短板，促进专科整体能力提升。要将专科联盟建设与区域医疗中心设置工作有机结合，逐步减少患者就诊跨行政区域流动。

（二）以基层医疗机构能力建设为重点推进分级诊疗城乡分开

区卫生计生委要从“资源整合、政策激励、人才建设、互联网＋”四个方面增强基层医疗机构能力，提升对区域内常见病、多发病以及传染病、地方病的诊疗能力及急诊、儿科、麻醉科、重症医学科等薄弱专科能力。通过加强与上级医院的技术合作，引进并推广适宜技术项目，提高内镜、介入治疗等微创技术临床使用比例，提升肿瘤、心脑血管疾病、感染性疾病等重大疾病诊疗能力。

（三）以重大疾病单病种管理为重点推进分级诊疗上下分开

紧密型医联体和医共体要按照《高血压、糖尿病等7个病种分级诊疗服务技术方案》要求， 做好高血压、糖尿病、慢性阻塞性肺疾病、冠状动脉粥样硬化性心脏病、脑血管疾病、乳腺癌、甲状腺癌等重大慢性非传染性疾病分级诊疗。各级医疗机构要以解决“上转容易下转难”为重点，落实7个病种的入、出院标准和转诊原则，并逐步扩大病种范围，规范开展双向转诊工作。

各社区卫生服务中心要以特色专科建设为抓手加强能力建设，做好常见病向下转诊和疑难复杂疾病向上转诊服务，提高区域内就诊率。基层医疗机构要提高服务的可及性，为下转患者提供康复、护理、随访、建立健康档案等工作。

区卫生计生委及相关医疗机构要逐步增加紧密型医联体和医共体内上级医院为基层医疗卫生机构预留号源的数量，经预约转诊的患者优先安排就诊，对需要住院治疗的预约转诊病人设立绿色通道，逐步建立基层首诊、转诊的就医模式，要采取多种措施提高基层医疗机构患者用药便利性，提升基层药学服务能力，确保基层用药合理安全。

（四）以三级医院日间服务为重点推进分级诊疗急慢分开

符合条件的三级医院要稳步开展日间手术并逐步扩大病种范围，提高日间手术占择期手术的比例。鼓励有条件的医院设置日间病房、日间治疗中心等，为患者提供适宜的日间诊疗服务。三级医院要主动调整门诊病种结构，引导诊断明确、病情稳定的患者向下转诊，逐步减少常见病、多发病、慢性病患者占比，增加手术、急危重症的诊疗量占比。

基层医疗卫生机构要稳步推进家庭医生签约服务工作，优先做好老年人、孕产妇、0—6岁儿童、慢性疾病（高血压、糖尿病、结核病等）患者和严重精神障碍患者等重点人群的签约服务，按照相关服务规范提供健康管理服务，规范慢性病患者健康管理。

（五）以分级诊疗信息化为支撑，推进双向转诊规范化

加快全市分级诊疗双向转诊平台的推广运用。医疗联合体内各级医疗机构要加强市级双向转诊平台的应用，优化院内转诊流程，以方便患者为前提，实现门诊、住院、康复等常见转诊业务的在线办理，使双向转诊更加方便、快捷。区卫生计生委要加强双向转诊系统的审核与监测，及时统计区域内双向转诊数据信息。

（六）完善保障政策

1.建立医联体绩效考核制度。根据《关于印发医疗联合体综合绩效考核工作方案（试行）的通知》（国卫医发 〔2018〕26号）精神，建立医联体综合绩效考核制度和动态调整机制，促进优质医疗资源下沉， 引导各级各类医疗机构落实功能定位。要将医联体年度绩效考核结果向行业内公布，促进紧密型医联体和医共体形成良性竞争。逐步将部分考核结果向居民公布，方便居民选择医联体和家庭医生签约团队。

2.加快推进信息化建设。贯彻落实国务院办公厅《关于促进“互联网+医疗健康”发展的意见》，鼓励医联体、医共体内医疗机构使用电子健康卡实现基层首诊、远程会诊、双向转诊“一卡通”，为居民提供连续医疗服务。制订完善医联体信息功能规范，加强信息化顶层设计。积极运用互联网技术，加快实现医疗资源上下贯通、信息互通共享、业务高效协同， 推进“基层检查、上级诊断”，医联体内充分借助人工智能等技术手段，提高基层医疗服务能力，医疗机构间实现检查检验结果实时查阅、互认共享。

3.加强医疗卫生人才队伍建设。加强医联体内专业人才培养。采取规范化培训、助理全科医生培训、定向免费培养、转岗培训等方式，加大全科医生培养力度。鼓励在医联体内，通过专科进修、送教上门、远程教育、现场培训等多种形式的继续医学教育，不断提高基层专业技术人员服务能力。

4.推动落实配套政策。积极协调医保部门推进医保支付方式改革，探索对紧密型医联体和医共体实行医保总额付费，引导医联体内部形成顺畅的转诊机制，真正形成共同体。协调医保部门研究制定家庭病床、居家护理、签约服务、远程医疗等医疗服务项目价格与医保报销政策，适应服务需求和服务模式转变，形成可持续发展的长效机制。

四、工作要求

（一）加强组织领导。推进分级诊疗制度建设是深化医改的重要目标和任务，各部门、各单位要高度重视，切实加强领导，明确工作责任，形成主要负责人亲自抓、负总责，分管领导集中精力抓，相关部门共同参与的工作机制。

（二）加强监督考核。各部门、各单位要将分级诊疗制度建设推进工作纳入卫生计生工作目标考核内容，把责任追究作为工作的关键环节来抓。要认真开展督查，积极采取专项检查、明查暗访等形式进行针对性督查，确保全面完成12项工作目标任务。

（三）加强舆论引导。区卫生计生委要及时总结有关工作经验和成果，推广有益经验。充分利用报纸、广播、电视、网络等媒体，大力宣传分级诊疗制度和医联体建设相关政策，加强典型宣传，展示工作成效，营造良好舆论氛围。

硚口区卫生和计划生育委员会
