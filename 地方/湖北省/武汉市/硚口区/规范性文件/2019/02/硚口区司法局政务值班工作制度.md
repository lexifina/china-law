# 硚口区司法局政务值班工作制度

第一条，专人24小时值班制度。每天安排正式在编人员在岗值班，同时安排备班人员，不安排临时人员值班，原则上每班次1人值守。值班人员值班期间必须24小时坚守岗位，做到无缝交接，保证值班电话24小时畅通。防汛期间、发生重大以上突发事件，特殊敏感时期等，可实行双人专职24小时值班。

第二条，领导带班制度。法定节假日、特殊敏感时期每天安排一名分管领导在岗带班，局党政主要负责同志驻地带班，并保持手机畅通。

第三条，来电接听制度。值班人员应当及时、认真接听来电，精炼、礼貌应答，对重要来电应当准确、详细地做好记录。

第四条，首接负责制度。第一个接听电话的值班人员应当负责全程予以跟踪，及时办理和回告相关工作事项，直至办理工作结束；如有特殊情况，由他人接替办理，应当做好交接工作。

第四条，值班记录制度。值班人员应当如实填写值班记录并妥善完整保存《值班记录本》。值班记录内容包括值班时间、带班领导、值班人员、交接班情况，突发事件应当按时间顺序详细记录处置全过程。记录应当要素齐全、详略得当、字迹清楚。

第五条，信息收集报送制度。值班人员要全面掌握全局运转情况，了解局领导去向及联络途径，及时接听电话、收发传真、上报值班情况，遇紧急情况应及时向带班领导报告，按要求妥善处理并立即报告处理结果；带班领导应全面掌握全局重要敏感信息和突发事件情况，并有效组织处置。

第六条，保密制度。值班人员使用电话、传真、网络传递有关文件和信息时，要严格遵守各项保密规定，杜绝失（泄）密事件发生；未经允许，不得让无关人员在值班室滞留或者使用值班设施设备。

第七条，检查通报制度。局政治（警务）处、局纪检监察室将不定期对全局值班情况进行检查和抽查，并及时通报检查、抽查结果。
