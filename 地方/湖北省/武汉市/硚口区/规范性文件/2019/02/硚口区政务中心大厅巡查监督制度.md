# 硚口区政务中心大厅巡查监督制度

为提高硚口政务大厅服务质量，优化企业群众办事环境，合力打造最优政务服务城区，进一步强化大厅巡查管理工作，特制定大厅巡查监督制度。

一、实行巡查频查制度

每天随机巡查不少于五次，各入驻部门对各自窗口的日常管理和巡查监督负主体责任。

二、执行多层次巡查监督

1、每天各入驻部门现场主管、首席巡查各自区域。

2、每天区政务服务和大数据管理局政务服务科组织对大厅各区域多次巡查。

3、每月组织各入驻部门交叉巡查不少于一次。

4、每周区政务服务和大数据管理局领导带队、各业务科室不定时巡查。

三、完善巡查内容

1、窗口工作人员业务水平和服务能力

2、窗口工作人员工作规范和工作纪律

3、政务大厅及各窗口服务环境

4、首问负责、一次性告知执行情况

5、大厅各部门现场管理、问题处理整改情况

6、大厅文明建设各项工作常态化落实情况

四、强化结果运用

1、每日巡查问题及时公布。

2、每周发巡查通报监督整改。

3、每月对部门评分排名纳入部门综合绩效考核。

4、对整改不力、排名连续靠后的入驻企业实行末位淘汰，取消进驻政务服务中心大厅的资格。

5、各部门利用考核结果对其工作人员进行奖惩。
