# 关于印发《2019年硚口区司法行政工作要点》的通知

各科、处（室）、所：

现将《2019年硚口区司法行政工作要点》印发给你们，请认真贯彻落实。

武汉市硚口区司法局

2019年3月13日

2019年硚口区司法行政工作要点

2019年是新中国成立70周年，是司法行政系统改革重组后的开局之年，是武汉市承办第七届世界军人运动会的重要之年，是硚口全面开启高质量发展新征程的关键之年。硚口区司法局要坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻落实习近平总书记全面依法治国新理念新思想新战略，坚持党对司法行政工作的绝对领导，坚持以人民为中心的发展思想，坚持稳中求进的工作总基调，全面履行“一个统筹、四大职能”，奋力开创新时代司法行政工作新局面。

一、强力推进全面从严治党

1.强化政治引领。深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，树牢“四个意识”，坚定 “四个自信”，坚决做到 “两个维护”。扎实开展“不忘初心、牢记使命”主题教育，不断深化“支部主题党日+”活动，通过组织培训、典型交流、警示教育、网络学习等形式，深入推进“两学一做”学习教育常态化、制度化，增强学习针对性和实效性。将意识形态工作纳入工作学习的重要内容，与严守政治纪律和政治规矩紧密结合，把加强政治引领作为提高自身政治素质和履职能力的首要任务来抓，努力在学习实践中提高政治站位，夯实工作基础。

2.强化正风肃纪。巩固拓展“四风”整治成果，继续将违反中央八项规定精神和“四风”问题列为执纪审查重点。深入推进作风建设，以钉钉子精神打好作风建设持久战，从“细”处着眼，从“根”上入手，从“实”处发力，坚持开展“每周一查”，扎实推进“双评议”工作，促进干部作风不断转变。 健全完善“三重一大” 事项廉政预审备案机制，严把“三重一大” 事项决策关，充分发挥监督预警作用。着力在日常监督、长期监督上探索创新，整合监督力量，完善监督机制，优化监督方式，紧盯苗头细微，把监督做实做细做到位。

3.强化党风廉政建设。坚持标本兼治，在全局范围内构建权责清晰、措施得力、务实管用的廉政风险防控机制，坚持将纪法教育、制度建设、督导检查和整改落实一体推进，不断完善机制，优化管理模式，规范工作流程。深化“十进十建”，加强经常性纪律教育和广泛性警示教育。以廉政风险防控为切入点和突破口，强作风，树政风，推进全面从严治党向纵深发展。

二、全力维护社会安全稳定

4.筑牢社区矫正安全底线。坚持“稳”字当头，全力以赴“保建国大庆、保军运平安”，加强重点人员、重点时段、重点部位管控，坚守安全底线。严格落实社区服刑人员分类管理、分级处遇、分阶段教育措施，严格执行报告、外出、进入特定场所等重点环节审批制度，严格运行日报告、周研判、月排查机制。强化电子腕带跟踪管理系统运用，提高定位准确度、及时性和数据调取效率，确保社区矫正执法“过程不变形，结果不出事”。进一步推动社会力量参与社区矫正安置帮教工作，强化心理矫治，积极推进“啄木鸟—关护计划”，提高未成年社区服刑人员矫正质量。加大帮扶力度，进一步加强汉正街“焐心硚”安置帮教基地宣传推广，在司法所建立“一街一基地”，使帮扶更灵活、更及时、更有针对性。

5.筑牢矛盾化解第一防线。布局“大调解”工作网络，夯实诉调、公调、访调对接平台，持续推进行业性专业性调委会作用发挥，保障“大调解机制”顺畅运行。开展规范化调委会创建，争取行业性专业性和街道调解组织规范化率达90%，社区规范化率达50%以上。持续打造“黄坚工作室”、“红色调解室”品牌特色，按照横向发力、纵向指导、重点孵化的思路培养一批以黄坚为中坚力量的“硚口区星级人民调解员队伍”，做好重点项目相关矛盾纠纷调处工作，不断拓展人民调解参与社会治理新维度。

6.筑牢信访维稳法治防线。持续完善一把手开门接访、领导班子重点管控、责任部门包案化解、综合部门研判调度的信访机制，确保信访投诉不越线。运用法治思维和法治方式解决信访突出问题，维护全区改革发展稳定大局，积极开展领导干部下基层大接访。树立风险意识，做好全国两会、第七届军运会、建国70周年庆等重大时间节点的信访应急预案。继续做好律师参与信访值班和社会矛盾纠纷化解工作，健全律师参与信访接待值班、接访等制度。

三、聚力服务中心工作

7.服务重大项目建设。紧紧围绕“项目建设”这一硚口经济工作的头号工程，找准司法行政与高质量发展最佳结合点，深度挖潜，精准聚焦，为全区重点项目保驾护航。以企业需求为导向，研发法律服务产品，针对性地组织律师进企业、进商会、进创业（工业）园区，对可能产生的风险提出预防建议，为维护企业合法权益提供精准的法律帮助，努力做到服务企业“零距离”、办事效率“零延误”、生产经营“零干扰”。

8.助力军运会综合整治。发挥职能优势，认真履行法治宣传、纠纷化解、法律服务、特殊人群监管等职责，为顺利举办高质量、高标准的军运会提供坚强法治保障。扎实开展“清洁家园迎军运”活动，营造关心军运会、支持军运会、参与军运会、服务军运会的良好氛围。

9.纵深推进扫黑除恶专项斗争。提高政治站位，压实工作责任，咬定三年为期目标不放松，突出今年阶段性要求，在深化打击、综合整治、固本强基上下功夫，以更精准的举措推进专项斗争。进一步加强对律师涉黑涉恶案件辩护代理工作的监督指导，落实大要案备案制度。进一步加大扫黑除恶宣传力度，提升群众参与扫黑除恶专项斗争工作的共识和自觉性。进一步加强涉黑涉恶线索摸排，严守保密纪律，严防泄密事件发生。面对黑恶势力要敢于亮剑，戒除“鸵鸟心态”“孔雀作态”，确保扫黑除恶专项斗争在深挖根治阶段取得实效。

四、合力推进全面依法治区

10.统筹推进法治政府建设。全面贯彻落实法治政府建设实施方案，科学设定法治政府建设评价指标体系，组织开展督查、考核。加强社会信用体系建设，大力推进“双随机、一公开”工作，加强事中事后监管，不断完善依法行政和行政执法工作制度，有效提升依法行政、依法办事水平。认真抓好已出台制度的贯彻落实，加强行政规范性文件制定和监督管理，强化行政执法监督检查，坚决纠正违法和不当行政行为，推动政府工作全面纳入法治轨道。

11.全面加强法治社会建设。全面落实“谁执法谁普法”的普法责任制，完善联席会议制度和考核考评机制，创新在城管、审批等执法部门试点开展述法工作，建立完善法官、检察官以案释法制度。进一步深化“四大行动”，围绕全方位宣传宪法、打好“三大攻坚战”、优化营商环境等重点工作，深入开展“法治宣传+主题”活动。坚持普法工作和法治实践相结合，不断加强法治文化阵地建设。充分利用“硚口发布”、“硚口普法”微信公众号等新媒体，灵活运用法治动漫、微电影、讲座视频等通俗易懂的方式，提升普法宣传的影响力和实效性。

五、着力保障和改善民生

12.加快推进公共法律服务平台一体化。积极配合市局推进公共法律服务实体、网络、热线三大平台融合发展，实现互融互通、有机衔接。认真落实一次性告知制度、首问负责制，公示服务承诺、服务人员、服务流程等，明确服务内容、服务对象、责任主体。加强对窗口值班律师的管理与考核，建立健全统筹协调、日常管理、工作评价机制，不断提升公共法律服务的专业化水平，打造优质公共法律服务产品，为群众提供便捷高效的法律服务。集中优势争创五星实体平台，积极打造市级公共法律服务示范点，努力实现区、街、社区三级实体平台“三星全覆盖、四星为常态、五星不断增加”的工作目标。

13.扩大法律援助惠民效应。畅通未成年人、老年人、残疾人、农民工、妇女法律援助绿色通道，切实做好特殊群体法律援助工作，持续开展“法援惠民生”系列主题活动。进一步完善刑事辩护全覆盖衔接配合机制，规范辩护律师参与认罪认罚从宽工作流程，不断巩固深化改革成果，满足人民群众司法需求。加强法律援助工作站规范化建设，严格执行省市法律援助案件质量标准。扎实开展行政评查及同行评估工作，对重点案件进行庭审旁听，实行“每案必访”，多方位监管，提升法律援助服务质量。

14.提高律师行业服务质量。提升为民服务意识，加强社区法律顾问部署及监管工作。扎实开展律师行业党建规范化建设年活动，将党建工作纳入律师事务所章程，进一步提高律师行业党的组织覆盖和工作覆盖质量。发挥党员律师“头雁”作用，创建律师党员“示范岗”“先锋岗”等，选树一批典型党员律师，以点带面，提升周四“律师进社区”服务质量。建立硚口区社区律师“介绍信”制度，进一步做好“律师进社区”衔接工作。继续落实社区法治讲座制度，全年不少于610场。完善律师调解试点工作，探索打造律师调解“硚口模式”。

六、努力夯实司法行政事业发展基础

15.稳步推进机构改革。认真贯彻落实中央、省、市、区关于深化机构改革工作的部署和要求，制定“时间表”“路线图”，稳步推进机构改革各项工作。坚持政治引领、党建先行，把机构改革作为一项重要的政治任务抓紧抓实，加快推进机构、职能、队伍、工作、感情深度融合，促进业务贯通、职能融通、人心相通。鼓励和引导干部发挥专业优势，施展聪明才智，积极适应职责定位、工作方式的新变化，确保工作不断，节奏不乱，人心不散。

16.不断加强基层基础建设。围绕司法行政全面强基础之年，持续强化司法所规范化建设，按省级规范化要求着重打造1至2个红旗司法所，一个综合实力的标杆所。加快“数字法治、智慧司法”建设，按照 “一切业务数据化、一切数据业务化” 要求，优化信息化管理机制，全面完成市局视频会议系统、远程会见系统、指挥中心视频点名系统、监控视频汇聚系统的推广运用。树立“精品”意识，加强宣传力度。深入挖掘工作中涌现出的典型人物和经验做法，捕捉司法行政工作中有创新、有典型、有亮点的素材，借助线上+线下的平台，组织“司法行政开放日”活动，讲好司法行政故事，唱响司法行政声音。

17.加快建设“四化”政法队伍。贯彻落实《中国共产党政法工作条例》《关于新形势下加强政法队伍建设的意见》《关于新形势下加强司法行政队伍建设的意见》，严把选人用人政治关、品行关、作风关、廉洁关，树立正确的用人导向。突出实战、实用、实效，全面提升司法行政队伍法律政策运用能力、防控风险能力、群众工作能力、科技应用能力、舆论引导能力，练就“五个过硬”的本领，推进司法行政队伍革命化、正规化、专业化、职业化建设。关心爱护党外青年干部成长，做好精准扶贫、政务值班、政务公开、老干部服务和机关后勤保障等工作。
