# 硚口区司法局考勤制度

为切实加强我局机关工作人员作风建设，增强局机关工作人员组织纪律观念，更好地发挥司法行政机关职能作用，经局党组研究决定，在局机关启用人脸识别考勤系统，特制定本制度。

一、适用范围：硚口区司法局机关全体工作人员（含聘用人员）

二、使用方法及注意事项

1、管理员统一为机关全体工作人员设置人脸识别图像。

2、考勤机全天开机,机关全体工作人员在工作日须进行考勤登记。

3、考勤时，机关工作人员应将面部置于考勤机前方，对准屏幕，待考勤机显示“已考勤”后，即操作成功。考勤结束后，应立即离开考勤机，不得重复、随意录入面像考勤。

4、考勤机已设定管理员，其他人员不得随意操作考勤机界面。

三、考勤管理

1、 严格遵守考勤签到制度。分别按照6：30－8：30，17：30－19：30签到、签退。未在规定时间签到或签退的视为迟到或早退，未签到又未事前履行请假或报告手续的视为旷工。

2、非全天参加会议或培训的人员原则上应在规定时间内签到、签退。如有特殊情况确不能签到或签退的，应事先报请分管领导批准后，报局办公室备案；外出参加会议、培训或处理公务1天以上的，应在履行完相应审批手续后，报局政治处备案；全局工作人员外出须按照《硚口区司法局请销假管理制度》规定程序办理请假手续，未经备案，一律视为旷工。

3、工作人员的考勤情况将作为个人日常绩效考核及年终考

核的一项重要依据，给予客观公正的评价。

以上各项考勤制度望引起局机关全体工作人员重视，并自觉遵守执行。
