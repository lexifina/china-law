# 区人民政府办公室关于印发硚口区新型智慧城市建设行动纲要的通知

硚政办〔2019〕11号

各街办事处，区人民政府各部门、各直属机构：

《硚口区新型智慧城市建设行动纲要》已报经区人民政府同意，现印发给你们，请认真遵照执行。

硚口区人民政府办公室

2019年7月17日

硚口区新型智慧城市建设行动纲要

为主动参与武汉市实施国家级智慧城市试点，全面落实建设国家创新型城市各项工作部署，加快打造现代科创智城，推动硚口新型智慧城市建设创建标杆、走在前列，根据《国家信息化发展战略纲要》（中办发〔2016〕48号）、《湖北省大数据发展行动计划（2016—2020年）》（鄂政发〔2016〕49号）、《武汉市人民政府办公厅关于印发武汉市推进数字政府建设实施方案（2019—2020）的通知》等文件精神，结合硚口实际，制定本纲要。

一、总体要求

（一）指导思想

按照党的十九大关于建设网络强国、数字中国、智慧社会的战略部署，深入贯彻习近平总书记治国理政新理念、新思想、新战略，牢固树立“创新、协调、绿色、开放、共享”五大发展理念，紧密围绕硚口“打造现代科创智城”的城区发展定位，始终坚持“以人民为根本，以发展为中心”的核心建设理念，通过实施“信息基础设施提升、基础公共平台建设、智慧政务标杆创建、市民服务效能提升、产业经济竟进提质和社会治理创新引领”六大行动，进一步增强硚口区信息基础设施服务能级和基础公共平台统一支撑能力，有效支撑新一代信息技术在智慧政务、市民服务、产业发展和城市治理各领域的创新应用，着力建设更加智能的服务型政府，着力培育具有更强互联网基因和更具活力的特色经济，着力提升城市网络化协同治理能力，为硚口区抢抓武汉市建设国家中心城市、复兴大武汉黄金机遇，加快构建创新生态，再造经济形态，培育新型业态，实现转型跨越发展提供持久动力。

（二）发展目标

围绕将硚口打造成“改革创新先行区、转型发展引领区、三生融合示范区、中心城市核心区”的远景目标，坚定不移推动新型智慧城市建设。力争到2021年左右，基本完成智慧硚口“六大行动”建设。基于物联网的精确感知、基于云计算的开放服务、基于大数据的创新应用成为推动硚口内生增长、创新发展的重要动能；基于“互联网+”的智慧政务、智慧民生、智慧经济、智慧治理成为引领高效便捷、无所不在综合信息服务体系的建设典范，新型智慧城市建设进入全国前列。

1．建成全方位、全天候、可视化的智能感知体系。推动各类传感设备和关键技术在工业制造、城市交通、现代物流、社会事业、公共安全、生态环保、安全生产、城市管理等领域实现广泛应用，基本建成物移融合、物云融合的泛在物联网络和深度感知系统，对城市脉搏的精确把控能力进一步增强，基本具备从万物互联向万物智能跃迁的基础。

2．建成标准统一、集约高效、开放共享、自主可控的智慧硚口基础公共平台。按照适度超前、弹性扩容理念，推动硚口电子政务中心机房云化升级，打造全市领先的云计算大数据中心，逐步形成全区统一的标准化云服务架构、统一的城市级云服务入口和即需即取、弹性扩展、安全可靠的云计算应用环境，为各部门信息化建设提供统一的云计算设施支撑。推动各部门信息化建设从独立分散向大平台整合跃升，实现平台复用能力、统一支撑能力和业务快速开发能力全面提升。

3．深度融合、创新多元的“互联网+”应用成为引领新型智慧城市建设的先进标杆。到2021年，线上线下、全程全时的为民服务体系达到全国先进水平，成为全省智慧政府的建设标杆；规模化、高端化、融合化、特色化信息技术产业实现跨越发展，对相关产业的带动提升作用明显增强，数字驱动、创新驱动型现代产业体系成为新常态下经济转型升级的成功样本，精细高效、多元共治的城市治理模式成为引领武汉特色特大中心城市创新治理的一面旗帜，公共服务智能便捷、产业经济竞进提质、城市治理精细可视、转型升级动能强劲的新硚口基本成型。

（三）阶段目标

第一阶段：基础强化

完成全区宽带网络提速、无线网络升级、免费WIFI覆盖和感知网络部署；启动搭建云计算支撑、物联网管理、公共信息交换、时空信息等基础公共平台；组织开展智慧政务、智慧民生、智慧经济、智慧治理行动和相关工程建设。

第二阶段：整合提升

建成跨层级、跨部门的信息资源共享体系，政务服务和社会管理核心业务数据深度整合，实现更加全面的信息共享和更加高效的业务协同，“互联网+”应用渗透率大幅提升，在经济发展、民生服务中发挥突出作用。

第三阶段：能力跃迁

无所不在的信息服务、全程全时的公共服务体系全面建成，信息技术发展红利在经济社会各领域加速显现，创新驱动、赶超发展的经济增长新动能显著增强，全国“改革创新先行区、转型发展引领区、三生融合示范区、中心城市核心区”的战略地位进一步凸显。

二、总体架构

充分借鉴国内外先进地区智慧城市顶层设计理念，按照“统一架构、统一标准、统一建设、统一管理”设计思想，以标准规范体系、信息基础设施、通用基础平台、城市数据资源、公共服务平台、业务应用体系、信息安全体系六大功能部件为核心，统筹搭建架构合理、集约共享、管理高效的智慧硚口一体化应用环境。

（一）统一架构。基于云计算架构，构建智慧硚口业务应用系统“可插拔式”部署架构，通过基础资源租赁服务促进电子政务云化升级，引导和推动各政府部门二级业务系统或业务平台基于云平台进行统一部署和业务协同，减少分散化建设模式下存在的系统异构难互通、分散运维成本高、信息安全风险大等问题。

（二）统一标准。通过集中布设云计算、大数据设施，鼓励购买云服务，逐步统一各部门业务系统硬件资源标准，推动各部门开发的异构应用平台向开放标准架构平台逐步演进。通过资源整合，统一视频网络、基础数据库等可复用资源的互通标准，夯实智慧硚口资源整合与共享、业务协同与联动的标准化基础。

（三）统一建设。由区政府统一搭建云计算和大数据基础设施，所有使用区财政拨款的单位未经批准不得新建数据中心，数据资源原则上在区电子政务中心机房部署，现有政务公开类信息系统逐步向区电子政务云平台迁移。

（四）统一管理。重点考虑从底层基础设施到上层应用服务模块的整合复用和集约化管理，包括底层的物联感知设施、物联网管理平台、大数据平台、公共信息平台等，通过整合一批涉及多部门的共性支撑平台，对外提供一批从底层硬件、数据资源到上层业务应用的公共服务能力，最大限度避免重复建设和投资浪费。

三、主要任务

（一）信息基础设施提升行动

围绕全面提升硚口区信息基础设施服务能级，按照“统一规划、政府引导、企业主体、先进适用”的建网策略和“物联化、感知化、智能化”的网络发展方向，充分发挥电信、移动、联通、广电等运营商的主力军作用，全面协调推进“宽带硚口”、“无线硚口”、“感知硚口”建设，加快构建宽带、融合、安全、泛在的下一代信息基础设施，进一步提升全区网络综合承载能级，实现信息化基础设施能级指标全市领先。

1．“宽带硚口”提升工程。结合三大功能区建设规划和城市更新改造计划，加快推进光传输网络和光纤接入网络建设，实现全区域百兆入户、千兆进楼、万兆入园。完成区、街道、社区三级电子政务网络光纤升级改造，促进光纤宽带在电子政务、协同办公、行政审批、社区服务等重点领域全面普及。（牵头单位：区科经局，配合单位：区行政审批局、区大数据中心、各街、开发区、三大通信运营商）

2．“无线硚口”建设工程。进一步完善和优化4G移动通信网络覆盖，实现全域4G网络无缝、优质覆盖，广泛开展4G+应用。支持铁塔公司加快5G基站规划建设，推动网络运营商在2019年完成硚口区5G实验网建设，2020年具备商用能力。努力打造适应高清视频、虚拟现实、增强现实等互联网新业态的5G应用环境，推动5G网络与工业设施、医疗器械、交通工具等智能设备在硚口区率先实现应用突破。（牵头单位：区科经局，配合单位：区行政审批局、区规划分局、区城管局、区园林局、区房管局、各街、区大数据中心、铁塔公司、三大通信运营商）

3．免费WIFI覆盖工程。鼓励和支持电信运营商及第三方企业加快城市公共热点区域免费WiFi无线宽带覆盖和开放，重点加快区内政府部门、医疗机构、行政服务中心、学校、景区、酒店、商贸中心等公共场所无线访问接入点建设，基本实现主要公共场所免费无线上网热点100%覆盖。（牵头单位：区科经局，配合单位：区行政审批局、区大数据中心、区教育局、区卫健局、区文旅局、各街、开发区、三大通信运营商）

4．“感知硚口”联网工程。统筹推进物联网络建设，支持多部门联合共建全域覆盖的视频感知网络、身份识别网络、位置感知网络体系，加快打造一套标准统一、规范接入、安全可控并可满足各行业智慧应用需要的智能感知一张网。以城市视频监控立杆资源为基础，推进智慧多功能杆建设。鼓励相关部门积极开展物联网与下一代互联网、云计算、大数据、地理空间等新一代信息技术的融合应用试点，为物联网技术在公共建筑、地下管网、城市照明、交通出行、电力保障、供水供气、安全生产、环境保护、健康医疗等领域广泛应用奠定基础。（牵头单位：区科经局、区行政审批局，配合单位：区公安分局、区城管局、区水务和湖泊局、区环保局、区大数据中心）

（二）基础公共平台建设行动

以“创新、协调、绿色、开放、共享”五大发展理念为指引，以加快构建硚口新型智慧城市核心竞争力，加快形成创新驱动、跨越发展新动能为导向，按照“统一规划、集中集约、互联互通、共建共享、安全可控”原则，统筹推动本区物联网管理平台、时空信息云平台、云计算平台、大数据平台以及公共信息平台等基础性、通用性平台建设，推动各部门信息化建设从独立分散向大平台整合跃升，提升基础性、通用性平台的复用能力和统一支撑能力。

5．云计算平台建设工程。继续坚持物理和逻辑双集中建设模式，按照“政府引导、企业主体、集中集约、统建共享、安全可控”原则，采用国际先进的开源云技术和自主、安全、可控的软硬件产品，以区电子政务中心机房为主体，统筹整合“智慧园区”等新建机房资源，并与市级、省级政务云实时对接。通过开发建设资源共享、集中管理、动态管控、快速部署的云计算管理平台和智慧IT基础架构，搭建绿色集约、公私隔离、弹性扩展的智慧硚口云计算中心，实现硬件设施统一配置、数据资源集中存储、运维管理与信息安全统一保障。依托云计算中心推动各部门新建政务应用系统集中在云计算中心统一部署，引导原有二级业务系统和业务平台有序向云计算中心迁移，统筹“两化融合”专项资金，研究出台专项激励政策，大力支持重点行业和产业园区加快组织实施“企业上云”，力争到2021年，在云计算基础设施和应用环境两个方面实现区域领先，达到国内一流水平。（牵头单位：区行政审批局，配合单位：区财政局、区大数据中心）

6．大数据平台共建共享工程。加强全区数据资源统筹，建立更加完善的大数据体系，依托区统计局、区公安分局、区行政审批局、区科经局、区市场监管局、区税务局、区规划分局等部门基础数据资源，以现有人口、法人、空间地理和宏观经济四大基础数据库为基础，综合采用行政采集、企业收集、个人提供、有偿购买、传感收集等方式，持续加强本级数据沉淀，加快建立以城市公共基础数据库、公共业务数据库、公共服务数据库和视频资源数据库为核心，以社会信用、电子证照、统计执法、城市部件信息为重要支撑的智慧硚口大数据资源体系，为政府公共管理、居民生活服务和企业生产经营提供有力的信息支撑。并与市级政务大数据平台和数据资源基础信息库实时对接。（牵头单位：区行政审批局，配合单位：各街、各部门）

7．物联网管理平台建设工程。集成智能传感与感知技术、物联网海量数据采集、存储与处理技术、计算机控制技术、智能决策支持等技术，采用支持多协议、多标识转换的通用网关和开源物联网操作系统，开发建设基于云计算的物联网统一接入管理平台，提供感知终端管理、信息汇聚、目录组织、信息共享等功能，实现各类感知终端的统一识别和接入，以及信息集成分发。推动城管、交通、环保、水务、安监等部门按统一标准加快物联感知体系建设，并接入全区物联网管理平台，实现各部门物联网监测数据的统一汇聚。（牵头单位：区行政审批局，配合单位：各街、各部门）

8．时空信息云平台建设工程。综合集成北斗卫星导航、互联网、云计算、大数据、物联网、传感器等先进技术，以北斗时空为基准，以位置服务为核心，以地理信息资源开发利用为主线，集中搭建基于北斗时空基准的时空信息云平台。推动现有地理空间数据与公安、城管、交通、建设、水务、园林、工商、统计等部门、行业单位数据对接，推进全区人口、法人、城市部件等数据与北斗空间基准和时间信息加快融合，为政府宏观决策、应急管理、智慧应用、社会公益服务提供标准化的地理空间信息服务。（牵头单位：区规划分局，配合单位：区政府各部门）

（三）智慧政务标杆创建行动

围绕政务协同应用、政务渠道拓展等需求，以加快政府职能转变为核心，通过构建一体化网上政务服务体系，面向市民和企业提供更便捷、更贴心的网上行政、并联审批和行政服务功能，进一步提升政府管理效率和公共服务水平。

9．“行政效能提升”工程。不断完善办公自动化体系建设，推动无纸化办公覆盖率进一步提升，完成电子公文交换、绩效考核、公务督办等系统的迭代升级。构建全区统一的政务大数据综合服务平台，依托现有数据资源目录，以企业全生命周期数据管理为核心，建立招商引资项目、企业落户、企业扶持、企业奖惩、企业经济数据、全区经济指标运行等数据管理的综合应用平台。深入推进公共服务平台建设，加大各类服务型和投诉受理型平台整合力度；加快“服务企业直通车”平台建设，进一步提升政府服务和管理水平，优化营商环境。加快“统计智库”建设，加强统计数据质量源头监测，提升经济运行统计分析，为全区经济高质量发展提供坚实的统计保障。提升政府网站服务能力和智能化水平，优化硚口发布、云端硚口、在线访谈等网络宣传和交互平台。（牵头单位：区网信办，配合单位：区委组织部、区委办、区政府办、区行政审批局、区市场监管局、区统计局、区大数据中心、区网格化中心、区融媒体中心）

加强智慧城市建设的统一领导，建立分工合理、责任明确的组织体系与管理体制。由区政府主要领导牵头负责，区网信办、区行政审批局、区发改局、区财政局、区科经局、区公安分局、区城管局、区教育局、区卫健局等部门以及各街道按职分工，统筹推进智慧城市建设项目的落实，并负责重大决策制定和关键事项审批。设立硚口新型智慧城市标杆创建专家咨询委员会，加强对智慧城市平台搭建、商业模式构建等重大问题的咨询引导。

（二）创新扶持政策

坚持政府引导，市场主导的发展思路，充分落实现行各项优惠政策，全面执行国家、省、市有关促进中小企业创新发展和互联网产业发展的相关措施。结合硚口区产业发展布局和新型智慧城市建设运营需要，重点面向互联网、云计算、大数据、电子商务等战略性新兴产业，通过政策众筹，在广泛听取社会各界意见的基础上，为城市合伙人、创新创业者量身定做最好的政策。进一步加大信息化建设向社会购买服务的力度，鼓励社会资本参与智慧城市建设投资与运营，并获得合理回报。区内立项的“互联网+”和智慧城市建设重点项目，区财政优先提供财政资金保障，积极争取国家和省级资金对试点示范项目的扶持。

（三）强化评估考核

明确硚口区新型智慧城市建设责任分工和工作目标，纳入全区绩效管理和领导干部年度考评体系，加强考核评估与结果运用。对标国家、省市考核标准，结合硚口区实际，建立新型智慧城市评价体系和评估考核办法，按照自然年度，采用指标考核、公众评议、专家评定三种方式对智慧城市建设绩效进行评估。强化目标导向、结果评价，以考核评估为抓手，促进各建设单位依据年度行动计划，加快组织实施，加强协调配合，切实把握好规划实施的重点和时序，及时发现问题和提出改进意见，保障规划目标顺利实现。

（四）提升信息安全

加快建立以技术为核心、制度为保障、评估为手段、灾备为支撑的智慧城市信息安全四位一体综合保障体系。综合利用各种成熟的信息安全技术与产品，从物理、网络、主机、应用、终端和数据几个层面建立起强健的智慧城市信息安全技术保障体系。建立健全信息安全标准规范和信息安全管理实施办法，在信息安全组织、运行和技术体系等标准化、制度化的基础上形成一整套对信息安全有效管理的规定。

建立健全信息安全风险测评、敏感数据操作审计工作机制，加强云计算平台安全防护，明确政务数据、行业数据开放利用的安全保护策略。择机建设灾备中心，建立业务连续性计划、应急响应和灾难恢复计划，定期开展应急演练，保证硚口新型智慧城市相关业务运行的连续性。

（五）加强人才保障

制定适应硚口新型智慧城市发展要求的人才战略和措施，建立人才培养、引进、流动和使用机制，在各方面增强对信息化人才的吸引力和凝聚力。紧密对接“双招双引”“资智回汉”等重点工作，创新推进“城市合伙人”“硚口英才计划”，继续办好武汉大学生“互联网+”创新创业大赛，不断加强信息化人才引进和培养力度，重点加强数据挖掘、算法设计、机器学习、智能软硬件设计、自动驾驶、图像识别、物联网基础器件等领域顶尖人才和高水平创新团队的引进。强化党政机关信息化专业人才队伍建设，充实互联网工作机构人员队伍，推动信息化与政务业务的融合。做好全区各级干部的信息化知识和技能培训工作，提升机关公务人员利用互联网技术和信息化手段开展工作的意识和能力。
