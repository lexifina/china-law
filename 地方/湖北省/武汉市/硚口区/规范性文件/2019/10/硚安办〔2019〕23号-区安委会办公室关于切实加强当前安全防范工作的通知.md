# 区安委会办公室关于切实加强当前安全防范工作的通知

各街、区经济开发区安委会，区各安全生产专业委员会，区安委会成员单位，区有关部门和单位：

按照《国务院安委会办公室 应急管理部关于切实加强当前安全防范工作的通知》（安委办明电〔2019〕14号）、《省安委办 省应急管理厅关于切实加强当前安全防范工作的通知》（鄂安办〔2019〕38号）、《市安委会办公室 市应急管理局关于切实加强当前安全防范工作的通知》（武安办〔2019〕57号）文件要求，结合近期中央、省、市、区会议精神和区委、区政府“迎大庆、保军运”各项决策部署，为扎实做好当前特别是新中国成立70周年大庆、第七届世界军人运动会期间安全防范工作，有效防范化解重大安全风险，坚决遏制重特大事故，确保人民群众生命财产安全和社会稳定。现就有关要求通知如下：

一、提高政治站位，落实各方安全生产责任

新中国成立70周年大庆将至，第七届世界军人运动会即将召开，做好“防风险、保安全，迎大庆、保军运”工作，是当前最重大、最紧迫、最特别的政治任务。各街、各安全生产专委会、各部门和单位要认真贯彻落实习近平总书记关于安全生产、应急管理的重要指示精神以及中央、省、市、区各项决策部署，结合“不忘初心、牢记使命”主题教育，进一步提高政治站位，牢固树立以人民为中心的思想，坚决扛起防范化解安全风险的政治责任，狠抓各项安全防范措施落实，筑牢安全生产防线。

要警钟长鸣、举一反三，深刻汲取近期各类事故教训，细化、实化、深化各层级、各环节、各方面安全生产责任。按照“党政同责、一岗双责、齐抓共管、失职追责”和“三个必须”要求，大力宣贯落实《地方党政领导干部安全生产责任制规定》《湖北省地方党政领导干部安全生产责任制细则》《市安委会关于进一步强化安全生产责任和责任追究的意见（试行）》，紧密结合实际，深入研判安全风险，制定针对性防控措施，做到心中有数、手中有招，强化防范化解安全风险的领导能力、组织能力、执行能力，切实负起“促一方发展、保一方平安”的政治责任。

要坚持问题导向、目标导向和结果导向，着力防范化解重点行业领域安全风险和隐患。各企业要坚决消除重生产、轻安全思想，落实安全生产主体责任，防止片面追求经济效益忽视安全底线的问题。要主动加强企业安全管理体系和安全生产标准化建设，着力提高企业负责人、管理人员和从业人员安全意识、安全素质和安全技能。要进一步加大针对性安全投入，针对前期各级督查检查发现的问题，积极改进工艺技术装备，有效提升本质安全水平。要深入梳理本辖区、本行业领域、本系统、本单位安全薄弱环节，采取针对性措施“固底板、补短板”，紧密结合安全生产形势特点和季节特点，制定新中国成立70周年大庆、第七届世界军人运动会等重大活动应急管理和安全生产保障专项方案，严格落实管控举措，确保城市运行安全和生产安全。

二、突出工作重点，深入推进安全隐患排查治理

各街、各安全生产专委会、各部门和单位要按照区委、区政府统一部署，在安全发展、高质量发展上再聚焦、再发力，强化风险意识和事前预防，聚焦重点区域、重点时段、重点行业、重点领域，深入推进安全隐患排查治理和安全生产专项整治。

（一）危险化学品领域。要继续抓好化工企业设计复核，迅速制定化工、危险化学品企业“排险除患”专项行动方案并组织实施。要盯紧看牢高风险区，逐一落实管控措施、完善应急预案、前置救援力量，严防事故发生。要督促危险化学品企业落实“五人包联”和“五员包保”责任制，强化企业重大危险源管控、企业自动化改造和投用以及门禁管理。

（二）交通运输领域。要加强对交通运输企业、“两客一危一货”车辆、车站等安全监督检查。要以“三超一疲劳”、非法载客等严重违法行为为重点，深入开展道路运输和城市客运安全专项治理；以防火防爆为重点，开展危险货物储存作业专项治理；以桥上防护安全风险防控为重点，开展公路运营安全和工程施工安全专项治理。

（三）消防领域。落实“警消联动”工作机制，突出城乡接合部、城中村、老旧居民区以及“三合一”、“多合一”、群租房、“十小场所”、大型商业综合体、高层建筑、仓储物流、地下空间、公共娱乐场所、宾馆饭店、养老院、文博古建筑等人员密集场所和重点场所深入开展安全执法检查专项行动，深化火灾隐患排查整改。要加强对火灾易发多发场所的夜间“错时制”检查，坚决纠治堵塞消防通道、违规用火用电用油用气、电动车违规充电等动态隐患。

（四）建设领域。要深刻汲取东西湖区“9·11”一般坍塌事故、岱家山大桥“9·14”一般高处坠落事故教训，加强在建工程、工地（包括公路道路市政工程、装修施工、拆迁工地、危房改造）安全生产督查检查，强化“危大工程”的现场安全管理与巡查检查，强化施工现场起重机械、附着式升降脚手架、塔吊和施工电梯安全管理，全面开展安全隐患排查整改，严防高处坠落、物体打击、机械伤害、触电、建筑火灾等事故。要加强城市更新中改、扩建工程及装饰装修工程的安全管理。全面开展外墙墙面及附着物、建筑附属构建高坠隐患整治，加大外墙外保温系统安全隐患整治力度，深入开展既有建筑玻璃幕墙安全排查，推进“一楼一档”的全覆盖。要狠抓施工现场安全管理体系，深入排查在建工程关键岗位人员到岗履职情况，切实加强风险识别和施工人员安全教育，强化物防技防手段运用，将各项安全防范措施落到实处。

（五）教育领域。要加强对学校重点部位、重点场所特别是校车安全监管，为中小学和幼儿园配齐安保人员及必要的安全防护装备器械，开展针对性防火、防爆、防灾、防不法侵害等安全专题教育和应急疏散演练，切实提升学生的自我防护能力和逃生自救能力。要对校园周边综合治理、校内生活设施、学生集中活动场所等逐一进行摸排，特别是要做好涉校涉生矛盾化解和重点人员管控工作，高质量落实三个“100%”校园安全防范措施。

（六）大型群众性活动。公安机关要严格各类大型活动审批与管控，坚持“谁主办、谁负责”和“谁审批、谁负责”原则，督促承办单位和相关部门制定应急预案，落实安全保障措施，并事先进行演练；要加强人流监测，安排足够警力，对人员密集和公共活动场所加强巡逻值守、安全防范和应急响应，严防发生拥挤、踩踏等伤亡事故。

（七）城市运行领域。要加强供电、供水、供气、通信等城市生命线基础设施保护，确保安全运行。要继续常态化开展非法加油（气）站点专项整治行动。落实车站交通安全各项保障工作，强化大型商场、江滩、旅游景点、夜市等人员密集场所的安全管理，强化军运会场馆和接待酒店安全检查，强化校园、外国人生活出行集中区域管控，确保国庆、军运会等重要活动期间安全运行。要加强基层安全网格化管理，日常安全巡查要进店、进厂、进小区，重点排查城乡结合部、插花地带、人员密集场所、中小微企业等易忽略的监管盲区，确保将各类潜在风险消除在萌芽状态。

液氨制冷、有限空间、粉尘涉爆、工业、寄递物流、城镇燃气、特种设备等重点行业领域也要结合本行业领域特点，抓好风险管控和隐患排查治理，持续深化安全生产专项整治，确保平安无事故。

三、落实非常之举，营造安全稳定社会环境

各街、各安全生产专委会、各部门和单位要紧盯“五个零”、“六个坚决防止”和“一无一降”目标不放，落实非常之举，采取一切有力措施，利用一切有利条件，坚决防范遏制事故发生，为新中国成立70周年大庆和第七届世界军人运动会顺利召开营造安全稳定的社会环境。

（一）科学制定专项措施。要按照区委、区政府统一部署，研究制定本辖区、本行业领域、本单位国庆、军运会等重大活动期间安全管控的特殊举措。企业要按照管控要求，妥善处理好计划进度安排，合理调整工期，加强停产复工、工艺变更、检维修等环节的安全风险管控，严格防范因赶工期、抢进度、违规违法生产、偷工减料等原因引发生产安全事故。

（二）加大监管执法力度。要按照全方位、全领域、全覆盖、全行业、全环节、全时段要求，下沉执法力量，加大监管执法、明查暗访、突击检查力度，突出风险高、隐患多、事故易发多发频发的区域、行业领域和企业，紧盯可能造成重特大事故的重大隐患和严重违法违规行为，综合运用联合执法、行政处罚、挂牌督办、公开曝光、举报投诉、联合惩戒、线索移交等手段，出重拳、下狠手，推动整改一批安全隐患，关闭取缔一批安全生产问题突出的生产经营单位，问责一批安全生产责任不落实、安全工作不作为的单位和个人。要坚持问题导向，建立执法检查发现问题隐患台账，逐项督促整改、闭环管理。对整改期间无法保证安全的，一律依法依规责令停产停业整改；对重大隐患问题无力整改、拒不整改的一律依法依规予以关闭；对排查整治期间发生生产安全事故的，安全隐患严重、问题突出的，一律依法依规予以上限处罚。区安办各督查组将不间断对各街、各部门工作情况进行督查检查，定期对发现的典型问题进行通报。

（三）全时全域做好应急准备和信息报送工作。要严格执行领导干部到岗带班和24小时干部值班制度，健全完善监测预警、应急协调联动、风险研判、调度会商工作机制。各街、各部门、各应急救援队伍要时刻保持战备状态，针对当前特别是国庆、军运会期间可能出现的各类突发事故（事件），完善应急预案、开展应急演练、前置应急救援力量，确保第一时间科学有效应对，严防引发次生事故灾害。要严格落实“零报告”制度，有事报信息、无事报平安，坚持重要信息随时报，日常信息累计报，坚决防止谎报、瞒报、漏报、迟报、随意报，确保各项工作“一日一交账”。要强化涉安舆情分析研判，强化正面引导和快速处置，确保有效管控、严密防范，及时回应社会关切，确保“网络舆情零炒作”。
