# 区人民政府关于印发蔡甸区推动生活垃圾分类高质量发展工作方案的通知

各街道办事处、乡人民政府，区人民政府各部门、各直属机构：

《蔡甸区推动生活垃圾分类高质量发展工作方案》已经区人民政府同意，现印发给你们，请认真遵照执行。

蔡甸区人民政府

2026年2月10日

蔡甸区推动生活垃圾分类高质量发展

工作方案

为贯彻落实《住建部生活垃圾分类工作评估办法》以及省、市关于高质量推动生活垃圾分类工作要求，按照《市人民政府办公厅关于印发武汉市推动生活垃圾分类高质量发展三年行动方案（2026—2028年）的通知》（武政办〔2025〕136号）文件精神，结合我区实际，制定本方案。

一、工作目标

坚持强基础、补短板、攻难点，不断完善生活垃圾分类治理体系，进一步健全长效工作机制，全面促进日常工作更加规范，生活垃圾分类收集、运输、处理能力稳步提升，社会参与生活垃圾分类的积极性明显提高，群众分类投放习惯逐步养成，全区生活垃圾减量化、资源化、无害化处理水平不断提升，基本实现全区生活垃圾分类全覆盖。

二、工作范围、责任主体

（一）工作范围

各街道（含中法生态城、蔡甸经济开发区、消泗乡，下同），含区农业农村局除拆迁区域以外的56个社区、235个行政村（大队、场）及单位，覆盖居民户数215161户。

（二）责任主体

坚持“社区（村）为基础，街道具体负责，部门协同”的原则，建立区、街道、社区（村）三级联动生活垃圾分类工作体系，统筹推进全区生活垃圾分类工作。

三、主要任务

（一）压实各方责任，构建长效工作机制

严格落实“管行业就要管垃圾分类”工作要求，各有关部门和单位按照职责分工，推进本行业垃圾分类工作标准和制度落实落地。各街道充分发挥实施主体责任，依托“街道—社区（村）—小区（网格）”架构，健全生活垃圾分类制度，协调各方力量落实生活垃圾分类责任。物业服务企业要做好容器配置、宣传督导、管理维护等工作，保持投放点、垃圾容器、收集屋及周边环境卫生整洁。

（二）加强分类管理，提升分类运行能力

1. 实施源头减量治理。坚持有关部门为主导、街道配合，结合无废城市建设，持续开展公共机构食堂、餐饮经营场所“光盘行动”，大力开展源头减量治理。推行简约包装，加大可循环、可折叠快递包装应用力度，推广使用菜篮子、布袋子和环保纸袋。落实禁塑限塑规定，引导住宿经营主体落实入住提醒，推行不主动提供一次性塑料用品；倡导餐饮行业不主动提供一次性用品；商场、超市、农贸市场、生鲜超市等商品零售场所落实一次性塑料制品禁用限用规定；禁止生产和销售一次性发泡塑料餐具、一次性塑料棉签和含塑料微珠的日化产品。

2. 加强分类设施管理。强化分类设施日常管理维护，设施规范使用率达95%以上。实行物业管理的小区，将前段设施运维管理纳入物业服务内容；无物业服务的小区以及村湾，由街道或社区（村）指定设施运维管理单位。

3. 开展分类提质行动。实施居民小区分类分级管理，逐步实现一、二类小区占比达到50%以上，推行“两袋对两桶”简易生活垃圾分类投放模式。巩固“撤桶并点”工作成效，规范分类标识，鼓励分类投放点集并设置。持续开展生活垃圾投放点便利化改造，逐步推动居民小区生活垃圾收集屋应建尽建。因地制宜推行农村区域“一坑两桶三上门”生活垃圾分类模式，有序推动农村厨余垃圾就地处理设施规范运行，加快推进农村生活垃圾收集屋建设试点。结合和美乡村建设，逐步改造乡村生活垃圾收集点。

4. 推行公共机构分类引领。推行公共机构强制生活垃圾分类，健全分类管理制度，规范分类设施设置，加强分类投放引导。公共机构要带头践行源头减量措施，持续推动无纸化办公，将生活垃圾分类工作纳入“节约型机关”等建设内容。全面推进公共机构标准化建设，每年按10%比例打造生活垃圾分类样板，充分发挥公共机构示范引领作用。

（三）健全分类体系，强化垃圾分类支撑

1. 强化分类运行提效。严格实行生活垃圾分类收集、分类运输、分类处理，生活垃圾无害化处理率达100%。小区（村湾）合理设置生活垃圾分类暂存点（集中转运点），提升生活垃圾分类收集暂存能力。加强生活垃圾分类收运管理，着重解决收运作业噪音、异味、容器占道、跑冒滴漏等扰民问题。结合实际需求，改造生活垃圾收集转运站，逐步满足分类转运需求。

2. 提升厨余垃圾管理质效。厨余垃圾以就地处理为主，外运处理为辅。大力推进农贸市场、生鲜超市厨余垃圾统一收运、集中处置，推广“不分类、不收运”机制。强化餐厨废弃物信息化监管，推行巡回收集、接驳转运、定时定点清运模式，严厉打击私收私处违法行为，切实提升餐厨废弃物全链条管理质效。

3. 实施有害垃圾闭环处置。按照“定点分类投放—街道收集暂存—专业运输处置”模式，进一步优化有害垃圾闭环管理体系。各街道建立有害垃圾暂存站（点），指导督促居民小区（村湾）有害垃圾定期收集至暂存站（点）细分类暂存，并由专业运输单位定期转运至危废中心处置。

4. 完善可回收物回收模式。居民小区（村湾）规范设置可回收物投放点和暂存点，持续推进智能回收箱进小区。各街道建立至少1处可回收物暂存站，鼓励精细化分类，促进可回收物应分尽分，应收尽收。构建“便民投放、专业收运、集中拆解、资源化利用”的大件垃圾处理体系，开展大件垃圾专项回收。

（四）深化宣传发动，推动分类习惯养成

1. 开展分类主题宣传。打造主题宣传阵地，规范设置宣传栏、公示栏，加强现有宣传设施管理维护，及时更新破损设施，持续巩固生活垃圾分类宣教阵地。组建生活垃圾分类宣讲队伍，采取日常入户宣传、集中宣传活动、融入其他各类活动等多种宣传形式，持续开展“五进”宣传活动、“敲门行动”和“千媒万屏”阵地宣传，充分利用微信公众号、微博、视频号等新媒体，普及生活垃圾分类常识。鼓励和倡导更多的社区志愿者、青年志愿者和社会组织参与生活垃圾分类宣传和桶边督导工作，有效发挥行业指导、协会带动、党员及志愿者等宣传引导作用，全面营造浓厚社会氛围。

2. 开展全覆盖培训。聚焦餐饮企业、农贸市场、物业企业、公共机构、居委会、村委会等重点领域，围绕“环境卫生责任制”“不分类不收运”“餐厨废弃物收运”“前端设施运行管理维护”“可回收物循环利用”“文明投放习惯养成”等关键环节，广泛开展生活垃圾分类培训，落实基层从业人员培训全覆盖。

3. 开展垃圾分类执法。各街道综合执法中心要持续开展生活垃圾分类执法检查，对生活垃圾分类责任不落实、收运作业不规范、设施管理不到位、不履行投放管理责任人责任等违法行为，依法依规进行处罚。

四、保障措施

建立区级生活垃圾分类协调联动机制，区城管执法局要强化统筹协调，各行业主管部门要按照职责分工协同推进生活垃圾分类工作，各街道要落实细化生活垃圾分类工作要求，社区（村）要组建生活垃圾分类工作队伍，建立层层抓落实的工作机制。区财政要加大生活垃圾分类工作的投入，鼓励社会资本参与，拓宽融资路径。生活垃圾分类工作经费按20元/户/年给予补贴，根据各街道工作情况核拨，由街道统筹分配使用。加强资金管理和监督检查，提高资金使用绩效，确保资金专项用于生活垃圾分类工作，不得截留、挤占、挪用。

本工作方案自2026年3月16日起施行，有效期2年。
