# 市房管局关于公布规范性文件清理结果的通知

各区房管局、直属各单位、机关各处室：

为了适应依法行政工作的需要，根据《市人民政府办公厅关于全面开展规范性文件清理工作的通知》(武政办电〔2016〕9号)和《武汉市行政规范性文件管理规定》(市政府令第175号)要求，我局对历年制发的现行有效规范性文件(截至2017年6月30日止)进行了清理。经过清理，确定了继续有效、废止、失效、拟修改的规范性文件共110件，其中，继续有效的规范性文件36件；废止的规范性文件49件；失效的规范性文件9件；拟修改的规范性文件16件。现将继续有效、废止、失效、拟修改的规范性文件目录予以公布。
