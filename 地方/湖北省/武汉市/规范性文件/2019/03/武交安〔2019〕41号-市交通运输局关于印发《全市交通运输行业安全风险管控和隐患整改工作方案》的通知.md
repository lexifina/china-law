# 市交通运输局关于印发《全市交通运输行业安全风险管控和隐患整改工作方案》的通知

全市交通运输行业安全风险管控和

隐患整改工作方案

一、工作目标

集中整改市安委会办公室印发《全市有关行业领域安全风险管控和隐患整改责任清单》中涉及交通运输行业的相关问题，确保及时、有效和高质量、高标准地完成整改工作。通过问题整改，补齐交通运输安全生产工作的短板，健全安全生产责任体系、隐患排查治理体系和安全预防控制体系，确保全市交通运输行业安全形势稳定。

二、整改内容

涉及交通运输行业所属公路桥梁隧道、综合交通、危险化学品经营储存和运输等四大类13项安全风险管控和隐患整改问题（具体见附件）。

三、整改要求

（一）加强组织领导。市交通运输局成立以徐斌局长为组长，相关分管局长为副组长，局机关相关处室和局属行业管理部门主要负责人为成员的整改工作领导小组，办公室设在局安监处，负责全行业相关问题整改的统筹、协调和督办工作。各单位要严格按照“党政同责、一岗双责、齐抓共管、失职追责”和“三个必须”的要求，成立本行业、本地区、本单位整改工作领导机构，加强整改问题的组织领导。

（二）加强整改落实。各单位对市安委办指出的问题要诚恳接受，照单全收，狠抓整改。要认真剖析问题存在的深层次原因，逐条逐项研究制定整改措施，分行业（领域）、分层级制定整改方案。能立即整改的要迅速整改；不能立即整改的要明确落实整改的措施、责任、资金、时限和应急预案，确保生产经营安全；存在严重隐患的单位要坚决停产整顿，对重大隐患要进行挂牌督办；在规定时限达不到整改要求的，要依法关闭或取缔。

（三）加强督查问责。市交通运输局将整改工作纳入安全生产目标管理，严格实施“一票否决”。各单位要将整改工作列入年度安全生产重点工作，加强协调、检查，确保问题整改有序推进，取得实效。市交通运输局将适时采取现场推进会和暗访暗查等方式进行督导，对未按期完成整改或整改不认真、不达标的单位予以全行业通报，并抄送至上级主管部门或辖区政府；对整改不力负有责任的，要依法依规追究相关人员责任。

各单位应于3月8日前将整改工作方案、联络员名单，8月5日前（整改时限在此之前的按照表中所列的时限报送）将整改落实情况和长效机制建立情况以书面形式报市交通运输局。上述材料请同时报送电子版。联系人：周洁峰、易侃，电话：68820069，邮箱：505422997@qq.com。
