# 市交通运输局关于认真吸取江苏省盐城市响水县“3.21”爆炸事故教训切实加强安全生产工作的紧急通知

武汉交通运输各单位：

为认真贯彻落实习近平总书记关于江苏省盐城市响水县“3.21”爆炸事故的重要批示精神，深刻汲取事故教训，举一反三，切实加强当前安全生产工作，有效防范和坚决遏制重特大生产安全事故，确保全市交通运输行业安全生产形势平稳，现将有关事项紧急通知如下：

一、切实提高政治站位，加强安全生产工作组织领导

近期，全国发生多起重特大事故，充分暴露出当前安全生产形势的严峻性，尤其是危险化学品和道路旅客运输领域的高危性、事故的易发性。交通运输各级领导干部要严格落实安全生产“三必须”和“党政同责、一岗双责、齐抓共管、失职追责”的总要求，以高度政治责任感和使命感抓好分管行业（领域）的安全生产工作。要组织开展一次安全生产形势集中分析，剖析本地区、本行业安全生产领域的突出问题和重大风险，认真检查当前工作上存在的薄弱环节，有针对性采取强有力的应对措施，强化监管、堵塞漏洞，有效稳控行业安全生产形势。特别是当前正值市、区机构改革关键时期，部分区级交通运输管理机构正在进行部门调整或职能转移，更要做好人员和市场监管的无缝衔接，确保安全责任和措施的延续性，确保安全监管不出现真空、不出现盲区。

二、突出重点行业领域，全面开展事故隐患排查治理

各部门、各单位要力戒官僚主义和形式主义，深入基层一线，切实加强重点区域、重点部位、重点环节、重点时段的安全隐患排查治理，对查出的事故隐患要立即整改，确保万无一失。

（一）水上交通：重点加强对非法渡口、“三无”船舶、非法营运和船舶超载等违法行为的查处，对乡镇渡口渡船、库湖区旅游船的通信、消防、救生等安全设备的保养、配备情况进行检查，对港口危险品装卸、储运等安全规范的落实情况进行检查。

（二）道路运输：重点加强营运车辆技术状况和驾驶员从业资格的监管，重点检查危险货物运输车辆罐体紧急切断装置的加装及使用、车辆日检和例检情况，督促“两客一危”运输企业加强车辆动态监控管理和客运站 “三不进站、六不出站”及长途客运实名制等规范的管理。

（三）城市公交：重点加强公交车的行车和停车秩序整顿，持续治理高速行车、争道抢行、开车打手机、载客加油等违规行为；对营运公交车、船安全技术状况日维护、周安检、月例保规程和运营安保“九个一”防范措施情况进行检查。

（四）客运出租：重点加强出租车非法营运行为的查处，督促企业落实车辆强制维护制度、车辆保险制度、车辆安全检查制度以及驾驶员安全知识培训教育的检查。

（五）轨道交通：重点加强对故障频率较高、影响运营较多的信号、供电、车辆、线路等部位和薄弱环节的专项整治，对电（扶）梯、吊车等特种设备的定期保养情况进行检查，对车站、指挥中心等运营重点部位“三品”查堵情况进行检查。

（六）公路管理：重点加强农村客运班车、校车通行公路和急弯陡坡、临水临崖等危险路段的隐患治理，加强公路桥梁的巡查、监测和维护，对超限超载等违法行为进行查处。加强与公安交管部门的配合，全力做好节日期间小客车免费通行工作，确保车辆通行安全畅通。

（七）交通建设：重点加强对桥梁涵洞和深基坑施工等安全责任和措施落实情况的检查，加强施工现场脚手架搭设、施工用电、塔吊和施工机械安全管理情况的检查，严防人员和设备高坠现象的发生。加强施工分包队伍资质、人员证照、专项方案审批等事项的检查，对现场管理混乱、问题突出、隐患严重的施工工地坚决进行停工整顿。

三、切实落实安全责任，确保各项工作措施落到实处

各部门、各单位要督促企业强化安全生产主体责任，严格落实安全生产层级责任制，完善安全事故双重预防机制，有效管控运输工具、特种设备、作业施工场地、人员密集场所等方面的安全风险，及时消除事故隐患。要加强对安全管理人员和特殊岗位人员的安全培训和警示教育，严防违章操作引发事故。要坚持谁主管、谁负责原则，认真履行安全监管职责，及时纠正查处非法违法、违规违章行为。要建立和完善聘请安全管理专业技术人员参与安全检查督导工作制度，提高隐患排查治理工作的准确性和权威性。要认真落实隐患治理分级督办制度，对负有责任的领导、工作人员，要依法依规严肃处理，并及时向社会公布调查处理结果。

四、强化安全应急值守，及时有效处置各类突发事故

各部门、各单位要严格实行领导带班和24小时值班制度。要加强应急队伍的建设和管理，配备必要救援装备、器材和物资，加强应急演练，处于临战待命状态，一旦发生险情，能够快速、有效地予以处置。要加强安全信息报送工作，确保信息畅通。严格执行事故专报制度，严禁迟报、漏报、谎报、瞒报。

各区交通运输主管部门和局属各行业管理部门要立即进行部署和动员，从即日起，每天15:30前报送《武汉市安全生产专项督查情况统计表》（见附表），4月28日前报送贯彻落实情况至市交通运输局安监处（联系人：易侃，传真电话： 68820069，邮箱：505422997@qq.com）。
