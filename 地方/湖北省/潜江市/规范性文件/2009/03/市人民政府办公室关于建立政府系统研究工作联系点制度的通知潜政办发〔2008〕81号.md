# 市人民政府办公室关于建立政府系统研究工作联系点制度的通知潜政办发〔2008〕81号

潜政办发〔2008〕81号

市人民政府办公室

关于建立政府系统研究工作联系点制度的

通 知

各管理区，镇人民政府、办事处，高场原种场，市政府各部门：

为推动政府系统研究工作的深入开展，开创政府系统研究工作新局面，进一步促进政府系统研究工作的规范化和制度化，经市政府领导同意，市政府研究室决定在全市政府系统建立研究工作联系点制度。现就有关事项通知如下：

一、建立研究工作联系点的目的

通过建立研究工作联系点，加强与各地各部门的联系和沟通，及时了解各地各部门贯彻落实市委、市政府重大决策和工作部署的进展情况，采取的新举措、取得的新成果、总结的新经验、遇到的新问题，增强研究工作的针对性、时效性和预见性。通过充分发挥研究工作联系点的平台和纽带作用，使研究工作一方面能够源于基层、面向基层、为基层服务，另一方面能够及时、准确、深入地传递基层实际情况，更好地服务于市委、市政府的重大决策，服务于全市经济社会发展。

二、研究工作联系点的主要任务

研究工作联系点的主要任务是对本地本部门所承担的主要工作开展调查、研究、总结，并定期（每月）向市政府研究室报送工作情况和调研文章。各研究工作联系点报送的情况和调研文章主要包括：

（一）本地本部门本月（本季、半年、全年）贯彻落实市委、市政府重大决策和工作部署的基本情况，取得的主要进展，存在的主要问题；

（二）本地本部门在积极履行职责、推进各项工作中采取的新举措、新方法；

（三）本地本部门的特色工作及取得的典型经验；

（四）针对某项具体课题或工作，提出的意见或建议等；

（五）对日常工作中随时发生的有价值的事件或情况，可随时向市政府研究室反映。

三、研究工作联系点成果的应用

市政府研究中心通过下列方式对研究工作联系点的研究成果进行应用：

（一）对各联系点报送的主要工作进展情况进行综合整理，形成每月、每季、半年、全年的全市经济社会形势分析报告送市委、市政府领导阅示，为领导科学决策和合理调度提供依据。其中，半年情况将作为全市半年经济形势分析会上市政府主要领导所作主题报告的素材来源，全年情况将作为起草《政府工作报告》的素材来源。

（二）及时总结各联系点反映出的好经验和好做法，通过《政府工作》等形式上报市政府领导批示，在本市交流和推广。

（三）对各联系点报送的优秀调研文章，在《政府工作》上刊载，或推荐给省以上刊物发表，并在年终组织评奖。

（四）组织工作表现突出的联系点分管领导和工作人员参加专题调研、外出考察和研讨会等活动。

（五）定期将研究工作联系点的优秀材料和文章编辑整理成书，出版发行。

四、研究工作联系点成员单位及有关要求

（一）联系点成员单位：

为全面掌握全市经济社会发展情况，确定全市各区镇处场、与经济社会发展相关的市直各部门、市内重点企业均为研究工作联系点成员单位。

根据实际工作需要，明确下列联系点必须在每月上旬报送本单位所承担主要工作的进展情况，其他联系点可视自身工作情况进行报送，但半年和全年工作情况所有联系点都必须报送：

1、经济综合主管部门、经济发展服务部门、社会事务主管部门（50个）：市发改委，市经委，市农办，市建委，市财政局，市统计局，市商务局（招商局），市劳动和社会保障局，市民政局，市教育局，市卫生局，市经济发展环境投诉中心，市信访局，市文指办，市支油办，市国土局，市工商局，市国税局，市地税局，市科技局，市人口和计生委，市城投公司，市开发性金融合作办，市行政服务中心，市综合招投标办，市国资办，市文化局，市广电局，市公安局，市综治办，市安监局，市交通局，市药监局，市烟草局，市质监局，市供电公司，市农管局，市农业局，市水利局，市林业局，市水产局，市畜牧局，市农机办、市物价局，市人行，市银监办，市环保局，市房管局，市规划局，市住房公积金管理中心。

2、开发区及工业园区（5个）：园林办事处（园林国家级星火技术密集区），潜江经济开发区，杨市办事处（杨市工业园），王场镇（江汉盐化工业园），张金镇（张金经济开发区）。

3、各重点项目指挥部：具体工作情况由项目指挥部办公室所在单位负责一并报送。

4、重点企业：企业建设及生产经营情况由所在的区、镇、处、场负责一并报送。

（二）有关要求

各研究工作联系点单位应明确1名领导分管此项工作，并确定1名以上的具备一定理论水平和研究能力、具有较强的创新精神、文字功底较强的同志负责本单位的研究工作。

请各单位在6月30日前将本单位的分管领导及研究工作人员名单及联系方式报送市政府研究室。联系人：市政府办公室综合调研科李军；联系电话：6291691。
