# 市人民政府关于调整我市城乡居民最低生活保障标准的批复

市民政局：

你局《关于调整城乡居民最低生活保障标准的请示》（潜民政文〔2011〕120号）收悉。经研究，现批复如下：

一、同意将我市城市居民最低生活保障标准从300元/月提高到360元/月，农村居民最低生活保障标准从100元/月提高到150元/月。从2012年1月起执行。

二、提高保障标准后，要重新核实低保家庭月收入，按规定将补助资金发放给保障对象。

三、要不断完善促进低保对象就业的办法和措施，形成“低保对象有进有出、补助水平有升有降”的良性运行机制。

潜江市人民政府办公室

二○一二年一月九日
