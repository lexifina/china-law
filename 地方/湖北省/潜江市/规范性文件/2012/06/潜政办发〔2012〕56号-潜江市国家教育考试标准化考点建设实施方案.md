# 潜江市国家教育考试标准化考点建设实施方案

根据《教育部财政部关于大力推进国家教育考试标准化考点建设工作的通知》（教学〔2011〕1号）、《省教育厅省财政厅关于大力推进国家教育考试标准化考点建设工作的通知》（鄂教财〔2012〕1号）精神，综合普通高考、成人高考、自学考试等各类国家教育考试需求，结合我市国家教育考试实际情况，制定本实施方案。

一、指导思想和基本原则

（一）指导思想。

根据国家和省《中长期教育改革和发展规划纲要（2010-2020年）》有关要求，进一步加强国家教育考试管理，严格防范和严肃查处招生考试舞弊行为，维护招生考试的安全和秩序，切实做到公平、公正；建立科学规范的考试管理体系，推进教育考试标准化建设，建立国家教育考试信息数据库和信息采集共享平台。

（二）基本原则。

1．程序规范，务实高效，质量第一。

2．统一领导，统筹规划，统一标准。

3．分步实施，分级管理，谁建设、谁负责。

二、建设目标

充分利用网络、无线电通讯、数据库等高科技手段，分两个阶段完成我市标准化考点建设。第一阶段:在2012年6月1日前，完成9个高考考点、1个试卷保密室、1个考务指挥中心和325个考场的标准化建设，形成全市普通高考考点考场视频监控和网上巡查系统。第二阶段:在2013年底前完成标准化考点其它系统的建设任务。

三、组织领导

市政府成立“潜江市国家教育考试标准化考点建设领导小组”（名单附后），负责标准化考点建设。

领导小组下设标准化考点建设工作小组，负责贯彻执行标准化考点建设的相关标准及规范，组织标准化考点建设的实施、监督管理及验收工作。

各考点学校要成立由学校主要负责人为组长的工作专班，具体负责学校标准化考点建设与管理工作。

四、工作安排

（一）工作步骤。

第一阶段（2012年4月—5月底）：

1.4月中旬，召开学校标准化考点建设工作动员大会，明确相关部门的责任和任务，对标准化考点建设工作进行动员部署。

2.4月下旬，落实市级配套资金，确定建设实施方案，完成招投标工作，选定施工队伍和施工监理方。

3.4月25日前，完成考点和指挥中心施工建设。

4.5月30日前，完成测试验收工作。

第二阶段（2013年底前）：

完成标准化考点其它系统的建设任务。

（二）资金来源及投资预算。

标准化考点建设预算总额658万元：

第一阶段投资预算558万元，其中国家和省财政奖补资金286万元，市级财政配套资金272万元。

第二阶段投资预算100万元，资金来源根据国家和省财政奖补情况而定。

（三）项目实施。

在标准化考点建设过程中，严格按照《国家教育考试标准化考点规范（暂行）》、《国家教育考试标准化考点信息标准》、《国家教育考试标准化考点视频指挥建设技术规范》、《国家教育考试标准化考点网上巡查技术标准》的要求及市国家教育考试标准化考点建设领导小组审定的“建设实施方案”，认真组织开展标准化考点的建设工作。

各相关部门要切实加强对标准化考点建设执行情况的管理，做好项目前期的规划论证、方案设计、资金落实，项目中期的招投标、采购、工程施工、设备安装调试，以及项目后期的检查、验收等环节的工作。

（四）监督监理。

建立标准化考点建设的监督检查机制，强化督察与指导，确保标准化考点建设在规定工期内保质保量完成。

标准化考点建设项目应接受国家和省相关单位依法进行的监督检查，接受省教育考试院及纪检监察等部门的监督。

（五）项目验收。

项目验收应按照“谁建设、谁负责”的原则进行。项目验收的内容包括工程质量、网络平台建设、应用系统的性能测试、网络系统的互联互通等。具体验收工作由标准化考点建设工作小组组织实施。

对验收合格的考点学校，经市国家教育考试标准化考点建设领导小组审核同意后，报省工作小组验收。对验收不合格的考点学校要责令其限期整改，并于6月1 日前整改到位。

（六）运行和维护。

在运行维护阶段，要保证网络、系统正常稳定运行,并根据实际情况优化网络、调整设备参数，确保标准化考点重要设备和数据的安全。

标准化考点应用系统的运行和维护要遵循教育部考试中心所制定的各项制度和规定。各考点学校要结合自身实际，逐步建立健全各项管理制度，建立标准化考点安全管理、日常运行保养管理体系，从而最大程度地发挥系统的效能，保障系统使用的规范化。

市国家教育考试标准化考点建设领导小组办公室统筹协调标准化考点运行维护的管理工作，各考点应负责标准化考点设备的日常运行和维护工作，确保设备正常运行，并优先保障国家教育考试使用。
