# 市人民政府办公室关于调整潜江市打击制贩假币犯罪联合行动领导小组的通知

各管理区，镇人民政府、办事处，市政府各部门：

鉴于人事变动，根据工作需要，经市政府研究同意，决定对“潜江市打击制贩假币犯罪联合行动领导小组”进行调整。领导小组成员的调整及其工作职责，由领导小组办公室报请组长同意后自行发文。现将调整后的成员名单通知如下：

组 长：罗茂文 市委常委、常务副市长

副组长：李长兵 市政府副秘书长

张春阳 人行潜江市支行行长

领导小组下设办公室，办公室设在市人民银行，郑月强同志任办公室主任。

潜江市人民政府办公室

二○一二年六月七日
