# 市人民政府办公室关于做好2012年度政策性“三农”保险工作的通知

各管理区，镇人民政府、办事处，市政府有关部门：

为了切实增强农业、农村、农民抵御自然灾害和意外事故风险的能力，构建全市“三农”风险保障机制，促进农村经济健康协调发展，根据中央和全省农村工作会议精神，结合我市实际，现就做好2012年度全市政策性“三农”保险工作通知如下：

一、政策性“三农”保险的范围及保费补贴方案

（一）保险范围。

2012年政策性“三农”保险推广险种包括水稻保险、油菜保险、能繁母猪保险、“两属两户”（持证的农村军属、烈属和低保户、分散供养的五保户）农房保险、农民工意外伤害保险。

（二）保险经办机构。

按省有关要求，参照周边县市做法，2012年政策性“三农”保险范围内所涉及险种由人保财险潜江支公司承办。

（三）保费补贴方案。

1.水稻保险。保险金额为每亩200元，保险费率7%，即每亩每季保费14元，其中：中央财政补贴40%，每亩5.6元；省财政补贴25%，每亩3.5元；市财政补贴10%，每亩1.4元；农民承担25%，每亩3.5元。

2.能繁母猪保险。保险金额为每头1000元，保险费率6%，即每头母猪一年保费60元，其中：中央财政补贴50%，每头30元；省财政补贴30%，每头18元；农民承担20%，每头12元。

3.“两属两户”农房保险。为全市“两属两户”提供农房保险，保险金额为每户3000元，保险费率3‰，即每户每年保费9元，其中：省财政补贴70%，每户6.3元；市财政补贴30%，每户2.7元。

4.油菜保险。保险金额为每亩200元，保险费率5%，保险费每亩10元，其中：中央财政承担40%，每亩4元；省财政承担25%，每亩2.5元；市财政承担10%，每亩1元；农民承担25%，每亩2.5元。

5.农民工意外伤害保险。为外出务工人员投保意外伤害保险，每人保费5元，保险金额4万元。保费由农民工自行承担。

二、政策性“三农”保险的承保流程

各有关部门和人保财险潜江支公司会同各地按照“加强引导、农民自愿、优质服务”的原则，以村为单位逐户登记、逐户收取农民应付的保险费。人保财险潜江支公司与各村签订统一投保单、保险单，并根据农民投保明细制作保险凭证，由村组发放到每位投保农户手中，做到每个险种一户一证。

三、政策性“三农”保险的理赔办法

（一）报案。保险事故发生后，投保农户应及时向人保财险机构报案（全国统一报案电话：95518）。

（二）查勘定损。人保财险潜江支公司接到报案后应及时派人进行现场查勘，按照保险条款载明的理赔方式和标准核定损失。

（三）赔付。对属于保险责任的，人保财险潜江支公司应从投保农户提供齐全手续之日起15日内进行赔付。对不属于保险责任的，人保财险潜江市支公司应耐心做好宣传、解释工作，以获得投保农户的理解。

四、政策性“三农”保险的保障措施

（一）突出工作重点。

2012年政策性“三农”保险工作重点是突出抓好水稻保险工作。水稻保险季节性强、涉及面广、工作难度大、时间要求紧，各地要高度重视，加强领导，强化宣传，集中力量，集中时间，采取有效措施完成全市水稻保险投保工作，做到水稻种植面积应保尽保。

（二）切实落实保费。

各地要切实做好政策性“三农”保险农民应承担的保费的收缴工作。市财政局要落实好财政保费补贴资金，具体程序为：人保财险潜江支公司定期将签订的保单及农户已缴清的保费汇总，并按险种报市农业、民政、畜牧部门审核后，向市财政局进行申报；市财政局按照相关管理办法，将年初纳入市级财政预算的保险配套资金及时拨付，并积极向上申报中央和省级财政保险保费补贴资金。

（三）加强市、镇、村“三农”保险服务体系建设。

“三农”保险服务体系是做好政策性“三农”保险的基础性工作。要进一步巩固市、镇、村“三农”保险服务体系建设，成立市、镇“三农”保险工作机构，依托镇政府农业办公室或者财管所等涉农部门成立“三农”保险服务站，同时选聘一名“三农”保险专职负责人，在各村选聘一至二名协保员。镇“三农”保险负责人和村协保员在人保财险潜江支公司和镇政府的领导下开展宣传、承保、查勘等工作。

（四）严肃政策性“三农”保险工作纪律。

财政保费补贴资金要实行“专户管理、封闭运行、保单结算、据实补贴”。市财政、审计、监察部门要加强对补贴资金的监督管理，确保政策性“三农”保险真正惠及“三农”。市有关部门和人保财险潜江支公司要严格执行中央和省有关政策，对违反规定、弄虚作假，挤占、挪用财政保费补贴资金，骗保、套保的要严肃查处。

（五）做好宣传发动工作。

政策性“三农”保险遵循农民自愿参保的原则。人保财险潜江支公司和相关部门要充分利用广播、电视、报刊、网络等媒体，广泛宣传“三农”保险工作的政策和重要意义，将党和政府的惠农政策和经办机构的承保要求印制成宣传单发放到户，及时向广大农户宣传，做到家喻户晓，增强广大农民群众的保险意识，千方百计调动农民自愿参保的积极性。

五、组织领导

市政府成立“潜江市2012年政策性‘三农’保险工作领导小组”（名单附后），全面推进全市“三农”保险服务体系建设，各成员单位和各工作专班具体负责“三农”保险工作的组织协调工作。各地要高度重视，成立相应工作专班，切实加强领导，把政策性“三农”保险工作纳入重要议事日程。建立全市政策性“三农”保险工作联席会议制度，由市政府金融办作为召集单位，市农业局、市财政局、市民政局、市人力资源和社会保障局、市水务局、市国税局、市地税局、市气象局、人保财险潜江支公司等有关部门为成员单位，根据工作需要召开“三农”保险工作联席会议，协调解决工作中出现的困难和问题。市政府金融办要加强检查督办，定期通报各地政策性“三农”保险工作进展情况。
