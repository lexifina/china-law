# 市人民政府办公室关于进一步加强农村气象灾害防御工作的意见

各管理区，镇人民政府、办事处，市政府各部门：

为切实做好我市农村气象灾害防御工作，发挥气象服务“三农”的重要作用，现就进一步加强我市农村气象灾害防御工作提出如下意见：

一、充分认识加强农村气象灾害防御工作的重要意义

近年来，我市极端灾害天气频发，给农业生产和农民收成造成了不利的影响。加强农村气象灾害防御工作，对于提高政府公共服务能力、提高全社会防灾减灾水平、保障人民生命财产安全具有重要的现实意义。

做好农村气象灾害防御工作，有利于趋利避害，有利于巩固农业农村发展的大好形势，有利于加强社会主义新农村建设。各地、各有关部门要把农村气象灾害防御工作作为农村公共服务体系建设的重要组成部分，精心部署，落到实处，抓出成效。

二、切实加强组织领导

（一）加强组织领导。为强化管理，市政府成立潜江市农村气象灾害防御工作领导小组，组织协调全市农村气象灾害防御工作。领导小组由分管农业工作副市长任组长，市农办、气象局、民政局、农业局、水务局、林业局、交通运输局、公安局、国土资源局、广播电影电视局、市政府应急办等单位负责人为成员。领导小组下设办公室，办公室设在市气象局。

（二）健全工作机制。要按照“政府主导、部门联动、社会参与”的工作思路，高度重视并持之以恒地抓好基层气象灾害防御组织体系建设。市气象、农业、水务、民政、国土资源、林业、公安、广播电视、通信等部门和单位要加强合作，推动农业农村气象信息、资源和成果共享，建立多部门合作的联动机制。

（三）加强监督考核。各地、各有关部门要将农村气象灾害防御工作融入到农村公共服务体系中积极推进。气象部门要加强调查研究，及时进行检查督办，高质量地推进农村气象灾害防御工作。要将农村气象灾害防御工作落实情况，作为农村工作先进单位评选考核的依据之一。

三、大力加强气象灾害防御体系建设

（一）抓好气象灾害防御规划编制工作。科学编制气象灾害防御规划，是做好农村气象灾害防御工作的前提。市气象局要精心编制气象灾害防御规划，明确气象灾害防御工作的发展目标、主要任务和灾害应对措施，大力推进气象防灾减灾体系建设。今年要编制出台潜江市气象灾害防御规划，完成全市气象灾害风险调查和区划工作。

（二）加快农村气象信息服务站和气象协理（信息）员队伍建设。农村气象信息服务站、气象协理（信息）员是推进气象信息进村入户的有效途径，是为农民提供气象信息服务的主要载体，是农村公共气象服务体系和综合信息服务体系建设的组成部分。各地要配备1名以上兼职气象协理（信息）员，农村社区便民服务中心要将气象信息服务工作纳入日常工作。要实现镇（管理区、办事处）有气象信息服务站、村有气象信息员的工作目标。气象协理（信息）员工作由所在地政府及村委会考核，市气象局协助提供技术支持和业务培训。

（三）加强气象灾害防御应急组织工作。要建立健全气象灾害防御预警机制，做好气象灾害预警到村、责任到人的农村气象灾害应急处置工作。行政村村委会主任为本区域气象灾害防御责任人。村级组织要在气象灾害危险区设立警示牌，并清楚标明气象灾害防御应对措施。各地要建立健全气象灾害应急预警工作责任制，加快推进预警到村入户的农村气象灾害应急预警机制建设。

（四）健全气象预警信息发布传播网络。各地要针对气象灾害具有突发性、影响面广的特点，健全农村气象灾害预警发布网络。要加强镇村级高音预警广播、气象信息电子显示屏、预警短信平台等传播发布气象灾害预警信息的载体建设，确保在重大气象灾害发生前，能做到将气象灾害防御预警信息及时通知到每村每组每户。相关预警发布系统由市政府统一建设，其中镇村级高音预警广播、气象信息电子显示屏由所在地气象协理（信）员负责管理，气象预警中心发布平台由市气象局建设、维护。

（五）加强农村防雷安全工作。雷电灾害是危害农村最严重的气象灾害之一。市气象局要进一步普及农村防雷安全知识，增强农民的防雷意识，做好雷电监测预警工作，通过广播、电视、手机短信以及气象信息电子显示屏等方式及时发布雷电预警信息。要做好农村防雷安全技术的指导，重点加强农村中小学校舍防雷安全工作。有条件的地方可以对自愿为新建建筑安装防雷装置的农户给予适当补助。要创造条件开展防雷安全示范村建设工作，努力减少农村因雷电引发的伤亡事故。

（六）积极开展人工影响天气作业。市气象局要加强天气预测预报工作，指导开展好人工影响天气工作。要积极加强人影设施、人影队伍、队伍作业水平建设，在出现干旱缺水时，积极开展人工增雨作业，充分利用空中云水资源，努力缓解农业用水紧张。
