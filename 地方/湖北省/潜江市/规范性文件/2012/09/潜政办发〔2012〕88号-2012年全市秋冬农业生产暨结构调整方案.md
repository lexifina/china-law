# 2012年全市秋冬农业生产暨结构调整方案

为切实抓好2012年秋冬农业生产，科学引导2013年农业结构调整，确保农业增产、农民增收，特制定如下实施方案。

一、指导思想

坚持以科学发展观为指导，以市场为导向，以发展现代农业、建设农业强市为目标，以农作物高产创建、畜禽规模化养殖和水产生态健康养殖为抓手，以种满种足为重点，以提质增效为核心，实行布局区域化、基地规模化、技术集约化、生产标准化、经营专业化，全面提升秋冬农业综合生产能力，加快推进现代农业建设，促进“三化同步”协调发展。

二、目标任务

2012年全市秋冬农业生产总体目标是：农作物布局立足稳粮、扩油、增菜，坚持夏粮、油菜、蔬菜三大类优势作物协调发展，调整品种结构，提高产量和品质，增加综合效益。秋冬播规划总面积106.3万亩，比上年增加0.16万亩，其中夏粮面积42.0万亩（小麦39.0万亩、大麦0.3万亩、蚕豆0.1万亩、马铃薯2.6万亩），比上年减少3.95万亩；油菜面积53.0万亩，比上年增加3.26万亩；蔬菜面积11.0万亩，比上年增加0.67万亩；绿肥等其它作物0.30万亩。规划2013年夏粮产量10.71万吨，比上年减少0.44万吨；油菜籽产量10.87万吨，比上年增加0.92万吨；蔬菜产量29.70万吨，比上年增加1.71万吨。畜牧业立足积极发展生猪养殖，全年规划出栏110万头，比上年增加5万头；稳定发展家禽养殖，全年规划出笼1800万只，比上年增加100万只；大力发展牛羊养殖，今年达到6.1万头，比上年增加0.6万头。水产业立足大力发展虾稻共生，面积达到22万亩，比上年增加1.8万亩；积极发展水产生态健康养殖，面积达到12万亩，比上年增加2万亩；稳步发展网箱养鳝，总规模达到60万口，比上年增加3万口。

三、主要措施

（一）调整种养结构，优化产业布局。

1.稳定发展夏粮生产。紧紧抓住国家“新增千亿斤粮食生产能力规划”政策实施的机遇，积极扩大马铃薯种植面积，调整小麦种植区域，稳定管理区旱地小麦种植面积，适度调减镇处和管理区水田小麦种植面积，确保全市小麦种植面积稳定在39万亩左右，优质小麦种植面积达到95%以上。大力开展高产创建，全面提高小麦、马铃薯单产水平和种植效益。

2.扩大油菜种植面积。充分利用“油料大县”奖励政策，采取统一供种等办法，按照“一镇一品”、“一村一品”的要求，积极组织龙头企业和中介服务组织参与，大力推进双低优质油菜连片种植，恢复性发展油菜生产，确保全市油菜种植面积超过53万亩，双低油菜优质率达100%，订单生产达到60%以上。

3.提升蔬菜生产水平。以推进新一轮“菜篮子”工程建设为重点，引导龙头企业和合作组织建设生产基地，大力发展大棚蔬菜和大棚西瓜。抓好现有基地的改造升级和新基地的达标建设。大力发展莴苣、甘蓝、花菜、辣椒、西红柿、菜薹等精细蔬菜，力争秋冬播精细蔬菜面积占蔬菜种植面积的50%以上。

4.持续发展畜禽生产。充分发挥“畜牧大县”优势，按照巩固老基地、发展新基地，建设核心区、带动辐射区，打造龙头企业、突破性发展加工业的要求，持续发展畜禽生产。以后湖管理区为中心，辐射带动积玉口镇、浩口镇、张金镇、龙湾镇等地建设现代生猪养殖示范区；以明强禽业为龙头，带动园林办事处、竹根滩镇、周矶办事处、杨市办事处等地建设500万只家禽标准化养殖基地；以海天牧业为龙头，引导总口管理区、园林办事处、渔洋镇、竹根滩镇等地大力发展牛羊规模养殖。

5.加快发展水产养殖。推进龙湾现代渔业科技示范园、后湖张家窑小龙虾科技示范园和西大垸观赏鱼基地建设，充分发挥示范引领作用；健全完善水产良种繁育体系，抓好小龙虾、泥鳅、翘嘴红鲌、鱤鱼等苗种繁育基地建设；加大小龙虾规模养殖基地建设力度，出台扶持政策，掀起小龙虾养殖新高潮；加大水产生态健康养殖基地建设，全面提高水产品产量和质量。

（二）推进高产创建，带动平衡增产。

加大小麦、马铃薯、油菜高产创建和蔬菜标准园创建力度。按照统一整地播种、统一肥水管理、统一技术培训、统一病虫防治、统一机械收获的技术路线，集约项目、集中力量、集成技术，加快农业规模化、标准化生产步伐。积极探索高产创建与种植大户、专业合作社、产业化龙头企业相结合模式，推进生产组织方式创新。今年秋冬播生产中，市级办好熊口镇、渔洋镇、老新镇三个万亩油菜高产创建示范片，后湖管理区、积玉口镇、浩口镇三个万亩小麦高产创建示范片，熊口管理区、高场办事处、广华办事处、竹根滩镇四个千亩蔬菜标准园创建示范片和熊口镇千亩马铃薯高产创建示范片；其他管理区各办好一个1000-5000亩的小麦高产创建示范片；镇处各办好一个1000-5000亩的油菜高产创建示范片。通过高产创建，带动粮、油、菜大面积平衡增产，全面提升秋冬播作物综合生产能力。

（三）强化技术支撑，提高科技水平。

1.实行秋冬播品种主导制。引导农民正确选用良种，促进秋冬播生产向优质、高产、高效方向发展。继续实行秋冬播品种主导制，油菜主导华油杂13号、华油杂9号、华油杂15号等华油杂、中油杂、中双系列品种；小麦主导襄麦25、鄂麦23等鄂麦系列品种，力争全市秋冬播良种覆盖率达98%以上。

2.重点推广轻简化栽培技术。在西大垸管理区、后湖管理区等地推广小麦机械精量和半精量播种技术；在熊口镇、渔洋镇、老新镇、浩口镇等地扩大油菜免耕直播、翻耕直播、免耕套播等轻简化栽培技术应用规模。力争全市秋冬播轻简化栽培面积达到70万亩。

3.广泛应用高效种植模式。因地制宜抓好菜-稻-菜、稻-薯（菜）、瓜-瓜-菜、棉/麦‖菜、豆-菜等高效种植模式的推广应用，力争应用面积超过25万亩；充分利用冬闲田和低洼地，大力发展虾稻共生模式，力争面积达到22万亩。

4.推广标准化生产技术。加强标准化生产示范基地建设，大力推广无公害、标准化生产技术，引导农民选用安全、高效、低残留农药，确保农产品质量安全。力争小麦、马铃薯、油菜、蔬菜无公害标准化技术应用面积分别达到30万亩、2万亩、40万亩、10万亩。

5.全面应用测土配方施肥技术。扩大测土配方施肥应用范围，全市秋冬播作物测土配方施肥面积达到105万亩，小麦、油菜实现测土配方施肥全覆盖，肥料利用率提高3-5个百分点。免费为全市所有农户提供测土配方技术服务，测土施肥示范片镇级覆盖率达100%，技术信息上墙村级覆盖率达100%。

6.推进农机农艺融合。积极组织农机专业化队伍投入秋冬播生产，加快机收、机耕、机整、机播进度，大力推广小麦机械条播技术，示范油菜机播、机收技术，着力解决播种和收获期间生产季节紧、劳动强度大、人工成本高的问题。重点加强机械收割、秸秆还田、精量直播等技术培训，提高农机手的作业水平。力争今年秋冬播机耕面积超过85%、机播面积超过40%。

7.发展畜禽标准化养殖。积极引导龙头企业和养殖户发展生猪“150”、蛋鸡“153”、肉牛“165”、肉禽“156”等标准化养殖模式。推广良种繁育、科学配方、冻精配种、粪污生态治理等技术。全市优良品种覆盖率达到90%、养殖设施化达到70%以上、标准化养殖比例达到70%、粪污生态治理达到80%以上，实现畜禽产品的优质、高产、高效、安全。

8.普及水产生态健康养殖。科学引导养殖户对老化鱼池实施规模化、标准化、生态化建设和改造，积极推广纳米微孔增氧、水质在线监测、病害远程诊断系统等设备，实行养殖废水集中净化处理和无害化排放，推动高效、生态健康养殖方式普及推广，提高养殖水面效益。力争今冬全市老化鱼池改造2万亩以上。

9.切实加强防灾减灾。牢固树立防灾、抗灾、减灾意识，高度重视灾害性气候对秋冬农业生产的影响，把握秋冬农业生产的主动权。小麦抓好适期播种，力争一播全苗、壮苗越冬；油菜抓好适期早育苗，适量育好预备苗，推广以播代育；蔬菜抓好清园消毒、杀灭虫卵、防冻护苗工作。秋冬播作物播栽结束后，迅速抓好沟厢升级。病虫草害综合防治重点抓好小麦药剂拌种，突出抓好油菜蚜虫、菌核病和小麦锈病、赤霉病等病虫害的防治；两夏化学除草面积达100%，小麦药剂拌种面积达90%以上，油菜菌核病为害损失控制在3%以内，小麦“三病”为害损失控制在5%以内；切实抓好畜禽疫病秋季防疫，重点抓好禽流感、口蹄疫等重大疫病防控，确保不发生区域性重大动物疫情和重大食品安全事故。

（四）抓好资源配置，转变经营方式。

1.积极引导土地流转。在完善土地承包关系的前提下，引导农民依法、自愿、有偿、有序地流转土地承包经营权，培育一批农业生产经营大户和专业合作社，推动全市规模化特色农业基地建设。力争今年秋冬通过土地流转实现千亩连片种植和规模以上养殖基地达10个以上。

2.大力扶持中介服务组织。大力发展专业协会、专业合作社等农民专业合作组织，建立一批种养殖专业合作社、农机服务合作社、病虫专业化统防统治合作社。扶持专业合作组织广泛参与农业产前、产中、产后服务，服务农业生产经营全过程。

3.大力发挥龙头企业的引领作用。积极发挥同光面粉、巨源油业、湖北瑞旭、绿亿园食品、湖北原野、莱克水产、华山水产、湖北南泥湾、明强禽业、海天牧业等龙头企业在秋冬农业生产中的引导作用，通过自办或领办专业化生产基地，带动主导产业和特色产业发展，促进农产品种植、养殖、加工、流通的良性发展，提高农产品附加值，更好地服务现代农业建设。

（五）加强组织领导，强化服务指导。

1.强化领导责任。各地、各相关部门要高度重视秋冬播生产，坚持主要领导亲自抓、分管领导具体抓、工作专班负责抓，一级抓一级，层层抓落实。要落实好各项强农惠农政策，确保落实政策不走样，给农民的实惠不缩水，发挥政策激励作用，充分调动农民生产积极性。

2.强化服务指导。各地、各相关部门要切实转变工作作风，深入基层，开展调查研究，办好示范，帮助农民排忧解难，全力推进秋冬播生产。农业部门要组织实施好种子、肥料、饲料、农药、兽（渔）药等主要生产资料公告制度，引导农民科学选用优质农资，搞好种子种苗的调剂供应，抓好技术培训，办好示范样板；农业、工商、质监等部门要密切配合，集中开展种子、种苗、肥料、农药、饲料、兽（渔）药等农资市场专项整治活动，严厉打击销售假冒伪劣农资行为，防止坑农事件发生，保证农业生产安全，维护农民合法权益；发改、水务、电力等部门要保证秋冬农业生产用油、用水、用电需求；金融部门要多方筹措资金，充分利用小额信贷等行之有效的办法，解决秋冬农业生产所需资金；宣传部门要配合做好农产品市场和价格信息发布工作，采取多种形式加强政策和工作典型宣传，为秋冬农业生产营造良好氛围。

3.强化检查督办。秋冬农业生产期间农业部门要成立督导专班，深入各地进行检查督办，重点检查面积落实、措施落实、基地落实及秋冬农业生产进度与质量等方面的工作。对工作主动、任务完成较好的地方进行通报表扬；对工作不力、出现连片空闲田、完不成各项目标任务的地方予以通报批评。
