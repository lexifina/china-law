# 市人民政府关于明确徐李闸除险加固工程项目法人及法定代表人的通知

各管理区，镇人民政府、办事处，市政府有关部门：

为确保徐李闸除险加固工程顺利实施，根据国家、省有关精神要求，经研究，成立潜江市徐李闸除险加固工程建设项目管理办公室。潜江市徐李闸除险加固工程建设项目管理办公室为该工程的项目法人，项目法定代表人为鲁家祥同志。项目法人是项目建设的责任主体，对项目建设的工程质量、工程进度、资金管理和生产安全负总责。

潜江市人民政府办公室

二○一二年八月六日
