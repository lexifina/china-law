# 市人民政府关于禁止在总口华中家具产业园规划区内非法抢建抢栽抢挖的通告

为确保总口华中家具产业园建设顺利进行，根据《中华人民共和国城乡规划法》、《中华人民共和国土地管理法》等法律法规的规定，现就禁止在总口华中家具产业园区范围内非法抢建建筑物，抢栽林木、果苗，抢挖鱼塘等事宜通告如下：

一、禁止范围：东起247省道复线，西至百里长渠，南起总口农场南二渠（八支渠），北至沪蓉高速公路（集镇规划区除外）。

二、禁止内容：未经规划、国土、建设等有关部门批准，抢建建筑物，抢栽林木、果苗，抢挖鱼塘等。

三、具体事宜

（一）在规划区内，未经有关部门按法定程序批准，抢建建筑，抢栽林木、果苗，抢挖鱼塘的，自本通告发布之日起15日内一律无条件自行拆除和清除，并恢复土地原貌。对拒不执行的，市政府将责成有关部门依法实施无补偿强制拆除和清除。

（二）总口华中家具产业园应切实履行职责，积极配合规划、国土、建设等相关部门共同做好总口华中家具产业园的控管工作。

（三）广大人民群众要积极向有关部门、总口华中家具产业园举报非法抢建、抢栽、抢挖行为；要自觉服从市政府关于总口华中家具产业园的规划管理，以实际行动支持总口华中家具产业园建设。

（四）对阻挠国家公务人员执行公务的，将依法追究其法律责任。

（五）本通告自发布之日起实施。
