# 关于认真做好《潜江市2011年统计年鉴》编辑出版工作的通知

各管理区，镇人民政府、办事处，市政府各部门：

《潜江市2011年统计年鉴》是一部综合、全面、准确反映我市2011年经济社会发展情况的权威性工具书，为做好编辑出版工作，现就有关事项通知如下：

一、充分认识年鉴编纂工作的意义

《潜江市2011年统计年鉴》是一部全面、系统反映全市经济社会发展的综合性资料，具有覆盖面广、信息量大、数据翔实、权威性强等特点，已成为全市各地、各部门及社会各界研究、了解潜江必不可少的信息资源，为对外宣传潜江发挥了积极作用。《潜江市2011年统计年鉴》按期编辑出版，是全市统计工作的重要组成部分，各地、各部门要进一步提高认识，加强组织领导，积极支持配合，共同做好编辑出版工作。

二、认真做好资料报送工作

《潜江市2011年统计年鉴》共分图片、文字和数据三大部分，将以不同的形式，从不同的角度对潜江市2011年经济社会发展全貌进行真实记录和客观反映。各地、各部门要以实事求是的态度，紧紧围绕市委、市政府中心工作和各级领导、社会公众关注的热点、难点问题，认真做好统计资料的收集、整理和编辑工作，及时提供真实、准确、高质量的统计资料及文稿；要按照“数据准确、体系科学、出版及时、使用方便、装帧美观、管理规范”的要求，合理设计统计指标体系，加强资料审核把关，提高统计资料质量。所有文稿及图片资料要在4月30日前上报市统计局综合科（联系电话：6232915），确保《潜江市2011年统计年鉴》在5月底以前出版发行。

三、切实加强组织领导

《潜江市2011年统计年鉴》内容多、涉及面广、质量要求高，各地、各部门要高度重视，加强组织领导，明确专班或专人做好资料的组稿和报送工作。市统计局作为具体承办部门，要加强组织领导，搞好协调，全力以赴做好各项工作，确保编辑质量。
