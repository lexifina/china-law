# 关于成立潜江市高新技术产业园的通知

各管理区，镇人民政府、办事处，市政府各部门：

杨市工业园是我市重点打造的以发展高新技术产业为主导方向的新型工业园，为充分利用其区位优势、产业优势，发挥高新技术对产业发展的带动作用，经市政府研究同意，在杨市工业园建设潜江市高新技术产业园。现将有关事项通知如下：

一、指导思想

以科技创新和体制创新为动力，以市场为导向，以现代电子信息、新材料、新能源、现代生物医药、现代食品加工、现代纺织服装等产业为重点，发挥政府在产业导向和管理服务等方面的作用，加快高新技术产业化的进程，促进全市产业结构调整和转型升级。

二、高新技术产业园的规划选址

潜江市高新技术产业园总占地面积23.25平方公里，北起宜黄高速公路，南抵总口二支渠，西至百里长渠，东起潜监公路复线。

三、高新技术产业园的组织机构

潜江市高新技术产业园建设于杨市工业园，与杨市工业园两块牌子一套班子运作，根据实际情况适当增设管理机构及人员编制。

四、加快高新技术产业园建设

（一）杨市工业园管委会要迅速制定高新技术产业发展规划，扎实推进实施。要进一步加大招商引资力度，改造、提升传统产业，建立以高新技术产业为主体的多元化投入体系，完善技术创新体系，建设与高新技术产业快速发展相适应的高素质人才队伍，促进高新技术产业又好又快发展。充分发挥高新技术产业园的辐射带动作用，引导全市高新技术企业在高新技术产业园集中、集约发展。

（二）高新技术产业园是实施市委、市政府“勇争全国百强、建设幸福潜江”战略的重要载体，也是实施“工业强市”和资源枯竭型城市转型发展的重要抓手。各有关单位要从项目资金、技术服务、人才等方面给予大力支持，促进潜江市高新技术产业园快速发展，使之成为带动全市新兴产业发展的龙头。
