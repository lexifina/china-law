# 关于成立潜江市体育彩票工作领导小组的通知

各管理区，镇人民政府、办事处，市政府各部门：

根据工作需要，市政府决定成立“潜江市体育彩票工作领导小组”，现将组成人员名单通知如下：

组 长：王玉梅 副市长

副组长：陈 华 市政府副秘书长

成 员：郑学国 市文化旅游局局长

何安然 市财政局总经济师

秦绪文 市公安局副政委

龚义海 市城管局副局长

曾 平 市工商局副局长

刘雄伟 市地税局副局长

孙同福 市广电局副局长

张志诚 市文化旅游局副局长

领导小组下设办公室，办公室设在市体育局,郑学国同志兼任办公室主任。

二○一二年六月五日
