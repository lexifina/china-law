# 关于2011年度全市造林绿化情况的通报

各管理区，镇人民政府、办事处，市政府各部门：

2011年，各地、各有关单位按照与市人民政府签订的造林绿化责任状要求，精心组织，认真实施，圆满地完成了全市林业生产任务。经验收统计，全市共完成人工造林40141亩，其中完成重点工程造林12600亩；发展苗木和花卉苗圃17010亩；蛀干害虫有虫株率为8.3%；杨树造林良种使用率为100%。

根据责任状评分标准，各责任单位2011年度造林绿化工作的具体评分为：老新镇101.7分, 龙湾镇101.7分，积玉口镇101.7分, 张金镇101.3分，浩口镇101.3分，渔洋镇101.2分，运粮湖管理区101.1分，西大垸管理区101分，汉江河道管理局潜江东荆河分局100.7分，后湖管理区100.6分, 杨市办事处100.6分, 高石碑镇100.3分,王场镇100.3分， 熊口镇100分, 潜江经济开发区100分，周矶办事处100分, 周矶管理区99.9分,园林办事处99.9分, 熊口管理区99.8分，竹根滩镇99.8分，汉江河道管理局潜江汉江分局99.6分，四湖管理局99.6分，总口管理区99.5分，高场办事处99.4分。

按照造林绿化责任状考评标准，评定老新镇、龙湾镇、积玉口镇获得一等奖，授予“2011年度造林绿化红旗单位”称号；张金镇、浩口镇、渔洋镇、运粮湖管理区、西大垸管理区获得二等奖；汉江河道管理局潜江东荆河分局、后湖管理区、杨市办事处、高石碑镇、王场镇获得三等奖。同时授予获得二等奖、三等奖的单位“2011年度造林绿化先进单位”称号。

希望各地、各单位发扬成绩，在今后的植树造林工作中加强领导，精心组织，再接再厉，再创佳绩，为全市林业生产作出新贡献。

二○一二年一月三十日
