# 市人民政府办公室关于2012年度全市造林绿化情况的通报

各区、镇、办事处，市政府各部门：

2012年，各地、各有关部门按照与市人民政府签订的造林绿化责任状要求，精心组织，认真实施，圆满地完成了全市林业生产任务。经验收统计，全市共完成人工造林38115亩，其中完成重点工程造林24100亩，重点工程造林综合完成率达到100%;发展苗木和花卉苗圃19000亩;杨树蛀干害虫有虫株率为9.1%;林业有害生物成灾率控制在3.6‰;造林苗木良种使用率为100%。

根据造林绿化责任状具体内容和评分标准，经严格、公正的检查考评，各责任单位评分结果为：积玉口镇101.4分，王场镇101.4分，浩口镇101.4分，老新镇99.9分, 龙湾镇99.9分，运粮湖管理区99.7分，高石碑镇99.7分, 泰丰办事处99.4分，渔洋镇99.1分，张金镇99分，熊口镇98.8分, 园林办事处98.8分, 熊口管理区98.6分，白鹭湖管理区98.6分，周矶办事处98.3分, 总口管理区98.1分，汉江管理分局98分，东荆河管理分局98分，后湖管理区98分,杨市办事处97.8分, 四湖管理局97.4分，广华办事处97分，周矶管理区96.5分,竹根滩镇95.9分，潜江经济开发区95.5分，高场办事处77分。按照考评结果，评定积玉口镇、王场镇、浩口镇为红旗单位，授予“2012年度造林绿化红旗单位”称号;老新镇、龙湾镇、运粮湖管理区、高石碑镇、泰丰办事处为先进单位，授予“2012年度造林绿化先进单位”称号;渔洋镇、张金镇、熊口镇、园林办事处、熊口管理区、白鹭湖管理区、周矶办事处、 总口管理区、汉江管理分局、东荆河管理分局、后湖管理区、杨市办事处、四湖管理局、广华办事处、周矶管理区、竹根滩镇、潜江经济开发区为合格单位;高场办事处为不合格单位。

希望各地、各部门发扬成绩，在今后的造林绿化工作中加强领导，再接再厉，再创佳绩，为全市林业生产作出新贡献。

特此通报。

2012年12月13日
