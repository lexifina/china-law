# 市人民政府办公室关于印发《潜江市政府2014年廉政工作要点》的通知

各区、镇、办事处，市政府有关部门：

《潜江市政府2014年廉政工作要点》已经市人民政府同意，现印发给你们，请遵照执行。

2014年3月24日

潜江市政府2014年廉政工作要点

为深入贯彻落实国务院、省政府第二次廉政工作会议精神，扎实推进政府廉政建设和反腐败工作，特制定如下工作要点：

一、指导思想

以邓小平理论、“三个代表”重要思想和科学发展观为指导，认真贯彻落实党的十八大、十八届三中全会精神，紧紧围绕国务院、省政府第二次廉政工作会议重要工作安排部署，坚持转变工作作风，严格执行中央“八项规定”、“约法三章”和省委“六条意见”，不断健全规范权力运行机制，强化行政效能监察，着力解决损害群众利益的突出问题，加快推进惩治和预防腐败体系建设，为市域经济快速发展提供坚实保障。

二、主要任务

（一）严格落实政府系统党风廉政建设责任制。

按照“谁主管谁负责”的原则，政府系统的党风廉政建设实行行政主要负责人负总责，分管负责人承担分管责任，一级抓一级，层层抓落实。根据《中共潜江市委关于市委常委、市政府党员副市长落实党风廉政建设责任制的实施意见》（潜文〔2005〕23号）精神，明确工作职责，加强责任考核，严格责任追究。

（二）进一步转变工作作风、狠刹“四风”。

1.严格执行中央“八项规定”、“约法三章”和省委“六条意见”。进一步加大明察暗访力度，强化日常监管，建立长效机制，对违反规定的问题，发现一起，查处一起，曝光一起。

2.严控“三公经费”和“机构编制”。严格落实“三公经费只降不升”的要求，健全完善公务接待、公车管理、公务出国境管理制度，精简会议项目，压缩会务支出，严肃查处公款同城接待、超标准接待、娱乐场所高消费等问题。严格人员编制管理，对公务员招录、事业单位人员新进严格把关，坚决落实“财政编制只减不增”的要求。

3.继续开展治庸问责活动，坚决刹住“四风”。对政府部门工作人员作风不实、行政效率不高、“吃拿卡要”等群众反映突出问题要集中惩处；对上班迟到早退和上班期间吃早餐、上网玩游戏、聚餐打麻将等不良习气，必须下大力进行整治，坚决维护纪律的严肃性。

（三）进一步深化政务公开，强化政务服务。

1.进一步抓好简政放权。在2013年全市第七轮行政审批事项清理的基础上，进一步精减和调整行政审批事项，最大限度地减少行政许可和非行政许可审批，精减审批事项、减少审批环节、压缩审批时限、优化审批程序、规范收费行为、提升服务质量。对行政审批事项的精减，审批前置事项的设立，严格落实好“法无授予不可行”的要求，最大限度减少审批事项和环节，同步减少和规范前置审批。积极主动做好国务院、省政府下放的行政审批事项对口衔接。

2.进一步规范政务服务中心运行。各部门要严格按照“应进必进”、“三集中”、“三到位”要求，成立行政审批科（室），充分授权，明确“首席代表”， 选派业务精通的骨干进驻市政务服务中心窗口服务。各地要积极筹措资金，因地制宜抓好本地便民服务大厅建设。

3.进一步深化政务公开。严格落实政务、事务、村务、厂务公开制度，进一步扩展公开范围、明确公开内容、强化公开时效，特别是对与群众根本利益联系紧密的问题、群众迫切需要了解的问题、群众反映比较突出的问题，一定要做到及时、全面、准确地公开，保障群众的知情权、参与权和监督权。要继续抓好对部门财政预决算、三公经费支出、重大建设项目和社会公益事业经费开支、农村强农惠农资金使用管理等信息的公示公开，防止权力滥用和暗箱操作。

（四）进一步强化反腐倡廉基础制度建设。

1.完善行政决策机制，增强公共政策制定透明度和公众参与度。

2.完善行政监督机制，健全重大项目和民生工程领导分工责任制和跟踪监督制度。

3.完善财务管理制度，切实强化预算管理，严格控制预算事项和支出调整，继续推进国库集中支付制度和公务员公务消费卡制度改革，形成有利于监督的制约机制。

4.推进公共资源交易市场建设。创新开评标方式，将现有的资格预审更改为资格后审，同步实施网上报名，有效解决围标、串标问题，确保交易公正。加强标后监管，借助行政监察手段，规范公共资源交易各方当事人交易活动的行为，强化责任追究。

5.规范政府集中采购。严格执行政府采购预算制度，进一步健全完善网上报价采购、定点采购、询价采购等相关管理制度和办法，严肃查处规避政府采购进行大额物资购置的问题。

6.建立健全不动产统一登记制度，清理规范专项转移支付资金。对所有公共资金、国有资产、国有资源实行审计监督全覆盖。

（五）进一步加大行政执法纠风力度。

1.开展教育乱收费专项治理。规范幼儿教育、义务教育阶段收费管理，严肃查处教师业余辅导补课、指定课外作业售购点、摊派学习资料费及营养费等各类乱收费问题。

2.开展医疗领域专项治理。健全完善农村合作医疗保险报销程序，规范村级卫生室运行管理；开展医保定点药店违规出售与药品无关商品问题专项清理，确保医保专项资金合理有效运行；继续抓好医药购销和医疗服务中的不正之风专项整治，严肃查处药品耗材违规加价、医疗服务超标准超范围收费、重复收取住院病人诊查费护理费床位费等问题，严肃查处收取医药商药品回扣、病人红包礼金的行为。

3.继续治理涉农负担中的突出问题。严肃查处涉农乱收费、集资摊派以及哄抬农资价格、制售假劣农资坑害农民和进城务工人员合法权益等问题。

4.规范行业协会、市场中介组织、公共服务行业的服务和收费行为，严厉查处以各类名义乱收费以及只收费不服务的行为。

5.继续开展“电视问政”活动。建立健全民主评议、政风行风热线、新闻媒介相结合的政风行风建设监督体系，严肃查处行政不作为、慢作为、乱作为和失职渎职的问题。

（六）进一步加大违法违纪案件查处力度。

对腐败分子和消极腐败现象要严厉惩处整治，严肃查处发生在领导机关和领导干部中的贪污贿赂、徇私舞弊、腐化堕落、失职渎职案件；严肃查处发生在民生、经济发展环境、工程建设及招投标领域，国家专项资金等重点领域和重点环节的腐败案件；严肃查处侵害群众利益案件、群体性事件和重大责任事故背后的腐败案件。要更加重视来信来访，健全网络举报和受理机制，凡是有群众举报的，都必须及时受理，凡是有具体线索的，都要认真核实，凡是违反党纪国法的，都要严肃处理。

三、工作要求

（一）增强责任意识。各地、各部门领导干部，特别是主要领导干部要进一步认识到反腐败是关系党和国家生死存亡的大事，一定要在廉政方面作出表率，以身作则，严于律己。

（二）切实履行职责。各地、各部门要明确工作职责和任务，落实工作考核和责任追究制度。监察机关要认真履行职责，加强组织协调，加大监督和查处力度。各纠风执法专项牵头单位和源头治腐牵头单位要严格按照责任分工，结合自身工作实际制定相应的工作方案和工作措施，认真抓好落实。

（三）强化监督检查。要通过各类专项监督检查，及时发现和解决反腐倡廉工作中的问题，通过总结经验，巩固成果，分析问题，查找原因，研究对策，促进政府廉政工作落到实处。
