# 市人民政府关于授予湖北巨源油业有限公司等241家企业为2012-2013年度潜江市“守合同重信用”企业称号的通报

各区、镇、办事处，市政府各部门：

近年来，各地按照市委、市政府关于加强“信用潜江”建设的要求，统一部署，精心组织，扎实工作，全市市场经济秩序进一步得到规范，市场主体的信用意识不断加强，涌现出了一批诚实守信的先进单位。经过评审，市人民政府决定授予湖北巨源油业有限公司等241家企业为2012-2013年度潜江市“守合同重信用”企业称号，并予通报表彰。

希望获得荣誉称号的企业发扬成绩，再接再厉，进一步提高自身的管理水平和信用意识，充分发挥示范带头作用。全市广大企业要以“守合同重信用”企业为榜样，依法经营，诚实守信，不断优化我市经济发展环境，进一步推动“信用潜江”建设，促进全市经济又好又快发展。

附件：潜江市2012-2013年度“守合同重信用”企业名单
