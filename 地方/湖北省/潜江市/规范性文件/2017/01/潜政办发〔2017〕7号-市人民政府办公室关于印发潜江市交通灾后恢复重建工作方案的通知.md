# 市人民政府办公室关于印发潜江市交通灾后恢复重建工作方案的通知

各区、镇、办事处，市政府有关部门：

《潜江市交通灾后恢复重建工作方案》已经市政府研究同意，现印发给你们，请认真组织实施。

2017年1月20日

潜江市交通灾后恢复重建工作方案

自2016年6月中旬以来，我市连续遭遇六轮特大暴雨袭击，致使全市多条国省干线、县乡公路、通村公路及桥梁损毁惨重，群众出行受到严重影响。据初步统计，全市道路路基损坏126.69万立方米，路面损毁195.52万平方米，桥涵损坏35座；港口、航道、客运招呼站等交通基础设施损坏68处，直接经济损失达3.5亿元。灾情发生后，市委、市政府迅速启动应急预案，按照“分级负责、先通后畅”的总体要求，全市上下迅速开展抢险救灾和灾后重建工作。为确保交通灾后重建工作顺利进行，尽快恢复我市公路通行能力，保证人民群众出行顺利，特制定本方案。

一、指导思想

以党的十八大和十八届三中、四中、五中、六中全会精神为指导，认真贯彻落实省、市关于抗灾救灾和灾后重建工作的指导意见，按照“保障民生、交通先行”的总要求，把交通抗灾救灾和灾后重建作为全市当前和今后一个时期的中心工作，遵照“政府主导、分级负责，先通后畅、分步实施，突出重点、部门联动，提档达标、科学重建”的总体原则，结合全市“十三五”发展规划和精准扶贫工作要求，统筹安排、超前谋划，立足应急、着眼长远，科学设计、分步实施，充分调动各方力量，统筹整合各种资源，全力开展交通灾后重建工作，奋力夺取交通抗灾救灾和灾后重建工作的全面胜利。

二、基本原则

（一）政府主导、分级负责原则。国、省干线公路及列养县道水毁修复重建责任主体是市交通运输局，并负责组织项目实施；农村公路水毁修复重建责任主体是各区镇处，由各区镇处负责组织实施。国省干线公路水毁修复重建资金主要争取上级交通主管部门补助解决；农村公路主干线公路的水毁路面、桥梁、涵洞、挡土墙和通村公路的水毁桥梁修复重建以各区镇处开展生产自救为主。市政府统筹整合发改、水务、国土、财政、移民等项目资金用于国省干线沿线重点整治的河道、地质灾害点和农村公路水毁修复重建。

（二）先通后畅、分步实施原则。坚持以人为本，把保障民生放在优先位置。坚持先通后畅、先主后次，突出重点、分步实施，做到全面恢复重建与发展相结合。首先保证国省干线、县道、重点农村干线公路以及重要通道的恢复通车，其他水毁道路的修复重建应制订恢复完成时间表，建立管理台账，确保公路水毁修复重建方案按计划、按要求全面实施。

（三）突出重点、部门联动原则。各有关部门之间要加强协调配合，统筹规划、整合力量、加大投入，加快推进我市公路水毁设施修复重建，全面提升公路通畅水平。全市公路涉及到水务、国土、财政、移民等相关部门及各区镇处在公路沿线河道设置挡水坝(堰)、顺坝、水渠等构造物，影响道路防洪能力并易造成公路水毁的，按照“谁建设、谁恢复”原则，相关单位承担相应的水毁工程修复重建的主体责任。

1.水务、国土、财政等相关部门及各区镇处在公路路堤沿线河道设置挡水坝、导流设施、水渠、节制闸等构造物，影响并易造成公路水毁的，以各相关部门及区镇处为责任主体制订综合整治方案。综合整治方案和设计图纸应提交到交通部门评审后组织实施。

2.对此次洪灾后反映出来的道路沿线河道行洪能力不足，易造成公路水毁的河段，由水务部门制定整治方案并负责项目整治和实施，以切实提高河道的行洪能力。

3.按《公路法》等相关法规的规定，加强道路沿线河道挖矿、采砂等作业的管理，河道挖矿、采砂等作业不得危害到道路安全。国省干线公路距路基边坡坡脚20米、其他公路l0米范围内，任何单位和个人不得进行河道挖矿、采砂等施工作业。由水务部门负责落实，交通部门加强监督。

4．道路沿线涉及到地质灾害的，由国土、交通部门联合调查，制订科学的整治方案并联合组织实施，确保道路通行安全。

（四）提档达标、科学重建的原则。认真汲取教训，深刻进行灾后反思，尊重自然、尊重规律，按照“应急与长远相结合、恢复与重建相结合、达标与提档相结合”的方针，着力提高交通设施抗汛抗灾能力，确保灾后重建工程质量和标准达到一个新的水平。水毁工程修复重建前应对水毁路段进行彻底调查，判定水毁的成因，科学制订整治方案。对重点水毁路段的桥涵、护坡、导流设施、排水设施及河道行洪能力应在科学计算评估基础上，适当加大排水通道的结构尺寸，提高行洪能力；对易发地质灾害的路段，进行有效的防灾整治；对水毁多发、易发的重点路段的路基、桥涵及附属工程设施适当提高防洪标准。

三、目标任务

（一）工作目标。

国省干线：2017年3月底前，完成除大型桥梁及大型滑坡体整治以外的重建任务。2017年6月底前，补齐国省干线公路短板，完成国省干线全部重建任务，确保全市国省干线恢复重建路段的路容路貌、通行能力、抗灾能力及服务水平明显提升，为实现“十三五”国检赶超进位打好基础。

农村公路：2017年3月底前，以通达为目标修复重建中断路段，以安全为目标恢复重建通客车路段，完成除大型桥梁以外的恢复重建任务及中型泵站、涵闸等水务设施防汛通道的恢复重建。2017年12月底前，完成全部恢复重建任务，确保农村公路通行服务能力基本恢复到灾前水平。按照“四好农村路”的要求，全面提升区镇处经济干线、精准扶贫产业路的通行服务保障能力。

（二）工作任务。

1.重建方案的编制。国省干线、列养县道水毁修复重建方案由市交通运输局按要求编制和实施。农村乡村公路修复重建方案由市交通运输局协助区镇处制订，长度5米以上桥梁、高度大于5米的驳岸、挡土墙由具有相应设计资质的设计单位设计；其余由各区镇处组织交通、水务或住建等相关单位有经验的技术人员自行制定。

2.重建项目的实施。按职责分工和分级负责的原则组织项目实施。各地各有关部门确保一般水毁路段一个月左右的时间完成修复重建，重点水毁路段及桥梁半年内完成修复重建，全面恢复公路原有通行能力，达到灾前通行水平，保证人民群众和车辆的安全、顺利出行。

3.重建项目的管理。

（1）项目法人。国省干线和列养县道的水毁修复重建工程的项目法人为市公路局；农村乡村主干线和通村公路水毁修复重建工程的项目法人为各区镇处。各区镇处主要负责人为水毁修复重建工程项目的具体责任人，具体负责辖区内水毁修复重建工程的实施和质量管理。

（2）工程招投标。按照《市人民政府办公室关于建立绿色通道加快灾后恢复重建项目建设的实施方案》，优化招投标流程，简化招投标程序，缩短审查期限。对因灾受损的交通主干道、通村公路、桥梁以及其他应急度汛项目，如不及时维修改造将对生产生活造成重大影响的，按照招标投标法等法律法规规定，可不进行招标。对不招标项目应由项目业主单位提出书面申请，相关行业主管部门和招投标主管部门共同审核。

（3）工程监理。国省干线和农村主干线公路的水毁路面、桥梁、涵洞、挡土墙及村组桥梁等修复重建工程应严格执行工程建设监理制度，其监理单位和监理人员的选择必须符合相关规定。村组公路其他水毁修复重建工程项目，由各区镇处组织交通、水务或住建等相关单位有经验的技术人员进行技术指导。公路水毁项目的修复均应有详细施工记录。

（4）工程质量监管。国省干线公路的水毁修复重建工程的质量监管由市交通运输局负责；农村公路水毁工程的修复重建质量监管由各区镇处负责，并接受市交通部门和相关单位的监督和检查。市交通部门应组织专门力量进行日常巡查，对巡查中发现的问题责令整改，情节严重的将进行通报。

（5）工程变更。水毁修复重建工程必须严格按照确定的修复方案和设计施工图纸施工，不得擅自变更修复方案和设计施工图纸。国省干线和县道水毁修复重建项目的方案和设计图纸确需变更的，按照相关规定执行。农村公路水毁修复重建项目方案和设计图纸确需变更的，由各区镇处提出申请，并委托原制订修复方案的设计单位重新确定方案，报市交通运输局审查备案后方能实施。严禁擅自修改方案和图纸，未经审批擅自变更修复重建方案和设计施工图纸的将不予验收。

（6）项目验收。国省干线公路的水毁修复重建工程项目竣工后由市交通运输局组织验收；农村公路水毁路面、桥梁、涵洞、挡土墙以及水毁桥梁项目竣工后由各区镇处向市交通运输局提出申请，市交通运输局会同财政、区镇处、监理单位、施工单位等相关人员进行验收并出具工程验收单。水务、国土等相关部门负责的道路沿线构造物水毁修复重建项目完工后，应邀请交通部门派人参加竣工验收，并提供项目竣工图纸。水毁修复重建工程验收时施工单位应提供施工合同、水毁工程修复重建方案、施工图纸、施工原始记录、工程质量检测报告等相关资料。

（三）资金使用和管理。

1.国省干线、列养县道水毁修复重建资金由市财政拨付到市公路局，由市公路局统筹安排使用。市政府补助的农村公路路面、桥梁、涵洞和挡土墙以及通组桥梁水毁修复重建资金，由市财政局会同市交通部门按项目直接拨付到项目实施单位，各区镇处负责监督管理。

2.发改、水务、国土、财政、移民等相关部门整合用于交通公路水毁修复重建的资金，由各相关责任单位从项目资金中调剂并监督使用。

3．市政府安排的水毁修复重建补助资金按照计划安排分期拨付。水毁修复重建工程计划下达后，先预拨部分资金，剩余资金待项目完工后经验收合格拨付，验收不合格的工程不拨付工程款。

4.各地各相关部门要应用好、管好水毁修复重建补助资金，水毁修复重建资金应当严格管理、专款专用，任何单位和个人不得侵占、挪用和截留。同时，要应积极筹措资金，为公路水毁修复重建工程作好资金保障。水毁修复重建工程完成后市财政、审计部门应对资金使用情况进行审计。

四、组织保障

（一）加强组织领导。成立市交通灾后恢复重建指挥部，由市政府分管领导任指挥长，市直相关部门和各区镇处主要负责人为成员。领导小组下设办公室，办公室设在市交通运输局。各区镇处要成立相应的组织机构，具体负责辖区内的交通基础设施灾后恢复重建工作。

（二）建立考核机制。市交通灾后恢复重建指挥部对交通灾后恢复重建工作实行月检查，各地各有关部门应抓好水毁修复重建工作的具体落实。

（三）实行责任追究。交通灾后恢复重建工程是重要的民生工程，涉及到群众的切身利益，必须确保工程质量，保证资金合理有效使用。各地各有关部门必须加强施工过程的管理，切实落实各自的责任。对建设过程中存在履责不力、监管不到位，出现质量和安全事故的单位和个人，将依纪依规追究责任。
