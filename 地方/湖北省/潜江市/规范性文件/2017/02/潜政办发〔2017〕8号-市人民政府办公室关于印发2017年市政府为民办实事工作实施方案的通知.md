# 市人民政府办公室关于印发2017年市政府为民办实事工作实施方案的通知

各区、镇、办事处，市政府有关部门：

《2017年市政府为民办实事工作实施方案》已经市人民政府同意，现印发给你们，请认真组织实施。

2017年2月9日

2017年市政府为民办实事工作实施方案

为指导和推动2017年市政府为民办实事工作的顺利开展，确保为民办实事项目的全面完成，特制定本实施方案。

一、工作任务

（一）筹资1.8亿元，继续推进精准扶贫工作（完成2.8万人脱贫和22个贫困村出列，全面兑现我市精准扶贫军令状）。

（二）筹资12.28亿元，继续推进保障性安居工程建设（完成垦区危房改造3879户，城市棚户区改造1500户，潜江经济开发区棚户区改造640户）。

（三）筹资3.53亿元，加快工业园区和集镇污水处理厂建设（重点推进潜江经济开发区工业污水处理厂一期和潜江市南部园区污水处理厂建设，启动城北生活污水处理厂提档升级和集镇污水处理厂建设）。

（四）筹资1.27亿元，开展城区黑臭水体综合整治工程建设（完成南门河1号湖驳岸加高及南门河1、2、3号湖清淤工程；完成一支渠、二支渠、五支渠黑臭水体综合整治工程）。

（五）筹资9500万元，开展城乡环境卫生综合整治工程建设（新建城乡垃圾中转站14座，改建城乡垃圾中转站3座，升级改造杨市垃圾处理场；新增、改建城区公厕15座；购置环卫机械设备60台套；推行城乡垃圾收运一体化，对各地村组保洁员实行补贴等)。

（六）筹资1.285亿元，推进民生交通工程（建设通村公路100公里，改造县乡公路100公里，改造农村公路危桥10座）。

（七）筹资1.4亿元，继续开展“绿满潜江”建设（完成人工造林3万亩，推进园林绿化提档升级，重点开展园区“绿色生态长廊”建设）。

（八）筹资7600万元，推进创业带动就业（扶持新增创业3000人，带动就业7000人）。

（九）筹资4340万元，实施“健康潜江”工程，提升市民健康素养（实施基本公共卫生服务，推行“医防结合”、“责任医生签约服务”模式，为0—6岁儿童、孕产妇、65岁以上老人等六类重点人群提供“三个一”服务，即一人一份健康卡、一人一名健康服务签约医生、一人一个健康服务免费包）。

（十）筹资2581万元，开展文化体育惠民活动（包括送戏下乡100场、送图书30000册、“两馆一站”免费开放、补助农村文化基础设施维护和开展文化活动、市民体育中心向社会运营开放、配送体育健身器材、农民健身工程、文体广场建设、送电影下乡活动）。

（十一）筹资1.8亿元，开展农村电网改造升级工程。

（十二）筹资1278万元，实施残疾人民生保障工程（发放困难残疾人生活补贴、重度残疾人护理补贴，实施0-6岁残疾儿童抢救性康复训练工程）。

（十三）筹资8000万元，改善义务教育学校办学条件（新建泰丰中学，新建、维修教学及辅助用房3万余平方米和食堂、宿舍等生活用房1万余平方米；推进教育信息化试点工作，提高教育信息化发展水平，添置教育教学及生活设施设备等）。

（十四）筹资8700万元，改造城区背街小巷和老旧小区（进一步完善园林办事处、泰丰办事处背街小巷道路、排水设施改造，完成背街小巷及老旧小区改造项目30个）。

（十五）筹资1340万元，打造食品安全放心市（包括放心蔬菜、放心肉工程、开展农产品质量安全追溯体系建设、食品生产加工小作坊提档升级，“放心粮油”市场体系建设与管理）。

二、工作机制

（一）健全协调配合机制。实行市政府分管副市长领办制，一事一案，当年办结。市政府办公室负责为民办实事工作的组织、协调、督查和考核，市扶贫与移民办等24家牵头单位要切实负起牵头职责，要精心组织，确保落实，其他责任单位要按照工作职责，积极配合，主动参与，与牵头单位一起及时协调处理工作中存在的问题，进一步形成强大的工作合力和良好的工作格局。

（二）完善投入保障机制。各责任单位要统筹谋划、合理安排，多渠道筹集资金，将资金配套到位，在争取上级投入、财政配套的同时，对列入计划预算的资金，一定要确保专款专用、及时兑现。

（三）强化督查考核机制。市政府办公室将对为民办实事项目的进展情况进行定期督查通报，并通过优化考核办法、完善考核程序加大考核力度。为民办实事项目各牵头单位和责任单位要加强阶段性的督促检查，及时发现问题，及时进行整改，确保完成工作任务。

三、工作考核

（一）考核单位：由市政府办公室负责为民办实事考核工作。

（二）考核对象：24家为民办实事责任单位，分别是市扶贫与移民办、市住房局、市农管局、市住建委、市经信委、市水务局、市城管局、市交通运输局、市林业局、市人社局、市卫计委、市文体旅新局、市广电局、市民政局、市教育局、市农业局、市食药监管局、市粮食局、市残联、市城投公司、市供电公司、潜江经济开发区·竹根滩镇、总口管理区、杨市办事处。

（三）考核方法：将为民办实事工作纳入目标管理工作考核，列入各责任单位重点工作或日常工作任务，采取平时检查、季度督查和年末验收相结合的方式，对各责任单位实行量化考核。

四、工作要求

（一）切实加强领导。各责任单位要高度重视，把思想和行动统一到市委、市政府的决策部署上来，统一到坚持以人为本、执政为民的根本宗旨上来，切实增强使命感和责任感，着力为民办实事、解难事、做好事。要建立健全领导责任制，真正把实事办好、好事办实。

（二）落实工作责任。各责任单位要真抓实干，通力合作，在保证工作质量的前提下，提高工作效率和工作水平。各分管副秘书长要及时协调解决为民办实事中存在的问题，及时向分管副市长反馈办理情况，确保各项目标任务的完成。各项实事目标任务必须在12月20日前完成。各责任单位要认真制定项目实施方案，合理分配任务。请各责任单位将具体实施工作方案于2月20日前报送市政府政务督查室。

（三）强化后续管理。各责任单位要切实加强对已完成为民办实事项目的后续管理，落实责任，把对已办实事的后续管理与完成本年度为民办实事任务同部署、同考核。对已办实事项目，要认真组织“回头看”，及时总结推广好的经验和做法。各责任单位要认真研究和完善推进项目后续管理的政策措施，加强对项目后续管理的人员和经费保障。

（四）严格督查考核。坚持自查、核查、督查的督办机制，提高督查督办效率。各责任单位要在每月底向市政府政务督查室报告为民办实事工作进展情况，市政府政务督查室对为民办实事进行重点督办，对进展缓慢、落实不力、未完成工作任务的责任单位进行通报批评和挂牌督办。
