# 市人民政府办公室关于印发潜江市金融助力民营企业发展专项行动方案的通知

各区、镇、办事处，市政府有关部门：

《潜江市金融助力民营企业发展专项行动方案》已经市人民政府同意，现印发给你们，请认真组织实施。

2017年3月23日

潜江市金融助力民营企业发展专项行动方案

为深入贯彻落实《省人民政府办公厅关于构建公平竞争市场环境促进民间投资健康发展的意见》（鄂政办发〔2016〕51号）精神，推动《潜江市支持企业“去杠杆”行动方案》（潜政办发〔2016〕55号）的全面展开，进一步加大对民营企业的支持力度，着力解决民间投资融资难、融资贵问题，拓宽民间融资渠道和方式，制定本行动方案。

一、主要目标

进一步降低企业杠杆率，降低民营企业债券发行门槛。引导金融机构合理确定贷款利率，规范收费行为。充分发挥担保机构的作用，引导更多信贷资金进入民营企业。

二、主要措施

（一）加大对民营企业的信贷投放。针对诚信经营、发展前景好、产品适销对路、财务管理规范，但因资金周转困难导致按时还贷有困难的中小微企业，全面落实省“不断贷、不抽贷、不压贷”的要求，力争年度新增贷款不低于50%用于民营企业，支持企业健康发展。（牵头单位：人行市支行、市银监办，责任单位：市域银行机构）

（二）拓宽政银合作产品覆盖面。进一步加大政银合作力度，提高集合贷、助保贷、助企贷等政银合作产品的覆盖面和企业信贷资金获得感；提高小额贷款保证保险覆盖面，完善政府、银行、保险风险共担机制，为小微民营企业提供增信担保。发挥好“过桥”资金作用。大力发展产业链融资、商业圈融资、企业群融资，积极推动股权、知识产权、排污权、碳排放权、动产、保单等抵质押融资业务。（牵头单位：市金融办，责任单位：人行市支行、市银监办、市工商局、市国土资源局、市经信委、市域银行机构、市保险业协会、市汇桥担保公司）

（三）稳步推进投贷联动。鼓励金融机构在有效监管风险的前提下，创新续贷、循环贷款、知识产权质押融资等流动资金贷款还款方式，降低中小微企业“过桥”融资成本。（牵头单位：人行市支行、市银监办，责任单位：市科技局、市工商局、市经信委、市域银行机构）

（四）规范发展各类股权投资。积极对接省长江经济带产业基金、省级股权投资引导基金以及省级创业投资引导基金，制定引进基金机构优惠政策，引导天使基金、风投基金、创投基金等机构入驻并投资民营中小微企业。充分发挥政府投资基金带动作用，撬动社会资本围绕我市八大产业（石油化工、装备制造、纺织服装、高端家居、大健康、光信息电子、生物医药、新能源新材料）进行投资，培育一批优质民营中小微企业成长，打造优势产业集群。（牵头单位：市财政局、市科技局，责任单位：市金融办、市经信委、市工商局、人行市支行、市银监办）

（五）加大担保机构对民营企业的支持力度。加强与省担保平台和再担保平台的合作，提升服务功能。引导金融机构和担保机构提高信用良好企业的抵押物折扣率，降低保费率；金融机构对为实体经济提供担保服务、风险控制能力强、社会效益好的融资担保机构，要提供减免保证金、适当提高放大倍数、控制贷款利率上浮等支持措施；在处理业务风险时，与融资担保机构加强沟通协调，采取一致行动；政府出资的担保公司对小微企业免收的担保费，由市财政适当补助，降低民营企业融资成本。（牵头单位：市经信委、市财政局，责任单位：市金融办、人行市支行、市银监办、市汇桥担保公司、市域银行机构）

（六）支持民营企业上市。引导、激励民营企业进行规范化的股份制改造，构建现代化的、具有较强自我约束力的股份公司治理结构，为企业进入资本市场创造条件。支持石油化工、装备制造、纺织服装、大健康、光电子信息、生物医药、新能源新材料、高端家居等八大产业体系中的民营企业，以及民营企业中建立现代企业制度的试点企业，在各层次资本市场进行股权融资。加大上市后备企业培育力度，引导企业进步省“金种子”企业项目库，鼓励符合条件的企业在境内外上市融资。（牵头单位：市发改委、市金融办，责任单位：市上市工作领导小组成员单位）

（七）推进民营企业在“新三板”和“四板”挂牌。完善场外市场后备企业库，鼓励更多民营企业在“新三板”和武汉股权托管交易中心挂牌融资。鼓励创新创业和成长型民营企业规范改制，在区域性市场挂牌、股权登记托管，开展股权质押融资。支持符合条件的优质“四板”民营企业转板到全国股转系统挂牌。（牵头单位：市金融办、市财政局，责任单位：市农办、市经信委、市科技局、市商务局、人行市支行、市银监办）

（八）推进民营企业债券融资。引导和推动一批经营稳定、业绩优良、市场信誉良好的民营企业通过发行企业债券筹集资金。积极争取上级有关部门在我市开展企业发行资产抵押债券和信用债券、中小企业集合债券等工作。深入挖掘传统行业优质民营企业发债潜力，促进转型升级。积极组织和引导，选择发行一般企业债、专项企业债、项目收益债券融资；鼓励符合条件的企业发行绿色债券。积极探索债券信用保险。（牵头单位：市发改委，责任单位：市财政局）

（九）降低民营企业融资成本。继续整顿金融服务乱收费，指导金融机构合理确定利率水平和收费项目，加大对不合理收费的查处力度，降低企业融资成本和债务负担。进一步规范企业融资过程中担保、评估、登记、审计等中介机构收费行为，清理不必要的资金“通道”和“过桥”环节收费，将清理规范后的收费项目向社会公布。经营服务性项目放开市场准入，交由企业和社会机构双方按市场规则自主协商，行政管理部门和金融机构均不得强制社会机构为企业提供服务。（牵头单位：市物价局，责任单位：人行市支行、市银监办）
