# 市人民政府办公室关于加强财政投资评审工作的实施意见

各区、镇、办事处，市政府各部门：

为进一步规范财政投资评审工作，加强政府投资项目资金的支出管理，保证评审工作质量，根据《预算法》、《政府采购法》、财政部《财政投资评审管理规定》（财建〔2009〕648号）、《基本建设财务规则》（财政部令第81号）、《潜江市政府投资项目管理办法》（潜政办发〔2016〕64号）等法律和行政规定，结合我市实际，提出如下实施意见：

一、统一思想，进一步提高对财政投资评审工作重要性的认识

财政投资评审是财政职能的重要组成部分，是财政部门对财政性资金投资项目预（概）算和竣工决（结）算进行评价与审查，对财政性资金投资项目资金使用情况以及其他财政专项资金使用情况进行专项核查及追踪问效，通过对财政投资项目进行客观公正的评审及对专项资金的核查，既可以有效控制建设项目中的高估冒算、弄虚作假、截留挪用等浪费建设资金的现象和违法违纪行为，确保财政资金规范、安全、有效运行，又可以为财政业务部门和项目建设单位在资金拨付和项目预算控制环节提供科学依据。因此，对财政投资项目评审，不仅是节约财政支出的有力手段，而且是健全财政监管体系的重要环节。各项目建设单位要提高对财政投资评审工作的认识，积极配合和有效推进财政投资评审工作，实现对政府投资项目资金运用和财务活动的监管，最大限度地提高政府投资效益。

二、明确财政投资评审工作的范围、内容、方式及程序，进一步加强财政部门在建设领域的监督管理

我市财政投资评审工作目前主要是按照《湖北省土地整治项目资金管理暂行办法》（鄂财建发〔2015〕250号）及《潜江市政府投资项目管理办法》（潜政办发〔2016〕64号）规定，承担市域内国土整治项目的预、决算评审及政府投资项目的预算评审工作。

（一）财政投资评审工作的范围包括：

1.财政预算内基本建设资金安排的50万元及以上建设项目。

2.政府性基金等安排的50万元及以上建设项目。

3.政府性融资安排的50万元及以上建设项目。

4.其他财政性资金安排的50万元及以上建设项目。

5.其他市政府需要评审的建设项目。

（二）财政投资评审工作的内容包括:

1.本级政府性项目预算、非本级项目预算和国土整治项目预算、竣工决（结）算（下同）的真实性、准确性、完整性和时效性等审核。

2.项目基本建设程序合规性和基本建设管理制度执行情况审核。

3.项目资金使用管理的合法性、合理性审核。

4.项目施工图预算和招标控制价的合理性审核。

5.项目招标程序、招标方式、招标文件、各项合同等合规性审核。

6.项目预算执行情况以及项目实施过程中发生的工程变更及索赔情况的审核。

7.项目建设使用材料、设备价格及执行政府采购规定情况的审核。

8.其他与项目相关联事项的审核。

（三）财政投资评审工作的方式包括：

1.本级政府性项目预算、非本级项目预算和国土整治项目竣工决（结）算的评价与审查。

（1）项目建设单位在项目设计和预算编制完成后，对设计和预算编制初审后，将项目资料及时报送市财政投资评审中心，市财政投资评审中心对报送的施工图和预算进行全面评审，审核工程量清单，确定工程最高限价，以保证工程招投标的合理公正。

（2）项目建设单位提供的工程预算投资额不得超出政府相关部门批准的概算投资额，项目决算评审应在批准的预算投资额范围内进行。

2.对财政性资金使用情况进行专项核查及追踪问效。

3.其他应采取的评审方式。

（四）财政投资评审工作的程序包括：

1.由市财政局或各相关建设单位向市财政投资评审中心下达委托评审文件（书）或提出项目评审申请。

2.项目主管部门通知项目建设（或代建，下同）单位配合评审工作。

3.市财政投资评审中心根据下达的委托评审文件（书）或评审申请结合项目情况，分配项目评审任务。承担评审任务的机构制定评审计划，并对项目建设单位提供的资料进行核查。

4.承担评审任务的机构按评审的要求，在评审中心的主持下，根据有关标准、定额、规定对建设项目内容进行现场核实。项目建设单位应给予积极配合，组织项目设计、预算编制、工程监理、施工单位及项目建设单位管理人员，参与建设项目现场勘查工作，并对核实情况签字确认，作为核定工程量的依据。

5.承担评审任务的机构根据现场核实的工程量，依据定额及当地行业主管部门发布的建筑材料价格信息进行算量和价格审查，逐项逐条审核，确定合理的工程造价，形成初步评审结论，并征求项目建设单位意见。

6.项目建设单位对初步评审结论签署书面反馈意见（如初审结论出现较大争议和分歧，评审中心组织三方现场核对并交换意见，若达不成一致意见的聘请行业专家鉴定确认）。

7.承担任务的评审机构根据初步评审结论和项目建设单位在规定时限内的反馈意见出具评审报告，财政投资评审中心对评审报告进行复核后报市政府和市财政局审批（投资额在2000万元以下的政府投资项目评审结论报市财政局确认后下达，投资额在2000万元及以上的政府投资项目评审结论报市政府批复后下达），经审批确认后向项目建设单位下达项目评审确认书。

三、切实履行财政评审职能，进一步提高工作时效

为提高财政投资评审在财政资金监管中的作用，充分发挥财政投资评审的专业优势，强化财政投资评审结果的运用。一是严格执行“五先五后”的评审模式，即“先评审、后预算”、“先评审、后采购”、“先评审、后招标”、“先评审、后拨款”、“先评审、后评价”，将投资评审贯穿整个项目资金管理过程。二是实行质量保证责任制。严格按程序出具评审结论，坚持谁评审谁负责，谁失误谁担责，形成环环相扣、层层有人负责的评审流程，确保评审结论科学、准确。三是要进一步增强专业技术人员配备、吸纳技术力量强、社会信誉好的中介机构和技术专家，组建财政评审中介机构和专家库。四是严格在规定时间内向财政部门和项目单位出具评审报告（在送审项目资料齐全情况下），投资额在50万元及以上、500万元以下的，5个工作日出具初审结论；投资额在500万元及以上、2000万元以下的，10个工作日内出具初审结论；投资额在2000万元及以上、5000万元以下的，12个工作日内出具初审结论；投资额在5000万元及以上的，15个工作日内出具初审结论。特大型建设项目，评审工作日可适当延长；如不能在规定时间内完成评审任务，应及时向财政部门和项目单位报告，并说明原因。五是加强廉政评审建设，建立项目单位廉政信息反馈制度，严禁利用项目评审权利谋取私利等不廉洁行为。

四、进一步明确项目建设单位责任和义务，确保评审质量

（一）项目建设单位应积极配合财政投资评审中心开展工作，及时向市财政投资评审中心提供评审工作所需的相关资料，并对所提供资料的真实性、完整性、合法性负责。

（二）项目建设单位委托项目设计和预算编制单位进行项目设计和预算编制，应在合同条款中明确责任，避免项目在设计和预算编制中出现重大纰漏和故意高估冒算。如果财政评审结论与送审预算投资额相差10%以上的（正常价差调整不计算在内），按照《湖北省建设工程造价管理办法》（省人民政府令第311号）、《潜江市政府投资项目管理办法》（潜政办发〔2016〕64号）等规定执行。

（三）对评审工作中涉及需要现场核实或取证的事项，应积极配合，不得拒绝、隐匿或提供虚假资料。

（四）项目建设单位应在收到市财政投资评审中心出具的建设项目评审初审结论5个工作日内，提出答复意见，并由项目建设单位及其负责人盖章签字，逾期不签署意见，视同同意初审结论。

（五）根据市政府、市财政部门对评审报告的批复（批转）意见及时对项目预算进行整改。

五、进一步加强协调管理，优化评审环境

财政投资评审工作涉及面广、政策性强，各部门之间加强协调与配合是优化投资评审环境，做好财政投资评审工作的重要前提。一是要加强财政投资评审工作的主体责任。财政部门作为财政投资评审工作的组织者和监督者，负责从专业角度对建设项目开展投资评审，把财政投资评审作为加强财政支出管理的重要手段。二是要加强部门之间的沟通、协调配合。财政、发改、住建、审计、公共资源交易等部门要按照《潜江市政府投资项目管理办法》要求，对照各自职责对项目进行监督管理，加强沟通，相互支持，保证政府资金使用的科学性、合规性、合理性。三是要协调好部门与建设单位的工作关系。项目建设单位要按照《潜江市政府投资项目管理办法》的规定，积极配合财政、审计等部门开展财政投资评审工作，及时提供投资评审所需的各种文件和资料，主动介绍项目建设情况，并安排专人配合。同时，各相关部门要增强服务意识，创新工作方法，要通过财政投资项目的评审，帮助建设单位完善制度建设，规范财务管理，将优质服务与严格监督有机结合起来。

六、进一步严肃工作纪律，防范评审风险

（一）市财政投资评审中心要组织专业机构和人员依法开展评审工作，遵循合法性、公正性和客观性原则，对评审结论的真实性、准确性负责，并接受纪检监察、审计等部门的监督检查。评审机构和人员在财政投资评审过程中若存在玩忽职守、滥用职权、徇私舞弊或泄露国家机密、商业秘密等违法违规行为的，给予行政处分；构成犯罪的，依法追究刑事责任。财政投资评审机构因过失或故意提供不实或虚假评审报告的，依法承担相应的法律责任。

（二）项目建设单位应注重送审程序的严肃性和送审资料的严谨性，确保“一次送审，一次审结”，评审过程中避免随意变更设计，更改预算。评审确认书下达后，项目建设单位不得要求重新评审。确因特殊情况需增补或重新评审的，必须按程序报市政府审批同意。对项目建设单位违反《潜江市政府投资项目管理办法》和其它相关规定，拒不配合或阻扰投资评审工作的，财政部门或项目投资部门有权根据情况暂停拨付项目资金；对不按规定进行项目投资评审、擅自实施项目建设或变更工程项目的，除暂停拨付资金外，还要追究主要负责人的责任，造成重大经济损失的，依法依规追究相关责任。
