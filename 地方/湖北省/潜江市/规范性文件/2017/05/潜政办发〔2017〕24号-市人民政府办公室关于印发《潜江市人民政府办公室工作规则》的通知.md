# 市人民政府办公室关于印发《潜江市人民政府办公室工作规则》的通知

潜政办发〔2017〕24号

市人民政府办公室

关于印发《潜江市人民政府办公室

工作规则》的通知

各区、镇、办事处，市政府有关部门：

《潜江市人民政府办公室工作规则》已经市人民政府研究同意，现印发给你们，请认真贯彻执行。

2017年5月5日

潜江市人民政府办公室工作规则

为规范工作，提高效能，加强管理，充分发挥参谋助手、综合协调、督办落实、保障服务职能作用，根据《潜江市人民政府工作规则》及有关制度，结合市政府办公室工作实际，制定本规则。

一、主要职责

市政府办公室是协助市政府领导同志处理市政府日常工作的综合办事机构。市政府办公室在市政府秘书长（办公室主任）领导下，负责具体会议、文电、信息、调研、协调、督查、接待、应急值守及机关建设等日常工作，以及市政府领导交办的其他事项。

（一）负责市政府会议的会务工作，协助市政府领导同志组织会议决定事项的实施。

（二）协助市政府领导组织起草或审核以市政府及市政府办公室名义发布的公文。

（三）研究市政府各部门和各区、镇、处请示市政府的问题，提出审核意见，报市政府领导同志审批。

（四）根据市政府领导同志的指示，对市政府部门间出现的争议问题提出处理意见，报市政府领导同志决定。

（五）督促检查市政府各部门和各区、镇、处对市政府公文、会议决定事项及市政府领导同志有关指示的执行落实情况，并跟踪调研，及时向市政府领导同志报告。

（六）负责市政府工作范围内的人大代表建议、政协委员提案办理工作。

（七）负责市政府值班工作，及时向市政府领导同志报告紧急重要情况，协调处理有关重大应急突发事件、信访事项和各地各部门向市政府反映的重要问题。

（八）围绕市政府的重点工作和市政府领导同志的指示，组织专题调查研究，及时反映情况，提出建议。

（九）及时做好信息收集和反馈工作，负责全市电子政务外网建设和管理，为市政府领导同志决策服务。

（十）负责市政府机关精神文明建设、社会治安综合治理和安全保卫工作。

（十一）做好行政事务工作及行政接待工作，为市政府领导同志服务。

（十二）负责市政府驻外办事机构和市政府办公室挂靠单位的管理工作。

（十三）办理市政府领导同志交办的其他事项。

二、分工负责制度

（一）市政府办公室与市政府研究室合署办公，两块牌子，一套班子，实行秘书长（办公室主任）负责制，秘书长（办公室主任）主持办公室（含研究室，下同）的全面工作，对市政府及市长负责，办公室班子成员协助秘书长（办公室主任）工作，对秘书长（办公室主任）负责。秘书长（办公室主任）外出，由协助抓全面工作的办公室班子成员代行其职。办公室班子成员按照工作分工或秘书长（办公室主任）和市政府领导的安排开展工作，分管工作中的重要问题必须向秘书长（办公室主任）汇报并按其意见办理，必要时向市政府有关领导汇报；对秘书长（办公室主任）直接安排有关科室承办的事项，应主动督促落实，确需由领导集体处理的提交秘书长办公会议研究决定。

（二）市政府秘书长（办公室主任）、办公室班子成员与市政府各部门实行对口联系，协助市长、副市长工作。

（三）市政府办公室各科室对办公室班子成员负责，并协助办公室分管班子成员做好协调、服务和督查工作。各科室主要负责人务必处理好对口负责与对办公室整体负责的关系，对办公室分管班子成员安排的工作，必须不折不扣地完成，对办公室其他班子成员在征得办公室分管班子成员或秘书长（办公室主任）同意后安排的工作，要认真办理；对科室工作中的重要问题除向办公室分管班子成员汇报外，还应及时向秘书长（办公室主任）汇报。各科室之间要密切联系，相互配合。

三、会议制度

（一）市政府办公室全体工作人员会议。由秘书长（办公室主任）或秘书长（办公室主任）委托协助抓全面工作的办公室班子成员召集，办公室全体工作人员参加。会议的主要任务是：传达上级文件和会议精神；组织政治、业务学习，通报全市经济和社会发展中的重要情况；通报办公室工作情况，部署办公室工作；讨论其他需要办公室全体会议研究决定事项。一般两个月召开一次，必要时可根据需要不定期召开。

（二）秘书长办公会议。由秘书长（办公室主任）或秘书长（办公室主任）委托办公室班子成员主持召开，办公室全体班子成员出席，必要时通知有关科室负责人列席。会议的主要任务是：传达上级文件和会议精神；研究决定办公室工作中的重要问题，通报有关情况；安排部署阶段性工作。一般每月召开一次，必要时可根据情况随时召开。

（三）市政府办公室党组会议。由办公室党组书记召集、主持，党组成员参加，必要时通知相关科室负责人列席。会议的主要任务是：传达上级文件和会议精神；讨论办公室机关党的建设、思想政治工作和党风廉政建设工作；研究办公室机构设置、人员调配、干部任免、奖励处分、年度考核及投资较大基建、办公设备购置等“三重一大”事项；部署其他需要党组会议研究决定事项。一般每月召开一次，必要时可根据情况随时召开。党组成员的民主生活会每年召开一次。

市政府办公室全体工作人员会议、秘书长办公会议、市政府办公室党组会议的组成人员应按照会议通知要求按时参加会议。因特殊情况不能参加会议的，须及时向会议主持人请假。

（四）全市政府系统办公室主任会议。会议的主要任务是：传达上级的重要指示、决定和会议精神；总结交流政府系统办公室工作，组织开展办公室相关业务工作培训；研究和安排全市政府系统办公室的各项业务工作。一般每年召开一次。

（五）市政府全体会议及市政府召开的全市综合性会议，由秘书长（办公室主任）统筹，协助抓全面工作的办公室班子成员负责，会务工作由秘书一科负责承办，相关科室配合。市委、市政府召开的大型会议，办公室负责协办的，由办公室分管班子成员负责。办公室全体工作人员会议和党组会议，会务工作由政工科负责。市人大、市政协召开的需市政府领导参加的会议，会议通知及有关会议事项，由市政府政务督查室负责。

（六）市政府常务会议的议题收集与登记，会议记录与整理及相关会务准备由综合科负责；有关部门提请市政府常务会议审议的材料由综合科审核修改，研究室副主任审核把关，重要事项须经秘书长（办公室主任）或市政府法制办审核把关后列入会议议题方案，报市长审定。

（七）市政府专题会议由办公室分管班子成员负责，会务及会议的记录与整理由相关科室负责。

（八）政府工作报告、全市性会议上市长的讲话、市政府综合性汇报材料由综合科负责起草，研究室副主任和秘书长（办公室主任）审核把关后，报市政府领导审阅定稿。

（九）专题会议领导讲话材料和专题汇报材料由部门起草后，相关科室负责修改，办公室分管班子成员审核把关。

（十）市政府和市政府办公室召开的各类会议，要带头贯彻执行中央八项规定、省委六条意见和市委实施细则的要求，办公室领导审核或审定签发会议通知时要按照“必要、精简”的原则，严格控制会议数量，并对会议时间、参会对象和会议材料严格审查把关，提高会议质量和效率。

四、公文办理与审批

（一）各区、镇、处和市政府各部门向市政府报送的请示，由秘书一科统一审核受理，审核的重点是：是否应由本机关办理；行文理由是否充分，行文依据是否准确；内容是否符合法律、法规、规章及其他有关规定；涉及其他部门职权的事项是否已经协商会签；文种使用、公文格式是否规范。对不符合规定的公文退回呈报单位并说明理由。

受理的请示应及时进行登记，加盖文书处理专用章，紧急公文加盖急件章，送分管公文处理的办公室班子成员阅批，并根据阅批意见，送相关领导审批。需转有关部门征求意见的，应及时转办，有关部门一般应在收文后3个工作日内答复。

请示一般应在收文后7个工作日内作出答复。在回复请示事项时，领导签批意见一致的，用领导签批意见回复或采用其他方式回复；领导签批意见不一致或不同意请示事项的，用电话回复，并做好电话记录。任何人不得在公文上随便批注、修改领导同志的批示、意见，不得随意向外透露领导同志批示的原文。

（二）上级来文、来电、传真以及市委、市人大、市政协及其他单位来文、来电、来函，一般由市政府总值班室登记后送分管公文处理的办公室班子成员阅批，根据阅批意见，送市长、常务副市长、分管副市长、秘书长（办公室主任）、相关办公室班子成员阅示，并按照阅示意见，转相关领导、科室、部门和地方承办。

（三）市政府和市政府办公室文件由秘书一科负责核稿、送审、编号、校对、缮印、发放（送）、归档。规范性文件由市政府法制办负责核稿、送审、校对，交秘书一科编号、归档。

（四）需以市委、市政府或市委办、市政府办联合制发的公文，由秘书一科受理，送分管公文处理的办公室班子成员签批后，依次批呈办公室分管班子成员、秘书长（办公室主任）、分管副市长、常务副市长、市长审阅，然后按领导签批意见送市委签发。

（五）使用市政府印章须报经秘书长（办公室主任）审核，市长或常务副市长批准。使用市政府办公室印章须报经秘书长（办公室主任）批准。如遇紧急情况，经请示秘书长（办公室主任）批准，可先用印，后补办有关手续。严禁在空白纸张上加盖印章。凡以市政府、市政府办公室名义发文需用印章的，印章保管人员应根据市政府及市政府办公室领导签批意见，检查文件格式无误和文印质量合格后，方可用印。

（六）市政府常务会议纪要由综合科负责核稿、送审、校对、归档；市政府专题会议纪要由相关科室核稿、送审，交秘书一科编号、归档；市政府秘书长办公会议纪要由秘书一科记录、整理、核稿、送审、校对、编号、归档。

（七）《潜江政文》《潜政发》《潜政函》《潜政办发》《潜政办函》按照《潜江市人民政府工作规则》中公文审批的相关要求进行送审和签发。

（八）《市政府常务会议纪要》：一般由研究室副主任、秘书长（办公室主任）审核，报常务副市长、市长签发。

（九）《市政府专题会议纪要》：一般由参加会议的办公室班子成员或秘书长（办公室主任）审核，报主持会议的副市长或市长签发。其中重大问题，应送相关副市长审核后，报市长签发。

（十）《政府工作》：一般由研究室副主任审核，报秘书长（办公室主任）签发。刊登市长、副市长讲话的，一般应经市长、副市长本人审定，也可由参加会议的秘书长（办公室主任）或办公室班子成员签发。

五、信息调研制度

（一）围绕全市中心工作和领导的工作需要，及时捕捉、收集、反馈，全面展示全市经济、社会发展的动态性信息，为领导决策提供有效服务。信息调研的重点是中央、省、市重大决策部署的贯彻落实情况以及遇到的问题和对策建议；全市经济发展中的动态及工作措施；人民群众关心的热点和难点问题。

（二）完善政府信息工作考核制度。加强和完善信息网络建设，坚持全员办信息，健全信息采集、筛选、调研、报送各项制度，拓展信息服务广度和深度，提升信息服务水平。

（三）市政府办公室班子成员和各科室务必加强调研和政务信息工作，每年都要安排一定时间深入基层开展调查研究。

（四）《政府工作》由综合科、调研科负责编辑。综合科负责刊发市政府领导的讲话。调研科每年至少在省级以上报刊刊发文章4篇，并督促指导各地各部门每年上报1—2篇结合潜江实际有价值的调研文章。

（五）《潜江政务信息》由信息科编辑。信息科每周编辑《潜江政务信息》1—2期，每月上报省政府办公厅政务信息不少于20条；其他各科室要积极参与信息收集与报送，每年报送有价值的信息不少于10条。

（六）认真贯彻落实《中华人民共和国政府信息公开条例》、《湖北省政府信息公开规定》，积极推进全市政府信息公开工作，提高政府工作透明度。

六、协调督查制度

（一）严格按照《市长活动安排调度制度》，科学合理安排好市政府领导的日常活动。每周五市政府总值班室和相关专业科室要拟定市政府领导下周活动安排，由市政府总值班室汇总后报市政府领导和办公室领导，及时掌握和调度相关活动，切实发挥市长活动“指挥棒”作用，确保政府工作“一盘棋”。

（二）省政府及其部门领导来潜活动原则上根据分工实行对口承办。办公室分管班子成员负责活动的统筹协调，相关专业科室具体负责，由相关部门负责承办。重大活动由秘书长（办公室主任）统筹，活动涉及的相关班子成员负责，相关科室密切配合具体负责。

（三）协调工作原则上按分工实行对口承办。办公室分管班子成员和对口科室在调处矛盾纠纷的过程中要把握政策，依法办事，妥善处理，不留后患。对调处工作的进展情况和结果应分别向相关副市长和秘书长（办公室主任）汇报，对确需由秘书长（办公室主任）或相关副市长出面协调解决的问题要提出建议方案。

（四）重点围绕市政府决策和部署的贯彻落实做好督查督办工作。坚持政务督查室督办与业务科室督办相结合的督查督办工作机制，健全和完善督促检查、定期反馈、公开通报、考核奖惩等工作制度，形成全员督办的大督查格局。

（五）市政府政务督查室负责市政府重大决策和重大工作部署、重要会议决定事项、人大代表建议、政协委员提案、新闻媒体及网络曝光的重大问题和批评意见、市政府领导同志重要指示、市政府为民办实事、网络及市长热线电话反映问题等工作任务的督查督办。一般业务工作的督办落实由相关科室负责。

七、纪律和作风

（一）公务接待应当坚持有利公务、务实节俭、严格标准、简化礼仪、高效透明的原则。严格执行公务接待审批、用餐、乘车等规定，接待标准按照相关规定执行。

（二）积极规范行政行为，增强服务观念，强化责任意识，树立规范服务、依法行政的良好风尚。严格执行党政机关重大事项请示报告制度，对涉及本单位、领导干部个人的重大问题和重要事项要按照要求和程序，自觉请示、如实报告。同时，严格遵守机关作息时间，按时上下班，不得无故迟到、早退，因事因病不能上班的，须履行请销假手续。

（三）市政府办公室党组要切实履行党风廉政建设主体责任，办公室监察室要认真履行监督责任，不断健全和完善惩治和预防腐败体系。办公室工作人员要严格遵守《关于新形势下党内政治生活的若干准则》《中国共产党党内监督条例》等规定，严格贯彻执行党的政治纪律、组织纪律、工作纪律、财经纪律和生活纪律，做到严于律己、廉洁奉公。

八、其他方面

（一）应急管理工作实行24小时值班制度和紧急重要信息报告制度，严格按照《市政府总值班室政务值班制度》《全市政府系统政务值班工作规范》《突发事件操作规程》，切实做好政务值班和突发事件信息处置工作。

（二）财务管理工作坚持依法理财、统一管理、合理支配、勤俭节约的原则，严格按照办公室财务管理制度执行。同时，按照《市人民政府办公室公务车辆使用管理暂行办法》，确保车辆管理规范透明，车辆调度科学高效。

（三）干部教育培训管理工作按规定组织办公室干部参加岗位培训、党校学习及有关业务培训，按照办公室岗位责任制度、考核奖惩制度等相关制度，正向激励、反向督促干部职工守规矩、担责任。

（四）办公室挂靠单位按照本规则执行，并服从办公室统一领导和工作安排。

（五）其他未尽事宜由秘书长办公会议补充完善。
