# 市人民政府关于印发《政府系统“提高工作标准、提高担当勇气、提高落实速度”实施方案》的通知

各区、镇、办事处，市政府各部门：

现将《政府系统“提高工作标准、提高担当勇气、提高落实速度”实施方案》印发给你们，请认真组织实施。

2017年7月19日

政府系统“提高工作标准、提高担当勇气、

提高落实速度”实施方案

为深入贯彻落实《中共潜江市委 潜江市人民政府关于开展“提高工作标准、提高担当勇气、提高落实速度”活动实施方案》，结合政府系统工作实际，制定本实施方案。

一、指导思想

深入贯彻党的十八大和十八届三中、四中、五中、六中全会精神，以习近平总书记系列重要讲话精神和治国理政新理念新思想新战略为指导，全面落实省委、省政府和市委各项决策部署，坚持以“提高工作标准、提高担当勇气、提高落实速度”（以下简称“三提高”）为抓手，着力推进完成各项重大部署、重点任务、重要项目，为决战工业3000亿、决战虾-稻产业800亿、打造城乡建设“三大亮点”片区提供有力保障。

二、具体措施

（一）提高工作标准。针对工作中“五个自我”（自我凑合、自我满足、自我封闭、自我放松、自我糊弄）的问题，聚焦区域、全省、全国高标定位，形成人人争一流、事事争一流、时时争一流的自觉追求。

1.查摆问题找差距。各地各部门要认真分析自身工作是否达到了市委、市政府要求的标准，是否达到了上级部门制定的标准，距离全国一流、全省第一的标准还有多大差距。深刻查找本地本部门干部职工是否存在“五个自我”的情况，对查摆出来的问题，建立整改台账，制定整改措施，限期整改到位。

2.瞄准先进对好标。各地各部门要着眼全市一流、全市创优、全省争先，确立发展目标，争取召开全国、全省工作现场会；各行业、产业要瞄准市内、省内乃至全国一流水平和先进标准，与行业、产业高端对标，致力打造具有高竞争力的行业、产业；每个岗位、每名干部、每位党员要瞄准最好，做到干到极致、追求卓越、争创一流。

3.明确标杆定标准。各地各部门要对照标杆单位和目标，制定自身工作标准，对干什么、怎么干、干到什么程度、达到什么标准、怎样确保达标、如不达标将承担什么责任等问题要予以明确。原来工作标准低的，要主动调高；没有工作标准的，要结合实际，全面制定层次高、易操作的具体工作标准。

（二）提高担当勇气。针对工作中“四个不敢”（不敢担责、不敢拍板、不敢协调、不敢啃硬骨头）的问题，强化履职能力，直面困难，大事敢负责，难事勇担当，真正做到想干事、能干事、干成事、不出事。

1.强化责任意识。一是建立部门职责清单。市政府各部门要依照“三定”方案，按照权力清单、责任清单，分解到班子成员、科室站所，确保责任到人。二是建立属地责任清单。各地要守土有责、守土负责，结合市委市政府各项工作部署要求，认真梳理本辖区年度工作目标任务，分解到人，落实到人。三是建立一岗多责责任清单。各地各部门按照一岗多责原则，明确班子成员及科室站所各自分工领域的廉政、信访、安全、环保等工作责任。四是建立特别重要工作履职承诺制度。按照层层分解、责任到人的原则，对关乎我市改革发展稳定大局的特别重要工作，细化目标任务，签责任书、立“军令状”，做出履职承诺，严格抓好落实。

2.强化担当作为。一是主动履职。要按照“谁主管、谁负责、谁办理”的原则，主动解决职权范围的问题和矛盾。对职责范围内的本职工作，由本地本部门自己负责解决。对各领导小组工作事项，由领导小组办公室协调解决，解决不了的，再由分管市长进行协调。对于地方部门重大事情，确需市政府解决的，提出有价值的明确建议，提请市政府协调解决。二是主动补位。对于职责交叉重叠的工作，按照“法定职责、上下对口、便于工作”的原则，明确职责边界，及时界定分管领导、相关部门责任。对于涉及多个部门的工作，市政府指定牵头负责单位、协同配合单位，认真推动工作落实，避免因职责交叉重合产生管理真空、责任空档。三是主动领责。市政府主要领导批示中明确分管领导的，分管领导要亲自拿在手上督办推动，负责到底；明确了牵头单位或单位负责人的，其单位和负责人为直接承办单位和承办人，必须不折不扣抓好落实，真正做到事事有结果、件件有回音。

3.强化攻坚克难。一是突出难题破解。围绕私房禁建、“两违”整治、征地拆迁、环境整治、安全生产、园区配套等全市性重难点工作，统筹用力，合力攻坚，积极学习借鉴外地经验，科学合理制定工作方案，加快推进工作落实。二是突出补齐短板。要加强对本地本部门本行业工作研究，找准工作短板，列出补短板工作任务和计划，迅速补齐短板。三是突出改革创新。聚焦中央、省、市改革任务，直面问题和矛盾，迎难而上，敢闯、敢试、敢于创新，着力在先行先试上实现突破，形成在全省、全国可复制、可推广的改革经验。四是突出重大任务。对市委市政府决定的决战工业3000亿、决战虾-稻产业800亿、打造城乡建设“三大亮点”片区等重大部署，以及市委、市政府确定的重点目标和任务，各地各部门要细化方案、细化措施，明确具体责任人和完成时限，按照时间节点压茬推进，确保圆满或超额完成目标任务。

（三）提高落实速度。针对工作中“四个不”（办事不力、落实不快、效率不高、成效不明显）的问题，建立马上就办、办就办好工作机制，自我加压、主动提速，形成雷厉风行、扭住不放、一抓到底的作风。

1.强运转。一是办文办会提速。各地各部门要严格按照公文办理要求，提高文件质量，严格送审程序，加快文件办理，提升办文效率。要切实转变会风，严格控制会议规模、时间、频次和流程，转变会议方式，提高会议决策效力。二是行政审批提速。全面把握“放管服”改革工作要求，实行行政审批程序再造，对各种行政审批事项进行再次清理，进一步精减行政审批事项，简化审批环节，优化审批程序，提高审批效率。创新行政审批工作机制，开辟绿色通道，大力推行联审联办、容缺预审，即收即办、办完即转，确保在第一时间启动“办”的程序、进入“办”的状态。三是项目推进提速。对市委市政府确定的政府性投资项目、招商引资项目、为民办实事项目、征地拆迁以及事关企业和群众切身利益的公共事项等工作，要急事急办、实事实办。

2.优服务。一是优化办事流程。建立健全招商引资、重点项目推进责任制、协调机制、跟踪督查机制和分级负责机制，对重点工程和招商引资签约项目实行全程帮办服务，由项目所在地有关部门或引资单位主要领导挂牌领办、跟踪服务。二是加快问题解决。各项目包联领导、指挥部、工作专班和牵头单位要深入项目一线，收集问题、研究问题、解决问题，建立工作台帐、问题清单，及时交办督办，将重大项目服务逐步纳入规范化、制度化、标准化轨道。三是强化一线管理。各单位要严格落实一线工作人员、窗口人员工作职责，加强管理，确保事情办得更好、更快，企业和群众满意度更高。

3.大督办。建立健全工作台账制度、限时报告制度、调查复核制度、情况通报制度、督查调研制度，进一步健全完善督查工作机制，形成大督查工作格局。市政府政务督查室要强化督查督导工作，各领导小组、指挥部、项目组、牵头单位等都要担负起督导检查责任，重点围绕各单位在项目推进上采取的工作措施、在节点任务上取得的工作进展等方面，采取重大任务重点督办、专项事务专项督办、常规工作常规督办相结合的方式，运用明察暗访、限期督办、不定期通报等措施，开展定期或不定期督查。对临近时间节点的重点项目、重点任务，及时发出预警通知。

4.严问责。在工作中存在以下情形的：对上级和我市安排必须落实的工作，在一定期限内未开展，且不能做出合理说明的；工作进度未达到预定目标，不能如期完成工作任务的；工作进度落实到位，但工作质量未达到预期效果，离标准要求有差距的；因工作方式方法不当引发矛盾问题，造成不良后果的；因执法不严、监管不力等致使我市被上级通报、责令检讨或形成负面舆论热点的，市政府政务督查室要对相关责任单位、责任人予以全市通报。同时，要与市纪委监察局建立联动问责机制，对于屡督不办、屡推不动的单位或个人，移交市纪委监察局进行追责问责，严肃处理。

三、强化保障

（一）加强组织领导。坚持全员推动、全域动员、全程落实，政府系统所有党员干部都必须把“三提高”作为工作追求，自觉把行动统一到市委部署上来，把“三提高”内化为办事、做事、干事、成事的个人工作素养，把“三提高”要求贯穿各项工作的始终，各个环节、各个节点都积极践行“三提高”标准，及时总结好经验、好做法，形成制度。

（二）实行容错机制。严格落实市委《关于为敢于担当的干部担当为敢于负责的干部负责的若干意见（试行）》，鼓励各级干部充分发挥主观能动性，放胆创新、大胆实践。对干部在体制机制改革、试点探索中先行先试，创造性推动工作，临机处置突发事件、群体性事件等出现的失误和错误视情况给予免责或从轻、减轻处理。

（三）加大舆论宣传。广泛利用广播、电视、报纸、网络平台等宣传阵地，既要大力宣传在“三提高”工作中涌现出的好典型、形成的好经验、总结的好办法，也要曝光个别单位、机关干部为官不为、效能低下等突出问题，形成共同落实“三提高”工作要求的强大合力，在全市营造干事创业、敢于担当、务实重行的浓厚氛围。
