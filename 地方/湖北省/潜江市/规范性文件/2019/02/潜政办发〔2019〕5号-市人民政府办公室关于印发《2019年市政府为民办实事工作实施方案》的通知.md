# 市人民政府办公室关于印发《2019年市政府为民办实事工作实施方案》的通知

关于印发《2019年市政府为民办实事

工作实施方案》的通知

各区、镇、办事处，市政府有关部门：

《2019年市政府为民办实事工作实施方案》已经市人民政府同意，现印发给你们，请结合实际，认真组织实施。

2019年2月22日

2019年市政府为民办实事工作实施方案

办好民生实事，增进民生福祉，是政府义不容辞的责任。为指导和推动2019年市政府为民办实事工作的顺利开展，确保为民办实事项目的全面完成，特制定本实施方案。

一、工作任务

（一）筹资1.59亿元，实施脱贫攻坚工程，确保全市现行标准下贫困人口全部脱贫、贫困村全部出列。

（二）筹资1.6亿元，实施黑臭水体整治工程，完成保驾路排水改造及桥梁连通工程建设，完成县河、莫解渠、四支渠和六支渠黑臭水体整治。

（三）筹资8550万元，实施农村生活垃圾统筹治理工程，完成全市农村生活垃圾精准治理和农村垃圾中转房试点建设。

（四）通过政府统筹、市场投入等办法，筹措各方面资金21.78亿元，开工建设公租房、还建房2981套。

（五）筹资5.9亿元，实施教育惠民工程，加快高新区中、小学及泰丰中、小学等6所学校建设。

（六）筹资1.16亿元，实施农村安全饮水提质工程，解决熊口镇、龙湾镇、张金镇、熊口管理区、运粮湖管理区等地安全饮水问题。

（七）筹资1.5亿元，实施民生交通工程，改造县乡公路100公里以上、农村危桥10座，新建通村组公路50公里。

（八）筹资1亿元，实施农村电网升级改造工程，进一步完善农村供电基础设施条件。

（九）筹资5841万元，推进“健康潜江”建设，强化健康问题干预措施，有效预防和控制主要传染病及慢性病。

（十）筹资4300万元，实施天然气城乡一体化建设，敷设管网38.26公里。

（十一）筹资4040万元，实施创业就业扶持工程，推进新增创业3000人，带动就业6500人。

（十二）筹资3600万元，实施养老服务惠民工程，支持新建2所民办养老机构，引导建设9个居家养老服务中心。

（十三）筹资1593万元，实施文体惠民工程，开展系列文体活动。

（十四）实施城乡公交一体化工程，让广大城乡居民享受更加安全、便捷、经济、舒适的出行服务。

二、工作机制

（一）强化组织领导。实行市政府分管副市长领办制，一事一案，当年办结。市政府办公室负责为民办实事工作的组织、协调、督查和考核，市扶贫办等15家牵头单位要强化主体责任，狠抓工作落实；其他责任单位要强化服务责任，全力以赴，密切配合，形成合力，加快项目推进，高质量完成为民办实事各项工作，确保向全市人民交上满意的“答卷”。

（二）保障资金投入。各责任单位要统筹谋划、合理安排，多渠道筹集资金，将资金配套到位，在争取上级投入、财政配套的同时，对列入计划预算的资金，严格实行专款专用，拨款及时拨付到位，确保为民办实事的顺利推进。

（三）严格督查考核。市政府办公室将对为民办实事项目的进展情况进行定期督查通报。为民办实事项目各牵头单位和责任单位要加强阶段性的督促检查，及时研究解决为民办实事项目推进过程中发现的问题，确保各项任务圆满完成。

三、工作考核

（一）考核单位：市政府办公室。

（二）考核对象：15家为民办实事责任单位，分别是市扶贫办、市住建委、市城管局、市住房局、市城投公司、市教育局、市水务局、市交通运输局、市供电公司、市卫计委、市妇联、市人社局、市民政局、市文体旅新局、市广电局。

（三）考核方法：采取平时检查、季度督查和年末验收相结合的方式，对各责任单位实行量化考核，考核结果纳入年度目标管理。

四、工作要求

（一）提高思想认识。各责任单位必须在思想上高度重视，把确定的各项目标作为必成任务，敢于挑担子、加压力。要进一步强化责任意识，增强为民办实事的紧迫感，做到“跟”“盯”“追”，全流程跟进度、盯部门、追环节。各牵头单位和责任单位要强化主动意识、牢固树立目标必成意识，提高重视程度，拓宽思路、务实举措，扎实推进各项工作，切实完成年度目标。

（二）狠抓工作落实。各责任单位要真抓实干，求真务实，在保证工作质量的前提下，提高工作效率和工作水平。各牵头单位要认真开展“回头看”，对于达到序时进度的实事项目，要按照从紧从早要求，力争保证质量早完成；对于未达到序时进度的实事项目，相关单位要认真分析进度滞后的原因，制订采取有效措施方案，狠抓推进。各项实事目标任务必须在2019年12月20日前完成。各责任单位要认真制定项目实施方案，合理分配任务。请各责任单位将具体实施工作方案于2019年3月5日前报送市政府政务督查室。

（三）加强督查考核。要坚持以督查促落实，实施常态化督查，坚持自查、核查、督查的督办机制，提高督办效率。市政府政务督查室对为民办实事要严格督查，加强考核，对进展缓慢、落实不力、未按要求完成工作任务的责任单位进行通报批评和挂牌督办，并按照《潜江市政务督查工作考核办法》对贯彻落实情况进行考核记录。
