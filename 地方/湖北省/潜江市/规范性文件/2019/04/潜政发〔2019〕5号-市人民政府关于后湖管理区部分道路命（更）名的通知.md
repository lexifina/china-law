# 市人民政府关于后湖管理区部分道路命（更）名的通知

各区、镇、办事处，市政府各部门：

为实现地名标志标准化，进一步规范我市地名管理，加强社区建设管理工作，市民政局根据《国务院地名管理条例》有关规定，严格按照道路命名程序，组织后湖管理区、相关职能部门和专家开展了后湖管理区部分道路命（更）名工作，并通过媒体向社会进行了公示。经广泛征求意见，市政府决定对后湖管理区部分道路进行命（更）名，现予以公布，请按命名更名情况执行。
