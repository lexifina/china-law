# 市人民政府关于潜江市第十一届青少年科技创新政府奖获奖情况的通报

关于潜江市第十一届青少年科技创新政府奖

获奖情况的通报

各区、镇、办事处，市政府有关部门：

2018年以来，全市各地、各学校认真贯彻落实党的十九大精神和党的教育方针，积极开展青少年科技创新活动，培养学生的科学素质、创新精神和实践能力，取得了一批高质量的科技创新成果。

根据《潜江市青少年科技创新政府奖奖励办法》（潜政办发〔2008〕97号），市青少年科技创新政府奖领导小组组织专家评审小组，对各地、各学校申报的青少年科技创新项目进行了评审，共评出优秀成果40项，其中周平等同学的6项成果被评为潜江市第十一届青少年科技创新政府奖一等奖，刘心跃等同学的12项成果被评为潜江市第十一届青少年科技创新政府奖二等奖，徐瑞青等同学的22项成果被评为潜江市第十一届青少年科技创新政府奖三等奖（名单附后）。经市人民政府同意，现对上述获奖者予以通报表扬。

希望受到表扬的同学及辅导教师发扬成绩，再接再厉，取得更多更好的科技创新成果。各地、各有关部门要以党的十九大精神和党的教育方针为指导，扎实推进全国教育体制改革试点项目“建立青少年科技创新政府奖制度”的实施，加快推进教育现代化强市进程，为我市“东进南扩、产城融合，四区联动、全域振兴”战略提供人才保障和智力支撑。全市广大教职工要深入开展科技创新的理论研究与实践探索，培养崇尚科学、勇于探索、大胆创新的钻研精神，为促进教育高质量发展作出更大贡献。

附件：潜江市第十一届青少年科技创新政府奖获奖名单
