# 市人民政府办公室关于推进电子商务与快递物流协同发展的实施意见

各区、镇、办事处，市政府有关部门：

为贯彻落实《国务院办公厅关于推进电子商务与快递物流协同发展的意见》（国办发〔2018〕1号）、《省人民政府办公厅关于推进电子商务与快递物流协同发展的实施意见》（鄂政办发〔2018〕41号）和《潜江市现代物流业“十三五”发展规划》，全面提高我市电子商务与快递物流协同发展水平，结合我市实际，提出如下实施意见。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大精神，坚持规划引领、协同带动、共建共享、融合发展，以供给侧结构性改革为主线，以完善基础体系、培育市场主体为重点，以营造制度环境为保障，优化快递物流节点布局，在全市范围内形成规范、有序、健全、高效的电子商务与快递物流协同发展机制，促进经济增长方式转变，全面提升电子商务发展水平。

二、发展目标

到2021年，我市快递物流系统更加完善，快递物流基础设施更加完善，快递物流体系更加完善，节点布局更加优化，快递物流运营管理更加规范，信息更加畅通，科技应用更加广泛，基本实现市、镇、村（社区）网店全覆盖，有效推动和实现工业品下行、农产品上行双流通，基本形成布局科学化、信息开放化、通行便利化、产业融合化的电子商务与快递物流紧密协同发展新格局。

三、重点任务

（一）加强协同发展的规划引领。

1.强化规划引领。推动电子商务与快递物流业发展规划的统筹对接。在国土空间规划和城乡规划中，统筹考虑快递物流仓储、分拨、配送等设施用地和快件大型集散、分拣等基础设施用地。按照集约用地原则，探索土地供应新方式，将智能快件箱、快递末端综合服务场所纳入公共服务设施相关规划。（责任单位：市交通运输局、市自然资源和规划局、市住建局、市商务局、市发改委，各区、镇、办事处）

2.加强电商与物流体系的有效衔接。推进铁路、公路、邮政等物流基础设施建设，实现电商与快递物流的无缝衔接。推动交通、邮政、供销等相关单位快递物流资源与电商、快递等企业的物流服务网络和基础设施衔接共享。（责任单位：市交通运输局、市发改委、荆州市邮政管理局、市供销社、市商务局，各区、镇、办事处）

3.保障电商快递物流基础设施用地。落实好现有相关用地政策，保障电子商务快递物流基础设施建设用地。在不改变用地主体、规划条件的前提下，利用存量房产和土地资源建设电子商务快递物流项目的，可在5年内保持土地原用途和权利类型不变，5年期满后需办理相关用地手续的，可采取协议方式办理。（责任单位：市自然资源和规划局、市住建局、市发改委，各区、镇、办事处）

4.加快基础设施网络建设。加强农村物流基础设施建设，鼓励电商快递物流企业建设仓配一体化项目，提升电子商务后端仓储与配送能力，合理布局冷链仓储中心和农产品集中配送中心。依托市级物流中心建立电商三级物流体系，打通工业品下乡、农产品进城的双向物流配送渠道，构建城乡一体化快递物流配送网络，解决物流配送“最后一公里”的难题，进一步提升电商精准扶贫成效。（责任单位:市交通运输局、市商务局、市经信局,各区、镇、办事处）

（二）营造协同发展的制度环境。

1.深化“放管服”改革。进一步优化流程，改革快递企业年度报告制度，实施快递末端网点备案管理，实现许可备案事项网上统一办理。加强事中事后监管，建立完善执法人员数据库和监管企业数据库，建立快递物流随机抽查事项清单，全面推行“双随机、一公开”监管。（责任单位：市交通运输局、荆州市邮政管理局、市市场监督管理局）

2.加强信息互联共享。贯彻落实《国家邮政局 商务部关于规范快递与电子商务数据互联共享的指导意见》，鼓励和引导电子商务平台与快递物流企业间开展数据交换共享，共同提升配送效率。试点推行区域电子商务物流快递公共信息服务平台建设，发挥运力调配、交通引导、供给调解和市场服务等方面作用，降低社会综合物流成本，实现服务协同联动。（责任单位：市商务局、荆州市邮政管理局、市交通运输局、市公安局、市政务服务和大数据管理局）

3.强化市场主体培育和行业监管。重点把控物流企业准入机制，降低门槛，鼓励发展现代电商物流，做好物流市场主体培育工作。对物流企业进行法律法规宣传，重教育、严管理、轻处罚，建立信用公示制度，为快递企业创造健康、和谐和体面的工作环境，促进诚信合法经营。（责任单位：市交通运输局、荆州市邮政管理局）

（三）创新产业支持政策。

1.支持园区建设升级。发挥现有电子商务示范基地引领带动作用，整合空间资源，设立快递物流集散和分拨中心，拓展服务功能，提升综合实力，促进产业链创新发展。鼓励传统物流园区主动适应电子商务与快递业发展需求转型升级，提升仓储、运输、配送、信息等综合管理和服务水平。（责任单位：市交通运输局、市商务局、市发改委、市经信局，各区、镇、办事处）

2.支持农村快递物流发展。统筹推进“快递下乡”工程，建立市镇村三级快递配送服务体系。支持快递企业与农家店、农村综合服务站、农产品购销代办站等以建立合作网点的形式提供快递服务，在邮政“三农”服务站等邮政网点办理（代理）快递业务，打造农村邮政综合服务平台。鼓励快递企业深入农村开展投递服务合作，进行城乡间、乡镇间、乡镇与村组间快件集中运输。依托电子商务进农村综合示范等工程，对服务农村电商成效突出的邮政、供销社、快递企业，给予相关政策支持。（责任单位：荆州市邮政管理局、市发改委、市财政局、市商务局、市农业农村局、市供销社，各区、镇、办事处）

（四）优化配送通行管理。

1.规范配送车辆运营管理。对快递服务车辆实施统一编号和标识管理，加强对快递服务车辆驾驶人交通安全教育。支持快递企业为快递服务车辆统一购买交通意外险。引导快递企业使用符合标准的配送车型，推动配送车辆标准化、厢式化。（责任单位：市交通运输局、市公安局，各区、镇、办事处）

2.保障配送车辆便利通行。完善城市配送车辆通行管理政策，合理确定通行区域和时段，对快递服务车辆等城市配送车辆依法给予通行、停靠便利。完善商业区、居住区等区域停靠、装卸、充电等设施，推广分时停车、错时停车。（责任单位：市公安局、市发改委，各区、镇、办事处）

（五）加强科技人才安全支撑。

1.提高科技应用水平。鼓励电子商务和快递物流企业采用先进技术和装备，推进云计算、大数据、区块链等关键技术在电子商务领域的研究和运用。推进物联网技术与电子商务模式的融合创新，推进建立完整的商品追溯体系和服务平台。（责任单位：市科技局、市发改委、市经信局、市商务局、市市场监督管理局、市财政局，各区、镇、办事处）

2.加强人才培养。支持有条件的电子商务和快递物流企业与相关院校共建人才培养基地。鼓励本市高职学校开设电子商务和快递物流专业课程，为行业发展输送专业人才。（责任单位：市人社局、市教育局、市财政局，各区、镇、办事处）

3.推进“平安快递”建设。完善邮政业和物流行业安全监管体制机制，建立市级寄递物流渠道安全管理领导小组和邮政业与物流行业安全中心，强化企业安全主体责任、政府部门监管责任和属地管理责任，加强市镇联动与部门合作，全面提升安全监管质效。严格执行“收寄验视、实名收寄、过机安检”三项安全制度，加强寄递物流安全防范。建立健全快递物流运单及电子数据管理制度，采取有效技术手段保证用户信息安全。（责任单位：市委政法委、荆州市邮政管理局、市交通运输局、市财政局、市公安局、市应急管理局，各区、镇、办事处）

（六）发展绿色生态供应链。

1.推广绿色包装。探索包装回收和循环利用，建立包装生产者、使用者和消费者等多方协同回收利用体系。鼓励电商平台提供绿色包装选择，建立积分反馈、绿色信用等机制，引导消费者使用绿色包装和减量包装。按照有关政策对快递绿色包装生产、回收和使用企业给予适当补贴。（责任单位:市发改委、市商务局、市生态环境局、市财政局、市经信局,各区、镇、办事处）

2.推动绿色运营。推动运输结构调整，逐步提高铁路等清洁运输方式在快递物流领域的应用比例。鼓励快递物流领域加快推广使用新能源汽车和满足更高排放标准的燃油汽车，逐步提高新能源汽车使用比例。推广可重复使用的中转袋、中转箱、笼车等设备应用，提升作业效率。（责任单位：市交通运输局、市发改委、市生态环境局、市财政局、市经信局、市商务局，各区、镇、办事处）

四、保障措施

（一）加强组织领导。成立市电商快递物流协同发展领导小组，由市政府分管副市长任组长，市委政法委、市商务局、市交通运输局、市发改委、市财政局、市市场监督管理局、市经信局、市自然资源和规划局、市住建局、市公安局、市农业农村局、市生态环境局、市应急管理局、市科技局、市政务服务和大数据管理局、市教育局、市人社局、市供销社、荆州市邮政管理局和各区、镇、办事处等单位分管领导为成员，领导小组办公室设在市商务局，各成员单位要充分认识推动电子商务与快递物流协同发展的重要意义，强化组织领导和统筹协调，加强部门间、行业间的联系沟通，形成职责明确、分工合作、齐抓共管的工作格局，建立健全促进电商企业、快递企业发展的政策措施，提升电子商务与快递物流协同发展水平，确保电子商务与快递物流协同发展取得成效。

（二）加大资金支持。统筹电子商务发展资金，探索采用“借转补”“事后奖补”等方式，发挥财政资金杠杆作用，支持电子商务与快递物流协同发展。对服务电商企业成效突出的快递企业，根据业务量给予一定补助，快递物流企业入驻园区与电商企业享有同等优惠政策，支持符合条件的快递物流园区建设项目申报专项资金。

（三）注重人才培养。加大电商和物流专业人才引进，提升电商快递物流产业协同发展规划、建设、管理能力；相关行业部门要鼓励、引导现有电商、物流企业管理人员转变经营理念，积极引进省内外专业人才，适时组织电商、物流从业人员的岗前培训、在岗培训，提升从业人员的素质，提高行业竞争力。

（四）深入宣传推广。各成员单位要做好电子商务与快递物流协同发展推进工作，及时总结工作中的经验，通过传统媒体和网络媒体进行宣传推广，营造良好氛围，引导舆论形成共识，共同推动行业健康有序发展。

（五）强化督导落实。牵头责任单位要加强与相关单位配合，强化组织领导和统筹协调，明确责任分工，细化工作举措，抓好工作落实，及时协调解决工作中遇到的问题，确保各项工作稳步推进。市商务局要会同有关部门加强工作指导和监督检查，确保各项措施落实到位。

2019年9月4日
