# 市人民政府办公室关于印发2019年潜半夏产业发展实施方案的通知

关于印发2019年潜半夏产业发展

实施方案的通知

各区、镇、办事处，市政府有关部门：

《2019年潜半夏产业发展实施方案》已经市人民政府同意，现印发给你们，请结合实际，认真组织实施。

2019年9月10日

2019年潜半夏产业发展实施方案

为贯彻落实农业农村部《全国道地药材生产基地建设规划（2018-2025年）》（农农发〔2018〕4号）和《湖北特色农产品优势区建设规划（2018-2022年）》精神，更快更好地发展潜半夏产业，特制定本实施方案。

一、指导思想

按照乡村振兴战略的总体安排和省委、省政府关于加强中医药强省建设步伐的要求，坚持一二三产业融合发展理念，以市场为导向，建立健全产业发展体系，把潜半夏产业打造成我市旱田区农民增收致富，助力脱贫攻坚的主导产业。

二、工作目标

以提高潜半夏综合生产能力、抗风险能力和市场竞争能力为主攻方向，创新体制机制，打造潜半夏区域公用品牌。通过3年努力，建设5000亩潜半夏野生种质资源保护区、2000亩潜半夏原种良种繁育基地、2万亩潜半夏标准化种植基地，年加工半夏半成品（干品）2000吨，开发半夏饮品3-5个，半夏年交易量3万吨。把潜江建设成为全国半夏野生种质资源保护基地、全国半夏种子交易中心、全国半夏初加工产品交易中心、全国优质半夏饮片供应中心、全国半夏一二三产业融合发展示范基地，潜半夏全产业链综合产值达到100亿元。

三、主要措施

（一）建设良种繁育和生产基地。

1.建设良种繁育基地。在高石碑镇建设露地良种繁育基地1000亩，年产良种50万公斤；在周矶管理区、浩口镇、潜江经济开发区·竹根滩镇等地流转土地，通过“公司+基地+农户”等形式，建设设施原种良种繁育基地1000亩，年产良种60万公斤。力争把潜江打造成全国最大的半夏良种繁育中心。（责任单位：市农业发展中心、相关区镇处）

2.建设标准化生产基地。通过潜半夏公司、康润公司等企业领办、自办设施基地，建设1000亩的标准化、规范化示范基地，返租给农户种植并引导农户自建设施大棚，基地由合作社组织管理，按“五统一”模式组织生产和全程服务。（责任单位：市农业发展中心、周矶管理区等区镇处）

3.建设露地连片生产基地和分户种植基地。在潜江经济开发区·竹根滩镇、老新镇、王场镇、高石碑镇、周矶办事处、杨市办事处和浩口镇等有基础的区镇处新建设规模露地连片种植基地2000亩以上，着力推广“万户万亩万元”模式，通过良种繁育基地带动农户自发采种，新发展分户种植模式4000亩，力争2019年全市半夏种植面积达到8000亩,2020年达到12000亩，2021年达到20000亩（责任单位：市农业发展中心、相关区镇处）。

4.建设潜半夏野生种质资源保护区。在我市汉江、东荆河沿线（潜江经济开发区除外）护堤林地约5000亩划定为种质资源保护区，重点地段设置标志牌，禁止无序采挖，提升潜半夏野生种质资源品质。（责任单位：市农业发展中心、市自然资源和规划局、相关区镇处）

（二）发展精深加工。

5.加快精深加工项目建设。支持潜半夏公司建设2000吨原料药和1000吨毒性饮片加工项目；支持湖北鼎药中药材有限公司建设GMP标准化潜半夏加工项目，年加工半夏半成品（干品）1000吨；支持康润公司建设中药饮品加工项目，加快设计论证中药饮片厂的前处理车间、中药饮片车间和半夏毒性饮片车间工艺流程,年加工半夏饮片1000吨。（责任单位：市市场监督管理局、相关区镇处和企业）

（三）拓展产业链条。

6.建设潜半夏交易加工中心。将潜半夏交易加工中心项目纳入乡村振兴项目，尽早开工，力争建成全国最大的半夏交易加工中心。（责任单位：周矶管理区、市水乡园林投资有限公司）

7.提升检测能力。完善检测设备，配置并培训检测人员，确保对潜半夏产品实施全面检测。（责任单位：市公共检验检测中心）

8.培育生产经营主体。整合从事潜半夏研究、生产、加工的各企业、合作社、家庭农场、种植大户等，建立潜半夏产业联合体，建立利益联结机制，加强行业自律和管理。（责任单位：市农业发展中心、市市场监督管理局、市经管局）

9.规范潜半夏品牌管理。由市农业发展中心会同相关部门、半夏协会及经营主体等加强“潜半夏”品牌规范管理，实行备案登记制度，实现更多半夏从业主体共建共享“潜半夏”地理标志集体商标。（责任单位：市农业发展中心、市市场监督管理局、潜江市半夏协会）

四、保障措施

（一）加强组织领导。积极学习借鉴半夏产业强省强市工作经验，加快产业发展。成立潜江市潜半夏产业发展领导小组（领导小组名单附后），加强领导、指导、协调和督办，定期召开专题会议，及时解决产业发展中的问题。

（二）强化政策扶持。加大潜半夏产业发展政策和金融支持力度。统筹相关部门涉农项目和资金给予产业发展支持，市财政设立潜半夏产业发展专项资金800万元，对当年新种植半夏新型经营主体和个人给予一次性补贴，露地种植半夏每亩补贴500元；对新建避雨设施种植半夏的，每个标棚（320平方米）补贴1000元（租用设施种植半夏每个标棚补贴200元）。金融部门要创新产品，支持半夏产业发展，协调市内商业性银行对龙头企业提供加工和收购周转金贷款；对于符合条件的半夏种植户和企业予以贷款，由邮储银行潜江支行、潜江中银富登村镇银行、湖北银行潜江支行提供支持（每亩贷款总额不超过5000元，加工企业贷款不超过500万元），市财政按贷款利息的50%给予种植贴息，按贷款利息的20%给予加工企业贴息。新建潜半夏饮片加工中心（公司），含半夏配方颗粒及中成药厂，通过GMP认证后，按涉及半夏的单体车间投资总额10%予以奖补，最高不超过100万元。支持开展潜半夏种植生产灾害保险，半夏种植每亩保额5000元，费率8%（400元/亩），财政补贴70%（280元/亩），种植主体出资30%（120元/亩），按自愿参保原则，为种植户提供保险保障，防范风险。对潜半夏种植技术研究予以奖补支持。

（三）加强技术支撑。与华中农业大学、湖北中医药大学等高等院校开展校企合作，成立研发中心，对潜半夏生产、加工全产业链进行基础性研究。开展潜半夏种植模式、标准化生产试验示范研究，制定潜半夏规范种植技术规程。加快潜半夏产业人才引进和培养，扶持半夏技能培训中心开展半夏种植专业技术培训，保证产业持续发展。

（四）加强部门监管。市财政局加强资金监管。凡财政补贴资金和涉农项目，严格按照财政和项目资金使用规定，切实加强资金管理，明确专人负责专账管理，定期对资金管理使用情况进行监督检查。市纪委监委加大对截留、挪用、套取补贴资金等违法违纪线索问题的查处。

（五）强化总结宣传。充分利用广播、电视、报纸和网络等多种新闻媒体，大力宣传潜半夏产业发展过程中的好经验、好措施。宣传好标准化、规范化示范基地，发挥好典型引领作用和辐射带动作用。明确专人具体负责产业发展相关信息收集，及时发布工作动态，营造良好的舆论氛围和发展环境。

2019年潜半夏产业“以奖代补”方案

1.露地基地（200万元）：2019年拟新发展露地种植潜半夏4000亩，每亩奖补500元。

2.设施基地（100万元）：2019年新建钢架大棚并进行种植潜半夏，每个钢架大棚（40米×8米）最高奖补1000元。预计2019年新发展设施钢架大棚1000个（包括租用标棚）。

3.加工销售（200万元）：2019年新建潜半夏加工厂房并进行潜半夏加工销售。按主体生产车间和厂房总投资额度10%奖补（每处最高不超过100万元）。2019年拟新建潜半夏产品加工厂房2处。

4.试验示范推广（30万元）：开展潜半夏“三新”技术试验示范和技术推广，组织开展潜半夏技术培训和印发潜半夏种植技术资料等。

5.贴息贷款（130万元）：金融扶持农民和合作社种植潜半夏，预计贷款总额2600万元；支持加工企业融资贷款预计6500万元。

6.生产灾害保险（140万元）：2019年半夏生产总面积5000亩，预计投保总额200万元，其中：市财政负担140万元，种植户承担60万元。

2019年设立潜半夏产业发展奖补资金800万元。
