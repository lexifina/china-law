# 市人民政府关于公布实施潜江市基准地价更新成果的通知

各区、镇、办事处，市政府各部门：

根据《省国土资源厅办公室转发关于加强公示地价体系建设和管理有关问题的通知》（鄂土资办文〔2017〕37号）和《省国土资源厅办公室关于公示地价成果验收备案事项的通知》（鄂土资办函〔2018〕94号）要求，为进一步健全土地市场价格体系，促进土地市场的平稳、健康发展，增强政府宏观调控能力，经市政府研究决定，现将潜江市基准地价更新成果予以公布。请各单位按照有关规定和程序认真组织落实。

本基准地价自发文之日起实施。
