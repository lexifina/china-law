# 市人民政府关于部分道路命名（更名）的通知

各区、镇、办事处，市政府各部门：

为清理整治不规范地名，进一步规范我市地名管理，方便群众生产生活，市民政局根据《国务院地名管理条例》和《湖北省地名管理办法》有关规定，严格按照道路命名程序，组织所属5个区镇处、相关职能部门和专家开展了部分道路命名（更名）工作，经广泛征求意见，市政府决定对部分道路进行命（更）名，现予以公布，请按命名更名情况执行。
