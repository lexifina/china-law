# 市人民政府关于印发潜江市市级行政审批中介服务事项清单（2019年版）的通知

关于印发潜江市市级行政审批中介服务事项

清单（2019年版）的通知

各区、镇、办事处，市政府有关部门：

为规范全市行政审批中介服务，市发改委、市民政局等部门对全市行政审批中介服务事项进行重新清理规范。经审核确认，我市市级行政审批中介服务事项共89项，其中：由申请人委托相关中介机构开展的行政审批中介服务事项70项，由审批部门委托相关机构开展的行政审批中介服务事项19项。现将《潜江市市级行政审批中介服务事项清单（2019年版）》予以印发公布，并就有关事项通知如下:

一、凡未纳入省、市目录的中介服务事项，一律不得作为行政审批的受理条件，由审批部门委托相关机构开展的中介服务事项，一律不得要求行政审批申请人承担费用。

二、各有关单位要进一步加强行业管理，简化、优化审批流程，规范中介机构和从业人员的执业行为，不断提高中介服务质量和效率。

附件：潜江市市级行政审批中介服务事项清单（2019年版）

2019年11月19日
