# 市人民政府关于规范园林等七个街道办事处名称的通知

各区、镇、办事处，市政府各部门：

为了规范园林、泽口、广华寺、周矶、杨市、泰丰、高场七个街道办事处名称使用不规范问题，市委、市政府决定规范园林等七个街道办事处名称，并通知如下:

“园林办事处”规范为“园林街道办事处”；

“泽口办事处”规范为“泽口街道办事处”；

“广华寺办事处”规范为“广华寺街道办事处”；

“周矶办事处”规范为“周矶街道办事处”；

“杨市办事处”规范为“杨市街道办事处”；

“泰丰办事处”规范为“泰丰街道办事处”；

“高场办事处”规范为“高场街道办事处”。

七个街道办事处及辖区村（社区）请按市政府发文更换牌子和印章，所辖各基层单位应相应作出调整。

2020年11月2日
