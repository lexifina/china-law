# 市司法局关于进一步加强人民调解委员会规范化建设的通知

011217651/2017-29886

文号：

鄂州司发通〔2017〕7号

发布机构：

鄂州市司法局办公室

发布日期：

2017年01月16日

信息分类：

其他

有效性：

有效

各区司法局，各开发区、街道司法所：

为加强人民调解组织规范化建设，提高人民调解工作质量和水平，增强人民调解工作社会公信力，充分发挥人民调解在预防化解矛盾纠纷、维护社会和谐稳定中的作用，根据《中华人民共和国人民调解法》、《人民调解工作若干规定》、《湖北省人民调解规定》以及司法部、中华全国人民调解员协会、湖北省司法厅等相关文件要求，市局决定在全市范围内组织开展人民调解委员会规范化建设工作。现将有关事项通知如下：

一、工作目标

促进人民调解组织网络进一步健全，培养和树立一批规范化人民调解委员会建设的典型；人民调解员队伍整体素质进一步提高；工作制度更加完善；基础设施等保障明显改观；人民调解工作职能作用得到充分发挥。

二、工作内容

（一）组织机构

1.依法建立人民调解委员会。

乡镇（街道、开发区）以及村民（社区居民）委员会依法设立人民调解委员会；企业事业单位、社会团体或者其他组织根据需要设立人民调解委员会。

村（社区）人民调解委员会以自然村（居民小组）、小区（楼院）等为单位设立调解小组，聘任调解员（纠纷信息员）；建立健全村（社区）人民调解委员会—调解小组—人民调解员（纠纷信息员）三级调解网络。

2.人民调解组织的设立实行备案制度。

人民调解委员会应当将设立、变更及人员组成情况报所在地司法行政机关备案：村（社区）人民调解委员会报司法所备案；乡镇、区级行业性专业性人民调解委员会报区司法局备案；开发区（街道）、市级行业性专业性人民调解委员会报市司法局备案。

3.规范人民调解场所设置、印章。

有独立工作场所的人民调解委员会应当在工作场所外悬挂人民调解委员会名称标牌。标牌一般为竖式外挂标牌，悬挂于人民调解委员会正门左侧合适位置。无独立工作场所的人民调解委员会，应当在调解室门左侧或上侧合适位置悬挂人民调解委员会名称方形标牌。人民调解委员会内应当在醒目位置悬挂人民调解标识和人民调解原则、范围，人民调解员名单、纪律、当事人权利义务等图版。调解室墙上要悬挂全国统一的人民调解标识，悬挂关于人民调解制度、纪律、纠纷双方当事人权利、义务等内容的版面；在标识下方设置主持人、调解员和记录员席，左右两旁各设双方当事人席，另设置必要的旁听席。

人民调解委员会印章实行全国统一规格、式样。印章为圆形，直径4.2厘米，中央刊五角星，五角星外刊人民调解委员会所在地行政区划名称或者所属群众自治组织、企业事业单位、社团组织的法定名称，自左至右环形。五角星下刊“人民调解委员会”字样，自左至右直形。乡镇、街道人民调解委员会的组成和表述是“鄂州市XX区XX乡（镇、街道、开发区）人民调解委员会”；村（居）民委员会人民调解委员会的组成和表述是“XX乡（镇、街道、开发区）XX村民委员会（社区居民委员会）人民调解委员会”；企业事业单位人民调解委员会的组成和表述是“xxx（企业事业单位）人民调解委员会”;行业性专业性人民调解委员会的组成和表述是“xx市（区）+行业、专业纠纷类型+人民调解委员会”。

（二）队伍建设

1.选任优质人民调解员。

人民调解员由人民调解委员会聘任。人民调解员应当由公道正派、热心人民调解工作，并具有一定文化水平、政策水平和法律知识的成年公民担任。

乡镇（开发区、街道）人民调解委员会最少配备1名专职人民调解员，行业性专业性人民调解委员会至少配备3名专职人民调解员。

2.抓好岗位教育培训。

初任人民调解员应当通过岗位培训；继任人民调解员应当接受年度培训。

区司法局应当定期对人民调解员进行业务培训；开发区、街道、乡镇司法所应当通过举办培训班、以会代训、经验交流、旁听庭审和推荐担任人民陪审员等多种形式对村（社区）人民调解员进行业务培训或指导，让村（社区）人民调解员了解熟悉法律政策和规范调解文书的制作，互相通报交流纠纷信息，不断提高人民调解员的法律政策水平和调解工作技能。

3.加强人民调解员管理。对不履行职责、严重失职、不能正常发挥作用的人民调解员，及时予以撤换或解聘。人民调解员调解纠纷时应佩戴人民调解员徽章。

（三）工作程序

1.明确受理范围。人民调解委员会受理纠纷的范围是：发生在公民与公民之间、公民与法人和其他社会组织之间，涉及民事权利义务争议的各种纠纷。不得受理法律法规规定只能由专门机关管辖处理的，或者法律法规禁止采用调解方式解决的纠纷。

当事人可以向人民调解委员会申请调解，人民调解委员会也可以主动调解，当事人一方拒绝调解的，不得调解。

2.规范调解程序。人民调解委员会调解纠纷应当做好调解前的准备工作，必要时可以邀请有关人员和相关人民调解委员会共同调解。人民调解员应当主动告知当事人在调解活动中的权利义务，充分听取双方当事人对纠纷事实的讲述，认真做好调查取证工作，讲解有关法律、法规和国家政策，耐心疏导，在当事人平等协商、互谅互让的基础上提出纠纷解决方案，帮助当事人自愿达成调解协议。

3.严格协议书制作。经人民调解委员会调解达成调解协议的，可以制作调解协议书，人民调解协议书必须按照司法部人民调解文书格式的要求严格制作。当事人认为无需制作调解协议书的，可以采取口头协议方式,人民调解员应当填写人民调解口头协议登记表。

4.督促协议履行。人民调解协议达成后，双方当事人认为有必要的，可以自调解协议生效之日起30日内共同向人民法院申请司法确认，以便双方更好地履行调解协议。人民调解委员会应当对调解协议的履行情况适时进行回访，并就履行情况做出记录，督促当事人履行约定的义务。发现人民调解协议内容不当的，在征得各方当事人同意后，可以再次进行调解达成新的调解协议。

5.定期立卷归档。人民调解委员会调解纠纷，一般应当制作调解卷宗，一案一卷。纠纷调解过程简单或者达成口头调解协议的，可以多案一卷，定期集中组卷归档。

调解卷宗文书格式统一参照司法部《关于印发人民调解文书格式和统计报表的通知》（司发通[2010]239号)执行。调解卷宗主要包括：封面、目录、人民调解申请书（人民调解受理登记表）、人民调解调查记录、人民调解证据材料、人民调解记录、人民调解协议书（人民调解口头协议登记表）、人民调解回访记录、司法确认有关材料、卷宗情况说明、封底。其中，封面“卷号”乡镇（村）级调委会统一填写“xx乡（镇、街道）或xx村（社区）人调字[20xx]xx号”，行业性专业性调解组织统一填写“xx市（区）+行业属性+调字[20xx]xx号”

调解卷宗保管期限分为短期、长期、永久三种，短期保管期限为5年；长期保管期限为10年。

（四）工作制度

1.健全人民调解工作制度。人民调解委员会应当建立健全岗位责任制、例会、学习、考评、业务登记、统计和档案等各项规章制度，用制度管人，靠制度办事。

2.规范人民调解统计与报送。人民调解委员会应当及时、准确、如实填报人民调解工作统计表，杜绝迟报、虚报、漏报现象的发生。加强人民调解统计分析，把握民间纠纷的产生发展变化规律，提高人民调解的主动性和针对性。

（五）经费保障

按照《人民调解法》第六条“县级以上地方人民政府对人民调解工作所需经费应当给予必要的支持和保障”的规定和财政部、司法部《关于进一步加强人民调解工作经费保障的意见》（财行〔2007〕179号）以及《省财政厅省司法厅关于进一步加强人民调解工作经费保障的意见》（鄂财行发[2014]74号）、市财政局市司法局关于转发《省财政厅省司法厅关于进一步加强人民调解工作经费保障的意见》（鄂州财行发[2014]640号）的通知精神，认真做好人民调解各项经费的测算工作，积极争取将全市各级司法行政机关指导人民调解工作经费、人民调解委员会补助经费、人民调解员的补贴经费、专家咨询补贴经费等列入同级财政预算。

三、工作要求

（一）提高认识。要把开展人民调解委员会规范化建设工作摆上重要位置，列入议事日程，加强组织领导，将规范化建设工作要求落实到每个人民调解委员会，不留空白和死角，确保取得实效。

（二）加强指导。要将村（社区）、乡镇（街道）人民调解委员会作为规范化建设工作的重点，深入一线，面对面进行指导，督促辖区人民调解委员会进行自查自纠，逐步完善。

（三）争取支持。要以开展规范化建设工作为契机，对人民调解委员会难以解决的工作场所、办公设施、工作经费和人员补贴等实际困难，及时汇总，主动汇报，争取党委政府和主管部门支持，切实加以解决。

（四）推动工作。要以开展人民调解委员会规范化建设工作为抓手，进一步加强和改进人民调解工作，拓宽人民调解工作范围，提高调解质量，提升人民调解社会影响力，推动人民调解工作实现新发展。

（五）培植典型。要通过开展人民调解委员会规范化建设工作，发现、培植典型，及时总结推广它们的典型经验和做法，逐步提高辖区内人民调解委员会规范化建设水平。

2017年1月16日
