# 关于2019年高考、中考期间协助备考的通知

市住建局

失效日期：

各区住建局，全市各建筑施工企业、物业服务企业，各工程项目部：

2019年高考、中考即将临近，为了给广大考生营造一个“舒适、安宁、卫生、便捷”的学习和休息环境，现就高考（2019年6月7日至6月8日）、中考（6月20日至6月21日）考试时段全市建筑工地、物业管理小区有关行为通知如下：

一、全市各考点及考生集中入住的宾馆酒店、居民区周边的建筑工地，以及各物业管理小区内的装修场所，自考试前一天下午6时起一律停止施工，至考试后第二天恢复正常施工。

二、各物业小区露天场地组织娱乐活动时，不得发出噪音干扰他人休息。

三、小区车辆出入请勿争道、禁止鸣笛，特别是早上外出，请提前降速，安全有序行驶，避免发生拥堵。

请各有关单位和人员自觉关爱考生、互帮互助，做好以上工作，市有关部门将在考试时段内组织巡查。

鄂州市住房和城乡建设局

2019年5月27日
