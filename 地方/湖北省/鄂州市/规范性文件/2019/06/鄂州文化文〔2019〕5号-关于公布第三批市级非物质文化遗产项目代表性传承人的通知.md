# 关于公布第三批市级非物质文化遗产项目代表性传承人的通知

各区文化和旅游局，葛店开发区社发局，各综合文化馆、站，市直有关单位：

按照《中华人民共和国非物质文化遗产法》和《湖北省非物质文化遗产条例》的有关要求，为鼓励和支持非物质文化遗产传承人开展传习活动，加强我市非物质文化遗产保护工作，市文化和旅游局组织开展了第三批鄂州市非物质文化遗产项目代表性传承人的申报评审工作。经各地申报、专家评审、公示等程序，确定朱青等19人为第三批市级非物质文化遗产项目代表性传承人，现予以公布。

市级非物质文化遗产项目代表性传承人是我市非物质文化遗产的重要承载者和传递者，掌握着非物质文化遗产的丰富知识和精湛技艺，是非物质文化遗产活态传承的代表性人物。各级文化主管部门要坚持“保护为主、抢救第一、合理利用、传承发展”的工作方针，鼓励和支持非物质文化遗产项目代表性传承人开展传承传播活动，切实做好非物质文化遗产保护传承工作，努力推动中华优秀传统文化创造性转化和创新性发展。各位传承人要认真履行义务，积极开展传承活动，为全市非物质文化遗产保护工作做出新的更大的贡献。

特此通知。
