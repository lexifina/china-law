# 关于全市工程造价咨询企业专项检查违规问题整改情况的通报

发文单位：

市住房和城乡建设局

发布日期：

效力状态：

有效

生效日期：

2019年11月13日

失效日期：

各工程造价咨询企业、各有关单位：

2019年8月中下旬，市住建局组织专项检查组开展了全市工程造价咨询企业专项检查，并重点检查了造价咨询企业在鄂州设立的分支机构。检查中发现部分造价咨询企业鄂州分公司存在以下主要问题：专业技术力量薄弱，没有注册造价工程师执业；违反建设部令第149号第二十三条规定，未在规定的时间内办理分公司备案手续。专项检查组针对存在的问题下达了《责令整改通知书》。

为规范工程造价咨询市场秩序，提升工程造价咨询工作质量，现对未整改落实的湖北中天宏建设项目管理有限公司鄂州分公司、湖北中南华大建设项目管理有限公司鄂州分公司（均为造价咨询乙级资质）提出通报批评，并责令设立分支机构的上述两家企业迅速采取措施整改到位。在未完成整改期间，上述两家企业及其分支机构在鄂州区域内暂时停止工程造价咨询执业活动。如发现仍开展执业活动，市住建局将严格按照有关规定处理。

特此通报。
