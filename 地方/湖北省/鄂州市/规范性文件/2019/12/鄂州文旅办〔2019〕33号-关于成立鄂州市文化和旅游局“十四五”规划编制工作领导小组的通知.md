# 关于成立鄂州市文化和旅游局“十四五”规划编制工作领导小组的通知

局属各单位、局机关各科室：

“十四五”规划是开启全面建设社会主义现代化国家新征程的第一个五年规划，是推进文化和旅游领域治理体系和治理能力现代化，推动文化、旅游、体育、广电业深度融合发展的关键时期，编制并贯彻实施好文旅事业“十四五”规划事关长远，意义重大。根据《市人民政府办公室关于印发鄂州市“十四五”规划编制工作方案的通知》（鄂州政办发〔2019〕45号），为加强对市文化和旅游局“十四五”规划编制工作的统筹协调，经局党组同意，成立市文化和旅游局“十四五”规划编制工作领导小组，组成人员如下：

领导小组副组长负责分管领域的统筹指导工作。领导小组下设办公室，办公室设在局政策法规科，刘传坤同志兼任办公室主任。领导小组及其办公室在“十四五”规划编制完成后自行撤销。

同时，组建“十四五”规划单项规划编制工作专班，该工作专班由局机关各相关科室负责人和局属单位负责人组成，科室负责人根据职责划分负责本科室及对应局属单位或行业单位的单项发展规划编写的统筹协调工作。局属单位负责人负责本单位单项发展规划的编写统筹工作。各科室单项规划，原则上按照三定方案中科室职能划分进行编写，局属单位根据自身职能职责进行编写。单项规划主要包括：“十四五”时期艺术事业发展、现代公共文化旅游服务体系建设发展、文化旅游产业体系建设发展、文化旅游宣传推广、文化旅游体育领域行业监管（安全）及市场体系建设发展、文博事业发展、公共图书发展、非物质文化遗产保护传承、文化和旅游体育广电人才队伍建设、群众体育和竞技体育事业发展、广播电视事业发展及行业监管、文化旅游放管服建设发展、文化旅游法治综治建设发展等十三个。科室兼多个职能的可以合并编写一个单项发展规划。

“十四五”规划子规划编制工作专班主要任务是组织编写上述13项子规划，并自行组织论证；局领导小组及其办公室主要任务是与省、市相关部门对接，深入调查研究，收集汇总单项规划，统筹编制整体规划，建立规划编制目录清单，形成《鄂州市文化和旅游（体育广电）“十四五”发展规划》初稿，征求意见并报局党组审定。
