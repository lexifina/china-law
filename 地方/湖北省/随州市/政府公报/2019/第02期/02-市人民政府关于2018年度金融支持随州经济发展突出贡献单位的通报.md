# 市人民政府关于2018年度金融支持随州经济发展突出贡献单位的通报

各县、市、区人民政府，随州高新区、大洪山风景名胜区管理委员会，市政府各部门：

2018年，全市金融系统以习近平新时代中国特色社会主义思想为指导，围绕全市中心工作，奋力拼搏、克难攻坚、砥砺前行，金融资源投放取得新进展、金融改革创新取得新成果、金融风险防控取得新成效。截至2018年末，全市金融机构各项存款、贷款余额分别达到1359.8亿元和692.3亿元，同比增长9.6%和14.3%，增量贷存比达72.2%，大幅增加15.3个百分点；实现保费收入28.2亿元，增长8.8%。金融招商、金融扶贫和资本市场建设成效明显，有效促进了金融与实体经济以及金融机构内部体系的良性循环。

市政府决定对2018年度支持随州经济发展贡献突出的中国人民银行随州市中心支行等3家金融监管部门和中国建设银行股份有限公司随州分行等7家金融机构予以通报。

2019年是新中国成立70周年，是全面建成小康社会的关键之年。全市金融系统要深入贯彻习近平总书记视察湖北重要讲话精神，认真落实省委省政府、市委市政府关于金融工作的决策部署，坚持稳中求进工作总基调，以促进实体经济发展为主线，以加强金融资源投放和资本市场建设为抓手，以防范化解金融风险为保障，为助推品质随州建设作出更大贡献。
