# 市人民政府关于印发2019年全市审计项目计划的通知

各县、市、区人民政府，随州高新区、大洪山风景名胜区管理委员会，市政府各部门：

现将《2019年全市审计项目计划》印发给你们，请认真组织实施。

2019年3月18日

2019年全市审计项目计划

2019年，全市审计工作要以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，按照市委、市政府、市委审计委员会的决策部署，坚持稳中求进工作总基调，坚持新发展理念，坚持推动高质量发展，深入推进审计全覆盖，依法全面高效履行审计监督职责，更好发挥审计在服务高质量发展和建设品质随州中的重要作用。全市审计项目以“围绕中心，突出重点，提升层次，确保质量”为原则，安排政策落实、财政金融、专项资金、政府投资、经济责任、自然资源资产审计等各类项目。

一、政策落实跟踪审计

（一）政策措施落实情况跟踪审计（审计署、省审计厅统筹）

1.审计目标和重点。继续以推动中央和各级党委政府关于稳增长、促改革、调结构、惠民生、防风险政策措施落实到位，促进经济平稳运行、健康发展和转型升级为目标，围绕打好“三大攻坚战”，重点关注地方政府债务、精准扶贫精准脱贫、生态环境保护和污染防治等方面；围绕服务实体经济发展，支持民营企业发展，重点关注减税降费、政府融资性担保公司政策落实情况；围绕高质量发展，重点关注重点项目推进实施、土地出让金征收管理、重大项目招投标程序等方面；围绕保障和改善民生，重点关注公立医院改革、饮用水源地治理保护等方面，针对审计发现的问题，研究提出解决问题的对策，推动政策措施贯彻落实。

2.实施方式。“异地交叉审”与“同级审”相结合。根据省安排，派出审计组审计异地。同时，每季度由市审计局根据省审计厅统一部署的重点任务，对市本级进行跟踪审计。

二、财政审计

（二）市本级及随州高新区、大洪山风景名胜区预算执行及决算草案审计

1.审计目标和重点。全面掌握2018年市本级及随州高新区、大洪山风景名胜区财政预算编制、组织、执行及决算总体情况，重点审查收支预算编制是否完整、科学、合理，促进公共财政预算、基金预算、国有资本经营预算、社会保障资金预算体系加快建立；通过收支预算执行审计，分析预算追加调整对预算执行的总体影响；关注存量资金，分析影响资金长期闲置的因素，促进盘活资金存量，合理调动使用资金；关注资金分配环节，重点揭示资金分配周期长，资金使用效益低下等问题。同时，从体制机制层面分析原因，提出加强管理，进一步深化财政管理制度改革的意见和建议。

2.实施方式。采取“同级审”和“上审下”，对2018年市本级及高新区、大洪山风景名胜区财政预算编制、组织、执行及决算相关内容进行审计。

（三）市直部门预算执行审计全覆盖（含支持民营企业发展政策措施落实情况审计）

1.审计目标和重点。以促进预算精细化、规范化、法制化管理，推进和加大预算刚性约束、强化法规政策执行、提高部门预算资金使用绩效为目标，重点关注收支预算执行结果及差异、部门资金存量、结余（结转）资金以及项目预算编制和项目支出预算执行情况，审查总收总支数据、非税收入数据和“三公”经费、会议费和培训费使用等情况。进一步关注市直各部门财政收支管理情况、简政放权及支持民营企业发展政策措施落实情况，减少行政事业性收费政策落实情况，国有资产管理情况以及履职履责情况等。同时，通过向年度预算编制与执行效果的“两头延伸”，揭示和反映预算执行部门（单位）存在的内控管理、执行财经纪律和法规制度等方面存在的普遍性、突出性问题，提出加强管理，完善制度的意见和建议。

2.实施方式。采取“同级审”，对全市所有市直部门及所属二、三级预算单位2018年度预算编制和执行情况审计全覆盖。同时，根据财政大数据筛查情况及年度审计项目计划安排情况，对部分部门（单位）的财政财务收支进行重点审计。

三、专项审计

（四）扶贫政策落实及扶贫资金审计（省审计厅统筹）

1.审计目标和重点。以促进精准扶贫、精准脱贫政策措施贯彻落实，提高资金使用效益，确保贫困人口按计划如期脱贫为目标，在摸清扶贫资金筹集、分配、拨付、管理使用及项目实施完成情况的基础上，重点关注扶贫政策措施的落实、资金整合使用和项目实施效果情况，突出“易地扶贫搬迁项目任务完成情况”和“一卡通”惠农资金审计专题，揭露发生在贫困群众身边的腐败和作风问题，促进打赢脱贫攻坚战。

2.实施方式。“异地交叉审”与“同级审”相结合。根据省安排，派出审计组审计异地贫困县。同时，对市本级政府和相关部门2018年扶贫政策措施落实、资金管理使用及项目实施情况进行审计。

（五）社保基金审计

1.审计目标和重点。以摸清底数，保障安全，完善制度，规范管理，提高绩效为目标，在摸清各类社会保险基金规模、来源和分布的基础上，围绕防范基金风险，找准社会保险基金的主要风险点，关注各类保险政策执行、业务管理和制度衔接中存在的突出问题，推动社会保险相关政策、制度贯彻执行和健全完善。

2.实施方式。采取“同级审”，对市本级社会保险基金征收、管理、使用情况开展审计。

（六）民生资金大数据审计（省审计厅统筹）

1.审计目标和重点。按照“坚持科技强审，向信息化要资源、向大数据要效率”的要求，通过数据集中分析、疑点核查及现场审计，扩大民生资金大数据审计覆盖面，以促进惠民政策落地，提高资金使用效益为目标，重点关注民生资金政策落实、资金管理使用等情况，充分揭示和反映民生资金分配管理使用中存在的突出问题，分析问题原因，提出可行建议。

2.实施方式。“异地交叉审”与“上审下”相结合。根据省安排，派出审计组审计异地，与政策落实审计同步实施。同时，对广水市和曾都区民生资金管理使用情况开展审计。

（七）保障性安居工程资金投入和使用绩效审计（审计署、省审计厅统筹）

1.审计目标和重点。以促进全面落实棚户区改造等重大政策措施落实，保障资金安全，提高资金使用绩效，推动加快建立多主体供给、多渠道保障、租购并举的住房制度，更好地保障人民群众住有所居为目标，重点关注历年目标任务完成、采购和分配、公共租赁住房分配使用绩效、公共租赁住房和棚改项目建设、保障绩效、资金使用、领导经济责任、项目招投标程序、棚改范围和标准、棚改货币化安置、建设用地等政策落实情况。

2.实施方式。采取“异地交叉审”，根据省安排，派出审计组审计异地。

（八）市县农村饮水安全审计（省审计厅统筹）

1.审计目标和重点。围绕服务民生和乡村振兴战略，促进农村饮水安全巩固提升工程向“安全型”“稳定型”转变，确保农村饮水安全保障水平，使广大农村居民喝上更方便、稳定和安全的饮用水为目标，重点关注农村饮水安全巩固提升工程建设和资金管理使用情况，核实项目建设成本的真实性、合法性等。

2.实施方式。采取“异地交叉审”，根据省安排，派出审计组审计异地。

（九）政府融资性担保公司经营管理情况专项审计调查（省审计厅统筹）

1.审计目标和重点。以促进防范担保公司及政府的风险，规范担保公司的管理及担保行为，缓解中小微企业融资难、融资贵，充分发挥担保公司在地方经济发展中的作用为目标，审计调查围绕政府、担保公司和合作银行的关系，重点关注合作银行向担保公司收费情况，政府促进担保公司发展相关政策和资金的落实情况，以及担保公司经营管理和潜在风险情况等。

2.实施方式。采取“异地交叉审”，根据省安排，派出审计组审计异地。

（十）文物保护专项资金审计

1.审计目标和重点。以深入了解文物保护现状及文物保护资金的使用绩效，推动完善文物发掘、保护、管理工作，推进文旅名城建设为目标，重点关注国家、省级等文物保护专项资金使用情况，紧紧围绕文物保护修缮方案、立项、批复、资金拨付等关键环节，揭露是否存在文物保护相关制度不健全或执行不到位、违法违规使用专项资金及管理不规范等问题，确保充分发挥文物保护专项资金使用效益，提高文物保护成效。

2.实施方式。采取“同级审”，对我市文物保护专项资金管理、使用情况进行审计。

四、领导干部自然资源资产离任审计

（十一）领导干部自然资源资产离任审计

1.审计目标和重点。以促进生态文明建设和绿色发展为目标，以领导干部履行自然资源资产管理和生态环境保护责任情况为主线，根据被审计领导干部所在地区主体功能定位、自然资源资产禀赋特点和生态环境保护工作重点，因地制宜地聚焦土地资源、水资源、森林资源、矿山生态环境治理、大气污染防治等重点领域进行审计。通过审计，全面客观评价被审计领导干部履行自然资源资产管理和生态环境保护责任情况，揭露和查处损毁自然资源资产、破坏生态环境的违法违规问题，准确界定被审计领导干部及相关人员应当承担的责任，推动建立生态环境损害责任终身追究制，并加强审计结果运用。

2.实施方式。采取“同级审”、“结合审”，结合领导干部经济责任审计项目，同步实施自然资源资产审计工作。

五、固定资产投资审计

（十二）重点投资项目审计

1.审计目标和重点。以监管项目资金为主线，以规范项目建设程序为重点，以评价项目投资效益为目标，通过对政府投资项目和建设资金的审计监督，切实加强规范政府投资管理，遏制建设领域中的腐败行为。在全面摸清工程建设和资金管理使用情况的基础上，重点关注工程质量、环境保护、征地拆迁和资金使用等方面的问题，重点揭示违背国家产业、土地和环保政策，严重铺张浪费，侵害群众利益的问题，重点查处转移、挤占挪用建设资金，转包和违法分包工程以及工程质量低劣、损失浪费、高估冒算等重大违法违纪问题；突出关注宏观政策落实、工程质量效益、重大采购以及项目建设进度情况，确保项目建设顺利和有关政策的落实。

2.实施方式。组织对市中心医院文帝院区、氵厥水一桥等部分重点工程建设项目以及市政府交办的各项投资工程项目审计。

六、经济责任审计

（十三）经济责任审计(市经济责任审计工作领导小组交办)

1.审计目标和重点。坚持经济责任审计与自然资源资产、预算执行、专项资金等审计相结合。以促进领导干部履职尽责和推动本地区、本部门、本单位科学发展、绿色发展，实行地方党政领导干部审计全覆盖为目标，重点关注被审计领导干部任期内本地区、本部门、本单位财政收支以及有关经济活动的真实、合法和效益情况，自然资源资产管理情况，政府性债务管理情况，国有资产（资源）管理情况，政府投资项目管理情况，相关目标责任制落实情况，对直接分管部门的管理监督情况，以及遵守廉洁从政有关规定情况等，通过经济责任审计监督，促进领导干部增强履责意识和正确行使公共权力意识，提高科学决策、依法行政、依法办事水平。

2.实施方式。全市经济责任审计项目任务经市经济责任审计工作领导小组确定。

七、信息系统审计

（十四）市财政管理信息系统审计

1.审计目标和重点。以促进完善财政管理信息系统的内部管控、保障和安全机制，提升财政管理的科学化、规范化、精细化水平为目标，全面检查和评价财政管理信息系统的安全性、有效性、经济性及系统数据的真实性、完整性，揭示出信息系统存在的风险和问题，提出改进意见和审计建议。

2.实施方式。采取“同级审”，对市财政局财政管理信息系统进行审计。

八、其他

（十五）市委、市政府及市委审计委员会交办的其他审计项目

围绕品质随州建设、党政机构改革、重大政府投资等市委市政府中心工作，预留部分审计力量，按照市委、市政府、市委审计委员会领导要求，开展审计工作，为市领导决策和宏观管理提供参考服务。
