# 市人民政府办公室关于印发随州市2019年项目落地工作实施方案的通知

各县、市、区人民政府，随州高新区、大洪山风景名胜区管理委员会，市政府各部门：

《随州市2019年项目落地工作实施方案》已经市人民政府同意，现印发给你们，请结合实际，认真组织实施。

2019年3月4日

随州市2019年项目落地工作实施方案

2019年是新中国成立70周年，是落实习近平总书记视察湖北重要讲话精神、推动经济社会高质量发展的关键之年，更是拼搏赶超、建设品质随州大有可为之年。根据《省人民政府办公厅关于高质量推动2019—2020年重大项目谋划建设工作的通知》（鄂政办电〔2019〕8号）精神，为做好招商引资、项目建设和要素保障等相关工作，确保2019年实现11%的投资增长目标任务，特制定本方案。

一、强化“三库”管理

“三库”（储备库、建设库、达效库）管理是全市项目谋划、项目推进、项目建设情况最集中、最直观的综合反映，各地各部门要切实做好相关工作。

（一）编制目标计划。市发改委要会同市招商局编制招商引资项目落地计划、重大项目储备和转化计划。市县两级项目储备库的规模要达到2018年完成投资的2.5倍以上，其中5000万元以上项目投资规模占75%以上。储备库的项目年度累计转化率达到30%以上，建设库的项目年度累计转竣工转化率达到30%以上。

（二）动态更新“三库”。市发改委要会同市招商局及时将招商引资项目和策划项目入库建档，按区域、按行业、按投资额分类进行储备，每月更新，动态管理。

二、实行挂图作战

（一）编制五张进度情况表。根据全市招商引资、项目建设计划目标，编制市领导包保项目进度情况表、全市招商引资项目落地计划表、策划项目进度情况表、5000万元以上新开工项目进度表、5000万元以上续建项目进度表等5张表，各县市区对照编制目标计划。

（二）实行工作进展节点管控。各地各部门要认真对照5张表，明确每个项目的开工时间节点、竣工时间节点和前期工作关键时间节点，项目的各个节点要落实到责任单位和责任人，严格对照节点管控时序挂图作战。

三、定期集中开工

（一）定时集中开工。全市每月组织集中开工一次。从2019年2月开始，每月下旬为集中开工时间。

（二）开工方案报备。各地政府（管委会）每月20日前要将下月开工项目报市发改委汇总，由市发改委确定全市每月集中开工活动主会场和活动主题，报请市政府批准实施。

（三）开工项目通报。每月上旬，市政府督查室对上月项目集中开工情况进行通报。

四、建立调度机制

（一）旬通报。每旬向市政府报告各地各部门招商引资项目及重点项目开工情况、已开工项目建设进度情况、策划项目前期工作进展情况等，通报各地各部门相关工作督办落实情况。

（二）月调度。每月组织召开全市项目建设调度会，统筹调度项目进度，协调解决重大问题。

（三）季观摩。每季度的下月中旬，组织开展一次招商引资项目及重点项目拉练观摩活动，邀请市人大、政协领导参加，季度排名靠前的县市区政府（管委会）交流经验，排名靠后的县市区政府（管委会）作表态发言，提出整改措施。

五、强化服务督办

对5张表中的项目开辟“快车道”，提供要素保障，加快项目落地、项目建设和建成投产。

（一）开辟绿色通道。随州高新区、各县市区开发区全面启动“先建后验”工作；市、县级有关部门按照职责分工负责组织区域性统一评价、多规合一和多评合一工作；发改、自然资源和规划、住建、生态环境等部门按照“现在办、立即办、马上办”的工作要求，靠前服务、提前介入、容缺预审。

（二）强化要素保障。各地各部门要按照“保重点、保落地、保开工、保投产”的工作要求，提前编制并及时向相应主管部门上报项目要素需求计划表，坚持一事一议、急事先办、特事特办，确保土地指标、环境容量以及水电气、资金、人力、技术等要素优先保障。

六、落实工作责任

成立市招商引资项目落地和重点项目建设推进工作领导小组，由常务副市长任组长，各位副市长任副组长，各位副秘书长及市政府督查室、市发改委、市教育局、市科技局、市经信局、市公安局、市人社局、市自然资源和规划局、市生态环境局、市住建局、市交通运输局、市水利和湖泊局、市农业农村局、市商务局、市文化和旅游局、市卫生健康委、市国资委、市统计局、市民防办、市招商局、市城管执法委、市地方金融工作局、人行随州中支行、市城投公司、市建投公司和各县市区政府（管委会）分管负责人为成员。领导小组下设办公室，从相关单位抽调业务骨干2—3人，集中在市发改委办公，承担领导小组的日常工作。

各地各相关部门要严格对照“五张表”的内容逐项落实，健全跟踪督查公示机制，强化考评问责，确保按期高质量完成全市重大项目落地任务。
