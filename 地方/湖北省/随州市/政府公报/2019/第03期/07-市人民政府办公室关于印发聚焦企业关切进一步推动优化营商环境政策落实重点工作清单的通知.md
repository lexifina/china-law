# 市人民政府办公室关于印发聚焦企业关切进一步推动优化营商环境政策落实重点工作清单的通知

各县、市、区人民政府，随州高新区、大洪山风景名胜区管理委员会，市政府各部门:

为贯彻落实中央、省关于优化营商环境工作的有关精神，切实解决企业反映的突出问题，确保优化营商环境各项政策措施落到实处，打造法治化、国际化、便利化的营商环境，根据《省人民政府办公厅关于印发聚焦企业关切进一步推动优化营商环境政策落实重点工作清单的通知》（鄂政办发〔2019〕28号）要求，经市政府同意，现将《聚焦企业关切进一步推动优化营商环境政策落实重点工作清单》印发给你们，并就有关事项通知如下：

一、提高思想认识，强化责任担当。各地各部门要以习近平新时代中国特色社会主义思想为指导，认真贯彻落实党中央、国务院，省委、省政府和市委、市政府关于优化营商环境的决策部署，将优化营商环境、减轻企业负担、解决企业反映的突出问题作为“六稳”工作的重要措施，迅速制定落实优化营商环境政策的具体实施办法，明确责任主体、工作措施、完成时限和实施要求，全力消除制约企业发展的各种障碍，努力打造良好营商环境，让企业家安心搞经营、放心办企业。各地各部门主要负责同志要亲自负责，抓好统筹协调，分管负责同志要具体抓到位，并层层落实责任，确保各项政策取得实效。

二、强化考核评价，抓好政策落地落实。各地各部门要按照《清单》要求，结合工作实际，细化任务，明确路线图、时间表、任务书，抓好贯彻落实。各重点工作牵头单位要切实履行牵头抓总职责，加强统筹推进，搞好沟通协调，形成工作合力，及时研究推进政策落实面临的新情况，解决新问题，重大事项及时报市人民政府。市人民政府将建立健全营商环境督查、评价工作机制，并将优化营商环境工作纳入年终责任目标考核，定期组织开展营商环境专项督查和评价，对排名靠后、政策落实不到位的县市区政府（管委会）进行通报约谈。各地各部门要建立营商环境投诉举报和查处回应机制，及时纠正发现的问题，并公开曝光营商环境反面典型案例，对损害营商环境的单位和个人严肃追责问责。

三、加强政策宣传，引导舆论预期。各地各部门要加强对已出台营商环境政策措施的宣传解读，准确传递权威信息和政策意图，提高政策的知晓率、覆盖面。对市场主体关注的重点难点问题，要及时研究解决，回应社会关切，合理引导预期。要及时总结推广利企便民的创新做法，树立先进典型，推动形成竞相优化营商环境的良好局面。

2019年5月14日
