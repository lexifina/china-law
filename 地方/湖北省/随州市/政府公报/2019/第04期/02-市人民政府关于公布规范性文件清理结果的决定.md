# 市人民政府关于公布规范性文件清理结果的决定

(随政发〔2019〕8号)

各县、市、区人民政府，随州高新区、大洪山风景名胜区管理委员会，市政府各部门:

为贯彻落实《中共湖北省委湖北省人民政府关于印发湖北省法治政府建设实施方案(2016—2020年)的通知》(鄂发〔2016〕37号)精神，根据行政规范性文件管理的有关要求，市政府对截至2019年6月21日现行有效的以市政府及市政府办公室名义发布的规范性文件进行了清理，清理结果已经2019年6月26日市政府四届四十八次常务会议审议。现将清理结果公布如下:

继续有效的市政府规范性文件11件、市政府办公室规范性文件7件;失效的市政府规范性文件14件、市政府办公室规范性文件6件;予以修改的市政府规范性文件1件。因有效期届满失效的规范性文件但还需要作为行政管理依据的，实施单位应在60日内按程序重新提请印发。

本决定自公布之日起生效。

附件:1.继续有效的市政府规范性文件目录(11件)
