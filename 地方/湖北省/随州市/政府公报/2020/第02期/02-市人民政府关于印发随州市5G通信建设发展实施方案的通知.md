# 市人民政府关于印发随州市5G通信建设发展实施方案的通知

各县、市、区人民政府，随州高新区、大洪山风景名胜区管理委员会，市政府各部门：

现将《随州市5Ｇ通信建设发展实施方案》印发给你们，请认真组织实施。

2020年4月15日

随州市5Ｇ通信建设发展实施方案

为进一步贯彻全省“一芯两带三区”发展战略和品质随州建设要求，抢抓5Ｇ发展新机遇，加快我市产业数字化、网络化、智能化转型，根据《省人民政府关于印发湖北省5Ｇ产业发展行动计划（2019—2021年）的通知》（鄂政发〔2019〕18号）精神，特制定本方案。

一、发展目标

——网络建设目标：到2021年，全市网络建设累计投入达到15亿元，力争建设5Ｇ基站3000个以上。逐步实现随州城区及主要乡镇和发达农村的5Ｇ网络全覆盖。

——行业应用目标：推动5Ｇ技术应用，融合随州区域特色，重点发展工业互联网、智能联网汽车、ＡＲ远程巡检、远程医疗、智慧教育、智慧旅游、智慧农业等行业应用，将随州打造成具有重要影响力的5Ｇ产业发展先行区。

二、重点任务

（一）加快5Ｇ网络基础建设

1．加快编制5Ｇ基础建设规划。按照4Ｇ／5Ｇ并行的原则，在我市存量基站建设规划的基础上，编制随州市5Ｇ基础建设发展规划，将5Ｇ基础建设规划纳入国土空间规划和城市通信基础设施专项规划。将5Ｇ基础站址、机房及管线、电力等配套设施纳入市政基础设施规划。优化审批流程，确保新、改、扩建民用建筑及公共基础设施的通信设施与建筑主体同时设计、同时施工、同时验收，以适应5Ｇ网络建设需要。

2．实施5Ｇ统筹布局。按照统筹规划、分步实施、新站旧站并用、宏站微站结合的原则，分步实施5Ｇ基站建设，推进5Ｇ网络商用步伐。优先覆盖万达商圈、解放路、高铁南站、一河两岸等热点地区，率先完成20个5Ｇ试验网基站的建设任务；2020年计划5Ｇ建设延伸至随州市一般城区、县城城区、交通干线等区域，包含城南新区、曾都经济开发区、随县城区、广水市城区、高铁高速以及3Ａ级以上景区，实现城区、县城、重点交通干线的5Ｇ连续覆盖。2021年力争建成5Ｇ基站3000座以上，主要涵盖城区，实现县城深度覆盖和乡镇连续覆盖，37个乡镇均实现5Ｇ信号连续覆盖，以满足随州地区5Ｇ发展应用需求。各地、各相关单位要结合旧城改造，做好通讯设施迁改工作。

3．推动社会资源共享。将现有满足安全运行条件的路灯杆、监控杆、电力杆等社会杆塔资源向5Ｇ网络建设逐步开放，避免通信杆塔重复建设。免费开放公路、铁路、桥梁、隧道、港口、车站、服务区、市政绿地、公共地下空间等公共区域；免费开放学校、医院、旅游景点等公共场所；免费开放党政机关、事业单位、国有企业非涉密楼顶屋面及公共区域，为5Ｇ网络设施建设提供便利。推动满足安全运行条件的市政路灯杆、交警监控杆、电力塔、管道、住宅小区和商业楼宇等资源，在双方协商下开放共享，支持5Ｇ基础建设。探索推进5Ｇ“多杆合一”建设，完善设计规范，在城区道路统筹建成集市政照明、城市监控、交通信号、通信基站、环境监测、应急广播等功能于一体的综合杆塔，实现“多杆合一”，加强资源共享。鼓励铁塔公司和基础电信运营公司在开发区、城南新区等新建主干道开展“多杆合一”示范道路的合作建设。

（二）推动5Ｇ规模化示范应用

1．推动工业领域应用。加大5Ｇ在重点产业应用，助力企业提质增效。支持在专用汽车产业开展试验场区5Ｇ无人驾驶应用，支持ＶＲ（虚拟现实）／ＡＲ（增强型虚拟现实）／ＭＲ（混合现实）在制造企业应用，支持传统产业优化升级，对专用汽车产业30公里长廊实施智能化改造。推动智慧园区应用，支持5Ｇ网络技术在产业园区安全、管理、经营和服务环节应用。

2．推动智能网联汽车应用。积极开展交通状态监控与评估系统、应急指挥及救援系统、交通运行控制系统、无人驾驶体验区、智能停车系统等的示范应用。

3．推动智慧农业应用。推进5Ｇ应用与农业生产、经营、管理、销售等环节加速融合，启动开展农业全过程无人作业实验，在随州香菇产业、尚市葡萄园基地等领域开展5Ｇ技术应用，实现精细化种植管理，促进农产品增收。

4．推动智慧旅游应用。聚焦随州文化和旅游资源，打造智慧景区、智慧文化场馆，利用5Ｇ新技术，大力推广随州炎帝故里文化旅游区、大洪山景区、西游记公园、千里银杏谷、随州博物馆等文化旅游景点，提升随州旅游文化的发展。

5．推动智慧教育应用。将高校、中小学校纳入随州5Ｇ网络建设重点区域，探索5Ｇ技术在教育领域的应用，推动智能教育在全息远程互动教学、校园智能化管理等领域应用，缓解城乡、区域师资力量配比不平衡的问题，促进优质教育资源共享，助力城乡教育公共服务均等化。

三、保障措施

（一）建立协调推进机制。各牵头单位和责任单位要围绕5Ｇ网络建设目标，认真履行职责，加强协作配合，切实帮助建设单位解决运营过程中的机房和基站选址、环保审批、用地预审、管道建设、台站审批、电力引入、设施保护、基站租金、转供电价格、管道租赁、光交建设、光缆布放、共建共享等困难和问题，对规委会审议事项涉及铁塔相关业务的征求铁塔公司意见。全力推进5Ｇ网络建设与发展。完善政产学研合作和产业链协作机制，推动行业主管部门、基础电信运营商、应用示范单位在标准制定、测试验证及示范应用等方面开展合作协作。

（二）统筹优化共建共享。强化共建共享、集约发展的大局意识，各级政府部门、企事业单位要大力支持5Ｇ共建共享，铁塔公司做好共建共享统筹工作，实现资源优化。推进新建公共楼宇、广场、园区、公共设施等区域的网络同步覆盖。

（三）加大5Ｇ建设政策支持。各地各有关部门要为5Ｇ建设提供政策保障。积极争取国家、省新一代信息基础设施建设和产业发展项目基金，支持我市5Ｇ网络建设、产业发展、科技创新和应用普及。自然资源和规划、住建、供电、市场监管、发改等部门要按照各自职能，为5Ｇ网络建设开辟绿色通道，给予政策支持。房地产开发企业、物业服务企业等单位不得违规收取通信设施进场费、协调费、分摊费等不合理费用。

（四）强化5Ｇ网络安全保障。严格落实网络安全法和移动互联网安全标准规范，建立涵盖5Ｇ网络安全、终端安全、应用场景安全、数据安全的多层次5Ｇ网络安全保障体系。按照有关规定，确需改动或者迁移电信设施的，依据市、县人民政府规定的标准进行补偿。严厉打击和治理盗窃、破坏公用电信设施的违法违规行为，确保通信网络正常运行。

（五）开展5Ｇ法律法规宣传。加大宣传力度，将通信基础设施建设和保护的法律法规宣传、电磁辐射知识的科普宣传纳入各类普法宣传、公益宣传、健康宣传的范围，引导公众正确认识电磁辐射，增强支持通信基础设施建设和保护的法律意识、责任意识。
