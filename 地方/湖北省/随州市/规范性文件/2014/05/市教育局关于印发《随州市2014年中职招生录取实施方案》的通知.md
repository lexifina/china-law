# 市教育局关于印发《随州市2014年中职招生录取实施方案》的通知

各县、市、区教育局，市直各有关学校，各中职学校：

现将《随州市2014年中职招生录取实施方案》印发给你们，请遵照执行。

2014年5月12日

随州市2014年中职招生录取实施方案

根据《省教育厅关于做好2014年高中阶段学校招生工作的通知》（鄂教发〔2014〕3号）精神，坚持公开、公平、公正原则，努力实现普职比大体相当的工作目标，确保2014年中职招生全市统一录取工作顺利实施，特制定本方案：

一、招生计划

鼓励中职学校在办学条件许可范围内招足。

二、招生范围

中职学校招生不受学校属地限制，鼓励中职学校面向中西部地区招生。

三、志愿填报

参加随州市2014年中考的考生，在填报普通高中志愿时同时填报中职志愿。填报志愿在“湖北省高中阶段学校招生管理信息系统”上进行。直接填报中职志愿，而没有填报普通高中志愿的考生，将优先录取，优先享受国家资助金。参加中考的应届考生具备填报“五年一贯制”和“3+2”学校（专业）志愿资格。

四、录取注册

（一）参加中考的考生以及未参加中考的应、往届初、高中学生具备录取到中职学校的资格。

（二）学籍注册在市招委构建的统一招生平台下，按2013年秋季注册流程进行。

（三）禁止在普通高中就读注册中职学籍。

（四）禁止未经审批，中职学校设立分校和校外班。

五、统筹招生宣传

实行市教育局统筹中职招生宣传工作。

（一）在市招委构建的统一招生平台下，市教育局统一组织编印中职招生宣传册，各县（市、区）教育局组织免费发放至每一位初中毕业生手中。

（二）统筹报刊宣传。各中职学校招生简章将由市教育局在《随州日报》上统一刊登。

（三）各中职学校须单独在《随州日报》等媒体刊发招生宣传广告的，必须经市教育局审核。

（四）凡是未经市教育局审核的宣传名册等，各县（市、区）教育局和初中毕业生学校不予受理。

六、收费

按鄂教财〔2006〕8号、鄂价费规〔2013〕110号、鄂价费规〔2013〕215号等文件执行。各校务必在招生前通过学校公示榜和新闻媒体向社会公布本学校收费标准。

七、工作要求

统筹管理中职学校招生工作，是我市理顺招生关系，规范招生行为的一项重大举措。 各县（市、区）教育局、各招考机构和招生学校要向社会全面彻底公开招生政策、招生计划、录取标准、录取结果、收费标准、咨询和投诉办法、收费违规问题处理结果等。

初中毕业生学校不得限制或强迫初中毕业生选报志愿，不得更改学生上网密码，不得扣压有关学校录取通知书，不得扣压市教育局统一组织编印的中职招生宣传册或以此名义收取费用；招生学校不得进行有偿招生，不得抢拉生源，搞恶性竞争。各地教育行政部门要深刻认识这项工作重大而深远的意义，要切实加强领导，确保2014年中职招生工作有序、高效、阳光运行。
