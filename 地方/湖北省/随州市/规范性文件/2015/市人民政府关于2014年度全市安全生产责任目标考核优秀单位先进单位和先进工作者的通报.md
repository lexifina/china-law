# 市人民政府关于2014年度全市安全生产责任目标考核优秀单位先进单位和先进工作者的通报

各县、市、区人民政府，随州高新区、大洪山风景名胜区管理委员会，市政府各部门：

2014年，在市委、市政府的正确领导下，全市各地、各部门认真贯彻省委省政府、市委市政府关于安全生产的决策部署和指示精神，扎实推进安全生产各项工作，全市安全生产形势持续稳定好转。

为了总结成绩，表彰先进，经市安委会考核和各地各部门推荐，市人民政府决定授予广水市人民政府等4个单位为“2014年度全市安全生产工作责任目标考核优秀单位”，授予随县人民政府等22个单位为“2014年度全市安全生产工作先进单位”，授予孙登科等21名同志为“2014年度全市安全生产工作先进工作者”。

希望受表彰的先进单位和个人，珍惜荣誉，戒骄戒躁，再接再厉，再创佳绩。各地、各单位要以先进为榜样，扎实抓好安全生产工作，促进全市安全生产形势进一步明显好转。

附件：2014年度全市安全生产工作责任目标考核优秀单位、先进单位、先进工作者名单

2015年3月4日
