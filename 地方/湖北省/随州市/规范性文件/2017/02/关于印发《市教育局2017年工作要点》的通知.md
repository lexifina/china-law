# 关于印发《市教育局2017年工作要点》的通知

2017年是实施“十三五”教育发展规划的重要一年，全市教育系统要深入学习贯彻党的十八大、十八届三中、四中、五中、六中全会和习近平总书记系列重要讲话精神，坚持创新、协调、绿色、开放、共享的发展理念，以立德树人为根本任务，以深化教育综合改革为动力，以依法治教为保障，着力促进教育公平，着力提高教育质量，着力维护和谐稳定，努力办好让人民满意的教育。

一、抓学习，切实加强全市教育系统党的建设

1．深入学习贯彻党的十八届六中全会精神。利用中心组理论学习、“三会一课”、专题培训研讨等形式，按照全会精神加强和改进党建与思想政治工作，推进“两学一做”学习教育常态化制度化，推动全面从严治党要求向教育系统基层延伸，把全面从严治党的要求落实到全体党员，牢固树立政治意识、大局意识、核心意识、看齐意识，以优异成绩迎接党的十九大胜利召开。

2．加强党风廉政建设。严格执行《准则》、《条例》，全面落实中央八项规定、省委六条意见和市委实施细则要求，持续整治“四风”问题。扎实推进党风廉政建设“两个责任”落实，推进惩治和预防腐败体系建设，全面推行政务公开、校务公开。强化执纪问责，加大治理教育乱收费查处力度，促进教育公平公正。加强风险防控，完善约束机制，优化教育发展环境。

3．切实加强基层党建工作。全面落实全面从严治党主体责任，建立健全机关党建工作责任制，严格规范党内组织生活，进一步丰富和完善支部主题党日活动。加强市直教育系统党员干部思想政治教育，进一步完善基层党组织建设，继续开展直属单位党委（支部）抓党建述职评议考核工作。加强机关干部队伍建设和直属单位领导班子建设，坚持从严管理干部。加强离退休干部思想政治建设和组织建设，指导支持关心下一代工作。加强群团建设工作，充分发挥教育工会、共青团、妇委会等群团组织的职能作用。扎实开展教代会星级评估工作。

二、抓改革，稳步推进教育系统创新发展

4．科学谋划教育改革发展。全面落实全市教育事业发展“十三五”规划各项改革任务。制定《市教育局2017年全面深化教育综合改革工作实施方案》，引领全市教育持续健康发展。

5．抓好招生考试工作。深化中考招生考试制度改革，建立与湖北教育考试网互联互通的招考信息综合平台，完善中考招生信息发布制度，继续规范中考招生秩序。推进国家教育考试标准化考点升级、扩容或新建，加强标准化考点建设。进一步推进我市教育招生考试规范化管理工作，严肃考风考纪，确保各项考试工作安全、平稳、顺利进行。

6．加强教育督导工作。深化教育督导体制机制改革，推进中小学校责任督学挂牌督导工作，大力推动各县（市、区）积极争创全国中小学挂牌督导创新县（市、区）。开展“全面改薄”、教师队伍建设、校园安全和校车安全监管等专项督导。完善教育督导问责机制，加大教育督政力度，继续开展对县（市、区）党政领导干部履行教育职责督导考核，落实教育督导结果的公开、公示和使用制度。加强督导队伍建设，提请市政府做好教育督导委员会人员调整和市政府兼职督学的换届工作。

7．推进教育信息化建设与应用。认真落实市政府办印发的《国家教育信息化试点省建设随州市实施方案》精神，加快推进“三通两平台”建设，基本实现“宽带网络校校通”、“优质资源班班通”，推进“网络空间人人通”。深入开展“一师一优课，一课一名师”活动，加强信息技术在教育教学中的应用。

8．推进民办教育科学发展。鼓励社会力量依据新修订的《民办教育促进法》兴办教育，加大对民办学校（幼儿园）政策支持与扶持力度，建立健全政府补贴、政府购买服务、捐资激励等制度，鼓励社会力量以多种形式兴办教育、支持教育、提供教育服务。规范民办教育管理，做好民办教育机构资质复核、年检工作，督促依法办学。

三、抓质量，坚持各级各类教育协调发展

9．加强学校德育工作。坚持立德树人，大力推进社会主义核心价值观教育和中华优秀传统文化教育，继续抓好　“朝读经典”、“起点阅读”教育活动。积极推进研学旅行试点。继续开展“十星级文明学校”创建活动。

10．切实加强教科研工作。扎实推进课堂教学改革，深入推进高效课堂建设，继续开展“名师讲堂”活动，使课改向纵深方向发展。努力创新教研方式，组织形式多样、内容丰富的“教研下乡”活动，大力推进网络教研，注重基地学校建设，发挥基地学校示范、辐射作用。加强课程建设，认真抓好校本教研、校本课程的开发与管理。加强备考指导，增强高考备考工作的针对性和有效性。推进对外合作办学与交流。

11．继续加快发展学前教育。督促各县（市、区）做好第二期学前教育三年行动计划竣工验收审计工作，制定第三期学前教育三年行动计划。规范学前保育教育工作，推动幼儿园教玩具配备达标建设，指导幼儿园科学保教，防止和纠正幼儿园“小学化”倾向。推动各地做好普惠性民办幼儿园认定、奖补工作。做好幼儿园年审工作，开展市级示范幼儿园评估认定。

12．推动义务教育均衡发展。贯彻落实《国务院关于统筹推进县域内城乡义务教育一体化改革发展的若干意见》，推进县域内城乡义务教育一体化发展。开展义务教育质量监测，做好迎接2017年全国义务教育学科质量监测抽查工作。加强义务教育阶段学校学生学籍管理，切实做好防辍控流工作，提高普及程度和巩固率。做好义务教育基本均衡发展“回头看”，抓好整改提高工作，不断提升区域内的义务教育均衡发展水平。

13．推动普通高中优质发展。统筹高中阶段教育资源，合理确定普职招生比例。深入推进普通高中课程改革，推动普通高中多样化特色发展，完善课程改革管理制度，抓好普通高中学生综合素质评价工作。组织学习《湖北省深化考试招生制度改革实施方案》等，开展迎接新高考研讨，做好进入新高考招生前课程开设准备工作。开展普通高中走班教学、学生生涯规划等改革试点，开展交流培训。

14．夯实职业教育发展基础。巩固中职教育规模，加大中职招生力度，开展全市职业教育宣传月活动。加强教学质量监管，规范中职生文化课、技能理论课、技能操作测试统考制度，以统考促规范。积极推进现代学徒制试点，深化产教融合、校企合作，提升职业院校主动服务地方经济社会发展的能力和水平。办好全市中职生技能大赛。

15．推进学校体育美育工作。加强学校体育工作，落实阳光体育运动，扎实推进校园足球工作。举办随州市第五届中学生运动会，承办湖北省2017年北片地区校园足球联赛，组队参加省第十四届中学生运动会。做好学校公共卫生和艾滋病、结核病等疾病预防知识教育工作，开展中小学校国家学生体质健康标准测试。深入开展艺术教育活动，继续做好戏曲进校园工作，举办第四届中小学生钢琴比赛。做好军训、国防教育、双拥等工作。

16．努力办好特殊教育。启动实施《第二期特殊教育提升计划（2017—2020年）》。指导特校做好智障、聋哑儿童的教育工作。做好弱智和肢残儿童随班就读工作，提高残疾儿童少年义务教育普及水平。

17．依法推进语言文字工作。开展第20届全国推广普通话宣传周活动和省市级语言文字规范化示范学校创建，提高师生语言文字规范意识和应用能力。

四、抓保障，大力促进教育公平

18．大力推进依法治教。落实“七五”普法宣传教育规划，加强青少年法制教育，推进教育系统法律顾问制度建设。全面加强学校法治教育，大力开展依法治教、依法治校创建活动，推进教育系统依法治理、学校依法治教、教师依法执教，不断推动实现教育治理体系和治理能力现代化。认真落实权力清单和责任清单制度。

19．提高教师队伍建设水平。强化师德师风建设，加大教师培训、名师培育力度，市本级及以上培训达到3000人次以上，继续实施“2·1·5名师”培养工程。加强“随州名师工作室”建设，启动第三批随州名师评选工作，出台《随州市名师、市学科带头人、市级骨干教师管理办法》。稳步推进教师资格定期注册改革，分类推进教师职务制度改革，进一步完善聘用制度和岗位管理制度。实行区域内教师编制总控、岗位总控，建立人才引进专项通道，在编制内及时补充新教师。落实好教师待遇政策，依法保障教师合法权益。积极做好2017年农村义务教育学校新机制教师招聘工作，完善农村义务教育学校教师补充机制，按省要求对新机制教师实行“空岗补齐”，进一步完善新机制教师队伍管理。加大城乡教师交流力度，推进“县管校聘”改革。

20．大力推进“全面改薄”工作。积极争取专项资金，加大投入，改善义务教育薄弱学校基本办学条件，投入1亿元，新建、改扩建50所义务教育学校校舍4万平方米，并完善教育教学设施，提高装备水平。迎接“全面改薄”国家、省督导评估及省审计厅全面审计。

21．推进入学机会公平。督促各地实施《消除义务教育学校大班额专项规划（2016—2020年）》，完成本年度消减城区学校“大班额”任务。按照“划片招生、就近入学”的原则，规范义务教育阶段学校招生入学管理工作。做好进城务工人员随迁子女就近入学安置工作，保障流动人口子女平等接受教育。加强对农村留守儿童的关爱、教育和管理，提高留守儿童教育关爱水平。

22．加强学校后勤保障与管理工作。进一步规范学校后勤服务性收费管理，继续在全市中小学食堂推行营养食谱和“五员制”运行机制，巩固全市义务教育阶段食堂管理“一价制”成果。加强学校食堂等后勤保障管理，鼓励通过购买人力资源服务方式，提升管理水平。继续开展放心食堂、放心超市、文明宿舍、绿色生态校园等“四个创建”活动。做好随州市国家级示范性综合实践基地项目工作和随县青少年校外活动中心建设工作。

23．倾情抓好教育关爱工程。继续健全覆盖各类教育的家庭经济困难学生资助体系，按照“安全管理，精准资助，提升内涵，激发活力”的工作思路，全面落实国家各项资助政策，积极争取社会人士捐资助学。筹措资金4000万元，资助3万人次家庭困难学生，确保不让一名学生因家庭经济困难而失学。

24．全力维护校园安全稳定。加大校园安全隐患排查治理力度，进一步推进“两化”达标建设，切实增强安全隐患整治效果。继续开展“平安校园”创建工作，提高人防、物防、技防水平。定期开展学校及周边治安综合治理专项整治活动，继续加大校车安全管理力度。落实安全管理培训，加强安全教育和避灾自救及消防演练，确保学校师生安全。加大教育宣传，应对教育舆情，做好教育信访工作，做好重要节、会、敏感节点维稳工作。

25．统筹抓好其他各项工作。积极推进教育精准扶贫工作。认真做好全市新一轮“五城同创”和第七轮“三万”活动相关工作，继续做好社会治安综合治理、计划生育、文明创建、档案、保密、政务服务、人大建议和政协提案的办理等工作。
