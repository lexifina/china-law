# 市教育局市文化体育新闻出版广电局关于随州市第二届运动会暨第五届中学生运动会比赛结果的通报

各县、市、区教育局、文体局，市直各学校：

根据《市教育局 市文化体育新闻出版广电局关于举办第五届中学生运动会的通知》（随教文〔2017〕1号）精神，2017年定于3月26日—4月1日在随县一中、随州市二中和曾都区文峰学校举办全市第二届运动会暨第五届中学生运动会。此次运动会得到了各级党委、政府的高度重视和全市各高中、初中学校的广泛参与，特别是得到了随县教育局、曾都区教育局、随州市二中、随县一中、曾都区文峰学校的大力支持，使本届运动会得以圆满成功举行。本届运动会推动了我市体育工作的发展，促进了学校教学、体育训练质量和运动竞技水平的提高，并取得了运动成绩和精神文明的双丰收。现将比赛各项结果、体育道德风尚奖、优秀教练员、优秀裁判员、优秀运动员、优秀体育工作者名单予以通报（见附件）。

希望各单位进一步加强学校体育工作，巩固本届运动会取得的成果，不断深化体育教育教学改革，使学校的体育教育工作再上新台阶，进而推动素质教育的全面实施。

附件：1. 随州市第二届运会暨第五届中学生运动会成绩通报

2. 体育道德风尚奖单位名单

3. 优秀教练员名单

4. 优秀裁判员名单

5. 优秀运动员名单

6. 优秀体育工作者

2017年5月16日
