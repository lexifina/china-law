# 市人民政府关于聘请第六届市级兼职督学的通知

各县、市、区人民政府，随州高新区、大洪山风景名胜区管理委员会，市政府各部门：

为切实做好我市教育督导工作，发挥教育督导职能作用，推动全市教育事业健康发展，根据《教育督导条例》和《湖北省教育督导规定》，经各地、各学校民主推荐，市政府决定，聘请骆帮军等29名同志为随州市第六届市级兼职督学，聘期3年。

附件：随州市第六届市级兼职督学名单

2017年4月25日
