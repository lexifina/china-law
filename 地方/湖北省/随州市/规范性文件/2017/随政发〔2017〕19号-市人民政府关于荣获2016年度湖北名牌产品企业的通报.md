# 市人民政府关于荣获2016年度湖北名牌产品企业的通报

各县、市、区人民政府，随州高新区、大洪山风景名胜区管理委员会，市政府各部门：

2016年，全市上下认真贯彻落实国务院《质量发展纲要》，狠抓供给侧结构性改革和质量保障能力建设，不断强化质量发展措施，大力实施名牌战略，取得了一定成效。我市湖北省齐星汽车车身股份有限公司等6家企业生产的8种产品荣获2016年度湖北名牌产品称号。为进一步推动名牌战略的实施，引导和鼓励企业争创名牌名标，经研究，市政府决定对荣获2016年度湖北名牌产品的6家企业予以通报，并对新获得湖北名牌产品的湖北省齐星汽车车身股份有限公司、湖北江南专用特种汽车有限公司、奥龙汽车有限公司、湖北犇星化工有限责任公司4家企业各奖励人民币5万元。

希望荣获湖北名牌产品的企业勇于创新，再接再厉，不断强化企业管理和科技创新，提升品牌形象，提高产品市场竞争力。全市广大企业要向这些企业学习，狠抓产品质量，努力开拓市场，积极争创名牌产品，提升产品品质和档次，为全市产品质量的全面提高和经济社会发展做出积极贡献。

附件：随州市荣获2016年度湖北名牌产品企业名单

2017年5月24日
