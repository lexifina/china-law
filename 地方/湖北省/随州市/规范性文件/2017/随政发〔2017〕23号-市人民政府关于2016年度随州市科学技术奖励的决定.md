# 市人民政府关于2016年度随州市科学技术奖励的决定

各县、市、区人民政府，随州高新区、大洪山风景名胜区管理委员会，市政府各部门：

为大力实施科教兴市战略、人才强市战略和创新驱动发展战略，奖励为我市科技进步、经济社会发展作出突出贡献的科学技术人员和单位,根据《中共随州市委、随州市人民政府关于强力推进工业兴市战略的意见》（随发〔2010〕10号）、《市人民政府关于印发随州市科学技术奖励办法实施细则的通知》（随政发〔2013〕42号） 、《市人民政府关于印发随州市鼓励自主创新和促进科技成果转化实施办法的通知》（随政发〔2016〕33号）等有关规定，市人民政府决定，授予“新型高效洗扫吸污车”等4项成果为随州市科学技术进步一等奖，授予“分段吸入式抽真空离心鼓风机”等10项成果为随州市科学技术进步二等奖，授予“垂直循环机械式停车设备的研究与开发”等16项成果为随州市科学技术进步三等奖；对新认定的省级产业技术研究院湖北省香菇产业技术研究院奖励30万元，对湖北省电子晶硅气体材料工程技术研究中心等6家省级创新平台分别奖励10万元，对东风汽车车轮随州有限公司等18家2016年度新认定的高新技术企业分别奖励10万元。

希望受奖励的单位和个人珍惜荣誉，再接再厉，再创佳绩。全市科学技术工作者要向获奖者学习，求真务实，勇于创新，不断提高我市自主创新能力, 促进科技成果产业化，为开创“圣地车都”建设新局面、加快建设经济转型升级和创新驱动示范城市、早日建成区域性中心城市作出更大贡献。
