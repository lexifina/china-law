# 关于印发《市教育局2018年工作要点》的通知

2018年全市教育工作的总体要求是：深入学习贯彻党的十九大精神，以习近平新时代中国特色社会主义思想为指导，全面贯彻党的教育方针，以立德树人为根本任务，以高质量发展为根本要求，以深化教育综合改革为动力，以依法治教为保障，着力促进教育公平，着力提高教育质量，着力维护和谐稳定，努力办好人民满意的教育。

一、提高政治站位，切实加强党对教育工作的全面领导

1．深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神。以学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神为主线，组织多形式、全覆盖的学习培训，深入推进“两学一做”学习教育常态化制度化，扎实开展“不忘初心、牢记使命”主题教育。广泛宣讲党的十九大精神，推动习近平新时代中国特色社会主义思想进校园、进课堂、进头脑，引导全系统党员干部牢固树立“四个意识”、坚定“四个自信”，坚决维护党中央权威和集中统一领导。

2．切实加强基层党建工作。贯彻落实中组部、教育部党组《关于加强中小学党的建设工作的意见》，推进中小学校党组织和党的工作全覆盖，督促中小学党组织切实履行职责。落实全面从严治党主体责任，建立健全机关党建工作责任制，严格规范党内组织生活，进一步丰富和完善支部主题党日活动。加强市直教育系统党员干部思想政治教育，进一步完善基层党组织建设，继续开展直属单位党委（支部）抓党建述职评议考核工作。加强机关干部队伍建设和直属单位领导班子建设，坚持从严管理干部。加强离退休干部思想政治建设和组织建设，指导支持关心下一代工作。加强群团建设工作，充分发挥教育工会、共青团、妇委会等群团组织的职能作用。强化意识形态和宣传思想教育工作。

3．加强党风廉政建设。进一步压实主体责任，做好市直学校和局直属二级单位落实党风廉政建设责任制考核工作，强化考核结果运用，推动主体责任向基层延伸。加强党性党风党纪教育，扎实开展第十九个党风廉政建设宣传教育月活动。全面落实中央八项规定和省、市委实施办法要求，持之以恒正风肃纪，紧盯“四风”问题新动向、新表现，深化运用监督执纪“四种形态”，抓早抓小，防微杜渐。推进惩治和预防腐败体系建设，全面推行政务公开、校务公开。强化执纪问责，严肃整治和查处违反中考招生纪律、中小学补课乱收费等教育领域群众反映强烈的突出问题，促进教育公平公正。

二、深化教育体制机制改革，充分激发教育发展活力

4．加强教育改革统筹谋划。推动落实《关于深化教育体制机制改革的意见》，制定《市教育局2018年全面深化教育综合改革工作实施方案》，统筹推进国家、省、市确定的教育改革任务，引领全市教育持续健康发展。

5．深化考试招生制度改革。2018年秋季在高一入学新生中整体实施、全面实行考试招生制度综合改革，探索选课走班、分层教学、课程实施、班级管理、学生综合素质评价等教育教学管理改革，做好普通高中学业水平考试启动工作。研制《随州市推进高中阶段学校考试招生制度改革实施方案》。加强现有标准化考点维护管理，推进国家教育考试标准化考点升级、扩容或新建工作。进一步推进我市教育招生考试规范化管理工作，严肃考风考纪，确保各项考试工作安全、平稳、顺利进行。

6．加强教育督导工作。深化教育督导体制机制改革，切实履行督政、督学、评估监测职责。推进中小学幼儿园责任督学挂牌督导工作，开展中小学校素质教育评估和中小学校管理督导评价工作，开展“全面改薄”、教师队伍建设、推进县域内城乡义务教育一体化改革发展、义务教育优质均衡发展、校园安全和校车安全监管等专项督导。完善教育督导问责机制，加大教育督政力度，拟定开展对县（市、区）政府履行教育职责督导考核的具体实施方案，落实教育督导结果的公开、公示和使用制度。

7．提升教育信息化水平。认真落实市政府办印发的《国家教育信息化试点省建设随州市实施方案》精神，加快推进“三通两平台”建设，基本实现“宽带网络校校通”、“优质资源班班通”，推进“网络空间人人通”。深入开展“一师一优课，一课一名师”活动，做好国家、省、市“优课”遴选与推送工作。

8．推进民办教育科学发展。落实鼓励社会力量兴办教育的政策，促进民办教育健康发展。依法依规推进民办学校分类管理，规范办学行为。联合有关部门集中开展校外培训机构专项治理行动，切实减轻中小学生课外负担。

三、以办人民满意教育为宗旨，狠抓各级各类教育公平优质发展

9．加强学校德育工作。坚持立德树人，深入开展理想信念教育、社会主义核心价值观教育、中华优秀传统文化教育、生态文明教育，统筹推进中小学劳动教育、心理健康教育、国防教育、家庭教育及研学旅行。持续抓好“朝读经典”“起点阅读”和“同声诵经典”“同上一堂课”品牌建设。继续开展“十星级文明学校”创建活动。

10．切实加强教科研工作。扎实推进课堂教学改革，深入推进高效课堂建设，不断提高课堂教学效益。加强课程建设，指导校本课程开发和学校文化建设。继续开办高中名师讲堂活动。积极构建科学完善的高中教学质量监测体系，加强备考指导，增强高考备考工作的针对性和有效性。推进对外合作办学与交流。

11．提升学前教育普惠水平。发展学前教育，实施第三期学前教育三年行动计划，鼓励普惠性幼儿园发展，增加普惠性资源供给，提升保育教育质量。加大学前教育教师培训力度，提高学前教育专业教师合格率。加强保教设备配备尤其是玩教具资源建设，坚决防止和纠正“小学化”倾向。做好幼儿园年审工作，开展市级示范幼儿园评估认定。

12．推动义务教育均衡发展。贯彻落实《市人民政府关于推进县域内城乡义务教育一体化改革发展的通知》精神，积极推进县域内城乡义务教育一体化发展。指导各县（市、区）新建或改扩建一批义务教育阶段学校，增加学位供给，满足学生就学需要，督促随州城区新建白云湖初中、南郊中心小学、五丰学校，改扩建东城文峰塔小学、蒋家岗学校，建好云龙小学。推进中小学管理模式改革，推行学区化管理和集团化办学。加强义务教育阶段学校学生学籍管理，切实做好防辍控流工作，提高普及程度和巩固率。抓好义务教育基本均衡发展迎国检复查整改提高工作，不断提升区域内的义务教育均衡发展水平。

13．推动普通高中优质发展。加快普及高中阶段教育，继续提高办学质量，推动普通高中多样化有特色发展，规范普通高中招生和学籍管理。加强新高考改革前瞻性、适应性研究，实施普通高中新课改方案和课程标准，深化普通高中课程改革，指导高中学校开展学生生涯规划指导。加强高中学校教学资源和保障条件建设。

14．推进职业教育产教融合发展。坚持普职协调发展，巩固中职教育规模，加大中职招生力度，开展全市职业教育宣传周活动。加强教学质量监管，规范中职生文化课、技能理论课、技能操作测试统考制度，以统考促规范。积极推进现代学徒制试点，深化产教融合、校企合作，提升职业院校主动服务地方经济社会发展的能力和水平。办好全市中职生技能大赛，组织好参加省级技能大赛。

15．推进学校体育美育和卫生工作。加强学校体育工作，落实阳光体育运动，举办中小学生校园足球锦标赛和足球教师培训，开展体育传统项目学校创建工作，组队参加省中学生体育项目竞赛。做好学校公共卫生和艾滋病、结核病等疾病预防知识教育工作，针对季节性传染病高发的特点，切实做好疾病防控工作。开展中小学校国家学生体质健康标准测试，指导各地各中小学校做好学生体检和幼儿入园前疫苗接种工作。深入开展艺术教育活动，举办随州市第六届编钟美育节和“大家唱、大家跳”比赛，举办随州市第五届中小学生钢琴比赛，积极参加湖北省第十一届黄鹤美育节等综合性艺术教育交流活动。继续做好戏曲进校园工作，会同文体部门开展戏曲进校园600场。做好军训、国防教育、双拥等工作。

16．努力办好特殊教育。推进实施《第二期特殊教育提升计划（2017—2020年）》。指导特校做好智障、聋哑儿童的教育工作。做好弱智和肢残儿童随班就读工作，提高残疾儿童少年义务教育普及水平。

17．依法推进语言文字工作。开展第21届全国推广普通话宣传周活动和省市级语言文字规范化示范学校创建，提高师生语言文字规范意识和应用能力。扎实开展语言文字工作督导评估示范试点工作，对曾都区政府及其有关部门语言文字工作进行督导评估，年底接受省级督导评估。

四、不断提高保障水平，大力促进教育公平

18．大力推进依法治教。落实“七五”普法宣传教育规划，加强青少年法治教育，推进法治建设示范学校创建，推进中小学全面开展章程建设，建立法律顾问制度和法治建设考评机制，推进教育系统依法治理、学校依法治教、教师依法执教，不断推动实现教育治理体系和治理能力现代化。

19．提高教师队伍建设水平。强化师德师风建设，加大教师培训、名师培育力度，市本级及以上培训达到3000人次以上，抓好“2·1·5名师”培养工程总结和成果推广工作，加强“随州名师工作室”建设。稳步推进教师资格定期注册改革，分类推进教师职务制度改革，进一步完善聘用制度和岗位管理制度。实行区域内教师编制总控、岗位总控，建立人才引进专项通道，在编制内及时补充新教师。落实好教师待遇政策，依法保障教师合法权益。积极做好2018年农村义务教育学校新机制教师招聘工作，完善农村义务教育学校教师补充机制，进一步完善新机制教师队伍管理。加大城乡教师交流力度，推进“县管校聘”改革。落实炎帝人才支持计划，切实推进“一园十基地”建设。

20．大力推进“全面改薄”工作。积极争取专项资金，加大投入，加大义务教育薄弱学校改造力度，投入5000万元实施“全面改薄”工程，推进城乡学校标准化建设，改善义务教育办学条件。

21．推进入学机会公平。督促各地实施《消除义务教育学校大班额专项规划（2016—2020年）》，完成本年度消减城区学校“大班额”任务，大力缓解“大班额”问题。按照“划片招生、就近入学”的原则，规范义务教育阶段学校招生入学管理工作。做好进城务工人员随迁子女就近入学安置工作，保障流动人口子女平等接受教育。加强对农村留守儿童的关爱、教育和管理，提高留守儿童教育关爱水平。制定普通高中消除大班额和减少超大规模学校时间表和路线图，从2018年秋启动实施。

22．完善经费保障机制。落实政府财政教育经费政策，积极争取国家、省、市教育经费投入。落实学前教育、义务教育、高中和职业教育生均拨款制度，提高各学段经费保障水平。进一步优化经费支出结构，加强教育经费使用管理，完善项目资金管理制度，加强绩效评价，提高使用效益。

23．加强学校后勤保障与管理工作。贯彻执行学校后勤“公益性”原则，规范服务性收费行为。继续在全市中小学食堂推行营养食谱和“五员制”运行机制，巩固全市义务教育阶段食堂管理“一价制”成果。积极探索学校食堂引入“托管经营”模式，提高学校食品安全管理水平。继续开展放心食堂、放心超市、文明宿舍、绿色生态校园等“四个创建”活动。做好综合实践基地项目建设工作。

24．倾情抓好教育关爱工程。继续健全覆盖各类教育的家庭经济困难学生资助体系，全面落实贫困家庭子女义务教育“两免一补”等国家各项资助政策，开展多种形式的社会捐资和资助育人活动，加强资助管理标准化建设。筹措资金4700万元，资助5万人次家庭困难学生，确保不让一名学生因家庭经济困难而失学。

25．全力维护校园安全。强化校园安全隐患排查治理力度，进一步推进“两化”达标建设，切实增强安全隐患整治效果。以开学检查为重点，对各级各类学校安全工作进行全面督导检查。严格执行学生安全三方告知书和责任书制度，落实学校、学生、家长安全责任。继续开展“平安校园”创建工作，提高人防、物防、技防水平，继续开展“三防”建设达标验收工作。加强学校消防安全，不定期开展学校用火、用电、用气和实验室危化品等安全管理和督查。持续开展校园欺凌和暴力、非法“校园贷”等专项治理。落实《湖北省校车安全条例》，加强校车安全管理。开展预案建设年活动，全面梳理、完善教育行政部门和学校各项应急预案，对各类突发事件及时有效处置。加强安全教育和避灾自救演练，确保学校师生安全。

26．持续开展校园周边环境综合治理。会同综治、公安、文体等部门，开展春、秋季开学涉校安全隐患排查整治专项行动，针对排查出的问题，实行挂牌督办、整改销号管理。积极应对舆情，完善教育领域矛盾纠纷排查化解工作制度，有效化解各类矛盾纠纷，防止群体性事件风险，做好重要节、会、敏感节点维稳工作。推进社会心理服务体系建设，着力培育理性平和的社会心态。

27．统筹抓好其他各项工作。积极推进教育精准扶贫工作。认真做好全市新一轮“五城同创”相关工作，继续做好社会治安综合治理、计划生育、文明创建、招商引资、档案、保密、政务服务、人大建议和政协提案的办理等工作。
