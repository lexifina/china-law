# 市政府教育督导室关于调整市直学校挂牌督导责任督学的通知

市直各学校，市政府有关督学：

随州市政府第五届兼职督学任期已届满，经推荐、审核产生了随州市政府第六届兼职督学。为了进一步加强市直学校责任督学挂牌督导工作，经研究，决定对市直学校挂牌责任督学进行相应调整，并就有关工作作出如下要求：

一、明确责任督学及岗位职责

（一）市直学校的责任督学挂牌督导，实行“一主两辅”督导制度，即一校一名责任督学负主责，为学校挂牌督导的主要责任人，负责组织完成市政府教育督导室安排的督导任务，形成督导报告，记录和整理督导资料；另外两名督学协助责任督学开展学校督导工作。市直各学校主责任督学和两名协助督学安排见附表一。

（二）责任督学对学校开展政府教育督导室安排的月专项督导和需要随机性开展的经常性督导。专项督导时，“一主两辅”督学要全部到校，挂牌责任督学负责组织安排两名协助督导的督学任务，督导结束后责任督学要汇总形成督导报告。经常性督导时，驻校责任督学督导为主，需要参加的协助督学人员根据工作任务轻重灵活安排。责任督学到校督导要坚持“依法监督、正确指导、深入调研、及时反馈、合理建议”的工作方针，在市政府教育督导室的指导下，采取随机听课、查阅资料、列席会议、座谈走访、问卷调查、校园巡视等方式开展随机督导工作。

（三）各学校要安排一名副校级干部，作为督导工作联络员，配合、协助责任督学开展督导工作。

二、建立评价考核制度，实施双向考核机制

为了加强对责任督学和被督导学校的管理，决定对督学和学校实行双向评价考核。

（一）对学校挂牌责任督学的考核内容

1. 责任督学到挂牌学校开展督导活动的次数。

2. 引导学校确立正确的办学理念和发展目标，引导和监督学校全面贯彻教育方针，规范办学行为，严格执行课程计划，保证学生在校1小时体育锻炼活动时间。遵循教育教学规律，全面推进素质教育。

3. 完成责任学校相关信息、报告、论文报送工作。及时推荐督导过程中发现的先进典型。

4. 严格遵守督导工作纪律，维护督学形象。

5. 将督导活动中发现的可能影响学校正常教学秩序以及违背教育规律的倾向性问题，及时向市督导办公室报告并提出意见与建议，督促学校整改问题。

6. 责任学校无安全隐患，无师生合法权益被损害，无群众举报、投诉、上访。

责任督学的评价考核工作由市督导办公室负责组织实施。每半年开展一次交流小结；每年进行一次评价考核，考核时间为当年的12月底。责任督学个人根据岗位职责在12月中下旬开展自评，同时，学校要对责任督学一年的工作表现进行一次鉴定；市教育督导办公室于12月底前组织对责任督学的工作情况进行全面考核。考核采用百分制（详见附件二），90分以上为优秀，61—89分为称职，60分以下为不称职。考核优秀的全市通报表扬；连续两年考核不称职的取消其责任督学挂牌督导资格，并在全市通报批评。

（二）责任督学对挂牌学校督导评价考核

责任督学每一年要对学校工作进行一次全面的督导评估，形成专题督导考评综合报告。主要从下面三方面评价：

1. 配合工作，落实责任情况。学校按照《国家教育督导条例》规定自觉接受责任督学的监督和指导的态度，主动配合责任督学工作情况，能如实提供与督导事项有关的文件、资料、财务账目及其他有关材料，如实反映情况。能认真研究责任督学在督导工作中提出的意见和建议，并积极落实整改。

2. 保障条件，落实“三有”情况。被督导学校为督学提供了必要的工作条件，做到了三有：有办公地点（责任督学工作室），有办公桌椅、档案柜及基本办公用品，有督导工作规章制度、并且悬挂上墙。明确一名副校级以上干部担任责任督学工作联络员，协助和配合责任督学开展督导工作。

3. 考核评估学校通过实行责任督学挂牌督导工作，是否促进了学校均衡、优质和特色发展。学校办学行为是否规范，通过督导是否推进了学校内涵发展。使学校办学条件明显改善，学校管理更加规范，办学效益明显提升，学生素质全面提高，社会对学校的满意度逐年攀升。

三、重视督导结果应用

市教育局充分重视责任督学的督导结果和建议，将其作为对学校年终综合评价、主要负责人考评问责的重要依据之一。在学校评优评先、干部任免、工作考核方面，充分听取责任督学的意见。市政府教育督导室每年对市直各学校配合责任督学开展督导工作态度、问题整改落实情况等方面进行综合评比，通报表扬先进；对拒绝、阻挠责任督学依法实施督导或不按要求整改的学校，将予以通报批评并责令改正；情节严重的将对学校主要负责人进行问责。

希望各责任督学严格按照《中小学校责任督学挂牌督导规程》要求，开展好每一次专项督导工作，同时，要按照《中小学校责任督学挂牌督导办法》（简称《办法》）要求，自主对《办法》中规定的“八项”主要事项实施经常性督导。
