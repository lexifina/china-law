# 关于做好岁末年初和全国两会期间安全生产工作的通知

2019年春节将至，全国两会即将召开，各地各学校要认真贯彻落实习近平总书记和李克强总理关于安全生产的重要批示精神，统筹做好春节和全国两会期间各项安全生产工作，全力维护教育系统安全稳定。现就有关事项通知如下：

一、切实增强安全生产责任。

各地各校要高度重视，加强领导，落实责任，把岁末年初和全国两会期间校园稳定安全工作作为头等大事来抓，尽早动手，周密安排，采取有效措施，确保安全稳定。

二、全面排查整改各类安全隐患。

在传统佳节来临之即，各地各学校要认真分析当前稳定安全工作形势，积极做好安全隐患排查整改工作。各学校要组织相关人员排查本单位安全隐患，对存在的管理漏洞和安全隐患彻底予以整改，消除安全隐患。

三、加强教育强化学生安全防范意识。

各地各校要坚持“安全第一，预防为主”的方针，要将学生安全工作放在各项工作的首位，在放假前必须对全校师生进行一次安全知识教育。要针对冬季季节特点，对学生进行用电、饮水、取暖等方面安全知识的教育，特别是防火、安全自救教育，提高学生的安全防范意识和自救自护能力，防止学生触电、烫伤、煤气中毒、火灾等意外事故发生。要教育学生在公共场所模范遵守法律法规，遵守社会公德，不在禁鞭区域内燃放烟花爆竹，注意自身安全。　各地各校在放假前夕，要充分利用家长会时间，向家长进行安全知识宣传，提醒家长带孩子外出时，一定要提高安全防范意识，要求家长加大对孩子在家期间的安全管理，防止意外事故发生。及时发现学生中出现的各种心理问题，及时与家长联系，及时开展有针对性的心理辅导和干预，积极与家长沟通并配合家长转至相应专业机构进行有针对性的心理辅导和治疗。　各地各校要广泛开展女生自尊、自爱、自律、自强意识教育活动，帮助她们形成健康向上的人格，提升女学生的综合素质，教育学生提高自我防护意识和能力，教育女生懂得洁身自爱，注意自己的言行举止，行端言稳，如何避免上当受骗；告诫女学生不当交往对学习、生活、身心健康的影响等。教育学生出门前必须向家长打招呼，告诉去向，并按时回家，不得在未告知家长的情况下擅自离家外出、在外住宿和远游，避免与陌生人、不良行为人接触，防治被拐骗、性侵、绑架或走失。与陌生人打交道时，要提高警惕，谨防上当受骗。遇到紧急情况，要用智慧机智应对，善于巧为，避免自身受到伤害。

四、切实做好“控流保学”工作。

各地教育主管部门和学校要强化家长和适龄儿童少年的法律意识，学校要建立健全适龄儿童少年和辍学学生入学、劝返复学的登记与书面报告制度，异动学生追踪工作；要建立包保责任制，加强学校与社区和家庭的联系，配合政府部门逐一做好入学和劝返复学工作。对无正当理由未送适龄儿童少年入学接受义务教育造成辍学的父母或者其他法定监护人，落实家长责任，由乡镇人民政府或者县级教育部门予以批评教育，责令限期改正；逾期不改的，由司法部门依法发放相关司法文书，督促其保证辍学学生尽早复学；情节严重或构成犯罪的，依法追究法律责任。

五、充分发挥家长学校作用。

建立“学校、家庭、社会”三位一体共育机制。要充分发挥家长学校作用，要不定期开展“学校、家庭、社会三位一体共育”研讨活动，让社会、家长理解学校教育工作，树立正确的教育观，尊重教育规律，遵循学生的成长规律，发挥好“学校、家庭、社会”三位一体的育人功能。

六、严格值守有效应对突发安全事件。

各地各校要严格落实节假日期间的值班制度，坚持领导带班、专人值班，值班电话要24小时畅通，若发生安全事故，及时上报市教育局。元旦、春节值班表要在节前报市教育局办公室。请各地各学校于2019年2月25日前将安全大检查隐患排查清单和隐患整改情况报市教育局法制与学校安全管理科。市教育局值班电话：0722—3590885。
