# 市教育局关于做好2019年义务教育学校招生入学工作的通知

各县、市、区教育局：

根据《教育部办公厅关于做好2019年普通中小学招生入学工作的通知》（教基厅〔2019〕1号）和《省教育厅基础教育处 省教育厅学前教育与高中教育处关于做好2019年普通中小学招生入学工作的通知》精神，为充分保障适龄儿童少年接受义务教育的权利，做好义务教育招生入学工作，现就做好我市2019年义务教育学校招生入学工作通知如下。

一、加强组织领导，依法保障适龄儿童少年入学

义务教育阶段学校新生招生入学工作政策性强，涉及面广，是社会关注的热点和焦点。各地要坚持以县为主，严格落实《义务教育法》等法律法规。要成立义务教育学校招生工作领导小组，建立工作机制，明确工作责任，相互协作，切实做好招生工作。各地教育行政部门和学校要做好义务教育阶段学校招生组织实施工作，建立一把手负责制，校长是学校招生工作的第一责任人。要严格按照国家和省市要求，根据人口分布及学校布局状况，制定2019年义务教育阶段学校新生招生入学工作方案和应急预案。要认真排查，严厉查处社会培训机构以“国学班”“读经班”“私塾”等形式代替义务教育行为，督促适龄儿童少年家长（或监护人）按时送孩子报名上学，保护学生的合法权利，实现适龄儿童少年接受义务教育“一个不能少”目标。

二、落实就近入学，严格执行招生计划

严格落实义务教育招生入学的县级政府主体责任，按照“科学划片招生，就近免试入学”原则，统筹推进办学模式改革及资源配置，合理划分片区，科学确定入学方式，扎实推进免试就近入学。各地教育局要科学制定招生计划，予以公布并严格执行，确保义务教育学校起始年级按照核定的招生计划招生、按照标准班额编班。各县（市、区）教育局要加强民办学校招生管理，对民办学校的办学条件和办学规模逐校进行核查，根据其办学条件、规模依法依规下达招生计划，并将下达的招生计划报市教育局备案。民办学校不得超计划招生、超班额编班。加强对公办学校招收择校生的监管，各县（市、区）要认真调查摸底，制定解决“择校热”的措施和办法，有效缓解公办学校招收择校生问题，制止招生乱象，彰显教育公平，遏制产生新的“大班额”。未经省级教育行政部门批准，任何学校（含民办学校）不得招收特长生。

三、强化追责问责，严格落实“十项严禁”纪律

任何学校（含民办学校）招生都必须遵循免试入学的原则，严格落实教育部“十项严禁”，严禁组织学科知识和能力方面的招生笔试；严禁与社会培训机构联合举办以选拔生源为目的的各类考试；严禁违反招生范围跨区域招生；严禁提前组织招生，变相“掐尖”选生源；严禁任何学校收取或变相收取与入学挂钩的“捐资助学款”；严禁义务教育阶段学校设立任何名义的重点班、快慢班。落实教育部、省教育厅有关民办学校招生要求，规范民办学校招生行为。凡违规招生的学校，一经查实，取消当年评先表彰资格，视其情节轻重给予约谈、通报批评、追究学校主要领导和相关人员的责任。对民办学校视其违规情况给予核减下一年度招生计划、停止当年招生直至吊销办学许可证等处罚。市教育局、市政府教育督导室将通过明察暗访、专项督查、随机抽查等方式对各地、各校的招生入学进行督查。对违纪违规问题，发现一起、查处一起、曝光一起。

四、倾情关注民生，做好特殊学生入学

各地各校要积极接收随迁子女就学，坚持以公办学校为主，对于公办学校学位不足的，可以通过政府购买服务方式安排在民办学校就读，满足随迁子女入学需求，保障同等受教育权利。要积极安排残疾学生尽可能在普通学校随班就读，确实不适合在普通学校就读的残疾学生，要妥善安排到特殊教育学校就读，或送教上门、医教结合。各类学校应当积极为残疾学生入学后的学习、生活提供便利和条件，落实教育优待政策。

五、严格学籍管理，做好新生报到注册和控辍保学工作

严格实行义务教育入学通知书制度，各县（市、区）教育局要制定入学通知发放办法，明确发放流程和时间，学生及家长（监护人）到划片入读学校领取县（市、区）制发的入学通知书。各级教育行政部门要把控辍保学纳入对学校考核的重要内容，加强控辍保学，建立失学辍学适龄儿童少年工作台账，落实联控联保工作机制，做好失学辍学学生劝返工作，提高义务教育巩固水平。各地各校要严格按照招生结果完成国网学籍注册工作，对9月10日仍未入学的学生，各地政府和教育行政部门要按照控辍保学方案，启动劝返程序，落实包保责任，进行逐一清查走访，依法依规劝返。

六、主动作为，公开透明，确保招生入学工作平稳有序

各地各校要切实提高政治站位，将普通中小学招生入学工作作为推进教育公平和社会公平、提升群众满意度和获得感的重要内容。各地教育局和学校要坚持公开、公平、公正的原则，细化具体措施，周密组织部署。要充分利用电视、报纸、网络等媒体，及时主动向社会公开招生方案、招生计划、招生范围、招生程序、报名条件、录取结果、咨询电话和联系人，做好对社会和家长的政策宣传和引导，主动接受社会监督。各地各学校要成立应急工作专班，按照应急预案做好矛盾化解工作，确保招生入学工作平稳有序，维护社会稳定。各县（市、区）教育局于6月28日前将义务教育学校招生工作方案、应急预案、招生工作具体联系人和联系电话报送市教育局基础教育科。

2019年6月17日
