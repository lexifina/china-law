# 市教育局关于批转随州市第二中学等学校招收体育艺术特长生实施方案的通知

各县、市、区教育局，市直有关学校：

收到随州市第二中学和曾都区第一中学关于招收体育艺术特长生的请示后，根据《市教育局关于印发〈随州市2019年高中阶段学校招生录取实施方案〉的通知》（随教发〔2019〕4号）精神，经研究，同意以上两所学校招收体育艺术特长生。现将两所学校招收体育艺术特长生实施方案批转各地，请各地、各校结合以下要求一并组织实施。

一、广泛宣传，确保招生信息在初中学校全覆盖

各县（市、区）教育局和各初中学校要认真宣传体育艺术特长生招生实施方案，并将体育艺术特长生招生实施方案张贴在学校醒目位置，确保招生信息在全市初中学校全覆盖。各招生学校要积极主动接收招生范围内符合条件的考生报名。

二、认真组考，严肃考纪，确保公平、公正

各招生学校要成立特长生招生工作领导小组，明确责任，周密组考，严格按照本校制定的特长生招生实施方案进行组考，严肃考风考纪，如遇近亲属参加考试，要严格执行回避制度。要认真检查考场设施安全，做好考试服务，确保考试工作顺利实施。市教育考试中心全程监督、参与、指导各校招生报名和考试工作，要选派人员巡视招生学校考试测试。测试成绩将于7月1日前在市教育考试中心网站公示。

三、招生范围

随州市第二中学面向全市招生，曾都区第一中学面向曾都区和随州高新区招生。

四、按时上报考试成绩

请各招生学校于6月30日17:30以前将考试成绩报市教育考试中心。
