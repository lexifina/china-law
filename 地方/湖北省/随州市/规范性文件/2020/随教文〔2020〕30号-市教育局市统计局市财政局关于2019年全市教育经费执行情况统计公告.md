# 市教育局市统计局市财政局关于2019年全市教育经费执行情况统计公告

2019年，全市教育经费总投入为321556万元，比上年的302896万元增长6.16%。其中：国家财政性教育经费（主要包括一般公共预算安排的教育经费，政府性基金预算安排的教育经费等）为246509万元，比上年的239943万元增长2.74%。

二、落实《教育法》规定的“三个增长”情况

1. 全市一般公共预算教育经费增长情况

2019年全市一般公共预算教育经费（包括教育事业费、基本建设经费、教育费附加）为240983万元，比上年的234822万元增长2.62%。

2. 各级教育生均一般公共预算教育经费增长情况

2019年全市幼儿园、普通小学、普通初中、普通高中、中等职业学校、普通高等学校生均一般公共预算教育经费增长情况是：

（1）全市幼儿园为1906.72元，比上年的1631.82元增长16.85%。

（2）全市普通小学为8057.02元，比上年的8134.45元减少0.95%。其中农村为8842.22元，比上年的8814.56元增长了0.31%。

（3）全市普通初中为14047.75元，比上年的14459.87元减少2.85%。其中农村为16036.90元，比上年的16405.35元减少了2.25%。

（4）全市普通高中为12022.19元，比上年的10615.37元增长13.25%。

（5）全市中等职业学校为7220.28元，比上年的8970.68元减少19.51%。

（6）全市普通高等学校为9329.61元，比上年的9317.77元增长0.13%。

3. 各级教育生均一般公共预算教育事业费支出增长情况

2019年全市幼儿园、普通小学、普通初中、普通高中、中等职业学校、普通高等学校生均一般公共预算教育事业费支出情况为：

（1）全市幼儿园为1927.52元，比上年的1673.78元增长15.16%。

（2）全市普通小学为8101.40元，比上年的8060.23元增长0.51%。其中，农村为8884.32元，比上年的8802.64元增长0.93%。

（3）全市普通初中为14035.54元，比上年的14369.16元减少2.32%。其中，农村为16018.21元，比上年的16436.25元减少2.54%。

（4）全市普通高中为12031.67元，比上年的10410.69元增长15.57%。

（5）全市中等职业学校为7231.60元，比上年的7646.14元减少5.42%。

（6）全市普通高等学校为8938.77元，比上年的12475.64元减少28.35%。

4. 各级教育生均一般公共预算公用经费支出增长情况

2019年全市幼儿园、普通小学、普通初中、普通高中、中等职业学校、普通高等学校生均一般公共预算公用经费支出情况为：

（1）全市幼儿园为658.45元，比上年的488.21元增长34.87%。

（2）全市普通小学为1500.97元，比上年的1437.1元增长4.44%。其中，农村为1648.80元，比上年的1442.03元增长14.34%。

（3）全市普通初中为1910.40元，比上年的1805.36元增长5.82%。其中，农村为2161.87元，比上年的1991.68元增长8.55%。

（4）全市普通高中为1844.80元，比上年的1702.87元增长8.33%。

（5）全市中等职业学校为1806.86元，比上年的1996.45元减少9.50%。

（6）全市普通高等学校为3322.31元，比上年的5171.81元减少35.76%。

三、一般公共预算教育经费占一般公共预算支出比例情况

2019年，全市一般公共预算教育经费占一般公共预算支出1579036万元的比例为15.26%，比上年的15.23%增长了0.03个百分点。
