# 市经信局办公室关于做好2018年度全省重点成长型产业集群考核和2019年度申报工作的通知

各县（市）区经信（发）局，有关行业协会：

现将《省经信厅办公室关于做好2018年度全省重点成长型产业集群考核和2019年度申报工作的通知》（鄂经信办函〔2019〕15号）转发给你们，各单位要高度重视、严格把关，按照文件要求，按时完成考核和申报工作。

请各单位将考核材料和申报材料一式三份（电子版请发至邮箱）于4月18日前报送市经信局产业政策科。
