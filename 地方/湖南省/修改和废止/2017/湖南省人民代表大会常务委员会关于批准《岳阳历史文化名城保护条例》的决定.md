# 湖南省人民代表大会常务委员会关于批准《岳阳历史文化名城保护条例》的决定

(2017年3月31日湖南省第十二届人民代表大会常务委员会第二十九次会议通过)

湖南省第十二届人民代表大会常务委员会第二十九次会议经过审查，决定批准《岳阳历史文化名城保护条例》，由岳阳市人民代表大会常务委员会公布施行。
