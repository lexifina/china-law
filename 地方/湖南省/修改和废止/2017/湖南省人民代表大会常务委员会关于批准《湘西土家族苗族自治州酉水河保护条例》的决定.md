# 湖南省人民代表大会常务委员会关于批准《湘西土家族苗族自治州酉水河保护条例》的决定

(2017年3月31日湖南省第十二届人民代表大会常务委员会第二十九次会议通过)

湖南省第十二届人民代表大会常务委员会第二十九次会议经过审查，决定批准《湘西土家族苗族自治州酉水河保护条例》，由湘西土家族苗族自治州人民代表大会常务委员会公布施行。
