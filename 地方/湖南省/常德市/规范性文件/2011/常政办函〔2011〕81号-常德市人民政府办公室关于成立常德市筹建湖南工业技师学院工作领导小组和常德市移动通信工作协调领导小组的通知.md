# 常德市人民政府办公室关于成立常德市筹建湖南工业技师学院工作领导小组和常德市移动通信工作协调领导小组的通知

各县市区人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直有关单位：

根据工作需要，经市人民政府研究，决定成立常德市筹建湖南工业技师学院工作领导小组、常德市移动通信工作协调领导小组。现通知如下：
