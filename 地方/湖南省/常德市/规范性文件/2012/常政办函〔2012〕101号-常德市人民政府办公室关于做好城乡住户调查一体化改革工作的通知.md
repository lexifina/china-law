# 常德市人民政府办公室关于做好城乡住户调查一体化改革工作的通知

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直有关单位：

为真实反映城乡居民收入水平和生活状况，更好地适应改善民生和统筹城乡发展的需要，根据国家统计局《关于印发〈城乡住户调查一体化改革总体方案〉的通知》（国统字〔2012〕22号）和国家统计局湖南调查总队、省统计局《关于做好住户调查一体化改革准备工作的通知》（湘调字〔2012〕76号）精神，现就做好我市城乡住户调查一体化改革工作有关事项通知如下：

一、充分认识城乡住户调查一体化改革的重要意义

住户调查是反映城乡居民收入、消费、就业、教育、医疗、人口和居住等状况的重要民生统计调查，关系国计民生，关系惠民政策的制定和实施。开展城乡住户调查一体化改革，有利于准确完整掌握全体居民收入、支出以及家庭就业、消费、住房等信息，及时监测农民工、贫困人口等群体的生活状况，有利于客观反映城乡之间、地区之间和不同群体之间的收入差距及其变化，对于更好地满足党和政府以及社会各界对居民生活状况信息的需要，合理调整收入分配关系，建立扩大消费需求的长效机制，促进城乡居民收入稳步增长，切实保障和改善民生，具有十分重要的意义。各级各有关部门要进一步提高思想认识，加强组织领导，高质量、高效率地做好城乡住户调查一体化改革工作。

二、工作目标

建立市县统一、城乡一体的住户调查体系，统一城镇居民和农村居民收支指标，及时准确全面地发布全体居民可支配收入等相关数据，提高政府公信力；完善住户调查制度，改进住户调查手段，提高住户调查能力和数据质量；全面反映不同收入层次居民的生活状况，为制定城乡统筹发展政策和民生改善政策提供可靠依据。

三、调查任务及时间安排

（一）2012年全市大样本框摸底调查数量为16363户，其中武陵区1564户、鼎城区2159户、安乡县2361户、汉寿县1988户、澧县1487户、临澧县1605户、桃源县1639户、石门县1981户、津市市1579户。

（二）2013年全市常规调查样本量为1080户，其中武陵区100户、鼎城区120户、安乡县130户、汉寿县130户、澧县130户、临澧县120户、桃源县120户、石门县130户、津市市100户。

（三）全市城乡住户调查一体化改革分为准备阶段和实施阶段。2012年10月底前为准备阶段，主要任务是建立一体化住户调查制度，抽选对全市和分区县市有充分代表性的住户调查样本，组织培训各级调查人员，选聘辅助调查员，清查样本小区建筑物，绘制样本小区图，登记住宅摸底表，抽选常规调查样本户。2012年11月1日起进行试记账；12月1日完成新旧住户调查网点交接工作，全市108个新一轮调查网点、1080户常规调查样本户正式开始记账。

四、积极稳妥推进城乡住户调查一体化改革工作

（一）强化组织保障。城乡住户调查一体化改革涉及面广，任务艰巨，影响深远。各区县市政府要把此项工作作为一项重要的民生基础工作来抓，建立分管领导牵头的城乡住户调查一体化改革工作领导机构，及时研究解决工作中遇到的困难和问题，在组织实施、工作经费、调查力量及改善工作条件等方面提供必要保障和支持。各级政府要将住户调查所需工作经费和调查经费纳入地方财政预算。

（二）明确工作职责。全市城乡住户调查一体化改革工作由国家统计局常德调查队负责组织实施，市、县两级政府统计部门，以及发改、财政、民政、住建、规划、房管、人社、农村工作等部门要积极支持配合。有关乡镇、街道办事处、村居基层组织要协助做好住户调查网点维稳、调查对象宣传动员工作。各新闻媒体要强化宣传优势，加大宣传力度，争取社会各界和调查对象对城乡住户调查一体化改革工作的充分理解和大力支持。

（三）确保调查质量。国家统计局常德调查队要严格按照上级有关要求，认真落实调查方案、实施步骤、质量控制、数据管理发布等工作，进一步规范管理住户调查网点，有效整合调查资源，保证改革顺利实施。各级各有关部门不得强令、授意调查机构、调查人员弄虚作假。各级统计调查机构要认真履行职责，坚持直接调查、独立调查，实事求是、独立上报，确保调查结果真实可信。
