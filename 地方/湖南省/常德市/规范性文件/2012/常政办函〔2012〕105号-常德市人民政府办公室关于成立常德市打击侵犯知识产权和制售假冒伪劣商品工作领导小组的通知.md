# 常德市人民政府办公室关于成立常德市打击侵犯知识产权和制售假冒伪劣商品工作领导小组的通知

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直有关单位：

根据工作需要，经市人民政府研究，决定成立常德市打击侵犯知识产权和制售假冒伪劣商品工作领导小组。现通知如下：

领导小组办公室设在市知识产权局，由肖忠嫦同志兼办公室主任。

今后，领导小组组成人员如有变动，由相应岗位的人员自然递补。确需行文的，由领导小组行文，报市政府办公室备案，市政府办公室不再行文。
