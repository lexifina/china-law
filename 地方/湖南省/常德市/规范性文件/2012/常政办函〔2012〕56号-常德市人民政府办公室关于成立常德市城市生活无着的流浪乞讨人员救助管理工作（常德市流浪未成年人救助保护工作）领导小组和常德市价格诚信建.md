# 常德市人民政府办公室关于成立常德市城市生活无着的流浪乞讨人员救助管理工作（常德市流浪未成年人救助保护工作）领导小组和常德市价格诚信建设工作领导小组的通知

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直有关单位：

根据工作需要，经市人民政府研究，决定成立常德市城市生活无着的流浪乞讨人员救助管理工作（常德市流浪未成年人救助保护工作）领导小组和常德市价格诚信建设工作领导小组。现通知如下：
