# 常德市人民政府办公室关于印发《2012年全市推进依法行政工作要点》的通知

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直有关单位：

《2012年全市推进依法行政工作要点》已经市人民政府同意，现印发给你们，请认真贯彻执行。

二○一二年四月九日

2012年全市推进依法行政工作要点

2012年，全市推进依法行政工作坚持以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，紧紧围绕建设“法治常德”这个主题，认真贯彻实施《国务院全面推进依法行政实施纲要》、《国务院关于加强法治政府建设的意见》（国发〔2010〕33号）、《湖南省行政程序规定》、《湖南省规范行政裁量权办法》、《法治湖南建设纲要》和市委《关于建设法治常德的意见》等政策法规，进一步推进依法行政各项工作，为建设现代常德、幸福家园提供有力的法治保障。

一、进一步落实科学民主决策

（一）不断完善重大决策听证制度。各级各部门要按照“扩大听证范围，提高听证质量”的总体要求，根据《湖南省行政程序规定》和本地区、本单位年度工作安排，深入落实调查研究、专家咨询论证、风险评估、成本效益分析、合法性审查和集体讨论相结合的决策机制。继续编制实施听证会年度计划，今年市政府举行重大行政决策听证会不少于5次，对列入《2012年市政府重大行政决策听证计划》的听证事项，市直有关单位要认真落实，按计划组织实施听证。

（二）进一步规范听证会程序。创新听证会质量管理与考核办法，严格执行公开产生听证代表、如实记录听证笔录、向社会公布听证意见采纳情况等关键程序，确保听证会公信度，提升科学民主决策水平。加强重大行政决策的合法性审查，重大行政决策方案在提交政府常务会议或者部门领导班子会议审议前由法制机构进行合法性审查。

（三）加强重大决策执行情况跟踪反馈和责任追究。努力建设诚信政府，作出的决策、承诺的事项要说到做到，坚决兑现，不打折扣。对违反决策规定、出现重大决策失误、造成重大损失的，要严格追究相关人员责任。

二、继续深入落实公正执法工作

（一）进一步完善行政处罚自由裁量权基准，严格规范行政裁量权行使。开展自由裁量权基准“回头看”工作，对行政处罚自由裁量权基准与执法实际相脱节的，及时进行修改和完善。在完善自由裁量权基准工作的基础上，进一步强化行政处罚自由裁量权基准的适用，重点加强对各级行政执法部门行政处罚自由裁量权基准适用等行政执法工作的监督检查，促进裁量权基准适用和落实。

（二）进一步推进行政执法责任制。市县两级行政部门要按照公布的“权力清单”，将执法职权与执法责任层层分解，落实到岗位和个人，做到权责一体。进一步推行行政执法指导案例制度，认真编撰发布行政执法指导案例。建立和完善行政执法绩效评估和奖惩机制，严格落实执法过错责任追究制度。

（三）进一步做好执法培训换证工作。按照全省统一部署，对行政执法人员的持证情况进行全面清理和培训换证，严格行政执法资格审查和证件管理。各区县市要进一步加大乡镇工作人员的培训力度，提高执法人员的依法办事能力。结合换证培训做好《中华人民共和国行政强制法》的学习和贯彻实施工作。

三、深入贯彻实施《湖南省政府服务规定》

（一）强化政策保障。科学制定关于就业促进、社会保险、社会救助、社会福利、住房保障等14项公共服务工作的规范性文件，逐步建立健全我市有关公共服务的规范性文件体系，完善公共服务准则和规范，引导、约束服务行为。

（二）加快服务平台建设。各级公安部门要整合公共服务资源，建立统一的报警服务平台。各级卫生部门要建立健全统一的120医疗急救指挥服务系统，规范各医疗机构急救号码，实现集中受理、统一调度。

（三）深化行政审批制度改革。严格按照国务院、省政府推进行政审批制度改革的有关要求，进一步控制、减少行政审批项目；进一步下放权力，凡可以下放的行政审批和办事服务项目，坚决下放到位；扩大区县市权限，增强县域经济活力；进一步简化审批程序、减少审批环节、压缩审批时限，建立健全岗位责任制、服务承诺制、一次告知制、首问责任制、代理制等制度，提高行政效能。严格工作纪律，强化监督检查，防止已下放的权限被上收，坚决禁止继续或变相实施已经取消或者调整的行政审批项目。

四、进一步提高规范性文件管理水平

（一）坚持“有件必审” 、“有件必登”、 “有件必备”。规范性文件草案必须经法制机构进行严格审查，确保合法性审查工作的“零失误”和“零差错”。 继续做好市本级部门规范性文件统一登记、统一编号、统一公布工作，依法纠正未经“三统一”程序发布规范性文件的行为。完善规范性文件网上公布系统、加强规范性文件网上公布管理工作。做好规范性文件报送省政府、市人大常委会备案工作，继续抓好区县市政府规范性文件备案审查。定期向社会公布通过备案审查的规范性文件目录。

（二）加强对规范性文件管理审查和“三统一”工作的监督检查。把规范性文件审查和“三统一”工作列入依法行政考核。认真处理公民、法人和其他组织提出的规范性文件审查申请，做到“有错必纠”。对违法的规范性文件，责令制定机关限期纠正；逾期不纠正的，依法予以撤销并公开通报。

五、着力提升行政复议工作水平

（一）规范行政复议案件受理和审理工作。凡符合《中华人民共和国行政复议法》及实施条例规定条件的行政复议申请，行政机关必须依法受理。进一步规范行政执法文书，落实行政复议权利告知制度。在申请方式上进一步方便当事人，加大对不予受理的监督力度。不断提高案件办理质量，着力提升案件办理效率，加大办案的和解、调解力度。注重对新类型案件的办理和研究，妥善处置群体性案件。建立健全行政复议决定履行情况反馈、责令限期履行等监督机制，确保行政复议决定得到有效落实。

（二）规范行政复议指导监督工作。加强对行政复议的筹划、组织和推动工作，认真落实重大行政复议决定备案制度，抓好宣传和培训，进一步加大行政复议指导监督力度。继续规范行政复议案件统计分析工作，保证统计的准确性和时效性，为科学决策提供依据。

六、进一步提高政府法制服务水平

（一）明确服务目标。紧紧围绕市委、市政府的中心工作开展法律服务，进一步增强做好法律服务工作的主动性、预见性和针对性，为建设“法治常德”创造良好的法治环境。

（二）突出服务重点。做好重大行政决策、重大经济活动、重大建设项目的法律服务工作。重点为政府投资、资源开发、产业规划、招商引资、合同签订等重大经济活动，提供法律意见和法律服务。

（三）完善服务机制。丰富法律服务的形式和手段，综合采取提交合法性审查报告、调研报告，出具法律意见书、行政复议意见书和建议书等形式，不断提高政府法律服务质量。

七、继续加强依法行政的组织推动工作

（一）全面开展依法行政考核工作。按照《湖南省依法行政考核办法》的要求，全面启动依法行政考核工作，将依法行政考核纳入绩效评估考核范畴。考核内容以行政程序建设为重点，主要考核重大行政决策听证会、规范性文件“三统一”、规范行政裁量权、行政复议、领导干部和公务员学法等工作。

（二）继续坚持领导干部和行政机关工作人员学法制度。继续实行市政府常务会议集体学法制度，组织开展领导干部和行政机关工作人员学法活动。加强对领导干部任职前的法律知识考查和测试，并强化行政执法人员培训。各区县市要结合“两证”换发工作，扩大工作人员法律知识培训范围，努力提升依法办事水平。

（三）深入推进政务公开。继续抓好政府信息公开有关配套制度建设，全面加强政务服务中心的建设和管理。深入推进电子政务外网平台建设，完善网上行政审批系统和行政监察系统，推行行政许可项目网上审批。不断完善电子政务内网平台，抓好协同办公系统建设，实现管理信息共享。
