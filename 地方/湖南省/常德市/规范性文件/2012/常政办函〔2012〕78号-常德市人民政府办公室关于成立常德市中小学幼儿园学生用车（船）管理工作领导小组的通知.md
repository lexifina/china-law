# 常德市人民政府办公室关于成立常德市中小学幼儿园学生用车（船）管理工作领导小组的通知

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直有关单位：

根据工作需要，经市人民政府研究，决定成立常德市中小学幼儿园学生用车(船)管理工作领导小组。现通知如下：

组长：万成贞 市人民政府副市长

成员：

陈智慧 市人民政府副秘书长

诸戈文 市教育局局长

丁克刚 市委宣传部副部长

熊连初 市监察局副局长、正处级监察员、市政协副秘书长（兼）

李培桂 市公安局副局长

刘慎松 市财政局副局长

徐世明 市交通运输局副局长

陈宏元 市安监局副局长

赵怡德 市物价局党组成员

晏丰儒 市工商局副局长

向 实 市国税局党组成员、总经济师

姚建军 市地税局副局长

杜卫雄 市交警支队副支队长

邓 威 市运管处副主任

黄 锐 市教育局纪委书记

领导小组办公室设在市教育局，由诸戈文同志兼任办公室主任，黄锐、李培桂、徐世明同志兼任办公室副主任。

今后，领导小组成员因工作变动需要调整的，由所在单位提出意见，经领导小组办公室审核，报领导小组组长批准后，由领导小组行文，报市政府办公室备案。

二○一二年六月十五日
