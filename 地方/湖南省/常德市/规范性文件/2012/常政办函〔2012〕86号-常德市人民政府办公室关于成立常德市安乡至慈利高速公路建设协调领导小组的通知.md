# 常德市人民政府办公室关于成立常德市安乡至慈利高速公路建设协调领导小组的通知

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直有关单位：

因工作需要，经市人民政府研究，决定成立常德市安乡至慈利高速公路建设协调领导小组。现通知如下：

组 长：

陈文浩　市委副书记、市人民政府市长

徐超文　市人民政府副市长

领导小组办公室设在市交通运输局，由郑德贵同志兼任办公室主任。

今后，领导小组组成人员如有变动，由相应的人员自然递补。确需行文的，由领导小组行文，报市政府办公室备案，市政府办公室不再行文。
