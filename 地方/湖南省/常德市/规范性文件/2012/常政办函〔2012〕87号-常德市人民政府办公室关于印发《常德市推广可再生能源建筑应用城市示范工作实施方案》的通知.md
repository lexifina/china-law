# 常德市人民政府办公室关于印发《常德市推广可再生能源建筑应用城市示范工作实施方案》的通知

武陵区、鼎城区人民政府，常德经济技术开发区、柳叶湖旅游度假区管委会，市直有关单位：

现将《常德市推广可再生能源建筑应用城市示范工作实施方案》印发给你们，请认真贯彻执行。

二O一二年七月二十三日

常德市推广可再生能源建筑应用城市示范工作

实 施 方 案

为贯彻落实国务院节能减排战略部署，加快推进可再生能源建筑应用城市示范工作，根据财政部、住房和城乡建设部《关于印发可再生能源建筑应用城市示范实施方案的通知》（财建〔2009〕305号）精神，结合我市实际，制定本实施方案。

一、指导思想

深入贯彻落实科学发展观，紧紧围绕建筑节能发展的总体目标，转变建筑能源需求增长方式，提升建筑节能工作水平，提高可再生能源建筑应用比例，加快推进节能减排，促进全市经济社会可持续健康发展。

二、工作目标

到2013年底，市城区（包括武陵区、常德经济技术开发区、柳叶湖旅游度假区及鼎城区武陵镇）完成可再生能源建筑应用面积271万平方米。其中，太阳能光热项目应用面积22万平方米，地源热泵项目应用面积249万平方米。

三、主要措施

（一）科学规划引导。住房和城乡建设部门要会同有关部门，对本地区可再生能源分布和可利用情况进行充分论证或评估，加强规划引导。要切实把握地源热泵技术推广的适用性和可行性，坚持适度发展，合理布局，避免盲目性和对资源的非合理利用。在实施既有建筑节能改造、棚户区改造和城市新区建设过程中，应统筹考虑可再生能源应用。

（二）加强质量管理。加强对可再生能源建筑应用项目的质量管理，在项目设计、施工、监理、验收等环节，依据国家法律法规和工程强制性标准加强监督检查和指导，对不符合现行有关标准或不能实现项目预期节能目标的要责令改正。要加强对项目的跟踪服务，指导项目加强运行管理，提高利用效率。

（三）强化技术支撑。建立完善可再生能源建筑应用监管制度与程序，在现行规定、规范的基础上不断完善技术标准，加强可再生能源建筑应用能力建设，逐步扩展应用规模，提高技术水平。着力培育专业建筑节能与可再生能源建筑应用咨询服务公司及能效检测等中介机构，加强可再生能源建筑应用宣传、标准制定、推广与竣工能效检测等咨询服务。对可再生能源建筑应用项目从技术方案论证、施工图审查、施工过程监管到竣工验收及能效测评等各个环节，做好技术指导与推广工作。鼓励设计、科研机构加强应用技术学习培训，提升科技创新能力，加快形成设计、施工、监理等系统化的专业人才体系。

（四）加大资金支持。按照突出重点、兼顾一般的原则，积极支持可再生能源示范项目工程建设、建筑应用标准制定及技术研究与信息系统建设等配套能力建设。市财政和市住房和城乡建设部门要制定完善示范项目资金管理办法，采取直接补助与以奖代补的方式，确保中央财政奖补资金落实到位。中央财政补助的专项资金实行专款专用，任何企业、单位或个人不得截留、挪用。鼓励和引导社会资金投入，放大财政补助资金使用效益。

四、组织保障

（一）加强组织领导。市政府成立可再生能源建筑应用城市示范工作领导小组，市政府分管副市长任组长，市政府分管副秘书长、市住房和城乡建设局主要负责人、市财政局分管负责人任副组长，市发改委、市住房和城乡建设局、市国土资源局、市环保局、市水利局、市规划局、市房管局、市城建投集团、市经建投集团等单位负责人为成员。领导小组办公室设在市住房和城乡建设局，负责日常联络和综合协调有关工作。

（二）明确工作职责

市住房和城乡建设局负责编制我市可再生能源建筑应用规划，制定并落实实施项目，加强推广应用配套能力建设；与市财政局共同做好可再生能源建筑应用示范项目管理，负责示范项目实施方案的审核和实施过程中的监管、验收工作；与市财政局共同确定补助方案及按相关文件审批中央财政补助资金。

市财政局负责可再生能源建筑应用城市示范工作的有关监督管理；负责中央补助资金管理、地方配套资金的筹措及补助资金审核，并及时拨付补助资金；负责推广工作经费的安排与拨付。

市发改委负责在项目可研和立项审批核准、备案时，按照本实施方案的要求对项目是否应用可再生能源予以明确，并将可再生能源投资额列入项目总投资额。

市规划局负责按照有关规定，在新建项目提出规划设计要点时对应用可再生能源提出明确要求；审批规划设计方案时把可再生能源建筑应用作为重要审评内容；审批采用太阳能热水系统建筑一体化设计时，对太阳能集热器与建筑立面的协调与统一重点审查；做好示范建设中的有关管理工作。

市经信委负责配合做好可再生能源建筑应用有关工作；负责对已建成且使用空调的公共建筑的温度实行控制管理（夏季不低于26℃，冬季不高于20℃）。

市环保局负责在环评审批阶段，按照本实施方案要求，对必须采用可再生能源建筑应用的建设项目提出环保要求；配合市住房和城乡建设局、市财政局做好示范项目建设中的有关管理工作。

市水利局负责地下水源热泵取水的水资源论证和取水许可工作；负责地下水源热泵取水设施的竣工验收工作；负责地下水源热泵取水管理；与市住房和城乡建设局联合发布关于规范地下水源热泵报批、建设和管理的规范性文件，明确地下水源热泵开采地下水的范围、条件和要求。

市房管局负责明确中心城区高档商品住宅采用可再生能源建筑应用实施要求；按照本实施方案要求，在预售价格备案时，将可再生能源应用系统设备及安装费用纳入总房价，监督开发商不得在交房时向购房户另行收取。

其他有关部门要结合工作职能，积极支持配合可再生能源建筑应用城市示范工作。

（三）广泛宣传发动。要组织相关业主单位负责人及工作人员参加技术讲座，进行经济回报分析，参观典型示范工程，让业主单位现场感受实用效果和经济效益，激发其推广利用可再生能源应用的积极性。通过报纸、电视、网络等宣传形式，广泛宣传可再生能源建筑应用城市示范工作重大意义、主要任务和相关活动，让普通市民了解节能技术，崇尚低碳生活，营造良好的工作氛围。
