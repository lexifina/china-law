# 常德市人民政府办公室关于印发《邀请市民旁听市人民政府常务会议实施方案》的通知

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直有关单位：

现将《邀请市民旁听市人民政府常务会议实施方案》印发给你们，供你们阅知。

二○一二年八月二日

邀请市民旁听市人民政府常务会议实施方案

为进一步加强市政府与人民群众之间的联系，促进政府科学民主决策，提高政府决策的社会透明度，根据《常德市人民政府会议组织办法》，制定本方案。

一、邀请旁听的议题

市人民政府常务会议对以下事项进行研究决策时，在符合保密原则的前提下，可邀请市民旁听会议：

（一）涉及重大公共利益的。

（二）涉及人民群众切身利益的。

（三）涉及社会热点、难点问题的。

二、邀请的人数和条件

每次市政府常务会议邀请2名市民旁听会议，参加旁听的市民应符合以下条件：

（一）为本市常住人口，年满18周岁。

（二）享有政治权利，具备完全民事行为能力。

（三）具备良好的思想品德和综合素质。

三、邀请对象的确立

（一）市政府办公室根据市政府常务会议议题安排情况，提出安排市民旁听会议的建议，包括安排旁听的议题、邀请旁听市民的基本情况等，报市人民政府市长决定。

（二）安排市民旁听的市人民政府常务会议，由市政府办公室将会议召开的时间和议题，提前15日在《常德日报》、常德电视台和常德政府网站发布公告，接受市民的旁听申请。

（三）市民根据公告上的联系方式报名，并持本人身份证到市政府值班室填写申请登记表，当次市政府常务会议报名截止时间为会议召开前5个工作日。

（四）市政府办公室从申请人中初步选定5名备选对象后，会同其所在地区和单位对其进行身份核查，报市政府秘书长确定2名市民旁听会议。

（五）市政府办公室于会议召开2日前向所确定的市民送达《市民旁听市人民政府常务会议通知书》，并告知会议有关情况。市民旁听市人民政府常务会议时应当出具《市民旁听市人民政府常务会议通知书》和有效身份证明，不得委托他人参加。获邀市民因特殊情况临时不能旁听会议的，应及时将情况告知市政府值班室，市政府值班室按上述程序进行人员选补。

四、其他事项

（一）会场设立市民旁听席，旁听会议的市民应在工作人员的安排下按时进入会场，并遵守会议纪律。

（二）旁听会议的市民可以就会议研究的事项提出自己的意见和建议。

（三）旁听会议的市民要妥善保管会议文件，需回收的文件应当在离会时交回。
