# 常德市人民政府关于实施粮油深加工及物流产业工程的意见

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直有关单位：

为充分发挥我市粮油资源优势，加快粮油产业化步伐，提高粮油深加工和现代物流水平，根据《湖南省人民政府关于实施粮油深加工及物流千亿产业工程的意见》（湘政发〔2010〕33号）精神，结合我市实际，现就实施粮油深加工及物流产业工程提出如下意见。

一、充分认识实施粮油深加工及物流产业工程的重要意义

我市是传统的粮油生产大市。实施粮油深加工及物流产业工程，是推动农业产业化和现代化的重要举措，是夯实农业发展基础、保障粮食安全的必然要求，是提高农业比较效益、推动农业增效和农民增收的有效途径。各级各有关部门要从我市经济社会发展大局的战略高度，充分认识粮油深加工及物流产业工程的重要意义，统一思想，更新观念，大力推进粮油产业工程实施，促进我市从粮油资源大市向粮油经济强市转变。

二、指导思想和发展目标

（一）指导思想

以科学发展观为指导，按照“发挥资源优势，促进粮油深加工和综合利用，提高粮油综合经营效益”的基本思路，以优势资源为基础，以精深加工和循环利用为主线，以政策引导为抓手，优化产业布局，转变增长方式，做强龙头企业，培育产业集群，推进品牌整合，实现粮油产业高效、协调、可持续发展。

（二）发展目标

用3-5年时间，实现全市粮油加工及物流业总产值突破200亿元。粮油加工转化率达65%，副产品综合利用率达85%，深加工和副产品综合利用成为我市粮油经济的主要增长点。建设一批具有一定规模的粮油产业园区。全市形成产值过20亿元的龙头企业3家，过10亿元的企业3家，过5亿元的企业5家，过1亿元的企业15家以上。粮油加工企业进入国家级农业产业化龙头企业达到5家以上、省级18家以上、市级28家以上。新培育1家粮油加工类上市公司。

三、主要措施

（一）大力推进粮油深加工和副产品循环利用。支持龙头企业适应市场需求提高粮油精深加工产品比例，开发特色粮油产品和专用粮油产品。重点开发稻谷及食用植物油深加工产品，推动传统粮油产品向生态、绿色、有机、营养方向发展。加强对副产品的综合利用，大力发展循环经济，提高资源利用率和产品附加值。加大科研投入，加快技术升级，开展关键技术攻关和推广。加快建立企业科技创新机制，鼓励和支持企业与科研院校合作，加快建立以企业为主体、产学研相结合、科技资源共享、技术优势互补的科技创新体系。

（二）培育产业集群和龙头企业。根据各地自然、资源禀赋条件，立足现有基础，按照优势资源向优势企业集中、优势企业向优势区域集聚的内在要求，逐步形成一批具有较大规模和集聚效应的粮油产业园区。充分发挥市场配置资源的基础性作用，打破行业、地域和所有制界限，着力推进企业战略合作和重组，培育一批规模大、实力强、技术装备先进、有核心竞争力、行业带动力强的大型龙头企业。对发展潜力较大、实力较强的龙头企业要加大扶持力度，培育成上市公司。

（三）推进现代粮食物流体系建设。积极扶持企业发展第三方物流，畅通粮油产品物流通道。加强“四散”化（散装、散卸、散储、散运）设施建设，积极开发建设粮食物流信息平台和电子交易平台，降低物流成本，提高物流效率。稳妥推进粮食物流服务标准化建设，建立完善物流服务标准化体系。加快形成以金健（广积）粮油工业城、西洞庭食品工业园、桃源县现代粮食物流中心、汉寿县现代粮食物流中心、澧县湘鄂粮食物流中心等物流园区为核心，各区县市骨干粮库为节点的现代粮食物流体系。

（四）实施品牌战略。引导企业由做产品向做品牌转变，以优势企业和优势品牌为核心，通过政府引导、市场运作、企业自愿的方式，推进品牌整合，提升粮油品牌知名度。强化品牌标准与技术支撑，提升企业质检能力和管理水平。发挥品牌对消费的引导作用，积极开拓销售市场，扩大粮油产品的市场占有率。充分利用各种媒体、会展，推介品牌，不断提高粮油品牌的知名度和美誉度。

四、加大政策支持

（一）整合粮油产业发展资金。2008年以来新增产粮大县奖励资金按照省政府规定全部用于粮油深加工及物流产业工程建设，特别是用于完善粮油收购、仓储、流通、加工等方面支出；粮食企业改制后的国有资产运营收益及处置收入纳入财政预算统筹管理，主要用于粮油企业发展和处理改革遗留问题。农业综合开发资金、产学研结合专项资金、农业产业化专项资金、科技部门“三项费用”、品牌创建奖励等各项财政专项资金优先支持粮油深加工项目。

（二）设立粮油深加工及物流产业发展专项引导资金。从2012年起，市财政每年安排100万元专项资金，用于引导粮油深加工及物流产业发展。重点支持粮油深加工和副产品循环利用、粮食现代物流体系建设、粮油仓储设施建设、品牌及资源整合等项目。各区县市根据本级财政状况，每年安排一定专项资金用于支持粮油深加工及现代粮食物流体系建设。

（三）落实税收优惠政策。对承担政府粮食收储任务的国有粮食购销企业销售的粮食免征增值税，对其他粮食企业销售的军队用粮、救灾救济粮、水库移民口粮和退耕还林粮，免征增值税。政府储备食用植物油销售免征增值税。粮油企业中经认定的高新技术企业，减按15%的税率征收企业所得税。粮油企业引进技术和进口设备，符合国家产业政策和税收政策规定的，免征进口关税。对国家级粮油产业化龙头企业给予按现行城镇土地使用税等级税额标准下降一级的优惠；对接受中央、省、市、县四级政府委托，承担粮油储备任务的粮油企业，除办公房屋及用地外，对承担商品储备业务自用的房产、土地，在2012年12月31日前免征房产税、城镇土地使用税。其他粮油企业缴纳房产税、城镇土地使用税确有困难的，可向主管地税务部门申请，由县以上地方税务机关按照税收减免管理权限审批。自2012年1月1日起至2014年12月31日止，对物流企业自有的（包括自用和出租）6000平方米以上大宗商品仓储设施用地，减按所属土地等级适用税额标准的50%计征城镇土地使用税。从事粮油加工、物流的粮油企业，按《中华人民共和国企业所得税法》及其实施条例落实企业所得税优惠政策。

（四）加强金融支持。农业发展银行要积极支持具有粮油收购资质的各类粮油企业入市收购；加大对订单生产基地、物流项目、产业园区、仓储基础设施和技术改造项目等贷款支持力度。积极争取商业银行对粮油基础建设项目直接贷款。同时，鼓励和支持企业通过发行股票、债券、产权交易、集合信托、私募股权融资等方式开展多渠道融资。在常德市境内注册的粮油企业首次公开发行股票并上市，按照《常德市人民政府关于加快金融业发展的意见》（常政发〔2010〕10号）文件的有关规定，享受各项优惠及奖励政策。

五、加强组织领导

各级各有关部门要进一步提高认识，统筹安排，精心部署，积极推进。市政府成立实施粮油深加工及物流产业工程领导小组，领导小组办公室设在市粮食局。各区县市政府也要成立相应机构，及时协调解决粮油产业发展中存在的困难和问题。粮食行政管理部门要切实担负起牵头责任，科学规划、明确目标，强化措施、加强联系，抓好有关具体工作。发展改革部门要把粮油产业发展列入当地经济社会发展总体规划。财政部门要整合财政资金，支持粮油深加工及物流产业发展。农业部门要统筹协调，根据粮油及食品消费趋势合理调整种植结构。经济和信息化部门要把粮油深加工及物流产业工程融入食品产业发展规划，加强引导和服务。科技部门要加强粮食科技项目的支持和指导。国税、地税、金融、国土资源、交通运输、电力、工商、质监等部门也要密切配合，形成合力，确保我市粮油深加工及物流产业工程顺利推进。
