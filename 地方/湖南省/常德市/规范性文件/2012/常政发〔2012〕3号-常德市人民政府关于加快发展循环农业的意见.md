# 常德市人民政府关于加快发展循环农业的意见

各县市区人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直有关单位：

循环农业是以减量化、再利用、资源化为原则，以低消耗、低排放、高效率为基本特征的现代农业发展方式。发展循环农业对转变农业发展方式、节约农业资源、保护农业环境、促进农业经济可持续发展具有重要意义。为了切实加强生态农业建设，加快发展循环农业，根据《中华人民共和国循环经济促进法》和农业部《关于继续推进发展现代农业重点行动的意见》（农发〔2008〕2号）精神，结合我市实际，现提出如下意见：

一、指导思想

以科学发展观为指导，以转变农业发展方式、构建资源节约型和环境友好型农业生产体系为目标，以发展循环农业产业、延伸农业产业链条、加强农业资源高效利用、促进农业废弃物无害化处理和资源化利用为重点，以科技创新和制度创新为动力，大力推广循环农业技术，建立和完善循环农业政策体系，加速传统农业向现代农业转变，实现农业经济与生态环境的协调发展。

二、发展目标

到2015年，建立较为完善的循环农业技术体系和运行管理机制。建设循环农业示范企业70个、示范村（区、片）70个；农作物秸秆无害化处理与综合利用率达到60%；畜禽粪便无害化处理与综合利用率达到80%；化肥使用量减少10%，化肥有效利用率提高5个百分点；农药使用量减少10%；农业投入品包装等废弃物回收利用率达到80%。农业面源污染得到有效治理，农业生态环境得到明显改善，农村居民居住环境质量得到显著提高，形成全市农村循环经济协调发展的良好局面。

三、主要任务

（一） 转变农业增长方式

推广应用节约型农业技术，改变不合理的生产方式；推广农业清洁生产技术，减少化肥、农药的投入；推广农村清洁工程，大力发展农村沼气建设，推进畜禽粪便无害化处理与综合利用；推广农业投入品废弃物处理技术，解决农业生产过程中的面源污染。

（二）促进农业资源高效利用

加强耕地资源的保育，大力推广测土配方施肥，保护和改善耕地质量；全面推进农村生活垃圾和污水、畜禽粪便等废弃物资源循环利用；保护渔业资源，实现重要渔业资源的恢复和增殖；加强农业野生植物资源保护和利用，防治外来有害生物入侵。

（三）拓展延伸农业功能

大力发展农业生物质产业，开展农作物秸秆能源化、饲料化、肥料化等综合利用。因地制宜发展甘蔗、甜高粱、甘薯等能源作物。围绕农作物秸秆、畜禽粪便、生活垃圾和污水收集处理和水、电、气综合维护，大力发展乡村物业，增加农民就业。引导发展旅游观光农业，发挥农业文化休闲功能。

（四）增强科技支撑能力

加强技术交流与合作，引进、消化、吸收国内外高新技术和先进管理方法，着力解决废弃物资源化利用、能源作物培育扩繁、土壤污染修复、节约型农业等循环农业的关键技术。加强对技术推广人员和科技示范农户的循环农业技术培训，提高发展循环农业的技术水平和能力。

四、工作措施

（一）推广节约型农业技术

1.推广节肥技术。推广化肥合理使用技术，实施有机质提升行动，增施有机肥。大力开展测土配方施肥技术指导与服务，推广测土配方施肥技术，优化配置肥料资源，合理调整施肥结构，提高肥料利用率。

2.推广节药技术。科学合理使用高效、低毒、低残留农药和先进施药机械，建立多元化、社会化病虫害防治专业服务组织，实行统一防治、承包防治等措施，进行病虫抗药性监测与治理，提高防治效果和农药利用率，减少农药用量。

3.推广节水技术。发展大棚、地膜覆盖、遮阳种植，利用滴灌、喷灌等农业节水灌溉方式；加强水环境治理和保护，禁止向农田灌溉水源排放不符合农田灌溉标准的污水。

4.推广节能技术。加快省柴节煤灶的升级换代，加强太阳能、风能等可再生能源技术的推广应用，推广节能型太阳能蔬菜大棚及畜禽舍技术，大力发展节油、节电、节煤等农业机械和渔业机械技术，降低农业装备耗能。积极推进墙体材料革新和节能建筑，推广应用高效节能产品。

（二）推进废弃物循环利用

1.实施乡村清洁工程。以自然村为基本单元，建设秸秆、粪便、生活垃圾等有机废弃物处理设施，推进人畜粪便、生活垃圾、污水等向肥料、饲料、原料的资源转化，推广化肥、农药合理使用技术，推广秸秆覆盖还田、秸秆快速腐熟还田和机械化还田技术，实现农村家园清洁、水源清洁和田园清洁，从源头防治农业生产和农村生活带来的污染。到2015年，全市20%的建制村完成农村清洁工程建设任务。

2.发展农村沼气。鼓励分散型农户以改厕、改圈、改厨为主要内容，建设户用沼气，形成“猪—沼—果（菜、稻）能源生态模式；支持集约化养殖场和养殖小区建设大中型沼气发酵池、原料处理和沼气沼渣沼液利用设施，形成养殖清洁化、废弃物资源化、种植生态化的生态农业模式。到2015年，全市建设22万口农村户用沼气，完成所有规模畜禽养殖场大中型沼气工程建设，全市畜禽粪便无害化处理率达到80%以上，规模化养殖场废水治理达标率达到80%以上。

3.推进秸秆资源利用。大力推广秸秆饲料技术、秸秆肥料技术、秸秆食用菌技术、秸秆生物反应堆技术、秸秆能源技术。到2015年，全市农村秸秆综合利用率达60%以上，新增食用菌生产企业（个体户）100家，秸秆生物反应堆技术推广面积达到10000亩以上。

（三）加强农业资源保护

开展农业野生植物调查，建立一批野生植物原生境保护区，对濒危野生植物物种进行抢救性保护。开展外来有害入侵生物风险评估和监测预警，对重点区域的外来有害入侵生物采用生物、物理、化学防治及生态修复相结合的方法，进行集中灭除，防治外来有害入侵生物的扩散和蔓延。建设农业湿地资源开发利用项目，探索农业湿地保护经验和模式。

（四）抓好试点示范

把发展循环农业与新农村建设相结合，加快生态文明乡村建设步伐。围绕“抓试点、树样板、推亮点、带周边”的思路，挖掘一批发展前景好、竞争力和带动力强的种养大户、龙头企业、典型村庄，给予政策引导、技术指导和重点支持，着力建设循环农业示范户、示范企业、示范村（区、片）。进一步完善不同类型的循环农业发展模式与机制，总结经验，全面推广。到2015年，全市建设循环农业示范企业或示范村（区、片）70个，重点建设不少于20个。

五、组织保障

（一） 加强组织领导

市政府成立循环农业建设工作领导小组，由分管副市长任组长，市发改委、市财政局、市农村办、市农业局、市环保局、市畜牧兽医水产局、市蔬菜办、市水利局、市乡镇企业局、市农机化局、市能源办等单位负责人为成员。领导小组办公室设在市农业局，统筹抓好循环农业发展工作。各县市区也要相应成立工作机构，有效推进循环农业发展。

（二）落实工作责任

各级各有关部门要按照“统一管理、分工负责”的原则，各司其职，各尽其责，合力抓好循环农业建设。市发改委负责将循环农业纳入国民经济和社会发展规划，组织相关重大项目的争取、衔接与监督管理；市财政局负责筹集发展循环农业的公共基础设施建设和公共服务投入资金，搞好资金使用管理和监督；市农村办负责将循环农业纳入农村经济社会发展的重要内容综合推进；市农业局负责组织协调循环农业发展，制订全市循环农业示范企业、示范村（区、片）建设方案，推广种植业循环生产、清洁生产模式和技术；市环保局负责农业节能减排的宏观指导，将循环农业纳入生态村建设内容；市畜牧兽医水产局负责发展标准化养殖、健康养殖，逐步减少养殖过程中对农业环境的污染；市蔬菜办负责蔬菜产业规模发展；市乡镇企业局负责扶持龙头企业加强节能减排技术改造、延长产业链条、进行深度研发；市水利局负责加强水资源保护；市农机化局负责农业机械的推广使用和技术指导；市农村能源办负责推广、开发利用沼气等生物质能源项目和技术，普及清洁能源。

（三）加大资金投入

要加大对循环农业试点示范项目建设、农作物秸秆综合利用、畜禽粪便无害化处理、农村垃圾与污水处理、农业投入品包装物回收利用的资金支持；积极争取资源、能源开发和生态环境保护等方面的项目投资；鼓励不同经济成份和各类社会投资主体及民间资本参与循环农业建设。

（四）强化宣传培训

各地要利用广播、电视、报刊、互联网等媒介，大力宣传循环农业建设的重要意义、政策措施、先进典型和经验做法，努力营造发展循环农业的浓厚氛围。要研究推广使用循环农业的新技术和新模式，重点围绕节约型农业、废弃物综合利用、农产品精深加工、能源作物培育、土壤污染修复等进行研究和推广；要牵头组织循环农业建设负责人、技术骨干、基层农技人员、企业负责人、农村经济大户进行分级分类、定期培训；要通过设立循环农业专家热线、咨询信箱等方式，强化技术指导，不断提高发展循环农业的能力和水平。

（五）严格考核验收

各级政府要把发展循环农业纳入目标管理考核内容，层层落实责任。循环农业建设工作领导小组办公室要制定考核细则，加大考核力度，推动工作平衡开展。对发展循环农业作出突出贡献的单位和个人给予表彰。
