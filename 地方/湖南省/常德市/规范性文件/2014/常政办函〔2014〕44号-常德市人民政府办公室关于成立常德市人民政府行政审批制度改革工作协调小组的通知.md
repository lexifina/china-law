# 常德市人民政府办公室关于成立常德市人民政府行政审批制度改革工作协调小组的通知

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直和中央、省驻常有关单位：

根据工作需要，经市人民政府研究，决定成立常德市人民政府行政审批制度改革工作协调小组。现通知如下：

组 长：

赵应云 市委常委、市人民政府常务副市长

副组长：

周代惠 市人民政府秘书长、市政府办主任

成 员：

熊国健 市纪委副书记（常务）、市人民政府党组成员、市监察局（市预防腐败局）局长

张跃华 市人民政府副秘书长、市政务中心主任

吴新涛 市人民政府副秘书长

吴让晓 市委编办主任

汤祚国 市发改委主任

龚美爱 市民政局局长

尹正锡 市财政局局长

张运华 市人社局局长、市委组织部副部长（兼）

戴君耀 市住建局局长

吴德新 市商务局局长

张克武 市审计局局长

袁云波 市物价局局长

于汉卿 市法制办主任

舒兆兰 市电子政务办主任

胡祖国 市工商局局长

协调小组办公室设在市委编办，由吴让晓同志兼任办公室主任。

今后，协调小组组成人员如有变动，由相应岗位的人员自然递补。确需行文的，由协调小组行文，报市政府办公室备案，市政府办公室不再行文。

常德市人民政府办公室
