# 常德市人民政府办公室关于印发《常德市重度残疾人护理补贴制度实施方案》的通知

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直有关单位：《常德市重度残疾人护理补贴制度实施方案》已经市人民政府同意，现印发给你们，请认真贯彻执行。

常德市人民政府办公室

2014年11月3日

常德市重度残疾人护理补贴制度实施方案

为进一步改善全市重度残疾人生活质量，根据《湖南省人民政府办公厅关于印发〈湖南省重度残疾人护理补贴制度实施办法〉的通知》（湘政办发〔2014〕65号）（以下简称《办法》）精神，结合我市实际，制定本方案。

一、实施范围

全市所有重度残疾人，即具有本市户籍、持有第二代《中华人民共和国残疾人证》（以下简称残疾人证）且残疾等级为一、二级的残疾人。

二、补贴标准

重度残疾人护理补贴标准为每人每月50元；根据全市经济和社会发展情况，市适时调整重度残疾人护理补贴标准。

三、申报对象

重度残疾人护理补贴由本人或法定监护人向户籍所在村（居）民委员会提出书面申请；监护权在残疾人托养服务机构或无法确定监护人且自己不能准确表达意愿的重度残疾人，可由托养机构或所在村（居）委会代为提出申请。

四、资金来源

重度残疾人护理补贴资金实行分级负担。对市财政直管区（武陵区、鼎城区、常德经开区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区、桃花源旅游管理区），由市财政补齐全省最低标准平均补助50%的差额部分，其余的50%部分由各区自行负担。对省财政直管县（市），省财政补助后，其余资金由各县（市）自行负担。　　各区县市人民政府应加强对重度残疾人护理补贴工作的领导，安排必需的工作经费，并列入财政预算。

五、时间安排

（一）宣传发动阶段（11月15日前）。各级各有关部门要利用广播、电视、报刊、互联网等媒介，加大对重度残疾人护理补贴优惠政策的宣传力度，努力在全社会营造关心残疾人的良好氛围。

（二）集中申报阶段（11月16日-12月15日）。按照《办法》明确的申报程序，村（社区）要集中做好摸底调查及申报工作，并填写好相关表格。其中，2014年4月30日前申领重度残疾人证的残疾人，在2015年5月1日前申报重度残疾人护理补贴并获批准的，从2014年5月1日起计发；2015年5月1日后申报重度残疾人护理补贴的，则从申请批准之日的下月计发。2014年5月1日后申领重度残疾人证的残疾人，其重度残疾人护理补贴从申报批准之日的下月计发。

（三）审核公示阶段（12月16日-2015年1月15日）。各级各有关部门要按规定范围和程序，对申请人的条件认真审查、审核，并在规定时间内完成。区县市残联对享受重度残疾人护理补贴的人员，要在政府门户网站或电台、报纸等媒体上公示，并公布举报电话，自觉接受群众监督。对实际残疾程度与残疾人证等级明显不符的，要通过定点医疗机构重新鉴定，及时予以纠正。今后，每年5月底前对重度残疾人补贴对象进行重新审核。

（四）集中发放阶段（2015年1月16日-1月31日）。按照《办法》要求，各区县市2015年1月底前要将首批申报人员的重度残疾人护理补贴发放到位。今后，区县市残联每季度后一个月填报《湖南省享受重度残疾人护理补贴人员汇总表》，提交同级财政部门。财政部门根据《汇总表》委托金融机构在下一季度的第一个月将补贴资金及时足额打卡发放到位。

六、工作要求

各级人民政府要加强对重度残疾人护理补贴工作的领导，主管领导和相关责任部门必须高度重视，认真组织实施。各相关部门要严格按照工作流程和时限要求，切实做好重度残疾人护理补贴有关工作。要严格资金管理，对采取虚报、伪造证明材料等不正当手段骗取重度残疾人护理补贴的村（居）民，情节较轻的由区县市残联给予批评教育，追回冒领的重度残疾人补贴；情节严重构成犯罪的，移交司法机关处理。
