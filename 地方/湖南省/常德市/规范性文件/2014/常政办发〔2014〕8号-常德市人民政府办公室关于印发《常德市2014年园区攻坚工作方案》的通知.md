# 常德市人民政府办公室关于印发《常德市2014年园区攻坚工作方案》的通知

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直有关单位：

《常德市2014年园区攻坚工作方案》已经市委、市政府同意，现印发给你们，请认真贯彻执行。

常德市人民政府办公室

2014年3月17日

常德市2014年园区攻坚工作方案

工业园区（含经济技术开发区、高新技术产业园区、工业集中区等）是新常德新创业的核心平台。为落实市委、市政府工业主导战略重要部署，打好园区攻坚战役，特制定如下方案。

一、攻坚目标

2014年，全市工业园区规模工业产值增长25%以上；工业园区规模工业企业实缴税金增长15%以上；新增百亿园区1个；工业园区内新增产值过50亿元企业1家；各工业园区规模工业增加值占所在地规模工业增加值比重达到55%以上；全市工业园区新引进亿元以上工业项目80个以上；全市工业园区完成基础建设投入50亿元以上，建设标准化厂房面积200万平方米；常德经开区技工贸总收入达到460亿元，规模工业总产值达到270亿元以上，新引进亿元以上工业项目15个以上。2014年上半年，全面建成“一权两制一司”园区体制机制。

到2017年，工业园区规模工业增加值占所在地规模工业增加值比重达到70%以上；实现百亿园区全覆盖；工业园区建成面积实现翻番；全市建成标准化厂房500万平方米以上；常德经开区技工贸总收入、规模工业总产值分别达到1000亿元、800亿元以上。

二、攻坚重点

（一）常德经开区“二次创业”攻坚。强力推进常德经开区二次创业,加快建成千亿园区;加快完善 “一权两制一司”体制;加快产业发展和项目建设，全年力争在奔驰重卡、中国南车、保税仓库、新型材料等项目上签约1个以上，全年引进各类项目资金100亿元以上，签约10亿元以上项目2个；完善基础设施和功能配套，推动产城融合发展，把常德经开区建设成为新型工业化的示范区，改革创新的试验区，新型城镇化的样板区，城乡统筹发展的先行区，使常德经开区早日成为以现代工业文明为特征的现代化新城区。

（二）园区规划创建和基础建设攻坚。①年内完成全市各个工业园区新一轮扩规修编，进一步完善、优化园区空间布局、产业布局和项目布局规划。②上半年完成并按程序发布中联重科千亿工业走廊各项规划，年内完成并按程序发布常德经开区千亿园区、芙蓉王现代新城各项规划。③年内启动规划和申报以鼎城高新区、汉寿高新区、西洞庭工业集中区为基础，以中联重科千亿工业走廊为依托的国家级高新区；以津澧融城为契机，加快整合津市工业集中区和澧县经开区，创建国家级经开区，力争用3年左右时间建成2个国家级高新区或经济技术开发区。④着力抓好园区基础设施建设，完成全年基础建设投入50亿元以上任务，其中常德经开区完成15亿元以上，西洞庭工业集中区完成3亿元以上。⑤强化土地资源储备，保证重点项目用地，确保全市工业园区净地储备量达到5000亩以上。

（三）体制机制和环境优化攻坚。各区县市要高度重视工业园区的发展，切实加强对工业园区的领导，要确定一名副职兼任工业园区的主要负责人。要加快工业园区“一权两制一司”体制改革创新。全面建立相对独立的园区行政管理体制，各园区行使同级政府有关社会经济管理权限。各工业园区管委会根据工作需要及相关规定内设办事机构，需上级部门设派驻机构的，原则上其人、财、物全部下放工业园区管理，并相对独立行使管理权限。鼓励、探索建立相对独立的园区财政体制，各工业园区充分享有财政独立支配权，确保园区运转、建设和发展等方面的刚性支出，确保园区财政支出的增长速度高于同级财政支出的增长速度。加快市场化开发经营步伐，各工业园区必须按照企业化管理、市场化运作的现代园区发展理念，组建1家以上经营开发公司，主要负责园区建设的筹融资，为主承建园区基础设施和项目建设。要切实优化园区发展环境。各级政府相关职能部门要按照“政府委托、园区办理、部门备案”的原则，将相关行政审批权限下放给园区；实行入园项目行政审批、审核事项园区全程代办制度，推进政务服务审批提速提质；切实减轻企业负担，严肃处理乱收费等行为；建立企业和项目周边环境事件快速处置、责任追究机制。

（四）“1115”工程及工业项目建设攻坚。①做大做强烟草、装备制造、食品及生物医药、有色金属及新材料、纺织服装、电子信息等六大产业，大力发展高新技术产业和战略性新兴产业，年内六大产业产值占全市规模工业产值比重提高5个百分点。各工业园区要结合自身实际明确2～3个主导产业，制定产业集群培育规划并组织实施。②强力推进“1115”工程，不折不扣落实“三特”政策，加快推进中联重科工业走廊、常德经开区、烟草产业“三个千亿”工程，年内规模工业产值分别增长20%、20%、11%。③强力推进工业项目建设，确保一批重大项目年内落地开工，一批重点项目年内竣工投产。加快金健米业技术改造项目、金帛化纤锦纶切片项目、金鹏印务八期技改等重点项目建设，确保年内竣工投产，确保常德烟厂易地技扩改项目主体工程年内基本竣工。

（五）招商引资攻坚。加强项目包装策划，重点策划一批过10亿、过50亿、过100亿元的重大项目；加强项目发布，组织项目洽谈，促进项目对接；加快项目招引，开展专业招商、产业招商，全市园区签约引进工业项目投资额350亿元以上，其中常德经开区70亿元以上、西洞庭管理区30亿元以上;加大对重大项目的招引对接力度，重点争取中联重卡、南车产业园、新型材料等战略投资项目落户常德。

（六）标准化厂房建设攻坚。创新融资模式、吸纳多元投资主体参与标准化厂房建设，发挥市财政1亿元补贴资金的引导、撬动作用，年内建设标准化厂房200万平方米。

四、保障措施

（一）切实强化责任。各攻坚组、各区县市要进一步强化园区攻坚的工作责任，分解工作任务，细化工作方案，拿出时间表、路线图，做到责任到单位、到个人、到具体时间节点。各攻坚组牵头领导及组长要切实组织好相应的攻坚活动。各成员单位要积极主动支持，搞好协作配合。其他职能部门要实行“一把手”负总责，明确分管负责人，明确专人对口服务园区。各区县市要成立相应的园区攻坚指挥部，由区县市长担任指挥长，制定具体方案，明确责任，强化措施，认真组织实施。

（二）切实加强配合。各区县市及市直各职能部门要大力支持、主动配合园区攻坚工作，加强沟通协调，形成整体合力。要结合全市工业园区实际，加强对土地供应、财政税收、信贷融资、招商引资、项目建设等方面的研究，认真落实园区各项优惠政策，出台相关配套措施，并制定具体的对接方案，确保园区攻坚顺利推进。

（三）切实加强考核。市园区攻坚指挥部办公室要建立工作调度机制、制定目标考核办法，并将园区攻坚战役工作考核结果纳入全市推进新型工业化目标考核和全市目标管理绩效考核范畴。加强考核督查，对各攻坚组、各园区攻坚情况实施一周一调度，一月一通报，一季一督查。年终考核前3名的区县市评为“园区攻坚先进单位”，各奖励20万元；对年终考核前3名的攻坚组，给予一定奖励；对园区攻坚工作不力、效果不佳、目标任务完成不理想的要追究责任，考核排最后一名的，取消评先评优资格，并向市委、市政府书面说明情况。

（四）切实加强宣传。加强对园区攻坚战役的新闻宣传，积极利用报刊、电视、电台、网络和户外广告等媒体平台，加强舆论造势，营造人人关心、个个支持的浓厚氛围。组织媒体推出专栏、专刊、专页进行宣传，将宣传工作贯穿到园区攻坚的全过程、各阶段，及时、全面、深入地反映园区攻坚最新动态和先进典型。
