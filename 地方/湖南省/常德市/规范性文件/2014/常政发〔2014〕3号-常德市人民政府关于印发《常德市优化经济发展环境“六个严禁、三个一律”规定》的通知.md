# 常德市人民政府关于印发《常德市优化经济发展环境“六个严禁、三个一律”规定》的通知

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直和中央、省驻常各单位：

《常德市优化经济发展环境“六个严禁、三个一律”规定》已经市人民政府同意，现印发给你们，请认真贯彻落实。

常德市人民政府

2014年2月7日

常德市优化经济发展环境“六个严禁、三个一律”规定

一、六个严禁

（一）严禁涉企乱检查、乱收费、乱罚款

严禁涉企检查不到优化部门备案登记；

严禁违反《湖南省规范涉企检查若干规定》，对同一企业同一事项一年多次检查；

严禁擅自设立收费项目、提高收费标准或扩大收费范围；

严禁擅自设立罚款项目、提高罚款标准或扩大罚款范围；

严禁违反法定程序和行政处罚裁量权基准进行处罚。

（二）严禁对企业索、拿、卡、要、报

严禁向企业索要钱物、有价证券；

严禁强行向企业拉赞助、拉捐赠；

严禁强迫企业订购报刊、书籍；

严禁接受企业礼品礼金、会员卡、宴请、游玩等；

严禁到企业报销费用。

（三）严禁行政不作为、乱作为、缓作为

严禁擅自增加审批环节或前置条件；

严禁继续执行已经取消的行政审批项目；

严禁审批超时限；

严禁违法违规收取费用；

严禁不实行一次性告知，增加办事难度。

（四）严禁违规有偿服务加重企业负担

严禁将行政职能转移、分解到下属事业单位或者经济实体，对企业或服务对象进行有偿服务；

严禁强迫企业接受有偿服务或者指定购买产品（商品）；

严禁只收费不服务，或者强行服务收费，或者强迫企业接受行业协会、学会收费；

严禁以负面宣传要挟企业或服务对象。

（五）严禁影响和损害项目建设环境

严禁对阻工挠工、强揽工程、强买强卖、欺行霸市等行为不制止、不处置、不打击；

严禁挪用、截留征地、拆迁、安置、补偿等费用和工程建设资金；

严禁带头、参与、支持或怂恿家人、亲属参与阻工挠工、强揽工程、强买强卖、敲诈勒索。

（六）严禁违反《湖南省优化经济发展环境十条禁止性规定》所列其他禁止性规定

二、三个一律

行政机关、事业单位及其工作人员违反上述禁止性规定的，实行责任追究“三个一律”：

（一） 经监察机关初核属实的，一律对其直接责任人先停职，再调查；

（二） 经监察机关查证属实的，一律按照《湖南省影响机关效能与损害经济环境行为处理办法》（湘办发〔2011〕9号）中相应处理规定从严处理，并追究单位主要负责人的领导责任；

（三） 凡发生了损害经济环境案件的单位，一律取消其评先评优资格，并对责任单位及责任人进行全市通报。
