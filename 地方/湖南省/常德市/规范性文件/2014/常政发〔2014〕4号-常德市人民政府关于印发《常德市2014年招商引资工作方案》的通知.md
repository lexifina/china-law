# 常德市人民政府关于印发《常德市2014年招商引资工作方案》的通知

各区县市人民政府，常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直和中央、省驻常有关单位：

《常德市2014年招商引资工作方案》已经市人民政府同意，现印发给你们，请认真贯彻执行。

常德市人民政府

2014年3月12日

常德市2014年招商引资工作方案

一、目标任务

（一）总体目标。2014年，全市引进内外资到位资金总额500亿元以上，引进亿元以上工业项目100个以上，直接利用外资增长15%以上。

（二）工作任务

1.常德经济技术开发区引进项目投资总额100亿元以上，其中亿元以上工业项目15个以上，10亿元以上工业项目3个以上；西洞庭管理区引进项目投资总额50亿元以上，其中亿元以上工业项目10个以上，5亿元以上工业项目2个以上。

2.现代工业、现代农业、现代服务业招商组引进项目投资总额100亿元以上，其中现代工业招商组30亿元以上，现代农业招商组15亿元以上，现代服务业招商组55亿元以上。

3.市外侨办、市工商联、市台办、市贸促会引进项目投资总额分别达到5亿元以上。

4.市政府驻北京、上海、深圳联络处引进项目投资总额分别达到10亿元以上。

5.其他区县市任务指标另行下文分解下达。

二、组建招商工作组

（一）专业化招商工作组

1.现代工业招商组

组长：沈习淼市人民政府副市长

牵头负责人：[姓名略]经信委主任

成员：市经信委、市发改委、市科技局、市财政局、市招商局、市国资委等单位负责人。

招商方向：围绕推进“1115”工程，以引进重大工业项目为重点，面向装备制造、食品生物医药、有色金属及新材料、电子信息、纺织服装等我市传统优势产业和战略性新兴产业招商。

2.现代农业招商组

组长：朱晓平市人民政府副市长

牵头负责人：[姓名略]委农村工作部部长、市政府农村办主任

成员：市农村办、市农业局、市林业局、市水利局、市供销社、市农机局、市畜牧兽医水产局、市扶贫办、市农科所、现代农业投资公司、市农业产业化局、市经管局等单位负责人。

招商方向：以加速推进农业产业化为重点，主要面向现代农业种养业、农产品加工流通业、现代农业种业、休闲观光农业、现代农业服务业等产业招商。

3.现代服务业招商组

组长：匡加才市人民政府副市长

牵头负责人：[姓名略]商务局局长

成员：市商务局、市教育局、市文广新局、市旅游局等单位负责人。

招商方向：以大力推进商贸流通、加快文化旅游产业发展为重点，主要面向现代商贸、总部经济、专业化市场、口岸建设、物流业、旅游、文化教育等产业招商。

以上三个招商组要细化方案、明确分工、分解任务，并配备一定的专业招商人员，脱产专职从事专业化招商工作。招商组工作人员由牵头单位优先在本单位（本系统）内挑选（不增加编制），也可以在市直相关单位内抽调。各招商组具体工作方案由牵头单位制定，经招商组组长审定后，报市招商引资工作协调领导小组备案。

（二）重大项目招商工作组

1.新型材料项目招商组

组长：沈习淼市人民政府副市长

牵头单位：市国资委

主体责任单位：常德经济技术开发区

2.中国南车集团项目招商组

组长：沈习淼市人民政府副市长

牵头单位：市经信委

主体责任单位：常德经济技术开发区

3.中联重科项目招商组

组长：沈习淼市人民政府副市长

牵头单位：市发改委

主体责任单位：常德经济技术开发区

4.华侨城项目招商组

组长：魏立刚市委副巡视员

牵头单位：市旅游局

主体责任单位：市政府驻深圳联络处、柳叶湖旅游度假区。

以上四个重大项目招商组分别负责相应项目引进到落地的全程协调服务。重大项目招商工作组设置可视项目进展情况进行调整。

三、相关市直单位招商责任

1.市商务局（招商局）负责牵头抓好全市招商引资工作的管理、指导、协调、服务、调度和考核。

2.市外侨办、市台办、市工商联、市贸促会等招商引资密切相关单位要充分发挥各自优势和职能作用，积极开展招商引资，大力承接产业转移，侧重引进外贸企业和外资企业。

3.市政府驻北京、上海、深圳联络处要转变工作方式，把主要精力放在招商引资上来。

4.市国土资源局、市环保局、市住建局、市规划局、市工商局等相关职能部门要积极履职，全力服务好招商引资工作。其他市直部门也要积极支持、参与招商引资工作。

四、组织保障

成立市招商引资工作协调领导小组，由市委常委、常务副市长赵应云任组长，副市长匡加才任副组长，市直有关单位负责人为成员，负责项目落户跟进服务工作的总协调，着力推进全市招商引资工作。领导小组办公室设在市商务局，由市商务局局长吴德新任办公室主任，负责日常联络和综合协调有关工作。

五、工作机制

1.建立项目评审制度。由市招商引资工作协调领导小组办公室牵头，按月组织市农村办、发改、经信、科技、财政、环保、国土、规划、税务等市直有关单位和项目落户地政府（管委会）对市本级亿元以上招商项目进行联合会审，提高项目质量，规避潜在风险，避免重复建设和恶性竞争，并组织按程序报批。

2.坚持三级调度制度。继续坚持和完善招商引资工作三级调度制。市委常委会、市政府常务会每半年听取一次招商引资情况汇报，研究解决重大战略项目引进落户问题。市招商引资工作协调领导小组每季度调度一次，专题分析研究具体工作；领导小组办公室每月调度一次工作进度。

3.坚持定期通报制度。市招商引资工作协调领导小组办公室按月收集汇总各招商工作组和区县市招商引资工作有关情况，一月一通报；同时认真梳理项目落地过程中存在的困难和问题，报领导小组召开专题会议协调解决。全市招商引资主要指标按季在市级主要媒体上公布。

4.坚持检查督促制度。由市招商引资工作协调领导小组办公室牵头，会同相关单位定期或不定期对全市招商引资工作进行督导检查。

六、考核奖惩

1. 设立突出成效奖。区县市招商引资年度考核前3名的评为市招商引资工作先进单位，由市人民政府各奖励50万元；常德经济技术开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区年度考核第1名的评为市招商引资工作先进单位，由市人民政府奖励10万元；市直单位中评选出10个全市招商引资工作先进单位，由市人民政府予以表彰。

2. 设立重大项目引进奖。对新引进1亿元以上（不含土地价款）工业项目（含农业产业化项目）和5亿元以上(不含土地价款)商贸物流项目（含文化旅游项目）落户市及市辖区，由市人民政府对引进单位予以奖励。按照引进工业项目（含农业产业化项目）总投资额1亿元以上、5亿元以上、10亿元以上，分别奖励引进单位10万元、50万元、100万元；5亿元、10亿元以上的商贸物流项目（含文化旅游项目），分别奖励引进单位25万元、50万元。奖金分两次拨付，项目开工建设且固定资产投入（不含土地价款和政府补贴额度）达到总投资额的30%以上，按相应比例给予奖金，项目建成投产后给予余下的奖金。对2014年以前引进的项目，2014年内能开工建设的，项目建成投产后仍按照《常德市人民政府关于印发〈常德市引进新上工业项目奖励暂行办法〉的通知》（常政发〔2011〕26号）的文件精神给予奖励。

3.设立外资到位奖和外贸业绩奖。按实际到位外资每100万美元奖励区县市1万元人民币；对新引进外贸企业，外贸业绩每增加100万美元奖励区县市1万元。

4. 设立绩效考核分值奖。区县市和市直有关单位招商引资工作纳入目标管理绩效考核，分值提高到30分。区县市招商引资绩效考核指标由市人社局会同市招商引资工作协调领导小组办公室下达，市直有关单位招商引资绩效考核指标由市直机关工委会同市招商引资工作协调领导小组办公室及各市直招商工作组牵头单位下达。没有完成年度目标任务的区县市和市直有关单位，主要负责人不参与评先评优。没有招商引资任务的市直单位，每引进一个亿元以上工业项目或5亿元以上商贸物流、文化旅游项目，奖励3分。

年底由市招商引资工作协调领导小组办公室牵头，组织市纪委、市委组织部、市直机关工委、市委农村工作部、市发改委、市经信委、市人社局、市财政局、市商务局、市审计局等单位，对区县市、市直单位招商引资工作情况进行考核奖惩。

市人民政府此前出台的招商引资有关规定与本通知不一致的，以本通知为准。
