# 常德市人民政府办公室关于修改废止不符合生态文明建设和环境保护要求文件规划的通知

各区县市人民政府，常德经济技术开发区、常德高新技术产业开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直和中央、省驻常有关单位：

为认真贯彻落实中央第六环境保护督察组督察意见要求和《湖南省人民政府办公厅关于修改废止不符合生态文明建设和环境保护要求文件规划的通知》(湘政办发〔2017〕47号)精神，市政府组织对现行有效的以市政府和市政府办名义制定的文件和有关规划进行了清理，对不符合生态文明建设和环境保护要求的文件和规划进行修改废止。现通知如下：

一、将《常德市人民政府关于印发〈常德市优化经济发展环境“六个严禁、三个一律”规定〉的通知》(常政发〔2014〕3号)第一点中的“严禁涉企检查不到优化部门备案登记” 修改为“禁止违法违规随意对企业进行各类检查”，并重新公布。

二、废止《常德市人民政府关于同意〈长江流域中小河流采砂管理湖南省常德市武陵区规划报告〉等8个河道采砂规划报告的批复》(常政函〔2014〕27号)。

三、原市环境保护委员会印发的《常德市环境保护委员会关于印发〈常德市清理整治环保违规建设项目工作方案〉的通知》(常环委发〔2016〕2号)由市生态环境保护委员会自行发文废止。

四、各级各部门要对本机关制定的文件和规划进行认真清理，对违反生态文明建设和环境保护要求的文件及时进行修改或废止。

常德市人民政府办公室

2017年10月21日
