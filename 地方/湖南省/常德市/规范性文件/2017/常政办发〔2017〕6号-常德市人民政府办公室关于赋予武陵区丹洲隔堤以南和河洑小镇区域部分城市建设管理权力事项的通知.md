# 常德市人民政府办公室关于赋予武陵区丹洲隔堤以南和河洑小镇区域部分城市建设管理权力事项的通知

CDCR-2017-01007

武陵区人民政府、市直有关单位：

根据《常德市人民政府办公室关于印发〈赋予武陵区和柳叶湖旅游度假区部分城市建设管理工作职能的实施方案〉的通知》（常政办发〔2016〕21号）精神，经市政府同意，决定将市国土资源局、市环保局、市住建局、市水利局、市规划局、市人防办等6个部门实施的146项行政权力事项（其中行政许可10项、行政处罚120项、行政强制3项、行政征收3项、行政检查4项、行政奖励2项、行政裁决1项、其他行政权力3项），赋予武陵区在丹洲隔堤以南和河洑小镇区域实施，并就有关工作要求通知如下：

一、高度重视承接工作。市直有关部门和武陵区有关部门要认真做好下放行政权力事项的衔接落实工作，及时调整权力事项目录，完成行政审批流程梳理和公开工作，加快配套改革和相关制度建设。各承接部门要充分认识权力事项下放工作的重要性，切实加强领导，精心组织实施，明确分管领导、承办科室和具体承办人员，确保各项事项承接到位。市直有关部门要切实做好对下培训和业务指导工作，加强后续监管，避免工作脱节和监管真空。

二、加大督促检查力度。市政府办、市委编委办（市政府审改办）、市发改委、市监察局、市法制办、市政务中心、市电子政务办等部门要适时对承接工作进行督查，督查内容包括各部门的承接机构、职能职责、项目、落实情况和相关制度建设情况等。对于在工作中应接不接、承接不彻底造成管理工作断档脱节的部门，市政府将严肃问责。
