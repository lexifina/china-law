# 常德市人民政府关于在桃花源旅游管理区（筹）及周边区域划定畜禽规模化养殖禁养区和限养区的通告

CDCR-2017-00003

为保护桃花源旅游管理区（筹）旅游资源和饮用水资源，保障人民群众饮水安全，助力我市旅游建设，根据《风景名胜区条例》、《畜禽规模养殖污染防治条例》和《饮用水水源保护区污染防治管理规定》等法规、规章规定，经市人民政府研究，决定在桃花源旅游管理区（筹）及周边区域划定畜禽规模化养殖禁养区和限养区，现就有关事项通告如下：

一、桃花源旅游管理区（筹）及周边区域的“一圈一线”为畜禽规模化养殖禁养区。“一圈”即桃花山景区、桃源山景区、秦谷景区、桃花源古镇景区、五柳小镇、五柳湖景区、太极广场景区、桃仙岭景区、桃林博览园和五柳湖村、桃仙岭村、武陵渔村、白鳞洲村、桃花源村、汤家山村、桃花社区、翘望嘴社区。“一线”即秦溪（原水溪河）两岸分别向外延伸500米范围内的区域，包括桃源县芦花水库龙虎溪流域、鼎城区廖花河流域和桃花源旅游管理区（筹）水溪流域。

二、桃花源旅游管理区（筹）内“一圈一线”之外的区域，为畜禽规模化养殖限养区。

三、在禁养区范围内，严禁畜禽规模化养殖活动，禁养区内现有的畜禽规模化养殖场必须于2017年6月30日前依法搬迁或关闭。

四、限养区内严格控制畜禽养殖总量，禁止新建规模化畜禽养殖场。已建畜禽规模化养殖场应在2017年6月30日前完成污染治理，确保污染物达标排放，污染物排放不能达标的，应当依法选址搬迁或关闭；改建畜禽规模化养殖场的，必须严格执行环境影响评价规定和污染防治设施同时设计、同时施工、同时投产使用制度，确保符合污染物总量控制要求。

五、鼎城区、桃源县、桃花源旅游管理区（筹）按属地管理、联合整治原则，负责本辖区内禁养区、限养区的畜禽规模化养殖污染治理工作。

六、在上述禁养、限养区域违反本通告规定的，由有关行政机关依法给予行政处罚。

七、本通告自发布之日起实施。
