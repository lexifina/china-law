# 常德市人民政府办公室关于印发《常德市企业上市（挂牌）扶持奖励办法》的通知

各区县市人民政府，常德经济技术开发区、常德高新技术产业开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直和中央、省驻常有关单位：

《常德市企业上市（挂牌）扶持奖励办法》已经市人民政府同意，现印发给你们，请认真贯彻执行。

常德市人民政府办公室 2018年2月5日（此件主动公开）

常德市企业上市（挂牌）扶持奖励办法

为鼓励、扶持和引导企业利用资本市场做大、做优、做强，带动区域经济发展转型，制定本办法。

一、扶持奖励条件

本办法适用于我市范围内主营业务突出，发展前景良好，具有高成长性，符合国家产业发展方向及我市产业发展规划的拟上市（挂牌）企业，其基本条件为：

（一）在我市范围内依法进行工商注册和税务登记；

（二）已设立或拟设立为股份有限公司；

（三）已制定详细的上市（挂牌）工作计划，经中介机构确认适合上市（挂牌）条件，并签订上市（挂牌）工作协议；

（四）已进入《常德市拟上市（挂牌）企业名单》（拟上市〈挂牌〉企业由企业每年一季度自行申报，市政府办〈市金融办〉确认产生）。

二、扶持优惠政策

（一）拟上市企业进行股份制改造，在办理资产过户、更名时须缴纳的税费，在中国证券监督管理委员会或境外证券交易所管理机构正式受理企业发行上市申请材料后，由受益财政按地方留成部分安排上市扶持资金补助给企业。

（二）拟上市企业将资本公积、盈余公积、未分配利润转增为股本所缴纳的企业所得税，由受益财政按地方留成部分安排上市扶持资金补助给企业。其中，在中国证券监督管理委员会或境外证券交易所管理机构正式受理企业发行上市申请材料后，拨付40%给拟上市企业；成功上市后，拨付余下的60%部分。

（三）拟上市企业设立股份有限公司时，根据审计、评估调账需要而使资产评估增值等转增资本金所缴纳的企业所得税，由受益财政按地方留成部分安排上市扶持资金补助给企业。其中，在中国证券监督管理委员会或境外证券交易所管理机构正式受理企业发行上市申请材料后，拨付40%给拟上市企业；成功上市后，拨付余下的60%部分。

（四）拟上市企业从确认接受上市辅导之日起，期间内企业主体税收（指增值税、企业所得税）年纳税额以不低于上年纳税额50%的环比增长的，超过50%部分的地方留成部分，由受益财政按80%的比例安排上市扶持资金补助给企业，累计补贴金额不超过500万元，补贴期限至上市年度（原则上不超过三年）。

三、扶持奖励政策

（一）境内外上市

1．在券商、律师事务所、会计师事务所等上市（挂牌）中介机构的辅导下，完成股份制改造并取得股份公司营业执照的，由市财政给予扶持资金20万元；

2．对向中国证券监督管理委员会提出IPO申请被受理的，由市财政给予扶持资金80万元；

3．对在境内外证券市场实现IPO上市的，由市财政给予扶持资金100万元。

（二）新三板挂牌

1．在券商、律师事务所、会计师事务所等上市（挂牌）中介机构的辅导下，完成股份制改造并取得股份公司营业执照的，由市财政给予扶持资金20万元；

2．向“新三板”系统提出申请被受理的，由市财政给予扶持资金20万元；

3．对在“新三板”挂牌的，由市财政给予扶持资金10万元。

四、扶持资金监管

扶持资金监管按目前财政管理体制实际情况，实行分级监管。市级扶持资金监管要求如下：

（一）市财政局负责补贴奖励资金的预算管理和拨付；

（二）市政府办（市金融办）负责受理扶持奖励资金申请；会同市财政局对其申请进行审核；负责补贴奖励资金申报、审核、审批档案资料的管理；负责在次年年初将上年度补贴奖励资金使用情况形成专题报告报市人民政府；

（三）补贴奖励资金的使用情况每年接受市审计局审计；

（四）申请企业应据实报送申请资料。对以欺诈、蒙骗等手段获得扶持和奖励资金的，全额追回已取得的扶持奖励资金，对构成犯罪的，依法追究其刑事责任。

五、其他事项

（一）企业采用买壳、借壳方式上市，并将上市公司注册地迁至常德市范围内的，视同改制上市，享受同等扶持优惠和奖励政策。

（二）企业从“新三板”转至境内外上市的，按照两者补助标准的差额进行补助。同一企业在不同层次资本市场上市、挂牌的，按照就高不就低的原则进行补助，不重复享受相关补助。

（三）上市（挂牌）过程中遇到的土地、环保等特殊问题报市人民政府采取一企一议、一事一议的办法解决。

（四）市城区奖励资金由受益财政按税收分享比例承担，由市财政局统一兑现。

（五）本办法自发布之日起执行，之前文件规定与本办法不一致的，按本办法规定执行。
