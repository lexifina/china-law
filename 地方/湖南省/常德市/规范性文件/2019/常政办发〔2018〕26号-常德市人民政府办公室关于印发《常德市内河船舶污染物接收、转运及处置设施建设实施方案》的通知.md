# 常德市人民政府办公室关于印发《常德市内河船舶污染物接收、转运及处置设施建设实施方案》的通知

常政办发〔2018〕26号

各区县市人民政府，常德经济技术开发区、常德高新技术产业开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直和中央、省驻常有关单位：

《常德市内河船舶污染物接收、转运及处置设施建设实施方案》已经市人民政府同意，现印发给你们，请认真组织实施。

常德市人民政府办公室

2018年12月29日（此件主动公开）

常德市内河船舶污染物接收、转运及处置设施建设实施方案

为全面推进常德市内河船舶污染防治工作，促进绿色水运发展，切实落实《常德市城乡生活垃圾管理条例》等法规，以及 《交通运输部关于印发船舶与港口污染防治专项行动实施方案（2015—2020年）的通知》（交水发〔2015〕133号）、《湖南省贯彻落实〈水污染防治行动计划〉实施方案（2016—2020年）》（湘政发〔2015〕53号）等文件精神，结合我市实际，特制定本方案。

一、建立健全船舶污染物处置机制

以污染物“上岸处置”为原则，根据我市辖区内港口码头和到港船舶污染物接收、转运、处置现状及需求,建立我市内河船舶与港口污染物收集处置体系，制定污染物接收、转运及处置设施的建设方案和运营机制，提升污染物接收处置能力, 提高污染物管理控制水平,促进水运生态绿色发展。

二、加强水域垃圾预测及实际接收能力

根据2016—2017年全市8个主要港口年船舶进港总艘次、年进出港船舶总吨及年港口货物吞吐量等数据，结合本市实际情况，预测2018—2020年全市港口船舶污染物年均理论值为1176吨，其中船舶生活污水、船舶含矿物油污水、船舶垃圾分别为721吨、323吨、132吨。

我市现有1家船舶污染物接收公司，年最大接收能力为含矿物油污水60吨、残油140吨、垃圾200吨。

三、建设方案

（一）建设布局。建成6个船舶生活垃圾、生活污水及含矿物油污水收集点。

1. 汉寿县船舶污水垃圾中转站，位于汉寿县岩汪湖镇雷神庵村。

2. 安乡船舶污水垃圾中转站，位于安乡县深柳镇沿河大道南城茗都大门左侧。

3. 艳洲枢纽收集点，位于澧县澧浦街道黄沙湾社区。

4. 戴家湾收集点，位于澧县小渡口镇江湾村。

5. 陬市收集点，位于桃源县陬市港区。

6. 德山收集点，位于常德市武陵区芦荻山乡沅水二桥下。

（二）建设内容。船舶生活垃圾、生活污水及含矿物油污水的收集，采取设置专业船舶对辖区航段船舶污染物进行收集再转送至岸上，生活垃圾由有处理资质的单位集中接收处置，有条件依托港口的将生活污水排至城市管网，无条件的通过新建“地埋式”污水处理装置处理，含矿物油污水处理后由专业企业回收的方式。船舶垃圾上岸建设工程主要内容：

1.垃圾上岸斜坡道或码头；

2.工作趸船；

3.船舶生活垃圾和含矿物油污水暂存转运站及标志标牌等设施；

4.管网改造或“地埋式”污水处理装置。

其中岸上配套包含码头的新建或改建，对应配套的趸船及船舶生活垃圾及含矿物油污水暂存转运站为本工程实际建设内容，垃圾收集船舶等其他设施由营运企业自行承担。

（三）投资匡算。站点建设分为依托及不依托城镇管网两种情况。依托城镇管网的，不需建设污水处置设施，新建管网对接城镇污水管网；不依托城镇管网的，要建设“地埋式”污水处理装置。根据相关技术规范，参照各航段垃圾预测总量，经匡算，我市6个收集点总投资约为3160万元。

四、运营管理

（一）水上营运管理。船舶含矿物油污水（危险废物）收集经营必须取得由生态环境部门颁发的《危险废物经营许可证》，并符合相关管理规划和要求。海事管理机构要依法对收集船舶进行船舶检验及日常监管。

船舶垃圾收集企业要对船舶生活垃圾、生活污水、含矿物油污水等船舶污染物的收集情况进行记录，并定期将污染物收集记录台账提交给海事管理机构。对未按规定向船方出具船舶污染物接收单证明的，海事管理机构依法处理。

（二）岸上营运管理。船舶污染物收集企业将污染物收集后应安全运送至垃圾转运站；含矿物油污水收集后集中转运至具有资质的废油回收企业；生活污水抽入城市污水管网。

五、保障措施　　各地各有关部门要在市政府统一领导下，各负其责，按照本方案要求完成建设任务。成立交通、生态环境、住建、农业农村、城管等部门参与的联合监督机制，建立船舶污染物联单管理制度，严格落实船舶污染物防治综合监管；协调解决港口船舶污染物接收、运营及处置中存在的问题，共同推进落实船舶污染物防治工作。
