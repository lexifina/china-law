# 常德市人民政府办公室关于促进油茶产业高质量发展的通知

各区县市人民政府，常德经济技术开发区、常德高新技术产业开发区、柳叶湖旅游度假区、西湖管理区、西洞庭管理区管委会，市直和中央、省驻常有关单位：

为大力发展油茶产业，助推乡村振兴，将油茶产业打造成我市特色优势产业和富民强市支柱产业，根据《湖南省人民政府关于深入推进农业“百千万”工程促进产业兴旺的意见》（湘政发〔2018〕3号）和《湖南省人民政府办公厅关于进一步推动油茶产业发展的意见》（湘政办发〔2015〕14号）等文件精神，经市人民政府同意，现就促进油茶产业高质量发展有关事项通知如下：

一、明确发展目标。与湖南省打造“千亿级” 油茶产业目标对接，确定全市油茶产业发展目标，制定全市油茶产业中长期发展规划和年度实施方案。到2025年，全市油茶种植面积达200万亩，丰产油茶林面积达110万亩，茶油年产量增加到5万吨，油茶产业年产值达100亿元以上，打响“常德茶油”公共品牌。

二、加大资金扶持。市财政每年在农口专项资金中安排油茶产业发展专项资金，重点支持丰产油茶林资源培育、油茶采穗圃和育苗基地建设、油茶产业贷款贴息、油茶企业上市培育、品牌创建、科技攻关及产品深度研发、技术培训等。充分发挥常德产业发展基金引导作用，促进全市油茶产业快速、健康、高质量发展。油茶主产区区县市要加大资金投入力度，扶持油茶产业发展。

三、着力资源培育。按照“依法、自愿、有偿”原则，有序流转林地经营权，大力推广“企业+合作社+农户”油茶经营模式，不断优化农户与企业利益链接机制，引导广大林农积极参与油茶产业建设。建设4个油茶标准化种植示范基地，增强示范带动效应；培植50个1000亩以上的油茶良种丰产林基地乡、500个300亩以上油茶良种丰产林基地村；每年新造4万亩油茶林、更新改造4万亩油茶林、垦复和疏密低改7万亩油茶林。支持一二三产业融合发展，探索建设现代油茶庄园。

四、提升科技水平。加强市林科所“常德铁城一号”、常林系列等油茶良种采穗圃和4个重点良种育苗基地建设，加强油茶良种选育和栽培技术研究与推广应用。以市林科所为载体建设市油茶科技推广中心。以湖南省油茶产业技术创新战略联盟为平台，发挥驻常高校及市林科所等科研力量，联合国内从事油茶研究的一流科研院所，围绕油茶产业发展需求开展科研攻关和技术服务，不断提高油茶产业科技水平。加快科技人才培养，不断推动全市油茶创新驱动发展和科技成果转化。支持油茶企业提升精深加工水平，延伸产业链，提高附加值。

五、实施品牌战略。积极推进“常德茶油”国家地理标志产品保护工作，并作为常德公共品牌宣传推介。积极举办和参加国内有影响力的产品博览会和展示展销会，举办常德油茶新技术、新产品发布体验会，策划包装油茶项目招商引资，充分发挥品牌引领作用。

六、搭建发展平台。建立泛湘西北油茶产品交易市场，建设油茶产业配套仓储、物流中心，完善物流体系。加强市场监管，全面规范油茶加工行为，建立健全油茶产品质量安全监督、检验、监测和追溯体系，建立相应产品数据平台。推动油茶产品“互联网+”交易，拓宽油茶产品营销渠道。

七、加强组织领导。成立市油茶产业发展协调领导小组，由市人民政府分管副市长任组长，市人民政府分管副秘书长、市林业局局长任副组长，市发改委、市科技局、市财政局、市自然资源和规划局、市水利局、市农业农村局、市商务局、市市场监督管理局、市林业局、市广播电视台、常德日报社、农发行常德市分行、农行常德市分行等为成员单位。领导小组办公室设在市林业局，由市林业局局长兼任办公室主任，安排工作人员、技术专家3—5人，工作经费从油茶产业发展专项资金中列支。领导小组主要负责贯彻落实国家、省、市关于发展油茶产业的政策，组织制定全市油茶产业发展规划和政策，制定任务指标并组织实施，负责油茶产业生产、加工、销售等各个环节的综合协调等。油茶主产区区县市要参照建立相应工作机制，加强对本地油茶产业发展的领导和管理。

八、广泛宣传引导。各级各有关部门、单位要充分利用电视、广播、报刊、网络等媒体，广泛宣传油茶产业和油茶产品的独特功能、综合效益、巨大潜力及发展油茶产业的政策、技术、典型，挖掘油茶产业的文化内涵，为促进油茶产业高质量发展创造良好氛围。
