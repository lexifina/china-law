# 关于加强2019年高考期间环境秩序管理工作的通告

2019年高考即将来临，为了给广大考生营造一个安静舒适的考试、休息环境，根据《中华人民共和国环境噪声污染防治法》《中华人民共和国治安管理处罚法》等法律法规，经县人民政府研究决定，全面加强高考期间（6月1日—6月9日）县城规划区范围内环境秩序管理。现将有关事项通告如下：

一、县城规划区内各建筑工地、家居装修6月1日—6月9日每晚20时至次日6时严格禁止施工作业；6月6日—6月8日，会同一中考点1500米范围内所有建筑工地、家居装修在24小时内都必须暂停一切施工作业。

二、禁止进行超标排放噪声的装修活动。

三、禁止在商业经营活动中使用高音喇叭或其他发出高噪声的方法招徕顾客。

四、禁止KTV、影院、网吧、茶馆等文化娱乐场所超标排放噪声。

五、禁止在公共场所举行跳广场舞、打陀螺等产生环境噪声污染的活动。

六、禁止使用伴唱机、乐器进行露天娱乐活动产生噪声污染。

七、居民使用家用电器、乐器进行娱乐、悼念等活动，其音量不得超过国家规定的环境噪声排放标准。

八、严格执行县城规划区限制燃放烟花爆竹的有关规定。

九、所有机动车辆必须严格遵守城区禁鸣喇叭的规定。6月7日—6月8日，上午8:30～12:00、下午14:00～17:30，对雷鸣湾大桥东侧滨江大道至滨江大道与S318线交汇处路段实行交通管制。

各单位和个人必须严格遵守本通告规定，积极配合有关部门及早做好停工停业准备工作，合理安排施工和营业时间；广大市民要关心、爱护考生，尽力为广大考生营造良好的考试环境。凡违反以上规定者，将依照有关法律法规从重从严处罚。

本通告自2019年6月1日起施行。
