# 关于印发《杜家坪乡进一步加强和改进临时救助工作的实施意见》的通知

各村委会、乡直机关各单位：

临时救助是社会救助体系的重要组成部分，为进一步发挥临时救助托底线、救急难作用，经乡党委、政府集体研究，现将《杜家坪乡进一步加强和改进临时救助工作的实施意见》下发给你们，请认真贯彻落实。

杜家坪乡人民政府

2019年8月22日

杜家坪乡进一步加强和改进临时救助工作的实施意见

为缓解困难群众突发性、紧迫性、临时性基本生活困难，切实保障困难群众基本生活，结合我乡实际，现就进一步加强和改进临时救助工作提出如下意见：

一、总体要求

全面贯彻落实党的十九大精神，以习近平新时代中国特色社会主义思想为指导，坚持以人民为中心的发展思路，以有效解决城乡群众突发性、紧迫性、临时性基本生活困难为目标。完善政策措施、健全工作机制、加强组织保障，切实保障困难群众基本生活权益。

（一）救助对象范围和类别

根据困难情形，临时救助对象可分为急难型救助对象和支出型救助对象。急难型救助对象包括以下人群：

1、因意外事件（火灾、交通事故等突发意外事件）导致基本生活暂时出现严重困难、需要立即采取措施的家庭和个人。

2、因家庭成员突发重大疾病（43种病种含长期慢性病、重大疾病、罕见病）需要立即采取救助措施的家庭和个人。

3、因遭遇县级人民政府民政部门认定的其他突发性特殊困难、需要立即采取救助措施的家庭和个人。

支出型救助对象包括因教育、医疗等生活必须开支突然增加超出家庭承受能力、导致基本生活一定时期内出现严重困难的以下人群：

1、农村低保对象；

2、特困人员；

3、建档立卡贫困户；

4、困难残疾人；

5、低保边缘人群；

6、其他原因导致生活困难人群。

（二）审核审批程序

申请临时救助一般程序为：

1、个人申请；

2、村支两委签署调查意见

3、联村领导签署救助意见；

4、民政所审核把关；

5、领导审批；

6、村级公示；

7、资金打卡发放。

对于急难型临时救助，乡可简化申请对象家庭经济状况核对、民主评议和公示环节，直接予以“先行救助”，以防止造成无法挽回的损失和无法改变的严重后果。待急难情况缓解后，乡民政所按程序要求补齐相关资料，包括申请人救助事由、救助金额等信息及经办人员签字或盖章手续。

（三）健全救助对象档案

1、要建立临时救助对象纸质档案，包括救助对象申请报告、救助对象身份证原件、一卡通户主账号；

2、将临时救助各项数据及时录入湖南省社会救助信息管理系统。

二、强化组织保障

（一）加强组织领导。成立临时救助领导小组，党委书记总负责。由乡长覃娜同志任组长，分管领导罗雪琴同志任副组长，其他班子成员、民政所长、民政专干任成员。领导小组下设办公室，由民政所长黄艳红同志担任办公室主任，负责日常工作开展，分管领导具体把关临时救助工作进展。

（二）加强资金监督。一年内申请对象同一原因临时救助次数不得超过2次，一次性基本生活临时救助不超过当月低保标准的1—6倍（不超过2000元），1000元以内由分管领导签字审批，1000元以上由主要领导签字审批，大额临时救助资金（2000元以上）需召开领导班子成员会一事一议，集体研究审核。各联村领导负责驻村临时救助资金审核把关。

（三）加大“主动救助”工作力度。1、充分运用“四支队伍”集村部脱贫攻坚行动，充分发挥驻村干部、驻村工作队、结对帮扶人等作用，及时发现、核实辖区内突发性特殊情况，对符合临时救助条件的，协助困难群众申请临时救助，并按救助程序实施临时救助。

2、各村在工作中发现或接到有关部门、社会组织、公民个人报告救助线索后，要主动核查情况，对符合临时救助条件的，及时上报乡民政所，协助困难群众申请临时救助。并按救助程序实施临时救助。

（四）加强资金保障。乡政府建立主动救助工作机制，并落实临时主动救助备用金制度，按上年度临时救助资金支出的一定比例（5000元）设立临时救助备用金用于处理紧急性突发事件。确保困难群众按规定得到及时救助，发挥临时救助制度效能作用，提高群众满意度。

本意见自2019年8月22日起施行。

杜家坪乡人民政府

2019年8月22日
