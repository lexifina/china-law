# 芷江侗族自治县发展和改革局关于发布2018年版政府定价的经营服务性收费目录清单的公告

根据省发改委《关于发布2018年版政府定价的经营服务性收费目录清单的公告》(2018年第2号)、《关于进一步清理规范经营服务性收费的通知》(湘发改价费〔2018〕751号)、《湖南省定价目录》(湘发改价调〔2017〕1237号)、市发改委《关于发布2018年版政府定价的经营服务性收费目录清单的公告》(2018年第1号)，结合我县实际，我局对芷江侗族自治县政府定价的经营服务性收费进行了清理规范，制定了《芷江侗族自治县2018年版政府定价的经营服务性收费目录清单》，现予以公告。

本公告发布的《芷江侗族自治县2018年版政府定价的经营服务性收费目录清单》自2018年11月1日起执行，《关于印发芷江侗族自治县2017年版政府定价的涉企行政审批前置服务收费目录清单和涉企经营服务收费目录清单的通知》(芷发改价服〔2017〕05号)文同时废止。
