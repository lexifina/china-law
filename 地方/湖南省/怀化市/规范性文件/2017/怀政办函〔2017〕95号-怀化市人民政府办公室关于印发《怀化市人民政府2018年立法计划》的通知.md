# 怀化市人民政府办公室关于印发《怀化市人民政府2018年立法计划》的通知

各县市区人民政府，市直机关各单位：

《怀化市人民政府2018年立法计划》已经市人民政府同意，现印发给你们，请认真贯彻执行。

怀化市人民政府办公室

2017年12月25日

怀化市人民政府2018年立法计划

为了深入贯彻落实党的十九大精神，切实增强我市立法工作的计划性、科学性，提高立法质量，根据《中华人民共和国立法》的规定，结合我市实际，特制定本计划。

一、2018年市政府立法项目

（一）提交市人大审议的地方性法规项目

《怀化市公园管理条例》

起草单位：市城市管理和行政执法局

（二） 出台的政府规章项目

1.《怀化市户外广告管理办法》

起草单位：市城市管理和行政执法局

2.《怀化市人民政府制定地方性法规草案和规章办法》

起草单位：市人民政府法制和经济研究室

（三）开展调研论证的项目

《怀化市城市园林绿化管理办法》

起草单位：市城市管理和行政执法局

二、具体要求

（一）提高思想认识。各级各部门要高度重视立法工作，维护立法计划的严肃性，切实加强组织领导，坚持科学立法、民主立法，确保按时按质完成工作任务，充分发挥立法的引领和推动作用，为我市全面深化改革、实现“一极两带”发展战略提供法制保障。

（二）确保立法质量。起草单位要坚持问题导向，发现、找准行政管理的重点难点问题，严格按照立法程序和立法技术规范进行文本起草，鼓励实施服务外包，充分发挥“智库”、“外脑”作用，确保制度设计科学、表述精准规范。列入立法计划的立法项目，要通过专家论证会、咨询会、立法调研座谈会、征求意见会等形式，充分发挥专家学者的作用，畅通公众参与的渠道，不断完善立法工作机制，确保政府立法程序合法、内容合法。

（三）明确工作责任。市政府将立法计划的执行情况纳入法治政府建设考核范围。起草单位要严把时间节点，合理安排工作任务，按时高质量完成论证、起草任务。市人民政府法制和经济研究室要加强对立法工作的组织、指导、协调、督查，严格依照考核指标对相关单位进行考核，确保完成立法计划。
