# 关于公布第一批市本级公共服务事项目录的通知

怀政发〔2017〕8号

各县市区人民政府，市直机关各单位：

为贯彻落实国务院、省政府简化优化公共服务流程方便基层群众办事创业的有关部署，切实为群众提供优质高效便捷的公共服务，更好地推动大众创业、万众创新，激发市场活力和社会创造力，经研究，决定公布第一批市本级公共服务事项164项。

各有关部门要抓紧做好公共服务事项的落实和衔接工作，及时在部门门户网站、政务服务中心等载体公布本部门的公共服务事项目录，对公布的公共服务事项实行动态管理。要逐项制定公共服务事项标准，编制形成办事指南，推进政务服务标准化。

本通知自公布之日起施行。
