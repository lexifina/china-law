# 怀化市人民政府办公室关于印发《2019年怀化市城区“绿城攻坚”活动实施方案》的通知

鹤城区人民政府，市直机关各单位：

《2019年怀化市城区“绿城攻坚”活动实施方案》已经市人民政府同意，现印发给你们，请认真组织实施。

怀化市人民政府办公室

2018年11月12日

2019年怀化市城区“绿城攻坚”活动实施方案

为创建国家园林城市、国家森林城市，改善城市生态环境，提高城市品位和市民生活质量，在2018年开展怀化市城区“绿城攻坚”活动的基础上，开展2019年怀化市城区“绿城攻坚”活动。为确保活动顺利开展并取得实效，特制定本方案。

一、指导思想

落实国家“建设美丽中国”和省“城市绿荫行动”要求，以创建国家园林城市、国家森林城市为目标，大力推进城市园林绿化建设管理，通过增量提质、强化管理、完善制度，进一步提升城市园林绿化水平，努力建成空气清洁、环境优美、生态良好、人居舒适的山水园林城市。

二、攻坚目标

解决综合性公园少、街头游园少、道路绿地率低、有绿无荫或有绿少荫、季相不明等问题。续建4个公园（岩门公园、怀化植物博物园、怀化植物园、湖天公园）、新建1个公园（舞水公园）、启动犀牛塘湿地公园建设，新建街头游园10个、交通渠化岛26个，新建林荫停车场5个，新建和提质改造道路绿化10条，争创一批省市级园林式单位（小区），完成2条滨水风光带建设，新增绿地327万平方米，在绿化主要指标上全面达到国家园林城市要求。

三、工作任务

（一）道路绿化。完成环城北路、环城南路、环城西路、舞阳大道、顺天大道、湖天大道、高堰路、刘塘路、天星东路的林荫建设；新建道路全部达到湖南省城镇道路绿化建设导则的要求。新建26个交通渠化岛。对城郊通往卢阳、芷江、麻阳、杨村等方向国、省干道两侧规划控制区域实施绿化提质改造。全面开展道路两侧见缝插绿、立体绿化建设。实施主次干道交叉路口林荫工程，栽植高分枝点落叶乔木，提高绿荫效果，消除交通安全隐患。

（二）公园游园建设。完成岩门公园、怀化植物博物园、怀化植物园续建和舞水公园建设，启动犀牛塘湿地公园建设。按照《公园设计规范》及城市居民出行“300米见绿，500米见园”的要求，新建10个街头小游园。

（三）庭院小区绿化建设。广泛开展 “园林式单位（小区）”的创建活动，建设林荫小区，完成8个省级园林式单位（小区）、20个市级园林式、森林单位（小区）创建。对无物业管理小区绿化建设和提质实行对口帮扶（具体帮扶任务由市三创办分解）。

（四）林荫停车场建设。新建5个林荫停车场，对老旧停车场进行林荫化改造。

（五）滨水绿地建设。完成太平溪风光带、舞水河风光带建设。

（六）闲置用地绿化。对黄土裸露闲置空地进行绿化，提高城区绿化覆盖率；对临近主次干道的闲置土地，按主次干道行道树的品种、规格栽植5排以上乔木，其余空地全部栽植以常绿为主、落叶为辅的乔木或花灌木。

四、责任分工

“绿城攻坚”活动由市人民政府统筹，市创建国家园林城市工作小组负责组织相关单位实施，工作小组办公室负责日常工作。

（一）鹤城区人民政府：负责所辖道路的见缝插绿、立体绿化建设。负责中坡绿色廊道和城郊通往卢阳、芷江、麻阳、杨村等方向国、省道两边规划控制10～20米区域绿化提质；完成岩门公园续建，以及1个街头游园、1个交通渠化岛建设。负责市城区无物业管理小区绿化建设和提质对口帮扶工作的协调；建成50个以上林荫小区。负责辖区内各单位、小区、庭院、部队、宾馆、酒店等绿化提质，以及“园林式单位（小区）”的创建。负责完成太平溪上游风光带续建；完成辖区城市规划区内废弃地、受损山体生态修复，完成辖区内古树名木保护管理工作。

（二）怀化经开区管委会：负责舞阳大道、环城西路林荫建设及所辖道路的见缝插绿、立体绿化建设；完成舞水公园和1个街头游园、5个交通渠化岛建设。负责辖区内无物业管理小区绿化建设和提质对口帮扶工作的协调。负责辖区内各单位、小区、庭院、部队、宾馆、酒店等绿化提质及“园林式单位（小区）”的创建；完成1个林荫停车场建设；完成辖区城市规划区内废弃地、受损山体生态修复。负责河西污水处理厂再生水回收用于绿化灌溉项目建设，再生水回收利用率达到30%；完成辖区内古树名木保护管理工作。

（三）市城建投资公司：负责完成环城南路、顺天大道、湖天大道、刘塘路、天星东路的林荫建设；完成怀化植物博物园建设、湖天公园续建,启动犀牛塘湿地公园建设；完成舞水河风光带（三桥至五桥）、太平溪风光带（二、三期）及潭口溪、岩堰溪景观绿化建设。完成2个林荫停车场和主城区4个街头小游园、10个交通渠化岛建设。

（四）市交建投资公司：负责完成环城北路、高堰路的林荫建设；完成2个林荫停车场建设和主城区4个街头小游园、10个交通渠化岛建设。

（五）市水务投资公司：负责在大型绿地内选择10个点进行以滴灌、喷灌为主的节约型园林建设；负责全城污水处理厂、城东污水处理厂再生水回收用于绿化灌溉项目建设（再生水回收利用率达到30%。）。负责城东污水处理厂厂区内外绿化建设。

（六）市林业局：负责市城区周边山头林相改造。负责苗木植物检疫、森林景观建设质量把关、乡村义务植树等工作。负责怀化植物园建设。负责城乡结合部古树名木保护管理工作。

（七）市住房和城乡建设局：负责市城区在建小区绿化建设工作的组织领导、督查考核，督促其按省或市级园林式单位（小区）标准进行绿化建设，并开展好屋顶绿化、墙体绿化。基本完成棚户区和城市危房改造。同时，组织市城区大型房地产企业开展城市公共绿地建设。

（八）市房产局：负责市城区已建成小区园林绿化建设工作的组织领导、督查考核，督促省级园林式小区继续提质、市级园林式小区创建省级园林式小区，其他小区力争建成省、市级园林式小区，并开展屋顶绿化、墙体绿化建设。

（九）市国土资源局：负责市城区内围而未建黄土裸露的闲置土地绿化恢复工作的组织实施。

（十）市规划局：负责市城区绿化用地规划，重点做好市城区新建公园、游园和重要节点及滨水风光带等用地选址工作；及时完成“绿城攻坚”活动所涉及项目的规划评审。完成城市总体规划修编、城市绿地系统规划修编，全面划定城市绿线。制定城市蓝线规划、城市步行自行车交通系统规划、城市绿道建设规划、海绵城市规划、城市绿地系统防灾避险规划、城市历史风貌保护规划、城市生物多样性保护规划、城市湿地资源保护规划，并经批准后及时实施。

（十一）市城市管理和行政执法局：负责市城区绿线管控，以及“绿城攻坚”活动项目质量把关和技术指导。负责主城区主次干道双排行道树、主次干道交叉路口林荫工程、行道树树池、见缝插绿、立体绿化等项目的规划设计，以及城区“3.12”义务植树活动的组织。负责市城区“园林式单位（小区）”创建工作的技术指导和考核验收。

（十二）市财政局：及时完成“绿城攻坚”项目预算评审，以及经费预算和拨付等工作。

（十三）市交警支队：因地制宜实施步行、自行车交通体系建设。加强主干道机非物理隔离保障安全。

（十四）市委宣传部：负责做好市城区“绿城攻坚”活动新闻宣传报道工作，营造良好的宣传氛围。

（十五）其他各级各相关单位：积极开展园林式单位（小区）创建活动，未创成园林式单位（小区）的要争创市级园林式单位（小区），已是省级的要提质、市级的要创成省级，特别是城区各学校、医院，要带头搞好园林式单位创建。同时，按照“绿城攻坚”活动要求做好相关工作。

五、工作要求

（一）加强调度指挥。各有关单位要切实加强对各自所负责项目的调度指挥，对标对表，不打折扣地全面完成工作任务。各项目审批、审查单位要主动对接项目业主，及时做好项目前期各项服务工作。

（二）加强质量监管。绿化建设项目要接受市城市管理和行政执法局的绿化规划设计审查、施工过程质量监管、工程竣工验收,确保规划设计科学合理、工程质量优良。同时，项目建设业主、施工队伍必须确保一年养护期满后工程合格，按时移交管理。

（三）多方筹措资金。坚持“政府主导、市场运作、全民参与”，多渠道筹措资金。积极开辟认建、认养城市绿地渠道,动员大型房地产企业捐资建绿，中央、省属单位出资对城区主次干道进行立体绿化、双排行道树栽植、树池改造、见缝插绿等。同时，鼓励广大干部群众积极参加义务植树，参与园林绿化建设管理。

（四）广泛宣传发动。进一步加大“绿城攻坚”宣传力度，增强市民绿化意识，充分调动社会各方面的积极性、主动性、创造性，营造人人关心、人人参与“绿城攻坚”活动的良好氛围。

（五）严格督查考核。将“绿城攻坚”活动任务完成情况列入年度绩效考核内容，市三创办、市创园办、市创森办要定期和不定期地开展督促检查，并对督查情况进行通报。对逾期未完成任务的，责令及时整改；对措施不力、行动迟缓、推诿扯皮的，严肃追究牵头单位、责任单位和责任人的责任。
