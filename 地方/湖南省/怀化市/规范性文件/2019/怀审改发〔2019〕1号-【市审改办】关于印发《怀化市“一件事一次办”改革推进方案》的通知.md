# 【市审改办】关于印发《怀化市“一件事一次办”改革推进方案》的通知

怀审改发〔2019〕1号

怀化市人民政府行政审批制度改革工作领导小组文件

关于印发《怀化市“一件事一次办”改革推进方案》的通知

各县市区人民政府，市直相关单位，怀化高新区、怀化经开区管委会，中央、省在怀单位：

《怀化市“一件事一次办”改革推进方案》已经市人民政府同意，现印发给你们，请结合实际认真贯彻落实。

怀化市人民政府行政审批制度改革工作领导小组

2019年7月15日

怀化市“一件事一次办”改革推进方案

为持续降低制度性交易成本，激发市场活力，营造更加便利的营商环境，根据《湖南省人民政府办公厅关于印发<“一件事一次办”改革工作实施方案>的通知》（湘政办发〔2019〕15号）及《湖南省政务管理服务局关于印发<“一件事一次办”改革市州推进方案》（湘政务函〔2019〕5号）文件精神，现就全市深入推进“一件事一次办”改革，制定本方案。

一、工作目标

按照“一次告知，一次表单，一次联办，一次办好”的工作要求，一事一攻关、一步一突破，2019年12月底之前，全面落实省首批公布的100项“一件事一次办”改革。到2020年底，全市实现政务服务事项“一件事一次办”全覆盖（法律法规另有规定的除外）。

二、重点任务

（一）梳理事项清单。

1.公布责任清单。依照湖南省首批100项“一件事一次办”事项目录，公布市本级与各县市区事项清单。8月底之前，县市区落实单独的50件“事”（第51-100项）改革，10月底之前市本级完成50件“一揽子事”（第1-50项）改革，其中，8月底前完成12件试点（见附件1：市本级“一件事一次办”改革12个试点项目责任清单）。

2.再造办事流程。聚焦每件“一件事”，市直相关部门、各县市区要全环节、全链条、全要素进行梳理，打通关节、归并流程，形成“一件事一次办”新的流程规程和办事指南。

3.整合一次表单。按照“三级四同”和“减环节、减材料、减时限、减费用”要求，对涉及多个部门“一件事”的材料，进行精简、优化、合并，由综合窗口整理成一张材料清单和申请表单，方便企业和群众到现场或通过网上平台一次性阅知，一次性填报。

4.探索赋权放权。建立将同一类别审批向一个层级集中、同一链条审批向一个关口集中的审批运行机制。鼓励将个人事项下放到县市区、各类园区和街道乡镇办理。市本级9月底之前完成对高新区、经开区、鹤城区赋权放权事项清单的制定。

（二）实现业务联办。

1.申请人依单申请。申请人填写“一件事”申请表单，会同材料清单一起送（发）政务中心“一件事一次办”综合窗口初审。

2.综合窗口统一受理。申请人在线下提交“一件事”申请材料的，由综合窗口统一受理并进行初审分发。对材料不全的，当场一次性告知申请人需补齐材料并出具一次性告知书；对申请材料次要条件或次要手续有欠缺的，在当事人承诺补正后，可先予受理分发由职能部门审核。材料齐全后，出具受理告知书，并将纸质材料分发到相关单位。申请人在线上发起“一件事”业务申请并提交申请材料的，由综合窗口受理后，通过“一件事一次办”业务系统自动进行材料分发，相关单位在收到分发到件提示后进行材料下载、审批操作。

3.业务部门限时办理。各联办单位在收到分件后，开展全面审查。对申请材料齐全、符合法定条件能当场办结的，一次性办好。对申请材料次要条件或次要手续有欠缺的，申请人承诺补正，采取容缺方式一次性办好。对申请材料齐全但需多部门到现场查验测量的，由联办的第一个单位发起、共同限时完成。各联办单位审批后将结果材料通过线上线下两种方式送（发）至综合受理窗口。

4.综合窗口统一出件。根据业务部门提供的结果材料，综合窗口统一出件后，将相关证照、批准文书等，采取现场递交、邮寄和网上传输等方式一次性将结果材料送达申请人。

（三）强化平台支撑。

1.提升实体大厅功能。

（1）保障场地面积。实体政务大厅场地（不含办公用房、技术用房）面积要求：市本级不低于8000平方米；沅陵、辰溪、溆浦、新晃、芷江、麻阳、中方、洪江市、会同、靖州、通道等县，不低于5000平米；鹤城区、洪江区不低于3000平米；怀化高新区、经开区不低于2000平方米。2019年底前，政务服务事项基本实现“应进必进”。

（2）优化窗口设置。按办事频度和关联度优化大厅布局；按“1+N”的模式设立综合窗口、主题窗口。在市、县政务服务中心设立自助服务区方便群众“自助办”；设立“一件事一次办”综合窗口；设立工程建设项目并联审批综合窗口（含帮代办窗口）。

（3）明确岗位职责。按照“前台统一受理、后台分类审批、综合窗口出件”的工作机制，通过政府购买服务，“一件事一次办”综合窗口聘用一批工作人员，开展受理、审核、分发、出件服务。各职能部门窗口在后台开展集中审批。

（4）完善设备配置。按照“一件事一次办”的要求，实体大厅配备必要的自助服务机、排队取号机、自助评价机、高拍仪等办公设备，不断提升服务功能。

（5）服务网点延伸。将自助设备向乡镇（街道）、村（社区）投放，开设自助终端试点，完成实体办事大厅延伸，方便企业群众“就近办”。

2.加强网络平台建设。

（1）建设全市统一的“互联网+政务服务”一体化平台。各县市区原则上依托市一体化平台开展相应的实施工作，实现市、县、乡、村四级政务服务平台的统一。对面向企业和群众的所有线上线下服务事项，逐步做到一网受理、协同服务，一网通办、全市通办。

（2）加强平台对接工作。2019年6月底前市“互联网+政务服务”一体化平台与省级政务服务平台完成对接，2019年7月底前市“一件事一次办”系统与县市区及其他市直部门保留的业务审批系统实现对接。加快完善与省统一身份认证系统、电子印章系统、统一物流系统、统一支付系统的对接，完善安全保障体系、运维管理体系，2020年底前实现跨系统、跨业务、跨部门、跨层级、跨地区“网络通、数据通、业务通”。

（3）完善市级信息资源共享交换平台建设。继续推进市信息资源共享交换平台建设，完善自然人、法人、自然资源和空间地理等基础数据库；加快推进电子证照、信用信息、金融信息等服务型数据库建设，形成全市统一的政务信息共享交换渠道。2019年实现市直部门间的数据共享，2020年实现市县两级的数据共享；加快与省级数据共享交换平台对接，实现省、市、县三级数据共享平台的对接。

（四）探索推行“三即”承诺制。

1.领照即开业。梳理、优化、再造市场准入审批流程，实现企业从设立到具备一般性经营条件的办理时间压缩到3个工作日以内。加快推进“证照分离”改革，许可事项清单以外事项一律不得作为限制企业经营的依据。

2.交房即交证。健全不动产登记信息实时互通共享机制，全面推行不动产登记、交易、税务“一窗受理、一站办结”（除法院拍卖、产权部分转让、赠与及拆迁减免等特殊业务外），提高不动产登记效率和便利化程度，实现不动产登记产权类业务3-5个工作日内完成，抵押类业务3个工作日之内完成。

3.交地即开工。全力落实工程建设项目审批制度改革，大力推行多图联审、多测合一、多评合一、区域评估等工作机制，在园区试点“先建后验”告知承诺制和工业用地“标准地”出让模式。将政府和社会投资项目从立项到开工的审批时间压缩至86天、61天之内。

（五）提升政务监管效能。

1.完善事中事后监管。做好公示系统（湖南）与怀化市信用信息共享交换平台的对接优化，深入推进“双随机、一公开”监管全覆盖、常态化，治理认证乱象，全面强化信用监管，完善守信联合激励和失信联合惩戒机制。建立覆盖全市各层级、与抽查事项相对应的检查对象名录库和执法检查人员名录库。

2.打造12345热线政务服务客服号。将市县12345服务热线作为政务服务客服电话，统一受理企业群众对政务服务事项办理的咨询、投诉和反馈，做到即时咨询、即时答复，切实增强群众获得感、满意度。

3.建立电子监察系统。重点围绕“一件事一次办”开展全程监督、评价并及时反馈；拓展效能监督深度广度，强化对“互联网+政务服务”一体化平台、数据共享交换平台、线上线下融合、电子政务外网统一云平台等使用效能的监督。

三、分步推进

（一）形成示例范本。

对照省里首批100件“一件事”，市本级从“一揽子事”中选择12件“事”先行先试，组织精干力量逐个环节集中攻关，强力推动落实，在实践操作中逐步完善，形成“怀化范本”。

（二）推广示例范本。

对形成的示例范本，成熟一个，推广一个，以点带面，带动其他事项尽快落实。县市区要将本区域内示例范本报市政府办（政务服务科），市政府办优中择优，在全市进行推广。

（三）开展体验式办理。

在政务服务大厅设立“一件事一次办”体验区，开展体验式办理，对“一件事一次办”事项，逐个走一遍流程，检验改革成效，找出问题，及时解决。市政府办将适时组织有关部门和人员对各县市区改革事项进行体验式办理，发现问题，督促整改。

（四）总体提炼经验。

市直相关部门，各县市区在“一件事一次办”改革过程中要勇于创新，认真总结提炼，形成典型经验，在年底前全面总结改革成效，形成制度性、经验性成果。

四、保障措施

（一）加强组织领导。

根据机构改革情况的变动，重新调整市人民政府行政审批制度改革工作领导小组成员，并实行“一办三组”（办公室、事项梳理组、平台建设组、工作保障组）的工作运行机制，抽调专人集中办公，按照本方案责任体系（见附件2：怀化市“一件事一次办”改革责任体系分工安排表）要求，加强对全市改革工作的统筹协调和指导督促。各县市区和市直相关部门单位也要参照市里的工作机制，制定配套方案，压实工作责任，形成一级抓一级的工作格局，确保各项工作任务落实、落地、落细。

（二）注重宣传引导。

各级各部门要加强对“一件事一次办”全流程操作指南解读解说，告知群众办理方式、办理流程，营造良好实践操作环境；充分利用广播、电视、新媒体等载体宣传“一件事一次办”改革的典型经验和做法，并将典型经验及时报市政府办。（联系人：刘远宁；电话：0745-2718666；邮箱：hhzwfw2136@163.com）

（三）强化调度督办。

各级各部门要根据全市统一安排，紧盯任务时间节点，逐项落实工作责任。市直相关单位及各县市区每攻破一件“事”，要即时填报《100个事项“一件事一次办”实现情况表》（见附件3），每半月向市政府办条目式简要报送工作情况，遇到重点难点问题及时汇报，以便市政府办及时调度，督导解决。市政府办将半月一调度、一月一通报改革进展情况。

（四）严格考核问责。

“一件事一次办”改革已列入2019年度省委改革工作重要内容，也是省委集中整治形式主义官僚主义20条措施之一，我市也将“一件事一次办”改革纳入2019年全市绩效考核指标。各级各部门务必提高政治站位，“一把手”要亲自抓。市政府办将协同相关部门综合运用督查激励、通报问责、第三方评估等手段，对工作滞后的县市区和市直部门重点督办。对督办后仍未见成效的，提请市政府对单位主要负责人进行约谈。对不作为、慢作为、乱作为的部门单位，情节严重、涉嫌违规违纪违法的，交由市纪委监委严肃查处。
