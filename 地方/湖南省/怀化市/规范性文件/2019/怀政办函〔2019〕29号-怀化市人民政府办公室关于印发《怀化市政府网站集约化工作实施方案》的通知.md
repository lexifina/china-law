# 怀化市人民政府办公室关于印发《怀化市政府网站集约化工作实施方案》的通知

各县市区人民政府，市直机关各单位：

经市人民政府同意，现将《怀化市政府网站集约化工作实施方案》印发给你们，请认真组织实施。

怀化市人民政府办公室

2019年5月22日

怀化市政府网站集约化工作实施方案

为贯彻落实《湖南省人民政府办公厅关于做好全省政府网站集约化试点工作的通知》（湘政办函〔2019〕14号）精神，加快推进我市政府网站集约化建设，确保按时完成建设任务，制定本方案。

一、工作目标

以市政府网站集约化平台为中心，推进全市政府网站集约化建设，形成以市政府门户网站为主网站，县市区政府和市政府部门、直属机构网站为子网站的政府网站群，统一技术平台、统一标准体系、统一安全防护、统一运维监管，推进资源整合、集约共享，提高政府网站管理和服务水平。2019年9月底前，完成全市政府网站集约化工作。

二、建设模式

根据省政府要求，采用“市级统建、区县实施”模式，对全市各级政府门户网站、政府部门网站进行集约化建设。建成市级政府网站集约化平台后，各县市区政府和市政府各部门、各直属机构使用“.gov.cn”为后缀的政府网站全部迁移至集约化平台。其中：集约化平台建设经费和市直部门网站集约经费由市财政统筹，各县市区政府门户网站集约实施经费由各县市区按照全市统一集约化平台建设方案自行统筹。

三、重点任务

按照统一技术平台、统一标准体系、统一安全防护、统一运维监管的要求，推进数据融通、服务融通、应用融通。

（一）建设全市政府网站集约化平台

按照全省统一标准规范，将全市各级政府门户网站、政府部门网站集约至市政府门户网站技术平台，建成向平台上的政府网站提供统一站点管理、栏目管理、资源管理、权限管理、内容发布、互动交流、用户注册、统一身份认证、站内搜索、投诉举报、评价监督、个性定制、内容推送、运维监控、统计分析、安全防护等功能支撑的政府网站集约化平台。

（二）建设集约化平台安全防护体系

严格落实网络安全法和关键信息基础设施安全保护有关要求，加快推进市、县两级电子政务外网平台升级改造，其中市本级达到三级保护等级，各县市区至少达到二级保护等级；建立安全监测预警机制，通过技术手段对集约化平台数据、硬件、软件、通信网络、资源等进行监控，实时全面掌控集约化平台各项数据，对异常情况及时报警和处置；建立政府网站信息数据安全保护制度，加强域名解析安全防护，对政府网站域名进行集中解析，并完成电子政务外网改造任务，确保全面支持互联网协议第六版（IPv6）。

（三）建设统一的网上政务服务平台

打造全市“三统一”“一窗口”政府网站服务平台。搭建全市统一互动交流平台，统一智能检索、智能问答和咨询问答库，为全市政府网站提供留言评论、咨询投诉、征集调查、在线访谈、检索问答等服务；定制全市统一“千人千网”平台，以用户需求为导向，加强信息资源开发利用，主动推送服务信息，努力为用户提供“千人千网”等个性化、便捷化的政务服务；建设全市统一政务新媒体平台，以市政府门户网站政务新媒体为龙头，推动政务信息数据资源向“两微一端”等延伸拓展，实现政府网站和政务新媒体数据同源、服务同根、更新同步，提供多渠道、便利化的“掌上服务”；建设全市政府网站政务服务窗口，以市政府门户网站作为总入口，各级政府网站为分入口，各类对外服务的业务系统应作为政务服务内容整合到政务服务平台，与“互联网+政务服务”平台实现数据融合，统一对外提供服务。

（四）建设信息资源库

根据省里的统一部署建设市信息资源库，按照“先入库、后使用”原则，进行统一管理和持续完善，不断推动跨网站、跨系统、跨层级的资源相互调用和信息互认共享。

四、实施步骤

（一）2019年5月底前完成全市政府网站集约化平台招投标工作；完成5家政府工作部门新建政府网站的逐级申请和审核，并申报入全国政府网站普查系统；完成5家因机构改革职能调整部门网站的整合工作。

（二）2019年6月底前完成5家关停部门网站全国政府网站普查系统的申请及域名注销工作；完成市政府门户网站平台的建设和数据迁移，并完成互联网协议第六版(IPv6)改造方案的编制和上报。

（三）2019年7月底前完成市直部门网站平台集约和数据迁移；8月底前完成县市区政府门户网站平台集约和数据迁移。

（四）2019年9月底前全市政府网站集约化平台及配套的政府网站服务平台上线试运行，完成全省统一信息资源库的部署和信息系统三级保护等级建设工作。

（五）2019年11月底前完成全市集约化平台信息资源入库，实现集约化平台数据互联互通，并完成互联网协议第六版(IPv6)改造的部署工作。

五、工作要求

（一）加强组织领导。市政府办公室负责统筹协调、检查指导全市政府网站集约化工作。市政务服务中心负责市级平台建设，具体组织实施全市政府网站集约化建设工作。各县市区政府、市直各部门负责本地区本部门网站集约化建设实施，按照本方案确定的工作目标、建设模式、重点任务和实施步骤，认真抓好落实。

（二）强化运维保障。各级各部门要为政府网站集约化工作安排必要的人员和经费，县市区政府要把政府网站集约化平台实施及运维经费纳入财政预算。探索通过购买服务等方式，保障政府网站集约化平台技术功能迭代更新的需要。健全完善培训交流机制，定期组织开展培训，建立交流平台，加强业务研讨，加强工作总结，分享经验做法，共同提高政府网站集约化建设水平。

（三）加强督导检查。市政务服务中心要加强政府网站集约化建设工作的督导检查，对行动迟缓、拖延推诿、未按统一时限要求完成工作任务的予以通报批评，对影响政府网站普查的约谈其相关责任人。

各县市区要结合实际抓紧制定实施方案，细化任务措施，明确时间节点，于2019年5月底前报市政府办公室备案，每月底定期报送工作进展情况。各县市区、市直各单位要将政府网站集约化建设工作的分管领导和联络员名单（职务、电话、电子邮箱）于2019年5月27日前报送至市政府办公室。(联系人：胡敏，电话兼传真：2713621，电子邮箱：6842361@qq.com)
