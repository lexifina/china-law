# 怀化市人民政府办公室关于认真落实2019年市《政府工作报告》主要目标任务的通知

各县市区人民政府，市直机关各单位，中央、省在怀各单位：

为认真落实2019年市《政府工作报告》主要目标任务，经市人民政府同意，现就有关事项通知如下：

一、统一思想，强化调度

2019年是新中国成立70周年，是决胜全面建成小康社会第一个百年奋斗目标的关键之年。《政府工作报告》是市政府的施政纲领，是向人大代表、政协委员和全市人民作出的庄严承诺，各级各部门一定要对标目标任务，制定切实可行的工作方案，认真抓好落实，分管领导要一月一调度，主要负责人要一季一调度。每个季度末或下个季度初，市人民政府将对《政府工作报告》目标任务完成情况进行总调度。第一责任单位每季度第一个月的10日前要将上季度工作进展情况、存在问题和下一步工作安排汇总，以书面形式报市政府督查室。

二、科学运作，落实责任

各级各部门要迅速部署，根据“一个项目、一名分管领导、一个牵头单位、一批责任单位”的责任体系，将所承担的工作任务进一步细化分解，推行工作项目化、责任具体化、运作联动化，将工作任务落实到具体领导，明确到具体责任人，逐项按月明确进度要求，实行“挂图作战”。各级政府各部门行政主要负责人原则上是第一责任人，必须科学计划安排，靠前指挥，亲自督战。

三、形成合力，严格考核问责

第一责任单位要发挥统筹协调作用，推动工作落实。责任单位要主动配合，各司其职，形成合力，确保任务目标顺利推进。市政府督查室要对任务落实情况开展定期和不定期督查，并进行通报。对达不到进度要求的，第一责任单位要及时查清原因，找出症结，制订解决方案，并付诸实施。同时，建立责任追究制度，把指标按时、按质完成情况作为绩效考核、评先评优的主要依据。对没有完成指标任务的，计扣绩效考核分值；对担当不力、落实不力、推进不力，以及失职、渎职或违法违纪的，严格按照相关规定进行追责问责。

本通知下发后，如领导分工和部门职能有变动，则随分工和职能相应调整，不再另行发文。
