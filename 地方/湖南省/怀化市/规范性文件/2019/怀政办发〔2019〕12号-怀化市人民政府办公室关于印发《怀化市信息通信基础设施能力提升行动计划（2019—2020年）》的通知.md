# 怀化市人民政府办公室关于印发《怀化市信息通信基础设施能力提升行动计划（2019—2020年）》的通知

各县市区人民政府，市直有关单位：

《怀化市信息通信基础设施能力提升行动计划（2019—2020年）》已经市人民政府同意，现印发给你们，请认真贯彻落实。

怀化市人民政府办公室

2019年4月29日

怀化市信息通信基础设施能力提升行动计划（2019—2020年）

为贯彻落实党中央、国务院网络强国战略部署，加快我市信息通信基础设施建设，支撑怀化经济高质量发展，根据《湖南省人民政府办公厅关于印发<湖南省信息通信基础设施能力提升行动计划（2018-2020年）>的通知》（湘政办发〔2018〕53号）精神，结合我市实际，特制定如下计划。

一、主要目标

积极开展信息通信基础设施建设和升级改造，提高新一代移动网络覆盖水平，力争到2020年实现城乡光纤网络、4G网络全覆盖，推进5G网络建设，使我市信息通信基础设施能力与经济社会发展需求相适应，满足人民群众日益增长的信息通信应用需求。具体目标如下：

2019年目标：全市城镇光纤覆盖98%以上居民小区、楼宇、学校、园区，农村地区自然村（20户以上村民小组或聚居寨）光纤通达率达到55%；全市4G移动通信基站新增776个， 100%的行政村及80%的自然村（20户以上村民小组或聚居寨）4G覆盖，新增铁塔120座；力争启动5G基站建设，实现热点区域5G覆盖；新增NB-IoT基站1646站，乡镇以上区域形成连续覆盖；形成企业级数据中心，拓展云计算的外部应用。新增移动宽带用户35.3万户、新增固定家庭宽带用户13.5万户，分别达到360万户、113.5万户。

2020年目标：全市城镇光纤覆盖100%以上居民小区、楼宇、学校、园区，农村地区自然村（20户以上村民小组或聚居寨）光纤通达率达到60%；4G移动通信基站新增602站，90%的自然村（20户以上村民小组或聚居寨）4G覆盖；全面开启5G基站建设，具备规模化服务能力； NB-IoT基站新增617站，城乡普遍覆盖；全市各数据中心、云服务平台完成IPv6改造，数据中心产业链初步完善，云服务实现按需供给。新增固定家庭宽带用户13.5万户，移动宽带用户37.4万户，力争主要通信发展指标达到全省上游水平。

二、重点任务

（一）开展光网提升行动，建设高水平全光纤网络。

1.构建高速骨干光纤网络。优化互联网骨干网的架构，提高骨干网络的出市带宽和质量。总出市带宽达到1500G以上。

2.打造千兆光网城市。大力推进“千兆光纤进楼宇、百兆光纤进家庭”行动，全面推进新建住宅小区和商业楼宇落实国家光纤到户标准，新城区超前规划建设通信管道，既有住宅小区和商业楼宇采取成片区、分批次开展光纤到户改造，落实共建共享要求，确保通信企业平等接入和用户自由选择权。到2020年底，城镇地区光纤覆盖率达99%以上，实现所有城镇用户接入能力100Mbps以上，总体实现用户接入能力和用户接入速率双翻番，90%宽带用户的接入速率达到100Mbps以上，支撑4K电视等高带宽业务普及应用。打造100个以上千兆光纤入户示范小区，其中：2019年打造千兆小区30个，2020年打造千兆小区60个。

3.建设百兆光网乡村。实施乡村信息基础设施振兴工程，充分发挥财政资金引导作用，深入推进电信普遍服务试点。鼓励通信企业在行政村村村通光纤的基础上，加快推进光纤网络向自然村、村民小组延伸。引导通信企业降低农村用户宽带接入资费，提升农村地区宽带用户普及率。到2020年底，全市60%自然村（20户以上村民小组或聚居寨）实现光纤网络通达，50户以上自然村光纤网络基本通达，农村90%以上宽带用户接入能力达到100Mbps以上，50%宽带用户的接入速率达到100Mbps以上。

4.实施光网扶贫行动。积极向上级争取电信普遍服务资金，优先投向贫困村特别是深度贫困村的光纤网络建设，鼓励企业通过在贫困地区开展视频服务、建立交互式网络电视（IPTV）等方式，提供各类扶贫资讯及应用，满足贫困群众多样化、多层次文化信息需求，促进文化信息消费。进一步加大网络提速降费力度，引导通信企业加大面向贫困地区和贫困人口的优惠力度，鼓励推出扶贫专属资费优惠，减轻贫困人口宽带网络使用负担。

（牵头单位：市工业和信息化局、省通信管理局怀化市通信发展管理办公室、市扶贫办、市发改委、市财政局；配合单位：各县市区人民政府；实施单位：中国电信怀化分公司、中国移动怀化分公司、中国联通怀化分公司、湖南有线怀化网络有限公司）

（二）开展无线网络提升行动，提高新一代移动网络覆盖水平。

1.推进4G网络扶贫行动。到2019年实现全市行政村4G移动宽带互联网100%覆盖。

2.推进乡镇及以上区域的4G连续覆盖，为Volte营造良好环境，为5G建设铺路搭桥。2019年重点解决市区县城的4G深度覆盖问题，力争达到市区县城区域内覆盖率达到100%。到2020年底，争取完成乡镇4G连续覆盖。

3.推进高速公路、高铁等沿线4G网络覆盖。开展高速公路、高铁沿线4G网络覆盖提升行动，确保现有的高速公路、高铁沿线4G网络覆盖，新开工的高速公路、高铁线路实现4G网络同步规划、同步建设、同步验收。到2019年底，实现张吉怀高铁怀化段4G网络覆盖与铁路建设同步开建。到2020年底，实现高速公路及高铁沿线及隧道、车站、服务区、收费站4G网络覆盖率达到100%，国道全线里程4G网络覆盖率达到95%，重要航道4G网络覆盖率达到98%以上。增加高速公路沿线铁塔建设密度，充分共享铁塔基础设施、电力供应、网络线路等资源，为开展警用350M数字集群通信系统建设提供基础条件。

4.推进5G网络规模建设。推动社会杆塔与通信杆塔双向开放共享，城管、电力、公安、房产等单位全力配合，支持运营商积极提交需求，由铁塔公司统筹集约利用社会资源，依托市政道路、铁路、视频杆、监控路灯杆（含小区内部）、公交站点等公用设施，提前储备5G站址资源。到2019年底，完成5G网络规划编制，三家电信企业完成5G试点基站开通。到2020年底，全面启动5G网络规模化部署。

（牵头单位：市工业和信息化局、省通信管理局怀化市通信发展管理办公室；配合单位：市国资委、市住房城乡建设局、市发改委、市公安局、市城市管理和综合执法局、国网怀化供电公司、市交警支队、各县市区人民政府；实施单位：中国铁塔怀化分公司、中国电信怀化分公司、中国移动怀化分公司、中国联通怀化分公司、湖南有线怀化网络有限公司）

（三）加快信息通信应用设施建设，满足日益增长的需求。

1.加快窄带物联网（NB-IoT）基站建设。加快推进NB-IoT等物联网网络建设，将网络覆盖由城市、部分县城和热点乡镇向全市县城和乡镇、热点农村区域延伸。推广NB-IoT在智能抄表、环保监测、交通管理、工业互联网等领域的应用，逐步开展中速物联网的试点部署，到2020年底，全市再新增NB-IoT基站2100站，NB-IoT网络实现业务需求重点区域深度覆盖。

2.开展工业互联网基础设施建设。积极争取在我市布局省级建设标识解析节点和公共递归解析节点，开展工业互联网标识解析的产业化应用模式探索，打破信息孤岛，实现工业大数据的有效汇聚；通信企业争取上级公司的支持，到2020年底基本建成满足企业低时延、高可靠、广覆盖的工业网络。

3.加强数据中心、云计算设施建设。适当降低大型数据中心（IDC）用电成本，引导通信企业和IDC企业下调数据中心服务价格水平，提高综合服务能力，形成明显的比较优势，全面提升我市数据中心服务的综合竞争力，带动数字经济产业发展。支持中国联通怀化分公司、中国电信怀化分公司、中国移动怀化分公司以及京东等互联网企业云数据中心做大做强，促进我市大数据、云计算、人工智能等产业规模持续扩大。

4.推动通信网络设施升级。到2020年底，全市各数据中心、云服务平台完成IPv6改造，为用户提供IPv6访问通道，逐步推进IPv6在经济社会各领域深度融合应用。

（牵头单位：市工业和信息化局；配合单位：省通信管理局怀化市通信发展管理办公室、市住房城乡建设局、市发改委、各县市区人民政府；实施单位：中国铁塔怀化分公司、中国电信怀化分公司、中国移动怀化分公司、中国联通怀化分公司、湖南有线怀化网络有限公司）

三、保障措施

（一）成立专项工作推进组。成立怀化市信息通信基础设施建设工作推进组，由副市长姚述铭任组长，办公室设在市工业和信息化局。推进组办公室负责统筹行动计划工作总体部署、组织协调和监督指导，研究解决重大事项和问题。

（二）强化督导落实。市政府督查室对行动计划中重点任务和支持政策落实情况，组织相关部门加强督查督办，对落实不力的，适时通报。各县市区人民政府要切实帮助解决基站选址难、管线铺设难、拆迁补偿难等问题。

（三）加强规划管理。将基础电信企业、市工业和信息化局纳入市规委会成员单位，加强通信基础设施专项规划与城市总体规划、控制性详细规划、土地利用总体规划相衔接，确保新（改、扩）建城市道路、隧道、综合管廊等市政基础设施与通信基础设施同步投入使用、新建住宅小区及商住楼建筑红线内通信设施及网络配套同步建设并纳入总造价。

(四）加强信息通信基础设施保护及关键网络安全防护。公安机关要加强信息通信基础设施保护，严格执行《湖南省通信条例》，依法惩处破坏信息基础设施、偷盗通信设施用电、阻挠信息基础设施建设维护、妨碍应急通信保障及通信设施抢修救险等违法行为。对因征地拆迁、城乡建设等造成基站、机房等通信基础设施迁移和损毁的，应按照有关法律和政策予以补偿。自然资源和规划部门在审批居民或单位建房用地时，发现建设用地上有通信设施，须由设施产权方签字确认再审批。各运营商应加强关键通信基础设施的网络安全防护。

（五）全面开放公共资源。除法律法规另有规定外，全面开放电力路灯杆、公安监控杆、交通信号杆、道路指示牌等公共杆塔资源支持通信基站建设，全面开放楼宇屋（墙）面、强弱电管网等公共资源支持通信基础设施建设，开放旅游景区、公共园林、道路绿化带等公共用地用于通信基础设施建设。

（六）建立公平有序的通信市场准入机制。规范住宅小区及商业楼宇、办公楼、宾馆、酒店、交通枢纽、高校、公共场馆、医院等场所通信配套设施建设行为，积极支持光纤入户以及管线、基站、室内分布系统等网络基础设施建设。禁止房地产企业、物业服务企业对通信基础设施建设收取任何准入费用、实施阻挠行为、与企业签订排他性协议，确保通信企业公平接入，维护用户自由选择通信服务的权益。大型园区、聚类场所的管道纳入园区统一配套建设，各基础电信企业以免费方式接入。

（责任单位：市工业和信息化局、市政府督查室、市自然资源和规划局、市公安局、市住房城乡建设局、市城市管理和综合执法局、国网怀化供电公司、市交警支队、市发改委、各县市区人民政府）
