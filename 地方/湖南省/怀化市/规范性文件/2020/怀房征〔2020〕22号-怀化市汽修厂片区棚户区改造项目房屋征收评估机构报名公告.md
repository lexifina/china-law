# 怀化市汽修厂片区棚户区改造项目房屋征收评估机构报名公告

怀房征〔2020〕22号

经怀化市人民政府批准，拟对怀化市汽修厂片区棚户区改造项目红线范围内的国有土地上房屋实施征收，为依法确定被征收房屋补偿价值，根据国务院《国有土地上房屋征收与补偿条例》（国务院令590号）《国有土地上房屋征收评估办法》（建房〔2011〕77号）《怀化市区国有土地上房屋征收评估管理办法》（怀政办发〔2016〕24号）等规定，现公开接受房地产价格评估机构报名。报名成功的房地产价格评估机构为候选评估机构，由被征收人在其中选定1家开展相关评估工作。现将报名有关事项公告如下：

一、项目名称

怀化市汽修厂片区棚户区改造项目。

二、项目概况

该项目位于原怀化市汽修厂用地范围内，项目占地面积约22.4亩，共涉及被征收房屋约102户（全部为私有住宅房屋），建筑面积约7560.43㎡，具体征收范围以该项目征收决定所附红线图为准。

三、委托单位

怀化市鹤城区住房和城乡建设局。

四、委托评估内容

（一）对被征收房屋及附属物补偿价值进行评估；

（二）对产权调换房屋市场价值进行评估；

（三）对被征收房屋装饰装修补偿价值进行评估。

五、报名条件

（一）已入选2020年度怀化市国有土地上房屋征收评估机构备选库，熟悉怀化市房地产市场和房屋征收评估业务，近两年内没有不良行为记录。

（二）能确保3名以上注册房地产估价师参与该项目（在报名时予以确认），其中2名房地产估价师须全程参与项目房屋征收评估业务和解释答复工作，直至全部签订房屋征收补偿协议。

六、报名需提交的资料

（一）报名表；

（二）评估机构营业执照、资质证书、法定代表人身份证明、估价师身份证、估价师注册证书及资格证书；

（三）近三年从事房屋征收项目评估工作情况；

（四）法定代表人委托报名的，须提供法定代表人授权委托书和委托代理人的身份证。

（以上材料装订成册，复印件加盖单位公章并在报名时携带原件备查）

以上报名资料由市、区房屋征收部门工作人员现场核查确认受理。

七、候选评估机构

参加报名的评估机构不足3家的，由鹤城区房屋征收部门在2020年度怀化市国有土地上房屋征收评估机构备选库中抽取，补足3家。

八、报名时间、地点

（一）报名时间：自公告之日起至2020年8月25日18:00止。

（二）报名地点：怀化市汽修厂片区棚户区改造项目指挥部。

（三）逾期报名的，不予受理。
