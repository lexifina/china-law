# 关于实施城乡居民基本医疗保险门诊统筹的通知

各县区（管理区）医疗保障局，卫生健康局：

为完善城乡居民基本医疗保险制度政策体系，保障参保对象门诊基本医疗需求，根据《湖南省医疗保障局

湖南省财政厅 湖南省卫生健康委员会关于实施城乡居民基本医疗保险门诊统筹的通知》（湘医保发〔2019〕20号）精神，现就在全市实行城乡居民基本医疗保险普通门诊统筹管理有关事项通知如下。

一、实施范围

参保对象在参保地的乡镇卫生院（含乡镇卫生院分院和非建制乡镇卫生院，下同）、社区卫生服务中心（含社区卫生服务站，下同）和村卫生室门诊就医的医疗费用，实行门诊统筹报销管理。

二、筹资标准与管理模式

1、门诊统筹基金按政策从医保基金中列支，按当年医保基金总额的10%左右确定，具体标准由县级医疗保障局根据本地实际情况确定。

2、按照“以收定支、收支平衡、略有结余”的原则，各县区（管理区）在确定门诊统筹基金筹资规模后，综合考虑人口、医疗技术、区域内基层医疗机构数量等因素，确定每个乡镇（街道、社区）门诊统筹总额控费指标，并分配到各乡镇卫生院、社区卫生服务中心，再由乡镇卫生院、社区服务中心按20%左右的比例分配到辖区的各村卫生室，并报县区医保局备案。当年门诊统筹费用超出总额控费指标的，由相应的基层医疗机构承担。

3、参保对象在协议基层医疗机构发生的门诊医疗费用纳入门诊统筹基金支付范围包括：按照分级诊疗服务功能定位提供的、符合基本医疗保险“三个目录”范围的门诊医疗项目。

三、支付政策

1、参保对象在参保地（县域内）门诊统筹定点医疗机构可自主选择就诊，并刷卡即时结算。未在门诊统筹定点医疗机构即时结算的门诊费用和在参保县域以外发生的门诊费用不予报销。门诊统筹每人每天限报账一次。

2、实行门诊统筹“限额付费制”，城乡居民参保对象在乡镇卫生院、社区卫生服务中心门诊看病，每次只需自付15元（不足15元的，据实自付）；在村卫生室门诊看病，每次只需自付8元（不足8元的，据实自付）。

3、严格控制门诊医疗费用。乡镇卫生院、社区卫生服务中心的门诊医疗费用，每月平均须控制在“50元∕人次”内（门诊统筹基金每月次均报销“限额35元/人次”）；村卫生室的门诊医疗费用，每月平均须控制在“30元∕人次”内（门诊统筹基金每月次均报销“限额22元/人次”）。超出的门诊医疗费用，由相应的基层医疗机构自负。

4、门诊统筹定点医疗机构的结算实行属地管理，门诊统筹定点医疗机构应按月将普通门诊统筹患者的医疗费用汇总后，报参保地医保经办机构审核、拨付。实行医共体的县区（管理区）由各医共体牵头单位负责。

5、对乡镇卫生院、社区卫生服务中心和村卫生室的门诊统筹结算，县级医保部门应当按月结算，逐月结清。

6、2019年，我市城乡居民医保家庭账户资金已划转，参保患者使用完家庭账户资金后再进行门诊统筹基金报销。从2020年起，全面取消门诊家庭账户制度，历年结余家庭账户资金，可用于门诊统筹个人自负部分结算。

四、工作要求

1、各县区（管理区）医疗保障局应根据本《通知》要求，制定具体的实施细则（须报市医疗保障局审核同意后方可实施）。

2、各县区（管理区）医疗保障部门应加强对门诊统筹定点医疗机构的监督和管理。要细化管理措施、服务质量、考核结算办法和奖惩机制等，确保门诊统筹服务质量，提高资金使用效率。各地医疗保障部门按月抽取一定比例的参保病人处方、医疗费用票据进行审核，对不符合规定的医疗费用，门诊统筹基金不予结算。

本通知自2019年9月1日实施，试行期一年，试行期满后进行政策评估，并提出修订完善的建议，按程序报批后正式实施。
