# 关于转发《交通运输部安委会关于转发国务院安委会办公室关于切实做好全国“两会”期间安全生产工作的通知》的通知

厅安办〔2017〕11号

各市州交通运输局，厅直各有关单位：

2017年春运已于昨日结束，全国“两会”将于3月上旬在北京召开。为进一步做好春运后及全国“两会”期间的交通运输安全生产工作，省厅现将《交通运输部安委会关于转发国务院安委会办公室关于切实做好全国“两会”期间安全生产工作的通知》（交安委明电〔2017〕1号）转发给你们，同时结合《湖南省安全生产委员会关于涟源市祖保煤矿“2·14”瓦斯爆炸事故的通报》（湘安明电〔2017〕2号）文件精神，就进一步抓好当前交通运输安全生产工作提出要求，请各单位一并抓好落实。

一、高度重视当前交通运输安全生产工作

全国“两会”历来是全国人民政治生活中的大事、盛事，确保“两会”期间安全生产形势稳定是交通运输部门不可推卸的责任，也是政治意识、大局意识、核心意识、看齐意识的重要体现。每年二、三月份，特别是春运结束后，往往是事故的高发期。全省各级交通运输部门、行业管理机构、交通运输企业要引起高度重视，切实加强对春运后及全国“两会”期间安全生产工作的组织领导。要有“清零意识”，贯彻“安全生产工作始终从零开始”的思维，坚决杜绝春运结束后产生麻痹松懈思想，始终把交通运输安全生产工作放在各项工作的首位。要在春运安全生产工作既有成效和经验的基础上，针对春运后往往事故易发多发的特点，结合全国“两会”召开严肃的政治要求，进一步拧紧发条、细化措施、加强管理，切实防范各类安全生产事故发生。

二、进一步抓好重点领域的安全生产工作

春运过后，逐渐迎来春暖花开时节，中短途旅游客流预计将会升温，给道路运输和水上交通安全生产带来新的压力，公路水运工程建设也逐步迎来节后复工潮。一是要进一步抓好道路运输领域安全生产工作，特别是要加大对从事夜间道路客运、旅游包车客运和危险化学品道路运输企业的监督检查管理力度，落实营运车辆动态监管各项要求；要督促客运站严格落实“三不进站、六不出站”和安全告知制度。二是要进一步抓好水上交通安全生产工作，督促有关水上运输企业落实安全生产主体责任，对“四类重点船舶” 加强技术性能监测，对“一湖两江三库”重点水域以及发展水上旅游业务的通航水域水上交通秩序加强监管，进一步加强对航道的巡查、疏浚和养护；要继续督促县乡政府履行好渡口渡船安全管理责任，确保渡运安全生产。三是要进一步抓好交通工程建设领域安全生产工作，结合《关于开展节后复工安全生产大检查的通知》（厅安委〔2017〕2号）要求，严格执行“五落实五到位”制度规定，加强开工前隐患排查治理工作和安全生产条件验收管理。

三、认真做好安全生产应急管理工作，严肃执行信息报送各项规定

春季气候多变，天气反复无常。各有关单位要有针对性地制订、完善相关应急预案，加强宣教和演练，切实做好安全防范工作。要密切与气象、水文（水利）、公安交警等有关部门的沟通联系和协调联动，及时掌握和发布天气变化、道路通行、铁路专用线及社会道口运营预警信息，并及时做好公路养护工作，为道路运输、铁路专用线运营、水上交通和群众出游服务。要严肃执行安全生产信息报送各项规定，明确专门报送人员，落实报送工作责任，杜绝迟报、漏报、谎报、瞒报情况的发生。
