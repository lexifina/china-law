# 关于认真做好端午节小长假和高考期间交通运输安全工作的紧急通知

各市州交通运输局，厅直有关单位：

为了切实做好2017年我省端午节小长假和高考期间道路、水路运输安全保障工作，确保广大人民群众出行，给广大考生提供一个安全、顺畅、快捷的交通运输环境.现将有关事项紧急通知如下：

一、高度重视，周密部署。各市州交通运输局、厅直各有关单位的党政主要负责同志要高度重视端午节小长假和高考期间的安全工作，切实加强对此期间安全生产工作的组织领导，把安全工作放在当前各项工作的首位加强组织领导。要针对假期特点，结合“平安交通专项整治”、“隐患清零”行动和“安全生产月”等活动进行专题研究部署。要按照“三个必须管”的原则，督促班子其他成员厘清监管职责，落实监管责任，确保关于小长假安全生产的各项措施落实到位。各单位要结合当地实际，制定切实可行的安全保障预案，建立和完善各项安全制度，层层落实安全管理责任制和责任追究制，确保交通运输安全。

二、加强检查，强化监管。端午节期间，要把握道路运输、水上交通、港口生产、公路水运工程建设施工、公路养护作业、铁路专用线及轨道交通运营等重点领域，抓住“两客一危”重点车辆、汽车客运站、“四类重点船舶”、“一湖两线三库”重点水域、危险桥梁、高风险路段、高空作业等关键环节、关键对象，采取针对性措施，突出加强安全监管，督促相关交通运输企业切实做到安全责任到位、安全管理到位、安全投入到位、安全培训到位和应急救援到位，确保节日期间安全生产，服务群众便捷出行。高考期间，各地要加强高考学生乘车的安全管理，不仅要方便考生乘客出行，更要保障考生的乘车安全，要督促相关客运企业加强驾驶员、营运车辆的安全管理，加强驾驶员安全教育，杜绝存在安全隐患问题的车辆上路行驶，为广大考生提供便利安全出行条件。

三、加强值班值守和信息报送。端午小长假期间和高考期间，各单位要严格执行24小时值班制度和领导带班制度，确保政令和通讯畅通，要及时了解和掌握交通运输安全生产动态，妥善处理各类突发性事件和险情，并按照有关规定及时向上级有关部门报告，确保各类信息的畅通。各地发生的事故要及时报告省厅安委办，特别重大事故或突发事件要随时报告，并实行跟踪报告制度。
