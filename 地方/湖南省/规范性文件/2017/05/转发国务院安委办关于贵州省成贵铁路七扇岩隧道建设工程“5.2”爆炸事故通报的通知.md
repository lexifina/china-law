# 转发国务院安委办关于贵州省成贵铁路七扇岩隧道建设工程“5.2”爆炸事故通报的通知

各市州交通运输局和厅直有关单位：

现将《国务院安委办关于贵州省成贵铁路七扇岩隧道建设工程“5.2”爆炸事故通报的通知》（安委办函﹝2017﹞17号）转发给你们，请结合实际认真组织学习，深刻吸取近期全国和我省发生的几起重大事故教训，进一步强化全省交通建设施工领域的安全监管。要按照通报要求，深入开展交通建设领域安全专项治理，重点加强隧道、桥梁、深基坑、高边坡、涉水、临崖等施工条件复杂、施工难度大等工程项目的安全监管，督促企业严格落实安全生产主体责任，全面排查和防控事故风险，彻底整治事故隐患，有效防范和遏制群死群伤事故的发生。

请各单位迅速将本通知转发至各项目建设单位，并认真抓好贯彻落实。

附件：国务院安委会办公室关于贵州省成贵铁路七扇岩隧道建设工程“5.2”爆炸事故通报（安委办函﹝2017﹞17号）

湖南省交通运输厅安全生产委员会办公室
