# 关于2017年1-4月安全生产资料和信息报送情况的通报

各市州交通运输局，厅直各有关单位：

为进一步加强全省交通运输系统安全生产日常工作联系，强化事故隐患排查治理和事故形势分析，提高预防和遏制事故发生的能力，厅安委印发了《关于重申加强安全生产有关资料和信息报送工作的通知》（厅安委〔2016〕10号）。

2017年1-4月，各有关单位根据“厅安委〔2016〕10号”文件要求，对照各自职能职责，结合各自工作实际，全面梳理应报事项，不断提高报送质量，较好地完成了有关报送工作任务，全省交通运输系统安全生产工作日常联系进一步加强，事故形势分析、预防措施采取等管控能力进一步提升，保安全、强联系的成效初步显现。然而，通过梳理统计也发现，少数单位对该项工作认识不到位、履职不积极、报送不及时，反映了对安全生产常规、基础工作不够重视、对有关数据信息资料的统计分析不够到位等问题。厅根据1-4月份相关报送情况，对株洲市交通运输局，省水运管理局、省交通建设质量安全监督管理局共3家单位提出批评，并在省厅2017年对各市州交通运输局、厅直各有关单位的安全生产目标管理绩效考核时分别预扣减2分。

为了持续改进安全生产资料和信息报送工作，提高全系统安全监管、信息联通水平，省厅将在接下来的每一个季度对各单位落实该项工作情况进行通报。请各有关单位严肃认真对待，对照“厅安委〔2016〕10号”文件精神，结合本轮通报内容开展自查自纠，剖析问题与不足，加快整改落实，按时高质量做好下一阶段有关安全生产各项报送工作。
