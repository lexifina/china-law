# 关于规范交通运输安全生产隐患清单的通知

各市州交通运输局，厅直各行业管理局、省铁路专线办：

为加强安全生产隐患排查治理，规范隐患报送工作，厅统一制定了《交通运输安全生产隐患清单》（空白样表的电子版请登录厅安委办公共电子邮箱hnjtaqggyx@163.com下载,密码ggyx123456），现印发给你们，请遵照执行。现就有关事项通知如下：

一、今后，厅直各单位向厅安委办报送安全生产检查发现的隐患、各市州交通运输局向厅安委办报送辖区内的重大隐患，统一采用《交通运输安全生产隐患清单》。

二、厅直各行业管理局近期根据《湖南省交通运输厅关于开展全省交通运输安全生产“隐患清零”督查工作的通知》（湘交安监〔2017〕126号）组织的暗访活动中发现的隐患，也要按要求填报《交通运输安全生产隐患清单》，并于7月24日下班前报厅安委办。确有特殊情况不能按时报送的，需说明情况，并于厅级领导带队督查前将相关材料报厅安委办。
