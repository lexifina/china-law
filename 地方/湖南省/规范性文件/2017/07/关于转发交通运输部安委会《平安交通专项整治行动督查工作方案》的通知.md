# 关于转发交通运输部安委会《平安交通专项整治行动督查工作方案》的通知

各市州交通运输局，厅直各行业管理局、省铁路专线办，厅相关处室：

现将交通运输部安委会《平安交通专项整治行动督查工作方案》（交安委〔2017〕6号）转发给你们，并就有关事项通知如下：

一、请各单位特别是省道路运输管理局根据方案要求，对照两个附表的条款逐一开展自查，结合各自实际查漏补缺，并督促相关企业迅速开展自查自改，认真抓好有关安全生产和“平安交通”专项整治工作落实。

二、省厅将结合安全生产大检查、“隐患清零”行动督查，适时组织明查暗访，明查暗访结果将作为2017年对各单位安全生产绩效考核的重要依据。

附：交通运输部安委会关于印发平安交通专项整治行动督查工作方案的通知

湖南省交通运输厅安全生产委员会
