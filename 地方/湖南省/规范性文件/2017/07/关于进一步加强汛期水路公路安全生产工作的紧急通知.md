# 关于进一步加强汛期水路公路安全生产工作的紧急通知

各市州交通运输局，厅直各有关单位：

6月22日以来，我省遭遇强降雨袭击，目前我省湘江、资水、沅江干流及洞庭湖部分地区发生超警洪水，多地连续发生船舶走锚碰撞下游桥梁或其他构造物事件，严重影响人民群众生命财产安全。28日19时左右，在衡东县新塘镇洣河的京珠高速洣河桥上游约2千米，1艘挖砂船和7艘自御驳运砂船因洪水上涨从采砂区连在一起下滑，严重威胁下游高速公路桥梁运营安全。经多方努力，29日清晨险情排除。30日21时30分左右，湘西州泸溪县五里洲大桥遭受自沅江上游辰溪县漂流而下的2艘挖（运）砂船撞击，导致大桥栏杆被撞坏两排，桥墩不同程度受损，船舶横侧翻，卡在五里洲大桥处，情况十分危急，目前仍在紧急处置中。省委、省政府对此高度重视，要求我厅进一步采取有力措施确保交通运输畅通安全。根据省领导指示精神，现就近期全省水路公路保安全、保畅通工作进一步紧急要求如下：

一、进一步落实责任制，全力做好防汛各项工作

全省交通运输系统各级各部门必须把防汛抗灾作为当前交通运输工作的头等大事，进一步增强政治感和责任感，严格落实防汛责任。各级领导干部和各类防汛责任人必须在岗在位，以上率下，亲力亲为。要加强对防汛责任的督查，在防汛工作中因失职渎职造成重大损失的，要严肃追责问责。各交通运输管理部门、企业要及时服从和响应当地防指的指挥，加强防汛抢险物资、器材和队伍的运输调度，积极作为，把洪水给人民群众带来的不便和威胁降到最低程度，确保安全度汛。

二、全面做好水路公路安全隐患排查整改，严防走锚船舶影响安全事件发生

各级交通运输部门要在前期排查的基础上，全面做好问题整改，完善度汛方案，做好抢险物资器材准备。水运、海事管理机构要重点加强对船舶配员及值班制度落实情况的督促检查，确保船舶值班人员充足、船员适任；对辖区内长期停泊无人或少人看守的船舶，要提请当地政府落实属地管理责任，采取切实有力的措施，进一步加强系固和值班值守，防止走锚威胁下游人民群众生命财产安全。公路管理机构要重点加强沿水、临坡临崖公路及其附属设施的检查，有针对性地开展工作，遇到险情要及时处置；及时发布路况信息，设置警示标志强化诱导，及时公布绕行方案；水毁公路桥梁要及时抢修，确保畅通。

三、强化应急值守，协调联动科学处置突发事件

全省交通运输各级各部门要落实值班制度，加强应急值守，保持各类通信监控设备、应急车辆、船舶状况良好，确保应急方案完善，保障支援到位。遇到突发情况，及时准确上报各类信息，不得迟报、瞒报、谎报。同时，还应加强与受到影响的单位和地区的沟通协调，形成应急处置合力，确保应对突发事件时看得见、管得到、处置得当，最大限度地保障人民群众出行和生命财产安全。

湖南省交通运输厅安全生产委员会

2017年7月2日
