# 关于印发《全省交通运输系统2018年安全监管“强执法防事故”行动方案》的通知

各市州交通运输局，厅直各有关单位：

为进一步落实《湖南省安全生产委员会关于印发<2018年湖南省安全监管“强执法防事故”行动方案>的通知》（湘安发〔2018〕1号）精神，省厅制订了《全省交通运输系统2018年安全监管“强执法防事故”行动方案》，现予印发，请遵照执行。

湖南省交通运输厅安全生产委员会

2018年5月28日

全省交通运输系统

2018年安全监管“强执法防事故”行动方案

为进一步加强本系统安全生产监管执法工作，巩固2018年安全生产“打非治违百日行动”成果，推动全行业“落实企业安全生产主体责任年”活动取得实效，全力防范交通运输安全生产事故特别是重特大安全生产事故的发生，按照省统一部署，决定自当前至12月在全系统组织开展安全监管“强执法防事故”行动，现制定方案如下：

一、指导思想和工作目标

以习近平新时代中国特色社会主义思想为指导，深入贯彻党的十九大精神，牢固树立安全发展理念，坚持依法治安，严格落实“党政同责、一岗双责、齐抓共管、失职追责” 和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”要求，以预防事故为中心，以落实企业主体责任为重点，以加强监管执法为主线，在全系统深入开展安全监管“强执法防事故”行动。通过严格执法、严厉处罚、严肃问责，狠抓安全生产监管执法工作落实，努力实现安全生产监管方式的“三个转变”（由行政管理模式向依法治理机制转变、由运动式集中整治向常态化监管执法转变、由主要代替企业排查隐患向通过执法督促企业自觉排查隐患转变），有效推动安全生产步入法治化、规范化、常态化轨道。

二、主要内容

（一）深入开展安全生产法制教育。各市州交通运输局、厅直各有关单位要通过党委（党组）中心组学习、专题培训等形式，切实增强干部职工安全生产法治意识，提高以法治方式解决安全生产突出矛盾和问题的能力。要结合“落实企业安全生产主体责任年”活动、《交通运输从业人员安全素质提升方案》，督促所管行业、领域企业开展专题教育培训，着力提高企业主要负责人及从业人员安全生产法治意识，督促其自觉服从和配合监管执法。要充分运用传统和新兴的各类媒体、平台，以安全生产宣传教育“七进”（进机关、进企业、进学校、进社区、进农村、进家庭、进公共场所）活动为抓手，宣传安全生产法律法规，不断提高全民依法治安意识。

（二）加强安全监管机制建设。各市州交通运输局、厅直各有关单位要重点建立健全以下几项机制：一是建立健全行政执法与司法制度相衔接的机制，加强涉安全生产违法线索通报、案件移送与协查，杜绝有案不移、有案难移、以罚代刑等现象。二是建立健全涉安全生产重大行政处罚案件合法性审查和听证制度，促进公正、公平、文明、廉洁执法。三是建立健全领导干部非法干预安全生产监管执法的记录、通报和责任追究制度，坚决做到不执人情法、不办关系案。四是建立健全“分类别、分层级、全对接”的计划执法和“四不两直”暗查暗访、“双随机”抽查制度，确保执法效果。要采取厅直各有关单位分线检查、各市州交通运输部门交叉检查等督查方式，对涉安全生产执法工作落实情况进行监管。

（三）全面推行安全生产计划检查（执法）。各市州交通运输局、厅直各有关单位要根据厅4月下旬印发的监督检查计划，结合自身实际，认真编制年度安全生产检查计划，督促行业监管部门开展计划执法，分层级、分类别、全对接，明确每个生产经营单位的安全监管主体，明确“双随机”抽查企业的数量比例，按照执法计划编制现场执法检查方案，明确检查的区域、内容、重点及方式等，提高执法效果。

（四）继续深入开展“打非治违”和重点整治。各市州交通运输局、厅直各有关单位要抓住事故防范 “牛鼻子”，延展年初以来开展的“打非治违百日行动”，继续保持“打非治违”高压态势。要认真梳理本辖区本行业领域突出隐患问题和典型常见、反复发生的非法违法现象，结合重点行业领域专项整治、重大事故隐患“一单四制”等，集中打击、整治一批表现突出的非法违法、违规违章行为。要继续开展道路运输脱离监控车辆专项整治行动，加大工作力度，坚持严管重罚，综合运用教育培训、停业、停运、罚款以及吊销营运资格、吊销从业资格等手段，促进道路运输领域规范从业。要不定期组织开展“回头看”，切实加强复查，防止违法违规行为死灰复燃。

（五）规范执法行为，形成执法震慑。各市州交通运输局、厅直各有关单位要严格规范涉安全生产行政执法工作程序、实体内容，严禁以工作检查代替监管执法，严禁以工作要求代替行政处罚，严禁擅自减免行政处罚。要结合各类安全生产专项整治行动，对问题和矛盾集中的重点区域、重点行业、重点企业，组织力量开展集中联合执法，查办典型案件，形成执法震慑，并及时向厅安委办报告典型案件查处和曝光情况。

（六）加强执法监督和信用信息应用。各市州交通运输局、厅直各有关单位要依据职能职责，加强对涉安全生产执法工作的监督指导。推行“阳光执法”，有条件的单位要通过合适的形式公开涉安全生产行政处罚决定书，自觉接受社会各界监督。加强安全生产诚信体系建设，将涉安全生产行政处罚信息及时推送至相关信用信息共享交换平台，纳入社会信用管理。加大涉安全生产失信联合惩戒力度，严格执行各项安全生产“黑名单”制度。

（七）参与“全省安全监管执法质量排行榜”活动。省安委部署从今年6月开始组织开展“全省安全监管执法质量排行榜”活动，以“三比三严”（比数量、比增量、比质量，严格程序、严格惩戒措施、严格自由裁量）为主要内容，并按照依法处罚和影响力、震慑力均大于去年的基本原则，对安全监管执法情况进行统计、讲评、排名、通报，以形成安全监管执法“比、学、赶、超”的良好氛围。全系统各有关单位要遵照省安委的总体部署，积极参与、认真落实有关各项工作。

三、工作步骤

（一）动员部署阶段(5月底前)。各市州交通运输局、厅直各有关单位要着眼实际效果，对安全监管“强执法防事故”行动进行部署，把各项工作落实到基层安全监管执法部门，落实到生产经营单位。

（二）集中推进阶段(6月1日~11月30日)。各市州交通运输局、厅直各有关单位要精心组织、扎实推进安全监管“强执法防事故”行动，认真做好企业主要负责人培训考核、安全生产监管计划执法、联合集中执法和监管执法“三比三严”评议等工作，每月10日前向厅安委办报表（见附件）。要认真督促检查本地、本行业领域安全监管执法的开展情况，通过明查暗访，推动工作落实。省厅将适时组织督导调度。

（三）总结提高阶段(12月1日~12月31日)。各市州交通运输局、厅直各有关单位要认真做好安全监管“强执法防事故”行动总结，查摆问题、总结经验，积极探索加强安全监管执法的长效机制，相关总结材料于12月15日前报送厅安委办。

四、保障措施和要求

（一）高度重视，强化组织领导。各市州交通运输局、厅直各有关单位要按照《中共党中央 国务院关于推进安全生产领域改革发展的意见》《中共湖南省委 湖南省人民政府关于推进安全生产领域改革发展的实施意见》精神，正视长期以来安全监管执法“失之于宽、失之于软”的突出问题，牢固树立“从严治安”监管执法理念，把安全监管“强执法防事故”行动作为当前安全生产重点工作，主要领导要亲自部署，分管领导要亲自参加，坚决按照“全覆盖、零容忍、严执法、重实效”的要求，落实工作责任。

（二）强化保障，提高执法能力。各市州交通运输局、厅直各有关单位要进一步健全涉安全生产监管执法机构，配齐执法人员和执法装备，保障执法经费，确保人员、经费、装备到位，确保执法行动取得实效。要通过专题培训等形式，提升各级监管人员的执法能力和水平。要充分发挥专家作用，为监管执法提供技术支撑。

（三）细化措施，敢于动真碰硬。各市州交通运输局、厅直各有关单位要综合运用全面督查、重点执法、专项执法、联合执法、暗访暗查等多种方式推进安全监管“强执法防事故”行动。要完善跟进制度，定期分析研究解决工作中发现的问题。要严格落实典型案例公开、“黑名单”和“一案双查”等制度，对违法行为当事人拒不执行安全生产行政执法决定的，要依法采取行政强制措施或依法申请司法机关强制执行。

（四）广泛宣传，营造浓厚氛围。各市州交通运输局、厅直各有关单位要充分发挥舆论监督和宣传导向作用，运用电视、广播、报刊杂志、微信、网站等媒体，加强安全监管“强执法防事故”行动的宣传报道。坚持监管执法和普法宣传相结合，将宣传教育渗透到监管执法的全过程，以案说法、以案普法、以案学法，营造全社会关心和支持安全生产工作的浓厚氛围。

（五）加强督促，严肃责任追究。省厅将把安全监管“强执法防事故”工作情况纳入2018年安全生产目标考核的重要内容，对工作不认真负责、推进不力的，将采取通报批评、警示约谈等责任追究措施。
