# 关于印发湖南省交通运输安全生产宣传教育“七进”活动方案的通知

各市州交通运输局，厅直有关单位：

现将《湖南省交通运输安全生产宣传教育“七进”活动方案》印发给你们，请认真贯彻落实。

湖南省交通运输厅安全生产委员会

2018年5月8日

湖南省交通运输安全生产宣传教育“七进”活动方案

为深入学习贯彻落实习近平新时代中国特色社会主义思想和党的十九大精神，推动交通运输安全生产宣传教育进企业、进校园、进机关、进社区、进农村、进家庭、进公共场所（以下简称“七进”），进一步提高交通运输行业全员安全意识和水平，根据《安全生产宣传教育“七进”活动基本规范》（安委办〔2017〕35 号）要求，结合我省交通运输行业实际，特制定本工作方案。

一、工作目标

认真贯彻落实中央、省委省政府和交通运输部关于加强安全生产工作的重要部署，牢固树立以人为本、生命至上的理念，面向企业、面向员工、面向社会，深入开展“平安交通”活动，以“三下降，一杜绝”为目标，努力提升行业安全意识和应急处置能力，围绕交通运输行业安全生产重点工作，把握宣传规律，创新宣传形式，丰富宣教内容，建立健全交通运输安全生产宣传教育工作机制，实现安全生产宣传教育全覆盖，为全省交通运输安全生产形势持续稳定提供坚实保障。

二、工作重点

(一)强化安全生产政策法规宣传

深入宣传安全生产重大决策部署和中央领导同志关于安全生产工作的系列讲话和指示批示精神及重大决策部署，大力宣传学习《中华人民共和国安全生产法》、《中共中央国务院关于推进安全生产领域改革发展的意见》、《湖南省水上交通安全条例》、《湖南省安全生产条例》、《中共湖南省委湖南省人民政府关于推进安全生产领域改革发展的实施意见》等有关法律法规和规范性文件。

（二）加强警示教育宣传

结合行业、企业和岗位特点，以生动鲜活的事例，开展安全警示教育，督促企业或组织企业管理人员、安全监管人员和一线从业人员开展安全生产典型事故案例分析和学习，强化违法违规和不安全生产行为危害性的认识，吸取血的教训，增强社会责任感，时刻明白安全责任重于泰山，做到警钟长鸣，切实用安全生产典型事故案例教训推动安全生产工作。

(三)强化行业安全生产重点工作宣传

突出交通运输安全生产专项整治、隐患清零、打非治违、隐患排查治理、安全监管督查（执法）检查、“平安交通”建设以及道路运输、水上交通和交通建设施工领域安全监管、安全生产标准化达标等重点工作的宣传。

(四)突出对安全生产先进典型的宣传

深入交通运输生产一线，做好行业安全生产典型的挖掘和宣传工作，树立先进典型，对先进的行业安全生产管理经验、优秀个人事迹在全行业内进行宣传，营造良好氛围。

(五)突出对安全意识、应急处置知识的宣传

针对长途客运、农村客运、学生客渡运输、危货运输、建设施工等重点领域易发事故类型，采取入户（工地、企业、学校）宣传、知识竞赛、讲座等多种形式，有针对性的开展宣传教育活动。结合行业安全生产特点，及时发布安全生产提示信息、播放安全警示片和安全知识。

三、工作任务

（一）安全生产宣传教育“进企业”

加强交通运输企业安全生产宣传教育，督促企业落实安全生产主体责任，提高安全生产水平，预防和减少各类事故坚决杜绝重特大安全事故发生。企业要将安全生产宣传教育纳入企业日常管理工作，与生产经营工作同研究、同部署、同落实，确保有专门责任人和专项工作经费。要将安全生产宣传教育作为上岗前会、月度例会、生产经营会和安全生产工作会议的固定议题，深入研究，及时部署；定期开展岗位安全知识培训和安全应急演练。企业要加强安全文化教育，深入开展“安康杯”竞赛、“安全生产月”、相关法律法规和其它安全生产宣传教育活动，将企业安全文化建设作为安全生产标准化建设重要内容。企业要加强安全警示教育，在企业醒目位置设置安全生产宣传专栏，悬挂、张贴安全生产宣传标语、播放安全宣传片和安全警示提示；每季度至少要组织全体职工观看一次安全生产警示教育片，定期组织安全反思活动。企业要完善安全标识，设置岗位安全描述、风险公告、警示提示、安全操作规程等标识。

（二）安全生产宣传教育“进校园”

按照交通运输部和教育部的要求，与教育部门联合开展“水上平安交通，安全伴我成长”为主题的“水上交通安全知识进校园”活动，将水上交通安全教育内容纳入学校教育教学计划，因地制宜开展水上交通安全教育，传授水上交通安全、水上求生救助、防溺水等方面的安全知识和技能。其他行业领域，也可通过与教育部门合作形式，加强校园安全生产的宣传教育，面向广大学生普及安全乘车、安全出行等常识和技能，强化安全意识；要向学生发放校园安全知识资料，在图书馆、活动室和校园网设立安全角，提供安全知识读物借阅和电子资料下载服务。

（三）安全生产宣传教育“进机关”

加强机关工作人员安全生产法律法规的宣传教育，按照 “党政同责、一岗双责、齐抓共管、失职追责”的要求，将安全生产教育融入到日常机关管理工作中。把安全生产宣传教育作为机关宣传教育和日常培训的重要内容之一，定期邀请专家、学者对本机关工作人员开展安全生产专题讲座。要在机关宣传栏、橱窗、走廊等场所张贴安全生产宣传教育系列挂图和宣传画，在机关网站中开设安全生产专题，及时宣传报道安全生产方针政策、法律法规、相关行业领域举措等。要采取集中学习、分组学习、座谈讨论等多种方式学习《安全生产法》及安全生产相关的法律法规，做到深学笃用，使全体干部职工懂法、守法、用法，不断强化自身安全生产意识。

（四）安全生产宣传教育“进社区”

有条件的地区，可通过与街道社区合作，联合开展交通运输安全进社区活动，聘请义务安全员，加强安全出行安全教育，把交通运输安全知识引入社区，加强社区居民安全出行宣传教育，重点宣传乘坐合规车、强化监督举报等事项，促进广大社区居民将“生命至上、安全第一”转化为强烈的自觉意识，有效提升社区群众出行安全水平。

（五）安全生产宣传教育“进农村”

通过加强农村安全生产宣传教育，进一步提升广大农民安全意识和安全素质，为乡村振兴战略提供有力的安全生产支撑和保障。要结合当地农村交通运输实际，加强渡运安全、农村客运安全和农村公路安全知识的宣传和普及，督促当地群众不乘坐超载车、不乘坐超载船、不从事非法营运生意。要充分利用农村社区综合服务设施、村文化活动站、学习室，广播等，开展主题安全宣传教育。要结合扶贫帮扶工作，利用定期到农村扶贫驻点的机会开展安全宣教活动、提供咨询服务，除宣传交通运输安全工作外，也要强化对留守老人、儿童的安全宣传教育，普及道路交通、火灾等日常生活方面安全知识，在村民经常停留或活动且存在安全风险的区域设置警示标语，并做好隐患排查治理。

（六）安全生产宣传教育“进家庭”

通过加强家庭安全生产宣传教育，推动形成有效的安全生产社会治理和良好的安全生产社会秩序。各交通运输企业要将安全生产知识带入到员工家庭，通过对员工家庭成员的安全教育，争取员工家庭对企业安全生产工作的支持，督促员工自觉遵守安全生产意识，推动企业整体安全生产水平的提升。要与安全宣传教育“进学校”相结合，重点对上学需要乘车、乘船或步行经过涉水、危险路段的学生家庭，组织开展“小手牵大手”“我给爸爸妈妈讲安全”“我把安全带回家”等活动，加强学生、家长和家庭的安全意识教育。

（七）安全生产宣传教育“进公共场所”

要通过加强运输站场、港口码头、高速公路服务区等公共场所安全生产宣传教育，提升社会公众安全防范意识、应急避险和自救互救能力，预防和减少公共安全事故及群死群伤事故发生。要结合“安全生产月”活动，开设交通运输安全咨询台，采取专家现场咨询、张贴海报标语、发放安全生产法律法规读物等方式，为过往旅客、车辆驾驶员提供安全咨询，普及交通运输安全生产法律知识。要在出租车、公交车上滚动播放安全生产公益广告，普及安全知识，提高大家应急避险和自救互救能力。同时，要针对节假日免收小型客车通行费的交通安全特点，全时段、全路线、全方位地开展安全宣传教育。

四、工作要求

（一）加强领导，精心组织。各单位要高度重视，深入开展交通运输行业安全生产宣传教育“七进”活动，围绕主题，认真制定工作方案，切实督促交通运输企业抓好安全生产宣传教育。要根据不同时段、不同安全工作重点有针对性地进行安全宣传教育，重视对从业人员的安全教育，加大对一线作业人员和安全管理人员的培训，定期组织企业从业人员进行安全知识的更新培训，切实提高安全管理整体水平。确保组织到位，措施到位，宣传培训到位，确保安全生产宣教培训工作取得良好效果。省厅 根据全年交通运输安全生产特点，拟定了全年各阶段“七进”活动主题，各单位可结合实际进行开展，重点做好安全生产宣传教育进交通运输企业、进交通运输公共场所、进学校、进机关的工作。

（二）典型引导，试点先行。各单位要充分认识开展“七进”活动的重要性和必要性，把“七进”活动作为普及安全知识和法律的重要载体，大胆探索，创造性地开展工作。省厅拟建立交通运输安全体验馆，通过VR等形式强化体验式培训；有条件的地方也可以试点建设VR体验馆，开展体验式安全教育。各单位可根据实际情况，创新安全生产宣传教育方式，通过以点带面，全面推进，形成人人关注、人人参与、人人支持的良好安全氛围。

（三）强化督导，务求实效。通过深入开展交通运输安全生产宣传教育活动，有力促进广大运输从业人员特别是运输企业负责人安全生产意识进一步提升，安全防范能力进一步增强，安全管理水平进一步提高。各单位要积极利用各类安全生产工作督查，开展对安全生产宣传教育工作的检查，对宣传教育工作落实不到位的单位或企业予以通报批评。在进行宣教活动中，及时总结经验，收集活动中的工作亮点、优秀典型等信息，要于12月10日前分别将全年安全生产宣传教育“七进”活动工作总结上报厅安委办。
