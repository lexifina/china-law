# 关于进一步加强当前安全生产工作的紧急通知

各市州交通运输局，厅直有关单位：

7月5日，两艘载有中国游客的游船在泰国普吉岛附近海域发生倾覆事故，造成我国公民重大伤亡。当前正值暑运，又是主汛期、台风期，洪涝、泥石流、大风等自然灾害频发期，给交通运输繁忙的旅客和货物运输安全生产带来极大影响。7月6日，国务院安委会办公室与应急管理部联合下发了关于进一步加强当前安全防范工作的紧急通知（交委办明电〔2018〕10 号），要求各地区各单位要切实加强安全防范，严格落实责任措施，坚决遏制重特大事故发生。为进一步加强我省交通运输安全生产工作，结合交通运输实际，现提出如下要求：

一、切实增强交通运输安全生产工作的紧迫感和责任感。各单位各部门要认真贯彻落实中央领导同志重要指示批示精神，切实加强对极端天气和各种自然灾害的预警预防，加强领导，周密部署，认真落实各项安全生产责任制度和工作措施，特别是安全生产第一责任人一定要站在讲政治讲大局的高度，清醒地认识当前交通安全工作面临的严峻形势，切实增强危机感、紧迫感和政治责任感，举一反三，深刻吸取事故教训，率先垂范，紧急行动，靠前指挥，对当前的安全生产工作再进行深入分析研究，坚持问题导向，找出安全生产存在的问题和薄弱环节，充实和完善工作部署，采取果断有效措施，坚决遏制重特大事故的发生。各级领导干部要狠抓安全生产各项防范措施落实，凡因工作责任不落实、防范措施不到位而发生安全生产事故的，依法依规严肃追责。

二、突出重点领域安全监管。各单位要结合“安全生产责任年活动”、“水上交通安全专项整治”、“隐患清零”升级版行动、“强执法防事故”专项整治等活动，严格落实交通运输安全管理各项措施。一是开展道路客运专项整治行动，重点整治道路客运、旅游包车市场秩序，严格客运企业、车辆、驾驶员的资质审查，严禁不符合要求的车辆上路、驾驶员上岗。督促企业发挥车辆联网联控系统作用，加强营运车辆动态监管，及时纠正违章行为。严格客车进站检查、出站查验，切实将“三不进站、六不出站”制度落到实处。二是严格检查“两客一危”车辆安全技术状况以及消防、应急设施装备配备情况，严禁不符合安全技术条件的车辆营运，依法严肃查处车辆无证经营、超范围经营、非法营运等违法违规行为。三是加强“六区一线”重点水域和“四类重点船舶”安全监管，严格落实水上旅游、客汽渡运法定安全监管职责，按规定严禁冒大风、冒大雾、冒大浪航行。要加强客运码头、危险品港口装卸、存储作业的监督管理，切实加强人员密集场所和危化品运输和作业的防火工作。四是继续深入排查公路水运工程宿营地、工棚、仓库等重点位置存在的洪水、滑坡、泥石流等自然灾害风险隐患，严格控制安全距离，遇到暴雨、大风等极端天气提前采取有效防范应对措施。五是继续加大公路安全生命防护工程建设，做好桥隧和隐患路段整治工作。

三、继续抓好隐患排查治理。各单位各部门要认真吸取近期国内外发生的重大事故教训，突出重点地区、重点领域、重点部位、重点环节，采取“四不两直”和“双随机”的方式，按照隐患排查治理普查要求和部署，加大隐患排查治理力度，坚决杜绝排查盲区，及时整改事故隐患，对存在重大隐患和问题的企业要挂牌督办。同时要加强跟踪督办和督查检查，对隐患拒不整改或整改措施落实不到位的，要依法严厉查处，将企业纳入“黑名单”管理，并严肃追究有关人员的责任，确保消除事故隐患。

四、及时报送事故信息并妥善处置突发事故。各单位各部门要加强值班和应急值守工作，严格落实岗位责任制和节假日期间领导带班、关键岗位24小时值班制度。严格按规定及时报送事故信息，对迟报、谎报、漏报的单位和人员要严肃追责。进一步完善各类安全生产事故应急处置预案，加大应急演练力度。保障救助应急车辆、船舶、飞机处于良好状态，确保应急救援装备物资配备落实到位，一旦发生突发事故，做到科学应急，及时妥善处置。

湖南省交通运输厅安全生产委员会办公室
