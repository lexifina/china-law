# 湖南省交通运输厅安全生产委员会办公室关于做好全省公路水运工程建设领域台风“白鹿”安全应对工作的紧急通知

各市州交通运输局，省公路管理局、省水运管理局、省交通建设质量安全监督管理局，厅基本建设处、厅港航管理处：

根据省气象部门预报，受台风“白鹿”影响，预计今天（25日）下午至27日省内有一次强降雨天气过程。湘西、湘南累计雨量达50～80毫米，其中湘东南部分地区达100～140毫米，永州南部、郴州南部局地达150～200毫米；最强降雨时段出现在今天夜间～明天；风力普遍加大到4～5级，局地瞬时阵风7级。气象专家提醒，近期，湘西、湘南需加强防御局地强降雨可能诱发的山洪和滑坡、崩塌、泥石流等地质灾害；同时需注意防范大风对城乡建筑、高空作业等造成的不利影响。

为做好全省公路水运工程建设领域台风“白鹿”安全应对工作，现就有关事项紧急通知如下：

一、高度重视，切实抓好安全应对。在台风“白鹿”影响期间，特别是重点影响的市州，各有关单位务必高度重视，严格落实近期省厅关于主汛期、台风期交通运输安全生产工作的一系列部署安排，坚决克服麻痹松懈思想，进一步加强公路水运工程建设领域安全应对工作，及时做好监测预警，全面落地安全措施。

二、强化措施，全力确保安全生产。各有关单位要把确保人员安全放在首位，对公路水运工程建设领域各项防御应对措施再细化、再安排、再落实。重点地区在建项目“该停的要停”。重点做好在建工程水上作业船舶避风、防大（暴）雨工作，开展防台避险、小流域山洪和山体滑坡、泥石流等地质灾害防范工作。加强施工现场隐患排查和人员驻地检查，督促相关单位对塔吊、移动模架、挂篮等高空机械设施和支架脚手架、临时结构物、拌和站储料室进行有效加固或科学安排，将所有人员转移至安全区域，坚决保证人身安全，将现场高处堆放的材料吊运至土层稳固处，现场小型机械集中堆放；全面检查施工现场临时设施和施工围挡安全性，对现场临时设施设置缆风绳、施工围挡增加斜撑的方式进行加固；检查深基坑支护，做好排水、加固、监测和巡查工作，基坑四周排水需畅通，防止基坑坍塌事故发生；对现场临时用电线路、配电箱、开关箱进行加固，并进行防雨覆盖。台风影响期间，停止一切野外作业，防止坍塌、高空坠落、物体打击等事故发生。

三、落实责任，认真做好安全生产应急值守工作。各有关单位要严格落实责任，认真执行安全生产应急值守制度和信息报告制度。同步强化指挥调度，加强信息发布、巡查督查等工作，落实保障措施。如遇公路水运工程建设领域施工险情，要科学、高效开展应急处置，确保安全生产。
