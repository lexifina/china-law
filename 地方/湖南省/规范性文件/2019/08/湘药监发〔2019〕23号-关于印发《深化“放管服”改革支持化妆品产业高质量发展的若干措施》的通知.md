# 关于印发《深化“放管服”改革支持化妆品产业高质量发展的若干措施》的通知

各市州市场监督管理局，省局机关各处室、各直属单位：

现将《关于深化“放管服”改革支持化妆品产业高质量发展的若干措施》印发给你们，请认真遵照执行。

湖南省药品监督管理局

2019年8月2日

（公开属性：主动公开）

深化“放管服”改革支持化妆品产业高质量发展的若干措施

为深化“放管服”改革，进一步优化营商环境，服务承接化妆品产业转移，促进我省化妆品产业高质量发展，提出如下措施。

一、最大限度缩减行政许可流程和时限。精简化妆品生产许可申报资料，允许线下初次提交有关申报资料容缺，实行资料审查与技术评估同步进行，逐步推进化妆品生产许可网上申报，试行电子证书。优化化妆品生产许可服务流程，大幅度压缩化妆品生产许可办理时限，即自受理申请之日起5个工作日内作出许可决定。

二、建立产业转移许可服务绿色通道。积极为省外化妆品生产企业转移我省提供许可申报等咨询服务，对转移企业在生产车间功能布局设计、实验室建设、设备安装等方面有需求的，省局组织专家到现场开展一对一“菜单式”服务，让企业落地即领证. 积极支持市县政府打造化妆品专业园区，为产业招商提供优质服务.

三、大力支持企业自主创新。鼓励化妆品生产企业加大研发投入，将创新能力强、成长性好、附加值高的化妆品生产企业纳入湖南科药联合基金支持范围，支持相关企业与医药院校、检测检验机构等加强合作，围绕皮肤生理与化妆品安全、中药与皮肤健康、化妆品功能性原料的开发与应用等关键技术方面开展研发攻关，着力打造民族特色品牌，提升我省化妆品市场竞争力。

四、进一步完善监管方式。寓监管于服务之中，组织开展进企业精准帮扶促发展行动，主动为化妆品企业排忧解难。加强事中事后监管，全面推行“双随机、一公开”模式，针对重点品种、重点环节、重点场所和重点企业，科学制定监管计划，对风险隐患较多的企业加强“飞行检查”。

五、支持检验检测机构发展。积极支持省药品检验研究院建设国家化妆品风险监测承检机构、国家化妆品监督抽检复检机构，加强市州药检所化妆品检测能力建设，引导第三方化妆品检验检测机构规范发展，推动产业园区第三方检验检测服务机构等为化妆品生产企业提供检验检测服务。
