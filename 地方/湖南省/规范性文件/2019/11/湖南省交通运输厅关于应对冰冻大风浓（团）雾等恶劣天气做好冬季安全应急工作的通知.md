# 湖南省交通运输厅关于应对冰冻大风浓（团）雾等恶劣天气做好冬季安全应急工作的通知

省高速公路集团有限公司，各市州交通运输局，厅直有关单位：

冬季已经来临，冰冻、大风、浓（团）雾等恶劣天气多发，是各行各业特别是交通运输行业安全生产事故的高发、易发期，安全生产风险将持续处于高位。据气象部门预测，本月末段，湘西、湘北阴天有小雨，高寒地区有雨夹雪或冻雨，极有可能对交通运输保通畅、保安全造成不利影响。

根据《交通运输部关于做好2019-2020年度防范寒潮大风等极端天气工作的通知》（交应急明电〔2019〕7号）、《交通运输部安委会关于切实抓好冬季安全生产工作的通知》（交安委明电〔2019〕21号）等文件精神以及陈飞副省长近日在《气象专题报告》（2019年11月22日，第68期）上作的“请应急、交通厅关注气象变化，及时应对，确保安全”的批示精神，结合我省冬季交通运输安全生产实际，现就应对冰冻大风浓（团）雾等恶劣天气做好冬季安全应急工作通知如下：

一、高度重视，认清形势，强化做好冬季安全应急工作的责任担当

习近平总书记多次就安全生产工作作出系列指示批示，也就自然灾害防治工作提出了“两个坚持、三个转变”的防灾减灾救灾理念，这是我们做好安全应急工作的根本遵循。全省交通运输系统各级各部门各单位要高度重视安全应急工作，以习近平总书记关于安全、应急的系列指示批示精神为指导，认真贯彻落实近期以来党中央、国务院，交通运输部，省委、省政府，省安委办等关于安全生产、应急管理的决策部署，切实加强对冬季安全应急工作的组织领导，统筹部署，及时调度，维护冬季全省交通运输安全应急形势稳定。当前，全省交通运输安全应急形势总体稳定，但稳中有忧、稳中有险，可能引发较大及以上级别安全事故、应急事件的安全隐患和突出风险并存，切不可掉以轻心。要增强做好冬季交通运输安全应急工作的责任感、使命感，结合各领域、地域交通运输安全应急工作的重点、难点、痛点等，针对冬季冰冻、大风、浓（团）雾等恶劣天气多发的规律，深入分析研判冬季安全应急面临的形势和潜在的风险、隐患，把安全应急责任、措施落实到位，及时开展培训、演练工作，科学高效应对处置应急事件，坚决防范和遏制重特大事故发生，减少较大及一般事故发生，切实降低人民群众特别是交通运输参与人的生命财产损失。

二、突出抓好重点领域安全应急工作

全省各级交通运输主管部门要抓好统筹部署，全力推进交通问题顽瘴痼疾集中整治行动等专项行动，切实加强当地交通运输行业安全应急工作，着力查大风险、除大隐患、防大事故，确保交通运输行业安全发展形势稳定。要紧盯客运、危货运输重点车船，突出高速公路、旅游景区公路、高寒山区易结冰路段、公跨铁桥梁路段、连续长陡下坡路段，繁忙通航水域，冬季公路水运工程施工高风险作业点，轨道交通运营大客流站点等重点区域、点段，强化对一线从业人员行为的动态安全监管。要督促相关机构及时修订完善交通运输各领域应急预案，并加强演练，增强科学应急处置能力。针对前期部、省及厅交办的安全隐患排查治理任务，要协调、督促加快整改进程，及时向厅报送相关情况。

各级道路运输管理机构要从“11·16”“11·24”两起道路运输危化品泄露事故（事件）中举一反三，以“两客一危”领域为重点，认真履行“三关一监督”职责。要督促道路运输企业加强对驾驶员、车辆的安全管理，提升驾驶员的临危应急处置素养和营运车辆技术性能；督促客运站严格执行“三不进站，六不出站”规定。要做好农村客运安全管理，推进农村客运一体化改革发展步伐。要密切关注气象和道路通行信息，在恶劣天气下按规定实施停班停运，督促客运站做好应急保障工作。

各级海事、水运、航道、港口管理机构要督促船主落实安全生产主体责任。要加强与气象、水文等相关部门（机构）的沟通协调，有效推送安全航行相关信息；严把船舶适航和船员适任关，强化对桥区、渡口、锚地、客货运输繁忙、涉水工程作业区等重点通航水域的现场巡查，维护良好的水上交通秩序；严格落实恶劣天气禁限航管理措施，切实做好船舶防抗大风工作。要突出抓好涉客运、危险货物运输船舶和港口生产作业特别是危险货物装卸、储存作业的安全监管。要做好航道及其设施的养护管理和应急抢通工作；加强救助打捞应急技能训练，科学部署救助力量，有效救助遇险人员、船舶。要督促县乡人民政府落实属地管理责任，加强对渡口渡船和乡镇非运输船舶的安全管理。

各级交通建设质量安全监督管理机构要督促参建单位合理安排工期进度，及时做好预警研判，尽可能避免或减少恶劣天气下施工作业，确保冬季施工作业安全生产。要科学设置施工驻地，增加现场安全管理力量，提升施工人员安全意识，严格执行安全操作规程，落实防寒防突风、防火、防触电、防中毒等安全措施，严防坍塌、高空坠落、爆炸、火灾等安全事故发生。

各级公路管理机构要从“2018·12·08”系列道路交通事故中吸取教训，举一反三，督促公路经营管理单位科学开展养护巡查，消除安全隐患、降低安全风险。要加强与气象部门、公安部门道路交通管理机构的信息联动，做好路网运行监测、路况信息发布和公众出行引导工作；要针对易结冰路段及时开展扫雪除冰工作，一旦因冰冻、浓（团）雾等恶劣天气引起公路（路段）封闭，要科学制定绕行方案，全力做好应对恶劣天气的保安保畅工作。要做好公路养护作业过程中的安全防范工作，防止发生作业事故；认真落实“路警联合治超”机制，加大公路安全保护力度；加强与地方政府有关部门的沟通衔接，参与查处马路市场等涉路安全生产违法行为。发生灾情后，要有序做好受损公路抢通保通工作，积极配合有关部门（机构）开展交通疏导工作。

各级铁路专用线及社会道口安全管理机构要督促权属单位完善安全制度，开展冬季安全隐患排查治理，特别是钢轨、道岔等重点部位的巡查和冬季融雪除冰工作；要督促城市轨道交通、磁悬浮运营单位结合冬季恶劣天气等特殊时段客流变化规律，强化列车检修、行车调度、行包安检、客流疏导、站务执勤等安全管理工作，加强应急演练和应急保障工作，确保安全运营。

三、认真落实安全应急方面值班值守和信息报送机制

全系统各级各有关部门、机构、单位要根据安全应急工作要求，落实值班值守制度，确保安全应急人员在岗、政令畅通。一旦发生安全应急事故（事件），要迅速响应，科学处置，及时报告，确保事故（事件）处置得力，信息报送及时完整。

各行业管理机构要迅速将通知精神传达到生产经营单位。

湖南省交通运输厅
