# 在全市创建全国文明城市重点工作协调推进会上的讲话

（2020年7月7日）

坚决打赢决战决胜全国文明城市“两连冠”攻坚战，是必须完成的政治任务。在创建“两连冠”工作进入倒计时的关键阶段，今天我们召开重点工作协调推进会，主要任务是研究解决创建工作中存在的重点难点问题，调动全市各级各方面的力量，确保顺利通过全国文明城市复核验收。

一、认清形势，提高站位，切实增强创城工作的紧迫感和责任感

从目前掌握的情况来看，中央文明办预计8至9月份对全国文明城市进行复查验收，留给我们的时间不到2个月，可以说迎检迫在眉睫，时间非常紧迫，形势十分严峻，大家绝不能有任何的麻痹、大意和放松。一方面，在全国层面，今年中央文明办将对175家全国文明城市，进行全面复核验收并排名。现在已经明确，排在末位的城市，将全国通报并实行末位淘汰，取消“全国文明城市”的牌子。另一方面，在我省内部，今年金昌市同样面临着复核验收，创建力度也非常大。因此，我们不仅要顺利通过中央文明办的复核验收，而且还要力争取得一个好的成绩。

但从刚才壁成同志通报和近期督查情况看，我们在创建工作中还有一些短板，存在10个方面、45个重点难点问题，涉及到20多个部门、31个社区、17个行政村，如果解决不好势必会影响我市整体成绩。从深层次看，有的部门、单位仍然没有站在全市的高度认识和看待创城工作，对职责范围内的工作推诿扯皮，对未达标事项不想办法加以解决，讲客观、找借口、推责任，问题整改推进缓慢；有的行业主管单位发挥作用不明显，在组织行业对标达标方面，还有等待观望的现象；有的问题市上早就已经点出，也出台了相关规定，但还是落实不到位。这些问题，归根到底还是思想上浮躁、精神上懈怠、行动上迟缓。同志们，今年是我市争创全国文明城市“两连冠”之年，现在真正到了“百米冲刺”的紧要关头。如果在我们手里丢掉了这块牌子，如何向省委交差？如何向嘉峪关老百姓交代？各部门各单位一定要深刻认识创建工作的极端重要性和现实紧迫性，把其作为增强“四个意识”、坚定“四个自信”、做到“两个维护”的政治工程，作为检验担当精神、治理能力和工作水平的“试金石”，只争朝夕、快马加鞭，全面进入决战决胜状态，确保如期实现“两连冠”目标。

二、

围绕重点，真抓实干，集中精力打好创城“三大攻坚战”

创建全国文明城市“两连冠”，这是全市当前的头等大事。各责任单位要坚持问题导向，以《全国文明城市测评体系》作为工作大纲和主要依据，集中精力，加大力度，采取务实、高效、精准的措施，全力以赴打好“三大攻坚战”。

第一，打好环境整治的攻坚战。市容环境卫生是一座城市的“门面”，是城市形象最直观的体现。各部门要结合自身职能，拿出一些硬措施、硬办法，做深、做细、做实环境整治这篇文章。一是要整治环境卫生。环卫部门要加大主次干道清扫保洁的频次，提升保洁质量，保证垃圾随有随清，街道干净整洁。要加快推进垃圾分类试点工作，深入开展垃圾分类宣传教育，确保这项工作年内全方位铺开。二是要整治市容秩序。各街道要督促社区强化“门前五包”工作责任制落实，重点围绕私搭乱建、乱堆乱放、乱贴乱画、乱泼污水、乱倒垃圾、非机动车乱停乱放等现象，整治沿街商铺秩序、卫生、文明、绿化、安全五个方面的问题。市场监管部门要加强对地摊经营的规范化管理，合理划定区域，避免临时摊点妨碍交通、扰乱公共秩序、影响环境卫生。三是要整治居民小区。目前正在改造的老旧小区，要加快施工进度，加强施工管理，最大限度减少工程项目对居民群众生活的影响。街道、社区要协调好无物业小区的环境卫生、绿化、基础设施等问题，加强日常管理，方便群众生活。房产服务中心要加强对物业企业的考评，督促做好居民小区的绿化、美化、硬化、车辆停放及楼院卫生整治工作，进一步提升物业服务的质量和水平。

第二，打好舆论宣传的攻坚战。今年全国文明城市复查验收时，中央文明办将通过问卷调查等方式，测评市民群众对创城工作的知晓率、支持率和参与率。客观上说，我们在氛围营造方面做了一些工作，但与测评要求相比，还有一定差距。从现在开始，宣传部门要全面加大宣传的力度、广度和密度，利用一切宣传阵地，运用一切宣传手段，开展全方位、多形式的创建宣传，切实形成创城的浓厚氛围。要精心设计创建活动载体，通过发放市民应知应会手册、开展模拟问卷调查、随街走访等方式，普及创城知识，调动各方面积极性，使创建过程真正成为广大群众自觉参与的过程。电视、广播、报纸、网络等新闻媒体要通过开辟专栏专题，广泛宣传我市创城的重大举措、经验做法、成效成果和优秀典型，使创城工作深入人心。要充分发挥新闻媒体的舆论监督作用，规范社会文明礼仪，及时曝光“不文明”现象，教育引导市民从自我做起、从小事做起，自觉养成文明行为习惯，为创建工作添砖加瓦、献计出力。

第三，打好补齐短板的攻坚战。重点要解决好以下几个方面的问题。一是基础设施薄弱的问题。根据掌握的情况，目前我市部分路面破损、公共场所座椅损坏、建筑施工围挡缺失或不整洁，居民小区、背街小巷坑洼不平等现象还比较多。此外，机关单位办事大厅、医院、商场、车站、公园等出入口和公厕内，还存在着无障碍设施不完善等问题。市住建局、市容环卫总站等相关部门，要尽快对城市基础设施状况进行专项排查，严格落实管理责任，对广场、公园、景区、公厕等市政设施存在破损和缺陷的，该修补的修补，该完善的完善。二是交通秩序混乱的问题。交通秩序是文明测评的一个重要方面，我市的问题主要集中在行人乱闯红灯、非机动车逆行及乱停乱放、交通标线标识不到位，特别是出租车随意调头、车内卫生不整洁、不主动出具票据等现象还比较普遍。针对这些问题，公安、交通运输、城管执法等部门，要进一步加大工作力度，采取务实有效措施，尽快整改到位。三是市场管理不规范的问题。针对集贸市场环境卫生脏乱差、临时摊位占道经营、堵塞消防通道、私搭乱建等管理不到位问题，市场监管局、城管执法局等相关责任部门要从严管理、综合整治，一个点位一个点位梳理问题，有针对性制定整改措施，确保测评指标都达标、不失分。

三、强化联动，靠实责任，广泛凝聚起推进创城工作的整体合力

创建全国文明城市，是一项涉及全市性、全民性的重大任务。各部门各单位要切实增强大局意识、责任意识，举全市之力，集全民之智，齐心协力坚决打赢创城“两连冠”这场攻坚战。

一要强化责任落实。各部门各单位要坚持“一把手”负责制，把创建工作牢牢抓在手上，把承担的任务细化分解到具体科室和人头。特别是针对本领域存在问题，要制定详尽的工作推进表，每周干什么、完成哪些任务，都要明确列上日程，保证按时间节点全部落实到位。市创城办和文明办要充分发挥牵头抓总、综合协调作用，抓好总体谋划，加强统筹调度，开展具体指导，及时研究解决遇到的困难和问题，协调推进各项工作落实。

二要凝聚工作合力。各部门各单位要牢固树立创城“一盘棋”思想，强化沟通，协调配合，高效联动，形成整体合力。对于本单位职责范围内的工作，要不等不靠、主动认领，全面抓好落实；对于涉及多个部门的工作，牵头单位要积极担责、搞好组织协调，参与部门要服从调度、加强沟通协作，共同推动工作落实。同时，要广泛动员干部职工参与创建活动和志愿服务活动，更好发挥工会、团委、妇联等组织作用，凝聚起众志成城、合力创城的强大正能量。

三要加强督查考核。市创城办和文明办要针对通报中指出的问题，进一步加大指导和督查力度，严格对照测评标准限期整改，对整改进度缓慢、工作不实不细的，该通报的通报、该约谈的约谈，确保责任落实、任务落地。要建立问责工作机制，创城测评验收结束后开展“回头看”，对于承担内容扣分、影响整体测评结果的单位实行“一票否决”，严肃追究相关责任。

创建全国文明城市“两连冠”迎检测评已经到了最后的冲刺阶段。我们要坚定信心、提振精神，迅速进入战时状态，不讲客观原因，不谈制约因素，采取扎实有效的措施，确保顺利通过测评验收，力争实现“两连冠”目标，为全市人民交上一份满意的答卷。
