# 关于印发《岷县2019年经济适用住房实施方案》的通知

各乡镇人民政府，县级国家机关及各部门：

《岷县2019年经济适用住房实施方案》已经县政府第四十三次常务会议讨论通过，现印发你们，请结合各自实际，抓好贯彻落实。

岷县人民政府办公室

2019年3月5日

岷县2019年经济适用住房实施方案

为确保顺利实施经济适用住房的分配管理，切实解决城市中低收入家庭住房困难，促进“住有所居”目标的实现，现根据国家和省、市有关经济适用住房保障政策及《岷县经济适用住房管理办法（试行）》（岷政办发〔2013〕132号）相关规定，特制定本方案。

一、申请对象及条件

（一）具有岷阳镇范围内常住家庭户口，申请人在18周岁以上。

（二）家庭人均月收入在全县上年度城镇居民人均可支配收入1.5倍以下（本方案中收入均不含缴纳的社会保险、住房公积金）；

（三）无房户（家庭成员无房产）或住房困难家庭（家庭人均住房建筑面积在15平方米以下的）;

（四）个人住宅被依法征收后再无其它住宅的且未实行产权置换；

（五）家庭成员中不得名下有价值10万元以上的私有车辆（含10万元）、不得有月营业额在5万元以上（含5万元）或注册资金10万元以上（含10万元）的企业或实体；

（六）在岷工作的全国、省部级劳模、全国英模、失独家庭、荣立二等功以上的复转军人、军转干部住房困难家庭不受收入限制。

对符合条件的优抚对象、住房救助对象等，以及个人住宅被征收未实行产权置换的对象，应当优先给予保障。

二、申请需提供的资料

（一）本人书面申请；

（二）《岷县保障性住房申请表》;

（三）申请人及家庭成员身份证、户口簿复印件;

（四）婚姻状况证明。已婚、离婚人员需提供相关证明;

（五）收入证明。有就业单位的，由单位出具收入证明；无就业单位的，由户籍所在社区出具收入证明；住房救助家庭提供户口所在地民政部门认定证明;

（六）现住房状况的证明。在县城有自有私房的提供房屋所有权证或土地使用证复印件，无房屋所有权证的，由原户口所在地社区出具证明（社区干部签字）和房屋照片；无房屋的提供所在地社区出具的住房证明（社区干部签字）。

（七）优抚证、个人住宅征收协议、车辆购置发票、注册企业营业执照、残疾证、二女结扎户父母光荣证或独生子女证等。

注：所有申请材料中需提供复印件的，复印件上须注明“与原件核对无误”字样并由乡镇或就业单位经办人核对签字并加盖单位公章。

三、经济适用住房价格与产权

配售最终价格按照《甘肃省经济适用住房价格管理实施办法》和《岷县经济适用住房管理办法（试行）》之规定，分别由县市场监管局成本监审后，报县政府审定批准。配售面积在60㎡以内的，按县政府审定的价格计算，配售面积超过60㎡的，超过的部分按照同年度同地段同类普通商品房价格计算。

经济适用住房实行政府与个人共有产权，个人产权应按照配售价格与同年度普通商品住房均价的比例计算。

四、分配方式

根据审批确定的保障对象在公证处、新闻媒体的监督下，坚持公开、公平、公正原则，委托摇号公司采用电脑摇号的方式进行公开配售。

五、经济适用住房办理程序和要求

（一）受理申请、初审公示阶段（30个工作日）。由申请人到原户口所在乡镇政府或就业单位提出书面申请，填写《岷县保障性住房申请表》，提供相关材料，进行初审并公示，公示期限不得少于7天。对公示无异议或异议不成立的，将符合条件人员花名册报住建局住房保障办。

（二）部门联审阶段（10个工作日）。由岷阳镇或就业单位确定专人或申请人带《岷县保障性住房申请表》分别到县房管局、不动产局、公安局、财政局、税务局、市场监管局、社保局、人社局、交警大队车管所、公积金管理中心、民政局等单位进行信息比对审核签字盖章后，将申请表及材料报县住建局进行审批。

（三）住建局审批公示阶段（5个工作日）。县住建局根据部门联审结果进行审批、公示，公示期限为7天，对公示无异议或异议不成立的，纳入保障对象，对公示有异议或异议成立的，告知申请人并说明理由。

（四）摇号分配阶段（15个工作日）。预缴房款15万元（不计利息）、公布分配方案、选房摇号、公示摇号结果。

（五）签订合同、入住阶段（10个工作日）。摇号结果公示结束后，对公示无异议或异议不成立的，在接到县住建局通知后10个工作日内结算房款签订合同、组织入住。

六、动态管理和退出机制

（一）动态管理

（1）购买经济适用住房住房的家庭，应主动配合相关职能部门检查经济适用住房使用情况，经济适用住房不得出售、转借、出租（转租）、闲置、改变用途。

（2）经济适用住房的购买家庭签订该住房房屋买卖合同之日起满五年的，由县住建局牵头负责对其家庭的保障条件进行一次全面审核。对已不再符合相应的住房保障条件的，应当退出经济适用住房，或者通过补交土地收益等价款取得完全产权。对拒不服从退出管理的，可以依照规定或合同约定申请人民法院强制执行。

（3）经济适用住房物业管理企业应当配合做好经济适用住房居住情况的监管。物业服务企业发现有改变使用性质的，应及时告知县住房保障管理部门，配合住房保障管理部门做好入户调查等动态跟踪工作，并协助督促违规家庭整改。对不履责或履职不到位的物业服务企业解除聘用合同，县房地产管理部门将该企业纳入不诚信企业名单。

（4）承购人购买经济适用住房未满5年的，不得转让经济适用住房；确需转让的，由县人民政府按照原购房价格并考虑折旧和物价水平等因素予以回购。

承购人购买经济适用住房已满5年的，可以转让经济适用住房，并按照配售合同约定的产权份额向县人民政府补缴相应价款，县人民政府在同等条件下享有优先购买的权利；承购人也可以按照配售合同约定的产权份额补缴相应价款，取得完全产权。但是，县人民政府规定不得转让或者不得补缴相应价款取得完全产权的除外。

（5）经济适用住房承购人及配偶死亡的，其合法继承人应主动向县住建局申报对房屋进行处理。有其他共同申请人的，变更经济适用住房配售合同；无共同申请人的，收回经济适用住房。

（6）经济适用住房承租人离婚，且将经济适用住房归属其中一方的，另一方视为未配售经济适用住房，但在离婚后五年内不得申请经济适用住房；经济适用住房归属方若再婚，其配偶视为承购经济适用住房。

（7）中介机构不得违规代理出售、出租经济适用住房的，应当依法给予处罚。

（二）退出机制

经济适用住房违规使用等行为处理按照受理、调查、处理的程序办理。

1.受理

（1）受理举报；

（2）定期和非定期的专项督查和执法检查；

（3）物业服务企业日常巡查报告；

（4）其他来源。

任何单位和个人有权对经济适用住房违规使用行为进行举报。设立举报电话、信箱、电子邮箱、信访部门等机构受理的住房保障违规行为举报，应当及时内转送县住建局正式受理。

经县住建局决定不予受理的，属实名举报的应当书面通知举报人，并说明理由；其他情况由县住建局和受理举报的部门将书面材料存档备查。

2.调查

经济适用住房违规使用行为受理后，县住建局应当立即组织工作人员了解情况、实地调查收集证据，核实违规行为，承担该经济适用住房物业服务的物业服务企业应当积极主动予以配合。调查应当制作《调查询问笔录》，并告知当事人认定违规行为的事实、拟作出相应处理的理由和依据，以及当事人依法享有的陈述和申辩的权利。

对于调查属实的，县住建局按照本程序予以相应处理。对于调查不属实的，属实名举报的应当书面告知举报人，对举报人公开调查结果；其他情况由县住建局将书面材料存档备查。

3.处理

擅自将经济适用住房违规出售、出租、出借、无正当理由连续六个月闲置、改变住房用途的，按以下程序进行处理：

①县住建局出具整改通知书，物业服务企业将该通知书送达至违规使用者；

②县住建局会同物业服务企业督促违规使用者在《整改通知书》规定的期限内进行整改；

③违规使用者逾期拒不纠正违规行为的，县住建局告知经济适用住房的出卖人；

④经济适用住房的出卖人依据法律规定和购房合同的约定，根据购房时间分别予以处理。

⑤违规使用者拒不接受处理的，经济适用住房的出卖人依照法律规定和合同约定向人民法院提起诉讼。

（1）发现经济适用住房住户违反规定将保障性住房出租、转租、转借、调换、转让以及从事其他经营性活动的行为，由县住建局发出限期整改通知，整改期限为一个月。对在整改期限内未整改的违规家庭，作出收回处理决定，从处理决定之日起，该家庭五年内不得再次申请经济适用住房。住房保障管理部门依照购房合同约定以及相关规定追回出租、出借所得租金、收益和追究该家庭法律责任。

对闲置、空置六个月以上的经济适用住房，限期三个月内入住。逾期未入住的家庭，县住建局作出收回处理决定。从处理决定之日起，该家庭五年内不得再次申请经济适用住房。

对违反规定的经济适用住房住户视情可在政府网站和媒体上予以通报。

（2）已配售经济适用住房且拥有其他住房或非居住类房屋的经济适用住房住户，应当主动向经济适用住房产权管理单位申报，并在三个月内退出保障性住房。主动退出的，经济适用住房购房款按原购房价格退回。未主动退出的，从第四个月起，经济适用住房购房退回款按原购房价格每日扣减0.5‰计算；土地、房管部门冻结购房人所有房屋土地交易手续；经济适用住房产权管理单位依法申请人民法院强制执行。

（3）经济适用住房购房人（即申请家庭全体成员，下同）取得房屋所有权证（或签订配售合同）不满五年，须购买其他住房、非居住类房屋以及购房人迁往外地或者出国定居或家庭成员因特殊原因急需资金须退房的，经济适用住房由政府予以回购。回购价格为经济适用住房原销售价格。经济适用住房房屋装修不予补偿，不计入回购价格。

购买的经济适用住房，自取得《房屋所有权证》（签订购房合同）之日起满五年的，可以上市交易；购房人向政府交纳土地收益等价款后，可以取得完全产权。土地收益等价款按照经济适用住房住户申请上市交易届时的同地段同类普通商品住房市场指导价（由县房地产管理部门提供）与原购买经济适用住房价格差价收取。交易税费按规定缴纳。申请政府回购的，回购价格为经济适用住房原销售价格加银行存款利息（计息时段为经济适用住房原购房款交清之日起至申请回购之日止，利率为签订房屋转让合同之日的中国人民银行活期存款利率）。

（4）经济适用住房住房购房人及其配偶死亡的，其合法继承人应主动向县住建局申报对房屋进行处理。该房屋权属可按规定办理至其符合购买经济适用住房条件的合法继承人名下；没有符合购买经济适用住房条件合法继承人的，该房屋由政府回购，回购价格由县市场监管部门按照原价格并考虑折旧和物价水平等因素确定，装修不予补偿。

从回购完成之日起，该家庭五年内不得再次申请经济适用住房。县住建局可将违反规定的经济适用住房购房人的相关信息在政府网站或媒体上予以通报。

（5）经济适用住房购房人离婚，且将经济适用住房归属其中一方的，另一方视为未购经济适用住房，但在离婚后五年内不得申请购买经济适用住房；经济适用住房归属方若再婚，其配偶视为已购经济适用住房。

（6）违反本办法第六条第一项第七款的，依照《房地产经纪管理办法》第三十七条，由县级以上地方人民政府住房城乡建设（房地产）主管部门责令限期改正，记入房地产经纪信用档案；对房地产经纪人员，处以1万元以下罚款；对房地产经纪机构，取消网上签约资格，处以3万元以下罚款。

七、法律责任

对弄虚作假、隐瞒家庭收入和住房条件，骗购经济适用住房的，由县住建局负责追回房屋。县住建局可提请购房人所在单位或有关部门对购房人依法依纪追究责任；并可提请有关部门追究出具虚假证明的单位主要领导和直接责任人的责任；涉嫌犯罪的，移送司法机关处理。

由县住建局追回房屋的，县住建局应限令该购房人3个月内搬离，追回该房屋、退回购房款。退回价格由县市场监管部门按照原价格并考虑折旧等因素确定，购房人腾退房屋时违规装修的费用由承购人自行承担，同时应结清承租期间的水、电、暖、物业管理等相关费用，并由物业管理企业对房屋进行检查验收，提供验收结果证明，造成损失的，依法承担赔偿责任。购房人不配合的，县住建局可依法申请人民法院追回。

八、附则

本方案自发布之日起执行，县住建局负责对本方案进行解释。
