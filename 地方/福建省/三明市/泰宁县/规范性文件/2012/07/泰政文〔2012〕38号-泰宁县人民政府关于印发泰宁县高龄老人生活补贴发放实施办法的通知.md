# 泰宁县人民政府关于印发泰宁县高龄老人生活补贴发放实施办法的通知

各乡（镇）人民政府，县各单位：

《泰宁县高龄老人生活补贴发放实施办法》已经县政府常务会议研究同意，现印发给你们，请认真组织实施。

二○一二年五月二十五日

泰宁县高龄老人生活补贴发放实施办法

为进一步落实县委、县政府惠民政策，弘扬中华民族尊老敬老爱老的传统美德，提高老年人幸福指数，提升全县80岁以上高龄老人生活质量，结合我县实际，特制定本实施办法。

一、发放范围

凡本县行政区域内，持有本地城乡居民户口，且年龄在80岁及以上的高龄老人，未享受机关、企、事业离退休养老金的人员均属补贴范围。

二、发放标准

分三个年龄段：80—89岁的高龄老人每人每月发给30元生活补贴；90—99岁的高龄老人每人每月发给50元生活补贴；年满百岁及以上的高龄老人每人每月发给400元生活补贴（其中200元为长寿营养补贴、200元为高龄老人生活补贴）。

三、审批办法

高龄老人申领生活补贴，向所在村（居）委会申报，按要求如实填写《高龄老人生活补贴申报审批表》，并提供本人户口簿、第二代身份证复印件，同时将原件交村（居）委会查验；无身份证的，应到当地派出所开具户籍证明。

申报审批表内容必须真实、完整，应在村（居）所在地公示5天后，经村（居）委会盖章，报乡（镇）老龄办复审后，由乡（镇）填报《泰宁县高龄老人生活补贴花名册》，并与《申报审批表》一起报送县老龄办审批，《花名册》需要同时报送电子版。

四、资金筹措和发放办法

（一）资金筹措。全县高龄老人生活补贴所需的资金，由县财政每年列入年度财政预算，实行专项管理。

（二）高龄补贴发放办法。高龄老人生活补贴按季度发放，县老龄办在每季度次月初向县财政申报所需资金，县财政在每季度次月上旬前核拨县老龄办，县老龄办按季度通过邮政储蓄银行，直接将补贴发放到享受高龄补贴的老人手中。

（三）高龄老人生活补贴的增减变动。每年1月为年龄达到80岁及以上高龄老人的申报时间（计算年龄按出生时间对年不对月，如2012年享受对象为1932年12月31日前出生的老年人）。享受高龄生活补贴的对象死亡、户口迁出本县等，乡（镇）老龄办应在其发生变动的次月及时上报县老龄办核销。

五、工作要求

（一）加强领导。为80岁以上老年人发放高龄生活补贴，是贯彻落实科学发展观，关心关注民生，构建和谐泰宁的一项重要举措，是一项长期工作，各相关部门要高度重视，切实加强领导。县老龄办要加大对发放工作的监督、检查、指导力度，真正把这一保障和改善高龄老人基本生活、维护老年人合法权益的民生实事办好。

（二）广泛宣传。要加大对实施高龄老人生活补贴制度的宣传力度，使之家喻户晓，人人皆知，确保符合条件对象均能享受优待政策。同时，要大力宣传中华民族尊老敬老爱老传统美德，呼吁全社会关心关注老年人和老龄事业，努力营造全社会关心关爱老年人的浓厚氛围。

（三）规范手续。高龄老人生活补贴发放工作涉及人员广、工作任务重。各乡（镇）要规范申请、审核各个环节，严格把关，既要让符合条件的老年人及时享受优待政策，又要坚决维护政策实施的严肃性，杜绝弄虚作假、虚报瞒报。对空巢和行动不便等有实际困难的老年人，可上门办理申请手续，力争符合条件的对象不遗漏。

（四）加强管理。县老龄办、各乡（镇）要落实专门人员，全面收集发放对象的信息，建立发放数据库，建立完善相关档案，实行动态化管理，同时要按规定要求做好增减变动的调整工作，确保我县高龄老人生活补贴发放工作落到实处。

六、实施时间

本实施办法自2012年7月1日起施行。
