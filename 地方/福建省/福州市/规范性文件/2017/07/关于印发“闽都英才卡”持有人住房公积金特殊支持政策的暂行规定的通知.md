# 关于印发“闽都英才卡”持有人住房公积金特殊支持政策的暂行规定的通知

各住房公积金管理机构：

经2017年第1次福州住房公积金管理委员会全体成员会议审议通过，现印发《关于“闽都英才卡”持有人才住房公积金特殊支持政策的暂行规定》，请遵照执行。

福州住房公积金管理委员会

2017年6月28日

关于“闽都英才卡”持有人住房公积金特殊支持政策的暂行规定

为深入实施人才强市战略，进一步优化福州市人才发展的环境，为高层次人才提供高效、便利、优质的服务，根据《福建省引进高层次优秀人才服务办法》、《福州市引进高层次优秀人才服务办法》等文件精神，结合我市实际，对“闽都英才卡”持有人在执行我市住房公积金政策基础上，实行以下住房公积金特殊支持政策：

一、在福州有工作单位的“闽都英才卡”持有人及其配偶可缴存住房公积金。

二、“闽都英才卡”持有人及其配偶在福州地区购买具有产权的自住住房的，自正常缴存住房公积金当月起，即可申请住房公积金贷款。

三、“闽都英才卡”持有人及其配偶在福州地区首次申请住房公积金贷款的，贷款最高额度可放宽至福州住房公积金最高贷款额度的4倍。

四、“闽都英才卡”持有人及其配偶在福州地区申请住房公积金贷款时，应提供福州地区住房公积金管理机构规定的贷款材料和“闽都英才卡”。

五、本细则自2017年7月1日起执行。
