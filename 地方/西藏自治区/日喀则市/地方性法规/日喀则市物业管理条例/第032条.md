# 第三十二条

业主、物业使用人、物业服务人等不得实施下列行为：

（一）擅自拆改建筑物主体、承重结构；

（二）擅自利用共用部位、共用设施设备进行经营；

（三）违法搭建建筑物、构筑物、障碍物或者擅自挖掘地下空间；

（四）在建筑内的公共门厅、疏散通道、楼梯间、安全出口等公共区域停放电动自行车或者为电动自行车充电；

（五）擅自拆改共用供水、排水、再生水等管线；

（六）从建筑物中抛掷物品；

（七）制造噪声干扰他人正常生活；

（八）侵占绿地、毁坏绿化植物和绿化设施；

（九）通过设置地锁、石墩、栅栏等障碍物和乱堆乱放杂物等方式，占用、堵塞、封闭消防通道、疏散通道等共用部位，或者损坏消防设施等共用设施设备；

（十）法律法规禁止的其他行为。
