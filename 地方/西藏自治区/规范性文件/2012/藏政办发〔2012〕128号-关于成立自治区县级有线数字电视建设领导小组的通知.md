# 关于成立自治区县级有线数字电视建设领导小组的通知

背景色：

小

中

大

各行署、拉萨市人民政府，自治区各委、办、厅、局：

为推进全区有线电视数字化建设，加快县级有线数字电视建设工作，经自治区人民政府同意，成立自治区县级有线数字电视建设领导小组（以下简称领导小组）。领导小组组成人员如下：

组 长： 多 托 自治区副主席

副 组 长： 才旦南杰 自治区人民政府副秘书长

张 崇 银 区党委宣传部副部长、广电局局长

成 员： 庄 劲 松 区党委宣传部副部长

胡 新 生 发展改革委副主任

尹 分 水 财政厅副厅长

才 旺 广电局副局长

青 其 通信管理局局长

领导小组下设办公室，办公室设在广电局，张崇银同志兼任办公室主任，才旺同志兼任办公室副主任。

2012年10月19日
