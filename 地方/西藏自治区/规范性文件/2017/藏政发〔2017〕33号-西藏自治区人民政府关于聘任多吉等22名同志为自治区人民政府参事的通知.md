# 西藏自治区人民政府关于聘任多吉等22名同志为自治区人民政府参事的通知

西藏自治区人民政府

背景色：

小

中

大

各地（市）行署（人民政府），自治区各委、办、厅、局：

参事工作是加强中国特色新型智库建设、建立健全决策咨询制度的重要组成部分。为进一步发挥政府参事“参政议政、建言献策、咨询国是、民主监督、统战联谊”的职责和作用，进一步提升政府决策科学化、民主化水平，经十届自治区人民政府第77次常务会议研究，聘任以下22名同志为自治区人民政府参事。
