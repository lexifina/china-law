# 西藏自治区人民政府关于开展西藏自治区第三次全国土地调查工作的通知

西藏自治区人民政府

背景色：

小

中

大

各地（市）行署（人民政府），自治区各委、办、厅、局：

为贯彻落实《国务院关于开展第三次全国土地调查的通知》（国发〔2017〕48号）精神，做好我区第三次全国土地调查工作。现将有关事项通知如下：

一、调查目的和意义

土地调查是一项重大的国情国力调查，是查清查实土地资源的重要手段。开展第三次全国土地调查，目的是全面查清当前土地利用状况，掌握真实准确的土地基础数据，健全土地调查、监测和统计制度，强化土地资源信息社会化服务，满足经济社会发展和国土资源管理工作的需要。

做好第三次全国土地调查，掌握真实准确的土地基础数据，是加快推进生态文明建设、夯实自然资源调查基础和推进统一确权登记的重要举措；是编制国民经济和社会发展规划、加快宏观调制、推进科学决策的重要依据；是实施创新驱动发展战略、支撑新产业新业态发展、提高政府依法行政能力和国土资源管理服务水平的需要；是落实最严格的耕地保护制度和最严格的节约用地制度、保障国家粮食安全和社会稳定、维护农民合法权益的重要内容；是科学规划、合理利用、有效保护国土资源的基本前提。

当前，我区正处在长足发展和全面建成小康社会的关键时期，国土资源管理工作面临的形势任务更加艰巨。各行各业对土地资源基础数据提出了更高、更精、更准的要求，而当前我区现有的土地调查成果已不能满足经济社会发展需要。做好第三次全国土地调查及成果应用工作，对于推进国家治理体系和治理能力现代化、促进经济社会全面协调可持续发展具有重要的意义。

二、调查任务和内容

第三次全国土地调查的主要任务是在第二次全国土地调查成果基础上，按照统一的技术标准，采用新修订的《土地利用现状分类》，利用遥感和“互联网+”等新科技手段，查清全国各类农用地、建设用地和未利用土地的面积、分布及用途等状况；查清全国各类土地的权属状况；更新全国永久性基本农田数量、质量、分布状况；建立国家、省、市、县四级土地基础数据库，完善各级互联共享的网络化管理系统；健全土地资源变化信息的调查统计、全天候全覆盖遥感监测与快速更新机制。

三、调查时间安排

（一）第三次土地调查的标准时点为2019年12月31日。

（二）2017年底前，全面部署第三次土地调查，完成调查方案编制、组织机构建立、培训宣传等工作。

（三）2018年1月至2019年6月，组织开展实地调查和数据库建设。

（四）2019年下半年，完成调查成果整理、数据更新、成果汇交、汇总形成全区第三次土地调查基本数据，上报国土资源部。

（五）2020年汇总全区第三次土地调查数据，形成调查数据库及管理系统，完成调查工作验收、成果发布等。

四、调查组织实施

第三次全国土地调查涉及范围广、参与部门多、工作任务重、技术要求高，各地（市）、各有关部门要按照“自治区统一领导、部门分工协作、地方分级负责、各方共同参与”的原则组织实施调查。

为加强组织领导，成立了西藏自治区第三次全国土地调查领导小组，负责领导和协调解决调查工作中的重大问题。领导小组下设办公室，办公室设在国土资源厅，具体负责组织协调、业务指导、督促检查等日常工作。各有关部门要结合职能分工，相互配合协作，认真做好组织实施。对工作中遇到的困难和问题，要及时采取措施，切实予以解决。

各地（市）、县（区）要将西藏自治区第三次全国土地调查工作纳入重点工作安排，成立相应的领导小组及其办公室，负责本行政区域工作的组织实施。县（区）人民政府是第三次全国土地调查工作的法定主体，务必将此项工作纳入各级政府国土资源管理目标考核，对工作措施不得力，不能按期完成工作任务的要追究责任。各级政府要加强专业技术队伍及工作人员的协调配置，确保工作进度和工作质量，并对本行政区域的第三次全国土地调查工作成果质量负责。

五、调查经费保障

各级政府要按照中央的要求，统筹安排，将我区第三次全国土地调查工作经费足额纳入财政预算，按时拨付，确保足额到位，保障工作顺利实施。

六、工作要求

各地（市）要加强对承担调查任务的调查队伍的监管。各调查机构及其工作人员必须严格按照《中华人民共和国统计法》等有关法律法规要求，按时报送调查数据，确保调查数据真实、准确、完整。任何地方、部门、单位和个人都不得虚报、瞒报、拒报、迟报，不得弄虚作假和篡改调查数据。调查成果要按程序逐级汇总上报。调查中所获得的涉密资料和数据，必须严格保密。

各级政府要通过报纸、电视、网络、宣传标语等媒体和方式，全面深入宣传土地调查的重要意义和要求，为调查工作顺利进行营造良好的社会氛围。
