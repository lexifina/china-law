# 日土县人民政府办公室关于做好2018年度政府信息公开年报及数据统计工作的通知

各乡（镇）人民政府，政府各局、委、办：

根据《西藏自治区人民政府办公厅转发<国务院办公厅关于加强和规范政府信息公开情况统计报送工作的通知>>(藏政办发〔2014〕76号）和《西藏自治区人民政府办公厅关于印发<西藏自治区政府信息公开办法>的通知》（藏政办发〔2015〕64号）有关规定和工作要求，现就做好2018年政府信息公开工作年度报告编制和数据统计有关事宜通知如下：

一、认真总结编制

各单位要高度重视，全面总结2018年度本乡（镇）、本部门政府信息公开工作进展情况和取得的成效，客观反映存在的问题和改进情况，切实做好年度报告编制、公布和政府信息公开情况数据统计工作。

年度报告内容应包括：行政机关主动公开政府信息情况；公民、法人或者其他组织申请公开政府信息的行政机关同意公开、部分公开和不予公开政府信息的分类统计情况；因政府信息公开申请行政复议、提起行政诉讼的情况及其他处理结果；政府信息公开的收费及免除情况；政府信息公开工作存在的主要问题及改进情况；其他需要报告的重要事项。

二、规范审核统计

各单位要对政府信息公开工作年度报告进行认真审核把关。一是准确定性公开申请。详细梳理本单位受理依申请公开情况，确保依申请公开情况统计真实准确，不能把政策咨询、业务询问等列入依申请公开范围。二是加强数据审核工作。采取逐级逐项审查方式，加强审核、反复核对，确保数据真实准确完整。三是确保口径一致。对统计行政复议、提起行政诉讼、举报投诉等情况，应与本级司法、监察部门及法院沟通确认。

三、及时公布报送

请于2019年2月20日前将年度报告通过日土县政府门户网站及时向社会公布。请对照政府信息公开情况统计指标填报说明，逐项填写《政府信息公开情况统计表》（无须公布）。年度报告及情况统计表（纸质材料附电子文档）请于1月24日下班前报送政府办211。

未及时公布或按时报送的，视作年度未开展相关工作。
