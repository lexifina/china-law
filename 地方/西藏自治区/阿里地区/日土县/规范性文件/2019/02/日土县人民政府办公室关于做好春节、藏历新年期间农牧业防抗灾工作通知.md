# 日土县人民政府办公室关于做好春节、藏历新年期间农牧业防抗灾工作通知

各乡（镇）人民政府：

为做好冬春季节农牧业防抗灾工作，明确防抗灾工作方针、目标、任务，做好早计划、早安排、早落实，最大限度地减轻灾害对农牧业生产和群众生活造成的损失，我县多次召开会议，专题研究部署去冬今春防抗灾工作。入冬以来，我县出现降雪天气，加之我县农牧业基础设施较为薄弱，抗御自然灾害能力较差，抗灾工作距离远且十分分散若出现新一轮及强降雪，导致我县前期的积雪维持或加深，防灾保畜形势不容乐观。目前，我们即将迎来春节、藏历新年，将做好农牧业防抗灾工作列为当前一项重要工作，要求各乡（镇）切实予以贯彻落实，现就加强做好春节、藏历年期间农牧业防抗灾工作通知如下：

一、统一思想，加强颁导，切实做好防抗灾工作

各乡（镇）要把做好农牧业防抗灾工作作为当前一项重要任务来抓，牢固树立“有灾抗灾、无灾防灾”的思想，切实加强领导，做到思想到位、责任到位、组织到位和工作到位。要进一步加强领导、精心安排、周密部署、狠抓落实，切实将责任落到实处、落到单位、落到人头。坚决克服麻痹思想和侥幸心理，保持高度警惕，及时研究分析可能出现的异常现象，高度重视气象部门预警信息和建议，及早制定有效防范措施，力争使灾害损失减少到最低程度。

二、扎实做好“六有”、“四储备”工作

各乡（镇）要对广大农牧民群众“六有”（有粮食、有衣穿、有房住、有燃料、有药物、有饲草料”情况进行实地检查，确认达到储备要求，对出现物资紧缺的，要及时协调抓好调配补充工作。加强定居房屋、牲畜棚圈、人畜饮水点和储草棚建设，提升草原畜牧业防灾抗灾能力。特别是易灾乡（镇）、村要按照“以人定燃料、以畜定草料”的原则加强农牧民防寒衣物、燃料、牲畜饲草料、人畜药品等抗救灾物资储备，特别是在高寒易灾牧区要储备足够的牲畜饲草料和燃料。同时，做好防抗救灾机械维修保养工作。协同做好应急力量和防抗灾装备设备的维护等准备工作。各乡（镇）要根据历年经验，协调组织和准备好一定规模的应急力量和装备设备待命，确保一旦发生灾情、接到指令后，相关应急队伍和装备能够拉得出、用得上。

三、狠抓春季接羔育幼工作，提高幼畜成活率

各乡（镇）务必要切实加强对接羔育幼工作的管理和指导，组织技术人员深入乡村牧区，开展巡回检査指导，提早准备好接羔育幼草场、维修好暖棚和羔宫，加强对母畜和仔畜的饲养管理，有效提高新生仔畜成活率。要根据天气的变化趋势，提早计划，搞好饲草料准备、牲畜转场放牧，以及群众的生活必需品的准备等工作，牢牢把握防抗灾工作的主动权。要高度重视春季草原防火工作，重点加强冬春草场及接羔育幼草场的防火，排除火灾隐患，保护草场这一牲畜的生命线。

四、扎实做好重大动物疫病防治工作

各乡（镇）要在思想上警钟长鸣，工作上常抓不懈，措施上科学规范，坚决克服麻痹思想和侥幸心理。要坚持“预防为主”的方针，认真落实重大动物应急预案，建立处理突发重大疫情的机制，切实提高预案的预见性、针对性和可操作性。要扎实开展疫情监和强制性免疫工作，严格落实疫情监测制度，提高监测密度，确保及时准确地掌握疫情。一旦发现疫情，要依法坚决落实强制性揩施，就地进行控制扑灭，防止疫情扩散蔓延。

五、加强信息报送工作，确保信息畅通

各乡（镇）要严格落实灾情报告制度，及时转发预警信息，把天气异常情况和重大灾情信息的报送工作纳入紧急信息报送范围。密切关注本地区的天气变化趋势，做好雪灾霜冻、大风等灾害性天气的预测预报和防范工作，做到早发现、早预防、早救治。（各乡镇）要将重大气象预测预报及时传送各村、组，督促各村提早准备，提早部署提早落实各项防抗灾措施。一旦发生灾害，要按照农业自然灾害等级管理要求，分级及时启动自然灾害突发应急预案。

六、强化应急备勤，做到数据准情况实

各乡（镇）要调整充实值班人员，落实24小时值班和领导带班制度，确保灾情信息及时上传下达。要确保信息渠道畅通，及时收集核实灾情的发生的时间、地点、范围、危害程度、损失等情况。上报情况务必做到数据准、情况实、速度快，要统一口径、统一上报渠道，及时按规定将灾情情况反馈县防抗灾办和应急办，无特殊情况、未经许可不得越级上报相关灾情情况；要认真做好牲畜政策性保险投保、灾害评估和理赔等相关工作，有效减轻群众受灾因灾损失

日土县人民政府办公室

2019年2月1日
