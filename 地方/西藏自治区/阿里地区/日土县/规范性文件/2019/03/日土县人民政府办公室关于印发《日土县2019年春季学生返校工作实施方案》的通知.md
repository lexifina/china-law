# 日土县人民政府办公室关于印发《日土县2019年春季学生返校工作实施方案》的通知

各乡（镇）人民政府，县教育局、财政局、公安局、交通局、卫计委、安监局、食药局、各级各类学校：

根据阿里地区各学校寒暑假学生接送及内地西藏班（中职班）暑假进出藏学生接送工作的有关通知，阿行办发〔2018〕162号文件和关于印发《2018年日土县各学校暑假前期各类安全稳定工作实施方案》的通知，日政办发〔2018〕60号文件及关于做好阿里地区中小学、幼儿园寒假放假、开学时间及学生接送车辆安排的通知，阿教体字〔2018〕360号文件要求，进一步做好我县各学校（含内地西藏班、中职班）学生开学返校接送工作，全力确保学生返校道路交通安全，保障广大学生的生命财产安全，遏制学生安全接送责任事故的发生，确保春季开学顺利接送学生，结合我县实际，特制定本工作实施方案：

一、领导小组

认真做好学生安全返校工作，加强组织领导，以“安全第一、预防为主、落实责任、保障安全”的原则，切实担负起工作责任，确保学生返校工作中不出任何安全隐患。特成立春季学生返校工作领导小组：

二、分化职责、强化落实

1.各乡（镇）人民政府按照“属地管理”原则，根据学生就读学校和学生学龄阶段等不同情况，研究制定本乡（镇）学生返校工作实施方案，积极鼓励和支持学生乘坐由学校统一组织的国营客运车辆，不得擅自乘坐非法营运车辆（黑车），并联合有关部门做好学生返校道路交通安全宣传教育工作，切实督促所属学校“三到位”情况，务必做到所有师生于3月10日前完成返校工作。

2.县教育局负责跟踪掌握学生返校动态和道路交通安全情况，负责从日土至狮泉河往返，狮泉河至拉萨返校集中统一接送学生车辆的协调配合和相关交通运费协调落实工作，并协调解决接送工作中存在的突出问题和困难，安排专人配合、组织协调公安、工商、卫生、综治、食药等部门，及时沟通信息，加大校园周边治安乱点清理整治，净化校园周边治安环境。

3.县公安局和交警支队负责协调各学校对学生返校集中统一接送车辆安排引道，护送民警人员的安排及相关车辆安全秩序工作，并与护送教师通力合作做好学生乘车管理和护送工作。及时对其他学校（拉萨阿里高级中学、拉萨河北完全中学、地区职业技术学校、地区中学）安排一辆警车、一名专职驾驶员、两名干警的护送工作，针对县域内路途较远、路况较差的阿汝村、松西村、扎普村、丁则村、乌江村、过巴村必须要安排警车开道，其他村必须配备一名警车和一名老师。

4.县卫计委和食药局做好在学生返校集中统一接送时发生突发事件和人身伤亡时第一时间保障医疗急救工作。负责指导各校完善流行性疾病和传染病防治措施，务必提前做好常规药品的筹备工作，切实加强开学前各学校消毒工作，防止各种传染病的流行发生，加强全县学校卫生防疫、疫控工作。加强学校食堂采购物品的质量管理、监督和检查，预防学生食物中毒，开学后立即组织相关部门对各学校检查各类食品库存情况，要确保食品的存放“三离一通”要求，全面加强和规范食品的入口关和出口关，防止出现腐烂、变质、过期等问题。

5.边防支队和交通四支队负责学生返校集中统一接送车辆的安全通行，及时清理路面积雪结冰道路，严防出现道路拥堵，出行难等问题，确保各学校返校学生及时安全有序通检。

6.交通部门（交通执法、运管）一是积极联合相关部门，坚决制止农用车辆、货车、无营运资质等接送学生，配合教育部门协调和解决学生接送运力问题。二是严格把关接送学生车辆的准入关、营运车辆技术状况、营运驾驶人员资格关，落实客运安全责任制度。三是掌握接送学生车辆底数、车主、运行区间、车辆安全技术状况、驾驶员资质、车牌号、核载人数等基本信息，严格按规定，安排营运路线，确保学生交通安全。四是强化车辆定期保养制度，杜绝病车上路。五是加强现场监管力度，坚决打击酒驾、疲劳驾驶、超载、超速、超重、无证驾驶等违法行为，严肃打击无照、无营运资质的“黑车”承运行为。六是严格执行“三关一监督”制度和“三不进站、六不出站”规定。负责驾驶员的安全教育，防止出现酒驾、疲劳驾驶、超载、超重、无证驾驶等违法行为。

7.安全生产监督管理部门:会同公安、交通、教育等部门，加强对相关制度、措施落实情况的检查指导，并将接送学生车辆管理纳入安全生产目标责任制，强化对接送学生车辆的综合管理。定期或不定期抽查接送车辆安全管理，督促乡(镇)和相关部门认真履行安全生产管理职责落实。

8.各学校要在开学前安排专人负责统计本学校学生人数和基本信息（即：基本信息统计细化到村一级），各学校为确保学生安全到校，学校与护送教师和司机层层签订责任书，必须指定专人组织学生上车护送学生返校。维持学生上下车的正常秩序，安排做好控制乘坐车辆的学生人数，注意安全、不得拥挤，杜绝学生将头、手、脚伸出车外，接生教师负责清点学生人数后报值班老师，值班老师严格执行“一日两报”工作。

三、返校对象及返校时间

春季返校对象：全县县域内返校时间：2019年3月3日—3月4日，3月5日正式开学；拉萨阿里高级中学返校时间：2月25日统一从日土送往拉萨；拉萨河北完中返校时间：3月1日统一从日土送往拉萨；阿里地区职业技术学校、地区中学返校时间为3月5日。

四、相关工作要求

（一）要提高认识。各部门要从维护学生生命财产安全、维护社会和谐稳定的高度出发，统一思想，提高认识，加强对接送学生车辆的组织领导，部门主要负责人作为第一责任人，要亲自抓、亲子管、亲自过问，实行层层签订责任制，切实将责任落实到人。

（二）要认真开展青少年学生自救教育，提高青少年学生遇险自救能力。加强对中小学生交通安全教育，确保假期在藏期间安全工作万无一失。

（三）加强组建对接送学生车辆安全管理工作领导小组办公室，要加强督促检查和指导各相关职能部门职责履行情况，落实具体的工作措施。凡在学生交通运输安全工作中未履行职责，玩忽职守，工作不到位，责任不落实，失职渎职而造成的严重后果，将严格按照有关规定，追究相关领导和责任人的责任。
