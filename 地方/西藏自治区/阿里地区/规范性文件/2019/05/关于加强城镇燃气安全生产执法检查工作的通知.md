# 关于加强城镇燃气安全生产执法检查工作的通知

文章来源： 发布日期：2019-05-05 浏览：

各县住房和城乡建设局：

根据《阿里地区危险化学品等重点行业领域安全生产专项执法检查行动实施方案》（阿安危〔2019〕10号）精神，为进一步落实各项安全生产责任和措施，切实加强我地区城镇燃气行业安全生产工作，现将有关工作通知如下。

一、高度重视

各县要认真贯彻落实习近平总书记、李克强总理关于安全生产批示精神，深刻吸取近期全国非煤矿山、煤矿、危险化学品、“3.21”等领域重大事故的经验教训，牢固树立风险底线、坚守安全红线，严格落实安全生产责任制，做好城镇燃气安全生产执法检查工作。

二、强化督导检查

各县严格按照自治区、地区关于安全生产决策部署，认真开展城镇燃气安全生产执法检查工作，主要检查为取得相关审批手续擅自改动燃气设施的；未取得燃气经营许可证，擅自从事燃气经营的；燃气企业未建立健全日常巡检检查制度，未按要求开展巡检和检查的；无安全事故应急预案和应急处突预案，无抢险救援物资和反恐防范器械，未定期组织演练的；管理人员、操作人员未经专业培训或考核不合格，无证上岗，不穿工作服的；未安装防撞、防爆、燃气泄漏报警装置的；未安装视频监控系统，未建立24小时质保、巡查制度的；场内无安全警示标识、安全常识宣传栏的；对燃气设施安全运营情况未进行安全风险评估等方面开展执法检查，发现问题及时整改。

三、积极配合做好迎检工作

各县严格按照《关于印发<危险化学安全专项巡查工作方案>的通知》（阿安危办〔2019〕8号）要求，积极做好迎检准备工作，并督促燃气经营企业按要求做好迎检工作。

阿里地区住房和城乡建设局
