# 阿里地区行署办公室关于做好行署门户网站信息报送工作的通知

文章来源： 发布日期：2019-06-11 浏览：

各县人民政府，行署各局、委、办、处：

行署门户网站（www.al.gov.cn）于2019年1月1日正式上线，原阿里网已停运。为进一步加强政府网站建设，提升网站服务水平，及时挖掘新闻信息资源，充分反映全地区在经济、社会、民生等领域取得的成就，不断加强网站新闻和公开信息的时效性，确保行署门户网站正常高效运行。现就有关事宜通知如下。

一、建立信息员联络制度

各县各部门要高度重视信息资料报送工作，指定1名网络信息员，负责向行署门户网站报送相关信息和政策性文件。网络信息员原则上为办公室主任或负责人，请各县各部门将联络员的姓名、职务、联系电话等基本信息于6月14日前报行署办公室网络信息中心。

二、具体报送要求

1.按照“谁提供、谁审稿、谁负责”的原则，把好信息的审查关，确保报送的信息重点突出、内容真实、数据准确、语言精炼。

2.行署门户网站“政务公开”栏目涉及教育、卫生、市监、财政、项目、住建、民族团结、便民服务和食品药品安全等26个领域，行署各部门要将本单位上报下发的与人民群众生活息息相关的文件（不涉密）及时上报。

3.各县各部门每周至少报送2条有价值的新闻信息。当天起草的信息呈送主要领导审批签字后，应在当天报送，确保信息的时效性。

3.各县各部门主要领导要守好新闻信息保密审核的“最后一关”，对报送稿件内容要认真审核，确保真实准确、内容可公开后方可报送。要加强对网络信息员的保密教育和学习，切实提升网络信息员的保密安全意识。

三、严格追责问责

行署办公室将定期或不定期对各县各部门信息、文件报送情况进行通报，对报送数量较少、报送质量较差、报送稿件内容有误的单位，将对网络信息员进行追责问责。

四、信息报送方式

信息可通过邮箱进行报送（文件必须刻录光盘），也可刻录光盘送至行署办公楼附楼二层网络信息中心。
