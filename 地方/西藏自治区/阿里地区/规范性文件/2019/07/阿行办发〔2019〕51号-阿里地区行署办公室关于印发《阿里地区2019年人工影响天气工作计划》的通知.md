# 阿里地区行署办公室关于印发《阿里地区2019年人工影响天气工作计划》的通知

文章来源： 发布日期：2019-07-12 浏览：

各县人民政府，行署各局、委、办、处：

《阿里地区2019年人工影响天气工作计划》已经行署同意，现印发给你们，请认真贯彻执行。

阿里地区行署办公室

2019年7月4日

阿里地区2019年人工影响天气工作计划

根据《国务院人工影响天气管理条例》《西藏自治区人工影响天气管理办法》等有关规定，结合我地区实际，为确保全地区人工影响天气工作持续、健康、安全、有序开展，制定本计划。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会以及中央经济工作会议、中央第六次西藏工作座谈会议精神，深入贯彻习近平总书记关于治边稳藏重要论述和加强民族团结、建设美丽西藏的重要指示精神，深入贯彻胡春华副总理在人工影响天气工作座谈会上的讲话精神，贯彻自治区第九次党代会、区党委九届三次、四次、五次全会和区党委、地委经济工作会议以及全国、全区气象局长会议精神，按照今年地区人工影响天气工作安排，切实加大人工影响天气现代化、标准化建设，通过提高人工影响天气科技水平、作业能力、管理水平和服务效益，为全地区经济社会发展和人民群众安全福祉提供有力保障。

二、工作目标

根据《阿里地区“十三五”气象事业发展规划》《阿里地区打赢蓝天保卫战三年行动计划实施方案》要求，坚持基础性、公益性定位，利用高炮、移动式火箭架等方式全力开展春夏季农业抗旱增雨、防雹和保障重大社会活动等人工影响天气工作，为建设美丽阿里作出积极贡献。

三、主要任务

（一）科学组织开展人影作业。顺应经济社会发展对人工影响天气工作提出的新要求，地、县两级人工影响天气领导小组办公室要提前做好作业部署，密切监视天气变化，应用好自治区人工影响天气中心发布的人工增雨（雪）作业和人工防雹指导产品，加强与地区气象台沟通，除常规作业外，重点做好农作物需水季节、干旱发生期和冰雹多发期的人影作业。在技术装备和气象条件允许的情况下，根据实际需要，组织开展保障重大社会活动人影工作，其他时段根据气候变化和应急作业需求适时调整作业部署。各作业点要严格执行24小时值班带班制度，根据人影工作任务，结合实际，适时组织开展人影作业。

（二）加强人影作业能力建设。大力推进科学作业、精准作业、安全作业，引进地（市）级人工影响天气装备弹药物联网监控系统和人工影响天气综合处理分析与指挥系统（CPAS），争取早日实现本地化应用，建成普兰县西德村标准化作业点，加快普兰县多油村、仁贡村及噶尔县门士乡3个作业点标准化建设项目申报，配齐配强软硬件设施，不断提高作业条件潜势预报能力。完善现有人影作业点建设。

（三）加强人影作业安全管理。牢固树立安全是人影工作生命线的意识，各县人民政府与本县气象部门签订安全责任书，落实安全责任制，严格执行人影工作各项规章制度，加强空域申请、作业公告、弹药储运、转场交通、作业人员安全等重点环节管理，健全完善人影安全监督管理体系，完善安全事故应急处置预案，年内至少开展1次应急演练，不断提高事故应急处置能力。加强作业装备安全管理，委托具备相关资质机构开展人影作业设备年检维修，做好装备使用、维护、保养和状态登记，严禁使用未年检或年检不合格的高炮、火箭发射装置。加强与公安、应急管理、军队等有关部门沟通协调，规范人影弹药购买、存储、运输等工作，严格执行弹药出入库管理、人影地面作业空域申请报批、作业前公告等有关规定，禁止使用过期、故障弹药，建立齐抓共管的安全监管合作机制，杜绝人影安全事故发生。健全人影安全管理制度和常态化安全巡查制度，定期和不定期开展人影安全检查，发现问题及时督促整改。进一步加强作业人员安全管理，严禁未经培训和培训不合格的人员上岗作业。

（四）加强人影人才队伍建设。加大走出去力度，积极选派业务骨干人员参加人影业务培训，提高专业技能。采取分批次、分阶段的方式对作业人员进行安全技能培训，今年5月下旬、10月中旬对普兰县西德村、多油村、仁贡村及噶尔县门士乡18名作业人员开展技能培训，确保培训上岗率达到100%。要适当提高作业人员补助，及时解决作业补助落实不到位、不及时、标准过低等问题，稳定基层人影作业队伍。

四、作业计划安排

（一）第一季度。沟通协调昆莎机场空中管制部门，完成2019年空域申请工作。安装完善防雷设施，避免雷击事件发生。 （二）第二季度。做好地县两级人影装备弹药物联网监控系统和人影综合处理分析与指挥系统本地化应用工作。做好人影弹药运输存储分发工作，确保5月底前将弹药安全运送到各作业点。与各作业点炮长签订安全责任书，明确职责，压实责任，确保工作顺利推进。6月初在普兰、噶尔两县各作业点进点前组织开展人影作业人员安全培训。

（三）第三季度。做好汛期人影安全管理工作，定期或不定期对作业点进行安全检查。地县人工影响天气办公室和各作业点要严密监视天气变化，积极开展防雹增雨作业，确保农作物不受冰雹灾害。地区人工影响天气工作领导小组办公室要以狮泉河水电站水库增雨蓄水（发电）为重点，根据需求开展人工种草区、防沙治沙区增雨工作。

（四）第四季度。做好各作业点非汛期安全管理工作，对各作业点弹药进行清查、统计，剩余弹药由地区人工影响天气工作领导小组办公室统一回收储存。做好作业人员年终考核、评比和效果评估工作。

五、保障措施

（一）加强组织领导。根据深化党政机构改革和部门职能调整实际，及时调整地县人影领导小组成员，进一步明确职责和任务，确保工作有人管、有人抓、有人落实。健全完善“政府领导、部门联动、军地联合”的人影工作机制，各级政府要把人影工作纳入重要议事日程，纳入政府公共服务体系建设范畴，地县人工影响天气领导小组要继续强化本辖区内人影工作的统筹协调、指挥力度，有效组织、协调和指导本辖区内人影工作，及时解决人影工作中遇到的重点难点问题。

（二）加强经费保障。要完善投入机制，加大对人影工作的财政支持力度，多渠道、多途径解决人影所需经费。做好人影作业、装备升级改造、标准化作业点建设的经费保障。

（三）加强信息发布和材料上报。加大信息发布力度，通过各类新闻媒介及时发布人影作业公告，强化宣传力度，将作业公告制度落到实处。做好地区人影信息系统数据采集、信息汇总、总结上报等工作。
