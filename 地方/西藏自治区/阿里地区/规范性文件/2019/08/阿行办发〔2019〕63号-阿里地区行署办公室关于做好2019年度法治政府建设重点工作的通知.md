# 阿里地区行署办公室关于做好2019年度法治政府建设重点工作的通知

文章来源： 发布日期：2019-08-30 浏览：

各县人民政府，行署各局、委、办、处：

2019年阿里地区法治政府建设总体要求是：深入学习贯彻习近平总书记全面依法治国新理念新思想新战略，认真学习贯彻习近平总书记在中央全面依法治国委员会第一次、第二次会议上的重要讲话精神，贯彻落实自治区党委全面依法治藏委员会会议精神、阿里地委法治建设工作领导小组会议精神。充分认识加强法治政府建设是依法治地的有机组成部分，准确把握法治政府建设重点工作任务，加大法治政府建设力度，全面落实《中共西藏自治区委员会 西藏自治区人民政府关于贯彻落实<法治政府实施纲要（2015—2020年）>的实施意见》（藏党发〔2016〕18号）和《西藏自治区人民政府办公厅关于做好2019年度法治政府建设重点工作的通知》（藏政办发〔2019〕31号）精神，结合阿里实际，经行署研究同意，提出《阿里地区2019年度法治政府建设重点工作任务分解表》，现就有关要求通知如下。

一、切实强化第一责任人职责

法治政府建设是今后推进全面依法治地的重要内容，各县人民政府及其部门主要负责人是法治政府建设第一责任人，要切实增强推动法治政府建设的紧迫感、使命感和责任感，坚决贯彻落实党中央、国务院，自治区党委、政府和阿里地委、行署关于法治政府建设的重大决策部署。要认真履行法治政府建设重要组织者、推动者和实践者的职责，做到重要工作部署、重大决策亲自过问、重点环节亲自协调、重要任务亲自督办，确保年度重点工作全面完成。

二、大力加强部门协调

2019年度各县人民政府和地区有关部门需要完成的重点工作共37项、可检验成果形式55项。各牵头单位要落实主体责任，切实做到守土有责、守土尽责，制定具体工作计划，细化工作方案和具体措施，明确具体承办部门和责任人，层层压实责任，加快工作进度，保证工作质量，加强同参加单位的沟通协调，主动争取参加单位的配合支持。各参加单位要增强大局意识，明确具体承办部门和责任人，积极配合牵头单位，主动承担并认真完成职责范围内的工作，努力形成人人有责、人人负责、人人尽责的工作格局，并将实施方案于8月25日前报送至阿里地区法治政府建设工作领导小组办公室（地区司法处四楼法治管理科）。

三、扎实开展督导考核

阿里地区法治政府建设领导小组办公室会同行署督查室，对各县各部门重点工作推动落实情况开展检查和专项督查，及时通报督查情况，提出整改意见，认真制定法治政府建设考核办法和量化指标，2020年第一季度对各县各部门法治政府建设工作情况进行考核，考核结果向社会公布，充分发挥考核对法治政府建设工作的重要推动作用。同时，在督导检查考核上，杜绝形式主义和官僚主义，切实贯彻执行为基层减负各项举措，严格实行督查检查考核年度计划和审批报备制度，力戒重痕迹、轻实绩，做到重实绩、求实效。
