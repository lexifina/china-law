# 抚顺市人民政府办公厅关于落实《抚顺市国民经济和社会发展第十三个五年规划纲要》主要目标和任务工作分工的通知

抚顺市人民政府办公厅关于落实《抚顺市国民经济和社会发展第十三个五年规划纲要》

主要目标和任务工作分工的通知

抚政办发〔2017〕7号

各县、区人民政府，沈抚新城、石化新城管委会，市政府各部门、各直属单位：

《抚顺市国民经济和社会发展第十三个五年规划纲要》（以下简称《纲要》）经市第十五届人民代表大会第五次会议审查批准。《纲要》明确提出了我市“十三五”时期国民经济和社会发展的目标任务和工作重点，是未来五年我市经济和社会发展的宏伟蓝图和全市人民共同的行动纲领，是各级政府履行经济调节、市场监督、社会管理和公共服务职责的重要依据。为切实做好《纲要》实施工作，市政府决定按照职责分工将《纲要》提出的主要目标和任务分解落实到各地区、各部门。现就有关事项通知如下：

一、分工原则

（一）正确处理政府与市场的关系。使市场在资源配置中发挥决定性作用和更好发挥政府作用，重点明确政府责任，对需要政府履行职责的目标和任务进行分解，对依靠市场主体自主行为实现的目标和任务不作分解。

（二）合理划分各级政府职责。在统筹考虑各级政府事权及配置公共资源能力的基础上，重点将主要目标和任务分解落实到市有关部门，部分目标和任务同时分解落实到有关县区政府。

（三）科学把握全面和重点关系。在全面落实经济社会发展各领域任务的同时，重点分解政府完成的各项指标、公共服务以及完善体制机制、制定政策举措、健全法律法规、编制实施规划等方面的任务。

（三）增强创新驱动，加快形成经济发展新方式。

1. 完善企业创新机制。

强化企业创新主体地位，实施提升企业技术创新能力行动计划和创新型中小企业成长扶持计划，加快构建以企业为主体、市场为导向、产学研结合的技术创新体系。鼓励大型国有企业和民营企业加大研发投入，充分发挥抚顺石化、抚矿集团、抚顺特钢等大型企业在科技创新过程的引领作用，发挥罕王微电子、中国煤炭研究院沈阳分院、隆基电磁等新兴企业的科技创新示范作用，带动新材料、精细化工、装备制造、电子信息等相关产业集聚创新。（牵头单位：市科技局，配合单位：市工业和信息化委等）

实施培育“三名”行动计划，培育一批知名企业、知名品牌和知名企业家，打造一批拥有自主知识产权、市场竞争力强的优势龙头企业来支撑抚顺制造业。（牵头单位：市工业和信息化委，配合单位：市科技局等）

加快工业化与信息化融合，加大用信息技术改造传统产业的支持力度，促进信息技术在研发、设计、生产、销售全流程应用，提高基础装备的数字化、智能化水平。（牵头单位：市工业和信息化委）

2. 增强创新驱动能力。

争取国家重大科技基础设施、重要科研机构和重大创新能力项目落户抚顺，加快推进重大创新平台建设，支持石化、煤炭、特钢等科研院所在重点学科和关键产业技术领域的研发，加快促进科技成果转化生产力。健全创新资源配置机制，开展创新资源集聚行动，促进全社会创新资源的高效配置和综合集成，加大政府创新投入，完善政府统筹使用、监督管理和绩效评估制度，建立创新要素自由流动的市场调节机制，促进各类创新资源优化配置。（牵头单位：市科技局）

培育科技创新消费热点，把培育发展信息消费摆在突出重要位置，结合“宽带中国”、“三网融合”、“信息惠民”等重大工程，制定相应规划与扶持措施，不断壮大信息消费市场。（牵头单位：市工业和信息化委，配合单位：市科技局、市规划局等）

3. 建设创新型人才队伍。

加强引才引智，深入实施并不断完善引进领军人才和创新型科研团队计划，构建多层次的人才培养体系，培养经济社会发展重点领域的急需紧缺专门人才，突出培养创新型科技人才和高技能人才。强化育才育智，鼓励和引导高校与企业建立联合培养人才机制，重点加强研究团队和优势学科高级科技人才培养。加快完善留住人才政策，营造良好的人才发展环境，充分发挥全市科技人才的创新创业引领作用。建立健全多层次的培训体系，加强国内外人才交流，不断完善人才服务和管理体系。加强人才服务与管理，发挥市场在人力资源配置中的基础性作用，构建统一、开放、有序的人力资源市场。积极发展人力资源服务业，建立科学的人才评价发现机制，完善跨区域的人才交流合作服务平台，健全人才信息管理标准和人才资源动态预警机制。（牵头单位：市人力资源社会保障局，配合单位：市教育局、市科技局等）

4. 营造良好的创新环境。

建立健全创业风险投资机制，设立抚顺市创业投资引导基金和国家地方联合新兴产业创业投资基金，开展科技保险试点，建设创业投融资担保平台，引导和鼓励创业投资投向重点创新领域。（牵头单位：市发展改革委，配合单位：市政府金融办、市科技局等）

积极发展知识产权质押、租赁融资，大力推动创新型企业上市融资。（牵头单位：市政府金融办，配合单位：市发展改革委、市科技局、市工业和信息化委等）

实施知识产权和技术标准战略，加强知识产权的创造、运用、保护和管理，强化省市知识产权战略合作，建设专利信息服务中心和知识产权公共信息综合服务平台，发展知识产权优势企业和示范企业。实施自主知识产权技术标准培植工程，优先采用和推广具有自主知识产权的技术标准。加强创新文化建设和传播，积极营造“鼓励创新、激励探索、包容个性、宽容失败”的创新文化氛围。完善创新驱动政策体系，推进形成尊重人才的社会环境和平等公开、竞争择优的制度环境，增强社会公共创新创业意识。加强科普基础设施建设，开展多种形式的科普宣传工作。（牵头单位：市科技局，配合单位：市委宣传部、市文化广电局、市人力资源社会保障局、市科协等）

（四）深化改革开放，激发市场活力和内生动力。

1. 加快政府职能转变。

全部取消非行政许可审批事项，积极推进行政权力行使依据、过程、结果向社会公开。（牵头单位：市编委办、市政府办公厅，配合单位：市政府相关部门、各县区政府等）

整合政府资源，理顺部门职能关系，完善政府绩效考评指标体系和绩效考核评价体系。（牵头单位：市目标绩效办）

完善资源节约、环境、技术、安全等市场准入标准，建立健全防范和化解产能过剩长效机制。（牵头单位：市工业和信息化委）

推广政府和社会资本合作（PPP）模式。扩大国有资本经营预算编制范围，推进跨年度预算平衡机制建设。（牵头单位：市财政局，配合单位：市发展改革委、市国资委等）

逐步建立地方各级政府举债限额管理制度和审批制度、偿债准备金制度，分类管理政府性债务，防范系统性财政风险。推进增值税改革，逐步扩大“营改增”试点范围。（牵头单位：市财政局、各县区政府，配合单位：市国税局、市地税局等）

加快出台降低企业成本政策，简化企业行政审批项目，减轻企业负担。（牵头单位：市编委办，配合单位：市发展改革委、市财政局、市行政审批局、各县区政府等）

2. 深化国资国企改革。

坚持国有企业分类改革原则，对公益类企业实施公司制改革，对竞争类企业实施市场化改革，对空壳企业实施关闭破产。鼓励公益性企业发展混合所有制，支持地方企业与央企采取多种合作方式，将科技成果转化为生产力，实现共赢。充分运用国家政策，妥善处理国有企业历史遗留问题，逐步解决厂办大集体养老保险接续等问题。全力完成在抚央企“三供一业”移交改造任务。以管资本为主健全完善国资监管体系，依法履行出资人职责。（牵头单位：市国资委，配合单位：市人力资源社会保障局、市工业和信息化委、市科技局、各县区政府等）

3. 支持非公有制经济发展。

进一步消除制约非公经济发展的制度性障碍，鼓励非公有企业依法进入基础设施、市政公用事业、金融服务、社会事业、保障性住房建设、文化、旅游、现代物流等领域，支持非公有制企业建立现代企业制度，支持非国有资本参与国有企业改革，加快推进融资平台、公共技术服务平台、人才培训平台和信息共享平台建设，为激发非公有制经济活力创造条件。认真贯彻《抚顺市促进中小企业发展条例》，切实改善民营经济发展环境，加快民营经济企业产业结构调整，促进产品升级换代，提升盈利水平。厚植民营企业发展土壤，建立健全激励和约束机制，营造企业家成长的良好环境。（牵头单位：市工业和信息化委，配合单位：市政府金融办、市住房城乡建设委、市文化广电局、市旅游委、市服务业委等）

4. 深入社会事业改革。

深化教育领域综合改革，推进人才培养模式、教育发展方式、办学体制和管理体制改革，推进县（区）域内义务教育学校校长教师交流轮岗工作，推进教育信息化建设，支持和规范民办教育发展，鼓励社会力量和民间资本提供多样化教育服务。（牵头单位：市教育局，配合单位：各县区政府等）

完善覆盖城乡的公共就业创业服务体系，建立健全劳动争议专业化预防调解机制，健全困难群体就业援助制度，完善各项养老保险制度衔接机制。（牵头单位：市人力资源社会保障局，配合单位：各县区政府等）

深化公立医院综合改革，实施城乡居民重特大疾病医疗保险制度，改革医保支付方式，扩大基本药物制度实施范围。（牵头单位：市卫生计生委，配合单位：市人力资源社会保障局、各县区政府等）

完善医疗纠纷第三方调解工作。（牵头单位：市司法局，配合单位：各县区政府等）

3. 增强县域经济发展活力。

坚持一县一业为主、多业并举发展思路，坚持县区为主、统筹规划、规模经营、稳步推进原则，稳定农村土地承包关系，完善土地所有权、承包权、经营权分置办法，依法推进土地经营权有序流转，构建培育新型农业经营主体的政策体系。以行政推动、政策扶持、龙头带动、科技支撑为手段，促进农村经济、农业结构的优化调整。（牵头单位：市发展改革委，配合单位：各县政府等）

4. 建设社会主义新农村。

统筹推进农业产业化、农村工业化、新型城镇化、三产多元化、县域生态化的“五化联动”，以县为单元，按照产业、新农村、土地、公共服务和生态规划五规合一的要求，在评估县域村镇体系规划的基础上，修订完善新农村规划。（牵头单位：市规划局，配合单位：各县区政府等）

以产业发展为基础，科学确定村庄布局和规模，突出建设特色，打造农民幸福家园和宜居乡村，积极推进少数民族特色村镇建设。（牵头单位：市民委，配合单位：市发展改革委、市文化广电局、市财政局、市农委、各县区政府等）

把城中村、城郊村纳入城市统一规划、建设和管理，加快推进城市化改造。开展农村人居环境综合整治，加强村庄基础设施和公共服务设施建设，推进垃圾分类处理、畜禽粪便集中处理，提升污水处理技术水平，改善农村能源结构，逐步全面实现村路硬化、村庄亮化、村容美化、村屯绿化，加快宜居乡村建设。（牵头单位：市住房城乡建设委，配合单位：市发展改革委、市农委、市财政局、市环保局、各县区政府等）

（十二）加强依法治市，推进平安抚顺和谐发展。

1. 加快推进民主法制建设。

扎实推进依法治市，深化司法体制机制改革，加强政法队伍建设，全面提高依法行政水平。推进公共法律服务体系建设，提高全社会的法治理念和法律意识。（牵头单位：市司法局，配合单位：各县区政府等）

全面贯彻党的民族、宗教政策，加强民族团结，依法管理宗教事务。（牵头单位：市民委，配合单位：市民族宗教工作领导小组成员单位、各县区政府等）

发展基层民主，推进政务公开等各类信息、事务的公开，保证人民群众依法行使各项民主权利。（牵头单位：市民政局，配合单位：各县区政府等）

2. 加强社会治安综合治理。

推进立体化社会治安防控体系建设，建设完善覆盖城乡的社会治安动态视频监控网络，构建城区动态专业化巡逻防控网，根据需要新增、更新、补充治安巡逻直升机、快艇、车辆，加强城乡社区警务、群防群治等基础建设，进一步拓展社会治安防控工作覆盖面。（牵头单位：市公安局）

加强社会治安综合治理，积极开展社区矫正，强化对特殊人群的帮教、安置和管理工作。（牵头单位：市司法局）

完善政法保障机制，加强公安派出所、司法所、人民法庭、综治维稳中心建设。强化国家安全人民防线、防恐反恐、处置突发事件和反邪教斗争。（牵头单位：市政法委）

进一步做好双拥工作，积极争创第九轮双拥模范城。（牵头单位：市民政局，配合单位：市双拥工作领导小组成员单位、各县区政府等）

逐步将信访纳入法治化轨道，注重从源头上解决信访问题，保障群众合法权益。（牵头单位：市信访局）

3. 提高公共安全预防和监管能力。

完善安全监管监察和安全生产技术支撑体系，加强监管队伍建设，提高安全生产监管能力。建立重点行业领域专项治理和隐患排查治理机制，防止重特大事故发生。加强职业危害监管，保障职工健康。到2020年，亿元国内生产总值生产安全事故死亡率下降36%以上。（牵头单位：市安全生产监管局）

强化综合交通安全管理，减少交通事故。（牵头单位：市公安局）

全面加强消防、防洪、防震等设施应急能力和救援队伍建设，健全人防指挥体系、强化防护体系，完善地质、地震、气象等自然灾害的监测和预警体系，提高灾害综合预警预报水平。加强市民风险防范和自救互救教育，充分发挥公民、社会力量在应急管理中的重要作用。（牵头单位：市政府应急办，配合单位：市消防局、市人防办、市国土资源局、市气象局等）
