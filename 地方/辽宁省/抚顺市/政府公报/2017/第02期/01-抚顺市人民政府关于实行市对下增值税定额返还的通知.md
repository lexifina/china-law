# 抚顺市人民政府关于实行市对下增值税定额返还的通知

抚顺市人民政府关于实行

市对下增值税定额返还的通知

抚政发〔2017〕6号

各县、区人民政府，经济开发区管委会，市政府各部门、各直属单位：

为贯彻落实《国务院关于实行中央对地方增值税定额返还的通知》（国发〔2016〕71号），以及《辽宁省人民政府关于实行省对下增值税定额返还的通知》（辽政发〔2017〕2号） 精神，进一步理顺市对下财政管理体制，落实全面推开营改增试点后完善市、县（区）财政管理体制过渡方案。市政府决定， 从2016年起，调整市对下原体制增值税返还办法，由1994 年实行分税制财政体制改革时确定的增值税返还，改为以 2015年为基数实行定额返还，对增值税增长或下降县（区）不再实行增量返还或扣款。同时，取消市对县提高增值税返还系数政策。返还基数的具体数额，由市财政局核定。

抚顺市人民政府

2017年3月11日
