# 抚顺市人民政府关于废止、宣布失效和修改部分市政府规范性文件的决定

抚顺市人民政府关于废止、宣布失效

和修改部分市政府规范性文件的决定

抚政发〔2017〕4号

各县、区人民政府，沈抚新城、石化新城管委会，市政府各部门、各直属单位：

经市政府第53次常务会议审议通过，现决定：

一、废止《抚顺市人民政府办公厅关于印发大伙房水源保护区有机农业示范基地建设监督管理办法的通知》（抚政办发〔2014〕36号）。

二、宣布《抚顺市人民政府办公厅关于印发调整后抚顺市地表水环境功能区划的通知》（抚政办发〔2011〕95号）、《抚顺市人民政府办公厅关于提高城乡居民最低生活保障和农村五保对象供养标准的通知》（抚政办发〔2015〕9号）、《抚顺市人民政府办公厅关于印发抚顺市榆林采沉区住宅房屋脱险搬迁安置实施办法的通知》（抚政办发〔2015〕39号）3件市政府规范性文件失效。

三、对《抚顺市国有土地上房屋征收与补偿实施办法》（抚政办发〔2015〕19号）部分条款予以修改。

删除第二十条、第二十一条第一项。

第二十一条第二项修改为“房屋征收主管部门将征收范围、评估内容等信息在公众媒体发布，公开邀请评估机构，接受邀请的评估单位名单在征收范围内和公众媒体上公示；”

此外，条文顺序作相应调整。

本决定自公布之日起施行。

抚顺市人民政府

2017年3月5日
