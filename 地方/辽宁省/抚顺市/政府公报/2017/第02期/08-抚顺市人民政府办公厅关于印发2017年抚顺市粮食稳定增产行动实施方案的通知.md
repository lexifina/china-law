# 抚顺市人民政府办公厅关于印发2017年抚顺市粮食稳定增产行动实施方案的通知

抚顺市人民政府办公厅

关于印发2017年抚顺市

粮食稳定增产行动实施方案的通知

抚政办发〔2017〕15号

各县、区人民政府，经济开发区管委会，市政府各部门、各直属单位：

经市政府同意，现将市农委《2016年抚顺市粮食稳定增产行动实施方案》转发给你们，认真组织实施。

抚顺市人民政府办公厅

2017年4月17日

2017年抚顺市

粮食稳定增产行动实施方案

为全面贯彻落实省、市农村工作会议和农业工作会议精神，以推进农业供给侧结构性改革为主线，确保我市粮食生产持续稳定发展，2017年，在全市范围内继续深入开展粮食稳定增产行动，特制定本实施方案。

一、总体要求

认真落实“中央1号文件”精神，以努力践行“五大发展理念”为引领，以推进农业供给侧结构性改革为主线，不断增强粮食生产能力，深入推进种植结构调整，按照依靠科技、主攻单产的思路，以数量、质量、效益并重为原则，促进粮食稳定增产。

二、工作目标

在不发生特大自然灾害的情况下，粮食总产稳定在50万吨以上。

三、主要任务

（一）扎实做好备耕工作。全市春耕前备实玉米杂交种1659.6吨、水稻种527.9吨、化肥5.97万吨、农药477.9吨、农膜718吨，检修农机具15万台套。

（二）大力推进农业机械化。巩固水稻生产全程机械化作业，实现水稻育秧和机插秧的技术配套。全面开展玉米全程机械化作业。年内综合机械化水平达到78.4%以上。

（三）提升农作物病虫害统防统治水平。推广绿色防控面积20万亩次，力争使全市因病虫害造成的损失降低到5%以下，确保丰收。

（四）积极申报粮油绿色高产高效创建县。推进新宾县水稻绿色高产高效创建县申报工作，认真对照入围条件，严格把关，认真审核，力争新宾县申报2017年水稻绿色高产高效创建县成功。

（五）做好测土配方施肥、耕地保护及质量提升工作。大力推行主要作物控减施肥与手机信息化服务技术。通过项目集成实施，培肥土壤，科学合理施肥，提高肥料利用率，减少农业面源污染。

（六）加大大田作物农业保险度。投保作物包括玉米、水稻、大豆、花生，保障农户在突发性气象灾害后及时得到经济补偿。计划开展大田作物农业保险105.7万亩。

（七）认真推进种植结构调整。完成全市2.1万亩玉米播种面积调减任务，发展食用菌、山野菜、中药材、花卉、杂粮等作物，其中：清原县0.7万亩、新宾县0.7万亩、抚顺县0.4万亩、新抚区0.1万亩、开发区0.2万亩。

四、工作措施

（一）加强组织领导。抚顺市推进粮食生产工作领导小组要做好全市粮食生产的组织和协调工作。各有关部门要各尽其责，密切配合，共同做好粮食稳定增产各项工作。各县（区）要加大对粮食和农业生产的资金投入，成立粮食稳定增产行动推进机构，层层分解任务，落实责任，强化监督检查，确保粮食稳定增产的各项措施落到实处。

（二）加快农业科技推广应用。以市政府与省农科院科技共建为平台，充分发挥粮食专家团的作用，结合粮油绿色高产高效创建、农业综合机械化，从育苗、田间管理到秋收实行全程服务。推广密植型玉米品种、宽窄行种植技术、机械化免耕精量播种技术、水稻旱育壮秧技术，提升农业科技成果覆盖率。

（三）进一步提高防灾减灾能力。加强灾害性天气的预测预报，建立气象、农业部门重大农业气象灾害会商机制，强化对干旱、渍涝、低温、霜冻等灾害的监测预警，为农业生产提供及时、准确的气象监测、预警与影响评估服务。加强人工影响天气安全管理，及时开展人工增雨作业，最大限度减少灾害损失。一旦发生严重灾情，要立即启动应急预案，及时派出工作督导组和技术指导组，帮助农民搞好灾后田间管理，最大限度减轻灾害影响和损失。针对全市主要农作物病虫害呈中等偏重发生，局部地区重发生的趋势，强化联防联控、统防统治、群防群治，确保不暴发重大病虫灾害。

（四）提高广大农民种粮积极性。全面落实各项惠农政策，将耕地地力保护补贴、农机具购置补贴、大豆目标价格补贴、种粮及粮食加工合作社补贴等国家、省、市惠农政策落到实处，新增补贴向粮食主产区，种植大户、农民专业合作社、家庭农场等新型农业经营主体倾斜。

（五）强化考核与激励。市政府将种植结构调整面积，粮食产量等指标纳入对各县（区）政府的绩效考核，各有关部门要按照职责分工，制定具体工作方案，落实考核措施，充分调动地方政府重农抓粮、农技人员科技兴粮、农民务农种粮的积极性。对考核排名靠前的县（区）给予奖励，并在年度资金安排上给予照顾。

（六）加大宣传力度。要充分利用广播、电视、报纸、网络等媒体，大力宣传粮食生产和抗灾救灾的好经验、好做法、好典型，营造重农抓粮的良好氛围。
