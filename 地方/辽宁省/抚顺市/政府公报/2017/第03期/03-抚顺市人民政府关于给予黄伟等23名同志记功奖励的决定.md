# 抚顺市人民政府关于给予黄伟等23名同志记功奖励的决定

抚顺市人民政府关于给予黄伟等

23名同志记功奖励的决定

抚政发〔2017〕11号

各县、区人民政府，沈抚新城、石化新城管委会，市政府各部门、各直属单位：

2016年4月21日，新宾县苇子峪镇富家村发生一起持猎枪杀人案件，经省公安厅、我市及沈阳、本溪、锦州、辽阳、铁岭等市公安机关连续5昼夜的奋战，于4月26日13时将犯罪嫌疑人抓获，缴获单筒猎枪1支，子弹5发。

在案件侦破工作中，抚顺市公安干警昼夜奋战、不惧危险、敢于担当，为案件成功告破做出了突出贡献。为表彰先进、弘扬正气、鼓舞斗志，市政府决定为在案件侦破中做出突出贡献的市公安局新抚分局局长黄伟等4名同志记二等功，为新宾县公安局政委张忠华等7名同志记三等功，给予新宾县公安局副局长孟繁龙等12名同志嘉奖。

希望受到表彰的同志珍惜荣誉，谦虚谨慎，戒骄戒躁，再立新功。希望全市公安机关及广大公安干警向受到表彰的同志学习，进一步坚定理想信念，振奋精神，锐意进取，扎实工作，全面加强社会治安防范，为我市经济建设和社会发展保驾护航，为进一步提高人民群众安全指数、确保社会治安大局稳定做出新的贡献。

抚顺市人民政府

2017年5月13日
