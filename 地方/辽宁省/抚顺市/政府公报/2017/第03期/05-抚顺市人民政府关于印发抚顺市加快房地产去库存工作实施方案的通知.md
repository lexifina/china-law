# 抚顺市人民政府关于印发抚顺市加快房地产去库存工作实施方案的通知

抚顺市人民政府关于印发抚顺市

加快房地产去库存工作实施方案的通知

抚政发〔2017〕13号

各县、区人民政府，沈抚新城、石化新城管委会，市政府各部门，各直属单位：

现将《抚顺市加快房地产去库存工作实施方案》印发给你们，请结合实际，认真组织实施。

抚顺市人民政府

2017年5月31日

抚顺市加快房地产去库存工作实施方案

为贯彻落实《辽宁省人民政府关于印发辽宁省加快房地产去库存工作方案的通知》（辽政发〔2016〕83号）精神，深入推进供给侧结构性改革，有效化解房地产库存，结合我市实际情况，制定本实施方案。

一、指导思想

全面贯彻习近平总书记在辽宁代表团审议时发表的重要讲话，贯彻新发展理念，深化“四个着力”，落实“三个推进”，按照市第十二次党代会和全市经济工作会议精神，牢固树立创新、协调、绿色、开放、共享的发展理念，完善居民住房合理消费相关政策，适应住房刚性需求和改善性需求，分类调控、因城施策，努力完成化解房地产库存任务，促进房地产市场平稳健康发展。

二、工作目标

（一）短期目标：全面完成2017年省政府确定的商品房销售指标。

2017年全市实现商品房销售面积同比增长12%。

（二）中长期目标：用3至5年时间，基本完成房地产去库存任务。

——通过户籍和住房制度改革、土地供应总量控制、发挥市场功能等措施，将房地产库存去化周期调整到合理水平。

——房地产库存去化周期进一步缩短，争取在2020年末，逐步将住宅类商品房去化周期，控制在12至18个月以内。

——重点区域房地产库存得到有效化解，商品房增量控制在合理规模，基本建立满足多层次需求的住房供应体系，促进房地产市场供求基本平衡、产品结构基本合理。

三、重点任务

（一）全面实行棚改安置货币化和公租房保障货币化。不再统一新建棚改安置用房和公租房，打通货币化、去库存转换通道。采取棚改居民利用新型货币补偿自主购房、动员开发企业打折销售、政府团购社会房源等方式，推行棚改货币化安置，做好2627户棚改拆迁安置和消化存量商品住房的衔接，消化库存商品住房。

积极推行公租房保障货币化。支持公租房保障对象通过市场租房，对符合条件的家庭给予租赁补贴。将符合当地公租房准入条件的城镇中等偏下收入住房困难家庭、城镇稳定就业的外来务工人员、新就业大学生纳入公租房保障范围。同时要结合楼宇经济发展、创新创业经济的发展，利用政府团购的部分房源建立社会公用住房机制，为引进企业和人才创造有力条件。（责任单位：各县、区政府，开发区管委会，市住房城乡建设委、市财政局按职责分工负责）

（二）鼓励农民进城购房置业，推进存量农业转移人口市民化。加快推进户籍制度改革，鼓励有能力在城镇稳定就业和生活的农业转移人口进城购房落户，推动居住证持有人享有与当地户籍同等的住房保障权利。各县区要制定农民进城购房优惠政策，对农业转移人口进城购买首套商品住房的给予适当补贴，鼓励房地产企业、商业银行给予购房折扣和贷款优惠，发挥好“农民安家贷”的支持作用。保障农民在农村的原有权益，消除其后顾之忧。（责任单位：各县、区政府，开发区管委会，市公安局、市教育局、市住房城乡建设委、市政府金融办按职责分工负责）

（三）加快培育和发展住房租赁市场。培育住房租赁市场经营主体，增加租赁住房有效供应，推动住房租赁市场健康发展。鼓励和引导房地产开发企业、房地产中介机构、物业服务企业等各类机构成立住房租赁企业，通过租赁、购买商品住房等方式多渠道筹集房源，促进库存商品房转化为租赁住房。初步建立起购租并举的住房制度，积极搭建租赁企业及出租房屋信息平台，免费提供租赁房源信息及需求信息等服务。（责任单位：各县、区政府，开发区管委会，市住房城乡建设委按职责分工负责）

（四）支持居民自住和改善性住房需求。加大棚户区改造力度，积极推进城市危房和老旧小区改造。鼓励高等院校、科研院所通过发放住房补贴或购买、租赁商品房等方式，解决引进人才住房问题。落实新就业大学生购买普通商品住房各种支持政策。鼓励旧房交易及以旧换新，组织开展多种类型的房交会，出台购房优惠政策，促进商品房销售。落实国家、省出台的居民房地产交易环节税收优惠政策，规范银行涉房地产金融服务流程，降低服务收费标准。（责任单位：各县区政府，开发区管委会，市住房城乡建设委、市财政局、市地税局、市政府金融办按职责分工负责）

（五）加大住房公积金支持力度。扩大住房公积金覆盖面，进一步推进非公企业建立住房公积金制度。落实住房公积金差别化贷款政策，合理放宽公积金使用条件，减少审批环节，缩短办理贷款周期。推进住房公积金异地个人住房贷款，将住房公积金的使用方向调整到主要用于贷款购房，提高住房公积金购房贷款和提取使用率。缴存职工的直系亲属可以作为共同还款人，相互使用住房公积金用于购房。把符合条件的农民工和个体工商户纳入住房公积金覆盖范围，支持农民工贷款购房。强化住房公积金风险防范和规范运行，确保安全管理和有效使用。（责任单位：各县、区政府，开发区管委会，市住房公积金管理中心按职责分工负责）

（六）实行差异化供地政策。要依据全市及各县、区住宅类商品房库存去化周期，控制房地产开发用地供给，严格控制商品住宅新增供地。库存严重的县区要暂停供应房地产开发用地；已供应、未开发的房地产开发用地可申请调整商住比例。引导房地产企业将未开发用地转为国家支持的新兴产业项目建设用地。科学编制年度房地产用地供应计划，合理调控土地供应规模、布局和节奏。（责任单位：各县、区政府，开发区管委会，市国土资源局、市规划局、市住房城乡建设委按职责分工负责）

（七）完善交通和公共服务设施。加快推进基础设施、公共服务配套设施和交通网络建设。在库存商品房规模较大、库存项目相对集中的区域，加快建设交通、学校、医院、商业等配套服务设施，提高交通可达性和生活便利性。通过特许经营、投资补助、政府购买服务等多种方式，吸引社会资本参与投资、建设和运营城市基础设施项目。（责任单位：各县、区政府，开发区管委会，市公安局、市交通局、市发展改革委、市教育局、市住房城乡建设委、市卫生计生委）

（八）优化住房供应结构，严控住房库存增量。严格执行预售管理的有关规定，科学调节商品住房预售许可发放，在土地供应、新开工、施工、预售四个环节，加大房地产库存管控力度。根据市场需求，适当提供部分精准定位的产品，有效契合购房者实际需求。对拿地未开工项目、已开工未售出项目、已竣工未售出项目，可以适当调整规划用途、商业配套比例、户型结构、车位配比等规划设计条件。全面实行住宅工程质量分户验收，提高宜居环境建设水平。支持房地产开发企业将符合条件的库存商品房发展楼宇经济，并享受有关优惠政策。（责任单位：各县、区政府，开发区管委会，市规划局、市住房城乡建设委、市国土资源局按职责分工负责）

（九）支持房地产企业健康发展。鼓励开发企业向规模化、集约化、专业化发展。严格执行涉房税收优惠政策。全面清理整顿不合理审批和收费，推动房地产企业“降成本”，减轻企业负担。积极引导房地产开发企业规范经营，依法查处企业不正当经营行为。依法加强市场监管，规范房地产开发和中介市场秩序。（责任单位：各县、区政府，开发区管委会，市工商局，市住房城乡建设委、市地税局等按职责分工负责）

（十）加强房地产市场监测分析。切实做好房地产市场的监测分析工作，全面推行新建商品房、二手房合同网签备案。建立健全房地产市场运行数据的统计与共享机制，提高统计数据的准确性和及时性。要对全地区房地产市场交易情况和去库存情况实行月调度，定期通报各县、区商品房销售和库存状况。（责任单位：各县、区政府、开发区管委会，市住房城乡建设委、市统计局等按职责分工负责）

（十一）加强房地产市场的舆论引导。加强对房地产市场的宣传引导，稳定市场预期。充分发挥各类新闻媒体的作用，准确宣传房地产去库存政策，客观报道房地产去库存进展情况，营造有利于化解房地产库存的良好氛围。（责任单位：各县、区政府、开发区管委会，市委宣传部、市住房城乡建设委等按职责分工负责）

四、保障措施

（一）加强领导，落实责任。市政府成立由分管副市长任组长，分管副秘书长、市住房城乡建设委主任任副组长，各县、区政府，开发区管委会，相关市直部门分管领导为成员的抚顺市加快房地产去库存工作领导小组，负责全市房地产去库存工作的组织领导，协调各地区、各部门的衔接工作。领导小组办公室设在市住房城乡建设委，负责领导小组日常综合统筹工作，办公室主任由市住房城乡建设委主任兼任。各县、区政府，开发区管委会承担本地区去库存主体责任，主要领导是第一责任人。各县区要加强领导、落实责任、明确时限、落实到位，要在政策框架内积极探索，研究出台符合本地实际的有效去库存措施，制定房地产去库存的工作举措和方案，明确去库存、稳市场工作的任务书、路线图、时间表和责任人。各相关责任部门要围绕各自工作责任制定具体措施，明确任务时限和责任人。

（二）分类调控，因城施策。住宅类商品房去化周期超过18个月的县区，要明确工作目标，严控商品房增量，消化商品房存量；住宅类商品房去化周期超过30个月的县区，要明确去库存的时间表和具体措施，暂停供应房地产开发用地；非住宅类商品房去化周期较长的县区，要适当调整规划用途、商业配套比例等规划设计条件。

（三）实事求是，应统尽统。市、县区两级住房城乡建设、统计主管部门要指导开发企业坚持实事求是的原则，开展房地产市场数据统计工作，切实加强工作配合，建立定期协调机制，对“一套表”联网直报平台入库的房地产企业进行梳理，做到应入库的企业和项目全部入库，确保有关数据及时、准确地反映房地产市场真实运行情况。要切实做好房地产市场的监测分析，全面推行新建商品房、二手房合同网签备案。对未能按规定使用网签备案系统，未能按计划实现市、县区联网工作、未能按期报送“交易日报”的县区和单位，要进行督办和通报。

（四）督查督办，考核问责。各县、区政府，开发区管委会，市直有关部门要对上级房地产去库存有关文件贯彻落实情况逐条对照梳理，逐条分解落实。对尚未落实到位的，要尽快采取措施，明确时限，确保落实到位。市政府将加强对房地产去库存工作的督查督办和考核问责，将政策落实情况作为市政府对各县区及市直相关部门绩效考核的重要内容，对工作迟缓、落实不力的县区和部门进行约谈、问责。
