# 抚顺市人民政府办公厅关于加强人民群众来信和网上留言办理工作的意见

抚顺市人民政府办公厅关于加强

人民群众来信和网上留言办理工作的意见

抚政办发〔2017〕17号

各县、区人民政府，沈抚新城、石化新城管委会，市政府各部门、各直属单位：

人民群众以信函和网络留言的形式，向政府反映问题、政策咨询、建言献策等，是人民群众监督政府工作的有效方式，是政府及其工作部门了解民意、联系群众、优化营商环境的重要渠道，也是政府办公部门服务群众、化解矛盾纠纷、维护社会稳定的重要内容。根据《中共辽宁省委办公厅关于进一步加强〈人民网〉网民留言办理工作的意见》（厅秘发〔2015〕25号）、《辽宁省人民政府办公厅关于进一步加强和改进〈省长信箱〉人民群众来信和〈人民网〉网民留言办理工作的意见》（辽政办发〔2016〕4号），为进一步做好人民群众来信和网上留言办理工作，确保人民群众反映的问题能够及时办理，经市政府同意，现提出如下意见。

一、受理范围

（一）人民群众写给市长和省长的来信；

（二）抚顺市政府门户网《市长信箱》人民群众来信；

（三）省政府转办的辽宁省政府门户网《省长信箱》人民群众来信和《人民网·地方领导留言板》人民群众给省政府主要领导的留言；

（四）人民群众通过《人民网·地方领导留言板》给市政府主要领导的留言；

（五）市政府领导交办的人民群众通过网络反映的相关问题。

二、受理方式

市政府办公厅网络诉求处是办理人民群众来信和网上留言的工作部门，具体负责人民群众来信和网上留言的日常受理和办理、转办、督办等工作。县区政府、市政府工作部门和有关单位按照事权和职责分工具体承办。

（一）信息登记。

1. 准确填写诉求人的姓名、住址、联系电话；

2. 准确填写诉求的性质及诉求类别；

3. 简明扼要记录诉求的内容，准确掌握诉求人的意愿和要求；

4. 尊重并注明诉求人的保密要求。

（二）自办。

下列情况的诉求件，由市政府办公厅网络诉求处直接办理：

1. 能直接答复的诉求；

2. 对紧急突发事件立即协调市政府应急办及相关部门办理，及时向相关领导报告；

3. 对涉及党风、党纪及司法类、历史遗留类等投诉件，引导其向纪检监察或信访部门投诉举报；

4. 承办单位反馈件，经验收合格的及时归档，对验收不合格的退回承办单位重新办理。

下列情况的来信和留言，视为无效类诉求件，由市政府办公厅网络诉求处留存备查：

1. 来信和留言人姓名、联系方式填写不完整或不真实，无法展开具体调查和处理的来信和留言；

2. 来信和留言内容不完整、反映的问题表述不清或无任何实质内容，导致无法回答的来信和留言；

3. 通过其它受诉渠道反映的内容相同、正在办理或已作出答复的来信和留言；

4. 来信和留言中有侮辱诽谤他人、侵害他人合法权益的词语，或有违反国家法律法规、违反党和国家政策、违反社会主义道德的文字表述；

5. 进入信访、司法、仲裁、诉讼程序和存在经济、民事纠纷的来信和留言；

6. 反映的问题不属于人民政府职权范围且诉求不明确的来信和留言；

7. 有广告行为或借助政府力量生产和营销的来信和留言。

（三）转办。

1. 对涉及责任主体清楚的求助类和建议类来信和留言，立即转交有关主管部门或责任单位办理；

2. 对责任主体涉及两个或以上责任单位的诉求件，由市政府办公厅指定牵头单位，协调相关单位共同办理。

（四）督办。

有下列情况之一的，由市政府督查办督办落实：

1. 主管部门或相关责任单位应办未办的；

2. 市民普遍关注、影响面较大的热点难点或涉及单位多，经指定牵头单位协调仍不能按期办结的。

三、办理流程

对市政府办公厅网络诉求处转办的诉求件，由承办责任单位办理：

（一）承办责任单位接到转办件后，应立即向本单位主管领导报告，重大问题应报告行政主要领导，并按领导批示的意见在限定时限内处理；

（二）转办件办结后，承办责任单位除负责向诉求人进行答复并作满意度情况回访外，还要向市政府办公厅网络诉求处反馈办理结果；

（三）对合理的诉求件，因客观原因暂时解决不了的，由承办责任单位查清情况，提出工作建议，在报市政府分管市长决策的同时，做好诉求人的解释、疏导工作，并将工作情况报市政府办公厅网络诉求处；

（四）咨询类来信和留言首次办理时间为5个工作日（以转交时间为准，节假日顺延）；投诉类来信和留言为10个工作日；需要多个部门或单位协调办理的来信和留言为15个工作日；对反映的问题比较复杂的来信和留言，需要进行深入调查核实处理的首次办理时间可延长到30个工作日；

（五）承办单位在规定时限内不能如期办结的，要及时向市政府办公厅网络诉求处报送经本单位主管领导签字的书面情况说明，经市政府办公厅分管领导审定后，办理时间可延长10个工作日，但申请延长办理不得超过2次；涉及安监、交通、城建、环保、劳动监察等方面的诉求问题，按相关法律法规、政策规定时限办理；

（六）按诉求人要求做好保密工作。

四、工作要求

（一）各县区、市政府工作部门和有关单位要高度重视人民群众来信和网上留言办理工作，加强领导，强化措施，要指定专兼职人员负责人民群众来信和网上留言办理工作，及时解决人民群众诉求，化解矛盾纠纷、维护社会稳定。

（二）坚持和完善“受理-承办-回访-反馈”工作流程，强化每个环节的工作时限、质量要求，并具体落实责任单位和责任人，办理过程做到目标明确、评价客观，记录真实。

（三）答复诉求人的回信或通过网络回复诉求人的办理结果，应有相关的法律法规、政策规定作依据，条理清晰、措辞得当、言简意赅，避免因政策运用失当造成不良影响。

（四）人民群众来信和网上留言办理情况，接受人民群众监督和评价，由诉求人给出满意、基本满意和不满意的评价。对诉求人给出不满意评价的诉求件，市政府办公厅网络诉求处应对反映的诉求及承办单位的办理情况进行复查，对应办未办的责令重新办理，并进行通报批评；对敷衍应付、推诿扯皮、搁置不办、弄虚作假的，按有关规定问责追责。

（五）办理人民群众来信和网上留言的政府办公部门和承办单位的工作人员要严格遵守保密纪律，不得擅自传播来信人和留言者的信息，不得擅自发布或传播未经领导审批的相关办理情况。对擅自发布或传播相关信息造成不良后果的，追究当事人和相关领导的责任。

抚顺市人民政府办公厅
