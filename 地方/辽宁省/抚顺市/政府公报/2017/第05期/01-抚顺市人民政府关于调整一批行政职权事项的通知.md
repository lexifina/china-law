# 抚顺市人民政府关于调整一批行政职权事项的通知

抚顺市人民政府关于

调整一批行政职权事项的通知

抚政发〔2017〕22号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

为贯彻落实《辽宁省人民政府关于调整一批行政职权事项的决定》（辽政发〔2017〕26号）精神，市政府决定对156项行政职权事项进行调整。其中，由市级部门行使调整为省级部门行使的行政职权12项，市、县（区）级政府相关部门对应增加行政职权50项、取消行政职权94项。

各县区、各部门要做好调整行政职权事项的衔接落实工作。对取消的行政职权，不得再以任何方式继续行使，同时要制定有效措施，加强监管；对于新增的行政职权，有关部门要优化办事流程，及时公开办理流程图和办事指南，确保权力运行简洁高效。市、县（区）机构编制部门要按照《抚顺市权责清单管理办法》的规定，对权责清单进行调整。

附件：1. 抚顺市人民政府调整市政府部门行政职权目录

2. 抚顺市人民政府取消市县级政府行政职权目录
