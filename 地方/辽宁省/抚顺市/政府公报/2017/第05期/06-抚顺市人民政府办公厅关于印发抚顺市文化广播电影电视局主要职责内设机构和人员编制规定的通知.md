# 抚顺市人民政府办公厅关于印发抚顺市文化广播电影电视局主要职责内设机构和人员编制规定的通知

抚顺市人民政府办公厅关于

印发抚顺市文化广播电影电视局

主要职责内设机构和人员编制规定的通知

抚政办发〔2017〕60号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

《抚顺市文化广播电影电视局主要职责内设机构和人员编制规定》已经市政府批准，现予印发。

抚顺市人民政府办公厅

2017年11月6日

抚顺市文化广播电影电视局

主要职责内设机构和人员编制规定

根据《中共辽宁省委办公厅 辽宁省人民政府办公厅关于印发〈抚顺市人民政府职能转变和机构改革方案〉的通知》（厅秘发〔2014〕18号），设立抚顺市文化广播电影电视局（简称市文化广电局），挂抚顺市新闻出版局、抚顺市版权局、抚顺市文物局牌子，局级，为市政府工作部门。

一、职能转变

（一）取消的职责。

取消已由市政府公布取消的相关职责。

（二）增加的职责。

承接国务院、省政府下放的相关职责。

（三）加强的职责。

1.加强文化供给侧结构性改革，强化培育新兴文化艺术产业。

2.加强公益文化、文化遗产保护、文化市场监管工作。

3.加强文物保护工作、文物执法监督，进一步加强新时期文物工作。

4.加强组织推进文化新闻出版广播影视领域公共服务，指导基层文化建设，大力促进城乡公共服务一体化发展，促进文化新闻出版广播影视事业繁荣发展。

5.加强指导、协调、推动文化新闻出版广播影视产业发展，优化配置文化新闻出版广播影视资源，加强业态整合，促进综合集成发展。

6.加强文化新闻出版广播影视领域体制机制改革。

7.加强对数字出版以及网络视听节目服务、公共视听载体播放广播影视节目的规划指导和监督管理，推动协调其健康发展。

8.加强著作权保护管理和公共服务，加大反侵权盗版工作力度。

9.加强管理理念和方式的创新转变，充分发挥市场调节、社会监督和行业自律作用。

二、主要职责

（一）贯彻执行党和国家、省委、省政府关于文化艺术、新闻出版、版权、文物、广播电影电视工作的方针政策和法律法规，组织起草相关的地方性法规、规章草案。

（二）拟订全市文化艺术、新闻出版、文物、广播电影电视事业发展规划并组织实施，推进体制机制改革。

（三）负责指导、管理全市文学艺术事业，指导艺术创作与生产，扶持具有代表性、示范性、实验性的文化艺术品种，促进各门类艺术发展。

（四）推进全市文化艺术领域的公共文化服务，规划、引导公共文化产品生产、重点文化设施以及基层文化设施建设。

（五）指导、管理全市图书馆、文化馆（站）和基层文化建设等公共文化事业，指导文化志愿服务。

（六）拟订全市文化产业规划，指导、协调文化艺术产业发展，推进对外文化产业交流与合作。

（七）拟订全市动漫、游戏产业发展规划并组织实施，指导、协调动漫、游戏产业发展。

（八）拟订全市文化市场发展规划，指导文化市场综合执法工作，负责对文化艺术经营活动进行行业监管，管理全市性重大文化活动，指导对从事演艺活动民办机构的监管工作。

（九）负责全市互联网文化活动的监管工作，对互联网上网服务营业场所实行经营许可证管理。

（十）拟订全市非物质文化遗产保护规划，组织开展非物质文化遗产保护和优秀传统文化的传承普及工作。

（十一）指导、协调全市不可移动文物（包括附属文物）的管理、保护、抢救、研究及配合上级部门勘探发掘等工作，指导、协调全市博物馆收藏、研究、展示等工作，负责可移动文物及社会文物保护等工作。

（十二）依法组织查处文物违法行为，协助配合有关部门查处文物犯罪的重大案件。

（十三）推进文化科技信息建设，指导文化艺术行业职业教育和文化科研工作，组织开展对外文化交流活动。

（十四）指导全市广播影视宣传和广播影视创作，并协调其题材规划，把握正确的舆论导向和创作导向，监督管理全市广播影视机构和业务，监督管理广播影视节目、网络视听节目、公共视听载体播放的广播影视节目的内容和质量。

（十五）负责全市新闻出版、版权工作，负责图书、报纸、期刊、音像、电子出版物市场及印刷行业的监督管理，负责组织、指导、协调全市“扫黄打非”工作。

（十六）承办市委、市政府交办的其他事项。

三、内设机构

根据上述职责，市文化广电局设8个内设机构。

（一）党委工作部（工会、团委）。

负责机关及所属单位党的建设、精神文明建设及工会和共青团工作，负责机关及所属单位机构编制、干部人事工作，负责机关离退休干部管理服务工作。

（二）办公室。

负责机关政务工作，研究拟订文化广电事业中长期发展规划和年度工作计划，起草重要文件、报告，负责文电、会务、机要、保密、档案、信息、信访、综治、应急、建议提案、机关后勤、安全保卫等，承担政务公开、政务督办、新闻发布、舆情应对和政务宣传等工作，负责精准扶贫协调工作。承担局机关财务、固定资产和内部审计工作，负责文化事业、新闻出版影视专项资金监督管理工作，负责指导、监督所属单位的财务工作，行政事业单位内部控制建设牵头工作，负责文化系统统计工作，负责机关及所属事业单位网上名称管理工作。

（三）行政审批处。

负责本单位行政审批事项的受理和审批工作，组织协调行政审批事项现场勘验、专家论证和技术审查工作，负责行政审批事项许可证照发放、换证、初审、报备事宜，负责对县区本系统审批事项的指导、督促、检查、备案等工作。

（四）市场法规产业处。

拟订全市文化市场发展规划和政策，指导全市文化市场综合执法工作，依法管理营业性演出、互联网文化活动、娱乐场所和互联网上网服务营业场所及艺术品经营活动，负责动漫游戏市场的监管，承担社会艺术水平考级活动的管理工作，指导、督促检查文化经营场所的安全生产工作。负责组织起草地方性法规、规章草案，负责行政复议、行政应诉工作。拟订全市文化产业发展规划和政策，扶持和促进文化产业建设与发展，指导文化产业园区、基地和区域特色文化产业建设，负责推进对外文化产业交流与合作。

（五）文化艺术处（非物质文化遗产处）。

拟订全市公共文化事业发展规划和政策，指导群众文化、少数民族文化、未成年人文化和老年文化等工作，指导图书馆和文化馆（站）事业，指导文化信息资源共享工程建设和古籍保护工作，指导基层群众文化活动和文化志愿服务，指导村文化活动室和社区文化活动中心建设，指导、督查所属文化事业单位及举办大型群众文化活动的安全工作。拟订全市文学艺术事业发展规划，指导艺术创作生产、艺术研究与评论，扶持代表性、示范性、实验性文艺品种，扶持体现社会主义核心价值体系的文艺作品和代表市级水准及民族特色的文艺团体，推动舞台艺术、美术创作等各门类艺术的发展，指导、协调全市性艺术展演、展览及重大文艺活动，拟订全市对外及港澳台文化交流发展规划，指导、管理全市对外及港澳台文化交流工作，按规定权限负责对外及港澳台文化交流项目工作，组织大型对外文化交流活动。负责拟订全市非物质文化遗产保护规划和政策，组织开展全市非物质文化遗产保护工作。

（六）文物管理处。

拟订全市文物保护、博物馆事业工作规划和政策，协调、指导申报全国重点文物保护单位、省级文物保护单位工作，负责市级文物保护单位申报工作，组织指导各县区开展辖区内市级文物保护单位保护工程的申报、论证、设计、施工、质量监督与验收工作，配合上级部门开展全市考古发掘项目、大型基本建设工程中考古工作的实施，监督管理全市文物勘探工作，监督文物执法机构依法查处各类文物违法案件，协助配合有关部门依法查处文物犯罪的重大案件，指导、督促检查全市文物系统的安全保卫、消防、技防工作，协调推动文物和博物馆科技、信息化、标准化等工作，指导博物馆制度建设和业务管理工作，协调博物馆间的交流与协作，协调民间珍贵文物抢救、征集工作。

（七）新闻出版处（版权处）。

拟订全市新闻出版事业发展规划，拟订著作权保护管理使用的政策措施，负责全市出版、印刷、发行等行业的监督管理和许可证年检工作，查处非法出版、印刷、发行行为及著作权领域违法违规行为，组织推进软件正版化工作，组织实施全民阅读推广活动，承担市“扫黄打非”工作领导小组办公室日常工作。

（八）广电管理处。

拟订全市广播电影电视事业总体规划和政策并组织实施，负责把握正确的广播电视舆论宣传和创作导向，管理、监督全市广播电视频率和频道的播出，负责广播电视卫星地面接收设施、视频点播、闭路电视系统、大屏幕电视、营业性电视摄像服务、广播电视节目制作等经营机构及相关行业的管理工作，指导和监督管理全市广播电视广告播放的相关工作。推进三网融合，推进应急广播建设，承担全市广播影视安全播出的监督管理和技术保障工作，承担广播影视质量技术监督、监测和计量检测工作。承担监督管理电影放映单位的相关业务及许可证年检工作，指导和组织实施农村和社区公益电影放映，指导、协调全市性重大的广播电影电视活动。

四、人员编制（略）

五、其他事项

所属事业单位的设置、职责和编制事项另行规定。

六、附则

本规定由市机构编制委员会办公室负责解释，其调整由市机构编制委员会办公室按规定程序办理。
