# 抚顺市人民政府办公厅关于印发抚顺市体育局主要职责内设机构和人员编制规定的通知

抚顺市人民政府办公厅关于印发抚顺市体育局

主要职责内设机构和人员编制规定的通知

抚政办发〔2017〕61号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

《抚顺市体育局主要职责内设机构和人员编制规定》已经市政府批准，现予印发。

抚顺市人民政府办公厅

2017年11月6日

抚顺市体育局主要职责

内设机构和人员编制规定

根据《中共辽宁省委办公厅 辽宁省人民政府办公厅关于印发〈抚顺市人民政府职能转变和机构改革方案〉的通知》（厅秘发〔2014〕18号），设立抚顺市体育局（简称市体育局），局级，为市政府工作部门。

一、职能转变

（一）取消的职责。

取消已由市政府公布取消的相关职责。

（二）加强的职责。

1．加强运动员文化教育和保障工作。

2．加强体育产业规划和指导工作。

二、主要职责

（一）贯彻执行国家和省体育工作的方针、政策，拟订全市体育工作有关政策，起草地方性法规和市政府规章草案。

（二）研究编制全市体育事业发展规划，指导和推动全市体育行业体制改革工作。

（三）组织全市体育领域重大科研攻关和成果推广工作，组织开展反兴奋剂工作。

（四）推行全民健身计划，指导并开展群众性体育活动，推动国家体育锻炼标准的实施，开展国民体质监测，指导公共体育设施的建设，负责对公共体育设施的监督管理工作。

（五）统筹规划竞技体育发展，指导全市业余训练项目的设置与布局，组织参加国际性、全国性、省级重大体育比赛工作，组织全市综合性体育竞赛，承办在我市举办的国际性、全国性、省级体育比赛工作。

（六）统筹规划青少年体育发展，指导和推进青少年体育工作，指导运动员的文化教育和保障工作。

（七）负责体育外事工作，开展体育合作交流工作。

（八）承办市政府交办的其他事项。

三、内设机构

根据上述职责，市体育局设4个内设机构：

（一）办公室。

起草地方性法规和市政府规章草案，拟订全市体育工作发展规划并组织实施和监督检查，负责文电、会务、机要、财务、档案、后勤等机关日常运转工作，承担信息、安全、保密、信访、文字综合、政务公开、建议提案和综合协调等工作，负责体育宣传和发布重大体育新闻，负责舆情应对工作，指导所属单位的财务工作，负责体育统计工作，负责机关及所属单位的党群工作、机构编制和人事管理工作，负责机关离退休干部工作，指导所属单位离退休干部工作，负责体育外事工作，开展体育合作交流工作。

（二）群众体育处。

拟订全市群众体育工作的发展规划，推行全民健身计划，推动并监督国家体育锻炼标准实施，推行社会体育指导员和国民体质监测制度，指导和推动各行业、各类人群全民健身活动的发展。

（三）体育竞赛训练处。

拟订全市性体育竞赛制度和竞赛计划，设置、调整业余训练的项目布局并组织实施，统筹协调大型体育赛会的组织、参赛工作，拟订全市青少年体育发展规划及政策，负责运动员参赛资格审查，参与审核全市青少年比赛计划、竞赛规程，参与指导青少年运动员注册工作，指导各级各类后备人才基地、青少年体育俱乐部、户外活动营地、体育传统校建设和管理，开展青少年体育相关工作研究和培训，提出教练员、运动员参加全省比赛奖励办法和标准，负责组织开展反兴奋剂工作，指导全市体育领域科研攻关和体育科研成果管理推广工作，负责大型赛会的信息收集、统计、分析等工作，负责各项目运动员和裁判员等级的管理工作。

（四）体育产业处（行政审批处）。

拟订体育产业的发展规划和政策，指导体育产业发展，规范体育服务管理，依法监管体育市场经营和安全生产工作，拟订加快体育产业发展、促进体育消费的政策措施，并组织实施和监督检查，指导和促进体育经营活动有序进行，加强和指导体育场馆的管理和开发利用，负责体育系统体育设施建设的组织与协调工作，负责行政审批相关工作。

四、人员编制（略）

五、其他事项

所属事业单位的设置、职责和编制事项另行规定。

六、附则

本规定由市机构编制委员会办公室负责解释，其调整由市机构编制委员会办公室按规定程序办理。
