# 抚顺市人民政府办公厅关于印发抚顺市农产品加工集聚区发展三年行动计划（2018—2020年）的通知

抚政办发〔2018〕38号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

经市政府同意，现将《抚顺市农产品加工集聚区发展三年行动计划（2018—2020年）》印发给你们，请认真贯彻执行。

抚顺市人民政府办公厅

2018年4月12日

（此件公开发布）

抚顺市农产品加工集聚区发展三年行动计划（2018—2020年）

为认真贯彻落实乡村振兴战略，拓展农民增收渠道，推进农村一二三产业融合，加快农产品加工业集聚发展，提升农业产业化经营和现代农业发展水平，根据《辽宁省人民政府关于加快农产品加工业发展的实施意见》（辽政发〔2016〕19号）、《辽宁省人民政府办公厅关于印发〈辽宁省农产品加工集聚区发展规划（2017-2020年）〉的通知》（辽政办发〔2017〕66号）和《中共抚顺市委 抚顺市人民政府关于加快县域经济发展的实施意见》（抚委发〔2017〕41）精神，结合《抚顺市现代农业发展“十三五”规划纲要》，制定本计划。

一、总体要求

（一）指导思想。

深入贯彻落实党的十九大精神和习近平总书记系列重要讲话精神，牢固树立创新、协调、绿色、开放、共享发展理念，以实施乡村振兴战略为主线，以促进农业增效和农民增收为目标，以农业供给侧结构性改革为动力，以市场需求为导向，以招商引资为突破口，以林下经济和食品加工等特色产业规划为引领，以推进产业集聚为核心，以政策为支撑，以资金、人才、技术等要素为杠杆，尽快形成布局合理、特色鲜明、产业集聚、集约发展、功能配套的集聚区，着力提升全市农产品加工业竞争力，促进农村一二三产业融合发展，为全面建成小康社会和发展壮大县域经济提供重要支撑。

（二）基本原则。

1. 坚持政府主导。发挥政府的政策引导作用，通过制定和实施集聚区建设发展规划、政策，引导农产品加工业合理布局，坚持高起点、高水平建设，不断提高集聚区承载力和吸引力，推动集聚区快速发展。

2. 坚持产业集聚。结合区域资源禀赋、产业基础和产品特色，充分发挥不同的特色产业优势，壮大基地规模，培育农产品品牌，扶持龙头企业，促进加工企业向集聚区集聚，形成各具特色的集聚区产业布局。

3. 坚持龙头带动。依托龙头企业，将农产品加工及其相关的产前、产中、产后服务业相对集中，促进农产品加工企业与农产品基地、原料基地紧密结合，上下游产品有机衔接，产加销一体化经营，产业链条式发展，不断延长产业链，推进精深加工，提升价值链。

4. 坚持创新驱动。加大技术攻关和技术创新力度，重视引进、开发和应用高新技术、设备和工艺，加快企业技术改造，不断培育和提高企业的自主研发能力，着重发展精深加工，提高产品质量、档次，推动农产品加工业由粗放型向集约型转变。

5. 坚持绿色发展。坚持生态优先，合理开发农业、森林资源，按照“减量化、再利用、资源化”的要求，引进先进工艺和技术，发展循环经济，做到节约、降耗、减污、增效，实现资源利用和环境保护协调发展。

（三）发展目标。

到2018年，计划实现主营业务收入12.36亿元、力争达到14.3亿元；到2019年，计划实现主营业务收入16.98亿元、力争达到21.5亿元；到2020年，计划实现主营业务收入22.24亿元、力争达到31亿元。其中：

----抚顺县农产品加工集聚区。2018年，计划实现主营业务收入3.3亿元；2019年，计划实现主营业务收入3.8亿元、力争达到5亿元；2020年，计划实现主营业务收入4.1亿元、力争达到7亿元。

----清原满族自治县农产品加工集聚区。2018年，计划实现主营业务收入2.31亿元、力争达到4亿元；2019年，计划实现主营业务收入4.2亿元、力争达到6亿元；2020年，计划实现主营业务收入5.6亿元、力争达到8.5亿元。

----新宾满族自治县农产品加工集聚区。2018年，计划实现主营业务收入4.75亿元、力争达到5亿元；2019年计划实现主营业务收入5.13亿元、力争达到6.5亿元；2020年，计划实现主营业务收入5.54亿元、力争达到8.5亿元。

----东洲区农产品加工集聚区。2018年，计划实现主营业务收入2亿元；2019年，计划实现主营业务收入3.85亿元、力争达到4亿元；2020年，计划实现主营业务收入7亿元。

二、空间布局及产业定位

依据全市现代农业十三五发展规划、区域农产品资源优势和现有农产品加工业发展基础，合理布局全市集聚区和主导产业定位。

（一）抚顺县。以104省道（抚金线）为轴线，以东部汤图乡、后安镇和马圈子乡为核心区，以中部上马乡、救兵乡和峡河乡为辐射区，以西部石文镇和海浪乡为带动区，依托三友生物科技公司等龙头企业，拓展食用菌主导产业上下游产业链，增强集聚区规模化发展和产业化经营水平，形成引领全国的区域菌种繁育、基地种植和农产品精深加工一体化发展的产业集聚区。

（二）清原满族自治县。以“一城、两区、三带”的空间发展布局为前提，以湾甸子镇集成材园区为核心，依托浩琳木业等龙头企业，加快与德国（WEINIG）威力公司的战略合作，引进木制品加工业先进生产技术和经营理念，重点发展以樟子松为主要原料集成材、生物颗粒等产业，打造东北现代智能自动化集成材集散地，做强做大林产品加工集聚区。

（三）新宾满族自治县。聚焦生态产业，坚持“两个优先”发展战略，按照“一区一场一业”总体布局，以永陵中药材、榆树木制品加工集聚区为核心，以人参、五加、细辛等中药材交易市场建设为平台，以“一乡一特一业”为支撑，大力发展生态农业，形成集种植、加工、销售于一体的产业链，打造省级农村一二三产业融合发展示范区。

（四）东洲区。以哈达镇阿及村和上年村为核心，依托禾丰牧业等龙头企业，加快基础设施建设，强化招商引资力度，大力推进项目建设，全面推进养殖废弃物资源化循环利用，促进畜牧业绿色发展，形成集生猪繁育、养殖、屠宰和食品加工于一体的全生态产业链农产品加工集聚区，打造区域生态循环农业的示范区、样板区。

三、主要任务

（一）科学编制集聚区发展规划。坚持“高起点、高标准、布局合理、适度超前”原则，以政府为主导，以发展特色产业、林下经济和食品加工业为突破口，以培育壮大骨干企业为依托，充分利用现有产业园区，发挥资源比较优势，对产业集群发展进行科学规划，编制农产品加工业集聚区发展规划。（责任单位：三县一区政府）

（二）加快集聚区专用原料基地建设。鼓励农产品加工企业开展原料示范基地、标准园、示范场等多种形式规模化经营。大力推行专业化、标准化、规模化生产，建立稳定的农产品加工业原料生产基地。加强农田水利、道路等生产性配套设施建设，为农产品加工业专用原料生产夯实基础。（责任单位：市农委、市国土资源局、市水务局、市交通局、三县一区政府）

（三）加强集聚区基础设施建设。充分整合、优化、提升集聚区要素资源，科学确定主导产业，加大基础设施建设投入力度，积极鼓励社会资本投入，不断提高投资强度和土地集约化程度，促进产业集聚升级，引导龙头企业从横向和纵向两个方面实现聚集。（责任单位：三县一区政府）

（四）加快集聚区项目建设。加大招商引资力度，着力引进一批成长性好、市场潜力大、产业关联度高、科技含量足、品牌竞争力强、节能环保的优势产业项目，引导农产品加工企业向集聚区集中。（责任单位：市商务局、三县一区政府）

（五）大力培育龙头企业。加快培育经营主体，鼓励农产品加工企业通过收购、兼并、参股、租赁、产业链延伸、品牌联盟等多种形式进行重组整合，发展壮大一批大型农产品加工企业集团。（责任单位：市农委、市工业和信息化委、三县一区政府）

（六）推进企业品牌和区域品牌建设。引导和支持产业集群内企业创立品牌，逐步实现从无牌、贴牌到有牌、名牌的转变，支持企业积极争创省级以上名牌产品，大力培育农产品商标和地理标志证明商标。推动生产要素向品牌企业和优势企业活动，转成集聚效应，培育区域产业文化。（责任单位：市农委、市质监局、三县一区政府）

（七）加快企业自主创新。加快以企业为主体，市场为导向，产学研相结合的技术创新体系建设，根据产业集群发展需求，引导集群内的企业加强与高等院校、科研机构的合作，在关键技术、关键工艺上、加快企业技术创新，推动科技成果转化和产业化。（责任单位：市农委、市科技局、三县一区政府）

（八）支持农产品营销服务平台建设。支持有条件地区打造农产品集散、冷链物流、产品展销中心。大力发展直供直销、连锁经营、“互联网+流通”等新型流通业态和模式。（责任单位：市农委、市商务局、三县一区政府）

（九）支持企业利用资本市场融资。加强融资服务和指导，支持符合条件农产品加工企业扩大规模，在国内外上市融资，在全国中小企业股份转让系统挂牌融资，扩大股票市场再融资规模。（责任单位：市金融办、三县一区政府）

四、扶持政策

（一）加强金融服务。充分利用辽宁省产业（创业）投资引导基金，积极吸引社会资本加大对农产品加工业发展的投融资力度。结合农产品加工企业生产特点，引导金融机构调整优化涉农信贷结构，合理安排授信，创新金融产品和服务。加大农业产业化重点龙头企业扶持力度，对龙头企业在原材料收购、仓储设施、生产加工基地建设和技术改造等方面的合理资金需求，金融机构根据实际情况给予信贷资金支持。鼓励银行机构积极利用支农再贷款，加大对农村企业和城市涉农企业的支持力度。

（二）加大财税扶持。充分利用辽宁产业（创业）投资引导基金，以及现有涉农资金，加大对省级农产品加工集聚区基础设施建设投入力度；对投资建设新认定的国家级和省级企业技术研发中心、新认定的国家级和省级质检平台、在境内外证券交易市场（柜台交易市场除外）实现挂牌上市以及获得中国质量奖及质量提名奖、省长质量奖、辽宁省名牌农产品加工企业以及培育农产品商标和地理标志证明商标，给予必要的支持。

（三）完善土地政策。对进入农产品加工集聚区重点项目建设用地，要优先保障。在符合规划、不改变用途的前提下，对农产品加工企业通过厂房加层、老厂改造、内部整理等途径提高利用率的，不再增收土地价款。农产品加工企业新办畜禽饲养场的畜禽舍、水产养殖池塘等生产设施用地，依据国土资源部、农业部《关于进一步支持设施农业健康发展的通知》（国土资发〔2014〕127号）办理备案，按照农用地管理。鼓励利用集体土地兴办农产品加工企业。支持与农业产业化龙头企业相联结的农产品基地建设。各县区每年要安排一定数量的用地指标，满足农产品加工集聚区建设和农产品加工企业拓展发展空间的需要。

五、保障措施

（一）加强组织领导。在市县域经济工作领导小组领导下，成立以市政府分管农业副市长为组长、市政府副秘书长和市农委主任为副组长、市直相关部门为成员单位的农产品加工集聚区工作推进组，主要负责调查研究、协调解决农产品加工集聚区发展有关重大事项，督查指导、监测考核农产品加工集聚区建设工作。在市农委下设办公室，主要职责是全面掌握农产品加工集聚区发展动态，负责农产品加工集聚区建设工作的组织协调，协同推进。

（二）强化服务督导。建立健全市、县区两级农产品加工企业经济运行督导服务体系，加强对市级重点龙头企业发展跟踪服务。完善市级重点龙头企业认定监测制度，实行动态管理。建立农产品加工业信息发布平台，做好信息的收集、整理和发布，为政府制定政策和企业生产经营提供信息服务。

（三）创新体制机制。三县和东洲区要全面落实主体责任，成立以副县区级以上领导挂帅的管委会，加快融资公司、建投公司等平台建设，强化管委会在规划、监管和服务以及平台公司在土地开发、融资渠道、基础建设和招商引资等方面功能，加快形成分工明确、职责清晰、运行高效的“管委会+公司”体制机制，促进集聚区健康有序发展。

（四）完善考评办法。由市农产品加工集聚区工作推进组制定考评量化指标和考评办法，加强考核工作，对做出突出贡献的县区政府、农产品加工集聚区以及农产品加工龙头企业，给予适当物质奖励和优先安排项目申报。
