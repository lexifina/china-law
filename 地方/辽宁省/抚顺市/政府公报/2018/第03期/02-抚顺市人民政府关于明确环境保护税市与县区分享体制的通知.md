# 抚顺市人民政府关于明确环境保护税市与县区分享体制的通知

抚顺市人民政府关于明确

环境保护税市与县区分享体制的通知

抚政发〔2018〕7号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

为顺利推进环境保护税改革，实现排污费向环境保护税的平稳过渡，妥善处理好市与县区间的利益关系，根据《辽宁省人民政府关于明确环境保护税省与市分享体制的通知》（辽政发〔2018〕5号）精神，结合我市实际情况，现对环境保护税市与县区分享体制予以明确，自2018年1月1日起执行。现就有关事宜通知如下：

抚顺县、清原县和新宾县环境保护税实行属地征管、属地入库，扣除上缴省20％后，其余归县级留存，市本级不参与分享。城区实行属地征管，扣除上缴省20％后，其余直接缴入市级国库，城区不参与分享。

执行期间，如遇国家和省出台重大税制调整或财政管理体制调整，市政府将相应予以调整。本通知执行过程中涉及的具体问题，由市财政局负责解释。

抚顺市人民政府

2018年5月4日
