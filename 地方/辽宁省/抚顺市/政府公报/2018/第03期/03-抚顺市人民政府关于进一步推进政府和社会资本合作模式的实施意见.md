# 抚顺市人民政府关于进一步推进政府和社会资本合作模式的实施意见

抚顺市人民政府关于进一步推进

政府和社会资本合作模式的实施意见

抚政发〔2018〕10号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

为鼓励和引导社会投资，提高公共产品供给能力和效率，根据《国家发展改革委关于开展政府和社会资本合作的指导意见》（发改投资〔2014〕2724号）、《辽宁省人民政府关于推广运用政府和社会资本合作模式的实施意见》（辽政发〔2015〕37号）等文件精神，结合我市实际，现就进一步推进政府和社会资本合作（PPP）模式，提出以下实施意见。

一、总体要求

（一）指导思想。

全面贯彻落实国家关于“允许社会资本通过特许经营方式参与城市基础设施投资和运营”的精神，立足我市实际情况，改革创新基础设施及公共服务供给机制和投入方式，发挥市场在资源配置中的决定性作用，加快政府职能转变，引导和鼓励社会资本特别是民间资本积极参与基础设施及公共服务供给，提高公共产品服务质量和效率。

（二）基本原则。

1.转变职能，清晰界定政府职责。按照政府决策、规范运营、市场化运作的原则，将政府职能逐步从公共产品的直接“提供者”转变为政策的“制定者”、社会资本的“合作者”及PPP项目的“监管者”。

2.严肃监管，全力保障公众利益。正确处理公众、政府和社会资本之间的关系，建立健全特许经营差异化定价、补贴、考评和利润调节机制，在不增加公众生活负担的前提下开展PPP项目，提高公共产品供给质量和效率，全力保障公众利益。

3.因地制宜，合理确定投资回报。建立健全PPP项目的投资回报机制，根据本地区、本行业实际，明确排他性约定，加强成本监测，核定收费价格和补贴额度，合理确定投资回报。

4.诚信守约，保证各方合法权益。严格执行合同条款，牢固树立法律责任、契约精神和信用意识，保证合作各方合法权益，无故违约须承担相应责任。

二、适用范围

PPP模式适用于能源、交通运输、水利、环境保护、农业、林业、重大市政工程、科技、保障性安居工程、医疗、卫生、养老、教育、体育、旅游、文化等政府负有提供责任且适宜市场化运作的项目。鼓励逐步提高新建项目使用PPP模式的比例。已定性为政府债务中的存量项目，经评估符合条件的，鼓励采用PPP模式引入社会资本。

三、操作方式

（一）对于具有明确收费基础，并且使用者付费能够完全覆盖投资成本的新建经营性项目，可通过政府授予特许经营权，采用建设—运营—移交（BOT）、建设—拥有—运营—移交（BOOT）等模式推进，积极推动自然垄断行业逐步实行特许经营。

（二）对于使用者付费不足以覆盖投资成本，需政府补贴部分资金或资源的新建准经营性项目，可通过政府授予特许经营权附加部分补贴或直接投资参股等方式，采用建设—运营—移交（BOT）、建设—拥有—运营（BOO）等模式推进。

（三）对于已建成的基础设施或已有的公共服务，根据项目实际情况，可采用转让—运营—移交（TOT）、委托运营（O＆M）、改建—运营—移交（ROT）、管理合同（MC）等模式推进。

（四）鼓励探索非经营性项目同经营性项目捆绑运作，通过建立合理的使用者付费机制，增强非经营性项目对社会资本的吸引力。

四、市本级操作流程

（一）项目储备。

市PPP工作领导小组办公室负责向相关行业主管部门征集潜在政府和社会资本合作项目，行业主管部门负责按照行业近三年发展规划提出拟实施PPP项目（经分管副市长同意）报市PPP工作领导小组办公室，经领导小组办公室组织相关部门和专家初审合格后报领导小组，经领导小组审批通过后符合入库条件的按程序要求分别纳入发改、财政系统PPP项目库。

社会资本方发起PPP项目的，由社会资本方向行业主管部门提出申请，行业主管部门审核同意后（经分管副市长同意）提交市PPP工作领导小组办公室。

项目申报须附送可行性研究报告、项目产出说明、存量公共资产的历史资料和初步实施方案等相关资料，明确PPP项目的实施机构、合作模式、回报方案与合作周期。

（二）项目评估与决策。

市PPP工作领导小组办公室会同财政及行业主管部门，根据有关政策法规要求，扎实做好项目的必要性、可行性、经济性、合规性等前期论证工作。

1.确定PPP项目及实施机构

市PPP工作领导小组办公室对储备项目进行初步筛选后提出年度拟推进的项目，领导小组确定年度推进的项目。对列入年度实施计划的PPP项目，根据项目性质和行业特点，由政府行业主管部门或政府委托的相关单位作为项目实施机构。项目实施机构依法通过政府采购方式委托咨询机构编制项目实施方案，与市财政局共同做好物有所值评价报告和财政承受能力论证报告的前期论证工作，依法开展社会资本方选择工作，负责签订项目合同、项目合作期满移交等工作。

2.编制项目实施方案

纳入年度计划的PPP项目，应编制项目实施方案。项目实施方案原则上在可行性研究报告批复后编制，对于重大政府投资项目，应重视项目初步设计方案的深化研究，细化工程技术方案和投资概算等内容，并作为确定项目实施方案的重要依据。实施方案应由实施机构组织编制，实施方案编制过程中，可征求潜在社会资本方的意见。

项目实施方案应包括项目概况、运作方式、社会资本选择方式、投融资和财务方案、建设运营及移交方案、风险分配方案、政府支出责任、合同体系及主要内容、监管框架、变更及退出机制、政府承诺和保障等。实施方案中应对物有所值等进行专篇分析，并对财政承受能力进行研究分析。

3.论证物有所值评价和财政承受能力

项目实施机构可依法通过政府采购方式委托专家或第三方专业机构，编制项目物有所值评价报告，市财政局会同行业主管部门对物有所值评价报告进行审查。市财政局组织编制财政承受能力论证报告，综合考虑行业均衡性和PPP项目开发计划后，出具财政承受能力论证报告审查意见。未通过物有所值评价和财政承受能力论证的项目，不得采用PPP模式。

4.审查实施方案

通过物有所值评价、财政承受能力论证报告审查拟实施的PPP项目，由市发展改革委和相关行业主管部门牵头，委托第三方专业机构出具评估意见，会同财政、规划、国资、国土、物价、法制等政府有关部门对项目实施方案进行联合评审并形成审查结论，报市PPP工作领导小组审议批准。实施方案经领导小组审议批准后，由项目实施机构负责推进项目实施。未通过审批的，可对实施方案进行调整后重新审批；经重新审批后仍不能通过的，不得采用PPP模式。

（三）选择社会资本方。

1.社会资本遴选

项目实施方案经市PPP工作领导小组审议通过后，项目实施机构根据《中华人民共和国政府采购法》、《中华人民共和国招标投标法》及财政部《政府和社会资本合作项目政府采购管理办法》等规定，按照“公开、公平、公正、择优、高效”的原则，通过招标采购等竞争方式，综合项目合作伙伴的专业资质、技术能力、管理经验、经营能力、财务实力及信用状况等因素，择优选择诚实可信、安全可靠的合作伙伴。

2.合作合同签订

由项目实施机构会同相关部门将项目合同报送市PPP工作领导小组。市PPP工作领导小组审核同意后，由项目实施机构与中选社会资本方正式签署PPP合同，项目合作合同需确定各方权利和义务，合理分配项目风险。合同范本参照国家发展改革委、财政部有关文件。

（四）合同履行。

1.项目公司设立

项目实施机构应会同相关职能部门按照合同约定，督促各方按时足额出资设立项目公司，政府可指定相关机构依法参股项目公司。项目公司成立后，应由项目公司与项目实施机构重新签署项目合同，或签署关于承继项目合同的补充合同，保证按时完成项目融资并履行项目建设、运营、维护和移交等合同义务，定期对设施进行检修和保养，保证设施正常运转，确保项目可持续运营。项目实施机构会同有关部门对项目进行验收。

2.全生命周期绩效管理

项目行业主管部门会同市财政局开展项目全生命周期成本监测。行业主管部门应根据各自行业特点制定不同领域的行业技术标准、公共产品或服务技术规范，加强对公共产品或服务质量的监管，建立事前设定绩效目标、事中进行绩效跟踪、事后进行绩效评价的全生命周期绩效管理机制。

3.项目运营绩效评价

市财政局应会同行业主管部门，根据项目合同约定，定期对项目运营服务进行绩效评价，绩效评价结果应作为项目公司或社会资本方取得项目回报的依据。项目实施机构应会同行业主管部门，自行组织或委托第三方专业机构对项目进行中期评估，及时发现存在的问题，制订应对措施，推动项目绩效目标顺利完成。

（五）项目临时接管和提前终止。

在项目合作期限内，如出现重大违约或者不可抗力导致项目运营持续恶化，危及公共安全或重大利益时，政府要及时采取应对措施，必要时可指定项目实施机构等临时接管项目，切实保障公共安全和重大公共利益，直至项目恢复正常运营，不能恢复正常运营的，要提前终止，并按合同约定妥善做好后续工作。

（六）项目移交。

项目合作期满，项目实施机构会同有关部门负责项目移交工作，依据合同约定进行项目资产移交。移交时应对移交资产进行性能测试、资产评估和登记入账，并按照国家统一的会计制度进行核算。项目资产符合合同约定的，项目实施机构会同有关部门与社会资本进行资产交接，项目资产不符合合同约定移交标准的，社会资本方应采取补救措施或赔偿损失。项目移交完成后，市财政局应会同行业主管部门对项目产出、成本效益、监管成效、可持续性、PPP模式应用等方面进行绩效评价，评价结果作为政府工作决策参考依据。

五、政策保障机制

（一）强化组织协调，明确部门分工。市政府成立政府和社会资本合作工作领导小组（以下简称“市PPP工作领导小组”）统一协调全市PPP工作，领导小组下设办公室，办公室设在市发展改革委，负责协调推进与PPP项目实施相关的各项工作。

1.市政府和社会资本合作工作领导小组，组织领导全市PPP工作，协调解决重大问题，研究部署重大政策，审议决定市本级PPP项目的选定和实施。

2.市发展改革委履行市PPP工作领导小组办公室职责，承担市PPP领导小组办公室日常工作。提出完善PPP工作体制机制的建议，会同有关部门开展项目的规划、储备、发布和申报工作，组织编制市本级PPP项目年度实施计划，指导行业主管部门开展PPP项目实施方案，组织开展PPP项目实施方案联合评审工作。

3.市财政局负责与上级财政部门沟通协调PPP相关工作，组织开展物有所值评价审查、财政承受能力论证报告编制及审查、政府采购监管等工作，落实中央财政和省财政有关奖补政策，对PPP项目涉及的财政补贴实行预算管理等。建设、管理市级专家库、专业咨询服务机构库，符合入库条件的办理项目财政综合信息平台入库事宜，组织开展绩效评价工作。

4.市PPP服务中心协助市PPP工作领导小组办公室开展工作，具体承办市级PPP工作咨询培训、调度发展改革委项目库重点项目、指导项目单位策划项目，搭建PPP项目交流推介平台，向市PPP工作领导小组办公室提供保障服务。

5.市规划局、市国土资源局、市政府法制办、市政府金融办、市国资委等政府职能部门依法依规履行 PPP 项目的指导、服务、监管等职责。

6.根据政府授权，行业主管部门或事业单位可以作为PPP项目实施机构。

（二）优化发展环境。加强全社会信用体系建设，完善投资者保护政策，及时兑现各类承诺和合同约定，维护社会资本投资人的合法权益。规范PPP项目配套措施，创新PPP项目金融支持政策，引导金融机构加大对社会资本参与项目的信贷支持力度。

（三）加强监督管理。政府方应从项目识别、准备、采购、执行、移交等全生命周期参与监督管理，按照诚信履诺的要求，加强信用体系建设，强化社会资本的自律约束，形成政府监管部门、投资者、社会公众等共同参与的监督机制。

（四）注重宣传引导。要充分利用各类媒体，采取多种形式做好政策解读和成果推广，增进政府、社会和市场主体共识，营造推广运用PPP模式的良好舆论环境。

本办法自发布之日起施行，试行期限一年。
