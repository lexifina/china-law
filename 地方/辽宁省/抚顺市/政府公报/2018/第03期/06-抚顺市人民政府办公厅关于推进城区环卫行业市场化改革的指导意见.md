# 抚顺市人民政府办公厅关于推进城区环卫行业市场化改革的指导意见

抚政办发〔2018〕63号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

为贯彻落实市委、市政府关于加快推进环卫行业市场化改革的要求，推进统一开放、有序竞争、运转高效的环卫作业服务市场体系，提高环卫管理水平，经市政府同意，现就有关事项提出如下意见。

一、改革目标

按照市委、市政府关于在我市推进环卫行业市场化改革工作的要求，进一步探索完善环卫工作管理机制，以实现环境卫生“管理科学化、服务社会化、运作市场化”为目标，引入市场竞争机制和政府购买服务模式，构建“事企分开、管干分离、重心下移、市场运作”的环卫运行新模式和管理新机制，逐步建立开放、竞争、有序的环卫行业市场体系，形成作业企业化、运行市场化、投资多元化、监管规范化的环卫行业发展新格局。

二、改革原则

（一）坚持管干分离，市场运作的原则。各城区、开发区环卫主管部门逐步改变既负责扫保作业，又实施检查考核的管理模式，转为管理部门，负责制定标准、监督考核、检查指导等工作；企业负责提供环卫作业及冬季除运雪等服务。

（二）坚持公开透明，规范招标的原则。各城区、开发区作为本区域环卫作业项目的发包主体，要本着“公开透明、程序规范，市场运作、效能优先”的原则，通过公开招标，确定环卫作业服务企业。

（三）坚持“预算与产出结果挂钩”的原则。环卫作业经费投入应重在结果，即要按照作业量进行测算，又要合理测算成本，从而明确投入与需要产出的差距。各城区、开发区根据自身的财政状况相应进行投入，保证环卫作业改革的顺利实施。

（四）坚持妥善安置、确保稳定的原则。推进环卫行业市场化改革工作，是落实市委、市政府深化体制改革的重要举措，各城区、开发区要针对我市环卫系统事业编制人员的实际，切实做好环卫行业市场化改革过程中的人员安置工作，通过合同约定和强化履约监管，保证队伍稳定、待遇不降低，确保平稳过渡。

三、改革范围和服务项目

（一）改革范围。抚顺市主城区全区域，即新抚区、望花区、东洲区、顺城区，抚顺经济开发区。

（二）服务项目。

1. 城市道路（含道路两侧墙根范围和道路两侧立面间区域）、人行天桥、地下通道、铁路沿线（城市段）、绿地（含分车绿化带）的清扫保洁及机械化洗扫、冲洗作业；冬季除运雪作业；生活垃圾收集运输作业；环卫设施管养作业（公厕、垃圾中转站、垃圾箱、果皮箱、道路交通隔离栏等）；无主建筑、装修垃圾和下水清掏物的清理作业；

2. 非物业住宅小区清扫保洁作业（含小区甬道、公共庭院、绿地、游园）；冬季除运雪作业；垃圾收集作业及环卫设施配套。

3. 辖区内主要街道及主要街道沿线建筑物的大小粘贴、广告清理工作。

4. 各种迎检、重大活动的保障任务和突发应急事项的处理。

5. 市、区环卫主管部门负责新建垃圾处理场（分拣场）、机扫车辆清灰场、垃圾压缩中转站、公厕、环卫工人休息室、果皮箱等环卫基础设施的建设，各城区、开发区可根据实际扩展服务项目和范围，或实施城乡环卫一体化改革。

四、改革措施

（一）推行公开招标。

市环卫主管部门结合我市创城标准，制定统一的环卫作业规范及考核标准。各城区、开发区要设定投标企业资格条件，投标企业要具有与环卫作业相匹配的机械化潜在购买能力和企业规模，具备较强的专业技术、组织能力以及良好的投融资能力（或设备自产能力）和智能化监管体系建设能力，同时原则上须在3个（含）以上城市从事环卫行业市场化服务或500万平方米以上的单个运营项目服务，且取得优秀业绩。

各城区、开发区结合作业总量，一般以1个标段进行招标采购，承包作业期限采用“5+3”政府购买服务模式。服务协议包括服务范围、作业规范、作业标准、考核标准、退出机制等内容，特别要纳入安全生产重大活动保障任务和环卫突发应急处置事项等内容，并将其作为退出机制的重要考核内容。

（二）安置环卫人员。

各城区、开发区政府要在确保稳定的前提下做好人员安置工作。市场化改革范围内的事业身份在职人员自愿选择保留或放弃事业身份进入企业，或通过转岗等多种渠道进行安置；离退休人员的经费按照现行办法管理，按原渠道支付退休费等；劳动合同制人员转入中标企业，执行企业薪酬待遇，在不低于原工资标准的基础上稳中有升（不低于本地区最低工资标准），并在协议中明确薪酬、公积金、保险等待遇执行标准和过度保护期等条件，确保人员权益得到保障、队伍稳定。改革期间，改革单位要冻结事业编制，停止人员调入、职务调整、职称评定和岗位聘用。

（三）强化部门监管职能。

市、区环卫主管部门要强化对中标企业的运行监管。市环卫主管部门制定监管考核标准、退出机制等，将城市可机扫道路机扫率85%以上、垃圾密闭贮存、转运、运输率98%和公厕完好开放率95%以上等指标作为环卫作业标准。市、区环卫主管部门要整合原有机构，组建市、区两级环卫监管考核队伍及建立社会监督机制，负责对中标企业的环卫作业情况进行监督考核验收，督促中标企业高效履行合同约定，确保区域环卫质量显著提升。根据考核结果，全市每年评选年度优质服务企业，并将其作为企业下届招标的加分条件。

（四）行政事业单位国有资产处置管理。

1. 动产处置管理。对于现有的环卫作业车辆和设备，属行政事业单位资产的，要依法依规履行化为经营性资产手续。做好资产划拨工作及管理。经专业评估机构评估后，可转让、租赁或以实物参股。

2. 不动产处置管理。可利用的停车场、车库、办公楼等环卫公共设施可租赁或交付企业使用、维护和管养；环卫工人休息室、公厕、小型压缩站、果皮箱等无法取得经营收入的环卫公共设施交付企业使用和维护、管养，其维护费用计入企业作业成本。区国资部门对国有资产实施监管，确保国有资产保值增值。环卫主管部门负责行业指导、考核、管理等。

（五）建立经费保障体系。

环卫服务经费原则资金渠道、现有基数、拨款方式不改变。对增加作业项目、作业量和提高作业标准的企业，充分考虑其管理成本（人员、物耗、机械、管理、安全生产等费用）、设施设备折旧费、税费以及合理利润空间（以5年期贷款利率为准）等因素，遵循质价等同原则，经市、区环卫主管部门和市、区财政部门核定后，将增量经费同步纳入环卫服务费，由市、区财政按比例共同承担。各城区、开发区环卫主管部门根据中标企业的考核结果和合同约定，及时支付相关经费。中标企业要建立环卫人员工资保障（增长）制度，确保环卫人员待遇稳中有升。

五、实施步骤

（一）准备和制定方案阶段（2018年6月15日前）。由市政府环卫行业市场化改革领导小组召开会议，下发“抚顺市城区环卫行业市场化改革指导意见”，明确任务，部署工作；各城区、开发区根据指导意见，制定本地区环卫行业市场化改革实施方案，并经区委常委会议通过后，报市政府环卫行业市场化改革领导小组审核批准。

（二）测绘评估和成本测算阶段（2018年6月16日—2018年7月15日）。各城区、开发区通过公开招标或直接委托程序，确定第三方测绘机构，对辖区范围内的市政道路及设施进行测绘，测算环卫作业面积和居民小区作业面积，确定合作边界；在测绘明确的作业量基础上，开展测算作业成本、标段划分、拦标价测算等工作，同时开展人员流向摸底、现有设施设备清产核资和评估工作，以及标段作业明细的上报审核工作。

（三）招标采购阶段（2018年7月16日—2018年8 月15日）。各城区、开发区办理招标立项手续，完成代理机构委托、上网公示、开标前答疑等工作，完成公开招采购标工作。

（四）组织实施阶段（2018年8月16日—2018年9月20日）。各城区、开发区环卫主管部门与中标企业签订合同，完成项目公司注册，协助企业进行人员和相关业务对接工作。

六、组织保障

（一）加强组织领导。成立抚顺市环卫行业市场化改革工作领导小组，指导、组织、协调全市环卫行业市场化改革工作，督促各城区全力推进环卫行业市场化的进程。由市政府主要领导任组长，分管领导和副秘书长任副组长，成员单位包括市城管局、市人力资源社会保障局、市财政局、市住房城乡建设委、市国资委、市发展改革委、市编委办、市政府法制办、市营监局和各城区政府、经济开发区管委会。领导小组办公室设在市城管局，负责日常统筹协调工作，办公室主任由城管局主要领导担任。各城区、开发区要充分认识环卫行业市场化改革的重要意义，将此项工作纳入区域创新改革工作内容，成立相应的组织机构，妥善处理各种矛盾和问题，认真组织开展好辖区内环卫行业市场化改革工作。

（二）坚持市场导向。坚持“公开、公平、公正”的原则，将作业质量作为中标企业重要的考核标准，完善市场竞争机制，防止恶意低价竞争，充分运用法律、经济、行政措施，加强监督管理，逐步建立完善我市环卫服务企业信用体系。

（三）强化履约监督。各县区要严格督促中标企业高效履约，强化对日常作业的监督检查，不断梳理和完善合同条款的约定内容，切实通过市场化改革促进我市环境卫生质量不断提高。
