# 抚顺市人民政府办公厅关于印发2018中国（抚顺·新宾）满族风情国际旅游（旗袍）节活动方案的通知

抚顺市人民政府办公厅关于印发

2018中国（抚顺·新宾）满族风情

国际旅游（旗袍）节活动方案的通知

抚政办发〔2018〕64号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

经市政府同意，现将《2018中国（抚顺·新宾）满族风情国际旅游（旗袍）节活动方案》印发给你们，请认真组织实施。

抚顺市人民政府办公厅

2018年6月15日

（此件公开发布）

2018中国（抚顺·新宾）满族风情

国际旅游（旗袍）节活动方案

为进一步提升中国十佳魅力城市的影响力，推动《魅力中国城》成果转化，促进抚顺旗袍产业发展，抚顺市人民政府决定，举办2018中国（抚顺·新宾）满族风情国际旅游（旗袍）节。

一、主办单位和活动时间

本届旅游（旗袍）节由中国纺织服装协会、中国服装设计师协会为支持单位，辽宁省旅游发展委员会、辽宁省纺织服装协会、盈科旅游、抚顺市人民政府共同主办，时间为6月23日至10月10日。

二、活动主题

本届旅游（旗袍）节将本着热烈、节俭、实效的原则，以“走进中国十佳魅力城市 领略一极六峰”为主题，充分展示抚顺特色文化，宣传丰富的旅游资源，重点推介“旗袍故里”品牌，扩大招商引资，促进城市转型振兴。

三、活动内容

（一）2018中国（抚顺·新宾）满族风情国际旅游（旗袍）节开幕式

活动时间：2018年6月23日（周六）19∶00

活动地点：新宾赫图阿拉城景区汗宫大衙门

活动内容：开幕仪式。包括：领导致辞，播放满族民俗、城市风光宣传片，“旗袍故里”杯全国旗袍摄影大赛启动仪式，“旗袍故里”杯国际旗袍模特大赛。

支持单位：中国服装设计师协会、中国纺织服装协会
