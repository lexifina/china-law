# 抚顺市人民政府办公厅关于加强我市列入不可移动文物名录具有重要历史价值工业遗产保护的通知

抚顺市人民政府办公厅关于

加强我市列入不可移动文物名录

具有重要历史价值工业遗产保护的通知

抚政办发〔2018〕85号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各有关企事业单位：

抚顺是我国重要的老工业基地，工业基础雄厚，集中了煤、油、电、钢、铝、军工、装备制造等一批关系国计民生和国家安全的基础产业。随着产业升级，近年来，老工业区绝大部分企业随着市场经济的发展，所拥有的工业设施设备逐步退出历史舞台，但其遗址却彰显出工业遗产价值。

抚顺市也是日本帝国主义对华进行军事侵略和经济掠夺的典型城市。目前仍存的一批日伪时期重要建筑物、构筑物，记录了日本帝国主义对我市人民进行经济掠夺和抚顺军民奋起反抗日本殖民统治斗争的历史。

保护好这些记载抚顺百年工业史的建筑、构筑物及附属设施，一方面具有以史为鉴、警示后人和对全市人民进行爱国主义教育的重要作用。另一方面，这些象征抚顺老工业基地辉煌，并具有传承历史价值的工业遗产，因其承载历史、凝结精神，而具有了传承文化、凝聚人心的公共作用。

为加强对我市已列入不可移动文物名录，且现存具有重要工业遗产价值的建筑、构筑物及附属设施的保护，经市政府同意，现就相关事宜通知如下：

一、各县、区人民政府，市政府各部门和相关企事业单位要提高文物保护意识，制定措施，落实责任，共同做好这批具有重要工业遗产价值的建筑、构筑物及附属设施的保护工作。各相关单位的主要负责人是保护的第一责任人，要切实履行保护义务。

二、对已经公布为各级文物保护单位的工业遗产，产权所有者或所在地方政府要严格按照《中华人民共和国文物保护法》履行保护责任。如龙凤矿竖井、萝卜坎炼铁炉、满铁抚顺病院旧址、炭矿俱乐部旧址、高等女学校旧址、七条小学旧址、炭矿事务所旧址、东林园日式小楼要保护好。

三、各有关单位没有法定依据或不遵守法定程序的，不得擅自拆除（包括内部设施）、改建或变卖，违者追究有关责任人的责任。文保、公安等部门要加大巡查力度，发现问题及时处置。

附件：我市现存具有重要工业遗产价值的建筑、构筑物及附属设施保护名单

抚顺市人民政府办公厅
