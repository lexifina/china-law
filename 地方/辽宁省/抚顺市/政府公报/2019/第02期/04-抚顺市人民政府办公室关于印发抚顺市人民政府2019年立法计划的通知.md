# 抚顺市人民政府办公室关于印发抚顺市人民政府2019年立法计划的通知

抚顺市人民政府办公室关于印发

抚顺市人民政府2019年立法计划的通知

抚政办发〔2019〕12号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

为深入贯彻落实习近平总书记在辽宁考察时和在深入推进东北振兴座谈会上重要讲话精神，根据党中央、国务院《法治政府建设实施纲要（2015—2020年）》，市政府制定了抚顺市人民政府2019年立法计划，现印发给你们，同时提出以下要求，请一并按照执行。

一是加强组织领导，保障立法工作有序、高效进行。各县区政府、市政府有关部门要高度重视立法计划实施工作，在市委的坚强领导和市人大常委会的主导下，把地方性法规草案和规章草案起草、调研等工作，作为重要工作抓紧抓实，加强协调配合，形成工作合力，保证立法项目顺利完成。

二是坚持科学民主立法，提高立法工作水平。在草案起草过程中，坚持问题导向，对拟解决的问题、制度设计、管理措施等认真论证分析，切实增强立法的针对性、实效性和可操作性。广泛征求社会意见建议，拓宽群众有序参与立法的渠道，认真研究吸纳各方面意见建议，确保立法最大限度集中民智、反映民意。

三是起草部门要把立法工作纳入本单位重要议事日程，成立起草小组、制定工作方案、明确工作进度、抓好工作落实，确保送审稿高质量如期完成。立法工作中涉及的重大问题，主要领导要亲自过问，积极协调。起草部门要主动向市人大汇报立法工作情况，邀请市人大相关专门委员会和法制工作委员会提前介入指导、参与法规草案的调研、论证、起草工作。市司法局要组织好年度立法计划的实施，加强对立法草案起草工作的督促指导，对起草部门报送的送审稿要严格审查，确保立法草案质量。

抚顺市人民政府办公室

2019年4月17日

（此件公开发布）
