# 抚顺市人民政府办公室关于公布抚顺市征地区片综合地价标准的通知

抚顺市人民政府办公室关于公布

抚顺市征地区片综合地价标准的通知

抚政办发〔2019〕11号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府有关部门、有关直属单位：

《抚顺市征地区片综合地价标准》（以下简称“《标准》”）已经市政府同意，现公布实行。

一、《标准》适用于抚顺市行政区域范围内（沈抚新区管理范围除外）的征收补偿。

二、《标准》是指法律规定征收农用地的土地补偿费和安置补助费之和。基准对象为一般农用地。以此为基础，按照集体建设用地1.0、未利用地0.8、基本农田1.1系数进行调整。在实施征收中不得降低补偿标准。

三、被征收土地上有附着物和青苗的，对地上附着物和青苗的所有权人应另行补偿，补偿标准按照有关规定执行。

四、依法收回国有农场土地使用权的补偿和职工安置按照《国土资源部 农业部关于加强国有农场土地使用管理的意见》（国土资发〔2008〕202号）有关规定执行。

五、建设项目施工和地质勘查等需要临时使用集体土地、国有农用地和未利用地，每年按征地区片综合地价标准的15%给予补偿。

六、各县区政府应当通过多种方式公布新的征地区片综合地价标准，加强政策宣传解释工作，妥善解决实施中的有关问题，确保新的征地区片综合地价标准顺利实施。

七、本通知自发布之日起实施。
