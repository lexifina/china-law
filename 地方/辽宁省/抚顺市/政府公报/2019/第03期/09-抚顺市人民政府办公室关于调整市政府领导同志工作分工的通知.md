# 抚顺市人民政府办公室关于调整市政府领导同志工作分工的通知

抚顺市人民政府办公室关于

调整市政府领导同志工作分工的通知

抚政办发〔2019〕26号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

根据机构改革职能调整和部分领导同志工作变动情况，市政府研究决定，对市政府领导同志工作分工进行调整，调整后的工作分工如下：

一、市长

杨 维：领导市政府全面工作，负责审计工作。

分管市审计局。

二、副市长

蒲信子：负责市政府常务工作。负责发展改革、财税、自然资源、林业、城乡建设、应急管理、信访、统计、金融、营商环境建设、督查考核、行政审批、粮食储备和物资流通、能源、产业引导基金管理、行政资源整合项目建设等方面工作。负责抚顺经济开发区工作，牵头推进争创国家级开发区、国家级生态文明先行示范区工作，负责分管领域国有资产管理和国有资本经营工作。

分管市发展改革委（粮食和储备局、能源局）、财政局、自然资源局（林草局）、住房城乡建设局（人防办）、应急管理局（煤矿安监局）、信访局、统计局、金融发展局、营商局（行政审批局、政府督考办）、行政学院、财政发展服务中心（市社会保障基金理事会）、先进装备制造业发展促进中心（抚顺经济开发区综合服务中心）、自然资源事务服务中心（采煤影响区综合治理和开发利用中心、不动产登记与房屋交易中心）、应急服务中心、林业发展服务中心、住房公积金管理中心、城市建设发展促进中心、城建投资有限公司、财金投资控股公司、生态加产业管理有限公司、国际工程咨询集团、园林绿化集团、供水集团、热力集团。

联系市人大、政协、纪委监委机关、各民主党派、税务局、金融保险单位、国家统计局抚顺调查队、驻抚部队。

程国慧：负责市场监管、知识产权方面工作。牵头推进2024年全国冬运会申办、标准抚顺建设和国家食品安全示范城市创建工作，协助推进冰雪旅游产业发展、“魅力中国城”成果转化等专项工作，负责分管领域国有资产管理和国有资本经营工作。

分管市市场监管局（知识产权局）、技术创新研究院（检验检测认证中心）。

联系市民族宗教事务局、工商联、文联、抚顺日报社。

臧 红：负责民政、文化旅游和广播电视、体育、文物管理、卫生健康和中医药管理等方面工作。牵头推进全民运动健身模范市（县、区）、国家卫生城市创建和冰雪旅游产业发展、“魅力中国城”成果转化工作，负责分管领域国有资产管理和国有资本经营工作。

分管市民政局、文化旅游和广电局（体育局、文物局）、卫生健康委（中医药局）、广播电视台、红十字会和市社会福利保障中心、老年事业发展服务中心、卫生健康服务中心、文化旅游发展促进中心、体育事业发展中心（冰雪产业发展促进中心）、文体旅集团。

联系市新闻出版局（版权局）、残联、社科院、档案馆、慈善总会。

孟祥斌：负责公安、司法和突发群体性事件处置等方面工作。负责分管领域国有资产管理和国有资本经营工作。

分管市公安局、司法局、市民权益保障中心。

联系市法院、检察院、国家安全局。

朱光明：负责交通运输、水利、农业农村、扶贫开发、供销等方面工作。牵头推进第一产业发展和浑河滨水生态经济带建设，牵头推进沈白客运铁路专线建设，负责分管领域国有资产管理和国有资本经营工作。

分管市交通运输局、水务局、农业农村局、扶贫办、供销社和市交通运输发展服务中心、现代农业及扶贫开发促进中心（市轻工业发展促进中心）、公交公司。

联系市气象局、铁路运输企业。

王金华：负责科技、工业和信息化、生态环境、商务和外事、国有资产监管、民营经济等方面工作。统筹推进全市招商引资工作，牵头推进第二、三产业发展和南环现代工业产业带建设，负责分管领域国有资产管理和国有资本经营工作。

分管市科技局（外国专家局）、工业和信息化局（国防科工办）、生态环境局、商务局（政府外事办）、国资委、生态环境保护促进中心（河流环境保护服务中心）、大数据应用中心、龙晟集团，负责市经济合作发展服务中心的招商引资工作。

联系市总工会、台办、侨联、台联、辽宁石化大学、煤科院沈阳研究院、抚顺石油化工研究院、沈阳海关抚顺办事处、烟草专卖局、大伙房水库管理局、邮政、科协、老科技工作者协会及石化、矿业、电力通讯、军工等省中直企业。

朱祥霖：负责教育、人力资源社会保障、退役军人事务、医疗保障、就业等方面工作。牵头推进先行先试工作，负责分管领域国有资产管理和国有资本经营工作。

分管市教育局、人力资源社会保障局、退役军人事务局、医疗保障局、市属院校、教育发展服务中心、就业和人才服务中心、社会保险事业服务中心。

联系团市委、妇联。

张百祥：负责国家级高新技术产业开发区、可持续发展议程创新示范区、省级开发区创建和石蜡产业基地建设等工作，负责分管领域国有资产管理和国有资本经营工作。

分管市高新技术产业开发区、工业园区、石蜡基地；协助分管财税、科技工作。

三、秘书长

张文献：协助市长处理市政府日常工作，协调市政府副秘书长的工作。协助市长分管市政府办公室（政府研究室、机关事务管理局），协助常务副市长推进督查考核工作。分管市政府驻外联络处，直接负责驻京联络处业务管理与考核。代管市公共资源交易中心、经济合作发展服务中心。联系市政府新闻办。
