# 抚顺市人民政府办公室关于印发抚顺市推进政务新媒体健康有序发展实施方案的通知

抚顺市人民政府办公室关于印发抚顺市推进

政务新媒体健康有序发展实施方案的通知

抚政办发〔2019〕38号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

经市政府同意，现将《抚顺市推进政务新媒体健康有序发展实施方案》印发给你们，请认真贯彻执行。

抚顺市人民政府办公室

2019年9月26日

（此件公开发布）

抚顺市推进政务新媒体健康有序发展实施方案

为深入贯彻落实《国务院办公厅关于推进政务新媒体健康有序发展的意见》（国办发〔2018〕123号）、《辽宁省人民政府办公厅关于推进政务新媒体健康有序发展实施方案的通知》（辽政办发〔2019〕24号）精神，结合实际，制定本实施方案。

一、工作目标

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，坚持“正确导向、需求引领、互联融合、创新发展”基本原则。

2019年，市、县区政府开设政务新媒体，市政府部门及其他单位可根据工作需要规范开设新媒体，政务新媒体管理体制机制基本理顺。

到2020年，建成以市政府门户网政务新媒体为龙头，各县区、各部门政务新媒体为主体的整体协同、响应迅速的矩阵体系。

到2022年，全市政务新媒体传播力、引导力、影响力、公信力全面升级，成为更加权威便捷的信息发布、解读回应、政民互动和办事服务平台。

二、工作任务

（一）加强发布解读回应。推进“五公开”（决策、执行、管理、服务和结果)和重点信息发布工作；重点发布财政预决算、公共资源配置、社会公益事业建设等领域信息；积极推进决策前广泛征求意见；精准解读重大政策文件和涉及群众切身利益、需要公众广泛知晓的政府信息，解读形式要多样化；把政务新媒体作为突发公共事件信息发布和政务舆情回应、引导的重要平台，根据事件发展和工作进展及时发布动态信息；对公众关注的热点问题，及时作出权威正面回应，阐明政策，解疑释惑。（责任单位：各县区政府，市政府各部门）

（二）强化公众参与互动。规范政务新媒体做好公众留言审看发布、处理反馈工作，回复留言依法依规、态度诚恳、严谨周到；加强与业务部门沟通协作，对于群众诉求限时办结、及时反馈；进一步做优做强主账号，建立集信息发布、政民互动、为民服务于一体的综合性政务平台。（责任单位：各县区政府，市政府各部门）

（三）掌上服务工作。以民生事项为重点，推动更多事项“掌上办”；围绕利企便民，着力推进政务新媒体与全市一体化在线政务服务平台的业务联动，实现数据同源、服务同根，为公众提供办事指引和办事渠道，增强新媒体办事功能；梳理与群众日常生产生活密切相关的民生事项，制定“掌上办”服务事项清单，在市政府门户网站、抚顺政务服务网以及政府网站同步公开，并实行动态调整更新。（牵头单位：市营商局；配合单位：各县区政府，具有政务服务职能的市政府部门）

三、运维管理

（四）开设整合。各县区政府和市政府部门应当开设政务新媒体；一个单位在同一平台只开设一个政务新媒体账号；集中力量做优做强一个账号，构建政务新媒体矩阵体系；政务新媒体命名要简洁规范，与主办单位工作职责相关联，在公开认证信息中标明主办单位名称，主办单位在不同平台上开设的政务新媒体名称应保持一致；开展移动客户端等应用系统建设，全面支持IPv6；各级政府和部门开设、变更、关停、注销政务新媒体应向同级政府办公部门备案，市和县区政府应向上一级政府办公部门备案，主办单位发生变化，应及时注销或变更账号信息，并向社会公告；2019年9月底前，对功能相近、用户关注度和利用率低的政务新媒体进行清理整合，确属无力维护的要坚决关停。（牵头单位：市政府办公室、市大数据应用中心，配合单位：各县区政府，市政府各部门）

（五）内容发布。建立信息发布审核制度，按照“谁发布、谁审核”的原则，明确审核主体、审核流程，严把政治关、法律关、政策关、保密关、文字关，发布信息具有时效性、准确性和权威性；建立规范转载制度，原则上只转载党委和政府网站以及有关主管部门发布的信息，不得擅自发布代表个人观点、言论以及商业广告；严禁购买“粉丝”等数据造假行为；建立信息内容更新制度，市、县区政府要确保做到每个工作日对政务新媒体发布内容进行更新，市政府各部门要确保每周更新不少于2次。（责任单位：市政府办公室、各县区政府、市政府各部门）

（六）安全防护。严格执行网络安全法等法律法规，落实安全管理责任，建立健全安全管理制度、保密审查制度和应急预案，提高政务新媒体安全防护能力；加强监测预警和应急处置，账号密码应由专职人员管理，防止发生账号被盗用或被恶意攻击等安全事件；对假冒政务新媒体，要立即关停。（责任单位：各县区政府，市政府各部门）

（七）监督管理。按照《政府网站与政务新媒体检查指标》要求，进一步加强政务新媒体的日常监管，定期组织检查，积极运用技术手段进行实时监控，及时通报、督促整改存在的突出问题。（责任单位：各县区政府，市政府各部门）

四、工作保障

（八）组织领导。各县区、各部门要充分认识做好新时期政务新媒体工作的重大意义，将其纳入重要议事日程，主要领导亲自抓、负总责，明确分管负责人，配齐配强工作人员，提供专项经费；建立健全协调机制，共同做好发布引导、舆情应对、网络安全等工作。

（九）责任落实。市政府办公室是全市政务新媒体工作的主管单位，各县区政府办公室是本地区政务新媒体工作的主管单位，市政府各部门办公室是本部门政务新媒体工作的主管单位。主管单位负责推进、指导、协调、监督政务新媒体工作；行业主管部门要加强对本行业承担公共服务职能的企事业单位新媒体工作的指导和监督；市大数据应用中心负责全市政务新媒体运行监测和评估的技术服务工作。

（十）队伍建设。将政务新媒体工作纳入领导干部和公务员教育培训重要内容，着力强化运用政务新媒体履职能力。市政务新媒体主管单位将每年至少组织一次业务培训，确保到2020年对所有从事政务新媒体工作人员轮训一遍，打造一支政治立场坚定、熟悉政策法规、掌握传播规律的专职干部队伍。

（十一）考核评价。各县区、各部门要将政务新媒体工作情况纳入年度绩效考核，制定考核评价办法；积极推进政务新媒体工作，认真总结典型经验做法报送市政府办公室。
