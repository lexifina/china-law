# 抚顺市人民政府办公室关于印发抚顺市人民政府2020年立法计划的通知

抚顺市人民政府办公室关于印发

抚顺市人民政府2020年立法计划的通知

抚政办发〔2020〕13号

各县、区人民政府，抚顺经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

为深入推进法治政府建设，充分发挥立法在深化改革、促进发展、保障民生等方面的服务引领作用，经市委、市政府同意，现将抚顺市人民政府2020年立法计划印发给你们，请按照以下工作要求认真执行。

一、坚持科学民主立法，提高立法工作水平。在草案起草、立法后评估过程中，坚持问题导向，对拟解决的问题、制度设计、管理措施等认真论证分析，切实增强立法的针对性、实效性和可操作性。广泛征求社会意见建议，拓宽群众有序参与立法的渠道，认真研究吸纳各方面意见建议，确保立法最大限度集中民智、反映民意。

二、加强组织领导，保障立法有序进行。立法草案起草单位、立法后评估负责单位要把立法、评估工作纳入本单位重要议事日程，成立起草、评估小组，制定工作方案、明确工作进度、抓好工作落实，确保立法草案送审稿、立法后评估报告高质量如期完成。立法工作中涉及的重大问题，主要领导要亲自过问，积极协调。

三、积极联系沟通，争取工作指导支持。由市政府提案的地方性法规项目，按照市人大常委会2020年立法计划工作安排执行，起草单位要主动向市人大汇报立法工作情况，邀请市人大相关专门委员会和法制工作委员会提前介入指导、参与法规草案的调研、论证、起草工作。

四、统筹协调推进，确保立法计划完成。市司法局要抓好年度立法计划的组织实施，强化进度管理。对立法草案起草和立法后评估工作要加强督促检查和协调指导。对报送的立法草案送审稿要抓紧组织审查，及时提请市政府常务会议审议。

抚顺市人民政府办公室

2020年4月13日

（此件公开发布）

抚顺市人民政府2020年立法计划

2020年，市政府安排立法项目共12项。其中，立法计划项目4项，立法调研项目3项,立法后评估项目5项。具体项目安排如下：

一、立法计划项目

1. 制定《抚顺市直管公房管理规定》

起草单位：市住房城乡建设局

2. 制定《抚顺市城市供热收费管理规定》

起草单位：市住房城乡建设局

3. 制定《抚顺市政府规章制定办法》

起草单位：市司法局

4. 修改《抚顺市城市除雪规定》

起草单位：市住房城乡建设局

二、立法调研项目

1. 《抚顺市餐厨垃圾管理办法》

起草单位：市住房城乡建设局

2. 《抚顺市城市生活垃圾处理费征收管理办法》

起草单位：市住房城乡建设局

3. 《抚顺市政务信息化项目管理办法》

起草单位：市大数据应用中心

三、立法后评估项目

1. 《抚顺市地方文献呈缴办法》

负责单位：市文化旅游促进中心

2. 《抚顺市地名管理办法》

负责单位：市民政局

3. 《抚顺市渔业资源增殖保护费征收使用办法》

负责单位：市农业农村局

4. 《抚顺市机动车停泊管理办法》

负责单位：市公安局、市住房城乡建设局

5. 《抚顺市城区禁止违法建设管理规定》

负责单位：市司法局
