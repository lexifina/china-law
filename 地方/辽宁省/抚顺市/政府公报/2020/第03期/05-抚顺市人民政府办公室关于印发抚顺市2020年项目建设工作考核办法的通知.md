# 抚顺市人民政府办公室关于印发抚顺市2020年项目建设工作考核办法的通知

抚顺市人民政府办公室关于印发抚顺市

2020年项目建设工作考核办法的通知

抚政办发〔2020〕12号

各县、区人民政府，经济开发区、高新技术产业开发区管委会，市政府各部门、各直属单位：

《抚顺市2020年项目建设工作考核办法》已经市政府同意，现印发给你们，请认真按照执行。

抚顺市人民政府办公室

2020年4月14日

（此件公开发布）

抚顺市2020年项目建设工作考核办法

为进一步增强我市各县区、省级开发区、市直行业部门抓好抓实项目建设的紧迫感和责任感，落实“项目为王”的工作理念，全面客观考评全市项目建设工作，特制定本考核办法。

一、考核目的

围绕2020年全市项目建设目标任务，形成奖优罚劣、赏罚分明的考核体系；通过量化打分排名，形成鼓励先进、激励后进的氛围。建立起合纵连横、协力共进的网格化项目推进工作机制，确保完成全年项目建设目标任务。

二、考核原则

（一）全面覆盖，全过程考核原则。围绕推进项目建设进度、强化项目储备、加快“飞地经济”发展、提升园区承载力等方面进行全周期、全口径、全流程考核，步步有指标。

（二）区别对待，分类考核原则。坚持纵向考核县区、横向考核部门、突出考核开发区的原则，落实县区、开发区和市直行业部门的项目建设主体责任。

（三）实事求是，客观公正原则。考核工作坚持以数据为依据，以成效论成绩，客观科学评价考核对象，关注项目建设工作实绩和经济社会效益，做到精准、客观、可操作。

（四）日常调度，节点考核原则。围绕全市项目建设工作，做好季度排名、半年拉练、全年考核相关工作，督促相关单位时刻绷紧项目建设这根弦。

三、考核对象

（一）对各县政府列为县域组进行考核评比；

（二）对各区政府列为城区组进行考核评比；

（三）对望花经济开发区、胜利经济开发区、抚顺高新技术产业开发区列为省级开发区组进行考核评比；

（四）对市直行业部门按所属行业列为行业部门组进行考核评比。

四、考核主体

考核工作由市发改委总牵头，考核结果在全年绩效考核中的应用工作由市政府督考办牵头，对各县区、各省级开发区考核工作由市发改委联合市政府督考办、市商务局、市科技局等部门组成考核组负责，对市直行业部门考核工作由市发改委负责。

考核工作分为被考核单位自评、现场调研、检查相关资料、综合评定四个环节。

五、考核内容和方法

（一）考核内容。围绕项目建设2020年目标任务，从总量、结构、质量三个方面考核项目建设工作完成情况。

1. 总量考核，重点考核被考核单位储备项目工作、项目建设等指标总量方面完成情况。主要包括策划包装项目建议书和可研报告水平项目情况、开复工项目数量、新开工项目数量、竣工项目情况等。

2. 结构考核，重点关注项目建设结构是否优化合理，是否符合“工业立市、工业强市、产业兴市”发展战略。主要包括产业项目（非房地产）情况、飞地项目、基础设施项目、高技术项目总量占比情况等。

3. 质量考核，重点关注被考核单位项目建设投资质量。主要包括建设项目投资强度、实际完成投资占总投资比例等情况。

（二）考核方法。

建立量化指标考核体系，明确考核点、考核数据来源和评分规则，通过考核相关项得分之和计算出总分。

六、考核等次及结果运用

考核评价分为优秀、良好、一般三个等次。根据得分对各县区政府、各开发区、市直行业部门分别排名。

——县：第一、二、三名分别为优秀、良好、一般等次。。

——区：第一名评为优秀等次，最后一名为一般等次，其余为良好等次。

——省级经济开发区：第一、二、三名分别为优秀、良好、一般等次。

——市直行业部门：前两名评为优秀等次，后两名为一般等次，其余为良好等次。

——对飞地经济和园区建设工作排名第一（“项目结构和质量”考核指标中的“飞地项目”和“园区基础设施”两项积分之和）的县区政府在争取省政府奖励之外，给予一定的园区基础设施建设专项补助资金。

考核结果作为市委、市政府对县区政府、开发区、市直行业部门年终绩效考核的加分项，优秀的绩效考核总分加10分；良好的绩效考核总分加5分；对项目建设成效明显、贡献突出的单位和个人，市委、市政府给予专项奖励。

抚顺市2020年项目建设工作

考核评价指标的说明

一、项目前期工作

考核县、区、省级开发区、市直相关部门。

项目前期工作基础分为30分，完成全年项目建议书水平得基础分5分，完成全年可研报告水平得基础分10分，完成全年项目签约水平的基础分15分。在项目规模上设有加分项。

二、项目和投资总量

考核县、区、省级开发区、市直相关部门。

1. 实际开复工项目数：指已纳入统计项目库的开复工项目数量。

2. 实际开复工项目数占年度计划开复工项目数比例：指已纳入统计项目库的开复工项目（续建和新开工项目）数量与年度计划开复工项目数的比值。

3. 当年实际完成投资：指纳入统计项目库的开复工项目当年形成的有效投资，仅统计续建和新开工项目当年完成投资，竣工项目完成投资不重复计算。

4. 当年实际完成投资占年度投资计划比例：指全年实际完成投资与年计划投资比值。

5. 当年实际完成投资占总投资比例：指全年实际完成投资与全部开复工项目总投资的比值。

三、项目结构和质量

考核县、区、省级开发区。

1. 实际开工项目数：指已纳入统计项目库的各类开复工项目数量。

2. 占全年实际开复工项目总数比例：指已纳入统计项目库的各类开复工项目数与全年实际开复工项目数的比值。

3. 当年实际完成投资：指纳入统计项目库的各类开复工项目当年形成的有效投资。

4. 实际完成投资占此类项目总投资比例：指本类项目实际完成投资与此类项目总投资的比值。

5. 当年实际完成投资占全部开复工项目年度实际投资比例：指本类项目实际完成投资与本单位全部开复工项目年度实际投资的比值。

四、补充说明

1. 项目建设相关数据以纳入统计项目库数据为准，统计项目库没有统计数据的，需要被考核单位提供相关证明材料。

2. 被考核单位需要填报相关考核表并盖章确认。

3. 对于在数据或证明材料上弄虚作假的，一经查实，取消被考核单位项目建设所有得分，情节严重的报送纪检监察机关处理。

4. 本考核办法由市发展改革委负责解释。
