# 本溪市人民政府关于促进全市建筑业健康发展的意见

本溪市人民政府文件

本政发〔2014〕12号

本溪市人民政府关于促进全市

建筑业健康发展的意见

各自治县、区人民政府，本钢，市政府有关委办局、直属机构：

为推动全市建筑业又好又快发展，做大做强建筑业，市政府现就促进全市建筑业健康发展提出如下意见：

一、积极创造条件，鼓励企业做大做强

1. 加大对企业扶持力度。各级规划建设行政主管部门要会同有关部门，根据国家有关政策和全市建筑业发展现状，制定全市建筑业发展扶持计划，确定重点扶持企业。建筑业企业年产值达到20亿元（非房建施工总承包、专业承包为10亿元）的，由市政府命名为“建筑业龙头企业”；年产值达到10亿元（非房建施工总承包、专业承包为5亿元）的，由市政府命名为“建筑业骨干企业”，并在土地、税收、信贷等方面给予扶持。

2. 鼓励企业重组合并，提高竞争力。支持企业通过联合、兼并、重组等多种形式，进一步做大做强。鼓励建筑业企业与勘察设计企业联合重组，实现设计施工一体化发展。企业在联合、兼并、重组过程中涉及的土地、房产、车船等变更费用，享受转制企业有关费用减免政策。

3. 减轻建筑业企业社会保险负担。将社会保险费纳入工程建设成本，减轻建筑业企业负担。由施工企业先交纳工程造价的209%社会保险费，建设单位应根据施工企业在建设项目上被扣缴社会保险费的凭证，向施工企业支付该项费用。

4．招投标优先考虑骨干企业。市域范围内的政府投资项目，建设单位在编制招投标文件时，同等条件下优先考虑市建筑业龙头骨干企业和创省级以上（含省级）优质工程的优秀项目经理。

5. 对市级以上优秀项目经理实行政策扶持。市级以上优秀项目经理，在其承接的工程项目主体竣工后，可持工程主体验收及未拖欠农民工工资等证明继续参加投标活动。

二、鼓励企业积极开拓外埠市场

1. 积极提供信贷支持。建筑业企业在外埠承接20层以上或造价在3000万元以上的工程，凡符合信贷政策和贷款条件的，凭工程承包合同和工程施工许可证向企业注册地开户银行申请贷款，企业注册地开户银行应予以积极支持。

2. 进行企业所得税税收奖励。建筑业企业在外埠承接建设项目且企业所得税回注册地缴纳的，按该项目产生企业所得税地方留成部分的50%奖励该企业。

3. 积极进行跟踪服务。构建实施“走出去”战略信息服务平台，规划建设行政主管部门和行业协会要紧密跟踪、及时发布国内外建筑市场的发展趋势和建筑业发展的各项法规政策，以及国内外重点区域建筑市场的需求动态，为企业寻求商机、开拓市场提供实时、动态、网络化的信息服务。同时，要充分发挥行业协会作用，主动与外埠市场的当地规划建设行政主管部门沟通，更好地为我市建筑业企业服务。

三、鼓励和扶持企业提升资质等级，拓宽经营渠道

1．大力提升企业综合实力。大力扶持全市有实力的建筑业企业资质等级上台阶、企业规模上水平，使其尽快做大做强做专。要尽快发展一批资金雄厚、人才密集、技术先进、资质类别齐全的大型企业集团，充分发挥其龙头和辐射带动作用。

2．实现多种经营，拓宽经营渠道。推动中小企业向“专、精、特、新”发展，促进有实力的骨干企业向市政、园林、道桥等国家重点投资方向发展。要切实做到让建筑业企业有质的提升和量的飞跃，逐步形成高端与低端、主营与兼营多业并举、共同发展的产业新格局。

3. 培养和打造建筑业领军企业。积极支持本钢建设有限责任公司及所属企业组建晋升特级企业，使其成为本溪市建筑业领军企业，更好地发挥引领作用，开拓更大的建筑市场。同时，要培养一批高素质的领军人物，打造一批知名度高、影响力大、技术过硬、诚实守信的企业，为全市建筑业发展提供强大的智力支撑和品牌保障。要把培植龙头企业作为全市加快建筑业发展的重要抓手，集聚优势资源、扩大企业规模、提高资质等级。重点扶持冶金、矿山、公路、钢结构、设备安装等优势建筑业企业，扩大经营规模，提升综合实力。

4. 大力发展装饰装修业。要加强装饰装修市场管理，尤其是要规范家庭装饰装修市场。同时，要做好装饰装修产值的统计工作，增加装饰装修行业对建筑业的贡献率。

四、实施品牌战略，确保建设工程质量和施工安全

1. 积极鼓励工程质量创优活动。要认真贯彻执行《本溪市建设工程质量创优奖励暂行规定》，对获得国家“鲁班奖”的项目奖励100万元；对获得国家“鲁班奖”提名奖的项目奖励50万元；对获得省“世纪杯”的项目奖励20万元；对获得市“天女木兰杯”的项目奖励10万元。对施工企业获得的质量创优奖励要通过媒体予以公布，提高企业的创优意识和积极性，促进全市建设工程质量整体水平提高。同时，要按照市城乡规划建设委和市总工会《关于对获得国家和省、市优质工程奖授予相关荣誉称号的决定》（本建发〔2013〕41号）规定，对获得国家“鲁班奖”工程的项目经理，授予其相应的荣誉称号；对获得国家“鲁班奖”的施工单位，授予其本溪市优秀施工企业和工程质量管理先进单位等荣誉称号，并推荐争创国家级和省级荣誉称号。

2. 确保建设工程安全生产。加强安全文明施工管理，建设单位要足额交纳安全文明施工措施费，施工企业要保证有20%的费用用于安全生产设备和设施的更新维护。

五、加快人才培育和引进

1. 宣传和鼓励报考建造师。要加大对一、二级建造师的报考宣传力度，人社部门要积极鼓励和支持我市建筑领域有更多的专业技术人员参加报考并取得建造师资格，扩大建造师队伍，为建筑业企业资质升级和发展创造条件，力争每年建造师考试通过率增加15%。

2. 实施人才战略。通过本溪人才网建造师专业人员的人才流动信息平台，为企业牵线搭桥，促进人才流动。

本溪市人民政府
