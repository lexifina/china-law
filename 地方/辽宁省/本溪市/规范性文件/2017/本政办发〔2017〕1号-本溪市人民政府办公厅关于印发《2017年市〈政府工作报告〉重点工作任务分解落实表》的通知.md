# 本溪市人民政府办公厅关于印发《2017年市〈政府工作报告〉重点工作任务分解落实表》的通知

本溪市人民政府办公厅文件

本政办发〔2017〕1号

本溪市人民政府办公厅关于印发

《2017年市〈政府工作报告〉重点工作任务

分解落实表》的通知

各自治县、区人民政府，本钢，市政府有关委办局、直属机构：

经市政府同意，现将《2017年市〈政府工作报告〉重点工作任务分解落实表》印发给你们，请结合工作实际认真组织实施，要制定切实可行的“任务书、时间表、路线图”，确保承担的各项重点工作任务分解落实到具体单位、具体负责人，并定期向市政府报告进展情况。市政府督查室要加强督促检查，确保2017年市《政府工作报告》部署的各项重点工作任务如期顺利完成。

本溪市人民政府办公厅

2017年1月11日
