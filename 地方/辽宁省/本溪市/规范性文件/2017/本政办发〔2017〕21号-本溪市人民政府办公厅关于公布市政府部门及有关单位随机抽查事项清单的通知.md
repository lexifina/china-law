# 本溪市人民政府办公厅关于公布市政府部门及有关单位随机抽查事项清单的通知

本溪市人民政府办公厅文件

本政办发〔2017〕21号

本溪市人民政府办公厅关于公布市政府

部门及有关单位随机抽查事项清单的通知

各自治县、区人民政府，市政府各委办局、直属机构：

根据《辽宁省人民政府办公厅关于加快推进全省“双随机、一公开”监管改革工作的通知》（辽政办明电〔2016〕95号）要求，各级政府部门于2017年3月底要实现随机抽查全覆盖。经市政府同意，市政府各部门及有关单位实行随机抽查事项132项，现予公布。

市政府各部门及有关单位要在本部门网站及时跟进公布，同时依据清单建立和完善“随机抽查对象名录库、检查人员名录库”，结合工作实际制定本部门“随机抽查工作细则”，规范市场执法行为，提升监管的公平性、规范性和有效性，减轻企业负担和减少权力寻租，切实做到清单之外无检查，全面推进“双随机、一公开”监管改革。
