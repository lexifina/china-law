# 本溪市人民政府办公厅关于印发本溪市体育领域供给侧结构性改革实施方案的通知

本溪市人民政府办公厅文件

本政办发〔2017〕46号

本溪市人民政府办公厅

关于印发本溪市体育领域供给侧

结构性改革实施方案的通知

各自治县、区人民政府，本钢，市政府各委办局、直属机构：

经市政府同意，现将《本溪市体育领域供给侧结构性改革实施方案》印发给你们，请认真组织实施。

本溪市人民政府办公厅

2017年6月28日

本溪市体育领域供给侧

结构性改革实施方案

为贯彻《辽宁省人民政府办公厅关于印发辽宁省体育领域供给侧结构性改革实施方案的通知》（辽政办发〔2016〕148号）精神，全面落实习近平总书记参加十二届全国人大五次会议辽宁代表团审议时重要讲话精神的要求，结合我市实际，制定本方案。

一、总体要求

（一）指导思想

以党的十八大和十八届三中、四中、五中、六中全会精神及习近平总书记参加十二届全国人大五次会议辽宁代表团审议时的重要讲话精神为指导，以“健康中国2030”规划纲要为引领，深入贯彻落实以习近平同志为核心的党中央对体育工作提出的一系列战略思想和重要论述，将增强全市人民体质、提高健康水平作为根本目标，充分把握全民健身上升为国家战略和借助CBA联赛长期落户我市的有利契机，促进我市群众体育、竞技体育和体育产业协调发展。进一步优化体育供给结构，创新体制机制，增强体育活力，促进供需均衡发展，为推动我市经济社会生产力水平整体提升、全面建成小康社会提供有力支撑。

（二）基本原则

——坚持体育事业和体育产业协调发展。加强体育公共服务，不断增加体育市场供给，努力为人民群众提供健康丰富的体育产品，满足大众旺盛的体育需求。

——坚持全民健身和体育产业协调发展。以CBA等大型体育赛事活动为主线，以全民健身为基础，充分发挥赛事的驱动作用，不断增加经常参加锻炼的人口数量和群体。

——坚持竞技体育和体育产业协调发展。加强青少年体育后备人才队伍建设，全面推进学校体育工作，扶持青少年体育俱乐部发展，建立和完善后备人才选拔、培养、输送渠道，努力提升我市竞技体育水平。

——坚持政府引导和市场推动相结合。加强政府规划、政策引导，激活体制内资源的有效利用，完善体育协会、体育俱乐部和体育类企业的市场运行机制，积极培育多元化市场主体。

——坚持深化改革和开拓创新。坚持跨界、整合、创新，推动科技创新、人才创新、制度创新、服务创新，加快建立和完善有利于群众体育、竞技体育、体育产业发展的体制机制。

（三）工作目标

增加体育基础设施供给。到2025年，全市人均体育场地面积达到2平方米，城市老旧居民小区建成15分钟健身圈，新建居民小区体育设施覆盖率达到100%，乡（镇）、行政村实现公共体育健身设施100%全覆盖。

增加公共体育服务供给。建立完善的覆盖市、县（区）、乡（镇、街道）三级公共体育服务网络体系，满足全市广大人民群众日益增长的体育健身需求。

增加全民健身活动供给。坚持开展经常性、传统性、品牌性的全民健身活动，统筹推进青少年、老年人、农村人口等各类人群体育健身活动均衡发展。

增加品牌体育赛事供给。积极引进和承办品牌体育赛事，满足广大人民群众日益增长的体育文化需求，充分发挥赛事的驱动作用，促进体育、旅游、服务业消费，进而助推经济社会发展。

增加特色体育活动供给。利用本溪山水林泉洞等自然资源，整合冰雪资源，开展系列户外休闲特色品牌项目和冰雪运动。大力发展武术、户外、山地、水上、低空飞行等休闲特色体育活动。

增加体育人才和科技供给。通过人才引进、科技交流，创新体育资源运营管理机制，加强体育领域人才培养的国际交流与合作，加强体育领域理论研究，建立体育领域研究智库，完善政府、用人单位和社会互为补充的多层次人才奖励体系，对创意设计、自主研发、经营管理等人才进行奖励和资助。

减少体育行政审批事项。大幅度削减体育领域相关审批事项，实施负面清单管理，全面清理不利于体育领域发展的有关规定，取消不合理的行政审批事项，凡是法律法规没有明令禁入的领域，都要向社会开放。改革赛事管理制度，取消商业性和群众性体育赛事活动审批。

减免体育类企业税费。充分考虑体育类企业特点，对符合条件的体育类企业，从完善税费政策层面推动各门类协同发展。关系到健身成本的体育场馆等健身场所的税费及水、电、气费进行适当调整。

二、重点任务

（一）增加体育基础设施供给，加强体育基础设施建设

到2025年，全市人均体育场地面积达到2平方米， 100%的乡（镇、街道）、村（社区）建有体育设施；100%的县（区）建有至少一个多功能全民健身体育中心；建设3个城市体育公园；100%的郊野公园建有健身场地设施；具备开放条件的学校体育场地设施100%面向社会开放；建设城市15分钟健身圈。

鼓励和引导社会资本投入体育设施建设和体育服务，倡导政府与社会资本合作的PPP模式，建设一批中小型便民体育健身场馆和体育设施。加快推进市政府与省体育局建立体育工作全方位战略合作工作，积极争取国家和省对我市体育设施建设的政策扶持和资金投入。

（二）增加公共体育服务供给，加快推进体育培训业发展

加强公共体育服务体系建设，重点推进体育培训业发展，满足广大人民群众日益增长的健身需求。一是完善市、县（区）、乡（镇、街道）三级公共体育服务网络体系建设；二是鼓励各级各类体育协会、俱乐部等社会组织参与体育培训业，条件成熟的青少年业余训练运动项目，可采取联办、委托等形式，向培训业市场开放；三是加强体育培训专业人才队伍建设；四是提供科学健身咨询与服务；五是推进体育场馆低收费、免收费向公众开放。

（三）增加全民健身活动供给，打造全民健身特色品牌

广泛开展群众喜闻乐见、简便易行的健身活动，推动各级各类体育赛事活动成果惠及更多群众。全市重点举办本溪市全民运动会、全民健身日活动、全市篮球比赛、万人健身操展演、龙舟大赛、全省公路自行车大赛、户外登山大赛和省级以上全民健身大会、冬泳比赛、百万青少年冰雪活动、全国冬季阳光体育大会等具有一定影响力的群众性全民健身品牌活动。各县（区）重点组织本行政区域内全民健身活动的开展，经常性开展武术、乒乓球、羽毛球、足球、篮球、健身操、广场舞、登山、健步走等活动，基本形成“一县一特色，一区一品牌”的全民健身新亮点。同时，每季度安排一项大型体育赛事，每月组织一项群众性体育活动。鼓励乡（镇、街道）、机关、企事业单位、社会服务机构、社区等定期组织不同类型的全民健身竞赛和活动，确保每周锻炼活动不少于3次，每次不少于30分钟。培育青少年体育爱好，掌握一项以上体育运动技能，确保学生校内每天体育活动时间不少于1小时。

（四）增加体育赛事供给，加快推进各类基地建设

积极引进和承办好CBA联赛等品牌体育赛事，满足广大人民群众日益增长的欣赏高水平体育赛事的需求。不断引进省级以上品牌体育赛事，重点做好CBA联赛的承办工作和“辽宁省冬季体育在本溪”的冰雪赛事组织工作，积极申办全国青少年“未来之星”冬季阳光体育大会。利用赛事影响力和市场空间，大力发展体育赛事经济，积极探索体育赛事衍生品、体育赛事活动冠名、体育场馆冠名、运动队冠名等无形资产的市场开发。

加快推进体育产业示范基地、自行车训练基地、航空飞行基地、房车露营基地、垂钓基地、水上训练基地、体育特色小镇和全国登山户外示范城市创建工作，以基地建设带动品牌赛事的引进与举办。

（五）增加特色体育供给，加快推进健身休闲产业发展

全面贯彻落实《国务院办公厅关于加快发展健身休闲产业的指导意见》，按照“政府主导、市场配置、分类推进、百姓受益”的原则，调整优化产业结构，积极发展水上、山地、航空运动产业。充分利用我市山地体育公园、太子河亲水体育、国家航空飞行营地等建设项目，建立水、陆、空三位一体的立体化健身休闲特色产业发展模式。完善健身休闲配套建设，推动健身休闲产业可持续发展。同时，着力培育打造富有本溪当地特色的户外和冰雪运动品牌赛事，并向外输出赛事品牌。

（六）增加体育人才和科技供给，加强人才队伍建设

把人才的引进和培养作为加快进行体育领域供给侧结构性改革的战略举措。多渠道培养既懂经营管理又懂体育营销的复合型体育人才。建立健全人才评估体系和激励机制，采取有力措施吸引、留住、用好人才。建立健全体育人才信息资源库和信息保障服务平台，制定严谨科学合理的人才考核机制，规范职业资格审批程序。

（七）加快推进政府购买公共体育服务

建立多元化市场主体，发挥市场在体育资源配置方面的作用，鼓励社会力量承办体育赛事，兴建体育设施，参与政府购买公共服务。按照《本溪市人民政府向社会力量购买公共文化服务指导性目录》规定的六大类公共体育服务项目，放开政府向社会力量购买公共服务市场，提升符合条件的社会力量参与度，繁荣体育产业市场。

（八）减少体育类行政审批事项，规范行业管理

取消商业性和群众性体育赛事活动审批，加快综合性和单项体育赛事管理制度改革；公开赛事举办项目单，通过市场机制积极引入社会资本承办赛事；精简协会、俱乐部成立流程，适当降低准入门槛；加快推进体育行业协会与行政机关脱钩，将适合由体育社会组织提供的公共服务和解决的事项，交由体育社会组织承担；加强经营高危险性体育项目许可管理和安全监管工作，规范经营高危险性体育项目单位经营活动，保障消费者人身安全，促进体育市场健康发展。

（九）减少符合条件的体育类企业税费

按照《国务院关于加快发展体育产业促进体育消费的若干意见》（国发〔2014〕46号）要求，落实相关税费政策。符合条件的体育类企业享受文化创意产业税收减免的相关优惠政策；对经认定为高新技术企业的体育企业，减按15%的税率征收企业所得税；提供体育服务的社会组织，经认定取得非营利组织企业所得税免税优惠资格的，依法享受相关优惠政策；体育场馆自用的房产和土地，可享受有关房产税和城镇土地使用税优惠，体育场馆等健身场所的水、电、气价格不高于一般工业标准执行。

（十）完善健身休闲标准和统计制度

全面推动健身休闲标准体系建设，制定健身休闲服务规范和质量标准，在服务提供、技能培训、活动管理、设施建设、器材装备制造等方面提高健身休闲产业标准化水平。引导和鼓励企业积极参与行业和国家标准制定。以国家体育产业统计分类为基础，完善体育产业统计制度和指标体系，建立体育产业监测机制。

三、保障措施

（一）提高认识，加强领导

要从全面振兴东北老工业基地的高度，充分认识体育领域供给侧结构性改革的重大意义，增强紧迫性和责任感，采取切实有效措施，加快推进体育领域供给侧结构性改革。

市政府成立工作小组，市体育行政主管部门及相关单位统筹协调，建立健全推进体育领域供给侧结构性改革协调工作机制，做好组织协调和指导推动工作，及时解决推进体育领域供给侧结构性改革中遇到的重大问题。

（二）明确分工，责任到人

各相关部门，要在各自的职责范围内积极落实各项政策措施，确定一位领导同志负责体育领域供给侧结构性改革工作，明确职责分工，做到层层有责任、逐级抓落实，将工作责任落实到岗到人，形成齐抓共管的工作格局，确保工作实效。

（三）成效评估，稳步推进

市体育行政主管部门要会同有关部门建立长效督查评估机制，对本实施方案的实施情况进行检查指导，对实施工作进展进行考核。各部门要加强沟通协调，确保此项工作稳步推进。
