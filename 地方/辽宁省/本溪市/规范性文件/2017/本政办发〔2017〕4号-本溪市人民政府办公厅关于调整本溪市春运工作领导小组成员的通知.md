# 本溪市人民政府办公厅关于调整本溪市春运工作领导小组成员的通知

本溪市人民政府办公厅文件

本政办发〔2017〕4号

本溪市人民政府办公厅关于

调整本溪市春运工作领导小组成员的通知

各自治县、区人民政府，本钢，市政府有关委办局、直属机构：

按照省春运办通知要求，根据工作需要和市春运工作领导小组成员变动情况，市政府决定对本溪市春运工作领导小组成员进行调整，现将调整后的成员及主要职责通知如下：

二、领导小组职责

（一）负责全市春运工作的组织、领导、协调和保障工作。

（二）负责制定全市春运工作方案，定期召开春运工作协调会、推进会。

（三）指导各成员单位依据各自职责制定本系统春运工作方案，扎实做好各项春运保障工作，加强部门间协调配合。

（四）组织开展春运期间的安全、生产和服务督导检查，深入现场发现问题、解决问题，督导慰问一线职工。

（五）督导相关单位、部门和企业严格落实值班值守制度，加强宣传引导，强化信息总结报送，做好主要时间节点信息发布。

（六）组织做好春运工作总结，评选我市春运先进单位和个人。

三、有关要求

（一）统一思想，强化认识。春运工作关乎人民群众切身利益，关系社会和谐稳定，是一项重要的民生工程，社会关注度高、影响大。各部门、各单位要从讲政治、保民生的高度，精心组织，周密安排，切实抓紧抓好。

（二）明确职责，全面准备。各部门、各单位要加强对春运工作的研究，科学分析形势，预想情况，研究对策，制定针对性、操作性强的春运工作方案。

（三）加强配合，形成合力。要建立健全春运工作协调机制，加强监测分析和工作会商，强化督促检查，及时协调解决突出问题。要认真履职，密切配合，加强沟通，上下联动，切实形成我市抓春运工作合力，确保圆满完成春运各项任务。
