# 本溪市人民政府办公厅关于调整本溪市民族事务委员会兼职单位职责及工作制度的通知

本溪市人民政府办公厅文件

本政办发〔2017〕62号

本溪市人民政府办公厅关于调整

本溪市民族事务委员会兼职单位职责

及工作制度的通知

各自治县、区人民政府，本钢，市政府各委办局、直属机构：

为进一步做好我市民族工作，充分发挥各兼职单位在民族工作中的职能作用，经市政府同意，现对市民委各兼职单位工作职责及工作制度调整如下：

一、市民委委员单位主要职责

全面贯彻执行党和国家民族政策，坚持和完善民族区域自治制度，围绕共同团结奋斗、共同繁荣发展的民族工作主题，巩固和发展平等、团结、互助、和谐的社会主义民族关系；根据本部门职能，在拟定政策、法规时，充分考虑少数民族和民族地区实际，深入调查研究，采取有效措施，解决民族工作面临的突出问题和特殊困难，支持少数民族和民族地区加快发展，促进民族地区与全市同步建成小康社会。

二、市民委委员单位具体职责

市发展改革委：开展民族地区国民经济和社会发展战略研究，指导编制促进民族地区发展相关专项规划；协调解决少数民族和民族地区经济社会发展以及经济运行中的特殊问题；支持和扶持人口较少民族整体发展；在全市资源开发、生态环境建设和安排全市基础设施建设项目等方面向民族地区倾斜；指导和协调民族地区与经济相对发达地区经济、技术、人才交流合作；按照同等条件、优先扶持的原则，支持民族地区的企业技术改造、资源开发与综合利用和社会事业发展。

市工业和信息化委：研究拟定推进民族地区工业和通信业发展以及“两化融合”(工业化和信息化融合)的相关政策；指导民族地区编制工业和信息化发展规划；指导和支持民族地区特色工业发展、农副产品深加工以及通信业发展；协调解决民族地区工业发展和信息化建设中的重要问题。

市教育局：研究拟定促进民族教育发展的政策和规划，加大公共教育资源向少数民族和民族地区倾斜力度，重点解决少数民族和民族地区教育事业发展面临的特殊困难和突出问题；协调指导对民族地区教育援助，支持帮助办好各级各类民族学校；统筹指导学校民族团结教育工作，在各级各类学校广泛开展民族团结进步教育；统筹指导少数民族“双语”教育工作。

市科技产权局：推动创新驱动发展战略在少数民族和民族地区的实施，加快民族地区科技进步；研究拟定促进少数民族和民族地区科技发展规划和优惠政策；加大对民族地区科技投入力度，解决少数民族和民族地区在科技发展中的特殊问题；统筹和优化科技资源在民族地区的配置，推动开展区域间科技合作；在实用技术的引进开发与推广、科普工作、科技人才和科技干部的培训培养、科技服务体系的建立等方面给予少数民族和民族地区重点倾斜。

市民委（宗教局）：全面贯彻党和国家关于民族宗教工作的方针政策，统筹协调推进全市民族工作、宗教工作；深入开展民族团结进步宣传教育和创建活动；大力促进少数民族和民族地区加快发展；繁荣发展少数民族文化；做好散居少数民族工作；加强少数民族干部队伍建设和培训培养；依法履行宗教事务管理职责；加强宗教工作三支队伍培训，开展宗教政策法规宣传教育；做好少数民族的宗教工作。

市公安局：协调处理涉及民族方面影响社会稳定的重大问题，依法打击利用民族、宗教进行的违法犯罪活动，维护国家统一、民族团结和社会稳定；协调处理在社会治安综合治理工作中涉及民族事务方面的有关问题；协调解决民族成份更改工作中有关特殊问题。

市民政局：协调解决少数民族和民族地区在减灾救灾、社会救助、社会福利、社会组织管理、基层民主和社会建设、服务军队和国防建设，以及区划地名、专项社会事务管理服务中的特殊问题；协调推进社区民族工作。

市财政局：落实国家扶持少数民族经济发展的相关政策；协调解决民族地区经济发展和社会各项事业发展中的特殊困难；加大对民族地区财政转移支付力度，在同等条件下优先安排民族地区的财政专项资金和增加财源项目；贯彻落实国家对民族贸易和民族用品生产企业的技改贷款贴息政策。

市人社局：研究拟定培养选拔各类专业技术人员的政策和规划；加大对各级领导干部民族团结教育培训力度；指导和协调民族地区人力资源开发工作，制定优惠政策，鼓励和支持各类人才到民族地区工作；指导开展民族团结进步表彰工作。

市国土资源局：研究拟定民族地区土地和矿产资源政策；协调解决民族地区在土地和矿产等资源开发和保护方面的特殊问题；在开发利用民族地区土地和矿产等资源时，切实保障少数民族和民族地区利益。

市环保局：协调和指导编制民族地区环境功能区划和环境保护规划；协调指导民族地区主要污染物减排工作；加强对民族地区环境污染防治以及重要生态环境建设、生态破坏恢复的监督管理；开展民族地区国家和省、市重点生态功能区生态环境质量检测、评估与考核；指导和协调解决民族地区重大环境问题，推进民族地区生态文明建设。

市城乡规划建设委：规范民族地区住房和城乡建设管理秩序，指导民族地区城乡规划编制实施、村镇规划编制、农村住房建设和安全及危房改造工作；研究民族地区村庄和小城镇建设政策，统筹推进少数民族特色村镇建设；指导和协调民族地区人居生态环境的改善工作。

市综合执法局：在涉及少数民族群众执法工作中充分考虑民族特殊性，做好执法对象教育疏导工作，尽量避免采取刚性措施，协调解决好执法领域涉及民族方面各类问题，防止和避免激化矛盾。

市交通运输局：研究拟定民族地区公路水路交通发展政策和中长期规划，大力支持民族地区交通事业发展；协调处理民族地区在公路建设中的特殊问题，对民族地区公路交通基础设施建设给予支持和帮助。

市农委：研究拟定民族地区农业、农村经济发展和农民增收的优惠政策措施；指导民族地区立足农业资源综合开发，进一步调整优化农业产业结构，推动农业现代化进程，支持少数民族特色村镇建设；在民族地区发展特色农业、加快农业基础设施建设、推进农业科技进步、提高产业化经营水平、培养新型农民、开拓农产品市场、建设美丽乡村、保护生态环境、促进农业可持续发展等方面给予重点扶持。

市水务局：研究拟定民族地区水利发展规划和扶持政策；加大对民族地区水利基础设施建设投入和倾斜力度，对民族地区水库、河流的综合治理和开发给予重点扶持；研究解决少数民族和民族地区水土保持和饮水安全问题。

市林业局：研究拟定民族地区生态建设和特色优势产业发展的相关政策和规划；协调解决民族地区林业发展和保护工作中的特殊问题，支持民族地区森林及野生动植物等资源保护和恢复；加大对民族地区林业资金的投入和倾斜力度，优先安排民族地区造林绿化、天然林保护和各类自然保护区和重点火险区、重要湿地建设等重点林业建设项目。

市文化广电局：研究制定全市少数民族文化事业发展规划；加强少数民族和民族地区各级文化设施和人才培训工作；组织和开展少数民族文化活动，与市民委共同组织好全市少数民族文艺汇演等活动；大力宣传党和国家的民族政策和有关法规，传播民族知识，报道民族工作重要新闻；积极扶持少数民族和民族地区新闻出版广播影视事业发展；严格审查、禁止制作播出违反党的民族政策和伤害民族感情内容的广播影视作品，会同有关部门妥善处理广播影视作品和出版物中违反党和国家民族政策、伤害民族感情内容的事件。

市卫生计生委：研究拟定民族地区卫生计生事业发展规划和目标，积极扶持民族地区卫生计生事业发展；协调解决民族地区卫生计生方面的特殊问题，制定改善民族地区卫生计生状况的政策、措施；建立健全县（区）、乡（镇、街道）、村（社区）医疗预防保健网络，加强对民族地区地方病、多发病的防治等工作；协调组织城市医疗单位在人才、技术和物资上支援民族地区农村医疗卫生工作；研究拟定促进少数民族和民族地区医药事业发展的政策措施，加强民族医药人才培养。

市食品药品监管局：研究民族地区食品药品方面的特殊问题，在拟订食品药品安全监管政策规章时，充分考虑少数民族和民族地区的特殊情况；支持民族地区食品药品安全监管事务的开展；会同有关部门加强清真食品安全监管。

市体育发展委：研究拟定发展少数民族和民族地区体育事业的政策措施，促进少数民族体育事业的发展；加快民族地区体育基础设施规划和建设；扶持少数民族传统体育项目保护与发展，培养少数民族体育人才；协同做好参加全省少数民族传统体育运动会有关工作。

市统计局：协助做好民族统计、民族自治地方贫困监测和民族地区经济形势监测分析工作；着重做好民族自治县和民族乡（镇）等经济社会发展方面的数据统计工作。

市政府法制办：贯彻落实党的民族政策，支持民族工作部门加强民族事务法治建设，加快民族工作法治化进程；研究拟订少数民族和民族地区经济社会发展的地方法规和政府规章。

市旅游发展委：研究拟定民族地区旅游业发展的规划和政策；培育和完善民族地区旅游市场，研究拟定市场开发战略措施并指导实施；指导民族地区重点旅游区域的规划开发建设，重点扶持民族地区全域旅游、民族特色旅游；按照同等条件、优先扶持的原则，指导民族地区旅游教育、培训工作。

市国资委：指导监管国有独资及国有控股企业积极履行社会责任，充分发挥监管国有独资及国有控股企业在人才、技术、管理等方面的优势，支持民族地区经济社会发展；鼓励、引导、支持监管国有独资及国有控股企业积极参与民族地区经济社会建设，带动和促进民族地区加快发展。

市工商局：把好办理各类企业（包括外商投资企业）、个体工商户营业执照、引导商标注册的民族政策关；对民族地区的各类企业、农民专业合作社和民贸民品企业等市场主体的登记注册给予政策倾斜，提高服务效能；依法规范和维护民族地区市场经营秩序，依法查处假冒伪劣等违法行为，保护民族企业、少数民族个体工商户及其从业者生产经营的合法权益。

市质监局：做好清真食品相关产品生产加工企业监管服务工作，严格实行生产许可、检查检验等清真食品相关产品质量安全市场准入制度，参与清真食品相关产品生产经营管理执法检查工作，做好清真食品相关产品企业质量保障宣传工作。

市政府金融办：贯彻执行国家、省关于民族地区有关金融政策；协调解决民族地区资本市场规范发展中的特殊问题；协调人民银行本溪市中心支行和市各商业银行加大对民族地区的支持力度，不断完善金融服务，落实国家有关民族贸易和少数民族特需商品生产优惠政策。

市扶贫办：研究拟定促进少数民族和民族地区扶贫开发的优惠政策措施；协调解决少数民族和民族地区扶贫开发中的特殊困难和特殊问题；进一步加大对少数民族和民族地区扶贫开发力度，在扶贫资金、外援项目及贫困地区干部培训等方面对少数民族和民族地区给予照顾；支持和促进人口较少民族整体脱贫工作。

市国税局：贯彻落实国家支持民族地区经济社会发展的各项税收政策措施，大力扶持民族地区各类企业和民贸民品企业壮大发展，维护少数民族和民族地区纳税人合法税收权益。

市地税局：贯彻落实国家和省、市支持民族地区经济和社会发展的各项税收优惠政策措施。

人民银行本溪市中心支行：贯彻执行国家关于民族地区的金融政策，结合我市实际，提出实施意见；协调市各商业银行，落实国家有关民族贸易和民族用品生产的优惠政策。

三、工作制度

（一）委员和联络员选任制度

各委员单位按照具体职责确定1名领导班子成员为市民委委员单位委员，负责牵头落实本委员单位职责范围内的民族工作。同时，指定1名与民族工作联系密切的业务处室负责人为市民委委员单位联络员，负责具体联络协调工作。各委员单位委员、联络员如遇工作变动，由所在单位提出调整意见，报市民委委员会办公室（市民委）备案。

（二）全体会议制度

原则上每年召开一次市民委委员单位全体会议，总结上一年度各委员单位贯彻落实市委、市政府关于民族工作决策部署情况，安排部署下一年度市民委委员会工作，研究解决民族工作中的重大问题。各委员单位交流经验做法，提出意见建议。会议要形成纪要，有关情况及时报告市委、市政府。

（三）联络员会议制度

市民委委员会办公室（市民委）根据工作需要，不定期组织召开市民委委员单位联络员会议，加强工作联系和信息共享，推动开展合作和协同落实，收集整理需要市民委委员会决策的有关议题。

（四）议事决策制度

对事关全市民族工作的长远发展规划、年度工作计划、重大工作部署、重要改革措施及其他重大事项，必须充分讨论，集思广益，由市民委委员会办公室（市民委）征求意见，并整理提交市民委委员会全体会议或请示市民委委员会主任作出决策。

（五）工作计划制度

各委员单位从各自职责出发，把每年要为少数民族和民族地区办的实事、解决的问题列入本单位年度工作计划，并于每年3月1日前送至市民委委员会办公室（市民委）。市民委委员会办公室（市民委）依据各单位年度工作计划，编制市民委委员会年度工作计划草案，提交市民委委员会全体会议讨论决策。

（六）工作协调制度

贯彻落实少数民族政策、处理解决涉及少数民族问题及相关事务过程中，需要协调其他委员单位共同做好相关工作的，由市民委委员会办公室（市民委）联系协调有关委员单位，沟通相关情况，充分发挥各委员单位工作职责，共同做好贯彻落实及处置解决工作。

（七）效能督查制度

市民委委员会办公室（市民委）不定期牵头组织相关委员单位就民委委员会年度工作计划落实情况开展效能督查，确保各项工作落到实处。
