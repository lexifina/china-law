# 本溪市人民政府办公厅关于印发本溪市装备制造业重点领域发展的实施意见

本溪市人民政府办公厅文件

本政办发〔2017〕87号

本溪市人民政府办公厅关于印发

本溪市装备制造业重点领域发展的实施意见

各自治县、区人民政府，本钢，市政府各委办局、直属机构：

为加快推进全市装备制造业发展，按照《中共辽宁省委办公厅辽宁省人民政府办公厅关于印发<辽宁省装备制造业重点领域 发展指导意见>的通知》（辽委办发〔2016〕63号）精神，经市政府同意，现就我市装备制造业重点领域发展提出如下实施 意见。

一、指导思想

全面贯彻党的十九大精神，紧紧围绕统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，认真贯彻落实“ 四个着力”要求和新发展理念，扎实推进工业供给侧结构性改革，按照数字化、网络化、智能化发展方向，加快新一代信 息技术与装备制造业深度融合，加快传统产业转型升级和战略新兴产业发展壮大，着力优化装备制造业供给结构，完善装 备制造业创新体系，不断提升装备制造业核心竞争力，积极融入全省装备制造业发展全局，努力建设全省装备制造业材料 基地、关键零部件研发生产基地和重大技术装备战略基地。

二、基本原则

1.坚持创新驱动。始终把创新摆在装备制造业发展全局的核心位置。充分利用和整合科技创新资源，强化企业创新主体地位，完善有利于创新的制度和政策环境，建立政产学研用相结合的有效机制，推动跨领域、跨行业联合攻关、协同创新， 努力突破一批重点领域关键共性技术。

2.坚持结构优化。始终把结构调整作为提升我市装备制造业的关键环节。彻底打破传统产业发展格局，大力发展先进装备 制造业，加快改造提升传统产业步伐，加快培育发展新兴产业，淘汰落后产能，推动生产型制造向服务型制造的转变。优 化产业空间布局，培育一批具有核心竞争力的产业集群和产业联盟。

3.坚持绿色发展。始终把可持续发展作为提升我市装备制造业的重要着力点。积极构建绿色制造体系，加强产业政策导向 ，健全绿色制造标准。加快低碳技术的升级与应用，加快传统产业节能改造，扩大节能环保产品的推广应用。

4.坚持“两化”融合。始终把新一代信息技术与制造技术深度融合作为重要抓手。充分发挥信息化在转型升级中的支撑和 牵引作用，深化信息技术集成应用，着力发展智能装备和产品，积极培育新业态新模式，提高企业研发、生产、管理和服 务智能化水平，加快推动装备制造业向数字化、网络化、智能化、服务化转变。

5.坚持质量为先。始终把质量提升作为提升我市装备制造业的重要保障。强化质量意识、品牌意识和信誉意识，加强质量 技术攻关，完善标准体系建设，加强人员培训，提高质量检测手段，提升产品一致性保证能力。建立质量信誉体系，营造 诚信经营环境。

6.坚持开放合作。始终把开放合作作为提升我市装备制造业的重要动力。进一步拓展国际视野，使本溪装备制造业融入国 内、国际产业链条，充分利用全球资源和市场，不断加强国际交流合作。鼓励引进消化国内外先进适用技术，提升装备制 造业开放发展水平。

三、发展目标

到2020年，装备制造业整体质量较大幅度提升，自主创新能力显著增强，优势领域居全国先进行列，新兴产业快速发展， 基础产业取得突破；产品数字化、网络化、智能化水平明显提高；重点行业单位工业增加值能耗、物耗及污染物排放达到 国内领先水平，钢铁等装备材料产业销售收入达到600亿元以上；成套装备及零部件制造业销售收入达到50亿元以上，比重 由目前的2.3%提高到4%左右；力争在汽车行业和3D打印产业方面实现突破。

四、发展重点

（一）装备制造材料产业

1.产业基础。我市装备材料优势主要在于本钢板材、棒线材、特殊钢以及精品铸造用生铁。本钢拥有2300mm带钢热轧机组 、东北地区炉容最大的4747立方米炼铁高炉、1970mm酸洗冷轧机组，整体装备达到世界先进水平。大台沟铁矿、思山岭铁 矿将为绿色钢都建设提供原料保障，银龙预应力材料、金桥焊材分别为东北最大的预应力材料、焊接材料生产基地。北方 炼铁、盛开机械、聚鑫达、参铁集团、坤琦精密铸造、华声铸造、四野铸业等7户企业被工信部认定为铸造用生铁生产企业 ，其生产的铸造用生铁是中高端装备不可或缺的原材料。

2.发展重点。充分发挥本钢集团的技术、设备和人才等优势，大力开发超高强汽车用钢及第三代先进高强钢，高等级海底 石油膨胀管用钢，耐大气和应力腐蚀石油管线钢，高纯净度轴承钢、长寿命高性能齿轮、高端气瓶、军工用等特殊钢，汽 车排气系统用、家电面板用、深冲用等不锈钢，高级帘线钢、高强度紧固件用钢、高强钢筋等。突出“人参铁”资源优势 ，研发精品铸件用生铁，发展3D打印金属粉末材料。

3.发展目标。到2020年，实现装备材料生产能力和生产效率显著提升，资源利用率和产品附加值明显提高，力争实现销售 收入600亿元，努力打造国内领先、竞争力强、资源消耗低、生态环境好的装备材料生产基地。

（二）中高端装备零部件产业

1.产业基础。我市中高端装备零部件处于起步阶段，主要产品集中在冶金、矿山装备零部件、管件和机床及床身。本溪世恒机床技术处于领先水平，拥有国内先进的滚丝机产品测试系统及液压系统试验站。北台铸管的系列管件产品占据国内市 场份额前三甲。东华铸业的铸造床身深受韩国客商青睐。盛开机械的风力发电机齿轮箱、恒通轧辊等拥有良好的市场前景 。

2.发展重点。围绕本钢产品，打造装备制造产业配套基地。重点发展轴承、齿轮、齿轮箱、高铁传动部件、新型集装箱、 高强耐磨板、汽车车厢部件、高铁配件、小五金件、工槽角等建筑型材、钢结构、不锈钢冲压件、彩涂板等。打造精品铸 件产业基地，发展矿山工程机械、机床床体、海洋石油开采设备、风电装备等铸铁配件，以及新型铸铁管材、管件等产品 。努力发展3D打印技术，配套生产航空、船舶及高端装备的高精度零部件、异形件等，填补航空、船舶等高端制造领域空 白。

3.发展目标。到2020年，实现自主设计能力和智能制造水平显著提升，形成较为完善的设计、总装建造、设备配套、技术服务产业体系，3D打印技术得到推广和应用，力争销售收入突破30亿元。打造科技含量高、技术水平过硬、产品配套率强 的中高端装备零部件生产基地。

3.发展目标。瞄准高端化、成套化、智能化方向，加快研制一批首台（套）重大技术装备，提高对国家重点专项、重大工 程的总承包能力，全面提升成套装备生产企业的数量及产品质量，走入装备制造业价值链高端行列。到2020年，力争销售 收入达到10亿元。

五、保障措施

（一）优化产业发展环境

加快政府职能转变，深入推进简政放权，最大限度地取消和下放行政审批事项，推动工业投资管理重心由事前审批向事中 事后监管转变，建立和完善重大项目绿色审批通道，提高审批效率。规范管理部门职责权限，深化市场准入制度改革，实 施负面清单管理，全面清理和废止不利于市场建设的政策措施。积极发展混合所有制经济，鼓励非公企业参与国企改革。 大力发展民营经济，进一步增强市场主体活力。

（二）加大政策资金支持力度

贯彻落实国家支持东北老工业基地振兴的各项优惠政策，积极争取国家、省支持装备制造业发展的相关政策和资金。引导 社会资本参与装备制造业重大项目建设、企业技术改造和关键基础设施建设。引导金融机构创新贷款方式，优化信贷配置 结构，鼓励金融机构开展信用保险保单质押、股权质押、知识产权质押、仓单质押等贷款业务，加大信贷投放力度，开展 多形式、多层次的银企合作。鼓励符合条件的重点行业骨干企业（集团）通过融资租赁等多种方式，拓宽融资渠道。

（三）健全产业创新体系

搭建以企业为主体、高等院校和科研院所紧密协作的产学研用合作关系，建设设备制造业创新公共服务平台。围绕我市装 备制造业薄弱环节和关键领域，开展行业基础和跨行业共性关键技术研发，尽快突破一批核心技术和重大关键技术，形成 一批具有自主知识产权的科技成果。以改革科技成果转化激励机制为核心，完善促进科技成果转化和产业化的政策措施， 在先进适用的创新成果产业化推广方面给予政策支持，并加强对知识产权的保护。

（四）推进重点项目建设

加大定向招商力度，重点引进装备制造业龙头企业，加快谋划一批带动力强、牵动力大的装备制造业重点领域项目。建立 装备制造业重点项目库，对符合条件的装备制造重点领域项目在办理立项、用地、环保、生产许可等审批手续时开通绿色 通道，优先保障装备制造企业用电、用能的合理需求。

（五）推进产业协同发展

按照“专精特新”的发展需求，大力发展零部件产业，扶持一批专业特色鲜明、技术含量较高、配套能力较强、市场前景 较好的装备关键零部件制造企业，与省产业政策相契合，完善产业格局并同省内龙头装备制造业企业看齐，促进上下游产 品对接。加快制造与服务协同发展，促进装备制造业企业由生产型制造向服务型制造转变。

（六）健全人才培养体系

组织实施装备制造业人才培养计划，加大人工智能高端人才培养计划，加大专业技术人才、经营管理人才和技能人才的培 养力度，完善从研发、转化、生产到管理的人才培养体系。引导和支持高等院校、高职院校和科研机构围绕装备制造业发 展的人才需求调整、新设学科和专业，加快培养产业发展所需的各类人才。鼓励校企合作，培养装备制造业急需的科研人 员、技术技能人才与复合型人才。建立普惠性就业培训制度，加大政府培训补贴力度，鼓励引导装备制造业技能人才参加 职业技能培训。
