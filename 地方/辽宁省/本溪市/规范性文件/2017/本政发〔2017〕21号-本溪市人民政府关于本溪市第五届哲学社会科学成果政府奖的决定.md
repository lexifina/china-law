# 本溪市人民政府关于本溪市第五届哲学社会科学成果政府奖的决定

本溪市人民政府文件

本政发〔2017〕21号

本溪市人民政府关于本溪市第五届

哲学社会科学成果政府奖的决定

各自治县、区人民政府，本钢，市政府各委办局、直属机构：

近年来，全市哲学社会科学工作者紧跟时代发展步伐，紧密结合本溪经济社会发展实践，积极开展基础理论和应用对策研究，较好地发挥了社会科学界思想库和智囊团作用，取得了较为丰硕的成果。为表彰先进，激励广大社科工作者进一步深入实践开展研究，更好地服务于本溪振兴发展大局，经市评委会评审、市政府第102次常务会议研究，市政府决定对本溪市第五届（2014—2015年度）哲学社会科学成果给予奖励,授予《沸流集——高句丽及辽东史地论稿》等70项成果为本溪市第五届哲学社会科学成果政府奖。

市政府号召全市哲学社会科学工作者和广大干部群众要向获奖者学习，发扬理论创新、学术严谨和理论联系实际的学风，进一步增强服务本溪振兴发展的使命感和紧迫感，主动回应和回答事关本溪振兴发展的重大理论与现实问题，努力突破一批重大应用对策研究课题，不断提升学术水平、多出学术研究成果，繁荣发展哲学社会科学事业，为推进本溪经济社会科学发展贡献力量。
