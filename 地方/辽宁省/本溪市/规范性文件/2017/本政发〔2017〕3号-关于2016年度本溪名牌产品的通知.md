# 关于2016年度本溪名牌产品的通知

本溪市人民政府文件

本政发〔2017〕3号

关于2016年度本溪名牌产品的通知

各自治县、区人民政府，本钢，市政府各委办局、直属机构：

为进一步推进我市名牌产品战略，使质量强市向纵深发展，按照《本溪市名牌产品管理办法》和《本溪市名牌产品企业现场评价准则（试行）》规定，经本溪市名牌战略推进委员会名牌产品评定小组评定和向社会公示，市政府确认2016年度本溪名牌产品9项（详见附件），有效期为2017年1月1日至2019年12月31日。
