# 本溪市人民政府办公厅关于做好《民生用气保障责任书》落实工作的通知

本溪市人民政府办公厅文件

本政办发〔2018〕37号

本溪市人民政府办公厅关于做好

《民生用气保障责任书》落实工作的通知

各自治县、区人民政府，本钢，市政府有关委办局、直属机构：

省政府已与国家发展改革委、国家能源局签订《民生用气保障责任书》，并于近期将与我市政府签订《民生用气保障责任书》。为保障全市民生用气需求，切实做好《民生用气保障责任书》目标任务落实工作，经市政府同意，现将有关事项通知如下：

一、目标任务

坚持统筹规划、循序渐进、尽力而为，实现天然气供需总体动态平衡。推动加快建立天然气储气调峰设施，逐步解决天然气季节性供需矛盾。高峰期实施有序用气，确保满足居民用气、集中供热以及学校、医院、公交等公共服务类民生用气需求。

二、工作责任

保障民生用气是各级政府的重要责任，是天然气产供储销体系建设的重要组成部分。市政府成立由市政府领导同志任组长的全市天然气产供储销体系建设及供应保障协调工作组，工作组办公室设在市发展改革委。各县（区，含本溪高新区，下同）要成立相应的协调工作组，确定总协调人，明确牵头部门，组织相关部门在确保安全的前提下，落实天然气产供储销体系建设和供应保障工作。

（一）加快推进储气设施建设。各县（区）、有关部门要落实储气设施建设责任，结合实际情况，积极创造条件，研究制定支持储气设施建设政策。（责任单位：各县区，市住房和城乡建设委、市工业和信息化委、市财政局）2018年上半年，要制定专项计划并确定今年拟开工的项目，按照2020年供暖季前至少形成不低于保障本地区日均3天用气量的应急储备能力的目标，分层次稳步推进，并明确工程建设施工进度、责任单位和责任人，制定考核奖惩办法，防止新增地方政府债务。其中，地方政府控股企业建成的储气设施，可认定为地方政府具备的储气能力。（责任单位：市住房和城乡建设委、市城乡规划局）市住房和城乡建设委要结合全市燃气行业管理实际，负责做好与我市辖区内各燃气企业、不可中断大用户签订储气责任书，市工业和信息化委负责做好与我市辖区内不可中断工业用气大户签订储气责任书，落实城市燃气企业、不可中断大用户在2020年底前形成不低于其年用气量5%的应急储气能力的主体责任。（责任单位：市住房和城乡建设委、市工业和信息化委）各县（区）要同样做好与本辖区内各燃气企业、不可中断大用户签订储气责任书的相关工作。（责任单位：各县区）在2018年供暖季前，对尚未达到要求的部分，应通过购买或签约调峰能力的办法，履行应承担的储气能力社会责任。（责任单位：各县区，各燃气企业，市住房和城乡建设委、市工业和信息化委）

（二）切实做到供用气合同“全覆盖”。要按照“先规划、先合同、后发展”的原则，将供气合同作为发展用户与保障供需平衡的首要条件，实现供气合同全覆盖。（责任单位：市住房和城乡建设委，各燃气企业）各县（区）、有关部门要督促用气企业和供气企业全面签订2018年及2018—2019采暖季天然气供用气合同，坚持量入为出、量力而行的总原则，根据资源供应安排，抓紧完成2018年天然气供用气合同签订工作。合同内容应详细规范，有量有价，体现价格浮动机制，标明可中断用户政策，明确违约责任等相关内容。其中，市住房和城乡建设委负责全市民生用气合同的签订工作，市工业和信息化委负责全市工业用气合同签订工作，各县（区）负责配合市住房和城乡建设委、市工业和信息化委做好本辖区供用气合同签订工作，并于6月13日前由市住房和城乡建设委、市工业和信息化委分别将用气合同签订情况对口报送省住房城乡建设厅、省工业和信息化委，同时报送市天然气产供储销体系建设及供应保障协调工作组办公室。（责任单位：市住房和城乡建设委、市工业和信息化委，各县区，各燃气企业）协调工作组办公室梳理汇总后报送省发展改革委。（责任单位：市发展改革委）

（三）有序做好“压非保民”工作。市住房和城乡建设委要承担起我市民生用气的保供主管责任，全面掌握天然气供需情况，按照“压非保民”的原则，分层级制定应急预案，细化至终端用气企业并依法明确不同层级预案启动条件和程序，及时协调解决影响平稳供气问题。（责任单位：市住房和城乡建设委，各燃气企业）各县（区）要切实承担起民生用气的保供主体责任，做好制定应急预案的配合工作。（责任单位：各县区）要合理确定天然气销售价格，促进燃气企业正常生产经营，同时加强输配价格监管，降低偏高的输配价格，切实做好低收入等特殊群体基本生活保障工作。（责任单位：市发展改革委）执行“压非保民”措施、压减工业用气时，要按照“确保安全、提前告知、充分沟通、稳妥推进”的原则，综合考虑不同工业用户生产装置的客观要求，对须连续运行的生产设备维持最低负荷用气，避免造成设备损坏。（责任单位：市工业和信息化委，各燃气企业）

（四）强化应急调峰能力建设。市住房和城乡建设委要指导燃气企业根据用气特点对终端用户进行分类，区分为可中断用户、可调减用户和不可中断用户。要因地制宜调整优化用气结构，通过优化供气方式、优先保障气源、施行淡季优惠气价等方式，鼓励和引导我市各燃气企业优先发展可中断用户和可调减用户，科学有效降低非民用气负荷，形成不少于高峰日用气量20%的用户调峰能力。要加强城市燃气的运行、监测、预警和应急处置，制定并组织实施城市燃气应急预案。（责任单位：市住房和城乡建设委，各燃气企业）

（五）坚持“以气定改”原则推进“煤改气”。各县（区）、有关部门要从实际出发，统筹规划、循序渐进、量力而行，按照供用气合同落实的气源，优先保障2017年结转“煤改气”用户，再发展新增“煤改气”工程；统筹考虑总量和高峰期双重因素，合理确定“煤改气”规模，务必做到“先合同、后改造”，改造到位并稳定供气前，继续保持原有取暖方式不受影响。有条件的地区要通过调整用气结构，支持保障民用“煤改气”需求。（责任单位：市住房和城乡建设委、市工业和信息化委、市环保局，各县区，各燃气企业）

（六）大力优化建设环境。各县（区）要在成立的天然气产供储销体系建设及供应保障协调工作组中确定总负责人，专门负责衔接推进天然气上游气田、管道等基础设施、互联互通等国家重点工程建设工作。（责任单位：各县区）各县（区）、有关部门要坚持依法、合规、高效原则，简化优化天然气产供储销国家重点工程核准和建设程序，加快原址进口LNG接收站扩建等项目核准。（责任单位：各县区，市发展改革委、市工业和信息化委、市住房和城乡建设委、市环保局、市国土资源局、市安监局）

三、保障措施

（一）加强督促协调。市天然气产供储销体系建设及供应保障协调工作组负责统筹协调，监督推动民生用气保障各项工作落实，研究制定鼓励各县（区）、企业投入的支持政策，帮助解决推进工作中遇到的困难和问题。

（二）依法实施通报问责。对落实天然气供应保障工作不到位的单位和个人，将依据有关规定视具体情形分别责令其限期改正、予以内部通报、全市通报或建议有关部门给予行政处分，对问题严重的将依法追究法律责任。

（三）及时上报重大问题。对存在特别重大问题、保障民生用气各项工作未如期开展或严重滞后的单位和个人，市天然气产供储销体系建设及供应保障协调工作组办公室要及时报告市委、市政府。

（四）市政府将与各县（区）签订《民生用气保障责任书》，进一步落实相关责任。

各县（区）、有关部门要于6月15日前将落实情况报送市天然气产供储销体系建设及供应保障协调工作组办公室。
