# 本溪市人民政府办公厅关于成立本溪市第三次全国土地调查领导小组的通知

本溪市人民政府办公厅文件

本政办发〔2018〕81号

本溪市人民政府办公厅关于成立

本溪市第三次全国土地调查领导小组的通知

各自治县、区人民政府，本钢，市政府各委办局、直属机构：

为保证我市第三次全国土地调查工作顺利进行，市政府决定成立本溪市第三次全国土地调查领导小组。现将领导小组成员和主要职责通知如下：

组 长：隋显利 常务副市长

副组长：胡 勇 市政府副秘书长

吕彦明 市国土资源局局长

成 员：谢 冰 市发展改革委副主任

邓伟儒 市民政局副局长

柴慈祥 市财政局副局长

佟 军 市环保局副局长

刘小茹 市住房和城乡建设委副主任

杨 华 市水务局副局长

高凤娟 市农委副主任

李可丹 市统计局副局长

杨 萍 市林业局副局长

领导小组主要职责：负责我市第三次全国土地调查工作的组织实施，研究解决工作中出现的重大问题，保障我市第三次全国土地调查工作顺利开展。

领导小组办公室设在市国土资源局，负责领导小组日常工作，办公室主任（兼）。

任务完成后领导小组随即撤销。

本溪市人民政府办公厅

2018年10月25日
