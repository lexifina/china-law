# 本溪市人民政府办公室关于赋予本溪市桥北和本溪湖开发区管委会市级行政审批事项的通知

本溪市人民政府办公室文件

本政办发〔2019〕14号

本溪市人民政府办公室关于赋予

本溪市桥北和本溪湖开发区管委会

市级行政审批事项的通知

各自治县、区人民政府，本钢，市政府各委办局：

为充分发挥重点产业园区示范引领作用，进一步提高行政审批效能，实现“园区事园区办”，经市政府同意，现将赋予本溪桥北经济开发区和本溪湖经济开发区市级行政审批事项有关事宜通知如下：

市直相关部门要主动与平山区、溪湖区和桥北、本溪湖经济开发区管委会对接，按照“谁赋权、谁负责”的原则，加强指导和工作协调，及时处理赋权过程中遇到的困难和问题，切实做好赋权衔接工作。桥北、本溪湖经济开发区管委会要按照权责一致的要求，依法承担承接事项的管理职责，及时制定权责清单、编制办事指南，切实优化服务流程、提高办事效率，确保各项职权规范管理、优化运行。

附件：赋予桥北、本溪湖经济开发区管委会审批事项目录
