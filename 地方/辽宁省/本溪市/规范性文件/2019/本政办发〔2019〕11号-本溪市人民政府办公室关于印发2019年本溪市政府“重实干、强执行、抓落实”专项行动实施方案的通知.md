# 本溪市人民政府办公室关于印发2019年本溪市政府“重实干、强执行、抓落实”专项行动实施方案的通知

本政办发〔2019〕11号

2019年本溪市政府“重实干、强执行、抓落实”

专项行动实施方案的通知

经市政府同意，现将《2019年本溪市政府“重实干、强执行、抓落实”专项行动实施方案》印发给你们，请认真贯彻执行。

本溪市人民政府办公室

2019年2月28日

（此件公开发布）

2019年本溪市政府“重实干、强执行、抓落实”

专项行动实施方案

今年是新中国成立70周年，是决胜全面建成小康社会的关键之年。为确保完成省、市经济社会发展目标任务，按照省政府统一安排部署，市政府继续深入开展“重实干、强执行、抓落实”专项行动，特制定本实施方案。

一、总体要求

坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，深入贯彻落实习近平总书记在辽宁考察时和在深入推进东北振兴座谈会上重要讲话精神，全面落实中央和省委、市委经济工作会议精神，认真贯彻“一带五基地”和“五大区域发展战略”部署，以“三都”建设为突破，聚焦“争先晋位”目标，推进“抓党建促振兴、抓项目促发展、抓稳定促和谐”，确保如期完成全年各项目标任务。

二、主要任务

开展重点指标、重点工作、重点任务和重大项目“三重一大”四个方面抓落实专项行动。

（一）重点指标抓落实专项行动。围绕全市经济社会发展主要预期目标和省约束性指标，设定重点指标17项。

（二）重点工作抓落实专项行动。深入落实习近平总书记在辽宁考察时和在深入推进东北振兴座谈会上重要讲话精神，按照省、市《政府工作报告》目标任务和市委经济工作会议部署，坚定不移实施“工业强市、文旅兴市、生态立市”发展战略，设定重点工作199项。

（三）重点任务抓落实专项行动。明确任务，突出重点，在推动高质量发展上抓落实求突破，继续打好三大攻坚战，统筹推进稳增长、促改革、调结构、惠民生、防风险工作，着力办好15件民生实事，设定重点任务72项。

（四）重大项目抓落实专项行动。充分发挥有效投资的拉动和引擎作用，牢固树立“项目为王”理念，积极推进列入省“双百攻坚”的5个重大项目和1个重大招商项目，同时推进6类重大项目建设及储备工作。

三、实施步骤

（一）动员部署。2019年2月中旬，市政府召开“重实干、强执行、抓落实”动员部署大会进行全面部署。各县（区）、各部门要再动员再部署，全面动员、全体参与，进一步统一思想，明确任务，主要负责同志负总责，分管负责同志负直接责任，把责任落实到具体部门、具体人，针对每项任务制定具体工作方案，列出时间表、路线图，做到“一项任务、一名领导、一个团队、一张图表、一抓到底”。在承接市政府专项行动目标任务的基础上，要结合实际，认真制定本地区、本部门“重实干、强执行、抓落实”专项行动工作方案。各责任单位要选出责任心强、业务精、相对固定的分管领导和联络员，作为具体工作责任人。

（二）推进落实。成立2019年本溪市政府“重实干、强执行、抓落实”专项行动领导小组。

1.坚持问题导向，实行月通报、月调度、季推进、半年评估、全年总结工作机制。市政府常务会议每月听取一次专项行动进展情况汇报，市专项行动领导小组每季度召开一次推进会议，调度协调解决遇到的难点问题。

2.坚持以上率下，充分发挥领导干部示范带动作用。包县（区）的副市长要经常深入县（区）指挥调度，每半个月要调度一次。各级领导既要当好指挥员，更要做好战斗员和“施工队长”，率先沉入一线、走进现场抓落实，带头向前冲、扑下身子解难题。

3.坚持精准发力，形成各方协同、压茬推进的合力。牵头单位要切实负起牵头抓总的作用，其他责任单位要各司其职、各负其责，形成上下贯通、左右协同抓落实的工作格局。

4.坚持督查保障，更好发挥抓落实的利器作用。利用专项督查、现场督查、暗访督查等多种方式，对重点指标督进度、重点工作督质量、重点任务督成效、重大项目督服务，确保各项工作落实到位、举措行动到位、力量配置到位。

5.坚持宣传鼓劲，形成求真务实、真抓实干的良好氛围。加大宣传报道力度，充分发挥舆论导向作用，对各县（区）、各部门好经验、好做法、好机制要及时总结推广，引导广大干部群众积极参与、主动作为，展现本溪新风采，塑造本溪新形象。

（三）考核总结。2019年12月底至2020年初，对专项行动完成情况进行逐项考核、全面总结，考核结果拉开档次，考出差别、考出干劲。

1.实行定期考核通报制度。连续两个月通报排名在部门后五位及县（区）后两位的，在下个月的全市专项行动汇报会上要作出书面检讨。

2.建立督查考评奖惩机制。坚持线上实时督考，专项行动所有目标任务全部纳入市直机关工委和市政府办公室分别牵头的绩效考核体系，对标年度目标及月、季、半年节点内容完成情况进行督考。设立主要经济指标及重点工作为“一票否决”考核项目，包括：地区生产总值、一般公共预算收入、固定资产投资、规模以上工业增加值、社会消费品零售总额、城镇和农村常住居民人均可支配收入、养老金足额上解、化解政府债务、招商引资、项目建设、安全生产。未完成上述考核项目的县（区）及相应牵头责任部门，不能被评为“好”等次，每有一项未完成，年终评定结果降低一个等次，最低降至“基本合格”等次。不承担“一票否决”考核项目牵头责任的部门，年终完成目标任务数在百分之九十以下的不能被评为“较好”以上档次。

市政府办公室相关副主任

领导小组办公室设在市政府办公室，负责专项行动的综合协调、督查考评和宣传等日常工作。办公室主任由市政府办公室负责日常工作的副主任担任，副主任由市委宣传部相关副部长、市直机关工委相关副书记、市政府办公室相关副主任兼任。

办公室下设督考协调、综合材料、宣传报道3个组，人员主要由市政府办公室、市直机关工委、市委宣传部有关人员组成。

督考协调组：设在市政府办公室。负责专项行动的总体设计、综合协调、日常指导；组织好各类会议，牵头抓好分析研判；对各县（区）、各部门开展专项行动情况进行督查考核，根据每项任务自然属性科学设置序时节点、完成标准和时限，纳入对县（区）及市直部门绩效考核系统。

综合材料组：设在市政府办公室。负责综合性文稿的起草，编发简报，总结工作经验，促进工作成果转化等。

宣传报道组：设在市委宣传部（市政府新闻办）。负责专项行动的媒体宣传，总结宣传报道一批先进典型及工作中形成的好经验、好做法、好机制等。
