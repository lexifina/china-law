# 本溪市人民政府办公室关于印发本溪市2019年涉企行政执法检查计划的通知

本溪市人民政府办公室文件

本政办发〔2019〕19号

本溪市人民政府办公室关于印发

本溪市2019年涉企行政执法检查计划的通知

各自治县、区人民政府，本钢，市政府有关委办局、直属机构：

为进一步优化我市营商法治环境，规范和控制行政执法检查行为，保护企业和企业家合法权益，按照《辽宁省优化营商环境条例》和《辽宁省涉企行政执法检查计划管理办法》要求，我市对2019年涉企行政执法检查计划进行审核和汇总，经市政府同意，现将《本溪市2019年涉企行政执法检查计划》（已在本溪市人民政府门户网站http://www.benxi.gov.cn/上公示）印发给你们，同时提出如下要求，请一并认真贯彻落实。

各行政执法机关在履行涉企行政执法检查时，要切实打造优良营商环境，杜绝执法检查干扰企业正常生产经营活动，最大程序减轻企业负担。

对法律、法规规定的食品药品安全、安全生产、公共安全、环境保护等直接涉及人民群众生命财产安全的检查事项，有关行政机关要按照“双随机、一公开”要求，采取随机方式进行检查。

各县（区，含本溪高新区）要结合实际，参照本《通知》制定本地区2019年涉企行政执法检查计划，并积极组织实施。涉企检查计划要通过报纸和网站等形式向社会公示。
