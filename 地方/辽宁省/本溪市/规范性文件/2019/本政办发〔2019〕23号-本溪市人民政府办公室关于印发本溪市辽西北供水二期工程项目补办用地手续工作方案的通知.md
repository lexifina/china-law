# 本溪市人民政府办公室关于印发本溪市辽西北供水二期工程项目补办用地手续工作方案的通知

本溪市人民政府办公室文件

本政办发〔2019〕23号

本溪市人民政府办公室关于

印发本溪市辽西北供水二期工程项目

补办用地手续工作方案的通知

桓仁满族自治县人民政府，市政府有关委办局：

经市政府同意，现将《辽西北供水二期工程项目补办用地手续工作方案》印发给你们，请认真组织实施。

本溪市人民政府办公室

2019年5月23日

本溪市辽西北供水二期工程项目

补办用地手续工作方案

为落实国家自然资源督察沈阳局2018年例行督察时提出的对往年遗留下来的问题要尽快完成整改的要求，按时完成辽西北供水工程项目补办用地手续工作，特制定本方案。

一、工作目标

力争2019年6月底前完成辽西北供水二期工程项目补办用地手续上报省自然资源厅审查。

二、工作内容和步骤

（一）县级申报阶段（5月11日-6月20日）

建设单位向地方政府提出正式用地申请，提供预审、立项及初步设计批复等征地组卷必备要件，委托开展勘测定界、地质灾害危险性评估、编制土地复垦等方案，办理压覆矿产资源登记及征占林地、草原等手续，缴纳耕地开垦费、将征地补偿费等征地费用预存至专户。

县级政府组织生态环境等部门对项目用地是否位于保护区及用地是否符合保护区管理规定进行审核，组织人社部门对被征地农民参保资格进行审核和社会保障资金筹集工作。社会保险经办机构按照县级政府提供的人员名单及时办理参保缴费和享受待遇事宜。落实耕地占补平衡，涉及占用基本农田的编制土地利用总体规划修改方案、基本农田补划方案。

县级自然资源主管部门组织开展征地前期告知、确认和听证程序，编报“一书四方案”等材料，经县级政府审核同意后，报市级自然资源部门审查。

（二）市级审查申报阶段（6月21日-6月30日）

市级自然资源部门在收到上报的建设用地呈报说明书和有关方案后，组织有关科室进行审查，符合条件的，报经市政府审核后向省政府申请用地，并将审查所需材料报省自然资源厅审查。

三、工作要求

（一）提高认识，加强组织领导

县政府和自然资源主管部门要把思想和行动统一到市政府严格自然资源管理、加强宏观调控的要求上来，从全局战略高度，充分认识督察整改的重要性、紧迫性，不折不扣地抓好督察整改落实，确保整改工作按时限、高标准整改到位。

（二）政府主导，全面推进整改

县政府主要负责同志是督察整改的第一责任人，对督察整改工作负总责，分管领导具体抓落实工作。要把做好此项工作作为自然资源管理工作的重中之重来抓，统筹协调推进辽西北供水二期工程补办用地手续工作，及时发现、解决补办用地手续工作中的重点、难点问题。建立周报告制度，桓仁县每周要向市自然资源局报送《国家和省重点项目征地组卷报批进展情况表》。
