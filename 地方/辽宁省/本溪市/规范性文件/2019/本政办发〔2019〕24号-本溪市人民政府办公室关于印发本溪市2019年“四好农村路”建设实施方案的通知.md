# 本溪市人民政府办公室关于印发本溪市2019年“四好农村路”建设实施方案的通知

本溪市人民政府办公室文件

本政办发〔2019〕24号

本溪市人民政府办公室关于印发本溪市

2019年“四好农村路”建设实施方案的通知

各自治县、区人民政府，本钢，市政府有关委办局：

经市政府同意，现将《本溪市2019年“四好农村路”建设实施方案》印发给你们，请认真组织实施。

本溪市人民政府办公室

2019年5月24日

（此件公开发布）

本溪市2019年“四好农村路”

建设实施方案

为深入贯彻落实习近平总书记关于“四好农村路”建设的重要指示精神和全省深入推进“四好农村路”高质量发展工作电视电话会议精神，按照辽宁省交通运输厅《关于印发推进“四好农村路”建设实施方案的通知》（辽交公路发〔2016〕325号）要求，结合我市实际，特制定本方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党中央、国务院关于推进交通运输供给侧结构性改革的工作部署，以助力乡村振兴和脱贫攻坚为目标，进一步完善政策措施，调动一切积极因素，加快农村公路建设，切实“建好、管好、护好、运营好”农村公路，为我市广大人民群众致富奔小康提供交通运输服务保障。

二、工作目标

2019年我市“四好农村路”建设目标为：本溪县争创全国“四好农村路”示范县同时争创2-3个省级“四好农村路”示范乡，桓仁县争创2-3个省级“四好农村路”示范乡，明山区、南芬区争创1-2个“四好农村路”示范乡，全力打造9个乡（镇）27条204.08公里“畅、安、舒、美”的农村公路。同时，确保“四好农村路”建设各项工作扎实开展，不断提高广大人民群众的出行满意度。

三、工作任务

（一）以提质增效为重点，“建好”农村公路

1. 路面工程。全市计划打造27条204.08公里路线。其中，19条140.38公里已在2015年—2018年间进行了大中修，其他8条63.7公里路线计划2019年进行大中修，今年建设的工程要实体质量过硬，综合附属设施配套完善。

2. 安保工程。计划打造的27条204.08公里路线，需增设道口标柱、示警桩、减速带、诱导标、指路标志及旅游标志，以保证沿线百姓出行安全，特别是仙新线等游客较多、人流密集的路线。

3. 村屯治理。在“四好农村路”建设中，农村公路沿路村屯段治理是重要工作内容。今年打造路线中重点村屯段要做到浆砌边沟通畅、过道板及院落围墙样式统一。

4. 景点建设。要因地制宜、科学设计，以满足游客出行需要为前提，计划在重要旅游路线建设具有休息、购物、观景、拍照等功用的多功能景点1处，在旅游路线仙新线、产业路四刀线建设观景台各1处。

5. 文化墙建设。文化墙外观要达到乡或村统一，内容要有爱路、护路的村规民约，位于村内主要道路两侧，合理安排建设数量，严把建设质量，全面展现农村风貌。仙新线、四刀线等路线的文化墙需统一建设、粉饰。

（二）以完善体制机制为重点，“管好”农村公路

1. 在乡（镇）现有机构总量内，明确乡（镇）承担农村公路养护管理职能的机构，确定1名乡（镇）政府领导牵头、交通助理具体负责，可再聘用2名管理人员，负责组织实施辖区内乡村公路的路面保洁、路基整修、堆占清理、防汛除雪及日常巡查等公路养护管理工作。在建制村建立农村公路管理议事机制，明确1名村委会成员具体负责，聘用1至2名村民为护路员，负责村道巡线护路、查险报告、保洁等日常养护工作。

2. 路政管理工作由县（区）农村公路路政管理部门负责，开展路政安全、法制宣传活动、接受群众咨询、制作更新村规民约、散发宣传资料。乡村道限高、限宽设施要有计划地规范设置。联合交警、运管等部门开展路政专项整治工作，对农村公路的超载超限进行治理，对沿途的脏乱差、占道堆放物品、广告标牌随意摆放等行为进行清理，使农村公路行驶质量指数及路域环境大幅提升，保障公路畅通和环境优美。

（三）以环境整治为重点，“养好”农村公路

对今年打造的9个乡（镇）27条204.08公里农村公路养护要求如下：

1. 绿化美化。要进行绿化补植及栽种草本花卉。在做好乔木、灌木绿化的同时，要根据实际地形和花卉品种、花期特点进行多种形式的花卉栽种，进一步提高公路沿线绿化美化水平。要提高绿化养护管理水平，新植、补植树木成活率达到90%以上。

2. 路域环境。要修建双侧路肩，根据实际确定宽度，与黑色路面、边沟衔接顺畅，做到规范、美观、实用。同时，今年打造的路线需进行路域环境整治，以清理路域范围内的草堆、粪堆、垃圾堆、建筑垃圾、非法废品收购点、非公路标志及骑路市场为整治重点，全面深入推进公路沿线洁化、绿化、美化，实现公路沿线环境与自然的和谐统一。要把水天线、四刀线、曲四线作为示范路线，带动其他路线提高全市路域整治水平。

3. 养护管理。除日常养护工作以外，全市开展春秋两季养护会战，各县（区）要安排专职人员完成日常养护工作，病害由专业队进行定期维修，及时做好水毁抢险、除雪防滑工作，并做好各种应急预案制定工作。

（四）以提升服务为重点，“运营好”农村公路

积极推进县、乡、村三级农村物流网络节点体系建设，初步构建农村电商生态体系和服务体系，建成县（区）公共服务中心，构建县、乡、村三级服务网络。

推进和引导县（区）客运站增加物流服务功能，加快农村物流发展。发挥典型企业示范带动作用。2019年培育1家骨干农村物流企业和客运站融合；初步建成本溪县电商服务平台和桓仁县物流仓储配送中心，引导电子商务进农村和村级服务站。

四、工作步骤

（一）准备阶段（2019年3月20日至4月10日）

各县（区）按照全市统一部署，拟订具体工作方案，进行宣传发动，做好各项准备工作。

（二）建设阶段（2019年4月11日至9月30日）

各县（区）按照工作方案，统一推进各项工程建设，相关部门提供业务指导并进行质量、进度检查。

（三）总结阶段（2019年10月1日至10月31日）

各县（区）对“四好农村路”建设工作进行自查，市相关部门进行检查，总结经验，查找不足。

五、保障措施

（一）加强组织领导

各县（区）要成立以政府负责人为组长的领导小组，制定切实可行、符合实际的实施方案，做到任务清晰、责任明确、落实有力，要将“四好农村路”建设工作纳入政府工作目标，将目标完成情况按照有关规定纳入绩效考核。

（二）加强资金保障

要将农村公路建设与养护所需资金纳入财政预算。各县（区）应制定优惠政策，统筹解决农村公路建设、养护所需砂、石、土料场，生活用地、取水和供电等问题。要加大社会筹资、企业捐资、帮扶投入等政策支持力度，努力争取政府债券、各种扶贫和涉农资金用于农村公路发展，完善“以奖代补”政策。

（三）大力推行“路长制”管理

为解决多年来存在的农村公路重建设、轻管理的突出问题，加快健全我市农村公路及沿线环境管理长效机制，全市推行“路长负责制”。建立县（区）长任总路长，主管交通副县（区）长任县级路长，乡（镇）长任乡级路长，村委会主任任村级路长，乡（镇）派出所所长任警务路长，路政管理所所长任巡查路长的“六级路长”责任体系，明确责任分工，并定期召开路长工作调度会议。各级路长的主体责任须落实到位，同时设置“路长制”公示牌，广泛接受社会监督。

（四）积极开展争创示范县、示范乡（镇）活动

2019年全省将大力实施“四个一”工程，即建设10个示范县、100个示范乡、1000个示范村、10000公里乡村美丽示范路。各县（区）要高度重视示范引领作用，落实主体责任，以点带面，按照“经验突出、可推广、可复制”的原则，在示范县（区）基础上积极开展示范乡（镇）创建工作，全面推进我市“四好农村路”建设提质升级。

（五）加强工程质量管理

1. 2019年要把农村公路建设质量工作作为农村公路的工作主线，形成省里督导、市里指导、县里主导的上下联动质量管理体系。

2. 市级管理部门将加大检查力度及频率，并委托第三方检测机构对工程质量进行检测及不定期抽检，对质量存在问题的工程项目进行全市通报并要求限期整改。

3. 县（区）交通行政部门要监督检查施工质量、进度及工程质量动态管理，收集、发布工程质量信息。县（区）质监机构要对施工现场工程质量与安全行为进行监督检查。

4. 监理单位要严把开工审批关、施工过程检查旁站关，做好平行试验，工程转序前要进行现场核实检测。
