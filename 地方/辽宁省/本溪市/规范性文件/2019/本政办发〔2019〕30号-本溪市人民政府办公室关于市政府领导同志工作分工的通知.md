# 本溪市人民政府办公室关于市政府领导同志工作分工的通知

本溪市人民政府办公室文件

本政办发〔2019〕30号

本溪市人民政府办公室关于

市政府领导同志工作分工的通知

各自治县、区人民政府，本钢，市政府各委办局：

经研究，市政府领导同志工作分工如下：

同志：主持市政府全面工作，负责审计、营商环境建设方面工作。分管市审计局、市营商环境建设局（市行政审批局）。

吴世民同志：负责市政府常务工作，负责发展改革、财税、人力资源和社会保障、应急管理、统计、城投、县域经济、机关事务管理、社会稳定等方面工作；协助分管审计工作。分管市政府办公室、市发展和改革委员会（市粮食和物资储备局）、市财政局、市人力资源和社会保障局、市统计局、市应急管理局、市机关事务管理局、市城市投资公司；协助分管市审计局；负责联系市税务局、国家统计局本溪调查队等方面工作；负责联系市人大、市政协、民主党派、信访等方面工作。协助市长协调副市长之间的工作。

任尊严同志：负责教育、商务等方面工作。协助分管营商环境建设方面工作。分管市教育局、市商务局（市政府外事办公室）、市属院校。协助分管市营商环境建设局（市行政审批局）。负责联系工会、共青团、妇联、残联、侨联、海关、驻溪院校、对外友好协会等方面工作。

刘旭东同志：负责自然资源、住房和城乡建设、交通运输等方面工作。分管市自然资源局、市住房和城乡建设局（市城市管理综合行政执法局、市人民防空办公室）、市交通运输局；负责联系路政、地质等方面工作。

刘艳萍同志：负责科技、金融等方面工作。分管市科学技术局（市外国专家局）、市金融发展局、本溪银行；负责联系民族宗教、科协、社科联、老科协和人民银行本溪市中心支行、本溪银保监分局、银行、证券等驻溪金融机构等方面工作。

王会奇同志：负责公安、司法、打击走私等方面工作。分管市公安局、市司法局、市消防局；负责联系市中级法院、市检察院、国家安全等方面工作。

高巍同志：负责本溪高新技术产业开发区、工业和信息化、生态环境、国有资产监管和国企国资改革发展、市场监管等方面工作。分管本溪高新技术产业开发区管委会、市工业和信息化局（市国防科技工业办公室）、市生态环境局、市国有资产监督管理委员会、市市场监督管理局（市知识产权局）、市属企业；负责联系本钢集团有限公司，联系通信、邮政、电力、石化、烟草专卖、铁路、民航、港口、工商联等方面工作。

于庆伟同志：负责民政、农业农村、扶贫、水务、退役军人事务、林业草原、供销等方面工作。分管市民政局、市农业农村局（市扶贫开发领导小组办公室）、市水务局、市退役军人事务局、市林业和草原局、市供销社。负责联系市气象局、市慈善总会、驻溪部队、武警部队等方面工作。

牟傲风同志：负责文体旅游、卫生健康、医疗保障等方面工作。分管市卫生健康委员会、市医疗保障局；负责联系市文化旅游和广播电视局（市体育局、市文物局）、市文联、市红十字会、驻溪医疗机构等方面工作。

栾奎杰同志：协助市长处理市政府日常工作，协调市政府副秘书长之间的工作。协助分管市政府办公室、市机关事务管理局；办理市长、副市长交办的其他工作。
