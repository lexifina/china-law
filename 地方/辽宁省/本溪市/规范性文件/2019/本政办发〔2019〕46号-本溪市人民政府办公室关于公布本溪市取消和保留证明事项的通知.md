# 本溪市人民政府办公室关于公布本溪市取消和保留证明事项的通知

本溪市人民政府办公室文件

本政办发〔2019〕46号

本溪市政府办公室关于公布

本溪市取消和保留证明事项的通知

各自治县、区人民政府，本钢，市政府各委办局：

经市政府同意，现将《本溪市取消和保留证明事项》印发给你们，请结合实际认真组织实施。

本溪市人民政府办公室

2019年10月14日

（此件公开发布）

本溪市取消和保留证明事项

根据《国务院办公厅关于做好证明事项清理工作的通知》（国办发〔2018〕47号）和《中共本溪市委办公室 本溪市人民政府办公室关于印发<本溪市深入推进审批服务便民化实施意见>的通知》

（本委办发〔2019〕3号）要求，市政府对全市执行的证明事项进行了清理，现将取消的259项和保留的295项证明事项目录予以公布。

自本通知印发之日起，相关单位不得再向办事群众索要已取消的证明事项。对取消的证明事项，相关单位要积极配合，通过法定证照、书面告知承诺、政府部门内部核查和部门间核查、网络核验、合同凭证、主动调查等办理方式加大便民服务力度。

各县（区）、各部门和单位要登陆本溪市人民政府门户网站（http://www.benxi.gov.cn）政府文件栏目下载《本溪市证明事项取消目录》和《本溪市证明事项保留目录》。
