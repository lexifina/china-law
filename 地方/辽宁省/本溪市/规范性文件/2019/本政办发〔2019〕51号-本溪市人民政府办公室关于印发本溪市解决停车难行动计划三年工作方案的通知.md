# 本溪市人民政府办公室关于印发本溪市解决停车难行动计划三年工作方案的通知

本溪市人民政府办公室文件

本政办发〔2019〕51号

本溪市人民政府办公室关于印发本溪市

解决停车难行动计划三年工作方案的通知

各自治县、区人民政府，本钢，市政府各委办局：

经市政府同意，现将《本溪市解决停车难行动计划三年工作方案》印发给你们，请结合实际认真组织实施。

本溪市人民政府办公室

2019年11月26日

（此件公开发布）

本溪市解决停车难行动计划三年工作方案

为加快解决我市停车难问题，提升城市道路交通治理能力现代化水平，根据公安部、住房和城乡建设部《关于印发〈关于加强和改进城市停车管理工作的指导意见〉的通知》（公交管〔2019〕345号）要求，结合我市实际，制定本工作方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，坚持以人民为中心发展理念，立足城市交通发展战略，以解决中心城区停车难问题为目标，加快推进停车设施建设，盘活现有停车资源，着力提升城市停车管理水平，促进城市交通与社会经济协调发展。

二、基本原则

（一）坚持政府主导、协同共治原则。建立健全城市停车管理体制机制，明晰停车管理职责，形成政府统筹协调、部门密切配合、社区深度参与、社会协作共治的停车治理工作格局。

（二）坚持因地制宜、差别供给原则。按照“建筑配建停车为主，路外公共停车为辅，道路路内停车为补充”原则，分类确定停车设施建设规模，实现中心城区路内停车泊位的有序递减。

（三）坚持需求调控、价格引导原则。鼓励群众绿色出行，发挥市场价格杠杆作用，按照“路内高于路外、地面高于立体、地上高于地下、繁忙区段高于外围区段、拥堵时段高于空闲时段”的原则，制定差异化停车收费标准，合理调控出行停车需求。

（四）坚持信息驱动、资源共享原则。推进停车信息管理平台、停车诱导系统的建设应用，提升停车管理信息化水平。试行热点区域限时停车、即停即走，提升停车资源周转率。

（五）坚持重点突破、依法治理原则。加强老旧小区、医院、学校等重点区域的停车管理，规范设置停车设施，挖掘停车资源潜力。建立健全停车执法联动机制，着力消除停车乱象。

（六）坚持多元化投资建设原则。坚持“谁投资、谁受益”，实施市场运作、优惠政策，鼓励和吸引社会资本参与停车设施的开发、建设、经营、管理，通过市场机制解决停车难问题。

三、总体目标

用三年时间解决我市主城区停车难问题，2019年底初步缓解主城区停车难问题，2020年底基本解决主城区停车难问题，2021年底基本形成政府引导、企业为主、市场运作、结构合理、良性互动、健康发展的停车行业产业化发展模式。

四、主要工作

（一）健全完善停车管理制度，理顺停车管理体制机制

1.完善停车设施管理制度。市公安局会同市住房城乡建设局完善《本溪市机动车停车场管理办法》。

2.完善停车收费管理标准。市发展改革委负责制定差异化收费标准，运用价格杠杆，提高停车泊位周转率，规范停车秩序。

3.进一步规范停车管理。严厉查处违规停车行为、加大对违规停车机动车驾驶员处罚力度。

4.建立完善停车设施建设运营机制。加快推进停车产业化发展，广泛吸引社会资本投资城市停车行业，建立健全停车场经营管理的特许经营机制，引进专业公司进行统一经营和管理。

（二）盘活现有停车资源，科学调控停车需求

1.推动内部停车设施向社会开放。有序引导和鼓励具备安全管理条件的党政机关、企事业单位、居住小区停车设施在满足自用的情况下，全天对外开放，实行有偿使用、错时共享。

2.合理调控临时停车需求。加强路内停车泊位限时管理，严格控制停车泊位使用时段、时长，有条件的满足临时停车需求。

3.实施差异化停车收费政策。完善停车价格机制，严格依据相关法律法规规范停车收费管理，研究制定新的停车收费管理办法。对公益性停车设施和路内停车泊位，实行政府定价，根据区位、设施条件等推行差别化停车收费，调控停车需求。

4.鼓励市民绿色交通出行方式。大力发展公共交通，进一步完善慢行交通系统，吸引广大市民选择公共交通、自行车、步行等绿色交通出行方式，降低机动车出行停车需求。

（三）有序推进停车设施建设，优化停车供给结构

近期以增加供给为目标，重点抓好老旧小区、主要商业区、人口密集区等停车难问题突出区域的停车场建设工作。

1.编制停车设施专项规划。依据本溪市总体规划和本溪市综合交通体系规划，编制停车设施专项规划。

2.推动路外公共停车设施建设。积极推动停车楼、地下停车场、机械式立体停车库等集约化停车设施建设。鼓励在城市待建土地、边角空地等闲置场所设置临时停车设施。

3.依照停车设施专项规划，科学选址。充分开发既有道路、公园绿地等地下空间以及高架桥下、废弃工业厂房、闲置储备地块等资源建设停车场；对原有地面及地下停车场，鼓励依靠技术进步扩容改造为占地少、成本低、见效快的立体机械式停车设施；结合人防工程，建设“平战结合”停车场，对具备改造条件的已建人防设施，逐步改造为停车场；在中小学操场地下，以人防工程标准建设公共停车场；鼓励各企事业单位利用自有用地新建或改建停车场；对土地出让还未启动建设的项目，可建设临时公共停车场。

4.规范施划路内停车泊位。定期分析路内泊位的位置、数量等对交通的影响，一路一策、一位一研，逐年缩减、合理清退。泊位设置不得占用人行道，不得影响步行及非机动车日常出行。

（四）汇聚停车资源信息，提升停车治理智能化水平

搭建本溪市停车管理信息智慧交通管理平台，提升停车信息服务水平。建设停车泊位信息查询系统，实现信息资源共享，引导驾驶人及时泊车，有效提高停车设施利用效率。

（五）创新停车共治模式，破解重点区域停车难题

1.盘活一批闲置停车泊位。加大对主城区停车设施闲置情况监查力度，充分激活现有停车供给资源，严加惩处只售不租、挪作他用等导致停车泊位大比例空置行为，并责令其限期改正。

2.共享一批现有停车泊位。启动居住区与商业办公区、旅游景点等停车泊位错时共享。在上下学高峰时段，启动周边居住区停车设施向学校接送车辆共享，缓解城市动态交通压力。

3.挖潜一批停车泊位。结合老旧小区综合整治，在充分征求业主意见、保障消防通道畅通的基础上，规范施划停车泊位；有条件的老旧小区，利用空闲土地或通过“拆违房，建车位”等多种形式，在合适的区域因地制宜建设停车设施。

4.优化医院内外部停车组织。优化医院内部及周边交通组织，充分考虑就诊需求，加大停车设施供给。将医院职工停车需求向周边空余停车设施疏解，将医院停车位提供给就诊车辆。

（六）积极拓宽融资渠道

进一步扩大政府投资计划中公共停车场建设资金支出范围，可用于停车场相关设施建设等支出。拓宽停车场建设投融资渠道，由企业独立投资经营的，完全由企业投资建设并经营管理；由政府与企业合作投资经营的，按照“政府出地、市场出资”的政府与社会资本合作（PPP）模式操作。

五、2019—2020年具体工作任务

（一）2019年工作任务

1.由市公安局、市住房城乡建设局负责，于2019年10月15日前，完成对站前商圈地区、地工路及周边地区、消防地区、大峪周边地区4处重点区域内违章停车、占道经营等现象的集中整治工作。城建控股负责规范施划停车标线。

2.由市城市建设服务中心负责，于2019年10月15日前制定《本溪市机动车停放服务收费管理规定》。

3.由市城市建设服务中心、市公安局负责，于2019年12月30日前，补充完善《本溪市机动车停车场管理办法》。

4.由市发展改革委负责，城建控股配合，于2019年10月15日前，制定《本溪市机动车停放服务差别化收费标准》。

5.由市住房城乡建设局牵头，明山区、平山区、溪湖区政府负责组织实施，于2019年10月30日前，在主城区居住小区及周边挖潜和规范施划停车泊位5000个。其中平山区2000个、明山区2000个、溪湖区1000个。

6.由城建控股负责，于2019年10月30日前，对永丰立交桥下等17处社会公共停车场继续实行停车收费运营管理；对站前商圈、地工路周边、大峪、消防、南地、工字楼区域部分城市道路的路内、路上已施划的停车泊位实行试点收费运营管理。

7.由城建控股牵头，市公安局配合，于2019年10月30日前，完成全市停车资源调查工作。

8.由城建控股、市卫生健康委负责，于2019年12月30日前，完成工字楼区域（中心医院）立体停车场建设工作，新增停车泊位300个以上。

9.由本溪广播电视台负责，加大文明停车宣传力度，为停车行业发展营造良好的舆论氛围。

10.由市自然资源局负责，于2019年12月30日前，依托调查结果，编制完成《本溪市静态交通专项规划》。

（二）2020年具体工作

1.由市公安局、市住房城乡建设局负责，于2020年12月30日前，继续开展全市中心城区道路违规停车集中整治行动，彻底整顿车辆乱停乱放问题。

2.由平山区、明山区、溪湖区政府负责，市自然资源局配合，于2020年8月30日前，利用老平山区政府、丹霞商业综合体、溪彩路周边等土储用地或出让但未建设用地建设临时停车泊位1000个。由市住房城乡建设局牵头，平山区、明山区、溪湖区政府配合，于2020年8月30日前，在主城区居住小区及周边继续挖潜和规范施划停车泊位10000个。

3.由平山区、明山区、溪湖区政府和市住房城乡建设局负责，于2020年8月30日前，盘活世佳大厦、新宇公寓等既有公建和居住小区内的地上、地下闲置停车泊位及挪作他用的停车泊位共1000个。

4.由市机关事务局、市住房城乡建设局，平山区、明山区、溪湖区政府负责，于2020年12月30日前，推动市总工会、市住房城乡建设局、平山区政府、原市政府、小堡体育馆等有条件的机关及事业单位开放共享停车泊位2000个，开放小区共享停车泊位1000个。

5.由城建控股负责，于2020年12月30日前，搭建智慧停车管理信息平台，整合全市停车资源，对全市停车场实行规模化经营、专业化管理。在试点停车收费基础上，拓展收费范围，具备条件的全部实行停车收费运营管理。推广停车诱导系统，打造智能停车系统，严格管控路内停车；建立信息档案，动态调整路内泊位范围和规模；定期维护标志标线，灵活设置全天停车、夜间停车、限时停车等分时段泊位。

6.由市公安局负责，于2020年12月30日前，加大全市静态交通管理、加快电子警察建设，加强违法治理工作，重点路段违法停车及时发现、实时清拖。

六、工作措施

（一）加强组织领导

成立本溪市解决“停车难”问题工作领导小组，组长由市长担任，副组长由分管城市建设管理、公安工作的副市长担任，成员单位由市发展改革委、市教育局、市公安局、市司法局、市财政局、市自然资源局、市住房城乡建设局、市交通运输局、市文化旅游和广电局、市卫生健康委、市机关事务局、市行政审批局、平山区、明山区、溪湖区组成。领导小组办公室设在市住房城乡建设局，负责领导小组日常工作。

（二）建立联席会议制度

建立解决“停车难”工作联席会议制度，由分管城市建设管理的副市长召集，研究制定和完善停车场规划建设管理有关政策，审定停车设施年度建设计划，协调解决停车设施规划建设管理中遇到的问题。重大事项报市解决“停车难”问题工作领导小组决定。

（三）明确部门职责，出台配套政策和实施细则

市文化旅游和广电局负责做好舆论宣传工作。市公安局负责依法整治城市道路机动车辆乱停乱放，规范引导机动车有序停放；负责制定清理整治工作维稳预案，妥善处置突发事件；负责修订和完善《本溪市机动车停车管理条例》。各城区政府负责居民小区公共停车场建设、管理工作。市自然资源局负责停车设施用地及规划审批工作；负责研究制定停车场土地供应实施办法；负责编制停车场专项规划。市发展改革委负责制定社会公共停车场停车服务收费标准；负责城区公共停车场建设项目的立项及向上争取政策支持工作。市财政局负责停车场专项资金的筹措保障工作。市机关事务局牵头负责各党政机关和企事业单位专用停车场的规范化建设，做好单位停车场对外开放管理工作。市交通运输局负责加强公共交通、优化公交线路的实施工作；负责做好公交停车场的规划建设及公交停车场、道路客货运输场站配套（设施）管理工作。市卫生健康委负责优化中心城区医院内部及周边交通组织。市税务局负责贯彻落实各项税收优惠政策。市司法局负责审查有关部门制定停车行业发展的法规和规章，并对相关部门工作提供法制方面的指导。市信访局负责做好停车难整治工作的信访维稳工作。市教育局负责实施中心城区中小学错时上学和弹性放学，有效分散接送学生车辆集中停靠；负责推行家校合作等模式，由交通志愿者、值班家长或保安开车门接送学生。
