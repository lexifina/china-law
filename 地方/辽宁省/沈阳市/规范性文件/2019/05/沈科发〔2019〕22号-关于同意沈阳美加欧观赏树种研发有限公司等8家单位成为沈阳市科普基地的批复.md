# 关于同意沈阳美加欧观赏树种研发有限公司等8家单位成为沈阳市科普基地的批复

沈科发〔2019〕22号

各有关单位：

根据《沈阳市科普基地认定管理办法》(沈科发〔2017〕89号)规定，经沈阳市科普基地专家评审小组对申请单位的评审和市科技局、市科协联合审批，同意沈阳美加欧观赏树种研发有限公司等8家单位成为沈阳市科普基地。

希望以上8家单位以此为契机，探索科普宣传教育的新形式，广泛开展各种形式的科普教育活动，为沈阳市的科普工作做出新的贡献。

沈阳市科学技术局

2019年5月15日
