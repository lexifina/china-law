# 安康市人民政府办公室关于2012年上半年应急管理信息报送情况的通报

各县区人民政府，市政府各工作部门、直属机构：

今年以来，各县区、有关部门高度重视应急管理信息报送工作，采取有力措施，不断提升水平，及时真实反映了我市应急管理工作动态、突发事件、应急预案、应急演练、科普宣教等方面情况，信息报送工作走在全省前列，有力促进了我市应急管理工作。上半年，全市共报送应急管理信息1850 条，其中被省政府应急管理网站采用1349 条，被市政府办采用1692 条。为进一步做好应急管理信息报送工作，市政府办公室决定对上半年信息报送工作成绩突出的白河、紫阳、平利、石泉、宁陕、镇坪、汉滨、汉阴、岚皋县和市应急办、教育局、药监局、气象局等13 个单位予以通报表彰。

希望受到表彰奖励的单位珍惜荣誉，再接再厉，进一步加大信息报送力度，提高信息报送质量，推动应急管理工作更好开展。各县区、各相关部门要按照市政府办公室《关于转发〈陕西省应急管理网站信息报送工作考评办法（试行）〉的通知》（安政办函〔2012〕84 号）要求，从2012 年8 月开始，在完成规定信息报送任务的基础上，县区每月要报送2 条以上、市直部门要报送1 条以上视频类和论文类信息，各县区、各相关部门要按照新的要求，认真做好信息报送工作，力促全市应急管理信息工作再上新台阶。
