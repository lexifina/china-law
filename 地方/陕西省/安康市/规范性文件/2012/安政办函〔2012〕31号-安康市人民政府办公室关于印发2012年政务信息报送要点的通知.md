# 安康市人民政府办公室关于印发2012年政务信息报送要点的通知

各县、区人民政府，市政府各工作部门、直属机构：

现将《2012年政务信息报送要点》印发你们，请结合实际认真做好政务信息报送工作。

2012 年政务信息报送要点

2012 年是建设美好安康的启首年，也是“十二五”发展承上启下的重要一年。各信息报送单位要紧紧围绕市委、市政府的中心工作，进一步加强调查研究，确保全面、及时、准确的报送信息，为政府领导决策提供更加有效的服务。现提出 2012年政务信息报送要点如下：

一、关于新型工业发展

跟踪反映陕南循环经济发展规划实施情况，新型材料、清洁能源、富硒食品、装备制造等循环型工业产业发展情况，高新区和县域工业园区基础设施建设、招商引资情况。重点关注安康火电、金属镍、富硒矿泉水、旬阳烟厂技改、钒钛磁铁等重点工业项目建设情况，扶持劳动密集型产业政策措施及解决中小企业融资的做法。

二、关于城镇化建设

跟踪反映市域城镇体系构建情况，中心城市建设重点项目实施情况，城镇基础设施和产业建设情况，促进有条件农民进城落户政策措施落实情况。重点关注江北新区重点市政项目建设和东坝、西坝、新城等重点片区的综合改革情况，恒口统筹城乡一体化综合配套改革试验区和月河川道城镇带建设情况，各县城、10个市级重点镇和集镇新村基础设施建设、主导产业发展情况，促进有条件农民进城落户情况及推进措施。

三、关于现代农业发展

跟踪反映春耕备耕、“三夏”、秋收秋播进展情况，以粮果畜菜为重点的现代农业发展情况，劳务经济发展及新一轮扶贫开发工作推进情况。重点关注推动山林经济发展的措施及效果，各项农业补贴兑现情况，稳定粮食种植面积的具体措施、面临的困难和问题，56个现代农业示范园区、43个“一县一业”重点项目及月河川道现代农业产业基地建设情况。

四、关于生态旅游产业建设

跟踪反映“一山一湖一城”核心景区和四大旅游板块开发建设情况，旅游整合提升规划实施及重点景区、重点旅游村镇建设情况，以生态旅游发展带动三产服务业发展情况。重点关注大南宫山景区开发建设情况和岚皋旅游综合改革试点县推进情况，瀛湖 4A 级景区创建情况，30个旅游重点镇建设情况，龙舟节、油菜花节、茶文化节、美好安康欢乐游等节庆活动开展情况。

五、关于基础设施建设

跟踪反映交通、水利、生态等基础设施项目进展情况、遇到的困难和问题，城乡电网、气化安康、通讯设施等重点项目的实施情况。重点关注安平高速公路、安康富强机场开工建设情况，白河至陕鄂界高速、安岚二级路建成通车情况，东西坝防洪、洞河水库、引汉济渭、汉江综合治理工程建设情况，县城污水处理厂和垃圾无害化处理场建设情况。

六、关于保障和改善民生

跟踪反映八大民生工程建设进展，改善和保障民生的工作成效。重点关注“双高普九”和学前教育三年行动计划实施情况，去年开建的公办标准化幼儿园投入使用及今年新建、扩建幼儿园情况，避灾扶贫搬迁工程实施和保障性住房建设情况，社会保障体系完善及民生政策落实情况，新型农村养老保障试点和县级公立医院改革推进情况，及时总结涉及民生民计的典型经验和做法。

七、推进重点改革及对外开放

跟踪反映农村综合改革、金融体制改革、医疗卫生体制改革等工作情况。重点关注投融资平台建设、新一轮投资体制改革启动、农村土地经营权流转和林权制度配套改革、县级公立医院改革全面推进等情况。跟踪反映招商引资、进出口、对外经济技术合作以及投资环境整治情况。重点关注承接长三角、珠三角、环渤海等发达地区的产业转移情况，安康陆路货运口岸建设情况。
