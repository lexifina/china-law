# 安康市人民政府办公室关于2012年1至4月应急管理信息报送情况的通报

各县区人民政府，市政府各工作部门、各直属机构：

根据市政府办公室《关于做好全市应急管理信息报送工作的通知》（安政办函〔2010〕58号）和《关于2010年应急管理信息报送情况的通报》（安政办函〔2011〕15号）要求，现将 2012年1至4月全市应急管理信息报送情况予以通报。

各县区、各部门要提高思想认识，不断提高信息报送质量和时效性，切实完成任务，更加全面、及时地反映本单位工作动态；同时，要按照市政府办公室《关于征集〈安康工作交流〉稿件工作的通知》（安政办字〔2012〕17号）要求，认真总结应急管理工作领域的好做法、新经验，特别是具有全局指导性、引领性的有效探索和创新性经验，促进应急管理工作交流和调查研究，推动应急管理工作的有效落实和深入开展。
