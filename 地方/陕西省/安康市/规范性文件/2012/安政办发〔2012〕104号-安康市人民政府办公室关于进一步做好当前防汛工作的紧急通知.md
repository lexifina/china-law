# 安康市人民政府办公室关于进一步做好当前防汛工作的紧急通知

各县、区人民政府，市政府各工作部门：

入汛以来，我市局地强对流暴雨灾害天气频发，具有突发性、短历时、高强度、致灾重的明显特征。8 月5 日20 时至8 月6 日8 时，白河县东北部出现局地短时强降雨天气过程，其中中厂、冷水、麻虎、构扒等镇突降大暴雨，12 小时降雨量分别达到81.1、88.9、50.2、46.5 毫米，引发白河县境内红石河、冷水河、白石河等流域山洪暴发，部分镇遭受严重灾害损失。特别是6 日0 时至4 时白河县中厂镇雨量站降雨量达60.5 毫米；与中厂镇紧邻的红石河上游湖北省郧西县高桥、大垭子、皮鼓和郧县红岩背、鲍峡雨量站12 小时降雨量分别达到83.1、166.4、130.5、137、91.2毫米，预测中厂镇新厂、顺利、新营等村12 小时降雨量达到100至150 毫米。受湖北省襄阳、十堰区域性强降雨影响，红石河上游降雨与中厂镇周边强降雨叠加，导致红石河全流域山洪暴涨，来势迅猛，洪峰流量达到700 立方米每秒，水位高程196.49 米，接近1975 年“8.7”特大暴雨洪灾洪峰流量（50 年一遇）。白河县“8.6”暴雨洪灾，再次敲响了山洪灾害防御警钟，警醒我们防汛工作丝毫不可麻痹松懈。全市各级各部门务必坚决克服侥幸心理，始终保持高度警惕，严阵以待，继续全力以赴做好防汛减灾各项工作。

一、必须高度重视突发高强度暴雨山洪灾害防范工作。要采取更有针对性的措施，切实加强对强对流灾害天气和系统性强降水过程的监测预报预警。各级气象、水文部门要充分利用新一代天气雷达和现代化预报预警手段，加密监测频次，做好中小尺度暴雨天气和中小河流洪水预报，努力提高预测预报精准率、时效性。各级防汛指挥部门要发挥雨水情监测站网和防汛预警信息平台作用，及时分析会商雨情水情，综合研判决策，超前安排部署，提早做好灾害防范应对工作。

二、必须切实做好提前安全转移危险区域群众工作。各级各有关部门必须认真贯彻落实“生命至上、安全第一、预防为主、提前撤离”的防汛工作方针，当有灾害预警信息发布时，要及时启动应急预案，做到快速反应，有效应对。及早对居住在危险地带和危房中的群众坚决果断提前转移避险，做到不漏一户、不少一人。对老弱病残、鳏寡孤独、留守妇女儿童等重点人群要逐一落实包抓责任，坚持做到受威胁群众不撤离转移包抓责任人不离开。要认真落实汛期过渡性转移措施，将撤离转移工作落实在雨前、汛前、险情发生前，宁可早撤、多撤，也不能晚撤、少撤，尽量避免夜间和行洪期间撤离转移人员。提前撤离转移要做到决策果断、安置稳妥、返回有序，确保人民群众生命安全。

三、必须进一步加强信息预警工作。要认真贯彻落实7 月31日全市防汛信息预警到户现场会议精神，重要雨情、汛情要通过手机短信、互联网、广播电视、预警设施在第一时间传递到村到户，做到预警信息全覆盖。要重视和加强中小河流全流域洪水监测预报预警工作，做到上下游、左右岸、跨行政区域之间的信息交流互通。县区之间、镇办之间、村村之间要互通雨情、水情，灵通信息，相互照应。坚持走群众路线，依靠群众做好防汛工作，建立和完善群测群防体系，打好暴雨山洪地质灾害防范总体战。

四、必须进一步加大水行政执法力度。各级政府和水行政主管部门必须切实加强河道管理，严格水行政执法，依法清除河道障碍，确保洪畅其流；要切实加强水电站、库塘安全度汛管理，严禁超汛限水位蓄水，病险库塘一律空库度汛。各大中型水库要充分发挥削峰、滞洪作用，雨前汛前预泄滕库，行洪期间坚决服从各级防汛指挥部的统一调度，尽力消解洪水灾害。

五、必须切实加强防汛应急值守。各级各部门都要严格遵守汛期24 小时值班和领导干部在岗带班制度，及时传递防汛信息，果断处置防汛应急事项。尤其是要加强节假日和夜间防汛应急值守工作，确保应急指挥畅通高效。

六、必须进一步严格信息报送制度。各级各部门都要健全和完善防汛信息和重大事项应急报送制度，在出现重大汛情、险情和灾情时，必须在规定时间内及时准确上报，不得延误。
