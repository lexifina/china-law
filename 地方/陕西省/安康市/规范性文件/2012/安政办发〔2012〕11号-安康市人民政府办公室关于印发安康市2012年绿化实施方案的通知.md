# 安康市人民政府办公室关于印发安康市2012年绿化实施方案的通知

各县区人民政府，市政府各工作部门：

《安康市2012年绿化实施方案》已经市政府同意，现予印发，请认真组织实施。

二〇一二年二月二十三日

安康市2012年绿化实施方案

为改善人居环境，提升城市品位，建设生态安康，加快创建国家园林城市步伐，特制定本实施方案。

一、指导思想

坚持以科学发展观为指导，以建设美好安康为目标，以推进“双创”、改善生态环境为抓手，着力创建国家园林城市。坚持政府主导、市县（区）联动、部门包抓、突出重点、建管并重、讲求实效，深入开展全民造林绿化活动，推动以安康城区及其周边山体水岸、出入城市交通要道为重点的造林绿化实现新突破，把安康建设成为绿树成荫、植物多样、景观优美的生态宜居城市。

二、实施范围

以中心城区及其周边山体水岸、出入城市交通要道为重点，西至付家河、鲤鱼山北侧，南至瀛湖镇、县河镇，东至十天高速公路安康东收费站、襄渝铁路安康东站，北至西康高速公路安康北服务区。

各县区要围绕创建国家园林城市目标同步抓好县城以及重点镇造林绿化工作。

三、任务及重点

中心城区完成各类造林绿化8084.8亩，其中城市公共造林绿化1367.8亩，建设公路铁路两侧绿化带837亩，实施山体水岸造林绿化5880亩；社会义务造林绿化80亩、栽植大树2060棵、种花30万盆、新建草坪16200平方米（详见附表）。绿化树种主要为银杏、紫薇、香樟、桂花、含笑等适宜本地气候条件生长的品种，要保证绿化质量，保证成活率。

各县区要结合实际，加大造林绿化力度，增加城市绿地面积，提升绿化品味，提高绿化覆盖率和人均公共绿地面积。已创建为省级园林县城的宁陕、石泉、汉阴、旬阳、岚皋、平利六个县城要积极创建国家园林县城；未达到省级园林县城标准的镇坪、紫阳、白河三个县城年内成功创建为省级园林县城；全市20个重点镇要力争全部创建为省级园林镇，实现创建达标全覆盖。

（一）城市公共绿化。按照“改造提升江南、高标准绿化江北”的总体要求，启动建设奠安公园、高新区生态运动公园、西郊公园、汉调二黄园二期、香溪隧道口休闲公园、瀛湖路街心公园、陈家沟街心公园、张岭街心公园、南环干道规模绿地、滨江大道等三条示范街；重点建设安康大道、秦岭大道、南环干道、汉江路绿色通道；着力实施安康城区汉江一江两岸绿化提升工程，打造汉江三桥至十天高速公路汉江大桥两岸景观林带，努力扩大城市公共绿地面积。其中，春季启动香溪隧道口休闲公园、陈家沟街心公园和安康大道两侧绿化带、汉江三桥至十天高速公路汉江大桥北岸景观林带、南环干道绿化带建设。

（二）城市出入交通要道绿化。以乡土树种为主，采用苗高3米以上、胸径6㎝以上树苗，按照两侧林带不低于5m宽的绿化标准，搞好城市出入要道造林绿化，提升公路铁路沿线绿化水平。完成瀛湖干道、安平公路枣园至县河口、十天高速公路安康东收费站至安康西服务区、西康高速公路五里收费站至安康北服务区和襄渝铁路安康西站至东站铁路两侧绿化。上述造林绿化地块春季全部启动，年底达标验收。

（三）周边山体水岸绿化。按照“大坑大苗、一次成林”的总体要求，经济林木采用Ⅰ级苗，其它树种按照苗高2米、胸径2㎝以上的要求，完成鲤鱼山北坡直观坡面造林绿化5000亩，黄洋河口至县河口、月河口至五里镇尹家营、吉河口至回龙观河道两岸各20米的水岸造林绿化880亩。其中，春季完成山体造林绿化2000亩，水岸造林绿化300亩。

（四）搞好社会义务造林绿化。以开展创建“园林单位”、“园林小区”为载体，广泛开展全民义务植树活动。安康中心城市所有党政机关、企事业单位都要新栽3-5棵20公分以上带冠的树木、住宅小区新栽10-20棵20公分以上带冠的树木；无栽植大树条件的单位，要因地制宜地建设园林小品、增设树箱花钵和盆景花卉。积极推行建筑物、阳台、屋顶、墙面等立体绿化，大力倡导市民养花种草，提高义务植树尽责率，推动家居、庭院绿化，共建美好家园。

四、绿化用地落实

共需征占土地350.8亩，置换土地79.2亩，租赁土地1283.5亩、划拨土地390.3亩。周边山体水岸绿化涉及农户用地5600亩。

一是新征用地。汉调二黄园二期36.8亩、香溪隧道口休闲公园2亩、汉江两岸景观带15亩、安康大道南侧绿化带24亩、高新生态运动公园180亩。二是划拨用地。陈家沟统征中心27.8亩储备用地、汉调二黄二期公园25亩、西郊公园330亩、市公共资产管理局管理的市移民局办公场所7.5亩街心公园绿化建设用地、张岭街心公园10亩绿化用地。三是置换用地。陈家沟新华公司18.2亩、满意建材市场61亩。四是租赁用地。陈家沟街心公园24亩、南环干道120亩、城市出入口交通要道539.5亩租赁绿化用地。五是按绿线管理需要退出的土地。安康大道南北两侧沿线建设绿化10米绿化带，用地105亩。公共绿化和城市出入交通要道绿化项目所涉土地，由市国土局、统征办牵头，发改委、住建局、规划局及汉滨区政府和区级对应单位参加土地协调征收工作，拿出具体征收办法，该征用的办理征占手续，该置换的与当事人商议置换协议，办理置换手续，该租赁的政府统一办理租赁手续；周边山体水体绿化由林业局、水利局与涉及乡镇、村组和农民协商办理土地租赁手续。同时，由汉滨区政府做好绿化用地的土地流转、征地拆迁及外部环境等相关保障工作。

五、资金筹措

按照城市公共绿化由财政筹资（高新区绿化资金自筹），周边山体水岸绿化采取捆绑国家林业和水保项目支持，叠加造林项目资金每亩投资1000元,不足部分由市级财政筹资补贴，高速公路和铁路沿线采取财政筹资补贴租地，路权单位配套绿化资金，社会义务绿化由机关、企事业单位自筹绿化资金的资金筹措办法。实施上述工程总投资44841.4万元，2012年度造林绿化投资32766.3万元。其中：城市公共绿化23722万元，高新区实施绿化投资15898万元，城市周边山体水岸绿化1380万元，城市出入交通要道绿化1827.3万元。2012年春季绿化投资21642.3万元，资金来源：2012年春季投资20642.3万元，其中需财政配套13303万元，高新区自筹配套13193万元(详见附表)。

六、责任分工

按照“政府主导、市区联动，部门包抓、全民参与”的推进机制，在市政府的统一领导下，责任分工如下：市双创指挥部办公室：负责中心城市绿化的组织、协调、督查和考核。

市绿化委员会办公室：负责编制中心城市造林绿化规划设计、年度计划和山体水岸造林绿化技术规程的制定。

汉滨区政府：负责辖区重点集镇、村庄造林绿化和本方案造林绿化用地的协调、流转。负责组织动员城区镇办、机关单位、市民绿化。

高新区管委会：负责高新区内造林绿化的组织实施。

市住建局：负责城市规划区内造林绿化的组织实施。

市公路局：负责国道、省道造林绿化的组织实施。

市林业局：负责城市周边山体造林绿化的组织实施。

市水利局：负责城市周边水岸造林绿化的组织实施。

高速集团安康分公司：负责十天高速公路两侧及服务区、机关院落造林绿化的组织实施。

交建集团安川分公司：负责西康高速公路两侧及服务区、机关院落造林绿化的组织实施。

西安铁路局林业局：负责襄渝铁路安康东站至西客站两侧及机关院落造林绿化的组织实施。

水电三局实业有限公司：负责张岭辖区内机关、小区的绿化。

市财政局：负责筹措实施本方案所需资金。

市国土局：负责绿化用地的协调、供给。

市规划局：负责中心城市造林绿化规划选址定点、建设单位绿线退出用地、绿线控制和规划监管。

城区各镇（办）:负责组织、动员、督促辖区各单位、住宅小区和社区、居民搞好造林绿化。

城区各单位：负责搞好本单位办公区和住宅区造林绿化。

七、保障措施

（一）加强领导。各级各部门、各单位要按照责任分工，细化实施方案，夯实工作责任，强化保障措施，各司其职，密切配合，形成合力。主要领导要亲自上手，安排部署本单位的造林绿化工作，带头参加义务植树活动。建立定期督查、通报制度，市政府将各县区、各部门、各单位造林绿化任务完成情况纳入年度重点工作考核内容，考核奖惩。

（二）加大投入。加大财政投入，市财政要加快投融资集团的组建，广筹绿化资金，确保造林绿化需要；各有关部门要加大项目争取工作力度，按照“渠道不乱、用途不变”的原则，整合林业、农业、水利、扶贫开发等项目资金用于中心城市造林绿化；各单位要按照创建“园林单位”的要求，加大本单位造林绿化和养花种草投入；鼓励社会团体、企事业单位及个人以出资方式认养城市绿地和树木；全体市民要积极投身中心城市造林绿化活动，每个家庭养花3-5盆，美化家居环境。

（三）严格管理。切实加强对城市现有绿地、林木的保护，严格执行项目环境影响评价和林地征占用可研制度；严格绿线规划控制，所有建设项目将造林绿化同步规划、同步实施、同步验收，凡绿线规划不达标的新上项目，发改部门不得立项，规划部门不得审批，国土部门不得供地。

（四）抓点示范。各级各部门要按照市政府确定的年度绿化目标任务，科学规划，选准突破口，认真借鉴瀛湖绿化治理的成功经验，结合责任分工，通过层层抓点示范，带动全民植树活动深入开展。林业、住建、水利、公路、铁路、高新区管委会等部门都要认真组织开展好植树月、植树周活动。

（五）强化宣传。市内各新闻媒体要充分发挥舆论宣传和监督的主渠道作用，采取多种形式，切实加强对安康城区造林绿化工作的宣传报道，积极营造全民参与、社会共建美好安康的浓厚氛围。

八、前期准备

按照绿化建设工作的总体要求，为了高起点、高标准启动中心城市绿化建设，市政府召开2012年全市绿化建设工作动员大会和春季绿化启动仪式。

动员大会拟在安康学院西校区礼堂举行，时间初步定在3月初，拟邀请国家林业局、省有关领导出席，所有市级领导，各县区政府，市级各部门、中省驻安单位及城区周边镇办主要负责同志参加。会议由市双创办牵头组织，市政府办、林业局、住建局、绿化办配合，由市政府办和市林业局负责邀请国家林业局和省有关领导，市双创办负责草拟领导讲话。

启动仪式拟在动员大会结束后紧接着进行，地点放在高新区（财富广场周边）。启动仪式由市林业局牵头组织，高新区、市住建局配合。同时，由市林业局、高新区、市住建局分别做好鲤鱼山山体大绿化、财富广场绿化、安康大道南侧绿化带安康学院段绿化启动大现场和各项组织工作。
