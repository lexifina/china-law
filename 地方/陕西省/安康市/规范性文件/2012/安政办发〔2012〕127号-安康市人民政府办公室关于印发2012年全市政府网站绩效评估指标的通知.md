# 安康市人民政府办公室关于印发2012年全市政府网站绩效评估指标的通知

各县区人民政府，市政府各工作部门、各直属机构：

现将《2012 年安康市政府网站绩效评估指标》印发给你们，请结合实际，进一步做好政府网站建设和管理工作。

自2007 年起，我市已连续5 年对全市政府网站进行绩效评估，通过评估，全市政府网站建设水平及网站安全防护能力得到了显著提高，对发挥政府网站政务公开和政务服务平台作用，促进服务型政府建设起到了积极作用。

2012 年政府网站评估工作，将于12月1日正式开始，12月31日正式结束，1月初通报评估结果。请各参评单位对本单位门户网站的建设管理情况进行自查，并于11月30日前将自查报告报送市政府电子政务办公室。自查报告中应突出网站管理工作情况及网站的编审制度、读网制度、保密审查制度和应急预案等制度的建立执行情况。
