# 安康市人民政府办公室关于认真做好2012年投入产出调查工作的通知

各县区人民政府，市政府各工作部门、直属机构：

按照《省政府办公厅关于认真做好2012年投入产出调查工作的通知》（陕政办发〔2012〕46号）文件精神，为认真做好我市2012年投入产出调查工作，现就有关事项通知如下：

一、调查目的和意义

投入产出调查是国家统一安排的全国性大型专项调查和国情国力调查，是编制国家和地区投入产出表的重要基础，是国民经济核算体系的重要组成部分，包括投入产出调查、编制投入产出表和开展投入产出应用三个阶段。通过投入产出调查，为GDP核算提供总体框架与核算参数，为各产业计算资金、劳动、能源原材料等中间投入和增加值率，对提高GDP核算质量和如实反映经济社会发展成果至关重要。编制投入产出表，是开展政策模拟和定量分析的有力工具，运用投入产出表进行宏观、微观投入产出分析，对制定国民经济发展规划，推进经济结构调整，促进节能降耗和环境监测，加强宏观经济管理和科学决策具有十分重要的作用。各县区、各部门及各调查单位要从思想上高度重视投入产出调查工作，增强对投入产出调查工作重要性的认识，认真搞好相关调查工作。

二、调查对象和范围

2012年投入产出调查对象是我市的重点法人单位，涉及除农林牧渔业外的所有国民经济行业。具体范围包括：采矿业，制造业，电力、热力、燃气及水的生产和供应业，建筑业，批发和零售业，交通运输、仓储和邮政业，住宿和餐饮业，信息传输、软件和信息技术服务业，金融业，房地产业，租赁和商务服务业，科学研究和技术服务业，水利、环境和公共设施管理业，居民服务、修理和其他服务业，教育，卫生和社会工作，文化、体育和娱乐业，以及公共管理、社会保障和社会组织等。

三、调查内容和时间

调查的主要内容：法人单位的成本费用构成和利润，投资项目的投资构成等。

调查时期为2012年度。

四、调查组织和实施

市统计局负责全市总体调查方案的制定和组织实施，以及评估、审核、汇总调查数据等工作；由各县区人民政府负责本县区投入产出调查工作；市直相关部门积极参与、做好配合。

五、调查经费

投入产出调查所需经费由市、县财政部门分级负担并按照《统计部门周期性普查和大型调查经费开支规定》列入相应年度财政预算。

六、调查要求

（一）加强组织领导。投入产出调查内容覆盖国民经济各个行业，调查单位众多，工作量大面广，调查涉及生产、技术、财会、供销、统计等各个方面。时间紧，任务重，技术和质量要求高。为加强对全市投入产出调查工作的统一领导、组织协调和督导检查，确保调查工作的顺利开展，市政府成立安康市投入产出调查工作领导小组（名单附后），领导小组办公室设在市统计局，负责组织开展全市投入产出调查工作。各县区政府也要成立相应的领导机构与办事机构。各级统计、调查队、发改、财政、工信、国税、地税等部门要积极配合，按照全市统一安排和部署，扎实细致地做好工作。各级财政部门要按照分级负担的原则，确保投入产出调查经费列入财政预算，确保资金按时到位。

（二）落实工作责任。各县区、各部门及各被调查单位要确定一名领导负责投入产出调查工作的组织领导，及时协调解决工作中出现的问题；明确组织机构，落实工作人员，根据有关要求，结合我市实际，制定符合我市实际的实施方案。要组织安排业务人员参加统一培训，认真学习调查方案和填报方法；要根据调查任务，制定工作计划，规范调查流程，明确岗位职责，落实责任目标，按时完成本单位的调查任务。

（三）严肃工作纪律。各县区、各被调查单位要把好数据质量关，严格按照投入产出调查方案规定的部门分类、指标口径、计算方法，实事求是地认真填报，层层严格审核，确保基层调查数据的准确性、清晰性。要严格按照《统计法》有关规定和调查的具体要求，如实独立填报调查数据，任何地方、部门、单位和个人都不得虚报、瞒报、拒报、迟报。投入产出调查取得的资料，仅限于编制投入产出表和国民经济核算工作需要，不得作为任何部门和单位对调查对象考核、奖惩的依据。调查机构及其工作人员对调查对象的资料必须履行严格的保密义务。
