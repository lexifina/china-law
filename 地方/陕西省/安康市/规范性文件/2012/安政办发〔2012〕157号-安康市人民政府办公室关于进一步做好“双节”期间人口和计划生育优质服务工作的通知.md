# 安康市人民政府办公室关于进一步做好“双节”期间人口和计划生育优质服务工作的通知

各县、区人民政府、市政府各工作部门、各直属机构：

为做好2013 年元旦、春节期间人口和计划生育优质服务工作，现将有关事项通知如下：

一、抓好宣传倡导。要抓住“双节”期间的有利时机，大造宣传声势，营造浓厚的舆论氛围。加强计生科普宣传，充分利用科技、文化、卫生“三下乡”活动，组织计划生育服务车巡回各乡镇、村组，利用车站、码头、中心广场流动人口集聚地设立服务点，免费发放计划生育宣传品、宣传材料、避孕药具，开展温馨化、个性化、面对面、心连心的宣传教育活动；要加强政策宣传，把利益导向、奖励优惠、政策法规、依法行政等宣传有机结合，提高群众政策知晓率，依法征收社会抚养费，不断转变群众婚育观念。

二、实施“两项工程”。 扎实推进母亲健康和优生促进“两项工程”，树立检查质量是“两项工程”的生命线的理念，严格按照“服务优质化，质量标准化，程序规范化，管理精细化，全程法制化”的要求，切实把“两项工程”作为促进人口长期均衡发展和关注民生、改善民生的实事抓好抓实。充分利用“双节”期间流动人口返乡有利时机开展补查普治，严格按照宣传动员、调查摸底、健康教育、检查治疗、建立健康档案、效果随访六个环节开展工作，以检查和治疗为手段，以提高育龄群众生殖健康水平为核心，增强育龄群众遵守计划生育的积极性和主动性。进一步提升优质服务工作水平，坚持以长效节育措施优先落实的原则，注重工作方法，为节育手术对象提供人性化的温馨服务，确保手术安全。严格依法行政，防止工作方法简单粗暴，坚决杜绝重大恶性案件和节育手术事故的发生。维护社会稳定，严防越级上访、群体上访问题的发生。

三、推进均等化服务。落实流动人口“宣传教育、技术服务、优生优育、生殖健康、奖励优待、便民维权”六项均等化服务，将均等化服务纳入“两项工程”之中。认真实施流动人口免费技术服务项目，进一步拓宽流动人口药具免费发放渠道，实现流动人口避孕药具免费发放全覆盖。切实简化服务程序，努力提高办事效率，实行“首接负责制”，免费为育龄群众办理独生子女父母光荣证、流动人口婚育证明、一孩生育服务登记，免费提供孕情、环情检查，避孕节育情况报告单由现居住地镇（办）计划生育技术服务机构通过流动人口信息平台向户籍地通报。认真开展流动人口清理清查，落实流出人口“四个一”和流入人口“七项”服务管理制度，建好一人一档个案信息。加大流出人口、流入人口婚育证明的办理和查验力度，防止脱管漏管，杜绝违法生育，为均等化服务奠定坚实的基础。

四、开展“关怀关爱”活动。要高度重视“双节”期间走访慰问计划生育贫困家庭、农村流动人口留守家庭工作，为流动人口提供“六个一服务”（放映一场主题电影、进行一回走访慰问、组织一次健康检查服务、召开一个专题会议、主办一台文艺晚会、送一本书）。各级协会要积极协调社会各方面的力量，充分发挥自己的优势与特长，通过计生家庭创业帮扶、幸福家庭促进、生育关怀访视、贫困家庭慰问，帮助解决计划生育家庭和育龄妇女在生产、生活、生育中遇到的困难，赢得广大群众对计划生育工作的理解和支持。

各级政府要认真安排部署，制定具体的工作方案，引导各级干部群众积极参与，形成关心支持人口和计划生育优质服务工作的良好局面。要实行定期通报制度，县区每半月、市上每月对“双节”期间优质服务工作进度进行通报。市、县区统筹解决人口问题领导小组成员单位要按照本单位的职责，做好配合工作。人口计生部门要加强业务指导，及时掌握进展情况，主动解决发现的问题。卫生、教育、财政、民政、公安、人社等部门，要积极主动的发挥职能作用，促进优质服务工作顺利开展。

安康市人民政府办公室

2012 年12 月13 日
