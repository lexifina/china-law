# 安康市人民政府办公室关于进一步加强工商行政管理工作的通知

各县、区人民政府，市政府各工作部门、直属机构：

市场监管是各级政府的重要职能。工商行政管理部门是政府主管市场监管和行政执法的重要部门。面对工商行政管理体制实行分级属地管理的新形势，为充分发挥工商行政管理在推动循环发展、建设美好安康中的职能作用，不断提高工商行政管理部门服务、监管、执法、维权水平，努力开创我市工商行政管理工作新局面，根据省政府办公厅《关于进一步加强工商行政管理工作的通知》（陕政办发〔2012〕82 号）精神，结合我市实际，现就进一步加强全市工商行政管理工作通知如下：

一、围绕发展大局，创新政策措施，提高服务效能

（一）壮大市场主体，积极促进全民创业。按照“催生一批、培育一批、引进一批、优化一批”的思路，建立健全有利于市场主体培育、有利于社会投资和资本整合的企业登记注册制度。大力支持国有企业改制重组，全面落实民间资本进入基础设施、市政建设、社会事业等领域的相关政策；积极开展动产抵押、股权质押、商标权质押、土地山林使用权入股、融资性担保公司和小额贷款公司登记管理工作，努力扩大融资渠道，积极支持民间资本投资创业；加大支持小微企业发展力度，引导有条件的个体户转型升级为企业，在名称字号使用、市场准入条件、经营范围核定等方面，提供政策支持和服务；积极培育多元化的市场主体，促进全民创业，支持非公有制经济发展。

（二）服务产业发展，做大做强园区经济。围绕现代农业、新型工业、现代旅游业和文化产业，发挥工商部门企业登记职能作用，继续支持清洁能源、新型材料、富硒食品、生物医药、安康丝绸、生态旅游、装备制造、汉水文化等产业发展，落实重大项目提前介入、主动协调、跟踪服务制度，支持组建企业集团，优化投资环境。支持安康高新区、恒口示范区及县级工业园区经济发展，制定扶持发展的优惠政策，引导各类企业在园区内和跨区域进行横向联合、纵向延伸，促进资本要素流动，实现发展优势互补，推动园区经济健康快速发展。做好文化部门转企改制相关登记工作，促进文化产业繁荣和发展。健全市场主体信息动态监测和定期发布制度，综合分析产业结构、行业特点和投资趋势，

为政府决策、投资创业和社会公众提供信息服务。

（三）推进商标战略，努力打造驰名品牌。建立商标战略阶梯式发展规划，推进一所一标工程，引导市场主体注册商标，积极培育市级知名商标、省级著名商标和国家驰名商标。重点帮扶企业集团、特色产业、地方名优产品、旅游资源注册产品商标、服务商标和地理标志商标。指导企业运用商标品牌价值，增强核心竞争力，扩大市场占有率，做大做强自主品牌。加强商标行政执法，切实保护注册商标专用权。

（四）完善惠农扶农政策，支持社会主义新农村建设。进一步夯实红盾护农、经纪活农、合同帮农等工作措施，大力支持现代高效农业园区发展现代农业，继续加大农民专业合作社发展力度，加强对农村经纪人的培育发证管理工作，要充分发挥经济合同管理职能，加强对涉农合同和订单农业的指导，大力支持进城农民、迁移扶贫农民和返乡农民投资产业发展，创办小微企业，支持三农工作，促进农村社会和谐和经济发展。

二、加大执法力度，不断提高市场监管效能

（一）努力加强流通领域食品安全监管工作。深入贯彻落实《食品安全法》，按照中省调整工商行政管理体制加强食品安全监管工作的决策部署，建立健全政府统一领导下的食品安全工作综合协调机制。各级工商部门要把流通环节食品安全监管工作作为监管执法的重中之重，健全食品安全管理工作体系，落实监管责任的各项措施，全面推行监管责任制度、索证索票、质量检测以及市场准入、商品退市和经营者自律一系列制度措施，杜绝不合格食品进入市场销售，为人民群众创造安全放心的食品消费环境。各县区要大力支持工商机关履行流通领域食品安全监管职责，为工商监管执法工作创建良好的条件和环境。

（二）切实维护良好的市场秩序。要综合发挥市场监管和行政执法职能，把流通环节商品质量监管、惩治虚假违法广告、打击传销规范直销、治理商业贿赂、查处取缔无照经营等市场监管执法工作纳入社会管理综合治理的重要内容，加强领导，协调配合，切实维护良好的市场环境。加强对粮食、成品油、汽车等重要商品市场监管，加大反垄断和反不正当竞争执法力度，严厉打击违法经营行为，切实维护市场物价基本稳定。继续推进市场主体信用分类监管，完善市场经营风险和监管风险预警防范机制，积极探索实践网络商品交易等监管新领域。继续加大信息网络技术在市场监管和行政执法中的推广和应用，不断提升政府的市场监管能力和水平。

（三）加强消费维权效能建设。进一步巩固和完善工商系统12315 行政执法网络体系建设，大力推进消费者协会分会、消费者投诉站和12315 联络站“一会两站”进商场、进超市、进市场、进企业、进景区等“五进”活动，积极推进工商所执法小组进驻12315 站点，不断完善基层消费维权网络。街道办事处、镇政府以及社区、村委会要将站点建设和消费维权工作，纳入社会管理、矛盾调解和维稳工作的重要内容常抓不懈。加强消费维权宣传和科学消费引导，提高消费者依法维权意识和科学消费理念，充分发挥消费提高生活水平、拉动经济增长的重要作用。

三、为工商行政管理部门发挥职能创造条件

（一）保障工商行政管理经费。工商行政管理体制调整后，上级财政划转的工商部门经费基数，下级财政不得挤占和挪用，下划后增加的人员和经费由同级财政另行增加预算。根据地方财力增长情况逐步增加各项专项工作所需经费，特别是要加大对流通领域食品安全监管、打击传销、惩治虚假违法广告、实施商标战略、“一会两站”建设等工作的支持。在应对重大疫情、重大自然灾害、重大社会事件以及各类突发事件中，要做好财力保障，积极争取上级支持，确保工商部门有效开展工作。

（二）继续推进工商部门基础设施规范化建设。根据实际工作需要，要逐步改善和提高基层工商部门的办公条件和装备水平。市工商局要加强对基层工商部门基础设施规范化建设的指导和监督。各县区及有关部门要帮助解决工商部门基础设施建设中存在的突出困难，在用地规划、拆迁补偿、配套设施建设及权证办理、规费减免和建设资金配套等方面予以支持。同时，要积极争取中省有关基层工商所基本建设项目和省工商局基础建设配套资金支持。各级工商部门下划的办公用房、执法装备等固定资产要维持现状、保持稳定，不得随意调拨或挪作他用。

（三）加强工商系统信息化建设。按照“统一规划、统一标准、统一建设、统一管理”的要求，大力支持红盾网络系统建设、运用、管理和维护，网络建设、改造等费用实行分级承担，市、县财政要纳入经费预算。要加强数据库建设，完善综合服务平台、公共服务平台和内部管理平台，不断提升工商行政管理信息化应用能力和服务水平。

四、切实加强对工商行政管理工作的组织领导

各级政府要将工商行政管理事业的科学发展纳入经济社会发展总体规划，以体制调整为契机，进一步加强对工商行政管理工作的领导，高度重视，及时研究解决工作中的重大问题。

（一）加强各级工商部门领导班子建设。进一步加强各级工商部门领导班子思想、组织和作风建设，不断提高各级领导班子的政治素质和履职能力。加快理顺干部层级管理关系，完善干部选拔任用制度，重视关心工商干部的政治成长，完善后备干部培养管理制度，为工商行政管理事业发展打下坚实的组织基础。健全对各级班子的考核机制，加强对市政府重大决策部署以及有关组织纪律和廉政规定执行情况的监督检查，确保政令畅通。

（二）加强干部教育培训。按照分级、分类的原则，继续深化工商干部全员培训和素质提升工程，着力培养专家型、复合型人才，改善队伍知识结构和能力素质结构，促进人才在工商部门依法履职过程中发挥积极有效的作用。把思想政治教育、职业道德教育和业务知识培训紧紧结合起来，不断深化工商文化建设，始终保持爱岗敬业、奋发有为的精神风貌。

（三）支持工商部门依法行政。进一步加大对工商部门执法工作的支持，破除地方保护主义，特别在案件查办中减少人为干扰因素。加强市场监管相关部门的协作配合，健全工作机制，形成工作合力，共同维护健康有序的市场环境。进一步落实执法责任制，完善政务公开、监督制约、执法检查等依法行政制度措施，不断提高执法水平和工商执法的公信力，为建设法治政府做出新的贡献。

安康市人民政府办公室

2012 年12 月18 日
