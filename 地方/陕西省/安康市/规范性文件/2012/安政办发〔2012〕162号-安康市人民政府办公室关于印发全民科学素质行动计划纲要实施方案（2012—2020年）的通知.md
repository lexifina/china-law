# 安康市人民政府办公室关于印发全民科学素质行动计划纲要实施方案（2012—2020年）的通知

各县区人民政府，市政府各工作部门、各直属机构：

《安康市全民科学素质行动计划纲要实施方案（2012—2020年）》已经市政府同意，现印发给你们，请认真贯彻执行。

安康市人民政府办公室

2012年12月27日

安康市全民科学素质行动计划纲要实施方案

（2012-2020年）

国务院颁布的《全民科学素质行动计划纲要》（以下简称《科学素质纲要》），是国家制定的第一部提高全民科学素质的纲领性文件，是贯彻落实《中华人民共和国科学技术普及法》和实施《国家中长期科学和技术发展规划纲要》的重要举措，体现了党和国家落实科学发展观、在全社会培育创新精神、全面建成小康社会的总体要求。为了进一步做好《科学素质纲要》在我市的贯彻实施工作，根据国务院关于实施《科学素质纲要》工作的总体部署和陕西省贯彻《全民科学素质行动计划纲要》实施方案，结合我市的实际情况，特制定本实施方案。

一、指导思想及主要目标

指导思想：高举中国特色社会主义伟大旗帜，以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，继续坚持“政府推动、全民参与、提升素质、促进和谐”的指导方针，关注民生、面向基层，完善机制、提升能力，加强领导、开拓创新，实现科学技术教育、传播与普及的公平普惠，不断提高全民科学素质，促进我市社会主义经济建设、政治建设、文化建设、社会建设以及生态文明建设的全面协调可持续发展。

主要目标：按照《科学素质纲要》确定的目标，全国“到2020年，科学技术教育、传播与普及有长足的发展，形成比较完善的公民科学素质的组织实施、基础设施、条件保障、监测评估等体系，公民科学素质在整体上有较大幅度的提高，达到世界主要发达国家21世纪初的水平”。因此，通过努力我市公民科学素质到2020年要基本达到全省平均水平，力争达到全国平均水平。

二、主要任务及责任分工

（一）组织实施未成年人科学素质行动。实施素质教育，加强基础教育阶段的科学教育；整合校内外科学教育资源，建立校外科技活动场所与学校科学课程相衔接的有效机制，充分发挥科技馆、青少年宫等活动场所的科普教育功能，开展好“大手拉小手科技传播行动”、科技专家进校园(社区、科普基地)、中学生进科研院所(实验室)等活动，促进科技工作者与未成年人交流，激发中小学生科学兴趣，增强实践能力，培养科学理念；营造崇尚科学的校园文化氛围，普及和倡导保护生态环境、节约能源资源、心理生理健康、安全避险自救等科学知识和理念，加强珍爱生命、远离毒品和崇尚科学文明、反对愚昧迷信的宣传教育。重视家庭和社区教育在未成年人素质教育中的作用。

此项工作由市教育局、团市委作为牵头部门，市委宣传部、市科技局、市人社局、市文广局、市卫生局、市委党校、市妇联为责任单位。

（二）组织实施农民科学素质行动。围绕科学生产和农业增效、农民增收，组织好“科技致富工程”、“星火计划”和“科普惠农兴村”项目的实施；切实抓好农村党员基层干部适用技术和市场经济知识培训、阳光工程、“农函大”、妇女“双学双比”等科技培训项目；广泛开展“三下乡”、“科技之春”、“科技周”、“科普日”等活动，重点宣传农业科技、健康卫生、移风易俗和反对愚昧迷信、陈规陋习等知识和观念，促进社会主义新农村建设；开展科技进步示范县区和科普示范县区、乡(镇)、村、户、示范基地建设，建立和完善科普示范体系；切实抓好农村技术推广体系建设与改革，加强农村基层科技传播与服务网络体系建设，做好农民专业技术职称评定工作，发展农村基层科普组织和农民合作经济组织，充分发挥科技社团的作用，组织专家咨询服务和志愿者队伍，建立健全科技人员为“三农”服务的长效机制。

此项工作由市农业局、市科协作为牵头部门，市委组织部、市委宣传部、市教育局、市科技局、市人社局、市文广局、市卫生局、市总工会、团市委、市妇联为责任单位。

（三）组织实施城镇劳动人口科学素质行动。针对走新型工业化道路和发展现代服务业的要求，以提高职业技能和技术创新能力为重点，搞好第二、第三产业从业人员的科学素质培训；针对城镇化进程的要求，搞好进城务工人员职业技能和适应城市生活能力的培训；针对失业人员搞好再就业能力、创业能力和适应职业变化能力的培训；将劳动人口应具备的基本科学素质内容纳入各类职业教育和成人教育培训课程，并作为培训、考核和鉴定内容；要充分发挥科技社团在各类执业资格认证工作中的作用；要充分发挥企业科协、职工技协、技术研发中心等组织和机构的作用，鼓励开展“职工技能大赛”、“讲创新、比贡献”、“金桥工程”、“厂会协作”等群众性技术创新和发明活动；要进一步开展好“科教进社区”活动，通过开辟社区科普活动室、建立科普画廊、创办科普学校、举办市民科普论坛等各种有效形式，建设学习型社区。

此项工作由市总工会、市人社局作为牵头部门，市委宣传部、市教育局、市科技局、市农业局、市文广局、市卫生局、市委党校、团市委、市妇联为责任单位。

（四）组织实施领导干部和公务员科学素质行动。以弘扬科学精神、提倡科学态度、讲究科学方法、增强科学行政能力为重点，认真搞好领导干部和公务员的科学素质培训工作；党校、行政院校和干部学院要将提高领导干部、公务员科学素质列入教学计划；各级党政机关干部教育培训工作主管部门及科技社团，要定期举办讲座、报告会、知识竞赛等科普活动，积极组织领导干部和公务员参加各种社会科普活动；要面向领导干部和公务员，编辑出版科普读物，介绍现代科技知识及发展趋势。

此项工作由市委组织部、市人社局作为牵头部门，市委宣传部、市科技局、市卫生局、市委党校、团市委、市妇联为责任单位。

（五）认真抓好科学教育与培训工程建设。加强科学教育基础设施建设，为开展科学教育与培训提供基础条件支持；加强科学教育师资力量，积极发展专业科学教育教师队伍，同时要组织动员高等院校、科研院所、科技社团的专家学者参加到科学教育工作中来；充分发挥社会教育体系在科学素质建设中的基础性作用，加强义务教育、高等院校、行政院校、职业学校、函授学校、广播电视学校等教育机构的科学教育和培训功能，鼓励和支持科技馆等科普场馆、社区学校、文化技术学校等开展科学教育与培训。

此项工作由市教育局、市人社局作为牵头部门，市委组织部、市委宣传部、市发改委、市科技局、市农业局、市文广局、市委党校、市总工会、团市委、市妇联为责任单位。

（六）认真抓好科普资源开发与共享工程建设。建立激励机制，充分发挥科技社团的作用，引导、鼓励和支持科普产品和信息资源的开发，繁荣科普创作；集成市内外科普挂图、展教品、科普文艺作品以及图片等各类科普资源，扩大科普信息资源的共享范围，为社会和公众提供科普资源支持和服务；针对公众生产生活的实际需求，组织编制简明生动的科普图书、音像制品、电子出版物等科普产品，创作编写一批高质量、成系列、广覆盖的通俗科普读物；逐步建立面向贫困地区的公益性科普产品配送共享制度。

此项工作由市科技局、市文广局、市科协作为牵头部门，市委宣传部、市农业局、市卫生局、市委党校为责任单位。

（七）认真抓好大众传媒科技传播能力建设工程。建立与公众需求相适应的大众科技传媒管理体制与运行机制；加大公众传媒的科技传播力度，采取有力措施，增加电台、电视台科技教育频道、栏目的播出时间，丰富节目内容，并不断提高节目质量，增强科普类节目的趣味性、知识性，扩大覆盖面，充分发挥大众传媒科技传播的倍增作用；逐步增加综合性报刊科技专栏、各类科技出版物的品种和发行量；建设科普网站和门户网站的科技专栏，研究开发网络科普的新技术和新形式；提高各类媒体对于公共卫生事件和重大自然灾害等突发事件的应急反应能力，指导公众以科学的行为和方式应对突发事件。

此项工作由市委宣传部、市文广局作为牵头部门，市科技局、市教育局、市农业局、市卫生局、市总工会、团市委、市妇联为责任单位。

（八）认真抓好科普基础设施工程建设。切实加强科普场馆建设。有条件的县区要力争建成有地方特色的科普活动中心；在城市中心、人流密集区域规划建设较高水平的科普画廊，有关城市规划、建设、管理部门要给予大力支持；积极在城市社区和农村建设科普画廊、科普活动站、科普宣传栏、网络远程科普宣传教育终端等设施，有条件的学校可以建立校内科技活动场所；积极争取中省科协支持，为我市配备科普大篷车，为各县区配备科普宣传车；不断拓展和完善现有科普基础设施的科普教育功能，充实内容、改进服务、激发活力；充分开发利用社会资源，发展建立科普教育基地和青少年科普教育基地；加大对公益性科普设施建设和运行经费的公共投入，落实科普场馆对未成年人和老年人的优惠措施。

此项工作由市发改委、市科协作为牵头部门，市委组织部、市科技局、市教育局、市财政局、市人社局、市农业局、市文广局、市委党校、市总工会、团市委、市妇联为责任单位。

三、保障措施

（一）加强组织领导。为了切实推进《科学素质纲要》在全市的贯彻实施工作，市政府成立安康市全民科学素质工作领导小组，领导小组组长由市政府分管副市长担任；副组长由市政府相关副秘书长、市科协主要领导担任；成员由市委组织部、市委宣传部、市教育局、市科技局、市发改委、市财政局、市人社局、市农业局、市文广局、市卫生局、市委党校、市总工会、团市委、市妇联、市科协等部门有关负责同志担任。领导小组下设办公室，办公室设在市科协，办公室成员由领导小组各成员单位相关科室负责同志担任，办公室设联络组，由领导小组各成员单位相关科室工作人员组成。

领导小组负责对贯彻实施《科学素质纲要》工作进行指导；研究制定《科学素质纲要》实施工作中的意见、措施、办法；协调解决实施中存在的重要问题；对各县区政府、各部门的实施工作情况进行督促检查和表彰奖励。

领导小组各成员单位按照各自职能范围积极开展工作，牵头部门按照本方案提出的主要任务和职责分工，会同责任单位研究制定可操作的具体实施方案，并负责组织实施，领导小组成员单位以外的有关部门，也要结合本部门实际，积极参与实施工作。

领导小组办公室承担领导小组日常工作；督查并落实领导小组会议决定事项；提出实施《科学素质纲要》的具体措施和建议，提出并研究年度工作计划。

各县区政府要建立健全《科学素质纲要》实施工作组织机构，将公民科学素质建设工作纳入当地国民经济和社会发展总体规划，把实施《科学素质纲要》的重点任务列入年度工作计划，纳入目标管理考核。

（二）完善政策法规。认真贯彻《科普法》和《科学素质纲要》，完善有关公民科学素质建设的政策法规，进一步明确政府、企业、社会组织及公民个人在全民科学素质建设中的责任、权利和义务。研究制定鼓励科普产品创作的相关政策与措施；研究提出鼓励支持广播、电视增加科技节目播出量，进一步提高节目质量的政策措施；制定、完善鼓励社会力量捐资赞助科普活动、开发兴办科技教育、传播与普及事业的相关政策措施；研究制定加强城镇社区委员会和农村村民委员会科普工作力度的相关政策措施。

此项工作由市科技局作为牵头部门，领导小组其它成员单位为责任单位。

（三）加大经费投入。按照《中华人民共和国科学技术普及法》和《科学素质纲要》的有关规定，全市各级政府要依法加强科普工作，将科普经费列入同级财政预算，并按照省市有关规定逐步提高科普经费的增长幅度。各有关部门、事业单位和人民团体根据各自承担的《科学素质纲要》实施任务，按照财政预算管理规定和现行资金渠道，统筹考虑和落实所需经费。广泛倡导捐资赞助，开辟社会资金投入渠道。

此项工作由市财政局作为牵头部门，领导小组其它成员单位为责任单位。

（四）加强队伍建设。加强中小学科学教育教师队伍建设，鼓励师范院校开设科学教育专业，培养专业科学教育教师；积极培育发展科普产品创作队伍，发现培养创作人才；采取各种有效措施，动员引导、鼓励支持社会力量开展科普产品创作活动；支持科技社团的专家主动参与科学教育、传播与普及；发展壮大科普志愿者队伍，调动科技人员、大学生、传媒工作者及离退休人员参加全民科学素质建设的积极性，并强化业务培训，提高其专业水准。

此项工作由市人事局、市科协作为牵头部门，领导小组其它成员单位为责任单位。

（五）做好监测评估。根据《中国公民科学素质基准》和《科学素质纲要》实施的监测指标体系，做好全市公民科学素质状况和《科学素质纲要》实施工作的监测评估，并提出相应的对策和建议。

此项工作由市科协、市科技局作为牵头部门，领导小组其它成员单位为责任单位。

四、工作要求

《科学素质纲要》的年度实施工作要围绕市委、市政府工作重点和提高全民科学素质的共性问题，确定工作切入点，组织开展主题科普活动，通过示范引导、突出重点、以点带面，推动全市公民科学素质的稳步提高。领导小组成员单位之间、各牵头单位和责任单位之间要加强沟通与联系，落实好联络员制度、情况通报制度等工作制度。各县区政府及有关部门、事业单位和人民团体的实施工作，要与全省和全市保持一致，形成上下联动、横向协同、狠抓落实的工作格局。通过广泛宣传和社会动员，充分调动全市群众参与《科学素质纲要》实施的积极性和主动性，在全市形成崇尚科学、尊重劳动、尊重知识、尊重人才、尊重创新的良好风尚。
