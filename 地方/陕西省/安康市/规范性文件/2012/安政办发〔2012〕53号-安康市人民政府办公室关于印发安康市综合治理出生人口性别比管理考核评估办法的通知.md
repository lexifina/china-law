# 安康市人民政府办公室关于印发安康市综合治理出生人口性别比管理考核评估办法的通知

各县、区人民政府，市政府各工作部门、各直属机构：

《安康市综合治理出生人口性别比管理考核评估办法》已经市政府同意，现印发给你们，请认真组织实施。

安康市综合治理出生人口性别比管理考核评估办法

为有效解决全市出生人口性别比偏高问题，实现“十二五”末全市出生人口性别比下降至正常范围,出生人口性别比高于107的县区每年下降超出107部分10%的目标。根据市政府办《关于深入开展关爱女孩行动综合治理出生人口性别比偏高问题的实施意见》（安政办发〔2007〕103号）和《陕西省人口计生委关于印发陕西省综合治理出生人口性别比管理考核评估意见的通知》（陕人口发〔2011〕66号）要求，结合全市综合治理出生人口性别比工作实际情况，现制定如下考核评估办法。

一、考评对象

各县、区人民政府；市统筹解决人口问题领导小组成员单位。

二、考评依据及评定标准。

考评依据：出生人口性别比数据指标考核依据县区住院分娩实名登记报表统计数据，参考年度分娩机构抽查数据。

评定标准：综合治理出生人口性别比工作实行年度综合考核评比，总分计200分。综合得分180分以上为优秀，150-179分为良好，120-149分为合格，120分以下为不合格。

三、考评内容

（一）县区考评(200分）

1、性别比数据指标（120分）出生人口性别比处于正常范围，指标高于107的县区完成年度下降10%的目标。

2、组织领导（15分）

（1）出生人口性别比综合治理纳入年度目标责任考核内容，建立目标责任考核体系；（5分）

（2）成立综合治理出生人口性别比的工作机构，组成专兼职工作队伍，牵头组织开展综合整治活动；（5分）

（3）召开联席会议，组织开展专项整治行动。（5分）

3、宣传教育（10分）

（1）年度开展包含男女平等、消除性别歧视等相关法律法规内容的宣传培训2次以上；（4分）

（2）印制包含关爱女孩综合治理出生人口性别比知识的入户宣传资料2类以上；（2分）

（3）将综合治理出生人口性别比的社会宣传纳入人口文化阵地建设内容；在市级以上新闻媒体刊发关爱女孩综合治理出生人口性别比相关新闻信息5篇以上。（4分）

4、政策落实（10分）

（1）落实中、省规定的独女、双女户奖励扶助政策；（2分）

（2）独女、双女户家庭奖励扶助纳入“计生家庭创业工程”；制定1项以上具有县区特色，有利于独女、双女户家庭的女孩在技能培训、就业及升学方面的奖励扶助政策；（4分）

（3）落实在农村新型合疗、农村养老保险、低保、集体林权制度改革、土地流转、移民搬迁、农村危房改造等方面有利于对独女、双女及家庭的优先优惠政策。（4分）

5、服务水平（15分）

（1）制定二孩全程优质服务工作实施细则或工作规范；明确镇（办）计生办、卫生院、计生服务站、村（社区）计生专干职责任务，制定具体奖罚措施；（5分）

（2）全面实行服务对象“一人一档”的服务管理，确保孕情随访服务率100%；（5分）

（3）确保二孩全程优质服务成功率在98%以上。（5分）

6、打击“两非”工作（15分）

（1）每年4月启动打击“两非”专项整治行动，年度专项整治行动不少于3次；（4分）

（2）设立举报电话、举报信箱，落实打击“两非”有奖举报制度；（2分）

（3）落实“两非”案件季度报表制度、14周以上终止妊娠手术申报审批制度、超声诊断设备登记备案制度；（6分）

（4）严格执行B 超操作人员持证上岗、检查对象实名登记和两人共同实施14周以上孕情检查等管理措施。（3分）

7、出生实名登记（15分）

（1）设立县区定点分娩机构，实行挂牌管理；（3分）

（2）县区人口计生局落实出生人口信息、户籍登记信息月通报制度；（8分）

（3）确保户籍人口实名登记漏报率在1.5%以下。（4分）

（二）部门考评内容（200分）

1、各成员单位完成《安康市统筹解决人口问题领导小组成员单位年度目标责任书》中综合治理出生人口性别比的目标任务；（140分）

2、各成员单位参与打击“两非”集中整治活动3 次以上；（60分）

3、市卫生局、市公安局每季度向市人口计生局通报出生人口实名登记和户籍登记汇总统计信息。（单列考评）

四、考评程序

1、考核评估与人口计生工作半年督查和年度目标责任考核同时进行，实行半年通报、年度综合考核。

2、各县区、市统筹解决人口问题领导小组成员单位每年12月底前依照本办法进行自检自查，并将自查报告报市统筹解决人口问题领导小组办公室（市人口计生局）。

3、市政府将综合治理出生人口性别比工作纳入全市人口和计划生育年度综合考评的重要内容，定期督查，严格考核，确保综合治理出生人口性别比工作落到实处。

安康市人民政府办公室

二〇一二年五月十一日
