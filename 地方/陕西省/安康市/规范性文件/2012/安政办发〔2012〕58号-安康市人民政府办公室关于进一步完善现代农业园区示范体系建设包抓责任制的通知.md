# 安康市人民政府办公室关于进一步完善现代农业园区示范体系建设包抓责任制的通知

各县、区人民政府，市政府各工作部门：

为强力推动《安康市现代农业园区示范体系建设规划》顺利实施，确保《安康市现代农业百园建设实施方案》所定目标任务的圆满完成，现就进一步完善现代农业园区示范体系建设包抓责任制作如下通知：

一、强化思想认识，加强组织领导

现代农业园区是农业主导产业发展的集聚示范区、先进科技应用核心区、生态循环农业样板区、体制机制创新试验区。各级各有关部门务必从加快“三化”进程、推动统筹城乡发展的高度，充分认识加强现代农业示范园区建设的重要性、紧迫性，将其列为当前农业农村工作的中心任务，进一步强化组织领导，落实工作责任，夯实工作措施，全力确保今年现代农业示范园区“百园建设”目标任务的顺利完成。为推动全市现代农业示范园区建设工作，市政府已于2011 年成立了由主管副市长任组长，有关部门主要负责同志为成员的安康市现代农业园区建设工作领导小组，并落实了市现代农业园区建设工作领导小组办公室（以下简称“市园区办”）机构和人员。各县区政府也要相应成立组织领导机构，明确办公机构和人员。市级各包抓部门要落实现代农业示范园区建设包抓工作责任领导和包抓科室、人员，迅速开展包抓工作。

二、明确目标任务，制定包抓方案

按照《安康市现代农业百园建设实施方案》要求，全市在原规划建设56 个现代农业示范园区的基础上，增加规划建设现代农业示范园区数量至111 个，并于今年全面启动实施。其中循环农业示范园区39 个、山林经济示范园区57 个（其中林业产业示范园区42 个、林下种养示范园区15 个）、渔业产业示范园区15 个；占地面积120.87 万亩（其中水域面积15.96 万亩）；重点扶持建设精品示范园区32 个，促其完善功能，尽快建成、达产达效；启动建设的79 个现代农业示范园区，主要任务是抓紧完成园区项目包装、规划设计、土地流转、招商引资等工作，按期完成年度建设任务，所有园区务于2015 年全面完成规划建设任务。各包抓单位应在认真学习相关建设规划、方案的基础上，按照《安康市2012年现代农业百园建设包抓任务一览表》明确的任务、要求，结合实际制定切实可行的包抓工作实施方案，迅速开展园区建设包抓组织实施工作。包抓方案应明确指导思想、包抓目标、包抓重点、包抓计划、包抓机构、工作责任、包抓措施、包抓进度安排等内容。

三、加大包抓力度，确保包抓实效

各包抓单位应将包抓现代农业园区建设作为贯彻落实“三问、三解”活动的具体举措，扑下身子，走进基层，经常深入园区生产建设一线，面对面、心贴心、实打实地为包抓园区解难事、做好事、办实事。要及时掌握园区建设进度，帮助协调解决园区生产建设中遇到的困难问题，全力帮助包抓园区引进培育建设主体，完善规划设计，加快土地流转，落实水、电、路、土地整理等基础设施配套建设，积极争取建设资金，促进园区按期建成，达产达效。各包抓单位主要负责人每季度至少到包抓园区进行一次调研指导，责任领导每月至少在包抓园区工作1 天以上，具体责任人每月在园区驻点天数不少于10 天；要及时向市园区办反馈园区建设新情况、新问题、新进展、新建议，每月10 日前向市园区办报送一次上月园区建设进展情况，6 月底和12 月底前书面报送半年和年度园区建设包抓工作总结。

四、完善考核机制，加强督促检查

市政府决定，将111 个现代农业示范园区建设包抓工作任务完成情况纳入市对县区政府和市级包抓部门年度重点工作考核内容，制定现代农业示范园区建设包抓工作考核办法，严格考评，奖惩兑现。各包抓单位要围绕园区建设目标，把各项工作任务分解落实到有关部门、科室和责任人，全面开展包抓工作。要建立和完善园区包抓档案，做好包抓工作记录，及时收集、整理包抓过程中形成的文字、图片资料。园区包抓档案将作为园区包抓工作考核的重要依据。市、县区政府督查室和园区办要加强对园区建设包抓工作的督促检查，采取电话抽查、实地查看、民主评议、召开园区业主座谈会等形式，对包抓单位包抓工作开展情况进行定期督查。市、县区园区办要对园区建设包抓工作中的好经验、好做法及时总结宣传，提供学习借鉴经验，对问题突出的园区要及时通报批评，责令整改，努力促进园区建设又好又快发展。

各包抓单位明确的责任领导和责任人员名单、联系方式及包抓方案请于2012 年5 月20 日前报送市园区办（地址：市政府行政中心416 室，联系人：王罡，电话：3808920，传真：3808920，电子邮箱：1097105625@qq.com）。
