# 安康市人民政府办公室关于进一步加强村级人口计生基层基础工作的意见

各县、区人民政府，市政府各工作部门、各直属机构：

为进一步提高全市人口计生工作水平，完善“县领导、镇负责、村为主”工作机制，推动村级人口计生工作规范化发展，现就加强村级人口计生基层基础工作提出如下意见。

一、充分认识加强村级人口计生基层基础工作的重要意义

近年来，全市各级党委、政府坚持以稳定低生育水平为中心，不断加强人口计生基层基础工作，大力推进统筹解决人口问题，全市人口计生工作整体水平明显提升。但随着形势的发展，全市流动人口和人户分离人口的数量日益增多，管理服务难度不断增大；部分村计生网络不健全，计生专干、中心户长人员、职责、报酬落不够实，有的村甚至没有专兼职计生干部，工作依靠镇上代管带干；一些村计生活动室、服务室、人口学校形同虚设，对群众的宣传咨询、三查服务、手术落实工作难开展；部分村计生软件资料不规范，各类表、卡、册、牌过于复杂，人口数据信息缺项漏项、逻辑关系错误严重，人口信息漏报、错报、瞒报现象有所抬头。当前，各县、区政府要从对人口和计划生育事业长远发展的高度，充分认识加强村级人口计生基层基础工作的重要意义，采取切实可行的措施，扎实推进村级基层计生规范化建设，强化村级人口计生基层基础，全面提升人口计生工作的质量和水平。

二、扎实推进村级人口计生阵地建设

（一）切实加强村级计生干部队伍建设。各县区要按照市委、市政府《关于全面加强人口和计划生育工作统筹解决人口问题的实施意见》（安发〔2007〕17 号）要求，认真落实市委办公室 市政府办公室《关于进一步加强农村人口和计划生育工作的实施意见》（安办发〔2008〕31 号）、《关于进一步加强基层计划生育工作的通知》（安办发〔2008〕37 号）、《关于创建流动人口计划生育服务管理一盘棋示范县的实施意见》（安政办发〔2011〕31 号）要求，指导支持配齐配强村级计生专干和中心户长，确保每个村有1 名专兼职计生干部，3000 人以上的村增设1 名计生专职副主任，社区增配1-2 名计生协管员，每个组设1-2 名中心户长。村级计生干部年报酬不低于村级正职的80%，中心户长报酬每人每年不低于240 元，纳入县区财政预算，由县区人口计生局统一考核兑现。村级计生干部采取公开招聘方式，实行“县管、镇聘、村用”管理机制，报酬由县区人口计生、财政部门从转移支付计生经费中拨付，并实行“直通车”发放。同时，要加强村级计生协会组织建设，按照协会章程选举产生协会会长、秘书长、协会理事和会员联户组长。

（二）大力推进村级计生网络阵地建设。按照村级计生人员、职责、报酬、阵地、设施“五落实”的要求，进一步加强村级“两室一校”建设，具体标准是：村级计生活动室：配备办公桌椅、档案柜和必要的办公用品，条件好的村可配备计算机，人口计生基本情况挂牌、工作网络图和主要工作制度上墙；村级计生服务室：可与村卫生室合建，配备避孕药具专柜、药具箱和药具展示牌，条件好的村可配备检查床、B 超等服务设备，优生优育、避孕节育、生殖保健、药具挂图上墙；村级人口学校（协会会员之家）：可与党群活动场所合建，面积20 ㎡以上，配备教学桌椅、写字板、电视机、DVD 机、图书柜。人口计生法规摘要、生殖健康、优生优育知识挂图上墙；村级计生公开栏：可与村务公开栏合建，主要向群众公开生育政策、生育计划、奖励扶助、有奖举报等政策内容。

（三）科学规范村级人口计生资料。按照简洁实用、科学规范的原则，实行村级“一牌一单一卡两册”软件管理模式。一牌：即人口计生工作基本情况挂牌，主要包括村级人口计生基本情况、工作网络情况和主要工作制度，在计生活动室悬挂。一单：即全员人口信息报告单，由村计生专干负责每月填报，存放在计生活动室。一卡：即已婚育龄妇女档案卡，由村专干负责每月更新，存放在计生活动室。两册：即村级人口计生管理册，由村专干负责每月填写，存放在计生活动室；村级人口计生服务册，由村服务室人员负责每月填写，存放在村服务室。

（四）全面落实村级人口计生工作职责。认真落实“三个一”领导机制，村级“两委会”全面负责人口计生工作，实行村支书、主任“亲自抓、负总责”工作制度。成立村级人口计生工作领导小组，实行目标管理责任制，按照镇办与村社区签订的年度目标责任书的规定，切实把目标和任务逐项分解到村级“两委会”成员，限定落实时间，确保责任到人、任务到人、考核到人。实行村级月例会制度，每月由村级主要领导主持召开村专干、中心户长会议，总结上月工作，分析存在问题，安排下月工作，汇总上报全员人口信息报告单，更新已婚育龄妇女档案卡。

三、切实加强对村级人口计生工作的领导

（一）加强组织领导。村级“两委会”主要领导要亲自抓负总责，定期研究解决困难和问题；其它班子成员要分工负责，落实责任和任务，形成村级领导班子共同抓落实的工作机制，确保责任任务落实到位、违法生育查处到位、奖励优惠政策落实到位。

（二）健全工作机制。建立人口信息月采集、月上报制度，确保全员人口信息全面准确；建立三查季检查、季报告制度，确保节育措施3 个月内落实，重点对象三查率达到100%；建立群众自治工作机制，规范群众自治章程、工作制度，结合实际探索制定计划生育奖励优惠和违法生育惩处措施，确保计划生育家庭得到激励和奖励，违法生育家庭受到约束和限制。

（三）严格信息报告。建立落实人口信息包抓责任制，采取村组干部分片包抓新婚、怀孕、节育对象，每月与对象见面，掌握人口出生、死亡和户籍变动等信息，及时向镇办报告。实行终止妊娠报告审批制度，对孕后人流引产、出生死亡、婴儿死亡等异常情况及时向镇办报告，并协助镇办查明真实情况。

（四）落实奖惩兑现。村级“两委会”每半年组织开展1 次自查，主动接受上级的检查评估，对自查和上级检查发现的问题，及时组织整改，及时向镇办报告整改情况。组织对各村（居）民小组、辖区机关、企事业单位进行检查考核，对成绩突出的上报镇办予以表彰，对问题严重的上报镇办给予批评。镇办党委、政府要加大对村级人口计生工作的督查考核力度，严格实行奖励与一票否决制度，确保年度目标责任制考核奖惩到位。

二〇一二年六月四日
