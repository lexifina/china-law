# 安康市人民政府办公室关于印发市自然灾害救助应急预案的通知

各县、区人民政府，市政府各工作部门、各直属机构：

重新修订的《安康市自然灾害救助应急预案》已经市政府同意，现印发给你们，请紧密结合本县区、本部门实际，认真贯彻落实。原《安康市自然灾害救助应急预案》（安政发〔2006〕9号）从即日起废止。

二〇一二年六月十四日
