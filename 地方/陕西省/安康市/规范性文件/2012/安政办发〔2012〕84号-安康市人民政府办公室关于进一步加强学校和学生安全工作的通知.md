# 安康市人民政府办公室关于进一步加强学校和学生安全工作的通知

各县、区人民政府，市政府各工作部门、各直属机构：

为进一步做好学校和学生安全工作，保障学校和广大师生财产、生命安全，确保社会安全稳定，现就有关要求通知如下：

一、提高认识，落实工作责任

学生安全涉及千家万户，关系到学校正常的教育教学秩序，关系到社会稳定与和谐社会的发展。各级各有关部门和学校要进一步统一思想，提高认识，牢固树立安全高于一切的思想，全面加强学校安全管理工作，做到居安思危，警钟长鸣，常抓不懈。要按照“分级负责、属地管理”、“谁主管、谁负责”的原则，认真落实 “一把手”负责制。积极探索建立学校安全管理长效机制，将学校安全纳入“对县区教育督导评估”活动的重要内容，进一步完善学校安全工作领导责任制、工作责任制和责任追究制。

二、突出重点，增强防范能力

针对阶段性、季节性学校安全管理的特点，突出抓好校舍安全、交通安全、涉水安全、疾病防疫、消防安全、食品卫生安全等“六个重点”工作。

（一）加快危房改建步伐。把师生安全放在首位，以农村边远学校、寄宿制学校为重点，集中对校舍安全隐患进行一次排查，对学校房屋重点部位以及与学生生活密切相关的设施进行全面检查。要采取建设过渡校舍、租用民房等方式科学合理分布教学点，利用暑期有利时机，集中加固、改造危房校舍，加快新建校舍进度，采取有效措施彻底排除校舍安全隐患。对D 级危房校舍要坚决杜绝使用。

（二）加强交通安全管理。持续开展道路交通安全教育，积极教育和引导广大学生，不乘坐报废车、货车、拖拉机、三轮汽车等非法营运车辆，不坐超员、超速等安全无保障的车辆，切实提高交通安全意识和守法意识；对学校周边交通安全设施的设置和交通安全管理情况进行全面彻底的摸查，尽快治理学校周边道路存在安全隐患；加大校园周边交通设施投入，特别是在学生经常横过交通干道的两端，加装交通警告标志外，设置减速带等安全设施。加强校车安全管理工作监督检查，进一步加大打击和查处“黑校车”力度，严禁无营运资质的车辆搭载学生。

（三）加强学生涉水安全管理。深入开展游泳安全宣传教育活动，以典型事例警示学生，提高每一个学生的游泳安全意识和自护自救能力；把防范中小学生溺水安全管理工作向校外延伸，加强家长安全知识宣传教育，督促家长履行监护人职责，切实负起对学生节假日和课余时间的监护和管理责任；严格纪律，明确要求：“禁止学生私自到危险水域游泳或游玩”，切实保证安全。组织对有隐患的禁泳地带进行拉网式的排查，有条件的在禁泳地带显著位置设立隔离栏、安全灯、禁止擅自下水游泳的警示牌等标识，做到不留“死角”和“盲点”。关注“留守儿童”的假期安全，加强管护，落实监管人员责任和义务。

（四）加强夏秋季传染病防控管理。学校要采取措施，对教室、图书馆等教学场所和食堂、宿舍、厕所等生活场所进行清扫和清理，保持良好的清洁卫生，清除传染病发生和流行的条件；认真落实晨检制度，做好晨检记录，努力做到传染病早发现、早报告、早治疗。组织开展手足口病预防和医疗救治等科普知识宣传工作，做好患儿家长的宣传教育，正确引导，消除不必要的疑虑和恐慌，维护社会稳定。

（五）做好学校消防安全管理。加强用火、用电安全管理，严禁学生在宿舍内使用电炉、热得快等大功率电器，严禁学生违规燃放烟花爆竹。规范实验室易燃易爆、有毒有害等危险品，做好校园内用电线路、食堂、师生宿舍、消防通道的排查，添齐配齐消防设施，下大功夫预防火灾发生。

(六)加强食品卫生安全管理。切实加强学校食堂管理，严禁变质食品和“三无”食品进入校园；进一步落实学校后勤从业人员工作职责，完善学校后勤卫生管理制度，规范学校后勤加工的操作程序，强化食堂卫生监督与管理；加强学校周边饮食摊点的监督检查，确保不发生食品安全事故。

三、齐抓共管，增强工作实效

各级各有关部门和学校要各司其职，互相配合，进一步增强工作合力。教育部门要主动联系公安、消防、卫生、文化等部门，根据学生身心发展和年龄特点，以及环境、季节变化的规律，通过举办专题讲座、应急疏散演练、知识竞赛、组织观看录像、制作宣传板等形式，有针对性地对学生进行防火、防盗、防爆炸、防中毒、防交通事故、防楼梯拥挤踩踏等方面的专题教育，创新安全教育形式，切实增强师生安全意识和自护自救能力。公安交警部门要进一步加强对学校及周边治安管理力度，对中小学周边地区易发案的重点时段、重点路段和重点部位要加强治安巡逻，对城区和道路沿线学校要完善警示标线标识标牌，对侵害师生人身财产安全的违法犯罪活动，坚决依法严厉打击，严密防范和消除侵害师生人身财产安全的恶性案件发生。卫生部门要对全市各学校食堂及学校周边饮食摊点进行专项执法检查，坚决杜绝“三无”食品流入校园，确保学校食品卫生安全。交通部门要加强对接送学生的交通工具的监督管理，严禁无营运资质的车辆搭载学生。工商部门要加强对学校周边经营摊点的管理，取缔无证无照的流动商贩和“黑网吧”。文化部门要规范学校周边文化娱乐场所，及时查处、取缔非法经营的书刊店、音像店及网吧等。建设部门要加强学校周边工程建设的安全监管，定期深入学校检查排查校舍等建筑安全隐患。各县区要切实做好本辖区易发事故场所的安全防范和安全隐患的排查工作，立即行动起来，扎实推进学校学生安全各项工作。

二〇一二年六月二十九日
