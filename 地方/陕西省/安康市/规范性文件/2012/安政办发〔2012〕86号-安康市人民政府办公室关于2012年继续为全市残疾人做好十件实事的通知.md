# 安康市人民政府办公室关于2012年继续为全市残疾人做好十件实事的通知

各县、区人民政府，市政府各工作部门、直属机构：

近年来，市委、市政府坚持认真贯彻落实科学发展观，切实维护弱势群体权益，有力地推动了社会文明、促进了社会和谐。特别是在残疾人工作方面，从残疾人最关心、最直接、最现实的利益问题入手，坚持每年办好十件实事，努力为他们创造更好的生产生活条件。经过全市上下的共同努力，全市残疾人生存状况

有了明显改善，生活质量和水平明显提高。为了进一步加快残疾人事业发展，让残疾人更多地共享社会发展成果，结合中、省有关要求，市政府决定，2012 年继续为全市残疾人做好十件实事。

一、加强残疾人职业技能培训。坚持以市场需求为导向，以社会化培训为重点，多形式多渠道对2500 名城镇和农村残疾人进行职业技能和实用技术培训。

二、实施残疾人“阳光家园计划”和居家安养补助项目。对500 名智力残疾人、精神残疾人和其他各类重度残疾人实施居家安养补助，通过集中托养、日间照料、居家安养等方式，为其提供生活照料、职业康复等服务。

三、实施贫困残疾儿童康复服务项目。为50 名贫困残疾儿童植入人工耳蜗、免费实施矫治手术和康复训练。

四、实施贫困肢体残疾人假肢装配项目。为170 名贫困肢残患者免费安装假肢，改善肢残患者行走功能。

五、开展“感受自然、出门见阳光”关爱活动。对全市高位截瘫、四肢瘫、长年卧床不起的重度残疾人分类提供康复服务，开展无障碍建设示范及进家庭关爱活动，免费配发个性化辅助器具，帮助他们走出房间，感受大自然的美好阳光。

六、实施贫困残疾学生助学项目。为300 名贫困残疾中小学生给予生活补助。对今年被普通高等院校或特殊教育学院录取的贫困残疾大、中专生，市残联商扶贫部门按本科每人5000 元、专科每人4000 元、中专每人3000 元的标准给予一次性资助。

七、实施白内障复明康复服务。为全市1000 名白内障患者开展白内障复明手术，由市残联负责落实500 例，由市卫生部门负责落实500 例，确保发现一例，复明一例，巩固“全国白内障无障碍市”创建成果。

八、实施贫困精神残疾人康复项目。为600 名贫困精神病患者实施特别救助；进一步落实新型农村合作医疗、城镇居民医疗保险和民政医疗救助办法，对1300 名精神病患者实施有效康复治疗。

九、建立残疾人康复、托养中心设施。积极争取中省残联项目支持，十县区全部建立残疾人康复、托养中心设施，为改善残疾人生产生活状况提供更好的服务平台。

十、加快推进残疾人基层组织建设。全面完成161 个镇（办）、169 个社区、2375 个村残疾人专职委员选聘工作。在镇（办）、社区专职委员补贴落实到位的基础上，今年要重点解决村级残疾人专职委员待遇落实，村残疾人专职委员按年600 元补贴，市县按1：9 比例配套落实补贴资金，市财政从市本级残疾人就业保障金中拿出30 万元补贴县区，各县区要加大财政投入，确保残疾人专职委员待遇落实到位。

各县区、各部门要站在践行科学发展观、促进和谐安康建设的高度，充分认识做好残疾人工作的重要性、紧迫性，结合各自实际，千方百计帮助残疾人解决生产、生活中遇到的困难和问题，尽心尽力为残疾人办实事、解难题，使广大残疾人切实感受到党和政府的关怀和温暖，促进我市残疾人事业在新的起点上加快发展。

二〇一二年七月六日
