# 安康市人民政府办公室关于印发《中国农业科学院副院长王韧同志在与安康市人民政府科技合作协议签字仪式上的讲话》的通知

各县区人民政府，市政府各工作部门、直属机构：

现将2012年9月16日中国农业科学院副院长王韧同志在与安康市人民政府科技合作协议签字仪式上的讲话印发给你们，请组织传达学习。

安康市人民政府办公室

2012年9月27日

在与安康市人民政府科技合作协议签字仪式上的讲话

中国农业科学院副院长 王 韧

2012年9月16日

尊敬的各位领导、各位来宾，大家好！

值此安康市人民政府与中国农业科学院科技合作协议签字仪式举行之际，我谨代表中国农业科学院向出席今天活动的各位领导和专家表示热烈的欢迎和衷心的感谢！

党中央和国务院高度重视“三农”问题。今年的“中央1 号”文件及中央农村工作会议，突出强调农业科技创新和技术推广问题，把推进农业科技创新作为新时期促进农业稳定增产和发展现代农业的根本战略；在今年的“两院”院士大会上，温家宝总理指出农业科技创新和关键技术的重大突破，是解决粮食安全和农业发展问题的根本条件，强调要培养大批有文化、懂技术、会经营的新型农民，推动农业增长方式转变，全面提高我国农业发展水平；农业部也把今年确定为全国农业科技促进年，把加强农业科技创新和促进成果转化作为一项重要工作内容。我们一定要紧紧抓住这一有利时机，通过合作实现科技创新和成果转化同步发展，提高农业生产社会经济效益。

安康有着悠久的历史和灿烂的文化，是秦巴山区一颗美丽的明珠，是我国著名的硒谷、生态绿洲、旅游胜地、交通枢纽。近年来，在安康市委、市政府的正确领导下，全市经济社会持续稳定发展，人民生活水平不断提高。全市围绕“循环发展、富民强市”的主题，科学规划，明确主导产业发展方向，不断加快现代农业产业发展步伐，取得了骄人的成绩。尤其是富硒产业发展迅速，产品研发不断加强，产业发展不断壮大，形成了安康市新的经济增长点。

中国农业科学院创建于1957年，担负着农业科技创新、培养高级人才、组织全国协作、开展国际合作、服务国家宏观决策的历史使命。全院现有40个研究所，1个研究生院和1个出版社。研究领域包括作物科学、畜牧兽医科学、应用农业微生物学、农业资源与环境学、食品科学与工程、农业质量标准与检测、农业信息、农业经济与科技发展、农业工程学等9大学科群。全院在职职工10000余人，其中科技人员5200余人，具有高级职称的2200人，两院院士12人，国家级专家24人，政府特殊津贴专家964人，国家“百千万人才工程”人选44人。建有国家重大科学工程2个，国家重点实验室6个，农业部重点实验室42个，国家野外台站5个，农业部野外台站24个，国家工程技术研究中心5个，国家及部级质检中心40个，国家农作物种质资源长期库1座、中期库10座、国家农作物种质圃12 个。在党中央、国务院的领导下，在全国各级政府和兄弟单位的支持下，通过全院广大科技人员的积极努力，先后取得了“超级稻”、“禽流感疫苗”、“转基因抗虫棉”、“双低油菜”等一大批具有国际领先水平的科技成果，为保障国家粮食安全和建设创新型国家做出了应有的贡献。今年的我院工作会议，提出了要把中国农业科学院建设成世界一流科研院所，科技工作要“顶天立地”的发展战略目标，着力提升农业科技自主创新能力，着力强化成果转化和产业支撑能力。

中国农业科学院十分重视与地方政府的科技合作，先后与20多个省、自治区、直辖市签订了合作协议，在全国各地建立了1000多个科技示范点，为我国农业和农村经济的发展提供了有力的科技支撑。这次与安康签署科技合作协议，就是本着“优势互补、互利共赢、共建共享、持续发展”的原则，充分发挥中国农业科学院科技、人才、信息以及安康市区域、资源等优势，共同推进农业科技创新和成果转化，为安康现代农业和农村经济发展提供强有力的科技支撑。双方将在现代农业发展规划、共建研发平台、联合培养人才、加强信息服务等方面开展全面合作，促进安康市现代农业的发展。我相信，通过双方的共同努力，我们的合作一定会取得丰硕的成果。

最后，借此机会向长期以来关心和支持我院各项工作的安康市委、市人民政府以及各级部门的领导表示衷心的感谢！
