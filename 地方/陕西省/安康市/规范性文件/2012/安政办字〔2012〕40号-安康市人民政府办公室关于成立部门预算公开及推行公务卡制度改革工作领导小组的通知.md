# 安康市人民政府办公室关于成立部门预算公开及推行公务卡制度改革工作领导小组的通知

各县区人民政府，市政府各工作部门、直属机构：

为切实做好全市部门预算公开及推行公务卡制度改革工作，根据中、省有关要求，经市政府同意，决定成立市部门预算公开及推行公务卡制度改革工作领导小组，现将组成人员通知如下：

组 长：徐启方 市委常委、常务副市长

副组长：何邦军 市政府党组成员、市财政局局长

郭正明 市政府党组成员、市监察局局长

赵立根 市政府副秘书长、法制办主任

成 员：杜保华 市审计局局长

马 勇 市财政局副局长、公产局局长

郭正平 安康银监局局长

袁泽强 人行安康支行行长

张治国 工行安康分行行长

董 云 农行安康分行行长

锁安升 建行安康分行行长

王明强 中行安康分行行长

宇 彦 市财政局纪检组长

领导小组办公室设在市财政局，马勇同志兼任办公室主任，宇彦同志兼任办公室副主任，办公人员从领导小组成员单位抽调。

二〇一二年六月二十六日
