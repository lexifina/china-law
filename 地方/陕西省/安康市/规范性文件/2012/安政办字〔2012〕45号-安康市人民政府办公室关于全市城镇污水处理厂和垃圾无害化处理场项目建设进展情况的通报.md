# 安康市人民政府办公室关于全市城镇污水处理厂和垃圾无害化处理场项目建设进展情况的通报

各县区人民政府，市政府有关工作部门：

城镇污水处理厂和垃圾无害化处理场是一项重要的民生工程，也是今年目标责任考核中的一项重要的指标任务。5月22日召开的全市污染减排工作会议对此项工作进行了再次安排部署。根据年初的总体安排，6月12日至15日，市政府组织相关部门成立了3个督查组，对全市城镇污水处理厂、垃圾无害化处理场及中心城市医疗废物处置中心项目上半年建设情况进行了专项督查。现将督查情况通报如下：

今年以来，各县区按照市政府的统一安排，全面加快“两厂（场）”项目建设步伐，尤其是在全市污染减排工作会议后，各县区政府高度重视，进一步加强了组织领导，加大资金投入，优化环境保障，科学组织施工，集中解决了一批影响工程进度的难点问题，工程建设不断加快。截止6月底，10个城镇污水处理厂建设累计完成投资46745万元，占总投资的56.10%；10个城镇垃圾无害化处理场累计完成投资36306 万元，占总投资的67.17%；中心城市医疗废物处置中心基本建成并试运营。（详见附表）

从总体情况看，“两厂（场）”项目建设虽然进度加快，但由于前期工作启动慢、欠账大，施工过程一些新问题的出现，建设进度与目标考核要求还有一定差距。一是进展不平衡。10个县区城镇污水处理厂、垃圾无害化处理场项目完成投资任务80%以上的各有2个，完成投资任务不足50%的各有3个，其他县区基本实现了计划与进度同步。二是不确定因素多。受汛期泄洪、周边环境、项目建设等不确定因素影响，一些县区的污水处理厂施工难度加大。三是个别县欠账多，距目标要求差距大。市政府要求，各县区要认真贯彻落实5月22日全市污染减排工作会议、5月25日郭青市长办公会议和市政府办公室《关于切实做好污染减排工作的实施意见》精神，进一步统一思想，强化责任意识，坚定信心，克服困难，健全机制，采取更加有力的措施，确保按期完成建设任务。同时，要提前着手考虑污水处理厂运营问题，确保污水处理厂既能尽快建成，又能正常运营、发挥作用。
