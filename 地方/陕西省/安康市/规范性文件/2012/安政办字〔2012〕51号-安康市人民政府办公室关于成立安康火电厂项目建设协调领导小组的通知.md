# 安康市人民政府办公室关于成立安康火电厂项目建设协调领导小组的通知

各县区人民政府，市政府各工作部门、直属机构：

为切实加强安康火电厂项目建设组织协调力度，加快推进建设进度，市政府决定成立安康火电厂项目建设协调领导小组，现将组成人员通知如下：
