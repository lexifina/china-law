# 安康市人民政府办公室关于印发我市科学用盐促进健康减盐活动实施方案（2012-2015）的通知

各县区人民政府，市政府有关工作部门：

市卫生局、盐务局联合拟定的《安康市科学用盐促进健康减盐活动实施方案（2012-2015）》，已经市政府同意，现印发给你们，请认真贯彻执行。

安康市人民政府办公室

2012 年10 月8 日

安康市科学用盐促进健康减盐活动实施方案（2012-2015）

食盐安全是食品安全的重要基础。高食盐摄入量是导致高血压和心脑血管疾病的重要原因，通过降低食盐摄入量可以降低患冠心病和中风的危险。为积极响应《中国减盐行动（2010 -2020行动划）》，落实国家卫生部等联合印发的《中国慢性病防治工作规划（2012－2015 年）》，深入宣传“科学用盐、促进健康”理念，营造良好的社会氛围，有效降低居民人均食盐摄入量，最大限度控制高血压危害，提高全民健康水平，促进经济社会可持续发展，市政府决定在全市范围开展“科学用盐、促进健康”减盐活动，现结合实际，特制定本实施方案。

一、指导思想

以科学发展观为指导，以减少人均每日食盐摄入量、减少高血压及其相关疾病危害为目标，积极宣传倡导“少吃盐、吃好盐、多用盐”的新理念，改善饮食环境与习惯，完善高血压等疾病防控措施，提高群众健康水平。

二、工作目标

2012 年，在全市持续开展“推广使用低钠盐，预防控制高血压”宣传活动，营造减盐社会氛围。编制不同行业人员培训教材，制作健康教育与公众传播资料，提高居民低盐膳食知识知晓率和行为形成率，倡导科学健康饮食，强化减盐意识，并推出健康低钠盐。

2013 年，广泛开展公众健康教育和重点行业、职业人群培训。选择市内骨干食品加工企业、零售企业和大型餐饮单位及部分慢性非传染性疾病综合防治示范县(区)，先行开展减盐防控高血压工作试点。2013 年底，小包装食用盐中低钠盐的市场占有率要达到15-20%。

2014 年，继续做好减盐活动宣传和实施推广工作，50%以上的食品生产加工企业、零售企业和餐饮单位采取减盐措施。2014年底，低钠盐市场占有率达到25-30%。

2015 年，继续推动减盐政策措施的落实，扩大减盐覆盖面，做好总结和经验推广，继续完善配套政策措施，建立减盐防控高血压工作长效机制。2015 年底，全市低钠盐食用率达到40%以上。

三、工作内容

(一) 宣传普及低盐膳食与高血压防治知识。

1、大力开展宣传教育，普及低盐低钠膳食与高血压防治知识，开展多种形式、群众喜闻乐见的健康教育与健康促进活动，强化公众减盐防控高血压意识，营造浓厚的减盐防控高血压等疾病社会氛围。

2、强化儿童、青少年、家庭妇女等重点人群干预措施。落实“减盐防控高血压，从娃娃抓起”，抓住儿童青少年味觉形成的关键时期，培养低盐饮食习惯。中小学校开设低盐膳食及高血压防控健康教育课程，发挥妇联组织、妇女儿童活动中心等阵地作用，面向妇女和家庭开展家庭减盐专项活动，与和谐家庭、文明家庭创建、巾帼志愿者等活动相结合，强化家庭妇女低盐膳食知识宣传与培训。

3、发挥重点职业人群的带动作用。以医务人员和教师等为重点，通过岗位培训、继续教育等平台和载体，强化减盐防控高血压意识，充分发挥他们在不同行业和社会公众中的影响力。

4、开展食品行业、餐饮单位和集体食堂从业人员培训，做好减盐相关政策的宣传贯彻，增强从业人员低盐膳食和科学用盐意识，主动落实减盐措施。

（二）建立完善减盐政策环境。

1、倡导食品生产加工企业在食品生产加工过程中合理减少和控制食盐使用量。鼓励低钠盐食品的研发与生产，满足居民多样化饮食需求。

2、倡导推广涉盐食品包装标签标注低盐膳食健康提示。

3、引导餐饮单位、集体食堂积极采取控制食盐使用量的措施，提倡使用低钠盐。开展健康餐厅、健康食堂创建与评选活动，鼓励餐饮单位和集体食堂开发和提供低盐低钠菜品。

4、在商场、超市等食品销售企业开设低盐低钠食品专柜，为居民识别、购买提供方便。

5、促进标准化控盐用具的生产和推广使用，为餐饮单位和居民家庭测量、控制食盐使用量提供支持。

(三)完善高血压防控措施。

1、开展人群高血压筛查和行为危险因素调查，及时更新完善居民健康档案相关信息，在有条件的公共场所建立血压等健康指标自助检测点，提供体格测量简易设备，提高人群自我血压知晓率，早期发现高血压高危人员和患者，进行早期健康指导，采取预防性干预措施。

2、落实国家基本公共卫生服务规范，完善高血压患者健康档案和随访服务，提高高血压患者登记率、治疗率和管理率，发挥患者自我管理作用，改善血压控制效果。

3、结合健康教育、慢性病管理等基本公共卫生服务项目实施，开展低盐膳食和防控高血压健康指导工作。强化干预措施，促进居民饮食健康行为的形成。

(四)建立减盐防控高血压监测评价体系。

1、开展基线调查，了解人群低盐膳食与高血压相关知识水平，掌握居民食盐摄入量及其来源、血压等指标的基线水平，逐步建立居民家庭烹调盐使用量、居民尿钠水平和血压水平的动态监测系统。

2、在食品生产加工企业、销售企业和餐饮单位、集体食堂建立监测点，开展低盐食品和低盐餐饮相关政策监测、食盐及涉盐食品生产与销售监测、餐饮行业从业人员知识与行为及食盐使用量监测等，动态了解减盐政策与环境支持体系变化情况。

四、保障措施

(一)加强组织领导。市政府成立“科学用盐、促进健康”减盐活动领导小组，由分管副市长任组长，市盐务局局长任副组长，相关部门为成员单位，领导小组办公室设在市盐务局，负责减盐行动的总体组织协调和实施。各县区要成立相应的工作机构，制定工作方案，抓好“科学用盐、促进健康”减盐活动工作落实。

各有关部门要明确职责，完善政策措施，共同推进活动实施。卫生部门负责将减盐防控高血压纳入基本公共卫生服务慢病管理项目重要内容组织实施，为相关部门开展行业宣传和培训提供必要的技术支持。

宣传部门负责做好减盐活动宣传工作。

妇联负责将低盐膳食与高血压防控知识宣传和培训纳入妇联日常工作、活动中，推动家庭减盐活动的开展。

教育部门负责将低盐膳食与高血压防控知识纳入中小学生健康教育课内容，在学校集体食堂推行减盐措施，推动学校低盐食品加工。

科技部门负责将减盐防控高血压相关内容纳入科技活动周活动；鼓励有关高校、科研单位和企业开展减盐防控高血压相关研究，促进减盐相关技术转化。

财政部门负责对减盐防控高血压项目进行支持，并对资金使用情况进行监督。

商务部门负责引导和组织食品销售企业、餐饮单位开展减盐相关工作，在食品销售场所开设低盐食品专柜。

工商、质监、药监部门负责加强对流通环节、涉盐食品生产企业、餐饮单位和集体食堂等涉盐食品的监管监测工作。

旅游部门负责推动旅游星级饭店落实减盐措施，开展减盐防控高血压知识宣传。

双创办负责将“科学用盐、促进健康”减盐活动纳入双创健康教育宣传重要内容，督促各单位落实。

盐务部门负责“科学用盐、促进健康”减盐活动的组织协调和实施。依据盐业法规政策做好低钠盐的宣传推广供应和市场监管工作，按类别按步骤落实低钠盐在食品加工、餐饮业、学校食堂的使用，协助做好高血压防控有关调研和低盐膳食宣传。

(二)加大资金整合力度。卫生、财政部门要根据公共卫生项目管理及资金管理的要求，加大公共卫生资源整合力度，将减盐防控高血压与国家基本和重大公共卫生项目有机结合，强化项目实施的规范性、科学性、实效性，落实居民健康教育、重点人群指导和人群血压等工作任务。盐业部门积极筹集减盐行动专项资金，用于宣传教育经费。

(三)强化督导考评。各级、各部门要实行责任制，明确职责任务，制定考核指标体系，分阶段、有步骤地组织开展督导检查和项目评估，定期通报考核结果。
