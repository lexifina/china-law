# 安康市人民政府关于调整市军队转业干部安置工作领导小组组成人员的通知

各县区人民政府，市人民政府各工作部门、各直属机构：

鉴于市军队转业干部安置工作领导小组部分组成人员工作变动，为适应工作需要，市政府决定对该领导小组组成人员进行调整。调整后的领导小组组成人员如下：

组 长：徐启方 市委常委、常务副市长

副组长：鲍永能 市委常委、市委组织部部长

马权斌 安康军分区副政委

吕述伟 武警安康支队政委

赵立根 市政府副秘书长、市政府办公室主任

陈伦宝 市委组织部副部长、市人力资源和社会保障局局长

成 员：王建强 市委宣传部副部长、市文明办主任

薛同新 市编委办副主任

孟 平 市发展改革委副主任

余乐海 市教育局纪委书记

屈夏眉 市公安局副局长、政治部主任

张 伟 市民政局副局长

马 勇 市财政局副局长

焦富清 市人力资源和社会保障局副局长

王开群 市住房和城乡建设局党委副书记、纪委书记

周功耀 市政府机关事务管理局局长

市军队转业干部安置工作领导小组办公室设在市人力资源和社会保障局，焦富清同志兼任办公室主任，具体负责全市军队转业干部安置日常工作。

安康市人民政府

2012年11月7日
