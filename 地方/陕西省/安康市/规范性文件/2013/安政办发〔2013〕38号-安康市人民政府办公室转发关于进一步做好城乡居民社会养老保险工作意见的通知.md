# 安康市人民政府办公室转发关于进一步做好城乡居民社会养老保险工作意见的通知

各县区人民政府，市政府各工作部门、直属机构：

市人力资源和社会保障局《关于进一步做好城乡居民社会养老保险工作的意见》已经市政府同意，现转发给你们，请认真抓好贯彻落实。

安康市人民政府办公室

2013 年4 月7 日

关于进一步做好城乡居民社会养老保险工作的意见

市人力资源和社会保障局

为进一步改善和保障民生，实现全市城乡居民社会养老保险人群全覆盖，根据中省有关文件精神，现就进一步做好我市城乡居民社会养老保险工作提出以下意见。

一、指导思想

认真贯彻落实党的十八大精神，以科学发展观为指导，以增强公平性、适应流动性、保证可持续性为重点，以全面建成覆盖城乡居民的社会保障体系为目标，以政府主导、群众自愿、健全机制、规范管理为原则，进一步完善制度体系，健全经办机制，强化工作责任，提升服务水平，促进全市经济健康发展和社会和谐进步。

二、目标任务

通过三至五年的努力，实现社会统筹与个人账户相结合、与家庭养老、社会救助、社会福利等其他社会保障政策相配套，覆盖全民的城乡居民养老保障体系；建成多险种统管、跨区域接续、城乡一体的社会保障经办服务系统，实现全市城乡居民社会养老保险人群全覆盖。

三、完善机制

（一）建立健全缴费激励机制。各县区根据经济发展、财政增长等情况，建立“长缴多得”机制，对缴费16 年及以上的参保人员，可结合实际适当增加基础养老金标准。积极探索建立城乡居民社会养老保险丧葬费补助制度，提高群众受益水平，具体补助标准由各县区自行确定。

（二）建立健全经费保障机制。各县区在本级财政预算中合理安排城乡居民养老保险经办机构工作经费，也可建立与服务人群和业务量挂钩的经费保障机制，但不得从基金中提取。对镇、村协管人员、信息员给予一定的工作补助，对镇、村城乡居民养老社会保险工作所需经费给予保障，确保基层有人办事、有钱办事。

（三）建立健全基金安全监管机制。切实加强基金监管，建立健全监管制度，层层夯实责任，确保群众的每一分钱都能及时进入财政专户和个人账户。各级财政部门和经办机构要加强内部监督，制定内部监管办法，坚持收支“两条线”管理，严防违纪违规行为发生。建立城乡居民养老待遇资格认证制度，定期审验，严格查处欺诈冒领养老待遇的行为。

（四）建立健全参保转移衔接机制。市、县区经办机构要抓紧研究制定险种内跨统筹区转接办法，确保城乡居民社会养老保险转接有章可循、有据可依、转接有序。加强城乡居民养老保险制度与职工基本养老保险制度的衔接，按照有关规定妥善处理重复参保群体的个人账户转、退手续和资金；符合城乡居民养老保险待遇领取条件且享受被征地农民基本生活保障、水库移民后期扶持政策、最低生活保障、计划生育家庭奖励扶助、社会优抚、农村“五保”等待遇的人员，可同时叠加享受。

四、规范服务

（一）加强基础服务平台建设。规范设置城乡居民养老保险经办机构，配强领导班子，配齐工作人员，合理设置岗位。依托镇、办社会保障所建设，整合农村社保服务项目，建好群众服务窗口平台，改善经办服务条件。加强与代理银行沟通协调，逐步实现群众“不出村”或就近办理参保手续、领取养老金。

（二）加强经办服务队伍建设。高度重视县镇经办队伍建设，在足数配备县级经办人员的同时，加强镇（办）经办服务队伍建设，每个镇（办）社会保障服务站明确1 至2 名城乡居民养老保险经办专职工作人员。

（三）加快信息网络系统建设。扎实推动城乡居民养老保险信息系统建设，积极开展网上办公，及时更新信息数据，逐步实现网上申报、缴费、结算。大力推行社会保障卡发行，实现社会保障卡跨越险种、跨地区广泛应用，努力实现社会保障全国“一卡通”目标。

（四）创新规范经办服务体系。切实抓好个人账户管理，做到建账及时，记录准确，对账及时，实帐管理，杜绝使用个人账户基金垫付基础养老金问题的发生。以示范点建设为突破口，每年市城乡居民社会养老保险经办处抓2 至3 个示范县、每个县区抓2 个以上的示范镇、5 个以上的示范村，充分发挥示范带动作用，努力提升城乡居民养老保险经办服务水平。及时总结经验，积极探索创新，不断完善机制，健全经办服务体系。

五、工作要求

（一）加强组织协调。人社部门要认真履行主管部门职责，充分发挥牵头抓总作用，积极主动向党委、政府汇报工作中存在的困难和问题，主动加强与相关部门的沟通协调，努力形成政府主导、人社部门牵头、相关部门密切配合的工作格局。

（二）加强舆论宣传。坚持正确的舆论导向，充分运用各种宣传手段，向广大城乡居民深入宣传建立城乡居民社会养老保险制度的重大意义和具体政策，不断增强城乡居民自觉参保意识，为深入推进城乡居民社会养老保险工作营造良好氛围。

（三）加强督查考核。各县区要将城乡居民社会养老保险工作纳入经济社会发展规划和年度计划，作为目标责任考核的重要内容。加强工作督促指导，对配套资金不落实、养老金不能按月发放的，要及时通报，坚决进行纠正整改。
