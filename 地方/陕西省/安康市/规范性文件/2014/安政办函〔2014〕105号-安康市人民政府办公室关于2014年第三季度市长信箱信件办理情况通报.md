# 安康市人民政府办公室关于2014年第三季度市长信箱信件办理情况通报

各县区人民政府，市政府各工作部门、直属机构：

现将2014 年第三季度“市长信箱”信件办理情况通报如下：

一、基本情况

第三季度“市长信箱”共受理有效信件1190 件，已办结1053 件，办结率88%。其中，转送县、区政府办理720 件，已办结640 件，办结率89%；转送市直及中省驻安单位办理470 件，已办结413 件，办结率88%。送市政府领导批示30 件，已全部直接转送。

按归属单位分，汉滨区、旬阳县、平利县、岚皋县，市公安局、市交通局、市住建局、市交警支队、市人社局信件较多。从办理情况看，旬阳县、平利县、汉阴县、白河县、紫阳县、石泉县、高新区、宁陕县、镇坪县，市交警支队、市人社局、市卫生局、市教育局、市规划局、市物价局、市环保局办理情况较好。汉滨区、恒口示范区，市公安局回复率较低，分别为76%、73%和46%；瀛湖生态旅游区，市住房公积金管理中心、安康职业技术学院、市国土局、市司法局、市气象局、市邮政局、中国联通安康分公司、中国电信安康分公司等单位回复率为零。

从信件类型看，反映的求决类问题主要是城镇征地拆迁安置补偿、小区物业收费、居住环境污染等方面；咨询类问题主要是户口迁移、大学生创业扶持和退伍军人安置等政策问题；监督投诉类主要是教师违规办班、车辆违章记录和村干部违规违纪等问题；建言献策类主要是对城市双创、城区规划和建设以及道路交通建设等方面。

第三季度人民网地方领导留言板给市长留言19 件，交办 19件，回复19 件。

二、存在的主要问题及工作要求

第三季度“市长信箱”信件总量比二季度有所上升，同比增加43%。从办理情况看，绝大部分责任单位对转交信件能仔细核实，认真调查，按期回复，办理情况得到了来信人和广大网友的认可和肯定，但仍存在一些问题和不足：一是部分责任单位领导重视不够。少数单位以业务工作繁忙、信件量大、工作人员少为由，对“市长信箱”转去的信件没有认真调查核实，也未按期回复，造成大量信件积压，影响全市信件办理工作质量。二是信件办理不及时。少数单位办件迟缓、拖沓，对转交的信件不及时查看、核实，工作人员督办后，找客观原因要求延缓办件时间，办信工作效率偏低。三是信件办理质量不高。少数承办单位采取“踢皮球”的办法，对转交的信件互相推卸责任，找客观原因要求退回，给交办和转办工作带来难度；个别单位在通报下发前，集中回复逾期信件，对回复内容审核不严，导致出现文不对题、格式不规范、错别字多等问题，影响了“市长信箱”形象；有些部门回复寥寥数语，用“已转交相关部门处理，请与其联系”等形式回复，致使群众对答复不满意，多次重复发信。

各级各部门在接到通报后，要结合全市正在开展的党的群众路线教育实践活动，认真研究本单位“市长信箱”信件办理工作中存在的问题，并将其纳入政风行风建设内容之一，不断强化宗旨意识、责任意识，落实整改措施，改进工作作风，规范工作程序，提高工作效率，树立良好的政府机关形象，真正做到群众反映诉求事事有回音、件件有着落，提高“市长信箱”办理工作水平。
