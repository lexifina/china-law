# 安康市人民政府办公室关于建立信息平台建设联席会议制度的通知

各县区人民政府，市政府各工作部门、直属机构：

为进一步规范信息平台建设，充分发挥现有信息平台作用，市政府建立信息平台建设联席会议制度，现将有关事项通知如下：

总召集人：王安利 市委常委、常务副市长

召 集 人：何邦军 市政府党组成员、市财政局局长

王龙军 市政府副秘书长、督查室主任

成 员：周庆意 市财政局副局长、征收管理局局长

邓 军 市发改委副主任、项目办主任

周开升 市工信局纪委书记

刘明泰 市发展研究中心主任

马宝剑 市应急办主任

联席会议办公室设在市发展研究中心，由王龙军同志兼任办公室主任，周庆意、刘明泰同志兼任办公室副主任。今后，各部门原则上不再自行建设信息平台，确因工作需要建设的，由本部门提出建设规模、资金筹措方案，由市发展研究中心组织相关专业技术人员进行可行性评审，提出建设规模、资金及技术参数等意见，报经市联席会议研究审定后，由市发改委立项审批，市财政局统筹建设资金。涉及应急系统平台建设的，由市应急办提出整合意见。

安康市人民政府办公室

2014 年10 月23 日
