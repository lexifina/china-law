# 安康市人民政府办公室关于做好《陕西年鉴》2014卷安康部分供稿工作和编纂《安康年鉴》2014卷的通知

各县区人民政府，市政府各工作部门、直属机构：

为认真贯彻落实陕西省人民政府办公厅《关于进一步做好<陕西年鉴>编纂工作的通知》（陕政办函〔2014〕34 号）文件精神，切实做好《陕西年鉴》2014 卷供稿和《安康年鉴》2014 卷编纂工作，现就有关事项通知如下：

一、统一思想，提高认识

《陕西年鉴》和《安康年鉴》是全面、系统记述省、市年度政治、经济、文化、社会和生态文明建设的大型资料性文献，是记载和见证省、市经济社会发展变化的权威性、实用性、资料性的综合工具书，是省、市对外宣传的重要窗口之一。在存史资政、繁荣文化、服务省、市经济社会发展等方面发挥着重要作用。各级各部门要进一步提高认识，不断增强工作责任感和使命感，以对历史高度负责的态度，做好《陕西年鉴》2014 卷供稿和《安康年鉴》2014 卷编纂工作，使其更好地为建设美丽富裕新安康服务。

二、精心组织，落实责任

各县区及承担《陕西年鉴》供稿任务的各部门要严格按照《陕西年鉴》的供稿要求精心组织，突出重点，客观真实反映2013年全市经济社会发展状况。在编纂《安康年鉴》时，要突出2013年工作特点，确保科学实用。要围绕本单位本行业重点和亮点工作，广泛收集资料，提供具有时代特色和行业特点的稿件，选择上一年度的大事要闻和典型事件入编，切实做到“大事不漏”“小事不上”，确保全市重要地情资料得到及时系统的收集、积累和保存。各单位要积极配合年鉴彩版的组稿工作，注重增强年鉴的可读性、存史性。注重宣传全市的先进单位、先进集体和英模人物，突出重点地宣介一批名优物产、知名企业和企业家，力求全方位多层次展示、宣传我市经济建设和社会发展的新特点、新变化、新成就。

三、加强领导，确保质量

各级各部门要加强对年鉴供稿和编纂工作的组织领导，严格按照编纂要求提供图片和文字资料，确保按时完成供稿工作。各供稿单位要把供稿作为本单位的一项常规性工作，明确主抓领导，落实工作责任。确定具有较高政策理论水平，熟悉业务，责任心强的同志承担撰稿工作。各供稿单位要认真审核稿件，把好政治关、保密关、事实关和文字关，于3 月30 日前将稿件（电子版及打印文稿）报送市地方志办公室。市地方志办公室作为《陕西年鉴》的组织供稿单位和《安康年鉴》的编纂单位，要树立精品意识，精心组织编辑，严格编审程序，加强与供稿单位的信息沟通和业务对接，及时对编辑和供稿人员进行业务培训，不断提高年鉴编纂质量，努力将其打造成文化精品。
