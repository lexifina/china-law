# 安康市人民政府办公室关于调整市政府秘书长副秘书长和办公室领导工作分工的通知

各县、区人民政府，市政府各工作部门、各直属机构：

根据人员变动和工作需要，现将市政府秘书长、副秘书长和办公室领导工作分工调整通知如下：

赵良亭（市政府秘书长）：协助市长、常务副市长处理市政府日常工作，受市长、副市长委托处理应急事项。协助分管市信访局、驻外办事机构。

领导市政府办公室全面工作。

分管市政府办公室秘书科、综合一科。

赵立根（市政府副秘书长、办公室主任）：负责市政府办公室日常工作，负责协调与市人大、市政协的工作联系。负责办公室双创工作。联系赵俊民同志及分管方面工作。分管市政府机关事务管理局，市应急管理办公室，市政府办公室政办科、机关党委、机关工会、机要科、综合三科，市政府招待所、市政府机关幼儿园。

赵德成（市政府副秘书长、市政府法制办公室主任）：负责市政府法制办公室工作，联系杜寿平同志及分管方面工作。分管市政府办公室综合八科。

马 霞（市政府副秘书长、市信访局局长）：负责市信访局工作。

王龙军（市政府副秘书长、市政府督查室主任）：负责市政府督查室工作，联系王安利同志及分管方面工作（除市政府办公室工作）。分管市外事侨务办公室，市政府办公室综合二科。

卢晨辉（市政府副秘书长[挂职]）：联系梁志坚同志及分管方面工作。分管市发展研究中心(市政府网站)。

陶柏林（市政府副秘书长）：联系张全明同志及分管方面工作。分管市政府办公室综合五科。

唐安庵（市政府副秘书长）：联系巨拴科同志及分管方面工作。分管市政府办公室综合四科。

阮家军（市政府副秘书长）：联系鲁琦同志及分管方面工作。分管市政府办公室综合七科。

张 峰（市政府副秘书长）：联系邹顺生同志及分管方面工作。分管市政府办公室综合六科。

黄庆杰（市政府副秘书长[挂职]）：协助赵良亭同志处理相关工作。

朱小敏（市政府办公室纪检组长）：负责市政府办公室纪检监察工作，分管市政府办公室监察室、信息科。协助分管督查工作。

周功耀（市政府机关事务管理局局长）：负责市政府机关事务管理局工作。负责办公室“双创”日常工作、中心城区周边绿化帮扶工作。

马宝剑（市应急管理办公室主任）：负责市应急管理办公室工作。负责市政府办公室“三联共建”、社会主义新农村建设帮扶和联校支教工作。

杨克山(市政府法制办副主任)：负责市政府法制办公室日常工作。协助赵立根同志联系赵俊民同志分管方面工作，协助分管综合三科。

陈泽勇(市政府督查室副主任)：负责市政府督查室日常工作。负责市政府重要文件、主要领导相关材料的组织起草和审核把关工作。协助分管市政府办公室秘书科、综合一科。

张爱萍（市政府督查室副县级督查专员）：协助处理市政府督查室日常工作，负责市政府督查专项工作。

安康市人民政府办公室

2014 年3 月7 日
