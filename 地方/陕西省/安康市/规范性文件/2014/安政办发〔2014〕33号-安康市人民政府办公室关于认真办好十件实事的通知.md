# 安康市人民政府办公室关于认真办好十件实事的通知

各县区人民政府，市政府各有关工作部门、直属机构：

在市第三届人民代表大会第五次会议上，市政府向全市人民作出了集中办好“十件实事”的庄严承诺。为切实办好“十件实事”，现将有关事项通知如下：

一、统一思想，提高认识。为民办好十件实事，是市政府让全市人民更多更好的享受改革发展成果的重要举措，是坚持执政为民、改善民生的具体体现，是市政府向全市人民作出的庄严承诺。办好民生实事，是宗旨所在、民心所向、责任所系，是确保群众教育实践活动取得实效的要求。各级各部门要提高认识，高度重视，确保按期高质量完成。

二、明确责任，分工协作。由各责任部门和责任人牵头负责，逐项制定工作方案，细化分解落实到专门领导和人头，明确每月、每季度进度安排，强化工作措施，精心组织实施。各配合单位要主动协作，密切配合，真抓实干，形成合力。

三、公开承诺，接受监督。由市政府办公室牵头，组织各责任部门责任人，通过新闻媒体向社会公开承诺办理措施和完成时限，主动接受群众监督，确保如期兑现，取信于民。各新闻单位要加强跟踪报道，确保十件实事落到实处。

四、强化督查，跟踪问效。市政府督查室负责，对十件实事进行“挂牌督办”，逐项建立督查台账，每月通报进度，半年督办检查，年终考核评比，对工作不力、达不到进度要求的，将追究责任部门及相关配合单位的责任。
