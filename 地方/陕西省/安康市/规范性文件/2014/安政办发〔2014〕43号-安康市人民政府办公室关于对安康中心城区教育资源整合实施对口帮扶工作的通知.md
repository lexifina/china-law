# 安康市人民政府办公室关于对安康中心城区教育资源整合实施对口帮扶工作的通知

汉滨区人民政府，市政府各工作部门：

为扎实推进安康中心城区教育资源整合工作，确保按时完成各项目标任务，按照《安康市人民政府办公室关于印发安康市中心城区教育资源整合方案的通知》(安政办发〔2013〕155 号)和安康中心城区教育资源整合工作动员大会精神，决定实行中心城区教育资源整合对口帮扶，现就有关要求通知如下：

一、提高认识

实施安康中心城区教育资源整合是一项事关群众切身利益的重大民生工程，是我市教育领域的一项重大综合改革。当前，中心城区教育资源整合工作正处在关键时期，时间紧、任务重、困难大。市区联动、部门帮扶，推进中心城区教育资源整合是2014年市政府确定集中办好“十件实事”的重要内容。实施对口帮扶工作，就是要充分调动社会各方面力量，集中人力物力财力，科学组织，统筹推进，形成攻坚合力，有序推进各项目标任务的完成。对口帮扶工作期限为2014 年1 月至2015 年12 月，与教育资源整合完成时限、目标任务一致。对口帮扶任务与整合项目任务捆绑，两年不变。各帮扶单位要站在支持教育就是支持安康发展的高度重视对口帮扶工作，认真研究安康市中心城区教育资源整合方案任务和节点工作，夯实对口帮扶工作的责任和任务，合力打好教育资源整合攻坚战。

二、明确任务

城区教育资源整合对口帮扶涉及学校12 所，其中：迁建学校4 所，改扩建学校8 所。时间紧、任务重、困难大、矛盾多、资金短缺。要如期完成目标任务，必须聚合各方力量，明确牵头帮扶和协同帮扶工作的责任和任务。

（一）制定帮扶方案。各帮扶单位要主动深入帮扶学校进行调查研究，主动与帮扶学校和牵头实施部门沟通协商，制定切实可行的帮扶工作方案，明确帮扶工作重点、目标任务和完成时限。于2014 年4 月10 日前将帮扶方案报市城区教育资源整合领导小组办公室（设在市教育局）。

（二）帮助解决问题。各帮扶单位要多方沟通协调，积极主动上门为学校建设提供全方位跟踪服务，协调解决对口帮扶学校在项目建设实施过程中的征地、拆迁、项目报建等困难和问题，为项目顺利建设创造条件。

（三）落实资金投入。城区教育资源整合难点在资金投入，各帮扶单位要充分发挥自身优势，充分利用可以利用的资源，想方设法帮助争取项目，筹措资金。要积极动员鼓励社会力量，引进社会资本和民间资本捐资助学。

三、工作要求

（一）加强领导，落实责任。按照“政府负责、市区联动、部门帮扶、社会参与、学校实施”原则，市区政府各负其责，分别对本级学校的资源整合工作负主体责任；市级牵头部门要切实担负起帮扶工作的牵头抓总，统筹协调、检查指导工作；市区协同帮扶部门要切实加强对帮扶工作的组织领导，主要领导要亲自抓，明确专人具体抓，工作责任和任务要落到科室（部门）和具体责任人；各帮扶企事业单位要竭尽所能，最大限度地为对口帮扶学校出资出力、办好事、办实事。

（二）密切配合，形成合力。各帮扶单位要加强与城区教育资源整合工作领导小组办公室、牵头实施部门和帮扶学校的密切配合，通力协作。责任领导和牵头单位要梳理任务，细化责任，帮建单位要主动工作，不等不靠，不回避矛盾，不推卸责任，定期对存在的问题进行集中研究解决，形成部门联动、相互协作的强大合力，确保各项整合工作有序推进。

（三）严格督办，强化考核。市中心城区教育资源整合工作领导小组办公室、市支教办要做好组织、协调工作，城区教育资源整合领导小组办公室、市政府督查室、市监察局效能室要加强对单位帮扶工作的督查，定期进行通报，督促结对帮扶工作快速顺利推进。对口帮扶任务完成情况纳入政府年度重点目标责任考核内容,一并进行考核。
