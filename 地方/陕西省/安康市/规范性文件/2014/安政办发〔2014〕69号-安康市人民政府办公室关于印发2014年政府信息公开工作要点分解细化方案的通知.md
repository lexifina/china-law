# 安康市人民政府办公室关于印发2014年政府信息公开工作要点分解细化方案的通知

各县区人民政府，市政府各工作部门、各直属机构：

为进一步增强政府信息公开实效，提高政府公信力，根据《陕西省人民政府办公厅关于印发2014 年政府信息公开工作要点分解细化方案》（陕政办发〔2014〕28 号）文件精神，结合我市实际，现将我市《2014 年政府信息公开工作要点分解细化方案》（以下简称《方案》）印发你们，请认真贯彻落实。

各县区要进一步提高对政府信息公开工作的认识，加强组织领导，明确责任分工，结合实际制订本地区分解细化方案和工作进度安排，确保各项任务落实到位。市政府各工作部门、各直属机构要按照《方案》分工，将所承担的任务抓紧抓实抓好。各县区、各部门要在今年11 月底前向市政府办报送政府信息公开工

作要点落实情况。市政府办公室将适时对落实情况组织检查。

安康市人民政府办公室

2014年5月28日
