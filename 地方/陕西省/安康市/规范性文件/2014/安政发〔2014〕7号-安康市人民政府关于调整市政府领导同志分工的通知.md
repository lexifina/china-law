# 安康市人民政府关于调整市政府领导同志分工的通知

各县、区人民政府，市政府各工作部门、各直属机构：

根据人员变动和工作需要，现将市政府领导同志分工调整通知如下：

徐启方：领导市政府全面工作。分管市财政局。

王安利：负责市政府常务和发展改革、人力资源和社会保障、编制、监察、公安、税务、行政学院方面工作以及区域物流中心建设。分管市政府办公室（督查室、应急办、外事侨务办公室、驻外办事机构），发展和改革委员会（重点项目办），监察局，公安局，司法局，审计局，人力资源和社会保障局（公务员局、城乡居民社会养老保险经办处、社会保险经办中心），统计局，信访局，台办，住房公积金管理中心。协助分管市财政局（公共资产管理局、财政征收管理局、安康发展投资集团有限公司、财信担保公司）。联系市国税局，地税局，国家安全局，安康监狱，养老保险经办处，国家统计局安康调查队，省属企事业审计处，驻安部队，驻安武警部队，恒口示范区。

赵俊民：负责工业信息、交通运输、对外开放、安全生产、电力、高新区方面工作以及新型材料、装备制造、生物医药、电子信息产业发展和区域交通枢纽、县域工业集中区、安康机场建设。分管市工业和信息化局（国资委、中小企业促进局），交通运输局，安全生产监督管理局（道路交通、消防安全委员会），高新区，招商局，公路管理局，金州矿业公司。联系总工会，工商联，安康供电局，地电安康分公司，西安铁路局驻安各单位，中石油安康分公司，安康机场有限公司，陕煤化集团陕南投资开发公司，陕西交建集团安川分公司，陕西高速集团白泉分公司。

梁志坚：负责南水北调方面工作。分管市政府法制办，市政府发展研究中心，南水北调办公室，盐务局，物价局，粮食局，协助分管发展改革工作，联系国家粮食储备库。

巨拴科：负责科技、环境保护、商务、食品药品安全、市场监管、通信、保险方面工作以及富硒食品产业发展和品牌建设。分管市科学技术局（地震办），环境保护局，商务局，食品药品监督管理局，工商局，质监局。联系科协，烟草专卖局，中国人民财产保险安康分公司，中国人寿保险安康分公司，无线电管理处，电信分公司，移动分公司，联通分公司。

张全明：负责卫生、金融方面工作。分管市卫生局（爱卫办），金融办，医改办，供销社。联系红十字会，人民银行，中国银监会安康监管分局，工商银行，中国银行，建设银行，长安银行，信合安康办事处，农业银行，农业发展银行，邮政储蓄银行，西部证券安康营业部。

邹顺生：负责国土资源、城乡规划建设、扶贫开发方面工作和中心城市建设。分管市国土资源局，城乡建设规划局，住房和城乡建设局（房管局），扶贫开发局（避灾扶贫搬迁办公室），人民防空办公室，双创办，土地统征中心，中心城区防洪保安工程建设指挥部，城市建设投资公司。联系水电三局实业发展总公司，省地质矿产勘查开发局第一地质队，瀛湖生态旅游区。

杜寿平：负责教育、文化、旅游、体育、人口和计划生育、妇女儿童方面工作和瀛湖旅游产业基地建设。分管市教育局（督导室）、文化文物广电局，人口和计划生育局，旅游局，体育局，安康职业技术学院，地方志办公室。联系团市委，妇联，文联，安康学院，市邮政局，市邮政管理局，广电传媒公司安康分公司，安康市新华书店有限责任公司。

鲁 琦：负责农村、农业、救灾、民政、民族宗教方面工作和现代农业园区建设。分管市民政局（老龄办），民族宗教事务局，水利局（防汛抗旱办公室），农业局，林业局（化龙山保护区管理局），移民开发局。联系市残联，市气象局，市水文水资源局、安康水电总厂，陕西汉江投资开发有限公司石泉、喜河、蜀河、旬阳水电厂，中国广核集团白河水电站。

何邦军：负责市财政局工作。

王汉琳：负责市旅游局工作，协助分管市文化文物广电局。

赵良亭：协助市长、常务副市长处理市政府日常工作，负责市政府办公室全面工作，协助分管市信访局、驻外办事机构。

安康市人民政府
