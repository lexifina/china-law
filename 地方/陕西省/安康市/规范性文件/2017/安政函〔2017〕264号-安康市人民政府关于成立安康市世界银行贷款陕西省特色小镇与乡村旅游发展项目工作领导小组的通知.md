# 安康市人民政府关于成立安康市世界银行贷款陕西省特色小镇与乡村旅游发展项目工作领导小组的通知

各县区人民政府，市政府各工作部门、直属机构：

为促进安康市世界银行贷款陕西省特色小镇与乡村旅游发展项目的积极争取和顺利实施，经研究决定，成立安康市世界银行贷款陕西省特色小镇与乡村旅游发展项目工作领导小组，其组成人员如下：

组 长：赵 璟 市委常委、常务副市长

副组长：赵德成 市政府副秘书长、办公室主任

廖良成 市发改委主任

马 勇 市财政局局长

陶柏林 市住建局局长

成 员：范传斌 汉滨区政府区长

杨尧根 市纪委常委、监察局副局长

许启汉 市民政局局长

陈国进 市审计局局长

廖坤波 市国土局局长

陈 彪 市环保局局长

石昌林 市规划局局长

江家安 市交通运输局局长

吴 平 市水利局局长

凌寿斌 市安监局局长

邱祖满 市公安局常务副局长

江 华 市国民经济动员办公室副主任

周仕成 市财政局副局长

张兆明 市住建局副局长

领导小组下设办公室，办公室设在市住建局，市住建局局长陶柏林兼任办公室主任。领导小组办公室负责项目前期准备、组织实施、项目建设及日常管理工作；市发改委负责项目上下协调衔接并兼顾指导石泉、紫阳两县的项目推进工作；市财政局负责项目贷款资金申请、拨付和监督管理；其他各部门做好工作配合，在项目规划、财务、环境、水利、采购、安保等方面搞好服务、把好关口，确保项目稳步推进。

安康市人民政府

2017年12月10日
