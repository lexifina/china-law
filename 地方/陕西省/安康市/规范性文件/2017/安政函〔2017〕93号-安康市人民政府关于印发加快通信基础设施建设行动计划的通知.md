# 安康市人民政府关于印发加快通信基础设施建设行动计划的通知

各县区人民政府，市政府各工作部门、直属机构：

现将《安康市加快通信基础设施建设行动计划》印发给你们，请结合实际，认真组织实施。

安康市人民政府

2017年5月25日

安康市加快通信基础设施建设行动计划

为进一步加快我市通信基础设施建设，提升通信基础设施支撑能力和水平，根据《陕西省加快通信基础设施建设行动计划》要求，结合我市实际，制定本行动计划。

一、总体目标

到2017年底，全市固定宽带平均可用下载速率同比提升23%。全市电信普遍服务覆盖率达到95%以上，农村固定宽带接入能力达到12Mbps。固定宽带家庭普及率超过65%，户均资费下降15%。全市城区、重点区域及公共场所4G网络覆盖率达到100%，手机流量平均资费下降20%。

（一）提升光纤网络支撑能力。

到2017年底，全市新增光缆总长1.7万公里，达到8.5万公里。新增光纤到户端口32.65万个，达到116万个。互联网城域网出口带宽总量达到900 G。切实提升用户上网体验，固定宽带平均可用下载速率达到13.5Mbps。

（二）提高全光网城市质量。

主要针对城市老旧小区加大改造力度，实现光进铜退，光网到户，畅通“最后一公里”。到2017年底，城市既有住宅小区光纤改造率达到99%。光纤到户用户总数达到47.5万户。光纤到户城市家庭具备100Mbps接入能力。光网用户接入带宽全部免费提升至20Mbps以上。50Mbps以上用户超过60%。

（三）推进电信普遍服务覆盖工程。

积极落实国家试点工程，推动农村及偏远贫困地区宽带建设发展，逐步缩小“数字鸿沟”，促进城乡基本公共服务均等化。到2017年底，全面完成第二批电信普遍服务试点项目，完成光纤宽带进入行政村703个，每村预留端口不少于3个，其中：汉滨区243个、高新区5个、汉阴县64个、石泉县58个、宁陕县21个、紫阳县66个、岚皋县37个、旬阳县144个、镇坪县3个、平利县31个、白河县31个。市工信局要牵头协调电信分公司、广电网络分公司加快施工进度，确保年底如期完成。同时要积极申报并启动国家第三批电信普遍服务试点项目。

（四）加快移动网络覆盖。

以公共区域开放为切入点，加快推动基站建设，不断提高4G网络城乡覆盖率。到2017年底，全市新建基站物理站址637个，新建4G基站总数1868个，新增移动网络室内分布系统75个区域；全市城区、重点区域及公共场所4G网络深度覆盖率达到95%以上，移动4G信号农村覆盖率达到95%、电信4G网络覆盖率达到62.5%、联通4G网络覆盖率达到19%；移动互联网用户普及率超过85%。4G用户突破152.5万户。

二、重点任务

（一）按照省通信管理局制定的网络架构优化方案，做好年度工作计划，明确目标任务，加大投资建设力度，及时升级固定宽带用户接入节点和骨干网节点设备，强化网络流量疏通能力。加快实施光纤入户工程，既有小区基本实现“光进铜退”，大力推进电信普遍服务项目，确保按时完成建设任务。要按照全市基站布点专项规划，优先布局城区、重点区域和公共场所物理站址。加快室内分布系统建设，全力消除楼宇内部、电梯、地下场所等移动网络盲点。（市宽带基础设施建设推进办，电信安康分公司、移动安康分公司、联通安康分公司、铁塔安康分公司、广电网络安康分公司负责）

（二）积极配合开展省通信基础设施服务能力监测及评估，帮助电信企业不断提升服务质量和能力。按照市委、市政府的决策部署和工作要求，组成工作组督促各级各部门各单位抓好贯彻落实。（市委网信办，市工信局负责）

（三）2017年6月底前组织完成全市通信基站布点专项规划的编制和报批工作。落实服务质量提升行动，配合开展通信市场监管，规范电信企业竞争行为，促进电信服务质量改善提升。落实提速降费行动，按照省2017年电信业务降费计划，协调督促各电信企业实现提速降费目标。落实网络架构优化行动，进一步扩容我市互联网出口带宽，协调督促电信企业加大基础设施投入、加快网络设备升级，强化网络流量疏通能力。实施好国家第二批电信普遍服务试点项目，组织好第三批试点项目申报。积极申请国家资金补助，争取国家试点示范项目，着力提升我市通信基础设施建设水平。（市工信局，各电信企业，市宽带基础设施建设推进办负责）

（四）按照《住房城乡建设部 工业和信息化部关于贯彻落实光纤到户国家标准的通知》（建标〔2013〕36号）、《陕西省住房和城乡建设厅、陕西省通信管理局关于加强光纤到户通信设施建设管理工作的通知》（陕建发〔2015〕78号）要求，深入贯彻落实各项光纤到户国家标准，建立并落实联席会议、新建小区项目清单、联合验收备案、联合监督检查等联合工作机制，以光纤到户设计审图、联合验收备案为抓手，将新建住宅区和住宅建筑内通信设施与建筑同步设计、同步施工、同步验收改造落到实处。严格落实新建住宅项目竣工通信设施验收备案制度，进一步规范新建住宅预先铺设通信配套设施建设，实现与住宅建筑投资主体同一化、设计一体化、施工同步化、验收标准化。督导各县区加大对通信配套设施资源共享的监管力度，严格按照建设管理程序，积极支持相关通信运营企业建设，为光纤改造工程施工提供便利条件。夯实各级建设行政主管部门、业主委员会、街道办事处相关责任，严厉查处建设单位、物业服务企业阻挠光纤到户改造和通信基站建设等违法违规行为。（市规划局、市住建局、各县区政府、高新区管委会、瀛湖生态旅游区管委会、恒口示范区管委会、市宽带基础设施建设推进办负责）

（五）结合放管服改革，优化环评审批程序，细化铁塔公司、各电信企业负责基站建设环评报备登记和自查检测，市县环保部门负责基站电磁辐射事后监管和问题查处的工作流程。加强电磁辐射科普知识宣传力度，促进公众对通信基站电磁辐射的科学认知。（市环保局、市教育局，铁塔安康分公司、电信安康分公司、移动安康分公司、联通安康分公司负责）

（六）按照《安康市人民政府办公室关于加快高速宽带网络建设推进网络提速降费的通知》（安政办发〔2016〕5号）精神，采取有力措施，落实公共区域全部免费开放要求，确保政府机关、学校、医院、展馆、工业园区、旅游景点、机场、公路沿线、铁路沿线、桥梁隧道、铁路车站、公路客运站、码头等所属建筑物以及路灯、道路指示牌、绿化区等公共设施场所空间全部免费开放，支持光纤铺设和4G基站建设。（各县区政府、高新区管委会、瀛湖生态旅游区管委会、恒口示范区管委会、市交通局、安康铁路机务段负责）

（七）在全市范围内，组织开展专项检查行动，严厉查处通信基础设施建设中针对电信企业的不合理收费行为。加强电信资费监管执法检查，维护消费者合法权益。（市发改委、市工商局、市宽带基础设施建设推进办负责）

（八）加大对通信、广电基础设施供电保障力度，建立用电报装、线路租挂、电力抢修等保障机制，不断提高通信基础设施直供电的比例，缩短通信基础设施用电开户和引入的审批时限。严格执行农村通信基础设施电费优惠政策，有效降低通信基础设施能耗成本。（安康供电局、地电安康分公司）

（九）按照职责推动我市通信基础设施健康有序发展。积极争取“宽带中国”、“宽带乡村”示范工程等国家通信基础设施项目和资金支持。督导做好宽带网络提速降费措施落实工作，引进和鼓励互联网内容信息源提供商在我市落户。广泛宣传通信基础设施安全保护政策法规，加大打击破坏通信基础设施、阻碍通信基础设施建设的违法犯罪行为力度，确保通信基础设施安全。做好网络安全、通信基础设施保护法律法规宣传教育进校园工作。（市发改委、市教育局、市工信局、市公安局、市文广局负责）

（十）切实将通信基础设施建设纳入政府议事日程，加强组织领导，强力推进各项工作落实。7月底前要完成通信基站布点专项规划审批，并纳入城乡规划和控制性详细规划。加强基站站址、通信机房和线路等通信基础设施建设的用地保障，优化基站环评流程，主动协调解决基站建设、光纤到户和土地征用过程中出现的矛盾和问题。加大资金配套力度，加快推进电信普遍服务试点项目落地落实。积极主动配合市级有关部门争取国家试点示范项目和资金支持。（各县区政府、高新区管委会、瀛湖生态旅游区管委会、恒口示范区管委会负责）

三、加强组织领导

（一）建立健全工作机制。

在市信息化发展和“智慧安康”建设领导小组的统一领导下，成立市通信基础设施建设工作组，由市委常委、常务副市长赵俊民任组长，副市长蒋清海任副组长，市政府副秘书长、办公室主任王龙军，市金融办主任张涛和市委网信办、市发改委、市教育局、市工信局、市公安局、市财政局、市国土局、市环保局、市规划局、市住建局、市交通局、市文广局、市工商局、铁路安康机务段、安康供电局、地电安康分公司、电信安康分公司、移动安康分公司、联通安康分公司、铁塔安康分公司、广电网络安康分公司、市宽带建设推进办主要负责人为成员，定期听取通信基础设施建设推进情况汇报，研究解决工作中的困难和问题。工作组办公室设在市工信局，负责做好日常工作，督导重点任务落实。

（二）建立月度报送制度。

各有关部门要细化工作方案，列出月工作进度表，每月20日前向工作组报告进展情况和下月度工作计划。各电信运营企业要细化工作任务，制定月度工作进度表，每月20日前向工作组报告进展情况、需要协调的问题和下月度工作计划。

（三）进度安排。

1.启动阶段。市上5月中旬完成工作机制建立，传达贯彻全省加快通信基础设施建设推进会精神，印发《行动计划》；

各责任单位（各县区、各部门、各运营企业）要建立相应的工作机制，制定工作方案，落实工作目标、措施和责任，于6月15日前报送工作组办公室（市工信局）。

2.推进阶段。6月底前完成规划编制，各运营商完成网络架构优化方案；启动全市光纤到户国标落实检查工作；

7月底前完成规划审批；

8月底前所有工作全面铺开；

10月底前完成所有铁塔基站布点，全面取消国内长途和漫游费；

11月底前所有基站挂机运行，所有老旧小区完成改造任务；

12月中旬完成电信普遍服务任务。

（四）建立通信基础设施建设考评机制。

市委、市政府将对各县区、各单位工作落实情况进行验收考评，考评结果作为年度目标责任考核参考，并在全市通报；12月下旬迎接省委、省政府验收考评。
