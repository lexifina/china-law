# 安康市人民政府办公室关于成立农村危房改造脱贫攻坚工作领导小组的通知

各县区人民政府，市政府各工作部门、直属机构：

为进一步加快推进我市农村危房改造脱贫攻坚工作，市政府决定成立安康市农村危房改造脱贫攻坚工作领导小组，现将组成人员通知如下：

组长：赵俊民 市委常委、常务副市长

副组长：王龙军 市政府副秘书长、市政府办公室主任

陶柏林 市住建局局长

成员：廖良成 市发改委主任

马勇 市财政局局长

廖坤波 市国土局局长

刘子龙 市扶贫局副局长

薛玉发 市移民搬迁办主任

段平安 市住建局副局长

领导小组下设办公室，陶柏林同志兼任办公室主任，段平安同志、市移民搬迁办副主任王纯凯同志兼任办公室副主任，负责全市农村危房改造脱贫攻坚日常工作。各县区均要成立相应机构，全力推进全市农村危房改造脱贫攻坚工作。

安康市人民政府办公室

2017年5月2日
