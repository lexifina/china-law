# 安康市人民政府办公室关于成立安康市公共资源交易审查监督委员会的通知

各县区人民政府，市政府各工作部门、直属机构：

按照省政府办公厅《关于整合建立统一的公共资源交易平台实施方案》（陕政办发〔2016〕12号）、《陕西省公共资源交易管理办法》有关要求，为切实做好我市公共资源交易平台整合工作，加强公共资源交易审查监督，市政府决定成立安康市公共资源交易审查监督委员会（以下简称市审监委），现就有关事项通知如下：

一、主要职能

（一）研究制定公共资源交易有关政策，审核拟出台的有关法规、制度。

（二）协调解决全市公共资源交易平台整合及运行中的重大问题，督促、指导公共资源交易和平台整合有关工作。

（三）开展联合执法检查和工作调研。

（四）研究其他需要协商解决的重要事项。

二、组成人员

市审监委主任由市政府常务副市长担任，副主任分别由市政府分管副秘书长、市发改委主任担任，成员由市级相关部门和单位负责同志组成。市审监委成员因工作变动需要调整的，由所在单位提出，市审监委确定。

市审监委设联络员，由各成员单位有关科室负责同志担任。

三、工作规则

市审监委全体会议根据工作需要召开，由主任或副主任主持，可根据议题邀请其他部门和单位参加会议。市审监委以纪要形式明确议定事项，重要事项及时报告市政府。

四、工作要求

各成员单位要按照职责和任务分工，认真落实市审监委议定事项，主动研究解决实际工作中出现的新情况、新问题；要密切配合、相互支持、形成合力，确保各项工作顺利推进，各项任务落到实处。
