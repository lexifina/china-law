# 安康市人民政府办公室关于印发《应急管理工作“五进”活动方案》的通知

各县区人民政府，市政府各工作部门、直属机构：

现将《安康市应急管理工作“五进”活动方案》印发给你们，请结合工作实际，认真组织实施。

安康市人民政府办公室

2017年6月6日

安康市应急管理工作“五进”活动方案

为深入推动应急管理工作进机关、进农村、进社区、进企业、进学校（以下简称“五进”活动），提高基层管理和应对突发事件能力，普及公众避险、自救、互救等应急防护知识，最大程度预防和减少突发事件，最大限度维护人民群众生命财产安全，结合实际制定本方案。

一、总体目标

（一）应急管理体制机制更加完善。落实各级各部门应急管理组织机构、工作职责及工作经费，明确专兼职人员负责应急管理工作，建成四级应急管理组织体系。推动应急管理以政府为主向“政府主导、社会全面参与”转变，凝聚全社会应对突发事件的合力。

（二）应急管理工作依法开展。深入贯彻《突发事件应对法》、陕西省《实施办法》，加强应急管理法律法规的学习、宣传、培训和实施，提高公众知晓率，提升应急管理工作的法制化、科学化、精细化水平。

（三）应急预案体系更加完善。基本建立“横向到边、纵向到底”的应急预案体系，总体预案、专项预案、部门预案、基层预案更加规范，贴近实际。预案演练经常性开展，针对演练中发现的问题，及时修订和完善预案，增强预案的针对性和实操性。

（四）应急科普宣教深入开展。以应急救援知识普及为重点，提高公众自救、互救和应对各类突发事件的能力。给合典型突发事件案例，教育、引导公众增强安全意识和防范意识。

二、活动内容

（一）应急管理工作进机关。各级政府、各部门应急管理工作有机构、有专兼职人员、有经费；全面贯彻落实《突发事件应对法》和陕西省《实施办法》，推动各级干部学法知法用法；预案制定牵头部门定期组织本系统、本单位开展应急预案的实战演练，及时修订和完善预案，增强预案的针对性和实操性；定期组织本系统、本单位开展应急管理知识宣传教育和专题培训，全方位普及应急知识和救援技能。（责任单位：市直各单位，各县区政府，高新区管委会、恒口示范区、瀛湖生态旅游区）

（二）应急管理工作进农村。基层村委会应急管理工作有机构、有兼职人员、有经费支持；积极开展基层应急管理示范点创建活动；重点围绕征地拆迁、社会治安、留守人员安全、山洪防御、地质灾害等方面深入开展风险隐患排查，定期对卫生院（室）、敬老院等公共建筑及病险水库、河道堤防、塘坝等水利设施进行检查；建立基层应急抢险救援队伍，定期开展应急演练和培训；积极设立信息直报点，鼓励群众及时报告突发事件信息；利用广播、标语、图片、宣传单等形式，宣传防御风雹雷击、山洪泥石流、用电、山林防火、防胡蜂、防食物中毒、防控动植物疫病等常识，使村民了解应急基本知识，懂得自救、互救和逃生常识。（责任单位：市水利局、市国土资源局、市卫计局、市民政局、市公安局、市交通运输局、市食药监局、市农业局、市林业局、市气象局，各县区政府，高新区管委会、恒口示范区、瀛湖生态旅游区）

（三）应急管理工作进社区。基层社区应急管理工作有机构、有兼职人员、有经费支持；深入开展基层应急管理示范点创建活动，夯实应急基础设施；对辖区各类隐患排查评估和监测预警，协调有关部门及时治理、消除隐患；结合实际，储备必要的应急物资，因地制宜设立应急避难场所；大力开展应急知识科普宣教活动（成立一支义务宣传队、购置一套应急知识学习资料、设置一块应急知识宣传专栏、每季度开展一次应急知识宣传教育活动、每半年开展一次应急演练、组建一支社区应急救援志愿者队伍）。（责任单位：各县区政府，高新区管委会、恒口示范区、瀛湖生态旅游区）

（四）应急管理工作进企业。各类企业应急管理工作有机构、有专兼职人员、有经费；深入开展基层应急管理示范点创建活动，夯实应急基础设施；定期开展隐患排查和治理，加强监测预警；预案齐全，组织开展应急演练，及时修订和完善预案；应急管理知识宣教氛围浓厚，应急法律法规得到普及，配备有宣传挂图、展板、图书、音像资料等，企业周边有宣传标语；经常性组织员工开展应急知识培训；高危企业要组建应急救援队伍，配备应急救援设备和物资。（责任单位：市工信局、市安监局、市公安局、市商务局、市交通运输局、市质监局、市食药监局、市住建局、市规划局、市环境保护局、市消防支队，各县区政府，高新区管委会、恒口示范区、瀛湖生态旅游区）

（五）应急管理工作进学校。各类学校应急管理工作有机构、有专兼职人员、有经费支持；开展基层应急管理示范点创建活动；定期开展校园安全隐患排查和治理；安全管理预案齐全，定期组织开展应急演练，及时修订和完善预案；在各级各类学校实施应急知识进校园“五个一”活动（每所学校每学期开展一次应急演练、开设一门应急课程、观看一部应急知识科普电影、阅读一本应急书籍、掌握一项自救技能），达到“小手拉大手，带动全社会”的目的。特别是在寒、暑假放假前等特殊时期，向家长、学生普及有关交通安全、食品卫生安全、防溺水、防煤气中毒、防触电、防火等安全知识，不断提高学生的应急避险和自救、互救能力。（责任单位：市教育局，各县区政府，高新区管委会、恒口示范区、瀛湖生态旅游区）

三、活动要求

（一）加强组织领导。各级各部门要高度重视应急管理五进工作，将其作为一项重要工作抓紧、抓实。各县区政府，高新区管委会、恒口示范区、瀛湖生态旅游区，市公安、安监、民政、卫计、教育、商务、工信、农业、林业、水利、国土、住建、规划、环保、交通、质监、气象、消防等有关部门要根据实际，突出重点，制定本县区、本系统具体活动实施方案，抓好动员部署，深入开展应急管理工作“五进”活动。在活动中，要广泛发动社会团体、企事业单位以及志愿者等参与应急管理工作中来，形成全社会共同参与的良好氛围。

（二）做好经费保障。各级政府要把基层应急管理工作的经费纳入公共财政预算支出范围，督促财政部门对社区、乡村、学校的应急设施、应急队伍、避难场所等基层应急能力建设安排必要的投入，使人力、物力、财力等要素适应基层应急管理工作的要求。各级各类机关、农村、社区、企业、学校等“五进”活动实施主体要积极争取财政、社会等方面支持，切实加大应急物资的投入，制订应急物资保障方案，重点加强防护用品、救援装备、救援器材的物资储备，做到数量充足、品种齐全、质量可靠。

（三）加大宣传力度。各级公安（消防）、安监、卫生、民政、工信、食药、气象、国土、水利、农业、环保、住建、规划（人防、地震）、教育等与群众日常生活密切相关的部门，要根据季节特点及时提供鲜活、生动的教育素材，加强与各级新闻媒体、通信运营商沟通协作，充分发挥广播、电视、报纸、网络等新闻媒体和手机短信平台的作用，积极开展应急管理工作“五进”活动开展及应急知识宣传普及工作，采取群众喜闻乐见、寓教于乐的方式，细分受众层次，尽可能使用通俗语言，简明扼要，多题材、多角度、有针对性地进行宣传报道。

（四）加强督促检查。市应急办负责全市应急管理工作“五进”活动的指导督促和协调工作，对各县区、市直有关单位工作开展情况进行监督检查，确保活动开展取得实效。请各县区政府、市直相关单位将具体活动实施方案于6月30日前报市应急办。
