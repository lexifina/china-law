# 安康市人民政府办公室关于调整市信息安全等级保护工作领导小组组成成员的通知

各县区人民政府，市政府各工作部门、直属机构：

为进一步提高我市基础信息网路和重要信息系统的安全保护能力，加强对全市网络信息安全等级保护工作的协调指导，市政府决定对市信息安全等级保护工作领导小组组成人员进行调整。调整后的组成人员名单如下：

组 长：杨尚伟 市政府副市长、市公安局局长

副组长：马 霞 市政府副秘书长、市信访局局长

成 员：李康林 市委宣传部副部长、市文联党组书记

邱祖满 市公安局常务副局长

张祥国 市工信局副局长

何昌平 市保密局副局长

王朝辉 市公安局网安支队支队长

领导小组办公室设在市公安局，办公室主任由邱祖满同志兼任，办公室副主任由王朝辉同志兼任。

安康市人民政府办公室

2017年6月27日
