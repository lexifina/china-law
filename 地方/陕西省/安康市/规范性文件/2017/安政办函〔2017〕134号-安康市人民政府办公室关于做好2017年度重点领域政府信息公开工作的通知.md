# 安康市人民政府办公室关于做好2017年度重点领域政府信息公开工作的通知

市政府各工作部门：

为进一步加强全市政府信息公开工作，按照中、省有关文件要求，结合《陕西省2017年全省政务公开评估指标体系》，市电子政务办公室对2017年度全省政务公开评估考核指标中涉及的部门重点领域信息公开任务进行了疏理，并按部门进行了任务分解（详见附表），请各有关单位按照任务要求，在本部门网站建立专栏并发布有关信息。今年我市已将政务公开纳入年度目标责任考核内容，请各单位务必要高度重视，按时完成相关任务。市电子政务办公室将于7月15日开始对各部门发布情况进行检查，检查结果将作为全市政务公开工作考核依据。

附件：安康市2017年度重点领域政府信息公开任务分解表

安康市人民政府办公室
