# 安康市人民政府办公室关于2017年二季度市长信箱信件办理情况的通报

各县区人民政府，市政府各工作部门、直属机构：

现将二季度“市长信箱”信件办理情况通报如下。

二季度“市长信箱”共受理有效信件 1302 件，同比上升 4.8%，已办结 1287 件，办结率 98.8%。转送县（区）政府办理 777 件，已办结 766 件，办结率 98.6%；转送市直和中省驻安单位办理 525件，已办结 521 件，办结率 99.2%。办理情况较好的有：旬阳县、白河县、紫阳县，市国土局、市城市管理局、市交警支队。办理差的有：平利县、汉阴县，市公安局、市发改委。人民网“地方领导留言板”给市长的 19 件留言已全部办结。

上半年“市长信箱”共受理有效信件 2330 件，同比上升11.5%，已办结 2305 件，办结率 98.9%。转送县（区）政府办理1356 件，已办结 1339 件，办结率 98.7%；转送市直和中省驻安单位办理 973 件，已办结 966 件，办结率 99.3%。人民网“地方领导留言板”给市长的 38 件留言已全部办结。

二季度热点问题：一是房地产开发方面。此类诉求主要是房屋产权证办理、小区停车位、物业服务收费、居民用水用电等。其中金州国际城小区、汉城国际小区部分业主已集体到市滞留上访。二是城市管理方面。随着中心城市规模不断扩大，群众反映交通拥堵、车辆停放、占道经营、环境卫生方面的诉求不断增加。比如群众多次反映城区西堤头乱摆摊，市城管局果断采取措施进行治理，此问题迅速得到解决。三是脱贫攻坚领域。此类信件占信件总量 12%，其中要求纳入贫困户占 35%、政策落地不实占 25%、要求享受扶贫待遇占 20%、检举贫困户评审不公占 20%。汉滨区、

平利县、白河县此类问题突出，分别达 60 件、22 件、21 件。

下半年将召开党的十九大，同时也是全市追赶超越、打赢脱贫攻坚战役的冲刺阶段。各县区、各部门要牢固树立“抓信访就是抓民生”意识，充分运用“市长信箱”这一平台，着力解决群众关心的热点、难点问题。特别要重点关注涉军群体、涉众型案件受损群体、民办代课教师，以及脱贫攻坚、征地拆迁、房地产开发、企业改制遗留问题，采取有力措施进行化解，努力减少问题累积和矛盾上行，防止发生越级集体上访或非正常上访，为党的十九大胜利召开和全市中心工作有序推进营造良好社会环境。
