# 安康市人民政府办公室关于2017年二季度全市政务服务工作情况的通报

各县区人民政府，市政府各工作部门、直属机构：

二季度，全市政务服务工作以深化“放管服”改革的总体要求为指引，以政务服务标准化建设和“最多跑一次”改革为抓手，积极推进全市“互联网+政务服务”体系建设，努力打造优质、高效、便捷的政务服务模式。市、县区（含高新区）两级政务服务中心共受理行政审批和便民服务事项40.82万件、办结40.44万件、在办0.38万件、办结率99.1%，群众满意率99.7%。

一、市级亮点工作

一是推行政务服务标准化建设。4月份，市政务中心、市质监局联合制定了《安康市政务服务中心标准化建设工作指导意见》（安政办发〔2017〕37号），从组织机构、设施设备、服务事项、窗口建设、办事流程、管理制度、服务行为、政务公开、监督考核、队伍建设等10个方面对政务服务工作进行规范，明确具体标准要求，建立公开、便民、高效、廉洁、规范、监督的服务机制，努力在全市构建覆盖全面、科学有效的政务服务标准体系，真正做到政务服务“一切工作有标准，一切标准有程序，一切程序有监督，一切监督有公开”。二是开展“我为群众代办一件事”活动。5月份，市政务中心启动“我为群众代办一件事”活动，让中心工作人员为群众进行代办服务，感受窗口工作作风、服务态度和服务效能，了解审批事项的办事流程、办结时限及申请材料等，查找窗口在审批服务过程中存在的问题与不足，为改进提升办事效率和服务质量打下良好基础。市政务中心46名同志为群众代办业务，提交46份事项代办调研报告，查找涉及15个窗口单位的26个问题，并针对进一步精简材料、压缩时限、提升服务提出了26条有效意见与建议。针对办事群众反映二手房交易难、交易慢的问题，市政务中心立即协调市不动产登记中心、市房管局，从整合窗口设置、优化办理流程、规范前置程序等方面入手，将单独二手房交易办结时限（含前置程序）压缩至35个工作日，提升效率40%以上。三是推进国地税办税事项同城通办便利化改革。4月份，市政务中心组织市国税局、市地税局等部门召开联席会议，专题研究国地税办税事项同城通办便利化改革工作，要求国地税办税业务进行深度融合，实现“一窗受理、内部流转、限时办结”。经过多次沟通协调，通过多方共同努力，6月1日起市政务中心国地税办税事项同城通办业务正式对外运行，有效解决了纳税人办税多头找、多次跑的问题，真正让纳税人“进一个门、找一个人、办两种税”。同时，结合国地税业务的整体进驻和政务大厅的改造升级，市政务中心单设了民政、司法、公安、消防、卫计、供电6个窗口，服务窗口由原来的64个增加到74个，政务大厅的服务功能更加齐全，服务环境更加优美。四是组织开展各类学习培训和文化活动。市政务中心按照“两例会、一检查”工作机制，积极组织开展各类学习培训和文化活动，不断强化窗口工作人员的服务意识，提升能力素质，调动工作积极性和创造性。4月份，市政府副秘书长、市政务中心主任刘福全结合政务服务工作，给中心全体党员干部上了一堂《践行“两学一做” 深化“放管服”改革》的主题党课。5月份，中心组织召开了政务服务云平台系统操作培训会和政务礼仪培训等活动。6月30日，举办“不忘为民初心 砥砺奋进前行”为主题的庆祝中国共产党成立九十六周年暨全市政务服务系统联谊文艺演出活动，市政务中心、九县两区（汉滨区、高新区）政务中心参加并演出，全面展现了安康政务人努力拼搏、健康向上的良好精神风貌。

二、县区亮点工作

汉阴县公布《汉阴县群众企业办事“最多跑一次”72项事项清单（首批）》，整合建设全县政务服务资源共享数据资源库，搭建政务云服务“一张网”软硬件平台，全县10个镇级便民服务大厅与县政务中心实现网络办事平台互联互通；印发《汉阴县不动产登记等一批并联审批事项实施方案》，将涉及15个单位共10项审批事项纳入“并联审批”，研发并联审批操作系统并投入使用。岚皋县大力推进“最多跑一次”改革，明确了涉及22个部门共71项“最多跑一次”事项；开展“局长进大厅”活动，部门主要领导及分管领导按约定时间到大厅窗口，解决窗口工作中遇到的问题，赢得了办事群众一致好评。高新区公布26项“最多跑一次”事项清单，深化重大招商引资项目落户准入全程联办、跟办、帮办机制，实行国地税业务联合服务，涉税业务一站式办结,并设立24小时自助办税服务区，为办税人提供发票业务的全天候服务。石泉县推动政务服务体系规范化建设，完成了6个镇级服务中心规范化升级改造。启用钉钉OA系统等科技手段延伸中心的管理工作，进一步简化工作流程，全面提高管理效率，有效防止了工作疏漏现象。宁陕县经过第一轮梳理，对外公布“最多跑一次”事项37项。设立贫困人口医疗保障“一站式”服务窗口，建立了“一站式”医疗服务工作机制。平利县建立政务中心进驻单位联席会议制度，每月定期组织召开部门工作联席会议，达到部门窗口之间信息互通、相互借鉴、共同提高的目的。汉滨区政务中心建立贫困户“医疗报销”一站式办理服务窗口，全区就医贫困户只需提供一套资料即可办结看病医疗报销。旬阳县自5月1日起，原由省、市核准的冠“陕西”“安康”字样企业名称，现由县政务服务中心市场监管局窗口直接办理，办理时限由3个工作日压缩为即办件；白河县创新服务方式，开展了“预约”5.20”，幸福敞开门”婚姻登记业务预约服务活动，受到了办事群众一致好评。
