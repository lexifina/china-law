# 安康市人民政府办公室关于三季度全市政府网站建设情况的通报

各县区人民政府，市政府各工作部门、各直属机构：

按照《国务院办公厅关于印发政府网站发展指引的通知》（国办发〔2017〕47号）要求，市政府办于8月1至4日组织开展了2017年第三季度全市政府网站抽查，并于8月21至24日进行了复查，对部分网站信息公开、办事服务和网站安全进行了重点检查。现将有关情况通报如下：

一、基本情况

目前，全市正在运行的政府网站66家。第三季度，“我为政府网站找错”栏目网民有效留言11条，总体办结率达100%；各县区、各部门政府信息公开工作进一步深化，对上级政府网站保障力度稳步提升；随机人工抽查全市政府网站35个，有8个政府网站不合格，30个网站未在网站准确链接中国政府网“我为政府网站找错”平台，总体抽查合格率为77%；

二、存在问题

（一）日常监管措施不到位。部分主办单位没有建立网站季度自查制度，网站常态化监管力度仍需加强，内容更新不及时、空栏目、信息发布不准确、错链、严重错误字词等问题依然存在。

个别主办单位在网站管理负责人变更或网站改版后，不能及时主动更新全国政府网站信息报送系统基本信息，严重影响中省对我市政府网站检查的准确性。

（二）应付检查、日常运维懈怠现象依然存在。部分县区和部门依然没有认识到政府网站管理的严峻形势，落实省市整改要求不积极、不到位，整改流于形式，工作不精细，在省市复查时发现依然有个别县区和部门整改问题不彻底。个别主办单位不注重日常运维，出现信息发布审核不严、网站纠错办理和域名续费不及时等问题给全市政府网站普查工作造成很大被动。镇坪县政府门户网站域名续费不及时造成该网站长达3天不能正常访问，宁陕县政府门户网站纠错系统整改反馈不及时不规范，先后被省政府办公厅电话点名批评。

（三）办事服务要素不齐全，政民互动不密切。部分网站办事服务事项要素不齐全、内容不准确；政策解读、舆情反馈不及时；监测时间点前1年内开展网上调查和意见征集活动次数不达标，不能主动倾听公众意见，接受社会的批评监督。

（四）网站安全管理不到位。部分主办单位重建设轻管理，特别是对网站安全管理措施不到位。8月2至3日，省委网信办对我市政府网站安全进行了专门检查，发现部分网站存在安全漏洞、用户口令简单且不按时更换、未进行日常安全检测等问题，造成极大安全隐患。

（五）网站建设管理不规范。部分政府网站名称和域名不符合《指引》要求，十县区中仅汉滨、岚皋政府网站名称符合要求，其他均不符合要求，市教育局、民政局、国土局、统计局、体育局、交警支队、方志办等部门网站名称也不符合要求；旬阳县政府网站英文域名不符合以.gov.cn为后缀的要求。

三、工作要求

各县区、各部门要按照《指引》有关要求，进一步推进政府网站规范管理运行。一是认真学习落实《指引》要求，规范政府网站建设标准。严格政府网站开设、整合、下线、备案流程；规范网站名称、域名、徽标和宣传语，政府网站要以本地区、本部门机构名称命名，要使用以.gov.cn为后缀的英文域名和符合要求的中文域名，不得使用其他后缀的英文域名。二是科学设计，深化网站功能。完善政府网站信息发布、解读回应、办事服务和互动交流机制，加强网站政务服务功能，搭建统一的互动交流平台，为企业和群众提供准确好用的办事服务，充分发挥政务公开第一平台和政务服务总门户作用。三是做好网站安全防护。落实网站安全测评和等级保护制度，做好网站防攻击、防篡改、防瘫痪、防泄密等安全工作，确保网站稳定、可靠、安全运行。四是迅速落实抓好整改。迅速安排专人，对照全国政府网站普查指标和已下发的问题清单，查漏补缺，于9月3日前全面进行排查整改，并将整改结果报市电子政务办公室，对整改不到位的将进行全市通报批评，被中省点名批评或通报的将按相关规定启动约谈和问责机制。
