# 安康市人民政府办公室关于调整市推进职能转变协调小组组成人员的通知

各县区人民政府，市政府各工作部门、各直属机构：

根据工作需要和人员变动情况，市政府决定对市推进职能转变协调小组（以下简称协调小组）组成人员、各专题组、功能组及相关职责进行调整。现将调整事项通知如下：

一、协调小组组成人员及主要职责

（一）组成人员

市委常委、常务副市长赵璟担任协调小组组长，市政府秘书长、市编委办主任陈伍文担任副组长，市政府副秘书长、办公室主任王龙军，市政府副秘书长、法制办主任赵德成，市政府副秘书长、政务中心主任刘福全，市政府副秘书长戴胡爽、谢奎，市政府督查室主任阮家军为成员。

（二）主要职责

推进简政放权、放管结合、优化服务改革，统筹研究重要领域和关键环节的重大改革措施，研究拟提请市政府常务会议审议的有关重要事项，协调推动解决改革中遇到的困难和重点难点问题，指导县区相关工作，督促各县区各部门落实改革措施。

协调小组下设行政审批改革组、投资审批改革组、职业资格改革组、收费清理改革组、商事制度改革组、教科文卫体改革组、政务服务改革组7个专题组和综合组、督查组、法制组、评估专家组4个功能组。

二、协调小组专题组组长、副组长及主要职责

（一）行政审批改革组。

组长由市编委办（市审改办）主任陈伍文担任，副组长由市编委办（市审改办）副主任薛同新担任。

负责牵头推进全市行政审批制度改革，进一步取消和下放行政审批事项，推进权责清单制度建设，推行相对集中行政许可权改革试点工作，规范行政审批行为，防止和纠正变相审批，约束自由裁量权，提高政府服务水平。

（二）投资审批改革组。

组长由市发改委（物价局）主任、局长廖良成担任，副组长由市委维稳办副主任茹甫英、市国土资源局副局长马吉安、市环保局副局长刘波、市规划局总规划师田曙安、市住建局副局长何向发、市政务服务中心副主任马劲柏担任。

负责牵头推进投资项目审批制度改革，大幅减少投资项目前置审批和规范前置中介服务，推进并联审批和投资项目在线审批监管平台建设，积极探索投资项目清单管理模式，运用大数据和互联网等技术手段加强监管。

（三）职业资格改革组。

组长由市人社局（公务员局）局长汪小卫担任，副组长由市人社局副局长、安康市技师学院院长徐郧顺担任。

负责牵头推进全市职业资格管理制度改革，减少职业资格许可和认定事项，建立职业资格目录清单管理制度，规范职业资格和证书管理，加强对职业资格制度实施情况的监管。

（四）收费清理改革组。

组长由市财政局局长马勇担任，副组长由市发改委（物价局）副主任、副局长曾朝阳，市工信局副局长卢浩，市民政局副局长刘林担任。

负责牵头推进全市收费管理制度改革，清理取消不合法不合理收费项目，实行收费目录清单管理，完善收费监管制度。

（五）商事制度改革组。

组长由市工商局局长王传杰担任，副组长由市发改委（物价局）副主任、副局长邓军，市工商局副局长申林斌，市质监局总检验师郝江山，市国税局副局长汪卫，市地税局总经济师王恒丁担任。

负责牵头推进全市商事制度改革，深化“先照后证”“多证合一、一照一码”和工商登记全程电子化改革，构建以信用为核心的新型市场监管机制，不断加强事中事后监管工作。

（六）教科文卫体改革组。

组长由市政府副秘书长、法制办主任赵德成担任，副组长由市教育局副局长李黎、市科技局副局长孙伟庆、市文广局副局长鄢明建、市卫计局副局长刘芳霞、市体育局纪检组长郑翔太担任。

负责牵头协调推动全市教科文卫体领域简政放权、转变职能、增加公共产品和公共服务供给的措施，研究加强事中事后监管的措施，按照促进大众创业、万众创新的要求，研究提出相关意见和措施。

（七）政务服务改革组。

组长由市政府副秘书长、市政务中心主任刘福全担任，副组长由市政务中心副主任马劲柏担任。

负责全市政务服务改革和推进全市“互联网+政务服务”体系建设，改进优化政务服务工作，加强政府信息公开工作，指导全市各级政务服务中心建设和政务服务效能监督工作。

各专题组的日常工作由组长单位承担。各专题组负责调查研究本领域社会反响大、群众意见集中的问题，协调相关部门对重点难点问题合作攻关，提出改革建议。各专题组的改革建议可在请示市政府分管领导同志后，提交协调小组会议审议。专题组的职责和组成可根据工作需要调整。

三、协调小组功能组组长、副组长及主要职责

（一）综合组（协调小组办公室）。

组长（主任）由市政府副秘书长、办公室主任王龙军担任，副组长（副主任）由市编委办（市审改办）副主任薛同新担任。综合组设在市编委办，从市级部门抽调人员组成，实行集中办公。

负责协调小组的日常工作；负责沟通协调各专题组工作，跟踪了解、分析研究各专题组重点工作、改革措施，反映改革中遇到的困难和问题，向协调小组提出意见和建议；组织对简政放权、放管结合、优化服务改革重大问题和长远问题的调查研究，向协调小组提出工作建议；指导和推动地方改革工作；收集汇总相关信息资料，编发工作简报；联系新闻宣传、网络信息等主管部门组织媒体做好宣传和舆论引导工作。

（二）督查组。

组长由市政府督查室主任阮家军担任，副组长由市编办正县级督查专员邓型权、市政府督查室副县级督察专员毛良韶担任。

负责督促检查简政放权、放管结合、优化服务改革各项措施贯彻落实情况，核查督办各专题组提出的部门和县区改革中存在的问题，以及社会对有关改革反映强烈的问题。

（三）法制组。

组长由市政府副秘书长、法制办主任赵德成担任，副组长由市政府办（市法制办）副主任杨克山担任。

负责对简政放权、放管结合、优化服务改革措施进行合法性审核，及时提出修订相关地方性法规和政府规章的建议方案，对清理的文件进行审核等。

（四）评估专家组。

组长由市委党校（行政学院）常务副校长屈晓红担任，副组长由市委党校（行政学院）副校长王彦青担任。评估专家组的日常工作由市委党校（行政学院）承担。

负责对全市简政放权、放管结合、优化服务改革过程中的重大决策进行调研和论证，对改革的成效进行第三方评估，对全市各县区营商环境进行综合评价和排名。根据工作需要，对评估专家组成员进行动态调整。

安康市人民政府办公室
