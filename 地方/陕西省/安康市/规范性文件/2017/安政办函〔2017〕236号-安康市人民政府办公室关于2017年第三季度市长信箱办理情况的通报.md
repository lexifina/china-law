# 安康市人民政府办公室关于2017年第三季度市长信箱办理情况的通报

各县区人民政府，市政府各工作部门、直属机构：

现将2017年第三季度“市长信箱”信件办理情况通报如下：

三季度“市长信箱”共受理有效信件1402件，环比增加7.7%，同比增加24.8%，已办结1387件，办结率98.9%。其中：转送县（区）政府办理 797件，已办结785件，办结率98.5%；转送市直及中省驻安单位办理605件，已办结602件，办结率99.5%；人民网地方领导留言板给市长留言16件，已全部办结。从办理情况看，旬阳县、白河县、紫阳县、市住建局、市公安局、市交警支队受理及时、答复办理情况较好；少数县区和部门重视不够，信件办理滞后，如恒口示范区办结率82.1%、市环保局办结率89.5%。

本季度热点问题：一是农村农业方面。主要反映扶贫政策落实、乡村公路硬化、村干部违纪等问题。二是小区管理方面。主要反映房产证办理、物业管理、停车等问题。其中元辰国际、金州国际城等小区业主已发生了集体访，近期金城美墅业主多人多次反映小区出现安全隐患。三是城市管理方面。主要反映占道经营、环境卫生、车辆乱停等问题。在责任单位的积极协调下，如张沟桥、中渡路马路市场问题，九华巷道脏乱差的饮食摊点的问题，育才西路人行道长期停放的僵尸车问题，中心城区背街小巷私装地锁，中渡路车辆乱停乱放等一批群众反映强烈的问题得到有效解决。

各县区、各部门要及时协调解决群众通过“市长信箱”反映的合理诉求，及时回应，妥善处理，防止问题累积和矛盾上行，为党的十九大胜利召开营造安全稳定的社会环境。
