# 安康市人民政府办公室关于成立安康市推进资本市场融资工作领导小组的通知

各县区人民政府，市政府各工作部门、直属机构：

为抢抓国家支持贫困地区企业利用资本市场加快发展的有利时机，积极引导和推动我市企业赴境内外证券市场上市或赴场外股权交易市场挂牌，借助资本市场力量促进资源优化整合与产业转型升级，推动全市经济持续健康发展，市政府决定成立安康市推进资本市场融资工作领导小组。现将组成人员通知如下：

领导小组办公室设在市金融办，由张涛同志兼任办公室主任。领导小组办公室具体负责做好全市资本市场发展建设规划、政策措施制定和综合协调服务等工作；领导小组各成员单位根据职责分工，及时制定和完善促进多层次资本市场建设的产业规划、财税扶持等政策措施，为加快推进我市资本市场发展创造良好条件。

安康市人民政府办公室
