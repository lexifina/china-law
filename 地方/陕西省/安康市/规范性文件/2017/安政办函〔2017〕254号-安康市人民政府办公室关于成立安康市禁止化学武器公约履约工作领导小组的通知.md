# 安康市人民政府办公室关于成立安康市禁止化学武器公约履约工作领导小组的通知

各县区人民政府，市政府各工作部门、直属机构：

为切实加强我市禁止化学武器履行国际公约工作，根据省禁化武办《关于报送履约机构设立情况的通知》（陕禁化武办发[2017]5号）要求，市政府决定成立安康市禁止化学武器公约履约工作领导小组，现将组成人员通知如下：

组 长：赵 璟 市委常委、市政府常务副市长

副组长：赵德成 市政府副秘书长、办公室主任

许启政 市工信局局长

杨 柳 市政府外事办公室主任

成 员：市发改委、市财政局、市工信局、市公安局、市环保局、市商务局、市卫计局、市工商局、市安监局、市质监局、市国家安全局、市外事办，西铁安康建筑段负责人。

领导小组下设办公室，具体负责禁化武领导小组的日常工作。办公室设在市工信局，办公室主任由市工信局副局长向德刚同志兼任。

安康市人民政府办公室

2017年10月30日
