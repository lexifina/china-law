# 安康市人民政府办公室关于公布市级部门随机抽查事项清单（第一批）的通知

各县区人民政府，市政府各工作部门、直属机构：

根据省政府办公厅《关于印发〈陕西省推广随机抽查规范事中事后监管工作实施方案〉的通知》（陕政办发〔2016〕15号）要求，市审改办会同市政府法制办，对市级部门梳理的随机抽查事项进行汇总审查，形成了《安康市市级部门随机抽查事项清单（第一批）》，已经市政府常务会议审议通过，现予公布，并就有关事项通知如下：

一、相关市级部门要在本通知发布之日起10个工作日内，在本部门门户网站公布部门随机抽查事项清单，接受社会监督。

二、各县区、各部门要在编制公开随机抽查事项清单的基础上，进一步建立完善“双随机”抽查规则和随机抽查对象库及执法检查人员名录库，通过信息化手段实现抽查对象及检查人员的“双随机”抽取，切实开展“双随机”监管工作。

三、市级各部门要加强对下级业务部门“双随机”监管工作的指导和监督，各县区要根据本地实际，及时审定并公布本级部门随机抽查事项清单，加快推进“双随机”监管工作。

四、各县区、各部门要建立随机抽查事项清单动态管理制度，适时根据法律法规规章废改立情况和工作实际，对本级、本部门随机抽查事项清单进行动态调整和更新。今后凡有变动的随机抽查事项，市级各部门要主动梳理，并报市审改办、市政府法制办审核同意后集中公布。

五、市审改办、市政府法制办要依据自身职能，加强对随机抽查事项清单执行情况的监督检查，收集和受理公民、法人或其他组织的意见建议、投诉举报。（监督举报电话：市审改办：0915-3221566，市政府法制办：0915-3218501）。
