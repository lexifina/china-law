# 安康市人民政府办公室关于调整市社会信用体系建设工作联席会议成员单位的通知

各县区人民政府，市政府各工作部门、直属机构：

根据社会信用体系建设工作的新形势、新要求，为加快推进全市社会信用体系建设步伐，深入开展“信用安康”建设，市政府决定对市社会信用体系建设工作联席会议成员单位进行调整，现将调整后的组成人员通知如下：

总召集人：赵俊民 市委常委、市政府常务副市长

召 集 人：蒋清海 市政府副市长

王龙军 市政府副秘书长、办公室主任

廖良成 市发展改革委主任

具体成员由市委宣传部、市编委办、市档案局、市发展改革委、市中级法院、市检察院、市教育局、市科技局、市工信局、市公安局、市民政局、市司法局、市审计局、市财政局、市人社局、市国土局、市环保局、市规划局、市住建局、市交通局、市水利局、市农业局、市林业局、市商务局、市文广局、市卫计局、市药监局、市旅游局、市体育局、市统计局、市安监局、市工商局、市质监局、市发展研究中心、市金融办、市民宗局、市盐务局、市国税局、市地税局、市气象局、人行安康中支、安康银监分局、安康邮政管理局、市烟草专卖局负责同志组成。

联席会议办公室设在市发展改革委，廖良成同志兼任办公室主任，市国民经济动员办副主任江华同志兼任办公室副主任。

安康市人民政府办公室

2017 年 3月22日
