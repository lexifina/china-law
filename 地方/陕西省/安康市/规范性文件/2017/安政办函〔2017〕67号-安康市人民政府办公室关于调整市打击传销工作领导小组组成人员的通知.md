# 安康市人民政府办公室关于调整市打击传销工作领导小组组成人员的通知

各县区人民政府，市政府各工作部门、直属机构：

为进一步加强对打击传销工作的组织领导，健全完善打击传销长效工作机制，保障我市经济社会健康有序发展，根据机构调整和人员变动，市政府决定对市打击传销工作领导小组组成人员进行调整，现将调整后的组成人员通知如下：
