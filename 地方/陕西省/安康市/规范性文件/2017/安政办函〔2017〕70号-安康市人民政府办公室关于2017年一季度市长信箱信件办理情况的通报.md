# 安康市人民政府办公室关于2017年一季度市长信箱信件办理情况的通报

各县区人民政府，市政府各工作部门、直属机构：

现将一季度“市长信箱”信件办理情况通报如下：

一季度“市长信箱”共受理有效信件1027件，已办结997件，办结率97.1%。信件总量同比上升24.3%，增幅较大的县区和部门有白河县上升48.5%、汉滨区上升35.1%、汉阴县上升28.6%、市运管局上升514.3%、市公安局上升52.9%、市住建局上升34.7%。转送县（区）政府办理579件，已办结552件，办结率95.3%；转送市直和中省驻安单位办理448件，已办结445件，办结率99.3%。旬阳县、汉阴县、白河县，市住建局、市人社局、市卫计局办理情况较好。汉滨区信件总量最大，本季度办结率仅为87.5%。我市第一季度收到的19件“人民网地方领导留言板”给市长留言已全部办结。

本季度热点问题：一是扶贫领域。县区反映扶贫政策的信件100余件、移民搬迁的信件80余件。请各县区务必加强政策宣传，保证政策落实公正、公开、高效。二是物业管理。反映居民小区物业的信件50余件，市政府领导多次批示要求公安、住建、规划、工商等部门联合办理。请各单位密切配合，切实解决好群众身边的问题，防止由信变访。三是城市公交。群众对政府近年来大力发展城市公交高度认可，对公交运行、管理、服务建言献策40余件，请主管部门认真研究采纳，以提升城市公交服务水平和营运效率。

当前，全市上下正在奋力“追赶超越”建设西北生态经济强市。为切实提升“市长信箱”公信力，市政府将对部分已办理的涉及群众切身利益的问题进行回访，对“重回复，轻办理”的信件将退回承办单位重新办理，对在办理工作中敷衍推诿、缓办不办的单位进行通报。
