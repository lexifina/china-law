# 安康市人民政府办公室关于一季度全市政府网站抽查情况的通报

各县区人民政府，市政府各工作部门、直属机构：

现将一季度全市政府网站抽查情况通报如下：

一、基本情况

一季度，省政府办公厅对全省政府网站进行了抽查，发现我市有9家政府网站存在突出问题，其中4家被一票否决，目前有8家已完成整改；市电子政务办公室对13家政府网站进行了抽查，要求9家存在突出问题的网站限时进行整改，其中6家已完成整改。

二、存在问题

（一）“四不”等问题出现反弹。部分主办单位不能严格按照普查指标要求建设管理本单位网站，网站不能访问、内容更新不及时、空栏目、错链接、严重错别字、办事指南要素缺失、互动交流渠道不畅通、不经上级审批重新开启已关停网站、网站改版不修改普查系统基础信息库、人员更替工作不交接等问题依然存在。（见附件1）。

（二）缺乏主动性，检查整改流于形式。部分县区和部门不能积极主动检查整改本单位网站存在问题，被动等待上级部门为本单位网站检查问题的依赖思想严重；在落实整改要求时，仅满足于完成上级抽查时指出的问题，不能对网站进行全面检查整改和优化，致使出现在二次抽查时又发现其他问题的现象。

（三）政府信息公开不深入。政府信息公开存在主动发布意识不强、申请公开答复不规范、内容不全面、公开不及时等问题。如市财政局未公开市级2016年财政预算、2015年决算及“三公”经费信息。（见附件2）

（四）对上级政府网站内容保障不到位。部分由部门负责保障的信息公开、办事服务、互动交流等内容不能及时准确提供，造成栏目内容缺失。不能积极主动利用政府网站“在线访谈”、“意见征集”等栏目与网民进行沟通交流，如市住建局于3月17日在本单位网站公布了“长春路七里沟立交节点方案公示”意见征集后，未及时主动通过市政府网站这个政府信息公开第一平台公开信息；相关部门不能及时主动通过政府网站公开与人民群众密切相关的公众应广泛知晓的政策，以及停水、停电、道路施工、交通出行、生产生活等方面信息；部分部门不能积极向政府网站报送政务信息。（见附件3）

三、工作要求

一是切实做好自查整改。各县区、各部门要迅速安排专人，对照全国政府网站普查指标，对本单位网站进行全面自查和整改，巩固提升政府网站建设管理水平，确保网站达标并顺利通过中省每季度的检查。同时，要完善常态化监管机制，每季度对本单位网站建设管理情况进行自查，并将自查情况报市电子政务办公室，落实情况纳入全市政府网站绩效评估体系予以评分。

二是核查普查系统信息真实性。全面核查更新全国政府网站普查信息报送系统基础信息（http://121.43.68.40），确保与网站栏目信息一致；网站负责人和联系人等基本信息真实可靠，特别是在负责人员更替时，相关工作要交接到位、不断链。

三是深化政府信息公开。利用政府网站和新媒体及时主动公开政府信息公开目录、重点领域等方面信息，建立重点工作和社会热点信息专题专栏，按时编制发布政府信息公开工作年度报告。

四是加强互动交流。要优先利用政府门户网站开展政策解读、舆情反馈、网上调查和意见征集，广泛倾听公众意见，接受社会的批评监督；及时通过政府门户网站发布与人民群众密切相关的公众应广泛知晓的政策和生产生活等方面信息，搭建政府与公众交流的“直通车”。
