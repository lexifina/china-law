# 安康市人民政府办公室关于印发2017年深化简政放权放管结合优化服务改革重点任务分解落实方案的通知

各县区人民政府，市政府各工作部门、直属机构：

为贯彻落实《全国深化简政放权放管结合优化服务改革电视电话会议重点任务分工方案》（国办发〔2017〕57号）、《关于印发深化简政放权放管结合优化服务改革重点任务分解落实方案的通知》（陕政办发〔2017〕58号）精神，围绕“为促进就业创业降门槛、为各类市场主体减负担、为激发有效投资拓空间、为公平营商创条件、为群众办事生活增便利”，进一步提高全市“放管服”改革的强度、力度和速度，持续在重要领域和关键环节取得突破，激发市场活力和社会创造力，经市政府同意，现将《2017年深化简政放权放管结合优化服务改革重点任务分解落实方案》印发给你们，请认真抓好贯彻落实。

一、加强组织领导。各县区各部门主要负责同志要亲自研究部署深化“放管服”改革工作，分管负责同志要紧盯重点任务的各个环节，抓好组织实施和跟踪问效。相关部门要细化分解任务，明确时间节点，层层压实责任，真正做到任务落实、措施落实、责任落实。各县区各部门要在本通知印发20日内，对照省市要求,紧密结合实际,制定具有本地区特色的“放管服”改革方案并扎实推进。2017年12月20日前，重点任务牵头单位汇总完成情况报市推进职能转变协调小组办公室。

二、强化统筹协调。各县区各部门要切实增强大局意识，理顺工作机制，加强上下之间、横向之间的工作衔接和政策对接，形成推进改革的强大合力。各级推进职能转变协调小组要切实发挥牵头抓总作用，配齐配强职转小组办公室机构和力量，加强对“放管服”改革的统筹协调、督促检查和业务指导，认真协调解决深化改革过程中的重点难点问题，确保各项改革任务顺利推进。

三、大胆创新实践。要充分把握开展相对集中行政许可权改革试点、基层政务公开标准化规范化试点等机遇，着力在深化“放管服”改革上先行先试，当好改革“排头兵”，打造改革“新高地”，构建政府治理创新试验区和便利化营商环境样板。要尊重基层首创精神，积极营造良好环境，加强指导协调，鼓励支持探索创新，加快形成试点先行、以点带面的工作格局。

四、强化督查问责。不断加大“放管服”改革任务落实情况的督查力度，各级推进职能转变协调小组要建立健全专项督查、第三方评估、考核评价和问责追究等机制，确保改革措施落地生效。实施“放管服”政策措施落实审计监督，各级审计部门要全方位监督检查改革政策措施的落实进度和成效，严肃查处上有政策、下有对策，有令不行、有禁不止，以及重大履职不到位等问题。
