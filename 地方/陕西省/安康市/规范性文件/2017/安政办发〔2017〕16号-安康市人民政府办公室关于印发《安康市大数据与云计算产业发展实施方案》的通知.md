# 安康市人民政府办公室关于印发《安康市大数据与云计算产业发展实施方案》的通知

各县区人民政府、市政府各工作部门、直属机构：

现将《安康市大数据与云计算产业发展实施方案》印发给你们，请认真贯彻落实。

安康市人民政府办公室

2017年2月27日

安康市大数据与云计算产业发展实施方案

为认真贯彻落实《国家信息化发展战略纲要》（中办发〔2016〕48号）、《陕西省大数据与云计算产业发展五年行动计划》（陕政发〔2016〕22号）和《陕西省大数据与云计算产业示范工程实施方案》（陕政办发〔2016〕50号）精神，促进我市云计算、大数据等信息产业发展，加快推进产业结构优化升级，促进创业创新，制定本实施方案。

一、工作思路和发展目标

（一）工作思路。按照“十八大”新型工业化、信息化、城镇化、农业现代化同步发展的总要求，坚持“政府引导、市场驱动、聚焦应用、创新突破”发展原则，夯实基础、培育体系、深化应用，通过2-3年努力，使我市大数据与云计算具备一定的产业发展基础、产业链和产业体系初步构建，以政务云建设为切入点，并在部分重点行业应用取得突破和创新，促进全市经济结构转型和增强治理能力现代化。

（二）发展目标。到2018年，通过配合开展秦云工程、实施城市信息融合工程、大数据应用工程，形成明确的产业方向和较好的产业支撑能力，引进或培育1家大数据龙头企业，建设安康大数据中心，积极培育产业关键环节骨干企业。

二、主要任务

(一)云平台建设工程

发挥安康环境、电力等优势，加强与国内大型ICT企业合作，在高新区建设大数据和云计算中心，为安康及秦巴地区政府、企业、社会提供云资源和云服务。

1.电子政务云。以市电子政务网络统一平台为基础，整合市级各部门的网络、机房、存储资源，创新建设模式，围绕政务数据聚集与开放、政务大数据应用，建设电子政务云平台，保障各类政务数据资源的整合分析与信息共享服务，建立政务数据开放资源体系、供给体系和保障体系。(责任单位：市电子政务办)

2.政务服务云。按照“互联网+政务服务”的总体思路，运用大数据、云计算、移动互联网和物联网等现代信息技术，创新政务服务形式，建设集行政审批、公共服务、公共资源交易、政务公开、效能监察、数据分析六大功能于一体的安康市政务服务云平台。整合部门信息资源，联通市、县、镇、村四级政务服务网络，形成“横向到边、纵向到底”的安康政务服务模式。 (责任单位：市政务服务中心)

3.健康云。以已建成的县级卫生信息平台为基础，整合计生信息系统网络、平台、数据资源，构建统一高效、资源整合、互联互通、信息共享、透明公开、使用便捷、实时监管的卫生计生市级平台，推动惠及全民的健康信息服务。（责任单位：市卫生计生局）

4.智慧城管云。以城市综合管理为对象，构建科学的预警监控体系，整合城市规划、交通、治安、城管、环境、气象等方面的数据资源，建立可视化和智能化的大数据应用分析模型，通过对海量数据的智能分类、整理和分析，使城市管理者能够更准确地预测可能出现的情况，及时调度资源，从而有效疏导、防范和处理城市管理领域的风险和问题，打造智慧、平安、和谐城市的典范。（责任单位：市城管局）

5.安居云。整合住房保障、房地产市场、个人住房信息、公积金管理等信息系统，实现全市住房信息的实时采集、统计分析和监督管理。（责任单位：市住建局）

6.旅游云。建设旅游大数据云平台，推动旅游信息向各级旅游管理部门、旅游企业及电子商务平台开放。发展在线度假租赁、旅游网络购物、在线旅游租车平台等互联网旅游新业态，开展旅游宣传推广、智能导游、电子讲解、在线预订、旅游信息推送、咨询投诉等服务。促进智慧旅游APP、微信服务平台、景区虚拟旅游、三维实景、位置语音导览、实时视频展播等智慧旅游应用，为游客提供个性化、互动式旅游服务。（责任单位：市旅游局）

7.公共安全云。整合、分析通信运营商数据和视频监控数据，实时监控人流走向，人群密度，防范踩踏、非法集会等群体性安全事件发生。推动公共安全大数据在综治、公安、消防、交通、应急、城市管理等部门应用，构建全方位、立体化的公共安全网。（责任单位：市公安局）

8.工业云。积极推进陕西工业云在安康的推广和应用，使更多企业充分利用工业云的云资源、云智慧、云应用、高性能计算、工业协同设计提高企业的研发、生产、管理、销售能力，增加企业的竞争力。（责任单位：市工信局）

9.配合开展“秦云”建设。积极配合陕西省开展“秦云”工程建设，推进数据共享和开放，加强和工商云、环保云、质量云、食药监云、安监云、教育云、文化云、社保云、国安警务云的对接，并加快应用和推广。（责任单位：市级相关部门）

（二）城市信息融合工程

学习咸阳城市信息融合试点示范经验，统一项目建设、统一资金管理、统一数据开放、统一资源共享、统一业务协同，加快现有信息系统整合，建设群众办事一站通、便民服务一号通、惠民资金一卡通、掌上安康一点通、和谐社区一格通、协同办公一网通等优政惠民“六个一”工程，推进政策融合、技术融合、数据融合，促进大数据关联分析和综合应用，推动大数据产业发展。（责任单位：市委网信办、市工信局）

（三）大数据应用工程

1.社会公共服务一卡通项目。以社会公共服务卡（居民健康卡）为载体，推进金融 IC 卡、市民卡、旅游消费卡等应用集成和一卡通用，实现与财政惠民卡、社会保障卡互联互通。用一张卡纵向互联实现政府实时监管，横向打通各行业系统公共服务，实现集约服务协同管理，方便政府治理和群众生活。同时形成实时数据综合积累，部门数据集中比对，通过海量数据脱敏脱密后的开放，促进我市大数据产业发展。（责任单位：市卫生计生局、市财政局、市人社局负责）

2.信用信息平台及服务项目。依托陕西省公共信用信息平台的各项管理和应用服务功能，全面归集整合各级政府部门在履行职责中形成或掌握的信用信息，实现各县区、各部门信用信息互联共享。构建政府与社会互动的信用信息共享机制，不断拓展信用信息征集共享范围，形成覆盖全市所有法人和自然人的信用信息大数据库，为政府管理及各类经济社会活动提供信用信息服务。（责任单位：市发改委、市信用办、市电子政务办）

3.工业企业大数据动态监测项目。推进工业、统计、电力、货运、税务、银行等部门企业数据共享、关联比对和分析，充分挖掘企业动态数据价值，改进提升经济运行监测、预测和风险预警，带动工业大数据相关产业发展。（责任单位：市工信局、市统计局）

4.投资项目在线审批监管平台应用项目。各级政府相关部门尽快接入国家电子政务外网，加快推进政务服务中心涉及投资项目审批事项纳入在线平台，实现跨部门、跨层级项目审批、核准、备案，支撑市、县投资项目在线审批监管业务开展和各级政府投资项目管理与决策。（责任单位：市发改委）

三、工作措施

（一）加强组织领导。由市信息化发展和“智慧安康”建设领导小组统筹领导全市大数据与云计算产业发展工作，领导小组办公室（市工信局）负责大数据与云计算产业发展具体日常工作。

（二）加强战略合作。积极开展与省信息化工程研究院合作，打造安康大数据与云计算发展专家团队，编制安康大数据与云计算规划和顶层设计，为安康的大数据与云计算发展提供策划和指导。积极开展与陕西西咸新区沣西新城大数据基地及国内知名信息化集团公司的合作，充分利用其人才、技术、资金、平台、数据资源优势，共建安康大数据和云计算服务平台，服务安康的大数据与云计算产业发展。

（三）加强政策资金配套。认真贯彻落实中省关于云计算、大数据发展的系列文件精神，并结合安康实际，制订相应的配套文件，对大数据、云计算重点项目在电力、用地、财税、融资等方面予以倾斜扶持，推动安康大数据与云计算的发展。财政部门要安排适当的建设资金，引导和撬动社会资金，建立以政府投入为引导，社会投入为主体的投融资机制，为大数据与云计算提供资金保障。

（四）加强信息基础设施建设。加快推进全光纤网络城市和4G网络建设，加速推进光纤到户进程，扩大移动通信覆盖范围，提高互联网网间质量，提高宽带网络速率；以电信普遍服务试点为契机，加大农村宽带网络建设力度，着力缩小“数字鸿沟”，到2017年底，安康城区家庭具备100 Mbps光纤接入能力，宽带用户平均接入速率超过30Mbps，县城区宽带用户平均接入速率达20 Mbps，80%的行政村实现光纤到村，农村宽带家庭普及率大幅提升；4G网络全面覆盖城市和农村。

（五）加强人才队伍建设。积极寻求与西安等地及本地各大院校、科研院所的合作，创造条件，优化环境，引进大数据、云计算高端人才；鼓励本地高校设立大数据和云计算等专业，并通过与国内知名高校和信息技术企业进行课件置换，更新课程，培养大数据、云计算人才；在高新区创业大厦、创客中心建立培训实习基地，为初创团队和人员提供免费场地、共享海量数据和平台技术，培养大数据、云计算创新应用人才。

（六）强化数据信息安全。按照“统一数据存储和管理，统一系统平台和运营”的原则，制定信息采集和管控，敏感数据管理、数据交换、数据权益等大数据管理制度，明确大数据采集、使用、开放等环节涉及信息安全的范围、要求和责任。
