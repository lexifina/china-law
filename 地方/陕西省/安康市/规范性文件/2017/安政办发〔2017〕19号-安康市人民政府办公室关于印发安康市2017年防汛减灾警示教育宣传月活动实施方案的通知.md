# 安康市人民政府办公室关于印发安康市2017年防汛减灾警示教育宣传月活动实施方案的通知

各县区人民政府，市政府有关工作部门：

现将《安康市2017年防汛减灾警示教育宣传月活动实施方案》印发给你们，请认真组织实施。

安康市人民政府办公室

2017年3月6日

安康市2017年防汛减灾警示教育宣传月活动实施方案

2017 年防汛减灾工作事关全局，责任重大。为切实增强全民防汛减灾意识，努力营造广泛参与灾害风险管理和综合减灾浓厚氛围，提高防灾减灾能力，实现安全度汛目标，特制定本实施方案。

一、指导思想

全面贯彻习近平总书记关于防汛抗洪抢险救灾工作重要讲话和市第四次党代会精神， 突出“以人为本、生命至上、安全第一”的防汛理念， 坚持以防为主、防抗救相结合，实现从注重灾后救助向注重灾前预防转变，从减少灾害损失向减轻灾害风险转变，从应对单一灾种向综合减灾转变，以汉江防汛和山地灾害防范为重点，普及防汛减灾知识，增强公众水患意识，提高各级各部门、广大干部群众防汛减灾避险自救互救能力，保障人民群众生命财产安全，最大程度减轻灾害损失， 为加快建设西北生态经济强市提供安全保障。

二、活动内容

（一）举行警示教育宣传月启动仪式。 结合“3.22”世界水日及第三十届“中国水周”和科技之春等活动，由市、县区政府分别在安康中心城区、各县城启动防汛减灾警示教育宣传月活动。全市活动的启动仪式由市水利局（防汛办）牵头，汉滨区人民政府配合，组织市国土、气象、水文及汉滨区水利局（防汛办）、安康水电厂等单位在中心城区开展播放电视专题片、发放宣传资料、展板宣传、现场咨询等活动。

（二）开展形式多样的宣传活动。 深入开展防汛减灾工作进机关、进学校、进企业、进村组社区、进家庭“五进”活动。联合安康人民广播电台、安康电视台继续开办《对话防汛减灾》系列访谈节目，市气象局、安康水文局和安康水电厂、石泉水电厂分别组织开展防汛减灾工作“开放日”活动，邀请人大代表、政协委员和群众代表座谈，参观监测预警和应急指挥设施，征求对气象、水文服务和防汛减灾等建议意见，各有关部门根据职责做好防汛减灾警示教育宣传活动，普及防汛减灾科普知识，增强广大群众防汛减灾意识和避险自救互救能力，营造全社会关心、参与防汛减灾工作的浓厚氛围。

（三）提早开展各项备汛工作。 根据预测分析，今年气候形势复杂，旱涝灾害可能重于常年，短历时强降水增加，中小河流和山洪灾害多发，防汛形势严峻。各级各部门要立足于防大汛、抗大旱、抢大险，更加注重灾前预防，强化综合减灾措施，及早扎实做好备汛工作。全面落实“党政同责、一岗双责”防汛抗旱责任制，层层签订责任书，把工作责任落到实处；及时召开防汛抗旱工作会议，全面安排部署防汛减灾工作；认真编修各级防汛抗洪预案，储备补充防汛抢险物资，加强防汛抗洪抢险应急队伍建设；切实落实“河长制”，加快汉江综合整治、中小河流山洪沟治理、病险水库除险加固、山洪灾害防治和水毁修复工程建设，落实各项防汛减灾措施。

（四）夯实“ 三到户” 工作措施。 各县区和市级防汛包抓有关部门要按照“情况掌握到户、信息预警到户、责任落实到户”的工作要求，深入包抓村组社区、住户进行防汛宣传动员，讲解防汛预案，公示防汛明白卡，签订包抓责任书，全面落实“防、抢、撤”措施。各相关部门和单位要抓紧对防汛监测预警、通讯等设施进行调试、试鸣，确保设备正常运转。安康城区防汛工作“三到户”会议由汉滨区政府及早筹备组织召开。

（五）扎实开展防汛隐患大排查。 由各县区包联领导带队，结合全面深化河长制，抽调包抓干部组成督导组深入镇办、村组社区、河湖库渠，对防汛重点单位、要害部位、关键环节和涉水在建工程、水电站、库塘、尾矿库、校园、旅游区、敬老院、移民安置社区等区域度汛工作进行全面排查，建立台账，落实整改责任领导、措施和时限，确保安全度汛。

（六）组织开展防汛应急演练。 各级防汛指挥部要结合实际，针对防汛重点部位地段和关键环节，结合防汛抗洪救灾应急预案、山洪灾害防御预案和水库调度运行计划，组织开展“抗洪救灾、提前转移、水库度汛”为主要内容的防汛应急演练，切实提升灾害应急处置能力。

三、职责分工

（一）加强组织领导。 市政府成立防汛减灾警示教育宣传月活动领导小组，由市政府分管领导任组长，分管副秘书长和市水利局主要负责同志任副组长，市防汛办、国土局（地灾办）、民政局、安监局、规划局、住建局、文广局、安监局、公安局、教育局、卫计局、科技局（地震办）、工信局、武警支队、消防支队、交警支队、气象局、水文局、科协、安康水电厂、安康日报社、安康电视台、安康人民广播电台等单位负责人为成员，组织开展各项防汛减灾警示教育宣传活动。

（二）落实工作职责。 各县区政府要成立领导小组，制定活动方案，明确职责分工，抓好活动的具体实施工作，确保取得实效。市防汛减灾警示教育宣传月活动领导小组各成员单位要按照职责分工，尽快制定本系统、本单位的实施方案，加强协调配合，逐项抓好落实，扎实做好警示教育活动。市水利局（防汛办）要搞好统筹协调、督查落实等工作，推动各项活动扎实开展。安康日报社、安康电视台、安康人民广播电台、市政府网站要通过开设专栏专题、刊发评论文章、播放专题片和公益广告等形式，及时报道市、县区及部门开展“防汛减灾警示教育宣传月”活动情况。电信安康分公司、移动安康分公司、联通安康分公司负责发送防汛减灾公益短信，营造全社会广泛参与防汛减灾工作氛围。

（三）确保活动实效。 按照厉行节约、节俭办事、注重实效的原则，组织开展防汛减灾警示教育宣传活动。各县区各有关部门要组织专门力量，深入排查隐患，及时整改，组织专业技术人员和志愿者，深入城乡社区村组、学校厂矿企业等基层单位，普及防汛避险、自救互救等知识技能，切实提高全民防汛减灾能力。
