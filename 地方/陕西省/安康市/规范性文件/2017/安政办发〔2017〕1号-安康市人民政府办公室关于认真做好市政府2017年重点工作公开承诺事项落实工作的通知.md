# 安康市人民政府办公室关于认真做好市政府2017年重点工作公开承诺事项落实工作的通知

各县区人民政府，市政府各工作部门、直属机构：

为贯彻落实省委追赶超越精神和“三项机制”要求，创新推动市委、市政府重点工作落实，提高政府效能和执行力，确保按时、按要求完成市政府2017年重点工作公开承诺任务，根据市政府《重点工作公开承诺制度》、《重点工作公开承诺事项问效问责办法》相关要求，现就有关事项通知如下：

一、夯实责任，扎实推进。各承诺单位要按照“聚焦重点、自加压力、迎难而上、追赶超越”要求，高度重视公开承诺事项落实工作，将公开承诺事项列入本单位重要议事日程，召开专题会议安排部署，逐件制定推进计划，切实将责任落实到具体领导、部门、科室和人员，确保按时、按要求完成公开承诺任务。

二、规范报送，保证质量。各承诺单位要明确专人具体负责公开承诺事项的督办衔接工作，并在2017年4月13日前将联络人及联系方式报市政府督查室（网络协同办公系统）。从2017年4月份起，各承诺单位要在每月底前将本单位承诺事项当月进展情况报送市政府督查室（网络协同办公系统），报送材料必须简明扼要、不漏项，项目类进展情况要说明形象进度，已完成工作要报送印证资料。

三、跟踪督办，严格考核。市政府督查室要邀请人大代表、政协委员、监察机关、新闻媒体参与督查，形成督查合力，要通过现场督查、联合督查、专项督查、季度点评等方式对承诺事项实行全程跟踪督办，及时、据实、公开通报进展情况。同时，对工作推进不力、不按要求报送进展情况的承诺单位，市政府将根据相关规定追究责任。年底，市政府督查室要结合全年督查督办、问效问责情况形成督查意见报市考核办，市考核办根据督查意见进行考核、赋分。对未完成且未经市政府同意调整的公开承诺事项，承诺单位要在市级媒体上向社会各界作出说明。对于全面完成公开承诺事项、社会反响好的承诺单位，将根据“三项机制”相关要求进行鼓励激励，市级媒体将其作为抓落实典型进行宣传报道。

2.7月底前完成西成客专330千伏电源线路工程（宁陕段），12月底前开工建设110千伏岚皋变第二电源工程，年底前完成35千伏大河增容扩建工程。年底前完成33眼农村机井通电、196个贫困村动力电不足改造、75个中心村电网改造及16项2016年农网改造升级工程。

3.实施110千伏东郊变10千伏送出、110千伏江南变部分10千伏线路改造等11项工程，围绕中心城市重点市政建设项目和棚户区改造等民生工程,进一步优化供电网架结构，提高城市配电网供电能力和供电可靠性。

4.年底前建成投运5座充电站，保证新能源及时接入和消纳。围绕推进安康高铁站建设，完善电网建设规划。

5.根据机场迁建工程进度需要，7月底前完成10千伏五里西线勇敢支线迁改，10月底前完成10千伏五里西线红旗支线迁改工程；会同机场办4月底前完成五恒、五恒牵线路迁改工程，10月底前完成金梁、金恒线路迁改工程。

6.完成脱贫攻坚指挥部下达的年度任务，制定支持贫困村合作社、涉农企业和大户等经济实体用电扶持优惠政策，农网改造529公里，新改建高压线路38公里；完成汉滨区晏坝镇竹园村年度包抓帮扶任务。

八十、地电安康分公司

1.建成宁陕35千伏金鸡河输变电工程、110千伏江口变电站35千伏线路接入工程和镇坪35千伏曾家变电站二期工程。

2.加大辖内贫困村农网改造和重点基础设施、重点产业项目建设环境保障力度，解决68个贫困村的电力线路改造升级，新建10千伏线路12.29公里，改造10千伏线路26.97公里，安装变压器6.75兆伏安/42台；新建低压线路176.38公里，改造低压线路299.29公里，完成户表改造7420户。

3.2017年7月底前完成安康机场西导航台（汉阴县双乳镇）施工临时用电工程，12月底前完成供电工程项目编报工作。

4.加大全市农网改造力度，新建10千伏线路74.75公里，改造10千伏线路169.63公里；安装配电变压器29.55兆伏安/167台，新建0.4千伏线路94.86公里，改造0.4千伏线路185.28公里，户表改造4.3074万户；完成镇坪县钟宝镇民主村年度包抓帮扶任务。

八十一、安康水电厂

1.坚持“防汛第一”的原则，严格执行各级防汛指令，及时消峰错峰，确保电站安全度汛,保障安康城区及下游城镇防汛安全。

2.科学调度，合理利用水资源，保障汉江生态基流不小于73m3/s。

3.积极参与瀛湖湖泊治理，开展库区漂浮物打捞,加大水质保护宣传力度，常态下开展漂浮物巡查，确保汉江水质。

4.开展电站扩机前期研究相关工作，力争项目立项，助推安康清洁能源发展。

5.落实融合发展理念，配合瀛湖库区改造，大力发展电站工业旅游，助力瀛湖生态旅游产业发展。

6.完成市脱贫攻坚指挥部下达的年度任务和旬阳县赵湾镇王长沟村年度包抓帮扶任务。

八十二、中国人寿安康分公司

1.确保全年完成总保费5.4亿元，同比增长15%。

2.全力做好中国人寿保险陕西省分公司与安康市政府战略合作协议落地生根。

3.全市计生家庭保险覆盖率不底于90%，计生家庭及专干保险参保户数不少于6000户。“三农”服务专员人数达150人以上。组建100个镇办农村小额保险服务站，实现村村有保险服务专员。

4.衔接中国人寿保险陕西省分公司将赞助的200万元贫困大学生资金落实到位。

5.支持高新金融聚集区建设，全力推进人寿安康分公司本部办公区域北迁。

6.完成脱贫攻坚指挥部下达的年度任务，创新保险产品，大力开展贫困人口意外保险、大病补充医疗保险、农村小额人身扶贫保险，着力化解贫困群众人身风险；完成汉滨区洪山镇双柏村年度包抓帮扶任务。

八十三、人保财险安康分公司

1.全年完成保费收入2.6亿元，完成各类赔款支付1.8亿元，案件处理率达到100%以上。

2.复制政保扶贫合作的人保“宁陕模式”，为全市9县1区建档立卡贫困户统一办理房屋保险、家庭成员意外伤害保险、农业种植养殖保险和大病补充医疗保险的“三保一补”保险。大力推进平利两权抵押贷款保证保险业务。

3.强力推进政府救助（一元民生）保险业务，把全市318万城乡居民纳入保险保障范围，为建设平安安康保驾护航。

4.大力推进安康富硒食品的产品质量保险和产品责任保险，提升安康富硒食品在全国的知名度和市场影响力。

5.全年新建成三农营销服务部36个，扩大城乡居民就业数量，探索拓展农业全产业链保险，努力培育特色农业保险，实现“三农”保险供给升级。

6.支持高新金融聚集区建设，2017年为高新支公司在高新区购买办公用房，完成机关本部北迁方案的上报工作。

7.完成市脱贫攻坚指挥部下达的年度任务，创新财险产品，为贫困户量身定做保险产品,为脱贫户的发展和个人做好灾害和人身意外保险；完成白河茅坪镇田湾茶园和汉滨区建民办青春村年度包抓帮扶任务。
