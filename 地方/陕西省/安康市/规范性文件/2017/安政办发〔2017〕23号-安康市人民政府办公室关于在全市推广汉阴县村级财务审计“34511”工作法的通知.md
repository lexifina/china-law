# 安康市人民政府办公室关于在全市推广汉阴县村级财务审计“34511”工作法的通知

各县区人民政府，市政府各工作部门、直属机构：

开展村级财务审计是在坚持村民自治法律架构下，以改革创新精神、法治理念完善农村基层治理体系、扩大基层民主、保障农村长治久安的客观要求，是依托审计制度加强和规范村级财务管理，保障农村集体资金、资产、资源安全,维护农民群众切身利益，密切党群干群关系，促进农村基层党风廉政建设的重大举措。2015年11月，市委、市政府作出关于开展村级财务审计试点工作部署。汉阴县坚持问题导向，大胆实践，积极探索，认真总结，形成了村级财务审计初步工作方法。形成了村级财务审计“34511”（即：坚持三不原则、处理好四个关系、实行四人编组形式、把好五个关口、有序推进十一个步骤）工作法。该工作法具有首创性、科学性和较强的操作性，体现了“工作思路新、工作模式优、工作成效显著、各方反响好”的特点，在村财审计实践中成效显著，并在2016年6月市政府召开的全市推进村级财务审计工作现场会上进行总结交流，得到省审计厅、省编委办的肯定和《中国审计》《陕西日报》、陕西电视台等中省媒体及社会各界的广泛关注。

为建立健全村财审计科学模式和长效机制，推进村财审计尽快实现常态化、规范化，推广我市村财审计的好做法好经验，扩大我市村财审计工作在全省、全国的影响力。市政府决定在全市推广汉阴县村级财务审计“34511” 工作法，现将有关要求通知如下：

一、加强组织领导，切实推进村财审计“全覆盖”。汉阴县村级财务审计的成功实践，不仅落实了“对公共资金、国有资产、国有资源、领导干部经济责任审计实现全覆盖”的新要求，还顺应了群众深入参与基层民主管理、扩大村务公开的新期待，有效破解了村级财务管理不规范、村干部经济违法违纪案件多发易发的老问题。各县区要充分认识推进村级财务审计“全覆盖”的重要意义，切实加强组织领导，加大督导检查力度，确保安排部署到位、监督指导到位、审计结果落实到位，确保今年5月底前全面实现村级财务审计首轮“全覆盖”目标，为助推全面建成小康社会和脱贫攻坚，建设西北生态经济强市做出应有贡献。

二、继续创新探索，着力打造村财审计“升级版”。各县区要认真学习村财审计“34511工作法”，通过村财审计解决一批群众反映强烈的问题，查处一批与民争利、损公肥私的违纪违法行为，建立一系列风险防范管理制度。同时，又要坚持标本兼治、纠建并举，大胆探索、锐意创新，注重经验总结，将工作实践提炼上升为理论制度，形成更加科学规范、更加易记实用的工作方法和操作规程，打造具有各县区鲜明特点的村财审计“升级版”。

三、加强宣传推广，不断提升村财审计“知名度”。各县区、各有关部门，尤其是各级审计机关要在扎实做好村财审计工作的同时，切实加大对外宣传力度，创新宣传方式，边走边“唱”搞好审计宣传，讲好审计故事，传播审计正能量，提升我市村财审计的影响力和知名度，为我市村财审计工作经验走向全省、推向全国奠定良好基础。
