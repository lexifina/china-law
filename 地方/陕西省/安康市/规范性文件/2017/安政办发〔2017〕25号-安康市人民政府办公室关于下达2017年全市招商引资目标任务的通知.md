# 安康市人民政府办公室关于下达2017年全市招商引资目标任务的通知

各县区人民政府，市政府各工作部门、直属机构：

为做好2017年全市招商引资工作，经市政府同意，确定2017年全市招商引资（省际）实际到位资金515亿元，现将目标任务下达给你们（见任务分解表），并就有关事项通知如下：

一、明确目标，夯实任务。各级各部门要高度重视招商引资工作，认真制定招商引资工作方案，强化工作措施，细化分解任务，促进工作落实。

二、强化责任，跟踪进度。各责任单位要落实责任，每月3日前将上月招商引资统计数据和统计分析报告报市招商局，由市招商局审核、汇总，并将综合分析情况上报市政府。

三、加强督查，严格考核。各责任单位要认真开展招商引资数据的统计核查。市招商局要加强督促检查，灵通信息，及时通报工作任务完成情况。招商引资目标任务完成情况纳入各单位年度目标考核内容，由市考核办从严考核。
