# 安康市人民政府办公室关于印发安康市富硒产业发展2017-2020年行动计划的通知

各县区人民政府，市政府各工作部门、直属机构：

《安康市富硒产业发展2017-2020年行动计划》已经市政府2017年第二次常务会议审定同意，现印发给你们，请认真遵照执行。

安康市人民政府办公室

2017年4月18日

安康市富硒产业发展2017-2020年行动计划

硒是人类必需的微量元素，具有抗氧化、抗衰老、提高机体免疫力、抑制肿瘤、修复细胞、拮抗重金属等多种有益功能。安康是中国最大天然富硒区，硒资源赋存条件好，生态环境优良，富硒产业已在全国具有一定影响力。为助推安康追赶超越、绿色崛起，建设中国富硒产业第一市，根据《安康市富硒产业总体规划（2017-2020年）》，特制定本行动计划。

一、总体要求

以党的十八大精神为指引，按照“五大发展理念”要求，大力发展富硒产业，推动安康追赶超越、绿色崛起。按照“三产引领、一产奠基、二产支撑”策略，推动全市富硒产业向科技创新、精深加工、一二三产融合发展，将安康建设成为全国著名的硒疗养生基地、全国最大的富硒产业聚集区和富硒产业标准化示范区，促进安康经济由产品经济向服务经济的转变、富硒农业向富硒产业的转变、工业文明向生态文明的转变，实现“以硒兴业”、“以硒富民”、“以硒兴城”，培育“世界硒源地”，打造“国际健康城”。

到2020年，富硒产业链产值达到2000亿元以上，其中富硒食品产业总产值达到1300亿元（其中富硒种养产值350亿元），富硒服务业产值达到700亿元以上。

二、建设任务

（一）做优做强富硒农业

依托富硒资源、优良生态，以建设集农业新技术研发、示范、推广于一体的现代农业示范园为引领，坚持品种优良化、生产标准化、规模化和营销品牌化，发展富硒茶、富硒魔芋、富硒畜牧、富硒水产、富硒林果、富硒粮油、富硒药材、富硒蚕桑、富硒食用菌等9大特色优势富硒农业。

1.富硒茶。完善富硒茶叶种植、加工标准化技术体系，强化品牌培育、精深加工，延长产业链条，推进一二三产融合。以“陕茶一号”为核心品种，以紫阳、平利、汉滨、岚皋为中心区域，建成标准化生态茶100万亩，建设现代富硒茶示范园100个（其中省级25个），建设集加工、品鉴、营销为一体的高档生态茶庄50个，实现综合产值 100亿元，建设中国特色优质功能农业-富硒茶示范基地，建设中国富硒茶叶第一市。（市林业局牵头，各县区负责）

2.富硒畜牧。围绕“特色品种、富硒饲料、无抗生素、种养循环、生态放养、绿色生态”六大核心要素，打造特色、富硒、生态、安全“安康富硒畜禽”品牌。突出生猪产业，推广“安康富硒猪肉”生产标准体系，强化阳晨牧业生猪联盟，建成生猪产业重点镇50个、重点村100个，出栏富硒特色猪300万头。建设现代畜牧示范园区100个（其中省级20个），培育产值亿元以上企业3-5家，上市公司1-2家。实现综合产值150亿元。（市农业局牵头，各县区负责）

3.富硒魔芋。夯实富硒魔芋标准化种植基础，以科技创新、龙头培育为重点，大力开展病害攻关、新品开发、标准制定、品牌打造、市场开拓等工作，占领行业制高点。建设魔芋主题公园，打造魔芋文化节，树立“世界魔芋看中国，富硒魔芋数安康”形象。建设现代富硒魔芋示范园10个（其中省级3个），优质魔芋种植基地50万亩，培育产值亿元以上加工企业3-5家，上市公司1-2家，实现综合产值50亿元。大力推广魔芋种植“安康模式”，打造中国魔芋第一市。（市农业局牵头，相关县区负责）

4.富硒水产。依托富硒、优质、丰富的水资源，以汉江鱼、娃娃鱼、金樽鱼、鸭嘴鱼为重点，强化地方珍稀特色品种繁育，加大精深开发，大力发展安康富硒精品水产。举办安康富硒鱼文化节、环保放鱼节、国际鱼拓大赛，推广“安康富硒鱼宴”，打造特色高端“安康富硒鱼”品牌。养殖水面22万亩，发展建设集垂钓、观赏、休闲为一体现代渔业示范园20个（其中省级5个），实现综合产值50亿元。（市水利局牵头，相关县区负责）

5.富硒林果。以富硒核桃、板栗为发展重点，紫阳金钱橘、旬阳狮头柑等特色林果为补充，突出科技创新、龙头培育、品牌建设、旅游融合重点，加强林果种植管理，提高产品加工技术含量、工艺水平，提高附加值。种植核桃200万亩、板栗120万亩，发展现代富硒林果示范园100个（其中省级10个），培育产值亿元以上加工企业2-5家，实现富硒林果综合产值50亿元。打造中国富硒林果第一市。（市林业局牵头，各县区负责）

6.富硒粮油。建设绿色、有机的高标准基本农田，突出优良品种、标准化种植、精深加工重点，大力发展安康富硒粮油。发展现代农业示范园10个（其中省级3个），建设优质富硒大米50万亩、富硒玉米100万亩，富硒土豆200万亩，富硒油料50万亩。（市农业局牵头，相关县区负责）

7.特色中药材。围绕杜仲、厚朴、银杏、葛根、绞股蓝、黄连、金银花等重点，推进中药材标准化、规范化建设，加强GAP、道地药材等认证，建设富硒药材与健康研发平台，开发富硒功能性食品、保健品及药品，延伸中药材产业链，促进安康大健康产业发展，建设“中国秦巴药谷”。发展杜仲、厚朴、银杏药材50万亩、草药种植50万亩，野生药材50万亩，发展现代中药示范园10个（其中省级3个），实现综合产值100亿元。（市食药局牵头，市农业局、市林业局、各县区负责）

8.富硒蚕桑。顺应市场需求，优化药用桑、果桑、蚕桑结构，强化多元化技术研发，加大精深综合开发力度，拓展桑、蚕、丝在食品、医药、化工、饲料和材料等领域的应用，延长产业链条，实现安康市现代蚕桑产业转型升级，建设丝绸之路上的“中国金蚕之乡”。建设标准化富硒桑园面积50万亩左右，发展现代蚕桑示范园5个（其中省级2个），实现综合产值50亿元。（市林业局牵头，相关县区负责）

9.富硒食用菌。围绕吸收、转化硒能力较强的香菇、木耳、蛹虫草等重点，实施标准化、规范化种植，推动农作物秸秆、枝条再利用，科学发展安康富硒食用菌。发展袋料菌10万袋，草腐菌10万平米，药用菌1000万平米，食用菌鲜品产量达5万吨。发展现代富硒食用菌示范园5个（其中省级2个）。（市科技局牵头，相关县区负责）

10.发展富硒体验观光农业。依托农村山水田园、农耕文化资源和现代农业，采取政府引导、农民主导、社会参与、市场运作的方式，融吃、住、行、游、购、娱六大要素于一体，建设休闲现农业园区50个、休闲农业观光示范村100个、体验农庄500个，中国美丽田园10处、全国休闲观光农业示范县3个，让外来游客在休闲体验中真正享受富硒食品、生态风光、健康服务。（市农业局牵头，各县区负责，市旅游局配合）

11.突出县域特色主导产业。围绕“一业为主，一主多辅”，推动县域特色富硒经济，形成功能定位差异化、互补化、规模化，共同促进全市富硒产业基地发展。紫阳县重点建设中国富硒茶之乡，岚皋县重点建设中国富硒魔芋之乡、平利县重点建设中国绞股蓝之乡、汉滨区重点建设中国富硒养殖之乡、汉阴县重点建设中国富硒米之乡、旬阳县重点建设中国拐枣之乡、白河县重点建设中国木瓜之乡、镇坪县重点建设中国黄连之乡、宁陕县重点建设中国大鲵之乡、石泉县重点建设中国金蚕之乡。（各县区负责）

（二）加快发展富硒加工业

12.建设中国最大的富硒产业聚集区。做好富硒工业规划布局，扩大招商引资，培育和壮大龙头企业，依托高新园区、飞地园区和十县区产业集群园区，通过富硒产业工业联盟，不断壮大富硒肥料饲料集群、富硒饮品集群、富硒生物提取物集群、富硒保健药品集群、富硒日化产业集群等，提高富硒工业集群规模效应，提高安康富硒工业综合实力。打造5-10家上市公司，50家以上年产值超过1亿元企业，实现富硒工业产值1000亿元。（市工信局负责，市商务局、市招商局、各县区负责）

13.建设国际富硒产业园。以制度创新为核心，以良好公共配套为基础，以高新技术为支撑，以“一带一路”缺硒国家为重点，以富硒功能性食品、富硒医药保健品和富硒日化开发为特色，瞄准国内外知名企业，引进高级人才、顶尖科技、先进设备，提高富硒工商企业管理水平，提高富硒产品品牌形象，提高国际贸易水平，建设安康富硒产品和“一带一路”国家特色产品贸易平台，推动安康市富硒产品及其服务出口产值过5-10亿元，打造中国富硒产业核心高新区。（高新区负责）

14.加大建设县区特色富硒工业园。突出特色优势、差异互补，建设汉滨区恒五富硒饲料、富硒肥料、富硒生物剂、富硒饮品和食品园区，汉阴县富硒功能性食品园区、紫阳县硒谷生态工业园区、岚皋县富硒魔芋产业园区、平利县富硒绞股蓝产业园区、白河县木瓜产业园区、旬阳县富硒功能性食品产业园区、镇坪县富硒功能食品产业园区、石泉县富硒蚕桑产业园区、宁陕县富硒冷水鱼产业园区。（各县区负责）

15.建设中国硒谷产业联盟平台。加大招商引资，引进大资本、建设大企业、大集团；整合资源、产品、品牌，组建由小到大、不同行业的中国硒谷产业联盟、富硒产业专业协会；按照“扶优、扶强”原则，倾斜国家项目投资、地方财政专项资金，积极培育现代化的富硒产业发展龙头，提高安康富硒产业竞争力，占领全国硒产品市场的制高点和话语权。培育5-10个上市公司，5个过50亿元产值企业联盟，10个过5亿元产值企业，20个超亿元产值企业。（市工信局牵头，市招商局、相关县区负责）

（三）大力发展特色现代服务业

强化三产“龙头”作用，深度融合富硒一二三产业，充分发挥三产的龙头带动作用，推动富硒产品经营方式由单一的“卖出去”变为“请人来、卖出去”两条腿走路。以硒疗养生综合体、硒疗养生小镇为抓手，发展养生养老、运动休闲、生态旅游等高端服务业，打造全国著名的硒疗养生基地。

16.建设硒疗养生综合体1号工程。以硒泉水源、富硒食品、优良生态为依托，以中医保健为手段，以硒疗养生康复为核心，以名胜景区为基地，引进北京301医院、协和医院、第四军医大等知名医疗科研机构派驻安康，建立“半小时到达”急救专线，打造10个以上集富硒水养生、富硒美食体验、富硒康体疗养、富硒文化传播、娱乐养生养老于一体的硒疗养生综合体，大力开展硒疗康复养生服务，真正让消费者体验到“到安康、送健康”。（市卫计局牵头，市旅游局、各县区负责）

17.打造安康硒品1号店。引入和选择10个（每县区一个）营销实力强大企业，由政府统一设计、授权、监管和补贴，建设安康富硒产品正品店，打造安康富硒产品高端知名富硒总部，搭建“中国硒谷·生态安康”富硒产品电商平台（淘宝/苏宁/京东等），销售安康市优质富硒产品，确保产品有检测、有认证、可追溯，打造真正意义上的正品店、形象店和综合店。（市供销社牵头，市商务局、各县区负责）

18.建设富硒产品交易中心和物流园。合理布局和建设专业交易市场、大型物流园区，完善物流集散的枢纽和物流网络的节点，完善交易市场设施，提高富硒产业物流质量与水平。在高新区和十县区建设10个专业交易市场、20个物流园区，50个特色农贸市场小镇。（市商务局牵头，各县区负责）

19.大力发展富硒产品仓储、物流业。合理、科学布局，发展20个具备现代企业制度和现代设施的大型仓储、物流业公司，建立健全覆盖产地预冷、产地冷藏、冷链运输、低温配送、冷链销售等安康富硒产品冷链物流体系，提高安康富硒产业物流、信息流的质量和水平。（市工信局牵头，市商务局、相关县区负责）

（四）实施科技创新战略

创新科技研发新模式、科技培训推广新方式、科技应用新机制，激发大众创新、万众创业积极性，大力推广富硒产业新技术，不断攻克富硒新产品开发关键技术，开拓富硒产品新功能，不断延长富硒产业链条，增强富硒产业核心竞争力，提高富硒资源利用率、产品附加值、劳动生产率和提高科技贡献率，在富硒科技研究与应用上打造名副其实的“世界硒源地，国际健康城”。

20.建设富硒科研创新平台。统筹整合安康科研资源，以国家级富硒食品实验室为核心，建立开放、共享的科研平台。通过与中国农业科学院、中国农业大学、北京中医药大学、西北农林科技大学、云南农业大学、安康学院等科研院校合作，联合国内外医疗机构，大力开展富硒产品及其服务的基础研究和应用技术研究，打造安康富硒产业发展“第一生产力”，打造中国富硒产业一流科技研发平台。（安康富硒产业研究中心负责）

21.建设富硒标准体系。围绕富硒产业的资源-肥料、饲料-农产品-食品、药品、化工品-富硒品服务等完整链条，依据最新硒研究成果，联合国内外专家，组织农业技术、食品加工、标准制订等方向的专门力量，有组织、有计划、有步骤、分门别类地推进富硒产品团体标准（企业标准）、大宗品种的国家标准和特色产业的行业标准的制定，为富硒产品标准化生产、科学检测、健康消费奠定扎实基础。（安康富硒产业研究中心牵头，市质监局、市农业局、市林业局、市水利局、市科技局、市工信局、市食药局负责）

22.打造国家级硒产品综合质检中心。加大资金、设备和人才投资，强化申报审批，以国家级富硒食品实验室为核心，以其他科研院所实验室为辅助，建设国家级硒产品综合质检中心，提高对大宗富硒产品权威检测的质量和数量。（安康富硒产业研究中心牵头，市财政局、市发改委、市人社局、市质监局负责）

（五）提升富硒产业文化软实力

加强安康市文化资源与硒相关文化的融合，以文化产业带动硒知识科普和安康市区域品牌提升，全面打造安康市富硒产业的软实力。

23.打造富硒文化“六个一”工程。挖掘富硒文化资源，结合现代人文精神、科研成果，突出硒文化主题，精心打造富硒文化“六个一”精品工程：即一部电影、一部电视剧、一部纪录片、一本专著、一个文化节、一个博物馆。通过有组织、有步骤、多手段、全方位的广泛宣传，提高安康人民硒文化知识水平，扩大安康富硒文化的影响力。（市文广局牵头负责）

24.强化安康富硒文化传播。开通“国际健康城”网站专栏、微信、微博公众账号，定期推送安康富硒健康养生、休闲旅游、新闻动态、企业家创业等内容。收集、整理、播放与安康富硒产业有关的视频资料，用真人、真事、真体验，激发国内外对安康富硒产品及其服务的关注热情，大力宣传特色富硒产业和安康市形象。（市发展研究中心牵头，各县区负责）

25.举办安康富硒美食文化节。实施富硒“名店、名菜、名街、名师”工程，积极申报富硒“名小食”非物质文化遗产。结合安康龙舟节，每年举行一次富硒美食文化节活动，展示、展销与品尝各区县特色富硒小吃，开展富硒“十佳菜肴”、“十大特色小吃”评奖活动；举办美食厨艺大赛、美食试吃吉尼斯、美食体验工坊等活动；开设富硒养生讲堂（论坛），推广和传播补硒膳食、硒疗康复文化。（汉滨区牵头，各县负责）

26.加大富硒产品及服务的推介力度。积极参加全国性农高会、博览会、展销会、运动会，在大中城市、缺硒地城市开设安康富硒产品实体店，面对面推介、展销安康富硒产品。在北京等大城市召开富硒产业相关新闻发布会，推介安康新型优质富硒产品及其服务，宣传富硒产业核心关键技术成就和富硒产业发展成功经验，扩大安康富硒产业在国内外的影响力。（市商务局牵头，各县区负责）

27.实施知名品牌策略。积极申请国家级特色农产品产品示范基地、国家地理标志保护产品、无公害、绿色、有机、GAP、MAP、ISO9001 等认证。积极申请专利保护，积极注册商标，大力开展创建著名商标、驰名商标活动。鼓励和扶持企业创建知名品牌，举办知名品牌授牌仪式，有组织地在中央媒体、现代媒体上加大知名品牌、明星企业的宣传力度，提升安康富硒产业发展的知名度、影响力。（市质监局牵头，市工商局、市科技局、各县区负责）

三、强化保障措施

28.加强领导。成立由市长任组长、分管领导任副组长、相关部门负责人为成员的富硒产业发展协调领导小组，设立富硒产业发展协调办公室（富硒办），负责对全市富硒产业发展工作的安排、协调、检查、督促、考核和表彰。各区（县）成立相应的领导机构。（市政府办牵头，各县区负责）

29.强化监管。加强富硒基地、产品、企业等各种认证工作，加大商标、品牌和专利保护，完善登记、备案、发标工作的机制体制，严厉打击假冒伪劣等违法侵权行为，净化富硒产业交易市场，促进安康富硒产业发展再上新台阶。（市工商局牵头，市质监局、市食药局、各县区负责）

30.完善政策。全面深化改革，加快制定富硒产业相关配套政策，激活土地、人才、资本、技术等生产要素，降低富硒产业企业行政成本、融资成本、税费负担，妥善处理和保障各方利益关系，促进安康富硒产业稳健发展。（市发展研究中心牵头，各县区负责）

31.加大投资。加大中省项目争取、招商引资、金融扶持力度，增加财政专项资金、基金和补贴。每年建设100个、投资100亿以上的富硒产业重大建设项目，奋力增加富硒产业固定资产投资，改善富硒产业发展的基础条件，提升富硒产业发展的质量与水平。（市发改委牵头，市财政局、市招商局、市金融办负责）

32.优化环境。加大“放管服”改革步伐，转变政府职能，提高政务效能、公信力。严厉打击阻扰、破坏富硒产业发展的行为，大力鼓励、宣传、表彰促进安康富硒产业发展的先进典型，在全社会形成共同促进安康富硒产业发展的良好环境。（市政府督查室牵头，市文广局、市公安局负责）
