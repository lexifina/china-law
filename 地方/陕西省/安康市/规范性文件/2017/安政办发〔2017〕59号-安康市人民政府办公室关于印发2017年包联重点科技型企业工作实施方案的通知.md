# 安康市人民政府办公室关于印发2017年包联重点科技型企业工作实施方案的通知

各县区人民政府，市政府有关工作部门：

《2017年包联重点科技型企业工作实施方案》已经市政府审定同意，现印发给你们，请认真组织实施。

安康市人民政府办公室

2017年5月17日

安康市2017年包联重点科技型企业工作实施方案

为认真贯彻落实中省市关于实施创新驱动发展战略的决策部署，切实提升企业创新能力，营造全社会重视科技、关注创新、服务企业的良好氛围，按照《安康市人民政府关于推进科技创新实施创新驱动发展的意见》（安政发〔2016〕13 号）和《安康市人民政府办公室关于印发安康市企业创新工程实施方案的通知》（安政办发〔2016〕37 号）要求，结合我市科技企业发展实际，特制定本实施方案。

一、指导思想

以科学发展观为指导，深入贯彻市第四次党代会、市“两会”、全市追赶超越和科技创新工作会议精神，紧紧围绕创新驱动发展，深化科技体制改革，促进企业技术创新、产品创新、管理创新和商业模式创新等，加快培育一批科技创新示范企业和科技型“小巨人”企业，为加快建设西北生态经济强市提供有力支撑。

二、主要内容

（一）包联对象。研发能力强、发展基础好、市场潜力大的50户重点科技型企业。

（二）包联单位。市包联重点科技企业工作领导小组成员单位，每个单位对应包联 1 户科技企业（详见附表）。

（三）包联目标。实行“一企一策”和定制化联系帮扶，支持企业与国内高校、科研院所、研发机构等联合建立一批高水平的实验室、工程中心等，以企业为主体实施一批产业创新重大项目，推进科技政策、科技项目、科技人才、科研平台等创新资源向企业聚集，力争利用三年时间，在全市培育科技创新示范企业10户、科技型小巨人企业40户。

（四）包联职责。侧重从以下十个方面入手，切实加大对重点科技企业的引导和扶持。

1.指导企业做好项目申报，帮助多渠道争取项目资金。用足用好中、省、市支持企业发展的各项政策措施，指导企业提高项目申报质量，多渠道争取项目资金。对纳入科技创新示范企业创建名单的10户企业，2017年度争取项目资金不得低于100万元；纳入科技型“小巨人”企业创建名单的企业，2017年度争取项目资金不得低于50万元；指导企业申报各类科研项目1项以上；申报科技成果1项或申报专利2项以上。

2.指导企业组建研发平台，加强产学研合作。通过深入企业广泛征集技术需求和技术难题，推动企业与国内相关领域高校、科研院所开展产学研合作，指导企业自建或与高校院所联合共建重点实验室、工程技术研究中心或技术创新联盟等研发平台。对于已经组建研发平台的企业要立足企业自主创新，面向行业开展技术服务。

3.指导企业加强自主创新，大力开发“杀手锏”产品。鼓励企业与高校院所建立完善产学研协同创新机制，通过实施以企业为主导的科技专项和产业化项目，突破一批具有行业领先水平的核心技术，形成一批具有自主知识产权和竞争优势的重大创新产品，带动产业链上下游企业配套协作。2017年指导企业开发新产品1项，研发新技术2项，开展工艺技术改造和提升2-3项。

4.帮助企业引进专业人才，加强创新人才队伍建设。通过建立专家大院、博士后工作站、申请选派首席工程师、科技特派员等方式，选聘1-2名专家、教授进驻企业开展技术服务，多渠道帮助企业引进专业技术人才。

5.协调解决科技型企业发展资金瓶颈。对生产经营周转资金短缺的企业，要在帮助企业加速资金周转的同时，积极协调金融部门、融资担保机构、投资公司，帮助企业解决融资难问题。

6.指导企业加强和完善内部经营管理。以培养和引进企业人才、完善现代企业制度等为抓手，利用各种渠道和方式，采取切实有效措施，帮助企业提高经营管理水平。

7.帮助开展品牌设计与策划，实施品牌培育。组织专业服务机构，帮助企业制定发展战略、市场营销战略、技术发展路线图，促进企业利用互联网技术平台创新商业模式，占据价值链高端。组织科技型中小企业与重大项目、工程配套对接，做大规模和品牌，提高行业影响力和市场知名度。积极指导企业申报“地理标志保护产品”或“陕西省名牌产品”、 “安康市特色品牌产品”、“中国驰名商标”、“地理标志证明商标或集体商标”及“陕西省著名商标”，提高品牌保护意识。

8.帮助企业解决生产要素保障。对因电力、原材料、天然气等关键要素制约正常生产和项目建设的，积极协调推进解决，帮助企业破解制约，正常生产建设。

9.帮助企业积极开拓市场。帮助企业在引进营销人才、创新营销思路、拓展营销渠道、完善营销机制、改善营销手段、提升市场占有率等方面取得重大突破。

10.帮助企业实现招技引资目标。帮助企业寻找战略合作伙伴，引进战略投资者，实现高校、科研院所重大科技成果在企业转移转化，推动企业做大做强。

三、工作要求

(一)提高认识，明确责任。各帮扶单位要结合联系企业实际，按照帮扶工作要求，厘清工作思路，细化工作方案，明确工作重点，夯实工作责任，建立工作台账，开展动态管理，确保措施有落实，推进有力度，帮扶有成效。

(二)深入调研，建立帮扶台账。对包联企业就技术创新、高新技术企业培育、人才引进培养、商业模式创新、并购重组、上市融资等方面开展实地调研，了解企业发展的瓶颈和制约因素，实行一企一策，开展有针对性的帮扶。

(三)精心组织，统筹协调。市包联办公室要开展定期走访，做好跟踪服务。各包联单位之间要搞好衔接配合、互通情况、及时沟通，形成合力。每季度末，各包联部门要将工作进展情况以书面形式上报领导小组办公室。对单靠一个部门难以解决的问题，领导小组办公室要积极做好组织、协调工作。各县区科技工作部门应积极参与、密切配合、上下联动，确保帮扶工作扎实开展。

(四)强化纪律，务求实效。包联单位要按照“帮扶不包办、参与不干预、帮忙不添乱”的原则，切实解决企业研发和技术创新中的实际问题，防止走过场和搞形式，全力推动企业转型发展。要严明工作纪律，不得干预企业正常生产经营及其他内部事务，不得在企业吃喝和报销、摊派任何费用。每年年终对帮扶工作进行总结，对工作不力的包联单位将通报批评和责任追究，对成绩突出的包联单位予以表彰奖励。

(五)完善机制，加强督查。领导小组办公室将按照“滚动实施、优胜劣汰、动态管理”的原则，采取“月报季查、半年通报、年终考核公告”的方式，对入选企业加强工作指导，及时提供服务，实施检查评估。对评价优秀的企业加大支持力度，对于评估不合格的企业取消相应称号，按照程序再递补新的企业。各县区、各包联单位要结合部门职能，统筹各类资源，创新工作方法，确保年度帮扶目标任务完成，为加快科技创新促进民营经济转型升级作出积极贡献。

四、保障措施

(一)加强组织领导。市政府成立由分管副市长任组长，市发改委、市财政局、市工信局、市招商局、市工商局、市国税局、市供电局等 50 个包帮市直部门和中省驻安单位主要领导为成员的市包联重点科技企业工作领导小组，领导小组办公室设在市科技局，科技局局长兼任办公室主任，办公室具体负责收集、整理企业发展中遇到的困难和问题，及时跟踪部门帮扶工作进展情况，向市包联重点科技企业工作领导小组报告。

(二)强化联席会议制度。建立定期联席会议机制，联席会议原则上每季度召开一次，由领导小组办公室负责组织。重点听取包联工作情况汇报，总结帮扶工作经验，研究和落实帮扶工作措施，协调解决具体问题。

(三)强化目标责任考核。将包联重点科技企业工作纳入市政府对部门和中省驻安单位的年度目标责任考核内容，由市考核办进行年度考核。包联重点科技企业考核实施细则由市考核办会同市科技局另行制定。市政府督查室负责对包联重点科技企业工作落实情况进行跟踪督查。
