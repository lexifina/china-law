# 安康市人民政府办公室关于印发《安康市涉水产业发展行动计划（2017-2020年）》的通知

各县区人民政府，市政府各工作部门、直属机构：

《安康市涉水产业发展行动计划（2017-2020年）》已经市政府2017年第六次常务会议审定同意，现印发给你们，请认真贯彻执行。

安康市人民政府办公室

2017年7月4日

安康市涉水产业发展行动计划

（2017-2020年）

为全面贯彻落实市政府《关于大力发展涉水产业的意见》（安政发〔2012〕32号）和《安康市涉水产业总体发展规划（2013－2020年）》（安政发〔2014〕23号）总体部署和要求，立足安康生态优势，走民生为本的循环发展之路，全力打造全市生态友好型产业新的增长极，实现经济社会与资源环境和谐发展，形成“水养人、人养水”的良性循环，加快建设西北生态经济强市，特制定本行动计划。

一、产业概况

我市涉水产业包括饮用水（饮品）制造、亲水旅游、生态渔业、水电能源、汉江航运等主要产业。截至2016年底，全市已建成饮用水（饮品）生产企业22户，年设计产能178万吨，营业收入过亿元企业7户。瓶（桶）装饮用水企业基本形成了高、中、低三个档次，可以满足不同消费群体需求，“真硒水”已成为陕西绿色新名片；亲水旅游已形成集河道漂流、体育赛事、休闲度假、娱乐观光于一体的发展大格局，并成功打造了瀛湖文化旅游产业基地、汉水龙舟文化园等亲水旅游品牌；生态渔业除发展养殖外，还着力构建种苗繁育、水产加工、储运销售、休闲旅游等一、二、三产协调共进的新型生态渔业发展体系；水电能源以汉江干支流水电站开发为重点，现已建成石泉、喜河、安康、蜀河4座电站，总装机152.75万千瓦，小水电总装机达60多万千瓦。2016年，全市涉水产业实现产值140亿元。以饮用水（饮品）制造业、亲水旅游、生态渔业、水电能源为重点的涉水产业在全市经济发展中发挥着重要作用。

二、总体思路和发展目标

（一）总体思路

以创新、协调、绿色、开放、共享的发展理念为指引，以“追赶超越、绿色崛起”为主线，以产业政策为引导，以市场需求为导向，按照“产业园区承载、重大项目引领、龙头企业培育、知名品牌创建”的思路，在加强水体、水景、水质保护的前提下，创新管理，优化环境，完善服务，推动涉水产业标准化、专业化、集约化发展。力争通过3至4年的开发和发展，使涉水产业在全市经济发展中发挥更加重要的支撑作用。

（二）发展目标

按照市场化开发、品牌化建设、集群化发展的思路，通过四年努力，培育1－2户年产值过10亿元的龙头企业、2－3户年产值过5亿元的龙头企业、10－15户年产值过亿元的企业，培育5-10个名牌产品，涉水产业水平提升、发展提速、比重提高、结构优化，产业集群显现，规模化发展取得突破。

到2020年底，全市饮用水（饮品）制造业年设计产能达到220万吨（制造产能180万吨），实现产值150亿元，年均增长35%以上，新增年产值过亿元企业6户；亲水旅游收入120亿元，年均增长20%以上，综合收入过亿元企业4户；生态渔业总产值30 亿元，年增长10%左右，新增年产值过亿元企业3户；水电能源产值30亿元，增长10%以上，新增年产值过亿元企业2户。

三、发展重点

重点发展饮用水（饮品）制造业、亲水旅游，稳步推进生态渔业、水电能源发展，逐步启动汉江航运等相关产业。努力构筑特色明显、综合竞争力强的涉水产业空间布局，把涉水产业培育成为我市支柱产业。

（一）饮用水（饮品）制造

1.加快发展瓶（桶）装饮用水。加大招商引资力度，吸引国内外知名品牌入驻安康，全力打造安全健康天然富硒水品牌；鼓励紫阳县、旬阳县、岚皋县等有条件的饮用水（饮品）制造企业整合资源、兼并重组，推动饮用水制造业向规模化、优质化、功能化发展。石泉县、紫阳县重点发展天然矿泉水项目；汉滨区、岚皋县、旬阳县重点发展包装饮用水项目；平利县重点发展其他饮用水项目。支持紫阳县“真硒水”打造“中国健康第一水品牌”；推进岚皋县30万吨天然富硒山泉水开发、紫阳县年产20万吨山泉水生产线、旬阳县年产40万吨天然饮用水建成投产。

2.突破发展富硒功能饮料。紫阳县、平利县发展富硒茶饮料、绞股蓝功能饮料；白河县、旬阳县、镇坪县、汉阴县以木瓜、拐枣、五味子、猕猴桃、莲藕以及具有保健功能的中草药等为原料，生产富硒保健功能性饮料和特色饮品，寻求避开常规饮料占领市场制高点的有效途径。汉滨区、旬阳县、紫阳县重点发展功能饮料，鼓励安康正森食品、旬阳太极缘等重点企业加大科研投入，开发健康产品，扩大市场销售；力促汉阴福田系列饮品生产项目、荣氏食品加工基地等在建项目尽快达产达效。

3.积极发展以果酒为主的其他酒类制造业。旬阳、白河、宁陕、镇坪等县充分利用拐枣、木瓜、五味子、猕猴桃等生物资源，加大研发力度、完善生产工艺、提升产品质量，做优富硒果酒，同时做大做强泸康系列白酒和保健酒等酒类制造业。

（饮用水（饮品）制造业由市工信局牵头，相关县区实施，市级相关部门配合）

（二）亲水旅游

1.构建亲水旅游空间格局。沿汉江安康段340公里水道，打造“七百里汉江生态画廊”，布局“一主四副”的空间格局。即以瀛湖为核心聚集区，建设月河川道亲水旅游休闲聚集区、石泉汉水风光游览聚集区、紫阳茶歌山水文化聚集区、旬阳太极城文化旅游聚集区。同时，加快建设石泉县城至宁陕广货街秦岭山水亲水旅游带、汉滨县河至平利龙头田园风光亲水旅游带、岚皋佐龙至镇坪曙河“巴山画廊”亲水旅游带。

2.建设亲水旅游重点景区。加快实施安康瀛湖旅游产业基地、汉滨双龙生态旅游景区二期，石泉汉江印象、后柳水乡、雁山瀑布，紫阳滨江长廊、任河漂流景区，汉阴凤堰古梯田水景，岚皋神河源千层河景区，平利芍药谷，旬阳太极城水景、蜀河古镇，白河桥儿沟、红石河，镇坪飞渡峡景区二期、代安河等重点景区建设，提升全市涉水旅游景区旅游品质。

3.打造亲水旅游精品线路。构建亲水旅游板块，策划精品亲水旅游线路，借力西安国际一流旅游目的地建设，补充西安亲水旅游之不足，以涉水体验活动为主导，吸引国内外游客，特别是“三北”地区游客从西安出发，通过瀛湖亲水旅游的主核心聚集区及其它四个副核心区集散，穿越“七百里汉江画廊”，游览“四条亲水旅游产业带”；通过水岸观光、滨水度假、水上漂流、水上娱乐、水上运动、水下体验和水体养生等亲水体验活动，培养游客对安康亲水旅游的兴趣和感情，支撑精品线路的生命活力。

4.加快亲水旅游产品开发。沿江、沿河建设度假山庄、休闲会所等休闲度假村，开发江边垂钓、江河游览、过江索道等亲水体育旅游产品；修建自驾营地、露营野餐、汽车旅馆等江边临建设施，开发夏季江边浴场、水上避暑乐园项目；在江河水流落差大地段开发峡谷漂流项目；在汉江水面开阔区域开设豪华游船、水上滑翔、水上摩托等游乐设施；持续举办安康汉江龙舟节、美食文化节、安康峡谷漂流旅游季等节庆活动；依托旅游村，积极推出“住渔家、品鱼宴、聊鱼事、享渔乐”等渔家乐亲水旅游产品；依托水产养殖，开发各类旅游小商品、旅游纪念品，丰富旅游产品种类。

（亲水旅游由市旅游局牵头，有关县区实施，市级相关部门配合）

（三）生态渔业

1.科学开发特色养殖。突出生态养殖和休闲渔业，调整渔业结构，减少大水面投食性鱼类比例、增加滤食性鱼类比例，确保水质不受污染。川道地区大力发展水库池塘养鱼和稻田养鱼，充分利用现有具备养殖条件的100 余座中小型水库、近万口池塘，扩张规模，加强管理，提升效益。中高山地区主攻冷水鱼养殖，重点发展大鲵、钱鱼、金鳟、虹鳟等特色冷水鱼。

2.加快建设种苗产业基地。大力开展良种繁育，在发展花鲢、白鲢、大鲵、钱鱼等本地品种的基础上，研究和制定养殖标准、生产标准和富硒标准。到2020 年末，全市鱼种繁育能力达到20 亿尾/年。

3.全力打造“安康富硒鱼”公用品牌。 大力推进生产标准化，加快制定和完善渔业生态化养殖标准，加快开展水产品“三品一标”认证，积极创建“瀛湖花鲢”和“大鲵”地理标志产品，全力打造“安康富硒鱼”公用品牌。增强网上销售、在线监测、手机APP等现代化手段在渔业生产管理、经营中的推广应用，推动“互联网+生态渔业”发展。

4.大力发展休闲渔业。将渔业资源、旅游资源和生态资源等进行优化配置，用加工业带动养殖、旅游业，使旅游观光、休闲娱乐、餐饮、科普等与渔业有机结合，再以渔业养殖基地为依托，大力发展集休闲垂钓区、渔民生活体验区、汉水河鲜美食长廊、水产品购物等形式的渔家乐，形成独具特色的风格和品牌。

（生态渔业由市水利局牵头，有关县区实施，市级相关部门配合）

（四）水电能源和汉江航运

1.水电能源。巩固发展汉江干流水电能源，积极推进旬阳、白河水电站建设；严格管控，科学开发小水电建设。

（市发改委牵头，相关各县区政府实施、市级相关部门配合）

2.汉江航运。结合汉江梯级电站建设，完成旬阳、白河枢纽通航建筑物建设；启动石泉、蜀河、喜河枢纽过坝和安康枢纽通航建筑物维护改造建设；实施安康枢纽下航道整治工程，实现汉江至长江间的干支直达运输。

（市交通局牵头，汉滨区、石泉县、旬阳县、白河县政府实施，市级相关部门配合）

四、主要任务

（一）突出优势，优化布局。优化产业空间布局，构筑安康涉水产业“一核一廊多点支撑”(一核：由主城区、高新区、恒口示范区和瀛湖生态旅游区形成的产业发展核心区；一廊：头起石泉，尾至白河，北达汉阴，南到岚皋的产业发展中心走廊；多点支撑：以秦岭汉江支流为依托，保护性开发大鲵、虹鳟等冷水鱼养殖，东南部以岚河、黄洋河、南江河等汉江支流为依托，重点开发生态养生旅游区，东部突出发展以绞股蓝、木瓜等生物资源为主的富硒功能饮料产业)的空间架构。

（二）延伸链条，调整结构。饮用水（饮品）制造、亲水旅游、生态渔业按照资源集约利用、骨干品牌突出、龙头企业带动、服务体系完善的思路，全力推进涉水产业供给侧结构调整。在汉滨、紫阳、旬阳等地率先推广产业集群示范试点，增强配套功能，加快包装、物流等相关产业发展；加强专业分工协作，整合品牌、市场、技术等资源，发展一批上规模、上水平的饮用水企业，培育形成以骨干企业为龙头、小微型企业为补充，配套检验检测、包装印刷、人才培训、科技开发、产品设计、物流建设、融资平台等多项生产性服务业企业，打造研发中心、标准中心、检测中心、集散中心，推动涉水产业结构进一步优化。

（三）强化质量，保障安全。统筹市场监管等部门力量，建立健全饮用水（饮品）制造和生态渔业质量服务体系、亲水旅游和水电能源安全保障体系，以物联网、移动互联网等现代信息技术为支撑，建立原料、生产、包装、物流、终端销售全产业链的产品质量溯源体系，强化企业饮（食）品质量与安全保障主体责任，督促企业完善检测设备，强化生产过程动态监测、产品出厂检测，形成涉水产业质量与安全保障机制。

（四）加大宣传，打造品牌。实施品牌战略，持续加大宣传营销力度。饮用水（饮品）制造以富硒矿泉水，红茶、绿茶和绞股蓝饮料为突破口，通过引进国内外知名品牌或取得著名品牌使用权，推动涉水产业标准化、专业化、集约化发展；生态渔业以龙泉冷冻分割大鲵肉、五福鲜鱼类系列产品等品牌为依托，开发多品种、小包装、便携带的产品，积极申报“瀛湖花鲢”地理标志产品，全力打造“安康富硒鱼”公用品牌；亲水旅游更加注重增强旅游的娱乐性，继续办好“中国安康汉江龙舟节”，把涉水产业品牌建设与文化品牌建设有机统一起来，以品牌彰显城市形象，以城市影响力提升涉水产业竞争力。

五、保障措施

（一）加强组织领导。市上建立涉水产业联席会议制度，形成“政府主导、发改牵头、部门配合、社会参与”的工作机制。各县区建立相应机制，坚持规划引领，强化统筹协调，完善配套政策，加强考核奖惩，认真研究解决涉水产业发展中的实际问题，凝聚推进涉水产业健康发展的强大合力。

（二）强化资源支撑。林业部门要加强水源保护区的退耕还林，天然林建设和保护，减少水土流失、涵养水源；农业部门要加强农村面源污染控制，重点减少农药、化肥的使用量；水利部门要强化水功能区综合治理，严格审查水域纳污能力，减少排污总量；环保部门要加强水质监测监管能力建设，确保水质安全。强化环保、质监、工商、渔政等部门执法工作，严打危害涉水产业及水域安全的违法行为，维护涉水产业正常的生产经营秩序。

（三）加大招商引资。建立市、县、园区协调招商机制，组织开展招商、推介，积极吸引相关领域龙头企业、国内外大集团来安合作、开发。抢抓中省加大脱贫攻坚、对口协作、资源保护以及促进旅游业、健康服务业、养老产业发展等机遇，积极争取中省资金投入、项目布局等多方面支持。

（四）落实资金保障。充分利用国家专项建设基金和我市产业发展基金解决企业融资难的问题。拓展中小型企业信贷风险补偿金覆盖范围，探索设立企业信用贷款风险补偿金。市财政从产业发展专项基金中给予资金支持。鼓励采用私募股权投资基金（PE）、创业投资基金（VC）、天使投资基金、信托贷款、租赁、保理等多种融资方式，培育和扶植一批企业上市融资。

（五）发挥协会作用。根据行业特点，积极组建饮用水（饮品）制造业、亲水旅游业和生态渔业行业协会，通过提供政策咨询、制定行业标准、开展行业研究、加强行业自律、服务企业发展，促进涉水产业健康发展。
