# 安康市人民政府办公室关于市政府秘书长副秘书长及办公室领导分工的通知

各县区人民政府，市政府各工作部门、直属机构：

现将市政府秘书长、副秘书长等同志工作分工通知如下。

陈伍文（市政府秘书长）：协助市长、常务副市长处理市政府日常工作，受市长、常务副市长委托处理应急事项。协助分管市信访局、发展研究中心、驻外办事机构。负责市政府办公室全面工作。联系徐启方同志及分管方面工作。分管市政府办公室秘书科、综合一科。

王龙军（市政府副秘书长、市政府办公室主任）：负责市政府办公室日常工作。负责市政府办公室“双创”工作。负责协调与市人大、市政协工作联系。联系赵俊民同志及分管方面工作。分管市政府办公室政办科、机关党委、机关工会、信息科、综合二科；联系市机关事务管理局工作。

赵德成（市政府副秘书长、市政府法制办公室主任）：负责市政府法制办公室工作。联系孙矿玲同志及分管方面工作。分管市政府办公室综合八科。

马 霞（市政府副秘书长、市信访局局长）：负责市信访局工作。负责市政府机关非正常上访处置工作。联系杨尚伟同志及分管方面工作。分管市政府办公室综合四科。

刘福全（市政府副秘书长、市政务服务中心主任）：负责市政务服务中心工作。联系何邦军同志及分管方面工作。分管市政府办公室综合三科。

贺兆华（市政府副秘书长〔挂职〕）：联系尹清辽同志及分管方面工作。分管市应急办、市政府办公室综合六科。

阮家军（市政府办公室党组成员、市政府督查室主任）：负责市政府督查室工作。负责市政府办公室精准扶贫帮扶工作。联系鲁琦同志及分管方面工作。分管市政府办公室综合七科。

朱小敏（市政府办公室党组成员、纪检组长）：负责市政府办公室纪检监察工作。分管市政府办公室监察室。

周功耀（市政府机关事务管理局局长）：负责市机关事务管理局工作。负责市政府办公室“双创”日常工作、中心城区周边绿化帮扶工作。

杨克山（市政府法制办公室副主任）：负责市政府法制办公室日常工作。协助王龙军同志联系赵俊民同志及分管方面工作。协助分管市政府办公室综合二科。

张爱萍（市政府督查室副县级督查专员）：负责市政府督查室日常工作。负责市政府督查专项工作。

张 涛（市金融工作办公室主任）：负责市金融办工作。联系蒋清海同志及分管方面工作。分管市政府办公室综合五科。

谢 奎（市应急办主任）：负责市应急办工作。负责市政府重要文件、主要领导相关材料的组织起草和审核把关工作。协助陈伍文同志联系徐启方同志及分管方面工作。分管市政府办公室机要科。协助分管市政府办公室秘书科、综合一科。

安康市人民政府办公室

2017年1月25日
