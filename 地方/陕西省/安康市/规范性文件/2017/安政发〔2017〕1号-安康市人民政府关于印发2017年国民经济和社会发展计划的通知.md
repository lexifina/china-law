# 安康市人民政府关于印发2017年国民经济和社会发展计划的通知

各县区人民政府，市政府各工作部门、直属机构：

《安康市2017年国民经济和社会发展计划》已经市四届人大一次会议审议批准，现予印发，请遵照执行。

2017年各项具体计划，由市发展改革委及有关部门组织下达实施。

安康市人民政府

2017年3月9日

安康市2017年国民经济和社会发展计划

一、经济社会发展的总体要求

以“四个全面”战略布局和“五大发展”理念为引领，全面贯彻中央经济工作会议、省委十二届十一次全会、市第四次党代会和四届人大一次会议精神，以“追赶超越、绿色崛起”为主线，以提高发展质量和效益为中心，坚持创新驱动、开放引领、绿色循环、民生优先、协调发展，突出供给侧结构性改革，突出稳增长调结构，突出新经济新动能，突出惠民生促和谐，努力补齐经济发展短板，保持经济平稳较快增长，加快建设西北生态经济强市。

二、经济社会发展的主要预期目标

生产总值增长10.5%，规模工业增加值增长15%，全社会固定资产投资增长16.5%，社会消费品零售总额增长13.5%，城乡居民收入分别增长9%和10%，财政总收入和一般预算收入分别增长3%和6%，城镇登记失业率控制在3.9%以内，万元GDP能耗下降3.1%，CPI涨幅控制在2%以内，303个贫困村15.7万贫困人口实现脱贫。

三、经济社会发展的主要任务

（一）深化供给侧改革，培育经济增长新动能。坚持创新引领发展，实施业态创新、产品创新、服务创新、技术创新、商业模式创新，提升有效供给能力。实施“互联网+”行动计划，务实推进与上海复星、阿里巴巴、中兴、太极等企业合作，支持天贸城二期、天一城市广场、汉城国际商业街、高新金融服务聚集区等项目加快推进。深化与友好城市、高等院校、科研机构的战略合作，建立产业技术创新战略联盟和研发中心。协同推进汉江生态经济带建设，主动融入丝绸之路经济带和长江经济带。深入推进“三去一降一补”，贯彻落实工业稳增长措施，综合施策降低企业成本；坚持去库存与移民搬迁、促进人口城镇化有机结合，积极消化房地产库存。深化“放管服”改革，实行网上并联审批，建成运行市级公共资源交易中心。

（二）突出重大项目建设，着力扩大有效投资。完善扩大有效投资的考核激励机制，着力增强投资的有效性。实施“千亿投资”工程，完成全社会固定资产投资1080亿元，增长16.5%。抓实220个市级重点建设项目，完成年度投资350亿元，其中：续建项目104个，年度投资256亿元；新建项目116个，年度投资94亿元。抢抓中省政策机遇，发挥政府投资引导作用，吸引民间投资进入电力、电信、交通、市政等领域，全年争取新开工PPP项目15个。完成民间投资490亿元，增长18%。重点推进100个前期工作项目，争取开工7个。进一步优化投资环境，加强社会诚信体系建设，深入实施开放发展行动计划，全年招商引资到位资金500亿元。

（三）扎实推进精准扶贫，打好脱贫攻坚战。全面实施“十三五”脱贫攻坚规划，按照“四个切实”、“七个一批”和“六个精准”要求，瞄准建档立卡贫困人口，突出抓好产业扶贫和移民搬迁，做到经营主体、资金支持、政策保障、结对帮扶“四个全覆盖”，全年减少贫困村303个，脱贫15.7万人。实施好国家政策性金融扶贫试验示范区建设，5个金融扶贫试点县区投放金融扶贫贷款5亿元。加大教育扶贫力度，实现贫困家庭子女接受中高职教育和贫困大学生资助全覆盖。开展农民实用技术培训10万人次。发放扶贫小额贴息贷款2.5亿元。实施土地治理3万亩。规划建设避灾扶贫搬迁集中安置社区290个，完成避灾扶贫移民搬迁6.3万户17.8万人。

（四）培育壮大新型工业，构建循环产业体系。做大总量、盘活存量、扩大增量，全年实现规模工业增加值410亿元。加快127个重点产业项目建设，确保旬阳烟厂技改一期、高新钒氮合金二期和大运富硒食品等20个工业项目建成投产，力促30个工业项目开工。实施富硒产业发展行动计划，以茶叶、魔芋、包装饮用水、生猪等产业为重点，每个产业培育2-3户龙头企业、一批新型经营主体和专业技术人员，延伸产业链条，提升产品价值，增强核心竞争力，打造一批知名品牌。切实发挥安康高新区、旬阳高新区示范引领和汉滨区龙头带头作用，努力在经济增长、财税收入、进出口等方面提高对全市的贡献率。加快“飞地经济园区”基础设施配套，全年完成投资2亿元，争取10户企业落地建设和建成投产。建设县域工业集中区标准化厂房15万平方米，新增投资千万元入园工业企业45户。全年培育40户规模工业企业和10户产值过5亿元企业。

（五）做优特色高效农业，促进农业增收增效。深入推进农业供给侧结构性改革，狠抓农产品标准化生产、品牌创建和质量安全监管，推动与二产、三产融合发展。全年计划粮食总产80万吨、油料13万吨、肉类27万吨、水产品4万吨、茶叶2.7万吨。大力实施现代农业园区“五个一”提质增效工程，加快建设生态优质高效畜牧、茶叶、魔芋、烤烟等主导产业基地，新增省级现代农业园区3个、市级园区10个。深化与中国农科院院地合作，推动富硒茶、富硒魔芋和富硒猪肉生产标准上升为国家标准。创建山林经济示范县2个、示范镇10个、示范村20个，创建市级山林经济园区30个。培育家庭农场50个、新型职业农民1000人。

（六）提升生态旅游品质，力促现代服务业发展。加快旅游产品全域统筹、线路全域整合、品牌全域营销、环境全域优化，打造全域旅游。完成4A景区整改提升和凤凰山景区等10个旅游项目策划规划，突出抓好中心城市“一江两岸”、瀛湖文化旅游产业基地、秦岭、巴山等景区景点提升建设，积极推动南宫山创建5A景区。统筹大凤凰山等景区旅游综合开发，推进月河川道现代农业休闲园和全国重点镇、省级示范镇、省级文化旅游名镇（街区）、特色小镇以及乡村旅游扶贫示范村建设，谋划建设汉江滨水景观长廊。全年接待境内外游客3600万人次，实现综合收入200亿元，分别增长11.7%和17.6%。大力发展电子商务、现代物流、中介服务等新兴服务业，改造提升商贸零售、住宿餐饮、交通运输等传统服务业。全年培育规上服务业企业30户、限额以上商贸企业45户，三产服务业增长9%，完成社会消费品零售总额284亿元。

（七）加强基础设施建设，增强支撑保障能力。补短板、强基础、促提升，统筹推进交通、水利和电力等基础设施建设，实施好52个重大基础设施项目建设，进一步改善基础条件。围绕建设综合交通枢纽和物流中心，实质性推进西渝高铁项目前期工作，争取安康试验段工程开工建设。加快阳安铁路复线、安康富强机场、平镇和安岚高速公路、江南公交总站建设，加快实施G541石紫岚、G316安旬白、G316平梁至涧池、G210宁陕至两河、S102旬阳至小河二级路改建工程，完成安康大道提升改造工程，开工建设月河快速干道、江北大道东段等工程。加强水利基础设施建设，实施洞河水库、月河堤防和南山排洪工程，开工建设黄洋河护岸等工程，持续推进“月河补水”工程前期工作。推进330千伏安康水电站送出通道、110千伏、35千伏输变电及农网改造升级项目。

（八）推进新型城镇化建设，加快城乡统筹发展。强化规划引领，统筹城乡布局，深入推进以人为核心的新型城镇化。坚持“湖城一体、疏解江南、重心北移”，加快建设区域中心城市和生态宜居品质城市。编制“湖城一体”规划，重点系统谋划瀛湖-中心城市-安康湖（汉江旬阳库区）一体化发展，推进沿江、沿湖公路建设，规划建设“一江两岸环江百里”景观带和城东新区，加快汉江公园三期、黄洋河公园等项目建设。加快特色小镇建设。“疏解江南”重点是实施“退、转、改、停、禁”，逐步把江南城区打造成商务宜居区。实施东坝、西坝、高井、西关、金川等片区棚户区改造，全年完成棚户区改造2.6万户。实施巴山路、金州北路改造，完成一批公共资产腾退。严控江南城区开发建设强度，禁止乱搭乱建。“重心北移”重点是突出产城融合，狠抓基础配套，实施长春路、北环线、机场干线等控制性工程和医养中心、工人俱乐部、体育运动场馆、青少年足球运动中心、新罗公园、鹭湾中央公园等重点项目。统筹月河川道城镇带、石紫岚沿江（线）生态经济带、汉江生态经济带和县城、重点镇、农村新型社区以及美丽乡村建设，深入推进城乡一体化。探索建立城镇“规划、建设、管理相统筹，权力、责任、投入相一致”的管理体制和运行机制，切实以精细化管理提升城市品质。

（九）加强生态文明建设，打造青山绿水典范。全面落实主体功能区建设试点示范实施方案和产业准入负面清单，加大生态建设和环境保护力度，启动国家低碳城市试点。继续开展以汉江水质保护“十大专项行动”为重点的专项整治，做好汉江水质保护、大气污染防治、农村环境保护和污染减排，深化“河长”制和“网格化”管理，确保汉江水质稳定达标、城乡居民饮水安全。大力实施新一轮退耕还林，全年造林绿化50万亩，治理水土流失面积850平方公里。以面源污染、土壤重金属和化学污染为重点，强化农村环境综合整治。加快实施瀛湖湖泊治理、江北污水处理厂升级改造、江南污水处理厂迁建、白石河流域重金属污染综合治理，建成东坝排涝泵站和13个镇级垃圾污水处理工程。全年万元GDP能耗下降3.1%。

（十）用心办好民生实事，不断增进群众福祉。全年完成民生工程投资150亿元，抓好就业创业等八大民生工程。完善和落实就业创业优惠政策和配套措施，新增城镇就业2万人，免费技能培训2.5万人次，发放创业担保贷款4亿元。全面实施13年免费教育，新建和改扩建中小学、幼儿园235所，加快安中高新分校、市一小高新分校、安康职业技术学院附属小学等建设。岚皋、紫阳通过国家义务教育均衡发展县验收。坚持以人民健康为中心，实施市眼科医院、市中医院全科医师培训中心、安康职业技术学院附属医院、高新医养医院等项目，全面提升公共卫生和医疗服务能力。完善低保、五保、医疗等救助体系，全面推行新型农村合作医疗大病保险，实施“全民参保计划”。加快构建公共文化服务体系，启动国家公共文化服务示范区创建，开工建设西城阁“古西城文化园”、市工人文化宫、香溪书院，建成汉江大剧院。以筹备第十四届全运会为契机，完善城乡体育设施。启动中心城市“四网同线”改造，加大气化工程推进力度。深入推进“平安安康”建设，让全市人民在改革发展中有更多的获得感和安全感。
