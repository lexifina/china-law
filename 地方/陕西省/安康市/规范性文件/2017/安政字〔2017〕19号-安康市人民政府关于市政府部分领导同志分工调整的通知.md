# 安康市人民政府关于市政府部分领导同志分工调整的通知

各县、区人民政府，市政府各工作部门、直属机构：

经市政府党组会议研究决定，现将部分领导同志分工调整通知如下：

赵俊民：负责市政府常务工作和发展改革、工业和信息化、人力资源和社会保障、监察、税务、城乡规划建设管理、行政学院,以及中心城市、恒口示范区（恒口镇级小城市综合改革试验区）、区域物流中心、信息产业发展和县域工业集中区、“飞地经济”园区、对外开放方面的工作。

分管市政府办公室（法制办、督查室、应急办、外侨办、机关事务管理局、政务服务中心、驻外办事机构）、市发改委（重点项目办、南水北调办）、市工信局（国资委、中小企业促进局）、市监察局、市审计局、市人社局（公务员局、城乡居民社会养老保险经办处、社会保险经办中心）、市规划局（人防办、地震局）、市住建局（房管局）、市城管局（创建办）、市环保局、市统计局、市台办、市住房公积金管理中心、市政府新闻办、市机场办、中心城区防洪保安工程建设指挥部。协助分管市财政局（公共资产管理局、财政征收管理局）、市编委办。

联系驻安部队、市国税局、市地税局、市养老保险经办处、国家统计局安康调查队、省属企事业审计处、水电三局基地管理中心、西部机场集团安康机场有限公司、陕西煤化集团陕南投资公司、陕建集团安康分公司、安康市发展投资集团、城市建设投资公司、金州矿业公司。

何邦军：负责脱贫攻坚、交通运输、国土资源管理、电力，区域交通枢纽建设方面的工作。

分管市扶贫局（脱贫攻坚指挥部办公室）、市交通局（邮政管理局）、市国土局（移民〔脱贫〕搬迁办、不动产登记局）、市土地统征中心、市公路局。

联系安康高新区、市总工会，市工商联、安康供电局、地电安康分公司、西安铁路局驻安各单位、中石油安康分公司、陕西交建集团安川分公司、安平分公司，陕西高速集团白泉分公司、陕西邮政安康分公司、省地质一队、市扶贫开发投资公司、市公交公司。

杨尚伟：负责公安、信访、司法、国安、工商、质监，安全生产以及道路交通安全、消防安全方面的工作。

主管市公安局，分管市信访局、市司法局、市安监局、市工商局、市质监局。

联系市中级法院、市检察院，武警、消防支队，国家安全局、安康监狱、市法学会。

其他领导同志分工不变。

安康市人民政府

2017年4月16日
