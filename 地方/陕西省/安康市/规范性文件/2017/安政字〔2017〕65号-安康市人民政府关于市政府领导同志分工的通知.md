# 安康市人民政府关于市政府领导同志分工的通知

各县、区人民政府，市政府各工作部门、直属机构：

经市政府研究决定，现将市政府领导同志分工通知如下：

赵俊民：领导市政府全面工作。

分管市编委办、市财政局（公共资产管理局、财政征收管理局）、市审计局、市机场建设指挥部办公室，联系安康机场投资建设公司、西部机场集团安康机场公司。

赵 璟：负责市政府常务工作和发展改革、工业和信息化、国资监管、城乡规划建设、城市管理、人力资源和社会保障、监察、税务、行政学院以及安康国家高新区、县域工业集中区建设方面工作；统筹协调信访维稳工作。

分管市政府办公室（法制办，督查室、应急办、外侨办、机关事务管理局、政务服务中心、驻外办事机构）、市发改委（重点项目办、南水北调办、“飞地”办）、市工信局（国资委、中小企业促进局）、市监察局、市人社局（公务员局、城乡居民社会养老保险经办处、社会保险经办中心）、市规划局（人防办、地震局）、市住建局（房管局）、市统计局、市城管局（创建办）、市住房公积金管理中心、市政府新闻办（市委网信办）、中心城区防洪保安工程建设指挥部。

协助分管市编委办、市财政局（公共资产管理局、财政征收管理局）、市审计局、市机场建设指挥部办公室。

联系驻安部队、市国税局、市地税局、市总工会、市工商联、市养老保险经办处、国家统计局安康调查队、省属企事业审计处，市发展投资集团、市中心城市建设投资公司、金州矿业公司、市水务集团、国家粮食储备粮安康直属库、市粮食储备库、陕建集团安康公司、水电三局基地管理中心、陕西煤化集团陕南投资公司。

尹清辽：负责科技、商务、招商方面的工作。

分管市科技局、市商务局、市招商局、市台办。

联系市科协、中石油安康分公司、中石化安康分公司。

鲁 琦：负责农村、农业、救灾、民政、民族宗教以及现代农业园区建设、富硒产业发展方面的工作。

分管市民政局（老龄办）、市农业局、市水利局（防汛抗旱指挥部办公室）、市林业局（化龙山保护区管理局）、市移民局、市民宗局、市供销社、市富硒产业研发中心。

联系市残联、市气象局、市烟草专卖局、市水文水资源局、安康水电总厂，石泉、喜河、蜀河水电厂及旬阳水电站、白河水电站建设，市水电联合实业有限公司，市蚕种场。

寇全安：负责环境保护、市场监管、旅游发展、瀛湖生态旅游区方面的工作。

分管市环保局、市旅发委、市工商局、市质监局、市食品药品监管局、市盐务局。

联系市盐业公司、陕西文投安康文旅公司。

何邦军：负责脱贫攻坚、交通运输（含铁路、水运）、国土资源管理、电力以及区域交通枢纽建设、恒口示范区（恒口镇级小城市综合改革试验区）方面的工作。

分管市扶贫局（脱贫攻坚指挥部办公室）、市交通局、市国土资源局（移民〔脱贫〕搬迁办、不动产登记局、市土地统征中心）、市公路局。

联系安康供电局、陕西地电安康分公司、西安铁路局驻安各单位，陕西交建集团安川分公司、安平分公司，陕西高速集团白泉分公司、西汉分公司安康段，陕西邮政安康分公司、省地质一队、市扶贫开发投资公司、市公交公司、市慈善协会。

杨尚伟：负责公安、信访、司法、国安、安全生产方面的工作。

主管市公安局，分管市信访局、市司法局、市安监局（市交安委、市消安委）。

联系市中级法院、市检察院，市武警支队、市消防支队、市国家安全局、安康监狱、市法学会。

蒋清海：负责金融、发展研究、地方志、通信和高新区金融聚集区建设方面的工作。

分管市金融办、市发展研究中心、市方志办，协助分管脱贫攻坚、信息化建设工作。

联系市人行、银监局及银行、保险、证券等金融机构，市无线电管理处，电信安康分公司、移动安康分公司、联通安康分公司、铁塔安康分公司、广电网络安康分公司。

杨 淼：负责教育、文化、卫生和计划生育、体育以及妇女儿童、大健康产业发展、旬阳省级高新区方面的工作。

分管安康职业技术学院、市教育局（教育督导室）、市卫计局（医改办、爱卫办）、市文广局、市体育局。

联系安康学院、团市委、市妇联、市文联、市红十字会，新华书店、市文化投资公司、市体育产业公司。

陈伍文：协助市长、常务副市长处理市政府日常工作，受市长、常务副市长委托处理应急事项。

负责市政府办公室全面工作，协助分管市信访局、市发展研究中心、驻外办事机构。

安康市人民政府

2017 年10月12日
