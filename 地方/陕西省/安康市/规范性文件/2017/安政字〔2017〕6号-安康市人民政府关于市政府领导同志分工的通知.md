# 安康市人民政府关于市政府领导同志分工的通知

各县、区人民政府，市政府各工作部门、直属机构：

经市政府会议研究决定，现将市政府领导同志分工通知如下：

徐启方：领导市政府全面工作。分管市财政局（公共资产管理局、财政征收管理局）、市编委办。

赵俊民：负责市政府常务工作和发展改革、人力资源和社会保障、监察、税务、城乡规划建设管理、行政学院,以及中心城市、恒口示范区（恒口镇级小城市综合改革试验区）、区域物流中心、“飞地经济”园区、对外开放方面的工作。

分管市政府办公室（法制办、督查室、应急办、外侨办、机关事务管理局、政务服务中心、驻外办事机构）、市发改委（重点项目办、南水北调办）、市监察局、市审计局、市人社局（公务员局、城乡居民社会养老保险经办处、社会保险经办中心）、市规划局（人防办、地震局）、市住建局（房管局）、市城管局（创建办）、市环保局、市统计局、市台办、市住房公积金管理中心、市政府新闻办、市机场办、中心城区防洪保安工程建设指挥部。协助分管市财政局（公共资产管理局、财政征收管理局）、市编委办。

联系驻安部队、市国税局、市地税局、市养老保险经办处、国家统计局安康调查队、省属企事业审计处、水电三局基地管理中心、西部机场集团安康机场有限公司，陕建集团安康分公司、安康市发展投资集团、城市建设投资公司。

尹清辽：负责科技、商务、招商方面的工作。

分管市科技局、市商务局、市招商局。协助分管发展改革、对外开放工作。

联系市科协、国家储备粮安康直属库。

鲁 琦：负责农村、农业、救灾、民政、民族宗教，以及现代农业园区建设、富硒食品产业发展方面的工作。

分管市民政局（老龄办）、市农业局（富硒产品研发中心）、市水利局（防汛抗旱办公室）、市林业局（化龙山保护区管理局）、市移民局、市民宗局、市供销社。

联系市残联、市气象局、烟草专卖局、水文水资源局、安康水电总厂，陕西汉江投资开发有限公司石泉、喜河、蜀河水电厂及旬阳水电站，中广核集团白河水电站、水电联合实业有限公司、安康市蚕种场。

孙矿玲：负责教育、卫生和计划生育、食品药品监管、文化、旅游、体育、妇女儿童、瀛湖生态旅游区，以及旅游、大健康产业发展方面的工作。

分管市教育局（督导室）、市卫计局（医改办、爱卫办）、市食品和药品监管局、市文广局、市旅游局、市体育局、市方志办、安康职业技术学院。

联系团市委、妇联、文联、红十字会、安康学院、广电安康分公司、新华书店、陕文投安康文投公司。

何邦军：负责工业和信息化、交通运输、国土资源管理、安全生产、脱贫攻坚、电力，信息产业发展和区域交通枢纽、县域工业集中区建设方面的工作。

分管市工信局（国资委、中小企业促进局）、市交通局（邮政管理局）、市国土局（不动产登记局、移民〔脱贫〕搬迁办）、市扶贫局（脱贫攻坚指挥部办公室）、市安监局、市土地统征中心、市公路局。

联系安康高新区、市总工会，市工商联、安康供电局、地电安康分公司、西安铁路局驻安各单位、中石油安康分公司、陕西煤化集团陕南投资公司，陕西交建集团安川分公司、安平分公司，陕西高速集团白泉分公司、陕西邮政安康分公司、省地质一队、市扶贫开发投资公司、金州矿业公司、市公交公司。

杨尚伟：负责公安、信访、司法、国安、工商、质监，以及道路交通安全、消防安全方面的工作。

主管市公安局，分管市信访局、市司法局、市工商局、市质监局。

联系市中级法院、市检察院，武警、消防支队，国家安全局、安康监狱、市法学会。

蒋清海：负责金融、盐务、通信、发展研究、高新区金融聚集区建设方面的工作。

分管市金融办、市发展研究中心、市盐务局。协助分管脱贫攻坚、信息化建设工作。

联系市人行、银监局及各商业银行、保险、证券等金融机构和无线电管理处、电信安康分公司、移动安康分公司、联通安康分公司、铁塔安康分公司、市盐业总公司。

陈伍文：协助市长、常务副市长处理市政府日常工作，受市长、常务副市长委托处理应急事项。协助分管市信访局、市发展研究中心、驻外办事机构。

负责市政府办公室全面工作。

安康市人民政府

2017年1月14日
