# 安康市人民政府关于命名2017年度市级生态村的通报

各县区人民政府，市政府各工作部门、直属机构：

2017年，我市全面贯彻党的十九大精神，牢固树立生态文明理念，以“追赶超越，绿色崛起”为目标，积极推进生态文明建设和农村环境综合整治，全市人居环境得到明显改善，生态文明建设和环境保护工作取得新成效。经县区申报、市环保部门考核验收，市政府常务会议研究审定，市政府决定命名汉滨区建民办事处忠诚村等56个村为市级生态村。

希望被命名的村要珍惜荣誉，戒骄戒躁，健全完善农村环境保护工作长效管理机制，巩固提升生态创建成果和人居环境质量，强化生态文明建设，协调推进乡村振兴战略深入实施。各级各有关部门都要以先进为榜样，深入扎实开展生态创建工作，为推进西北生态经济强市建设做出更大的贡献。
