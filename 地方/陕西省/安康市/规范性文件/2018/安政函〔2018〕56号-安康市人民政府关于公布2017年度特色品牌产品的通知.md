# 安康市人民政府关于公布2017年度特色品牌产品的通知

各县区人民政府，市政府各工作部门、直属机构：

依据《安康市特色品牌产品评定办法》有关规定，经企业申报,市质量强市工作推进委员会评审,市政府常务会议审定，市政府决定认定“家家贝”牌腊肉干等9种产品为2017年度安康市特色品牌产品，现予以公布。

希望获得安康市特色品牌产品称号的企业再接再厉、戒骄戒躁、再创佳绩,持续提升产品质量水平，进一步加大技术创新力度，努力争创省级名牌产品，不断增强品牌影响力和市场竞争力。各级各部门要按照高质量发展要求，坚持质量第一、效益优先，推动经济发展质量变革、效率变革和动力变革，加快实施质量强市战略，持续深入加大品牌创建力度，为加快追赶超越和建设西北生态经济强市作出新的更大贡献。

附件：2017年度安康市特色品牌产品名单

安康市人民政府
