# 安康市人民政府关于命名2017年度市级卫生镇卫生村和卫生先进单位的通报

各县区人民政府，市政府各工作部门、直属机构：

2017年，全市上下围绕健康安康建设，积极推进卫生创建工作，涌现了一批先进典型。经严格评选，市政府决定命名汉滨区紫荆镇等3个镇为市级卫生镇，汉滨区瀛湖镇清泉村等43个村为市级卫生村，汉滨区瀛湖镇玉岚卫生院等20个单位为市级卫生先进单位。

希望被命名的市级卫生镇、村和卫生先进单位珍惜荣誉，再接再厉，再创佳绩。同时，各级各部门、各单位要以先进为榜样，积极开展新时期爱国卫生工作，深入推进城乡环境卫生综合治理，努力创造促进健康的良好环境，全面提高人民群众文明卫生素质，为深化国家卫生城市创建成果、推进健康安康建设作出新的更大的贡献。
