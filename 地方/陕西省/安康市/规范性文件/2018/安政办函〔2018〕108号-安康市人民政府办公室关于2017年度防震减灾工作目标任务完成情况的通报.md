# 安康市人民政府办公室关于2017年度防震减灾工作目标任务完成情况的通报

各县区人民政府，市政府各工作部门、各直属机构：

依据市政府与县区政府签订的《2017年度防震减灾工作目标责任书》要求，组织对各县区2017年防震减灾工作目标责任完成情况进行了考核检查，现将有关情况予以通报。

从考核检查情况看，各县区能够深入贯彻落实习近平总书记关于防灾减灾救灾新理念新思想新战略，着眼人民群众安全需求，把防震减灾融入经济社会发展全局谋划，能够严格按照市上部署要求，积极落实防震减灾各项工作任务，成效较为明显。一是防震减灾工作普遍得到重视。各县区政府常务会议、县长办公会议或专项办公会议研究了防震减灾工作。二是防震减灾目标责任全面落实。汉滨、宁陕、镇坪、汉阴将防震减灾工作纳入对乡镇政府的目标考核，促进了各项工作任务的全面开展。三是防震减灾工作机构人员有效加强。九县一区全部制定了机构划转意见，明确地震机构人员，并迅速完成机构划转、人员划转、资产划转，保证了地震业务工作的持续性。四是牢固树立“震情第一”观念。及时落实宏观异常、强化地震“三网一员”培训、群测群防工作进一步加强。五是震害防御扎实推进。市县集中开展抗震设防执法大检查，确保抗震设防备案率达到100%。全年完成一般建设工程备案288项，创建县级防震减灾科普示范学校17所、防震减灾示范社区6处，其中，宁陕县梅子镇子午社区被认定为国家级地震安全示范社区。六是地震应急准备不断完善。各县区修订完善地震应急预案，完善应对措施。特别是在四川九寨沟发生7.0级地震后，有感县区快速反应、有效应对、维护了社会秩序稳定。在各县区的共同努力下，我市2017年防震减灾工作再次被省政府认定为优秀等次。在取得以上成绩的同时，还存在部分县区对防震减灾工作重视性不够、管理机构不完善、财政投入严重不足、在“防、抗、救”各环节工作不够积极、措施不够扎实、亟待进一步改进和加强。

根据考核结果和日常工作开展情况，评定汉滨区、宁陕县、旬阳县、镇坪县为2017年度防震减灾工作优秀等次，汉阴县、平利县、石泉县、白河县、岚皋县、紫阳县为2017年度防震减灾工作良好等次。

2018年，各县区要继续落实防震减灾目标责任制，坚持以防为主，努力提升地震灾害安全风险防范能力。强化建设工程抗震设防监管，重点做好农村民居抗震设防指导。切实加强地震应急准备，提高地震应急救援能力，加快建设步伐，推进标准化应急避难场所建设。市直各相关部门要按照防震减灾领导小组成员单位职责分工齐抓共管落实防震减灾目标任务，形成工作合力，全面完成2018年省对市防震减灾目标任务，为将我市建成西北生态经济强市提供有力保障。

安康市人民政府办公室

2018年4月18日
