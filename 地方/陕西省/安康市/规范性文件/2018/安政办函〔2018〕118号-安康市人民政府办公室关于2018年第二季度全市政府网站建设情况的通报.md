# 安康市人民政府办公室关于2018年第二季度全市政府网站建设情况的通报

各县区人民政府，市政府各工作部门、各直属机构：

按照中省全面推进政务公开和加强政府网站建设管理的要求，市电子政务办于近日对全市正在运行的59家政府网站进行了检查。市安监局、信访局、民政局等大部分部门网站能够按照《国务院办公厅关于印发政府网站发展指引的通知》要求，及时更新信息、完善服务事项，规范网站运维，积极办理“市长信箱”网民留言，较好地发挥了政府网站信息公开、解读回应、办事服务、互动交流等作用。市商务局、工信局、环保局、质监局、旅发委等19家网站存在内容更新不及时等问题。主要问题如下：

一、建设管理不规范。部分县区部门网站集约到县政府门户网站后，网站底部信息不统一；部分部门网站域名统一规范为市政府网站二级域名后，未在全国党政机关事业单位互联网网站标识管理服务平台和全国政府网站信息报送系统中及时更新英文域名、地址、网站名称等备案信息。汉滨教体局网站下线集约后未按要求关停注销原域名；市核桃产业发展协会冒用市林业局名义开办安康核桃网；市旅发委网站网页展现形式不符合网页设计规范，商业广告倾象化明显；紫阳县未按程序申报备案，自主开通公共资源交易网。以上网站均受到省政府政务公开办点名批评。

二、问题整改不彻底。部分网站主办单位季度自查流于形式，落实省市整改要求不认真、不到位，工作不精细，问题整改不彻底。个别网站栏目缺少信息发布时间，专栏未对“历史专题”或“归档”专题进行标识。市商务局、工信局、环保局、质监局、旅发委等网站未按要求及时完成整改，栏目不更新、错字词错链接、空白栏目等问题依然存在。市食药监局、市住房公积金管理中心、市规划局、市公安局等部门网站未按时落实省政府政务公开办关于要求转发“群众办事百项堵点疏解行动”活动链接的任务。

三、服务功能不完备。部分县区不注重办事服务事项梳理和内容更新，网上办事大厅栏目空白、事项要素不齐全、内容不准确现象依然存在。个别网站开展网上调查和意见征集活动次数不达标，不能主动倾听公众意见，接受社会的批评监督。市商务局网站“咨询留言”栏目网民留言超过1年未回复，市工信局网站网上调查栏目超过1年未更新。汉阴县、平利县、市扶贫局“市长信箱”办理工作滞后。

各县区、各部门要按照《政府网站发展指引》有关要求，夯实措施，加强人力保障，迅速落实整改任务，进一步推进政府网站规范化管理和运行。

一是迅速进行问题整改。存在问题的网站主管单位要安排专人，对照网站建设标准和已下发的问题清单，于4月27日前对网站进行复查整改；因网站问题被中省点名批评或通报的将按照相关规定启动约谈或问责机制。做好政府网站查遗补漏工作，将各级各类政府网站纳入“全国政府网站信息报送系统”统一管理。联系人变更或已改版的部门网站，迅速复查全国政府网站信息报送系统基本信息，更新联系人和栏目地址，确保信息真实性。市直部门网站中链接系统内的县区部门网站链接，统一更新链接到各县区政府网站。

二是规范建设政府网站。严格政府网站开设、整合、下线和备案流程，规范网站名称、域名、徽标和宣传语，严格按照《网页设计规范》设置网站布局形式。完善政府网站信息发布、解读回应、办事服务和互动交流功能，畅通互动渠道，加强网站政务服务功能，做到件件有落实，事事有回音。

三是加强常态化监管。进一步完善落实政府网站监管机制，持续做好自查上报工作，发现问题及时整改。认真做好网站集约迁移工作，杜绝网站随意上线下线、“假整合”和信息“假更新”等问题。认真做好“我为政府网站找错”网民留言办理，按要求在2个工作日内办理和回复网民留言。规范信息发布流程，严格信息发布检查审核，确保政府网站信息的及时性、准确性和权威性。

四是加强网站安全保障。落实网站安全测评和等级保护制度，全面排查风险隐患，做好防攻击、防篡改、防瘫痪、防泄密等安全保障工作，加强节假日值班值守，确保网站稳定、可靠、安全运行。
