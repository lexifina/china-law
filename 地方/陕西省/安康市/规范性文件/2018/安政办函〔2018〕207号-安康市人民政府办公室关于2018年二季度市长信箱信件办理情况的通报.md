# 安康市人民政府办公室关于2018年二季度市长信箱信件办理情况的通报

各县区人民政府，市政府各工作部门、直属机构：

现将二季度“市长信箱”信件办理情况通报如下。

一、基本情况

二季度“市长信箱”共受理有效信件1253件，同比上升9.4%，已办结1185件，办结率94.5%。转送县（区）政府办理749件，已办结681件，办结率90.1%；转送市直和中省驻安单位办理504件，已办结504件，办结率100%。人民网“地方领导留言板”给市长的9件留言已全部按期办结。

上半年“市长信箱”累计受理有效信件2398件，同比上升2.3%，已办结2314件，办结率96.5%。累计转送县（区）政府办理1438件，已办结1354件，办结率94.1%；转送市直和中省驻安单位办理960件，已办结960件，办结率100%。人民网“地方领导留言板”给市长的留言共计16件，已全部按期办结。

二、信件分析

从来信情况看，反映问题主要集中在以下几个方面:(一)监督投诉类问题，占比约35%。主要反映村级“两委”换届违规、环境污染、房地产开发领域、城市交通等问题。比如针对市民多次投诉公交车、出租车环境差、服务差等问题，市运管局决定在全市公共交通领域开展作风建设年活动，并与市总工会在公交车、出租车驾驶员中开展“安全行车、节能提效、文明服务”劳动竞赛活动，活动重点抓住群众反响强烈的难点、热点问题，通过活动深入开展，公共交通服务质量有了明显提升。（二）咨询类问题 ，占比约20%。主要咨询的有单位招考招聘、医疗教育、公积金办理、户口迁移、证件办理、棚户区改造等问题。特别是由于我市今年出台大力吸引人才人口若干政策措施，收到此类咨询信件较多，主管部门除了做好网上答复，还要跟进做好政策宣传。(三)建议类问题，占比约15%。信件主要是对城市建设和城市规划、交通安全、体育健身、便民措施、公交车路线等方面的建议。本季度较突出的信件是反映育才路梧桐树飞絮造成影响的信件，该问题近三年不断在市长信箱、两会提案中被提起，也得到市政府领导重视和批示。市住建局积极回应，并联系交管、城管、供电等部门，利用冬季修剪季节，对梧桐树进行整体重裁，有效减少飞絮对居民的影响。(四)求决类问题，占比约30%。来信主要反映农村农业、脱贫攻坚、社会保障等问题。涉及扶贫类信件80余件，信件量同比有所下降，但脱贫攻坚战正在关键时期，各县区务必高度重视，做好政策宣传同时，保证政策落实公正、公开、高效。

三、存在问题

从办理情况看，绝大多数承办单位都能按照《关于进一步加强市长信箱办理工作的通知》（安政办函〔2018〕139 号）要求，依法依规，及时有效处理管辖范围内的群众诉求。特别是旬阳县、汉阴县、平利县，市住建局、市公安局、市教育局等县区和部门领导重视程度高，调查核实问题实，处理答复诉求准，整体办理质量较好。但也有少数责任单位对群众通过“市长信箱”反映的诉求重视度不够，超期办理、答非所问、避重就轻、久拖不决问题仍不同程度存在。特别是汉滨区和恒口示范区，按期办结率仅分别为85.2%、59.7%，且整体工作滞后，群众满意度低。
