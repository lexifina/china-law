# 安康市人民政府办公室关于成立安康市推进城镇人口密集区危险化学品生产企业搬迁改造工作领导小组的通知

各县区人民政府，市政府各工作部门、直属机构：

为切实加强全市城镇人口密集区危险化学品生产企业搬迁改造工作的组织领导，市政府决定成立安康市推进城镇人口密集区危险化学品生产企业搬迁改造工作领导小组，现将组成人员通知如下：

组 长：刘元世 市委常委、副市长

领导小组下设办公室，具体负责全市城镇人口密集区危险化学品生产企业搬迁改造工作领导小组的日常工作。办公室设在市工信局，市工信局副局长向德刚同志兼任办公室主任。
