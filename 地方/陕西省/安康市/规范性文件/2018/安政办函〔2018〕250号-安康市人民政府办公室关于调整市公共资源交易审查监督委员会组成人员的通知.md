# 安康市人民政府办公室关于调整市公共资源交易审查监督委员会组成人员的通知

各县区人民政府，市政府各工作部门、直属机构：

根据《安康市级公共资源交易管理办法(试行)》（安办字〔2017〕168号）和《关于成立安康市公共资源交易审查监督委员会的通知》（安政办函〔2017〕109号），结合机构设置、人员变动情况和工作需要，市政府决定对市公共资源交易审查监督委员会组成单位和人员进行调整。现将调整后的名单通知如下：
