# 安康市人民政府办公室关于印发市政务服务中心进驻事项目录和2018年度第一批“最多跑一次”事项清单的通知

市政府各工作部门、直属机构：

为贯彻落实各级党委、政府关于审批服务便民化、“一网、一门、一次”改革及优化提升营商环境有关要求，市政务服务中心组织各部门对进驻事项、“最多跑一次”事项进行了再次梳理，汇总编制了《市政务服务中心进驻事项目录（不含市税务局）》和《安康市2018年度第一批“最多跑一次”事项清单（不含市税务局）》。为确保各项改革措施落地生效，切实为企业和群众办事提供便利，现将有关事项通知如下：

一、《市政务服务中心进驻事项目录》和《安康市2018年度“最多跑一次”事项清单》通过媒体对外公布，接受社会监督。依托12345便民服务热线，建立政务服务事项投诉举报机制，企业和群众在办事过程中如发现进驻事项“体外循环”、“明进暗不进”，“最多跑一次”事项仍然需要“跑多次”等问题，可通过12345热线进行投诉举报，经查属实的按照《安康市政务服务平台建设运行监督管理办法》（安政办发〔2017〕110号）予以追责。

二、经对照《权责清单》梳理，市级各部门共有政务服务事项428项（因税务部门机构改革尚未到位，本次统计数字不含市税务局），其中进驻市政务服务中心367项，进驻比例86%，61项事项因涉密、场地等原因未进驻，相关单位均书面报送了情况说明。下一步，市审改办、市政务服务中心及相关部门要建立政务服务事项动态管理机制，及时承接落实中省取消、下放事项，确保事项应进全进，审批合法合规。联系人：钟骏，联系电话：2390005。

三、各进驻部门要按照“减环节、减材料、压时限”的要求，进一步优化办事流程，通过现场办结、全程网办、免费邮寄等方式，推出更多的“最多跑一次”和“零跑路”事项，最大限度方便企业和群众办事创业。

附件：1.市政务服务中心进驻事项目录（不含市税务局）.rar

2.安康市2018年度第一批“最多跑一次”事项清单（不含市税务局）.rar
