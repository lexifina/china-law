# 安康市人民政府办公室关于2018年第三季度市长信箱办理情况的通报

各县区人民政府，市政府各工作部门、直属机构：

现将2018年第三季度“市长信箱”信件办理情况通报如下：

一、基本情况

三季度“市长信箱”共受理有效信件1289件，环比增加4%，同比减少8%，已办结1281件，办结率99.4%。其中：转送县（区）政府办理771件，已办结763件，办结率99%；转送市直及中省驻安单位办理518件，已办结518件，办结率100%；人民网“地方领导留言板”给市长留言3件，已全部办结。从办理情况看，旬阳县、白河县、汉阴县、市公安局、市运管局、市卫计局受理及时，答复办理情况较好。

二、诉求分类

从来信情况看，反映问题集中在以下几个方面：一是监督投诉类。中心城区交通管理、精准扶贫、村干部违纪、房地产领域、公共交通服务、环境污染、医疗卫生、教育等方面的投诉较多，占信件总数的60%，环比减少7.7%；二是政策咨询类。机关事业单位招考、退伍安置、社会保障、住房公积金、不动产登记、高铁规划等方面的政策咨询较多，占信件总25%，环比增加66.7%；三是建言献策类。城乡规划建设、公交车线路规划、旅游开发、劳动保障等方面的建言献策活跃，占信件总数的15%，环比减少25%。

三、存在问题

一是办理工作滞后。少数县区和部门对“市长信箱”信件办理工作重视度不够，工作责任落不实，有的单位由于接收的信件较少，工作人员长期不查看信箱，存在突击办理情况，如市交通局本季度存在此问题；二是办理质量不高。承办单位虽能落实领导签字审核，但是部分回复内容对信件反映的问题没有深入调查核实，在网上回复的内容中没有准确回复反映的问题，回复内容和办理工作避重就轻，导致群众同一事项多次投诉。

四、工作建议

本季度热点问题：一是扶贫领域。涉及扶贫的信件110余件，环比增加37.5%，主要反映扶贫政策落地不实、要求享受扶贫待遇等。各县区务必高度重视，对反映的诉求逐一核实，及时解决合理诉求，进一步加强宣传引导，保证政策落实公正、公开；二是小区管理。此类信件约60余件。主要是反映房屋产权证办理、停车位管理、物业服务收费、居民用水用电等。请各单位密切配合、综合施策、及时化解，努力减少问题累积和矛盾上行，防止发生集体上访；三是社区管理。主要反映社区工作者管理、待遇等方面的请求和建议，此类信件虽然件数不多，但是涉及人数较多，请相关部门及时调研，尽快健全完善社区专职工作人员管理办法。四是政策宣传。本季度政策咨询类信件增幅较大，各县区、各部门务必加强政策宣传力度，创新宣传形式，让群众对党的创新理论，国家的好政策听得进、记得住，传播好“安康好声音”。

各级、各部门要持续重视“市长信箱”的办理，严格按照《安康市市长信箱管理办法》要求，确定专人负责此项工作，确保办理工作责任落得实。在具体办理过程中，不避重就轻，不回避矛盾，特别是反映集中的涉众问题，职能部门要坚持网上网下两手抓，除了网上及时答复外，还要跟进做好群众思想疏导和政策法律宣传解释工作，避免由信转访或引发越级集体上访。

安康市人民政府办公室
