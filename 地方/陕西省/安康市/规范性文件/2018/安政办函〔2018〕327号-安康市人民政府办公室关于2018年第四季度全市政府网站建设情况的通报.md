# 安康市人民政府办公室关于2018年第四季度全市政府网站建设情况的通报

各县区人民政府，市政府各工作部门、直属机构：

根据《陕西省人民政府办公厅关于2018年第三季度全省政府网站抽查情况的通报》（陕政办函〔2018〕292号）要求，市政府办公室近期组织开展了2018年第四季度全市政府网站检查。经市政府同意，现将有关情况通报如下：

一、总体情况

第四季度，全市正在运行政府网站60家，关停不合格政务微信22个、微博27个。市电子政务办公室持续加强政府网站监管，对全市政府网站和政务新媒体进行了全面检查，政府网站总体合格率为93%，政务新媒体合格率为96%。8至10月，有4家问题网站相关负责人被约谈，6家问题新媒体主管单位9名具体负责人脱岗参加整改培训学习；市政府网站主动公开政务信息2372条，其中采用县区和部门政务信息1010条；受理国办“我为政府网站找错”平台有效留言21条，按期办结率100%。“市长信箱”1至9月累计受理有效信件3687件，办结率96.8%。

各县区、各部门按时完成中省“群众办事百项堵点疏解行动”“国家政务服务投诉与建议小程序”和环境保护督察回头看宣传发布等任务。平利县政府、市国土局、市文广局常态化监管措施落实有力，按要求开展四季度网站自查并公开了结果。市财政局主动组织县区、部门网站公开2017年决算和2018年预算公开目录，市国土局、市卫计局、市住建局等部门积极配合保障重点领域信息公开，全市政务公开水平稳步提升。

二、存在问题

（一）部分网站管理不规范、整改不彻底。部分网站主办单位管理不到位，日常监管和自查整改流于形式。经多次催办、复查，石泉县政府、恒口示范区管委会、市教育局、市移民局网站依然未按要求整改，网站检查不合格；汉滨区政府、市公安局、市司法局网站存在突出问题（具体问题见附件1）。个别单位未按《2018 年第二季度全市政府网站建设情况的通报》要求完善“全国政府网站信息报送系统”信息，市城管局未填写公安机关备案标识码和党政机关网站标识；市移民局、市食药监局、市交警支队未按规范填写公安机关备案标识码。部分网站主管单位未按要求开展第四季度网站自查。

（二）互动交流服务水平不高。个别网站网民意见建议的审看、处理和反馈机制不完善，网民留言答复不及时，开展网上调查和意见征集活动次数不达标，不能主动倾听公众意见、接受社会监督，给政府形象和公信力造成不良影响。恒口示范区管委会网站监测点1年内调查征集互动次数少于6次；市公安局“局长信箱”栏目未见留言答复反馈信息。

（三）政务新媒体日常监管不到位。部分政务微信、微博主管单位重建设轻管理，缺乏常态化管理机制；个别县区政府办监管责任落实不到位，对辖区内政务新媒体摸底不清，自查和问题整改不彻底。经复查，汉滨区政府、紫阳县政府、恒口示范区管委会、市民政局、市教育局、市环保局、市食药监局第三季度通报的问题微信微博“僵尸化”现象依然存在（具体问题见附件3）；其中，“安康民政”微信和微博公众号长期不更新，在三季度情况通报后，经多次督促依然未进行整改，主管单位也未按要求派相关责任人参加整改培训。

三、工作要求

一要迅速落实整改。问题网站主管单位要迅速安排专人，全面检查各自网站和微信、微博，于11月12日前完成整改，未按要求整改或被中省点名批评通报的，将按照相关规定启动约谈或问责机制。市民政局政务新媒体分管负责人和具体责任人于11月13日到市政府行政中心707会议室参加约谈，并就本单位网站、新媒体自查和建设管理情况作简要汇报（汇报书面材料一式两份）。汉滨区政府、石泉县政府、紫阳县政府、恒口示范区管委会、市教育局、市移民局、市民政局、市环保局、市食药监局等网站复查不合格、政务新媒体“僵尸化”倾象严重的主管单位，派具体负责人到市电子政务办公室培训学习5天（参训名单请于11月13日前报市电子政务办公室）。

二要夯实常态化监管措施。规范建设政府网站和新媒体，无力保障更新的政务新媒体要注销关停账号进行整改，市直部门网站无力保障的意见征集、网民留言、网上调查等互动栏目要转链至市政府网站相关栏目，相关信息要及时通过市政府网站予以公开。严格遵守政府网站、政务新媒体开设和下线备案制度。做好重点领域政府信息公开，及时处置依申请公开信件。迅速落实网站和政务新媒体自查制度，并于11月12日前在各自网站公开自查结果。全面准确公开办事指南信息，确保服务功能可用、实用。完善网民留言处置转办回应机制，认真做好“我为政府网站找错”网民留言答复。“紫陽交警大队”“安康环保举报热线”“安康食品药品监管”3个长期不更新微博要于11月25日前注销关停账号。

三要认真做好政务公开绩效评估。各县区、各部门要以今年政务公开工作绩效评估为契机，对照评估指标组织全面自查，完善丰富网站各类信息公开内容，拓展公开范围，加强组织保障，按要求上报各项印证材料，扎实做好政务公开各项工作，推进我市政务公开再上新台阶。
