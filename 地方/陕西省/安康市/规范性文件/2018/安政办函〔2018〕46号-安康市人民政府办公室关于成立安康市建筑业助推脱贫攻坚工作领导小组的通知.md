# 安康市人民政府办公室关于成立安康市建筑业助推脱贫攻坚工作领导小组的通知

各县区人民政府，市政府各工作部门、直属机构：

按照市委、市政府打赢脱贫攻坚战的工作部署和总体要求，为贯彻落实全市建筑业工作会议精神，深入推进就业脱贫工作，市政府决定成立安康市建筑业助推脱贫攻坚工作领导小组(以下简称领导小组)。组成人员如下：

组 长：赵 璟 市委常委、市政府常务副市长

副组长: 赵德成 市政府副秘书长、办公室主任

石昌林 市规划局（人防办）局长（主任）

郭德林 市脱贫办主任、扶贫局局长

汪小卫 市人社局局长

成 员：市发改委、财政局、工信局（国资委）、人社局、扶贫局、国土局、规划局（人防办）、住建局、统计局、工商局主要负责人。

领导小组主要负责围绕中、省、市关于脱贫攻坚工作的方针政策，研究制定建筑业助推脱贫攻坚相关政策和措施，对全市建筑业助推脱贫攻坚工作作出具体安排部署、检查考核等工作。领导小组下设办公室，办公室设在市规划局，办公室主任由石昌林同志兼任，副主任由市规划局副局长王波担任，具体负责组织协调和落实工作。

安康市人民政府办公室

2018年2月3日
