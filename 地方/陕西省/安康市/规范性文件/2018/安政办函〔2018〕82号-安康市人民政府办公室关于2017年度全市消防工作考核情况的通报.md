# 安康市人民政府办公室关于2017年度全市消防工作考核情况的通报

各县区人民政府，市政府各工作部门、各直属机构：

为切实加强消防工作，依法推动消防安全责任落实，2017年初，市政府与各县区政府、高新区管委会和相关行业部门单位签订了2017年度消防安全目标责任书。今年1月，市消防安全委员会组织对全市消防安全目标责任完成情况进行了考核。经市政府同意，现将有关情况通报如下：

从考核情况看，各县区和相关部门单位认真履职尽责，狠抓工作落实，不断完善“政府统一领导、部门依法监管、单位全面负责、公民积极参与”的消防工作格局，各项工作取得明显成效。一是消防工作责任得到有效落实。各县区、各部门、各单位高度重视，定期研究部署消防工作，逐级夯实目标责任，及时开展督导检查，认真组织年度考核，有效落实了“党政同责、一岗双责、齐抓共管、失职追责”的要求。二是消防基础建设得到有效提升。大力实施消防能力建设提振计划，各级消防经费保障力度明显加大，消防装备、市政消火栓等公共消防设施建设步伐加快，政府专职消防队站建设持续推进，城乡消防规划编制和修订工作基本完成。三是社会火灾防控能力稳步增强。不断健全完善消防应急救援力量体系，现役、专职等多种形式消防队伍不断发展壮大。全面开展常态化隐患排查整治，不断深化消防安全专项治理，强化挂牌督办、联合监管、公开曝光力度，全市抗御火灾能力显著增强，实现连续20年未发生较大以上火灾事故。四是消防宣传教育深入开展。消防宣传教育培训方式、方法不断创新，传统媒体与新兴媒体的宣传阵地不断拓展，消防宣传“七进”活动更加深入，社会公众消防安全意识进一步提高。但取得成绩的同时，部分县区、部门单位还存在着消防安全责任不明确、公共消防基础设施建设欠账较多、消防规划编制进展缓慢、火灾隐患整治力度不够和社会单位主体责任落实不到位等问题，亟待加强和改进。

根据考核结果并结合日常消防工作开展情况，评定石泉县、汉滨区、汉阴县、市文广局、市教育局、市旅发委、市住建局、市规划局、市民政局、中国石油安康销售分公司、中国移动安康分公司为“优秀”等次；旬阳县、宁陕县、平利县、白河县、岚皋县、紫阳县、高新区、市交通局、市卫计局、市质监局、市工商局、市商务局、中国电信安康分公司、国网安康供电分公司、陕西地方电力安康供电公司为“良好”等次；镇坪县、中国联通安康分公司、中石化安康分公司为“合格”等次。

2018年是消防改革的关键之年，也是实施消防能力建设提振计划的攻坚之年。各县区、各部门、各单位要以习近平新时代中国特色社会主义思想和十九大、十九届一中、二中、三中全会精神为指导，认真贯彻落实《消防安全责任制实施办法》，进一步建立健全消防安全责任体系，加强城乡公共消防基础设施建设，持续发展多种形式消防队伍，落实常态化火灾隐患排查整治机制，全面增强我市社会火灾防控能力，更好地满足人民群众对消防安全的新期待和新需要，努力为建设西北生态经济强市创造良好的消防安全环境。

安康市人民政府办公室

2018年3月26日
