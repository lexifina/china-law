# 安康市人民政府办公室关于印发安康市2018年政务督查工作要点的通知

各县区人民政府，市政府各工作部门、直属机构：

经市政府同意，现将《安康市2018年政务督查工作要点》印发给你们，请结合实际，认真组织实施。

安康市人民政府办公室

2018年3月29日

2018年，全市政务督查工作要以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九大精神，紧紧围绕追赶超越目标和“五新”战略部署，不断创新督查方式，完善督查制度，强化督查结果运用，全面提升督查效率，充分发挥政务督查抓落实、促发展利器作用，推进中、省、市重大决策部署和重点工作落地生效，全面实现“五个一流”工作要求。

一、坚决落实中、省重大决策部署

1．配合完成国务院第五次大督查。积极配合国办督查室、省政府督查室完成国务院第五次大督查任务，做好自查自评、统筹协调、保障服务等工作，切实抓好反馈问题整改工作。

2．对接落实中、省年度重点督查任务。积极配合中、省完成各类专项督查，坚持效能主导、统分结合、跟踪问效的原则，推进中、省各项重大决策部署在安康落地生根。

二、扎实推进市政府重大决策部署和重点任务

3．抓好《政府工作报告》重点任务督办落实。以《政府工作报告》确定重点工作为蓝本，以公开承诺制度为抓手，将关乎经济社会发展和民生福祉的重点工作纳入县区政府和市政府各工作部门、中省驻安相关单位的公开承诺内容，按照“按月督查、季度通报、半年小结、年底考核”要求，对公开承诺事项完成情况进行跟踪督办，充分发挥人大代表、政协委员、新闻媒体的督促作用，全面提高承诺兑现率。

4．加强市政府常务会议和市长办公会议确定事项督办。坚持“一会一督办一通报”原则，在会议结束一个月开始对确定事项进行跟踪督办，直到确定事项全面落实。

三、切实抓好批示件督办落实

5．提高领导批示件办理质量。认真做好中、省、市领导同志批示件的督办工作，建立督办台账，加大现场核查力度，充分发挥协调落实作用，促进批示事项落到实处，切实做到“交必办、办必果、果必报”。

6．提高人民网网民留言办理实效。确定专人负责省政府督查室转办的人民网网民给省委、省政府主要领导同志的留言办理工作，对重点留言进行现场核实，并定期对办理情况进行“回头望”，全面提高办理实效。督查指导相关部门按期办复人民网网民给市委、市政府主要领导同志的留言。

四、全面提高专项督查工作水平

7．提高专项督查的针对性。结合阶段性重点工作，协调相关部门有计划地开展专项督查，增强督查工作主动性，提高专项督查针对性。全年围绕脱贫攻坚、招商引资和优化提升营商环境、市级重点项目、农口目标任务书、便捷医疗行动、中心城区教育提升工程、中省环保督察反馈问题整改、安全生产四项攻坚行动等工作，组织相关部门和第三方机构开展专项督查，公开通报进展情况，及时向市政府报告存在的问题，提出解决措施，提高专项督查实效。

8．坚持专项督查审批备案制。严格按照市委办、市政府办《关于进一步精文减会和规范检查调研表彰活动的通知》(安办字〔2017〕115号)要求，实行督查审批备案制，精简整合各类督查，避免重复督查、多头督查，切实减轻基层负担。

五、督促指导按期完成建议提案办理工作

9﹒按期完成省、市人大代表建议、政协提案办理任务。按时完成市政府承办的省市人大代表建议、政协提案办理任务。督促指导市政府系统各承办单位落实好市人大代表建议、政协提案办理责任，抓好办前沟通、办中协商、办后回访三个环节，切实从“办文”向“办事”转变，进一步提高办理实效和代表、委员满意率，确保在法定时限内完成办理任务。

各县区政府、市政府各部门要高度重视政务督查工作，切实做到督查与决策并行。要进一步完善督查工作体系，配齐督查力量，统筹协调各方资源，形成各级各部门齐抓共管、社会力量广泛参与的“大督查”格局。要强化督查结果运用，信赏必罚，对重点工作推进较好的旗帜鲜明地进行褒奖，对重点工作推进不力的依法依规严肃问责，激发广大干部干事创业的积极性，全面提高政府效能。
