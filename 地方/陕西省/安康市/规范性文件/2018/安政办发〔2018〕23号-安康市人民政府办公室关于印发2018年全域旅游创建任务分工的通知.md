# 安康市人民政府办公室关于印发2018年全域旅游创建任务分工的通知

各县区人民政府，市政府各工作部门、直属机构：

按照《陕西省人民政府办公厅关于印发陕西省全域旅游示范省创建实施方案的通知》（陕政办发〔2017〕62号）要求，为确保我市全域旅游创建任务顺利实现，现将2018年全市创建主要任务予以分工。各级各有关部门要按照分工要求，制定详细的工作推进计划和目标责任清单，采取切实可行的措施，扎实推进创建任务落实。各责任部门于每季度末月20日前将任务完成情况及印证资料送市旅发委。
