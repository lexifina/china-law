# 安康市人民政府办公室关于印发《安康市加快培育上市后备企业资源行动计划（2018-2020）》的通知

各县区人民政府，市政府各工作部门、各直属机构：

现将《安康市加快培育上市后备企业资源行动计划（2018-2020）》印发给你们，请结合实际，认真贯彻落实。

附件：安康市加快培育上市后备企业资源行动计划 （2018-2020）

安康市人民政府办公室

2018年7月9日

附件

安康市加快培育上市后备企业资源行动计划

（2018—2020年）

为贯彻落实省委、省政府《关于加强金融工作的意见》（陕发〔2017〕12号）和省金融办、省证监局《关于印发陕西省加快培育上市后备企业资源行动计划（2018—2020年）的通知》（陕金融发〔2017〕7号）精神，加快挖掘和培育我市上市企业资源，有效助推我市经济追赶超越，特制定本行动计划。

一、总体目标

到2020年末，全市新增上市公司2-4家；每年向中国证监会报送上市申请材料企业不少于1家，在省证监局辅导备案企业不少于1家，新三板挂牌企业达到10家，四板挂牌企业达到100家；到2018年末，重点上市后备企业不低于5家,2019年、2020年重点上市后备企业存量均不低于2018年水平。

二、主要任务

（一）建立重点上市后备企业资源库。各县区要建立重点上市后备企业资源库，明确企业入库标准。到2018年末，全市重点培育的后备企业数量不低于30家，其中高新区不低于5家，汉滨区、旬阳县、汉阴县、石泉县均不低于3家，紫阳县、岚皋县、平利县、镇坪县、白河县不低于2家，宁陕县、恒口示范区、瀛湖生态旅游区不少于1家。2019年、2020年各县区重点上市后备企业存量均不低于2018年水平。

（二）加快推进企业与券商等中介机构签约。2018年-2020年，全市至少有10家企业与券商签订辅导协议。

（三）积极推动企业在陕西证监局辅导备案。2018—2020年，全市至少有5家企业在陕西证监局辅导备案，安康高新区至少有2家企业、汉滨、镇坪、旬阳三县区至少各有1家企业在陕西证监局辅导备案，其他各县也要积极争取境内企业到省证监局辅导备案。

（四）大力支持企业向中国证监会报送上市申请材料。2018—2020年，全市至少有3家企业向中国证监会报送上市申请材料，汉滨区、镇坪县、高新区至少各报送1家。

三、工作措施

（一）加大政策支持力度。市政府将A股上市企业奖励资金提高到500万元。各县区要根据自身情况，参照省市相关文件，制定完善支持企业在多层次资本市场发展的奖补办法和扶持政策，明确对企业在改制上市各阶段的奖励补助额度，落实资金来源，减轻企业改制上市负担，并为企业挂牌上市过程中办理土地、税收、环保、房产等手续开辟绿色通道，加快企业改制上市进程。对深度贫困县区的企业，要降低获取奖补资金的条件门槛，制定特殊扶持政策。

（二）建立后备企业资源库。各县区每年至少开展一次挂牌与上市后备企业资源的全面摸排，并参照挂牌上市的基本条件对企业进行筛选，建立挂牌上市后备企业资源库，持续跟踪、动态管理。特别是对深度贫困县境内的企业要全方位、无死角挖掘，并优先纳入上市后备企业资源库。

（三）加快中介机构进场辅导进程。各县区要加强和上交所、深交所、全国中小企业股份转让系统、陕西股权交易中心及证券中介机构的联系沟通和战略合作，不定期组织全市上市后备企业与交易所、券商交流信息，加强资本市场相关政策的宣传辅导力度，定期开展资本市场专题辅导，讲解培育企业上市的流程和要点，实现资本市场培训常态化。

四、保障措施

（一）加强组织领导。市政府成立由市政府常务副市长任组长，分管副市长为副组长，市金融办、市发改委、市工信局（国资委）、市财政局、市人社局、市国土局、市环保局、市工商局、市国税局、市地税局等部门负责人为成员的全市推进资本市场发展工作领导小组，负责全市企业上市工作的组织领导和协调服务工作，及时协调解决企业挂牌上市工作中的突出问题。领导小组设在市金融办，承担日常具体工作。各县区也要结合工作实际，成立相关工作机构，切实加强对企业挂牌上市工作的组织领导。

（二）强化工作督导。市金融办、市工信局要加大统筹协调和督促检查力度，每年组织券商等专业机构到各县（区）开展调研，走访当地优质上市后备企业，指导企业上市培育工作。

（三）建立考核机制。市政府与各县区签订目标责任书，明确年度挂牌上市目标任务，并将此项工作纳入市对县区年度目标责任考核内容，以确保各项任务落实到位。

附件：各县区推进企业上市挂牌工作任务表

注：“上市”仅指在上海证券交易所和深圳证券交易所挂牌；根据中国证监会公布的首次公开发行股票申请企业情况，上市板块分为上交所、深交所中小板和深交所创业板。
