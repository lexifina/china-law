# 安康市人民政府办公室关于印发安康富硒茶品牌整合方案的通知

各县区人民政府，市政府各工作部门、直属机构：

《安康富硒茶品牌整合方案》已经市政府同意，现印发给你们，请认真贯彻落实。

安康市人民政府办公室

2018年8月19日

安康富硒茶品牌整合方案

为充分整合市县区资源，不断提升“安康富硒茶”地理标志证明商标商业价值，做优产品、做亮品牌、做大市场，按照安康市富硒茶产业创新行动计划要求，全力加快提升“安康富硒茶”品牌效益和市场综合竞争力，特制定本方案。

一、总体要求

坚持政府主导、市场运作、行业管理、企业主体，以提高“安康富硒茶”产品质量为基础，以提升公用品牌商业价值为目标，以加强公用品牌管理为手段，以政策扶持引导为保障，充分发挥政府推动和市场引导作用，凝心聚力推进茶叶品牌整合，着力把“安康富硒茶”打造成为全国知名品牌。

二、目标任务

通过行政推动，大力宣传和推广使用“安康富硒茶”公用品牌，着力扩大“安康富硒茶”公用品牌使用率和覆盖面。为确保品牌整合平稳推进，暂保留“紫阳富硒茶”和“平利女娲茶”两个县域公用品牌，实行市、县区公用品牌并行使用，其中：紫阳和平利两县茶企自愿按照“市域品牌（‘安康富硒茶’）+县域品牌（‘紫阳富硒茶’‘平利女娲茶’）+企业品牌”的并行方式或直接采用“安康富硒茶+企业品牌”的方式进行茶产品营销;汉滨区、汉阴县、石泉县、岚皋县、镇坪县、旬阳县、白河县符合条件的企业全部申请使用“安康富硒茶”公用品牌，直接采用“安康富硒茶+企业品牌”的方式进行茶产品营销。利用3-5年时间，将“安康富硒茶”培育成国家地理标志保护产品、中国优秀茶叶区域公用品牌、中国驰名商标和全国十大名茶。

三、重点工作

（一）统一质量标准。由市质监局、市林业局、市农业局牵头，市食药监局、市工信局、市科技局、市工商局、市富硒研发中心等有关部门和市茶业协会及涉茶技术单位（院校）共同参与，研究制定“安康富硒茶”质量技术标准综合体，形成从良种繁育到种植管理、生产加工、贮运销售的标准体系，促进“安康富硒茶”标准化生产、品牌化经营、网络化销售。

（二）统一品牌管理。全市采用“市域公用品牌+企业品牌”母子商标和紫阳、平利两县暂时实行市、县区公用品牌并行使用的管理模式，不断扩大“安康富硒茶”公用品牌推广使用范围，提高市场影响力。由市工商局牵头，会同各县区政府及市林业局、市农业局、市质监局、市食药监局、市工信局、市富硒研发中心等涉茶管理部门及市茶业协会，研究制定《安康富硒茶地理标志证明商标使用管理办法》，按照各自职责行使产品生产管理、商标管理、品牌保护、质量监测和市场监管等职责，建立健全产品质量可溯源体系。

（三）统一宣传推介。由市林业局、市政府新闻办牵头，市农业局、市工信局、市商务局、市招商局、市旅发委及市茶业协会共同参与，按照政府主导、协会运作、企业主体的方式，聘请专业机构对“安康富硒茶”公用品牌宣传营销进行全面策划，按照策划方案通过刊登广告、会展推介、媒体宣传和开展重大茶事活动等方式对 “安康富硒茶”公用品牌进行持续不断地宣传营销；各产茶县区和各茶叶企业在举办的茶事展会活动和印送的各类对外宣传推介资料中必须以“安康富硒茶”公用品牌对外宣传推介，着力加大“安康富硒茶”品牌推广使用和市场营销，全面塑造“安康富硒茶”公用品牌良好形象，不断提升“安康富硒茶”市场占有率和品牌商业价值，全力打造“安康富硒茶”全国知名品牌。

（四）统一包装标识。由市茶业协会会同市工商局、市茶业办负责“安康富硒茶”地理标志证明商标标识管理。授权使用“安康富硒茶”地理标志证明商标的茶企业，在印制产品（内外）包装、宣传资料、门头牌匾、宣传广告、开办网站网页以及茶品宣传推介等市场营销过程中，必须按照规范要求统一印制和使用“安康富硒茶”公用品牌及其标识；各县区各部门在对外宣传推介和招商活动中的涉茶宣传品、印刷品、音视频及文件材料全部统一使用“安康富硒茶”公用品牌及其标识。市、县区合力加强“安康富硒茶”公用品牌推广使用和市场营销，加快品牌形象塑造。

（五）统一营销模式。市、县区要按照集中力量打造“安康富硒茶”公用品牌、培育一批市场主体、建设两个营销市场（电商和实体店销售）的总体要求，实行“统一门店招牌、统一营销培训、统一服务规范”的经营模式，组织重点茶企业在县域和全国地级以上城市分别设立100个以上“安康富硒茶”专营店，构建具有“四梁八柱”支撑性质的“安康富硒茶”生产营销体系，以“安康富硒茶”独特的营销管理模式提升品牌价值和品牌形象，扩大市场销售。

四、保障措施

（一）加强组织领导。成立由市长任组长，分管副市长任副组长，各区县政府、市直有关部门、市茶业协会等单位主要领导为成员的“安康富硒茶”公用品牌建设工作领导小组，协调解决“安康富硒茶”品牌整合与建设过程中遇到的相关问题。市林业局负责促进富硒茶产业发展的综合协调、基地建设和品牌建设工作领导小组办公室日常工作；市发改委负责促进富硒茶产业发展的统筹规划和项目计划；市财政局负责富硒茶品牌整合资金保障和财政扶持项目落实；市农业局负责争取中、省项目倾斜支持富硒茶产业发展、“三品一标”认证和公用品牌营销；市食药监局负责“安康富硒茶”地方食品安全标准立项和申报，涉茶追溯体系建设与管理和茶叶产品质量安全监管；市工商局负责“安康富硒茶”品牌使用、保护与市场监管及驰名商标培育；市质监局负责“安康富硒茶”种植、加工环节地方质量技术标准的立项、审批发布和“安康富硒茶”富硒专用标志的监督管理、名牌产品培育；市工信局负责涉茶企业培育和茶产品促销；市招商局负责做好“安康富硒茶”产业招商引资和品牌宣传推介；市商务局、市供销社负责“安康富硒茶”线上线下市场体系建设、产品商贸流通与销售；市科技局、市富硒研发中心负责加强与高层次科研机构、人才合作，为“安康富硒茶”产品开发和产业发展提供技术支撑；市文广局负责“安康富硒茶”文化发掘提升；市旅发委负责在旅游产品营销中加强“安康富硒茶”公用品牌宣传，促进茶旅融合发展；市茶业协会负责加强行业自律和品牌使用与管理等；市统计局、市扶贫局和金融、保险等涉茶发展部门（单位）都要各司其职、各尽其责、共促发展。

（二）加大政策扶持。市级财政每年安排不少于300万元的专项资金用于“安康富硒茶”品牌宣传、品牌维护、展销推介和市场监管等工作；在同等条件下对积极使用“安康富硒茶”公用品牌的茶叶生产经营企业优先对外宣传推介企业产品、优先支持创建命名和表彰奖励、优先倾斜支持基础设施配套建设、优先申报扶持项目资金等。各县区都要按照市政府统一安排积极开展品牌整合工作，并安排一定的财政专项资金，支持“安康富硒茶”品牌使用企业开展公用品牌宣传和市场营销。

（三）加大龙头培育。坚持梯次培育，加大“安康富硒茶”龙头企业培育力度，通过3-5年努力，全市培育1-2家国家级茶叶龙头企业、30家省级茶叶龙头企业、100家市级茶叶龙头企业；坚持园区承载，加快推进高标准茶园建设，3-5年内，全市建成130个市级以上茶叶示范园区。同时，以企业为主体、资本为纽带，运用市场化手段，通过招商引资、企业兼并重组等方式，积极推进大型茶叶集团公司、茶产业发展联盟和专业合作社联合社组建，形成以企业为主体的“安康富硒茶”品牌运营管理体制机制，促进富硒茶产业持续健康发展。

（四）加强品牌保护。市、县区茶叶主管部门和市场管理部门要协同加强品牌建设与管理；市茶业协会依据《安康富硒茶地理标志证明商标使用管理办法》授权企业使用“安康富硒茶”地理标志证明商标，审核包装设计制作，配合行业和市场管理部门加强“安康富硒茶”商标使用管理；农林部门负责原料基地建设管理、“三品一标”认证管理、中国优秀茶叶区域公用品牌创建等；市场监督管理部门（工商、质监、食药监）负责省级名牌产品、中国驰名商标或知名品牌示范区创建，负责“安康富硒茶”地理标志证明商标专有权、产品质量监管和商标标识使用监管等，及时查处冒用、滥用“安康富硒茶”地理标志证明商标行为，维护“安康富硒茶”公用品牌形象。

（五）严格考核奖惩。市委、市政府将“安康富硒茶”品牌整合打造工作纳入市对县区、部门年度目标责任考核指标体系予以考核；市政府督查室对“安康富硒茶”品牌整合工作进行定期督办检查，确保“安康富硒茶”品牌整合工作有力有序推进。
