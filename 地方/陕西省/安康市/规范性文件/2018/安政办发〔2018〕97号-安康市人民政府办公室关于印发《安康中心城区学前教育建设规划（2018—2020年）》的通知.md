# 安康市人民政府办公室关于印发《安康中心城区学前教育建设规划（2018—2020年）》的通知

汉滨区人民政府，市政府各工作部门、各直属机构：

现将《安康中心城区学前教育建设规划（2018—2020年）》印发给你们，请认真组织实施。

安康市人民政府办公室

2018年10月25日

安康中心城区学前教育建设规划（2018—2020年）

为顺应城镇化发展及生育政策调整需要，全面提升安康中心城区学前教育的服务能力和水平，依据《安康市区学校中长期布局建设规划（2012—2020年）》、《“十三五”安康中心城区教育提升工程实施方案》及市人大常委会《关于对安康中心城区基础教育规划实施情况报告的审议意见》等要求，特制订《安康中心城区学前教育建设规划（2018—2020年）》。

一、规划背景

自“十二五”国家启动实施三期“学前教育行动计划”以来，市委、市政府高度重视中心城区学前教育发展，通过统筹规划、优化布局、整合资源、加大投入、改革创新、规范管理等举措，使中心城区学前教育资源快速扩大、办园条件不断改善，基本让群众子女有园上。截止2017年，安康市中心城区160平方公里规划范围内共有幼儿园77所，其中：公办幼儿园16所，民办幼儿园61所；在园幼儿总数20827人，其中：公办幼儿园3433人，附设学前班2539人，民办幼儿园14855人。江南片区42所，在园幼儿12491人；江北片区28所，在园幼儿5498人；高新片区7所，在园幼儿2838人。

随着城镇化步伐加快，城区人口快速增长，学前教育布局建设已难以适应群众需求，成为各类教育中的薄弱环节和最大短板。一是布局结构不合理。幼儿园布点主要集中在人口密集的新城和老城区，城东、城西、江北幼儿园布点少，群众子女入园不便。二是公办学前教育资源严重短缺。公办幼儿园占比为20.78%，公办园幼儿数占比为16.48%，其中江南城区公办幼儿园占比仅为13.33%。三是普惠性幼儿园占比低。2017年，中心城区普惠性幼儿园占比为25.97%，与省考核指标相差40.15个百分点，与全省规划2020年达到85%的要求差距更大。四是民办幼儿园办园设施简陋。城区大部分民办幼儿园办园条件不达标，存在缺少户外活动场地、教室拥挤、设备陈旧、班额超标、安全条件差等问题。五是学前教育投入不足。中省资金有限，市区财力紧张，难以投入更多资金用于公办幼儿园建设；幼儿园师资配备不足，相当数量的保教人员由幼儿园自行聘用，又导致办园经费紧张。因此，解决中心城区学前教育发展不充分不平衡的矛盾，已成当务之急。

二、总体要求

（一）指导思想。全面贯彻习近平新时代中国特色社会主义思想及党的十九大精神，坚持以人民为中心的发展思想，准确把握中心城区学前教育面临的新形势新要求，切实把中心城区学前教育作为补短板、惠民生的优先任务，强化规划引领，加大资金投入，推进改革创新，聚力攻坚克难，全面提升中心城区学前教育公共服务水平，努力办好群众满意的城区学前教育。

（二）基本原则：坚持统筹规划。坚持规划与城市发展、学龄人口增长相适应，依据学前教育的特点和规律，按照适度超前、方便入园、配套建设的原则，统一规划，合理布局。城东新区规划建设中必须保障公办幼儿园建设用地，旧城改造和住宅小区建设中必须按配置标准设置幼儿园，江南城区机关单位北迁腾退公共资产优先用于改建公办幼儿园。坚持公益普惠。强化学前教育公益普惠导向，加大公办幼儿园的建设力度，积极扶持普惠性民办幼儿园的发展，中心城区新增学前教育资源以设立公办幼儿园和民办普惠园为主。坚持因地制宜。结合中心城区规划建设的实际，江南主城区和江北建成区主要以可用公产资源改建和小区配建为主，城东、城西、江北和安康高新区等新开发区的片区、小区以配套新建幼儿园为主，努力扩大学前教育资源总量。坚持优质发展。以加强教师队伍建设、幼儿园课程建设、办园质量监测机制建设和推进家园共育为重点，加强幼儿园内涵建设，提升薄弱幼儿园的办园质量，全面提升幼儿园办园等级。

（三）预期目标。通过实施中心城区学前教育建设工程，新建、改扩建一批公办幼儿园、居民小区配建幼儿园，扶持一批民办幼儿园提供普惠性学前教育服务，力争到2020年，中心城区学前教育学位基本满足需求，普惠性幼儿园占比提高到45%以上，“入园难”“入园贵”问题得到缓解。

三、主要任务

（一）加大公办幼儿园建设力度。规划新建东坝社区幼儿园、陈家山幼儿园、张滩镇奠安幼儿园和水电三局幼儿园；迁建吉河镇幼儿园和建民办长岭幼儿园；利用闲置校舍和资产改建关庙镇劳动幼儿园、砂石厂幼儿园、西坝幼儿园、江北办中心幼儿园和黄沟幼儿园；改扩建市幼儿园、市第二幼儿园和汉滨区铁路幼儿园。新建、迁建和改扩建园舍面积4.87万平方米及购置设备玩教具等，计划总投资14002万元。预计到2020年规划项目完成后，新增幼儿班数93个，新增幼儿学位2654个。

（二）加强小区配套幼儿园建设。规划居民小区配建幼儿园9所，新建园舍面积5.19万平方米及购置设备玩教具等，计划总投资20550万元，规划项目完成后，预计新增幼儿班数68个，新增幼儿学位2040个。

（三）鼓励社会力量办园。坚持“积极鼓励、大力支持、正确引导、依法管理”的方针，探索多元化办园形式，支持具有一定规模、质量较高、办园条件好的民办幼儿园做强、做优，满足人民群众不同层次的学前教育需求。计划新建、改扩建民办园5所，园舍建筑面积1.23万平方米及购置玩教具等，计划总投资4440万元；扶持认定普惠性民办幼儿园17所，计划投资1326万元。规划项目完成后，预计新增幼儿班数17个，新增幼儿学位510个。

四、保障措施

（一）加强组织领导。市政府中心城区学校建设工作联席会议将学前教育基础设施建设作为重点内容，加强组织协调。汉滨区政府、安康高新区管委会要将学前教育作为教育发展的重点，摆上政府工作重要议程，制定专项方案及年度计划，实行目标责任管理，强力推进实施。

（二）明确工作责任。按照“市级统筹、以区为主”的原则，明确中心城区幼儿园规划、建设、管理的责权关系。市政府统筹中心城区幼儿园的布局规划，负责市直属幼儿园的建设与管理；汉滨区政府、安康高新区管委会是本辖区学前教育发展的责任主体，负责辖区内城区幼儿园的建设与管理。市级相关部门要认真履行职责，加强协作配合，共同推进建设规划的实施。

（三）加大经费投入。中心城区中小学幼儿园建设资金筹措以区为主，市级从中省专项资金给予补助，并优先重点安排。汉滨区政府和安康高新区管委会要落实好教育投入政策，优化财政教育支出结构，重点向城区幼儿园建设项目倾斜；同时要切实加大对学前教育师资队伍、内涵发展、质量提升方面的财政经费保障力度。

（四）落实小区配建政策。规划、教育、财政等部门要认真落实中省关于城镇小区配套幼儿园要与小区同步规划、同步建设、同步交付使用的政策规定。未按规定安排配套幼儿园建设的小区规划不予审批。小区配套幼儿园建成后，要作为公共教育资源交付当地政府统筹安排，举办公办幼儿园或委托办成普惠性民办幼儿园，优先满足小区居民子女的入园需求。

（五）推进民办普惠认定。汉滨区和安康高新区要制定出台政府购买服务扶持政策，加大政府购买学前教育服务力度，积极推进普惠性民办幼儿园的认定工作，确保普惠园占比目标如期实现。

（六）强化监督检查。加强过程调度，按照“项目化、时间表、责任人”的要求，对学前教育专项建设项目规划的实施情况进行专项检查，列入年度目标责任考核，年初下达任务指标，年中开展督促检查，年底进行考核总结，实行项目进度月报告制度，及时掌握项目建设进展情况，确保项目建设按照时间节点顺利推进。
