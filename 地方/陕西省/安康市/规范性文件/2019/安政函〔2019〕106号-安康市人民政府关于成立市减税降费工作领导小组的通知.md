# 安康市人民政府关于成立市减税降费工作领导小组的通知

各县区人民政府，市政府各工作部门、直属机构：

为做好我市减税降费工作，市政府决定成立市减税降费工作领导小组。组成人员如下：

组 长：赵俊民 市长

副组长：王 刚 常务副市长

成 员：陈伍文 市政府秘书长

阮家军 市政府副秘书长、办公室主任

廖良成 市发展改革委主任

许启政 市工业和信息化局局长、国资委主任

许启汉 市民政局局长

石昌林 市财政局局长

汪小卫 市人力资源和社会保障局局长

刘家骐 市商务局局长

张宗富 市市场监管局局长

张大峰 市税务局局长

王 宁 人民银行安康中心支行行长

领导小组办公室设在市财政局。办公室主任由市财政局局长石昌林同志兼任。

安康市人民政府

2019年6月5日
