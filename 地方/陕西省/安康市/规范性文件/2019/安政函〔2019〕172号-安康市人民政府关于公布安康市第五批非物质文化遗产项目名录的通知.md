# 安康市人民政府关于公布安康市第五批非物质文化遗产项目名录的通知

各县区人民政府，市政府各工作部门、直属机构：

按照《中华人民共和国非物质文化遗产法》和《陕西省非物质文化遗产条例》相关规定，经申报、评审、公示等程序，现将“旬阳牌鼓”等四大类20 个项目列入安康市第五批非物质文化遗产项目名录并予以公布。

安康市人民政府

2019年8月22日
