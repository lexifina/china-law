# 安康市人民政府关于命名2018年度市级卫生镇卫生村和卫生先进单位的通报

各县区人民政府，市政府各工作部门、直属机构：

2018年，全市各级各部门坚持“政府主导、部门协作、科学指导、群众参与”的原则，积极推进卫生创建工作，着力解决人民群众生产生活中的突出问题，城乡环境面貌持续改善，卫生基础设施不断完善，人民群众健康水平显著提高，卫生创建工作取得明显成效。为表彰先进，树立典型，市政府决定命名汉滨区叶坪镇等3个镇为市级卫生镇，汉滨区谭坝镇惠坪村等73个村为市级卫生村，汉滨区县河幼儿园等16个单位为市级卫生先进单位。

希望被命名的卫生镇、卫生村和卫生先进单位珍惜荣誉，不断努力，巩固成果，再创佳绩。各级各部门要以先进为榜样，深入开展新时期爱国卫生工作，切实推进城乡环境卫生综合治理，努力建设健康环境，积极开展健康细胞示范建设，为加快推进健康安康建设做出新的更大的贡献。
