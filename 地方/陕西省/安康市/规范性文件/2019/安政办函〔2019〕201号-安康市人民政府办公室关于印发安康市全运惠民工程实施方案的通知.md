# 安康市人民政府办公室关于印发安康市全运惠民工程实施方案的通知

各县区人民政府，市政府各工作部门、直属机构：

《安康市全运惠民工程实施方案》已经市政府同意，现印发给你们，请结合实际认真贯彻落实。

安康市人民政府办公室

2019年9月18日

安康市全运惠民工程实施方案

2021年第十四届全国运动会（以下简称十四运会）将在我省举办，届时我市将承办武术（散打）和10公里马拉松游泳项目。省政府决定在十四运会筹办期间协同推进“全运惠民工程”，根据《陕西省全运惠民工程实施方案》有关要求，结合我市实际，特制定方案如下。

一、目标任务

到2021年，市、县基本公共体育设施力争实现全覆盖，人均体育场地面积达到1.8平方米；群众健身意识普遍增强，经常参加体育锻炼的人数比例达到40%；全民健身赛事活动更具吸引力，群众参与度更加广泛；健身组织体系更加完善，协会、俱乐部数量大幅提升，达到每千人有2名社会体育指导员的目标；科学健身指导服务明显提升，积极建设市县两级国民体质监测与科学健身指导站点，国民体质监测工作经常化，测试群众突破3万人次。

二、重点任务

（一）健身设施惠民。

1.健全市县基本公共体育设施。大力推进安康市体育馆建设，力争2020年6月建成投用，实现市级场馆“四个一”，即市级拥有一个体育场、一个体育馆、一个游泳馆、一个国民体质监测中心。推动实现县级场馆“四个一”，即一个体育场、一个全民健身中心或社区健身中心、一个室外运动场地、一个国民体质监测和科学健身指导站。目前我市石泉县、平利县、宁陕县已实现县级场馆“四个一”，其他各县区均有不同程度欠缺。各县区要聚焦各自短板，重点发力，补足欠账。（市教体局牵头，市发改委、市财政局参与，各县（区）政府、管委会负责落实，以下各项任务均需各县（区）政府、管委会承担，不再列出）

2.完善群众身边的健身设施。围绕建设15分钟健身圈的目标，建设一批体育公园、健身步道、社区多功能健身场地、社区健身中心，对现有的公园、广场进行改造，增加必要的体育设施，在农村人口聚集点实施农民体育健身工程。我市新建3个体育公园、30个社区多功能健身场地，5个社区健身中心，每个县区建设不少于100公里的健身步道和一定数量的农民体育健身工程。（市教体局牵头，市发改委、市自然资源局、市住建局参与）

3.推进全民健身重点工程。实施好汉江全民健身长廊和秦岭健身步道项目，在现有基础上完善规划、统筹资源、集中力量，同步建设各种体育设施和其它配套设施。全市新建足球、篮球等健身场地30块，自行车道200公里，安装体育器材600件，打造成集体育健身和休闲旅游为一体的民生工程。（市教体局牵头，市发改委、市财政局、市水利局、市自然资源局、市住建局、市林业局参与）

4.提升体育场馆设施智能化水平。推动全国试点旬阳县党家坝智慧健身中心的设施完善和优化运营工作。依托互联网和新科技，对具备条件的体育设施增加智能化系统，运用智能技术增添健身运动的便捷性、趣味性和吸引力。（市教体局牵头，市工信局参与）

（二）组织服务惠民。

1.完善体育组织网络体系。进一步健全以体育部门为主导，以事业性体育机构为骨干，以社团性体育组织为助手，以群众性体育健身组织为基础的全民健身组织体系。按照“4+X”（即体育总会、社会体育指导员协会、老年人体育协会、农民体育协会，若干单项体育运动协会）模式，扩大协会数量，力争全市县级体育总会实现全覆盖，每个县区新培育2至3个基层体育社团，基本实现全市乡镇、街办体育工作规范化。采取政府购买服务的方式，持续加大对协会的支持力度，推进协会实体化进程。（市教体局牵头，市民政局、市农业局参与）

2.加强社会体育指导员队伍建设。采取配备服装、培训学习等方式予以激励，不断扩大社会体育指导员数量，提升其服务能力。各县区每年新增三级社会体育指导员不少于30人，到2020年底，实现全市每千人拥有2名社会体育指导员的目标。规范社会体育指导员管理，形成组织落实、结构合理、覆盖城乡、服务到位的全民健身志愿服务队伍。（市教体局牵头）

3.开展科学健身指导服务。完善市、县区两级国民体质监测体系，加强县级国民体质监测站建设。到2020年底，实现全市县区国民体质监测体系全覆盖，推进国民体质监测工作常态化。推进全民健身和全民健康深度融合，做好医生开具运动处方培训工作，更好服务群众科学健身。（市教体局牵头，市卫健委参与）

4.鼓励俱乐部发展。鼓励和引导社会资金投资健身服务业，充分发挥健身俱乐部在服务、推广、培训等方面的作用，不断提升其承接全民健身服务的能力和水平。积极开展国家级示范性青少年体育俱乐部创建工作，探索“俱乐部+体传校+训练基地”模式，通过“以奖代补”等形式扶持青少年体育俱乐部发展。（市教体局牵头，市民政局参与）

（三）赛事活动惠民。

持续打造“秦巴明珠·幸福安康”体育赛事品牌。以群众性、竞技性、区域性和开放性为目标，市级重点组织好汉江龙舟节龙舟赛、中国大秦岭（宁陕）山地越野挑战赛、环秦岭自行车联赛、群众足球（篮球、羽毛球）联赛等赛事活动。以小型、分散、多样为原则，办好岚皋“南宫山之旅”品牌赛事、“秦楚边城·水色白河”系列赛事、旬阳太极系列赛事等“一县一品”“一镇一特色”体育赛事活动，让更多的群众参与到赛事活动中来，带动全民健身活动开展。广泛开展“我要上全运·健康安康人”系列活动，采取线上线下相结合的方式，充分调动群众参与的积极性，营造全社会关注、支持全运会的浓厚氛围。深入开展“全民健身进基层”活动，推动政府机关、企事业等单位实行工间健身制度，提升科学健身意识，树立健康生活方式。（市教体局牵头，市总工会参与）

（四）体育文化惠民。

大力倡导“全民全运、全运惠民”理念，传承和弘扬奥林匹克精神和中华体育精神。加强和媒体沟通合作，打造体育宣传精品节目，扩大安康体育品牌赛事的影响力。深入挖掘整理具有安康特色的武术、龙舟、“翻天印”、“板凳龙”等民间传统体育项目并进行推广，充分展示富有地方特色的体育文化新风采。积极开展“最美体育人”评选、“奥运冠军进校园”等活动，传播体育文化，弘扬体育精神。（市教体局牵头，市委宣传部、市文旅广电局参与）

（五）场馆开放惠民。

全面推动公共体育场馆免费或低成本对外开放，满足群众就近健身的需求。推进学校体育设施向社会开放，在保障安全和教学的前提下，加大学校体育设施开放力度。逐步研究制定开放方法，促进有条件的企事业单位体育场馆设施在业余时间面向公众开放。（市教体局牵头，市国资委、市公共资产管理局、市总工会参与）

三、组织保障

（一）强化组织领导。各县区、各部门要高度重视“全运惠民工程”，抓好工作落实，制定实施方案，明确任务、分工、步骤，确保全运惠民工程深入推进。

（二）落实各项保障。各县区要整合项目，统筹安排好资金保障。市级各相关部门要根据职责和任务，研究制定配套措施，确保工作扎实推进。各项惠民工程项目均以县区投入为主，省市奖补为辅。积极引导社会资本建设各类体育设施，形成政府主导、部门协同、社会参与的良好机制。

（三）加大宣传力度。采取多种方式，做好全运惠民工程的宣传，引导群众广泛参与各类健身活动，为十四运会成功举办营造浓厚社会氛围。
