# 安康市人民政府办公室关于做好2020年寒假大学生到政府机关见习工作的通知

各县区人民政府，市政府各工作部门、直属机构：

按照《陕西省人民政府办公厅关于做好2020年寒假大学生到政府机关见习工作的通知》（陕政办函〔2019〕191号）要求，现就做好我市2020年寒假大学生到政府机关见习工作通知如下：

一、时间安排

市级机关见习时间安排:

2019年12月30日－2020年1月9日 发布公告、报名遴选

2020年1月16日－2020年2月7日 学生见习

各县区结合本地实际自行确定报名遴选及见习时间。

二、见习单位

市级机关见习工作在市政府各工作部门、直属机构开展。

各县区政府自行确定本地开展见习工作的部门和单位。

三、报名条件

（一）到市级机关见习的学生须符合以下条件：

1.安康学院和安康籍全国普通高校大二、大三本科生和非毕业学期在读全日制硕士、博士研究生。

2.思想品德良好、身体健康、成绩优良、综合素质较高。无违法犯罪记录，未受任何处分。

3.能够保证充足的见习工作时间。

4.能够自行解决见习期间的食宿问题。

为让更多大学生有机会参与见习活动，参加过往期市政府机关见习活动的学生，不得报名参加本次市政府机关见习活动。

（二）各县区结合本地实际自行确定本地见习学生的报名条件。

四、遴选工作

遴选工作本着“自愿报名、统一组织”的原则开展，坚持公开、公平、公正。

市级机关本次接收50名大学生（公开遴选45名，安康学院推荐5名）参加见习活动，通过安康市政府网站公开发布遴选公告。

各县区接收见习大学生不少于30名，通过本县区政府门户网站公开发布遴选公告。

五、责任分工

（一）市级机关见习工作由市政府办公室牵头，团市委负责见习大学生遴选、组织、协调、管理等工作；市人社局负责见习生岗前培训工作；市财政局负责为见习生购买人身意外伤害保险，发放见习补助（市级机关见习生每人500元，各县区可自行确定标准）；市机关事务服务中心负责做好见习相关保障；市政府网站负责做好报名遴选网络技术服务；接收单位具体负责见习生的日常管理。

(二)各县区应明确牵头部门，制定本县区实施方案，于2020年1月10日前报市政府办公室备案。

六、工作要求

（一）高度重视大学生见习工作。各县区和安康学院在遴选过程中要坚持公开、公正、公平的原则，广泛宣传，择优遴选。接收单位要合理安排见习岗位，提供适当的工作条件，安排专人指导，安排见习生到基层调研，加深见习生对安康基本市情的认识和思考；不得安排见习生承担春节等法定节假日值班工作。

（二）要严格按照《安康市大学生假期到政府机关见习管理办法（试行）》（安团发〔2019〕43号）要求做好日常管理，接收单位要教育引导大学生遵守各项规章制度，注意人身财产安全，注意自身形象，自觉接受管理。

（三）见习结束时，每名见习生撰写一份1500字左右的见习总结，填写《见习考核表》，由见习单位签署意见后，交本级政府见习组织单位备案（市级机关见习生交团市委备案，由市政府办、团市委负责对完成见习的大学生发放见习证书）。

（四）请各县区政府、团市委于2020年2月底前分别推荐3-5篇优秀见习文章（文章内容形式不限），报市政府办公室。
