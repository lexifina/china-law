# 安康市人民政府办公室关于2018年度政务公开工作绩效评估情况的通报

各县区人民政府，市政府各工作部门、直属机构：

为进一步加强政务公开和政府网站建设，经市政府同意，市电子政务办公室引入第三方评测机构，按照《安康市人民政府办公室关于印发2018年政务公开工作绩效评估指标的通知》（安政办函〔2018〕305号）要求，对各县区、各部门政务公开和政府网站建设工作组织开展了绩效评估活动。现将评估结果及有关情况通报如下：

一、评估情况

本次纳入绩效评估范围的县区和市直部门共57个，其中县（区）级政府网站13个(含派出机构)，市政府部门、直属机构44个；县（区）政府、市政府部门政务微博30个、政务微信42个。评估主要从政府信息公开、解读回应参与、政务服务、平台建设、制度化规范化建设、组织保障6个方面进行综合评估。从整体评估情况来看，我市政府网站规范管理、监管成效、公开水平、服务能力明显提升，主要表现在：

（一）政府网站规范建设和监管成效明显。网站建设管理富有成效，网站的开设、下线、备案、名称、域名、徽标、宣传语、使用地图、页面布局、栏目设置、信息发布、集约建设规范水平稳步提升。常态监管持续发力，政府网站季度自查、检查、督查、问责机制全面落实，创新培训学习、互查互学措施有力，全年共约谈5家不合格网站主管单位负责人，15个网站主办单位19人脱岗参加跟班培训学习，有效增强了问题网站和政务新媒体的整改效果。引入第三方开展监测评估，空栏目、更新不及时、信息不准确、服务不实用、错字词错链接等问题明显减少。全市60家政府网站连续11个季度顺利通过国办每季度一次的专项检查。石泉县突出展现热门服务主题，平利县“脱贫攻坚”专栏紧扣工作、分类清晰、内容详实，市水利局立足职责设置水雨情查询、水利百科等行业特色栏目，市国土局增设无障碍浏览功能，这些网站功能建设的好做法应予肯定。

（二）政务公开深入推进。各单位充分发挥政府网站政务公开第一平台作用，推进决策、执行、管理、服务、结果“五公开”，着力推动政府权力运行各流程环节公开的模式初见成效。关乎群众利益和公众关切的多个重点领域信息公开持续加强，增强了群众的获得感、认同感。充分发挥政务微信、微博、客户端等新媒体优势，多形式推进政务公开，节省了政务公开成本，拓宽了群众参政议政渠道。个别网站优化了检索功能，功能涵盖“标题、时间、正文、新闻、服务、互动、微信、微博、图片”等多类选择功能，以信息检索的精准度，满足了群众查询需求。市财政局按照“四统一”要求，采用“2+N”（2个集中公开平台+N个部门门户网站）的方式强力推进部门决算公开，社会反响良好。

（三）服务水平稳步提升。市政府网站搭建统一的互动交流平台，实现留言评论、在线访谈、征集调查、咨询投诉等功能，通过多种形式听取民意、了解民愿、汇聚民智，积极回应关切、引导舆论，成为正能量传播、政策宣传、政务服务输出的重要平台。“市长信箱”栏目共受理有效信件4817件，办结率97.9%。深入推进“互联网+政务服务”，推进各县区各部门政务服务平台规范化、标准化、集约化建设和互联互通，形成全市政务服务“一张网”。公开了“马上办、网上办、就近办、一次办”事项清单，向公众提供213 项“马上办”、857 项“网上办”、58 项“就近办”、310 项“一次办”事项服务。紫阳县推出手机APP“指尖政务”，全县130项行政审批服务事项在手机端即可完成“一网通办”，实现群众办事“零跑路”。

二、存在问题

（一）保障机制不到位。个别县区和部门对政务公开、政府网站、政务新媒体建设重视不够，重建设轻管理，常态化监管责任落实不及时、不到位，网站安全管理严重缺位；网站季度自查履责不实，栏目内容更新不及时、错字词错链接等现象仍然存在。部分政府网站主管单位公开“政府网站工作报表”不及时。市教育局、市卫计局、紫阳县司法局、紫阳县交警大队、紫阳县招商局5家政务微信，市科技局、市住房公积金管理中心2家政务微博存在“僵尸化”倾向。岚皋县没有按要求监督四季镇注销已下线网站域名的注册信息。

（二）信息公开落实力度不够。部分县区和部门信息公开工作力量薄弱，公开意识不强，与群众切身利益、方便群众办事、群众关心关注的信息公开不规范、不及时、不全面；信息公开审核不严，部分规范性文件未标注有效期，未公开文件修改、废止、失效情况。个别县和部门权力运行和重点领域公开落实不到位，依申请答复存在不及时、不规范等问题；不能适应互联网发展变化和公众使用习惯，推进政府网站向移动终端、自助终端、热线电话、政务新媒体等多渠道延伸，为企业和群众提供多样便捷的信息获取和办事途径。瀛湖管委会、恒口管委会政务公开、解读回应栏目建设不合格，白河县政府未开通政务微信，镇坪县政府政务微信、微博均未开通。市商务局网站未提供信息公开指南，未设置依申请公开栏目，自查整改流于形式，网站空白链接问题仍然未整改。

（三）服务能力仍有差距。部分县区和部门对本级政策文件解读比例较低，解读形式单一；回应社会热点不及时，回复留言存在敷衍推诿、答非所问等问题；没有主动依托上级门户网站积极开展意见征集、民意调查、在线访谈活动。部分单位公布的办事服务事项，与纳入本级行政权责清单、公共服务事项清单事项不一致，服务事项要素缺失或不准确。汉滨区、旬阳县政府网站办事服务主题空白较多，镇坪县、石泉县、汉阴县政府网站互动功能不完整，未提供满意度评价。市民宗局网民留言回复不规范，市林业局未设置政务咨询类栏目。

三、工作要求

各县区、各部门要进一步贯彻落实《国务院办公厅关于印发政府网站发展指引的通知》《国务院办公厅关于推进政务新媒体健康有序发展的意见》《国务院办公厅关于加强政府网站域名管理的通知》要求，认真研读分析第三方评估报告，排查问题，立行立改，不断提升政府网上服务能力，建好管好用好政府网站。

（一）夯实措施，加强常态监管。各县区、各部门要按照中省市相关要求，切实做好政府网站和政务新媒体的科学规划、组织保障、规范建设、内容监管、安全防护，落实政府网站常态监管机制，规范域名和备案信息注册注销程序，推进政府网站和政务新媒体健康、稳定运行。1月22日前公开和上报政府网站工作报表，并全面完成已下线政府网站域名、ICP备案等信息排查清理工作，启动域名和其他备案信息注销程序。1月30日前完成2019年一季度网站和政务新媒体自查并公开结果。2月1日前公开和上报政府信息公开年度报告。

（二）深化政务公开，提升服务水平。要加强政务公开组织机构建设，多形式、多渠道深化以权力运行、重点领域信息、依申请公开为重点的政务公开，强化对个人隐私的保护。要落实政策解读、互动回应制度，政策文件起草部门要提高对重要政策文件的解读比率，文件正式印制3日内要在本单位和同级政府门户网站公开解读材料。要主动在上级门户网站积极开展意见征集、民意调查等活动。要及时回应群众诉求和社会热点问题，对有关单位提供的回复内容出现敷衍推诿、答非所问等情况的，要予以退回并积极沟通，督促相关单位重新回复。要依托全国一体化在线政务服务平台，开展个性化、有特色的服务创新，推进线上线下深度融合，规范服务办事指南，优化完善政务服务平台功能，切实提升政务服务质量和效率。

（三）加强安全防护。加快推进政府网站集约化建设，落实网络安全等级保护制度，加强网站日常安全监测，定期开展网站安全检查和风险评估；积极采取必要措施，落实专人负责，落实追责问责机制，做好防攻击、防篡改、防瘫痪、防泄密等安全保障工作，加强节假日值班值守，确保网站稳定、可靠、安全运行。
