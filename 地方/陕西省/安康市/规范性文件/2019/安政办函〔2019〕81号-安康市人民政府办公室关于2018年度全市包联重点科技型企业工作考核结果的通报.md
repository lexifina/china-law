# 安康市人民政府办公室关于2018年度全市包联重点科技型企业工作考核结果的通报

各县区人民政府，市政府各工作部门、直属机构：

2018年，按照市政府包联重点科技型企业的部署要求，市级各包联单位全力以赴为所联企业办实事解难题，助推企业科技创新取得新的成效。各包联单位累计筹措资金2.8亿元，推动新建省级科技企业孵化器1家，组建市级工程技术研究中心4个，转化科技成果12项，研制新产品15个，申请发明专利269件，认定高新技术企业16家，入评国家级科技型企业156户，为推动经济高质量发展发挥了重要作用。

依据《2018年全市包联重点科技型企业工作实施方案》及其考核办法（安政办发〔2018〕24号、376号），市科技局牵头对50个包联单位2018年的工作进行了考核，经市政府同意，现将考核结果通报如下：

市发改委、市科技局、市工信局、市教育局、市民政局、市审计局、市财政局、市人社局、市环保局、市住建局、市城管局、市水利局、市农业局、市林业局、市食药监局、市扶贫局、市商务局、市卫计局、市统计局、市安监局、市移民局、市旅发委、市招商局、团市委、市科协、市总工会、地电安康分公司、农行安康分行、工行安康分行29个单位为优秀格次。

市司法局、市国土局、市交通局、市文广局、市质监局、市工商局、市税务局、市工商联、市供销社、市公积金中心、安康供电局、中国银行安康分行、人行安康中心支行、信合安康办事处、邮储银行安康分行15个单位为良好格次。

市银监局、农发行安康分行、建行安康分行、中石油安康分公司4个单位为一般格次。

2019年，是实施创新驱动发展战略和加快追赶超越的关键之年，全市上下要紧扣“追赶超越”定位和“五个扎实”要求，坚持“发展为要、生态立市、开放兴市、产业强市”实施路径，深化科技“三大创新工程”，扎实开展科技型企业包联工作，加快推动科技型企业和实体经济高质量发展，为建设西北生态经济强市作出新的贡献。

安康市人民政府办公室

2019年3月29日
