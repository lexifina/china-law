# 安康市人民政府办公室关于“市长信箱”办理工作调整事宜的通知

各县区人民政府，市政府各工作部门、直属机构：

按照市政府安排，自2019年4月1日起，“市长信箱”的日常管理工作由市政务服务中心负责。3月31日前收到的“市长信箱”信件按原程序和期限办理，4月1日后收到的信件按“12345”工单程序和期限办理。

安康市人民政府办公室

2019年4月8日
