# 安康市人民政府办公室关于印发2019年包装饮用水产业发展工作实施方案的通知

各县区人民政府，市政府各工作部门：

《2019年包装饮用水产业发展工作实施方案》已经市政府审定同意，现印发给你们，请认真组织实施。

安康市人民政府办公室

2019年4月19日

2019年包装饮用水产业发展工作实施方案

为深入贯彻落实市委四届七次全会、市政府全体会议和全市工业和信息化工作会议精神，促进全市包装饮用水产业快速发展，根据《安康市涉水产业发展行动计划（2017-2020年）》，现制定2019年工作实施方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，抢抓西部大开发、汉江生态经济带建设机遇，以量大质优水资源为依托，以招商合作、技改扩能、产品销售为重点，加快推进地理标志保护产品、证明商标的申报认证工作，聚力开展资源勘探、水源保护、检验检测、品牌建设、链条延伸等工作，努力做大做强全市包装饮用水产业，为加快建设西北生态强市作出新贡献。

二、目标任务

积极推进2个地理标志（保护产品、证明商标）申报认证，组织开展2种资源（含硒水、富硒水）普查详查，引进2家知名水企来安康合作开发，完成2个以上技改扩能项目，举办2次专题推介活动，新发展2户包装饮用水企业，新培育2户规模以上企业，确保全市包装饮用水产业产值增速达到25%以上。

三、重点工作

1.推进地标申报。切实加强与中省部门的沟通协调，督促和指导市包装饮用水产业协会推进“安康硒水”地理标志保护产品、证明商标申报工作，力争在12月底前进入地理标志申报公示阶段。（市市场监管局负责，市工信局配合）

2.开展资源勘探。在全市范围内组织开展包装饮用水资源普查详查，强化数据收集与整理，查找可供开发利用的水源地，建立可供投资商直接开发利用的含硒水、富硒水资源数据库。（市自然资源局负责，市富硒产业办配合）

3.加强水源保护。建立健全饮用水源地水质监测网络和水污染预警体系，加强日常执法监管，坚决依法打击各类污染水资源、破坏水环境的行为，确保包装饮用水企业的水源地水质安全稳定。（市生态环境局负责，市水利局配合）

4.扩大招商引资。全年至少引进2家知名水企来安康开展合作，通过嫁接知名品牌、参股并购合作或联合开发等方式，扩大全市包装饮用水经济总量，不断提高“安康硒水、健康好水”知名度。（市工信局负责，市招商和经济合作局配合）

5.鼓励技改扩能。强化土地、环评、融资等要素保障，鼓励市场前景好的包装饮用水企业（全年不少于2家）采用新技术、新工艺、新设备，实施技术改造，扩大生产规模，发展相关产业，延伸产业链条。（市工信局负责，各相关单位配合）

6.强化检验检测。建立安康市包装饮用水产品质量定期检测、检测费用财政补贴等制度，定期对全市包装饮用水产品质量进行检测，严把产品质量关，切实维护好“安康硒水、健康好水”的品牌形象。（市市场监管局负责，市财政局等相关单位配合）

7.加强品牌建设。大力实施质量强市战略，鼓励和支持包装饮用水企业走优质发展、以质取胜的路子。突出“安康富硒水”，建立政府支持、企业做市的品牌推进格局。充分发挥市包装饮用水产业协会作用，加强行业自律，着力打造“安康硒水、健康好水”公共品牌。（市市场监管局负责，各相关单位配合）。

8.开拓产品市场。紧盯大中城市和南水北调受水区、缺硒区，特别是京津冀、雄安新区等重点区域，组织开展安康包装饮用水专题推介活动，力争全年不少于2次。持续向国家部委、省市部门推介使用安康包装饮用水，倡导地方党政机关、企事业单位在同等市场条件下优先采购使用地方包装饮用水产品，全力支持本地包装饮用水进商场、进超市、进酒店。（市工信局负责，各相关单位配合）

9.延伸产业链条。依托安康优质水资源，支持做大做强现有白酒企业，突破发展以果酒为主的其他酒制造业。积极发展果汁、植物蛋白等其他饮品制造业，探索发展食品、保健品、化妆品等大健康产业，配套发展饮料和酒的包装业，不断延伸产业链条。（市发改委、市工信局分工负责，各相关单位配合）

10.做大规模总量。强化协调服务，吸引民间资本投资包装饮用水产业，全年新发展包装饮用水企业2户以上。加大规模企业培育力度，全年新培育规模以上包装饮用水企业2户以上，全市包装饮用水产业总产值增速达到25%以上。（市工信局负责，各相关单位配合）

四、保障措施

1.强化包联包抓。由市工信局负责，把投资5000万元以上的包装饮用水新建（技改）项目和重点包装饮用水企业纳入全市重点工业企业包联包抓范围，督促包联单位加强指导，帮助企业解决项目建设和生产经营中存在的困难问题。

2.加大财政支持。由市工信局牵头，市财政局配合，从市级产业引导基金中拿出一定的资金，支持包装饮用水企业实施技改扩能、市场开拓、水源保护和品牌培育等，并优先推荐符合条件的包装饮用水企业申报中省项目资金支持。

3.建立联动机制。各县区、各有关部门要围绕方案明确的任务，认真抓好落实工作。市级各牵头单位是任务落实的主体，要依据责任分工，扎实开展工作。各配合单位要积极支持，共同发力，形成合力。市工信局要加强督促检查，确保各项工作落实到实处，工作推进情况要定期通报。
