# 安康市人民政府办公室关于张宇同志工作分工的通知

各县区人民政府，市政府各工作部门、直属机构：

经研究并报市委审核同意，现将张宇同志分工通知如下：

张 宇（市政府副秘书长〔挂职〕）：负责苏陕交流对口帮扶工作；协助谢奎同志联系杨淼同志及分管方面工作；协助分管市政府办公室政府职能转变协调办公室。

市政府办公室其他领导同志分工不变。

安康市人民政府办公室

2019年8月20日
