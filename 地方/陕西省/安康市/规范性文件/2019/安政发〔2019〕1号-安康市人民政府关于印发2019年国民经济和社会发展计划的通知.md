# 安康市人民政府关于印发2019年国民经济和社会发展计划的通知

各县区人民政府，市政府各工作部门、直属机构：

《安康市2019年国民经济和社会发展计划》已经市四届人大五次会议审议批准，现予印发，请遵照执行。2019年各专项计划，由市发展改革委及有关部门组织下达实施。

安康市人民政府

2019年4月3日

安康市2019年国民经济和社会发展计划

一、总体要求

以习近平新时代中国特色社会主义思想为指导，紧扣“追赶超越”定位和“五个扎实”要求，全面贯彻中央经济工作会议、省委十三届四次全会、市委四届七次全会精神，认真落实“五个坚持”和“五新战略”，大力发展“三个经济”，坚定践行“发展为要、生态立市、开放兴市、产业强市”，统筹推进稳增长、促改革、调结构、惠民生、防风险、保稳定工作，敢创一流、敢挑重任、敢为人先，确保实现以高质量发展引领高速度增长，加快建设西北生态经济强市。

二、预期目标

全市生产总值增长9%，全社会固定资产投资增长12%以上，规上工业增加值增长13%以上，社会消费品零售总额增长11%；财政一般预算收入同口径增长6%，城乡居民收入分别增长8%和9%。居民消费价格指数控制在3%以内；城镇化率49.3%。完成省定主要污染物减排和节能降耗任务。实现22.9万贫困人口脱贫、9个贫困县区全部摘帽。

三、主要任务

（一）聚焦高质量发展，着力抓关键强支撑。立足稳中快进抓投资，扎实开展“项目攻坚年”活动。确保全社会固定资产投资增长12%以上，民间投资增长15%。抓实200个市级重点建设项目，完成年度投资490亿元。其中，续建项目112个，年度投资338亿元；新建项目88个，年度投资152亿元。扎实推进100个市级重点前期项目。实现安康机场年内首飞，开工建设西康高铁。加快阳安铁路复线和平镇、安岚、石宁高速公路建设以及汉王至洞河、石梯至张滩、安康至旬阳、旬阳至小河等干线公路改造提升。力推桐旬高速、月河快速干道、通用机场群、关中至安康750千伏输变电通道等前期工作。实施“四好农村路”建设，新改建整治通村组公路5662公里。加快建设800千伏特高压、月河、滨江输变电等16个电力项目，以及石泉年产3亿袋料理包生产线、高新国医健康科技产业基地等112个特色产业重点项目。创新项目策划运作机制，高质量储备一批利当前、管长远的重大项目。聚力园区做强增长极，安康国家高新区要聚焦新安康门户区建设和高新技术产业发展，加快金融聚集区建设，支持驻安金融机构总部北迁，建成秦岭大道、高新大道Ⅲ标段、康汇智能手机、量子康养机器人等项目，确保经济增速持续高于全市10个百分点以上；瀛湖生态旅游区要加快创建5A级景区，建成瀛湖渔港码头、渔文化旅游村和流水一号街区改造工程。实施莲花岛主题公园、流水生态农业采摘园、织女石景点改造提升。启动医养基地、航运文化体验街区和玉兴岛综合改造等项目，推动瀛湖国家级旅游服务业标准化由试点向示范转变；恒口示范区（试验区）要深化小城市综合改革试点与城乡一体化发展，抓好安贝斯毛绒玩具、星和宅配物流、宏鑫建工环保建材等产业项目，加快实施恒河水库建设、月河综治工程和“两馆一院”等项目，着力打造安康城市副中心；“飞地经济”园区要加大市域层面统筹力度，促进差异化发展，加快形成产业集群，全年签约项目30个，落地项目25个；旬阳省级高新区要加快推进富硒食药品产业园、智能（毛绒）玩具产业园、绿色植物提取循环产业园和领盛科技功能新材料产业基地等项目建设，大力发展绿色循环产业，积极争创一流省级高新区。强力启动新安康门户区建设，高质量编制建设性总体规划、控制性详细规划和各类专项规划。实行项目、用地和投资单列，完善“1+X”系列支持政策。强化公共服务能力，推动优质资源聚集，加快配套骨干路网，实施高铁站前广场、新经济产业用房、傅家河生态环境整治、三航纳米材料、柔性显示屏、金富康智能电子等重点项目，力促中央商务区、中央创新区重大产业项目落地，加快建设新经济引领区、空港经济区、新行政中心区、现代服务聚集区、秦巴特色产业区。

（二）聚焦有效供给，着力抓重点兴产业。做强特色农业，坚定富硒特色农业发展方向，以现代农业园区为集聚平台，推动三次产业融合发展。认真抓好富硒资源普查，扎实推进富硒产品研发、标准制定、企业培育和品牌建设，“硒博会”期间集中发布一批科研新成果。坚定发展生猪、茶叶、魔芋、核桃、生态渔业五大特色产业，因地制宜做优富硒粮油、蔬菜、鲜果、中药材、蚕桑等产业。推进“猪-沼-园”产业联盟标准示范区建设，稳定生猪出栏规模。加大富硒茶品牌整合力度，巩固提升20个良种茶叶繁育圃，新建改建优质茶园11万亩。推行魔芋标准化种植，建成全市种源基地和42个种芋繁育示范园，新增魔芋种植面积5万亩。创建核桃地方品种繁育示范园30个，新建核桃产业基地10万亩。狠抓生态渔业转型升级与品牌创建，保持水产品产量3.5万吨以上。持续推进“千村千园”工程，提升20个“航母园区”建设水平，培育认定市级农业园区55个。壮大绿色工业，以装备制造、新型材料、清洁能源、生物医药、纺织丝绸为重点，下功夫扩充总量、优化存量、提高质量。突出抓好普瑞达电梯、南水汽配、奥邦锻造、宝通专用车、高性能复合材料、绿色装配建材、方圆制药、北医大制药和旬阳、白河水电站等项目，夯实绿色工业增长点。以包装饮用水为重点，加强饮用水、茶饮料、酒类产业的深度开发，提升产业规模和产品质量、包装及营销水平，引进和培育产业龙头企业，巩固富硒饮品高速增长态势。挖掘安康兴桑养蚕缫丝的悠久历史和文化内涵，借助“鎏金铜蚕”国际影响力，带动纺织丝绸产业焕发新的活力。加大工业专项支持力度，持续做好企业帮扶工作。全年新建标准化厂房50万平方米，新增投资千万元以上入园企业50户，新增规模工业企业40户，规模工业增加值增长13%以上。提升现代服务业，实施现代服务业创新发展行动计划，坚持新兴和传统服务业同步，生产性和生活性服务业并重，加快现代服务业发展，培育壮大新型物流业态，建设一批组织化程度高、辐射力强、特色鲜明的物流园区。加快万达商业广场、天贸城配套功能区和天一城市广场二期等商业综合体建设。强力推进全域旅游发展，抓紧实施三年行动计划，支持石泉、岚皋、宁陕创建国家全域旅游示范县，加快创建南宫山、瀛湖5A级景区，打造一批特色旅游小镇和示范村。全年旅游综合收入增长11%以上，三产服务业增加值增长7.5%。

（三）聚焦乡村振兴，着力抓短板助脱贫。把实施乡村振兴战略作为总抓手，把决胜脱贫攻坚作为优先任务，更加注重脱贫攻坚与乡村振兴深度融合，突出基础设施、“两房”建设、产业就业等重点，持续加大“八办三组”和中省定点扶贫、苏陕扶贫协作、“三大帮扶体系”工作力度，确保实现9个县区脱贫摘帽、22.9万贫困人口稳定脱贫。全面完成2330个交通项目、717个水利项目、51个电力项目、107个村卫生室建设和易地扶贫搬迁安置、农村危房改造“两房”保障对象入住任务。夯实产业扶贫关键支撑，新建扩建农业园区210个、合作社360个、农业企业200个、工业企业50个、电商服务点10个、互助资金协会80个以上。组织贫困劳动力技能培训2.1万人，贫困人口转移就业4.18万人，实施避灾生态移民搬迁6000户。扎实推进乡村振兴先导工程，加快编制乡村振兴专项规划和实施方案，统筹非贫困村道路、水利、电力、通讯等基础设施建设。实施“十百千万”农业经营主体培育工程，新增职业农民1000人、市级农民专业合作社（家庭农场）100个、市级农业龙头企业30个以上。组织开展农产品加工示范园创建，培育一批规模农产品加工企业。全面落实“新社区工厂”扶持政策，以100户以上集中安置社区为重点，推动“新社区工厂”与“新社区工厂贷”全覆盖，力促毛绒玩具文创企业总量突破300家。实施农村人居环境整治“百村示范、千村推进”计划，积极开展农村卫生厕所改造行动，加快建设美丽宜居村庄，全年创建100个示范村，带动1000个村整村推进，打造10个农村垃圾分类和资源化利用示范点。

（四）聚焦生态建设，着力抓保护守底线。深入推进国家主体功能区、国家低碳城市试点示范建设，积极创建省级生态文明建设示范区。全力打好“青山、蓝天、碧水、净土”四场保卫战，全天候、全市域严管秸秆禁燃和禁放区内烟花爆竹禁燃，坚决取缔汉江网箱养殖，确保环境空气质量和地表水环境质量保持全省前列，汉江出境断面水质稳定达标。聚焦中省环保督察“回头看”反馈问题和秦岭生态环境整治问题，高质量实施整改，按期完成销号，进一步完善生态保护与环境治理长效机制。加强生态保护红线管控，抓好全市污染源普查。扎实推进汉江及其主要支流综合整治，抓好安康湖等重点区域和“三沿三边”区域绿化，建设56个镇污水垃圾处理项目，造林绿化50万亩，退耕还林15万亩，治理水土流失850平方公里。加快实施中心城市水环境PPP项目，建成江南再生水厂，开工建设中心城市生活垃圾焚烧发电项目。推动县区水环境PPP项目落地实施。积极争取天然气长输管线项目，推动“气化安康”工程向镇村延伸。加强环保执法日常监管和专项检查，加大联防联控联治力度，坚决制止和查处破坏生态环境行为。全年单位生产总值能耗下降3.2%，单位生产总值二氧化碳排放下降3.66%。

（五）聚焦城镇建设，着力抓管理提品质。强化以人为本的新型城镇化理念，以中心城市为引领，抓好规划建设管理关键环节，打造高品质的区域中心城市，建设有特色的小城镇。深入实施中心城市“湖城一体、疏解老城、重心北移”战略，统筹不同区域板块规划建设，编制完成中心城市道路系统专项规划和东南片区、月河口长春片区、火车站北片区、关庙片区控制性详细规划。完成汉江公园三期和黄沟东路、香溪路、白天鹅广场综合改造，加快建设北环线、长春路、西坝市政路网、汉江大剧院广场、鹭湾中央公园和火车站广场、重点棚户区改造等项目，扎实推进汉江人行景观桥建设以及汉江黄洋河大桥、316国道高新区周家沟桥、花园沟桥加宽改造。加强中心城市厕所建设管理和服务，新建公厕39座，改造41座；推动有条件的沿街机关单位、商业门店厕所免费开放，力促人员密集区域公厕布点半径小于500米。加强城市主干道治堵保畅和背街小巷改造提升，新建张岭、党校路、静宁南路、黄沟路4个集贸市场，组织实施50个社区（城中村）环境提升和200处背街小巷改造整修项目。加快打造城东新区产城融合创新示范区，开工建设张石大道、秦巴大道、明珠大道等一批重大基础设施项目，启动实施石梯养生谷大坝等项目，完成投资20亿元以上，力促绿地集团等一批有实力的大企业落户。突出抓好“五城联创”“四级同创”，大力提升城市品质内涵和文明程度。坚持把保障公共利益、公共环境、公共秩序放在突出位置，狠抓公共设施、违章停车、临时建筑、门前四包、噪音扰民、施工环境“六个严管”。加快推进汉江沿线、月河川道城镇带建设，以保障性住房、市政路网、垃圾污水处理、公厕建设、绿化亮化等基础设施和公共服务建设为重点，持续抓好县城、县域副中心、重点镇、文化旅游名镇和特色小镇建设，深入推进恒口镇级小城市综合改革试验区建设，全市城镇化率达到49.3%。

（六）聚焦营商环境，着力抓改革促招商。紧扣开放招商“第一抓手”，坚定以开放促改革、促创新、促发展。着力深化供给侧结构性改革、农村土地制度和农业经营体系等农村改革。突出抓好市场准入负面清单、国资国企、投资审批、电力体制、成本监审、行业协会商会脱钩、交通运输价格和农业水价综合改革。推动农村“三变”改革、新社区工厂等特色改革取得新成效。实施全方位开放招商，强化领导招商的关键作用，坚持“特色产品展销+合作项目推介”招商模式，探索全产业、链条式、集群化招商，建立“一个产品门类、一批精品项目、一组招商专班、一套考评办法”的“四个一”工作机制，力促全年招商引资到位资金760亿元，进出口贸易总额5.4亿元以上，利用外资4000万美元以上。强化“人人都是营商环境”理念，扎实开展“营商环境深化年”活动，深入实施优化提升营商环境专项行动，协同推进“放管服”“互联网+政务服务”，进一步精简行政审批事项，优化审批办理流程，提升“12345热线”服务质量，增加“最多跑一次”和“不见面”办理事项，做到政务服务事项网上可办率70%以上，申办材料减少60%以上，工程建设项目审批时间压缩40%以上，高频事项办理“最多跑一次”达100项以上。全年新增市场主体3万户，总量突破20万户。深入推进科技“三大创新工程”，全年培育科技创新示范企业10户、科技型小巨人企业40户、小微企业200户。继续实施“百千万”创新人才工程，强化吸引人才人口柔性措施，新引进硕博以上高端人才120名以上。

（七）聚焦民生关切，着力抓普惠促公平。坚持尽力而为、量力而行，精准实施“八项民生工程”，扎实办好民生实事，全年完成民生投入280亿元。大力发展公平而有质量的教育，高质量实施225个教育重点项目，确保深度贫困县区和农村学校基本办学条件达标，启动创建宁陕县、平利县国家义务教育发展优质均衡县，确保汉滨区创建国家义务教育均衡发展县（区）通过评估验收。中心城市新增学位6000个。稳定高中毛入学率92%以上。提高公办幼儿园资源利用与服务供给能力，力促普惠性幼儿园占比达80%以上。推动职业教育扩能提质，职业技能培训4万人次。支持安康学院转型发展。全面加强教师队伍建设。提高全民健康保障水平，突出抓好市中医院传承创新工程、市中心医院江北院区改扩建等15个卫生重点项目，加快推进国际标准医养医院、国际中医医院建设。建成市县镇村业务专网和分级诊疗信息系统，三级医院全面接入预约挂号应用平台。家庭医生签约服务覆盖率35%以上。扎实推进国家级医养结合试点和全省生态健康养老试点市建设，培育2个省级医养结合示范基地和10个市级医养结合示范点、10个生态健康养老示范园、10个标准化居家养老示范社区。深化健康细胞示范建设，打造全民健康“微环境”。实施110个体育惠民工程，加快安康体育馆等重点项目建设，积极备战全国十四运。高质量推进国家公共文化服务体系示范区建设，加快实施古西城文化园、汉江大剧院、安康美术馆等项目，新建镇村（社区）综合性文化服务中心309个。精心筹办“鎏金铜蚕”与开放发展论坛、第19届汉江龙舟节等活动。推动实施“汉水人文生态博物馆群”建设和“振兴繁荣汉剧”工程，加大非物质文化遗产传承扶持力度。加快发展文化产业，全年文化产业增加值增长13%以上。全力做好兜底保障、养老服务、困难救助、优抚安置、特殊关爱等工作。用好开发性金融支持返乡创业等积极就业政策，支持农民工返乡创业和创业带动就业。加快推动100户以上移民搬迁集中安置社区新社区工厂全覆盖，新增新社区工厂200家以上。城镇新增就业1.8万人，城镇登记失业率控制在4%以内。实施重点群体增收计划，城镇和农村居民人均可支配收入分别增长8%和9%。落实粮食安全责任制，确保区域粮食安全。扎实做好社会治理、扫黑除恶、安全生产、防灾减灾、食品药品监管等工作，让人民群众在共建共享中安全感更强、获得感更多、幸福感更好。
