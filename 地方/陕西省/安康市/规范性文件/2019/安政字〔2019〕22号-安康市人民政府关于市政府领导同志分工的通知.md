# 安康市人民政府关于市政府领导同志分工的通知

各县区人民政府，市政府各工作部门、直属机构：

经市政府研究决定，现将市政府领导同志分工通知如下：

赵俊民：领导市政府全面工作。

分管市财政局(市公共资产经办处)、市审计局（市省属企事业审计处）、市机场建设指挥部办公室。

赵 璟：负责市政府常务工作和发展改革、营商环境、人力资源和社会保障、国资监管、应急管理、安全生产、外事管理、行政审批、政务公开、税务以及新安康门户区、综合交通枢纽建设、安康国家高新区、城东新区、飞地经济建设方面工作。

分管市政府办公室（市政府督查室、市机关事务服务中心、驻外办事机构、外事办公室）、市发改委（市粮食局、市秦岭保护办、市重点项目储备统建中心）、市人社局（市养老失业工伤保险经办处、市创业就业服务中心）、市国资委、市应急管理局（市安委办）、市统计局、市行政审批服务局(市政务服务中心)、市消安办、市交安办、中心城区防洪保安工程建设指挥部。

协助分管市财政局、市审计局。

联系市人大、市政协，驻安部队、市消防救援队伍，国家税务总局安康市税务局、市养老保险经办处、国家统计局安康调查队，市发展投资集团公司、金州矿业公司、陕西煤化集团陕南投资公司、中央储备粮安康直属库、陕西粮农安康储备库、市粮食储备库。

刘元世：负责工业和信息化、政务宣传、工业扶贫、西康高铁建设方面工作。

分管市工信局、市政府新闻办、市高铁办，协助分管脱贫攻坚、机场建设工作。

联系市委网信办、市总工会、市工商联，市无线电管理处，电信安康分公司、移动安康分公司、联通安康分公司、铁塔安康分公司、广电网络安康分公司，安康机场投资建设公司、西部机场集团安康机场公司。

邱纪成：负责金融、发展研究、地方志、金融扶贫和金融聚集区建设方面工作。

分管市金融办、市发展研究中心、市地方志办，协助分管脱贫攻坚工作。

联系中国人民银行安康中心支行、安康银监分局及各类银行、保险、证券、小贷、担保、拍卖等中省市金融单位和非金融机构。

刘建平：负责交通运输（含铁路、水运）、卫生和健康、医疗保障、电力等方面工作。

分管市交通局(市道路运输管理局、市海事局)、市卫健委、市医疗保障局（市医疗保险经办处）、市公路局。

联系市红十字会、市公交公司、市交投公司，西安铁路局驻安康各单位，安康供电局、省地电安康分公司，陕西交建集团安川分公司、安平分公司，陕西高速集团白泉分公司，陕西邮政安康分公司。

鲁 琦：负责农业农村、民政、民族宗教以及产业脱贫、富硒产业发展等方面工作。

分管市农业农村局（市茶叶局）、市水利局（市水旱灾害防治监测中心、市防汛抗旱指挥部办公室、市推行河长责任制办公室、市库区移民工作处）、市林业局（市化龙山保护区管理局）、市民政局、市富硒产业办(市富硒产业研发中心)、市民族宗教事务局、市供销社。

联系市残联、市气象局、市烟草专卖局、市水文水资源局、安康水电总厂，石泉、喜河、蜀河水电厂及旬阳水电站、白河水电站建设，安康水电联合实业有限公司，市蚕种场，市慈善协会。

寇全安：负责生态环境、市场监管、科技创新、台湾事务、侨务、瀛湖生态旅游区、旬阳省级高新区等方面工作。

分管市生态环境局、市市场监管局、市科技局，市政府台湾事务办公室、侨务办公室。

联系团市委、市科协、市侨联，市盐业公司，陕文投安康文旅公司，旬阳省级高新区。

何邦军：负责脱贫攻坚、自然资源、城乡建设、城市管理、恒口试验区等方面工作。

分管市扶贫局（市脱贫攻坚指挥部办公室）、市自然资源局〔市不动产登记局、市移民（脱贫）搬迁办、市土地统征储备整理中心〕、市住建局（市人防办、市住房公积金经办中心、市地震监测站）、市城管执法局（市创建办）。

联系市移民（扶贫）搬迁公司、市中心城市建设投资公司、市水务(集团)公司，省地质一队、陕西建工十二建公司、水电三局基地管理中心。

杨 淼：负责教育体育、招商、商务、文旅广电等方面工作。

分管市教育体育局、市招商和经济合作局、市商务局、市文化和旅游广电局。

联系安康学院，安康职业技术学院，市妇联、市文联、市文投公司，新华书店、中石油安康分公司、中石化安康分公司，口岸、海关和进出口检验检疫业务。

张维护：负责公安、信访、司法、退役军人事务、国安等方面工作。

主管市公安局，分管市信访局、市司法局、市退役军人事务局。

联系市中级法院、市检察院，市国家安全局、安康监狱、市法学会。

陈伍文：协助市长、常务副市长处理市政府日常工作，受市长、常务副市长委托处理应急事项。

负责市政府办公室全面工作，协助分管市信访局、市发展研究中心、驻外办事机构。

郭德林：协助负责脱贫攻坚工作。

主管市扶贫局（市脱贫攻坚指挥部办公室），协助何邦军同志分管脱贫攻坚工作。

安康市人民政府
