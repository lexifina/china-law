# 宝鸡市司法局关于下达创建依法行政示范单位工作任务的通知

局机关各处科室：

为进一步做好创建依法行政示范单位工作，根据《宝鸡市创建陕西省依法行政示范市标准》、《宝鸡市依法行政示范县区和宝鸡市依法行政示范单位标准》，现对我局创建任务进行分解，请各处科室遵照执行，对2013年以来形成的有关资料认真整理，于7月4日之前将有关资料及电子版报送市局社法科。

邮箱：bjsfjsfk@163.com 联系人：秋宇峰 3260869

宝鸡市司法局

2014年6月20日

宝鸡市司法局创建依法行政示范单位工作任务

一、加强组织领导

1. 建立依法行政工作的组织领导机制。制定依法行政工作计划。（社法科负责）

2. 成立创建依法行政示范单位领导小组，下发文件对创建工作进行安排。（社法科负责）

3.建立健全依法行政监督、考核制度。对依法行政任务落实情况进行监督、检查，年度考核结果纳入目标责任考核范畴。（政治处、社法科负责）

4.加强法制机构建设，有承担日常法制工作的科室，正式编制3人以上，年度经费落实到位。（社法科负责）

5.培育依法行政先进典型的文件及做法。（社法科负责）

6.建立依法行政年度报告制度。（社法科负责）

二、法治意识、宣传与培训

7.完成领导干部学法任务。每年学法不少于3次。（宣传科提供法制讲座计划文件及法制讲座的时间、地点、参加人员、主讲人等内容；政治处提供局务会学法时间、地点、内容记录的文件）

8.加强行政机关工作人员法律知识培训。建立公务员、行政执法人员年度考核表和任职文件中体现依法行政知识培训内容的制度。（由宣传科、社法科、公律科、基层科提供本科室执法人员参加有关业务培训的时间、地点、内容、姓名基本情况；政治处提供对公务员年度考核中包含依法行政内容的文件或制度）

7.加强对法律、法规、规章和依法行政的宣传。制定年度宣传计划。开展问卷调查、网上调查、收集统计数据等相关资料。（由社法科提供年度依法行政宣传计划；宣传科提供全市年度普法依法治理计划文件）

三、科学民主决策

8.完善行政决策机制。推行重大行政决策听证制度；健全重大行政决策咨询制度、合法性审查制度及集体决定制度，建立重大行政决策实施情况后评价制度；建立重大行政决策责任追究制度。(社法科负责)

四、制度建设

9.严格规范性文件制定权限和发布程序，建立规范性文件制定制定听取意见制度，完善合法性审查制度和集体讨论决定制度，健全规范性文件发布制度。建立规范性文件三统一制度和有效期制度。（社法科负责）

10.建立规范性文件制定审核、备案审查制度，依法履行报送备案职责，建立规范性文件异议审查制度，开展规范性文件实施效果测评工作。（社法科负责）

11.建立规范性文件定期清理制度。每隔两年进行一次规范性文件清理，并向社会公布继续有效，废止和失效后规范性文件目录。未列入继续有效的文件目录的规范性文件，不得作为行政管理的依据。（社法科负责）

五、信息公开

12.完善信息公开工作制度。指定专门机构负责信息公开日常工作，严格按照法定的内容、程序和方式，及时、准确地向社会公开信息。（由办公室提供信息公开管理制度文件、指定负责信息公开机构文件）

13.健全信息公开发布制度。建立信息公开指南和公开目录的编制修订。做好信息公开网站的数据记录。（由办公室提供宝鸡司法之窗网站建设数据记录）

14.健全信息公开工作考核、社会评议、年度报告、责任追究等制度。对信息公开工作进行一次集中考核、评议。做好信息公开工作的年度总结。（由办公室提供对信息公开工作进行考核、评议活动的文件；提供信息公开工作总结）

六、提高行政效能

15.积极履行行政审批、许可监督检查职责。办理行政许可、行政审批事项必须符合国家和省政府的有关规定。按照“谁实施、谁监督”的原则，对作出的行政许可行为进行监督检查。（社法科负责）

16.岗位责任制、首问责任制、限时办结制落实到位。对机关人员进行定期效能考核。（由监察室提供岗位责任制、首问责任制、限时办结制、一次性告知管理制度）

17.强化行政服务、行政审批“一次性告知”，定期清理，坚持日常动态管理。（社法科提供市司法局许可项目等行政审批清理文件）

七、行政执法

18.厘清行政执法职权，避免行政执法机构权责不明、执法层次过多和重叠交叉执法现象。（社法科负责）

19.开展行政执法案卷评查和行政执法监督检查，推行行政执法自由裁量基准制度，规范行政执法行为。（社法科负责）

20.加强行政执法队伍建设。清理、确认并公告行政执法主体，抓好执法队伍思想和作风建设。（社法科负责清理、确认行政执法主体资料，政治处提供执法队伍思想和作风建设文件）

21.健全行政执法责任追究制度，强化行政执法责任追究。（社法科、监察室负责）

22.严格执行罚缴分离和收支两条线管理制度，罚没收入全额缴入国库，纳入预算管理。（律公科、基层科、社法科提供罚缴分离执法资料）

八、防范和化解矛盾

23.积极发挥调解在解决社会矛盾中的作用，充分保护当事人合法权益。（基层科提供人民调解活动安排及总结、社区矫正执法总结）

24.健全行政复议机构，推行行政复议人员资格管理制度。（社法科负责）

25.依法受理复议案件，改进行政复议审理方式，依法作出

行政复议决定。积极创新审理方式，充分运用书面审查、实地调查、听证、和解、调解等手段办案。（社法科负责）

26.鼓励与倡导行政机关负责人出庭应诉。（社法科负责）

九、行政监督

27.自觉接受人大、政协的监督和司法监督。进行问卷调查，人大代表、政协委员对议案、建议、提案办理的满意度达到80%以上。（由办公室提供对人大代表、政协委员议案的办理情况）

28.严格执行司法机关生效的决定、裁定、判决。（社法科负责）

29.加强办理信访案件力度，依法接受社会监督。信访案件办案结案率应达到80%以上。（由办公室提供信访案件办理情况资料）

30.完善群众举报投诉制度。确定专门科室、指定专人负责承办群众投诉举报。收集近年司法行政机关接收的所有群众举报、投诉案件。不得对群众的举报，投诉不予受理或者不在法定期限内予以处理。社会影响较大的，将处理结果向社会公布，接受监督。严禁打击报复违法及不当行政行为的检举、揭发、曝光者。（由监察室提供设置专门机构、专人承办群众举报投诉制度的文件；2013-2014年接收的群众举报案件记录及处理情况）

31.依法履行国家赔偿和行政补偿案件，应赔补的按法定程序依法给予足额赔偿和补偿。（社法科负责）

32.健全特邀行政执法监督员制度。（社法科负责）
