# 关于公布优化提升营商环境投诉举报电话的公告

为深入推进“营商环境提升年”工作，扎实开展“10+3”行动，及时受理群众和企业有关营商环境的各类投诉和举报，切实解决企业最关心、最现实、最紧迫的突出营商环境问题，市政府决定在开展专项督查期间，开通12345和3212558热线电话受理优化提升营商环境投诉举报，主要包括：企业开办和注销、施工许可证办理、水电气暖接入、不动产登记办理、信贷、纳税、跨境贸易和投资便利化、降成本等方面，投诉时间为工作日8时30分至12时，13时30分至17时30分。近日，市优化提升营商环境工作专项督查组将赴各县市区开展实地督查，欢迎社会各界和广大群众积极提供相关问题线索。

市优化提升营商环境工作专项督查组

2018年5月23日
