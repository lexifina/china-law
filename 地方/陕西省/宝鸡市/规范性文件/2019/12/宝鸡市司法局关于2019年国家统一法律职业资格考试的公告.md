# 宝鸡市司法局关于2019年国家统一法律职业资格考试的公告

参加2019年国家统一法律职业资格考试的应试人员对主观题考试成绩有异议的,可在2019年12月13日前,以书面形式向报名地司法行政机关申请核查。书面申请应写明申请人姓名、准考证号、考试所在考区、考点和考场,提供本人准考证复印件。

宝鸡市司法局办公地址：宝鸡市卧龙寺惠民路17号（502室），电话：0917--3260867。
