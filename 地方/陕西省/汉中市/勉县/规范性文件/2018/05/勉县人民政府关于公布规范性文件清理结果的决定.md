# 勉县人民政府关于公布规范性文件清理结果的决定

为全面推进依法行政，建设法治政府,根据《陕西省规范性文件监督管理办法》和《汉中市人民政府办公室关于开展规范性文件清理工作的通知》（汉政办函〔2017〕56号）精神，县政府对以县政府及县政府办公室名义发布的规范性文件（2010年1月1日至2017年6月30日）进行了全面清理，并经2018年县政府第3次常务会议审议通过。现将清理结果公布如下：

一、规范性文件有效期一般为五年。各镇（办）、各部门以及法律法规授权组织，对2012年12月31日以前（含12月31日）发布的规范性文件，除程序性规定、技术规范和内容符合现行法律、法规的文件以外，原则上一律废止，确需继续使用的，按规范性文件制定程序重新发布。

二、对本次清理的规范性文件，已过有效期、需要重新制定发布和修改的，要按照制定程序于2017年12月31日前完成，逾期没有重新发布的，自2018年6月30日起废止。

三、废止的规范性文件自发文之日起停止执行，各实施部门负责做好废止文件的解释、衔接等工作。

四、为确保抽象行政行为合法、可行，各镇（办）、各部门以及法律法规授权组织制发的规范性文件应当规定文件有效期，并严格按照规范性文件“三统一”要求进行统一编号、备案和登记，实行动态管理、定期清理。
