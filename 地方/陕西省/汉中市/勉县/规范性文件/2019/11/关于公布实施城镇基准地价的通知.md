# 关于公布实施城镇基准地价的通知

各镇人民政府，勉阳街道办事处，县政府各工作部门、直属机构：

按照省国土资源厅《关于开展2018年度全省基准地价制订和更新调整工作的通知》（陕国土资用发〔2017〕25号）的要求，我县按程序对城镇基准地价进行了新一轮更新和调整，并经县土地收购储备委员会2019年第3次会议研究同意，现予以公布。新一轮基准地价从公布之日起执行，同时废止县政府2017年公布的2014年城镇基准地价。
