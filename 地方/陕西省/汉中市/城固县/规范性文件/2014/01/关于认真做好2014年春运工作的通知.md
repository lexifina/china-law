# 关于认真做好2014年春运工作的通知

各镇人民政府，县政府有关工作部门、直属机构：

根据汉中市发展和改革委员会《关于认真做好2014年春运工作的通知》（汉发改交通〔2014〕14号）精神，2014年春运工作从1月16日至2月24日，为期40天。为全力做好2014年春运各项工作，努力满足广大人民群众出行需要，保障全县经济平稳运行，经县政府同意，现就我县春运工作有关事项通知如下：

一、提高认识，加强组织领导

做好春运工作事关人民群众的切身利益，更是一项重要的民生工程，对于保障人民群众平安顺利出行、维护社会稳定具有重要意义，也是对落实党的群众路线教育实践活动成效的一次检验。省、市各级高度重视此项工作，对切实做好春运工作提出了明确要求。为此，各镇、各有关部门和交通运输企业要深入落实党的十八大和十八届三中全会精神，贯彻“以人为本、执政为民”理念，按照“以客为主、科学组织、协调配合、安全有序”原则，制定春运方案，抓好组织协调，推进各项工作。

为切实加强对春运工作的组织领导，县政府成立由县委常委、常务副县长黎建军任组长，副县长荣江任副组长，县政府办、发改局、经贸局、交通运输局、公安局、教体局、文广局、人社局、民政局、文旅局、工商局、安监局、物价局、消防大队、城固火车站等部门和单位为成员的城固县2014年春运工作领导小组，全面负责全县春运工作。领导小组办公室设在县发改局，办公室主任由县发改局副局长马忠厚同志兼任，具体负责春运综合协调工作。各镇、各有关部门也要迅速成立相应的春运组织机构，确定1名负责人具体分管、抓实抓好，真正做到春运工作组织落实、领导到位。同时，对春运工作所需人力、物力和经费等予以必要保障，确保春运工作有序开展。

二、高度重视，抓好安全工作

各镇、各部门、各单位要认真学习贯彻习近平总书记在听取青岛输油管线事故汇报时的重要讲话和李克强总理最近关于安全生产的重要批示，始终坚持“安全第一、预防为主、综合治理”方针，建立健全最严格的安全生产制度，把安全责任落实到岗位、落实到人员。尤其要认真吸取渭南市蒲城县长途客车爆炸事故和咸阳市东郊长庆石油助剂厂火灾等深刻教训，进一步加强防范意识，强化监督检查，消除事故隐患，为实现安全春运奠定基础。近期，要集中力量对车、船等运输设施进行彻底检查，发现问题及时整改，消除隐患，确保运输、消防、救生等设施设备处于良好状态；要加强重点隧道、桥梁、镇村道路的检查和养护，做好易堵点交通指挥和疏导，强化安全管理，防范事故发生；要严格审查驾车人员资格，对司乘人员和经营者进行安全教育，提高自觉遵守安全规章意识；要对铁路道口进行全面检查，对安全隐患及时整改，确保节假日期间铁路道口不发生任何事故。各镇政府和县春运工作领导小组成员单位具体职责是：

各镇政府：负责本辖区应急预案的制定和应急工作的组织领导，及时向县政府和县春运工作领导小组办公室报送信息，协调做好滞留人员安置和救助工作。

县发改局：负责承担县春运工作领导小组的日常工作，会同有关部门统筹制定春运工作方案，加强监测分析，及时掌握动态，汇总有关情况，协调处理突发事件和跨镇、跨部门等问题。

县经贸局：负责掌握春运期间重点物资运输需求，努力保证煤炭、石油、粮食、化肥及节日市场供应商品的运输，确保重点物资运输通畅，保障市场供应稳定。

交通运输局：严格管理汽车客运站及道路客运秩序，及时掌握各汽车客运站动态并及时向县春运工作领导小组报告；利用技术手段对运输工具运转情况进行全程监控，严禁旅客携带易燃、易爆及其他危险品乘坐汽车、火车；及时调配公路运力，做好旅客的应急疏运和应急物资的运输工作。

县公安局：负责维护各客运站区域的治安、交通秩序，组织警力确保旅客进出客运站通道畅顺和生命财产安全，特别是做好防爆防火防恐等突发事件的应急处置工作；负责各客运站及周边道路的交通疏导，管制进出客运站各种车辆，严厉打击车匪路霸、扰乱治安及交通秩序行为。特别是加大执法力度，严查超载、超速、疲劳驾驶、酒驾等违法违章行为，在接到应急指令时，及时增派警力迅速到达指定区域，坚决遏制重特大事故发生。

县文广局：负责组织开展“和谐春运、安全春运”宣传教育活动，协调新闻媒体对春运进行采访报道，及时纠正春运出现的违法现象，营造良好的春运舆论氛围。

县人社局：负责协调组织农民工有序流动，积极配合运输部门做好农民工返乡工作。

县教体局：加强对学生的有序流动和引导，及时提供客流信息，以便交通运输部门合理安排运力。

县民政局：负责春运突发事件所需应急物资的储备和滞留旅客的安抚救济工作。

县文旅局：负责配合做好旅游客流的运输工作，参与旅游景点和旅游活动重大事故应急救援。

县工商局：负责对流通市场突发事件进行领导和指挥，并根据突发事件的具体情况开展处置工作。

县物价局：负责加大市场检查力度，严肃查处各种价格违法行为，保证春运期间市场价格稳定。

县安监局：负责协调春运期间全县重大安全事故及突发事件的调查处理工作。

县消防支队：负责春运期间的消防安全检查，处理突发事件。

城固火车站：负责铁路春运的组织协调工作，针对客流突增、天气突变等非正常情况，制定完善应急预案。

三、科学组织，完善运力保障

据初步预测，2014年春运期间我县旅客量将比去年增长10%左右。县交通运输局要引导各运输企业要针对春运客流特点，进一步摸清旅客的流量、流时、流向情况，科学调配运力、增设路线、提升运能，应对客流高峰，尽量满足出行需要，保证旅客“走的了、走的好”。城固火车站要合理安排运力，用好用满客运能力，满足旅客差异化需求。县人社局要督促用工企业按时足额发放工人工资，清理欠薪，让务工人员尽量早日返乡。各镇政府要协调企业错开务工人员返乡时间，创造条件引导务工人员留在当地过年。同时，要本着“统筹兼顾、合理安排”原则，组织好煤、电、成品油、节日商品等重点物资和生活物资的运输，确保市场供应有序、物价稳定。

四、完善预案，做好应急准备

各镇、各相关部门要根据近年来本辖区、本部门实际情况，针对春运工作特点，制定和完善客流异常、旅客大面积滞留、交通事故处置等各类应急预案，明确响应等级、响应范围和责任人，有效应对突发事件及特殊情况，确保春运顺利完成。

各镇、各相关部门要在易积雪、结冰路段和事故多发路段，提前备好备足应急物资、清障和除雪铲冰设备，组织好应急队伍，保证及时铲冰除雪，快速恢复道路通行。要做好各类应急车辆、应急食品、应急医疗、应急油料等准备和服务工作，确保及时迅速投入使用。

交通运输部门和各企业要进一步完善应对异常天气的运输疏导预案，选择好临时安置点，准备好应急运力。一旦出现旅客大面积滞留和运输中断，及时启动预案，加强车辆分流，对滞留旅客尽快救助，妥善安排，并及时上报县政府和县春运工作领导小组。特别要密切关注气象预测，及时掌握春运期间可能出现的区域性低温和雨雪冰冻天气，提前采取应对措施。同时，假日期间小型客车高速公路免费通行，可能导致道路车流量急剧增加，要进一步完善免费放行办法，提前做好防堵保畅预案。

五、以人为本，提升服务质量

春运高峰期间，堵车、滞留情况难以避免，各相关部门和交通运输企业要牢固树立“以人为本”的服务理念，创新服务方式，增加服务内容，提高春运服务能力和水平，努力让人民群众满意出行。各运输部门要利用多种形式，及时发布班次增减、客票余额、道路拥堵、交通管制等信息，采取网上售票、团体预售往返票等多种售票方式，方便旅客购买客票。火车站要在售票厅专门开设农民工团体订票窗口，提前开展寒假学生团体票征订工作，为返家农民工和学生搞好优质服务。及时发布班次延误信息，做好旅客沟通解释和相应服务工作，尽量增加车站候车面积，维护车站秩序，引导旅客有序上下车。各级工会组织要继续开展“平安返乡”活动，并在春节期间深入车站、家庭，慰问坚守在春运一线的职工及其家属。

春运期间，铁路、公路旅客票价一律不得擅自涨浮，各运输企业要严格执行。物价、交通运管部门要认真做好春运期间客运票价收费监管工作，在客运站点设立举报投诉点，及时处理消费者投诉，规范经营者价格行为。物价、公路、公安等部门要加大督查力度，严格查处加价、变相加价以及拉客、倒客、宰客、黑车运输等行为，严禁利用春运之际乱涨价、乱罚款、乱收费，严厉打击倒卖车票、欺行霸市等非法活动，维护旅客合法权益。

六、齐心协力，打好春运攻坚战

春运是一项系统工程，各镇、各相关部门和运输企业一定要齐心协力、密切配合，切实打好春运攻坚战。一是春运领导小组各成员单位务必相互积极配合，对春运工作出现的各种问题，共同协商、尽快解决。二是各镇和运输部门之间要建立协调联动机制，在客流量和运力发生较大变化和调整时相互通报，采取联动措施抓好春运工作。三是各运输部门之间要加强协作，相互支持，充分发挥多种运输方式的作用，共同满足旅客出行需要。四是公安和交通运输部门要加强合作，出现大雪、大雾等恶劣天气时，共同采取措施，尽量减少高速公路、国道主干线封路，努力保证道路畅通。五是及时掌握春运日常动态，发现问题迅速予以解决，并及时向县发改局（县春运办公室）反馈上报信息。县发改局要加强与各镇、各运输部门、各企业的联系，第一时间协调好春运工作中出现的问题，定期通报春运工作的总体运行情况。

春运工作结束后，各镇、各相关部门和运输企业要对本地区、部门、企业的春运工作进行认真总结，并将总结于2014年2月26日前书面报县发改局（县春运办公室）。
