# 关于下达2014年各镇地方财政收入计划的通知

各镇人民政府：

为了全面完成今年各项财政收支任务，充分调动各级各部门组织收入工作的积极性，根据我县税源情况，经县人民政府研究决定，现将2014年各镇地方财政收入计划下达给你们（详见附表），并就有关事项通知如下，请认真贯彻落实。

一、夯实目标任务，落实工作责任。各镇要对辖区内税源情况进行全面摸底排查，迅速将目标任务逐一明确到各责任单位，逐层分解到各责任人身上，落实到各税源企业和税源项目，形成层层有任务、个个有压力、齐心协力抓收入的局面，确保全年目标任务的顺利完成。

二、加大协调力度，及时解决问题。各镇要进一步统一思想，坚定信心，切实加强对财税工作的组织领导，继续坚持财、税、库联席会议制度，加强对重点行业、企业、税源监控，及时掌握和分析财政收支预算执行情况，协调解决收入征管中存在的问题，加快收入入库进度。

三、加强收入征管，确保应收尽收。紧紧把握中央继续实施积极的财政政策和稳健货币政策的有利契机，本着“抓大不放小”的原则，一方面抓好辖区内交通、水利、教育等重点投资项目税收的征缴入库工作，另一方面要全力协助配合税务部门做好零散税收的代征代扣代缴工作，特别是加强对车船税、资源税、个人所得税、建安营业税等重点零散税收的征管力度，坚决堵塞“跑、冒、滴、漏”，努力做到应收尽收。

四、强化考核机制，严明奖罚措施。各镇零散工商税收计划和农业两税收入完成情况依据城财发〔2008〕22号文件审核认定。年终，县政府将按照年度目标责任考核办法对各镇完成情况进行考核评分，并对完成全年收入任务的镇按零散工商税收实际完成数的4%拨付征收经费。
