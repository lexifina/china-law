# 关于做好2014年夏季秸秆禁烧和综合利用工作的通知

各镇人民政府，县政府各工作部门、直属事业机构，中省市驻城各有关单位：

为切实做好我县秸秆禁烧和综合利用工作，保障人居环境，维护公共安全和群众利益，巩固全县秸秆禁烧和综合利用工作成效，根据全市油菜秸秆禁烧及综合利用现场会议安排部署和市政府办《关于做好油菜秸秆禁烧和综合利用工作的通知》（汉政办发〔2014〕8号）文件要求，现就我县2014年夏季秸秆禁烧和综合利用工作有关事项通知如下：

一、禁烧目标和范围

2014年夏季秸秆禁烧工作，按照“疏堵结合、统筹规划、板块推进、突出重点、分类指导”的原则，坚持“综合利用、粉碎还田、集中堆放、杜绝火点、责任追究”二十字方针，采取秸秆禁烧与综合利用相结合、全面禁止与重点防控相结合、行政推动与技术服务相结合、宣传引导与考核问责相结合的方式，分为两大片区开展，即重点禁烧区和一般禁烧区：重点禁烧区为博望镇、沙河营镇、柳林镇、崔家山镇、上元观镇、董家营镇、三合镇7个镇所有村，龙头镇、文川镇、老庄镇、桔园镇、五郎庙镇、原公镇6个镇公路沿线两侧500米内的村；一般禁烧区为除重点禁烧区外的所有镇村。

二、工作步骤

2014年夏季秸秆禁烧工作从5月4日开始到6月20日结束，分三个阶段进行。

（一）宣传动员阶段（5月4日至5月10日）。各镇要及时召开秸秆禁烧和综合利用工作会议，与村组签订目标责任书，积极探索秸秆综合利用途径，采取灵活多样的形式广泛宣传有关法律、法规，教育引导广大人民群众增强环境保护意识，提高参与秸秆禁烧和综合利用的自觉性。

（二）全面禁烧阶段（5月11日至6月10日）。各镇要切实履行职责，坚持全天候巡回检查，确保24小时值班蹲守，防止发生焚烧秸秆现象。县禁烧办和综合利用办对各镇秸秆禁烧和综合利用工作开展情况及违法焚烧秸秆行为加大督导检查力度，及时发布秸秆禁烧和综合利用工作信息。

（三）考核验收阶段（6月11日至6月20日）。县禁烧办和综合利用办深入各镇，对秸秆禁烧工作进行全面考核验收，并将考核验收结果和市禁烧督导通报检查情况汇总通报，结果纳入年终综合考核目标，实行“一票否决”。

三、工作措施

（一）明确责任主体。各镇是秸秆禁烧工作的责任主体，对本辖区内秸秆禁烧工作负总责。继续落实“县级领导包镇、部门单位包村、镇村干部包农户和田块”的包抓责任制，各部门、单位要严格按照《城固县汉江流域污染防治三年行动计划》分工协助镇村开展禁烧工作。县环保局负责指导协调全县禁烧日常工作；县农业局负责协调指导和监督检查全县秸秆还田和综合利用措施落实情况；县交通局负责国、省道沿线的秸秆禁烧工作；县公安局负责对随意焚烧、恶意焚烧和大面积焚烧造成严重后果的依法处置；县文广局负责禁烧宣传报道，禁烧期间设立曝光台；县监察局负责实施问责追究。

（二）落实分区管控。重点禁烧区实施全面禁烧，秸秆综合利用率达到90%以上，禁烧率达到100%，做到不燃一把火，不冒一处烟，不见一处黑斑。一般禁烧区要推广秸秆综合利用，在天气晴好、秸秆充分晾干的条件下，对确实不能转化利用的秸秆，可以按照“三烧三不烧”（干烧、湿不烧，晴天烧、阴雨天不烧，中午烧，早晚不烧）的原则，在12时－15时之间分期分批有计划地组织焚烧，尽可能减少对空气的集中污染，禁烧率达到50%。

（三）开展综合利用。各镇要教育引导群众选用带有粉碎装置的联合收割机械进田收获小麦，按照秸秆粉碎还田的统一要求，实现秸秆粉碎还田，坚决杜绝农户因加装粉碎设备后机收费用增加而放弃粉碎还田等现象的发生。暂无条件综合利用的秸秆，各镇要合理安排秸秆堆存场所，帮助和引导农户将秸秆及时清运、有序堆放，采用粉碎机对秸秆进行统一粉碎，用作腐熟肥料或由综合利用企业有偿收购，实现变废为宝、增加收入，为秸秆禁烧工作创造条件。

（四）采取补贴机制。在秸秆禁烧重点镇做好小麦秸秆粉碎还田和油菜秸秆搬运的农户，经镇、村、组核实亩数后，由市、县财政共同筹资，按20元/亩的标准，拨付给镇、村及农户。对秸秆集中堆放点所配备的粉碎机，由村、组组织农机操作手申购，县农机管理站提供所购机型参考，除享受国家农机购置补贴外，财政给予一定补助。村、组确定的秸秆集中堆放点，可选择在交通便利的农户秋季弃耕地或闲置土地，由村、组与农户协商，按一季水稻产量折价由县、镇、村给予补偿。

（五）严格督查考核。对领导重视、措施得力、无焚烧现象的镇和包抓部门在年终考核时予以加分、奖励；对大面积焚烧，造成恶劣影响的实行“一票否决”；对在秸秆禁烧和综合利用工作中有突出贡献的先进单位和个人予以表彰奖励。
