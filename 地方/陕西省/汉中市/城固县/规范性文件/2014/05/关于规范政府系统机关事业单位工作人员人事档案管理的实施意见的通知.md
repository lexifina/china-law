# 关于规范政府系统机关事业单位工作人员人事档案管理的实施意见的通知

县政府各工作部门、直属机构：

县人力资源和社会保障局《关于规范政府系统机关事业单位工作人员人事档案管理的意见》已经县人民政府研究同意，现转发给你们，请认真贯彻落实。

城固县人民政府办公室

2014年4月30日

关于规范政府系统机关事业单位工作人员

人事档案管理的实施意见

城固县人力资源和社会保障局

为了加强政府系统机关事业单位工作人员人事档案管理工作，推进人事档案管理规范化、制度化、科学化。根据《干部档案管理条例》和《干部人事档案材料收集归档规定》有关人事档案管理要求，结合我县干部职工人事档案现状，现就规范政府系统机关事业单位人事档案管理工作有关事项提出如下意见：

一、目的意义

人事档案是机关事业单位工作人员考录、调配、晋升、辞职、辞退、退休等工作的重要依据，是组织人事部门管理干部职工的基础性资料，涉及每位机关事业单位工作人员的切身利益。通过全面清理全县干部职工档案，确保有人必有档，在清理的基础上对档案的内容逐步完善、补充，在管理模式上进行调整，并在今后逐步形成档案管理常态化、制度化、规范化，为规范人员管理奠定坚实基础。

二、范围及对象

本次清理规范的人事档案是指按干部人事管理权限，归口县人社局管理的县政府系统正式在编机关事业单位工作人员的人事档案。除教体系统事业单位外的所有机关事业单位工作人员档案统一由县人社局管理。教体系统事业单位人员档案由县人社局委托县教体局按同类要求进行清理规范，存教体局档案室，县人社局定期进行检查指导。

三、方法步骤

本次清理规范人事档案工作在县人社局的统一指导下，各部门具体负责本系统干部职工的人事档案清理规范工作。时间从2014年3月到2014年12月底结束，分清理、规范、常态化管理三个阶段完成。

1．全面清理，确保有人必有档。从3月20日至6月20日结束，本阶段的主要任务是各部门、各单位要结合本系统干部职工特点，确定专人，精心组织，全面系统地清查所有正式干部职工的人事档案存放地点和编号，形成附件3《干部职工档案目录花名册》。对无法找到的人员人事档案，查找到该人员参加工作及调入本单位原始资料经人社局确认后，再查找近六年来各类工作资料入档备案。为了有序完成本阶段任务，请各部门、各单位按照附件4《2014年各单位清查档案时间安排表》的要求，派专人来县人社局档案室由管档人员配合清查。

2．充实完善，确保档案内容完整。从6月21日至10月31日结束，本阶段的主要任务是在全面清理清查完单位人员档案基础上对照档案整理目录，对每个人的档案材料进行自查，对档案内容进行充实和完善。重点是对近五年来每个人的考核、调资、奖惩任免、入党等材料规范整理后，统一编号归类，并按照附件5《2014年各单位移交档案时间安排表》的要求，派专人到县人社局档案室进行审核入档。整理标准以附件2《干部人事档案材料收集归档规定》为准。

3．健全制度，确保档案管理常态化。从11月1日至12月31日结束，本阶段的主要任务是总结经验，全面检查验收。在全面清理规范人事档案后，县人社局将对全县档案清理规范工作进行全面的总结，查找存在的问题和困难，并制订相应的档案管理制度。本次清理规范后，全县政府系统机关事业单位干部职工人事档案统一由县人社局集中管理，不允许再出现由部门及单位存放干部职工人事档案的现象。今后各部门要派专人收集本系统干部职工的集散材料，定期报人社局审核后，存入个人档案，每年至少报送一次，形成档案管理常态化。在硬件设施上，县人社局要进一步规范档案室标准化建设，建设库房、阅档室、办公室三室分离的标准化档案室，并配备专职的人员从事档案管理工作。在制度建设上，要完善档案管理制度、查档制度、档案接转制度，形成档案管理科学化、制度化。

县教体局要建成规范的档案室，并配备档案管理必须的设备，在硬件上达标。同时要配备相应的档案管理人员，并与县人社局档案室管理模式保持一致。县人社局将于12月底前，对其进行验收。

四、几点要求

1．高度重视

本次清理规范干部职工人事档案工作规模大，范围广，任务繁重，各部门领导要高度重视，明确责任，集中人力，统筹安排。主要领导要对清理规范档案工作经常监督和检查，使清档工作有计划，有步骤地开展起来。

2．严肃纪律

各部门清理、报送人事档案工作要严格贯彻执行党和国家有关档案保密的法规和制度，做好档案的保密工作，防止泄露人事档案内容和丢失人事档案材料，尤其不得涂改、伪造档案中的原始内容，一经发现，要按相关规定严肃追究有关责任人和当事人的责任。

3．按时完成

各部门要按时间要求，及时完成清理、清查工作，按时报送相关资料，确保全县档案管理工作顺利实施。未按规定转交档案或者档案内材料缺失催交不补的人员按单位非正式人员对待，不予办理调整工资、晋升职称、岗位聘用、调配、考核、退休等事项。
