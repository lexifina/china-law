# 关于下达2014年专利工作任务的通知

各镇人民政府，县政府有关工作部门：

专利是衡量一个地区技术创新和科技进步的重要标志，市委、市政府已把专利工作纳入对县委、县政府的目标责任考核体系。为进一步提高县域科技创新能力，加速推进“创业腾飞”和“六个城固”建设步伐，根据我县涉科企业布局发展和专利申请工作实际，经县政府同意，现将2014年专利工作任务分解下达给你们，请各单位高度重视，采取有力措施，加大工作力度，确保年度目标任务顺利完成。

一、2014年专利工作任务

我县2014年专利工作任务为专利申请量100件，专利授权量43件，现分解到各责任单位（见附件）。

二、工作要求

1．提高思想认识。专利(含发明、实用新型、外观设计)申请量是衡量一个地区自主创新能力和核心竞争力的重要指标，各有关单位要进一步提高认识，切实增强做好专利申请工作的责任感、紧迫感和主动性，努力完成目标任务。

2．加大工作力度。各责任单位要认真研究，尽早部署，细化分解任务，加强宣传培训，确保任务落到实处。专利工作人员要认真学习业务，积极协调指导，为专利申请提供优质高效服务。县科技局、知识产权办公室要及时帮助专利权人申请省、市级专利资助，做好专利资助政策的兑现。未下达专利申请任务的单位也要结合实际，积极开展专利申请工作，努力提升自主创新水平。

3．注重专利质量。在保证完成专利申请目标任务的同时，要注重专利申请的质量，调整好专利申请结构，加大发明专利申请和实用新型专利申请的比例，并增加职务专利申请的比例。要积极引导发明人通过中介代理机构申请专利，提高专利申请文件的撰写质量，增加专利授权量。

4．严格任务认定。专利申请任务的认定以专利申请书填写地址为准，同一专利不能重复认定任务。

三、检查考核

专利工作完成情况采取平时检查与年终考核、单项检查与综合评价相结合的方式进行，考核结果将纳入县上对各镇和部门的目标责任考核体系。平时检查由县科技局、知识产权办公室组织实施，年终考核由县科技局、知识产权办公室根据专利任务完成数和平时检查情况确定考核结果并报县考核办。县上将对专利工作成绩突出的单位予以表彰奖励，对专利工作滞后的单位进行通报批评。
