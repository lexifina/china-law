# 关于印发城固县邀请公民代表走进政府活动实施办法（暂行）的通知

各镇人民政府，县政府各工作部门、直属机构：

现将《城固县邀请公民代表走进政府活动实施办法（暂行）》印发给你们，请结合实际，认真贯彻落实。

城固县人民政府办公室

2014年9月9日

城固县邀请公民代表走进政府

活动实施办法（暂行）

为了贯彻落实群众路线，进一步密切政府与人民群众的联系，使人民群众更加了解政府运作，政府更加直接倾听人民群众呼声，根据省政府办公厅《关于开展邀请公民代表走进市政府活动有关事项的通知》（陕政办函〔2013〕73号）和市政府办公室《关于印发汉中市2014年邀请公民代表走进政府活动方案的通知》（汉政办函〔2014〕21号）精神，现就我县邀请公民代表走进政府活动安排如下。

一、活动意义

开展邀请公民代表走进政府活动，是新时期政务公开工作的有效方式，是践行群众路线、群众观点、尊重人民主体地位的重要体现。开展好这项活动，有利于人民群众走进政府、了解政府、监督政府，有利于政府机关转变作风，树立良好的自身形象，有利于建设透明政府、亲民政府和服务政府，进一步密切政府与人民群众的联系。

二、邀请公民代表走进县政府活动安排

（一）公民参与方式

1．邀请方式：采取公民公开自愿报名的方式进行。

2．报名条件：凡年满18周岁，具有完全民事行为能力的本县公民或在我县居住半年以上的县外公民。

3．报名方式及时间：

（1）实地报名：符合报名条件的公民可携带身份证等有效证件，于每月1—5日在户口所在地或常住地的镇政府办公室填表报名，或直接到县政府办公室政办科填表报名；每月6—8日由各镇将收集到的报名表统一报送至县政府办公室，县政府办公室负责汇总报送至县邀请公民代表走进政府活动领导小组。

（2）网上报名：符合报名条件的公民可登陆城固县人民政府门户网站进行网上报名。

4．报名确认：县政府办公室根据报名情况，分期分批邀请公民代表参加活动，活动具体时间由县政府办公室确定，再由县政府办公室具体通知到公民代表本人。

（二）活动内容

1．公民代表参观县政府有关部门。由专人引导公民代表参观了解县政府有关部门，被参观部门确定专人讲解并带领公民代表参观本部门工作场所，部门负责人介绍本部门职能和工作情况。县政务服务中心、县信访接待中心、县档案局作为公民代表固定参观的三个单位，其余参观对象根据各期活动的公民代表统一提出的活动主题确定，原则上选择与公民代表关系密切或公民代表关注度高的部门。

2．县政府领导与公民代表交流座谈。活动中，由县政府一名领导（原则上县政府每位领导每年至少出席1次活动）和被参观部门的负责人，与公民代表进行座谈交流，听取公民代表对县政府工作的意见和建议。

3．转办、回复公民代表的意见和建议。活动领导小组收集、整理公民代表提出的意见和建议，转交、督促相关部门进行认真办理，并在15个工作日内由政府办公室将办理情况回复给公民代表。

（三）组织实施

开展邀请公民代表走进政府活动要坚持实事求是原则，让公民了解政府机关作风建设的真实情况；要坚持循序渐进原则，从参观办公场所逐步推向深入并监督政府工作；要坚持勤俭节约、方便自愿原则，努力降低活动成本。活动由县政府办公室牵头组织协调，县政府各工作部门、直属机构积极参与实施，负责向公民代表提供本部门（单位）参观的引导、讲解及其他相关服务和组织工作。按照省市文件要求，我县邀请公民代表走进政府活动每月至少开展1次。

三、工作要求

（一）加强组织领导。邀请公民代表走进政府活动是省市安排部署的一项重要工作，县政府对此高度重视，专门成立邀请公民代表走进县政府活动领导小组（见附件）。各镇、各部门要站在创新新时期群众工作的高度，充分认识开展活动的重要性和必要性，紧紧围绕活动的主要内容，加强领导，周密安排，密切配合，切实把活动开展好。

（二）创新活动形式。各部门在接待公民代表参观时，要结合本部门、本单位工作特色，不拘形式，因地制宜，大胆创新开展活动。要深入发掘有参观价值的场所和物品，以增强活动的吸引力和实效性，激起群众共鸣，触动群众的思考，获得群众的支持，激发群众的正能量。

（三）注重政府形象。在活动开展过程中，要维护秩序，厉行节约，妥处突发事件；机关工作人员要注意自身形象，做到文明礼貌，热情服务，耐心解答公民代表的提问，虚心听取公民代表的意见和建议，充分展示人民公仆形象，努力维护良好的政府形象。
