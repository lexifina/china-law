# 关于进一步做好当前防汛救灾工作的紧急通知

各镇人民政府，县政府有关工作部门、直属机构：

近期持续降雨，全县各镇不同程度出现灾情。对此，县委、县政府主要领导和其他县级领导多次深入各镇检查指导防汛工作，发现了一些问题。据气象部门预报，本周还将有明显的强降水过程，全县防汛救灾形势异常严峻。为切实做好当前防汛救灾工作，现就有关事项重申如下：

一、明确工作重点。各镇、各有关部门要牢固树立“防大汛、抗大洪、抢大险、救大灾”的思想，切实把防汛救灾工作作为当前头等大事，把保障人民群众生命安全作为防汛救灾工作的头等大事，认清形势、提高认识，夯实责任、强化措施，确保人员安全。

二、深入排查灾情。各镇要组织动员镇村干部分组入户查灾核灾，对辖区滑坡险段居住群众和危房户、倒房户、削坡建房户再次进行全面摸底排查，查准户数、查实人口、查清姓名，逐户登记造册、建立台账，落实包抓责任人和防灾救灾措施，并将情况及时上报县政府办、民政局。

三、做好转移避险。对居住在危险地段、危险房屋中的群众要一律强制动员撤离；对危房户要动员其投亲靠友，撤离避险；对倒房户要就近安置到固定场所，并限期拆除房屋，对未完全倒塌的房屋要加锁封禁；对削坡建房户、房屋结构坚固但房屋周围有安全隐患的群众要动员其在庭院搭建临时帐篷避险，确保群众生命财产安全。

四、全力救灾除险。各镇、各有关部门要迅速组织专门力量，不等不靠，全力以赴开展救灾工作。各镇要实行辖区负责制，对发现的险情要及时排除。水利部门要及时修复损毁渠系，清除河道障碍物，确保行洪畅通；交通、电力、通讯等部门要采取有力措施，快速抢修，迅速恢复交通运输和通信电力；民政部门要切实抓好灾情统计汇总，及时下拨救灾资金及物资，保障受灾群众生活所需；各镇要会同公安、信访等部门做好辖区治安维稳工作，确保社会大局稳定。

五、抓好灾后重建。按照以镇为单位、辖区负责、相关部门指导支持的原则，由黎建军、肖万朋同志牵头，国土、住建、移民等部门组成联合工作组，派出专人分赴各镇，实地对倒房户、危房户、特困户、居住在危险地段农户进行摸底登记。在尊重农户意愿的基础上，结合移民搬迁等政策，合理安排项目，帮助群众尽快开建新房、尽快住进新居。今后对群众修建新房要选址在安全地带，对削坡建房的，一律不予审批，确保选址科学，居住安全。

城固县人民政府办公室
