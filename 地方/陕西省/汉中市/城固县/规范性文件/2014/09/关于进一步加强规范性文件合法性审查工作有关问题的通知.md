# 关于进一步加强规范性文件合法性审查工作有关问题的通知

各镇人民政府，县政府各工作部门、直属机构：

为了进一步加强对规范性文件的监督管理，促进规范性文件制定与审查工作制度化、规范化，确保行政机关抽象行政行为的合法性，切实推进依法行政，根据《陕西省规范性文件监督办法》、《汉中市行政机关规范性文件制定办法》和《汉中市行政机关规范性文件评估办法》等文件精神，现就进一步加强我县规范性文件合法性审查工作通知如下：

一、进一步提高对规范性文件合法性审查工作重要性的认识

规范性文件是行政机关为贯彻实施宪法、法律、法规而形成的重要性文件，涉及公民、法人和其他组织的权利和义务，具有普遍约束力，在一定时期、一定范围内可以反复适用，其内容是否合法、是否合理适当，对于确保宪法和法律实施，保护群众切身利益，维护社会稳定，关系重大。加强规范性文件合法性审查工作，是促进政府依法行政的现实需要，有利于提高规范性文件的质量，从源头上预防和减少违法抽象行政行为的发生；有利于预防和纠正行政机关的不当行政行为，促进法治政府建设。

我县自2006年出台《城固县人民政府规范性文件制定程序及备案办法（试行）（城政发〔2006〕39号），建立规范性文件合法性审查制度以来，各镇、各部门做了大量切实有效的基础工作，规范性文件制定质量不断提高，但在具体实施过程中，仍然存在不少问题和不足。主要表现在：一是一些镇和部门对规范性文件制定和审查工作的重要性认识不足、重视不够；二是报送迟缓，没有给法制办及法律顾问留够充分时间；三是草拟的规范性文件格式不规范，关键用语非法律语言，需县法制办在文字上作大量修改完善工作；四是规范性文件制发随意照抄照搬，脱离本县实际，内容违法的现象时有发生，规范性文件的质量有待进一步提高；五是一些镇政府和部门制发规范性文件不经县法制办审查，或对县法制办提出的法律意见不予采纳，直接上会审议。以上情况影响了规范性文件制定和审查工作的正常开展，为规范性文件不规范埋下隐患。因此，各镇、各部门要进一步提高对规范性文件合法性审查工作重要性的认识，切实增强责任感，采取得力措施，加大工作力度，严格执行有关规定，确保政府制定的规范性文件合法有效。

二、合法性审查的范围

我县具有管理公共事务职能的各级行政机关代县政府制定的文件，有下列情形之一的，应当进行合法性审查。

（一）涉及改革发展稳定大局和人民群众切身利益、社会普遍关注的重大问题的；

（二）涉及公民、法人或者其他组织权利或者义务的；

（三）公开发布并反复适用，具有普遍约束力的；

（四）结合我县实际制定的贯彻国家法律法规规章及相关政策的规范性文件；

（五）虽无上位法规定但符合社会经济发展需要或保障民生需要以及符合法律精神、法律原则，且以省内外其他县政府已出台相关规范性文件为借鉴的；

（六）其他涉权涉法需要进行合法性审查的。

三、严格报送程序和审查标准

镇政府、县政府部门或直属机构起草的拟以县政府或县政府办公室文件发布的规范文件按以下程序报送审查：

（一）镇政府、部门相关科室起草，送本镇、部门法制机构审查；

（二）书面征求相关部门意见，专业性或技术性较强的规范性文件，应组织专家讨论；

（三）按照相关部门和专家意见修改后，报送县政府办公室相关科室，经分管领导审签后报送县政府法制办，同时提交以下材料：

1．规范性文件草案及电子文本；

2．起草说明；

3．法律政策依据；

4．征求相关部门及专家的书面意见；

5．可能涉及社会稳定的风险评估报告；

6．其他需要报送的材料。

按要求报送审查材料迟缓和报送材料不全的，县政府法制办可暂缓审查，相关责任由起草部门负责。

规范性文件着重审查以下几方面内容：

（一）是否与法律、法规、规章和国家方针、政策相抵触；

（二）是否违法设定行政处罚、行政强制、行政许可、行政事业性收费和其他应当由法律、法规、规章规定的内容；

（三）是否增设公民、法人或者其他组织的义务，是否超越法律、法规、规章的规定限制公民、法人或者其他组织的权利；

（四）是否设定地方保护政策或违反市场经济规律；

（五）文件内容是否明确、具体，是否具有可操作性；

（六）语言文字是否符合法律规范。

四、规范运用审查意见

（一）县政府法制办组织政府法律顾问对部门报送的规范性文件草案审查后，制作《审查意见书》，并加盖本单位印章或由法制办负责人签字。

（二）规范性文件的起草部门或机构，应按照县法制办审查意见进行修改后提请县政府常务会议研究决定。未经合法性审查或审查不合法的，不得列入县政府常务会议题审议，不得发布施行。
