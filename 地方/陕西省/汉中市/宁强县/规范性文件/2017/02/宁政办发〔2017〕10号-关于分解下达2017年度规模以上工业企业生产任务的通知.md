# 关于分解下达2017年度规模以上工业企业生产任务的通知

各镇人民政府、街道办事处，县政府各部门、直属机构，市县双管单位：

为确保2017年工业经济目标任务顺利完成，结合全县规模企业生产经营实际，现将2017年度全县规模以上工业企业生产任务予以分解下达，并就有关事宜通知如下：

一、强化领导，夯实措施。继续坚持县级领导、责任部门、责任人分级负责制，各包抓领导、联系部门要定期深入企业一线，稳定企业家信心，以新发展理念为指导，有效解决好经济新常态下企业面临的实际问题和困难，因企施策加大帮扶力度，积极化解各种风险，切实减轻企业负担，降低企业运行成本，推动企业积极应对发展危机和挑战，促进工业经济平稳健康发展。

二、稳中求进，均衡推进。各部门单位、镇（办）要充分认识和把握经济发展趋势，加强预期引导，深化创新驱动，积极落实县政府工商企业稳增长扩投资增效益的决定，在稳定增长的前提下奋发有为。各规模工业企业要保持战略发展定力，坚持以提高质量效益和核心竞争力为中心，筑牢发展根基，均衡推进生产任务落实，确保工业生产任务按时按计划顺利完成。

三、加强指导，落实责任。县经贸局、县统计局要切实履行统计主体责任，依照统计制度变化新情况，及时指导企业做好统计上报工作，务必做到应报尽报，应统尽统。各规模工业企业要按规定扎实做好统计数据网上直报工作，并同步向县经贸局、县统计局上报，以便县委、县政府及时掌握规模工业经济运行情况，科学调度生产要素。
