# 关于印发宁强县加快推进农业倍增工程实施方案的通知

各镇人民政府、街道办事处，县政府各部门、直属机构,市县双管单位：

《宁强县加快推进农业倍增工程实施方案》已经县政府同意，现印发给你们，请认真组织实施。

宁强县人民政府办公室

2017年2月10日

宁强县加快推进农业倍增工程实施方案

为加快转变农业发展方式，推进现代农业快速发展，确保如期实现全县农业倍增工程预期目标。根据中共宁强县委、宁强县人民政府《关于实施农业倍增工程的意见》（宁发〔2014〕8号）要求，制定如下实施方案。

一、农业倍增工程发展现状

自2013年农业倍增工程实施以来，全县上下认真贯彻落实市县决策部署，坚持以发展现代农业为核心，以加快结构调整为主线，以实现农民增收为目标，强化园区承载、龙头带动、集群发展、品牌培育，全力推进农业倍增工程，农业农村经济发展取得明显成效。2016年全县农业总产值33.76亿元，较2012年增长32.5%；农村常住居民人均可支配收入8746元，较2012年增长52%。粮油总产保持稳定，2016年粮油总产9.8万吨，实现产值4.1亿元。“5+5”农业产业布局初步形成，五大主导产业提质增效，茶园总面积15.21万亩，产量6617吨，产值3.52亿元；出栏生猪45.6万头、牛羊2.3万头、土鸡119万只，畜牧业产值12.48亿元；发展食用菌3845万袋，产量5766吨，产值2.3亿元；发展中药材（不含银杏）6.05万亩，产值2.44亿元；发展核桃园23万亩，林业产值1.88亿元。五大骨干项目发展势头良好，发展烤烟7500亩、蔬菜4.13万亩、银杏5.6万亩、猕猴桃1567亩、中蜂养殖7546箱，实现产值 4.7亿元；农林牧渔服务业产值1.4亿元。现代农业园区建设稳步推进，认定省级现代农业园区3个、市级11个、县级32个。新型经营主体逐步壮大，累计认定省、市级农业产业化龙头企业22个、家庭农场65个，培育农民专业合作社276个、新型职业农民425人。农业品牌建设不断提升，获得中国驰名商标1个、省级著名商标5个，认证无公害农产品31个、有机茶园3500亩，取得“宁强银杏叶生态原产地产品保护”“宁强华细辛地理标志保护产品”、“宁强茶叶地理标志”认证3个。

二、发展思路和目标任务

（一）发展思路。深入推进农业供给侧结构性改革，在确保粮食安全基础上，着力优化产业产品结构，按照扩大规模、延长链条、提质增效、绿色发展思路，坚持市场导向、政府扶持、社会服务、新型经营主体引领原则，强化科技支撑、园区承载、龙头带动、集群发展、品牌提升，做强优势主导产业，做优农产品品牌，做大农业总量，推进现代农业加速发展，实现农业总产值和农民收入倍增目标。

（二）发展目标。到2019年，全县农业总产值在2012年基础上实现倍增，力争达到51.2亿元，年均增长12%；到2017年，全县农村常住人口人均可支配收入达到10057元，较2016年增长15%。

三、工作措施

（一）深化农业农村改革。推进农村土地制度改革,2017年全面完成农村土地承包经营权确权登记颁证工作。围绕主导特色产业,有序推进土地经营权流转，发展多种形式适度规模经营,健全土地承包经营纠纷调解仲裁机构和土地流转信息交易平台，全县土地流转率达到18%以上。积极探索农户以股金或土地承包经营权入股农业产业化建设,推动农户资产变资本、资本促增收，并在同等条件下享有优先就业权利。推进农村金融制度改革,鼓励金融机构积极开发农村金融产品,金融服务延伸到村到户,逐年增加精准扶贫财政担保基金和风险补偿基金，增加茶叶、食用菌、中药材等主导农产品保险险种和价格保险，增强农业产业抵御自然灾害和市场风险的能力。

（二）稳定粮油生产面积。实施好“藏粮于地、藏粮于技”战略，大力实施粮油增产工程、种子工程、植保工程和沃土工程，加大良种推广力度，抓好病虫害防控，大力推广测土配方施肥、秸秆还田综合利用，加强农田基础设施建设，改善物质装备条件，促进粮油综合生产能力稳步提高。川道地区重点发展优质水稻4万亩、双低油菜7万亩；五丁关以北以玉米和小麦生产为主，巴山中海拔地区以种植玉米和马铃薯为主，发展优质高产马铃薯8万亩。全县粮食播种面积保持在46万亩，总产稳定在8.14万吨，其中优粮占比70%以上，产值3.28亿元；油料种植面积保持在9.25万亩，总产1.1万吨以上，产值达到0.75亿元。

（三）加快农业产业基地建设。坚持规模化、集约化、绿色化发展方向，纵深推进生猪、茶叶、中药材、食用菌、干果等主导产业规模，不断壮大烤烟、蔬菜、银杏、猕猴桃和中蜂养殖等骨干项目发展，促进农业产业优化升级。到2019年，全县年出栏生猪52.9万头、牛羊2.8万头、土鸡132万只，养殖中蜂2.03万箱，畜牧业总产值达到16.75亿元；培育优质高产茶园12万亩，全县茶园面积17万亩，加大夏秋茶研发、加工能力，产茶7050吨，综合产值8.5亿元；发展中药材18万亩，引进并建成中药材深加工企业4个，实现综合产值8亿元，其中建成银杏采摘园10万亩；发展食用菌4500万袋以上，产量6750吨（干品），食用菌精深加工2000吨，综合产值4.7亿元以上；每年新建优质核桃园1万亩以上，核桃园总面积达到27.8万亩，积极发展林下经济、苗木花卉、龙脑樟等产业，实现林业总产值4.2亿元；蔬菜复种面积达到5万亩，产值2.3亿元，其中发展高山蔬菜5150亩、魔芋4.5万亩；发展烤烟1万亩，产值0.52亿元；发展猕猴桃5000亩以上，果品产值 0.3亿元；水产养殖面积达到295公顷，产量770吨，渔业总产值达到0.3亿元；积极发展休闲农业，拓宽农业增收渠道，农林牧渔服务业实现产值1.6亿元。

（四）培育壮大新型经营主体。支持农村实用人才、致富带头人和外出务工返乡农民流转土地和林地，从事农业开发。全面落实财政扶持、税收优惠、贷款贴息等政策，扶持发展专业大户、家庭农场、农民合作社、龙头企业等新型经营主体，指导完善管理运行机制。支持新型经营主体承担项目，在机械设备、技术服务、惠农补贴、金融保险等方面给予重点扶持。探索开展土地经营权抵押贷款试点，建立财政支持的农业信贷担保体系，为农业经营主体贷款提供信用担保和风险补偿。加大新型职业农民培育力度，建立新型职业农民培育体系，培育一批懂技术、会经营、善管理的高素质职业农民。到2019年，培育认定市级以上农业产业化重点龙头企业25个、规模经营家庭农场80个以上，发展农民专业合作社300个以上，培育职业农民550人。

（五）推进现代农业园区提质增效。结合脱贫攻坚、移民搬迁、城镇化、美丽乡村建设和全域旅游等，坚持高水平规划、大力度推进、全方位配套，着力打造一批科技含量高、辐射带动力强、产业链条长的现代农业园区。引导园区企业采取农工贸、产学研相结合的经营方式，推广立体种养、资源循环等新型农作模式，提升园区经营效益和辐射带动能力。到2019年，建成省级现代农业园区3-4个，市级现代农业园区8-10个，其中农林类占80%、渔业类占20%。园区核心区土地流转比例达到85%。

（六）加快发展农产品加工业。围绕主导产业和特色优势产业，鼓励龙头企业向优势产区集中，大力发展精深加工、循环加工，推动特色产业集群发展。引导支持省、市级农业重点龙头企业在贫困村建立原料生产基地，带动当地产业发展，增加农民收入。加强技术创新和技术改造，不断提升茶叶、食用菌等农产品精深加工能力和水平，延伸产业链条，提高农产品市场竞争力和附加值。加大农业招商引资力度，精心策划包装项目，广泛吸纳外地客商、工商资本、民间资金投入中药材、茶叶产业发展和山野菜、食用菌加工、生物萃取项目。依托汉江水源地良好的生态优势，充分利用各种宣传推介，积极开展宁强茶叶、核桃、中药材、香菇等优势农产品推介活动，拓宽农产品外销渠道。加快农村物流体系建设，着力打造完善青木川农产品市场、燕子砭核桃天麻交易市场、巴山高山蔬菜交易市场、县城农贸市场等集散中心，联结打通城乡商贸流通体系，在镇（办）、村发展商业服务网点、农产品配送中心，争取项目支持农产品冷链体系建设。

（七）强化农产品质量安全监管。积极开展农产品质量安全示范县创建，建立农产品身份识别、质量安全内控体系和追溯系统，严格管控生产源头、产品加工、市场流通三大环节。推行省、市级现代农业园区“五治一品”建设，推进产地认证、市场准入与质量追溯互联互通。加强农业执法监管能力建设，强化执法检查和农资市场抽检，严厉打击出售假种子、假农药、假化肥、假饲料等坑农害农行为。做好动物疫病防控和畜禽屠宰监管，加强饲料及饲料添加剂、兽药监测监管工作。

（八）提高农业技术装备水平。推进科技创新驱动发展，深化企业与农业科研院校合作，重点围绕茶叶、香菇、核桃、猕猴桃良种选育、关键技术创新和新技术引进示范，开展农业科技研发与推广。加强油菜、马铃薯良种繁育基地建设和良种普及推广力度，有序推进航天育种资源保护和试验示范工作。加大农机购置补贴政策宣传落实力度，优化农机装备结构，充分发挥农业机械关键作用，加快茶叶机械化采摘、畜禽机械化饲喂等机具配套研究示范，普及山区农耕机具应用，推进粮油等主要农作物全程机械化，提高综合机械化水平。开展“互联网+现代农业”行动，鼓励扶持电子商务主体入驻电商产业孵化园区，加快推进电商与实体经济对接。建立县、镇（办）、村三级电商运营配送体系，促进农产品“线上线下”交易。强化县级农业信息网站和镇（办）农技服务一点通服务管理，实现农业信息系统互联互通。

（九）加大政策扶持力度。认真贯彻落实国家扶持农业发展各项政策，积极争取中省市投入，助推农业产业快速发展。整合涉农项目资金，建立完善财政投入同步增长机制，逐年增加农业倍增工程扶持资金。县财政配套800万元奖励扶持农业产业发展，重点支持现代农业园区建设、农产品加工能力建设和辐射带动贫困户增收项目等。对新建农业基地以及开发“四荒地”从事农业生产的，纳入土地治理项目予以扶持，达到一定规模可按农业用地安排一定比例附属设施建设用地。发挥金融机构服务“三农”作用，切实加大“三农”支持力度，对具备发展潜力的产业项目、农业园区、龙头企业和合作组织等，在信贷项目、贷款额度、贷款贴息及手续办理等方面给予支持优惠。

四、工作推进机制

（一）加强组织领导。县农业倍增工程领导小组负责建立完善农业倍增工程推进机制，及时协调解决重大问题。领导小组办公室（县农业局）负责全县农业倍增工程组织实施、协调督导工作。各成员单位要把实施农业倍增工程纳入重要议事日程，坚持主要领导牵头抓总、一抓到底，分管领导跟踪落实、紧抓不放，确保如期实现农业倍增目标。

（二）明确职责分工。各镇（办）是农业倍增工程的实施主体，要尽快制定本辖区加快农业倍增工程实施方案和推进措施，层层夯实责任，把任务细化分解到村组、企业、地块。县农业局、林业局、水利局、科技局、扶贫办要切实抓好规划制定、任务分解、协调督查、项目实施、信息收集等工作。涉农企事业单位要紧紧围绕农业倍增工程，找准位置、发挥优势、强化服务、培育典型，加快科技创新，增强农业发展动能。各有关部门要结合自身职能，从政策扶持、项目安排、资金整合、配套建设等方面制定具体措施，各司其职，相互配合，整合力量资源形成强大合力。

（三）严格督查考核。县考核办负责协调有关方面，将实施农业倍增工作纳入年度目标责任综合考核体系，加大考核比分权重，细化考核指标，充分调动各方积极因素推进农业倍增工程实施。县统计局负责指导协调县农业局等部门建立健全农业倍增工程监测评价体系，强化农业各项指标监测分析，扎实抓好季报、年报工作，确保农业各项指标走在省、市前列。县农业局负责会同县考核办和相关产业部门制定农业倍增工程具体考核办法，分解下达年度目标任务，采取日常检查、月督查、季度通报、半年点评、季度考核相结合的方式，加大督查考核力度，确保如期实现倍增目标。对如期实现农业倍增目标、工作成效显著的镇（办）、部门和单位，将在全县范围内予以通报表彰；对因工作不力、措施不佳，导致产业发展滞后、影响全县总体目标实现的，将在全县范围内进行通报批评，并严肃追究责任。
