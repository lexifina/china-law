# 关于印发建档立卡非易地搬迁贫困户农村危房改造工作实施方案的通知

各镇人民政府、街道办事处，县政府各有关部门、直属机构，市县双管单位：

《建档立卡非易地搬迁贫困户农村危房改造工作实施方案》已经县政府同意，现印发给你们，请认真组织实施。

宁强县人民政府办公室

2017年5月18日

建档立卡非易地搬迁贫困户农村危房改造

工作实施方案

为认真贯彻省委、省政府《关于贯彻落实<中共中央、国务院关于打赢脱贫攻坚战的决定>的实施意见》（陕发〔2015〕20号）精神，坚决落实“优先实施建档立卡贫困户危房改造”工作要求，加快我县农村危房改造工作进度，切实改善困难群众居住条件，按照住房城乡建设部、财政部、国务院扶贫开发办公室《关于加强建档立卡贫困户等重点对象危房改造工作的指导意见》（建村〔2016〕251号）要求，结合我县实际，制定本实施方案。

一、目标任务

以实现“住房安全有保障”为目标，以解决建档立卡非易地搬迁贫困户住房安全问题为重点，根据省委、省政府确定的贫困户脱贫时限，统筹规划、整合资源，加大投入、创新方式，分期分批、精心实施，通过政府补助、政策扶持等措施，全面完成全县建档立卡符合危房改造条件贫困户危房改造任务，切实改善农村困难群众生活条件和居住环境。

二、基本原则

（一）安全为本。牢牢把握脱贫攻坚工作要求，以实现住房安全有保障为目标，认真实施农村危房改造工作，确保贫困群众住房安全。

（二）减轻负担。加大政策倾斜支持力度，以改造为主、新建为辅，按照国家农村危房改造建筑面积标准，推进加固改造，实施特困户兜底政策，避免因建房返贫。要根据建设实际，尽可能利用好当地传统建筑材料，尽可能就地取材。要积极推广造价低、工期短、安全可靠的农房加固技术。新建住房要符合全县总体规划和镇村规划，原则上安排原宅基地建设，也可利用闲置宅基地、村内空闲地进行建设，尽可能节约改造资金。

（三）科学推进。科学制定农村危房改造计划，做好与相关规划的衔接，确保良好质效。要立足当前、着眼长远，因地制宜、分类指导，根据自然地理条件和经济发展水平，按照有利生产、方便生活、相对集中的要求，统筹规划，分批实施。

（四）公开、公平、公正。坚持扶持政策、申请条件、补助标准、审批程序和审批结果公开原则，广泛接受群众监督，确保阳光操作。

三、改造要求及标准

拟改造农村危房属整栋危房（D级）的应拆除重建，属局部危险（C级）的应修缮加固。需重建的危房需由县住建部门根据住建部《农村危房鉴定技术导则（试行）》要求，组织专业技术人员及相关工作人员对危房进行调查核实，科学确定危房等级，在各镇办及相关部门单位组织协调下，帮助农户选择有资质的施工单位统一进行建设。危房改造要根据镇村总体规划，以村（社区）为单位，保持房屋色调整体统一。

（一）D级危房重建标准：严格控制建房面积和标准，在满足基本居住功能和安全的前提下，原则上1至3人农户控制在40～60平方米以内，且1人农户不低于20平方米、2人农户不低于30平方米、3人农户不低于40平方米；3人以上农户人均建筑面积不超过18平方米、不低于13平方米。

（二）C级危房维修加固标准

1.地面部分:地基基础无塌陷，安全稳定；房屋四周散水、廊檐及室内地面硬化处理，表面平整；室外有排水沟，排水通畅，地基周围无积水。

2.墙面部分：墙体内、外粉刷，无裂缝，墙面平整光滑、感观良好，墙面白色涂料不掉色；墙裙颜色要求深灰色，线条平直，墙裙高度60公分；门、窗油漆刷涂维修，开启灵活无损坏。

3.房面部分:屋面屋顶陈旧、且在国省县公路干线及旅游景区沿线的，应结合各镇办美丽乡村建设规划，因地制宜，实施维修加固；损坏变形的柱、梁、檩、椽等部件需维修更换，确保主体结构安全；封檐板及外立柱需油漆处理，保证质量安全、适用美观。

4.室内部分:室内老化电线要进行更换，线路走向平直、布局规范合理；室内陈旧、污损顶棚进行吊顶处理。

四、补助标准及审核程序

（一）补助标准：建档立卡非易地搬迁贫困户农村危房改造补助资金由县级财政统筹予以保障。其中，修缮加固（C级）危房，户均补助不超过1万元；拆除重建（D级）危房，户均补助不低于3万元。具体办法由县住建局制定执行。

（二）审核程序

1.申请。符合危房改造条件的贫困户向当地村民委员会提出书面申请，并填写《农村危房改造农户申请表》，同时提供户籍、住房、低保、收入等证明材料。

2.评议。村民委员会对收到的申请，通过召开村民代表会议进行评议，初步确定改造对象，并予以公示，广泛听取和征求意见。经评议符合条件的，签署意见后报当地镇办。对不符合条件的，应向申请人说明情况和理由。

3.审查。各镇办对上报的申请材料要及时进行审核，并根据住建部《农村危房鉴定技术导则（试行）》要求，组织专家及相关人员对申请人的住房和家庭经济情况等进行调查核实,符合条件的，及时报县住建、财政、发改、移民（脱贫）办等部门。

4.核准。县住建、财政、发改、移民（脱贫）办等部门联合对各镇办上报的申请材料及时进行汇总复核，对符合危房改造条件的，核准改造方式及补助标准，并根据住房危险程度，按照先重后轻的原则提出分批改造计划，推进组织实施。各镇办要根据核准意见，及时做好与符合条件的危房改造农户签订改造合同或协议。

5.验收。建档立卡贫困户农村危房改造项目竣工后，由县农

村危房改造领导小组办公室、县脱贫办、各镇办等相关部门单位共同进行全面检查验收，并填写验收合格报告表。

五、资金兑付

危房改造任务下达后，补助资金由县财政统一拨付至各镇办财政所，再由各镇办拨付给危房改造农户。

具体流程：危房改造工程启动后，由农户申请，各镇办、村组拍摄施工现场图片并签署意见后，按工程进度分期发放相应补助资金至危房改造户惠农卡；工程整体竣工，经验收合格，且档案资料齐备并审定后，发放剩余补助资金至危房改造户惠农卡。

六、档案资料管理

农村危房改造实行一户一档，批准一户、建档一户，规范管理。农户档案资料包括档案表、危房改造申请、政府补助申请、公示、协议及改造前后住房情况资料等材料。各镇办要积极与县住建局、扶贫办、移民（脱贫）办等部门单位做好衔接协调，按要求做好农户档案资料信息化录入工作，确保将危房改造农户信息及时、完整、真实、准确录入住房和城乡建设部“农村危房改造管理信息系统”。

七、工作措施

（一）加强组织领导。成立由县政府分管副县长任组长，县住建局局长、县扶贫办主任任副组长，县发改、财政、住建、国土、扶贫办、移民（脱贫）办、农业、水利、交运、文广等部门及各镇办主要负责人为成员的“农村危房改造工作领导小组”。领导小组办公室设在县住建局，住建局局长兼任办公室主任，具体负责农村危房改造工作的组织协调。各镇办也要成立相应领导机构，确保农村危房改造工作有序实施。

（二）明确工作职责。县住建部门负责全县建档立卡贫困户农村危房改造工作的组织实施，组织专业技术人员做好危房等级鉴定，提供危房改造技术支持，加强施工管理，定期抽查检查，做好资料验收归档和信息录入的技术指导工作；建立农村危房改造质量安全管理制度，落实专人负责监管，对项目施工现场进行跟踪巡查与指导监督，督促严格执行建筑施工相关标准，确保工程质量。各镇办是农村危房改造工作的责任主体，要精心组织，认真、细致地做好危房改造资料搜集整理，及时报县危改办归档。要根据辖区群众危房鉴定意见及结果，选择符合资质条件的施工单位，及时开展危房改造工作，确保按时建成入住。县发改、财政、扶贫、移民（脱贫）办等部门单位要根据各自职责，协助办理危房改造相关手续，共同做好农村危房改造工作。县委宣传部、县文广局要加强危房改造工作先进经验和做法的宣传报道，营造良好社会舆论氛围。

（三）严格责任追究。各镇办、各有关部门单位要切实履行好各自职责，加强协作，密切配合，确保贫困群众农村危房改造工作有力有序推进。对推诿扯皮、玩忽职守、弄虚作假、办事拖拉，或造成群众不满、上访等恶劣影响及出现截留、套用危房改造资金等违法违规行为的，将严肃查处并追究责任。

（四）加大扶持力度。各有关部门单位要高度重视农村危房改造工作，加大支持、扶持力度，切实为危房改造工作提供有利条件。县供电部门要及时完成供电线路改造工作；县文广部门要进一步扩大农村广播电视覆盖面；县农业部门要积极推广沼气池修建，并给予资金补助；县水利部门要做好人畜饮水配套建设；县交通部门加快通村公路建设；县金融部门要积极解决群众建房小额贷款问题。

（五）及时报送信息。实行农村危房改造项目信息月报制度，工程开工后，各项目实施单位于每月20日前将本月危房改造工程进度及完成投资情况报县危改办（县住建局）。（电话传真：4228181）
