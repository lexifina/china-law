# 关于规范统筹整合涉农资金账务处理的通知

各镇（办）、有关部门：

为了加强统筹整合涉农资金管理，规范涉农资金账务处理，加强资金管理，提高资金使用效益，促进涉农资金规范安全运行，按照中省市县资金分级、分项、分账核算，账务清晰，管好用好涉农资金，请各部门和镇办参照以下模式记账。

一、账套名称：统筹整合财政涉农资金

二、收到统筹整合财政涉农资金记账：

财政补助收入（一级科目）

——2017年统筹整合财政涉农资金（二级科目）

——扶贫项目（三级科目）

——整村推进（四级科目）

——XX村（五级科目）

——产业精准扶贫（六级科目）

——基础设施（六级科目）

——互助资金（六级科目）三

——基础设施小项目（四级科目）

——依据小项目名称依次续设（五级科目）

——绩效评价奖励项目（四级科目）

——依据小项目名称依次续设（五级科目）

——贷款贴息（四级科目）

——农民实用技术培训（四级科目）

——代赈项目（三级科目）

——依据小项目名称续设（四级科目）

——交通项目（三级科目）

——依据小项目名称续设（四级科目）

——水利项目（三级科目）

——依据小项目名称续设（四级科目）

相关部门、各镇（办）对统筹整合财政涉农资金账务处理这项工作要高度重视，严格按以上模式及时记账，对模式范围内的未尽事宜，咨询财政局农财科，电话：4223170。
