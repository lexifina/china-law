# 关于成立宁强县脱贫攻坚农村危房改造工作技术指导服务组的通知

各镇人民政府、街道办事处，局属相关股室、单位：

为全面贯彻落实省、市脱贫攻坚会议精神，切实加强我县脱贫攻坚农村危房改造工作稳步推进，确保完成2017年农村危房改造目标任务。经宁强县农村危房改造工作领导小组研究，决定成立宁强县脱贫攻坚农村危房改造工作技术指导服务组。现就有关事项通知如下：

一、工作时间及方式

全县农村危房改造工程技术指导工作按月不定期进行 ，通过座谈交流、查阅资料、实地查看等方式督促，抽查各镇危房改造工作进度，每月20日前上报月报表。

二、人员组成

为确保脱贫攻坚农村危房改造技术指导服务组工作的正常开展，抽调我局相关人员，组成6个技术服务小组，落实责任，分组分片对全县农村危房改造工程进行技术指导服务：

第一小组：副组长袁魏、成员县质检站，负责指导汉源街道办、高寨子街道办、舒家坝镇。

第二小组：组长张树庆、副组长郑锋、成员局规划股，负责指导胡家坝镇、铁锁关镇、二郎坝镇。

第三小组：组长陈柏荣、副组长曹军利、成员县住房保障管理中心，县设计院，负责指导大安镇、代家坝镇、巨亭镇。

第四小组：组长王斌、副组长何明、成员局城建股，局办公室，负责指导阳平关镇、太阳岭镇、燕子砭镇。

第五小组：组长崔小平、副组长罗明军、成员县镇村站，负指导查青木川镇、广坪镇、安乐河镇。

第六小组：组长刘振涛、副组长马兴平、成员局房产股、建管股，负责指导巴山镇、毛坝河镇、禅家岩镇。

三、工作职责

1、认真执行县农村危房改造工作领导小组的安排部署，贯彻落实省、市脱贫攻坚农村危房改造工作的各项政策措施，做好脱贫攻坚农村危房改造的日常管理工作。

2、督促指导各镇办脱贫攻坚农村危房改造各项工作，协调解决农村危房改造实施过程中的各类问题的研究与处理，抓好改造进度工作。

3、协调各镇办做好全县脱贫攻坚农村危房改造（C级和D级）的技术服务指导，工程质量的安全监管和补助资金使用管理等工作。

4、做好全县脱贫攻坚农村危房改造的工作信息、文件资料收集汇总，分类建档等工作，做好全县脱贫攻坚农村危房改造相关信息的宣传与报道等工作。

宁强县住房和城乡建设管理局
