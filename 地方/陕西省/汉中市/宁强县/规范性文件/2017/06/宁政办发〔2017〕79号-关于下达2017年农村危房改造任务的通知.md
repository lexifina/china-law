# 关于下达2017年农村危房改造任务的通知

各镇人民政府、街道办事处，县政府各有关部门、直属机构，市县双管单位：

为认真贯彻省委、省政府《关于贯彻落实<中共中央、国务院关于打赢脱贫攻坚战的决定>的实施意见》（陕发〔2015〕20号）精神，坚决落实“优先实施建档立卡贫困户危房改造”工作要求，加快我县农村危房改造工作进度，切实改善困难群众居住条件，按照住房城乡建设部、财政部、国务院扶贫开发办公室《关于加强建档立卡贫困户等重点对象危房改造工作的指导意见》（建村〔2016〕251号）要求，结合《宁强县建档立卡非易地搬迁贫困户农村危房改造工作实施方案》，现将2017年农村危房改造任务分解下达给你们，并将有关事宜通知如下：

一、准确把握目标任务。本次下达的2017年工作任务主要为当年拟脱贫建档立卡贫困户危房改造，全县共计1517户（C级678户、D级839户），涉及补助资金3195万元。各镇（办）要严格按照全县脱贫攻坚任务锁定的建档立卡贫困户范围以及下达任务对象（各镇办改造任务见附件）实施改造工作，要切实履行好主体责任，迅速成立相应工作机构、制定工作方案、明确责任领导和具体责任人，确保及时开工并按时完成改造任务。每月20日前,各镇（办）要将工作开展情况报送县住建局。县政府督查室将定期通报工作开展情况，并纳入年终目标责任考核。

二、严格控制建房标准。实施农村危房改造要坚持“一户一宅、建新拆旧”原则，严格落实国家建房面积控制要求，确保改造后的农房建筑面积适当、基本功能齐全、主要部件合格和房屋结构安全，防止群众盲目攀比、超标准建房。危房改造在满足基本居住功能和安全的前提下，原则上1至3人农户控制在40～60平方米以内，且1人农户不低于20平方米、2人农户不低于30平方米、3人农户不低于40平方米；3人以上农户人均建筑面积不超过18平方米、不低于13平方米。要优先采用修缮加固的方式对危房进行改造，切实节约成本。签订危房改造协议时，改造对象应当明确承诺建房标准，未履行承诺的要追回补助资金。

三、严格补助资金管理。建档立卡非易地搬迁贫困户农村危房改造补助资金由县级财政统筹予以保障。其中，建档立卡贫困户C级（加固维修）户均补助资金不超过1万元，D级（重建）户均补助资金不低于3万元。本次危房改造任务下达后，补助资金由县财政统一拨付至各镇（办）财政所，再由各镇（办）通过“一卡通”直接拨付给危房改造农户，并及时将拨付凭证录入管理信息系统，确保资金安全。县住建局、各镇（办）及相关部门单位要严格按照国家有关规定，公布县级及本级农村危房改造投诉电话，对危房改造资金实行专项管理，严禁截留、挤占、挪用或变相使用、拆分使用，对不符合补助要求或者违反危改协议的，不得发放补助，已经发放且经责令整改无效的要及时追回，并追究相关人员的责任。

四、加强技术服务管理。县危改办、各镇（办）要组织专业技术人员，在农村危房改造房屋核查、施工中、竣工后等关键阶段，及时到现场进行技术指导和检查，发现不符合要求的当即告知帮扶对象及施工单位，并提出处理建议和做好现场纪录，以便后期复查。农村危房改造必须按国家和省市有关规定，签订相关合同，由具备资质的人员和单位承担施工任务并对改造工作负责，对不请具备相关资质人员和单位的，由各镇（办）出具安全质量承诺书。县危改办要组织相关部门对全县危房改造工作开展定期或不定期专项检查，督促施工进度，确保质量安全，并组织开展年度任务完成情况绩效考核。要加强信息系统动态管理，对已录入信息定期进行更新。

五、迅速启动危房改造工作

各镇（办）要迅速开展工作，7月10日前制定完成辖区2017年农村危房改造工作方案，并报县住建局备案；要将改造任务合理细化分解，并落实到户到人，及时解决好建房过程中遇到的困难和问题。C级（加固维修）户要保证在7月底前开工建设，9月底前100%完成改造任务。D级（重建）户要在8月底前动工，2017年11月底前100%竣工，春节前100%入住新居。县危改办、各镇（办）要根据危房改造实施进度，及时组织开展验收工作，并收集、完善相关资料，完成信息系统录入等工作，做好上级检查验收准备。在做好2017年农村危房改造工作的基础上，要对2018年农村危房改造进行摸底调查，做好前期准备工作，为来年工作顺利开展打好基础。
