# 宁强县2017年农村学校特设岗位教师面试公告

根据省市统一安排和要求，为了切实做好我县2017年农村学校特设岗位教师面试工作，确保公平、公正、公开，择优选拔人才，根据《汉中市事业单位公开招聘工作人员面试工作暂行办法》和市教育局《关于做好2017年特岗教师招聘面试及相关工作的通知》精神，特制定我县面试工作方案。

一、面试时间、地点

面试时间：7月20日上午8:00——12:00，下午12:30——18:00。

面试地点：宁一中。

二、面试分组

本次进入面试人员共计204人。其中小学17人，学前教育148人，初中30人，体育特长生9人。小学和体育特长生一个组；初中一个组；学前教育5个组；共计7个面试小组。

三、面试方式、内容及成绩计算方法

1、面试方式：采用试讲的方式进行，时间为50分钟，其中备课40分钟，试讲时间为10分钟。体育特长生面试另行制定方案（方案附后）。

面试内容：先随机抽签确定试讲课题，试讲将对职业认知、心理素质、仪表仪态、言语表达、思维品质、教学设计、教学评价等方面进行综合考评。

2、面试成绩计算：面试成绩按百分制计算，满分为100分，由7个评委根据评分标准现场打分，打分后去掉一个最高分和一个最低分，其余5名评委的打分相加后的平均得分为考生的面试成绩（保留2位小数，不实行四舍五入。），现场公布面试成绩、考生签字确认。

四、 面试教材

教材统一为我县现行使用教材。小学试讲五年级下册内容（数学北京师范大学出版社，语文人民教育出版社，信息技术陕西科学技术出版社）；初中试讲初二(化学测评初三)下册内容（化学人民教育出版社，数学华东师范大学出版社，物理江苏科技出版社，生物人民教育出版社，英语人民教育出版社）；幼儿园测评大班下册语言、科学、数学（江苏教育出版社（凤凰小康轩））。

五、 面试程序

1、报到、交费：考生于2017年7月19日下午15:00至17:30持本人身份证、笔试考试准考证在宁强县教体局三楼会议室报到，参照《关于录用机关工作人员和国家工作人员收费等有关问题的通知》（陕价费调发[2001]89号）相关标准，考生交面试费用50元。

2、抽签确定顺序：考生于2017年7月20日上午8:00在面试点候考室抽取试讲顺序签。

3、备课：按抽取顺序每隔10分钟，由引导员引导至备课室抽取课题，进行40分钟的手工备课。

4、现场试讲：考生按备课时间完成后按顺序带上抽签号、试讲稿，在引导员引导下进入面试教室试讲，每人限时10分钟，试讲完成后，将试讲稿上交评委，作为试讲评价的参考。

5、公布成绩：待后一名考生面试结束，公布前一名考生面试成绩，考生本人对面试顺序号和面试成绩当场核对，确认无误后签字退场。

六、面试纪律要求

1、考生须持本人身份证、笔试准考证原件按时报到参加面试，证件不齐，未按时报到抽签者不得参加面试。

2、面试期间实行全封闭管理。使用的教材、纸张统一提供，考生除自带备课用笔外，不得携带任何辅导材料和参考用书。考生经金属探测仪检测通过后，进入休息室，通讯工具自行关闭后，一律交监察员统一保管，面试结束后领取自带物品，方可离开考场。面试考点实行无线电信号屏蔽，试讲过程全程录像。

3、面试开始后，候考考生未经允许不得离开侯考室，已经结束面试的考生不得返回侯考室，须在指定地点等候，待签字确认面试成绩后退场，且不得在校园内逗留。

4、考生只报告面试号，不得介绍本人基本情况和家庭情况（考委会成员也不得询问），考生必须服从现场工作人员的安排和相关规定进行面试，否则按违纪处理。

5、面试考官及面试工作人员凡与应聘人员有夫妻关系、直系血亲关系、近姻亲关系等应当主动提出回避。

6、面试考官及相关工作人员要严格遵守考试的规章制度，自觉接受纪检、监察和社会各方面的监督，对违反工作纪律的面试考官及工作人员，按照有关规定严肃处理。

七、确定体检、政审人员的原则方法

根据考生笔试成绩的50%，加面试成绩的50%，按照招聘专业计划数按1:1的比例，从高分到低分确定参加体检、政审人员。

面试总成绩不四舍五入保留2位小数，总成绩并列时，以笔试成绩高的优先，笔试成绩并列时，本县籍生源优先，本县籍生源成绩再并列时，学历高的优先，学历相同时，毕业时间早的优先。
