# 宁强县农业技术推广中心关于加强粘虫监测与防控的紧急通知

各镇（办）农业综合服务站：

粘虫是一种远距离迁飞暴发性害虫，主要危害玉米、水稻、小麦、大豆等多种作物及杂草。该虫具有群聚性、迁飞性、杂食性、暴食性等特点，属农业重大害虫。成虫迁飞，幼虫食叶，大发生时可将作物叶片全部食光，造成严重损失。5月下旬以来，江苏、安徽、河南、山东、陕西等地一代成虫进入发生高峰期，大部地区诱虫量高于前两年。预计二代粘虫总体偏重发生。最近城固、勉县、南郑、洋县、西乡等县陆续发现玉米粘虫为害，有的县发生面积较大为害较重，现在正在组织防治。为做好粘虫防控工作，确保秋粮生产安全，现将有关事项通知如下：

一.各镇办要高度重视，立即抽调人员，及时调查了解掌握粘虫发生情况，抓好应急防控。由于粘虫发生危害的不确定性和暴发性的特点，各镇办要尽量扩大调查范围，不留死角，充分利用各种会议宣传到每个包村干部和村组干部，利用他们在村组开展工作的便利，及时调查了解掌握本辖区粘虫发生情况，各镇办农业综合服务站及时汇总上报。

二.及时上报粘虫发生及防控情况，施行零报告制度。从7月开始，至8月上旬，各镇办要安排专人在每周五向县植保站上报粘虫发生情况及防控情况。如发现粘虫危害，要立即上报并组织防治。

三、防治方法：当百株玉米虫口达30头时，应立即进行防治，防治适期掌握在三龄前。每亩用2.5%敌百虫可溶性粉剂2千克，或4.5%高效氯氰菊酯每亩用120毫升或亩用120毫升25%唑磷.毒死蜱兑水30公斤进行喷雾，连续用药2次。喷药时，需对发生田内及周围杂草一起喷药。
