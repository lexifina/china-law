# 宁强县招聘特岗教师体育专业面试公告

为适应我县发展特色教育工作的需要，拟招聘3名体育教师（其中篮球1人，羽毛球1人，足球1人），充实到我县教师队伍中，针对面试的相关内容、评分方法等事项制定如下方案：

1、技能评定（100分）

由考生根据自己特长选报进行测试

（1） 篮球技评：根据篮球技评内容及项目逐项进行测试。

（2）羽毛球技评：根据羽毛球技评内容及项目逐项进行测试。

（3）足球技评：根据足球内容及项目逐项进行测试。

2、评分说明

每个项目的计分方法：评委按各项技评内容标准打分，将该项目各项得分汇总即得出该项目的总分。

篮球技评内容及项目（100分）

（一）往返运球上篮(10分)

1、 测验方法：由球场右侧边线与中线交叉点持球开始，面向球篮以右手运球并上篮，听裁判员口令出发，计时开始;球中篮后，右手运至左侧边线与中线交叉点;然后折回换左手运球上篮;球中篮后，左手运球回到原起点。

2、要求：运球过程中如出现违例(带球走、运球翻腕、两次运球)现象每次扣2分，投篮不中扣2分。(图)

（二）投篮(15分)

1、 在罚球线投篮15次，投进一个得1分；

2、投篮时任何一只脚不得踩线。

（三）助跑摸高(15分)

1、测验方法：助跑单脚(或双脚)起跳摸高，记录触及的最高高度，每人试跳两次，取最佳成绩。

2、要求：测试前受测者在单(双)手指上涂抹粉末，摸高时粉末触及的刻度线为摸高成绩。

3、评分标准：15分(3.15米)、13分(3.13米)、12分(3.10米)、11分(3.08米)、9分(3.05米)、6分(3.00米)、5分(2.95米)、4分(2.90米)、3分(2.85米)、1分(2.80米)

（四）25米折返跑(10分)按名次加10分、9分、8分、7分、6分、5分、4分。

（五） 一对一对抗(50分)

1、每场投入5个球为胜。

2、第一名：50分 第二名：45分 第三名：40分

第四名：35分

羽毛球球技评内容及项目（100分）

比赛：100分

第一名：100分 第二名：90分 第三名：80分

第四名：70分 第五名：60分

(1) 比赛用亚狮龙6号球；

(2) 比赛采用三局二胜21分制；

(3) 比赛不分男女，男女比赛中女到15分胜，男到21分胜；

(4) 比赛使用室外场地。

足球技评内容及项目（100分）

（一）垫球（20分）

第一名：20分 第二名：15分 第三名：10分 第四名：9分 第五名：8分

（二）绕杆射门（25分）

第一名：25分 第二名：20分 第三名：15分 第四名：10分 第五名：8分

（三）精准吊球（40分）

第一名：40分 第二名：35分 第三名：30分

第四名：25分 第五名：20分

(四) 30米折返跑（15分）

第一名：15分 第二名：10分 第三名：8分

第四名：7分 第五名：6分

3、计分办法

1、篮球专项总分=篮球技评分+笔试成绩。

2、羽毛球专项总分=羽毛球技评分+笔试成绩。

3、足球专项总分=足球球技评分+笔试成绩。
