# 关于申报2017年县级现代农业园区和镇级农业示范园的通知

各镇人民政府、街道办、各有关部门：

为加快我县现代农业发展步伐，进一步凸显农业园区示范引领作用，根据《宁强县县级现代农业园区镇级农业示范园认定标准》，现将申报有关事项通知如下:

一、申报条件。拟申报的县级现代农业园区和镇级示范园要符合《宁强县县级现代农业园区镇级农业示范园认定标准》（宁农园办发〔2014〕1号）之规定。

二、申报程序。符合条件的县级现代农业园区和镇级农业示范园填报申请表，并提供相关印证材料。各镇（街道办）和县产业部门对申报材料的真实性进行审查，签署初审意见后加盖印章报县农业局，县农业局将组织考察组对推荐的县级现代农业园区和镇级农业示范园进行复核筛选，择优予以认定。

三、申报要求。各镇（街道办）和产业部门要严格把关，择优选取申报对象。推荐申报材料按照顺序装订成正式文本，一式1份，于2017年10月20日前报县园区办（县农业局）。《宁强县县级现代农业园区、镇级农业示范园认定标准》和申请表格在宁强县农业信息网自行下载。
