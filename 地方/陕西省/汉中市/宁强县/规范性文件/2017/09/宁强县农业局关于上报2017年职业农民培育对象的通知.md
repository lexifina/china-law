# 宁强县农业局关于上报2017年职业农民培育对象的通知

各镇（办）：

根据汉中市农业局 财政局《关于2017年新型职业农民培育工作实施方案》（汉农计财〔2017〕27）文件精神，为做好2017年职业农民培育工作，经研究，现将我县2017年职业农民培育对象遴选有关事项通知如下：

一、2017年新型职业农民培育工作，市上下达我县100名生产经营培育对象，这次开设种植和养殖两个班，培育对象由各镇（办）按照下达名额认真筛选推荐（名额附后），新型职业农民培育将纳入对各镇（办）年终考核指标，各镇（办）要高度重视并确定一名联络员，负责做好此项工作。

二、培育对象遴选条件：

1.年龄在18-55岁之间；

2.具备初中及初中以上文化程度，收入主要来源于农业，并且收入达到当地农民人均纯收入的3倍以上；

3.农业职业特征明显、经营规模大、主体地位明确、从业稳定性高，具备新型职业农民特征，包括种养大户、家庭农场主、农民专业合作社骨干；

4.有农业产业创业投资意向的农科大中专毕业生、返乡青年、复转军人。

符合以上条件三年内（2014-2016年度）已参加过职业农民培育的人员不得再推荐。

三、对推荐的培育对象经县培育办审核通过后，按《陕西省新型职业农民教育培训大纲(试行)》的要求进行公共基础课、专业技能课、能力拓展课和实践操作课培训，符合认定条件，由县农业局认定为初级职业农民，核发新型职业农民资格证书，持证人员可依据县政府奖励扶持办法，申请政策项目资金扶持。

四、上报要求：各镇（办）按照推荐名额确定人员后，由本人认真填写生产经营型职业农民基本情况调查表，于9月21日前将加盖镇（办）公章统一报宁强县职业农民培育办公室（宁强县农广校），地点：宁强县农业技术推广中心三楼，联系人：李文兵，电话4222146。

宁强县农业局
