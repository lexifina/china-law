# 关于建立保障性住房申请资格准入和退出联审联查工作机制的通知

各镇人民政府、街道办事处，县政府各有关部门、直属机构,市县双管单位：

为进一步加强我县保障性住房准入退出管理，建立规范有序、公开透明、运作高效的管理机制，确保准入退出公开、公平、公正，根据汉中市住房和城市管理局《关于进一步加强保障对象准入退出管理的通知》（汉市住管发〔2013〕152号）要求，经县政府研究，决定建立保障性住房申请资格准入退出联审联查工作机制。现就有关事项通知如下：

一、审查对象和审查内容

（一）审查对象：公共租赁住房申请对象，保障性住房租赁补贴申请对象，经济适用住房、限价商品住房申购对象。

（二）联审联查内容：对保障性住房申请对象或已纳入住房保障范围的家庭及其成员的住房情况、收入情况和家庭财产情况进行审查核实。

二、审查途径

联审联查通过下列途径组织实施：

（一）工资性收入可以通过调查就业和劳动报酬、各种福利收入情况以及社会保险费、住房公积金、个人所得税的缴纳等方式进行审核；

（二）经营性净收入可以通过调查工商登记、企业或者个体工商户的生产经营状况等方式进行审核；

（三）财产性收入可以通过调查利息、股息与红利、保险收益、出租房屋收入以及知识产权的收益情况等方式进行审核；

（四）转移性收入可以通过调查养老金、失业保险金、社会救济金、住房公积金的领取以及获得赠与、补偿、赔偿等情况进行审核；

（五）实物财产可以通过调查房产、车辆等有较大价值实物的拥有情况等进行审核；

（六）货币财产可以通过调查存款、有价证券持有情况及债权债务情况等方式进行审核。

三、职责分工

建立县住建、国土、民政、公安、财政、人社、税务、市场监管和金融机构、住房公积金管理部及各镇（办）等部门单位保障性住房准入退出联合审查机制，各部门单位按照各自职责分工，认真审查相关信息并出具证明。具体职责分工如下：

各镇（办）：申请受理，通过书面审查、入户调查、信息查证、邻里访问(有记录并留存影像资料)以及信函索证等方式，对申请人家庭或已纳入住房保障范围家庭住房、收入及资产等情况进行调查核实，并提出初审意见。

县保障性住房管理中心：负责保障性住房准入退出联合审查工作的组织协调和推进；负责组织相关部门对申请人家庭成员资格进行复核认定、公示及发起年度抽查、复审等工作；负责收集汇总有关部门审查情况信息，并提出审核意见。

县民政局：负责对城镇最低收入家庭和低收入家庭进行认定，做好申请家庭成员婚姻关系审查。

县公安局（车辆管理所）：负责对申请人及其共同申请人的居住情况、户籍情况以及购置车辆信息等情况进行认定。

县财政局：负责保障性住房租赁补贴资金的筹集、拨付、管理和预决算审核以及监督检查。

县人社局：负责对申请人及其共同申请人就业、缴纳社会保险费和领取社会保险待遇等信息进行认定。

县国土局（不动产登记局）：负责对申请人及其共同申请人的不动产权信息进行认定。

县住建局：负责对申请人及其共同申请人拥有或承租的房产、房产交易等信息进行认定。

县国税局、地税局：负责对申请人及其共同申请人个人、个体工商户或注册企业的经营性收入及纳税信息进行认定。

县市场监管局：负责对申请人及其共同申请人投资设立企业及个体工商户等信息进行认定。

县人行：负责协调各银行及其他金融机构配合提供申请人及家庭成员的存贷款、个人保险、证券等信息。

县住房公积金管理部：负责对申请人及其共同申请人公积金缴纳和提取、贷款等情况进行认定。

县监察局：对各部门单位联审联查工作进行监督。

四、工作程序

（一）准入资格审核程序

1.申请受理及初审。各镇（办）、社区居委会负责受理本辖区现居住家庭保障房实物配租或租赁补贴申请，核查相关情况后进行公示。各社区居委会提出初审意见并公示后3个工作日内上报所属镇（办），相关镇（办）从受理之日起15个工作日内提出审核意见并完成公示，公示后3个工作日内报送县保障性住房管理中心。

2.联合审查。县保障性住房管理中心自收到各镇（办）保障房申请材料之日起5个工作日内组织开展有关部门联合审查，各有关部门自收到联查信息起10个工作日内进行信息核查并反馈审查意见。

3.复核认定。县保障性住房管理中心自收到各部门复审意见后10个工作日内进行复核认定并公示。

（二）保障资格退出及年审程序

1.主动退出。对保障对象因不再符合保障条件或其他原因主动退出保障资格的，在提出退出保障性住房申请后，由县保障性住房管理中心直接办理有关手续，不再经过各部门联合审查。

2.资格年审

（1）每年第四季度，县住建局及县保障性住房管理中心对已入住保障性住房或继领租赁补贴的保障对象进行年度审核。各镇办及社区居委会按照要求，通知辖区住房保障对象及时提交相应审核资料，并到涉及联审联查部门取得家庭成员有关审核信息，5个工作日内将所有审核资料报送户籍所在地社区居委会或镇办。

（2）各镇办及所属社区居委会在收集汇总住房保障对象年审资料后，应采取入户调查、函调相关信息、走访邻里等方式，在20个工作日内完成所有住房保障对象资格初审工作，公示无异议并签注明确意见后，提交县保障性住房管理中心进行复审。

（3）县保障性住房管理中心接收各镇办审核材料后，在15个工作日内完成复审，作出资格审核最终意见，公示5个工作日后向被审核住房保障对象送达终审意见。对符合住房保障条件的，继续享有保障性住房居住资格。对不符合保障条件，应退出保障性住房的对象，各镇办、社区居委会积极配合县保障性住房管理中心取消其住房保障资格。

五、相关要求

（一）在保障性住房申请和复核时，申请对象应当出具同意资格审查承诺书。

（二）经申请人及其共同申请人同意，有关联审联查部门根据需要对申请人及其共同申请人个人房产、车辆、资产、储蓄、贷款、财产收益情况以及股票、基金、期货、金融产品、证券、保险产品等持有情况进行查询，并提供相应证明材料。

（三）各联审联查部门要认真履行职责，根据各自职责分工，指定专人负责，按照审查内容和时限，严格进行信息核查，准确掌握申请人家庭结构、住房、收入和财产状况，未按规定内容或时限反馈核查信息的，视为“同意默认”，由相关部门承担相应后果和责任。各有关部门要依法依规开展联审联查工作，对相关信息予以保密，不得向与审核工作无关的组织或个人泄露。对滥用职权、玩忽职守、徇私舞弊，造成一定后果的，根据国家法规严肃处理，构成犯罪的，依法追究刑事责任。

（四）县保障性住房建设工作领导小组办公室要建立保障性住房准入退出联合审查情况通报制度，每季度对有关部门单位保障性住房准入退出审查工作开展情况进行一次通报，对工作开展滞后、推进不力的予以通报批评。

（五）县监察部门积极进行监督，确保住房保障资格联审联查公开公正、循法合规。
