# 关于印发宁强县行政事业单位房屋土地国有资产出租出借实施细则（试行）的通知

印发宁强县行政事业单位房屋土地国有资产

出租出借实施细则（试行）的通知

各镇、街道办，县委和县级国家机关各部门、直属机构，各人民团体:

《宁强县行政事业单位房屋土地国有资产出租出借实施细则（试行）》已经县政府研究同意，现印发给你们，请认真贯彻执行。

宁强县财政局

2017年11月 10日

宁强县行政事业单位房屋土地国有资产

出租出借实施细则（试行）

第一章总则

第一条为加强全县行政事业单位国有资产管理，规范行政事业单位国有资产出租、出借行为，维护国有资产权益，确保国有资产的安全、完整，根据《汉中市行政事业单位房屋土地国有资产出租出借管理办法》（汉政发〔2014〕3号），结合我县实际，特制定本实施细则。

第二条本细则适用于全县各级党政机关、事业单位，以及由财政供给经费的社会团体。

第三条行政事业单位国有资产出租（含出租、合作、参股），是指单位在保证行政职能正常履行、事业正常发展的前提下，将闲置的房屋、建筑物、场地由非经营性资产转为经营性资产取得资产收益的行为。包括各类办公性用房、商业（生产）性用房、仓储性用房、居住性用房及临时性构筑物、场地的出租。以承包等名义，提供房屋给他人使用，取得收益而不承担经营风险的，视同房屋出租。

行政事业单位国有资产出借是指单位将自己占有使用的国有资产使用权出借给同级财政供养的行政事业单位不超过一年的行为。行政事业单位国有资产不得出借给非财政供给的其他单位或个人；出借超过一年以上的应当办理资产调拨审批。

第四条行政事业单位国有资产出租须报县财政局审核批准，未经批准不得擅自出租。行政事业单位国有资产出租收入的收缴工作，由县非税局负责。各行政事业单位、社会团体对出租资产进行日常管理。

第五条行政事业单位国有资产出租，应当遵循“价高优先和自愿、平等、互利”的原则，采用公开招租的方式对外出租，接受社会的监督。

公开招租的方式有：竞价（拍租、挂牌）、招标。整体资产出租、年租赁收入在2万元以上的国有资产出租必须实施公开招租。

第六条行政事业单位国有资产招租工作由县财政局会同主管部门及资产占有使用单位组织实施。

第二章实施程序

第七条行政事业单位出租国有资产必须经单位领导班子集体研究决定，形成会议纪要，并在单位内进行公示。

行政事业单位进行国有资产出租时，必须对承租人的经营行为和承租能力进行认真考察。单位领导班子成员的亲属承租国有资产，应实行回避制度。

第八条拟出租国有资产的单位应填报《宁强县行政事业单位国有资产出租审批表》，上报其主管部门审核后，报县财政局审批，主管部门出租国有资产则直接报县财政局审批。

第九条行政事业单位房屋、场地等国有资产的出租租赁价格不得低于同地段房屋、场地租赁的市场价格。对于公开招租的房屋、场地原则上应当委托有资质的社会中介机构，根据其房屋价值并综合考虑房产所在地段、租赁市场行情等因素对租金进行评估，确定出租房屋的租赁建议价格。

第十条公开招租程序：

1、资产评估。由县财政局委托有资质的评估中介机构进行评估；

2、发布公告。公告时间不得少于10个工作日；

3、招租报名；

4、竞价招租，中标确认。

第十一条签订合同。资产租赁合同按规定的范本要求，由单位与承租人之间签订，并报主管部门、县财政备案。合同期限原则上签订1-3年，最长不超过5年。对遵纪守法、文明经营且按时交纳租金等费用的原承租人要求租赁合同到期后续租的，在同等条件下可以给予优先。

第十二条下列行为的国有资产出租，经县财政局审批同意后，可以采用协议租赁等其他租赁方式，但租赁价格不得低于市场价格：

（一）经公开征集只产生一个报名者的；

（二）出租给县行政事业单位作为办公用房的；

（三）零星资产出租、收益在2万元以下的国有资产出租的；

（四）其他经审批同意未实施公开招租的。

第十三条对于公开招租未成交（流拍）的国有资产，原则上仍应以原租赁建议价再次实行公开招租。对以原租赁建议价公开招租两次以上无人参与竞拍的国有资产，可采取协议价租赁。

第十四条出租的行政事业单位国有资产，其资产的国家所有性质不变，行政事业单位在搞好物业管理的同时赋有保障国有资产安全完整的职责，承租人应当按照租赁合同的约定使用资产，未经许可，不得擅自转租。

第三章收入管理

第十五条行政事业单位国有资产出租收入属国有资产经营收益，按照政府非税收入管理的规定，纳入部门预算，实行收支两条线管理。

第十六条行政事业单位国有资产租金，由县非税局，依据县财政局确认的合同载明金额和交款期限收取。

第十七条行政事业单位国有资产出租收入应缴纳的税费，由出租单位向县地税局申报缴纳。

第十八条对于承租人违反合同约定，出租人收回出租的房屋，应当重新履行公开招租程序，收取的违约金按照房租收入进行管理。

第四章责任追究

第十九条行政事业单位出租国有资产，必须严格按照程序，报县财政局审批。对于不按照规定程序，暗箱操作的租赁行为，一律视为无效。

第二十条对于不按期缴纳租赁收入的部门和单位，县财政采取预算扣款等方式强制收缴，经强制手段收缴的租金一律不予返还，并收回该单位对出租资产的受托管理权。

第二十一条出租单位与承租方相互串通，隐瞒收入，私设“小金库”，一经发现，取得的租赁收入将全部没收上缴，同时并按有关法律、行政法规规定，追究有关单位领导和直接责任人的责任。

第二十二条行政事业单位国有资产出租未按规定实行公开竞租、与承租人相互串通隐匿、截留、贪污、私分租金收入，不实行“收支两条线”管理、以收坐支的；不按照规定办理出租各类手续，逃避监督的；有其他违规行为，造成国有资产流失的。由纪检监察机关立案查处，构成犯罪的，移送司法机关追究刑事责任。

审计部门要强化监督，定期不定期对资产收益的缴存、使用情况进行抽审，及时将抽审情况反馈给县纪检、财政部门。

第五章附则

第二十三条以下房产的出租暂不适用本细则：

（一）居住性的政府直管公房；

（二）纳入县政府统一规划出租的廉租住房；

（三）其他有特殊规定用途的房产。

被设置为担保物的房产出租，应当符合《中华人民共和国担保法》、《中华人民共和国物权法》等法律的有关规定。

第二十四条因政府统一规划拆迁或不可抗力等特殊因素影响，需提前解除租赁合同的，经原产权单位和县财政局审核后，将未到期限部分的租金退还给承租人。

第二十五条国有企业（国有独资及控股企业）、企业化管理的事业单位房屋、场地出租参照本细则管理。

第二十六条 本细则未尽事宜，按照国家法律、政策规定行。

第二十七条 本细则自发布之日起执行。
