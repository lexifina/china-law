# 关于规范行政裁量权的通知

各行政执法单位：

为贯彻落实《法治政府建设实施纲要（2015-2020年）》（以下简称《纲要》）、《陕西省建设法治政府实施方案（2016-2020年）》严格规范公正文明执法要求和《陕西省人民政府关于全面规范行政裁量权的意见》（陕政发〔2016〕21号）精神，结合宁强实际，现就我县规范行政裁量权工作通知如下：

一、充分认识规范行政裁量权的重要基础意义

严格执行行政裁量基准制度，规范行政裁量权，是《全面推进依法治国若干重大问题的决定》的总体部署，是《纲要》、《实施方案》关于行政执法的具体要求，也是推进行政执法责任制和重大行政执法决定法制审核制度的必要环节和基础配套制度。各单位要高度重视执行行政裁量基准制度，规范行使行政裁量权，各单位法制机构作为本单位行政裁量权执行的监督机构，要逐步建立行政裁量权执行、监督制度，确保行政执法行为做到严格、规范、文明、公正。

二、规范行政裁量权内容

（一）合法合理裁量。法律、法规和规章没有规定行政裁量的，行政机关应当严格依照相关规定实施行政管理。法律、法规和规章规定行政裁量的，行政机关应当按照法定程序在法定行政裁量范围、种类、幅度内行使裁量权。行使裁量权应当符合法律、法规和规章目的，排除不相关因素干扰，所采取的措施和手段应当必要、适当，可以采用多种方式实现行政目的的，应当采用对当事人与违法行为的事实、性质、情节、以及社会危害程度相当，损害最小的方式，除法律依据和客观情况变化以外，因素相同或相似的，应做出基本相同决定。

（二）公开裁量基准。所有行政裁量基准应在县政府门户网站公开，以便公众查询，接受社会监督。本通知附件中各裁量基准由县政府法制办统一进行公开，今后行政机关依据相应法律、法规和规章立改废释和上级业务指导部门对行政裁量基准进行修订、废止、新制定等情形或在各单位调查摸底中遗漏本部门行政裁量基准的，应及时向县政府法制办备案，并报送县信息办在县政府门户网站公开更新。

（三）探索裁量基准。法律、法规和规章规定行政裁量，但中、省、市相关部门没有制定行政裁量基准，确因行政执法需要，可在市级业务指导部门和同级政府法制机构同意后，依据法律、法规和规章规定，探索制定相应裁量基准试行办法，服务行政执法工作。法律、法规和规章修改或中、省、市出台相应行政裁量基准后自行废止。

三、切实保障行政裁量规范行使

（一）加强组织领导。规范行政裁量权工作法律性强、业务能力要求高，各行政执法单位是本部门规范行政裁量权的责任主体，要切实做好上下对应和衔接，及时掌握上级行政裁量基准动向，依法规范履行行政裁量权，推动行政裁量基准贯彻落实工作严格、规范、文明、公正。

（二）健全制度衔接。行政执法单位要确保行政裁量基准在行政执法工作中得到有效落实，在落实行政执法责任制的基础上，强化部门法律法规规章、行政裁量基准和《宁强县重大行政执法决定法制审核制度》培训工作，畅通各项制度有效衔接，依据法律法规规章指导行政裁量基准合法合理贯彻执行，以《重大行政执法决定法制审核制度》检验行政裁量基准同等、相似因素基本平等对待。

（三）加强督促落实。各单位的法制机构是部门行政裁量权行使内部监督机构，要结合《宁强县重大行政执法决定法制审核制度》，在进行法制审核时督促本单位各执法机构全面准确落实行业行政裁量基准，县政府法制办将通过行政执法监督检查、行政执法案件评查等途径，对行政执法部门行使行政裁量权制度进行监督检查，对违法违规形式行政裁量权导致重大违法或出现在本行政区域产生重大影响的行政违法案件，将按照《陕西省行政执法责任制实施办法》追究有关人员责任，执法单位在依法行政考核中扣除全部分值。
