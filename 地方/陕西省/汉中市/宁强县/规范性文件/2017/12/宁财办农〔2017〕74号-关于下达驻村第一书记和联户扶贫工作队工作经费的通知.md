# 关于下达驻村第一书记和联户扶贫工作队工作经费的通知

县财政局农财科：

根据汉中市财政局汉财办农〔2017〕52号文件通知，为了充分调动驻村第一书记和联户扶贫工作队员的积极性，根据省市“对驻村第一书记和联户扶贫工作队员加强管理激励的意见”，现将市级驻村第一书记经费和联户扶贫工作队工作经费64.2万元下达你科，列2017年支出功能科目“2130599其他扶贫支出”，县级经济分类科目列“51201不同级政府间转移性支出”。

请严格按照专项资金管理规定，加强资金监管，确保专款专用，提高资金使用效益。

宁强县财政局

2017年12月25日
