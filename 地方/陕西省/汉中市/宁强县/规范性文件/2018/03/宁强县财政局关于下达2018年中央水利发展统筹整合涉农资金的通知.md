# 宁强县财政局关于下达2018年中央水利发展统筹整合涉农资金的通知

关于下达2018年中央水利发展统筹

整合涉农资金的通知

县扶贫办：

为进一步提高资金使用效益，保障贫困县集中资源打赢脱贫攻坚战，按照国务院部署要求和省政府办公厅《关于支持贫困县开展统筹整合使用财政涉农资金试点的实施意见》（陕政办发〔2016〕84号），省财政厅、省扶贫办《关于做好涉农资金整合试点工作有关事项的通知》（陕财办农〔2016〕170号）精神要求，统筹整合涉农资金用于脱贫攻坚。根据汉中市财政局(汉财办农〔2018〕22号)文件精神，现下达你们2018年中央水利发展资金1610万元，其中（中小河流治理1200万元，列政府收支科目“2130305水利工程建设”；水土保持370万元，列政府收支科目“2130310水土保持”；水利工程维修养护40万元，列政府收支科目“2130306水利工程维修养护”），政府预算支出经济分类科目“59999其他支出”。

整合资金严格按照《宁强县2018年度统筹整合财政涉农资金实施方案》已下达计划项目实施，涉农资金管理使用严格按照《宁强县统筹整合使用财政涉农资金管理办法》执行，设立专账，按照中省市县资金分级、分项、分账核算，及时报账，管好用好涉农资金。

宁强县财政局

2018年3月16日
