# 关于拨付2018年统筹整合财政涉农资金产业直补到户资金的通知

各镇办：

根据宁强县农业局《关于下达2018年统筹整合财政涉农资金项目直补到户资金的通知》（宁政农函[2018]7号），现将宁强县2018年统筹整合财政涉农资金产业直补到户资金拨付你们，本次拨付1650万元，累计拨款1650万元。请管好用好项目资金，确保专款专用。

2018年3月6日
