# 宁强县体育馆2018年开放方案

根据《体育总局办公厅关于做好2018年大型体育场馆免费或低收费开放工作有关事宜的通知》（体群字〔2018〕49号）要求，现将宁强县体育馆2018年免费或低收费开放工作方案公示如下：

一、宁强县体育场馆简介

宁强县少儿体校是宁强县教育体育局直属的全额拨款事业单位，现有事业管理岗位9人。

宁强县体育馆位于宁强县体育路，占120地亩，总投资9396万元，于2010年建成并投入使用，由县少儿体校负责运营。辖体育场、体育馆、游泳池、乒乓球场、网球场、羽毛球场、篮球场及室外健身广场。2010年以来，少儿体校对各场馆提供专业、系统、常态化服务，确保运行规范有序、健康高效。其中县体育馆于2014年被纳入国家体育场馆免费低收费开放场馆至今，该馆占地面积20788平方米，建筑面积10318平方米，场地面积3000平方米，观众座位3100座；设标准室内篮球场1块，并可根据比赛需要临时铺设羽毛球场6片、乒乓球场16片；辅配健身房1个，配备跑步机6台、各类锻炼器械20余台。可承办省级篮球、排球、乒乓球、羽毛球、跆拳道、体操等单项赛事，也可兼顾市县级大型集会以及各种庆祝活动、文化展览、文艺演出等。

二、免费低收费开放项目、开放时间及收费标准

（一）开放项目和场地

体育馆内所有设施均向公众免费开放。主要包括：6片羽毛球场地、1片篮球场，1个健身房。

同时，为更好地惠及民生保障，助推全民健身活动常态化开展，我们坚持扩大免费开放范围，实行体育场馆设施全部免费对外开放。具体设施有：

1、乒乓球场14张乒乓球台；

2、标准网球场1片；

3、标准足球场1片；

4、标准门球场1片；

5、室外标准篮球场5片；

6、室外健身路径1条、健身广场1个。

（二）开放时间

体育场、体育馆、乒乓球场、健身房、网球场、篮球场免费向社会开放时间：上午7：00—11：30、下午14：30—21：30，公休日、法定节假日、全民健身日每天开放时间超过12小时，周平均开放时间达90小时以上，年平均开放时间350天以上；户外公共区域及户外运动场地、健身设施全天候开放。因维修、保养、安全、训练、赛事、天气等原因，不能向社会开放或需调整开放时间提前7天对外公告。

（三）收费标准

体育馆、健身房、乒乓球场、足球场、田径场、门球场、网球场及室外篮球场、健身广场、健身路径均实行免费向公众开放。

（二）免费向公众提供以下基本公共体育服务

1、力争全年举办各类赛事活动4次以上；

2、体育知识、技能、急救讲座3次以上；

3、开展健身技能培训2000人次；

四、群众参加体育赛事和体育活动、接受体育培训、进行日常健身服务情况

（一）室内体育场地

体育馆、健身房、乒乓球场计划全年接待不低于58320人次、月均接待不低于4860人次，日均接待不低于162人次。全年室内体育场地每万平米平均接待不低于80000人次。

（二）室外体育场地

体育场、网球场、门球场、足球场、田径场、篮球场、室外健身广场计划全年接待不低于230400人次，月均接待不低于19200人次。日均接待不低于640人次、全年室外体育场地平均每万平米接待不低于100000人次。

五、为群众身边的体育组织服务情况

到2018年底，体育场馆将为9个运动项目俱乐部（群众体育组织、体育协会）提供活动场所，会员总数逾800人。

六、成本支出情况

2018年场馆开放成本支出预计最低为150万元，其中水电气热能耗支出最低为30万元。
