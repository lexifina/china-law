# 关于下达2017年统筹整合财政涉农结转结余资金的通知

扶贫办：

按照省市要求加快结转结余扶贫资金支出，进一步提高资金使用效益，杜绝资金趴窝、滞留现象，用好用活扶贫专项资金，现将毛坝河文家坪村灌溉工程项目结转结余资金56万元下达你们（该工程以使用其他资金实施），纳入2018年统筹整合涉农资金使用。尽快将结转结余资金拨付项目单位，

严格按照《宁强县2018年度统筹整合财政涉农资金实施方案》已下达计划项目实施，涉农资金管理使用严格按照《宁强县统筹整合使用财政涉农资金管理办法》执行，设立专账，按照中省市县资金分级、分项、分账核算，及时报账，管好用好涉农资金。

宁强县财政局

2018年11月2日
