# 关于下达宁强县2019年统筹整合财政涉农资金项目投资计划的通知

县交运局、水利局、住建局、农业农村局（含原县委农工部）、生态环境局、文旅局：

为认真贯彻中省市县脱贫攻坚工作会议精神，按照国办发〔2016〕22号《关于支持贫困县开展统筹整合使用财政涉农资金试点的意见》文件有关要求，我县积极统筹整合财政涉农资金35161万元用于村组基础设施建设及产业项目发展，并撬动金融资本和社会帮扶资金8194万元投入脱贫攻坚，确保2019年实现1.24万贫困人口脱贫，54个贫困村摘帽（含13个深度贫困村）。依据《宁强县2019年度统筹整合财政涉农资金实施方案》（宁脱组办发〔2019〕3号）文件，现将全县2019年统筹整合财政涉农资金项目投资计划下达你们，并就有关事项通知如下：

一、下达宁强县2019年统筹整合财政涉农资金项目397个，总投资43355万元，其中统筹整合财政涉农资金35161万元，社会资金7144万元，其他资金1050万元。

项目计划包含2019年提前启动的两批项目，项目计划文件分别是“宁发改代赈〔2018〕188号”、“宁发改代赈〔2018〕345号”，由于前期启动的部分项目在实施工程中有调整，调整后前两批项目计划以此文件为准（详见附件1、附件2备注）。项目分类如下：

（一）基础设施类项目133个，总投资12868万元，其中财政资金12868万元。

1、交通基础设施项目48个，总投资5576万元，其中财政资金5576万元。

2、水利基础设施项目53个，总投资5765万元，其中财政资金5765万元。

3、农村环境综合整治项目25个，总投资1410万元，其中财政资金1410万元。

5、危房改造项目7个，总投资117万元，其中财政资金117万元。

（二）产业发展类项260个，总投资30242万元，其中财政资金22048万元,社会资金7144万元，其他资金1050万元。

6、产业道路建设项目22个，总投资2104万元，其中财政资金2104万元。

7、产业直补到户项目18个，总投资2248万元，其中财政资金2248万元。

8、农业产业化项目76个，总投资5699万元，其中财政资金2766万元，社会资金2623万元，其他资金310万元。

9、村集体经济发展项目33个，总投资4740万元，其中财政资金4740万元。

10、食用菌产业发展园区建设项目14个，总投资3746万元，其中财政资金2478万元，社会资金1268万元。

11、光伏项目：续建2018年已启动光伏项目24个，总投资600万元，其中财政资金600万元。

12、乡村旅游项目4个，总投资840万元，其中财政资金840万元。

13、产业贴息项目1个，总投资1400万元，其中财政资金1400万元。

14、烟叶发展项目24个，总投资431万元，其中财政资金431万元。

15、农业产业园建设项目26个，总投资5223万元，其中财政资金1230万元，社会资金3253万元，其他资金740万元。

16、贫困户退出后续产业扶持项目18个，总投资3211万元，其中财政资金3211万元。

（三）其他类4个，总投资245万元，其中雨露计划、技能脱贫“千校行动”和致富带头人培训145万元，项目管理费100万元。

二、切实加强项目管理，确保工程质量。各相关行业主管部门接此通知后，要加快项目的组织实施。对由镇办具体组织实施的项目，要在3日内将项目（主要指第三批项目）投资计划分解转发给相关镇办。要严格按照批准的项目设计组织施工，严禁随意变更项目名称、规模和项目建设内容。要认真落实项目法人责任制、招投标制、合同管理制和工程监理制。各行业主管部门要加强工程质量监管、做好技术指导，除落实专业技术人员具体负责工程质量外，还要有当地的村民代表参与工程质量监督，确保项目顺利实施。

三、在项目实施过程中，应科学组织施工，严把投资概算，力求节约资金。项目建设资金如有结余收回县财政，由县涉农资金管理工作领导小组统筹协调使用，严禁擅自挪作他用。

四、在项目建设过程中，县发改局、财政局、扶贫办要积极协同项目主管部门加强督促检查，发现问题及时予处理，确保项目早日建成投用。

五、加强公告公示。各项目主管部门、各镇办要将涉及本行业、本镇办扶贫资金项目安排情况通过政府网站、手机APP、政务公开栏向社会公开。项目实施单位在资金项目实施前后都要在项目所在贫困村或实施地进行公告公示，公告公示位置要醒目、时限不少于10天。公告公示主要内容包括项目名称、资金来源、资金规模、实施地点、建设内容、实施期限、预期目标、项目实施结果、实施单位及负责人、监督举报电话等。

六、各项目建设单位要切实加快项目建设进度，确保本次所有建设项目在2019年9月底前竣工投入使用。同时要及时收集项目建设资料，并于每月十五日前和月底前分两次将项目建设进展情况报送业务主管部门，由业务主管部门收集、汇总后报县脱贫攻坚工作领导小组办公室。
