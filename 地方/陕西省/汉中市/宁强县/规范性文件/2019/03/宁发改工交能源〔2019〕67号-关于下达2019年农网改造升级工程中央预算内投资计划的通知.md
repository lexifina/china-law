# 关于下达2019年农网改造升级工程中央预算内投资计划的通知

宁强县供电分公司：

为进一步推进乡村振兴和脱贫攻坚，筑劳农村电力基础设施，提高农网供电能力和供电可靠性，促进农村经济社会发展。按照市发改委《关于下达2019年农网改造升级工程中央预算内投资计划的通知》（汉发改能源〔2019〕105号），下达我县2019年农网改造升级工程中央预算内投资计划1148万元（其中：中央预算内投资230万元，银行贷款919万元）。现将投资计划下达给你们（详见附表），并就有关事项通知如下：

一、宁强县供电分公司要严格按照中央预算内投资及农网改造升级项目管理规定，认真组织实施，按照脱贫攻坚的要求完成建设任务。项目实施中不得擅自变更建设内容，项目确需要调整变更的，按照有关规定和要求重新履行相关审批手续；严格资金管理、核算，严禁挤占、挪用农网改造升级资金，杜绝工程建设中乱收费、乱摊派问题。

二、强化组织领导，加强项目管理。县发改局要充分发挥农网改造升级工作领导小组的作用，适时组织对工程进度和质量的检查监督，协调解决工程建设中的重大问题，确保完成年度建设任务。县供电分公司要加强工程建设和质量管理，按时完成工程建设、决算、审计和单项工程验收，主动依靠各级政府，配合政府的督促检查指导，共同解决好工程建设中的问题，自动接收群众监督，切实解决好群众关心的用电问题。

三、落实工程项目监管责任。项目实施单位要严格落实投资计划执行和监管的主体责任，于每月10日前将投资计划开工情况、投资完成情况、工程进度等数据通过全国投资项目在线审批监管平台报至国家发改委。

四、各镇办、县级有关部门要及时协调解决工程建设中存在问题，做好项目建设环境保障工作。
