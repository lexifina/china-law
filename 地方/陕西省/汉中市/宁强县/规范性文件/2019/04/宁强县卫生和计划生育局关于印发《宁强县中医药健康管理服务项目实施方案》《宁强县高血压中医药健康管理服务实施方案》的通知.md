# 宁强县卫生和计划生育局关于印发《宁强县中医药健康管理服务项目实施方案》《宁强县高血压中医药健康管理服务实施方案》的通知

各镇办卫生院，县直医疗卫生计生单位：

现将《宁强县中医药健康管理服务项目实施方案》《宁强县高血压中医药健康管理服务实施方案》印发给你们，请认真遵照执行。

宁强县卫生和计划生育局

2018年4月8日

宁强县中医药健康管理服务项目实施方案

根据《国家基本公共卫生服务规范(第三版)》《国家中医药健康管理技术规范》要求，充分发挥中医药在公共卫生服务中的作用，不断提升老年人中医体质辨识和儿童中医药调养服务能力。为确保2018年该项目工作全面的有序开展，现结合我县实际，制定本方案。

一、目标

1、老年人中医药健康管理服务率为45%以上。

2、0－36月龄儿童中医药健康管理服务率为45%以上。

二、范围和对象

范围：全县各镇(办)。

对象：1、辖区内居住的所有65岁以上老年人。

2、辖区内居住的所有0－36月龄儿童。

三、成立组织机构

（一）领导小组

组 长：杨春强

副组长：杜永波

成 员：赵 波　殷芳琴　高静安　吴彦超　黄卫华　赵世远

赵鹏飞

（二）技术指导小组

组 长：高静安

成 员：吴彦超　黄卫华　赵世远　李彬　何山雾　李映智　郑静平　徐朝荣

领导小组和技术指导小组下设办公室，办公室设在县中医医院基层指导科，由赵世远担任办公室主任，负责日常管理工作。

四、服务内容

全面掌握本辖区内65岁以上老年人及0－36月龄儿童总数，摸清服务对象，造册登记管理。

（一）65岁以上老年人中医药健康管理服务

按照《国家基本公共卫生项目服务规范》要求开展项目服务工作。每年为65岁老年人提供1次中医药健康管理服务。依照《老年人中医药管理服务记录表》，以老年人近一年的体验和感觉，进行33项问题采集信息，按9类体质类型辨识相关体质，辨识结果告知服务对象。根据不同体质进行中医药保健指导，教会并指导服务对象情志调摄、饮食调养、起居调摄、运动保健、穴位保健等5项服务保健内容。

（二）0－36月龄儿童中医药健康管理服务

认真填写《0－36个月儿童中医药健康管理服务记录表》，按不同月龄进行中医药保健指导，分别在6、12、18、24、30、36月龄向家长提供儿童中医药饮食调养、起居调摄等保健内容。在6、12月龄教会家长摩腹和捏脊方法；在18、24月龄教会家长按揉迎香穴位、足三里穴位的方法；在30、36月龄传授按揉四神聪穴位的保健方法。

五、服务要求

1、开展老年人及儿童中医药健康服务的工作人员，都应为中医类别执业（助理）医师或接受过中医药知识和技能专门培训，能够提供该项目中医药健康管理服务的其他类医师（含乡村医生）。

2、每次服务后要及时、完整记录相关信息，并及时在公卫信息系统中录入，记录在案。

3、各镇（办）卫生院必须按时在次月3号之前报上月的各种服务统计月报表，迟报或不报的记入年底考评。

六、加强业务培训，提高服务能力

县级每年组织一次培训或到各镇培训。各镇卫生院对村卫室中医药管理服务人员，中医药管理服务内容培训一年不少于2次。针对65岁以上老年人33项问题的信息采集，9种类型的中医体质辨识，穴位等五项中医药保健方法，0－36月龄儿童不同月龄段的中医药保健中医饮食调养、起居活动指导和穴位保健方法，运用理论与实践相结合进行适宜技术培训。每次培训必须做到有通知、签到册、课件、印证影像资料、试卷、培训小结等内容。通过培训，使镇村中医药管理服务人员，都能熟炼掌握中医药保健技能，人人都能独立开展中医药健康管理服务，努力提升中医药服务人员的业务水平和服务技能。

七、扎实多样，积极开展中医药健康管理教育工作

广泛宣传中医药健康保健管理服务的内容和政策，充分利用健康教育与健康促进工作的平台，将65岁以上的老人和0－36月龄儿童中医药保健知识通过板报、健康讲座、健康咨询、宣传单等多种形式的宣传。让中医药保健知识进社区、进学校、进商场、进机关、进家庭，积极营造了解中医、拥护中医、积极参与和自觉接受中医药健康管理服务的良好氛围，提高居民的知晓率。

八、经费支持

65岁以上老年人和0－36月龄儿童中医药健康管理服务所需经费在基本公共卫生服务经费中统筹安排。

九、加强督导，严格考核

1、中医药健康管理服务，资料要单独建立，便于检查、督导、考核。

2、县级每半年对该项目实施情况督导检查一次。包括听取汇报、查阅文件、现场核查、走访座谈、电话调查等方式。核实中医药健康管理服务人数。查阅培训和健康教育宣传资料。查看镇卫生院对村卫生室每季度督导检查、考核资料及电子录入情况。

3、对只做表面工作、实质性服务工作未达项目标准的单位，扣减相关经费，并依据有关规定追究主管领导和相关工作人员的责任。

宁强县高血压中医药健康管理服务实施方案

根据《国家中医药管理局关于积极发展中医预防保健服务的实施意见》要求，进一步发挥中医药在防病治病中的作用，不断提高我县对高血压患者的中医药健康管理服务能力，现结合实际制定本方案。

一、明确任务目标

以镇（村）为单位，35岁以上人群高血压患者中医药健康管理服务率为25%以上。

二、范围和对象

全县范围内35岁以上人群中高血压患者。

三、成立组织机构

（一）领导小组

组 长：杨春强

副组长：杜永波

成 员：殷芳琴　赵 波　高静安　吴彦超　黄卫华　赵世远　赵鹏飞

（二）技术指导小组

组 长：高静安

成 员：吴彦超　黄卫华　赵世远　李彬　何山雾　李映智　郑静平

领导小组和技术指导小组下设办公室，办公室设在中医医院基层指导科，由赵世远担任办公室主任，负责日常管理工作。

四、中医药健康管理程序

掌握本辖区内35岁以上高血压患者人数，依照高血压患者中医药健康管理服务要求，以中医理论“四诊合参”“八纲辨证”诊断风痰上扰证、阴虚阳亢证、肝火上炎证、痰瘀互结证、气血亏虚证、肾精不足证等6个高血压患者证型。针对不同证型的高血压患者采取不同的中医药治疗，并指导饮食调养、运动起居保健，传授四季养生、穴位按摩、足浴等中医药技术。

高血压患者中医健康管理服务流程

五、专项服务要求

1、从事35岁以上高血压患者中医药保健工作人员，应为中医类别执业（助理）医师或接受过中医药知识和技能专门培训，能够提供该项目中医药健康管理服务的其他类医师（含乡村医生）。

2、高血压患者中医药保健治疗，每年服务1次，对中医药服务的高血压患者，2周后随访一次。

3、认真填写《高血压患者中医药健康管理服务记录表》，附加随访记录。填写项目要规范、真实、不缺项、漏项。辨证准确，指导服务到位，相关信息记录及时完整，表册一致备查。

4、各镇（办）卫生院在次月3号之前报上月的服务统计月报表，迟报或不报的记入年底考评。

六、加强宣传和业务培训，提高服务能力

1、充分发挥健康教育平台，运用板报、健康讲座、微信、宣传单等多种形式宣传高血压患者中医药健康管理服务的内容，提高居民的知晓率和患者自觉接受的服务率。

2、县级每年组织一次专业培训或到各镇卫生院培训。镇卫生院对村卫生室管理人员，针对高血压病的六个辨证分型和中医药健康指导内容培训一年不少于2次。每次培训要做到有通知、签到册、课件、印证影像资料、试卷、培训小结等内容。通过培训，全面提升高血压患者中医药健康管理服务人员业务水平和服务技能。

七、经费支持

35岁以上高血压患者，中医药健康管理服务所需经费在基本公共卫生服务经费中统筹安排。

八、强化督导，严格考核

1、中医药健康管理服务，服务资料要单独建立，便于检查、督导、考核。

2、县级每半年对该项目实施情况督导检查一次。包括听汇报、查阅文件、现场核查、走访座谈、电话调查等方式。核实是医药健康管理服务人数。查阅培训和健康教育宣传资料。查看镇卫生院对村卫生室每季度督导检查、考核资料等内容。

3、对只做表面工作、实质性服务工作未达项目标准的单位，扣减相关经费，并依据有关规定追究主管领导和相关工作人员的责任。
