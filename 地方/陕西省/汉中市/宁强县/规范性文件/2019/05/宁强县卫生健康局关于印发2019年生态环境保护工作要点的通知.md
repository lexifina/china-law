# 宁强县卫生健康局关于印发2019年生态环境保护工作要点的通知

各镇（办）卫生院，县直医疗卫生单位，宁强协和医院、大安仁康中医医院、宁强精神病康复医院:

现将《2019年卫生健康系统生态环境保护工作要点》印发你们，请认真贯彻落实。

宁强县卫生健康局

2019年5月9日

2019年卫生健康系统生态环境保护工作要点

为深入贯彻落实习近平生态文明思想，切实加强卫生健康系统生态文明建设和生态环境保护，根据市卫生健康委《关于印发2019年生态环境保护工作要点的通知》和宁强县人民政府办公室《关于印发四大保卫战2019年工作方案的通知》（宁政办发[2019]19号）精神，结合我县卫生健康系统实际，制定2019年卫生健康系统生态环境保护工作要点。

一、切实加强领导

(一)深入学习贯彻习近平生态文明思想。树牢“四个意识”，坚决做到“两个维护”，贯彻落实好生态文明建设和生态环境保护重大部署和重要任务，各单位每年研究生态环境保护工作不少于4次。

(二)成立县卫生健康局环境保护督查组。成立主要领导任组长，分管领导任副组长，医政法规、公共卫生、爱国卫生、卫生计生综合监督等单位、股室负责同志为成员的县卫生健康局环境保护督查组，对全系统生态环境保护工作开展督导检查。

(三)严格工作考核。县卫健局已将生态环境保护工作纳入对各单位的目标责任考核指标，年度目标任务未完成的单位主要负责人和有关班子成员不得评先评优。在迎接上级环保督察考核工作中出现重大问题，影响全县、全系统环保工作的单位予以责任追究。各单位也要将生态环境保护工作纳入单位对科室、人员的绩效考核指标。

二、具体工作任务

(四)巩固餐厨污染治理成效。各医疗卫生机构要持续实施“清炉”行动，单位集体食堂要使用清洁燃料，禁止使用煤炭等高污染燃料。单位集体食堂、尚未完成改电、改气等清洁能源和安装餐饮油烟净化设施的医疗卫生机构，5月底前务必改装到位，全面完成“清炉”目标，油烟治理达标排放;对已完成治理的要定期检查抽查，确保设施正常运行，建立运行台账。按照宁卫计函〔2019〕4号《转发市卫计局关于进一步加强餐厨废弃物管理的通知》、《汉中市餐厨废弃物管理暂行办法》要求，加强餐厨废弃物管理，建立健全餐厨废弃物管理制度，逐步安装油水分离器，实现餐厨废弃物规范管理。

(五)加强医疗废物管理。各医疗机构要规范处置医疗废物。医疗废物暂存间设置不规范的要在5月底前完成整改。各镇办卫生院医废集中处置工作要进一步落实代收代缴协议，村卫生室要按规定时间上交至卫生院。各医疗机构要进一步规范医疗废水处置，20张床位以下的医疗机构要合理测算日均污水排放量、规范投放消毒剂、按相关技术标准检测，确保达到排放标准，同时要做好投药记录，保存好消毒剂购买凭证。20张床位以上(含20张)的医疗机构废水无害化处置系统要通过第三方排放检测，并保障24小时无间断正常运行。因地制宜改造污水处理设施，配置污泥脱水设备，降低污泥处置成本。

(六)规范处置医疗卫生机构生活垃圾中的可回收物。按照宁卫计发〔2018〕45号文件转发《关于在医疗机构推进生活垃圾分类管理》（国卫办医发〔2017〕30号）对医疗卫生机构生活垃圾的分类标准，加强输液瓶(袋)等可回收物的管理，严格分拣输液管、针头等医疗废物，可回收物统一交由经商务(经贸)部门备案的再生资源回收经营者。要参考《医疗废物转移联单》建立的转运交接单，做好交接、登记和统计等工作。

(七)加大秦岭生态环境保护区公共场所整治力度。对辖区秦岭生态环境保护区禁止开发区、限制开发区和适度开发区从事住宿、洗浴(游泳)娱乐等公共场所全面排查，准确摸清底数，建立管理台账。要严把行政审批关口，强化监管和整改力度，达到相关标准要求。

(八)完善饮用水水质卫生安全状况信息公示。县卫生计生综合执法大队要督促县自来水厂定期进行水质检验，并及时公布饮用水卫生安全状况，包括但不限于供水单位出厂水质、管网末梢水水质等方面的水质安全状况。

(九)做好辐射安全防护。取得《放射诊疗许可证》的医疗机构，要加强射线装置的安全防护管理，严格落实放射性污染防治措施。制定辐射事故应急处置预案，加强人员培训，配备防护用品，定期组织第三方检测。严格按照相关法律法规要求，规范放射诊疗行为。

(十)加大监督执法力度。开展秦岭生态环境保护区公共场所、医疗废物等专项整治，落实“双随机、一公开”等工作制度，加大监督检查频次和违法案件处罚力度。

三、巩固省委环保督察反馈问题整改成效

(十一)持续抓好省委环保督察反馈问题整改。对照原卫生和计划生育局《关于印发落实省委环境保护督察反馈意见整改方案的通知》(宁卫计发〔2018〕30号)和当前交办的整改任务，全面进行对标自查，定期开展“回头看”，确保整改到位，整改现场不反弹。要做好资料的收集整理，逐项梳理印证材料，确保整改资料与整改现场一致。
