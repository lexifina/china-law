# 宁强县卫生健康局关于印发《宁强县卫生健康局创建省级食品安全示范县工作实施方案的通知

各镇（办）卫生院，县直医疗卫生单位：

根据宁强县人民政府办公室《关于印发2019年宁强县食品安全和创建省级食品安全示范县重点工作安排的通知》（宁政办发〔2019〕16号），结合我局工作实际，制定本实施方案，请认真组织实施。

宁强县卫生健康局

2019年5月10日

宁强县卫生健康局创建省级食品安全示范县工作实施方案

为全面落实省级食品安全示范县创建工作，结合我局工作实际，制定本方案。

一、总体思路

全面贯彻落实习近平新时代中国特色社会主义思想和党的十九大和十九届三中全会精神，全面落实各级党委政府关于加强食品安全工作一系列决策部署，按照“稳中求进、补齐短板、突出亮点、守住底线”的基本思路，以保障和改善民生为出发点，以开展创建省级食品安全示范县活动为抓手，全方位加强食品安全工作，推动我县食品安全形势持续稳定好转，人民群众食品安全满意度明显提升，共享食品安全幸福感。

二、工作任务及分工

1.食源性疾病监测报告。所有医疗机构对疑似与食品有关的感染病例、中毒病例（含横纹肌溶解综合征病例）、异常病例进行监测。扩大食源性疾病监测报告系统覆盖区域，包括县天津医院、中医医院、县妇幼保健院、镇（办）卫生院。（各医疗机构及县疾控中心）

2.食品安全相关信息报告。在调查处理传染病或其他突发公共事件中发现与食品安全相关的信息，以及接到与食品安全相关的食源性疾病病人或疑似病人的报告信息，及时通报县市场监督管理局。（局公卫股、县疾控中心）

3.强化餐饮具集中消毒服务单位的监管整治。按照县市场监督管理局提供的信息，确定被检查名单，结合已取得工商营业执照的餐具、饮具集中消毒服务单位进行监督检查。重点检查餐具、饮具消毒单位的选址、布局、消毒工艺流程、生产用水、设备、使用的消毒产品以及消毒餐饮具的产品包装和标签等内容，对已取得《营业执照》的餐具、饮具集中消毒服务单位，对包装好的消毒餐具、饮具进行抽检，并要求餐具、饮具消毒服务单位开展自检工作。（县卫生计生综合执法大队）

4．做好食品安全培训、宣传及应急演练工作。组织开展全县医疗机构食源性疾病监测报告和食品安全事故流行病学调查培训；组织开展食品安全事故流行病学调查、现场应急演练。（县疾控中心、县健康教育中心、各医疗机构）

三、实施步骤

（一）动员部署阶段：（2019年5月）。研究制定我局创建省级食品安全示范县工作实施方案，统一部署创建活动，并组织宣传发动。

（二）组织创建阶段：（2019年5月—2019年11月）。各单位按照任分工有序推进，全面组织开展各项创建工作。

（三）迎接考评总结阶段：（2019年12月）。迎接县食安办组织考评组对创建工作进行考评，深入总结创建成效和不足，拟定2020年食品安全工作计划。

四、工作要求

（一）加强组织领导。县卫健局对创建工作实施统一领导，细化分解创建任务，明确职责分工和进度安排，及时协调解决创建工作中遇到的问题，切实把各项创建工作措施落到实处。

（二）突出创建过程。各单位要切实开展形式多样、务实高效的宣传引导创建活动，不断增进社会了解，凝聚社会共识，形成人人支持创建、参与创建的良好社会环境，提高食品安全社会参与广度和深度，推动形成食品安全长治久安的良好态势。
