# 宁强县卫生健康局关于进一步加强医院感染预防与控制工作的通知

各镇（办）卫生院，县直医疗卫生计生单位：

为贯彻落实2019年5月14日全国医疗机构感染预防与控制电视电话会议精神，认真汲取南方医科大学顺德医院新生儿科医院感染事件教训，切实加强全县医疗机构医院感染预防与控制工作，维护人民群众健康权益，现将有关事项通知如下：

一、进一步提高对感染防控工作重要性的认识

做好感染防控工作，是坚持以人民健康为中心、实施健康中国战略的任务要求,是落实党中央关于防范化解重大风险决策部署的必然要求,是建立现代医院管理制度的客观要求,是保障医疗质量和医疗安全的底线要求。当前，感染防控工作面临着新的形势与挑战，各地市中医药管理部门和各级中医医疗机构要站在维护人民群众健康权益的角度，进一步提高政治站位，树立底线意识，强化岗位责任，高度重视医疗质量和医疗安全管理；进一步提高对院感防控重要性的认识，树立“三线”思维（感染防控是贯穿诊疗活动的“主线”、是保证患者安全的“底线”和依法执业的“红线”），认真主动地学习贯彻落实感染防控相关法律法规和工作要求，将感染防控的理念和措施，融入到医疗卫生服务的全过程、全环节、全要素之中；进一步落实医疗质量安全核心制度，切实履行政治职责，采取有力有效措施，消除医疗安全隐患，防范化解重大风险，以高度负责任的态度为人民群众提供高质量的医疗服务。

二、进一步落实感染防控工作主体责任

各级医疗机构要切实落实主体责任，法定代表人或主要负责人是感染防控工作的第一责任人。要严格执行《医院感染管理办法》和相关技术规范，切实发挥医疗机构感控委员会作用和医院感染管理质控体系职能，明确感控管理部门、医务、药学、护理、临床检验以及各临床科室的职责分工，压实部门责任，并建立多学科、多部门协作机制，形成合力共同开展感控工作。要进一步加大对感染防控的经费投入，加强对医院感染重点部门，特别是微生物实验室、消毒供应中心、内镜室等的建设，积极建设医院感染信息化监测系统，不得以控制成本和支出为由，挤占、削减感染控制费用，影响感染防控工作的有效开展。

三、进一步加强感染防控人才队伍建设

感染防控工作涉及专业领域广，覆盖了医院感染管理、医疗、护理、药学、临床检验、流行病、疾病控制等多个专业领域。目前大部分医院人员配备数量不足，同时个别医院的院感管理人员还兼有其他工作，各级医疗机构要进一步加强感染防控人才队伍建设，确保感染防控专（兼）职人员配备充足，健全感控人员职业发展路径和激励机制，加大投入倾斜力度，保持感控队伍的稳定性。加强对易发生感染的重点科室管理力度，指定专人负责重点科室感控工作，明确其岗位责任，统一接受感控管理部门业务指导，确保各项防控措施落实到位。同时要做好感染主动监测，及早发现干预医院感染事件。

四、进一步严格落实相关防控措施

各级医疗机构要进一步严格落实各项规章制度和防控措施，对医疗复用器具清洗消毒是否规范、医疗操作人员消毒隔离及感染防控意识是否到位，手术器械是否由供应室集中清洗消毒灭菌，手术室洁污区域分区是否明确、人流物流是否存在交叉等感染风险和管理隐患保持高度敏感和警觉。要督促医务人员必须不断增强依法执业、规范执业的责任意识，深刻认识落实感染防控措施是依法执业的基本要求，在执业活动中严格做到“早发现、早报告、早隔离、早治疗”的感染防控管理要求，全面落实各项感染防控措施。要规范开展医院感染目标性监测工作，对发现的医院感染事件及时准确报告。

五、进一步履行职责

县卫生计生综合监督执法大队要加大对医疗机构感染防控的日常监管，加强对辖区内感染高风险、管理较薄弱的医疗机构的监督检查；县医院感染控制管理中心要加强对基层医疗机构院感防控工作的指导，并及时公开院感信息，及时预警院感风险，查找风险原因，防范感染聚集和暴发事件的发生；县卫健局将把医院感染防控工作作为“一票否决”项，纳入医疗机构等级评审、绩效考核、评优评先等工作；。

六、迅速开展医院感染管理专项检查

各单位要迅速开展医院感染防控自查自纠工作，积极完成整改工作，于5月31日前将整改报告报局医政科，我局将适时对各单位进行抽查。
