# 宁强县健康宁强建设工作委员会关于印发《2019年健康宁强建设工作实施方案》的通知

各镇人民政府、街道办事处，县健康宁强建设工作委员会成员部门：

为全面贯彻落实《健康中国2030规划纲要》精神，进一步巩固国家卫生县城创建成果和提高全民健康意识，现将《2019年健康宁强建设工作实施方案》印发给你们，请结合工作实际，认真贯彻落实。

宁强县健康宁强建设工作委员会

2019年7月18日

2019年健康宁强建设工作实施方案

总体要求是：以习近平新时代中国特色社会主义思想为指导，深入贯彻党中央、国务院健康中国、省委省政府健康陕西、市委市政府健康汉中战略部署，坚持以提高人民群众健康水平为核心，以健康县城、健康镇（街道办）、健康细胞建设为抓手，普及健康生活、优化健康服务、完善健康保障、建设健康环境、发展健康产业，加快健康宁强建设进程，不断提升全县城乡居民健康水平。

一、普及健康生活

1、开展健康生活指导。以合理膳食和适量运动为重点，强化生活方式指导和干预，组织开展三减三健（减盐、减油、减糖，健康体重、 健康骨骼、健康口腔）等专项行动，以镇（街道办）为单位全覆盖，形成健康自我管理，人际互助的社会氛围。

主抓单位：县卫健局，县健康教育中心，各镇（办）卫生院。

2、开展控烟限酒。推进控烟履约，落实领导干部公共场所带头禁烟，全面实施室内公共场所禁烟。加强限酒健康教育，控制酒精过度使用、减少酗酒。

主抓单位：县卫健局、县健康教育中心、各镇人民政府（街道办事处）。

3、开展全民健身活动。实施全民健身计划，开展国民体质监测，推动全民健身生活化。加强社会体育指导员队伍建设。加大全民健身公共设施设备建设力度，促进社区学校、机关、企事业单位的体育设施免费或低收费向社会开放共享。

主抓单位：县总工会、县财政局、县教体局、县直机关工委、县经贸局、各镇人民政府（街道办事处）。

4、培育各类健康人群。将健康教育纳入国民教育体系，落实《中小学健康教育指导纲要》，确保每学期健康教育课程不少于6课时。全县各级机关、企事业单位要积极开展职工健康教育工作，通过健康讲座、健康橱窗（展板）等形式，在全体职工中普及健康知识，落实工间操制度。

主抓单位：县教体局、县直机关工委、县经贸局、各镇人民政府（街道办事处）。

二、优化健康服务

5、推进基本公共卫生服务均等化。全面实施国家基本公共卫生服务项目和重大公共卫生服务项目，对城乡居民主要健康问题实施有效干预，减少主要健康危害因素，健全项目过程考核和质量评估指标体系，提高精细化管理水平。

主抓单位：县卫健局。

6、创新健康服务供给模式。以县天津医院、县中医院为龙头，按照“总额管理、超支不补、结余留用”的原则，实行医保基金按人头总额预算包干支付，建立利益、服务、管理、发展县镇一体的紧密型医疗共同体，促进优质资源上下贯通，减轻群众就医负担，夯实健康管理关口。加强重点临床专科、急救中心建设，促进优质医疗资源下沉，全面提升医疗服务能力。

主抓单位：县卫健局、县天津医院、县中医医院。

7、推进健康管理医防并举。在健联体总体框架下，夯实医院健康联合体和疾控健康联合体的职责，以区域健康信息平台为支撑，深入实施“重点疾病筛查干预、慢病个性化精准管理、健康教育一对一服务”。推进“防大病、管慢病、促健康”的健康管理和健康促进。

主抓单位：县卫健局、县疾控中心、县健康教育中心。

8、提高中医药服务能力。健全覆盖城乡的中医医疗保健服务体系，二级以上中医医院设立“治未病”科（中心），其他公立医疗机构设立中医药科室。推广中医药适宜技术和非药物疗法。实施中医药传、帮、带工程，培养一批县级名中医。

主抓单位：县卫健局、县中医医院。

9、深化贫团人口健康帮扶。巩固深化健康扶贫“汉中模式”，持续推行“三类分治、四重保障、一单结算、两体管理”模式，确保实现贫困人口基本医疗有保障。推进农村贫困人口大病患者集中救治、慢病患者签约服务管理全覆盖。

主抓单位：县卫健局、各镇（办）卫生院。

三、完善健康保障

10、完善全民医保体系。加强基本医保、大病保险、医疗救助、商业补充保险的有效衔接，推动城乡居民基本医保整合。推行按病种、按人头、按床日、总额预付等复合型付费方式。

主抓单位：县医保局、县人社局、县民政局、县人寿保险公司、县人保财险公司。

11、发展商业健康保险。推进商业保险公司与医疗、体检、护理等机构合作，开发长期护理保险、特殊大病保险以及与健康管理、运动健身、养老服务等相关健康保险产品。推动二级以上医疗机构全部办理医疗责任保险并向基层医疗机构覆盖。

主抓单位：县人寿保险公司、县人保财险公司。

12、完善药品供应保障体系。完善基本药物制度，落实基层医疗卫生机构基本药物综合补偿政策，推动基本药物制度与城乡居民医保制度衔接。全面实施药品耗材采购“两票制”和药品零差率销售政策。

主抓单位：县卫健局、各镇（办）卫生院。

四、建设健康环境

13、开展健康城市建设。以巩固国家卫生县城为主线，组织实施“食品放心、全民健身、保卫蓝天，城乡整洁、合理膳食和全民控烟”六项行动，统筹协调各部门全方位、多层次、宽领域推进健康城市建设。深入开展省市级、国家卫生镇创建活动。青木川国家卫生镇已通过市级综合评估考核，争取年内建成；巨亭镇建成省级卫生镇；巴山镇关口坝村、茅坪沟村和巨亭镇黑水村、流溪沟村建成省级卫生村；舒家坝镇和二郎坝镇建成市级卫生镇。

主抓单位：县卫健局、各镇人民政府（街道办事处）。

14、推进健康细胞建设。坚持“分级负责，行业指导”的原则，加快推进9类健康细胞示范建设，不断扩大建设覆盖面。年内建成健康机关42个、健康军营2个、健康村庄30个、健康社区7个、健康学校55个、健康医院17个、健康企业10个、健康食堂（酒店）27个、健康家庭1000个。

健康机关主抓单位：县机关工委；健康军营主抓单位：县人民武装部；健康村庄主抓单位：县农业农村局；健康社区主抓单位：县民政局；健康学校主抓单位：县教体局；健康医院主抓单位：县卫健局；健康企业主抓单位：县经贸局；健康食堂（酒店）主抓单位：县市场监管局；健康家庭主抓单位：县妇联。

15、加强食品药品安全监管。强化食品安全源头治理和药品安全监管，县城打造5个以上食品安全示范街区、各镇（街道办）打造1个食品安全示范街区，创建国家食品安全示范县城。严厉打击食品安全违法犯罪行为，保障人民群众舌尖上的安全。

主抓单位：县市场监管局。

16、深入推进“四个保卫战”。坚持减煤、控车、抑尘、治源、禁燃、增绿六大治污降霾措施，推动全市空气质量持续改善。严格落实河（湖）长制，加强水源地保护，确保全县水质保持优良，实施农村饮水安全工程，提升自来水普及率。持续开展农业面源污染防治、城乡生态环境综合整治和农村土地综合整治，确保土壤污染“零增量”。持续深化生态环境专项整治，推进天然林保护、退耕还林、水保治理和重点区域绿化。

主抓单位：县环保局、县交运局、县公安局、县住建局、县农业农村局、县水利局、县林业局、县自然资源局。

17、加强道路交通安全。加大国、省道路扬尘污染防治工作力度，实施国省道沿线权属用地范围内的环境卫生综合整治，加快通村道路、通组道路的建设。严格道路运输企业安全管理，落实道路运输企业主体责任。

主抓单位：县交运局。

五、发展健康产业

18、推进康养产业发展。充分利用已建好的宁强康达医养中心资源优势，加快康养产业发展，大力发展康体健身、医养结合等产业，打造宁强“绿色康养胜地”。

主抓单位：县卫健局、宁强康达医养中心。

19、健康食品。培育壮大绿色有机食品生产基地和产业集群，推进十大绿色农产品基地提档升级。强化“三品一标”认证管理，打造“宁字号”特色品牌农产品。

主抓单位：县市场监管局。

20、健康医疗大数据产业。推动健康医疗业务与大数据技术深度融合，构建健康医疗大数据应用服务网络，增强信息技术对卫生与健康领域的支撑能力。

主抓单位：县卫健局。
