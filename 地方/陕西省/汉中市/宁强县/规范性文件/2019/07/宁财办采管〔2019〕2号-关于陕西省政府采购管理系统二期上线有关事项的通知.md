# 关于陕西省政府采购管理系统二期上线有关事项的通知

各镇人民政府、街道办事处，县委和县级国家机关各部门、直属事业单位，各人民团体：

建设陕西省政府采购管理系统，形成全省政府采购“一张网”，是我省“财政云”体系建设的重要组成部分，是深化财政管理“放管服”改革、落实采购人主体责任的重大举措。按照省财政厅的统一部署和《汉中市财政局关于陕西省政府采购管理系统二期上线有关事项的通知》〔汉财办采管（2019）5号〕文件精神，确定我县该系统二期上线时间为2019年7月1日。为了抓好此项工作的推进，确保全县按期上线运行，现就有关事项通知如下。

一、陕西省政府采购管理系统二期上线主要功能

二期系统主要开通采购预算录入、采购项目线上申报、采购项目线上委托、采购合同网上公示、采购活动诚信评价等功能。今后，采购限额标准以上的采购项目，全部实行网上申报，网上委托，采购流程全部在网上办理。

（一）采购预算管理

在新的采购管理系统中，将严格按照“无预算，不采购”的原则进行采购项目备案。凡是达到该年度政府采购限额的项目，采购单位登录陕西省政府采购网（网址www.ccgp-shaanxi.gov.cn)“网上办公”系统录入采购预算，上传采购预算下达文件或凭据；如需预算调整的采购项目，须上传采购预算调整审批表（见附件1）。

（二）采购计划备案

采购预算录入后，各采购单位在“网上办公系统”进行采购项目申报，同时严格按照该年度集中采购目录及采购限额自行选择采购方式。但以下几种情形采购人需提出书面申请，经财政政府采购管理部门批准后方可实施：

1．达到公开招标限额标准，拟申请采用非公开招标方式的项目(市级财政管理部门审批）。

2．采购标的物包含有进口商品（设备）的项目（市级财政管理部门审批）。

3．采用单一来源方式的采购项目。

采购单位自行登录宁强县人民政府网站（信息公开—政府采购—工程招标—政策法规）下载《宁强县政府采购预算调整申请表》、《政府采购公开招标采购方式变更非公开招标采购方式申请表》、《单一来源项目专家论证意见表》、《宁强县政府采购单一来源方式申请表》、《进口商品申请表》、《进口商品行业所属主管部门意见表》、《进口商品专家论证意见表》（详见附件）。

（三）采购项目委托

采购单位在采购项目备案成功后，属于集中采购目录的，采购单位必须选择政府集中采购机构实施（县政府采购中心）；属于部门集中采购目录的，采购单位选择政府集中采购机构或采购代理机构实施。属自行采购的项目，采购单位有能力组织实施的由单位自行组织实施，采购单位没有能力组织实施的，应当委托代理机构实施。

（四）采购合同管理

按照《政府采购法》规定，采购合同必须公示。涉及国家秘密或者商业秘密的，按照有关规定处理。国库支付或者授权支付时，须核查公示合同自动生成的合同编号方可支付。

（五）诚信评价

为了维护政府采购活动公平、诚信，代理机构、评审专家、采购单位、供应商各自按照系统设置对采购活动中非己方的相关情况进行诚信评价，评价结果统一管理和使用。

二、系统二期上线时间

自2019年7月1日起，陕西省政府采购管理系统二期在我县正式上线，各镇办、各部门、各单位政府采购项目一律实行网上备案，县财政局政府采购管理部门不再接受纸质备案材料。

三、注意事项

（一）陕西省政府采购管理系统全面上线运行以后，采购业务一律实行网上办理，各单位应设置采购业务专管员，负责政府采购事宜。

（二）各单位应切实履行采购人主体责任，建立健全政府采购内控制度。

（三）各单位可自行登录陕西省政府采购网“下载专区”下载采购用户使用手册，操作中遇到疑问，可拨打技术支持电话029-96702，也可咨询宁强县财政局采购管理办公室，联系电话：0916-4222669。

（四）各单位登陆用户名账号及初始密码请自行到县财政局采购管理办公室领取；凡机构调整统一社会信用代码变更或新成立的一级预算单位向财政局提供相关材料后申请相关账号。

（五）未纳入一级预算管理的行政事业等单位政府采购网上备案工作一律由其主管部门负责。

（六）采购人在采购备案前应办理国有资产购置审批相关手续并在采购管理系统中上传资料备查。
