# 关于下达2019年统筹整合财政涉农资金的通知

各有关部门：

为进一步提高资金使用效益，保障全县集中资源打赢脱贫攻坚战，按照宁强县发展改革局、县财政局、县扶贫开发办公室《关于下达宁强县2019年度统筹整合使用财政涉农资金项目投资计划的通知》（宁发改代赈〔2019〕79号），根据宁财办农〔2019〕36号、38号文件精神，本次下达统筹整合财政涉农资金1475万元，其中：下达县文旅局乡村旅游项目资金345万元，下达县农业农村局农业产业园项目资金1130万元。

请严格执行《宁强县统筹整合使用财政涉农资金管理办法》的相关规定，切实做好资金支付进度统计上报、资金公告公示、资金监督检查、资金精准使用、资金报账管理、信息宣传、印证资料收集等工作，管好用好财政涉农资金。

宁强县扶贫开发办公室 宁强县财政局

2019年8月5日
