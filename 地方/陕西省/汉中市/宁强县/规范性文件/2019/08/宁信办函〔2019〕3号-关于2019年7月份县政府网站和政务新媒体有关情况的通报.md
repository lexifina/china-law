# 关于2019年7月份县政府网站和政务新媒体有关情况的通报

各镇人民政府、街道办事处，县政府各部门、直属事业单位：

7月份，县政府门户网站“县长信箱”“咨询投诉”等栏目共收到群众来信64件，其中无效14件、重复1件、有效49件。截至8月8日，共办结49件，办结率100%。

截止8月13日，全县在运行政务新媒体39个，完成注销1个，超5个工作日未更新10个。报备后需注销但仍未完成注销的新媒体有16个。请各相关单位针对政务新媒体检查发现的问题认真做好整改工作，同时加强内容保障和日常监管，建立信息发布审核机制，不断提高信息发布、解读回应水平。对确无保留必要或无人负责管理的政务新媒体，要按规范程序予以注销。
