# 宁强县卫生健康局关于印发防范化解卫生健康领域重大风险工作方案的通知

各镇（办）卫生院，县直医疗卫生单位，宁强协和医院、大安仁康中医医院、宁强精神病康复医院：

现将《防范化解卫生健康领域重大风险工作方案》印发你们，请认真抓好贯彻落实。

宁强县卫生健康局

2019年8月6日

宁强县卫生健康局防范化解卫生健康领域重大风险工作方案

为深入贯彻落实中省市县有关工作部署，做好我县卫生健康领域防范化解重大风险工作，根据市卫生健康委《关于防范化解卫生健康领域重大风险工作方案》（汉卫发〔2019〕39号），结合我县实际，制定本工作方案。

一、指导思想和工作目标

坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻落实习近平总书记关于防范化解重大风险的重要讲话精神，切实履行政治责任，以全县人民健康为中心，坚持底线思维，增强忧患意识，强化斗争精神，提高防控能力，全力防范化解卫生健康领域各类风险隐患，坚决防止各类矛盾转变升级为现实危害，进一步维护好人民群众健康安全，促进全县经济持续健康发展和社会大局稳定，为推进健康中国行动，建设“健康宁强”奠定良好基础。

二、组织领导

成立宁强县卫生健康系统防范化解重大风险工作领导小组，由局党组书记、局长为组长，党组成员为副组长，领导小组办公室设在局办公室，具体负责卫生健康领域重大风险防范化解的组织、协调、督办等工作，各股室负责人为领导小组办公室成员。

（一）公共卫生方面。

1.重大传染病风险。各类公共场所和设施的人群流动频繁，输入性、新发性传染病不断出现，结核病等传统传染病疫情时有发生，冬春季流感、手足口等疾病聚集性多发，特别是学校、餐厅等场所存在疫情暴发、扩散、传播的风险隐患。

责任领导：杨春强

责任股室：公卫股  基建股

责任单位：县疾控中心  各医疗机构

防范化解措施：落实重点传染病“专病专策”精准防控措施，加强学校传染病防控；规范传染病网络报告工作，建立重大传染病防控联席会议制度，定期研究传染病防控工作；推进县天津医院标准化感染病区建设项目。

2.疫苗使用管理风险。在疫苗出入库、保存管理、登记接种信息，存在接种疫苗登记信息错误、过期疫苗未及时清理甚至疫苗失效等风险隐患。

责任领导：杨春强

责任股室：公卫股

责任单位：县疾控中心  各接种单位

防范化解措施：各镇（办）在卫生院集中设置免疫规划接种点，各镇（办）卫生院建设规范化预防接种门诊，加强接种人员培训，严格审核把关接种人员资质，落实疫苗使用管理制度，加强疫苗流通使用环节管理，确保疫苗使用管理工作严谨规范。

（二）医疗卫生方面。

3.院内感染风险。个别医疗机构院内感染防控制度落实不力，输入型传染病、流感、结核病等聚集性重大传染病防控方面的风险隐患。

责任领导：燕林宝  杨春强

责任股室：医政股  公卫股

责任单位：县院感质控中心  县疾控中心  各医疗机构

防范化解措施：县院感质控中心加强各医疗机构业务培训，提高院内感染防控业务水平；加强各医疗机构院感督导检查；各医疗机构要建立院感防控全员培训制度，每年至少开展一次院感防控法律法规、知识和技能专项培训，提高全体工作人员院感防控意识和能力，做到防控关口前移，避免院感事件的发生；各医疗机构要着重关注新生儿病房、口腔科、感染性疾病科、血液透析室、重症监护室、内镜室、手术室、检验室、 消毒供应室等重点部门、重点环节的院感防控工作，有效落实预防和控制医院感染的各项工作措施，进一步规范医疗操作，预防各种侵入性医疗器具导致的感染；加强医院感染管理，防止出现院感暴发事件。

4.医疗废物风险。医疗废物处置不规范，在医疗机构流失、泄露、扩散的风险隐患。

责任领导：燕林宝

责任股室：医政股

责任单位：县卫生计生综合监督执法大队  各医疗机构

防范化解措施：巩固秦岭生态环境保护工作成果，持续抓好医疗废物、污水、污泥和大气污染治理；加强业务培训，提高医疗机构医疗废物处置业务水平；加强对医疗机构医废管理监督检查，及时查处违规违法案件。

5.特殊医疗用品管理风险。特别是医疗机构的毒麻药品、精神药品、放射源、血液制品的管理、使用方面的风险隐患。

责任领导：燕林宝

责任股室：医政股

责任单位：县卫生计生综合监督执法大队  各医疗机构

防范化解措施：加强监督检查，督促医疗机构落实管理责任，规范管理和使用毒麻药品、精神药品、放射类医疗设备、血液制品。

（三）安全生产及维稳方面。

6.安全生产及反恐风险。医疗机构人员密集，制氧、放射源、易燃易爆品等设施设备较多，不同程度上存在安全生产及反恐的风险隐患。

责任领导：燕林宝

责任股室：医政股

责任单位：卫生健康系统各单位

防范化解措施：落实县安委会关于安全生产的安排部署，指导卫健系统各单位加强安全生产工作，做好安全生产督导检查；深入推进县卫健系统扫黑除恶专项斗争，扎实开展行业集中治乱。

7.信访维稳风险。医疗纠纷、计生优惠政策落实不到位、专业技术人员职称晋升聘用、村医待遇问题、卫生健康项目建设单位拖欠民工工资等问题引发的上访。

责任领导：燕林宝  周中斌  杨春强  李勇

责任股室：各相关股室

责任单位：卫生健康系统各单位

防范化解措施：医疗机构建立完善诉求解决机制，畅通投诉渠道；做好医疗纠纷当事人的疏导和情绪化解，及时、妥善化解医疗纠纷；做好转办和群众来信来访办理；按政策落实城市独生子女补助、计生特殊家庭“六免一补”、奖励扶助等优惠政策；加大专业技术人员职称晋升聘用等政策宣传解读力度；加大核查力度，杜绝克扣截留村医补助行为发生；加强项目建设管理，督促用工单位及时兑现民工工资。

（四）卫生健康管理方面。

8.信息安全风险。对外信息发布、区域卫生信息平台数据信息、涉密文件安全风险。

责任领导：燕林宝  周中斌

责任股室：办公室  宣教股  信息中心

责任单位：卫生健康系统各单位

防范化解措施：建立信息发布审核把关制度，对外发布的工作信息，严格审核把关；要积极应对，主动化解网络舆情；加强网络数据安全管理，保障卫生健康信息数据安排；规范档案管理，降低档案安全风险，严防泄密事件发生。

9.廉政风险。药品器械采购、基建项目、资金使用等廉政风险。

责任领导：燕林宝  杨春强  李勇

责任股室：计财股  医改办  基建股  监察室

责任单位：卫生健康系统各单位

防范化解措施：进一步加强财务管理和会计核算工作，严格实施财会监督和内部审计监督，促进财务工作高效、有序进行；规范药品耗材采购、器械购买、基础建设、物资采购程序，加强资金使用监管；集中开展群众反映突出问题专项整治，加大违纪违法案件查处，对腐败“零容忍”。

四、工作要求

（一）提高思想认识。全县卫健系统各单位要进一步提高政治站位，增强风险意识，牢固树立底线思维，把防范化解重大风险隐患工作摆在更加突出的位置，充分认识防范化解重大风险的重要性和紧迫性，强化组织领导，周密安排部署，完善工作机制，使风险排查常态化、风险识别具体化、风险评估精细化、风险防控常态化。

（二）夯实防控责任。全县卫生健康系统各单位主要负责人是防范化解重大风险隐患的第一责任人，要切实落实主体责任，做好本单位风险隐患排查化解工作，对确需县卫健局协调解决的重大风险隐患，要及时报告，提出有针对性的具体措施建议，县卫健局相关牵头领导和责任股室，要勇于担当、履职尽责，把职责范围内的风险防控好。

（三）加强督导检查。县卫健局防范化解重大风险工作领导小组，要定期对卫健系统各单位进行督导检查，了解和掌握重大风险隐患排查梳理和防范化解等进展情况，对防范化解重大风险工作不重视，组织开展不力，风险问题排查不准不细不全，化解落实不力引发风险事件的，要倒查风险隐患防控工作责任落实情况，依纪依法追究责任。
