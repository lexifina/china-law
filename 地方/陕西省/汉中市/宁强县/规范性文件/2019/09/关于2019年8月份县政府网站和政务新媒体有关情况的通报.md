# 关于2019年8月份县政府网站和政务新媒体有关情况的通报

各镇人民政府、街道办事处，县政府各部门、直属事业单位：

8月份，县政府门户网站“县长信箱”“咨询投诉”等栏目共收到群众来信55件，其中无效5件、重复7件、有效43件。截至9月8日，共办结31件，办结率72.1%。

截止9月9日，全县在运行政务新媒体37个，不合格1个，超5个工作日未更新7个。报备后需注销但仍未完成注销的新媒体有11个。现将情况通报如下（见附件）。
