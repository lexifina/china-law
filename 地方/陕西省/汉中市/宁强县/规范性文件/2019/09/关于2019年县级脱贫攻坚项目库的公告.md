# 关于2019年县级脱贫攻坚项目库的公告

按照国务院扶贫办《关于进一步做好脱贫攻坚项目库建设的通知》和《陕西省县级脱贫攻坚项目库建设工作导引》文件精神，我县完善编制了2019年脱贫攻坚项目库，报行业部门初审后，县脱贫办进行了汇总审核，并由脱贫攻坚工作领导小组召开专题会议审定了年度脱贫攻坚项目库，于8月30日至9月8日在县政府门户网站上进行了公示。

公示期间无反馈意见，现对最终审定通过的项目库进行县级公告，欢迎社会各界和广大干部群众监督。
