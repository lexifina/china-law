# 关于下达2019年度统筹整合财政涉农项目中期调整资金的通知

各有关镇（办）：

根据宁强县发展和改革局、宁强县财政局、宁强县扶贫开发办公室《关于下达宁强县2019年统筹整合财政涉农资金中期调整项目投资计划的通知》（宁发改代赈〔2019〕205号）、宁强县扶贫开发办公室、宁强县财政局《关于下达2019年统筹整合财政涉农项目中期调整资金的通知》（宁扶办发〔2019〕38号）文件精神，本次下达各镇（办）整合涉农项目中期调整资金共计42万元，专项用于食用菌产业园项目建设。

请严格按照《宁强县食用菌产业园建设项目管理办法》、《宁强县统筹整合使用财政涉农资金管理办法》的相关规定，抓好项目的实施和资金的安全使用工作。各镇（办）按建设进度拨付资金并及时报账，同时收集整理好项目实施和资金使用的各项印证资料备查。

宁强县食用菌产业开发中心

2019年9月18日
