# 关于下达2019年第二批涉农资金项目计划的通知

相关镇办，有关单位：

根据宁强县发改局《关于新增下达第二批2019年统筹整合财政涉农资金项目投资计划的通知》宁发改代赈〔2019〕211号文件要求,现将2019年第二批项目统筹整合财政涉农资金（烟叶产业路建设）计划下达给你们,请按照有关规定，认真抓好项目实施。

一、项目内容。烟叶生产区产业道路及基础设施建设。

二、使用范围。主要用于烟区道路、灌溉、电力、烤烟房等基础设施建设。

三、具体要求。

（一）项目实施过程中，严禁弄虚作假，严格按照涉农资金相关规定操作，出现违规操作责任自负。

（二）严格按照财政绩效评价量化指标，切实做好资金支付进度统计上

报、项目资金公示公告、资金监督检查、资金精准使用、资金报账管理、印证资料收集等工作，确保年度财政专项扶贫资金绩效评价达A级标准。

（三）涉及镇办必须加快项目建设进度，加大监管力度，搞好督导检查。所有项目必须在11低月底全部完成建设指标。

（四）项目实施结束后及时报账，本次下拨资金务必在12月10日前完成报账。
