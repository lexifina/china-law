# 关于下达2019年统筹整合财政涉农资金的通知

各有关部门：

为进一步提高资金使用效益，保障全县集中资源打赢脱贫攻坚战，按照宁强县发展改革局、县财政局、县扶贫开发办公室《关于新增下达第二批2019年度统筹整合使用财政涉农资金项目投资计划的通知》（宁发改代赈〔2019〕211号），根据宁财办建〔2019〕30号、33号、36号文件精神，根据宁扶办发〔2019〕38号文件下达中期调整资金226.36万元，本次共下达统筹整合财政涉农资金4993.36万元，其中：下达县交运局交通基础设施项目资金2494万元，下达县食用菌中心食用菌产业园区建设资金260万元，下达县农业农村局产业发展直补到户项目资金45万元、产业道路建设项目资金2123万元，下达县扶贫办烟叶产业发展项目资金71.36万元。

请严格执行《宁强县统筹整合使用财政涉农资金管理办法》的相关规定，切实做好资金支付进度统计上报、资金公告公示、资金监督检查、资金精准使用、资金报账管理、信息宣传、印证资料收集等工作，管好用好财政涉农资金。

宁强县扶贫开发办公室 宁强县财政局

2019年9月11日
