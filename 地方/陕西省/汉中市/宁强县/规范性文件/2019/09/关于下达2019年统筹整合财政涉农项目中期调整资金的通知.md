# 关于下达2019年统筹整合财政涉农项目中期调整资金的通知

各有关部门：

为进一步提高资金使用效益，保障全县集中资源打赢脱贫攻坚战，按照宁强县发展改革局、县财政局、县扶贫开发办公室《关于下达宁强县2019年度统筹整合使用财政涉农资金中期调整项目投资计划的通知》（宁发改代赈〔2019〕205号），调减原下达6个部门项目资金2574.5万元（详见附件1），按照宁强县脱贫攻坚工作领导小组办公室《关于收回中期调整取消项目变更项目资金的通知》，调减资金已全部统一收回“共管账户”。现根据中期调整方案另下达6部门调减收回资金2348.14万元（详见附件2），其中：下达县交运局村组道路建设项目资金1233万元，下达县电力局农村电网改造项目资金230万元，下达县农业农村局产业道路建设资金75万元、产业发展直补到户资金154万元、集体经济发展资金389.14万元、农业产业化项目资金125万元，下达县扶贫办烟叶产业发展项目资金65万元，下达县食用菌产业中心食用菌园区项目资金42万元，下达县文化旅游局乡村旅游项目资金35万元。

请严格执行《宁强县统筹整合使用财政涉农资金管理办法》的相关规定，切实做好资金支付进度统计上报、资金公告公示、资金监督检查、资金精准使用、资金报账管理、信息宣传、印证资料收集等工作，管好用好财政涉农资金。
