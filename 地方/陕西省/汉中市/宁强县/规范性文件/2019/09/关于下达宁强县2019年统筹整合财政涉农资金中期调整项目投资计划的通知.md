# 关于下达宁强县2019年统筹整合财政涉农资金中期调整项目投资计划的通知

县交运局、水利局、住建局、农业农村局、文旅局、电力局：

按照省市各级培训会议精神、文件精神，结合我县实际，6月初，县脱贫攻坚领导小组办公室印发了《关于做好2019年度统筹整合使用财政涉农资金中期调整的紧急通知》，调整程序按照镇村申报，行业部门评审，县级脱贫攻坚领导小组审定的程序开展。6月19日，进行了第一次部门联席会议初审中期拟调整项目，后经部门多次审核、镇办意见多次反馈再完善，7月29日，最后一次汇总形成了拟调整项目明细清单（且转发县财政、农业等部门交换意见），8月4日，县脱贫攻坚领导小组办公室组织召开了项目中期调整初审会议，形成了初审意见，于8月7日提交了县脱贫攻坚领导小组审定通过后，报上级备案。

根据各镇（办）上报的关于调整年初下达的《2019年统筹整合财政涉农资金项目投资计划》（宁发改代赈〔2019〕79号）的报告，经县级行业主管部门对拟调整项目分类审核，县脱贫攻坚工作领导小组审定后，编制了《宁强县2019年度统筹整合财政涉农资金中期调整实施方案》（宁脱组办发〔2019〕21号），并通过了省市评审。

现将调整后的宁强县2019年统筹整合使用财政涉农资金项目投资计划下达你们，并就有关事项通知如下：

一、2019年年初下达资金项目情况

资金总规模：财政涉农资金整合35161万元。

分项目资金规模：基础设施投入财政涉农资金12868万元，其中投入村组道路（桥）建设5576万元、投入人饮工程及农田水利5765万元、投入农村环境综合整治项目1410万元、投入危房改造117万元；产业发展投入财政涉农资金22048万元，其中产业道路2104万元、产业到户补助投入2248万元、农业产业化项目投入2766万元、集体经济发展投入4740万元、食用菌产业发展园区建设投入2478万元、光伏扶贫资金投入600万元、乡村旅游发展项目投入840万元、小额贷款贴息投入1400万元、烟叶产业项目投入431万元、农业产业园区项目投入1230万元、贫困户退出后续产业扶持资金3211万元；其他类投入245万元，扶贫项目管理费100万元、雨露计划培训100万元、建档立卡家庭中职学生扶贫助学补助15万元和致富带头人培训30万元。

项目共计778个，分类如下：围绕发展壮大特色产业、发展集体经济、促进贫困户增收，重点实施产业精准扶贫、小额贷款贴息、产业基地建设等产业发展项目641个；围绕2018年脱贫村巩固提升和2019年计划脱贫村（含深度贫困村）及部分非贫困村基础条件改善，重点实施道路建设、人饮工程、农村环境综合整治等基础设施项目133个；扶贫项目管理费、雨露计划培训、建档立卡家庭中职学生扶贫助学补助和致富带头人培训等其他项目4个。

二、2019年度年中方案调整情况

（一）项目调整原因

项目调整涉共涉及10类70个项目、财政资金5235万元。具体情况如下：

1、基础设施项目：涉及原道路建设项目2个，交运部门新增道路完善工程项目22个，调整后项目25个，资金增加1211万元。原农村人居环境整治项目25个、财政1410万元，根据上级文件，未摘帽的贫困县不得将整合资金用于人居环境项目，固项目全部取消。新增农村电网改造项目17个，增加资金230万元。

2、产业发展项目：由于农作物种植季节错过不合适或个别实施主体自身发展等情况，调整项目涉及产业道路项目、产业直补到户、农业产业化项目、食用菌产业园区建设、乡村旅游项目、烟叶产业项目。

3、其他类项目：由于项目进入“负面清单”，取消致富带头人培训项目1个。

（二）项目调减情况

调减项目共计33个、财政资金1894万元。分别是农村人居环境综合整治项目25个、财政资金1410万元；农业产业项目7个、财政资金454万元；其他项目1个、财政资金30万元。

（三）项目调增情况

新增项目共计42个、财政资金1490万元。分别是基础设施道路项目23个、财政资金1233万元；农村电网改造项目17个、财政资金230万元；产业项目2个、财政资金27万元。

（四）调整后整体情况

本次中期调整纳入整合计划34445.5万元，调整资金规模占年初方案项目资金总额（35161万元）的14.89%，调整后产业占比61.93%。

经调整的项目在附表中已备注。

基础设施建设：项目148个。投入财政涉农资金12899万元。其中投入村组道路（桥）建设6787万元、投入人饮工程及农田水利5765万元、投入危房改造117万元、投入农村电网改造230万元。

产业发展：项目641个。投入财政涉农资金21331.5万元。其中产业道路1729万元、产业到户补助投入2217万元、农业产业化项目投入2591万元、集体经济发展投入4740万元、食用菌产业发展园区建设投入2350万元、光伏扶贫资金投入600万元、乡村旅游发展项目投入875万元、小额贷款贴息投入1400万元、烟叶产业项目投入388.5万元、农业产业园区项目投入1230万元、贫困户退出后续产业扶持资金3211万元。

其他类：项目3个。投入215万元。扶贫项目管理费100万元、雨露计划培训15万元、贫困户农村实用技术培训100万元。

三、有关要求

1、切实加强项目管理，确保工程质量。各相关行业主管部门接此通知后，要加快项目的组织实施。对由镇办具体组织实施的项目，要在3日内将项目投资计划分解转发给相关镇办。要严格按照批准的项目设计组织施工，严禁随意变更项目名称、规模和项目建设内容。要认真落实项目法人责任制、招投标制、合同管理制和工程监理制。各行业主管部门要加强工程质量监管、做好技术指导，除落实专业技术人员具体负责工程质量外，还要有当地的村民代表参与工程质量监督，确保项目顺利实施。

2、在项目实施过程中，应科学组织施工，严把投资概算，力求节约资金。项目建设资金如有结余收回县财政，由县涉农资金管理工作领导小组统筹协调使用，严禁擅自挪作他用。

3、在项目建设过程中，县发改局、财政局、扶贫办要积极协同项目主管部门加强督促检查，发现问题及时予处理，确保项目早日建成投用。

4、加强公告公示。各项目主管部门、各镇办要将涉及本行业、本镇办扶贫资金项目安排情况通过政府网站、手机APP、政务公开栏向社会公开。项目实施单位在资金项目实施前后都要在项目所在贫困村或实施地进行公告公示，公告公示位置要醒目、时限不少于10天。公告公示主要内容包括项目名称、资金来源、资金规模、实施地点、建设内容、实施期限、预期目标、项目实施结果、实施单位及负责人、监督举报电话等。

5、各项目建设单位要切实加快项目建设进度，确保本次所有建设项目在2019年12月底前竣工投入使用。同时要及时收集项目建设资料，并于每月十五日前和月底前分两次将项目建设进展情况报送业务主管部门，由业务主管部门收集、汇总后报县脱贫攻坚工作领导小组办公室。
