# 关于下达宁强县2019年食用菌产业园建设项目投资计划的通知

各有关镇（办）：

为发挥好财政涉农资金扶贫效益，确保全县脱贫摘帽工作顺利完成，根据宁发改代赈〔2019〕205号《关于下达宁强县2019年度统筹整合财政涉农资金中期调整项目投资计划的通知》、宁发改代赈〔2019〕211号《关于新增下达第二批2019年度统筹整合财政涉农资金项目的通知》，现将2019年食用菌产业园建设项目投资计划下达你们，并就有关事项通知如下：

一、2019年下达食用菌产业园建设项目16个，财政涉农资金2610万元。相关镇办建设任务见附表。

二、项目下达后，各镇办要及时成立机构组织实施。各项目建设单位要切实加快项目建设进度，确保项目按时竣工投入使用。

三、切实加强项目管理，确保产业园建设质量。按照《宁强县食用菌产业园建设管理办法》，认真落实项目法人责任制、招投标制，确定带贫模式，同时确保资金使用安全。

四、加强项目公告公示。严格按照宁强县脱贫攻坚工作领导小组办公室印发的《宁强县扶贫资金项目公告公示实施细则》(宁脱组办发〔2018〕13号）文件要求，及时在镇村显著位置进行项目公示。
