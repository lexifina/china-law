# 宁强县农业农村局关于报送2019年农业系列专业技术职务中级评审材料的通知

各镇人民政府（街道办事处）、局属各单位：

根据汉中市职称改革办公室、汉中市农业农村局《关于报送2019年度农业系列中级专业技术资格评审材料的通知》（汉职办发【2019】7号）文件精神，现将有关事项通知如下：

1、《关于报送2019年度农业系列中级专业技术资格评审材料的通知》文件已发布于《宁强县人民政府信息网》县农业农村局部门文件栏目（http://www.nq.gov.cn/gk/gk0903/42250.htm），请各单位在网上下载，认真阅读，按照申报所需要的资料准备评审材料，一人一袋，用档案袋装好，于10月8日前将材料报宁强县政务中心农业农村局窗口。

2、请各镇（办）负责通知本镇（街道办事处）符合申报条件的农技人员申报，局属各单位在负责组织好本单位人员申报的同时，及时督促本行业的镇（办）人员进行申报。

3、请申报人员务必高度重视，按时上报评审材料，中级职称申报缴纳评审费200元，逾期不予受理。

宁强县农业农村局

2019年9月11日
