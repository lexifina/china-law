# 关于下达2019年统筹整合财政涉农资金的通知

各有关部门：

为进一步提高资金使用效益，保障全县集中资源打赢脱贫攻坚战，按照宁强县发展改革局、县财政局、县扶贫开发办公室《关于新增下达第四批2019年度统筹整合使用财政涉农资金项目投资计划的通知》（宁发改代赈〔2019〕304号），根据宁财办农〔2019〕48号、宁财办建〔2019〕41号、宁财办农改〔2019〕4号、宁财办事〔2019〕73号文件精神，本次共下达整合财政涉农资金1755.36万元，其中：下达县农业农村局农业产业化项目项目资金50万元、产业道路项目资金1222万元，下达县交运局交通基础设施建设资金480.66万元，下达县扶贫办贫困家庭子女技工院校补助资金2.7万元。

请严格执行《宁强县统筹整合使用财政涉农资金管理办法》的相关规定，切实做好资金支付进度统计上报、资金公告公示、资金监督检查、资金精准使用、资金报账管理、信息宣传、印证资料收集等工作，管好用好财政涉农资金。

宁强县扶贫开发办公室 宁强县财政局

2019年11月8日
