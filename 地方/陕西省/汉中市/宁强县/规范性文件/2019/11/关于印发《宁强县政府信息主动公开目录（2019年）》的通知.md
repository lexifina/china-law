# 关于印发《宁强县政府信息主动公开目录（2019年）》的通知

各镇人民政府、街道办事处，县政府各部门、直属事业单位：

《宁强县政府信息主动公开目录（2019年）》（以下简称目录）已经县政府同意，现印发给你们，请结合实际，围绕《中华人民共和国政府信息公开条例》（国务院令第711号）和本单位“三定”方案，制订本单位政府信息主动公开基本目录，目录内容可参照《目录》样式，具体条目可根据实际进行补充删减，于2019年12月15日前将报县信息办，并在县政府网站“信息公开目录”栏目予以公开。（联系人：马长兴；联系电话：[电话略]；传真：0916-4221727）
