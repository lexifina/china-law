# 关于印发《宁强县危化品车辆道路交通事故后续处置方案》的通知

各镇人民政府、街道办事处，县政府各有关部门：

《宁强县危化品车辆道路交通事故后续处置方案》已经县政府同意，现印发给你们，请结合工作实际，认真遵照执行。

宁强县人民政府办公室

2019年12月2日

宁强县危化品车辆道路交通事故后续处置方案

近年来，我县过境危化品运输车辆较多、车流量大，危化品车辆道路交通事故时有发生，为切实做好危化品运输车辆道路交通事故后续处置工作，为进一步明确职责分工，夯实工作责任，强化危化品车辆道路交通事故后续处置工作合力，确保后续处置快速有序，制定此方案。

一、成立领导机构

为进一步落实责任，加强领导，县政府成立危化品车辆道路交通事故后续处置领导小组：

组 长：县委常委、常务副县长

副组长：分管环保、交通工作副县长

分管公安工作副县长

成 员：县应急管理局局长、县公安局分管副局长、市生态环境局宁强分局局长、县交运局局长、县交管大队大队长、涉事地镇（办）镇长（主任）。

领导小组下设办公室，办公室设在县应急管理局，办公室主任由县应急管理局局长担任，副主任由市生态环境局宁强分局局长、县公安局分管副局长担任。

二、主要任务

危化品车辆道路交通事故后续处置主要任务：

1.核查人员伤亡情况，估算经济损失；恢复受影响群众正常生活、生产秩序；

2.评估事故对土壤、水源、空气造成的现实危害，并对事故现场和周边环境跟踪监测。处置事故危险废弃物，消除危害因素。

3.调查分析事故原因，第一时间按照危化品车辆道路交通事故处理程序对肇事企业、个人进行处理。构成犯罪的，依法追究刑事责任。

4.对事故应急救援处置有功人员进行奖励。

三、任务分工

1.县应急管理局：配合做好事故调查，督促相关镇（办）及部门评估估算应急救援费用（救援队伍工资、调运车辆、物资、设备费用等），并统计汇总。

2.县公安局：核查人员伤亡情况，调查分析事故原因，第一时间核实危险化学品道路运输事故企业情况，依法依规控制现场、司机、押运人员，对其违法违规问题进行调查，核查运输车辆货物、标识标牌情况是否合法合规。按照事故造成经济损失额度依法对司机和押运人员采取强制措施，构成犯罪的，依法追究刑事责任。

3.市生态环境局宁强分局：评估事故对土壤、水源、空气造成的现实危害，并对事故现场和周边环境跟踪监测。处置事故危险废弃物，消除危害因素；配合做好事故调查，估算处置费用（包括环境监测、水质检测、危废处置、现场勘查等）。

4.县交运局：核查路面受损情况，估算经济损失，及时修复受损路面。

5.涉事地镇（办）：及时恢复受影响群众正常生产、生活秩序。估算受影响群众经济损失，以及镇（办）应急救援费用（救援队伍工资、调运车辆、物资、设备费用）。

四、工作要求

（一）统一思想认识。危化品车辆道路交通事故后续处置领导小组各成员单位要充分认识事故后续处置的重要性，主动作为，第一时间按照职责分工开展工作，将事故造成不良后果减轻到最小程度，对于因推诿扯皮造成后续处置工作被动的，将严肃追究相关单位和责任人责任。

（二）加强衔接配合。各成员单位要创新工作措施，加强协调配合，及时处置完成事故后续处置，同时要立足本部门职责，及时调查事故中的违法违规行为。

（三）落实工作措施。各成员单位要按照职责分工及本单位实际，认真研究安排本部门单位的具体处置流程，落实措施责任，保障后续处置有序开展，不留问题隐患。
