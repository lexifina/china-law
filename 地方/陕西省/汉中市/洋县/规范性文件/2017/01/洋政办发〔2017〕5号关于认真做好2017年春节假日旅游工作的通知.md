# 洋政办发〔2017〕5号关于认真做好2017年春节假日旅游工作的通知

洋政办发〔2017〕5号

洋县人民政府办公室

关于认真做好2017年春节假日旅游工作的

通 知

各镇人民政府、街道办事处，县政府有关工作部门、直属机构，市管单位：

2017年春节即将来临，根据市假日旅游指挥中心通知精神，为切实做好春节假日旅游工作，确保节日期间的社会稳定和旅游活动安全，全面提升我县假日旅游服务水平，让全县人民和游客度过一个欢乐祥和、丰富多彩的春节，实现假日旅游“安全、秩序、质量、效益”四统一目标，现将有关事项通知如下：

一、高度重视，精心安排，全面启动春节假日旅游工作机制

做好春节假日旅游工作，对提升我县旅游形象，促进旅游消费，维护社会和谐稳定具有重要意义。各有关镇办、部门及各旅游接待单位要进一步增强大局意识、责任意识，及早部署本单位的春节旅游工作，制定并完善各项工作方案，按照“精心组织、周密安排、落实责任、加强协调”的总体要求，扎实做好春节假日旅游的各项工作。

为确保今年春节假日旅游安全、有序进行，及时有效地协调处理有关问题和各类突发事件，县政府决定成立春节假日旅游工作领导小组，由县政府副县长李刚任组长，县政府办主任李波、县文旅局局长潘晓刚任副组长，华阳景区管委会、交通局、公安局、市监局、住建局、林业局、安监局、经贸局、物价局、文广局、卫生局、交警大队、朱鹮梨园景区管委会办公室、朱鹮保护局及洋州办事处、纸坊办事处、龙亭镇、溢水镇、谢村镇、华阳镇、茅坪镇、黄安镇等主要领导为成员，负责假日期间的指挥、协调和应急处理等工作。领导小组下设办公室，办公地点设在县文旅局，办公室主任由潘晓刚同志兼任。

二、落实责任，提升服务，确保假日旅游安全顺利

春节是我国重要的传统节日，市民游客出游集中、出游形式多样。部分旅游企业、单位还将组织丰富多彩的春节文化活动，群众集聚度高，还有临时摆摊设点多、燃放烟花爆竹等危险点和安全隐患，安全压力巨大。各有关镇办、部门要以高度负责的精神，精心组织安排，落实安全责任，强化安全措施，保障好广大市民游客的生命财产安全。

1.抓好旅游交通安全。针对冬季雨雪冰冻、大雾天气较多，群众返乡探亲和旅游等人流叠加，高速路小客车春节期间免费通行优惠政策实施，自驾车出游多等特点，交通局及早制定运力调度和游客疏导方案，避免大范围游客滞留；运政、市监、交通、交警部门要加强游客客运监管和交通设施维护，严禁非法营运、带病车辆和超时超载运营，交警大队要在重点路段设置警示标志和警力部署，特别要在洋华路等路段加强部署，严防重大旅游交通事故发生。

2.抓好森林防火安全。近期我县天干少雨，森林防火等级高，林业局、消防大队要做好森林防火工作，制定周密应急预案，严防森林火灾发生。以原始生态资源为主的青山观、两角山、华阳等景区在春节期间人流大，将是森林防火的重点区域。林业局、防火办及相关镇办要及早部署，及时检查，节日专人严防死守，确保不在景区出现火情，坚决杜绝火灾。

3.抓好游客密集场所安全管理。公安、消防、市监、安监、卫计等部门要加强交通集散地、旅游活动场所、住宿餐饮、旅游景区、游乐设施等重点部位的安全管理，督促业主单位建立和落实安全责任制，认真开展安全检查，消除安全隐患，严防踩踏、火灾、食物中毒等事故发生。加强对节庆活动的审查和监管，按照“属地管理”和“谁主办、谁负责，谁审批、谁负责”的原则，落实主承办单位和场所管理单位的安全责任，全面排查安全隐患，做好预案演练和现场疏导工作，严防群死群伤事故发生。

4、做好旅游管理和服务工作。（1）文旅局：着力抓好景区的服务质量，认真受理并处理游客投诉，保证游客的切身利益，在县旅游咨询服务中心为游客提供咨询接待。（2）各景区（点）：对本单位内部进行全面检查、清洁，整治旅游综合环境，以崭新的面貌迎接游客，加强景区最大承载量管控，制定详细的旅游接待工作方案，保证游客“吃、住、行、游、购、娱”无忧；（3）洋州办事处、纸坊办事处、磨子桥镇、龙亭镇、谢村镇、华阳镇、茅坪镇、溢水镇要对通往旅游景区(点)的主干道及周边环境进行集中整治，确保道路畅通美观。

5、抓紧油菜花节的建设，开展环境整治。油菜花节重点项目建设，要抓紧建设，保质量、保工期，按时完成项目进度。各镇办要利用春节有利时段，对交通干线、景区周边、群众聚集场所、农户院落的环境卫生进行治理，创造一个干净整洁、舒适卫生的环境，营造春节浓厚节日氛围。

三、加强值班，畅通信息，做好旅游统计工作

为确保春节旅游安全、有序进行，及时有效协调处理各类问题，各有关镇办和部门、旅游接待单位要坚持24小时值班和主要领导带班制度，保证通讯畅通，春节期间值班名单于1月23日前报县文旅局。文旅局要全面负责全县旅游管理和接待协调工作，加强与有关部门、景点的信息联络。一旦发生险情和事故要迅速按照县政府《重大突发事件应急处理办法》处置，并按程序及时上报，对险情较大需要救援的，各有关镇办、部门和单位要积极配合，全力援助，把损失降到最低限度。

县文旅局要切实提高统计水平，为全县旅游业的又好又快发展提供决策依据，各旅游接待单位春节期间每日13:30前将当日游客接待情况、收入情况及总体情况报送县文旅局。(旅游咨询、投诉电话：0916—2982066)

洋县人民政府办公室
