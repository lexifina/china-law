# 洋政办发〔2017〕16号关于印发洋县2016年度土地矿产卫片执法监督检查工作实施方案的通知

洋政办发〔2017〕16号

洋县人民政府办公室关于

印发洋县2016年度土地矿产卫片执法

监督检查工作实施方案的通知

各镇人民政府、街道办事处，县政府相关工作部门、直属机构，市管单位：

《洋县2016年度土地矿产卫片执法监督检查工作实施方案》已经县政府同意，现印发给你们，请认真组织实施。

洋县人民政府办公室

2017年2月28日

洋县2016年度土地矿产卫片执法监督检查

工作实施方案

为加强对土地利用、矿产资源勘查开采情况的全面监管，依法依规管地用地、管矿用矿，根据《汉中市人民政府办公室关于做好2016年度土地矿产卫片执法监督检查工作的通知》精神，现就我县2016年度土地矿产卫片执法监督检查工作(以下简称“卫片执法”)通知如下：

一、主要任务

通过开展卫片执法，督促我县严格按照规范查处整改国土资源违法行为，维护国土资源管理秩序；监督检查国土资源监管责任落实情况，评估一个区域年度国土资源管理秩序；检验一个区域国土资源日常执法监管情况，推动执法方式向“发现在初始、解决在萌芽”转变。同时，配合土地例行督察，加强土地执法监督检查。

二、检查对象

2016年度土地卫片执法工作对象为国土资源部下发的2016年度土地变更调查遥感监测图斑经合法性判定后，涉及违法用地的图斑。

2016年度矿产卫片执法工作对象为2016年度矿产疑似违法图斑。

三、工作安排

（一）核查整改阶段

2017年3月20日前，对2016年度土地变更调查遥感监测图斑和国土资源部下发的矿产疑似违法图斑，按照边核查边整改的原则，完成图斑外业核查、内业审核、案卷组卷、成果归档，并通过填报系统上报初步的核查数据，积极配合市国土局做好上报数据的初步审核工作，及时按照市局反馈意见修正数据。

2017年4月，对国土资源部下发的2016年度重点矿区以外的矿产疑似违法图斑进行实地核查，并立案查处。

2017年4月20日前，完成所有案件的查处整改和落实工作，同时根据检查结果，上报一批直接查处、挂牌督办、公开曝光的典型案件，并报市土地矿产卫片执法监督检查工作领导小组办公室备案。

（二）督查整改和验收阶段

2017年4月30日前，县土地矿产卫片执法监督检查领导小组办公室抽调工作人员成立专门的数据审核小组，开展数据审核工作，提出整改要求；接受市级审核验收工作，同时向市国土资源局正式上报卫片检查统计数据和工作报告。

（三）分级约谈问责阶段

2017年5月10日前，根据全县违法占用耕地比例和整改查处情况，对违法占用耕地比例高、查处整改不力、弄虚作假、工作不重视的镇人民政府、办事处和部门报请县政府开展警示、约谈工作。

各阶段工作结束后，县国土资源局要按照各工作时间节点，向市卫片执法监督检查领导小组办公室上报卫片执法工作报告和相关统计数据，并做好迎接部、省级验收准备。

四、工作要求

（一）强化各级领导，明确相关责任。

各镇人民政府、街道办事处、县政府相关工作部门要高度重视卫片执法工作，严格贯彻落实“党委领导、政府负责、部门协同、公众参与、上下联动”的要求，县上成立由县政府分管领导任组长，县政府办公室主任、县监察局局长、县国土资源局局长任副组长，县公安、发改、住建、水利、农业、林业、安监局主要领导为成员的洋县土地矿产卫片执法监督检查工作领导小组，下设办公室，办公室设在县国土局。各部门要按照紧密合作、分工协作、多方参与、各司其职、分级负责的原则组织开展工作，切实负起责任，抓好落实，确保按时保质完成卫片执法各项工作。其中，县国土局对卫片执法检查发现的土地矿产违法违规行为，依法依规进行调查、处理；县纪检监察部门及时对县国土局移送建议党政纪处分的案件，依法依规予以处理；县公安局及时对涉及土地矿产违法犯罪案件予以受理,依法处理;县发改局要及时向县国土局提供合法新增建设用地项目立项批文；县住建局要及时向县国土局提供合法新增建设用地规划许可证；县农业部门要及时对涉案耕地破坏情况作出鉴定，对符合农业产业结构调整的项目出具审查文件；县财政局对必要的工作经费要予以保障；各镇人民政府、办事处和部门务必及时动员部署，组织各方力量全力推进卫片执法各项任务。同时，各镇人民政府、办事处和部门要成立相应的领导机构和办事机构，负责组织开展卫片执法工作。

（二）狠抓案件查处，促进整改落实。

县国土局要把国土资源违法行为查处整改成果作为衡量卫片执法工作成效的第一标准，对卫片执法工作中发现的违法问题要态度坚决，行动迅速，依法依规“重典”惩处，发挥好震慑作用，卫片涉及到的违法案件必须100%立案，结案率要达到95%以上，整改到位率要达到50%以上，坚决做到“六个该”：该没收的必须没收、该拆除复耕的必须拆除复耕、该罚款的必须罚款、该申请法院强制执行的必须申请、该向纪检监察机关提出处分建议的必须提出建议、该移送司法机关追究刑事责任的必须移送，实事求是、客观真实、严肃认真的做好查处整改工作；对制止无效、查处无法实施的违法行为和案件，在履行发现、制止和查处职责的前提下，要按照《国土资源违法行为查处工作规程》、《关于进一步加强和规范对违反国土资源管理法律法规行为报告工作的意见》的有关要求，进行专项报告；对于涉嫌犯罪的违法案件，要按照省国土资源厅联合省高院、检察院、公安厅、监察厅下发的《关于建立协调配合机制严肃查处国土资源违法犯罪案件的若干意见》要求，建立案件查处绿色通道，有效解决有案不移、有案难移、以罚代刑等问题，确保违法案件查处整改到位；要积极配合省、市两级开展违法案件直查，以省、市两级直查案件为契机，着力提升全县国土资源行政处罚案件办理水平；同时要充分利用新闻媒体的宣传教育作用公开曝光一批违法占地面积大、社会影响恶劣的典型案件，做好《土地管理法》、《矿产资源法》的宣传工作，为依法治县奠定良好基础。

（三）严明政策法纪，严格约谈问责。

县政府将对违法用地、违法勘查开采矿产资源严重地区或因土地管理秩序混乱的镇人民政府、办事处的主要负责人、分管负责人及有关人员依据相关法律法规进行警示约谈或实施问责。

在确定约谈问责对象时，对违法数量较大、违法占用耕地面积比例达到15%以上的各镇人民政府、办事处，要纳入约谈、问责范围；对土地管理混乱、违法占用耕地比例虽未达到15%以上但造成恶劣影响或者其他严重后果的，要纳入约谈、问责范围；对违法比例不高或者数量不大，但不认真组织查处整改的，日常执法评估问题突出的，也要纳入约谈、问责范围；县国土局在完成省级验收、确认有关事实后，对土地管理秩序仍然混乱，符合《违反土地管理规定行为处分办法》(监察部、人力资源和社会保障部、国土资源部令第15号)相关规定的各镇人民政府、办事处，立即报请县政府实施问责程序。

（四）落实共同责任，打击违法行为。

要认真落实“政府领导、部门参与” 的监管共同责任机制，要进一步加大执法监察力度，积极预防和依法查处国土资源违法行为。对于制止无效、查处无法实施的违法行为和案件，可以根据情况将涉嫌违法的事实及制止违法行为情况抄告发改、规划、建设、环保、市政、电力、金融、工商、安监、公安等相关部门，提请相关部门按照共同责任机制的要求履行部门职责，采取措施共同制止违法行为。各相关部门要依据本部门职责，切实加强监管，形成执法合力。对未取得合法用地手续的建设项目，县发改局不得办理项目审批、核准手续；县住建局不得办理建设规划许可，不得发放施工许可证，不得办理房屋所有权登记手续；县工商局不得注册登记；县电力局及市政公用企业不得通电、通水、通气；金融机构不得发放贷款等措施；严厉打击国土资源违法行为。

（五）落实动态监管，注重源头防控。

各相关部门要按照县政府和业务部门的统一安排部署，做好卫片执法监督检查工作，要坚持“预防为主、查防并重”的原则，从制度上、措施上不断强化日常监管，预防和及时制止违法违规行为的发生，力争将违法行为“发现在初始、制止在萌芽”；要注重数据统计、案件查处、日常巡查、案件报告、12336举报线索等日常工作，积极组织人员查处打击各类土地违法行为，打破“唯比例论”和“重卫片执法、轻日常监管”的思维模式，注重源头防控，细化土地矿产动态巡查责任，积极完善用地台账，注重重大违法案件抄报报告制度，加大各类国土资源违法案件查处力度，不断提高国土资源管理水平。
