# 洋政办发〔2017〕17号关于印发洋县地质灾害防治高标准“十有县”建设工作实施方案的通知

洋政办发〔2017〕17号

洋县人民政府办公室

关于印发洋县地质灾害防治高标准“十有县”

建设工作实施方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县地质灾害防治高标准“十有县”建设工作实施方案》已经县政府同意，现印发给你们，请认真贯彻落实。

洋县人民政府办公室

2017年3月6日

洋县地质灾害防治高标准“十有县”

建设工作实施方案

2017年，我县被省国土资源厅确定为全省地质灾害防治高标准“十有县”建设县，为确保建设工作顺利推进，根据《国土资源部办公厅关于开展地质灾害防治高标准“十有县”建设工作的通知》(国土资厅发〔2013〕43号)和《陕西省国土资源厅关于印发陕西省地质灾害防治高标准“十有县”建设指南（试行）的通知》（陕国土资环发〔2014〕30号），结合我县实际，制定本实施方案。

一、指导思想

牢固树立“以人为本、科学防控”理念，全面贯彻落实《地质灾害防治条例》、《国务院关于加强地质灾害防治工作的决定》(国发〔2011〕20号)和《陕西省人民政府关于贯彻落实国务院加强地质灾害防治工作决定的实施意见》(陕政发〔2011〕59号)，按照有制度、有机构、有经费、有监测、有预警、有评估、有避让、有宣传、有演练、有效果的高标准“十有县”建设内容，稳步推进地质灾害防治体系建设的规范化、标准化，切实提高地质灾害防治水平，最大限度避免地质灾害造成的人员伤亡和财产损失。

二、基本原则

（一）坚持“以人为本，安全第一”原则。充分发挥政府主导作用，切实把人民生命财产安全放在首位，加强地质灾害防治工作，促进社会和谐。

（二）坚持“预防为主，常备不懈”原则。加强巡查、监测工作，做到早发现、早预警、早采取避让或治理等措施，做好应对突发地质灾害的各项准备工作，确保将灾情、险情控制在可控范围内。

（三）坚持“群测群防，干群结合”原则。调动全社会的积极性，全民参与防灾减灾工作，以群测群防、监测预警为主，动员镇（村）组织、企事业单位和各级干部及广大人民群众积极参与，建立健全全县地质灾害群测群防体系。

（四）坚持“分级分类，属地管理”原则。落实防灾措施，镇、村组织及企事业单位和有关部门对本辖区内地质灾害防治工作负责。

（五）坚持“协调一致，扎实推进”原则。将地质灾害防治与防治其它自然灾害相结合，与建设工程、资源开发、环境保护相结合，整体推进、稳步提升。

三、目标任务

根据国土资源部高标准“十有县”内容要求，结合我县具体实际情况，确定工作任务。

（一）有制度。全面建立地质灾害防治各项制度。健全完善《洋县地质灾害调查排查制度》、《洋县地质灾害巡查核查制度》、《洋县地质灾害值班值守制度》、《洋县地质灾害预警预报制度》、《洋县地质灾害信息报告制度》、《洋县地质灾害应急会商制度》、《洋县地质灾害应急处置工作规则》、《洋县地质灾害防治培训与科学普及制度》、《洋县地质灾害应急预案和隐患点避险演练制度》、《洋县地质灾害防治项目和资金管理办法》、《洋县地质灾害群测群防动态更新制度》等11项制度，做到防治有规划、工作有计划、年度有方案、点上有预案。制定《洋县地质灾害防治高标准“十有县”建设工作手册》。

（二）有机构。健全洋县地质灾害防治工作领导小组，领导小组下设办公室。县国土局按照《洋县应急能力装备和信息化建设方案》配备地质环境监测站办公设备。各镇政府、街道办成立地质灾害防治领导小组，设立办公室，负责处理日常事务，实现评估、巡查、预案、宣传和人员五到位。各村委会（社区居委会）设立村（社区）地质灾害联防组织，做到本村范围内地质灾害监测、巡查、避险撤离有制度、有预案。

（三）有经费。将地质灾害防治工作经费纳入年度财政预算，每年预算不低于50万元，主要用于隐患点监测人员补贴、成功预报人员奖励、监测设施维护、预报预警信息发送、地质灾害宣传、公益性建设项目和农村居民建房选址地质灾害评估等工作，确保项目配套资金能及时到位,确保防灾监测补贴能及时发放到位，充分调动群众的积极性。

（四）有监测。建立健全县、镇、村三级地质灾害监测责任体系，将现有的119处地质灾害隐患点全部纳入群测群防网络，落实监测人和责任人，配备简易监测设备，在黄金峡初级中学滑坡隐患点安装专业监测预警设备，建立地质灾害监测预警示范区，定期对监测记录进行综合分析整理，形成年度地质灾害隐患点监测报告。

（五）有预警。县国土局与县气象局共同建立地质灾害气象预警平台，联合开展地质灾害气象风险预报（警）工作。同时，建立国土、气象、水利等部门的预报预警会商制度，根据气象降雨情况及时会商，形成预警预报信息，通过广播电视、网页、手机短信等形式向各级防灾责任人、监测人、社会发布预警信息。根据气象预报和日常监测，开展单点地质灾害监测预警预报工作。重点地灾隐患点配备无线寻呼大喇叭预警系统，实现手机控制广播预警、信息传送、远程会议、应急指挥等，满足地质灾害协同防治和应对管理的实际需要。

（六）有评估。县国土局要制订《地质灾害危险性评估工作管理办法》，在县境内地质灾害易发区内实施的建设工程、各类城镇、村庄、集中安置点等规划必须开展地质灾害危险性评估工作。评估报告中提到的防治措施在工程建设中予以实施，并作为工程验收的重要依据。对于农村居民零散建房选址，由镇政府和国土所对场地进行简单安全评估，提出合理建议，住户落实后方能建房。农村居民建房选址评估所需经费纳入防治经费范畴。县国土资源局要指导建设单位加强评估报告或评估意见的落实，有效降低建设工程项目遭受地质灾害的风险。

（七）有避让。全面建成现有119处隐患点的应急避险场所，建立地质灾害预警指示牌、地质灾害应急避险场所标识牌，让每个受威胁群众了解熟悉撤离路线和应急避险场所位置，通过演练、宣传等手段，让群众熟悉撤离路线，保证接到撤离预警信息后，受威胁群众都能及时、安全撤离，实现地质灾害避让成功率达到100%。

（八）有宣传。充分利用各类宣传日，运用广播、电视、互联网、电子显示屏等平台开展宣传工作，普及地质灾害防治科学知识，增强各镇、各部门、企业和广大人民群众的防灾意识。经常性组织开展地质灾害防灾减灾政策宣传、临灾避险知识普及、防治技术培训等活动。使基层地质灾害防治人员基本掌握“四应知”(应知隐患点情况和威胁范围、应知群众避险场所和转移路线、应知险情灾情报告程序和方法、应知地质灾害监测时间和次数)，“四应会”（应会识别地灾发生前兆、应会使用简易监测方法、应会对监测数据记录分析和初步判断、应会指导防治和应急处置)，全年全县宣传培训人数不少于1万人。

（九）有演练。按照《陕西省突发地质灾害应急预案演练指南（试行）》和《陕西省地质灾害隐患点应急避险演练指南（试行）》要求，认真组织开展应急演练。在汛期前选择一处重要地质灾害隐患点进行县级地质灾害应急演练，以磨合机制检查装备，锻炼防灾队伍。2017年7月份之前各镇办要组织开展隐患点避险应急演练，教育群众安全撤离到应急避难场所，全年共完成应急演练54场次。

（十）有效果。地质灾害隐患威胁情况清楚，对已查明的可能有重大危害的隐患点制定治理、搬迁计划，并按计划完成治理、搬迁等工作，有效减少受威胁群众。

四、实施步骤

地质灾害防治高标准“十有县”建设工作分四个阶段实施。

（一）准备阶段（2017年2月5日至3月5日）。制定高标准“十有县”建设工作方案，召开宣传动员会议，研究部署和启动“十有县”创建工作。

（二）建设阶段（2017年3月6至5月31日）。根据高标准“十有县”建设工作方案要求，逐项落实建设任务。

（三）自查完善资料阶段（2017年6月1日至6月30日）。总结前阶段建设工作，按照高标准“十有县”建设内容逐项查找不足，及时解决存在的问题，并编制高标准“十有县”申报资料。

（四）验收阶段（2017年7月1日至7月31日）。上报地质灾害防治高标准“十有县”申报资料，并做好各项验收准备工作。

（五）巩固提升阶段（2017年8月1日至9月30日）。高标准“十有县”建设工作通过省市验收后，对建设工作进行全面总结、巩固建设成果。

五、工作要求

（一）强化责任，精心组织。各镇（办）、各有关部门要将地质灾害防治高标准“十有县”建设工作作为2017年地质灾害防治工作重点，制定详细的工作任务和责任，做到任务明确、责任到人、措施到位。同时，建立健全责任奖惩考核机制，确保创建各项工作任务顺利完成。

（二）加强指导，确保成效。地质灾害防治各成员单位要加强对地质灾害防治高标准“十有县”建设工作的配合与指导。各镇（办）要深入调查,结合实际，制定切实可行的创建方案，并按照方案开展好辖区地质灾害防治工作，确保地质灾害防治高标准“十有县”建设工作取得预期成效。

（三）加强培训，提高水平。地质灾害防治高标准“十有县”建设工作是一项基础性、群众性很强的工作，县国土局要加强全县地质灾害群测群防监测责任人的培训，保证各镇村干部及群众都能掌握地质灾害防治知识，提高全县群测群防能力。

（四）加强考核督导。地质灾害防治高标准“十有县”建设工作时间紧、任务重，各镇（办）、有关部门要切实履行各自工作职责，按照实施方案和各项工作时间节点紧锣密鼓开展工作，确保任务完成。县政府督查室将此项工作纳入重点督查事项，县考评办一月一考核，一月一通报。对工作不力、推诿扯皮、影响工作进度的部门和人员严肃追究责任。
