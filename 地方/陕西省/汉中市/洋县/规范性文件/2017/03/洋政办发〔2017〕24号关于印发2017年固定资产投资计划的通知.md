# 洋政办发〔2017〕24号关于印发2017年固定资产投资计划的通知

洋政办发〔2017〕24号

洋县人民政府办公室

关于印发2017年固定资产投资计划的通知

县政府各工作部门、直属机构，市管单位：

2017年是“十三五”规划的关键之年，也是全面建成小康社会的攻坚期。为了确保全县经济社会持续、健康发展，按照市委、市政府确定的全市全社会固定资产投资增速20%的目标任务要求，结合我县实际，在调研论证的基础上，将固定资产投资按系统、按年度目标及均衡进度进行任务分解，安排固定资产投资115.74亿元，现随文附上2017年固定资产投资计划分解表（见附表）。并就有关事项通知如下：

一、各项目主管部门要进一步夯实固定资产投资任务，充分挖掘项目，并按照新的统计制度要求，确定专人完善项目报建和进入统计口径的各种手续，及时到县统计局入统登记并向发改局和统计局提供项目进度资料，确保按时、按节点完成目标任务。

二、纳入固定资产投资计划的项目实行一把手责任制。项目主管部门的主要领导要积极协调项目建设中征地、拆迁和资金等重大问题，同时要求固定资产投资5000万以上的项目建设单位积极完成网上申报工作，确保项目应统尽统并顺利开展。

三、严格按照《洋县固定资产投资工作考核办法》要求，将固定资产投资完成情况纳入项目主管部门年度考核， 2017年固定资产投资实行百分制考核。第一季度占20分、第二季度占30分、第二季度占20分、第四季度占30分，每季度根据各部门完成的实际数字进行通报（数字由县统计局负责提供），分数换算后报县考核办，纳入年终考核。对圆满完成任务的单位将予以表彰奖励；对完成任务不到70%的，实行“一票否决”，年终取消评优资格。
