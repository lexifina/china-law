# 洋政办发〔2017〕29号关于抽调人员保障花海节开幕式相关活动的通知

洋政办发〔2017〕29号

洋县人民政府办公室

关于抽调人员保障花海节开幕式相关活动的

通 知

各镇人民政府，街道办事处，县政府各工作部门、直属机构，市管单位：

为了高质量、高标准开展花海节主会场系列活动，经政府研究，决定抽调部分单位相关人员全程参与花海节开幕式活动保障工作，现就有关事项通知如下：

一、抽调时段及人员报到

抽调时段：3月21日（星期二）下午2:30—24日（星期五）下午6:00。

报到时间：所有抽调人员于3月21日（星期二）下午2:30，到花海节筹委会办公室报到，参加开幕式保障工作会。

报到地点：县教体局二楼会议室。

二、抽调人员名单

所抽调人员名单附后（附件）。

三、几点要求

1、统一认识。全力做好开幕式相关活动保障工作是高标准举办花海节的重中之重，各镇办、各部门必须统一思想认识，克服自身困难，服从全县大局，严格按照既定时间节点，安排所抽调人员准时到岗。必须选派所抽调人员本人参与活动，不得以任何形式替换顶岗。

2、强化保障。花海节期间（3.22日——4.09日），承担其他43项系列活动保障任务的青年志愿者，要严格按照既定安排（《洋州青年志愿者协会2017年主要活动任务分解表》）和后续相关通知，按时到岗开展工作。所在单位要及时安排志愿者出勤，确保花海节期间各项活动顺利进行。

3、严明纪律。各镇办、各部门必须严格按照文件要求安排所抽调人员按时到岗，不得以任何理由推诿塞责。对于思想不重视、安排不到位的镇办、部门，要严肃追究单位主要领导的责任；对于不按时到岗、不服从任务安排的干部个人，将由监察部门按照有关规定给予严肃处理。
