# 洋政发〔2017〕7号洋县矿产资源开发保发展治粗放保安全治隐患保生态治污染行动计划（2017—2020年）的通知

洋政发〔2017〕7号

洋县人民政府关于印发

洋县矿产资源开发保发展治粗放保安全治隐患保生态治污染行动计划（2017—2020年）的

通 知

各镇人民政府、街道办事处，县政府有关工作部门、直属机构：

现将《洋县矿产资源开发保发展治粗放保安全治隐患保生态治污染行动计划（2017—2020年）》印发给你们，请按照各自职责分工，结合实际，认真贯彻执行。

洋县人民政府

2017年3月6日

洋县矿产资源开发

保发展治粗放保安全治隐患保生态治污染行动计划（2017—2020年）

为落实绿色发展理念，强化矿山生态环境和安全生产监管，提高矿产资源开发经济、社会、生态综合效益，根据省市要求，现就进一步做好我县矿产资源开发保发展、治粗放，保安全、治隐患，保生态、治污染（以下简称“三保三治”）工作通知如下：

一、总体目标

实现矿产资源规模开发、综合利用、集约经营、安全生产、绿色发展，繁荣矿业经济，促进经济实现中高速增长、产业结构转型升级。

（一）矿业经济支撑作用进一步增强。

（二）矿业经济结构明显优化。矿山布局进一步优化，矿产深加工能力明显增强，能源矿产、大宗金属、“优、急、稀、特”等战略性矿产多元支撑的矿业发展格局基本形成。

（三）节约集约利用水平明显提高。矿山总量减少35%，大中型矿山占比提高到20%；10万吨/年以下的采石矿山和2000万块/年以下的粘土砖瓦厂全部淘汰；全县露天采石矿山通过整治整合最终保留7个，最低开采规模、开采年限符合国家产业政策；大中型矿山“三率”全面达标；共伴生、难利用矿综合利用率大幅提升。

（四）矿山安全生产能力显著增强。矿山安全“三同时”制度全面落实，实时监控系统全面建成，事故总量大幅减少、重特大事故基本杜绝；各种违法违规行为得到全面遏制，矿业秩序全面好转。

（五）生态环境影响大幅降低。自然保护区、人文景观区、水源保护区、居民集中生活区和重要交通干线、河流湖泊直观可视范围内矿山依法逐步退出。矿山生态环境恢复治理率达到80%；尾矿、废渣利用率达60%以上，矿山废水、废气、粉尘排放全面达标，矿山人为重金属污染基本根治。

二、工作步骤

矿产资源开发“三保三治”工作由县人民政府负责，县级相关部门按职责分工组织实施。共分五个阶段：

（一）部署任务阶段（2017年3月—2017年5月）。逐级落实“三保三治”行动任务。明确行动重点、目标任务、责任分工、完成时限和相关具体要求，落实工作责任。各镇人民政府（街道办）要制订“三保三治”行动实施方案，并于3月底前报县国土局。

（二）集中治理阶段（2017年6月—2017年12月）。认真落实省市“三保三治”工作要求，分行业、分领域、分种类，因地制宜制定产业升级、推进整合、综合治理、改造提升的具体计划和措施，按时完成产业升级、资源整合、综合整治、改造升级工作和安全隐患矿山整治任务。

（三）完善提高阶段（2018年1月—2018年6月）。积极配合省、市做好中期评估工作，县政府组织相关部门成立督查小组，对全县“三保三治”工作进行督查，夯实责任，落实整改。

（四）整治提升阶段（2018年7月—2019年12月）。在总结前两年工作经验的基础上，对标检查，针对工作中的问题，进一步细化措施、完善方案、治理提升，基本形成绿色矿业发展格局。

（五）总结验收阶段（2020年1月—12月）。2020年3月底前，完成自查整改，对照发现问题，分类梳理、健全治理体系、建立长效机制，完善制度建设，巩固行动成果，迎接省市检查验收。

三、任务分工

县发改局：制定全县矿产资源开发保发展治粗放行动方案；依据全县主体功能区规划，划定矿产资源重点开发区、限制开发区和禁止开发区；制定矿业发展循环经济延伸产业链详细工作计划，淘汰落后生产技术装备和产能，加大金属、非金属加工配套项目建设力度，县内深加工率不低于80%；健全矿业市场，大力推行矿业权市场化，增强矿业资源开发调控能力，从严投放采矿权；探索建立矿业权有偿有序退出机制；拓宽矿山企业融资渠道，推行矿业权抵押备案制度；积极推进钒钛磁铁、石墨烯等优势资源开发，争取建设全省石墨烯加工研发基地，引进建成一批矿产品加工示范企业和产业基地（县经贸局、财政局、科技局、国土局、住建局、林业局、水利局、有色工业园区管委会等部门配合）。

县安监局：制定全县矿产资源开发保安全治隐患行动方案；完善矿山企业安全生产管理制度，夯实企业主体责任，督促矿山企业全面履行安全生产法定义务；严格落实矿山安全生产“三同时”制度；建立矿山安全隐患排查工作常态化机制，开展尾矿库等矿山安全专项整治，对查出的各类隐患要实时登记，建立台账，落实整改措施和责任，坚决停产，限期整改，对整改不到位的要倒查责任，依法追究；严格执行矿山安全生产许可制度，加强矿山安全生产执法大检查，加强矿山安全生产许可证延续年检管理和审查，依法严惩安全生产领域的违法违规行为；全面开展矿山安全生产标准化达标创建活动，引导矿山企业进一步树立安全生产法律法规意识，进一步提高安全生产经营管理水平（县国土局、环保局、林业局等部门配合）。

县环保局：制定全县矿产资源开发保生态治污染行动方案；严格执行矿山环境影响评价在先制度，落实“三同时”制度；推进秦岭生态环境保护区生态环境恢复治理；大力推进绿色矿山建设，打造一批具有重要示范意义的绿色矿山；建立分级负责的重点矿山环境监管责任制度，制定全县重点监管企业名单，实行一对一监管，责任到人；建立矿山环境动态监测体系，全面掌握全县矿山环境动态变化情况；研究制定矿山及选矿企业环境管理、环境风险管控制度措施，对达不到规范要求的新建矿山不得通过审批；对达不到规范要求的已建矿山，限期整改，拒不改正或整改不合格的依法予以关闭（县发改局、国土局、林业局、水利局等部门配合）。

县国土局：制定全县矿产资源总体规划；始终坚持环境影响评价优先制度，建立健全矿山联合审查机制，严把采矿权准入关，严禁在“三区两线”范围内新设矿业权。实施矿产资源整合常态化管理，大力推进开山采石专及粘土砖瓦厂专项整治，加强地质勘查项目和矿山企业的监管和执法检查，对乱采滥挖违法行为进行查处，严厉打击无证、超层越界开采、以采代探、非法转让矿业权等违法违规行为；积极申报地勘基金项目；积极做好整装勘查外部环境保障，强力推进整装勘查区找矿突破；建立矿山环境动态监测体系，全面掌握全省矿山环境动态变化情况。落实矿山企业“边开采、边治理”“谁破坏、谁治理”的主体责任，严格执行矿山地质环境治理恢复保证金和土地复垦履约金制度，探索建立矿山地质环境年度治理恢复实施情况与保证金缴存挂钩机制（县发改局、经贸局、安监局、环保局等部门配合）。

县林业局：严厉打击毁坏林木、破坏山体的非法开采行为，做好各类自然保护区的日常管护及巡查工作，配合国土部门做好地质环境治理恢复工作。

县水利局：加强水源地保护，做好城乡居民饮水安全，强化河道挖沙采石监管，开展河道挖沙采石专项治理行动，严厉打击非法开采行为，确保“一江清水送北京”。

县公安局：加强矿山企业火工用品及选冶用化学制品运输、保存、使用的监管；加大矿山环境污染及损害案件查处力度。

县监察局：督促跟踪检查各部门及乡镇履职尽责情况，重点查出工作措施不力、责任不实等问题。

各镇人民政府（街道办）：各镇（街道办）是矿产资源开发“三保三治”工作的责任主体，扎实开展工作，确保辖区矿产资源开发有序推进，矿业经济转型升级。

四、工作要求

（一）加强领导。为推动“三保三治”工作深入开展，县政府决定建立“洋县三保三治工作协调领导小组（名单附后）”，统筹协调推进全县“三保三治”工作。各镇办各有关部门要按照县政府的工作部署，组建机构，扎实开展“三保三治”工作；按照“属地管理、联合审查、首审负责、分类监管”原则，结合本地实际，将方案细化分解，制定详细计划，确保“三保三治”行动落到实处。对中省市关于矿业经济发展、矿山安全生产、环境保护治理等方面的政策和项目资金进行有机整合，集中投放，最大限度发挥政策叠加效应。

（二）强化协作。落实部门责任分工，按照“有规定从其规定、规定交叉重叠的合理划分、没有规定的监管盲区归并到业务相近部门”的思路予以明确，认真履职，密切配合，形成合力，确保本次行动全面顺利完成。要畅通信息交流，搞好工作联动，对属本部门业务范围的要及时采取措施，即时处理；对检查中发现的非本部门职责范围内的问题或违法违规行为，要及时移交由管辖权的部门，提高工作效率和系统治理效果。

（三）加强督导。县“三保三治”工作协调领导小组要每季度检查各镇（街道办）和有关部门“三保三治”工作进展情况，对发现的问题及时提出处理意见，限期整改，定期发布督查通报。各镇（街道办）和有关部门每季度末将“三保三治”工作实施情况上报县“三保三治”工作协调领导小组办公室（办公室设在县国土局）。

（四）营造氛围。充分发挥新闻媒体的舆论导向和监督作用，通过报刊、户外、通信、广播、电视及网络等平台、采取多种形式，深入宣传开展“三保三治”行动的重大意义、目标任务，扩大社会影响，使绿色发展、安全生产、环境保护、综合利用矿产资源的理念深入人心。及时推广先进典型，加大社会舆论引导，营造全社会支持开展“三保三治”行动的良好舆论氛围，推动工作任务顺利开展，圆满完成。

县级部门“三保三治”

行动计划（2017—2020年）工作要点

一、保发展、治粗放

（一）制定全县矿产资源开发保发展治粗放行动方案（县发改局牵头，相关部门参与）。

（二）完善发展规划，优化资源开发格局。

1．修订完善洋县主体功能区规划（县发改局牵头，相关部门参与）。

2．制定洋县矿产资源总体规划（县国土局负责）。

3．制定洋县石墨烯产业发展规划（县发改局牵头，相关部门参与）。

（三）健全矿业市场，提高资源配置效率。

增强矿产资源开发调控能力，从严投放采矿权（县国土局负责）。

（四）发展循环经济，不断延伸产业链条。

1．大力推进洋县新型材料循环产业园建设（有色工业园区管委会办公室牵头，相关部门参与）。

2．实施矿产资源节约和综合利用示范工程，建成一批示范企业和产业基地（县国土局牵头，相关部门配合）。

（五）持续加大找矿力度，切实保障资源需求。

1．积极申报地勘基金项目（县国土局负责）。

2．积极做好整装勘查外部环境保障，强力推进整装勘查区找矿突破（县国土局牵头，相关镇办配合）。

（六）强化政策支持，减轻矿山企业负担。

1．探索建立采矿权价款缓缴与储量挂钩机制（县国土局负责）。

2．探索建立矿山地质环境年度治理恢复实施情况与保证金缴存挂钩机制（县国土局负责）。

二、保安全、治隐患

（一）制定完成全县矿产资源开发保安全治隐患行动方案（县安监局牵头，相关部门参与）。

（二）推动资源整合，扭转散、小、弱、差局面。

1．实施矿产资源整合常态化管理（县国土局负责）。

2．有序推进开山采石专项整治，减少矿山数40%（县国土局负责）。

3．开展粘土砖瓦窑场专项整治（县国土局、县住建局牵头，相关部门配合）。

（三）切实加大矿山安全生产投入。

1．完善矿山企业安全生产管理制度，夯实企业主体责任，严格落实矿山安全生产“三同时”制度（县安监局负责）。

2．全面落实矿山企业厂区地质灾害危险性评估制度（县国土局负责）。

（四）全面排查矿山生产各类安全隐患。

1．建立矿山安全隐患排查工作常态化机制（县安监局牵头，相关部门配合）。

2．加强矿山企业火工用品及选冶用化学制品的监管（县公安局负责）。

3．开展尾矿库等矿山安全专项整治（县安监局牵头，相关部门配合）。

（五）严厉打击矿产资源违法违规行为。

1．加强地质勘查项目和矿山企业的督察和执法检查，严厉打击无证、超层越界开采、以采代探、非法转让矿业权等违法违规行为（县国土局牵头，相关部门配合）。

2．严格执行矿山安全生产许可制度，加强矿山安全生产执法大检查（县安监局牵头，相关部门配合）。

3．对矿山重特大隐患排查整治不到位的进行问责（县监察局牵头，相关部门配合）。

（六）创新矿山安全生产监管手段。

1．全面开展矿山安全生产标准化达标创建活动（县安监局牵头，相关部门配合）。

2．推进矿山储量动态监管（县国土局负责）。

三、保生态、治污染

（一）制定完成全县矿产资源开发保生态治污染行动方案（县环保局牵头，相关部门参与）。

（二）大力推进绿色矿山创建活动，打造一批具有重要示范意义的绿色矿山（县国土局牵头，相关部门配合）。

（三）加强重要生态区域保护。

1．严禁在重要生态区域范围内新设矿业权（县国土局牵头，相关部门配合）。

2．严格执行矿山环境影响评价在先制度，落实“三同时”制度（县环保局牵头，相关部门配合）。

3．严格执行矿山地质环境治理恢复保证金和土地复垦履约金制度，落实矿山企业恢复治理环境的主体责任（县国土局牵头，相关部门配合）。

（四）落实环境监管责任。

1．建立分级负责的重点矿山环境监管责任制（县环保局牵头，相关部门配合）。

2．对占用耕地乱采滥建违法行为进行查处（县国土局牵头，相关部门配合）。

3．对在规划林地内乱采滥建违法行为进行查处（县林业局牵头，相关部门配合）。

4．对已有建设用地上乱采滥建违法行为进行查处（县住建局牵头，相关部门配合）。

5．对河道内乱采滥建违法行为进行查处（县水利局牵头，相关部门配合）。

6．加大矿山环境污染及损害案件查处力度（县公安局牵头，相关部门配合）。

（五）强化环境准入管理。

1．建立新建矿山联合审查机制，严把采矿权准入关（县国土局牵头，相关部门配合）。

2．严把矿山环境保护“三同时”竣工验收（县环保局牵头，相关部门配合）。
