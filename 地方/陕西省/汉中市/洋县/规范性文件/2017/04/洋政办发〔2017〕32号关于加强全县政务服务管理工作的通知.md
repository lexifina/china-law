# 洋政办发〔2017〕32号关于加强全县政务服务管理工作的通知

洋政办发〔2017〕32号

洋县人民政府办公室

关于加强全县政务服务管理工作的通知

各镇政府、部门、直属机构：

政务服务中心（便民服务大厅）是推进“放管服”改革、建设服务型政府的重要平台，是政府联系人民群众、服务社会公众的重要场所。为切实加强和进一步规范全县各级各类政务服务大厅管理工作，现将有关事项通知如下：

一、加强协调，建立服务联动机制。各镇各部门要进一步加强政务服务事项办理工作的协调组织，按照“服务窗口谁接待谁负责、业务部门谁主管谁负责”的原则，建立县、镇政府办公室牵头的政务服务联动机制（部门设立的服务大厅由本部门建立内部联动机制），加强前台服务窗口与后台职能部门有效联动、工作衔接，无缝对接前后台工作，有效解决在服务过程中出现的各类问题，避免让群众“多头跑路、来回跑路”的现象发生。

二、优化流程，推进服务透明高效。各镇各部门按照“放管服”改革要求，结合编制权力清单、责任清单、公共服务清单编制工作，对服务事项进行全面梳理，对政务服务办理事项逐项编制办事指南，要列明办理依据、受理单位、基本流程、申请材料、示范文本及常见问题示例、收费依据及标准、办理时限、咨询方式等内容，并及时动态调整。按照“应进必进”的原则，推动各类审批服务事项进驻政务服务中心办理。2017年，县上行政许可事项进驻中心办理比例不低于50℅，原则上2018年实现全部进驻。同时，进一步优化工作环节，坚决砍掉各类无谓证明和繁琐手续，最大限度精简办事程序，减少办事环节，缩短办理时限，提高办事效率。

三、完善制度，加快服务中心功能升级。县行政服务中心要积极探索将部门分设的办事窗口整合为综合窗口，变“多头受理”为“一口受理”，为群众提供项目齐全、标准统一、便捷高效的政务服务。各镇、部门、直属机构要认真学习并结合县中心的首问负责、一次性告知、并联办理、显示办结等制度，完善管辖区政务服务管理制度，同时积极推行一站式办理、上门办理、预约办理、自助办理、委托代办等服务，鼓励大胆创新，向社会公众提供联办会办、容缺审批等新型政务服务，探索开展由申请人书面承诺符合相关条件并进行公示，办事部门先予以办理，再相应加强事后核查监管的服务模式。按照《陕西省人民政府关于加快推进全省“互联网+政务服务”工作的实施意见》（陕政法〔2016〕55号）要求，进一步提升政务服务能力，整合网上服务资源，加快推动政务服务向网上延伸。

四、强化管理，严格落实考核奖惩制度。县行政服务中心要构建科学完备、运行有效的管理体系，严格落实巡查、约谈、反馈等制度，实行政务服务“日统计、月分析、季通报、年考评”。各镇和部门在认真学习这种管理体系的基础上，严格辖区便民服务大厅的管理，积极推进政务服务中心（便民服务大厅）对窗口工作人员统一考核，并根据考核情况进行奖惩。进驻中心开展工作或设立服务大厅的部门，要把服务窗口作为提升本部门效能、展示本单位形象的重要阵地，严格遵守中心规定，接受政务服务中心对本部门出窗口统一监管。

五、优化队伍，进一步转变工作作风。窗口工作人员是实施服务的主体，政务服务中心（便民服务大厅）要不断优化工作人员结构，加强培训教育，建设高素质、高效率、高质量的窗口工作人员队伍。县上负责主管政务服务的部门和领导要定期督导检查，对存在问题的单位及时督促整改，对群众反映强烈的不作为、乱作为现象，要加大问责追责力度。充分发挥群众监督和舆论监督作用，有效推进工作作风转变。
