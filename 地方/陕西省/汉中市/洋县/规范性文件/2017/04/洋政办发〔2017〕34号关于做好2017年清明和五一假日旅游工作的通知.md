# 洋政办发〔2017〕34号关于做好2017年清明和五一假日旅游工作的通知

洋政办发〔2017〕34号

洋县人民政府办公室

关于做好2017年清明和五一假日旅游工作的

通 知

各有关镇人民政府、街道办事处，县政府各有关工作部门、直属机构：

2017中国最美油菜花海汉中旅游文化节在我县开幕后，来洋县游客数量激增，随着清明和五一小长假的到来，必将再次形成新的旅游高峰。因此，各有关镇办、部门和各旅游接待单位要高度重视，充分认识“安全是旅游发展的生命线”，增强旅游安全防范意识，高标准、高质量地做好各项准备工作，促进假日旅游市场持续繁荣稳定，实现“安全、秩序、质量、效益”四统一目标，让广大游客享受一个“舒心、和谐、安全”的清明和五一小长假。现就有关事项通知如下：

一、突出重点，认真抓好旅游安全管理

各有关镇办、部门和接待单位要把旅游安全工作摆到突出位置，始终坚持“安全第一、预防为主”的方针，落实安全责任，完善安全措施，抓好旅游安全管理工作落实。

1.抓好旅游交通安全。针对可能出现的雨雾天气及旅游团队车辆多、自驾车出游多、游客密集等特点，交通局及早制定运力调度和游客疏导方案，避免大范围游客滞留；交通、交警、安监部门要加强游客客运监管和交通设施维护，严禁非法营运、带病车辆和超时超载运营；洋州、纸坊、戚氏三个街道办，谢村镇、龙亭镇、磨子桥镇在小长假期间至少要安排150名安全协理员，在本辖区内交通要道、主要路段和观花点协助疏导交通，引导游客规范有序停放车辆；交警大队要在重点路段设置警示标志和警力部署，特别要在洋华路、磨草路、朱鹮大道、梨园大道等路段加强部署，严防重大旅游交通事故发生，确保车辆畅通。

2.抓好各项活动安全。在假日期间举办的各项活动，要精心制定好活动方案和突发事件的应急救援预案，加强与公安、交警部门的沟通衔接，事先进行预演，防止发生群死群伤事故。如遇安全事故发生，按预警级别启动《洋县旅游安全应急预案》。

3.抓好游客密集场所安全管理。公安、消防、市监、安监、卫计等部门要加强交通集散地、旅游活动场所、住宿餐饮、旅游景区、游乐设施等重点部位的安全管理，督促业主单位建立和落实安全责任制，认真开展安全检查，消除安全隐患，严防踩踏、火灾、食物中毒等事故发生。

二、加强协作，不断提升假日旅游环境质量

各有关部门、单位都要以游客满意为目标，加大监督纠查力度，加强对假日旅游市场的规范和引导，努力营造和谐、文明、有序的旅游环境。

1.开展联合执法。由市监局牵头，文旅局、交通局、物价局、卫计局、公安局、安监局等部门配合，认真开展执法检查。重点查处无资质经营者发布旅游服务广告、超出经营范围进行广告宣传以及误导欺诈消费者的广告宣传等行为；查处无资质经营旅游业务和从事旅游服务的行为；查处非法转让、出租或者出借旅游业务经营许可证的行为；查处强迫消费或变相强迫旅游者消费的行为；检查旅游景区及周边旅游市场秩序。

2.倡导诚信经营。各旅行社门店、各景区（点）要从旅游窗口单位诚信经营理念角度出发，对预定协议及优惠措施要不折不扣兑现；各宾馆、酒店要杜绝借机随意涨价、不讲诚信行为，对部分餐饮单位近期出现的恶意涨价行为，市监、文旅、物价部门要严肃查处；文旅部门要认真做好旅游行业管理工作，着力抓好景区的服务质量，认真受理游客投诉，保证游客的切身利益，规范旅游经营行为，维护好旅游市场秩序。

3.加强公共信息服务。要及时全面掌握市场变化，有针对性地发布对公众有实用价值的出行信息。重点旅游景区（景点）和交通干线以及客流集散地要采取措施，加强即时动态信息发布，更好地引导公众出行。同时，充分发挥新闻媒体的舆论引导作用，围绕建设生态文明，积极倡导资源节约、环境友好的旅游理念，推出各种有力措施，共同维护良好生态环境。

三、加强值班，做好旅游统计工作

节日期间，各有关镇办和部门、旅游接待单位都要科学安排值班工作，落实好领导带班、24小时值班制度，保证通讯畅通，并在假日前将假日值班名单报县文旅局。文旅局要全面负责全县旅游管理和接待协调工作，加强与有关部门、景点的信息联络，一旦发生险情和事故要迅速按照县政府《重大突发事件应急处理办法》处置，并按程序及时上报，对险情较大需要救援的，各有关部门和单位要积极配合，全力援助，把损失降到最低限度。

各旅游接待单位清明和五一假日期间务必于每日14:30点前将当日游客接待情况、收入情况及总体情况报送县文旅局。
