# 洋政办发〔2017〕36号关于印发洋县农村垃圾治理专项行动实施方案的通知

洋政办发〔2017〕36号

洋县人民政府办公室

关于印发洋县农村垃圾治理专项行动

实施方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县农村垃圾治理专项行动实施方案》已经县政府同意，现印发给你们，请认真贯彻执行。

洋县人民政府办公室

2017年3月31日

洋县农村垃圾治理专项行动实施方案

为加快推进美丽宜居乡村建设，根据省政府工作要求，决定在全省开展为期60天的农村垃圾治理专项行动。现结合我县实际，制定洋县农村垃圾治理专项行动实施方案。

一、指导思想

深入贯彻落实党的十八届五中、六中全会精神，以城乡一体化发展为导向，以改善农村人居环境，加快美丽宜居乡村建设为核心，按照我县“生态立县、旅游兴县”战略，各镇人民政府、街道办事处要结合汉江流域污染防治、美丽乡村建设和农村环境综合整治活动统筹推进农村垃圾治理专项行动。

二、目标任务

1、彻底清除陈年垃圾。集中力量，限定时间，全面排查清理农村陈年生活垃圾堆弃点，重点整治路边、河边、坑塘、沟渠、村边、城乡结合部等堆弃的生活垃圾。禁止城市向农村转移垃圾，防止在村庄周边新增生活垃圾堆放点。

2、建立长效管理机制。农村垃圾收运和处理的责任主体为各镇人民政府、街道办事处，实施主体为各行政村村民委员会。各镇人民政府、街道办事处要制定农村垃圾简易分类、统一收集、集中处理的长效管理制度，建立设施设备定期维护检查制度，及时修缮破损设施设备，培训操作人员和保洁员，严格执行垃圾收集和转运技术要求，确保垃圾及时清除、及时收运、及时处理。

三、时间安排

农村垃圾专项治理分三个阶段：

1、镇、办治理阶段（3月28日—4月20日）。各镇人民政府、街道办事处要认真开展非正规垃圾堆放点全面排查工作，督促各村（社区）迅速开展农村垃圾治理专项行动。集中清理工作结束后，要组织力量逐村进行巡回检查，确保不产生新的垃圾堆放点。并在4月15日前形成自查报告报住建局（村镇站）。

2、县级抽查阶段（4月20日—4月30日）。县住建局将联系有关部门以不少于50%的比例对各镇人民政府、街道办事处上报的专项治理情况进行现场抽查，同时对抽查情况进行通报。

3、省、市督查阶段（5月4日—5月15日）。省住房城乡建设厅将组织督查组开展专项督查，对未完成专项治理任务的县（区），予以通报、追责、问责并督促整，并将检查结果报省政府。

四、有关要求

1、落实各方责任。各镇人民政府、街道办事处要认真学习中、省、市有关农村垃圾治理指示精神和安排部署，以央视曝光的临潼区、户县、乾县等地农村垃圾围村问题为警示，在县政府的统一领导下，做好与相关部门的协调沟通，把专项治理任务落实到每一个行政村，明确责任人，确保任务到位、责任到位。

2、建立工作台账。根据县住房和城乡建设管理局、县环境保护局、县农业局、县水利局《关于做好非正规垃圾堆放点排查工作的通知》（洋建发〔2017〕26号）文件要求，各镇人民政府、街道办事处要高度重视非正规垃圾堆放点信息调查的准确性，摸清本行政区域内现有非正规垃圾堆放点的数量、规模、位置等基本情况，于4月10日前将排查信息录入住房和城乡建设部非正规垃圾堆放点排查信息系统（网址：http://czjs.mohurd.gov.cn），同时将加盖镇、办公章的调查表报住建局村镇站存档。住建局将根据各镇人民政府、街道办事处上报的非正规垃圾堆放点调查表建立县级工作台账。

3、迎接各级验收。4月中旬，住建局将会同环保局、农业局、水利局对排查信息进行核实，对治理情况进行督查。4月底市级建规、环保等部门将对排查信息进行核查，校核信息系统填报数据，检查漏报、瞒报情况。根据省政府关于改善全省农村人居环境工作安排部署，全省2018年前完成国家垃圾治理验收。今年，省住房城乡建设厅将联合有关部门对所有县（区）的农村垃圾治理进行考核验收。各镇人民政府、街道办事处要利用这次专项行动的契机，切实做好迎接省、市及国家验收的相关工作。

4、加强信息报送。各镇人民政府、街道办事处要确定专人负责开展农村垃圾专项治理信息系统填报和信息报送工作，及时将专项治理工作动态（包括好的做法、存在的问题）报送住建局（村镇站）。

洋县人民政府办公室
