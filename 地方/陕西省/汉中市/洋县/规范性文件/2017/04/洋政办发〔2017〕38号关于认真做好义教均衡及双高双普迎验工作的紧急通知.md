# 洋政办发〔2017〕38号关于认真做好义教均衡及双高双普迎验工作的紧急通知

洋政办发〔2017〕38号

洋县人民政府办公室

关于认真做好义教均衡及双高双普迎验

工作的紧急通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

4月9日，省政府教育督导团将对我县义务教育均衡发展及“双高双普”创建工作进行过程性督导评估。为确保此次评估顺利通过，现将有关事项通知如下。

一、提高认识，明确任务。义务教育均衡发展及双高双普合格县创建是2017年我县的重点工作之一，各镇办、各部门要高度重视，严格按照县上义务教育均衡发展和双高双普工作时间表、作战图、责任书，明确职责任务，加强领导、高效推动，确保本镇办、本单位高标准、高质量完成各项任务。

二、夯实责任，自查补漏。各包抓牵头部门要按照《洋县“双高双普”实施方案》（洋办发〔2016〕40号）和《陕西省“双高双普”评估验收标准》文件要求，切实帮助结对学校、幼儿园解决具体困难。各镇办要积极督查、指导和协调辖区中小学、幼儿园的双高双普创建工作，落实辖区内村（社区）、组教育工作职责，促进区域内各类教育持续、健康、协调发展；各迎验学校要将责任细化到人，对照验收标准，积极查漏补缺；县教体局负责在4月8日前组织人力对各迎验学校开展一次模拟验收，要严格按照验收标准对各校涉验项目进行一次内部摸底检验，将所发现的问题现场整理反馈，并要求相关学校立即整改落实，确保在省教育督导团验收时不出纰漏，不拖后腿。

三、分工协作，力求达效。各镇办、各部门要切实落实校园及周边环境综合治理工作职责，立足本职、分工协作。由各镇办具体负责，在4月8日前对辖区学校附近环境卫生进行一次集中整治，重点做好道路两边垃圾箱、绿化带及河道内的卫生整治，各迎验学校负责在4月8日前对校园环境卫生进行集中清扫，确保可视、可触范围内环境整洁。同时，各镇办、各单位要按照职责分工，确定专人负责做好自查整改和信访综治维稳等具体工作，积极协调配合，及时灵通信息，确保我县顺利通过评估验收。

洋县人民政府办公室

2017年4月7日
