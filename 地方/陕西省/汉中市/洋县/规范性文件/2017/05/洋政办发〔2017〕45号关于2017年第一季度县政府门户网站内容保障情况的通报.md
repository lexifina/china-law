# 洋政办发〔2017〕45号关于2017年第一季度县政府门户网站内容保障情况的通报

洋政办发〔2017〕45号

洋县人民政府办公室关于

2017年第一季度县政府门户网站内容

保障情况的通报

各镇人民政府、街道办事处，县政府各工作部门、直属机构:

根据洋县人民政府办公室《关于印发洋县政府网站管理有关规定的通知》(洋政办发[2016]44号)、《关于做好县政府门户网站内容保障工作的通知》(洋政办发[2016]45号)文件要求，现将2017年第一季度(1月1日-3月31日)政府门户网站内容保障情况通报如下:

2017年第一季度，县政府门户网站共发布各类信息1234条，其中：新闻动态类信息528条，信息公开类信息706条；政府各部门单位及镇办通过网站后台自行上传信息527条，政府信息中心上传信息707条。处理“县长信箱”和“咨询投诉建议”来信121件，已办结111件、超时办结17件，未办结10件。其中，教体局、国土局、科技局、茅坪镇信息发布和信息公开总数超过25条；经贸局、环保局、搬迁办、纸坊办事处、龙亭镇未发布和公开一条信息，信息统计为0。槐树关镇、龙亭镇在信件办理过程中存在未办结信件，部分单位超时办结现象依然突出。审计局、交通局、市场监管局、文旅局、扶贫办、纸坊街道办、龙亭镇、槐树关镇、溢水镇、黄家营镇未按照《中华人民共和国政府信息公开条例》要求，在3月31日前公开本单位“2016年政府信息公开年度报告”。

以上问题，请各镇办、各部门务必高度重视，进一步加强组织领导，完善管理机制，对存在的问题认真整改落实，全面做好政府网站内容保障工作。
