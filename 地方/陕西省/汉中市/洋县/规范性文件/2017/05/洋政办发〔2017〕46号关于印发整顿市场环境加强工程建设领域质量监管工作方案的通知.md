# 洋政办发〔2017〕46号关于印发整顿市场环境加强工程建设领域质量监管工作方案的通知

洋政办发〔2017〕46号

洋县人民政府办公室

关于印发整顿市场环境加强工程建设领域

质量监管工作方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

根据省市关于整顿市场环境加强工程建设领域质量监管工作的安排部署，为进一步整顿和规范市场环境，强化事中事后监管，特别是加强工程建设领域全面质量监管，制定了《整顿市场环境加强工程建设领域质量监管工作方案》，现印发给你们，请遵照实施。

洋县人民政府办公室

2017年4月20日

洋县整顿市场环境

加强工程建设领域质量监管工作方案

为进一步整顿和规范市场环境，全面加强工程建设领域质量监管，营造良好的追赶超越发展环境，现制定以下工作方案。

一、统筹推进放管结合，加强事中事后监管

（一）坚持放管结合。按照简政放权、放管结合、优化服务“三管齐下”的原则，发挥市场在资源配置中起决定性作用和更好发挥政府作用，着力降低制度性交易成本，优化营商环境，激发市场活力和社会创造力。完善企业投资项目核准备案管理办法，加强建设项目审批事项并联审批，提高审批效率；建立“三个清单”动态管理机制，适时调整并及时向社会公布，主动接受社会监督。

（二）强化事中事后监管。依托全省在线审批监管平台，加强项目建设领域各部门、各环节的协调、配合与衔接，在前置要件齐备后按照时间节点完成事项审批；加强项目报建阶段审批事项监管，严格落实项目开工各项条件，实现全过程监管。按照“谁审批谁监管、谁主管谁监管”原则，明确监管责任，整合监管力量，共享监管信息，实现协同监管。

二、规范招标投标行为，推进公开公正科学评定

（三）严格项目招标事项管理。按照《陕西省工程建设项目招标实施方案核准办法》，原则上实行公开招标，严格邀请招标和自行招标审批管理。规范信息公开内容，将公开招标项目资格预审公告、招标公告、中标结果公告、违法失信行为等纳入信息公开范围。

（四）严格工程发包分包管理。各有关部门要根据职责分工，加强对工程建设、勘察、设计、施工、监理招标投标监督管理。项目建设单位对招标投标工作负总责，对总承包企业采购关键设备材料全过程监督。总承包企业要按照合同约定对工程质量、工期、造价等向建设单位负责，对关键设备材料、分包工程要严格执行招标程序。

（五）严厉查处招标投标违纪违法行为。各有关部门要严厉查处通过制定专门条款或采取量身定做、恶意竞争等不正当手段限制或排斥潜在投标人投标，以及规避招标、围标串标、弄虚作假、操纵评标、借用资质投标等违法违规行为；近期开展专项整治活动，对典型案例曝光警示，对涉及违法的行为人进行严肃查处。

三、夯实工程监管责任，健全全过程监管体系

（六）严格执行工程建设法定程序。对未经批准或手续不全开工的，要依法责令停工；对项目建设单位和参与建设的施工、监理等单位，责令限期整改。项目建成后及时组织竣工验收。

（七）强化工程质量监管。严格落实建设、勘察、设计、施工和监理五方主体质量终身责任，落实质量终身负责制承诺书、法定代表人授权书、永久性质量责任标牌等三项制度，强化五方项目责任人的质量终身责任追究。建设单位要强化工程建设各阶段的质量管理责任。施工单位要配备和使用依法检定合格的计量标准器具，加强原材料、半成品、建筑构配件等进场验收和报验管理。监理单位要严格实行见证取样

及见证送检制度。

（八）全面整顿工程质量检测市场。完善工程质量检测管理制度，健全工程计量保障体系。加强对检测过程和检测行为的监管，严厉惩戒出具虚假检测报告行为。强化对检测机构在检测、校准和生产企业在生产过程中违法违规行为的查处，有效制止弄虚作假行为。

（九）加强工程质量执法监督。重点围绕重大基础设施和公共服务设施开展执法监督检查，对使用不合格计量器具、建筑材料或不按国家标准规范要求施工的承包单位，以及违反工程质量法律、法规和强制性标准的相关责任人，依法追究责任。对监理单位敷衍塞责、渎职失察，责令整改并依法惩处。加大违法违规案件公开力度，充分发挥社会舆论监督作用，形成工程质量社会共治局面。

四、加强产品质量监督，健全全面监管体系

（十）加强产品质量监督监管。依据有关法律法规，在生产、流通、使用环节，对产品质量定期监督检查，对重要产品要建立长效监督机制。全面推行“双随机、全覆盖”监管，完善质量安全防控机制。加强对质量检验检测机构和计量检定校准机构的监督管理，对出现违规行为的机构责令整改直至吊销资质。对发现质量问题的企业，严格依法处理，纳入重点监管名单。

（十一）严格著名商标认定管理。严格落实著名商标的申报认定审查条件，认真开展抽查检查，加强著名商标动态管理,充分运用国家企业信用信息公示系统，实施联合惩戒，对发现著名商标持有人受到有关部门依法处罚的，及时撤销其著名商标。加强注册商标专用权保护，严肃查处商标侵权行为，尤其是假冒仿冒知名商品的违法经营行为。

（十二）深化产品质量源头治理。住建、市场监管等部门要按照产品质量标准，加强对产品质量监督监管，对抽查发现的质量问题，及时通报生产者和所在地市场监管部门。按照“谁抽查谁负责”原则及时向社会公布抽查结果，实现产品质量协同监督。在工程建设中发现的问题产品，要立即封存进行处理；对一经曝光的问题产品，一律停止使用；对知情不报、失职渎职的单位和个人，严肃追究相关责任。

五、集中整治与常态监管结合，加大力度破获一批生产销售假冒伪劣商品等破坏市场经济秩序案件，消除社会治安隐患

从四月下旬到五月下旬，围绕工程建设和生产流通领域开展为期一月的集中整治，住建部门负责工程建设领域的秩序环境整治，市场监管局负责生产、流通领域的集中整治，公安等部门做好配合。同时要常抓不懈，确保工程建设和生产流通领域的不法行为得到有效遏制。

（十三）严厉打击假冒伪劣产品损害公共利益犯罪。住建、市场监管、公安等部门要密切协作，完善联合执法、信息共享、案件通报移送等工作机制，认真研究本地假冒伪劣产品犯罪的规律、特点，充分利用各种信息平台和侦控手段，深挖行业内幕，以打团伙、打系列、打跨区域犯罪为重点，精心组织开展专案攻坚和集群战役，坚决遏制制售假冒伪劣产品犯罪。

（十四）严厉打击破坏市场经济秩序、“围标”“串标”等利益输送犯罪。以“破大案、打团伙、端窝点、抓逃犯、追财产”为主要任务，大力加强侦查破案力度。探索建立防范和打击“围标”、“串标”利益输送犯罪侦查工作机制，工作中发现违法线索，及时反馈有关职能部门问责查处；对构成犯罪的，迅速介入，深挖犯罪内幕，查清犯罪事实，依法严厉打击犯罪分子，净化市场经济环境。

（十五）严厉打击沙霸、村霸等黑恶势力犯罪。深化扫黑除恶专项斗争，在建筑领域等易于滋生黑恶势力的行业、领域摸出一批隐藏较深的黑恶犯罪线索，确定一批重点目标案件，集中优势警力，实施精确打击，严厉打击强卖强买等扰乱重点项目建设的黑恶势力、农村黑恶势力以及涉足民生领域的黑恶势力，及时铲除恶势力团伙，全力侦破一批领导关心、群众关注、社会影响恶劣的黑恶犯罪大案。

六、完善社会信用体系，强制信用信息共享共用

（十六）实现信用信息共享。加快完善公共信用信息平台建设，各部门相关信息系统要全面实现与信用平台的互联互通，在履行职责过程中产生的市场主体登记备案、行政许可、行政处罚、行政奖励、检查抽查等信用信息，要及时汇集至信用平台，并持续按时更新。

（十七）加强信用信息公开应用。依托“信用陕西”网站，建设统一的公共信用信息查询、企业信用公开承诺窗口和信息公示专栏，并与中省企业信用信息公示系统等实现信息对接。全面建立信用信息核查使用制度，在行政管理、项目招标投标和公共资源交易中必须设立信用信息查询环节，将市场主体的信用状况和信用承诺作为决策的重要参考。在涉及公共利益的重大经济活动中，全面推行第三方企业综合信用等级评价制度。

（十八）健全激励惩戒机制。完善诚信典型“红名单”和严重失信“黑名单”管理制度，依托信用平台实现各行业领域“红黑名单”信息共享，建立跨地区、跨部门、跨领域的信用协同监管和联合奖惩机制，尤其要加大对严重违法失信主体的曝光和惩戒力度。

（十九）完善信用信息管理。各部门要将社会信用体系建设摆在突出位置，完善落实各项信用管理制度。对未按规定公开、共享、使用信用信息的部门定期给予通报；对因此造成不良后果的，严肃追究领导责任。

七、加大整顿查处力度，强化工程建设监管

（二十）加强组织领导。各部门要高度重视，把整顿和规范市场环境、加强工程建设领域质量监管作为日常工作抓紧抓好。建立整顿和规范市场环境工作联席会议制度，及时召开专题会议，研究解决突出问题，落实整改措施，完善相关体制机制，持续加强市场环境和工程建设监管。

（二十一）强化审计稽查。各部门各单位明确工程质量监管责任，确保责任落实到人，加强对重大工程的检查力度，对发现的违规违法行为严肃查处，确保工程质量和资金安全，维护国家和社会公共利益。

（二十二）加大查处力度。进一步深化和拓展市场秩序整治工作，县住建局组织开展建设工程质量安全检查专项行动，县市场监管局组织开展产品检验检测机构规范治理专项行动，严肃查处工程建设领域的违法违纪问题，严厉打击生产经营销售假冒伪劣产品等破坏市场秩序的行为，强化责任追究，着力营造公平、公正、高效、透明的营商环境。
