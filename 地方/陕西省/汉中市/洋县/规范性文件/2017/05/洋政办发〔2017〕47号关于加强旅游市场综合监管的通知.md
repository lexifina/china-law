# 洋政办发〔2017〕47号关于加强旅游市场综合监管的通知

洋政办发〔2017〕47号

洋县人民政府办公室

关于加强旅游市场综合监管的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构：

为贯彻落实中省市关于加强旅游市场综合监管的文件精神，加快建立责权明确、执法有力、行为规范、保障有效的旅游市场综合监管机制，营造放心舒心的旅游消费环境，有效保障旅游和旅游经营者合法权益，全面提升旅游服务质量，促进我县全域旅游发展。经县政府同意，现就推进全县旅游市场综合监管有关事项通知如下：

一、健全旅游市场综合监管机制

建立由县文旅局牵头、各有关部门按照职能分工具体负责的旅游市场综合监管工作机制，统筹旅游市场综合监管的指导、协调和监督等工作。由县文旅局召集相关部门不定期召开联席会议，协调重大联合执法行动，通报旅游综合执法和旅游投诉处理情况，研究解决综合监管中的重要问题及事项。公安、市场监管、交通和旅游等部门，要加强旅游市场综合监管工作的联络、沟通，逐步建立统一、规范、高效的旅游综合执法体制和行之有效的综合监管机制，加大联合执法、协调监管的力度。各镇办、各有关部门要按照“属地管理、部门联动、行业自律、各司其职、齐抓共管”的原则，认真履行旅游市场监管责任，建立健全本辖区、本部门旅游市场监管工作制度，制定旅游市场监管工作年度计划，要明确具体人员，负责本单位的工作联络，抓好相关旅游市场监管常规执法检查，并配合旅游部门做好其他相关工作，共同引导旅游企业依法诚信经营，优质规范服务，凝聚合力，全面提升我县旅游市场综合监管效率和整治效果。加快推进旅游发展委员会的成立，设立旅游稽查大队、旅游法庭、旅游派出所、旅游工商所的成立，逐步建立旅游执法“1+3”模式。

二、夯实相关部门监管责任

县文旅局：规范旅游市场秩序、监督管理服务质量、维护旅游消费者和经营者合法权益的责任；负责牵头组织对旅游市场秩序的整治工作；依照《中华人民共和国旅游法》等相关法律法规，负责对旅行社、导游等旅游经营企业和旅游从业人员违法违规经营行为的查处和投诉处理；负责对“不合理低价游”、强迫和变相强迫消费、违反旅游合同等违法违规行为的查处；联合或配合相关部门查处“黑社”“黑导”“黑车”“黑店”等非法经营行为；负责对涉及其他职能部门职责的投诉及案件进行转办等；开展安全检查行动，确保文物景点安全和游客安全，特别是做好重大节日前的各种应急预案和演练等。

县编办：协调解决旅游市场综合监管工作方面的机构改革和机构编制管理等工作。

县公安局：依法严厉打击在我县旅游景区、县运司、汉运司等交通站点侵害旅游者权益的违法犯罪团伙，及时查处强迫消费、敲诈勒索等违法犯罪行为；配合文旅、市场监管、交通运输等部门对旅游违法行为进行联合查处等。

县市场监管局：依法监管旅游企业违反工商登记法律法规的行为；依法查处旅游市场中的虚假广告、误导消费的宣传、销售假冒伪劣商品、利用合同格式条款侵害消费者合法权益、垄断行为（价格垄断行为除外）、商业贿赂等不正当竞争行为及其他违法违规行为。依法对旅游场所大型游乐设施、索道、场（厂）内专用机动车辆等特种设备实施安全监察，对涉及特种设备安全的投诉举报及违法违规行为进行调查处理，负责规范和监督涉旅商品质量和市场计量行为等。协调有关成员单位，针对旅游购物场所、旅游纪念品市场侵权假冒问题，加大市场监管力度，维护消费者合法权益等。依法承担对旅游景区（点）、旅游密集场所的餐饮服务和食品安全监督管理及投诉处理等工作。

县交通局：依法查处旅游客运市场的违法违规行为；负责道路、水路运输市场监管；负责对管养公路沿线范围内依法设置的景区、景点指示牌被遮挡的投诉处理；联合公安、旅游部门打击旅游“黑车”非法经营行为等。

县文广局：负责对旅游演出、娱乐场所文化经营活动等方面的投诉处理和案件查处等。充分发挥新闻媒体宣传作用，开展《中华人民共和国旅游法》、《陕西省旅游条例》、《中国公民国内旅游文明公约》、《中国公民出境旅游文明行为指南》等旅游法律法规的宣传教育，加强正面消费和依法维权的宣传报道，普及文明旅游知识，引导游客理性消费，提升游客素质等。

县国税局、地税局：依法承担法律法规规定的税、费征收管理责任，力争税款应收尽收；依照法定职权和程序严厉查处旅游市场偷逃税款、虚开发票等违法行为，涉嫌犯罪的依法移送司法机关处理等。

县物价局：负责旅游市场价格行为监管，严厉查处旅游行业不执行政府定价和政府指导价、不按规定明码标价、欺诈宰客、低价倾销，景区门票捆绑销售、违规收费等问题。充分发挥“12358”价格监管平台作用，依法受理游客对价格违法行为的投诉举报，切实保护消费者合法权益，整顿规范旅游市场价格秩序等。

县卫计局：依法对宾馆、酒店、饭店、招待所等住宿经营单位的卫生许可情况、从业人员健康体检、卫生知识培训及公共用品采购、贮存、索证索票等情况进行监督检查，对违反《公共场所卫生管理条例》和《公共场所卫生管理条例实施细则》的行为进行处罚，处理卫生管理工作投诉等。

县民宗局：依法对风景名胜区内宗教活动场所进行管理；对宗教教职人员诱导游客高消费行为进行监督和处理；联合公安局对宗教活动场所内假冒宗教教职人员骗取游客钱财等行为进行打击处理等。

县住建局：按照《风景名胜区条例》有关要求，认真编制风景名胜区总体规划，合理确定旅游景区最大承载量；指导风景名胜区管理机构制定流量控制方案并监督实施；负责风景名胜区内的安全管理工作，会同相关部门做好旅游市场综合监管和投诉处理等。负责对政府授权实行城市化管理的重点景区（点）周边及沿线乱搭乱建、乱停乱放，旅游景区周边环境卫生等方面的市场监管和投诉处理等。

县教体局：按照职权，依法对旅游景区经营高危性体育项目进行许可、监督和管理等。

县安监局：充分发挥安全综合协调职能作用，依法组织开展旅游安全生产事故调查处理等工作。

县网管办：依法对电信和互联网等信息通信服务实行监管，承担互联网行业管理责任；督促电信企业和旅游互联网企业落实网络与信息安全管理责任，配合开展在线旅游网络环境和信息治理，配合处理网上虚假旅游广告信息等。

三、提升综合监管水平

（一）加强旅游法律法规宣传教育。各镇办、各部门要加强《中华人民共和国旅游法》、《中华人民共和国行政处罚法》、《陕西省旅游条例》等法律法规普法宣传教育，结合“5·19中国旅游日”、“9·27世界旅游日”、“12·4法制宣传日”，积极开展旅游法规宣传活动，使旅游经营者、从业人员准确把握旅游相关法律法规的内容，守法经营、依法执业。加强执法人员培训，做到主体合法、内容合法、程序合法，文明执法。要提醒广大旅游者理性消费、文明出游。在全社会营造学法、懂法、知法、守法、用法的浓厚氛围。

（二）强化旅游执法检查。由县文旅局牵头组织，联合相关部门在旅游黄金周、小长假、寒暑假等旅游高峰时段进行旅游市场联合执法检查，对影响重大的案件及时启动综合执法。各有关部门根据职责分别开展旅游市场的日常监管和执法。在日常监管、联合检查、综合执法中以及在处理举报、投诉时，发现违反法律规定行为的，应当在法定时限内作出处理。对不属于本部门职责范围的事项，应当及时书面通知并移交有关部门查处。各相关部门要将涉旅案件办理结果，按季度向县文旅局进行书面反馈，内容包括涉旅案件的时间、地点、单位和人员、案件经过、处理依据及处理结果等。

（三）建立旅游投诉联合处理机制。充分利用全国“12301”平台和现有的旅游投诉渠道，建立旅游投诉联合处理机制。实行首接负责制，部门在首次接到各类旅游投诉和案件后，要立即立案，不得拒接、推诿。属于本部门职责的，及时处理；涉及其他部门的，及时移交有关部门处理，并告知投诉者。旅游投诉案件责任部门应当在法定时限内完成投诉处理。

（四）大力推动旅游市场监管标准化。把标准化作为旅游市场综合监管的重要手段，通过标准化提升行业管理服务水平。大力推行旅游景区A级标准、旅游饭店星级标准、《导游领队引导文明旅游规范》等国家标准和行业标准，引导、鼓励有关企业参加景区A级评定、饭店星级评定、旅行社等级评定，实施旅游标准化管理与旅游市场准入、退出相结合的制度，严格标准的执行和管理。加强A级景区、星级饭店等涉旅市场主体的检查，对不符合标准的坚决取消或降低其等级资格。

（五）开展旅游市场监管随机抽查。各镇办、各部门要在职责范围内开展涉及旅游的市场检查，特别要在旅游旺季、节假日前、寒暑假期间开展旅游市场检查。县文旅局要会同相关部门制定旅游市场随机抽样工作方案，适时开展旅游市场随机抽查，引导涉旅企业自觉守法。

（六）建立健全旅游诚信体系。建立旅游行业失信惩戒制度和旅游信用信息公示制度，将旅游经营服务不良信息记录和旅游行政主管部门对旅游企业作出的行政许可准予、变更和行政处罚信息在企业信用信息公示系统上公示，定期公布违法违规旅游经营者和旅游从业人员经营服务不良信息记录。

（七）发挥社会公众的监督作用。鼓励社会各界对旅游市场进行监督，积极提供各类违法违规行为线索。开展旅游志愿服务，提醒旅游者遵守文明旅游行为公约和行为指南，自觉抵制“不合理低价游”。充分发挥旅游服务质量社会监督员监督作用，定期组织旅游服务质量社会监督员实地进行监督活动。重视媒体的舆论监督，支持媒体曝光扰乱旅游市场秩序的典型事件。

四、提高监管保障能力

（一）加强基础保障。做好旅游执法经费保障工作。积极利用旅游大数据，开展旅游市场舆情监测分析，统计分析旅游投诉举报案件数据，为做好市场综合监管提供依据。

（二）强化人员培训。各镇办、各部门要明确负责旅游市场秩序综合监管的部门及人员，加强业务培训和执法培训，及时动态更新。所有旅游市场综合执法人员必须经培训取得行政执法证后方可上岗。

（三）加强考核问责。将旅游市场秩序整治和服务质量提升工作纳入政府质量工作考核。建立涉旅重大处罚决定合法性审查机制，进一步细化、量化行政裁量标准，合理规范裁量种类、幅度。对影响旅游市场秩序的重大事件要进行督办问责。建立旅游市场综合监管过程记录制度，对接到旅游投诉举报查处不及时、不依法对旅游违法行为实施处罚的，对涉嫌犯罪案件不移送以及在履行监督管理职责中滥用职权、玩忽职守、徇私舞弊的，要依法依纪追究有关单位及人员的责任；构成犯罪的，依法追究刑事责任。
