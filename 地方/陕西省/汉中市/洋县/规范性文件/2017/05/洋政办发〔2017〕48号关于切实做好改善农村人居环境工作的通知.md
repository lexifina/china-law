# 洋政办发〔2017〕48号关于切实做好改善农村人居环境工作的通知

洋政办发〔2017〕48号

洋县人民政府办公室

关于切实做好改善农村人居环境工作的

通      知

各镇人民政府、街道办事处，县政府各工作部门、直属机构、市管单位：

为认真贯彻落实《陕西省人民政府关于加快全省改善农村人居环境工作的意见》（陕政发〔2016〕18号），《陕西省人民政府办公厅关于印发<陕西省改善农村人居环境工作考核办法（试行）>的通知》（陕政办发〔2016〕106号）以及《汉中市人民政府办公室关于切实做好改善农村人居环境工作的通知》（汉政办发〔2017〕7号）文件要求，结合实际，现就做好我县改善农村人居环境工作有关事项通知如下：

一、 加强组织领导，建立联席会议制度

建立县级改善农村人居环境工作联席会议制度。县政府分管副县长担任召集人，各镇办、农工部、发改局、财政局、国土局、住建局、交通局、农业局、林业局、水利局、卫计局、环保局、文旅局、电力局等部门为成员单位。联席会议办公室设在住建局，成员单位要指定专职人员负责综合协调、督查考核等日常工作。各镇、办要形成明确的推进机制，统筹安排年度任务，实行目标责任管理。

二、 明确目标任务，扎实推进各项工作

各成员单位为牵头部门，要按照洋县改善农村人居环境工作任务分解表（详见附件1），把改善农村人居环境工作纳入本部门年度工作任务，一并安排部署，并加强对各镇、办的指导。各镇、办为具体实施单位，要依据洋县改善农村人居环境工作任务分解表中的重点工作，制定推进改善农村人居环境建设任务实施方案和年度计划，并报联席会议办公室备案。同时依据《洋县人民政府办公室关于印发洋县农村垃圾治理专项行动实施方案的通知》（洋政办发〔2017〕36号）文件，做好今年省上开展的县区垃圾治理验收迎检准备工作。联席会议办公室将结合市上下达我县的年度目标任务，分解下达各镇、办年度目标任务。

三、 多措并举，进一步加大资金投入

农村环境综合整治工作量大面广，资金需求量大，各镇、办要建立多元化的投入机制，按照《国务院办公厅关于创新农村基础设施投融资体制机制的指导意见》（国办发〔2017〕17号）精神，加大财政投入，整合涉农资金，调动农民积极性，形成政府主导，村民共建的工作机制。大胆探索市场化运作模式，拓宽投融资渠道，组织和引导社会参与农村环境综合整治工作。

四、 强化监督，建立上下联动的考核机制

县改善农村人居环境工作联席会议办公室将按照省、市文件要求，组织开展对各镇、办的考核和通报，并向市联席会议办公室报送我县工作情况。

各镇人民政府、街道办事处要确定专职人员填报季度统计报表。每季度末月18日前将“      （镇人民政府、街道办事处）改善农村人居环境季度统计表”（详见附件2）和“      （镇人民政府、街道办事处）农村人居环境信息系统季进度统计表”（详见附件3）经单位负责人签字（加盖公章）后，以纸质和电子版两种形式报县联席会议办公室，各镇、办不得随意调整和变更报表样式。季度统计报表填报情况将作为各镇、办改善农村人居环境工作年度考核的重要依据。

各镇、办专职人员要在村镇建设管理平台（http://czjs.mohurd.gov.cn/）全国农村人居环境信息系统中认真核对各行政村的基本情况和数据，以确保填报数据的全面、真实、准确性，并对系统中的数据及时予以更新，确保年底顺利完成数据录入工作。

各镇、办每年6月18日前和12月10日前向县联席会议办公室报送半年和年度工作任务完成情况。县联席会议办公室结合各镇、办季度统计报表和任务完成情况，对各镇、办工作进行综合评定，提出考核等次初步意见并进行排名。考核初步意见和排名情况征求县联席会议各成员单位意见后，报县联席会议审定通报。

请各镇、办及联席会议成员单位将“改善农村人居环境（专职）工作联系人及电话”（详见附件4）于5月5日前报送县联席会议办公室（联系电话：8221234）。
