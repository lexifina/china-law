# 洋政办发〔2017〕50号关于进一步加强黄标车淘汰治理工作的通知

洋政办发[2017]50号

洋县人民政府办公室

关于进一步加强黄标车淘汰治理工作的

通 知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为全面完成“黄标车”淘汰治理任务，切实改善空气质量，保障人民身体健康，按照省大气污染防治工作现场推进会议精神及汉中市人民政府办公室《关于进一步加强黄标车淘汰治理工作的通知》（汉政办发【2017】16）号有关要求，现就加强“黄标车”淘汰治理有关工作通知如下：

一、统一思想，提高认识

国务院高度重视大气污染防治工作。“黄标车”淘汰治理是减少移动源污染排放、保护大气环境的重要举措，也是大气污染防治工作的重要内容。目前，我县仍有需要淘汰的“黄标车”133辆。根据省市要求及“黄标车”淘汰补助政策的截止时间规定，2017年5月底前应全部淘汰拆解完毕（各镇办任务详见附件），时间紧迫，任务艰巨。各镇办相关各部门要从讲政治的高度充分认识“黄标车”淘汰治理工作的重要性和紧迫性，切实将“黄标车”淘汰治理作为近期的重点工作来抓，认真研究，协同配合，确保各项工作任务圆满完成。

二、细化任务，落实责任

各镇办对本行政区域内治理淘汰“黄标车”负总责，要全面摸清辖区内“黄标车”底数，建立明细台账，掌握具体情况，找准问题所在。要结合实际，研究制定有针对性的工作措施，细化目标任务，层层分解落实，夯实工作责任，切实做到责任到人，严禁“不见车、不见人”。要充分发挥各镇办、村、组干部“情况熟，人情熟”的优势，安排专人具体负责查找本辖区内的“黄标车”，认真登记造册。县交警大队各中队及公安局派出所要积极配合各镇办工作，及时将车辆移送至集中停放点，联系报废公司进行拆解。同时加强政策宣讲和沟通，提高车主的知晓率和主动配合性，按时依规按原来的程序做好淘汰处置。

三、深入宣传，营造氛围

各镇办及相关部门要充分利用广播、电视、网络等各类媒体，广泛宣传“黄标车”高污染、高排放的危害性和治理淘汰的相关政策，争取广大车主的理解、支持和配合，增强群众环保意识和淘汰“黄标车”的自觉性。同时要加大对财政补贴激励政策的宣传力度，引导车主自觉淘汰“黄标车”。

四、加强领导，健全机制

为切实加强对“黄标车”淘汰治理工作的领导，县上成立淘汰治理工作领导小组，由县政府分管副县长任组长，政府办、公安局、环保局、财政局、交通局、市监局主要领导任副组长，领导小组下设办公室，办公室设在县交警大队，县公安局交警大队大队长任办公室主任，负责办公室日常工作。各镇办也要结合实际，成立相应的领导小组，加强组织领导，强化工作措施，确保各项工作有序开展。

五、强化监督，严格问责

各镇办要在每周五12时前将“黄标车”淘汰治理进展情况报县“黄标车”淘汰治理办公室，县上将定期对各镇办任务完成情况进行督导检查，对未按要求、按进度推进工作的，在全县范围内进行通报。检查中发现伪造数据的，将追究有关人员责任。
