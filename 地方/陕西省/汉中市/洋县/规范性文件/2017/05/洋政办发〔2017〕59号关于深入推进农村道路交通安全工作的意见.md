# 洋政办发〔2017〕59号关于深入推进农村道路交通安全工作的意见

洋政办发〔2017〕59号

洋县人民政府办公室

关于深入推进农村道路交通安全工作的意见

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为切实加强农村道路交通安全工作，有效预防和减少农村道路交通事故，促进全县道路安全形势持续好转，按照陕西省人民政府办公厅《关于加强全省农村道路交通安全工作的意见》（陕政办发〔2016〕73号）、汉中市人民政府办公室《关于深入推进全市农村道路交通安全工作的意见》（汉政办发〔2016〕78号）文件精神，经县政府同意，现提出以下意见：

一、强化农村道路交通安全组织领导。全县各镇（办事处）具体承担农村道路交通安全工作的属地管理责任。要从全面建成小康社会、改善和保障民生的高度，充分认识农村道路交通安全工作的重要性，切实增强工作责任感和紧迫感，把农村道路交通安全工作与党建工作、脱贫攻坚、促进区域协调发展紧密结合起来，因地制宜，创新思路，找准差距，补齐短板，不断夯实农村道路交通安全基础工作，打造平安畅通的农村道路交通安全工作环境。（各镇、办事处负责）

二 、健全农村道路交通安全管理体系。各镇（办事处）交安办要扎实抓好本辖区农村道路交通安全工作，镇长、办事处主任任交安办主任，由主抓工作的镇（办事处）负责人兼任交安办副主任，各村（社区）确定专（兼）职交通安全员，履行辖区内农村道路交通安全管理职责 。较大行政村（社区）设立交通安全劝导站，由村（社区）两委主要负责人担任站长，组织开展辖区内交通安全劝导员工作。劝导站本着“因地制宜、规模适度、简单实用，满足劝导员日常工作需要，充分利用现有设施”的原则设置。2017年9月底前，全县所有行政村及农村社区实现农村道路交通安全劝导站实现全覆盖，其中：2015年县上确定的洋州办、戚氏办、龙亭镇、谢村镇、磨子桥5个重点镇（办事处）除各村设立二、三级劝导站外，必须保证2处一级劝导站，其余13个镇（办事处）在设立二、三级劝导站的基础上，务必建设1处一级交通安全劝导站。5个重点镇（办事处）由县财政仍然按照每年5万元保障工作经费，其余13个镇（办事处）由县财政按照每年2.5万元工作经费给予保障，确保县、镇、村三级农村道路交通安全管理组织自上而下体系健全、工作顺畅、落实有力。（各镇政府、办事处负责，县财政局、县交安委办公室配合）

三、加强劝导员队伍和监管队伍建设。交警大队要加强对镇交通安全员、村劝导员的业务培训和指导，交通安全员和劝导员要按照职责开展工作。县政府成立由公安、交通、安监、农业部门联合组成的县级监管队伍；各镇政府（办事处）牵头，镇交安办主抓，成立由交警中队、派出所、安监站、农机站、运管站联合组成的镇监管队伍，全面开展农村道路交通安全管理联合执法，形成长效工作机制，维护道路交通秩序。（各镇、办事处负责，辖区派出所、交警中队、安监站、农机站、运管站配合）

四、提高农村地区警务效能。县交安委要按照《公安部关于农村公安派出所参与道路交通安全工作的通知》（公通字〔2007〕4号）、省政府《关于加强全省农村道路交通安全工作的意见》（陕政办发〔2016〕73号）、市政府《关于深入推进全市农村道路交通安全工作的意见》（汉政办发〔2016〕78号）文件精神，加强农村公安派出所与基层交警中队的协调配合，在未设置交警中队的镇派出所，加挂交警中队牌子，由县公安局牵头，交警大队赋予相关派出所农村道路交通管理工作职责，强化农村道路交通安全管控，实现农村地区警务效能的最大化。（县公安局负责）

五、加快推进农村道路生命防护工程建设。各镇（办事处）要按照“先重后轻、先急后缓”和“控制增量、减少存量”的原则，加快推进农村道路生命防护工程建设，先行完成农村道路客车、校车通行路段，旅游线路和临水、临崖路段的生命防护工程建设，不断改善农村道路通行条件。按照全省农村道路生命防护工程建设工作要求，力争到2025年底全面完成全县农村道路隐患路段的治理任务。农村道路管理局要联合安监、财政、交警等部门统筹安排治理计划，生命防护工程治理和建设完成后统一组织验收。对今后新建、改建、扩建的农村公路项目，要充分考虑道路安全设施建设，对公安交警部门提出的交通事故多发频发路段，切实做到同时设计、同时施工、同时验收，避免形成新的安全隐患。县财政要加大农村道路安全改造力度和交通安全设施投入力度，确保按期完成治理任务。（农管局负责，县财政局、安监局、各镇、办事处、交警大队配合）

六、不断提高农村道路交通管理信息化水平。各镇（办事处）交安办要在全国农村道路交通安全管理信息系统试点结束后，逐步推广应用农村道路交通安全管理信息系统 ，实现对农村重点车辆、重点驾驶人、重点路段的动态采集、管理、预警和跟踪考核。公安交管部门要将公路交通安全防控体系建设向农村道路逐步推进和延伸，整合各方资源，建设县、镇、村三级联动、互联互通的全县农村道路网格化勤务指挥调度系统。要充分运用“天眼”工程等公安信息化建设契机，把劝导站的信息化建设列入其中，统一安排部署，整合资源，避免重复建设。实现对农村劝导站、农村重点路段、路面勤务等智能化、可视化、扁平化的指挥调度，逐步构建人防、物防、技防相结合的农村道路交通安全防控体系，提高农村道路交通信息化管理水平。（县公安局和各镇、办事处负责，县财政局、县交安委办公室配合）

七、切实加强农村交通安全宣传教育。各镇（办事处）、各部门、各单位要按照法定职责，认真履行交通安全宣传义务，将农村交通安全宣传教育作为加强农村道路交通安全工作的一项重要措施抓紧抓好。要充分利用传统手段和现代媒体，结合农村群众特点，深入广泛开展形式多样、群众喜闻乐见的交通安全宣传活动，不断增强农村群众的交通安全意识。要不断创新农村交通安全宣传形式，强化农村交通安全服务，促进农村交通安全宣传教育工作的常态化、制度化。(各镇、办事处和交警大队负责)

八、积极推进农村客运事业发展。县交通局要按照“建、管、养、运”一体化发展思路，统筹制定农村客运线路发展规划，要将道路交通安全作为首要因素，建立公安交警部门主动参与到农村客运班线审核工作的机制，全面落实国家对农村客运道路的现行税收优惠政策和油价补贴政策，大力推进农村客运公司化、标准化经营，全面提高建制村通客车覆盖面，有效解决农村群众出行难问题，从源头上杜绝农村三轮汽车、低速载货汽车和拖拉机违法载人等交通违法行为。（县交通局负责，各镇、办事处配合）

九、严厉整治农村客货运市场秩序。加强农村客货运市场的整顿和管理，在县政府统一领导下，定期组织运管、安监 、公安等部门，开展农村客货运市场集中整治、交通安全专项整治等活动，严查违法超限超载运输车辆，严厉整治农村客运无牌无证、超员超速、酒后驾驶、非法载客、超范围经营、随意变更线路等扰乱客运市场秩序和交通安全违法违规行为，积极营造农村客货运规范、良好的市场秩序。（县交警大队牵头，县交通局、安监局、农村道路管理局配合）

十、完善农村道路交通安全考评体系。考核办和县交安委办公室要根据全县道路交通安全工作考核评价办法，结合实际和工作需要，制定出具体的实施办法，将农村道路交通安全工作作为安全生产考核和社会治安综合治理考核重要内容，督促农村道路交通安全工作责任的落实。（县考核办负责，县安监局、交警大队配合）

十一、严格责任追究制度。要建立严格的问责机制，对未按时效完成生命防护工程建设、劝导站建设、网格化信息系统建设任务或不履行道路交通安全职责的单位和个人，要按照“谁主管、谁负责”的原则，结合安监局、交通局、公安局检查督促情况，对于开展本项工作不力的，由县政府督查室按期进行通报，对落实不力的责令限期整改；对因责任不实、措施不到位导致重特大道路交通事故的，由监察及司法机关依法依规追究有关单位和工作人员责任。（县安监局牵头，交通局、公安局配合）

洋县人民政府办公室

2017年5月11日
