# 洋政办发〔2017〕61号关于印发洋县易地扶贫搬迁安置实施办法的通知

洋政办发〔2017〕61号

洋县人民政府办公室

关于印发洋县易地扶贫搬迁安置实施办法的

通 知

各镇人民政府、街道办事处，县政府有关工作部门：

《洋县易地扶贫搬迁安置实施办法》已经县移民（脱贫）搬迁工作领导小组2017第一次会议审议通过，现印发给你们，请认真贯彻执行。

洋县人民政府办公室

2017年5月15日

洋县易地扶贫搬迁安置实施办法

根据市政府办公室《关于印发汉中市移民（脱贫）搬迁建房到人补助办法等5个办法的通知》（汉政办发[2017]4号）及全省脱贫攻坚新部署新政策精神，结合我县易地扶贫搬迁实际情况，特制订本实施办法。

一、易地扶贫搬迁对象以全县2017年5月份精准识别的建档立卡贫困户中标注有搬迁意愿的贫困户为准。

二、易地扶贫搬迁对象建房补助标准：

1、集中安置：建房补助每人2.5万元。

2、分散安置：建房补助每人1.5万元。

3、易地扶贫搬迁对象建房面积人均控制在25㎡以内；人均建房出资不得超过2500元，户建房出资额不得超过1万元。

4、易地扶贫搬迁对象中的特困户实行免费安置，人均建房面积严格控制在25㎡以内。

5、对每人2万元的基础和公共服务设施补助资金由县上统筹使用，主要用于小配套建设和安置点大配套难落实的项目及用于建立“建档立卡搬迁贫困户脱贫保障金”。

6、旧宅基地腾退补助：按人均1万元的标准，综合贫困户旧宅基地面积、房屋结构及房屋建筑面积等因素另行制定具体的差别补助标准。

三、易地扶贫搬迁对象申请李家村、磨子桥两个移民点安置的具体方案：

1、特困户：2—3人家庭安排60㎡户型；4人家庭安排80㎡—89㎡户型；5人以上（含5人）家庭安排90㎡--100㎡户型。实行“交钥匙”工程免费入住，公开摇号分房，不承担楼层差。残疾人家庭户优先安排在低楼层（限定肢残和眼残三级以上）。

2、一般贫困户：2—3人家庭安排60㎡的户型，其中2人家庭人均出资2500元，3人家庭人均出资1000元；4人家庭安排90㎡—100㎡的户型，人均出资2500元；5人家庭（含5人）安排100㎡以上的户型，户均出资10000元。公开摇号分房，凡摇号在6楼的贫困户，在出资额的基础上减免30%；摇号在5楼的贫困户，在出资额的基础上减免20%。残疾人家庭户优先安排在低楼层（限定肢残和眼残三级以上）。

3、为避免易地扶贫搬迁户因购房举债，暂不对扶贫搬迁户销售柴房、车库，暂不收大修基金。待贫困户脱贫后，根据贫困户意愿，按照标准销售柴房、车库，收取大修基金。若其不缴纳大修基金，则质保期以外的大修问题，由该户自行承担。

4、易地扶贫搬迁户家庭在安排住房面积时均不计算计生奖励人口。对易地扶贫搬迁户中的独生子女户按照每户5000元、双女户每户3000元的标准予以奖励。遵照汉政办发﹝2017﹞4号文件及市移民（脱贫）工作办公室的补充通知精神，结合我县实际，对于易地扶贫搬迁户中的独生子女户、双女户奖励政策从2016年元月开始执行；避灾生态搬迁户中独生子女、双女户奖励政策从2017年3月9日执行。具体奖励办法由县卫计局、财政局、移民（脱贫）搬迁办联合另行制定。

四、易地扶贫搬迁因受“双红线”限制，故不与“县城内商品房”结合安置，易地扶贫搬迁户不得购买商品房。

五、2016年（含2016年）以后的搬迁对象按本办法执行，由县移民（脱贫）搬迁工作办公室负责解释。原《洋县关于落实易地扶贫移民搬迁有关政策的实施办法》（洋政办发﹝2016﹞114号文件）同时废止。
