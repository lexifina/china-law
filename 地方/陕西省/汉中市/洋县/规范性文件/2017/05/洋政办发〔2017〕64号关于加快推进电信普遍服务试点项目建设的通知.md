# 洋政办发〔2017〕64号关于加快推进电信普遍服务试点项目建设的通知

洋政办发〔2017〕64号

洋县人民政府办公室

关于加快推进电信普遍服务试点项目建设的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

电信普遍服务试点是“宽带中国”的重要组成部分，是国家推动公共服务均等化、统筹区域经济协调发展、助力贫困地区精准扶贫工作的重要举措。汉中市于2016年被确定为国家第二批电信普遍服务试点城市，我县涉及全县各镇办154个村（包含54个已撤并村）的宽带升级和建设任务，为加快试点项目建设顺利实施，现就有关事项通知如下：

一、目标任务

电信普遍服务试点主要是支持农村及偏远地区未通宽带村开展光纤覆盖建设、已通宽带但接入速率未达到12Mbps的村进行升级改造，并保证六年网络通畅。根据项目安排，我县将完成94个未通宽带行政村及60个宽带升级行政村工程，所需建设资金由中央支持配套资金和中标单位自筹，县上不需另行筹集资金。此项目由陕西省通信管理局具体组织实施，陕西广电网络传媒(集团)股份有限公司中标实施，今年内全部建成并投入使用。

二、保障措施

（一）保障宽带基础设施用地。各镇办要对项目建设所需的通信机房、传输线路、建设用地等给予支持。属于集体用地需要征收的，应当按照中、省文件要求，拟订合理合法的补偿方案，依法办理征收手续。要协调农村地区通信、电力、广电等沿线管线杆路向试点项目建设开放共享，并协调行政村公共场所提供宽带设备需要使用的场地资源等。

（二）保障建设用电供给。电力部门要加大对通信基础设施供电保障力度，对用电报装、线路租挂、电力抢修等建立保障机制，缩短用电的开户和引入的审批时限；要规范用电单位的二次转供电收费标准，特别是在农村宽带工程中进行电费优惠，减免市电引入费，降低能耗成本。

（三）将宽带基础设施纳入规划。各镇办要将项目建设中所需的通信管道、杆路、供配电等通信基础设施建设纳入城乡建设规划、土地利用总体规划，与水、电、气、路建设维护统筹规划，同时做好农村信息化发展规划与实施，充分发挥光网宽带的经济效益和社会效益。

（四）加强对已建通信设施的保护。对破坏通信设施、阻挠通信建设的行为，公安机关要从速、从严受理查处。要做好相关法律知识宣传活动，保证项目建设的通信基础设施稳定良好运行。

三、工作要求

（一）高度重视，加强组织领导。各镇办、各有关部门要高度重视电信普遍服务试点工作，进一步强化大局意识、责任意识、担当意识，把项目建设作为一项重要的民生工程、脱贫工程，切实抓好落实。各镇办要成立工作机构，明确目标，落实责任，积极配合中标单位施工，确保本辖区试点工作顺利实施。

（二）上下联动，密切协作配合。在县电信普遍服务试点工作领导小组领导下，由县政府信息中心负责日常工作，加强与省、市协调衔接。各成员单位结合部门职责，对项目实施过程中涉及的具体事项按照有关政策，依法予以协调解决。各镇办要广泛动员村组力量，加强教育引导，依法保护通信设施，营造良好的建设环境。

（三）严把质量，落实共建共享。县广电网络公司要认真履行协议，严格按照项目要求，认真做好规划设计，落实相关技术标准，严把工程质量关，加快施工进度，优质高效地完成项目建设任务。其他网络运营商也要按照“共建、共享、共赢”的原则，发挥各自优势，共同配合、齐心协力做好全县的电信普遍服务试点工作。

（四）加强督查，确保高效完成。各镇办要强化督促检查，实行目标管理，确保试点项目建设工作整体顺利推进。县政府将项目实施作为重点工作进行督查，对督查中发现政策落实不到位、故意拖沓延误、工作不力的镇办和部门将予以通报，并追究有关部门责任人的责任。
