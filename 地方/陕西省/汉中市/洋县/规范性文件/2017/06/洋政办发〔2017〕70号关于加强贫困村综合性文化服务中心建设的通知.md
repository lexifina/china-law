# 洋政办发〔2017〕70号关于加强贫困村综合性文化服务中心建设的通知

洋政办发〔2017〕70号

洋县人民政府办公室

关于加强贫困村综合性文化服务中心建设的

通 知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

村级综合性文化服务中心建设是整合基层文化资源，加强文化设施达标，保障群众基本文化权益的重要举措。2016年，县政府印发了《洋县基层综合性文化服务中心建设工作方案的通知》(洋政办发〔2016〕95号)。但从年底考核结果来看（以2016年下达计划为准），2016年20个脱贫的村中仅有16个村勉强达标，仍有4个村不达标。为确保全县贫困村综合性文化服务中心建设高效、节俭、实用、达标，现就建设有关事宜通知如下：

一、增强政治敏锐性，层层夯实政治责任

脱贫攻坚是当前全党极为严肃、极其重大的政治任务。扶贫先扶志、扶志必扶智，文化建设是文化增智的关键行作，近年来，镇（办）、村因地制宜，虽然在基层文化基础设施建设上做了大量工作，但距省、市基层综合性文化服务中心建设总体要求仍有较大差距。因此，各镇（办）要把思想和行动统一到中省市部署和要求上来，切实把脱贫攻坚政治责任落到实处，克难攻坚、主动作为，切实发挥文化广电部门在脱贫攻坚中的重要作用，为全县脱贫攻坚工作做出积极贡献。

二、总体目标

贫困村综合性文化服务中心建设要与美丽乡村建设、老人院建设、城镇化建设紧密结合。到2018年底，全县110个贫困村全部建成集宣传文化、党员教育、科学普及、法制教育、文体健身等功能于一体，资源充足、设备齐全、服务规范、保障有力、群众满意度较高的基层综合性文化服务中心全面实现公共服务资源的共建共享，充分满足基层群众多层次、多花样的基本公共服务需求。因此，2016年通过验收受到奖补的贫困村要对照建设标准对文化建设进行完善，未达标的磨桥镇沙溪村和八一村、黄安镇蒙渡村、黄家营镇庙坝村要加紧建设，并纳入2017年考核验收。2017年集中建设计划达标的41个贫困村，要抓紧建设，争取在10月底前建成，11月集中验收。2018年脱贫的49个村要早安排、早动手，今年能建设完成的将纳入今年考核验收一并奖补。

三、建设内容及标准

基础设施条件较好的贫困村其综合性文化服务中心建设标准依据《汉中市基层综合性文化服务中心建设标准》（洋政办发〔2016〕95号文件附件），一般的村原则要求文体广场面积不低于600平方米，建设一个简易舞台（10米×5米×0.8米），基本功能空间包括书报刊阅览室（农家书屋）、娱乐活动室或室内体育健身室、文化信息共享工程服务点或公共电子阅览室、多功能活动厅或培训教室、展览展示室等；文体广场安装路径健身器材，建一个标准篮球场、配备乒乓球台，并配建文化墙，设置阅报栏等，组建一支有地域特色的文艺演出队伍。

四、组织领导及保障机制

各镇（办）要把贫困村综合性文化服务中心建设列入脱贫攻坚工作议事议程，并成立专门机构具体指导、督查文化服务中心建设工作。县文化广电局除做好日常检查、指导外，还应做好相关项目对接申报工作。县政府将把贫困村综合性文化服务中心建设纳入年终脱贫工作考核。为了保障贫困村综合性文化服务中心的建设经费，首先要按比例在贫困村基础设施建设专项经费中列支文化建设有关费用，市、县将按考核情况对建设达标的村进行奖补；其次，统筹使用相关部门和扶贫开发资金，支持贫困村综合性文化服务中心建设。在综合性文化服务中心功能设置上要整合资源，最大限度用好设施设备，使贫困村文化设施建设日趋完善，满足广大群众开展文化活动的设施需求，实现我县城乡群众的共同富裕，为我县经济社会不断进步作出新贡献。
