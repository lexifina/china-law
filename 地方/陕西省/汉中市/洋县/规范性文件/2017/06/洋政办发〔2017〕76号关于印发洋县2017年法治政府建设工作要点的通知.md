# 洋政办发〔2017〕76号关于印发洋县2017年法治政府建设工作要点的通知

洋政办发〔2017〕76号

洋县人民政府办公室

关于印发洋县2017年法治政府建设

工作要点的通知

各镇人民政府，街道办事处，县政府各工作部门、各直属机构:

《洋县2017年法治政府建设工作要点》已经县政府同意，现印发给你们，请认真贯彻执行。

洋县人民政府办公室

2017年6月5日

洋县2017年法治政府建设工作要点

为深入贯彻落实《法治政府建设实施纲要（2015-2020年）》（以下简称《纲要》）、《陕西省法治政府建设实施方案（2016-2020年）》（以下简称《方案》）和县委、县政府各项决策部署，加快推进法治政府建设，现结合洋县实际，提出2017年法治政府建设工作要点。

一、总体要求

全面贯彻落实党的十八届四中、五中、六中全会精神和习近平总书记系列重要讲话精神，以2020年全面建成法治政府为目标，紧紧围绕《纲要》和《方案》确定的工作任务，突出重点，落实责任，扎实做好依法行政各项工作，为全县追赶超越、建设六个洋县提供有力的法治保障。

二、主要任务

（一）依法全面履行政府职能

1.积极推进政府职能转变。继续依法取消、下放行政许可事项，禁止实施目录以外的行政许可项目。对行政审批实施全过程监督，取消不必要的与行政审批相关的各类年审、年检。加快推进“互联网+政务服务”体系建设,规范行政许可事项管理，做好网上办事平台建设前期准备。对行政许可中介服务事项清单进行动态管理。（县编办牵头，各镇办、法制办、信息中心、行政服务中心等按职责分工分别负责。）

2.推行权责清单和负面清单制度。做好市场准入负面清单制度试点工作，建立全县行政事业性收费和政府性基金目录清单，清单之外收费基金项目一律取消。推进各级政府事权规范化，加强公共服务事项清单、权力责任清单动态管理。（县编办牵头，各镇办、财政局、市场监管局、法制办按职责分工分别负责。）

3.加强市场监管。推进商事登记便利化，落实放宽企业住所、名称、经营范围登记条件优惠政策，实行简易退市制度，探索推进企业登记全程电子化。做好“双随机、一公开”配套建设，建立信息公示、防范化解风险等协同监管机制，强化事中事后监管，加大违法失信惩治力度。（市场监管局牵头，发改委、县编办按职责分工分别负责）

4.强化生态环境保护。强化生态环境保护巡查制度，推进环境监管体制改革，落实环境信息公开制度、环境影响评价制度和污染物排放总量控制制度。健全完善污水处理政策，推进环境污染第三方治理。（环保局牵头，各镇办、发改委、国土局、水利局、农业局、林业局、财政局按职责分工分别负责）

（二）完善依法行政制度体系

5.加强规范性文件监督管理。继续推进规范性文件“三统一”制度，坚持“逢文必审”，对公民、法人或者其他组织规范性文件提出异议审查的，要认真办理。组织开展规范性文件评估和清理工作，向社会公布清理结果，提高规范性文件制定质量和实施效果。（法制办牵头，各镇办、政府各有关部门按职责分工分别负责）

（三）推进行政决策法治化、民主化、科学化

6.落实重大行政决策程序。严格执行公众参与、专家论证、风险评估、合法性审查、集体讨论决定等法定程序，继续坚持各类政府会议纪要法律审查制度。健全纪检监察、组织、巡视、审计和行业监管等单位和部门的协作机制，建立重大行政决策责任追究制度和责任倒查制度落实。(各镇办、政府各有关部门、法制办按职责分工分别负责)

7.增强公众参与实效。事关经济社会发展全局和涉及群众切身利益的重大行政决策事项，与利害关系人充分沟通，并充分听取有关人大代表、政协委员、人民团体、基层组织、社会组织的意见。要加强公众互动平台建设，对社会关注度高的决策事项，应公开信息、解释说明，及时反馈意见采纳情况和理由。(政府办牵头，各镇办、政府各有关部门按职责分工分别负责)

8.积极发挥政府法律顾问作用。出台《洋县人民政府法律顾问工作规则》，做好法律顾问的聘任、管理和服务工作，畅通政府及部门领导与法律顾问的沟通渠道，充分发挥法律顾问在重大行政决策合法性审查、代理行政诉讼、处理疑难行政复议案件、提供法律咨询论证等方面的作用。加强各类行政性合同管理，各单位、部门起草签订的合同或协议均应由本单位、本部门法制机构或法律顾问先行法律审查，再提交县政府法制机构进行法律审查，坚决杜绝体外循环或直接报送县政府法制办审查。（法制办牵头，各镇办、政府各有关部门按职责分工分别负责）

（四）坚持严格规范公正文明执法

9.推进执法体制改革。根据事权和职能要求，合理配置执法力量。完善县镇办两级行政执法管理，加强统一领导和协调，推进行政执法重心下移。继续强化镇办政府职能，通过依法委托的方式赋予镇办部分行政执法权。（县编办牵头，各镇办、行政执法部门、法制办按职责分工分别负责）

10.完善行政执法程序和方式。严格落实重大行政执法决定法制审核制度和行政执法公示制度，行政执法部门严格执行本部门权责清单，公开部门执法依据、职责权限、实施机构、执法流程、监督方式等事项。在全县推行行政执法全过程记录制度，行政执法部门要加快配备记录仪、摄像机等执法设备。（法制办牵头，各镇办、财政局、行政执法部门按职责分工分别负责）

11.加强行政执法队伍监管。全面落实行政执法人员持证上岗和资格管理制度。2017年，对全县150余名行政执法人员进行换证培训，并对行政执法队伍进行一次严格筛查清理，不符合执法条件的人员，不得从事执法活动。（法制办牵头，政府各有关部门按职责分工分别负责）

12.推进规范行政裁量权工作。按照县政府《关于印发开展规范行政裁量权工作方案的通知》要求，2018年2月底前，县级行政执法部门要完成各类行政裁量基准的制定和公开工作。（法制办牵头，行政执法部门按职责分工分别负责）

（五）强化对行政权力的制约和监督

13.健全行政权力运行制约和监督体系。自觉接受党内监督、人大监督、民主监督、司法监督、社会监督和舆论监督。支持人民法院依据行政诉讼法受理和审理行政案件，落实行政机关负责人出庭应诉制度，尊重并执行人民法院的生效裁判，健全法院判决执行通报制度。积极配合支持检察机关开展公益诉讼试点工作。健全行政执法案卷评查、行政执法投诉举报、行政执法督办等制度。（监察局牵头，各镇办、法制办、政府各有关部门按职责分工分别负责）

14.全面推进政务公开。积极推进决策、执行、管理、服务、结果“五公开”，全面、详尽、准确公开权力清单、责任清单、公共服务事项清单。重点推进财政预决算、公共资源配置、重大建设项目批准和社会公益事业建设领域的政府信息公开。加强互联网政务信息数据服务平台和推动便民服务平台建设，充分利用政务微博、微信等新媒体，回应社会关切的问题。开展公民代表走进政府、大学生到政府机关见习等活动，提高政务公开的社会效益。（政府办牵头，各镇办、政府各有关部门按职责分工分别负责）

15.完善纠错问责机制。加大行政问责力度，对行政机关不积极主动履行行政复议工作职责，不履行行政复议决定的责任人进行问责。坚决纠正行政不作为、乱作为、慢作为，对“四风”问题突出、发生顶风违纪问题或者出现区域性、系统性腐败案件的单位要严格追责。（监察局牵头，各镇办、人社局、政府各有关部门按职责分工分别负责）

（六）依法预防和化解社会矛盾

16.健全依法预防和化解纠纷机制。落实社会救济救助制度和法律援助制度。依法强化危害食品药品安全、影响安全生产、损害生态环境、破坏网络安全、非法融资集资等重点问题治理，促进社会和谐稳定。贯彻《陕西省人民调解员管理服务办法》，完善人民调解、行政调解、司法调解的联动工作体系，引导当事人选择适当的解决途径。推行“阳光信访”模式，规范信访工作程序，属于人民法院受案范围的，告知当事人寻求司法救济。完善及时就地解决问题机制。（司法局牵头，各镇办、金融办、信访局、政府各有关部门按职责分工分别负责）

17.加强行政复议、行政应诉。规范行政复议案件审理程序，提高行政复议质量，增强行政复议公信力。加强行政复议机构建设，所需经费纳入本级政府财政预算。探索重大、疑难复议案件审理机制和行政复议应诉专家咨询机制。建立与人民法院的联络机制，做好行政应诉工作。（法制办牵头，各镇办、政府各有关部门按职责分工分别负责）

（七）全面提高政府工作人员法治思维和依法行政能力

18.继续开展集体学法活动。制定《2017年县政府领导集体学法安排意见》，并组织实施。建立公务员及行政执法人员法律培训制度，举办法治专题培训班，不断提高政府工作人员的法治思维和依法行政能力。(法制办牵头，各镇办、人社局、司法局、政府相关部门按职责分工分别负责)

19.加强法制机构和队伍建设。进一步加强政府法制机构力量，配齐配强政府法制机构领导和工作人员，各执法部门要设置法制科或明确承担法制工作的科室，加强法律业务能力培训，不断提高自身能力建设。（县编办、人社局牵头，各镇办、政府各有关部门按职责分工分别负责）

21.加强法制宣传工作。依照《汉中市“七五”普法规划》，认真落实谁执法谁普法制度。按照2017年政府法制宣传和理论研究计划，主动在《汉中政府法制》、汉中法制信息网等媒体投稿，大力宣传我县在法治政府建设中取得的成效。(法制办、司法局牵头，各镇办按职责分工分别负责)

三、工作要求

（一）提高思想认识。各镇办、各部门要充分认识推进依法行政、建设法治政府的重要性、紧迫性，切实增强责任感、使命感。各镇办、各部门主要负责人作为推进法治政府建设第一责任人，要将建设法治政府摆在工作全局的重要位置，有部署有安排，确保工作落实落细。

（二）制定计划措施。按照本要点要求，各镇办、各部门要对本地区、本部门的依法行政、法治政府建设情况进行一次全面回顾，结合实际制定年度要点或工作计划，加强贯彻落实的同时上报县政府法制办。

（三）加强督导考核。县政府法制办要加强综合协调和督促指导，及时跟踪本要点实施情况，通过开展执法检查、行政执法案卷评查等活动，推动工作有力开展。量化本年度依法治理目标任务，做好平时考评及年终考核工作，充分发挥考核的评价、导向、激励作用，确保完成法治政府建设任务。
