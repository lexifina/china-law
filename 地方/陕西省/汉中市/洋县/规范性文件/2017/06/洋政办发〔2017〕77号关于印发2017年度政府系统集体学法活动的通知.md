# 洋政办发〔2017〕77号关于印发2017年度政府系统集体学法活动的通知

洋政办发〔2017〕77号

洋县人民政府办公室关于

印发2017年度政府系统集体学法活动的通知

各镇人民政府、街道办事处，县政府各部门，直属机构、市管单位：

为深入推进依法行政，加快建设法治政府，根据国务院《关于加强法治政府建设的意见》文件规定，县政府决定在全县政府系统全面开展集体学法用法工作。现将有关事宜通知如下：

一、充分认识集体学法活动的重大意义

领导干部是推行依法行政、建设法治政府的主力军。领导干部学法用法，是树立法治理念、运用法律思维处理各项工作的关键，是全县行政机关依法作为、合法有为的前提，是适应当前利益诉求多元化、矛盾纠纷复杂化、法律维权意识觉醒的重要举措，是加快法治政府、服务政府建设、转变政府职能的重要保障。因此，全县领导干部要高度重视集体学法活动，切实增强使命感和责任感，抓好、抓实、抓细该项工作。

二、集体学法活动的范围

县政府、各镇人民政府、街道办事处、县政府各部门、直属机构、市管单位及相关事业单位均要在本通知发布之日起，按本通知要求每季度组织一次本单位全体人员集体学法活动，各单位、各部门可以根据工作实际延伸集体学法活动参加范围。

三、集体学法活动的组织及学习内容

1、县政府集体学法活动

在每季度末月的政府常务会、县政府专题会或县政府碰头会上,由县法制办牵头，相关单位配合，经汇报县政府分管领导同意后，确定学法时间和内容，形成讲稿，经县法制办或相关部门审核学法讲稿后，由县政府领导、相关部门主要负责人或政府法律顾问担任主讲，以案说法、以案析理、以理服人。讲解结束后，由县长或常务副县长对本次学活动进行点评，通过集体学法达到以学促用，以用促学的目的。

县政府集体学法主要以《宪法》、《政府工作规则》、《行政监察法》、《行政诉讼法》、《行政复议法》、《国家赔偿法》、《保密法》、《突发事件应对法》、《环境保护法》、《安全生产法》、《食品安全法》和《政府信息公开条例》为主，灵活安排其他学法内容。

2、部门集体学法活动

在每季度末月的部门全体会上，由办公室（行政科）或法制科牵头，相关业务科室配合，确定学法内容，形成讲稿，经主要领导审定后，由分管领导或法律顾问担任主讲，贴近群众、接近现场，以案说法、示警明人。讲解结束，由单位主要领导进行点评。集体学法活动可根据实际需要，可通知相关业务单位或企业法人参加。

部门集体学法活动要以《政府信息公开条例》、《行政诉讼法》、《行政许可法》、《行政处罚法》、《行政复议法》、《行政强制法》和陕西省《行政处罚自由裁量权暂行规定》为主，辅以各部门承担的职能所涉的法律法规。辅助学习由各部门自行安排。

3、各镇办集体学法活动

在每季度末月的镇办全体会议上，由党政办牵头，各相关科室、站办所配合，确定讲课内容，形成学法讲稿，经镇长（主任）审定后，由分管镇长（主任）担任主讲。学法活动讲解结束后，由镇长（主任）进行点评。一般由全体干部参加，可根据学法内容将参加范围延伸至村(居)两委主要领导，促使学法活动扩围，增强学法实效。

各镇办集体学法要以《行政诉讼法》、《行政复议法》、《人民调解法》、《突发事件应对法》、《信访条例》为主，辅以《婚姻法》、《道路交通安全法》、《土地管理法》、《农村土地承包法》、《农民专业合作社法》、《残疾预防和残疾人康复条例》和《陕西省农村扶贫开发条例》学习，其余由各镇办自行调剂学习。

四、工作要求

1、高度重视，精心组织。用法律思维处理各种事务是体现领导干部领导能力的重要指标，集体学法是促进和强化领导干部树立法治理念、权责意识的重要举措，各单位要精心组织，制定方案，落实专人，保障经费，切实组织好本单位集体学法活动，将学法方案报县法制办备案。

2、统筹兼顾，紧扣中心。各镇办、各部门应当围绕县委、县政府中心工作，群众关注焦点，以正面讲解为主、负面警示为辅、结合本部门、本单位的职能和工作实际，创造性做好集体学法活动，认真总结经验，及时将集体学法活动讲稿送县法制办，集体学法活动杜绝以单纯空读法条等形式单一、枯燥乏味的方式进行。

3、督促检查，考核奖励，县法制办代县政府组织力量对各部门、各单位集体学法活动进行不定期检查，对于未开展集体学法或未按进度开展的镇办、部门在全县予以通报批评。同时，县政府将集体学法活动纳入年度依法行政考核之中，各镇办、各部门要在11月底前将本年度集体学法总结及讲稿送县法制办，县法制办将组织依法行政领导小组成员单位对讲稿进行评定，评为优秀的，在全县予以表彰奖励；评为不合格的，全县通报批评。

洋县人民政府办公室
