# 洋政办发〔2017〕83号关于规范社会中介机构参与政府投资项目审计的通知

洋政办发［2017］83号

洋县人民政府办公室关于

规范社会中介机构参与政府投资项目

审计的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为实现审计全覆盖目标，充分发挥政府投资项目审计监督的时效性和建设性作用，根据《陕西省国家建设项目审计条例》、《洋县政府投资项目审计管理办法》（洋政发[2015]29号）有关规定，现就社会中介机构参与我县政府投资项目审计工作通知如下：

一、根据洋政发[2015]29号文件精神,县审计局从市审计局公开选聘并经评审的入库中介机构中，确定13 家中介机构，组建洋县政府投资审计备选库（名单附后），参与部分政府投资项目审计。各镇（办）、各单位不得在备选库之外委托中介机构审计。

二、政府投资项目按投资额度实施层级审计：工程送审价或项目资金30万元以下（含本数）的项目，按《洋县人民政府关于印发加强预算内投资项目管理意见的通知》（洋政发[2015]25号）规定执行；如需审计结论的，由各建设单位直接委托中介机构进行审计，将审计结果报审计局备案。送审价或项目资金30万元至50万元之间的项目，各建设单位提出审计申请，商县审计局确定中介机构后，由建设单位委托中介机构进行审计，将审计结果报县审计局审核备案。送审价或项目资金50万元以上的项目，由审计局组织审计（审计局自行审计或委托中介机构审计），并出具审计报告。

三、各镇（办）、各单位委托中介机构审计，应对工程签证、工程审计现场勘查记录等严格审核把关，确保审计质量。县审计局每年对中介机构审计的项目进行抽查复核，作为考核中介机构的依据。
