# 洋政办发〔2017〕86号关于开设整合涉农资金账户有关问题的通知

关于开设整合涉农资金账户有关问题的

通 知

各镇人民政府、街道办事处，县统筹整合使用财政涉农资金领导小组成员单位：

根据上级统筹整合财政涉农资金会议精神，现就我县开设整合财政涉农资金账户的有关情况通知如下：

一、 开设账户依据

县级和镇（办）涉农资金账户开设依据陕西省财政厅、中国人民银行西安分行《陕西省预算单位银行账户管理暂行办法》（陕财办库﹝2014﹞16号）和洋县统筹整合使用财政涉农资金领导小组第3次会议纪要。

二、 账户及资金管理

1、县级整合资金在县扶贫办开设资金共管账户，由县扶贫办、县财政局共同监管，全县每个镇（办）开设扶贫专户（核算内容包括整合资金），县扶贫办、各主管部门、各镇（办）要对资金使用的合法性、规范性及资金拨付的及时性负责。

2、资金拨付程序。县统筹整合使用财政涉农资金领导小组办公室将年度内的涉农资金整合项目及资金文件下达后，县财政局相关科室将纳入涉农整合范围的项目类资金指标在支付系统内录为实拨指标，国库科按下达的整合资金文件将资金划入县扶贫办共管账户；将纳入涉农整合范围，但属于工作经费类的资金继续按集中支付程序办理。县扶贫办要及时将共管户收到的项目资金进行梳理。对于县级行业部门管理的项目，属于镇(办）实施的，在收到资金后经行业主管部门的审定后及时将款划拨到镇（办)扶贫专户，行业部门负责按项目管理规定和管理办法督促镇（办）加快项目实施。对于属县级行业部门管理实施的项目，资金到位后,县扶贫办、财政局要及时通知行业主管部门办理支付、拨付事项。对于形成的项目支出，由项目施工单位提出申请和票据，经行业主管部门按项目管理、财务管理规定审核，县扶贫办按程序，将资金由共管户直接支付给施工单位。

3、资金核算管理。资金核算实行分级管理，县统筹整合使用财政涉农资金办公室，要按中、省、市、县资金来源的级次、资金项目、资金整合后资金去向，分用途、部门、村、项目建立台账进行核算；县财政局、县扶贫办对共管账户的整合资金设立专账、专人管理进行日常的会计处理及核算；镇（办）对所属预算内、专户整合资金进行日常会计处理及核算。县整合办公室、扶贫办、镇(办）要各司其职，确保核算及时、账务清楚，资料齐全、手续齐备、管理规范。

4、设置会计核算科目。为了规范会计核算，设置县、镇（办）专户会计核算科目（详见表一、二），并按此核算。

5、县、镇（办）共管账户实行财务报告制度。各镇(办）扶贫办、县级项目实施部门要在每月末工作日最后一天，向县扶贫办、县统筹整合使用财政涉农资金领导小组办公室报送支出报表（表三），县扶贫办、县统筹整合使用财政涉农资金领导小组办公室要将每月全县的整合资金收支结余报表于次月5日前送县脱贫攻坚指挥部办公室。

6、整合涉农资金报账。整合的涉农资金不再实行县级财政报账制，镇（办）实施的项目在镇(办)报账,由镇（办）负责审核。部门实施项目在县扶贫办共管户报账，由各项目主管部门审核。各镇（办）、各项目主管部门依据相关法律法规和管理制度审核项目支出的合法性、合规性，确保项目建设和财务资料规范、完善。各级各部门应简化程序、明确事权，同时应加强项目监管，资金管理，不能因资金整合放权管理，造成责任缺失，确保涉农整合资金安全、规范、高效运行。
