# 洋政办发〔2017〕100号关于印发省内流转闲置集体建设用地增减挂钩拆除复垦及拆后管理实施方案的通知

洋政办发〔2017〕100号

洋县人民政府办公室

关于印发省内流转闲置集体建设用地增减挂钩拆除复垦及拆后管理实施方案的通知

各镇人民政府、街道办事处：

《省内流转闲置集体建设用地增减挂钩拆除复垦及拆后管理实施方案》已经县政府同意，现印发给你们，请遵照执行。

洋县人民政府办公室

2017年7月10日

省内流转闲置集体建设用地增减挂钩拆除复垦及拆后管理实施方案

为贯彻落实《中共中央国务院关于打赢脱贫攻坚战的决定》，充分利用我县闲置集体建设用地资源优势，有效利用土地资源配置政策的有利条件，发挥补充耕地指标跨区域配置的政策，解决脱贫攻坚资金不足的难题，县政府决定分期分批跨区域流转一定数量的闲置集体建设用地指标。为确保扎扎实实做好闲置集体建设用地指标流转工作，根据《国土资源部关于用好用活增减挂钩政策积极支持扶贫开发及易地扶贫搬迁工作的通知》（国土资规〔2016〕2号）、《关于开展省域内城乡建设用地增减挂钩积极支持脱贫攻坚和易地扶贫搬迁的意见》的通知（陕国土资发〔2016〕14号）、《关于做好省域内城乡建设用地增减挂钩指标流转管理工作的通知》（陕国土资发〔2016〕90号）和《陕南移民搬迁土地综合利用实施管理办法》（陕国土资发〔2016〕38号）等文件要求，结合我县实际，特制定本实施方案。

一、总体思路

按照土地利用总体规划和项目实施规划，将各镇（街道办）拟复垦为耕地的农村闲置建设用地地块（即拆旧区）、拟用于安置搬迁农户的村庄建设用地地块（即安置区）共同组成拆旧安置项目区（以下简称项目区），在项目区内对农村居民点用地进行拆迁、整理、复垦，新增加的耕地在满足县域内建设用地需求的前提下，节余的建设用地指标作为省域周转指标，用于全省范围内跨县指标流转使用。

二、工作原则

1、增减挂钩项目严格按照 “总量控制、封闭运行、定期考核、到期归还”的原则进行管理。

2、坚持“政府主导、国土指导、部门联动、镇村负责、群众参与”的原则组织实施，同时遵循统筹兼顾、符合规划、因地制宜、节约集约用地原则。

3、项目建设中采取政府主导、国土局规划设计、镇（办）村组织拆除复垦加强监管的基本原则。

三、工作内容

1、工作对象

省内流转闲置集体建设用地增减挂钩251.1亩，涉及马畅、谢村、龙亭、槐树关4个镇，洋州、戚氏、纸坊3个街道办事处，野猪沟、魏渠、大池、小池等35个村77个地块。

2、实施主体

项目由各镇办组织实施，达到验收标准。

3、工作任务

对77个项目区地块进行清理，达到省、市验收标准。主要完成下列工作任务：

（1）清理地上附着物。清理掉地面上的零星树木、建筑物、构筑物。

（2）实施土地平整。达到符合耕种条件的要求，即土层厚度大于50㎝，土壤为砂质土壤，土地平整，灌溉设施能满足作物生长。

4、验收

拆旧地块整理复垦竣工后，由各镇（街道办）进行自验，编制竣工报告，申请县国土资源局初验。（联系电话：[电话略]）

5、完成时限

各镇办务必于2017年7月 日前完成复垦验收，达到省、市标准。

6、后期管理

项目完成后，镇办、村为项目工程管护主体，负责项目工程后期管护工作，主要对复垦后的拆旧地块进行流转或承包。县政府与镇办、镇办与村签订管护责任书，实行层层管理。复垦后的土地只能用于农业生产，禁止用于非农业建设，不得擅自改变土地用途。

7、资金拨付及管理。项目资金按1万元/亩拨付给镇办，由镇办根据工作量拨付给项目所在的村用于清理建筑物、构筑物、树木、杂草，土地平整等。在项目实施过程中，由各镇办根据批准的项目实施方案，由县政府预拨付30%的启动资金，项目竣工验收合格后拨付剩余的70%资金。项目产生的土地收益交在洋县人民政府土地收购储备中心资金专户，专帐核算，专款专用，严格审批，封闭运行。

三、保障措施

1、高度重视。各镇办、村要高度重视省内流转闲置集体建设用地增减挂钩拆除复垦及拆后管理工作，加强组织领导，抽调专人负责，按时保质保量完成拆旧清理复垦任务。

2、明确责任分工。县政府制订年度指标流转计划，负责签订指标流转协议，安排审批指标流转资金的使用方向。县国土局负责闲置农村建设用地的初步确定，编制项目规划、设计方案，进行项目实施技术指导，组织项目实施验收工作。镇办、村负责该行政区内项目地块的拆除、复垦和后续监管工作。

3、加快实施。国土资源局要加强对项目区涉及的镇办、村进行督导检查，加快工作进度，确保按时完成工作任务。对工作推诿、履职不到位，影响项目顺利实施的镇办、村，将追究主要领导责任，并暂停该镇的建设用地报批和土地整治项目。

4、严明纪律。建立由监察部门牵头，国土、财政、审计等部门及当地群众参与的项目监督机构。加强对政策落实情况的监督检查，受理群众举报，查处违纪违法问题。对以增减挂钩项目为名违法违规占用耕地和擅自扩大城乡建设用地规模的，要严肃查处，依法追究有关人员的责任，对违反政策规定，造成重大损失或引发群体性事件的，要严格责任追究；构成犯罪的，要移送司法机关。
