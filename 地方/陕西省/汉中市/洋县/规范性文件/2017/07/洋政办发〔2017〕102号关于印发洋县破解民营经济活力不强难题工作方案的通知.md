# 洋政办发〔2017〕102号关于印发洋县破解民营经济活力不强难题工作方案的通知

洋政办发〔2017〕102号

洋县人民政府办公室

关于印发洋县破解民营经济活力不强

难题工作方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县破解民营经济活力不强难题工作方案》已经县政府同意，现印发给你们，请认真组织落实。

洋县人民政府办公室

2017年7月24日

洋县破解民营经济活力不强

难题工作方案

为深入贯彻落实市委、市政府追赶超越决策部署，切实破解我县民营经济发展活力不足难题，根据市、县追赶超越季度点评工作要求，结合我县实际，现制定如下工作方案。

一、现状和问题

2016年，我县民营经济现状和特点：一是发展总量持续扩张。当前全县共有各类民营经济组织24000个，从业人员 96342人，民营经济发展涵盖我县工业、农业、建筑、交通运输、商贸、旅游、城乡基础设施建设、社会化服务等多个领域，已成为县域经济发展的主力军。二是非公经济增加值占全县GDP比重达到52.3%。三是县域工业园区建设稳步推进。以民营经济为主体的县域工业园区实现营业收入97.077亿元，完成园区基础设施建设投资15.67亿元。四是产业结构不断优化。当前，我县民营工业经济形成了冶金、建材、矿产、农产品加工、医药化工、有机食品、装备制造、水电八大产业，构成了全县工业经济快速发展的主体。五是服务体系建设进一步规范。我县已完善大力发展民营经济的创业辅导、人员技术培训、信息化服务、融资担保、管理咨询、法律维权等服务体系建设。六是各级财政支持民营经济工作力度进一步加大。

当前，我县民营经济活力不强的问题主要表现在：一是发展总量与全市平川县相比有差距，目前位居第4。二是产业竞争力不强。我县民营工业经济高精尖产品和高科技占比相对较低,产业竞争力不够明显。三是民营经济融资难问题依然存在。四是县域工业园区建设有差距，存在产业规划布局与实施不够协调一致，产业集聚力不强的问题。五是管理水平不高，部分企业尚未建立现代化企业管理制度，管理水平不高，人才短缺，招人难，选人难，留人难，可持续发展后劲不足。

二、破解思路

认真贯彻落实省、市、县追赶超越的新部署、新要求，坚持问题导向，突出服务质量，强化监管机制，优化发展环境，聚焦聚力难题，激发市场主体活力，努力促进民营经济加快发展，转型升级，提质增效，为实现我县追赶超越和工业稳增长做出新贡献。

三、目标任务

今后五年，全县年均新增私营企业130户，新增规模以上工业企业4户，新增入园企业4户，规模以上中小工业主营业务收入年均增长15%左右，工业园区企业营业收入年均增长15%左右。到2021年，全县非公经济增加值占全县生产总值比重达55%，追平全市平均水平，工业园区营业收入超过 120亿元。

四、工作重点

（一）放宽民营企业准入门槛。按照“非禁即入”原则，支持民营资金进入交通能源、电力通信、教育文化、养老社保等行业，参与基础性公共设施和公共服务领域的PPP项目建设。（牵头单位：县发改局；配合单位：县经贸局、县财政局、县交通局）

（二）降低民营企业经营成本。全面实施“营改增”，落实中小微企业税收优惠政策，减轻民营企业税费负担。简化行政审批程序，进一步降低民营企业失业、工伤、生育保险缴费比例。（牵头单位：县发改局、县财政局；配合单位：县人社局、县国税局、县地税局）

（三）缓解融资难题。加大“助保贷”及民营企业项目建设贷款财政贴息支持力度，创新针对民营企业的金融产品、信贷模式和服务方式，改进对小微企业征信评估机制，降低民营企业贷款门槛，加大对民营经济的支持力度。（牵头单位：县中小企业局；配合单位：县财政局、县发改局、县金融办、人民银行洋县支行）

（四）推进民营企业科技创新。支持民营企业大力发展科技创新型、资源节约型、绿色环保型产业和产品。积极引导民营企业运用高新技术和先进实用技术改造提升传统产业，研发具有自主知识产权的产品，增强民营企业的核心竞争力。鼓励、支持民营企业建立创新研发平台，引导和支持企业研发机构提高创新能力，稳步提升高科技产品、产值所占比重。（牵头单位：县科技局；配合单位：县经贸局、县中小企业局）

（五）加快县域工业园区建设。县域工业园区是我县民营经济快速发展的“孵化器”和县域工业经济的增长极，加快完善县域工业园区基础设施和加大投资力度，建立健全园区配套服务体系，促进大企业、大项目向园区集聚，推动园区快速、健康发展。（牵头单位：有色工业园区管委会办公室；配合单位：县国土局、县住建局、县水利局、县环保局、县中小企业局）

（六）促进转型升级。实施民营经济工业小微企业培育成长工程。按照“扶优扶强、加快发展”的原则，每年选择10户工业小微企业作为扶持培育对象，通过培育，力争每年使其中3户小微企业发展成为规模以上企业，不断扩大布局结构合理、管理先进、带动能力强、竞争优势明显的企业群体，带动我县小微企业全面快速发展。（牵头单位：县经贸局；配合单位：县统计局、县科技局、县中小企业局）

（七）提高民营经济发展管理水平。进一步加强民营经济管理，不断提高民营经济健康发展整体水平，引导民营经济苦练内功，降本增效，严格遵守安全、环保、产品质量、卫生、劳动保障等法律法规，诚实守信经营，履行社会责任。（县安监局、县人社局、县环保局、县经贸局负责）

（八）推进服务体系建设。搭建政府主导，市场化运作的中小企业公共服务平台，采取政府购买服务等方式支持平台建设。服务机构就企业需求主动对接，为我县民营企业开展管理咨询、人才培训、技术指导、融资服务、法律维权等活动。（县中小企业局、县人社局负责）

（九）保护民营经济合法权益。进一步优化民营经济发展环境，营造良好、和谐的发展氛围。政府保护民营企业及其出资人的合法权益及因投资取得的合法收益，任何单位和个人不得侵犯民营企业财产及其合法收益。搭建民营企业投诉平台，受理和协调处理企业提出的投诉事项。（县经贸局、县市监局负责）

五、保障机制

（一）加强组织领导。成立破解民营经济活力不强难题工作领导小组，由主管副县长任组长，发改、财政、经贸、市监、环保、水利、林业、住建、电力等部门领导为成员。发挥县发展非公经济领导小组办公室（设在中小企业局）职能作用，加强对全县民营经济发展的统筹规划和政策协调，各有关部门和镇（办）各司其职，密切配合，明确职责，形成合力，切实加强引导和服务，全力推进我县民营经济发展不断迈上新台阶。（县中小企业局负责）

（二）强化财政支持。县上分别设立中小企业非公经济发展专项资金和工业园区发展专项资金，用于支持中小企业非公经济转型发展及工业园区建设，并形成专项资金逐年增长机制。（县财政局负责）

（三）加大考核力度。考核部门加大镇（办）年度发展民营经济权重分值，对年度考核分值靠后的镇（办）予以通报。（县考核办、中小企业局负责）
