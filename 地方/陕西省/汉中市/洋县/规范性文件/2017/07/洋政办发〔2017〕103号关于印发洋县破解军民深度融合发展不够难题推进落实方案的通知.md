# 洋政办发〔2017〕103号关于印发洋县破解军民深度融合发展不够难题推进落实方案的通知

洋政办发〔2017〕103号

洋县人民政府办公室

关于印发洋县破解军民深度融合发展不够

难题推进落实方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县破解军民深度融合发展不够难题推进落实方案》已经县政府同意，现印发给你们，请认真组织落实。

洋县人民政府办公室

2017年7月24日

洋县破解军民深度融合发展不够难题

推进落实方案

根据《汉中市人民政府办公室关于印发汉中市破解军民深度融合发展不够难题推进落实方案的通知》（汉政办发〔2017〕39号）文件精神，为着力破解我县军民深度融合发展不够难题，实现追赶超越发展，结合我县实际，特制定本方案。

一、指导思想

认真贯彻落实省委、省政府和市委、市政府关于追赶超越的部署和要求，以五大发展理念为指导，以环境保障为抓手，以创新求突破，以共建促发展，全力推进军民深度融合，实现军民融合产业总量扩张和提质增效。

二、发展目标

通过推动军民融合体制机制改革创新、军民融合产业加速发展、军民科技资源开放共享、建立健全军民融合服务体系，努力破解军民融合难题。全力打造四O五核原料基地、中航飞机起落架公司零部件加工配套产业，力争到2021年实现4000吨分离功率/年能力，为中航飞机起落架公司配套的加工企业由现在的1户达到5户以上，使军民融合产业产值达到100亿以上。

三、重点工作任务

（一）发展整机集成。积极配合市级部门，全力协助陕飞公司加快对民用货机的深度研发进程，争取中省相关部门早日规划立项，推动民机项目的实质性进展。鼓励发展上下游配套产品和相关产业；不断增强民企服务国企的能力。（牵头部门：县发改局，配合部门：县经贸局）

（二）全方位推进军民融合。支持军工单位发挥技术、人才优势，参与垃圾、污水处理利用，不断拓展应用服务范围。鼓励军工单位采取跨区域、跨行业、跨所有制开放式合作，推动企业、资本、技术、产品和人力资源的整合。支持军工单位与地方企业合作创办人财物相对独立的民品企业，加快国防科技成果转化，延长和完善产业链。（牵头部门：县发改局，配合部门：县经贸局、县科技局、县人社局、县市监局）

（三）强化军民融合产业配套。借助汉中航空智慧新城聚合作用，依托中航飞机起落架公司和燎原金属机电公司资源，通过有针对性的专项招商引资，股本重组、生产转包等形式引导“军转民”和“民参军”，加快我县航空零组件制造产业聚集发展。以基础配套、零部件加工为重点，培育和发展一批“民参军”的“小巨人”企业。（牵头部门：县经贸局；配合部门：县发改局、县科技局、县市监局）

（四）支持军民融合重点项目建设。全力支持四O五核材料产业园项目建设。积极配合四O五厂搞好南区建设项目的规划、审批。全力保障项目建设的外部环境，严厉打击干扰和破坏基础设施、生活设施和生产设施的违法犯罪行为，确保项目建设顺利进展。（牵头部门：县公安局，配合单位：谢村镇、溢水镇、戚氏办）

（五）搞好央企“三供一业”和企业办社会职能剥离移交工作。按照《国务院国资委、民政部、财政部、住房和城乡建设部关于国有企业办市政、社区管理等职能分离移交的指导意见》（国资发改革〔2017〕85号）和汉中市剥离国有企业办社会职能和解决历史遗留问题工作领导小组办公室《关于转发省剥离领导小组办公室<关于印发国有企业职工家属区供水、供电、供气、供热分离移交工作操作流程的通知>的通知》（汉市国资发〔2017〕26号），积极协助四O五厂、燎原机电公司、二十一社区向上争取资金，搞好项目规划、设计、改造和移交工作，使国有企业甩掉包袱干主业。（牵头部门：县经贸局，配合部门：县发改局、县财政局、县住建局、县民政局、县教体局、县水利局、县人社局、县编办）

四、保障措施

（一）加强组织领导。成立洋县破解军民融合发展不够难题推进落实领导小组，协调解决军民融合发展中一些重大事项和具体问题，由分管副县长任组长，经贸、发改、财政、公安、住建、市监、民政、教体、水利、卫计、电力等单位领导为成员，领导小组办公室设在县经贸局，由县经贸局局长兼任办公室主任，负责日常工作。各重点任务牵头单位按季度将工作进展情况形成书面材料报县经贸局。

（二）推动机制创新。一是对军民融合重大工程和项目，县政府将全力提供环境保障，搞好协调服务。二是支持民营企业、社会资本与军工企业开展合作，共同投资发展混合所有制经济。

（三）做好政策对接。加强与国家国防科工局、省国防科工办、市发改委、市工信委等中省市相关部门的联系沟通，争取中省市政策支持。依托中省军转民专项扶持资金和省军民融合产业发展基金，引导促进军民融合产业科技创新和产业结构调整升级。

（四）改善发展环境。继续推进军工企业周边环境治理，优先保证军工企业和军民融合重点项目的土地、用水、供电、通讯等生产保障，支持重点军工企业发展。深化军地双拥共建活动，激发和调动社会各界特别是新经济组织、新社会组织参与军民融合发展的积极性、创造性。
