# 洋政办发〔2017〕105号关于进一步规范贫困户带资入企委托合作和企业创业贷工作的通知

洋政办发〔2017〕105号

洋县人民政府办公室

关于进一步规范贫困户带资入企委托合作和

企业创业贷工作的通知

各镇人民政府、街道办事处，县政府有关工作部门、直属机构,市管单位：

为加大脱贫攻坚金融支持力度，破解贫困群众贷款难、贷款贵问题，引导贫困群众正确合理使用扶贫资金，多渠道多措施增加收入，加快脱贫致富步伐，县脱贫攻坚指挥部办公室下发了《洋县扶贫小额贷款管理办法<修订>》（洋脱贫指办发[2017]35号）和《洋县“企业+金融+贫困户”精准扶贫带动模式试点工作实施方案的通知》（洋脱贫指办发 [2017]36号）文件，明确了贫困户带资入企委托合作和银企合作（创业贷）的金融精准扶贫带动模式及其相关政策。近期,市上对两项工作提出了指导性意见和工作要求,现就规范贫困户带资入企委托合作和企业创业贷工作的有关事项通知如下：

一、严格审核，积极稳妥推进贫困户带资入企委托合作

各镇办要积极用足用活扶贫小额信贷政策，在坚持“政府引导，企业参与；因地制宜，产业引领；平等自愿，遵守合约；利益联结，合作共赢”的原则下，鼓励引导贫困户与农业龙头企业以及农民专业合作社广泛开展信贷资金委托合作。

（一）明确带资入企委托合作的实施主体

各镇人民政府、街道办事处为带资入企委托合作的实施主体，对合作企业选择对接、委托贫困户资格审核、签订委托合作协议、兑付贴息资金等负主体责任。

（二）明确贷款安全风险把控和贷后监管责任主体

相关承贷金融机构对贷款安全风险把控及贷后资金监管负主体责任。

（三）明确参与带资入企委托合作的范围及条件

1、参与企业范围及条件：原则上为全县范围内省、市、县级农业产业化龙头企业（须有一定产业基地规模）、经营正常效益良好的农民专业合作社。特殊情况的须报县金融电商推进组和产业推进组共同确定。

2、合作农户范围：全县尚未获得扶贫小额贷款,无直接产业贷款需求、自主发展产业能力不足、收入不稳定的一般贫困户和2016年以来已脱贫户（不含剔除户）。

（四）带资入企合作企业和农民专业合作社的优选推荐

带资入企合作企业实行推荐制，即以县农业局为主，相关金融机构配合，建立农业产业化龙头企业信息库，在建立信息库的基础上，按照洋县5115产业精准扶贫工程产业布局，优选确定与有机稻米、蔬菜、果品、养殖、林特五大类主导产业联系紧密且信用等级良好的农业龙头企业并将名单推荐给各镇办，镇办在合作企业推荐名单中选择对接合作企业。农民专业合作社由镇办根据辖内农民专业合作社经营状况自主推荐。

(五)带资入企信贷资金规模

每户合作企业委托信贷资金规模原则上不高于500万元；每个农民专业合作社委托信贷资金规模原则上不高于200万元。

（六）带资入企信贷资金期限

不超过三年。

（七）带资入企操作流程

1、有合作意愿的企业（须在农业局推荐的名单中）向产业基地所在地镇办提交带资入企委托合作书面申请报告，报告中须明确企业基本情况、主营产业项目基地规模、产业关联度以及带动能力等内容（农民专业合作社向辖区镇办提交申请报告）。

2、镇办根据企业或农民专业合作社申请报告进行核实，形成书面审定意见后签订《企业+贫困户精准扶贫合作框架协议》一式四份，镇（办）、企业或农民专业合作社双方各执二份。

3、镇办将审定意见提交给承办银行核定合作企业或农民专业合作社贷款风险额度后，由镇（办）、承办银行、企业或农民专业合作社三方共同确定委托合作贫困户数量和带资入企规模。

4、镇（办）村在贫困户充分自愿的基础上，鼓励参与带资入企委托合作并形成初选名单，由镇办对带资入企委托贫困户资格进行审核，审核确认后引导其与企业在平等自愿的前提下签订《精准扶贫贫困户带资入企委托合作协议》一式五份，协议中需明确贫困户委托企业或农民专业合作社使用扶贫小额贷款的意愿额度、分红标准、时限以及企业或农民专业合作社还本付息、违约责任等。贫困户按约定分红比例享受固定收益，固定收益比例应按不低于企业或农民专业合作社向当地金融机构同期贷款基准利率（含财政贴息资金），镇（办）、村、企业或农民专业合作社、贫困户各执一份，报县农业局备案一份。

5、承办银行按照贫困户委托企业或农民专业合作社使用的意愿额度发放贷款，信贷资金打入委托贫困户银行账户，再转入合作企业或农民专业合作社账户。合作企业或农民专业合作社及其法人代表承担连带担保责任,由企业或农民专业合作社还本付息,贫困户不承担企业或农民专业合作社任何经营风险，利息按中国人民银行同期同档基准利率执行，财政扶贫贴息资金通过“惠农一卡通”直接贴付给贫困户作为入股分红，每半年贴付一次。

（八）带资入企委托合作贷款的使用范围：合作企业或农民专业合作社通过带资入企委托合作取得的信贷资金，必须用于主营产业的生产、加工、流通、建立产业基地以及对贫困户的帮扶投资，不得挪作他用。

二、发挥财政资金撬动作用，推动企业创业贷有序开展

相关金融机构要依照吸纳贫困户就业和产业带动情况，向积极履行社会帮扶责任的经营主体发放精准扶贫创业贷，推动银企合作深入开展。

（一）申请创业贷的经营主体范围：县境内能积极履行社会帮扶责任且从事农、林、牧、副渔业生产、加工、流通等经营活动的中、小微型企业、农村新型经营主体（农民专业合作社、专业协会、家庭农场）以及非涉农企业。

（二）创业贷贷款条件：依据《中国人民银行关于建立金融精准扶贫贷款专项统计制度的通知》（银发[2017]185号）文件规定，设定贷款条件为：年经营收入500万元以上2亿元以下的中型涉农企业吸纳贫困人口就业或产业带动累加5户或5人以上；年经营收入50万元以上500万元以下的小型涉农企业吸纳贫困人口就业或产业带动累加3人或3户以上；年经营收入50万元以下的微型涉农企业吸纳建档立卡人口就业或产业带动1户或1人以上；农民专业合作组织（含扶贫专业互助合作社）吸纳建档立卡贫困人口就业或产业带动1人或1户以上；非涉农中型企业吸纳贫困人口就业5人以上或占职工总人数2%以上。上述经营主体吸纳建档立卡贫困人口就业或产业带动期限不得低于1年。

（三）创业贷贷款利率执行标准：金融机构根据借款人的偿还能力、信用状况等自主确定，对带动能力强、帮扶成效明显的企业，贷款利率应予以优惠。

（四）创业贷申请方式及相关说明：创业贷由经营主体法人向相关金融机构申请并按规定条件提交吸纳贫困人口就业或产业带动的协议或合同；受理金融机构按正常企业贷款规定审贷，财政担保基金对贷款不予担保。

（五）创业贷贴息条件、标准及方式：经营主体每联结1户贫困户（以与贫困签订的协议或合同为依据）认定5万元的贴息贷款规模，中型涉农企业贴息贷款规模最高不超过500万元，小型涉农企业贴息贷款规模最高不超过200万元，微型涉农企业贴息贷款规模不超过100万元；农村新型经营主体贴息贷款规模不超过50万元。非涉农中型企业贷款不予贴息。贷款在实际发生一年后，经验收合格后按实际认定的贷款规模年利率5%给予贴息，财政扶贫贴息资金直接打入企业账户。

（六）创业贷的使用范围：取得创业贷款的经营主体，信贷资金必须用于产品的生产加工流通以及贫困户帮扶投资，不得挪作他用。

带资入企委托合作和企业创业贷在政策执行过程中，若与洋脱贫指办发[2017]35号和[2017]36号文件相抵触的，以该文件为准。

三、加强协调配合

1、加强组织领导。贫困户带资入企委托合作工作，相关镇人民政府和街道办事处是第一责任人。镇（办）、村要确保对象精准、需求精准，要及时向金融机构提供建档立卡贫困户数据核实相关信息；财政部门要做好金融扶贫风险补偿金、贴息资金的筹措、拨付和监管工作；县金融办要会同人民银行、银监部门，加强带资入企和企业创业贷实施情况分析、监管、监督检查和考评。驻村工作队要积极配合村两委做好带资入企委托合作对象审查、指导协议签订等各项工作。

2、提高服务水平。各承贷金融机构要进一步完善工作措施，简化贷款程序、减少贷款环节、优化贷款环境、优惠贷款利率，在防范风险的同时，严格按照工作程序发放贷款，努力做到应贷尽贷。不能随意抬高贷款门槛，不能提前扣除利息和提前结息，严禁以各种不合理理由收费。要加强贷后管理，协助龙头企业等经营主体管好、用好扶贫信贷资金。

3、强化工作监管。县金融办、人行、银监、金融机构等部门要加强监督检查，做到层层把关、信息共享，严格识别贷款对象，严格界定贷款用途。对虚列虚报、冒领套取风险补偿资金、财政贴息资金的单位和个人，依法依规严肃处理。要加强管理，监督贷款经营主体，按界定的贷款用途使用信贷扶贫资金，不得转移用途。一经发现，要及时收回贷款并列入诚信记录。

4、加大宣传引导。各级各有关部门特别是驻村工作队要会同金融机构，大力开展扶贫小额信贷政策和带资入企委托合作的宣传培训，努力提高镇（办）、村干部和贫困户对扶贫小额信贷特别是带资入企委托合作对象、用途、方法步骤的理解和掌握，充分调动干部群众参与金融精准扶贫工作的积极性和主动性。要积极培养、宣传典型，推动金融扶贫信贷工作。要引导贫困户和经营主体树立诚信意识，规范贷款行为，努力营造贫困群众靠金融谋发展促增收、早日脱贫致富小康的良好氛围。

5、增强贫困户自主发展能力。对于带资入企企业，各镇（办）要督促其为带资入企贫困户提供农资、技术服务指导，积极吸纳贫困户就业，保底收购贫困户农副产品，增强贫困户自主发展能力。
