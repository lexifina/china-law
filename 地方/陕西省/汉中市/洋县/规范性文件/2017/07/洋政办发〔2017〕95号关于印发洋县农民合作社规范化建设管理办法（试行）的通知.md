# 洋政办发〔2017〕95号关于印发洋县农民合作社规范化建设管理办法（试行）的通知

洋政办发〔2017〕95号

洋县人民政府办公室

关于印发洋县农民合作社规范化建设管理

办法（试行）的通知

各镇人民政府、街道办事处，县政府有关工作部门、直属机构：

《洋县农民合作社规范化建设管理办法（试行）》已经县政府同意，现印发你们，请遵照执行。

洋县人民政府办公室

2017年6月26日

洋县农民合作社规范化建设管理办法（试行）

为促进农民合作社规范、有序、健康发展，提高农民组织化程度，增加农民收入，根据《中华人民共和国农民专业合作社法》和省委省政府《关于稳步推进农村集体产权改革的实施意见》，结合我县实际制定本办法。

一、农民专业合作社

（一）组织机构

1、依法进行工商登记注册，挂牌经营，并提交营业执照、工商登记资料和银行开户账户复印件在县农业局（县农经站）备案。

2、理事会、监事会、成员（代表）大会等组织机构健全，职能作用发挥良好。民主选举理事会应由5--7人组成，在理事会中应选举产生理事长1名、副理事长至少1名；民主选举监事会成员至少3名，并从中选举产生监事长1名。不设监事会的，选举执行监事1名。理事会成员与监事会成员不得交叉任职。

3、办公场地固定，合作社标志醒目，办公设施齐全；农资产品购销部、技术服务部、财务部等内设机构科学合理；理事会、监事会分工清楚，职责明确，管理制度上墙。

4、成员入社手续齐全，核发有《社员证》，且社员的权利和义务明确，建有成员登记簿。

5、每年6月30日前完成工商登记年检。

（二）制度建设

1、合作社章程规范，能严格依照章程开展经营管理活动，并有详实的经营活动记录，建有成员生产经营台账。

2、理事会、监事会、成员（代表）大会、财务及资产管理、生产经营管理、盈余返还、重大事项报告制度和民主决策等管理制度健全，并能严格执行。

3、按照《农民专业合作社财务会计制度》规定进行独立的会计核算；实行财务公开，每年向社员公开财务不少于1次，向社员或成员代表大会通报合作社工作情况2次；实行盈余返还，每年至少进行一次收益分配；定期向业务主管部门报送会计报表，财务定期接受监督和审计。

4、合作社发展规划、工作计划切实可行。工作总结、财务分析报告、会议、培训等档案齐全，落实管护人员、专柜存放。

5、合作社每年12月10日前要向县农经站报送合作社工作总结和有关数据表册。列入监测点的合作社，每年要向县农经站报送2次情况。

（三） 规模品牌建设

1、开展示范社、标杆社创建活动。合作社按县、市、省及省以上示范社标准自行申报，县上业务单位组织实地效果评估、查阅资料、评审优选向上推荐。镇标杆社由所在镇办考察认定，县农业局备案。

2、合作社所从事的产业应为当地主导产业或特色优势产业，能够带动区域产业的规模发展，成员增收效果明显。

3、建立无公害农产品生产基地，取得无公害产地、产品认证，积极创建农产品品牌，实行品牌化经营。

（四）宣传培训建设

多形式、多渠道宣传农民专业合作社的意义作用、社员的权利义务以及国家扶持壮大合作社发展的优惠政策；各合作社办公场所、培训室均有统一标准要求的固定宣传标语1—2条；每年定期组织社员开展技术培训和政策宣传，全年集中培训不少于2次，并有培训工作记录。

（五）经营服务和功能发挥

1、搞好农业投入品的统一采购和供应服务，全年向社员统一供应农资比例达到80%以上。

2、抓好农产品销售服务，合作社成员80%以上的农产品通过合作社统一组织对外销售。

3、合作社建有生产资料采购和农产品销售台帐，台账记载交易量作为盈余分配的依据。

4、合作社要根据社员的需要，积极创办农产品销售、储藏、加工、运输等经营性实体，实行产加销一体化服务，提高农产品的市场竞争力，不断壮大合作社的经营实力。

5、发展“龙头企业+专业合作社+基地”、“专业合作社+股份经济合作社”营销模式，开拓农产品流通渠道，延长产业化经营链条。探索发展“农社对接”、“农超对接” 销售模式，与省内外各大超市、批发市场进行有效合作，建立长期供货关系，减少流通环节，扩大市场占有份额。

（六）财务管理

农民合专业作社实行会计出纳单设、账钱分管制度，各项收支按时记账。每年向社员大会或社员代表大会公布财务收支情况和分红方案，自觉接受监事会监督。报账时要出据有效票据才能入账，入账发票上要有经办人签字,并注明用途,分别由监事长和理事长审查签字后才能履行报账、记账手续。采购千元以物品，需签订采购合同，报账时要将采购合同作为报账的附件。农资采购、人员雇工费用、培训费、差旅费、品牌建设和办公耗材费用计入生产成本。各级投入的建设项目实行县、镇（办）和投入主管单位三级管理。财政项目支持合作社资金平均量化到入社成员账户，作为出资成员收益分红的依据；财政拨入合作社的扶贫产业发展资金，由各镇（办）监管使用，并按贫困户入社成员进行平均股权量化，作为贫困户成员入股资金，计入成员账户，收益按股分红。

二、农村经济股份合作社

（一）组织机构建设

1、村组依据农村经济股份合作社实施意见组建农村经济股份合作社，向县农业局提交章程、股权登记簿、民主选举的理事会、监事会成员名单及合作社社长、副社长、监事会会长、副会长任职名单原件和复印件等资料，由县农业局核发登记证书。农村经济股份合作社依据登记证书办理银行开户手续，挂牌经营。

2、理事会、监事会、成员（代表）大会职能作用发挥良好。民主选举理事会应由5--7人组成，在理事会中应选举产生社长1名、副社长至少1名；民主选举监事会成员至少3名，并从中选举产生监事长1名。理事会成员与监事会成员不得交叉任职。

3、实行分工负责，管理体制合理。在村委会挂牌办公。内设的农资产品购销部、技术服务部、财务部等，理事会、监事会成员分工清楚，职责明确，管理制度上墙。会计、出纳单设，账、钱分管。

4、股权结构合理。产权制度改革中，对村组集体经济组织形成的经营性资产、政府补助、社会捐助的资金平均量化到本集体经济组织成员。财政拨入农村股份合作社的扶贫产业发展资金，由各镇（办）监管使用，并按贫困户入社成员进行平均股权量化，作为贫困户成员入股资金，计入成员账户，与村组集体经济组织资产量化的股份合并参与股份合作社分红。

（二）规章制度建设

1、章程规范。章程经全体股民或股民代表会议讨论通过，严格依照章程开展经营管理活动，并有详实的经营活动记录。建有成员生产经营台账。

2、理事会、监事会、成员（代表）大会、财务及资产管理、生产经营管理、盈余返还、重大事项报告制度和民主决策等管理制度健全，并能严格执行。

3、实行社务公开。每年公开财务不少于2次，定期向社员或成员代表大会通报工作计划执行情况；实行盈余返还，每年至少进行一次收益分配；定期向镇（办）和业务主管部门报送会计报表，财务定期接受监督和审计。财务报告、会议、培训等档案资料齐全，立档归卷，落实管护人员、专柜存放。

4、开展示范社创建。根据农民专业合作社法和创建示范社标准，在已登记的合作社中，由农业部门规范一批、提升一批，使更多的合作社进入县、市、省、国家级示范社行列；由市场监管部门清理一批，对己停办或不按要求进行年鉴及未运行的合作社给予注消处理，收回营业执照。

（三） 规模品牌建设

1、积极探索开展生产经营加资金互助的“1+1”模式、生产经营加资金互助加土地流转的“1+2”模式，土地入股统一经营或托管服务运作模式，或股份经济合作社+农民专业合作社模式，创新统分结合的双层经营体制，使农民增收和集体经济不断发展壮大。

2、所从事的产业应为当地主导产业或特色优势产业，能够带动区域产业的规模发展，成员增收效果明显。

3、 建立无公害农产品生产基地，取得无公害产地、产品认证，积极创建农产品品牌，实行品牌化经营。

（四）财务管理

农村经济股份合作社实行会计出纳单设、账钱分管制度，各项收支按时记账。每年向社员大会或社员代表大会公布财务收支情况和分红方案，自觉接受监事会监督。报账时要出据有效票据才能入账，入账发票上要有经办人签字,并注明用途,分别有监事长和理事长审签字后才能履行报账、记账手续。采购千元以物品，要签订采购合同，报账时要将采购合同作为报账的附件。农资采购、人员雇工费用、培训费、差旅费、品牌建设和办公耗材费用计入生产成本。财政拨入的资金拨入各镇(办)实行报账制，专账监管。
