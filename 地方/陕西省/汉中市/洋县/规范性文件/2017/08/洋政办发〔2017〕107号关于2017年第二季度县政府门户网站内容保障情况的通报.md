# 洋政办发〔2017〕107号关于2017年第二季度县政府门户网站内容保障情况的通报

洋政办发〔2017〕107号

洋县人民政府办公室关于

2017年第二季度县政府门户网站内容

保障情况的通报

各镇人民政府、街道办事处，县政府各工作部门、直属机构:

根据洋县人民政府办公室《关于印发洋县政府网站管理有关规定的通知》(洋政办发〔2016〕44号)、《关于做好县政府门户网站内容保障工作的通知》(洋政办发〔2016〕45号)文件要求，现将2017年第二季度(4月1日-6月30日)政府门户网站内容保障情况通报如下:

2017年第二季度，县政府门户网站共发布各类信息1095条，其中：新闻动态类信息710条，信息公开类信息385条；政府各部门单位及镇办通过网站后台自行上传信息413条，政府信息中心上传信息682条。处理“县长信箱”和“咨询投诉建议”来信127件，已办结120件、超时办结14件，未办结7件。其中，教体局、农业局、茅坪镇信息发布和信息公开总数超过20条；统计局、公安局、信访局、搬迁办、龙亭镇未发布和公开一条信息，信息统计为0。住建局、国土局、环保局、戚氏办事处、纸坊办事处、黄安镇在信件办理过程中存在未办结信件，部分单位超时办结现象依然突出。

根据总体情况来看，2017年第2季度各单位上传新闻动态类信息较多，信息公开类信息较少，有26个部门、镇（办）在第2季度信息公开类信息统计为0。请各部门单位严格按照《中华人民共和国政府信息公开条例》要求，依法、依规公开政府信息，同时积极做好“依申请公开”工作，对收到的政府信息公开申请，要严把时限要求，务必于15个工作日内答复申请人。对未按《条例》要求依法履行信息公开义务，发生行政复议、行政诉讼且行政败诉的机关单位，将依法、依规追究有关责任。

以上问题，请各镇办、各部门务必高度重视，认真对照、查找问题、及时改进，共同做好政府网站内容保障工作。
