# 洋政办发〔2017〕116号关于加强全县雷电防护工作的通知

洋政办发〔2017〕116号

洋县人民政府办公室

关于加强全县雷电防护工作的通知

各镇人民政府、街道办事处，县政府各有关工作部门、直属机构,市管单位：

近年来随着气候异常变化引起的气候极端事件频繁发生，特别是雷击现象呈现多发和早发的趋势，雷击事件一旦出现，常常对人身安全和财产造成极大损失。为贯彻落实省政府《关于调整优化建设工程防雷许可的通知》（陕政发〔2016〕51号）文件精神，进一步加强防雷安全监管有关工作，现就有关事项通知如下。

一、高度重视，杜绝各类雷电安全事故发生

洋县地处汉中盆地东缘，北依秦岭，南屏巴山，境内地形复杂，夏季对流旺盛，极易发生雷电天气，对房屋建筑，尤其是易燃易爆、危化场所安全生产工作带来极大威胁。各单位要吸取近年来因雷电灾害引发的安全生产事故教训，进一步强化组织领导，严格落实安全生产责任制，坚持“安全第一、预防为主、综合治理”的原则，认真查找本辖区、本行业、本企业防雷安全的薄弱环节，抓好各项雷电防护安全措施的落实。防雷安全主管部门和安全生产监管部门要切实加强督促检查，及时发现存在问题，采取措施彻底解决，确保我县各类雷电安全事故零发生。

二、落实防雷许可调整，确保监管到位

1.2017年1月1日起，县气象局承担的房屋建筑工程和市政基础设施工程防雷装置设计审核、竣工验收许可，整合纳入建筑工程施工图审查、竣工验收备案，统一由县住房和城乡建设局负责。

2.油库、气库、弹药库、化学品仓库、烟花爆竹、石化等易燃易爆建设工程和场所，雷电易发区内的矿区、旅游景点，投入使用的建（构）筑物、设施等需要单独安装雷电防护装置的场所，以及雷电风险高且没有防雷标准规范、需要进行特殊论证的大型项目，仍由县气象局负责防雷装置设计审核和竣工验收许可。公路、水路、水利、电力、通信等专业建设工程防雷管理，由各专业部门负责。

三、强化防雷安全监管，提高灾害防御能力

（一）严格执行建筑工程防雷行政许可工作

县住建局负责全县房屋建筑工程和市政基础设施工程的防雷工程建设监管工作，建筑工程的施工许可必须把防雷工程设计作为前置条件。建筑工程必须进行防雷随工检测，由有气象部门颁发的雷电防护装置检测资质证的单位进行，工程竣工验收前，应对防雷工程检测报告进行查验，符合施工图审查文件和相关技术标准后，该工程方可进行竣工验收。

（二）严格落实防雷电装置定期检测制度

1.县气象局要联合安监局、公安局、消防中队等单位，加大对油库、气库、弹药库、化学品仓库、烟花爆竹、石化等易燃易爆建设工程和场所的防雷安全检查，对未按规定安装防雷装置和进行防雷检测的要坚决查处，及时整改。

2.中小学校、金融机构、医疗场所等公共服务部门应主动向气象主管机构授权的具有资质的防雷技术安全检测机构申请检测，县气象局要加强对有防雷安全隐患的公共服务部门防雷检测工作的督查，确保检测到位。

（三）严格履行防雷安全监管责任

各相关工作部门要依法履行防雷安全监管职责，落实雷电灾害防御责任，并将防雷减灾工作纳入安全生产监管体系和目标考核体系。县气象局要加强对雷电灾害防御工作的组织管理，做好雷电监测、预报预警、雷电灾害调查鉴定和防雷科普宣传，划分雷电易发区域及其防范等级并及时向社会公布。县气象局和县住建局要会同相关部门建立建设工程防雷管理联席会议制度，完善标准规范和工作流程，研究解决防雷管理中的重大问题。各相关部门要加强协调配合，按照谁审批、谁负责、谁监管的原则，履行建设工程防雷监管职责，明确和落实建设工程设计、施工、监理、检测单位以及业主单位等在防雷工程质量安全方面的主体责任，督促相关行业将防雷安全工作纳入安全生产责任制并落实防雷安全措施。

（四）落实防雷安全保障措施

建立健全政府财政投入保障机制，将审批部门委托有关机构开展并支付费用的防雷行政许可技术服务事项列入县政府购买公共服务目录。各相关部门要按照国家清理规范行政审批及其中介服务事项的要求，切实优化流程、缩短审批时限、提高审批效率，制定有效措施，强化防雷安全监管。要加强雷电监测网和雷电灾害预警预报系统的建设，完善雷电灾害易发区的村庄、风景名胜区、人员密集区和易燃易爆场所等地点的雷电防御设施建设，努力提高全社会雷电灾害防御能力。

洋县人民政府办公室

2017年7月25日
