# 洋政办发〔2017〕118号关于进一步加强松材线虫病防控工作的通知

洋政办发〔2017〕118 号

洋县人民政府办公室关于

进一步加强松材线虫病防控工作的通知

各镇人民政府、街道办事处，县政府有关工作部门：

为切实加强松材线虫病防控工作，确保全县森林资源安全，推进生态文明建设，经县政府同意，现就有关事项通知如下：

一、高度重视松材线虫病防控工作

松材线虫病是危害极大、传播蔓延快的检疫性林木病害，被称为松树的“癌症”。近年来，受多种因素影响，我县松材线虫病发生范围不断扩大，疫点1个镇，枯死松树范围已扩大到11个镇（办）、1个国有林场，严重威胁全县松林安全，防控形势十分严峻。各镇办各部门要切实增强做好防控工作的责任感和紧迫感，坚决克服侥幸心理和麻痹思想，把松材线虫病防控作为维护生态安全的重要措施，统筹各方力量，加大防治力度，尽快遏制松材线虫病传播蔓延的势头。

二、科学制定防控方案

“十三五”是松材线虫病防控的关键时期，各镇（办）要抓紧制定“十三五”防控方案，县林业局要抓紧制定全县总体防控方案，按照“预防为主、依法防治、主攻疫区、突防身边”的思路，以疫木除治、松褐天牛防治为抓手，以控制疫点疫情为重点，坚持政府主导、社会参与、多措并举、综合防控，实现监测普查、检疫监管、督查考核全覆盖，使疫点发生面积得到有效控制，疫点数量下降，枯死松树数量减少，全县疫情得到有效控制。各镇办的防控方案在今年8月10前报县林业局备案。

三、全面强化防控措施

（一）狠抓监测预警。各镇（办）要建立健全镇（办）、村、组三级监测网络，落实监测人员责任，充分发挥村级生态护林员作用，把监测触角延伸到每一片松林，做到早发现、早报告、早处置。要加快开发监测数据实时报送系统，大力推广应用无人机监测等新技术，不断提高监测水平。要扎实开展春秋季松材线虫病普查，实行定人、定责、定时制度，严禁虚报、瞒报疫情。

（二）突出检疫执法。县林业局及时组织执法检查，要依法依规严格检疫封锁，必要时可按相关规定在主要路口和木材检查站设立临时检疫哨卡。各镇（办）、林场要加强疫木管理，严禁使用和调运疫木，严禁疫木离开山场，流入群众的柴堆草垛。要严格涉木企业和涉木施工场地登记制度，建立报检、承诺、台账等检疫监管长效机制。各相关建设单位凡在林区施工涉及使用松木及其制品的，要将检疫要求列入采购合同条款，履行检疫手续；松木及其制品到达施工场地后要主动向县林业局森防站申请复检。县林业局要加大检疫案件查处力度，依法打击违规调运和非法利用疫木行为。

（三）强化疫木除治。各镇（办）和县林业局要认真做好年度除治作业设计，建立除治专业队，有组织、有计划地全面彻底清理病害木和枯死松树，每年3月底前完成疫木清理任务。对新发生、孤立疫点和发生面积小、地理位置重要、潜在危险性大的疫点，以及疫木周围1千米内有天牛刻槽的松树，采取一次性全面采伐、块状采伐或强度择伐措施，彻底清除疫情。要建立和完善分片包干、分段把关、跟班作业的全程监管制度，严格把好除治过程的每道工序、每个环节，确保除治质量。在烧毁疫木时，各镇（办）要精心安排，落实专人看护火场，严防引起森林火灾。

（四）综合防治天牛。松褐天牛是松材线虫的主要媒介昆虫。各镇（办）和县林业局要认真开展松褐天牛防治，综合运用人工地面防治、飞机防治、引诱剂防治、诱捕器诱杀等技术，最大程度降低虫口密度，减少传播扩散几率，切断松材线虫病扩展蔓延的途径。

四、夯实防控工作责任

各镇（办）和县林业局要认真实行主要领导负责制，严格落实“双线”目标责任，将松材线虫病防控任务纳入年度目标责任考核，定期督导检查和评比考核。县财政局要将防控经费纳入同级财政预算，全面落实森林保险配套资金，确保防治工作顺利开展。县林业局要切实做好疫情监测调查、检疫封锁、技术指导、检查验收等工作，组织开展林业有害生物森林保险，及时刊播预警预报信息。交通、住建、电力、通讯、气象等有关部门要全力配合做好检疫监管执法、防控报务指导工作。县政府将按国家有关奖惩制度，对松材线虫病防控工作成绩显著的单位和个人通报表扬。对预防除治不力，造成重大损失的，将追究相关单位和人员责任。

洋县人民政府办公室
