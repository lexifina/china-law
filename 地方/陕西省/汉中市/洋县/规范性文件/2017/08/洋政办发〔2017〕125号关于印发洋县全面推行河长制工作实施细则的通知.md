# 洋政办发〔2017〕125号关于印发洋县全面推行河长制工作实施细则的通知

洋政办发〔2017〕125号

洋县人民政府办公室

关于印发洋县全面推行河长制工作

实施细则的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县全面推行河长制工作实施细则》已经县政府同意，现印发给你们，请认真组织实施。

洋县人民政府办公室

2017年5月25日

洋县全面推行河长制工作实施细则

为深入贯彻中省市全面推行河长制文件精神，认真落实《洋县全面推行河长制实施方案》要求，全面推行我县河长制工作，结合我县实际，制定如下实施细则。

一、总体要求

全面贯彻落实党的十八大和十八届三中、四中、五中、六中全会精神，深入学习贯彻习近平总书记系列重要讲话特别是来陕视察重要讲话精神，坚持“生态优先、绿色发展，党政领导、部门联动，问题导向、因地制宜，强化监督、严格考核”的基本原则和“节水优先、空间均衡、系统治理、两手发力”的工作方针，以加强水管理、保护水资源、防治水污染、改善水环境、修复水生态为主要任务，构建责任明确、协调有序、监管严格、运行有效的河长管理制度，为维护我县健康水环境、实现河道功能永续利用提供制度保障。确保到2018年底前，在汉江干流、19条入汉江支流，全面建立以县委、县政府主要领导负责制为核心的县、镇（办）两级河长体系，有效遏制乱倒乱排、乱采乱挖、乱占乱建、乱围乱堵等现象，打造“水清岸绿、生态健康、自然优美、人水和谐”的河道环境。

二、重点工作

（一）编制实施方案。按照《洋县全面推行河长制实施方案》和工作计划表要求，制定镇（办）河长制实施方案，细化分解阶段性目标任务，明确时间节点，按期推进相关工作。

（二）推进一河一策。坚持问题导向，开展“一河一策”水系摸底和江河排污口调查，科学制定“一河一策”方案，逐步建立长效管理机制。完善和公布汉江河洋县段、湑水河、坪堵河、沙河、溢水河、党水河、桑园河、酉水河、茅坪河、八里关河、金水河、子午河、清溪河、后坝河、天宁寺河、龙亭河、沙溪河、桃溪河、吊坝河共19条河流的摸底情况，年底前建立河流基础数据库。

（三）强化项目支撑。对照中省市全面推行河长制主要任务，坚持项目推动，积极推进相关整治项目落实，每年安排一批重点项目有序实施。

（四）做好污染防治。重点开展汉江水污染防治保护突出问题整治，加强工矿企业及工业园区、有机产业园区水污染防治监督管理，城镇生活污水治理，推动畜禽养殖污染控制，推进农业化学肥料、农药零增长治理，加大农村生活垃圾及生活污水整治。

（五）健全执法监管。完善江河保护管理制度，建立水行政主管部门牵头，环保、电力、朱鹮保护、农业、林业、住建、国土资源、交通运输、公安等相关部门参与负责的联合执法机制，严厉打击破坏江河库渠生态环境等违法犯罪行为。

三、保障措施

（一）加强组织领导。县、镇、村各级领导要带头落实河长制工作，切实抓好各项具体任务，适时召开河长制工作推进会和部署会。积极落实河道管理保护经费，建立长效、稳定的河道管理保护投入机制。

（二）建立工作机制。县河长制办公室要迅速落实相关工作人员和经费，研究制定河长制联席会议、考核问责、信息共享和成员单位职责等配套制度，落实县镇（办）二级河长管理责任，构建责任明确、协调有序、监管严格、保护有力的河库管理保护机制。

（三）强化部门协作。县河长制责任部门要密切配合，加强沟通，共同推进河道管理保护工作。要充分发挥职能优势，协调联动，形成合力，切实加强对河长制工作业务指导和政策支持。

（四）严格考核问责。将河长制工作纳入镇（办）目标责任考核，量化考核指标，考核结果作为党政领导班子及有关成员综合考核评价的重要依据。加大考核督查力度，定期通报各镇（办）河长制推行进展，对工作措施不到位、河长制推进不力的，严格追究责任。

（五）加强社会监督。8月底前，在县政府网站公布区

域和流域河流河长名单，设立投诉举报平台，公布举报电话，主动接受社会监督。加大宣传引导，增强社会各界水资源水环境保护责任意识和参与意识，营造全民参与河长制的良好氛围。
