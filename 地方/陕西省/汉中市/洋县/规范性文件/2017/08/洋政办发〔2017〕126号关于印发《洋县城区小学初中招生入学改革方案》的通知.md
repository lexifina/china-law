# 洋政办发〔2017〕126号关于印发《洋县城区小学初中招生入学改革方案》的通知

洋政办发〔2017〕126号

洋县人民政府办公室

关于印发《洋县城区小学初中招生入学改革方案》的通知

各镇人民政府、办事处，县政府各工作部门、直属机构：

《洋县城区小学初中招生入学改革方案》已经县政府同意，现印发你们，请遵照执行。

洋县人民政府办公室

2017年8月20日

洋县城区小学初中招生入学改革方案

2017年秋季学期，城南九年制学校即将开门招生。为贯彻落实《陕西省教育厅转发教育部办公厅关于做好2017年义务教育招生入学工作的通知》（陕教基一办〔2017〕10号）精神，确保义务教育免试划片就近入学政策全覆盖落实到位，依法保障县域内适龄儿童少年就近入学的权利，根据中省市有关文件和《洋县城区小学招生入学改革方案》（洋政办发〔2015〕88号）精神，特制定本方案。

一、指导思想

以认真落实义务教育免试就近入学政策、努力办好人民满意的教育为宗旨，深入贯彻《中华人民共和国义务教育法》等法律法规，全面规范县域内义务教育学校招生入学行为，逐步彰显招生入学在促进教育均衡、提高教育质量、推进教育公平等方面的导向作用，确保招生入学工作依法依规、规范有序、公正公平、公开透明，确保教育资源充分利用，全面推进县域教育均衡发展。

二、工作目标

坚持依法治教、学位管理，全面推进城区小学初中招生实行划片免试就近入学，遏制择校现象，着力化解南街小学、青年路小学、城西小学、书院初中生源不均衡现象和超大校额、超大班额，确保适龄儿童少年100%按时入学，2017年秋季学期全县小学和农村初中及城区初中一年级消除66人以上超大班额目标，2020年全县基本消除56人以上大班额，进城落户和进城务工就业随迁子女按政策接受义务教育。

三、工作原则

1.依法行政原则。以《中华人民共和国义务教育法》《陕西省实施〈中华人民共和国义务教育法〉办法》《陕西省义务教育阶段学生学籍管理办法》、中省市有关义务教育招生入学文件和《洋县城区小学招生入学改革方案》等为政策依据，依法推进城区小学初中招生入学改革工作。

2.均衡发展原则。在做好城区小学初中招生入学工作的同时，着力加强农村义务教育学校建设、深入推进校长教师交流轮岗、积极落实乡村教师生活补助、稳步推进洋县中学招生名额向农村初中倾斜，不断提高农村义务教育学校发展水平和办学效益，统筹兼顾城乡义务教育均衡发展。

3.安全就近原则。依法履行县级人民政府合理配置教育资源、促进义务教育均衡发展的责任，切实保障所有适龄儿童依法、平等、安全、免试就近入学的权利。

4.平稳有序原则。科学研判县域教育实际、民生实际、适龄儿童分布范围、群众对优质教育资源需求等因素，制定划片入学和学生分流、师资调配、资源配置、风险防控等实施方案，确保城区小学初中招生入学改革工作平稳有序。

5.提高质量原则。以招生入学工作为突破口，全面深化教育改革，推进依法治教，化解城区大校额、大班额，面向全体学生，全面提高教育质量。

6.公平公正原则。主动征求社会各界意见建议，及时回应群众关切，广泛接受群众监督，确保城区小学初中招生入学工作程序公开、公平公正、阳光运行，真正使招生入学工作利民惠生、有序实施，让人民群众切实享受到改革的利益。

四、学区划分

南街小学：西以西环路为界、北以文明路为界、南以南环路为界、东以东环南路为界，具体包括南街社区以及东城、东街、北街、西街社区延伸部分。

青年路小学：西以洋华路为界、南以文明路为界、北以牛头山下为界、东以原贯溪辖区西边界为界（不包含城南学校小学部学区），具体包括青年路社区、明珠社区以及东城、东街、北街、巩家槽社区延伸部分。

城西小学：南以108路为界、西以竹园村（含）为界、东以洋华路为界，具体包括竹园村、五郎庙社区、洋州新区社区以及西街社区、纸坊街村延伸部分。

城南学校小学部：东以天宁寺河为界，北以文明路—真符路—和平路—东环路—南环路为界。

城北完小：李家村社区以及纸坊街村、巩家槽社区延伸部分。

书院初中和城南学校初中部：总学区包含以上南街小学、青年路小学、城西小学和城南学校小学部的各学区，南北分界线为和平路东段—朝阳路—东大街—中山街—西街。

民办实验学校小学、初中：面向全县招生。

五、招生办法

根据《陕西省实施〈中华人民共和国义务教育法〉办法》《陕西省义务教育阶段学生学籍管理办法》《陕西省教育厅关于切实做好全省义务教育招生入学工作的通知》《陕西省人民政府办公厅关于加快中西部教育发展的实施意见》《教育部办公厅关于做好2017年义务教育招生入学工作的通知》《洋县城区小学招生入学改革方案》等法规政策文件精神，我县城区小学初中的招生坚持依法治教、学位管理的办法操作执行。

（一）小学一年级入学

根据《洋县城区小学招生入学改革方案》精神，从2017年秋季学期开始，截止当年8月31日年满六周岁，严格按照“户籍登记为主、住房登记为辅、就业经营补充”的入学登记原则划片免试就近入学。凡不符合入学登记原则的适龄儿童，按照“谁招生、谁负责”的原则，由原就读幼儿园劝其返回户籍所在地入学就读。以上城区公办小学以新划定的学区范围，按照入学登记原则，具体登记办法如下：

1.属以上学区内户籍的学生，按照户籍登记与住房登记相结合的方式确定入学：

（1）户籍与实际居住地相符，由学生父母（法定监护人）持户口簿和儿童《预防接种证》到对应学区小学登记。

（2）户籍与实际住址不符，可选择与实际居住地较近的对应学区小学入学。由学生父母（法定监护人）持户口簿、儿童《预防接种证》、房产证明到对应学区小学登记。

2.本县非以上学区户籍学生，按照住房登记与就业经营相结合的方式确定入学。具体为：

（1）在以上学区范围内有房产的，由学生父母（法定监护人）持全家户口簿、儿童《预防接种证》、房产证明到对应学区小学登记。

（2）在以上学区范围无房产，但学生父母（法定监护人）在该学区范围内实际经商核查属实的，由学生父母（法定监护人）持全家户口簿、儿童《预防接种证》、学生父母（法定监护人）的营业执照和相应执业资格证到对应学区小学登记。对应小学学位不足的，由教体局统筹调剂解决。

3.其它情况：

（1）随军子女、随父母工作调动人员子女的入学与户籍在学区范围学生同等对待，持父或母所在单位出具工作关系证明、工资证明、户口簿、儿童《预防接种证》到对应学区小学登记。

（2）进城务工人员随迁子女入学，由学生父母（法定监护人）持全家户口簿、随迁子女及其父母（法定监护人）本人在洋县县城实际居住证明（即居住证）、儿童《预防接种证》到对应学区小学登记。对应小学学位不足的，由教体局统筹调剂解决。

（二）小学二至六年级入学

1.原东咀小学学生直升城南学校。

2.非城区小学学生，但符合城区“户籍登记为主、住房登记为辅、就业经营补充”条件、确需转入城区公办小学的，统一安排至城南学校，城南学校学位不足的，由教体局统筹调剂解决。

3.南街小学、青年路小学、城西小学实行学位管理，进行合理分流，分流实行指标控制。各校学位及分流指标由教体局根据办学资源合理确定，学生分流办法、措施由各校自行确定。总体要实现2017年秋季学期，南街小学、青年路小学班额不超过65人，城西小学班额不超过55人，城南学校班额不超过50人，城区各小学各年级人数逐步趋于均衡、与办学资源基本相称。2020年，全县基本消除56人以上大班额。

（三）初中一年级招生

1.城北小学毕业生直升纸坊初中，原东咀小学毕业生直升城南学校。

2.从2017年秋季学期开始，南街小学、青年路小学、城西小学毕业生，分流办法如下：

（1）以新划定的学区范围，属城南学校初中部或书院初中学区的，严格按照“户籍登记为主、住房登记为辅、就业经营补充”的入学登记原则划片免试就近在城南学校或书院初中入学登记。具体登记办法与小学一年级相同。

（2）不符合三项入学原则的，鼓励回户籍所在地初中免试就近入学，或可选择民办实验学校入学。

3.非城区公办小学毕业生，符合城区“户籍登记为主、住房登记为辅、就业经营补充”、确需就读城区公办初中一年级的，由教体局根据学位情况统筹安排解决。

（四）有关表述解释

1.房产证明：有房产证的出具由房产管理部门核发的正规房产证书；自建房或小产权房无房产证的，出具有关合法票据和由社区（村）、街道办审核确认的书面证明；商品房暂未办理房产证的，出具房管局备案登记的购房合同和交费票据；移民搬迁房的出具移民办证明和交费票据。

2.进城务工人员随迁子女，即户籍属外县<区>，随务工父母到我县城区<同住>并需要入学接受义务教育的适龄儿童。

3.适龄儿童无户口簿的要出具医学出生证明。

六、保障措施

1.加强组织领导。成立由县政府分管副县长任组长，教体、发改、编办、人社、财政、公安、监察、住建、卫计、水利、市场监管、信访、交通、文广、电信、移动、广电网络公司、教育督导室、洋州办、纸坊办、戚氏办等单位为成员的洋县城区小学初中招生入学改革工作领导小组，建立会商协调机制，研究解决落实招生入学改革过程中出现的问题。

2.加快城区学校建设。各相关职能部门要在各自的职能范围内积极做好新建城区学校及周边相关设施设备建设，确保学校的教育教学需求和师生生活及群众出行的安全方便。教体局要根据教育教学需求，积极做好新建学校的各种功能部室建设、教育教学设施添置，积极营造健康向上、独具特色的校园文化氛围。同时，要选优配强新建学校领导班子，积极做好教师调配工作和学生分流工作，确保师生在校生活有保障、学习有质量。

3.抓好农村学校建设。要继续以义教均衡和双高双普创建为契机，继续加快农村学校硬件建设、环境建设和教师队伍建设，加强教育教学管理和内涵发展提升，不断提高农村学校办学水平和办学效益，努力办好人民群众家门口学校，全面促进城乡义务教育均衡发展，全面提高教育质量。

4.切实规范办园行为。教体局要切实加大对幼儿园办园行为的监管力度，对违规招生和办班的，属公办幼儿园的进行通报批评、取消幼儿园和园长评选各类先进资格，并限期整改；属民办幼儿园的暂停招生、取消普惠性幼儿园资质，并限期整改，从源头上扼制城区公民办幼儿园无序招生行为。

5.做好舆论宣传引导。通过电视、门户网站、新媒体、现场参观等方式，加强对新建学校校园环境、名优教师、领导团队的宣传。加强义务教育招生入学政策和规范幼儿园办园行为意见的宣传和解读，让社会各界了解改革的总体情况，引导家长充分认识就近入学对孩子健康成长的价值和意义，争取社会各界对城区小学初中招生入学改革工作的理解与支持，营造全社会共同关心支持教育领域综合改革的良好氛围。

6.严肃工作纪律。各镇（办）、各部门要履职尽责，协调联动，依法行政，务实工作，坚决杜绝在户籍、房产、务工、经商证明等方面弄虚作假的违纪违法行为，坚决打击各类违法上访行为，坚决扼制各种批条子、打招呼、讲人情、走关系等人为干预行为，如有违反和群众举报，一经查实，严肃追究相关人员责任。
