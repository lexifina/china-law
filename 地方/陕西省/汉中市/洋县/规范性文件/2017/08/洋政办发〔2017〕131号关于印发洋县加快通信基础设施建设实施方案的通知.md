# 洋政办发〔2017〕131号关于印发洋县加快通信基础设施建设实施方案的通知

洋政办发〔2017〕131号

洋县人民政府办公室关于

印发洋县加快通信基础设施建设实施方案的

通 知

各镇人民政府，街道办事处，县政府各工作部门、直属机构、市管单位：

《洋县加快通信基础设施建设实施方案》已经县政府同意，现印发给你们，请结合实际，认真组织实施。

洋县人民政府办公室

2017年8月22日

洋县加快通信基础设施建设实施方案

为深入贯彻省、市政府关于加快通信基础设施建设推进会议精神，进一步提升我县通信基础设施建设速度，提升支撑能力和服务水平，落实好《陕西省加快通信基础设施建设行动计划》，现结合《“智慧汉中”总体规划（2016-2020）》制定本实施方案。

一、总体目标

到2017年底，全县固定宽带平均可用下载速率大幅提升，达到13.5Mbps。新增光缆总长度0.8万公里，新增光纤入户端口7.5万个。城市住宅小区光纤覆盖率达到99%，新建4G基站总数270个。协调免费开放本地区公共区域站址9个，新增移动网络室内分布系统4个区域。全县城区、重点区域及公共场所4G网络深度覆盖率达到95%以上。

（一）提升光纤网络支撑能力

到2017年底，全县新增光缆总长度0.8万公里，达到2.6万公里，新增光纤到户端口7.5万个，达到35万个，互联网出口总带宽由480G提升至880G，切实提升用户上网体验。全县固定宽带平均可用下载速率达到13.5Mbps。

（二）提高光网城市质量

到2017年底，城市既有住宅小区光纤改造率达到99%，光纤用户数量达到70%，光纤到户城市家庭具备100Mbps接入能力，光网用户接入宽带全部免费提升至20Mbps，50Mbps以上用户达到60%。

（三）推进电信普遍服务

到2017年底，在全县全面完成电信普遍服务试点项目，加大农村宽带网络建设力度，行政村光纤覆盖率达到99%。

（四）加快移动网络覆盖

到2017年底，全县新建基站物理站址270个,4G用户突破20万户。全县城区、重点区域及公共场所全覆盖，农村行政村4G覆盖率分别为：移动4G网络覆盖达到95%、电信4G网络覆盖达到70.62%、联通4G网络覆盖达到27%，移动互联网普及率超过85%。免费开放公共区域站址9个，新增移动网络室内分布系统4个区域。

二、总体要求

以“创新、协调、绿色、开放、共享”五大发展理念为指引，深入研究工作重点，协调解决核心难题，积极推进通信基础设施建设，着力缩小“数字鸿沟”。

三、重点任务

（一）按照省通信管理局制定的网络架构优化方案，根据省市公司工作计划制定年度工作计划。明确目标任务，加大投资建设力度，及时升级固定宽带用户接入点和骨干网节点设备，强化网络流量疏通能力。加快实施光纤入户工程，既有小区基本实现“光进铜退”。大力推进电信普遍服务项目，确保按时完成建设任务。要按照全县基站布点规划，优先布局城区、重点区域和公共场所。加快室内分布系统建设，全力消除楼宇内部、电梯、地下场所等移动网络盲点。（电信公司、移动公司、联通公司、广电网络公司负责）

（二）认真执行省市制定的通信基础设施服务能力检测及评估体系，严格按照标准、方法，定期进行评测，将结果向企业和社会公示，帮助电信企业不断提升服务质量和能力。按照县通信基础设施建设工作组的决策部署和工作要求，督促各镇办、各部门抓好贯彻落实。（发改局、政府信息中心负责）

（三）2017年7月组织完成全县通信基站布点专项规划的编制和报批工作。实施服务质量提升行动，加大通信市场监管力度，规范电信企业竞争行为，充分发挥“12300”用户申诉平台的作用，按照法定程序调解用户与电信企业争议，促进电信服务质量改善提升。实施提速降费行动，按照全省制定的2017年电信业务降费计划，积极组织实施提速降费行动。加强电信资费监管执法检查，督促各电信企业实现提速降费目标。实施网络架构优化行动，进一步扩容我县互联网出口带宽，督促电信企业加大基础设施投入、加快网络设备升级，强化网络流量疏通能力。实施好国家电信普遍服务试点项目。积极申请资金补助，争取试点示范项目，着力提升我县通信基础设施建设水平。（电信公司、移动公司、联通公司、广电网络公司负责）

（四）根据《住房城乡建设部工业和信息化部关于贯彻落实光纤到户国家标准的通知》（建标〔2013〕36号）精神，严格落实新建住宅项目竣工通信设施验收备案制度，进一步规范新建住宅预先铺设通信配套设施建设，实现与住宅建筑投资主体同一化、设计一体化、施工同步化、验收标准化。督导加大对通信配套设施资源共享的监管力度，严格按照建设管理程序，积极支持相关通信运营企业建设，为光纤改造工程施工提供便利条件。落实建设行政主管部门、业主委员会、街道办事处相关责任，严厉查处建设单位、物业服务企业阻挠光纤到户改造和通信基站建设等违法违规行为。（住建局负责）

（五）结合“放管服”改革，优化环评审批程序，细化铁塔报备登记和自查检测、县环保部门负责基站电磁辐射事后监管和问题查处的工作流程。加强电磁辐射科普知识宣传力度，促进公众对通信基站电磁辐射的科学认知。（环保局、教体局负责）

（六）按照《陕西省人民政府办公厅关于加快高速宽带网络建设推进网络提速降费的实施意见》（陕政办发〔2015〕95号）精神，切实采取有力措施，落实公共区域全部免费开放要求，确保政府机关、学校、医院、展馆、工业园区、旅游景点、机场、公路沿线、铁路沿线、桥梁隧道、铁路车站、地铁沿线、公路客运站、码头等所属建筑物以及路灯、道路指示牌、绿化区等公共设施场所空间全部开放，支持光纤铺设和4G基站建设。（住建局、交通局负责）

（七）在全县范围内，组织开展专项检查行动，严厉查处通信基础设施建设中针对电信企业的不合理收费行为。加强电信资费监管执法检查，维护消费者合法权益。（物价局负责）

（八）加大对通信、广电基础设施供电保障力度，建立用电报装、线路租挂、电力抢修等保障机制，提高农村通信基础设施办电效率，缩短通信基础设施办理用电时限。引导通讯设施用电设备合理选型，有效降低通信基础设施能耗成本。（地电洋县分公司负责）

（九）积极争取“宽带中国”“宽带乡村”示范工程等国家通信基础设施项目和资金支持。协调督导做好宽带网络提速降费措施落实工作，制定引进和鼓励互联网内容信息源提供商在我县落户的政策措施。广泛宣传通信基础设施安全保护政策法规，加大打击破坏通信基础设施的力度，确保通信基础设施安全。做好网络安全、通信基础设施保护法律法规宣传教育进校园工作。（发改局、教体局、公安局、文广局负责）

（十）切实将通信基础设施建设纳入议事日程，加强组织领导，强力推进各项工作落实。8月底要完成通信基站布点专项规划审批，并纳入城乡规划和控制性详细规划。加强基站站址、通信机房和线路等通信基础设施建设的用地保障，优化基站环评流程，主动协调解决基站建设、光纤到户和土地征用过程中出现的矛盾和问题。加大监督及推进力度，年底前全面完成电信普遍服务试点项目。（发改局、国土局、财政局、政府信息中心、各镇办负责）

（二）建立月度报送制度

各有关部门要细化工作方案，明确责任主体，列出月工作进度表，每月22日前向工作组办公室报告进展情况和下月度工作计划。各运营商要细化工作任务，抓好组织实施，并按月列出工作进度表，每月22日前向工作组办公室报告进展情况、需要协调的问题和下月度工作计划。

（三）认真执行省上制定的服务能力检测及评估体系

加强督导检查和考核考评。8月31日前完成工作机制和细化方案；8月底前完成规划编制，完成网络架构优化方案；9月初完成规划审批；9月中旬前所有工作全面铺开；10月底前完成所有铁塔基站布点，全面取消国内长途和漫游费；11月底前所有基站挂机运行，所有老旧小区完成改造任务；12月初完成电信普遍服务任务；12月10日前县委县政府将对各镇办、各部门落实情况组织验收考评，考评结果将作为年度目标责任考核参考，并在全县通报。

各镇办、部门要根据实际建立相应的工作机制，于8月31日前将有关工作机制，召集人和联络员信息报送县发改局；各电信企业于8月31日前将工作方案和年度工作计划报送县发改局。
