# 洋政办发〔2017〕133号关于印发洋县2016年至2020年审计全覆盖实施方案的通知

洋政办发〔2017〕133号

洋县人民政府办公室关于

印发洋县2016年至2020年审计全覆盖

实施方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构：

现将《洋县2016年至2020年审计全覆盖实施方案》印发给你们，请结合实际，认真贯彻落实。

洋县人民政府办公室

2017年8月24日

洋县2016年至2020年

审计全覆盖实施方案

为确保在“十三五”期间实现审计全覆盖，充分发挥审计监督作用，根据中办、国办《关于完善审计制度若干重大问题的框架意见》及相关配套文件、《国务院关于加强审计工作的意见》和《汉中市“十三五”审计工作发展规划》等规定，制定本实施方案。

一、总体要求

实现审计全覆盖是党中央、国务院和省委、省政府对审计工作提出的明确要求。“十三五”期间，要按照协调推进“四个全面”战略布局的要求，紧紧围绕提高发展质量和效益这个中心，贯彻供给侧结构性改革这条主线，贯彻党政同责、同责同审要求，对依法属于审计监督范围的所有管理分配使用公共资金、国有资产、国有资源的部门和单位，以及党政主要领导干部和国有企事业单位领导人员履行经济责任情况进行审计，按照科学规划、统筹安排、分类实施的要求，区别不同审计对象，分类确定审计重点和审计频次，做到应审尽审、凡审必严、严肃问责。对重点部门要每年审计，其他审计对象“十三五”期间至少审计1次，对重点部门以及关键岗位的领导干部任期内至少审计1次，对重大政策措施、重大投资项目、重点专项资金和重大突发事件开展跟踪审计，坚持问题导向，对问题突出、群众反映强烈的单位及领导干部，有针对性地增加审计频次，确保实现有重点、有步骤、有深度、有成效的审计全覆盖，更好地发挥审计在党和国家监督体系中的重要作用。

二、政策落实跟踪审计

㈠审计目标。持续跟踪审计国家重大政策措施和宏观调控部署落实情况，着力推动项目落地、资金保障、简政放权、风险防范，促进政策落实到位，发挥审计保障作用。

㈡审计重点。重点检查各部门、各单位贯彻落实国家重大政策措施的具体部署、执行进度和实际效果，及时发现和纠正有令不行、有禁不止行为，促进政令畅通。严肃揭露和查处不作为、慢作为、假作为等重大履职不到位，重大失职渎职、重大损失浪费、重大风险隐患和重大违纪违法等问题，及时揭示反映改革措施不配套、不衔接甚至相互矛盾、相互抵消等重大机制体制问题，大力推动制度创新力度、大力推动深化改革。要紧密结合不同时期、不同行业、不同部门单位的实际情况，确定审计内容，重点关注“三去一降一步”重点任务、国家扶贫政策、科技创新政策贯彻落实情况。

㈢组织实施。“十三五”期间，持续对国家重大政策措施贯彻落实情况进行跟踪审计，同时各年度安排的所有审计项目都要把国家重大政策措施贯彻落实情况作为重要审计内容。根据省委、省政府的要求，把各级政府追赶超越经济社会发展目标完成情况与国家重大政策措施落实情况审计有机结合起来。

三、财政审计

主要包括：县级财政预算执行审计、部门预算执行及决算草案审计、下级政府财政收支决算审计、税收征管审计。

㈠财政预算执行及决算草案审计

1、审计目标。促进深化财税体制改革、推动建立现代财政制度、增强国家政策执行效果、保障公共资金高效使用。

2、审计重点。重点关注财政体制运行情况、财政政策执行情况、完善政府预算体系、财政支出和转移支付资金预算管理使用、预算绩效管理、政府债务管理等方面；推进政府资产报告制度、权责发生制综合财政报告制度、财政库底目标余额管理制度等。

3、组织实施。每年对同级预算执行情况进行审计，监督检查预算执行的真实性、合法性、效益性。

㈡部门预算执行及决算草案审计

1、审计目标。促进提高公共资金使用绩效，促进依法履职尽责，严格预算约束。

2、审计重点。持续关注贯彻中央八项规定精神及国务院“约法三章”要求的落实，三公经费和会议费支出等情况。加强对楼堂馆所建设和公车改革情况的审计，加强对政府采购及政策功能的审计力度。

3、组织实施。“十三五”期间，部门预算执行和决算草案审计要力争做到一级预算执行单位审计全覆盖。要逐步建立部门决算草案审签制度，对重点单位每年审计；对重点审计之外的部门和单位采取内审自查和审计抽查方式进行监督，审计抽查单位应不低于自查单位的30%。

㈢下级政府财政收支决算审计

1、审计目标。以预算执行和决算的真实性、完整性为基础，保障财政资金安全，促进公共资金安全高效使用，促进执行统一财税政策，促进增强财政政策的有效性。

2、审计重点。重点关注各镇（办）财政体制运行情况，执行统一财税政策情况，上级转移支付资金预算管理和使用情况，政府债务管理情况等。

3、组织实施。“十三五”期间，每年审计3至4个镇（办）财政收支决算，并根据工作需要延伸到村级财务收支情况。镇（办）财政收支决算审计要与地方党政领导干部经济责任审计统筹安排。

㈣税收征管审计

1、审计目标。促进建立税种科学、结构优化、法律健全、规范公平、征管高效的现代税收制度。

2、审计重点。围绕优化税制结构、完善税收功能、规范税收政策、推进依法治税，加强对税制改革和非税收入改革推进情况审计，重点税种收入征收审计，强化对税收征管机制、税收优惠政策落实和重大税收制度的调查、分析和评估。

3、组织实施。“十三五”期间，每年对地方税务部门税收征管情况进行审计。税收征管情况审计作为对财政预算执行审计的主要内容，与重大政策措施跟踪审计和追赶超越审计相结合。

四、企业审计

㈠审计目标。促进国有企业提质增效，保值增值，推动国有企业深化改革，增强国有经济活力和抗风险能力，维护国有资本安全。

㈡审计重点。重点检查国有资产监管机构履行监管职责，企业贯彻落实国家重大政策措施情况及效果，国有企业改革推进，国有资产的真实、完整和保值增值，资产负债损益，重大投资决策及投资绩效，发展潜力和风险隐患，破产企业的清算，同时结合企业审计核查社会审计机构出具的相关审计报告，企业审计要与经济责任审计相结合。

㈢组织实施。结合县级部门预算执行审计，组织对县级国有、国有资本控股或占主导地位的企业进行审计，通过采取重大政策落实、财务收支、经济责任、专项审计及自查抽查等方式，确保“十三五”期间至少审计1次。

五、民生审计

主要包括：扶贫和涉农审计、社会保障审计、科教文卫等领域审计和重大突发公共事件跟踪审计等。“十三五”期间，要加大对扶贫、三农、就业、社会保障、科技、文化、教育、救灾等民生资金和项目的审计力度，根据资金流向，从政策要求、预算安排、资金拨付追踪到项目和个人，确保惠民政策落地生根、不断完善和发挥实效。

㈠扶贫和涉农资金

1、审计目标。紧紧围绕中央对扶贫脱贫、“三农”工作的部署要求，以农业供给侧改革为主线，推动涉农资金、扶贫资金整合和统筹使用，提高资金管理绩效，促进强农惠农政策落实，推动农村改革和新农村建设，促进转变农业发展方式和加快农业现代化建设，促进精准扶贫、精准脱贫，打赢脱贫攻坚战，切实维护农民利益。

2、审计重点。重点检查国家扶贫脱贫和涉农政策贯彻落实情况，政府及主管部门履职情况，扶贫和涉农项目建设管理实施情况，以及相关脱贫工作责任落实情况。

3、组织实施。“十三五”期间，持续组织对扶贫政策贯彻落实情况进行跟踪审计，组织对“农林水”专项资金进行审计。要与财政决算审计和重大政策措施落实跟踪审计统筹安排。

㈡社会保障审计

1、审计目标。促进社会保障资金安全规范运行，推进建立健全以政府为主提供基本保障、以市场为主满足多层次需求的社会保障体系，推动健全社会救助体系和社会福利制度，促进建立更加公平和持续的社会保障制度。

2、审计重点。重点对养老、医疗、工伤、失业、生育等社会保险基金、低保和优抚资金、保障性安居工程、住房公积金、住宅维修基金、捐赠资金、彩票公益金、再就业等专项资金进行审计。主要关注社保领域国家有关重大政策措施贯彻落实情况，相关改革举措推进情况、有关基金和资金的征收、管理、分配和使用情况，有关项目建设管理情况。

3、组织实施。“十三五”期间，持续组织实施对保障性安居工程审计，对其他社会保障资金和项目，结合预算执行审计、财政决算审计、重大政策措施贯彻落实跟踪审计或专项资金审计，开展有重点、有层次的审计监督。

㈢教科文卫等领域审计

1、审计目标。促进科教文卫等领域规范管理、完善制度、改革创新，提高资金管理使用绩效，健全国家基本公共服务制度，完善基本公共服务体系，提高基本公共服务共建能力和共享水平，保障和完善民生。

2、审计重点。重点检查中、省、市关于教科文卫等领域重大政策措施贯彻落实情况，科技、教体、文化和医疗卫生资金的管理、分配、使用和绩效情况，有关教科文卫领域重点民生项目的建设管理实施情况，及时反映教科文卫领域改革中出现的新情况新问题，提出对策建议，推动深化改革。

3、组织实施。“十三五”期间，结合重大政策措施贯彻落实跟踪审计，持续对科技创新政策贯彻落实情况进行审计，组织对教体、文化、医疗卫生等资金和项目进行审计。

㈣重大突发性公共事件跟踪审计

1、审计目标。保障重大突发性公共事件应急处置、预防预警、恢复重建等工作顺利进行。

2、审计重点。重点检查贯彻落实中省市县决策部署情况，有关资金及物资的筹集、分配、拨付、使用情况和有关项目的建设推进情况等。

3、组织实施。“十三五”期间，根据实际情况，及时组织开展重大突发性公共事件跟踪审计。

六、资源环境审计

㈠审计目标。促进全面节约和高效利用资源，加快改善生态环境，推动生态文明建设，促进形成绿色发展方式和生活方式，推动绿色发展。

㈡审计重点。对土地、矿山、水资源、森林等国有自然资源，特许经营权、排污权等国有无形资产，大气污染防治、水污染防治、环境风险防范等环境综合治理，自然生态修复和保护，领导干部履行自然资源资产管理和环境保护责任情况等进行审计。重点检查国家相关法律法规制度执行情况，贯彻执行国家重大政策措施和宏观调控部署情况，领导干部自然资源资产管理和生态环境保护责任履行情况，国有资源管理和生态环境保护部门的职责履行情况，国有重要自然资源开发利用和保护情况，重点领域、重点行业、重点地区污染防治行动规划落实情况，有关资金的征收、管理、分配和使用情况，重点资源环境保护项目的建设和运营效果情况，以及环境治理基础制度改革推进情况等。

㈢组织实施。“十三五”期间，每年组织安排资源环境审计项目特别是要加大对资源富集地区、污染严重地区、生态保护和修复重点地区的审计力度。2017年组织开展领导干部自然资源资产离任审计试点。2018年至2020年建立常态化的审计制度。要结合党政领导干部和国有企业领导人员经济责任审计项目统筹安排实施。同时，“十三五”期间，所有审计项目都要把国有资源开发利用，污染治理和生态环境保护情况作为重要审计内容。

七、经济责任审计

㈠审计目标。坚持“全面推进、突出重点、健全制度、规范管理、提高质量、深化发展”的工作思路。促进领导干部守法、守纪、守规、尽责，更好地践行创新、协调、绿色、开放、共享的发展理念，依法作为，主动作为，有效作为。

㈡审计重点。立足权力运行与责任落实，分类别确定领导干部经济责任审计的重点和频次。主要检查领导干部贯彻执行党和国家经济方针政策决策的部署情况，遵守有关法律法规和财经纪律情况，本地区本部门本单位发展规划和政策措施制定、执行情况及效果，重大决策和内部控制制度的执行情况及效果，本人遵守党风廉政建设有关规定情况等。对党员领导干部，重点监督检查贯彻落实中央政策措施责任、经济发展责任、结构调整责任、防范化解风险责任、环境保护责任、民生改善责任、廉政建设责任等。

㈢组织实施。“十三五”期间，根据工作需要，科学调配审计资源，按照《党政主要领导干部和国有企业领导人员经济责任审计规定》及其实施细则，《陕西省党政主要领导干部和国有企业领导人员经济责任审计实施办法》的规定，根据组织部门的委托建议，确定年度审计对象，根据党政同责、同责同审，坚持任中审计和离任审计相结合，经济责任审计与财政审计、资源环境审计等相结合，实现项目统筹安排，协同实施。

八、政府投资项目审计

㈠审计目标。以深化投资体制改革、优化投资结构、提高固定资产投资效益为目标，牢固树立发展、法治、改革、绩效、绿色投资审计理念，创新审计技术与方法，推进投资审计转型发展和现代化。

㈡审计重点。重点检查投资项目规划布局、投向结构和经济社会环境效益情况，重大投资政策和宏观调控的部署贯彻落实情况，重点审计项目立项决策、项目审批、征地拆迁、环境保护、工程招投标、物资采购、资金管理使用、工程质量管理和项目竣工决算等。

㈢组织实施。“十三五”期间，对洋县“十三五”规划确定的重点投资项目，“一带一路”重点建设项目，政府与社会资本合作等方式建设的重大基础公共工程进行审计监督，同时结合重大政策措施贯彻落实情况跟踪审计、经济责任审计开展投资项目审计。

九、保障措施

㈠适应新常态、践行新理念。自觉服从经济社会发展全局，紧紧围绕党和国家的中心任务、重大政策、重大决策部署，按照审计法等法律法规赋予的职责，以及中省市的要求，加大审计力度，更好地服务经济社会持续健康发展。牢固树立科学的审计理念，坚持依法审计，客观公正，鼓励创新，推动改革，正确把握改革和发展中出现的新情况新问题，正确处理严格依法与实事求是的关系，严格按照“三个区分”原则，客观审慎的做出审计结论和处理。

㈡突出和聚焦审计重点。各项审计都要准确把握审计目标、聚焦审计重点，集中力量，重点突破。坚持问题导向，严肃查处损害国家和人民利益、重大违纪违法、重大履职不到位、重大损失浪费、重大环境污染和资源毁损、重大风险隐患等问题。要注意点面结合、深度解剖，通过揭示典型性、倾向性问题，推动建立健全体制机制，充分发挥审计的建设性作用。

㈢大力创新审计组织管理。进一步创新审计管理模式和组织方式，统筹安排各类审计项目，加大资源整合力度，实现成果和信息共享。加强与组织人事、纪检监察、司法机关以及其他主管部门的沟通协调，推动审计结果运用最大化。加强内部审计的业务指导和监督，充分利用内部审计成果；根据工作需要购买社会服务，聘请有关专业人员提供支持，弥补审计力量不足。

㈣全面推进数字化审计方式。建立完善审计数据中心，加大数据集中和关联分析力度，全面推进数字化审计方式，努力实现由单点离散审计向多点联动审计转变，由局部审计向全覆盖审计转变；静态审计和动态审计相结合，事后审计和事中审计相结合，微观审计和宏观审计相结合。同时围绕国家大数据战略和“互联网+”行动，加大对信息化建设项目及信息系统的审计力度。

㈤着力加强审计队伍建设。始终坚持党对审计事业的领导。全面加强审计队伍的政治、思想、组织、作风、能力和制度建设，坚持从严管理审计队伍，不断强化党员干部和全体审计人员的政治意识、大局意识、核心意识和看齐意识，着力打造一支政治强、业务精、作风优、纪律严的审计铁军，推进审计职业化建设，提升审计队伍专业化，为审计事业发展提供坚强的人才保障。
