# 洋政发〔2017〕31号关于印发畜禽禁养区、限养区、宜养区划定方案（试行）的通知

洋政发〔2017〕31号

洋县人民政府

关于印发畜禽禁养区、限养区、宜养区

划定方案（试行）的通知

各镇人民政府、街道办事处，县政府有关工作部门、直属机构，市管单位：

《洋县畜禽禁养区、限养区、宜养区划定方案（试行）》已经县政府同意，现印发给你们，请遵照执行。

洋县人民政府

2017年7月 25 日

洋县畜禽禁养区、限养区、宜养区划定方案（试行）

为减轻畜禽养殖业污染，保障人民群众身体健康，促进我县畜禽养殖业持续健康发展，根据《中华人民共和国环境保护法》、《动物防疫法》、《中华人民共和国畜牧法》、《畜禽规模养殖污染防治条例》、《畜禽养殖禁养区划定技术指南》等有关法律法规，按照环保部、省政府要求和中共洋县县委办公室、洋县人民政府办公室（洋办发[2017]8号）《洋县突出环境问题整改方案的通知》精神，结合我县实际，制定本方案。

一、指导思想

以控制农业面源污染、保障生态环境安全、优化畜禽养殖产业布局为目的，坚持保护环境与促进畜牧业协调发展的原则，在保护生态环境的基础上，实行统筹规划、合理布局。通过科学规划、合理布局畜禽养殖禁养区、限养区和宜养区，对现有畜禽养殖场污染进行综合整治，削减敏感区域的饲养总量，使养殖总量与环境容量有机统一，推进畜禽养殖废弃物的综合利用和无害化处理，保障和改善环境，实现畜牧业可持续发展。

二、划定的规模化畜禽养殖场标准

根据《陕西省畜禽养殖场养殖小区备案管理办法（试行）》第六条，规模化畜禽养殖场（小区）标准为：

规模畜禽养殖场：猪（≧25公斤）存栏300头以上；牛存栏100头以上；羊存栏200只以上；家禽存栏1万只以上；兔存栏1000只以上。

畜禽养殖小区：猪（≧25公斤）存栏1000头以上；牛存栏200头以上；羊存栏500只以上；家禽存栏2万只以上；兔存栏3000只以上。

三、禁养区、限养区和宜养区划定范围

（一）禁养区

畜禽禁养区是指按照法律、法规、行政规章等规定，在指定范围内禁止任何单位和个人禁止建设畜禽规模养殖场（小区）或禁止有污染物排放的畜禽规模养殖场（小区）。主要包括生活饮用水源保护区、自然保护区、风景名胜区、城镇居民区、文化教育科研区、基本农田保护区。

1、饮用水水源保护区，包括一级饮用水水源保护区和二级饮用水水源保护区的陆域范围。其中，饮水水源保护一级保护区内禁止建设规模养殖场（小区）。饮用水水源二级保护区禁止建设有污染物排放的规模养殖场(注：畜禽粪便、养殖废水、沼渣、沼液等经过无害化处理用作肥料还田，符合法律法规要求以及国家和地方相关标准不造成环境污染的，不属于排放污染物)。

2、朱鹮自然保护区、长青华阳自然保护区的核心区和缓冲区。

3、华阳景区、梨园景区、金沙湖景区的核心区禁止建设规模养殖场（小区），非核心景区，禁止建设有污染物排放的规模养殖场（小区）。

4、城区，集镇、行政村、自然村人口聚集区。

5.法律、法规、规章规定需要特殊保护的其他区域。

禁止在禁养区新建畜禽规模养殖场（小区），对现有的规模养殖场（小区），要严格限制养殖规模，已达到畜禽规模养殖场（小区）标准并向周边环境排放污染物的，依据《中华人民共和国环境保护法》第六十条和《畜禽规模养殖污染防治条例》第三十七条采取限制生产、停产整治等措施，以达到引导其自行搬出禁养区目的；情节严重的，由相关部门依法调查并形成调查处理意见，报经县人民政府批准，责令停业、关闭。

（二）限养区

限养区是禁养区和宜养区之间的过渡区域，在该过渡区域内限定畜禽养殖数量，禁止新建、扩建畜禽规模养殖场（小区）的区域。

1、一级饮用水水源保护区和二级饮用水水源保护区的陆域外延500米以内的区域。

2、距离城镇居民区、文化教育科研等人口集中区域周边500米以内的区域。

3、高速路、108国道、铁路、高铁等主要交通干线两侧500米以内的区域。

4、汉江河堤外延500米以内的区域。

5、法律、法规规定的其他限养区域。

限养区内畜禽养殖废气、废渣和废水等排放要达到《畜禽规模养殖污染防治条例》规定标准，对超过规定排放标准或排放总量指标，排放污染物或造成周围环境严重污染的规模畜禽养殖场，限期治理，无法完成限期治理的，报经县人民政府批准，依法强制搬迁或关闭。

对限养区内现有的养殖场（户）大力推广沼气工程等粪污综合治理技术，按照环境保护有关法律法规规章及政策规定，控制和缩小畜禽养殖规模，削减污染物排放总量。

（三）宜养区

除禁养区、限养区以外的区域为畜禽宜养区域。

在宜养区内新建、改建、扩建畜禽养殖场、养殖小区，应当先到县环保局进行环境影响评价，然后到县国土局进行土地备案，再到农业局进行养殖备案和动物防疫条件审核，最后到市监局办理营业执照。建设规模化畜禽养殖场、养殖小区取用水资源的，应向水行政主管部门申请办理取水许可审批手续，如需设置入河排污的，还应向水行政主管部门申请入河排污口设置审批手续，并符合陕西省水功能区区划及水利部《水功能区监督管理办法》的要求。对环境可能造成重大影响的大型畜禽养殖场、养殖小区，应当编制环境影响报告书；其他畜禽养殖场、养殖小区应当填报环境影响登记表。其污染防治措施及畜禽排泄物综合利用措施必须与主体工程同时设计、同时施工、同时投产使用，其污染物排放不得超过国家和地方规定的排放标准和总量控制要求。

宜养区内已建成的规模养殖场要严格落实畜禽废物综合利用措施，保证畜禽粪便、废水综合利用、粪污处理和无害化处理设施正常运转。

四、保障措施

（一）加强组织领导。为确保畜禽养殖“三区”划定方案落实及禁养区限养区整治工作取得明显成效，县政府将成立由农业、环保、发改、财政、住建、国土、公安等相关部门参加的畜禽污染治理专项整治工作领导小组，各镇也要成立相应的领导小组，由镇政府“一把手”负总责，认真筹划，周密部署，确保划定方案落到实处，整治行动取得显著效果，促进当地畜禽养殖朝着标准化、规模化、无害化、生态化发展，有力提升畜禽产品质量水平。

（二）明确职责，齐抓共管。县农业局负责按照限养区、宜养区有关要求对新建养殖场进行备案和防疫条件审核。指导规模养殖场（小区）建设粪污处理设施，推动实现区域畜禽养殖粪污处理种养平衡；组织开展综合利用技术示范推广，开展节水养殖、清洁生产、还田利用、生态养殖等试点示范建设，指导畜禽养殖小区（场）改进粪污处理设施和工艺。

县环保局依据《畜禽规模养殖污染防治条例》第三十七条和《环境保护法》第六十条，对在禁（限）养区内建设规模养殖场（小区）和超过污染物排放标准或超过重点污染物排放总量控制指标排放污染物的进行处理。

县国土局负责养殖业压占基本农田和非法用地的查处。优先安排对合法占地的规模养殖场（小区）迁建用地选址、审批。禁养区、限养区禁止新建和扩建规模养殖场，对在宜养区新建规模养殖场（小区）的用地要严格把关，对没有土地审批的规模养殖场严格查处。

县财政局负责安排禁养区内现有规模养殖场（小区）的迁建、关停和拆除补助资金的落实。

各镇（办）协助落实对禁养区内的规模养殖场的迁建选址和用地协调工作，做好禁养区规模养殖场的关停、迁建和拆除工作，做好限养区、宜养区的监管。

（三）严格考核。将畜牧产业发展与畜禽污染防治纳入国民经济和社会发展总体规划，切实加强对畜禽养殖污染防治工作的组织领导，纳入镇（办）和相关部门年度考核。建立约谈、监督问责制度，构建政府统一领导、部门分工协作、镇（办）属地管理、上下整体联动的工作格局。

（四）加强宣传引导。各镇（办）、各部门要充分利用电视、报刊、网络等多种媒体向全社会广泛开展多层次、多形式的宣传，特别是要大力加强面向农村的宣传，及时报道畜禽养殖废弃物综合利用的经验做法及先进典型，及时曝光对环境造成污染的违法行为，为推进畜禽养殖污染防治营造良好的舆论氛围。
