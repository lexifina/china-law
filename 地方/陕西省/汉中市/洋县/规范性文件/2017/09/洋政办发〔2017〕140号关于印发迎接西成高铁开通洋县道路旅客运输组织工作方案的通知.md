# 洋政办发〔2017〕140号关于印发迎接西成高铁开通洋县道路旅客运输组织工作方案的通知

洋政办发〔2017〕140号

洋县人民政府办公室

关于印发迎接西成高铁开通洋县道路旅客

运输组织工作方案的通知

各镇人民政府、办事处，县政府各工作部门、直属机构：

《迎接西成高铁开通洋县道路旅客运输组织工作方案》已经县政府同意，现印发你们，请认真做好贯彻落实。

洋县人民政府办公室

2017年9月7日

迎接西成高铁开通洋县道路旅客

运输组织工作方案

西成高铁开通在即，为切实做好西成高铁开通后铁路客运、公路客运、城市公交、出租汽车和旅游包车的运输组织工作，根据我县实际，制定本方案。

一、总体目标

以方便全县人民群众出行，方便外地游客到我县旅游为目标，以构建综合运输体系为引领，发挥“互联网+交通”的先导作用，通过调整旅客运输组织结构，完善优化运输配套设施，实现各种运输方式之间的高效接驳、集散和“零换乘”。

二、主要工作任务

（一）加快高铁客运站场配套服务建设。为顺利实现高铁与公路客运、城市公交、出租汽车和旅游运输的无缝衔接，县交通局与西城高铁洋县西站应科学规划、合理布局，在洋县西站广场区域内分别划设公交车停泊发车区、出租汽车停车泊位和直达主要景区（点）定线旅游客车停泊发车区。

（二）优化配置公交线路。根据洋县西站高铁发车时刻及旅客的流量、流向，通过新增或延伸公交线路，科学调配公交运力，实现高铁站与城区、重点乡镇和景区之间的直通互达。

1、新增3条公交线路:

①南环路公交车：由洋县西站始发，经五路口、南环路、果酒厂，至城南小学。

②北环路公交车：由洋县西站始发，经县运司、西环路、北环路、梨园景区，至朱鹮保护站。

③城区客运站接驳公交车：由客运公司车站始发，经文明路、县运司车站、汉运司车站，至洋县西站。

2、延伸4条公交线路：

①2路公交车：从洋县西站始发，经五路口、县运司、文明西路、文明东路、东环路、108国道、贯溪、龙泉、301，至橡岭。

②5路公交车：从洋县西站始发，经五路口、县运司、文明西路、武康路、客运公司、果酒厂、贯溪、龙亭街，至蔡伦墓。

③8路公交车：从洋县西站始发，经城西小学路口、傥滨小区、西环北路、县运司、文明西路、武康路、果酒厂、贯溪、杨家湾，至龙亭镇江。

④13路公交车：从洋县西站始发，经城西小学路口、傥滨小区、西环北路、县运司、文明西路、文明东路、东环路、108国道、贯溪、龙泉、木瓜园，至任家湾。

3、增设洋县西站过路公交车停靠点：

1路、7路、10路、11路、12路公交车在洋县西站与108国道交叉路口前后设置洋县西站公交车停靠点，以方便我县城西片区人民群众乘高铁往返出行需求。

（三）调整优化客运班线。县交通管理部门要配合开通镇巴、西乡经十天高速、西汉高速至洋县西站县际客运班线，以进一步方便未通高铁的镇巴县、西乡县人民群众就近乘坐高铁出行的实际需求。县内各运输企业应根据洋县西站高铁到站及发车时刻，调整优化或增加客运班次，最大程度地方便全县人民群众乘坐高铁。同时，要适时增开洋县西站--华阳古镇等重点景区的客运直达班车，以实现乘高铁来我县旅游的外地旅客“零换乘”运输服务目标。

（四）积极发展旅游客运。相关客运企业要紧抓高铁开通带来的旅游运输发展机遇，全力做好高铁站及县城至华阳景区、梨园景区、金沙湖景区、蔡伦墓祠、朱鹮保护站、北部五岭观光环线、青山观等景区（点）的定线旅游客运服务保障工作。同时，县内各旅行社和道路旅游客运企业要依托我县及周边县区丰富的旅游资源，大力发展接地旅游包车运输服务业务，努力实现我县周边重点景区旅游客运全覆盖。

（五）提升出租汽车服务水平。深入推进全县出租汽车行业改革，促进全县出租汽车行业和互联网融合对接，促进巡游出租汽车转型升级，规范网约出租汽车经营，逐步实现两种业态整合发展，同时加强出租汽车行业从业人员培训教育，强化出租汽车日常监管，全力提升出租汽车服务能力和服务水平，为本地群众和外地游客提供更为便捷、舒适的个性化出行服务。并在洋县西站划定必要的出租汽车停靠待客泊位，组织出租汽车有序规范运营。

（六）推进汽车租赁连锁经营。鼓励、引导、推进本地企业开展汽车租赁连锁经营业务，实现高铁站、城区和景区之间租车业务联网，提供“网上预约、异地还车”服务，构建方便、快捷、高效的汽车租赁网络，满足本地群众和外地游客租车出行需求。

（七）完善运输配套设施。对高速公路引道、城市道路和过境国省干线公路的标识标牌进一步完善，突出高铁站及重点景区指引，以方便游客自驾游需求。同时，加快景区主要道路、景区充电桩建设，积极服务新能源汽车的应用。

（八）建立道路运输应急保障体系。积极配合汉中市交通主管部门，加快12328交通运输服务监督电话呼叫中心建设，确保高铁开通前投入使用，实现交通运输行业投诉处理、信息化查询、应急指挥“一站式服务”。同时，为应对高铁客流可能发生的突然变化，确保旅客顺畅疏散，县内骨干运输企业应储备一定数量的客运运力，用于应急调度，做好应急保障。

三、保障措施

（一）成立领导机构。县政府成立迎高铁道路客运组织工作领导小组，由分管副县长任组长，县交通局局长任副组长，县发改、公安、国土、住建、交通、文旅、市监和西城高铁洋县西站等部门（单位）分管领导为成员。领导小组下设办公室，办公室设在县交通局，由副局长封成贵同志兼任主任，县运管所所长薛文继同志和交通局运管科科长张成刚同志任副主任。

（二）搞好协调配合。相关部门（单位）要加强协调配合，建立信息互通机制，适时通报任务完成情况，一同查找问题、分析原因、落实措施，共同助推工作任务顺利完成。

（三）加强督促检查。由县政府督查室牵头，县政府迎高铁道路客运组织工作领导小组办公室参与，根据工作分工、具体任务和时间节点，定期开展专项督查，按月通报责任单位工作进展情况，对未按时完成目标任务的部门（单位），将对主要领导实施约谈，确保各项工作扎实有效推进。
