# 洋政办发〔2017〕144号关于印发政府购买特殊群体有线数字电视公共文化服务工程实施方案的通知

洋政办发〔2017〕144号

洋县人民政府办公室

关于印发政府购买特殊群体有线数字电视

公共文化服务工程实施方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《政府购买特殊群体有线数字电视公共文化服务工程实施方案》已经县人民政府同意，现印发你们，请认真组织实施。

洋县人民政府办公室

2017年9月12日

政府购买特殊群体有线数字电视

公共文化服务工程实施方案

为促进我县农村精神文明和信息化建设，加快农村有线广播电视和无线WiFi覆盖工程，全面推进政府购买有线数字电视和无线宽带服务，保障广大农村群众享受到更加便捷的广播电视服务，充分占领宣传文化主阵地，根据省市相关要求及县政府2016年第11次常务会议决定，结合我县实际，制定本方案。

一、指导思想

以党的十八大及十八届三中、四中、五中全会精神为指导，以完善农村广播电视基本公共服务体系建设为中心，认真实施政府购买有线数字电视和无线宽带服务，切实解决好农村群众看电视难的问题，丰富人民群众精神文化生活。

二、实施范围

一是省级美丽乡村建设示范村； 二是磨子桥、李家村、西南坝三个大型移民集中安置点；三是电商扶贫重点村。以上三类特殊群体累计涉及家庭户32828户，其中除建档立卡精准扶贫户6431户已经享受了免费电视服务政策，不再重复享受政策外，计划安装数字电视主终端26397个。计划安装无线wifi热点30个（建档立卡精准贫困村除外）。通过实施政府购买有线电视服务后，在原有接收5 0多套卫星电视节目的基础上，增加本省、市、县电视频道为主的高清电视节目和时移回看及点播功能，并将我县自办电视节目进入陕西广电网络点播平台，实现在陕西省域内任意广电互动终端的点播功能，为宣传推介洋县，扩大洋县知名度做出有益的探索和尝试。

三、实施方式

采取“企业投资建网、政府购买服务”方式，按照“企业让一点、政府补一点、百姓出一点”的思路，由政府为全县有关特殊群体向广电网络公司购买有线电视和无线wifi服务，受益用户2.6万多户。具体用户以实际接入数量为准，按年度进行费用结算。购买服务期限为2016年至2020年，共计五年。

（一）有线电视用户收视维护费标准为：享受高清互动节目服务的用户，基本收视维护费每户每年240元，县广电网络公司让利60元／年／户，县财政补贴120元／年／户，用户个人承担缴费60元／年／户。

（二）全县政府购买特殊群体范围内的30个WiFi热点服务费用，县级财政参照全省广电扶贫有关优惠政策，按每个WiFi点每年2000元标准给予补助。

（三）在实施政府购买服务范围内持有“户户通”的用户，可置换为政府购买有线电视服务用户，原“户户通”设备上缴后一次性冲抵6 0元收视费。

四、工作步骤

（一）数据摸底阶段：（2016年6—7月）。根据县人民政府2016年第11次常务会议纪要精神，县文广局牵头，各镇（街道办）、广电网络支公司配合，已对全县政府购买范围内的行政村（社区、移民集中安置点）的各类住户进行了全面摸底，并编制上报了建设方案，建立了台账，签订了相关协议。

（二）网络建设阶段：（2016年8-11月）。陕西广电网络洋县支公司已根据建设方案对有线数字电视网络干线和无线WiFi点全面铺开了施工建设。

（三）安装开通阶段：（2016年12月-2018年12月）。

2016年12月至2017年12月底前计划完成覆盖工程量60%。重点范围是磨子桥、李家村、西南坝三个大型移民安置点和马畅镇、谢村镇、龙亭镇的9个省级美丽乡村建设示范村。即计划新装数字电视主终端15000多个，新装无线wifi热点20个。目前，网络线路工程建设已基本就绪，入户安装工程已开始实施。

2018年12月底完成覆盖工程量40%。重点范围是全县60个电商扶贫重点村。即计划新装数字电视主终端10000多个，保持15000多个，合计26000个；新装无线wifi热点10个，保持20个，合计30个。

五、保障措施

（一）强化组织领导。成立政府购买特殊群体有线数字电视和无线宽带服务专项工作领导小组，由县政府主要领导任组长，分管领导任副组长，财政局、扶贫办、文广局、移民办、电商办、广电网络公司及各镇（街道办）负责人为成员，领导小组在文广局设立办公室，办公室主任由文广局局长担任，负责对购买有线数字电视和无线宽带服务工作的组织、指导和监督。各镇（街道办）、各部门（单位）要充分认识做好此项工作的重要意义，积极协调配合，确保工作顺利推进。

（二）夯实工作职责。文广局要加强工作的组织实施和检查监督，指导广电网络公司制定具体服务标准和服务规范，确保惠民政策落实到位。各镇（街道办）要做好宣传发动，引导农户尽早实施安装。广电网络公司要做好工程的勘察设计、实施及日常维护和服务等工作，要在各镇（街道办）设立广电网络服务站点，为用户提供维修、业务咨询等服务，保障有线电视延伸后的服务质量。每年具体安装数量，由县广电网络公司提出计划，报文广、财政、扶贫等相关部门审定同意后具体组织实施。县财政局、扶贫办、移民办、电商办、文广局要定期组织检查考核，根据考核结果兑现县级补助资金。

（三）严格考核检查。各镇（街道办）要将农村有线广播电视和WiFi覆盖工程作为建设美丽乡村的重要内容，全力做好协调服务和环境保障工作。县考核办要将此项工作纳入镇（街道办）、相关部门年度目标责任考核，强化检查，严格督办，确保此项工作不折不扣落实，真正惠及广大农村群众。
