# 洋政办发〔2017〕153号关于印发党的十九大消防安全保卫战工作方案的通知

洋政办发〔2017〕153号

洋县人民政府办公室

关于印发党的十九大消防安全

保卫战工作方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为认真贯彻中、省、市有关部署要求，切实做好党的十九大期间消防安全保卫工作，为党的十九大胜利召开创造安全稳定的社会环境，经县政府研究同意，现将《党的十九大消防安全保卫战工作方案》印发给你们，请结合实际，认真贯彻落实。

洋县人民政府办公室

2017年9月25日

党的十九大消防安全保卫战工作方案

为认真做好党的十九大消防安全保卫工作，坚决预防和遏制重特大火灾事故发生，确保党的十九大期间我县消防形势安全稳定。经县政府决定，从即日起至党的十九大闭幕，在全县范围内组织开展“迎接十九大奋战一百天忠诚保平安”消防专项行动，特制定此方案。

一、工作目标

在县委、县政府统一领导下，动员社会各方面力量，全面排查整治火灾隐患，全面开展“迎接十九大奋战一百天忠诚保平安”消防专项行动，坚决实现“三个确保”（确保各类安保活动现场万无一失；确保不发生较大尤其是重特大火灾事故；确保全县社会面不发生因火灾引起的信访案件）。

二、组织领导

县政府成立由县委常委、常务副县长卢兴华任组长，公安局副局长宋海虎任副组长，县消防安全委员会成员单位负责人为成员的党的十九大消防安保专项行动领导小组。领导小组办公室设在县消防大队，县公安局副局长宋海虎兼任办公室主任，消防大队军政主官为副主任，负责专项行动的组织协调、督导考评、信息整理等工作。各镇办、各行业部门要成立专门工作机构，研究阶段性重点工作，定期通报工作情况，实施统一指挥调度。

三、工作措施

（一）强化火灾防控工作。各镇办、各行业部门要按照夏季消防检查、高层建筑及电气火灾综合治理等工作部署的重点、目标和任务，动员各方面力量，对人员密集场所、易燃易爆单位、高层建筑、文物古建筑等重点场所开展火灾隐患排查攻坚，夯实火灾防控基础。

1．落实“不放心清单”制度。各镇办、各行业部门要认真分析本地区本行业消防安全形势，找准薄弱环节和突出问题。要针对高风险区域、行业、场所开展专项检查，逐个列出“最不放心区域、最不放心行业、最不放心场所”清单，明确监管责任，督促单位场所法定代表人和责任人落实整改责任，集中攻坚整治。

2．落实“三个排查整治”。集中排查整治高层建筑，9月30日前，对列管的高层建筑消防安全重点单位全部排查一遍，做到检查一家，督促整改一家，放心一家。集中排查整治电气火灾隐患，要组织相关单位，排查电器产品及其线路是否符合规定，并逐一落实整改措施。集中排查整治重点单位场所，重点排查人员密集场所、易燃易爆单位、文物古建筑和“三合一”场所、群租房火灾隐患。10月9日前，各镇办、各行业部门要完成辖区全部人员密集场所、火灾高危单位、易燃易爆单位，名镇、名村及文物古建筑隐患排查整治工作。

3．落实“两个创新工作”。督促易燃易爆企业建立企业专职消防队，深入开展“一厂一策一演练”

和“互查互学”活动，确保单位安全。

4．落实物防技防措施。10月10日前，各镇办、各行业部门要督促社会单位开展1次建筑消防设施维护保养、1次电气线路检测、1次油烟道清洗，保证设施设备完好有效。积极推动老旧建筑、“三合一”场所、养老机构设置火灾应急广播、独立式感烟火灾探测报警器、简易喷淋设施，提高初起火灾预警和处置能力。

5．落实“四级”消防大约谈。10月10日前，县政府对各镇办和行业部门负责人进行1次集中约谈；10月13日前，分行业系统对单位消防安全责任人、管理人进行1次集中约谈；10月10日前，消防部门组织对重大火灾隐患单位责任人进行1次集中约谈。

6．落实“四类人员”大培训。9月30日前，全县要分级组织对党政机关、行业部门以及各镇办、社区负责人进行1次全员培训；对重点单位消防安全责任人、管理人及专兼职消防人员进行1次集中培训；督促单位履行消防安全教育培训职责，对从业人员和单位员工进行1次消防培训，重点单位员工“一懂三会”掌握率达到100%；督促居民委员会、物业服务企业组织对社区居民开展1次防火知识宣传和逃生自救演练。

7．落实消防安全社区创建。各镇办要督促所辖社区在前期创建的基础上，逐步实现消防安全社区“消防管理组织制度健全、网格化管理成效明显、消防通道安全畅通、电气及危险品管理规范、消防设施器材完整好用、消防宣传实效管用、微型消防站有战斗力”的总体目标。十九大前，所有社区消防安全社区完成达标创建活动。

（二）强化管控措施。党的十九大重大活动期间，各镇办、各行业部门要采取超常规管控措施，做到发动到位、人员到位、责任到位。

1．落实铁腕整治火灾隐患。对检查发现的火灾隐患，按时限实行“清零管理”，确保到期一家整改一家；对重大火灾隐患，逐家挂牌督办，督促落实整改方案、责任和资金，力争党的十九大前整改销案；10月20日前，对确实难以整改的火灾隐患，依法采取关停措施，对无法关停的特殊建筑，责令单位明确带班领导，加强值班力量，24小时死看死守。

2．落实派出所“所长消防助理”制度。消防部门要向公安派出所派驻业务过硬的监督执法干部，推行“所长消防助理”制度，每周开展不少于2天的消防业务指导。

3．落实社会单位火灾防范措施。各镇办、各行业部门要督促社会单位提高火灾防范等级，落实“六加一”措施，做到消防控制室值班人员、防火巡查人员、重点部位看守人员“三落实”，确保消防安全。要督促消防控制室值班人员持证上岗、在岗在位；落实单位消防安全责任人、管理人和岗位人员值班制度，加强日常巡查检查。对设有自动消防设施的社会单位，要督促与具有资质的消防技术服务机构签订维护保养合同，落实维护保养制度。

（三）强化灭火救援准备。全县要深入开展执勤战备大检查，集中对重点单位开展熟悉演练，全力推动灭火救援攻坚专业队伍建设，不断加强微型消防站、政府专职消防队（卫星消防站）联勤联训，十九大前，联勤联训率要达60%（其中重点单位要达100%）。

1．落实灭火熟悉演练。消防大队要组织力量集中对辖区重点单位进行全面调研，修订完善灭火救援预案。要建立与微型站、卫星站、专职队的联勤联训制度，会同社会应急联动力量对重点单位逐一开展实战演练。

2．落实“四级力量体系”建设。各镇办、各行业部门要推动消防能力提振计划年度工作任务落实，要进一步完善“1+3+5+X”灭火救援体系建设，推动社会单位严格按标准建设微型消防站，建立“一点着火、多点出动、邻里互助、协同作战”联防区域工作机制。9月30日前，消防力量“云平台”全面实战化运行。

（四）强化宣传教育培训。专项行动期间，各镇办、各行业部门要充分利用各类新闻媒体、门户网站及消防官方微博微信，广泛开展消防公益提示宣传，集中曝光重大火灾隐患，持续报道消防工作动态。要积极谋划抓好“119”消防主题宣传活动，营造浓厚的宣传氛围。

1．落实校园、单位、社区“三个方面”宣教。各镇办、各行业部门要扎实推进学校消防安全教育“教材、师资、课时、场地”四到位。在社区、单位、公共场所广泛张贴消防宣传挂图，充分利用橱窗、楼宇电视、电子显示屏等开展“三提示”等消防公益宣传。组织开展“全民消防我代言”119大型公益行动等主题活动，营造浓厚的舆论氛围。

2.落实“三个专项整治”宣传工作。各镇办、各行业部门要紧密结合夏季消防检查、高层建筑及电气火灾综合治理，广泛开展警示性、提示性宣传活动，制作播出火灾案例警示教育片，定期发布火灾预警信息、消防安全提示，提升公众消防安全素质。

四、任务分工

专项行动期间，各镇办、各行业部门要明确分工、密切协作，依法整治各类火灾隐患。

各镇人民政府、街道办事处：负责本辖区消防安全保卫工作的部署和督导，各镇办领导要带队组织检查。各镇办要成立消防管理机构，扎实推进消防安全网格化管理工作。各行业、各系统要扎实开展火灾隐患大排查、大整治工作，对各行业系统发现的重大火灾隐患，实行挂牌督办，督促整改，确保本地区消防安全。

县公安局：要充分发挥消防、治安、督察等警种力量，建立消防多警联动机制，警种联动，共同消除火灾隐患。各个警种要根据职责分工，对所列管的消防安全重点和一般单位，以及“九小”场所等开展火灾隐患排查整治，建立火灾隐患举报投诉中心，发动群众举报隐患，组织全社会开展党的十九大消防安全保卫工作。

县教体局：负责把消防法律法规纳入义务教育、课程教育、专题教育当中，提高全民消防安全意识。要组织对中小学校、幼儿园进行消防安全检查，消除火灾隐患。推进学校消防安全教育“教材、师资、课时、场地”四到位，中小学校消防教材（读本）普及率达到100%。

县财政局：负责落实和保障县级消防业务和专项行动工作经费。

县民政局：负责民政系统的消防工作，组织牵头对全县养老机构开展消防安全检查，督促落实安全措施，确保消防安全。在社会福利机构推广安装简易喷淋、独立式感烟火灾探测报警器等简易消防设施。

县住建局：负责对在建工地及高层建筑开展消防安全大排查和消防宣传教育活动，督促各物业管理企业履行消防安全职责，配合消防部门开展好社区消防建设。加强市政消火栓建设及日常维护保养。

县卫计局：负责在全县疾病预防控制机构、医疗机构、卫生医疗科研机构等开展火灾隐患排查整治工作，对消防违法行为，按照职责权限依法处理，确保各类医疗机构消防安全。

县市监局：负责在流通领域开展消防安全排查整治工作，依法查处经销假、冒、伪、劣消防产品，并将查处情况通报质监和消防部门。

县文旅局、文广局：负责在公共文化服务单位、公共文化设施重点单位、文化娱乐场所开展消防安全大排查、大整治和消防宣传教育活动，及时消除火灾隐患，落实各项消防安全措施。积极开负责组织具有旅游行业特点火灾隐患排查整治活动，深化旅游景点、景区的单位和场所“四个能力”建设，消除旅游景点、景区的火灾隐患。

县人防办：对利用人防工程开设的商场、市场和娱乐场所，开展火灾隐患排查整治工作，督促相关单位制定消防应急预案，组织开展灭火和应急疏散演练。

县电力公司、石油公司：要根据行业特点，组织开展易燃易爆场所火灾隐患排查整治，建立健全自我管理、自我检查、自我整改、责任自负的消防工作机制，积极消除火灾隐患，开展消防安全宣传教育，加强所属的义务消防队建设，制定灭火和应急处置预案，并实施演练。

县政府其他各部门要定期研判本行业、本系统消防安全形势，配合有关部门组织开展消防安全检查，督促所属企业、单位建立健全消防安全制度，整改火灾隐患，解决消防安全突出问题，推行行业消防安全标准化管理，逐级落实行业消防安全监管责任。

五、督导检查

在十九大召开前，由县级领导带队，县消安委会成员单位组成5个综合督查组，采取书面督办与现场督查相结合、明查与暗访相结合、定向定点督办与抽查相结合、检查企业与督导政府及部门相结合的方式，对全县十九大安保工作进行抽查，同时对各镇、办和各行业部门工作落实情况进行督查。

六、工作要求

（一）强化组织领导，落实各级责任。各镇办、各行业部门要增强政治意识、大局意识和责任意识，把十九大消防安保工作作为压倒一切的政治任务，精心谋划、周密部署，严密组织、确保完胜。建立健全十九大消防安保工作责任制，逐级分解任务，明确工作责任。凡发生亡人等重大火灾事故，必须现场剖析原因，严肃追究责任。

（二）强化灵通信息，确保及时反馈。各镇办、各行业部门工作情况及时报县党的十九大消防安保专项行动领导小组办公室（消防大队），每月25日前上报当月工作开展情况，党的十九大闭幕后3日内上报工作总结。（联系人：李卓阳，联系电话：8210648）
