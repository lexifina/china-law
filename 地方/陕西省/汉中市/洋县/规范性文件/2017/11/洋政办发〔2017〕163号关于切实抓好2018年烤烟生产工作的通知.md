# 洋政办发〔2017〕163号关于切实抓好2018年烤烟生产工作的通知

洋政办发〔2017〕163号

洋县人民政府办公室

关于切实抓好2018年烤烟生产工作的通知

各镇人民政府、街道办事处，县政府有关工作部门、直属机构,市管单位：

烤烟产业是我县重要的特色产业。多年来，我县依托得天独厚的自然条件，大力发展烤烟产业，有力地促进了农业增效和农民增收。为进一步做大做强烤烟产业，切实做好2018年烤烟生产工作，现就有关事项通知如下：

一、明确任务，全面抓好2018年烤烟种植面积落实

2018年，我县烤烟生产要本着“做精、做强、做出特色”的原则，坚持“向基地镇集中、向适中户集中”的方向，按照“政府规划、效益引导、订单落实、规模发展”的思路，科学合理制定生产计划。2018年全县计划种植烤烟5000亩，收购烟叶1.48万担，实现产值1770万元，烟税389.4万元以上。烤烟生产具有时间短、见效快、收入稳定的优点，是农民脱贫致富的好产业，各有关镇、街道办事处要把烤烟生产作为精准扶贫的一项重要措施，进一步提高发展烟叶生产对调整农业产业结构、增加烟农收入及地方收入重要性的认识，强化任务观念，与烟草局加强协调沟通，夯实工作责任，组织动员村、组干部和农户，提早抓好2018年烤烟面积落实工作。

二、强化服务，落实优惠政策，切实抓好烤烟生产

各有关镇、街道办事处和县烟草部门要立即行动，采取各种措施，加强优惠政策宣传和服务指导，引导烟农加强田间管理。各有关镇、街道办事处要抓好烤烟生产工作的安排部署，组织村、组干部和烟叶生产技术人员主动上门，与农户面对面分析烤烟种植、烘烤中存在的问题，及时采取改进方法措施，进一步坚定农户种烟的信心，扩大种植面积。县烟草部门继续实行技术人员包村、包组、包大户的技术责任制，严格考核奖惩，扎实抓好育苗、移栽、大田管理、病虫害防治、烘烤、分级打捆和预检等技术指导服务工作；要不断提高收购环节的服务水平，严格收购监督管理，切实维护烟农利益，充分调动和保护烟农生产积极性。各有关镇、街道办事处和相关部门要认真贯彻落实陕政办发〔2012〕74号文件精神，加大人力、物力、财力等方面的扶持，以优惠的政策吸引烟农、鼓励烟农，以优质的服务支持烟农、取信烟农，引导烟农发展烤烟。

2018年，有关镇、街道办事处和县烤烟办要按照《洋县人民政府关于进一步加快烤烟产业发展的决定》（洋政字[2014]100号）文件扶持奖励。相关部门要加大考核力度，确保各项数字的真实性和准确性，确保按要求拨付到位，坚决杜绝虚报现象。

三、加强领导，夯实责任，确保完成2018年烤烟任务

县烤烟办要切实担负起烤烟生产协调指导和督促检查责任，对烤烟生产工作各阶段中存在的问题要及时协调解决，确保各项工作扎实有效推进。各有关镇、街道办事处要成立相应的工作机构，主要领导亲自挂帅、亲自安排，抓好落实；要确定一名分管领导具体负责，抽调工作人员，深入村、组开展组织协调工作；对种烟大户租赁土地，要重点支持，保证种烟土地的需求。各有关镇、街道办事处之间、各村之间也要加强协作，积极支持种烟大户跨镇（街道办事处）、跨村组租地种烟，提供优质服务，为烤烟生产提供便利条件，确保2018年烤烟种植计划的全面完成。
