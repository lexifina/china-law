# 洋政办发〔2017〕165号关于印发洋县2018年农村小额人身保险工作实施方案的通知

洋政办发〔2017〕165号

洋县人民政府办公室关于

印发洋县2018年农村小额人身保险工作

实施方案的通知

各镇人民政府、街道办事处：

《洋县2018年农村小额人身保险工作实施方案》已经县政府同意，现予印发，请遵照执行。

洋县人民政府办公室

2017年11月3日

洋县2018年农村小额人身保险工作实施方案

为了认真执行《汉中市人民政府办公室关于进一步推进农村小额人身保险工作的通知》（汉政办发〔2015〕54号）及《洋县人民政府办公室转发汉中市人民政府办公室关于进一步推进农村小额人身保险工作的通知》（洋政办发〔2015〕136号）文件精神，促进我县2018年小额人身保险工作顺利开展，特制定洋县2018年农村小额人身保险工作实施方案。

一、工作目标

2018年各镇（办）适龄人员参保率达到90% 。

二、参保时间

2017年11月1日至2018年3月31日。

三、参保收费、保险期限及参保年龄

每人20元，保险期限为壹年（2018年1月1日至2018年12月31日），参保年龄为0-70周岁。

四、具体要求

（一）、统筹安排。各镇（办）要高度重视，安排专人负责， 与“新农合”、“城镇医保”等工作同部署、同推进。

（二）、加强宣传。各镇（办）和县人寿公司要及时深入各村开展宣传和承保工作，要通过电视、报刊、网络等多种宣传媒体，以浅显易懂的方式，重点向广大农民宣传推广小额保险的风险保障功能，努力形成有利于农村小额保险全面推进的舆论氛围。

（三）、加强督导。县农村小额人身保险办公室要做好业务指导及工作督导，定期通报各镇（办）工作完成情况，确保按期顺利完成任务。

（四）、优化服务。负责承办的中国人寿保险公司要进一步建立健全理赔服务体系，向镇村派驻服务人员，协助各镇（办）共同推进全县小额人身保险工作持续健康发展。
