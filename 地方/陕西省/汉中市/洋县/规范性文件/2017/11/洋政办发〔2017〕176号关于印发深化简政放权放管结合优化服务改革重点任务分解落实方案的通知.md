# 洋政办发〔2017〕176号关于印发深化简政放权放管结合优化服务改革重点任务分解落实方案的通知

洋政办发〔2017〕176号

洋县人民政府办公室

关于印发深化简政放权放管结合优化服务

改革重点任务分解落实方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为贯彻落实市政府办公室《关于印发深化简政放权放管结合优化服务改革重点任务分解落实方案的通知》（汉政办发〔2017〕66号）精神，围绕“为促进就业创业降门槛、为各类市场主体减负担、为激发有效投资拓空间、为公平营商创条件、为群众办事生活增便利”，进一步转变政府职能，激发市场活力和创造力，经县政府同意，现将《洋县深化简政放权放管结合优化服务改革重点任务分解落实方案》印发给你们，请抓好组织实施。

一、加强组织领导。各镇办、县级各部门主要负责同志要亲自研究部署“放管服”改革工作，督促各项改革任务落实，分管负责同志要紧盯重点任务的各个环节，抓好组织实施和跟踪问效，切实加强对改革工作的组织领导，科学谋划、统筹兼顾，有力有序推进各项改革任务。

二、狠抓任务落实。要按照本方案精神，细化分解改革任务，明确时间节点，压实工作责任，形成明晰的改革“施工图”、“进度表”，全力推进各项改革进程。2017年12月1日前，各镇办、县级各牵头部门要汇总重点任务完成情况报县推进职能转变协调小组办公室（县编办）。

三、注重统筹协调。进一步理顺工作机制，明确责任分工，加强上下之间、横向之间的工作衔接和政策对接，努力形成推进改革的强大合力。县各牵头部门要切实发挥牵头抓总作用，加强对改革重点任务的统筹协调和督促检查，及时解决好改革进程中出现的各种困难问题，确保各项改革任务顺利完成。

四、强化督查问效。突出问题导向、效果导向，进一步加大重点改革任务的督查督导工作力度，县推进职能转变协调小组办公室要进一步健全督查问效机制，强化督查督导，对改革任务落实到位、成效显著的部门单位进行通报表扬、给予激励，对敷衍塞责、改革不力的进行严肃问责、督促整改，以强有力的督查保障各项改革任务落地见效。
