# 洋政发〔2017〕47号关于印发洋县社会综合治税工作实施方案的通知

洋政发〔2017〕47号

洋县人民政府

关于印发洋县社会综合治税工作

实施方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县社会综合治税工作实施方案》已经县政府研究审定,现印发你们，请认真遵照执行。

洋县人民政府

2017年10月24日

洋县社会综合治税工作实施方案

为深入贯彻《中华人民共和国预算法》、《中华人民共和国税收征收管理法》等财税法规以及《汉中市税收保障办法》，推进财税与经济协调发展，建立部门间涉税信息高度共享、相互印证的财税管理机制，实现税收及时足额入库，确保财政收入稳定增长，提高政府财税治理能力现代化水平，促进国民经济快速协调发展，特制定本实施方案。

一、总体要求

（一）指导思想。深入贯彻党的十八大以来历次全会精神，按照全面依法治国和深化财税体制改革的有关要求，以财税法律、法规为依据，以信息化手段为支撑，创新征管方式、征管技术和征管机制，充分调动社会各界力量，促进涉税信息资源科学配置和有效利用，提升税收征收效率和财税管理水平，为加快洋县经济发展提供坚实保障。

（二）基本原则。

1．坚持依法治税。涉税部门和单位在综合治税工作中须严格依照法律规定行使权力、履职尽责。

2．坚持信息共享。以综合治税平台为依托，实现各部门涉税信息集中共享，强化涉税信息增值利用。

3．坚持协调联动。充分调动部门和社会力量参与税收监督管理的积极性，实现税务机关与各有关部门之间协同配合，由税务机关单一征管转变为多部门联动协作、共同推进。

4．坚持综合运用。加强综合治税信息与其他政务信息平台数据衔接利用，促进整体数据分析能力提升，为有效处理复杂财税问题提供新手段，逐步实现基于大数据的科学决策。

二、组织领导

县上成立洋县税收保障工作领导小组，由县长任组长，常务副县长任副组长，县法院、检察院、政府办、公安局、财政局、国税局、地税局、发改局、审计局、市监局、经贸局、教体局、科技局、民政局、司法局、人社局、国土局、环保局、住建局、交通局、水利局、农业局、林业局、文广局、卫计局、文旅局、安监局、人防办、残联、烟草局、人行洋县支行、住房公积金洋县管理部、电力局、邮政局、自来水公司、天然气公司和消防大队等单位负责人为成员，负责税收保障工作的组织、协调、指导等有关重大事项。领导小组下设办公室，办公室设在财政局，办公室主任由县财政局局长担任，副主任由县国税局、地税局局长担任，工作人员从财政、国税、地税等部门抽调，各成员单位指定1名业务人员负责涉税信息收集、整理、报送、反馈等工作。

三、主要内容

（一）建立涉税信息共享工作机制

县税收保障工作小组办公室（以下简称“县保税办”）负责搭建全县统一的综合治税信息管理平台，根据政策法规及各成员单位管理职能编制《洋县涉税信息目录》，确定涉税信息的名称、详细内容、传递时限和工作规则，规范涉税信息交换的格式、标准，建立涉税信息综合资料数据库，完善信息共享及分析报告制度。各有关部门要按要求及时向县税收保障工作领导小组办公室提供有关涉税信息，实现涉税信息和资源跨系统、平台、数据结构的交汇互融，共享数据资源。

（二）强化涉税信息分析利用

县保税办和相关单位要加强对涉税信息的筛选、整理、汇总和分析比对工作，充分挖掘涉税信息的使用价值，围绕主体税种、重点行业和重点企业，深入查找税收征管问题和不足，全力做好经济运行分析、财税收入预测预警、税收政策研究，为政府决策提供数据信息支撑。县国税、地税部门要及时对信息预警事项和涉税督办交办事项深入查证和分析，并将处理结果及时反馈到县保税办。针对疑点信息涉及的重点领域要加大税收专项检查力度，确保税源管控的有效性，切实防范税收征管风险。逐步将涉税信息运用于税额核定、纳税评估、税务稽查、涉税司法案件查处、纳税信用等级评定及财政资金安排等领域，不断延伸涉税信息利用链条。

（三）建立税收保障工作机制

1、加强源头控税。各有关部门要发挥自身职能优势，在遵守法律法规的前提下，积极协助税务机关加强税收征管，在办理行政审批等事项时先审核行政相对人纳税义务履行情况，后办理有关手续，构建规范化、精细化、科学化的源头控税机制，确保应收尽收。

2、健全工作机制。国地税部门应加强代扣代缴、代收代缴、委托代征工作，完善税收委托代征工作机制。加强委托代征工作核查督查，对未按规定代征代缴税款、违反税收发票管理规定导致税款流失的部门、单位及个人，依照有关规定严肃处理。

3、加强司法协助。司法部门要依法打击伪造、变造、贩卖发票及利用假发票进行犯罪的行为；对税务机关移送的涉嫌犯罪案件依法进行查处;对拒绝、阻碍税务机关依法执行公务构成违反治安管理的行为或者犯罪行为的相关人依法予以处理；按照税务机关提交的相关阻止出境文书，依法阻止有关人员出境，为社会综合治税工作提供有效的法律服务和司法保障。

4、加强监督检查。县保税办每年组织对各个重点涉税单位、各镇办涉税项目纳税情况进行一次检查，对不认真履行税收源头控制办法的单位，由县税收保障工作领导小组审定后进行通报批评，对因工作不力或失职渎职造成严重后果的，依法依纪追究相关单位主要负责人和直接责任人的责任。

（四）建立协调机制

县税收保障工作领导小组定期召开联席工作会议，通报综合治税工作进展情况，研究制定工作办法，及时协调解决工作中存在的各类重大问题，督促成员单位认真履行协税护税职责义务，研究和明确相关单位的协作内容、方式、要求、责任。

四、保障措施

（一）加强组织领导。开展综合治税工作是财税管理机制的重大创新，是确保依法征税、应收尽收的有效手段，是解决部门之间、政府与企业之间信息不对称的必然要求，对政府提升财税治理能力意义重大。各有关部门要充分认识此项工作的重要意义，采取切实有效措施，确保工作落实，抓紧研究制定实施办法，推动各项工作有效开展。

（二）明确工作责任。财税部门要充分履行牵头部门职责，在县税收保障工作领导小组领导下组织协调各成员单位共同开展工作；要把综合治税所需经费和奖励资金纳入本级预算，为工作顺利开展提供保障。保税办负责涉税单位涉税信息的收集、分析及传送。税务机关要加大涉税信息的综合利用和疑点信息的查证落实力度，完善税收征管长效机制。其他成员单位要完善内部工作制度，指定专门机构和人员负责及时传递本单位涉税信息并加强共享信息的使用管理。各相关单位及工作人员要按规定做好涉税信息的安全与保密工作，按规定存储、交换、保存、使用并承担保密责任，不得将涉税信息用于改造职责外其他用途。

（三）强化督导考核。县考核办要将综合治税工作纳入各成员单位年度目标责任考核体系，全程跟踪督办，确保各项税收应收尽收。县保税办要建立综合治税工作考评，按年度对各成员单位综合治税工作任务完成情况进行考评，及时向县政府报告考核情况。对工作成绩突出的部门予以表彰奖励；对措施不力、不认真履行综合治税职责的部门予以通报批评；对因工作不力或失职渎职造成严重后果的，依法依纪追究相关单位主要负责人和直接责任人的责任。

（四）加强引导宣传。要充分利用广播、电视、网站等多种渠道，加大对开展综合治税工作的宣传力度，定期向社会通报综合治税工作情况，积极推动涉税信息依法开放共享，营造全社会理解和支持综合治税工作的良好氛围。
