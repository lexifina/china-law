# 洋政发〔2017〕50号关于印发洋县古树名木目录的通知

洋政发〔2017〕50号

洋县人民政府

关于印发洋县古树名木目录的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

根据《汉中市人民政府关于印发汉中市古树名木目录的通知》(汉政发〔2017〕24号)文件公布的全市古树名木目录，我县进入目录的古树共有234株，其中：特级古树13株，一级古树42株，二级古树40株，三级古树139株。为切实保护好我县的古树名木资源，现就有关事项通知如下：

一、全面实施挂牌保护，层层落实管护责任

县林业局应及时按照目录及文件要求统一制作古树名木标志牌，并指导各镇办、各部门按标准进行悬挂。在悬挂标志牌的同时，及时与古树名木养护责任单位和责任人签订养护责任书，全面落实养护责任。

二、严格古树名木执法管理，认真做好日常养护

各镇办、各单位要认真贯彻执行《陕西省古树名木保护条例》的相关规定，因科学研究，工程建设确需移植古树名木的，应当经市古树名木行政主管部门审查同意后，上报省林业行政主管部门批准；对古树名木死亡的，按照程序逐级报送市以上主管部门确认后，方可处理；对危害和影响古树名木正常生长的行为，要及时予以制止，责令限期采取措施消除危害；对违法砍伐、擅自移植、擅自处理未经确认的死亡古树以及其他损毁、破坏古树名木的行为，要依法严肃处罚，构成犯罪的，依法追究刑事责任。

古树名木养护单位和责任人要认真做好松土、除草、浇水等日常养护工作，积极采取措施保持土壤透水、透气性，对古树出现病虫害、衰弱濒危症状及人为破坏的，要及时上报县林业局。县林业局要积极开展技术指导，定期开展病虫防治等专业养护工作，对濒危的古树名木要及时组织专业力量，采取措施尽力进行抢救。

三、积极筹集资金，健全保障机制

古树名木保护是公益性事业，保护所产生的生态、社会、经济效益将造福于全社会。因此必须依靠全社会力量，加大投入。各镇办、各单位应本着“分级管理、分级投入”的原则，积极筹措资金，加大古树名木保护投入力度。同时，建立健全机制，鼓励社会各界参与保护，积极开展认养、资助、捐赠等活动，推动古树名木保护工作有效开展。
