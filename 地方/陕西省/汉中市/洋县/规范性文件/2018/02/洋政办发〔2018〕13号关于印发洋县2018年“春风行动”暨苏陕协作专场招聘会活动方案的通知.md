# 洋政办发〔2018〕13号关于印发洋县2018年“春风行动”暨苏陕协作专场招聘会活动方案的通知

洋政办发〔2018〕13号

洋县人民政府办公室

关于印发洋县2018年“春风行动”暨苏陕协作专场招聘会活动方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县2018年“春风行动”暨苏陕协作专场招聘会活动方案》已经县政府同意，现印发给你们，请认真遵照执行。

洋县人民政府办公室

2018年1月26日

洋县2018年“春风行动”暨苏陕协作

专场招聘会活动方案

2018年是洋县确定的扶贫作风建设年，也是全县脱贫工作三步走的关键之年，根据如皋-洋县对口协作工作安排，经如皋市、洋县有关部门对接研究，决定于春节前后组织双方企业开展劳务扶贫协作活动，为确保活动顺利开展，现制定方案如下：

一、活动主题

搭建劳务平台，引导充分就业，促进创新创业，助推脱贫致富。

二、服务对象

1.返乡农民工、进城务工农村劳动者、高校毕业生、专业人才、技能人才、退役士兵、就业困难人员等各类有就业创业意愿的城乡劳动者。

2.如皋市及周边地区用工企业；县内有招聘需求的用人单位。

三、活动目标、原则

全面贯彻落实党的十九大精神，以构建新型就业创业服务平台为抓手，引导和促进各类城乡待就业人员转移就业，服务企业用工，推动实现更高质量的就业。按照平等自愿、公开公平、互利共赢的原则，发挥好苏陕协作平台作用，进一步落实如皋-洋县政府间协作和劳务协作框架协议精神，高度关注贫困劳动力特别是深度贫困村劳动力，引导全县劳动力资源实现高水平、高质量转移就业，力争全县有劳动能力的人员外出务工率达到40%，实现0.5万人到江苏、上海市等东部地区务工，人均年增收3.0万元的目标。

四、活动内容

第一阶段：宣传动员阶段，从2018年1月20日至2018年2月23日。

1. “春风行动”暨苏陕协作专场招聘会动员会。1月下旬，召开“春风行动”暨苏陕协作专场招聘会动员会。由县人社局牵头，发改局配合，做好会议组织、材料印制等工作，落实布置活动各项工作，拟定各镇办招聘计划。

2.开展全方位宣传和氛围营造。①抓住春节前后务工人员返乡的时机，发动广播、电视、网络等各类宣传媒介，逐村逐户进行宣传，让村民充分知晓、充分参与。②由人社局牵头，在网站等媒体对招聘活动进行推送宣传，形成浓烈氛围。③由扶贫办牵头，人社局配合，结合春节前走访慰问活动，扶贫工作队、包扶干部及时将就业创业扶贫政策、招聘岗位信息等送进千家万户，并做好宣传对接工作。

第二阶段：组织落实阶段，从2018年2月24日至2018年2月27日。

1.2月24日，举行“春风行动”暨苏陕协作专场招聘会开幕式暨如皋-洋县就业服务中心揭牌成立仪式。开幕式由县人社局牵头负责，县发改局配合。（设立如皋-洋县就业服务中心事宜由洋县人社局协商如皋人社局筹备，开幕式当天揭牌成立）。

2.“春风行动”暨苏陕协作专场招聘会正式活动。

主会场时间：2月24日上午（开幕式结束后进行）。地点为洋县人力资源一楼大厅或开明广场，为提高该活动的综合效果，由扶贫办牵头，在招聘会现场，各相关部门要结合各自业务特点，现场开展扶贫政策宣传服务活动，发放相关宣传资料，解答政策。相关企业设置招聘展位，布置广告牌。

分会场时间：2月26-2月27日。在槐树关、谢村、磨子桥、华阳等4个镇设分会场。分会场应聘人员由各镇办具体组织，以村为单位，前期进行摸底和造册登记，镇（办）确定一名领导带队，带领辖区自愿务工者进行招聘（具体计划表附后）。每个镇半天时间，组织企业到相关镇进行招聘。分会场由人社局牵头、各相关镇办具体承办，各镇办根据安排组织人员在不同时间进场应聘、洽谈等。同时，安排好回乡创业人员座谈会、表彰会、辖区劳务输出培训工作。确保人员组织到位、招聘效果到位。

活动期间，各镇办社保所要充分发挥基层就业平台的作用，调动村级信息员的积极性，及时把就业信息、政策宣传到户，组织有外出就业愿望的劳动力报名参加招聘活动。扶贫工作队、包扶干部要主动做好动员工作。

第三阶段：跟踪服务阶段，招聘会结束后。各企业组织好录用人员赴如皋的交通保障工作；各企业及时报送好录用人员信息。劳动部门及时派员护送进厂。县人社局在如皋建立洋县务工人员服务窗口和热线电话，并及时公布，为赴如皋就业人员提供各类服务，协调解决劳务相关问题。及时做好本次招聘活动的总结工作，激励先进，兑现企业招聘相关待遇。

洋县劳动服务局将签订合同的务工人员统一派员护送进厂，属建档立卡贫困户人员补助交通费用。

五、活动要求

1. 统一思想，提高认识。各镇办、相关部门要将该活动与脱贫攻坚春季攻势百日会战相结合，作为新春脱贫攻坚重要工作任务，通过活动开展抓出成效。要按照全面对接的要求，充分借助南通如皋市优势资源和雄厚的产业基础这一平台，推动洋县如皋劳务协作，实现精准扶贫。要根据各自承担的工作任务，落实好方案，组织好本次活动，通过本次务工，促进人力资源的培训和储备，为我县今后县域经济、支柱产业发展等方面提供人力保障。

2. 加强协作，强化保障。成立“春风行动”暨苏陕协作专场招聘活动工作小组，县人社局牵头负责组织实施，县发改局、扶贫办等部门及各镇（办）共同参加，县劳动服务局和各镇（办）具体负责活动宣传和招聘活动的组织实施。本次活动所需经费由人社局按照相关政策落实。“春风行动”招聘活动实行免费服务，各分会场拨给3000元组织活动经费。

3. 精细组织，高效务实。人社局、发改局协作办提早谋划，筹备好本次活动，负责邀请如皋市相关部门、企业届时参会。各项活动的组织开展要以劳务协作对接为主，不举办务虚性会议和活动。各镇根据区域特点，组织召开小型招聘会、返乡农民工座谈会、表彰会，开展就业创业政策宣传，引导组织农村富余劳动力转移就业，返乡创业。加强组织领导，发挥第一书记、驻村工作队的作用，与精准扶贫工作相结合，实现就业一人、脱贫一户的目标。

4. 加大力度，广泛宣传。围绕洋县扶贫工作现状,结合县域劳动力资源情况，对接、精选一批承接力强、关联度高、对接性好的企业来我县招聘。要充分利用广播、电视、网络、微信、基层就业平台等，高密度、高频率地开展宣传，把活动信息、活动内容、日程安排广泛宣传出去，营造全社会关心贫困群众务工、劳动者就业的氛围。活动期间，县劳动服务局免费为各镇和群众发放一批《就业创业知识读本》、《就业创业服务指南》。活动结束后，各镇办要在3月30日前，将活动总结报县劳动服务局。
