# 洋政办发〔2018〕31号关于印发洋县消费品工业“三品”专项行动实施方案的通知

洋政办发〔2018〕31号

洋县人民政府办公室关于

印发洋县消费品工业“三品”专项行动

实施方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县消费品工业“三品”专项行动实施方案》已经县政府同意，现印发给你们，请认真贯彻落实。

洋县人民政府办公室

2018年3月16日

洋县消费品工业“三品”专项行动实施方案

为贯彻落实市政府办公室《关于印发汉中市消费品工业“三品”专项行动实施方案的通知》（汉政办发〔2018〕7号）精神，推进我县消费品工业供给侧结构性改革，结合我县实际，制订如下方案：

一、总体要求

（一）指导思想。全面贯彻中、省、市有关会议精神，按照高质量发展的要求，以供给侧结构性改革为主线，以市场为导向，以创新为动力，以企业为主体，以实施增品种、提品质、创品牌的“三品”战略为抓手，改善营商环境，从供给侧和需求侧两端发力，着力提高消费品有效供给能力和水平，更好地满足人民群众消费升级的需要，实现消费品工业更加稳定、更有效益、更可持续的发展。

（二）发展思路。重点围绕有机食品、有机中药材，突出食品行业，通过抓骨干和小而精致的企业，着力提高消费品有效供给能力和水平，实现由资源要素型向创新驱动型转变，产业链低端向中高端转变，简单聚集向深度集聚转变，为我县工业经济实现追赶超越发挥重要作用。

（三）主要目标。到2021年，我县消费品工业传统优势得到巩固提升，新兴产业不断壮大，市场环境进一步优化，“三品”专项行动取得积极进展，品种丰富度、品质满意度、品牌认可度明显提升，产品和服务对消费升级的适应能力显著增强，全县消费品工业总产值突破80亿元，占全县工业比重提升3个百分点，培育形成省级以上名牌3个以上，企业研发投入占主营业务收入比重提升0.5个百分点，省级以上企业技术中心达到2户以上。朱鹮、秦洋、周大黑、大咸德等知名品牌市场影响力进一步增强，洋县黑米、谢村黄酒等地域品牌竞争力进一步提升。

二、重点任务

（一）“一企一策”增品种

1. 培育消费品领军企业。到2021年，培育5亿元以上龙头骨干企业1户、1亿元以上骨干企业3户、5000万元以上级小而精致企业5户。采取政企联动，“一企一策”精准施策，激发企业活力和创造力，做优存量、做大增量。鼓励领军企业不断开发新产品，推动消费品工业转型发展。（责任单位：县经贸局、县发改局、县农业局、县统计局）

2. 提升供给能力。支持企业深度挖掘用户需求，适应和引领消费升级趋势，在产品开发、外观设计、产品包装、市场营销等方面加强创新，积极开展个性化定制、柔性化生产，丰富和细化消费品种类。实施“工业+文化”行动，加快培育工艺美术设计、工业设计等创意设计产业。增加中高端消费品供给能力建设，发展个性化、功能化、绿色化消费品，推出一批科技含量高、附加值高、设计精美、制作精细、性能优越的产品，促进产品向高性价比、优势精品转变。（责任单位：县经贸局、县科技局）

3. 推进企业技术改造升级。支持双亚公司周大黑黑米茶、大咸德黑米醋及洋县黑米系列产品技术改造升级，加快形成新的增长动能。（责任单位：县经贸局、县发改局）

4. 打造提升产业链。坚持围绕产业链部署创新链，围绕创新链培育产业链，依托有机产业优势，充分利用丝博会、中博会、茶博会等展会平台，开展产业链条式、整体式、集群式招商和合作对接，吸引一批投资效益好、带动引领作用强的项目落地，不断培育壮大优势企业。优化整合各级农业产业园区、工业集中区，重点培育打造绿色有机食药产业集群。通过种植布局、加工产业布局、物流体系布局和研发质量监管布局，细分延伸产业链，推动产业协同发展。（责任单位：县招商办、县经贸局、县发改局、县农业局、县市监局）

5. 发展特色消费品。弘扬工匠精神，汇集传统文化，重点发展有机食品、功能食品等具有洋县特色的消费品，培育一批独树一帜、享誉省内外的小而精致企业。（责任单位：县经贸局、县农业局、县文广局）

（二）“对标示范”提品质

1. 实施精品制造工程。在消费品行业中选择1-2户重点企业，与国内国际知名产品进行比对，引导企业树立标杆，加强创新研发，推出一批性能优越的精品，力争产品质量接近或达到国内先进水平。（责任单位：县经贸局、县市监局、县发改局）

2. 全面提升产品质量。引导支持秦洋酒业、黑米酒业等龙头企业，加强从原料到生产销售全流程质量监控，逐步建立和完善食品质量安全追溯体系，推广先进质量管理模式和管理体系，提高产品质量安全监管水平。（责任单位：县市监局、县经贸局）

3. 保障优质原料供应。加大黑米、有机米等农产品源头治理力度，从原料端保障消费品质量，切实维护广大人民群众“舌尖上的安全”。（责任单位：县农业局、县发改局、县科技局）

（三）“一业一品”创品牌

1. 开展品牌培育工程。提升引领“洋县黑米”、“谢村黄酒”等一批区域强势品牌，通过开展企业兼并重组、加强创新研发、扩大宣传等方式提升品牌知名度，抢占国内市场。培育孵化一批活力旺盛的品牌梯队，形成各具特色的品牌培育体系。建立品牌人才培训服务机构，形成多层次的品牌人才培养体系。（责任单位：县市监局）

2. 提高品牌竞争力。鼓励企业制定品牌发展战略，构建管理体系，明确品牌定位，采用合理定价、差异化发展等策略，整合渠道资源，提高品牌产品性价比。建立品牌商品对接机制，大力开展知名品牌产品“全国行”“网上行”和“进名店”等活动，引导企业积极参与放心消费创建活动，争创放心消费示范（品牌）企业。（责任单位：县市监局、县经贸局）

3. 加快网络品牌推广。鼓励消费品企业应用“互联网+”，促进品牌企业与大型电商平台对接，拓宽流通渠道，减少流通环节，推动线上品牌与线下品牌共同发展。（责任单位：县经贸局、县市监局）

三、保障措施

（一）加强组织领导。成立县消费品工业“三品”专项行动工作领导小组，组长由县政府分管副县长担任，副组长由县政府办主任、县经贸局局长担任，县发改局、经贸局、科技局、财政局、人社局、农业局、林业局、文广局、卫计局、环保局、安监局、文旅局、市监局、招商办、供销社分管负责同志为成员，领导小组办公室设在县经贸局，统筹协调落实消费品工业“三品”专项行动实施方案，及时研究解决有关重大问题，指导、督促各有关部门开展工作。各领导小组成员单位于每年12月20日前将工作开展情况书面报送领导小组办公室。（责任单位：县经贸局，领导小组成员单位）

（二）加大财税支持力度。积极落实西部大开发、高新技术企业、城镇土地使用税和房产税优惠政策，加大收费清理和降费力度。整合放大涉农资金、工业资金、科技资金，采取入股、贴息、担保、租赁等方式，支持有实力、潜力大的龙头企业研发创新、品牌培育和项目建设。（责任单位：县经贸局、县发改局、县科技局、县财政局、县农业局、县市监局、县金融办）

（三）强化市场建设和技术创新支持。对新获得省级名牌产品、省著名商标、中国驰名商标的消费品企业，按照省、市有关政策进行奖补支持，县政府也给予适当奖励。积极争取省上首台（套）应用、消费品超销售奖励以及对工业品促销活动补贴等项目资金扶持。支持工业消费品企业开展科技创新、科技成果转化、人才引进，对新认定的国家级和省级企业技术中心，重大科技转化成果，引进的高层次人才，按照省、市政府已出台的政策予以奖励、补助或贷款贴息，县政府也给予适当奖励。（责任单位：县经贸局、县科技局、县市监局、县财政局）

（四）大力开展品牌宣传活动。加大宣传投入和宣传力度，积极促使当地人文资源与“三品”品牌文化融合，提高产品知名度和美誉度。充分利用“3·15国际消费者权益日”、“食品安全宣传周”等活动，引导群众识别和抵制假冒伪劣产品，提高名牌产品的知名度，帮助企业巩固拓展市场占有率，形成全社会重视名牌、保护名牌、发展名牌的良好氛围。（责任单位：县文广局、县经贸局、县财政局、县市监局）
