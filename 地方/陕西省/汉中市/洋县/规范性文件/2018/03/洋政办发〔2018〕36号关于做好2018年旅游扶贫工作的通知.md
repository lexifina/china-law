# 洋政办发〔2018〕36号关于做好2018年旅游扶贫工作的通知

洋政办发〔2018〕36号

洋县人民政府办公室

关于做好2018年旅游扶贫工作的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为大力实施乡村振兴战略，认真贯彻落实中省市关于做好脱贫攻坚工作和旅游扶贫工作的一系列决策部署，推动全域旅游工程深入实施，根据陕西省旅游发展委员会办公室《关于深入实施陕西省“十三五”旅游扶贫行动计划的通知》（陕旅办字〔2018〕9号）和汉中市旅游发展委员会《关于做好2018年旅游扶贫工作的通知》（汉旅字〔2018〕21号）要求，结合我县实际，现就做好2018年旅游扶贫工作通知如下。

一、提高站位，充分认识旅游扶贫的重要作用

旅游扶贫是开展“三农”工作的重要抓手，是建设美丽乡村的重要载体，是打赢脱贫攻坚战的重要路径。我县部分贫困乡村由于区位偏远、交通不便等因素，仍然保留着比较原始的自然风貌和纯朴的民风民俗，为发展乡村旅游、开展旅游扶贫提供了较好的资源和条件。但是，当前各部门、镇办还没有充分认识旅游扶贫的重要作用，对发展乡村旅游的重视还不够，整合资金加强旅游扶贫重点村建设的合力还没有形成；有的旅游扶贫重点村基础设施薄弱，缺乏懂管理、会经营的专业人才；旅游产品规模小、知名度不高，没有市场竞争力。对此，发改、财政、住建、交通、农业、旅游、林业、文广等涉旅部门和镇办要高度重视，切实提高思想认识，主动对接市上对应的综合部门，争取上级相关单位对旅游扶贫中的景区开发、道路建设、基础设施配套以及乡村旅游示范项目建设的支持，整合相关旅游资源和项目资金，加大贫困村旅游资源的开发力度，加快推动旅游产业发展，带动更多的贫困人口脱贫致富。

二、突出重点，深入推进旅游扶贫开发建设

围绕旅游发展带动扶贫，以“五变战略”为指导（景区变扶贫基地、旅游项目变扶贫开发区、乡村旅游点变精准扶贫点、农产品变旅游商品、贫困人口变经营老板），推动“五个一批”（旅游示范县建设带动脱贫一批、旅游景区建设带动脱贫一批、文化旅游名镇建设带动脱贫一批、旅游扶贫试点村建设带动脱贫一批、旅游土特产生产销售带动脱贫一批），实施七大行动计划，力争让更多的贫困人口通过发展旅游受益。

（一）推进扶贫村规划编制。发改、农业、林业、水利、旅游、扶贫等部门和各镇办要将旅游扶贫纳入“乡村振兴战略”的重要内容，积极争取中省市支持，指导有条件的建档立卡扶贫重点村编制旅游扶贫规划，明确旅游产业重点及落地项目，发展个性化、特色化、差异化旅游业态，通过加强对乡村生态环境和文化遗存的保护，探索旅游扶贫开发规划与城镇规划、交通运输规划、易地扶贫搬迁规划等“多规合一”编制模式及内容，为旅游扶贫指明方向，提供依据。积极引导旅游企业参与规划的制定和实施，与建档立卡村开展结对帮扶。（农业局牵头，发改局、林业局、水利局、旅发委、脱贫办、各镇办配合）

（二）推进扶贫村公共设施建设。结合重点环境综合整治，积极协调相关部门，将道路、停车场、厨厕改造、垃圾污水处理等旅游基础设施和公共服务设施纳入各镇办和相关部门年度项目计划。交通部门要做好高A级旅游景区（点）到干线公路的连接线、交通标识建设工作；住建、农业、环保等部门要联合推进重点旅游扶贫村的污水处理设施、下水管网、垃圾处理站建设，推动旅游厕所建设；移动、电信、联通公司要做好提升乡村通信工程设施工作。各镇办对从事乡村旅游经营的贫困户实施以改厨、改厕、改房、整理院落为主要内容的“三改一整”工程，改善旅游接待条件（发改局牵头，交通局、住建局、农业局、环保局、创建办、旅发委、移动公司、联通公司、各镇办配合）。

（三）培育贫困地区旅游品牌。发改、财政等部门要积极鼓励、引导重点旅游扶贫村培育旅游精品产品及项目，优先安排项目及资金支持；旅游部门要做好申报创建国家A级景区、星级酒店、旅游度假区、省级旅游特色名镇及乡村旅游示范村等品牌，华阳景区、华阳镇要积极培育发展自驾车房车营地、帐篷营地、星级农家乐等新业态；文广部门要开展市级及以上非物质文化遗产的保护与活化工作，打造乡村特色文化演艺、节庆及农事体验活动；农业、住建、扶贫等部门要结合美丽乡村、特色小镇、田园综合体、古镇建设等，大力发展休闲农业、乡村旅游、乡村养老等产业，推动乡村旅游形成品牌，通过增强游客体验性、延长游客停留时间，提高乡村旅游综合收入，使更多的贫困人口受益。（发改局、财政局、旅发委、文广局、农业局、扶贫办、各镇办、各景区负责）

（四）强化旅游扶贫宣传推广。利用网站、微信、微博等平台，大力宣传中省市关于脱贫攻坚、乡村旅游等决策部署和文件会议精神，使广大群众和贫困户及时了解掌握旅游扶贫政策。全面介绍全县旅游扶贫工作的思路、举措和成效，及时报道县旅发委发展乡村旅游、实施旅游扶贫、开展走访慰问等工作情况，深入挖掘我县旅游扶贫工作的经验做法和先进典型，积极开展乡村旅游产品与项目的公益性宣传。以油菜花节为重点，强化对外宣传推介，精心举办旅游节会，积极参加会展促销，进一步拓展旅游市场、吸引人气财气、促进农民增收。大力发展智慧旅游，完善信息咨询、产品营销、综合服务等功能，实现免费WiFi、智能导游、电子讲解、信息推送等功能全覆盖，不断提升服务游客群众的能力。（文广局牵头，扶贫办、旅发委配合）

（五）加快贫困地区旅游项目建设。支持贫困村旅游项目建设，积极打造具有核心竞争力的旅游产品，吸引游客消费，直接增加贫困人口就业，带动周边贫困人口通过提供住宿、餐饮、商品及劳务增加收入。深入推进乡村旅游“后备箱工程”，鼓励各类市场主体整合开发乡村特色土特产品，打造一批乡村旅游“热购商品”，提高贫困地区农产品附加值，带动贫困人口增收。（发改局、农业局牵头，旅发委、各镇办配合）

（六）开展旅游扶贫示范工程。以“全域旅游”为发展理念，注重产业带动脱贫增收实效，重点培育打造1-2个旅游扶贫示范村，鼓励星级饭店、旅行社、景区等涉旅企业参加扶贫活动。通过以奖代补形式，给予政策和资金支持，发挥财政资金撬动作用，提高政府、企业和其他组织的积极性，确保形成工作合力，为全县旅游扶贫创建经验，形成示范。（发改局、财政局、经贸局、扶贫办、旅发委、各镇办负责）

（七）实施“送教上门”培训。围绕解决贫困地区旅游人才缺乏的问题，持续组织实施”送教上门”培训工作，按照“培训一人、就业一人、脱贫一家”的扶贫工作要点，重点做好旅游扶贫干部、旅游投资项目负责人、旅游扶贫村村干部、乡村旅游带头人、乡村旅游经营户、能工巧匠传承人、乡村旅游创客、乡村旅游导游等八类人才培训，提高从业人员整体素质。（人社局牵头，旅发委、各镇办配合）

三、多措并举，确保旅游扶贫取得实效

县旅发委要加强与相关部门的协调配合，将旅游扶贫做为乡村振兴战略的重要内容，推动与美丽乡村、特色小镇等融合发展，确保旅游扶贫取得实效。

（一）结合发展乡村旅游推动“三变改革”。积极引进企业化运营管理模式，培育壮大集体经济，建立科学合理利益分配机制，引导和支持贫困群众通过土地、宅基地入股等形式参与旅游经营，积极安排贫困人口到企业就业，实现增收脱贫。（扶贫办牵头，农业局、旅发委、各镇办负责）

（二）加大项目招商引资力度。将旅游扶贫推荐项目纳入招商引资手册，加大推介工作力度，努力实现引进一批企业、带活一方经济、脱贫一批建档立卡贫困户。将旅游扶贫项目、产品做为旅游目的地宣传的重要内容，组织旅游扶贫项目相关企业参加各类推介会。对于旅游扶贫重点村的项目，在组织参加宣传推介时，应综合考虑重点村集体经济情况，采取减免参展费用等方式予以支持。（招商办牵头，文广局、旅发委、各镇办负责）

（三）发挥好财政资金的引导作用。落实“凡财政资金支持的项目必须有扶贫内容”要求，引导财政资金支持项目通过安置就业、收购农产品、组织培训、扶持发展农家乐等形式，与旅游扶贫重点村开展结对帮扶，确保贫困人口直接受益。（财政局牵头，发改局、旅发委、各镇办负责）

（四）扎实推进苏陕旅游协作。进一步加强与江苏省南通如皋市旅游部门联系，推动苏陕合作项目落地生根。落实《关于支持苏陕合作项目带动贫困人口脱贫的意见》《关于推动落实〈苏陕旅游战略合作协议〉的通知》，与江苏省南通如皋市签订两地旅游发展战略合作协议；针对江苏企业和游客，出台管用的优惠政策，吸引江苏企业和游客来汉投资兴业，旅游观光。（旅发委牵头，招商办负责）

（五）大力推广旅游扶贫先进模式。充分发挥好政府的主导作用，大力推广草坝、柳山等旅游扶贫工作经验，并在实践中不断创造新的经验。认真推广“景区带村”、“能人带户”、“企业+农户”、“合作社+农户”等旅游扶贫模式，深入持续开展“旅游万企万村帮扶”活动，发挥好企业和能人在旅游扶贫中的作用。（文广局牵头，旅发委、扶贫办、各镇办负责）

（六）加大先进典型宣传力度。深入挖掘和宣传旅游扶贫先进经验，在全社会营造关心、支持旅游扶贫的良好氛围。对贫困地区特色资源及旅游扶贫典型经验进行宣传，指定专人负责做好旅游扶贫宣传工作；联合相关媒体深入我县组织系列报道，对旅游扶贫先进典型进行表彰奖励。（文广局牵头，旅发委、脱贫办负责）

（七）积极改变工作作风。要认真贯彻落实习近平总书记就新华社《形式主义、官僚主义新表现值得警惕》一文作出的重要批示精神，切实克服旅游扶贫工作中的形式主义、官僚主义。抓好《陕西省脱贫攻坚工作倒查追责九条规定》落实，确保不发生问题。各责任部门要按照通知要求，认真制定好2018年度旅游扶贫工作计划，做到目标明确、措施具体、责任夯实，并指定一名分管领导和工作人员具体负责旅游扶贫工作，于3月26日前将年度旅游扶贫工作计划，分管领导、工作人员名单及联系方式报县旅发委；每季度最后一个月18日前报送季度旅游扶贫工作总结及旅游扶贫情况统计表。县政府督查室将其做为季度追赶超越及旅游扶贫考核的重要内容并适时进行通报。（各责任部门、各镇办负责）
