# 洋政办发〔2018〕52号关于进一步明确责任切实做好优化提升营商环境各项工作的通知

洋政办发〔2018〕52号

洋县人民政府办公室

关于进一步明确责任切实做好优化提升

营商环境各项工作的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为深入贯彻落实省、市优化提升营商环境电视电话会议精神和陕西省“营商环境提升年”部署安排，进一步加快政府职能转变，打造稳定公平透明、可预期的法治化、国际化、便利化营商环境，助力“六个洋县”建设和追赶超越发展，现就进一步明确责任切实做好优化提升营商环境各项工作通知如下：

一、充分认识我县营商环境现状，对标自查，切实增强紧迫感

4月8日，省统计局通报了全省第一季度县域营商环境监测评价结果，在四大类29项监测事项中，我县22项指标排序全省50名以后。在全省107个县和17个开发区及14个自贸区，共计138个监测对象中，我县综合排名第116位，在全市11个县（区）中，我县排名末位。

各部门要认真对照各监测事项全省平均水平和全市指标要求，逐项分析落后原因，找出症结所在，确定追赶目标，并结合实际，找准薄弱环节，研究细化有针对性、可操作性的工作措施，就各项指标的审批时限、办理成本和申请材料件数，逐一做出“数字性承诺”，在5月10日前，向县委、县政府递交“军令状”（见附件1《军令状样式》)。

我县排序在全省50名以后的监测事项分别为（见附件2《洋县2018年第一季度营商环境监测事项全省排名及责任单位一览表》）：

企业开办类（5项）：企业登记申请材料受理到发放营业执照所需的时间、涉税事项受理到办结所需的时间、银行开立账户受理到办结所需的时间、公章刻制受理到办结所需的费用、涉税事项受理到办结所需的费用；

开办施工许可、纳税和获得信贷类（7项）：所有环节共花费的时间、完成所有环节所需要的费用、纳税总额（不含非税缴纳）占同期经营收入的比率即综合税收负担率、企业（小额纳税人）完成纳税所需要的时间、是否使用民间资本、企业贷款中来自正规金融机构的比例、最近一次获得信贷所需的时间；

办事优化程度类（4项）：企业获得水所需要的时间、企业获得气所需要的时间、企业获得水所需要的费用、企业获得气所需要的费用；

政务服务和产权登记类（6项）：是否按省上统一标准建设网上服务平台并与全省平台无缝对接、政府对权责清单进行动态管理情况、一站式办结事项占本级政府部门全部审批服务事项数比例、网上办理事项占本级政府部门全部审批服务事项的比例、取得土地使用证共花费的时间、取得土地使用证共花费的费用。

二、进一步明确工作职责，提高站位，切实增强责任感

优化营商环境是一个系统工程，十大行动涉及各个部门，各部门要自觉深化“优化营商环境就是解放生产力、提升综合竞争力”的认识，提高思想站位，切实增强责任感。在各司其职、各负其责的基础上，牵头部门要充分发挥主观能动性，勇于担当，自觉做好统揽协调工作，配合部门要主动衔接沟通，积极反映工作进度，持续优化提升营商环境。

三、进一步严明纪律，狠抓落实，力促营商环境大改善

各部门、各单位要充分认识优化提升营商环境工作的重要性和必要性，按照“追赶超越”的精神要求，精心研究、深刻领会、狠抓落实，积极主动推动优化提升营商环境工作，筑牢“六个洋县”建设基础。

（一）加强领导。各部门、各单位要构建组织有力、协调顺畅、联动高效的领导机制，全面加强对优化提升营商环境工作组织领导和协调推动，明确分管领导，确定责任科室和责任人，建立健全工作机制，确保工作落实、取得实效。

（二）迅速行动。各部门、各单位要以“办公场所下移、工作重心下沉、工作精力下派”的工作状态，迅速采取有力措施，补齐自身的短板，切实解决影响和制约营商环境建设的突出问题，逐项抓好推进落实，要以长流水、不断线的韧劲恒心持续推进。

（三）严肃问责。各部门、各单位要以“精准严实”的工作作风，力促营商环境不断优化提升，以作风的大转变来推动效能的大提高，以服务水平的大提升来促进营商环境的大改善。对工作推进中不作为、慢作为、乱作为，造成第二季度县域营商环境监测评价排序未进入全省第一方阵的，县政府将严肃追究责任。
