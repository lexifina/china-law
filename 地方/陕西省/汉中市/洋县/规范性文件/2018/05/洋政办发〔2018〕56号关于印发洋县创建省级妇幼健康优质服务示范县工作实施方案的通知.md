# 洋政办发〔2018〕56号关于印发洋县创建省级妇幼健康优质服务示范县工作实施方案的通知

洋政办发〔2018〕56号

洋县人民政府办公室

关于印发洋县创建省级妇幼健康优质服务

示范县工作实施方案的通知

各镇人民政府、街道办事处，县政府有关工作部门、直属机构，市管单位：

《洋县创建省级妇幼健康优质服务示范县工作实施方案》已经县政府同意，现印发给你们，请认真组织实施。

洋县人民政府办公室

2018年5月15日

洋县创建省级妇幼健康优质服务示范县

工作实施方案

为扎实推进省级妇幼健康优质服务示范县创建工作，提升我县妇幼健康服务管理水平，按照《国家卫生和计划生育委员会关于实施妇幼健康优质服务示范工程的通知》（国卫妇幼发〔2014〕39号）《陕西省卫生计生委关于推进2017年妇幼健康优质服务示范工程的通知》（陕卫办妇幼函〔2017〕220号）和《汉中市卫生和计划生育局关于推进2017年妇幼健康优质服务示范工程的通知》（汉卫计发〔2017〕135号）精神，结合我县实际，制定如下实施方案。

一、指导思想

坚持以党的十九大和习近平总书记系列重要讲话精神为指导，认真贯彻落实《中华人民共和国母婴保健法》《中华人民共和国人口与计划生育法》《2011-2020年中国妇女儿童发展纲要》和《2011-2020年陕西省妇女儿童发展纲要》，牢固树立“儿童优先、母亲安全”宗旨意识，加快推进妇幼健康优质服务能力建设，切实满足广大妇女儿童健康服务需求，不断提升妇幼健康工作水平。

二、工作目标

将妇幼健康工作纳入经济社会发展总体规划和政府目标责任考核范畴，建立有效的协调工作机制和稳定的投入保障机制。按照有关标准，规范妇幼健康服务机构建设，健全和完善妇幼健康服务体系，完善管理机制、工作制度、技术规范、操作流程，确保监督管理有力、制度执行到位。不断提高医疗保健服务质量和水平，持续提升妇女儿童核心健康指标，做优妇幼健康服务品牌，确保服务对象满意度逐步提高。

三、主要内容

（一）完善规划体系。将妇幼健康工作纳入经济和社会发展规划，将孕产妇死亡率、婴儿死亡率、5岁以下儿童死亡率、避孕节育服务有效率、出生缺陷防治措施落实率等妇幼健康核心指标纳入年度目标责任考核。制定妇幼健康事业发展规划并组织实施，明确各相关部门职责，建立协调工作机制，实施妇幼健康目标管理。落实妇幼健康服务各项工作经费，保障各项任务顺利完成。

（二）强化能力建设。加快推进妇幼保健与计划生育技术服务资源优化整合，全面实施机构标准化建设，保障基本业务用房，配置基本医疗资源；狠抓人才队伍建设，落实人员编制和经费，配备专业技术人员，建设妇幼健康重点专科。坚持“以保健为中心，以保障生殖健康”为目标，为妇女儿童提供从出生到老年、内容涵盖生理和心理的主动、连续的医疗保健服务与健康管理，夯实公共卫生责任，突出群体保健功能，落实妇幼健康服务指标。

（三）健全完善规章制度。严格按照有关标准规范，加快完善妇幼健康服务相关管理制度、工作规范、技术标准、操作流程等，健全监督评价机制体制。各相关医疗机构建立健全产科、产房、新生儿科和计划生育技术服务管理制度，规范工作流程。妇幼健康服务机构严格执行医疗服务的相关法律法规和管理规定，其他提供妇幼健康服务的医疗机构认真落实妇幼保健工作的相关要求，县卫计局等业务主管部门定期组织对制度落实情况进行督导检查，确保各项制度落实到位。

（四）加强人员培训。制定并组织实施妇幼健康人员业务培训规划，大力培训推广适宜技术和新技术，加强对妇幼健康工作的业务指导、培训管理和综合评价，采取多种方式强化岗位培训和医学继续教育。以群众需要为目标，广泛开展便民惠民服务，改善服务设施，优化服务流程，积极开展群众满意度调查，不断适应群众对妇幼健康服务的需求。

（五）提升服务质量。强化危急重症孕产妇和新生儿救治中心建设，健全急救转诊网络，确保绿色通道通畅。建立健全妇幼健康服务机构服务质量、医疗安全评价体系，加强重点环节、重点区域、重点人员管理，改进服务质量，确保医疗安全。严格落实首诊负责、三级医师查房、疑难病例讨论、会诊、术前讨论、死亡病例讨论、交接班等核心制度，规范病历书写，促进合理检查、合理用药、合理治疗。合理控制剖宫产率，积极倡导母乳喂养。

（六）推进母婴健康安全行动。降低孕产妇死亡率、婴儿死亡率、5岁以下儿童死亡率及出生缺陷率，提高免费计划生育技术服务率工作指标。

1、开展妇幼健康民生项目。全面推进孕产妇系统保健免费基本服务项目，做好免费孕前优生健康检查、增补叶酸预防神经管缺陷、孕产妇健康管理、产前艾滋病和梅毒检查、农村孕产妇住院分娩补助、新生儿疾病筛查和听力筛查、0-6岁儿童健康管理，优化服务流程，开展项目宣传、培训和督导，完成目标任务，按要求汇总上报信息。规范实施农村妇女宫颈癌、乳腺癌检查，贫困地区儿童营养改善和儿童健康管理等妇幼重大和基本公共卫生服务项目，确保各项目标顺利完成。

2、加强出生缺陷三级防控。组织开展婚检摸底调查，建立产前筛查转诊救治网络，组织产前超声检查培训，做好新生儿疾病筛查，开展阳性患儿的早期干预，努力减少出生缺陷和残疾发生。加强产科质量安全管理，开展孕产妇危重症评审，做好孕产妇和新生儿死亡评审工作。组织新生儿窒息复苏技术的师资培训。

（七）强化监督管理。以贯彻落实《医疗机构从业人员行为规范》为重点，深入开展医务人员职业道德和法制纪律教育，加强行风建设，提升医德医风水平。加强对群众的健康教育，传播健康知识，提高群众健康素养。全面推行妇幼健康服务机构院务公开制度，通过设置意见箱、开通热线电话和网上信箱等多种形式，畅通投诉举报渠道，主动接受社会各界监督。将母婴保健和计划生育技术服务监督执法纳入综合监督执法，严格机构、人员和技术准入，规范服务行为。建立妇幼健康服务定期巡查和不定期抽查制度，组织开展日常巡查检查。强化《出生医学证明》管理，加强妇幼信息系统使用管理，提高妇幼信息化管理水平。

（八）树立行业良好形象。弘扬良好职业道德、服务意识和奉献精神，为妇女儿童提供人性化服务和人文关怀。树立先进典型，加大对爱岗敬业、勤奋工作、无私奉献先进典型的宣传报道力度，展现广大妇幼健康工作者精神面貌，塑造好形象，传递正能量。

四、职责分工

各镇办：开展妇幼健康知识健康教育和宣传动员工作。做好服务对象的摸底调查、组织协调工作。组织各村（社区）完善妇幼健康服务原始登记工作，整理装订档案，迎接检查验收。

县卫计局：建立部门信息联动和协调推进工作机制，明确相关部门职责分工，制定妇幼健康事业发展规划并组织落实。将妇幼健康服务机构建设纳入区域医疗卫生机构建设规划，积极推进区域妇幼健康服务信息化建设。督促妇幼健康服务机构落实妇女儿童保健和计划生育各项指标。

县发改局：将促进妇女儿童健康事业纳入“十三五”经济和社会发展总体规划，并对妇幼健康服务体系建设给予重点支持，不断提升全县妇幼健康服务管理水平。

县教体局：以儿童保健、青少年生殖保健为重点，强化健康教育。督促托幼机构落实体检、膳食营养管理、消毒、保健人员配置等。协助县卫计局加强全县托幼机构卫生保健监督管理工作。

县财政局：根据创建省级妇幼健康优质服务示范县需求，统筹安排保障项目经费。

县人社局：支持相关妇幼健康服务机构建立妇幼健康服务人才培养、引进、招聘和薪酬分配激励机制，鼓励妇幼健康相关专业技术人员服务基层。逐步提高医疗保险、生育保险中妇女儿童健康的保障水平。

县编办：根据妇幼健康服务机构编制标准，核定妇幼健康服务人员编制数。采取调剂措施，落实妇幼健康服务机构人员编制，解决当前妇幼健康服务机构紧缺岗位人员配置。

县文广局：做好《中华人民共和国母婴保健法》、“两纲”、妇幼健康科普知识及妇幼健康服务项目的公益宣传，对妇幼健康事业发展重大事件及时进行新闻报道，提高群众对国家惠民政策的知晓率。

县妇联：协调和推动各部门加快推进“两纲”和陕西省妇女儿童发展规划实施，积极发挥妇联协调作用，做好宣传动员，协助做好农村妇女病普查工作，维护妇女儿童合法权益。

县残联：做好妇幼健康服务机构筛查转介的智力、听力、脑瘫等残疾儿童的救助康复、信息统计和康复情况反馈等工作。完善儿童疾病筛查服务网络，做到早发现、早诊断、早康复，减少儿童残疾发生，提高人口素质。

县人民医院：加强妇产科、儿科建设，完成孕产妇急救中心建设任务。建立和完善各项工作和管理制度，急救绿色通道通畅，规范各项服务行为，积极开展业务人员培训，不断提高服务水平。

县妇幼保健计划生育服务中心：加强妇产科、儿科建设，完成新生儿急救中心建设任务。承担省级妇幼健康优质服务示范县创建办公室日常工作。组织妇幼健康服务专业人员，督促指导各单位创建工作，对照考核指标，查漏补缺，搜集完善创建办公室相关资料。

五、实施步骤

创建省级妇幼健康优质服务示范县分为4个阶段进行：

第一阶段：安排部署（2018年5月20前）。成立创建领导小组，印发实施方案，细化分解工作任务。组织召开全县创建省级妇幼健康优质服务示范县启动会议，对创建工作进行动员部署。

第二阶段：组织实施（2018年5月21日至9月30日）。各镇办、相关部门和单位按照《妇幼健康优质服务示范工程评估指标体系（2017年版）》积极开展各项创建工作，做好迎接抽查复核准备。

第三阶段：抽检复核（2018年10月8日至12月底）。省卫计委组织对创建工作进行验收考评。

第四阶段：巩固提升（2019年1月至12月）。继续加强示范县建设，不断总结经验，巩固成效。力争2020年创建成为国家级妇幼健康优质服务示范县。

七、工作要求

（一）加强领导，夯实责任。实施妇幼健康优质服务示范县创建工作是落实深化医药卫生体制改革要求，强化我县妇幼健康服务能力建设的重要抓手，对于提升我县妇幼健康服务管理水平具有重要意义。各镇办、各部门要切实增强责任感、使命感和紧迫感，把妇幼健康优质服务示范县创建作为一项重点工作来抓，实行主要领导亲自抓、负总责，建立多部门协作的工作机制，为妇幼健康优质服务示范县创建活动提供坚实的组织保障。

（二）突出重点，精心组织。各镇办、各有关部门要严格对照省级妇幼健康优质服务示范县的评估标准，进一步细化分解各项目标任务，采取有力措施，统筹推进示范县创建工作。要认真落实每一个阶段、每一个环节工作任务，力求做到有方案、有计划、有记录、有效果。要注重互联互通、形成工作合力，统筹解决好创建工作中的各种问题，确保创建工作取得预期成效。

（三）规范管理，加强督导。各镇办、各部门要严格按照有关要求，全力推进示范县创建工作。创建工作领导小组办公室要切实发挥综合协调、跟踪督导作用，定期联合县政府督查室，组织对各单位创建工作情况进行督促检查，不断提高妇幼健康优质服务规范化、科学化、制度化水平，确保如期完成创建工作任务。
