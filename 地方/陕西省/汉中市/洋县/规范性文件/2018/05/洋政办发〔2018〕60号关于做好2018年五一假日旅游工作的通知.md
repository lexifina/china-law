# 洋政办发〔2018〕60号关于做好2018年五一假日旅游工作的通知

洋政办发〔2018〕60号

洋县人民政府办公室

关于做好2018年五一假日旅游工作的

通 知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

五一小长假历来是我县旅游高峰，为做好假日旅游各项工作，切实提高假日旅游市场安全意识，强化旅游市场安全责任，实现假日旅游“安全、秩序、质量、效益、文明”五统一目标，让游客高兴而来，满意而归。现将有关事项通知如下：

一、切实加强组织领导

三月份以来，来洋游客日益增多，特别是随着2018中国最美油菜花海汉中旅游文化节暨洋县第九届梨花节启动以来，我县旅游接待压力不断增大，并将在五一小长假形成旅游高峰。各镇办、各部门、各单位要高度重视，按照“政府主导、分级负责、属地管理”的原则，强化领导责任，主要领导为旅游市场综合监管第一责任人，要加快建立完善权责明确、执法有力、行为规范、保障有效的旅游市场综合监管机制，加强对旅游市场秩序的日常监管，并将旅游市场秩序综合治理和服务质量提升工作纳入考核范围，县上将结合目标责任考核，对各镇办、各部门、各单位旅游市场综合治理行动开展情况进行督导考核。

二、突出抓好安全管理

一是抓好旅游交通安全。县交通局要针对旅游团队车辆多、自驾车出游多、游客密集出行等特点，及早制定运力调配和客流疏导方案，避免大范围的游客滞留；县交通局、交警大队、运管所要加强旅游客运监管和交通设施维护，加强对重点路段的交通疏导，严查非法营运和超时超载运营，增强重点时段、路段、道口的警示标志和警力部署，严防发生旅游交通事故。

二是抓好旅游节庆活动安全。节庆活动要按照“谁主办、谁负责，谁审批、谁负责，谁检查、谁负责”的原则，落实好主体责任和安保措施，保证各类节庆活动安全。对在旅游景区、广场、商场等公共场所内自发形成的游客聚集活动，要有分析预判，制定应急预案，定点部署警力，加强现场疏导，确保人员安全。

三是抓好旅游安全排查。县旅发委要督促旅游企事业单位，扎实组织旅游安全隐患排查，对车辆、游船、观光车等游客运输工具，易发生安全事故的旅游项目和大型游乐设备，可能发生火灾、食物中毒及群众伤亡的大众娱乐场所、宾馆饭店、餐饮企业等领域加强排查，市监、交通、消防等部门要对重点环节加强排查，切实消除安全隐患。

四是抓好旅游综合环境整治行动。持续开展“三建设一整治”活动，加大旅游厕所及重点景区连接线旅游环境“脏、乱、差”整治力度。

三、不断提升服务质量

一要开展联合执法检查。县旅发委要在节前组织公安、交通、经贸、市监、物价等部门开展一次联合执法，重点对旅行社规范经营、景区及周边旅游市场秩序、涉旅企业诚信经营、旅游价格、宗教场所燃香、假日旅游组织及安全工作落实等情况进行检查。假日期间县旅发委将对全县旅游市场秩序进行重点抽查。

二是倡导诚信经营。各旅游景区、旅游饭店、旅行社等涉旅企业要从维护洋县城市形象、恪守旅游窗口单位诚信经营理念角度出发，严格践行承诺，对预定协议及优惠措施要不折不扣兑现；各星级饭店、旅社等住宿单位要采取有效措施，挖掘住宿潜能，制定应急预案，杜绝借机随意涨价、不讲诚信行为；相关部门要加大对非诚信经营企事业单位查处力度，规范旅游经营行为，维护好旅游市场秩序。

三是加强公共信息服务。充分发挥传统媒体和新兴媒体在旅游信息服务中的作用，综合利用广播、电视、报纸、网站、微博、微信以及车站、广场、景点信息屏等多种渠道，加强面向游客旅游出行信息服务；及时发布交通、住宿、游览、气象、卫生以及节日市场供求、价格等旅游公共信息，引导群众错峰出行，理性出游；加强对探险游等特种旅游活动的安全引导和提示，提高游客防范风险的意识和能力。同时，充分发挥新闻媒体的舆论引导作用，积极围绕文明旅游，推动公民文明旅游素质提升，使文明旅游理念深入人心。

四、认真做好值班工作

一是严格落实值班制度。节日期间，各镇办、各部门、各景区要科学安排值班工作，落实好领导带班、24小时值班制度，妥善处理假日期间各项事务，不得私自将值班电话呼叫转移，保证信息畅通。各单位要将五一期间带班领导、值班人员信息（姓名、职务、联系电话、手机号码）于2018年4月28日前报县政府及县旅发委。值班人员在本单位保持在岗，电话畅通，有突发事件第一时间启动《洋县旅游安全应急预案》，各有关镇办、部门要全力配合，力争将损失降到最低。

二是妥善处理咨询投诉。县旅发委要面向社会公布游客咨询、投诉电话，确保咨询投诉电话24小时有人接听；及时解答游客咨询，妥善处理游客投诉。县旅发委按属地管理和部门职能对旅游投诉进行转办，及时处理游客投诉。

三是及时报送旅游信息。各旅游接待单位要在假日每天13:30前将各自统计数据报县旅发委，旅发委要将假日每天旅游统计数据及当日旅游小结经当日值班领导签字后，于15：00时前向市假日办报送。

假日期间的整体旅游接待情况要于5月1日15:00前报市旅发委及县委、县政府。（旅游咨询、投诉电话：0916-2982076）

洋县人民政府办公室
