# 洋政发〔2018〕21号关于印发县级部门行政许可项目目录（2018版）的通知

洋政发〔2018〕21号

洋县人民政府

关于印发县级部门行政许可项目

目录（2018版）的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为了进一步深化行政审批制度改革，按照《陕西省人民政府办公厅关于印发<陕西省权力和责任清单管理办法>的通知》（陕政办发〔2016〕17号）和《陕西省机构编制委员会办公室陕西省人民政府法制办公室关于印发<陕西省市县两级行政许可项目通用参考目录>的通知》（陕编办发〔2017〕158号）要求，推进行政许可事项标准化，规范行政许可名称，县政府决定发布《县级部门行政许可项目目录（2018版）》（以下简称《目录》），现就有关事项通知如下：

一、规范实施。各部门要结合“陕西省权责清单和公共服务事项清单统一发布平台”发布的权责清单事项，及时做好本部门有关事项的调整和规范。严格按照公布的项目名称、实施依据、承诺时限、收费情况、办理材料和审批流程图等内容进行许可行为，以方便公民、法人和其他组织申请和办理相关审批事项。同时，要进一步简化审批程序、精简申报材料、缩短审批时限、降低收费标准，建立健全网络全程监控、办理时限预警、日常考核督办等长效机制，不断提升服务水平。

二、加强监管。从本通知印发之日起，各部门只能对《目录》所列的行政许可项目实施审批。除以上审批事项外，一律不得实施审批或变相审批，坚决杜绝随意新设、边减边增、明减暗增等问题。有关部门要加大对行政审批工作的监督力度，及时发现和纠正违法违规审批行为，依法依纪追究违反有关规定的相关单位和人员责任。

三、动态调整。中省市取消、下放行政审批事项成为一项常态，各审批实施部门要根据中省市取消和下放行政审批事项的文件精神，及时与上级业务部门做好沟通衔接，提出取消、承接意见报县编办（县审改办），县编办（县审改办）按照《陕西省权力和责任清单管理办法》相关要求会同县政府法制办审定后，按程序在“陕西省权责清单和公共服务事项清单统一发布平台”进行调整并向社会公开。这次《目录》发布后，县政府今后将不再单独公布行政许可项目目录，各部门按照县审改办《关于加强权责清单统一发布平台数据维护工作的通知》（洋审改办发〔2017〕1号）精神进行调整。
