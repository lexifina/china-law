# 洋政办发〔2018〕68号关于进一步加快财政扶贫资金支出进度的紧急通知

洋政办发〔2018〕68号

洋县人民政府办公室

关于进一步加快财政扶贫资金支出进度的

紧急通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构：

按照中、省、市关于脱贫攻坚的重大部署要求，为进一步加快财政扶贫资金支出进度，提高资金使用效益，确保实现全省半年核查财政扶贫资金支出进度达到50%以上，现将有关事项通知如下：

一、提高政治站位，增强财政扶贫资金支出的责任感和紧迫感

加快财政扶贫资金的支出进度，是打赢全县脱贫攻坚战的重要举措，各镇（办）、部门要从思想上高度重视，提高政治站位，切实把加快财政扶贫资金支出进度作为当前一项重要任务来抓，采取超常规的措施，确保全年财政扶贫资金支出进度目标的顺利完成。

二、加快资金拨付，尽快形成支出，提高财政扶贫资金使用效益

按照“急事急办、特事特办”的原则，缩短文件传递、预算下达、资金拨付等环节运转的时间，各镇（办）及相关部门在收到扶贫资金后2日内应尽快组织实施，需拨付村级的扶贫资金在2日内拨付。严禁资金滞留、趴窝，一经发现，将严肃处理。

三、夯实任务，落实责任

按照省级核查要求，财政扶贫资金实际支出进度应达到50%以上，各镇（办）及相关部门要高度重视，加快支出进度，尽快完善报账资料，不得虚报、瞒报，确保支出数据真实性。特别是今年中省专项扶贫资金在6月底前支出务必达到70%以上。对于支出进度缓慢的镇（办）及部门，县政府将对主要负责人进行约谈。

四、加强督办，定期通报

实行支出进度月报制度，每月4日（遇节假日提前报送）由各镇（办）及相关部门将《洋县2018 年统筹整合财政涉农资金项目支出明细统计表》电子版上传县统筹整合使用财政涉农资金领导小组办公室微信群（县财政局农财科），并将纸质版加盖公章后一并报送。县整合办要按各单位报来的支出进度进行评比排名送县脱贫攻坚指挥部，对连续三次排名靠后的单位发出书面整改函,予以全县通报批评，并视其情况作为线索移交县监察委。

洋县人民政府办公室

2018年6月26日
