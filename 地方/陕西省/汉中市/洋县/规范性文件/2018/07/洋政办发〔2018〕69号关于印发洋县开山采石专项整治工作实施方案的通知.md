# 洋政办发〔2018〕69号关于印发洋县开山采石专项整治工作实施方案的通知

洋政办发〔2018〕69号

洋县人民政府办公室

关于印发洋县开山采石专项整治

工作实施方案的通知

各镇人民政府、街道办事处，县政府有关工作部门、直属机构，市管单位：

《洋县开山采石专项整治工作实施方案》已经县政府同意，现印发给你们，请认真贯彻执行。

洋县人民政府办公室

2018年6月26日

洋县开山采石专项整治工作实施方案

按照省、市人民政府关于深入开展开山采石专项整治切实加强采石场管理的通知要求，我县扎实开展采石场专项整治工作，自2015年起至2017年底全县采石企业数量减少了50%；扭转了全县采石业“多、小、散、乱”局面，提高了石材资源对经济建设的保障能力，减少了环境破坏。按照中央环保督察反馈问题整改和秦岭生态环境保护要求，为进一步保护秦岭生态环境，落实环保督察整改，现制定我县开山采石专项整治工作实施方案如下：

一、目标任务

通过综合整治，实现“三年减一半、五年大变样”的总体目标。到2020年底，全县保留采石企业不超过7家，实现矿山开发合理布局，矿山企业结构不断优化，矿产资源开发利用水平明显提高，安全生产条件和矿区生态环境明显改善，对经济发展的保障能力明显增强。

二、清理整治范围

（一）依据陕西省国土资源厅办公室《关于汉中市开山采石专项整治工作有关问题的复函》（陕国土资矿函〔2016〕74号）文件精神，我县开山采石企业整治范围为建筑石料及饰面石材开采企业，水泥厂自备矿山和石英岩等特殊用途矿种不列入开山采石整治范围。

（二）禁采区内的采石企业。根据我县实际，在“三区两线”即长青自然保护区、朱鹮保护区、风景名胜区、水源地保护区及重要交通干线、河流湖泊直观可视范围内的矿山企业一律予以关闭。水土流失严重、生态脆弱地区从事露天开采石材、石料等非金属矿产资源的矿山企业一律纳入专项整治范畴。

（三）违法违规采石企业。1．未依法取得采矿许可证、工商营业执照、安全生产许可证等证照，土地、环境保护、林地、水土保持等手续不全，擅自开山采石的；2．存在越界开采、非法转让、开采矿种与核准矿种不符等违法行为，且未按要求整改的；3．违反建设项目安全设施、污染治理设施“三同时”规定，拒不执行安全环保监管指令、在限期内未完善相关手续的；4．采矿许可证和安全生产许可证到期未提出延期换证申请，经限期整改仍未办理延期换证手续的；5．不按期缴纳各种税费，经责令限期缴纳仍不缴纳的；6．关闭后擅自恢复生产的。

（四）小规模和技术落后企业。1．年开采规模10万吨以下的；2．使用国家或地方政府明令淘汰的落后工艺、技术和设备，安全生产和环境保护得不到保障的；3．无正规设计或不按设计规范建设，开采方式和方法不符合规定的。

（五）存在安全隐患的采石企业。1．存在防洪行洪、地质灾害隐患的；2．相邻露天采石场采矿许可证核准的范围之间最小距离（300米）不符合有关规定的；3．发生较大以上安全生产责任事故或次生环境事件，且整改不到位的。

（六）对生态环境影响较大的采石企业。不按规定编制矿山地质环境保护与恢复治理方案，不依法缴存保证金且不落实环境恢复责任的。

（七）省市颁发采矿许可证的矿山按照省市的处置方案由洋县人民政府予以整合整治。对砖瓦用页岩矿，结合洋县第三轮矿产资源规划编制工作做出专题的发展规划，分区域、有计划的进行整合整治。

三、整治工作步骤

（一）编制规划阶段（2018年6月底完成）。在摸底调查的基础上，由县国土局牵头，会同发改、安监、环保、水利、林业等部门，各镇办配合，完成2016—2020年采石场发展规划和县级矿产资源规划编制工作。采石场发展规划报县政府批准后实施,县级矿产资源规划经专家论证报市级审批。

（二）集中整治阶段（2018年6月—2020年6月）。在整治工作期间，暂停县级新设立采石矿权的审批。对决定关闭的矿山，由县政府组织有关部门依法实施关闭，妥善解决遗留问题，确保关闭到位和社会和谐稳定。对列入整合的矿山，按照“先停产、后整合”的原则，督促整合企业签订协议，落实整合主体，确保整合工作顺利实施和生产安全。县政府将根据整治工作进展情况，组织有关部门对重点地区和突出问题进行督导检查。

（三）组织验收阶段（2020年6月—12月）。县政府将组织有关职能部门以镇办为单位统一进行验收，验收不合格的，要及时整改。验收合格后，对保留的采石企业和整合企业，按照审批权限统一换发证照。

四、关闭矿山企业措施

（一）依法吊销或注销采矿许可证、安全生产许可证，责令变更经营范围或注销营业执照；

（二）拆除供电、供水、运输等直接用于生产的设备和设施；

（三）清理废石废渣，恢复生态环境，消除重大安全、地质灾害和环境隐患，地表设立警示标志，封堵进入采矿场的道路；

（四）清理收缴矿山留存的民用爆炸物品和危险化学品。

五、工作分工及要求

（一）夯实各级责任。各镇办是落实整治工作的实施主体，要依法有序实施整治工作，落实责任，形成合力，确保整治工作顺利实施。

（二）加强组织领导。县国土局牵头，县环保、林业、水利、公安、市监、安监、地税、电力等部门和单位密切合作，建立顺畅的沟通协调机制，切实组织好专项整治工作。

（三）明确部门分工。各相关部门和单位要结合各自职能及本次整治的要求，各司其职、紧密配合，按照时间节点，全面完成专项整治工作。国土部门主要负责检查采矿许可证有效性，合法合规开采，依法转让等情况；检查矿产资源开发利用方案、矿山地质环境保护与土地复垦方案的编制、审查、实施以及矿山地质环境治理恢复基金缴存情况。安监部门主要负责检查企业安全生产许可证有效性和安全生产情况。环保部门主要负责检查开山采石企业开发利用的环境影响评价文件编制、审批及执行情况；检查矿山生态环境恢复治理方案编制、审批及实施情况；检查自然保护区内等开山采石环境破坏情况。林业部门负责检查林地使用手续审批及林地保护，做好关闭矿山植被恢复。水利部门主要负责检查水资源及河道保护情况，水土保持方案编制、审批及实施情况。公安部门主要负责检查火工品的使用与保存情况。市场监管部门主要负责检查企业营业执照载明的经营范围是否含有开山采石项目。税务部门主要负责检查税费缴纳情况。相关部门要完善执法机制，建立健全联合执法工作机制，采取有效措施，努力推动整治工作顺利实施。

（四）强化监督检查。县国土局要加强宣传引导和社会监督，分期分批将关闭对象在当地主流媒体公告，同时设立举报电话、举报信箱，鼓励广大群众积极举报非法违法行为；加大督导检查力度，对不认真履职、互相推诿、导致不能完成整治关闭工作任务或仍然存在非法违法矿山的，除依法依规严肃查处外，还要追究相关责任人的责任。
