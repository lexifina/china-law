# 洋政办发〔2018〕74号关于2018年第二季度县政府门户网站内容保障情况的通报

洋政办发〔2018〕74 号

洋县人民政府办公室关于

2018年第二季度县政府门户网站内容

保障情况的通报

各镇人民政府、街道办事处，县政府各工作部门、直属机构：

2018年第二季度，县政府门户网站共发布各类信息1165条，其中新闻动态类信息789条；信息公开类376条。政府各部门单位及镇办通过网站后台上传各类信息461条，政府信息中心上传信息704条。处理“县长信箱”和“咨询投诉建议”来信156件，已办结145件、超时办结23件，未办结11件。其中：财政局、环保局、市场监管局、农业局、国土局、卫计局、马畅镇在信息发布和信息公开总数量均超过20条，经贸局未发布和公开一条信息，信息统计为0；人社局、公安局在信件办理过程中回复及时，答复质量较高；住建局、龙亭镇、槐树关镇、洋州办、谢村镇、金水镇存在未办结信件。

根据第二季度总体情况来看，大多数单位在政府信息发布和处理群众来信情况较好，信息公开意识进一步加强，信息发布数量逐步增多，但部分单位依然存在信息公开量少，信息公开不及时的情况。在处理“县长信箱”信件过程中，依然存在信件处理不及时，信件答复质量不高，内容中存在敷衍搪塞、推诿责任的现象，且超期回复现象突出，个别单位依然存在信件未办结的问题。另外，部分单位没有按照政府网站所分配管理账号来发布信息，依旧通过QQ、邮箱等方式报送，导致这部分信息无法通过网站后台进行统计。以上问题请各单位务必高度重视，进一步加强组织领导，增强公开意识，完善工作方法，全力做好政府网站内容保障工作。
