# 洋政办发〔2018〕100号关于做好2018年中秋国庆假日旅游工作的通知

洋政办发〔2018〕100号

洋县人民政府办公室

关于做好2018年中秋国庆假日旅游工作的

通 知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

今年中秋、国庆假日，我县又将迎来一个旅游高峰，为做好双节假日旅游各项工作，实现假日旅游“安全、秩序、质量、效益、文明”的目标，现将有关事项通知如下：

一、高度重视，加强领导，全面启动假日旅游工作机制

做好中秋、国庆假日旅游工作，对提升我县旅游形象、促进旅游消费、维护社会和谐稳定具有重要意义。各镇办、部门及旅游接待单位要进一步增强大局意识、责任意识，及早部署本单位的假日旅游工作，制定并完善各项工作方案，按照“精心组织、周密安排、落实责任、加强协调”的总体要求，扎实做好双节假日旅游的各项工作。

为确保今年中秋、国庆假日旅游安全，及时有效地协调处理有关问题和各类突发事件，县政府决定成立中秋、国庆假日旅游工作领导小组，由县政府副县长杨妮娜任组长，县政府办主任李波、县旅发委副主任卢树森任副组长，华阳景区管委会、交通局、公安局、市监局、住建局、林业局、安监局、经贸局、消防中队、物价局、文广局、卫计局、交警大队、团县委、朱鹮梨园景区管委会办公室、朱鹮保护局、洋州办、纸坊办、戚氏办、龙亭镇、溢水镇、谢村镇、华阳镇、茅坪镇、黄安镇等单位主要领导为成员，负责假日期间的指挥、协调和应急处理等工作。领导小组下设办公室，办公地点设在县旅发委，办公室主任由卢树森同志兼任。

二、突出重点，落实责任，认真抓好旅游安全管理

随着今年汉中最美油菜花海节洋县分会场的成功举办，我县知名度不断提高，旅游外延不断扩大，内涵不断延伸，慕名而来的游客将对我县旅游接待工作产生巨大压力。各镇办、部门和接待单位要严格遵循“安全是旅游的生命线”要求，把旅游安全工作摆到突出位置，始终坚持“安全第一、预防为主”的方针，进一步增强安全意识，落实安全责任，完善安全措施，突出抓好旅游安全管理各项工作落实。

1.抓好旅游交通安全。交通局要针对旅游团队车辆多、自驾车出游多、游客密集出行等特点，及早制定运力调配和客流疏导方案，避免大范围的游客滞留；交通局、运管所要加强旅游客运监管和交通设施维护，严查非法营运和超时超载运营；交警大队要增强重点时段、路段、道口的警示标志和警力部署，严防发生旅游交通事故。

2.抓好游客密集场所安全管理。公安局、消防中队、市监局、安监局、卫计局等部门要加强交通集散地、旅游活动场所、住宿餐饮、旅游景区、游乐设施等重点部位的安全管理，督促业主单位建立和落实安全责任制，认真开展安全检查，消除安全隐患，严防踩踏、火灾、食物中毒、涉水溺亡等事故发生。林业局、消防中队要做好森林防火工作，制定周密应急预案，严防森林火灾发生。以原始生态资源为主的青山观、两角山、华阳等景区在双节期间人流大，将是森林防火的重点区域。林业局及相关镇办要及早部署，及时检查，安排专人严防死守，确保景区不出现火情。同时，加强对节庆活动的审查和监管，按照“属地管理”和“谁主办、谁负责，谁审批、谁负责”的原则，落实主承办单位和场所管理单位的安全责任，全面排查安全隐患，做好预案演练和现场疏导工作，严防群死群伤事故发生。

3.抓好旅游安全排查。开展节前联合执法检查，由旅发委牵头，公安局、市监局、经贸局、卫计局、安监局、物价局等部门参与开展联合执法，重点对旅行社规范经营、景区及周边旅游市场秩序、涉水区域安全、涉旅企业诚信经营、旅游价格、旅游场所食品安全、宗教场所燃香、假日旅游组织及安全工作落实等情况进行检查。双节期间，旅发委将对全县旅游市场秩序进行重点抽查。

4.各景区（点）要抓好内部安全管理。一是结合各自实际情况，迅速制订科学的安全接待容量、最大接待容量，各景区（点）接近最大接待容量时要及时向社会发布预警信息，超过最大接待容量的，谁接待、谁负责，防止因游客爆满带来安全隐患。二是各景区（点）要迅速制定接待方案和应急预案，同时要抓好应对各类公共性突发事件的准备工作。三是要建立旅游安全报警点，设专人值守，同旅游、公安部门随时保持联络畅通，同时要夯实各项安全保卫措施，检查消防、救护等安全预防工作，特别要加强古建筑、停车场、观光车、涉水区域、餐饮点和商品市场消防设备设施检查工作，危险路段和区域要设警示牌或护栏网，确保活动场所的安全。

三、全域联动，加强管理，不断提升旅游服务质量

1.做好旅游管理和服务工作。（1）旅发委：着力抓好景区的服务质量，认真受理并处理游客投诉，保证游客的切身利益，在县旅游咨询服务中心为游客提供咨询接待。（2）县团委：在两个高速路出口增设志愿者服务点，为旅客提供方便的旅游咨询服务。（3）各景区（点）：对本单位内部进行全面检查、清洁，整治旅游综合环境，以崭新的面貌迎接游客，加强景区最大承载量管控，制定详细的旅游接待工作方案，保证游客“吃、住、行、游、购、娱”无忧。（4）洋州办、纸坊办、戚氏办、磨子桥镇、龙亭镇、谢村镇、华阳镇、茅坪镇、溢水镇、黄安镇要对通往旅游景区(点)的主干道及周边环境进行集中整治，确保道路畅通美观。

2.加强公共信息服务。围绕服务游客出行，充分利用媒体资源，及时发布各类假日旅游提示信息。综合利用广播、电视、报纸、网站、微博、微信以及车站、广场、景点信息屏等多种渠道，加强游客旅游出行信息服务；及时发布交通、住宿、游览、气象、卫生以及节日市场供求、价格等旅游公共信息，引导群众错峰出行，理性出游；加强对探险游等特种旅游活动的安全引导和提示，提高游客防范风险的意识和能力。同时，充分发挥新闻媒体的舆论引导作用，积极围绕文明旅游，推动公民文明旅游素质提升，使文明旅游理念深入人心。

3.倡导诚信经营。各旅游景区、宾馆饭店、旅行社门店等涉旅单位要从维护洋县城市形象、恪守旅游窗口单位诚信经营理念角度出发，严格践行承诺，对预定协议及优惠措施要不折不扣兑现；各星级饭店、酒店等住宿单位要采取有效措施，挖掘住宿潜能，制定应急预案，杜绝借机随意涨价、不讲诚信行为；市监局要加大对非诚信经营企事业单位查处力度，规范旅游经营行为，维护好旅游市场秩序。

四、加强值班，畅通信息，做好旅游统计工作

为确保国庆中秋旅游安全、有序进行，及时有效协调处理各类问题，各镇办、部门和旅游接待单位要坚持24小时值班和主要领导带班制度，保证通讯畅通，双节期间值班名单于9月19日前报县旅发委。旅发委要全面负责全县旅游管理和接待协调工作，加强与有关部门、景点的信息联络。一旦发生险情和事故要迅速按照县政府《重大突发事件应急处理办法》处置，并按程序及时上报，对险情较大需要救援的，各有关镇办、部门和涉旅接待单位要积极配合，全力援助，把损失降到最低。

县旅发委要切实提高统计水平，各旅游接待单位双节期间每日10：30前将当日游客接待情况、收入情况及总体情况报送县旅发委。(旅游咨询、投诉电话：0916—2982076)
