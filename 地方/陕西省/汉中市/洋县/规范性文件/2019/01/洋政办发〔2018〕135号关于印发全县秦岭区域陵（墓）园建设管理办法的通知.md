# 洋政办发〔2018〕135号关于印发全县秦岭区域陵（墓）园建设管理办法的通知

洋政办发〔2018〕135号

洋县人民政府办公室

关于印发全县秦岭区域陵（墓）园建设

管理办法的通知

各镇人民政府、街道办事处、县政府有关部门：

《洋县秦岭区域陵（墓）园建设管理办法》已经县政府研究同意，现印发给你们，请认真贯彻执行。

洋县人民政府办公室

2018年12月26日

洋县秦岭区域陵（墓）园建设管理办法

为深入贯彻落实省委秦岭生态环境专项整治工作精神，健全秦岭生态环境保护长效机制，按照《中共汉中市委办公室汉中市人民政府印发关于全面深化殡葬改革的实施意见》（汉办发〔2017〕4号）和《汉中市民政局印发关于规范秦岭区域陵（墓）园建设管理保护秦岭生态环境的意见》（〔2018〕108号）文件要求，结合我县殡葬工作实际，现就有关工作通知如下：

一、持续推进骨灰安葬改革，减少殡葬设施对环境的影响

火葬区居民死亡后遗体经火化在骨灰堂或公墓内采取骨灰存放、树葬、花葬、草坪葬及骨灰撒散等生态节地葬法，不得将骨灰装棺再葬，不得超标准修建墓穴墓碑，提倡墓碑平卧或小型化。土葬改革区死亡人口遗体应当选择荒山瘠地实行集中安葬，从严控制墓穴占地面积和规格，不得使用钢筋混凝土、花岗岩等石材建造坟墓，严禁修建大墓、豪华墓，推行平地深埋、不留坟头的遗体安葬方式。提倡地上不建墓基，不建设硬质墓穴，推行墓碑小型化或不立碑，提高绿化覆盖率。耕地、林地，水库及河流堤坝附近和水源保护区、风景名胜区、文物保护区、城市规划区，以及铁路、高速公路、国道省道主干线两侧，严禁建墓立碑。坚决禁止擅自在承包土地、林地或农村集体土地、林地非法建造坟地，以及对外开展经营活动等违法行为。各镇（办）要根据实际情况配合殡葬管理部门强化骨灰管理，制定骨灰跟踪管理办法，严格实行骨灰有序流动。各经营性公墓要按规定设立生态安葬墓区，积极推广使用木质骨灰容器（骨灰盒）。各镇（办）要探索建立对自愿选择花葬、树葬、草坪葬、深埋等绿色生态葬法实行政府奖励政策，制定相关实施方案。

二、实行网格化管理，制止并依法处置乱埋乱葬行为

网格设置及划分标准参照《洋县秦岭生态环境保护网格化管理的实施意见》洋政办发〔2018〕104号文件具体实施。我县12个镇办123个村（社区）列入了秦岭区域陵（墓）园建设保护范围（详见附件）。按照界限清晰、任务均衡、管理便捷、无缝对接、全面覆盖的要求，全县秦岭生态区域陵墓园建设管理设置为三级网格体系，具体划分为1个一级网格（县级部门）；12个二级网格（12个镇办）；123个三级网格（各行政村、社区）。秦岭生态保护区所有镇（办）、村（社区）均纳入陵墓园建设网格监管，形成横向到边、纵向到底，不留空白、不留死角的秦岭生态区域陵墓园建设管理网格化监管工作体系。

一级网格：全县设立1个一级网格，分管县长为网格长，相关部门、镇办主要负责人为网格员，按照《陕西省秦岭生态环境保护条例》和《汉中市秦岭生态环境保护管理办法》《陕西省殡葬管理条例》要求各负其责，开展工作。主要工作职责：

1.制定全县秦岭生态环境陵（墓）园建设网格化管理实施方案和考核工作制度，完善运行机制。

2.负责全县秦岭生态环境陵（墓）园网格化管理各项工作的统筹协调、督导检查及考核管理。

3.协调解决下级网格上报的跨区域和重点问题。

4.做好与下级网格负责人的工作联系，及时传达并督促落实重点工作任务和要求。

5.开展本级网格工作情况调查研究，及时向包抓领导和县政府相关职能部门通报工作状况，督促解决具体问题。

二级网格：以镇办为单位，镇长、街道办主任为网格长，辖区行政村、社区主要负责人为网格员。主要工作职责：

1.制定方案。按照“定区域、定人员、定职责、定标准、定流程、定考核”的“六定”原则，制定本辖区秦岭生态区域陵（墓）园建设网格化管理方案。

2.统筹协调。开展本级网格工作情况调查研究，定期召开辖区秦岭生态区域陵（墓）园重点工作推进会，并做好会议记录。及时上传下达并落实重点工作任务和要求，统筹协调解决下级网格上报的问题。

3.检查处置。制定检查计划，对检查发现的问题进行处置。

4.信息上报。对检查中发现的陵（墓）园建设违法行为，迅速将情况上报到一级网格及相关职能部门，提出处理意见，配合相关部门进行处理。

5.监督考核。监督本辖区四级网格的工作开展情况，对网格员的工作进行指导、考核、评价。

三级网格：以行政村、社区为单位，主要负责人为网格长，每个行政村、社区确定1-2名网格巡查员。主要工作职责：

1.定期对所属网格进行巡视检查，及时了解辖区秦岭生态保护区域（陵）墓园建设管理各项工作进展情况。

2.对在秦岭生态环境保护区域的乱埋乱葬行为进行告知、劝阻。

3.及时上报检查中发现的秦岭生态区域乱埋乱葬行为，配合相关部门进行查处。

4.对查处问题进行全方位监督和跟踪落实，直至问题解决。

秦岭生态环境（陵）墓园建设网格化管理要发挥一级网格组织、指挥、督查、协调的领导作用，二级、三级网格巡查、发现、上报、及时处置的基础作用，对发现的问题，逐级负责，分级办理。三级网格负责网格内日常巡查监督，发现问题及时劝阻，及时上报二级和一级网格，并配合县、镇（办）相关部门对违法行为及时处置。对上级反馈的问题处理处置情况再次进行核查，直至问题最终解决，方可办理结案手续。二级网格及时处置三级网格上报的问题，并上报一级网格管理机构，确需职能部门解决的问题，同时上报相关职能部门，配相关职能部门及时查处。

三、合理规划公益性墓地，加强农村公益性公墓建设管理

建设农村公益性公墓要遵守《陕西省秦岭生态环境保护条例》和汉中市民政局《加强全市农村公益性公墓建设与管理意见》（汉民发〔2016〕95号）相关规定。选址上，必须符合当地土地利用总体规划和城乡建设规划的要求，必须要与自然环境相协调，不得破坏当地的生态环境，要尽可能地选择在荒山、荒坡、非耕地或不宜耕种的瘠地上建设，不得占用耕地、林地，不得建在风景名胜区、文物保护区、水源保护区和水库、湖泊、河流、引水渠堤坝1000米内以及铁路、公路主干线两侧500米地界内。

公墓建设用地必须进行勘测定界，明确具体范围，按照有关规定报批，严禁占用耕地、国有林地和纳入中央及省级补偿的重点公益林地。要积极推进绿色殡葬，倡导树葬、花葬、草坪葬、壁葬、骨灰堂存放等葬法，减少殡葬用地；要与治理乱埋乱葬、旧坟搬迁结合起来，将治理后的土地及时恢复为林地、草地、耕地。

建设管理上，要因地制宜，努力降低建设成本。墓地面积墓碑大小要严格执行国家《殡葬管理条例》和省市的有关规定，骨灰入土安葬的单人墓占地面积不得超过0.8平方米、双人合葬墓不得超过1平方米，墓碑高度不得超过0.8米；遗体入土安葬的单人墓不得超过4平方米、双人合葬墓不得超过6平方米，墓碑高度不得超过0.8米。国家新的《殡葬管理条例》颁布后及省、市有新的规定，及时调整墓位占地面积和墓碑大小。在土地少的地区，对于村民要求建骨灰堂（骨灰存放格位）的应予以支持。严格限制公墓墓位占地面积、墓碑高度和使用期限。

四、加强殡葬单位行风建设，不断提高为民服务水平

按照“管行业必须管行风”的要求，切实加强殡葬行风建设和纠风工作，不断提高为民服务水平。各相关部门要大力开宣传辖区殡葬民主评议行风和文明窗口单位创建活动，提升整体素质和服务水平。科学制定公平公正的行业政策，加强殡葬服务、骨灰安葬、土葬改革、移风易俗、清明祭扫和火化炉尾气监测、花圈和祭品焚烧烟雾的排放治理、环境评价等工作的监督管理。合理界定基本殡葬服务和市场选择性殡葬服务范围，严格执行政府定价、政府指导价和市场调节价，全面公开服务标准和服务价格，坚决纠正利用行业特殊性乱收费、乱涨价及捆绑销售丧葬用品等损害群众利益的问题，对有令不行、有禁不止、顶风违纪的典型案件进行严肃查处、公开曝光。

五、工作要求

各部门要把规范和加强秦岭区域陵墓园建设管理等殡葬管理工作作为贯彻中省市关于保护秦岭生态环境重大决策部署、促进生态文明建设的重要内容，提高站位纳入重要议事日程，建立健全党委领导、政府负责、部门协作、社会参与的殡葬管理工作机制。

县民政局作为殡葬执法责任主体，要加强殡葬执法机构建设，配强执法队伍，加大执法力度，强化部门联合执法协作，不断提高秦岭区域殡葬执法能力和水平。要按照市委办、市政府办印发的《关于全面深化殡葬改革的实施意见》（汉办发〔2017〕4号）精神，积极联系各有关部门各司其职。密切配合、齐抓共管、形成合力。

由民政局牵头，县级相关部门配合，成立殡葬领域联合执法组，执法组要不定期深入各镇（办）巡查陵（墓）园建设规范问题，各单位成员之间要互通消息，加强联系，共同负责处理辖区重大陵（墓）园建设中存在的违法、违规问题。林业局、水利局要做好公益性墓地区域范围内的植树造林和水土保持工作。环保局、经贸局要将火化设备的环保节能改造、技术革新列入扶持项目。民政局要承担推进殡葬改革、加强殡葬管理、监督殡葬服务等职能，协调配合有关部门制止乱埋乱葬，加强殡葬公共服务设施建设。物价局要按规定核定殡仪服务和公益性公墓的收费项目及价格，依法查处价格违法行为。卫计局要加强对医院太平间的管理，医疗机构除遗体短时冷藏存放外，不得从事遗体运送或殡仪服务等经营活动，坚决杜绝遗体私自乱埋乱葬。民宗局要规范少数民族和宗教人士的丧葬工作。国土局、林业局、公安局、住建局要加大乱埋乱葬、毁田毁林造坟、城区游丧闹丧等行为的治理。发改局、财政局、民政局要加强基本殡葬服务供给，完善惠民殡葬政策措施。

各镇（办）要切实落实好殡葬管理辖区责任。至少每半年联合民政、公安、国土、环保、林业等部门开展一次殡葬执法巡查和乱埋乱葬专项整治行动。要突出重点，精心组织，集中时间，依法依规对辖区网格片区内的治丧活动中殡、葬、祭三方面违法违纪行为进行查纠，全面改善散埋乱葬现象，制止并依法处置秦岭区域乱埋乱葬行为，确保丧葬陋习得到有效治理。对现有乱埋乱葬坟墓，要区分情况处置，原则上对成片乱埋乱葬坟墓，采取拆除墓碑、恢复植被予以遮挡处置；对零星乱葬坟墓，动员丧属迁入合法墓地；对无名无主坟墓公告后进行平毁；对毁林造坟、毁田造坟和违规建造大墓、豪华墓要坚决依法拆除恢复原貌，力争实现耕地、林地、风景名胜区、文物保护区、水库及河流堤坝附近、水源保护区及铁路、高速公路、国道省道主干线两侧无坟化。对村、居民办丧中的陋习，各镇（办）、村（社区）要积极联系有关部门通力协作，进一步加强联合执法，及时制止违规行为。对拒不听从劝阻的，要依法依规严肃查处；对涉及到的党员干部交由组织人事部门或纪检监察机关追究相应责任。
