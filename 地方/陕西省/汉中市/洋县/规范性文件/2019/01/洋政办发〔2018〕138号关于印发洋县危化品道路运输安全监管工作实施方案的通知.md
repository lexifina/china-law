# 洋政办发〔2018〕138号关于印发洋县危化品道路运输安全监管工作实施方案的通知

洋政办发〔2018〕138号

洋县人民政府办公室关于

印发洋县危化品道路运输安全监管工作

实施方案的通知

各镇人民政府、街道办事处,县政府各工作部门、直属机构，市管单位：

《洋县危化品道路运输安全监管工作实施方案》已经县政府同意，现印发你们，请认真抓好落实。

洋县人民政府办公室

2018年12月31日

洋县危化品道路运输安全监管工作实施方案

为切实加强全县危化品道路运输安全监管工作，有效防范和遏制危化品运输事故，确保人民群众生命财产安全和生态环境安全，根据有关规定和《汉中市人民政府办公室关于印发汉中市危化品道路运输安全监管工作实施方案的通知》（汉政办发〔2018〕68号）精神，结合我县实际，特制订本方案。

一、指导思想

坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大精神和习近平总书记关于安全生产的重要指示批示精神，牢固树立以人民为中心的发展思想和安全发展理念，始终把维护人民群众生命财产安全放在首位，以防事故、保安全、保畅通、促和谐为核心，以落实各级各方面主体责任为重点，全面加强基础设施建设，强化危化品道路运输安全管理和监督执法，为全县经济社会建设提供良好的发展环境。

二、工作目标

按照“依法监管、联合监管、重点监管、源头监管”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的工作要求，健全完善基础管理措施和政府主导、部门主抓、企业参与的危化品道路运输安全联合监管体制机制，进一步加强危化品道路运输全过程监管，加大违法违规行为查处力度，有效预防和减少因危化品运输引发的交通事故和环境污染事故，促进全县道路运输和安全生产形势持续稳定好转。

三、具体措施

（一）夯实工作责任，强化源头管理。各镇办、各部门要依据法定职责，督促危化品运输企业严格落实生产、储存、运输、销售等环节的主体责任。落实“双随机”抽查机制，定期深入辖区企业，检查产品质量安全、生产制度落实和运输车辆动态监管等情况，及时消除安全隐患，确保生产产品合格、销售程序合法、货物装载达标、运载工具和容器安全、人员持证上岗。

（二）坚持分类施策，加强路面管控。县交通局会同领导小组相关成员单位抓紧制定危化品运输安全承诺书，并与通行县境内的危化品运输车辆所有人及时签订安全承诺书。严格落实安全监管措施，对违法违规的危化品运输车辆所有人、驾驶人、押运人由相关部门依法依规顶格处罚。对路查路检中发现和运输安全事故暴露出问题的危化品生产、运输企业，由安监、交通运输部门责令限期整改，问题突出的依法取消危化品生产和运输资质。

1．抓好车辆分流管控。加强道路通行情况分析研判，根据路网结构及周边环境及时发布危化品运输车辆通行线路公告，确保危化品运输车辆按指定线路行驶。综合采取分类分道分时段通行等方式，做好危化品运输车辆分流工作，易燃易爆危化品车辆继续通行国省道，易腐蚀和有毒危化品车辆在采取有效管控措施后在西汉高速公路通行。交警大队要加强国省道监控设施建设，加大巡查力度，对不按规定线路、车道行驶和不听劝阻、强行通行的依法顶格处理。特殊天气采取分时段通行，并由路政、交警联合引导护送。

2．抓好强制限速行驶。根据我县辖区道路状况和安全管理需要，在G108过境路段继续实施限速60km/h的管理措施。

（三）加快交通路网建设。进一步加快危化品集中运输通道建设，切实避开人口密集区、水源地、特长桥隧，有效降低安全风险隐患。

（四）加快基础设施建设。交警大队要加大危化品运输安全管理投入力度，加快推进路面监控设备建设，实现临水临崖、急弯陡坡和易积水结冰、易发团雾等特殊路段视频监控全覆盖。

（五）加快应急设施建设。县安监局要会同有关部门，严格按照相关标准和要求，在G108沿线主要河流、重要水库和水源地等重点路段设置实体密封护栏，修建导流槽、拦截坝、应急池等防污染设施，防止因危化品泄露造成水环境污染。

四、工作要求

（一）提高思想认识，加强组织领导。各镇办、各有关部门要站在保护人民群众生命财产安全和环境安全的高度，充分认识做好危化品运输车辆安全监管的重要意义，切实加强组织领导，制订具体可落实的措施，夯实工作责任，确保各项工作落实到位、取得实效。县上成立危化品道路运输安全监管工作领导小组，县委常委副县长张振任组长，公安局局长李明辉任第一副组长，县政府办公室主任李波、安监局局长杨建鹏、交通局局长冯军任副组长，发改局、财政局、环保局、国土局、水利局、卫计局、编办、人社局和各镇办主要领导为成员，领导小组日常工作由公安局牵头，领导小组办公室设在交警大队，公安局局长李明辉兼任办公室主任，交警大队长冯智敏任办公室副主任。领导小组不定期召开专题会议，通报危化品道路运输安全形势和相关情况，协调解决有关问题，督促各成员单位推动安全管理各项措施落实到位。

（二）强化基础保障，提升应急能力。加强应急救援队伍建设，配置应急装备，科学储备救援物资，不断夯实应急救援基础保障。健全完善应急预案和应急救援机制，积极组织开展应急培训和应急演练，不断提升应急处置能力。要积极引导、鼓励运输企业转变运输方式，重点解决好临崖临水等重要路段的危化品道路运输安全问题。县发改局、财政局、编办、人社局、国土资源局要统筹抓好项目规划、机构编制、人员保障、土地供应和资金投入等工作，为做好全县危化品运输安全监管工作提供坚实保障。

（三）加强事故调查，严格追究责任。根据相关规定，对危化品运输车辆发生一次造成3人（不含）以下死亡事故和其他严重后果，或存在严重安全问题的道路交通事故，由县政府负责调查；对一次性死亡3人（含）以上较大事故，造成道路运输中断5小时以上，或起火爆炸造成公私财产损失达百万元以上，或剧毒品运输车辆发生泄漏造成环境污染和人员伤亡的道路交通事故，由市级人民政府负责调查，依法依规严格追究相关职能部门和有关企业及个人责任。

（四）严格督导检查，加强信息报送。县危化品道路运输安全监管工作领导小组原则上每月对各相关部门、镇办任务落实情况进行一次实际检查，实时召开工作推进会，研究解决问题，督促工作落实。各成员单位和镇办要确定1名联络员，于每月1日和16日前，向领导小组办公室报送工作开展情况，重要情况随时报告。联络员名单于2019年1月10日前报领导小组办公室。
