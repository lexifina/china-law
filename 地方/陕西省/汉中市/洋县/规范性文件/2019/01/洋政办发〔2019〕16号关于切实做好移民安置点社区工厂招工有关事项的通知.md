# 洋政办发〔2019〕16号关于切实做好移民安置点社区工厂招工有关事项的通知

洋政办发〔2019〕16号

洋县人民政府办公室

关于切实做好移民安置点社区工厂招工有关事项的通知

各镇人民政府、街道办事处，县政府有关工作部门、直属机构：

为深入推进就业扶贫、扩大就业增收，进一步解决贫困劳动力、移民搬迁群众及重点群体就地就近就业和企业用工问题，确保社区工厂就业扶贫项目有效实施，实现稳定脱贫，现将社区工厂招工有关事项通知如下：

一、 任务目标

按照李家村移民安置点社区工厂发展需求，2019年2月底前，招工达到450人以上；到2020年年底，全县累计招工3000人以上。具体分为两期：

一期：2019年5月底前在贯溪、巩家槽、磨子桥、柳山4个村设立扶贫车间，计划每个车间招工150-200人左右，带动周边区域群众特别是贫困群众就业。

二期：在龙亭、槐树关、溢水、金水、谢村5个镇设立社区工厂，每个社区工厂计划招工300-500人，在2020年6月底前，招工不少于2000人。（招工具体任务分配详见附件）

二、任务分工

为确保社区工厂招工任务顺利完成，现将相关单位具体任务分工如下：

人社局：负责社区工厂招工的综合协调和督促检查，制定社区工厂工人培训及相关补贴政策。

发改局（苏陕办）：做好社区工厂与苏陕协作对口工作协调，积极争取项目扶持资金，落实相关配套政策。

搬迁办：负责做好社区工厂厂房、水电保障及工厂周边问题协调。

扶贫办：负责向贫困户提供招工信息，落实扶贫相关政策。

残 联：负责向残疾人提供招工信息，落实残疾人就业等相关政策。

文广局：负责招工信息宣传，通过电视、广播等相关平台推送招工信息，提高群众知晓率。

城管局：负责城区招工点位的外围环境保障。

洋州办：负责落实贯溪村扶贫车间150-200人的用工保障。

纸坊办：负责落实李家村社区工厂350人和巩家槽村扶贫车间150-200人的用工保障。

龙亭镇：负责落实柳山村扶贫车间200人的用工保障。

磨子桥镇：负责落实磨子桥镇扶贫车间200人的用工保障，以及一期25人的用工保障。

槐树关、溢水、金水、谢村镇：负责各自辖区社区工厂用工保障，以及一期25人的用工保障。

三、工作要求

（一）加强领导。各相关镇办和单位要切实加强领导，落实一名分管领导具体负责此项工作，组织精干力量，做好各自区域招工工作。

（二）强化宣传。各相关镇办要充分发挥村两委、驻村工作队的优势，抓住春节前后有利时机，利用海报、宣传单等各种形式，全方位、多渠道积极宣传企业招工信息，引导区域内返乡务工人员及剩余劳动力就近到社区工厂就业。

（三）做好衔接。各相关镇办和部门要积极做好与社区工厂的沟通衔接，为招工提供必要的便利条件，全力配合工厂做好招工工作。社区工厂联系电话：[电话略]、[电话略]、[电话略]
