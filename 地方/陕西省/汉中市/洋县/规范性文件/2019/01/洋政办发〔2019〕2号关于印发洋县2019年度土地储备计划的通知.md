# 洋政办发〔2019〕2号关于印发洋县2019年度土地储备计划的通知

洋政办发〔2019〕2号

洋县人民政府办公室

关于印发洋县2019年度土地储备计划的

通 知

各镇人民政府，街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县2019年度土地储备计划》已经县政府研究同意，现印发你们，请遵照执行。

洋县人民政府办公室

2019年1月11日

洋县2019年度土地储备计划

为了切实加强自然资源资产管理，规范土地储备融资行为，健全完善土地收购储备制度，增强政府对城乡统一建设用地市场的调控和保障能力，促进土地资源的高效配置和合理利用，保障建设用地供应，根据《汉中市人民政府办公室关于建立土地收储规划开发连动的大收储制度的实施意见》（汉政办〔2018〕40号）文件精神，依据我县《土地利用总体规划》、《城乡建设规划》,现制定我县2019年度土地收储计划如下。

一、指导思想

科学确定年度土地储备规模和新增建设用地供应总量，盘活存量建设用地，加大对土地市场的宏观调控，确保对建设用地的统一供应，从而达到优化土地利用结构，规范土地市场秩序，推动土地利用向规范、节约、集约、高效的方向发展，切实保障重点项目、民生工程、公共设施、公益事业和生态建设用地，为县域经济社会可持续发展提供土地资源保障。

二、编制计划的原则

（一）坚持规划引领，科学编制土地储备规划。根据洋县国民经济和社会发展规划、土地利用总体规划、城乡建设规划等，编制土地储备，合理确定未来三年土地储备规模。对可收储的土地资源，在总量、结构、布局、时序等方面做出统筹安排，优先储备空闲、低效利用等存量建设用地，立足于挖掘存量、控制增量，严控新增土地供应规模。围绕规划统筹安排，优先储备以有色工业园区、“一江两岸”综合开发等重点项目和重点产业用地，控制一般性用地。

（二）坚持市场导向，合理制定年度收储计划。着眼县域经济社会发展以及房地产业发展需求、社会投资意愿和投资方向，结合洋县社会发展规划，土地储备规划、年度土地供应计划、地方政府债务限额等因素，准确把握土地收储和供应总量、结构和节奏，合理制定年度土地收储计划。对利用价值大、成本相对低的地块优先储备，成本大、效益低的采取规划控制储备。优先储备开发存量建设用地，严格控制新增建设用地，坚持节约、集约用地。

（三）坚持协调发展，提高土地综合利用效益。正确处理好土地收储与城市建设的关系，按照城市发展要求，积极创新运作方式，加强土地收储与基础设施、公共配套设施建设的有机衔接，以完善的配套设施建设，提高土地开发条件，提高土地利用的经济效益和社会效益。

（四）提高收储土地质量，确保国有资产收益最大化。制定收储土地前期开发项目管理办法，加大对储备土地的管护，严格绩效评价标准。

（五）加大土地储备力度，增加土地储备量，提高调控土地市场的能力。储备我县历年来已批未供土地，将2019年以前所有已批未供土地纳入土地储备库。

三、年度土地储备规模

2019年拟按照以下情况进行收储：

（一）城市规划区范围内依照城市建设规划需改造和调整使用的存量建设用地、改变规划用途为经营性用地的土地；

（二）城市规划区范围内已办理农用地转用土地征收批准手续的新增建设用地；

（三）已审批征收未供的土地；

（四）依法应无偿收回的国有闲置土地；

（五）实施动态管理，及时将新批的和县政府确定的重大工程、重大项目用地需要纳入的土地进行储备。

按照上述收储范围，计划2019年度储备土地72宗；共计 面积342.6185公顷。其中：（1）2018年新增国有建设用地24宗，面积 61.2565 公顷；（2）结转2017年度新增国有建设用地14宗，面积 153.8839公顷；（3）往年度以前项目新增国有建设用地34宗，面积127.4781公顷。（详见附件《洋县2019年度土地收储计划一览表》）。

四、计划的实施和监督

（一）储备计划经县政府批准后，向社会公布实施。县国土资源局（土地储备机构）定期公布土地储备供应政策，绩效评价，最终结果、取得成效等相关信息，为广大用户提供用地服务。

（二）划拨土地使用权转让的应先进入政府土地储备库，然后向社会公告，确定供地方式，办理相关审批手续。

（三）积极探索土地储备筹资新渠道，加强土地储备资金管理。建立土地收购储备专项资金，加大对土地收储的资金投入力度，确保土地收储资金“足额到位，专款专用”，保障政府对土地市场的调控能力。

（四）县收储办年底要向县国土资源收购储备管理委员会报告计划的执行情况，并不断完善和改进土地收储和供应工作，逐步完善全县统一的土地收储和集中供应。
