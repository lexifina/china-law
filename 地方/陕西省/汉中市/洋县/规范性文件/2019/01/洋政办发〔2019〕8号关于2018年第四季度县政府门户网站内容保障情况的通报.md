# 洋政办发〔2019〕8号关于2018年第四季度县政府门户网站内容保障情况的通报

洋政办发〔2019〕8号

洋县人民政府办公室关于

2018年第四季度县政府门户网站内容

保障情况的通报

各镇人民政府、街道办事处，县政府各工作部门、直属机构：

2018年第四季度（10月1日-12月31日），县政府门户网站共发布各类信息1211条，其中新闻动态类信息603条，信息公开类608条。政府各部门单位及镇办通过网站后台上传各类信息448条，政府信息中心上传信息763条。处理“县长信箱”和“咨询投诉建议”来信180件，已办结167件、超时办结17件，未办结13件。其中：环保局、财政局、教体局、市场监管局、卫计局、国土局在信息发布和信息公开总数量均超过20条，旅发委、安监局、经贸局、纸坊办事处、槐树关镇、龙亭镇、华阳镇未发布和公开一条信息，信息统计为0；卫计局、民政局、教体局在信件办理过程中回复及时，答复质量较高；龙亭镇、槐树关镇、黄家营镇、桑溪镇、经贸局存在未办结信件，请以上单位于2019年元月23日前务必办结。

根据第四季度总体情况来看，大多数单位在政府信息发布和处理群众来信的情况较好，但仍有部分单位对本单位信息公开目录更新重视不够，对目录中的“机构职责”、“部门（镇办）文件”、“政策解读”等按规定需主动公开的政府信息，长时间不主动公开，引起网民投诉；部分单位在处理“县长信箱”及“咨询投诉建议”信件过程中，存在处理不及时，答复质量不高，推诿责任的现象，且超期回复现象依然突出。

以上问题，请各镇办、各部门务必高度重视，要继续加强组织领导，进一步完善信息发布的常态化机制，细化分解责任，彻底杜绝信息公开栏目更新不及时的问题；同时，在回复群众来件过程中，要依法依规处理来件人所反映的问题，回复内容要做到事实清楚，有理有据，措辞得当，不得敷衍塞责。
