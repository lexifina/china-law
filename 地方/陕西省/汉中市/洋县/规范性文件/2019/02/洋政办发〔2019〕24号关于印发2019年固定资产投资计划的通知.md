# 洋政办发〔2019〕24号关于印发2019年固定资产投资计划的通知

洋政办发〔2019〕24号

洋县人民政府办公室

关于印发2019年固定资产投资计划的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

2019年是实现“十三五”规划目标，全面建成小康社会的关键之年。为了确保全县经济社会持续健康发展，按照县委、县政府确定的我县全社会固定资产投资增速的目标，2019年我县固定资产投资计划125.5亿元，现将任务分解下达到各相关单位（见附件），并就有关事项通知如下：

一、各相关责任单位要进一步夯实固定资产投资任务，充分挖掘项目，并按照统计制度要求，确定专人完善项目报建和进入统计口径的各种手续，及时到县统计局入统登记并向发改局和统计局提供项目进度资料，确保按时、按节点完成目标任务。

二、纳入固定资产投资计划的项目实行一把手责任制。项目主管部门的主要领导要积极协调项目建设中征地、拆迁和资金筹措等重大问题，同时要求项目总投资在5000万以上的项目建设单位认真做好网上申报工作，按时、准确进行投资申报。

三、严格按照《洋县贯彻落实“三项机制”助推固定资产投资工作实施细则》要求，将固定资产投资完成情况纳入项目主管部门年度考核， 2019年固定资产投资实行百分制考核。第一季度占20分、第二季度占30分、第二季度占20分、第四季度占30分，每季度根据各部门完成的实际数字进行通报（数字由县统计局负责提供），分数换算后报县考核办，纳入年终考核。对圆满完成任务的单位将予以表彰奖励；对完成任务不到70%的，实行“一票否决”，年终取消评优资格。
