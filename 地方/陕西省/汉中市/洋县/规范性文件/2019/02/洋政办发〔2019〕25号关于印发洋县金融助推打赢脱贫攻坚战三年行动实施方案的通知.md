# 洋政办发〔2019〕25号关于印发洋县金融助推打赢脱贫攻坚战三年行动实施方案的通知

洋政办发〔2019〕25号

洋县人民政府办公室

关于印发洋县金融助推打赢脱贫攻坚战

三年行动实施方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县金融助推打赢脱贫攻坚战三年行动实施方案》已经县政府同意，现印发你们，请认真抓好贯彻落实。

洋县人民政府办公室

2019年2月19日

洋县金融助推打赢脱贫攻坚战三年行动实施方案

（2018－2020年）

根据中、省、市打赢脱贫攻坚战总体规划以及《汉中市金融助推打赢脱贫攻坚战三年行动实施方案》，为进一步加大脱贫攻坚金融支持力度，助推全县打赢脱贫攻坚战，特制定本方案。

一、目标原则

通过大力开展金融扶贫工作，进一步提升全县贫困地区金融服务和保障体系，推动金融服务到村到户到人，力争让所有符合条件的贫困人口都能按需获得贷款支持，让所有需要金融服务的贫困人口都能获得便捷的现代金融服务，助力脱贫攻坚，确保到2019年全县贫困地区和贫困人口与全国全省全市一道进入全面小康社会，为实施乡村振兴战略打好基础。

（一）坚持统筹协调原则。进一步完善“政府主导、监管指导推动、金融机构参与”的工作机制，加强金融扶贫与财税、产业扶贫等政策资源、信息共享，推动形成金融助推脱贫攻坚的合力。

（二）坚持突出重点原则。加强与贫困地区和贫困人口发展规划的衔接，重点支持建档立卡贫困户、易地扶贫搬迁、特色产业发展以及基础设施和基本公共服务建设。

（三）坚持风险防控原则。进一步发挥市场配置资源的决定性作用，突出金融扶贫的“造血”功能，推动建立金融扶贫风险分担和补偿机側，既注重资金投入又注重风险防控。

（四）坚持信息共享原则。建立和完善脱贫攻坚金融服务工作联动机制，定期分析研究金融扶贫工作情况，建立信息对接风险补偿等合作机制，确保信息、传递迅速，及时解决工作中的具体问题。

二、主要内容

（一）积极发挥再贷款货币政策工具作用。对符合条件的地方法人金融机构发放扶贫再贷款，支持地方法人金融机构利用扶贫再贷款加大贫困地区信贷投入力度。严格执行扶贫再贷款优惠利率政策，引导地方法人金融机构认真落实运用扶贫再贷款资金发放贷款相关规定，发挥扶贫再贷款在降低贫困地区融资成本中的引领作用。（人民银行洋县支行牵头，各有关银行配合）

（二）加大扶贫信贷资金投放力度。简化涉农、扶贫贷款手续，提高贷款效率，满足各类扶贫信贷需求，努力实现全县每年各项贷款、贫困户贷款持续增长。拓宽扶贫信贷抵质押品范围，积极发展农村“两权”抵押、林权抵押贷款，积极采用果园、茶园抵押，订单、仓单、应收账款质押等方式为农业产业链提供融资。优化贫困地区基础设施、公共服务设施、易地扶贫搬迁等项目贷款的期限和还款方式，原则上以中长期贷款为主。积极采用“企业＋农民合作社＋农户”“企业＋家庭农场”“家庭农场＋农民合作社”等模式提高农村金融服务集约化水平。持续做好扶贫小额信贷，期限延长至脱贫攻坚期内，对已发放但确有困难无法归还的，要通过“展期”或“无还本续贷”等方式延长还款期限，努力实现应贷尽贷，满足贫困户发展生产的有效信贷需求。（人民银行洋县支行牵头，各有关银行配合）

（三）持续推进基础金融服务到村到户。建立健全农村金融组织服务体系和支付结算服务体系，建立起基础金融服务不出村、综合金融服务不出镇、办的金融服务体系。各金融机构要优先在贫困村设立网点、布设电子机具，力争2020年以前实现贫困村及镇、办的网点全覆盖。（人民银行洋县支行牵头，各有关银行配合）

（四）强化农业保险在扶贫中的作用。积极做好贫困地区农业政策性保险，力争到2020年，全市水稻、油菜等粮食作物保险覆盖率达70％以上，奶牛、育肥猪等养殖业保险覆盖率达30％以上。开展农业保险创新，探索在农业龙头企业开展农产品价格指数保险、气象指数保险、产量保险和收入保险。增加农业保险品种，大力发展黑谷、食用菌、蔬菜、柑橘、中药材等特色农业保险，争取2020年全县特色农业保险品种达到5个以上。逐步减少或取消深度贫困村县级财政承担的补贴部分，鼓励各镇办用财政专项扶贫资金和涉农整合资金，对建档立卡贫困户参加政策性农业保险个人自担保费额予以直补，通过“一卡通”发放到户。（县农业局牵头，县财政局、县金融办、各保险公司配合）

（五）进一步完善金融精准扶贫风险分担补偿机制。进一步加强精准扶贫贷款风险补偿金的管理，各镇办根据年度新增扶贫贷款规模和合作金融机构贷款进度，合理统筹安排资金按约定比例分担实际发生的风险。各金融机构平等享受财政贴息和风险缓释政策。引导保险业机构为扶贫贷款提供贷款保证保险和借款人意外伤害保险业务，积极探索建立由保险、银行、政府基金和贷款户按比例分担贷款损失机制。（县财政局、县扶贫办牵头，各保险公司及各镇办配合）

（六）推动扶贫涉农企业进入多层次资本市场。加大上市后备企业资源培育，引导全县扶贫涉农企业集中在陕西股权交易中心挂牌，促进改制规范、增信、投融资对接；争取用好国家支持贫困地区企业上市绿色通道政策，鼓励引导我县扶贫涉农企业在“新三板”挂牌交易，充分利用多层次资本市场融资。对涉农企业进入资本市场按照现有融资奖励政策实行特别奖励。（县金融办牵头，各镇办配合）

（七）加强农村信用体系建设。继续推进建档立卡贫困户和新型农业经营主体信用档案建设，持续改善农村信用环境，促进信用与信贷联动，有效发挥农村信用体系建设成果在金融精准扶贫中的作用。积极建立镇、村、金融机构等多方参与的贫困户和新型农业经营主体信用评定制度，持续开展农村信用户、信用村和信用镇办创建，不断提高贫困地区各类主体的信用意识，营造良好农村信用环境。加大信用评定结果运用，对诚信主体在贷款金额、利率、期限等方面给予倾斜优惠，对失信主体给予相应限制。拓展和优化征信服务，采用在涉农金融机构安装配置自助查询设备或利用互联网查询等方式，为农村主体依法查询信用报告提供便利。（人民银行洋县支行牵头，各有关银行配合）

（八）做好深度贫困村的金融服务工作。积极引导金融资源向深度贫困村倾斜，提高深度贫困村扶贫小额信贷风险补偿金放大倍数，努力争取深度贫困村扶贫小额信贷增速不低于全县扶贫小额信贷平均增速。引导辖内银行业机构新增信贷资金优先满足深度贫困村，新增金融服务优先布局深度贫困村，优先在深度贫困村开展扶贫保险服务。（人民银行洋县支行牵头，县财政局、各有关银行、各保险公司配合）

三、保障措施

（一）进一步完善全市脱贫攻坚金融服务工作联动机制。进一步加强金融管理部门、政府扶贫部门、金融机构之间的信息沟通与联系推动扶贫、农业等部门与金融机构共享建档立卡贫困户基础信用、产业发展等信息，实现部门协作、政策协同以及信息共享。加强对我县金融精准扶贫工作指导，确保金融扶贫政策得到有效贯彻落实；加大扶贫产业政策与金融政策的协调配合力度，推进金融产品与服务方式创新。定期召开金融扶贫工作联席会议，准确传导金融扶贫政策，及时协调解决突出问题，各镇办也要建立相应工作机制，统筹推进我县金融扶贫工作。

（二）进一步加强金融扶贫信贷风险防范。各镇办要切实履行好主体责任，加强对金融扶贫工作的统筹组织。要严格执行中、省、市金融扶贫各项政策，进一步明确扶贫小额信贷对象、用途、使用、管理，统筹扶贫、农业、财政等部门及镇、村，与金融机构形成合力，加强对防范化解扶贫小额信贷逾期风险的组织领导和信贷逾期清收、催收，建立和完善不良追偿机制，加大对恶意逃废银行债务行为的打击力度，把恶意“欠钱不还”的苗头彻底扼杀，防止负面效应，确保金融扶贫平稳运行，防范风险。

（三）注重宣传，营造良好氛围。学习示范县西乡县金融精准扶贫工作，为贫困地区金融支持脱贫攻坚、助推贫困户发展产业脱贫致富提供可以借鉴和复制的经验。通过报纸、广播、电视、网络等主要媒体，金融机构营业网点以及村组、社区等公共宣传媒介，大力开展金融扶贫政策宣传，增强贫困户对金融扶贫政策的了解和运用。及时梳理总结金融助推脱贫攻坚的工作成效、典型经验以及成功案例，加强宣传推介和经验交流，促进形成各方关注、多方参与金融助推脱贫攻坚的良好局面。
