# 洋政办发〔2019〕26号关于加强审计报告反映问题整改工作的通知

洋政办发〔2019〕26号

洋县人民政府办公室

关于加强审计报告反映问题整改工作的

通    知

各镇人民政府、街道办事处，县政府各工作部门、直属机构、市管单位：

为进一步加强审计报告反映问题整改工作，根据《中华人民共和国审计法》《陕西省地方各级预算执行情况监督实施办法》和《洋县人民代表大会常务委员会关于县人民政府审计工作及审计整改的监督办法》，现就2018年度审计发现问题整改工作通知如下：

一、深化认识，高度重视审计整改。审计监督是《宪法》规定的一项重要制度，是维护财经秩序、推进依法行政、加强廉政建设的必然要求，对于充分发挥审计监督职能、保障经济社会健康发展具有重要意义。各镇（办）、各部门、各单位要从推进依法治国、建设法治政府的战略高度，将审计整改工作列入重要日程，精心安排部署，采取有力措施，坚持整改、持续整改、长效整改。各被审计单位主要负责人要切实担负起审计整改第一责任人的职责，亲自安排、督办。要安排专人逐问题落实销号，认真整改审计查出问题，深入研究和采纳审计提出的建议，切实增强落实审计整改工作的自觉性和主动性。

二、立行立改，确保审计整改到位。各被审计单位要围绕审计报告，迅速行动、抓紧制定整改方案，明确整改目标，逐项提出整改措施，以“严、紧、细、深”的标准落实整改。做好审计整改“回头望”，确保“审计—整改—规范—提高”效果。要注重源头防范，立足整改，加强分析研究，从问题发生的制度、机制和体制方面查找原因，举一反三，建立健全相关制度，防止问题再度发生。

三、严明纪律，坚决维护审计成果。对审计查出的违纪违规资金要坚决纠正，做到该上缴财政坚决上缴，该归还原资金渠道的归还到位，该调整会计科目的及时调整，该追究当事人责任的严肃追究。在整改过程中，要坚决防止应付式整改、文字整改，不得搞变通，避重就轻。

四、加强督查，全面落实整改任务。按照“谁主管、谁负责”的原则，加强审计查出问题的监督检查，进一步加大审计整改结果公开力度，以公开促整改。县政府督查室、县审计局要逐单位、逐问题核查，跟踪督办。对审计整改不到位、不彻底、应付交差的单位要进行通报批评，追究主要领导和分管领导的责任。以审计整改推进作风建设，推进立制规范，推动县委县政府重大决策、重点建设项目落地生根、快速发展。

洋县人民政府办公室
