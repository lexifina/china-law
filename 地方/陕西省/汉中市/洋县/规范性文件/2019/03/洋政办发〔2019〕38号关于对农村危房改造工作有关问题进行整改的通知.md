# 洋政办发〔2019〕38号关于对农村危房改造工作有关问题进行整改的通知

洋政办发〔2019〕38号

洋县人民政府办公室

关于对农村危房改造工作有关问题进行

整改的通知

各镇人民政府、街道办事处，县政府有关工作部门、直属机构：

2019年3月上旬，市脱贫办对我县脱贫攻坚工作进行了检查调研，指出我县农村危房改造工作仍存在一些问题，必须尽快予以整改。为了全面落实市脱贫办指示要求，确保我县农村危房改造工作顺利推进。现将问题整改有关事项通知如下：

一、工作重点

1.各镇办普遍存在农村危房改造完成后，继续使用原有危房，导致安全隐患。D级危房改造后，原有危房未拆除，仍用于厨房、仓库、居住等用途，这种现象，既违反危房改造政策又构成重大安全隐患，必须拆除。

2.C级危房修缮加固不彻底，仍属于危房。对于鉴定为C级的农村危房，通过修缮加固危险点，必须使其达到安全住房标准；对于未达到安全住房标准的，由镇办负责，查明原因，自筹资金立即整改到位。

3.核实历年已实施农村危房改造对象的住房安全情况，对于因自然灾害导致房屋受损的，由农户申请救助渠道或镇办统筹解决；对于往年已享受农村危房改造政策，核查住房安全性未达到要求的，镇办要自筹资金解决其住房安全问题，并对违反农村危房改造竣工验收有关规定的行为追究责任。

4.对于未享受过农村危房改造政策的建房户，按照《土地法》有关规定，新房建成入住后必须拆除旧房，对原有宅基地进行腾退复垦。

5.结合村庄环境整治，拆除废弃的农村危房、旧房及残垣断壁，改善村容村貌。

二、时间安排

2019年3月25日——2019年4月18日，各镇办认真排查、摸清底数、形成清单。

2019年4月18日——2019年8月18日，各镇办根据排查汇总的问题清单进行整改。

2019年8月18日——2019年8月31日，县住建局联合县政府督查室对各镇办本次整改工作进行抽查验收。

三、工作要求

1.提高站位。农村危房改造是一项惠民工程，也是脱贫攻坚的重点任务。因此，各镇办要站在讲政治的高度，切实将农村危房改造作为当前一项重要工作来抓，各镇办要成立领导机构，由主要领导负总责，分管领导具体抓，全面彻底开展好本次整改工作，确保按时完成任务。

2.扎实整改。各镇办要坚持问题导向、目标导向，对照市脱贫办指出的问题，认真开展排查，扎实进行整改，已完成危房改造的必须按期拆除原有危房，修缮加固未达到安全住房标准的立即进行整改，影响村容村貌的废弃旧房必须拆除复垦。

3.严肃问责。各镇办必须按照整改要求，在规定时间内完成各项任务，对因责任不明、措施不力、推进缓慢，影响全县危改工作整改进度的，由住建局、县政府督查室将相关线索移交县纪委监委，进行严肃问责。

洋县人民政府办公室
