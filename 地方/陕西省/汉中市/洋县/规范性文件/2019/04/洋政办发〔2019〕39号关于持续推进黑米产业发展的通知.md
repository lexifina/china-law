# 洋政办发〔2019〕39号关于持续推进黑米产业发展的通知

洋政办发〔2019〕39号

洋县人民政府办公室

关于持续推进黑米产业发展的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

去年以来，县委、县政府坚持“规模化、标准化、产业化、品牌化和全程化监管”的思路，加大投资引导，加强跟踪服务，洋县黑米产业取得了初步成绩，为了进一步持续推进我县黑米产业，助推产业扶贫和县域经济发展，现将相关事项通知如下。

一、加大重点环节建设

（一）加大种植基地建设

结合农村“三变改革”，鼓励和引导有条件的大米加工龙头企业、合作社、经纪人、生产大户等经营主体通过流转土地自种、订单生产等多种方式，集中连片，整村、整条沟发展，建立黑米种植基地，全县种植面积达到6万亩。加大对黑米种植基地机耕路、机电井及配套、桥涵闸、渠道防渗、排灌站等小型农田水利设施建设扶持力度，优先实施高标准水田建设项目。落实好农机购置补贴资金，鼓励和指导企业、合作社完善机械育插秧、机械收割、自动晾晒、烘干等环节设备，提高黑米收种全程机械化水平。黑米耕种收综合机械化水平达到80%以上。

(二)加强标准化生产

开展科技攻关，着力提高黑米单产、品质和抗逆性，选育一批有突破性的新品种，在全县进行重点推广。除少数特殊订单外，全县要重点推广“洋黑三号”“双亚黑一号”等糯型黑稻品种，确保洋县黑米内在品质。全县黑米良种覆盖率保持100%水平。通过政策支持和市场引导，鼓励涉农企业和农业生产合作社发展生产“三品一标”黑米，积极开展“三品一标”黑米认证，提高洋县黑米标准化生产水平，其中有机认证面积达全县黑米种植总面积的80%以上。

(三)拓展销售渠道

鼓励企业、合作社、个人等开展电子商务和在国内重点城市建立品牌直销店，“线上线下”互动，多渠道拓宽洋县黑米销售渠道。外销洋县黑米达到2万吨，全县实现加工综合销售收入4亿元。

(四)加大品牌建设

按照“食补国宝–洋县黑米”发展战略，做大做强“洋县黑米”区域公用品牌和“朱鹮”商标。按照“区域公用品牌+企业产品品牌”的双品牌模式，整合洋县黑米产品品牌，提高市场知名度和占有率。完善规范洋县有机产业协会，充分发挥协会职能作用，组织制定洋县黑米地理标志品牌使用管理办法，规范企业行为，维护品牌信誉。加大督查、监管力度，政府相关部门定期开展洋县黑米品牌专项检查和整治行动，依法打击制售假冒伪劣和侵犯洋县黑米系列商标专用权的违法行为，依法从重处理，净化市场环境。

（五）加强宣传推介

加大洋县黑米宣传推介，探索举办黑米美食节、文化节、年货节等主题节会，积极参加全国各类知名特色农产品、有机产品展销会、博览会，多途径宣传洋县黑米。建立和完善洋县黑米品牌宣传机制，鼓励和引导多元主体加大品牌宣传投入、创新品牌宣传方式，提升洋县黑米在全国的知名度和影响力。

(六)强化质量安全监管

加强土壤污染状况调查和地表水污染防治，全面推进农业面源污染防治。加强对种子、肥料、农药等农资投入品的市场监督检查，加强对农药等投入品的使用监督和指导；严厉打击国家明令禁止的高毒农药使用，从源头把黑米生产安全关。建立健全质量追溯管理制度，支持和推动洋县黑米信息采集和监管系统建设。全县黑米基本实现生产有记录、信息可查询。

二、加大政策扶持

(一)加大资金扶持力度

1.规划区域内农户集中连片种植黑米，每亩补助150元，贫困户发展黑米补助标准每亩400元。

2.加大“三品一标”黑米认证，对获得“有机食品”“绿色食品”“无公害”黑米认证的，认证费100%补贴；对黑米产业化发展中新取得的相关发明专利，每项奖励1万元。

3.对线上线下销售洋县黑米及其深加工产品年销售额达到1000万元（以原始销售发票为准）以上的农产品经营主体，根据销售量每年奖励3-10万元；对于出口洋县黑米及其深加工产品年出口额在500万元（以原始销售发票为准）以上的企业，根据出口额每年奖励10-30万元。

4.列支100万元，用于黑米种质资源保护、新品种选育、引进、试验、示范、黑米品牌整合宣传及黑米深加工产业的研发等方面工作费用。

5.列支300万元，用于黑米产业市场风险防控。

6.对企业收购黑米的贷款进行贴息，贴息期限为9个月（每年10月-到次年6月底）。贷款额度在100万元以下的按照国家同期半年期贷款基准利率的70%贴息；贷款额度在100万元-300万元（含）的按照国家同期半年期贷款基准利率的80%贴息；贷款额度在300万元-500万元（含）的按照国家同期贷款半年期基准利率的90%贴息；贷款额度在500万元以上的按照国家同期半年期贷款基准利率的100%贴息，最高不超过50万元。

贫困村和贫困户补贴资金由扶贫产业整合资金中列支，非贫村和非贫户补贴资金由县财政安排。各相关黑米生产主体在享受以上扶持政策时，不再重复享受政府其他相关优惠政策中相同环节补助。

(二)加大项目扶持力度

县发改局、财政局、农业农村局、自然资源局、水利局、科技局、经贸局等部门，要结合黑米产业发展，积极挖掘上报项目，多途径加大对黑米产业的项目支持。

(三)加大金融、保险支持力度

鼓励金融机构加大信贷投放力度，发挥中小企业担保公司的作用，帮助加工企业、生产企业以及农民合作组织和粮食种植基地(种植大户)融资。推行政策性农业保险，建立完善全县农业保险体系，鼓励农民积极参保，提高农业生产抗风险能力。

三、强化督查考核

（一）加大黑米种植基地建设督查。各镇办为责任主体，要加强对本辖区黑米种植的监督核查，6月底前将各类经营主体种植黑米情况调查表（见附件1）及种植户花名册（见附件2）公示无异后报县农业农村局备案。

（二）强化品牌建设、销售等环节督查。各相关责任部门要按照自身职能，加强对各黑米生产主体品牌建设、销售等环节的服务和管理，督导核实建设情况，严防弄虚作假。
