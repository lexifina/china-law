# 洋政办发〔2019〕46号关于印发2019年“放管服”改革和“一网通办”工作要点的通知

洋政办发〔2019〕46 号

洋县人民政府办公室

关于印发2019年“放管服”改革和

“一网通办”工作要点的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县2019年“放管服”改革和“一网通办”工作要点》已经县政府同意，现印发给你们，请认真组织实施。

洋县人民政府办公室

2019年5月10日

洋县2019年“放管服”改革和“一网通办”

工作要点

为深入推进“放管服”改革，全面提升政务服务水平，不断优化营商环境，根据陕西省人民政府办公厅印发关于《2019年“放管服”改革和“一网通办”工作要点》的通知要求，结合我县实际，对2019年“放管服”改革和“一网通办”重点工作安排如下：

一、指导思想

2019年是新中国成立70周年，是决胜全面建成小康社会的关键之年，也是深化“放管服”改革，优化营商环境的重要一年。今年“放管服”改革的总体思路是：以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九大、十九届二中、三中全会及中央经济工作会精神，坚持以人民为中心的发展思想，将“放管服”改革、优化提升营商环境和“互联网+政务服务”三位一体统筹推进，构建线上线下一体化政务服务体系，推进政务信息资源联通共享，全面实现“一网通办”，打造“宽进、快办、严管、便民、公开”的服务模式，推动政务服务从政府供给导向向群众需求导向转变，更快更好方便企业和群众办事创业，为推动营商环境优化提升和加快“六个洋县”建设提供有力保障。

二、主要任务

（一）全面推进相对集中行政许可权改革

1.落实机构改革要求，全面厘清各部门权力责任事项，逐步建立审批监管分离的工作机制。(县委编办、县行政审批服务局负责，6月底前完成)

2.按照“应划尽划”的要求，做好行政许可权力划转等工作，理顺行政审批服务局与各业务主管部门、监管部门、执法机构之间的权责关系。(县行政审批服务局负责，7月底前完成)

（二）不断强化简政放权改革力度

3.根据机构改革后各部门职能变化情况，及时对已完成梳理的行政许可、审核转报、备案和服务类事项进行调整完善，强化清单动态调整;对未完成梳理的行政处罚、行政强制、行政征收、行政给付、行政检查、行政确认、行政奖励、行政裁决等事项，按照“颗粒化”和“三级四同”要求，编制统一、规范的办事指南;进一步丰富完善县级事项库和“马上办、网上办、就近办、一次办”事项。(县委编办牵头，县行政审批服务局配合，6月底前完成)

4.做好对上级下放的行政许可事项承接工作，适时开展县级行政许可权委托下放到镇、办的试点工作。（县行政审批服务局牵头，各相关镇、办配合，12月底前完成)

5.清理烦扰企业群众的各类无谓证明，实行证明清单式管理，列明设定依据、索要单位、开具单位、办理指南并对外公开，精简办事所需材料和证明。(县司法局牵头，各相关部门负责，持续推进)

6.积极推进证照分离改革，全面落实首批106项“证照分离”改革事项的推进工作。(县市场监督管理局牵头，各有关部门配合，持续推进)

7.推进工程建设项目审批制度改革，对房屋建筑和城市基础设施等工程建设项目(不包括特殊工程和交通、水利、能源等领域的重大工程)审批全过程(包括从立项到竣工验收和公共设施接入服务)，落实国务院“四个统一”改革要求，即统一审批流程、统一信息数据平台、统一审批管理体系、统一监管方式。（县住房和城乡建设局牵头，各有关部门配合，年底前完成）

（三）切实增强事中事后监管实效

8.推进综合行政执法改革，整合各类执法机构、职责和队伍，清理归并执法清单，完成市场监管、生态环境、文化、交通运输、农业等五个领域综合执法改革。(县委编办牵头，县市场监督管理局、市生态环境局洋县分局、县文化和旅游局、县交通局、县农业农村局负责，6月底前完成)

9.全面推行市场监管清单制度，编制并公布市场监管清单，明确监管事项、监管依据、监管对象，厘清监管职责，落实监管责任，加快形成权责明确、公平公正、透明高效、法治保障的市场监管格局。（县委编办、县司法局、县市场监督管理局牵头，各有关部门配合，6月底前完成）

10.深入推进随机抽查监管，实现“双随机、一公开”全覆盖，积极推进跨部门“双随机”联合抽查，提高抽查检查的规范化、专业化水平，做好抽查检查结果的归集、公示、共享工作，建立健全失信联合惩戒机制，实现“事前管标准、事中管检查、事后管处罚、信用管终身”。（县市场监督管理局、县发改局牵头，各有关部门配合，6月底前完成）

11.建设“互联网+监管”系统，配合省市做好“互联网+监管”系统建设相关工作。(县政府办公室负责，各有关部门配合，按要求时限完成)

（四）持续提升网上服务能力

12.推进“互联网+政务服务”体系建设，依托全省统一的“互联网+政务服务”平台，加快实现全县范围内“一张网”应用。全面推进行政许可事项网上审批，除法律规定或涉密事项外，县级行政许可事项原则上都要利用互联网政务服务平台开展受理审批工作，网上可办的县级政务服务事项不低于70%。（县行政审批服务局牵头，各有关部门、各镇办负责，6月底前完成）

13.优化政务服务事项“一站式”办理，进一步完善“前台综合受理、后台分类审批、综合窗口出件”工作模式，实行一窗受理、集成服务、一网通办。积极推广容缺后补、绿色通道、告知承诺、邮政专递送达等便利化措施，推行预约办理、同城通办、异地代办、跨层联办、智能导办、一对一专办等多种服务方式，多渠道多途径提高办理效率和服务水平，（县行政审批服务局牵头，各相关部门配合，6月底前完成）

（五）加快推进政务服务体系规范化

14.树立政务服务统一形象，按照全省统一的政务服务标识，进行政务大厅标准化建设，提升政务服务中心整体形象。(县行政审批服务局负责，9月底前完成)

15.推进政务服务事项集中办理，按照办事“只进一扇门”的要求，撤销各政府部门独立设置的服务大厅，因特殊原因需要保留的，经县政府同意，作为政务大厅的分厅，统一监督管理，统一服务标准，凡非涉密且与企业经营、群众生活密切相关的政务服务事项应当全部进驻政务大厅集中办理。(县政府办公室、县委编办、县行政审批服务局牵头，各有关部门配合，12月底前完成)

16.加快镇村便民服务体系建设， 在镇（街道办）、村（社区）全面建立便民服务中心（站），作为县级实体政务大厅的延伸窗口，将更多的审批和服务事项下放到镇（街道办）和村（社区）办理，积极开展代缴代办代理等便民服务，实现群众办事“就近办”。（县委编办牵头，县行政审批服务局、各镇办配合，12月底前完成）

(六）全面加强工作保障

17.加强组织领导。深化“放管服”改革和推进“一网通办”审批服务便民化工作涉及面广、时间紧、任务重，各相关部门和各镇办要建立主要领导负总责、亲自抓，分管领导具体抓的工作推进机制，进一步夯实工作责任、细化目标任务、明确完成时限和要求，确保改革措施落地见效。（县政府办公室牵头，各相关部门、镇办负责，6月底前完成）

18.强化机制保障。结合机构改革职能调整的实际，进一步理顺政务服务工作体制机制，配齐配强工作队伍。落实“三项机制”，将行政审批服务局和政务中心作为提拔锻炼后备干部的人才培养基地，促进政务服务工作人员强素质、转作风、优服务。将政务服务平台建设、人员聘用、考核奖励、工作宣传等经费纳入财政预算，保障工作开展。（县政府办公室牵头，县行政审批服务局、县财政局、县人社局等相关部门负责，6月底前完成）

19.积极宣传推广。大力宣传深化“一网通办”推进审批服务便民化工作中各项便民利企的举措和成效，及时宣传报道社会欢迎、群众认可的经验做法和典型案例，用群众语言解读政策、用新媒体传播政策，积极听取吸纳各届意见建议，及时回应公众关切，营造良好社会氛围。（县政府办公室、县行政审批服务局负责，12月底前完成）

20.严格督查考核。将深化“放管服”改革和“一网通办”推进审批服务便民化工作情况纳入各部门和各镇办年度目标责任考核体系。适时组织开展第三方评估，把企业和群众评判作为衡量改革成效的标准。采用明察和暗访相结合的形式，定期组织专项督查，对工作推动不力、未按时限完成任务的部门和镇办予以通报批评，对敷衍塞责、延误改革的要依法依规依纪严肃问责，确保各项改革落到实处。（县政府督查室牵头，各相关部门、镇办负责，12月底前完成）
