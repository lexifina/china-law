# 洋政办发〔2019〕48号关于印发洋县城区声环境功能区调整划分方案的通知

洋政办发〔2019〕48号

洋县人民政府办公室

关于印发洋县城区声环境功能区调整

划分方案的通知

各镇人民政府、街道办事处，县政府各工作机构、直属事业单位，市管单位：

《洋县城区声环境功能区调整划分方案》已经县政府同意，现印发你们，请认真组织实施。

洋县人民政府办公室

2019年5月27日

洋县城区声环境功能区调整划分方案

为认真贯彻落实《中华人民共和国环境噪声污染防治法》有关要求，进一步加强城区声环境管理，有效控制环境噪声污染，营造良好城市环境，按照省市声环境功能区划分调整工作安排，根据《声环境质量标准》（GB3096-2008），《声环境功能区划分技术规范》（GB/T 15190-2014）等标准，结合洋县城区总体规划和建设现状，制定本方案。

一、指导思想

全面贯彻党的十九大精神，坚持以习近平新时代中国特色社会主义思想为指导，牢固树立和贯彻落实创新、协调、绿色、开放、共享的发展理念，认真贯彻实施《中华人民共和国环境保护法》和《中华人民共和国噪声污染防治法》，结合洋县城市近年来建设规划和用地现状，科学合理划定声环境功能区，强化噪声排放源监督管理，以提高声环境质量为核心，全面提升噪声污染防治和声环境质量管理水平，完善声环境质量管理体系，努力建设宁静舒适的生活环境。

二、基本原则

1.坚持依法划定原则。根据国家和陕西省相关法律、法规和技术规范要求，科学合理划定声环境功能区，划定中不随意降低声环境功能区级别和管控要求，以有利于环境噪声管控和提高声环境质量为宗旨，切实维护声环境功能区划分的严肃性。

2.坚持规划与现状相结合的原则。声环境功能区划以城市总体规划为指导，按区域规划用地的主导功能，用地现状确定，覆盖整个城市规划面积。

3.坚持务实管用原则。明确区划单元的地理边界、位置坐标，将声环境功能区落地、上图、入库，力求“划得实、管得住”，使声环境功能区划分方案成为环境监测、质量评估、环评审批、行政执法等环境日常管理和城市用地规划，交通规划等空间管制的重要依据，增强保护实效。

4.坚持宏观控制原则。声环境功能区划分以宏观控制为主，宜粗不宜细，宜大不宜小，宜连不宜断。单块的声环境功能区面积，原则上不小于0.5km2，山区等地形特殊的城市，可根据城市的地形特征确定适宜的区域面积。

5.坚持以人为本，从严控制原则。调整声环境功能区类别需进行充分的说明，严格控制4类声环境功能区范围，提高声环境质量，以保障居民正常生活，学习和工作场所的安静。

6.坚持适时调整原则。声环境功能区划分根据城市规模和用地变化情况，噪声区划可适时调整，原则上不超过5年调整一次。

三、划分依据

《中华人民共和国环境保护法》（2015年1月1日起施行）；《中华人民共和国环境噪声污染防治法》（2018年12月29日修订）；环境保护部办公厅《关于加强和规范声环境功能区划分管理工作的通知》（环办大气函〔2017〕1709号）；陕西省环境保护厅《关于加强和规范声环境功能区划分管理工作的通知》（陕环气函〔2017〕10号）；汉中市环境保护局《关于加强和规范声环境功能区划分管理工作的通知》（汉环函〔2018〕253号）;《声环境质量标准》（GB3096-2008）；《声环境功能区划分技术规范》（GB/T15190-2014）；《洋县土地利用总体规划（2006-2020年）》；《陕西省洋县城市总体规划（2013－2030年）》。

四、划分范围及执行标准

依据《陕西省洋县城市总体规划（2013－2030年）》中的规划用地范围，对1998年颁布实施的城区噪声功能区域划分方案进行了调整，洋县城区声环境功能区范围调整划分为西至朱家村东侧，东至白鹤村，北至纸坊街村，南至京昆高速北侧，总面积1599.87公顷。城区声环境适用区域执行《声环境质量标准》（GB3096-2008）中规定的标准，详见表1。

五、洋县声环境功能区调整划分结果

根据《声环境功能区划分技术规范》（GB/T15190-2014），结合县城建成区实际情况，将洋县城区划分为四类声环境功能适用区域，无0类声环境功能区适用区域。

1.一类标准适用区：西至东环路，南至永平路，东至天宁寺西路，北至华阳路-南环路区域；西至傥滨路，南至汉江大道-小西街，东至北街，北至北环路-晋昌路区域；西至梨园大道，南至北环路，东至东二环路，北至北二环路区域。一类声环境功能区面积为155.22公顷，占整个规划功能区面积的9.70%。

2.二类标准适用区：西至汉江以东，南至京昆高速，东至金城东路-城南路-天宁寺东路，北至永平路区域；西至天宁寺西路-东岳庙巷-东二环路，南至华阳路-天宁寺西路-永平路，东至天宁寺东路-横十六路-工业大道，北至横十五路-天宁寺东路-金城东路-北二环路区域；西至北街-小西街-汉江大道-汉江以东，南至永平路，东至东环路-东岳庙巷-东二环路，北至北环路区域；西至城西路，南至汉江以北，东至傥滨路，北至晋昌路-朱鹮大道-晋昌北路-傥源路-晋昌路-纵六路-晋昌北路区域；西至纵五北路-金城西路-城西路，南至晋昌北路，东至朱鹮大道，南至北二环路区域；西至朱鹮大道，南至晋昌路-北环路，东至梨园大道，北至北二环路区域；西至朱鹮大道以北，南至北二环路-纸坊路-文昌路-北二环路，东至武康北路以北，北至规划边界上纸坊街村区域。二类声环境功能区面积为1124.10公顷，占整个规划功能区面积的70.26%。

3.三类标准适用区：西至规划边界城西路，南至金城西路，东至纵五北路，北至北二环路区域；西至纸坊路，南至北二环路，东至文昌路，北至纸坊村区域；西至东环路，南至南环路，东至东二环路，北至东岳庙巷区域；西至东二环路，南至东岳庙巷，东至天宁寺西路，北至北二环路区域；西至天宁寺东路-横十五路-工业大道-横十六路-天宁寺东路，南至城南路，东至规划边界金城东路，北至金城东路-天宁寺西路区域。三类声环境功能区面积为306.96公顷，占整个规划功能区面积的19.19%。

4.四类标准适用区：4a类区为规划范围内洋县城区主干路及次干路交通干线两侧；4b类区为规划范围内洋县城区铁路线两侧和西成高铁洋县西站。4b类声环境功能区面积为13.59公顷，占整个规划功能区面积的0.85%。

（1）4a类区道路交通干线两侧区域的划分。若临街建筑以高于三层楼房以上（含三层）的建筑为主，将第一排建筑物面向道路一侧的区域为4a类标准适用区域。若临街建筑以低于三层楼房建筑（含开阔地）为主，将道路红线外一定距离内的区域为4a类标准适用区域。距离的确定方法如下：相邻区域为一类标准适用区域，距离为50m；相邻区域为二类标准适用区域，距离为35m；相邻区域为三类标准适用区域，距离为20m。

（2）4b类区铁路两侧区域的划分。若铁路两侧相邻区域为一类标准适用区域，距离为50m；铁路两侧相邻区域为二类标准适用区域，距离为35m；铁路两侧相邻区域为三类标准适用区域，距离为20m。
