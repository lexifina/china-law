# 洋政办发〔2019〕49号关于印发洋县城镇小区配套幼儿园治理工作实施方案的通知

洋政办发〔2019〕49号

洋县人民政府办公室

关于印发洋县城镇小区配套幼儿园治理工作

实施方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县城镇小区配套幼儿园治理工作实施方案》已经县政府同意，现印发给你们，请结合实际，认真组织实施。

洋县人民政府办公室

2019年5月31日

洋县城镇小区配套幼儿园治理工作实施方案

为解决全县城镇小区配套幼儿园规划、建设、移交、办园等环节存在的突出问题，依法落实城镇公共服务设施建设规定，着力构建以普惠性资源为主体的学前教育公共服务体系，有效解决“入园难”“入园贵”问题，按照市政府办公室《关于印发城镇小区配套幼儿园治理工作方案的通知》（汉政办发〔2019〕6号）精神，结合我县实际，制订以下实施方案。

一、主要任务

（一）全面摸排。对城镇小区配套幼儿园情况进行全面分类摸底排查，针对规划、配建、移交、使用不到位等情况，详细摸底，针对1500户以上小区(含1500户)，对应配建未配建，应缴费未缴费或缴费不足等情况建立台账，按照“一事一议”“一园一案”的要求制订治理方案，开展分类治理工作。对1500户以下小区，结合县城内学前教育资源规划，进行摸底和分析研判后，将需要补建的纳入治理范围。

（二）分类治理

1.对应移交但未移交的现有配套幼儿园的治理。已建成的小区配套幼儿园要按照规定及时移交县教体局。对经济适用房、移民搬迁、棚户区改造等小区，幼儿园用地以划拨方式取得的，或小区配建幼儿园合同签订未移交的配套幼儿园，应移交县教体局统筹办成公办园。对幼儿园用地以出让方式取得的，可采取租赁、购置、置换、捐赠、购买服务等方式，移交县教体局办成公办园或普惠性民办幼儿园。未移交县教体局的要限期完成移交，对已挪作他用的要采取有效措施予以收回。有关部门要按照规定对移交的幼儿园办理土地、园舍移交及资产登记手续。

2.对应配建幼儿园但未配建的现有城镇小区的治理。我县从2013年起，根据市政府下达的《汉中市收缴城市新建居住区配套规划幼儿园小学建设费实施办法》（汉政办发〔2012〕45号），县教体、住建、发改、国土、财政、监察六部门联合下发了《洋县收缴城市新建居住区规划幼儿园小学配套建设费实施细则》（洋教体发〔2012〕191号）和《关于进一步规范收缴城市新建居住区规划幼儿园小学配套建设费的通知》（洋教体发〔2013〕252号），对新建居住小区配建幼儿园及规划幼儿园小学收缴配套做了规定，目前执行情况较好。针对2013年1月1日前应配建幼儿园但未配建的城镇小区治理，要依据国家配建标准和省、市要求，通过补建、改建或就近新建、置换、购置等方式配建规模相适应的配套幼儿园。

3.对需配建幼儿园的在建或规划城镇小区的治理。对缓建、缩建、停建或不建配套幼儿园的在建城镇小区，要严格对标整改，在整改到位之前，不得办理竣工验收手续。需配建的幼儿园要按照标准与首期建设的居民住宅区同步设计、同步建设、同步验收、同步交付使用。对1500户以下单个居住小区不够配建标准但连片居住区密集度高、人口密度大的区域，要结合学前教育整体布局规划，统筹补建规模相适应的公办园或普惠性民办园。

（三）联合督查。在摸底自查、整改落实中，要加强部门联动，相关部门要开展联合督查和交叉检查，对落实不力、整改不到位的进行通报。

二、部门职责

1.住建局：负责对中心城区住宅小区配套幼儿园情况进行分类摸底排查，填报《洋县现有城镇小区配套幼儿园应移交未移交治理清单》（附件1），《洋县现有城镇小区应配建但未建幼儿园治理清单》（附件2），并完成摸底排查工作；加强对城镇小区配套幼儿园的建筑设计、施工建设、验收、移交的监管落实。

2.教体局：配合住建局和自然资源局完成中心城区配套幼儿园情况分类摸底排查工作；认真落实《汉中市收缴城市新建居住区配套规划幼儿园小学建设费实施办法》（汉政办发〔2012〕45号)《汉中市收缴城市新建居住区规划幼儿园小学配套建设费实施细则》（汉教发〔2012〕211号）文件精神，按照自然资源局开具的《洋县建设工程住宅建筑面积抄告单》，做好新建居住区规划幼儿园小学建设配套费收缴工作；参与小区配套幼儿园规划、建设、验收、移交等各环节工作，做好配建小区幼儿园移交的接收工作，办好人民满意的幼儿园。

3.发改局：参与小区配套建设幼儿园建设项目规划布局，对需要补建、改建、新建的项目按程序及时办理审批、核准或备案手续。

4.自然资源局：负责填报《洋县在建或规划城镇小区配套幼儿园情况摸排清单》（附件3）；负责改建、新建的配套幼儿园的规划选址工作；根据国家和地方配建标准，统筹规划城镇小区配套幼儿园，完成城镇新建居住小区配建幼儿园用地规划和工程规划许可等审批工作；对未达到配建幼儿园标准的城市新建小区向教体局开具《洋县建设工程住宅建筑面积抄告单》，并指导开展相关工作。

5.财政局：配合教体局做好城市新建居住小区配套建设费的收缴工作；做好配建幼儿园移交后的经费预算工作。

6.县编办、民政局：按照程序做好小区配套幼儿园移交涉及的机构编制工作，根据办园性质，分别由机构编制部门和民政部门依法办理事业单位法人登记或民办非企业单位法人登记。

三、工作要求

1.加强领导，落实责任。县政府成立洋县城镇小区配套幼儿园治理工作领导小组（以下简称县治理工作领导小组），组长由县政府分管教育的副县长担任，副组长由政府办主任、教体局局长、住建局局长、自然资源局局长担任，成员由发改局、教体局、民政局、住建局、自然资源局、编办、民政局等部门负责同志组成。县治理工作领导小组联合办公室分别设在教体局、住建局和自然资源局。各相关部门要相互配合、协同作战，确保治理工作落到实处，见到实效。各部门参照建立相应工作机制，加强治理工作协调。

2.强化措施，健全机制。各部门要认真制定具体实施方案，确保治理工作如期完成。要加强舆论引导和社会监督，及时向社会公布治理工作方案、治理措施及结果，畅通群众反映意见渠道，设立并公布监督举报电话和信箱。要健全部门工作联动、形势研判和应急反映机制，妥善处理突发事件，坚决维护社会稳定。要及时总结治理情况，制定完善小区配套幼儿园管理办法，形成规范管理的长效机制。

3.明确时限，顺利推进。2019年5月30日前，完成城镇小区配套幼儿园摸底排查和汇总上报；2019年6月15日前，完成已经建成、需要办理移交手续的配套幼儿园治理工作；2019年9月15日前，完成需要回收、置换、购置的配套幼儿园治理工作；2019年12月15日前，完成需要补建、改建、新建的配套幼儿园相关建设规划，2020年12月底前完成项目竣工验收和移交。2019年12月15日前，完成对各城镇小区配套幼儿园治理工作的督查。

各部门治理工作方案、反映意见渠道以及摸底排查、整改等情况，由县治理工作领导小组联合办公室分别对应报送市治理工作领导小组联合办公室。
