# 洋政办发〔2019〕59号关于印发洋县引汉济渭工程黄金峡水库不安全住房移民过渡安置工作方案（试行）的通知

洋政办发〔2019〕59号

洋县人民政府办公室

关于印发洋县引汉济渭工程黄金峡水库

不安全住房移民过渡安置工作方案（试行）的

通 知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县引汉济渭工程黄金峡水库不安全住房移民过渡安置工作方案》（试行）已经县政府同意，现印发给你们，请遵照执行。

洋县人民政府办公室

2019年7月22日

洋县引汉济渭工程黄金峡水库不安全住房

移民过渡安置工作方案（试行）

鉴于目前黄金峡水库移民安置工作正在实施过程当中，部分移民尚住在不安全住房中，为了确保汛期移民群众生命财产安全，不影响全县脱贫退出工作。按照2019年第6次县政府常务会议安排，对黄金峡水库不安全住房移民采取租房过渡方式进行临时性过渡安置，现制订本方案。

一、过渡安置条件范围

黄金峡水库移民当中无安全住房户（黄金峡库区范围内无房户及经住建部门认定并出具房屋鉴定报告属C、D级住房户），且未享受过过渡安置政策的水库移民户。具体如下：

1.未签订安置协议的；

2.已签订安置协议的，在集中安置点建房的，且2019年8月30号前达不到搬迁入住条件的；

3.已签订后靠安置协议的，因后靠宅基地划拨审批问题，在2019年8月30号前达不到搬迁入住条件的。

二、过渡安置方式方法

满足过渡安置条件范围的移民户采取租赁房屋过渡安置方式进行安置。各镇办、村要本着“一户一策”的原则，结合实际情况分类施策，对确需采取过渡方式安置的水库移民对象逐一进行研判，制订切实可行的实施方案。

三、过渡安置标准、时限

1.过渡安置标准：租房费每人每年按2000元计算、搬迁补助费每人一次性按1000元计算。

2.时限：过渡安置补助费（含租房费、搬迁补助费）一次性补助，过渡时限最长不超过一年。

四、工作要求

（一）核清底子，精准确定过渡安置对象

结合前期各镇办摸排上报脱贫办、水库移民办不安全住房户底数，各镇办要参照住建部门房屋安全级别鉴定，进一步核实核准不安全住房是否为移民唯一住房，精准确定过渡户数、人数，并于2019年7月31日前报县水库移民办和县脱贫办。

（二）严肃纪律，加快实施过渡搬迁

1.草坝、孤魂庙、五郎庙、柳树庙Ⅰ安置点以及采取分散、后靠方式达到入住条件的移民，各镇办要积极动员，确保2019年8月31日前搬迁入住。

2.在建或未安置且需租房的移民户，各镇办要在2019年8月30日前落实过渡安全住房；对未签订拆迁安置协议的过渡安置户，要在2019年7月30日前签订拆迁安置协议，按本方案实施。

3.有其他安全住房的移民，各镇要积极动员其尽快搬离旧房，及时拆除旧房。

4.过渡对象一经确定，不得随意增减变化，各镇办要严格审查收集原住房鉴定书、个人申请、新旧房照片、租房协议、拆迁安置协议书、旧房拆除后照片等相关佐证资料。

5.住建部门要积极配合镇村做好危房鉴定工作。

6.各镇办要做好政策宣传，动员搬迁过渡，做到公正、公平，及时化解矛盾，防止由此带来的上访、信访事项，确保库区移民稳定。

（三）高度重视，建立信息报送制度和督办制度

各镇办要落实专人，将水库移民各类统计报表，按照脱贫办报表时间要求，及时同步报水库移民办和脱贫办。水库移民办要梳理镇办移民问题清单，一月一交办，并做好督导落实工作。
