# 洋政办发〔2019〕51号关于明确洋县城区建筑垃圾及渣土扬尘污染治理联合执法领导小组办公室机构职责及人员组成的通知

洋政办发〔2019〕51号

洋县人民政府办公室

关于明确洋县城区建筑垃圾及渣土扬尘污染治理联合执法领导小组办公室机构职责及人员组成的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为进一步理顺我县建筑垃圾及渣土扬尘污染治理工作机制，根据县政府2019年第10次常务会议纪要精神，现就明确洋县城区建筑垃圾及渣土扬尘污染治理联合执法领导小组办公室机构及人员组成有关事项通知如下：

一、机构职责及具体任务

洋县城区建筑垃圾及渣土扬尘污染治理联合执法领导小组为县政府负责专项工作的议事协调机构，领导小组下设办公室，负责城区建筑垃圾及渣土扬尘污染治理联合执法工作，相对独立运行。

（一）主要职责：受县政府委托，依据《中华人民共和国国家安全法》《中华人民共和国道路运输条例》《中华人民共和国建筑垃圾管理规定》等相关法律法规，依法对城区内的建筑垃圾和渣土扬尘污染治理进行联合执法，并对与此相关的散装流体易抛洒材料运输进行管理。

（二）具体任务：1.负责城市规划区建筑垃圾处置运输，消纳场所核准工作。2.对建筑垃圾、渣土运输路线、时间、进行审核。3.会同相关单位对城市规划区施工工地进行监督管理。4.对城区各居民小区、物业管理区内房屋装修垃圾，及沿街店铺商业装修垃圾实施规范管理。5.对砂石、商混等散装流体货物生产厂进行源头监管。6.对未经核准擅自处理或超出核准范围处置建筑垃圾。不符合运输条件、未取得处置核准证件的单位或个人从事建筑垃圾、渣土、砂石等六类违法违规行为依法进行查处。7.做好本区域组建专业化运输公司与上级主管部门的工作衔接。8.完成上级交办的其它工作任务。

二、内设机构及人员组成

洋县城区建筑垃圾及渣土扬尘污染治理联合执法领导小组办公室主任由城管执法局局长兼任，副主任由县住建局、交通局、水利局、自然资源局、洋县交警大队、城管执法大队分管领导兼任，城管执法大队副大队长王文斌同志负责办公室具体开展工作。

洋县城区建筑垃圾及渣土扬尘污染治理联合执法领导小组办公室共设置综合组、源头监管组、联合执法组共3个内设机构，工作人员从各相关部门抽调，具体为：从洋县城市管理综合执法大队、洋县交警大队各抽调工作人员9名，从公安、运管、路政三个部门各抽调3名工作人员，从住建、水利、自然资源局各抽调2名工作人员，以上各单位抽调人员至少要有2人以上具备行政执法资格；从桑溪镇、黄家营镇各抽调1名工作人员。

洋县人民政府办公室
