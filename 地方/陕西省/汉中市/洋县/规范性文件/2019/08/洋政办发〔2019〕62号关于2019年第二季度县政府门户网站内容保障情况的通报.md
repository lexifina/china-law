# 洋政办发〔2019〕62号关于2019年第二季度县政府门户网站内容保障情况的通报

洋政办发〔2019〕62号

洋县人民政府办公室

关于2019年第二季度县政府门户网站内容

保障情况的通报

各镇人民政府、街道办事处，县政府各工作部门、直属机构：

2019年第二季度（4月1日-6月30日），县政府门户网站共发布各类信息1156条，其中新闻动态类信息657条，信息公开类499条。政府各部门及镇办通过网站后台上传各类信息501条，政府信息中心上传信息655条。处理“县长信箱”和“咨询投诉建议”来信201件，已办结197件、超时办结25件，未办结4件。

其中：教体局、生态环境分局、卫生健康局、磨子桥镇在信息发布和信息公开总量均超过20条，司法局、应急管理局、桑溪镇、黄金峡镇、纸坊办未发布和公开一条信息，信息统计为0；住建局、自然资源局、公安局在信件办理过程中回复及时，答复质量较高；交通局、洋州办、八里关镇存在未办结信件。

根据第二季度总体情况来看，大多数单位信息发布和处理群众来信情况较好，但仍有部分单位在发布信息时存在审核把关不严的现象；有17个部门、镇（办）政府信息公开意识不强，信息公开类信息统计为0。在处理网民留言方面，部分单位信件答复质量不高，答复效率较低，存在推诿扯皮，转办信件超期回复现象依然突出。

以上问题，请各镇办、各部门高度重视，特别是有未办结信件的单位，要安排专人尽快处理回复，务必做到事事有回音，件件有着落，避免反映人通过其他渠道重复反映同一问题；对群众关注度高的问题，承办单位要切实增强办理实效，力争做到答复语言规范、依据充分、事实清楚。
