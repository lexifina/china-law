# 洋政办发〔2019〕63号关于进一步强化网格化环境监管工作的通知

洋政办发〔2019〕63号

洋县人民政府办公室

关于进一步强化网格化环境监管工作的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为进一步提升县、镇（街道办）、村（社区）三级网格化环境监管体系建设水平，根据《洋县人民政府办公室关于印发洋县网格化环境监管工作方案的通知》（洋政办发〔2016〕16号）要求，结合我县环境保护监管工作实际，现就进一步强化网格化环境监管工作通知如下。

一、总体要求

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，深入贯彻落实习近平生态文明思想，以创新环境监管体制机制为切入点，以解决大气、水、土壤、农村环境监管中存在的盲区死角为重点，全面落实《环境保护法》：“地方各级人民政府对本行政区域内环境质量负责”要求，坚持党政同责、一岗双责、责权一致、齐抓共管，按照“谁主管、谁负责”“谁决策、谁负责”的原则，建立责任体系及问责制度，形成“各级政府组织实施、环保部门统一协调、相关部门各负其责、社会各界广泛参与”的环境保护工作格局，形成监管合力，提高监管效能，为全县经济社会又好又快发展提供有力保障。

二、工作原则

根据《洋县人民政府办公室关于印发<洋县网格化环境监管工作方案>的通知》（洋政办发〔2016〕16号）要求，全县实行县、镇（街道办）、村（社区）三级网格管理体系。县级主要负责制定全县网格化环境监管体系实施方案，建立网格化环境监管台账，并督导辖区内各镇办网格化环境监管体系的建立和运行，参照《洋县人民政府关于印发各镇办、各部门环境保护工作职责的通知》确定责任分工，督促具有环境监管职能的相关部门落实网格内的环境监管职责。

（1）实行“五定”。即：定区域、定人员、定职责、定任务、定奖惩。各镇办要在之前制定的网格化监管工作方案的基础上进一步细化，做到网格边界清晰、责任主体明确、目标任务具体，并进行公开公示。

（2）建立责任制。进一步明确工作任务和奖惩措施，各级网格之间（县与镇办部门，镇与村、社区居委会）层层签订责任书，横向部门之间加强协调联动，认真履行职责。

（3）构建环境监管信息系统。建立网格化监管台账，充分运用无人机等现代信息技术手段，建立网格化环境监管信息系统，逐步实现数字网格化监管。

三、运行管理

（1）巡查。三级网格（村、社区）责任人员要对辖区内生态破坏、排污企业、信访案件、污染纠纷、环境安全隐患、违法建设项目、饮用水源地、农村环境综合整治等生态环境影响行为进行定期巡查和监督，及时发现和制止环境违法行为，并向上级网格进行报告，协助调查和解决环境违法行为。

强化信息报送：各镇办要在每月3日前向县网格化环境监管工作办公室（设在市生态环境局洋县分局）书面报告上月网格巡查情况，发生突发情况应立即报告。

（2）查处。二级网格（镇办）责任主体接到巡查和监督人员的报告后，对属于本级本部门管辖的，要按照环境监管职责文件要求及时进行查处或移交有关单位部门进行查处。受理单位要在规定时间完成查处工作，并将处理结果反馈给移交单位。县网格化环境监管领导小组负责对联合执法行动实施统一协调，研究行动中的重大问题，制定行动方案，督办重点案件，相关部门要充分发挥各自职责，加强协调配合，坚持定期协商、联合检查及案件移送制度，形成执法合力，整治突出环境问题，确保环境安全。

（3）反馈。对环境违法行为的查处结果要及时答复相关人员，按要求进行公开，同时将查处结果告知下级网格责任主体。

（4）监督。县人大常委会、县政协、县纪委监委、社会舆论等监督体系，对环境监管工作情况进行及时监督；上级网格对下级网格的运行情况进行监督，不断完善和优化网格化环境监管体系的运行。

（5）联合审查。对新建项目，要加强同发改、自然资源、生态环境等相关部门的协同沟通，联合查看场地，共同研究审定投资项目是否符合国家政策，选址是否符合规划、环保等要求。通过信息共享、定期协商等有效方式，共同做好建设项目环境保护管理工作。

（6）强化奖惩机制。充分发挥村干部在网格中的巡查监管作用，在网格内发现环境问题应主动上报上级网格，对有问题隐瞒不报的追究相关村干部的责任。上级网格对下级网格检查、巡查时，发现的环境问题确属监管不力造成的，以及监管人员没有及时发现或者发现以后没有制止、处理情况严重的，移送县纪委监委严肃追责。

各镇办要结合本区域实际情况，及时安排部署、重新制定完善本区域的实施方案。要明确任务要求，按照网格划分方案进一步明确在网格化监管中的工作职责，逐一明确监管责任人，健全完善组织、监管、监督、保障、奖惩、企业自律“六大体系”。

请各镇办将重新制定的网格化环境监管方案于2019年8月25日前报送市生态环境局洋县分局。

洋县人民政府办公室

2019年8月2日
