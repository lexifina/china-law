# 洋政办发〔2019〕64号关于切实做好近期防灾减灾救灾工作的紧急通知

洋政办发〔2019〕64号

洋县人民政府办公室

关于切实做好近期防灾减灾救灾工作的

紧急通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

8月1日以来，我县多次遭受暴雨、滑坡等自然灾害。8月9日凌晨3时左右，溢水镇西河村七组发生山体滑坡，造成1人死亡；8月10日，黄家营镇华沟村发生山体滑坡，导致1人死亡、1人轻伤。血的教训警示我们做好防灾减灾救灾工作刻不容缓。为切实做好近期防灾减灾救灾工作，确保人民群众生命财产安全，现就有关事项紧急通知如下：

一、加强组织领导，确保责任和措施落实

各镇办、各有关部门要针对近期降雨过程可能出现的灾害天气，认真贯彻落实县委、县政府关于防灾减灾部署要求，特别是8月10日下午全市防汛视频会议王建军书记讲话精神，进一步加强领导，夯实责任，周密部署，全面排查，扎实有效做好工作，最大限度减少灾害损失，严防次生灾害导致人员伤亡事件发生。

二、加强监测预警预报，做好防范应对

应急、防汛、水利、自然资源、气象等部门要密切关注天气变化，进一步加强强降雨天气中短期预报、预警信息发布等工作，及时分析会商研判重要情况，为防灾减灾工作提供气象预报预警信息、灾害影响评估和对策建议。

各镇办要加强应急知识宣传，提高人民群众的自我保护和安全防范意识，要充分利用广播、电视、互联网等媒体，发挥好微信、短信、电子显示屏等平台作用，及时发布灾害预警信息和简明防灾避灾办法，指导群众特别是重点部位人群，采取有效防范应对措施，做好紧急避险。

三、加强隐患排查治理，确保人民群众生命财产安全

各镇办、各有关部门要进一步组织力量，结合近期脱贫攻坚交叉检查，将危房拆除纳入检查内容，加大对仍居住在旧房的群众再动员，拆旧腾退除隐患，入住新房保安全。要进村入户逐一对塘库、危旧房屋、削坡建房户、易涝易滑塌等部位进行全面巡查、排查、复查。对所有排查出来的隐患点、重点户要逐一落实管控措施，提前制定防、抢、撤应对措施，做好应急救援和应急处置准备，确保群众生命安全。

四、加强灾害救助，做好群众生活保障

各镇办和自然资源、应急管理、防汛、水利、卫健、民政、交通、电力、通讯等有关部门要充分发挥职能作用，积极做好防灾抗灾及与群众生活密切相关的各类物资储备，保证灾情发生时，能够及时抢修损毁道路、电力线路及通讯设施，并及时向受灾地区调拨帐篷、食品、饮用水、衣被等生活必备物资。卫生防疫和医疗救助要迅速到位，保证受灾群众有饭吃、有衣穿、有干净水喝、有安全住房、有病及时医治。一旦出现灾情各部门之间要加强应急联动，组织专业队伍和社会各方面力量，及时开展应急处置工作。各镇办要加强河道及河道沿线的巡查、警示，做好人员疏散工作。要严密防范次生灾害发生，努力将灾害造成的损失降到最低限度。

五、加强应急值班值守和灾情报送工作

各镇办、各有关部门要进一步加强应急值班值守工作，严格执行24小时值班和领导带班制度，及时掌握灾情信息，积极做好灾情核查核报和受灾群众安置救助等工作。要严格落实属地和部门责任，对因工作落实不力造成严重后果的将严肃问责。

洋县人民政府办公室

2019年8月10日
