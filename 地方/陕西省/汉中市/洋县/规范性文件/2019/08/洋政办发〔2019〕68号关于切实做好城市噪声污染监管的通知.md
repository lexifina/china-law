# 洋政办发〔2019〕68号关于切实做好城市噪声污染监管的通知

洋政办发〔2019〕68号

洋县人民政府办公室

关于切实做好城市噪声污染监管的

通 知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为进一步加强我县城市噪音污染监管，明确各相关部门单位工作责任，改善城区声环境质量，不断提升人民群众的获得感和幸福感，根据《中华人民共和国环境噪声污染防治法》《中华人民共和国治安管理处罚法》《城市管理执法办法》和县政府会议精神，现就切实做好城市噪声污染监管有关事项通知如下：

一、查处噪声污染行为的工作程序

（一）城市生活噪音。城管执法局接到市民投诉举报后，第一时间函告生态环境局和公安局，在48小时内开展现场核查。生态环境局做好前期调查取证，并对噪音污染情况进行测定。如未超标，应与当事人联系做好解释；如已超标，应及时锁定违法证据，出具《噪音污染检测鉴定报告》，并移交县公安局。公安局负责做好群众的稳控工作，并对噪声源制造者进行警告，纠正违法行为，对于警告无效的，依据《中华人民共和国治安管理处罚法》进行处罚。生态环境局和公安局应在规定时限内将核查或处理结果书面函复城管执法局，由城管执法局做好回复销号。

（二）建筑工地夜间施工噪音。城管执法局接到建筑工地夜间施工噪音举报后，第一时间函告生态环境局和住建局，在48小时内开展现场核查。如夜间施工已被核准，则由住建局负责做好解释工作；如夜间施工未核准，则由生态环境局进行查处。查处结束后，应及时将查处情况函复城管执法局，城管执法局按程序回复销号。

二、日常监管

（一）生态环境局负责工业噪声、建筑施工噪声和商业经营活动中使用空调器、冷却塔等固定设施产生的噪声的污染监管，生态环境局要依照相关法律法规，加强工业企业噪声排放情况的监督检查，对超过国家噪声排放标准造成环境污染的企业，依据法定程序责令限期整改或限期治理。严格建筑施工噪声管理，未按照规定作业时间施工的或不按《建筑施工噪声排放许可证》规定的作业时间施工的，要依据有关法律法规予以处罚。因特殊情况，确需在夜间连续进行施工作业的，须经住建局批准并公告附近居民。

（二）公安局负责社会生活噪声、交通噪声的污染整治，公安局要加强对商业经营活动中使用高音喇叭或者采用其他发出高噪声的方法招揽顾客、在公共场所组织娱乐集会使用音响器材、室内娱乐活动、已竣工交付使用的住宅楼进行室内装修等产生的噪声污染的监管，以及警车、消防车等机动车辆安装、使用警报器的监管。

（三）文化旅游局负责文化娱乐场所噪声污染的监管，文化旅游局在核发《文化经营许可证》前，应征求生态环境局的意见，对场界噪声不符合排放标准的，不得核发《文化经营许可证》。对未领取《文化经营许可证》的KTV、酒吧等营业场所，严格按照《娱乐场所管理条例》有关规定依法予以取缔。

（四）住建局负责审查建筑施工单位，建筑施工单位因特殊情况，需要在夜间连续进行有环境噪声污染的施工作业的情形，需经住建局审批后，报生态环境局、城管执法局审核同意，同时公告附近居民后，方可施工。住建局负责开明广场、体育场、蔡伦广场、高铁广场等场所使用音响器材造成的噪声污染的监管职责。

（五）城管执法局负责沿街商业经营活动中使用高音广播喇叭或者采用其他发出高噪声的方法招揽顾客及沿街窜卖的劝导，配合相关部门做好监管。

城管执法局负责城市噪声污染防治的牵头工作，生态环境局、住建局、公安局、文化旅游局按照职责做好查处。
