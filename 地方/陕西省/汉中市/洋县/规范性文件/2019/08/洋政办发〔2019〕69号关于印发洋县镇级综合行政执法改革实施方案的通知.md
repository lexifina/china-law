# 洋政办发〔2019〕69号关于印发洋县镇级综合行政执法改革实施方案的通知

洋政办发〔2019〕69号

洋县人民政府办公室

关于印发洋县镇级综合行政执法改革

实施方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县镇级综合行政执法改革实施方案》已经县政府同意，现印发给你们，请认真贯彻落实。

洋县人民政府办公室

2019年8月22日

洋县镇级综合行政执法改革实施方案

为认真贯彻落实《中共中央办公厅、国务院办公厅印发关于推进基层整合审批服务执法力量的实施意见》（中办发〔2019〕5号）、《中共汉中市委办公室、汉中市人民政府办公室关于印发<镇级行政管理体制改革试点实施方案>的通知》（汉办发〔2019〕6号）精神和《中华人民共和国行政处罚法》等有关法律法规规定，进一步转变政府职能，深化镇级行政管理体制改革，理顺县镇权责关系，提高基层执法能力，推进综合执法，现结合工作实际，制定洋县镇级综合行政执法改革实施方案。

一、指导思想

深入学习贯彻党的十九大和十九届二中、三中全会精神，以习近平新时代中国特色社会主义思想为指导，按照加强基层政权建设、统筹城乡协调发展的要求，遵循“统筹管理、权责统一，相对集中、依法行政，积极稳妥、有序推进”的原则，通过下移执法职权，整合执法力量，建立“权责明确、行为规范、监督有效、保障有力”的基层行政执法体系和运行机制，努力破解镇级行政管理的体制机制障碍，着力提高镇级经济社会治理和公共服务能力，促进镇域经济社会又好又快发展，为建设“六个洋县”提供有力保障。

二、工作目标

（一）结合镇级行政管理体制改革，探索建立符合镇级发展需要的权责明确、行为规范、公正透明、廉洁高效的基层行政执法管理体制，有效解决镇（办）行政执法权责不明、多头执法、执法缺位，在镇级逐步实现一支队伍管执法，使各镇（办）行政执法更加规范，执法力量明显加强，执法水平明显提高，实现镇级管理向服务型、法治型转变。

（二）把法律法规赋予镇（办）的行政处罚、行政强制、行政检查、行政征收等执法权相对集中。

（三）根据镇（办）经济发展和社会管理的需要，在充分考虑镇（办）行政管理需求和承接能力的前提下，采取“先易后难、先少后多”的方式，重点将法律、法规、规章规定的县级部门在城镇规划建设、城镇管理、安全生产、市场监管、民生保障等领域的行政执法职权赋予镇级，通过委托的形式由镇（办）在本辖区范围内履行。同时全面实行行政执法责任制和责任追究机制，加强行政执法监督，确保下放镇（办）的执法权接得住、用得好。

三、建立综合执法管理体制

按照《洋县镇级行政管理体制改革实施方案》，整合镇（办）现有办、站、所执法力量和资源，设立的镇（办）综合执法办公室，统筹辖区内派驻和基层执法力量实行联合执法，按照有关法律规定相对集中以镇（办）名义行使行政处罚权及相关行政强制和监督检查权。县级部门派出行政执法机构接受镇（办）统一指导和协调，以派出单位名义开展执法工作，日常执法活动以镇（办）管理为主，逐步实现基层一支队伍管执法。

四、明确执法职权

（一）对现行法律法规、规章赋予镇（办）的行政执法权，由镇（办）综合执法办公室负责直接行使。

（二）对部门依法委托给镇（办）行使的行政执法权，由镇（办）综合执法办公室以委托主体的名义负责行使。各部门要依据权责清单，针对镇（办）执法半径短、快捷高效的特点，按照违法行为易于确定、执法程序简便易行的原则确定具体执法事项并进行委托，建立行政执法重心下移常态机制，不断加强综合行政执法。

（三）要规范镇（办）综合行政执法程序。有关部门要及时制定出台镇（办）综合行政执法的相关指导意见，积极指导、支持镇（办）开展相关工作。

五、组织实施

（一）明确行政执法主体。各镇（办）依照法律法规、规章规定依法行使监督管理、行政处罚等方面的行政执法职权，由各镇（办）综合执法办公室在镇级执法事项范围内以镇（办）名义实施行政执法行为，在受委托的执法事项范围内以委托部门名义实施行政执法行为，具体行政执法任务由镇（办）综合执法办公室承担。其中：对于适用简易程序的行政处罚案件，所作出的行政处罚决定必须及时到原部门备案；对一般程序的行政处罚案件，镇（办）综合执法办公室在立案时应书面告知委托的部门，委托部门应及时予以指导和监督。

（二）明确法律责任。按照权责一致,“谁主管、谁负责”的原则，镇（办）综合执法办公室对承担的综合行政执法事项全面负责。因行政执法引起的行政复议、行政诉讼案件，由各镇（办）负责举证和出庭应诉等具体法律事务；因此而产生的法律责任也由各镇（办）承担。

（三）加强人员配备和管理。县级相关执法部门、镇（办）应为镇（办）综合行政执法队伍选派业务水平高、责任心强的人员。镇（办）综合行政执法人员确定后，由有关部门和各镇（办）统一到司法局、人社局审核备案。

（四）规范统一执法文书格式。参照县级行政执法部门的各类执法文书，编制镇（办）综合行政执法法律文书格式。

六、工作要求

（一）广泛宣传发动。在镇（办）开展综合行政执法工作，是我县镇级行政管理体制的重大改革，要通过各种途径广泛、深入地宣传与镇（办）综合行政执法工作有关的法律法规、方针政策、程序步骤，使广大人民群众能够认识到这一改革的积极性，保证镇（办）综合行政执法工作健康、有序进行。

（二）建立执法协作机制。建立县级执法部门与各镇（办）的信息共享机制、执法协作机制和业务指导定期联系制度。县级执法部门要加强对各镇（办）的业务指导，受理处理各镇（办）在巡查中发现并上报的违法违规问题,对因指导和监管不力造成过错的要承担相应的行政责任。各镇（办）要建立案件分类处理机制，第一时间制止违法违规行为，受理处理权限内违法违规行为，发现权限外的违法行为，及时通报相关执法部门。县级相关行政执法部门要对各镇（办）依法履行职责的活动予以积极支持和全力配合，帮助解决执法过程中遇到的问题，规范综合执法行为，提高综合执法水平。

（三）监管处罚并举。要遵循“防控为主、处罚为辅”的原则，坚持执法与服务相结合、处罚与教育相结合，积极推行行政指导，引导公众广泛参与管理并自觉接受监督。要切实加强日常监管，实现监管与执法的有效衔接，消除监管中的薄弱环节。执法中应首先进行劝导制止、责令整改，劝导无效或确需作出行政处罚的，依照管理规定作出定性认定，实施行政处罚。

（四）强化执法队伍建设。统一组织对镇（办）综合行政执法人员实施专业培训，县级相关执法部门也要定期安排人员到各镇（办）进行业务培训和指导。各镇（办）要积极组织综合执法人员参加培训，并自行组织开展各种形式的业务工作培训，同时要加强对执法人员的思想政治教育和职业道德教育，提高执法人员的政治素质、法律意识，树立公正、文明执法的良好形象。
