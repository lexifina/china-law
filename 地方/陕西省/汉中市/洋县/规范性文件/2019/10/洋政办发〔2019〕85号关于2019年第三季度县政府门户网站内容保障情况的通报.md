# 洋政办发〔2019〕85号关于2019年第三季度县政府门户网站内容保障情况的通报

洋政办发〔2019〕85号

洋县人民政府办公室

关于2019年第三季度县政府门户网站内容

保障情况的通报

各镇人民政府、街道办事处，县政府各工作部门、直属机构：

2019年第三季度（7月1日-9月30日），县政府门户网站共发布各类信息1099条，其中新闻动态类信息646条，信息公开类453条。政府各部门及镇办通过网站后台上传各类信息435条，政府信息中心上传信息664条。处理“县长信箱”和“咨询投诉建议”来信272件，已办结256件、超时办结34件，未办结17件。其中：生态环境分局、财政局、市监局、教体局在信息发布和信息公开总量均超过20条，经贸局、关帝镇、纸坊办未发布和公开一条信息，信息统计为0；人社局、自然资源局在信件办理过程中回复及时，答复质量较高；住建局、文旅局、洋州办、槐树关镇、黄家营镇、八里关镇存在未办结信件。

根据第三季度总体情况来看，大多数单位信息发布和处理群众来信情况较好，但部分单位存在信息公开不及时，信息公开量少的问题，其中有23个部门、镇（办）政府信息公开统计量为0。在处理网民留言方面，依然存在部分信件处理不及时，答复质量不高，内容敷衍搪塞的现象，且超期回复现象依然突出，个别单位存在信件未办结的问题。

以上问题，请各镇办、各部门高度重视，要进一步夯实责任，完善信息发布的常态化机制，彻底杜绝信息公开栏目更新不及时或不更新的问题；同时，在回复群众来件过程中，要依法依规处理来件人所反映的问题，回复内容要做到事实清楚，有理有据，措辞得当，确保件件有答复、事事有回音。
