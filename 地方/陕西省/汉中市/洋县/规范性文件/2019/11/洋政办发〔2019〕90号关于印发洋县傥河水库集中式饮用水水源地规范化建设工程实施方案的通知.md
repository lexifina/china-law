# 洋政办发〔2019〕90号关于印发洋县傥河水库集中式饮用水水源地规范化建设工程实施方案的通知

洋政办发〔2019〕90号

洋县人民政府办公室

关于印发洋县傥河水库集中式饮用水水源地

规范化建设工程实施方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县傥河水库集中式饮用水水源地规范化建设工程实施方案》已经县政府同意，现印发给你们，请认真贯彻落实。

洋县人民政府办公室

2019年11月7日

洋县傥河水库集中式饮用水水源地规范化建设工程实施方案

为全面推进傥河水库集中式饮用水水源地规范化建设，加快实施傥河水库饮用水水源地保护工程，确保人民群众饮用水安全，根据城市饮用水水源保护要求和《洋县傥河水库饮用水水源地环境保护规划方案》，制定本实施方案。

一、工作目标

按照《集中式饮用水水源地规范化建设环境保护技术要求》（HJ773—2015），通过实施相应工程保护措施，全面加强傥河水库集中式饮用水水源地保护区规范化建设，完善长效管理工作机制，确保傥河水库饮用水水源水质安全稳定达标。

二、实施范围

傥河水库饮用水水源地划分为一级保护区、二级保护区和准保护区（陕环水体函〔2019〕12号），对一、二级保护区重点实施保护工程。

（一）一级保护区

一级保护区包括水域、陆域两部分，总面积5.97km2。

1.水域范围：正常蓄水水位线以下的全部 水域面积，保护面积1.472km2。

2.陆域范围：正常水位线上外延200m的陆域面积，保护面积4.498km2。

（二）二级保护区

二级保护区包括水域、陆域两部分，总面积22.815km2。

1.水域范围：入库河流河道由水库库尾上溯3km的水域面积，保护面积0.238km2。

2.陆域范围：与二级保护区水源对应的左右两岸各50m范围内的陆域面积和一级保护区陆域对应左右边界至流域内的汇水范围，保护面积22.577km2。

（三）准保护区

坝址以上除一、二级保护区以外的全部流域内的汇水范围，总面积208.215km2。

三、建设内容

（一）设置保护区标志标识

1.按照《饮用水水源保护区标志技术要求》（HJ/T433—2008），设置傥河水库水源保护区边界界桩134个，其中一级保护区64个，二级保护区70个。

责任单位：县水利局

配合单位：纸坊办、戚氏办、关帝镇

完成时限：2019年12月31日

2.按照《饮用水水源保护区标志技术要求》（HJ/T433—2008），设置傥河水库水源保护区警示牌27个，其中一级保护区14个（关帝镇鸭岭村3个、白刘村1个，纸坊办清凉村5个、西岭村3个、冉家村2个），二级保护区13个（戚氏办上赵村1个、潘湾村1个，纸坊办西岭村2个、田岭村2个、石槽村1个，关帝镇马家岭3个，里湾口、王家台、史家后面各1个）。

责任单位：县水利局

配合单位：纸坊办、戚氏办、关帝镇

完成时限：2019年12月31日

3.按照《饮用水水源保护区标志技术要求》（HJ/T433—2008），设置水源保护条例标志牌56个，其中关帝镇鸭岭村4个、白刘村11个，戚氏办上赵村、潘湾村各1个，纸坊办清凉村、西岭村各10个、田岭村3个、冉家村14个、流浴村2个。在一、二级保护区村庄设置水源保护宣传牌。

责任单位：县水利局

配合单位：纸坊办、戚氏办、关帝镇

完成时限：2019年12月31日

4.按照《饮用水水源保护区标志技术要求》（HJ/T433—2008），设置水源保护区道路交通警示牌39个，其中洋铁路（一、二级保护区内长6公里）12个，戚氏—纸坊通村路北至胡家湾南至傥河水库大坝前区域（一、二级保护区内长5公里）20个，戚氏—纸坊通村路南起石槽村北至潘修村念佛崖区域（一、二级保护区内长1.5公里）7个。

责任单位：县交通局

配合单位：纸坊办、戚氏办、关帝镇

完成时限：2019年12月31日

（二）实施保护区隔离防护

1.按照《饮用水水源保护区标志技术要求》（HJ/T433—2008），在一级保护区边界建设隔离防护栏网20 km，优先隔离保护取水口核心部分，封闭人员易靠近区域。

责任单位：省水务集团洋县供水公司

配合单位：县水利局、纸坊办、戚氏办、关帝镇

完成时限：2020年12月31日

2.在保护区公路与水库或居住区与水库之间，采用常年青乔木建设多处防护林隔离带，适当加密原有林地，形成天然隔离防护屏障。

责任单位：县林业局

配合单位：纸坊办、戚氏办、关帝镇

完成时限：2020年12月31日

（三）防治生活面源污染

1.制定计划分年度搬迁一级保护区内现有88户住户（纸坊办西岭村六组24户、清凉村二组14户、清凉村三组19户、冉家村十一组10户，关帝镇鸭岭村三组11户、白刘村一组10户）。在完成搬迁前实行严格登记管理，禁止一级保护区内出现新增住户。搬迁完成后，对原居住地进行生态恢复。

责任单位：纸坊办、关帝镇

配合单位：县住建局、县自然资源局、县水利局

完成时限：按照搬迁计划

2.封堵一、二级保护区内生活排污口和现有的直排水库的明渠暗槽。一级保护区内88户住户未完成搬迁前，采取收集处理方式，严禁生活污水外排。二级保护区内村庄生活污水进行集中收集处理后在保护区外排放。

责任单位：纸坊办、戚氏办、关帝镇

配合单位：市生态环境局洋县分局、县住建局

完成时限：按照搬迁计划

3.在保护区内各村庄配置生活垃圾收集转运设施（大型垃圾箱36个，其中关帝镇鸭岭村1个、白刘村5个，戚氏办上赵村1个，纸坊办西岭村7个、田岭村4个、流域村1个、冉家村9个，垃圾转运车7辆），一、二级保护区内村镇生活垃圾统一收集、统一运送至保护区外进行无害化处理。

责任单位：纸坊办、戚氏办、关帝镇

配合单位：县住建局

完成时限：2019年12月31日

（四）防治工业源污染

一级保护区内拆除或关闭已建成的与供水设施和保护水源无关的建设项目，禁止新、改、扩建与供水设施和保护水源无关的建设项目。二级保护区内拆除或关闭已建成的排放污染物的建设项目，禁止新、改、扩建排放污染物的建设项目。

责任单位：纸坊办、戚氏办、关帝镇

配合单位：县发改局、县住建局、县自然资源局、县经贸局、市生态环境局洋县分局

完成时限：2019年12月31日

（五）防治农业面源污染

1.拆除或关闭一级保护区内现有的规模化畜禽养殖场和网箱养殖，禁止新建规模化养殖场；二级保护区内拆除或关闭保护区划定前已有的规模化畜禽养殖场；保护区内分散式畜禽养殖废物全部资源化利用零排放。

责任单位：纸坊办、戚氏办、关帝镇

配合单位：县农业农村局

完成时限：2019年12月31日

2.严格控制保护区内41.79km2耕地农作物种植面积，大力发展生态有机农业。一级保护区内禁止新增农业种植和经济林，保护区划定前已有的农业种植和经济林严格控制化肥、农药等非点源污染，并逐步退出。

责任单位: 县农业农村局

配合单位：县自然资源局、纸坊办、戚氏办、关帝镇

完成时限：长期坚持

（六）建立水源地监测机制

按照国家相关技术规范要求，设置监测断面点位，定期开展水源地常规监测。

责任单位: 市生态环境局洋县分局

配合单位：省水务集团洋县供水公司

完成时限：长期坚持

（七）开展应急能力建设

1.建设应急防护工程。对一级保护区内洋铁路河西村至符家沟之间1km区域，设置防撞护栏600m、公路两侧隔离网600m、靠近水库一侧事故导流槽600m和应急池。对一级保护区内戚氏—纸坊通村公路北至胡家湾南至傥河水库大坝前区域，设置防撞栏2km、公路两侧隔离网2km、靠近水库一侧事故导流槽2km、监控摄像头4个和应急池。对一级保护区内戚氏—纸坊通村公路南起石槽村北至潘修村念佛崖区域，设置防护撞栏900m、公路两侧隔离网900m、靠近水库一侧事故导流槽2km、监控摄像头3个和应急池。保护区内严格限制危险化学品运输车辆。

责任单位: 县交通局

配合单位：纸坊办、戚氏办、关帝镇

完成时限：2020年12月31日

2.编制备案傥河水库饮用水水源突发环境事件应急预案，健全完善应急体系，防范水体富营养化风险，定期开展应急演练并修订应急预案。

责任单位：省水务集团洋县供水公司

配合单位：纸坊办、戚氏办、关帝镇、县水利局

完成时限：2020年6月30日

四、工作要求

(一)夯实工作责任。各相关单位要将集中式饮用水水源地规范化建设作为夯实水源地管护基础、提升水源地环境管理水平的重要着力点，加强组织领导，强化措施落实，确保水源地保护各项工程措施按期完成。

(二)加快建设进度。各单位要紧盯时间节点，按照职责分工，加强统筹协调，全力以赴抓进度抓落实。对工作不力、进展迟缓的，要严格督察督办，严肃追责问责。

(三)健全长效机制。建立健全水源地管理机制，完善水源地日常监管制度，强化部门沟通合作，加强水源地生态环境保护协调联动，切实提高集中式饮用水水源环境安全保障水平。
