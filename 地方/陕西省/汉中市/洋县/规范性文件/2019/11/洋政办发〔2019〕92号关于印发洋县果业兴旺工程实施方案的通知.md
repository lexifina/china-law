# 洋政办发〔2019〕92号关于印发洋县果业兴旺工程实施方案的通知

洋政办发〔2019〕92号

洋县人民政府办公室

关于印发洋县果业兴旺工程实施方案的

通     知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县果业兴旺工程实施方案》已经县政府研究同意，现印发给你们，请认真贯彻执行。

洋县人民政府办公室

2019年11月20日

洋县果业兴旺战略实施方案

为认真贯彻落实市政府“3+X”特色产业发展要求，加快猕猴桃产业“东扩南移”战略步伐，进一步做大做强洋县水果产业，助推产业扶贫和县域经济发展，结合洋县实际，现制定本实施方案：

一、发展思路

以实现习近平总书记提出的“果业强、果农富、果乡美”为目标，突出“猕猴桃、梨”两大拳头果品，强化“柑桔、桃、葡萄三大优势果品，通过扩大规模化种植，加强标准化生产、产业化经营、全程化监管，形成品种技术先进、设施装备精良、产业结构优化、区域布局合理、经营机制有效、经营主体有力、经济效益优良、生态环境友好的新型现代化果业格局，实现产业增效，农民增收。

二、任务目标

(一)建立标准化种植基地

从2019年每年新建优质水果基地6000亩，至2023年新建标准化水果基地3万亩，使全县水果面积达到15万亩。其中有机标准化种植面积5万亩-8万亩，占全县水果总面积的50%以上。

(二)提升产业化经营水平

培育水果产业主体，发展壮大果业龙头企业，到2023年，全县果业龙头企业发展到8-10户，其中省级2-5户、市级5-8户，果业龙头企业带动作用日趋明显；积极引导发展专业合作社，把专业合作社作为水果产业规模化、标准化生产的承载主体，到2023年，全县发展水果类专业合作社达30个以上。

(三)提升品牌效应

突出有机生态优势，做强“朱鹮”商标，不断提升我县果业整体形象，在国内消费群体中的认知度进一步提高，在相关电子商务网站的销售排名居于前列。

(四)提高产品附加值

加大果品的储藏及精深加工，延长产业链条，拓展销售渠道，提高水果加工附加值，2023年实现果品加工综合销售收入2亿元。

三、重点工作

（一）规模化建设

1.扩大种植规模。以马畅、谢村、溢水、戚氏、洋州、纸坊、龙亭、磨子桥、黄安、槐树关等10个平川镇办为重点，以猕猴桃为首选，梨、柑桔为补充，逐步形成汉江北部丘陵，汉江南部坡地两个果业带。2019年优先实施汉江北部丘陵果业带，西部竹园--五郎庙片，包括戚氏办全丰村、陶岭村、竹园村、五郎庙村、藩湾村、下赵村发展猕猴桃产业；中部牛头山片，包括纸纺办巩家槽社区、草坝村、文同村发展猕猴桃、梨产业；东部何家村--柳山片，洋州办何家村、梁家村、龙泉村、木瓜园村，龙亭镇柳山村、平溪沟村发展猕猴桃、桃产业。2020年后续完成东起槐树关镇万岭村、王湾村，龙亭镇杜村村、镇江村，西至马畅镇大坝沟村、倪家村的北部丘陵果业带。同时推动汉江南部坡地果业带，逐步形成黄安东村村、黄安村、何家村、闫堡村、蒙家渡村，磨子桥镇磨子桥村、张山下村、白河村、牛砭村、袁赛村、八一村片汉江南部坡地果业带，发展猕猴桃、柑桔产业。利用5年时间打造洋县15万亩水果产业带。结合农村“三变改革”，鼓励和引导有条件的企业、合作社、经纪人、生产大户等经营主体集中连片，整村、整条沟发展，建立水果种植基地。以上每个镇办每年至少建立300亩以上示范片1个，有生产基础的贫困村优先开展建设。全县利用5年时间，每年新建优质水果生产基地6000亩（见附件1）建成果业新基地3万亩，形成15万亩水果产业带。(责任单位：县农业农村局、扶贫办、水利局、发改局、财政局、相关镇办)

2.加强果园基础设施建设。通过积极争取各方面资金，加大对水果种植基地机耕路、机电井及配套、桥涵闸、渠道防渗、排灌站等小型农田水利设施建设扶持力度，优先实施高标准农田建设项目。(责任单位：县水利局、电力局、交通局、农业农村局、发改局、财政局、相关镇办)

3.提高果业机械化水平。落实好农机购置补贴资金，鼓励和指导企业、合作社多渠道筹集资金，购置先进适用、低耗高效、安全可靠的果园作业机械，重点支持果园割草机、喷药弥雾机等中小型组合式农机具，促进作业机械和动力机械配套。推进果园作业机械化，力争耕作、除草割草、开沟施肥等地面作业环节机械化率达到70%以上，修剪等环节实现半机械化。 (责任单位：县农业农村局、财政局)

(二)标准化生产

1.加快健全和完善洋县水果标准体系。加快配套制定保障果品质量安全的生产技术规范和操作规程。制定和完善洋县梨、猕猴桃、葡萄、柑桔、桃的产地环境、品种、种植、田间管理、收获、贮藏、运输和加工等方面的地方标准，并在全县推行。(责任单位：县农业农村局、市监局、经贸局)

2.加快标准化果园建设。 按照农业农村部果树标准园创建方案、生产技术规程和产品质量安全管理制度，在自然条件和产业基础较好的地区，集中连片布局，完善道路、水利等基础设施，选用优良品种，合理选择栽培模式，应用先进技术，高标准建设20个标准化果园，每个面积300亩。加强示范引领，在果业生产水平较高的区域选择2个镇，设立果业标准化示范区，整县推进标准化。(责任单位：县农业农村局、经贸局、财政局、相关镇办)

3.加强老果园改造。 以梨、桃和柑桔为重点，加快老果园改造更新，提高老果园生产能力。对条件适宜、建园时间较短，但品种较差的果园，通过高接换头、老品种淘汰更新等方式，实现果园品种改良。对管理粗放、病虫害严重、产量低而不稳的果园，推广应用改土施肥，扩盘蓄水、整形修剪、保花保果、病虫害防治等关键技术，改善老果园生产条件，促进树体复壮和产量恢复，提高效益。对品种老化、病虫害严重的果园，尽快实施全园更新。到2023年，全县改造果园2万亩，提升3万亩。（县农业农村局、财政局、相关镇办）

4.加大有机认证力度。通过政策支持和市场引导，鼓励涉农企业和农业生产合作社发展有机认证生产，积极开展“有机水果认证，提高洋县水果标准化生产水平。2023年基地有机水果种植面积发展到5万亩-8万亩，占全县水果种植总面积的50%以上。(责任单位：县有机办、农业农村局、市监局、财政局)

(三)产业化经营

1.创新产业经营主体。大力发展水果生产企业、农民专业合作社、家庭农场、营销经纪人、生产大户，提高生产经营能力。着力培育壮大企业和农民专业合作社，到2023年，全县水果龙头企业发展到3-5户，其中省级1-2户，水果产业专业合作社达50个以上。(责任单位：县农业农村局、经贸局、市监局、财政局、相关镇办)

2.加大新型农业经营主体带动作用。省、市、县级水果产业化重点龙头企业和农民专业合作社要分别带动200户、100户和50户以上农户发展水果产业。(责任单位：县农业农村局、发改局、经贸局、相关镇办)

3.创新经营形式。鼓励农产品龙头企业与农民专业合作社成立洋县果业协会或产销联盟，引导水果种植户参加农民专业合作社，探索开展“党支部+村集体经济组织+专业合作社（龙头企业等）”“企业+合作社+贫困户（种植户）”“合作社+贫困户（种植户）”等多种生产模式，通过入股分红、订单生产、入企务工等多种形式与贫困户完善利益联结机制，推进产业扶贫。(责任单位：县农业农村局、扶贫办、财政局、相关镇办)

4.拓展营销渠道。鼓励企业、合作社、个人等开展电子商务和在国内重点城市建立品牌直销店，“线上线下”互动，多渠道拓宽洋县水果销售渠道。到2023年，外销洋县果品达到10万吨，全县实现加工综合销售收入2亿元。(责任单位：县经贸局、市监局、供销社、财政局)

（四）集约化融合

以梨园景区、田园综合体为载体，注重参与体验，挖掘文化内涵，加大休闲农业资源整合力度，建设一批集果业生产、文化娱乐、教育展示、生态环保、产品销售于一体的多元化休闲果业观光园区。引导有条件的果农发展以“吃农家饭、住农家院、摘农家果”为主要内容的农家乐，争创星级农家乐。以休闲度假和参与体验为核心，拓展多元功能，发展功能齐全、环境友好、文化浓郁的休闲农庄。依托时令水果和其他特色水果产业，合理配置树种、品种，建设一批鲜果主题公园和市民采摘果园。进一步拓展洋县黄金梨果采摘节等果业节会活动的形式和内容，将果品节会与当地旅游资源和民风民俗结合起来，实现“以节会友、以节拓市、以节富民”。(责任单位：县文旅局、农业农村局、扶贫办、财政局、相关镇办)

(五)强化产后初加工和冷链贮运

1.加强采后初加工。实施果品采后商品化提升项目。加强果品初加工设施建设，在采后预冷、清洗、烘干、打蜡、分级、包装等环节，支持果业企业、合作社，提升完善猕猴桃、柑橘、葡萄等果品采后初加工生产线，形成万吨采后商品化处理能力。采取政府扶持、新型经营主体建设、农业部门技术指导和服务的方式，筛选与示范推广先进适用的果品采后商品化处理技术，提高果品产地初加工水平。(责任单位：县农业农村局、发改局、财政局、相关镇办)

2.完善冷链贮运。加强冷藏设施建设，在果品基地镇建设大中型果品气调库或机械冷库，新建机械制冷或气调冷库5个。大力发展冷链运输，建设以冷藏运输车为主、以网点冷藏为辅的鲜果冷链物流体系，配备节能环保的长短途冷链运输车辆。鼓励企业和合作社加快冷链物流设施建设，积极培育第三方冷链物流服务企业，实现产销市场冷链物流的高效对接。(责任单位：县农业农村局、发改局、财政局、相关镇办)

（六）品牌化发展

1.加快洋县水果品牌整合。做大做强“洋县果品”区域公用品牌和“朱鹮”商标。按照“区域公用品牌+企业产品品牌”的双品牌模式，整合洋县果品产品品牌，提高市场知名度和占有率。(责任单位：县市监局、经贸局、农业农村局、财政局、供销社)

2.加强品牌规范与自律。充分发挥协会职能作用，组织制定洋县果品标志品牌使用管理办法，规范企业行为，维护品牌信誉。(责任单位：县市监局、经贸局、农业农村局、民政局、相关镇办)

3.加强洋县果品品牌监督管理。加大督查、监管力度，政府相关部门定期开展洋县果品品牌专项检查和整治行动，依法打击制售假冒伪劣和侵犯洋县果品系列商标专用权的违法行为，依法从重处理，净化市场环境。(责任单位：县市监局、公安局、经贸局、农业农村局)

4.组织开展洋县果品品牌宣传。围绕我县生态环境、水果种植优势、内在品质以及历史文化，利用电视、广播、报纸、网络等媒体做好系列报道宣传，探索举办果品采摘节、梨花节、文化节等主题节会，积极参加全国各类知名特色农产品、有机产品展销会、博览会，多途径宣传洋县果品。建立和完善洋县果品品牌宣传机制，鼓励和引导多元主体加大品牌宣传投入、创新品牌宣传方式，提升洋县果品在全国的知名度和影响力。(责任单位：县农业农村局、宣传部、经贸局、供销社、发改局、财政局)

(七)全程化监管

1.强化土壤环境保护的监督管理。加强土壤污染状况调查和地表水污染防治，全面推进农业面源污染防治。(责任单位：县农业农村局、水利局、生态环境局、市监局、自然资源局、相关镇办)

2.加强投入品监管。加强对种子、肥料、农药等农资投入品的市场监督检查，加强对农药等投入品的使用监督和指导；严厉打击国家明令禁止的高毒农药使用，从源头把住果品生产安全关。(责任单位：县农业农村局、市监局、相关镇办)

3.加强种植环节管理指导。组织全县农业技术服务推广部门做好水果种植中农业投入品规范使用的技术指导与服务，做好果树病虫害的绿色防控、统防统治技术推广。鼓励增加有机肥施用量，推广生物物理除虫技术，最大限度降低有害物质残留。支持种植基地300亩以上片区安装24小时监控摄像头，建立数据中心，实施整个生产过程监控。(责任单位：县农业农村局、发改局、财政局、相关镇办)

4.质量安全追溯。建立健全质量追溯管理制度，支持和推动洋县果品信息采集和监管系统建设。力争到2020年，全县果品基本实现生产有记录、信息可查询。(责任单位：县农业农村局、市监局、财政局)

四、保障措施

(一)加强组织领导

洋县果业发展领导小组负责全县果业兴旺工程基地建设的组织和领导工作，领导小组办公室设在县农业农村局，负责贯彻执行领导小组工作部署，组织实施果业兴旺工程建设。相关镇办也应要组建相应的机构，加强发展果业基地建设的组织领导和协调工作。

(二)强化部门联动

产业发展各环节所列责任部门第一位的为牵头部门，做好本环节组织协调工作，各相关部门要立足本职工作，主动承担任务，密切配合，通力协作，为洋县果业带的快速发展壮大尽职尽责。

(三)加大资金扶持力度

从2019年起，每年不低于1000万元，重点支持水果产业发展。

1.规划区域内集中连片发展水果面积达50亩以上实施补助。新发展猕猴桃每亩补助2000元，其中苗木500元，棚架补助1000元，水肥一体化补助500元；新发展梨、桃、柑桔每亩补助300元。在规划区近三年内发展的果园，建园苗木、水肥一体化和棚架补助的面积单项或多项未获补助的可申报对应补助，已经获得建园苗木和棚架补助的面积不再补助。

2.各类农业经营主体集中连片发展水果100亩以上，每亩奖励100元；在贫困村集中连片发展水果100亩以上，每亩奖励150元；相关镇办以村为单位集中连片发展果业100亩以上每亩奖励100元。

3.对企业聘请专家进行补助。企业果园面积达到100亩以上，由企业自主聘请技术专家，政府一次性按每亩10元的标准给予补助，最高不超过2万元。

4.对新购置旋耕机、果园割草机、喷药弥雾机各类主体，按所对应国家农机具购置定额补贴的50%再给予补贴，最高不超过3万元。

5.对获得“有机食品”果品认证的，认证费100%补贴；对果业产业化发展中新取得的相关发明专利，每项奖励1万元。

6.对企业发展产后加工和冷链贮运贷款（有相关银行认可的、合法有效的）进行贴息，贴息期限为5年。贷款额度在100万元以下的按照国家同期贷款基准利率的70%贴息；贷款额度在100万元-300万元（含）的按照国家同期贷款基准利率的80%贴息；贷款额度在300万元-500万元（含）的按照国家同期贷款基准利率的90%贴息；贷款额度在500万元以上的按照国家同期贷款基准利率的100%贴息，最高不超过50万元。

7.每年列支100万元，用于水果种质资源保护、新品种选育、引进、试验、示范、水果品牌整合及宣传等方面工作费用。

8.每年列支300万元，用于水果产业市场风险防控。

各相关水果经营主体在享受扶持政策时，不再重复享受政府其他相关优惠政策中相同环节补助。

(四)加大项目扶持力度

县发改局、财政局、农业农村局、水利局、自然资源局、经贸局等部门，要结合水果产业发展，积极挖掘上报项目，多途径加大对水果产业的项目支持力度。

(五)加大金融、保险支持力度

鼓励金融机构加大信贷投放力度，发挥中小企业担保公司的作用，帮助企业、农民合作组织和家庭农场融资。推行政策性农业保险，建立完善全县农业保险体系，鼓励农民积极参保，提高农业生产抗风险能力。

（六）强化督查考核

1.加大水果种植基地建设督查。相关镇办为责任主体，采取企业申报，基地所属村汇总、公示，镇核查，县抽查，加强对本辖区水果种植的监督核查，每年11月底前将各类经营主体果业新建设果园情况调查表（见附件2）及花名册（见附件3）公示无异后报镇办，由镇、办组织人员核查，核查汇总、公示无异后报备县农业农村局。每年12月份，县政府派出检查组，对相关镇办经营主体果业基地建设进行考核，并在相关镇办所报发展花名册中随机抽取不少于10%样本进行实际核查，核查结果作为相关补贴发放的主要依据。

2.强化品牌建设、销售等环节督查。各相关责任部门，按照自身职能，加强对各水果生产主体品牌建设、销售等环节的服务和管理，督导核实建设情况，严防弄虚作假。

3.将水果基地发展纳入相关镇办年度目标责任考核内容，重点考核土地流转和保障机制的落实，县考核办要加强水果产业建设检查和考核，实行产业发展一票否决制。
