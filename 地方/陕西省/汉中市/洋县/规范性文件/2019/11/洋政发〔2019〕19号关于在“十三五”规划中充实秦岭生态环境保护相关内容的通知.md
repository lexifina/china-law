# 洋政发〔2019〕19号关于在“十三五”规划中充实秦岭生态环境保护相关内容的通知

洋政发〔2019〕19号

洋县人民政府

关于在“十三五”规划中充实秦岭生态

环境保护相关内容的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为深入践行习近平生态文明思想，切实抓好省委第八巡视组反馈意见整改落实，10月11日县政府第19次常务会议审议通过了《“十三五”洋县秦岭生态环境保护补充规划》，现将相关内容充实在《洋县国民经济和社会发展第十三个五年规划》第七章 “加快生态文明建设 着力打造美丽家园”第四条。请认真贯彻执行。

补充规划：

第七章“加快生态文明建设 着力打造美丽家园”。

四、全面加强秦岭生态环境保护

牢固树立“绿水青山就是金山银山”理念，坚持节约优先、保护优先、修复优先的生态优先原则，以《陕西省秦岭生态环境保护条例》为遵循，以《汉中市秦岭生态环境保护总体规划》为依据，以保护好秦岭生态环境为目标，以系统治理山水林田湖为路径，统筹推进植被保护、水资源保护、生物多样性保护、开发建设生态环境保护等任务，加快形成秦岭地区主体功能定位清晰、生态屏障坚强有力、人与自然和谐相处、经济发展与民生改善共生共赢的发展新格局。

强化主体功能区在秦岭保护中的基础作用，涉及秦岭的开发建设活动，遵循先规划、后建设的原则，除法律、行政法规另有规定外，核心保护区不得进行与生态保护、科学研究无关的活动。重点保护区内不得进行与其保护功能不相符的生产、建设活动。一般保护区的生产、生活和建设活动，应当遵守法律、法规和条例的规定，并符合省秦岭生态环境保护总体规划和产业政策的要求。重点保护区、一般保护区实行产业准入负面清单制度，严格建设项目准入，落实生态环境保护责任，加强事中事后监管。

按照“谁污染谁治理、谁破坏谁修复”原则，强化政府监督责任和企业主体责任，采用先进工艺、技术和措施，综合治理水、土壤、大气、尾矿库、重金属等污染，集中储存、处置尾矿渣等废弃物、污染物，确保达标排放，切实减少和控制各类开发建设活动对秦岭生态环境的损害。

以保护和恢复森林植被为核心，按照自然修复为主、人工修复相结合原则，实施天然林资源保护、长江防护林二期、退耕还林、水土保持等工程建设，采取封山育林、人工造林、飞播造林、退耕还林等措施，提高植被覆盖率，修复自然生态环境功能。到2020年，生态保护红线全面划定，矿区环境恢复治理与复垦、自然保护区、生态示范区建设进一步加强，生态环境质量总体改善，环境风险得到有效管控，环境监管能力显著提升，地表水环境质量达到水功能区划水质要求，汉江出境断面水质稳定保持达标，秦岭生态环境保护综合协调、齐抓共管的长效化机制基本健全，生态环境保护水平同全面建成小康社会目标相适应。

洋县人民政府

2019年10月24日
