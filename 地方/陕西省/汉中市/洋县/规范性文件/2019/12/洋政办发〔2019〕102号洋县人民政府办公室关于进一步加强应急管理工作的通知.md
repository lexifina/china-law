# 洋政办发〔2019〕102号洋县人民政府办公室关于进一步加强应急管理工作的通知

洋政办发〔2019〕102号

洋县人民政府办公室

关于进一步加强应急管理工作的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

为进一步加强应急管理工作，不断提高应急管理能力和水平，有效防范和处置各类突发事件，切实保护人民群众生命财产安全，确保我县经济社会持续、快速、健康发展，现就有关事项通知如下：

一、扎实做好政务值班工作

（一）认真落实值班各项制度规定。严格执行24小时值班和领导带班制度，严肃值班纪律，做到值守到位、联络畅通、运转高效。精心组织节假日和重要敏感时期的值班工作，落实“零报告”“日报告”制度。公安、应急、卫健等承担突发事件应急管理的部门单位，各镇办以及其他直接涉及公共安全的企业事业单位要强化值班力量建设，加强协调配合，落实好值班、带班制度，确保反应迅速、应对有力。

（二）强化值班规范化建设。持续推进政务值班标准化建设，及时总结经验、推广典型，引导各部门不断提升值守应急规范化、精细化水平，着力构建岗位职责明确、值班保障有力、工作制度健全、工作行为规范、监督管理到位的应急值班工作格局。探索推广视频点名机制，定期交流经验做法，确保工作实效。同时，加强对值班工作的督导检查，及时发现问题，限期整改落实。

二、着力提升信息报告水平

（一）提高信息报告质量。认真贯彻落实中省市县关于突发事件信息报送工作的有关要求，严格落实信息报告主体责任，不断增强第一时间获取信息、核实信息、报告信息能力，确保重要敏感信息报告及时、准确、规范。各镇办以及县公安、应急、卫健、市监、交通等部门单位，要充分发挥接触现场早、覆盖面广等优势，加强重要信息的收集报告工作，着力提升信息报告能力。同时，要加强对微博、微信、网络媒体的监测分析，及时掌握突发事件线索和影响社会安全稳定的苗头性、趋势性、敏感性信息。

（二）畅通信息报告渠道。加强对信息报告工作的研究分析，坚持问题导向，不断优化信息处理流程，提高报告时效。积极推进基层信息员队伍建设，创新形式，在企业、社区、农村、学校等基层单位以及事故、灾害易发多发地区，建立健全信息员队伍，夯实基层信息报告工作基础。

（三）及时报告重要敏感信息。严格按照紧急敏感信息报告规定要求，加强对重要信息的分析研判，防止出现紧急敏感信息漏报迟报。事发地镇办及有关部门接到要求核报的信息， 要通过各种渠道迅速核实，及时反馈相关情况。

三、切实强化应急预警和处置

（一）健全完善应急预案体系。大力推动应急预案建设，重点加快村、社区和中小学校、重点企事业等基层单位应急预案的编制工作，进一步扩大应急预案覆盖面。从应急预案的编制、审批、发布、备案、修订、宣传培训和演练等各个环节加强管理，明确各类应急预案修订完善的责任主体和时限，推动应急预案体系建设制度化和规范化。同时，针对生产经营的特点，以贴近实战为标准，分批次组织开展专项应急演练。

（二）不断提高预警防范水平。进一步完善监测预警机制，及时发布有关预警信息，提醒有关方面做好应对准备、采取预警期的措施或者启动相应级别的应急响应。加强镇办减灾信息员培训工作，分批次轮训村级灾害信息员，确保基层信息员“懂预警、会监测、能上报”，同时做好防震减灾助理员、灾情速报员的确认和信息登记工作。对学校、医院、体育场等公共设施和铁路、电力等重要基础设施实行分级分类管理，合理规划布局应急避难场所。

（三）健全完善应急联动机制。加快整合应急资源和救援力量，建立应急联动系统、应急指挥体系和资源保障机制， 切实提高应急处置救援反应速度和技战术水平，确保快速有效处置各类突发事件。实施突发事件应对联席会商机制和信息通报机制，遇有突发事件发生，第一时间启动应急响应，成立现场应急救援指挥部，召集相关部门和专家进行会商，研究应对处置方案，并及时对外发布事件信息和应对处置情况。从信息共享、资源共享、协作联动、联合演练、联席会议五个方面加强沟通、交流、合作，构建突发事件长期、稳定、高效的应急联动处置机制，不断提升各类突发事件的应急能力。

四、加强应急保障体系建设

（一）强化应急管理基础能力建设。各部门要健全、规范应急管理办事机构，配足配强专职、兼职人员，提供经费保障，确保应急管理工作有人抓、有人管。要完善专项应急指挥机构，进一步强化职能，做好各领域突发事件应对处置工作。抓好应急示范点建设，在学校、企业等基层单位开展应急管理示范点规范提升活动，鼓励基层应急管理机构充分发挥职能作用，服务群众生产生活。

（二）全力推进应急救援队伍建设。探索、创新基层综合应急救援队伍建设思路，切实发挥镇办派出所、联防队员、医务人员、民兵组织的作用，组建镇级综合应急队伍；动员各村（社区）和企事业单位，做好基层应急队伍组建工作。加强对各级各类应急救援队伍的业务指导和联络沟通，强化协调联动，畅通联系渠道，提高综合应对和紧急处置的能力，构建统一高效、上下联动、协调一致的应急救援体系。

（三）做好应急专家组服务协调。应急局要根据工作实际需要，健全完善各类应急救援专家人才库，做好人力资源的统筹规划。适时组织专家组开展重大课题调研活动，发挥专家在突发事件信息研判、决策咨询、专业救援、灾后评估等方面的作用，为应急管理提供决策支持。

五、加强应急管理宣教指导

（一）强化应急知识宣传。各镇办、各部门要加强对突发事件应对法律、法规和应急知识的宣教，普及应急预防、避险、自救、互救、减灾、预案等知识，推动应急宣传进机关、进企业、进学校、进社区、进农村、进家庭，切实提高社会公众防灾避险意识和自救互救能力。新闻媒体要无偿开展突发事件预防与处置、自救与互救等知识的公益宣传。各行业主管部门要负责各企业、事业单位从业人员安全知识和操作规程培训，对未按要求开展培训的，责令限期整改，对达不到要求的管理人员和职工，不得上岗。县应急局要定期举办“减灾日、消防日”“安全月”等活动，编制《洋县应急管理手册》、印发应急管理宣传海报等资料，全面普及安全知识，全力提升广大群众安全意识。

（二）加大应急培训力度。各级各部门要将应急管理教育纳入党员干部教育培训计划，定期举办专题培训班，强化应急知识的学习和操作技能的掌握；县安委办要对县安委会各成员单位应急管理干部进行培训，使其熟悉并掌握应急预案和相关工作制度，切实增强高效开展应急管理工作的能力；各行业管理部门要对行业内企事业单位负责人进行培训，尤其是对高危行业从业人员进行安全知识的教育培训，使其增强公共安全和风险防范意识，提高排查安全隐患、安全管理和第一时间应急处置突发事件的能力。

（三）加强应急管理检查考核。应急管理工作已纳入全县目标考核内容，《洋县安全生产考核奖惩实施办法》即将印发，县应急局要联合相关部门适时开展督查考核，对在日常应急管理、预防和处置突发事件应急工作中有失职、渎职、玩忽职守等行为，以及在突发事件信息报告中有迟报、漏报甚至瞒报、谎报等行为的予以通报批评，并严格目标考核，造成严重后果的，将依法追究相关单位和人员的责任。

洋县人民政府办公室
