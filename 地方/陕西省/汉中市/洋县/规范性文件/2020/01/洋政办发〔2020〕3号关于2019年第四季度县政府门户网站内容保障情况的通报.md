# 洋政办发〔2020〕3号关于2019年第四季度县政府门户网站内容保障情况的通报

洋政办发〔2020〕3号

洋县人民政府办公室

关于2019年第四季度县政府门户网站内容

保障情况的通报

各镇人民政府、街道办事处，县政府各工作部门、直属机构：

2019年第四季度（10月1日-12月31日），县政府门户网站共发布各类信息1205条，其中新闻动态类信息587条，信息公开类618条。政府各部门及镇办通过网站后台上传各类信息546条，政府信息中心上传信息659条。处理“县长信箱”和“咨询投诉建议”来信178件，已办结171件、超时办结13件，未办结7件。其中：生态环境分局、市监局、住建局、农业农村局、卫健局、自然资源局、戚氏办在信息发布和信息公开总量均超过20条，退役军人事务局、搬迁办、龙亭镇、华阳镇、八里关镇、黄金峡镇未发布和公开一条信息，信息统计为0；医保局、教体局、自然资源局、人社局、公安局、卫健局在信件办理过程中回复及时，答复质量较高；住建局、洋州办、城管执法局、龙亭镇、槐树关镇存在未办结信件。

根据第四季度总体情况来看，仍有部分单位存在信息公开不及时，信息公开量少的问题，有11个单位政府信息公开数量为0。通过检查各单位“政府信息公开目录”，发现8个单位存在栏目更新不及时，5个单位存在栏目长期不更新的问题，洋州办、华阳镇、八里关镇近一年未在本单位“政府信息公开目录”中公开政府信息，未履行政府信息公开义务，形成“僵尸栏目”。有25个单位未按照相关要求公开《政府信息主动公开基本目录》。

目前，省市对政府网站监测和评估工作已形成常态化，并建立了网站监管和问责机制，不断加强政府网站检查工作力度，对出现更新不及时、空白栏目等问题的网站行政主体进行约谈问责。以上通报中所存在的问题，请各镇办、各部门务必高度重视，要进一步夯实责任，完善信息发布的常态化机制，要按照网站上划分的“信息公开目录”和政务公开绩效评估工作相关要求，落实栏目保障责任，梳理完善有关内容，切实做到“以公开为常态，不公开为例外”。同时要建立自查自纠工作机制，各单位的“政府信息公开目录”每月至少更新1次，彻底杜绝信息公开栏目出现更新不及时和长期不更新的问题。

附件：1.2019年第四季度政府网站后台信息发布情况；

2.2019年第四季度政府网站“县长信箱”及“咨询投诉建议”办理情况；

3. 各单位“政府信息公开目录”更新情况；

4. 《政府信息主动公开基本目录》公开情况。
