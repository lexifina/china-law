# 洋政办发〔2020〕18号关于印发洋县镇级财政国库集中支付制度改革实施方案的通知

洋政办发〔2020〕18号

洋县人民政府办公室

关于印发洋县镇级财政国库集中支付制度

改革实施方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县镇级财政国库集中支付制度改革实施方案》已经县政府同意，现印发给你们，请认真组织实施。

洋县人民政府办公室

2020年3月24日

洋县镇级财政国库集中支付制度改革实施方案

为进一步深化财政国库集中支付制度改革,切实加强镇级财政管理，确保镇级财政资金安全运行，充分发挥财政资金使用效益，根据《预算法》关于“国家实行国库集中收缴和集中支付制度，对政府全部收入和支出实行国库集中收付管理”的有关规定，以及《财政部关于乡镇国库集中支付制度改革的指导意见》（财库〔2014〕177号）等文件精神，结合我县实际，制定本方案。

一、改革的指导思想和基本原则

（一）指导思想

贯彻落实中省市关于财政国库管理制度改革精神，按照社会主义市场经济体制下公共财政的发展要求，结合我县镇级实际情况，建立和完善以国库单一账户体系为基础，资金缴拨以国库集中收付为主要形式的镇级财政国库管理制度，努力打造“高效、规范、公开、透明”的镇级财政资金收付管理新模式。

（二）基本原则

在现行的镇级财政预算管理总体框架下，按照全面推进财政科学化精细化管理要求，坚持镇级财政资金使用权、所有权、财务管理权、会计核算权和镇财政管理责任“五个不变”，充分发挥财政信息应用大平台作用，建立和完善国库单一账户体系，对镇级财政性资金通过镇级国库单一账户体系存储、支付和清算，确保镇财政资金安全运行，提高财政资金使用效率，更好地发挥财政的管理和服务职能，促进镇域经济和社会事业全面发展。

二、改革的主要内容

（一）确定科学的改革模式，健全单一账户管理体系

按中央和省、市确定的改革基本框架，未设置镇级金库的镇办，可将镇办视同县级预算单位实施国库集中支付制度改革。我县镇级财政国库集中支付制度改革充分考虑镇级金库设置情况、镇级财政管理体制、财政收支规模、实际管理需要等因素，以是否有利于增强财政透明度、是否有利于保障财政资金安全、是否有利于提高财政资金运行效率为原则，结合实际情况，确定以“镇级视同县级预算单位实施改革”模式进行改革。

（二）规范账户设置

建立镇级统一的国库单一账户体系。镇级财政可设置的账户包括：

1.镇级预算单位零余额账户。由各镇办财政审计所按照县级财政部门要求在代理银行开设，用于财政授权支付，并与县级国库单一账户清算，做到日终零余额管理。实行财政直接支付的镇级财政资金，通过县级财政零余额账户办理。镇级预算单位零余额账户统一命名为：××镇人民政府（街道办事处）零余额账户，预留镇政府（街道办事处）印鉴。

2.镇级财政审计所零余额账户。由各镇办财政审计所按照县级财政部门要求在代理银行开设，统一命名为：××镇人民政府（街道办事处）财政审计所零余额账户，预留财政审计所印鉴。

3.镇级往来资金财政专户。将原来的预算户改为××镇人民政府（街道办事处）实存往来资金户，用于管理核算各镇预算单位往来资金、捐助资金、保证金等。每个镇办只能开设1个往来资金财政专户，对不同性质资金实行分账核算。

4.保留原有的民政专户、扶贫专户和搬迁专户，按原有方式继续管理核算。

除上述专户外，其余专户全部撤销，将剩余专户资金转入实存往来资金户。

（三）规范收入收缴程序

按照现行财政体制和相关管理要求，各镇办财政审计所将所收各项应缴收入及时、足额缴入县国库或县非税收入财政专户，严禁坐收坐支，更不得直接转换成单位其它资金指标。

（四）规范支出拨付程序

1.支出类型

镇级财政支出总体上分为基本支出和项目支出。

基本支出包括：

（1）工资福利性支出。反映单位开支的在职职工和编制外长期聘用人员的各类劳动报酬，以及为上述人员缴纳的各项社会保险费等。

（2）商品和服务支出。反映单位购买商品和服务的支出。

（3）对个人和家庭补助支出。反映单位用于对个人和家庭的补助支出。

项目支出包括：纳入政府采购的资金支出，上级拨付的各种专项资金等。

2.支付方式

按照不同的支付主体，对不同类型的支出，分别实行财政直接支付、财政授权支付和财政实拨支付。

（1）财政直接支付。镇办财政审计所提出财政资金支付申请，通过县财政零余额账户，直接将财政资金支付到商品和劳务供应者或用款单位。

（2）财政授权支付。由镇办财政审计所依据财政授权额度，自行开具财政授权支付凭证，通过预算单位零余额账户将资金支付到收款人，可以办理转账、电汇和提现业务。严格控制现金支出额度，属于公务卡支出范围的，必须通过公务卡支出。

（3）财政实拨支付。纳入预算管理的财政性资金都应实行国库集中支付。镇级往来资金、其他非财政性资金等可采用实拨方式，由镇办开具财政实拨支付凭证，通过财政实有资金账户将资金支付到收款人，不得从往来户开具大额现金支票，原则上不得大额转账至个人账户。

3.项目用款计划申报

（一）纳入“财政云”管理的项目支出。县财政局依据各镇办年度预算和调整预算录入并审核下达指标额度。镇级各单位根据预算单位指标情况，通过“财政云”在指标额度内申报预算单位用款计划报经镇政府（办事处）、财政审计所主要领导审定后提交县财政局。县财政局预算科根据批准的年度预算、资金使用计划及相关要求进行初审，县财政局国库科根据库款情况进行终审并下达用款计划。

(二)其他项目支出。各镇办财政审计所要按照项目管理要求建立项目支出台账，加强项目资金监管。对项目单位的用款计划进行审核并报镇政府主要领导审批后按程序拨付。

4.支付要求

（1）纳入“财政云”管理的支出。按照县级相关要求办理授权支付。

（2）其他支出。要严格按照相关资金管理的要求，加强内部控制，分设会计和出纳岗位，严格票据审核，不得违规支付。

（五）会计核算

实行镇级国库集中支付后，不改变现行的会计核算管理模式,镇办财政审计所要切实履行预算会计职能，根据县财政局下达的预算指标、用款计划及支付凭证进行账务处理。各镇办财政审计所记账会计负责预算、代管往来资金的核算。镇级预算单位会计核算按要求实行电算化核算。县财政局通过网络对镇办资金支付和会计核算进行实时监管。

三、改革的配套措施

（一）规范预算编制管理

根据预算管理要求，镇办财政审计所应在县级财政部门的指导下，结合国库集中支付制度改革相关要求，进一步规范和细化预算，不断提升预算编制的科学性和准确性，逐步使所有财政资金的支付建立在明晰的预算基础上，为顺利实施国库集中支付改革创造条件。

（二）完善县镇财政网络

以目前县、镇财政网络为依托，实现县财政局、镇办财政审计所、代理银行分支机构的专网连接，建立全县统一的国库单一账户体系。各镇办通过全省统一的“财政云”，对镇办预算指标、用款计划、资金支付实行网上监控。资金支付实行网上申请、审核、支付和查询，提高财政信息化管理水平和资金使用效率。

（三）夯实总预算会计基础工作

切实加强镇办总预算会计管理基础工作，健全岗位设置和人员配备，形成有效的内部制衡机制。镇办财政审计所代理预算单位记账的，应将预算单位会计账与总预算会计账分设。规范镇级财政专户管理，实行国库集中支付的资金，不通过财政专户核算。

（四）规范代理银行管理

结合我县银行业金融机构设置和服务情况，选择经中国人民银行洋县支行认定具备国库集中收付代理业务资格的洋县农村信用合作联社为代理银行，与代理银行签订规范的委托代理协议，并全面、清晰界定双方的权利和义务。

四、职责任务

实行镇级国库集中支付后，各镇办及相关部门的基本职责如下：

县财政局：负责组织制定有关政策和规章制度，管理和监督财政国库集中支付改革实施；负责管理、开设镇国库集中支付有关账户；审核、批复各镇办预算，下达预算指标；审核、批复各镇办用款计划，合理调度资金，进行资金清算；负责对镇办预算执行、资金支付及财政决算中的重大事项进行监督和稽查；负责财政信息系统的维护管理工作。

人行洋县支行：负责办理国库资金结算；对国库资金进行监督管理；从业务上指导和监督洋县农村信用合作联社代理国库收付业务。

各镇办：负责编报单位年度预算、分月单位用款计划；负责按部门预算管理使用财政性资金，并做好相应的财务管理工作；负责提出财政直接支付申请，提供有关申请所需凭证，并保证凭证的真实性、合法性；负责编制本级预决算执行情况报告和报表；依照本办法规定按时与县财政局有关科室、县国库支付局、代理银行核对账务。

五、改革单位、实施步骤和时间

（一）改革单位

对全县18个镇、街道办事处实施“预算单位”模式的改革。

（二）实施步骤和时间

1.改革前期准备阶段。2020年3月31日前县财政局出台国库集中支付操作、会计核算、资金清算等相关制度，系统设置和测试，组织相关业务人员培训。各镇办按照改革要求开设相关银行账户，做好指标和资金的核对，安装软件、系统设置和测试。代理银行负责各镇办分支机构与财政业务内网连通、配备相关办公设备等工作。

2.改革实施阶段。2020年4月1日，改革后的镇办国库集中支付系统（即财政云）正式上线运行。

六、工作要求

（一）提高思想认识。各镇办要从制度创新和源头防腐的高度统一思想，提高对镇级国库集中支付制度改革重要性和必要性的认识，积极配合参与改革，确保我县镇级财政国库集中支付改革顺利推进。

（二）严明财经纪律。国库单一账户体系建立后，各镇办应按照各账户规定的用途使用账户，对未经财政国库部门批准、备案的银行账户一律视为“小金库”，账户资金予以没收，并对主要领导和直接经办人员依法依纪予以严肃处理。

（三）加强监督制约。各镇办要加强对财政资金使用的监督，认真审核资金使用计划；建立健全内部监督制约机制，对国库支付执行过程中出现的问题及时向县财政局反馈，确保财政资金安全。

（四）加强业务培训。财政部门要加大对财政局相关科室、各镇办财政审计所和代理银行等部门相关人员的培训力度，指导学习改革相关文件，督促尽快熟悉业务操作流程，切实履行各自职责。各单位要加强协调配合，确定专人、明确职责，确保改革顺利进行。
