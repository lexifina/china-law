# 洋政办发〔2021〕8号关于印发洋县深化“互联网+先进制造业”发展工业互联网实施方案的通知

洋政办发〔2021〕8号

洋县人民政府办公室关于

印发洋县深化“互联网+先进制造业”发展工业互联网实施方案的通知

各镇人民政府、街道办事处，县政府各工作部门、直属机构，市管单位：

《洋县深化“互联网+先进制造业”发展工业互联网实施方案》已经县政府研究同意，现印发给你们，请认真贯彻落实。

洋县人民政府办公室

2021年3月7日

洋县深化“互联网+先进制造业”

发展工业互联网实施方案

为加快我县工业互联网建设，推动工业及制造业提质增效，建设制造强县和网络强县，根据市政府办公室《关于深化“互联网+先进制造业”发展工业互联网的实施方案》（汉政办发〔2020〕29号）精神，结合我县实际，制定如下实施方案。

一、指导思想和工作目标

以习近平新时代中国特色社会主义思想为指导，深入学习贯彻习近平总书记来陕考察重要讲话精神，积极贯彻新发展理念，推动全县制造业与新一代信息技术深度融合，以建设工业强县为战略目标，以企业核心业务和重点设备上云为牵引，着力构建以网络为基础、平台为核心、安全为保障的工业互联网生态体系，积极推广基于工业互联网平台的各类应用，提升制造业发展质量、效率与价值，构建数字驱动的工业经济新生态，实现制造业与互联网相互促进、同步提升。

到2021年，初步建成低时延、高可靠、广覆盖的工业互联网网络基础设施，5G等新型网络在工业领域推广商用，县内先进制造业、企业内外部网络升级改造有序展开。

到2023年底，全县5G基础设施建设初具规模，基础网络支撑能力显著提升，工业互联网标识解析应用服务得到推广，打造一批“5G+工业互联网”建设改造和应用示范样板。

到2025年，基本形成具备较强竞争力的工业互联网基础设施和产业体系，加快IPV6、工业无线等网络技术及5G在规模以上工业企业中应用；积极融入工业互联网生态体系，带动30家企业上云上平台。工业互联网新技术、新模式、新业态大规模推广应用，推动两化深度融合迈上新台阶；工业互联网安全保障体系基本建成，安全保障能力明显提升。

二、主要任务

（一）夯实网络基础。

1. 加快企业互联网基础设施建设。加强5G基站规划布局，打造“5G+工业互联网”广域网。加快跨区域5G+工业专用网络建设，打造“5G+工业互联网”园区/企业/车间专网。鼓励企业更新老旧互联网通信设备，满足工业互联网建设的基本条件。根据工业企业网络需求，加快推动5G网络建设和IPV6部署，提升工业互联网基础支撑能力。选择具备条件的工业企业，开展“5G+工业互联网”内网建设、改造，推动电信企业结合5G独立组网和推广应用，提供工业互联网设计、建设和管理运维服务，探索可持续发展的商业模式。（县委网信办牵头，县经贸局、电信洋县分公司、移动洋县分公司、联通洋县分公司配合）

2. 落实网络提速降费。全面落实中省市关于光纤网络向高速率、大容量、低资费升级的要求，加快互联网技术的升级改造，提升网络传输和交换能力，不断提升网络速率，有效降低网络资费水平。（电信洋县分公司、移动洋县分公司、联通洋县分公司负责）

3. 推进标识解析体系建设。按照省市要求，完成我县工业互联网标识解析服务体系建设任务。逐步推动标识解析系统与工业企业信息化系统的集成，实现供应链系统和企业生产系统间精准对接，促进信息资源集成共享。（县经贸局牵头，县发改局、县网委信办、电信洋县分公司、移动洋县分公司、联通洋县分公司配合）

（二）打造平台体系。

1. 加强工业互联网平台建设。突出我县优势和特色，积极推进洋县工业互联网平台建设，整合上下游产业链相关资源，力争2022年建成以数据为核心、资源高效配置、创新活跃的互联网平台，积极支持中小企业公共服务平台改造升级，为企业提供知识产权、企业征信、检验检测、质量品牌等方面服务。（县委网信办牵头，县经贸局、相关镇办、电信洋县分公司、移动洋县分公司、联通洋县分公司配合）

2. 积极支持企业上云。根据企业信息化基础和个性化需求，鼓励引导有条件企业使用工业互联网平台，大力推广供需对接、软件租赁、能力开放、众包众创、云制造等创新型应用，降低企业信息化成本，提升工业化资源配置效率，推进互联网与制造业融合发展。到2025年，推动至少30家企业“上平台用平台”。围绕企业生产管理关键环节，运用工业互联网新技术新模式实施数字化、网络化、智能化升级。（县经贸局牵头，县委网信办、电信洋县分公司、移动洋县分公司、联通洋县分公司、相关镇办、工业园区管委会配合）

3. 提升平台运营能力。开展面向不同行业的应用创新，为用户提供设备管理、能源管理、生产管理、协同设计制造等各类应用，提升服务能力。不断探索商业模式创新，通过资源出租、服务租赁、产融合作等手段，不断拓展平台盈利空间，实现长期可持续运营。（县委网信办牵头，县经贸局、电信洋县分公司、移动洋县分公司、联通洋县分公司、工业园区管委会配合）

（三）抓好示范引领。

1. 推进工业企业平台应用试点示范。重点支持装备制造、能源产业、绿色食药、现代材料等支柱行业，开展基于工业互联网平台的网络化协同制造、个性化定制、服务化延伸等试点示范，培育一批产业新模式。支持秦洋酒业、国恒机械、盛信电子、尧柏水泥、海创环保科技等骨干企业建设企业级工业云平台，围绕协同研发设计、供应链管理、设备精准运维、设备能效管理、生产工艺优化、能耗管理优化、制造能力交易、产品质量追溯、产品远程服务等方面开展工业互联网平台试点示范，打造一批标杆示范企业。鼓励企业利用工业互联网平台的成熟技术和工业APP等相关应用进行企业信息化、数字化、智能化改造。（县经贸局牵头，县委网信办、电信洋县分公司、移动洋县分公司、联通洋县分公司、相关镇办、工业园区管委会配合）

2. 推进工业互联网聚集区和示范区创建。在工业园区、产业集群等区域加快信息基础设施建设和改造升级，提升制造资源共享和产业协同水平，促进整体数字化网络化升级，创建产业示范基地。（县委网信办、县经贸局牵头，县发改局、相关镇办、工业园区管委会配合）

（四）推动创新发展。

1. 促进企业智能化改造。促进工业互联网平台在企业智能化改造过程中的应用，推动工业互联网平台与智能制造关键技术装备、工业软件、工业云平台、信息安全系统等在工厂的集成应用。加快工业互联网平台在中小企业的普及应用，鼓励智能制造系统集成商、装备制造商、工业软件开发商在企业智能化改造过程中开发和应用工业互联网平台，为企业信息化应用与发展提供有力支撑。到2025年，力争工业互联网平台应用于5家以上智能制造示范企业。（县经贸局牵头，县发改局、县委网信办、相关镇办、工业园区管委会配合）

2. 培育工业APP。制定工业APP建设奖补政策，鼓励有技术实力的信息化企业与高校建立工业APP研发联合体，建设基础共性、行业通用和企业专用三大类工业APP、接口、插件，提升工业信息化实力。推动工业关键技术研发，鼓励企业围绕产品设计、制造、服务等各生产周期，以及工业数据采集、传输、处理、分析等各数据周期提炼专业工业知识，进行软件化、模块化，并封装成可重复使用的标准模块。（县经贸局牵头，县发改局、县委网信办、相关镇办、工业园区管委会配合）

3. 推进产学研深度融合。充分发挥中核陕铀、中航燎原分公司、尧柏水泥、国恒机械等重点骨干制造业企业的产业优势以及在陕在汉高校和科研院所的技术优势。以工业互联网的技术开发促进企业需求与高校科研院所相关学科高度粘合，开发满足企业对工业互联网的差异化需求服务。（县发改局牵头，县教育局、县经贸局配合）

4. 积极构建生态体系。鼓励工业互联网平台接口开放，打通产业数据链。利用工业互联网平台驱动工业全要素、全产业链、全价值链深度互联，推动生产和服务资源优化配置，促进制造体系和服务体系再造，促进工业数字化转型。支持工业互联网平台提供开发环境与工具，广泛汇聚第三方应用开发者，形成集体开发、合作创新的研发机制。依托工业互联网创新发展，打造工业互联网企业内5G网络化改造及推广服务平台，鼓励工业企业建设“5G+工业互联网”融合应用先导区，打造良好产业生态发展环境。（县委网信办、县经贸局牵头，电信洋县分公司、移动洋县分公司、联通洋县分公司配合）

（五）强化安全防护。

1. 完善工业互联网安全保障机制。建立和完善工业互联网安全工作机制，定期开展网络安全检查和风险评估。落实工业企业信息安全主体责任及安全防护要求，提升信息安全防护能力。工业企业要加强工业生产、主机、智能终端等设备安全接入和防护，强化安全保障。工业互联网平台商、服务商要强化自主可控的技术和工业信息安全管理，对“上云上平台”涉及的网络、数据、应用、设备、控制等安全开展全面评估，保障企业“上云上平台”安全。（县委网信办牵头，县经贸局、县公安局、相关镇办、工业园区管委会配合）

2. 提高服务机构能力。工业互联网相关服务企业要加强工业互联网平台安全、工业控制系统安全、工业大数据安全等关键技术攻关，重点研发攻击保护、预警监测等安全防护设备和技术，不断提升设备、网络、控制、应用和数据的安全保障能力。充分发挥第三方安全服务机构在风险预警、运行维护、诊断评估、标准认证等方面的服务作用，为企业提供全方位的安全保障支撑。（县经贸局牵头，县委网信办、县发改局、相关镇办、工业园区管委会配合）

三、保障措施

（一）加强组织领导。由县经贸局会同县级相关部门建立工业互联网推进机制，按照各自工作职责分工，协调任务安排，抓好工作落实，强化各方联动，形成推进合力，确保各项任务有序推进。（县经贸局、县委网信办牵头，县发改局、县财政局、相关镇办、各园区配合）

（二）加强政策支持。全面落实各级扶持工业互联网发展的政策，鼓励社会资本通过市场化运作，建设企业级、行业级工业互联网平台。鼓励金融机构与工业互联网相关企业精准对接，优化提升金融服务质效。支持保险公司根据工业互联网需求创新产品和服务。支持工业互联网产品和服务创新的规模化应用。按照企业承担一点、平台优惠一点、财政补贴一点的方式给予资金补助，每家企业每年补贴金额的上限根据所提供服务的工业互联网平台对洋县经济贡献的大小来确定。（县财政局牵头，县发改局、县经贸局、县金融办、县税务局、人行洋县支行配合）

（三）加强人才培养。加大对国内外工业互联网人才及创新型团队的引进和培养力度，不断壮大我县工业互联网人才队伍。充分发挥高校、企业、科研院所等各方作用，开辟急需紧缺人才培养“绿色通道”，大力培育工业互联网技术人才和应用创新型人才。强化专家咨询服务，建立人才数据库和专家库，搭建专家与企业之间的交流平台。（县人社局牵头，县教育局、发改局、经贸局配合）

（四）营造发展氛围。积极开展工业互联网创新发展的宣传和普及工作，利用线上线下等多种形式开展工业互联网发展政策解读与宣传，增强全社会对工业互联网的认知度与参与度。加强对接和交流，组织工业互联网优势企业参加各类专业展会。发挥专家智库、协会、联盟等作用，开展工业互联网人才培训、咨询、成果对接、创业创新等服务，加强工业互联网优秀方案和典型案例的研究和示范推广，多途径营造工业互联网发展氛围。（县经贸局牵头，县发改局、相关镇办、工业园区管委会配合）
