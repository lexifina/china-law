# 留坝县人民政府办公室关于切实做好近期防灾减灾救灾工作的紧急通知

各镇人民政府，紫柏街道办事处，县政府有关工作部门，驻留有关单位：

当前正值主汛期，加之我县近期先后遭受多轮降雨天气过程，山洪、滑坡、塌方、泥石流等灾害易发多发，防汛形势严峻。为切实做好近期防灾减灾救灾工作，根据省、市《关于切实做好近期防灾减灾救灾工作的紧急通知》和主要领导批示要求，现就有关事项紧急通知如下：

一、提高思想认识，切实加强组织领导。各镇（街道办）、有关部门、单位要充分认清当前防汛工作的严峻形势，坚持以人民为中心的发展理念，始终把保障人民群众生命财产安全放在首位，树立“防大汛、抢大险、救大灾”的思想，务必严格按照省市的统一部署，全面落实各方面责任和各项措施。要坚决杜绝麻痹大意和侥幸心理，进一步强化和落实救灾工作责任制，层层压实责任，层层传导压力，层层细化措施，强化部门协同配合，形成有效工作合力，科学有序应对自然灾害，确保各项救灾工作有序有效进行。

二、突出以防为主，扎实开展隐患排查。各镇（街道办）、有关部门、单位要坚持“以防为主、防抗救相结合”的原则，针对汛期可能多发的暴雨、山洪等灾害，在本辖区、本行业范围内组织开展风险隐患排查，对排查中发现的突出问题、薄弱环节和安全隐患，要提出有针对性的整治措施，明确工作责任和时间进度，加强跟踪督办，确保隐患和问题及时整改到位，严防发生各类次生灾害。要以水电站、尾矿坝、弃渣场等防洪重点区域和山洪易发区、地质灾害隐患点为重点，突出中小学校、幼儿园、卫生院、敬老院、在建工程工地办公区、避灾场所、临建设施等人员密集场所和重要区域，加强巡查力量，加密巡查次数，发现险情要立即报告、迅速处置，坚决把险情消灭在萌芽状态。

三、强化监测预警，做好防灾救灾准备。各镇（街道办）、有关部门、单位要关注灾害性天气过程的动态，做好部门间的沟通、会商，科学分析研判，严防强降雨可能引发的暴洪、泥石流、山体滑坡及其他次生灾害。特别是气象、水利和应急管理、自然资源等部门要加强监测预警，及时发布强降雨天气、重大雨情、地质灾害和道路状况预警信息，对于突发重大自然灾害，要提高预警预报信息发布的时效性和准确性，加大预警预报信息发布频率，通过传统手段和现代手段相结合，多途径、多平台发布灾害预警信息，切实做到发送到户、预警到人。

四、开展宣传教育，增强抵御灾害能力。各镇（街道办）、有关部门、单位要健全完善防灾减灾宣传教育活动长效机制，不断丰富防灾减灾宣传教育内容，充分利用广播、电视、简报、标语等传统媒体和互联网、微博、微信等新兴媒体，持续深入开展防灾减灾宣传教育工作，特别要加大山洪易发区、地质灾害隐患点和人口密集区域的宣传力度，向社会公众尤其是中小学生、社区居民、务工人员等群众广泛普及灾害风险、自救互救、避险逃生等知识技能，切实提升全民防灾减灾意识。要密切关注网络舆情动态，切实做好灾情信息发布，正确引导社会舆论，及时回应社会关切。

五、加强应急值守，高效处置突发事件。各镇（街道办）、有关部门、单位要加强应急值守，严格实行24小时在岗值班和领导干部在岗带班制度，特别要规范安排好双休日和节假日值班带班工作，及时处置各种突发重大险情灾情并第一时间上报，不得迟报、漏报、瞒报。要密切关注灾情发展趋势，视情以及时启动各类救灾应急预案，及时组织抢险救援。同时，要提前做好转移群众安置场所的生活必需品等应急救助的各项准备工作。对存在灾害隐患和居住危旧房屋的群众，要在统一组织领导下提前转移并加以妥善安置。重点对五保户、低保户、建档立卡贫困户等困难群体要逐户落实防灾避灾措施，确保安全度汛。

留坝县人民政府办公室
