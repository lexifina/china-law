# 略阳县人民政府办公室关于撤销五龙洞镇九股树村等13个非洲猪瘟防控临时检查站的通知

各镇人民政府、街道办事处，县政府有关工作部门及直属机构,驻略有关单位：

经县政府研究决定,自2019年3月6日起,撤销县域内五龙洞镇九股树村等13个非洲猪瘟防控临时检查站,现将有关事项通知如下：

一、撤销县域内13个非洲猪瘟防控临时检查站

1.略阳县五龙洞镇九股树村非洲猪瘟防控临时检查站;

2.略阳县白水江镇甘溪沟村非洲猪瘟防控临时检查站;

3.略阳县白水江镇小河村非洲猪瘟防控临时检查站;

4.略阳县白水江镇铁佛寺村非洲猪瘟防控临时检查站;

5.略阳县郭镇木瓜院村非洲猪瘟防控临时检查站;

6.略阳县郭镇杨家岭村非洲猪瘟防控临时检查站;

7.略阳县郭镇干河坝村非洲猪瘟防控临时检查站;

8.略阳县乐素河镇大柒垭村非洲猪瘟防控临时检查站;

9.略阳县乐素河镇瓦房村非洲猪瘟防控临时检查站;

10.略阳县西淮坝镇大沟村非洲猪瘟防控临时检查站;

11.略阳县西淮坝镇梁家河村非洲猪瘟防控临时检查站;

12.略阳县十天高速略阳非洲猪瘟防控临时检查站;

13.略阳县十天高速五郎坪非洲猪瘟防控临时检查站。

二、具体要求

1.从3月6日起，保留略阳县十天高速陕甘界白水江非洲猪瘟防控临时检查站和略阳县309省道郭镇非洲猪瘟防控临时检查站。以上两个检查站原有值班人员不减，责任不变，力度不变，补助不变。

2.县域内撤销的非洲猪瘟防控临时检查站所形成的资产及工作资料由当地镇办统一管理，如需紧急恢复防控检查站，所在镇办立即做好防控准备,坚决杜绝将相应的资产私分挪用、变卖私吞，必须做到妥善保管，以备应急使用。

3.县域内撤销的非洲猪瘟防控临时检查站值班人员补助发放至检查站撤销之日，于3月15日以前兑现到位，发放的衣物自行使用、自行保管。

4.各镇办对日常的非洲猪瘟防控监管工作不能松懈，实行属地管理制，镇村要加强动态监管，建立台账，同时每周将非洲猪瘟防控情况书面报县非防办，如遇突发事件，要立即上报相关情况。镇级畜牧兽医站要发挥好辖区内防控业务指导作用。

5.县非防办和县畜牧兽医技术推广中心定期做好巡查、检查、督查，灵通信息，搞好业务培训指导，及时传达上级防控工作精神要求。

6.各镇办要提高政治站位，统一思想，严格按照防控工作规定和要求执行，不按通知要求执行办理，县纪委将启动追责、问责机制。

略阳县人民政府办公室
