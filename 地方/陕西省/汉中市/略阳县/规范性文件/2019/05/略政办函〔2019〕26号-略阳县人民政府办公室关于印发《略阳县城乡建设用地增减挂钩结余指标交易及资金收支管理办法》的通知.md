# 略阳县人民政府办公室关于印发《略阳县城乡建设用地增减挂钩结余指标交易及资金收支管理办法》的通知

各镇人民政府、各街道办事处，县政府各工作部门及直属单位,各有关企事业单位：

《略阳县城乡建设用地增减挂钩结余指标交易及资金收支管理办法》已经县政府同意，现印发给你们，请认真遵照执行。

略阳县人民政府办公室

2019年5月23日

略阳县城乡建设用地增减挂钩结余指标交易及资金收支管理办法

为加强城乡建设用地增减挂钩结余指标流转资金管理，确保项目安全、规范实施，根据城乡建设用地增减挂钩节余指标有关政策规定，结合我县实际，特制定本办法。

一、加强结余指标交易管理

（一）充分把握可交易结余指标的稀缺性。按照城乡建设用地增减挂钩的相关政策和法规，利用城乡建设用地增减挂钩节余指标进行交易，是有效解决乡村振兴战略“钱从哪里来”问题的重要途径之一。全县各职能部门、镇（办）和村组要在组织推进城乡建设用地增减挂钩相关工作同时，统筹规划、分步实施，确保运用好城乡建设用地增减挂钩这一稀缺资源，充分发挥城乡建设用地增减挂钩节余指标的最大综合效益。

（二）合理选择流转交易方式。相关单位和职能部门在实施城乡建设用地增减挂钩节余指标流转的过程中要充分开展市场交易情况调查，合理选择市内跨县区、省内跨市以及跨省域等调剂流转交易方式，以平台挂网和直接谈判等途径，寻求效益合理、价格相对较高的交易方。

（三）合理控制交易节奏。县国土局、相关镇（办）要按照分配下达给略阳县的城乡建设用地增减挂钩计划，合理安排项目实施进度。对经过验收合格取得可交易的城乡建设用地增减挂钩结余指标，要把握好供需变化趋势和交易价格走势，合理安排交易时间，控制交易节奏。

（四）确定预留交易数量。项目实施后获得的可交易增减节余指标，应按预计指标交易价格和项目实施主体每年需支付的工程款项，确定每年需预留的可交易节余指标。县增减办负责将进行组卷报批，安排节余指标进行流转交易，分年度支付项目实施主体工程款项。剩余结余指标由县上统筹安排使用。

二、加强结余指标交易资金专户管理

（一）设立资金专户。县城乡建设用地增减办设立资金专户，作为全县城乡建设用地增减挂钩结余指标流转收益的收支账户，并加强账户资金管理。

（二）节余指标交易收入到款后的账户资金管理。县财政局要根据城乡建设用地增减挂钩项目建设的实际需要，按照预算管理有关要求，及时筹集、划拨资金至专户，资金要按时拨付至项目实施主体，确保项目实施主体按时足额拨付项目运营过程中产生的运营成本。

（三）资金专户日常余额控制。城乡建设用地增减挂钩结余指标交易资金账户实行动态管理。

三、加强节余指标交易收益管理

（一）严格控制交易收益资金用途。按照省市有关政策的规定和要求，对于城乡建设用地增减挂钩节余指标流转获得的收益，要通过支出预算重点用于全县巩固扶贫成果和支持实施乡村振兴战略等。

（二）严格执行支出审批程序。县城乡建设用地增减资金专户支出要履行严格的审批手续，由相关用款单位提供申请资料，报县政府审批。

（三）建立健全资金管理档案制度。各相关部门应建立健全城乡建设用地增减挂钩项目资金管理的档案制度，完善会计资料，准确记录项目进展、资金使用、交易收益的全过程，提高资金管理规范化水平和资金使用效益。
