# 略阳县人民政府办公室关于印发《略阳县精准扶贫贷款风险补偿金使用管理实施细则》的通知

各镇人民政府、街道办事处，县政府有关部门，驻略有关单位：

《略阳县精准扶贫贷款风险补偿金使用管理实施细则》已经县政府同意，现印发给你们，请遵照执行。

略阳县人民政府办公室

2019年6月20日

略阳县精准扶贫贷款风险补偿金使用管理实施细则

为进一步规范管理使用我县精准扶贫贷款风险补偿金，根据《略阳县精准扶贫贷款风险补偿金管理办法》，制定本实施细则。

一、风险补偿金的设立与管理

县扶贫办、财政局在经办金融机构分别开设扶贫小额信贷风险补偿金专户，依据经办金融机构扶贫小额信贷投放情况，按照1:10的比例存入相应风险补偿金，设立专户专账，动态管理，用于精准扶贫贷款风险代偿。

精准扶贫贷款风险补偿金的代偿及补充须经略阳县扶贫小额信贷风险防控领导小组会议审定。县扶贫办负责风险补偿金的日常管理，建立风险补偿金代偿台账、受理风险代偿申请等；县财政局负责风险补偿金的筹措、拨付和监管工作。

二、风险补偿金的代偿

（一）代偿条件。以下三类逾期贷款，可动用风险补偿金进行代偿，风险补偿金承担70%风险损失、金融机构承担30%风险损失，风险补偿金代偿后金融机构不得再作为逾期贷款挂账。

1.法院裁判执行后仍不能收回的部分。扶贫小额信贷逾期超过90天以上，经办金融机构不少于2次有效催收，对无正当理由拒不偿还贷款的，经办金融机构依法向人民法院提起诉讼，经法院裁判并强制执行后仍不能回收的部分，可申报风险补偿金代偿。

2.保险理赔后仍不能回收的部分。金融机构是精准扶贫贷款保险第一受益人。借款人出现《略阳县精准扶贫贷款保险办法》中第三条所载明情形，人身及财产受到损失，经保险公司核实赔付后仍不能回收的部分，可申报风险补偿金代偿。

3.因特殊原因借款人丧失还款能力。借款人不符合依法起诉及保险理赔条件，但确因意外事故、重大疾病、自然灾害等造成死亡绝户、丧失劳动能力等情况的，可申报风险补偿金代偿。

（二）代偿程序。风险补偿金代偿原则上每季度审定一次，金融机构要加强与镇办的对接，强化贷后管理，准确掌握贷款户真实情况，对拟使用风险补偿金代偿的及时收集资料并提交县扶贫办复核，确保精准高效使用风险补偿金。

1.申报。借款人出现符合使用风险补偿金代偿的情形时，金融机构要第一时间搜集相关印证资料，以正式文件向县扶贫办申报。印证资料包括：①借款人经法院判决或失踪、死亡的，要有法院或公安机关出具的相关法律文书；②经保险公司理赔的，要有保险赔付相关资料；③借款人重病、意外伤残等情况的，要有县级以上医院出具的相关证明；④借款人家庭遭受自然灾害等情况的，要有县应急管理或民政部门出具的相关证明；⑤以上所有情形借款人所在的村（社区）都要出具相关的情况说明。

2.复核。县扶贫办收到金融机构报来的申请后，会同相关镇办逐户核实，并根据复核情况提出代偿意见。

3.审定。召开县扶贫小额信贷风险防控领导小组会议，提请会议审定复核结果，特殊情况书面征求领导小组正副组长及成员意见，审定同意后划拨风险补偿金进行代偿。

三、风险补偿金代偿后的追索

使用风险补偿金代偿贷款本息后，金融机构要继续做好追索工作，每月至少上门催收1次并送达书面催款通知单，直至贷款全部清偿。追回的个户贷款本息，先偿还银行分担的风险损失，剩余部分偿还风险补偿金。金融机构要按季度向县扶贫办报告追索情况。
