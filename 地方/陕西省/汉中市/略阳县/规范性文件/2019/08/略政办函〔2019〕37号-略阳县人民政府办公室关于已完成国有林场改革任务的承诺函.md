# 略阳县人民政府办公室关于已完成国有林场改革任务的承诺函

市发改委、市林业局：

根据《国家发展改革委办公厅 国家林草局办公室关于部署国有林场改革验收工作的通知》（发改办体改〔2019〕794号）要求，按照省、市印发的《国有林场改革方案》和我县印发《国有林场改革方案》，我县承诺已经全部完成国有林场改革各项任务。

按照《汉中市国有林场改革验收办法》（汉林场改办发〔2018〕5号），县级自验得分为60分，扣分项为0。对2018年省级验收中发现“国有林场道路未全部按属性纳入规划；未按规定提供国有林场管理资产核定资料；改革工作面貌展示资料不齐；县财政安排国有林场改革补助资金印证资料不到位；基础设施建设资金不到位”的问题，已于2018年11月全部整改到位。从省级验收结果看，森林面积较改革前增加了0.97万亩，森林蓄积量较改革前增加了11.3万立方米。

特此承诺。

略阳县人民政府办公室

2019年8月8日
