# 略阳县人民政府办公室关于撤销黑河镇黑河坝等11个动物疫病防控消毒站和2个省际间非洲猪瘟防控临时检查站的通知

各镇人民政府、街道办事处，县政府有关工作部门及直属机构,驻略有关单位：

经县政府研究，决定自2019年9月10日起,撤销县域内黑河镇黑河坝等11个动物疫病防控消毒站和2个省际间非洲猪瘟防控临时检查站。现将有关事项通知如下：

一、撤销

1.略阳县黑河镇黑河坝动物疫病防控消毒站;

2.略阳县观音寺镇毛垭子动物疫病防控消毒站；

3.略阳县白水江镇甘溪沟动物疫病防控消毒站;

4.略阳县白水江镇小河动物疫病防控消毒站;

5.略阳县接官亭镇腰庄动物疫病防控消毒站;

6.略阳县硖口驿镇王家营动物疫病防控消毒站;

7.略阳县郭镇木瓜院动物疫病防控消毒站;

8.略阳县白雀寺镇中坝子动物疫病防控消毒站;

9.略阳县白雀寺镇木匣沟（乐高路）动物疫病防控消毒站;

10.十天高速略阳出口动物疫病防控消毒站;

11.十天高速五郎坪出口动物疫病防控消毒站。

12.十天高速陕甘界白水江非洲猪瘟防控临时检查站；

13.略阳县309省道郭镇非洲猪瘟防控临时检查站。

二、具体要求

1.从9月10日起，撤销的2个省际间非洲猪瘟防控临时检查站原有值班人员回原单位正常上班，如需紧急恢复防控检查站，县政府将另行发文通知。

2.县域内撤销的动物疫病防控消毒站配备的设备物资和所形成的资产及工作资料，由所在辖区的镇人民政府、街道办事处统一管理，如需紧急恢复防控消毒站，所在镇办立即做好防控准备,坚决杜绝将相应的资产私分挪用、变卖私吞，必须做到妥善保管，以备应急使用；撤销的2个省际间非洲猪瘟防控临时检查站配备的设备物资和所形成的资产及工作资料由县畜牧兽医总站统一管理使用。

3.撤销的动物疫病防控消毒站和省际间非洲猪瘟防控临时检查站值班人员补助发放至检查站撤销之日，设站镇办于9月15日以前将值班考勤表报县畜牧兽医总站。

4.各镇办对日常的动物疫病防控监管工作实行属地管理，务必高度重视，要克服麻痹大意思想，坚持不懈做好防控工作。镇村要加强动态监管，建立台账，做好宣传，坚持正确的舆论导向，如遇突发事件，要立即上报县农业农村局。镇级畜牧兽医站要发挥好辖区内防控业务指导作用。

5.县农业农村局要定期做好防控工作巡查、检查、督查，灵通信息，搞好业务培训指导，及时传达上级防控工作精神要求。对突发疫情，要第一时间开展调查诊断，指导相关镇办果断采取措施，迅速处置，严防疫情扩大蔓延。

6.各镇办要提高政治站位，统一思想，严格按照防控工作规定和要求执行，不按通知要求执行办理，县纪（监）委将启动追责、问责机制。

略阳县人民政府办公室
