# 略阳县人民政府办公室关于调整畜禽养殖禁养区划定范围的通知

各镇人民政府、街道办事处，县政府有关工作部门及直属单位：

为规范畜禽规模养殖场（小区）建设，治理和防范畜禽养殖污染，保护生态环境，促进畜禽养殖业可持续健康发展，根据《中华人民共和国环境保护法》《中华人民共和国畜牧法》《动物防疫条件审查办法》等相关规定，经县政府研究，决定调整我县畜禽养殖禁养区划定范围。现将调整后的略阳县畜禽养殖禁养区划定范围通知如下：

（一）饮用水源保护区一级保护区范围内，主要是指略阳县城市饮用水水源地（金池院河）瓦场坝的低坝取水口为中心下游100米处的观音庙至上游1000米处的蒲家梁及河岸两侧分别外延500米的水域陆域；集镇、农村集中人畜水源点500米内。

（二）风景名胜区范围内，主要指灵岩寺、五龙洞国家级森林公园等划定的区域。

（三）自然保护区的核心区和缓冲区，主要指陕西省宝峰山自然保护区、陕西略阳珍稀水生动物国家级自然保护区核心区和缓冲区范围内。

（四）城镇建设总体规划区，城镇居民区、文化教育科研等人口集中区域外延500米范围内。

（五）宝成铁路略阳段、十天高速公路略阳段、345国道略阳段等交通主干线两侧500米范围内。

（六）嘉陵江略阳段、黑河、白河等干流两侧300米范围内。

（七）全县境内海拔1500米以上秦岭重点保护区域。

（八）已划定为基本农田和退耕还林地块区域。

（九）法律、法规、规章规定的其他禁养区域。

在禁养区内禁止建设畜禽规模养殖场、养殖小区。禁养区内原有的规模畜禽养殖场、养殖小区，由各镇办、各相关部门根据实际情况依法关停或责令搬迁。
