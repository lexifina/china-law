# 略阳县人民政府办公室关于稳定生猪生产保障市场供应的通知

各镇人民政府、街道办事处，县政府有关工作部门及直属机构：

为认真贯彻《汉中市人民政府办公室关于稳定生猪生产保障市场供应的通知》（汉政办发密电〔2019〕2号）精神，进一步稳定全县生猪生产，保障猪肉市场供应，经县政府同意，现就有关事项通知如下：

一、严格落实“菜篮子”政府负责制

各镇办对本地稳定生猪生产工作负总责，主要负责人是第一责任人，以确保猪肉供应为目标，统筹做好生猪生产、疫病防控和市场保供各项工作，千方百计遏制和扭转生猪产能下滑势头。从2019年起，实行生猪生产红线制度，各镇办生猪出栏量不低于全县生猪生产基本保障任务（见附表），将最低生猪出栏量纳入镇办年度目标责任制考核，确保完成年度生猪出栏任务。积极引导养殖场户扩大牛羊和以略阳乌鸡为主的家禽生产，保障肉类市场供应总体稳定。全面开展“大清洗、大消毒”专项行动，指导养猪场（户）科学补栏，防止因“一哄而上”补栏增加疫病传播风险。

二、大力支持生猪产业转型升级

加快转变畜牧业发展方式，大力发展家庭适度规模养殖，积极引导标准化规模养殖，科学指导现有规模养猪场户加快标准化改造升级，实现畜牧业“保供给”和农民“增收入”的有机结合。2019年到2022年，统筹整合涉农财政资金向生猪养殖项目倾斜，支持优良品种繁育、适度规模养殖、粪污综合治理和新建养殖设施，鼓励村集体经济组织和经营状况好、带动能力强的农业新型经营主体在扩大规模、改善条件、提升效益的同时，通过“公司（合作社）+农户”等组织形式，采取统一发放种苗、技术指导、产品销售等方式合作，带动农户“抱团”发展生猪养殖。鼓励生猪养殖企业开展无公害、绿色、有机农产品“三品”认证，创建地方特色品牌，推进生猪产业高质量发展。

1.扶持优良品种繁育。2019年对存栏能繁母猪30头以上的良种养殖场户，每头能繁母猪一次性扶持1000元，每头种公猪一次性扶持3000元，2020年以后按增量进行补助。

2.支持适度规模养殖。对当年出栏育肥猪50头以上的生猪养殖场户，按县镇畜牧兽医机构检疫数量为补助依据，每出栏1头育肥猪补助50元。

3.加大粪污综合治理。年出栏50头以上的生猪养殖场户必须建立粪污资源化利用处理设施，凡符合防渗、防漏、防溢技术标准，且建成粪污设施10立方米以上（含10立方米），每立方米一次性补助200元。

4.鼓励新建养殖设施。对新建并配套建成粪污资源化利用处理设施，且年出栏50头以上的生猪养殖圈舍给予补助,每平方米补助200元。

5.落实农机购置补贴。认真落实国家农机具购置补贴政策，对养殖户和经营主体购买纳入补贴目录范围内的饲料加工等养殖相关机具，依照有关规定优先办理，应补尽补。

6.普及生猪养殖保险。加大养殖保险政策宣传力度，认真落实保险补贴政策，尽可能简化投保和理赔程序，积极探索推行生猪目标价格保险，扩大种公猪、能繁母猪、育肥猪和仔猪保险全覆盖，大力引导养殖场户购买生猪养殖保险，做到应保尽保，有效降低养殖风险。

7.引导开展“三品”认证。鼓励生猪养殖场户开展无公害、绿色、有机农产品认证，对当年获得无公害、绿色、有机农产品认证的生猪养殖场户给予50%的认证补助。

三、强化生猪屠宰流通监管

1.加强生猪屠宰监管。严格执行生猪屠宰环节非洲猪瘟自检和驻场官方兽医制度，对未取得“三证”（动物防疫条件合格证、生猪定点屠宰许可证、排污许可证）和不符合检疫检测要求的屠宰场点，坚决予以取缔。强化生猪定点屠宰场监管，严把生猪进场关、同步检疫关和产品出场关，确保出场肉品质量安全。

2.畅通生猪流通渠道。全面落实非洲猪瘟防控期间生猪及其产品差异化调运政策，畅通仔猪、种猪跨区域调运渠道，从现在起，对整车合法运输仔猪及冷鲜猪肉的车辆，恢复执行鲜活农产品运输“绿色通道”政策；对整车合法运输种猪及冷冻猪肉的车辆，在2020年6月30日前免收车辆通行费。加大生猪及其产品运输环节查验力度，强化生猪运输车辆标准化改造、备案、清洗、消毒监管，坚决消除疫病传播风险。

3.严格上市肉品查验。加大上市肉品“两章两证”查验力度，杜绝私屠滥宰和不合格肉品上市流通，教育引导肉品经营企业和从业人员，尤其是城乡集贸市场肉品商贩从合法生猪屠宰企业进购的合格肉品进行销售，确保上市肉品安全，保障消费者权益。

四、加强生猪疫病防控

各镇办和有关部门要充分认识当前非洲猪瘟疫情严峻形势，进一步压实工作责任，全面落实养殖场户动物防疫主体责任，严格按照市县的相关安排部署，切实消除侥幸麻痹心理和松劲懈怠思想，进一步加强非洲猪瘟等重大动物疫病防控工作，确保监测、消毒、移动控制等各项防控措施落实到位，持续做好禁止泔水喂猪宣传教育和排查，杜绝泔水喂猪现象发生，降低疫情发生风险。继续坚持开展非洲猪瘟疫情排查，加大巡查频次，对重点区域、关键环节和不明原因死亡生猪，按规定开展采样送样监测，加强流行病学调查工作，做好疫情追溯追踪，及时发现和消除隐患。加强科学养殖和疫病防控技术培训与指导服务工作，提升科学养殖水平和疫病防控能力，确保生猪产业健康发展。

五、落实政策保障措施

1.强化金融支持。各镇办、有关部门要积极宣传贷款贴息政策，金融部门要千方百计为符合条件的生猪养殖企业提供信贷支持，解决养猪企业资金紧张问题。

2.规范养殖管理。县生态环境局牵头，深入开展自查，完善畜禽养殖区域划定方案，及时调整超出法律法规规定范围划定的禁养区和限养区。不得以改善生态环境为由，限制养猪业发展或压减生猪产能，对因污染需要整改的养猪场户，给予合理过渡期和技术指导，避免处置措施简单粗暴、一关了之。

3.保障养殖用地。严格执行自然资源部办公厅《关于保障生猪养殖用地有关问题的通知》（自然资电发〔2019〕39号）要求，积极引导新建或扩建的生猪养殖项目合理选址，鼓励利用荒山、荒沟、荒丘、荒滩和农村集体建设用地发展生猪生产。对依法依规划定的禁养区内关停搬迁的养猪场户，合理安排用地，支持易地重建。生猪产业发展用地属于农用地的，按农用地管理，不需办理农用地转用审批手续。在不占用永久基本农田的前提下，合理安排生猪养殖空间，允许生猪养殖用地使用一般耕地，作为养殖用途不需耕地占补平衡。

六、强化部门协调配合

县农业农村局要牵头抓总，各镇办和有关部门密切配合，确保各项任务落实到位。县发改局要加强市场监测预警、价格补贴发放，支持养猪场户基础设施建设。县财政局要确保对生猪生产资金支持力度。县自然资源局要认真做好用地政策宣传解读工作，指导、协调用地问题，对符合土地规划的养殖场实行备案制管理，明确养殖项目选址意见。县生态环境局要指导规模养猪场户开展环保达标改造。电力、经贸、交通运输、市场监管、人民银行、金融办等部门单位要结合各自工作职责，为稳定生猪生产提供有力保障。

七、本通知自印发之日起执行，《略阳县产业脱贫工作领导小组办公室关于稳定生猪产业发展的指导意见（暂行）》（略产脱办发〔2019〕9号）同时废止，其他有关文件规定与本通知不一致的以本通知为准。
