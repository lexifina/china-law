# 略阳县人民政府办公室关于加快推动高速公路电子不停车收费应用服务的紧急通知

各镇人民政府、街道办事处，县政府各工作部门，驻略有关单位：

为认真贯彻中省市关于取消高速公路省界收费站推动高速公路电子不停车收费应用服务的政策措施，根据《汉中市加快推动高速公路电子不停车收费应用服务实施方案》（汉收费路改〔2019〕1号）和12月5日市政府召开的ETC推广发行推进会议精神，现就加快推动我县高速公路电子不停车收费应用服务有关工作紧急通知如下：

一、明确工作任务

坚持“政府主导、市场引导、社会参与”的原则，充分发挥各部门及镇办的主体作用，调动各方资源，加快推动高速公路电子不停车快捷收费（ETC）应用，使高速公路收费站ETC全覆盖，ETC车道成为主要收费车道，确保到2019年12月30日前，全面完成0.63万辆ETC车载装置安装任务。

二、落实工作责任

各有关部门和单位要按照“优化服务、取消储值、免费安装、优惠缴费、快捷通行”的要求，采取有力措施，加快安装ETC车载装置，大力推广ETC应用与服务，确保按时完成我县安装任务。具体职责如下：

（一）县政府办（机关事务管理局）负责全县机关事业单位公务用车率先安装使用ETC。

（二）县经贸局负责督促县域工矿、服务企业车辆安装使用ETC。

（三）县交通运输局负责ETC安装的沟通协调和工作进展信息收集上报等工作。

（四）县公安局负责在新增机动车注册登记及机动车辆定期检验、驾驶证审验时，引导车辆所有人或使用人主动安装ETC车载装置；落实机动车注册登记信息共享政策，准确提供车辆户籍、分布、数量等情况，为政府决策提供基础。

（五）县运管所负责督促各客货运企业所属车辆安装ETC车载装置。12月底前，出租车、涉及高速客车安装率100%，公路货运车辆等营运车辆安装使用ETC率达80％以上。

（六）各镇办负责做好居民小区、村组政策宣传，督促引导本辖区车辆所有人或使用人安装ETC车载装置。整合驻地涉车涉企管理机构，配合发行银行开展工作，确保12月底前本辖区内车辆安装ETC车载装置率达80％以上。

（七）人行略阳分行负责督促各ETC合作发行银行大力宣传ETC相关政策和通行费优惠制度，支持客户自主选择产品服务，自行注册，自助安装。各ETC合作发行银行要主动与保险、通信运营商等服务网点以及汽车维修厂、停车场、加油站、社区等车辆集中场点联系，就近提供一站式全流程安装服务。为整合资源便于工作，对ETC发行银行实行镇办分片包干制，其中：工商银行包干乐素河镇、白雀寺镇、兴州街道办、五龙洞镇，建设银行包干硖口驿镇、接官亭镇、金家河镇、郭镇、西淮坝镇，农业银行包干黑河镇、两河口镇、仙台坝镇、观音寺镇，邮储银行包干横现河街道办、徐家坪镇、马蹄湾镇、白水江镇。

三、工作要求

（一）加强组织领导。各有关部门单位、镇办要高度重视ETC安装工作，单位主要领导亲自部署，分管领导要具体抓，要严格按照职责分工，精心组织实施，全力支持配合，扎实推进全县ETC推广安装工作。

（二）加强宣传引导。各有关部门、镇办及发行机构要充分利用媒体平台及车辆密集场所，深入开展ETC优惠政策及约束规定宣传，引导公众积极安装、使用ETC车载装置，切实提高人民群众的获得感、幸福感，营造安全、畅通、绿色的高速公路路域环境。

（三）加强督查检查。ETC安装工作实行周报制，各责任单位要指定专人负责信息收集、档案资料管理工作，每周四上午12时前将ETC安装进展报县交通局（联系人：付建菲；电话：[电话略]）。县政府督查室、县交通局将联合开展检查督查，及时通报情况，对履职不力、未按时完成任务的单位和责任人将按有关程序追责问效。

略阳县人民政府办公室
