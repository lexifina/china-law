# 略阳县人民政府办公室关于统筹安排2020年全县重点经贸合作及投资促进活动的通知

县政府各有关工作部门及直属机构，各有关企事业单位：

经县政府同意，现将2020年国内、国外重点经贸合作及投资促进活动安排、县内招商产业工作组自主投资促进活动安排、全国重点经贸展会活动安排印发给你们，请按照要求统筹抓好本年度经贸合作与投资促进活动。

一、要突出招商重点

各部门、各单位要按照国家政策导向，紧紧围绕建设“三个略阳”总体目标，突出产业招商、园区招商、生态招商、精准招商，不断加大招引力度，为县域经济高质量发展增添新业绩。

二、要强化招大引强

围绕国家鼓励发展的重点产业，在农业生物、文化旅游、现代服务业、新材料等领域科学谋划、合理布局，瞄准国际、国内龙头型、总部型先进技术、创业创新、旅游休闲、养老养生等大项目招商引资。

三、务实精心组织

各部门、各单位要充分做好招商引资项目洽谈的前期准备工作，及时制定活动方案，明确责任分工，合理控制招商引资活动规模和经费，确保各类活动组织有序，成效显著。

略阳县人民政府办公室

2020年5月11日
