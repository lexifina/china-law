# 西乡县人民政府关于公布规范性文件清理结果

西政发〔2019〕50号

西乡县人民政府

关于公布规范性文件清理结果的通知

各镇人民政府，城北、城南街道办事处，县政府各工作部门，县直及驻县各单位：

根据《陕西省规范性文件监督管理办法》《汉中市行政机关规范性文件管理办法》和《汉中市人民政府办公室关于进一步加强行政规范性文件合法性审核和监督管理工作的通知》（汉政办发〔2019〕21号）的有关精神，我县主要对以县政府（办公室）名义及相关部门（单位）印发的规范性文件进行了清理，现将清理结果公布如下：

一、宣布《关于重新调整划定火化区和土葬改革区范围的通知》（西政办发〔2014〕85号）等8件规范性文件废止；确认《关于进一步做好矿产资源开发保发展治粗放保安全治隐患保生态治污染工作的通知》（西政办发〔2017〕21号）等43件规范性文件继续有效。宣布《关于公布实施我县城镇基准地价的通知》（西政发〔2016〕51号）等11件规范性文件待修订后重新发布；确认《关于印发《西乡县城市规划区国有零星土地处置办法（暂行）》的通知》（西政办发〔2017〕63号）等12件规范性文件失效。

二、规范性文件有效期一般为五年，试用的规范性文件有效期一般为两年。县政府（办公室）及相关部门（单位）2018年12月31日以前（含12月31日）发布的规范性文件，除程序性规定、技术规范和实施法规、规章的文件以外，如未在此次清理范围内，但已超过有效期的一律废止，确需继续使用的，按规范性文件制定程序重新发布。规范性文件已过有效期、需要重新制定发布和修改的，按制定程序于2019年12月31日前完成，逾期没有重新发布的，自2020年1月1日起废止。

三、废止的规范性文件自本公告发布之日起停止执行。已经失效的规范性文件，不得作为行政管理的依据。

四、各相关部门（单位）要按照中省市县有关规范性文件管理规定，切实做好有关规范性文件废止后的后续监管工作，严格施行继续有效、修改后重新发布的规范性文件，推进依法行政再上新水平。
