# 西乡县人民政府办公室关于印发《西乡县2020年度造林绿化实施方案》的通知

西政办发〔2020〕3号

西乡县人民政府办公室

关于印发《西乡县2020年度造林绿化实施方案》的

通 知

各镇人民政府，城北、城南街道办事处，县政府有关部门，县直及驻县有关单位：

《西乡县2020年度造林绿化实施方案》已经县政府同意，现印发给你们，请认真组织实施。

西乡县人民政府办公室

2020年1月11日

西乡县2020年度造林绿化实施方案

为进一步加大造林绿化工作力度，加快“六个西乡”建设步伐，早日实现生态宜居、美丽西乡目标，切实推进2020年造林绿化工作，结合我县实际，特制定本实施方案。

一、总体要求

（一）指导思想

深入贯彻落实党的十九大、十九届四中全会精神，以习近平新时代中国特色社会主义思想为指导，以“建设生态文明”为统领，以维护生态安全为方向，以发展林业产业巩固脱贫成果为契机，以增绿增质增效为要求，认真贯彻落实省市关于改善生态环境的一系列部署和工作要求，坚持生态优先、绿色宜居发展理念，大力开展全民义务植树活动，全民实施生态绿化工程，在科学造林、强化管护、提质增效、产业富民上实现新突破，为“六个西乡”建设奠定坚实的基础。

（二）基本原则

1.生态优先、协调发展。坚持绿色发展，将改善生态作为城乡绿化的首要目标，充分利用和发挥绿化的多种功能和综合效益，促进生态改善、产业发展、经济增长、农民增收、社会和谐。

2.分区施策、突出重点。围绕生态文明建设、产业建设和全域旅游发展，结合城乡区域自然地理特点和资源优势，以国、县道、旅游干线和城市周边为重点，兼顾美丽乡村、产业园区，统筹规划，宜景则景，合理布局，突出区域特色，全面推进城乡绿化。

3.政府推动、多方参与。坚持以政府主导、部门联动、社会参与、市场化运作方式相结合，以各镇（街道）、部门为主，加大投入，落实责任，健全长效工作机制合力推进。

二、目标任务

2020年重点抓好全民义务植树、林业产业发展、国家储备林建设、重点区域绿化造林工作。全县计划共完成植树造林2.6万亩，义务植树80万株。其中：雷竹经济林11000亩、国家储备林10000亩、封山育林5000亩；建设美丽宜居示范村17个；河道绿化1000亩、村庄社区绿化1000亩、道路绿化500亩、庭院绿化500亩。

三、工作重点

围绕上述目标任务，重点抓好以下六个方面工作。

（一）开展全民义务植树活动。以“3·12”植树节为契机，广泛动员全县机关事业单位、驻军、工商企业以及社会各界人员，积极投身全民义务植树活动。重点组织好“3·12”县级机关单位义务植树活动，带动全县义务植树活动向更广、更深发展。各镇（街道）都要建立一个党政领导义务植树基地，为本地区开展全民义务植树活动树立样板，通过示范带动，迅速掀起造林绿化高潮，确保完成义务植树80万株任务目标。（责任单位：县林业局，配合单位：各镇、街道）

（二）推进林业产业发展建设。以巩固产业脱贫成果为目标，在全县范围大力发展雷竹经济林产业，树立“生态建设产业化”理念，充分发挥造林绿化的经济效益。2020年度计划在全县17个镇（街道）92个村发展雷竹11000亩。以林业产业发展为依托，使群众在造林植绿的同时实现增收，巩固产业脱贫成果。（责任单位：县雷竹办，配合单位：各镇、街道）

（三）国家储备林试点建设。以陕西省国家储备林基地建设试点项目为契机，坚持以生态建设为目标，以改善生态改善民生为任务。充分利用西乡林地资源，选择群众积极性高、自然条件优越、交通便利、相对集中连片且符合国储林区划条件的区域建设储备林基地。大力培育大径级材树种，加快建成一批集约化、基地化、规模化、标准化的国家木材战略储备基地，增加活立木储备，为保障国家木材安全做出积极贡献。切实提高农民收入，助推脱贫攻坚，促进全县经济社会与生态环境协调发展。计划在2020年试点建设开展国家储备林1万亩。（责任单位：县林业局，配合单位：沙河镇、私渡镇）

（四）美丽宜居示范村建设。结合农村人居环境整治、乡村振兴战略实施，在统一规划、逐步推进的基础上，充分利用村旁、宅旁、坑旁、路旁等宜林地资源，大力开展“四旁”植树，坚持“环村有绿带、道路有绿网、街心有绿地、广场有绿荫、庭院有花果”的“五有标准”，以街道绿化、环村林带为重点，提升村庄绿化水平。2020年全县计划完成17个美丽宜居示范村建设任务，各镇（街道）完成1个以上示范村任务。（责任单位：各镇、街道）

（五）重点区域绿化造林建设。以综合创建为抓手，紧紧围绕美丽西乡建设，重点提升沿高速、沿国省县道、沿河流及社区周围、公共场所、内部道路和房前屋后绿化美化。以乔灌为主，乔灌藤相结合，大力发展优良乡土树种，提高常绿树和花卉配置比例，切实改善居民生活环境。2020年全县计划完成河道绿化1000亩、道路绿化500亩、村庄社区绿化1000亩、庭院绿化500亩。（责任单位：县交通局、县水利局、县农业农村局，配合单位：各镇、街道）

（六）开展城区植绿补绿建设。进一步完善街头绿地、社区绿地和城区主次干道绿化等人居环境提升。按照“美化、香化、彩化”的建设标准，对县城各主要街道按街长制分段包干，定期对绿化树木开展补植和管护，提升街道绿化水平。（责任单位：县住建局）

四、工作要求

（一）明确目标任务，突出绿化重点。春季和秋冬季是造林绿化的主要季节，也是完成全年造林绿化任务的关键时期。各镇（街道）、各有关部门要按照年度绿化任务，制定切实可行的工作方案，提前落实造林地块，做好种苗筹备，做到早计划、早安排、早行动，确保造林绿化工作顺利推进。同时要结合农村人居环境整治、美丽西乡建设任务，抓好集镇村庄、移民搬迁点、辖区道路及河流两侧坡面绿化工作。

（二）加强组织领导，强化督促检查。造林绿化是林业建设的核心任务和建设生态文明的重要基础。各镇（街道）要加强领导，周密部署，科学合理细化造林绿化任务，夯实责任，将造林绿化任务分解落实到村、到人。各镇（街道）领导干部要深入造林一线，统筹造林工作，及时解决问题，确保造林进度，造林结束后要向县林业局报送造林任务完成情况。

（三）强化技术保障，确保造林质量。立足区域资源，科学编制作业设计，因地制宜、合理配置密度，大力营造混交林，提高森林生态系统的质量和稳定性。严格检疫检查，所用苗木要严格实行“两证一签”制度，坚决杜绝检验检疫不合格和不宜成活的苗木上山。加强技术服务和培训，大力推广低产低效林改造等实用技术，提升造林绿化质量。

（四）强化管护措施，巩固绿化成果。各镇（街道）、有关部门要深刻认识到管护工作的重要性，按照“三分造，七分管”的思路，严格落实苗木管护工作。林业局要严格执行林木采伐审批制度，严格管控征占用林地审批，加强森林火灾的预防、扑救能力建设，强化森林病虫害的预测、预报和防治工作。各镇（街道）要在认真做好春季造林绿化的同时，对近三年造林绿化地块及时开展补植浇水、松土、除草、割灌等抚育管护工作，促进新造幼苗正常生长，确保栽一片、活一片、绿一片。各镇（街道）要建立健全护林组织，切实加大执法力度，严肃查处乱砍滥伐，侵占林地等不法行为，巩固造林成果。

五、保障措施

（一）严格责任落实。各镇（街道）要把造林绿化作为建设生态文明、改善生态环境的重大举措，主要领导亲自抓，分管领导具体抓，逐级签订责任状。县有关部门要按照职责分工，齐抓共管，形成合力，切实推动造林绿化深入开展。

（二）加大宣传力度。充分调动各有关部门和社会各界参与造林绿化的积极性，营造植树绿化、美化环境的良好社会氛围。利用电视、网络、新闻媒体等，全方位、大力度报道造林工作推进情况，宣传先进，努力营造全社会重视绿化、支持绿化、参与绿化的浓厚氛围。

（三）加大资金投入。采取政府主导、争取上级资金支持、吸引社会投资等多种形式，搞好造林绿化工作。县财政要进一步加大投入力度，列出专项资金，推动造林绿化工作的开展。积极争取国省造林绿化工程项目，用于支持造林绿化重点工程的建设。各相关部门要整合资金，设立绿化专用资金，确保部门绿化任务顺利完成。

（四）强化督查考核。县上将造林绿化纳入年度目标责任考核，各镇（街道）、各部门要结合年度造林绿化任务，制定切实可行的工作方案，强化考评管理，进一步完善工作效能督查督办制度，定期上报造林进度和完成情况，并对年度林业生产责任目标完成情况进行自查。县政府将在各镇（街道）、部门自查的基础上全面检查验收，严格兑现奖惩。
