# 汉中市人民政府办公室关于印发汉中市2014年依法行政工作要点的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

现将《汉中市2014年依法行政工作要点》印发给你们，请结合实际，认真贯彻执行。

汉中市人民政府办公室

2014年6月6日

汉中市2014年依法行政工作要点

为全面推进依法行政，加快法治政府建设，按照《国务院关于加强法治政府建设的意见》及省、市《加强法治政府建设规划（2011—2015年）》（以下简称《规划》）的要求，依据《陕西省2014年依法行政要点》，结合我市实际，提出2014年依法行政工作要点：

一、指导思想

认真贯彻党的十八大和十八届二中、三中全会,省委十二届四次全会及市委四届五次全会精神，按照法治政府建设的新要求，以落实全省政府法制工作会议精神为主线，以推进市县政府依法行政为重点，创新完善依法行政各项制度，全面落实依法行政各项任务，着力解决推进依法行政的突出和难点问题，努力为“三市”建设创造更加良好的法治环境。

二、主要任务

（一）强化依法行政意识

提高运用法治思维的能力。要牢固树立法治理念，提升行政机关工作人员特别是领导干部运用法治思维和法治方式深化改革、推动发展、化解矛盾、维护稳定的能力，在法治轨道上推动各项工作。落实市县政府和部门法制机构列席政府常务会议或局长办公会制度。每年至少听取2次依法行政工作汇报，解决突出问题。市县政府领导在检查工作、调查研究时，应当把依法行政作为重要内容。

坚持领导干部学法与法制培训。市县政府要把依法行政知识纳入各类领导干部培训班教学内容，全年安排3次以上领导集体学法，至少举办1期领导干部依法行政专题培训班。对行政机关主要负责人和法制系统干部进行依法行政专项培训。实行领导干部晋职依法行政情况考察和法律知识测试制度。

加强法制机构和队伍建设。市县政府及其部门要落实法制机构人员编制，提高法律专业人员比例，保障工作经费。加强对法制干部的培养、使用和交流，政府法制机构工作人员要不断提高工作能力，做好依法行政的参谋和助手。

营造良好法治舆论与氛围。落实六五普法规划，采取有效方式方法增强全民法治观念，正面引导舆论。制定政府法制宣传计划，拓展法制宣传渠道，提高宣传实效，进一步提升政府法制工作影响力，形成良好法治氛围。

（二）加快政府职能转变

科学界定政府职责权限。合理划分不同层级政府事权，加强公共服务、市场监管、社会治理、环境保护等职责。推进市县政府组织机构、职能、运行方式法治化，将法律法规赋予的行政权与“三定”方案相结合，依法确定政府部门职责。

深化行政审批制度改革。开展新一轮行政审批事项清理工作，全面清理行政审批项目，依法予以取消、下放或整合，并通过适当方式向社会公布。规范行政审批行为，建立行政审批责任追究制度，推动行政审批行为程序化、法制化、信息化、公开化。加强市、县行政服务中心建设，符合条件的行政审批事项要实行集中办理和“一站式”服务。公开审批事项，优化审批流程，严格依法收费。

加强公共服务。充分发挥政府的主导作用，强化社会治理及创新，切实履行公共服务职责，努力建设服务型政府。加快发展独立公正、规范运行的社会组织，鼓励、引导社会组织依法有序参与社会管理。建立政府向社会组织购买公共服务制度，引入竞争机制，通过合同、委托等方式向社会购买，推进公共服务提供主体和方式的多元化。

（三）坚持依法科学民主决策

完善重大行政决策制度。明确重大决策事项、必经程序和法律责任，重大行政决策提请审议前必须通过法制机构合法性审查。严格行政决策责任追究，对超越法定权限、违反法定程序，出现重大决策失误，造成重大损失的，依法追究行政机关主要负责人和相关责任人责任。

扩大公众参与行政决策。进一步完善重大行政决策听证制度，明确应听证的决策事项范围，建立科学公正的听证代表遴选制度，对听证意见的采纳情况要说明理由并予以公开和反馈，听证结果作为行政决策的重要依据。提高风险评估工作质量，有序引入社会组织和专业机构进行重大决策风险评估工作，未经风险评估的，一律不得作出决策。市、县政府及其部门应普遍建立法律顾问制度，法制机构做好法律顾问的联系和服务，提高专家论证质量，为政府决策提供有力法律保障。

加强规范性文件监督管理。坚持“逢文必审”，市、县政府及其部门的涉权涉法文件未经本级法制机构合法性审查或审查不合格的，不得上会研究或签发。加大规范性文件审查备案力度，做到“有件必备”；完善规范性文件评估制度，及时纠正违法或不当的规范性文件，做到“有错必纠”。总结汉台区、勉县规范性文件“三统一”试点经验，分步有序地在全市推广规范性文件“统一登记、统一编号、统一公布”制度。严格规范性文件有效期制度，及时清理规范性文件。

（四）加强和规范行政执法行为

提升行政执法质量。规范行政执法人员执法行为，落实行政处罚自由裁量权基准制度，通过执法检查、案卷评查、执法评议考核等多种方式，加大监督力度，提高行政执法水平。提高基层，尤其是县、镇行政执法能力，充实食品药品、安全生产、环境保护等重点领域基层执法力量。

严格公正文明执法。增强行政执法部门的程序意识，严格依程序执法。行政执法部门要进一步完善执法依据适用规则，细化执法流程，保障程序公正。推进文明执法，引导行政执法部门更多地运用行政指导、行政奖励等柔性执法方式，减少执法冲突。完善行政执法财政保障体系，不得下达或变相下达罚没指标，不得以任何形式返还或者变相返还行政事业性收费和罚没收入。

加强执法队伍建设。严格执法人员持证上岗和资格管理制度，未取得执法资格的人员不得从事执法工作。对聘用的合同工、临时工，坚决调离行政执法岗位。开展《陕西省行政执法证》换发工作，对资格审核不合格、未参加培训和法律知识考试不及格的人员一律不予发证。试点开展行政执法人员评星定级工作。落实行政执法人员法律培训制度，每人每年培训时间不少于40小时。

（五）健全依法行政监督机制

加强行政机关内部监督。严格落实《陕西省依法行政监督办法》，进一步完善监督程序，提高监督效能。深化行政处罚自由裁量基准制度，加强检查和指导，督促全市各级行政执法部门严格按裁量基准实施处罚。组织好依法行政监督，在全面检查的基础上，对食品药品、安全生产、社会保障、环境保护等重点行业进行有针对性地执法检查。

强化依法行政考核。市县政府要把依法行政纳入年度目标责任考核，建立《汉中市县（区）政府依法行政工作质量评价体系》，制定科学有效的依法行政考核方式和指标，重点推进市县依法行政工作。积极推动宁强县青木川镇、镇巴县杨家河镇依法行政示范镇创建工作。加强相关部门沟通协调，逐步提高考核分值。

完善权力运行问责机制。规范问责主体、问责范围、问责方式和问责程序，使行政问责制度化、常态化。畅通渠道，加强广大人民群众对权力行使的监督。

（六）全面推进政务公开

加大政府信息公开力度。不断拓宽公开的领域和范围，及时、准确、全面、具体地公开政府信息，增强政府公信力。市县政府要组织清理“权力清单”，并向社会公布。加快推进市级部门财政收支预、决算公开制度，建立“三公”经费支出定期通报制度。在市县财政预算执行部门（单位），逐步推行“三公”经费公开。

完善办事公开。所有面向社会服务的政府部门要依法在办公场所公开办事依据、条件、流程、办理机构和人员、收费标准等信息，并将办事结果通过适当方式进行公开。有关行政机关要依法规范和监督医院、学校、公交、公用等公共企事业单位的办事公开，重点公开岗位职责、服务承诺、收费项目和标准、工作规范、办事纪律、监督渠道，为人民群众提供优质、高效、便利的服务。

依法办理依申请公开政府信息。健全依申请公开政府信息相关制度，完善受理、审查、处理、答复等环节的工作程序，对人民群众申请公开政府信息的，在法定时限内予以答复，对不予公开的要说明理由。加强舆情特别是网络舆情的应对和处置，及时回应民声民意。

（七）依法有效化解社会矛盾

发挥行政复议化解矛盾的主渠道作用。进一步完善行政复议受理程序，严格遵守法定程序，加强实地调查，采取公开听证、专家论证等方式加大案件审理透明度，提高办案质量。深化行政复议机制改革，推进行政复议委员会试点工作。进一步加强对仲裁工作的指导，发挥仲裁在解决民商事纠纷中的作用。

加强人民调解和行政调解工作。健全完善人民调解组织网络，实现村委会、居委会人民调解组织全覆盖，推进企事业单位、镇街道办事处、社会团体或其他组织中人民调解组织建设。重点解决消费者权益、劳资关系、医患关系、物业管理等方面的矛盾纠纷，促进当事人平等协商、公平公正解决矛盾纠纷。

三、工作要求

（一）全市行政机关及其部门要把全面推进依法行政、加强法治政府建设摆在更加突出的位置，及时部署工作重点、具体任务和工作措施。市县政府和部门要切实承担责任，对不认真履行依法行政领导职责，发生重大违法行政案件并造成严重社会后果的要予以通报，严格依法追究责任。

（二）加强对推进依法行政工作的督促指导和监督检查。各级行政机关及其部门要完善工作机制，强化工作责任，市县镇三级联动，层层抓落实。抓好依法行政示范工作，对示范县区的先进经验和典型做法要大力宣传，对推进工作不力、存在问题较多的予以通报批评，确保建设法治政府的各项制度落到实处。

（三）县区政府及市级各部门要按照本工作要点，结合工作实际，制定年度依法行政工作重点任务，并于2014年6月15日前报市政府法制办。
