# 汉中市人民政府办公室转发政协汉中市委员会关于全市信访工作的建议案的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

现将政协汉中市委员会《关于全市信访工作的建议案》（汉政协字〔2014〕3号）转发给你们，请高度重视，认真吸纳意见建议，进一步强化工作措施、完善信访机制、规范信访秩序、优化社会环境，为维护全市社会大局和谐稳定作出积极贡献。

汉中市人民政府办公室

2014年7月21日

全市信访工作的建议案政协汉中市委员会

6月12日，市政协召开四届十六次常委会议，专题协商讨论全市信访工作。会前，市政协社会法制委组织部分政协委员，在市政协党组副书记、副主席胡长芳、副主席王青平同志带领下，深入城固县、勉县就信访工作开展情况进行了专题调研，并形成了《全市信访工作调研报告》。会上，市政协常委听取了市政府关于全市信访工作的通报，市政协社会法制委汇报了全市信访工作调研情况，参与调研的5名市政协常委和委员作了大会发言。

会议认为，近年来，市委、市政府高度重视信访工作，措施不断强化，工作强力推进，机制日益完善，秩序有效规范，基础逐步夯实，队伍坚强有力，信访工作成效明显，为全市社会大局和谐稳定作出了积极的贡献。

会议指出，当前信访工作还存在诸如信访形势依然严峻、信访机制有待完善、防控措施尚显乏力、政策法规缺少刚性、政府处置手段弱化、群众法制观念淡薄等薄弱环节和问题，已经影响和制约了全市信访工作进一步推进，成为社会各界和人民群众关注的热点难点问题，必须予以高度重视。对此，提出以下建议：

一、深化思想认识，提升工作水平。各级各部门一定要牢固树立一手抓发展、一手抓稳定的观念，从讲政治的高度、从维护改革发展稳定的高度、从执政为民的高度，充分认识信访工作的必要性和重要性，不断增强做好新形势下信访工作的紧迫感和责任感，切实在思想观念上做到“四个转变”，即：从就信访办信访，向服务发展第一要务、服务大局办信访转变；从简单接访办信，向综合分析提供决策建议转变；从满足于对信访事项的转办交办，向督促检查并促进问题解决转变；从事后被动受理群众来信来访，向事前预测、防范并及时化解矛盾转变，不断探索新思路，采取新办法，化解矛盾，解决问题，努力提高信访工作质量和水平。

二、构建网络格局，畅通信访渠道。一是加强传统信访网络建设。市县区要不断加强对信访工作的重视和支持力度，进一步强化和延伸市、县、镇、村四级规范化、制度化稳定信访网络机构，形成横向到边、纵向到底的信访工作网络格局。按照国家信访局新出台的《关于进一步规范信访事项受理办理程序引导来访人依法逐级走访的办法》有关规定，推行逐级受理办理信访事项，督促各级依法、及时、就地解决好群众提出的合理诉求。二是加强信息化信访网络建设。市县财政要加大投入，加快推进信访信息化建设步伐，全面推行网上信访受理制度。建立网下办理、网上流转的办理程序，实现办理过程和结果可查询、可跟踪、可督办、可评价。积极开展信访事项办理群众满意度评价工作，提高网上信访投诉受理件办结率和息诉率、群众满意率，打造“阳光信访”，引导群众更多地以书信、网络、电话等形式表达诉求。

三、健全信访机制，提高工作成效。一是探索建立对无理闹访缠访的听证、答询制度。对闹访缠访事件，邀请人大代表、政协委员、律师和当事人及其亲属参加公开听证和答询，依靠社会力量和群众舆论做好化解矛盾、处理纠纷，达到罢访息访的效果；二是积极开展信访“五进”和主题创建活动。继续推行行之有效的信访工作进村庄、进社区、进企业、进学校、进机关，开展“民主法治村（社区）”、“信访稳定村（社区）”、“平安村（社区）”等主题创建活动，努力把信访矛盾化解在基层；三是建立完善信访维稳督查工作机制，建立信访维稳督查工作专人负责的信访维稳督查员制度，把督查工作作为解决信访问题的重要手段，同时，要重点督办案件处理过程中是否按照《信访条例》的要求，落实答复、复查、复核制度；四是进一步完善信访事项办结报送制度，对不能按期办结的应向上级说明原因；五是建立健全信访预案机制，对有可能发生集体访、非正常访等苗头性上访事件，要提早做好应对措施，变被动接访为上门征求意见，变上访为下访，以人民群众的建议、诉求、呼声作为工作的出发点和落脚点。

四、强化监督制约，注重源头防范。各级政府要建立重大社会决策、重大工程社会稳定风险评估机制，对涉及群众切身利益的重大社会决策和重大项目，不仅要进行经济效益的评估，看该不该干，还要进行社会稳定风险评估，看能不能干，坚持尊重大多数群众的意愿。在出台每项政策时都要进行充分地调研，做到出台的政策公正、公平和透明，努力从源头上防范和减少群众上访。要注重把内部监督与上级监督、社会监督结合起来，形成监督合力，做到既解决群众反映的问题，又积极探索治本之策，逐步建立长效工作机制。要积极推进基层民主政治建设，完善和落实民主决策、民主管理和民主监督的各项规定，深入推进群众密切关注的政务、村务、事务、党务公开，切实维护群众的切身利益。

五、增强法治思维，规范信访秩序。一是依照《信访条例》有关规定，明确信访联席会议各成员单位的工作职责、考评方式等方面的工作要求，协调协作、整体联动、狠抓落实。对信访工作不重视，对信访事件处理不及时，造成重大影响和严重后果的，依法追究领导责任；二是要加强信访工作与人民调解、司法调解、行政调解的有机衔接，建立完善工作机制，进一步强化信访工作职能作用；三是要加大依法处置力度。甄别情况，对非正常上访、一般滞留人员，可劝其自行返籍，对于无理缠访、无理取闹，甚至违法的上访，经劝解无效，公安机关应积极介入，予以配合，进行依法处置，坚决杜绝“小闹小解决，大闹大解决，不闹不解决”，使无理上访人无利可图。

六、重视宣传教育，优化信访环境。一是推进各级干部学法用法，促使各级领导干部以及信访干部熟悉和掌握履行职责所需要的法律知识，善于运用法律手段管理经济和社会事务，做到依法执政、依法决策、依法行政、依法管理。二是将与群众利益密切相关的《法规》、《条例》纳入普法计划，通过法律知识的普及，切实提高广大群众的法律素质，增强法律意识，让公众了解法律在社会运行中的调解作用，引导群众按照正常渠道反映诉求，运用法律手段解决纷争，保护自身权益，摒弃信“访”不信“法”的不正常思维和行为。

七、加强信访基础，增进干部活力。建立一支高素质的信访队伍是做好信访工作的基础。要不断加强信访干部政治素养，提高信访干部沟通协调能力、应对复杂局面的能力、掌握和运用政策的能力、处理具体问题的能力。市委、市政府要以贯彻落实中、省《关于加强信访干部队伍建设的意见》为契机,不断加强信访干部业务培训力度，关心信访干部成长，加大交流提拔使用力度，切实解决信访工作中存在的困难和问题，增强信访干部队伍活力，努力为实现信访工作的法制化、规范化、制度化提供强有力地组织保障和人才支撑。
