# 汉中市人民政府办公室关于印发汉中市自然保护区生态环境整治方案的通知

市水利局：

《汉中市自然保护区生态环境整治方案》已经市政府同意，现印发给你们，请认真抓好落实，如期完成整改任务。

有关整改进展情况于每月15日、30日前报市林业局。

汉中市人民政府办公室

2017年7月11日

汉中市自然保护区生态环境整治方案

为切实加强全市自然保护区生态环境保护工作，建立长效保护机制，根据中央环保督察组反馈我市的自然保护区存在问题和省委、省政府《关于印发<贯彻落实中央环保督查组反馈意见整改方案>的通知》（陕字〔2017〕24号）、省林业厅《关于印发<陕西省自然保护区生态环境整治方案>的通知》（陕林护字〔2017〕101号）要求，结合我市自然保护区工作实际，制定本方案。

一、总体要求

深入贯彻党的十八届三中、四中、五中、六中全会精神，以习近平总书记有关生态文明建设的系列重要讲话精神为指导，严格贯彻执行《中华人民共和国环境保护法》、《中华人民共和国自然保护区条例》等相关法律法规，深刻认识加强保护区生态环境保护工作的紧迫性和必要性，不断提高认识，强化措施，落实责任，加强自然保护区建设与管理，着力解决我市个别自然保护区存在采矿、采石、采砂等违法违规问题，确保我市自然保护区资源环境安全。

二、整改目标

近期目标：以此次中央环保督察为契机，加大对自然保护区内存在问题整改力度。2017年9月30日前，坚决关停、取缔在自然保护区内的采矿、采砂、采石等违法行为；修编《汉江干流汉中平川段2015-2019年河道采砂规划》，江汉江干流湑水河口至小峡口段干流，城固县湑水河、洋县湑水河、溢水、党河等汉中朱鹮国家级自然保护区划为河道采砂禁采区；研究制定自然保护区内矿业权退出指导意见。

远期目标：　　三、整改任务

（一）认真落实主体责任。按照省市统一部署，针对自然保护区存在采矿、采石、采砂等违法违规问题，由自然保护区管理机构和所在县人民政府以及市级保护区主管部门，按照自然保护区有关法律法规、中省环保督察要求和“谁审批谁取缔、谁建设谁退出、谁违法追责谁”的原则，坚持问题导向，建立问题清单，制定具体整改方案，明确分工，明确要求，落实责任，限期整改，严肃查处并追究有关责任人的责任。对违法违规企业、责任单位，以及监管不力的单位要进行严肃处理、曝光。

责任单位及分工：市环保局统一协调，市林业局、市水利局、市国土资源局负责，分别制定实施主管的有问题自然保护区整改方案，各县政府负责，制定并实施辖区内有问题自然保护区的整改方案。

（二）切实履行管职责。全市自然保护区管理机构要依照《中华人民共和国自然保护区条例》、《陕西省实施〈中华人民共和国自然保护区条例〉办法》，以及相关办法规定要求，建立健全各项规章制度，加强日常巡护监测，开展经常性执法和宣传教育，严格审批事项申报许可，认真落实管理职责。严禁在自然保护区内开展不符合功能定位的开发建设活动。禁止在自然保护区核心区、缓冲区开展任何开发建设活动，建设任何生产经营设施；不得在试验区建设污染环境、破坏自然资源或自然景观的生产设施。对各种违规行为及时告知、制止，造成破坏的，责令限期整改并恢复原状。

责任单位：市发改委、市环保局、市林业局、市水利局、市国土局；各县人民政府；各保护区管理机构。

（三）深入开展专项检查。7月份，对本行政区域内自然保

护区内存在的开发建设活动进行一次全面检查。重点检查自然保护区内存在的采矿、探矿、采石、采砂、开垦，以及核心区、缓冲区内的旅游开发建设等破坏资源环境的活动。检查结果要向社会公布，充分发挥社会舆论的监督作用，鼓励社会公众举报、揭发涉及自然保护区违法违规建设活动。

（四）严肃整治违法活动。今年下半年，各有关部门要依据相关法规和文件要求，对检查发现的违法开发建设活动进行专项整治。禁止在自然保护区内进行采矿、采石、采砂、开垦等法律明令禁止的活动，对在核心区和缓冲区内违法开展的水电开发、房地产、旅游开发等活动，要立即予以关停或关闭，限期拆除，并实施生态恢复。对实验区内未批先建、批建不符的项目，要责令停止建设和使用，并恢复原状。对违法排放污染物和影响生态环境的项目，要责令限期整改；整改后仍不达标的，要坚决依法关停或关闭。对自然保护区内已设置的商业探矿权、采矿权和取水权，要限期退出。对保护区内原有居民的自用房建设应符合土地管理相关法律规定和自然保护区管理有关规定，不对自然景观造成破坏。对开发建设活动造成重大生态破坏的，要暂停审批项目所在区域内建设项目环境影响评价，并依法追究相关单位和人员的责任。

责任单位及分工：市环保局牵头，市林业局、市水利局、市国土局、市农业局开展主管的所有保护区违法开发建设活动整治；各县区政府开展辖区内所有保护区违法开发建设活动整治；保护区管理机构开展区域内违法开发建设活动全面调查，建立清单。

（五）加强建设项目监管。各有关部门依据各自职责，切实加强涉及自然保护区建设项目的准入审查。建设项目选址（线）应尽可能避让自然保护区，确因重大基础设施建设和自然条件等因素限制无法避让的，要严格执行环境影响评价等制度。凡涉及自然保护区的开发建设项目，其环境影响评价文件的审批，需征得自然保护区行政主管部门和环境保护行政主管部门同意。对经批准在自然保护区内开展的建设项目，项目所在地环保部门、保护区行政主管部门和保护区管理机构要进行全程跟踪，加强项目施工期间的监管，督促建设单位落实保护与恢复治理方案。保护区管理机构要对项目建设进行全过程跟踪，发现问题要及时处理和报告，确保各项生态保护措施落实到位。

责任单位及分工：市环保局牵头，市发改委、市林业局、市水利局、市国土局，各县区政府按职责分工负责，保护区管理机构监督实施。

（六）积极争取资金支持。各国家级自然保护区要在编制总体规划的基础上，抓紧完成一、二、三期项目可行性研究报告（实施方案）和年度能力建设项目申请编制工作，积极开展项目储备。各地方级自然保护区要积极争取省级财政的支持，将自然保护区森林资源纳入生态效益补偿范围，资金主要用于开展自然保护区的基础设施建设和管理，以及开展自然保护区的勘界立标，加大自然保护区宣传力度等，形成良好的生态保护氛围。

（一）高度重视，加强领导。各有关县区政府一定要高度重视中央环保督察反馈我市自然保护区存在的问题，一定要要坚持生态环境保护“党政同责，一岗双责”，切实加强领导，成立整改工作领导小组，制定整改工作方案，明确整改目标、工作责任和工作要求，指导相关部门开展整治工作。

（二）落实责任，细化任务。各县区在制定整改方案时，要逐级落实责任，层层细化任务，强化工作措施，全面推进各项整改工作。对责任不落实，工作不得力，未按期完成整改任务的单位、企业和有关责任人，依法依规进行责任追究。
