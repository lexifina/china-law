# 汉中市人民政府办公室关于印发汉中市2017年主要污染物总量减排工作方案的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、属机构：

《汉中市2017年主要污染物总量减排工作方案》已经市政府同意，现印发给你们，请认真贯彻实施。

汉中市人民政府办公室

2017年5月31日

汉中市2017年主要污染物总量减排工作方案

为切实保护和改善全市环境质量，控制主要污染物排放总量，全面完成省政府下达我市的2017年主要污染物总量减排目标，制订本方案。

一、目标任务

省上下达我市2017201720161.5％、1.51.8％、1.5“0”根据全市年社会经济发展目标估算，2017吨、吨、吨和吨，加上存量削减指标，全市年化学需氧量、氨氮、二氧化硫和氮氧化物削减任务约为吨、吨、吨和吨；挥发性有机物排放量保持“0”。各县区20171　　二、主要措施

（一）完善生活污染治理设施，强化运行监管。一是狠抓生活污水处理厂运行监管。按中省环保督察整改要求，加快推进市污水处理厂及8个县区污水处理厂提标改造工程，全部达到污水排放一级A标准；加快城市污水收集管网和雨污分流工程建设，提升城市建成区的污水收集率，切实发挥污水处理厂治污减排作用；做好污水处理厂日常运行管控，不得发生超标排放现象；二是加快31个重点镇污水处理厂建设进度，已开工的4个镇尽快建成投运，其他镇尽快制定建设推进计划，尽早开工。三是城固县垃圾处理场、汉台江北垃圾处理场、洋县城市垃圾处理场、勉县垃圾处理场要加强垃圾渗滤液处理设施的运行监管，确保自动监测设施规范稳定运行，并同步联网传输数据，其他县要加快垃圾填埋场渗滤液处理工程建设。

（二）加大重点行业污染治理力度，确保规范达标运行。一是抓好重点减排项目的建设运行。陕钢集团汉中公司要规范运行烧结机和球团生产线脱硫设施，略钢公司要规范运行烧结机脱硫设施，确保100%投运并稳定达标排放；汉钢公司要尽快淘汰不符合产业政策的烧结机和高炉。中材汉江、尧柏等水泥企业要规范运行脱硝设施，确保氮氧化物排放浓度稳定低于400mg/m3。大唐略阳发电有限公司9月底前要完成6号机组超低排放改造，进一步提升6号、7号机组脱硫脱硝设施的管理水平，确保设施稳定达标运行。二是强化重点企业污染治理设施运行监管，督促企业及时运维好治污设施，确保污染物排放浓度达到国家最新排放标准要求。城固酒业有限公司要加强水循环利用及污水综合处理工程运行，完善运行台账记录。三是加大散煤治理力度，巩固燃煤锅炉拆改成效。将散煤削减纳入燃煤消费总量控制计划，加大城市及农村供电、供气等基础设施建设力度，提高清洁能源比例。逐步扩大禁煤区范围，“禁煤区”内严禁新建燃煤锅炉。

（三）全面实施农业污染治理。2017年6月底完成畜禽养殖禁养区划定方案的制定，并向社会公布；依法关闭和搬迁畜禽养殖禁养区内规模化养殖场；辖区现有规模化养殖企业和养殖小区全部完成治污设施建设。陕西农旺牧业有限公司和佛坪县广福养猪家庭农场必须在要求时限内建成粪污治理工程，达到减排核算要求。

（四）加快实施落后产能淘汰。大力推动退城入园，督促企业加快产业升级，清理取缔一批“散乱污”违法企业，从源头减少污染物排放。城固要按期完成3户皂素企业和3户粘土砖生产企业的关停淘汰，陕西省汉中市汉江油脂有限责任公司、洋县旧垃圾处理场要按时关停。

（五）全面实施机动车尾气污染防治。全面落实《汉中市机动车污染防治雷霆行动实施方案》要求的各项工作措施，坚决淘汰“黄标车”和老旧车，确保11月底前完成“黄标车”及老旧车淘汰任务；严格执行机动车排放检验前置要求，对排放检验不合格或无定期排放检验合格报告的机动车，不予核发安全技术检验合格标志；全面实行国家第五阶段机动车排放标准，严禁不达标车辆上牌入户，加大机动车路检，严格落实“黄标车”禁限行措施，严厉查处“冒黑烟”机动车尾气超标排放行为。大力发展清洁绿色交通，加强机动车油品质量管控，遏制机动车尾气污染。

（六）推进挥发性有机物整治工作。完成储油库和加油站油气三次回收改造，进一步提高油气回收效率。强化管理，确保油气回收设施规范运行。全面开展335家规模餐饮和135家汽车4S店挥发性有机物污染治理工作，强化协同控制，减少臭氧污染。

（七）加强减排管理。一是持续抓好减排监测体系建设，强化确保自动监测设施发挥监管作用，支撑减排核查核算。二是严格落实总量控制制度，全面实施排污许可制度。6三是抓好减排台帐建设。严格按照中省市的相关要求，规范建立减排项目纸质及电子台帐，强化环境统计和减排核算基础数据调度，确保及时、充分、准确反映减排成效。

三、工作要求

（一）夯实工作责任。各县区政府要紧紧围绕环境质量改善这一中心任务，严格落实污染物总量减排各项措施，实现环境质量目标与污染减排目标协同控制。主要领导要履行减排第一责任人的职责，专题研究部署污染减排工作，制定工作方案，分解任务、夯实责任，着力解决制约年度任务顺利完成的问题和困难，确保各项工作全面按期完成。环保、发改、统计、工信、农业、公安、住建、工商、电力等部门要加强协作配合，监督各重点减排企业单位自觉履行减排义务，按期完成治理任务。

（二）狠抓项目实施。各县区政府要及时制定辖区减排工作实施方案，细化项目时间表，落实监管责任。突出抓好市上安排的重点减排项目，严把时间节点，确保按时完成并投运。

（三）严格考核问责。市政府将加强对重点减排项目的监督检查，实行半年点评、年终考核，对减排项目推进缓慢、减排任务完成较差的县区政府及部门单位进行通报、预警，严格兑现污染减排绩效考核、“区域限批”、“一票否决”等制度规定，确保全市减排目标顺利实现。

（四）强化信息报送。各县区要按照市政府下达的2017年度减排目标任务，尽快制定减排方案并于2017年5月31日前报市减排办。7月10日、12月10日前将半年主要污染物总量减排工作进展情况报市减排办。各县区半年进展报送工作计入年度考核的平时考核成绩。
