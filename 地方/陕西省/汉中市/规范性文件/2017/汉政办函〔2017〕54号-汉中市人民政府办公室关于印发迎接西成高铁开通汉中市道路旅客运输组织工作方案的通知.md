# 汉中市人民政府办公室关于印发迎接西成高铁开通汉中市道路旅客运输组织工作方案的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

《迎接西成高铁开通汉中市道路旅客运输组织工作方案》已经市政府研究同意，现印发你们，请抓好贯彻落实。

汉中市人民政府办公室

2017年7月24日

迎接西成高铁开通汉中市道路旅客

运输组织工作方案

为做好西成高铁开通后铁路客运、公路客运、城市公交、出租汽车、旅游包车的运输组织工作，根据汉中实际，制定本方案。

一、总体目标

以方便汉中群众出行、方便来汉游客旅行为目标，以构建综合运输体系为引领，发挥“互联网+交通”的先导作用，通过调整道路旅客运输组织结构，完善优化运输配套设施，实现各种运输方式之间的高效接驳集散和“零换乘”。

二、主要工作任务

（一）加快通高铁站道路及客运场站建设。加快汉中站、城固北站、洋县西站、宁强南站和佛坪站等五个高铁站与城区、主要景区的路网衔接建设；加快汉中综合客运枢纽站建设，确保与高铁开通同步投入使用；做好城固北站、洋县西站、宁强南站和佛坪站道路客运车辆停靠区域的划定和建设工作。

（二）科学安排公交线路。根据高铁旅客流量、流时及流向，通过新增、调整、延伸公交线路，科学调配公交运力，实现高铁站与城区、重点乡镇、景区（点）和机场之间的直通直达、互通互达。

1. 汉中综合客运枢纽站。

（1）汉中火车站原有4条始发公交线路，调整到汉中综合客运枢纽站内始发，具体为：

1路：汉中综合客运枢纽站经人民路、天汉大道至大河坎；

24路：汉中综合客运枢纽站经北一环路、天汉大道、虎桥路、西环路、劳动西路、西一环路、虎桥西路、舒营路至梁山；

25路：汉中综合客运枢纽站经人民路、北大街、莲湖路、北团结街、南团结街、滨江路、益州路至黄家坡；

④103路：汉中综合客运枢纽站经人民路、前进中路、天汉大道、虎桥路、西环路、将坛西路、天汉大道、迎宾路、南郑大道至周家坪。

（2）对6条公交线路进行调整，经停汉中综合客运枢纽站，具体为：

8路：陕西航空技师学院经天汉大道、北一环路、汉中综合客运枢纽站、人民路、前进中路、天汉大道、南郑大道、红军路至陕西航空技术学院；

23路：汉中综合客运枢纽站经人民路、劳动路、天台路、汉武路至武乡镇；

④26路：滨江西路经民主街西段、民主街、西环路、劳动西路、人民路、汉中综合客运枢纽站、北一环路、天汉大道北段、宝汉路、宗武路、武乡至天台山景区；

⑤102路：陕西理工大学南区（东门）经东一环路、兴汉路、人民路、汉中综合客运枢纽站、北一环路、天汉大道北段、316国道、褒纪路至陕西理工大学北区；

⑥105路：汉中综合客运枢纽站经人民路、兴汉路（高客站）、兴汉东路、108国道至柳林机场。

2.高铁城固北站站前广场。开通3条公交线路：城固北站经城固运输公司汽车站、汉运司城固汽车站至城固江滨休闲广场；城固北站至张骞墓；城固北站经五门堰至桔园景区。

3. 高铁洋县西站站前广场。开通3条公交线路：洋县西站经汉运司洋县汽车站、洋县运输公司汽车站至洋县客运公司汽车站；洋县西站经梨园风景区至朱鹮保护站；洋县西站至蔡伦墓。

4. 高铁宁强南站站前广场。开通2条公交线路：宁强南站至宁强汽车站；宁强南站至汉水源森林公园。

5. 高铁佛坪站站前广场。开通2条公交线路：佛坪站至县城;佛坪站至熊猫谷景区。

（三）调整优化客运班线。结合高铁站分布情况，通过新增、调整客运班线，开通汉中综合客运枢纽站发往西乡、勉县、略阳、镇巴、留坝县城的客运班线；开通镇巴经西乡至洋县高铁站、略阳至宁强高铁站的客运班线，实现未通高铁各县与汉中境内各高铁站直通直达、无缝衔接。城固、洋县、宁强、佛坪等县要根据本地群众和来汉游客出行需求，分别调整或开通高铁站至桔园、华阳古镇、青木川古镇、熊猫谷等重点景区的客运班线。

（四）积极发展旅游客运。开通汉中综合客运枢纽站至黎坪景区、华阳景区、紫柏山景区、五龙洞景区、汉水源森林公园景区、红寺湖（经南湖）、诸葛古镇（经武侯祠、武侯墓）、蔡伦墓（经张骞墓）、青木川古镇、镇巴苗寨民俗风情区等境内已成规模的风景名胜区和红色旅游、天坑群地质遗迹等定线旅游客运专线，对周边重点景区形成旅游客运全覆盖。以满足游客多样化、个性化需求为目标，发挥各旅行社及各道路旅游客运企业作用，积极发展旅游包车服务。

为适应全域旅游发展需要，全市旅游客运企业计划新增高一级及以上车型旅游客车403辆，总座位11946个。

（五）提升出租汽车服务水平。深入推进出租汽车行业改革，促进全市出租汽车行业和互联网融合对接，促进巡游出租汽车转型升级，规范网络预约出租汽车经营，逐步实现两种业态融合发展，同时加强培训教育，强化日常监管，大力提升出租汽车服务能力和服务水平，为本地群众和来汉旅客提供更为便捷、舒适的个性化出行服务。在城固北站、洋县西站、宁强南站和佛坪站划定出租汽车停靠待客泊位，组织出租汽车有序运营。

（六）推进汽车租赁连锁经营。鼓励、引导、推动本地企业开展汽车租赁连锁经营业务，在开通高铁的县区，先行推动汽车租赁连锁化经营，实现高铁站、城区、景区之间租车业务联网，提供“网上预约、异地还车”服务，构建方便、快捷、高效的汽车租赁网络，满足本地群众和来汉旅客租车出行需求。

（七）完善运输配套设施。对高速公路引道、城市道路和境内国省干线公路的标识标牌进行完善，突出高铁站、重点景区指引，满足游客自驾需求。依托汉运司充电桩公司，加快主要道路、重点景区充电桩建设，服务新能源汽车的应用。

（八）建立道路运输应急保障体系。加快12328交通运输服务监督电话呼叫中心建设，确保高铁开通前投入使用，实现交通运输行业投诉处理、信息查询、应急指挥“一站式服务”。为应对高铁客流可能发生的突然变化，确保旅客顺畅疏散，由骨干国有客运企业负责储备一定数量的客运运力，用于应急调度，做好应急保障。

三、保障措施

（一）成立领导机构。市政府成立迎高铁道路客运组织工作领导小组，由分管副市长任组长，市政府分管副秘书长、市交通运输局局长任副组长，市发改、工信、公安、国土、建规、住管、交通、旅游、工商和铁路汉中车务段等部门（单位）分管领导为成员。领导小组下设办公室，办公室设在市交通运输局，由副局长杨会议同志兼任主任，局党组成员、市道路运输管理处处长龚野同志任副主任。

相关县区也要成立相应的工作机构，并根据市上道路旅客运输组织工作方案制定相应的实施方案，积极推进辖区道路客运组织工作。

（二）搞好协调配合。相关部门（单位）要加强协调配合，建立信息互通机制，适时通报任务完成情况，一同查找问题、分析原因、落实措施，共同助推工作任务的顺利完成。

（三）加强督促检查。由市政府督查室牵头，市政府迎高铁道路客运组织工作领导小组办公室参与，根据工作分工、具体任务和时间节点，定期开展专项督查，按月通报责任单位工作进展情况，对未按时完成目标任务的县区和市直相关部门，将对主要领导实施约谈，确保各项工作扎实有效推进。
