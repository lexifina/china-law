# 汉中市人民政府办公室关于印发汉中市推进控制污染物排放许可制实施方案的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

《汉中市推进控制污染物排放许可制实施方案》已经市政府同意，现印发给你们，请认真贯彻执行。

汉中市人民政府办公室

2017年8月9日

汉中市推进控制污染物排放许可制实施方案

为贯彻落实《国务院控制污染物排放许可制实施方案》（国办发〔2016〕81号，以下称《实施方案》），充分发挥排污许可管理制度效能，落实企事业单位治污主体责任，强化环保部门依证监管，促进环境质量改善，根据《省人民政府办公厅关于印发控制污染物排放许可制实施计划的通知》精神，结合我市实际，制定本方案。

一、总体要求

控制污染物排放许可制（以下称排污许可制），是通过向企事业单位发放排污许可证，全面落实排污单位治污主体责任，依法规范企事业单位排污行为的基础性环境管理制度。逐步与固定源环境管理相关制度整合、衔接，实现分类管理、一企一证，依证监管，有效控制污染物排放，持续提升环境治理能力和水平，加快改善生态环境质量。

二、目标任务

严格按照《固定污染源排污许可分类管理名录》（以下简称《名录》）要求，按行业分步推进排污许可证核发。率先开展火电、造纸行业企业许可证核发工作；2017年完成水十条、大气十条重点行业及产能过剩行业企业许可证核发，重点包括石化、化工、钢铁、有色、水泥、印染、制革、焦化、农副食品加工、农药、电镀等；2020年基本完成名录规定行业企业的许可证核发，各项环境管理制度精简合理、有机衔接，企事业单位环保主体责任得到落实，对固定污染源实施全过程管理和多污染物协同控制，实现系统化、科学化、法治化、精细化、信息化的“一证式”管理。

三、主要措施

（一）强化排污单位环境保护主体责任

通过排污许可证对企事业单位排放大气、水等各类污染物进行统一规范和约束，实施“一证式”管理，重点对污染治理设施、污染物排放浓度、排放量以及管理要求进行许可，排污单位应当承担的污染物排放责任和义务在许可证中予以规定。本着诚信原则，以企业承诺守法的方式，强化排污单位环境保护主体责任。企业作为排污单位，应自行申领排污许可证并对申请材料的真实性、准确性和完整性承担法律责任；应持证排污、依证自主管理排污行为，依法承担防止、减少环境污染的责任；应通过自行或委托开展监测、建立排污台账、按期报告持证排污情况等自证守法；应在申领许可证前和在许可证执行过程中依法向社会公开污染物排放数据，按期如实向环境保护部门报告排污许可证执行情况，并对数据真实性负责，同时接受社会监督；当产排污情况等发生变更时或许可证到期应自行申请变更或延期。逐步营造排污者如实申报、监管者阳光执法、社会共同监督的环境治理氛围，形成系统完整、权责清晰、监管有效的污染管理新格局。

（二）依法有序规范实施排污许可

1.实行分类分级许可

市级环境保护主管部门负责全市排污许可制的组织实施和监督，指导各县区实施排污许可制。对污染物产生量大、排放量大或环境危害程度高的排污单位实行排污许可重点管理，对其他排污单位实行排污许可简化管理。按照《名录》确定实行重点管理或者简化管理的排污单位。

对简化管理的排污单位，由县级环境保护部门负责核发排污许可证，其余排污许可证（除大唐略电外）原则上由市级环境保护主管部门负责核发。南郑县参照市级排污许可证核发权限执行。县级环境保护主管部门被调整为市级环境保护主管部门派出分局后，由市级环境保护主管部门组织所属派出分局实施排污许可证核发管理。

2.合理确定许可内容

排污许可证中应明确许可排放的污染物种类、浓度、排放量、排放去向等事项，载明污染治理设施、环境管理要求以及排污权交易等相关内容。根据污染物排放标准、总量控制指标、环境影响评价文件及批复或承诺备案要求等，依法合理确定许可排放的污染物种类、浓度及排放量。排放标准、总量控制指标等发生变更，排污许可内容应及时进行更新。

对环境质量不达标地区，县级以上人民政府可通过依法制定环境质量限期达标规划，对排污单位提出更加严格的要求；各县区依法制定的重污染天气应对措施，以及限期达标规划或有关水污染防治应急预案中枯水期环境管理要求等，针对特殊时段排污行为提出更加严格的要求，应在许可证中载明，严格控制污染物排放，更好地促进环境质量改善。

3.依法核发排污许可证

排污单位应在管理信息平台上填报并提交排污许可证申请，同时向核发部门提交通过管理信息平台印制的书面申请材料。核发部门收到排污单位提交的申请材料后，对材料的完整性、规范性进行审查，对满足条件的排污单位核发排污许可证。

根据省环保厅《关于印发<排污许可证管理暂行规定>陕西省实施细则》规定，由市级环保部门根据中省要求确定全市范围内排污许可证具体的申请时限、核发机关、申请程序等相关事项，向社会公告并报省环保厅备案。

（三）依证执法，严查违法排污行为

环境保护主管部门应按照“谁核发、谁监管”的原则定期开展执法监管，对已核发排污许可证的行业，应以排污许可证为依据，以定期或随机抽查的方式开展监管执法，重点检查许可事项和管理要求的落实情况，通过执法监测、核查台账等手段，检查是否存在批建不符、故意隐瞒和弄虚作假等情况，核实排放数据和报告的真实性，判定是否达标排放，核定排放量。对检查发现实际情况与环境管理台账、排污许可证执行报告等不一致的、不符合排污许可证要求的企事业单位责令其对存在的问题作出说明；对未能说明且无法提供自行监测原始记录等证明材料的，应依法予以处罚，并将抽查结果纳入全国排污许可证管理信息平台记录；对有违规违法记录的，要提高检查频次。对污染严重的产能过剩行业企业，加大执法频次与处罚力度，推动去产能工作。加大对无证排污和不按证排污等行为的整治力度。根据违法排污情节轻重，依法采取按日连续处罚、限制生产、停产整治、停业、关闭等措施，严厉查处违法排污行为，对构成犯罪的，依法移交司法机关追究刑事责任。2017年下半年，要组织对首次核发排污许可证的企业开展监督检查，督促企业按照排污许可证要求落实主体责任。

各县区要根据辖区污染物排放特点与环境质量改善要求，逐步扩大安装在线监测设施企业的范围，推动实现在线监控对所有固定污染源的全覆盖。可通过政府购买服务的方式，委托第三方机构对排污单位的排许可证申请材料、申报的污染物排放量、日常的台账记录以及排污许可执行报告进行审核，提出审核意见，作为环境保护部门监督检查的依据。

（四）实施市场调节，推行排污许可有偿使用机制

排污许可证是排污权的确认凭证、排污交易的管理载体，根据《陕西省主要污染物排污权有偿使用和交易管理办法（试行）》（陕政办发〔2016〕51号）要求，从2017年开始按照企业排污许可证载明的污染物排放总量指标，开展排污权有偿使用费的征收，先期在火电企业(含自备电厂)开展；2018年1月1日起，在所有排污单位全面开展排污权有偿使用收入征收。鼓励企业通过淘汰落后和过剩产能、清洁生产、污染治理、技术改造升级等措施削减污染物排放量，形成的“富余排污权”可按规定在市场进行交易，获得减排收益。对自愿实施严于许可排放浓度和排放量且在排污许可证中载明的企事业单位，加大环保电价等价格激励措施力度，符合条件的可以享受相关环保、资源综合利用等方面的优惠政策。

（五）加强信息公开，促进社会监督

各级环境保护部门要督导申领排污许可证的企事业单位在全国排污许可证管理信息平台上及时公开自行监测数据，公布监管执法信息和不按证排污的企事业单位名单，并向省公共信用交换平台推送相关信息。环境保护部门和税务部门交换共享企事业单位实际排放数据与纳税申报数据，引导企事业单位按证排污并诚信纳税。建立有奖举报机制，落实奖励资金，鼓励公众举报无证和不按证排污等违法违规行为。

四、工作要求

（一）加强组织领导。各县区要高度重视排污许可制实施工作，统一思想，提高认识，切实做好组织领导、综合保障、统筹协调和技术指导等工作；要制定排污许可证监管计划，认真组织排查，按时限列出应纳入排污许可管理的企业名录，督促企业规范申报开展排污许可证申报，按时限完成排污许可证核发工作。由市级环境保护部门结合我市实际，完善排污许可证相关管理制度，严格按照《排污许可证管理暂行规定》及相关技术规范要求组织核发和管理。要做好排污许可制推进期间各项环境管理制度的衔接，避免出现管理真空。

（二）优化指导服务。各县区要加大对排污许可证管理工作的财政支持力度，保障排污许可证专网及软硬件配置；加强对环保部门和排污单位的技术服务，鼓励发展政府购买服务，探索政府购买服务的第三方技术监管制度；探索建立固定污染源全过程运行监管体系，引导企业自觉守法排污，完善排污许可证执行和监管执法技术体系，指导企事业单位自行监测、台账记录、执行报告、信息公开等工作，规范环境保护部门台账核查、现场执法等行为，确保排污许可证核发和管理工作顺利推进。

（三）开展宣传培训。各县区要充分履行地方政府环境保护主体责任，加大对排污许可制的宣传力度，做好制度解读，及时回应社会关切。强化基层环保部门和排污单位的培训，强化企事业单位持证排污意识，有序引导社会公众更好参与监督企事业单位排污行为，形成政府综合管控、企业依证守法、社会共同监督的良好氛围。

（四）严格督察问责。排污许可制落实情况是省市环境保护督察巡查工作的重要内容，对未按照时限要求完成排污许可证核发工作的县区将进行问责，对违规发放排污许可证的，依法追究相关人员责任。
