# 汉中市人民政府办公室关于印发近期政务信息报送要点的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

现将《近期政务信息报送要点》印发给你们，请结合实际，认真做好信息报送工作。

汉中市人民政府办公室

2017年8月10日

近期政务信息报送要点

一、关于经济形势

1. 宏观经济运行情况，包括就业、工业、投资、消费、进出口、财税等领域的新情况、新问题。

2. 农业生产情况，特别是夏季粮油收购、肉蛋禽市场运行情况。

3. 重点行业和企业运行情况，特别是钢铁、煤炭、汽车、机械、装备制造、纺织、光伏等运行情况和突出问题。

4. 房地产市场运行走势及房地产政策调控效果分析。

5. 国际大宗商品市场情况，包括原油、铁矿石、有色金属、农产品等市场运行的新动向。

6. 金融市场运行情况以及防控金融风险的主要措施。

二、关于“放管服”改革

1. 深化商事制度改革，进一步推进“多证合一、一照一码”和削减工商登记前置审批进展情况、典型案例、困难问题及建议。

2. 加快完善以负面清单为主的市场准入制度的进展情况、创新做法、困难问题及建议。

3. 全面推开涉企收费公示制，全面清理整顿行业协会商会、各类中介机构收费项目的进展情况和经验成效。

4. 放宽社会服务业市场准入，特别是解决健康养老、医疗康复、技术培训、文化体育等领域准入门槛高、互为前置审批问题的进展情况、创新做法、经验成效、困难问题及建议。

5. 简化工业产品生产许可和审批程序，强化部门监管责任和企业产品质量安全主体责任的创新做法、典型案例、初步成效、困难问题及建议。

6. 加强事中事后监管，推进“双随机、一公开”监管全覆盖和综合行政执法改革，更大力度推动跨部门联合检查的进展情况、创新做法、典型案例和取得的成效。

7. 推进社会信用体系建设，充分发挥信用信息共享平台作用，建立健全政府部门间协同监管和联合奖惩机制，完善企业信用信息公示系统，加强信用监管的进展情况、创新做法、困难问题及意见建议。

8. 针对烦扰群众的各种“奇葩”证明、循环证明、重复证明问题，持续开展“减证便民”行动的进展情况、创新做法和取得的成效。

9. 加快推行“互联网+政务服务”，推动政府部门在协同联动、流程再造、系统整合方面进行改革，提升线上线下一体化政务服务能力的创新做法、经验成效、困难问题。

10. 全国和全省“放管服”改革会议精神贯彻落实情况。

11.《陕西省深化简政放权放管结合优化服务改革重点任务分解落实方案》落实进展情况。

三、关于发展新动能

1. 持续推进大众创业万众创新示范基地建设，鼓励大企业和科研院所、高校设立专业化众创空间进展情况、遇到的困难问题，首批“双创”示范基地建设的创新做法和取得的成效，第二批“双创”示范基地建设进展情况及工作打算。

2. 加大农业“双创”力度，推进农业与“互联网+”等现代科技相结合，先进农业技术和创新机制的成效、问题及典型案例。

3. 推动一二三产业相互渗透、大中小企业融通发展的创新做法、典型案例、遇到的困难问题及建议。

4. 支持大学毕业生、海外留学人员、返乡农民工、复员转业军人等重点群体创业的进展、做法、成效、问题及典型案例。

5. 大力实施“中国制造2025”汉中实施行动方案，以智能制造为主攻方向，运用新技术、新业态、新模式加快改造提升传统产业的创新做法、经验成效和典型案例。

6.在智慧养老、智能医疗、智能交通等服务业领域，加快推进“互联网+”行动，增加中高端服务供给的创新做法、经验成效和典型案例。

7. 运用市场化法治化手段，推进钢铁、煤炭等行业去产能，有效处置“僵尸企业”，加快淘汰落后产能，实现资源优化再配置的进展情况、经验成效、困难问题及建议。

8. 用好军民融合产业基金，建设国家军民融合知识产权协同运用示范基地，培育一批“民参军”、“军转民”企业进展情况、典型案例、遇到的困难问题及建议。

四、关于释放内需潜力

1. 积极扩大有效投资和促进民间投资，加快交通、水利、电信基础设施、地下综合管廊建设等重点项目建设的进展情况、困难问题及建议。

2. 加快实施新一轮农村电网改造升级工程的进展情况、主要做法、困难问题及建议。

3. 深化政府和社会资本合作(PPP)，完善相关价格、税费等优惠政策的进展情况、困难问题、意见建议，以及对典型案例的分析。

4. 加快发展服务消费，促进网络零售市场发展，发展医养结合、文化创意等新兴消费，扩大数字家庭、在线教育等信息消费的典型做法、经验成效、困难问题及建议。

5. 切实加强个人信息保护，推进信息消费升级的创新做法、经验成效、困难问题及建议。

6. 广泛开展质量提升行动，加强全面质量管理进展情况、创新做法、困难问题及建议。

7. 推进新型城镇化，促进产城融合、推广绿色建筑、建设智慧城市，完善多层次公共服务的创新做法和典型案例。

8. 全省县域经济发展和城镇建设工作会议精神贯彻落实情况、创新做法、经验成效。

五、关于实体经济

1. 持续加大减税力度，特别是扩大享受企业所得税优惠的小型微利企业范围等政策的实施情况、取得的成效、遇到的新情况新问题及建议。

2. 降低涉企收费，清理规范政府性基金、行政事业性收费，大幅减少涉企经营服务性收费，特别是2017年4月1日和7月1日两批降费措施的落实情况、初步成效、困难问题及建议。

3. 降低融资负担，加大金融对实体经济特别是小微企业支持力度，发挥政府投资的担保机构作用等进展情况、经验成效、困难问题和典型案例。

4. 降低人工成本，继续适当降低“五险一金”有关缴费比例等进展情况、初步成效、困难问题及建议。

5. 降低用能用地成本，合理降低输配电价格，扩大电力直接交易规模等进展情况、初步成效、困难问题及建议。

6. 降低物流成本，加强物流薄弱环节和重点领域基础设施建设，推进发展物流新业态和集装箱运输，发展“互联网+”高效物流，降低物流用地成本等政策的实施情况、取得的成效、遇到的新情况新问题及建议。

7. 提高资金周转效率，清理地方政府对企业的资金拖欠，清理规范各类保证金的进展情况、困难问题及建议。

六、关于双向开放

1. 围绕商事登记、审批监管、投资贸易、金融服务、法治环境等领域可开展制度创新的进展情况、经验成效、困难问题及建议。

2. 深化外商投资企业注册资本制度改革，放宽外资准入领域，鼓励外资通过合资、参股、并购等方式参与企业改造和兼并重组等进展情况、创新做法、困难问题及建议。

3. 利用外资的新情况、新问题及典型案例分析，国内外招商引资政策的横向比较。

4. 提升贸易便利化水平，推进通关一体化，加快推进国际贸易“单一窗口”建设进展情况、困难问题及建议。

5. 实施更加有效的人才引进和扶持政策，吸引更多优秀人才回流，投身创业创新的做法、初步成效和困难问题。

6. 丝博会签约项目落地情况。

七、关于深化改革

1. 深入推进供给侧结构性改革，“三去一降一补”的新进展、新情况、新问题，以及各地推进相关工作、落实相关政策措施的创新举措。

2. 深入推进国企国资改革，市属企业“一企一策”改革方案落实情况，重点领域混合所有制改革试点进展情况、困难问题、意见建议。

3. 推进财税体制改革，进一步规范地方举债行为，有效防范和化解财政领域潜在风险的做法成效、困难问题、意见建议。

4. 继续推进营改增，简化增值税税率结构，落实和完善相关政策措施的进展情况、政策效应分析、遇到的困难问题及建议。

5. 深化金融机构和金融监管体制改革，大力发展普惠金融、科技金融、能源金融、绿色金融和供应链金融，加快推动投贷联动、知识产权抵质押贷款和农村“两权”抵押贷款试点进展情况、创新做法、取得的成效和典型案例。

6. 推进农业供给侧结构性改革，调整农业种植品种和规模等进展情况、困难问题及建议。

7. 深化医疗、医保、医药联动改革，加快推进异地就医住院费用直接结算，推进医疗联合体建设、分级诊疗试点和家庭签约服务的进展情况、创新做法、困难问题及建议。

8. 深化生态文明体制改革，完善主体功能区制度、实施生态文明建设试点示范、完善生态环境保护制度、深入推进国有林场和国有林区改革、健全自然资源资产产权制度等进展情况、经验成效、困难问题及建议。

八、关于民生社会事业

1. 中央巡视“回头看”和国务院扶贫开发领导小组第十九巡查组反馈意见整改落实情况。

2. 中央巡视“回头看”和环保督察反馈问题整改进展情况，铁腕治霾“1+10+2”攻坚行动及有关奖补政策落实情况。

3. 扎实推进脱贫攻坚，做好教育和健康扶贫，帮助集中连片特困地区增强自我发展能力的创新做法、经验成效。

4. 坚持综合施策，扎实做好产业扶贫和易地扶贫搬迁等工作，激发贫困群众脱贫内生动力，确保脱贫任务完成情况、创新做法、经验成效和典型案例。

5. 大力实施就业优先战略和更加积极的就业政策，加强就业服务和职业培训，统筹做好高校毕业生、就业困难人员、化解过剩产能职工等重点群体就业工作的做法和成效。

6. 持续加大棚户区改造力度，完善水电气热路和教育、医疗等配套设施，进一步提高货币化安置比例，实现经济和民生多重效益的创新做法、经验成效和典型案例。

7. 加强中小学幼儿园安全风险防控体系建设，打造“平安校园”的进展情况、创新做法、困难问题及建议。

8. 以河长制为抓手加强江河治理及生态修复工程建设进展情况、困难问题及建议。

9. 加强农村公路、农村光纤、农村饮水安全、农村危房改造等基础设施建设的进展情况、困难问题及建议。

10. 各地各部门力减“文山会海”采取的主要措施、典型做法、取得的成效、遇到的困难问题及建议。

九、关于防范和化解各类风险

1. 紧盯煤矿、道路交通、危化品、消防、建筑工地等重点行业领域，开展安全生产大检查和专项整治行动情况。

2. 抓好汛期各类灾害防范和安全生产工作，严防山洪、滑坡、泥石流等灾害的工作举措。

3. 创新农业救灾机制，开展提高农业大灾保险保障水平试点，加强病害防控的进展情况、经验成效、困难问题。

4. 不良资产、债券违约、影子银行、互联网金融等金融领域的苗头性情况，以及防范处置的措施建议。

5. 依法严厉打击各类犯罪活动，打击电信诈骗、非法集资等涉众型经济犯罪的典型做法和成效。

6. 完善食品药品安全监管体制机制，充实基层监管力量，坚持源头控制、产管并重、重典治乱，把好饮食用药安全每一道关口的创新做法、经验成效、困难问题及建议。

7. 坚决查处假冒伪劣、坑蒙拐骗以及涉及食品、药品、环保等群众密切关注的违法违规问题，为市场主体公平竞争营造环境的主要做法和典型案例。
