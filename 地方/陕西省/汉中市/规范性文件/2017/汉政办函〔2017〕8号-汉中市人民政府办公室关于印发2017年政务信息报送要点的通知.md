# 汉中市人民政府办公室关于印发2017年政务信息报送要点的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

根据省政府办公厅信息报送要点，结合全市中心工作，现将《2017年政务信息报送要点》印发你们，请结合实际，认真做好报送工作。

汉中市人民政府办公室

2017年2月17日

2017年政务信息报送要点

一、关于经济形势

1.宏观经济运行情况，特别是工业、投资、消费、进出口、财税、就业、物价等运行中出现的新情况、新问题。

2.金融市场运行情况以及防控金融风险的主要措施。

3.房地产市场运行情况及走势分析，以及促进房地产市场平稳健康发展的主要措施和成效。

4.重点行业和企业运行情况，特别是春节前后企业用工、产品销售、订单、库存等方面出现的新情况、新问题。

5.国际大宗商品市场运行情况，包括原油、铁矿石、有色金属、农产品等市场运行新动向。

二、关于供给侧结构性改革

1.以清单管理推动减权限权，全面清理调整各种行业准入证、生产许可证、经营许可证、职业资格证的进展情况和典型做法。

2.持续深化商事制度改革，实行多证合一等进展情况和典型做法。

3.全面推行“双随机、一公开”监管，推进综合执法改革，运用大数据等推动监管创新的进展情况和创新做法。

4.大力推行“互联网+政务服务”，优化再造服务流程和服务平台的创新做法、典型案例、困难问题及建议。

5.开展减证便民专项行动，全面清理各类证明和手续的典型做法和经验成效。

6.推动钢铁、煤炭等行业化解过剩产能进展情况，以及妥善安置去产能下岗职工的进展情况、典型做法、遇到的困难问题和建议。

7.降低企业特别是国有企业负债水平，积极稳妥降低企业杠杆率，推进市场化债转股等工作的进展、典型案例、面临的困难问题及建议。

8.规范清理各类涉企收费，降低融资、交易、用能、物流等成本，减轻企业非税负担，为制造业发展营造更好营商环境的主要做法、典型案例、遇到的困难问题及建议。

9.突出重点补短板，精心实施促进民营经济发展、提高城乡居民可支配收入等举措进展情况、面临的困难问题及建议。

10.推进财税体制改革，盘活财政沉淀资金，完善营改增试点政策，扩大减税效应等进展情况、取得的成效、遇到的困难及建议。

11.依托“互联网+”发展信息经济和分享经济，加快建设电子商务平台、农村物流配送体系建设进展情况。

12.我省供给侧结构性改革去杠杆行动计划实施情况、取得的成效、面临的问题及建议。

三、关于释放内需潜力

1.创新投融资方式，大力推进政府和社会资本合作（PPP）模式的进展情况、经验做法、典型案例和取得的成效。

2.进一步加大医疗、养老、教育培训、文化、体育等社会领域简政放权力度，放宽市场准入，激发民间投资活力的进展情况、经验做法、面临的困难问题及建议。

3.加快解决拖欠民营企业工程款、采购款、保证金等问题的进展情况、典型做法、面临的困难问题及建议。

4.加快建设汉中至宝鸡高速公路进展情况；西成高铁、宝汉高速汉中以北段等44个收尾项目阳安二线、西镇高速等101个续建项目，天汉大剧院、244国道汉台至南郑一级公路等60个计划新开工项目，秦巴深山公路环线、民用货机研制等99个前期项目等进展情况及存在问题、建议。

5.积极推进全光纤网络城市、热点区域无线网络覆盖，构建高速、移动、安全、泛在的新一代信息基础设施建设进展情况。

6.城市地下综合管廊及海绵城市试点项目建设情况、面临的困难问题及建议。

7.引汉济渭等重大水利项目建设进展情况、面临的困难问题及建议。

8.积极运用信息技术，推动交通出行、房屋住宿、生活服务等领域管理和营销模式变革，培育健康、养老、家政等新的消费增长点情况。

9.加快城乡流通网络一体化建设，推动电子商务进农村、进社区进展情况、面临的困难问题及建议。

10.加快推进陕南绿色循环发展情况、面临的困难问题及建议。

11.持续推进“全域旅游工程”，加快国家全域旅游示范市创建步伐，完成年度投资195亿元，全力推进30个重点文旅项目建设进展情况；推动汉中天坑地质遗迹旅游开发和“大汉中、古栈道”文化旅游品牌建设情况；全力推动兴汉新区核心文化景区、滨江新区天汉文化公园等项目建设情况；加快紫柏山、华阳、黎坪、青木川景区创5A步伐工作进展情况；加快藏羌彝文化产业走廊等重大项目和龙岗遗址文化生态园等产业园区建设情况。

12.加快亿丰国际商贸城、普汇中金世界港以及社区便民消费工程、农村商品和农产品流通网络项目建设情况；实施农村市场建设项目情况。

四、关于结构转型升级

1.大力实施“中国制造 2025”和“互联网+”行动，推动制造业和互联网深度融合发展，运用新技术、新业态全面改造提升传统产业，促进实体经济转型升级的进展情况、主要做法、遇到的困难问题及建议。

2.新技术、新产业、新业态、新模式发展动向，以及扶持“四新”经济发展采取的主要措施。

3.认真落实工业稳增长促投资措施；大力推进航空智慧新城等22个重点园区晋档升级，着力培育七大战略性新兴产业、五大工业集群，以重点领域转型升级带动全部工业提质增效工作情况；抓好陕飞运X飞机生产及总装扩能配套、燕航精工年产10万台汽车自动变速器生产线等一批重点技改项目进展情况；全年培育中小微企业2000户、中小企业梯队企业10050户、瞪羚企业30户、规模以上企业3010户工作进展情况。

4.用好军民融合产业基金，建设国家军民融合知识产权协同运用示范基地，组建军民融合产业联盟，培育一批“民参军”、“军转民”企业进展情况、面临的困难问题及建议。

5.大众创业、万众创新的新情况新趋势，特别是创新创业的典型案例、相关群体诉求、支持新创办小微企业发展的 创新做法和取得的成效。

6.发挥天使投资、风险投资、科技成果转化引导基金作用，促进科技与金融紧密结合，大力培育高新技术企业、瞪羚企业，促进高成长性中小企业加快发展情况。

7.全力推进滨江新区、龙岗新区开发和东关、南关等十大棚改街区改造，打通汉宁路、望江路等断头路等项目进展情况；抓好48个农村社区服务中心、2个街道社区服务中心、22个社区服务站、4个社区室外活动广场建设情况；加快打造10条美丽乡村风景线和20个旅游精品村，新启动100个美丽乡村示范村，建设500个清洁乡村、300个生态乡村、100个幸福乡村、50个魅力乡村工作进展情况、存在问题及建议。

五、关于“”工作

1.推进土地承包权有偿退出、经营权抵押贷款试点，支持新型农业经营主体、社会化服务组织开展土地经营权流转、股份经营、托管经营等多种形式的规模经营情况。

2.严守耕地红线，全面建立基本农田保护责任区制度，实施整镇连片现代粮食基地建设情况。

3.扩大猕猴桃、桔子、樱桃、核桃、梨等果业种植规模及经济效益情况。

4.大力发展设施农业，支持特色养殖、绿色蔬菜、花卉苗木和木本油料产业发展情况。

5.积极发展多种形式的适度规模经营，加快运用现代技术、现代装备、现代组织方式发展现代农业的进展情况和典型做法。

6.深化农村产权制度改革，统筹推进农村土地征收、集体经营性建设用地入市和宅基地制度改革试点的主要做法、取得的进展、出现的新情况新问题及相关建议。

7.我省实施产业融合发展“十县百镇千村”示范工程，农村一二三产业融合发展试点情况。我市突出抓好十大绿色农产品基地建设、深入开展市级示范家庭农场和合作社创建、大力发展休闲农业工作情况。

8.推进农村环境突出问题综合治理和退耕还林等工作的进展情况、主要做法、遇到的困难问题及建议。

9.抓好夏秋粮收购和冬春农业生产，特别是抓好冬种和越冬作物田间管理的工作情况、面临的困难问题及建议。

10.加快建设农产品质量安全追溯体系、监管体系、信用体系的主要措施、经验做法和推进中的困难问题及建议。

六、关于对外开放

1.“一带一路”交通物流、科技创新、产业合作、文化旅游和金融合作五大中心建设进展情况。

2.扩大对外开放，积极利用外资，降低外资准入门槛，打造更有国际竞争力的投资环境的进展情况和经验做法。

3.支持优势企业参与国际产能和现代农业合作情况，在国外设立经贸合作园区建设进展情况。

4.实施名牌产品出口暨外贸孵化工程，扩大装备制造、新材料等产品出口情况。

5.2017丝绸之路国际博览会暨第21届中国东西部合作与投资贸易洽谈会筹备情况。

七、关于环境保护

1.中央环保督察问题的整改落实情况。

2.全面实行河长制，开展重点流域综合治理，推进水污染防治工作进展情况、主要做法及取得的成效。

3.今冬明春大气污染联防联控十大专项行动开展情况、取得的成效及经验做法。

4.实施天然林保护、防护林和退耕还林等工程进展情况。

5.开展土壤污染状况详查，建立污染地块名录及开发利用负面清单，推动土壤污染治理与修复试点的进展情况、经验做法、困难问题及建议。

6.开展“保发展、治粗放，保安全、治隐患，保生态、治污染”行动和陕南尾矿库专项整治情况。

7.推动新能源汽车产业健康发展，完善补贴政策进展情况、经验做法、困难问题及建议。

8.加强对污染排放高的重点行业的治理，实施工业园区、煤化工基地综合整治，严厉打击环境违法违规行为的典型案例和经验成效。

9.大力推广运用新技术、新装备、新产品，促进传统产业清洁生产、绿色改造的典型做法和成效。

10.加快发展节能环保产业，支持推广节能环保先进技术装备的典型做法和成效。

八、关于民生改善和社会建设

1.治理拖欠农民工工资问题，保障农民工工资支付，维护农民工劳动报酬权益有关工作进展情况。

2.大力实施精准扶贫、精准脱贫各项政策措施，加大易地扶贫搬迁、教育扶贫、健康扶贫力度的进展情况、典型案例、困难问题及建议。

3.促进高校毕业生、农民工、军转干部和退役士兵等重点群体就业创业进展情况、经验做法、困难问题及建议。

4.深入实施健康陕西行动计划，推进全国综合医改试点，建立现代医院管理制度，推进医疗服务价格改革，推动优质医疗资源下沉等工作进展情况。

5.推进城乡医保整合，实施异地就医住院医疗费用直接结算进展情况。

6.加快解决困难群众基本住房问题，进一步做好棚户区改造和住房保障工作的进展情况、困难问题及建议。

7.实施“大秦岭·中国脊梁”文艺创作工程，抓好“百优计划”，健全公共文化服务体系，加强文化活动室、书香三秦、农家书屋、社区博物馆建设情况。

8.深入推进“平安汉中”建设，建立健全风险隐患排查和整改长效机制，防范和有效遏制重大安全生产事故、重大公共安全事故、重大环境事故的典型做法和成效。

9.依法严厉打击各类犯罪活动，打击电信诈骗、非法集资等涉众型经济犯罪的典型做法和成效。

10.困难群体救助、食品安全、安全生产、市场供应等方面突出情况和工作措施。
