# 汉中市人民政府办公室关于配合支持汉台区西乡县开展相对集中行政许可权改革试点工作的通知

市政府各工作部门、直属机构：

根据省委办公厅、省政府办公厅《印发<关于开展相对集中行政许可权改革试点工作的方案>的通知》（陕办字〔2017〕89号）和市委办公室、市政府办公室《关于印发汉台区西乡县<相对集中行政许可权改革试点实施方案>的通知》（汉办发〔2017〕40号）精神，汉台区、西乡县是我市相对集中行政许可权改革省级试点单位。目前，汉台区和西乡县行政审批服务局已挂牌运行，为加快推进改革试点工作，并顺利通过12月省督导评估组的评估验收，现就配合支持汉台区、西乡县开展相对集中行政许可权改革试点工作有关事项通知如下：

一、做好行政许可事项上下衔接

本次改革试点，汉台区共涉及14个部门承担的115项、西乡县15个部门承担的173项行政审批事项（见附表1、2），将统一交由区县行政审批服务局实施，区县相关部门不再行使行政许可权。市政府各部门要高度重视，积极配合支持试点工作，对汉台区、西乡县行政审批服务局申报的各类文件予以认可，建立上下业务对接机制，尤其对项目申报、资金拨付、评比达标等事项给予支持，确保申报审批事项流转顺畅，各审批事项无缝对接、落到实处。

二、做好审批专网端口调整工作

按照省审改办《关于配合相对集中行政许可权改革做好相关审批专网端口调整工作的函》（陕审改办函〔2017〕49号）要求，市级有关部门要尽快与省级主管部门联系对接，将划转至汉台、西乡行政审批服务局的行政审批事项，涉及专网申报系统中的发证机关变更为汉台区、西乡县行政审批服务局，并赋予承办事项应有的系统操作权限。同时，要及时落实省、市行政许可相关政策，加大业务指导和培训力度，提高区县行政审批服务局行政效能。

三、建立行政审批和监管衔接配合机制

按照“谁主管、谁监管，谁审批、谁负责”的原则，汉台区、西乡县行政审批服务局依据相关职能部门提供的审批标准实施标准化审批，并承担审批主体责任和行政应诉，原相关职能部门承担审批事项事中事后监管的主体责任，区县政府和市政府业务主管部门承担行政复议职责，建立健全规范高效的审批与监管、行政应诉与复议衔接配合机制。
