# 汉中市人民政府办公室关于认真做好2017年第三季度追赶超越目标完成情况审计发现问题整改工作的通知

汉中经济开发区管委会，滨江新区、兴汉新区、航空智慧城管委会：

根据《审计法》有关规定和市政府主要领导的批示精神，市政府办公室对市审计局《审计报告》（汉审字〔2017〕93号）反馈问题进行了认真梳理，形成了《四个开发区2017年第三季度追赶超越目标完成情况审计发现问题整改任务分工》，现将其印发给你们，请按整改目标、时限要求抓好落实。为确保整改工作有序推进，现就有关事项通知如下：

一、落实整改责任。认真整改审计查出问题，是国家有关法律的明确规定，是被审计单位的职责所在。四个管委会要主动承担主体责任，全力抓好整改落实。特别是主要负责同志作为“第一责任人”，要高度重视、率先垂范，做到高位推动、高效推进，确保整改工作有力有序进行。

二、认真扎实整改。对审计查出问题，四个管委会要建立审计整改消号制度，紧盯不放，抓好整改，做到事事有回音、件件有落实。对暂时不能全面整改到位的，要制定计划，限期整改；对反复出现的，要分析原因、健全机制，从源头上落实解决问题的根本措施，不断扩大审计监督成效。

三、及时报告结果。四个管委会要认真落实和严格执行审计发现问题整改情况报告制度，在抓紧整改审计反馈问题的基础上，按照时限要求及时向市政府报送审计整改情况、整改中存在的问题以及进一步加强审计整改工作的建议等，同时抄送市审计局、市政府督查室。

汉中市人民政府办公室

滨江新区项目建设资金缺口大、融资渠道单一，符合条件担保平台少。受财政部《关于进一步规范地方政府举债融资行为的通知》（财预[2017]50号）和《关于坚决制止地方以政府购买服务名义违法违规融资的通知》（财预[2017]87号）文件影响，建信信托12.5亿元基础设施建设基金融资受阻。PPP项目对合法性要求严格，报批周期长、争报项目多、需当地财力保证，同时社会资本与政府出资仅占总投资约三成，剩余部分投资靠金融机构贷款；政府购买服务仅适用于棚改、扶贫、海绵城市和地下综合管廊等项目，致使滨江新区天汉大剧院、天汉楼及附属建筑群等项目资金缺口达10亿元以上。虽然通过地方金融机构及基金中介机构进行融资是破解融资难的有效途径，但需要信用等次2A以上平台公司担保，而目前全市2A以上平台公司仅市城投公司一家，迫切需要对现有平台公司进行评级、增信。

滨江新区存在合作协议纠纷和资产回购风险。2013年9月27日汉中滨江实业公司与汉中市鹏程置业发展有限公司（以下简称鹏程置业）签订天汉文化公园E区业态项目合作开发协议，滨江实业公司负责E区证书办理，以及土地出让金、城建配套费等费用缴纳，鹏程置业负责E区房建的施工、质量管理、向施工单位支付工程款和业态销售等事项。协议约定项目建成后，滨江实业公司按实际建筑面积（5160元/平方米）收取鹏程置业楼面价款。因E区房建项目证件办理滞后、E区商铺销售不理想，鹏程置业公司资金链出现问题，拖欠施工方工程款，导致施工方多次上访讨要工程款。2017年7月25日，鹏程置业申请退出合作开发协议，解除合作开发协议并由滨江实业公司以审定造价回购E区全部楼盘。截止审计日，鹏程置业未支付滨江实业公司楼面价款。
