# 汉中市人民政府办公室关于进一步加强校园安全管理工作的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

为深入贯彻落实中共中央、国务院《关于推进安全生产领域改革发展的意见》和中、省关于加强校园安全管理的部署、要求，有效防范和遏制校园安全事故的发生，确保广大师生的生命财产安全，维护社会和谐稳定，现就进一步加强校园安全管理工作有关事项通知如下：

一、切实增强校园安全工作的紧迫感和责任感

校园安全事关广大青少年的健康成长，事关千家万户的幸福，事关经济社会发展稳定大局，社会关注度高、敏感性强、影响面广。当前，我市中小学、幼儿园等校园及周边安全总体态势保持稳定。但必须清醒地看到，影响学校及周边安全稳定的因素相对复杂，校园安全隐患在一定程度上仍将长期存在，维护校园安全的工作形势依然严峻，任务十分繁重。各县区、各有关部门要充分认清当前我市校园安全管理工作面临的严峻形势，深刻汲取近年来校园安全事故教训，站在保障师生安全、促进教育发展、维护社会大局稳定的高度，切实增强做好校园安全管理工作的紧迫感和责任感，把校园安全管理工作摆在更加突出的位置，坚决防止校园及周边各类安全事故的发生，全力维护社会安全稳定。

二、全面落实校园及周边安全管理工作责任

校园安全管理是一项系统工程，市级有关部门要结合工作职责和季节特点，密切协作，合力抓好学校安全管理工作，加快建立完善“政府统一领导、部门联防联动、社会广泛参与”的管理体制和运行机制。

（一）教育部门：要全面掌握学校、幼儿园安全工作状况，加强对校园安全工作的检查指导，督促学校、幼儿园落实校园安全主体责任，建立健全安全管理制度，及时排查整治校园安全隐患，加强对学生的安全教育、法治教育和心理健康教育，组织开展应急疏散演练，增强学生的安全防范意识和自我保护能力。

（二）公安部门：要加大对学校幼儿园内部安全保卫、消防安全工作的指导、检查和监督。依法打击侵害学校及师生合法权益的各种违法犯罪行为。加大校园周边的巡逻管控力度和频次，严厉打击针对师生的抢劫、绑架、暴力伤害、敲诈勒索等侵害人身和财产安全的各类违法犯罪行为。依法在学校门前及周边道路设置规范的交通警示标志、标识、标线、信号灯，加强上学、放学时段交通秩序维护，依法打击校园周边非法营运车辆搭载中小学生的行为。

（三）交通运输部门：要科学规划设计校园周边道路及配套设施，根据需要设置减速带、过街天桥、施划人行横道等设施。加强对载运学生车辆、船舶的安全管理，对无牌无证、不符合安全标准的依法予以取缔，及时制止和查处超载等违法行为。

（四）文化广电新闻出版部门：要严格校园周边游戏厅、台球厅、网吧、游艺室、图书及电子音像零售点、报刊亭、歌舞厅等娱乐场所的审批管理。依法查处接纳未成年人进入的网吧等娱乐场所，依法取缔学校周边兜售非法出版物的游商和无证摊点，查缴各类非法出版物。广泛开展校园及周边安全宣传，不断提高社会安全防范意识。

（五）食品药品监管部门：要做好学校幼儿园食堂、学生集体用餐配送单位、餐饮服务单位及从业人员准入资格的审核工作，加强对校园食堂食品卫生安全管理的检查、指导。加大校园周边托餐场所的管理，严厉查处各种危害师生安全健康的违法行为。

（六）工商部门：要加强对学校周边市场、经营户的管理，坚决取缔无照经营场所，定期开展执法检查，依法查处在校园周边制售假冒伪劣、过期变质、“三无”产品和从事传销活动等违法行为。

（七）质监部门：要指导学校建立健全特种设备安全管理制度，督促学校定期开展特种设备检测和维护保养。组织开展特种设备安全知识进校园活动，对学校特种设备安全管理、操作人员进行安全教育和技能培训。

（八）司法部门：要指导学校开展法制宣传教育工作，协调落实学校法制副校长及法制辅导员配备，加强法制副校长及法制辅导员管理，督促指导其定期到校开展法制教育活动。为保护师生员工的合法权益提供法律服务，做好有劣迹青少年的帮教和校园及周边矛盾纠纷的排查调解工作。

（九）住房和城市管理部门：要加强对校园周边经营商户的监督检查，规范临街门店经营行为，及时纠正出店经营、占道经营等现象，对违章经营摊点和流动摊贩予以清理和取缔。清理、拆除学校周边各种违法建筑物、构筑物和堆放物。

（十）城乡建设规划部门：要加强对校园及周边建设工程的监督管理，督促施工单位对在建工程内的深基坑、沟槽、水池等设立安全警示标识，落实安全防护措施。

（十一）卫生部门：要指导学校幼儿园加强疾病预防控制和饮用水的卫生监督监测工作。根据不同季节传染病流行特点，确定疾病预防工作重点，指导学校幼儿园建立健全突发公共卫生事件等应急处置机制和报告制度。加强传染病、常见病、地方病的预防知识宣传，指导学校幼儿园对师生进行健康教育。

（十二）水利部门：要做好江河、湖库、渠道、堰塘、涝池等水域隐患排查整治，对易发生溺水事故的水域建立涉水管理台账，做到有警示标识标志、有安全防护和救生设施、有日常巡查看护、有专门人员值守、有应急救援方案。加强河道采砂管理，督促采砂业主及时回填因采砂形成的危险水域。

（十三）国土资源部门：要做好校园及周边滑坡、崩塌、泥石流、地面沉降与塌陷等地质灾害防治工作。

各县区政府要按照“属地管理、分级负责”的原则，对本辖区内校园安全负总责，将校园安全工作列入重要议事日程，加强对本辖区内校园安全工作的统一领导、组织和协调，切实保障校园安全经费投入，及时协调解决校园安全工作中的重大问题。

三、加强组织领导，确保校园安全形势持续稳定

市政府成立全市校园及周边安全管理工作领导小组，由分管教育工作的副市长任组长，市政府分管副秘书长、市教育局局长任副组长，市教育局、公安局、司法局、交通运输局、国土资源局、建规局、住管局、水利局、卫计局、文广新局、食药监管局、质监局、工商局和各县区人民政府负责同志为成员。领导小组下设办公室，办公室设在市教育局，市教育局局长兼任办公室主任。领导小组将定期召开会议，及时通报工作情况，协调解决存在问题，形成各司其职、各负其责、齐抓共管、综合治理的工作格局。各县区、成员单位也要成立相应工作机构，明确职责任务，扎实做好校园及周边安全管理工作。

四、认真组织开展检查考核工作

各级各部门要对照工作职责，团结协作，密切配合，认真组织开展摸排整治工作。对排查出的问题，要建立隐患台账，制定整改方案，逐一整改销号。对反复出现及师生、家长反映强烈的问题，实行重点挂牌督办，严格问责问效。各县区政府、市级有关部门要加快制定完善校园安全工作考核体系，将校园安全管理工作纳入目标责任考核，建立起安全防范长效机制。严格落实安全工作责任制和责任追究制，对未认真履行职责、工作不力、管理不到位等原因造成校园安全责任事故的，严肃责任追究。

各县区人民政府、汉中经济开发区管委会要根据本通知精神研究制定具体实施方案，认真抓好贯彻落实。
