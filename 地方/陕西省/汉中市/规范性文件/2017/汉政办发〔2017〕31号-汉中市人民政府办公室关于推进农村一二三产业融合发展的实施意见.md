# 汉中市人民政府办公室关于推进农村一二三产业融合发展的实施意见

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

为贯彻落实《陕西省人民政府办公厅关于推进农村一二三产业融合发展的实施意见》（陕政办发20178号）文件精神，加快转变发展方式，推进产业转型升级，助力我市“追赶超越”，经市政府同意，结合我市实际，现就推进农村一二三产业融合发展提出以下实施意见。

一、主要目标

坚持以五大发展理念为引领，以市场需求为导向，以完善利益联结机制为核心，以新型城镇化建设为依托，以制度、技术和商业模式创新为动力，转变发展方式，推进农业供给侧结构性改革，补齐一二三产融合发展短板，着力构建农业与二三产业融合的现代产业体系，提高农业接二连三的全产业链收益。到2020年，农村产业融合发展总体水平明显提升，产业链条完整、功能多样、业态丰富、利益联结紧密的新格局基本形成，主要农产品加工转化率达到70%左右。农村居民收入结构更加优化，人均可支配收入达到14000元以上。

二、夯实农村产业融合发展基础

（一）加快农业结构调整。结合汉中实际，按照平川盆地、浅山丘陵、中低山区三维立体布局，围绕粮食主产区、重要农产品生产保护区、特色农产品优势区“三区”建设，不断优化产业布局，着力推进绿色生态农业建设。以平川县区粮食主产功能区建设为重点，加快百万亩优质水稻基地建设，不断优化品种结构，发展优质专用品种，推行绿色生产和机械化节本增效技术，实施藏粮于地、藏粮于技战略，确保粮食供给安全；以重要农产品生产保护区为抓手，加快百万亩双低油菜基地建设，千万头生猪为主的畜牧业基地建设和蔬菜基地建设，促进农旅融合发展，建设种养循环标准化生产基地，推行种养循环标准化生产模式，加快蔬菜提档升级；发挥生态资源优势，建设汉中特色农产品优势区，以洋县有机示范县建设为抓手，加快有机高端农产品培育力度。积极发展牛羊、乌鸡、蜜蜂、林麝、野猪等特色特种养殖；实施柑桔优果工程和猕猴桃东扩南移，加快现代特色果业发展；加大天麻、西洋参、杜仲、元胡、银杏、附子等“汉八味”中药材发展，建立辐射全国的“秦巴天然药库”集散和交易中心；发展林下经济和名优鱼等水产养殖，推广适合精深加工、休闲采摘的农作物新品种。加强农业标准体系建设，严格生产全过程管理。（市农业局、市林业局、市科技局、市水利局、市发改委、市质监局负责，列第一位者为牵头单位，下同）

（二）推进农产品精深加工。完善产业空间布局和功能定位。突出加工园区、主体培育、链条延伸三个重点，按照“初级加工靠近产地、精深加工靠拢城市”格局，结合优势产业布局，积极创建省级农产品加工产业园区；鼓励大型农业企业向优势产区集中，发展精深加工、循环加工，打造特色现代农业产业集群，不断提升主要农产品加工增值水平。以水果、蔬菜、食用菌为主，大力开展产地初加工，鼓励支持家庭农场和合作社建设先进实用的初加工设施。发展大米、菜油、茶叶、生猪、中药等农产品精深加工，提高商品化率和入市品级，延伸产业链条，提高附加值。加快形成产地初加工与精深加工分工合理、优势互补、协调发展的格局。发展“一村一品”、“一乡一业”，加快培育乡村手工艺品和农村土特产品；注重品质、品相、品牌、品位“四品结合”，挖掘品牌价值，打造“汉字号”知名品牌；推进生猪产业联盟建设，加快粮油、畜禽、茶叶、魔芋、食用菌、汉中大鲵、中药材等农产品全产业链开发，提高农产品加工转化率和附加值；围绕“一带一路”，加快培育柑桔、茶叶、食用菌和山野菜出口基地，培育一批自主品牌和较强竞争力的骨干企业，增强国际竞争力。（市发改委、市科技局、市财政局、市国土局、市农业局、市水利局、市商务局、市工商局负责）

（三）发展社会化服务业。发展农村电子商务、农超对接、直供直销、连锁经营等现代流通方式，搭建农产品营销“线上线下”交易平台，培育农产品电子商务主体和优质农产品品质，大力发展县、镇、村三级电商运营配送体系。建立农产品身份识别、质量安全内控和追溯体系。 加快农产品冷链物流、共同配送及县区物流分拣配送中心体系建设，推进市场流通体系与储运加工布局有机衔接。落实支持新型农业经营主体的用地政策。健全农产品产地营销体系，推广农超、农企等形式的产销对接，鼓励在城市社区设立鲜活农产品直销网点。鼓励开展代耕代种代收、大田托管、统防统治、烘干储藏等市场化和专业化服务。（市发改委、市财政局、市国土局、市商务局、市农业局、市质监局、市供销社负责）

（四）加快休闲农业和乡村旅游。修订完善市县休闲农业发展规划，突出“规范发展、示范创建、宣传推介”，深挖农耕文化优势资源，发展观光农业、体验农业、创意农业。抓好省级旅游示范县和省级旅游特色名镇、乡村旅游示范村创建，有序发展新型乡村旅游休闲产品，打造参与式生态旅游综合体及小众产业，建设民俗农庄和农耕文化体验馆，包装打造一批茶园游、果园游、城郊游等精品休闲农业线路。组织开展特色旅游文化节、民俗文化节等主题活动。加强农村传统文化保护开发，配套完善乡村旅游基础设施，实现农区变景区、田园变公园、农房变客房、农产品变商品。发展农产品加工和乡村手工艺等产业，创建“小众”产业示范基地，打造“小众”产业特色品牌。统筹利用现有资源建设农业教育和社会实践基地，引导公众参与农业科普和农事体验。完善休闲农业、乡村旅游等相关标准，健全食品、消防、环境、消费等规范，强化管理服务。迎接高铁时代，建立与西安、成都等地休闲农业产业联盟，构建都市乡村休闲旅游圈。推进农业、林业与休闲旅游、教育文化、养生养老等深度融合。（市农业局、市发改委、市教育局、市财政局、市林业局、市旅发委负责）

（五）大力发展农业新型业态。加快发展互联网＋农业新业态，采用大数据、云计算等技术，改进监测统计、分析预警、信息发布等手段，健全农业信息监测预警体系。推进农业生产、经营、管理和服务信息化建设。发展农田艺术景观、阳台农艺、人工水工程等创意农业。鼓励在城郊发展工厂化、立体化等高科技农业。支持发展农业生产租赁业务，探索农产品个性化定制服务、会展农业、农业众筹、水养殖等新型业态。大力发展农村电子商务，加快农产品电子商务示范县建设，构建市县镇村四级农村电子商务服务平台，实施“快递入村”工程，开展农产品电子商务配送等服务，农村电商人才培训培养。落实定向减税和普遍性降费政策，降低创业成本和企业负担。（市农业局、市发改委、市科技局、市工信委、市财政局、市商务局负责）

（六）着力推进新型城镇化建设。推进城乡一体化发展，依托特色产业，培育产业文化旅游三位一体、生产生活生态同步改善、一二三产深度融合的特色村镇。加快基础设施和公共服务设施建设，完善服务功能，提升承载能力，引导人口、产业、公共资源等要素向特色镇、重点镇集聚，推进省级重点示范镇和文化旅游名镇建设，培育县域副中心。建立购租并举的住房制度，加快农业转移人口落户城镇。推进城镇基本公共服务常住人口全覆盖，推动城乡最低生活保障制度统筹发展，完善城乡特困人员供养制度，加大受灾、教育、住房、就业和临时救助力度，健全重特大疾病、疾病应急、贫困人口医疗等救助制度体系。（市发改委、市民政局、市人社局、市规划局、市住管局、市商务局、市卫计局负责）

三、培育农村产业融合主体

（七）强化农民合作社和家庭农场基础作用。鼓励大中专毕业生、新型职业农民、务工经商返乡人员领办农民合作社、兴办家庭农场。引导农民合作社、家庭农场积极发展农产品加工、销售和农产品直销。支持符合条件的农民合作社、家庭农场优先承担政府涉农项目，落实财政项目资金直接投向农民合作社、形成资产转交合作社成员持有和管护政策。积极开展省级示范合作社创建申报和市级示范社提升行动。在依法、自愿、有偿前提下，引导土地流向农民合作社和家庭农场。（市农业局、市财政局负责）

（八）支持龙头企业发挥引领示范作用。鼓励农业企业向优势产区集中，打造特色现代农业产业集群。拓展农业园区功能、完善产业体系、培育产品品牌，支持做大做强“汉字号”农业品牌。推进园区转型升级。完善和推广产业联盟模式，建设标准化和规模化原料生产基地，引导农业产业化龙头企业重点发展农产品加工流通、电子商务和农业社会化服务，带动农民和农民合作社发展规模种养业、农产品加工业和农村服务业。鼓励龙头企业建设现代物流体系，健全农产品营销网络。（市农业局、市商务局、市供销社负责）

（九）发挥供销合作社综合服务优势。支持供销合作社拓展经营领域，在农资供应、农产品流通、农村服务等重点领域和环节为农民提供便利实惠、安全优质的服务。推动供销合作社与新型农业经营主体有效对接，培育大型农产品加工、流通企业。推进供销合作社实体经济与电子商务融合发展，实现“线上线下、互动联通”。支持供销合作社创办领办农民合作社、合办联合社，引领农民参与农村产业融合发展、分享产业链收益。（市供销社负责）

（十）积极发展行业协会和产业联盟。充分发挥行业协会自律、教育培训和品牌营销作用，开展标准制订、商业模式推介等工作。鼓励农业园区、企业与涉农院校及科研院所加强合作，围绕“汉字号”特色名优农产品，鼓励发展行业协会、产业联盟，支持联盟成员通过共同研发、科技成果产业化、融资拆借、统一营销等方式，实现信息互通、优势互补。（市农业局、市民政局、市科技局负责）

（十一）鼓励社会资本投入。鼓励各类社会资本投向农业农村，发展适合企业化经营的现代种养业，利用农村“四荒”资源发展多种经营，开展农业环境治理、农田水利建设和生态修复。对社会资本投资建设连片面积达到一定规模的高标准农田、生态公益林等，给予政策支持。深入开展农村“双创”活动，全面开放商业化运营的农村服务业。积极引导外商投资农村产业融合发展。（市发改委、市财政局、市国土局、市环保局、市水利局、市农业局、市林业局、市商务局负责）

四、建立多形式利益联结机制

（十二）创新发展订单农业。引导龙头企业在平等互利基础上，与农户、家庭农场、农民合作社签订农产品购销合同，稳定购销关系，形成风险共担的利益机制。支持龙头企业为农户、家庭农场、农民合作社提供贷款担保，资助订单农户参加农业保险。鼓励农产品产销合作，建立技术开发、生产标准和质量追溯体系。加强汉茶、汉猪、汉米等“汉字号”农业优势特色产业品牌整合，打造联合品牌，实现利益共享。（市农业局、市发改委、市商务局、市工商局、汉中银监分局、市金融办负责）

（十三）鼓励发展股份合作。稳步推进和逐步扩大农村产权流转交易试点，全面完成农村承包地确权登记颁证工作。推行“龙头企业+合作社+农户”模式，大力发展合作经济，打开城乡产业融合通道，实现资源变资本、资金变股金、农民变股东、自然人农业变法人农业。以土地、林地为基础的各种形式合作，凡是享受财政投入或政策支持的承包经营者均应成为股东方，并采取“保底收益+按股分红”等形式，让农户分享加工、销售环节收益。探索形成以农户承包土地经营权入股的股份合作社、股份合作制企业利润分配机制，切实保障土地经营权入股部分的收益。（市农业局、市发改委、市财政局、市国土局、市林业局负责）

（十四）强化工商企业社会责任。鼓励从事农村产业融合发展的工商企业优先聘用流转出土地的农民，为其提供技能培训、就业岗位和社会保障。引导工商企业发挥自身优势，辐射带动农户扩大生产经营规模,提高管理水平。严格龙头企业认定标准，完善健全认定和退出机制，加强动态管理，逐步建立社会责任报告制度。强化龙头企业联农带农激励机制，相关扶持政策与利益联结机制相挂钩。（市农业局、市发改委、市财政局负责）

（十五）健全风险防范机制。探索建设与农业保险担保相结合的土地流转、订单农业等风险保障制度，提高风险防范能力。规范工商资本租赁农地行为，增强新型农业经营主体契约意识，加快建立适合农村特点的信用评级体系。制定和推行涉农合同示范文本，依法打击涉农合同欺诈违法行为。加强土地流转、订单等合同履约监督，建立健全纠纷调解机制。（市金融办、市发改委、市财政局、市工商局、人行汉中支行、市农业局负责）

五、完善多渠道产业融合服务

（十六）搭建公共服务平台。加强农村综合性信息化服务平台建设，为电子商务、乡村旅游、农业物联网、价格信息、市场营销等提供定制化服务。优化农村创业孵化平台，建立在线技术支持体系，提供设计、创意、技术、市场、融资等定制化解决方案及其他创业服务。建设农村产权流转交易市场，引导其健康发展。采取政府购买、资助、奖励等形式，引导科研机构、行业协会、龙头企业等提供公共服务。（市农业局、市发改委、市科技局、市工信委、市建规局、市住管局、市商务局负责）

（十七）创新农村金融服务。发展农村普惠金融，优化县域金融机构网点布局，推进县域村镇银行全覆盖。鼓励金融机构与新型农业经营主体建立紧密合作关系，推广产业链金融模式，加大对农村产业融合发展的信贷支持。稳妥有序开展农村承包土地经营权、农民住房财产权抵押贷款试点。完善农业保险制度，丰富农业保险产品，开发满足新型农业经营主体需求的保险产品，鼓励金融机构积极利用互联网技术，为农业经营主体提供小额存贷款、支付结算和保险等金融服务。扩大农业保险覆盖面。严厉打击农村非法集资和金融诈骗。（人行汉中支行、市发改委、市财政局、市农业局、汉中银监分局、市金融办负责）

（十八）强化人才和科技支撑。加快培育面向农村的实用人才和新型职业农民。健全科技创新体系,完善农业科技创新激励机制，加快农业机械化进程。深化与西北农林科技大学、陕西理工大学及科研院所合作，开展产业融合发展的科技创新，积极开发农产品加工贮藏、分级包装等新技术。加强以青年为重点的农村电商人才培养。鼓励农业企业发展产品加工业，延长产业链，提高农产品附加值。落实省市促进科技成果转化有关政策，建立农业科技人才正向激励机制，健全县、镇农业科技推广服务体系，鼓励各类科技人员、大中专毕业生到农村创业创新，在农业企业任职兼职，将现代农业技术、生产方式和经营模式引入农村。（市教育局、市发改委、市科技局、市人社局、市农业局负责）

（十九）改善农村基础设施条件。实施“整治农村环境、优化旅游环境”活动，推进农村环境综合整治和生态保护，实现“清洁农村”建设目标。抓点示范、以线串点、点线带面，梯次推进美丽乡村建设，加快完善农村水、电、路、通信等基础设施。完善休闲农业和乡村旅游道路、供电、供水、停车场、观景台、游客接待中心等配套设施。高标准打造美丽乡村示范村、旅游精品村、风景线。统筹规划建设农村物流设施，逐步健全以县、乡、村三级物流节点为支撑的农村物流网络体系，打造具有影响力的特色农产品集散中心、价格形成中心、物流加工配送中心。（市发改委、市工信委、市财政局、市交通局、市水利局、市农业局、市商务局、市旅发委负责）

（二十）支持贫困地区农村产业融合发展。落实省市《关于贯彻落实〈中共中央国务院关于打赢脱贫攻坚战的决定〉的实施意见》精神，引导和支持贫困地区立足当地资源优势，发展特色种养业、农产品加工业和农村服务业。要认真梳理发展思路，找准关键环节，统筹用好涉农资金，以项目带动促产业发展和贫困户增收。要积极培育更多的精准脱贫范例和样板，总结推广主体带动型、互助帮扶型、科技引领型、务工输出型、政策驱动型等脱贫模式，加快“造血式”扶贫、精准化脱贫。要以移民搬迁集中安置区为重点，建设现代农业园区和农产品加工园区，搭建搬迁贫困户发展产业、就地就业、创业创新的综合平台，力争贫困县“两园建设”全覆盖。要创新流通新业态，加强农产品流通设施和市场建设，提升农产品产地仓储及物流水平，搞活市场流通，积极帮助农户解决好产品销售问题。创新发展创意农业、农耕体验新业态，打造休闲农业精品；建立各类农村产业融合发展平台，探索以土地、劳力等资源入股带动贫困户的利益连接新机制，为农民增收拓展更大空间。支持企事业单位、社会组织和个人投资贫困地区农村产业融合项目，推进精准扶贫、精准脱贫。（市扶贫办、市发改委、市农业局、市国土局负责）

(二十一)加强农村物流体系建设。开展电子商务示范县、点创建活动，加快完善农产品流通设施布局，建立健全以县、乡、村三级物流节点为支撑的配送网络体系。实施优势农产品储藏营销设施补助项目，加强农产品产区预冷、保鲜、烘干等仓储物流设施建设，支持合作社发展直供直销，降低农产品物流成本。支持供销合作社、邮政物流、粮食流通、大型商贸企业等参与农产品批发市场、仓储物流体系建设。鼓励民营资本与农民合作社合作建设名特优农产品配送中心，支持大型超市在优势农产品产区建设直接采购基地。(市商务局、市交通局、市农业局、市供销社负责)

六、健全推进农村产业融合机制

（二十二）加大财税支持力度。财政部门在现有资金渠道内安排资金支持农村产业融合发展试点，涉农资金要向农村产业融合发展项目倾斜。改革财政支农投入使用机制，调整优化部分存量资金和新增补贴资金，对各类从事农村产业融合发展的新型农业经营主体予以倾斜。通过政府与社会资本合作、政府购买服务、担保贴息、以奖代补等方式，带动金融和社会资本投向农业农村。（市财政局、市发改委、市地税局负责）

（二十三）开展试点示范。围绕产业融合模式、主体培育、政策创新和投融资机制，开展农村产业融合发展试点示范，理顺政府和市场关系，完善体制，创新机制，促进农村产业融合加快发展。积极争取省农村产业融合发展“十县百乡千村”试点示范工程，积极探索和总结成功做法，形成可复制、可推广的经验。（市发改委、市财政局、市农业局、市商务局、市旅发委负责）

（二十四）强化组织保障。各县区政府要加强组织领导，把推进农村产业融合发展摆上重要议事日程，纳入经济社会发展总体规划、年度计划和年度目标责任考核。要强化主体责任，制定具体实施方案，引导资金、技术、人才等要素向农村产业融合集聚。各有关部门要抓紧制定和完善相关政策措施，密切协作配合，确保各项任务落实到位。
