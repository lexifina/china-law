# 汉中市人民政府办公室转发人行汉中市中心支行关于金融支持电子商务发展指导意见的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

人行汉中市中心支行《关于金融支持电子商务发展的指导意见》已经市政府同意，现转发给你们，请结合实际，认真抓好贯彻落实。

汉中市人民政府办公室

2017年6月7日

关于金融支持电子商务发展的指导意见

中国人民银行汉中市中心支行

为进一步提升金融创新和服务水平，加大金融支持力度，加快推进全市电子商务发展，按照市政府《关于大力发展电子商务加快培育经济新动力的实施意见》（汉政发〔2016〕29号）精神，现就金融支持电子商务发展提出如下意见。

一、加快金融支持电子商务发展

近年来，随着“互联网+”战略的大力实施，网络经济与实体经济深度融合，电子商务的发展改变了企业传统经营模式和公众消费方式，加快了要素流动，释放了经济新动能，具有重要的战略意义。各金融机构要充分认识到二、明确支持重点，提升服务水平

（一）重点领域加大信贷投放。一是积极参与电子商务产业园建设。重点加大对江南电子商务产业示范园、江北网络电子商务产业园和小微企业孵化创业园的信贷投入，带动全市电子商务产业园区发展。探索电子商务园区主办行制度，对园内优质企业适当降低抵押担保要求，通过“园区贷”、“助保贷”等政府增信模式向入园企业发放信用贷款，为企业提供结算、融资等全方位金融服务。二是着力打造特色电商品牌。积极满足柑桔、有机大米、中药材等汉中名优农特产品在种植、加工、营销等环节的资金需求，支持县区政府在国内知名电商平台开设“地方特色馆”，打响“汉”字号品牌。三是加大对电子商务综合应用平台的支持。充分发挥互联网金融优势，通过提供结算、融资、咨询等金融服务，加大对农业龙头企业的金融支持力度，培育一批具有汉中特色和城市品牌的电子商务综合应用平台。四是大力支持网络零售业发展和传统零售业转型升级。大力发展票据融资、网络贷款、“POS”贷等适合网络零售业特点的结算和融资服务，支持传统零售业采取线上线下相融合的模式，实现网络化销售，优化供应链，扩大销售市场，满足传统零售业转型升级资金需求。五是加大对电子商务物流配送行业的支持。重点跟进满足褒河物流园区等专业园区、电子商务物流中心建设和电子商务企业自建仓储的资金需求，支持现代物流体系发展。

（二）完善电商信贷管理制度。各银行业金融机构要根据电子商务发展特点，创新和完善信贷管理制度，将企业电子交易信息纳入信贷管理全流程，充分运用大数据、云计算等技术，创新符合电子商务企业特点的信贷产品。建立与电子商务发展相适应的信用评级、业务审批、风险控制、内部激励约束等机制，合理确定电子商务企业贷款利率，提高金融与电子商务发展的融合度。

（三）创新电商服务金融产品。各银行业金融机构要加强信贷产品创新，开发与电子商务发展相适应的特色化信贷产品。对电子商务重点建设项目，各金融机构可为其提供银团贷款；对小微电子商务企业，创新抵质押担保模式，适当提高抵质押率，开展基于供应链融资的应收账款、订单、仓单、保单等质押贷款；大力发展金融仓储模式，加强与信用等级高的物流仓储公司合作，发展存货动态质押、物流保理、票据承兑等业务，满足电商物流全流程融资需求；为优质电子商务企业和信用等级高的网上个人零售业主办理信用贷款。可充分发展“融e购”、善融商城等自有网购平台，利用“善融贷”、“循环贷”等信贷产品为入驻企业提供信用贷款，解决企业短期流动性问题。

（四）拓宽电商企业融资渠道。各银行业金融机构要建立适应电子商务发展的多元化投融资机制，加大企业债务融资和股权融资工具的宣传、推介和承销力度，有针对性地挖掘、培育和支持电子商务企业在银行间债券市场发行短期融资券、中期票据、非公开定向债务融资工具和资产支持票据等非金融企业债务融资工具。支持有实力的电子商务企业开展股权融资，在主板、中小板、区域股权交易中心等挂牌上市，拓宽融资渠道和规模，降低融资成本。各县区政府要设立电子商务发展专项资金，专项用于电子商务企业技术创新、传统企业电子化改造等项目。

三、大力发展农村电商助推精准扶贫

（一）积极支持涉农电子商务发展。各县区政府应积极与京东、苏宁、农村淘宝、“乐村淘”等国内知名电商平台开展合作，开设特色农产品网上销售平台。各银行业金融机构要主动为平台内企业提供结算、融资等金融服务，要通过农户小额信用贷款、创业担保贷款、精准扶贫担保基金贷款等信贷产品，满足县级电商管理服务中心、镇（街道办）电商服务配送站点和村级电商体验店的建设资金需求。推行农村电商主办行制度，按照“一县一业”、“一村一品”产业布局，加大对当地特色优势产业的信贷支持，适当降低抵押物标准，降低贷款利率，延长贷款期限。

（二）创新电商扶贫模式。各银行业金融机构要结合各县区政府确定的扶贫目标和实施方案，创新“精准扶贫+农村电商+绿色金融”的农村电商扶贫模式，将绿色食药、文化旅游行业作为信贷投放重点，将电商扶贫纳入扶贫信贷重点支持范围，为推进电子商务精准扶贫工作提供全方位的金融服务。对从事特色农产品种养殖的贫困户，通过发放精准扶贫担保基金贷款、创业促就业贷款等给予资金支持，对开办网店、从事农产品网络销售的农户和吸纳贫困户就业、代理销售农产品的优质企业，给予免抵押、免担保小额信贷支持，争取农业、扶贫、电商等配套政策扶持。针对电子商务企业和个人资金需求特点，开发小额循环贷款，对政府相关部门认定的优质电商企业，开通信贷审批绿色通道。

（三）积极支持电商示范县建设。各银行业金融机构要加大对略阳县、洋县国家电子商务进农村综合示范县和留坝县省级电子商务示范县建设的金融支持力度，力争形成可复制、可推广的金融服务电商模式。加强与政府相关部门合作和信息共享，充分发挥电子商务发展资金的撬动作用，扩大对农村电商企业和本地电商平台的信贷投放，争取上级行政策支持，在风险可控前提下，创新存货、订单、应收账款等抵质押和担保模式，先行先试，紧密契合电商企业不同发展阶段、不同类型和期限的资金需求。

四、大力支持跨境电子商务发展

（一）鼓励开展跨境电商业务。各银行业金融机构要主动对接外贸企业和电子商务企业，营销跨境金融服务，积极落实跨境电子商务外汇管理便利化措施，简化进出口收付汇业务办理手续，优化服务流程，支持本地企业通过电子商务“走出去”。要进一步加强与商务、出入境检疫、税收、财政等部门政策衔接，提高全市跨境电子商务便利化水平。根据跨境电子商务特点，引入保险机构为电商企业开发出口信用保险，提高企业出口竞争力，防范跨境贸易风险。

（二）大力推动跨境电子商务平台发展。各银行业金融机构要加强与各类跨境电子商务平台的合作，加快跨境金融产品创新，提升跨境金融服务水平，为跨境电子商务和跨境人民币结算业务提供便利。组织银行业金融机构宣传和推介“通丝路”陕西省跨境电子商务结算平台，鼓励企业积极入驻，并为其提供跨境人民币结算和跨境融资服务，帮助企业拓宽销售市场，规避汇率风险，降低财务成本。

五、拓宽电子商务支付渠道

（一）深化电子支付业务创新和应用。各银行业金融机构要针对电子商务企业特点，加快企业网银、单位结算卡、快捷支付等电子支付产品创新，完善网上银行、手机银行、微信银行等业务种类和功能，加快发展网络融资、灵活理财、实时转账等线上金融服务，将电子支付与网络信贷有效对接。加快个人电子支付业务发展，优化支付系统界面和功能，提升客户体验，满足B2C、C2C业务及跨境消费的结算需求。

（二）改善农村地区支付环境。各银行业金融机构要加大农村地区支付基础设施投入，合理配置ATM、POS机等自助设备，加快贫困村村级电商服务点、助农取款服务点建设；充分利用农村地区现有网络通信设施，大力发展网上支付、手机支付等各类新型支付工具；大力推广银行卡业务，扩大银行卡受理范围，发行面向“三农”、具有便农惠农特色的银行卡，结合各项政策补贴，推广非现金支付工具农户一卡通、惠农卡等，全面提升农村地区现代化支付水平。

（三）加强第三方支付体系建设。各银行业金融机构要加强与第三方支付机构的深度合作，创新电子票据、电子钱包等新型支付工具。鼓励已获得人民银行支付业务许可证的第三方支付机构在我市设立分支公司，促进本地支付服务环境的优化。通过与第三方支付机构签约结算协议、协助企业开发电子商务平台等方式，构建安全、便捷、稳定的网上支付体系。

六、加强电子商务信用体系建设

（一）加强电子商务信用体系建设。探索将电子商务企业的信用信息纳入中小企业信用信息管理系统，完善电子商务企业信用分级分类管理制度，建立电子商务信用信息共享机制，通过与人民银行征信系统对接，实现对电子商务企业及企业主个人信用状况的综合分析。各银行业金融机构可综合运用内外部信用评级结果对电子商务企业开展综合评级，优先对信用等级高的电子商务企业进行信贷支持。

（二）切实防范互联网金融风险。银行业金融机构要加强业务培训，掌握电子商务经营特点和互联网金融风险特点，完善信贷风险管理体制，提高风险识别能力和控制能力，切实防范电子商务信贷风险和互联网金融风险，促进电子商务金融服务健康有序发展。

七、健全电子商务发展的配套机制

（一）建立部门协调和信息共享机制。各县区政府要加快建立由人社、商务、税务、质监、食药监管等部门组成电商跨部门协调工作机制，开设联合办公窗口，统筹推进电子商务发展工作。配套建立电子商务发展工作考核机制，将任务分解落实到具体部门。定期组织召开电子商务企业政银企座谈会，加强政银企三方信息共享，减少信息不对称。

（二）加强扶持政策的协调配合。各银行业金融机构要按照全市产业规划和布局，加大对农村电商、现代物流等重点领域的信贷支持，积极推动信贷政策与财政、税收、扶贫政策的协调配合。对电子商务发展支持较多的银行业金融机构，可通过再贷款、再贴现等货币政策工具给予支持，切实增强电子商务信贷投放力度，降低电商企业融资成本。

（三）支持电子商务领域就业创业。各银行业金融机构要加强与人社、商务等部门合作，充分利用就业创业相关政策，优先为符合条件的贫困地区高校毕业生、返乡创业青年和网络商户等提供创业担保贷款，支持贫困村青年、妇女、残疾人依托电子商务就业创业。相关部门要组织开展专业技术、经营管理、税收、金融等电子商务相关知识培训，提高电子商务企业和个人的经营能力和防风险能力。
