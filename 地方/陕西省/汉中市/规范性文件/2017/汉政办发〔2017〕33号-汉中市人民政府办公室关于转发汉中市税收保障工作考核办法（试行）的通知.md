# 汉中市人民政府办公室关于转发汉中市税收保障工作考核办法（试行）的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

市财政局、国税局、地税局制定的《汉中市税收保障工作考核办法（试行）》已经市政府同意，现转发给你们，请抓好贯彻落实。

汉中市人民政府办公室

2017年6月9日

汉中市税收保障工作考核办法（试行）

市财政局 市国税局 市地税局

为深入贯彻落实《汉中市税收保障办法》，充分调动部门和单位协税、护税工作积极性，客观公正评价部门和单位税收保障工作实绩，制定本考核办法。

一、考核目的

建立完善的税收保障暨综合治税奖惩激励机制，运用有效的考核方法和手段，通过科学、合理的考核指标，全面、准确、客观地评价和反映我市税收保障各相关部门、单位的工作质量和效率，实现信息充分共享、工作有机衔接，税收应收尽收，促进税收保障暨综合治税工作的顺利开展。

二、考核对象

《汉中市税收保障办法》规定的协税护税、信息传递的部门和单位，以及有义务配合财税部门开展税收保障工作的其他部门和单位。

三、考核原则

（一）实事求是原则。以事实为依据，客观公正地评价各涉税部门、单位工作实绩。

（二）公正透明原则。根据各部门、单位承担的协税护税责任，进行公开公平公正考核。

（三）激励奖惩原则。根据考核结果实施奖惩，以充分调动各相关部门、单位和有关人员的工作积极性和主动性。

四、考核内容及标准

考核内容、标准以《汉中市税收保障办法》所规定的涉税信息为主，并根据需要实时更新，实行百分制考核（详见附件1、2），具体内容如下：

（一）组织领导情况：10分。其中，完善工作机制4分、明确专职人员3分、开通报送渠道3分。缺项及未及时报送综合治税工作专职人员变动情况的扣减相应分值，本项分值扣完为止。

（二）涉税信息传递情况： 70分。其中，及时性15分、完整性30分、真实性15分、规范性10分。每发现一项未达到要求，该项一次扣减5分，本项分值扣完为止。

（三）协税护税工作情况： 10分。考核各涉税信息报送部门和单位按照《汉中市税收保障办法》规定，应承担的协税护税责任和相关配合工作的落实情况，一次未做到扣减2分，本项分值扣完为止。

（四）委托代征工作情况： 10分。部门、单位是否按照《汉中市税收保障办法》规定，签订委托代征协议，履行代征代扣税款义务，并按照要求及时足额解缴税款入库，一次未做到扣减5分，本项分值扣完为止。

五、考核方法

考核工作由汉中市税收保障工作领导小组负责，领导小组办公室具体组织实施，采取日常考核和年度综合考核相结合的方法进行。

（一）日常考核。以市综合治税信息平台记录为主要依据，考核部门、单位报送涉税信息等情况。

（二）年终综合考核。主要考核除日常考核以外的其他考核事项。由市税收保障工作领导小组组成考核检查组通过查阅资料、实地核查等形式对协税护税部门工作开展情况进行年度综合考核。

市税收保障工作领导小组根据日常考核、年终综合考核计分汇总出年度考核结果，将考核结果上报市委、市政府，并予以通报。

六、考核等次评定

考核结果分优秀、良好、一般、较差四个等次。

优秀等次：出色完成任务，成绩突出，年度考核得分高于95分（含）且位列前十名的部门、单位。

良好等次：工作比较扎实，全面完成任务，年度考核得分高于90分（含）的部门、单位。

一般等次：基本完成工作任务，年度考核得分高于80分（含）的部门、单位。

较差等次：有下列情形之一的，确定为较差等次。完成任务较差，年度考核得分低于80分的；未及时传递涉税信息、按规定履行保障义务的；造成税收流失的；无正当理由拒绝协助税务机关依法执行公务的。

七、本办法实施时间

本考核办法自2017年7月1日起实施，汉政办发〔2014〕30号文件废止。
