# 汉中市人民政府办公室关于进一步加强科技特派员工作的实施意见

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

为认真贯彻落实《陕西省政府办公厅关于深入推行科技特派员制度的实施意见》（陕政办发〔2017〕4号）精神，深入实施创新驱动发展战略，积极引导各类科技人才面向“三农”开展创新创业和技术服务，实施科技扶贫，培育新型农业经营和服务主体，推动现代农业向全产业链增值和品牌化、高端化发展，经市政府同意，现就进一步加强科技特派员工作提出如下实施意见：

一、主要目标

至2020年，全市建立健全科技特派员选派和服务机制，农村科技创新创业服务平台有效运转，科技特派员服务领域进一步拓展，基本形成以高校、科研院所、农机推广机构、群众团体、农业经营主体、社会化服务机构等单位和各类科技实用人才广泛参与的科技特派员队伍。

（一）市、县区两级每年选派不少于300人的科技特派员队伍，新认定50个以上的法人科技特派员。

（二）全市组建农业科技创新战略联盟550“”20（三）农村创新创业环境更加优化，科技成果评价机制有效实施，农村科技信息服务平台全面建成，在全社会形成浓厚的激励创新创业的价值导向和制度环境。

二、重点任务

（一）壮大个人科技特派员队伍。积极引导和支持高等院校、科研院所等单位的科技人员，以及退休技术人员、大学生、退伍转业军人、农村青年、返乡农民工等具备技术特长的人员，以科技特派员身份到农村开展科技扶贫、技术服务和创新创业。对已入选“三区”（边远贫困地区、民族地区、革命老区）人才支持计划的科技人员、已担任市级首席工程师的科技人员纳入个人科技特派员队伍管理。把市本级选派的科技特派员并入国家“三区”人才支持计划并享受有关政策待遇。

（二）大力发展法人科技特派员。鼓励支持高等院校、科研院所、涉农科技型企业以及科技服务机构等法人单位，依托其辐射性、带动性强和技术、人才集聚优势，作为法人科技特派员带动创新创业，围绕我市主导产业和特色农业产业链开展技术服务。

（三）积极支持科技特派员团队。3人以上的科技特派员团队，瞄准农村、涉农企业等创新发展需求，围绕产业链，拓展创新链，开展技术服务、产品开发和成果转化。

（四）开展反向科技特派员选派。落实市政府与省科技厅会商共识，以推动科技成果转移转化、促进区域协调发展为目标，启动汉中向省科技厅反向选派科技特派员工作，构筑“汉中特色产业需求—科技特派员小组—西安科技成果供给”的供需链深度合作模式，实现汉中市产业需求与全省科技成果的无缝衔接，推动产业创新发展，企业转型升级。

（五）围绕脱贫攻坚创新创业。认真落实市本级科技资金10%用于科技精准扶贫，60%以上的科技精准扶贫计划项目面向建档立卡贫困村的要求，把科技特派员精准扶贫创新创业项目纳入市级科技计划的申报和管理，予以优先支持。支持科技特派员与建档立卡贫困户结对子，精准施策，推进“一户一技能”，增强贫困户自我发展能力，加快脱贫致富进程。

（六）深化开展产学研合作。落实汉中市促进科技成果转化若干规定要求，支持科技特派员与企业开展产学研合作研发和技术服务，申报各级各类技术创新项目。对科技特派员携带科技成果到企业转化，或组织企业实施成果转化、研发新技术和新产品项目优先予以科技计划立项支持，成效显著的给予10万元立项支持。鼓励科技特派员以科技成果和知识产权入股企业，取得合法收益。鼓励支持各类企业吸引科技特派员到企业开展技术创新和研发，建设各类企业研发中心。对科技特派员促成企业与高等院校、科研院所共建的科技创新研发机构，被认定为省、市级科技创新研发机构的，优先享受研发机构扶持政策。

（七）创建创新创业基地。支持个人科技特派员和科技特派员团队围绕现代种业、粮油、蔬果、食用菌、茶叶、中药材、畜禽、渔业等主导农业产业，对接当地需求，建设科技特派员示范基地，依托企业建设或领办、创办“星创天地”。经认定的市级“星创天地”享受相关优惠政策扶持，并择优推荐申报省级“星创天地”。

（八）创新服务新模式。积极推广西北农林科技大学的“试验示范站大学农技服务模式”和“农技服务大荔模式”，围绕创新型试点城市联动工程，瞄准区域主导产业建立技术需求库，与省内外高等院校、科研院所、大型龙头企业加强合作，共建创新平台、示范基地，推行“一县N高校、一县N院所、一县N企业”，为区域创新发展提供科技支撑。

（九）建立创新创业协会。建立汉中市科技特派员创新创业协会（省科技特派员创新创业协会分会），开展项目咨询、设计和论证服务，提供专业技能、创新创业和政策方面的培训与指导等，成为集科技特派员孵化、培训、服务和创业链培育为一体的社团服务组织，鼓励各县区成立科技特派员创新创业协会分会。

三、保障措施

（一）明确选派程序。按照“政府引导、双向选择”的原则，对符合条件切自愿担任科技特派员的公职人员，经本人申请、所在单位同意并在本单位公示后，报科技管理部门审核，按要求选派。非公职人员自愿担任科技特派员的，须征得服务单位同意并支付合理报酬后，向科技管理部门提出申请备案，纳入科技特派员管理。县区选派的科技特派员要与管理单位、派出单位和服务单位三方签订技术服务协议。

（二）保障合法权益。高校、科研院所、职业学校等事业单位科技特派员下派开展农村科技公益服务的，在5年时间内岗位、编制等均保持不变，工资、奖金、福利等待遇不变，由本人所在单位发放，其工作业绩作为其职称评审和考核的重要依据，并在同等条件下晋升职称。对深入农村开展科技创新创业的，在5年内保留其人事关系，与原单位其他在岗人员同等享有参加职称评聘、岗位等级晋升和社会保险等方面的权利，期满后可以根据本人意愿选择辞职或回原单位工作。

（三）强化组织领导。各县区政府要将科技特派员工作作为加强区域科技创新的重要抓手，按照本实施意见制订考评管理办法。市、县区科技部门作为科技特派员管理牵头部门，要分别会同组织、人社、教育、农业等部门及派出单位对选派的科技特派员进行年度考核，年度考核不称职的，按程序退出科技特派员队伍。科技特派员选派期间因渎职失职，给服务对象造成损失或产生不良社会影响的，纳入科研诚信黑名单，取消其科技特派员资格，有违法违纪的，依法依纪予以处理。

（四）加强宣传表彰。对作出贡献的优秀个人科技特派员、法人科技特派员、科技特派员派出单位以及相关组织管理机构等要予以表彰。鼓励社会力量设奖对科技特派员予以奖励。新闻媒体要加大对科技特派员工作的宣传报道力度，形成全社会关注、支持科技特派员的良好氛围。
