# 汉中市人民政府办公室关于印发汉中市2018年国家义务教育均衡发展评估认定前期准备工作实施方案的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门，直属机构：

现将《汉中市2018年国家义务教育均衡发展评估认定前期准备工作实施方案》印发给你们，请认真抓好贯彻落实。

汉中市人民政府办公室

2017年10月24日

汉中市2018年国家义务教育均衡发展评估认定前期准备工作实施方案

根据省政府教育督导团《关于做好2018年国家义务教育均衡发展评估认定前期准备工作的意见》(陕政督团〔2017〕11号)精神，2018年，国家将对2013-2017年通过评估认定的县区进行评估复查。为做好我市国家义务教育均衡发展评估复查工作，结合我市实际，制定本方案。

一、总体要求

以国家和省市《关于推进义务教育均衡发展意见》为总领，全面落实教育优先发展战略地位，不断深化教育综合改革，完善教育保障机制，优化教育资源配置，改善办学条件，规范办学行为，实施素质教育，提高教育质量，促进教育公平，巩固县域义务教育均衡发展成果，全面做好国家义务教育均衡发展评估认定前期准备工作，进一步提高教育发展水平。

二、工作任务

（一）梯次推进，优先完成义务教育均衡发展工作任务。

1．巩固创建成果。全市已通过国家评估认定的佛坪县、宁强县、西乡县、留坝县、略阳县、勉县和南郑县7个县要在今年第四季度对义务教育均衡发展工作进行一次全面对标自查“回头望”，建立新的问题台账，部署自查整改完善工作，把国家评估认定当年反馈指出的遗留问题解决到位，在巩固创建成果的基础上提高义务教育均衡发展水平。

2．全力完成创建任务。今年要创建国家义务教育发展基本均衡县的汉台区、城固县、洋县和镇巴县及汉中经济开发区北区要夯实责任，落实措施，切实把省上过程督导中反馈的问题逐条落实到位，确保顺利通过国家评估认定。

3．优先安排义务教育学校项目建设。加快推进2018年教育基础设施建设项目的立项、开工、建设，确保到2018年8月底前基本完成义务教育校建项目和义务教育教学设施采购配备任务。

4．优化义务教育学校布局。根据国家和省市中小学校布局调整工作要求，结合实际合理确定教学点、完全小学、乡镇中心小学、初中等布点设置，规范布局调整审批程序，明确学校布局调整的保障措施，办好每一所学校。加大城市新区、开发区、新建居民小区和老旧城区配套学校建设力度，严格落实新建居住区配套建设学校的政策，加快县城以上城区中小学建设，提高城乡教育一体化发展水平。

5．守住义务教育学校办学条件底线。切实落实义务教育均衡发展评估认定的“四个一票否决”项目要求（全面改薄项目未完成、残疾少儿入学率未达标、教育经费政策未落实、教育系统发生安全责任事故等实行一票否决）和义务教育学校办学条件“20条底线”要求，重点消除危房、消除土操场、消除土木结构的校舍、消除大通铺；到2018年基本消除66人以上的超大班额，到2020年基本消除56人以上的大班额。守住义务教育学校办学条件9项“门槛”指标，所有义务教育学校办学条件“综合评估”必须达标。全面完成义务教育学校标准化建设任务，力争实现“三通两平台”，提高义务教育水平。要加强教育数据统计分析工作，建立义务教育均衡状况监测评估制度，全面、客观、实事求是地填报教育数据，教育事业统计年报工作由县区教育局局长负总责、督导室主任负监测责任、统计人员负直接责任。所有县区2017年义务教育校际综合差异系数控制到国家标准范围内，小学小于或等于0.60、初中小于或等于0.50。

6．不断加强学校管理。坚持改善办学条件和促进内涵发展两手抓，进一步规范办学行为，提高学校文化建设品位，促进教育内涵发展。

（二）统筹协调，明确国家评估认定的对象和范围。国家义务教育均衡发展评估认定的对象是县区行政区划单位。所有义务教育学校（含市直属及民办义务教育学校和教学点）按所在县区工作部署开展迎国检工作。汉中经济开发区的义务教育学校纳入《教育事业统计年报》，开展迎接国家评估认定。各县区要加强对辖区内的义务教育学校迎国检工作的统一领导，做到同步动员部署、同步督导检查、同步迎接国检。所有县区到2018年通过国家评估复查，所有义务教育学校达到国家评估标准要求。

（三）缩小差距，均衡配置县域义务教育资源。将国家义务教育均衡发展评估标准要求的入学机会、条件保障、教师队伍、质量与管理等4项17条评估指标分解到县级有关部门，确保县区政府工作得分达到85分以上（满分100分）。

1．保障适龄儿童少年平等入学机会。落实进城务工人员随迁子女就学“两为主”“两纳入”（以流入地为主、以公办学校为主，纳入城镇发展规划、纳入财政保障范围）政策规定。建立以政府为主导、社会各方面广泛参与的留守儿童关爱体系。树立全纳教育理念，切实保障残疾儿童少年受教育的权利，30万人口以上的县区应独立设置一所特殊教育学校，建设好县级特殊教育资源中心。县域内视力、听力、智力残疾儿童少年义务教育入学率达到90%以上，基本普及残疾儿童少年义务教育，落实特殊教育教师津贴政策，加强特殊教育教师定向培养。优质普通高中招生名额分配到县域内各初中的比例逐步提高。

2．完善义务教育经费投入保障机制。义务教育经费投入在财政预算中单列，重点落实中省义务教育经费投入政策，包括义务教育经费投入的“三个增长”，中央农村税费改革转移支付总额的50%用于教育，其中40%用于补助危房改造和弥补公用经费不足，教育费附加和地方教育附加足额征收、全额拨付，主要用于中小学校建设和义务教育均衡发展并完成全面改薄任务。

3．加强教师队伍建设。全面实施义务教育岗位绩效工资制度。落实乡村学校教师生活补助政策。学科教师配备合理，教师编制标准达到省定标准要求。建立并完善县域义务教育学校教师校长交流轮岗制度，落实教师培训经费，加强教师培训。

4．提高教育质量和学校管理水平。按照全面推进素质教育、全面提高学校管理水平、全面提高教育质量的要求。开齐开足国家规定课程课时，促进初中毕业生升学率高于去年，小学、初中巩固率均达到99.91%，小学、初中国家学生体质健康标准测试及格率达到85%以上。义务教育阶段学校不得设置重点校、重点班，有效遏制公办义务教育学校择校现象，减轻中小学生过重课业负担。

（四）宣传发动，形成迎复检浓厚氛围。大力宣传义务教育均衡发展的理念意义、政策措施、标准要求，宣传先进典型和成功案例。加强对义务教育均衡发展评估标准的培训工作。定期向人大代表、政协委员、学生家长、校长教师和干部群众通报义务教育均衡发展状况，听取意见建议，营造全社会关心、理解、支持义务教育均衡发展的良好社会环境和舆论氛围。

三、工作要求

（一）提高认识，高点站位。各县区政府要充分认识推进义务教育均衡发展工作的长期性、艰巨性和战略性，增强均衡发展义务教育的战略意识，增强完成义务教育均衡发展攻坚任务的时限意识，增强所有义务教育学校必须全部达标的标准意识，尽快制定2018年国家义务教育均衡发展评估认定前期准备工作实施方案，切实抓紧抓实抓好复检工作，确保国家评估复查工作一次性顺利通过。

（二）健全机制，夯实责任。复查工作实行“一把手”负责制，建立“一把手”负总责、分管领导负直接责任、具体工作人员负具体责任的复查工作责任机制。所有涉及的单位、部门都要制定迎复查工作日程表，落实各项工作的具体责任人。县区党政主要领导要履行教育管理的第一责任人的责任，统筹力量，整合资源，亲自动员部署、亲自督导检查、亲自协调解决教育重大问题，市县教育、财政、人社、督导等有关部门要坚持问题导向和目标导向，专题研究，超前部署2018年国家评估认定义务教育均衡发展的前期准备工作，重点部署并完成教育基础设施建设、教育经费投入政策落实、教育教学设施充实配备、教师校长队伍建设等基础工作。要通过扎实细致的工作，形成推进义务教育均衡发展的攻坚合力。

（三）强化督导，严格奖惩。为确保全面高质量顺利通过国家评估复查，要进一步加强督查和指导工作，严格执行奖惩制度。各县区政府要加强对镇办和部门工作的检查指导，尤其是强化对各有关单位的过程性督查和指导，发现问题及时督促整改到位。按省政府教育督导团要求，到2018年8月，所有县区要成立政府教育督导委员会及办公室，配齐专职督学。县区政府教育督导室要切实履行督政督学职能，为评估复查过程进行动态监测和精准督导，及时通报工作进展情况。在复查工作中，对工作不力、进度缓慢、质量不佳的单位和个人，给予通报批评；对不按时完成任务，严重影响整体工作的单位及其主要负责人和当事人，将按照相关规定，追究单位或学校主要负责人及当事人的责任，并在全市进行通报；对工作表现突出，成绩显著的单位和个人，给予表彰奖励。
