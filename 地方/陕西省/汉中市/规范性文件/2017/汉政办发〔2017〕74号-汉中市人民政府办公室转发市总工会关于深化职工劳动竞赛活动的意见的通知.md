# 汉中市人民政府办公室转发市总工会关于深化职工劳动竞赛活动的意见的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

市总工会《关于深化职工劳动竞赛活动的意见》已经市政府同意，现转发给你们，请结合实际，认真贯彻落实。

汉中市人民政府办公室

2017年11月21日

关于深化职工劳动竞赛活动的意见

汉中市总工会

为推进职工劳动竞赛活动深入开展，组织动员广大职工在汉中追赶超越、建设新“三市”中建功立业，特提出以下意见：

一、指导思想

以党的十九大精神和习近平总书记系列重要讲话精神为指导，坚持全心全意依靠工人阶级的方针，紧紧围绕我市实施“六大战略”、壮大“六大产业”、推进“十大工程”、做优“两汉三国·真美汉中”城市品牌总体部署，广泛开展“践行新理念、建功‘十三五’”主题劳动竞赛，引导广大职工积极践行创新、协调、绿色、开放、共享的发展理念，大力弘扬劳模精神、劳动精神和工匠精神，不断提高劳动技能水平，在全市经济社会建设中充分发挥主力军作用。

二、主要任务

（一）深化职工建功立业活动。围绕供给侧结构性改革和全市重点项目建设，以实施工业技改项目为契机，在地方和行业组织开展职工建功立业活动，促进军民深度融合、科技成果转化、产业结构优化升级。针对产业关键共性技术和企业现场管理、技术、工艺等难题，引导和组织职工立足岗位广泛开展合理化建议、技术创新、技术协作、发明创造等活动，形成基础广泛、人才集聚、成果丰富的职工建功立业活动体系。大力创建职工（劳模）创新工作室、技能大师工作室，充分发挥其人才集聚、集智创新、技术攻关、技能传承功能和示范带动作用。广泛开展职工创新成果评选、展示、交流活动，加强技术开发、技术转让、技术咨询、技术服务，落实职工知识产权保护措施，促进职工技术成果转化。

（二）着力培养汉中工匠。围绕全市“六大战略”，结合地区、行业、企业发展目标，广泛开展职工职业技能大赛，探索网上练兵、网上技能比赛等新形式，不断提高广大职工的劳动技能水平，壮大汉中高技能人才队伍。加强职工职业技能培训，按规定足额提取职工教育经费，总结交流推广绝招、绝技、绝活和先进操作法，开展高技能人才“名师带徒”活动。健全校企合作培训体系，促进学历与非学历教育纵向衔接连通、横向互通互认，鼓励职工参加学历教育和继续教育。大力推行首席技师、首席员工、金牌工人制度及对优秀技术工人进行奖励、开辟晋级绿色通道等做法，帮助更多的职工取得和晋升职业技术资格。建立健全技能型人才档案库，推动企业提高技能工人的待遇，更好地激发职工学技术、钻业务、练技能的热情。

（三）深化职工节能减排活动。围绕实施节能技改工程、传统制造业绿色改造和发展循环经济等，积极开展节能减排立功竞赛活动，引导职工提倡节约意识、环保意识、生态意识，应用节能减排新技术、新工艺、新材料、新设备。在电力、化工、冶金等高耗能、高排放行业中，深入开展以“三比一降” （比创新、比技能、比管理、降能耗和排放）为主要内容的对标竞赛活动，促进资源能源节约高效利用。加强职工节能减排义务监督员队伍建设，充分发挥义务监督员在节约资源和保护环境中的重要作用。

（四）深化“安康杯”竞赛活动。以采掘、建筑、交通、冶金、化工、电力等行业为重点，以促进安全生产、防范职业危害为目标，广泛开展“安康杯”竞赛活动，力争到2020年参加竞赛活动的企业达90%以上。开展“安全承诺”签名、安全生产合理化建议等活动，推广工会参与职业病防治工作模式，完善劳动保护监督检查机制。加强群众性劳动保护工作，充分发挥工会劳动保护监督检查员作用，严守安全生产的第一道防线。每年树立一批“安康杯”竞赛先进集体和先进个人，总结和宣传典型经验、先进事迹，引导各企事业单位实现安全发展，减少生产事故和控制职业危害。

（五）加强班组建设。结合行业和企业实际，不断推进班组科学化、标准化和规范化建设，有重点、分步骤地推进非公企业班组建设。深入开展以创建“工人先锋号”为载体的班组（科室、团队）竞赛，吸引广大职工参与到竞赛活动中来，创建更多的技能型、效益型、管理型、创新型、和谐型“五型”班组。做好班组长的培养和选拔工作，建立科学的班组长岗位竞争机制和考核机制，努力为班组建设和自身成长创造条件。

三、完善劳动竞赛机制

（一）完善活动机制。以改善经营管理、推动技术进步和促进企业发展为目标，以班组竞赛为基础，以提高职工技能水平和增强职工创新能力为重点，科学制定竞赛方案，落实专门机构组织实施，推进竞赛活动系统、深入、规范开展。坚持从实际出发，科学安排、精心组织竞赛活动，努力把生产型竞赛、技能型竞赛和智能型竞赛有机结合起来，把动机与效果、内容与形式、职工利益实现与企业发展有机统一起来，切实增强竞赛实效。

（二）完善评估机制。制定科学的竞赛评估方法和评估指标体系，量化竞赛评估工作，做到科学化、规范化、制度化。把竞赛方案制定、竞赛活动开展、竞赛目标任务实现等纳入评估范围，以劳动竞赛在提升职工素质、推动企业技术进步和促进经济发展中所发挥的作用作为评估重点，及时组织相关单位和职工代表进行评审，促进竞赛活动深入扎实开展。坚持走群众路线，充分听取职工群众对竞赛活动的意见，并把群众意见作为评估劳动竞赛的重要依据。

（三）完善激励机制。制订和完善劳动竞赛奖励办法，把比技术创新、团结协作、质量效益、安全环保和创一流工作、一流业绩、一流团队作为主要内容，坚持精神鼓励与物质奖励相结合，对劳动竞赛中涌现出来的先进集体、先进职工及时予以表彰奖励。建立健全技能人才培养、考核、使用、待遇相统一的激励机制，形成重视和使用高技能人才的良好氛围。大力宣传和表彰竞赛活动中涌现出来的先进集体、模范职工和优秀技术创新成果，调动和激发职工创先争优建功立业的积极性。

四、保障措施

（一）加强工作协调。各级劳动竞赛委员会要切实加强对此项工作的组织领导，结合本地实际，制定工作规划，建立相关工作制度，及时协调解决工作中遇到的问题和困难，确保此项工作深入持久开展。各劳动竞赛委员会成员单位要密切配合，加强政策协调、工作协商和信息沟通，发挥各自优势，形成工作合力，共同推动劳动竞赛各项工作任务落到实处。

（二）落实工作责任。各企事业单位要把职工劳动竞赛活动作为落实党的全心全意依靠工人阶级的重要内容，与生产经营、评选先进、职称晋升等结合起来，精心组织，落实责任，加强检查，确保此项活动不走形式。各级劳动人事部门要将职工劳动竞赛活动纳入创建劳动关系和谐企业和工业园区活动内容，加强督促检查，严格审核把关，促进各企事业单位把劳动竞赛活动作为单位一项基础性工作常抓不懈。职业技术学院要面向广大职工开展技能培训，主动为各单位开展劳动竞赛提供技术指导。科技部门要将职工技术创新工作纳入科技创新内容，积极为职工技术创新成果保护、创新专利申请提供服务。工会要履行好劳动竞赛委员会办公室的职责，结合实际制定工作计划，加强分类指导，群策群力做好竞赛各项工作。

（三）加大宣传力度。要重视职工劳动竞赛活动的宣传工作，充分利用各种新闻媒体和互联网，广泛宣传职工劳动竞赛活动的重要意义，宣传在活动中涌现出的好经验、好做法、新成果和先进典型，使职工的劳动热情得到保护、创新才能得到发挥、创新成果得到肯定，为此项活动的顺利开展营造良好社会氛围。
