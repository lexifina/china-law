# 汉中市人民政府办公室关于强化学校体育促进学生身心健康全面发展的实施意见

各县区人民政府、市政府各工作部门、各直属机构：

为贯彻落实省政府办《关于强化学校体育促进学生身心健康全面发展的实施意见》（陕政办发〔2016〕111号）精神，进一步强化我市学校体育工作，促进青少年学生身心健康全面发展，提出以下贯彻意见：

一、总体目标

以促进学生身心健康、体魄强健为出发点，以“天天锻炼、健康成长、终身受益”为目标，全面提升体育教育质量，健全学生人格品质。到2020年，全市学校体育办学条件总体达标，体育课时和锻炼时间得到切实保证；教学、训练与竞赛体系基本完备，体育教学质量明显提高；学生体育锻炼习惯基本养成，运动技能和体质健康水平明显提升，规则意识、合作精神和意志品质显著增强；政府主导、部门协作、社会参与的学校体育推进机制基本完善，体系健全、制度完善、充满活力、注重实效的学校体育发展格局基本形成。

二、重点任务

（一）完善体育课程。全市各级各类学校要严格执行国家课程标准，开足、开齐体育课程，保证学生每天1小时校园体育活动。自2017年起，小学、初中体育课调整为每周4节，高中（含中等职业学校）体育课调整为每周3节，严禁削减、挤占体育课时间。各县区和学校要大力开展足球、篮球、排球等集体项目和田径、游泳、体操等基础项目，广泛开展乒乓球、羽毛球、武术等地方优势项目，积极挖掘整理民族民间体育，充实和丰富体育课程内容。

（二）提升教学水平。各县区和学校要加强学校体育教学科学管理，提高体育教学质量和科学研究水平，逐步形成“一校一品”“一校多品”“一球一操”“一县（区）一特色”等体育教学模式；充分发挥学校体育教学指导委员会作用，加强对学校体育教学的指导；充分利用现代信息技术手段，开发和创新体育教学资源，不断增强教学吸引力。学校体育教学要加强健康知识教育，制定开展运动项目指南，注重运动技能学习和实践练习，让学生熟练掌握1至2项运动技能。学校要关注学生体育能力和体质水平差异，做到区别对待、因材施教，研究推广适合不同类型学生的体育教学方法，提高特殊教育学校和残疾学生的体育教学质量，保证每个学生接受体育教育的权利。

（三）强化课外锻炼。全市各级各类学校要把课外体育活动、运动队训练、比赛和俱乐部开展体育活动纳入学校日常教学计划。中小学每天上午必须安排30分钟大课间体育活动，当天没有体育课的，下午课后必须组织学生进行1小时体育锻炼。各县区要组织指导各学校坚持每年开展学生冬季长跑、体育艺术2＋1以及校外全民健身运动等群体性活动，形成覆盖校内外的学生课外体育锻炼体系。中小学要合理安排家庭“体育作业”，引导家长支持学生参加社会体育活动。幼儿园要遵循幼儿年龄特点和身心发展规律，开展丰富多彩的体育活动。社区要为学生体育活动创造便利条件。

（四）推动教体结合。市、县区教育、体育行政部门要遵循教育、体育发展规律，积极整合资源、改善场地设施条件、畅通运行机制，探索建立常态化校园体育竞赛机制，提升教体结合水平；鼓励体育俱乐部和机构辅助学校开展体育教学和训练竞赛，并加强对进入学校的体育俱乐部和机构的管理。各县区要定期举办综合性学生运动会，每年举办专项阳光体育竞赛活动；完善竞赛选拔机制，畅通学生进入各级专业运动队、代表队的渠道。各级各类学校每年要举办春、秋季运动会或体育文化节，开展形式多样的课余体育训练。教育行政部门要将公办体育运动学校纳入义务教育管理范围，会同体育行政部门做好教学管理、评估、教师配备、培训等工作。办好体育传统项目学校，充分发挥引领示范作用。

（五）加强队伍建设。全市各级各类学校要按规定配齐配强体育教师。市人社局在招录学校体育教师时，要对获得较好运动成绩的优秀退役运动员（省运会冠军及以上成绩者）给予一定政策倾斜。鼓励优秀教练员、退役运动员、社会体育指导员、有体育特长人员担任中小学兼职体育教师。要切实保障体育教师合法权益，科学合理确定体育教师工作量，把组织开展课外活动、学生体质健康测试、课余训练、比赛等纳入教学工作量；保障体育教师在职称（职务）评聘、福利待遇、评优表彰、晋级晋升等方面与其他学科教师享有同等待遇。市教育局要组织实施体育教师全员培训，自2017年起，对现有中小学体育教师每3年进行一次全员轮训，每名体育教师每年接受继续教育时间不少于48课时。

（六）推进设施建设。各县区要以“保基本、兜底线”为原则，加大体育设施建设和器材配备力度。到2020年，全市中心小学以上学校操场全部完成建设改造，每个县区至少建设一块标准足球场地，每所学校应建设篮球、排球、乒乓球、羽毛球等活动场所。鼓励有条件的中小学校建设游泳池、专业项目训练馆。在新建体育场馆设施时应统筹考虑社会和学校的共用问题，避免重复建设。积极推动公共体育场馆设施向学生免费或优惠开放。有条件的学校在保证学校教育教学需要和校园安全的情况下，在节假日将学校体育场地设施向社会有序开放。充分利用青少年活动中心、少年宫、户外营地等资源开展体育活动。

（七）规范考试评价。构建课内外相结合、各学段相衔接的学校体育考核评价体系，规范和完善体育运动项目考核和学业水平考试。体育课程考核要突出过程管理，从学生出勤、课堂表现、健康知识、运动技能、体质健康、课外锻炼、参与活动情况等方面进行全面评价。学校要把学生参加体育活动情况、学生体质健康状况和运动技能等级纳入初中、高中学业水平考试，纳入学生综合素质评价体系，认真组织实施好初中毕业升学体育考试。

（八）完善监测机制。全面实施《国家学生体质健康标准》，建立健全学生体质健康档案，每年对所有学生进行体质健康测试，测试结果经审核后逐级上报。加大对学校测试数据的抽测复测力度，确保测试数据真实、有效和完整，并向学生家长和社会通报。建立和完善中小学体育课程实施情况监测制度，定期开展体育课程国家基础教育质量监测。按照分级管理原则，依据教育部《中小学校体育工作评估办法》，组织开展中小学校体育工作评估。深入推进中小学校体育工作年度报告制度，逐级报告学校体育开课率、阳光体育运动情况、体育经费投入、教学条件改善、教师队伍建设和学生体质健康状况等。

三、保障措施

（一）加强组织领导。各县区要把学校体育工作纳入经济社会发展规划和教育事业整体发展规划，结合实际，研究制订加强学校体育工作的具体实施方案，加强统筹协调，落实管理责任。建立学校体育工作联席会议制度，由教育部门牵头、有关部门分工负责，落实好深化学校体育改革的各项任务。教育部门要完善政策，制定标准，加强监督管理和科学指导，将学校体育纳入各级各类教育发展规划。体育部门要把学校体育作为全民健身计划的重点，在技术、人才、场地和体育组织建设等方面加强对学校体育工作的支持。发展改革部门要把提高青少年身心健康水平纳入经济社会发展规划，支持学校体育发展。财政部门要完善支持学校体育的投入政策。建立专项督查、抽查、公告制度和行政问责机制，对学生体质健康水平持续3年下降的县区和学校，在教育工作评估中实行“一票否决”。

（二）保障经费投入。各县区要切实加大学校体育经费投入力度，在安排财政转移支付资金和本级财力时对学校体育方面给予倾斜。鼓励和引导社会资金支持发展学校体育，多渠道增加学校体育投入。市、县教育部门要根据需求将学校体育工作经费纳入年度预算，学校要保障体育工作的经费需求。

（三）整合各方资源。完善政策措施，采取政府购买体育服务等方式，逐步建立社会力量支持学校体育发展的长效机制，引导技术、人才等资源服务学校体育教学、训练和竞赛等活动。鼓励专业运动队、职业体育俱乐部定期组织教练员、运动员深入学校指导开展有关体育活动。支持学校与科研院所、社会团队、企业等开展广泛合作，提升学校体育工作水平。加强学校体育国际交流，深化同港澳台青少年体育活动的合作。

（四）强化风险管控。健全学校体育运动伤害风险防范机制，保障学校体育工作健康有序开展。各级各类学校要对学生进行安全教育，培养学生安全意识和自我保护能力，提高学生的伤害应急处置和救护能力。加强校长、教师及有关管理人员培训，提高学校体育从业人员运动风险管理意识和能力。学校应当根据体育器材设施及场地的安全风险进行分类管理，定期开展检查，有安全风险的应当设立明显警示标志和安全提示。完善校方责任险，探索建立涵盖体育意外伤害的学生综合保险机制。鼓励各县区试点推行学生体育安全事故第三方调解办法。

（五）营造良好环境。各县区、各有关部门要坚持正确舆论导向，充分利用各种宣传媒介和手段，宣传学校体育工作的政策要求、典型经验和有效做法，采取多种方式加强学校体育文化建设，形成全社会重视青少年健康的良好氛围。学校要充分发挥在学生体质健康发展中的主渠道作用，加强与家庭和社区的沟通与合作，努力培养学生终身体育意识，养成良好体育锻炼习惯。社区要不断改善社区内体育活动设施，利用节假日、寒暑假、双休日，组织社区内青少年开展形式多样的体育活动，引导广大青少年积极参与全民健身运动。
