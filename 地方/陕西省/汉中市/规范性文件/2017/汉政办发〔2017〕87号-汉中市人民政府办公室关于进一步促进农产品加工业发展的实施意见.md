# 汉中市人民政府办公室关于进一步促进农产品加工业发展的实施意见

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

为贯彻落实《陕西省人民政府办公厅关于进一步促进农产品加工业发展的意见》（陕政办发〔2017〕81号）、《汉中市做好小农户对接大市场实施意见》（汉政发〔2017〕19号）以及《汉中市人民政府关于支持农业产业化重点龙头企业做大做强的实施意见》（汉政发〔2017〕17号），深入推进农业供给侧结构性改革，不断满足城乡居民消费需求，进一步促进小农户对接大市场，经市政府同意，提出如下实施意见。

一、总体要求

认真贯彻落实党的十九大精神，以习近平新时代中国特色社会主义思想为指导，紧紧围绕统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，牢固树立创新、协调、绿色、开放、共享的发展理念，在确保粮食安全和农产品质量安全的基础上，以转变农业发展方式、调整优化产业结构为主线，以市场需求为导向，以增加农民收入、提升农业综合效益和竞争力为核心，完善扶持政策，强化指导服务，加快推动农产品加工由初级向精深转变、由传统工艺向先进适用技术转变，全面提升农产品加工业发展水平，构建农产品“产地初加工+精深加工+农副产品综合利用”的现代农产品加工业格局，助推汉中农业追赶超越和脱贫攻坚。到2020年，现代农业产业布局进一步优化，农业产业体系、生产体系、经营体系更加完善，农业竞争力明显提高；主要农产品加工转化率达到70%左右，农产品加工业产值与农业总产值比达到2.2∶1；市级以上重点龙头企业超过220家，对粮、茶、畜、果、菜、中药材、水产等优势特色产业实现全覆盖；产业集群基本形成，建成年销售收入5亿元以上的特色农产品加工产业示范园区5个。

二、优化农产品加工业布局

（一）推进向优势产区集中布局。根据全市现代农业发展规划和十大绿色农产品优势产业带，积极对接全省农业产业发展规划，合理布局原料生产基地、粮食生产功能区、重要农产品生产保护区以及特色农产品优势区，形成生产与加工、科研与产业、企业与农户、产品与市场衔接配套的全产业链格局，促进农产品加工转化、增值增效。大力发展优质粮油、茶叶、果蔬、畜禽、中药材、水产养殖产业，夯实农产品加工基础。支持农产品加工及提取企业向优势区域和具备条件的贫困地区集中布局。着力推动产业集聚带、配套销售物流平台和加工示范园区建设。支持有条件的县区重点发展米面油主食产品、酱料等方便食品、休闲食品和净菜加工。支持贫困地区结合精准扶贫、精准脱贫，大力开展产业扶贫，通过发展农产品加工业，建立完善带动贫困户脱贫增收机制。实施招大引强战略，引进有品牌、有实力、有市场的省内外大型加工龙头企业，提升农产品加工水平。支持以县区为单元建设加工基地，以镇、村为单元建设原料生产基地。着力建设优质专用原料基地的仓储物流体系。（市农业局、市发改委、市财政局、市林业局、市商务局、市扶贫办、市粮食局等负责，列第一位为牵头单位，下同）

（二）加快农产品初加工发展。培育发展加工型农民合作社等新型经营主体，大力发展农产品产地初加工，促进区域特色农产品就地加工转化。以水稻、食用菌、茶叶、水果、蔬菜等为重点，支持种植大户、农民合作社、加工企业改善储藏、保鲜、烘干、清选分级、包装等设施装备条件，调节市场供需，降低产后损失，提高产品附加值。鼓励农户、农民合作社建设果蔬冷藏库、加热式烘房等设施，延长产品储藏周期，拓展农民致富增收空间。通过实施相关项目和推广适用技术，推动农产品初加工水平整体提升。（市农业局、市发改委、市财政局、市林业局、市粮食局等负责）

（三）提升农产品精深加工水平。加大生物、工程、环保、信息等技术集成应用力度，加快新型非热加工、新型杀菌、高效分离、节能干燥、清洁生产等技术升级，开展精深加工技术和信息化、智能化、工程化装备研发。适应市场和消费升级需求，积极开发“有机米”、“胚芽米”、“易煮糙米”、“保健油”、“果脯”、“果汁”等营养健康的功能性食品，“茶多酚”、“黄酮”、“胶原蛋白”等生物提取保健产品。拓宽主食供应渠道，加快培育示范企业，积极打造质量过硬、标准化程度高的主食品牌。研制生产一批传统米面、杂粮、预制菜肴等产品，加快发展主食产品加工业。（市工信委、市科技局、市农业局、市发改委、市粮食局等负责）

（四）加强农副产品综合利用。选择重点品种，主攻农产品及其加工副产物循环利用、全值利用、梯次利用，总结推广发展经验和模式。采取先进的提取、分离、粉碎与制备技术，集中建立副产物收集、运输和处理渠道，加快推进秸秆、稻壳米糠、麦麸、油料饼粕、果蔬皮渣、畜禽皮毛骨血、水产品皮骨内脏等副产物综合利用，开发新能源、新材料、新产品等，不断挖掘农产品加工潜力，提升增值空间。（市农业局、市科技局、市工信委、市林业局等负责）

三、推进多种业态发展

（五）支持农民合作社等发展加工流通。扶持农民合作社、种养大户、家庭农场建设烘储、直供直销等设施，发展“农户（贫困户）＋合作社＋企业”模式，引导农民以土地经营权、林权和设施装备等入股农民合作社和企业。大力培育加工型合作组织，支持农民合作示范单位实施农产品初加工、精深加工和副产物综合利用。推进粮食产后服务体系建设，探索粮食统一烘干、贮藏、加工和销售的经营方式。（市农业局、市发改委、市林业局、市粮食局等负责）

（六）鼓励企业打造全产业链。继续实施“十百千万”工程，积极创建加工型明星企业。支持农产品加工企业向前端延伸带动农户建设原料基地，向后端延伸建设物流营销和服务网络。鼓励农产品加工企业与上下游各类市场主体组建产业联盟，与农民（贫困户）建立稳定的订单和契约关系，积极推广“保底收益、按股分红”等利益联结形式，构建让农民分享加工流通增值收益的利益联结机制。积极打造“优势特色产业+行业龙头企业+金融资本+小农户（贫困户）”典型模式。（市农业局、市工信委、市林业局、市商务局、市投控集团有限公司等负责）

（七）创新模式和业态。将农产品加工业纳入“互联网+”现代农业行动，利用大数据、物联网、云计算、移动互联网等新一代信息技术，培育发展网络化、智能化、精细化现代加工新模式。引导农产品加工业与休闲、旅游、文化、教育、科普、养生养老等产业深度融合。积极发展电子商务、农商直供、汉中特色店、加工体验、中央厨房等新业态。（市工信委、市科技局、市农业局、市林业局、市商务局、市文广新局、市旅发委等负责）

（八）推进加工园区建设。以农产品加工聚集区为重点，统筹用好现有食品加工园基础，积极开展省级农产品加工产业示范园区创建工作。支持基础设施和公共服务平台建设，完善功能、优化分工，吸引农产品加工企业向园区集聚，逐步形成标准化种养、精细化加工、高效化物流为一体的现代农业产业示范集群。以加工园区为主要依托，创建集标准化原料基地、集约化加工、便利化服务网络于一体的产业集群和融合发展先导区，加快建设农产品加工特色小镇，实现产城融合发展。（市农业局、市发改委、市粮食局、各县区政府等负责）

四、加快产业转型升级

（九）提升科技创新能力。依托陕西农产品加工技术研究院、西北农林科技大学、陕西理工大学等科研单位，开展农产品加工校地合作，加强农产品加工利用、储藏保鲜等关键技术攻关，围绕农产品加工重点领域开展基础研究、前沿研究和共性关键技术研发，组织实施一批科技项目。重点支持粮油、茶叶、蔬菜、菌类、果品（林产品）和中药材等营养成分提取技术研究，开发营养均衡、养生保健、食药同源的加工食品。强化协同机制，鼓励农产品加工骨干企业与大专院校、科研院所联合组建科学技术研究与开发中心，开展果汁、奶畜、菜茶等产品研发，实施质量检验检测平台建设，支持精深加工装备改造升级，增强产业创新驱动力。完善农产品加工技术研发体系，建设一批农产品加工技术集成基地。（市农业局、市科技局、市工信委、市林业局、市食药监局等负责）

（十）加速科技成果转化推广。选取一批成熟适用加工技术、工艺和关键设备，搭建科企技术对接平台，鼓励农产品加工企业应用新技术、新材料、新工艺及新设备，鼓励建设科技成果转化交易中心，支持科技人员与他人合作或者以科技成果作价投资，加快推进科技成果转化。（市科技局、市农业局、市知识产权局等负责）

（十一）提高农产品加工企业管理水平。强化环保、能耗、质量、安全、卫生等标准使用，鼓励企业开展质量管理、食品安全控制、追溯等体系认证，支持企业与农户开展无公害农产品、绿色食品、有机农产品认证以及危害分析与关键控制点、良好农业规范认证，加强事中事后监管，建立健全现代企业管理制度。实施品牌战略，培育、打造一批规模大、品牌亮、代表性强的农产品加工品牌，到2020年，扶持发展8家加工及流通骨干明星企业。加强农产品商标和地理标志注册与保护，严厉打击侵犯知识产权和制售假冒伪劣商品等行为。对被认定为中国驰名商标和地理标志产品（商标）及获得省级以上名牌产品等称号的农产品加工企业，在安排项目资金时予以倾斜支持。（市农业局、市工信委、市环保局、市林业局、市商务局、市工商局、市质监局、市食药监局、市知识产权局等负责）

（十二）加强人才队伍培养。培育一批经营管理队伍、科技领军人才、创新团队、生产能手和技能人才。支持大中专院校开设农产品加工、食品科学相关专业。开展职业技能和创业培训，建设一批农产品加工创业创新孵化园，支持返乡下乡人员创办领办农产品加工企业。（市教育局、市科技局、市人社局、市农业局等负责）

五、完善政策措施

（十三）加强财政支持。发挥财政资金撬动作用，引导工商资本、社会资本投向农产品加工业。支持符合条件的农产品加工企业申请支农项目、补助资金和省市发展基金，对带动贫困户增收作用明显的予以优先扶持。新型农业经营主体购置仓储烘干设备，可按规定享受农机购置补贴政策、农产品产地初加工补助政策。支持农产品加工原料基地、农产品加工园区、物流配送体系建设和技术改造、人才培训、品牌推广等。（市财政局、市发改委、市农业局、市林业局等负责）

（十四）完善税收政策。扩大农产品增值税进项税额核定扣除试点行业范围，积极推进试点工作。农产品加工企业可凭收购发票按规定抵扣增值税。落实农产品初加工企业所得税优惠政策。在实施与农产品加工有关的国家鼓励类项目中，进口国内不能生产的所需先进设备，所缴纳进口环节增值税可按规定予以抵扣。（市国税局、市地税局、市财政局等负责）

（十五）强化金融服务。鼓励银行业等金融机构加大对农产品加工企业信贷支持力度，创新金融产品和服务方式，为农产品生产、收购、加工、流通和仓储等各环节提供多元化金融服务。市投控集团等政策性金融机构要充分发挥银企合作桥梁作用，扩大担保规模，完善银担合作和风险分担机制，积极开展厂房抵押和知识产权、股权、货权、应收账款、订单、存单质押等融资业务，加大对农产品加工企业的担保服务力度，开展供应链授信业务，为农产品加工企业融资增信。将农民合作社兴办加工流通企业列入农业担保体系支持范围。支持符合条件的农产品加工企业上市融资、发行债券。积极推广小额信贷保证保险等新型险种，鼓励农业担保与农业产业链加速融合，探索开展农产品质量安全保险。（人行汉中市中心支行、市发改委、市财政局、汉中银监局、汉中保险业协会、金融办等负责）

（十六）改善投资贸易条件。支持社会资本依照相关规定从事农产品加工、流通。鼓励符合条件的农产品加工企业开展对外合作，加大对其出口信用保险的支持，强化在融资和通关等方面的便利化服务。支持企业申请国际国内认证、专利、商标、品牌、标准等，鼓励使用人民币计价结算和收付资金。（市商务局、市发改委、市财政局、市农业局、市工商局、市质监局、汉中保险业协会等负责）

（十七）落实用地用电政策。将农产品加工用地列入土地利用总体规划和年度计划，认真落实农产品初加工用地政策，优先安排园区用地。支持农村集体经济组织以集体建设用地使用权入股、联营等形式与其他单位、个人共同兴办农产品加工企业。城乡建设用地增减挂钩节余的用地指标要重点支持农产品产地初加工发展。落实农产品初加工用电执行农业生产用电价格的政策，按照市政府汉政发〔2017〕17号文件要求，认真落实龙头企业加工、仓储方面用电优惠政策，切实保障农产品加工用电。（市国土局、市发改委、地电汉中分公司、汉中供电局等负责）

六、加强组织保障

（十八）完善工作机制。各县区要把推进农产品加工业发展摆上重要议事日程，纳入年度目标责任考核，落实有关扶持政策，切实抓好加工型农业企业培育提升工作。要进一步完善农产品加工业管理机构，加强农产品加工管理，履行规划、指导、管理、服务等职能，督促各项政策措施落到实处。有关部门要各司其职，密切配合，形成合力。（市农业局、市编办、市考核办、各县区政府等负责）

（十九）强化公共服务。推进农产品加工投资贸易、展示展销平台建设，加强政策指导、融资信息、人才对接等公共服务。完善农产品加工业统计制度和调查方法，开展行业运行监测分析。通过政府购买服务等方式为企业提供公共服务。（市农业局、市发改委、市商务局、市质监局、市统计局等负责）

（二十）加强舆论引导。积极发挥行业协会和其他社会组织在行业自律、教育培训和品牌营销等方面的作用，督促企业切实履行质量安全、吸纳就业和产业扶贫等责任。加强食品农产品质量安全法律法规、公众营养膳食科普知识宣传，努力营造促进农产品加工业持续稳定健康发展的良好氛围。（市农业局、市食药监局等负责）

（二十一）强化跟踪问效。各县区政府、各有关部门要夯实工作责任，确定目标任务，不断创新工作机制，切实加大农产品加工业培育提升力度。各县区、各部门每年12月20日前将支持农产品加工业发展落实情况报市农业局。（市农业局、市工信委、市商务局、市国土局、市发改委、各县区政府等负责）
