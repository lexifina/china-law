# 汉中市人民政府办公室关于加强全市房屋安全隐患排查整治的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

为确保人民群众生命财产安全，促进社会和谐稳定，现就加强全市房屋安全隐患排查整治工作有关事项通知如下：

一、夯实责任，明确任务分工

各县区人民政府承担辖区内城镇及农村房屋安全隐患排查整治工作的主体责任，市住房和城市管理局负责全市城镇房屋安全鉴定管理的指导工作，市城乡建设规划局负责全市农村房屋安全鉴定管理的指导工作，市民政局负责全市危房灾民生活救助保障和农村土坯房治理相关政策保障工作，其他相关部门（单位）按照职能承担相应的工作任务和责任，具体任务分工明确如下：

（一）新建（在建）商品房的房屋质量安全排查整治工作由市县建设行政主管部门负责，由工程质量监督机构严格按照《中华人民共和国建筑法》和《陕西省建设工程质量和安全生产管理条例》等规定进行认真排查摸底，发现问题及时督促五大责任主体处置。

（二）城镇居民老旧房屋的安全排查整治工作由各县区人民政府负责，安排当地社区、办事处、乡镇政府和县区建设行政主管部门成立机构抽调专人进行认真排查摸底，发现问题及时处置。

（三）农村房屋的安全排查整治工作由各县区人民政府负责，安排当地村、镇两委和县区建设行政主管部门成立机构抽调专人进行认真排查摸底，重点对土坯房屋和易发生山体滑坡周边的房屋及易遭受洪水破坏周边的房屋等进行排查整治，发现问题及时处置。

（四）市县（区）级的直管公房和公共租赁型保障房、棚户区改造安置住房的安全排查整治工作由市县（区）各房产主管部门负责，抽调专人进行认真排查摸底，发现问题及时处置。

（五）国家行政企事业单位办公用房的安全排查整治工作由各用房单位负责，发现问题及时处置并报所在县、区房产主管部门备案。商业、教育、卫生、文化娱乐等人员密集的公共场所用房为安全检查的重点，对应的行政主管部门应每年安排一次安全检查整治，并将检查整治结果报告所在辖区的房产主管部门。

（一）房屋安全隐患排查重点

各县区人民政府要围绕重点，督促各镇、村（社区）、办事处及各责任单位认真、全面、系统地开展辖区内房屋安全隐患排查工作：重点排查城中村、工矿棚户区的老旧危房；重点排查建设手续不齐全、村民自建土坯用房、未审批的加盖加层多建违章建筑；重点排查学校、幼儿园、医院、宾馆、商业和文化娱乐场所等人员密集的公共场所；重点排查劳动密集型企业和住宿地；重点排查洪水、地震、滑坡、沉降不均等地质问题易发多发区域和山体、水系、白蚁、大树等易垮塌易倾倒区域周边的房屋，以及因遭受施工、堆物、撞击、火灾、爆炸等人为或意外事故而出现异常的房屋等。

（二）房屋安全隐患处置办法

要根据房屋安全等级分类处置：该加固的要及时进行加固；该拆除的要及时围挡和拆除；对加盖加层多建违章建筑要及时强拆并处罚相关责任人，切实消除各类房屋安全隐患。对存在重大安全隐患的房屋，必须立即组织人员撤离，并设立安全警戒标志，全面落实日常巡查制度和网格化管理制度，实行动态监管、隔离管理。对排查中发现安全隐患的危房，一律不准出租经营使用、不得用做公共活动场所。治理私有危险房屋，房屋所有人进行抢险解危需要办理各项手续时，各有关部门按照职能应简化程序给予及时办理，以免延误时间发生事故。

（三）房屋治理修缮的原则

一是房屋所有人对经鉴定的危险房屋，必须按照鉴定机构报告中提出的处理建议，及时进行加固（修缮）或拆除治理。

二是危险房屋治理修缮发生的费用一般应由房屋所有人或造成危房的责任方承担。如系出租房屋，可以和承租人合资治理，承租人付出的修缮费用可以折抵租金或由出租人分期偿还；异产毗连危险房屋的各所有人，应按照国家对异产毗连房屋的有关规定，共同履行治理责任。拒不承担责任的，当事人可向当地人民法院起诉。

三是危险房屋治理修缮的责任应区分原因分别承担。因自然灾害等不可抗力或年久失修造成的，由房屋所有人承担修缮治理的责任；因使用人装修、扩建擅自拆改房屋承重结构或重要构件造成的，由使用人承担修缮治理的责任；因工程施工导致相邻房屋出现质量问题的，由五大责任主体承担相应治理责任。拒不承担责任的，由房屋权利人向当地人民法院依法起诉。

（一）机构保障

按照国家建设部《城市危险房屋管理规定》要求，市、县人民政府均应设立房屋安全鉴定机构（以下简称鉴定机构），负责房屋的安全鉴定工作，并统一启用“房屋安全鉴定专用章”。汉中市城镇房屋安全鉴定委员会已于2008年成立，设在汉中市住房和城市管理局，是汉中市城镇房屋安全鉴定的专职机构。

有条件的县区要迅速设立城镇和农村房屋安全鉴定委员会专职机构，具体实施办法参照《汉中市人民政府办公室关于印发汉中市城镇房屋安全管理实施办法的通知》（汉政办发〔2014〕42号）；无条件设立的县区，对排查出的房屋安全隐患需要鉴定的，直接由县区房产主管部门或乡镇政府、办事处等组织按照职能分别向市级房屋安全鉴定委员会申请鉴定。

（二）制度保障

一是建立日常巡查制度。各县区和相关单位要针对房屋安全重点排查内容进行巡查，做到不走形势、不走过场，及时发现问题。二是建立应急处置制度。各县区和相关单位要制定房屋安全治理应急处置措施，落实专人负责应急处置。三是建立挂牌督办制度。各县区和相关单位要安排专人针对日常巡查、处置落实情况挂牌督办，直到危房治理到位。四是建立重大问题报告制度。对排查出的重大房屋安全隐患问题和应急处置情况，要及时逐级报告有关上级部门。五是建立建档立卡制度。对发现安全隐患的各类房屋，要将排查出的问题、处置方式、责任人落实情况逐一登记，安排专人负责建立危房处置档案，制卡明确责任和处理时限。六是建立责任追究制度。按照属地管理职能分工，要夯实责任，对发现问题不及时报告、不及时处置的，要依法依规追究相关人的责任，造成重大后果的要承担相应的法律责任。

（三）政策保障

一是将危房治理工作与城镇住房保障工作相结合。市县（区）房产主管部门应整合住房保障资源，制定保障措施，对突发重大自然灾害的无房人员和确定为危房需紧急撤离的人员提供应急周转住房保障，民政部门应提供生活救助保障。

二是将城镇危房治理工作与棚户区改造工作相结合。市县（区）相关职能部门应统筹兼顾危房治理工作和城镇棚户区改造工作，对排查发现的比较集中的城中村危房，要因地制宜地纳入棚户区改造工作范围，做到精心组织、科学规划、因片施策，要严格棚改资金管理，做到精准发力，协调推进危房治理和棚户区改造工作。各县区保障房管理中心要筹集一批公共租赁房，为排查出的城中村危房户提供过渡周转房，做到应保尽保。

三是将农村危房治理工作与陕南移民搬迁工作相结合。各县区人民政府应统筹辖区农村危房治理工作和陕南移民搬迁安置工作。要充分尊重危房农户的意愿，鼓励危房农户向市、县移民安置点迁移。凡符合移民搬迁政策的农户，各县区移民办应及时落实相关补助资金。

四是将农村危房治理工作与农村土坯房改造工作相结合。为顺利推进全市新农村建设，建规、民政等部门应对危险土坯房农户按照土坯房改造相关政策给予支持保障。按照“先急后缓、分步实施”的原则，对居住房屋存在危险、家庭较困难农户的房屋先行改造建设。本着“先规划、后建设、有特色”的原则，注重科学规划，突出地方特色，着力改善农村人居环境，推进城乡一体化。

（一）高度重视，周密安排部署。各县区人民政府及各相关单位主要负责人必须高度重视房屋安全隐患大排查大整治工作，加强组织领导，精心组织安排，明确检查重点、时间节点和工作责任，做到动员部署到位、组织落实到位、机制保障到位。

（二）落实责任，确保取得实效。各级要切实履行职责，层层自查自纠、强化检查督查，要做到排查不留死角、不留盲区、不漏一户，对排查出的房屋安全隐患要迅速制定应急处置措施，要严格落实日常巡查、应急处置、建档立卡、挂牌督办等制度。对排查出的风险点不得漏报、瞒报，否则要依法依规追究相关人员的责任。各县区人民政府要于每年8月20日前以表格形式（见附件）分别向市城乡建设规划局（农村危房整治情况）和市住房和城市管理局（城镇危房整治情况）报送房屋安全整治情况。

（三）加强宣传，引导社会参与。要充分利用电视、报纸、微信公众平台等媒体，对房屋安全隐患大排查大整治工作进行广泛的宣传，动员全社会参与，营造浓厚的社会氛围。要及时宣传先进典型和经验，公开曝光违法典型案例。

（四）夯实基础，建立长效机制。要把房屋安全隐患大排查大整治工作中的好经验、好做法，及时总结提炼固化为规章制度和标准规范，形成长效机制，常抓不懈。
