# 汉中市人民政府关于支持农业产业化重点龙头企业做大做强的实施意见

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

农业产业化重点龙头企业是构建现代农业经营体系，提升农业规模化、组织化、市场化程度的重要抓手。对促进小农户对接大市场，加快农业提质增效，带动农户特别是贫困户增收具有重要意义。为支持农业产业化龙头企业做大做强，进一步增强农业农村发展活力，现提出如下实施意见：

一、总体要求

以中央1号文件为指导，以深化农业供给侧结构性改革为主线，以促进农业增效、农民增收、农村增绿为目标，坚持市场需求导向，突出问题意识和短板意识，通过提升加工水平，创新流通方式，打造知名品牌，加强对外开放，强化引导扶持，多措并举，提升全产业链开发水平，切实增强龙头企业示范带动能力，促进农产品产销对接，助推汉中农业追赶超越和脱贫攻坚。

二、发展目标

到2020年，力争产值5000万元以上龙头企业达到70家，产值过亿元企业达到20家以上。力争生猪、茶叶、猕猴桃、食用菌、中药材、粮油等产业过亿元企业分别达到2家以上。全市主要农产品加工转化率达到70%，农产品加工流通企业在龙头企业中占比达到70%以上。全产业链农业经营体系不断壮大，以大型骨干龙头企业为引领、中小企业为支撑、适度规模经营为依托的现代农业生产格局基本形成。

三、支持重点

1、粮油龙头企业。坚持“稳定产能、优化品质、节本增效、综合利用”的思路，围绕百万亩优质水稻和双低油菜基地建设，支持粮油中高端产品开发及综合利用，促进龙头企业做大做强。一是支持企业新品开发。二是加大产品综合利用。三是促进产业节本增效。推行“龙头企业+合作社+农户”、“龙头企业+服务组织+农户”及“订单农业”等方式，支持龙头企业牵头引进适宜机械化生产的水稻油菜优质专用品种，扩大规模化生产，推行代耕代种代管等社会化服务，实行“统一品种、统一农资、统一管理、统一收购”，通过提高内在品质，提升发展效益。鼓励企业通过土地流转、股份合作、返租倒包等多种形式扩大经营规模，积极开展社会化服务，发展订单农业。

2、果蔬龙头企业。按照“稳定蔬菜、突破菌业、调优果业、强化仓储”的发展思路，重点支持蔬菜、食用菌、果业企业（合作社）建设保鲜、加工、分选等设施设备，带动果蔬产业持续发展。一是加快建设果蔬保鲜库。100吨冷库20个左右的，给予优先项目扶持。二是提高产品精深加工水平。鼓励龙头企业与高等院校、科研院所合建加工创新中心，重点围绕食用菌、柑橘、猕猴桃产业，引进风味速食、配餐酱料、果脯果汁等配套生产加工线，不断提升果蔬产品加工利用水平，提升果蔬产业发展效益。支持企业采用先进生产工艺，开发新品填补全市果蔬加工领域空白。三是加快特色产品自营出口。800万元以上的企业，给予一定奖励。对积极推进出口农产品质量安全示范区，产品出口货值居全市前3位的县区，市政府给予表彰奖励。

3、茶叶龙头企业。依托汉中茶叶资源禀赋，坚持“做亮品牌、开拓市场、产品多元、产业融合”的思路，支持龙头企业组建产业联盟，引领茶产业转型升级。一是打造国际知名品牌。100个以上汉茶品牌专营店，树立一批“汉中仙毫”展示牌，做好“汉中仙毫”品牌包装策划。力争用5-10年时间，把“汉中仙毫”打造成国内外公认的知名茶叶品牌。对品牌宣传成效突出的，给予一定额度广告费用补贴。二是加快产业融合发展。,县区政府可给予一定奖励。三是组建茶叶产业联盟。支持各县区整合优势资源，筛选10-20个在业内具有重要地位的茶叶生产加工企业，组建汉中仙毫茶产业联盟，发挥联盟在科技创新、产销对接、产品开发方面优势，鼓励具备条件的行业联盟组建企业集团，争取在资本市场上市融资。对在境内外主板、中小板、创业板、全国中小企业股份转让系统（即“新三板”）挂牌并成功实现融资的，按市政府有关政策给予扶持奖励。

4、畜牧龙头企业。以骨干企业为依托，加快建设生猪产业联盟，积极做好大型企业集团招商引资工作。支持发展集“原种扩繁、饲料生产、定单养殖、屠宰加工销售、信用担保”于一体的全产业链生猪产业联盟等先进模式，通过抓典型、树样板、推模式，实现生猪产业规模扩张、提质增效。积极开展对外招商引资，引进一批实力强、影响大、科技含量高的外地大型龙头企业，来汉投资原种扩繁、畜禽屠宰、产品深加工等领域，补齐产业发展短板。各级政府及有关部门要在项目审批、用地等环节给予支持。引导企业发展“猪—沼—菜（茶、果）—游”等循环种养模式，加快有机肥生产加工线建设，提高畜牧业可持续发展水平。支持企业引进国内领先智能化管理设备，大力发展种养循环，开展畜禽面源污染治理，提升资源利用水平。

5、生物资源开发。立足天麻、杜仲等“汉八味”中药材及名优水产养殖资源优势，鼓励生物资源提取的龙头企业，以功能食品、添加剂、生物药品等为主攻方向，加快构建校企联合技术研发平台，开展黄酮、花青苷、葡甘聚糖、紫杉醇、茶多酚、胶原蛋白等生物提取物系列产品开发，提高资源综合利用率。促进中药材、水产等特色产业链条延伸、效益提升。

四、保障措施

1县区是支持龙头企业做大做强的责任主体，要尽快制定具体意见和推进措施，层层夯实责任，把各项任务落实到位，切实抓好大型龙头企业培育工作。各相关部门要结合自身职能，从政策扶持、项目安排、资金整合、配套建设等方面制定具体措施，各司其职，相互配合，形成强大的工作合力。

2。财政部门要发挥市投资控股集团优势，市县联动、整合放大涉农资金，采取入股、贴息、担保、租赁等方式，支持有实力、潜力大的骨干龙头企业发展；国土部门要在年度建设用地指标中单列一定比例专门用于龙头企业建设配套辅助设施。对发展农业主导产业、建设农业园区等达到一定规模的，可按农业用地安排一定比例的附属设施建设用地；要强化金融机构服务“三农”职责，积极扩大农村资源资产抵押、质押贷款范围，切实加强对龙头企业的支持力度，对具备发展潜力的龙头企业、农业园区等，在贷款额度、利息及手续办理等方面给予支持优惠；电力部门对市政府确定的重点龙头企业，在加工、仓储用电方面享受电价优惠；要完善农业保险制度，扩大粮油生产保险范围，加快建立生猪、蔬菜、茶叶、果业等价格和天气指数保险试点；税务部门要落实好龙头企业税收优惠政策；工商、质监等部门要帮助企业创建著名（驰名）商标和名牌产品；农业部门要支持企业申报省级、国家级龙头企业，落实好龙头企业扶持政策。

3加大龙头企业走出去、引进来战略实施力度，围绕优质特色产业，整合包装一批精品项目，通过项目招商、以商招商、叩门招商，吸引一批实力强、品牌亮、影响广的国内大型企业和集团，来汉投资农业产业发展。提升招商服务水平，对用地、环保等审批关键环节，在符合国家政策的前提下，实行限时办结、督查问效。对暂时经营性困难但后续发展前景好的龙头企业，可采取基金入股、兼并重组、引进外地企业合作等方式，盘活企业资产资源，帮助企业尽早恢复产能。对市政府确定的重点招商引资项目，由市投资控股集团采取市场化方式，从农业发展专项基金中给予优先扶持。

4、强化跟踪问效。各县区政府、各有关部门要夯实工作责任，确定目标任务，不断创新工作机制，切实加大骨干型龙头企业培育力度。对工作成效突出的县区和部门给予表彰奖励，工作不力的予以通报批评。各县区、各部门每年12月10日前报送1次支持农业产业化龙头企业做大做强工作落实情况。市上根据需要适时召开联席会议，协调解决问题，加快工作进度。

汉中市人民政府

2017年6月14日
