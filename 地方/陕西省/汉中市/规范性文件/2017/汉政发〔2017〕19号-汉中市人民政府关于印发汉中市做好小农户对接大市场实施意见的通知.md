# 汉中市人民政府关于印发汉中市做好小农户对接大市场实施意见的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

《汉中市做好小农户对接大市场实施意见》已经市政府2017年第7次常务会议研究同意，现印发给你们，请认真遵照执行。

汉中市人民政府

2017年6月21日

汉中市做好小农户对接大市场实施意见

打通农产品进入市场通道，促进小农户对接大市场，推动农业供给侧结构性改革，扩大汉中农产品市场份额，现提出如下实施意见：

一、指导思想

立足汉中区位优势和特色优势农产品资源禀赋，以打通和连接农产品生产、加工、仓储、销售、配送等各环节，形成环环相通、环环相连的链式结构为目的，以提高农产品生产经营的组织化、专业化、市场化为手段，突出政策引导，强化市场运作，着眼国内、国际两个市场，努力实现小农户对接大市场，搞活农产品流通，防范和化解风险，有效促进农业增效，农民增收。

二、实施目标

近期目标：　　远期目标：通过政府引导，把小农户对接大市场作为加速我市农业现代化的有效途径，打造农产品全产业链生态系统，形成稳定的农产品全产业链利益共享机制，推动农业产业化加快发展。

三、基本原则

（一）政府引导原则：结合我市农业发展实际，充分发挥政府政策引导。

四、工作措施

（一）提高小农户的组织化程度。引导小农户参加农民专业合作社，鼓励农产品龙头企业与农民专业合作社成立行业协会或产销联盟。以农民专业合作社、农产品企业、行业协会、产销联盟为抓手，采取“小农户+N”+农民专业合作社，++农产品行业协会，+”等），提高小农户的组织化程度，促进小农户向大生产转变，对接大市场，扩大农产品销售，有效规避农业生产风险，增加农民收入。各县区政府要大力复制、推广先进的经验和模式。对新带动100户、5001000户以上小农户参与市场经营的农民专业合作社、农产品企业、行业协会和产销联盟，通过金融、投资、项目等方面分档予以支持。（责任单位：市农业局、商务局、供销社、财政局，各县区政府）

（二）做大做强农产品加工企业。围绕茶叶、柑橘、魔芋、山野菜、蜂产品、食用菌、生猪、家禽、中药材等特色优势农产品，与国内外大型知名农产品企业合作，开发新产品，延长产业链，提高产品附加值。鼓励“企业+农户+基地”的模式，培育新型农产品加工企业。加强质量监管，引导企业针对目标市场，开发适销对路的产品，鼓励企业在目标市场进行质量认证，取得当地市场“通行证”。根据企业综合带动效应，对企业研发、生产、市场开拓和品牌创建给予有效支持。（责任单位：市工信委、农业局、商务局、供销社、财政局，各县区政府）

（三）大力发展现代化农产品物流配送体系。引导本地有实力的物流企业加快开展农村配送业务，为农产品经营主体提供运输、仓储、共同配送、信息共享等综合物流服务。鼓励企业单位整合闲置、低效厂房、场地，转型升级改造现代化农产品仓库。重点支持发展农产品冷链物流，加大冷库、冷藏车等冷链设施设备投入。鼓励农产品企业与物流企业合作建设集仓库、运输、分拨、配送等功能于一体的农产品仓储物流配送中心。各县区政府依托资源禀赋打造区域性的农产品物流配送中心（园区）。对提供农产品仓储、配送服务的物流企业，给予政策优惠和费用补贴。（责任单位：市商务局、交通局、邮政管理局、农业局、供销社、财政局，各县区政府）

（四）大力打造农产品特色知名品牌。积极实施农产品品牌引领战略。各县区政府立足特色产品和地域品牌，重点将汉中茶叶、柑橘、魔芋、山野菜、腊肉、牛肉干、乌鸡、天麻、香菇、木耳和野蜂蜜等名优农特产品进行精深挖掘，精细加工，质量认证，打造一批具有影响力的区域公用品牌。鼓励企业大力打造地理标志产品、农产品地理标志产品，争创省级名牌产品、陕西省著名商标和中国驰名商标，打造一批产品竞争力强、市场占有率高、影响范围广的企业自有知名品牌。对新获得区域公用品牌、地理标志产品、农产品地理标志产品的县区和农产品经营主体，一次性奖励10万元；对新获得省级名牌产品的农产品经营主体，一次性奖励10万元；对新获得汉中市驰名商标的农产品经营主体，一次性奖励1万元；对新获得陕西省著名商标的农产品经营主体，一次性奖励3万元；对新获得中国驰名商标的农产品经营主体，一次性奖励30万元；对在境外进行商标注册、质量认证的农产品经营主体，视情况给予重奖。（责任单位：市工商局、质监局、商务局、农业局、食药监局、工信委、财政局，各县区政府）

（五）着力构建境内外农产品销售网络。树立大市场理念，确定一线城市为汉中市特色农产品销售的目标市场。各级政府要积极与一线城市建立战略合作关系，把采买供应汉中特色农产品作为我市与央企、大中型国企、民营企业签订战略合作协议的固定条款，着力打通我市与一线城市企业之间的农产品交易渠道。加强窗口饭店建设，与一线城市的餐饮饭店建立汉中特色农产品直供直采合作关系。对在目标市场开设全面展示汉中特色农产品名优小吃的餐饮饭店，给予支持。积极与机关、企事业单位、科研院所、学校建立汉中特色农产品直供直采合作关系。鼓励企业在一线城市拓展农产品营销网络，对在北京、上海、广州、深圳、杭州、天津、西安等大城市设立汉中名优地产品牌店和在其商场、超市、农产品批发市场设立地产品牌展销专柜（区）、特色商业街区设立汉中地产品牌示范店，年销售额达到1000万元以上的农产品经营主体，给予一次性房租50%的补助，最高不超过50万元；对在重点出入境口岸设立汉中地产品牌展销厅，年销售额达到800万元以上的农产品经营主体，给予一次性展厅租金50%的补助，最高不超过50万元；对走出国门在境外开设营销网点，年销售额达到500万元以上的农产品经营主体，给予一次性房租50%的补助，最高不超过100万元。（责任单位：市商务局、农业局、食药监局、供销社、财政局，各县区政府）

（六）大力推进农产品会展促销。各级政府及有关部门应积极主动，采取上门展、抱团展、定向展、融合展等多种形式举办展会，促进农产品销售。主动到北京、上海、深圳一线城市等目标市场上门举办展会，积极塑造大品牌，突出汉中特色农产品原产地、原生态、有机绿色特点，高位包装策划，高端布展组展，全面展示展销汉中特色农产品。鼓励各县区政府、行业协会、企业抱团组展。鼓励针对高端市场、目标客户群定向举办特色农产品展会。鼓励把汉中特色农产品展销与汉中旅游、文化展示相融合，扩大农产品销售。（责任单位：市商务局、农业局、供销社、经合局、旅发委、财政局，各县区政府）

（七）积极推进“农商互联”快速发展。以“全国电子商务进农村综合示范县”项目实施为契机，加大农村信息基础设施建设，完善农村物流配送体系，充分发挥我市农产品资源优势，整合利用并引导扶持商务、农业、供销、邮政等涉农网络平台和信息资源，加强农产品网上销售，引导特色农产品主产区在知名电商平台开设地方特色馆，支持电商平台与农业合作社、养殖基地、种养大户建立直采直供关系。重点开展“农商互联”工作，支持新型农业经营主体、农产品加工企业与电商企业全面对接融合，推动农产品流通线上线下交易，建立健全农产品供应链，促进农村电商产销互动提升发展。对农产品电子商务年交易额新增达到1000万元（含）以上的农产品经营主体，一次性奖励10万元；新增5000万元（含）以上的，一次性奖励30万元；新增1亿元（含）以上的，一次性奖励50万元。（责任单位：市商务局、农业局、供销社、财政局，各县区政府）

（八）招大引强涉农龙头企业。围绕农业优质特色产业，整合包装一批精品项目，通过项目招商、以商招商、叩门招商，吸引一批实力强、品牌亮、影响广的国内大型企业和集团，来汉投资农业产业发展。提升招商服务水平，对用地、环保等审批关键环节，在符合国家政策的前提下，实行限时办结、督查问效。对暂时经营性困难但后续发展前景好的龙头企业，可采取基金入股、兼并重组、引进外地企业合作等方式，盘活企业资产资源。对市政府确定的重点招商引资项目，由市投资控股集团采取市场化方式，从农业发展专项基金中给予优先扶持。（责任单位：市经合局、农业局、商务局、发改委、国土局、环保局、财政局，各县区政府）

（九）强化“汉”字品牌宣传。由财政出资，对汉中农产品区域公用品牌在中央电视台、香港凤凰卫视台等高端媒体进行品牌宣传，着力扩大“汉”字农产品品牌的知名度、美誉度和影响力。（责任单位：市农业局、商务局、财政局，各县区政府）

（十）加大金融保险支农力度。发挥金融保险作用，针对农产品，创新金融保险产品，有效降低农产品生产经营风险，稳定市场。各县区政府通过产品质押、政府担保、贴息、股权投入等灵活方式，解决季节性生产、收储过程中的资金周转问题。加大金融机构对农产品龙头企业、农民专业合作社的贷款扶持力度，切实缓解农业企业融资难问题。鼓励各县区政府对辖区内的重点农产品实行统保，通过购买农产品价格指数保险、气象指数保险等险种，有效控制农产品生产、加工、销售风险。鼓励对农产品经营主体提供信贷担保，给予一定的奖励。（责任单位：市金融办，市保险协会，各县区政府）

（十一）整合资金，推动产业脱贫。各级各部门统筹整合资金，集中使用，提升效益，用好各项政策性（如扶贫）资金，把产业发展基金重点投向农产品全产业链领域，特别是农产品冷链物流、仓储配送设施，推动农产品做大做优做强。把小农户对接大市场与脱贫攻坚工作紧密联系起来，确定“一村一品”、“一镇一业”，通过做优做精、做大做强农产品，带动一村一县脱贫。（责任单位：市发改委、农业局、农工办、人社局、林业局、水利局、文旅局、商务局、供销社、国土局、工信委、财政局、金融办、工商局、扶贫办，各县区政府）

五、保障措施

（一）成立汉中市小农户对接大市场领导小组，由市政府主要领导任组长，市政府分管副市长、市政府秘书长和分管副秘书长、市商务局局长任副组长，市发改委、工信委、财政局、农业局、扶贫办、林业局、水利局、交通局、商务局、旅发委、食药监局、工商局、质监局、经合局、供销社、邮政管理局、金融办、农工办，市投资控股集团公司主要负责同志和市脱贫攻坚工作顾问为成员。领导小组办公室设在市商务局，具体负责日常工作，各相关成员单位根据各自职责抓好工作落实，办公室主任由市商务局局长兼任。各县区政府、开发区管委会要建立相应的领导组织机构。原则上每季度由领导小组组长或副组长主持召开一次小农户对接大市场领导小组会议，研究部署有关工作。

（二）加大政策保障力度，优先解决农产品企业的用地、资金、人才、电力等要素保障问题，严格落实农产品流通有关税收优惠政策，为农产品企业建设、运营、管理提供“绿色通道”。对辐射面广、带动能力强的大型农产品经营主体，市政府采用投融资平台、基金、担保、质押、贴息、融资租赁等多种灵活方式，促进小农户对接大市场。积极主动对接中省政策性平台公司，争取成为试点示范，促进各项政策倾斜和落地。《实施意见》中涉及资金支持的奖励标准，由市商务局会同相关部门另行制定细则。（责任单位：市国土局、发改委、人社局、电力局、国税局、地税局、财政局、金融办、商务局，各县区政府）

（三）2017年，确定在勉县、西乡、留坝3个县区进行小农户对接大市场试点工作，先行先试，总结经验，形成一批可复制可推广的经验做法，按步骤、分阶段在全市开展。

（四）对农产品龙头企业的支持政策按照《汉中市人民政府关于支持农业产业化重点龙头企业做大做强的实施意见》贯彻执行。
