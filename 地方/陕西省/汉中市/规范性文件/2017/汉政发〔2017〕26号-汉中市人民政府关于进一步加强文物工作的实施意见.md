# 汉中市人民政府关于进一步加强文物工作的实施意见

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

为认真贯彻落实国务院《关于进一步加强文物工作的指导意见》（国发〔2016〕17号）和省政府《关于进一步加强文物工作的实施意见》（陕政发〔2016〕54号），切实加强全市文物工作，不断提升新形势下文物保护、管理和利用水平，结合汉中实际，提出如下实施意见。

一、重要意义

文物承载灿烂文明，传承历史文化，是祖先留给我们的瑰宝，是不可再生的珍贵文化资源，是国家的“金色名片”。汉中历史悠久，文物资源众多，尤以“两汉”、“三国”为特色的历史文化遗存驰名中外。进一步加强文物工作，支持关心文物事业，对于传承优秀传统文化，满足人民群众精神文化需求，发展壮大文化旅游产业，建设“三市”具有十分重要的意义。

二、目标要求

（一）总体要求

坚持“保护为主、抢救第一、合理利用、加强管理”的文物工作方针，深入挖掘和系统阐发文物所蕴含的文化内涵和时代价值，充分发挥文物资源在弘扬社会主义核心价值观、提高市民素质和社会文明建设中的作用，加大管理力度，强化保护措施，切实做到在保护中发展、在发展中保护，提升文化软实力，努力推动“文化旅游强市”建设。

（二）主要目标

到2020年，全国重点文物保护单位、省级文物保护单位保存状况良好，市、县级文物保护单位保存状况明显改善，尚未核定公布为文物保护单位的不可移动文物保护措施得到落实；馆藏文物保存环境大幅改善，预防性保护和抢救性修复工作持续加强；博物馆保护展示利用手段和形式实现突破，基础设施建设和服务水平进一步提升；类型多样、体制多元的博物馆格局基本形成，免费开放工作不断深化，公共服务功能和社会教育作用更加彰显；文物法制建设和执法队伍建设全面加强，文物安全长效保障机制更加健全；文物保护科学化和文博队伍专业化程度明显提高；文物执法督察体系基本建立，执法力量得到加强，安全责任体系更加完善，安全形势明显好转；社会力量广泛参与文物保护利用格局基本形成，文物资源促进经济社会发展的作用逐步增强；文物对外交流合作积极开展，汉中文化影响力进一步扩大。

三、主要任务

（一）推进文物工作法治化

加大普法力度。围绕“中国文化和自然遗产日”“5.18国际博物馆日”“12.4法制宣传日”等，持续开展形式多样的文物法制宣传教育和法治实践活动，创新方式宣传普及文物保护法律法规，与社会共享遗产资源信息，强化公众文化遗产保护意识。

严格依法行政。市、县两级文物行政管理部门要聘请专业法律顾问，推行行政决策合法性审查，建立行政执法全过程记录，做到公正文明执法。逐步建立和完善县区文物行政执法机构，加强对行政执法人员的专业培训，提高行政执法水平。

筑牢安全底线。健全文物安全管理制度，完善预案预警机制；注重现代科技在文物安全保护中的应用，提高防范能力；加强田野文物管护，建立群防网络和信息沟通机制；完善文物安全防控体系，有效打击和遏制文物犯罪。公安、工商和文物等部门要加强协作，加大防范和打击文物犯罪的力度，坚决打击盗窃、盗掘、走私、倒卖文物等犯罪活动。追缴的涉案文物应及时无偿移交同级或上级文物行政主管部门，文物行政主管部门根据文物保护法律法规对侦办案件过程中的先进单位和个人予以奖励。

（二）全面加强文物保护工作

加强文物保护规划编制。按照“多规合一”要求将文物保护规划相关内容作为上位规划纳入城乡规划；继续做好全国重点文物保护单位和省级文物保护单位规划及重要区域性文物保护规划的编制。按照轻重缓急，分批次有序开展市县级文物保护规划编制，建立健全全市文物保护规划体系。

强化文物保护基础工作。各县区对本辖区内不可移动文物的数量、分布情况和保护状况要建立健全档案，对已公布的文物保护单位要认真落实“四有”规定，对尚未公布为文物保护单位的不可移动文物要加强保护管理；充分运用“三普”成果，在前期公布的市、县级文物保护单位的基础上，遴选申报一批省级文物保护单位和全国重点文物保护单位。扎实开展文物日常养护巡查和监测保护，注重与周边环境协调，重视岁修，减少大修，防止因维修不当造成破坏，对存在重大险情的各级文物保护单位及时开展抢救性保护；组织实施一批具有重大影响和示范意义的文物保护重点项目，加强革命文物本体保护维修，提升陈展开放水平，弘扬社会主义核心价值观。

推进大遗址保护工作。推动龙岗寺遗址考古工作和秦蜀古道调查和勘探工作，对辖区内大遗址进行全面调查、勘探和选择性发掘，为大遗址保护提供科学依据；积极申请国家大遗址保护经费，探索大遗址保护模式，推进龙岗寺遗址国家考古遗址公园和李家村遗址等省级文化遗址公园建设；结合“一带一路”倡议，扎实做好丝绸之路世界文化遗产点张骞墓的文物保护工作。

加强可移动文物保护。充分利用可移动文物普查成果，全面梳理可移动文物保存状况，抢救修复濒危珍贵文物。逐步完善文物收藏单位的文物监测和调控设施。扎实推进文物库房标准化建设，改善文物存储环境。支持实施经济社会发展变迁物证征藏工程。加强文物科技保护机构建设，探索建立多元化、多渠道、高效率的科技投入体系和保护机制，逐步实现文物保护科技的研发、转化和运用。

做好城乡建设中的文物保护。正确处理城乡建设与文物保护的关系，防止擅自拆除、迁移不可移动文物等建设性破坏行为发生，保持历史文化名城、街区、名镇、名村和传统村落整体格局、历史风貌的真实性和完整性。在旧城区、危旧房改造中，应根据文物资源调查数据妥善筛查遴选，进行分类处理，逐处落实不可移动文物保护措施。坚持文物前置审批手续，大型基本建设项目和在地下文物埋藏区、水下文物保护区、各级文物保护单位保护范围及建设控制地带内的建设项目要依法开展考古调查勘探发掘，相关经费纳入建设工程预算。涉及水库淹没区的文物调查内容应纳入水库移民安置规划大纲。涉及文物保护单位保护范围和建设控制地带的建设工程，必须严格按照文物保护法的规定办理审批手续。

（三）推动文物合理利用

健全博物馆体系。以汉中市博物馆为龙头，加快推进县级博物馆建设，具备条件的县区至少拥有一座体现地域特色的综合博物馆或专题博物馆。推进汉中市文物博物馆、生态博物馆、社区博物馆等建设工作。贯彻落实国家文物局《关于进一步推动非国有博物馆发展的意见》，规范非国有博物馆管理，提高办馆质量，逐步健全以国有博物馆为主，非国有博物馆为补充的博物馆体系。

完善博物馆功能。全面开展馆藏文物保存状况调查, 提档升级文物收藏单位的设施设备，建立馆藏文物保存环境监测平台；支持重点博物馆藏品征集工作，充实藏品数量；进一步提升馆藏文物展示利用水平，实施智慧博物馆项目，提高博物馆的数字化建设水平，实现博物馆公共文化服务全覆盖；完善博物馆免费开放机制，加强免费开放专项资金监管；探索推进理事会管理制度，总结推广理事会制度改革经验；鼓励博物馆加强与学校教育的有效衔接，建立优秀传统文化研习基地，发挥文化传承与社会服务作用。

推动不可移动文物展示利用。以龙岗寺遗址、西汉三遗址、张良庙古建群等文物保护单位为龙头，带动全市不可移动文物展示利用水平逐步提升；持续加快展示利用项目实施，借鉴国内外成功经验，不断探索展示利用形式，全力打造“大汉中、古栈道”“两汉三国”等系列精品展示利用项目。

探索研发文创产品。以汉中文物资源为依托，鼓励支持文博单位设计研发文化创意产品，围绕汉文化、三国文化、红色文化、宗教文化等开发文物复仿制品和衍生品，形成独具汉中特色的文化创意产品。

扩大对外交流合作。结合“一带一路”建设等机遇，创新方式、突出主题，组织汉中精品文物赴外地展出交流，增强以汉中市博物馆、川陕革命根据地纪念馆等为核心的交流与合作，提升在文物学术研究和保护领域的知名度；积极引入其他省市精品文物、优秀文化遗产在汉中展出，与其他博物馆或相应机构建立馆际长期友好关系，深化专家学者双向互动交流，在文化交流互鉴中扩大汉中文化影响力。

四、职能职责

（一）加强组织领导

全市各级政府要进一步提高对文物保护重要性的认识，增强历史文物保护意识，切实履行文物保护主体责任，充分发挥文物保护主导作用，统筹做好文物的有效保护与合理利用。要把文物工作作为领导班子和领导干部综合考核评价的重要参考，不断建立完善文物保护责任评估和责任追究制度。进一步加强文物行政机构建设，根据文物工作实际，明确承担文物保护管理职能机构的工作。全市各级文物行政部门要依法做好本行政区域内的文物工作，根据文物普查成果，建立全市文物资源总目录和数据资源库，全面掌握文物保存状况和保护需求，实现文物资源动态管理，推进信息资源社会共享和文物普查成果转化利用，有计划开展文物保护利用工作。

（二）夯实保护责任

进一步做好不可移动文物权属确认工作，明晰和落实文物所有人、使用人的保护管理责任。处于文物密集区的政府派出机构或直属事业单位承担管辖区的文物保护管理责任，落实文物安全管理主体责任；无使用人的由文物所在县区文物行政部门聘请文物保护员负责保护管理；企业、镇村、社区等集体所有或使用的不可移动文物，由文物所在地基层文物管理部门和企业董事会、村委会、居委会等签订文物保护责任书；个人所有或使用的不可移动文物，由文物所在地基层文物管理部门和所有人或使用人签订文物保护责任书。对文物保护单位进行修缮、国有文物保护单位变更用途、非国有不可移动文物转让抵押或者改变用途等，应按规定程序报批。

（三）建立协调机制

要建立健全文物安全联席会议制度，发改、公安、教育、国土、建规、住管、环保、工商、文化、文物、旅游、宗教等部门要按照职能分工，各司其职、各负其责，形成工作合力，严格落实文物保护基本程序，及时解决文物保护中存在的问题，夯实维护文物管理秩序。发展改革部门要将文物工作纳入国民经济和社会发展规划，积极支持文物保护建设项目。城乡建设规划部门要加大历史文化名城、名镇、名村、街区和传统村落中的文物保护力度，配合文物部门划定文物保护单位的保护范围和建设控制地带，并作为项目审批依据，在城市规划建设时尽可能避开不可移动文物，在《建设用地规划许可证》颁发前督促建设单位履行文物保护报批手续。财政部门要落实文物保护专项资金，对存在重大险情的文物保护单位在资金安排上予以支持。国土资源部门要在文物保护项目的用地审批上开辟“绿色通道”，在土地利用、资源开发等项目审批中加强文物保护。教育部门要加强与文物部门的协调合作，建立中小学生参观博物馆的长效机制。公安、工商等部门要加大对盗窃、盗掘、倒卖、走私文物等违法犯罪活动的打击力度，及时向文物部门移交涉案文物。交通运输、水利、农业、林业等部门要做好相关建设工程中的文物保护工作。公安、消防、气象部门要对文物的安防、消防、防雷提供技术支持并做好监管。

五、保障措施

（一）保障经费投入

各级政府要根据“分级管理、分级负担”的原则，依法将文物工作所需经费纳入本级财政预算，建立财政投入稳定增长机制，加大对文物保护专项资金的投入，加强经费绩效管理和监督审计。大力推广政府和社会资本合作（PPP）模式，拓宽社会资金进入文物保护利用领域的渠道。

（二）加强科技应用

加大文物科技保护投入，注重文物保护科技成果的推广应用。利用“互联网+”等现代信息技术，推动文物保护与现代科技融合创新。重点支持文物保护修复、文物预防性保护、智慧博物馆、文物保护设备等方面的研发、转化和应用，全面提升文物保护与利用的科技水平。

（三）重视人才培养

发挥已有专业技术人员特长，以重点科研项目为支撑，通过“传、帮、带”做好人才培养。鼓励从业人员参加专业教育深造，适时开展相关课题研究，做好成果转化。结合需要培养专业型和复合型人才，适当提高市县文博单位中高级专业技术人员比例。重视民间匠人传统技艺的挖掘、保护与传承。

各县区、各有关部门要按照本实施意见要求，结合工作实际，认真抓好贯彻落实。

汉中市人民政府

2017年9月29日
