# 汉中市人民政府关于印发汉中市盐业体制改革实施方案的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门，直属机构：

《汉中市盐业体制改革实施方案》已经市政府2017年第12次常务会议审议通过，现印发给你们，请认真贯彻落实。

汉中市人民政府

2017年10月16日

汉中市盐业体制改革实施方案

为贯彻落实《国务院关于印发盐业体制改革方案的通知》（国发〔2016〕25号）和《陕西省盐业体制改革实施方案》（陕政发〔2017〕3号）精神，推进我市盐业体制改革，进一步激发市场活力，实现盐业资源有效配置，促进盐行业健康持续发展，结合汉中盐业实际，特制定本方案。

一、总体要求

按照国务院和省政府盐业体制改革总体部署，以确保食盐质量安全和供应安全为核心，在全市盐业系统实行政企分开。在坚持食盐专营制度基础上推进供给侧结构性改革，坚持依法治盐，创新管理模式，注重统筹兼顾，健全食盐储备，严格市场监管，建立公平竞争、监管到位的市场环境，逐步建立市场化食盐运营体系和新的盐业管理体制。

二、主要任务

（一）完善食盐专业化监管体制

1.实行政企分离。根据政企分开、政资分开的原则，对目前市盐务局与市盐业公司政企合一、以司养局的体制和职能进行调整，将市盐务局与市盐业公司进行彻底分离。

2.理顺管理体制。保持现有专业化食盐监管体制不变，坚持食盐安全属地管理原则。市盐务局是市政府直属事业机构，正县级建制，行使全市盐业行政管理职能，负责全市盐业工作，制定盐业发展规划，依法负责全市食盐质量安全及食盐市场的管理与监督。与公安、司法、卫生计生、食品药品监管、工商等行政执法部门密切协作，依法加强食盐安全监管。

各县区盐业主管机构要结合行政执法体制改革，推进盐业监管体制改革，剥离食盐批发企业原承担的行政管理职能，将食盐质量安全管理与监督职能移交食品药品监管部门或市场监管部门负责。

3.完成清产核资。由市国资委牵头，市盐务局、财政局、审计局等部门参与，制定清产核资方案，抓紧做好市盐务局与市盐业公司改革前的清产核资工作和改革后的资产划分工作。

（二）理顺盐业公司管理体制

政企分离以后，市盐业公司成为依法依规自主经营、自负盈亏的市场主体，主管部门为市盐务局，资产由市国资委监管。市盐业公司领导班子由市盐务局、市国资委按相关程序进行任免。市盐业公司要建立规范的公司法人治理结构，转换经营机制，发挥本市盐行业的龙头和主渠道作用，积极通过与县区公司、生产厂家、社会资本开展战略合作和资源整合，支持组建新的联合体或新的有限责任公司、股份公司等集团公司，抱团竞争，促进企业做强做大。

（三）改革食盐政府定价机制

坚持食盐批发专营制度，未经许可，其他各类商品流通企业不得经营食盐批发。食盐批发和零售价格，由企业根据经营成本、食盐品质、市场供求状况等因素自主确定。市县物价部门要加强对食盐零售价格的市场监测预警，配合盐业主管机构采取措施，保持价格基本稳定，特殊情况下可依法采取价格干预或其他紧急措施，防止普通食盐价格异常波动。

（四）加强科学补碘工作

充分发挥食盐批发企业的保障供应作用，确保全市合格碘盐覆盖率在90%以上。积极做好科学补碘宣传教育，合理布局非碘盐销售网点，满足特定人群非碘盐消费需求。市卫计局要组织落实好市内碘缺乏病的监测防治工作。市盐务局、财政局要会同有关部门组织落实好省政府碘盐补贴运销费用，或直接贴补贫困人口等政策，保证边远地区群众吃得上、吃得起合格碘盐。

（五）改革工业盐运销管理

各县区政府要严格执行国家放开工业盐运销管制政策要求，取消对小工业盐及盐产品进入市场的各类限制，放开小工业盐及盐产品市场和价格，研究制定落实细则和责任追究等有关管理办法。批发企业要建立销售档案，保存完整的销售记录，严防工业盐流入食盐市场。市县镇盐业主管机构依法负责本行政区域内工业用盐市场的管理与监督。质监部门要加强工业盐产品质量监管，依法查处不合格产品。工商部门要依法查处涉盐虚假广告和侵权假冒行为。

（六）改革食盐储备体系

按照社会化储备、县区储备的思路，建立由政府储备和企业社会责任储备相结合的食盐储备体系，确保自然灾害或突发事件发生时食盐的安全供应。市盐务局委托有资质的盐业公司进行日常管理和轮储，实行动态监管，确保储备到位。市级财政预算应安排资金对本级食盐储备贷款贴息、管理费支出等给予支持。完善企业储备制度，食盐批发企业的最低库存不得低于本企业正常情况一个月的平均销售量，各级盐业主管机构要加强对库存情况的监督检查，防止食盐市场供应短缺和企业囤积居奇。鼓励企业在最低库存基础上建立成本自担的社会责任储备。

（七）加强应急机制建设

市县盐业主管机构要会同有关部门抓紧研究制定食盐供应应急方案，并向同级政府应急管理部门备案。要密切关注盐业市场动态，紧急突发情况下，由市盐务局按照应急预案规定，采取投放政府储备、调运企业社会责任储备等方式，确保食盐市场稳定。

（八）加强盐业市场监管

市县盐业主管机构要会同相关部门加强市场监管，依法打击制贩假盐或以工业盐假冒食盐等各类涉盐违法行为，全面排查食盐运输、流通过程中的安全隐患，不断净化盐业市场，保障食盐安全。

三、工作要求

（一）严格时间节点

2017年11月底前完成市盐务局、市盐业公司领导班子任命， 2017年12月中旬前实现政企分离，将职能、人员从市盐业公司完全剥离。

（二）确保队伍稳定

盐业部门要统一思想认识，自觉服从大局，切实做好职工干部的思想政治工作，确保盐业队伍思想稳定，工作有序，体制改革平稳。各县区政府具体负责本级盐业企业改制、重组和职工安置等工作，及时解决盐业体制改革中的有关问题，在制定县区盐业体制改革方案时，应将如何解决盐务局与盐业公司人员分流安置问题的意见纳入方案中，切实按照政企、事企分开的原则把政策落实到位。

（三）加强宣传引导

各级宣传部门要充分利用信息媒体，加大对盐业体制改革相关政策的宣传力度，进一步统一思想、凝聚共识，为盐业体制改革顺利推进营造良好氛围。新闻媒体要加强对制贩假盐违法犯罪活动处理案件的宣传报道，形成强大震慑力，维护盐业市场秩序。盐业主管机构要加强食盐安全宣传力度，普及食盐安全知识，引导消费者从正规渠道购买食盐，做好科学补碘宣传教育，提高孕妇、儿童和群众的科学补碘意识，提高全社会的食盐安全意识。

各县区政府负责本行政区域内盐业体制改革任务的推进落实，参照本实施方案制定具体实施办法或细则。
