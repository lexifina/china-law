# 汉中市人民政府关于深入推进政府和社会资本合作（PPP）工作的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

在公共服务领域推广政府和社会资本合作（PPP）模式，是中省确定的重大改革任务，是落实“五新”战略、提升发展质效的重要举措，是破解我市基础设施不足、项目建设不快、发展资金短缺难题和打造经济新增长点的重要抓手。2014年全市启动推广运用PPP模式以来，各级各部门主动作为、全力推进，PPP工作取得了一定成效。但也存在工作推进不平衡、项目前期工作不足和重建设、轻运营等问题。为破解难题、促进发展，市政府研究决定，深入推广运用PPP模式，现就有关事项通知如下。

一、提高认识，推动工作深入开展

各级各有关部门要深刻认识PPP模式对促改革、惠民生、稳增长的重要意义，坚定不移地推进PPP工作，推动公共服务从政府供给向合作供给、从单一投入向多元投入转变，提高公共服务的供给质量和效率，激发社会资本活力和创造力，助力经济社会持续健康发展。一是坚持科学发展理念。牢固树立全局意识，切实注重统筹协调，确保PPP模式与经济体制、财政体制、投融资体制等改革配套推进、相互促进。二是坚持市场导向原则。充分利用市场力量，鼓励社会资本特别是民营资本参与PPP项目，推动互利共赢，提振市场信心。三是坚持精心科学谋划。认真谋划一批社会需求大、行业前景好的项目实施PPP模式，扩大PPP模式覆盖范围，促进PPP项目行业领域多元化。四是坚持规范高效运行。细化工作内容，落实主体责任，重点从项目示范、资金引导、市场培育、制度保障等方面，推进PPP模式的规范、可持续发展。

二、紧扣重点，全面提升工作绩效

（一）做好项目谋划储备工作。一是做实项目前期。加强项目可行性研究，确保合理有效地提供公共产品和服务，对条件成熟、适合采用PPP模式的项目，依法选择社会资本方，同步开展项目前期审批程序，做到项目签约落地即可开工，切实提高工作效率。二是严把项目入口。以PPP综合信息平台为依托，建立能进能出的项目库动态管理机制，提高PPP项目入库率，按规定完成实施方案编制、论证评审等工作。三是加强项目策划。各级发改、财政部门要会同行业主管部门在充分论证项目可行性的基础上，根据拟实施PPP项目的行业、区域及阶段特点，分类运用市场定价、政府调价、财政补贴等方式，合理确定项目运作方式、合作周期、收费定价机制、投资收益水平、风险分配框架、收益回报机制等因素，做好物有所值评价和财政承受能力论证工作，为推动项目落地奠定坚实基础。

（二）加大两个“强制”推进力度。按照国家在污水、垃圾处理领域强制推广PPP模式的精神，对全市辖区内的城区、园区、村镇污水处理设施、配套管网、污泥处理、流域综合治理项目，采用PPP模式统一规划、设计、建设和运营，充分发挥社会资本的技术优势、管理优势，各级财政不得再安排“两场（厂）”专项建设补助，财政资金要加快从“补建设”向“补运营”转变。由市住管局统筹牵头负责、各县区政府及市级有关部门具体负责，按照统一标准、统一规划、统一采购、同步推进的要求和“整县打包、整市推进”方式，将分散的同类项目或关联项目组合打包，整合新建项目和已建成的存量项目，采取整体采购、整体签约、整体设计、分期实施的方式，加快推进“两场（厂）”项目建设。要按照“成熟一批、推进一批，边试点、边规范，边总结、边完善”的原则，建立健全市县协调机制、方案联审机制、项目执行机制、督导检查机制和上下联动机制，今年年底前完成实施方案制定和项目前期工作，2018年3月底前完成项目采购及合同签署，确保项目尽早进入实质运营。

（三）畅通民营资本进入渠道。各级行业主管部门要进一步开放公共服务领域，着力激发和促进民间投资，鼓励国有企业、民营企业、混合所有制企业、外资企业按照同等标准、同等待遇的原则，平等参与PPP项目竞争，并享有同等的土地和税收政策。项目实施机构要依法合理设定采购标准和条件，确保采购过程公平、公正、公开，优先采用公开招标、竞争性谈判、竞争性磋商等方式，鼓励社会资本积极参与、充分竞争。不得以不合理的采购条件对潜在社会资本方实行差别待遇或歧视性待遇，对民营资本设置差别条款和歧视性条款的PPP项目，各级财政部门不得安排资金和政策支持。各部门、单位要在政府和社会资本之间合理分散项目风险，既要实现公共服务供给效率和资金使用效益的提升，又要统筹考虑社会资本的合理收益预期、政府的财政承受能力以及使用者的支付能力，防止任何一方因此过分受损或超额获益。

（四）明确项目推进责任。各县区政府要结合本地实际认真制定年度实施计划，健全工作协调机制，减少行政审批环节，整合资源，凝聚合力，全力支持引入社会资本投资和采用PPP模式的项目，确保每年都有一批项目进入中、省PPP项目库。特别是PPP项目入库“空白县”，必须要有实质性突破，力求更多地项目达标入库、按期落地、规范实施。

市发改委牵头并协调相关部门，按照促存量项目转化、策划包装新建项目、推进在建项目、捆绑整合关联项目的思路，全面梳理符合PPP实施条件的项目，加快策划包装一批以PPP为主要模式的重大基础设施、民生事业、重要园区和重点景区建设等重大项目，力争取得重大突破。

市财政局要加快PPP项目策划和组织实施工作，依法依规将PPP项目财政支出责任纳入财政预算、中长期财政规划，督促项目主体、责任单位加快工作节奏，争取更多PPP项目落地；采取向社会购买咨询服务等方式推动项目实施，总结形成一批可复制、可推广的典型经验做法，指导县区和部门更好运用PPP模式推进项目建设。

市住管局要加快建设汉中境内的城镇污水、垃圾处理设施，适时启动建设其他镇污水、垃圾处理设施，确保“两场（厂）”建设全覆盖。

市国土局会同有关部门对PPP项目用地需求作出科学合理预测，优先安排土地利用年度计划，经批准后公布实施，确保PPP项目所需建设用地。

市金融办要积极推进服务方式创新，加强同业合作，充分发挥银行、证券、保险、信托等机构在项目论证、财务分析、资金供给、风险防范等方面优势。

市投资控股集团要加快设立和运营PPP引导基金，强化对PPP项目的融资支持。

其他各行业主管部门要在各自管理的领域内征集遴选PPP项目，组织编制项目实施方案，做好项目报批、招商、采购、执行监管、绩效评价和项目移交等工作，对项目单位根据项目合同依法办理的规划选址、环保评审和项目核准审批等要优化程序、限时办结。

（五）支持化解政府性债务。各级各有关部门要在存量政府性债务项目中，选择价格调整机制灵活、市场化程度较高、投资规模较大、需求长期稳定、可能产生一定现金流的项目，引入社会资本参与项目改造和运营，转型为PPP项目。在存量政府性债务项目转换过程中，要注重将其与新建项目进行整合，通过将无现金流或现金流较少项目与能产生稳定现金流项目整合，实现区域联动、行业联动、资源与资本联动，加大化解存量政府性债务工作力度。

三、强化措施，保障项目顺畅实施

（一）夯实目标责任。市财政局负责统一部署全市PPP模式推进工作，各县区政府对本级PPP工作负总责，明确专门机构和人员具体协调跟踪PPP项目的各阶段推进工作。结合年度PPP工作目标任务，对项目实施方案编制、审查、可承受能力评价、物有所值评价和项目招标、合同签订、项目开工建设等重要节点要倒排时间，环环相扣，确保各项工作按期推进，项目尽早落地建设。

（二）完善管理制度。结合中省政策规定和工作实际，努力在PPP项目投资服务、用地保障、金融服务、信用体系等方面研究制定切实可行的措施意见，加快完善PPP项目管理、预算管理、政府采购、绩效评价、咨询机构库管理等制度办法，促进PPP项目设立、运行、管理各环节公开透明、规范有序、务实高效，为PPP项目实施提供制度保障。

（三）推动信息公开。依托PPP综合信息平台，实现项目信息的及时发布与投资需求的有效对接，推动市场信息对称和充分公平竞争。依法及时、充分披露项目实施方案、招标投标、采购文件、项目合同、工程进展、运营绩效等相关信息，切实保障公众知情权，主动接受社会监督，维护公共利益。

（四）积极宣传推介。充分利用各类媒体资源广泛宣传PPP模式的深刻内涵和重要意义，加强对工作动态、政策文件和PPP项目的宣传，面向社会公开推介前期工作成熟、具备谈判条件的项目，为社会资本参与PPP项目搭建平台，充分调动各方积极性，营造PPP模式加快推广运用的良好环境。

（五）强化督查考核。建立县区推进PPP项目考核机制，落实项目实施监管责任，制定项目实施计划、推进时间进度表和分行业项目绩效指标体系，对PPP工作开展情况、项目签约落地情况、项目规范操作情况进行跟踪督查、定期通报，确保全程有监督、有考核、有验收。

汉中市人民政府
