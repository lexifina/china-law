# 汉中市人民政府办公室关于印发国家土地督察西安局反馈秦岭有关问题整改方案的通知

各县区人民政府，市政府有关工作部门：

《国家土地督察西安局反馈秦岭有关问题整改方案》已经市政府同意，现印发给你们，请认真抓好落实。

汉中市人民政府办公室

2018年8月8日

国家土地督察西安局反馈秦岭有关问题整改方案

按照自然资源部部长陆昊同志今年6月在陕西调研秦岭生态保护修复等问题时的工作指示和批示要求，国家土地督察西安局深入秦岭地区6个地市开展调研，向我省印发了《关于落实陆昊部长批示精神反馈秦岭有关问题的函》，共指出5个方面存在的问题。为深入贯彻落实中省决策部署，进一步加大秦岭生态环境保护工作力度，确保反馈问题全部整改到位，推动我市生态环境质量持续改善，提出以下整改方案。

一、指导思想

认真贯彻落实习近平总书记重要批示精神，以及中央派驻专项整治工作组和省委省政府秦岭专项整治工作要求，提高政治站位，增强“四个意识”，牢固树立和践行绿水青山就是金山银山的理念，坚持“实事求是，有则改之”原则，严肃认真做好国家土地督察西安局反馈秦岭问题整改工作，确保秦岭绿水青山常在，自然生态系统安全稳定，生态环境持续改善，切实筑牢秦岭生态安全屏障。

二、整改措施和责任分工

（一）矿业权退出和地质环境治理方面：合法矿业权退出补偿和地质环境治理尚未完全到位。

整改措施：

1. 矿业权退出方面：对所辖县区内各类保护区内探、采矿权进行摸排、核实、清理，确保国家级自然保护区内矿业权全部退出，其它各类保护区矿业权限期退出；按照市政府《关于印发汉中市秦岭生态环境保护总体规划的通知》（汉政发〔2018〕15号）要求，严把矿业权准入门槛，在禁止开发区、限制开发区内禁止新设探矿权、采矿权，适度开发区资源配置的重点为采用先进工艺技术和措施的采选加工企业，秦岭适度开发区内采矿权2020年底前全部退出；严格依据省级《矿业权退出指导意见》，依法依规补偿退出合法矿业权；妥善处置矿业权退出引起的信访、诉讼问题，维护社会稳定。

2. 地质环境治理方面：按照市、县矿山地质环境保护与治理规划，分步实施矿山地质环境恢复治理工作；按照矿山地质环境保护与土地复垦方案要求，坚持“边开采、边治理”，建设绿色矿山；用好用活各县区矿山环境恢复治理专项资金，积极争取中、省矿山环境恢复治理项目资金，鼓励引导社会资本参与，多渠道筹集资金，开展矿山环境恢复治理工作；切实发挥汉中市移民搬迁生态修复投资有限公司作用，积极构建“政府扶持、社会参与、开发式治理、市场化运作”的矿山地质环境恢复和综合治理新模式。

责任单位：市国土局牵头，各县区政府配合。

（二）耕地和永久基本农田保护方面：25°以上坡耕地多，全面退耕还林还草与耕地目标责任落实矛盾突出。

整改措施：严格按照省政府核减后的耕地保有量和基本农田保护目标面积，有序推进25°以上坡耕地退耕还林。

责任单位：市国土局牵头，市林业局、各县区政府配合。

（三）保护区内农民生产生活方式方面：农家乐增长较快，缺乏总量控制机制。

整改措施：加强农家乐监督管理，建立农家乐总量控制机制，按照“总量控制、适度发展、规范经营”的原则，指导和帮助农家乐有序向城镇周边集聚，向品牌化、特色化发展；做好保护区农家乐变更登记及注销的服务工作；加强对农家乐食品经营许可和经营活动的监督管理；按照公共场所卫生管理要求加强对秦岭保护区内住宿农家乐监督管理；加强对农家乐环保设施验收与登记备案及排污行为的监督管理，对符合要求的农家乐督促办理环评审批手续，对排放的污染物严格监管，严禁未经处理直接排放。

责任单位：市旅发委牵头，市工商局、市食品药品监管局、市卫计局、市环保局，各县区政府配合。

（四）基础设施、小水电建设和旅游开发方面：存在项目未批先建、临时用地复垦不及时、违法用地等问题。

1. 交通基础设施建设和旅游开发方面：

整改措施：加快建立健全共同责任机制，加大交通基础设施建设和旅游开发过程中国土资源违法违规行为的查处力度，对查处的违法违规行为，依法依规完善用地手续，消除违法状态；严格临时用地、弃碴场审批，对压占基本农田、不符合国家政策法规的一律不予审批；加大监管力度，对临时用地、弃碴场等复垦不及时的限期整改。

责任单位：市国土局牵头，市交通局、市旅发委、各县区政府配合。

2. 小水电建设方面：

整改措施：严格按照《陕西省秦岭区域和全省自然保护区小水电站问题整治及生态恢复治理工作方案》，做好陕西佛坪国家级自然保护区自行建设的三官庙、金水源2座水电站退出工作。对保留的陕西汉中朱鹮国家级自然保护区核心区的莲花水电站和实验区的党河水库坝后水电站，严格按省政府要求抓好整改，督促完成项目环评和河流生态修复工程，严格落实环保、水保各项治理措施，开展农村水电站安全生产标准化建设，达到绿色水电标准。

责任单位：市水利局牵头，市国土局、市环保局配合。

（五）管理工作方面：存在薄弱环节

1. 基层国土资源执法机构、人员不足，监管能力薄弱。

整改措施：加强基层国土执法队伍建设，配齐人员车辆，落实动态巡查制度，做到及时发现、及时制止、及时上报。

责任单位：市国土局牵头，各县区政府配合。

2. 各类保护区的范围是相关部门在各个历史时期确立的，保护区未确定准确的界址点和坐标、保护范围不清的问题，在有些地方比较突出。

整改措施：

（1）制定林业系统8个国家级自然保护区和2个省级自然保护区边界测绘勘定工作实施方案，组织开展保护区边界测绘勘定工作，规范划定保护区范围和功能区四至界线标识。力争12月底前完成边界测绘勘定工作。

责任单位：市林业局牵头，相关县区政府配合。

（2）做好略阳珍稀水生动物自然保护区边界测绘勘定工作，力争10月底前完成保护区边界测绘勘定暨界桩、界牌、防护保护工程。

责任单位：市水利局牵头，略阳县政府配合。

3. 生态保护红线划定尚未完成。

整改措施：完善汉中市生态保护红线划定方案，争取尽快完成省级审批。

责任单位：市环保局牵头，各县区政府配合。

4. 生态环境保护存在多头监管现象，国土资源、环保、林业等部门都有各自的卫星遥感监测影像数据，重复拍摄，分散使用。

整改措施：建立完善抄告制度，各职能部门在开展检查工作中，如发现有其他部门管辖的违法行为，要及时抄告给相关部门，实现信息资源共享、互通互联，形成齐抓共管的良好氛围。

责任单位：市国土局牵头，市环保局、市林业局配合。

三、工作要求

（一）提高思想认识。秦岭生态环境保护是当前压倒一切的重大政治任务和重点工作，各责任单位要高度重视，认真落实习近平总书记和陆昊部长重要指示批示精神，切实强化“四个意识”，认真落实主体责任，做到“条条要整改、件件有着落”。

（二）加强协调配合。各责任单位要树立大环保理念和全市“一盘棋”思想，通力配合、密切协作，主动担当、积极作为。牵头单位要切实履行主体责任，细化整改措施，明确整改责任人，确保整改落到实处。配合单位要增强大局意识、担当意识，从自身职责出发，采取强力措施，与牵头单位共同推动问题整改落实。

（三）强化销号管理。各牵头单位要建立问题台账，持续推进整改，每月向市秦岭办报送整改进展情况，整改完成的及时向市秦岭办报送自查报告。市秦岭办要加强调度、跟踪督办，坚持整改一个、销号一个，做到问题不解决不放过。

抄送：省秦岭办。

市委办公室，市人大常委会办公室，市政协办公室。
