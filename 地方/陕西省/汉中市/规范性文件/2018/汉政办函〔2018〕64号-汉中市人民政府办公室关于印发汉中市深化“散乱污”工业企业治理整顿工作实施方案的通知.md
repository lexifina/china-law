# 汉中市人民政府办公室关于印发汉中市深化“散乱污”工业企业治理整顿工作实施方案的通知

各县区人民政府，汉中经济开发区管委会，市政府有关工作部门：

《汉中市深化“散乱污”工业企业治理整顿工作实施方案》已经市政府同意，现印发你们，请认真贯彻执行。

汉中市人民政府办公室

2018年8月2日

汉中市深化“散乱污”工业企业

治理整顿工作实施方案

为贯彻落实全市大气污染防治突出问题整改工作推进会精神，扎实整改我市“散乱污”工业企业治理整顿存在的突出问题，根据《陕西省2018年“散乱污”工业企业综合整治专项行动方案》（陕治霾办函〔2018〕9号）、市委办、市政府办《关于印发汉中市铁腕治霾打赢蓝天保卫战三年行动方案（2018-2020年）的通知》（汉办发〔2018〕9号）和《关于印发汉中市整改大气污染防治突出问题工作方案的通知》（汉办发〔2018〕18号）要求，现就深化“散乱污”工业企业治理整顿工作制定以下实施方案。

一、工作目标

按照“谁主管、谁负责”和“谁许可、谁负责”以及属地管理原则，依法依规对“散乱污”工业企业进行综合整治。通过清理取缔、提升改造、停产整顿、完善手续、退城入园等措施，深入推进“散乱污”工业企业的综合整治，使企业合法生产经营，安全、达标排放。2018年8月31日前对列入2017年“散乱污”工业企业清理取缔清单的企业全部整治到位，2018年10月15日前对2018年年初摸排列入“散乱污”工业企业清理取缔清单的企业全部整治到位，做到“两断三清”或停产整治。2018年8月再次摸排的，应于2018年12月底前完成治理整顿。自2019年起，每年10月31日前完成当年新摸排列入“散乱污”工业企业的治理整顿工作。

二、“散乱污”工业企业的认定标准和范围

（一）“散乱污”工业企业认定标准

1. “散乱污”工业企业是指具有固定设施、有污染排放的生产性工业企业，并具有环保不达标、无证无照、违法用地和违法建设，存在安全隐患其中一项或多项基本特征的工业企业。2018年的整治范围为规模以下“散乱污”工业企业。

2. 散：选址布局不符合城市发展规划、城乡建设总体规划、土地利用规划等已发布生效的各类规划的工业企业。

3. 乱：所处行业不符合现行国家产业政策，属淘汰类行业，未取得工商营业执照、环境影响评价审批手续、土地审批手续、安全评价审批手续、发改部门项目核准备案手续等其中一项或多项相关审批手续的工业企业，主要是指工业小作坊。

4. 污：是指生产过程产生污染物对环境带来明显影响和危害，无污染防治设施、污染防治设施不完备或不能对产生的污染物进行有效收集处理，造成违法排放或超标排放的工业企业。

（二）地域范围和行业

全市辖区内所有规模以下工业企业。

三、坚持分类处置

（一）清理取缔一批

有下列情形之一的，均应清理取缔：

1. 不符合国家现行产业政策，属淘汰类行业工业企业；

2. 属于违法违规排放、超标排放废水、废气、废渣，经研判，无法实现环保达标排放的工业企业；

3. 存在重大安全生产隐患，经研判，无法通过改造彻底消除不安全生产隐患的工业企业；

4. 缺失行政审批手续，无法补办导致违法生产的工业企业。清理取缔应履行政府决定、书面告知等程序，采取多部门联动、联合执法方式予以取缔，清理取缔后必须达到“两断三清”。

（二）改造提升一批

通过技术改造、增加生产设施、改变生产工艺等方式，彻底消除安全生产隐患或实现环保达标排放，并安装在线监测系统予以改造提升。企业改造完成后应通过政府监管部门组织的验收通过后方可恢复生产。

（三）停产整顿一批

具备“散乱污”工业企业基本特征，生产现状不符合要求，但可以通过整治消除特征，消除安全生产隐患、实现环保达标排放、获取合法手续的，应先行停产，接受处罚，限期整改。整改期满后应通过政府监管部门验收达到要求，方可恢复生产。

（四）退城入园一批

对不符合城市发展规划、城乡建设总体规划、土地利用规划的企业，积极创造条件，鼓励搬迁至工业园区。

（五）完善手续一批

对手续缺失但可以完善的，应限定期限，履行合法程序，补齐手续。

四、工作安排

（一）全面排查。2018年8月底前，各县区政府和市级园区管委会要对本辖区内所有工业企业再次进行拉网式大排查，排查要做到全覆盖，不漏一户（各县区政府、市级园区管委会负责）。

（二）甄别认定。对摸排出的企业是否属于“散乱污”工业企业应经过三轮甄别认定。第一轮由镇办组织力量认定；对镇办无法认定或认定后企业有异议的，可上报县区或市级园区管委会组织发改、经贸、环保、安监、国土、工商、住建等部门进行第二轮甄别认定，认定期限自接到申请起不超过5个工作日；县区或市级园区管委会无法认定或认定后企业有异议的，可上报市“散乱污”工业企业治理整顿领导小组办公室（以下简称市散乱污整顿办）进行最后一次亦即第三轮认定，认定期限自接到申请起不超过10个工作日（各县区政府、市级园区管委会，市散乱污整顿办负责）。

（三）建立台账。对甄别认定的“散乱污”工业企业要建立工作台账，实行一企一档，清单化管理。台账应载明企业名称、厂址、行业、经营范围、法定代表人、“散乱污”认定结论主要认定事实、治理整顿措施、治理整顿期限、包抓责任部门等信息，档案应有对比照片、甄别认定记录等相关印证资料（各县区政府、市级园区管委会，市散乱污整顿办负责）。

（四）综合整治。县区政府或市级园区管委会应按照“谁主管、谁负责”、“谁许可、谁负责”和属地管理的原则，合理确定“散乱污”工业企业治理整顿包抓责任部门、镇办和配合部门，按照分类施策、一企一策的思路确定每户企业治理整顿措施和完成期限，做到责任实、措施硬，确保按期完成（各县区政府和市级园区管委会负责）。

（五）验收销号。“散乱污”工业企业治理整顿任务完成后，包抓部门或镇办应向同级散乱污整顿办书面申请验收销号，并向上级整顿办备案。验收销号应采取现场查验、核对整改措施是否到位、召开会议集体研究等方式进行，应做到完成一户、验收销号一户，不拖延、不悬空（各县区政府、市级园区管委会负责）。

（六）源头治理。对新上工业投资项目、扩能改造项目、技改项目要严把项目核准、备案关，确保符合国家产业政策。原则上新上工业项目，必须落户工业园区，要确保项目投产后依法取得安全生产许可，获得排污许可证并实现达标排放。要积极引导、鼓励、扶持企业打造绿色制造体系，生产绿色产品。要落实属地监管责任，加大检查力度，防止现有企业再次出现“散乱污”生产行为（各县区政府、市级园区管委会负责）。

五、工作标准

各县区政府和市级园区管委会对辖区内甄别认定的“散乱污”工业企业，按照“先停后治”的原则，分类采取停产整顿、改造提升、完善手续、退城入园、清理取缔等方式，精准整治，坚决杜绝已取缔的“散乱污”工业企业异地转移或死灰复燃。

六、工作职责

（一）各县区政府、市级园区管委会及其“散乱污”工业企业治理整顿领导小组办公室：各县区政府、市级园区管委会对辖区内“散乱污”工业企业治理整顿工作负总责，全面领导组织推动辖区内“散乱污”工业企业治理整顿工作，定期向县区党委、党工委汇报工作进展情况，构建散乱污整顿办牵头抓总、成员单位分工负责、镇办主办的齐抓共管的工作格局。散乱污整顿办要切实发挥好牵头抓总的作用，精心做好工作方案拟定、配套政策制定、督查、甄别认定、通报、信息报送、舆论宣传、联合执法等工作（各县区政府、市级园区管委会负责）。

（二）市工信委：承担市散乱污整顿办职能，牵头组织推动全市“散乱污”工业企业治理整顿工作。具体承担全市工作方案制订、配套政策研究提出、督查、指导、组织甄别认定、信息报送、汇报、会同市级有关部门进行考核、提出奖惩初步意见、筹办市级成员单位联席会议等职责。

（三）市环保局：主要负责无环保设施、无环评手续、企业超标排污、违法排放污染物等环境违法行为的调查处理。

（四）市工商局：主要负责全市无证无照、证照不全的“散乱污”工业企业的治理整顿，对存在危害群众健康、破坏环境资源的无证无照生产经营的企业坚决依法取缔，并把好企业注册登记关。

（五）市安监局：主要负责全市存在重大安全生产隐患的“散乱污”工业企业的治理整顿。对符合办证条件但未办理安全生产许可的企业限期办理安全生产许可证。

（六）市国土资源局：主要负责对存在违法用地、违法建设等问题的 “散乱污”工业企业进行治理整顿，禁止利用既有违法建设场所从事工业生产经营等活动。

（七）市发改委：严格执行中省产业政策，严把新上工业投资类项目准入关。

（八）市综合执法局：依法查处“散乱污”工业企业违法建设行为。

（九）市公安局：依法严厉打击以暴力、威胁等方式阻碍国家公职人员处置“散乱污”工业企业。为联合执法提供警力支持。

（十）市政府督查室：负责市“散乱污”工业企业治理整顿领导小组办公室提交重大任务的督查督办。

七、保障措施

（一）加强组织领导，夯实工作责任。市上已经成立了全市“散乱污”工业企业治理整顿工作领导小组及其办公室，各县区政府、市级园区管委会也要建立相应的领导机构及工作机构，制定工作方案，精心安排部署，细化工作任务，强化治理措施，推动“散乱污”工业企业清理整治工作取得实效。市、县区、园区散乱污整顿办和镇办政府要自上而下签订排查治理整顿工作目标责任书、承诺书，落实落细工作责任（各县区政府、市级园区管委会负责、市散乱污整顿办）。

（二）坚持问题导向，强化督导检查。市工信委、环保局、国土资源局、工商局、安监局牵头的5个督导组，要继续按照责任分工，持续推进县区、市级园区“散乱污”工业企业的综合整治。督导组要每月深入县区、市级园区督导一次，督导结束后向市散乱污整顿办提交督导书面报告（2018年第一次督导要求9月底前上报）。年终目标任务考核时，各督导组负责对相关县区和市级园区“散乱污”工业企业整治工作完成情况进行验收考核，并向市散乱污整顿办提交考核结果报告。

第一督导组：由市工信委带队，负责督导城固县、洋县、佛坪县。

第二督导组：由市环保局带队，负责督导汉台区、南郑区、经济开发区。

第三督导组：由市国土资源局带队，负责督导勉县、宁强县、略阳县。

第四督导组：市工商局带队，负责督导留坝县、滨江新区、航空智慧新城。

第五督导组：市安监局带队，负责督导西乡县、镇巴县、兴汉新区。

同时，县区、市级园区和市级有关部门可通过购买服务的方式，组成若干小分队，采取明察暗访、交叉检查等方式，加强对“散乱污”工业企业的督察检查（市工信委、环保局、国土资源局、安监局、工商局负责，各县区政府、市级园区管委会配合）。

（三）完善工作机制，及时跟踪督办。坚持月通报、不定期督办、年度考核机制。市散乱污整顿办每月将全市工作开展情况以简报形式予以通报。各县区、市级园区要建立信息搜集反馈报送机制，于每月28日前上报工作进展情况及经验材料。市上每季度召开一次督导组会议，了解动态，掌握情况，推动工作。督导组对督查中发现的重大问题要形成督办函，提醒、敦促县区和市级园区限期整改到位（市工信委，环保局、国土资源局、安监局、工商局负责）。

（四）加大考核力度，强化结果运用。进一步加大对县区、市级园区“散乱污”工业企业治理整顿工作的考核。对考核前三名的予以奖励表彰，对考核排名后三位的予以通报批评。对工作推动不力、不作为、慢作为、未按要求完成整治任务的单位和责任人，提交市监察委进行追责问责 （市工信委、环保局、国土资源局、安监局、工商局负责，市考核办、市政府督查室配合）。

（五）落实工作经费，加大保障力度。“散乱污”工业企业治理整顿量大面宽，需要大量的人力和物力保障。各县区政府、市级园区管委会、有关部门要落实“散乱污”工业企业治理整顿专项工作经费，为完成“散乱污”工业企业综合整治目标任务提供资金保障。各县区和市级园区应为散乱污整顿办配备相应的工作人员，平川不少于6人、山区不少于4人、园区不少于2人（各县区政府、市级园区管委会负责）。

（六）强化宣传引导，营造良好氛围。各县区、市级园区和市级有关部门要充分利用电视、报纸、广播、网络、期刊等新闻媒体，采取多种形式，广泛宣传整治“散乱污”工业企业的重要意义，曝光问题企业和查处情况，动员广大群众积极参与。设立有奖举报电话，发挥公众举报和媒体监督作用，形成全社会合力支持“散乱污”工业企业治理整顿的良好舆论氛围（市散乱污整顿办牵头，市文广新局、信息办配合）。

（七）建设创业基地，提高就业服务。进一步加快中小企业创业基地建设，加大政策扶持，完善服务体系，提高创业承载力；着力引导一批创业者到基地创业，鼓励和引导一批科技创新型和产业集群型民营中小企业到基地聚集，扩大基地孵化功能。建立促进就业的政策体系，加快培育和完善统一、开放、竞争有序的人才和劳动力市场，创造公平就业环境，加强职业教育培训、就业服务和就业援助，开展送岗位、送渠道、送培训的“三送”活动，全面促进就业工作（市人社局牵头，各县区政府、市级园区管委会负责）。

（八）建立长效机制，巩固整改成果。从今年起到2020年底前，每年5月31日前向市“散乱污”企业治理整顿领导小组上报当年新摸排“散乱污”工业企业名单，10月31日前完成本年度整治任务。为保证入档资料完整性，即使各县区政府、市级工业园区没有新增的“散乱污”工业企业，也要书面行文报告，说明情况。
