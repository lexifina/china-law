# 汉中市人民政府办公室关于印发汉中市一带一路重点项目建设任务分工一览表的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

为进一步落实《汉中市人民政府办公室关于贯彻陕西省“一带一路”建设2018年行动计划的实施意见》（汉政办发〔2018〕47号）精神，发挥重点项目建设对我市打造丝路源点城市的支撑作用，经市政府同意，现将《汉中市“一带一路”重点项目建设任务分工一览表》印发给你们，请按照任务分工和时间节点抓好落实推进。

一要高度重视。各县区、各部门要充分认识重点项目建设对于我市融入“一带一路”建设、发展“三个经济”、建设“三市”的重要意义，加强组织领导，统筹谋划推进，确定专门机构负责项目的日常管理，确保项目顺利推进实施。要注意规避和防范各种风险，确保项目质量和安全。

二要加快推进步伐。各县区、各部门要落实好“一带一路”相关扶持政策，严格对照任务分工，重点围绕“六个交易平台”建设，督促新建项目单位加快完善有关手续，帮助推动续建项目进展，积极协调解决影响项目推进中存在的问题，助推项目加快建设。

三要强化信息报送。各县区、各部门要加强对重点项目的督查督办工作，确定专人每季度将项目进展情况报市商务局（联系人：撒莉；电话兼传真：2628683）。市“一带一路”建设领导小组办公室（市商务局）每半年对项目建设开展情况进行一次督导检查，并将督导检查情况报市政府，对推进缓慢、工作不力的县区和部门在全市通报。
