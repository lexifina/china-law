# 汉中市人民政府办公室关于印发汉中市引进优质教育资源来汉兴办品牌教育助推经济社会发展的实施意见的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

《汉中市引进优质教育资源来汉兴办品牌教育助推经济社会发展的实施意见》已经市政府同意，现印发给你们，请认真贯彻实施。

汉中市人民政府办公室

2018年5月7日

汉中市引进优质教育资源来汉兴办品牌教育助推经济社会发展的实施意见

为加强教育对外开放与合作交流，满足人民群众多样化优质化教育需求，推动教育事业与我市重点产业深度对接，支撑汉中生产、生活、生态“三生融合”发展，助力汉中追赶超越和“三市”建设。现就汉中市引进优质教育资源来汉兴办品牌教育助推经济社会发展提出如下实施意见。

一、总体要求

（一）指导思想

以习近平新时代中国特色社会主义思想和党的十九大精神为指引，认真贯彻落实教育优先发展战略，以办好人民满意教育为宗旨，进一步加强教育对外开放与合作交流，大力引进优质教育资源来汉兴办品牌教育、对接地方产业发展，提高教育质量水平，提升教育支撑发展、服务发展能力水平。

（二）主要目标

在“十三五”期间，通过制定一系列优惠吸引政策，重点引进“双一流”高校及与我市区域产业支撑和城市未来发展契合度高的高校、优质品牌化中小学校（幼儿园）。在大力引进增量型优质教育资源的同时，科学谋划学校布局，精准对接产业需求，实现校企深度合作，“产学研”发展模式基本完善，教育对外交流合作水平进一步提高，教育服务市场发育更加成熟，快速提升教育对经济社会发展和产业升级的贡献力，打造汉中经济社会发展新的增长极。

（三）基本原则

1. 坚持优质发展。坚持质量优先，引优扶强，择优支持引进优质教育资源独立或合作举办教育机构，进一步提高全市各类学校办学水平和教育质量。通过引进并整合优质教育资源，最大化发挥学校智囊团和人才库作用，辐射带动全市其他产业集约化发展，推动我市区域经济社会健康、优质、可持续发展。

2. 坚持创新发展。实行教育机构非营利性和营利性分类管理，以政策创新为核心，实施差别化扶持政策，在财政资助、税收优惠、土地供给、人才吸引、教师社会保障等方面加大扶持，吸引优质教育资源来汉办学。

3. 坚持依法办学。深入贯彻党的教育方针，全面执行《中华人民共和国民办教育促进法》和国务院《关于鼓励社会力量兴办教育促进民办教育健康发展的若干意见》，遵循教育发展、学校发展和师生成长的客观规律，减少过多行政干预。

4. 坚持需求导向。围绕我市经济社会发展重大需求，全面对接创新驱动发展战略，深化产教融合、协同创新，促进各级各类学校合理定位，差别化发展，不断增强教育服务地方经济社会发展能力。

5. 坚持深化改革。以“放管服”改革为重点，深化学校综合改革，破除体制机制障碍，优化教育资源配置，促进教育内涵、特色发展。

二、重点任务

（一）打造优质教育资源集聚区。围绕中心城区“一江两岸”、兴汉新区等重点区域，建设1-2个教育园区，科学规划优先引进入驻。坚持高起点、高标准、高质量，使之成为汉中的形象建筑和城市亮点。延展社会教育和城市配套体系，加快推动教育+文化、教育+旅游行业发展，发挥汉中文化、旅游优势资源，通过资源共享和区域合作，打造一批示范性研学旅行优质产品、精品线路和研学基地；加快推动教育+互联网+科技，打造智慧教育、智慧校园，加快教育现代化建设，促进优质教育资源向农村、贫困地区覆盖。充分发挥教育集聚资源的优势，全力推动“城市+大学”的双向互动，推动餐饮、医疗、商业、物流、金融、通讯等业态向教育产业园区聚集，着力打造汉中教育新城，为加快建设丝路源点城市、全方位扩大开放奠定基础。

（二）引进优质高等教育学校。重点引进“双一流”大学来我市建立分校或研发机构。积极促进本地高校与地方合作，搭建人才、技术和信息产业、经济沟通交流平台。鼓励高校与企业共建实验室，加强产学研合作，形成以企业为主体、市场为导向、产学研相结合的技术创新体系。在驻汉高校遴选特色鲜明、教学质量高的专业与地方政府和企业共建，打造我市产业发展急需人才培养基地。通过高校引进一批名人、艺术家，有效汇聚各类艺术人才。通过各类技术博览会、科技研讨会展示和宣传高校先进的实用技术，促进企业精准对接所需的技术和人才，将高校的资源优势及时转化为产业优势。到2020年，全市至少新创建一流专业1个，新建国家、省、市工程技术研究中心（企业研发中心、企业技术中心）等产学研开发机构30个。

（三）打造职业教育集团。围绕装备制造、现代材料、高品质食药、文化旅游、新型能源和新兴产业，引进急需、紧缺专业的品牌职业院校。以专业建设为纽带，以协议形式组建相对固定、紧密联系的职业教育集团，实施职业教育集团化办学。根据企业需求调整优化专业结构，实行订单培养，实现院校专业设置与产业集群对接、人才培养与企业用工需求精准对接。到2020年，全市至少创建国家示范中学职业学校1所、精品专业10个。

（四）引进优质中小学和幼儿园。重点引进全国知名高校附属学校、知名教育集团、名校的品牌和优秀管理团队等优质教育教学资源来汉兴办品牌学校，稳定本地生源，吸引外地优质生源。将引进的中小学（幼儿园）作为当地基础教育的示范基地和校长、教师培养、培训基地，在队伍建设、学校管理、教育教学实施、教育评价等方面发挥辐射、示范作用，带动当地中小学校（幼儿园）共同发展。到2020年，基本消除城区学校择校热、大班额等问题，创建省级标准化高中4所。

（五）引进优质培训服务。鼓励民间资金参与在职人员职业培训、农村劳动力转移培训、转岗培训、出国留学等各类非学历教育与教育培训，大力发展社区教育和成人教育，推进终身学习体系和学习型社会建设。将更多的中小学教师、校长培训以购买服务形式外包给专业品牌教育机构，推动驻汉高校参与我市各类培训，提高培训质量和效益。

（六）引进智慧教育管理模式。探索政企合作新模式，引进智慧教育云平台，在教育信息化建设、科技创新、产学研、人才培养等方面进行合作，把全国的优质教育资源通过云平台落户到汉中，推动教育资源信息化和区域教育管理公共服务信息化，实现智慧化的校园服务和管理模式。

（七）加强教育对外交流合作。鼓励和引导高校围绕我市重点产业发展与国内外知名企业开展科研交流合作，为我市培养一流实用型人才搭建平台。加快推进“国际学生感知汉文化基地”项目建设，积极与国内外名校开展名师和优秀学生互派互访活动，促进学校和地区之间的合作交流。

（八）发展教育提升地产附加值。采取“名盘+名校”模式，鼓励大型地产商通过“傍名校”、“引名校”、“办名校”的方式，依附名校的资源，扩大地产影响力。引进大型教育集团与商业地产联手建设以教育核心、教育服务、商业配套为主的“教育综合体”，带动房地产业为城市提供更加精细的配套服务，实现教育和地产互促共赢。

（九）发展教育辅助产业。积极推动教学具、教育图书、教育软件、文具书包、教育玩具、学生餐饮、校服等产业发展，支持本土企业投资教育辅助产业，引进国内知名教育用品企业落户汉中。

三、政策支持

（一）建立教育发展基金。设立10亿元的教育发展基金，主要用于支持引进优质教育资源，支持教育园区和引进学校基础设施建设，保障人才团队、设备购置、项目研发及其他教学和科研条件建设；用于引进学校建设项目贷款和教师培训、社会保险的补助；用于政府购买教育和对促进汉中教育事业发展的公益事业等的支持。各县区结合实际设立教育发展基金，加大对引进学校的财政奖补力度。

（二）加大资金扶持。对引进并正式运行的非独立法人性质的优质高等教育机构，第一年给予不低于1000万元的补助资金，以后每年度根据绩效情况给予不低于300万元的补助资金，连续补助3年。对引进并正式运行的独立法人性质的优质高等教育机构，第一年给予不低于2000万元的补助资金，以后每年度根据绩效情况给予不低于500万元的补助资金，连续补助3年。对于引进的一次性投入达5000万元以上的品牌幼儿园，一次性投入1亿元以上的品牌小学、初中和3亿元以上品牌高中、中等职业学校，经财政部门认定后，按贷款实际产生的利息给予贴息，补助奖励最高不超过1000万元，连续补助不超过3年。

（三）支持学校前期发展。鼓励县区建设教育园区，为引进高等教育机构无偿代建基础设施。各级政府可为引进高校先期建设或提供办学所需校舍、仪器设备、图书和实验、实习场所，学校可定期无偿使用或低价租赁，待条件逐步成熟后再由学校逐年回购。鼓励县区政府通过“零租金”或“低租金”形式，将郊区义务教育学校委托教育品牌管理集团或团队开办非营利性品牌学校。在运营初期，对引进学校在水、电、气、暖等公共服务运转费用上给予一定财政补贴。

（四）吸引社会捐赠。支持引进学校通过楼宇、实验室等设施冠名、授予荣誉称号等方式吸引社会捐赠，市教育发展基金按一定比例配比资金，对获得捐赠的学校给予奖励补助。鼓励企业投资教育基础设施，政府给予一定补贴，产权归企业所有，学校以租赁方式使用教育设施。

（五）支持政府购买服务。鼓励县区政府购买优质教育机构的学校管理服务、特色课程开发、教育评估服务、教育设施服务和培训服务。

（六）强化科研扶持。支持高校加快发展与战略性新兴产业和我市产业发展需要相适应的学科，并给予相应资助。对落地高等教育机构引进的高端研发机构，经认定符合引进条件的，由市政府给予资金支持。支持高校承担基础性、前沿性、关键核心技术攻关项目，对获得国家和省重点支持的重大项目，市本级给予一定的资金配套支持。

（七）鼓励人才引进。引进的品牌学校教师应符合国家规定任职资格要求，在评聘专业技术职务、评先评优、培训进修等方面享受与公办学校教师同等待遇。引进学校与公办学校一样纳入政府各项评比表彰范畴。建立公办民办学校教师派遣交流机制，每年选派公办学校教师到非营利性品牌学校交流任教。其引进的高层次管理人员和骨干教师可享受《汉中市优秀人才服务绿卡》优惠服务政策，可免费居住高层次人才公寓或给予在汉购房补贴，在配偶就业、子女就学、医疗健康等方面提供便利。支持高校积极参与我市高水平新型智库建设，为政府决策提供咨询服务。入选国家和省级智库的，通过定向购买服务等方式，每年给予最高300万元的业务经费资助。

（八）强化土地保障。非营利性学校享受公办学校同等政策，可按照划拨等方式供应土地；营利性学校以有偿使用方式供地，按照招拍挂程序出让用地。只有一个意向用地者的，可按协议方式供地。

（九）减免相关税费。对企业办的各类学校、幼儿园自用的房产、土地，免征房产税和城镇土地使用税，从事学历教育的学校提供的教育服务免征增值税。个人或企业向高校的公益性捐赠在规定比例内准予税前扣除。

（十）完善社会保障。落实各项社会保险政策，引进学校按照规定缴纳社会保险费，其中单位和个人应缴纳的社会保险费由民办学校和教师个人按规定比例承担。落实办学自主权，引进品牌学校在完成国家规定课程前提下，可自主开展教育活动。

（十一）强化特殊支持。对引进的优质教育资源品牌效应明显、对全市经济社会发展具有特别重大意义的，可实行“一事一议”或“一校一议”，予以特别政策、资金支持。

四、保障措施

（一）加强组织领导。市政府成立汉中市引进优质教育资源来汉兴办品牌教育工作领导小组，由市长任组长，分管副市长，市政府秘书长、分管副秘书长任副组长，市编办，市发改委、工信委、教育局、科技局、财政局、人社局、国土资源局、建规局、住管局、国税局、地税局等部门主要负责同志及各县区政府县区长为成员，统筹、协调解决引进过程中遇到的困难和问题。领导小组办公室设在市教育局，市教育局局长兼任办公室主任。各县区要成立相应领导机构，制定具体的实施细则。同时，对引进的民办学校要实现党组织和党的工作全覆盖，确保树立正确的办学方向。

（二）密切协作配合。建立由市教育局牵头，有关部门共同参与的协同推进机制。市教育局、财政局、发改委等部门负责安排部署、推进实施、经费统筹、监督管理等工作。市编办负责调整优化编制结构，保障高层次创新人才的基本编制。市人社局在高层次人才引进、机构设置、岗位结构比例、绩效工资等方面完善相关支持政策。市科技局在科研项目管理、科技成果转移转化、科技人才引进等方面予以支持。市工信委在产业对接、校企合作等方面做好服务。

（三）强化跟踪问效。各县区要大力创新工作机制，研究制定具体实施方案和配套措施，明确责任主体，加强组织领导和统筹协调，形成强大工作合力，切实加大优质教育资源引进力度。各县区于每年12月底前报送引进优质教育资源来汉兴办品牌教育工作落实情况。市政府将对工作成效突出的县区和部门给予表彰奖励，工作不力的予以通报批评。

（四）严格监督管理。各县区政府要认真履行属地监管和引进工作责任，积极做好引进优质教育资源的跟踪监管和绩效评价，支持引进学校完成校建和办学目标任务，绩效评价结果作为财政资金支持的重要参考依据。对办学效果不佳或难以实现预期目标的办学机构及时督促整改，整改后绩效仍然不明显的，将取消设立资格并责令退回有关资助。同时，加强对辖区内引进学校办学行为的监督，规范中小学校（幼儿园）在招生、编班、收费、执行课程方案、遵守作息时间等方面的办学行为。
