# 汉中市人民政府办公室关于印发县区人民政府和市级有关部门履行教育职责评价实施方案的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

《县区人民政府和市级有关部门履行教育职责评价实施方案》已经市政府同意，现印发给你们，请认真贯彻执行。

汉中市人民政府办公室

2018年5月31日

县区人民政府和市级有关部门履行教育职责评价实施方案

为贯彻落实党的十九大精神，推进全市各级人民政府履行教育职责，提高教育质量，促进教育公平，提升教育服务经济社会发展能力，根据省政府办公厅《关于印发对设区市级人民政府和省级有关部门履行教育职责评价实施方案的通知》（陕政办发〔2017〕112号）有关要求，结合我市实际，现制定本方案。

一、评价目的

督促各县区人民政府和市级有关部门落实教育优先发展战略，推动各级政府履行教育工作主体责任，改进管理方式，落实教育政策法规，促进教育公平，确保国家教育方针政策的贯彻执行。

二、评价对象

各县区人民政府和市级有关部门。

三、组织领导

评价实施工作在市政府统一领导下，由市政府教育督导室具体组织实施，每年组织1次。

四、评价内容

（一）履行领导教育工作职责。全面贯彻党的教育方针，加强和改善党对教育工作的领导，加强教育系统党的建设和领导班子建设，落实全面从严治党和党风廉政建设主体责任。坚持正确办学方向，落实立德树人根本任务，完善现代学校管理制度，校长依法治教，教师依法执教，维护正常教育教学秩序和师生合法权益。充分运用督导评价结果，建立奖惩激励机制。加强和改进学校思想政治工作，把握党对学校意识形态工作的领导权、主导权，维护教育系统安全稳定。

（二）履行管理教育工作职责。落实教育管办评分离，转变教育管理方式，完善教育工作决策、管理、监督机制。制订教育事业发展规划，修订实施各类教育标准，不断规范各级各类学校办学行为。建立党政领导和部门包抓学校的长效机制，为维护正常教育教学秩序和师生安全全面施策。调动社会各方面大力支持教育的积极性，均衡配置教育资源，积极改善贫困地区学校基本办学条件，进一步缩小城乡、区域、校际间差距，形成推动全市教育改革发展的强大合力。

（三）履行发展教育工作职责。把教育优先发展纳入经济社会发展总体规划，在领导分工、干部配置、财力投入、工作部署上体现优先发展。制定区域内教育改革发展和基本建设规划，稳步推进各类教育布局调整，组织实施教育发展建设项目。推动城乡义务教育一体化发展，高度重视农村义务教育，办好学前教育、特珠教育和网络教育，普及高中阶段教育，努力让每个孩子都能享有公平有质量的教育。完善职业教育和培训体系，深化产教融合、校企合作。以义务教育优质均衡发展、教育强县建设、现代职业教育体系构建、特殊教育提升、民办教育发展等为抓手，统筹推进各级各类教育发展。积极回应人民群众诉求，及时解决教育热点难点问题。

（四）履行保障教育工作职责。全面推进依法治教，落实国家法律、法规、规章，按照“党政同责、一岗双责、失职追责”的要求，切实推进教育系统稳定发展。加强经费管理，切实提高经费使用效益。发挥政府投入主导作用，落实中央和省、市关于教育经费投入的有关规定，切实做到财政资金优先保障教育投入。县区政府提高财政教育投入占公共财政投入比例。切实落实教育财政拨款的增长应当高于财政经常性收入的增长，并使按在校学生人数平均的教育费用逐步增长，保证教师工资和学生人均公用经费逐步增长的“三个增长”要求。足额征收教育费附加和地方教育附加，落实中省市各类教育项目配套资金。县级政府落实中央农村税费改革转移支付资金50%以上用于教育，落实从土地出让收益和彩票收益中分别按10%计提教育资金的规定。推进教育信息化建设，改善和提高教育教学信息化配备能力。健全学生资助制度，使绝大多数城乡新增劳动力接受高中阶段教育、更多接受高等教育。支持和规范社会力量兴办教育。注重加强教师队伍建设，提高教师能力素质，优化教师资源配置，完善教师管理制度，加强师德师风建设，培养高素质教师队伍，打造一支整体水平较高、充满活力的适应教育事业发展需要的师资队伍。

五、方法程序

评价实施工作采取对县区人民政府及市级相关部门年度评价与对县区党政领导履行教育工作职责督导考核相结合的方式进行。根据评价的主要内容，实行量化管理，建立评价指标体系，对各县区履行教育工作职责情况进行评价(评价指标体系和实施细则根据年度教育工作重点，由市政府教育督导室另行下发)。评价工作实行百分制，满分100分。对县区人民政府评价由两部分构成：一是对县区人民政府年度评价占50分，二是对县区党政领导干部履行教育工作职责督导考核占50分。市级部门评价由两部分构成：一是本部门自评占50分，二是省级督导评价结果占50分。

（一）对县区党政领导履行教育工作职责督导考核(上年度10月—12月)。根据《中共汉中市委组织部汉中市教育局汉中市人民政府教育督导室关于加强县区党政领导履行教育工作主体责任督导考核的意见》(汉教督导发〔2017〕3号)，按照3年一轮的考核要求，每年考核不少于30%的县区党政领导干部，根据考核指标予以赋分，最后得分占评价总分的50%。

(二)自查自评(每年3月15日前)。各县区人民政府和市级有关部门依据指标体系组织本级政府、本部门进行自查自评，并将自评报告报送市政府教育督导室。

(三)实地督查(每年4月—5月)。市政府教育督导室根据县区自评以及群众反映的问题，编制实地督查评价目录，组织市级相关部门，随机抽取督学和专家组成督导组，随机确定督导对象，督查全市30%的县区，并依据评价指标体系予以赋分。督查具体方式包括听取汇报、查阅文件、重点督查、个别访谈等，得分占评价总分值50%。

(四)发布报告。市政府教育督导室根据县区、部门自评和

实地督查结果，形成评价意见书，按程序审定并向社会发布。

(五)整改落实。有关县区、市级有关部门在接到督导意见书后，按照整改要求和建议，积极整改落实，并在3个月内向市政府教育督导室书面报告整改情况。市政府教育督导室视整改落实情况进行复查。

六、结果运用

评价结果将作为对县区人民政府、市级有关部门领导班子和领导干部考核、奖惩的重要依据，评价不合格的单位及个人，取消评优评先资格，并予以通报、约谈，有关负责人要向市委、市政府写出书面检查。对履行教育职责不到位、整改不力、出现重特大教育安全责任事故、有弄虚作假行为的，对有关责任人依法依规进行处理。各县区政府根据本方案制定具体实施办法，开展对县域内镇政府、办事处履行教育职责的评价工作。

附件：县区人民政府、市级有关部门履行教育工作职责

附件：

县区人民政府、市级有关部门履行教育工作职责

县区人民政府：领导、管理、推进、保障本行政区域内教育事业。

市委组织部：指导各级各类学校党建工作。

市委宣传部：指导全市教育系统党的宣传思想文化工作。

市编办:根据教育事业发展需要，建立和完善编制动态调整机制，促进教师资源合理配置。

市发展改革委：按照教育优先发展的要求，把教育发展和改革纳入国民经济和社会发展规划；指导和支持教育部门编制教育事业发展规划；做好教育改革发展项目的审批工作，落实项目及资金审核；监督教育收费。

市教育局：研究拟订全市教育改革方针、政策，起草有关地方性法规规章草案并监督实施，会同有关部门制订各级各类学校的办学标准，指导各级各类学校的教育教学改革；负责推进全市义务教育均衡发展和促进教育公平，负责义务教育的宏观指导与协调，指导普通高中教育、学前教育和特殊教育工作。制订基础教育教学基本要求和教学基本文件，全面实施素质教育；指导全市的教育督导工作，负责组织和指导法律、法规规定范围的各级各类教育工作的督导检查和评估验收工作，指导教育发展水平、质量的监测工作；制订中等职业教育教学指导文件和教学评估标准，负责中等职业教育教学改革、专业建议和质量评估；编制下达部门教育经费预算并监督执行，管理教育专项资金；统筹管理本部门教育经费；参与拟订筹措教育经费、教育拨款、教育基建投资、教育收费、学生资助的政策和管理办法；监督全市教育经费的筹措和使用情况；实施家庭经济困难学生的资助工作；指导全市各级各类学校的德育工作、体育卫生与艺术教育工作及国防教育工作；主管全市的教师工作，执行国家关于各级各类教师资格标准；贯彻国家语言文字工作的方针、政策、规划、规范和标准，指导推广普通话工作；负责全市民办教育的综合管理工作，规范民办教育办学秩序；指导全市基础教育系统党的建设、思想政治建设、宣传统战和安全稳定等工作。

市公安局：加强学校周边治安环境治理，对学校周边流动人口的管理和出租房、各种经营性场所的治安和消防管理，积极指导学校的安全保卫工作和平安校园、文明校园的创建，协助学校开展法治教育，建立健全预防青少年违法犯罪长效机制，切实维护青少年合法权益。

市司法局：开展法治宣传教育，全面提高青少年法律意识和维权能力，为青少年提供法律援助，共同做好失足未成年人的转变教育工作。

市财政局：足额拨付教育经费，加强对教育经费拨付、使用和管理的监督检查。

市人力资源和社会保障局：加强教职工工资、福利的宏观管理和审批，指导协调并会同教育行政部门做好教师专业技术职务资格评审认定工作，开辟人才引进绿色通道，强化劳动执法监察，负责技工类学校的监督管理工作。

市国土资源局：审批和优先保证教育事业发展建设用地，按照公益性事业用地的有关规定，优先安排并解决各级各类学校中小学校建设用地，协调查处违法侵占、破坏学校、幼儿园场地的行为。

市城乡建设规划局：指导各县区做好学校布局规划，将学校周边的治安、消防、交通等基础设施建设纳入城乡规划，保障新建、改建的城市、农村居住区按规划配套教育设施。协调各市区查处违法侵占、破坏学校、幼儿园场地的行为；按照国家规定，加强学校建设的工程质量监管。

市卫生和计划生育局：监督、指导学校的健康教育和卫生工作。做好传染病、学生常见病和其他疾病的预防和治疗；监督检查学校的饮用水、教学环境、生活设施和公共场所卫生。依法对学校突发公共卫生事件进行调查和处置。根据教育行政部门或学校申清，对学校校舍新建、改建、扩建项目选址、设计和竣工验收进行预防性卫生监督指导。

市审计局：依法对管理和使用教育经费的部门、学校和有关单位的预算执行、财务收支、建设项目情况进行审计监督；加强对重大教育项目经费进行专项审计调查，并依法处理教育经费管理使用中的违法违规行为。

市食品药品监管局：依法履行学校食堂及周边食品安全监管职责，加强对食品采购、贮存、加工、销售等重点环节的监督检查，指导学校定期组织食堂管理人员和从业人员进行食品安全基础知识、法律法规、职业道德教育培训。

市工商局：加强对校园周边经营户诚信买卖教育，严格查处违法经营。

市科协：指导学校和校外机构有计划地开展青少年科普教育活动；充分利用科技场馆为开展青少年科技活动提供便利。

市政府法制办：指导监督教育依法行政，对以市政府及市政府办公室制发的教育规范性文件进行合法性审核。
