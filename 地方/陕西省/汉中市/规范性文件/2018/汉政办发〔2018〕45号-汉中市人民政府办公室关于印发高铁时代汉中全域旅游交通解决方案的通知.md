# 汉中市人民政府办公室关于印发高铁时代汉中全域旅游交通解决方案的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

《高铁时代汉中全域旅游交通解决方案》已经市政府同意，现印发给你们，请认真组织实施。

汉中市人民政府办公室

2018年9月19日

高铁时代汉中全域旅游交通解决方案

随着西成高铁建成通车，汉中作为关天、成渝、江汉三大经济圈节点城市、“一带一路”和长江经济带重要源点城市的地位和作用更加突显。为强力推进全域旅游工程，加快打造区域综合交通枢纽，带动以旅游业为龙头的现代服务业大发展大繁荣，推动经济社会发展新旧动能有效转换，实现“三市”建设目标，制定本方案。

一、指导思想

以习近平新时代中国特色社会主义思想和党的十九大精神为指引，抢抓国家推进中西部交通基础设施和区域互联互通机遇，紧扣绿色循环、生态宜居发展定位，以建设区域综合交通枢纽为目标，实施“交通+旅游”战略，统筹公路、铁路、航空建设，完善路网结构，提升综合运输体系效能，优化旅游业态，整治交通秩序，打造安全便捷、运行高效、绿色智能的现代旅游交通体系，加快建设区域中心城市、文化旅游强市、陕西最美城市。

二、基本原则

（一）立足实际，适度超前。旅游交通体系是实现全域旅游的基础，更是国民经济与社会发展的基础性、先导性产业，必须以促进全市国民经济和社会发展、生产力合理布局为基本出发点和根本目的，结合全域旅游、脱贫攻坚、乡村振兴实际需要，进一步完善功能布局，强化薄弱环节，确保运输能力适度超前，更好发挥交通先行官作用。

（二）以人为本，满足需求。以游客为中心，把建设人民群众满意交通作为出发点和落脚点，突出交通运输行业的服务属性，着力提升交通运输服务水平，努力实现便捷高效。把提质增效升级作为旅游交通发展的衡量标准，切实处理好发展速度、质量、效益的关系。

（三）科学统筹，协同发展。以满足区域经济发展需要为导向，正确处理好各种运输方式自我系统完善和各种方式之间协调发展的关系，达到合理顺畅衔接。大力推进旅游交通发展，促进产业融合、产城融合，全面增强旅游发展新功能，使发展成果惠及各方。

（四）因地制宜，绿色发展。牢固树立绿水青山就是金山银山理念，坚持保护优先，合理有序开发，突出生产、生活、生态“三生”融合发展模式，实现经济效益、社会效益、生态效益相互促进、共同提升。旅游交通规划尽量考虑与主要景区、经济中心、乡县之间的连接和沟通，实现景区之间、景区与城镇的便捷连接。

三、主要目标

到2020年，形成辐射汉中全域高效便捷的外向型城市和综合交通枢纽，基本形成以区域干线、组团联系交通网络为骨架，以城市公共交通与慢行交通为主体，舒适、低碳、具有休闲宜居特色，与城市空间布局相适应，多层次一体化的城市交通系统。到2025年，基本建成安全、便捷、高效、绿色的现代化旅游交通体系，京昆、银昆、十天三大综合交通通道基本形成，汉中成为辐射周边、服务全国、联通“一带一路”的交通枢纽。

四、主要任务

着力打造以“3441”为重点的项目支撑体系，即完善3大综合交通通道（京昆、银昆、十天三大通道），加快推进4条铁路（汉巴渝快速铁路及北上通道、阳安二线、兰渝铁路武都至阳平关连接线、天水经汉中至安康十堰城际铁路）、4条公路环线（秦巴深山环、浅山丘陵环、平川沿江环、高速绕城环）、1个航空枢纽（城固柳林机场）建设。规划实施重点建设项目62个，总投资1592亿元。为推动经济转型升级、加快追赶超越、奋力建设“三市”提供坚实基础。

（一）完善路网结构，解决游客“快进”问题

1. 构建三大综合运输通道。全力推进以三高三铁为主骨架的京昆、银昆、十天三大通道建设。“京昆通道”：以西汉高速、国道108、兰渝铁路武都至阳平关连接线、西成客专构成的东北—西南向通道。“银昆通道”：以宝巴高速、国道244、汉巴渝快速铁路及北上通道构成的南—北向通道。“十天通道”：以十天高速、国道316、国道345、阳安铁路、阳安二线、天水经汉中至十堰城际铁路构成的西北—东南通道，将汉中建成连接关天、成渝、江汉三大经济区和长江经济带的区域综合交通枢纽。

2. 构建骨架铁路网。加快阳平关至安康铁路复线建设步伐；启动汉巴渝快速铁路及北上通道项目和兰渝铁路武都至阳平关连接线项目前期工作，力争尽早纳入国家“十三五”现代综合交通运输体系发展规划，并开工建设；加快火车站北站房建设步伐，适时推进天水经汉中至十堰城际铁路、秦巴生态旅游圈小火车和洋县经华阳至太白等景区观光小火车等项目建设，全力打造铁路枢纽城市。

3. 完善公路路网建设。完善提升公路“四环红太阳”网络布局，加快西乡至镇巴高速公路建设，开工建设西汉高速龙亭至西乡赵家山和宁强胡家坝至勉县茶店连接线工程、略阳至宁强高速公路等重大节点工程；加快推进G108城固县城过境、洋县县城过境、汉台至勉县一级公路和勉县至宁强二级路，完成G244汉台至南郑一级公路、G316西乡过境、G316城固至留坝改线工程、留坝柴关岭隧道及引线工程、G210镇巴过境、S320镇巴星子山隧道及引线工程等国省道路提升改造工程。加快“155”产业集群公路建设，推进京昆和十天高速公路东连接线、京昆高速改线（宁强铁锁关至陕川界）、略阳至宁强高速连接线等重大项目建设。改造提升农村公路，重点推进通村公路建设，完善公路微网基础。打通省道连接的“肠梗阻”，加快建设宁强巨亭至略阳高潭子、西乡子午至安康界、大河至镇巴界等省道断头公路。

4. 建设陕西副枢纽机场。以稳定现有航线、加密热门航线、开辟新航线为重点，构建空中大通道。尽快开通汉中-广州航线、汉中-沈阳或大连航线、汉中-天津或青岛航线，优化调整北京（南苑）-汉中-昆明航线，争取加密上海、深圳航线，适时开通旅游热点城市季节性包机航线。加快汉中城固机场二期扩建工程和宁强、镇巴通用机场建设步伐。适时开展南郑、勉县、洋县、西乡等通用机场建设，完成“1+N”的航空布局。积极开展航线+通勤飞行、航线+旅游模式，构建私人直升机、热气球、动力伞等多元化低空飞行旅游服务体系。积极开展旅游和商务包机业务，提高航班客座率和收益率。努力将汉中城固机场打造为秦巴地区区域中心机场、咸阳机场疏解机场、陕南地区通航和货运基地机场，成为陕西副枢纽机场。

（二）提升运输体系，解决游客“慢游”制约

1. 推进中心城区路网提档升级。优化城市内外交通，完善路网结构，提高路网密度，形成快速路、主次干路和支路相互配合的道路网络，打通微循环。推进城市慢行交通设施和公共停车场建设。加快机场快速干道、西汉高速东出入口改造提升、龙岗大道等中心城区十大道路工程建设，完成北一环等火车站周边道路改造提升和南郑西汉高速龙岗互通式立交建设，逐步打通望江路等城区断头路和城区跨铁路通道，提高道路通达性。加快建设以天汉大道、兴汉路为轴线的特色化慢行交通线，合理规划单车停放点，加快步道、自行车专用道建设，营造良好的慢行交通环境。实施主次干道交叉口渠化和背街小巷的优化改造，全面改善群众出行条件。严格落实停车配建标准，加快停车设施建设。坚持以公共停车场为主体、路外停车为辅助、路内停车为补充的模式，科学规划建设城区停车设施，加快建设南一环西段等城市停车场，合理施划免费停车泊位，引导主干道车辆向次干道停放，鼓励单位、个人停车位等资源错时共享使用，缓解中心城区停车压力。适时启动城市轨道交通网建设，逐步实现汉台、南郑、勉县和城固等平川县区交通一体化。

2. 加快景区道路连通工程。启动“114”旅游道路建设，按照打造“1条轴线（沿汉江两岸旅游轴线）、1条旅游特色公路（108国道）、4条局域旅游环线（秦岭东北环线、秦岭西北环线、巴山绿三角、巴山腹地环线）”的全域旅游公路体系总体布局，加快推进相关项目建设。加快南郑青树至黎坪公路、洋县至华阳、洋县谢村至褒城、留坝县留侯镇张良庙至营盘、勉县通往黎坪方向的勉钢路、青木川至陕川界等重点旅游道路和“一江两岸”旅游廊道建设，完善停车服务区等道路配套设施建设，统筹推进游客步道、骑行道、行车道为一体的综合旅游道路建设，满足游客出行需求。逐步推进景区、汉家乐、观光园等旅游公路及环线公路建设，不断提高景区及农村公路网的纵、横向连接，力争尽快建成闭合交通环线。到2020年，基本建成自驾游一览秦岭巴山自然风光的美丽风景线路。到2025年，建成旅游巴士环线、自驾游环线、自行车旅游环线构成的观光旅游综合交通环线。

（三）推进业态优化，提高游客“舒适”感

1. 完善服务设施。加快建设汉中高铁站综合客运枢纽站、机场综合客运枢纽站、勉县定军旅游客运站，不断完善道路客运与高铁、民航客运互联互通集疏网络。鼓励发展网络预约、定制服务，支持在高铁站、机场、旅游景区发展定制车、网约车和汽车租赁服务，为旅客提供多种客运服务方式。大力发展全域旅游客运和包车客运，鼓励支持传统道路班线客运剩余运力依法转为包车客运、定制客运、旅游客运，逐步建成安全可靠、经济高效、衔接顺畅、服务优质的道路客运服务体系。推进城市公交系统改造升级，规划建设公交首末站，推广新能源车辆使用，加快天汉大道、兴汉路、莲湖路等主要交通干道港湾式公交站等设施建设，合理设置公交线路、运力调配、站点建设，提升公交网络的机动性、便利性。

2. 提升服务能力。依托客运枢纽站，加快游客咨询服务中心建设，为游客提供信息咨询、交通引导、商品展示等一站式综合信息服务。加快城区和景区充电桩建设，在中心城区合理增设公共停车场（点），供市民免费停车。合理设置通往景区的标志标牌，规划建设景区自驾车营地、山地户外营地、徒步骑行服务站和生态停车场。加快实施“互联网+交通”战略，推进互联网与交通运输的深度融合，实现游客出行的便利化。大力建设“智慧交通云平台”、“互联网+便捷出行”等工程，实现手机APP、公众微信号、出行信息服务网等全覆盖，拓展“12328”交通热线服务功能，不断完善网络订票、电话订票、微信订票等服务方式，积极推进手机支付、电子客票应用，有效提升公众便捷出行体验和交通服务品质。

3. 推进景区提档升级。围绕旅游业供给侧结构性改革，深入实施全域旅游工程，加大创建国家全域旅游示范市。加快紫柏山、华阳、黎坪、青木川创5A级景区等提档升级工程，积极开发参与性、体验性、互动性强的项目，不断完善景区设施和服务水平。加快天坑保护开发和西汉三遗址等全市重点旅游项目建设。持续开展汉中全域旅游形象宣传和推介，全面扩大旅游影响力。打造全域旅游发展新格局，建成国内外知名旅游目的地。

（四）整治交通秩序，提升城市“品味”

1. 有效提升管理水平。加强中心城区人行道车辆停放管理。对机动车辆乱停乱放进行专项整治，合理规划布局停车场，清理功能转移的现有停车场对外开放，实现还路于民。启动城区过街天桥建设及十字路口改道整治工程，完善交通标识标线和安全设施，推进公交首末站和港湾式公交站点建设。合理设置旅游交通指示牌，方便游客出行。坚决打击机动车乱停乱放、乱占道、乱变道、乱鸣号、逆向行驶，公交车不停靠公交港湾，非机动车乱骑行，行人乱穿马路，电动车、三轮车、残疾人车从事非法客运等违法行为。开展市容环境综合整治工作，坚决打击沿街门店占道经营和人行道乱搭乱建、乱堆乱放等违章问题。加强建筑渣土运输管理，坚决禁止渣土车辆不按既定路线行驶、运输途中滴漏抛洒现象发生。开展出租汽车专项整治活动，加强出租汽车行业监管，及时纠正处理违规经营行为和违法营运行为，严肃处理群众反映强烈或造成恶劣影响的突出问题。

2. 推进多种交通方式融合发展。推进多式联运体系建设，加快高铁站、高客站、机场综合客运中心向旅游集散中心转变，完善与公交、出租车、汽车租赁、景区专线巴士等换乘方式的“无缝衔接”，解决不同类型游客需求。根据客流信息和售票情况，及时编制和上报增开动车车次计划，增加动车开行频次，解决游客乘车需求；优化高铁站服务质量，增加高铁站自助售票机数量，方便游客购票。加快在高铁站、机场等游客集中地设立专门的旅游直通车发车站点、售票窗口，以实现多站点售票发班，真正实现游客至景区的“零距离”换乘。节假日等客流高峰时段，开辟旅游直通车线路，加开旅游直通车，直通车享有优先通行、专用停车位等权利。鼓励汽车租赁行业发展，加强监督管理，促进行业有效发展。

3. 提升服务品质。完善高铁站、机场、汽车站等游客集散中心的旅游服务功能，及时为游客提供信息调度、咨询服务、产品营销、天气预报等服务。加快建设特色鲜明的“汉家乐”、“产权式”酒店、“酒店式”公寓和“民宿”旅游等设施，配套建设自驾车、房车营地、“登山营地”等生活服务功能区。提升各类宾馆、酒店设施水平和服务质量，满足游客多样化的需求。

（五）任务分工

市发改委：牵头负责阳安二线建设，推进机场扩建和轨道交通项目前期工作。

市旅发委：牵头负责健全全域旅游服务体系，指导旅游景区、旅游饭店、旅行社提升服务质量，指导旅游集散与咨询服务体系建设和旅游交通引导标识建设；积极推动构建类型多样、结构合理、具有地域特色的旅游要素体系，满足来汉游客多元化、多层次的消费需求。

市交通运输局：牵头负责推进国省干线公路改造，推进西镇高速公路建设，加快农村公路建设，构建旅游公路体系；负责城内公交站点科学设置，城区港湾式公交站点建设，推进电动汽车应用；培养壮大汽车租赁行业规模，提升服务品质。

五、保障措施

（一）解放思想。全市上下要以追赶超越为引领，统一思想，凝聚共识，以“激情、干净、超越”作风建设活动为契机，以旅客为中心，以推动高铁时代汉中旅游产业大发展、大繁荣为目标，努力完成各项工作任务。

（二）健全机制。成立汉中市全域旅游交通管理协调领导小组，由常务副市长任组长，市发改委、公安局、财政局、交通局、建规局、住管局、旅发委、工商局和各县区政府为成员单位，共同参与我市全域旅游交通秩序管理协调，定期召开领导小组会议解决相关问题。通过对道路交通中的人、车、路、环境等进行监督管理，改变我市道路交通面貌，取得最佳道路交通效能。

（三）密切协作。各主责部门要牵好头，各配合部门要尽好责，积极主动向中省有关部门汇报情况，做好跟踪衔接落实，最大限度争取对我市完善旅游交通的支持帮助和倾斜。

（四）真抓实干。各县区各部门要开拓创新，狠抓落实，踏实干事，久久为功，创造性的破解旅游交通“提档升级”问题，确保2025年取得阶段性成果、突破性进展。

（五）创新模式。按照政府引导、地方为主、市场运作、社会参与的多元化投入机制，在积极争取中省资金的同时，拓宽资金筹集渠道，吸引社会资本参与相关项目的投资、建设和运营管理。
