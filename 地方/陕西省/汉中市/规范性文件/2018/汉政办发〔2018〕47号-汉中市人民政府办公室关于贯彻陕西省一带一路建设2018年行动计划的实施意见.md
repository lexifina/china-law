# 汉中市人民政府办公室关于贯彻陕西省一带一路建设2018年行动计划的实施意见

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

加快丝路源点城市建设，大力发展枢纽经济、门户经济、流动经济，打造对外开放新高地，经市政府同意，现就我市贯彻《陕西省“一带一路”建设2018年行动计划》（陕政办发〔2018〕16号）提出以下实施意见。

一、着力构建交通商贸中心

（一）建设综合立体交通网络。以承接南北、沟通东西、辐射陕甘川、构筑关天、江汉、成渝三大经济圈交通枢纽中心为方向，以铁路、航空和客运枢纽建设为引领，推动我市枢纽型交通和综合性交通网络建设，吸引资金、人才、技术、信息等各类生产要素加速向汉中集聚。重点建设秦岭、巴山、陕甘川腹地环线。依托“三高三铁五国道”铁路、高速公路体系，形成东北—西南、西北—东南及南北走向通道，构建“米”字型综合运输通道主骨架。建设市域公路环线，推动汉中与周边地市公路（道路）的互联互通。将汉中城固机场建为秦巴地区区域中心机场，打造为陕南地区通航、货运基地机场和陕西副枢纽机场。加快汉江航运建设。建设汉中综合客运枢纽和汉中机场综合客运枢纽，强化航空、铁路、公路运输衔接。加快城际轻轨项目研究，提升城市交通品位。

（二）打造现代物流配送网络体系。加强与陕甘川省际边缘区交通、运输、物流等企业的业务对接合作，发挥物流龙头企业的行业带动作用，支持物流龙头企业通过股份合作、联合加盟等方式建设物流公共服务平台，支持组建以龙头企业为核心的物流战略联盟，充分发挥物流战略联盟对资源的集成效应和对关联产业的支撑作用，着力打造陕甘川毗邻区域物流枢纽城市、陕南现代物流示范城市。夯实“互联网+”高效物流发展的信息基础，将褒河物流园区建设成为物流行业的信息、商品集散和电子商务集成运营枢纽。加快建设区域大数据中心和云计算中心，完善物流基础设施，深化与京东集团战略合作，推进智慧物流体系建设，将汉中打造为“一带一路”重要的物流节点城市，关天、江汉、成渝三大经济区物流协作体系的中心集散地。

（三）提升贸易和投资发展水平。加快汉中海关和口岸建设。全面深化和积极推进通关一体化和检验检疫区域一体化，加快普汇中金世界港公用型保税仓建设，推进汉中电子口岸、国际贸易“单一窗口”建设和汉中口岸“三互”大通关建设，积极融入陕西自由贸易区建设，加快我市国际贸易便利化发展步伐。健全外经贸协同服务机制，加大对重点外贸企业的跟踪巡访服务力度。大力培育孵化外贸企业，不断壮大外贸经营主体。积极组织外贸企业参加中国加工贸易博览会和首届中国国际进口博览会，吸引境内外加工贸易企业落户汉中，引进汉中发展需要的先进设备、技术和生活消费品。加大产业招商引资力度，坚持引资、引智、引技有机结合，瞄准国际国内500强、创新行业100强等企业招大引强，推动技术含量高、产业联动效应大的项目落地。加快陕南绿色产业对外开放步伐，把承接国际制造业转移和促进我市产业结构升级相结合，鼓励国内外投资者参与陕南循环发展。

二、积极开展国际产能合作

（一）支持优势企业开拓海外市场。发挥装备制造、有色冶金、机械加工、生物科技等产业优势，以“一带一路”沿线国家为重点，加强产业对接与合作，延伸产业链，提升价值链。组织企业参加哈萨克斯坦—陕西商品展、迪拜果蔬展、德国汉诺威工业展、肯尼亚中国贸易周、香港国际食品展、中国—东盟博览会等“一带一路”经贸合作活动。鼓励企业在“一带一路”沿线国家开展品牌推广、品牌收购、商标注册、质量认证等，加快培育一批拥有自主知识产权的国际品牌。鼓励我市变压器、传感器、服装等加工制造企业在非洲、欧盟和“一带一路”沿线地区建设“海外仓”或投资设厂，通过收购、兼并境外企业等方式获得国外资源、技术和专利，形成产能合作示范效应。

（二）加强战略对接与产业衔接合作。通过共建产业合作园，建设一批专业示范基地和承接平台，推进我市与关天、江汉、成渝经济区的战略合作和与长三角、珠三角地区的联络协作。深化与丝路沿线国家和地区在装备制造、矿产开发、电商旅游、科技文化等方面交流合作，推动“汉品出境”。强化京陕、津陕、苏陕、川陕等省际区域合作，积极参与“21世纪海上丝绸之路”和“长江经济带”建设，全面构建区域开放新格局。

三、强化科技教育领域创新融合

（一）创新融合发展模式。积极推动市内高校、科研机构和企业与国外创新机构合作设立创新合作平台，开展跨国联合研发和技术转移，引导支持市内有实力有条件的科技型企业、支柱企业到国外自建、并购或合作建立研发中心或企业孵化器，开发具有自主知识产权的新技术和新产品。鼓励支持市内高校、科研机构和企业参与国际大科学计划和大科学工程，参与实施政府间科技合作项目和承担国家战略性国际科技创新合作重点项目。

（二）提升科技创新能力。以国家级创新型试点城市建设为契机，推动汉中高新区升格为国家级高新区，航空智慧新城建成航空高科技制造及军民融合的产业新城；推进陕南循环研究院、科技资源统筹中心建设，建立一批产业技术联盟；推进政产学研合作，建成一批工程研究中心，不断完善科技服务平台体系；打造创新创业交流平台，在区域产业发展价值链、产业链、供应链中实现优势突破。

四、搭建国际文化旅游交流平台

（一）扩大人文交流合作。借助丝博会、欧亚经济论坛、全球秦商大会、中国最美油菜花海汉中文化旅游节、张骞经贸使团等活动，依托境内外主流媒体，大力宣传“两汉三国·真美汉中”城市品牌，传递汉中声音，讲好汉中故事，展示汉中新形象。

（二）加快文化产业发展。继续实施重大文化项目带动战略，加快汉中兴汉新区汉文化示范区建设。以“汉水、汉人、汉文化”、“两汉三国、真美汉中”为主题，深入挖掘汉中丰富的历史文化资源，实施文化人才培养计划，加强文化创意产业发展，搭建文化产业招商引资平台，组织参加展览展示活动，推动我市“一带一路”文化贸易发展。继续开展“张骞故里文化经贸使团”活动，推动我市与哈萨克斯坦国际一体化基金会达成的合作协议尽快落地实施。加强与国家汉办联系，持续做好以“学汉语、游汉中、探汉源、知中国”为主题的国际学生感知汉文化基地项目实践活动，展示汉中文化魅力，扩大汉中文化国际影响力。

（三）打造特色旅游品牌。完善汉中全域旅游规划“一核、两路、六组”空间布局，深化旅游供给侧结构性改革，优化旅游产品结构，丰富旅游产品供给，提升公共服务水平，加快国家全域旅游示范市创建工作。创新举办中国最美油菜花海汉中旅游文化节、柑橘节、红叶节等品牌节会。继续做好在凤凰卫视等主流媒体和丝路沿线、高铁网络城市等目标城市旅游形象宣传，利用各类社交媒体平台宣传汉中，构建汉中旅游宣传推介网络。强化与携程、新浪等互联网企业的战略合作，持续深化与战略合作城市、苏陕对口帮扶城市、陕甘川宁毗邻地区旅游联盟城市的区域旅游协作，积极参加中省举办的会展促销活动，精心组织举办好港澳、南京、杭州、太原等旅游推介活动。

五、持续优化发展环境

（一）加强组织领导。为推动我市更好更快融入“一带一路”建设，市政府决定成立汉中市“一带一路”建设领导小组，市政府分管副市长任组长，市发改委、市财政局、市教育局、市商务局、市交通局、市文广新局、市旅发委、市科技局、市经合局为成员单位。领导小组办公室设在市商务局，负责日常工作。市政府设立市“一带一路”建设项目专项工作经费，以“一带一路”沿线国家为重点方向，支持企业抱团“走出去”开拓国际市场。

（二）完善改革措施。以破解汉中对外开放度不够等问题为突破口，以提升贸易投资便利化水平为目标，制定出台《汉中市提升企业跨境贸易和投资便利化行动方案》，完善对外贸易、外商投资便利化措施，帮助企业大幅降低跨境贸易和投资环节制度性交易成本。与秦商联合会境外会员单位和我市企业境外公司建立联系机制，联系新疆、广西口岸，争取设立“汉中商品展示中心”，为更快融入“一带一路”沿线市场提供渠道和信息支持。

（三）加强宣传引导。充分发挥文化、文物、旅游、经贸、外事等部门官方综合服务平台作用，利用陕西一带一路网服务功能，加大政策解读和成果宣传，加强信息沟通和文化交流。组织企业参加涉外商事法律与“一带一路”沿线国家市场风险防范、商事认证服务、外事等培训，提升我市参与“一带一路”建设的能力水平，为我市企业“走出去”开拓国际市场提供事前、事中、事后政策服务。

汉中市人民政府办公室

2018年9月26日
