# 汉中市人民政府关于印发汉中市2018年重点项目中期调整计划的通知

各县区人民政府，汉中经济开发区管委会，市政府各工作部门、直属机构：

按照《汉中市2018项目建设主题年活动实施方案》总体安排，为进一步提高2018年度重点项目计划质量，确保项目整体顺利推进，不断扩大有效投资规模。在对市级2018年重点项目1-8月实施情况进行逐一分析研判的基础上，以“年度投资总量不减、调整一个、补充一个”为原则，对四类52个项目年度投资计划进行了调整。调整后，整体项目年度投资计划略高于调整前。现将《汉中市2018年重点项目中期调整计划》印发你们，请按照有关要求抓好项目推进工作。
