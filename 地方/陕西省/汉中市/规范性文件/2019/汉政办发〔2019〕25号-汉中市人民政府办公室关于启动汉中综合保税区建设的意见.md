# 汉中市人民政府办公室关于启动汉中综合保税区建设的意见

各县区人民政府，汉中经济技术开发区管委会，市政府各工作部门，直属事业单位：

为抢抓国家级经济技术开发区设立综合保税区的政策机遇，打造我市对外开放新高地，培育外贸发展新引擎，提升外向型经济发展新水平，市政府决定启动汉中综合保税区建设。根据《国务院关于促进综合保税区高水平开放高质量发展的若干意见》（国发〔2019〕3号）和《国务院关于推进国家级经济技术开发区创新提升打造改革开放新高地的意见》（国发〔2019〕11号）精神，结合我市实际，现就启动汉中综合保税区建设提出以下意见：

一、总体要求

围绕建设陕甘川毗邻地区区域中心城市、区域对外开放中心的目标定位，加快复制推广中国（陕西）自贸区改革创新成果，打造服务对外贸易海关特殊监管区和国际经济合作平台，建设口岸作业、保税加工、仓储物流三大功能区，将汉中综合保税区建设成为外贸产业的聚集区、营商环境的示范区、对外开放的新高地。

二、发展目标

在符合国家土地利用总体规划和城市总体规划的前提下，在汉中经济技术开发区（褒河物流园区）内规划选址建设汉中综合保税区，暂定面积2.5至3平方公里。按照“两年打基础、四年见成效”的要求加快推进，如期建成。

两年打基础：2020至2021年，编制可行性研究报告、规划，制定出台实施方案，明确目标、运行模式和园区布局，列出项目清单，呈报建设综合保税区请示。

四年见成效：2022至2025年，完成园区标准化厂房、仓储物流基地、展示交易中心、海关监管区、综合服务区等建设，完成综合保税区验收，封关运营，形成布局合理、配套齐全、功能完善的综合保税区。

三、重点任务

（一）加大综合保税区申报工作力度。按照综合保税区设立条件要求，在做好项目引进、基础设施建设等工作的同时，加快申报、核查、验收等工作。综合保税区建设工作领导小组及各成员单位要积极主动向海关总署等中省有关部门沟通汇报，力争综合保税区尽早获批设立。

（二）加快基础配套设施建设。按照高标准、高起点规划建设的要求，分期、分片推进综合保税区规划区域基础设施和配套设施建设。完成区域内路网建设，加快围网外主要道路建设，同步推进市政设施和公共服务设施建设，加快标准厂房、物流仓储等生产配套设施和卡口、查验场、监控系统等海关监管设施建设。

（三）加快引进重大产业项目。紧扣汉中产业发展需求，引进一批大企业、大项目入驻综合保税区，形成“网内带动网外、网外促进网内”的产业互动发展格局。在保税区重点引进保税加工龙头企业项目，为成功申报打下坚实基础。重点引进突出信息技术、装备制造、现代材料、高品质食药、新兴产业、新能源等项目，配套引进保税仓储物流项目，形成产业聚集区。

（四）加快征地拆迁安置步伐。在相关规划的科学指导下，有序组织推进实施，加大土地储备力度，满足综合保税区开发建设用地需求。集中力量开展征地拆迁工作，三年内完成围网内、外征地拆迁安置工作。

（五）做好综保区相关规划设计工作。完成控制详细性规划编制工作，确定综合保税区土地使用性质和使用强度的控制指标、道路和工程管线控制性位置以及空间环境控制等规划要求。完成修建性详细规划编制工作，制定指导综合保税区范围内各项建筑和工程设施的设计和施工规定。完成海关特殊监管区域必备设施设计和综合保区实际运营需要必备设施的设计。

（六）加大资金筹措力度。按照综合保税区建设标准、项目内容要求，提前对所需资金进行测算，切实加大资金筹措力度，确保综合保税区建设资金得到有效保障。

（七）建立申报建设组织机制。市政府成立汉中综合保税区建设工作领导小组（详见附件），统筹负责综合保税区申报建设组织领导工作。汉中经济技术开发区管委会负责组建工作专班，抽调专人具体推进综合保税区建设。

四、任务分工

（一）汉中经济技术开发区管委会：负责编制可行性研究报告，制定总体规划、实施方案；负责立项、申报、建设、项目运行、项目管理、项目招商等工作。

（二）市商务局：协助汉中经济技术开发区管委会做好相关工作，牵头开展综合保税区指标评估体系量化考核和提升工作。

（三）市发改委：做好项目审批工作，将综合保税区建设项目纳入省、市重大项目建设规划，积极争取中省支持。

（四）市财政局：贯彻落实中、省促进综合保税区发展的财税政策，提供必要的资金保障。

（五）市自然资源局：做好综合保税区规划用地审查、报批工作，落实用地计划指标，办理规划条件审批。

（六）市住建局：指导汉中综合保税区市政基础设施建设，统筹协调做好保税区周边衔接区域市政基础设施建设，做好相关建设项目的审批工作。

（七）市经济合作局：负责综合保税区加工贸易产业转移项目的招引工作，协助做好汉中综合保税区招商工作。

（八）市市场监管局：协助争取中、省市场监管部门的政策支持，配合做好申报政策的分析与服务工作。

（九）人民银行汉中市中心支行（外汇局）：协助争取中、省外汇管理部门的政策支持，配合做好申报政策的分析与服务工作。

（十）市税务局：协助争取中、省税务管理部门的政策支持，配合做好申报政策的分析与服务工作。

（十一）市行政审批服务局：配合做好项目审批工作，对项目申报及规划建设实行联审联批，及时向各有关部门通报项目行政审批办理情况。

（十二）汉台区人民政府：负责项目建设前期的征地拆迁安置工作。

（十三）汉中海关：协助争取西安海关、海关总署对汉中设立综合保税区的支持，协助做好综合保税区申报工作的政策分析与服务，配合做好综合保税区规划、申报、建设、验收等工作。

汉台区政府、汉中经济技术开发区管委会、市级相关部门要按照《综合保税区审核设立指导意见》《综合保税区设立指标评估体系》等政策标准规定，完善相关工作，补齐短板不足，为综合保税区获批打好基础。

五、保障措施

（一）加强组织领导。市政府成立汉中综合保税区建设工作领导小组，统筹组织实施综合保税区申报建设工作，及时协调解决推进过程中遇到的重大难题；建立联席会议制度，由领导小组办公室提请领导小组定期召开联席会议，研究制定相关政策措施，协调解决具体问题，督促有关部门落实任务，通报工作推进情况。

（二）构建工作合力。汉台区政府、汉中经济技术开发区管委会、市级相关部门要认真履职、密切配合，积极争取海关总署等中省对口部门的支持，确保按照时间节点和标准要求完成相关任务。要加快研究制定相关配套政策，重点在规划、土地、资金、招商引资等方面加大支持力度，助力综保区加快建设。

（三）强化监督考核。汉台区政府、汉中经济技术开发区管委会、市级相关部门要充分认识获批综合保税区的重要性、必要性和紧迫性，迅速行动、统筹推进，尽快制定各自工作方案，定期向领导小组办公室报告阶段性工作进展情况，重大事项和紧急事项及时报告领导小组办公室。领导小组办公室要制定督查办法，加强对各成员单位的监督检查，对工作不力、懈怠拖延、推诿扯皮的单位和责任人严肃问责。
