# 汉中市人民政府办公室关于印发汉中市“四好农村路”示范镇创建实施方案的通知

各县区人民政府，汉中经济技术开发区管委会，市政府各工作部门、直属事业单位：

《汉中市“四好农村路”示范镇创建实施方案》已经市政府同意，现印发给你们，请认真贯彻执行。

汉中市人民政府办公室

2019年4月29日

汉中市“四好农村路”示范镇创建实施方案

为做好“四好农村路”示范镇创建工作，根据市政府《关于进一步加快推进“四好农村路”建设意见》（汉政发〔2018〕30号），制定本方案：

一、总体要求

坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实习近平总书记关于“四好农村路”建设重要指示批示精神，牢固树立“建养并重、路运并举”工作思路，按照“县区政府主导、交通运输部门指导、相关部门配合、镇办实施创建”的原则，统筹结合脱贫攻坚、“美丽乡村”建设、城镇化建设，协调推进旅游路、产业路、园区路建设，全面提升农村公路建设、养护、管理和运营水平，为打赢交通脱贫攻坚战、实施乡村振兴战略、助力汉中新时代追赶超越、高质量建设“三市” 提供坚实的交通运输保障。

从2019年起，各县区每年创建1至2个“四好农村路”示范镇，树立农村公路标杆。通过示范引领，全面推进我市农村公路建设工作持续健康发展。

二、创建标准

（一）建好农村公路，夯实创建基础

1. 全面实现行政村和30户以上集中居住区通沥青（水泥）路。区域内主干道外连内通，无断头路和明显瓶颈路段。通行政村道路路面宽度不低于4.5米（特殊困难路段路面宽度不低于3.5米），安防、排水、绿化、招呼站等附属设施齐全。

2. 完成乡镇辖区范围内所有县道、乡道和通客运班车村道公路安防工程建设。农村公路标志、标牌、警示设施和护栏等安全保障设施按规定设置，通客运班车的农村公路危桥全部改造完成。

3. 严格建立“六位一体”质量保障体系，落实农村公路建设“七公开”制度，加强施工管理，农村公路交竣工验收合格率达到100%，无质量安全责任事故发生。

（二）管好农村公路，保障安全畅通

1. 农村公路管养体制健全。全面落实政府主体责任，建立“镇政府主要领导负总责、分管领导具体负责、相关部门齐抓共管、沿线群众积极参与”的农村公路管养体制。镇办成立农村公路养护管理机构，明确分管领导、管理人员和管理经费。村委会建立农村公路养护管理议事机制。

2. 按照依法治路的要求，基本建立“县有路政员、镇有监管员、村有专管员”的路产路权保护队伍，采取有效措施努力防止、及时制止和举报违法超限运输及其他各类侵占、损坏农村公路的行为。

3. 结合美丽乡村建设，大力整治农村公路路域环境，打造畅安舒美通行环境。实现路侧绿化、街道亮化、庭院净化、路域美化，公路无违法占用或打场晒粮，路肩无杂草杂物或种菜搭棚，建筑控制区内无非法建筑或乱堆乱放。

4. 具备条件的乡村公路实现“路田分家、路宅分家”。制定关于“爱路护路、安全出行”的乡规民约、村规民约公示率和群众知晓率达到100%。

（三）护好农村公路，提升服务水平

1. 镇办配有农村公路专（兼）职管理人员，村委会聘有护路员队伍，沿线村民积极性得到发挥，农村公路列养率达到100%，实现有路必养。

2. 健全养护工作机制，明确镇、村两级农村公路养护职责，建立农村公路养护管理监督检查、考核评比机制，养护质量与养护经费挂钩，严格实行奖优罚劣，实现养必到位。

3. 落实村道养护责任，要充分调动沿线村民积极性，整合涉农资金，结合公益岗位，让沿线群众开展清扫保洁、杂草清理、边沟清淤、绿化管护等工作，确保日常养护取得实效。

4. 区域内所有县道、乡道和连接行政村的主要村道达到“畅、洁、绿、美、安”标准，即：路面整洁无阻碍、路肩结实无杂草、排水畅通无堵塞、边坡稳固无流失、安防齐备无损毁、绿化廊道无遗漏、路域优美无死角。

（四）运营好农村公路，服务城乡发展

1. 镇办、建制村通客车率达到100%、通班车率高于全省平均水平。建立客运发展机制，农村客运管理规范、运行稳定。对符合条件的农村班线完成公交化改造。

2. 镇办建有五级及以上客运站，并按照“多站合一、资源共享”模式，完成镇办综合客运服务站改造。农村客运站点管理规范，候车亭、线路牌等附属设施维护良好、正常使用。

3. 建立农村客运线路通行条件联合审核机制，加快淘汰老旧农村客运车辆，不断提升客车安全性和舒适性。落实行业监管责任和企业安全生产主体责任，强化司乘人员培训教育，有效提升农村客运安全管理水平。

4. 加快农村物流发展，配合相关部门推进农产品进城、工业品下乡“双向流通”配送网络建设，鼓励专业化物流企业向乡村延伸经营，基本建成覆盖县、镇、村三级的农村物流网络节点。

三、创建程序

“四好农村路”示范镇创建工作按照“镇办申报、县区自评、市级评审”的程序进行。

（一）镇办申报。各县区政府于每年3月底前向市交通运输局书面推荐本年度创建计划。

（二）县级自评。各县区政府应组织相关部门对照本方案的“创建标准”对推荐创建市级“四好农村路”示范镇的镇办，开展自评，所有申报条件均满足要求的，公示5个工作日无异议后，形成申报材料，于当年10月31日前报市交通运输局。申报材料主要包括县级补助政策、创建过程、经验做法、县级初审情况、整改措施和主要证明材料等。

（三）市级审核

1. 专家评审。市交通运输局收到申报材料后，组织相关单位，邀请相关专家，对照“四好农村路”示范镇强制性指标和一般性指标（详见附件1、2），对各县区上报的市级示范镇创建情况进行强制性指标评审、一般性指标打分，强制性指标全部达标，且一般性指标总评分达到90分及以上的，通过评审。

2. 实地审核。专家评审通过的镇办，由市交通运输局牵头组织相关单位进行实地审核，对不满足创建标准的、创建效果不明显的，坚决不予通过。

3. 命名确定。市级审核通过后，结果在市交通运输局网站公示5个工作日，无异议后，由市交通运输局报请市人民政府进行授牌命名。

四、保障措施

（一）加强组织领导。各县区政府要加强“四好农村路”示范镇创建工作的组织领导，成立政府领导牵头的组织机构，落实经费，整合资源，统筹推进本地区“四好农村路”示范镇创建工作。市交通运输局要成立协调机构和工作专班，负责组织指导和验收工作。

（二）夯实工作责任。各县区政府是创建工作的责任主体，各镇办是创建“四好农村路”示范镇的实施主体，要健全管养机制、完善工作台账，结合当地实际研究制定具体创建方案，细化目标任务，抓好组织落实。市级有关部门要结合自身职责，强化协调配合，推动“四好农村路”示范镇创建工作顺利开展。市交通运输局负责牵头抓总，指导公路、运管部门做好行业管理工作。市编办积极支持市、县、镇农村公路管理机构队伍建设，增强管理职能。发改部门和各县区政府统筹创建镇辖区内基础设施建设项目。公安部门依法监管好农村交通安全管理和公共交通维稳管控工作。财政部门按要求落实本级政府财政资金，拓展融资渠道，加强资金监管，确保资金使用合法合规。市人社局配合市交通运输局做好“四好农村路”示范镇评选工作。市农业农村局配合“四好农村路”示范镇创建，指导镇、村开展街道建设，同步改善农村人居环境，建成美丽乡村。市林业局要积极推广“交通部门修路、林业部门栽树”的做法，确保绿化、美化同步到位。

（三）落实扶持政策。各县区人民政府和市财政局要按照市政府《关于进一步加快推进“四好农村路”建设意见》（汉政发〔2018〕30号）要求，落实全市农村公路日常养护资金和安全生命防护工程配套资金。鼓励企业和个人捐款，以及利用道路冠名权、路边资源开发权、绿化权等多种方式依法筹集社会资金用于农村公路发展。同时，要切实加强对创建乡镇的资金投入，在政策、资金、项目等方面重点倾斜与支持；督促各创建镇办加大创建资金的筹集力度，对创建资金应明确列支、重点保障，并按时足额到位，保障创建工作顺利开展。

（四）加强监督考核。市级相关部门和各县区政府要将“四好农村路”示范镇创建，作为“四好农村路”示范县创建的重要内容纳入考核。市交通运输局要重点对责任落实、建设质量、工作进度、资金到位等情况进行检查指导，及时发现和解决存在问题。

（五）注重示范引领。各县区政府要及时总结经验，通过现场会议、经验交流、培训讲座等方式，推广示范镇创建经验，以点带面全面提升“四好农村路”发展水平。

（六）加大奖补力度。县区政府要按照要求对开展“四好农村路”创建活动的镇办落实100万元补助资金，主要用于农村公路建设、管理、养护和运营工作。“四好农村路”示范镇评选秉持公平、公开、公正的原则，对验收通过的示范乡镇由市政府颁发“四好农村路”示范镇奖牌，并给予一次性奖励50万元专项创建资金。
