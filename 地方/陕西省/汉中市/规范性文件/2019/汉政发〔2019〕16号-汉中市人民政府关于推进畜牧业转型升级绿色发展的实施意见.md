# 汉中市人民政府关于推进畜牧业转型升级绿色发展的实施意见

各县区人民政府，汉中经济技术开发区管委会，市政府各工作部门、直属事业单位：

畜牧业是我市农业农村经济的主导产业，在实施乡村振兴战略和推进现代农业建设中具有重要地位。为着力破解畜牧业生产效能不高、龙头带动能力不强、种养结合不紧密、养殖废弃物资源化利用水平低、产品竞争力弱等问题，加快推进畜牧业转型升级绿色发展，结合我市实际，现提出以下意见。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，积极践行新发展理念，紧紧围绕实施乡村振兴战略，按照“稳生产、优结构、提品质、促融合、增效益”的思路，以绿色发展为导向，以“稳定生猪、扩充家禽、牛羊增量、特色做优、品牌做强、产业做大”为主线，紧扣规模养殖绿色发展、粪污资源化利用、疫病防控能力提升、销售流通模式变革、畜产品公用品牌创建等环节，着力构建现代畜牧业“3+2”体系，即现代畜牧业产业体系、生产体系、经营体系与粪污资源化利用体系、动物疫情防控体系，加快推进畜牧业转型升级，促进汉中现代畜牧业绿色高质量发展。

二、基本原则

（一）坚持问题导向。围绕制约畜牧产业发展的突出问题，找准破解路径，精准发力，解决重大动物疫病传播风险大、中小规模养殖场生产经营不规范、粪污污染治理任务重、产品附加值不高等突出问题，促进畜产品提质增效。

（二）坚持绿色发展。突出绿色生态、品质优先导向，普及清洁养殖工艺，加大畜禽粪污资源化利用，推动粮经饲统筹、种养加一体、一二三产业融合发展，以地定养、以养促种、种养结合，建立与资源、生态条件相协调，适应市场需求的畜牧产业结构，促进生产、生态协调发展。

（三）坚持市场导向。充分发挥市场在资源配置中的决定性作用，以市场引领畜禽生产结构调整，以新的消费催生新的生产，用“大众化保供应，中高端提品质”的市场逻辑指导生产，坚守“生态、优质、安全、营养、健康”的本质特征，走“精细、特色、高效”的发展之路。

（四）坚持全产业链统筹。统筹畜禽“种、养、加、销”全产业链布局，加快构建首尾相连、上下相依、集约集聚的产业生态循环发展体系，全面提升畜牧业综合生产能力、市场竞争能力和可持续发展能力。

三、目标任务

到2023年，全市畜禽规模化养殖（含适度规模养殖）比重达到65%以上、标准化养殖比重达70%以上，畜禽粪污综合利用率保持到90%以上，规模养殖场粪污处理设施装备配套率达到100%；全市畜牧产业结构进一步优化，生产效率进一步提高，畜牧业区域布局与资源环境承载力相匹配、生产生活生态相协调的绿色生产方式基本确立，畜禽产能总体稳定，无区域性重大动物疫情和畜产品安全事件发生，畜牧业转型升级取得突破性进展。

四、工作重点

（一）优化调整区域布局，加快构建特色鲜明的产业体系。按照“种养结合、畜地平衡”的原则，统筹考虑环境承载能力、资源禀赋、市场需求和污染治理，合理规划畜禽养殖品种、规模和养殖总量，严格控制汉江流域畜禽养殖总量，推动畜牧生产向环境承载能力较大区域转移。发挥区域资源优势和畜禽主产区的产能优势，在城固、西乡、洋县、南郑、勉县等重点区域培育打造“300万头生态肉猪养殖基地”，在洋县、西乡、镇巴等县区建设“100万头优势肉牛（羊）养殖产业带”，在略阳、留坝、城固、宁强等县区打造建立“500万只乌鸡、100万只生态土鸡、100万只蛋鸭特色家禽养殖产业带”，以留坝、佛坪、镇巴等县区为主打造“20万群秦巴山区中蜂养殖产业带”，持续调优产业结构、调绿产业布局、调新产业比重，打造畜牧优势特色产业带。实施错位竞争，提高比较优势，培植特色产业，适度发展培优略阳乌鸡、镇巴腊肉、西乡牛肉干、留坝土蜂蜜等县域优势特色产业，满足市场对优质、特色畜产品多元化消费的需求，培育新的经济增长点。

（二）加大粪污综合治理，加快构建农牧循环的利用体系。以畜牧养殖大县为重点，组织实施好中央财政畜禽粪污资源化利用整县推进项目，推动全市建立养殖废弃物收集、转化、利用网络体系，提升畜牧业可持续发展能力。坚持源头减量、过程控制、末端利用的治理路径，鼓励大型规模养殖场建立有机肥加工厂或大型沼气工程，开展畜禽粪污资源化集中处理与利用；引导中小型规模养殖场流转土地或与周边规模种植户签订粪肥供应合同，实现粪肥就地就近消纳利用；在粮、果、菜、茶等集中生产区域，大力推广“生态养殖+沼气工程+绿色种植”等循环发展模式和技术，推行有机肥替代化肥行动，配套建设粪肥田间贮存池、沼液输送管网、沼液施用设施等，打通粪肥还田通道，促进种养结合、农牧循环。严格依法依规科学划定畜禽禁养区，除法律法规规定的禁止养殖区域外，不得超范围划定禁养区，不得以改善生态环境为由限制畜牧业发展。对禁养区内确需关停搬迁的养殖场户，当地政府应在非禁养区安排用地予以搬迁重建，做到“拆一补一”；对不符合环保要求的养殖场户，要予以清理。

（三）发展生态健康养殖，加快构建标准规范的生产体系。按照“良法良种配套、设施工艺结合、增产增效并重、生产生态协调”的思路，持续推进“育、繁、推”一体化工程，以产地、原料、过程、标准安全保证产品安全，赢得市场。加强略阳乌鸡、汉中黑猪、汉中白猪等遗传资源的保护和开发利用，推进现代标准化畜禽育种场和扩繁场建设，加快畜禽优质品种更新换代步伐。持续开展畜禽标准化示范创建活动，推广节水、节料、节能养殖工艺和干清粪、微生物发酵等实用技术，推广应用机械化、自动化、智能化设施设备，提高畜禽养殖标准化、规模化、产业化发展水平。大力推进绿色生态养殖、健康养殖、清洁养殖，发挥龙头企业和专业合作社经济组织带动作用，通过统一生产、统一营销、技术共享、品牌共创等方式，带动和鼓励有意愿的小农户稳步扩大规模，发展适度规模养殖，逐步构建以规模养殖场为引领、以适度规模养殖场为主体、以家庭农场和散养户为补充的畜禽标准化生产体系，促进养殖户增收和产业转型协同发展。

（四）壮大新型经营主体，加快构建三产融合的经营体系。大力培育新型经营主体，实施小农户提升工程和家庭农场培育计划，积极发展专业化和农牧结合型家庭农场，鼓励规模养殖场、家庭农场之间加强横向联合，建立协会或合作社，培育新型职业农民，带动中小养殖农户融入现代畜牧业生产体系，打牢产业化经营组织基础。延伸产业链条，鼓励和支持畜禽养殖、屠宰加工等企业按照“强链、延链、补链”的原则，采取合作抱团发展模式，积极培育“互联网+现代畜牧业”，并逐步向产业链上下游延伸，促进畜禽产品就地深度加工，多次增值，拓宽发展空间。鼓励中小养殖场户主动嫁接大型养殖企业，通过“托管或代养”，打造社会化服务新载体，构建新型技术服务模式。统筹政府、企业、行业协会多方力量，实施品牌兴牧提升行动，引导生产更多绿色、有机、安全畜产品，着力培育一批标准高、规模大、产品新、外向型的龙头加工企业。在完善利用好“略阳乌鸡”“留坝土蜂蜜”等现有地理标志认证产品的基础上，着力培育全市特色鲜明、质量稳定、信誉良好、市场占有率高、影响力大的畜产品区域公共品牌。加强推介宣传和营销平台建设，开展“互联网＋畜产品”营销，大力发展畜产品电子商务，推进农超、农社等产销对接和线上线下融合发展，大力提升汉中畜产品区域公共品牌的知名度、美誉度和竞争力。积极推动畜禽养殖企业与农户（贫困户）通过签订代养协议、入场务工、入股分红等形式，建立长效稳定的利益联结机制。引导种畜禽场、规模养殖场、家庭农场、屠宰企业和农户（贫困户）加强分工协作，共同参与市场竞争，形成“利益共享、风险共担”的利益共同体。

（五）强化动物疫病防控，加快构建运转高效的防控体系。加大重大动物疫病防控和疫情预警监测责任体系建设，落实属地管理责任和生产经营者主体责任，推进重点动物疫病由“有效控制”逐步向“净化消灭”转变。鼓励畜牧养殖大县和规模养殖场建设运输车辆洗消中心，全面落实运输车辆登记备案和监管。引导规模养殖场与周边散养户构建防控共同体，加强生物安全设施建设，保障养殖安全。严格畜产品安全监管，加快病死动物无害化处理场所、动物检疫申报点、公路动物卫生监督检査站、活畜禽运输指定通道等基础设施建设，加快构建从养殖到屠宰全链条兽医卫生风险管理体系。严格落实《畜牧法》《动物防疫法》等法律法规，依法查处畜禽养殖、运输、屠宰、销售等环节中的违法违规行为。积极开展兽用抗菌药使用减量化专项行动，严格兽药、饲料、饲料添加剂等投入品使用，确保畜禽产品兽药残留监测合格率保持在99%以上。推动畜禽屠宰企业改造升级，根据全市畜牧业生产布局，合理设置生猪、牛羊、家禽定点屠宰企业，扶持培育一批科技含量高、带动能力强、产业链条长、加工程度深、市场竞争力强的屠宰加工企业，着力开发中高端系列化精深加工畜产品，实现畜牧业产加销一体化发展。深入开展生猪屠宰标准化建设，力争60%以上的生猪屠宰企业达到标准化生产水平。引导鼓励畜禽养殖、屠宰加工企业加强产销衔接，实行县域“定点屠宰场集中屠宰、乡镇分销配送”模式，加快推进建立与本地区生产销售规模相适应、上下游衔接的肉品冷链流通和配送体系，变革传统畜禽调运方式，推动肉品供应由“调猪”向“调肉”转变、由热鲜肉向冷鲜肉转变、由初加工向精深加工转变。

五、保障措施

（一）强化组织领导。强化政府在畜牧产业发展中的统筹谋划、政策引导、投入支持、执法监管等方面的作用。建立市促进畜牧产业转型升级绿色发展联席会议制度，负责研究制定相关政策措施、协调解决重大问题。市委编办、市发展改革委、财政局、自然资源局、生态环境局、农业农村局、林业局、商务局、供销社、市场监管局、人民银行汉中中心支行等有关部门要各司其职，形成服务畜牧业发展的工作合力。各县区政府要参照建立相应协调机制，贯彻落实支持畜牧业发展的政策措施，立足区域资源优势，制定主导产业清晰、目标任务明确、生产布局合理、配套设施良好、运行机制高效的畜牧业发展规划。加大政策引导，落实畜禽养殖全产业链各类企业的主体责任，调动其推进产业转型升级的积极性和主动性。

（二）加大财政金融等政策支持。围绕畜牧业转型升级绿色发展关键的薄弱环节，强化资金扶持，统筹整合中省财政专项资金，加大对畜禽良种繁育体系、畜产品安全监管体系建设以及动物疫病净化、畜产品公用品牌建设、畜禽粪污资源化利用、屠宰加工企业标准创建、畜牧技术创新等方面的支持。市上每年安排1000万元专项资金用于促进畜牧业转型升级、绿色发展。各县区也要结合畜牧业发展现状，每年安排一定的专项资金用于畜牧业发展。进一步完善动物疫病紧急处置补助救助机制，落实经费保障，对在疫病预防、控制、扑灭过程中强制扑杀和无害化处理的畜禽，给予相应生产救助补贴。创新金融服务方式，加大畜牧生产基金、信贷支持力度，在信贷资金投向、投量、期限、利率等方面予以倾斜，不断丰富增信手段，拓展信贷抵质押物范围。稳定预期、稳定信贷、稳定支持，对符合授信条件但遇到暂时经营困难的畜禽养殖场、屠宰加工企业不得盲目抽贷、断贷。积极探索推行生猪目标价格保险，拓展开发政策性畜禽生产保险险种，扩大种公猪、能繁母猪、育肥猪和仔猪政策性保险覆盖面，切实降低生猪养殖风险。加大对畜牧产业的投入，逐步建立完善政府扶持为导向、主体投入为主体、社会资本为补充、金融服务及时跟进的投入机制。对畜禽养殖用电执行农业生产用电价格。

（三）保障畜禽养殖用地。根据“种养结合、畜地平衡、产加配套”原则，将畜禽养殖用地纳入国土空间总体规划，有效保障新建、扩建畜禽规模养殖场设施用地。完善设施农用地政策，合理增加附属设施用地规模，取消15亩上限规定，保障畜禽废弃物处理等设施用地需要。在不占用永久基本农田的前提下，允许生猪养殖用地使用一般耕地。对需要升级改造的畜禽养殖场，允许在原场地范围内进行重建或改建。对大型畜禽屠宰企业、病死动物专业集中无害化处理中心、畜禽车辆洗消中心等建设用地，应在年度用地计划中给予优先安排。鼓励利用农村集体建设用地和“四荒地”（荒山、荒沟、荒丘、荒滩）发展生猪生产，鼓励发展林下规模养殖。

（四）稳定基层防控队伍。市、县（区）各级政府、相关部门要高度重视基层动物防疫队伍建设，配齐与养殖规模和工作任务相适应的防疫、检疫等专业技术人员，加强镇办技术力量，尽快建立起“党政重视、部门支持、运转高效、保障有力”的动物疫病防控体系。地方财政要保障工作经费和业务经费，改善设施装备条件，确保重大动物疫病防控、动物卫生监督、畜牧技术推广等工作能正常开展，切实解决基层一些地方工作缺位的问题。

（五）强化科技支撑。加大对地方畜禽遗传资源品种保护及产业化开发力度，支持创新型企业开展地方良种选育推广工作，培育优质、高产、市场竞争力强的新品种。建立健全畜牧业科技示范推广体系，强化科技推广机制创新，加强畜牧先进实用技术集成和推广，逐步提升农业科技进步贡献率。围绕制约畜牧业绿色发展的重大科技瓶颈，积极与畜牧兽医机构或高校合作开展科技攻关，争取在标准化养殖、动物疫病净化、畜牧公用品牌建设、废弃物综合利用等关键环节取得突破，为畜牧产业转型升级提供科技支撑。
