# 汉中市人民政府关于切实加强农村饮水安全工程运行管护的意见

各县区人民政府，汉中经济技术开发区管委会，市政府各工作部门、直属事业单位：

为切实加强农村饮水安全工程运行管护，建立健全长效管理机制，确保工程管得好、用得起、长受益。根据《中华人民共和国水法》《陕西省城乡供水用水条例》《陕西省小型水利工程运行管理办法》等相关规定，结合我市实际，提出如下意见。

一、总体要求

（一）指导思想。深入贯彻落实习近平新时代中国特色社会主义思想，按照“节水优先、空间均衡、系统治理、两手发力”的新时期治水方针，围绕高质量打赢脱贫攻坚战，以稳定实现农村贫困人口“两不愁三保障”为目标，统筹考虑农村人居环境整治、节水型社会建设，建立健全工程产权明晰、管护主体落实、监管责任到位、维护体系完善的农村饮水安全工程管护长效机制，实现规范化管理、专业化运营、长效化受益，为脱贫攻坚、乡村振兴和追赶超越建设“三市”提供坚实饮水安全保障。

（二）基本原则

——坚持政府主导，群众参与。各级人民政府对农村饮水安全保障工作负总责，在政策和资金上给予扶持，建立用水户全过程参与工作机制，推动农村群众安全饮水、清洁饮水、节约用水、有偿用水。

——坚持因地制宜，分类施策。根据自然条件、工程规模、用水人口分布等，因地制宜合理选择确定适合当地实际情况的运行管护方式，切实破解运行管护难题。

——坚持以水养水，长效受益。完善农村水价水费计收机制，树立农村群众水商品意识，推进供水价格市场化、供水服务社会化、城乡供水一体化，实现以水养水，安全长效运行。

——坚持节水优先，保护环境。统筹考虑节约用水、水环境保护工作需要，健全完善农村供水、用水、排水、污水处理体系，保障饮水安全、维护水环境健康。

二、健全管护方式

加快推进农村饮水安全工程量化赋权改革，按照“谁投资、谁所有、谁受益、谁负担”的原则，结合基层水利服务体系建设、水权水价综合改革要求，根据工程规模和建设投资构成，厘清国家、集体、社会法人及个人投资比例，明确农村饮水安全工程产权归属，通过改革发证确权，明晰所有权、界定管理权、明确使用权。2020年底前所有供水工程实现量化赋权。在此基础上，结合各县区实际和工程特性，合理选择、健全完善工程运行管护方式，确保长期发挥效益。

（一）联村式管理。覆盖集镇或两个以上行政村的供水工程，镇（办）是管护主体，牵头成立专管机构或抽调水利专业人员组建镇级供水管理站负责管护，供水管理站挂靠镇政府（街道办）或县区水利局，实行独立经营、自负盈亏。

（二）单村式管理。村委会是单村供水工程的管护主体，牵头组建管理机构负责管护，鼓励通过“村委会+合作社+服务队+贫困户”的管护方式，成立自来水管护服务队，引导带动贫困户和受益群众共同做好饮水安全工程建后管护。

（三）自主式管理。以户为单位建设的分散式供水工程，用水户是管护主体，供水设施由用水户采取轮流管护或指定有公益心、责任心强的农户负责管护。

（四）物业式管理。用水户居住相对集中，适合集约化管理服务的供水工程。如：移民搬迁安置点供水，由工程受益户组建用水协会，委托物业公司作为管护主体，实行物业化管护。

（五）民企式管理。在确保工程产权、公益属性不变和安全的前提下，因地制宜推行村镇集中供水工程特许经营、承包、租赁、股份合作等管理形式，吸引民间资本参与供水服务，由民营企业作为管护主体负责工程运营管护。

（六）托管式管理。将县城周边居住相对集中的农户纳入县城供水管理区域，由村委会统一与自来水公司签订供水协议，集中装表、代收水费；供水主管道、入户管道（设施）分别由自来水公司、用水户负责维修管护；具备托管条件的集镇供水工程，建成后交由县级自来水公司统一进行公司化管理。

三、推动以水养水

（一）实施有偿供水。农村饮水安全工程实行有偿供水、计量收费。所有集中式供水工程都应收取水费。各县区根据农村供用水实际情况，按照“合理负担、良性运行”的原则，2019年底前，以县为单元制定出台农村供水工程水价相关政策制度，千人以上供水工程全面定价；2020年底前，千人以下集中供水工程全面定价，收费工程处数占总数的95%以上，水费收缴率达90%以上。制定水价时充分考虑用水户承受能力，合理补偿供水成本。水费收入主要用于电费、运行费、管护人员工资等，同时计提维修基金用于工程日常维护，任何单位和个人不得截留挪用，通过收取水费，实现“以水养水、良性循环”。

（二）保障安全供水。在保障供水满足饮水安全评价四项指标的基础上，因地制宜实施管网延伸、互连互通改造，扩大工程供水规模和覆盖率，加强农村饮水水源地保护，合理选择净水消毒工艺，加强水质检测监测，建立完善供水应急反应机制，提高群众用水满意率，保障供水安全。

（三）鼓励清洁用水。结合美丽乡村建设、农村人居环境整治，积极引导镇村建立完善生活污水排放处理设施，减少面源污染，逐步消除生活污水随意排放现象；建立激励机制，发挥水价杠杆调节作用，镇村排水和污水处理设施体系完善的，适当调低水价。

（四）推动节约用水。大力推广一户一表、智能水表、预付费用水、基本水价与计量水价相结合的两部制水价，加大农村供水舆论宣传，引导群众树立“爱水、惜水、节水、保护水”的意识，养成节约用水习惯。

四、落实管护资金

（一）设立维修养护资金池。市县财政部门按比例共同出资建立农村饮水工程维修养护资金池，实行专户管理、专账核算，专项用于农村饮水安全工程因自然灾害造成损毁的修复，对确实无力实现自我良性循环的工程进行补贴。

（二）拓宽管护资金渠道。各县区政府拓宽建设管护和融资筹资渠道，加大对中省农村饮水安全巩固提升、维修养护补助资金和农村基础设施养护基金等的争取力度，扩大管护资金来源。

五、夯实管护责任

（一）落实政府主体责任

各县区人民政府是农村饮水安全管理的责任主体，统筹负责辖区内农村饮水安全工程运行管护的组织领导、制度保障、体系建设、经费落实和工作考核。

1. 推动农村饮水专管机构、管理办法和维修养护经费“三项制度”落实到位；推动县区人民政府主体责任、水利行业监管责任、供水单位运行管理责任“三个责任”落实到位；推动饮水安全工程统一规划设计、统一技术指导、统一工程标识、统一管理办法、统一专人负责“五个统一”落实到位。

2. 统筹做好农村饮水安全工程管护、污水处理、人居环境整治、节水型社会创建等工作，建设生态宜居美丽乡村。

3. 建立县级农村饮水安全工程应急物资库，储备饮水安全工程常用抢修物资，由县区水利部门统一管理，确保在应急突发情况下，及时调配抢修物资，快速恢复正常供水。

4. 依法划定农村集中式饮用水水源保护区或保护范围，建设保护设施；整治影响水源水质的生活污染源、工业污染源和农业面源污染。

5. 统筹考虑农村公共设施管护、生态环境保护，落实农村饮水工程管护公益性岗位；定期开展农村饮水安全工程管护人员技术培训，提高管护人员专业技能；开展多层次、多渠道的农村饮水安全工程宣传，引导群众重视饮水安全、爱护供水设施、增强用水缴费和节约用水意识，为健全长效管护机制创造良好环境。

6. 建立健全农村饮水安全工程运行管护督查考核机制，将农村饮水运行管护工作列入镇村年度目标责任考核；加大对镇村农村供水工程运行管护、水质保障工作的监督检查，对工作不力导致群众饮水出现重大问题的，依法依规严肃问责。

（二）落实部门监管责任

教育部门负责加强在校学生宣传教育，引导学生爱护供水设施、节约保护水资源；

财政部门负责落实保障农村饮水安全工程维修养护、水质监测等经费，并加强资金监管；

自然资源部门负责落实农村饮水安全工程新增建设用地计划指标和土地征（占）用工作；

农业农村部门负责农村人居环境整治，改善群众饮水环境；

扶贫部门负责脱贫攻坚饮水安全有关工作的监督指导；

水利部门负责农村饮水安全工程运行管护监管和技术指导；

生态环境部门负责农村饮水饮用水源地环境保护，加快农村生活污水处理设施建设，建立完善污水治理体系；

卫健部门负责水质监测监督协管工作，配合水利部门做好农村饮水安全工程水质监测；

电力部门负责落实农村饮水安全用电优惠政策，配合做好农村饮水安全工程运行管护。

（三）落实工程管护责任

1. 用水户是供水工程直接受益者，应服从供水管理单位的管理，按时缴纳水费，积极投工投劳参与供水工程运行管护，爱护供水设施、节约用水。

2. 供水工程管护主体负责建立健全管护制度，落实管护人员，做好水源巡查保护、供水设施管护维修，水费收缴、定期公开等工作，保障正常供水和水质安全。

3. 村委会负责协助供水工程管护主体做好村内水源和供水设施保护、监督辖区内村级供水工程运行管理，利用农村公益性岗位有关政策配齐管护人员，落实节水措施。

4. 镇（办）负责辖区内农村饮水安全工程运行管护、定期检查、成立专管机构，组织制定农村供水应急预案，开展农村饮水安全工程技术服务、业务培训，对农村供水工程运行和国有资产进行监管，协助做好供水设施维护、处理群众投诉等工作。
