# 西安市石榴园区强降雨后管理技术指导意见

当前我市石榴正处于果实膨大关键时期，近期强降水天气易导致石榴园积水造成涝害胁迫，极易诱发根腐病、果腐病及干腐病等多种病害。为最大限度降低损失，尽快恢复树势，保障产量和果实品质，特提出以下灾后管理技术指导意见。

一、排水清淤，松土散墒

（一）迅速排除积水。对积水地块，要第一时间组织人力和机械疏通排水沟渠，排除园内积水。对地势低洼、排水不畅的园区，可增设临时水泵抽排，加快排水进度。

（二）松土散墒。土壤稍干后（以脚踩不粘鞋为宜），及时对树盘进行5-10厘米浅耕松土，增强土壤透气性，促进根系有氧呼吸。避免深翻伤根。

（三）清理淤泥。清除树干基部堆积的淤泥，露出根颈部位，防止病菌从根颈侵染。

二、分类施策，养根护根

涝害后灌根应精准区分：一是轻度受害（叶片正常或轻微黄化）：只需松土透气，结合浇水冲施矿源黄腐酸钾或海藻酸类生根剂，促进新根萌发，无需灌药；二是中度受害（叶片黄化、萎蔫）：排水后2-3天土壤稍干时，在树冠滴水线附近开沟灌根，选用精甲霜·咯菌腈或甲霜·噁霉灵等低毒登记药剂，每株灌药液15-20公斤；三是重度受害（落叶严重、根皮变黑腐烂）：先扒开根际土壤晾根，刮除腐烂部分，再用上述药剂高浓度灌根急救；四是快速恢复土壤微生态，化学灌根后5-7天，可冲施枯草芽孢杆菌等生物菌剂，重建根部有益菌群，巩固防效。

三、叶面补肥，快速恢复

涝害后根系吸收功能受损，切忌立即土壤追肥，以免肥害伤根。应优先采用叶面喷施方式补充营养：

（一）推荐配方（每15升水）：

• 磷酸二氢钾 20-25克

• 氨基酸螯合糖醇钙 20-25毫升

• 海藻酸水溶肥 15-20毫升

• 28-芸苔素内酯 5毫升

（二）使用方法：间隔7天喷施一次，连喷2-3次，重点喷施叶片正反面，直至叶片转绿、树势恢复。叶面肥可与杀菌剂混用，需采用二次稀释法现混现用。

（三）根系养护：排水后3-5天，结合浇水冲施腐殖酸类或海藻酸类生根剂。待新根长出后（约10-15天），再少量追施平衡型水溶肥，切忌过量。

四、综合防控，严防病虫害

涝害后树体衰弱、伤口多，高温高湿极易暴发根腐病、炭疽病、褐斑病、干腐病等多种病害，须主动预防、综合管控。

（一）根部病害。主要按上述灌根方案分类处理，重点盯住低洼易涝区、衰弱树。

（二）叶部及果实病害。雨停后立即喷施内吸性杀菌剂（如唑醚·氟酰胺、苯甲·吡唑酯），搭配保护性杀菌剂（如代森锰锌），形成“治疗+保护”双重功效。

（三）虫害预防。涝害后树势弱，蚧壳虫、蚜虫等易趁机暴发，应加强监测，发现后及时选用螺虫乙酯、双丙环虫酯等药剂防控。

五、树体管理，减轻负载

（一）适度修剪。及时疏除枯枝、断枝、病虫枝，对黄化严重叶片可适当摘除，减少消耗、减轻根系负担。

（二）合理疏果。树体营养亏缺时，适当疏除部分弱果、小果、病虫果，集中营养保障优质果发育。树势较弱树应优先保留头茬果和优质二茬果，坚决疏除其他二茬果。

（三）检查果袋。检查已套袋果实，果袋破损及时更换，袋内积水需倒出晾干，防止果实腐烂。

6、 科学应对，确保实效

1. 切忌排水后立即土壤追肥，以免加重根系损伤。

2. 精准灌根，不搞一刀切，健康树只需松土生根，受害树才精准灌药。

3. 排水后一周是恢复关键期，叶面追肥和病害防控须在此窗口期内落实到位。

4. 持续关注天气预报，提前清理排水沟渠，防范再次降水造成二次灾害。
