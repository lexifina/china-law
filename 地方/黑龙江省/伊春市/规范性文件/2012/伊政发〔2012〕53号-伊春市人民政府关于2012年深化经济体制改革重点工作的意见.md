# 伊春市人民政府关于2012年深化经济体制改革重点工作的意见

伊政发〔2012〕53号

各县（市）、区人民政府（林业局），省属、中属在伊行政机构，各企事业单位，市政府各委、办、局：

根据《黑龙江省人民政府关于2012年深化经济体制改革重点工作的意见》精神，结合全市经济体制改革工作实际，现就2012年深化经济体制改革重点工作提出如下意见： "EN-US">

一、指导思想和总体要求

（一）指导思想。以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，高举第三次创业旗帜，紧紧抓住国家实施《大小兴安岭林区生态保护与经济转型规划》和“天保工程”二期的两大机遇，以加快发展为主题，以转变经济发展方式为主线，加快改革开放步伐，破除体制机制障碍，加速推进深度市场化，不断引入创新动力，推动全市经济转型升级。

（二）总体要求。坚持正确处理改革、发展、稳定的关系，通过改革，解决制约发展的体制性和机制问题，把握好改革任务的轻重缓急和社会承受程度，统筹兼顾，积极稳妥地推进重点领域和关键环节改革。

二、不断深化森工管理体制和国有企业改革

（三）争取将伊春纳入林区经济体制改革

1、积极推进伊春林业综合改革试验区建设。依据《大小兴安岭林区生态保护与经济转型规划》要求，积极争取国家以国有林区管理体制改革为核心，带动国有林区行政管理、森林资源管理、国有资产管理等方面的改革，在伊春设立林业综合改革试验区，创新投融资体制机制和生态保护体制，转变林业经营方式，推动森林旅游、林下产业、林下剩余产业、生态林业、科技林业等新型林业的发展，将伊春打造成为我国新型森林城市，为国有林区的改革积累经验，提供示范作用。（市发改委负责）

2、进一步完善集体林权制度的各项配套改革工作。一是完善林木采伐管理机制。编制森林经营方案，改革商品林采伐限额管理，简化审批程序。控制公益林采伐，依法进行抚育和更新性质的采伐。二是推进林业投融资改革。加大林业信贷投放，完善林业贷款财政政策，扩大林业信贷担保方式，健全林权抵押贷款制度，结合林木生长周期长的特点，增加贷款额度，延长贷款年限。三是加快建立森林保险制度。积极争取尽快启动国家、省、市、县和承包人按比例承担保费的新机制。四是加强林业社会化服务。扶持发展林业专业合作组织，培育一批辐射面广、带动力强的龙头企业。发展林业专业协会，充分发挥政策咨询、信息服务、科技推广、行业自律等作用。（市资源林政局负责）

3、进一步深化国有林权制度改革试点工作。一是争取将伊春国有林权制度改革试点纳入国有林场改革范围，并争取先行试点，实现从“林权”改革向“林场”改革。二是积极争取进一步放宽贷款政策、放大贷款额度、放长贷款周期。三是尽快启动活立木产权交易市场，在公开、公平的市场条件下，实现职工自愿、合理交易和转让。四是抓好造林、抚育和低产低效林改造，发展速生丰产工业原料林，加快推进林板、林纸一体化进程。五是加快组建各类经济合作组织，创立股份林场、合作林场、家庭林场、林业合作社等新型经济合作组织，提高承包经营的规模化、集约化水平。六是充分发挥林地优势，向林地要效益，做大做强规模，实现品牌化。（市资源林政局负责）

（四）深化国有企业改革。继续深入推进国有经济战略性调整和国有企业公司制改革，引进战略投资者，加快光明集团股份有限公司国有股权重组，促其进一步做大做强。积极推进符合条件的大中型企业上市融资。完善企业法人治理结构，加快推进董事会建设。做好政策性破产企业收尾工作，妥善处理改制企业遗留问题。加快推进企业间并购重组和资源整合，尽快组建和完善旅游、木材精深加工、小木制品等企业集团。以规范完善企业内部经营机制为重点，推动公益性国有企业改革。对全市具有公益性质的供水、供气、污水处理、公共交通等方面企业，以内部劳动用工、干部人事、分配制度改革为主要内容，规范法人治理结构和加强管理制度建设，明确出资人管理制度，完善考核评价体系建设，实施有效的行业监管，实现兼顾社会服务和自身持续发展的双重目标。（市工信委负责）

三、加快财政体制改革

（五）深化财政预算管理改革。强化收入预算管理，将财政收入目标列入市政府绩效管理工程。加强部门预算管理制度建设,调整完善公用经费定员定额标准，确保单位运转需要。推动部门预算和“三公”经费预算公开,实行公开的零基预算。公开确定分类分档标准，公开执行统一的公用经费定额标准，公开编制程序。（市财政局负责）

（六）完善财政转移支付制度。建立市对区超收奖励机制，完善标准财政收支测算和区、局基本财力保障机制奖补办法，增强基层政府提供基本公共服务的能力。深化国库集中收付制度改革，资金支付都在国库单一账户体系下统一进行，对政府财政资金采取财政直接支付和财政授权支付两种方式支付到商品和劳务供应商，强化预算执行力度。实行公务卡管理制度改革，提高财政财务透明度。实行政府采购制度改革。将政府大项目投资和大额支出纳入采购范围，凡涉及设备、物品购置、工程施工等内容的，按照市政府印发的《政府采购目录限额标准》，将规定数额以上的货物、服务类项目支出、工程类支出等全部实行政府采购。（市财政局负责）

（七）推进财政收入管理改革。健全财政收入均衡入库机制，在坚持依法征收、应收尽收的前提下，对一次性、特殊性收入等，制定入库进度计划。紧紧围绕财政“十二五”规划发展目标，研究促进财政收入持续健康稳定增长的办法。（市财政局负责）

（八）推进非税收入收缴管理改革。继续加强市本级非税收入收缴管理改革。将新设立批准项目全部纳入非税收入收缴管理改革范围。按照统一软件系统、统一项目库、统一账户设置、统一票据的要求，确保年底前将能够纳入改革的非税收入项目全部纳入改革范围，将应纳入改革的市直单位全部纳入改革范围，将未经立项审批的其他国有资源（资产）有偿使用收入、广告收入、利息收入、捐赠收入、主管部门集中收入等能够纳入非税收入管理改革的项目全部纳入改革范围。（市财政局负责）

（九）推进国有资本经营预算制度改革。建立健全国有资本经营预算制度，规范国有资本经营预算收支管理，逐步提高国有资本经营预算的资本支出比重。规范企业国有资产交易行为，全市企业国有资产交易统一纳入省产权交易市场。（市财政局、市国资办负责）

四、深化金融体制改革

（十）进一步抓好融资体系平台建设。一是要搭建银政企对接平台，把全市重点项目推荐给银行作为银行的优质客户，为项目的快融资做好稳定的坚实基础。二是打造特色化地方金融产品,积极引导银行业金融机构调整和优化信贷结构，围绕伊春林业发展的特色，构建信贷金融产品，满足不同类型的金融需求。在林区中小企业的信贷研发上，加强产品的整合与研发，增强金融创新意识和机制，尽快改变金融产品相对单一的局面。三是要将银企对接项目资金落到实处。引导银行树立“立足伊春，支持伊春，发展伊春”的信贷意识，筛选出旅游、冶金、木材精深加工等五大优势特色优质项目，确定专行、专人负责，进行重点跟踪和对接，破除严格的信贷准入理念，把信贷资金落到实处。（市金融办负责）

（十一）优化金融生态环境。一是强化企业诚信意识。以征信体系建设为切入点，稳步推进企业诚信建设。面向企业和社会公众开展征信宣传活动，增强企业和公众的诚信意识。二是强力清收银行不良贷款，重点打击公职人员恶意欠贷行为。同时，建立失信企业“黑名单”制度。三是建立治理金融生态环境惩戒机制，以及信用信息的公开和惩戒机制，通过对典型企业的宣传曝光，实现以典型带动群体，促进企业诚信建设。（市金融办负责）

（十二）继续深化金融改革和完善金融服务体系。一是进一步明确市场定位，体现地方性金融机构自身的经营特色，在发展中小企业优质客户和为群众服务上下功夫，不断提升综合市场竞争能力。二是为龙江银行建立分支机构创造积极便利的条件，全力支持其将业务范围向林业局延伸，通过扩大经营来增加市场的份额，做大做强龙江银行“品牌”。三是筹建小额贷款公司及担保公司。进一步建立健全小额贷款公司和融资性担保机构的扶持政策，通过支持有资金实力的本地或外来企业到我市成立小贷公司和担保公司，帮助中小企业和微小企业解决融资“瓶颈”，使中小企业资金运行走上良性发展的轨道。到2012年底，力争使我市小贷公司和担保公司的数量均新增3家。（市金融办负责）

（十三）促进直接融资。一是推进企业上市融资。加强协调服务，协助企业实现上市目标。二是进一步挖掘培育上市资源。精心选择一批成长性强、效益好、规模大的骨干企业作为上市后备资源进行重点培植，建立上市企业后备资源库。三是拓宽直接融资渠道。指导我市符合条件的优势企业，通过发行企业债券、中期票据、短期融资券、包装上市等渠道筹集发展资金。（市金融办负责）

五、深化资源型产品价格和环保体制改革

（十四）继续推进资源性产品价格改革。依据《黑龙江省物价监督管理局关于居民生活用电试行阶梯电价的通知》精神，积极推进电价改革。按照省有关要求，积极推进水价改革。（市物价监管局负责）

（十五）积极推进节能工作。加强对节能工作的组织领导，将其纳入目标责任评价考核，实行问责制和“一票否决”。严格落实固定资产投资项目的节能评估和审查制度，力争固定资产投资项目节能审查率达到100%。制定《伊春市2012年节能减排工作实施方案》，出台《伊春市2012年节能降耗预警调控方案》。强化节能监察队伍建设。做好省级循环经济试点园区的申报工作，积极推行清洁生产，发展壮大节能环保产业。（市发改委、市环保局负责）

六、深化收入分配和社会保障

（十六）深化工资收入分配制度改革。推进和落实义务教育学校和公共卫生与基层医疗卫生事业单位实施绩效工资。（市人社局负责）

（十七）完善社会保障体系。开展被征地农民养老保险参保工作。继续解决好特殊群体参加养老保险问题。实现城乡社会养老保险制度全覆盖。研究探索企业年金制度建设工作。继续扩大基本医疗保险覆盖范围，依法推进，提高三项保险参保强制力。一是设立医保服务大厅，实行一站式服务。二是公开服务内容。电子屏幕滚动播放服务事项、办事流程、工作时限等内容，方便群众，提高工作效率。（市人社局、市编委办负责）

七、深化文化教育卫生科技体制改革

（十八）全面推进国有文艺院团转企改制任务。按国家及省市文艺团体改革的路线图和时间表，全力推进黑龙江林业文工团有限公司的组建工作。按照现代化企业制度要求，完善法人治理结构，推进劳动人事、收入分配和社会保障制度改革，引入竞争和激励机制，全力打造集文艺研究、创作、生产、演出于一体，艺术门类齐全、资源配置合理、稳定的文艺团体。（市文广新局负责）

（十九）全面推进教育改革与发展。统筹兼顾教育发展规模、结构、质量和效益，全面推进教育改革。进一步推进农村学前教育投入及管理体制改革试点和学前教育三年行动计划，完善学前教育管理机制，深化幼教改革，不断提高保育教育质量。以国家标准化建设项目为牵动，以薄弱学校改造为重点，加快推进县域义务教育均衡发展进程。不断深化普通高中课程改革，促进普通高中多样化、特色化发展。推进职业教育改革和发展，加快职教集团和实习实训基地建设，进一步加强基础能力建设，不断增强职业教育吸引力，实现职业教育技能化。（市教育局负责）

（二十）继续深化医药卫生体制改革。加快健全基本医疗保障体系，巩固扩大基本医保覆盖面，增强保障能力，提高管理和服务水平。继续巩固国家基本药物制度，扩大实施范围。健全补偿和绩效考核制度，提高基层医疗卫生机构服务能力。不断提高公共卫生服务均等化水平，进一步提高突发公共卫生事件应急处置能力。积极探索推进公立医院改革，加快建立现代医院管理制度，改革以药补医机制。大力创新卫生人才培养和使用制度，逐步建立全科医生制度，加快培养紧缺人才，促进人才向基层流动，探索推进索推进医师多点执业。积极推进医疗卫生信息化建设。探索加快形成对外开放的多元办医格局。（市卫生局负责）

（二十一）深化科技体制改革。支持农业科技化建设，推动农业科技跨越发展。强化企业创新主体地位，促进科技与经济的紧密结合。建立协同创新机制，推动产学研、农科教紧密结合，提高创新体系整体功效。改革科技管理体制，促进科技资源高效利用和管理科学化。完善人才激励机制，激发科技人员积极性和发明创造性。营造良好政策环境，为科技创新服务提供保障。（市科技局负责）

八、推进行政体制改革

（二十二）推进人事制度改革。加强公务员考试录用制度建设，规范选拔作用机制，加大公务员分类管理的探索力度，稳慎推进聘用制公务员试点工作。深化职称制度改革，探索建立科学、分类、动态、面向全社会各类专业技术人员的新型职称制度。推进事业单位人事制度改革，全面实行聘用制度和岗位管理制度，大力推行公开招聘制度，探索建立符合事业单位规律和特点的人事管理制度。（市人社局、市编委办负责）

（二十三）加快事业单位分类改革。深化全市事业单位改革工作，对事业单位进行科学分类，按时完成事业单位机构编制“十定”工作，研究制定全市分类推进事业单位改革人员分流安置办法。深化事业单位管理体制和人事、收入分配、社会保障制度改革。（市编委办、市人社局、市财政局负责）

（二十四）进一步深化审批制度改革。以项目建设、民生工作、“三农”问题和构建现代产业体系为重点，完善并严格执行审批事项设立和实施制度，加强对行政审批的全程监督，规范审批程序，取消和调整一批审批事项。加强审批受理时限的监督检查，确保各项审批事项按时办结。积极推进行政服务中心建设，建立和完善网上审批平台和电子监察平台，进一步规范行政权力运行。同时，加强监督检查，确保各审批部门严格执行行政审批的有关规定。推进行政审批制度化建设，全面推行岗位责任制等各项制度，进一步规范行政审批程序，加强行政审批问题的责任追究。（市政府法制办、市监察局负责）

九、不断加大对外开放力度

（二十五）加大口岸和对外贸易工作。全力抓好包括浮箱固冰通道、沿江封闭公路、口岸码头在内的口岸过货通道项目建设，并积极督促配合俄方加强口岸设施建设，完善口岸功能，以实现口岸通关过货便捷化、常态化，促进口岸经济全面提升。重点抓好西钢、新春、海华、华泰、欧帮德等对俄经贸合作企业，鼓励引导企业扩大经营规模，增强发展实力。充分发挥奥嘉股份有限责任公司的组织协调作用，进一步推进对俄农业开发合作提档升级。（市商务局负责）

按照我市与比罗比詹市制定的“2011—2012年友好合作活动计划”，努力推进对俄经贸合作。一是保持政府间高层互访，巩固与俄方的传统友谊。二是加强体育、文化、旅游和经贸等领域的交流，为我市与俄方签署的各种经贸合作项目顺利开展提供支持与服务。三是争取拓展和延伸对俄友好合作计划，在太阳能、蓝莓培育与加工、蔬菜大棚、养殖业等领域开展合作提供服务。四是认真建好文化主题公园比罗比詹广场项目，以进一步增进相互间的了解，加深友谊、促进交流、加强合作。五是加强与哈巴边疆区、阿穆尔州等远东地区政府间的联系与交往，特别是为促进双方经贸及其他领域合作的进一步发展，及时解决合作过程中出现的各种问题，提供必要的支持和帮助。同时，积极拓展友城格局，努力开展与邻国（如日本、韩国等）的交流活动，力争签署一份缔结友好城市关系意向性协议。（市商务局负责）

继续实施“走出去”战略，为企业扩大招商引资成果创造出国门的机会，使企业在更大范围、更高层次上参与国际经济技术合作。增强服务意识，抓好服务经济这条主线，进一步提高办团效率和实际工作水平，把好因公出国审批关，努力为办团单位及人员做好服务。（市外侨办负责）

十、深化农村改革

（二十六）搞好县域村镇体系和小城镇建设规划。按照“撤并自然屯，壮大中心村，发展小城镇”的总体要求，做好布局调整。实行并村进镇，规划建设农民社区。分散的村民组(屯)实行并屯入村，并在合理范围内合并相邻的村，做大中心村。与保留的中心林场（所）相邻的村要实行村场合建，一并规划建设。林场（所）布局调整要落实转型规划，充分考虑各林场（所）经营范围、生产项目、交通条件。撤并人口少、施业区面积小的林场（所），集中力量建设一批高标准的中心林场（所）。积极推进农村集体土地确权登记发证，以及农村土地承包经营权登记工作。全面推进农村土地规模经营制度，在做好试点的基础上，以合作社为载体，有效实施农村土地规模经营。（市农委负责）

（二十七）加强农林人才队伍建设。加快推进农林一体化发展，持续增强农产品和森林食品供给保障能力，提升农业技术推广能力，大力发展农业社会化服务，实施农民和务农职工科技素质提升工程，全面培养农林人才队伍。加大资金投入力度和政策扶持力度，支持农业科技化建设，提升农业技术推广能力，提高农民和务农职工的生产水平，推动农业科技化跨越发展。有效整合科技资源，建立协同创新机制，推动产学研、农科教紧密结合，强化关键技术攻关，加快推进农林产业新技术、优势品种的引进、试验、示范与推广，有效增加科技创新储备，从总体上提升农业和森林食品产业科技水平，构建适应现代农业和林下经济产业发展需要的科技创新体系。（市农委负责）

（二十八）加快推进区域国有粮企资源整合重组。制定《伊春市国有粮食购销企业资源整合重组工作实施方案》，确定嘉荫县为2012年国有粮食购销企业进行资源整合重组，实现“一县一企”、“一企多库”改革的试点县，结合嘉荫县粮食购销企业实际情况实施经营机制改革。（市粮食局负责）
