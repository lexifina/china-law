# 伊春市人民政府关于印发伊春市全民健身实施计划（2016—2020年）的通知

伊政发〔2017〕4号

各县（市）、区人民政府（林业局），市政府各委、办、局，中、省直各单位，各企事业单位：

《伊春市全民健身实施计划（2016—2020年）》已经市政府十四届一次常务会议讨论通过，现印发给你们，请认真贯彻执行。

伊春市人民政府

2017年3月10日

伊春市全民健身实施计划

（2016-2020年）

全民健身是增强人民体魄、实现幸福生活、促进全民健康的重要途径。过去五年，经过全市上下的共同努力，初步形成具有伊春特色、覆盖城乡、比较健全的全民健身公共服务体系，全民健身工作成效显著。为进一步推进全民健身事业发展，更加广泛地开展全民健身运动，构建更加完善、惠及全市人民的全民健身公共服务体系，形成具有时代特征、伊春特色的全民健身发展模式，培育打造林都伊春全民健身新品牌。根据《“健康中国2030”规划纲要》、《全民健身条例》、《国务院全民健身计划（2016-2020年）》和《黑龙江省全民健身实施计划（2016-2020年）》精神和要求，结合我市实际，制定本计划。

一、指导思想

深入贯彻落实党的十八大和十八届三中、四中、五中、六中全会精神，以“四个全面”战略布局、习近平总书记有关全民健身的重要论述和视察伊春特指要求为统领，牢固树立和践行创新、协调、绿色、开放、共享的发展理念，借助“健康中国”、全民健身上升为国家战略的机遇，以增强人民体质、提高健康水平为目标，坚持以人为本、改革创新、依法治体、确保基本、多元互促、注重实效的工作原则，营造“人人共享体育，体育造福人人”的浓厚氛围。加快完善与全面建成小康社会相适应的全民健身公共服务体系，不断满足林区人民群众日益增长的多元化健身需求。建设“健康伊春”，在全社会形成崇尚健康文明科学的生活方式，为打造森林冰雪运动名城，康体休闲旅游之都，建设生态充满魅力、特色经济发达、环境和谐优越、人民健康幸福的现代化森林城市做出积极贡献。

二、工作目标

（一）人民群众体育健身意识和身体素质普遍提高。参加体育锻炼人数明显增多，其中每周参加1次以上体育锻炼人数比例达到全市总人口的55%以上，经常参加体育锻炼人数比例达到全市总人口的38%以上。

（二）公共体育场地设施建设更加完善。人均体育场地面积达到1.95平方米以上。市区新（改）建1座冰水综合馆、1座全民健身综合馆和1个田径综合体育场。每个县（市）、区、局至少建成1个全民健身活动中心，城乡、社区和林场（所）建有便捷、实用的足球场等基本公共体育健身设施，初步形成“十分钟健身圈”。全市各类体育场地设施和符合开放条件的公办学校体育场地设施开放率达到100%。

（三）全民健身组织网络体系更加健全。县（市）、区、局均建有体育总会，健全各行业、人群单项体育组织，推动体育类社会组织实体化步伐。体育组织网络向基层延伸，群众体育俱乐部、青少年体育俱乐部、青少年户外体育活动营地等有较大发展，全民健身站点数达到500个，每万人拥有健身站点5个以上，形成遍布城乡、规范有序、富有活力的社会化全民健身组织网络。

（四）全民健身活动广泛开展。大力开展群众参与性强、普及面广、健身价值高的体育运动项目，培育打造具有一定影响力、符合我市实际、具有林区特色的全民健身品牌活动，统筹推进各类人群体育健身活动均衡发展。

（五）科学健身指导水平不断提升。完善国民体质监测制度，积极开展体质测定和运动能力评估，不断提高科学锻炼水平，实现城乡、林场（所）居民《国民体质测定标准》合格人数比例达到92%。

（六）全民健身指导和志愿服务队伍进一步发展。加强社会体育指导员和非奥项目教练员、裁判员等体育骨干队伍建设，注册社会体育指导员达到5000人以上，每千人拥有社会体育指导员5人以上，体育骨干的业务素质和技能得到较大提升。

（七）伊春特色高端休闲健身项目建成。依托伊春极致的自然生态资源优势，创建3至4项具有伊春特色、时代特征、影响力较大的户外、拓展、探险等高端体育旅游休闲项目，推进实施社会化、市场化运营，创建新兴体育产业。

（八）冰雪运动大力推动普及和发展。努力培育打造“中国林都·雪城伊春”冰雪体育活动品牌，激发广大群众参与冰雪活动的热情，形成冰雪运动群众基础更加坚实，普及程度大幅提升，竞技实力极大提高，产业体系较为完备的冰雪运动发展格局。

三、主要任务

（一）充分发挥全民健身在促进人的全面发展和社会稳定和谐等方面的正能量。弘扬健康新理念，普及科学健身知识，引导群众养成体育健身习惯，树立“绿色、健康、休闲、养生”的生活理念和生活方式，把身心健康作为个人全面发展和适应社会的重要能力，树立以参与体育健身、拥有强健体魄为必需的个人发展理念，倡导人民群众人人喜爱并参加1项以上的健身活动，不断提高经常参加体育锻炼人数比例，使体育健身成为更多人的基本生活方式。发挥体育在践行社会主义核心价值观、弘扬中华民族传统美德方面的独特价值和作用，让体育成为社会主义先进文化的传播者和创造者，成为伊春林区时代精神的倡导者和先行者。

（二）提升群众身边体育设施建设水平，努力实现便民体育设施全覆盖。从广大群众健身需求的实际出发，改善群众体育健身条件和环境，在全市合理规划建设一批健身公园、健身长廊、健身步道等健身场地设施，建设好面向群众的游泳、篮球、足球、排球、羽毛球、乒乓球等大众健身活动场馆，建设一批笼式足球场、篮球场、游泳池、轮滑场等社区多功能体育设施。到2020年，全市建成50个社区多功能运动场，100个全民健身活动中心，150个农村和林场（所）全民健身中心，200个足球场（含笼式足球场）。加快冬季冰雪运动项目场地建设，科学规划布局冰雪运动场地，引导社会力量建设，鼓励支持商业化运营，有计划地建设滑冰馆、室外滑冰场和滑雪场。利用我市山地自然资源，在全市开辟建设50个自然滑雪场，建设100个移动滑冰场，浇筑200个室外滑冰场。严格落实国家新建居住区和社区按室内人均建筑面积不低于0.1平方米或室外人均用地不低于0.3平方米的标准配套群众健身相关设施。有效开发利用低效用地建设体育场地设施，积极改造旧厂房、仓库、老旧商业设施等用于体育健身。充分利用森林公园、城市公园、城市空置场所等建设休闲健身场地设施。结合广场绿地，加大城市健身步道、登山步道建设力度，达到健身（登山）步道每万人15公里以上。推进公共体育设施、学校体育设施、企事业单位体育设施向社会开放，通过规范管理、服务提升、补贴扶持、购买服务等措施，推动体育资源社会共享，实现公共体育设施和符合条件的学校体育设施100%向社会开放。

（三）提升群众身边的体育组织水平，努力实现全市体育社会组织网络全覆盖。加强各级体育总会建设，带动指导各级各类单项、行业和人群体育组织开展全民健身活动。积极推进体育社团社会化、实体化改革，按照政社分开、权责明确、依法自治的原则，增强体育社团的自我运行能力，分批分步将各级体育社团彻底与体育行政部门脱钩。指导推动各县（市）、区、局同步推进体育社团社会化、实体化改革。引导各类体育社会组织以提高服务能力为重点，加强自身建设，完善相关制度，依据法律和章程规范运行。实施体育社会组织培育工程，优化体育社会组织的发展环境和土壤，鼓励和支持社会力量举办体育社会组织。

（四）广泛开展全民健身活动，丰富并完善全民健身活动体系。以国家“全民健身日”、我省 “全民冰雪活动日”和我市“全市徒步日”等为依托，设计安排四季特色鲜明、形式多样、富有大森林气息的贴近群众、贴近实际、贴近生活，经常性、季节性、业余性的全民健身活动。积极组织开展适合老年人、妇女、青少年、少数民族、残疾人等不同群体的全民健身活动，大力开展和普及森林健身跑、林中健步走、登山、骑行、游泳、乒乓球、羽毛球、足球、篮球、排球、网球、广场舞、轮滑、滑冰、冰球、滑雪等群众喜闻乐见的运动项目，扶持太极拳、健身气功、柔力球、门球、毽球、风筝等具有民族民俗民间传统特点的体育项目，推广徒步、漂流、穿越、探险等具有伊春特色和消费引领特征的体育项目。各机关、企事业单位和部门要积极做好职工体育工作，培育职工体育健身意识，鼓励开展多种形式的运动会或趣味体育竞赛、拓展训练等。同时，依托我市极致的生态资源禀赋，积极申办承办国际森林马拉松赛、冰雪马拉松赛、冰雪龙舟赛、自然水域漂流赛、小兴安岭穿越赛等大型有国内外影响力的全民健身活动，使本土特色的生态体育、休闲体育成为提升城市综合实力的名片。全市每年举办20项以上全民健身系列赛事活动，每四年举办1届全市全民健身运动会，县（区）级每年举办1次全民健身运动会、多项有特色的全民健身活动，营造全市“天天有活动、周周有赛事、处处有运动、人人常健身”的良好氛围。

（五）借助2022年北京冬奥会大好机遇，大力普及发展冰雪运动。积极贯彻实施国家“四部委”《冰雪运动发展规划（2016—2025年）》，以“黑龙江省全民冰雪活动日”为契机，结合伊春森林冰雪欢乐季活动，精心谋划冰雪系列赛事活动，营造冰雪活动浓厚氛围，培育打造“林都雪城”冬季体育赛事活动品牌。建立联席会议制度，将冰雪传统项目和新项目、群众体育和竞技体育统筹考虑，依托各协会和俱乐部，调动市级、区级以及基层战线，统筹设计安排好各节点赛事活动，构建起区区有冰雪运动品牌，月月有规模赛事、周周有特色活动的精彩纷呈的冬季运动发展格局。以“三亿人上冰雪”为载体，开展丰富的冰雪活动，创造条件扩大上冰雪人群；加强培养以青少年为重点的全民冰雪运动技能水平的提升，创造性地把十万青少年上冰雪活动持续抓起来。积极支持社会力量承办举办冰雪赛事活动，培育冰雪竞赛表演业，推动我市冰雪运动上规模上水平，激发广大群众上冰雪的热情。

（六）进一步提升群众身边的健身指导水平，完善全市国民体质监测网络服务体系。加大对全民健身的科研投入，开展体质监测、健身指导和运动干预相结合的市民体质干预工作，实现体质监测指导与健身指导、公共卫生、疾病预防相结合，引导市民科学健身。完善国民体质监测制度，建立和完善我市国民体质基础数据库，积极组织并完成好全市公民体质监测和全民健身活动状况调查。大力宣传推广科学健身方法，积极开展体质测定、运动能力评估，提高全民健身质量和水平。鼓励社会资本开办康体、体质测定和运动康复等各类机构。建立信息化服务机制。充分发挥互联网与微信、微博等新媒体的重要作用，借助移动信息化优势，充分整合自媒体与传统媒体的体育健身要素，探索实现“互联网+全民健身”发展新模式。与企业共同研发全民健身APP，建立全民健身管理资源库和服务资源库。通过全民健身大数据和云计算系统掌握全市健身基础数据和上升趋势，为城乡居民提供及时便捷的多样化、个性化、精细化的指导和服务，实现全民健身工作管理和服务方式的根本改变。

（七）激活全民健身多元功能，完善全民健身服务体系。结合“健康中国2030”以及伊春绿色化转型发展战略，推进健康伊春建设，充分发挥全民健身在促进社会包容、民生改善、健身消费等方面的独特功能，促进体育与旅游、文化、养老、卫生等事业融合发展。充分利用我市森林、山水等自然环境，积极推动休闲体育发展，以创建省级、国家级休闲体育城市为目标，打造设施齐全、独具特色的漂流、穿越、露营、登山、溯溪等探险和拓展类运动休闲项目，打造具有消费引领特征的3至5个休闲度假区。设计精品线路，使冬季雪山穿越、森林狩猎，夏季各类漂流、溯溪探险活动优势互补，实现冬夏两季共同发展。发挥全民健身对体育产业的动力源作用，加快发展健身服务业，鼓励和引导社会资金投资兴办职业体育俱乐部和营利性体育健身俱乐部，推动体育健身、运动休闲、场馆服务、体育培训、运动健身用品等产业发展。围绕人民群众多层次、多元化的体育需求，丰富体育产品和服务供给，全力拉动全民健身产业发展。

（八）积极拓展大众体育交流，推动我市全民健身向更高层次发展。采取“请进来、走出去”的方式，拓展对外交流渠道，以体育人才的交流与赛事合作为重点，学习借鉴省内外全民健身事业发展的先进经验和做法，增强我市全民健身事业发展的综合实力。通过举办承办国际、国内重大赛事及开展论坛研讨、交流健身产品、人才互动、活动联办等形式，加强同周边省、市体育交流与合作，实现共同参与，成果共享。利用地缘、人员优势与俄罗斯、韩国等国家开展多层次交流平台。

四、保障措施

（一）完善工作机制。发挥市、县两级全民健身工作领导机制作用，加快建设政府主导、部门协同、社会组织共同参与的全民健身组织结构。理清各级政府在全民健身工作领域的事权关系、明确事权边界，处理好政府与社会组织和市场的关系。各级政府要将全民健身的相关工作与现有政策、目标、任务、考评相对接，建立全民健身责任小组和分工制度。明确体育社会组织在全民健身事业中的主体地位，组织开展形式多样、丰富多彩的群众体育活动，努力挖掘和拓展全民健身活动的深度和广度。

（二）加大投入保障。各级政府每年要将全民健身经费列入年度财政预算，并随着经济的发展逐步增加对全民健身的投入。严格贯彻落实《中央集中彩票公益金支持体育事业专项资金管理办法》的精神，积极对上争取，加大体育彩票公益金用于全民健身事业的拨付额度。坚持全民健身社会办的思路，通过社会筹资、本级财政投入和对上争取资金等，扩容全民健身发展资本，建立多渠道的体育经费投入体系。发挥体育协会组织筹融资的作用，设立体育社团发展专项资金，转变体育赛事发展模式和办赛方式，丰富体育赛事市场化运作手段，加快体育组织市场化改革进程。

（三）健全评价体系。参照国家和省级公共服务体系建设标准，结合伊春体育发展的实际情况，出台《伊春市全民健身公共服务体系建设标准》，鼓励县（市）、区、局结合实际制定全民健身公共服务体系建设地方标准，推进公共服务均等化、标准化，并依托政府、专家、智库对体育主管部门、各协同单位全民健身工作开展情况进行全方位评估。完善统计制度，做好体育健身场地、体育社会组织、全民健身指导和志愿服务队伍、全民健身活动、经费支持等方面的调查和数据分析，进而做好健身场地规划、明确全民健身发展情况、掌握群众健身诉求。

（四）创新激励机制。积极搭建政府主导、全社会广泛参与的全民健身激励机制，对支持和参与全民健身、在实施全民健身计划中做出突出贡献的组织机构和个人进行表彰。鼓励有条件的场地设施在特定时间段向特定人群免费、低费开放或发放健身券等方式，让更多群众参与到全民健身中。

（五）加快人才培养。树立新型全民健身人才观，建立完善以社会体育指导员、全民健身志愿者、优秀退役运动员、体育社会组织带头人、智库专家等为核心的全民健身人才队伍体系。调整优化体育工作者队伍结构，拓宽选才视野，开展多层次、多角度、多形式的培训教育，不断提高专兼职队伍的政治素质和业务水平。加强各类专业技术人才的继续教育，加大人才引进力度，逐步形成一支结构合理、数量充足的高素质人才队伍。加强对公益性和职业资格类社会体育指导员的培训，对社会体育指导员的注册分类管理。强化社会体育指导员对社会体育活动的参与示范和指导，不断提高社会体育指导员的综合素质和业务能力，发挥其在开展全民健身活动中的示范指导作用。

（六）推进法制建设。坚持依法治体、依法兴体的基本方略，全面贯彻落实《中华人民共和国体育法》、《全民健身条例》、《公共文化体育设施条例》、《彩票管理条例》等法律法规，紧密结合伊春体育改革发展实际和需要，建立完善《伊春市全民健身公共服务体系建设标准》，加快伊春全民健身法制建设进程，运用法治思维推进全民健身公共服务体系建设，完善全民健身公共服务体系相关配套规章制度，依法保障公民的体育健身权利和社会资本投入者的合法权益，依法保障全民健身事业主办者、参与者、投资者、消费者等各方的合法利益。

五、组织实施

（一）强化组织领导。建立完善实施计划的领导协调机制，把全民健身公共服务体系建设摆在重要位置，纳入国民经济和社会发展总体规划及基本公共服务发展规划，把相关重点工作纳入政府年度民生实事推进和考核。

（二）完善考评机制。加大对实施计划的督办落实力度，实行目标责任考核，建立市、县（市、区）两级组织机构，有组织、有步骤地分步推进实施。市体育部门定期开展第三方评估和社会满意度调查。2020年对《全民健身实施计划（2016—2020年）》实施情况进行全面评估，将评估结果和调查情况通过媒体向社区通报。
