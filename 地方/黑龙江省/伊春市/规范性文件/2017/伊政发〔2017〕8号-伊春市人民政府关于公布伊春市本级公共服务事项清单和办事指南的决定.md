# 伊春市人民政府关于公布伊春市本级公共服务事项清单和办事指南的决定

伊政发〔2017〕8号

各县（市）、区人民政府（林业局），市政府各委、办、局，中、省直各单位，各企事业单位：

市政府十四届五次常务会议讨论决定，公布市本级公共服务事项清单和公共服务事项办事指南（清单目录及办事指南请登录“中国·伊春”门户网站首页查阅下载，网址：http://yc.gov.cn/）。

各单位要强化责任落实，加强信息公开，保证人民群众对基本公共服务事项“应知尽知”“须知尽知”“想知尽知”，全面正确履行职责，保证国家的各项惠民政策切实落实到位。要按照公布的市本级公共服务办事指南，创新工作方式、丰富服务内容、强化服务意识，全面提升公共服务质量和水平。要畅通群众诉求表达渠道，及时准确了解基层群众公共服务需求，完善事项清单，动态调整，努力提升为民服务能力。

本决定自发布之日起施行。

伊春市人民政府

2017年5月31日
