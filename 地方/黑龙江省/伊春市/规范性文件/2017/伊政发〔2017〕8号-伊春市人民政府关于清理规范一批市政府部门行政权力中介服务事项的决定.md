# 伊春市人民政府关于清理规范一批市政府部门行政权力中介服务事项的决定

c

各县（市）、区人民政府（林业局），市政府各委、办、局，中、省直各单位，各企事业单位：

市政府十四届五次常务会议讨论决定，清理规范158项市政府部门行政权力中介服务事项。其中，取消7项、规范30项、保留121项（取消、规范、保留的市政府部门行政权力中介服务事项目录附后）。有关单位要认真抓好清理规范行政权力中介服务事项的落实，加快推进配套改革和相关制度建设，切实加强事中事后监管。对于涉及公共安全的行政权力事项，中介服务事项清理规范后，要进一步强化相关监管措施，确保安全责任落实到位。

本决定自发布之日起施行。

伊春市人民政府

2017年5月31日
