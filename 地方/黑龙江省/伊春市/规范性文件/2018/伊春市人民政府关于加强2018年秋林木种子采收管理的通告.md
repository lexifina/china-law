# 伊春市人民政府关于加强2018年秋林木种子采收管理的通告

为确保育苗、造林生产用种需求，根据《中华人民共和国种子法》和《黑龙江省林木种子管理条例》，现就加强2018年秋林木种子的采收管理事宜通告如下：

一、凡入山采集林木种子的人员，必须持有林业行政主管部门签发的《林木种子生产经营许可证》和防火部门签发的《入山证》。

二、采种林分包括种子园、母树林、一般采种林和临时采种林、群体和散生的优良母树。林木种子采收必须在种子成熟后进行。在林木种子生产基地内采集种子的，由种子生产基地的经营者组织实施；在其他范围内采集种子的，由各地营林主管部门指定地点。采集林木种子必须按照国家有关标准进行，严禁掠青和毁坏母树。禁止在劣质林内、劣质母树上采种，禁止在确定的采种林分外采种。

三、林木种子生产基地生产的林木种子应由林业林木种子管理部门统一收购，对违反规定收购林木种子的，一律没收纳入国库。持有林业行政主管部门核发《林木种子生产经营许可证》的单位或个人，待市政府下达的收购计划完成后，在《林木种子生产经营许可证》规定区域内采收。对故意哄抬种价或私下交易，扰乱种子市场的，一经发现，将按有关规定严肃处理。

四、外运红松、樟子松、落叶松林木种子必须持省林业行政主管部门或市林木种子站签发的《林木种子运输证明》和各级森林病虫害防治检疫站签发的《植物检疫证书》。公路客运站、铁路车站要严格把关，对无正规手续的，不予承运。资源林政木材检查站对外运红松、樟子松、落叶松林木种子的车辆要认真检查，对无证运输的，有权扣留，依法处理。

五、营林、公安、工商、资源林政和森防部门要认真履行职责，严格监督检查，严肃查处违反种子采收、防火和安全规定的行为。

伊春市人民政府
