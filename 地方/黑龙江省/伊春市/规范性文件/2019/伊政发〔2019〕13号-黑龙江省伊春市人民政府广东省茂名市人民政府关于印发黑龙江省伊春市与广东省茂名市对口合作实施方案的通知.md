# 黑龙江省伊春市人民政府广东省茂名市人民政府关于印发黑龙江省伊春市与广东省茂名市对口合作实施方案的通知

伊政发〔2019〕13号

按照《国务院办公厅关于印发东北地区与东部地区部分省市对口合作工作方案的通知》（国办发〔2017〕22号）、《黑龙江省人民政府 广东省人民政府对口合作框架协议（2017-2020年）》、《黑龙江省与广东省对口合作实施方案》和《黑龙江省伊春市与广东省茂名市对口合作框架协议》要求，结合两市实际，制定《黑龙江省伊春市与广东省茂名市对口合作实施方案》，现印发给你们，请认真组织实施。

伊春市人民政府              茂名市人民政府

2019年11月28日

黑龙江省伊春市与广东省茂名市

对口合作实施方案

为深入贯彻党的十九大精神，落实党中央、国务院关于推进新一轮东北地区等老工业基地振兴战略的决策部署，扎实推进两市对口合作务实有效开展，按照《国务院办公厅关于印发东北地区与东部地区部分省市对口合作工作方案的通知》（国办发〔2017〕22号）、《黑龙江省人民政府 广东省人民政府对口合作框架协议（2017-2020年）》、《黑龙江省与广东省对口合作实施方案》和《黑龙江省伊春市与广东省茂名市对口合作框架协议》要求，结合两市实际，制定本方案。

一、合作原则与目标

（一）合作原则

在两省统筹推动合作的基础上，综合考虑两市资源禀赋、产业基础、发展水平以及发展现状等因素，本着“政府搭台、社会参与，优势互补、合作共赢，市场运作、法制保障”的原则，两市开展相互学习、经验交流活动，推动各领域不同层次的对口合作，以市场为导向，促进要素合理流动、资源共享、产业合作、园区交流、人才交流，推动实现务实、高效、简约开展对口合作，促进两市经济互融发展。

（二）合作目标

到2020年，两市对口合作取得重要实质性成果，建立起横向联动、纵向衔接、定期会商、运转高效的工作机制，构建政府、园区、企业、商协会、研究机构和其他社会力量广泛参与的多层次、宽范围、广领域的合作体系，形成常态化干部交流和人才培训机制。探索共建特色产业合作平台，力争实现一批标志性跨区域合作项目。在相互学习、相互借鉴、相互交流中共同探索出一条南北联动、优势互补、互利共赢、共谋发展的新路径。

二、重点任务

（一）加强放管服改革、事业单位分类改革经验交流

加强两市在加快转变政府职能、分类推进事业单位改革、降低制度性交易成本等方面的经验交流，深化简政放权、放管结合、优化服务改革，提高两市政府和事业单位公共服务水平。加强在优化营商环境、推进“一网、一门、一次”改革、承诺制审批、实行企业投资项目管理负面清单等方面的经验交流。开展减证便民行动经验交流。发挥财政资金的导向作用，按照商业化、市场化原则，引导金融资本服务于经济社会改革发展。（责任单位：伊春市委编办、市营商局、市司法局、市市场监管局、市发改委、市财政局、市金融局；茂名市委编办、市政府办、市司法局、市市场监管局、市政务服务数据管理局、市发改局、市财政局、市金融局）

（二）加强两市民营经济发展经验交流

加强两市在中小企业公共服务平台网络建设和开展在线法律服务等方面经验交流，完善公共服务平台功能，提升平台建设水平。加快完善两市民营经济发展的政策环境、市场环境、金融环境、创新环境、人才环境，加快构建“亲”、“清”新型政商关系。推动两市社会资本相互流动，促进两市民营经济共赢发展。加强工商联、商会、行业协会对接合作，组织企业家到对方交流经验、洽谈合作。促进理念互融、信息互通、资源共享、人才互用。（责任单位：伊春市工信局、市商务局、市经合局、市工商联；茂名市工信局、市商务局、市投资促进局、市工商联）

（三）加强对内对外开放交流合作

协同参与“一带一路”建设。共同参与中蒙俄经济走廊建设。联合开展对俄经贸合作，拓展东北亚市场。利用广东省对外开放合作资源，共同拓展东盟市场，参与海上丝绸之路建设。引导企业参与东盟地区投资及国际产能合作，吸引优质外资。两市积极参与粤港澳大湾区建设，积极与港澳地区加强经贸投资合作。积极推动两市企业参加中国—俄罗斯博览会、中国进出口商品交易会、中国国际高新技术成果交易会、中国（深圳）国际文化产业博览交易会等展会及两省主办的其他经贸交流活动。（责任单位：伊春市商务局、市经合局、市工信局、市发改委；茂名市商务局、市投资促进局、市工信局、市发改局）

（四）加强装备制造业交流合作，促进转型升级

引导两地制造企业开展交流与协作，充分利用伊春市西钢集团、鹿鸣钼矿、铅冶炼等产业基础，借助茂名市金属加工及先进装备制造业的优势，实现双方企业在技术、管理、投资、生产加工、营销等方向合作对接，共同促进装备制造业转型升级发展。支持茂名先进装备制造业企业开拓东北市场。（责任单位：伊春市工信局、市发改委；茂名市工信局、市发改局）

（五）加强生物医药业交流合作，实现优势互补

发挥两市在药材种植、制药业方面的各自优势，共同扩大伊春市北药和茂名市南药品牌影响力。加强两市生物医药类优势企业合作交流，实现产业裂变升级扩张发展。两市合作开展原料收储及产地深加工，合作开发国内外市场营销。共同推动提升伊春市林都北药影响力，鼓励支持茂名市有实力的医药企业到伊春市拓展业务，促进伊春市道地药材就地加工，提高附加值。利用伊春市与俄罗斯远东地区毗邻的口岸优势，瞄准俄罗斯远东地区种类丰富、蕴藏巨大的野生中药材资源，进口市场紧缺的野生药材，开辟生物医药原料供给商贸新市场。（责任单位：伊春市工信局、市市场监管局、市农业农村局〔市北药产业服务中心〕；茂名市工信局、市市场监管局，市农业农村局、市商务局）

（六）加快农业和绿色食品交流合作，共同开拓市场

推动两市建立农业和绿色食品长期产销对接关系，两市在粮食精深加工、绿色食品产业发展方面深度合作。鼓励茂名市农业产业化龙头企业发挥资本、技术、市场优势，到伊春市投资建设一批农产品加工基地，建设物流园区、乡村旅游、养老等三产融合项目。两市加大力度宣传推介蓝莓、坚果、食用菌、森林猪、森林鸡、林下牛等伊春市优质特色森林食品，香蕉、荔枝、龙眼（桂圆）等茂名市优质特色农产品。支持引导茂名有实力的农副产品加工企业到伊春开展粮食订单生产和收购，合作建设若干绿色食品加工等特色产业基地。两市签订粮食安全战略合作框架协议，提升粮食安全合作水平。利用广东省发达的电子商务、营销网络、商业模式，设立伊春森林食品营销店，促进更多伊春市特色森林食品通过茂名市进入华南市场。加快茂名市农副产品、食品加工业借道伊春输往东北地区及俄罗斯远东地区。互相学习借鉴两地深入实施乡村振兴战略的经验做法，推动发展乡村经济。（责任单位：伊春市农业农村局、市发改委〔市粮食局〕、市经合局；茂名市农业农村局、市商务局、市投资促进局、市粮食和储备局）

（七）推动服务业合作，扩大内需市场

1.旅游业。充分发挥伊春市和茂名市旅游资源丰富、南北气候互补性强的优势，促进两市旅游资源互动、旅游业共同发展。通过共同开发伊春旅游景区、茂名滨海景区等多种方式打造特色旅游品牌和线路，推动两市互为旅游客源地和目的地。互相支持对方建设全域旅游示范区。互相支持对方举办、承办的各种旅游推介会。推动伊春市各类旅游产品、旅游纪念品进驻茂名市粤西手信城，利用茂名地域优势全面展示伊春市的旅游资源。两市联合打造“南来北往、寒来暑往、常来常往”旅游品牌交流活动，促进两地旅游产业发展合作共赢，双方推动旅游、文体、休闲等产业合作与发展。（责任单位：伊春市文化广电旅游局；茂名市文化广电旅游体育局）

2.养老、健康等产业。加强两市医疗卫生领域合作，共同发展养老、健康等产业。推动中医药项目合作。依托两市良好资源优势和产业基础，共同发展“互动式”养老、医疗大健康等产业，引导两市社会组织、养老机构到对方参与养老市场服务。（责任单位：伊春市卫健委、市民政局；茂名市卫健局、市民政局）

3.文化产业。充分发掘两市特色文化资源，在新媒体、演艺、文化旅游、工艺美术、文化产品等方面，加强交流合作，促进两市文化企业、文化事业共同发展。推动两市建立新闻出版广播影视媒体宣传和产业发展领域的对口合作关系。（责任单位：伊春市文化广电旅游局；茂名市文化广电旅游体育局）

4.金融业。积极加强两地金融工作经验交流，促进两地金融服务和创新能力提升。推动金融要素市场跨地区整合与流动。加强两市金融合作，推进两市合作发展创投基金、天使基金、股权投资基金等，支持服务两市实体经济发展。（责任单位：伊春市金融局、伊春银保监分局、人民银行伊春市中心支行；茂名市金融局、茂名银保监分局、人民银行茂名市中心支行）

（八）科技协同创新，力促科技成果转化

进一步加强科技创新合作，重点加强两市产学研合作交流，配合省遴选职业院校建立结对合作关系，组织两地科研院所、科技型企业开展科技对接交流活动。支持和鼓励两地优势科技型企业开展对接合作和到对方投资创业。围绕伊春森林食品、茂名农产品、生物医药等领域共建科技创新平台，实现两市科技计划项目立项对标合作，进一步促进科技成果转化利用。加强两市企业孵化器发展交流合作，建设完善科技孵化器。加强两市在双创工作方面的经验推广，围绕创新创业大赛成果，互相借鉴学习两地开展创新创业工作先进经验。组织开展两地高等院校、职业院校间的技术交流合作活动，建立两市院校的校际交流长效机制，定期举行校际交流活动，加强沟通、增进交流、加深友谊、促进互相学习提高。鼓励两地双创人才积极参与创新创业，进一步推动两地高校大学生创新创业工作。（责任单位：伊春市科技局、市教育局、市人社局；茂名市科技局、市教育局、市人社局）

（九）加强园区合作，探索互利共赢

加强两市高新区、经开区、专业园区、特色园区间的交流与合作，创新园区管理，优化园区服务，推动产业集聚，促进园区创新发展、优化发展。强化交流学习，借鉴茂名市园区的管理体制、招商引资、项目融资、运营机制等先进经验，助力提升伊春市园区建设。双方探索以市场化方式共同开发产业园区，吸引两地企业落户。（责任单位：伊春市商务局、市经合局；茂名市工信局、市商务局、市投资促进局）

（十）开展人才交流，夯实合作基础

落实两市干部人才交流培训合作协议，伊春市按照黑办发〔2018〕48号文件关于“选派优秀年轻干部到广东等改革开放前沿地区学习考察和实践锻炼”要求，可选派干部赴茂名挂职锻炼，或选派优秀年轻干部赴茂名短期学习考察。茂名市可结合实际，采取适合的方式选派干部到伊春挂职锻炼或考察交流，促进两市相关部门、战线、领域的干部之间业务交流、能力提升。围绕乡村振兴战略、园区和产业项目建设、资源开发利用等方面，两市组织不同层面学员到对方市委党校开展短期培训。加强职业教育，依托茂名技师学院、高级技工学校，为伊春市培养更多实用人才、本土人才。充分发挥人力资源市场人才资源配置作用，招聘交流两地企业急需人才。引入和支持专业技术、经营管理等各类人才跨地域从事技术帮扶服务，建立人才信息互通发布机制，实现两市人才信息网站互联、求职人才信息数据库共享，促进人才资源的有效对接。（责任单位：伊春市委组织部、市人社局；茂名市委组织部、市人社局）

（十一）充分发挥部门积极性

结合两地实际情况，两市各部门积极探索创新，依托两市要素资源和需求市场，开拓性地开展工作，切实推动两市对口合作工作落到实处、取得成效，为对口合作工作提供先进经验。（两市各有关部门）

（十二）协调推进两市县（市）、区间合作有序开展

推动两市县（市）、区依托资源优势、特色产业、需求市场，开展工作对接，探索建立结对合作关系，开拓性地开展工作，鼓励结对县（市、区）开展互访、组织干部挂职培训、开展经贸交流活动、开展企业、机关干部经验交流活动、推动各领域对口合作项目落地，协调解决项目合作中存在的问题和困难，积极推动合作项目早日取得成效。（各地政府牵头）

三、保障措施

（一）完善工作机制。在两省对口合作统一安排部署下两市建立对口合作领导和协调推进机制，分别成立由市长任组长的对口合作工作领导小组，领导小组办公室设在市发改委（局），负责对口合作日常工作。两市有关单位及有关县（市、区）作为领导小组成员单位，分别承担各自工作任务，推动相关合作任务落到实处。两市领导每年开展互访或座谈交流，共同研究推动重点工作。

（二）强化机制保障。建立以市场为导向的常态化机制，通过政府组织推动两市市场化、常态化合作。两市组织部门负责对接上级组织部门，牵头推进干部人才交流培训等工作。对口合作具体工作涉及的财政经费支出，按财政预算管理规定纳入同级预算管理。健全宣传机制，两市在报刊、广播、电视、网络等媒体互办栏目，充分宣传对方城市。

（三）强化政策扶持。各重点合作领域牵头部门要密切跟踪国家和省政策动态，积极与国家和省对口部门对接，在政策实施、规划编制、项目安排、改革创新、先行先试等方面争取国家和省部门支持。两市围绕合作重点项目，积极争取中央预算内资金支持和银行业金融机构信贷支持。

（四）制定年度工作计划。围绕对口合作工作方案重点任务，两市各职能部门按照分管领域和行业制定年度工作计划，落实重点合作项目，开展长效、稳定的对接合作。
