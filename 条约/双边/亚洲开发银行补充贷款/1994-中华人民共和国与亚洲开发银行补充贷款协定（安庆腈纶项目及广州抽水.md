# 中华人民共和国与亚洲开发银行补充贷款协定（安庆腈纶项目及广州抽水...

中华人民共和国与亚洲开发银行
补充贷款协定
(安慶脯給項目及廣州抽水蓄能電站二期項目)
本補充貸款協定於一九九四年四月十九日由中華人民共和國
(以下简称“借款人”)与亚洲开发银行(以下简称“亚行”签定。
监于，
(A)根據借款人與亞行一九九一年十二月二十日簽署的貸款
協定(以下簡稱“安慶主貸款協定”),亞行已經同意從其普通業
夯資金中,為安慶主貸款協定附件1所述之安慶脯綸項目(以下
简称“安庆项目”)向借款人提供一筆相當於一億零五百萬美元
(10500万美元)的貸款(以下簡稱“安慶主貸款”),;
(B)根据借款人与亚行一九九四年一月五日签署的贷款协定
(以下简称“广州主贷款协定”,亚行已经同意从其普通业务资金
中，为广州主贷款协定附件1所述之廣州抽水蓄能電站二期項目
(以下简称“广州项目?)》向借款人提供一笔二亿美元的贷款(以
下简称“广州主贷款"。安庆主贷款协定和广州主贷款协定,以下
統稱“主貸款協定”,安慶項目和廣州項目,以下統稱“項目”);
(C)根据亚行与安庆石化总厂(以下簡稱APW)於一九九一
年十二月二十日签订的项目协议〈以下简称“APW項目協議”),
安庆石化总厂负责执行安庆一期项目〈如安庆主贷款协定中附件
1之规定)。根据该项目协议,APW同意就安慶項目和安慶主貸款
問亞行承擔一定的義務,;
(D)安庆曙光化工厂〈以下简称ASCF)负责执行安庆二期
項目(如安慶主貸款協定中附件1之规定);
(E)根據亞行和廣東抽水蓄能電站聯營公司〈以下简称GP-

SJVC)于一九九四年一月五日签订的项目协议〈以下简称“GP-
SJVC項目協議”), GPSJVC负责实施广州项目。根据该项目协
议，GPSJVC同意就广州项目和广州主贷款向亚行承担一定的义
務(安慶項目協議和廣州項目協議以下統稱“項目協議);
(F)借款人已为项目向亚行申请一笔不超过七干八百万美元
(7800万美元)的补充贷款(以下簡稱“貸款”),其中包括Gi)金
額不超過一千五百萬美元(1500萬美元,以下簡稱“安慶貸款”)
和(Gii)金额不超过六干三百万美元(6300万美元,以下简称“广
州贷款”)。这项贷款全部由商业银行参加亚行融资的方式提供;
(G)为了这笔贷款，主贷款协定和项目协议将根据本补充贷
款协定子以修订;
(H)借款人将按照亚行满意的条款和条件把贷款资金提供给
APW和GPSJVC (以下简称“项目执行机构”);以及
(D基于上述情况,亚行特此同意按照本协定的条款和条件向
借款人提供這筆貸款,;
為此,雙方達成以下協定:
第一条定义
1.01定立:
除上、下文另有要求外，在本协定中使用的以下术语具有以
下含義:
(a) “放款”指商業銀行為了在本協定項下提款之目的而放出
的款项;
(b) “代理行”,指日本長期信用銀行及其繼承人,
(ce) “营业日指伦敦银行的工作日,同时也是纽约、香港和
东京商业银行开门营业的日子;
(d)“商业银行”或“所有商业银行”，指本协定附件1中所.
列的任何一家或所有參加貸款的銀行或金融机構,還應包括為借
款人和亚行所能接受的继承人、受让人和被转让人;

(e)“承诡"，指亚行按照本协定第2. 01款規定,向借款人提
供貸款的義務,
(f) “債務”,就借款人而言,指由各债务人为借款或筹款,或
为所购财产或劳务的延期付款而产生、发行、直接或间接担保,发
生或承担的负债或债务，包括对该债务人的资产或收入采取以任
何留置权形式作保证的上述任何负债或债务;
4g)“美元”和“$$”，指美利坚合众国的法定货币美元;
(h)“提款”,指應借款人的要求,在商业银行放款的基础上，
亞行對貸款資金的付出或過戶;
(G)“留置權”,指抵押、索物、典當、留置或對任何人的任何
债务提供保证的其他留置权;
()“連約事件”,指本協定第10. 01款所述的任何事件;
(k) “外債”,指借款人以其法定貨市以外的貨市償付的債務,
或向在借款人领土以外居住、设立总部或主要营业场所的任何人
偿付的债务;
()“定息日,就该贷款而言,对于有待决定利率的任何一段
时期，系指该期第一天的前两个营业日;
(m)“付息日”,指每年的三月十五日和九月十五日。如果第
一個付息日為一九九四年三月十五日(本協定付時日的順序和次
數應作出相應推算),而且如果这两天的任何一天不是营业日,那
么付息日应定在紧接着的下一个营业日;
(n)“计息期”，就每次提款而言，指从该提款日至提款后下
一個付息日的前一天(含這一天),此后的各个计息期均从前一个
计息期的最后一天的付息日至下一个付息日的前一天〈含这
一天)#
(o)“換文”,指借款人和亞行於同一日期就本貸款的管理費
和代理费达成的书面协议;
(p)“倫敦銀行同業拆放利率”,就任何有關的金額和任何有
美的期限而言,指代理行自行確定的利率,該利率應為下述利率

的算术平均值(精確到1%的1/16);
《i)在定息日伦敦时间上午11 : 00整或11 : 00左右,路透社
监视屏显示的伦敦银行同业市场上主要投资银行期限相当的美元
存款年利率。为此,“路透社监视屏”为路透社监视系统中“伦敦
银行同业拆放利率”的显示屏，也可以是该监视系统中能够报出
的這種利率的其他顯示器件;或者
(ii)在没有或只有一家利率于任何利息决定日显示的条件
下,各參考行通知代理行作為定息日倫敦時間上午十一時整或左
右,倫敦銀行同業市場主要銀行據以向參考行提供該期美元貸款
的年利率的各自利率。但如果任何參考行沒有就任何有關期限向
代理行通知该利率，对该期限的“伦敦银行同业拆放率”应按照
其他參考行通知的利率予以決定。
(q)“貸款”,根據上下文內容,指以借款人為受益人的貸款
本金總額,或已提取的金額,或未償還金額;
4r)伦敦银行营业日”,系指伦敦同业银行欧洲美元市场营业
的日子;
(s)“参考行"，指“东京银行"“巴克莱银行"“日本长期信
用银行”和“摩根信托公司”的主要伦敦办事处;
(t) “附属贷款”,指根据附属贷款协议向项目执行机构提供的
任何一第貸款;
(u) “附屬貸款協議”,指Gi)借款人和APW簽立的轉貸協
議。根據該協議,安慶主貸款資金應當提供給APW, Gi)借款人
和GPSJVC簽立的轉貸協議。根據該協議,廣州主貸款資金應當
提供給GPSJVC, (iii)借款人和APW簽立的本貸款的轉發協議。
根據該協議本貸款資金應當提供給APW,以及(Giv)借款人和GP-
SJVC簽立的本貸款協議,根據該協議,本貸款資金應當提供給
GPSJVC。
1.02除上、下文另有要求外，凡在本协定中出现的单数名
词周包括其复数形式，反之亦然。凡表示人的名词缘包括公司和

合伙人,凡提到的某條、某款或某附件,應當理解為本協定中特
指的那一條、那一款或那一附件。條款和附件的標題只是為了便
于查阅，故不得以此来解释本协定。
第二亲”贷款;承诺
2. 01贷款金额，承诺。
根據本協定的條件,亞行同意向借款人提供不超過七千八百
萬美元(7800万美元)的贷款，这笔贷款资金全部由商业银行通
过参加此项贷款的方式提供。
2. 02 ”贷款承诺的终止
(a)如果在本协定签署后一百八十(180)天內借款人沒有履
行協定第9. 01、9. 02和9. 03款中规定的首次提款的先决条件,亚
行可以书面通知借款人终止第2. 01款所述的贷款承诺;
(b)借款人有权在任何时候，至少应提前七个营业日书面通
知亞行,全部或部分地終止亞行的貸款承諾,每次終止的金額至
少應為二百萬美元(200萬美元),其超出部分應為五十萬美元的
整数倍。亚行承诺的任何一笔款额一旦子以终止，那么根据本协
定的规定，不得重新启用。
2.03终止日期
除非亚行另行同意，亚行的承诺于本协定签署后的第四个周
年日应无条件地全部终止，贷款的任何未提款项亦应自行取消。
2.04法律变化
当亚行被任一商业银行告知，由于在任何法律、法规、条例
中或負責解釋或實施的政府機構,在所作的解釋或實施中發生變
化,而導致該商業銀行繼續放款被認為非法時,盡管本協定的其
他条款另有规定，该商业银行继续放款义务将被终止，亚行的承
諮亦相應減少。如有變化要求,借款人應於亞行根據商業銀行的
请求或指令所指定的当天，偿还该商业银行未被偿带的放款及所
有累计利息和其他应付款项。在这种情况下，亚行应立即向借款

人出示经该商业银行核实的法律、法规、条令、解释或实施中发
生变化的证据，在此情况下，对该部分的终止款项，借款人没有
任何金融责任。
第三条”贷款的使用和提款
3.01贷款资金的使用
(a)借款人应按照亚行满意的条件,将贷款资金按附属贷款协
議的方式轉貸給每一個項目執行機構,除非經借款人和亞行另行
同意,貸款資金的轉貸條件應包括;
(i)安慶貸款轉貸給APW;
GI)广州贷款转贷给GPSJVC;
(iii)与本贷款规定的同一利率和还贷期;和
Gv)APW承担安庆贷款的外汇风险,GPSJVC承担广州贷款
的外汇风险。
(b)借款人应督促项目执行机构将贷款资金用于项目支出，
包括貸款的建設期利息,作為在主貸款項下提供融資的補充。
(c)借款人应保证用贷款资金所采购的货物.服务和其他支出
项目，均生产和采购于亚行成员国，并符合项目的技术要求。这
种货物、服务的价格和支付条件应当合理。
3.02提款
(a)借款人提款时，(i)安庆贷款和广州贷款的最小提款额应
各為三百萬(300万)美元,或者(ii)如果提款额高于此最小限
额，那么该款额应为一百万(100万)美元的倍數,所提款項應當
(15)个营业日，以附件2规定的格式，向亚行提出提款申请。该
申请一经亚行收到，应是不可撤销的并对借款人具有约束力。如
有果在提取这笔款额之前尚未具备本协定第9. 01、9. 02和9. 03款
(不包括第9. 03款中的(a)要求的提款条件)，那么代款人应当承
擔商業銀行由此而產生的一切合理開支。
(c)根遞亞行的要求,借款人應對每次提取的款項向亞行簽發

收据。
3. 03貸款資金使用情況的報告
(a)借款人應確保所提貸款資金已經按本協定3. 01款的規定
使用,以使亞行滿意。為此,借款人應當提供或督促提供亞行有
合理要求的有关报告和资料，其中包括〈i)贷款、贷款资金的使
用及項目設施的維護; Gi)用贷款资金所购的货物、服务和其他
支出項目; (iii)項目; (Giv)轉貸款; (v)任何其他与贷款有关的
事项。
(b)借款人应当让亚行代表检查项目、使用贷款资金所购的
设施以及任何有关的记录和文件。
第四条”利息、费用、杂费、分期偿还
4.01利筷
(a)借款人应于每个付息日,根据亚行收到的代理行通知的利
率,按已提取但未償還的貸款,向亞行支付該計息期應付利息的
年率為倫敦銀行同業拆放利率加百分之零點六五(0. 65)。
(b)亚行应在每个定息日后,在收到代理行通知的基礎上,立
即告訴借款人相應計息期的利率。亞行根據代理行的通知向借款
人發出的告示,是不可改變的並對借款人具有約束力(除非計算
和傳遞中發生明顯錯誤)。
4.02承诺费
从本协定签署之日后六十一天起至贷款承诺终止或全部提完
日为止，借款人应根据已经承诺但尚未提取的每日余额，以百分
之零点一二五(0. 125%%)的年率向亚行支付承诺费。从一九九四
年六月二十日第一个付息日开始，每年在本协定的签字周年日计
收一次到期的承诺费。如果该周年日不是营业日，那么应在下一
个营业日付出承诺费。
4.03管理费
借款人应向亚行支付管理费，再由亚行通过代理行转付给商

业银行。管理费的计付金额和支付时间应按照换文的规定办理，
4.04利息和承诺费的计算
本贷款的利息和承诺费，应以每年三百六十天为基础，根据
实际所发生的天数计算。在计算某计息期的天数时，应当包括该
期的第一天和最后一天。为避免含糊不清，对同一天不得计算一
次利息。
4.05代理费
借款人应向亚行支付代理费，再由亚行转付代理行。代理费
的應付金額和支付時間應按照換文的規定辦理。
4.06杂费
由于商业银行参加贷款而需要审阅、谈判并履行本协定及其
他有關協議和文件,無給是否已經按本協定提款,借款人都應按
照要求立即向亚行支付所有合理的零星开支,由亚行转贷代理行。
合理的零星开支包括律师费、本协定及有关文件的签字费，总额
不超過二萬(2万)美元。代理行应当证实,這些費用是代理行和
其他商業銀行已經發生的費用,否則,報銷這些開支時須附有代
理行出具的綜合帳單。
4. 07 ”税务执行费用
(a)对任何放款保留准备金或特别存款所发生的费用,和其他
任何遵守与放款有关的、或影响放款(或包括放款的任何部分)的
法律、條例或條件,或有關任何與提供資金或保留放款的,包括
已经颁布、修改、解释或在本协定生效后实施的虽不具有法律效
力，但商业银行应遵守的准备金或特别存款规定和任何政府的命
令、方針或政策所發生的費用;如果该商业银行向亚行提交能说
明该费用的性质和金额确定依据的文件，送达借款人，该确定对
借款人有約束力;借款人应按亚行根据该商业银行的要求偿付给
作为商业银行代表的亚行。
(b)如借款人被要求按本協議第4. 09款(a)支付，借称人
在提前五個營業日通知亞行的前提下,在某付息日或按本協定第:

4. 10款有关商业银行同意的其他日子,向有关商业银行提前偿还
該行的全部放款。
4.08提前還款的成本
如借款人按本协定第6. 01款提前偿还全部贷款;或根据第
4. 07 (b)款提前偿还商业银行已经放款但未偿还部分的款项借
款人应还连同提前还款日所累计发生的利息(在6. 01款的情况
下，接借款替代利率计算)和其他欠該商業銀行的所有款項,以
及补偿该商业银行合理成本的额外款项,和在第6. 01款的情况下
