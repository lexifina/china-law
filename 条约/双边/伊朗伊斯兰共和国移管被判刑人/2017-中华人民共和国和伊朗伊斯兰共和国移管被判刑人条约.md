# 中华人民共和国和伊朗伊斯兰共和国移管被判刑人条约

中華人民共和國和伊朗伊斯蘭共和國
关于移管被判刑人的条约
中華人民共和國和伊朗伊斯蘭共和國(以下簡稱“雙方和,
在相五尊重主權和平等互利的基礎上,為加強兩國在刑事司法領
域的合作,使被判刑人得以在其國籍國服刑,以有利於被判刑人
重返社會,議定下列各條:
第一条”定义
在本條約中:
(一)》“移交方”系指可能或者已經將被判刑人移管出其境
內的一方;
(二) “接收方”系指可能或者已經將被判刑人接收到其境
內的一方;
三)“被判刑人”系指在移交方被法院判处监禁刑罚的人。
第二条”一般规定
根据本条约的规定，一方可以向另一方移管被判刑人，以便
在接收方境内执行移交方对该人所判处的刑罚。

三、一方如果要更其指定的中央机关，应当通过外交途笃书

第四条移管的條件
一、只有符合下列條件,方可移管被判刑人:
《一)被判刑人是接收方的国民，
(二)对和补判刑人判处刑罚所针对的行为根据接收方的法和
也构成犯罪;
(三)对被判刑人判处刑罚的判决已经发生法律效力，且
存在进一步上诉的可能;
(四)在接到移管请求时，被判刑人还需服刑至少一年
(五)被判刑人书面同意移管，或者任何一方鉴于该人的年
冷、喘体或精神状况认为有必要时，经被判刑人的合法代理人刷
面同意移管;

(六)双方均同意移管。
二、在例外情况下，即使被判刑人尚需慑刑的期限少于本条
第一款第(四)項規定的期限,雙方也可以同意移管。
第五条移管的决定
一、一方认为移管有损其主权、安全、会去秩序或者违反本
国法律的基本原则，则可以拒绝移管被判刑人。
一、除本條第一款規定外,任何一方均可自主決定是否同意
吃一方提出的移管請求。
第六条”请求与答复
一、被判刑人可依據本條約向任何一方提出移管申請。收到
被判刑人移管申請的一方應將該申請書面告知另一方。
二、任何一方均可提出移管請求。被請求方應當將其是否
意移管请求的决定尽快通知请求方。
三、移官的请求与答复均应采取书面形式，并通过本条约第
三祭第一款規定的途徑遞交。

第七条所需文件
一、如有移管请求，除非被请求方已表示不同意移管，移交
方應當向接收方提供下列文件或說明:
(一)》如可行,被判刑人的身份信息與證明被判刑人國籍的
女件,
(二)經證明無誤的判決書副本,包括判决所依据的事实与
法律條文;
(三)》關於刑暫的種類、刑期及其起算日期的說明,;
四)关于被判刑人的服刑表现、已服刑期和剩余刑期的说
明,包括审判前靶押的时间、减刑和其他有关刑凡执行事项的说
明;
(五)关于本条约第四条第一至第〈五》项所提及的同意移
管的书面声明;
(六)关于被判刑人身体及精神健康状况的说明。
二、接收方應當向移交方提供下列文件或說明:
(一)證明被判刑人是接收方國民的文件;
(二)對被判刑人判處刑罰所針對的行為,根據接收方法律
也構成犯罪的法律條文;
(三)接收方根据本国法律执行移交方所判处刑六的有关程
序的信息。

第八条通知被判刑人
一、双方应当在各自境内遂知本条约适用范围内的被判
人,其可以根據本條約的規定被移管。
一、双方应当将移交方或者接收方根据本条约第五条和第7
条就移管请求所采取的措施或者所作出的决定,书面通知在其
内的有关被判刑人。
第九条被判刑人同意及其核实
一、移交方應當確保被判刑人或者其合法代理人在完全知曉
移管的法律后果的情况下自愿表示同意移管,並由其在同意移管
的声明中对此予以确认。
二、经接收方请求，移交方应当提供机会，使接收方通过指
定的官员核实被判刑人已按前款规定的条件表示同意。
第十条移交被判刑人
雙方如果就移管達成一致,應當通過本條約第三條第一款規
定的途徑協商確定移交被判刑人的時間、地點和方式。

第十一条”继续执行刑罚
一、在接收被判刑人后，接收方应按照移交方确定的刑罚性
质和期限继续执行刑罚。
一、如果移交方所確定的刑怕性質或期限不符合接收方的法
律,接收方可以将该刑罚调整为本国法律对同类犯罪规定的相应
刑大。调整刑寻时:
(一)接收方应当受移交方判决中关于事实认定的约束;接
收方不得将剥夺目由的刑习调整为财产刑:
二)调整后的州六应当尽可能与移交方所判处的刑罚相盖
斑;
(三)调整后的刑罚在性质上或刑期上不得重于移交方所判
處的刑罰,也不得超過接收方法律對同類犯罪所適用的最高弄
期;
四)调整后的剂杰不受接收方法律对同闫犯罪押适用的最
低刑的约束;
(五)應當扣除被判刑人在移交方境內已經被羈押的期間。
三、移管后，刑如的继续执行适用接收方的法律和程序，包
括对被判刑人减刑、假释或采取其他刑阐执行中的有关措施。

第十二条管轄權的保留
一、移交方保留对其法院所作定罪和量刑进行变更或撤销的
管辖权。
二、在被告知由移交方法院根据本条作出的任何变更或撤销
對被判刑人的定罪和量刑決定後,接收方应当立即变更或终止弄
局的執行。
第十三条”赦免
任何一方均可以根据本国法律对已被移管的被判刑人给予
赦免,並應當及時將赦免決定通過本條約第三條第一款規定的途
径通知另一方。
第十四条”通报执行信息
有下列情形之一的,接收方应当及时癌移区方提供有头执行
刑訂的信息:
(一)刑罚已经执行完毕;
(二)被判刑人在刑罚执行完毕前逃脱或者死亡;
(三)移交方要求提供特别说明。

第十五条被判刑人过境
如果任何一方將被判刑人移管至其境外或從其境外移管被
判刑人,另一方應遵照其國內法給予合作,為該被判刑人過境提
供便利。擱實施移管的一方應就此過境抵前通知另一方,除非折
使用航空运输且未计划在另一方降落。
第十六条”联系语言
为本条约之目的，双方应当使用各自的官方语言进行联系，
并附有男一方官方语言或英语的译文。
第十七条”免除认证
為本條約之目的,由双方主管机关制作并通过本条约第三条
第一亚规定途径递交的文件，经一方主管机关签名或者盖章，即
可以在另一方境內使用,無須認證。
第十八条”费用
一、接收方应当承担以下费用，

(一)移官被判刑人的費用,但完全在移交方境內發生的費
用除外,;
二)移管后继续执行刑罚的费用。
二、接收方可以向被判刑人追偿全部或部分费用。
第十九条”争议的解决
因本条约的解释、适用或执行产生的争议，如果双方中央机
关不能目行协议解决，应当通过外交途径解决

二、本條約可以經雙方書面協議隨時予以修訂。修订应根据

三、任何一方可以随时通过外区途径，以书面形式通知另二

四、本條約適用於生效後提出的任何移管請求,即使請求涉
