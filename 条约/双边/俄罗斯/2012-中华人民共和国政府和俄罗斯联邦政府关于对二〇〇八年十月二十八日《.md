# 中华人民共和国政府和俄罗斯联邦政府关于对二〇〇八年十月二十八日《...

中华人民共和国政府和俄罗斯联邦政府
关于对二OO八年十月二十八日
《中华人民共和国政府和俄罗斯联邦政府
关于共同建设、使用、管理和维护
中华人民共和国黑龙江省同江市一
俄罗斯联邦狐太目治州下列字斯冰耶
居民点区域内黑龙江〈阿稳尔河)
铁路界河桥协定》的修订议定书
根据二OO人和八年十月二十八日签订的《中华人民共
和國政府和俄多斯聯邦政府關於共同建設、使用、管理
和維擴中生人民共和國黑龍江省同江市一俄咕斯聯邦狡
太目治州下列宁斯阔耶居民点区域内黑龙江(阿穆尔河)
铁路界河桥协定》(以下简称“协定”)第十四條規定,
中华人民共和国政府和俄罗斯联邦政府(以下称“双方” )
达成协议如下:
第一条
一、协定第四条表述为:

“第四条
一、主桥共同建设。双方各自承担的界河桥建设、
使用、管理和维护责任的界限为中俄国界线。
二、建设界河桥，不应改变界河黑龙江(阿穆尔河)
的水流流向、河床、主航道、岸线和中俄国界线走向，
不應影響船只航行安全,不應破坏該地區生態及其他方
面的安全,。
三、各自一方对界河桥的所有权的分界线为中俄国
赤線,?”
二、第六条第一款第二段表述为:
“由本协定第二条规定的各自一方机构各自承担对
铁路桥在已方建设、使用、管理和维护责任界限内进行
蔷测、设计和建设的全部费用。”
第二条
本議定書自答字之日起生效,在協定有效期內有效,
本議定書於二0一二年四月二十八日在莫斯科答

订，一式兩份,每份均用中文和俄文寫成,兩種文本同
等作准，
