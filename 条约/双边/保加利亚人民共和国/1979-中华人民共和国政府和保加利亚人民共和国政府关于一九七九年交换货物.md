# 中华人民共和国政府和保加利亚人民共和国政府关于一九七九年交换货物...

中华人民共和国政府和
保加利亚人民共和国政府
关于一九七九年交换员物和付款协定
中華人民共和國政府和保加利亞人民共和國政府,為發展丁
國間的貿易關係,互相協助兩國的經濟建設,。以加強兩國間的友
好合作,現締結本協定,條文如下,
第一条
中華人民共和國和保加利亞人民共和國間的貨物交換都應按
照本協定所附的中華人民共和國一九七九年向保加利亞人民共和
國出口貨物總表和保加利亞人民共和國一九七九年向中華人民共
和國出口貨物總表辦理。
上述兩個貨物總表為本協定的組成部分。雙方應保證完成上
述货物总表所列货物的供给。|
第二条
本協定第一條所規定的貨物交換和同貨物交換有關的各種事
項,都應根據中、保兩國對外貿易機構一九五七年一月二十八日
签订的并且经过一九六二年三月三十日修改的交货共同条件议定
書和一九七九年的合同辦理。
上述合同应在本协定签字后三个月内签订。
第三条
本协定第一条所规定的货物总表，经双方同意，可以变更。
双方并同意，本协定货物总表未列入的商品，也可以根据需要和
可能相互交换。

第四条
依照本协定所供应的货物价格以瑞士法郎计价。
根据本协定所供应的商品，以国际市场价格为基础，按照平
等互利原則,由兩國對外貿易機構協商確定。
第五条.
依照本协定所供应货物的价款、垫付运费、保险费、劳务费
和双方同意的其他费用的支付和清算，在中国方面由中国银行、
在保加利亚方面由保加利亚对外贸易银行,以记帐结汇办法办理。
為此目的,雙方銀行應相互開立無息無費瑞士法郎帳戶,称為“一
九七九年清算帳戶”。
任何一方银行在接到付款通知后，不论对方银行帐户内有无
存款，应立即照付。关于付款的具体办法，按照兩國對外貿易機
构的交货共同条件办理。交货共同条件议定书中未规定的详细手
续，在中国银行和保加利亚对外贸易银行间的清算协定内规定。
本协定有效期满后，上述双方银行对于未履行本协定在本协
定有效期内所订合同的付款，仍应继续办理。
第六条
本协定所规定的货物交换和付款的最后结算日期，为一九七
九年十二月三十一日。双方银行至迟须在一九八口年二月底以前
将最后结算差额核对一致，并自动转入一九八口年清算帐户，在
該年度進出口貿易額內予以平衡。
第七条
根据本协定签订的合同，至一九八口年三月一日失效。合同
失效前的货款，自一九八口年一月一日起自动转入一九八口年幅
戶。未腦行的合同,如經雙方對外貿易機構同意,可以繼續交和貨,
作为一九八口年的订货处理。
第八条

本协定有效期限自一九七九年一月一日起至一九七九年十二
月三十一日终止。
本協定於一九七九年一月八日在北京簽訂,共兩份,每份都
用中、保兩種文字寫威,兩種文本具有同等效力。
