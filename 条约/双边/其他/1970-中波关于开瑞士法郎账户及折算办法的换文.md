# 中波关于开瑞士法郎账户及折算办法的换文

中波关于开瑞士法即账户
及折算办法的换文
我方去文
波蘭人民共和國政府貿易代表轉
可和伏的德葛稚夫斯基团长:
茲宋辛確認,中華人民共和國政府和波蘭人民共和國政府在商
誠一九七0年貨物交換和付款協定時,雙方達成協議如下:
一、一九七0年內應調整有色金屬的價格。兩國外貿機構以現
行世界市场价格为基础商定有色金属的价格。
二、一九七口年以户布签订的合同将按下列金平价折成瑞士
法即:
100卢布三485.86941瑞士法郎。
如瑞士法郎或盧布的含金量發生變化,則雙方在變化日的相互
俩务将相应折算,以便任何一方都不受到损失。
目一九七0年九月一日起,雙方外貿機構的所有結算單據均用
瑞士法度編制。
三、根据一九六三年二月八日在布拉格签订的“非贸易支付清
算协议”确定的一九七〇年非贸易支付账户差额也将按上述卢布对
瑞士法即的金平价折成瑞士法郎。
請接受我深切的破意。
中華人民共和國對外貿易部副部長
李强
(簽字)》
一九七0年七月二日於北京
