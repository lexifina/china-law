# 中华人民共和国地质部长和德意志联邦共和国研究技术部长关于在中国东...

中華人民共和國地質部長和
德意志聯邦共和國研究技術部長
关于在中国东海西部利用同位素
地球化学方法合作寻找碳氧化合物的议定书
中华人民共和国地质部长和德意志联邦共和国研究技术部长
根据一九七八年十月九日的“中华人民共和国政府和德意志
联邦共和国政府科学技术合作协定”，
一九七九年十一月二十日的“中華人民共和國國家科學技術
委员会主任和德意志联邦共和国研究技术部长关于原料和材料研
究合作的议定书”
以及一九七九年六月十九日的“中华人民共和国国家地质总
局与德意志联邦共和国经济部长关于开展地质科学技术合作的协
议”;
考虑到碳氧化合物的供给在一个国家经济发展中的重大意
义;
“認識到先進技術可更合理更經濟地找到和開發石油與天然
气;
為了加強地學領域內的合作和增進兩國地學工作者之間的相
互了解和友誼,達成協議如下:
第一条
中華人民共和國地質部長〈以下简称中方)和德意志联邦共
和國研究技術部長〈以下简称德方)在中國東海西部溫州附近海

域利用同位素地球化学方法合作寻找石油与天然气。
調查區的四角座標為:
東經12236/,北緯28 10/ ;
東經123 36/,北纬28"10/;
東經122 40/,北纬26"00/ ;
東經121740/,北纬26"30'。
上述地区的面积约为二万二千平方公里。
第二条
通過合作達到下列目的:
一、在中國東海西部溫州附近海域開展同位素地球化學工
作，寻找石油与天然气;
二、在联邦地学与原料研究院对取自普查区附近与生油有关
地区的样品共同进行同位素地球化学、地球化学与煤岩学的研
究,
三、用现有的或尚需实施的地震方法来解译地球化学资料;
四、协助中方培训和深造同位素地球化学专家。
第三条
双方共同完成下列任务;
一、开展8公里x 8公里取样密度的同位素地球化学普查;
二、在有利部位开展取样密度为4公里x 4公里的同位素地
球化學調查,
三、在合作区或其附近打一普查钼，对钻并中取得的样品进
行地球化學和同位素地球化學的研究,
四、在中華人民共和國建立一個用C 13/ C 12分析碳氧化合
物的陸地實驗室,
五、制定一套解释和绘制测量资料的数据处理程序;
六、在异常区可根据地质和地震资料改变取样密度。

工作结束后，双方在另行谈判的基础上，就详查与初勘工作
和扩大近海调查区签订一项新的协议。
第四条
雙方合作的方式為:
一x在中國東海西部溫州附近海域應用德方多年研究工作中
发展的同位素地球化学新方法。当调查区具备详细勘探和开发条
件并在此地区进行国际招标时，中方将向主管部门推荐，使德国
公司能够参加投标。
二、在中国东海西部温州附近海域进行近海作业时，以中方
為主,德國專家參加工作,
在聯邦地學與原料研究院進行實驗研究分析時,以德方為
主,中國專家參加工作,
对合作期间获得的数据资料进行解释评价以及建立、调试和
使用陆地实验室时平等地合作。
“第五条
雙方代表原則上每年會晤一次,評價以往的工作,特別是要
制定和批準下年度工作的書面計劃。會晤盡可能輪流在中華人民
共和國和德意志聯邦共和國舉行。
双方代表的会晤须根据一方的愿望在六十天内举行。
第一次会晤定于一九八口年在德意志联邦共和国举行。
第六条
中方委托海洋地质调查局、德方委托联邦地学与原料研究院
执行本合作项目〈项目承担者)。
項目承擔者在合作項目的所有階段密切合作,共同使用中方
獲得的與執行項目有關的地質、岩石和地球物理資料。
項目承擔者用中文和德文為按照第五條舉行的年度會晤向雙
方提交一份共同的報告。

第七条
中方提供下列主要设备，
一、带有定位移动台的调查船一般
二、近海钻探装置。
德方提供下列主要设备;
一、一套先进的船上样品制备和分析系统;
二、在陆地实验室内用C 13/C 12分析气态碳氧化合物和制
备样品所需的主要大型仪器。
第八条
雙方商定,本閉平等互惠原則,分擔費用如下:
、中方承担调查船、船只改装、专业设备及作业的费用;
一一一三
、中方承担打一普查钻孔的费用;
、德方承担由德方提供的专业设备、材料及国际运输费
用;
四、中方承担陆地实验室的房屋、运转和基本设施的费用，
以及双方认为必需的、中方能够提供的较小型仪器的费用
五、业务通讯费用由双方各自负担;
六、执行项目时，派出方负担各自专家的工资和国际旅费。
接待方负担对方专家在本国工作期间的食、宿、交通运输和医疗
费;
七、已發表和未發表的地質岩石和地球物理調查成果以及周
围地区样品材料的费用由中方负担;
八、在德意志联邦共和国化验的样品的运输费用由中方负
担，分析费用由德方负担。
第九条
双方根据本合作项目的目的和任务商定项目期限为三年。本
項目應於一九八0年四月開始執行。

第十条
项目承担者向双方提交下列共同的最终专业报告:
一、中国东海西部温州附近海域石油地球化学普查成果报
只
二、共同感兴趣的其它专业报告。
上述報告用中文和德文寫成。
本項目所有原始資料留存中華人民共和國,德方需要時可以
复制。取得的样品要满足德方化验分析的需要，其余部分由中方
保存。
第十一条
双方对合作范围内交换的情报资料和工作成果报告保密，并
有责任使所有参加此研究项目的单位和人员保密。
中方对项目实施期间所应用的和项目结束以后可供其继续使
用的技術方法保密。只有在征得德方同意的情況下,才能轉讓給
第三國或在中華人民共和國以外使用。
地質成果和中方提供的地質、地球物理資料只有在中方同意
的情況下才能發表或轉告第三國。
第十二条
双方将根据各自国家的有关法律规章尽可能协助参加合作项
目的专家及时获得签证。
第十三条
本議定書按照存在的狀況也適用於柏林(西)。
第十四条
本议定书自签字之日起生效，如双方确认本项目的合作目的
已经达到，则本议定书即行失效。
本议定书于一九七九年十一月二十日在北京签订，一式两
份，每份都用中文和德文写成，两种文本具有同等效力。

德意志联邦共和国
