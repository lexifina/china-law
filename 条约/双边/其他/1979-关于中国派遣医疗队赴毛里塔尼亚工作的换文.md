# 关于中国派遣医疗队赴毛里塔尼亚工作的换文

關於中國派遣醫療隊赴
毛里塔尼亚工作的换文
(一)我方去文
毛里塔尼亞伊斯蘭共和國外交、合作部國際合作司長
艾哈提德‧烏爾德‧梅內亞先生
司長先生:
我并代表中华人民共和国政府确认,我们双方经过友好协商，
達成協議如下:
一、根据毛里塔尼亚伊斯兰共和国政府的要求，中华人民共
和国政府同意将双方于一九七七年四月四日在努瓦克肖特签订的
“中华人民共和国政府和毛里塔尼亚伊斯兰共和国政府关于中国
派遣醫療隊赴毛里塔尼亞工作的議定書”延長一年,即自一九七
九年四月四日起至一九八0年四月三日止,
二、中华人民共和国医疗队工作地点由目前的基法、艾拥、
塞利巴比和内马四个点缩减为三个点,即基法、艾擁和塞利巴比,
撤销内马点。有关撤点工作于一九七九年七月三十一日前完成。
醫療隊人數由上述議定書規定的四十五人,減為三十三人。
以上如蒙复函确认，本函和您的复函即作为上述议定书的组
成部分。
順致崇高的敬意。
中华人民共和国驻毛里塔尼亚
伊斯兰共和国大使馆临时代办

乔贵元
(等字
“一九七九年七月四日
《二)对方来文
代办先生;
您通过一九七九年七月四日他09/79/C E号来函告知我，我
们双方经过友好协商，达成协议如下，
(内容同我方去文，略。一编者)
我说代表毛里塔尼亚政府向您确认并同意上述来函内容。
順致崇高的敬意。
國際合作司長
艾哈提德。鳥爾德‧梅內亞
(签字)
一九七九年七月二十三日
