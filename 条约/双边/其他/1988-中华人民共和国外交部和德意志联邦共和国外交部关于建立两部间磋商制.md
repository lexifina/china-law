# 中华人民共和国外交部和德意志联邦共和国外交部关于建立两部间磋商制...

中华人民共和国外交部和
德意志聯邦共和國外交部關於
建立兩部間磋商制度的議定書
中华人民共和国外交部和德意志联邦共和国外交部〈以下简
稱“雙方? )
一-确认两国在一九上二年十月十一日建立的外交关系的
基础上开始了密切和充满信任的对话，这种对话日益加强并促进
了两国之间的关系;
一一希望今後在各個領域繼續擴大和加深兩國之間的良好合
作，以有利于两国人民的幸福以及世界的和平与稳定;
一一致同意把现有的各层次的密切对话建立在一个牢固的
基础之上。
效此协议如下
第一条
双方将更广泛和深入地就双边关系问题和双方感兴趣的国际
问题进行磋商。
这些磋商有助于
一一加强在各个领域里的双边合作
一一商讨双方对国际政治和经济形势问题的立场;
一一就双方认为值得讨论的任何其他问题交换意见。
第二条
根握本议定书拖一条定期举行各个级别上的磋商，外长或副
外长原则上每年至少会晤一次，具体细节通过外交途径加以
确定。

第三条
本议定书自签字之日起生效。
議定書於一九八八年十月三十一日在北京簽訂,一式兩份?
