# 中华人民共和国卫生部和泰王国卫生部卫生医学科学和药品领域合作谅解...

中華人民共和國衛生部和泰王國衛生部
衛生醫學科學和藥品領域合作諒解僵蕊錄
中華人民共和國衛生部和泰王國衛生部(以下簡稱雙方),認
識到促進和加強兩國間業已存在的友好關係的必要性,同意兩國
在互惠互利的基础上促进卫生医学科学和药品领域的合作，达成
协议如下:
总目标
1本谅解备忘录为详细建议的具体领域的合作项目及经双
方共同考虑的执行计划提供了框架。
合作领域
2双方将同意在下列领域内鼓励、促进和发展合作:
2. 1传染病和流行病的预防
2. 2非传染病(腫瘤、高血壓、心腦血管疾病、糖尿病等)
2. 3传统医学
2.4药品和药用植物的开发
2. 5妇幼卫生
2. 6医疗和护理
2. 7医学和护理教育
2.8生物制品和藥品及醫療部械的開發
2. 9老年医学
2. 10显微外科和烧伤治疗
2. 11保护消费者

2. 12艾滋病防治
2. 13药物滥用的治疗和康复
合作方式
3双方的合作将以下列方式进行:
一一交流科學和醫學信息及最新醫學成就
一一互派卫生和医学专家及考察团;
一一共同實施科研合作計劃,
一一共同举办必要的研讨会和技术会议。
执行
4双方将建立中泰卫生合作联合委员会,以便制定为期两年
的執行計劃及協調執行本諒解備忘錄內的合作活動。聯合委員會
每年将定期开会。
5双方将互相探讨在生物制品.药品和医疗器械的合资和其
他形式的贸易合作的可能性。
6双方同意在世界卫生组织和其他国际组织的活动中进行
合作。
7双方将互派专家进行工作和研究。
费用
8派遣国家将负担其专家往返对方国家首都的国际旅费,接
待国家将负担食宿和当地交通费用。
9根據本諒解備忘錄派出的專家,如在訪問期間患急病或遇
意外事故,接待國家應負責醫療。
協商
10任何一方提出涉及本諒解備忘錄的條款有關事宣,雙方

将本着相互信任和合作精神进行协商并共同努力解决可能出现的
困难和分歧。
修改
11本諒解備忘錄的任何修正和更改必須經合作雙方相互
同意。
生效
12本谅解备忘录自签字之日起生效，有效期为五年。如任
何一方在備忘錄期滿前六個月未以書面形式通知另一方終止本諒
解備互錄,則本諒解備互錄將自動延長五年,並依此方法順延。
謹此證明各自部門授權的簽署人簽署了本諒解備忘錄。
本諒解備忘錄於1997年5月29日在北京签署,一式两份,每
份均用中文、泰文和英文寫成,三種文本同等作準,。
