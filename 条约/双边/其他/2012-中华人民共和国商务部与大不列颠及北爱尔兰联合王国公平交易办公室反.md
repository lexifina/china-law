# 中华人民共和国商务部与大不列颠及北爱尔兰联合王国公平交易办公室反...

中华人民共和国商务部
一
与一
大不列顛及北愛爾蘭聯合王國公平交易辦公室
反奏斷合作諒解盞于錄
前言
中华人民共和国商务部和英国公平交易办公室(以下简称
双方),认识到相互合作在促进各自国家有效运行的市场的价值
和重要性，旧在建立和发展双方在实施竞争法律与政策及相关
事项方面的合作，就以下事宣达成一致:
一、合作宗旨
签署本谅解备忘录的宗冲，是通过建立双边合作的总体杠
架，进一步加强双方之问的合作伙伴关系.
二、合作范轩
双方有关实施竞争法律与政策的合作将集中于执行双方商
定的年度工作计划。每年双方将讨论下一年度工作计划。
工作计划将提出双方拟开展的具体合作方案。在各自国家
法律允许的范围内，双方在以下方面开展合作:
交流与竞争法律与政策相关的信息及立法和执法情况;

交流關於各自國家的競爭法律制度和機樹效能經驗的信
和皿;
分享在解决市场竞争问题和鼓励企业守法方面的最佳做
法、知識和技巧;
此外，双方可共同商定开展合作的项目，
三、磋商
双方商定:
1、举行正式会议评估本谅解备忘录的进展和更新工作计
划。该类会议的时间和地点由双方共同商定。

时间、人员等资源方面抽有相应义务，

访问方自行承担其国际旅费、城市交通费和食宿费等

五、保密条款
双方一致认为，如果被交流的信息被相关法律所禁止或与
一方的利益相冲突，一方有权拒绝对方提出的交流信息请求.
在遵守相關法律要求的情況下,除非事先得到對方同意,
任何一方都將為依據本諒解備忘錄獲取的信息保密,

_有关本谅解备忘录解释或者适用上存在的分此或产生的争

八、其他规定
本谅解备忘录自签署之日起生效，有效期为两年，并可下
长至双方共同商定的期限。
任何一方均有权终止本谅解备忘录，但有义务在作出终止
决定30日之前书面通知另一方。
本谅解备忘录于二零一二年四月十七日在伦敦签署，一忒
两份，每份文本都用中文和英文写成，两种文本同等作准.
