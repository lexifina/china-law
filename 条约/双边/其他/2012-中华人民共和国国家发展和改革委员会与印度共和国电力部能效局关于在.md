# 中华人民共和国国家发展和改革委员会与印度共和国电力部能效局关于在...

中华人民共和国国家发展和改革委员会
說
印度共和國電力部能效局
關於在能效領域加強合作的諒解備忘錄
本备忘录由中华人民共和国国家发展和改革委员会和
印度共和国电力部共同签署，本备忘录中，中国国家发展和
改革委員會和印度電力部簡稱為“雙方>:
在在中印戰略經濟對話的框架機制(以下简称SED )
下,進一步提高能效領域的中印合作,國
认识到提高能效双边合作以及减少温室气体排放符合
双方共同利益，
共同承诺通过开展相关项目和活动，提高能效，减少温
室气体排放。
双方就以下内容达成共识:
加宗旨
双方一致同意进一步在能效领域加强合作，此类合作将
實現雙方互利。本備忘錄旨在為雙方能效部門開展合作設定
基本路線、合作方式和主要原則,

二、合作模式
雙方合作的主要方向是共同開發能效項目,此類項目符
合雙方共同利益,。
合作方式将包括但不仅限于以下活动:能效領域的信
妃、法律和法规交流;共同组织召开主题符合双边利益的专
题会、研讨会等会议;双方相互学习合同能源管理公司开展
能效項目時所私累的經驗,包括行政管理、合規和實現能耗
降低目标等方面的经验;鼓勵對在提高能效方面取得突出成
就的工业和制造业中心进行现场考察;合作、共同開發測試
規泡和標準;交流双方在执行IJSPO50001能源管理体系方面
私累的篤驗;开展培训和交换项目;以及提供技術支持
为深化在能效领域的合作，双方一致同意通过组织研讨
会加强信息交流。研讨会主题包括但不仅限于:基于节能目
标的能效项目的设计和实施;通过金融工具(如部分风险支
持工具和风险投资基金)的设计和实施来提高能效;通过交
多体系的设计和实施来提高能效;执行ISPO50001能源管理
的经验分享。双方一致同意轮流在对方国家举办能效相关主
题研讨会。研讨会主题将通过外交渠道提前商定。
雙方鼓勵對在提高能效方面取得突出成就的工業和制
造業中心進行現場考察,以深化雙方合作。考罕有利於促進
双方相互投资以及技术转让。双方将选定协会或商会组织，

该协会或组织负责拟定承担现场考察的企业名单。双方将与
协会或商会组织进行商讨，提前决定考察地点.
双方一致辐意合作、共同开发能效产品的测试协议和标
准,如发光二极管(LED ),以提高两国固态照明产品的品质、
协调两国相关标准。为深化两国能效标准的合作、节能产品
的认证，推动节能产品双边贸易，印度电力部指定印度标准
局.印度照明工程师协会以及印度能效局作为印度LED标准
协调方;中国国家发展和改革委员会指定中国国家发展和改
草委员会资源节约和环境保护司、国家半导体照明工程研发
及产业联盟和中国标准研究院作为中国LED标准协调方。双
方协调机构将通过拟定有关项目，负责协议和标准的开发，
項目中將明確有關目標和任務,
双方相互交流通过合同能源管理公司实现能耗降低的
目标和开展能效项目时所积累的经验。印度电力部指定印度
能效局，中国国家发展和改革委指定中国国家发展和改革委
员会资源节约和环境保护司、中国节能协会节能服务产业委
员会为开展本项合作的执行机构.
合作项目的实施应遵守本备忘录相关规定.
三、知识产权
双方将根据所有相关文件，各自保有其知识产权和专刊

权，生产权和商标权，本备扎录终止后相关文件或将公布，
经由双方一致认可，相关的文件条款应用商业木语表
述，并列入不同的协议中，包括保密协议和知识产权协议此
类强制性协议，
四、保密协议
雙方應確保,在實施本備忘錄或根據本備忘錄提供服務
時,其工作人員與合作伙伴對與本備忘錄以及備忘錄中涉及
的服务项相关的信息和文件进行严格保密。双方应确保，除
非获得双方中万一方的书面认可，其工作人员与合作伙伴不
会问第三方透露相关的信息和文件.本保密协议将在本备扎
錄終止後三年內有效,
五、执行机构
印度共和国政府指定电力部为本备忘录执行机构，中华
人民共和國政府指定國家發展和改單委為本備忘錄了執行機
构，

开展任何合作项目/活动的成本/费用将根据双方达成的
协定来确定。一旦双方同意合作开展项目，双方将签订子合
同,明確具體合作條款,。
研討會:双方将各自承担参加研讨会所产生的国际差旅
费、会议食宿费和本地交通费。会议主办国将承担会议举办
的國內費用,。
現場考察:雙方將各自承擔進行現場考察所產生的國際
才旅费、会议食宿费和本地交通费。主办国的负责机构将负
责安排考察工作。
七、和争议处理
雙方因理解或實施本備忘錄時所產生的任何爭議應通
过友好协商和磋商予以解决。
八、生效、修改和期限
本備忘錄在雙方授權代表答署後立即生效,有效期5年。
若元任何一方提前2個月修訂或終止本備忘錄,本備忘錄將
順延3年,
雙方在本備忘永下答訂的合同的有效期可超過備忘永
有效期

經雙方一致同意,本備忘錄可進行修訂,
本備忘永於2012年11月26日在新德里簽署,以英語、
中文、印地語三種語言寫成,三種版本具有同等效力。如有
分玻,以英文文本作準,

代表代表
