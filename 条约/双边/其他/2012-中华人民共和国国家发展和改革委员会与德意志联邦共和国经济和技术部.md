# 中华人民共和国国家发展和改革委员会与德意志联邦共和国经济和技术部...

中华人民共和国国家发展和改革委员会
与
德意志聯邦共和國聯邦經濟和技術部
關於在中德經濟技術合作論壇框染下
在能源工作组继续进行合作的谅解备扎系
为促进中德在能源领域的合作，中华人民共和国国家发展和
改革委員會與德意志聯邦共和國聯邦經濟和技術部(以下简称双
方)于2007年在中德经济技术合作论坛框架下设立了能源工作
组。
在过去五年中，双方的合作得到了进一步发展和加强，建立
了富有成效的信息和經驗交流的溝通机制,為雙方深入的合作英
定了坚实的基础。
因此,及方協是在中德經濟技術合作論壇框架下設立的能源
工作组内，继续推进中德两国在能源领域的合作。双方就此达成
如下共识:

(D能源工作组的目的是:
1.在能源政策、能源研究和能源技术方面交流信息和经验;
2.协调能源双边合作事宜;
3.推动两国企业在能源领域进行合作，通过制定和实施共同项
目，支持企业在对方国家开展和从事经营活动。
(2)第一款所述目标的制定旨在改善和扩建可持续能源基础设
施,為兩國經濟和社會的發展提供安全、經濟和環保的能源
供應,
第二条
能源工作组的工作范围包括:
1.能源战略、能源政策和能源法规;
2，币规和可再生能源生产技术(如粘砍、電力、石油、天然
气、太阳能、风能) ;
3.能源輸送和分配;
4，冻及相关议题，包括资源型城市的转型〈产煤城市) ;
5.提高能源效益,特別是建筑兩能領域;

6.能源領域的環境保護;
7，其他双方感兴趣的领域。
第三条
(1)定期(每年一次)在两国轮流召开能源工作组会议。在会议
中,經雙方一致同意確定合作的具体措施和活動,
(2)合作的可能形式舉例如下:
1.政府层面磋商;
2.學習班和研討會;
3.展会和展览
4.学者、专家及企业则的交流;
5.代表團互訪,
(3)能源工作组将定期以书面形式向中德经济技术合作论坛汇报
其活動,
第四條
中方主管部门为中华人民共和国成并国家发展改革委员会，
和餐方主管部门为联邦经济和技术部。中方邀请国家能源局在其职

贡邯围内参与。双方各任命一位主席和一位专家，后者作为组织
事宜方面的联络人。所有活动与措施均应在双方一致同意的情况
下侍诸实施。如无其他协议，双方各自承担目己所发生的费用。
在可再生能源領域,德方將邀請主管該領域的聯那環境、自然保
护和核反应推安全部参与。必要时双方可以邀请其他机构和企业
人参与。
第五条
双方实施的措施和开展的活动须遵循各目国冢现行法律、规
定及国际法规定的各项义务。双方均支持对知识产权的有效保
护。
如双方对本谅解备扎录的解释或适用产生分疏，双方将通过
协商加以解决
第七條

(1 )本访解备扎系上自人签字之日起适用，适用期为五(5 )年,
(2 )本護解備忘銷五(5 )年到期后将自动延长五(5)年。
(3 )雖然本諒解備忘錄將自烈延長,雙方仍可在任何時候以書
面形式通知對方終止本諒解備忘錄泥圍內的合作;但通知应
在本諒解備忘永預計的終止之日前九十(90)天內送達。已
经开始和正在实施的项目应不受其影响。
(4 )本護解備忘錄任何時候均可經雙方一致同意進行書面修
改。修改后的文本生殖日期应予以书面注明。
