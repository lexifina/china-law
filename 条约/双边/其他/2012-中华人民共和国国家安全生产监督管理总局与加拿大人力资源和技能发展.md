# 中华人民共和国国家安全生产监督管理总局与加拿大人力资源和技能发展...

中华人民共和国国家安全生产监督管理总局
与加拿大人力资源和技能发展部/劳工部
關於在安全生產與職業健康領域開展合作的諒解備妃錄
中华人民共和国国家安全生产监督管理总局与加拿大人
力資源和技能發展部/勞工部(以下简称“双方)认识到两国
在安全生产与职业健康领域开展合作的重要性,本着继续加强
在安全生产和职业健康领域合作的愿望，达成以下谅解备忘
錄:
一、总体目标
双方通过加强在安全生产与职业健康领域的交流与合作，
分享成功經驗和做法,不斷完善安全與健康管理体系,改善工
作場所,保護勞動者的安全與健康,
二、合作內容
双方可就以下方面开展合作:
1、安全与健康法规制度建设与完善
2、安全与健康监察执法机制和实践
3、促進預防性安全與健康文化建設;
4、安全与健康监管监察人员的录用与培训;
5、安全与健康绩效考核;
6、隐患治理与事故预防.

三、合作方式
1、双方可通过以下方式开展合作:
(1 )合作開展短期研究
(2)共同组织召开研讨会
(3)研究成果和信息交流
(4)专家和高层官员互访
(5 )双方认可的其它方式
2、本谅解备忘录项下的所有活动将由中国国家安全生产
监督管理总局国际合作司与加拿大人力资源和技能发展部/芝
工部国际与政府问劳动事务司共同协调。双方可指定各自部站
内的相关单位或机构参与此谅解备忘录下的合作.
3、雙方可根據需要,。邀請工人、鹿主、非政府組織代表
及大学和研究机构的专家参与本谅解备忘录下的合作。
四、时间表和管理安排
1、根据资金情况和需要，双方将制订一份时间表和工作
计划，并定期对其进行修订，
2、双方将各自承担其参加本谅解备忘录项下活动的费用。
3、关于互访，派出方将支付其团组在外发生的费用，如
住宿强和其它杂费.派出方需确保其代表在发生事故或患病的
情况下有适当的医疗和紧急旅行保险，
五、解释和适用异议
双方将通过协商解决本谅解备忘录解释和适用方面存在

的任何措议。
六、生效和有效期
1、本諒解備忘錄自答字之日起生效,有效期五年,
2、经双方书面同意，可对本这解备扎隶进行修订。
3、任何一方以書面通知對方即可終止本諒解備忘錄。
本諒解備忘錄於二O一二年四月十八日在北京銓署,一式
兩份,每份以中文、英文和法文寫成,三種文本同等作準,。
