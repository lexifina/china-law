# 中华人民共和国国家工商行政管理总局和巴西联邦共和国经济保护行政委...

中华人民共和国国家工商行政管理总局和
巴西联邦共和国经济保护行政委员会
关于竞争领域的合作谅解备忘录
前言
中华人民共和国国家工商行政管理总局和巴西联邦共和
国经济保护行政委员会(以下称“双方” )
考上點到1982年俭丰的《中华人民共和国政府和巴西联邦
共和国政府科学技术合作协定》，
希望发展和加强竞争法律和政策领域的合作，
旨在为双这关系发展创造有利条件，
根据平等互利原则，
這成以下謀解:
第一条.目的
本護解備忘薄旨在通過交流信息和最佳實蹣、開展能力
建設活動,促進和加強雙方間制度性合作關係。

第二条“合作领域
为体现双方共同关注，将在以下方面开展竞争领域的合
作:
(一)在各自国家法律允许的范围内，交流竞争领域的
政策、法律法规、典型案例以及立法、执法进展情况.
信息交流可以邮件或电子邮件的方式进行，语言为英
文,
(二)在资金允许范围内组织研讨会和学习访问，为处
理競爭案件的官員提供專業培訓.
(三)参加在中国和巴西举办的涉及竞争立法执法议题
的国际会议、研讨会和其他活动。
(四)组织双方高级官员会唔和工作层面的人员互访，
探讨双方共同关心的竞争领域问题，
(五)双方约定的其他事项，
第三条磋商與協調
双方同意:
(一)双方指定联络部门，以确保部门间的充分沟通。

实施本诬解备斥系框架内的行动。
(三)双方每年定期举行会隔，审议本备扎系执行情
况。会晤应由双方机构轮流主办，时间由双方协商确定。
第四条限制条天
(一)文方人員實施本諒解備忘錄框染內的公務活動時
所产生的费用，包括旅行费用，由双方各自承担。
(二)本護解備忘永框潑內的所有活動均取次於經紙情
况和各方预算安排。
(三)本謀解備軋錄不要求雙方同發生次金往來,

第五条信息傈密条天
(一)如被本国信息使用相关法律所茶止，或信息的区
流有俘目身利益,一方將不向咆一方提供信息。
(二)雇方均應依各自國家法律,對叻一方按照本協議
所提供的信息予以保密。經雙方協商一致可以公開的信息,
不受本协议保密规定的约束。
第六条争议解决
双方应通过友好协商的方式，解决本备忘录在解释和执
行方面产生的分歧。
第七条修订
经双方同意，可以对本谎解备乓和孙进行修订。修订将在
双方收到对方正式书面确认后生效。
第八条生效和终止
(一)本謀解備忘永自簽字之日起生效,
(二)本護解備忘永有效期三年,此后每年自動延期,
除非任何一方提前三十天以書面形式通知另一方終止本諒解
備忘永。

(三)本访解备扎系于二〇一二年九月十三日在巴西刊
亞簽訂,一式三份,每份均以中文、葡萄牙文和英文舉成,
三種文本同等作準。恕在解釋本誣解備蕊未時發生分戒,以
英文文本为准。
