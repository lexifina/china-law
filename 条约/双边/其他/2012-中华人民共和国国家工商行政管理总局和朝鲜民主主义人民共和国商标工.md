# 中华人民共和国国家工商行政管理总局和朝鲜民主主义人民共和国商标工...

中华人民共和国国家工商行政管理总局和
绷鲜民主主义人民共和国商标工业设计地理标志局
合作諒解備忘錄
中华人民共和国国家工商行政管理总局〈以下简称为“中国
国家工商总局”)和萌魚民主主八人民共和國商標、工業設計、地
理标志局〈以下简称为“再鲜商标局” ) (以下称为“双方> )
考卡到双方在商标、地理标志注册和保护，以及广告监管领
域拥有相似职责，
认识到完善和强化各自国家商标、地理标志和广告监管体系
的必要性，
期待通过信息交流和共同开展能力建设活动，进一步加强双
方合作,
南成諒解如下:
第一條合作目的
本谅解备忘录的目的在于双方建立一个双方合作的基本杠
架。本谅解备忘录框架内拟开展的活动旨在通过交流信息和最佳
实践以及开展能力建设活动，改善双方知识产权保护、加强广告
监管并提高效率，同

第二条合作领域
(一)奖流相关法律、法规、技术资料和期刊。信息交流将
使用英文，通过邮件或电子邮件方式，或者在双方代表会晤时进
行.
(二)組紀高居會議或坊回,審議本諒解備忘錄執行情況,
讨论双方合作继续发展的远景和意疝。
(三)组织开展工作质人员互访，探讨双方共同关心的技术
性问题。
(四)組織開護能力建設活動,如培訓、座談會、研討會和
学习访问。
(五)双方同意的其他事宜。
第三条协商
双方同意:
(一)双方将通过协商确定每年在本这解备扎录第二条所列
合作領域內開展的具体活動,包括活動議題、日期、地點,以及
經費等其他事項.
(二)各目揪足联络部门，负责本衣解备扎系的协调和实施，

第四条限制条姑
(一)本諒解備忘錄下所有活動的開展,艾應章守各自國家
的法律、法规.
(二)本諒解備忘錄不侵犯或影響雙方在各目參加的國際協
定中的权利和义务.
(三)本諒解備忘錄的所有有承詳均取決於經紙情況和各方預
算安排。除非經另行協商,雙方將承擔各自的旅行和食宿費用,
(四)本諒解備忘錄在經費方面不具約束力。
第五条保密條束
如被本國信息使用相關法律所禁止,或信息的交流有侶自身

利益，一方将不向另一方提供信息。
雙方艾應遵守本國相關法律要求,並且除非經雙方協商一致,
對吃一方按照本諒解備忘錄所提供的信息予以保密,。
第六條爭議解決
双方应通过友好协商的方式，解决本谅解备忘录在解释和执
行方面產生的分歧.
第七条修订
经双方节面同意，本谅解备扎隶可随时修订。
第八条”生效
本謀解備忘床自答字之日起生效,有效期三年。除非任何一
方盡前九十天以書面形式通知另一方終止本諒解備忘錄,本諒解
和備忘錄的有效期將自動延長三年。
第九条实施计划
為實施本謀解備忘錄,雙方將每年進行磋商並制定實施計劃。
第十條實施
双方保证按照合作、互惠的原则，患实执行本谅解备忘录，
