# 中华人民共和国水利部和匈牙利地方发展部在水资源领域合作谅解备忘录

中華人民共和國水利部
和
匈牙利地方家展部
在水資源領域合作諒解會忘錄
中人華人民共和國水利部和匈牙利地方發展部(以下噶獨攬及時尚稱
方”,同時提及時簡稱“雙方”)
認識到自2003年答著《中華人民共和國水利部與二牙利共和因柬境水
利部合作諒解備忘未》仿以來,雙方在水資源領域廈展的濕有成效的交流與台
作,以及未來在水資源利用和司持續管理方面所面臨的共器挑戰:
愿意在平等、互利和相互尊重的基础上，进一步贷进中匈两国在水资源
管理领域的合作与交流:
相信在双边水利技术、管理和经济合作方面存在巨大潜力:
深信此合作有利于实现两国共同利益，并能为优进两国人民在本资源各
理和经济社会领域的发展做出页献;

律上的约束，不影响双方基于其他条约、协定和地区性协议的权力和叉务.

6、交换有关国际招标项目的信息，鼓励两国的水利企业合作素拒水到
其目;
7、由双方协商确定的其他合作形式.

第五条財務安排
双方将各自承担所派出代表团的国际旅费、当地食宿费用工资和出过
期间的每日生活津贴。一方激请另一方专家提供技术服务，沂请方将承担所
发生的所有费用,除非能从第三方得到资助，商业和技术合作项目的资金未
源将根据具体情况由双方协商确定，
第六条保密和知识产权保护

定,遭箱雙方各自國家關於知識產權的法律法規及雙方共同按有的其他固險
协议，
