# 中华人民共和国环境保护部与意大利环境、领土与海洋部绿色经济行动计...

中华人氏共和国环境保护部
意大利环境、领土与海洋部
絲色經濟行動計劃
中年人民共和國環境保擴部與意大利環境領土與海洋部(以
下稱“雙方”)
在2012年3月意大利環境、領十與海洋部部長訪問中國時,
一致认同绿色经济对发展中国家和发达国家提高人民生活水平和
促进社会平等方面共有重要意义;
回顾双方于2012年3月16日簽署的環境保護及可持續發展
合作諒解備忘銷(以下稱“諒解備忘銷? )
为实现访解备扎系中确定的目标，并进一步优进未来中意两
國的環境合作;
同意采取恕下行動:
1.建立绿色经济联合平台
根据谅解备忘录第三条，双方将建立一个平台，用于共享信
息、經驗,以及國內、雙由、多由項目和國際成功案例中總結出
的最佳做法,

建立該平台的目的是為決策制定者及專家在制定政策、措施、
技術路線圖及示沁項目計劃時提供知識基礎,以促議組色經濟軸
型並減少環境及生念風險,。
重誠領域將包括:
1)綠色經濟,包括:绿色职业;能源獲取、效率及可持續
性;粮食安全及可持续农业;可持續城市;上自然或工業災害預防
及提高应对能力;路领域的优先重点。
2)水斷合管理,包括:水政策研究;水保护技术开发;流
域综合管理;污染防治;饮用水安全;環境風險評估及管理,
3)土壤、地下水及污染场地清理，包括:污染场地管理最
佳做法;土壤及地下水修复拆术;應急管理;修复责任及资金投
入;城市规划及发展整合.
其它双方认可的夫同关心的领域.
双方还将建立并优进同其它相关国家及国际组织的协同合
作。
双方同意在该联合平合下加强同中国环境与发展国际合作委
员会的合作，通过各种适合的方式共享研究成果。
在签署本行动计划后3個月內,雙方將成立中意工作小組,
负贡制定与联合平台建立相关的工作计划。
2.同其它发展中国家开展合作
根据访解备所系第四条，双方将与由双方共同确认的发展中

国一起在如下领域开展合作:
-环境公约履约，包括但不限于蒙特利尔议定书，斯德哥尔
摩公約及生物多樣性公約;
-水環境及水資源可持續綜合管理;
-可持續城市發展,包括清洁交通,空气污染監測及控制,
可持續城市規劃及生念建氣,鹿物綜合管理;
-能源效率及清洁能源開發
-生物多样性保护
-环境监测及管理
-环境影响评价;
-气候变化;
-其它共同认可的领域.
双方同其它发展中国家的合作可通过如下方式进行:
-双方联合举办研讨会，交流会或其它会议等，以促进与其
它发展中国家的经验交流;
-双方癌其它发展中国家派遣联合代表团;
-在其它发展中国家开展项目;
-开展符合其它发展中国家需求的培训项目:
-其它共同認可的方式,
在從著本行動計劃後3个月内，双方将共同制定一份工作建
议书，并确定一个发展中国家为合作伙伴.

3.宣传中意环保合作项目
为进一步宣传中意环保合作项目的成果及产出，以优进最佳
做法及成功淋例在中國及其它發展中國家的推廣和應用,雙方將
举办特别联合会议及研讨会
为实瑰上述目的，双方将考虑在2012年“里约+20”峰会其
闻联合誉欢活动的可能。
为确保本行不计划中规定的活动和任务能够全面执行，双方
授权中意合作项目管理办公室同其它相关管理部门及单位进行协
调，开发环境项目并组织必要活动。
本行动计划于2012年4月27日在罗马签订，一式两份，每
份均用中文、意大利文和英文写成，三种文本同等作准。在解释
上出现分时时，以英文文本为准。
