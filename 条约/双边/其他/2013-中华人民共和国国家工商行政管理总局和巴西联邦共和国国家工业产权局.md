# 中华人民共和国国家工商行政管理总局和巴西联邦共和国国家工业产权局...

中华人民共和国国家工商行政管理总局
和巴西聯邦共和國國家工業產權局
合作诬解备环录
中华人入民共和国国家工商行政管理总局和巴西联邦夫
和國國家工業產權局(以下稱“有雙方? )
认识到知识产权在促进国内经济与全球经济的发展、鼓
勵創新經流投資、塔于創業精神方面的重要性,
期待通過建立定期交流信息和最佳實距、共同開展培訓
和其他活动的机制，优进双方双这合作，继而强化现有的知
次产权体系，
达成这解如下:
第一条目的
本谅解备扎和永的目的在于双方建立一个双边合作的大
本框麻。本访解备扎系中拟开展的活动上在通过交流信息和
最佳实践以及开展能力建设活动，改善双方知识产权保护体
系的管理并提高效率。

第二条“合作领域
双方将在各自机构职责范围内，开展商标注册与保护令
域合作,包括但不限於:
_(一)在各自国家法律允许的范围内，交流商标注册令
域的相關信息,包括法律、法規、規章和規范性文件,
(二)组织并开展能力建设活动，如商标审查、商标蜡
议、商标和争议培训及其他类似培训，
(三)交流知识产权机构管理和办公自动化，以及知识
产权数据库建设方面的信息和最佳实践，例如入力资源管
理、质量控制，以及利用网络优化商标申请流程及异议和抽
销程序的做法，
(四)联合就对双方都重要的国际知识产权问题开展活
动,包括保护地理标志,以及其他国际商标实践的进展情况。
(五)双方就在各自国家开展商标权人教育进行合作，
包括商标权保护的方法和利用行政执法体系保护商标.
第三条磋商
雙方同意:
(一)双方是期举行会晤，审议本备筷隶执行情况，磋
商确定具体合作项目。会晤应由双方机构轮流主办，时间由

双方协商确定，一般以一年一次为宜。
(二)双方指定联络部门，以确保部门间的充分沟通。

第四条資源
雙方將承擔各自工作人員因參與本備忘錄項下活動所
产生的下列费用:各自工作人员发生的旅行费用和津贴.
本谅解备忘录的所有承诺均取决于经费情况和各方了预
算安排。本谅解备忘录在经费方面不具约束力。
第五条保密条款
(一)如被本国信息使用相关法律所禁止，或信息的区

流有悖自身利益，一方将不向另一方提供信息，
(二)双方均应依各自国家法律，对另一方按照本协议
所提供的信息予以保密。经双方协商一致可以公开的信息，
不受本协议保密规定的约束.
第六條限制祭款
本谅解备忘录和双方表达的意愿将遵守各自国家有效
适用的法律法规。本谅解备忘录不影响双方已加入的协议或
备忘录中的权利和义务，
第七条爭議解決
本谅解备扎系在解释或执行过程中发生的争议，由双方
共同协商解决
第八条有效其
本諒解備忘錄自簽署之日起有效期五年。任何一方均可
终止本谅解备忘录，但需提前九十天书面通知对方，
第九条其他条款
本谅解备忘录经双方签字后生效。经双方书面同意，可
以随时修订本谅解备忘录，

本諒解備忘錄於二0一三年八月三十日在里約熱內戶
籤訂,一式兩份,每份均用中文、葡萄牙文和英文寫成,三
种文本同等作準。如在解釋本諒解備軋錄時發生分玻,以英
文文本为准。
