# 中华人民共和国政府和印度共和国政府关于建立中印边境事务磋商和协调...

中华人民共和国政府和印度共和国政府
天于建立中印边境事务磋商
和协调工作机制的协定
中华人民共和国政府和印度共和国政府(以下简称“双
方?)
确信在两国边界问题解决前尊重和遵守实际控制线并
在中印边境地区保持和加强和平与安宁对于增进两国政治
互信与安全、早日解决边界问题和建设两国面向和平与繁荣
的战略合作伙伴关系具有重要意义:
渴望落实一九万三年九月七日签订的《中华人民共和国
政府和印度共和国政府关于在中印边境实际控制线地区保
持和平与安宁的协定》、一万九六年十一月二十九日签订的
《中华人民共和国政府和印度共和国政府关于在中印边境
实际控制线地区军事领域建立信任措施的协定》以及二OO
五年四月十一日签订的《中华人民共和国政府和印度共和国
政府关于在中印边境实际控制线地区军事领域建立信任措
施的實施辦法的議定書》的精神;
为及时就边境形势沟通信息，妥善处理边境事件，切实
开展在两国边境地区的其他合作事务，
达成协议如下:

第一条
双方同意建立中印边境事务磋商和协调工作机制(以下
简称“工作机制” ) ,处理与保持亡境地区和平与安守相关的
重大刻境事务。
第二条
工作机制由中华人民共和国外交部的司局级官员和印
度共和国外交部联秘级官员牵头，双方外交和军事官员组
成,
第三条
工作机制将研究开展和加强中印边境地区双方后事人
员和机构间交流与合作的方式方法。
第四條
工作機制將探討在雙方一致同意的過境地區開展合作,。
第五条
工作机制将承办双方共同商定的其它事宜，但不承担探
讨边界问题解决方案的任务，不影响中印边界问题特别代表
会晤机制。

第人条
工作機制將處理中印邊境地區可能出現的影響保持和
平与安守的问题和情势，积极保持两国间友好气氛。
第七条
工作机制每年誉行一至二次磁商，轮流在中国和印度举
行。视需要并经双方同意也可举行紧急磋商。
第八條
本协定自签字之日起生效。经双方同意可对其进行修
改、补充或终止。经双方同意的修改或补充将成为本协定不
可分割的一部分。
本协定于二O一二年一月十七日在新德里签订，一式两
份,每份区用中文、印地文和英文写成,三種文本同等作準,
如崗解釋上的分野,以英文本為淮,。
