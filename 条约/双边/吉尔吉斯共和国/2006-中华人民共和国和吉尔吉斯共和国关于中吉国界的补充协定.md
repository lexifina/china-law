# 中华人民共和国和吉尔吉斯共和国关于中吉国界的补充协定

中华人民闪和国和
百爾言斯鞭和國
关于中庆国界的补充协定
中華人民共和國和言爾言斯共和國(以下筒銜“締約以
方),
根據一九九六年七月四日《中華人民共和國和言小言斯共
和國關於中吉國界的協定》第三條的規定,為了明確和確定第
7界點至第8界點之加已達成一致的中吉國界線走問;
為了明確和確定第21界點至終點之間已達成一致的中訓
國界線走向;
并作为对上述协定的补充，
达成协议如下:
第一祭
中吉國界線自一九九六年七月四日《中華人民共和國和吉
爾吉斯共和國關於中吉國界的協定》第二祭所述的第7界點
起，党天山南脉〈无名山脉)山脊線向西行,經4401米高地、
4465米高地、4482米高地、4547米高地、4808米高地、4683
米高地、4742米高地、4743米高地,至第7/1界点。该界点在
上述山脉山痛4741.8米高地上,位於中國境內4470米高地北
偏西北約2.5公里，中国志内4556米高地东北约3.7公里,二
尔训斯斯坦境内4429米高地以南約1.6公里处。
从第7/1界點起,中吉國界線沿握名文脈山脊線向西偏西

南行，经4184米高地，至第7/2界点。该界点在上述文脉山兰
4309米高地上，位于中国境内4247米高地西偏西北約2.9公
里,吉爾吉斯斯坦境內3686米高地以東約2.2公里,吉爾吾
斯斯坦境內3784米高地以南約2.0公里處。
從第7/2界點起,中吉國界線沿無名文脈山脊線向南偏西
南行,經4028米鞍部、4497米高地、4327米高地、4234米高
地、4393米高地、4381米高地、4033米高地、3576米高地,
至第7/3界点。该界点在昌乌晋吉库乌什河〈马津太什河)水
流中心线或主流中心线和乌宗图什河〈基奇乌津古什河)水流
中心线或主流中心线相交处，位于中国境内3761米高地西北
約2.6公里,中國境內3675米高地北偏東北約1.7公里,言政
吉斯斯坦境內3838米高地东偶东南约2.5公里处。
从第7/3界点起，中吉国界线漳昌乌晋吉库马什河〈乌津
古什河)水流中心線或主流中心線向西偏西南行,至第7/4界
点。该界点在穷乌金格库乌什河〈乌津古什河)水流中心線或
主流中心线和右侧无名支流水流中心线或主流中心线相交处，
位于中国境内3754米高地西北约1.7公里，中国境内3967米
高地北偏東北約2.9公里,吉爾吉斯斯坦境內3509米高地以
东约4.3公里处。
从第7/4界点起，中吉国界线淹穷乌金格库马什河〈乌津
古什河)水流中心线或主流中心线向西行，经穷乌金格库乌什
河〈乌津古什河)水流中心線或主流中心線和奇坎培什河水流
中心线或主流中心线相交处，至第7/5界點。該界點在昌馬首
吉库乌什河〈乌津古什河)水流中心線或主流中心線和旨秋耶
庫衣人魯克河水流中心線或主流中心線相交處,位於中國境內
3673米高地北偏西北約1.1公里,吉爾吉斯斯坦境內3521米
高地以東約1.4公里,吉爾吉斯斯坦境內3281米高地以南約
0.7公里處。

从第7/5界點起,中吉國界線溯昌秋耶庫衣魯克河水流中
心線或主流中心線大人體敵西南行,經唱秋耶庫衣魯克河水流中
心线或主流中心线和埃基恰特河水流中心线或主流中心线相交
处、昌秋耶库衣和角死河水流中心线或主流中心线和一无名河
(婁尤克布拉克河)水流中心线或主流中心线相交处，至第7/6
罕點。該界點在兩條無名小河水流中心線相交處,直角坐標X
約為4555475, Y約為13735400,位於中國境內4692米高地以
西約2.2公里,中國境內4902米高地西偏西北約3.6公里,古
人尔计斯斯坦境内4615米高地東偏東北約2.2公里處。
從第7/6界點起,中吉國界線沿上述兩條無名小河之間分
水崔的分水線向南偏東南行,經4194米高地、4575米高地、
4746對高地,至第7/7界点。该界点在无名山脉(科克沙阿爾
陶)山脊4792米高地上,位於中國境內4902米高地南偏西南
約2.8公里,中國境內5033米高地以北約3.0公里,吉爾吉斯
斯坦境內5336米高地以東約3.9公里处。
从第7/7界点起，中吉国界线沿无名山脉(科克沙阿尔
陶)山脊線大人體向西南行,經5305米高地、5022米高地、
5009米高地,到4868米高地,然后轉向西偏西北行,經5193
米高地,至第7/8界点。该界点在无名山脉(科克沙阿爾陶)
山脊一無名高地上,位於中國境內5097米高地以北約1.9公
里,吉爾吉斯斯坦境內4744米高地東偏東北約4.0公里，地
尔吉斯斯坦境内5462米高地以南約2.4公里處。
从第7/8界点起，中吉国界线沿无名山脉(科克沙阿尔
陶)山脊線向西偏西南行,經5217米高地、5044米高地、
4917米高地、5083米高地,至第7/9界点。该界点在无名山脉
(科克沙阿爾塔馬山)山脊4885米高地上，位于中国境内4382
米高地以北约0.7公里,中國境內4804米高地東北約2.3公
里,吉爾吉斯斯坦境內4632米高地南偏東南約2.9公里处。

从第7/9界点起，中吉国界线沿无名山脉(科克沙阿爾塔
馬山)山脊線向西北行,到5355米高地，然后转向西偏西南
行,經5318米高地、5998米高地、5802米高地、5506米高
地,到5602米高地,再和轉向西行,經5452米高地、5269米高
地、5024米高地,至第7/10界点。该界点在无名山脉〈科区
沙阿爾培馬山)山脊5186米高地上，位于中国境内4808米高
地西偏西北約1.6公里，中国境内4784米高地東偏東北約2.6
公里,吉爾吉斯斯坦境內5724米高地以南約2.5公里处。
从第7/10界點起,中吉國界線沿無名山須(科克沙阿說
塔马山)山符線問西偏西北行,到4849米康蘇達折(無名山
口),然後特問北行,經5222米高地,至第7/11界点。该界点
在無名山采(科克沙阿爾塔馬山)山脊一無名高地上,位於中
國境內4772米高地東北約2.5公里,吉爾大斯斯坦境內5582
米高地南偏西南約0.7公里,吉爾吉斯斯坦境內5724米高地
西北約0.7公里处。
从第7/11界点起，中吉国界线沿无名山脉〈科克沙阿尔
塔马山)山脊線向西行,經5276米高地，到5401米高地，然
后转问西北行，经5113米高地,至一九九六年七月四日《中
華人民共和國和吉爾吉斯共和國關於中吉國界的協定》第二條
所述的第8界点。
中大國界線目一九九六年七月四日《中華人民共和國和吉
尔记斯共和国关于中放国界的协定》第二条所述的第21界点
起，猎无名山脉〈扎阿拉依斯基山)山脊線向西北行,然后轉
問西偏西南行,至第22界点。该界点在玛里他巴尔山〈扎里
亚沃斯托卡峰) 6349.5米高地上，位于中国境内5431米高地
以北約1.5公里，中国境内5318米高地东北约3.3公里,吉爾
百斯斯坦境內4946米高地東南約3.0公里处。
从第22界點起,中吉國界線沿無名山脈(扎阿拉依斯基

山)山脊線向西偏西北行,到6023米高地，然后转辐西人篇西
南行,經5939米局地，至第23界点。该界点是中订国界线的
終點,在6406米高地上,位於中國境內5431米高地以西約
4.5公里,中國境內5318米高地西偏西北約2.5公里，言尔吉
斯斯坦境内4946米高地西南約4.4公里處。
上述中大國界線用紅線標繪在聯合測制的比例尺為五萬分
之一的地图上。
國界線敘述中所用長度和坐標均系從上述地圖上量取的。
用红线标给中计国界线的上述地图附在本协定之后，并作
为其不可分割的部分。
第二条
缔约双方同意，一九九六年七月四日《中华人民共和国和
言尔言斯共和国关于中言国界的协定》中第一条、第四条、第
五条、第六条、第七条和第八条的规定在本协定中同样适用。
第三条
缔约双方应在完成为使本协定生效所必需的各自国内程序
后相互书面通知。
本协定自最后一份书面通知发出之日起生效。
本協定於一九九九年八月二十六日在比什同克簽訂,一式
兩份,每份都用中文、吉文和俄文寫成。締約雙方如對本協定
的解釋出現分小,以中文、俄文文本作準。
