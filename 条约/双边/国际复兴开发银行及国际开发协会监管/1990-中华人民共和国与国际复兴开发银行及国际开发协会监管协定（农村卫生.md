# 中华人民共和国与国际复兴开发银行及国际开发协会监管协定（农村卫生...

中华人民共和国与国际复兴开发银行
及国际开发协会监管协定
《农村卫生和预防医学项目)
一九九0年四月十日
中華人民共和國(受贈人)同国际复兴开发银行〈银行)及
国际开发协会〈协会)于1990年4月10日签订此协定。
鉴于:(A)根据受赠人同银行及协会于1987年1月15日签订的
农村卫生及预防医学项目〈信贷1713-CHA/贷款2723-CHA )
贷款及开发信贷协定，银行及协会已同意向受贈人提供一笔以
多种货币计算的相当于一千五百万美元的贷款($15,000,000 )
和一笔相當於五千七百二十萬特別提款權(SDR57,200,000)的
信貸,用於幫助資助開發信貸協定附件二所描述的項目(項目),
鉴于〈B)银行和协会已被一非官方組織(贈款人)請
求。並已同意,鹽管贈款人按照贈款人同銀行及協會間的一份信
范协议而提供一笔赠款〈赠款) ,该赠款将用于资助本项目B .1部
分，提供建立小儿麻阁口服疫苗厂〈疫苗厂)的外汇费用〈银行
及协会在此含义内被称为监管人) ;及
鉴于:(C)监管人已同意将该笔赠款按照下述规定的条款和
条件提供给受赠人，资助受赠人建立疫苗厂;
为此，本协定的缔约双方说协议如下:
第一条贈款
1.01节监管人同意按照本文规定的条款和条件，向受赠人

提供一笔一千五百万美元〈昭15,000,000)的贈款。
1.02节监管人和受赠人说此同意，1985年1月1日颁布的
《世界银行贷款及担保协定通则》《通则的规定也适用于本协
定，在细节上已作必要的修正。
1.03节(a)赠款款项得按照本协定附件一的规定从监管人
的托管帐户〈托管帐户)中提取，该附件经受赠人和监管人同意
得随时进行修改。
(b)受赠人应为本赠款在一银行开设并保持一个美元专用
帳戶其祭款和條件應為銀行所滿意。該專用帳戶的存款和支付
應按照本協定附件二的規定辦理。
1.04节截止日为1997年6月30日，或由监管人另定的更晚
的日期。对于更晚的日期，监管人应及时通知受赠人。
第二条疫苗厂建设工作的执行
2.01节《〈a)受贈人应接照适当的工程及公共卫生惯例，
以应有的勤奋与效率开展建设疫苗厂的必要的工作〈工作)，并
根据需要及时提供工作所需的资金、设施、服务及其他资源。
(b)受贈人應按照本項目的開發信貸、貸款及項目協定所
規定的由受贈人承擔的與項目有關的義務開展工作。
2.02节除非监管人另行同意，工作所需并由本赠款款项支
付的货物采购及咨询服务，應按照本項目開發信貸協定附件三的
規定辦理。
ww《〈a).受赠人应按照健全的会计惯例，保存或促使
汉让局岂区区有项人估珊开左工作或工作的任何部分的部]环各
构的业务、资源及费用开支的情况。“
(b)受贈人應
(1》按照一贯运用的适当的审計原則,由監管人可接受的
独立的审计师对本节〈a)段提及的每一财政年这各入记录和由
目包括专用帐户的记录和帐目进行审计#

(ii)尽快，但最晚不迟于每财政年度结束后的6个月，向
监管人提供经上述审计师按照监管人所合理要求的范围和详细程
度进行的该项审计的报告，及
(iii)向监管人提供其随时合理要求的与上述记录、帐目
和审计有关的其他资料。
(c)对于根据费用报表从托管帐户提款的全部开支，受赠
人應:
(i按照本节《a)》段的规定保存或促使保存反映這類
支出的記錄和上帳目)
(ii)保存所有證明上述費用支出的記錄(合同、訂單、發
票、帐单、收据及其他赁证》直到协会收到完成最后一次提款的
财政年度的审计报告后至少1年3
(iii)保证银行的代表能检查这些记录”及
(iv)保证这些记录和帐目被包括在本节〈b)段所提及的
年度审计内，并保证该报告包括该审计师对于该财政年度提交的
费用报表及有关的程序和内部控制是否可赖以证明有关提款的一
份单独的意见书。

3.01玉本协定经缔约双方签署后生效。
