# 中华人民共和国与国际复兴开发银行贷款协定（吴泾火电项目）

中华人民共和国与国际复兴开发银行
贷款协定
《吴泾火电项目)
一九八八年二月三日
中华人民共和国《以下简称“借款人”)与国际复兴开发户
行〈以下简称“银行”)于一九八八年二月三日签订本协定。
鉴于〈A)借款人確信本協定〔附件2 )中所述的本项目的
可行性及重要性,要求銀行對本項目予以資助,
(B)本項目將在借款人的幫助下由上海市電力局(以下简
称“上海电力局”)執行。作為這種幫助的一部分,借款人將使
上海電力局得到本協定所提供的貸款,
鉴于银行已经同意，基于上述情况，接照本协定以及银行与
上海电力局在同日签订的《项目协定》所规定的条款与条件向借
款人提供本貸款,
為此本協定的締約雙方現協議如下
第一条”通则和定义
1.01节”银行于一九八五年一月一日起实施的《国际复兴开
发银行贷款及担保协定通则》《简称《通则》)，除了删去其
3.02节中最后一名以外，是构成本协定整体的一个部分。

1.02节”本协定中所使用的词汇，除上下文另有要求者外，
其含义与《通则》中所作的解释相同，下列新用的词汇，则具有
以下词义;
(a) “项目协定”，系指在本协定签订的同日，银行与上
海电力局之间签订的协定，该协定同样可以随时修改。此词义也
包括《项目协定》的所有附件和补充协议在内?
已“转贷协定”，系指借款人与上海电力局根据本协定
3.01节〈b)款的规定所签署的协定，该协定同样可以随时修改。
此词义也包括《转贷协定》的所有附件在内
(c) “上海电力局”，系指按照其《章程》建立并开展业
务的上海市电力局，它是借款人的一个国营企业!
(d) “章程”，系指由水利电力部于一九八六年九月十一
日令布的《上海电力局章程》#
(e) “水电部”，系指借款人的水利电力部及其任何继
承者;
(f》“专用帐户”，系指本协定2.02节〈b》款中所指的
帐户。
第二条贷款
2.01节银行同意按照本贷款协定所规定的和提及的条款和
条件，向借款人提供一笔以多种货币计算的总额相当于一亿万千
萬美元〈($190 000000)的貸款。
2,02節。(a)》此項貸款可根據本協定【附件13的規定,
从“贷款帐户”中提取，用以支付已经发生的《如经银行同意也
可用于支付将发生的)、本协定[附件2 ]中所列本项目所需
的、应由本贷款支付的商品及服务的合理费用。
《b)为实现本项目的目的，借款人应按银行满意的条款和
条件,在一家银行开立并保持美元“专用帐户”。该“专用帐户?中
款项的存人和支付均应符合本协定5附件5 ]的规定。

2.08节”本项目的截止日期为一九九三年六月三十日或银行
另行规定的更晚的日期。对于更晚的日期，银行应及时通知借
款人。
2.04节”借款人对于尚未提取的贷款本人金应按百分之零点七
五〈0.75%)的年率，按时向银行交付承诺费。
2.05节。《〈a)难于已经提取尚未偿还的贷款本金，借款人
应按每一个“利息期”的年利率及时交付利息。此项年利率为
0.5%加上该利息期开始前刚结束的上一个“半年期”的“核定
借人款费用>。|
(b)银行根据实际可能，在每一个“半年期?终了后，及
时将该“半年期”的“核定借入款费用”通知借款人。
(e》在本节中使用的
(1 ) “利息期”，系指本协定2.06节中规定的每一日期开
始的六個月時期,包括本協定簽訂之日在內的“利息期。
(2 ) “核定借人款費用? ,系指銀行說一九八二年六月三
十日以后已经提取而未清偿的借人款的费用，由银行以合理确定
的年利率表示之。
(3 ) “半年期”，系指日历年度的前六个月或后六个月。
2.06节”利息及其它费用应每半年交付一次，交付日期为每
年的一月一日和七月一日。
2.07节借款人应按照本协定〔附件3 )中规定的分期还款
表償還貸款的本金。
2.08节上海电力局被指定为借款人的代表，以采取本协定
2.02节以及《通则》第五节的规定中所要求的或允许的各种
行动。
第三条”项目的执行
3.01《〈a)借款人对实现本协定【附件2 ]中所述的本
项目的各个目标作出承诺，为此，除了对履行本《贷款协定》所

规定的任何其他义务不受任何限制的约束外，借款人还应使上海
电力局履行《项目协定》中所规定的全部义务，应采取或促使采
取必要的或適當的一切行動,包括提供資金、設施、服務和其他
资源，使上海电力局能履行这些义务，不应进行或不允许进行任
何妨碍或干系履行这些义务的活动。
(b)借款人应依据借款人和上海电力局之间签订的《转贷
协定》，把本贷款资金按照银行认可的条款和条件转贷给上海电
力局
《1 )该笔贷葡资金将于二十年内还铺，包括五年宽限期，
年利率為百分之八點五(8.5%) )
《2 )承诺费和转贷贷款偿还的外汇风险〈美元与借款人的
货币之间)由上海电力承担。
《c)借款人应根据《转贷协定》行使其权利，以保护借款
人和銀行的利益,實現貸款的目的。除非銀行另行同意,借款人
不得转让、人修改、取消或放弃《转贷协定》或其中的任何条款。
3,02節”除非銀行另行同意,凡本項目所需的、由本貸款資
金支付的貨物、工程的采購和咨詢服務均應按照本協定〔附件
4 ]的规定办理。
3.037银行和借款人因此同意，《通则》9,04节、9 ,05
节、9.06节、9.07节、9.08节和9.09节中所规定的义务〈即有关
保险、货物和服务的使用、计划和进度表'、记录和报告、维修和
征地等)，应由上海电力局按照《项目协定》2 .03节执行。
