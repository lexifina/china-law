# 中华人民共和国与国际复兴开发银行贷款协定（上海环境项目）

中华人民共和国与国际复兴开发银行
貸款协定
(上海环境项目)
中華人民共和國(下稱借款人)与国际复兴开发银行(下稱
银行)于一九九四年六月二日签订本协定。监于
(A)借款人对于本协定附件2所述的项目可行性和优先性表
示满意，借款人请求银行对本项目给予资助。
(B)在借款人的協助下,本項目將由上海市(下稱上海)實
施,作為協助的一部分,借款人應按照本協定的規定將貸款資金
提供給上海;以及
鉴于银行已同意，特别以上文为基础，按照本协定及银行与
上海同一天签定的《项目协定》所规定的条款和条件向借款人提
供本贷款。
为此，本协定的缔约双方现协议如下:

则力，构成本协定整体的一部分。

第二条贷款
2.01节，银行同意按照贷款协定所规定或提及的条款和条
件，向借款人提供一笔以多种货币计算的总额相当于一亿六干万
等值美元($160, 000, 000)的贷款，其数额为银行按借款人每
次提款日汇率折算计值的提鞭金额总额。
2.02节〈a)本项贷款资金可根据本协定附件1的规定,从
贷款账户中提款，用于支付已发生的〈如银行同意，亦可用于支
付将发生的)、本协定附件2所述项目的所需的、并且应从本贷款
资金中支付的货物及服务的合理费用。
(b)為了本項目的目的,借款人应按银行满意的条件和条款，

包括適當地防止抵消,沒收或扣押,在一家銀行可以接受的商業
銀行開設一個美元專用賬戶,專用賬戶款項的存和人和支取均應按
照本协定附件四的规定办理。
2. 03节”提款截止期应二〇COCO年六月三十日,或由銀行另
行规定的更晚的日期。银行应及时将该更晚日期通知借款人。
2. 04节對於尚未提取的貸款本金,借款人应按百分之零点
七五(0.75%%)的年率按时向世行交付承诺费。
2.05节。(a)對於已經提取尚未償還的貸款本金,借款人应
按每一利息期的利率按時向世行交付利息,每一利息期的利率為
前一个半年所确定的核定借款成本加上百分之零点五(0.5%)。在
本协定第2. 06节规定的每个日期,借款人应支付上一个利息期沿
未偿还的贷款本金所产生的利息，该笔利息是按该利息期内适用
的利率计算。
(b)银行应根据实际可能，在每一个半年期终了后，将该半
年期的核定借款成本尽快通知借款人。
(e)在本節中使用的
Gi“利息期"系指本协定2. 06节中规定的每一日期以前的六
个月时期，包括本协定签订日所在的最初的利息期。
(Gii) “核定借款成本”系指银行在一九八二年六月三十日以后
已经提取而未清偿的借入款部分的费用，由银行合理确定并以年
百分比表示。银行借款部分不包括银行分配给下列资金的这类借
入款或部分借入款的费用: (A)銀行的投資; (B)銀行在一九八
九年七月一日以后可能发放的、其利率不根据本节(a)段確定的
贷款。
Giii)“半年期”系指日历年的前六个月或后六个月。
(d)銀行應至少提前六個月通知借款人在某一確定的日期對
本节(a)、(b)、(c)Gii)段進行如下修改:

”(b)银行应根据实际可能，在每一季度终了后，将该季度

”(c) (iii) “季度系指从每个日历年的一月一日.四月一日、

第三条”项目的执行
3.01节(a)借款人对实现本协定附件2中所述的本项目的
各個目標作出承諾,為此,在不受制於或不限於只履行貸款協定
中規定其應承擔的任何其他義務的情況下,借款人應促使上海履
行項目協定中規定的其他履行的一切義務,並應進行或促使進行
一切必要的或適當的活動,包括提供資金、設施、服務和其他資
源,以使上海能履行這些義務,不應進行或允許進行任何妨礙或
干擾履行這些義務的活動。
(b)在貸款過程中,如項目采購等而挫貸款賬戶中提取的或
特别账户支付的货币,借款人应以相应的美元(根据支付日期)提
供给上海。上海方面以银行同意的方式将同时应无条件地满足:
G)贷款资金偿还期十五年，包括五年宽限期;
(ii)对于已经提取而尚未偿还的贷款本金，上海应按照本协
定2. 05节规定的利率的90. 63上交付利息;以及
Gii)對於尚未提取的貸款本金,上海應以本協定2. 04節所述
利率支付承诺费;
3.02节除非银行另行同意,凡项目所需的并将由本贷款资

金支付的货物采购、土建工程及咨询服务，均应按照项目协定附
件1的规定办理。
3.03节”借款人与银行同意,《通则》第9. 04節、9. 05节、
9.06节、9. 07节、9. 08节和9. 09节中所规定的义务〈分别涉及
保险、货物和服务的使用、计划和进度表、记录和报告、维修及
土地征用等)，应由上海根据项目协定第2. 03节来承担。
第四条”财务约文
4.01节(a)对于根据费用报表从贷款账户中提款所作的全
部支出，借款人应:
GD根据健全的会计惯例保留或促使保留反映这些支出的记
录和账目;
(ii)保留证明这些支出的所有记录(合同、订单、发票、账
单、收据及其他文件),直到银行收到最后一次从贷款账户中提款
的那一个财政年度的审计报告后至少一年;以及
(iii)使银行的代表能够检查这些记录。
(b)借款人應:
G)由银行可以接受的独立的审计师,按照一贯运用的适当的
審計原則,對每一財政年度的在本節(a) (i)段提及的各类记录
和賬目,包括專用賬戶的各類記錄和賬目進行審計,
Gi)尽快，但在任何情况下最迟不晚于每一财政年度终止后
的六个月，向银行提供一份由前述审计师们按照银行合理要求的
范围及详细程度所作的这类审计报告，包括一份由上述审计师们
出具的、关于该财政年度内所提交的费用报表以及这些费用报表
准备的程序和内部控制是否能作为有关提款的依据的独立的审计
意見;以及
Gii)當銀行隨時提出合理要求時,向銀行提供關於上述記錄、
账目以及对它们所作的审计这类文件的其他资料。

第五条”银行的补救措施
5.01节根据《通则》第6. 02节〈1)款，特规定以下补充
事項:
(a)上海未能履行项目协定中规定的任何义务。
(b)》由于在本贷款协定签字后发生的事件所造成的特殊情
况，致使上海不可能履行项目协定中规定的义务。
(c)任何一方未能履行转贷协议中规定的任何义务。
(d)任何一方未能履行太湖泵站建设协议中规定的任何
义务。

發生本協定5. 01節(a)、(c)或(d)段所述的情況,并且在
银行向借款人发出通知后六十天内继续存在。
