# 中华人民共和国与国际开发协会开发信贷协定（贫困和少数民族地区基础...

中华人民共和国与国际开发协会
开发信贷协定
(貧困和少數民族地區基礎教育項目)
中華人民共和國《下稱借款人)与国际开发协会(下稱協
會)於一九九四年十一月八日簽定本協定。
监于借款人对本协定附件二所述项目的可行性和优先性表示
满意，请求协会对本项目给予资助;
鉴于协会已同意，特别是在上文的基础上，按照本协定中所
前明的条款和条件，向借款人提供本信贷。
为此，本协定的缔约双方现协议如下:
”第一条通则，定义
1.01节协会于一九八五年一月一日实行的《开发信贷协定
通則》(下稱《通則)》,除3. 02节最后一句外，构成本协定不可
分割的一部分。

第二奈信贷
2. 01节协会同意按照本《开发信贷协定》所规定或提及的
条秋和条件，向借款人提供一笔由多种货币组成的总额相当于六
干九百二十万个特别提款权(SDR69200000)的信贷。
2.02节(a)本信贷金额可根据本协定附件一的规定从信贷
账户中提取，用于支付已经发生的〈或如协会同意，亦可用于支
付將要發生的),附件二描述的項目所需要的,并应由本信贷资金

支付的货物和服务的合理费用。
(b)为了实现本项目的目的，借款人应按照协会所满意的条
件和条款，包括适当地防止抵消、没收或扣押，在一协会所满意
的商业银行，开设并保持专用存款账户。专用账户款项的存入和
支取均应按照本协定附件五的规定办理。
2. 03节截止日期應為二CC00年十二月三十一日,或由協
会规定的更晚的日期。对于该更晚的日期，协会应及时通知借
款人。
2. 04节。(a)借款人应按协会在每年的六月三十日所确定的
不超過百分之零點五(百分之一的二分之一)的年率，对不断变
化的尚未提取的信貸本金,向協會交付承諾費。
(b)承諾費應: (i)从本协定签字第六十天后之日(發生日)
起算,直到款项由借款人从信贷账户提取或款项被注销日为止;以
及Gi)按发生日前的最近的那个六月三十日确定的年率或按上述
(a)段的规定不时确定的年率计算.每年六月三十日确定的年率应
自本協定2. 06节规定的该年的第二个付款日始用。
(c)承諾費應, (i)在協會合理要求的地方交付; ii)在交付
上不受借款人施加的或借款人领土内的任何限制的影响，(iii)使
用本协定根据《通则》4. 02节的规定所选定的货币，或按照该节
规定不时指定或选定的其他一种或几种合格的货币交付。
2. 05节”借款人应按百分之零点七五〈百分之一的四分之
三)的年率，对不断变化的已提取而尚未偿还的信贷本金，向协
会交付手续费。
2. 06节，承诺费和手续费每半年交付一次,付款日為每年的
二月一日和八月一日。
2.07节。(a)尽管有下列(b)段和(ec)段的規定,借款人
應自二0C0五年二月一日始至二0一九年八月一日止,每半年分
期償還一次信貸本金,付款日為每年二月一日和八月一日。在二

百分之一點二五(百分之一又四分之一),此后每期应偿还本金的
百分之二點五(百分之二又二分之一)。
(b)當Gi)協會確定,借款人以一九八五年美元不變價格計
算的人均國民生產總值已連續五年超過790美元時;以及(ii)世
行考虑到借款人的借债信誉足以使用世行贷款时，在经协会执董

求借款人将尚未到期的每期的分期偿还金额增加一倍偿还，直至
本信贷本金全部偿还为止。如借款人有此要求，协会也可修订这

金額的辦法,改為由借款人對已提取而未償還的信貸本金部分,按
与协会商定的年率交付利息的办法。
(c)如果,在根据上述(b)段规定对条款进行修改后的任何
時候,协会确定借款人的经济情况严重恶化,如借款人有此要求，
協會須對償還條款再作修改,使之与上述(a)段中所列的分期偿
还安排一致。
2.08节将确定美利坚合众国的货币为《通则》4. 02节所要
求的貨市。
第三条”项目的执行
3.01节(a)借款人申明其对实现本协定附件二中所确定的
项目目标所作的承诺，为此，借款人要以应有的勤奋和效率，按
照适用的经济、财务、行政管理、技术和教育惯例，实施本项目
的D部分，并使参项省实施本项目的A、B和C部分,並及時提
供,或如需要,促使各参项省及时提供本项目所需资金、设施、服
务和其他资源。
(b)不限于本节(a)段的规定以及除非借款人和协会另行同
意,借款人應(i)按本协议附件四中规定的执行方案，实施项目
或促使項目實施,并且(ii)进一步采取上述执行计划中所提及的

这类行动，或按照规定，使之进一步采取这类行动。
3.02节除非协会另行同意,凡本項目所需的並將由本信貸
资金支付的货物采购、工程和咨询服务均应按照本协定附件三的
规定办理。
第四素”财务约文
4.01节(a)借款人应按照合理的会计惯例,保存或促使參
项省保存会计记录和账目，使其足以反映负责实施项目或其任何
部分的借款人的有关部门和机构的项目业务、资源和费用。
(b)借款人应:
〈i)按照一贯运用的适当的审计原则,由协会能接受的独立审
计师对上述(a)段提及的每一財政年度的記錄和賬目包括與專用
账户有关的记录和账目进行审计;
(ii)尽快，但最晚不应迟于该财政年度后六个月，向协会提
交或促使提交按上述要求审计过的经核实的其范围和详细程度为
协会合理要求的审计报告副本;以及
(iii)当协会随时合理要求时，向其提交其他与上述记录、账
目和审计有关的资料。
(c)对于根据费用报表从信贷账户提款的全部费用，借款
人应
(Gi)按照本节(a)段的规定，保存或促使保存反映该类费用
的记录和账目;
(ii)保留所有证明该费用的记录(合同、订单、发票、账单、
收据和其他文件),直到协会收到完成最后一次从信贷账户提款或
从专用账户付款的财政年度的审计报告后至少一年;
(iii)保證協會的代表能檢查該記錄;以及
(iv)保证该记录和账目包括在本节(b)段提及的年度审计中，
并保证该审计的报告包括上述审计师关于该财政年度里提交的费
用报表以及它们的准备过程和内部控制是否可以赖以支持有关提

款的独立意见。
第五条”协会的补救措施
5. 01节根据《通则》6. 02节(h)段的規定,增加以下事項:
(a)如果任何一参项省没有按照教育方案实施安排履行其
义务。
(b)在本信贷协定签字之日后，发生的情况而造成了一种非
党形势，使参项省不能按照教育方案实施安排履行义务。
5. 02六根据《通则》7. 01节(d)段規定,增加以下事項,
即:本协定5. 01節(a)段規定的情況發生並在協會向借款人就該
情况发出通知后持续存在达六十天之久时。
