# 中华人民共和国和塔吉克斯坦共和国关于进一步发展两国睦邻友好和互利...

中华人民共和国和塔吉死斯坦共和国
大于进一步发展两国睦邻友好和
孔利合作关系的联合声明
應中華人民共和國主席江澤民的邀請,培詩克斯坦共
和國總統埃英馬利‧拉赫英諾夫於一九九九年八月十一日至十
四日對中華人民共和國進行了友好訪問。
在访问期间举行的高层会见与会谈中，双方讨论了进一步
发展中华人民共和国和塔吉克斯坦共和国各领域合作关系及共
同感兴趣的国际和地区问题。
中華人民共和國和塔吉克斯坦共和國(以下簡稱“雙方”)
強再推動兩國睦交友好合作關係的進一步發展符合兩國的
根本利益;
认为两国解决历史遗留边界问题取得的显著进展具有重要
意义;
重申恪守一九九三年三月九日《关于中华人民共和国和塔
言克斯坦共和國相互關係基本原則的聯合聲明》和一九九六年
九月十六日《中華人民共和國和塔吉克斯坦共和國聯合聲明》
的各項內容;
聲明如下:
一、雙方對兩國建交以來在政治、經濟、文化、科技、教
育等领域互利合作的发展感到满意，并决心恪守和平共处五项
原则，保持和发展长期稳定的睦邻友好、互利合作关系。

一、雙方對此次丙國元首簽署《中華人民共和國和塔吉克
斯坦共和國關於中塔國界的協定》給予高度評價,並同意以有
关目前中塔国界的条约为基础，根据公认的国际法准则，本着
平等協商、互諒互讓的精神,就尚未協商一致地段的邊界線走
四问题继续进行谈判，以尽早圆满解决。
双方同意，在边界问题彻底解决前维持边界现状。
三、雙方將充分利用地緣優勢擴大和深化經貿合作,進一
步發展兩國間,包括邊境地區間、省州間多種形式的經貿合
作,鼓勵和文持兩國公司和企業建立直接聯繫。兩國政府將為
此创造更为良好的条件。
双方将加强两国政府间经贸混委会协调经贸合作的作用，
切实有效地落实已签署的双边经贸协议，及时解决经贸合作中
出现的问题。
四、双方将进一步发展运输领域的合作，采取必要措施，
相互为客仙运输提供便利，相信双方签署的汽车运输协定将有
助于实现上述目的。
雙方將探討共同修建庫里亞布一閉勒買公路個別路段或該
路輔助設施的可能性。
五、双方重申反对任何形式的民族分裂主义、宗教极端主
义以及国际念怖主义，不允许任何组织和势力在本国境内从事
针对帮一方的分裂活动。双方将在打击有组织犯罪、偷运武器
等跨國犯罪行為方面加強合作。
六、雙方將繼續打擊本地區日益頻繁的毒品非法種植、生
產和販運活動。為此,雙方將在國際和地區範圍內進行合作,
并相信两国就此问题签署的双边文件将有助于实现上述目的。
七、中華人民共和國重申,將繼續文持塔吉克斯坦共和國
及其领导人为维护国家独立与主权、维护国内稳定和实现民族
和解所做的努力。

塔吉克斯坦共和国对澳门即将回归中国表示欢迎，支持中
华人民共和国领导人致力于国家统一的政治努力，重申中华人
民共和國政府是中國惟一合法政府,台灣是中國領土不可分割
的一部分。塔吉克斯坦政府反對制造“兩個中國”或“一中一
台”的圖謀,確認不和台灣建立任何形式的官方關係和進行任
何形式的官方往來。
八、雙方對上海和莫斯科協定參加國元首比什凱克會晤表
示癌迎,認為該會晤是協定參加國為加強在歐亞地區的相互信
任與理解所采取的又一共同步驟
C
九、双方对阿富汗武装对抗升级表示关切，强调“6 + 2"
成员国的努力具有重要意义，主张为和平解决阿富汗冲突而继
續努力。
十、双方主张，在国际事务中应信守相互尊重主权和领土
完整、平等、互不干涉内政及通过友好协商解决相互分歧与争
端的原则;反对在国际关系中动辑使用武力或以武力相威胁;
维护联合国在处理国际及地区事务中的权威作用。
双方愿意在国际事务中加强磋商与合作，为建立公正合理
的国际政治经济新秩序而共同努力。
十一、塔吉克斯坦共和國總統埃莫馬利‧拉赫莫諾夫邀請
中华人民共和国主席江泽民对塔吉克斯坦进行正式友好访问。
江泽民主席对此表示感谢并接受邀请。访问时间将通过外交和途
径商定。

代表代表
