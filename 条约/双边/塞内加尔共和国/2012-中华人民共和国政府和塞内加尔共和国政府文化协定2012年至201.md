# 中华人民共和国政府和塞内加尔共和国政府文化协定2012年至201...

中华人民共和国政府和塞内加尔共和国政府文化协定
2012年至2015年执行计划
中华人民共和国政府和塞内加尔共和国政府(以下简称双
方)，为加强两国在文化艺术、文化遗广和博物馆、孝育、体
育、新闻出版、广播影视以及图书馆等方面的交流与合作，根
皂二DOA和八年一月十七日在达喀尔签订的两国政府文化协
定，特签署二O〇一二年至二〇一五年执行计划，条文如下:
第一祭文化和艺术
1.雙方將互派一不超過6人的部級政府文化代表團訪問,為
期不超过10天。
2.双方将互派一不超过20人的表演艺术团赴对方国家访演
交流,為期7至10天,
3.双方在双方国家学办一艺术展览，展期10天，随展2人。
4.双方将互派造型艺术家或作家共2人赴对方国家进行客
座創作,為期1至2個月。
5.座方同意利用网絡等新技術手段傳播對方的文化。中方
将在文通网( www. culturalink. goy. ca)上设立介绍塞内加尔
文化情况的分页。
6.双方将积极探讨互设文化中心的可能性。

7.及方辟勵兩國升展文化藝術領域的人力資源培訓合
作，如为对方国家相关艺术领域人员进行培训、组派文化艺术
官员和人士赴对方国家相关机构挂职等人尝守村通过
外交途径进一步商定。
第二条教育和体育
8.双方鼓励两国在教育领域开展交流与合作，如互派代表
团、在高等院校间开展交流合作等，
9.中方每年向塞方提供50人/年的奖学金名额(即塞方每年
享受中国政府奖学金在华学习的总人数不超过50名)。
10.双方将加强合作，共同推动体育事业的发展。具体事宣
將由雙方通過外交途徑另行商定.
第三條文化遗产和博物馆
11.双方鼓励两国文化遗产管理机构加强合作,增强业务能
力。重所就文化遗产保护和管理，以及博物馆发展〈如主题展
禹陈列布置等)开展合作。有具体项目将由双方通过外交渠道进
行沟通。
12.在本执行计划有将期内，双方商签防止盗穿、盗掘和非
法进出境文化财产的协定，共同打击文物犯罪。

第四条新闻出版、广播影视、图书馆
13.双方鼓励两国开展出版领域的交流与合作;鼓励并资助
本國出版社用本國語言介紹、翻譯、出版對方國家的優秀文學
作品及各类著作;鼓励本国出版机构积极参加在对方国家举办
的国际书展。具体事宣由双方主管机构事先通过外交途径商定;
14.雙方鼓勵兩國開展廣播、影視領域的交流與合作,如
互派代表团、互换广播和影视相关资料、互办电影周等。
15，双方鼓励两国国家图书馆进行经验交流。具体事宜由
雙方主管機構事先通過外交途徑商定,
第五条财务规定
16.根据本执行计划派出的互访人员，由派遗方负担国际
旅客和人人身保险费，接待方负担在其境内的食宿、交通和突发
医病的医疗费用。
17.表演艺术团互访，由派遗方负担演出道具的国际运
费，鞍待方负担演出道具在其境内的运费以及组织演出的相关
用。
二
18.展咒互访，由派站方负担展品国际往返运费和保险
费，承展方负担展品在其境内的运费、保险费和组织展览的相
关费用。
19.双方互派留学生费有用，根据各自规定执行。奖学金获
得者趟對方國和鬥業回國的國際機票由派遣方承撕。

20.双方至励各目企业赞助本执行计划的交流项目。
第六条其它规定
21.本执行计划不排除双方为扩大两国在相关领域进行合
作而相互同意进行的其它活动。
22.执行本计划过程中，如出现问题和分暑,通过双方友好
協商解決。
23,本擁行計劃自從字之日起生效,有效期截至2015年12月
31日。
赠约双方政府授权本国双方代表在本协议世上签字，以昭
信守。
本执行计划于二O一二年六月十九日在北京签订，一式丙
份，每份均用中文和法文写成，两种文本同等作准，
