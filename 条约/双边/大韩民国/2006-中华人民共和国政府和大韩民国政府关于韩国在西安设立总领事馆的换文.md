# 中华人民共和国政府和大韩民国政府关于韩国在西安设立总领事馆的换文

中华人民共和国政府和大二民国政府
關於家國在西安設立
总领事迄的换文
中方去文
(2006)部领字第210號
大韩民国驻华大使馆:
中華人民共和國外交部向大韓民國駐華大使館致意,並謹確
认收到大使馆二OO六年六月一日MCP06 -300號照會,內容
如下:
“大韓民國駐華大使館向中華人民共和國外交部致意,並謹
代表大韩民国政府确认，大韩民国政府和中华人民共和国政府本
着进一步发展两国友好关系和加强两国间领事合作的共同愿望，
经过友好协商，就大韩民国在西安设立总领事馆事达成协议
如下:
一、中华人民共和国政府同意大韩民国在西安开设总领事
馆，领区范围为陕西省、甘肃省和宁夏回族自治区。
二、大韩民国政府同意中华人民共和国政府保留在大韩民国
增设领事机构的权利。设领地点、领区范围和人员编制等事宜双
方将通过外交途径另行商定。
三、中华人民共和国政府将根据1963年4月24日《维也纳
領事關係公約》及中華人民共和國的有關法律規定和對等原則,

为大韩民国在西安设立总领事馆及执行领事职务提供一切必要的
协助和便利。
四、兩國政府將根據包括1963年4月24日《维也纳领事关
系公约》在内的国际法及国际惯例，并本着对等原则，通过友
好协商解决两国领事关系中可能出现的问题。
上述内容如蒙中华人民共和国外交部代表中华人民共和国政
府复照确认，本照会和复照即构成大韩民国政府和中华人民共和
国政府的一项协议，并自中华人民共和国外交部复照之日起
生效。
中華人民共和國外交部謹代表中華人民共和國政府確認,同
意上述照会内容。
顺臻最崇高的敬意。
中華人民共和國外交部(印)
二口口六年六月十三日于北京
