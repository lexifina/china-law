# 中华人民共和国和巴西联邦共和国联合公报

中华人民共和国
和巴西聯邦共和國聯合公報
(二00四年五月二十四日)
值此中巴建交30周年之际，应中华人民共和国主席胡锦涛
的邀请，巴西联邦共和国总统路易斯，伊纳西奥'卢拉'达席尔
瓦于2004年5月22日至27日对中华人民共和国进行了国事访
间。巴方7位部长、6位州长、1位参议员、10位众议员，以及
由420多人组成的企业代表团随行
访问期间，胡锦涛主席与卢拉总统在亲切友好气氛中举行了
会谈。两国领导人就双边关系及共同关心的国际和地区问题进行
了有益的交流。双方签署了多项加强双边合作的文件，双方认
为，卢拉总统对中华人民共和国的国事访问取得了非常积极的成
果，将进一步推动两国战略伙伴关系不断站前发展。
双方一致认为，中巴建交30年来，尤其是上世纪90年代建
立戰略伙伴關係以來,兩國關係的發展令人滿意,各領域合作均
取得重要成果。为进一步充实中巴战略伙伴关系，双方同意在以
下四项原则指导下发展两国关系: (一)坚持平等协商，增强政
治互信; (二)堅持互惠互利,擴大經貿往來; (三)保持磋商
协调，加强国际合作; (四)推動民間交往,增進相互了解

双方回顾了两国在经贸、科技、社会、文化等领域重大合作
项目的进展情况，认为中巴合作极语潜力。双方同意根据上述原
则，落实已签署的合作协议，不断拓展双边合作的新领域，为两
国人民谋取更大福社。
双方决定成立中巴高层协调与合作委员会，指导和协调两国
关系的发展。该委员会中方主席为吴仪副总理，巴方主席为阿伦
卡爾副息統。高層委員會的運作方式由雙方通過外交渠道商定。
关于和平利用外层空间，巴方祝锅中国首次成功发射绕地轨
道载人发鹏。西国元首对中巴地球资源卫星项目的顺利发展和取
得的成果表示滿意。繼續開展近感應用領域的合作將進一步擴大
双方现有合作成果，并将能为第三方提供上述卫星项目的有关
服务。
双方注意到两国经贸联系日益密切，双边贸易额连年增长。
巴方注意到中国经济体制改革所取得的重大进展，并条诺将本着
建设性精神，研究关于承认中国为市场经济国家的问题。双方重
申将共同致力于两国经贸合作的长期稳定发展，并提高合作
质量。
雙方對兩國大型企業在訪問期間簽署或宣布的重要合作文件
表示滿意,對由420多位企业家组成的巴西企业代表团随访并取
得良好成果感到高興。雙方祝賀中巴企業家委員會成立。
巴方重申,堅持“一個中國”原則,中華人民共和國政府
是代表全中國的唯一合法政府,這是30年来巴西对外政策的一
贯立场。巴方赞同中方关于人台湾、西藏是中国领土不可分割的一
部分的立场，反对任何旨在制造分裂、加剧台海紧张局势和导致
“台湾独立”的单边言行。中方对巴方的上述立场表示赞赏。
双方均主张国际关系民主化和世界多极化，认为这是应对全
球及地区性威胁和挑战，以尊重主权平等、遵守国际法为基础，
预防及和平解决分歧的根本要素。
雙方重申支持加強聯合國的權威及其在維護世界和平、安全

和促进发展方面的核心作用，认为有必要对联合国、包括安理会
進行改革,支持通過對安理會進行必要和合理的改單,加強發展
中國家的作用,以使安理會更具代表性和民主性。中方重視巴西
在地區和國際事務中的影響和作用,支持巴西作為西半球最大的
发展中国家在联合国等多边机构中发挥更大作用。中方愿在此问
题上与巴方加强沟通与合作
雙方號決反對一切形式的恐怖主義。一致認為反恕應來取練
合措施，标本碌治。双方呼吁国际社会加强合作，发挥联合国的
主导作用
双方认为全球范围内发展问题日益重要，主张国际社会应加
强合作，以促进经济和社会发展，消除贫困、歧视和不平等现
象，中方对卢拉总统积极致力于消除贫困的努力表示赞贫。双方
同意加强两国政府在这一领域的交流与合作，共同推进全球减贫
事业。
双方呼吁对经济全球化给发展中国家审来的挑成给予关注，
重申在平等基础上巩固多边贸易体制的重要性，认为新一轮多边
贸易谈判将为促进全球特别是发展中国家的发展发挥重要作用，
应优先解决发展中国家的关切。在此意义上，双方强调农业谈判
的核心作用以及二十国协调组发挥的建设性作用。双方愿继续在
多哈回合談判中加強相互協調,推動談判取得體現各方利益,特
別是發展中世界利益的結果,使其真正成為“發展回合”
双方重申在《维也纳行动纲领和声明》中确立的人权的普
记性、不可分割性和非选择性原则。强调全面实现发展权至关重
要，并重申促进和保护人权应遵守《联合国宪章》的宗旨和原
则。双方均不赞同将人权问题政治化和采取不同标准，重申将加
强两国在人权领域的交流与合作。中方对巴方在日内所人权会上
给予的支持表示感谢。
雙方認為,各自所在地區發展中國家的團結合作有利於促進
地区的稳定与发展。中国对巴西为推动拉美一体化所作的积极努

力表示贊賞和支持,巴西稱許中國的現代化進程是亞洲安全、穩
定、發展與合作的重要促進因素。
雙方認為,中巴戰略伙伴關係是中拉關係和亞拉跨地區合作
的重要组成部分，两国将继续致力于中拉、亚拉关系的不断发
展。巴方文持中国继续与拉美国家和地区组织开展互利合作，支
持中國成為美洲國家組織觀察員和泛美開發銀行成員。中國支持
巴西更多地參與亞洲發展進程,加入亞洲開發銀行。
双方强调，中国和南方共同市场经济互补性强，发展经贸合
作前景广阔，强调应不断完善中南对话机制，并就开展自由贸易
等共同感兴趣的问题深入磋商。
卢拉总统对访华期间所受到的热烈欢迎和盛情款待表示感
谢，邀请胡锦涛主席在适当时候访问巴西。胡锦涛主席愉快地接
受了邀請。
中华人民共和国主席巴西聯邦共和國總統
路易斯‧伊納西奧.
