# 中华人民共和国和意大利共和国文化和科技合作意向书

中华人民共和国和意大利共和国
文化和科技合作意向书
中华人民共和国国务院总理华国锋和意大利共和国总理弗朗
切斯科'科西加于一九七九年十一月三日至六日在罗马会见期间，
讨论了两国之间的文化关系和科技合作的进展情况。他们回顾了
两国教育部长的互访，并十分高兴地看到，在两国外交部长于一
九七八年十月六日在罗马签订文化和科技合作协定之后，在这些
方面所取得的具体的和有意义的成果。
此外，对于今年十月十五日至十九日在罗马举行的执行中意
文化、科技合作协定的第一次双边工作会议的圆满结束表示特别
满意。会议结束的时候，本着友好的精神签订了确定今后两年内
进行交流的合作计划。
在迄今已取得的成果的基础上，并按照上述合作计划指出的
有利前景，中华人民共和国国务院总理华国锋和意大利共和国总
理弗朗切斯科。科西加表达了各自政府将通过以下倡议进一步扩
大和加强两国文化和科技合作的共同愿望;
(1)促進大學之間的合作;
(2)加強兩國教育方面代表團的互訪;
( 3 )增加社会科学和自然科学奖学金名额
(4 )两国文化机构间的合作;
(5 )艺术、戏剧活动的交流;
(6)通過執行共同商定的合作計劃,包括共同研究,發展在
医学、空间、化学和核物理等方面的科技合作;

(7 )促进两国广播、电视机构间的直接联系;
(8 )双方努力加深对方的语言和文化知识，特别是通过在各
自的大学里增加这方面的教学活动。
中華人民共和國國務院總理華國鋒和意大利共和國總理弗朗
切斯科‧科西加都強調文化和科技合作對進一步加強中意兩國人
民之间存在的友好关系的重要性。
本意向书一九七九年十一月六日签于罗马，一式两份，用中
文和意大利文写成，两种文本具有同等效力。
中华人民共和国国务院总理意大利共和国总理
华國锋弗朗切斯科，科西加
