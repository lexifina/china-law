# 中华人民共和国政府和摩洛哥王国政府关于中国派遣医疗队赴摩洛哥工作...

中华人民共和国政府和摩洛哥王国政府
關於中國派遣醫療隊赴摩洛哥
工作的議定書
中華人民共和國政府(以下簡稱“中方”)和摩洛哥王國政
府〈以下简称“摩方")為加強兩國之間的醫療合作,經友好
协商，达成协议如下:
第一条
根据摩方要求，中方同意派遣几支中国医疗队(以下簡稱
“中国医疗队”)赴摩治哥工作。具体科别、人数及工作地点详
見本議定書附件,該附件為本議定書的組成部分。
第二条
中国医疗队将与摩方医务人员密切合作，相互交流经验，并
协助对摩方医务人员进行在职培训。
第三条
中國醫療隊員在摩洛哥的工作期限自其抵達之日起為兩年。

第四条
中方义务:
(一)中方负担中国医疗队员在摩工作期间的工资;
(二)中方负责派遗4名医疗队总队部管理人员，并负担其
国际旅费和生活费，他们的任务是管理和协调中国医疗队员在摩
期间的工作和生活;
(三)中方提供中国医疗队在摩开展工作所需的部分药品、
器械、針灸用具、個人物品和日常生活用品,並負責運至摩洛
哥,含運保費;這些藥品、難械和針灸用具由中國醫療隊保管和
使用。
第五条
摩方义务:
(一)摩方负责向中国医疗队员提供月津贴，津贴金额将根
据中国医疗队员的级别(专科医生、队长或其他队员)以及他
们将被派往按摩洛哥现行法规所划分的A、B、C类地区工作的
不同大區、省份來確定,具體標準如下:
地区类别专科医生和队长其他队员
六(+号) 3750迪拉姆
B(+15% ) 3450迪拉姆
C (+全部) 3300迪拉姆
该津贴经审核后，由摩方于每月月底拨付到中国医疗队在拉
巴特馬格里布銀行開立的N?2621 01006671的賬戶內;根据摩洛
哥現行法規,該津貼總額的50%可汇出;
(二)负担医疗队员往返摩洛哥和中国的国际旅费;
(三)无偿为医疗队员提供配备家具和设备的住房(含水電
费) ;

(四)负责提供医疗队员工作和生活所需的交通工具，包括
医疗队员的轮换接送、日常工作和生活及在摩境内的旅行;
(五)提供医疗队员工作所需的外科医疗设备、器械、药
品、醫用敷料和化學試劑等;
(六)根據摩洛哥現行法規,方便辦理中方提供給醫療隊的
药品、器械等报关、提取和免税手续，并负责在摩境内的运输;
摩方根据现行法规，对中国运往摩洛哥供医疗队使用的药
品、器械、个人物品和日常生活用品，对中国医疗队所使用的进
口公务车辆，将免除海关税、捐税和税款
(七)提供中国医疗队员每两年一次在摩境内度假的交通及
在摩衛生部所屬的地方住宿。
(八)為醫療隊員及其家屬(在赴摩探親的情況下)申请签
證提供便利。
第六条
中国医疗队员和摩洛哥行政部门公务员和公职人员一样享
受同等的条件下摩洛哥现行法令法规规定的关于工伤事故赔偿的
同等待遇。
第七条
中國醫療隊員在摩洛哥工作期間,享受中方和摩方各自規定
的節假日,並享受每年一個月的帶津貼休假。
第八条
中國醫療隊員在摩洛哥期間,應遵守摩洛哥現行法律、法
規,尊重摩洛哥人民的風俗習慣,不從事法醫工作。
第九条
本議定書如有未盡事宣或在執行中發生異議,雙方將通過友

好协商解决。摩洛哥王国卫生部有责任要求摩方有关部门和负责
人了解并执行本议定书的各项条款。
第十条
本议定书自签字之日起生效，有效期为两年。如双方默示继
，本议定书将自动延长同样的期限。如任何一方提出终止本协
入次
，需在到期前6个月书面通知对方。
本议定书于二OO六年四月二十四日在拉巴特签订，共两
份，每份均由中文、阿拉伯文和法文写成，双方各执一份，三种
文本同等作準。
