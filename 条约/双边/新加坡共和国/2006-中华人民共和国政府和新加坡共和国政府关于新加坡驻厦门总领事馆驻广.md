# 中华人民共和国政府和新加坡共和国政府关于新加坡驻厦门总领事馆驻广...

中华人民共和国政府和新加坡共和国
政府關於新加坡駐廈中鼠領事之
驻广州领事办公室升格为新加坡
旦广州总领事馆的换文
中方去文
(2006)部领字第145号
新加坡共和國駐華大使館:
中華人民共和國外交部向新加坡共和國駐華大使館致意,並
諾確認收到大使館2006年3月30日第BEJ/039/2006号照会，
內容如下:
“新加坡共和国驻华大使馆问中华人民共和国外交部致意，
并说代表新加坡共和国政府确认，新加坡共和国政府和中华人民
共和国政府本着进一步发展两国友好关系和加强两国间领事合作
的共同愿望，经过友好协商，就新加坡共和国驻厦门总领事馆驻
广州领事办公室升格为新加坡共和国驻广州总领事馆事达成协议
如下:
一、中华人民共和国政府同意新加坡共和国驻厦门总领事馆

驻广州领事办公室升格为新加坡共和国驻广州总领事馆，领区为
广东省、海南省、湖南省、贵州省、云南省和广西壮族自治区。
新加坡共和国驻厦门总领事馆领区相应调整为福建省和江
西省。
二、中华人民共和国政府将根据1963年4月24日《维也纳
領事關係公約》及中華人民共和國的有關法律和規定,為新加
坡共和國駐廣州總領事館的設立及執行領事職務提供一切必要的
協助和便利。
三、双方将根据包括1963年4月24日《维也纳领事关系公
约》在内的国际法及国际惯例，并本着对等原则，通过友好协
商解决两国领事关系中可能出现的问题。
上述內容如蒙中華人民共和國外交部代表中華人民共和國政
府复照确认，本照会和中华人民共和国外交部的复照即构成新加
坡共和国政府和中华人民共和国政府的一项协议，并自外交部复
照之日起生效。
中华人民共和国外交部谨代表中华人民共和国政府确认，同
意上述照会内容。
順致最崇高的敬意。
中華人民共和國外交部(印)
二DO六年四月十三日于北京
