# 中华人民共和国和格林纳达引渡条约

中华人民共和国和格林纳达引渡条儿
中华人民共和国和格林纳达(以下称双方)，
在相互尊重主权和平等互利的基础上，为优进两由在
打击犯罪方面的有效合作，
决定缔结本条约，并达成协议如下:
第一条引渡義務
双方有义务根据本条约的规定，应对方请求，相于习|
淡在一方境内发现的被另一方通缉的人员，以便对其进行
刑事诉讼或者执行刑罚
第二条”可引渡的犯罪
一、只有在引渡请求所针对的行为根据双方法律均构
成犯罪，并且符合下列条件之一时，才能准予引渡:
(一)为进行刑事诉讼而请求引渡的,根据双方法律，
对于该犯罪均可判处1年以上有期徒刑或者更重的刑罚|
(二)为执行刑罚而请求引渡的,在提出引渡請求時,

被請求引渡人尚未服完的刑期至少為6個月,
二、根據本條第一款確定某一行為是否根据容方湛律
均构成犯罪时，不应考虑双方法律是否将该行为归入疝_
犯罪种类或者使用同一罪名.
三、如果引渡请求涉及两个以上根据双方法律均构成
犯罪的行为，只要其中有一项行为符合本条第一款规定的
条件，被请求方即可以针对上述各项行为准予引渡，
第三条”应当拒绝引渡的理由
有下列情形之一的,應當拒絕引渡:
(一)被請求方認為,引渡請求所針對的犯罪是政治
犯罪,或者被請求方已經給予被請求引渡人受庇護的權帛,
仙人
治犯罪的不应视为政治犯罪
(二)被請求方有充分理由認為,請求引渡的目的是
基于被请求引渡人的种族、性别、宗教、国籍或者政治见
解而对该人进行起诉或者处罚，或者该人在司法程序中的
地位将会因为上述任何原因受到损害;
(三)引渡请求所针对的犯罪仅构成军事犯罪;
(四)根据任何一方的法律，由于时效已过或者珊锡

等原因,被请求引小人已经被免予追诉或者免予执行刑园;
(五)被請求方已經對被請求引渡人就引渡請求所針
对的犯罪作出生效判决或者终止刑事诉讼程序;
(六)被請求引渡人在請求方曾經遭受或者可能遭受
酷刑或者其他工忍,不人道或者有奎人格的待遇或者外加
第四条”可以拒绝引渡的理由
有下列情形之一的,可以拒絕引渡:
(一)被请求方根据本国法律对引渡请求所针对的犯
罪具有刑事管辖权，并且对被请求引渡人就该犯罪正租进
行刑事訴訟或者準備提起刑事訴訟;
(二)被请求方在考虑了犯罪的严重性和请求方利益
的情況下,認為由說被請求引渡人的年齡、健康或者其他
个人原因，引渡不符合人道主义考虑，
第五条国民不引渡
一、双方均有权拒绝引渡本国国民。
二、恕果根卸本條第一款規定未准予引渡,被請求方
应当根据请求方的请求，将该案件提交主管机关以便根据

第入条”联系途径
为本条约的目的，双方应当通过外交途径进行联系，
但本条约另有规定的除外。
第七条引渡请求及所需文件
一、引渡请求应当以书面形式提出并包括以下内容:
(一)请求机关的名称;

(三)有关犯罪事实的说明,包括犯罪的时间、地点、
行为和结果;

第八条”补充材料

限內提交補充材料,應當被視為自動放棄請求,但是媚芒
碍请求方就同一犯罪对同一人重新提出引渡请求。

途径以书面形式提出。
二、臨時羈押請求應當包括本條約第七條第一款所列
內容,並說明已經徐有第七條第二款所列文件,以及即將
提出正式引渡請求,
三、被请求方应当将处理该请求的结果及时通知请求
方,
四、如果被請求方在羈押被請求引渡人之後的45必內
未收到正式引渡請求,則應當解除臨時暴押。經請求己合
理要求，上述期限可以延长15天。
五、如果被请求方随后收到了正式引渡请求，则根据
本條第四款解除臨時羈押不應妨礙對被請求引渡人的引
渡。

第十条”对引渡请求作出决定
一、被请求方应当根据本国法律规定的程序处理引渡
请求，并且及时将决定通知请求方。
二、被請求方如果全部或者部分拒絕引渡請求,說當
将理由告知请求方。
第十一条”移交被引渡人
一、如果被请求方准予引渡，双方应当商定执行引渡

人在移交之前已經被羈押的時間告知請求方,
二、如果請求方在商定的批行引渡之日後的15天內未
接收被引渡人，被请求方应当立即流放该人，并且可以拒

请求方应当根据被请求方的要求，及时间被请求改通

在被请求方的引渡程序中产生的费用应当由被请求
方承担。与移交和接收被引渡人有关的交通费用和过境费
用应当由请求方承担。
