# 中华人民共和国政府与泰王国政府关于泰国在青岛设立总领事馆的换文

中华人民共和国政府
与
泰王國政府
關於泰國在青島
設立總領事館的換文
中方去文
秦王國駐華大使館:
中华人民共和国外交部向泰王国驻华大使信致塌，并
謹確認收到大使館二O一四年二月十二日第11001 / 105號
照會,內容如下:
“秦王国驻华大使信向中华人民共和国外交部致意，
并说代表秦王国政府确认，泰王国政府和中华人民共和国
政府本着进一步发展两国友好关系和双边领事关系的共同
愿望，经过友好协商，就泰王国在山东省青岛市设立总令
事馆达成协议如下:
一、中华人民共和国政府同意秦王国在青岛设立总令
事馆，领区为山东省
二、泰王国政府同意中华人民共和国保留在泰王国设
立领事机构的权利。设领地点、领区范围等事宜，双方将
通過外交途徑兄行商定,
三、双方将根据一九六三年四月二十四日《维也纳令
事关系公约》以及两国各自有关的法律规定和对等原则，

为对方在本国设立领事机构和执行领事职务提供一切必要
的協助和便利,
四、双方将根据包括一九六三年四月二十四日《维也
纳领事关系公约》在内的国际法及国际惯例，并本着对等
原则,通过友好协商解决两国领事关系中可能出现的问题。
上述内容如蛇中华人民共和国外交部代表中华人民
共和国政府复照确认，本照会和外交部的复照即构成泰王
國政府和中生人民共和國政府間的一項協議,並自外六部
复照之日起生效。”
中華人民共和國外交部店代表中和芥人民共和國政府
确认，同意上述照会内容。
順致崇高的敬意,
中华人民共和国外交部(印)
二O一四年三月日於北京

泰王国驻华大使馆向中华人民共和国外交部致意，并说代表
泰王國政府確認,泰王國政府和中華人民共和國政府本著進一步發展兩國
友好關係和雙直領事關係的共同點望,經過友好協商,就泰王國在山東衝
青鸟市设立总领事馆达成协议如下;
一、中华人民共和国政府同意泰王国在青岛设立总领事馆，
领区为山东省。
二、夾王國政府同意中華人民共和國保留在泰王國設立領事
發構的權利。設領地點、領區范圍等事宣,雙方將通過外交途徑另行商定。
三、双方将根据一九六三年四月二十四日《维也纳领事关系公
約》以及兩國各自有關的法律規定和對等原則,為對方在本國設立領事機
人和执行领事职务提供一切必要的协助和便利。
四、双方将根据包括一九六三年四月二十四日《维也纳领事关
系公约》在由的国际法及国际惯例，并本着对等原则，通过友好协商解决
两国领事关系中可能出现的问题。
上述内容如蒙中华人民共和国外交部代表中华人民共和国政府
复腿确认，本照会和外交部的复照即构成泰王国政府和中华人民共和国
政府间的一项协议，并自外交部复乳之日起生效。
順致崇高的敬意。
泰王国驻华大使馆《〈印)
