# 中华人民共和国政府和津巴布韦共和国政府关于互免持外交、公务护照人...

中华人民共和国政府和津巴布韦共和国
政府关于互免持外区、公务护照人员
侈证的这解备悉录
前言
中华人民共和国政府和津巴布韦共和国政府《〈以下合
称“舌约双方”，分称“舌约一方” );
鉴于两国业已存在的友谊和团结:
为进一步发展两国的友好关系,便利两国公民的往
來;
根据平等互圳原则，经过友好协商就互免持外次私
公务护照人员人验证问题;
达成谍解如下:
第一条免签
中华人民共和国持有歼的中华人民共和国外交、公务
护照的公民和津巴布韦共和国持有将的津巴布韦共和国外
交、公务护照的公民,在缔约吨一方国家入境、出卉或者

光境,免辦金證。
第二条入境、過境和出境
本徐夸錄第一祭所述縮約一方國家公民應從縮約另
一方国家疝国际旅客开放的口崖入境、出卉或者过境，并
應當依照締約另一方主管机關的規定懂行必要的手續,
第三条庭守法律和法规
一、紀約一方國家公民在縮約男一方國家停留期間,
應當遵守紀約另一方國家現行的法律和法規。
二、本价人忘錄第一條所述縮約一方國家公民,恕需在
締約另一方國家境內停留逾60日,应当依照缔约另一方主
管机关的有关规定欢理登记手续。
第四条正式访问
绪约一方的中央政府副部长级及以上职位的官员和
年队少将级及以上插衔的军官，因公前往纺约另一方国家
之前,應當通過外交途從通報縮約另一方相應主管部門。

第五条不受欢迎的人/不可接受的人
本備忘錄不限制任何締約一方拒絕不受歡迎或不可
接受的人进入本国领土或终止其在本国领土上的停留的权
利，并无须说明理由。
第7条備忘錄的中止
由於國家安全、公共秩序或公共衛生等原因,縮約任
何一方可痢时中止本备总录的全部或部分条歌。但在孕取
或者取消上述措施前，绪约一方应通过外交途径提前14晶
节面通知缔约万一方。
第七条交換所照樣本
一、縮約雙方應當在本備忘錄笙奢之日起30日內,通
贍外次途從交換本備畫錄第一條所述擴照的樣本,。
二、在本備忘錄有效期內,締約一方如更新本備羽錄
第一条所述护照样式，应至少提前30日通过外交途径通知
締約史一方,並提供新護照的樣本,。

第八条保客
缔约双方应对双方同意的保密信息履行保密义务，除
非缔约一方书面同意对特定信息放弃保唤要求。缔约双方
的保密义务不因本备筷录的终止而解除。
第九条爭議解決
缔约双方对于本备穆隶实施产生的任何争议应通过
外交途径友好协商或谈判解决。
第十条生效和有效期、修订和终止本备筷录
一、结约一方完成本备扎孙所需的国内法律程序后应
當通過外交途徑通知締約另一方,本備忘錄在後一份通知
發出之日起第30日生效。
二、本備忘錄長期有效,。
三、恕縮約一方要求終止本備忘錄,。應當通過外次途
径书面通知绪约另一方。本备起隶自上述通知发出之日起
第90日失效。

四、本备息录经双方书面同意可进行修改。
下列銓署人,經各自政府正式授權簽署本備忘錄,以
昭信守。

订，一式两份，每份均用中文、英文寫成,兩種文本同等
作准。
