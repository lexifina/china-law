# 中华人民共和国政府与澳大利亚政府关于加强投资合作的框架协议

中华人民共和国政府与澳大利亚政府
关于加强投资合作的框架协议
中华人民共和国政府与澳大利亚政府〈以下称“双方”)，
考处到中国和澳大利亚两国建交42年来，双边关系取得多
元化发展，双边合作不断深化，特别是2013年4月两国建立战
略伙伴关系，成为互利双边关系发展的重要里程碑:
认识到中国正在全面深化改革，澳大利亚继续调整经济结
构，两国经济结构高度互补，合作洪力巨大,两国经济结构调整
和和轉型發展為進一步加強雙向投資合作注入新的需求和動力;
根据2014年6月首次中首战略经济对话期间两国有关部门
达成的加强投资合作的共识，以及为在中省战略经济对话框习下
通过拓展和深化投资合作进一步促进中首战略伙伴关系的深入
发展;
就按以下条款执行本加强投资合作的框架协议达成一致:
第一条总体目标
一、沙实中澳战略经济对话期间达成的共识,按照互惠互乔
的原则,为实现优进中澳两国双边投资合作的首要目标,引导企
业并优进在新领域的投资,为两国经济社会发展和扩展双边经济
关系做出页献;
二、绪合两国各自经济发展和改革的重点，加强投资合作;
根据两国的发展战略,为增加双向投资和创造更多就业机会创造
有利条件;

三、为两国企业和金融机构在各重点领域开展优势互补、互
利共赢的合作努力创造良好环境和条件;
四、通過明確次向投資流動遇到的障礙,制定互利互惠的成
略，消除这些障碍并促进跨境投资流动，豐富雙邊經濟技術合作
和戰略伙伴關係的內涵,
第二条重点领域
一、双方认识到，中澳两国同为亚太地区重要国家，拥有共
同利益。两国双这经济关系互补性强。中省之间广泛的贸易关系
和不断增长的投资合作关系形成了进一步促进更广泛的双按投
资流久的良好基础。
二、在此基础上上，双方确定的初期投资合作重点领域包括但
个限于:能源资源、基础设施、农业、制造业、服务业。
三、对话将每年回顾这些和看扣领域，并制定工作计划，促进
在本框架协议下相关领域的投资.
四、在上述重所领域中，两国之问的合作将包括但不限于以
下领域:
(一)能源资源领域
双方将优进能源资源领域的投资合作，包括提高能效。
双方将歌励太业茧探、开发、生产和如产品加工等方面的合
作,。
(二)基础设施领域
雙方將鼓勵兩國企業在基礎設施發展方面開展投資合作.。
双方将评估多种促进合作的方式包括建设-转让(BT)、建设
-运营-转让(BOT )、政府和社会资本合作(PPP )等加强基础设
施领域的投资合作.

(三)农业和食品领域
双方将吾励两国企业在农业及相关领域的投资合作,优进农
业现代化及农业和食品供应链的融合，提高农业生产力，增加农
产品产量，为两国及全球市场提供优质农产品.
(四)制造业领域
雙方將鼓勵兩國企業在制造業領域開展投資合作,合作领域
可包括:太產品加工、先進製造業、高技術、制約和醫療技術,
(五)服务业领域
雙方將鼓勵兩國服務業領域合作,包括旅游业、育幼、医疗、
养老、文化、教育和金融服务业等。
(六)其他领域
双方同意探讨在其他领域的产业投资合作。
第三条組織實施
一、双方同意将通过2013年4月建立的中澳战略经济对话
协调、推丸和误励本框架协议下各相关领域的合作。
二、有双方在中澳战略经济对话框架下的投资合作，中方由中
國國家發展和改革委員會率頭,澳方由澳大利亞聯邦國庫部、外
貿易部率頭,兩國相關部門、企業、金融机構、研究機構等根
据需要共同参与。
三、中澳戰略經濟對話雙方主席(中方主席為國家發展改單
委主任、澳方主席為國庫部長、娘易投資部長)負責把握本框架
協議下投資合作的戰略方向,
四、两国相关政府机构将在双方主打的指导下开展推动投资
合作的日常工作,。
五、双方将通过以下活动推动两国投资合作:

(一)交流两国相关法律法规和投资政策，探讨为两国企业
开展合作创造良好的政策环境;在兩國政府政策指引下,促進跨
境投资，并注意到投资者对其尽职调查负责;
(二)在双方及与企业间，就两国在各级政府层面影响投资
决策的政策进行信息分享和交流;
(三)根据企业合作需求、两国经济目标和各自经济发展重
反领域的变化等因素，在双方协作和达成共识的前提下，更新投
資合作重點領域清單;
(四)根据两国的法律和企业社会责任的共同守则,为开展
跨境投資合作的企業提供一般性建議;
(五)组织项目推介会等投资促进活动,确定潜在的投资机
会，优进对两国政治、法规和法律框架的共同理解;
(六)至励两国金融机构、研究和培训机构、智库和类似组
织等为企业开展投资合作提供所需的融资、研究、人力资源及其
他方面的服務,以支持兩國企業問不斷發展的投資合作;
(七)在政府層面合作,支持企业在对方国家确定洪在的投
次合作伙伴;根据现有的政策框架，确定并制定应对阻碍两国间
更大规模投资合作的方案，
第四条爭端解決
在本杠展协议解释和执行过程中产生的纠纷应通过双方协
商友好解決。
弟五祭費用
除非及有和書面約定,双方各自承担其代表在本国执行或解释
本框架協議所發生的費用,。

第六条生效和终止
本框潑協議自雙方簽署之日起生效,有效期5年,恕任何一
方未在有效期滿前至少6个月以书面形式通知对方终止本框架
协议，则本框架协议有将期自动延长5年,並依此法順延。
第七条修改
经双方一致书面同意，可对本框架协议进行修改。
第八条框架协议的地位
本框架协议并非条约，不受国际法约束.
雙方可在框架協議下就具體領域的合作制定其他的執行協
議和百解備軋錄。
本框架协议于二O一四年十一月十七日在堪培拉签订，一
式兩份,每份均用中文和英文寫成,兩種文本同等作準,。
