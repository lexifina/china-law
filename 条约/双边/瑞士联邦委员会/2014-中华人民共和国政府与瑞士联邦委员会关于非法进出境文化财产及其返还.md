# 中华人民共和国政府与瑞士联邦委员会关于非法进出境文化财产及其返还...

中华人民共和国政府
好
瑞士联邦委员会
关于非法进出境文化财产及其返还的协定
中华人民共和国至持与瑞士联检委员会《兴下称'双方”》，
作为联合国孝科文组织(UNESCO )丁一九也0年十一月十
四日通过的《关于禁直和防止韭法进出境文化财产和非法转让其
所有祝的志波的公约》的纺约国;
考虑到盗密、动掠和非法进出境文化财产不利于正常的文化交流;
认识到文化峙产的流失将对人类文化遗产带求危害:
致力于为文化遗产的保耸与保护艇出贡献并防止文化财产
的非法轉讓:
秉承两国之合作可在此领域做出重要页献的理念;
致为于使非法进境文化财产的返还更加便捷并加强两国问
文化交流的联系;
考虑到国家加在科学、文化和教育方面而进行的文化财产交
流，会提升人类文明的知识，丰寅全人类的文化生活，数发国家
洱的相互尊重和欣赏，
達成如下協定:
第一条對象
--、本协定着在规范与协定双方诅基的文化财产的入境、转
移和返还等行为。
一、本协室仅适用于协定际录中所列类划的文化财产-
第二有余入境范国

一、广化周产可进境至本协定一方,但需向海關證明其已殿
行协定另一广文化财产出境的有有关规定.如果本协定方的法律
規定文共財產出境及出凌許可斌,文化財產出境至另一方嬰,則
须底协定六一方的海兴出了示广化赔产出境许豆证。
二、海关申报须包括以下枢糙:
(一)文化财产类别;
(二)有关文化财产制作项点尽可能详细挟摘述;如為才全
或吉生物出土文物,則需說明該文化財產的出土地點.
第三条返還要求:权池、送半法律、文持
一、如本协定一方的文化赚产非法入境至协定鸣……方境内，
则该方可向另一方提出要求返还文化出产的诉讼。
二、诉讼相向文化财产所在地有管辖权的法院提起。
三、文化珊产所在地的协定一方的国内法律决定诉讼的前提委件，
四、报据本读定第八条，文化册产所在地的主管部门在其权
限之內對提起訴訟的一方比供以下爭議和支持:
(一)確定文化如產所在地雯;)
(二)明确有管辖权的法院;
(三)提供专业法律代衣;
(西)为文化时产提供临时监管和颂护直至其返还。
第四条返还范围:形式
一、提起诉讼的执定方必须证的:
(一)该文化财产虹于本协定附东中所列的文化则产类别，民帮
(二)该文化周产是在本协定生效之后
被非法入卉至协定另一方的
二、如国武装冲窗、自然灾密或者其他危及本雇定方文化册
产揭特殊事件等造成在返还过程中得提起诉讼一方境内无法保
证出该文化财产的保护，别另一方可暂缓执行文化中产的撑还，

真至六文化由产在返还过程中的保护得到保证为止。
三,本协定一方殿出返逊文作风产的于求的期限为其主管部
获知谈义化财产让落及持有者信息的一年文肉,但最迟不得超
謊該文化過產非法出境拓的30年.
第五条返还藻围:费用、补偿
一、提起诉讼的本协定一方承担获取、保管和返还文化财产
所必需的費用,
二、拒起訴訟的本協定-方必須向該文化出產的善意取得者支
卻兢用,交根自其購買的價格以及為保護和保管文化財產所花費的
必要和有用的开支，得该文化财产返还时对其给予补偿。
三、倒照本协定第三条之规定爱理诉讼案代的本协定一方主
审法许筑定补全的金髓.
四、被要承返謂文化則產的個人在旗得罕僕前有權繼績持有
該文化期處,
第六条通报要求
本协定双方须向与本协定有关的部门和机构，如海关、刑事
检察补关和艺术上则交易组织等通报本协定的内容。
第七条”对返还的文化财产的处理
提出诉讼的本协定一方有义务确保返还的文化财产得到合
理保護,並為在另一方境內六其過行研究和展覽提供便利.
第八条主管部門
一、及方执行本协定的政府主管部生为:
(一)中华人民共和国:国家文物局;
(二)瑞士联帮:联邦内务部文化周产转让事备特别机构(联
邦至府文化事篆好公室)。

二、授权上述机攀在各昼权限内与丈方进行直接合作.
三、土述括构在市协定生汝后谷此交换有闪电话和传真号
码，并在己能的情况小各自指定一个通蜡对方语言的联络人.
四.总与本条条1坎积第2款有关的职能权限或指定机杭发
生性化，上述机鸭须立兄让对方通报.
第九条交換信息
一、本协定妈方通过本请定第八条确定的政府主管部门相互通
报涉及除件所列类别的文化嫩产的次村、支掠、丢失和其他行为
一、本協定數方將太時向別方通報客自國內有關文化財產鞭
让艇法律的任何修订-
第十条五惠约定
为执行本协定,本协定双方将与负责打击文化周产非法转欧
的国际机梅合作，比姬，联合国教科文组织(UNESCO )、国际
刑警组织【Interpoi)、国际捕物馆协会【ICOM )和世界海關組
織(WCO)等-
第十一条后续事家
一、本协定第八条中确定的双方政府主管部门将定期检查本
协定的执行情况，如有必要，将提出修改意见。奴方亦可讨论进
一步推进文化交流领域合作的演议，
一、肥方政府主管部门的代表最达在本协定有殖期结束尘会
晤,會晤在中國和瑞士輪流進行。此外,也可在本協定一方朝出
要求時會晤,特别是在与文化赔产转让有关的法律和行政法规发
生重大修订外。
第十二条与其他国际协定的关系
本寺定不影響雇定品方必行各自男入的其他區際,多这或者

骏边接定的义务。
第十三条意見交換和分歧解決
-、本协定第八条中确定的双方政府主管部门可就本视定的
总体执行情况或者具体问题以世面形式交换意见或者和过会肯
口头交换意见.
二、如对有基本协定的解释、应用和执行发生分战，双方可
通过协商和谈判加以解决.
第十加条势定的时限和协定终止的影响
一、潮定骏方将在各自完成本协定乍铭所肪的国内法律程序
后通知允方.本协定自收到后一份通知之日起第30日生效.
一、本壕定让势定生豆之日起五年内有效，如协定期满前6
个月任何一方未书面通知页方八目本埠定,则读定有效期自动延
長5年,
三、本協定的終井對尚未從淋的返還染件不產生影響,
本协定于二加一三年八月十六日于北京签订，一武两份,每
份均以中文、法文和英文書就,三種文本具有同等效力,如對文
本的解程發生分歧,以英文本謂淮.
