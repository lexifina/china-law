# 中华人民共和国政府和约旦哈希姆王国政府文化协定一九八六、一九八七...

中华人民共和国政府和约旦哈希姆王国政府
文化协定一九八六、一九八七、
一九八八年執行計劃
中華人民共和國政府和約旦哈希姆王國政府,為實施兩國政
府一九七九年十一月十一日締結的文化協定,加強兩國人民的友
好關係,發展兩國的文化合作,決定簽署本計劃,祭文如下:
一、文化和艺术
第一条“双方交换文化艺术方面的书籍和印刷品，互办文化
书籍展览。
第二条“双方鼓励档案工作者互访，考察档案工作，交换档
案出版物和具有历史价值文献的副本，具体事宜通过外交途径
商定。
第三条”双方通过互派讲学者和专家，互换资料，互派文化
机构工作人员访问，加强文化领域的合作。
第四条“双方鼓励互办造型艺术展览并互派艺术家访问。中
方於一九八七年或一九八八年派三至五人藝術家考察團訪問
约旦。
第五条”双方鼓励互派剧团、乐团、演奏家和民间艺术团访
问。其人数和访问细节，则通过外交途径商定。
二、高等教育
第六条“”约方每年向中方提供三名奖学金，在约旦有关大学
學習阿拉伯語,为期四年。中方将根据需要派址大学生或进修生。
约方向中国留学生提供住宿、免收学费、教材费、医疗费，并发

給每人每月三十五第納爾生活費(含伙食費和零用費)。
第七条”中方每年向约方提供五名奖学金在其大学学习。中
方向約旦留學生提供住宿,免收學費、教材費和醫療費,並發給
每個人每月人民市一百八十元(本科生)或二百元(進修生)的
生活费。中方另向约方提供五名自费生的名额。
第八条”双方互换一个三至四人的教育代表团到对方进行一
至二周的考察访问。具体事宜提前三个月通过外交途径商定。
第九条双方鼓励并促进两国高等院校建立直接的校际
联系。
三新闻
第十条”双方鼓励广播、电视方面的合作，交换广播、电视
节目和新闻素材。两国广播、电视机构互派代表团访问。中方于
一九八六年接待约且三至五人的新闻代表团访问两周。
第十一条“双方鼓励两国官方通讯社交换消息和新闻报道，
為通訊社和報社記者提供必要的方便。雙方促進約旦佩特拉通訊
社与新华通讯社之间签订一项双边合作协定。
四、体痛
第十二条(1)签约双方鼓励通过在两国间举行比赛和互派
体育专业人员访问，发展体育关系;
(2)雙方鼓勵中華人民共和國派遣專業教練赴約旦任教,並
举办训练班。体育专家和教练的经费，由两国有关方面就此细节
签订双边协定;
(3)雙方鼓勵兩國體育負責人互訪,了解體育成就,並交流
体育各方面的经验。
以上各项需通过外交途径商定。

五、社会发展
第十三条”双方鼓励从事社会福利和发展本国社会工作的专
家互訪,雙方於一九八七年互派五人左右的社會福利和發展工作
者代表团访问两周，了解对方的成就、活动并交流经验。具体事
宜通过外交途径商定。
六、衛生
第十四条”双方鼓励交流卫生、科学方面的经验，鼓励卫生
事務專職人員互訪,了解卫生领域的制度和方法，并进行培训。
七、其他规定
第十五条派遺方至少提前兩個月,通過外交途徑將代表團
訪問日期、目的和人數通知接待方。
第十六条“双方可通过外交途径直接联系，提出增加本计划
未列入的其他合作项目。
第十七条本计划交流项目的国际旅费由派遣国负担;接待
国负担国内的接待费用。
第十八条”本计划自签字之日起生效。
本計劃於一九八六年三月十三日在安曼簽訂,一式兩份,各
用中文和阿拉伯文寫成,兩種文本具有同等效力。
中華人民共和國政府约旦哈希姆王国政府
代表代表
