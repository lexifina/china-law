# 中华人民共和国政府与芬兰共和国政府社会保障协定

中华人民共和国政府和芬兰共和国政府
社会保障协定
中华人民共和国《〈以下称中国或缔约一国)政府和分兰共和
国〈以下称芬兰或缔约一国)政府為規范兩國在社會保障領域的
相互关系，达成其议如下:
第一部分总則
第一条定義
一、为本协定之目的:
(一)法律规定
在中國,系指本協定第二條第一歌第一項運用范圍所包括的
社会保险制度相关的法符、行政法规、部门规章、地方性法规和
其它规定:;
在分兰，系指本协定第二条第一球第二项适用范围所包括的
社会保险制度相关的法律法规。
(二)主管机关
在中国，系指人力资源和社会保障部:;
在芬兰，系指社会事务和卫生部。
(三)经办机构

在中国，系指人力资源和社会保障部社会保险事业管理中心
或由該部指定的其它機攀;
在芬蘭,系指負貢實施本協定第二條第一款第二項所規定的
法律及制度的機構或組織。
(四)领土
在中国，系指《中华人民夫和国社会保险法》以及相关法律
法规适用的领土;
在芬兰，系指分兰的领土。
(五)国民
在中國,系指具有中華人民共和國國籍的個人;
在分兰，系指国籍法所定义的分兰国民。
二、本條中未定義的翊語應具有縮約兩國各自适用法律規定
器子的含义。
第二条”法律适用范国
一、本协定适用于与以下社会保险制度相关的法律规定:
(一)在中国
1.職工基本養老保險,
2.失業保險。
(二)在分兰
1.与收入相关的年金计划下的老年、和残疾和和遗属年金
2.失業保險。

二、除非本协定另有规定，本条第一款所提及的法律规定不
包括缔约一国与第三国在社会保障方面缔结的条约或其它国际协
定,以及為具体實施之目的頒布的法律規定,
第三條人員計用范圍
除非另有规定，本协定将适用于正在或曾经受第二条所提及
法律规定管辖的所有人员，及从这些人员获得权益的其他人员。
第四條平等對符
除非本协定另有规定，第三条所提及人员在适用缔约一国法
律规定时，应当受到与该国国民平等的对待。
第五条待遇輸出
除非本协定另有规定，缔约一国不应仅因为待遇领取人停留
或居住在缔约另一国或第三国领土上而减少或改变依据缔约一国
法律規定獲得的待遇,。
第二部分“关于适用法律的规定
第六條一般規定
除非本协定为有规定，在缔约一国领土上受雇或自雇的人
只,就該項工作而言,僅受該縮約國法律規定管轄。
第七祭”派查人員和自雇人員
一、邵采殿员在缔约一国领土上受雇于在该缔约国领土有经
之場所的雇主,依其應全關人系被雇主派往縮約另一國領土為該雇

主工作,該雇員就該雇佣關係而言繼續僅適用首先提及締約國的
法律規定,如同該雇員仍在該締約國領土受座一樣,祭件是該泊
遺期限不超過60個日曆月,
二、受缔约一国法律规定管辖并且通常在该国领土上工作的
自记人员，临时到缔约另一国领土上从事自雇工作，该人员应仅
受首先提及缔约国法律规定管辖，如同该人员仍在该国领土上自
雇一样，条件是其在缔约另一国领土上从事自雇活动的期限不超
过60个日历月。
三、若本条第一款和第二款所提及的雇们或自雇期限超过
60个日历月，缔约两国主管机关或经办机构可同意该雇员或自
雇人员继续适用首先提及缔约国的法律规定。
第八条航海船舶和航空器上的雇员
一、在巷挂任一縮約國船旗的航海船舶上受座的人員誠用該
紀約國的法律規定。但是,恕果該雇員通常居住在締約一國領土
上,被在同一縮約國的雇主派遣到研挂締約另一國國旗的航海船
骨上工作,則該雇員适用首先提及締約國的法律規定,如同該應
員仍在該縮約國領土上受雇一梓。
二、在航空右上受雇的飛行人員,就其應佣關係而言,造用
其受懂企业总部所在地领土所属的缔约国法律规定。但是，如果
该企业在缔约另一国领土上拥有代表机构，则受雇于该代表机构
的人员将受该代表机构所在地领土所属的缔约国法律规定管辖。

第九条”外交、领事机构人员和公务员
一、本示定不影響一九六一年四月十八日從訂的《維也納外
交夫系公約》和一九六三年四月二十四日從訂的《維也納領事商
系公约》的适用。
二、公人務員及類似人員受其雇佣机构所在締約國法律規定管
乏。
第十条例外
缔约两国主管机关或经办机构可同意根据等定人员或人群的
情况对本协定第六至九条作例外处理，条件是所涉及人员受缔约
一國的法律規定管轄。
第三部分“其他和行政规定
第十一条实施安排
一、为实施本协定，缔约两国主管机关将签订行政协议，制
定必要措施，并指定联络机构。
二、缔约两国主管机关将相互通报可能会影响本协定实施的
任何立法修改和增订情况。
第十二條信息交流和相互協助
六约两国主管栅关或经欢机构应根据对方书面要求，在各自
法符规定允许的范围肉，相互提供实施本协定所需的信息和协
助。陝助應當免費提供。

第十三条信息保密
一、缔约一国主管机关、经办机构或联络机构根据本协定传送
至缔约太一国主管机关、经办机榴或联络机榴的个人信息应保密使
用,且只能專門用於龜施本協定及協定所運用的法律規定之目的。
二、本條第一款所指縮約一國接收的信息應當及到該縮約國
关于个人隐私保护和个人信息保密的国内法律约束。
第十四条交流语言
一、在实施本诚定时，缔约两国主管机关、经办机构和联络
發筍可以使用各自官方語言或英語進行交流。
二、缔约一国主管机关、经欢机榴和联络机构不得仅因为某
些文件二用纺约另一国官方语言写成而拒绝受理。
第十五条费用和认证免除
一、委公一國對依照本國法律規定應出具的證明書或其它文
書所只施的稅收、印花稅、登記或記錄費用的減免政策應同樣敵
用于依申缮约万一国法律规定应出共的证明书和同类文书。
二、为实施本协定所必须出县的文件和证明书，无须经外交
或領事楷構認證。
三、经弹约一国经欢机构或联络机梅证明真实准确的文件副
本,締約另一國經辦機構或聯絡機構應當作為真實準確的副本接
受，无须进一步证明。

第十六条“争端解决
缔约两国关于本协定解释或适用方面的任何争议应由缔约两
國主管機關通過談判和磋商方式解決。如果未能解決爭議,則店
通過外交途徑解決。
第四部分[過渡和最終條款
第十七条”协定生效前的派遗
在适用本协定第七条时，若该人员在本协定生效前已经在弹
约一国领土上工作，则第七条所指雇佣或自雇期限应当从本协定
生效之日起计算。
第十八条复审
一、和缔约两国可应缔约一国要求对本协定进行复审
二、本协定生效后10年内，缔约两国将对本协定进行复审，
决定是否需要修改本协定以确保完全覆盖参加或曾经参加了缔约
两国社会保障的双方国民。
第十九条生效
缔约两国应当通过外交渠道相互书面通知已完成使本协定生
效所必需的国内法律程序。本协定自最后一份通知收到之日后的
第三个月的第一天生效。
第二十條期限與終止
本协定长期有歼。缔约任一国可书面通知缔约志一国要求终

止本协定。本协定自缔约任一国向缔约另一国发出终止通知之日
起第12个月的最后一天起终止。-
下列代表，经各自政府正式授权，在本协定上签字，以照信守。

份,每份均用中文、分菩文及英文三種語言寫成,三種文本同等
作準。恕對文本的解釋發生分正,以英文本為淮。
