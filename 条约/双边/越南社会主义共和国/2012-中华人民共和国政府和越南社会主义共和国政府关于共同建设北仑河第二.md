# 中华人民共和国政府和越南社会主义共和国政府关于共同建设北仑河第二...

中华人民共和国政府和越南社会主义共和国政府
关于共同建设北仑河第二公路大桥协定
中华人民共各国政府和越南社会主义共和国政府(以下称"双
方”) ;
根据二〇GO九年十一月十八日签订的《中华人民共和国政府
和越南社会主义共和国政府关于中越陆地边界的勘界议定书》
《中华人民共和国政府和越南社会主义共和国政府关于中越陆地
边界管理制度的协定》和《中华人民共和国政府和越南社会主义共
和国政府夫于中越陆地边境口岩及其管理制度的协定》;
为优进中越两国贸易进一步发展,满足两国日益增长的客、货
运输需求,方便交易和人员往来,本着平等互利的原则,双方就共
则建设北仑河第二公路大桥(以下简称大桥”)达成协议如下:
第一条”基本规定
一大桥的桥位:
中方建桥地点:广西壮族自治区东兴市东郊,桥轴线柏位根据
两国相应控制网测定。
根据中国国家测绘网测定:
1.中方桩位轴点(B)
X癌坐标三2383724. 851

Y加坐标一499205. 152
2.越方检位轴点(D)
X向坐标二2383501. 851
Y辐坐标二499192. 309
越方建橋地點:廠著省芒街市海和坊,橋軸線祉位根据兩國相
应控制网测定。
根据越南国家GPS測定:
1.中方桩位轴把(B)
X向坐标和一2383557.758
Y癌坐标和524945. 929
2.越方柏位轴反(CD)
X回坐标一2383334. 738
Y加坐标一524933. 427
二、双方主管机关:
中方为中华人民共和国交通运输部
越方为越南社会主义共和国交通运输部。
三、双方负责大桥的建设维护和管理的执行机构:
中方为中华人民共和国广西壮族自治区交通运输厅;
越方为越再社会主义共和国广宁省交通运输厅。
第二条”建设.维护和管理
一\大桥的修建,不应改变桥区的水流流向和缩窗河槽,不应
改变两国现有边乔走癌,不应影响两尾已建永久性建筑物的安全，

而应满足航道通航要求,不影响河中的泄洪,维护河道生态环境和
保障其他方面的安全。
二\大桥由双方共同建设,共同拥有。双方以桥深主跨垂直于
桥轴线的平分线作为大桥的分踢管理线。双方对各目管理的桥梁
部分进行维修、保养和管理,共同保证桥梁的正销、安全使用。为
了不影响双方人流和车辆在大桥保养过程中的正第往来,双方应
提前相互通报大桥养护的计划、时间和保养项目。
三\大桥以中方河晨护刀外缘及越方河旦第二级平合(指最高
的平全)护坡底外缘作为基点,两基点连线的中点处为桥梁主跨跨
中位置。桥梁主路垂直于桥轴线的平分线只作为桥梁建成后的分
独管理线,双方不能以此作为边独线的确定依据。
第三条”建设规模
一\大桥建设采用主桥为上承式钢筋混凝土箱形拱桥,主跨
(净跨)105米,主桥长169米。中方引橋橋跨布置為:(5X 25)十
(5X25)十(4X30)米,中方橋長463. 5米;越方引桥桥跨布置为:
2X30米,越方桥长154.5米。桥梁总长618米。
二\大桥合拢点(主路跨中位置)的标高为19. 793米(中國黃
海高程) ,相当于越南标高为19. 263米(越南務島高程),大橋總寬
度為27.7米。
第四条设计与施工
一\双方同意成立大桥建设联合工作组(以下简称工作组2)，
并由其负责协商和统一技术标准,由中方完成主桥及引桥工程设

计，中越双方共同审定,并各目守成引道工程的设计。
二\大桥施工之前,双方的施工组织设计方案须经工作组商
定。
三大桥由双方共同投资建设。
四、大桥目主跨跨中位置至各目河尾的桥段.双方的引道和有
关工程,由双方依据工作组完成并经批准的施工组织设计方案进
行建设,并保证同步建设,进度一致。
五大桥的主跨合拢段由中方负责组织施工,双方共同对工程
质量、安全.进度进行监督。
第五条”建设痪用
一、目大桥主跨合拢段至双方河尾的引桥、引道和有关工程的
建设费用,由双方各目承担。
二、双方各自承担大桥主跨合拢段建设费用的50M%。工程预
算由双方共同审定。
第六条”协商与统一
一\考卡到两国建设技术标准和规范有所不同,双方同意将工
作组的会谈纪要及其协商统一的有关撤术标准作为大桥的设计和
施工依据。
二大桥的总体设计由工作组协商统一。
三、在設計和建設大橋過程中,工作組討論並統一的技術問應
和其他相关事项应提交本协定第一条所述的主管机关或执行机构
审查、批准。

四、双方在建设大桥的同时,应各自负责同步设计建设本方一
侧符合要求的口岸检查检验设施,以保证大桥建成后尽快实现品
岸功能。
第七条议定书
为确保大桥建设施工的顺利进行,在签订本协定的同时,双方
还将签订(中华人民共和国政府和越南社会主义共和国政府关于
简化共同建设北仑河第二公路大桥的人员、交通工具、施工设备和
建筑材料经东兴一芒街口岸出入境手续的议定书》。该议定书是
本协定不可分割的组成部分。
第八条”使用与管理
大桥的使用和管理办法及相关问题由本协定第一条所述双方
执行机构另行商定,并加以解决。
第九条”争议解决
任何關於本協定解釋和履行產生的爭議,雙方將通過友好協
商解决。
第十条”生效与有效期
一、本協定應在雙方完成各自國內生效所必需的法律程序后,
以外交有照會相互通知,並自最后一方發出通知之日起生效。
二、本協定自生效之日起有效期5年。除非任何一方在期滿
前6個月通過外交途徑書面通知另一方要求終止本協定,則本協
定將自動延長5年,並依此順延。

本协定于二人〇一二年三月二十六日在河内签订,一式两份,每
份均用中文和越文写成,两种文本同等作准。
