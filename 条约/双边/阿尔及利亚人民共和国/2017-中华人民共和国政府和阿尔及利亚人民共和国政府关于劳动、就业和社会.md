# 中华人民共和国政府和阿尔及利亚人民共和国政府关于劳动、就业和社会...

中华人民共和国政府和
阿尔及利亚民主人民共和国政府关于
庆动、就业和社会保障领域
合作的協定
中华人民共和国政府和阿尔及利亚民主人民共和国政府(以
下称双方或分别称一方)，为促进和加强两国及两国人民之间的
传统友谊，愿在互利基础上在劳动、就业和社会保障领域加强双
边合作，达成协议如下
第一条“总体目标
本协定的目标是发展和促进两国在区动、就业和社会保障及
其它相关领域的合作。
第二条”合作领城
双方将在以下领域促进合作:
一、宛动领域
(一)劳动管理，特别是劳动管理现代化;
(二)友动力市场的监督
(三)克动法律法规;
(四)各级社会对话机制;

(五)劳动监察监督主体及其组织的职责
(六)预防集体和个人劳动争议及其解决方法。
二、就業領域
(一)就業法律法規,
(二)創造就業和就業服務政策)
(三)劳动力市场法规和制定积极的政策和措施;
(四)外国劳动力相关法律。
三、社会保障领域
(一)社会保障制度发展和现代化
(二)医闻保险;
(三)失業保險,
(四)社会保障基金体系及收支平衡机制。
第三条“合作形式
双方将通过以下形式，促进在劳动、就业和社会保障领域的
合作,
一、交换信息、文件及相关法律;
、专家和官员互访;
|!
三、技术合作和项目开发，
四、完成聯合研究,參加兩國在上述領域舉辦的論壇、研討

五、在国际组织中就共同利益的问题协调立场
六、鼓勵在阿爾及利亞的中國企業中阿籍工人的培訓,培訓
工种经双方同意且是阿方所需工种。
第四条访问经费
在短期访问中，派出方负责其官员和专家的国际旅费和食箱
更用,接待方提供代表團在東道國國內的旅行費用,
第五条洛实和执行
一、为落实本协定，成立联合技术委员会，负责以下事务，
《一)根据本协定在劳动、就业和社会保障领域内的合作制
定执行计划
(二)根据双方达成的执行计划，确立必要的实施方法;
(三)跟踩和评估计划的执行情况，解决在执行过程中遇到
的问题和困难。
二、有双方各目从本国区动部门官员中指定3人作为联合技术
委员会的代表。联合技术委员会可以邀请两国专家共同参与相关
事务。
第六条”执行机构
负责执行本协定的机构是:
(一)中华人民共和国人力资源和社会保障部;
(二)阿爾及利亞民主人民共和國勞動、就業和社會保障部。

第七条“争端解决
对于在解释、落实和执行本协定时可能产生的分歧，应通过
外交和途径友好协商和谈判解决，
第八条修訂
在雙方一臻同意的情況下,可通過外交途徑以換文方式對本
协定进行修订。修订生效依据本协定生效相关程序进行。
第九条”生效、有效期和终止
本协定有效期为3年，除非任何一方在协定期满前6个月以
书面形式通过外交途径通知另一方要求终止本协定，否则本协定
有效期自动延长1年,並依此上順延,
如一方要求終止本協定,應當通過外交途徑書面通知另一
方。本协定自发出通知之日起第180日终止。
凑定的终止不影响双方正在执行项目的开展。
双方各自完成为使本协定生效所必须的国内法律程序后，应
通过外交途径书面通知另一方，本协定自后一份通知收到之日起
生效。
以下代表經各自政府授權簽署本協定並蓋章,
本协定于2015年4月29日在北京簽訂,一式二份,每份均
用中文、阿拉伯文、英文和法文寫成,四種文本同等作準。如果

对本文的解释和执行产生分此，以英文文本为准。
