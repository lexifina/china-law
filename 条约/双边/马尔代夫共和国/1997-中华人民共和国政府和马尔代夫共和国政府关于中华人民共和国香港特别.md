# 中华人民共和国政府和马尔代夫共和国政府关于中华人民共和国香港特别...

中华人民共和国政府和马尔代夫共和国政府
关于中华人民共和国香港特别
行政区与马尔代夫共和国
互免签证的协定
中華人民共和國政府和馬爾代夫共和國政府(以下簡稱“締
約雙方”),為了發展兩國的友好關係,促進中華人民共和國香港
特別行政區和馬爾代夫共和國之間的經濟和貿易的發展,便利人
員往來,通過友好協商,就中華人民共和國香港特別行政區和馬
爾代夫共和國之間的互免簽證問題議定如下:
第|祭
中華人民共和國公民持有效的中華人民共和國香港特別行政
区护照入、出或途经马尔代夫共和国、停留不超过天，免办签
证;马尔代夫共和国公民持有效的马尔代夫共和国护照〈包括使
用同一本护照的借行人)入、出或途经中华人民共和国香港特别
行政区，停留不超过天，免办签证。
第|末
一、\本协定第一条所述双方持照人,在對方境內逗留期間,应
遵守其有关法律和规章。
二、本協定第一條所述雙方持照人,如在對方境內欲逾免簽
期限,應依照對方主管機關的規定辦理有關手續。

第三奈
本协定不限制中华人民共和国香港特别行政区政府和马尔代
夫共和国政府的如下权力:拒绝不受欢迎或不可接受的对方人员
进入自己管辖区内或者终止其在该管辖区内的逗留，并无须说明
理由。
第四祭
由於國家安全、社會秩序、公共衛生等原因,締約雙方均可
临时中止实施本协定的全部或者部分条款，但在采取或者取消上
述措施前，缔约一方应当及时通过外交途径通知缔约另一方，并
目对方收到通知之日起生效。
第五条
一、締約雙方應當自本協定簽字之日起三十日內,通過外交
途径交换本协定第一条所述护照样本。
二、締約一方如更新上述護照式樣,應當提前三十日通過外
交途径通知缔约另一方，并提供新护照样本。
第六末
一、本協定自一九九七年七月一日起生效。
二、本協定無限期有效。締約一方如要求終止本協定,應通
過外交途徑書面通知締約另一方。本協定自通知之日起第九十日
失效。
三、缔约双方经协商，可通过适当方式补充或修改本协定。
第七条
自一九九七年七月一日起,中華人民共和國中央人民政府授

权香港特别行政区政府执行本协定。
本協定於一九九七年五月四日在馬累簽訂,一式兩份,每份
分別用中文和英文寫成,兩種文本同等作準。
