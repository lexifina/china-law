# 中华人民共和国政府和马来西亚政府科学技术和创新合作协定

中华人民共和国政府和马来西亚政府
科學技木和創新合作協定
中华人民共和国政府，由科学技术部代表，和马来西亚政
府,由科學技術與創新部代表(以下合稱雙方,單獨稱一方)
鉴于两国的友好关系及开展科学技术和创新合作的共同
意愿;
一致认为为了双方的共同利益，有必要开展长期有效的合作|
一致認為合作符合雙方的共同利益,將對促進兩國的科技
创新进步和社会经济发展做出贡献;
达成协议如下:
第一条”目标
双方同意在平等互利的基础上，依据本协定以及两国现行
的法律、法规和国家政策，加强两国的科学技术和创新合作。
第二条”合作方式
双方同意按照各自现行的法律、法规和国家政策执行和管
理本国的合作事务，并采取必要措施，训励和推动以下方式的

科學技術合作:
(一)互派科学冢、研究人员、专冢和学者;
(二)交换科学技术资料和文献;
(三)組織雙邊科學孩術研討會和培訓班;
(四)共同确定并实施研究成果可应用于工业、农业和其他
領域的合作研究項目,交流在合作研究中所獲得的經驗和技術;
(五)共同推动科技产业的创新合作;
(六)双方同意的其他科技创新合作方式，
第三条执行机构
双方分别指定中华人民共和国科学技术部和马来西亚科
学技术与创新部作为负责本协定的执行机构。
第四条”执行
一、双方将依据本协定，推动两国的科技创新相关政府部
门、企业、高校和研究机构(以下称项目合作方)开展合作，
必要时可在本协定的框架下缔结本协定第二条规定范围内的
具体合作协议和附属合作协议(以下称执行协议)。
二、执行协议将按照两国现行的法律和法规签署，必要时，
双方应确保执行协议中包含知识产权相关条蒜，了明确合作研究
成采的知识产权归属和利用等事项。知识产权归属和利用条款

的確定應當充分考慮到項目合作方的投入和創造性頁獻。
三、双方同意，在本协定的执行过程中，任何合作研究或
试验所需设备的运送以及生产设备的所有权问题，由双方视具
体情况协商而足.
第五条”联合委员会
一、双方成立由双方代表共同组成的中互科学技术和创新
合作联合委员会(以下称联委会)，并各自委派联合主席一名
和陛委會成員若十名。
二、聯委會擁有其獨立的議事規則,通常每兩年在雙方共
同商定的日期轮流在中国筷来西亚举欢，必要时可举行额外
会议。
三、联委会共有以下职能:
(一)规划并协调科学技术和创新合作计划;
(二)监督并推动科学技术和创新合作计划的执行;
(三)为推动具体领域的科学技术和创新合作提出建议，
包括方法和計劃;
(四)对科学技术和创新合作计划的执行进行审查和评估;
(五)其他与执行本协定相关的职能。
四、必要時,联委会可成立临时或第设分委会或工作小组，
处理具体事务，履行联委会授予的职能。

五、联委会会议期间，双方经商定可增加或修改现有的合
作活动。
第六条”财务安排
在本协定的框架下，合作活动的经费安排由双方根据资金
情况，视具体情况商足.
第七条”第三方参与
双方同意，一方需经另一方同意，方可邀请第三方参与本
协定的合作计划或项目。双方应采取措施，保证第三方在执行
相關合作計劃或項目時遵守本了協足。
第八条”知识产权的保护
一、双方根据本国现行的法律、法规和同为费约方的国际
公约、条约以及双边协定，保护在科学技术和创新合作中产生
的知识产权和信息。
二、項目合作一方未經另一方事先書面同意,不得在任何
出版物、文献或论文中使用其名称、标识或官方币章。
三、除本条款第一条规定外，对知识产权事项还做如下规定:
(一)经项目合作双方共同开展的任何技术开发、产品和
服務開發活動產生的知識產權,或雙方合作努力取得的研究成

果的知识产权，应根据相互达成的条款，由项目合作双方共同
所有。
(二)经项目合作茶一方单独开展的任何技术开发、产品
和服务开发活动产生的知识产权，或某一方单独努力取得的研
客成采的知识产权，应由该方单独所有。
第九条”保客
一、在执行本协定或依据本协定达成的其他协议过程中，
双方应严格保密并优使其项目合作双方严格保密来自或提供
给克一方的文件、信息和其他资料.
二、双方同意，本协定终止后，本条款对双方仍具有约束力。
第十条”中止
出于国家安全、国家利益、公共秩序或公共卫生的原因，
雙方保留暫時全部或部分中止執行本協定的權利。
一方经外区途径同为一方提交书面通知后，中止立即生效。
第十一条修订、修改和修正
一、双方均可书面要求对本协定的全部或部分条款进行修
订、修改或修正。
二、双方同意的任何修订、修改或修正，应以书面形式呈

现，并构成本协定的一部分。
三、以上修订、修改或修正在双方确定的日期生效。
四、在修正案生效前，任何修订、修改或修正不得损害本
协定中的权利与义务。
第十二条”争议解决
雙方在解釋、執行和應用本協定中所產生的任何分玻或爭
议，由双方经外交途径友好协商解决，不得涉及任何第三方或
国际仲裁机构。
第十三条”生效、有效期和终止
一、本協定自簽字之日起生效,有效期五年,
二、有效期滿后,本協定可自動延期一年,並依此法順延,
三、除本條款以上規定外,任何一方欲終止本協定,應至必
提前90日經外交途徑向另一方提交和書面通知,以終止本協定,
四、本协定的终止不影响终止之前已经开展的合作活动、
项目和计划。
下列代表經各自政府授權簽署本協定,以昭信守。
本协定于2013年10月4日在吉隆坡簽訂,文本共六份,
分別用中文、馬來文和英文寫成,三種文本同等作準。如對文

本的解释产生分歧，以英文本为准。
