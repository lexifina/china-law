# 大湄公河次区域电力贸易政府间协议

大湄公河次区域
电力贸易政府问协议
序言
大滑公河次区域(以下简称CMS )政府,即柬埔寨王国.中华人
民共和国,老挝人民民主共和国、缅甸联邦、泰王国和越南社会主义
共和国(以下简称各方) :
认识到CMS各国电力公司在各目国家从事供电业务,并硕望继
续发展各国电网间的互联,扩大容量和电能贸易以便提供进一步的
机会来:
(一)加強供電的可靠性;
(二)协调发电及输电设施的安装和运行;
(三)降低投资和运行成本;
(四)分享在他們的系統聯網運行後所市來的其他利益。
注意到CMS各成員國,表明他們都承認各國電力部門間合作的
利益,在一九九五年成立了CMS電力論壇( FPF ) ,並在一九九八年
成立了电力联网及贸易专家小组(ECP)研究和提出有关CMS电力
的建議;
回顾二OOO年一月在马尼拉举行的第九次CMS部長級會議,
* (1該協議於2003年11月27日生效。凶中国于2002年11月3日簽署該協議。
2003年8月26日照會各方,中國接受該協議。協議於2003年11月27日对中国生效。

會上GMS各國部長簽署了旨在促進電子貿易的“關於大湄公河次區
域電力貿易的政策聲明”。在這個政策聲明中,GMS各國部長一至
同意,希望其电力部门参加区域电力贸易的政府签订一个政府间协
議,以提供實施該政策聲明的框架;
因此,通过他们作为“关于大湄公河次区域电力贸易政府间协
议"的签字人的合适的授权代表,各方一致同意如下
第一条“本政府间协议的目的
一本政府间协议的目的是实施二OOO年一月由GMS各國部
长签署的关于区域电力贸易的政策声明,包括建立各方计划推进
GMS区域电力贸易的框架。本政策声明收入进本政府间协议,作为
附录A。
第二条“大湄公河次区域电力贸易的原则和目标
一本条中的原则和目标与附录A中提供的關於大湄公河次區
域电力贸易政策声明的实施是一致的。
二各方认可他们的关系是以下列原则为基础的:
(一)合作:以合作和互利的精神来处理与区域联网有关的问
题,各方具有平等的权利和义务,团结一致,并制止窃取他方的利益
(二)渐进性:各方认为,区域电力贸易要逐步地发展，
(三)环境方面可持续发展:区域电力贸易要在尊重环境的框架
内推行。
三\对所有参加国,基于本协议的区域电力贸易目标是:
(一)在系统规划和运营方面协调和合作,在保持满意的可靠性
同时,使得成本最低;
(二)完全回收其成本,公平地分享取得的效益,包括减少所需
的发电及输电容量.降低燃料成本和提高低成本电力资源的利用，
(三)对各方的用户提供可靠和经济的电力服务。
第三条”定义
(一)附录:本协议的附件,构成本协议的组成部分。
(二)授权机构:各方指派的执行本协议的机构。
(三)电力论坛(EPF) :根据一九九五年的GMS计划建立的电力

小组。
四)电力联网和贸易专家组(ECP ) :由来自各国电力公司和
CMS成只國政府專家組成的小組,於一九九八年由EPF成立。
(五)GMS計劃:一九九二年發起的大湄公河次區域經濟合作計劃。
(六)GMS部长级会议:CMS成员国每年举行一次部长级会议,它
是CMS計劃的組成部分,以協調次區域合作和提供總的指導和支持。
七)區域性電力劉安協貞委員會( RPTCC):GMS区域性电力贸
易協調委員會,擬在協調針對本IGA协议区域性电力贸易的执行。
(八)大洶公河次區域(GMS) :柬埔寨王国.中华人民共和国云南
省.老挝人民民主共和国缅甸联邦,泰王國和越南社會主義共和國。
(九)政府間了協議( IGA) :在柬埔寨王国.中华人民共和国,老挝
人民民主共和國緬甸聯邦,泰王國和越南社會主義共和國的政府之
间达成的本协议及其附件。
(十)区工电力贸易运行协议(PTOA ) :为本协议(ICA )中的区
域电力贸易的实施和操作而制定的技术和商业运营协议,将在
RPTCC的管理下起草。
(十一)各方:束埔雄王國中華人民共和國、老過人民民主共和
國緬甸聯邦,泰王國和越南社會主義共和國的政府。
(十二)关于大湄公河次区域中区域贸易的政策声明:由二O〇OO
年一月在馬尼拉召開的第九次CMS部长级会议所签署的声明。
第四条”机构框架
一\如末适合的话,各国将本政府间协议下的区域贸易政策指导
和监督的黄任分配给负责电力或电力政策的各位部长。在认为必要
的时候,或者应根据本协议第四条第二款组成的区域电力贸易协调
委员会(RPTCC )的请求,这些部长应召开会议。
二,各方认为需要有一个高级别团体,即大湄公河次区域电力贸
多協調委員會( RPTCC ) ,来为成功地实施区域贸易和代表区域电力
贸易中所涉及的国家而进行积极的协调。各方指定他们国家的代表
参加目前的电力论坛,组成第一个临时的RPTCC ,以实施本政府间
协议。RPTCC应向GMS部长级会议和各自国家的政府(通过第四

条第一玖中规定的有关部门)进行报告。RPTCC在其旨在实现其主
要目标的操作的管理中应具有独立性。目前的电力联网及贸易专家
组应对RPTCC提供技術文持。
三,RPTCC的作用:RPTCC的第一个任务是较为准确地确定区
域贸易安排的建立和实施的头几个步骤,他们应将其提交给各方签
著。這應包括完成以下工作計劃:
(一)回各方捉供区域贸匈运营协议(PITOA)的最后草案,规定
区域电力贸易的规则;
(二)回各方担供关于区域电力贸易的总的政策和日向管理的
建议,包括进行协凋的必要的机构;
(三)确定需要优先推行的短期.中期和长期的行动,以便在规
定的时间表内实现区域电力贸易的目标;
(四)确定实施区域贸易必要的步又,包括质金寿集的办法。
四各方还应授权合适的有关国家部门和政府授权的电力公司
等订必要的协定,调整区域电力贸多的机构和运营,包括PIOA ,但
顷经RPTCC批准。各方应文持和协助各目国家的指定机构和电力
部门履行和执行根据本协议(ICA)在各电力公司之间达成的任何协
议的条秋中规定的义务,并应与政策声明相符合。
第五条本协议的各方
一、本政府間協以由所有CMS成員國公開簽署。
二、吸收非CMS成員國參加,應經簽訂本政府間了協議的CMS各
方的同意。这类吸收的条天应在单独的协议中制定,作为附件,并成
為本政府間協議的一部分。
第六条”争议的解决
一\对于在解释或实施本政府间协以中发生的任何分上,执行本
协议的授权机构应通过协商寻求友好解决。在授权机构不能友好解
决任何问题的情况下,应将该问题提交给各方解决。
第七条批准和生效
一\本政府间协议应根据各方国家的程序由各方批准和接受。
各方應督促和加快在各自國家的批淮和接受的過程。各方應將它的

批准和接受通知其他方。
二本政府间协议应在批准或接受本协议的双方和多方之间自
第三方批准或接受的证明文件发布之日起生效。
第八条协议的期限
本政府间协议在由各方修订或终止之前应一直有效。
第九条退出协议
各方布望继续进行区域电力贸易的合作。然而,任何一方如提
前一年回其他各方发出书面通知,在从其生效之日或任何其后的时
间起两年期满后,可退出该政府间协议。所有各方在收到通知后一
年,协议的终止应生效,在这一年的期间内,退出方应继续履行本协
议的条和亚。退出本ICA将不影响在本协议的基础上签订的协议和
合同,直至这些合同期满为止。
第十条与其他协议的关系
一与非CMS各方的协议。本政府间协议不应限制任何CMS
国家与非CMS国家签订电力贸易协议。只要这类协议对非协议一
方的CMS国家不产生义务;并且只要这类协议不妨碍CMS一方履
行CMS区域电力贸易协议中对它规定的义务。
二,原先存在的协议
(一)本政府间协议的执行,根据其控制条天,在任何以前的合
同或協議期滿或終止前,不應妨礙修改或變更任何這些合同或協
议,除非各方相互同意后进行修改或终止。在原规定的到期日届满
后,这些协议将不再延期,所有新的协议或合同均应寻求与本政府间
协议相符合。
(二)虽然本政府加协议不强加义务,改变、修改或终止原有的
协议或合同,但各方要鼓励这类协议或合同的有关方尽最大努力,对
基于PTOA签订的第一批贸易运营日之前的影响区域贸易的任何条
多和条件进行重新协商。
三.其他区域协议
(一)各方确认他们应继续各重任何他们也是参加者的现有区
域协议或条约所规定的权利和义务;

(二)各方都知道,現已有幾個與CMS区域电力贸易有关的行
动。因此,各方应将责任赋予RPTCC,以確保促進本區域貿易的所
有行动得到协议,以免作重复的努力和提高合作的效益。
第十一条”审查和修订
本政府間協議的條款應每五年審查一次,或者至少三分之一
CMS成员国要求不短于五次审查一次。如需要,经本协议所有各方
同意,可进行修改。
第十二条整个协议
本协以构成各方之间的全部谅解。
