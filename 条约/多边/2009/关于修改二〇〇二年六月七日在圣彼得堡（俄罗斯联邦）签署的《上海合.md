# 关于修改二〇〇二年六月七日在圣彼得堡（俄罗斯联邦）签署的《上海合...

天于修改二OO二年入月七日在圣役得堡(俄罗斯联邦)
簽署的《上海合作組織成員國關於地區
恐怖機構的協定》的議定書
( 2007 )
上海合作组织成员国订立本议定书如下:
第一条
對《人上海合作組織成員國關於地區反恐怖機構的協定》(以下简称“协定”)作如下修改:
第十一條第三款修改為:
“主任由上海合作组织成员国元首会议根据理事会推荐任命。副主任由理事会根据拥有副主任职位的
有关方建议任免。
第二十一条修改为:
“地區反恐怖機構的官方和工作語言是漢語和俄語5
第二条
本议定书将根据协定第二十六条规定的程序生效。
本議定書自簽署之日起臨時適用。
本議定書於二OO七年八月十六日在比什凱克簽署,一式一份,用中文和俄文寫成,兩種文本同等
作準。
