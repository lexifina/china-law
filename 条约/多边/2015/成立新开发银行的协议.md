# 成立新开发银行的协议

成立新开发银行的协议
(中譯本)
巴西联邦共和国、俄罗斯联邦、印度共和国、中华人民共和国
和南非共和国【《以下统称“人金砖国家”)政府,
根据在2012年新德里金砖国家领导人第四次会晤期间作出，
并随后在2013年德班金砖国家领导人人第五次会晤期间宣布的关
於建立開發銀行的決定;
认可各国岂政部业已开展的工作:
相信建立该开发银行将反映金砖国家之间的对密关系，并为伺
进金夸国家经济合作捉供有力于段;
注意到新興市場國家和有發展中國家在推動基礎設施建設和可持
續發展方面仍面臨重大融資約束,
同意建立新开发银行(LNDB，以下简称“银行” )，并将按照所
附协定条款经营业务。该协定构成本协议不可分割的一部分。
第一条
守旧和职能
银行应为金砖国家及其他新兴经济体和发展中国家的基础设施
建設和可持續有發展項目動員資源,作為現有金邊和區域金融機構的
化”中国于2014年7月15日签署，2015年7月1日批准协定。

补充，促进全球增长与发展。
為履行其宗旨,銀行應通過貸款、擔保、股權投次和其他金融
工具為公共或者私人項目提供支持,。銀行還應與國際組絆和其他金
融實体開展合作,並為銀行支持的項目提供技術援助。
第二条
成员资格、投票、资本和股份
银行的创始成员为巴西联邦共和国、俄罗斯联邦、印度共和国、
中华人民共和国和南非共和国。
根据《新开发银行的协定》条坎的规定，银行的成员资格应向联
合国成员开放，并对信短成员和非倩敌成员开放。
新開發銀行的初始認繳資本為500億美元,初始法定資本為1000
億美元。初始認繳資本應在創始成員間平均分配。各成買的投囚權
应等于其在银行股本中的认缴股份。
第三祭
总部、组织结构与管理必
银行总部位于上海市。
银行应变一个理事会、一个董事会、一省行长和效溃副行长
银行行长应从创始成员国中选举产生并轮流担任，应从其他创始成
员国中分别产生至少一名副行长。
银行运谊应遵循尽好的银行业准唱。

定的时间内，仍未达成前秋中捉及的协议，则该国所持股本的回购
價格應為在該國家停止成只資格間天銀行賬薄上記載的賬面價值。
回購股份應遵循下列祭件:
(1】付束應按照銀行確定的分期付歌安排、時間和可用市種進行
支付，并应考虑银行的财务状泡。
Ki1】在銀行因回購股本而應回該國文付的避項中,應扣除該國
或其任何部門或代理機構因貸款或擔保業務而仍然保有的對銀行的
俩务。银行可选择将任何到期隐伟务从该夭项中子以扣队。但是，
對於該國根據第9條第(ce)款認購股本而對未來催繳股本所承擔的
或有俩务，不得进行任何扣除。
证)在荣一国家俘止成员货格之日，如采银行捉供或参与的癌
未收回的貸款或擔保遭受淨損失,且淨損失金額超過半日銀行為其
拨付的谁备金，则在银行账汪上的股份账面价值已经计人该损失的
情况下，该国应按银行的要求退还其股份回购价格中相应的减记金
額。此外,前銀行成只仍應在銀行已發生資本損矢且在確定股份回
購價格時已提出催繳要求的情況下,對第9祭第(ce)款所規定的催
繳俱頁。
ej根据本章项下加一个国家文付的任何股份回购夭项只能在该
到停止成员质格之日起12个月后进行文付。如采银行在该期间内父
止經營業務,則該國所有權利均應根據第41條至第43祭的規定相應
确定，且该国在这些条区下仍应被视为银行成员，但没有投票权。
第四十条”智停业务
在蒜急情形下,董事會在等符理事會作出進一步考慮和米取進
一步行動前,可暫停新的貸款、擔保、估人銷、技木援助和股權投資

等业务。
第四十一条”终止经谷
銀行可由理事會以特別多數方式典定終止其經營。終止經營時,
給與有秩序地變賣、保存和保管資記以及清修偵之等有關的活動外,
銀行應立即停止一切活動。
第四十二敘。成只的頁任和偵權的清修
a)所有成员由于认购银行股本以及因成员国货币紧值而产生的
債務將繼續有效,直到所有直接債務和或有債務全部清償完虹。
b )持有且接债权的债权人应首先从银行资产中受偿，然后从银
行應收而未收或竺繳股本的所收款項中受傍。在向持有直接債權的
價咎人述行任何敘付之鵬,董事會應根掂目己的判斷作出必要的安
排,以保證在各直接債權持有人和或有債權持有人之間按比例進行
任何。
第四十三条”资产分配
a】按照成只認繳的股本分配人資產,須在對價相人的所有俱偵已
經清條或作出安排之后方本進行。且資產分配必須經理事會以特列
多數方式批淮。
b】銀行疝成員分配人資產,應與各成只持有的股本成比例,並在
银行认为公平合理的时间和条件下实施。所分配的各份资产，在资
產閏型上不必一致。任何成員在若清對銀行的所有價務之前,無權
接受資遍分配。
c )成员对根据本条分配到的资产所享有的权利，应与分配前银
行對這些資產享有的權利相同。

第八草”人收苛、解冬及仲坊
第四十四条修订
a】本協定的修訂必須由理事會以特列多數方式決定。
b )有天修订本协定的任何建议，无论由成员、理事还是董事会
壹出，均应所区理事会主席，并由理事会主席握菇理事会讨论。如
采该修改建议获得理事会的批准，则银行应回全体成员询问是否接
受該修改建議。如末三分之二成只接受、批淮或核准該修訂,則銀
行应以公园通知所有成员。
c)對本協定的修訂應在根據本祭第(tb)款發出銀行公紅之日起
3个月后对全体成员生效。
第四十五条解释
a )几成员和银行间或成员之间对于本协定条文的解释发生任何
争议时，即应所区董事会裁决。
b )如审议中的问题对东个成员有特殊影啊时，该成员有权根扼
第12余第(i)款的規定派代表直接參加董事會會議。
ce)董事會作出本條第(a)款項下的決定後,任何成員仍可以要
求將該器題提交理事會討倫,由理事會作出最化決定。在理事會作
出裁决之前，银行如认为必要，可以根据董事会的决定行事。
第四十六条仲裁
a】如銀行坊已停止成只資格的國家之間或銀行作出停止經膏的
決定之和后在銀行和成買之加出現爭議,該爭議雇提交給由3名仲裁只
組成的仲裁法庭仲裁。仲裁員之中,一名由銀行任命;态一名由有天
居家任命;除半事方之間乃有協定外,第三名由理事會同意的權威機

构任佣。如有朱达成一致意抑的所有努力均后夫败，则3名仲裁员应通
过投票以价单多数方式作出裁定。
b )当事方在程序问题上有争议时，第三名仲裁员应有权处理全
部程序问题。
cj关于银行导倩秋国之间合同的任何争议，应根据有关合同子
以解決。
第四十七禾”默許同意
銀行米取任何行動前,如需要得到任何成只同意,應將擬議的
行蕙通知該成只。如該成只在銀行通知中規定的合理時間內沒有提
出反對意見,即應被作銀行已獲得該成只的同意。
