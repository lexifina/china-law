# 最高人民法院发布第六批司法改革案例

日前，最高人民法院司法改革领导小组印发《人民法院司法改革案例选编（六）》。该选编汇集20家法院深化司法体制综合配套改革、全面落实司法责任制的先进经验和特色做法，为全国法院深入推进司法体制综合配套改革提供了示范参照的样本。

《人民法院司法改革案例选编》是最高人民法院在深化司法体制改革过程中打造的一项亮点工程，旨在全面搜集、深度挖掘各地法院推进司法改革的特色经验，提炼可复制、可推广的典型做法，并以案例形式推广，为各地法院推进司法改革实践提供重要参考。2017年至今，最高人民法院先后印发了《人民法院司法改革案例选编》（一）至（六），共计115个案例，全面展现了各地法院贯彻中央司法体制改革精神的积极探索和生动实践，大家相互学习借鉴，取得良好效果，有力推动了人民法院司法体制改革的深入发展。

《人民法院司法改革案例选编（六）》以习近平新时代中国特色社会主义思想为指引，深入贯彻落实中共中央办公厅印发的《关于全面深化政法领域改革实施意见》，严格按照“人民法院第五个五年改革纲要”工作部署，收录了不同层级、不同地区法院在破解改革难题、推动改革发展方面的探索与创新。此次入选案例选编的法院有：北京市顺义区人民法院、北京市门头沟区人民法院、天津市河北区人民法院、上海市徐汇区人民法院、上海市长宁区人民法院、江苏省淮安市中级人民法院、江苏省昆山市人民法院、浙江省台州市中级人民法院、浙江省丽水市莲都区人民法院、福建省福州市鼓楼区人民法院、江西省高级人民法院、河南省信阳市中级人民法院、湖北省襄阳市中级人民法院、广东省深圳市中级人民法院、广东省深圳市福田区人民法院、广东省东莞市第二人民法院、重庆市高级人民法院、四川省宜宾市中级人民法院、甘肃省张掖市甘州区人民法院。

此次入选的案例涵盖领域广、探索创新性强、做法举措实，聚焦全面落实司法责任制改革的瓶颈性、制度性、配套性问题，重点推广了各地法院在强化审判监督管理，建立院庭长常态化办案机制，完善法律统一适用机制，推进诉源治理，深化案件繁简分流，强化科技手段深度应用等方面的经验做法。案例典型性强、可复制程度高，具有重要的示范意义。

近期，《人民法院报》将开设专栏，陆续登载《人民法院司法改革案例选编（六）》中的具体案例，敬请关注。（李承运）
