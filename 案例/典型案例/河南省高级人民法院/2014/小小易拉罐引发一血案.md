# 小小易拉罐引发一血案

一个废弃的易拉罐，它本应该待的地方是垃圾箱，但在一起斗殴案件中，当事人双方十余人为了一个扔错了地方的易拉罐大打出手，最终导致一人受轻伤，一人被判有期徒刑一年、缓刑一年。

2013年11月5日凌晨2点，张刚和王雯等陌陌好友共六人在位于新乡市卫滨区某烧烤店内吃饭。期间，王雯把喝过的啤酒易拉罐没有扔到垃圾箱，而是丢到了李海等人吃饭的桌子附近。两桌人员遂起争执，后言语不合开始厮打，张刚用板凳将李海头面部砸伤，经鉴定李海头面部创口所受损伤为轻伤二级。2013年11月27日，张刚被公安机关传唤到案。后张刚与李海达成和解协议，由张刚赔偿被害人李海医疗费、误工费、后期治疗费等共计5万元，取得被害人的谅解。

法院经审理后认为，被告人张刚故意伤害他人身体健康，致人轻伤，其行为已构成故意伤害罪。被告人张刚在案发后积极赔偿被害人经济损失，取得被害人谅解，可酌情对其从轻处罚。依照有关法律规定，判处被告人张刚犯故意伤害罪，判处有期徒刑一年，缓刑二年。
