# 法官高效调解当天立案即结案

一般民事案件的法定办案期限为6个月，但在郏县人民法院堂街法庭的朱法官创下了1天办结一起民事案件的记录。9月26日，一起离婚纠纷案在朱法官的高效调解下于立案当日顺利结案。

2016年，代某某与刘某某经人介绍认识并结婚。婚后不久，双方因为一系列矛盾纠纷不断争吵，夫妻感情降到了冰点，代某某一气之下离家出走，并诉至法院要求离婚，后申请撤诉。2017年9月26日，刘某某起诉，请求依法判决双方离婚并返还全部彩礼。

在代某某起诉离婚的纠纷中，承办法官就多次组织双方进行调解，无奈双方因彩礼返还数额问题，始终无法达成一致意见，代某某遂申请撤诉。虽然代某某撤诉了，但朱法官的心中却知道双方当事人的心结未打开，案结事未了。于是在案件结案后仍继续与双方的代理律师、原被告家人进行沟通、劝说和开导，希望双方能够摒弃前嫌，及时解决问题。

9月26日，在得知刘某某向法院提起诉讼的当天，朱法官便立即组织双方进行调解，加之朱法官前期的不懈努力，双方最终同意离婚，并就彩礼如何返还达成了一致意见，该案顺利结案。
