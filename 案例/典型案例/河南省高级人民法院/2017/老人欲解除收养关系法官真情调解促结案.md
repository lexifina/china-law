# 老人欲解除收养关系法官真情调解促结案

都说“养儿防老”，老人靠拾荒含辛茹苦把儿子养大，养子长大后却因盗窃被判刑，致使老人到了耄耋之年无人赡养，也不能进入五保户。无奈之下，老人痛心将养子告上法庭。8月7日，郏县人民法院冢头法庭法官通过真情调解，成功解除老人与养子的收养关系，该案顺利审结。

据了解，王大爷今年75岁，平日以捡垃圾为生，老伴早年病故，膝下无子。为了以后有人给自己养老送终，1981年秋天，他收养了刚满月的被告王某，多年如一日的呵护王某成长。谁知成年后的王某却不思进取、不知感恩，经常偷家里甚至别人的东西，对大爷的生活更是不管不问。2016年，王某因犯盗窃罪被法院依法判处有期徒刑九年。后王大爷听说村里在统计五保户，经询问，因王大爷与王某存在收养关系，故王大爷不能被录入五保户。于是，王大爷于8月1日向法院提起诉讼，请求解除与王某的收养关系。

了解基本案情之后，冢头法庭赵法官很是动容，通过多方打听才知道王某现被关押在郑州某监狱。于是，赵法官决定亲自前往监狱进行调解。8月2日，赵法官带着书记员冒着大雨，行驶230多公里，见到了正在服刑的王某。赵法官向王某阐明了事情的由来，并语重心长地阐明大义，以情动人、以理服人。经过赵法官的耐心教导，王某认识到了自己的错误，羞愧满面，并当场同意解除收养关系，表示以后会在监狱里好好改造，争取早日出去尽孝。8月7日，拿到法院调解书的王大爷终于露出了舒心的笑容。
