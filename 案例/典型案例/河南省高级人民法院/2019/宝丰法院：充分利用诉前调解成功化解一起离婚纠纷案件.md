# 宝丰法院：充分利用诉前调解成功化解一起离婚纠纷案件

8月28日上午，宝丰县人民法院诉前调解室内，陆某连声向立案庭庭长陈锐峰和工作人员道谢，“感谢你们挽回了我们的婚姻，也给孩子们一个完整的家！”

8月23日，原告孔某一纸诉状将其丈夫陆某告至宝丰法院，要求法院判决他们离婚，分割共同财产，并分别抚养婚内龙凤胎儿女。

孔某与其丈夫陆某于2005年6月30日在宝丰县民政局登记结婚，并于2012年生育龙凤胎儿女，这在别人看来幸福美满的家庭，实际上却没那么幸福。孔某是一名出租车司机，其丈夫陆某平时打零工，家里经济还说得过去，就是陆某脾气极其暴躁，三两句话说不到一块儿就大发雷霆，平时对孔某更是很少关心。其中一件事更让孔某伤心至极，2016年正月十五，孔某骑电车被撞，被120送往医院急救。陆某见到孔某后，先是对孔某咆哮，并声称自己没有钱，让还躺在担架上的孔某自己借钱治病，给孔某造成了极大的伤害。孔某与陆某多次协商离婚，但陆某均不同意，孔某以夫妻感情破裂为由诉至宝丰法院请求法院判决离婚。

陈锐峰庭长和立案庭工作人员了解了事情的来龙去脉后，认为双方并无本质矛盾，他们不能有效沟通是家庭矛盾的根源，于是先在调解室单独对陆某进行教育，经教育陆某本人也意识到自己平时处事方式不对，而且也知道妻子主动担起家庭的重担很不容易，为家为孩子付出很多，自己都看在眼里，也很感激妻子，并且没有离婚的想法。随后，陈庭长对孔某进行劝解，孔某说自己平时开出租车又要照顾家庭和孩子很累，但丈夫对自己没有一点感激，平时还动不动就发脾气。陈庭长耐心地对孔某进行劝解，告诉她其实她丈夫知道她的不易和对家庭的付出，只是不会说好听话，也对他批评教育了，他明确表示以后改正，另外，两个孩子本来就是龙凤胎感情好，相信你们也不忍心把他俩分开……

最后，孔某表示愿意再给丈夫一次机会，两人重归于好，陈锐峰庭长向他们发放了“夫妻美好祝福卡”，希望他们在今后的生活中能够勤于沟通，和睦相处。

自今年5月宝丰法院开展诉前调解工作以来，累计成功调解各类案件80余起，今后宝丰法院将继续积极开展诉前调解工作，节约审判资源、真正做到案结事了并最大程度践行司法为民宗旨。
