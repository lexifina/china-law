# 河南省高级人民法院2019年国际禁毒日典型案例

——毒品犯罪无论数量多少，都应当追究刑事责任

（一）基本案情

被告人[姓名略]，男，1958年10月14日出生，汉族，农民。

2017年10月份的一天，被告人[姓名略]在林州市任村镇任村村的家中，以70元一克的价格卖给李学存一克毒品“筋”（甲卡西酮）。

（二）裁判结果

林州市人民法院认为，被告人[姓名略]明知是毒品而予以贩卖，其行为已构成贩卖毒品罪。[姓名略]到案后如实供述自己的罪行，可依法从轻处罚。据此，法院以贩卖毒品罪判处被告人[姓名略]有期徒刑六个月，并处罚金人民币五千元。

一审宣判后，[姓名略]不上诉，检察机关未抗诉，该判决已生效。

案例3

[姓名略]贩卖、制造毒品案

——制造毒品数量大，社会危害性大

（一）基本案情

被告人[姓名略]，男，1952年7月12日出生，汉族，无业。

2016年10月份以来，被告人[姓名略]在自己家中制造冰毒，并先后两次通过本村邻居卢大狗（另案处理）卖出150克左右，获利10500元。2017年11月1日，侦查人员当场在[姓名略]家中查扣了制造冰毒的工具、疑似冰毒白色晶体、疑似冰毒半成品膏状物和液态物品。经称重并委托襄阳市公安局毒品检验鉴定中心检验，疑似冰毒白色晶体共计433.66克，甲基苯丙胺含量为59.3%；有毒品含量黄褐色液体117.14克，甲基苯丙胺含量为34.2%；黄褐色膏状物896.36克，甲基苯丙胺含量为22.3%。综上，被告人[姓名略]共计贩卖、制造毒品1597.16克。

（二）裁判结果

南召县人民法院认为，被告人[姓名略]贩卖、制造含有甲基苯丙胺的毒品共计1597.16克，其行为已构成贩卖、制造毒品罪。[姓名略]到案后如实供述自己的犯罪事实，系坦白，可以对其从轻处罚。据此，法院以贩卖、制造毒品罪，判处被告人[姓名略]有期徒刑十五年，并处没收财产10万元；并判令对扣押在案的含有甲基苯丙胺成分的毒品、用于贩卖、制造毒品的作案工具由扣押机关予以没收；对[姓名略]贩卖毒品违法犯罪所得10050元予以收缴，上缴国库。

本案宣判后，被告人[姓名略]不上诉，检察机关未抗诉，该判决已生效。
