# 起诉书（[姓名略]抢劫、故意杀人案)

成检公诉刑诉〔2017〕73号

被告人[姓名略]，男，1988年**月**日出生，身份证号码5101821988********，汉族，高中文化，无业，四川省彭州市人，户籍所在地：[地址略]。2006年8月9日因犯抢夺罪被四川省南部县人民法院判处有期徒刑九个月；2015年1月22日因犯容留他人吸毒罪被彭州市人民法院判处有期徒刑六个月，同年5月7日刑满释放。2016年9月20日因涉嫌抢劫罪被彭州市公安局刑事拘留，同年12月16日经彭州市人民检察院以涉嫌抢劫罪、故意杀人罪批准逮捕，同日由彭州市公安局执行。

被害人张某某（死亡），女，殁年48岁，户籍所在地：[地址略]。

本案由成都市公安局侦查终结，以被告人[姓名略]涉嫌抢劫罪、故意杀人罪于2017年2月13日移送本院审查起诉。本院受理后，于次日告知被告人有权委托辩护人，并告知被害人近亲属有权委托诉讼代理人，依法讯问了被告人，审查了全部案件材料。

经依法审查查明：

2016年9月17日4时许，被告人[姓名略]遇见与其家中有生意往来的被害人张某某后，萌生向其借钱的想法，遂在张某某家外等候，待张某某返家后趁其丈夫离开之机，从后门进入张某某家中。在向张某某借钱遭拒后，[姓名略]借故滞留张某某家中并伺机将其扑倒后控制，劫得张某某腰包内人民币1000余元，[姓名略]为防止张某某报警而胁迫其一同离开。二人行至彭州市丽春镇花棚村13组人民渠南堤河边时，[姓名略]担心张某某逃跑后报警，其犯罪行为败露而产生杀人灭口的想法，遂用腰带勒住张某某颈部致其窒息，并用一塑料袋套住张某某头部防止其复活，[姓名略]用玉米秸秆将张某某掩盖后逃离现场。经鉴定，被害人张某某系勒颈、塑料袋包裹头面部致机械性窒息死亡。

2016年9月20日，民警根据举报线索在被告人[姓名略]家将其挡获。

认定上述事实的证据如下：

现场勘验、检查笔录、书证、物证、鉴定意见、视听资料、证人[姓名略]，以及被告人供述和辩解等。

本院认为，被告人[姓名略]以非法占有为目的抢劫被害人张某某财物，在劫得财物后为灭口杀害被害人张某某的行为，分别触犯了《中华人民共和国刑法》第二百六十三条、第二百三十二条的规定。本案犯罪事实清楚，证据确实、充分，应当以抢劫罪、故意杀人罪追究被告人[姓名略]的刑事责任。被告人[姓名略]因犯容留他人吸毒罪被判处有期徒刑，刑罚执行完毕后五年内再犯应当判处有期徒刑以上刑罚之罪，系累犯，适用《中华人民共和国刑法》第六十五条的规定处罚。被告人[姓名略]一人犯数罪，适用《中华人民共和国刑法》第六十九条的规定数罪并罚。根据《中华人民共和国刑事诉讼法》第一百七十二条的规定，提起公诉，请依法判处。
