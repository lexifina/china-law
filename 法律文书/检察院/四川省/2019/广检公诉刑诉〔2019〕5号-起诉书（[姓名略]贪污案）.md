# 起诉书（[姓名略]贪污案）

广检公诉刑诉〔2019〕5号

被告人[姓名略]，男，1968年**月**日出生，公民身份号码5129281968********，汉族，大专文化程度，原系武胜县**公司财务科**，户籍所在地[地址略]，住[地址略]。因涉嫌贪污罪，于2019年1月24日经武胜县人民检察院决定，同日被武胜县公安局刑事拘留，于2019年2月1日经武胜县人民检察院决定，同日被武胜县公安局逮捕。

本案由华蓥市监察委员会调查终结，由武胜县监察委员会以被告人[姓名略]涉嫌贪污罪，于2019年1月24日移送武胜县人民检察院审查起诉。后因改变管辖，武胜县人民检察院于2019年3月8日报送本院审查起诉。本院受理后，于2019年3月11日已告知被告人有权委托辩护人，依法讯问了被告人，听取了辩护人的意见，审查了全部案件材料。其间，因案情重大、复杂，延长审查起诉期限一次（自2019年4月9日至4月23日）。

经依法审查查明：

1996年2月至2018年11月，被告人[姓名略]一直担任武胜县**公司财务科**。其间，自2004年开始，[姓名略]一直负责参与收取武胜县**公司的售票款并兼做车票售票款的收入账。2011年底，武胜县**公司经理李某某向[姓名略]借钱并承诺给付利息。随后[姓名略]将自己收取的售票款不存入单位银行账户，也不计入公司收入账，而是借给李某某并收取利息。[姓名略]在做售票款收入账的时候，为了平账，便将部分售票员结算单另行保存，不作为附件入账。经查证，[姓名略]将冯某某等人交给他的部分售票员结算单另行保管，同时将冯某某等人存入银行的售票款银行存款凭单结合自己收取的售票员结算单作为售票收入凭证入账，将自己收取的售票款另行保存而不入账。[姓名略]将自己收取的售票款多数存入自己的银行账户，供自己消费、借贷、投资、赌博、购买房产等；少量售票款没有直接存入银行，直接用于个人消费。

通过售票系统结算单原始数据与售票款会计账凭证相关结算单进行对比，2012年2月至2018年5月，[姓名略]通过收取售票款不入账的方式侵吞公款共计2176.86515万元。

另查明，被告人[姓名略]在接到组织通知协助调查时，主动交代了组织未掌握的犯罪事实，系自首。目前已追缴赃款200万元。

认定上述事实的证据如下：

1.书证；2.证人[姓名略]；3.被告人的供述与辩解。

本院认为，被告人[姓名略]在担任武胜县**公司财务科**期间，以非法占有为目的，利用职务上的便利，采取收入不入账的方式侵吞国有公司售票款据为己有，用于自己的消费、借贷、投资、赌博、购买房产等，数额特别巨大，其行为触犯了《中华人民共和国刑法》第三百八十二条第一款、第三百八十三条第一款、第二款的规定，犯罪事实清楚，证据确实、充分，应当以贪污罪追究其刑事责任。根据《中华人民共和国刑事诉讼法》第一百七十六条第一款的规定，提起公诉，请依法判处。

此致
