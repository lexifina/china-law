# 起诉书（[姓名略]故意杀人案）

资检公诉刑诉〔2019〕16号

被告人[姓名略]，男性，1973年**月**日出生，居民身份证号码5110221973********，汉族，初中肄业，务工，出生地四川省乐至县，户籍所在地[地址略]。因涉嫌故意杀人罪，于2018年8月5日被四川省乐至县公安局刑事拘留，同年9月18日经四川省乐至县人民检察院批准，于同日被四川省乐至县公安局逮捕。

本案由四川省乐至县公安局侦查终结，四川省资阳市公安局以被告人[姓名略]涉嫌故意杀人罪，于2018年11月17日向本院移送审查起诉。本院受理后，于同月20日已告知被告人有权委托辩护人，已告知被害人近亲属有权委托诉讼代理人，依法讯问了被告人，听取了指定辩护人的意见，审查了全部案件材料。其间，因部分事实不清、证据不足，退回侦查机关补充侦查一次（自2019年1月1日至1月9日），因案件重大、复杂，延长审查起诉期限一次（自2018年12月18日至2019年1月1日）。

经依法审查查明：

被告人[姓名略]系乐至县**镇**村村民，长期在上海打工。2018年8月1日，[姓名略]从其弟弟王某甲处得知其家中耕地地力保护补贴面积计算有误，遂通过电话与**村村支书被害人王某乙（殁年41岁）联系，要求解决。在与王某乙联系过程中，[姓名略]认为王某乙将其家中的土地划给了他人，导致其家中的耕地地力保护补贴面积减少，遂决定回乐至与王某乙面谈，若不能妥善解决就杀害王某乙。2018年8月2日，[姓名略]从上海返回成都，并在成都购买了作案刀具。同月4日，[姓名略]返回乐至县老家，并于5日早上携带刀具出门找王某乙面谈。当日上午9时许，[姓名略]在乐至县**镇**街一理发店找到王某乙，并质问王某乙土地的事情如何解决。在未得到满意答复后，[姓名略]持刀捅刺被害人王某乙右大腿及胸部，致王某乙当场死亡。经鉴定，被害人王某乙系生前胸部遭受单刃锐器作用致主动脉破裂，大出血死亡。

被告人[姓名略]作案后，当即拨打110投案，并在现场等候，后被公安民警控制。归案后，[姓名略]如实供述了主要犯罪事实。

认定上述事实的证据如下：

1.作案刀具等物证；2.王某甲的银行账户交易记录、2018年**村1组土地耕种面积核实表、**村群众会记录等书证；3.王某甲、李某某、许某某等证人[姓名略]；4.被告人[姓名略]的供述与辩解；5.法医学尸体检验鉴定书、DNA鉴定书、理化检验报告等鉴定意见；6.现场勘验检查工作记录、辨认笔录、提取笔录等勘验、搜查、辨认笔录；7.监控录像、[姓名略]微信聊天记录等视听资料和电子数据。

本院认为，被告人[姓名略]因纠纷而持刀捅刺他人，并致人死亡，其行为触犯了《中华人民共和国刑法》第二百三十二条之规定，犯罪事实清楚，证据确实、充分，应当以故意杀人罪追究其刑事责任。被告人[姓名略]作案后自动投案，如实供述主要犯罪事实，根据《中华人民共和国刑法》第六十七条第一款之规定，系自首。根据《中华人民共和国刑事诉讼法》第一百七十六条第一款的规定，提起公诉，请依法判处。

此致
