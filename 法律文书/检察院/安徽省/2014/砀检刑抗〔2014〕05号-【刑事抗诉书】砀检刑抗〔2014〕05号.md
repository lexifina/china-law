# 【刑事抗诉书】砀检刑抗〔2014〕05号

砀检刑抗〔2014〕05号

砀山县人民法院以（2014）砀刑初字第00098号刑事判决书对被告人[姓名略]、[姓名略]、[姓名略]犯破坏广播电视设施、公用电信设施罪一案判决：被告人[姓名略]犯过失损坏广播电视设施、公用电信设施罪，判处有期徒刑三年，被告人[姓名略]犯过失损坏广播电视设施、公用电信设施罪，判处有期徒刑三年缓刑四年，被告人[姓名略]犯过失损坏广播电视设施、公用电信设施罪，判处有期徒刑三年缓刑四年。本院依法审查后认为，该判决以过失损坏广播电视设施、公用电信设施罪对被告人[姓名略]判处刑罚，属认定事实有误、适用法律不当，导致量刑畸轻。理由如下：

虽然案发二十天前砀山境内发生了龙卷风自然灾害，但并未影响本案中的电缆线正常使用。被告人[姓名略]、[姓名略]与证人郭××均能证实，当时是[姓名略]声称电缆已毁，安排剪断。对于[姓名略]、[姓名略]而言，可能因听信[姓名略]而产生误判，但被告人[姓名略]对自己的行为是明知的，从其一再辩解“劝止未果”，亦可以得知其对剪断电缆线会的结果是明知的，但为了私利，仍提供断线钳并向他人许诺出事由自己负责，指使他人私自剪断电缆线，造成关帝庙等6个乡镇13260名宽带信号中断20小时30分，朱楼镇、关帝庙镇、薛楼工业园区5676户电视信号中断19小时的严重后果。被告人[姓名略]的行为已触犯《中华人民共和国刑法》第一百二十四条第一款，且造成严重后果，应当以破坏广播电视设施、公用电信设施罪处其七年以上有期徒刑。

综上所述，为维护司法公正，准确惩治犯罪，依照《中华人民共和国刑事诉讼法》第二百一十七条的规定，特提出抗诉，请依法判处。
