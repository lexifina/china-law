# 【刑事抗诉书】鸠检刑抗〔2014〕1号

鸠检刑抗〔2014〕1号

芜湖市鸠江区人民法院以（2014）鸠刑一初字第00048号刑事判决书对被告人[姓名略]、尚平、程斌诈骗一案判决，被告人[姓名略]犯诈骗罪判处有期徒刑三年零五个月，并处罚金人民币50000元；被告人尚平犯诈骗罪判处有期徒刑一年零八个月，并处罚金人民币15000元；被告人程斌犯诈骗罪，判处有期徒刑一年零七个月，并处罚金人民币15000元。本院依法审查后认为，该判决确有错误，理由如下：

一、一审判决认定被告人[姓名略]自首，系适用法律错误。

《中华人民共和国刑法》第六十七条第一款规定：犯罪以后自动投案，如实供述自己的罪行，系自首。在本案中，芜湖市公安局四褐山派出所民警因芜湖市发电有限责任公司润滑油被盗一案，电话通知被告人[姓名略]到四褐山派出所接受询问。被告人[姓名略]向公安机关提供线索，并协助公安机关抓获涉嫌掩饰隐瞒犯罪所得的犯罪嫌疑人[姓名略]。在接受询问期间，被告人[姓名略]并没有主动交代其涉嫌诈骗的犯罪事实。因有被害人报案称被告人[姓名略]对其实施诈骗，当天，芜湖市公安局鸠江分局刑警大队也正在查找被告人[姓名略]，因得知被告人正在四褐山派出所，遂到芜湖市公安局四褐山派出所将被告人[姓名略]抓获，并对其涉嫌诈骗的犯罪事实展开讯问。可见，被告人[姓名略]是被芜湖市公安局鸠江分局刑警大队民警抓获归案，其并没有主动、直接地向公安机关投案，因此不能认定被告人[姓名略]为自首。

故芜湖市鸠江区人民法院认定[姓名略]为自首，显属适用法律错误。

二、一审判决对被告人[姓名略]量刑畸轻。

虽然被告人[姓名略]具有立功表现，根据《中华人民共和国刑法》第六十八条第一款的规定，可以从轻或者减轻处罚。但在本案中，被告人[姓名略]的涉案数额达19万元，远超出诈骗罪数额巨大即5万元的起点。同时，[姓名略]在诈骗犯罪犯意的提起、行为的策划、赃款的分配上均起主要作用，系主犯，且未退出赃款。综合以上情节，对被告人[姓名略]的量刑也应在五年至六年有期徒刑的幅度内，而一审判决对被告人[姓名略]仅判处有期徒刑三年零五个月，并处罚金50000元，属于量刑畸轻。

综上所述，本院认为，一审判决适用法律错误，量刑畸轻。为维护司法公正，准确惩治犯罪，依照《中华人民共和国刑事诉讼法》第二百一十七条的规定，特提出抗诉，请依法判处。

此致
