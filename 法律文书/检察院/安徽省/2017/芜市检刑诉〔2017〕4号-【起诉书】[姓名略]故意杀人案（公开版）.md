# 【起诉书】[姓名略]故意杀人案（公开版）

芜市检刑诉〔2017〕4号

被告人[姓名略]，女，1980年**月**日出生，公民身份号码5202031980********，汉族，小学肄业，无业，户籍所在地[地址略]，现住[地址略]。2016年6月6日因涉嫌故意杀人罪被芜湖市公安局弋江分局刑事拘留，同年7月27日经芜湖市弋江区人民检察院批准，由芜湖市公安局弋江分局执行逮捕。

本案由芜湖市公安局弋江分局侦查终结，以被告人[姓名略]涉嫌故意杀人罪，于2016年9月27日经由芜湖市公安局向本院移送审查起诉。本院受理后，已告知被告人有权委托辩护人、被害人[姓名略]有权委托诉讼代理人，依法讯问了被告人，听取了辩护人、被害人[姓名略]的意见，审查了全部案件材料。期间，退回公安机关补充侦查两次，因案情重大复杂，延长审查起诉期限一次。

经依法审查查明：

2016年6月5日13时许，被害人茆某应被告人[姓名略]次女陈某甲之邀来[姓名略]家中玩，陈某甲将茆某带入主卧室。14时许，陈某甲离开主卧室上厕所，在客厅的[姓名略]趁机手持家中放置的橡皮锤进入房内，用锤多次打击茆某头部，直至茆某倒地。[姓名略]随即逃离现场，后被公安机关在小区门口抓获。

经法医鉴定，茆某系被他人持钝器打击头部致重度颅脑损伤死亡。经司法精神病学鉴定，[姓名略]作案时系限制行为能力人。

认定上述事实的证据如下：

1.橡皮锤等物证；

2.受案登记表、抓获经过、被告人的户籍信息、被害人的户籍信息、110接警记录单、芜湖市急救中心电话登记受理单及急救医疗记录等书证；

3.证人陈某乙、陈某甲、毕某某、王某甲、王某乙、陈某丙、韩某某、邰某某、陈某丁、张某甲、张某乙、童某某、卢某某、茆某某等人的证言；

4.被告人[姓名略]的供述与辩解；

5.法医学尸体检验鉴定书、法庭科学DNA鉴定书、司法精神学鉴定、理化检验报告等鉴定意见；

6.现场勘验笔录、人身检查笔录、辨认笔录等。

本院认为，被告人[姓名略]无故持锤多次打击被害人茆某头部致其死亡，非法剥夺他人生命，其行为已触犯《中华人民共和国刑法》第二百三十二条的规定，犯罪事实清楚，证据确实、充分，应当以故意杀人罪追究其刑事责任。鉴于被告人[姓名略]系限制行为能力人,符合《中华人民共和国刑法》第十八条第三款规定之情形。根据《中华人民共和国刑事诉讼法》第一百七十二条的规定，提起公诉，请依法判处。

此致
