# 【刑事抗诉书】相检诉刑抗〔2019〕1号

相检诉刑抗〔2019〕1号

淮北市相山区人民法院以（2018）皖0603刑初142号刑事判决书对被告人[姓名略]诈骗罪、非法采矿罪、串通投标罪、被告人胡某甲、陈某某非法采矿罪、被告人张某某、胡某丙串通投标罪

一案判决：其中，被告人[姓名略]犯非法采矿罪，判处有期徒刑四年，并处罚金人民币一千万元；犯串通投标罪，判处有期徒刑二年六个月，并处罚金人民币一千万元；犯帮助伪造证据罪，判处有期徒刑二年六个月，决定执行有期徒刑八年，并处罚金人民币二千万元。本院依法审查后认为，该判决认定事实有误，适用法律错误，量刑畸轻。

该判决书认定“本案目前在案证据显示，秦某某曾多次向[姓名略]出具借条，并约定借款利息，[姓名略]与秦某某两人的银行账户间亦有多笔资金往来，表明被告人[姓名略]与秦某某之间存在借贷关系，目前的在案证据尚不能排除[姓名略]对秦某某享有超过150万元的债权。赵某某接受债权转让支付对价款，并非是因陷入错误认识而处置财产，且在不能排除被告人[姓名略]对秦某某享有债权的情况下，亦不能认定被告人[姓名略]有非法占有他人财物的故意”，进而认定“[姓名略]的行为不符合诈骗罪的犯罪构成，但被告人[姓名略]以其妹周某乙的名义使用其伪造的证据向人民法院提起诉讼，妨害司法秩序，情节严重，应以帮助伪造证据罪追究其刑事责任”的事实认定错误，适用法律错误，量刑畸轻。

一、根据本案查明的事实，[姓名略]向秦某某提起民事诉讼的目的并非通过正常的民事诉讼确认、索要债务，其真实目的是为帮助秦某某保全正在由被害人赵某某[姓名略]执行的财产。

从秦某某和黄某某之间的录音材料看，能印证[姓名略]向秦某某提起民事诉讼的证据材料是虚假的，且系为保护其财产而提起诉讼事实。如录音中秦某某提到：“不是说弄了半年我想放弃，你说我为了保我的财产”；黄某某提到：“不就是别让赵某某弄完了，还有你欠人家的钱别叫人家弄完了，咱先保着”。根据周某乙的证言，亦证实秦某某没有给其出具过借条，后期向法院提供的借条是[姓名略]安排秦某某后写的借条。若[姓名略]与秦某某在提起民事诉讼前存在真实债权，则[姓名略]可以直接依据秦某某向[姓名略]出具的借条以自己名义直接向法院提起民事诉讼，而无需再通过伪造借条等诉讼证据的方式以他人名义向秦某某提起民事诉讼。且上述伪造证据提起民事诉讼的事实，该判决书亦予以认定，可见[姓名略]向秦某某提起民事诉讼的目的，就是为了帮助秦某某“保全”正在被赵某某[姓名略]执行的财产。

二、秦某某所欠[姓名略]债务在2013年2月提起民事诉讼前已经得到清偿，该判决书认定存在2012年8月7日秦某某出具给[姓名略]的970万元借条，进而认定“在案证据尚不能排除[姓名略]对秦某某享有150万的债权”的事实认定错误。

根据公安机关调取的秦某某、[姓名略]之间的银行账户流水往来显示，[姓名略]向秦某某账户转账9796.1万余元，秦某某向[姓名略]账户转账11357.45万余元，两者相差1591.35万余元，表明秦某某和[姓名略]互相拆借资金行为中，秦某某转给[姓名略]的资金远远大于[姓名略]转给秦某某的资金数额。被告人[姓名略]虽辩解其和秦某某之间有承兑汇票往来，但并未能提供任何秦某某签署的承兑汇票记录、单据等证据。此外，[姓名略]持有970万元借条，并不能否认秦某某已还款的事实。根据银行账户转账明细，2012年8月7日仅有一笔[姓名略]向秦某某转账970万的记录，也即[姓名略]只转给秦某某1次970万元，但却存在秦某某向[姓名略]和周某乙出具的两张同日期的借条，可见借条并不能客观反映秦某某未还款的事实；根据案件证据，无论是从秦某某的供述还是其与黄某某之间的录音材料中，均显示提起诉讼前，秦某某将对孔某某享有的3880余万债权转给[姓名略]，如2014年1月23日秦某某与黄某某录音证据显示，秦某某称：“孔某某那也是总共3880多万，那个合同可是你给起草的咱不知道，那些都转给他了，你想想可是，这乖来，我又多付2000多万”。借款担保协议、债权转让协议及借款合同，亦同时证明：2013年6月20日，[姓名略]与秦某某签订协议，协议中载明秦某某对周某甲、孔某某享有4297.3万元债权，[姓名略]对秦某某享有4500万元债权，双方约定秦某某将对周某甲、孔某某的债权中1060万元转给[姓名略]。2013年6月30日，秦某某与周某甲、孔某某签订借款担保协议书，双方结算周某甲、孔某某尚欠秦某某4600万元。2013年8月3日，[姓名略]与孔某某、李某某、周某甲签订借款合同，合同载明2013年7月30日[姓名略]借款给孔某某、李某某、周某甲3880万元。可见，在[姓名略]向秦某某提起民事诉讼前，秦某某已通过债权转让等方式与[姓名略]达成了债权、债务清算方式，秦某某已对债务进行清偿。该判决依据存在2012年8月7日秦某某出具给[姓名略]的970万元借条，进而认定“在案证据尚不能排除[姓名略]对秦某某享有150万的债权”的事实错误。

三、[姓名略]通过虚假诉讼的方式形成的“民事调解书”所确立的虚假债权，以债权转让方式骗取被害人交付150万现金，其行为应认定为诈骗罪，该判决认定其行为构成帮助伪造证据罪，适用法律错误，以致量刑畸轻。

根据查明的事实，[姓名略]与秦某某进行民事诉讼之目的并非为解决其两人的债务纠纷，而是通过伪造诉讼证据进行虚假诉讼，达到通过法院“确认”债权，进而加入到对被害人[姓名略]的查封房产执行程序之中，为秦某某“保全”财产的目的。后因在执行程序中查封房产三次流拍，[姓名略]利用其前期通过虚假诉讼行为形成的“民事调解书”，以转让该虚假债权中部分债权的方式，使被害人陷入错误认识向其支付150万元。从民事诉讼文书来看，法院民事调解书确认“秦某某支付周某乙借款2280万元本金及利息230万余元”，查封的秦某某7套房产价值也远远高于150万元，若被告人[姓名略]真实享有对秦某某的2000余万债权，且在具有可供执行的财产情况下，仅向被害人转让150万元债权即放弃其他可执行财产，亦不合符合常理。因此，[姓名略]的行为应认为诈骗，该判决认定[姓名略]的行为构成帮助伪造证据罪，适用法律错误，以致量刑畸轻。

综上所述，淮北市相山区人民法院（2018）皖0603刑初142号刑事判决书，认定不能排除被告人[姓名略]对秦某某享有债权的情况下，亦不能认定被告人[姓名略]有非法占有他人财物的故意，认定[姓名略]的行为构成帮助伪造证据罪的事实认定错误，导致对其适用法律错误，量刑畸轻。为维护司法公正，准确惩治犯罪，依照《中华人民共和国刑事诉讼法》第二百二十八条的规定，特提出抗诉，请依法判处。
