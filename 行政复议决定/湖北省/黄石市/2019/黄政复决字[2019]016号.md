# 黄石市人民政府行政复议决定书（黄政复决字[2019]016号）

黄政复决字[2019]016号

申请人：杨开伟

被申请人：黄石市下陆区市场监督管理局

申请人对原黄石市下陆区食品药品监督管理局（以下简称下陆区食药监局）作出的《投诉举报回复函》不服，于2019年3月19日向本机关申请行政复议，本机关依法予以受理。依据黄石市下陆区机构改革方案，原下陆区食药监局重新组建为黄石市下陆区市场监督管理局，原下陆区食药监局不再保留，故本案被申请人为黄石市下陆区市场监督管理局。案件现已审理终结。

申请人请求：撤销《投诉举报回复函》；责令被申请人在一定期限内重新作出具体行政行为。

申请人称：2019年1月14日，申请人向下陆区食药监局书面举报黄石市白鹭禽蛋加工厂生产的“华丰源松花鸭皮蛋”未标注质量等级不符合食品安全标准，请求其依法查处违法线索，对违法线索处以行政处罚，处罚完毕后奖励申请人。下陆区食药监局于2019年1月31日作出《投诉举报回复函》认定是瑕疵。《食品安全法实施条例》征求意见稿明确食品、食品添加剂的标签、说明书存在瑕疵，是指标签、说明书在字符间距、字体大小、标点符号等非食品安全标签和说明书实质内容存在不符合规定的情形，不影响食品安全，且不会对消费者的食品安全消费造成误导的情形。涉案产品违反禁止性条款，下陆区食药监局却称是瑕疵，将生产销售不符合食品安全标准的食品称之为瑕疵明显不当。

被申请人称：我机关积极履行法定职责，对申请人的投诉举报从受理、处罚、回复到后处理均符合法定程序，不存在申请人所说的纵容违法的问题。涉案皮蛋未标注质量等级，经查主要原因是近年来食品安全相关法规及标准多次修订，该企业没有适应变化，但并无主观故意，食品的各项指数符合所标注的具体内容，并没有欺诈和误导消费者。涉案皮蛋的生产厂家在生产过程中没有对该产品进行分类，所以在标签标识上没有标注优级、一级、二级。另外，生产厂家也没有根据三个等级的标准对该产品进行定价，不存在误导消费者的行为。正由于上述原因，所以在标签上并未标注等级划分。由于禽蛋类产品的主要危害在于重金属、食品添加剂等是否超标，我机关在履职过程中早前已委托第三方检测公司进行过监督抽检，抽检结果合格。但由于涉案产品的标签确有瑕疵，我局执法人员对该单位下达了责令改正通知书，给予该单位警告的行政处罚合情合理合法。申请人实质是对我机关行政处罚认定的事实及定性、法律适用和处罚结果不服，该行政处罚与申请人并无利害关系，申请人不具有对该处罚决定不服而申请行政复议的权利。

经查：2019年1月9日，申请人在大润发超市购买了一盒由黄石市白鹭禽蛋加工厂生产的松花鸭皮蛋。1月14日，申请人向原黄石市下陆区食药监局投诉举报该厂生产销售不符合食品安全标准的食品，生产的松花鸭皮蛋未标注质量等级，违反《食品安全法》相关规定，请求原下陆区食药监局依法调查并作出处理、书面反馈处理结果并给予奖励。1月18日，原下陆区食药监局收到申请人的投诉举报信，1月20日，原下陆区食药监局执法人员到黄石市白鹭禽蛋加工厂进行检查，当场下达了责令改正通知书，责令停止使用松花鸭皮蛋预包装标识标签存在瑕疵的产品。同时，执法人员当场作出了行政处罚决定，决定给予黄石市白鹭禽蛋加工厂警告的行政处罚。1月31日，原下陆区食药监局作出《投诉举报回复函》，称“……企业产品标签无故意诱导消费者且并不影响食品安全，依据《食品安全法》第125条第2款…的规定，我局已对其给予了警告并下达了责令改正通知书”，2月21日，向申请人邮寄送达了上述回复函。申请人对此回复函不服，于3月19日向本机关申请行政复议。

另，涉案松花皮蛋执行标准为GB/T9694《中华人民共和国国家标准-皮蛋》，该标准按感官要求（外观、形态、颜色、气味与滋味、破损率）将皮蛋划分为三个等级：优级、一级、二级，其8.1“标签与标志”规定预包装产品销售包装的标签按GB7718执行。而GB7718-2011《食品安全国家标准-预包装食品标签通则》其4.1.11.4“质量（品质等级）”规定食品所执行的相应产品标准已明确规定质量（品质等级）的，应标示质量（品质等级）。

以上事实，主要有以下证据证实：①《投诉举报书》；②《现场检查笔录》、（鄂黄）食药监（食）责改〔2019〕01-03号《责令改正通知书》、（黄下）食药监（食）当罚〔2019〕0120101号《当场行政处罚决定书》；③《投诉举报回复函》等证据。

本机关认为：依据《中华人民共和国食品安全法》第六条及《食品药品投诉举报管理办法》第五条的规定，被申请人具有对本行政区域的食品药品投诉举报作出相关行政行为的行政职权。

根据《食品药品投诉举报管理办法》第十五条、第十九条和第二十条的规定，食品药品监督管理部门接到投诉举报后，应当于收到之日起5日内作出是否受理的决定，予以受理的应当自投诉举报受理之日起60日内向投诉举报人反馈办理结果。本案中，被申请人接到申请人的投诉举报后予以受理，前往被投诉举报人处进行现场调查，在60日内向申请人反馈了案件办理结果，案件办理程序合法。

被申请人接到投诉举报后，经调查认为涉案松花皮蛋标签存在的问题符合《食品安全法》第一百二十五条第二款“生产经营的食品、食品添加剂的标签、说明书存在瑕疵但不影响食品安全且不会对消费者造成误导的，由县级以上人民政府食品安全监督管理部门责令改正”的规定，并以此作出责令改正决定和行政处罚。故，被申请人作出的《投诉举报回复函》内容并无不当。

本案经提交市行政复议委员会讨论，根据《中华人民共和国行政复议法》第二十八条第一款第（一）项规定，本机关决定：

维持原下陆区食药监局于2019年1月31日作出的《投诉举报回复函》。

若不服本决定，可以自接到本决定书之日起15日内向人民法院提起行政诉讼。

2019年5月8日
