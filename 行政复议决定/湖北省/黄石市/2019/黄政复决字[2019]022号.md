# 黄石市人民政府行政复议决定书（黄政复决字[2019]022号）

黄政复决字[2019]022号

申请人：[姓名略]

被申请人：西塞山区城市管理执法局

申请人对西塞山区行政综合执法局作出的西行政执拆决字第7000448号《限期拆除决定书》不服，于2019年4月19日向本机关申请行政复议，本机关依法予以受理。依据西塞山区机构改革方案，西塞山区行政综合执法局的职责转入西塞山区城市管理执法局，西塞山区行政综合执法局不再保留，故本案被申请人为西塞山区城市管理执法局。案件现已审理终结。

申请人请求：撤销西行政执拆决字第7000448号《限期拆除决定书》；赔偿因强制拆除造成的经济损失。

申请人称：申请人父亲陈杰身患神经硬化症，冬天急需阳光日晒，因家中无阳台，所以于2018年12月4日20时许制作好不锈钢阳台在家中二楼安装，被被申请人工作人员发现后叫停。12月6日，被申请人送来《限期拆除决定书》，陈杰不服提起了行政复议。2019年1月31日，被申请人再次下达了限期拆除决定，并于2月2日对未完工的不锈钢阳台进行强制拆除，没收了阳台材料。陈杰在自家二楼搭建的阳台没有使用土地，申请不了《建设用地规划许可证》、《土地使用权证》，根本无法获得《建筑工程规划许可证》，所以陈杰不能按照建设工程规划许可证的规定进行建设，也就是说在自家搭建阳台不需要向相关部门提出申请报批手续，陈杰也就不存在“实施了未取得建设工程规划许可证建设建筑物（构筑物）行为”，用《城乡规划法》第40条、第64条的规定处罚陈杰搭建阳台是适用法律不当，是滥用法律条款，属于行政乱作为。

被申请人称：申请人未取得建设工程规划许可证搭建阳台的违法事实清楚，有现场勘查及调查记录、照片等证据证实，申请人对其违反规划工程许可的行为也承认在卷。我机关办案程序合法，我机关在对本案处理过程中，依法进行了立案、勘查、现场调查、拍照取证，送达了《责令停止违法建设通知书》，经向规划部门核实涉案构筑物未经办理规划许可证后，向申请人送达了《限期拆除决定书》，行政行为遵循法律的规定进行。我机关履行行政拆除职责是为了加强城乡规划管理，不是申请人所称的行政处罚。综上，我机关对违法建造构筑物作出的决定依法有效，请求维持限期拆除决定。

经查：2018年12月4日20时许，被申请人执法人员巡查发现陈杰在其二楼房屋外墙搭建一钢架阳台，当场予以制止。12月5日，被申请人对该案予以立案调查，12月6日向陈杰送达西行政执责停建字7001126号《责令停止违法建设通知书》和西行政执拆决字第7000071号《限期拆除决定书》，称陈杰于2018年12月5日前在西塞山区民政局旁实施了未取得建设工程规划许可证建设建筑物（构筑物）行为，违反了《城乡规划法》第四十条之规定，依据《城乡规划法》第六十四条之规定，责令陈杰立即停止违法建设，于2018年12月6日前自行拆除该违法建筑。陈杰不服，于12月7日向黄石市人民政府申请行政复议。2019年1月21日，黄石市人民政府作出黄政复决字〔2018〕197号《行政复议决定书》，认为：陈杰未取得建设工程规划许可证即进行施工，违反了《城乡规划法》第四十条规定，被申请人根据《城乡规划法》第六十四条作出限期拆除决定并无不当；但西行政执拆决字第7000071号《限期拆除决定书》将“**大道**栋**”作为当事人明显错误，但上述错误不影响对陈杰未取得建设工程规划许可证建设构筑物行为的认定，不影响对涉案钢架阳台应予限期拆除的决定，最终决定确认西行政执拆决字第7000071号《限期拆除决定书》主体违法。2019年1月22日，黄政复决字〔2018〕197号《行政复议决定书》送达被申请人。1月31日，被申请人作出涉案西行政执拆决字第7000448号《限期拆除决定书》，认为[姓名略]于2019年1月31日前在**大道**栋**号实施了未取得建设工程规划许可证建设建筑物（构筑物）行为，建筑面积4平方米，钢架结构，层次一层，违反了《城乡规划法》第四十条之规定，依据《城乡规划法》第六十四条之规定，责令[姓名略]于2019年2月2日前自行拆除该违法建筑。申请人[姓名略]不服，委托父亲陈杰向本机关提起行政复议。

另查明，涉案房屋登记所有权人为[姓名略]，由其父亲陈杰实际居住。

以上事实，主要有以下证据证实：①《现场勘查记录》；②《视听资料证据》；③西行政执拆决字第7000448号《限期拆除决定书》；④黄政复决字〔2018〕197号《行政复议决定书》等证据。

本机关认为：本案中，涉案钢架阳台系由陈杰请人制作并安装，陈杰在其房屋外墙增建钢架阳台的行为属于在城市规划区内建设构筑物的行为，根据《城乡规划法》第四十条“在城市、镇规划区内进行建筑物、构筑物、道路、管线和其他工程建设的，建设单位或者个人应当向城市、县人民政府城乡规划主管部门或者……申请办理建设工程规划许可证”的规定，应当申请办理建设工程规划许可证。陈杰未取得建设工程规划许可证即进行施工，违反了上述规定。根据《城乡规划法》第六十四条的规定，上述钢架阳台应当予以限期拆除。

申请人[姓名略]虽系涉案房屋所有权人，但并未居住在涉案房屋，涉案钢架阳台并非其请人制作和安装，也未有证据证明其委托或指使他人安装，陈杰自述涉案钢架阳台系由其请人制作和安装，被申请人作出的涉案限期拆除决定将申请人[姓名略]作为违法行为当事人明显不当。且，在涉案房屋外墙搭建钢架阳台的违法行为，被申请人已作出过西行政执拆决字第7000071号《限期拆除决定书》，该限期拆除决定未被撤销，被申请人作出涉案限期拆除决定属重复作为。

至于申请人提出的赔偿损失的请求，因在涉案房屋外墙增建钢架阳台的行为违法事实清楚，应当予以拆除，且申请人也未向本机关提供所受损失的证据材料，故对该项请求不予支持。

本案经提交市行政复议委员会讨论，根据《中华人民共和国行政复议法》第二十八条第一款第（三）项和《中华人民共和国行政复议法实施条例》第二十一条第（二）项、第四十八条第一款第（二）项规定，本机关决定：

一、撤销西行政执拆决字第7000448号《限期拆除决定书》；

二、驳回申请人赔偿损失请求。

若不服本决定，可以自接到本决定书之日起15日内向人民法院提起行政诉讼。

2019年5月28日
