# 黄石市人民政府行政复议决定书（黄政复决字[2019]028号）

黄政复决字[2019]028号

申请人：张丕洪

被申请人：黄石市人力资源和社会保障局

申请人不服被申请人对其的养老金待遇核定，于2019年4月23日向本机关申请行政复议，本机关依法予以受理，现已审理终结。

申请人请求：请求被申请人重新核定申请人的养老金。

申请人称：从退休审批表上看，单位存在少缴、未缴社会保险费的情况，如2001—2005年和2007年等。根据社会保险法的规定，用人单位未按时缴纳社会保险费的，由征费机构责令企业缴纳和补足，并可申请法院强制执行。用人单位未缴和少缴不能降低缴费指数，也不应按用人单位缴费多少确定缴费指数。从社会保险费缴纳开始至2005年12月31日止，只有按省、市规定足额按时缴费，而没有十档之分，也就是按现在缴费的第五档的缴费指数1.0计算，申请人这11年的缴费指数合计为11.0，而退休审批表上这11年缴费指数是3.001，相差7.999，据此平均指数由原0.736改为0.9577。另，黄石交运集团少缴和未缴也导致个人账户储存额减少。

被申请人称：经核实，申请人档案记载出生时间为1959年，1978年参加工作，2014年12月经单位申报办理特殊工种提前退休手续。退休时核定的基本养老金为1414.25元，经重新核算，其基本养老金仍为1414.25元。申请人视同缴费年限为17.08年，视同缴费年限指数为17.08。实际缴费年限为19年，实际缴费指数为1996年1月1日至2014年12月期间参保人员及所在单位历年实际缴费基数与实际缴费上年度在岗职工平均工资的比值，累计为9.476。全程缴费指数为26.556。关于未缴和少缴的问题，经查，市交运集团于2009年补缴欠费570万元，其中包括申请人2008年以前的欠费。根据《湖北省城镇用人单位职工基本养老保险费补缴暂行办法》第四条“对原欠缴基本养老保险费以后补缴的，核定其退休待遇时，原欠资年度的缴费指数，应按实际缴费当年度的职工平均工资来计算，不能直接按欠缴当年度职工平均工资来计算”的规定，申请人的平均缴费指数为0.736。另外，关于缴费基数与实际不符，根据《关于完善企业职工基本养老保险若干政策问题的暂行处理意见》第十四条的规定，申请人未在有效时间内向市社会保险事业局申请复查补缴。综上，我局核定申请人养老金待遇符合政策规定。

经查：申请人于1959年出生，1978年参加工作，退休前系黄石市交通运输集团有限公司职工。2014年11月，黄石市交通运输集团有限公司为申请人申报特殊工种提前退休。2014年12月，被申请人准予申请人退休，核定计算缴费年限的起始时间为1978年12月，退休后月基本养老金为1414.25元，从2015年1月起执行。申请人退休审批表记载的申请人1996年—2014年养老保险费缴纳情况如下表：

我市建立基本养老保险个人账户的时间为1996年1月1日，根据原湖北省劳动和社会保障厅《关于改革企业职工基本养老金计发办法的通知》（鄂劳社文〔2006〕169号）第二条“缴费年限包括视同缴费年限和实际缴费年限。视同缴费年限指参保人员在建立基本养老保险个人账户前符合国家政策规定的连续工龄；实际缴费年限指参保人员在建立个人账户之后单位和个人共同缴纳基本养老保险费的时间”的规定，申请人的视同缴费年限为17.08年，实际缴费年限为19年，总缴纳年限为36.08年。黄石市2013年度在岗职工月平均工资为2796元。申请人退休时个人账户储存额为16460.26元。

申请人对被申请人发放的养老金数额不服，认为被申请人计算缴费指数有误，向本机关申请行政复议。

以上事实，主要有以下证据证实：《黄石市企业职工从事特殊工种提前退休审批表》等证据。

本机关认为：本案中，根据原湖北省劳动和社会保障厅《关于改革企业职工基本养老金计发办法的通知》第一条的规定，申请人退休后可享受的养老金包括基础养老金、个人账户养老金、过渡性养老金和调节性养老金20元/月，上述养老金由我市2013年度在岗职工月平均工资、缴费年限、缴费指数和个人账户储存额计算确定。申请人对我市2013年度在岗职工月平均工资、其缴费年限、视同缴费年限指数和记载的个人账户储存额未表示异议，但对实际缴费年限的缴费指数有异议。而1996年1月1日—2005年12月31日期间的实际缴费年限指数按本人当年度缴费基数与我市当年度在岗职工平均工资的比值计算，2006年1月1日之后的实际缴费年限指数按本人当年缴费基数与我市上年度在岗职工平均工资的比值计算，故，本案的实质问题是申请人当年缴费基数及缴费指数如何计算的问题。黄石市交通运输集团有限公司在2004年、2007年和2008年未缴纳申请人的养老保险费，在2003年、2005年等年度未足额缴纳申请人的养老保险费，导致申请人当年缴费指数比正常缴费情况下低。黄石市交通运输集团有限公司在2009年补缴了申请人2008年以前的欠费，被申请人根据《湖北省城镇用人单位职工基本养老保险费补缴暂行办法》第四条第四项“对原欠缴基本养老保险费以后补缴的，核定其退休待遇时，原欠资年度的缴费指数，应按实际缴费当年度的职工平均工资来计算，不能直接按欠缴当年度职工平均工资来计算”的规定，来计算申请人欠资年度的缴费指数并无不当。综上，被申请人根据申请人养老保险费的实际缴纳情况，依据原湖北省劳动和社会保障厅《关于改革企业职工基本养老金计发办法的通知》的规定计算申请人的养老金符合规定。

至于申请人提到的黄石市交通运输集团有限公司未缴和少缴申请人养老保险费，被申请人应责令黄石市交通运输集团有限公司限期缴纳和补足的理由，不属于本案审查范围。

本案经提交市行政复议委员会讨论，根据《中华人民共和国行政复议法》第二十八条第一款第（一）项规定，本机关决定：

维持被申请人对申请人的退休时养老金待遇核定行为。

若不服本决定，可以自接到本决定书之日起15日内向人民法院提起行政诉讼。

2019年6月24日
