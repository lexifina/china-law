# 黄石市人民政府行政复议决定书（黄政复决字[2019]037号）

黄政复决字[2019]037号

申请人：黄石德立翔工贸有限公司

被申请人：黄石市西塞山区人民政府

申请人不服被申请人作出的《政府信息公开答复书》，于2019年5月10日向本机关申请行政复议，本机关依法予以受理，现已审理终结。

申请人请求：撤销黄石市西塞山区人民政府办公室于2019年3月12日作出的《政府信息公开答复书》；依法公开申请人申请公开的请求事项。

申请人称：我公司申请公开的主体为西塞山区人民政府，并非西塞山区人民政府办公室。《政府信息公开答复书》认为我公司申请的信息不属于西塞山区人民政府办公室制作的内容没有事实与法律依据，被申请人作为法定的公开部门依法应予以公开，而非推诿给其他部门。西塞山区人民政府办公室认为申请人申请信息指向不明没有事实与法律依据，“申请内容不明确的，应当告知申请人作出更改、补充”，而无指向不明确一说。

被申请人称：西塞山区人民政府办公室有权就申请人申请的政府信息公开事宜进行答复。西塞山区人民政府办公室是西塞山区人民政府的工作部门，其工作职能包括全区政务信息工作，指导、监督全区政府系统信息公开工作等。其次，根据《政府信息公开条例》第二条的规定，县级以上地方人民政府办公厅（室）是本行政区域政府信息公开工作主管部门，负责推进、指导、协调、监督本行政区域的政府信息公开工作。申请人第一项申请事项涉及土地性质及规划用途的相关问题，其职权由黄石市自然资源和规划局行使。申请人第一项申请公开的信息不属于我机关制作的信息，不应由我机关履行公开义务。申请人第二项申请事项指向的内容不明确，我机关的答复符合相关规定。“各级政府”、“西塞山区企业关停整改的详细信息”均不明确，且企业关停整改有可能涉及到行政处罚的事项，关于行政处罚的相关信息不属于我机关制作，不应由我机关公开。我机关作出的政府信息公开答复程序合法。综上，申请人的复议请求没有事实和法律依据，我机关作出的《政府信息公开答复书》合法有效，应予以维持。

经查：2019年2月21日，申请人通过邮政EMS快递（单号1047173550531）向被申请人邮寄一份《信息公开申请书》，申请被申请人公开“原河口镇水泥厂地块土地性质已变更为商住用地的详细信息和各级政府从2013年至2018年对西塞山区企业关停整改的详细信息”。被申请人于2019年2月22日签收该信件，3月12日，西塞山区人民政府办公室作出《政府信息公开答复书》，称：1、“原河口镇水泥厂地块土地性质已变更为商住用地的详细信息”不属于西塞山区人民政府办公室制作的内容，根据《政府信息公开条例》第二十一条第三项的规定，应向黄石市自然资源和规划局进行申请公开；2、“各级政府从2013年至2018年对西塞山区企业关停整改的详细信息”指向不明确，根据《政府信息公开条例》第二十一条关于“申请内容不明确的，应当告知申请人作出更改、补充”的规定，请申请人对申请公开的政府信息内容进一步明确。被申请人当天将《政府信息公开答复书》邮寄送达申请人，申请人不服，向本机关申请行政复议。

另查明，根据《西塞山区人民政府办公室主要职责、内设机构和人员编制规定》，西塞山区人民政府办公室负责全区政务信息工作，指导、监督全区政府系统信息公开工作。

以上事实，主要有以下证据证实：①《信息公开申请书》；②《政府信息公开答复书》、送达回证；③《西塞山区人民政府办公室主要职责、内设机构和人员编制规定》等证据。

本机关认为：本案中，西塞山区人民政府办公室作为西塞山区人民政府的政府信息公开工作机构，根据《中华人民共和国政府信息公开条例》（2008年施行版，以下均同）第四条的规定，负责本行政机关政府信息公开的日常工作，具体承办本行政机关的政府信息公开事宜。因此，西塞山区人民政府办公室对申请人的政府信息公开申请进行答复并无不当。

申请人申请公开的“原河口镇水泥厂地块土地性质已变更为商住用地的详细信息”涉及土地性质和规划用途变更的问题，属于土地管理部门和城乡规划主管部门的职能范围，其相关文件应由上述两部门制作。根据《政府信息公开条例》第十七条“行政机关制作的政府信息，由制作该政府信息的行政机关负责公开”的规定，申请人申请的此政府信息不应由被申请人公开，故被申请人依据《政府信息公开条例》第二十一条第三项“依法不属于本行政机关公开或者该政府信息不存在的，应当告知申请人，对能够确定该政府信息的公开机关的，应当告知申请人该行政机关的名称、联系方式”的规定，告知申请人向黄石市自然资源和规划局申请公开并无不当，虽未书面告知黄石市自然资源和规划局的联系方式，但属瑕疵，申请人可通过其他方式获得，不影响申请人前往黄石市自然资源和规划局处申请公开。

申请人申请公开的“各级政府从2013年至2018年对西塞山区企业关停整改的详细信息”不明确，被申请人告知申请人对申请公开的政府信息内容进一步明确符合《政府信息公开条例》第二十一条第四项“申请内容不明确的，应当告知申请人作出更改、补充”的规定。且，《国务院办公厅关于做好政府信息依申请公开工作的意见》（国办发〔2010〕5号）第二条明确行政机关一般不承担为申请人汇总、加工或重新制作政府信息，以及向其他行政机关和公民、法人或者其他组织搜集信息的义务。

另，申请人在法定期限内书面对申请人的政府信息公开申请进行答复，程序合法。

本案经提交市行政复议委员会讨论，根据《中华人民共和国行政复议法》第二十八条第一款第（一）项规定，本机关决定：

维持被申请人于2019年3月12日作出的《政府信息公开答复书》。

若不服本决定，可以自接到本决定书之日起15日内向人民法院提起行政诉讼。

2019年7月2日
