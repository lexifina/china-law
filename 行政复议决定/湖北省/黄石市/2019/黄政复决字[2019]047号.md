# 黄石市人民政府行政复议决定书（黄政复决字[2019]047号）

黄政复决字[2019]047号

申请人：朱细兴

被申请人：黄石市人力资源和社会保障局

申请人对被申请人不予审批其特殊工种提前退休申请不服，于2019年7月29日向本机关申请行政复议，本机关依法予以受理。现已审理终结。

申请人请求：撤销被申请人作出的《黄石市职工特殊工种提前退休审批结论告知书》。

申请人称：我是1985年冶钢集团机制厂铸造车间除沙组一名员工，1987年脚在工作中受伤，1991年转为冶钢集团实业公司电镀厂员工。机制厂是高温作业，电镀厂是有毒有害作业，在生存的重压下咬牙坚持下来，做了20年的特殊工种，如今到了退休的年龄，却不给我办理退休。我请求按法律和政策执行，享受退休待遇。

被申请人称：1976年，大冶钢厂为解决本单位老职工两地分居问题，走“五七”道路，创办了冶钢农场。80年代初期，农场开办了一批工副企业，安排了一批农业户口的职工家属及其子女，但他们没有到劳动部门办理招工手续。按当时的政策，企业招收工人，必须经国家下达用人计划，到劳动部门办理招工手续。1991年8月，冶钢农场更名为冶钢工副公司后，对所属企业使用的农民工进行了清理整顿，并依据企业与劳动者签订的临时用工合同进行了登记注册，即所谓“注册农工”。本人档案中记载的《职工档案参加工作时间确认审核表》只能作为认定其本人参加工作时间的依据，而不是通过计划指标办理的正式的招工手续。根据《省人力资源和社会保障厅关于化解过剩产能职工过程中做好职工信息认定工作的通知》第一条第三款的规定，申报特殊工种提前退休的职工应经原县级以上劳动（人事）部门办理正式招收（录用）手续。由于申请人未经县级以上劳动（人事）部门办理正式招收（录用）手续，因此不符合特殊工种提前退休的条件。

经查：1976年，冶钢集团走“五七”道路，为解决老职工两地分居问题，在大冶湖围湖造田，创办了冶钢农场。1977年-1979年分别将职工的配偶及子女从原籍迁往农场。八十年代初期，农场为解决人多田地少的矛盾，创办了一批为钢铁服务的集体工副企业，安排了一批职工非城镇户口的家属和子女从事非农业性生产经营活动。1991年8月，冶钢农场更名为冶钢工副公司后，为加强对企业劳动用工规范管理，对所属企业使用非城镇户口的农民工进行了清理整顿，并依据企业与劳动者签订的临时用工合同，审核登记、评定工资、建档造册，即“注册农工”，共有1230人。1992年，冶钢改制，成立冶钢实业总公司，原工副公司所属企业使用的“注册农工”随同企业一起合并到冶钢实业总公司。1997年12月，《市劳动局对冶钢集团实业总公司关于解决“注册农工”遗留问题现场办公会议纪要》决定“注册农工”的工龄自1991年8月冶钢工副公司进行审核登记注册时起开始计算。2006年5月17日，黄石市劳动和社会保障局根据上述会议纪要精神，确认申请人1991年8月参加工作。申请人的《职工档案参加工作时间确认审核表》记载申请人1991年8月-2003年10月在冶钢实业公司电镀厂工作。

2019年6月，申请人向被申请人申请办理特殊工种提前退休手续，被申请人于2019年7月26日作出《黄石市职工特殊工种提前退休审批结论告知书》，认定申请人不符合特殊工种提前退休条件。申请人不服，向本机关申请行政复议。

另，根据1986年7月12日国务院发布的《国营企业招用工人暂行规定》第十一条，企业招用工人，应当向当地劳动行政主管部门办理录用手续。申请人到冶钢集团工作未经当地劳动行政主管部门办理招收录用手续。

以上事实，主要有以下证据证实：①《市劳动局对冶钢集团实业总公司关于解决“注册农工”遗留问题现场办公会议纪要》；②《职工档案参加工作时间确认审核表》等证据。

本机关认为：根据《国务院关于工人退休、退职的暂行办法》第一条的规定，对于特殊工种提前退休的审批，退休职工首先须为全民所有制企业、事业单位和党政机关、群众团体的工人。《省人力资源和社会保障厅关于化解过剩产能职工安置过程中做好职工信息认定工作的通知》（鄂人社函〔2016〕407号）第一条第三款也规定申报特殊工种提前退休的职工应当经原县级以上劳动（人事）部门办理过正式招收（录用）手续。本案中，由于申请人未经劳动（人事）部门办理过正式招收（录用）手续，不满足特定的身份条件，不属于特殊工种提前退休的对象。因此，被申请人不予批准申请人的特殊工种提前退休申请并无不当。

综上，根据《中华人民共和国行政复议法》第二十八条第一款第（一）项规定，本机关决定：

维持被申请人对申请人的特殊工种提前退休申请不予批准行政行为。

若不服本决定，可以自接到本决定书之日起15日内向人民法院提起行政诉讼。

2019年9月29日
