# 国务院关于贵阳市城市总体规划的批复

贵州省人民政府：

国务院原则同意你省报来的贵阳市城市总体规划，现批复如下：

贵阳是贵州省各民族政治、经济、文化中心，是我国西南地区重要的交通枢纽之一。由于贵阳市地理条件的限制，今后要严格控制市中心区的发展规模，合理发展外围城镇群。市中心区的人口到本世纪末应控制在六十万人左右，要通过严格控制人口的增长和调整布局来缓解其拥挤状况。今后，工业项目原则上应放在外围城镇。外围城镇的建设要结合全市的经济和社会发展规划，做好工业选址和统一规划。近期要有重点地建设好白云、新添、小河等城镇，逐步建成具有一定规模、基础设施比较完善、生活设施比较配套、相对独立的城镇。

在实施规划中，要大力加强城市基础设施的建设和河道治理，落实工业污染的治理措施，搞好排水系统和污水处理工作。要加强绿化建设，提高市中心区的绿化面积，使城市环境质量有较大的改善。要进一步搞好城市交通道路的规划，首先要有计划地改造不合理的路段和路口，适应市内和对外交通发展的需要。要根据财力、物力的可能搞好城市煤气工程建设，要在试点的基础上，认真总结经验，本着经济、合理的原则做好煤气统一规划、合理分区工作。要进一步落实水资源的开发工作，认真解决城市供水水源的开发与利用，加强对水库的管理，确保城市安全和供水水质。贵阳市周围有优美的自然景观和人文景观，旅游资源十分丰富，旅游业的发展要有计划、有步骤地进行，并注意提高旅游服务质量。要进一步提高建筑艺术水平，创造具有地方风格和多民族特色的城市面貌。

为适应城市经济体制改革和对外开放、对内搞活的需要，应在研究城市经济和社会发展战略的基础上，进一步搞好市域范围内的城镇布局，并编制好详细规划，使城市规划工作不断深化，为规划的实施和管理提供可靠依据。

城市总体规划是建设城市和管理城市的依据，要根据国务院批准的城市总体规划和国家有关法规制定实施细则，依法加强城市管理。驻贵阳市各级党、政、军、企事业单位都要模范遵守城市规划，服从规划管理，同心协力把贵阳建设成为经济发达、文化昌盛、环境优美的社会主义现代化城市。

国 务 院

一九八六年十一月十日
