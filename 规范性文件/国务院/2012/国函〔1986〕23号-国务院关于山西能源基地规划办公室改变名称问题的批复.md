# 国务院关于山西能源基地规划办公室改变名称问题的批复

国务院山西能源基地规划办公室：

你办一月三日要求改变名称的报告收悉。鉴于你办目前规划工作的范围已扩展到内蒙古、河南、陕西和宁夏等地，“山西能源基地规划办公室”这个名称已不能准确地反映实际情况，国务院同意你办改称“国务院能源基地规划办公室”。名称改变后，规划工作的范围为山西、宁夏、陕西北部、内蒙古西部和河南西部地区。

国 务 院

一九八六年二月十七日
