# 国务院、中央军委对我国“三机”研制成功的贺信

航空航天工业部:

欣悉你部承担的歼教七、歼七Ⅲ、歼八Ⅱ型飞机设计研制任务已胜利完成，并相继批准设计定型。国务院、中央军委向所有参与“三机”研制的同志，表示热烈的祝贺和亲切的慰问。

“三机”的研制成功，是广大科技人员、工人、干部发扬自力更生、艰苦奋斗、顽强拼搏精神取得的丰硕成果;是有关省市和部门，以及空军、海军大力支持的结果;表明我国航空工业由测绘仿制阶段进入了自行设计研制新型飞机的阶段。这对于加强我军航空兵部队的空中作战防御能力，增强我国军用飞机的出口创汇能力,具有重大的意义。

希望你们认真总结经验，再接再厉，坚持改革创新，不断提高科研和生产水平，为我军装备现代化和国民经济建设做出新的贡献。

国 务 院

中央军委

一九八八年十一月十六日
