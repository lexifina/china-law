# 国务院关于同意设立“全国交通安全日”的批复

公安部：

你部《关于将12月2日设立为“全国交通安全日”的请示》（公部请〔2012〕83号）收悉。同意自2012年起，将每年12月2日设立为“全国交通安全日”。具体工作由你部商有关部门组织实施。

国 务 院

2012年11月18日
