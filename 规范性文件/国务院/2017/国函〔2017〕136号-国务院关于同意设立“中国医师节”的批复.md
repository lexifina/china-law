# 国务院关于同意设立“中国医师节”的批复

国家卫生计生委：

你委《关于申请设立“中国医师节”的请示》（国卫办报〔2017〕138号）收悉。同意自2018年起，将每年8月19日设立为“中国医师节”。具体工作由你委商有关部门组织实施。

国务院

2017年11月3日

（此件公开发布）
