# 国务院关于同意设立“中国品牌日”的批复

国家发展改革委：

你委《关于设立“中国品牌日”的请示》（发改产业〔2016〕2484号）收悉。同意自2017年起，将每年5月10日设立为“中国品牌日”。具体工作由你委商有关部门组织实施。

国务院

2017年4月24日

（此件公开发布）
