# 国务院关于同意设立“残疾预防日”的批复

中国残疾人联合会：

你会《关于设立“全国残疾预防日”的请示》（残联发〔2016〕75号）收悉。同意自2017年起，将每年8月25日设立为“残疾预防日”。具体工作由你会商有关部门组织实施。

国务院

2017年6月24日

（此件公开发布）
