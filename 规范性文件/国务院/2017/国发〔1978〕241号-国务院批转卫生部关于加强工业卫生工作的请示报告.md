# 国务院批转卫生部关于加强工业卫生工作的请示报告

各省、市、自治区革命委员会，国务院各部委、各直属机构：

国务院同意卫生部《关于加强工业卫生工作的请示报告》，现转发给你们，望认真研究执行。

搞好工业卫生，保护环境，保护工人的健康与安全，对促进工业生产，实现四个现代化，具有十分重要的意义。望各地、各有关部门把这一工作列入重要议事日程，加强领导，采取有力措施，把这项工作做好，使工业卫生工作更好地为工业建设服务。

国务院

一九七八年十一月二十二日

关于加强工业卫生工作的请示报告

国务院：

为了贯彻落实英明领袖华主席在五届人大政府工作报告中提出的“认真做好城市和工矿企业的医疗卫生工作”的重要指示，我们邀请了几个工业交通部门主管卫生或劳动保护工作的负责同志进行了座谈。会上传达了国务院领导同志三月三十日关于加强工业卫生工作的指示。大家一致认为，华主席、党中央和国务院领导同志的指示很重要、很及时。对搞好工业卫生，保护工人的健康，促进工业生产，实现四个现代化，都具有重要意义。座谈中分析了工业卫生中存在的主要问题，讨论了今后改进工业卫生工作的意见。

伟大领袖毛主席、敬爱的周总理和英明领袖华主席对全国人民的健康历来十分关怀，对工业卫生和劳动保护工作作过许多重要指示。建国以来，党中央、国务院对工业卫生和劳动保护工作制定了一系列法令和政策，各工交系统、各省市建立了卫生和安全机构，有效地保护了广大职工群众的安全与健康。广大医药卫生人员在毛主席革命路线指引下，在各级党委的领导下，为搞好工业卫生，防治职业病、多发病，改变工矿卫生面貌，提高广大工人的健康水平勤奋工作，取得了显著成绩。

但是，近十几年来，工业卫生工作由于林彪、“四人帮”反革命修正主义路线干扰破坏，绝大部分工业交通部门和省市的工业卫生管理机构撤销或削弱了，致使工业卫生工作落后，职业病、职业中毒、多发病、常见病上升。据二十八个省、市、自治区在一九七四年至一九七六年三年中普查了二百九十多万名接触粉尘作业的工人，发现患有矽肺病的有十八万八千余人，比一九六二年增长五倍多，患病率为百分之六点四。另有可疑矽肺三十二万余人。矽肺病人以煤炭、冶金、建材部门居多。北京市普查京西煤矿井下工人一万九千八百人，查出矽肺患者四千二百人，可疑矽肺五千七百人，占受检人数的百分之四十九。职业中毒也很严重，各种急慢性中毒不断发生。据九省、市调查八千五百多名汞作业工人中，汞中毒检出率为百分之十点二。还有常见病、多发病，如高血压、肝炎、气管炎等病，也是工矿企业缺勤，影响生产的一个重要方面。据北京市调查十五个厂矿二十二万名职工，一九七五年上半年因病、伤缺勤率为百分之七点一。平均每天有一万六千人因病、伤休工。随着我国大规模现代化工业的发展，新的有害因素不可避免地将会增多，防治污染，保护环境，这些都将给工业卫生工作提出更多新任务、新要求。为了进一步加强和做好这一工作，提出以下几点意见：

一、加强党的领导，把工业卫生工作搞上去。

建议各级党委要把工业卫生工作列入重要议事日程，定期检查，每年抓几次。各级卫生部门要当好党委的参谋助手，经常深入厂矿调查了解，总结经验，抓好典型。

工业卫生工作的重点，当前是抓好工矿企业防尘防毒和职业病的防治。搞好射线防护工作。要重视保护环境，防止工业“三废”污染。争取在一、二年内使工矿企业劳动环境接近或达到国家卫生标准。基本上控制急性中毒，不断降低慢性中毒的发病率。要采取积极措施，把矽肺发病率降到历史最低水平。

二、恢复和健全工业交通部门和各省市的工业卫生管理机构。

一九五六年前，工业交通各部门都建有卫生管理机构，由于实行地方卫生部门统一领导后，各工业部门的卫生管理机构逐步撤消了。实践证明，搞好工业卫生工作必须充分发挥各工业部门和地方卫生部门的两个积极性，实行条块结合。建议国务院和各省、市、自治区的工业交通部门，根据职业危害和卫生工作任务的实际需要，恢复或健全必要的卫生管理机构，切实把本系统、本单位的卫生工作领导起来。

各省、市、自治区和工业集中城市的卫生部门都应恢复或健全工业卫生机构，以加强对工业卫生工作的领导。

为了适应职业中毒、职业病医疗的需要，加强科学研究，提高临床诊断治疗水平，积极开展对全国职业病防治工作的指导，拟在中国医学科学院卫生研究所新建职业病附属医院，病床三百张，并适当调整充实职业病临床技术力量。

各工业交通部门和各省、市、自治区工业集中的城市，应根据需要和可能逐步建立健全劳动卫生职业病防治研究机构，认真做好职业病防治研究工作。

三、由于工业卫生工作存在的问题较多，涉及面广，多年没有认真抓了，建议在明年适当时候，由我部会同有关部委、劳动总局、国务院环保领导小组，共同筹备召开全国工业卫生工作会议，总结交流工作经验，讨论研究工业卫生工作管理体制和工业卫生及职业病防治规划。使工业卫生工作更好地为工业建设服务，保证新时期总任务的胜利完成，为实现我国四个现代化作出更大贡献。

以上报告如无不妥，请批转各省、市、自治区，国务院各部委参照执行。

卫生部

一九七八年十月三十一日
