# 国务院批转国家医药管理总局关于中药广开生产门路的报告

各省、市、自治区人民政府（革命委员会），国务院各部委、各直属机构：

国务院同意国家医药管理总局《关于中药广开生产门路的报告》。现转发给你们，望研究执行。

中医中药是我国宝贵的文化遗产。我国中药资源丰富，广开生产门路大有可为。中药生产不仅为人民防病治病所需要，也能为农村社队增加收入，还可出口换取外汇，支援四化建设。

中药生产，要加强科学研究，大力培养人才，不断地提高中药材和中成药的质量。中药材经营，全国产、购、销合一，农、工、商一体，工作涉及面广，情况复杂，政策性强，望各级政府要加强领导，卫生、科研、农业、林业、外贸、商业、供销等部门要大力支持，共同把中药工作做好。

国务院

一九八〇年四月二十二日

(本文有删减)

关于中药广开生产门路的报告

国务院：

遵照中央领导同志对我局关于云南白药生产情况报告和对中央办公厅研究室调查材料《中药生产大有可为》的重要批示，我们对中药广开生产门路问题，进行了多次研究，并派出三个工作组作了重点调查。现将情况和意见报告如下：

中药是我国宝贵的文化遗产，我国劳动人民用它防治疾病已有几千年的历史，在国内外有很高的声誉，需求量越来越大。我国幅员辽阔，地处寒温热三带，中药资源十分丰富，品种繁多，有植物、动物、水产和矿物。明代李时珍《本草纲目》记载的药物有一千八百九十二种，加上清朝赵学敏《本草纲目拾遗》记载的药物七百一十六种，共有二千六百零八种。解放后，在党的中医中药政策指引下，中药品种又有较大的发展，据新编的《中药大辞典》收载的药物有五千七百六十七种，其中很多尚待发掘利用。中药材生产门路很多，有家种与野生；饲养与采集；加工与拣拾；涉及到农、林、牧、副、渔各个方面，是农村一项重要的副业收入。经药材公司系统收购的中药材数量近几年来每年约十三亿斤，价值十亿元左右。有些药材的主产区，如吉林抚松、集安、通化的人参收入占当地农副业收入三分之一，甘肃岷县的当归收入占当地农副业收入的百分之八十，对当地农业生产和农民生活关系重大。

在销售方面，中药市场广阔，潜力很大。我国人民自来有吃中药的习惯，但目前中药的消费水平还比较低。去年中药销售二十二亿元，平均每人只有二元二角多，而且地区、城乡之间极不平衡。上海平均每人每年消费中药九元多，而贵州只有一元多。河北城市平均每人每年消费中药八元多，而农村不到一元。现在广大农村特别是边、山、老、少、穷地区，缺药的情况并没解决。供应较好的北京、上海、天津等大城市，也有百种左右的中药材和一些中成药供不应求。从国际上讲，有从化学药向植物药发展的趋势，一些发达的资本主义国家采用植物药治病的日益增多。过去我国中药出口主要是东南亚一些国家和地区，现在已扩大到五大洲七十多个国家。过去绝大多数是华侨和中国血统的外籍人吃中药，现在有的外国人也吃中药，特别是滋补药逐渐增多。有些药材如甘草、姜黄、槐米、罗汉果等还作其它用途。国际医药市场对中药的需求越来越大，一九五六年中药出口仅九百零一万美元，一九七九年达到二亿七千万美元，增长二十六倍，而且一些紧缺品种不能满足供应。上述情况充分说明发展紧缺药材生产，满足国内外需要，亟为紧迫。就是目前基本平衡和逾量的品种，只要提高质量、降低成本、扩大用途、研制中成药新品种，增加销售和出口也是大有可为的。

我们初步规划，中药收购由一九八〇年十五亿六千万元到一九八五年增加到二十四亿元，增长百分之五十四；销售由一九八〇年二十二亿七千万元到一九八五年增加到三十一亿元，增长百分之三十六点五；中药出口由一九八〇年三亿美元到一九八五年增加到六亿美元，增长一倍。为了实现这个规划，必须扎扎实实地抓好以下工作：

（一）家种药材要在调整中发展提高

家种药材，目前紧缺的近三十种，逾量的有二十种，基本平衡的一百种。逾量品种虽少，但库存量大，占压资金多，仅白芍、三七、茯苓、党参、半夏等就有三亿多斤，占压资金十亿多元，影响正常的购销业务开展。对逾量品种，要一面继续调整生产，一面扩大销售，在寻找新用途、研制中成药新品种上广开门路。对基本平衡的品种要稳定种植面积，努力提高单产和质量，按计划生产。对当前国内外需要的紧缺药材，要作为主攻方向，积极发展生产。从全国讲，着重抓好贝母、黄连、银花、山芋肉、人参、杜仲、厚朴、枝子、砂仁、当归、巴戟、益智，河南的怀山药，山西、内蒙的黄芪，甘肃的红黄芪，宁夏的枸杞等品种。一九七九年这十六种药材的收购量为七十万担，根据目前产需情况，到一九八五年发展到一百万担，产值可达三亿元，社队收入将增加一亿元，如果按外贸需要出口，可为国家多换取七千万美元的外汇。

家种药材要着重抓好生产基地建设，与社队签订产销合同，有计划地组织生产，培育优良品种，积极防治病虫害，严格按照原有的商品等级规格收购。目前中药材质量普遍下降，严重影响医疗效果和出口信誉。如东北的人参上档货一至三等只占百分之十四，而南朝鲜人参一至三等占百分之八十。在香港，南朝鲜人参一吨可换二十万美元，我国人参一吨只能换四万五千美元。南朝鲜一年人参出口额高达六千三百万美元，而我国人参出口只有六百二十万美元，亟需改进栽培、加工和管理，提高质量。

（二）野生药材要发动群众做好采挖工作

野生动植物药材常用的有八百种左右。目前紧缺的主要品种有六七十种，如连翘、北五味、防风、桔梗、冬虫草、大芸、酸枣仁、知母、柏子仁、桃仁、麝香、蜈蚣、蟾酥、龟板、别甲、全虫、蛤蚧、白花蛇、祁蛇、鸡内金、蛇蜕等，这些药材都是治疗常见病、多发病的要药，只要领导重视，发动群众，及时组织采收，就可增加产量。四川、青海、西藏、甘肃等地区，要抓住产新季节，把麝香、冬虫草、川贝母、秦艽等野生药材管好收好，内蒙、新疆要把大芸采收好。湖北、江苏要总结捕捉蜈蚣、蟾酥的经验，交流推广，扩大收购。山东、河南要抓好全虫的收购工作，并研究全虫人工饲养的问题。要进一步落实经济政策，合理分配收益，对鸡内金、柏子仁等拣拾类药材，要明确谁拣拾归谁所有，集体积攒的，也要搞好收益分配。解决上山入林采药吃粮多、费衣费鞋等问题。对野生药材资源既要保护，又要合理利用，要有计划地组织采挖，有的可以建立保护区，轮封轮采，有的采种结合，扩大资源。

（三）努力发展饲养业，增加动物药材生产

动物药材是中药的重要组成部分，目前常用的有一百余种，年收购金额在一亿五千万元左右。这些动物药材多属野生野长，由于有的资源减少，有的用量增大，长期供不应求，影响医疗使用，必须区别不同品种，有计划地组织家养，扩大资源。有些动物药材价值很高，是治病的要药，如麝香、土元、海马、蛤蚧、虎骨等；有些动物药材如毛驴、乌龟、蛇类、乌鸡、田鸡等既可药用，又能提供肉食。对这些药材，不仅国家办场，有些社队也可以办场，属于家禽家畜类的，社员个人也可以饲养。动物药材的饲养早在一九五八年各地就已开始，二十多年来积累了一些经验，要认真总结推广。有些尚未成功，应继续加强科学研究。对暂时逾量的鹿茸，要提高质量，增加出口，适当降价，扩大内销，开展综合利用。

（四）大力发展中成药生产

中成药是我国独特的传统药品，它具有疗效好，服用方便，副作用小，群众乐用的特点。

发展中成药，应以提高质量为中心，增加品种，改进剂型，改进包装，确保国内常见病、多发病、地方病、老年病和疫情急救以及妇幼保健的需要。要注意生产、研究民族用药，特别是蒙藏药；同时，对国外需要的换汇率高的滋补、饮料、美容等方面的中成药，应多研究，多改进，多发展，力争多出口。

1、恢复、提高传统的名厂名药。名厂名药历史悠久，在国内外有很高声誉，据统计，全国传统的名牌中成药有一百多种，如北京同仁堂、天津达仁堂的安宫牛黄丸、乌鸡白凤丸、虎骨酒，上海、苏州雷允上的六神丸，福建漳州的片子癀，山西的定坤丹、龟龄集，四川重庆桐君阁的化症回生丹，河南郑州中药厂的婴儿素，山东的阿胶等。这些名药都是国内外畅销的品种，要根据原料情况，择优安排生产，继续提高质量，确保名牌。最近我们到云南白药厂开现场会议，把这个问题研究了一下。同时，要研制防治肿瘤、心血管、偏瘫等疾病的新的名牌中成药。

2、充分利用中草药，发展新产品。建国以来，各地已经研制几百个新品种。其中不少疗效好，深受国内外欢迎，如上海的感冒退热冲剂、伤湿止痛膏、三七露、菊花晶，江苏的排石冲剂、牛黄消炎丸，江西的夏天无片（针），天津的藿香正气水，北京的愈风宁心片等。对这些新品种、新剂型，要认真总结经验，改进提高。并继续扩大利用中草药，收集民间秘方、验方，争取到一九八五年再研制新品种二百个，丰富祖国医药宝库。

3、狠抓小品种和家庭必备常用的成药生产。小品种大有作为，上海出口的清凉油，一年能换外汇一百二十万美元。治鼻道炎的鼻渊丸，治脚气的华佗膏，防止晕车晕船的砂仁驱风油，治跌打损伤的万花油，以及午时茶、薄荷锭等都不可忽视，只要疗效确切，加强宣传，打开销路，就可以变小为大，集腋成裘。对家庭必备常用的成药，如救急水、仁丹及感冒、咳嗽、解热、外伤等药，特别是婴儿用药，也要根据需要安排生产。

目前绝大多数中成药厂，厂房陈旧，设备简陋，手工操作，卫生条件差，含杂菌量超过规定，不利于生产的发展和提高。为了推动中成药厂的改造和对外技术交流，建议北京、上海、天津、杭州、广东、山西继续把中药样板厂办好。各省市区对中成药厂的基建、技措、设备、材料、辅料等，要纳入计划优先安排，充分发挥中成药投资少、见效快、创汇高的优点，为四化提供资金。

（五）加强中药材质量管理，搞好整理加工

中药材历来有就地分等整理加工的习惯，在入药前还要经过炮炙，减少副作用，提高疗效。有些药材就地加工还可以搞综合利用。文化大革命期间，由于林彪、“四人帮”极左路线干扰破坏，不少地方不按国家规定的等级标准收购药材，致使中药材质量下降，影响疗效。为了提高中药质量，保证医疗效率，收购中药材要认真执行国家规定的规格、等级标准。要提高整理加工的质量，改进包装，逐步实行机械化、规格化、标准化，减少损失浪费。主要品种的集中产区，有条件的社队可以试办药材分等加工，增加收入。

我国饮片炮炙加工，技术精湛，工艺先进。历史上饮片就远销香港和东南亚各国，近年来香港商人要求我饮片出口，日本商人要求我按“汉方”（即我汉朝张仲景伤寒论的处方）加工成半成品出口。因此，饮片加工一定要按照传统的方法、工艺进行，同时要用现代科学积极而又慎重地改进提高。要讲究文明生产，改进加工条件，不断提高饮片炮炙加工质量，满足国内外的需要。

（六）加强科学研究，培训人才，发展中药生产

发展中药生产，科研工作亟待加强。一九七九年召开的全国医药科研座谈会确定中药科研项目三十九项，要与卫生、农林、科研、教学单位密切配合，认真落实，协同攻关。当前要重点抓好紧缺品种的研究，如麝香、猪苓、杜仲、冬虫草、贝母等。特别是麝香，除保护好野生资源、继续研究人工饲养技术外，还要加紧人工合成的科研工作，力争早日作出成果。对人参要从栽培、加工到内在成份分析，进行全面研究，提高质量。同时对一九七五年引种的西洋参进行总结，繁育种子种苗，扩大生产。要把研究三七治疗冠心病、降低胆固醇、防治肝炎等方面的新疗效、新用途，作为主攻项目。中成药着重抓好新品种、新剂型、新工艺和饮片加工连续化的研究。

中药科研力量十分薄弱，科研人员只占全行业职工总数的千分之六点七，而且水平低，很不适应中药事业的发展。为改变这种状况，要积极创造条件，建立中药科研中心，有条件的省、市、自治区根据需要建立中药研究所。要注意科研人才的培养，对现有的中等中药学校要加强领导，继续办好黑龙江商学院中药系；积极创造条件筹建中药学院；南京、沈阳药学院应增设中药系，加强中药人才的培养；西北大学、吉林农业大学增设中药专业；农林院校增设药物栽培专业，为国家培养较高水平的中药生产科技人才。对科技人员，政治上要关心，生活上要照顾，根据条件评定技术职称，调动他们的积极性。

（七）做好中药供应，保证人民防治疾病的需要

中药材公司是产、购、销合一，农、工、商一体的企业，做好中药供应，促进生产发展，对四化建设有重大意义。

当前中药供应工作的重点要放在农村，要照顾远山区，安排好工矿、林区和城市用药。对少数民族地区，要根据民族用药的特点，切实作好供应。对国际市场，要注意研究，做好预测和情报工作。要扩大经营品种，改善经营管理。一定的库存量是必要的，但目前中药库存结构不合理，二百三十个二级站库存过大，约占全国总库存额百分之六十五，二千二百多个县公司只占百分之三十五。大部分县公司和零售单位没有经营目录和库存定额，经营好坏没有标准。因此，要采取各种措施，疏通渠道，组织交流，搞好市场调节，把库存摆布好。县公司和零售单位要有合理库存，建立经营目录和库存定额。中药材多属农副土特产品，有多年生，当年生，一季产全年用，易受自然灾害，生产很不稳定，应当贯彻以丰补歉的方针，要有一定的储备，不能按一般商品对待。二级站应多时收储，少时调剂，起到蓄水池作用；根据不同品种，一般保持一年到一年半的库存。县公司应有半年库存，以适应疫情、急救和防病治病的需要。

要进一步密切医药结合，中药材的使用大部分需要通过医生处方，病患者才能服用，所以要互通情报，做到医知要情，药知医用，互相配合，共同促进和提高，更好地为病患者服务。

县药材公司应当积极支持农村合作医疗，在业务技术上指导合作医疗开展采、种、制、用中草药，使之巩固提高。

要做好旅游、外宾供应。继续贯彻国务院批准的关于对外宾供应中药材、中成药价格的规定，对旅游供应的中药材、中成药，要讲究规格、等级和质量，包装要美观大方。

要做好兽药供应。我国现在养猪三亿头、羊二亿只，大牲畜一亿头。历史上我国就有用中药治疗畜兽疾病的习惯，各级医药药材部门要根据产销情况，统筹安排畜兽用药供应。对当前供应充足的品种，要与农业部门和科研单位研究试制适于牲畜防病、治病、保健、催肥的新品种，促进我国畜牧事业的发展。

（八）内外贸密切配合，积极做好中药出口工作

中药出口，要与外贸密切配合，互相支持，统筹安排。对于国内外供应紧缺的药材，在生产发展的基础上适当挤一部分出口；基本平衡的品种，根据外贸需要满足出口；暂时逾量的品种，内外贸协作，加强宣传，研制新用途和新品种，打开销路，扩大出口。医药部门要及时向外贸部门提供中药产销情况，外贸部门也应向医药部门提供国际市场对中药的需要和换汇情况，共同做好出口工作。

目前，中药出口增加很快，一九七九年中药材出口百万美元以上的有当归、黄芪、党参、人参、虫草、三七等三十五种；中成药出口百万美元以上的有参茸制剂、三鞭丸（酒）、乌鸡白凤丸、虫草鸡精、菊花晶、精制银解片等二十余种。对这些品种要继续抓好，同时要研究发展新品种，提高竞争能力，扩大占领国际市场。

中药品种多，涉及的面广，政策性强，各级政府要加强领导，卫生、科研、农业、林业、外贸、商业、供销等部门要大力支持。药材经营部门要主动向政府和有关部门汇报，争取领导，解决存在问题，把中药生产广开门路工作做好。中药是防病治病的特殊物资，调剂面大，计划性强，应继续贯彻国务院〔1978〕111号文件精神，由中国药材公司统一计划，统一管理，统一经营，积极配合工商行政管理和药政部门，加强市场管理，取缔游医药贩，打击投机倒把，保证人民用药安全有效。中药价格要实行分级管理，充分运用价值规律，把经营搞活，把市场搞好，促进生产，有利供应。

以上报告如无不妥，请批转各省、市、自治区和有关部门研究执行。
