# 国务院办公厅关于国务院已撤三十八个非常设机构的通知

国务院各部委、各直属机构：

根据国务院机构改革方案，国务院已经撤销了科技领导小组等三十八个国务院非常设机构，并已发过文（国办通〔1988〕53号）。

现将这些机构的名单附后，特此通知。
