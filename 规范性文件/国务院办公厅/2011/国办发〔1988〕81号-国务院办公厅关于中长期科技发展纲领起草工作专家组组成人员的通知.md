# 国务院办公厅关于中长期科技发展纲领起草工作专家组组成人员的通知

各省、自治区、直辖市人民政府，国务院各部委、各直属机构:

为了充分发挥各方面专家在制定中长期科技发展纲领中的作用，以利决策的科学化、民主化，经国务院批准，成立中长期科技发展纲领起草工作专家组。这个专家组的主要任务是:受国务院的委托，负责“科技纲领”的起草和拟定工作，对若干重要问题进行讨论和审定。希望国务院各部门及各地人民政府，尤其是专家组成员所在单位对专家组的工作给予大力支持。
