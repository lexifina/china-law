# 国务院办公厅关于调整中国人民银行货币政策委员会组成人员的通知

人民银行：

你行《关于任免货币政策委员会委员的请示》（银发〔2017〕60号）收悉。根据《中国人民银行货币政策委员会条例》的有关规定，经国务院领导同意，现就调整货币政策委员会组成人员通知如下：

同意丁学东、郭树清担任货币政策委员会委员，肖捷、尚福林不再担任货币政策委员会委员职务。

国务院办公厅

2017年3月16日
