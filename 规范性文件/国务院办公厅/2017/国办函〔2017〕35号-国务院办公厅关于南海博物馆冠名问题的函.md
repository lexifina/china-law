# 国务院办公厅关于南海博物馆冠名问题的函

海南省人民政府：

你省《关于使用“国家南海博物馆”机构名称的请示》（琼府〔2017〕12号）收悉。经国务院领导同志同意，现函复如下：

南海博物馆馆名可定为“中国（海南）南海博物馆”。

国务院办公厅

2017年4月5日
