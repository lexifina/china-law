# 国务院办公厅关于调整中国人民银行货币政策委员会组成人员的通知

人民银行：

你行《关于任免货币政策委员会委员的请示》（银发〔2019〕154号）收悉。经国务院同意，现就调整货币政策委员会组成人员通知如下：

同意邹加怡担任货币政策委员会委员，刘伟（全国社会保障基金理事会理事长）不再担任货币政策委员会委员职务。

国务院办公厅

2019年6月19日
