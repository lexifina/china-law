# 教育部办公厅关于普通高中思想政治、语文和历史教学用书有关事项的通知

教材厅函〔2019〕4号

各省、自治区、直辖市教育厅（教委），新疆生产建设兵团教育局：

为做好普通高中思想政治、语文和历史教学用书工作，现就有关事项通知如下。

一、使用旧教材的省份，使用《2019年普通高中思想政治、语文和历史教学用书目录（根据2003年版课程标准编写）》中思想政治、语文和历史教材。有关事项按照教材厅函〔2019〕3号文件要求执行。

二、使用新教材的省份另行通知。

各地要高度重视，抓紧安排，确保课前到书。相关教学用书目录信息可在教育部门户网站（www.moe.gov.cn/）机构设置栏“教材局”下的“通知公告”中查询下载。

附件：2019年普通高中思想政治、语文和历史教学用书目录（根据2003年版课程标准编写）
