# 2018年全国教育经费执行情况统计公告

教育部　国家统计局　财政部关于2018年

全国教育经费执行情况统计公告

教财〔2019〕3号

一、全国教育经费情况

2018年，全国教育经费总投入为46143.00亿元，比上年的42562.01亿元增长8.41%。其中，国家财政性教育经费（主要包括一般公共预算安排的教育经费，政府性基金预算安排的教育经费，国有及国有控股企业办学中的企业拨款，校办产业和社会服务收入用于教育的经费等）为36995.77亿元，比上年的34207.75亿元增长8.15%。

二、一般公共预算教育经费情况

（一）全国一般公共预算教育经费增长情况

2018年全国一般公共预算教育经费（包括教育事业费，基建经费和教育费附加）为31992.73亿元，比上年增长6.93%。其中，中央财政教育经费5007.72亿元，比上年增长7.39%。

（二）各级教育生均一般公共预算教育经费增长情况

2018年全国幼儿园、普通小学、普通初中、普通高中、中等职业学校、普通高等学校生均一般公共预算教育经费增长情况是：

1．全国幼儿园为7671.84元，比上年的6951.49元增长10.36%。增长最快的是贵州省（29.71%）。

2．全国普通小学为11328.05元，比上年的10911.17元增长3.82%。其中，农村为10548.62元，比上年的10194.82元增长3.47%。普通小学增长最快的是河南省（10.81%）。

3．全国普通初中为16494.37元，比上年的15739.92元增长4.79%。其中，农村为14634.76元，比上年的14065.68元增长4.05%。普通初中增长最快的是安徽省（11.19%）。

4．全国普通高中为16446.71元，比上年的15138.49元增长8.64%。增长最快的是贵州省（19.89%）。

5．全国中等职业学校为16305.94元，比上年的15112.35元增长7.90%。增长最快的是江西省（24.78%）。

6．全国普通高等学校为22245.81元，比上年的21471.03元增长3.61%。增长最快的是海南省（29.78%）。

（三）各级教育生均一般公共预算教育事业费支出增长情况

2018年全国幼儿园、普通小学、普通初中、普通高中、中等职业学校、普通高等学校生均一般公共预算教育事业费支出情况是：

1．全国幼儿园为6896.28元，比上年的6183.97元增长11.52%。增长最快的是西藏自治区（23.89%）。

2．全国普通小学为10566.29元，比上年的10199.12元增长3.60%。其中，农村为10102.94元，比上年的9768.57元增长3.42%。普通小学增长最快的是河南省（10.60%）。

3．全国普通初中为15199.11元，比上年的14641.15元增长3.81%。其中，农村为13912.37元，比上年的13447.08元增长3.46%。普通初中增长最快的是安徽省（13.46%）。

4．全国普通高中为14955.66元，比上年的13768.92元增长8.62%。增长最快的是贵州省（20.27%）。

5．全国中等职业学校为14200.66元，比上年的13272.66元增长6.99%。增长最快的是青海省（26.26%）。

6．全国普通高等学校为20973.62元，比上年的20298.63元增长3.33%。增长最快的是青海省（32.85%）。

（四）各级教育生均一般公共预算公用经费支出增长情况

2018年全国幼儿园、普通小学、普通初中、普通高中、中等职业学校、普通高等学校生均一般公共预算公用经费支出情况是：

1．全国幼儿园为2431.70元，比上年的2226.39元增长9.22%。增长最快的是西藏自治区（61.50%）。

2．全国普通小学为2794.58元，比上年的2732.07元增长2.29%。其中，农村为2545.54元，比上年的2495.84元增长1.99%。普通小学增长最快的是浙江省（14.33%）。

3．全国普通初中为3907.82元，比上年的3792.53元增长3.04%。其中，农村为3460.77元，比上年的3406.72元增长1.59%。普通初中增长最快的是天津市（30.40%）。

4．全国普通高中为3646.99元，比上年的3395.59元增长7.40%。增长最快的是贵州省（40.36%）。

5．全国中等职业学校为5205.53元，比上年的4908.30元增长6.06%。增长最快的是甘肃省（54.69%）。

6．全国普通高等学校为8825.89元，比上年的8506.02元增长3.76%。增长最快的是青海省（61.05%）。

（五）一般公共预算教育经费占一般公共预算支出比例情况

2018年全国一般公共预算教育经费占一般公共预算支出220904.13亿元的比例为14.48%，比上年的14.73%降低了0.25个百分点。

三、国家财政性教育经费占国内生产总值比例情况

据统计，2018年全国国内生产总值为900309.5亿元，国家财政性教育经费占国内生产总值比例为4.11%。

附件：2018年全国教育经费执行情况统计表

教育部 国家统计局 财政部

注：1.公告中所涉及的全国性统计数据，均不包括台湾省、香港特别行政区、澳门特别行政区。

2.公告中的2018年全国国内生产总值900309.5亿元（初步核算数）和一般公共预算支出220904.13亿元均来源于《中国统计年鉴-2019》。

3.根据《中国统计年鉴-2019》中2017年全国一般公共预算支出数据，公告中将2017年一般公共预算教育经费占一般公共预算支出比例修订为14.73％。
